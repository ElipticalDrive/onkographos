# Voxel Meshing with Smooth Lighting

Also called: Biome-Driven Voxel Material (TSL), VisualMeshingJob, Voxel Surface Generation

## Overview
Voxel Meshing with Smooth Lighting is a surface extraction algorithm that generates a single quad mesh for exposed voxel faces, populating a `MeshData` buffer with vertices, indices, normals, UVs, tangents, and vertex colors based on face direction and block type [S1, unofficial]. It distinguishes itself from flat-shaded siblings by sampling 8 neighboring voxels per face to calculate smooth lighting transitions for both sun and block light, effectively baking ambient occlusion and gradient lighting into the vertex colors [S1, S2, unofficial]. This method handles both opaque and alpha (transparent) voxels, separating them into distinct index buffers for correct rendering order [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   `Voxels`: `NativeArray<VoxelData>` containing voxel IDs and flags.
    *   `SunLight`, `BlockLight`: `NativeArray<VoxelColor>` for the current chunk.
    *   `TextureRects`: `NativeArray<VoxelTextureRects>`, indexed by `voxelId - 1`.
    *   `NeighborData`: `NativeArray<VoxelColor>` for adjacent chunks (North, East, South, West) for Sun and Block light.
    *   `NeighborFlags`: `NeighborDataFlags` enum indicating which neighbor chunks have valid data.
    *   `UseSmoothLighting`: Boolean flag.
    *   Precomputed Tables: `FaceVerticesTable` (24 `float3`), `FaceNormalsTable` (6 `float3`), `NeighborOffsetsTable` (6 `int3`), `LightNeighborOffsetsTable` (48 `int3`).
*   **Outputs:**
    *   `Vertices`: `NativeList<VertexNative>`.
    *   `OpaqueIndices`: `NativeList<uint>`.
    *   `AlphaIndices`: `NativeList<uint>`.

**Data Structures:**
*   `VoxelTextureRects`: Sequential struct with fields `North`, `East`, `South`, `West`, `Top`, `Bottom` (each `float4` storing `x, y, width, height`). Access via `GetFace(faceIndex)`.
*   `VertexNative`: Sequential struct with fields:
    *   `Position`: `float3`
    *   `Normal`: `float3`
    *   `TexCoord`: `float2`
    *   `SunLight`: `uint` (packed `Color32`: `R | (G << 8) | (B << 16) | (A << 24)`)
    *   `BlockLight`: `uint` (packed `Color32`)
    *   `TileRepeat`: `float2`
*   `MeshConstants`: `WIDTH=16`, `HEIGHT=256`, `DEPTH=16`.

**Numbered Steps:**
1.  Initialize output lists: `Vertices`, `OpaqueIndices`, `AlphaIndices`.
2.  Loop `z` from 0 to `DEPTH-1`.
3.  Loop `y` from 0 to `HEIGHT-1`.
4.  Loop `x` from 0 to `WIDTH-1`.
5.  Calculate `voxelIdx = x + WIDTH * (y + HEIGHT * z)`.
6.  Get `voxel = Voxels[voxelIdx]`. If `voxel.Id == 0`, continue.
7.  Create `voxelPos = int3(x, y, z)`.
8.  Loop `face` from 0 to 5.
9.  Call `ProcessFace(voxelPos, voxel, face)`.

**ProcessFace(voxelPos, voxel, face):**
1.  Get `neighborOffset = NeighborOffsetsTable[face]`.
2.  Calculate `neighborPos = voxelPos + neighborOffset`.
3.  Determine `neighbor` voxel and light values:
    *   If `InBounds(neighborPos)`:
        *   `neighborIdx = VoxelIndex(neighborPos)`.
        *   `neighbor = Voxels[neighborIdx]`.
        *   `neighborSun = SunLight[neighborIdx]`.
        *   `neighborBlock = BlockLight[neighborIdx]`.
    *   Else:
        *   Sample from neighbor chunks based on `face` direction and `NeighborFlags`.
        *   If no neighbor data, clamp position to current chunk bounds and sample from current chunk border [S1, unofficial].
4.  Skip face generation if `neighbor.Id != 0` AND `(neighbor.Flags & VoxelFlags.AlphaRender) == 0` (neighbor is opaque) [S1, unofficial].
5.  Skip face generation if `voxel.Id == neighbor.Id` [S1, unofficial].
6.  Retrieve texture rectangle: `texRects = TextureRects[(int)voxel.Id - 1]`; `rect = texRects.GetFace(face)`.
7.  Calculate UV coordinates for the four vertices of the face quad:
    *   `uv0` (bottom-left), `uv1` (top-left), `uv2` (top-right), `uv3` (bottom-right) derived from `rect`.
8.  Determine flags:
    *   `normal = FaceNormalsTable[face]`.
    *   `isAlpha = (voxel.Flags & VoxelFlags.AlphaRender) != 0`.
    *   `isLightSource = (voxel.Flags & VoxelFlags.LightSource) != 0`.
9.  Calculate vertex lighting:
    *   If `UseSmoothLighting` is true:
        *   Call `CalculateSmoothLighting(neighborPos, face, out sunLight0..3, out blockLight0..3)`.
    *   Else (Flat Lighting):
        *   `flatSun = PackColor(neighborSun)`.
        *   `flatBlock = isLightSource ? PackColor(voxel.ColorData) : PackColor(neighborBlock)`.
        *   Assign `flatSun`/`flatBlock` to all 4 vertices.
10. Override block light for light source voxels: If `isLightSource`, set all `blockLight0..3` to `PackColor(voxel.ColorData)` [S1, unofficial].
11. Add 4 vertices to the vertex buffer. For each vertex `v` (0-3):
    *   Get `localPos` from `FaceVerticesTable[face*4 + v]`.
    *   `worldPos = voxelPos + localPos`.
    *   Assign `UV` and light values based on `v` index (`0->uv0/sun0/block0`, `1->uv1/sun1/block1`, etc.).
    *   Add `VertexNative(worldPos, normal, uv, sunLight, blockLight)` to `Vertices`.
12. Add 6 triangle indices for the quad. Use `vertexBase = Vertices.Length - 4`.
    *   Indices: `vertexBase, vertexBase+1, vertexBase+2, vertexBase, vertexBase+2, vertexBase+3`.
    *   Append to `AlphaIndices` if `isAlpha`, else `OpaqueIndices`.

**CalculateSmoothLighting(neighborPos, face, out sunLight0..3, out blockLight0..3):**
1.  Get `centerLight` via `SampleLight(neighborPos, out centerSun, out centerBlock)`.
2.  Sample 8 neighbor positions using `LightNeighborOffsetsTable[face * 8 + i]` for `i` in 0..7. Store results in `sunSamples` and `blockSamples` arrays.
3.  Calculate vertex lighting by averaging 4 light samples per vertex:
    *   Vertex 0: `AverageLight(center, samples[4], samples[5], samples[6])`.
    *   Vertex 1: `AverageLight(center, samples[6], samples[7], samples[0])`.
    *   Vertex 2: `AverageLight(center, samples[0], samples[1], samples[2])`.
    *   Vertex 3: `AverageLight(center, samples[2], samples[3], samples[4])`.

**AverageLight(center, s0, s1, s2, s3):**
1.  Decompose 4 `VoxelColors` into RGB components.
2.  Calculate average for each channel:
    *   `r = (cr + s0.r + s1.r + s2.r + s3.r) >> 2` (Note: Source says `cr + ar + br + ccr`, implying center + 3 samples, but logic implies 4 samples total including center or 4 neighbors. The source text explicitly lists `center` and 3 samples in the call, but the formula shows 4 components. Given the "8 neighbors" context, it likely averages the center and 3 adjacent light samples, or 4 specific samples. The source formula `r = (cr + ar + br + ccr) >> 2` suggests 4 components. We follow the source's explicit formula structure).
    *   *Correction based on source text*: "Vertex 0: AverageLight(center, samples[4], samples[5], samples[6])". The function `AverageLight` takes 4 arguments. The formula `r = (cr + ar + br + ccr) >> 2` implies averaging 4 values. Thus, it averages the center light and the 3 specified samples.
3.  Pack back into `uint` using `PackColor(r, g, b, 255)`.

**SampleLight(pos):**
1.  If `pos.y < 0` or `pos.y >= HEIGHT`, return black `(0,0,0)` [S1, unofficial].
2.  If `InBounds(pos)`, sample directly from `SunLight`/`BlockLight`.
3.  If out of bounds in X/Z:
    *   Check `NeighborFlags` for North/South/East/West.
    *   If flag set and wrapped position is valid within neighbor chunk dimensions, sample from neighbor chunk arrays.
    *   If no neighbor data, clamp position to current chunk bounds and sample from current chunk border [S1, unofficial].

**Pseudocode:**

```python
def VoxelMeshingWithSmoothLighting(Voxels, SunLight, BlockLight, TextureRects, NeighborData, NeighborFlags, UseSmoothLighting):
    WIDTH = 16
    HEIGHT = 256
    DEPTH = 16
    
    Vertices = []
    OpaqueIndices = []
    AlphaIndices = []
    
    # Precomputed tables assumed available
    FaceVerticesTable = [...] # 24 float3s
    FaceNormalsTable = [...] # 6 float3s
    NeighborOffsetsTable = [...] # 6 int3s
    LightNeighborOffsetsTable = [...] # 48 int3s
    
    def VoxelIndex(x, y, z):
        return x + WIDTH * (y + HEIGHT * z)
    
    def InBounds(pos):
        return 0 <= pos.x < WIDTH and 0 <= pos.y < HEIGHT and 0 <= pos.z < DEPTH
    
    def PackColor(r, g, b, a=255):
        return (r | (g << 8) | (b << 16) | (a << 24))
    
    def SampleLight(pos):
        if pos.y < 0 or pos.y >= HEIGHT:
            return (0, 0, 0)
        if InBounds(pos):
            idx = VoxelIndex(pos.x, pos.y, pos.z)
            return (SunLight[idx], BlockLight[idx])
        
        # Out of bounds in X/Z
        # Check NeighborFlags and NeighborData
        # If valid neighbor chunk, sample from it
        # Else clamp to current chunk bounds
        # [G] Implementation detail for neighbor chunk access omitted as per source cut-off
        # Assuming clamp fallback for robustness
        clamp_x = max(0, min(pos.x, WIDTH - 1))
        clamp_z = max(0, min(pos.z, DEPTH - 1))
        idx = VoxelIndex(clamp_x, pos.y, clamp_z)
        return (SunLight[idx], BlockLight[idx])

    def AverageLight(c, s0, s1, s2):
        # c, s0, s1, s2 are (r,g,b) tuples
        r = (c[0] + s0[0] + s1[0] + s2[0]) >> 2
        g = (c[1] + s0[1] + s1[1] + s2[1]) >> 2
        b = (c[2] + s0[2] + s1[2] + s2[2]) >> 2
        return PackColor(r, g, b)

    def CalculateSmoothLighting(neighborPos, face):
        centerSun, centerBlock = SampleLight(neighborPos)
        
        lightBase = face * 8
        samples = []
        for i in range(8):
            offset = LightNeighborOffsetsTable[lightBase + i]
            samplePos = neighborPos + offset
            sSun, sBlock = SampleLight(samplePos)
            samples.append((sSun, sBlock))
            
        # Vertex 0: center, samples[4], samples[5], samples[6]
        sun0 = AverageLight(centerSun, samples[4][0], samples[5][0], samples[6][0])
        block0 = AverageLight(centerBlock, samples[4][1], samples[5][1], samples[6][1])
        
        # Vertex 1: center, samples[6], samples[7], samples[0]
        sun1 = AverageLight(centerSun, samples[6][0], samples[7][0], samples[0][0])
        block1 = AverageLight(centerBlock, samples[6][1], samples[7][1], samples[0][1])
        
        # Vertex 2: center, samples[0], samples[1], samples[2]
        sun2 = AverageLight(centerSun, samples[0][0], samples[1][0], samples[2][0])
        block2 = AverageLight(centerBlock, samples[0][1], samples[1][1], samples[2][1])
        
        # Vertex 3: center, samples[2], samples[3], samples[4]
        sun3 = AverageLight(centerSun, samples[2][0], samples[3][0], samples[4][0])
        block3 = AverageLight(centerBlock, samples[2][1], samples[3][1], samples[4][1])
        
        return (sun0, sun1, sun2, sun3), (block0, block1, block2, block3)

    def ProcessFace(voxelPos, voxel, face):
        neighborOffset = NeighborOffsetsTable[face]
        neighborPos = voxelPos + neighborOffset
        
        if InBounds(neighborPos):
            neighborIdx = VoxelIndex(neighborPos.x, neighborPos.y, neighborPos.z)
            neighbor = Voxels[neighborIdx]
            neighborSun = SunLight[neighborIdx]
            neighborBlock = BlockLight[neighborIdx]
        else:
            # [G] Neighbor sampling logic for out-of-bounds
            neighborSun, neighborBlock = SampleLight(neighborPos)
            neighbor = Voxels[0] # Placeholder for ID check if not in bounds
            
        # Skip if neighbor is opaque
        if neighbor.Id != 0 and not (neighbor.Flags & VoxelFlags.AlphaRender):
            return
            
        # Skip if same block type
        if voxel.Id == neighbor.Id:
            return
            
        texRects = TextureRects[voxel.Id - 1]
        rect = texRects.GetFace(face)
        
        # Calculate UVs
        uv0 = (rect.x, rect.y)
        uv1 = (rect.x, rect.y + rect.height)
        uv2 = (rect.x + rect.width, rect.y + rect.height)
        uv3 = (rect.x + rect.width, rect.y)
        
        normal = FaceNormalsTable[face]
        isAlpha = bool(voxel.Flags & VoxelFlags.AlphaRender)
        isLightSource = bool(voxel.Flags & VoxelFlags.LightSource)
        
        if UseSmoothLighting:
            sunLights, blockLights = CalculateSmoothLighting(neighborPos, face)
        else:
            flatSun = PackColor(neighborSun)
            flatBlock = PackColor(voxel.ColorData) if isLightSource else PackColor(neighborBlock)
            sunLights = (flatSun, flatSun, flatSun, flatSun)
            blockLights = (flatBlock, flatBlock, flatBlock, flatBlock)
            
        if isLightSource:
            lightColor = PackColor(voxel.ColorData)
            blockLights = (lightColor, lightColor, lightColor, lightColor)
            
        vertexBase = len(Vertices)
        
        for v in range(4):
            localPos = FaceVerticesTable[face * 4 + v]
            worldPos = voxelPos + localPos
            
            if v == 0:
                uv, sun, block = uv0, sunLights[0], blockLights[0]
            elif v == 1:
                uv, sun, block = uv1, sunLights[1], blockLights[1]
            elif v == 2:
                uv, sun, block = uv2, sunLights[2], blockLights[2]
            else:
                uv, sun, block = uv3, sunLights[3], blockLights[3]
                
            Vertices.append({
                'Position': worldPos,
                'Normal': normal,
                'TexCoord': uv,
                'SunLight': sun,
                'BlockLight': block,
                'TileRepeat': (0, 0) # [G] Default tile repeat
            })
            
        indices = [
            vertexBase, vertexBase + 1, vertexBase + 2,
            vertexBase, vertexBase + 2, vertexBase + 3
        ]
        
        if isAlpha:
            AlphaIndices.extend(indices)
        else:
            OpaqueIndices.extend(indices)

    for z in range(DEPTH):
        for y in range(HEIGHT):
            for x in range(WIDTH):
                voxelIdx = VoxelIndex(x, y, z)
                voxel = Voxels[voxelIdx]
                if voxel.Id == 0:
                    continue
                voxelPos = (x, y, z)
                for face in range(6):
                    ProcessFace(voxelPos, voxel, face)
                    
    return Vertices, OpaqueIndices, AlphaIndices
```

## Subtopics

### [Optimized Indexed Geometry](11006-optimized-indexed-geometry.md)
Generates optimized indexed quad geometry for active voxels, reducing primitive count via heightfield data. Choose when vertex sharing is critical and heightfield data is available.

### [Chunk Meshing with Damage and Burning State](15835-chunk-meshing-with-damage-and-burning-state.md)
Generates mesh geometry for voxel chunks in WebAssembly, incorporating damage and burning state to modify vertex attributes. Choose when dynamic visual states (health, fire) require per-vertex attribute modification.

### [Voxel Mesh Generation (Greedy/Immediate)](18012-voxel-mesh-generation-greedy-immediate.md)
Generates a static Unity `Mesh` object by iterating through voxels and checking face visibility, omitting smooth lighting. Choose for simple geometric representation where lighting performance is prioritized over visual smoothness.

## Operating characteristics
*   **Time Complexity:** $O(V \cdot F \cdot L)$, where $V$ is the number of voxels, $F$ is the number of faces (6), and $L$ is the cost of lighting calculation (constant for flat, higher for smooth due to 8 neighbor samples).
*   **Memory Complexity:** $O(V)$ for vertex and index storage.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales linearly with chunk size. Chunk dimensions are fixed at $16 \times 256 \times 16$ [S1, unofficial].
*   **Strengths:** Smooth lighting transitions improve visual quality; handles alpha and opaque voxels; supports neighbor chunk sampling for seamless world rendering.
*   **Limitations:** Boundary voxels require complex neighbor data handling; smooth lighting increases computational cost per face.
*   **When to use:** When visual smoothness is important and neighbor data is available.
*   **When not:** When performance is critical and flat shading is acceptable, or when neighbor data is unavailable.

## Background
Originating from the VektorKnight/vektor-voxels project [S1, unofficial], this method is a Burst-compiled job for generating voxel chunk meshes. It was further refined in the context of TSL/WebGPU materials for "Phase 9" voxel surface exploration, where it was integrated with biome-driven fog and normal jitter for enhanced visual fidelity [S2, unofficial].
