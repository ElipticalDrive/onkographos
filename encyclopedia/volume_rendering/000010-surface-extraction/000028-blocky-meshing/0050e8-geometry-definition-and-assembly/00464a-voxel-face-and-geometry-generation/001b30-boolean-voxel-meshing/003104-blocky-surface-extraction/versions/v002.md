# Blocky Surface Extraction
Also called: Blocky
## Overview
Blocky Surface Extraction generates a voxel-aligned triangle mesh by iterating over voxels inside the isosurface and adding faces to the exterior boundary where adjacent voxels are outside the shape [S1, unofficial].
## How it works
### Inputs and Outputs
**Input:** A `VoxelGrid` providing scalar values per voxel, dimensions (`getWidth`, `getHeight`, `getDepth`), and corner position lookups (`getVoxelCornerPos`) [S1, unofficial].
**Output:** A `TriangleMesh` containing points (`float x,y,z`), faces (`int p0,p1,p2,p3,p4,p5` indices), and `faceSmoothingGroups` (`int group`) [S1, unofficial].
**Parameters:**
*   `isoLevel`: Scalar threshold separating inside from outside. Typical value: 0.0 [S1, unofficial].
*   `smoothShading`: Boolean flag. If true, `smoothGroup` is 1; if false, 0 [S1, unofficial].

### Data Structures
*   `VoxelGrid`: Accessor interface for voxel values and corner positions [S1, unofficial].
*   `HashMap<Float3, Integer> deDupMap`: Maps 3D vertex coordinates to unique mesh indices for deduplication [S1, unofficial].
*   `TriangleMesh`: Output container for points, faces, and smoothing groups [S1, unofficial].

### Algorithm Steps
1. Initialize `deDupMap` as empty [S1, unofficial].
2. Iterate $z$ from $0$ to `getDepth()`, $y$ from $0$ to `getHeight()`, $x$ from $0$ to `getWidth()` [S1, unofficial].
3. Let $v = \text{getVoxel}(x, y, z)$. If $v > \text{isoLevel}$, continue to next voxel [S1, unofficial].
4. Get corner positions: $P_{min} = \text{getVoxelCornerPos}(x, y, z)$ and $P_{max} = \text{getVoxelCornerPos}(x+1, y+1, z+1)$ [S1, unofficial].
5. Extract coordinates: $minX, minY, minZ$ from $P_{min}$ and $maxX, maxY, maxZ$ from $P_{max}$ [S1, unofficial].
6. Define 8 corner points: $p_0(minX,minY,minZ)$, $p_1(maxX,minY,minZ)$, $p_2(minX,maxY,minZ)$, $p_3(maxX,maxY,minZ)$, $p_4(minX,minY,maxZ)$, $p_5(maxX,minY,maxZ)$, $p_6(minX,maxY,maxZ)$, $p_7(maxX,maxY,maxZ)$ [S1, unofficial].
7. Get distances of 6 adjacent voxels: $d_0=\text{getVoxel}(x+1,y,z)$ [left], $d_1=\text{getVoxel}(x-1,y,z)$ [right], $d_2=\text{getVoxel}(x,y+1,z)$ [top], $d_3=\text{getVoxel}(x,y-1,z)$ [bottom], $d_4=\text{getVoxel}(x,y,z+1)$ [front], $d_5=\text{getVoxel}(x,y,z-1)$ [back] [S1, unofficial].
8. Add faces if adjacent voxel is outside ($d \ge \text{isoLevel}$):
    *   **Left Face** ($d_0 \ge \text{isoLevel}$): Add quad $(p_5, p_1, p_3, p_7)$ [S1, unofficial].
    *   **Right Face** ($d_1 \ge \text{isoLevel}$): Add quad $(p_4, p_6, p_2, p_0)$ [S1, unofficial].
    *   **Top Face** ($d_2 \ge \text{isoLevel}$): Add quad $(p_2, p_6, p_7, p_3)$ [S1, unofficial].
    *   **Bottom Face** ($d_3 \ge \text{isoLevel}$): Add quad $(p_0, p_1, p_5, p_4)$ [S1, unofficial].
    *   **Front Face** ($d_4 \ge \text{isoLevel}$): Add quad $(p_5, p_7, p_6, p_4)$ [S1, unofficial].
    *   **Back Face** ($d_5 \ge \text{isoLevel}$): Add quad $(p_0, p_2, p_3, p_1)$ [G].
9. Each quad is converted to two triangles and added to the mesh with `smoothGroup` [S1, unofficial]. Vertices are deduplicated using `deDupMap` [S1, unofficial].

### Pseudocode
```python
def blocky_surface_extraction(voxel_grid, iso_level, smooth_shading):
    de_dup_map = {}
    mesh_points = []
    mesh_faces = []
    smooth_group = 1 if smooth_shading else 0

    width = voxel_grid.get_width()
    height = voxel_grid.get_height()
    depth = voxel_grid.get_depth()

    def get_or_add_vertex(point):
        if point not in de_dup_map:
            idx = len(mesh_points)
            mesh_points.append(point)
            de_dup_map[point] = idx
        return de_dup_map[point]

    def add_quad_face(v0, v1, v2, v3):
        i0 = get_or_add_vertex(v0)
        i1 = get_or_add_vertex(v1)
        i2 = get_or_add_vertex(v2)
        i3 = get_or_add_vertex(v3)
        mesh_faces.append((i0, i1, i2, smooth_group, smooth_group, smooth_group))
        mesh_faces.append((i0, i2, i3, smooth_group, smooth_group, smooth_group))

    def get_neighbor(dx, dy, dz):
        nx, ny, nz = x + dx, y + dy, z + dz
        if 0 <= nx < width and 0 <= ny < height and 0 <= nz < depth:
            return voxel_grid.get_voxel(nx, ny, nz)
        return iso_level + 1.0  # Treat out-of-bounds as outside [G]

    for z in range(depth):
        for y in range(height):
            for x in range(width):
                voxel_val = voxel_grid.get_voxel(x, y, z)
                if voxel_val > iso_level:
                    continue

                min_pos = voxel_grid.get_voxel_corner_pos(x, y, z)
                max_pos = voxel_grid.get_voxel_corner_pos(x + 1, y + 1, z + 1)
                min_x, min_y, min_z = min_pos
                max_x, max_y, max_z = max_pos

                p0 = (min_x, min_y, min_z)
                p1 = (max_x, min_y, min_z)
                p2 = (min_x, max_y, min_z)
                p3 = (max_x, max_y, min_z)
                p4 = (min_x, min_y, max_z)
                p5 = (max_x, min_y, max_z)
                p6 = (min_x, max_y, max_z)
                p7 = (max_x, max_y, max_z)

                d0 = get_neighbor(1, 0, 0)
                d1 = get_neighbor(-1, 0, 0)
                d2 = get_neighbor(0, 1, 0)
                d3 = get_neighbor(0, -1, 0)
                d4 = get_neighbor(0, 0, 1)
                d5 = get_neighbor(0, 0, -1)

                if d0 >= iso_level:
                    add_quad_face(p5, p1, p3, p7)
                if d1 >= iso_level:
                    add_quad_face(p4, p6, p2, p0)
                if d2 >= iso_level:
                    add_quad_face(p2, p6, p7, p3)
                if d3 >= iso_level:
                    add_quad_face(p0, p1, p5, p4)
                if d4 >= iso_level:
                    add_quad_face(p5, p7, p6, p4)
                if d5 >= iso_level:
                    add_quad_face(p0, p2, p3, p1)

    return mesh_points, mesh_faces
```

### Edge Cases and Pitfalls
*   **Floating Point Precision:** Explicitly calculating min and max positions ensures identical cells match for deduplication. Failure may occur if `max_pos == min_pos + voxelSize` due to precision limits [S1, unofficial].
*   **Boundary Conditions:** Accessing `x-1`, `y-1`, `z-1` requires boundary checks or padding to avoid out-of-bounds errors. The source does not explicitly detail boundary handling [G].
*   **Back Face:** The source lists 5 face checks but omits the "Back" face ($z-1$) check. Implementation must include it for a closed manifold [G].
## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of voxels, as each voxel is visited once [G].
*   **Memory Complexity:** $O(V)$ where $V$ is the number of unique vertices on the surface [G].
*   **Strengths:** Simple implementation; produces strictly axis-aligned geometry; fast for boolean occupancy grids [G].
*   **Limitations:** "Blocky" appearance; no smoothing unless `smoothShading` is enabled (which only affects normals/grouping, not geometry); sensitive to floating point precision in vertex deduplication [G].
*   **When to use:** When a voxel-aligned aesthetic is desired or when performance is critical and smooth geometry is not required [G].
## Background
Originating from the `Chickenkeeper/IsosurfaceExtraction` project, this method is an unofficial implementation of blocky surface extraction [S1, unofficial]. It is part of a JavaFX-based isosurface visualization tool [S1, unofficial].
