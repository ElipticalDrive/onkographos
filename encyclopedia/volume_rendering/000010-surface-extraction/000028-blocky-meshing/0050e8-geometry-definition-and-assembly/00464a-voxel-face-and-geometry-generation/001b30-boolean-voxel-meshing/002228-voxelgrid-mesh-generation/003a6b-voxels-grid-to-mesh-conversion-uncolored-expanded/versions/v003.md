# Voxels Grid to Mesh Conversion (Uncolored/Expanded)

Also called: FVox::CreateRawMeshes, Raw Mesh Generation (Per-Voxel), VoxelsGridToMesh

## Overview
Converts a voxel grid into an expanded mesh representation where each occupied voxel is converted into a full cube with 8 vertices and 12 faces (6 sides, 2 triangles per side) [S1, unofficial]. This method does not share vertices between voxels [S1, unofficial]. It serves as the foundational geometry generation step for [RealityKit Voxel Mesh Generation](8784-realitykit-voxel-mesh-generation.md), which packs the expanded cube geometry into a single draw call via `MeshDescriptor` [S1, unofficial].

## How it works
**Inputs:**
- `grid`: A voxel grid object containing `Size()` (total voxels), `VoxelsPerSide()` (voxels per axis), `VoxelSize()` (physical size), `OriginX()`, `OriginY()`, `OriginZ()` (world-space origin coordinates) [S2, unofficial].
- `colors`: A `Grid<float>` containing SDF values for each voxel, used to compute vertex colors [S2, unofficial].

**Outputs:**
- A mesh object containing pre-allocated vertices and faces, storing the expanded cube geometry for all occupied voxels [S1, unofficial].

**Data Structures:**
- **Vertices**: Array pre-allocated to `max_vertices_num = grid.Size() * 8` [S2, unofficial]. Each vertex stores a 3D position and a color [S2, unofficial].
- **Faces**: Array pre-allocated to `max_faces_num = grid.Size() * 6` [S2, unofficial]. Each face stores 3 vertex indices [S1, unofficial]. The source reserves space for `grid.Size() * 6` faces but inserts 12 triangles per voxel, implying the reservation count refers to quads or is a source implementation detail [S2, unofficial].
- **Normals**: Fixed array of 6 predefined normals for the cube sides: `(0,0,1)` (BACK), `(0,1,0)` (TOP), `(1,0,0)` (RIGHT), `(0,0,-1)` (FRONT), `(0,-1,0)` (BOTTOM), `(-1,0,0)` (LEFT) [S2, unofficial].
- **Vertex Layout**: The 8 vertices of a voxel are indexed by `dx + 2*dy + 4*dz` where `dx, dy, dz \in \{0, 1\}`, corresponding to coordinates `(0,0,0)` through `(1,1,1)` in local space [S1, unofficial].
- **Face Layout**: 6 sides, each defined by 4 corner indices: Up={5,4,7,6}, Down={0,1,2,3}, Forward={5,6,2,1}, Backward={7,4,0,3}, Right={6,7,3,2}, Left={4,5,1,0} [S1, unofficial].
- **Polygon Layout**: Each side is split into 2 triangles using indices `{0,1,2}` and `{2,3,0}` [S1, unofficial].

**Parameters:**
- `SDFToRGB(value, max)`: Maps an SDF value to an RGB color, normalized by `max` [S2, unofficial].
- `max`: Maximum distance for color normalization, calculated as `max = \sqrt{3 \cdot (grid.VoxelsPerSide() \cdot grid.VoxelSize())^2}` [S2, unofficial]. This represents the diagonal length of the voxel grid [S2, unofficial].

**Steps:**
1. **Initialization**: Calculate `max_vertices_num = grid.Size() * 8` and `max_faces_num = grid.Size() * 6` [S2, unofficial]. Reserve memory for vertices and faces [S2, unofficial]. Initialize the 6 predefined normals [S2, unofficial]. Calculate `max` [S2, unofficial]. Initialize `numberVoxelInsert = 0` [S2, unofficial].
2. **Iteration**: Iterate through all voxel coordinates $(x, y, z)$ in the grid [S2, unofficial].
3. **Skip Condition**: If the voxel at $(x, y, z)$ is empty or its SDF value is `INFINITY`, skip to the next voxel [S2, unofficial].
4. **Vertex Generation**: For each occupied voxel, generate 8 vertices by iterating $dx, dy, dz \in \{0, 1\}$ [S2, unofficial]. Compute the world-space position: $pos = grid.Origin() + (x \cdot grid.VoxelSize()) + (grid.VoxelSize() \cdot dx, dy, dz)$ [S2, unofficial]. Compute the color: $color = SDFToRGB(\sqrt{colors(x, y, z)}, max)$ [S2, unofficial]. Add the vertex to the mesh [S2, unofficial].
5. **Face Generation**: Add 12 triangles (6 sides, 2 triangles per side) for the voxel [S2, unofficial]. The vertex indices are based on `numberVoxelInsert * 8` [S2, unofficial]. Use the normals array index to select the normal for each side: 0 for BACK, 1 for TOP, 2 for RIGHT, 3 for FRONT, 4 for BOTTOM, 5 for LEFT [S2, unofficial]. Insert the 3 vertex indices for each triangle into the mesh [S1, unofficial].
6. **Finalization**: Increment `numberVoxelInsert` after processing each voxel [S2, unofficial]. Shrink the mesh containers to fit [S2, unofficial]. If `ImportOption->bImportXYCenter` is set, subtract `(Size.X*0.5, Size.Y*0.5, 0)` from all `VertexPositions` [S1, unofficial]. Call `OutRawMesh.CompactMaterialIndices()` and verify `IsValidOrFixable()` [S1, unofficial].

**Pseudocode:**
```python
def voxels_grid_to_mesh_expanded(grid, colors):
    def sdf_to_rgb(value, max_val):
        normalized = max(0.0, min(1.0, value / max_val))
        return (normalized * 255, normalized * 255, normalized * 255)

    max_vertices_num = grid.size() * 8
    max_faces_num = grid.size() * 6
    
    vertices = []
    faces = []
    
    normals = [
        (0, 0, 1),   # 0: BACK
        (0, 1, 0),   # 1: TOP
        (1, 0, 0),   # 2: RIGHT
        (0, 0, -1),  # 3: FRONT
        (0, -1, 0),  # 4: BOTTOM
        (-1, 0, 0)   # 5: LEFT
    ]
    
    voxels_per_side = grid.voxels_per_side()
    voxel_size = grid.voxel_size()
    max_dist = (3 * (voxels_per_side * voxel_size) ** 2) ** 0.5
    
    number_voxel_insert = 0
    
    for x in range(grid.dim_x):
        for y in range(grid.dim_y):
            for z in range(grid.dim_z):
                if not grid.is_occupied(x, y, z) or grid.sdf(x, y, z) == float('inf'):
                    continue
                
                base_index = number_voxel_insert * 8
                for dx in [0, 1]:
                    for dy in [0, 1]:
                        for dz in [0, 1]:
                            pos_x = grid.origin_x() + (x * voxel_size) + (voxel_size * dx)
                            pos_y = grid.origin_y() + (y * voxel_size) + (voxel_size * dy)
                            pos_z = grid.origin_z() + (z * voxel_size) + (voxel_size * dz)
                            
                            sdf_val = grid.sdf(x, y, z)
                            color = sdf_to_rgb((sdf_val ** 0.5), max_dist)
                            vertices.append((pos_x, pos_y, pos_z, color))
                
                corners = [dx + 2 * dy + 4 * dz for dx in [0, 1] for dy in [0, 1] for dz in [0, 1]]
                
                face_corners = [
                    [5, 4, 7, 6], # Up
                    [0, 1, 2, 3], # Down
                    [5, 6, 2, 1], # Forward
                    [7, 4, 0, 3], # Backward
                    [6, 7, 3, 2], # Right
                    [4, 5, 1, 0]  # Left
                ]
                
                polygons = [[0, 1, 2], [2, 3, 0]]
                
                for face_c in face_corners:
                    for poly in polygons:
                        tri_indices = [base_index + corners[face_c[p]] for p in poly]
                        faces.append(tri_indices)
                
                number_voxel_insert += 1
    
    return vertices, faces
```

**Edge Cases and Pitfalls:**
- Empty voxels or `INFINITY` SDF values must be skipped to avoid degenerate geometry [S2, unofficial].
- The source reserves `grid.Size() * 6` faces but inserts 12 triangles per voxel, which may require adjusting the reservation logic to prevent out-of-bounds errors if strictly enforced [S2, unofficial].
- Color normalization depends on the grid diagonal `max`; non-cubic grids or unnormalized SDF values may produce incorrect colors [S2, unofficial].
- If `ImportOption->bImportXYCenter` is enabled, an offset of `(Size.X*0.5, Size.Y*0.5, 0)` must be subtracted from all vertex positions [S1, unofficial].

## Subtopics

### [RealityKit Voxel Mesh Generation](8784-realitykit-voxel-mesh-generation.md)
Generates a single `MeshResource` from an array of voxel positions and colors to render ~1M voxels in real time, avoiding the per-entity overhead of instantiating individual `ModelEntity` objects. It builds on [Voxels Grid to Mesh Conversion (Uncolored/Expanded)](8733-voxels-grid-to-mesh-conversion-uncolored-expanded.md) by packing the expanded cube geometry into a single draw call via `MeshDescriptor`.

## Operating characteristics
- **Time Complexity**: $O(N)$, where $N$ is the number of voxels in the grid [S2, unofficial]. Each voxel is processed once, and a constant number of vertices and faces are generated per voxel [S2, unofficial].
- **Memory Complexity**: $O(N)$ for vertices and faces. Specifically, $8N$ vertices and $12N$ triangles are generated per voxel [S2, unofficial].
- **Measured Performance**: Not given in the sources.
- **Scaling**: Linear scaling with the number of voxels. The method is suitable for dense voxel grids but may result in large mesh sizes due to the lack of vertex sharing [S1, unofficial].
- **Strengths**: Simple implementation, deterministic output, easy to parallelize [G].
- **Limitations**: High vertex count due to no vertex sharing, resulting in a larger memory footprint and potentially slower rendering compared to optimized meshing techniques [G]. The "blocky" appearance may not be suitable for all applications [G].
- **When to use**: When a simple, fast conversion from voxel grid to mesh is required, and the visual fidelity of a smooth surface is not critical [G].
- **When not to use**: When smooth surfaces are required, or when memory efficiency is a primary concern [G].

## Background
This method is part of the [cuda-mesh-voxelization](https://github.com/bigmat18/cuda-mesh-voxelization) library, which supports mesh voxelization, CSG operations, and SDF calculation [S2, unofficial]. The library uses the Jump Flooding Algorithm (JFA) for SDF computation [S2, unofficial]. The specific method for converting the voxel grid to an expanded mesh is described in the library's documentation [S2, unofficial].
