# Voxels Grid to Mesh Conversion (Uncolored/Expanded)

Also called: VoxelsGridToMesh

## Overview
This method converts a voxel grid into an expanded mesh representation where each occupied voxel is treated as an independent cube with 8 vertices and 12 triangular faces (6 sides, 2 triangles per side). Unlike marching cubes or other surface extraction techniques that share vertices between adjacent voxels to create a watertight manifold, this method does not share vertices between voxels [S1, unofficial]. It is a direct expansion technique used within the VoxelGrid Mesh Generation pipeline to generate a blocky, non-manifold mesh suitable for specific visualization or collision detection needs where vertex sharing is undesirable or unnecessary [S1, unofficial].

## How it works
**Inputs:**
- `grid`: A voxel grid object containing:
  - `Size()`: Total number of voxels in the grid.
  - `VoxelsPerSide()`: Number of voxels along one axis (assuming a cubic grid).
  - `VoxelSize()`: The physical size of a single voxel.
  - `OriginX()`, `OriginY()`, `OriginZ()`: The world-space coordinates of the grid's origin.
  - `Voxels(x, y, z)`: Accessor for voxel occupancy or state.
  - `colors(x, y, z)`: A `Grid<float>` containing Signed Distance Field (SDF) values for each voxel [S1, unofficial].
- `colors`: The SDF grid used for vertex coloring [S1, unofficial].

**Outputs:**
- `mesh`: A triangle mesh object with pre-allocated buffers for vertices and faces.

**Data Structures:**
- `mesh.Vertices`: A list of vertex positions and colors. Pre-allocated to `max_vertices_num`.
- `mesh.Faces`: A list of triangle indices. Pre-allocated to `max_faces_num`.
- `normals`: An array of 6 predefined unit normals corresponding to the 6 faces of a cube [S1, unofficial].

**Steps:**
1. **Pre-allocation:**
   - Calculate `max_vertices_num = grid.Size() * 8`.
   - Calculate `max_faces_num = grid.Size() * 6`. Note: The source code reserves space for `grid.Size() * 6` faces, but inserts 12 triangles per voxel (6 sides * 2 triangles). This implies the "face" count in the reserve might refer to quad sides or there is a discrepancy in the source's naming convention versus actual insertion count. The implementation inserts 12 triangles per voxel [S1, unofficial].
   - Call `mesh.VerticesReserve(max_vertices_num)` and `mesh.FacesReserve(max_faces_num)` [S1, unofficial].

2. **Initialization:**
   - Define the 6 normals for the cube faces in the order: BACK, FRONT, TOP, BOTTOM, RIGHT, LEFT [S1, unofficial]:
     - `normals[0] = (0, 0, 1)` (BACK)
     - `normals[1] = (0, 1, 0)` (TOP)
     - `normals[2] = (1, 0, 0)` (RIGHT)
     - `normals[3] = (0, 0, -1)` (FRONT)
     - `normals[4] = (0, -1, 0)` (BOTTOM)
     - `normals[5] = (-1, 0, 0)` (LEFT)
   - Calculate `max_dist` for color normalization:
     $$ max\_dist = \sqrt{3 \times (grid.VoxelsPerSide() \times grid.VoxelSize())^2} $$
     This represents the maximum possible distance from the origin to a corner of the grid [S1, unofficial].

3. **Iteration:**
   - Initialize `numberVoxelInsert = 0`.
   - Iterate through all voxel coordinates $(x, y, z)$ in the grid [S1, unofficial].

4. **Voxel Processing:**
   - Check if the voxel is empty or its SDF value is `INFINITY`. If so, skip to the next voxel [S1, unofficial].
   - For each occupied voxel:
     - **Generate Vertices:**
       - Iterate $dx, dy, dz$ from 0 to 1.
       - Compute vertex position:
         $$ P = (grid.OriginX() + x \times grid.VoxelSize() + dx \times grid.VoxelSize(), \dots) $$
         (Similarly for Y and Z components) [S1, unofficial].
       - Compute color:
         $$ C = SDFToRGB(\sqrt{colors(x, y, z)}, max\_dist) $$
         (Note: The source uses `std::sqrt(colors(x, y, z))` inside the color function. If `colors` contains negative SDF values, this may require handling, but the source specifies `sqrt` directly) [S1, unofficial].
       - Add vertex $(P, C)$ to `mesh.Vertices`.
     - **Generate Faces:**
       - Add 12 triangles (6 sides, 2 triangles per side) using the base index `numberVoxelInsert * 8` for the 8 vertices of the current voxel [S1, unofficial].
       - The normals array index determines the normal for each side:
         - Side 0 (BACK): Normal index 0
         - Side 1 (FRONT): Normal index 3
         - Side 2 (TOP): Normal index 1
         - Side 3 (BOTTOM): Normal index 4
         - Side 4 (RIGHT): Normal index 2
         - Side 5 (LEFT): Normal index 5
       - The specific vertex indices for the 2 triangles per side are derived from the 8 vertices of the cube. Standard cube triangulation is implied but not explicitly detailed in the source beyond "12 triangles (6 sides, 2 triangles per side)" [S1, unofficial].
     - Increment `numberVoxelInsert` [S1, unofficial].

5. **Finalization:**
   - Shrink the mesh containers to fit the actual number of inserted vertices and faces [S1, unofficial].

**Pseudocode:**

```python
def voxels_grid_to_mesh_expanded(grid, colors):
    # 1. Pre-allocation
    max_vertices_num = grid.Size() * 8
    max_faces_num = grid.Size() * 6  # Note: Source reserves this, but inserts 12 triangles per voxel
    
    mesh = Mesh()
    mesh.VerticesReserve(max_vertices_num)
    mesh.FacesReserve(max_faces_num)
    
    # 2. Initialization
    # Normals: BACK, TOP, RIGHT, FRONT, BOTTOM, LEFT
    normals = [
        (0, 0, 1),   # 0: BACK
        (0, 1, 0),   # 1: TOP
        (1, 0, 0),   # 2: RIGHT
        (0, 0, -1),  # 3: FRONT
        (0, -1, 0),  # 4: BOTTOM
        (-1, 0, 0)   # 5: LEFT
    ]
    
    voxels_per_side = grid.VoxelsPerSide()
    voxel_size = grid.VoxelSize()
    origin_x = grid.OriginX()
    origin_y = grid.OriginY()
    origin_z = grid.OriginZ()
    
    # Max distance for color normalization
    max_dist = sqrt(3 * (voxels_per_side * voxel_size) ** 2)
    
    number_voxel_insert = 0
    
    # 3. Iterate through all voxels
    for x in range(voxels_per_side):
        for y in range(voxels_per_side):
            for z in range(voxels_per_side):
                # Check if voxel is occupied
                if grid.Voxels(x, y, z) is empty or colors(x, y, z) == INFINITY:
                    continue
                
                base_index = number_voxel_insert * 8
                
                # 4. Generate 8 vertices
                vertex_indices = []
                for dx in [0, 1]:
                    for dy in [0, 1]:
                        for dz in [0, 1]:
                            # Compute position
                            vx = origin_x + x * voxel_size + dx * voxel_size
                            vy = origin_y + y * voxel_size + dy * voxel_size
                            vz = origin_z + z * voxel_size + dz * voxel_size
                            
                            # Compute color
                            # Note: Source uses sqrt(colors(x,y,z)). 
                            # If colors are SDF, negative values would cause issues with sqrt.
                            # Assuming colors are non-negative or handled by SDFToRGB.
                            sdf_val = colors(x, y, z)
                            color = SDFToRGB(sqrt(sdf_val), max_dist)
                            
                            vertex_idx = mesh.AddVertex((vx, vy, vz), color)
                            vertex_indices.append(vertex_idx)
                
                # 5. Add 12 triangles (6 sides, 2 triangles per side)
                # Mapping: 0:BACK, 1:TOP, 2:RIGHT, 3:FRONT, 4:BOTTOM, 5:LEFT
                # Standard cube triangulation for each face using the 8 vertices
                # Face 0: BACK (z=1 in local coords, indices 4,5,7 and 4,7,6)
                # Face 1: TOP (y=1, indices 2,3,7 and 2,7,6)
                # Face 2: RIGHT (x=1, indices 1,3,7 and 1,7,5)
                # Face 3: FRONT (z=0, indices 0,6,4 and 0,2,6)
                # Face 4: BOTTOM (y=0, indices 0,4,6 and 0,1,4)
                # Face 5: LEFT (x=0, indices 0,5,1 and 0,3,5)
                
                # Note: The exact vertex ordering for the 2 triangles per side 
                # is not explicitly detailed in the source, but standard cube 
                # triangulation is implied.
                
                # Back (z=1): vertices 4,5,7,6
                mesh.AddTriangle(vertex_indices[4], vertex_indices[5], vertex_indices[7])
                mesh.AddTriangle(vertex_indices[4], vertex_indices[7], vertex_indices[6])
                
                # Front (z=0): vertices 0,2,6,4
                mesh.AddTriangle(vertex_indices[0], vertex_indices[2], vertex_indices[6])
                mesh.AddTriangle(vertex_indices[0], vertex_indices[6], vertex_indices[4])
                
                # Top (y=1): vertices 2,3,7,6
                mesh.AddTriangle(vertex_indices[2], vertex_indices[3], vertex_indices[7])
                mesh.AddTriangle(vertex_indices[2], vertex_indices[7], vertex_indices[6])
                
                # Bottom (y=0): vertices 0,1,5,4
                mesh.AddTriangle(vertex_indices[0], vertex_indices[1], vertex_indices[5])
                mesh.AddTriangle(vertex_indices[0], vertex_indices[5], vertex_indices[4])
                
                # Right (x=1): vertices 1,3,7,5
                mesh.AddTriangle(vertex_indices[1], vertex_indices[3], vertex_indices[7])
                mesh.AddTriangle(vertex_indices[1], vertex_indices[7], vertex_indices[5])
                
                # Left (x=0): vertices 0,5,7,3
                mesh.AddTriangle(vertex_indices[0], vertex_indices[5], vertex_indices[7])
                mesh.AddTriangle(vertex_indices[0], vertex_indices[7], vertex_indices[3])
                
                number_voxel_insert += 1
    
    # 6. Shrink containers
    mesh.ShrinkToFit()
    
    return mesh
```

**Parameters:**
- `colors`: A `Grid<float>` containing SDF values for each voxel [S1, unofficial].

**Edge Cases and Pitfalls:**
- **SDF Values:** The source uses `std::sqrt(colors(x, y, z))` for color computation. If the SDF contains negative values (inside the object), this will result in NaN or complex numbers. The implementation assumes non-negative SDF values or that `SDFToRGB` handles the input appropriately [S1, unofficial].
- **Face Count Discrepancy:** The source reserves `grid.Size() * 6` faces but inserts 12 triangles per voxel. This suggests that the "face" count in the reserve might be counting quads or there is a bug in the source code's reservation logic. Implementers should ensure the face buffer is large enough for `grid.Size() * 12` triangles [S1, unofficial].
- **Vertex Sharing:** This method does not share vertices. This leads to a much larger mesh compared to manifold extraction methods, which impacts memory usage and rendering performance [S1, unofficial].

## Subtopics

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of voxels in the grid. Each voxel is processed independently in constant time.
- **Memory Complexity:** $O(N)$, with a constant factor of 8 vertices and 12 triangles per voxel. The memory usage is significantly higher than manifold extraction methods due to the lack of vertex sharing.
- **Performance:** The method is simple and parallelizable, as each voxel is independent. However, the large number of vertices and triangles can lead to high memory bandwidth usage during rendering [S1, unofficial].
- **Strengths:** Simple implementation, no need for complex topology management, suitable for blocky visualization.
- **Limitations:** High memory usage, non-manifold mesh, not suitable for physics simulations requiring watertight meshes [S1, unofficial].

## Background
This method is part of the `cuda-mesh-voxelization` project by bigmat18, which focuses on GPU-accelerated voxelization and CSG operations [S1, unofficial]. It is used as a step in generating a mesh representation from a voxel grid, often following SDF calculation via the Jump Flooding Algorithm (JFA) [S1, unofficial]. The project supports various voxelization techniques and CSG operations, and this specific method provides a straightforward way to visualize the voxel grid as a mesh [S1, unofficial].
