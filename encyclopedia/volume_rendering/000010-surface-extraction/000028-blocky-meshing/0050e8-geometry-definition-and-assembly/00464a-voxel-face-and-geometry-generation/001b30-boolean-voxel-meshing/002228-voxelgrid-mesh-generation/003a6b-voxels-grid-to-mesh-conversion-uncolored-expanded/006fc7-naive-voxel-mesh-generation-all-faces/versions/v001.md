# Naive Voxel Mesh Generation (All Faces)

Also called: AddBlock, GenerateGridMesh, Voxel Grid Mesh Generation (Explicit Quad Construction), VoxelGridMeshGenerator

## Overview
This method generates a mesh representation of a voxel grid by iterating through every voxel and explicitly constructing geometry for all six faces, regardless of whether the face is exposed to empty space or occluded by a neighbor [S1, unofficial]. It serves as the baseline implementation for converting a voxel grid into an expanded mesh, contrasting with optimized approaches that cull internal faces [S1, unofficial].

## How it works
**Inputs:**
- A voxel grid data structure (e.g., `space`) with dimensions `XLength`, `YLength`, `ZLength`.
- A boolean or integer value indicating voxel occupancy for each coordinate $(x, y, z)$.
- A scalar `voxelSize` defining the physical dimensions of a single voxel unit.

**Outputs:**
- A collection of `Quad` objects, each containing 4 vertex positions and a surface normal.

**Data Structures:**
- `Quad`: A struct containing:
  - `positions`: An array or list of 4 `Vector3` elements.
  - `normal`: A `Vector3` representing the face normal.
- `Vector3`: A 3D vector $(x, y, z)$.
- `VoxelSide`: An enum with values `BOTTOM`, `EAST`, `WEST`, `TOP`, `NORTH`, `SOUTH`.

**Steps:**
1. Initialize an empty list `mesh` to store `Quad` objects.
2. Iterate through the voxel grid using three nested loops for $x$, $y$, and $z$ dimensions:
   $$ \text{for } x \in [0, \text{XLength}) $$
   $$ \text{for } y \in [0, \text{YLength}) $$
   $$ \text{for } z \in [0, \text{ZLength}) $$
3. For each voxel at $(x, y, z)$, determine if the voxel is occupied. If occupied, proceed to generate geometry for all six sides. If the implementation requires generating geometry only for occupied voxels, check occupancy; otherwise, generate for all grid cells [S1, unofficial].
4. For each of the six `VoxelSide` enums, call the `AddBlock` function to generate the corresponding quad.
5. In `AddBlock(side, x, y, z, voxelSize)`:
   - Calculate the base coordinates scaled by `voxelSize`.
   - Construct the `Quad` based on the `side`:
     - **BOTTOM**: Vertices are $(x, y, z)$, $(x, y, z+1)$, $(x+1, y, z+1)$, $(x+1, y, z)$ scaled by `voxelSize`. Normal is $-Y$ ($0, -1, 0$).
     - **EAST**: Vertices are $(x+1, y, z+1)$, $(x+1, y+1, z+1)$, $(x+1, y+1, z)$, $(x+1, y, z)$ scaled by `voxelSize`. Normal is $+X$ ($1, 0, 0$).
     - **WEST**: Vertices are $(x, y, z)$, $(x, y+1, z)$, $(x, y+1, z+1)$, $(x, y, z+1)$ scaled by `voxelSize`. Normal is $-X$ ($-1, 0, 0$).
     - **TOP**: Vertices are $(x, y+1, z)$, $(x, y+1, z+1)$, $(x+1, y+1, z+1)$, $(x+1, y+1, z)$ scaled by `voxelSize`. Normal is $+Y$ ($0, 1, 0$).
     - **NORTH**: Vertices are $(x, y, z+1)$, $(x, y+1, z+1)$, $(x+1, y+1, z+1)$, $(x+1, y, z+1)$ scaled by `voxelSize`. Normal is $+Z$ ($0, 0, 1$).
     - **SOUTH**: Vertices are $(x, y, z)$, $(x, y+1, z)$, $(x+1, y+1, z)$, $(x+1, y, z)$ scaled by `voxelSize`. Normal is $-Z$ ($0, 0, -1$).
   - Add the constructed `Quad` to `mesh`.

**Pseudocode:**
```python
def generate_grid_mesh(space, voxel_size):
    mesh = []
    for x in range(space.XLength):
        for y in range(space.YLength):
            for z in range(space.ZLength):
                # Check if voxel is occupied. If the method generates for all cells, skip this check.
                if not space.is_occupied(x, y, z):
                    continue
                
                # Generate all 6 faces for this voxel
                add_block(mesh, x, y, z, voxel_size, VoxelSide.BOTTOM)
                add_block(mesh, x, y, z, voxel_size, VoxelSide.EAST)
                add_block(mesh, x, y, z, voxel_size, VoxelSide.WEST)
                add_block(mesh, x, y, z, voxel_size, VoxelSide.TOP)
                add_block(mesh, x, y, z, voxel_size, VoxelSide.NORTH)
                add_block(mesh, x, y, z, voxel_size, VoxelSide.SOUTH)
    return mesh

def add_block(mesh, x, y, z, voxel_size, side):
    # Scale grid coordinates to world space
    sx = x * voxel_size
    sy = y * voxel_size
    sz = z * voxel_size
    
    # Define vertices based on side
    if side == VoxelSide.BOTTOM:
        verts = [
            Vector3(sx, sy, sz),
            Vector3(sx, sy, sz + voxel_size),
            Vector3(sx + voxel_size, sy, sz + voxel_size),
            Vector3(sx + voxel_size, sy, sz)
        ]
        normal = Vector3(0, -1, 0)
    elif side == VoxelSide.EAST:
        verts = [
            Vector3(sx + voxel_size, sy, sz + voxel_size),
            Vector3(sx + voxel_size, sy + voxel_size, sz + voxel_size),
            Vector3(sx + voxel_size, sy + voxel_size, sz),
            Vector3(sx + voxel_size, sy, sz)
        ]
        normal = Vector3(1, 0, 0)
    elif side == VoxelSide.WEST:
        verts = [
            Vector3(sx, sy, sz),
            Vector3(sx, sy + voxel_size, sz),
            Vector3(sx, sy + voxel_size, sz + voxel_size),
            Vector3(sx, sy, sz + voxel_size)
        ]
        normal = Vector3(-1, 0, 0)
    elif side == VoxelSide.TOP:
        verts = [
            Vector3(sx, sy + voxel_size, sz),
            Vector3(sx, sy + voxel_size, sz + voxel_size),
            Vector3(sx + voxel_size, sy + voxel_size, sz + voxel_size),
            Vector3(sx + voxel_size, sy + voxel_size, sz)
        ]
        normal = Vector3(0, 1, 0)
    elif side == VoxelSide.NORTH:
        verts = [
            Vector3(sx, sy, sz + voxel_size),
            Vector3(sx, sy + voxel_size, sz + voxel_size),
            Vector3(sx + voxel_size, sy + voxel_size, sz + voxel_size),
            Vector3(sx + voxel_size, sy, sz + voxel_size)
        ]
        normal = Vector3(0, 0, 1)
    elif side == VoxelSide.SOUTH:
        verts = [
            Vector3(sx, sy, sz),
            Vector3(sx, sy + voxel_size, sz),
            Vector3(sx + voxel_size, sy + voxel_size, sz),
            Vector3(sx + voxel_size, sy, sz)
        ]
        normal = Vector3(0, 0, -1)
    else:
        return # Unknown side

    mesh.append(Quad(positions=verts, normal=normal))
```

**Parameters:**
- `voxel_size`: The physical size of a voxel. Typical value depends on the scene scale [S1, unofficial].

**Edge Cases:**
- **Occluded Faces:** This method generates geometry for faces that are internal to the voxel structure. This results in significantly higher vertex and face counts compared to methods that cull internal faces [S1, unofficial].
- **Precision:** Using floating-point arithmetic for vertex positions may introduce minor precision errors at large scales. Integer grid coordinates scaled by `voxel_size` are used to maintain consistency [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the total number of voxels in the grid. Each voxel generates a constant number of quads (6).
- **Memory Complexity:** $O(N)$, storing 6 quads per voxel.
- **Performance:** This method is simple to implement but inefficient for large scenes due to the generation of unnecessary geometry. It is suitable for small voxel grids or as a baseline for testing [S1, unofficial].
- **Strengths:** Simple logic, no neighbor checks required, consistent geometry generation.
- **Limitations:** High memory and rendering overhead due to occluded faces. Not suitable for large-scale voxel worlds where performance is critical.

## Background
This method is derived from the `GenerateGridMesh` implementation in the Wrecker project, which provides a straightforward approach to voxel mesh generation by explicitly constructing quads for all faces of each voxel [S1, unofficial]. It contrasts with the `GenerateMesh` method in the same project, which uses `FindExposedSides` to optimize geometry by only generating faces where the neighbor is empty or non-solid [S1, unofficial].
