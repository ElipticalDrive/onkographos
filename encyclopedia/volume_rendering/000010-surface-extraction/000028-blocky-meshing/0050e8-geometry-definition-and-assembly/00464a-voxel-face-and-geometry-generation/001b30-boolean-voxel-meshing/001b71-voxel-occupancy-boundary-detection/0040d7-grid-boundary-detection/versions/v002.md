# Grid Boundary Detection
Also called: RegularGrid::isBoundary
## Overview
Grid Boundary Detection determines if a voxel at $(x,y,z)$ lies on the boundary of an occupied region by checking if any voxel in its local neighborhood is empty [S1, unofficial].
## How it works
**Inputs:**
- `x, y, z`: Integer coordinates of the voxel to test.
- `numDivs`: Integer, the total number of divisions (dimensions) of the grid.
- `neighbourhoodSize`: Integer, the size of the cubic neighborhood to check.
- `grid`: 3D array where `grid[i][j][k]` returns the voxel state.

**Outputs:**
- Boolean: `true` if the voxel is on the boundary, `false` otherwise.

**Data Structures:**
- The grid is indexed from $0$ to $\text{numDivs}-1$ in each dimension [G].
- `VOXEL_EMPTY` is a constant representing unoccupied space [G].

**Steps:**
1. **Adjust Neighborhood Size:** If `neighbourhoodSize` is even, increment it by 1 to ensure odd dimensions for symmetric neighborhoods [S1, unofficial].
2. **Calculate Bounds:** Determine the minimum and maximum indices for the neighborhood in each dimension, clamped to the valid grid range $[0, \text{numDivs}-1]$ [S1, unofficial].
3. **Iterate and Check:** Iterate through all voxels in the neighborhood. If any voxel equals `VOXEL_EMPTY`, return `true` [S1, unofficial].

**Pseudocode:**
```python
VOXEL_EMPTY = 0  # Constant for empty state [G]

def is_boundary(x, y, z, numDivs, neighbourhoodSize, grid):
    # Step 1: Ensure odd neighborhood size for symmetry
    if neighbourhoodSize % 2 == 0:
        neighbourhoodSize += 1
    
    # Step 2: Calculate half-size and bounds
    half = neighbourhoodSize // 2
    x_min = max(0, x - half)
    x_max = min(numDivs - 1, x + half)
    y_min = max(0, y - half)
    y_max = min(numDivs - 1, y + half)
    z_min = max(0, z - half)
    z_max = min(numDivs - 1, z + half)
    
    # Step 3: Iterate and check for empty voxels
    for i in range(x_min, x_max + 1):
        for j in range(y_min, y_max + 1):
            for k in range(z_min, z_max + 1):
                if grid[i][j][k] == VOXEL_EMPTY:
                    return True
    return False
```

**Edge Cases and Pitfalls:**
- **Even Neighborhood Size:** Using an even size is corrected by incrementing to maintain symmetry [S1, unofficial].
- **Boundary Clamping:** Coordinates near the grid edges must be clamped to $[0, \text{numDivs}-1]$ to prevent out-of-bounds access [S1, unofficial].
