# Algorithm SD (Surface Detection)
Also called: Boundary surface extraction, Surface tracking algorithm
## Overview
Algorithm SD computes a boundary surface from a scene grid by tracking faces between voxels classified as inside or outside an object [S1]. It outputs a list of square faces, each defined by a center and a normal vector [S1]. It differs from its parent, Grid Boundary Detection, which only identifies boundary voxels, by actively tracking the specific interface and computing precise geometric properties for rendering [S1].
## How it works
**Inputs:** A scene grid $G_R$, a segmentation procedure $P$, a vector function $f$, and an initial boundary face $F_0$ [S1].
**Outputs:** A list of square faces, where each face $F$ has a center $C$ and a normal vector $N$ [S1].

**Data Structures:**
*   **Scene Grid $G_R$:** Stores density or feature values at voxel vertices [S1].
*   **Face $F$:** Represented by its center $C$ and normal $N$ [S1].
*   **Voxel $X$:** Identified by integer coordinates [S1].

**Steps:**
1.  **Initialization:** Start tracking from a known boundary face $F_0$ [S1].
2.  **Neighbor Identification:** Given a voxel $X$, a face $F$, and a direction, determine neighboring voxels $X_1$ and $X_2$ using lookup functions $N_1$ and $N_2$ [S1]. These functions are implemented as table lookups [S1].
3.  **Feature Evaluation:** Evaluate the feature vector $f(X)$ at point $X$ [S1]. If using trilinear interpolation, identify the 8 vertices of the smallest parallelepiped containing $X$ in $G_R$ and interpolate densities [S1].
4.  **Center Calculation:** Compute the center $C$ location along the line segment connecting the centers of $X_1$ and $X_2$ by finding where the decision boundary of $P$ lies [S1].
5.  **Normal Calculation:** Compute normal $N$ using six points equidistant from $C$: four at the centers of the edges of $F$, and two along the line segment connecting $X_1$ and $X_2$ [S1].
6.  **Density Sampling:** Determine the density at each of the six points using densities of 16 voxels in $G_R$ (8 with $x_3$ greater than the point's $x_3$, 8 with less) [S1].
7.  **Rendering:** Apply standard visibility and shading calculations to the generated surface faces [S1].

**Formulas:**
*   **Center Distance:** For a comparator threshold $T$ and linear interpolant $f$, the distance $d$ from $X_1$ to center $C$ is:
    $$ d = \frac{T - f(X_1)}{f(X_2) - f(X_1)} $$
    [S1]
*   **Shading:** The shading associated with a face $F$ is given by:
    $$ S(F) = k [k_d f_d(N, L) + k_s f_s(N, L)] e(d_F) + A $$
    where $k, k_d, k_s, A$ are constants, $f_d$ and $f_s$ are functions determining diffuse and specular components, and $e(d_F)$ is an attenuation factor [S1].

**Parameters:**
*   **Threshold $T$:** Used in comparator-based segmentation [S1].
*   **Interpolation:** Trilinear is common; higher-degree interpolants (e.g., cubic-spline) require larger subsets of points [S1].

**Edge Cases and Pitfalls:**
*   **Binary Scenes:** For binary scenes with different grid systems, use a scalar function $f$ estimating shortest distance to boundary (negative outside, positive inside) [S1]. Classification $P$ checks the sign of $f(X)$ [S1].
*   **Interpolation Accuracy:** The choice of classifier $P$ and function $f$ is critical; faces must truly form a boundary surface for the algorithm to work correctly [S1].
*   **Normal Computation:** Up to 96 voxels may contribute to the computation of $N$ due to the 16-voxel requirement per sample point [S1].

**Pseudocode:**
```python
def algorithm_sd(scene_grid, segmentation_procedure, feature_function, initial_face):
    """
    Computes a boundary surface from a scene grid.
    
    Args:
        scene_grid: Dict mapping (x,y,z) to density values.
        segmentation_procedure: Function P with attribute 'threshold' T.
        feature_function: Function f to evaluate features at a point.
        initial_face: Tuple (cx, cy, cz, nx, ny, nz) representing F_0.
        
    Returns:
        List of dicts with 'center' and 'normal' keys.
    """
    faces = []
    queue = [initial_face]
    visited = set()
    
    while queue:
        cx, cy, cz, nx, ny, nz = queue.pop(0)
        face_key = (int(cx), int(cy), int(cz), nx, ny, nz)
        if face_key in visited:
            continue
        visited.add(face_key)
        
        # Step 2: Identify neighboring voxels X1 and X2
        ix, iy, iz = int(cx), int(cy), int(cz)
        if nx == 1: x1, x2 = (ix-1, iy, iz), (ix, iy, iz)
        elif nx == -1: x1, x2 = (ix, iy, iz), (ix-1, iy, iz)
        elif ny == 1: x1, x2 = (ix, iy-1, iz), (ix, iy, iz)
        elif ny == -1: x1, x2 = (ix, iy, iz), (ix, iy-1, iz)
        elif nz == 1: x1, x2 = (ix, iy, iz-1), (ix, iy, iz)
        else: x1, x2 = (ix, iy, iz), (ix, iy, iz-1)
        
        # Step 3: Evaluate feature function f at X1 and X2
        f_x1 = feature_function(x1)
        f_x2 = feature_function(x2)
        
        # Step 4: Compute center C along X1-X2
        T = segmentation_procedure.threshold
        denom = f_x2 - f_x1
        d = (T - f_x1) / denom if abs(denom) > 1e-9 else 0.5
        center = (x1[0] + d*(x2[0]-x1[0]), x1[1] + d*(x2[1]-x1[1]), x1[2] + d*(x2[2]-x1[2]))
        
        # Step 5 & 6: Compute normal N using 6 equidistant points
        eps = 0.01
        points = [
            (center[0], center[1] + 0.5, center[2]),
            (center[0], center[1] - 0.5, center[2]),
            (center[0], center[1], center[2] + 0.5),
            (center[0], center[1], center[2] - 0.5),
            (center[0] - eps, center[1], center[2]),
            (center[0] + eps, center[1], center[2])
        ]
        densities = [compute_density_16_voxels(scene_grid, p) for p in points]
        
        # Pairwise differences for normal components
        nx_val = densities[0] - densities[1]
        ny_val = densities[2] - densities[3]
        nz_val = densities[4] - densities[5]
        mag = (nx_val**2 + ny_val**2 + nz_val**2)**0.5
        if mag > 0:
            nx_val, ny_val, nz_val = nx_val/mag, ny_val/mag, nz_val/mag
            
        faces.append({'center': center, 'normal': (nx_val, ny_val, nz_val)})
        
        # Add adjacent faces in the plane of F to queue
        for dx, dy, dz in [(1,0,0), (-1,0,0), (0,1,0), (0,-1,0)]:
            if nx == 0:
                nq = (center[0], center[1] + dy, center[2] + dz, nx, ny, nz)
            elif ny == 0:
                nq = (center[0] + dx, center[1], center[2] + dz, nx, ny, nz)
            else:
                nq = (center[0] + dx, center[1] + dy, center[2], nx, ny, nz)
            nkey = (int(nq[0]), int(nq[1]), int(nq[2]), nx, ny, nz)
            if nkey not in visited:
                queue.append(nq)
                
    return faces

def trilinear_interpolate(grid, p):
    ix, iy, iz = int(p[0]), int(p[1]), int(p[2])
    fx, fy, fz = p[0]-ix, p[1]-iy, p[2]-iz
    d = lambda x,y,z: grid.get((x,y,z), 0.0)
    c00 = d(ix, iy, iz)*(1-fx) + d(ix+1, iy, iz)*fx
    c01 = d(ix, iy+1, iz)*(1-fx) + d(ix+1, iy+1, iz)*fx
    c10 = d(ix, iy, iz+1)*(1-fx) + d(ix+1, iy, iz+1)*fx
    c11 = d(ix, iy+1, iz+1)*(1-fx) + d(ix+1, iy+1, iz+1)*fx
    return c00*(1-fy)*(1-fz) + c01*(1-fy)*fz + c10*fy*(1-fz) + c11*fy*fz

def compute_density_16_voxels(grid, p):
    # Uses 16 voxels: 8 with x3 > p[2], 8 with x3 < p[2]
    ix, iy = int(p[0]), int(p[1])
    iz = int(p[2])
    fz = p[2] - iz
    fy = p[1] - iy
    fx = p[0] - ix
    # Gather 2x2x4 block
    vals = []
    for dz in [-1, 0]:
        for dy in [0, 1]:
            for dx in [0, 1]:
                vals.append(grid.get((ix+dx, iy+dy, iz+dz), 0.0))
    # Interpolate over 16 points (2x2x4)
    c00 = vals[0]*(1-fz) + vals[4]*fz
    c10 = vals[1]*(1-fz) + vals[5]*fz
    c01 = vals[2]*(1-fz) + vals[6]*fz
    c11 = vals[3]*(1-fz) + vals[7]*fz
    c02 = vals[8]*(1-fz) + vals[12]*fz
    c12 = vals[9]*(1-fz) + vals[13]*fz
    c03 = vals[10]*(1-fz) + vals[14]*fz
    c13 = vals[11]*(1-fz) + vals[15]*fz
    c0 = c00*(1-fy) + c01*fy
    c1 = c10*(1-fy) + c11*fy
    c2 = c02*(1-fy) + c03*fy
    c3 = c12*(1-fy) + c13*fy
    return c0*(1-fx) + c1*fx
```
## Operating characteristics
*   **Complexity:** Not given in the sources.
*   **Performance:** Not given in the sources.
*   **Strengths:** Can compute surfaces on a grid coarser or finer than the input scene grid [S1]. Uses standard visibility and shading techniques [S1].
*   **Limitations:** Accuracy depends heavily on the choice of classifier $P$ and function $f$ [S1]. Normal computation can involve up to 96 voxels, potentially impacting performance [S1].
*   **When to use:** When a precise boundary surface representation is needed for rendering, especially when the input and output grid systems differ [S1].

## Background
Algorithm SD was introduced in the context of surface and volume rendering in three-dimensional imaging [S1]. It is designed to work with both scenes and binary scenes, regardless of whether the input and output grid systems are different or identical [S1]. The algorithm relies on a segmentation procedure $P$ and a vector function $f$ to classify voxels and evaluate features [S1].
