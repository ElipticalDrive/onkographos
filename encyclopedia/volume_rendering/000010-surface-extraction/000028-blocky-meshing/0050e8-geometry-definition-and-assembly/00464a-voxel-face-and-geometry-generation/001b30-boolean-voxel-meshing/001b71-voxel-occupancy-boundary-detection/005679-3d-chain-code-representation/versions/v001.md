# 3D Chain Code Representation

Also called: Hierarchical List of Chains, HLoC, HLoC algorithm, 3D Chain Code Representation of Voxelised Solids

## Overview
The 3D Chain Code Representation (3DCCR) is a method for describing the surfaces of voxelised solids by encoding boundary faces into a Hierarchical List of Chains (HLoC). It solves the problem of explicitly representing complex voxel geometries, including those with holes, cavities, and multiple components, while supporting edge-connectivity. Unlike methods restricted to solids without holes, this approach generates shorter, more compressible token sequences by pruning redundant paths and restructuring the hierarchy [S1].

## How it works

### Inputs and Outputs
**Input:** A voxel space $\mathcal{V}$ of resolution $X \times Y \times Z$, where each voxel $v_{i,j,k}$ has a state $s \in \{0, 1\}$ ($1$ occupied, $0$ empty). The solid $\mathcal{G}$ is assumed to be fully contained within $\mathcal{V}$ (no frontier voxels are part of $\mathcal{G}$) [S1].
**Output:** A file in the 3D Solid Chain Code (3SCC) format containing the HLoC data structures for all surfaces (outer boundaries and cavities) [S1].

### Data Structures

**1. HLoC Record**
Each record in a chain code sequence $S_s$ contains:
*   **Chain Code Symbol:** Either a pair $(i, j)$ for the 2D alphabet or a single integer $\sigma_i$ for the 3D alphabet.
*   **Branching Indices:** Two indices pointing to child sequences $S_{child1}$ and $S_{child2}$ originating from the current face. If no branching occurs, these are unset/null [S1].

**2. 3SCC File Header**
*   **Resolution:** Unsigned integers $X, Y, Z$.
*   **Surface Count:** Unsigned integer $u$ (number of HLoCs).
*   **Cavity Flags:** $\lceil u/8 \rceil$ bytes. The $k$-th bit indicates if the $k$-th HLoC is a cavity ($0$) or solid ($1$) [S1].
*   **Type Flag:** 1 byte. $0$ for 2D alphabet, $1$ for 3D alphabet [S1].

**3. HLoC Header (per surface)**
*   **Start Voxel:** 2 bytes per component $(i, j, k)$ (6 bytes total).
*   **Start Face Index:** 1 byte (0–5, representing the 6 faces of the voxel).
*   **Start Edge Index:** 1 byte (0–3, representing the 4 edges of the start face).
*   **Total Size:** 8 bytes [S1].

### Alphabet and Tokens
The method supports two alphabets. Tokens are the atomic units stored in the file.

**2D Alphabet ($\Sigma_{2D}$)**
*   **Symbols:** $\{0, 1, 2\}$.
*   **Token:** A pair $\sigma = (i, j)$ where $i, j \in \{0, 1, 2\}$.
*   **Extended Alphabet for Storage:** $\Sigma_{2D}^{store} = \{0, 1, 2, \text{'{'}, '\}'}\}$ (5 symbols) [S1].

**3D Alphabet ($\Sigma_{3D}$)**
*   **Symbols:** $\{0, 1, 2, 3, 4, 5, 6, 7, 8\}$.
*   **Token:** A single integer $\sigma_i \in \Sigma_{3D}$.
*   **Encoding Table:** The symbol $\sigma_i$ is derived from indices $i, j \in \{0, 1, 2\}$ as follows:
    *   $i=0$: $j=0 \to 0, j=1 \to 1, j=2 \to 2$
    *   $i=1$: $j=0 \to 3, j=1 \to 4, j=2 \to 5$
    *   $i=2$: $j=0 \to 6, j=1 \to 7, j=2 \to 8$
*   **Extended Alphabet for Storage:** $\Sigma_{3D}^{store} = \{0, 1, 2, 3, 4, 5, 6, 7, 8, \text{'{'}, '\}'}\}$ (11 symbols) [S1].

### Algorithm Steps

#### Phase 1: Construction of HLoC
1.  **Initialization:**
    *   Identify the set of boundary faces $\mathcal{F}$. A voxel $v$ is a boundary voxel if $s(v)=1$ and not all 6 face-connected neighbors have $s=1$. A boundary face is the face of a boundary voxel adjacent to an empty neighbor [S1].
    *   Select an arbitrary unvisited boundary face $f \in \mathcal{F}$. Mark $f$ as visited.
    *   Select an arbitrary edge $e$ on $f$. Calculate its midpoint $A$.
    *   Calculate the midpoint $C$ of face $f$. Define vector $\vec{AC}$ [S1].

2.  **Neighbor Evaluation (Traversing the Surface):**
    *   Identify three edge midpoints $B_i$ ($0 \le i < 3$) reachable from $A$ through $C$. These form angles of $90^\circ, 180^\circ, 270^\circ$ with $\vec{AC}$ in the positive mathematical sense [S1].
    *   Evaluate neighboring faces sharing each $B_i$. A neighbor is valid if it satisfies criteria $\Pi$:
        1.  It is a boundary face.
        2.  It has not been visited yet.
    *   **Case 1 (One Match):** If exactly one face $f'$ satisfies $\Pi$, calculate its midpoint $C'_j$. Determine index $j$ based on the angle between $\vec{CB_i}$ and $\vec{B_iC'_j}$. Store the token $(i, j)$ [2D] or $\sigma_i$ [3D]. Set $B_i$ as the new reference $A$, and repeat evaluation from $f'$ [S1].
    *   **Case 2 (Edge Connectivity/Three Matches):** If all three faces satisfy $\Pi$ (due to edge connectivity), select the face with the smallest angle between $\vec{CB_i}$ and $\vec{B_iC'_j}$. Store the corresponding token and continue [S1].
    *   **Case 3 (No Match/Backtracking):** If no face satisfies $\Pi$, initiate backtracking. Move back along the current sequence $S_0$ to the most recent face with unvisited neighbors. If a new branch is found, create a new sequence $S_s$ ($s > 0$) and store branching indices in the parent record. If backtracking reaches the start without finding new branches, the current surface is complete [S1].

3.  **Multiple Solids/Cavities:**
    *   After completing a surface, check if unvisited boundary faces remain in $\mathcal{F}$.
    *   If yes, select one and repeat Phase 1. This creates a new HLoC.
    *   Determine if the new HLoC is a cavity or solid using a ray-casting point-in-polyhedron test [S1].

#### Phase 2: Pruning
Pruning reduces redundancy and shortens sequences. It consists of two sub-steps.

**Pruning Step 1: Removing Redundant Endings**
1.  Sort all sequences $S_s$ in the HLoC by increasing length.
2.  Select the shortest sequence $S_a$. Start at its last element.
3.  Identify the voxel $v$ encoded by the last chain code.
4.  If $v$ is part of a branching element, skip to the next shortest sequence.
5.  If $v$ is not in a branching element, check if $v$ exists in any other sequence $S_t$ ($t \neq a$).
    *   If $v$ is **not** found in any other sequence: Move to the next shortest sequence.
    *   If $v$ **is** found: Remove the last element from $S_a$. Return to step 3 (re-evaluate the new last element).
6.  If $S_a$ becomes empty, delete it from the HLoC.
7.  Repeat until the longest sequence is processed. Use a hash table for efficient voxel lookup [S1].

**Pruning Step 2: Merging via New Branching Nodes**
1.  Mark all faces identified by the remaining HLoC codes as unvisited.
2.  Find a voxel $v$ with $>1$ unvisited faces belonging to different sequences $S_s$. Store these sequences in a temporary list $Q$ ($2 \le |Q| \le 4$). If none exist, terminate pruning.
3.  Search for the longest matching subsequences between pairs in $Q$. Move forward/backward from $v$ along sequences $S_i, S_j \in Q$.
    *   Check if faces share an edge and nodes are non-branching.
    *   Identify matched subsequences $\mathcal{A}$ and $\mathcal{B}$. At most 4 pairs are found.
4.  Select the longest pair $(\mathcal{A}, \mathcal{B})$. Length must be $> 3$. If no pair meets this, return to step 2.
5.  **Reconnection (Same Orientation):**
    *   Insert a new branching node at the end of $\mathcal{A}$.
    *   Connect this node to the continuation of the parent sequence $S_a$.
    *   Connect the node to sequence $S_b$ via a new token.
    *   Terminate $S_b$ just before the start of $\mathcal{B}$.
    *   Verify for cycles via backtracking.
        *   If a cycle occurs: Annul reconnections, swap $\mathcal{A}/\mathcal{B}$, and retry once. If it cycles again, mark faces visited, remove $\mathcal{A}/\mathcal{B}$ from $Q$, and return to step 2.
        *   If no cycle: Mark faces visited, remove $S_b$ from HLoC, and return to step 2 [S1].

#### Phase 3: Storage (DFS Encoding)
Store the HLoC in the 3SCC file using Depth-First Search (DFS):
1.  Write the global 3SCC header.
2.  For each HLoC, write the 8-byte HLoC header.
3.  Traverse the HLoC tree starting from $S_0$:
    *   Write the chain code token.
    *   If a branching index exists, write the symbol `'{'`.
    *   Recursively traverse the child branch.
    *   If no branching index exists (leaf), write the symbol `'}'` [S1].

### Pseudocode

```python
def encode_voxel_surface(voxel_grid, resolution):
    """
    Main entry point for 3D Chain Code Representation.
    voxel_grid: 3D array of 0s and 1s.
    resolution: tuple (X, Y, Z).
    Returns: bytes representing the 3SCC file.
    """
    # 1. Identify Boundary Faces
    boundary_faces = []
    for k in range(resolution[2]):
        for j in range(resolution[1]):
            for i in range(resolution[0]):
                if voxel_grid[i, j, k] == 1:
                    # Check 6 face neighbors
                    neighbors = get_face_neighbors(i, j, k, resolution)
                    if any(voxel_grid[n] == 0 for n in neighbors):
                        # Add all 6 faces of this voxel to potential boundary list
                        # Note: Only faces adjacent to empty voxels are true boundary faces
                        for face_idx in range(6):
                            neighbor = neighbors[face_idx]
                            if voxel_grid[neighbor] == 0:
                                boundary_faces.append((i, j, k, face_idx))
    
    visited_faces = set()
    hloc_list = [] # List of HLoC trees
    
    # 2. Construct HLoCs
    while boundary_faces:
        # Select arbitrary unvisited face
        start_face = boundary_faces.pop(0)
        if start_face in visited_faces:
            continue
            
        hloc = build_hloc(start_face, boundary_faces, visited_faces)
        hloc_list.append(hloc)
        
    # 3. Prune HLoCs
    for hloc in hloc_list:
        prune_hloc(hloc)
        
    # 4. Determine Cavity Status
    cavity_flags = []
    for hloc in hloc_list:
        # Ray casting test to determine if solid or cavity
        is_cavity = check_cavity(hloc, resolution)
        cavity_flags.append(0 if is_cavity else 1)
        
    # 5. Encode to 3SCC
    return encode_3scc(hloc_list, cavity_flags, resolution)

def build_hloc(start_face, all_boundary_faces, visited_faces):
    """
    Builds a single HLoC tree using DFS traversal of boundary faces.
    """
    i, j, k, f_idx = start_face
    visited_faces.add((i, j, k, f_idx))
    
    # Select arbitrary edge on face f_idx
    # Edge indices 0-3 depend on face orientation
    start_edge = 0 
    A = get_edge_midpoint(i, j, k, f_idx, start_edge)
    C = get_face_center(i, j, k, f_idx)
    vec_AC = C - A
    
    # Initialize root sequence
    root_sequence = Sequence()
    current_face = (i, j, k, f_idx)
    current_A = A
    current_vec_AC = vec_AC
    
    # Stack for DFS traversal of the HLoC tree
    # Each item: (current_face, current_A, current_vec_AC, parent_sequence, branch_index)
    stack = [(current_face, current_A, current_vec_AC, root_sequence, None)]
    
    while stack:
        face, A, vec_AC, parent_seq, branch_idx = stack.pop()
        
        # Evaluate neighbors
        B_candidates = get_edge_midpoints_from_AC(A, vec_AC) # Returns 3 midpoints B0, B1, B2
        valid_neighbors = []
        
        for idx, B in enumerate(B_candidates):
            # Find faces sharing midpoint B
            neighbor_faces = get_faces_sharing_midpoint(B)
            for nf in neighbor_faces:
                if nf not in visited_faces and is_boundary_face(nf):
                    valid_neighbors.append((idx, nf, B))
        
        if len(valid_neighbors) == 1:
            idx, next_face, B = valid_neighbors[0]
            # Case 1: One match
            C_next = get_face_center(*next_face)
            j_idx = get_angle_index(B, C_next, B) # Angle between CB and BC'
            token = encode_token(idx, j_idx)
            parent_seq.add_token(token)
            
            visited_faces.add(next_face)
            # Continue traversal
            new_A = B
            new_vec_AC = C_next - new_A
            stack.append((next_face, new_A, new_vec_AC, parent_seq, None))
            
        elif len(valid_neighbors) == 3:
            # Case 2: Edge connectivity
            # Select face with smallest angle
            best_match = None
            min_angle = infinity
            for idx, next_face, B in valid_neighbors:
                C_next = get_face_center(*next_face)
                angle = get_angle(B, C_next, B)
                if angle < min_angle:
                    min_angle = angle
                    best_match = (idx, next_face, B)
            
            idx, next_face, B = best_match
            C_next = get_face_center(*next_face)
            j_idx = get_angle_index(B, C_next, B)
            token = encode_token(idx, j_idx)
            parent_seq.add_token(token)
            
            visited_faces.add(next_face)
            new_A = B
            new_vec_AC = C_next - new_A
            stack.append((next_face, new_A, new_vec_AC, parent_seq, None))
            
        else:
            # Case 3: No match -> Backtracking/Branching
            # Find unvisited neighbors of current face to create branches
            unvisited_neighbors = []
            for idx, B in enumerate(B_candidates):
                neighbor_faces = get_faces_sharing_midpoint(B)
                for nf in neighbor_faces:
                    if nf not in visited_faces and is_boundary_face(nf):
                        unvisited_neighbors.append((idx, nf, B))
            
            for idx, next_face, B in unvisited_neighbors:
                # Create new branch
                new_seq = Sequence()
                parent_seq.add_branch(new_seq)
                
                visited_faces.add(next_face)
                C_next = get_face_center(*next_face)
                j_idx = get_angle_index(B, C_next, B)
                token = encode_token(idx, j_idx)
                new_seq.add_token(token)
                
                new_A = B
                new_vec_AC = C_next - new_A
                stack.append((next_face, new_A, new_vec_AC, new_seq, None))
                
    return root_sequence

def prune_hloc(hloc):
    """
    Applies pruning steps to reduce sequence length.
    """
    # Step 1: Remove redundant endings
    sequences = get_all_sequences(hloc)
    sequences.sort(key=len)
    
    for seq in sequences:
        while seq:
            last_token = seq[-1]
            voxel = decode_voxel(last_token)
            
            if is_branching_voxel(voxel, hloc):
                break # Cannot prune if in branching element
            
            # Check if voxel exists in other sequences
            found_in_other = False
            for other_seq in sequences:
                if other_seq is seq: continue
                if voxel_in_sequence(voxel, other_seq):
                    found_in_other = True
                    break
            
            if not found_in_other:
                break # Cannot prune
            
            seq.remove_last()
            if not seq:
                remove_sequence_from_hloc(hloc, seq)

    # Step 2: Merge via new branching nodes
    while True:
        mark_all_faces_unvisited(hloc)
        Q = find_voxel_with_multiple_unvisited_faces(hloc)
        if not Q:
            break
            
        # Find longest matching subsequences in Q
        pairs = find_longest_matches(Q)
        if not pairs:
            continue
            
        A, B = select_longest_pair(pairs)
        if len(A) < 3 or len(B) < 3:
            continue
            
        # Reconnect
        try:
            insert_branching_node(A, B, hloc)
            mark_faces_visited(A, B)
            remove_sequence_from_hloc(hloc, B)
        except CycleError:
            # Handle cycle logic as per spec
            pass

def encode_3scc(hloc_list, cavity_flags, resolution):
    """
    Encodes HLoCs into 3SCC binary format using DFS.
    """
    buffer = bytearray()
    
    # Global Header
    buffer.extend(struct.pack('III', *resolution))
    buffer.extend(struct.pack('I', len(hloc_list)))
    
    # Cavity flags
    num_bytes = (len(hloc_list) + 7) // 8
    flag_byte = 0
    for i, is_cavity in enumerate(cavity_flags):
        if is_cavity == 0: # Cavity
            flag_byte |= (1 << i)
    buffer.extend(flag_byte.to_bytes(num_bytes, 'little'))
    
    # Type flag (assuming 3D for this example, or detect from HLoC)
    buffer.extend(b'\x01') 
    
    # HLoC Data
    for hloc in hloc_list:
        # HLoC Header
        start_voxel = hloc.get_start_voxel()
        buffer.extend(struct.pack('HHH', *start_voxel))
        buffer.extend(struct.pack('B', hloc.get_start_face()))
        buffer.extend(struct.pack('B', hloc.get_start_edge()))
        
        # DFS Encoding
        encode_sequence_dfs(hloc.root, buffer)
        
    return bytes(buffer)

def encode_sequence_dfs(sequence, buffer):
    """
    Recursively encodes a sequence and its branches.
    """
    for token in sequence.tokens:
        buffer.extend(encode_token_to_byte(token))
        
    for branch in sequence.branches:
        buffer.extend(b'{')
        encode_sequence_dfs(branch, buffer)
        buffer.extend(b'}')
```

## Operating characteristics

**Time Complexity:**
*   **Construction:** $O(N)$ where $N$ is the number of boundary faces, as each face is visited once during the initial traversal. Backtracking adds overhead proportional to the number of branches.
*   **Pruning:** The first pruning step is $O(S \log S)$ for sorting sequences, where $S$ is the number of sequences. The second step involves searching for matches, which can be costly depending on the number of sequences and their lengths, but is bounded by the total number of tokens.
*   **Storage:** Linear in the size of the pruned HLoC.

**Memory Complexity:**
*   Requires storage for the voxel grid ($O(XYZ)$), the boundary face list ($O(N)$), and the HLoC structure. The HLoC size is significantly smaller than the raw voxel grid for smooth surfaces due to compression.

**Measured Performance:**
*   Compared to Lemus et al.'s method (which does not support holes), this method generates sequences up to 10% shorter on average [S1].
*   The information entropy of the token sequences is lower, resulting in better compression when using standard compressors like gzip and bzip2 [S1].

**Strengths:**
*   Handles complex topologies (holes, cavities, multiple components).
*   Supports edge-connectivity.
*   Produces compact, compressible representations.

**Limitations:**
*   Pruning algorithm complexity can be high for very fragmented surfaces.
*   Requires careful handling of edge cases in backtracking to avoid infinite loops or missed faces.

## Background

The method was introduced in a 2025 paper titled "An algorithm for voxelised solids representation using chain codes" [S1]. It extends earlier 2D chain code concepts (Freeman F4/F8) and previous 3D chain code attempts [S1]. The key innovation is the hierarchical structure (HLoC) combined with a specific pruning strategy that allows for the representation of solids with holes and cavities, addressing limitations of prior methods like Lemus et al.'s [S1].
