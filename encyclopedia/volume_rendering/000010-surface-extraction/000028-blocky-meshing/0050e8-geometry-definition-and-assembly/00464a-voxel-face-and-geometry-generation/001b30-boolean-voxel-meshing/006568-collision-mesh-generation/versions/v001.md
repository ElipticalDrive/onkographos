# Collision Mesh Generation

Also called: Lichtfeld Collision Mesh Generation, Voxel Enclosure Mesh

## Overview
Collision Mesh Generation creates a watertight triangular mesh from a set of 3D splat points by voxelizing the input, enclosing the occupied voxels with vertical walls and a ceiling, and extracting the surface [S1, unofficial]. It differs from standard surface extraction methods by explicitly constructing an enclosure (floor, walls, roof) to ensure the resulting mesh is closed and suitable for physics collision detection, rather than just representing the visible surface of the points [S1, unofficial]. It offers two modes: smooth (using marching cubes on a blurred field) and blocky (using planar merging of voxel faces) [S1, unofficial].

## How it works
**Inputs:**
- `points`: Array of 3D coordinates (world space).
- `spacing`: Voxel grid resolution in meters.
- `wall_height`: Height of vertical walls above the highest point.
- `smoothing`: Gaussian sigma for smooth mode (0.0 to 0.45).
- `opacity_cutoff`: Minimum opacity to include (filtering).
- `smooth`: Boolean flag for smooth vs. blocky mode.

**Outputs:**
- `vertices`: List of 3D coordinates (world space).
- `faces`: List of triangle indices.
- Metadata: `ceilingHeight`, `highestSelectedHeight`, `cells`, `voxels`, `boundaryEdges`.

**Data Structures:**
- `solids`: Set of integer tuples `(x, y, z)` representing occupied voxel coordinates in internal space.
- `floor`: Dictionary mapping `(x, z)` to minimum `y` (bottom) voxel index.
- `planes`: Dictionary mapping `(axis, sign, level)` to set of `(u, v)` tile coordinates for blocky mode.

**Steps:**

1. **Coordinate Transformation:** Transform input points from world coordinates to internal coordinates by applying scaling `[-1, -1, 1]`. This sets -Y as up and flips X/Y [S1, unofficial].
   $$ P_{internal} = P_{world} \times [-1, -1, 1] $$

2. **Voxelization:** Floor the coordinates divided by spacing to get voxel indices. Filter by opacity if provided.
   $$ V = \text{unique}(\lfloor P_{internal} / \text{spacing} \rfloor) $$

3. **Floor Footprint:** For each `(x, z)` column in `V`, find the minimum `y` (bottom) voxel.
   $$ \text{floor}[x, z] = \min \{ y \mid (x, y, z) \in V \} $$

4. **Ceiling Calculation:** Determine the highest selected Y coordinate, add `wall_height`, and calculate the roof layer index.
   $$ y_{max} = \max \{ y \mid (x, y, z) \in V \} $$
   $$ \text{ceiling} = (y_{max} + 1) \times \text{spacing} + \text{wall\_height} $$
   $$ \text{roof\_layer} = \lceil \text{ceiling} / \text{spacing} \rceil - 1 $$

5. **Enclosure Expansion:** For each `(x, z)` in `floor`:
   - Check the 4 horizontal neighbors: `(x±1, z)` and `(x, z±1)`.
   - If any neighbor is missing from `floor` (exposed), add all voxels from `floor[x, z]` up to `roof_layer` for `(x, z)` to `solids`.
   - If all neighbors exist (enclosed), add only the top voxel `(x, roof_layer, z)` to `solids`.
   This creates vertical walls around exposed edges and a flat roof over enclosed areas [S1, unofficial].

6. **Surface Extraction:**
   - **Smooth Mode:** Create a scalar field from `solids`, apply Gaussian blur, and run Marching Cubes.
   - **Blocky Mode:** Detect exposed faces, merge adjacent planar quads into triangles.

7. **Output Transformation:** Transform output vertices back to world coordinates by applying scaling `[-1, -1, 1]` [S1, unofficial].

**Pseudocode:**

```python
import math
import numpy as np

def collision_mesh_generation(points, spacing, wall_height, smoothing=0.35, smooth=True):
    # 1. Coordinate Transformation
    # Scale: [-1, -1, 1]
    points = points * np.array([-1, -1, 1], dtype=np.float64)
    
    # 2. Voxelization
    # Floor coordinates divided by spacing
    voxel_coords = np.floor(points / spacing).astype(np.int64)
    # Get unique voxels
    selected = np.unique(voxel_coords, axis=0)
    
    if len(selected) == 0:
        return {'vertices': [], 'faces': [], 'ceilingHeight': 0, 'highestSelectedHeight': 0, 'surfaceMode': 'blocky', 'smoothing': 0, 'cells': [], 'voxels': [], 'boundaryEdges': 0}

    solids = set(map(tuple, selected))
    
    # 3. Floor Footprint
    floor = {}
    for x, y, z in solids:
        key = (x, z)
        if key not in floor or y < floor[key]:
            floor[key] = y
            
    # 4. Ceiling Calculation
    highest_y = float(selected[:, 1].max())
    ceiling = (highest_y + 1) * spacing + wall_height
    roof_layer = math.ceil(ceiling / spacing) - 1
    
    # 5. Enclosure Expansion
    boundary_edges = 0
    for (x, z), bottom in floor.items():
        # Check 4 horizontal neighbors
        neighbors = [(x-1, z), (x+1, z), (x, z-1), (x, z+1)]
        exposed_count = sum(1 for k in neighbors if k not in floor)
        boundary_edges += exposed_count
        
        if exposed_count > 0:
            # Add all voxels from bottom to roof_layer
            for y in range(bottom, roof_layer + 1):
                solids.add((x, y, z))
        else:
            # Add only the top voxel
            solids.add((x, roof_layer, z))
            
    # 6. Surface Extraction
    if smooth:
        vertices, faces = smooth_surface(solids, spacing, ceiling, roof_layer, smoothing)
    else:
        vertices, faces = surface(solids, spacing, ceiling, roof_layer)
        
    # 7. Output Transformation
    # Scale back: [-1, -1, 1]
    vertices = np.array(vertices) * np.array([-1, -1, 1], dtype=np.float64)
    
    return {
        'version': 2,
        'spacing': spacing,
        'wallHeight': wall_height,
        'ceilingHeight': ceiling,
        'highestSelectedHeight': highest_y,
        'surfaceMode': 'smooth' if smooth else 'blocky',
        'smoothing': smoothing if smooth else 0.0,
        'cells': [[x, z, y * spacing] for (x, z), y in sorted(floor.items())],
        'voxels': sorted(list(solids)),
        'vertices': vertices.tolist(),
        'faces': faces,
        'boundaryEdges': boundary_edges
    }

def smooth_surface(voxels, spacing, ceiling, roof_layer, smoothing=0.35, max_samples=32000000, max_faces=2000000):
    if not 0 <= smoothing <= 0.45:
        raise ValueError('Smoothing must be between 0 and 0.45 voxels.')
        
    positions = np.asarray(sorted(voxels), dtype=np.int64)
    low = positions.min(axis=0) - 2
    shape = positions.max(axis=0) - low + 3
    
    if math.prod(map(int, shape)) > max_samples:
        raise ValueError('Smooth remesh grid exceeds 32 million samples.')
        
    field = np.zeros(tuple(shape), dtype=np.float32)
    indices = positions - low
    field[tuple(indices.T)] = 1.0
    
    if smoothing:
        from scipy.ndimage import gaussian_filter
        field = gaussian_filter(field, sigma=smoothing, mode='constant', cval=0., truncate=3.)
        
    from skimage.measure import marching_cubes
    vertices, faces, _, _ = marching_cubes(field, level=0.5, spacing=(spacing,) * 3, allow_degenerate=False, method='lewiner')
    
    # Shift vertices to align with voxel centers
    vertices = vertices.astype(np.float64) + (low + 0.5) * spacing
    
    # Clamp roof vertices
    roof_bottom = roof_layer * spacing
    top_region = vertices[:, 1] >= roof_bottom
    vertices[top_region, 1] = roof_bottom + (vertices[top_region, 1] - roof_bottom) * (ceiling - roof_bottom) / spacing
    
    # Ensure flat top
    top = vertices[:, 1].max()
    vertices[np.isclose(vertices[:, 1], top, atol=1e-7, rtol=0), 1] = ceiling
    
    # Ensure outward winding
    triangles = vertices[faces]
    volume = np.einsum('ij,ij->i', triangles[:, 0], np.cross(triangles[:, 1], triangles[:, 2])).sum()
    if volume < 0:
        faces = faces[:, [0, 2, 1]]
        
    return vertices.tolist(), faces.tolist()

def surface(voxels, spacing, ceiling, roof_layer, max_quads=1000000):
    planes = {}
    for p in voxels:
        for axis in range(3):
            other = [a for a in range(3) if a != axis]
            for sign in [-1, 1]:
                q = list(p)
                q[axis] += sign
                if tuple(q) not in voxels:
                    key = (axis, sign, p[axis] + (sign > 0))
                    planes.setdefault(key, set()).add((p[other[0]], p[other[1]]))
                    
    vertices = []
    faces = []
    lookup = {}
    
    def vertex(p):
        point = [v * spacing for v in p]
        if p[1] == roof_layer + 1:
            point[1] = ceiling
        key = tuple(point)
        if key not in lookup:
            lookup[key] = len(vertices)
            vertices.append(point)
        return lookup[key]
        
    quads = 0
    for (axis, sign, level), tiles in sorted(planes.items()):
        other = [a for a in range(3) if a != axis]
        for u, v in sorted(tiles):
            if (u, v) not in tiles:
                continue
            # Expand width
            width = 1
            while (u + width, v) in tiles:
                width += 1
            # Expand height
            height = 1
            while all((u + i, v + height) in tiles for i in range(width)):
                height += 1
                
            # Remove processed tiles
            for i in range(width):
                for j in range(height):
                    tiles.remove((u + i, v + j))
                    
            # Create corners
            corners = []
            for a, b in [(u, v), (u + width, v), (u + width, v + height), (u, v + height)]:
                p = [0, 0, 0]
                p[axis] = level
                p[other[0]] = a
                p[other[1]] = b
                corners.append(vertex(p))
                
            # Ensure consistent winding
            if sign != (-1 if axis == 1 else 1):
                corners.reverse()
                
            a, b, c, d = corners
            faces.extend([[a, b, c], [a, c, d]])
            quads += 1
            
    return vertices, faces
```

**Parameters:**
- `spacing`: Voxel grid resolution in meters. Typical values: 0.05, 0.1 (default), 0.2, 0.5, 1.0. Valid range: 0.025 to 1.0 [S1, unofficial].
- `wall_height`: Height of vertical walls extending above the highest selected splat. Typical values: 0.5 to 10.0 meters. Valid range: 0.5 to 20.0 [S1, unofficial].
- `smoothing`: Sigma for the Gaussian filter applied before marching cubes. Valid range: 0.0 to 0.45 voxels. Default: 0.35 [S1, unofficial].
- `opacity_cutoff`: Minimum splat opacity (0.01 to 0.95) to include in the mesh. Used to filter transparent splats/floaters [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Coordinate System:** The internal coordinate system uses -Y as up. Export functions (OBJ, GLB) must flip X and Y back to match the scene's world coordinates [S1, unofficial].
- **Smooth Mode Alignment:** Marching cubes operates on a scalar field where samples are at voxel centers. The resulting vertices (at grid corners) must be shifted by `(low + 0.5) * spacing` to align with voxel centers [S1, unofficial].
- **Smooth Mode Roof:** Vertices at the roof level must be clamped to the exact ceiling height to ensure a flat top [S1, unofficial].
- **Winding Order:** Triangle winding order must be outward-facing. This is checked by computing the signed volume of the mesh using the scalar triple product. If volume < 0, face indices are reversed [S1, unofficial].
- **Grid Size Limits:** Smooth mode raises an error if the grid exceeds 32 million samples. Blocky mode raises an error if the enclosure exceeds 5 million voxels [S1, unofficial].

## Subtopics

### [Smooth Mode](#how-it-works)
Uses marching cubes on a Gaussian-blurred voxel field, producing curved surfaces. Choose when smooth geometry is required.

### [Blocky Mode](#how-it-works)
Merges adjacent planar faces into quads/triangles, producing axis-aligned flat surfaces. Choose when performance or exact voxel alignment is required.

## Operating characteristics
- **Time Complexity:** Depends on the number of voxels and the surface extraction method. Smooth mode involves Gaussian blur and Marching Cubes, which are generally more expensive than the planar merging in blocky mode.
- **Memory Complexity:** Proportional to the number of voxels in the enclosure. Smooth mode requires a dense scalar field grid, which can be large if the bounding box is big but sparse. Blocky mode stores only exposed faces.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Smooth mode scales with the volume of the bounding box of the voxelized points. Blocky mode scales with the surface area of the enclosure.
- **Strengths:** Produces watertight meshes suitable for collision detection. Handles sparse point clouds by creating an enclosure. Offers both smooth and blocky outputs.
- **Limitations:** The enclosure adds volume not present in the original points. Smooth mode may introduce artifacts if smoothing is too high. Blocky mode is limited to axis-aligned surfaces.
- **When to use:** When a watertight collision mesh is needed from 3D splat points or voxel data.
- **When not to use:** When the exact surface geometry of the points is required without an enclosure, or when the points are already dense and form a closed surface.

## Background
Collision Mesh Generation is part of the Lichtfeld Collision Mesh toolset, developed by MisterE123 [S1, unofficial]. It is designed to convert 3D splat points into collision-ready meshes for use in game engines and simulation environments. The method combines voxelization, enclosure generation, and surface extraction to ensure the resulting mesh is watertight and properly oriented [S1, unofficial].
