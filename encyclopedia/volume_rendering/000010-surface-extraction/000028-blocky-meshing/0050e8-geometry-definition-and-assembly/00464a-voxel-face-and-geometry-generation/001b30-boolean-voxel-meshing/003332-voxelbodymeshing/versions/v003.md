# VoxelBodyMeshing

Also called: Voxel Body Mesh Building

## Overview
VoxelBodyMeshing is a blocky surface extraction method that converts a boolean voxel occupancy grid into a triangular mesh by processing sub-chunks of a `VoxelBody` [S1, unofficial]. It builds on [Boolean Voxel Meshing](971-boolean-voxel-meshing.md) by handling the meshing of individual chunks in a multi-threaded worker loop, supporting both hard-edged (face-merging) and smooth (Marching Cubes) modes [S1, unofficial]. It is distinct from sibling methods by its specific integration with the `VoxelEngine` architecture, using a thread-local `MeshGrid` and `MeshBuilder` to output `ChunkMeshData` parts that are transformed into body-local coordinates to allow shared model matrices [S1, unofficial].

## How it works
**Inputs and outputs:**
- **Input:** A `VoxelBody` instance providing voxel data via `body.Get(x, y, z)`, `body.Refinements` (tuples of index and field), and `body.ColorOrigin` [S1, unofficial]. A chunk origin `(originX, originY, originZ)` and a chunk `size` (typically `VoxelBody.ChunkSize`) [S1, unofficial]. A boolean `smooth` flag [S1, unofficial].
- **Output:** An array of `ChunkMeshData` objects, one per generated chunk, containing vertices and indices [S1, unofficial]. Vertices are in body voxel coordinates (local to the body, not the world) [S1, unofficial].

**Data structures:**
- `MeshGrid`: A 2D grid representation of the chunk. Created with dimensions `size` x `size` and depth 1 [S1, unofficial]. It uses a byte array `blocks` of size `MeshGrid.LengthFor(size, size)` [S1, unofficial].
- `MeshBuilder`: A helper object passed to the mesher [S1, unofficial].
- `ChunkMeshData`: The resulting mesh data for a chunk [S1, unofficial].
- `Entry`: Contains `Parts` (array of nullable `GpuMesh` arrays, one per chunk index), `Pending` (a `Task` returning an array of tuples `(int Chunk, ChunkMeshData[] Data)`), and `PendingSmooth` (bool indicating terrain mode) [S1, unofficial].

**Numbered steps:**
1. **Initialize Grid:** If the thread-static byte array `_grid` is null, initialize it with size `MeshGrid.LengthFor(size, size)` [S1, unofficial]. Create a `MeshGrid` instance using the `blocks` array, dimensions `size` x `size`, and depth 1 [S1, unofficial].
2. **Populate Grid:** Iterate `x`, `y`, `z` from `-1` to `size` (inclusive) [S1, unofficial]. For each coordinate, set `blocks[grid.Index(x, y, z)]` to the voxel value from `body.Get(originX + x, originY + y, originZ + z)` cast to `byte` [S1, unofficial]. This covers the sub-chunk and a one-voxel rim for boundary detection [S1, unofficial].
3. **Initialize Refinements:** If the static thread-local dictionary `_refinements` is null, initialize and clear it [S1, unofficial]. Iterate over `body.Refinements` tuples `(index, field)` [S1, unofficial]. Convert the index to local coordinates `(x, y, z)` by subtracting the origin [S1, unofficial]. If within bounds `[-1, size]`, store the field in `refinements` keyed by `grid.Index(x, y, z)` [S1, unofficial].
4. **Retrieve Colors:** Get `colorX`, `colorY`, `colorZ` from `body.ColorOrigin` [S1, unofficial].
5. **Build Mesh:** Call either `SmoothChunkMesher.Build` or `ChunkMesher.Build` depending on the `smooth` flag [S1, unofficial]. Pass the `builder`, `grid`, `refinements`, `colorX`, `colorY`, `colorZ`, and `size` [S1, unofficial]. If not smooth, pass `directionalShade: false` [S1, unofficial].
6. **Transform Vertices:** For all vertices in all returned `ChunkMeshData` parts, add `originX`, `originY`, and `originZ` to their respective X, Y, and Z components [S1, unofficial].

**Pseudocode:**
```python
# Thread-local storage
_grid = None
_refinements = None

# External dependencies stubbed for self-contained execution
class VoxelBody:
    def Get(self, x, y, z): return 1
    class Refinements: pass
    class ColorOrigin: pass
class ChunkMeshData:
    def __init__(self): self.vertices = []
class Vertex:
    def __init__(self, x, y, z): self.x, self.y, self.z = x, y, z

def VoxelBodyMeshing(body, originX, originY, originZ, size, smooth):
    global _grid, _refinements

    # Step 1: Initialize Grid
    if _grid is None:
        _grid = [0] * (size * size)  # MeshGrid.LengthFor(size, size)

    blocks = _grid
    # Simulate MeshGrid with dimensions size x size, depth 1
    # Note: Source specifies a 2D grid but the sampling loop covers z.
    # Using a flat index that safely maps the -1 to size range.
    def grid_index(x, y, z):
        return (x + 1) + (y + 1) * (size + 2) + (z + 1) * (size + 2) * (size + 2)

    # Step 2: Populate Grid
    for x in range(-1, size + 1):
        for y in range(-1, size + 1):
            for z in range(-1, size + 1):
                voxel_val = body.Get(originX + x, originY + y, originZ + z)
                idx = grid_index(x, y, z)
                blocks[idx] = int(voxel_val)  # Cast to byte equivalent

    # Step 3: Initialize Refinements
    if _refinements is None:
        _refinements = {}
        _refinements.clear()

    for index, field in body.Refinements:
        local_x = index.x - originX
        local_y = index.y - originY
        local_z = index.z - originZ
        if -1 <= local_x <= size and -1 <= local_y <= size and -1 <= local_z <= size:
            _refinements[grid_index(local_x, local_y, local_z)] = field

    # Step 4: Retrieve Colors
    colorX, colorY, colorZ = body.ColorOrigin

    # Step 5: Build Mesh
    builder = {}  # MeshBuilder instance
    if smooth:
        # Sources do not provide SmoothChunkMesher.Build internals [G]
        mesh_data_list = []
    else:
        # Sources do not provide ChunkMesher.Build internals [G]
        mesh_data_list = []

    # Step 6: Transform Vertices
    for mesh_data in mesh_data_list:
        for vertex in mesh_data.vertices:
            vertex.x += originX
            vertex.y += originY
            vertex.z += originZ

    return mesh_data_list
```

**Parameters:**
- `size`: The dimension of the sub-chunk. Typically `VoxelBody.ChunkSize` [S1, unofficial].
- `smooth`: Boolean flag. If true, uses smooth mode (Marching Cubes); if false, uses hard-edged mode (face merging) [S1, unofficial].

**Edge cases and pitfalls:**
- **Vertex Coordinates:** Vertices are output in body voxel coordinates [S1, unofficial]. This allows every sub-chunk of a body to be drawn with the same model matrix, avoiding per-chunk transformation overhead [S1, unofficial].
- **Shading:** No directional shade is baked into the mesh colors [S1, unofficial]. On a sphere, baked 'top is bright' shading would conflict with dynamic sunlight computed by the shader [S1, unofficial]. World shading is applied via shader using the world normal if `VoxelBody.WorldShade` is true [S1, unofficial].
- **Face Merging:** Hard-edged mode merges equal faces into rectangles to reduce vertex count [S1, unofficial]. Without merging, a planet hundreds of voxels across would have millions of vertices [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources [S1, unofficial].
- **Memory Complexity:** Not given in the sources [S1, unofficial].
- **Measured Performance:** Not given in the sources [S1, unofficial].
- **Strengths:** Hard-edged mode significantly reduces vertex count by merging equal faces into rectangles [S1, unofficial]. Processing is chunked and multi-threaded [S1, unofficial].
- **Limitations:** Smooth mode uses Marching Cubes, which is more computationally expensive than hard-edged mode [S1, unofficial].
- **When to use:** When rendering large voxel bodies where performance is critical and the visual style allows for blocky or smooth surfaces [S1, unofficial].
- **When not to use:** When per-vertex shading is required without shader support, or when the surface requires high-frequency detail not captured by the chunk size [S1, unofficial].

## Background
VoxelBodyMeshing is part of the `VoxelEngine` architecture, specifically in the `VoxelEngine.Core` namespace [S1, unofficial]. It is used in the `VoxelTerraformer` project [S1, unofficial]. The method is designed to work with the `GameHost` and `Game` classes, which manage the window, loop, and menus [S1, unofficial]. The meshing is performed in a worker thread loop, iterating over dirty chunks [S1, unofficial].
