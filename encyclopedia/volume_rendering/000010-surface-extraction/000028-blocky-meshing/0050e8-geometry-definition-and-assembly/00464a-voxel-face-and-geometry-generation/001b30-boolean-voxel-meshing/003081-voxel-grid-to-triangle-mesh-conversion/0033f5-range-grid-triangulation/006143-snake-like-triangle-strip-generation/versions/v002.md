# Snake-like Triangle Strip Generation

Also called: Grid Triangle Strip Generation, Snake-like Triangle Strip, Zigzag Triangle Strip

## Overview
Snake-like Triangle Strip Generation is a method for converting a 2D grid of vertices into a single, continuous triangle strip mesh [S1, unofficial]. It solves the problem of maintaining consistent face winding across a rectangular grid without generating degenerate triangles [S1, unofficial]. It sets itself apart from standard triangle list generation by reducing draw calls and from other strip techniques by using a deterministic boustrophedon traversal that guarantees valid strip continuity for any rectangular grid topology [S1, unofficial].

## How it works
**Inputs:**
- A 2D grid of vertices with positions, normals, and texture coordinates [S1, unofficial].
- Grid dimensions: $MESHNUM \times MESHNUM$ (square grid assumed in source) [S1, unofficial].
- Total vertex count: $MAPVERTS = MESHNUM \times MESHNUM$ [S1, unofficial].

**Outputs:**
- An index array `m_Index` defining a single triangle strip [S1, unofficial].

**Data Structures:**
- `m_Verts`: Array of size $MAPVERTS$. Each element contains `pos` (3D vector), `normal` (3D vector), and `texcoord` (2D vector) [S1, unofficial].
- `m_Index`: Dynamic array of integers storing vertex indices for the strip [S1, unofficial].

**Parameters:**
- $MESHNUM$: Integer, number of vertices along one axis [S1, unofficial].
- $TEXMAG$: Scaling factor for texture coordinates, defined as $1.0 / MESHNUM$ [S1, unofficial].

**Algorithm Steps:**
1. **Initialization:** Read vertex positions into `m_Verts` [S1, unofficial]. Compute $TEXMAG = 1.0 / MESHNUM$ [S1, unofficial]. Initialize `m_Index` as empty [G].
2. **Row Traversal:** Loop $y$ from $0$ to $MESHNUM - 2$ [S1, unofficial].
   - **Forward Pass:** Loop $x$ from $0$ to $MESHNUM - 2$ [S1, unofficial]. Define triangle with vertices $V_0 = y \cdot MESHNUM + x$, $V_1 = y \cdot MESHNUM + x + 1$, $V_2 = (y + 1) \cdot MESHNUM + x$ [S1, unofficial]. Compute normal via `CalcNormalVector()` and assign to $V_0$ and $V_1$ [S1, unofficial]. Set texcoords to $((x \cdot TEXMAG), (y \cdot TEXMAG))$ and $((x \cdot TEXMAG), ((y + 1) \cdot TEXMAG))$ [S1, unofficial]. Push indices $(y + 1) \cdot MESHNUM + x$ then $y \cdot MESHNUM + x$ to `m_Index` [S1, unofficial].
   - **Backward Pass:** Increment $y$ [S1, unofficial]. Loop $x$ from $MESHNUM - 1$ down to $1$ [S1, unofficial]. Define triangle with vertices $V_0 = y \cdot MESHNUM + x$, $V_1 = y \cdot MESHNUM + x - 1$, $V_2 = (y + 1) \cdot MESHNUM + x$ [S1, unofficial]. Compute normal and assign to $V_0$ and $V_1$ [S1, unofficial]. Set texcoords identically [S1, unofficial]. Push indices $y \cdot MESHNUM + x$ then $(y + 1) \cdot MESHNUM + x$ to `m_Index` [S1, unofficial].
3. **Rendering:** Issue a single draw call using `GL_TRIANGLE_STRIP` [S1, unofficial]. Iterate through `m_Index`, setting normal, texcoord, and position for each vertex [S1, unofficial].

**Pseudocode:**
```python
def snake_like_strip_generation(m_Verts, MESHNUM):
    """
    Generates a triangle strip index list for a 2D grid of vertices.
    m_Verts: List of Vertex objects with pos, normal, texcoord attributes.
    MESHNUM: Integer width/height of the square grid.
    Returns: List of integers representing the triangle strip indices.
    """
    m_Index = []
    TEXMAG = 1.0 / MESHNUM
    
    for y in range(MESHNUM - 1):
        # Forward pass: left to right
        for x in range(MESHNUM - 1):
            v0 = y * MESHNUM + x
            v1 = y * MESHNUM + x + 1
            v2 = (y + 1) * MESHNUM + x
            
            normal = calc_normal(m_Verts[v0].pos, m_Verts[v1].pos, m_Verts[v2].pos)
            m_Verts[v0].normal = normal
            m_Verts[v1].normal = normal
            
            m_Verts[v0].texcoord = (x * TEXMAG, y * TEXMAG)
            m_Verts[v1].texcoord = (x * TEXMAG, (y + 1) * TEXMAG)
            
            m_Index.append(v2)
            m_Index.append(v0)
            
        # Backward pass: right to left
        for x in range(MESHNUM - 1, 0, -1):
            v0 = y * MESHNUM + x
            v1 = y * MESHNUM + x - 1
            v2 = (y + 1) * MESHNUM + x
            
            normal = calc_normal(m_Verts[v0].pos, m_Verts[v1].pos, m_Verts[v2].pos)
            m_Verts[v0].normal = normal
            m_Verts[v1].normal = normal
            
            m_Verts[v0].texcoord = (x * TEXMAG, y * TEXMAG)
            m_Verts[v1].texcoord = (x * TEXMAG, (y + 1) * TEXMAG)
            
            m_Index.append(v0)
            m_Index.append(v2)
            
    return m_Index

def calc_normal(p0, p1, p2):
    """Calculates the normal vector of a triangle defined by three points."""
    v1 = p1 - p0
    v2 = p2 - p0
    return normalize(cross(v1, v2))
```

**Edge Cases and Pitfalls:**
- **Grid Dimensions:** The source assumes a square grid ($MESHNUM \times MESHNUM$) [S1, unofficial]. For non-square grids, the loop bounds and index calculations must be adjusted to $W \times H$ [G].
- **Normal Assignment:** Normals are computed per triangle and assigned to the first two vertices of that triangle, resulting in flat shading per triangle unless interpolated by the GPU [S1, unofficial].
- **Texture Coordinates:** Texture coordinates are set based on grid indices, not world space, assuming a tiled texture mapping [S1, unofficial].

- **Strengths:** Simple implementation, no need for complex strip generation algorithms, consistent winding [S1, unofficial].
- **Limitations:** Flat shading per triangle if normals are not interpolated or smoothed [S1, unofficial]. Assumes rectangular grid topology [S1, unofficial].
