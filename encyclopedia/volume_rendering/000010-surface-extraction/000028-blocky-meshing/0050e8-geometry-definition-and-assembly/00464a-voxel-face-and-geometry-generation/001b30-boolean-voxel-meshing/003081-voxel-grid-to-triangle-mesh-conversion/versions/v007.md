# Voxel Grid to Triangle Mesh Conversion

Also called: Exact Voxel-to-Mesh Triangulation, Open3D Voxel Grid to Triangle Mesh Conversion, Surface Voxel Face Extraction, Voxel Grid to Watertight Mesh Conversion

## Overview
Voxel Grid to Triangle Mesh Conversion extracts a watertight triangular mesh that represents the exact volume of a boolean voxel occupancy grid [S1, unofficial]. It solves the problem of preserving the discrete geometry of the voxel grid without the interpolation artifacts of marching cubes, ensuring that every edge in the resulting mesh connects to exactly two faces [S1, unofficial]. Unlike [Blocky Surface Extraction](6418-blocky-surface-extraction.md) which may produce non-watertight or simplified outputs, this method explicitly generates triangles for every exposed face of surface voxels, guaranteeing volume preservation at the cost of higher triangle counts [S1, unofficial].

## How it works
**Inputs:** A boolean voxel occupancy grid (dense encoding) and its spatial transform [S1, unofficial].
**Outputs:** A `TriangleMesh` object containing vertices and faces representing the surface of the voxel grid [S1, unofficial].

**Data Structures:**
1. **Voxel Grid:** A 3D boolean array `dense_encoding` of shape $(N_x, N_y, N_z)$, where `True` indicates a filled voxel [S1, unofficial].
2. **Surface Indices:** A list of 3D integer coordinates $(i, j, k)$ for all voxels where `dense_encoding[i, j, k]` is `True` and at least one neighbor is `False` or out of bounds [S1, unofficial].
3. **Surface Centers:** A list of 3D floating-point coordinates corresponding to the geometric center of each surface voxel [S1, unofficial].
4. **Face Mask:** A 6-element boolean array `[R, L, F, B, T, B]` for each surface voxel, indicating which of the six faces (Right, Left, Front, Back, Top, Bottom) are exposed [S1, unofficial].
5. **Triangles:** A list of triangle definitions, where each triangle is defined by 3 vertices [S1, unofficial].

**Parameters:**
* `hpitch`: Half the spacing between voxel centers. Computed as `pitch[0] / 2`, where `pitch` is the uniform spacing of the voxel grid [S1, unofficial].

**Steps:**
1. **Extract Surface Voxels:** Identify all voxels that are part of the surface using a morphological surface operation to create a hollow voxel grid with the same transform [S1, unofficial].
2. **Compute Centers:** Calculate the 3D world coordinates of the center of each surface voxel using the grid's transform and indices [S1, unofficial].
3. **Detect Exposed Faces:** For each surface voxel, initialize a 6-element boolean mask to `False` [S1, unofficial]. Check each of the 6 neighboring voxel indices (Right: $+x$, Left: $-x$, Front: $+y$, Back: $-y$, Top: $+z$, Bottom: $-z$) [S1, unofficial]. A face is marked `True` if the neighbor index is out of the grid bounds or if the neighbor voxel is not filled (`False`) [S1, unofficial].
4. **Generate Triangles:** For each surface voxel and each `True` entry in its face mask, generate two triangles [S1, unofficial]. The vertices are calculated by offsetting the voxel center by $\pm hpitch$ along the axes perpendicular to the face normal [S1, unofficial].
    * **Right Face ($+x$):** Vertices at $(x+hpitch, y\pm hpitch, z\pm hpitch)$ [S1, unofficial].
    * **Left Face ($-x$):** Vertices at $(x-hpitch, y\pm hpitch, z\pm hpitch)$ [S1, unofficial].
    * **Front Face ($+y$):** Vertices at $(x\pm hpitch, y+hpitch, z\pm hpitch)$ [S1, unofficial].
    * **Back Face ($-y$):** Vertices at $(x\pm hpitch, y-hpitch, z\pm hpitch)$ [S1, unofficial].
    * **Top Face ($+z$):** Vertices at $(x\pm hpitch, y\pm hpitch, z+hpitch)$ [S1, unofficial].
    * **Bottom Face ($-z$):** Vertices at $(x\pm hpitch, y\pm hpitch, z-hpitch)$ [S1, unofficial].
    Each face is triangulated into two triangles using counter-clockwise winding when viewed from outside the voxel [G].
5. **Construct Mesh:** Create a `TriangleMesh` object [S2, unofficial]. Add the generated vertices and faces [S2, unofficial]. **Crucial:** Disable vertex merging/processing during mesh creation (e.g., `process=False`) to prevent the merging of distinct vertices that share the same coordinate but belong to different faces [S1, unofficial]. Vertex merging causes edges to connect to 4 faces, violating watertightness [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def voxel_grid_to_triangle_mesh(dense_encoding, pitch, transform):
    """
    Converts a boolean voxel grid to a watertight triangle mesh.
    
    Args:
        dense_encoding: 3D numpy array of booleans (True=voxel present).
        pitch: float or array, spacing between voxel centers.
        transform: 4x4 numpy array, affine transform from grid indices to world space.
        
    Returns:
        vertices: Nx3 numpy array of vertex positions.
        faces: Mx3 numpy array of vertex indices.
    """
    hpitch = pitch[0] / 2.0
    shape = dense_encoding.shape
    
    def in_bounds(idx):
        return all(0 <= idx[d] < shape[d] for d in range(3))
        
    def actual_face(idx):
        return not in_bounds(idx) or not dense_encoding[idx[0], idx[1], idx[2]]

    # Step 1: Extract surface voxels using morphology operation
    surface_encoding = morphology_surface(dense_encoding) # [G] standard morphological surface extraction
    surface_indices = np.argwhere(surface_encoding)
    # Step 2: Compute world centers
    centers_grid = surface_indices * pitch + hpitch
    h_centers = np.hstack([centers_grid, np.ones((len(surface_indices), 1))])
    surface_centers = (transform @ h_centers.T).T[:, :3]
    
    triangles = []
    for i in range(len(surface_indices)):
        base_index = surface_indices[i]
        base_center = surface_centers[i]
        face_mask = [False] * 6
        
        # Step 3: Detect exposed faces
        target_index = base_index + np.array([1, 0, 0])
        if actual_face(target_index): face_mask[0] = True
        target_index = base_index + np.array([-1, 0, 0])
        if actual_face(target_index): face_mask[1] = True
        target_index = base_index + np.array([0, 1, 0])
        if actual_face(target_index): face_mask[2] = True
        target_index = base_index + np.array([0, -1, 0])
        if actual_face(target_index): face_mask[3] = True
        target_index = base_index + np.array([0, 0, 1])
        if actual_face(target_index): face_mask[4] = True
        target_index = base_index + np.array([0, 0, -1])
        if actual_face(target_index): face_mask[5] = True
        
        # Step 4: Generate triangles for exposed faces
        if face_mask[0]: # Right (+x)
            triangles.append([base_center + [hpitch, hpitch, -hpitch], base_center + [hpitch, hpitch, hpitch], base_center + [hpitch, -hpitch, hpitch]])
            triangles.append([base_center + [hpitch, hpitch, -hpitch], base_center + [hpitch, -hpitch, hpitch], base_center + [hpitch, -hpitch, -hpitch]])
        if face_mask[1]: # Left (-x)
            triangles.append([base_center + [-hpitch, -hpitch, hpitch], base_center + [-hpitch, -hpitch, -hpitch], base_center + [-hpitch, hpitch, -hpitch]])
            triangles.append([base_center + [-hpitch, -hpitch, hpitch], base_center + [-hpitch, hpitch, -hpitch], base_center + [-hpitch, hpitch, hpitch]])
        if face_mask[2]: # Front (+y)
            triangles.append([base_center + [hpitch, hpitch, hpitch], base_center + [-hpitch, hpitch, hpitch], base_center + [-hpitch, hpitch, -hpitch]])
            triangles.append([base_center + [hpitch, hpitch, hpitch], base_center + [-hpitch, hpitch, -hpitch], base_center + [hpitch, hpitch, -hpitch]])
        if face_mask[3]: # Back (-y)
            triangles.append([base_center + [-hpitch, -hpitch, -hpitch], base_center + [hpitch, -hpitch, -hpitch], base_center + [hpitch, -hpitch, hpitch]])
            triangles.append([base_center + [-hpitch, -hpitch, -hpitch], base_center + [hpitch, -hpitch, hpitch], base_center + [-hpitch, -hpitch, hpitch]])
        if face_mask[4]: # Top (+z)
            triangles.append([base_center + [hpitch, hpitch, hpitch], base_center + [-hpitch, hpitch, hpitch], base_center + [-hpitch, -hpitch, hpitch]])
            triangles.append([base_center + [hpitch, hpitch, hpitch], base_center + [-hpitch, -hpitch, hpitch], base_center + [hpitch, -hpitch, hpitch]])
        if face_mask[5]: # Bottom (-z)
            triangles.append([base_center + [-hpitch, -hpitch, -hpitch], base_center + [hpitch, -hpitch, -hpitch], base_center + [hpitch, hpitch, -hpitch]])
            triangles.append([base_center + [-hpitch, -hpitch, -hpitch], base_center + [hpitch, hpitch, -hpitch], base_center + [-hpitch, hpitch, -hpitch]])
            
    # Step 5: Construct mesh (vertices and faces assembled externally)
    return triangles
```

**Edge Cases and Pitfalls:**
* **Watertightness Violation:** If vertex merging is enabled during mesh construction, distinct vertices at the same geometric location (belonging to adjacent faces of the same voxel or different voxels) may be merged [S1, unofficial]. This causes edges to connect to 4 faces instead of 2, breaking the watertight property [S1, unofficial]. The solution is to disable vertex merging (`process=False`) [S1, unofficial].
* **Degenerate Input:** Empty voxel grids result in empty meshes [G].
* **Precision:** Floating-point precision in vertex calculation should be sufficient for standard graphics applications. Using `hpitch` ensures vertices align exactly with voxel boundaries [S1, unofficial].

## Subtopics

### [Range Grid Triangulation](7146-range-grid-triangulation.md)
Range Grid Triangulation converts a 2D range grid, where each grid cell points to a 3D vertex or is invalid, into a triangular mesh. It handles invalid vertices by constructing triangles only from valid corners and chooses diagonal directions to minimize sliver triangles. Choose it when working with pre-projected 2D range data rather than 3D scalar fields.

### [Naive Voxel Triangulation](14035-naive-voxel-triangulation.md)
Naive Voxel Triangulation is a surface extraction method that renders every voxel in a grid as a complete, closed cube by generating triangles for all six of its faces, regardless of whether the faces are occluded by neighboring voxels. It solves the problem of converting discrete voxel data into a renderable triangle mesh with maximum simplicity, serving as the baseline for more optimized approaches like [Range Grid Triangulation](7146-range-grid-triangulation.md) which selectively generate only exposed faces. Choose it when immediate rendering is required and visibility culling overhead is unacceptable.

### Simple Conversion
Simple Conversion is a voxel-to-mesh conversion mode prioritizing speed over high-fidelity detail preservation, suitable when a mesh is needed ASAP or subtle details are not critical [S3]. It works by uploading voxel data via 'Open DICOMs', 'Open RAW Voxels', or 'Open Voxels from TIFF', applying noise reduction using the 'Change ISO' function to isolate the region of interest, and navigating to the 'Voxels to Mesh' tab to select 'Simple Conversion' and click 'Convert' [S3]. An optional 'Preserve Voxel Object' setting keeps the original voxel data in the scene, resulting in the simple mesh overlaying the original voxel object [S3].

## Operating characteristics
* **Time Complexity:** $O(N)$, where $N$ is the number of surface voxels [G]. Each surface voxel is processed once, and a constant number of neighbors are checked [G].
* **Memory Complexity:** $O(N)$, storing vertices and faces for the surface mesh [G].
* **Performance:** The method is efficient for moderate-sized voxel grids. However, the triangle count is proportional to the surface area of the voxelized object, which can be significantly higher than smooth surface approximations like Marching Cubes [S1, unofficial].
* **Strengths:** Produces an exact representation of the voxel volume; guarantees watertightness if implemented correctly (no vertex merging); simple logic [S1, unofficial].
* **Limitations:** High triangle count for complex shapes; does not smooth or interpolate surfaces; requires disabling vertex merging to maintain watertightness, which may impact downstream boolean operations [S1, unofficial].
* **When to Use:** When exact volume preservation is required, or when working with boolean voxel grids where interpolation is undesirable [S1, unofficial].
* **When Not to Use:** When rendering performance is critical and the voxel resolution is high, or when a smooth surface is desired [G].

## Background
The method is implemented in the `trimesh` library for the voxel module, specifically for rapid construction of unioned boxes from a `VoxelGrid` [S1, unofficial]. It addresses issues raised in community discussions regarding watertightness in voxel-to-mesh conversions, where edges incorrectly connected to 4 faces instead of exactly 2 [S1, unofficial]. An alternative implementation using Open3D box primitives at voxel centers was also documented for animation workflows [S2, unofficial].
