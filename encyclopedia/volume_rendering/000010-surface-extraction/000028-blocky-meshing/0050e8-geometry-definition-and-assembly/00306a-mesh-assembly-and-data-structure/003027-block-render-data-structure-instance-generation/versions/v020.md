# Block Render Data Structure & Instance Generation

Also called: BlockRenderData, Face Tint Mixing

## Overview
This method aggregates per-face rendering metadata (texture IDs and color tints) into a compact data structure to drive instanced mesh generation for voxel blocks. It solves the problem of efficiently mapping logical face attributes to GPU instancing parameters without duplicating geometry data. It differs from sibling methods by focusing on the *attribute assembly* phase rather than the geometric mesh construction itself, preparing the data required by the subsequent mesh assembly stage.

## How it works

### Inputs and Outputs
**Inputs:**
- A mapping from texture names to integer IDs (`textureIDByName`).
- Face texture names (strings) for each of the 6 block faces: Back, Front, Top, Bottom, Left, Right.
- Face tint colors (`Vector3`) for each of the 6 faces. Defaults to white `(1, 1, 1)` if not specified.
- A reference to the geometric shape (`IShape`) to be instanced.

**Outputs:**
- A `BlockRenderData` struct instance containing the resolved texture IDs, tints, and shape reference.

### Data Structures
The core data structure is `BlockRenderData`. It is a struct containing 13 fields:
1.  `faceBack`: `int` (Texture ID)
2.  `faceFront`: `int` (Texture ID)
3.  `faceTop`: `int` (Texture ID)
4.  `faceBottom`: `int` (Texture ID)
5.  `faceLeft`: `int` (Texture ID)
6.  `faceRight`: `int` (Texture ID)
7.  `tintBack`: `Vector3` (RGB Tint)
8.  `tintFront`: `Vector3` (RGB Tint)
9.  `tintTop`: `Vector3` (RGB Tint)
10. `tintBottom`: `Vector3` (RGB Tint)
11. `tintLeft`: `Vector3` (RGB Tint)
12. `tintRight`: `Vector3` (RGB Tint)
13. `shape`: `IShape` (Reference to the mesh geometry)

### Steps
1.  **Initialize Texture Map:** Create a dictionary `textureIDByName` that maps texture name strings to unique integer IDs. This is typically derived from a `TextureLoader.Texture[]` array where the index serves as the ID [S1, unofficial].
2.  **Resolve Texture IDs:** For each face (Back, Front, Top, Bottom, Left, Right), look up the provided texture name string in `textureIDByName` to retrieve the corresponding integer ID. If a name is not found, behavior is undefined by the source [G].
3.  **Prepare Tints:** Assign the provided `Vector3` tint for each face. If no tint is provided for a specific face, default to `Vector3.One` (white) [S1, unofficial].
4.  **Construct Struct:** Instantiate `BlockRenderData` with the 6 resolved integer IDs, the 6 `Vector3` tints, and the `IShape` reference.

### Pseudocode
```python
class BlockRenderData:
    def __init__(self, face_back_id, face_front_id, face_top_id, face_bottom_id, face_left_id, face_right_id,
                 tint_back, tint_front, tint_top, tint_bottom, tint_left, tint_right, shape):
        self.face_back = face_back_id
        self.face_front = face_front_id
        self.face_top = face_top_id
        self.face_bottom = face_bottom_id
        self.face_left = face_left_id
        self.face_right = face_right_id
        self.tint_back = tint_back
        self.tint_front = tint_front
        self.tint_top = tint_top
        self.tint_bottom = tint_bottom
        self.tint_left = tint_left
        self.tint_right = tint_right
        self.shape = shape

def create_block_render_data(texture_name_to_id_map, face_names, face_tints, shape):
    """
    Creates a BlockRenderData instance.
    
    Args:
        texture_name_to_id_map: Dict[str, int] mapping texture names to IDs.
        face_names: Tuple[str, str, str, str, str, str] for (Back, Front, Top, Bottom, Left, Right).
        face_tints: Tuple[Vector3, Vector3, Vector3, Vector3, Vector3, Vector3] for tints.
        shape: IShape reference.
        
    Returns:
        BlockRenderData instance.
    """
    WHITE = Vector3(1.0, 1.0, 1.0)
    
    # Resolve texture IDs
    face_back_id = texture_name_to_id_map[face_names[0]]
    face_front_id = texture_name_to_id_map[face_names[1]]
    face_top_id = texture_name_to_id_map[face_names[2]]
    face_bottom_id = texture_name_to_id_map[face_names[3]]
    face_left_id = texture_name_to_id_map[face_names[4]]
    face_right_id = texture_name_to_id_map[face_names[5]]
    
    # Apply default tints if not provided (assuming face_tints might be None or empty)
    # Note: The source implies tints are always provided or default to White in helper methods.
    # If face_tints is a tuple of 6, use them. If a single tint is provided for all, replicate.
    # This pseudocode assumes the caller has already resolved tints to a tuple of 6.
    
    return BlockRenderData(
        face_back_id, face_front_id, face_top_id, face_bottom_id, face_left_id, face_right_id,
        face_tints[0], face_tints[1], face_tints[2], face_tints[3], face_tints[4], face_tints[5],
        shape
    )

# Helper methods shown in source logic (simplified)
def create_with_names(texture_name_to_id_map, face_names, shape):
    """All tints default to White."""
    white_tints = (WHITE, WHITE, WHITE, WHITE, WHITE, WHITE)
    return create_block_render_data(texture_name_to_id_map, face_names, white_tints, shape)

def create_with_names_and_tints(texture_name_to_id_map, face_names, face_tints, shape):
    """Uses provided tints."""
    return create_block_render_data(texture_name_to_id_map, face_names, face_tints, shape)
```

### Parameters
- **Default Tint:** `Vector3(1, 1, 1)` (White) [S1, unofficial].
- **Texture ID Source:** Index in the `TextureLoader.Texture[]` array [S1, unofficial].

### Edge Cases and Pitfalls
- **Missing Texture Names:** If a texture name provided in `face_names` is not present in `textureIDByName`, the lookup will fail. The source does not specify a fallback [G].
- **Tint Mixing:** The notes mention "Face Tint Mixing" and "Mix provided face tints with base block tints by element-wise multiplication" or "Replace base block tints entirely". The primary code structure in [S1, unofficial] uses provided tints directly. If mixing is required, it must be applied before constructing the `BlockRenderData` [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$ per block for data structure creation, assuming dictionary lookup is $O(1)$.
- **Memory Complexity:** $O(1)$ per block for the `BlockRenderData` struct. The struct size is fixed (6 ints + 6 vectors + 1 reference).
- **Strengths:** Compact representation of per-face attributes; separates attribute data from geometry data.
- **Limitations:** Does not handle geometry generation; relies on downstream assembly for batching.

## Background
Originated in the `Cubic-Grid_Voxel_Renderer` project by rarefushion [S1, unofficial]. It is part of a voxel rendering pipeline that uses instanced rendering for efficiency.
