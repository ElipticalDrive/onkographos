# Mesh Finalization

Also called: VTK Mesh Finalization

## Overview
Mesh Finalization is the post-processing stage that transforms raw, potentially fragmented mesh data into a validated, contiguous `RenderMesh` object suitable for rendering or analysis. It solves the problem of ensuring data consistency by extrapolating cell-centered values to vertices, flattening vector buffers, and computing geometric properties like normals and bounds. It is distinct from [Chunk Mesh Assembly](4100-chunk-mesh-assembly.md), which focuses on bulk geometry generation for voxel-based chunks, by handling general unstructured grid topology (polyhedra, polygons) and scalar/vector field association.

## How it works
**Inputs:** A raw mesh structure containing vertex positions, cell connectivity (faces/edges), and optional cell-centered or point-centered scalar/vector data.
**Outputs:** A finalized `RenderMesh` object with contiguous arrays for vertices, indices, normals, bounds, and associated scalar/vector fields.

**Data Structures:**
The `RenderMesh` object contains:
- `vertices`: Contiguous float array, size $N_{verts} \times 3$.
- `indices`: Contiguous integer array (typically `UInt32` for unstructured grids), size $N_{tris} \times 3$.
- `normals`: Contiguous float array, size $N_{verts} \times 3$.
- `cellCenters`: Contiguous float array, size $N_{cells} \times 3$.
- `pointScalars` / `cellScalars`: Contiguous float arrays for scalar fields.
- `pointVectorsData` / `cellVectorsData`: Contiguous float arrays for vector fields, with `pointVectorOffset` / `cellVectorOffset` mapping field indices to array positions.
- `bounds`: Axis-aligned bounding box (min/max vectors).

**Steps:**
1.  **Validation:** Check if `vertices` is empty. If so, log error and return [S1, unofficial]. Check if `indices` is empty; if so, and the mesh is not `POLYDATA` or `renderAsPoints`, log error and return [S1, unofficial]. Validate that all index values are $< N_{verts}$; if any are out of bounds, log error, clear indices, and return to prevent GPU out-of-range fetches [S1, unofficial].
2.  **Cell Data Extrapolation:** Extrapolate cell-centered data to point-centered data using `mesh_utils::extrapolateCellDataToPoints` [S1, unofficial]. This ensures all point-based operations have valid data.
3.  **Vector Buffer Flattening:**
    -   Flatten point vectors into `mesh.pointVectorsData` using `mesh.pointVectorOffset` to track per-field offsets. Set `mesh.pointVectorCount` to the number of vertices [S1, unofficial].
    -   Flatten cell vectors into `mesh.cellVectorsData` using `mesh.cellVectorOffset`. Set `mesh.cellVectorCount` to the number of cells [S1, unofficial].
    -   Record available cell vector names for UI selection [S1, unofficial].
4.  **Cell Center Computation:** Compute cell centers by averaging the vertex positions of each cell's corners. Store in `cellCenters` [S1, unofficial].
5.  **Active Scalar Selection:**
    -   If `scalarName` is empty or not in `pointScalars`, default to the first available point scalar [S1, unofficial].
    -   Validate that the selected scalar's size matches the vertex count. If not, clear scalars [S1, unofficial].
6.  **Active Vector Selection:**
    -   If `vectorName` is empty, default to the first available vector name [S1, unofficial].
7.  **Geometric Computation:** Compute vertex normals and update the mesh bounds [S1, unofficial]. If normals are empty but vertices exist, assign default normals (e.g., zero or uniform) [S1, unofficial].
8.  **UI Population:** Populate and sort available scalar and vector names alphabetically for user interface display [S1, unofficial].

**Pseudocode:**
```python
def finalize_mesh(mesh):
    # 1. Validation
    if len(mesh.vertices) == 0:
        log_error("Mesh vertices are empty")
        return None
    
    if len(mesh.indices) == 0 and not mesh.is_polydata and not mesh.render_as_points:
        log_error("Mesh indices are empty")
        return None
    
    for idx in mesh.indices:
        if idx >= len(mesh.vertices) // 3:
            log_error("Index out of range")
            mesh.indices = []
            return None

    # 2. Extrapolate cell data to points
    mesh_utils.extrapolate_cell_data_to_points(mesh)

    # 3. Flatten vector buffers
    mesh.point_vectors_data, mesh.point_vector_offset = flatten_vectors(mesh.point_vectors, len(mesh.vertices) // 3)
    mesh.point_vector_count = len(mesh.vertices) // 3
    
    mesh.cell_vectors_data, mesh.cell_vector_offset = flatten_vectors(mesh.cell_vectors, mesh.cell_count)
    mesh.cell_vector_count = mesh.cell_count
    record_cell_vector_names(mesh)

    # 4. Compute cell centers
    mesh.cell_centers = compute_cell_centers(mesh.cells, mesh.vertices)

    # 5. Select active scalar
    if not mesh.scalar_name or mesh.scalar_name not in mesh.point_scalars:
        mesh.scalar_name = get_first_scalar_name(mesh.point_scalars)
    
    if len(mesh.point_scalars[mesh.scalar_name]) != len(mesh.vertices) // 3:
        clear_scalars(mesh)

    # 6. Select active vector
    if not mesh.vector_name:
        mesh.vector_name = get_first_vector_name(mesh.point_vectors)

    # 7. Compute normals and bounds
    compute_normals(mesh)
    compute_bounds(mesh)
    
    if len(mesh.normals) == 0 and len(mesh.vertices) > 0:
        mesh.normals = [0.0, 0.0, 1.0] * (len(mesh.vertices) // 3)

    # 8. Populate UI data
    populate_ui_scalar_vector_names(mesh)
    
    return mesh
```

**Parameters:**
-   `scalarName`: String identifier for the active scalar field. Default: first available [S1, unofficial].
-   `vectorName`: String identifier for the active vector field. Default: first available [S1, unofficial].

**Edge Cases:**
-   Empty vertex or index arrays trigger immediate termination [S1, unofficial].
-   Out-of-bounds indices cause index array clearing to prevent GPU errors [S1, unofficial].
-   Mismatched scalar/vector sizes lead to clearing of the invalid field [S1, unofficial].

## Operating characteristics
-   **Time Complexity:** Linear with respect to the number of vertices and cells for extrapolation and flattening. Normal computation is typically $O(N)$ or $O(N \log N)$ depending on implementation.
-   **Memory Complexity:** Linear, as it creates contiguous copies of data. Vector buffers are flattened, potentially increasing memory usage if not shared.
-   **Strengths:** Ensures data integrity for rendering pipelines; handles complex unstructured topologies; provides consistent UI data.
-   **Limitations:** Requires full mesh validation; may involve significant data copying for flattening.
-   **When to use:** After mesh generation from unstructured grid solvers or complex geometry, before rendering or analysis.
-   **When not to use:** For simple, already-validated structured grids where performance is critical and data is already contiguous.

## Background
Mesh Finalization originates from the SciRender project, specifically within the `thermeng/SciRender` repository [S1, unofficial]. It is designed to bridge the gap between raw CFD (Computational Fluid Dynamics) mesh data and visualization-ready formats, handling the complexities of unstructured grids (polyhedra, polygons) and field data association. It is part of a broader ecosystem of mesh processing tools that prioritize correctness and UI integration for scientific visualization.
