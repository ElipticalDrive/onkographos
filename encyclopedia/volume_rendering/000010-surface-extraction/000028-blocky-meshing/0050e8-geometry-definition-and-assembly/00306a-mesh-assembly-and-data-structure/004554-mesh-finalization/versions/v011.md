# Mesh Finalization
Also called: VTK Mesh Finalization

## Overview
Mesh Finalization is the concluding phase of the geometry assembly pipeline that transforms raw, potentially fragmented mesh data into a validated, render-ready `RenderMesh` structure. It solves the problem of ensuring data consistency, resolving default attribute selections, and preparing auxiliary data (normals, bounds, cell centers) required by downstream rendering and analysis components. Unlike its siblings which focus on aggregation or sectioning, this method handles the semantic validation and geometric enrichment of the mesh, specifically bridging the gap between solver-generated cell data and point-based rendering requirements.

## How it works
### Inputs and Outputs
**Inputs:**
- A raw mesh structure containing:
  - `vertices`: Array of 3D coordinates (floats).
  - `indices`: Array of vertex indices (unsigned integers).
  - `pointScalars`, `pointVectors`: Per-vertex attribute arrays.
  - `cellScalars`, `cellVectors`: Per-cell attribute arrays.
  - `cellConnectivity`, `cellTypes`, `cellOffsets`: Topology definitions.
  - Configuration flags: `scalarName`, `vectorName`, `cellVectorName`, `renderAsPoints`, `isPolyData`.

**Outputs:**
- A finalized `RenderMesh` object with:
  - Validated and contiguous vertex/normal/index buffers.
  - Flattened and offset vector data buffers (`pointVectorsData`, `cellVectorsData`).
  - Computed `cellCenters`, `normals`, and `bounds`.
  - Resolved active scalar/vector selections.

### Data Structures
The `RenderMesh` structure includes the following key fields relevant to finalization:
- `vertices`: `std::vector<float>` (interleaved x, y, z).
- `indices`: `std::vector<std::uint32_t>`.
- `normals`: `std::vector<float>` (interleaved x, y, z).
- `pointVectorsData`: `std::vector<float>` (contiguous buffer for all point vectors).
- `pointVectorOffset`: `std::vector<std::size_t>` (byte offsets per vector field).
- `cellVectorsData`: `std::vector<float>` (contiguous buffer for all cell vectors).
- `cellVectorOffset`: `std::vector<std::size_t>` (byte offsets per cell vector field).
- `cellCenters`: `std::vector<Vec3>` (computed centroid for each cell).
- `bounds`: Axis-aligned bounding box (AABB) covering all vertices.

### Steps
1.  **Empty Check**: If `mesh.vertices` is empty, log an error and return immediately [S1, unofficial].
2.  **Index Validation**: If `mesh.indices` is empty and the mesh is not `POLYDATA` and not `renderAsPoints`, log an error and return [S1, unofficial].
3.  **Index Bounds Check**: Iterate through `mesh.indices`. If any index value $\ge$ `mesh.vertexCount`, log an error, clear `mesh.indices`, and return to prevent GPU out-of-range fetches [S1, unofficial].
4.  **Extrapolate Cell Data to Points**: Call `mesh_utils::extrapolateCellDataToPoints` to transfer cell-centered scalar/vector data to vertex locations. This ensures point-based renderers can access cell-derived data [S1, unofficial].
5.  **Flatten Point Vectors**:
    - Iterate through available point vector fields.
    - Append each field's data to `mesh.pointVectorsData`.
    - Record the starting byte offset of each field in `mesh.pointVectorOffset`.
    - Set `mesh.pointVectorCount` to the number of vertices (`perVertex`) [S1, unofficial].
6.  **Flatten Cell Vectors**:
    - Iterate through available cell vector fields.
    - Append each field's data to `mesh.cellVectorsData`.
    - Record the starting byte offset of each field in `mesh.cellVectorOffset`.
    - Set `mesh.cellVectorCount` to the number of cells (`cellCount`) [S1, unofficial].
    - Record the names of available cell vectors for UI selection [S1, unofficial].
7.  **Default Cell Vector Selection**: If `cellVectorName` is not set, select the first available cell vector name from the recorded list [S1, unofficial].
8.  **Compute Cell Centers**: For each cell, calculate the centroid by averaging the positions of its corner vertices. Store in `mesh.cellCenters` [S1, unofficial].
9.  **Select Active Scalar**:
    - If `scalarName` is empty or not found in `pointScalars`, default to the first available point scalar [S1, unofficial].
    - Validate that the selected scalar's size matches `vertexCount`. If not, clear the scalars array [S1, unofficial].
10. **Populate UI Names**: Sort and populate lists of available scalar and vector names alphabetically for user interface display [S1, unofficial].
11. **Default Vector Selection**: If `vectorName` is not set, select the first available vector name from the sorted list [S1, unofficial].
12. **Compute Normals**: Call `mesh_utils::computeNormals` to generate vertex normals based on geometry [S1, unofficial].
13. **Compute Bounds**: Call `mesh_utils::computeBounds` to calculate the AABB of the mesh [S1, unofficial].

### Pseudocode
```python
def finalize_mesh(mesh):
    # Step 1: Empty Check
    if len(mesh.vertices) == 0:
        log_error("Mesh vertices are empty")
        return False

    # Step 2 & 3: Index Validation
    if len(mesh.indices) == 0 and not mesh.is_polydata and not mesh.render_as_points:
        log_error("Mesh indices are empty for non-polydata/non-point render")
        return False

    vertex_count = len(mesh.vertices) // 3
    for idx in mesh.indices:
        if idx >= vertex_count:
            log_error("Index out of bounds")
            mesh.indices = []
            return False

    # Step 4: Extrapolate Cell Data
    extrapolate_cell_data_to_points(mesh)

    # Step 5: Flatten Point Vectors
    mesh.point_vectors_data = []
    mesh.point_vector_offset = []
    current_offset = 0
    for field in mesh.point_vectors:
        mesh.point_vectors_data.extend(field.data)
        mesh.point_vector_offset.append(current_offset)
        current_offset += len(field.data) * sizeof_float
    mesh.point_vector_count = vertex_count

    # Step 6: Flatten Cell Vectors
    mesh.cell_vectors_data = []
    mesh.cell_vector_offset = []
    current_offset = 0
    available_cell_vector_names = []
    for field in mesh.cell_vectors:
        mesh.cell_vectors_data.extend(field.data)
        mesh.cell_vector_offset.append(current_offset)
        current_offset += len(field.data) * sizeof_float
        available_cell_vector_names.append(field.name)
    mesh.cell_vector_count = len(mesh.cells)

    # Step 7: Default Cell Vector
    if not mesh.cell_vector_name and available_cell_vector_names:
        mesh.cell_vector_name = available_cell_vector_names[0]

    # Step 8: Compute Cell Centers
    mesh.cell_centers = []
    for cell in mesh.cells:
        center = Vec3(0, 0, 0)
        for vertex_idx in cell.vertices:
            v = mesh.vertices[vertex_idx * 3 : vertex_idx * 3 + 3]
            center += Vec3(v[0], v[1], v[2])
        center /= len(cell.vertices)
        mesh.cell_centers.append(center)

    # Step 9: Select Active Scalar
    if not mesh.scalar_name or mesh.scalar_name not in mesh.point_scalars:
        if mesh.point_scalars:
            mesh.scalar_name = mesh.point_scalars[0].name
        else:
            mesh.point_scalars = [] # Clear if none available
    else:
        # Validate size
        selected_scalar = mesh.point_scalars[mesh.scalar_name]
        if len(selected_scalar.data) != vertex_count:
            mesh.point_scalars = []
            log_error("Scalar size mismatch")

    # Step 10: Populate UI Names
    mesh.available_scalars = sorted([s.name for s in mesh.point_scalars])
    mesh.available_vectors = sorted([v.name for v in mesh.point_vectors])

    # Step 11: Default Vector
    if not mesh.vector_name and mesh.available_vectors:
        mesh.vector_name = mesh.available_vectors[0]

    # Step 12 & 13: Compute Normals and Bounds
    compute_normals(mesh)
    compute_bounds(mesh)

    return True
```

### Parameters
- `scalarName`: String. Name of the active point scalar. Default: First available [S1, unofficial].
- `vectorName`: String. Name of the active point vector. Default: First available [S1, unofficial].
- `cellVectorName`: String. Name of the active cell vector. Default: First available [S1, unofficial].
- `renderAsPoints`: Boolean. If true, empty indices are allowed [S1, unofficial].
- `isPolyData`: Boolean. If true, empty indices are allowed [S1, unofficial].

### Edge Cases and Pitfalls
- **Empty Vertices**: If `mesh.vertices` is empty, the function returns early with an error [S1, unofficial].
- **Empty Indices**: If `mesh.indices` is empty, it is only valid for `POLYDATA` or `renderAsPoints` modes. Otherwise, it is an error [S1, unofficial].
- **Out-of-Bounds Indices**: Any index $\ge$ `vertexCount` causes the indices to be cleared and an error logged, preventing GPU crashes [S1, unofficial].
- **Scalar Size Mismatch**: If the selected scalar's data length does not match the vertex count, the scalar array is cleared [S1, unofficial].

## Operating characteristics
- **Time Complexity**: $O(V + I + C + P + E)$, where $V$ is vertex count, $I$ is index count, $C$ is cell count, $P$ is point vector field count, and $E$ is cell vector field count. The dominant operations are linear scans for validation, flattening, and averaging for cell centers.
- **Memory Complexity**: $O(V + I + C + P + E)$. Additional memory is allocated for flattened vector buffers and cell centers.
- **Strengths**: Ensures data integrity for rendering; resolves ambiguous attribute selections; prepares auxiliary data for glyphs and gradients.
- **Limitations**: Requires all input data to be present; validation failures halt the process.

## Background
Mesh Finalization is part of the SciRender project, a tool for visualizing CFD (Computational Fluid Dynamics) data. It adapts VTK-like mesh structures for efficient rendering. The method handles the transition from solver-centric cell data to renderer-centric point data.
