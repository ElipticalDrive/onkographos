# Mesh Finalization

Also called: VTK Mesh Finalization

## Overview
Mesh Finalization prepares a raw geometric mesh for rendering by validating data integrity, computing derived attributes (normals, bounds), and organizing scalar/vector fields for efficient GPU access [S1, unofficial]. It differs from [Mesh Assembly and Data Structure](6268-mesh-assembly-and-data-structure.md) by focusing on post-assembly validation and attribute computation rather than buffer allocation and vertex/index packing. It serves as the bridge between geometry generation and shader execution, ensuring that all required data structures are consistent and complete.

## How it works
**Inputs:** A `RenderMesh` object containing raw vertices, indices, cell connectivity, and unprocessed scalar/vector data.
**Outputs:** A finalized `RenderMesh` with validated indices, computed normals, bounding boxes, and organized field buffers.

### Data Structures
The `RenderMesh` structure includes:
- `vertices`: Contiguous array of floats (x, y, z per vertex).
- `indices`: Contiguous array of unsigned integers (triangle indices).
- `normals`: Contiguous array of floats (x, y, z per vertex).
- `bounds`: Bounding box (min/max coordinates).
- `pointScalars`, `cellScalars`: Arrays of scalar data.
- `pointVectors`, `cellVectors`: Arrays of vector data.
- `pointVectorOffset`, `cellVectorOffset`: Offsets into contiguous vector buffers.
- `pointVectorCount`, `cellVectorCount`: Counts of vector components.
- `cellCenters`: Array of floats (x, y, z per cell).
- `cellTypes`, `cellOffsets`, `cellConnectivity`: For unstructured grid topology.

### Steps
1.  **Validation:**
    -   If `mesh.vertices` is empty, log an error and return [S1, unofficial].
    -   If `mesh.indices` is empty and the mesh is not `POLYDATA` or `renderAsPoints`, log an error and return [S1, unofficial].
    -   Validate indices: If any index $\ge$ vertex count, log an error, clear indices, and return to prevent GPU out-of-range fetches [S1, unofficial].

2.  **Cell Data Extrapolation:**
    -   Extrapolate cell-centered data to point-centered data using `mesh_utils::extrapolateCellDataToPoints` [S1, unofficial]. This ensures point-based rendering can access cell-derived values.

3.  **Vector Buffer Flattening:**
    -   Flatten point vectors into a contiguous buffer `mesh.pointVectorsData` with per-field offsets `mesh.pointVectorOffset`. Set `mesh.pointVectorCount` to the number of vertices [S1, unofficial].
    -   Flatten cell vectors into a contiguous buffer `mesh.cellVectorsData` with per-field offsets. Set `mesh.cellVectorCount` to the number of cells. Record available cell vector names [S1, unofficial].
    -   If no `cellVectorName` is set, default to the first available cell vector name [S1, unofficial].

4.  **Cell Center Computation:**
    -   Compute cell centers by averaging the vertex positions of each cell's corners [S1, unofficial]. For a cell with vertices $v_1, v_2, ..., v_n$, the center $C$ is:
        $$ C = \frac{1}{n} \sum_{i=1}^{n} v_i $$
    -   Store these in `mesh.cellCenters` [S1, unofficial].

5.  **Active Scalar Selection:**
    -   If `scalarName` is empty or not in `pointScalars`, default to the first point scalar [S1, unofficial].
    -   Validate size: If the scalar array size does not match the vertex count, clear scalars [S1, unofficial].

6.  **UI Data Population:**
    -   Populate available scalar and vector names for UI, sorting them alphabetically [S1, unofficial].
    -   If no `vectorName` is set, default to the first available vector name [S1, unofficial].

7.  **Attribute Computation:**
    -   Compute vertex normals using `mesh_utils::computeNormals` [S1, unofficial].
    -   Compute bounding box using `mesh_utils::computeBounds` [S1, unofficial].
    -   If normals are empty but vertices exist, assign default normals (e.g., [0,0,1]) [S1, unofficial].

### Pseudocode
```python
def finalize_mesh(mesh):
    # 1. Validation
    if len(mesh.vertices) == 0:
        log_error("Empty vertices")
        return False
    
    if len(mesh.indices) == 0 and not mesh.is_polydata and not mesh.render_as_points:
        log_error("Empty indices for non-polydata/non-point mesh")
        return False
    
    for idx in mesh.indices:
        if idx >= len(mesh.vertices) // 3:
            log_error("Index out of range")
            mesh.indices = []
            return False

    # 2. Cell Data Extrapolation
    mesh.point_scalars = extrapolate_cell_data_to_points(mesh.cell_scalars, mesh.cell_connectivity, mesh.cell_offsets)

    # 3. Vector Buffer Flattening
    mesh.point_vectors_data = flatten_vectors(mesh.point_vectors)
    mesh.point_vector_offset = compute_offsets(mesh.point_vectors)
    mesh.point_vector_count = len(mesh.vertices) // 3
    
    mesh.cell_vectors_data = flatten_vectors(mesh.cell_vectors)
    mesh.cell_vector_offset = compute_offsets(mesh.cell_vectors)
    mesh.cell_vector_count = len(mesh.cell_offsets) - 1
    
    if not mesh.cell_vector_name:
        mesh.cell_vector_name = get_first_available_cell_vector(mesh.cell_vectors_data)

    # 4. Cell Center Computation
    mesh.cell_centers = []
    for c in range(mesh.cell_vector_count):
        start = mesh.cell_offsets[c]
        end = mesh.cell_offsets[c+1]
        vertices = [mesh.vertices[i*3:i*3+3] for i in mesh.cell_connectivity[start:end]]
        center = [sum(v[j] for v in vertices) / len(vertices) for j in range(3)]
        mesh.cell_centers.append(center)

    # 5. Active Scalar Selection
    if not mesh.scalar_name or mesh.scalar_name not in mesh.point_scalars:
        mesh.scalar_name = get_first_available_scalar(mesh.point_scalars)
    
    if len(mesh.point_scalars[mesh.scalar_name]) != len(mesh.vertices) // 3:
        mesh.point_scalars[mesh.scalar_name] = []
        log_warning("Scalar size mismatch, cleared")

    # 6. UI Data Population
    mesh.available_scalars = sorted(list(mesh.point_scalars.keys()))
    mesh.available_vectors = sorted(list(mesh.cell_vectors_data.keys()))
    
    if not mesh.vector_name:
        mesh.vector_name = get_first_available_vector(mesh.cell_vectors_data)

    # 7. Attribute Computation
    compute_normals(mesh)
    compute_bounds(mesh)
    
    if not mesh.normals and len(mesh.vertices) > 0:
        mesh.normals = [0.0, 0.0, 1.0] * (len(mesh.vertices) // 3)

    return True
```

### Parameters
-   `scalarName`: Name of the active scalar field. Default: first available [S1, unofficial].
-   `vectorName`: Name of the active vector field. Default: first available [S1, unofficial].
-   `cellVectorName`: Name of the active cell vector field. Default: first available [S1, unofficial].

### Edge Cases and Pitfalls
-   **Empty Mesh:** If `mesh.vertices` is empty, the function returns early with an error [S1, unofficial].
-   **Empty Indices:** If `mesh.indices` is empty and the mesh is not `POLYDATA` or `renderAsPoints`, the function returns early with an error [S1, unofficial].
-   **Index Out of Bounds:** If any index in `mesh.indices` is $\ge$ vertex count, indices are cleared and the function returns early to prevent GPU errors [S1, unofficial].
-   **Scalar Size Mismatch:** If the selected scalar array size does not match the vertex count, the scalar is cleared [S1, unofficial].

## Operating characteristics
-   **Time Complexity:** $O(V + I + C)$, where $V$ is vertex count, $I$ is index count, and $C$ is cell count. Normal computation is typically $O(V)$ or $O(I)$ depending on implementation.
-   **Memory Complexity:** $O(V + I + C + F)$, where $F$ is the number of fields. Contiguous buffers minimize fragmentation [S2, 4100-chunk-mesh-assembly.md, unofficial].
-   **Strengths:** Ensures data integrity, computes necessary attributes for rendering, organizes fields for efficient access.
-   **Limitations:** Requires all input data to be present and correctly formatted. Validation steps can fail if data is inconsistent.
-   **When to Use:** After mesh assembly and before rendering. Essential for ensuring correct GPU submission.
-   **When Not to Use:** If the mesh is already validated and finalized, or if using a different rendering pipeline that handles these steps internally.

## Background
Mesh Finalization is part of the VTK (Visualization Toolkit) mesh processing pipeline, specifically adapted for CFD (Computational Fluid Dynamics) mesh rendering [S1, unofficial]. It ensures that unstructured grid data is properly prepared for visualization, handling the complexities of cell-to-point data extrapolation and attribute computation.
