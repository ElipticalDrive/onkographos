# Chunk Mesh Assembly

Also called: Mesh Assembly, Mesh Buffer Packing, PackedMeshBuffers, Procedural Voxel Mesh Generation, Section-based Mesh Building, Unity Mesh Configuration

## Overview
Chunk Mesh Assembly aggregates exposed voxel faces (quads) generated by geometry extraction into contiguous, typed arrays for GPU submission [S2, S3, unofficial]. It solves the problem of fragmented memory and inefficient draw calls by packing vertices and indices from multiple material layers into flat buffers, enabling single-pass GPU uploads [S2, unofficial]. Unlike sibling methods that focus on geometry generation or plugin architecture, this method specifically handles the final data structure layout and buffer population for the GPU [S2, S3, unofficial].

## How it works
**Inputs:**
- Voxel data store containing block types and colors [S1, unofficial].
- Chunk coordinate and size parameters [S1, S3, unofficial].
- Pre-computed mesh sections (quads) segregated by render layer (Opaque, Water, TransparentSolid, etc.) [S2, unofficial].
- Material map associating block types with rendering materials [S3, unofficial].

**Outputs:**
- A populated mesh object (e.g., Unity `Mesh`, Godot `ArrayMesh`) containing vertex, index, normal, and attribute buffers [S1, S3, unofficial].
- Assigned `MeshFilter` and `MeshCollider` components on the chunk entity [S1, unofficial].

**Data Structures:**
The assembly process relies on contiguous typed arrays. A common layout, `PackedMeshBuffers`, includes:
- `positions`: 32-bit floats (3 values per vertex) [S2, unofficial].
- `normals`: 8-bit signed integers (3 values per vertex, quantized) [S2, unofficial].
- `blockIds`: 16-bit unsigned integers (1 value per vertex) [S2, unofficial].
- `ambientOcclusion`: 8-bit unsigned integers (1 value per vertex) [S2, unofficial].
- `blockLight`: 8-bit unsigned integers (1 value per vertex) [S2, unofficial].
- `skyLight`: 8-bit unsigned integers (1 value per vertex) [S2, unofficial].
- `indices`: 32-bit unsigned integers (6 values per quad) [S2, unofficial].
- `groups`: Array of `MeshBufferGroup` descriptors [S2, unofficial].

`MeshBufferGroup` tracks offsets for each layer:
- `layer`: Enum identifying the render layer [S2, unofficial].
- `vertexOffset`: Start index in the vertex buffer [S2, unofficial].
- `vertexCount`: Number of vertices in this layer [S2, unofficial].
- `indexOffset`: Start index in the index buffer [S2, unofficial].
- `indexCount`: Number of indices in this layer [S2, unofficial].

**Steps:**
1. **Change Detection:** Check if the chunk has modified voxel data (`chunkProperties.HasChanges`) [S1, unofficial]. If false, skip assembly [S1, unofficial].
2. **Quad Counting:** Calculate the total number of quads across all defined layers (e.g., Opaque, Water, TransparentSolid, CrossPlants, Fluids, SpecialBlocks) [S2, unofficial].
3. **Buffer Allocation:** Allocate output arrays based on the total quad count:
   - Positions/Normals size: `quadCount * 4 * 3` (4 vertices per quad, 3 components per vertex) [S2, unofficial].
   - Indices size: `quadCount * 6` (2 triangles per quad) [S2, unofficial].
   - Attribute arrays (blockId, AO, lights): `quadCount * 4` [S2, unofficial].
4. **Initialization:** Initialize a writer with `vertexOffset = 0` and `indexOffset = 0` [S2, unofficial]. Clear existing mesh sections on the component [S3, unofficial].
5. **Layer Iteration:** Iterate through each layer in the layer list [S2, unofficial]:
   - Record current `vertexOffset` and `indexOffset` [S2, unofficial].
   - For each quad in the layer:
     - Compute vertex positions from quad bounds [S2, unofficial].
     - Write vertex attributes: position, normal, block ID, ambient occlusion (AO), and lighting data [S2, unofficial].
     - Write 6 indices (triangle fan: 0-1-2, 0-2-3) [S2, unofficial].
     - Update offsets [S2, unofficial].
   - Record new offsets in `MeshBufferGroup` for the current layer [S2, unofficial].
6. **Section Creation:** For each prepared section (e.g., `Prepared.Sections`):
   - Skip sections with zero vertices to avoid empty mesh sections [S3, unofficial].
   - Create a mesh section using `CreateMeshSection` with the populated vertices, triangles, normals, and UVs [S3, unofficial].
   - Set `bUpdateBounds` to false during creation [S3, unofficial].
7. **Mesh Configuration:**
   - Set vertex buffer parameters with `vertexCount` and `MeshingVertexData.VertexBufferMemoryLayout` [S1, unofficial].
   - Set index buffer parameters with `vertexCount` and `IndexFormat.UInt16` [S1, unofficial].
   - Set submesh count to 1 [S1, unofficial].
   - Create a `SubMeshDescriptor` with index count equal to `vertexCount` and assign it to submesh 0 [S1, unofficial].
   - Recalculate mesh bounds [S1, unofficial].
8. **Material Assignment:**
   - Look up the material for each block type [S3, unofficial].
   - If a material is not found, use a pre-scanned `FallbackMat` (the first non-null material in `BlockMaterials`) [S3, unofficial].
9. **Finalization:**
   - Assign the mesh to the chunk's `MeshFilter` and `MeshCollider` [S1, unofficial].
   - Enable the collider and renderer [S1, unofficial].
   - Reset `HasChanges` to false and set `IsMeshGenerated` to true [S1, unofficial].
   - Assign component and metadata to the output chunk structure (`OutChunk`), including `MeshComp`, `CollisionSectionIndex`, and shadow casting flags [S3, unofficial].

**Pseudocode:**
```python
def assemble_chunk_mesh(chunk, voxel_data, material_map):
    # 1. Check for changes
    if not chunk.properties.has_changes:
        return

    # 2. Count quads across all layers
    total_quads = sum(len(chunk.layers[l].quads) for l in chunk.layer_names)

    # 3. Allocate buffers
    positions = [0.0] * (total_quads * 12)
    normals = [0] * (total_quads * 12)
    indices = [0] * (total_quads * 6)
    block_ids = [0] * (total_quads * 4)
    ao_data = [0] * (total_quads * 4)
    light_data = [0] * (total_quads * 4)

    # 4. Initialize offsets
    vertex_offset = 0
    index_offset = 0
    mesh_groups = []

    # 5. Iterate layers
    for layer_name in chunk.layer_names:
        layer_start_v = vertex_offset
        layer_start_i = index_offset
        
        for quad in chunk.layers[layer_name].quads:
            verts = compute_quad_vertices(quad)
            
            # Write positions
            for i in range(4):
                positions[vertex_offset + i*3] = verts[i][0]
                positions[vertex_offset + i*3 + 1] = verts[i][1]
                positions[vertex_offset + i*3 + 2] = verts[i][2]
            
            # Write normals (quantized to Int8)
            for i in range(4):
                normals[vertex_offset + i*3] = quantize(verts[i][3])
                normals[vertex_offset + i*3 + 1] = quantize(verts[i][4])
                normals[vertex_offset + i*3 + 2] = quantize(verts[i][5])
            
            # Write attributes
            for i in range(4):
                block_ids[vertex_offset + i] = quad.block_id
                ao_data[vertex_offset + i] = quad.ao
                light_data[vertex_offset + i] = quad.light
            
            # Write indices (triangle fan: 0-1-2, 0-2-3)
            base_idx = index_offset
            indices[index_offset] = base_idx
            indices[index_offset + 1] = base_idx + 1
            indices[index_offset + 2] = base_idx + 2
            indices[index_offset + 3] = base_idx
            indices[index_offset + 4] = base_idx + 2
            indices[index_offset + 5] = base_idx + 3
            index_offset += 6
            
            vertex_offset += 4

        # Record group
        mesh_groups.append({
            'layer': layer_name,
            'vertexOffset': layer_start_v,
            'vertexCount': vertex_offset - layer_start_v,
            'indexOffset': layer_start_i,
            'indexCount': index_offset - layer_start_i
        })

    # 6. Create mesh sections
    section_index = 0
    for section in chunk.prepared_sections:
        if len(section.vertices) == 0:
            continue
        # Sources do not provide the engine-specific section creation logic [G]
        section_index += 1

    # 7. Configure Mesh
    mesh = {'vertices': positions, 'normals': normals, 'indices': indices, 'attributes': (block_ids, ao_data, light_data)}
    mesh['submesh_count'] = 1
    mesh['submesh_0'] = {'index_count': vertex_offset}
    mesh['bounds'] = recalculate_bounds(positions)

    # 8. Material Assignment
    fallback_mat = material_map.get_fallback()
    for group in mesh_groups:
        mat = material_map.get(group['layer']) or fallback_mat
        mesh['materials'][group['layer']] = mat

    # 9. Finalize
    chunk.mesh_filter = mesh
    chunk.mesh_collider.shared_mesh = mesh
    chunk.mesh_collider.enabled = True
    chunk.mesh_renderer.enabled = True
    chunk.properties.has_changes = False
    chunk.properties.is_mesh_generated = True

def compute_quad_vertices(quad):
    # Returns 4 vertices as tuples (x, y, z, nx, ny, nz) based on quad bounds
    return [
        (quad.min_x, quad.min_y, quad.min_z, quad.normal_x, quad.normal_y, quad.normal_z),
        (quad.max_x, quad.min_y, quad.min_z, quad.normal_x, quad.normal_y, quad.normal_z),
        (quad.max_x, quad.max_y, quad.min_z, quad.normal_x, quad.normal_y, quad.normal_z),
        (quad.min_x, quad.max_y, quad.min_z, quad.normal_x, quad.normal_y, quad.normal_z)
    ]

def quantize(value):
    # Quantize float [-1, 1] to signed byte [-128, 127]
    return int(max(-128, min(127, round(value * 127))))

def recalculate_bounds(positions):
    min_x = min(positions[0::3])
    max_x = max(positions[0::3])
    min_y = min(positions[1::3])
    max_y = max(positions[1::3])
    min_z = min(positions[2::3])
    max_z = max(positions[2::3])
    return {'min': (min_x, min_y, min_z), 'max': (max_x, max_y, max_z)}
```

**Parameters:**
- `BlockSize`: World units per voxel edge. Default value is 100.f [S3, unofficial].
- `NO_AMBIENT_OCCLUSION`: Constant value 0 used when AO is not provided [S2, unofficial].
- `NO_LIGHT`: Constant value 0 used when light data is not provided [S2, unofficial].
- `FallbackMat`: The first non-null material found in `BlockMaterials` during initialization [S3, unofficial].

**Edge Cases and Pitfalls:**
- **Empty Sections:** Sections with zero vertices must be skipped to prevent invalid mesh section creation [S3, unofficial].
- **Missing Materials:** If a block type is not found in the `BlockMaterials` map, a null pointer dereference may occur. Use a `FallbackMat` to prevent this [S3, unofficial].
- **Precision:** Normals are quantized to `Int8` to save memory, which may introduce minor visual artifacts in lighting [S2, unofficial].
- **Index Format:** The mesh descriptor uses `IndexFormat.UInt16` for the submesh, while the raw buffer stores indices as 32-bit values, requiring correct offset translation during upload [S1, S2, unofficial].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of exposed quads $Q$. $O(Q)$ for buffer allocation and writing [S2, unofficial].
- **Memory Complexity:** Linear with respect to $Q$. Buffers scale as $O(Q)$ for positions, normals, indices, and attributes [S2, unofficial].
- **Strengths:** Efficient GPU submission, support for multiple material layers, and modular design allowing for layer-specific optimizations [S2, unofficial].
- **Limitations:** Full chunk rebuilds can be expensive for large changes; relies on efficient geometry generation upstream [S1, S3, unofficial].
- **When to Use:** Real-time voxel games requiring dynamic terrain updates with multiple material types [S2, unofficial].
- **When Not to Use:** Static scenes where pre-baking is feasible, or scenes with extremely high vertex counts where streaming is required [S2, unofficial].

## Background
Chunk Mesh Assembly is a core technique in procedural voxel rendering, particularly in engines like Unity and Godot. It evolved from the need to efficiently render large voxel worlds with dynamic changes. The method is implemented in projects like Eldemarkki's Marching-Cubes-Terrain [S1, unofficial], nerima-games' mc-meshing [S2, unofficial], and HawkDev15's VoxelWorld [S3, unofficial]. It addresses the limitations of naive meshing by organizing data for optimal GPU access [S2, unofficial].
