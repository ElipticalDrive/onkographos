# Dirty Flag System for Incremental Meshing

Also called: Chunked Incremental Re-meshing, Dirty Chunk System, Lazy Rebuild

## Overview
The Dirty Flag System optimizes surface extraction in voxel terrain by tracking modified chunks to avoid remeshing unchanged geometry, enabling per-chunk incremental updates [S1, S2, unofficial]. It differs from full-scene re-meshing by only processing chunks containing modified density values [S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Voxel world grid dimensions $M_x \times M_y \times M_z$, chunk size $C$, and a modified voxel range $[minX, maxX] \times [minY, maxY] \times [minZ, maxZ]$ [S2, unofficial].
- Output: Updated GPU vertex buffers for only the affected chunks [S1, unofficial].

**Data Structures:**
- `Chunk`: Struct containing a boolean `dirty` flag indicating whether the chunk's geometry has changed since the last mesh pass [S1, unofficial].
- `dirtyChunks`: Set or list storing chunk indices $(c_x, c_y, c_z)$ that require rebuilding [S2, unofficial].
- `tempMeshData`: Temporary vertex storage allocated per chunk for meshing [S1, unofficial].

**Steps:**
1. **Marking Dirty Chunks:** When density is modified in a voxel range $[minX, maxX] \times [minY, maxY] \times [minZ, maxZ]$, calculate the affected chunk indices [S2, unofficial]. Because a voxel at index $x$ affects the cell to its left ($x-1$), the minimum chunk index is calculated using integer division: $c_{minX} = \lfloor (minX - 1) / C \rfloor$ [S2, unofficial]. The maximum chunk index is $c_{maxX} = \lfloor maxX / C \rfloor$ [G]. Iterate through all chunk indices from $(c_{minX}, c_{minY}, c_{minZ})$ to $(c_{maxX}, c_{maxY}, c_{maxZ})$ and add them to the `dirtyChunks` set [S2, unofficial].
2. **Meshing Cycle (LateUpdate):** Iterate through `dirtyChunks` [S2, unofficial]. For each chunk:
   a. Call `PreMeshing()`: Assert the chunk is dirty and call `UnsetDirty()` to clear the flag [S1, unofficial].
   b. Call `Rebuild()`: Perform Marching Cubes on the chunk's voxels [S2, unofficial].
   c. Call `PostMeshing()`: Check `tempMeshData.Length`. If $> 0$, create a new `VoxelVertexBuffer` and copy data via `BufferData()` [S1, unofficial]. Recycle temporary mesh visitor and vertex storage via `MeshVisitorAllocator.Recycle` and `TempStorageAllocator<VoxelVertex>.Recycle` [S1, unofficial].
   d. Remove the chunk from `dirtyChunks` [S2, unofficial].

**Parameters:**
- `chunkSize` ($C$): Typically 32, as chunks are always allocated in $32 \times 32 \times 32$ blocks [S1, unofficial].
- `dirty`: Boolean flag in the `Chunk` struct [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Boundary Effects:** The chunk index calculation must account for the fact that a voxel at index $x$ affects the cell to its left ($x-1$). Failing to subtract 1 before division causes incorrect chunk marking for voxels at the start of a chunk [S2, unofficial].

**Pseudocode:**
```python
def mark_dirty(minX, maxX, minY, maxY, minZ, maxZ, chunkSize, chunks, dirty_chunks):
    # Pitfall: voxel x affects cell x-1, so subtract 1 before division
    c_min_x = (minX - 1) // chunkSize
    c_min_y = (minY - 1) // chunkSize
    c_min_z = (minZ - 1) // chunkSize
    
    # Standard integer division for maximum affected chunk
    c_max_x = maxX // chunkSize
    c_max_y = maxY // chunkSize
    c_max_z = maxZ // chunkSize
    
    # Add all chunks in range to dirty set
    for cx in range(c_min_x, c_max_x + 1):
        for cy in range(c_min_y, c_max_y + 1):
            for cz in range(c_min_z, c_max_z + 1):
                dirty_chunks.add((cx, cy, cz))
                chunks[cx, cy, cz].dirty = True

def process_dirty_chunks(dirty_chunks, chunks, chunk_size):
    for (cx, cy, cz) in list(dirty_chunks):
        chunk = chunks[cx, cy, cz]
        
        # Pre-meshing: clear flag
        chunk.pre_meshing()
        chunk.dirty = False
        
        # Rebuild mesh
        temp_storage = chunk.rebuild()
        
        # Post-meshing: update buffer if needed
        if len(temp_storage) > 0:
            new_buffer = VertexBuffer(temp_storage)
            new_buffer.upload_to_gpu()
            # Recycle allocators
            MeshVisitorAllocator.recycle(chunk.mesh_visitor)
            TempStorageAllocator.recycle(temp_storage)
        
        dirty_chunks.remove((cx, cy, cz))
```
