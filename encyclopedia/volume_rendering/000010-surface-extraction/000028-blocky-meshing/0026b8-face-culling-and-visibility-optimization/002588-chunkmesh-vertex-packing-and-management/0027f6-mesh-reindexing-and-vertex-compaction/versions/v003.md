# Mesh Reindexing and Vertex Compaction

Also called: Mesh Simplification via Vertex Deduplication, Vertex Compaction, compactVertices

## Overview
This method compacts vertex buffers by removing unreferenced vertices and renumbering the remaining ones into a dense, contiguous array [S1, unofficial]. It addresses sparse vertex buffers generated during incremental blocky meshing, where vertices are allocated per voxel face but many are culled or unused [G]. Unlike [Voxel Face Meshing with Packed Attributes](4153-voxel-face-meshing-with-packed-attributes.md), which optimizes storage layout, this method actively reduces vertex count [G]. It differs from [Chunk Mesh Data Structure & Buffer Update](4182-chunk-mesh-data-structure-buffer-update.md) by performing logical remapping of indices and data rather than merely updating buffer pointers [G].

## How it works
**Inputs:** A mesh object containing a position buffer `mPositions`, an index collection `mIndexCollection`, and optional attribute buffers (`mNormals`, `mTexCoords`, and generic attributes from `mMesh->getAttributes()`) [S1, unofficial].
**Outputs:** The same mesh object with compacted buffers and remapped indices [S1, unofficial].

**Data Structures:**
*   `mPositions`: Array of vertex positions with size $N$ [S1, unofficial].
*   `mIndexCollection`: Collection of indices where each index has a component `.x()` representing the vertex ID [S1, unofficial].
*   `mNormals` / `mTexCoords`: Arrays of normals and texture coordinates, each with size $N$ if present [S1, unofficial].
*   `mMesh->getAttributes()`: List of generic attributes where each provides `getSize()`, `getNumComponents()`, `getFormat()`, and `assign()` methods [S1, unofficial].

**Steps:**
1.  **Implicit Index Check:** If the mesh uses implicit indices, return immediately to avoid undefined behavior [S1, unofficial].
2.  **Mark Used Vertices:** Create a boolean vector `used` of size $N$, initialized to `false` [S1, unofficial]. Iterate through `mIndexCollection` [S1, unofficial]. For each index `idx`, extract `vi = idx.x()` [S1, unofficial]. If `vi < N`, set `used[vi] = true` [S1, unofficial].
3.  **Build Remap Table:** Create a remap table `remap` of size $N$, initialized to `std::size_t(-1)` [S1, unofficial]. Initialize `newIndex = 0` [S1, unofficial]. Iterate `oldIndex` from $0$ to $N-1$ [S1, unofficial]. If `used[oldIndex]` is true, assign `remap[oldIndex] = newIndex` and increment `newIndex` [S1, unofficial]. The final value of `newIndex` is the new compacted vertex count $N'$ [S1, unofficial].
4.  **Compact Positions:** Create `newPositions` of size $N'$ [S1, unofficial]. Iterate `oldIndex` from $0$ to $N-1$ [S1, unofficial]. If `remap[oldIndex] != std::size_t(-1)`, set `newPositions[remap[oldIndex]] = mPositions[oldIndex]` [S1, unofficial]. Update `mPositions` with `newPositions` [S1, unofficial].
5.  **Compact Normals:** If `mNormals` exists and `mNormals.getSize() == N`, create `newNormals` of size $N'$ [S1, unofficial]. Iterate `oldIndex` from $0$ to $N-1$ [S1, unofficial]. If `remap[oldIndex] != std::size_t(-1)`, set `newNormals[remap[oldIndex]] = mNormals[oldIndex]` [S1, unofficial]. Update `mNormals` [S1, unofficial].
6.  **Compact TexCoords:** If `mTexCoords` exists and `mTexCoords.getSize() == N`, create `newTexCoords` of size $N'$ [S1, unofficial]. Iterate `oldIndex` from $0$ to $N-1$ [S1, unofficial]. If `remap[oldIndex] != std::size_t(-1)`, set `newTexCoords[remap[oldIndex]] = mTexCoords[oldIndex]` [S1, unofficial]. Update `mTexCoords` [S1, unofficial].
7.  **Compact Generic Attributes:** For each attribute `attr` in `mMesh->getAttributes()`: If `attr.getSize() == N`, create `newAttr` with size $N'$, same component count and format as `attr` [S1, unofficial]. Iterate `oldIndex` from $0$ to $N-1$ [S1, unofficial]. If `remap[oldIndex] != std::size_t(-1)`, call `newAttr.assign(remap[oldIndex], oldIndex, attr)` to copy the data [S1, unofficial]. Replace `attr` with `newAttr` [S1, unofficial]. If `attr.getSize() != N`, skip it to prevent data corruption [S1, unofficial].
8.  **Remap Indices:** Iterate through `mIndexCollection` [S1, unofficial]. For each `idx`, update `idx.x() = static_cast<std::uint32_t>(remap[idx.x()])` [S1, unofficial].

**Pseudocode:**
```python
class RawArray:
    def __init__(self):
        self._components = 0
        self._format = 0
        self._size = 0
        self._data = []
    def set_num_components(self, c): self._components = c
    def set_format(self, f): self._format = f
    def set_size(self, s):
        self._size = s
        self._data = [None] * s
    def assign(self, dst_idx, src_idx, src_attr):
        self._data[dst_idx] = src_attr._data[src_idx]

def compact_vertices(mesh):
    if mesh.has_implicit_indices():
        return

    n = mesh.m_positions.size()
    if n == 0:
        return

    used = [False] * n
    for idx in mesh.m_index_collection:
        vi = idx.x
        if 0 <= vi < n:
            used[vi] = True

    remap = [-1] * n
    new_index = 0
    for old_index in range(n):
        if used[old_index]:
            remap[old_index] = new_index
            new_index += 1

    new_n = new_index

    new_positions = [None] * new_n
    for old_index in range(n):
        if remap[old_index] != -1:
            new_positions[remap[old_index]] = mesh.m_positions[old_index]
    mesh.m_positions.set_values(new_positions)

    if mesh.m_normals is not None and mesh.m_normals.size() == n:
        new_normals = [None] * new_n
        for old_index in range(n):
            if remap[old_index] != -1:
                new_normals[remap[old_index]] = mesh.m_normals[old_index]
        mesh.m_normals.set_values(new_normals)

    if mesh.m_texcoords is not None and mesh.m_texcoords.size() == n:
        new_texcoords = [None] * new_n
        for old_index in range(n):
            if remap[old_index] != -1:
                new_texcoords[remap[old_index]] = mesh.m_texcoords[old_index]
        mesh.m_texcoords.set_values(new_texcoords)

    for attr in mesh.m_mesh.get_attributes():
        if attr.size() == n:
            new_attr = RawArray()
            new_attr.set_num_components(attr.get_num_components())
            new_attr.set_format(attr.get_format())
            new_attr.set_size(new_n)
            for old_index in range(n):
                if remap[old_index] != -1:
                    new_attr.assign(remap[old_index], old_index, attr)
            attr = new_attr

    for idx in mesh.m_index_collection:
        idx.x = int(remap[idx.x])
```

**Parameters:**
*   `epsDiagonal`, `epsDuplicate`: Not used in this method [S1, unofficial].
*   Typical values: Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Implicit Indices:** If the mesh uses implicit indices, the method returns immediately to avoid undefined behavior [S1, unofficial].
*   **Misaligned Attributes:** Attributes must have the same size as the position buffer to be compacted [S1, unofficial]. If sizes differ, they are skipped to prevent data corruption [S1, unofficial].
*   **Index Bounds:** Index values must be within $[0, N)$ to be marked as used [S1, unofficial]. Out-of-bounds indices are ignored during the marking phase [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N + I)$, where $N$ is the vertex count and $I$ is the index count, due to single passes over indices and vertices [G].
*   **Memory Complexity:** $O(N)$ for the `used` and `remap` arrays, plus $O(N')$ for the new compacted buffers, where $N' \le N$ [G].
*   **Strengths:** Reduces memory usage significantly when many vertices are unused [G]. Simple to implement [G].
*   **Limitations:** Does not remove duplicate vertices (only unreferenced ones) [G]. Requires a full pass over the mesh data [G].
*   **When to use:** After face culling and visibility optimization, before rendering, to reduce the vertex buffer size [G].
*   **When not to use:** If the mesh uses implicit indices or if attributes are not aligned with the position buffer [G].

## Background
This method originates from the codebase in [S1, unofficial]. It is applied in blocky meshing pipelines for volume rendering, specifically following chunk meshing and face culling steps [G].
