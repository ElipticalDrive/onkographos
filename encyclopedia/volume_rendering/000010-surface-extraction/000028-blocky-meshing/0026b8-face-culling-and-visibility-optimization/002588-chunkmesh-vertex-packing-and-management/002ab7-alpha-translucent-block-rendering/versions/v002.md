# Alpha/Translucent Block Rendering

Also called: Translucent Block Shader

## Overview
Alpha/Translucent Block Rendering renders semi-transparent voxel blocks using standard rasterization with pre-computed vertex attributes and fragment shading [S1, unofficial]. It avoids per-pixel ray-marching by applying distance-based fog and shading in the fragment shader [S1, unofficial].

## How it works
### Inputs and Outputs
The method takes a packed vertex buffer containing `vertex0` and `vertex1`, a `sampler2DArray`, and uniform variables as input [S1, unofficial]. It outputs a color buffer with shaded and fogged translucent faces.

### Data Structures
`vertex0` stores local block coordinates in 10-bit fields (x: bits 0–9, y: bits 10–19, z: bits 20–29) [S1, unofficial]. `vertex1` stores the texture layer, UV coordinates, and shading bits [S1, unofficial].

### Uniforms
`chunkPosition` (vec3), `fogFar` (float), and `fogColor` (vec4) are passed as uniforms [S1, unofficial].

### Algorithm Steps
1. Extract local `x`, `y`, `z` from `vertex0` using bitmasks `1023u` and shifts `10`, `20` [S1, unofficial].
2. Compute `worldPos` by adding `chunkPosition` to the extracted coordinates [S1, unofficial].
3. Compute `gl_Position` from `worldPos` [S1, unofficial].
4. Extract `textureLayer`, `texcoordX`, `texcoordY` from `vertex1` [S1, unofficial].
5. Scale UVs: `uv = vec2(texcoordX, texcoordY) * 0.0625f` [S1, unofficial].
6. Compute shading: `shadeData = (shadingBits * 0.2) + 0.4` [S1, unofficial].
7. Compute `viewPosition` for depth-based fog [S1, unofficial].
8. Sample `sampler2DArray` at `(uv, textureLayer)` [S1, unofficial].
9. Apply shading: `color.rgb *= shadeData` [S1, unofficial].
10. Apply fog: `finalColor = mix(color, fogColor, smoothstep(0.0f, fogFar, length(viewPosition)))` [S1, unofficial].

### Pseudocode
```python
# Vertex Shader
x = vertex0 & 1023u
y = (vertex0 >> 10) & 1023u
z = (vertex0 >> 20) & 1023u
worldPos = vec3(x, y, z) + chunkPosition
gl_Position = compute_clip_position(worldPos)
textureLayer, texcoordX, texcoordY = extract_vertex1_fields(vertex1)
uv = vec2(texcoordX, texcoordY) * 0.0625f
shadingBits = (vertex1 >> 20) & 1023u
shadeData = shadingBits * 0.2 + 0.4
viewPosition = compute_view_position(worldPos)

# Fragment Shader
color = texture(textureSampler, vec3(uv, textureLayer))
color.rgb *= shadeData
fogFactor = smoothstep(0.0f, fogFar, length(viewPosition))
finalColor = mix(color, fogColor, fogFactor)
```

### Edge Cases and Pitfalls
The `0.0625f` scale factor assumes a 16-unit texture atlas grid [S1, unofficial]. Draw order for alpha blending is not specified by this method and must be handled by the parent meshing system [G].

## Subtopics

### Greedy Meshing for Translucent Blocks
For each face of a translucent voxel block, render a flat color using raw UVs without an atlas lookup [S2, unofficial]. Retrieve face UVs via `quad.uvs(face, false)` and block color via `block_textures.to_color(&chunk_block_id, block_face)`, defaulting to `[0.0, 0.0, 0.0, 1.0]` on failure [S2, unofficial].

## Operating characteristics
Time and memory complexity, measured performance, and scaling are Not given in the sources. Strengths include low per-fragment computational cost and compatibility with standard pipelines [G]. Limitations include lack of true volumetric transparency and reliance on parent draw-order sorting [G].

## Background
Originates from practical voxel engine implementations, specifically the Exolands project [S1, unofficial] and Infinigen [S2, unofficial].
