# Voxel Face Visibility Check

Also called: Back-Face Culling, Camera-relative Block Culling, renderBlock

## Overview
Voxel Face Visibility Check determines which of the six faces of a voxel block are visible to the viewer by evaluating the geometric relationship between face normals and a reference direction [S1, unofficial]. It solves the problem of rendering unnecessary geometry that faces away from the camera, thereby avoiding unnecessary computation [S2, unofficial].

## How it works
**Inputs:**
- `cube_center`: The 3D position of the voxel block's center ($\mathbf{c}_{block}$) [S1, unofficial].
- `cube_size`: The side length of the cubic voxel block ($s$) [S1, unofficial].
- `camera_position`: The 3D position of the viewer [G].

**Outputs:**
- A boolean list or bitmask indicating which of the six faces are visible [S1, unofficial].

**Data Structures:**
The method evaluates six faces. Each face is defined by an outward normal $\mathbf{n}_i$ and a center point $\mathbf{c}_i$ [S1, unofficial].
- Normals:
  - Front: $(0, 0, 1)$
  - Back: $(0, 0, -1)$
  - Right: $(-1, 0, 0)$
  - Left: $(1, 0, 0)$
  - Top: $(0, 1, 0)$
  - Bottom: $(0, -1, 0)$ [S1, unofficial].

**Steps:**
1. Calculate the half-size of the cube: $h = s / 2$ [S1, unofficial].
2. Determine the center of each face $\mathbf{c}_i$ by adding the offset vector $h \cdot \mathbf{n}_i$ to `cube_center`:
   $$ \mathbf{c}_i = \mathbf{c}_{block} + h \cdot \mathbf{n}_i $$ [S1, unofficial].
3. For each face $i$, compute the dot product between the outward normal $\mathbf{n}_i$ and the viewing direction $\mathbf{v}$ (the vector from the face center to the camera):
   $$ \mathbf{v} = \text{camera\_position} - \mathbf{c}_i $$ [G].
   $$ v_i = \mathbf{n}_i \cdot \mathbf{v} $$ [S2, unofficial].
4. Mark face $i$ as visible if $v_i > 0$ [S2, unofficial].

**Pseudocode:**
```python
def voxel_face_visibility_check(cube_center, cube_size, camera_position):
    half_size = cube_size / 2.0
    normals = [
        (0, 0, 1),   # Front
        (0, 0, -1),  # Back
        (-1, 0, 0),  # Right
        (1, 0, 0),   # Left
        (0, 1, 0),   # Top
        (0, -1, 0)   # Bottom
    ]
    visible_faces = []
    for i, normal in enumerate(normals):
        face_center = (
            cube_center[0] + normal[0] * half_size,
            cube_center[1] + normal[1] * half_size,
            cube_center[2] + normal[2] * half_size
        )
        view_vector = (
            camera_position[0] - face_center[0],
            camera_position[1] - face_center[1],
            camera_position[2] - face_center[2]
        )
        dot_product = (normal[0] * view_vector[0] +
                       normal[1] * view_vector[1] +
                       normal[2] * view_vector[2])
        if dot_product > 0:
            visible_faces.append(i)
    return visible_faces
```

**Parameters:**
- `GL_CULL_FACE`: An OpenGL flag that enables back-face culling [S2, unofficial].

**Pitfalls:**
- **Reference Point Error:** Source [S1, unofficial] implements the visibility test using the world origin $(0,0,0)$ as the reference point for the dot product (i.e., computing $\mathbf{c}_i \cdot \mathbf{n}_i$ instead of $\mathbf{n}_i \cdot \mathbf{v}$). This marks faces as visible only if they point away from the world origin, which is incorrect for arbitrary camera positions [S1, unofficial].
- **Precision:** Floating-point precision issues may cause faces exactly parallel to the view direction (dot product $\approx 0$) to be incorrectly culled or rendered [G].

## Operating characteristics
- **Time Complexity:** $O(1)$ per block, as it involves a fixed number of arithmetic operations (6 dot products) [G].
- **Memory Complexity:** $O(1)$, requiring only temporary storage for face centers and normals [G].
- **Strengths:** Extremely fast; reduces the number of vertices and indices sent to the GPU [G].
- **Limitations:** Only culls faces facing away from the camera. It does not cull faces that are occluded by other geometry (requires depth testing or further culling) [G].

## Background
Back-face culling is a fundamental technique in computer graphics [G]. It is implemented via the `GL_CULL_FACE` flag in OpenGL [S2, unofficial].
