# Extraction of Surface Points (Sobierajski)
Also called: Sobierajski's method, Visible boundary voxel extraction

## Overview
A fast display method for direct rendering of boundary surfaces by extracting only visible boundary voxels from volume data [S1, unofficial]. It sets itself apart from sibling methods like [Face Culling](8735-face-culling.md) by using multi-view orthographic projection to determine visibility rather than local neighbor checks, and from [Saito's Fast Previewing Algorithm](#saitos-fast-previewing-algorithm) by extracting the full set of potentially visible voxels rather than a sparse subset.

## How it works
**Inputs:** Volume data (density values), viewing directions (typically six orthographic views along coordinate axes).
**Outputs:** A list of unique boundary voxels with attributes (coordinates, normal vectors).

**Data Structures:**
*   `BoundaryVoxel`: Struct containing `position` (3D integer coordinates), `normal` (3D vector), and `density` (scalar).
*   `VisibleSet`: A set or hash map storing unique `BoundaryVoxel` instances to remove duplicates.

**Steps:**
1.  **Visibility Determination:** For each of the $N$ viewing directions $V_i$:
    *   Project the volume onto a 2D slice perpendicular to $V_i$.
    *   Perform a 2D boundary tracing algorithm on the slice to identify boundary voxels visible from $V_i$ [S1, unofficial].
    *   A voxel is considered visible if it lies on the boundary of the opaque/transparent region in that projection.
2.  **Collection:** Add all identified visible boundary voxels to `VisibleSet`. Each voxel stores its coordinates and normal vector [S1, unofficial].
3.  **Deduplication:** Remove duplicate entries from `VisibleSet` based on voxel coordinates [S1, unofficial].
4.  **Backface Culling:** For each voxel in `VisibleSet` with normal $N$ and viewing direction $V$:
    *   Calculate dot product $D = N \cdot V$.
    *   If $D > 0$, the voxel is a back face and is removed from the list [S1, unofficial].
5.  **Rendering Preparation:** Pass the final list to the rendering engine.
    *   Project each voxel onto multiple pixels depending on the viewing direction to avoid holes caused by adjacent voxels mapping to non-adjacent pixels [S1, unofficial].
    *   Shade projected points according to lighting conditions.
    *   If cutting planes are used, render voxels intersected by the plane by projecting their original density values [S1, unofficial].

**Pseudocode:**
```python
def extract_surface_points(volume, viewing_directions):
    visible_voxels = set()
    
    # Step 1 & 2: Visibility determination and collection
    for view_dir in viewing_directions:
        # Project volume onto 2D slice perpendicular to view_dir
        # Perform 2D boundary tracing to find visible boundary voxels
        # This is a placeholder for the specific 2D tracing algorithm
        visible_boundary = trace_2d_boundary(volume, view_dir)
        
        for voxel in visible_boundary:
            # Store voxel with attributes
            visible_voxels.add(voxel)
            
    # Step 3: Deduplication is handled by the set data structure
    
    # Step 4: Backface culling
    final_voxels = []
    for voxel in visible_voxels:
        # Calculate dot product of surface normal and viewing direction
        dot_product = dot(voxel.normal, view_dir)
        
        # If dot product is positive, it is a back face
        if dot_product <= 0:
            final_voxels.append(voxel)
            
    return final_voxels

def render_surface_points(voxels, view_dir, lighting):

            color = shade(pixel.position, voxel.normal, lighting)
            draw_pixel(pixel, color)
```

## Subtopics

### Saito's Fast Previewing Algorithm
A previewing algorithm based on extracting a subset of boundary voxels according to a uniform distribution to increase rendering speed [S1, unofficial]. It extracts a subset of boundary voxels, converts them to geometrical primitives like crosslines perpendicular to the surface normal, and projects them onto the image plane [S1, unofficial].

### Trimmed Voxel Lists
A surface rendering algorithm that uses 3D points as geometric primitives by projecting exactly one point per visible surface cell to ensure image coverage without subdivision [S2, unofficial]. It identifies visible surface cells, selects exactly one 3D point per cell, and projects each point onto the image plane, allowing it to cover up to three pixels to guarantee coverage [S2, unofficial]. It differs from Dividing Cubes by avoiding recursive subdivision [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the 2D boundary tracing algorithm and the number of viewing directions. Typically $O(N \cdot M)$ where $N$ is the number of voxels and $M$ is the number of viewing directions.
*   **Memory Complexity:** $O(K)$ where $K$ is the number of visible boundary voxels.
*   **Strengths:** Fast for direct rendering of boundary surfaces; simple implementation; supports cutting planes easily [S1, unofficial].
*   **Limitations:** May produce holes if voxels are not projected onto multiple pixels; accuracy depends on the number of viewing directions; backface culling is view-dependent [S1, unofficial].
*   **When to use:** When fast previewing or direct boundary surface rendering is required; when cutting planes are needed [S1, unofficial].
*   **When not to use:** When high accuracy is required without holes; when the volume has complex internal structures not visible from orthographic views.

## Background
Proposed by Sobierajski [S1, unofficial]. It is a fast display method for direct rendering of boundary surfaces. It is often used in medical imaging systems where cutting operations are important [S1, unofficial].
