# Mesh Post-Processing (Cluster Filtering)
Also called: Cluster-based Mesh Simplification

## Overview
This method filters out floating artifacts and disconnected components from a 3D mesh by clustering triangles and retaining only the largest connected clusters [S2, unofficial]. It serves as a cleanup step following [Mesh Culling via 3D Projection and Connected Components](6963-mesh-culling-via-3d-projection-and-connected-components.md), specifically targeting small, noisy geometry that survives projection-based culling [G]. Unlike the parent method which removes occluded or distant geometry, this method removes topologically isolated fragments based on triangle count [S1, S2, unofficial].

## How it works
**Inputs:** A triangle mesh defined by vertices and faces [S1, unofficial].
**Outputs:** A cleaned triangle mesh with small disconnected components removed [S1, unofficial].

**Data Structures:**
*   `mesh`: Container for vertex positions and face indices.
*   `cluster_labels`: Integer array mapping each triangle index to a cluster identifier.
*   `cluster_n_triangles`: Array storing the triangle count for each cluster.

**Steps:**
1.  **Cluster Identification:** Identify connected triangle clusters by traversing the triangle adjacency graph [G].
2.  **Threshold Determination:** Sort `cluster_n_triangles` in descending order, select the $N$-th largest value where $N$ is `cluster_to_keep`, and enforce a minimum size `min_cluster_size` [S1, unofficial]. The effective threshold $T$ is computed as:
    $$ T = \max(\text{size of } N\text{-th largest cluster}, \text{min\_cluster\_size}) $$
3.  **Mask Creation:** Create a boolean mask marking triangles for removal if their cluster size is strictly less than $T$ [S1, unofficial].
4.  **Removal:** Remove triangles belonging to clusters smaller than the threshold, then remove unreferenced vertices and degenerate triangles [S1, unofficial].

**Parameters:**
*   `cluster_to_keep`: Integer specifying the maximum number of largest connected clusters to retain. Default value is 1000 [S1, unofficial].
*   `min_cluster_size`: Integer specifying the minimum number of triangles a cluster must have to be kept. Default value is 50 [S1, unofficial].

**Pseudocode:**
```python
def post_process_mesh(vertices, faces, cluster_to_keep=1000, min_cluster_size=50):
    """
    Filters out floating artifacts and disconnected components from a 3D mesh.
    
    Args:
        vertices: List of 3D coordinate tuples.
        faces: List of 3-tuples containing vertex indices.
        cluster_to_keep: Maximum number of largest clusters to retain.
        min_cluster_size: Minimum triangles per cluster to keep.
        
    Returns:
        Cleaned vertices and faces lists.
    """
    if len(faces) == 0:
        return vertices, faces

    # Step 1: Identify connected triangle clusters via BFS on triangle adjacency
    F = len(faces)
    cluster_labels = [-1] * F
    cluster_id = 0
    visited = [False] * F

    for i in range(F):
        if not visited[i]:
            queue = [i]
            visited[i] = True
            cluster_labels[i] = cluster_id
            while queue:
                curr = queue.pop(0)
                curr_verts = set(faces[curr])
                for j in range(F):
                    if not visited[j]:
                        if any(v in curr_verts for v in faces[j]):
                            visited[j] = True
                            cluster_labels[j] = cluster_id
                            queue.append(j)
            cluster_id += 1

    # Step 2: Determine threshold
    cluster_counts = [0] * cluster_id
    for label in cluster_labels:
        cluster_counts[label] += 1
    cluster_sizes = sorted(cluster_counts, reverse=True)

    if len(cluster_sizes) > cluster_to_keep:
        nth_largest_size = cluster_sizes[cluster_to_keep - 1]
    else:
        nth_largest_size = 0

    threshold = max(nth_largest_size, min_cluster_size)

    # Step 3 & 4: Mask creation and removal
    keep_mask = [cluster_counts[label] >= threshold for label in cluster_labels]
    new_faces = [faces[i] for i, keep in enumerate(keep_mask) if keep]

    # Remove unreferenced vertices
    used_verts = set()
    for f in new_faces:
        used_verts.update(f)
    sorted_verts = sorted(used_verts)
    vert_map = {v: i for i, v in enumerate(sorted_verts)}
    new_vertices = [vertices[v] for v in sorted_verts]
    new_faces = [[vert_map[v] for v in f] for f in new_faces]

    # Remove degenerate triangles
    def triangle_area(v0, v1, v2):
        return abs((v1[0]-v0[0])*(v2[1]-v0[1]) - (v2[0]-v0[0])*(v1[1]-v0[1]))
    final_faces = []
    for f in new_faces:
        if triangle_area(new_vertices[f[0]], new_vertices[f[1]], new_vertices[f[2]]) > 1e-8:
            final_faces.append(f)

    return new_vertices, final_faces
```

**Edge Cases and Pitfalls:**
*   **Precision:** Vertex sharing tolerance is required for adjacency detection if floating-point positions do not match exactly [G].
*   **Boundaries:** If `cluster_to_keep` exceeds the total number of clusters, the threshold falls back to `min_cluster_size` [S1, unofficial].
*   **Degenerate Input:** If the input mesh contains no triangles, the function returns the original empty mesh [G].

## Operating characteristics
*   **Time Complexity:** Dominated by the connected components traversal, which is $O(T)$ where $T$ is the number of triangles, plus $O(C \log C)$ for sorting cluster sizes where $C$ is the number of clusters [G].
*   **Memory Complexity:** $O(T)$ to store cluster labels, counts, and adjacency traversal state [G].
*   **Strengths:** Effectively removes small, noisy artifacts that are topologically disconnected from the main geometry [S1, unofficial].
*   **Limitations:** May remove valid small objects if they fall below `min_cluster_size` or if the cluster count exceeds `cluster_to_keep` [S1, unofficial]. It does not consider geometric significance, only topological connectivity and size [G].
*   **When to use:** After surface extraction or meshing from point clouds/voxels where noise and floating artifacts are common [G].
*   **When not to use:** When small objects are semantically important and should be preserved regardless of size [G].

## Background
This method is part of the post-processing pipeline for 3D Gaussian Splatting and related surface extraction techniques [S1, S2, unofficial]. It is specifically applied to clean up meshes generated from Gaussian splats by eliminating topologically isolated fragments [S2, unofficial].
