# Mesh Culling via 3D Projection and Connected Components

Also called: Mesh Culling via Multi-View Depth Projection, cull with 3d projection

## Overview
This method removes geometric artifacts and occluded regions from a 3D mesh by projecting its vertices into multiple camera views and comparing projected depths against reference depth maps. It classifies mesh faces as "seen," "unseen," or "forecast" based on multi-view consistency and front-face validation, then culls invisible geometry. Unlike parent methods that rely on voxel neighbor checks [Parent], this approach operates on the extracted mesh directly using camera-space projections, making it suitable for unbounded or sparse reconstructions where voxel grids are impractical.

## How it works
**Inputs:**
- A triangular mesh (vertices $V$, faces $F$).
- A list of camera poses $C = \{c_2w_i\}$ and intrinsic parameters $K = \text{diag}(f_x, f_y, c_x, c_y)$.
- Reference depth maps $D_i$ for each camera pose (rendered or captured).
- Parameters: `points_batch_size` (default $5 \times 10^5$), `eps` (default $0.005$), `remove_small_geometry_threshold` (default $0.2$), `forecast_radius` (optional, for bounding forecast region).

**Outputs:**
- A culled mesh with unreferenced vertices removed.

**Data Structures:**
- `valid`: Boolean tensor of shape $(N_{vertices})$, true if vertex is seen in $\ge 20$ cameras.
- `valid_forecast`: Boolean tensor of shape $(N_{vertices})$, true if vertex is in forecast region.
- `face_mask`: Boolean tensor of shape $(N_{faces})$, true if all vertices of the face are valid.

**Steps:**

1. **Initialize Masks:**
   Create zero tensors `valid`, `valid_num` (count), and `valid_forecast` of size $N_{vertices}$ on the target device.

2. **Iterate Camera Poses:**
   For each camera pose $c_2w_i$:
   a. **Coordinate Transform:** Negate the $y$ and $z$ rows of the rotation matrix in $c_2w_i$ to match the expected coordinate system.
   b. **World-to-Camera:** Compute $w2c_i = c_2w_i^{-1}$.
   c. **Project Vertices:**
      - Append ones to $V$ to form homogeneous coordinates $V_h$.
      - Compute camera-space coordinates: $V_c = w2c_i \cdot V_h$.
      - Extract $x_c, y_c, z_c$ from the first three rows.
   d. **Intrinsic Projection:**
      - Compute $u = f_x \cdot (x_c / z_c) + c_x$.
      - Compute $v = f_y \cdot (y_c / z_c) + c_y$.
      - Compute depth $z = z_c + \epsilon$ (where $\epsilon = 10^{-8}$ to avoid division by zero).
      - Normalize UV for grid sampling: $u_{norm} = \frac{2u}{W-1} - 1$, $v_{norm} = \frac{2v}{H-1} - 1$.
   e. **Frustum Check:**
      - Define `in_frustum`: $0 \le u < W$, $0 \le v < H$, $z > 0$.
      - If `forecast_radius` $> 0$, define `forecast_frustum`: $-r \le u < W+r$, $-r \le v < H+r$, $z > 0$.
   f. **Depth Sampling:**
      - Reshape reference depth $D_i$ to $(1, 1, H, W)$.
      - Sample depth at $(u_{norm}, v_{norm})$ using bilinear interpolation with border padding.
   g. **Front-Face Validation:**
      - Compute `is_front_face`: $depth_{sample} > 0$ AND $z < depth_{sample} + \text{eps}$.
   h. **Update Masks:**
      - For vertices in `in_frustum` and `is_front_face`, increment `valid_num` and set `valid` to true.
      - For vertices in `forecast_frustum` and `is_front_face`, set `valid_forecast` to true.

3. **Finalize Vertex Masks:**
   - `valid = valid_num >= 20` (requires projection into at least 20 cameras).
   - Combine `valid` and `valid_forecast` if forecast mode is active.

4. **Face Culling:**
   - Compute `face_mask`: For each face, check if all its vertices are valid (`face_mask = valid[faces].all(axis=1)`).
   - Update mesh: Keep only faces where `face_mask` is true.
   - Remove unreferenced vertices.

5. **Connected Component Filtering (Optional):**
   - If `forecast_radius > 0`:
     - Compute Oriented Bounding Box (OBB) from the cull mesh vertices.
     - Keep only forecast faces within this OBB.
   - Filter by area: Keep components where area $> \text{remove\_small\_geometry\_threshold} \times \text{global\_area}$, or keep only the largest component if `get_largest_components` is true.

**Pseudocode:**

```python
import torch
import numpy as np

def mesh_culling_3d_projection(mesh, cameras, depth_maps, params):
    """
    Cull mesh geometry using multi-view depth projection.
    
    Args:
        mesh: Mesh object with vertices (N, 3) and faces (M, 3).
        cameras: List of camera poses (c2w matrices, 4x4) and intrinsics (fx, fy, cx, cy, W, H).
        depth_maps: List of depth maps (H, W) for each camera.
        params: Dictionary with parameters (eps, batch_size, etc.).
        
    Returns:
        Culled mesh.
    """
    eps = params.get('eps', 0.005)
    batch_size = params.get('points_batch_size', 5e5)
    min_views = 20
    forecast_radius = params.get('forecast_radius', 0)
    
    vertices = mesh.vertices  # (N, 3)
    faces = mesh.faces        # (M, 3)
    N = vertices.shape[0]
    
    # Initialize masks
    valid = torch.zeros(N, dtype=torch.bool, device=vertices.device)
    valid_num = torch.zeros(N, dtype=torch.int, device=vertices.device)
    valid_forecast = torch.zeros(N, dtype=torch.bool, device=vertices.device)
    
    # Process in batches to limit memory
    for batch_start in range(0, N, batch_size):
        batch_end = min(batch_start + batch_size, N)
        batch_vertices = vertices[batch_start:batch_end]
        
        for i, (c2w, K, depth_map) in enumerate(zip(cameras, cameras, depth_maps)):
            # Coordinate transform
            c2w_transformed = c2w.clone()
            c2w_transformed[1:3, :] *= -1  # Negate y and z rows
            
            # World-to-Camera
            w2c = torch.inverse(c2w_transformed)
            
            # Homogeneous coordinates
            batch_h = torch.cat([batch_vertices, torch.ones(batch_vertices.shape[0], 1, device=vertices.device)], dim=1)
            
            # Project to camera space
            batch_cam = w2c[:3, :3] @ batch_h.T + w2c[:3, 3:4]
            x_c, y_c, z_c = batch_cam[0], batch_cam[1], batch_cam[2]
            
            # Intrinsic projection
            z_safe = z_c + 1e-8
            u = K.fx * (x_c / z_safe) + K.cx
            v = K.fy * (y_c / z_safe) + K.cy
            
            # Normalize UV for grid sampling
            u_norm = (2 * u / (K.W - 1)) - 1
            v_norm = (2 * v / (K.H - 1)) - 1
            
            # Frustum check
            in_frustum = (u >= 0) & (u < K.W) & (v >= 0) & (v < K.H) & (z_c > 0)
            
            # Forecast frustum
            if forecast_radius > 0:
                forecast_frustum = (u >= -forecast_radius) & (u < K.W + forecast_radius) & \
                                   (v >= -forecast_radius) & (v < K.H + forecast_radius) & (z_c > 0)
            else:
                forecast_frustum = torch.zeros_like(in_frustum)
            
            # Depth sampling
            # Reshape depth map to (1, 1, H, W)
            depth_tensor = torch.from_numpy(depth_map).unsqueeze(0).unsqueeze(0).to(vertices.device)
            # Create grid for grid_sample
            grid = torch.stack([u_norm, v_norm], dim=-1).unsqueeze(0).unsqueeze(0)
            depth_sample = torch.nn.functional.grid_sample(depth_tensor, grid, padding_mode='border', align_corners=True).squeeze()
            
            # Front-face validation
            is_front_face = (depth_sample > 0) & (z_c < depth_sample + eps)
            
            # Update masks
            valid_mask = in_frustum & is_front_face
            valid_num[batch_start:batch_end] += valid_mask.int()
            valid[batch_start:batch_end] |= valid_mask
            
            forecast_mask = forecast_frustum & is_front_face
            valid_forecast[batch_start:batch_end] |= forecast_mask
            
    # Finalize vertex masks
    valid = valid_num >= min_views
    
    # Face culling
    face_mask = valid[faces].all(dim=1)
    
    # Update mesh
    mesh.faces = mesh.faces[face_mask]
    mesh.remove_unreferenced_vertices()
    
    # Optional: Connected component filtering
    if forecast_radius > 0:

    # Filter by area

    return mesh
```

**Edge Cases and Pitfalls:**
- **Precision:** Use `eps` to handle floating-point inaccuracies in depth comparison.
- **Boundaries:** Vertices near image borders may fail frustum checks; use border padding in depth sampling.
- **Degenerate Input:** Empty meshes or meshes with no visible faces should be handled gracefully.
- **Memory:** Large meshes may require batching to avoid GPU memory overflow.

## Operating characteristics
- **Time Complexity:** $O(N \cdot C)$, where $N$ is the number of vertices and $C$ is the number of cameras. Depth sampling is $O(1)$ per vertex per camera.
- **Memory Complexity:** $O(N + C \cdot H \cdot W)$ for storing masks and depth maps.
- **Performance:** Efficient for large meshes due to batching and GPU acceleration. Performance scales linearly with the number of cameras.
- **Strengths:** Effective at removing occluded geometry and artifacts in unbounded reconstructions. Robust to sparse views.
- **Limitations:** Requires accurate camera poses and depth maps. Computationally expensive for very large numbers of cameras.
- **When to Use:** Suitable for unbounded Gaussian splatting reconstructions where voxel-based culling is not feasible.
- **When Not to Use:** Not ideal for bounded scenes with dense voxel grids, where neighbor-based culling is more efficient.

## Background
Originated in the context of 2D Gaussian Splatting for geometrically accurate radiance fields [S1, unofficial]. The method was developed to address artifacts in unbounded mesh extraction from Gaussian splats, where traditional voxel-based methods struggle with large, sparse scenes. It leverages multi-view consistency to identify and remove invisible geometry, improving the quality of reconstructed meshes.
