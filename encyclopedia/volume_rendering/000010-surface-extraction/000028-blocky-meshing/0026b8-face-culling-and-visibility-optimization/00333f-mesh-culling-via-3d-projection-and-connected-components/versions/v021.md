# Mesh Culling via 3D Projection and Connected Components

Also called: Mesh Culling via Multi-View Depth Projection, cull with 3d projection

## Overview
This method culls mesh geometry by projecting vertices into multiple camera views and comparing their depths against reference depth maps to identify and remove artifacts, particularly those arising from unbounded reconstructions like Gaussian Splatting [S1, unofficial]. It distinguishes itself from parent blocky culling methods by operating on arbitrary triangle meshes rather than voxel grids, using multi-view consistency to filter unseen or forecast geometry [S1, unofficial].

## How it works
**Inputs:**
- A triangle mesh $M$ with vertices $V$ and faces $F$.
- A list of camera poses $C = \{c_2w_i\}$ and intrinsic parameters $K_i$ (focal lengths $f_x, f_y$, principal point $c_x, c_y$, image dimensions $H, W$).
- Reference depth maps $D_i$ for each camera pose, typically extracted from the source data or a preliminary render.
- Parameters: `points_batch_size` (default $5 \times 10^5$), `eps` (default $0.005$), `remove_small_geometry_threshold` (default $0.2$), `forecast_radius` (default $0$, optional).

**Outputs:**
- A culled mesh $M'$ with reduced face count and cleaned topology.

**Data Structures:**
- `valid`: Boolean tensor of shape $(N_{pts})$, indicating if a point is "seen" (visible in $\ge 20$ cameras).
- `valid_forecast`: Boolean tensor of shape $(N_{pts})$, indicating if a point is in the "forecast" zone (within expanded frustum).
- `face_mask`: Boolean array of shape $(N_{faces})$, true if all vertices of the face are valid.

**Steps:**

1. **Initialize Masks:**
   Create zero tensors `valid`, `valid_num`, and `valid_forecast` of shape $(N_{vertices})$ on the target device (e.g., GPU).

2. **Iterate Camera Poses:**
   For each camera pose $c_2w$ and reference depth $D$:
   
   a. **Coordinate Transformation:**
      Negate the $y$ and $z$ rows of the rotation matrix in $c_2w$ to align with the expected coordinate system:
      $$ c_2w[:3, 1:3] *= -1 $$
      Compute the world-to-camera matrix:
      $$ w2c = c_2w^{-1} $$

   b. **Projection:**
      Convert vertices $V$ to homogeneous coordinates by appending ones. Transform to camera space:
      $$ P_{cam} = w2c \cdot V_{homog} $$
      Extract the first three rows to get $(x, y, z)$. Apply intrinsic matrix $K$:
      $$ uv = K \cdot P_{cam} $$
      Extract depth $z = uv[:, 2]$ and compute normalized UV coordinates:
      $$ u = uv[:, 0] / z, \quad v = uv[:, 1] / z $$
      Add epsilon to depth to avoid division by zero: $z \leftarrow z + 10^{-8}$.

   c. **Frustum and Forecast Checks:**
      Check if points are within the standard frustum:
      $$ \text{in\_frustum} = (u \ge 0) \land (u \le W-1) \land (v \ge 0) \land (v \le H-1) \land (z > 0) $$
      If `forecast_radius` $r > 0$, check the expanded forecast frustum:
      $$ \text{forecast\_frustum} = (u \ge -r) \land (u \le W-1+r) \land (v \ge -r) \land (v \le H-1+r) \land (z > 0) $$

   d. **Depth Sampling:**
      Reshape reference depth $D$ to $(1, 1, H, W)$. Normalize UV grid to $[-1, 1]$ for bilinear interpolation. Sample depth at $(u, v)$:
      $$ D_{sample} = \text{GridSample}(D, (u, v), \text{padding\_mode='border'}) $$
      Validate front-facing geometry:
      $$ \text{is\_front\_face} = (D_{sample} > 0.0) \land (z < D_{sample} + \text{eps}) $$

   e. **Update Masks:**
      If `in_frustum` and `is_front_face` are true, increment `valid_num` and set `valid` to true for the corresponding vertices.
      If `forecast_frustum` is true, set `valid_forecast` to true.

3. **Finalize Point Visibility:**
   A point is considered "seen" if it is valid in at least 20 cameras:
   $$ \text{FinalValid} = \text{valid\_num} \ge 20 $$

4. **Face Masking:**
   Create a face mask by checking if all vertices of each face are in `FinalValid`:
   $$ \text{face\_mask} = \text{FinalValid}[M.Faces].\text{all}(\text{axis}=1) $$
   Apply the mask to the mesh and remove unreferenced vertices.

5. **Optional Connected Component Culling (Forecast):**
   If `forecast_radius` > 0:
   a. Create a `forecast_mask` from `valid_forecast`.
   b. Compute the Oriented Bounding Box (OBB) of the currently kept mesh vertices.
   c. Keep only forecast faces that lie within this OBB.
   d. Filter remaining components by area: keep components where area $> \text{remove\_small\_geometry\_threshold} \times \text{global\_area}$, or keep only the largest component if `get_largest_components` is true.

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def cull_mesh_by_projection(mesh, cameras, depth_maps, params):
    """
    mesh: trimesh object with vertices (N, 3) and faces (M, 3)
    cameras: list of dicts with 'c2w' (4,4), 'K' (3,3), 'H', 'W'
    depth_maps: list of tensors (H, W)
    params: dict with 'eps', 'batch_size', 'forecast_radius', 'threshold'
    """
    vertices = mesh.vertices
    faces = mesh.faces
    N = vertices.shape[0]
    
    # Initialize masks
    valid = torch.zeros(N, dtype=torch.bool, device=vertices.device)
    valid_num = torch.zeros(N, dtype=torch.int, device=vertices.device)
    valid_forecast = torch.zeros(N, dtype=torch.bool, device=vertices.device)
    
    eps = params.get('eps', 0.005)
    forecast_radius = params.get('forecast_radius', 0)
    
    # Process in batches to limit memory
    batch_size = params.get('points_batch_size', 500000)
    num_batches = (N + batch_size - 1) // batch_size
    
    for b in range(num_batches):
        start = b * batch_size
        end = min((b + 1) * batch_size, N)
        batch_verts = vertices[start:end]
        
        for i, cam in enumerate(cameras):
            c2w = cam['c2w'].clone()
            # Negate y and z rows of rotation part
            c2w[:3, 1:3] *= -1
            w2c = torch.inverse(c2w)
            
            # Project vertices
            ones = torch.ones(end - start, 1, device=vertices.device)
            verts_homog = torch.cat([batch_verts, ones], dim=1)
            cam_coords = (w2c @ verts_homog.T).T[:, :3]
            
            # Apply intrinsics
            K = cam['K']
            uv = (K @ cam_coords.T).T
            z = uv[:, 2] + 1e-8
            u = uv[:, 0] / z
            v = uv[:, 1] / z
            
            H, W = cam['H'], cam['W']
            
            # Frustum checks
            in_frustum = (u >= 0) & (u <= W-1) & (v >= 0) & (v <= H-1) & (z > 0)
            
            forecast_frustum = torch.zeros_like(in_frustum)
            if forecast_radius > 0:
                r = forecast_radius
                forecast_frustum = (u >= -r) & (u <= W-1+r) & (v >= -r) & (v <= H-1+r) & (z > 0)
            
            # Sample depth
            depth_map = depth_maps[i].unsqueeze(0).unsqueeze(0).to(vertices.device) # (1, 1, H, W)
            # Normalize UV to [-1, 1]
            u_norm = 2.0 * u / (W - 1) - 1.0
            v_norm = 2.0 * v / (H - 1) - 1.0
            grid = torch.stack([u_norm, v_norm], dim=-1).unsqueeze(0) # (1, 1, batch, 2)
            
            depth_sample = F.grid_sample(depth_map, grid, align_corners=True, padding_mode='border')
            depth_sample = depth_sample.squeeze().squeeze() # (batch,)
            
            # Front face check
            is_front = (depth_sample > 0.0) & (z < depth_sample + eps)
            
            # Update masks
            mask = in_frustum & is_front
            valid_num[start:end] += mask.int()
            valid[start:end] = valid[start:end] | mask
            
            if forecast_radius > 0:
                valid_forecast[start:end] = valid_forecast[start:end] | forecast_frustum
        
        # Update global valid based on count threshold (20 cameras)
        # Note: In a real implementation, this check might be done after all cameras
        # or incrementally. Here we assume final check after loop.
        
    # Finalize seen mask
    final_valid = valid_num >= 20
    
    # Face mask: all vertices must be valid
    face_mask = final_valid[faces].all(dim=1)
    
    # Apply face mask
    new_faces = faces[face_mask]
    
    # Remove unreferenced vertices
    unique_verts = torch.unique(new_faces.flatten())
    vertex_map = torch.full((N,), -1, dtype=torch.long, device=vertices.device)
    vertex_map[unique_verts] = torch.arange(len(unique_verts), device=vertices.device)
    new_vertices = vertices[unique_verts]
    final_faces = vertex_map[new_faces]
    
    # Optional: Connected Component / Forecast Culling
    if forecast_radius > 0:
        # This part requires graph operations or bounding box checks
        # Simplified: Keep only faces where vertices are in valid_forecast OR final_valid
        # And filter by area if needed.
        pass
        
    return trimesh.Trimesh(vertices=new_vertices, faces=final_faces)
```

## Subtopics

### [Mesh Post-Processing (Cluster Filtering)](7002-mesh-post-processing-cluster-filtering.md)
Filters floating artifacts and disconnected components by clustering triangles and retaining only the largest connected clusters. Used as a cleanup step after this method to remove small, noisy geometry that survives projection-based culling.

## Operating characteristics
- **Time Complexity:** $O(N \cdot C \cdot B)$, where $N$ is the number of vertices, $C$ is the number of cameras, and $B$ is the batch size factor for memory management. Depth sampling is $O(1)$ per point.
- **Memory Complexity:** $O(N + H \cdot W \cdot C)$ for storing masks and depth maps.
- **Strengths:** Effective at removing background noise and unbounded artifacts in Gaussian Splatting reconstructions. Robust to complex geometry as it relies on multi-view consistency.
- **Limitations:** Requires accurate camera poses and depth maps. Computationally expensive for large meshes and many cameras. Sensitive to the threshold of 20 cameras; too high may remove valid geometry, too low may retain noise.
- **When to use:** When extracting meshes from unbounded radiance fields (e.g., 2D Gaussian Splatting) where background artifacts are prevalent.
- **When not to use:** For bounded, well-defined voxel grids where simpler face culling is sufficient.

## Background
This method was introduced in the context of "2D Gaussian Splatting for Geometrically Accurate Radiance Fields" (Huang et al., SIGGRAPH 2024) [S1, unofficial]. It addresses the challenge of extracting clean, bounded meshes from unbounded 3D Gaussian Splatting reconstructions, which often contain floating artifacts and background noise. The method leverages multi-view depth consistency to distinguish between valid surface geometry and spurious projections.
