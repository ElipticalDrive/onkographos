# Mesh Culling via 3D Projection and Connected Components

Also called: Mesh Culling via Multi-View Depth Projection, cull with 3d projection

## Overview
This method culls mesh geometry by projecting vertices into multiple camera views and comparing their depths against reference depth maps to identify and remove unseen or forecast geometry [S1, unofficial]. It is specifically designed to clean up artifacts from unbounded Gaussian splatting reconstruction by classifying points as seen, unseen, or forecast [S1, unofficial]. Unlike sibling methods that rely on topological connectivity or face coverage masks, this approach uses multi-view geometric consistency to filter out noise and distant fragments [S1, unofficial].

## How it works
**Inputs:**
- A triangular mesh $M$ with vertices $V$ and faces $F$.
- A list of camera poses $C = \{c_2w_i\}$ and intrinsic parameters $K_i = \{f_x, f_y, c_x, c_y, H, W\}$ for $N$ views.
- Reference depth maps $D_i$ for each camera pose, typically extracted from the mesh or ground truth.
- Parameters: `points_batch_size` (default $5 \times 10^5$), `eps` (default $0.005$), `remove_small_geometry_threshold` (default $0.2$), `forecast_radius` (default $0$).

**Outputs:**
- A culled mesh $M'$ with removed faces and unreferenced vertices.

**Data Structures:**
- `valid`: Boolean tensor of shape $(N_{pts})$, marking vertices seen in $\ge 20$ cameras.
- `valid_forecast`: Boolean tensor of shape $(N_{pts})$, marking vertices in the forecast frustum.
- `face_mask`: Boolean array of shape $(N_{faces})$, true if all vertices of a face are valid.

**Steps:**

1. **Initialize Masks:**
   Create `valid`, `valid_num`, and `valid_forecast` as zero tensors on the target device with length equal to the number of mesh vertices $N_{pts}$ [S1, unofficial].

2. **Iterate Over Cameras:**
   For each camera pose $c_2w$ and intrinsic $K$:
   
   a. **Coordinate Transformation:**
      Negate the $y$ and $z$ rows of the rotation matrix in $c_2w$ to align with the expected coordinate system:
      $$ c_2w[:3, 1:3] *= -1 $$
      Compute the world-to-camera matrix:
      $$ w2c = c_2w^{-1} $$
      [S1, unofficial]

   b. **Project Vertices:**
      For a batch of vertices $P \in \mathbb{R}^{B \times 3}$:
      - Convert to homogeneous coordinates: $P_h = [P, 1]^T$.
      - Transform to camera space: $P_c = w2c \cdot P_h$.
      - Extract the first three rows to get $(x_c, y_c, z_c)$.
      - Apply intrinsic matrix $K$:
        $$ u = f_x \frac{x_c}{z_c} + c_x $$
        $$ v = f_y \frac{y_c}{z_c} + c_y $$
        $$ z = z_c + 10^{-8} $$
      [S1, unofficial]

   c. **Frustum and Forecast Checks:**
      - **Standard Frustum:**
        $$ \text{in\_frustum} = (0 \le u < W) \land (0 \le v < H) \land (z > 0) $$
      - **Forecast Frustum** (if `forecast_radius` $r > 0$):
        $$ \text{forecast\_frustum} = (-r \le u < W+r) \land (-r \le v < H+r) \land (z > 0) $$
      [S1, unofficial]

   d. **Depth Sampling:**
      - Reshape reference depth $D$ to $(1, 1, H, W)$.
      - Normalize UV grid to $[-1, 1]$ for bilinear interpolation.
      - Sample depth at $(u, v)$:
        $$ d_{sample} = \text{grid\_sample}(D, (u, v), \text{padding\_mode='border'}) $$
      [S1, unofficial]

   e. **Front-Face Validation:**
      Check if the vertex is in front of the reference surface:
      $$ \text{is\_front\_face} = (d_{sample} > 0) \land (z < d_{sample} + \text{eps}) $$
      [S1, unofficial]

   f. **Update Masks:**
      - If `in_frustum` and `is_front_face`, increment `valid_num` and set `valid` to true for the batch vertices.
      - If `forecast_frustum`, set `valid_forecast` to true for the batch vertices.
      [S1, unofficial]

3. **Finalize Vertex Visibility:**
   A vertex is considered "seen" if it is valid in at least 20 cameras:
   $$ \text{final\_valid} = (\text{valid\_num} \ge 20) $$
   [S1, unofficial]

4. **Face Culling:**
   - Create a face mask where a face is kept if all its vertices are in `final_valid`:
     $$ \text{face\_mask} = \text{final\_valid}[M.faces].\text{all}(\text{axis}=1) $$
   - Update the mesh with `face_mask`.
   - Remove unreferenced vertices.
   [S1, unofficial]

5. **Connected Components Culling (Optional):**
   If `forecast_radius > 0`:
   - Create a `forecast_mask` from `valid_forecast`.
   - Compute the Oriented Bounding Box (OBB) of the cull mesh vertices.
   - Keep only forecast faces within this OBB.
   - Filter mesh components by area: keep components where area $> \text{remove\_small\_geometry\_threshold} \times \text{global\_area}$, or keep only the largest component if `get_largest_components` is True.
   [S1, unofficial]

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def cull_mesh_by_projection(mesh, cameras, depth_maps, params):
    """
    mesh: trimesh.Trimesh object with vertices and faces
    cameras: list of dicts with 'c2w', 'fx', 'fy', 'cx', 'cy', 'H', 'W'
    depth_maps: list of torch tensors (H, W)
    params: dict with 'eps', 'min_views', 'forecast_radius', 'small_geom_thresh'
    """
    vertices = torch.tensor(mesh.vertices, dtype=torch.float32, device='cuda')
    faces = torch.tensor(mesh.faces, dtype=torch.long, device='cuda')
    n_verts = vertices.shape[0]
    
    # Initialize masks
    valid_num = torch.zeros(n_verts, dtype=torch.int32, device='cuda')
    valid = torch.zeros(n_verts, dtype=torch.bool, device='cuda')
    valid_forecast = torch.zeros(n_verts, dtype=torch.bool, device='cuda')
    
    batch_size = params.get('points_batch_size', 500000)
    eps = params.get('eps', 0.005)
    min_views = params.get('min_views', 20)
    r = params.get('forecast_radius', 0)
    
    # Process vertices in batches to limit memory
    for start in range(0, n_verts, batch_size):
        end = min(start + batch_size, n_verts)
        batch_verts = vertices[start:end]
        
        # Initialize batch masks
        batch_valid_num = torch.zeros(end - start, dtype=torch.int32, device='cuda')
        batch_valid = torch.zeros(end - start, dtype=torch.bool, device='cuda')
        batch_valid_forecast = torch.zeros(end - start, dtype=torch.bool, device='cuda')
        
        for i, cam in enumerate(cameras):
            c2w = torch.tensor(cam['c2w'], dtype=torch.float32, device='cuda')
            # Negate y and z rows of rotation part
            c2w[:3, 1:3] *= -1
            w2c = torch.inverse(c2w)
            
            # Project to camera space
            ones = torch.ones(end - start, 1, device='cuda')
            verts_homo = torch.cat([batch_verts, ones], dim=1) # (B, 4)
            verts_cam = (w2c @ verts_homo.t()).t() # (B, 4)
            x_c, y_c, z_c = verts_cam[:, 0], verts_cam[:, 1], verts_cam[:, 2]
            
            # Intrinsic projection
            fx, fy, cx, cy = cam['fx'], cam['fy'], cam['cx'], cam['cy']
            H, W = cam['H'], cam['W']
            
            z = z_c + 1e-8
            u = fx * (x_c / z) + cx
            v = fy * (y_c / z) + cy
            
            # Frustum checks
            in_frustum = (u >= 0) & (u < W) & (v >= 0) & (v < H) & (z > 0)
            
            forecast_frustum = torch.zeros_like(in_frustum)
            if r > 0:
                forecast_frustum = (u >= -r) & (u < W + r) & (v >= -r) & (v < H + r) & (z > 0)
            
            # Depth sampling
            depth_map = depth_maps[i].unsqueeze(0).unsqueeze(0) # (1, 1, H, W)
            # Normalize UV to [-1, 1]
            u_norm = 2.0 * (u / (W - 1)) - 1.0
            v_norm = 2.0 * (v / (H - 1)) - 1.0
            grid = torch.stack([u_norm, v_norm], dim=-1).unsqueeze(0).unsqueeze(0) # (1, 1, B, 2)
            
            depth_sample = F.grid_sample(depth_map, grid, padding_mode='border', align_corners=True)
            depth_sample = depth_sample.squeeze() # (B,)
            
            # Front-face check
            is_front = (depth_sample > 0.0) & (z_c < depth_sample + eps)
            
            # Update masks
            visible = in_frustum & is_front
            batch_valid_num = batch_valid_num + visible.int()
            batch_valid = batch_valid | visible
            
            if r > 0:
                batch_valid_forecast = batch_valid_forecast | forecast_frustum
        
        # Finalize batch visibility
        batch_final_valid = batch_valid_num >= min_views
        
        # Write back to global masks
        valid[start:end] = batch_final_valid
        valid_forecast[start:end] = batch_valid_forecast
    
    # Face culling
    face_mask = valid[faces].all(dim=1)
    
    # Update mesh
    mesh.update_faces(face_mask)
    mesh.remove_unreferenced_vertices()
    
    # Optional connected components culling
    if r > 0:

    return mesh
```

## Subtopics

### [Mesh Post-Processing (Cluster Filtering)](7002-mesh-post-processing-cluster-filtering.md)
Filters floating artifacts and disconnected components by clustering triangles and retaining only the largest connected clusters. It serves as a cleanup step following this method, targeting small, noisy geometry that survives projection-based culling. Unlike this method which removes occluded or distant geometry, it removes topologically isolated fragments based on triangle count.

## Operating characteristics
- **Time Complexity:** $O(N \cdot V \cdot B)$, where $N$ is the number of cameras, $V$ is the number of vertices, and $B$ is the batch size factor for projection and sampling. Depth sampling is $O(1)$ per vertex per camera using bilinear interpolation.
- **Memory Complexity:** $O(V + N \cdot H \cdot W)$ for storing vertex masks and depth maps. Batch processing limits peak memory to $O(B + N \cdot H \cdot W)$.
- **Performance:** Efficient for large meshes due to batched processing and GPU acceleration. The requirement of $\ge 20$ views ensures robustness against noise but increases computation time linearly with the number of cameras.
- **Strengths:** Effective at removing unbounded artifacts and distant noise from Gaussian splatting reconstructions. Geometrically accurate as it relies on depth consistency.
- **Limitations:** Requires pre-computed or rendered depth maps for all camera poses. Sensitive to depth map accuracy and camera calibration. May remove valid geometry if the camera coverage is insufficient or depth maps are noisy.
- **When to use:** When cleaning up meshes from unbounded Gaussian splatting or similar reconstruction methods where multi-view depth information is available.
- **When not to use:** When depth maps are unavailable or unreliable. When real-time performance is critical and the number of cameras is very large.

## Background
This method was introduced in the context of "2D Gaussian Splatting for Geometrically Accurate Radiance Fields" by Huang et al. (SIGGRAPH 2024) [S1, unofficial]. It addresses the challenge of extracting clean, bounded meshes from unbounded Gaussian splatting reconstructions, which often contain artifacts and noise in unobserved regions. The method leverages multi-view depth consistency to distinguish between visible surface geometry and background noise [S1, unofficial].
