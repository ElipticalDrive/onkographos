# Mesh Culling via 3D Projection and Connected Components

Also called: Mesh Culling via Multi-View Depth Projection, cull with 3d projection

## Overview
This method culls mesh geometry by projecting vertices into multiple camera views and comparing their depths against reference depth maps to identify and remove unseen or forecast geometry [S1, unofficial]. It distinguishes itself from neighbor-based face culling [Face Culling and Visibility Optimization](3861-face-culling-and-visibility-optimization.md) by relying on global visibility from arbitrary viewpoints rather than local voxel adjacency, making it suitable for removing artifacts from unbounded reconstructions [S1, unofficial].

## How it works
**Inputs**: A triangle mesh, a list of camera poses (world-to-camera or camera-to-world matrices), camera intrinsic parameters ($f_x, f_y, c_x, c_y$), image resolution ($H, W$), and optional parameters for forecast radius and cluster filtering.
**Outputs**: A culled mesh with unreferenced vertices removed.

**Data Structures**:
- `mesh`: Triangle mesh with vertices $V \in \mathbb{R}^{N \times 3}$ and faces $F \in \mathbb{R}^{M \times 3}$ (indices into $V$).
- `depth_list`: List of reference depth maps, one per camera pose, shape $(H, W)$.
- `estimate_c2w_list`: List of camera-to-world transformation matrices, shape $(4, 4)$ per camera.
- `valid`, `valid_num`, `valid_forecast`: Boolean/int tensors of shape $(N,)$ tracking vertex visibility.

**Parameters**:
- `points_batch_size`: Max points processed per batch to limit GPU memory. Default: $5 \times 10^5$ [S1, unofficial].
- `remove_small_geometry_threshold`: Minimum face area ratio to keep a component. Default: $0.2$ [S1, unofficial].
- `eps`: Depth comparison tolerance. Default: $0.005$ [S1, unofficial].
- `forecast_radius`: Radius for expanding frustum bounds for forecast culling. Default: Not specified in sources, but used if $>0$ [S1, unofficial].

**Steps**:

1. **Initialize Masks**: Create tensors `valid`, `valid_num`, `valid_forecast` of shape $(N,)$ initialized to zero/false on the target device [S1, unofficial].

2. **Iterate Cameras**: For each camera pose $c2w$ in `estimate_c2w_list`:
    a. **Coordinate System Adjustment**: Negate the $y$ and $z$ rows of the rotation part of $c2w$ to match the expected coordinate system:
       $$ c2w_{adj} = c2w $$
       $$ c2w_{adj}[1, 1:3] *= -1 $$
       $$ c2w_{adj}[2, 1:3] *= -1 $$
    b. **World-to-Camera Matrix**: Compute $w2c = c2w_{adj}^{-1}$ [S1, unofficial].
    c. **Project Vertices**:
       - Convert vertices $V$ to homogeneous coordinates: $V_h = [V, \mathbf{1}]^T \in \mathbb{R}^{4 \times N}$ (assuming $V$ is $N \times 3$).
       - Transform to camera space: $P_{cam} = w2c \cdot V_h$.
       - Extract first three rows: $P_{cam} = [x_c, y_c, z_c, w_c]^T$. Note: In standard projection, $w_c$ is usually 1 if $w2c$ is affine, but here we extract the first three rows of the result of multiplying $w2c$ (4x4) by $V_h$ (4xN). The result is 4xN. Let $P_{proj} = P_{cam}[0:3, :]$ [S1, unofficial].
    d. **Intrinsic Projection**:
       - Apply intrinsic matrix $K = \begin{bmatrix} f_x & 0 & c_x \\ 0 & f_y & c_y \\ 0 & 0 & 1 \end{bmatrix}$.
       - $uv = K \cdot P_{proj}$.
       - Extract depth $z = uv[2, :] + 10^{-8}$ and normalized UV: $u = uv[0, :] / z$, $v = uv[1, :] / z$ [S1, unofficial].
    e. **Frustum Check**:
       - **Seen Frustum**: $in\_frustum = (u \ge 0) \land (u \le W-1) \land (v \ge 0) \land (v \le H-1) \land (z > 0)$ [S1, unofficial].
       - **Forecast Frustum** (if `forecast_radius` $r > 0$): $forecast\_frustum = (u \ge -r) \land (u \le W-1+r) \land (v \ge -r) \land (v \le H-1+r) \land (z > 0)$ [S1, unofficial].
    f. **Depth Sampling**:
       - Reshape reference depth map $D$ to $(1, 1, H, W)$.
       - Normalize UV grid to $[-1, 1]$ for sampling: $vgrid = 2 \cdot [u, v]^T - 1$ (shape $(2, N)$).
       - Sample depth using bilinear interpolation with border padding: $depth\_sample = \text{grid\_sample}(D, vgrid, \text{padding\_mode='border'}, \text{align\_corners=True})$. Shape $(1, 1, N)$ [S1, unofficial].
       - Extract scalar depth: $d_{sample} = depth\_sample[0, 0, :]$ [S1, unofficial].
    g. **Front-Face Validation**:
       - $is\_front\_face = (d_{sample} > 0.0) \land (z < d_{sample} + \epsilon)$ [S1, unofficial].
    h. **Update Masks**:
       - For vertices in $in\_frustum$ and $is\_front\_face$: increment `valid_num` and set `valid` to True [S1, unofficial].
       - For vertices in $forecast\_frustum$ and $is\_front\_face$: set `valid_forecast` to True [S1, unofficial].

3. **Finalize Vertex Masks**:
   - A vertex is considered "seen" if `valid_num` $\ge 20$ (requires projection into at least 20 cameras) [S1, unofficial].
   - Create `seen_mask` from `valid` and `valid_num`.
   - Create `forecast_mask` from `valid_forecast` [S1, unofficial].

4. **Face Masking**:
   - A face is visible if all its vertices are visible:
     $$ face\_mask = seen\_mask[mesh.faces].all(axis=1) $$
   - Update mesh: `mesh_with_hole.update_faces(face_mask)` [S1, unofficial].
   - Remove unreferenced vertices: `mesh_with_hole.remove_unreferenced_vertices()` [S1, unofficial].

5. **Forecast Culling (Optional)**:
   - If `forecast_radius` $> 0$:
     - Create a forecast mesh from `forecast_mask`.
     - Compute Oriented Bounding Box (OBB) of the cull mesh's vertices [S1, unofficial].
     - Keep only forecast faces within this OBB [S1, unofficial].

6. **Connected Component Filtering**:
   - Identify connected triangle clusters using `cluster_connected_triangles()` [S1, unofficial].
   - Sort clusters by number of triangles.
   - Select threshold: $N$-th largest cluster size (where $N$ is `cluster_to_keep`) or enforce `min_cluster_size` [S1, unofficial].
   - Remove triangles in clusters smaller than threshold.
   - Remove unreferenced vertices and degenerate triangles [S1, unofficial].

    """
    Cull mesh geometry based on multi-view depth projection and connected components.
    
    Args:

        c2w_list: List of camera-to-world matrices (4,4)

    Returns:
        Culled mesh
    """
    V = mesh.vertices # (N, 3)
    N = V.shape[0]
    
    # Initialize masks
    valid = torch.zeros(N, dtype=torch.bool, device=V.device)
    valid_num = torch.zeros(N, dtype=torch.int, device=V.device)
    valid_forecast = torch.zeros(N, dtype=torch.bool, device=V.device)
    
    # Process each camera
    for c2w in c2w_list:
        # Adjust coordinate system
        c2w_adj = c2w.clone()
        c2w_adj[1, 1:3] *= -1
        c2w_adj[2, 1:3] *= -1
        
        # World-to-Camera
        w2c = torch.inverse(c2w_adj)
        
        # Project vertices
        V_h = torch.cat([V, torch.ones(N, 1, device=V.device)], dim=1) # (N, 4)
        P_cam = (w2c @ V_h.T).T # (N, 4)
        x_c, y_c, z_c, _ = P_cam[:, 0], P_cam[:, 1], P_cam[:, 2], P_cam[:, 3]
        
        # Intrinsic projection
        # uv = K @ [x_c, y_c, z_c]^T
        uv_x = K[0,0]*x_c + K[0,1]*y_c + K[0,2]*z_c
        uv_y = K[1,0]*x_c + K[1,1]*y_c + K[1,2]*z_c
        uv_z = K[2,0]*x_c + K[2,1]*y_c + K[2,2]*z_c + 1e-8
        
        u = uv_x / uv_z
        v = uv_y / uv_z
        z = uv_z
        
        # Frustum checks
        in_frustum = (u >= 0) & (u <= W-1) & (v >= 0) & (v <= H-1) & (z > 0)
        
        if forecast_radius > 0:
            r = forecast_radius

        else:

        # Depth sampling

        vgrid = torch.stack([vgrid_u, vgrid_v], dim=0).unsqueeze(0).unsqueeze(0) # (1, 2, 1, N)

        # Front-face validation

        # Update masks
        seen_mask = in_frustum & is_front_face
        forecast_mask = forecast_frustum & is_front_face
        
        valid_num += seen_mask.int()
        valid |= seen_mask
        valid_forecast |= forecast_mask

    # Face masking

    # Update mesh

    cull_mesh.update_faces(face_visible)
    cull_mesh.remove_unreferenced_vertices()
    
    # Forecast culling

        forecast_mesh = mesh.copy()
        forecast_mesh.update_faces(forecast_face_visible)

## Subtopics

### Mesh Post-Processing (Cluster Filtering)
This variant focuses on removing small, disconnected noise components from the mesh after the initial projection culling. It identifies connected triangle clusters, sorts them by size, and removes those smaller than a threshold determined by the $N$-th largest cluster or a minimum triangle count. It is chosen when the mesh contains significant floating noise or artifacts that are not removed by depth projection alone. It differs from the main method by operating on the topological connectivity of the mesh rather than geometric visibility [S1, unofficial].

## Operating characteristics
- **Time Complexity**: $O(C \cdot N)$ for projection, where $C$ is the number of cameras and $N$ is the number of vertices. Connected component analysis is roughly $O(M)$ where $M$ is the number of faces.
- **Memory Complexity**: $O(N)$ for vertex masks, $O(H \cdot W)$ for depth maps.
- **Measured Performance**: Not given in the sources.
- **Scaling**: Scales linearly with the number of cameras and vertices. Batch processing (`points_batch_size`) helps manage GPU memory.
- **Strengths**: Effective at removing unseen geometry and artifacts from unbounded reconstructions. Robust to local occlusions.
- **Limitations**: Requires multiple camera views. Computationally expensive for large meshes and many cameras. Dependent on accurate depth maps and camera poses.
- **When to use**: When extracting meshes from unbounded radiance fields (e.g., Gaussian Splatting) where local face culling is insufficient.
- **When not to use**: For bounded voxel grids where neighbor-based culling is sufficient and faster.

## Background
This method originates from the "2D Gaussian Splatting for Geometrically Accurate Radiance Fields" paper by Huang et al. (SIGGRAPH 2024) [S1, unofficial]. It was developed to address the challenge of extracting clean, geometrically accurate meshes from unbounded 2D Gaussian Splatting reconstructions, which often contain artifacts and unseen geometry. The method leverages multi-view consistency to filter out these artifacts.
