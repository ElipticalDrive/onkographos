# Mesh Culling via 3D Projection and Connected Components

Also called: Mesh Culling via Multi-View Depth Projection, cull with 3d projection

## Overview
This method culls mesh geometry by projecting vertices into multiple camera views and comparing their depths against reference depth maps to identify and remove artifacts from unbounded reconstructions, such as those from Gaussian Splatting [S1, unofficial]. It classifies points as "seen," "unseen," or "forecast" based on multi-view consistency, then filters faces and connected components to retain only geometrically valid structures [S1, unofficial]. It differs from sibling methods like [Face Culling](8735-face-culling.md) by relying on external camera poses and depth rendering rather than local voxel adjacency or simple backface normals.

## How it works
**Inputs:**
- A mesh (vertices $V$, faces $F$).
- A list of camera poses (extrinsics $C_{2W}$) and intrinsic parameters ($K$: $f_x, f_y, c_x, c_y$, resolution $H, W$).
- Reference depth maps $D$ for each camera pose, rendered from the mesh or ground truth.
- Parameters: `points_batch_size` (default $5 \times 10^5$), `eps` (default $0.005$), `remove_small_geometry_threshold` (default $0.2$), `forecast_radius` (default $0$, optional), `cluster_to_keep` (default $1000$), `min_cluster_size` (default $50$).

**Outputs:**
- A culled mesh containing only visible, geometrically consistent faces and vertices.

**Data Structures:**
- `valid`: Boolean tensor of shape $(N_{pts})$, true if point is seen in $\ge 20$ cameras.
- `valid_forecast`: Boolean tensor of shape $(N_{pts})$, true if point is in forecast frustum and front-facing.
- `face_mask`: Boolean array of shape $(N_{faces})$, true if all vertices of the face are valid.

**Steps:**

1. **Initialize Masks:** Create `valid`, `valid_num`, and `valid_forecast` tensors of zeros with length equal to the number of mesh vertices, on the target device.

2. **Iterate Cameras:** For each camera pose $c2w$ and its corresponding depth map $D$:
    a. **Coordinate Transform:** Negate the $y$ and $z$ rows of the rotation matrix in $c2w$ to match the expected coordinate system:
       $$ c2w[:3, 1:3] *= -1 $$
    b. **World-to-Camera:** Compute $w2c = c2w^{-1}$.
    c. **Project Vertices:** For a batch of vertices $P_{world}$:
       i. Convert to homogeneous coordinates: $P_{hom} = [P_{world}, 1]$.
       ii. Transform to camera space: $P_{cam} = w2c \cdot P_{hom}$.
       iii. Extract first three rows: $uvz = P_{cam}[:3]$.
       iv. Compute depth $z = uvz[:, 2] + 10^{-8}$.
       v. Compute normalized UV: $u = uvz[:, 0] / z$, $v = uvz[:, 1] / z$.
    d. **Frustum Check:**
       i. Standard frustum: $in\_frustum = (0 \le u < W) \land (0 \le v < H) \land (z > 0)$.
       ii. Forecast frustum (if `forecast_radius` $r > 0$): $forecast\_frustum = (-r \le u < W+r) \land (-r \le v < H+r) \land (z > 0)$.
    e. **Depth Sampling:**
       i. Reshape $D$ to $(1, 1, H, W)$.
       ii. Normalize UV grid to $[-1, 1]$ for sampling.
       iii. Sample depth at $(u, v)$ using bilinear interpolation with border padding: $d_{sample} = \text{grid\_sample}(D, (u, v), \text{padding\_mode='border'})$.
    f. **Front-Face Validation:**
       $$ is\_front = (d_{sample} > 0) \land (z < d_{sample} + \epsilon) $$
    g. **Update Masks:**
       i. If $in\_frustum$ and $is\_front$: increment `valid_num` and set `valid` bit.
       ii. If $forecast\_frustum$ and $is\_front$: set `valid_forecast` bit.

3. **Finalize Point Visibility:**
   $$ valid = valid\_num \ge 20 $$
   This requires the point to be front-facing and within the frustum of at least 20 cameras.

4. **Face Culling:**
   a. Create `face_mask` where a face is kept if all its vertices are in `valid`:
      $$ face\_mask = valid[mesh.faces].all(axis=1) $$
   b. Apply mask to mesh: `mesh.update_faces(face_mask)`.
   c. Remove unreferenced vertices: `mesh.remove_unreferenced_vertices()`.

5. **Forecast Culling (Optional):**
   If `forecast_radius` $> 0$:
   a. Create a forecast mesh from faces where vertices are in `valid_forecast`.
   b. Compute the Oriented Bounding Box (OBB) of the cull mesh vertices.
   c. Keep only forecast faces within this OBB.

6. **Connected Component Filtering (Cluster Filtering):**
   a. Identify connected triangle clusters using `cluster_connected_triangles()`.
   b. Sort clusters by triangle count. Select the $N$-th largest value (where $N = \text{cluster\_to\_keep}$) as the threshold.
   c. Remove triangles belonging to clusters smaller than the threshold or smaller than `min_cluster_size`.
   d. Remove unreferenced vertices and degenerate triangles.

7. **Area-Based Filtering (Optional):**
   Filter components by area: keep components where area $> \text{remove\_small\_geometry\_threshold} \times \text{global\_area}$, or keep only the largest component if `get_largest_components` is True.

**Pseudocode:**

```python
import torch
import numpy as np

def project_and_cull(mesh, cameras, depth_maps, eps=0.005, batch_size=500000, forecast_radius=0):
    """
    mesh: object with .vertices (N, 3) and .faces (M, 3)
    cameras: list of dicts with 'c2w' (4, 4), 'K' (3, 3), 'H', 'W'
    depth_maps: list of tensors (H, W)
    """
    n_verts = mesh.vertices.shape[0]
    valid = torch.zeros(n_verts, dtype=torch.bool, device=mesh.vertices.device)
    valid_num = torch.zeros(n_verts, dtype=torch.int, device=mesh.vertices.device)
    valid_forecast = torch.zeros(n_verts, dtype=torch.bool, device=mesh.vertices.device)
    
    vertices = mesh.vertices
    
    for i, cam in enumerate(cameras):
        c2w = cam['c2w'].clone()
        # Negate y and z rows of rotation part
        c2w[:3, 1] *= -1
        c2w[:3, 2] *= -1
        
        w2c = torch.inverse(c2w)
        K = cam['K']
        H, W = cam['H'], cam['W']
        depth = depth_maps[i]
        
        # Process in batches
        for start in range(0, n_verts, batch_size):
            end = min(start + batch_size, n_verts)
            batch_verts = vertices[start:end]
            
            # Homogeneous
            ones = torch.ones_like(batch_verts[:, :1])
            P_hom = torch.cat([batch_verts, ones], dim=1)
            
            # World to Camera
            P_cam = (w2c @ P_hom.T).T
            z = P_cam[:, 2] + 1e-8
            uv = P_cam[:, :2] / z.unsqueeze(1)
            u, v = uv[:, 0], uv[:, 1]
            
            # Frustum checks
            in_frustum = (u >= 0) & (u < W) & (v >= 0) & (v < H) & (z > 0)
            
            forecast_frustum = torch.zeros_like(in_frustum)
            if forecast_radius > 0:
                r = forecast_radius
                forecast_frustum = (u >= -r) & (u < W + r) & (v >= -r) & (v < H + r) & (z > 0)
            
            if not in_frustum.any() and not forecast_frustum.any():
                continue
                
            # Sample depth
            # Normalize UV to [-1, 1] for grid_sample
            # grid_sample expects (N, H_in, W_in, 2) with values in [-1, 1]
            # u, v are in [0, W-1], [0, H-1]
            # Map to [-1, 1]: x = 2*u/(W-1) - 1, y = 2*v/(H-1) - 1
            # Note: grid_sample y axis is inverted relative to image rows usually, 
            # but align_corners=True and border padding handles standard UV if mapped correctly.
            # Assuming standard OpenGL/DirectX projection where y is up or down consistent with depth map.
            # The source uses F.grid_sample with padding_mode='border'.
            
            u_norm = 2.0 * u / (W - 1) - 1.0
            v_norm = 2.0 * v / (H - 1) - 1.0
            
            vgrid = torch.stack([u_norm, v_norm], dim=-1).unsqueeze(1) # (B, 1, 1, 2)
            depth_reshaped = depth.unsqueeze(0).unsqueeze(0).float() # (1, 1, H, W)
            
            depth_sample = torch.nn.functional.grid_sample(
                depth_reshaped, vgrid, 
                padding_mode='border', 
                align_corners=True
            ).squeeze() # (B,)
            
            # Front face check
            is_front = (depth_sample > 0.0) & (z < depth_sample + eps)
            
            # Update valid
            valid_mask = in_frustum & is_front
            valid_num[start:end] += valid_mask.int()
            valid[start:end] |= valid_mask
            
            # Update forecast
            if forecast_radius > 0:
                forecast_mask = forecast_frustum & is_front
                valid_forecast[start:end] |= forecast_mask

    # Finalize seen mask
    valid = valid_num >= 20
    
    # Face mask
    # mesh.faces is (M, 3)
    face_mask = valid[mesh.faces].all(dim=1)
    
    # Update mesh
    mesh.faces = mesh.faces[face_mask]
    
    # Remove unreferenced vertices
    # Find unique vertices in remaining faces
    unique_verts = torch.unique(mesh.faces.flatten())
    # Create new vertex array
    new_vertices = mesh.vertices[unique_verts]
    # Remap face indices
    vert_map = torch.zeros(n_verts, dtype=torch.long, device=mesh.vertices.device)
    vert_map[unique_verts] = torch.arange(len(unique_verts), device=mesh.vertices.device)
    mesh.faces = vert_map[mesh.faces]
    mesh.vertices = new_vertices
    
    return mesh
```

## Subtopics

### Mesh Post-Processing (Cluster Filtering)
This variant focuses on removing small, disconnected geometric artifacts after the initial projection culling. It identifies connected triangle clusters and removes those below a size threshold or count limit. It is chosen when the mesh contains significant noise or floating debris that survives depth-based culling. It differs from the main method by operating on topological connectivity rather than view-dependent visibility. Parameters: `cluster_to_keep` (default 1000), `min_cluster_size` (default 50) [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N \cdot C \cdot B)$, where $N$ is the number of vertices, $C$ is the number of cameras, and $B$ is the batch size. Depth sampling is $O(1)$ per vertex per camera.
- **Memory Complexity:** $O(N + H \cdot W \cdot C)$ for storing depth maps and masks.
- **Performance:** Effective for unbounded reconstructions like Gaussian Splatting where background artifacts are common. Requires accurate camera poses and depth maps.
- **Strengths:** Robust to noise, removes non-visible geometry, handles unbounded scenes.
- **Limitations:** Requires multiple camera views, sensitive to depth map accuracy, computationally intensive for high-resolution meshes and many cameras.
- **When to use:** Post-processing meshes from neural rendering methods (e.g., 3DGS) to remove floating artifacts.
- **When not to use:** Single-view reconstruction, real-time applications with limited GPU memory.

## Background
Originated in the context of 2D Gaussian Splatting for geometrically accurate radiance fields (Huang et al., SIGGRAPH 2024) [S1, unofficial]. The method addresses the issue of unbounded TSDF fusion producing artifacts from the background or noise in the Gaussian splatting reconstruction. It leverages multi-view consistency to distinguish between valid geometry and artifacts.
