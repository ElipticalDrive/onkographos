# Mesh Culling via 3D Projection and Connected Components

Also called: Mesh Culling via Multi-View Depth Projection, cull with 3d projection

## Overview
This method reduces mesh complexity in unbounded Gaussian splatting reconstructions by classifying 3D points as seen, unseen, or forecast, and culling mesh geometry by comparing projected point depths against reference depth maps from multiple camera poses [S1, unofficial]. It sets itself apart from sibling methods like [Face Culling](8735-face-culling.md) by using multi-view consistency rather than local voxel adjacency, and from [Block Visibility Culling](5334-block-visibility-culling.md) by operating on the final triangle mesh rather than the underlying voxel grid. It specifically targets artifacts arising from unbounded reconstruction where distant or occluded geometry may persist.

## How it works
**Inputs:** A triangular mesh $M$ (vertices $V$, faces $F$), a list of camera poses $C = \{c_2w_i\}$, intrinsic parameters $K = \{f_x, f_y, c_x, c_y\}$, image resolution $(H, W)$, and parameters: `points_batch_size` (default $5 \times 10^5$), `remove_small_geometry_threshold` (default 0.2), `forecast_radius` $r$ (default 0), `eps` (default 0.005), and `valid_min_cameras` (default 20).

**Outputs:** A culled mesh $M'$ with reduced face count and unreferenced vertices removed.

**Data Structures:**
- `valid`: Boolean tensor of shape $(N_{pts})$, initialized to zeros. Marks points seen by $\ge$ `valid_min_cameras`.
- `valid_num`: Integer tensor of shape $(N_{pts})$, initialized to zeros. Counts cameras seeing each point.
- `valid_forecast`: Boolean tensor of shape $(N_{pts})$, initialized to zeros. Marks points in the "forecast" frustum.
- `face_mask`: Boolean array of shape $(N_{faces})$. True if all vertices of the face are valid.

**Steps:**

1. **Extract Reference Depth Maps:** Render forward depth maps for all camera poses in $C$ using a rasterizer (e.g., PyRender with `DEPTH_ONLY` and `SKIP_CULL_FACES` flags) [S1, unofficial]. Let $D_i$ be the depth map for camera $i$.

2. **Initialize Masks:** Create `valid`, `valid_num`, and `valid_forecast` tensors on the target device, size $N_{pts}$ (number of unique vertices in $M$), initialized to 0 [S1, unofficial].

3. **Process Points in Batches:** For each batch of vertices $V_{batch}$ (size up to `points_batch_size`):
   a. **Coordinate Transformation:** For each camera $i$ with pose $c_2w_i$:
      - Negate the y and z rows of the rotation matrix: $c_2w_i[:3, 1:3] *= -1$ [S1, unofficial].
      - Compute world-to-camera matrix: $W2C_i = c_2w_i^{-1}$ [S1, unofficial].
   b. **Projection:** For each vertex $p \in V_{batch}$:
      - Convert to homogeneous coordinates: $p_h = [p_x, p_y, p_z, 1]^T$.
      - Transform to camera space: $p_c = W2C_i \cdot p_h$.
      - Extract first three components: $p_c = [x_c, y_c, z_c]^T$ [S1, unofficial].
   c. **Intrinsic Projection:** For each $p_c$:
      - Apply intrinsic matrix $K$: $u = f_x \frac{x_c}{z_c} + c_x$, $v = f_y \frac{y_c}{z_c} + c_y$ [S1, unofficial].
      - Extract depth: $z = z_c + 10^{-8}$ [S1, unofficial].
      - Normalize UV for grid sampling: $u_{norm} = \frac{2u}{W} - 1$, $v_{norm} = \frac{2v}{H} - 1$ [S1, unofficial].
   d. **Frustum and Depth Validation:**
      - Check standard frustum: $in\_frustum = (0 \le u < W) \land (0 \le v < H) \land (z > 0)$ [S1, unofficial].
      - Check forecast frustum (if $r > 0$): $forecast\_frustum = (-r \le u < W+r) \land (-r \le v < H+r) \land (z > 0)$ [S1, unofficial].
      - Sample reference depth: $d_{sample} = \text{grid\_sample}(D_i, [u_{norm}, v_{norm}], \text{padding}=\text{'border'})$ [S1, unofficial].
      - Validate front-facing geometry: $is\_front = (d_{sample} > 0) \land (z < d_{sample} + \epsilon)$ [S1, unofficial].
   e. **Update Masks:**
      - If $in\_frustum$ and $is\_front$: increment `valid_num` and set `valid` to True for these points [S1, unofficial].
      - If $forecast\_frustum$ and $is\_front$: set `valid_forecast` to True for these points [S1, unofficial].

4. **Finalize Point Masks:**
   - `valid = valid_num >= valid_min_cameras` [S1, unofficial].
   - Combine `valid` and `valid_forecast` if forecast mode is active [S1, unofficial].

5. **Create Face Mask:**
   - For each face $f \in F$ with vertices $v_1, v_2, v_3$:
     - $face\_mask[f] = valid[v_1] \land valid[v_2] \land valid[v_3]$ [S1, unofficial].

6. **Update Mesh:**
   - Apply `face_mask` to remove invalid faces.
   - Remove unreferenced vertices [S1, unofficial].

7. **Optional Connected Component Filtering (Forecast):**
   - If `forecast_radius > 0`:
     - Create a forecast mesh from faces marked by `valid_forecast`.
     - Compute Oriented Bounding Box (OBB) of the cull mesh vertices [S1, unofficial].
     - Keep only forecast faces within this OBB [S1, unofficial].
   - Filter components by area:
     - Compute connected components of the mesh.
     - Keep components where $Area > \text{remove\_small\_geometry\_threshold} \times \text{global\_area}$, or keep only the largest component if `get_largest_components` is True [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def cull_mesh_by_3d_projection(mesh, cameras, intrinsics, H, W, 
                               points_batch_size=5e5, 
                               remove_small_geometry_threshold=0.2,
                               forecast_radius=0, eps=0.005, valid_min_cameras=20):
    """
    Cull mesh geometry based on multi-view depth projection.
    
    Args:
        mesh: Triangle mesh object with vertices (N, 3) and faces (M, 3).
        cameras: List of camera poses (c2w matrices, 4x4).
        intrinsics: Tuple (fx, fy, cx, cy).
        H, W: Image height and width.
        points_batch_size: Max points per batch.
        remove_small_geometry_threshold: Min area ratio to keep component.
        forecast_radius: Radius for extended frustum check.
        eps: Depth comparison tolerance.
        valid_min_cameras: Min cameras required to mark point as 'seen'.
        
    Returns:
        Culled mesh.
    """
    vertices = mesh.vertices  # (N, 3)
    faces = mesh.faces        # (M, 3)
    N = vertices.shape[0]
    
    # Initialize masks
    valid = torch.zeros(N, dtype=torch.bool, device=vertices.device)
    valid_num = torch.zeros(N, dtype=torch.int, device=vertices.device)
    valid_forecast = torch.zeros(N, dtype=torch.bool, device=vertices.device)
    
    fx, fy, cx, cy = intrinsics
    
    # Process in batches
    for start in range(0, N, points_batch_size):
        end = min(start + points_batch_size, N)
        v_batch = vertices[start:end]  # (B, 3)
        
        # Process each camera
        for c2w in cameras:
            # Negate y and z rows of rotation matrix
            c2w_copy = c2w.clone()
            c2w_copy[:3, 1:3] *= -1
            
            # World-to-camera matrix
            w2c = torch.inverse(c2w_copy)
            
            # Homogeneous coordinates
            v_homo = torch.cat([v_batch, torch.ones(end - start, 1, device=v_batch.device)], dim=1)  # (B, 4)
            
            # Project to camera space
            v_cam = (w2c @ v_homo.t()).t()[:, :3]  # (B, 3)
            x_c, y_c, z_c = v_cam[:, 0], v_cam[:, 1], v_cam[:, 2]
            
            # Intrinsic projection
            z = z_c + 1e-8
            u = fx * (x_c / z) + cx
            v = fy * (y_c / z) + cy
            
            # Normalize UV for grid sampling [-1, 1]
            u_norm = 2 * u / W - 1
            v_norm = 2 * v / H - 1
            
            # Frustum checks
            in_frustum = (u >= 0) & (u < W) & (v >= 0) & (v < H) & (z > 0)
            forecast_frustum = (u >= -forecast_radius) & (u < W + forecast_radius) & \
                               (v >= -forecast_radius) & (v < H + forecast_radius) & (z > 0)
            
            # Sample reference depth (assuming depth_map is pre-rendered and on device)
            # depth_map shape: (1, 1, H, W)
            # vgrid shape: (1, B, 1, 2) with values [u_norm, v_norm]
            vgrid = torch.stack([u_norm, v_norm], dim=-1).unsqueeze(0).unsqueeze(2)  # (1, B, 1, 2)
            depth_sample = F.grid_sample(depth_map, vgrid, padding_mode='border', align_corners=True)  # (1, 1, B, 1)
            depth_sample = depth_sample.squeeze(0).squeeze(0).squeeze(-1)  # (B,)
            
            # Front-face validation
            is_front_face = (depth_sample > 0.0) & (z_c < depth_sample + eps)
            
            # Update masks
            seen_mask = in_frustum & is_front_face
            forecast_mask = forecast_frustum & is_front_face
            
            valid_num[start:end] += seen_mask.int()
            valid[start:end] |= seen_mask
            valid_forecast[start:end] |= forecast_mask
            
    # Finalize valid mask
    valid = valid_num >= valid_min_cameras
    
    # Combine valid and forecast if needed (simplified: use valid for now, forecast for OBB)
    # In practice, forecast might be used to keep nearby unseen geometry
    final_point_mask = valid | valid_forecast if forecast_radius > 0 else valid
    
    # Create face mask: all vertices of a face must be valid
    face_mask = final_point_mask[faces].all(dim=1)
    
    # Update mesh
    mesh_with_hole = mesh.copy()
    mesh_with_hole.update_faces(face_mask)
    mesh_with_hole.remove_unreferenced_vertices()
    
    # Optional: Connected component filtering
    if forecast_radius > 0:
        # Compute OBB of cull mesh vertices (simplified: use bounding box)
        min_v = mesh_with_hole.vertices.min(dim=0).values
        max_v = mesh_with_hole.vertices.max(dim=0).values
        
        # Keep forecast faces within OBB (simplified check)
        # This step requires identifying which faces were forecast-only
        # For simplicity, we assume the OBB filtering is applied to the forecast mesh
        # and merged back. Here we just note the step.
        pass
    
    # Filter small components
    components = mesh_with_hole.get_connected_components()
    global_area = mesh_with_hole.area
    keep_components = []
    for comp in components:
        comp_area = comp.area
        if comp_area > remove_small_geometry_threshold * global_area:
            keep_components.append(comp)
    
    # Merge kept components
    final_mesh = merge_components(keep_components)
    
    return final_mesh
```

**Edge Cases and Pitfalls:**
- **Precision:** Depth comparison uses `eps=0.005` to handle floating-point inaccuracies [S1, unofficial].
- **Boundaries:** Grid sampling uses `padding_mode='border'` to handle points near image edges [S1, unofficial].
- **Degenerate Input:** If no cameras see a point, it is culled. If a face has one valid vertex, it is removed.
- **Memory:** `points_batch_size` limits GPU memory usage [S1, unofficial].

## Subtopics

### [Mesh Post-Processing (Cluster Filtering)](7002-mesh-post-processing-cluster-filtering.md)
Filters floating artifacts and disconnected components by clustering triangles and retaining only the largest connected clusters. It serves as a cleanup step following this method, targeting small, noisy geometry that survives projection-based culling. Unlike this method, which removes occluded or distant geometry, it removes topologically isolated fragments based on triangle count.

## Operating characteristics
- **Time Complexity:** $O(N \cdot C \cdot B)$, where $N$ is the number of vertices, $C$ is the number of cameras, and $B$ is the batch size. Depth sampling is $O(1)$ per point per camera.
- **Memory Complexity:** $O(N + C \cdot H \cdot W)$ for storing masks and depth maps.
- **Measured Performance:** On DTU dataset, this method contributes to improved Chamfer distance (0.47 mean vs 0.80 for paper baseline) by removing geometric artifacts [S1, unofficial].
- **Scaling:** Scales linearly with the number of cameras and vertices. Batch processing allows handling large meshes.
- **Strengths:** Effective for unbounded scenes where local voxel checks fail. Multi-view consistency reduces false positives.
- **Limitations:** Requires pre-rendered depth maps. Computationally intensive for large $N$ and $C$.
- **When to Use:** When reconstructing meshes from unbounded Gaussian splatting with many camera views.
- **When Not to Use:** For bounded scenes with local voxel structures where [Face Culling](8735-face-culling.md) is more efficient.

## Background
This method originates from the "2D Gaussian Splatting for Geometrically Accurate Radiance Fields" paper by Huang et al. (SIGGRAPH 2024) [S1, unofficial]. It was developed to address artifacts in unbounded mesh extraction from 2D Gaussian splatting, where traditional culling methods are insufficient due to the lack of a bounded voxel grid. The method is part of the official implementation of the 2D Gaussian Splatting repository [S1, unofficial].
