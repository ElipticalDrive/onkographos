# Mesh Culling via 3D Projection and Connected Components

Also called: Mesh Culling via Multi-View Depth Projection, cull with 3d projection

## Overview
This method culls mesh geometry by projecting vertices into multiple camera views and comparing their depths against reference depth maps to identify and remove unseen or forecast geometry [S1, unofficial]. It distinguishes itself from local neighborhood checks by using global multi-view consistency to filter artifacts from unbounded reconstructions, specifically targeting geometry that is not consistently visible across a set of camera poses [S1, unofficial].

## How it works
**Inputs:** A triangular mesh (vertices $V$, faces $F$), a list of camera poses (extrinsics $C_{2W}$), camera intrinsics ($K$ with focal lengths $f_x, f_y$ and principal point $c_x, c_y$), image resolution ($H, W$), and a far plane distance ($far=20.0$) [S1, unofficial].

**Outputs:** A culled mesh with removed faces and unreferenced vertices [S1, unofficial].

**Data Structures:**
*   `valid`: Boolean tensor of shape $(N_{pts})$, initialized to zeros, marking points seen by $\ge 20$ cameras [S1, unofficial].
*   `valid_num`: Integer tensor of shape $(N_{pts})$, counting visible cameras per point [S1, unofficial].
*   `forecast_mask`: Boolean tensor of shape $(N_{faces})$, marking faces within the forecast OBB [S1, unofficial].

**Parameters:**
*   `points_batch_size`: $5 \times 10^5$ (max points per batch) [S1, unofficial].
*   `remove_small_geometry_threshold`: $0.2$ (minimum face area ratio) [S1, unofficial].
*   `eps`: $0.005$ (depth comparison tolerance) [S1, unofficial].
*   `forecast_radius`: $r$ (frustum expansion radius for forecast) [S1, unofficial].

**Steps:**

1.  **Initialize Masks:** Create `valid`, `valid_num`, and `forecast_mask` tensors on the target device, initialized to zero/false [S1, unofficial].
2.  **Iterate Cameras:** For each camera pose $C_{2W}$:
    a.  **Coordinate Conversion:** Negate the $y$ and $z$ rows of the rotation matrix in $C_{2W}$ to match the expected coordinate system [S1, unofficial].
    b.  **World-to-Camera:** Compute $W_{2C} = C_{2W}^{-1}$ [S1, unofficial].
    c.  **Project Vertices:** For each vertex $v \in V$:
        i.  Convert to homogeneous coordinates: $v_h = [v_x, v_y, v_z, 1]^T$.
        ii. Transform to camera space: $v_c = W_{2C} v_h$.
        iii. Extract first three rows: $uvz = [u, v, z]^T$ [S1, unofficial].
    d.  **Intrinsic Projection:** Apply intrinsic matrix $K$:
        $$ uv = K \cdot uvz $$
        $$ u_{pix} = uv[0], v_{pix} = uv[1], z = uv[2] $$
        $$ u_{norm} = u_{pix} / z, v_{norm} = v_{pix} / z $$
        Add epsilon to $z$: $z \leftarrow z + 10^{-8}$ [S1, unofficial].
    e.  **Frustum Check:** Determine if point is in frustum:
        $$ in\_frustum = (0 \le u_{norm} < W) \land (0 \le v_{norm} < H) \land (z > 0) $$
        For forecast check, expand bounds:
        $$ forecast\_frustum = (-r \le u_{norm} < W+r) \land (-r \le v_{norm} < H+r) \land (z > 0) $$
    f.  **Depth Sampling:**
        i.  Reshape reference depth map $D$ to $(1, 1, H, W)$.
        ii. Normalize UV grid to $[-1, 1]$ for sampling.
        iii. Sample depth at $(u_{norm}, v_{norm})$ using bilinear interpolation with border padding:
        $$ depth\_sample = \text{GridSample}(D, \text{vgrid}, \text{padding\_mode='border'}) $$
    g.  **Front-Face Validation:**
        $$ is\_front = (depth\_sample > 0.0) \land (z < depth\_sample + \epsilon) $$
    h.  **Update Masks:**
        i.  If $in\_frustum$ and $is\_front$: increment `valid_num` for the vertex and set `valid` to true [S1, unofficial].
        ii. If $forecast\_frustum$ and $is\_front$: mark vertex as forecast [S1, unofficial].
3.  **Face Visibility:** A face is visible if all its vertices are in `valid`:
    $$ face\_mask = \text{valid}[F].\text{all}(\text{axis}=1) $$
4.  **Forecast Culling (Optional):** If `forecast_radius > 0`:
    a.  Create a forecast mesh from faces marked in the forecast step.
    b.  Compute the Oriented Bounding Box (OBB) of the cull mesh vertices.
    c.  Keep only forecast faces within this OBB [S1, unofficial].
5.  **Apply Mask:** Update mesh with `face_mask` and remove unreferenced vertices [S1, unofficial].
6.  **Component Filtering:** Filter mesh components by area. Keep components where area $> \text{threshold} \times \text{global\_area}$, or keep only the largest component if specified [S1, unofficial].

## Subtopics

### [Mesh Post-Processing (Cluster Filtering)](7002-mesh-post-processing-cluster-filtering.md)
Filters floating artifacts and disconnected components by clustering triangles and retaining only the largest connected clusters. It serves as a cleanup step following this method, targeting small, noisy geometry that survives projection-based culling. Unlike this method which removes occluded or distant geometry, it removes topologically isolated fragments based on triangle count.

## Operating characteristics
**Time Complexity:** $O(N \cdot C)$, where $N$ is the number of vertices and $C$ is the number of cameras. Depth sampling is $O(1)$ per vertex per camera using bilinear interpolation [S1, unofficial].

**Memory Complexity:** $O(N)$ for vertex masks and $O(H \cdot W \cdot C)$ for storing depth maps if not streamed [S1, unofficial].

**Performance:** Effective for removing artifacts from unbounded Gaussian splatting reconstructions. Requires at least 20 camera views for robust visibility determination [S1, unofficial].

**Strengths:** Global visibility check; removes geometry not consistently seen across views; handles unbounded scenes [S1, unofficial].

**Limitations:** Requires pre-computed depth maps; sensitive to camera pose accuracy; may remove valid geometry if view coverage is sparse [S1, unofficial].

**When to use:** Post-processing meshes from unbounded reconstructions (e.g., 2D Gaussian Splatting) to remove background noise and artifacts [S1, unofficial].

**When not to use:** Real-time rendering where depth map generation is too expensive; scenes with very sparse camera coverage [S1, unofficial].

## Background
Originated in the context of 2D Gaussian Splatting for geometrically accurate radiance fields, specifically for unbounded mesh extraction [S1, unofficial]. The method was developed to address artifacts in meshes derived from Gaussian splatting, which can contain floating geometry not present in the original scene [S1, unofficial]. It is used in the official implementation of 2D Gaussian Splatting for mesh export [S1, unofficial].
