# Chunk Mesh Rebuild Queue

Also called: ProcessRebuildQueue, QueueRebuild

## Overview
A queue-based system to batch and process chunk mesh rebuilds asynchronously or on tick [S1, unofficial].

## How it works
**Inputs:**
- `RebuildQueue`: A list of chunk indices pending mesh regeneration [S1, unofficial].
- `RebuildSet`: A set of chunk indices currently in the queue for O(1) lookup [S1, unofficial].
- `ActiveChunks`: A set of chunk indices currently loaded and visible [S1, unofficial].
- `ChunkCache`: A storage structure mapping chunk indices to voxel block data [S1, unofficial].
- `WorldMesh`: The rendering component responsible for updating chunk geometry [S1, unofficial].
- `PlayerPosition`: The current player coordinates [S1, unofficial].

**Outputs:**
- Updated mesh geometry for processed chunks [S1, unofficial].
- Collision state updates for chunks near the player [S1, unofficial].

**Data Structures:**
- `RebuildQueue`: A dynamic array or stack of `ChunkIndex` values [S1, unofficial].
- `RebuildSet`: A hash set or boolean array indexed by `ChunkIndex` [S1, unofficial].
- `ChunkCache`: A map from `ChunkIndex` to voxel block data (e.g., `TMap<FIntPoint, TMap<FIntVector, EBlockType>>`) [S1, unofficial].

**Steps:**
1. **Enqueue:** When a chunk becomes dirty, if its `ChunkIndex` is not in `RebuildSet`, add it to both `RebuildSet` and `RebuildQueue` [S1, unofficial].
2. **Process Loop:**
   a. If `RebuildQueue` is empty or `WorldMesh` is null, return [S1, unofficial].
   b. Pop the last element from `RebuildQueue`: `ChunkIndex = RebuildQueue.Last()`, then `RebuildQueue.Pop()` [S1, unofficial].
   c. Remove `ChunkIndex` from `RebuildSet` [S1, unofficial].
   d. If `ChunkIndex` is not in `ActiveChunks`, skip to the next iteration [S1, unofficial].
   e. Retrieve chunk data from `ChunkCache`. If not found, skip to the next iteration [S1, unofficial].
   f. Prepare mesh: `Mesh = AWorldMeshActor::PrepareChunkMesh(*Data)` [S1, unofficial].
   g. Update the chunk mesh: `WorldMesh->UpdateChunk(ChunkIndex, Mesh)` [S1, unofficial].
   h. Check if the chunk is near the player (within 1 chunk in X and Y). If so, enable collision for the chunk [S1, unofficial].

**Pseudocode:**
```python
def QueueRebuild(RebuildQueue, RebuildSet, ChunkIndex):
    if ChunkIndex not in RebuildSet:
        RebuildSet.add(ChunkIndex)
        RebuildQueue.append(ChunkIndex)

def ProcessRebuildQueue(RebuildQueue, RebuildSet, ActiveChunks, ChunkCache, WorldMesh, PlayerPosition):
    while len(RebuildQueue) > 0 and WorldMesh is not None:
        ChunkIndex = RebuildQueue[-1]
        RebuildQueue.pop()
        RebuildSet.discard(ChunkIndex)

        if ChunkIndex not in ActiveChunks:
            continue

        Data = ChunkCache.get(ChunkIndex)
        if Data is None:
            continue

        Mesh = PrepareChunkMesh(Data)  # [G] Standard mesh generation from voxel data
        WorldMesh.UpdateChunk(ChunkIndex, Mesh)

        if abs(ChunkIndex.x - PlayerPosition.x) <= 1 and abs(ChunkIndex.y - PlayerPosition.y) <= 1:
            WorldMesh.EnableCollision(ChunkIndex)
```

**Edge Cases:**
- **Empty Queue:** The loop terminates immediately if no chunks are dirty [S1, unofficial].
- **Null WorldMesh:** Prevents crashes if the mesh component is not initialized [S1, unofficial].
- **Inactive Chunks:** Chunks not in `ActiveChunks` are skipped to avoid rendering unloaded geometry [S1, unofficial].
- **Missing Data:** Chunks not found in `ChunkCache` are skipped [S1, unofficial].
