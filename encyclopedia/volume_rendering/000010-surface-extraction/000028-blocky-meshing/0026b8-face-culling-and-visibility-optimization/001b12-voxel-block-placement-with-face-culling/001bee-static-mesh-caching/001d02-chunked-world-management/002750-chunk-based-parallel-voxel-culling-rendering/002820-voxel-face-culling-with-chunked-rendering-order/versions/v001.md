# Voxel Face Culling with Chunked Rendering Order

Also called: Camera-relative Chunk Iteration, Chunked Rendering Order

## Overview
This method optimizes the rendering of blocky voxel meshes by generating geometry only for voxel faces adjacent to empty space or chunk boundaries, while traversing the world in a camera-relative front-to-back order to improve GPU depth sorting efficiency [S1, unofficial]. It builds on [Chunk-Based Parallel Voxel Culling & Rendering](3994-chunk-based-parallel-voxel-culling-rendering.md) by adding specific traversal logic and boundary-aware face culling.

## How it works
**Inputs:** Camera position and look vector; array of `Chunk` objects; `Constants.ChunkSize` (linear dimension of a chunk in voxels).
**Outputs:** Draw calls for each chunk's `voxelBuffer`.

**Data Structures:**
*   `Voxel`: Contains `index` (byte/uint). Empty voxels have `index == 0`.
*   `Chunk`: Contains `Allocated` (bool), `voxels` (pointer to flat array of `Voxel`), `WorldPos` (vec3), `IsDirty` (bool), `fake` (bool), `voxelBuffer` (GPU buffer handle).
*   `Constants`:
    *   `ChunkSize`: Linear dimension $N$.
    *   `ChunkSizeM1`: $N - 1$.
    *   `ChunkSizeSquared`: $N^2$.
    *   `ACCESS_STEP_X`: 1.
    *   `ACCESS_STEP_Y`: $N$.
    *   `ACCESS_STEP_Z`: $N^2$.

**Algorithm:**

1.  **Calculate Chunk Iteration Bounds:**
    Determine traversal order based on the camera look vector $\vec{L} = (L_x, L_y, L_z)$.
    *   For X axis: If $L_x > 0$, $startX=0$, $endX=ChunkAmountX$, $xStep=1$, $xAccessStep=ChunkSize$. Else, reverse indices.
    *   For Z axis: If $L_z > 0$, $startZ=0$, $endZ=ChunkAmountZ$, $zStep=1$, $zAccessStep=ChunkSize$. Else, reverse indices.
    *   Y axis traversal is typically inner or outer depending on implementation, but the core optimization is X/Z relative to camera [S1, unofficial].

2.  **Iterate Chunks:**
    Loop over chunk indices $k$ (Z), $i$ (X), and $j$ (Y) using the calculated bounds and steps.
    *   Skip chunks where `chunk.Allocated` is false.
    *   If `chunk.IsDirty()` is true, regenerate the mesh.
    *   Bind `chunk.voxelBuffer` and issue draw call.

3.  **Mesh Chunk (Face Culling):**
    For each voxel in the chunk, determine which faces to render. A face is rendered if the neighbor is empty (`index == 0`) or outside the world.
    
    **Boundary Handling:**
    When checking a neighbor at a chunk boundary (e.g., X- direction at $x=0$):
    *   Identify the neighboring chunk (e.g., `chunkXN`).
    *   If `chunkXN.Allocated` is false, treat the neighbor as empty and render the face [S1, unofficial].
    *   If `chunkXN.Allocated` is true, fetch the voxel from the neighbor chunk's data. For X- boundary, the neighbor voxel is at local index corresponding to $x=N-1$ in the neighbor chunk.
    
    **Pseudocode:**

```python
def render_chunks(camera_look_vector, chunks, chunk_amounts, constants):
    # 1. Calculate iteration bounds
    L = camera_look_vector
    
    # X axis
    if L.x > 0:
        x_start, x_end, x_step = 0, chunk_amounts.x, 1
    else:
        x_start, x_end, x_step = chunk_amounts.x - 1, -1, -1
        
    # Z axis
    if L.z > 0:
        z_start, z_end, z_step = 0, chunk_amounts.z, 1
    else:
        z_start, z_end, z_step = chunk_amounts.z - 1, -1, -1
        
    N = constants.ChunkSize
    N2 = N * N
    N_minus_1 = N - 1
    
    # 2. Iterate chunks
    for k in range(z_start, z_end, z_step):
        for i in range(x_start, x_end, x_step):
            for j in range(chunk_amounts.y): # Y iteration order may vary
                chunk = chunks[i, j, k]
                
                if not chunk.allocated:
                    continue
                    
                if chunk.is_dirty:
                    mesh_chunk(chunk, constants)
                    
                if chunk.voxel_buffer is not None:
                    bind_and_draw(chunk.voxel_buffer)

    N = constants.ChunkSize
    N2 = N * N
    N_minus_1 = N - 1
    
    voxels = chunk.voxels
    # Assume chunk has pointers to neighbors: chunk_xn, chunk_xp, chunk_yn, chunk_yp, chunk_zn, chunk_zp
    
    for k in range(N):
        for i in range(N):
            for j in range(N):
                # Calculate linear index
                idx = i + j * N + k * N2
                
                voxel = voxels[idx]
                
                # Check 6 directions
                # X- Direction
                if i == 0:
                    neighbor_chunk = chunk.chunk_xn
                    if not neighbor_chunk.allocated:
                        render_face(idx, normal=(-1,0,0))
                    else:
                        # Neighbor is at x=N-1 in neighbor chunk
                        neighbor_idx = N_minus_1 + j * N + k * N2
                        if neighbor_chunk.voxels[neighbor_idx].index == 0:
                            render_face(idx, normal=(-1,0,0))
                else:
                    neighbor_idx = (i - 1) + j * N + k * N2
                    if voxels[neighbor_idx].index == 0:
                        render_face(idx, normal=(-1,0,0))
                        
                # X+ Direction
                if i == N_minus_1:

                    else:
                        # Neighbor is at x=0 in neighbor chunk
                        neighbor_idx = 0 + j * N + k * N2
                        if neighbor_chunk.voxels[neighbor_idx].index == 0:
                            render_face(idx, normal=(1,0,0))
                else:
                    neighbor_idx = (i + 1) + j * N + k * N2
                    if voxels[neighbor_idx].index == 0:
                        render_face(idx, normal=(1,0,0))
                        
                # Y- Direction
                if j == 0:
                    neighbor_chunk = chunk.chunk_yn
                    if not neighbor_chunk.allocated:
                        render_face(idx, normal=(0,-1,0))
                    else:
                        # Neighbor is at y=N-1 in neighbor chunk
                        neighbor_idx = i + N_minus_1 * N + k * N2
                        if neighbor_chunk.voxels[neighbor_idx].index == 0:
                            render_face(idx, normal=(0,-1,0))
                else:
                    neighbor_idx = i + (j - 1) * N + k * N2
                    if voxels[neighbor_idx].index == 0:
                        render_face(idx, normal=(0,-1,0))
                        
                # Y+ Direction
                if j == N_minus_1:
                    neighbor_chunk = chunk.chunk_yp
                    if not neighbor_chunk.allocated:
                        render_face(idx, normal=(0,1,0))
                    else:
                        # Neighbor is at y=0 in neighbor chunk
                        neighbor_idx = i + 0 * N + k * N2
                        if neighbor_chunk.voxels[neighbor_idx].index == 0:
                            render_face(idx, normal=(0,1,0))
                else:
                    neighbor_idx = i + (j + 1) * N + k * N2
                    if voxels[neighbor_idx].index == 0:
                        render_face(idx, normal=(0,1,0))
                        
                # Z- Direction
                if k == 0:
                    neighbor_chunk = chunk.chunk_zn
                    if not neighbor_chunk.allocated:
                        render_face(idx, normal=(0,0,-1))
                    else:
                        # Neighbor is at z=N-1 in neighbor chunk
                        neighbor_idx = i + j * N + N_minus_1 * N2
                        if neighbor_chunk.voxels[neighbor_idx].index == 0:
                            render_face(idx, normal=(0,0,-1))
                else:
                    neighbor_idx = i + j * N + (k - 1) * N2
                    if voxels[neighbor_idx].index == 0:
                        render_face(idx, normal=(0,0,-1))
                        
                # Z+ Direction
                if k == N_minus_1:
                    neighbor_chunk = chunk.chunk_zp
                    if not neighbor_chunk.allocated:
                        render_face(idx, normal=(0,0,1))
                    else:
                        # Neighbor is at z=0 in neighbor chunk
                        neighbor_idx = i + j * N + 0 * N2
                        if neighbor_chunk.voxels[neighbor_idx].index == 0:
                            render_face(idx, normal=(0,0,1))
                else:
                    neighbor_idx = i + j * N + (k + 1) * N2
                    if voxels[neighbor_idx].index == 0:
                        render_face(idx, normal=(0,0,1))
```

**Edge Cases:**
*   **Unallocated Neighbors:** If a neighbor chunk is not allocated, the face is always rendered, treating the out-of-bounds region as empty space [S1, unofficial].
*   **Precision:** Use integer arithmetic for indices to avoid floating-point errors in boundary calculations.

## Operating characteristics
*   **Time Complexity:** $O(V)$ where $V$ is the number of visible voxels. Chunk iteration is $O(C)$ where $C$ is the number of chunks.
*   **Memory Complexity:** $O(C \cdot N^3)$ for voxel data, plus $O(F)$ for mesh faces where $F$ is the number of faces.
*   **Performance:** Improves GPU depth sorting by rendering front-to-back relative to the camera. Reduces overdraw and culling overhead by only generating faces for solid-void interfaces [S1, unofficial].
*   **Strengths:** Efficient for large, sparse worlds. Simple boundary handling.
*   **Limitations:** Requires neighbor chunk pointers. Mesh regeneration is needed when chunks change.

## Background
This method is used in voxel-based game engines and editors, specifically referenced in the vercidium-patreon/meshing project [S1, unofficial]. It addresses the performance bottleneck of rendering large voxel worlds by combining spatial partitioning (chunks) with visibility optimization (culling and rendering order).
