# Chunk Mesh Rebuild Queue

Also called: ProcessRebuildQueue, QueueRebuild

## Overview
A queue-based system to batch and process chunk mesh rebuilds asynchronously or on tick [S1, unofficial]. It defers mesh regeneration from immediate block modifications, processing them in a dedicated loop [G].

## How it works
**Inputs:**
- `RebuildQueue`: List of `ChunkIndex` values pending regeneration.
- `RebuildSet`: Set of `ChunkIndex` values currently queued to prevent duplicates.
- `ActiveChunks`: Set of `ChunkIndex` values currently loaded.
- `ChunkCache`: Map from `ChunkIndex` to raw voxel block data.
- `WorldMesh`: Mesh manager object.
- `PlayerPosition`: 2D coordinates $(x, z)$ of the player.

**Outputs:**
- Updated meshes for processed chunks [S1, unofficial].
- Collision state updates for chunks near the player [S1, unofficial].

**Data Structures:**
- `ChunkIndex`: 2D integer coordinate $(x, z)$ or equivalent identifier.
- `RebuildQueue`: LIFO stack.
- `RebuildSet`: Hash set for $O(1)$ lookup.

**Steps:**
1. **Enqueue Modification:** When a chunk is modified, check if its `ChunkIndex` exists in `RebuildSet`. If not, add `ChunkIndex` to both `RebuildSet` and `RebuildQueue` [S1, unofficial].
2. **Process Loop:** Check if `RebuildQueue` is empty or `WorldMesh` is null. If so, terminate [S1, unofficial].
3. **Pop Task:** Retrieve the last element from `RebuildQueue`: `ChunkIndex = RebuildQueue.Last()`. Remove it from the queue: `RebuildQueue.Pop()`. Remove `ChunkIndex` from `RebuildSet` [S1, unofficial].
4. **Validate Activity:** Check if `ChunkIndex` is present in `ActiveChunks`. If not, return [S1, unofficial].
5. **Retrieve Data:** Fetch chunk data from `ChunkCache` using `ChunkIndex`. If data is missing, return [S1, unofficial].
6. **Prepare Mesh:** Generate geometry from the raw block data: `Mesh = PrepareChunkMesh(Data)` [S1, unofficial].
7. **Update Mesh:** Replace the old mesh with the new one: `WorldMesh.UpdateChunk(ChunkIndex, Mesh)` [S1, unofficial].
8. **Collision Check:** Determine if the chunk is near the player (within 1 chunk in X and Y axes). If true, enable collision for the chunk [S1, unofficial].

**Pseudocode:**
```python
def ProcessRebuildQueue(RebuildQueue, RebuildSet, ActiveChunks, ChunkCache, WorldMesh, PlayerPosition):
    if not RebuildQueue or WorldMesh is None:
        return

    ChunkIndex = RebuildQueue[-1]
    RebuildQueue.pop()
    RebuildSet.discard(ChunkIndex)

    if ChunkIndex not in ActiveChunks:
        return

    Data = ChunkCache.get(ChunkIndex)
    if Data is None:
        return

    Mesh = PrepareChunkMesh(Data)
    WorldMesh.UpdateChunk(ChunkIndex, Mesh)

    if abs(ChunkIndex.x - PlayerPosition.x) <= 1 and abs(ChunkIndex.z - PlayerPosition.z) <= 1:
        EnableCollision(ChunkIndex)

def PrepareChunkMesh(Data):
    # Generates mesh geometry from raw block data [G]
    return MeshGeometry(vertices=Data.vertices, indices=Data.indices)

def EnableCollision(ChunkIndex):
    # Enables collision flags for the chunk [G]
    ChunkCollisionState[ChunkIndex] = True
```

**Edge Cases:**
- **Duplicate Modifications:** The `RebuildSet` prevents adding the same chunk to the queue multiple times if multiple blocks change in the same frame [S1, unofficial].
- **Unloaded Chunks:** Chunks modified while outside the active view are skipped if they are not in `ActiveChunks` during processing [S1, unofficial].
- **Null Mesh:** If `WorldMesh` is not initialized, the queue processing halts immediately to prevent crashes [S1, unofficial].
