# Mask Projection Culling

Also called: Depth-Projected Mesh Culling, Mesh Culling via Mask Projection, point mask culling

## Overview
Mask Projection Culling is a visibility-based mesh filtering technique that removes faces and vertices not consistently observed across multiple camera poses by projecting points into camera space and comparing their depth against rendered depth maps or binary masks [S1, unofficial][S2, unofficial]. It differs from standard face culling (which relies on local voxel occupancy) by using global camera visibility to eliminate geometry occluded by the scene structure or outside the viewing frustum, thereby reducing vertex count and draw calls for downstream rendering [S1, unofficial][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A triangular mesh (vertices $V$, faces $F$), a set of $V_{cam}$ camera poses (world-to-camera matrices $W_i$ and intrinsic matrices $K_i$), and optionally binary masks $M_i$ for each view [S1, unofficial][S2, unofficial].
*   **Output:** A filtered mesh containing only vertices and faces visible in at least $T_{vis}$ views (typically 20) [S2, unofficial].

**Data Structures:**
*   **Vertices:** Array of 3D coordinates $(x, y, z)$.
*   **Faces:** Array of indices referencing vertices.
*   **Visibility Counter:** Integer array of size $N_{vertices}$, initialized to 0, tracking how many views each vertex is visible in [S2, unofficial].

**Parameters:**
*   $W, H$: Image width and height (e.g., 1600, 1200) [S1, unofficial].
*   $\epsilon$: Depth comparison tolerance (e.g., 0.005) [S2, unofficial].
*   $T_{vis}$: Minimum visibility count threshold (e.g., 20) [S2, unofficial].
*   $B_{size}$: Batch size for point processing to limit GPU memory (e.g., $5 \times 10^5$) [S2, unofficial].
*   $r_{dilate}$: Morphological dilation radius for masks (e.g., 24) [S1, unofficial].

**Steps:**

1.  **Camera Setup:** Load camera parameters. Compute projection matrices $P_i = W_i \times S_i$ (where $S_i$ is a scale matrix) and extract intrinsics $K_i$ and pose [S1, unofficial]. Handle coordinate system mismatches (e.g., OpenCV to OpenGL) by flipping Y and Z axes of the camera pose if necessary [S2, unofficial].
2.  **Depth Map Rendering:** Render forward depth maps $D_i$ from the mesh for each camera pose using an offscreen renderer with flags `DEPTH_ONLY` and `SKIP_CULL_FACES` [S2, unofficial].
3.  **Mask Loading:** Load binary masks $M_i$ from image files. Dilate masks using morphology (e.g., disk kernel of radius $r_{dilate}$) to account for discretization errors [S1, unofficial].
4.  **Projection and Visibility Check:** For each camera view $i$:
    a. Transform vertices to camera space: $C = W_i \times V$.
    b. Project to 2D: $UV = K_i \times C$. Perform homogeneous division: $u = UV_x / UV_z$, $v = UV_y / UV_z$.
    c. Check frustum bounds: $u \in [0, W-1]$, $v \in [0, H-1]$, $z > 0$ [S2, unofficial].
    d. Sample depth at $(u, v)$ from $D_i$ using bilinear interpolation with border padding to avoid NaNs [S2, unofficial].
    e. Determine if point is in front of surface: $is\_front = (z < D_{sampled} + \epsilon)$ [S2, unofficial].
    f. If masks are provided, sample the dilated mask $M_i$ at $(u, v)$ using nearest-neighbor interpolation. The point is valid only if $is\_front$ is true AND mask value > 0 [S1, unofficial].
    g. Increment visibility counter for valid vertices [S2, unofficial].
5.  **Filtering:** Identify vertices with visibility count $\ge T_{vis}$. Remove faces where any vertex is not in the valid set.
6.  **Post-processing:** Transform remaining vertices back to world space using inverse scale/translation matrices and export the mesh [S1, unofficial].

**Pseudocode:**

```python
import torch
import numpy as np

def mask_projection_culling(mesh, cameras, masks=None, epsilon=0.005, threshold=20, batch_size=500000):
    """
    mesh: dict with 'vertices' (N, 3) and 'faces' (F, 3)
    cameras: list of dicts with 'w2c' (4, 4), 'K' (3, 3), 'W', 'H'
    masks: list of tensors (H, W) or None
    """
    vertices = mesh['vertices'].clone()
    faces = mesh['faces']
    N = vertices.shape[0]
    
    # Initialize visibility counter
    visibility_counts = torch.zeros(N, dtype=torch.int32)
    
    # Process in batches to manage memory
    for batch_start in range(0, N, batch_size):
        batch_end = min(batch_start + batch_size, N)
        batch_verts = vertices[batch_start:batch_end]
        batch_size_actual = batch_verts.shape[0]
        
        # Initialize batch visibility
        batch_vis = torch.zeros(batch_size_actual, dtype=torch.int32)
        
        for i, cam in enumerate(cameras):
            w2c = cam['w2c']
            K = cam['K']
            W, H = cam['W'], cam['H']
            
            # Transform to camera space
            # Add homogeneous coordinate
            verts_hom = torch.cat([batch_verts, torch.ones(batch_size_actual, 1, device=batch_verts.device)], dim=1)
            cam_cord = (w2c @ verts_hom.t()).t() # (B, 4)
            
            # Project to 2D
            uv = (K @ cam_cord[:, :3].t()).t() # (B, 3)
            z = uv[:, 2:] + 1e-8
            uv_2d = uv[:, :2] / z # (B, 2)
            
            # Check frustum
            u = uv_2d[:, 0]
            v = uv_2d[:, 1]
            in_frustum = (u >= 0) & (u <= W - 1) & (v >= 0) & (v <= H - 1) & (z.squeeze() > 0)
            
            # Sample depth
            # Normalize to [-1, 1] for grid_sample
            vgrid = torch.zeros(batch_size_actual, 1, 2, device=uv_2d.device)
            vgrid[:, 0, 0] = (u / (W - 1) * 2.0 - 1.0)
            vgrid[:, 0, 1] = (v / (H - 1) * 2.0 - 1.0)
            
            # Render depth map D_i would be pre-computed
            # Assuming depth_map is (1, 1, H, W)
            depth_sample = torch.nn.functional.grid_sample(
                cam['depth_map'].unsqueeze(0), 
                vgrid, 
                padding_mode='border', 
                align_corners=True
            ).squeeze() # (B,)
            
            # Check if in front of surface
            is_front = z.squeeze() < (depth_sample + epsilon)
            
            # Check mask if provided
            valid = in_frustum & is_front
            if masks is not None:
                mask_val = torch.nn.functional.grid_sample(
                    cam['mask_tensor'].unsqueeze(0).unsqueeze(0), 
                    vgrid, 
                    mode='nearest', 
                    padding_mode='zeros', 
                    align_corners=True
                ).squeeze() # (B,)
                valid = valid & (mask_val > 0)
            
            # Update visibility
            batch_vis = batch_vis + valid.int()
        
        # Accumulate global visibility
        visibility_counts[batch_start:batch_end] += batch_vis
        
    # Filter vertices
    valid_verts_mask = visibility_counts >= threshold
    valid_vert_indices = torch.where(valid_verts_mask)[0]
    
    # Create mapping from old index to new index
    idx_map = torch.full((N,), -1, dtype=torch.long)
    idx_map[valid_vert_indices] = torch.arange(len(valid_vert_indices))
    
    # Filter faces
    # Check if all vertices of a face are valid
    face_verts = faces # (F, 3)
    valid_face_mask = torch.all(idx_map[face_verts] != -1, dim=1)
    new_faces = idx_map[faces[valid_face_mask]]
    
    new_vertices = vertices[valid_verts_mask]
    
    return {'vertices': new_vertices, 'faces': new_faces}
```

## Subtopics

### True Back-Face Culling via Group Masking
A back-face culling technique that splits chunk meshes into 6 vertex pool buckets based on face orientation (groups 0-5). Draw calls are masked based on the camera position relative to the chunk, preventing the draw call from being issued entirely rather than culling in the fragment shader [S3, unofficial]. It avoids the 6-fold driver overhead increase associated with splitting chunks into 6 sub-meshes by using existing vertex pool bucketing [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \times V \times B)$, where $N$ is the number of points, $V$ is the number of validation frames, and $B$ is the batch size [S2, unofficial].
*   **Memory Complexity:** $O(N \times V)$ for intermediate masks and valid counts [S2, unofficial].
*   **Strengths:** Effectively removes occluded geometry and out-of-frustum artifacts that local voxel culling misses. Reduces vertex count significantly for large scenes.
*   **Limitations:** Requires pre-rendered depth maps or masks for all views. Sensitive to coordinate system mismatches (e.g., OpenCV vs OpenGL) [S2, unofficial]. Out-of-bounds UV coordinates require careful padding handling to avoid NaNs [S2, unofficial].
*   **When to use:** When a set of camera views is available (e.g., from COLMAP or NeRF training) and the goal is to clean up a mesh for rendering from those specific viewpoints.
*   **When not to use:** For real-time dynamic culling without pre-computed views, or when memory is extremely constrained due to the $O(N \times V)$ intermediate storage.

## Background
Mask Projection Culling is derived from techniques used in 3D Gaussian Splatting and NeRF-based reconstruction pipelines, where visibility is determined by projecting points into multiple camera views [S1, unofficial][S2, unofficial]. It is commonly used in post-processing steps of differentiable rendering frameworks to extract clean meshes from implicit or point-based representations [S2, unofficial].
