# Mask Projection Culling

Also called: Depth-Projected Mesh Culling, Mesh Culling via Mask Projection, point mask culling

## Overview
Mask Projection Culling is a visibility-based mesh filtering technique that removes faces and vertices not consistently observed across multiple camera poses by projecting 3D points into camera space and comparing their depth against rendered depth maps or binary masks [S1, unofficial][S2, unofficial]. Unlike adjacency-based culling which relies on voxel occupancy, this method uses external geometric validation from multiple viewpoints to eliminate geometry that is either occluded, noisy, or outside the captured volume [S2, unofficial]. It is distinct from [Face Coverage Mask Culling](3397-face-coverage-mask-culling.md) which uses static coverage bitmasks, and [Block Visibility Culling](5334-block-visibility-culling.md) which operates on coarse blocks, as this method operates on fine-grained mesh primitives using multi-view depth consistency [S1, unofficial][S2, unofficial].

## How it works
The method filters a mesh by validating each vertex and face against a set of reference camera views. A vertex is retained only if it is visible (in front of the surface) and within the image bounds for a sufficient number of views.

### Inputs and Outputs
*   **Input:** A mesh (vertices $V$, faces $F$), a set of $V$ camera poses (world-to-camera matrices $W_i$ and intrinsic matrices $K_i$), and optionally binary masks $M_i$ for each view.
*   **Output:** A filtered mesh containing only vertices and faces valid across the validation frames.

### Data Structures
*   **Camera Parameters:** Stored as `world_mat` and `scale_mat`. The projection matrix $P$ is computed as $P = \text{world\_mat} \times \text{scale\_mat}$ [S1, unofficial]. Intrinsics and pose are extracted via `rend_util.load_K_Rt_from_P(None, P)` [S1, unofficial].
*   **Depth Maps:** Rendered forward depth maps for each camera pose using an offscreen renderer with flags `OFFSCREEN | DEPTH_ONLY | SKIP_CULL_FACES` [S2, unofficial].
*   **Binary Masks:** Loaded from `mask_dir/*.png` with fixed dimensions $W=1600, H=1200$ [S1, unofficial].
*   **Validity Counters:** An integer array of size $N$ (number of vertices) tracking how many views validate each vertex [S2, unofficial].

### Steps

1.  **Precompute Camera Matrices:**
    For each camera $i$, compute the inverse world-to-camera matrix $W2C_i = (\text{world\_mat}_i \times \text{scale\_mat}_i)^{-1}$ [S1, unofficial][S2, unofficial]. Handle coordinate system mismatches (e.g., OpenCV vs OpenGL) by flipping Y and Z axes of the camera pose if necessary: $C2W[:3, 1:3] *= -1$ [S2, unofficial].

2.  **Render Reference Depth Maps:**
    Render depth maps $D_i$ for each camera pose using an offscreen renderer [S2, unofficial].

3.  **Initialize Validity Counters:**
    Create an array `valid_counts` of size $N$ initialized to 0 [S2, unofficial].

4.  **Process Points in Batches:**
    To limit GPU memory, process vertices in batches of size $B$ (e.g., $B=5 \times 10^5$) [S2, unofficial]. For each batch of vertices $V_{batch}$:
    
    a. **Transform to Camera Space:**
    For each camera $i$, transform vertices to camera space:
    $$ P_{cam} = W2C_i \times V_{batch} $$
    where $V_{batch}$ is a $4 \times N_{batch}$ matrix (homogeneous coordinates) [S1, unofficial].

    b. **Project to 2D:**
    Compute pixel coordinates using intrinsic matrix $K_i$:
    $$ uv_{hom} = K_i \times P_{cam} $$
    $$ z = uv_{hom}[2, :] + \epsilon $$
    $$ uv = \frac{uv_{hom}[0:2, :]}{z} $$
    where $\epsilon = 10^{-6}$ prevents division by zero [S1, unofficial][S2, unofficial].

    c. **Normalize Coordinates:**
    Normalize UV coordinates to NDC space $[-1, 1]$ for grid sampling:
    $$ uv_{ndc}[0] = \frac{uv[0]}{W - 1} \times 2.0 - 1.0 $$
    $$ uv_{ndc}[1] = \frac{uv[1]}{H - 1} \times 2.0 - 1.0 $$
    [S1, unofficial][S2, unofficial].

    d. **Check Frustum Bounds:**
    Determine if points are within the image bounds:
    $$ \text{in\_frustum} = (0 \le uv[0] < W) \land (0 \le uv[1] < H) \land (z > 0) $$
    [S2, unofficial]. Alternatively, check NDC bounds:
    $$ \text{valid} = (-1 < uv_{ndc}[0] < 1) \land (-1 < uv_{ndc}[1] < 1) $$
    [S1, unofficial].

    e. **Sample Mask/Depth:**
    *   **Mask Variant:** Dilate the binary mask $M_i$ using morphology with a disk of radius 24. Sample the dilated mask at $uv_{ndc}$ using nearest-neighbor interpolation with zero padding [S1, unofficial].
    *   **Depth Variant:** Sample the depth map $D_i$ at $uv_{ndc}$ using bilinear interpolation with border padding to handle out-of-bounds queries (preventing NaNs) [S2, unofficial].

    f. **Validate Visibility:**
    *   **Mask Variant:** A vertex is valid for view $i$ if the sampled mask value $> 0$ [S1, unofficial].
    *   **Depth Variant:** A vertex is in front of the surface if:
        $$ \text{is\_front} = (z < \text{depth\_sample} + \text{eps}) $$
        where $\text{eps} = 0.005$ accounts for discretization errors [S2, unofficial].

    g. **Update Counts:**
    Increment `valid_counts` for vertices that pass the visibility check for view $i$ [S2, unofficial].

5.  **Filter Mesh:**
    After processing all views, retain vertices where `valid_counts` $\ge$ threshold (e.g., 20) [S2, unofficial]. Retain faces only if all their vertices are retained [S1, unofficial].

6.  **Transform and Export:**
    Transform retained vertices back to world space using `scale_mat` and export the filtered mesh [S1, unofficial].

### Pseudocode

```python
import torch
import numpy as np

def mask_projection_culling(mesh, cameras, masks=None, depth_maps=None, 
                            threshold=20, eps=0.005, batch_size=500000):
    """
    Filter mesh vertices and faces based on multi-view visibility.
    
    Args:
        mesh: Object with .vertices (N, 3) and .faces (F, 3)
        cameras: List of dicts with 'w2c' (4,4), 'K' (3,3), 'W', 'H'
        masks: List of binary masks (H, W) or None
        depth_maps: List of depth maps (H, W) or None
        threshold: Minimum number of views a vertex must be visible in
        eps: Depth comparison tolerance
        batch_size: Number of vertices to process per batch
        
    Returns:
        Filtered mesh vertices and faces
    """
    N = mesh.vertices.shape[0]
    valid_counts = np.zeros(N, dtype=np.int32)
    
    # Convert vertices to homogeneous coordinates (N, 4)
    vertices_hom = np.hstack([mesh.vertices, np.ones((N, 1))])
    
    for cam in cameras:
        w2c = cam['w2c']
        K = cam['K']
        W = cam['W']
        H = cam['H']
        
        # Process in batches to limit memory
        for start in range(0, N, batch_size):
            end = min(start + batch_size, N)
            v_batch = vertices_hom[start:end] # (B, 4)
            
            # Transform to camera space
            # w2c is (4,4), v_batch is (B, 4). Result: (B, 4)
            v_cam = (w2c @ v_batch.T).T 
            
            # Project to 2D
            # K is (3,3), v_cam is (B, 4). Result: (B, 3)
            uv_hom = (K @ v_cam.T).T 
            
            z = uv_hom[:, 2:3] + 1e-6
            uv = uv_hom[:, :2] / z # (B, 2)
            
            # Check frustum bounds
            in_frustum = (uv[:, 0] >= 0) & (uv[:, 0] < W) & \
                         (uv[:, 1] >= 0) & (uv[:, 1] < H) & \
                         (z[:, 0] > 0)
            
            # Normalize to NDC [-1, 1] for grid sampling
            uv_ndc = torch.tensor(uv, dtype=torch.float32)
            uv_ndc[:, 0] = (uv_ndc[:, 0] / (W - 1)) * 2.0 - 1.0
            uv_ndc[:, 1] = (uv_ndc[:, 1] / (H - 1)) * 2.0 - 1.0
            
            # Reshape for grid_sample: (1, B, 1, 2)
            vgrid = uv_ndc.unsqueeze(0).unsqueeze(0)
            
            is_valid_view = torch.zeros(end - start, dtype=torch.bool)
            
            if masks is not None:
                # Mask variant
                # Note: In practice, masks should be dilated beforehand
                mask_tensor = torch.from_numpy(masks[cameras.index(cam)]).unsqueeze(0).unsqueeze(0).float()
                # Sample using nearest neighbor
                sampled = torch.nn.functional.grid_sample(
                    mask_tensor, vgrid, 
                    mode='nearest', padding_mode='zeros', align_corners=True
                )
                # sampled shape: (1, 1, B, 1)
                is_valid_view = sampled[0, 0, :, 0] > 0.0
            elif depth_maps is not None:
                # Depth variant
                depth_tensor = torch.from_numpy(depth_maps[cameras.index(cam)]).unsqueeze(0).unsqueeze(0).float()
                # Sample using bilinear interpolation with border padding
                sampled_depth = torch.nn.functional.grid_sample(
                    depth_tensor, vgrid, 
                    mode='bilinear', padding_mode='border', align_corners=True
                )
                # sampled_depth shape: (1, 1, B, 1)
                z_tensor = torch.from_numpy(z).float()
                # Check if point is in front of surface
                is_front = z_tensor[:, 0] < (sampled_depth[0, 0, :, 0] + eps)
                is_valid_view = is_front & in_frustum
            
            # Update counts for valid vertices in this batch
            valid_indices = start + torch.arange(end - start)[is_valid_view]
            valid_counts[valid_indices] += 1
            
    # Filter vertices
    valid_vertices_mask = valid_counts >= threshold
    valid_vertex_indices = np.where(valid_vertices_mask)[0]
    
    # Create mapping from old index to new index
    idx_map = {old: new for new, old in enumerate(valid_vertex_indices)}
    
    # Filter faces
    valid_faces_mask = np.all(np.isin(mesh.faces, valid_vertex_indices), axis=1)
    valid_faces = mesh.faces[valid_faces_mask]
    
    # Remap face indices
    valid_faces = np.vectorize(idx_map.get)(valid_faces)
    
    return mesh.vertices[valid_vertices_mask], valid_faces
```

### Parameters
*   `eps`: Depth comparison tolerance. Typical value: 0.005 [S2, unofficial].
*   `points_batch_size`: Maximum points per batch. Typical value: $5 \times 10^5$ [S2, unofficial].
*   `threshold`: Minimum number of views for visibility. Typical value: 20 [S2, unofficial].
*   `mask_dilation_radius`: Radius for binary mask dilation. Typical value: 24 [S1, unofficial].

### Edge Cases and Pitfalls
*   **Coordinate System Mismatch:** OpenCV and OpenGL conventions differ in Y and Z axes. Failure to flip $C2W[:3, 1:3] *= -1$ causes incorrect depth comparisons [S2, unofficial].
*   **Out-of-Bounds Sampling:** UV coordinates outside $[0, W] \times [0, H]$ can cause NaNs. Use `padding_mode='border'` in depth sampling [S2, unofficial].
*   **Precision Errors:** Use $\epsilon = 10^{-6}$ in homogeneous division to avoid division by zero [S1, unofficial].

## Subtopics

### True Back-Face Culling via Group Masking
A back-face culling technique that splits chunk meshes into 6 vertex pool buckets based on face orientation (groups 0-5). Draw calls are masked based on the camera position relative to the chunk, preventing the draw call from being issued entirely rather than culling in the fragment shader [S3, unofficial]. It is chosen when driver overhead must be minimized compared to splitting chunks into 6 sub-meshes [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \times V \times B)$, where $N$ is the number of points, $V$ is the number of validation frames, and $B$ is the batch size [S2, unofficial].
*   **Memory Complexity:** $O(N \times V)$ for intermediate masks and valid counts [S2, unofficial].
*   **Strengths:** Effectively removes noise and occluded geometry that adjacency-based methods might miss; robust to complex topology [S2, unofficial].
*   **Limitations:** Requires multiple camera views and depth maps; computationally expensive for large meshes due to per-vertex projection [S2, unofficial].
*   **When to Use:** Post-processing for meshes reconstructed from multi-view data (e.g., NeRF, Gaussian Splatting) where geometric consistency is critical [S1, unofficial][S2, unofficial].
*   **When Not to Use:** Real-time rendering with single-view data or when computational resources are severely limited [S2, unofficial].

## Background
Mask Projection Culling originated in the context of 3D Gaussian Splatting and differentiable rasterization pipelines, where mesh extraction from implicit or point-based representations requires rigorous visibility filtering to remove artifacts [S1, unofficial][S2, unofficial]. It is commonly used in modern neural rendering frameworks to clean up extracted meshes for downstream applications like texturing or physics simulation [S1, unofficial][S2, unofficial].
