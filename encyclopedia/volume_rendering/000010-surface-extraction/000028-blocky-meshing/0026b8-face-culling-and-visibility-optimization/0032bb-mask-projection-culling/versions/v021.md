# Mask Projection Culling

Also called: Depth-Projected Mesh Culling, Mesh Culling via Mask Projection, point mask culling

## Overview
Mask Projection Culling is a visibility-based mesh filtering technique that removes faces and vertices not consistently observed across multiple camera poses by projecting points into camera space and comparing their depth against rendered depth maps or binary masks [S1, S2, unofficial]. It differs from neighbor-based culling (e.g., [Face Culling](8735-face-culling.md)) by relying on external camera viewpoints rather than local voxel topology, and from back-face culling (e.g., [Voxel Backface Culling and Internal Face Masking](4569-voxel-backface-culling-and-internal-face-mask.md)) by filtering based on occlusion and frustum containment rather than surface normal orientation.

## How it works
The method filters a mesh by verifying that its geometry is visible in a set of reference views. It involves projecting 3D vertices into 2D image space, sampling depth or mask data from those views, and discarding geometry that fails visibility checks.

### Inputs and Outputs
*   **Input Mesh**: A triangle mesh defined by vertices $V \in \mathbb{R}^{N \times 3}$ and faces $F \in \mathbb{R}^{M \times 3}$.
*   **Camera Data**: A set of $V$ camera poses (world-to-camera or camera-to-world matrices) and intrinsic matrices $K$.
*   **Reference Data**: For each view, either a rendered depth map $D_i$ or a binary visibility mask $M_i$ of resolution $W \times H$.
*   **Output**: A filtered mesh containing only vertices and faces deemed visible.

### Data Structures
*   **Vertices**: $N \times 3$ float array.
*   **Faces**: $M \times 3$ integer array (indices into vertices).
*   **Depth Maps**: $V \times H \times W$ float array (or tensor).
*   **Masks**: $V \times H \times W$ float array (0.0 or 1.0).
*   **Visibility Count**: $N \times 1$ integer array, initialized to 0.

### Parameters
*   $W, H$: Image width and height (e.g., 1600, 1200) [S1, unofficial].
*   $\epsilon$: Depth comparison tolerance (e.g., 0.005) [S2, unofficial].
*   $B$: Points batch size (e.g., $5 \times 10^5$) to limit GPU memory [S2, unofficial].
*   $T_{count}$: Minimum visibility count threshold (e.g., 20) [S2, unofficial].
*   $R_{dilate}$: Mask dilation radius (e.g., 24 pixels) [S1, unofficial].

### Steps

1.  **Initialize Visibility**: Create an integer array `valid_counts` of size $N$, initialized to 0.
2.  **Iterate Views**: For each camera view $i$ from $0$ to $V-1$:
    a.  **Load Camera Data**: Retrieve the camera-to-world matrix $C2W_i$ and intrinsic matrix $K_i$.
    b.  **Coordinate Correction**: If using OpenGL conventions with OpenCV-derived data, flip the Y and Z axes of the camera pose to ensure correct depth comparison [S2, unofficial]:
        $$ C2W_i[:3, 1:3] *= -1 $$
    c.  **Compute World-to-Camera**: Calculate $W2C_i = C2W_i^{-1}$.
    d.  **Process Vertices in Batches**: Split vertices $V$ into batches of size $B$. For each batch:
        i.  **Transform to Camera Space**:
            $$ P_{cam} = W2C_i \times P_{world} $$
            where $P_{world}$ is the $4 \times N_{batch}$ homogeneous vertex matrix.
        ii. **Project to 2D**:
            $$ uv_{hom} = K_i \times P_{cam} $$
            $$ z = uv_{hom}[:, 2] + \epsilon $$
            $$ u = uv_{hom}[:, 0] / z $$
            $$ v = uv_{hom}[:, 1] / z $$
        iii. **Frustum Check**: Determine if points are within the image bounds and in front of the camera:
            $$ \text{in\_frustum} = (u \ge 0) \land (u \le W-1) \land (v \ge 0) \land (v \le H-1) \land (z > 0) $$
        iv. **Sample Reference Data**:
            *   *If using Masks*: Normalize UVs to NDC $[-1, 1]$ for grid sampling:
                $$ u_{ndc} = \frac{u}{W-1} \times 2 - 1 $$
                $$ v_{ndc} = \frac{v}{H-1} \times 2 - 1 $$
                Dilate the binary mask $M_i$ with a disk of radius $R_{dilate}$. Sample the dilated mask at $(u_{ndc}, v_{ndc})$ using nearest-neighbor interpolation with zero padding. Let the sampled value be $m_{sample}$.
            *   *If using Depth*: Normalize UVs to NDC $[-1, 1]$. Sample the depth map $D_i$ at $(u_{ndc}, v_{ndc})$ using bilinear interpolation with border padding. Let the sampled value be $d_{sample}$.
        v.  **Visibility Test**:
            *   *Mask Mode*: A point is valid if $m_{sample} > 0$.
            *   *Depth Mode*: A point is valid (front-facing) if $d_{sample} > 0$ AND $z < d_{sample} + \epsilon$.
        vi. **Update Counts**: For points passing the test and `in_frustum`, increment `valid_counts`.
3.  **Filter Mesh**:
    a.  Identify valid vertices: $V_{valid} = \{ v_j \mid \text{valid\_counts}[j] \ge T_{count} \}$.
    b.  Identify valid faces: A face $f_k = (v_a, v_b, v_c)$ is valid if all three vertices are in $V_{valid}$.
    c.  Construct the output mesh using $V_{valid}$ and the valid faces.
4.  **Post-Processing (Optional)**: Remove small disconnected components. Calculate the area of each connected component in the filtered mesh. Retain only components with area ratio $\ge T_{small}$ (e.g., 0.2) relative to the total mesh area [S2, unofficial].

### Pseudocode

```python
import torch
import numpy as np

def mask_projection_culling(mesh, cameras, reference_data, config):
    """
    mesh: dict with 'vertices' (N,3) and 'faces' (M,3)
    cameras: list of dicts with 'c2w' (4,4), 'K' (3,3)
    reference_data: list of dicts with 'depth' (H,W) or 'mask' (H,W)
    config: dict with W, H, eps, batch_size, threshold, dilate_radius
    """
    vertices = mesh['vertices']
    faces = mesh['faces']
    N = vertices.shape[0]
    
    # Initialize visibility counts
    valid_counts = np.zeros(N, dtype=np.int32)
    
    # Pre-calculate NDC scaling factors
    u_scale = 2.0 / (config['W'] - 1)
    v_scale = 2.0 / (config['H'] - 1)
    
    for i, cam in enumerate(cameras):
        # 1. Coordinate Correction (OpenGL/OpenCV mismatch)
        c2w = cam['c2w'].copy()
        c2w[:3, 1:3] *= -1
        
        # 2. World-to-Camera
        w2c = np.linalg.inv(c2w)
        K = cam['K']
        
        # 3. Process in batches
        for start in range(0, N, config['batch_size']):
            end = min(start + config['batch_size'], N)
            batch_verts = vertices[start:end]
            
            # Transform to homogeneous
            ones = np.ones((batch_verts.shape[0], 1))
            verts_homo = np.hstack([batch_verts, ones])
            
            # World to Camera
            cam_coords = (w2c @ verts_homo.T).T[:, :3]
            z = cam_coords[:, 2]
            
            # Project
            uv_hom = (K @ cam_coords.T).T
            z_safe = z + config['eps']
            u = uv_hom[:, 0] / z_safe
            v = uv_hom[:, 1] / z_safe
            
            # Frustum Check
            in_frustum = (u >= 0) & (u <= config['W']-1) & \
                         (v >= 0) & (v <= config['H']-1) & \
                         (z > 0)
            
            # Normalize to NDC [-1, 1] for grid sampling
            u_ndc = u * u_scale - 1.0
            v_ndc = v * v_scale - 1.0
            
            # Stack for grid_sample input (1, H, W, 2) -> we need (1, N, 2)
            # PyTorch grid_sample expects grid of shape (N, H_out, W_out, 2)
            # Here we sample at single points, so H_out=1, W_out=1
            grid = torch.stack([u_ndc, v_ndc], dim=-1).unsqueeze(0).unsqueeze(0).float()
            
            # Get reference data for this view
            ref = reference_data[i]
            
            if 'mask' in ref:
                # Mask Mode
                # Dilate mask (using scipy or similar in practice, simulated here)
                # mask_dilated = binary_dilation(ref['mask'], disk(config['dilate_radius']))
                # Convert to tensor
                mask_tensor = torch.from_numpy(ref['mask']).unsqueeze(0).unsqueeze(0).float()
                
                # Sample
                # padding_mode='zeros', mode='nearest'
                sampled = torch.nn.functional.grid_sample(
                    mask_tensor, grid, 
                    padding_mode='zeros', align_corners=True, mode='nearest'
                )
                # sampled shape: (1, 1, 1, 1) -> squeeze
                is_visible = sampled.squeeze() > 0.0
            else:
                # Depth Mode
                depth_tensor = torch.from_numpy(ref['depth']).unsqueeze(0).unsqueeze(0).float()
                
                # Sample
                # padding_mode='border', mode='bilinear'
                sampled_depth = torch.nn.functional.grid_sample(
                    depth_tensor, grid, 
                    padding_mode='border', align_corners=True, mode='bilinear'
                )
                d_sample = sampled_depth.squeeze()
                
                # Check if in front of surface
                # z is camera space depth (positive in front)
                is_visible = (d_sample > 0.0) & (z < (d_sample + config['eps']))
            
            # Combine frustum and visibility
            valid_mask = in_frustum & is_visible.cpu().numpy()
            
            # Update counts
            valid_counts[start:end] += valid_mask.astype(np.int32)
            
    # Filter
    valid_vertices_mask = valid_counts >= config['threshold']
    valid_vertex_indices = np.where(valid_vertices_mask)[0]
    
    # Map old indices to new indices
    index_map = np.full(N, -1, dtype=np.int32)
    index_map[valid_vertex_indices] = np.arange(len(valid_vertex_indices))
    
    # Filter faces
    valid_faces_mask = np.all(index_map[faces] != -1, axis=1)
    new_faces = index_map[faces[valid_faces_mask]]
    
    new_vertices = vertices[valid_vertices_mask]
    
    return {'vertices': new_vertices, 'faces': new_faces}
```

### Edge Cases and Pitfalls
*   **Coordinate System Mismatch**: OpenCV cameras often have Y-down, Z-forward, while OpenGL expects Y-up, Z-backward. Failing to flip axes leads to incorrect depth comparisons [S2, unofficial].
*   **Out-of-Bounds Sampling**: Projected points may fall outside $[0, W-1] \times [0, H-1]$. Using `padding_mode='border'` in grid sampling prevents NaNs or crashes for depth maps [S2, unofficial]. For masks, `padding_mode='zeros'` is appropriate to treat out-of-bounds as invisible.
*   **Precision Errors**: Small projection errors can cause points to fall just outside the frustum or behind the depth surface. The tolerance $\epsilon$ and mask dilation radius $R_{dilate}$ mitigate this [S1, S2, unofficial].
*   **Degenerate Input**: If a mesh has no vertices or faces, the algorithm should return an empty mesh immediately.

## Subtopics

### True Back-Face Culling via Group Masking
A back-face culling technique that splits chunk meshes into 6 vertex pool buckets based on face orientation (groups 0-5) [S3, unofficial]. Draw calls are masked based on the camera position relative to the chunk, preventing the draw call from being issued entirely rather than culling in the fragment shader [S3, unofficial]. It is chosen when driver overhead must be minimized compared to splitting chunks into 6 sub-meshes [S3, unofficial]. It sets itself apart by using existing vertex pool bucketing instead of creating new VBOs [S3, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N \cdot V \cdot B)$, where $N$ is the number of points, $V$ is the number of validation frames, and $B$ is the batch size [S2, unofficial].
*   **Memory Complexity**: $O(N \cdot V)$ for intermediate masks and valid counts [S2, unofficial].
*   **Strengths**: Effective at removing occluded geometry and background noise; robust to local topology errors; leverages GPU-accelerated grid sampling.
*   **Limitations**: Requires pre-existing camera poses and reference data (depth/masks); sensitive to coordinate system conventions; performance scales linearly with the number of views.
*   **When to Use**: When high-quality visibility filtering is needed for meshes derived from multi-view reconstruction (e.g., NeRF, Gaussian Splatting) and camera poses are available.
*   **When Not to Use**: When camera data is unavailable, or when real-time culling per frame is required without pre-computation (use [Voxel Backface Culling and Internal Face Masking](4569-voxel-backface-culling-and-internal-face-mask.md) instead).

## Background
Mask Projection Culling originates from the post-processing pipelines of differentiable rendering and 3D Gaussian Splatting frameworks, where it is used to clean up reconstructed meshes or point clouds by leveraging the training views [S1, S2, unofficial]. It is commonly found in implementations like 2D Gaussian Splatting [S1, unofficial] and SVRaster [S2, unofficial]. The technique relies on standard computer graphics projection mathematics and GPU texture sampling operations.
