# Mask Projection Culling

Also called: Depth-Projected Mesh Culling, Mesh Culling via Mask Projection, point mask culling

## Overview
Mask Projection Culling is a visibility-based mesh filtering technique that removes vertices and faces not consistently observed across multiple camera poses by projecting 3D points into camera space and comparing their depth against rendered depth maps or binary masks [S1, S2, unofficial]. It differs from sibling methods like [Face Coverage Mask Culling](3397-face-coverage-mask-culling.md) (which uses local voxel neighborhood checks) and [Block Visibility Culling](5334-block-visibility-culling.md) (which operates on block-level occupancy) by relying on global camera projection and depth validation to identify surface geometry visible from specific viewpoints [S1, S2, unofficial].

## How it works
**Inputs:**
- A 3D mesh (vertices $V$, faces $F$).
- A set of $V$ camera poses (world-to-camera matrices $W_i$) and intrinsic matrices $K_i$.
- Optional: Binary masks $M_i$ for each view (e.g., from segmentation) [S1, unofficial].
- Optional: Pre-rendered depth maps $D_i$ for each view [S2, unofficial].

**Outputs:**
- A filtered mesh containing only vertices and faces deemed visible in at least $T$ views (e.g., $T=20$) [S2, unofficial].

**Data Structures:**
- `valid_counts`: Array of size $N$ (number of vertices), initialized to 0.
- `face_mask`: Boolean array of size $|F|$.

**Steps:**

1. **Initialize Visibility Counts:**
   Create an integer array `valid_counts` of length $N$ (number of vertices), initialized to 0.

2. **Iterate Over Views:**
   For each view $i$ from $0$ to $V-1$:
   
   a. **Prepare Camera Matrices:**
      Compute the world-to-camera matrix $W_i$ (or $w2c_i$). If using OpenGL conventions with OpenCV data, flip Y and Z axes: $W_i[:3, 1:3] *= -1$ [S2, unofficial].
      
   b. **Project Vertices:**
      For each vertex $v_j \in V$ with world coordinates $\mathbf{p}_j$:
      - Transform to camera space: $\mathbf{p}_{cam} = W_i \cdot [\mathbf{p}_j, 1]^T$.
      - Project to 2D: $\mathbf{uv}_j = K_i \cdot \mathbf{p}_{cam}$.
      - Perform homogeneous division: $z_j = \mathbf{uv}_j[2] + \epsilon$, $\mathbf{uv}_{norm, j} = [\mathbf{uv}_j[0]/z_j, \mathbf{uv}_j[1]/z_j]$.
      - Check frustum bounds: $in\_frustum_j = (0 \le \mathbf{uv}_{norm, j}[0] < W) \land (0 \le \mathbf{uv}_{norm, j}[1] < H) \land (z_j > 0)$ [S2, unofficial].
      
   c. **Visibility Check (Mask or Depth):**
      *Option A: Mask Projection (from [S1, unofficial])*
      - Normalize $\mathbf{uv}_{norm, j}$ to NDC $[-1, 1]$: $\mathbf{uv}_{ndc, j} = (\mathbf{uv}_{norm, j} / [W-1, H-1]) \cdot 2 - 1$.
      - Sample binary mask $M_i$ at $\mathbf{uv}_{ndc, j}$ using nearest-neighbor interpolation with dilation (radius 24) applied to $M_i$ beforehand.
      - If sampled value $> 0$, mark vertex as potentially visible.
      
      *Option B: Depth Comparison (from [S2, unofficial])*
      - Normalize $\mathbf{uv}_{norm, j}$ to grid sampling range $[-1, 1]$: $\mathbf{vgrid}_j = (\mathbf{uv}_{norm, j} / [W-1, H-1]) \cdot 2 - 1$.
      - Sample depth map $D_i$ at $\mathbf{vgrid}_j$ using bilinear interpolation with border padding.
      - Compare depth: $is\_front_j = (z_j < \text{sampled\_depth}_j + \epsilon_{depth})$.
      - If $is\_front_j$ is true, mark vertex as potentially visible.
      
   d. **Accumulate Counts:**
      For each vertex $j$ marked visible in view $i$, increment `valid_counts[j]`.

3. **Filter Vertices:**
   Create a boolean mask `valid_vertices` where `valid_vertices[j] = (valid_counts[j] >= T)`.

4. **Filter Faces:**
   For each face $f_k = (v_a, v_b, v_c)$:
   - `face_mask[k] = valid_vertices[a] \land valid_vertices[b] \land valid_vertices[c]`.

5. **Reconstruct Mesh:**
   - Keep only vertices where `valid_vertices` is true.
   - Keep only faces where `face_mask` is true.
   - Re-index vertices and faces.
   - Transform vertices back to world space if they were scaled during projection (e.g., undo `scale_mat`) [S1, unofficial].

**Parameters:**
- $\epsilon_{depth}$: Depth comparison tolerance. Typical value: 0.005 [S2, unofficial].
- $T$: Minimum number of views a vertex must be visible in. Typical value: 20 [S2, unofficial].
- `points_batch_size`: Max points processed per batch to limit GPU memory. Typical value: $5 \times 10^5$ [S2, unofficial].
- `remove_small_geometry_threshold`: Minimum area ratio for connected components to retain. Typical value: 0.2 [S2, unofficial].

**Pitfalls:**
- **Coordinate System Mismatch:** OpenCV and OpenGL conventions differ in Y/Z axis direction. Failure to flip axes causes incorrect depth comparisons [S2, unofficial].
- **Out-of-Bounds Sampling:** UV coordinates outside $[0, W] \times [0, H]$ cause NaNs. Use `padding_mode='border'` in grid sampling [S2, unofficial].
- **Precision Errors:** Use a small epsilon ($\epsilon$) in homogeneous division and depth comparison to avoid floating-point inaccuracies [S2, unofficial].

## Subtopics

### True Back-Face Culling via Group Masking
A back-face culling technique that splits chunk meshes into 6 vertex pool buckets based on face orientation (groups 0-5). Draw calls are masked based on camera position relative to the chunk, preventing the draw call from being issued entirely rather than culling in the fragment shader [S3, unofficial]. It uses the existing vertex pool bucketing, avoiding the 6-fold driver overhead increase associated with splitting chunks into 6 sub-meshes [S3, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N \cdot V \cdot B)$, where $N$ is the number of points, $V$ is the number of validation frames, and $B$ is the batch size [S2, unofficial].
- **Memory Complexity:** $O(N \cdot V)$ for intermediate masks and valid counts [S2, unofficial].
- **Strengths:** Effectively removes noise and non-visible geometry from reconstructed meshes; robust to partial occlusions by requiring visibility across multiple views [S1, S2, unofficial].
- **Limitations:** Requires pre-existing camera poses and depth maps/masks; computationally expensive for large meshes due to per-vertex projection and sampling [S2, unofficial].
- **When to Use:** Post-processing reconstructed meshes from NeRF or Gaussian Splatting pipelines where camera poses are known [S1, S2, unofficial].
- **When Not to Use:** Real-time rendering where per-frame culling is needed (use [Voxel Backface Culling](4569-voxel-backface-culling.md) or [True Back-Face Culling](#true-back-face-culling-via-group-masking) instead) [S3, unofficial].

## Background
Mask Projection Culling originated in the context of 3D Gaussian Splatting and NeRF-based reconstruction pipelines, specifically within the 2D Gaussian Splatting framework [S1, unofficial]. It was adapted for mesh extraction from volumetric or point-based representations to clean up noisy geometry by leveraging multi-view consistency [S2, unofficial]. The method relies on standard computer vision techniques of projective geometry and depth sampling [S1, S2, unofficial].
