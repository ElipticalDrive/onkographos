# VoxelBlockyModelMesh


## Overview
VoxelBlockyModelMesh generates a voxel model from a custom 3D mesh rather than requiring primitive cubes, allowing versatile model creation using standard 3D editor meshes with UV-mapping [S1]. It differs from [Cuberille Method](1718-cuberille-method.md) by accepting arbitrary triangulated geometry confined to a unit bounding box, and from [Greedy Meshing](8935-greedy-face-merging.md) by focusing on per-voxel side culling and cutouts rather than global face merging [S1].

## How it works
**Inputs:**
- `mesh`: A non-empty, indexed triangle mesh object [S1].
- `mesh_ortho_rotation_index`: Integer specifying orthogonal rotation during baking (GridMap tile convention) [S1].
- `side_cutout_enabled`: Boolean flag for occlusion-based side cutting [S1].
- `side_vertex_tolerance`: Float margin for side classification (default 0.001) [S1].

**Outputs:**
- A voxel model data structure compatible with the VoxelBlockyModel hierarchy [S1].

**Data Structures:**
The source mesh must be indexed and consist of triangles [S1]. The mesh is expected to be confined within a bounding box from $(0,0,0)$ to $(1,1,1)$ [S1].

**Steps:**
1. **Validation**: Ensure `mesh` is not empty and is indexed (e.g., via `SurfaceTool.index`) [S1]. If the mesh has more than 2 surfaces (materials), all surfaces after the second are ignored [S1].
2. **Rotation**: Apply the orthogonal rotation specified by `mesh_ortho_rotation_index` to the mesh geometry [S1].
3. **Side Classification**: For each triangle in the mesh, determine if it lies on one of the 6 sides of the unit cubic area. A triangle is considered to be on a specific side if its vertices are within `side_vertex_tolerance` of that side's plane [S1]. Only triangles on the sides of the cubic area are used for neighbor side culling [S1].
4. **Culling/Cutout**: If `side_cutout_enabled` is true, check for occlusion from neighbor voxels. If a neighbor voxel partially covers a side of the current voxel, the occluded geometry on that side is cut away [S1]. This optimization only functions if the shape of both interacting sides is a rectangle [S1].
5. **Generation**: Generate the voxel model using the processed geometry [S1].

**Pseudocode:**
```python

    # Step 1: Validation
    if mesh is empty:
        raise Error("Mesh must not be empty")
    if not mesh.is_indexed():
        mesh = mesh.index() # Ensure indexed
    if mesh.num_surfaces() > 2:
        # Ignore surfaces after the second
        mesh = mesh.slice_surfaces(0, 2)
    
    # Step 2: Rotation
    # Apply orthogonal rotation based on GridMap tile convention
    rotated_mesh = apply_orthogonal_rotation(mesh, mesh_ortho_rotation_index)
    
    # Step 3: Side Classification
    # Identify triangles on the 6 sides of the unit cube (0..1)
    side_triangles = {}
    for triangle in rotated_mesh.triangles:
        for side in [LEFT, RIGHT, BOTTOM, TOP, FRONT, BACK]:
            if is_triangle_on_side(triangle, side, side_vertex_tolerance):
                side_triangles.setdefault(side, []).append(triangle)
    
    # Step 4: Culling/Cutout
    if side_cutout_enabled:
        # Cut away occluded geometry if neighbor partially covers side
        # Only works if side shapes are rectangles
        for side, triangles in side_triangles.items():
            neighbor_side = get_opposite_side(side)
            if neighbor_side in side_triangles:
                cutout_geometry = compute_occlusion_cutout(triangles, side_triangles[neighbor_side])
                triangles = apply_cutout(triangles, cutout_geometry)
                side_triangles[side] = triangles
    
    # Step 5: Generation
    # Combine processed triangles into voxel model
    voxel_model = VoxelBlockyModel()
    voxel_model.add_geometry(side_triangles)
    return voxel_model
```
