# Greedy Meshing / Face Culling

Also called: Face culling meshing, Face-based Meshing, Block Mesh Generation, Voxel Face Generation, Block Surface Extraction, Voxel Surface Extraction

## Overview
Greedy Meshing / Face Culling generates a static triangle mesh for a voxel chunk by iterating through occupied voxel positions and emitting geometry only for faces that are adjacent to empty space or transparent blocks [S1, S3, S5, unofficial]. It builds on [Greedy face merging](8935-greedy-face-merging.md) by sweeping the volume along principal axes, checking face visibility against neighbors, and greedily expanding exposed faces into maximal quads. This approach reduces vertex count and draw calls compared to naive voxel rendering by excluding internal faces [S1, S3, unofficial].

## How it works
**Inputs:**
- A voxel volume defined by a function `volume(x, y, z)` returning a material ID or boolean occupancy [G].
- Dimensions `dims = (Dx, Dy, Dz)` [G].
- Boundary policy: `"air"` (out-of-bounds neighbors are empty, exposing faces) or `"solid"` (out-of-bounds neighbors are solid, hiding faces) [G].
- Optional merge key function `merge_key(material_id, x, y, z)` returning an integer identifier for grouping [G]. If not provided, defaults to identity [G].

**Outputs:**
- A list of quads, each defined by an origin `(x, y, z)`, a normal `n \in \{0, 1, 2\}`, and dimensions `(w, h)` [G].

**Data Structures:**
- `mask`: A 2D array of size $D_t \times D_b$ (where $t, b$ are tangent and bitangent axes). Stores the `merge_key` if the face is visible and unprocessed, otherwise $0$ [G].

**Steps:**
1. **Iterate Normals:** Loop over the three principal axes $n \in \{0, 1, 2\}$ (X, Y, Z) [G].
2. **Define Axes:** For each normal $n$, compute tangent $t = (n + 1) \pmod 3$ and bitangent $b = (n + 2) \pmod 3$ [G].
3. **Sweep Slices:** Iterate through each slice index $s$ along the normal axis $n$ from $0$ to $D_n - 1$ [G].
4. **Build Visibility Mask:** For each cell $(t, b)$ in the slice, determine coordinates $(x, y, z)$ corresponding to axes $t, b, n$ [G]. Check neighbors in the normal direction $n \pm 1$ [G]. A face is **exposed** if the neighbor voxel has a different material ID, or the neighbor is out of bounds and `boundary_policy` is `"air"` [G]. If exposed, set `mask[b * D_t + t] = merge_key(voxel_val, x, y, z)` [G]. Otherwise, set to $0$ [G].
5. **Greedy Expansion:** Scan the 2D mask in lexicographic order (row $b$ from $0$ to $D_b-1$, column $t$ from $0$ to $D_t-1$) [G]. Find the first unprocessed non-zero cell $(t_0, b_0)$ with key $K$ [G]. **Expand Width:** Increment $w$ while $t_0 + w < D_t$ and `mask[b_0 * D_t + (t_0 + w)] == K` [G]. **Expand Height:** Increment $h$ while $b_0 + h < D_b$ and all cells in the rectangle $[t_0, t_0 + w) \times [b_0, b_0 + h)$ have key $K$ [G]. **Emit Quad:** Create a quad with origin $(t_0, b_0, s)$, normal $n$, width $w$, height $h$ [G]. **Mark Processed:** Set all cells in the rectangle $[t_0, t_0 + w) \times [b_0, b_0 + h)$ in the mask to $0$ [G].

**Pseudocode:**
```python
def greedy_face_merge(volume, dims, boundary_policy="air", merge_key=None):
    """
    volume: function (x, y, z) -> material_id
    dims: tuple (Dx, Dy, Dz)
    boundary_policy: "air" (default) or "solid"
    merge_key: function (material_id, x, y, z) -> int. Default: identity.
    """
    if merge_key is None:
        merge_key = lambda m, x, y, z: m

    quads = []
    # Iterate over the 3 normal axes: 0=X, 1=Y, 2=Z
    for n in range(3):
        t = (n + 1) % 3  # Tangent axis
        b = (n + 2) % 3  # Bitangent axis
        dim_t, dim_b, dim_n = dims[t], dims[b], dims[n]
        
        # Mask stores the merge key if visible and unprocessed, else 0
        mask = [0] * (dim_t * dim_b)
        
        # Iterate through each slice along the normal axis
        for s in range(dim_n):
            # 1. Build Visibility Mask for slice s
            for y in range(dim_b):
                for x in range(dim_t):
                    coords = [0, 0, 0]
                    coords[n] = s
                    coords[t] = x
                    coords[b] = y
                    voxel_val = volume(*coords)
                    
                    exposed = False
                    # Check both neighbors along the normal axis
                    for dir in [-1, 1]:
                        nb_s = s + dir
                        if 0 <= nb_s < dim_n:
                            nb_coords = coords.copy()
                            nb_coords[n] = nb_s
                            nb_val = volume(*nb_coords)
                            if voxel_val != nb_val:
                                exposed = True
                                break
                        else:
                            # Out of bounds neighbor
                            if boundary_policy == "air":
                                exposed = True  # Air neighbor implies exposed face
                                break
                            else:  # solid
                                exposed = False  # Solid neighbor implies internal
                                break
                    
                    if exposed:
                        mask[y * dim_t + x] = merge_key(voxel_val, *coords)
                    else:
                        mask[y * dim_t + x] = 0

            # 2. Greedy Expansion on the 2D Mask
            for y in range(dim_b):
                for x in range(dim_t):
                    idx = y * dim_t + x
                    key = mask[idx]
                    
                    if key == 0:
                        continue
                    
                    # Start of a new quad
                    w = 1
                    # Expand width
                    while x + w < dim_t and mask[y * dim_t + (x + w)] == key:
                        w += 1
                    
                    h = 1
                    # Expand height
                    while y + h < dim_b:
                        row_match = True
                        for k in range(w):
                            if mask[(y + h) * dim_t + (x + k)] != key:
                                row_match = False
                                break
                        if not row_match:
                            break
                        h += 1
                    
                    # Emit Quad
                    origin = [0, 0, 0]
                    origin[n] = s
                    origin[t] = x
                    origin[b] = y
                    quads.append({
                        'origin': origin,
                        'normal': n,
                        'width': w,
                        'height': h
                    })
                    
                    # Mark cells as processed (set to 0)
                    for dy in range(h):
                        for dx in range(w):
                            mask[(y + dy) * dim_t + (x + dx)] = 0
                            
    return quads
```

## Subtopics

### [Visible Block Face Meshing](4919-visible-block-face-meshing.md)
Visible Block Face Meshing is a surface extraction technique that generates a static triangle mesh for a voxel chunk by iterating through occupied voxel positions and emitting geometry only for faces that are adjacent to empty space or transparent blocks. It differs from its parent method, [Voxel Chunk Mesh Generation (Face Culling)](4888-voxel-chunk-mesh-generation-face-culling.md), by explicitly handling cross-chunk boundary visibility checks to ensure global consistency, and it differs from [Greedy Meshing](52-greedy-meshing.md) by not merging adjacent coplanar faces into larger quads. This approach reduces vertex count and draw calls compared to naive voxel rendering by excluding internal faces.

### [Voxel Mesh Synthesis](5424-voxel-mesh-synthesis.md)
Voxel Mesh Synthesis is a post-processing step that converts validated leaf voxels from an octree into standard 3D cube meshes for export. It differs from its parent, Greedy Meshing, by generating individual cube geometry rather than merging adjacent faces into larger quads or blocks. It serves as a bridge between volumetric data structures and standard polygonal formats like Wavefront .obj.

### [Chunk Mesh Generation](8755-chunk-mesh-generation.md)
Chunk Mesh Generation creates a single vertex buffer for a voxel chunk by iterating through its voxels and generating geometry only for faces exposed to air or transparent blocks. It reduces draw calls by batching all visible faces of a chunk into one mesh, differing from instancing which draws individual block instances. It serves as the foundational geometry step before greedy face merging [Greedy Meshing / Face Culling](8783-greedy-meshing-face-culling.md).

### [Chunk Loading and Mesh Generation](8774-chunk-loading-and-mesh-generation.md)
This method manages the lifecycle of voxel chunk geometry by loading chunk data, generating its mesh, and caching GPU resources for rendering. It solves the problem of efficiently updating visible geometry when chunks are first accessed or when their content changes, ensuring only non-empty chunks are rendered. It builds on [Greedy Meshing / Face Culling](8783-greedy-meshing-face-culling.md) for triangle generation.
