# Chunk Mesh Preparation

Also called: Greedy Meshed Geometry Generation for Chunk Faces, Greedy Meshing for Opaque Blocks, Padded Chunk Preparation

## Overview
Chunk Mesh Preparation prepares a 3D voxel chunk for surface extraction by constructing a padded volume that incorporates neighbor data, enabling correct visibility culling across chunk boundaries [S1, S3, unofficial]. It solves the problem of boundary artifacts in greedy meshing by ensuring that the 1-voxel border around the chunk accurately reflects the material properties of adjacent chunks [S1, unofficial]. Unlike naive per-block meshing, this method specifically structures the input data for the subsequent greedy merge step, which targets maximal rectangular merging of opaque faces to minimize rendering overhead [S2, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** The current chunk's voxel data (size $S_X \times S_Y \times S_Z$), and the six face specifications (voxel arrays) from neighboring chunks.
- **Output:** A `PaddedChunk` array of size `PADDED_CHUNK_VOLUME` and a `FPreparedChunkMesh` structure containing chunk metadata and section references [S1, S3, unofficial].

**Data Structures:**
1.  **`VoxelBlock`**: An enum representing voxel content:
    -   `Opaque(MappedBlockID)`: Solid blocks.
    -   `Translucent(MappedBlockID)`: Glass, leaves, water, etc.
    -   `Empty`: Air or void.
    -   Visibility is derived via `VoxelVisibility` enum (`Empty`, `Translucent`, `Opaque`) [S1, unofficial].
2.  **`PaddedChunk`**: A 1D array of `VoxelBlock` with total size `PADDED_CHUNK_VOLUME`. The inner chunk (original voxels) is offset by +1 in all dimensions (indices 1 to `CHUNK_SIZE`). The outer layer (indices 0 and `CHUNK_SIZE+1`) contains neighbor face data [S1, unofficial].
3.  **`FPreparedChunkMesh`**: Struct with fields `ChunkIndex` (int32), `SizeX` (int32), `SizeY` (int32), `Sections` (map of block type to mesh section), and `CollisionSection` [S3, unofficial].

**Algorithm Steps:**

1.  **Initialize Padded Volume:**
    Create a `PaddedChunk` array of size `PADDED_CHUNK_VOLUME` and fill all entries with `VoxelBlock::Empty` [S1, unofficial].

2.  **Populate Neighbor Padding:**
    Iterate over all six directions (`Direction::iter()`). For each direction, determine the face specification and the corresponding neighbor face data [S1, unofficial].
    -   For each direction, iterate the two in-plane axes ($u, v$) from 0 to `CHUNK_SIZE`.
    -   Calculate the face index and the padded linear index using `padded_linearize(padded_coords(spec, u, v))` [S1, unofficial].
    -   Assign the voxel from the neighboring face to the padded array at this index. If a neighbor face is empty, the padding remains `Empty` [S1, unofficial].
    -   **Iteration Orders:**
        -   `xPos` / `xNeg`: $l_x \to l_z \to y$ [S1, S2, unofficial].
        -   `yPos` / `yNeg`: $y \to l_x \to l_z$ [S1, S2, unofficial].
        -   `zPos` / `zNeg`: $l_z \to l_x \to y$ [S1, S2, unofficial].

3.  **Populate Inner Chunk:**
    Iterate over the chunk voxels $b_x, b_y, b_z$ from 0 to `CHUNK_SIZE` [S1, unofficial].
    -   Retrieve the block from the chunk.
    -   If the block is `Some(mapped_id)`, calculate the padded index by offsetting coordinates by +1 ($b_x + 1$, etc.) and linearizing.
    -   Map the non-empty block using `map_non_empty(mapped_id, checker)` and assign it to the padded array at the calculated index [S1, unofficial].

4.  **Generate Face Masks and Prepare for Greedy Meshing:**
    For each of the six faces, create a visibility mask and prepare parameters for the `GreedyMeshSlice` function [S3, unofficial]. The visibility logic determines if a face between two voxels should be meshed based on `VoxelVisibility` [S1, unofficial].
    -   **+Z Face (Top):** Mask size $S_X \times S_Y$. Iterate $Z$ from 0 to $S_Z$. For each $Z$, iterate $Y$ then $X$. Set visibility if block is not Air and neighbor at $Z+1$ is opaque. Call `GreedyMeshSlice` with `AxisU=X`, `AxisV=Y`, `Normal=+Z`, Origin offset $(Z+1) \times S$ [S3, unofficial].
    -   **-Z Face (Bottom):** Mask size $S_Y \times S_X$. Iterate $Z$ from 0 to $S_Z$. For each $Z$, iterate $X$ then $Y$. Set visibility if block is not Air and neighbor at $Z-1$ is opaque. Call `GreedyMeshSlice` with `AxisU=Y`, `AxisV=X`, `Normal=-Z`, Origin offset $Z \times S$ [S3, unofficial].
    -   **+X Face (Right):** Mask size $S_Y \times S_Z$. Iterate $X$ from 0 to $S_X$. For each $X$, iterate $Z$ then $Y$. Set visibility if block is not Air and neighbor at $X+1$ is opaque. Call `GreedyMeshSlice` with `AxisU=Y`, `AxisV=Z`, `Normal=+X`, Origin offset $(X+1) \times S$ [S3, unofficial].
    -   **-X Face (Left):** Mask size $S_Z \times S_Y$. Iterate $X$ from 0 to $S_X$. For each $X$, iterate $Y$ then $Z$. Set visibility if block is not Air and neighbor at $X-1$ is opaque. Call `GreedyMeshSlice` with `AxisU=Z`, `AxisV=Y`, `Normal=-X`, Origin offset $X \times S$ [S3, unofficial].
    -   **+Y Face (Front/Top):** Mask size $S_Z \times S_X$. Iterate $Y$ from 0 to $S_Y$. For each $Y$, iterate $X$ then $Z$. Set visibility if block is not Air and neighbor at $Y+1$ is opaque. Call `GreedyMeshSlice` with `AxisU=Z`, `AxisV=X`, `Normal=+Y`, Origin offset $(Y+1) \times S$ [S3, unofficial].
    -   **-Y Face (Back/Bottom):** Mask size $S_X \times S_Z$. Iterate $Y$ from 0 to $S_Y$. For each $Y$, iterate $Z$ then $X$. Set visibility if block is not Air and neighbor at $Y-1$ is opaque. Call `GreedyMeshSlice` with `AxisU=X`, `AxisV=Z`, `Normal=-Y`, Origin offset $Y \times S$ [S3, unofficial].

**Pseudocode:**

```python
def prepare_chunk_mesh(chunk_data, neighbor_faces, chunk_size_x, chunk_size_y, chunk_size_z):
    """
    Prepares a padded chunk for greedy meshing.
    
    Args:
        chunk_data: 3D array of VoxelBlock (size X, Y, Z)
        neighbor_faces: Dict mapping Direction to 2D array of VoxelBlock
        chunk_size_x, chunk_size_y, chunk_size_z: Dimensions of the chunk
        
    Returns:
        padded_chunk: 1D array of VoxelBlock
        prepared_mesh: FPreparedChunkMesh struct
    """
    # Constants
    PADDED_CHUNK_VOLUME = (chunk_size_x + 2) * (chunk_size_y + 2) * (chunk_size_z + 2)
    
    # Step 1: Initialize Padded Volume
    padded_chunk = [VoxelBlock.Empty] * PADDED_CHUNK_VOLUME
    
    # Helper to linearize padded coordinates
    def padded_linearize(x, y, z):
        return x + y * (chunk_size_x + 2) + z * (chunk_size_x + 2) * (chunk_size_y + 2)
    
    # Step 2: Populate Neighbor Padding
    # Directions: +X, -X, +Y, -Y, +Z, -Z
    # For each direction, we fill the 1-voxel border corresponding to that face
    directions = [
        (1, 0, 0, 'xPos'), (-1, 0, 0, 'xNeg'),
        (0, 1, 0, 'yPos'), (0, -1, 0, 'yNeg'),
        (0, 0, 1, 'zPos'), (0, 0, -1, 'zNeg')
    ]
    
    for dx, dy, dz, face_name in directions:
        neighbor_data = neighbor_faces.get(face_name)
        if neighbor_data is None:
            continue
            
        # Determine iteration order based on face normal
        # xPos/xNeg: lx -> lz -> y (Note: lx is the axis along the face plane, 
        # but the note says lx->lz->y. Let's map to standard axes.
        # For +X face (normal 1,0,0), the face plane is YZ. 
        # The note says "lx -> lz -> y". This likely refers to the specific 
        # implementation's loop order for the 2D slice.
        # We will follow the note's explicit iteration orders for filling the border.
        
        if face_name in ['xPos', 'xNeg']:
            # Iterate lx -> lz -> y. Assuming lx corresponds to Z and lz to Y? 
            # Or lx is the primary axis of the face? 
            # Note says: "For xPos and xNeg faces, the iteration order is lx -> lz -> y."
            # Let's assume standard mapping: 
            # The face is at X=0 or X=SX+1. The coordinates on the face are Y and Z.
            # The note's "lx" might be a typo for "lz" or specific to the source.
            # However, S1 says "lx -> lz -> y". S2 says "y -> lx -> lz" for Y faces.
            # Let's stick to the explicit coordinate loops described in S3 for clarity.
            pass # Handled by specific face logic below for precision
        
        # Specific face filling logic based on S3 and S1
        if face_name == 'zPos':
            # Top face: Z = SZ + 1. Plane is X-Y.
            # Mask size SX * SY.
            for z in range(chunk_size_z + 1, chunk_size_z + 2): # Border layer
                for y in range(chunk_size_y):
                    for x in range(chunk_size_x):
                        # Neighbor data for +Z face is at Z-1 of neighbor chunk?
                        # Or simply the face data provided.
                        # S1 says: "Assign the voxel from the neighboring face"
                        # We need to map (x,y) in the face to the neighbor's data.
                        # Assuming neighbor_faces['zPos'] is a 2D array [Y][X] or [X][Y]
                        # Let's assume standard row-major [Y][X] for simplicity, 
                        # but S3 says "Iterate Y then X".
                        voxel = neighbor_data[y][x] # Placeholder for actual indexing
                        idx = padded_linearize(x + 1, y + 1, chunk_size_z + 1)
                        padded_chunk[idx] = voxel
                        
        elif face_name == 'zNeg':
            # Bottom face: Z = 0. Plane is X-Y.
            for y in range(chunk_size_y):
                for x in range(chunk_size_x):
                    voxel = neighbor_data[y][x]
                    idx = padded_linearize(x + 1, y + 1, 0)
                    padded_chunk[idx] = voxel
                    
        elif face_name == 'xPos':
            # Right face: X = SX + 1. Plane is Y-Z.
            # S3: Iterate X from 0 to SX (this is for visibility mask generation, 
            # not padding fill). For padding fill, we just copy the face.
            # S1: "Iterate u and v from 0 to CHUNK_SIZE".
            # For +X face, u=Y, v=Z.
            for y in range(chunk_size_y):
                for z in range(chunk_size_z):
                    voxel = neighbor_data[y][z]
                    idx = padded_linearize(chunk_size_x + 1, y + 1, z + 1)
                    padded_chunk[idx] = voxel
                    
        elif face_name == 'xNeg':
            # Left face: X = 0. Plane is Y-Z.
            for y in range(chunk_size_y):
                for z in range(chunk_size_z):
                    voxel = neighbor_data[y][z]
                    idx = padded_linearize(0, y + 1, z + 1)
                    padded_chunk[idx] = voxel
                    
        elif face_name == 'yPos':
            # Front/Top face: Y = SY + 1. Plane is X-Z.
            for x in range(chunk_size_x):
                for z in range(chunk_size_z):
                    voxel = neighbor_data[x][z]
                    idx = padded_linearize(x + 1, chunk_size_y + 1, z + 1)
                    padded_chunk[idx] = voxel
                    
        elif face_name == 'yNeg':
            # Back/Bottom face: Y = 0. Plane is X-Z.
            for x in range(chunk_size_x):
                for z in range(chunk_size_z):
                    voxel = neighbor_data[x][z]
                    idx = padded_linearize(x + 1, 0, z + 1)
                    padded_chunk[idx] = voxel

    # Step 3: Populate Inner Chunk
    for bz in range(chunk_size_z):
        for by in range(chunk_size_y):
            for bx in range(chunk_size_x):
                block = chunk_data[bx][by][bz]
                if block != VoxelBlock.Empty:
                    # Map non-empty block
                    mapped_id = block.id # Assuming MappedBlockID
                    mapped_block = map_non_empty(mapped_id, checker)
                    idx = padded_linearize(bx + 1, by + 1, bz + 1)
                    padded_chunk[idx] = mapped_block

    # Step 4: Prepare for Greedy Meshing (Visibility Masks)
    # This step generates the masks and calls GreedyMeshSlice.
    # The actual mesh generation is done in the next step (Greedy Merge).
    # Here we just ensure the padded chunk is ready.
    
    prepared_mesh = FPreparedChunkMesh(
        ChunkIndex=0,
        SizeX=chunk_size_x,
        SizeY=chunk_size_y,
        Sections={},
        CollisionSection=None
    )
    
    return padded_chunk, prepared_mesh
```

**Parameters:**
-   `PADDED_CHUNK_VOLUME`: Total volume of the padded array, including the 1-voxel border [S1, unofficial].
-   `Quad.width` and `Quad.height`: In the output of the subsequent greedy merge, these represent the dimensions of the merged rectangle, not always 1 [S2, unofficial].

**Edge Cases and Pitfalls:**
-   Neighbor faces must be provided for all six directions to correctly fill the 1-voxel padding. If a neighbor face is empty, the corresponding padding voxels remain `Empty` [S1, unofficial].
-   Transparent solids (glass, leaves), water, fluids, and plants are NOT merged. They are output as 1x1 primitives to preserve draw order and cell-specific attributes [S2, unofficial].

## Subtopics

### [Chunk Meshing with Greedy Merge](4470-chunk-meshing-with-greedy-merge.md)
Generates optimized geometry by merging adjacent coplanar faces of identical texture into maximal rectangles. It specifically targets opaque faces to minimize rendering overhead, unlike sibling methods that may use quad expansion or simple culling.

## Operating characteristics
-   **Time Complexity:** Greedy meshing is slower than naive face extraction, taking 1.16-1.47x wall-clock time [S2, unofficial]. It trades computation time for triangle count reduction.
-   **Memory Complexity:** Requires `PADDED_CHUNK_VOLUME` storage for the padded array, which is $(S_X+2)(S_Y+2)(S_Z+2)$ voxels [S1, unofficial].
-   **Performance:** Quad reduction results vary by shape: flat shapes achieve -99.8% reduction (4,608 → 10 quads), rolling shapes -82.7% (5,558 → 960 quads), and checkerboard patterns 0.0% reduction [S2, unofficial].
-   **Strengths:** Significantly reduces vertex count and draw calls for large flat surfaces.
-   **Limitations:** Higher computational cost per chunk compared to naive meshing; ineffective for high-frequency noise (checkerboard).

## Background
The method is implemented in various voxel world engines, including `infinigen` [S1, unofficial], `mc-meshing` [S2, unofficial], and `VoxelWorld` [S3, unofficial]. It is a standard preprocessing step for greedy meshing algorithms in voxel-based games and simulations.
