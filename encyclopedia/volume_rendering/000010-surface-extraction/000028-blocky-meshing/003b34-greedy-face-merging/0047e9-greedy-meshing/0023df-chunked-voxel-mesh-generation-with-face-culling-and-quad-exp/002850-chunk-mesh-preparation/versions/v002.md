# Chunk Mesh Preparation

Also called: Greedy Meshed Geometry Generation for Chunk Faces, Greedy Meshing for Opaque Blocks, Padded Chunk Preparation

## Overview
Chunk Mesh Preparation prepares a 3D voxel chunk for surface extraction by constructing a padded volume that incorporates data from neighboring chunks [S1, S3, unofficial]. This padding ensures that visibility culling at chunk boundaries is correct, allowing the subsequent greedy meshing algorithm to merge coplanar faces across chunk edges without artifacts [S1, S3, unofficial]. It differs from naive face extraction by explicitly handling neighbor dependencies to enable maximal rectangle merging, trading increased preparation time for significant triangle count reduction [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** The current chunk's voxel data, neighbor face data for all six directions, and configuration parameters (chunk dimensions, block visibility rules) [S1, unofficial].
*   **Output:** A `PaddedChunk` array and a `FPreparedChunkMesh` structure containing the mesh sections for each block type and a collision section [S3, unofficial].

**Data Structures:**
*   `VoxelBlock`: An enum representing voxel content.
    *   `Opaque(MappedBlockID)`: Solid, non-transparent block.
    *   `Translucent(MappedBlockID)`: Transparent block (e.g., glass, leaves).
    *   `Empty`: Air or void [S1, unofficial].
*   `PaddedChunk`: A 1D array of `VoxelBlock` with size `PADDED_CHUNK_VOLUME`. The original chunk voxels are offset by +1 in all dimensions (indices 1 to `CHUNK_SIZE`). The outer layer (indices 0 and `CHUNK_SIZE + 1`) contains the neighbor face data [S1, unofficial].
*   `FPreparedChunkMesh`:
    *   `ChunkIndex`: `int32`
    *   `SizeX`: `int32`
    *   `SizeY`: `int32`
    *   `Sections`: Map of `EBlockType` to `FChunkMeshSection`
    *   `CollisionSection`: `FChunkMeshSection` [S3, unofficial]

**Steps:**

1.  **Initialize Padded Volume:** Create a `PaddedChunk` array of size `PADDED_CHUNK_VOLUME` filled with `VoxelBlock::Empty` [S1, unofficial].
2.  **Fill Inner Chunk:** Iterate through all voxels `(bx, by, bz)` in the original chunk (0 to `CHUNK_SIZE`). If a voxel is `Some(mapped_id)`, calculate its padded index by offsetting coordinates by +1 (`bx + 1`, etc.) and linearizing. Map the block using `map_non_empty(mapped_id, checker)` and assign it to the padded array at the calculated index [S1, unofficial].
3.  **Fill Neighbor Padding:** For each of the six face directions (`Direction::iter()`):
    *   Retrieve the face specification and the corresponding neighbor face data from `neighbor_faces` [S1, unofficial].
    *   Iterate through the neighbor face coordinates `(u, v)` from 0 to `CHUNK_SIZE`.
    *   Calculate the face index and the padded linear index using `padded_linearize(padded_coords(spec, u, v))`.
    *   Assign the voxel from the neighboring face to the padded array at this index [S1, unofficial].
    *   *Note:* If a neighbor face is empty, the corresponding padding voxels remain `Empty` [S1, unofficial].
4.  **Generate Mesh Sections:** For each of the six directions (`+X`, `-X`, `+Y`, `-Y`, `+Z`, `-Z`):
    *   Create a visibility mask for the face. The size depends on the face orientation (e.g., `+Z` face mask is `SX * SY`) [S3, unofficial].
    *   Iterate through the slice coordinates based on the face normal. For example, for `+Z` (top), iterate `Z` from 0 to `SZ`, then `Y`, then `X` [S3, unofficial].
    *   Determine visibility: A face is visible if the block is not `Air` and the neighbor in the direction of the normal is opaque (or non-empty, depending on specific visibility rules) [S3, unofficial].
    *   Call `GreedyMeshSlice` with the appropriate `AxisU`, `AxisV`, `Normal`, and `Origin` offset to generate quads for that face [S3, unofficial].
    *   *Iteration Orders:*
        *   `xPos`/`xNeg`: `lx` → `lz` → `y` [S2, unofficial].
        *   `yPos`/`yNeg`: `y` → `lx` → `lz` [S2, unofficial].
        *   `zPos`/`zNeg`: `lz` → `lx` → `y` [S2, unofficial].
5.  **Assemble Result:** Initialize the result `ChunkIndex`, `SizeX`, and `SizeY` from the input data. Populate `Sections` with the generated quads for each block type and `CollisionSection` with collision geometry [S3, unofficial].

**Pseudocode:**

```python
def prepare_chunk_mesh(chunk_data, neighbor_faces, config):
    # 1. Initialize padded volume
    padded_chunk = [VoxelBlock.Empty] * config.PADDED_CHUNK_VOLUME
    
    # 2. Fill inner chunk
    for bz in range(config.CHUNK_SIZE):
        for by in range(config.CHUNK_SIZE):
            for bx in range(config.CHUNK_SIZE):
                block = chunk_data.get_block(bx, by, bz)
                if block is not None:
                    px, py, pz = bx + 1, by + 1, bz + 1
                    idx = padded_linearize(px, py, pz, config.CHUNK_SIZE)
                    padded_chunk[idx] = map_non_empty(block, config.checker)
    
    # 3. Fill neighbor padding
    for direction in Direction.iter():
        face_spec = get_face_spec(direction)
        neighbor_data = neighbor_faces[direction]
        for u in range(config.CHUNK_SIZE):
            for v in range(config.CHUNK_SIZE):
                padded_coords = padded_coords_from_face(face_spec, u, v)
                idx = padded_linearize(*padded_coords, config.CHUNK_SIZE)
                voxel = neighbor_data.get_voxel(u, v, direction)
                if voxel is not None:
                    padded_chunk[idx] = voxel
                # Else remains Empty [S1, unofficial]

    # 4. Generate mesh sections
    result = FPreparedChunkMesh()
    result.ChunkIndex = chunk_data.chunk_index
    result.SizeX = config.CHUNK_SIZE
    result.SizeY = config.CHUNK_SIZE
    
    for direction in Direction.iter():
        if direction == Direction.Z_POS:
            mask = [False] * (config.SX * config.SY)
            for z in range(config.SZ):
                for y in range(config.SY):
                    for x in range(config.SX):
                        if chunk_data.get_block(x, y, z) != Air and neighbor_faces[Direction.Z_POS].get_voxel(x, y, z) != Air:
                            mask[y * config.SX + x] = True
            result.Sections[block_type].add_quads(GreedyMeshSlice(mask, config.SX, config.SY, AxisU=X, AxisV=Y, Normal=Z_POS, Origin=(z+1)*config.S))
        elif direction == Direction.Z_NEG:
            mask = [False] * (config.SY * config.SX)
            for z in range(config.SZ):
                for x in range(config.SX):
                    for y in range(config.SY):
                        if chunk_data.get_block(x, y, z) != Air and neighbor_faces[Direction.Z_NEG].get_voxel(x, y, z) != Air:

            result.Sections[block_type].add_quads(GreedyMeshSlice(mask, config.SY, config.SX, AxisU=Y, AxisV=X, Normal=Z_NEG, Origin=z*config.S))
        elif direction == Direction.X_POS:
            mask = [False] * (config.SY * config.SZ)
            for x in range(config.SX):
                for z in range(config.SZ):
                    for y in range(config.SY):
                        if chunk_data.get_block(x, y, z) != Air and neighbor_faces[Direction.X_POS].get_voxel(x, y, z) != Air:
                            mask[z * config.SY + y] = True
            result.Sections[block_type].add_quads(GreedyMeshSlice(mask, config.SY, config.SZ, AxisU=Y, AxisV=Z, Normal=X_POS, Origin=(x+1)*config.S))
        elif direction == Direction.X_NEG:
            mask = [False] * (config.SZ * config.SY)
            for x in range(config.SX):
                for y in range(config.SY):
                    for z in range(config.SZ):
                        if chunk_data.get_block(x, y, z) != Air and neighbor_faces[Direction.X_NEG].get_voxel(x, y, z) != Air:
                            mask[y * config.SZ + z] = True
            result.Sections[block_type].add_quads(GreedyMeshSlice(mask, config.SZ, config.SY, AxisU=Z, AxisV=Y, Normal=X_NEG, Origin=x*config.S))
        elif direction == Direction.Y_POS:
            mask = [False] * (config.SZ * config.SX)
            for y in range(config.SY):
                for x in range(config.SX):
                    for z in range(config.SZ):
                        if chunk_data.get_block(x, y, z) != Air and neighbor_faces[Direction.Y_POS].get_voxel(x, y, z) != Air:
                            mask[x * config.SZ + z] = True
            result.Sections[block_type].add_quads(GreedyMeshSlice(mask, config.SZ, config.SX, AxisU=Z, AxisV=X, Normal=Y_POS, Origin=(y+1)*config.S))
        elif direction == Direction.Y_NEG:
            mask = [False] * (config.SX * config.SZ)
            for y in range(config.SY):
                for z in range(config.SZ):
                    for x in range(config.SX):
                        if chunk_data.get_block(x, y, z) != Air and neighbor_faces[Direction.Y_NEG].get_voxel(x, y, z) != Air:
                            mask[z * config.SX + x] = True
            result.Sections[block_type].add_quads(GreedyMeshSlice(mask, config.SX, config.SZ, AxisU=X, AxisV=Z, Normal=Y_NEG, Origin=y*config.S))
            
    return result
```

**Parameters:**
*   `PADDED_CHUNK_VOLUME`: Total volume of the padded array, including the 1-voxel border [S1, unofficial].
*   `CHUNK_SIZE`: Dimensions of the original chunk (assumed cubic in examples, but `SX`, `SY`, `SZ` may vary) [S3, unofficial].
*   `Quad.width` and `Quad.height`: Represent the dimensions of the merged rectangle, no longer always 1 [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Neighbor Data:** Neighbor faces must be provided for all six directions. Missing neighbors result in `Empty` padding, which may cause incorrect culling or visible gaps at chunk boundaries [S1, unofficial].
*   **Transparency:** Transparent solids (glass, leaves), water, fluids, and plants are NOT merged. They are output as 1x1 primitives to preserve draw order and cell-specific attributes [S2, unofficial].
*   **Precision:** Linearization indices must be calculated correctly to avoid out-of-bounds access in the padded array [S1, unofficial].

## Subtopics

### Chunk Meshing with Greedy Merge
This is the primary meshing algorithm that merges coplanar like-for-like opaque faces into maximal rectangles using a greedy approach [S2, unofficial]. It validates chunk views, retrieves special block lookups, and builds a chunk mesh context (including layer, fluid, and cross-plant lookups) [S2, unofficial]. It extracts fluids, layers, plants, and push data, and if the `yLimit` equals `EMPTY_CHUNK_CEILING`, it returns empty layers immediately [S2, unofficial]. It calculates buffer lengths, allocates work buffers (mask and light masks), and calls `meshAllFaces` with the chunk, fluids, light, lookup, mask, neighbors, plants, and special lookup [S2, unofficial]. This method is slower than naive face extraction (1.16-1.47x wall-clock time) but significantly reduces triangle count [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Slower than naive face extraction. The greedy merge algorithm requires building masks and sweeping them, which adds computational overhead [S2, unofficial].
*   **Memory Complexity:** Requires a `PaddedChunk` array of size `PADDED_CHUNK_VOLUME` plus work buffers for masks and light masks [S1, S2, unofficial].
*   **Measured Performance:** Quad reduction results vary by shape: flat shapes achieve -99.8% reduction (4,608 → 10 quads), rolling shapes -82.7% (5,558 → 960 quads), and checkerboard patterns 0.0% [S2, unofficial].
*   **Strengths:** Significant reduction in triangle count for large flat or rolling surfaces, reducing GPU draw calls and vertex processing load [S2, unofficial].
*   **Limitations:** Higher CPU time for mesh generation; ineffective for highly fragmented or checkerboard patterns where no merging occurs [S2, unofficial].
*   **When to Use:** Ideal for terrain and large structures with large flat areas. Not suitable for highly detailed, non-merged geometry or when CPU time is more critical than GPU bandwidth.

## Background
Chunk Mesh Preparation is part of the greedy meshing pipeline used in voxel-based game engines and world generation systems. It addresses the problem of efficient mesh generation for large voxel worlds by handling chunk boundaries correctly. The method is implemented in systems like Infinigen [S1, unofficial], MC-Meshing [S2, unofficial], and VoxelWorld [S3, unofficial]. The greedy merge algorithm trades computation time for triangle count reduction, a common optimization in voxel rendering [S2, unofficial].
