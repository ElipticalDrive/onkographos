# Greedy Meshing for Opaque/Undefined Blocks

Also called: RightGreedyMesh

## Overview
This method generates a triangle mesh for opaque voxel blocks by greedily merging adjacent faces of identical material into larger quads. It specifically targets the right-facing surface normal ($+X$), iterating along the X-axis to construct the mesh in the Z-Y plane [S2, unofficial]. It differs from general greedy meshing by fixing the sweep direction and normal, and from chunk-based approaches by operating on a single chunk's internal data structure while optionally checking immediate neighbors to cull hidden faces [S3, unofficial].

## How it works
**Inputs:**
- `blockArray1D`: A 1D array of block IDs (bytes) representing the chunk volume.
- `blockArray1D_right`: A 1D array of block IDs representing the immediate neighbor chunk to the right (+X direction) [S2, unofficial].
- `chunkWidth`, `chunkHeight`, `chunkLength`: Dimensions of the chunk in blocks [S2, unofficial].
- `chunkToRight`: Boolean flag indicating if a right neighbor exists [S2, unofficial].
- `colors`: Array of color values indexed by block ID [S2, unofficial].
- `blockSize`: Physical size of a single block unit [S2, unofficial].

**Outputs:**
- `verticies`: List of vertex positions.
- `uv`: List of UV coordinates.
- `colors`: List of vertex colors.

**Data Structures:**
- `blocks`: A 2D mask array of size `chunkLength` $\times$ `chunkHeight`, indexed as `blocks[z + (chunkLength * y)]`. It stores the block ID if the face is visible and unprocessed, or `0` if processed or hidden [S2, unofficial].

**Steps:**
1. **Initialization:** Initialize empty lists for `verticies`, `uv`, and `colors` [S2, unofficial].
2. **Sweep Loop:** Iterate X from `chunkWidth - 1` down to `0` [S2, unofficial].
   - If `x == chunkWidth - 1` and `!chunkToRight`, continue to next X (no right neighbor to check against, and no face exposed to the right if it's the boundary, assuming air boundary) [S2, unofficial].
3. **Slice Construction:** Construct the `blocks` mask for the current X slice [S2, unofficial].
   - If `x < chunkWidth - 1`:
     - Check `blockArray1D` at index `x + 1`.
     - If `blockArray1D[x + 1] > 0`, set all entries in `blocks` to `0` (face is internal, hidden by neighbor) [S2, unofficial].
     - Else, copy `blockArray1D` values for the current X slice into `blocks` [S2, unofficial].
   - If `x == chunkWidth - 1`:
     - Check `blockArray1D_right` at index `0` (assuming the neighbor array is aligned or indexed appropriately relative to the chunk start) [S2, unofficial].
     - If `blockArray1D_right[0] > 0`, set all entries in `blocks` to `0` [S2, unofficial].
     - Else, copy `blockArray1D` values for the current X slice into `blocks` [S2, unofficial].
4. **Greedy Expansion:** Iterate Z from `0` to `chunkLength - 1` and Y from `0` to `chunkHeight - 1` [S2, unofficial].
   - Let `blockID = blocks[z + (chunkLength * y)]`.
   - If `blockID == 0`, continue [S2, unofficial].
   - **Expand Height:** Initialize `height = 1`. While `y + height < chunkHeight` and `blocks[z + (chunkLength * (y + height))] == blockID`, increment `height` [S2, unofficial].
   - **Expand Length:** Initialize `length = 1`, `canExtend = true`. While `canExtend` and `z + length < chunkLength`:
     - Check if all cells in the column `z + length` for Y range `[y, y + height)` match `blockID`.
     - If yes, `length++`.
     - Else, `canExtend = false` [S2, unofficial].
5. **Mark Processed:** Set `blocks[(z + i) + (chunkLength * (y + j))] = 0` for `i` in `[0, length)` and `j` in `[0, height)` [S2, unofficial].
6. **Vertex Generation:**
   - Calculate `size = blockSize` [S2, unofficial].
   - `xPos = x * size` [S2, unofficial].
   - `yCenter = (y + height / 2.0f) * size` [S2, unofficial].
   - `zCenter = (z + length / 2.0f) * size` [S2, unofficial].
   - `halfHeight = (height * size) / 2.0f` [S2, unofficial].
   - `halfLength = (length * size) / 2.0f` [S2, unofficial].
   - `color = colors[blockID - 1]` [S2, unofficial].
   - Add 4 vertices to `verticies`:
     1. `(xPos + size, yCenter - halfHeight, zCenter - halfLength)`
     2. `(xPos + size, yCenter + halfHeight, zCenter - halfLength)`
     3. `(xPos + size, yCenter + halfHeight, zCenter + halfLength)`
     4. `(xPos + size, yCenter - halfHeight, zCenter + halfLength)` [S2, unofficial].
   - Extend `uv` with 4 sets of `[0.0, 2.0]` UV coordinates [S2, unofficial].
   - Extend `colors` with 4 sets of `[0.0, 4.0]` color coordinates (RGBA) [S2, unofficial].

**Pseudocode:**

```python
def right_greedy_mesh(block_array_1d, block_array_1d_right, chunk_width, chunk_height, chunk_length, block_size, colors, chunk_to_right):
    """
    Generates a mesh for the right-facing (+X) surfaces of a voxel chunk.
    
    Args:
        block_array_1d: List[int], block IDs for the current chunk.
        block_array_1d_right: List[int], block IDs for the chunk to the right.
        chunk_width: int, width of the chunk in blocks.
        chunk_height: int, height of the chunk in blocks.
        chunk_length: int, length of the chunk in blocks.
        block_size: float, physical size of one block.
        colors: List[List[float]], colors indexed by block ID (1-based).
        chunk_to_right: bool, True if a right neighbor exists.
        
    Returns:
        tuple: (vertices, uvs, vertex_colors)
    """
    vertices = []
    uvs = []
    vertex_colors = []
    
    # Iterate X from right to left
    for x in range(chunk_width - 1, -1, -1):
        # If it's the rightmost block and no neighbor, skip (assuming air boundary)
        if x == chunk_width - 1 and not chunk_to_right:
            continue
            
        # Construct the 2D mask for this X slice
        # Mask is indexed by z + (chunk_length * y)
        mask = [0] * (chunk_length * chunk_height)
        
        # Determine visibility based on neighbor
        if x < chunk_width - 1:
            # Check immediate right neighbor in the same chunk
            # Note: block_array_1d is likely flattened (x, y, z) or similar.
            # Assuming standard Minecraft-like layout: index = x + y*width + z*width*height
            # However, the source uses blockArray1D[x+1] directly, implying a specific layout.
            # We will assume the source's logic: check block at x+1.
            # To be precise with the source's "blockArray1D at x+1", we assume the array is 
            # structured such that adjacent X blocks are adjacent in memory or accessible via offset.
            # Given the source snippet `blockArray1D[x+1]`, we follow that.
            neighbor_val = block_array_1d[x + 1] # Simplified access based on source logic
            if neighbor_val > 0:
                # Face is internal, mask remains 0
                pass
            else:
                # Face is exposed, copy current X slice to mask
                # Assuming block_array_1d is laid out such that we can extract the slice.
                # The source says "copy from x". We assume a helper or direct mapping.
                # For implementation, we need the actual slice data.
                # Let's assume block_array_1d is indexed [x, y, z] -> x + y*W + z*W*H
                # Then slice x is at offset x.
                # But the source uses 1D array access `blockArray1D[x+1]`.
                # This implies the array might be [x, y, z] flattened differently or the source 
                # is pseudocode for a specific memory layout.
                # We will implement the copy based on the source's intent:
                # Copy the block IDs for the current X slice into the mask.
                for y in range(chunk_height):
                    for z in range(chunk_length):
                        # Calculate index in 1D array for (x, y, z)
                        # Standard layout: x + y*W + z*W*H
                        idx = x + y * chunk_width + z * chunk_width * chunk_height
                        mask[z + (chunk_length * y)] = block_array_1d[idx]
        else: # x == chunk_width - 1
            # Check right neighbor chunk
            if chunk_to_right:
                # Check blockArray1D_right at index 0
                # Source says `blockArray1D_right[0]`.
                neighbor_val = block_array_1d_right[0]
                if neighbor_val > 0:
                    pass # Internal
                else:
                    # Exposed, copy from x
                    for y in range(chunk_height):
                        for z in range(chunk_length):
                            idx = x + y * chunk_width + z * chunk_width * chunk_height
                            mask[z + (chunk_length * y)] = block_array_1d[idx]
            else:
                # No neighbor, assume air boundary -> exposed
                for y in range(chunk_height):
                    for z in range(chunk_length):
                        idx = x + y * chunk_width + z * chunk_width * chunk_height
                        mask[z + (chunk_length * y)] = block_array_1d[idx]

        # Greedy Expansion on the mask
        for y in range(chunk_height):
            for z in range(chunk_length):
                block_id = mask[z + (chunk_length * y)]
                if block_id == 0:
                    continue
                
                # Expand Height (Y)
                height = 1
                while y + height < chunk_height:
                    if mask[z + (chunk_length * (y + height))] == block_id:
                        height += 1
                    else:
                        break
                
                # Expand Length (Z)
                length = 1
                can_extend = True
                while can_extend and z + length < chunk_length:
                    # Check all cells in the column z+length for Y range [y, y+height)
                    match = True
                    for dy in range(height):
                        if mask[(z + length) + (chunk_length * (y + dy))] != block_id:
                            match = False
                            break
                    if match:
                        length += 1
                    else:
                        can_extend = False
                
                # Mark as processed
                for dy in range(height):
                    for dz in range(length):
                        mask[(z + dz) + (chunk_length * (y + dy))] = 0
                
                # Generate Vertices
                size = block_size
                x_pos = x * size
                y_center = (y + height / 2.0) * size
                z_center = (z + length / 2.0) * size
                half_height = (height * size) / 2.0
                half_length = (length * size) / 2.0
                
                # Color lookup (1-based index in source)
                color = colors[block_id - 1]
                
                # Add 4 vertices
                # 1. Bottom-Left (in local Z-Y plane relative to face)
                vertices.append((x_pos + size, y_center - half_height, z_center - half_length))
                # 2. Top-Left
                vertices.append((x_pos + size, y_center + half_height, z_center - half_length))
                # 3. Top-Right
                vertices.append((x_pos + size, y_center + half_height, z_center + half_length))
                # 4. Bottom-Right
                vertices.append((x_pos + size, y_center - half_height, z_center + half_length))
                
                # Add UVs
                uvs.extend([0.0, 2.0, 0.0, 2.0, 0.0, 2.0, 0.0, 2.0])
                
                # Add Colors
                vertex_colors.extend(color * 4)
                
    return vertices, uvs, vertex_colors
```

## Subtopics

### Chunk Neighbor Optimization
An optimization where chunks are made aware of their neighboring chunks to remove inner polygons that are never visible [S3, unofficial]. It solves the issue where neighboring chunks previously did not know about each other [S3, unofficial]. The world is constructed cube by cube, passing neighbor coordinates to the current cube to check visibility against each side as it is created [S3, unofficial]. A pitfall is Unity's restriction of ~65,000 vertices per mesh; a 65,536 cube chunk exceeds this, requiring recombination of multiple chunks [S3, unofficial].

### Greedy Meshing (Right Face)
This is the specific orientation implemented by the main method, focusing on the $+X$ normal. It iterates X backwards and merges in the Z-Y plane [S2, unofficial].

### Greedy Meshing (Bottom Face)
Not given in the sources.

## Operating characteristics
- **Time Complexity:** $O(V)$ where $V$ is the number of voxels, as each voxel is visited a constant number of times during slice construction and greedy expansion.
- **Memory Complexity:** $O(H \times L)$ for the mask array, where $H$ is height and $L$ is length of the chunk.
- **Strengths:** Reduces vertex count significantly by merging adjacent faces. Simple to implement.
- **Limitations:** Only handles one face orientation at a time. Requires separate passes for other normals.
- **When to use:** When rendering opaque voxel blocks and vertex count is a bottleneck.
- **When not to use:** When transparency is required or when dynamic updates are frequent and complex.

## Background
Originating from voxel engine implementations, this method is part of the broader greedy meshing family. It is specifically cited in the context of Unity-based voxel engines [S2, unofficial] and procedural terrain generation tools [S3, unofficial]. The "RightGreedyMesh" name appears in Unity Voxel Engine implementations [S2, unofficial].
