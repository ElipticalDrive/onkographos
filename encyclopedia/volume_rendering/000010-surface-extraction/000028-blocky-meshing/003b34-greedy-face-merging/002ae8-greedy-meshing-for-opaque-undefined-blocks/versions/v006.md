# Greedy Meshing for Opaque/Undefined Blocks


## Overview
This method extends the standard greedy face merging algorithm to handle voxel blocks that are either opaque or have undefined appearance, ensuring that only visible faces are meshed while maintaining correct UV and color attributes for rendering. It differs from [Greedy Meshing](3519-greedy-meshing.md) by explicitly managing the attribute arrays (UVs and colors) associated with the generated quads and enforcing strict visibility checks for blocks lacking defined appearance data.

## How it works
The method builds on [Greedy face merging](8935-greedy-face-merging.md). It processes the voxel volume to generate a mesh of quads, handling opaque and undefined blocks by validating appearance definitions and extending attribute arrays.

**Inputs and Outputs:**
- **Input:** A voxel volume where each cell has a material ID. A boundary policy (e.g., "air" or "solid") determines visibility at volume edges.
- **Output:** A list of quads, each with an origin, normal, width, height, and associated UV and color data.

**Data Structures:**
- **Quads List:** Each element contains:
  - `origin`: 3D vector $(x, y, z)$ representing the corner of the quad.
  - `normal`: Integer $n \in \{0, 1, 2\}$ for X, Y, Z axes.
  - `width`: Integer $w$.
  - `height`: Integer $h$.
  - `uvs`: Array of 4 UV pairs.
  - `colors`: Array of 4 RGBA values.
- **UVs Array:** Accumulates 4 UV coordinates per quad. Each UV is a pair $[u, v]$ where $u, v \in [0.0, 2.0]$.
- **Colors Array:** Accumulates 4 color values per quad. Each color is a 4-tuple $[r, g, b, a]$.

**Steps:**
1. **Initialize Attribute Arrays:** Start with empty `uvs` and `colors` arrays.
2. **Sweep and Visibility Check:** For each normal axis $n \in \{0, 1, 2\}$:
   - Define tangent $t = (n + 1) \pmod 3$ and bitangent $b = (n + 2) \pmod 3$.
   - Iterate through slices $s$ along the normal axis.
   - For each cell $(t, b)$ in the slice, check if the face is exposed. A face is exposed if the voxel $V(s, t, b)$ differs from its neighbor $V(s \pm 1, t, b)$ or if the neighbor is out of bounds and the boundary policy dictates exposure.
   - **Appearance Check:** If the voxel has no defined appearance, assert failure with the message "No appearance defined for block face" [S1, unofficial].
   - If exposed, mark the cell in the 2D mask with the material's merge key.
3. **Greedy Expansion:** Scan the 2D mask to find maximal rectangles of identical merge keys.
   - For each maximal rectangle found with origin $(t_0, b_0)$, width $w$, and height $h$:
     - Emit a quad with origin $(t_0, b_0, s)$, normal $n$, width $w$, and height $h$.
     - **Extend UVs:** Append 4 UV coordinates to the `uvs` array. The coordinates are typically normalized to $[0.0, 2.0]$ to support texture tiling across the quad [S1, unofficial].
     - **Extend Colors:** Append 4 color coordinates to the `colors` array. Each color is a 4-tuple $[r, g, b, a]$ [S1, unofficial].
   - Mark the cells in the mask as processed to prevent double-counting.

**Pseudocode:**
```python
def greedy_mesh_opaque_undefined(volume, dims, boundary_policy="air", merge_key=None):
    """
    volume: function (x, y, z) -> material_id
    dims: tuple (Dx, Dy, Dz)
    boundary_policy: "air" (default) or "solid"
    merge_key: function (material_id, x, y, z) -> int. Default: identity.
    """
    if merge_key is None:
        merge_key = lambda m, x, y, z: m

    quads = []
    uvs = []
    colors = []

    # Iterate over the 3 normal axes: 0=X, 1=Y, 2=Z
    for n in range(3):
        t = (n + 1) % 3  # Tangent axis
        b = (n + 2) % 3  # Bitangent axis
        dim_t, dim_b, dim_n = dims[t], dims[b], dims[n]
        
        # Mask stores the merge key if visible and unprocessed, else 0
        mask = [0] * (dim_t * dim_b)
        
        # Iterate through each slice along the normal axis
        for s in range(dim_n):
            # 1. Build Visibility Mask for slice s
            for y in range(dim_b):
                for x in range(dim_t):
                    coords = [0, 0, 0]
                    coords[n] = s
                    coords[t] = x
                    coords[b] = y
                    voxel_val = volume(*coords)
                    
                    # Check appearance definition
                    if not has_appearance(voxel_val): # [G] Placeholder for appearance check
                        raise Exception("No appearance defined for block face")
                    
                    exposed = False
                    # Check both neighbors along the normal axis
                    for dir in [-1, 1]:
                        nb_s = s + dir
                        if 0 <= nb_s < dim_n:
                            nb_coords = coords.copy()
                            nb_coords[n] = nb_s
                            nb_val = volume(*nb_coords)
                            if voxel_val != nb_val:
                                exposed = True
                                break
                        else:
                            # Out of bounds neighbor
                            if boundary_policy == "air":
                                exposed = True  # Air neighbor implies exposed face
                                break
                            else:  # solid
                                exposed = False  # Solid neighbor implies internal
                                break
                    
                    if exposed:
                        mask[y * dim_t + x] = merge_key(voxel_val, *coords)
                    else:
                        mask[y * dim_t + x] = 0

            # 2. Greedy Expansion on the 2D Mask
            for y in range(dim_b):
                for x in range(dim_t):
                    idx = y * dim_t + x
                    key = mask[idx]
                    
                    if key == 0:
                        continue
                    
                    # Start of a new quad
                    w = 1
                    # Expand width
                    while x + w < dim_t and mask[y * dim_t + (x + w)] == key:
                        w += 1
                    
                    h = 1
                    # Expand height
                    while y + h < dim_b:
                        row_match = True
                        for k in range(w):
                            if mask[(y + h) * dim_t + (x + k)] != key:
                                row_match = False
                                break
                        if not row_match:
                            break
                        h += 1
                    
                    # Emit Quad
                    origin = [0, 0, 0]
                    origin[n] = s
                    origin[t] = x
                    origin[b] = y
                    quads.append({
                        'origin': origin,
                        'normal': n,
                        'width': w,
                        'height': h
                    })
                    
                    # Extend UVs with 4 sets of [0.0; 2] UV coordinates
                    # [S1, unofficial]
                    for _ in range(4):
                        uvs.append([0.0, 2.0])
                    
                    # Extend Colors with 4 sets of [0.0; 4] color coordinates
                    # [S1, unofficial]
                    for _ in range(4):
                        colors.append([0.0, 0.0, 0.0, 1.0])
                    
                    # Mark cells as processed (set to 0)
                    for dy in range(h):
                        for dx in range(w):
                            mask[(y + dy) * dim_t + (x + dx)] = 0
                            
    return quads, uvs, colors
```

## Subtopics

### Chunk Neighbor Optimization
An optimization where chunks are made aware of their neighboring chunks to remove inner polygons that are never visible, solving the issue where neighboring chunks previously did not know about each other [S2, unofficial]. It constructs the world cube by cube, passing the neighbor's coordinates (if one exists) to the current cube and checking against each of the cube's sides as it is created to determine visibility [S2, unofficial]. A pitfall is that Unity restricts a mesh to approximately 65,000 vertices. A Minecraft-style chunk of 65,536 cubes exceeds this limit, so a single chunk cannot be made. The solution is to recombine meshes by stacking multiple chunks on top of each other [S2, unofficial].
