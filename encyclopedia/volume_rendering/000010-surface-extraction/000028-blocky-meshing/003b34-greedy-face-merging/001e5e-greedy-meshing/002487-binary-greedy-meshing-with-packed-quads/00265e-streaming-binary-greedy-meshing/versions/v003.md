# Streaming Binary Greedy Meshing

Also called: SBUG streaming step, Streaming Binary Greedy Meshing (SBUG) Core Loop

## Overview
Streaming Binary Greedy Meshing (SBGM) is a performance-oriented variant of Binary Greedy Meshing that combines face visibility generation and greedy merging into a single streaming traversal [S1, unofficial]. It retains only two rolling face data slices instead of six full chunk face arrays, significantly improving cache locality by ensuring data is consumed immediately after generation [S1, unofficial].

## How it works
SBGM processes a voxel chunk one x-slice at a time [S1, unofficial]. It maintains two `FaceSlice` buffers (current and next) and emits quads for all six face directions as compatible runs terminate [S1, unofficial].

**Inputs and Outputs:**
- **Input:** `voxels` (`uint8_t*`), `opaque` (`uint64_t*`), `MeshData& md`.
- **Output:** `md.vertices` (array of 6 `uint64_t*` buffers), `md.face_vertex_counts` (array of 6 `size_t`), `md.vertex_count` (`size_t`) [S1, unofficial].

**Data Structures:**
- **Chunk Dimensions:** Chunk Size `CS = 62`, Padded Size `CS_P = 64`, Padded Area `CS_P2 = 4096` [S1, unofficial].
- **Mask:** `P_MASK = ~(1ull << 63 | 1ull)` excludes top and bottom bits of a 64-bit integer [S1, unofficial].
- **FaceSlice:**
  ```cpp
  struct FaceSlice {
      uint64_t x_neg[CS_P];
      uint64_t x_pos[CS_P];
      uint64_t z_neg[CS_P];
      uint64_t z_pos[CS_P];
      uint64_t y_neg[CS_P];
      uint64_t y_pos[CS_P];
      uint8_t y_neg_span[CS_P2];
      uint8_t y_pos_span[CS_P2];
  };
  ```
- **MeshData:** Contains merge state arrays (`forward_merged`, `pos_forward_merged`, `y_right_merged`, etc.) and vertex buffers. Offsets are defined by `static_assert` constants (e.g., `MERGED_POS_FORWARD`) [S1, unofficial].
- **Outputs:** Array of 6 pointers to `uint64_t`, one for each face direction (0: X+, 1: X-, 2: Z+, 3: Z-, 4: Y+, 5: Y-) [S1, unofficial].

**Core Loop:**
1. Initialize two `FaceSlice` buffers. Build slices for x=1 and x=2.
2. Iterate x from 1 to CS.
3. For each x, determine the `right` neighbor slice: if `x < CS`, `right = next`; otherwise `right = &zero_slice`.
4. For each z from 1 to CS:
   - Calculate `slice_voxels = voxels + x * CS_P2` and `col = slice_voxels + z * CS_P`.
   - Calculate `span_base = z * CS_P`.
   - If `current->x_neg[z]` is non-zero, call `mesh_x_bits` with `col`, `-1`, `x`, `z`, `current->x_neg[z]`, `current->x_neg[z+1]`, `merged + MERGED_FORWARD`, and `outputs[1]`.
   - If `current->x_pos[z]` is non-zero, call `mesh_x_bits` with `col`, `+1`, `x`, `z`, `current->x_pos[z]`, `current->x_pos[z+1]`, `merged + MERGED_POS_FORWARD`, and `outputs[0]`.
   - If `current->y_neg[z]` is non-zero, call `mesh_y_end_bits_x_major` with `col`, `-1`, `x`, `z`, `current->y_neg[z]`, `right->y_neg[z]`, `current->y_neg_span + span_base`, `right->y_neg_span + span_base`, `merged + MERGED_Y_RIGHT + span_base`, and `outputs[5]`.
   - If `current->y_pos[z]` is non-zero, call `mesh_y_end_bits_x_major` with `col`, `+1`, `x`, `z`, `current->y_pos[z]`, `right->y_pos[z]`, `current->y_pos_span + span_base`, `right->y_pos_span + span_base`, `merged + MERGED_Y_POS_RIGHT + span_base`, and `outputs[4]`.
   - If `current->z_neg[z]` is non-zero, call `mesh_z_bits` with `col`, `-1`, `z`, `x`, `current->z_neg[z]`, `right->z_neg[z]`, `merged + MERGED_Z_FORWARD + span_base`, and `outputs[3]`.
   - If `current->z_pos[z]` is non-zero, call `mesh_z_bits` with `col`, `+1`, `z`, `x`, `current->z_pos[z]`, `right->z_pos[z]`, `merged + MERGED_Z_POS_FORWARD + span_base`, and `outputs[2]`.
5. Swap `current` and `next` pointers.
6. If `x + 2 <= CS`, call `build_face_slice(voxels, opaque, x + 2, *next)` to prepare the next slice's data.

**Helper Functions:**
- **`build_face_slice`:** Loads column occupancy bits for left, mid, and right slices, computes `x_neg` and `x_pos` by masking with `P_MASK` and neighbor occupancy, stores results in `slice.x_neg/z` and `slice.x_pos/z`, and sets `slice.x_neg[CS+1]` and `slice.x_pos[CS+1]` to 0 as sentinels. Calls `build_y_face_slice`.
- **`build_y_face_slice`:** Iterates z from 1 to CS, computing `neg_current` and `pos_current` bits from column occupancy and neighbors, calls `build_y_face_column` for each z, updates `prev_occ/current_occ/next_occ`, and handles z=CS sentinel by setting `neg_next/pos_next` to 0.
- **`build_y_face_column`:** Processes `neg_bits` and `pos_bits` separately: for each bit y, checks if neighbor has same material; if so, increments forward span and removes bit; else stores forward span to `span_end`, resets forward span to 0, and updates terminal bits.
- **`mesh_x_bits`:** Iterates `bits_here`: finds lowest set bit y, checks if `bits_next` has same bit and same material; if so, increments `forward_span` and continues; else computes height by comparing `bits_here` and `bits_next`, merges forward spans, creates quad via `get_quad`, and removes processed bits.
- **`mesh_z_bits`:** Iterates `bits_here`: finds lowest set bit y, checks if `bits_next` has same bit and same material; if so, increments `forward_span` and continues; else computes height by comparing `bits_here` and `bits_next`, merges forward spans, creates quad via `get_quad`, and removes processed bits.
- **`mesh_y_end_bits_x_major`:** Iterates `bits_here`: finds bit y, checks if `bits_right` has same bit, `forward_span` equals `span_right[y]`, and same material; if so, increments `right_span`; else computes `start_z/start_x/length_z/width_x` from spans, creates quad via `get_quad`, resets `right_span`, and removes processed bits.

**Pseudocode:**
```python
CS = 62
CS_P = 64
CS_P2 = 4096
P_MASK = ~(1 << 63 | 1)

class FaceSlice:
    def __init__(self):
        self.x_neg = [0] * CS_P
        self.x_pos = [0] * CS_P
        self.z_neg = [0] * CS_P
        self.z_pos = [0] * CS_P
        self.y_neg = [0] * CS_P
        self.y_pos = [0] * CS_P
        self.y_neg_span = [0] * CS_P2
        self.y_pos_span = [0] * CS_P2

def mesh(voxels, opaque, md):
    slices = [FaceSlice(), FaceSlice()]
    zero_slice = FaceSlice()
    current = slices[0]
    next_slice = slices[1]
    
    build_face_slice(voxels, opaque, 1, current)
    build_face_slice(voxels, opaque, 2, next_slice)
    
    outputs = [0, 0, 0, 0, 0, 0]
    begins = outputs[:]
    
    for x in range(1, CS + 1):
        right = next_slice if x < CS else zero_slice
        
        for z in range(1, CS + 1):
            col = voxels[x * CS_P2 + z * CS_P]
            span_base = z * CS_P
            
            if current.x_neg[z]:
                outputs[1] = mesh_x_bits(col, -1, x, z, current.x_neg[z], current.x_neg[z+1], md.forward_merged, MERGED_FORWARD, outputs[1])
            if current.x_pos[z]:
                outputs[0] = mesh_x_bits(col, 1, x, z, current.x_pos[z], current.x_pos[z+1], md.pos_forward_merged, MERGED_POS_FORWARD, outputs[0])
            if current.y_neg[z]:
                outputs[5] = mesh_y_end_bits_x_major(col, -1, x, z, current.y_neg[z], right.y_neg[z], current.y_neg_span, span_base, right.y_neg_span, span_base, md.y_right_merged, MERGED_Y_RIGHT, span_base, outputs[5])
            if current.y_pos[z]:
                outputs[4] = mesh_y_end_bits_x_major(col, 1, x, z, current.y_pos[z], right.y_pos[z], current.y_pos_span, span_base, right.y_pos_span, span_base, md.y_pos_right_merged, MERGED_Y_POS_RIGHT, span_base, outputs[4])
            if current.z_neg[z]:
                outputs[3] = mesh_z_bits(col, -1, z, x, current.z_neg[z], right.z_neg[z], md.z_forward_merged, MERGED_Z_FORWARD, span_base, outputs[3])
            if current.z_pos[z]:
                outputs[2] = mesh_z_bits(col, 1, z, x, current.z_pos[z], right.z_pos[z], md.z_pos_forward_merged, MERGED_Z_POS_FORWARD, span_base, outputs[2])
                
        current, next_slice = next_slice, current
        
        if x + 2 <= CS:
            build_face_slice(voxels, opaque, x + 2, next_slice)
            
    for face in range(6):
        md.face_vertex_counts[face] = outputs[face] - begins[face]
        md.vertex_count += md.face_vertex_counts[face]
        
    return md.vertex_count

def build_face_slice(voxels, opaque, x, slice):
    for z in range(CS_P):
        mid = opaque[x * CS_P + z]
        left = opaque[(x - 1) * CS_P + z]
        right = opaque[(x + 1) * CS_P + z]
        slice.x_neg[z] = mid & P_MASK & ~left
        slice.x_pos[z] = mid & P_MASK & ~right
    slice.x_neg[CS + 1] = 0
    slice.x_pos[CS + 1] = 0
    build_y_face_slice(voxels, opaque, x, slice.y_neg, slice.y_pos, slice.y_neg_span, slice.y_pos_span, slice.z_neg, slice.z_pos)

def build_y_face_slice(voxels, opaque, x, neg_end, pos_end, neg_span_end, pos_span_end, z_neg, z_pos):
    neg_forward = [0] * CS_P
    pos_forward = [0] * CS_P
    
    prev_occ = opaque[x * CS_P + 0]
    current_occ = opaque[x * CS_P + 1]
    column_bits = current_occ & P_MASK
    neg_current = column_bits & ~(current_occ << 1)
    pos_current = column_bits & ~(current_occ >> 1)
    
    for z in range(1, CS):
        col = voxels[x * CS_P2 + z * CS_P]
        next_occ = opaque[x * CS_P + z + 1]
        next_bits = next_occ & P_MASK
        neg_next = next_bits & ~(next_occ << 1)
        pos_next = next_bits & ~(next_occ >> 1)
        
        build_y_face_column(col, z * CS_P, neg_current, pos_current, neg_next, pos_next, neg_forward, pos_forward, neg_end, pos_end, neg_span_end, pos_span_end, z)
        
        prev_occ = current_occ
        current_occ = next_occ
        column_bits = next_bits
        neg_current = neg_next
        pos_current = pos_next
        
    z_neg[CS] = column_bits & ~prev_occ
    z_pos[CS] = column_bits & ~opaque[x * CS_P + CS + 1]
    build_y_face_column(voxels[x * CS_P2 + CS * CS_P], CS * CS_P, neg_current, pos_current, 0, 0, neg_forward, pos_forward, neg_end, pos_end, neg_span_end, pos_span_end, CS)

def build_y_face_column(col, span_base, neg_current, pos_current, neg_next, pos_next, neg_forward, pos_forward, neg_end, pos_end, neg_span_end, pos_span_end, z_idx):
    neg_bits = neg_current
    neg_terminal = neg_current
    while neg_bits:
        y = (neg_bits & -neg_bits).bit_length() - 1
        y_mask = 1 << y
        neg_bits &= neg_bits - 1
        
        material = col[y]
        if (neg_next & y_mask) != 0 and material == col[y + CS_P]:
            neg_forward[y] += 1
            neg_terminal &= ~y_mask
        else:
            neg_span_end[span_base + y] = neg_forward[y]
            neg_forward[y] = 0
            
    pos_bits = pos_current
    pos_terminal = pos_current
    while pos_bits:
        y = (pos_bits & -pos_bits).bit_length() - 1
        y_mask = 1 << y
        pos_bits &= pos_bits - 1
        
        material = col[y]
        if (pos_next & y_mask) != 0 and material == col[y + CS_P]:
            pos_forward[y] += 1
            pos_terminal &= ~y_mask
        else:
            pos_span_end[span_base + y] = pos_forward[y]
            pos_forward[y] = 0
            
    neg_end[z_idx] = neg_terminal
    pos_end[z_idx] = pos_terminal

def mesh_x_bits(col, sign, x, z, bits_here, bits_next, forward_merged, merged_offset, out_idx):
    while bits_here:
        y = (bits_here & -bits_here).bit_length() - 1
        y_mask = 1 << y
        material = col[y]
        forward_span = forward_merged[merged_offset + y]
        
        if (bits_next & y_mask) != 0 and material == col[y + CS_P]:
            forward_span += 1
            bits_here &= ~y_mask
            continue
            
        height_bits = (bits_here & ~bits_next) >> y
        max_height = (~height_bits & -~height_bits).bit_length()
        height = 1
        while height < max_height:
            next_y = y + height
            if forward_span != forward_merged[merged_offset + next_y]:
                break
            if material != col[next_y]:
                break
            forward_merged[merged_offset + next_y] = 0
            height += 1
            
        quad_mask = ((1 << height) - 1) << y
        bits_here &= ~quad_mask
        
        width = forward_span + 1
        start_z = z - forward_span
        forward_span = 0
        
        if sign > 0:
            md.vertices[1].append(get_quad(z, start_z - 1 + width, y - 1, width, height, material))
        else:
            md.vertices[1].append(get_quad(z - 1, start_z - 1, y - 1, width, height, material))
        out_idx += 1
        
    return out_idx

def mesh_z_bits(col, sign, z, x, bits_here, bits_next, forward_merged, merged_offset, out_idx):
    while bits_here:
        y = (bits_here & -bits_here).bit_length() - 1
        y_mask = 1 << y
        material = col[y]
        forward_span = forward_merged[merged_offset + y]
        
        if (bits_next & y_mask) != 0 and material == col[y + CS_P2]:
            forward_span += 1
            bits_here &= ~y_mask
            continue
            
        height_bits = (bits_here & ~bits_next) >> y
        max_height = (~height_bits & -~height_bits).bit_length()
        height = 1
        while height < max_height:
            next_y = y + height
            if forward_span != forward_merged[merged_offset + next_y]:
                break
            if material != col[next_y]:
                break
            forward_merged[merged_offset + next_y] = 0
            height += 1
            
        quad_mask = ((1 << height) - 1) << y
        bits_here &= ~quad_mask
        
        width = forward_span + 1
        start_x = x - forward_span
        forward_span = 0
        
        if sign > 0:
            md.vertices[2].append(get_quad(z, start_x - 1 + width, y - 1, width, height, material))
        else:
            md.vertices[2].append(get_quad(z - 1, start_x - 1, y - 1, width, height, material))
        out_idx += 1
        
    return out_idx

def mesh_y_end_bits_x_major(col, sign, x, z, bits_here, bits_right, span_here, span_base_here, span_right, span_base_right, right_merged, merged_offset, span_base_merged, out_idx):
    while bits_here:
        y = (bits_here & -bits_here).bit_length() - 1
        y_mask = 1 << y
        bits_here &= bits_here - 1
        
        material = col[y]
        forward_span = span_here[span_base_here + y]
        right_span = right_merged[merged_offset + span_base_merged + y]
        
        if (bits_right & y_mask) != 0 and forward_span == span_right[span_base_right + y] and material == col[y + CS_P2]:
            right_span += 1
            continue
            
        start_z = z - forward_span
        start_x = x - right_span
        length_z = forward_span + 1
        width_x = right_span + 1
        right_span = 0
        
        if sign > 0:
            md.vertices[4].append(get_quad(start_z - 1 + length_z, start_x - 1, y, length_z, width_x, material))
        else:
            md.vertices[4].append(get_quad(start_z - 1, start_x - 1, y - 1, length_z, width_x, material))
        out_idx += 1
        
    return out_idx

def get_quad(x, y, z, w, h, type):
    return (type << 32) | (h << 24) | (w << 18) | (z << 12) | (y << 6) | x

def column_mask(opaque, x, z):
    return opaque[z + x * CS_P]
```

**Edge Cases and Pitfalls:**
- **Sentinels:** `z=CS` is padding, so y spans must terminate here by setting `neg_next/pos_next` to 0 in `build_y_face_column`. `z=CS+1` sentinel: `slice.x_neg[CS+1]` and `slice.x_pos[CS+1]` are set to 0 to stop forward merges at the last interior column.
- **Quad Counts:** Quad counts may differ between SBGM and BGM because SBGM merges adjacent faces in a different order, though the benchmark validator confirms functionally equivalent coverage.

## Operating characteristics
- **Performance:** On a Ryzen 5 5600x with Windows 10, MSVC 19.44.35221.0, on a 64x64 grid at 8 iterations, SBGM achieves 37.52 us/chunk median throughput (26,650 chunks/s) compared to BGM's 100.27 us/chunk, a 2.67x speedup.
- **Strengths:** Improved cache locality by reducing exposed face data to two 11 KiB slices that are immediately consumed, avoiding L1 cache evictions.
- **Limitations:** Requires AVX2/BMI/BMI2 support. Quad counts may differ from BGM due to merge order.

## Background
SBGM is a performance-oriented variant of Binary Greedy Meshing (BGM). Traditional BGM builds six full-chunk face masks (180 KiB total) which do not fit in L1 data cache (32/48 KiB) and get evicted before meshing. SBGM traverses a chunk one x-slice at a time, reducing exposed face data to two 11 KiB slices that are immediately consumed for meshing, improving cache locality.
