# Mesh Generation & Entity Spawning Pipeline

Also called: Chunk Meshing Pipeline

## Overview
This pipeline orchestrates the asynchronous generation of triangle-list meshes from voxel data and their subsequent instantiation as renderable entities in a game engine [S1, S2, unofficial]. It solves the problem of decoupling expensive geometry computation from the main render loop, ensuring frame-rate stability by batching mesh creation and controlling entity spawn rates [S2, unofficial]. Unlike synchronous meshing, this method manages dependencies on neighbor chunks to ensure face consistency, deferring requests until all required context is available [S2, unofficial].

## How it works
The pipeline processes `MeshChunkRequest` events, consulting a cache of chunk states to determine whether to generate new geometry, wait for neighbors, or spawn an entity [S2, unofficial].

### Inputs and Outputs
*   **Input:** `MeshChunkRequest` containing `ChunkPosition` and `ZoomLevel` [S2, unofficial].
*   **Output:** Bevy `Entity` instances with attached `Mesh` assets, `Transform`, and `Material` [S1, S2, unofficial].

### Data Structures
**MeshInfo**
Holds the raw geometry data before being committed to a Bevy `Mesh` asset [S2, unofficial].
*   `positions`: `Vec<[f32; 3]>`
*   `normals`: `Vec<[f32; 3]>`
*   `colors`: `Vec<[f32; 4]>`
*   `uvs`: `Vec<[f32; 2]>`
*   `indices`: `Vec<u32>`

**MeshStatus**
Tracks the lifecycle state of a chunk's mesh in the `meshes` map (keyed by `(ChunkPosition, ZoomLevel)`) [S2, unofficial].
*   `Meshing`: Geometry is currently being computed.
*   `Empty`: Chunk contains no blocks; no mesh is generated.
*   `Meshed(MeshInfo)`: Geometry is ready for asset creation.

**Quad**
Represents a merged face on a chunk boundary [S2, unofficial].
*   `voxel`: `[u32; 3]` Base coordinate of the quad.
*   `width`: `u32`
*   `height`: `u32`

### Parameters
*   `MAX_DATA_TASKS`: Maximum concurrent data tasks. Value: `9` [S1, unofficial].
*   `MAX_MESH_TASKS`: Maximum concurrent mesh tasks. Value: `3` [S1, unofficial].
*   `MAX_SCANS`: Maximum chunks scanned per frame. Value: `26000` [S1, unofficial].
*   `CHUNK_SIZE`: Size of a chunk side in voxels. Value: `32` [S1, S2, unofficial].
*   `MESH_SPAWN_RATE`: Controls the rate at which meshed chunks are spawned as entities to prevent lag. Formula:
    $$ \text{MESH\_SPAWN\_RATE} = \left\lfloor 128.0 \times \frac{32.0}{\text{CHUNK\_SIZE\_F32}} \right\rfloor $$
    Default calculation scales inversely with chunk size [S2, unofficial].
*   `CHUNK_REQUEST_RATE`: Rate at which mesh requests are processed. Formula:
    $$ \text{CHUNK\_REQUEST\_RATE} = \text{MESH\_SPAWN\_RATE} \times 5 $$
    [S2, unofficial].

### Algorithm Steps
1.  **Request Reception:** Receive a `MeshChunkRequest` with `ChunkPosition` and `ZoomLevel` [S2, unofficial].
2.  **Cache Check:** Look up the chunk in `world.cache` (or the `meshes` map) [S2, unofficial]. If chunk data does not exist, request generation via `GenerateChunkRequest` and schedule a rerequest [S2, unofficial].
3.  **Generation Check:** If chunk is generating, schedule a rerequest [S2, unofficial].
4.  **Empty Check:** If chunk is empty, mark mesh status as `Empty` and skip [S2, unofficial].
5.  **Neighbor Validation:** If chunk is generated, collect neighbor chunk faces [S2, unofficial]. For each neighbor direction, get its opposite face data [S2, unofficial].
6.  **Neighbor Status Check:** If any neighbor is missing or generating, schedule a rerequest [S2, unofficial].
7.  **Mesh Generation:** If all neighbors are present, call mesh generation function (`bevy_mesh_greedy_quads` or `bevy_mesh_visible_block_faces`) with chunk, neighbor faces, block textures, and visibility checker [S2, unofficial].
8.  **Store Result:** Store result in `meshes` map with status `Meshed` or `Empty` [S2, unofficial].
9.  **Spawn Phase:** Take chunks with status `SpawnRequested` up to `MESH_SPAWN_RATE` [S2, unofficial].
10. **Entity Instantiation:** Spawn Bevy entities for opaque and translucent meshes with appropriate materials and transforms [S2, unofficial]. Create Bevy mesh with `PrimitiveTopology::TriangleList` and `RenderAssetUsages::RENDER_WORLD` [S1, unofficial]. Insert vertex attribute `ATTRIBUTE_VOXEL` with mesh vertices [S1, unofficial]. Insert indices as `Indices::U32` [S1, unofficial]. Add mesh to asset server and get handle [S1, unofficial]. Despawn existing entity at world position if present [S1, unofficial]. Spawn new chunk entity with AABB `from_min_max(Vec3::ZERO, Vec3::splat(32.0))`, transform `world_pos.as_vec3() * Vec3::splat(32.0)`, mesh handle, and global material [S1, unofficial]. Insert new entity into `chunk_entities` map [S1, unofficial].

### Pseudocode
```python
# Constants
MAX_DATA_TASKS = 9
MAX_MESH_TASKS = 3
MAX_SCANS = 26000
CHUNK_SIZE = 32
CHUNK_SIZE_F32 = 32.0
MESH_SPAWN_RATE = int(128.0 * (32.0 / CHUNK_SIZE_F32))
CHUNK_REQUEST_RATE = MESH_SPAWN_RATE * 5

# Data Structures
class MeshInfo:
    def __init__(self, positions, normals, colors, uvs, indices):
        self.positions = positions
        self.normals = normals
        self.colors = colors
        self.uvs = uvs
        self.indices = indices

class MeshStatus:
    Meshing = "Meshing"
    Empty = "Empty"
    def __init__(self, info=None):
        self.info = info

# Global State
meshes = {}  # Dict[(ChunkPosition, ZoomLevel), MeshStatus]
chunk_entities = {}  # Dict[ChunkPosition, Entity]
world_cache = {}  # Dict[ChunkPosition, ChunkData]
mesh_queue = []
spawn_queue = []

def process_mesh_request(request):
    pos = request.chunk_position
    zoom = request.zoom_level
    key = (pos, zoom)

    # 1. Cache Check
    if key not in meshes:
        if pos not in world_cache:
            # Request generation via GenerateChunkRequest and schedule rerequest
            schedule_generate_chunk(pos)
            schedule_rerequest_mesh(pos, zoom)
            return
        else:
            meshes[key] = MeshStatus.Meshing
            schedule_mesh_task(pos, zoom)
            return
    elif meshes[key] == MeshStatus.Meshing:
        schedule_rerequest_mesh(pos, zoom)
        return
    elif meshes[key] == MeshStatus.Empty:
        return

    # 2. Neighbor Validation
    neighbor_faces = collect_neighbor_faces(pos)
    if neighbor_faces is None:
        schedule_rerequest_mesh(pos, zoom)
        return

    # 3. Mesh Generation
    chunk_data = world_cache[pos]
    mesh_info = generate_mesh(chunk_data, neighbor_faces)

    meshes[key] = MeshStatus(mesh_info)
    spawn_queue.append(key)

def collect_neighbor_faces(pos):
    # Check 26 adjacent directions (Moore neighborhood excluding center)
    for direction in ADJACENT_CHUNK_DIRECTIONS:
        if direction == (0, 0, 0):
            continue
        neighbor_pos = pos + direction
        neighbor_status = get_mesh_status(neighbor_pos)

        if neighbor_status == MeshStatus.Meshing or neighbor_status is None:
            return None  # Defer
        elif neighbor_status == MeshStatus.Empty:
            return EMPTY_CHUNK_FACES
        else:
            return get_neighbor_faces(neighbor_pos)
    return collected_faces

def generate_mesh(chunk, neighbor_faces):
    # Call greedy or visible face algorithm
    return mesh_chunk_greedy_quads(chunk, neighbor_faces)

def spawn_entity(key):
    pos, zoom = key
    status = meshes.get(key)

    if not isinstance(status, MeshStatus) or status.info is None:
        return

    mesh_info = status.info

    # Create Bevy Mesh Asset
    bevy_mesh = create_bevy_mesh()
    bevy_mesh.insert_attribute("position", mesh_info.positions)
    bevy_mesh.insert_attribute("normal", mesh_info.normals)
    bevy_mesh.insert_attribute("color", mesh_info.colors)
    bevy_mesh.insert_attribute("uv", mesh_info.uvs)
    bevy_mesh.set_indices(mesh_info.indices)

    handle = asset_server.add(bevy_mesh)

    # Despawn old entity if exists
    if pos in chunk_entities:
        despawn(chunk_entities[pos])

    # Spawn new entity
    transform = Transform.from_translation(pos.as_vec3() * 32.0)
    aabb = AABB.from_min_max(Vec3(0, 0, 0), Vec3(32, 32, 32))

    material = get_global_material(mesh_info)

    entity = spawn_entity_bundle(
        TransformBundle(transform),
        MeshBundle(handle),
        MaterialBundle(material),
        VisibilityBundle(aabb)
    )

    chunk_entities[pos] = entity
    meshes[key] = MeshStatus.Empty

def main_loop():
    # 1. Scan for chunks to request
    scan_count = 0
    for chunk_pos in get_chunks_in_view():
        if scan_count >= MAX_SCANS:
            break
        if chunk_pos not in chunk_entities:
            schedule_mesh_request(chunk_pos)
            scan_count += 1

    # 2. Process Mesh Tasks (Async)
    while active_mesh_tasks < MAX_MESH_TASKS:
        if mesh_queue:
            task = mesh_queue.pop()
            process_mesh_request(task)

    # 3. Spawn Entities (Throttled)
    spawn_count = 0
    for key in list(spawn_queue):
        if spawn_count >= MESH_SPAWN_RATE:
            break
        if meshes.get(key) == MeshStatus.Meshing or meshes.get(key).info is not None:
            spawn_entity(key)
            spawn_count += 1
```

### Edge Cases and Pitfalls
*   **Neighbor Dependencies:** Neighbor chunks must be fully generated before meshing can proceed. If any neighbor is missing or still generating, the mesh request is deferred via `MeshChunkRerequest` to avoid incorrect culling or geometry [S2, unofficial].
*   **Empty Chunks:** Empty chunks (no blocks) must be handled explicitly to avoid spawning empty entities. The status `MeshStatus::Empty` causes the chunk request to be removed from the queue [S2, unofficial].
*   **Precision:** Vertex positions are typically integer-based (voxel coordinates) scaled by chunk size. Ensure `f32` precision is sufficient for large world coordinates; consider using `f64` for world positions if chunks exceed $2^{15}$ units [G].

## Operating characteristics
*   The pipeline uses asynchronous tasks (`MAX_MESH_TASKS = 3`) to prevent blocking the main thread [S1, unofficial].
*   The spawn rate is dynamically scaled based on chunk size to maintain consistent frame times [S2, unofficial].
*   The pipeline handles neighbor consistency automatically and prevents lag spikes via throttled spawning [S2, unofficial].

## Background
This pipeline is part of the Infinigen project, a sandbox for experimenting with Bevy and efficient chunk rendering in Rust [S2, unofficial]. It implements a procedural generation and rendering pipeline that manages chunk loading, mesh generation (greedy or visible face), and entity spawning, handling asynchronous requests and neighbor dependencies [S2, unofficial]. The codebase is maintained as an unofficial repository [S2, unofficial].
