# Mesh Finalization

Also called: VTK Mesh Finalization

## Overview
Mesh Finalization is the post-processing stage that transforms raw, potentially fragmented mesh geometry into a validated, contiguous `RenderMesh` structure suitable for GPU submission. It solves the problem of data inconsistency by validating vertex/index integrity, extrapolating cell-centered field data to vertices, and computing derived attributes like normals and bounds [S1, unofficial]. It differs from [Chunk Mesh Assembly](4100-chunk-mesh-assembly.md) by focusing on data structure validation and field interpolation rather than spatial partitioning and buffer packing, and from [Mesh Plugin Architecture](4921-mesh-plugin-architecture.md) by being a concrete implementation step rather than an interface definition.

## How it works
**Inputs:** A raw mesh structure containing `vertices` (float array), `indices` (uint array), `cellConnectivity`, `cellTypes`, and optional scalar/vector fields.
**Outputs:** A finalized `RenderMesh` object with contiguous buffers, computed normals, bounds, and validated field data.

**Data Structures:**
*   `RenderMesh`:
    *   `vertices`: `std::vector<float>` (contiguous, interleaved XYZ).
    *   `indices`: `std::vector<std::uint32_t>` (contiguous).
    *   `normals`: `std::vector<float>` (contiguous, XYZ per vertex).
    *   `pointScalars`: `std::map<std::string, std::vector<float>>` (name to contiguous float array).
    *   `pointVectors`: `std::map<std::string, std::vector<float>>` (name to contiguous float array).
    *   `pointVectorOffset`: `std::map<std::string, std::size_t>` (field name to start index in `pointVectorsData`).
    *   `pointVectorsData`: `std::vector<float>` (flattened vector data).
    *   `cellCenters`: `std::vector<Vec3>` (computed).
    *   `bounds`: `AABB` (computed).

**Steps:**

1.  **Validation:**
    *   If `mesh.vertices` is empty, log error and return [S1, unofficial].
    *   If `mesh.indices` is empty and the mesh is not `POLYDATA` and not `renderAsPoints`, log error and return [S1, unofficial].
    *   Validate indices: For each index $i$ in `mesh.indices`, if $i \ge \text{vertexCount}$, log error, clear `mesh.indices`, and return to prevent GPU out-of-range fetches [S1, unofficial].

2.  **Cell Data Extrapolation:**
    *   Call `mesh_utils::extrapolateCellDataToPoints(mesh)` to interpolate cell-centered values to vertex locations [S1, unofficial].

3.  **Flatten Point Vectors:**
    *   Iterate over available point vector fields.
    *   Append each field's data to `mesh.pointVectorsData`.
    *   Record the start index in `mesh.pointVectorOffset[fieldName]`.
    *   Set `mesh.pointVectorCount` to `perVertex` (number of vertices) [S1, unofficial].

4.  **Flatten Cell Vectors:**
    *   Iterate over available cell vector fields.
    *   Append each field's data to `mesh.cellVectorsData`.
    *   Record per-field offsets.
    *   Set `mesh.cellVectorCount` to `cellCount` [S1, unofficial].
    *   If no `cellVectorName` is explicitly set, default to the first available cell vector name [S1, unofficial].

5.  **Compute Cell Centers:**
    *   For each cell, compute the center $C_c$ by averaging the positions of its corner vertices $V_i$:
        $$ C_c = \frac{1}{N} \sum_{i=1}^{N} V_i $$
        where $N$ is the number of vertices in the cell [S1, unofficial].

6.  **Select Active Scalar:**
    *   If `scalarName` is empty or not found in `pointScalars`, default to the first point scalar [S1, unofficial].
    *   Validate size: If the selected scalar's size does not match `vertexCount`, clear the scalars and log an error [S1, unofficial].

7.  **Populate UI Names:**
    *   Collect all available scalar and vector names.
    *   Sort them alphabetically for UI display [S1, unofficial].
    *   If no `vectorName` is set, default to the first available vector name [S1, unofficial].

8.  **Compute Normals and Bounds:**
    *   Call `mesh_utils::computeBounds(mesh)` to calculate the Axis-Aligned Bounding Box (AABB) [S1, unofficial].
    *   Call `mesh_utils::computeNormals(mesh)` to generate vertex normals [S1, unofficial].
    *   If `normals` is empty but `vertices` is not, assign default normals (e.g., zero or up vector) to prevent rendering artifacts [S1, unofficial].

**Pseudocode:**
```python
def finalize_mesh(mesh):
    # 1. Validation
    if len(mesh.vertices) == 0:
        log_error("Empty vertices")
        return None
    
    vertex_count = len(mesh.vertices) // 3
    
    if len(mesh.indices) == 0:
        if mesh.dataset_type != "POLYDATA" and not mesh.render_as_points:
            log_error("Empty indices for non-polydata mesh")
            return None
    
    # Validate indices
    for idx in mesh.indices:
        if idx >= vertex_count:
            log_error("Index out of range")
            mesh.indices = []
            return None
            
    # 2. Extrapolate Cell Data
    extrapolate_cell_data_to_points(mesh)
    
    # 3. Flatten Point Vectors
    mesh.point_vectors_data = []
    mesh.point_vector_offset = {}
    for field_name, field_data in mesh.point_vectors.items():
        mesh.point_vector_offset[field_name] = len(mesh.point_vectors_data)
        mesh.point_vectors_data.extend(field_data)
    mesh.point_vector_count = vertex_count
    
    # 4. Flatten Cell Vectors
    mesh.cell_vectors_data = []
    mesh.cell_vector_offset = {}
    for field_name, field_data in mesh.cell_vectors.items():
        mesh.cell_vector_offset[field_name] = len(mesh.cell_vectors_data)
        mesh.cell_vectors_data.extend(field_data)
    mesh.cell_vector_count = len(mesh.cells)
    
    if not mesh.cell_vector_name and mesh.cell_vectors:
        mesh.cell_vector_name = next(iter(mesh.cell_vectors))
        
    # 5. Compute Cell Centers
    mesh.cell_centers = []
    for cell in mesh.cells:
        cell_vertices = [mesh.vertices[v*3:v*3+3] for v in cell]
        center = [sum(v[i] for v in cell_vertices) / len(cell_vertices) for i in range(3)]
        mesh.cell_centers.append(center)
        
    # 6. Select Active Scalar
    if not mesh.scalar_name or mesh.scalar_name not in mesh.point_scalars:
        if mesh.point_scalars:
            mesh.scalar_name = next(iter(mesh.point_scalars))
        else:
            mesh.point_scalars = {}
    else:
        if len(mesh.point_scalars[mesh.scalar_name]) != vertex_count:
            log_error("Scalar size mismatch")
            mesh.point_scalars = {}
            
    # 7. Populate UI Names
    scalar_names = sorted(mesh.point_scalars.keys())
    vector_names = sorted(mesh.point_vectors.keys())
    
    if not mesh.vector_name and vector_names:
        mesh.vector_name = vector_names[0]
        
    # 8. Compute Normals and Bounds
    compute_bounds(mesh)
    compute_normals(mesh)
    
    if not mesh.normals and mesh.vertices:
        # Default normal assignment [G]
        mesh.normals = [0.0, 0.0, 1.0] * vertex_count
        
    return mesh
```

## Operating characteristics
*   **Time Complexity:** $O(V + I + C \cdot K)$, where $V$ is vertex count, $I$ is index count, $C$ is cell count, and $K$ is average cell vertex count (for center computation). Extrapolation is typically $O(C)$ or $O(V)$ depending on implementation.
*   **Memory Complexity:** $O(V + C + F \cdot V)$, where $F$ is the number of vector fields. Flattening creates contiguous copies of vector data.
*   **Strengths:** Ensures GPU safety by validating indices; provides consistent field data for rendering; computes necessary derived attributes (normals, bounds) in one pass.
*   **Limitations:** Requires all field data to be present before finalization; extrapolation quality depends on the underlying solver's cell topology.
*   **When to use:** After mesh assembly and before GPU buffer upload.
*   **When not to use:** If the mesh is purely point-based and requires no field interpolation, or if incremental updates are needed (finalization is typically a full rebuild).

## Background
Mesh Finalization originates from the VTK (Visualization Toolkit) ecosystem, specifically adapted for CFD (Computational Fluid Dynamics) visualization in tools like SciRender [S1, unofficial]. It addresses the need to convert unstructured grid data (common in CFD) into a format suitable for real-time rendering engines, handling the complexities of cell-to-point data mapping and topology validation [S1, unofficial].
