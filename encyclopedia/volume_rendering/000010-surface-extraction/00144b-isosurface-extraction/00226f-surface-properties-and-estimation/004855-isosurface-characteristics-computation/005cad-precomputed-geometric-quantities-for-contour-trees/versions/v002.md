# Precomputed Geometric Quantities for Contour Trees

Also called: B-spline contour quantification, Topology Change Graph coloring

## Overview
This method precomputes the geometric properties (area and volume) of all possible contours for a 3D scalar field, enabling real-time evaluation for any selected isovalue without expensive surface extraction [S1]. It differs from post-extraction methods by using a contour tree to hierarchically aggregate B-spline functions, allowing rapid quantification of contour properties [S1].

## How it works
**Inputs:** A 3D scalar field $f$ defined on a simplicial mesh; a contour tree $CT$ of the field [S1].
**Outputs:** Precomputed B-spline functions for area and volume for every edge in the contour tree; a Topology Change Graph (TCG) with nodes colored by geometric quantities [S1].

**Data Structures:**
1.  **Simplicial Mesh:** The domain of $f$ [S1].
2.  **Contour Tree ($CT$):** A graph where nodes are critical points and edges represent continuous families of contours [S1].
3.  **B-spline Functions:** For each simplex $s$, univariate functions $A_s(w)$ (area) and $V_s(w)$ (volume) are precomputed [S1].
4.  **Edge Data:** For each edge $e$ in $CT$, store:
    *   $S_e = \{s(e,1), \dots, s(e,n)\}$: The set of simplices covering the region of the contour class [S1].
    *   $A(e, w)$: The merged area B-spline function [S1].
    *   $V(e, w)$: The merged volume B-spline function [S1].
    *   $V_{e'}$: Precomputed volume constants for upper/lower edges [S1].

**Steps:**
1.  **Compute Simplex Functions:** For each simplex $s$ in the mesh, compute the univariate B-spline functions $A_s(w)$ and $V_s(w)$ representing the area and volume of the isosurface within that simplex as a function of isovalue $w$ [S1].
2.  **Construct Contour Tree:** Build the contour tree $CT$ for the scalar field $f$ [S1].
3.  **Identify Covering Simplices:** For each edge $e = (v_1, v_2)$ in $CT$ (where $f(v_1) \le f(v_2)$), identify the set of simplices $S_e$ that cover the region represented by the contour class of $e$. This is done by picking a seed cell in $e$ and propagating to adjacent simplices [S1].
4.  **Compute Edge Area Functions:** For each edge $e$, compute the merged area function $A(e, w)$ by summing the simplex functions:
    $$ A(e, w) = \sum_{k=1}^{n} A_{s(e,k)}(w) $$
    where $n = |S_e|$ [S1].
5.  **Identify Upper/Lower Edges:** For each edge $e$, identify the set of upper edges $E_{upper}(e)$ and lower edges $E_{lower}(e)$ in the contour tree. These sets define the "inside" or "outside" regions relative to the contour class of $e$ [S1].
6.  **Compute Edge Volumes Incrementally:**
    *   For each edge $e'$ in the contour tree, compute the volume $V_{e'}$ of the region covered by its contour class [S1].
    *   Compute $V_{e'}$ incrementally through the hierarchical structure of the contour tree [S1].
    *   For each edge $e$, compute the merged volume function $V(e, w)$:
        $$ V(e, w) = \sum_{k=1}^{n} V_{s(e,k)}(w) + \sum_{e' \in E(e)} V_{e'} $$
        where $E(e)$ is either $E_{upper}(e)$ or $E_{lower}(e)$, depending on the user's choice of which side (inside/outside) to quantify [S1].
7.  **Runtime Evaluation:** Given an isovalue $w_0$ and an edge $e$, evaluate $A(e, w_0)$ and $V(e, w_0)$ to get the area and volume of the contour [S1].
8.  **TCG Coloring:** Construct a Topology Change Graph (TCG) where nodes represent contour segments. Color each node based on the geometric quantity (e.g., surface area) of the contour it represents, computed via the precomputed functions [S1].

**Pseudocode:**

def precompute_geometric_quantities(scalar_field, mesh):
    """
    Precomputes area and volume B-splines for all contours in a scalar field.
    """
    # Step 1: Compute simplex-level B-splines
    simplex_area_splines = {}
    simplex_volume_splines = {}
    for simplex in mesh.simplices:
        simplex_area_splines[simplex] = compute_simplex_area_b_spline(simplex, scalar_field)
        simplex_volume_splines[simplex] = compute_simplex_volume_b_spline(simplex, scalar_field)

    # Step 2: Build Contour Tree
    contour_tree = build_contour_tree(scalar_field, mesh)

    # Step 3 & 4: Compute Edge Area Functions
    edge_area_functions = {}
    for edge in contour_tree.edges:
        covering_simplices = identify_covering_simplices(edge, contour_tree, scalar_field)
        edge_area_functions[edge] = merge_b_splines([simplex_area_splines[s] for s in covering_simplices])

    # Step 5 & 6: Compute Edge Volumes Incrementally
    edge_region_volumes = {}
    for edge in contour_tree.edges:
        edge_region_volumes[edge] = compute_edge_region_volume(edge, contour_tree)

    edge_volume_functions = {}
    for edge in contour_tree.edges:
        covering_simplices = identify_covering_simplices(edge, contour_tree, scalar_field)
        upper_edges = get_upper_edges(edge, contour_tree)
        lower_edges = get_lower_edges(edge, contour_tree)
        
        sum_simplex_volumes = merge_b_splines([simplex_volume_splines[s] for s in covering_simplices])
        sum_upper_region_volumes = sum(edge_region_volumes[e_prime] for e_prime in upper_edges)
        sum_lower_region_volumes = sum(edge_region_volumes[e_prime] for e_prime in lower_edges)
        
        edge_volume_functions[edge] = {
            'simplex_part': sum_simplex_volumes,
            'upper_region_part': sum_upper_region_volumes,
            'lower_region_part': sum_lower_region_volumes
        }

    # Step 8: Color TCG nodes
    tcg = build_topology_change_graph(contour_tree)
    for node in tcg.nodes:
        edge = node.contour_edge
        node.color = evaluate_b_spline(edge_area_functions[edge], node.representative_isovalue)

    return edge_area_functions, edge_volume_functions, tcg

def evaluate_contour_properties(edge_area_func, edge_volume_func, isovalue, side='upper'):
    """
    Evaluate area and volume for a specific isovalue and edge.

    area = evaluate_b_spline(edge_area_func, isovalue)

**Edge Cases and Pitfalls:**
*   **Precision:** B-spline evaluation must be accurate to avoid artifacts in real-time quantification [S1].
*   **Boundary Conditions:** The definition of "inside" vs "outside" depends on the choice of upper or lower edges, which must be consistent with the user's intent [S1].
*   **Degenerate Input:** The method assumes a valid simplicial mesh and a well-defined contour tree [S1].

## Operating characteristics
*   **Time Complexity:** Precomputation requires evaluating B-splines for all simplices and building the contour tree. Runtime evaluation is fast and supports real-time interactive exploration [S1].
*   **Memory Complexity:** Requires storing B-spline coefficients for all simplices and edges. Not given in the sources.
*   **Strengths:** Enables real-time interactive exploration of topological features without repeated surface extraction [S1].
*   **Limitations:** Requires precomputation for each timestep in time-varying data. Not given in the sources.
*   **When to use:** Interactive visualization of time-varying scalar fields where users need to quickly assess geometric properties of contours [S1].
*   **When not to use:** When only a single isosurface extraction is needed, as the overhead of precomputation may not be justified. Not given in the sources.
