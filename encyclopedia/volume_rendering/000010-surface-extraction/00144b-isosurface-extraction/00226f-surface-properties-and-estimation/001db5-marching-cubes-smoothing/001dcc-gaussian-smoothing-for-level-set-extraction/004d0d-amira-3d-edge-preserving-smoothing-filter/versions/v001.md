# Amira 3D Edge-Preserving Smoothing Filter

Also called: edge-preserving-smoothing filter

## Overview
The Amira 3D Edge-Preserving Smoothing Filter is a non-linear smoothing method applied to 3D grayscale image stacks to reduce noise while maintaining sharp boundaries between distinct structures. It addresses the limitation of linear Gaussian smoothing, which blurs edges by averaging across intensity discontinuities. Unlike the parent [Gaussian Smoothing for Level-Set Extraction](1605-gaussian-smoothing-for-level-set-extraction.md) which uses a fixed kernel, this method dynamically adjusts the convolution kernel based on local image content to prevent edge blurring.

## How it works
The filter operates on a 3D volume of floating-point intensity values. It iteratively smooths the volume by varying the convolution kernel size and weights based on the local contrast between neighboring voxels.

**Inputs:**
- A 3D volume $V$ of size $W \times H \times D$ with floating-point intensity values.
- Parameters: Contrast threshold $C$, smoothing sigma $\sigma$, step size $S$, and stop threshold $T$.

**Outputs:**
- A smoothed 3D volume $V'$.

**Data Structures:**
- The volume is stored as a contiguous array or 3D array of floats.
- A temporary buffer is used for intermediate calculations to avoid overwriting input data during iteration.

**Parameters:**
- Contrast threshold $C = 3.5$ [S1].
- Smoothing sigma $\sigma = 3$ [S1].
- Step size $S = 5$ [S1].
- Stop threshold $T = 25$ [S1].

**Algorithm:**
1. Initialize $V_{current} = V$.
2. Initialize iteration counter $k = 0$.
3. While $k < T$:
    a. Calculate the local gradient or intensity difference for each voxel.
    b. Determine the effective kernel size or weights for each voxel based on the local contrast relative to $C$. If the local intensity difference exceeds $C$, reduce the smoothing influence to preserve the edge.
    c. Apply a weighted 3D convolution to $V_{current}$ using the adaptive weights. The sigma $\sigma$ controls the base spread of the smoothing.
    d. Update $V_{next}$ with the result of the convolution.
    e. Set $V_{current} = V_{next}$.
    f. Increment $k$.
4. Return $V_{current}$.

**Pseudocode:**
```python
def amira_edge_preserving_smooth(volume, contrast_threshold=3.5, sigma=3.0, step_size=5, stop_threshold=25):
    """
    Applies the Amira 3D Edge-Preserving Smoothing Filter.
    
    Args:
        volume: 3D numpy array of floats.
        contrast_threshold: C, threshold for edge detection.
        sigma: sigma, base smoothing width.
        step_size: S, step size parameter (interpretation varies by implementation).
        stop_threshold: T, maximum number of iterations.
        
    Returns:
        Smoothed 3D volume.
    """
    import numpy as np
    
    # Copy input to avoid modification
    current_vol = volume.copy()
    
    # The exact mathematical formulation of the adaptive kernel 
    # is not fully specified in the source, but it varies based on local content.
    # We assume a standard iterative diffusion or weighted averaging approach.
    
    for k in range(stop_threshold):
        # Calculate local intensity differences (gradient magnitude)
        # Using central differences for gradient estimation
        gx = np.zeros_like(current_vol)
        gy = np.zeros_like(current_vol)
        gz = np.zeros_like(current_vol)
        
        # Gradient in x
        gx[:, 1:-1, :] = (current_vol[:, 2:, :] - current_vol[:, :-2, :]) / 2.0
        # Gradient in y
        gy[1:-1, :, :] = (current_vol[2:, :, :] - current_vol[:-2, :, :]) / 2.0
        # Gradient in z
        gz[:, :, 1:-1] = (current_vol[:, :, 2:] - current_vol[:, :, :-2]) / 2.0
        
        # Local gradient magnitude
        grad_mag = np.sqrt(gx**2 + gy**2 + gz**2)
        
        # Adaptive weight calculation based on contrast threshold
        # If gradient is high (edge), weight should be low to preserve edge.
        # If gradient is low (smooth region), weight should be high for smoothing.
        # A common form for edge-preserving filters (e.g., Perona-Malik or similar)
        # uses a function like exp(-(grad / C)^2).
        # The source states the kernel varies depending on image content.
        weights = np.exp(-(grad_mag / contrast_threshold)**2)
        
        # Apply smoothing kernel
        # The source mentions a 3D convolution. 
        # We use a Gaussian kernel with sigma for the base smoothing.
        # Note: The 'step_size' parameter's exact role in the kernel generation 
        # is not detailed in the source. It may relate to the discretization or 
        # the range of the kernel. Without explicit formula, we assume standard 
        # Gaussian convolution modulated by weights.
        
        # Create Gaussian kernel
        kernel_size = int(4 * sigma) + 1
        if kernel_size % 2 == 0:
            kernel_size += 1
        ax = np.arange(-kernel_size // 2 + 1., kernel_size // 2 + 1.)
        xx, yy, zz = np.meshgrid(ax, ax, ax)
        kernel = np.exp(-(xx**2 + yy**2 + zz**2) / (2.0 * sigma**2))
        kernel = kernel / kernel.sum()
        
        # Convolve with the volume
        # To apply the adaptive weights, we can perform a weighted convolution.
        # However, the source implies the kernel itself varies. 
        # A simpler interpretation often used in such filters is:
        # V_new = Conv(V, Kernel) * Weight + V * (1 - Weight)
        # Or iterative diffusion. Given the lack of explicit formula, 
        # we implement a weighted average of the current voxel and its neighbors.
        
        # For implementation completeness, we use a standard convolution 
        # and then blend based on weights, or apply the weight to the kernel.
        # The most robust interpretation of "varying the kernel" is that the 
        # effective support or weight is modulated by the gradient.
        
        # Let's assume a simple weighted smoothing:
        # Smoothed = Conv(V, Kernel)
        # V_next = V * (1 - weights) + Smoothed * weights
        
        smoothed = convolve_3d(current_vol, kernel)
        
        # Blend based on edge preservation weights
        # High weight (low gradient) -> more smoothing
        # Low weight (high gradient) -> less smoothing (preserve original)
        current_vol = current_vol * (1.0 - weights) + smoothed * weights
        
    return current_vol

def convolve_3d(volume, kernel):
    """
    Performs 3D convolution using FFT for efficiency.
    """
    import numpy as np
    from scipy.signal import fftconvolve
    
    # Pad volume to handle boundaries
    pad_size = kernel.shape[0] // 2
    padded_vol = np.pad(volume, pad_size, mode='reflect')
    
    # Perform convolution
    result = fftconvolve(padded_vol, kernel, mode='valid')
    
    return result
```

**Edge Cases and Pitfalls:**
- Boundary conditions: The source does not specify boundary handling. Reflection or replication padding is typical [G].
- Precision: Floating-point arithmetic is required to maintain intensity gradients accurately.
- Degenerate input: Uniform regions will be smoothed heavily; sharp edges will be preserved. If the contrast threshold is too low, edges may be blurred. If too high, noise may remain.

## Subtopics

### Amira 3D Gaussian Smoothing Filter
A linear smoothing method applied to 3D grayscale image stacks. It performs a three-dimensional convolution with a Gaussian kernel to smooth structures and interpolate borders in less-stretched sections based on neighboring gray values. It is used for general smoothing and balancing inhomogeneous stretching. It is chosen when edge preservation is not required and uniform smoothing is sufficient. It differs from the edge-preserving filter by using a fixed kernel regardless of local content. Parameters: Kernel dimensions $3 \times 3 \times 3$ or $6 \times 6 \times 6$ (source mentions both, likely depending on context or version), standard deviation $\sigma = (1, 1, 1)$ along the three spatial axes [S1].

## Operating characteristics
- **Time Complexity:** $O(N \cdot K^3)$ per iteration, where $N$ is the number of voxels and $K$ is the kernel size. The edge-preserving filter requires multiple iterations (up to 25), making it slower than a single-pass Gaussian filter.
- **Memory Complexity:** $O(N)$ for the volume and temporary buffers.
- **Performance:** The source does not provide measured performance benchmarks.
- **Strengths:** Preserves sharp edges and boundaries while reducing noise in homogeneous regions.
- **Limitations:** Slower than linear filters due to iterative nature and adaptive kernel calculation. Parameter tuning (contrast, sigma) is required for optimal results.
- **When to use:** When edge preservation is critical, such as in biological imaging where structures have distinct boundaries.
- **When not to use:** When computational speed is paramount and edge blurring is acceptable, or when the volume is already noise-free.

## Background
The Amira 3D Edge-Preserving Smoothing Filter is part of the Amira 3D software package (specifically Amira 4.1 as cited). It was used in the context of volume rendering from serial sections of biological specimens, such as *Cristatella mucedo* and *Phoronis australis*. The method was applied to align and smooth image stacks before rendering, particularly for colored image stacks based on paraffin wax sections where pre-rendering procedures were complex [S1].
