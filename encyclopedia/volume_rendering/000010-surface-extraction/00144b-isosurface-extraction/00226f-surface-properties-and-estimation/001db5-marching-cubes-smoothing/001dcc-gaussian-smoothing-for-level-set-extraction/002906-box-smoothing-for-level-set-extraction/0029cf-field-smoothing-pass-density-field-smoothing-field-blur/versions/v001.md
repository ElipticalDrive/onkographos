# Field Smoothing Pass — Density Field Smoothing, Field Blur

Also called: Box kernel filtering, GPU-based Scalar Field Smoothing, Pre-extraction smoothing

## Overview
A preprocessing step that applies a smoothing filter to the electromagnetic-potential scalar field on the GPU before isosurface extraction to suppress high-frequency variations and produce spatially coherent surfaces [S1]. Unlike mesh-based smoothing, this method does not directly average or displace vertices of an already extracted mesh; it filters the scalar field first, allowing Marching Cubes to generate rounded geometry instead of sharp stair-stepped edges [S1]. It builds on [Box Smoothing for Level-Set Extraction](4420-box-smoothing-for-level-set-extraction.md).

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D uniform Cartesian grid of scalar values $V_{i,j,k}(t)$ representing the electromagnetic potential, with constant spacing along each spatial axis [S1].
*   **Output:** A smoothed scalar field $\tilde{V}_{i,j,k}$ and the resulting isosurface geometry extracted via Marching Cubes [S1].

**Data Structures:**
*   The scalar field is stored as a 3D array. For a grid of size $N_x \times N_y \times N_z$, indices $(i,j,k)$ range from $0$ to $N_x-1$, $0$ to $N_y-1$, and $0$ to $N_z-1$ respectively [S1].
*   No padding is used; boundary samples use only valid neighboring grid locations [S1].

**Parameters:**
*   $\lambda$ (smoothing coefficient): Set to $0.35$ [S1].
*   Number of iterations: $5$ [S1].
*   Kernel size: $3 \times 3 \times 3$ [S1].

**Steps:**
1.  Initialize the current field state $V^{(t)}$ with the input scalar field values.
2.  For each iteration $t$ from $0$ to $4$ (5 iterations total):
    a. Create a temporary buffer $V^{(t+1)}$ initialized to zeros or copy $V^{(t)}$.
    b. For each voxel $(i,j,k)$ in the grid:
        i. Identify the set of valid neighbors $\mathcal{W}_{i,j,k}$ within the $3 \times 3 \times 3$ neighborhood centered at $(i,j,k)$. Valid neighbors are those where indices $a,b,c$ satisfy $i-1 \le a \le i+1$, $j-1 \le b \le j+1$, $k-1 \le k+1$, and lie within the grid bounds $[0, N_x-1] \times [0, N_y-1] \times [0, N_z-1]$ [S1].
        ii. Calculate the number of valid neighbors $|\mathcal{W}_{i,j,k}|$.
        iii. Compute the sum of scalar values in the neighborhood: $S = \sum_{(a,b,c) \in \mathcal{W}_{i,j,k}} V^{(t)}_{a,b,c}$ [S1].
        iv. Update the voxel value using the formula:
        $$ \tilde{V}_{i,j,k}(t+1) = (1-\lambda)V_{i,j,k}(t) + \frac{\lambda}{|\mathcal{W}_{i,j,k}|} \sum_{(a,b,c) \in \mathcal{W}_{i,j,k}} V_{a,b,c}(t) $$
        where $\lambda = 0.35$ [S1].
    c. Update $V^{(t)} \leftarrow V^{(t+1)}$.
3.  After 5 iterations, the final smoothed field is $\tilde{V} = V^{(5)}$ [S1].
4.  Perform Marching Cubes on the smoothed field $\tilde{V}$ [S1].
5.  For each intersected grid edge with endpoints $\mathbf{x}_0$ and $\mathbf{x}_1$, and corresponding scalar values $\tilde{V}(\mathbf{x}_0)$ and $\tilde{V}(\mathbf{x}_1)$, compute the isosurface vertex position $\mathbf{p}$ for isovalue $\tau$:
    $$ \mathbf{p} = \mathbf{x}_0 + \frac{\tau - \tilde{V}(\mathbf{x}_0)}{\tilde{V}(\mathbf{x}_1) - \tilde{V}(\mathbf{x}_0)} (\mathbf{x}_1 - \mathbf{x}_0) $$
    [S1].
6.  Recompute face normals from the resulting triangle geometry [S1].

**Pitfalls:**
*   Smoothing affects vertex coordinates indirectly through filtered scalar values; triangle connectivity and vertex count may change if the filtered field alters the local Marching Cubes case [S1].
*   Boundary handling must strictly exclude invalid neighbors without padding to avoid introducing artificial data [S1].

**Pseudocode:**
```python
def field_smoothing_pass(field: List[List[List[float]]], 
                         nx: int, ny: int, nz: int, 
                         lambda_val: float = 0.35, 
                         iterations: int = 5) -> List[List[List[float]]]:
    """
    Applies Gaussian-like smoothing via box kernel filtering to a 3D scalar field.
    
    Args:
        field: 3D list of scalar values V[i][j][k]
        nx, ny, nz: Dimensions of the grid
        lambda_val: Smoothing coefficient (default 0.35)
        iterations: Number of smoothing passes (default 5)
        
    Returns:
        Smoothed 3D field
    """
    # Initialize current field state
    current_field = [[[[field[i][j][k] for k in range(nz)] for j in range(ny)] for i in range(nx)]]
    
    for t in range(iterations):
        next_field = [[[0.0 for k in range(nz)] for j in range(ny)] for i in range(nx)]
        
        for i in range(nx):
            for j in range(ny):
                for k in range(nz):
                    # Identify valid neighbors in 3x3x3 neighborhood
                    neighbor_sum = 0.0
                    neighbor_count = 0
                    
                    for a in range(max(0, i-1), min(nx, i+2)):
                        for b in range(max(0, j-1), min(ny, j+2)):
                            for c in range(max(0, k-1), min(nz, k+2)):
                                neighbor_sum += current_field[a][b][c]
                                neighbor_count += 1
                    
                    # Apply smoothing formula
                    # V_tilde(i,j,k)(t+1) = (1-lambda)*V(i,j,k)(t) + lambda/|W| * sum(V_neighbors)
                    center_val = current_field[i][j][k]
                    avg_neighbor = neighbor_sum / neighbor_count
                    
                    next_field[i][j][k] = (1 - lambda_val) * center_val + lambda_val * avg_neighbor
        
        current_field = next_field
        
    return current_field

def marching_cubes_edge_intersection(x0: Vector3, x1: Vector3, 
                                     v0: float, v1: float, 
                                     isovalue: float) -> Vector3:
    """
    Computes the intersection point of an isosurface with a grid edge.
    
    Args:
        x0, x1: Endpoints of the grid edge
        v0, v1: Scalar values at x0 and x1 from the smoothed field
        isovalue: The threshold value tau
        
    Returns:
        Intersection point p
    """
    # p = x0 + (tau - V(x0)) / (V(x1) - V(x0)) * (x1 - x0)
    denominator = v1 - v0
    if abs(denominator) < 1e-9:
        # Avoid division by zero; return midpoint if values are equal
        return (x0 + x1) / 2.0
    
    t = (isovalue - v0) / denominator
    return x0 + t * (x1 - x0)
```

## Operating characteristics
*   **Time Complexity:** $O(N \cdot K \cdot I)$, where $N$ is the number of voxels, $K$ is the kernel size (27 for $3 \times 3 \times 3$), and $I$ is the number of iterations (5) [S1].
*   **Memory Complexity:** $O(N)$ for storing the scalar field and a temporary buffer for each iteration [S1].
*   **Measured Performance:** Tested on a $256^3$ uniform Cartesian grid on a GPU [S1]. The same procedure is applicable to $512^3$ fields, though experiments for scalability evaluation used $512^3$ primarily for buffer capacity testing [S1].
*   **Strengths:** Suppresses local high-frequency variations and produces a more spatially coherent surface without modifying the mesh topology directly [S1].
*   **Limitations:** Does not address out-of-core streaming or tile-based caching for very large datasets; future work is needed for improved scalability and feature preservation [S1].
*   **When to use:** When the input scalar field contains high-frequency noise or stair-stepping artifacts that degrade the visual quality of the extracted isosurface [S1].
*   **When not to use:** When preserving fine, high-frequency features is critical, as smoothing will blur them [S1].

## Background
The method was introduced in the context of visual tools for 3D plasma simulation, specifically for GPU-based isosurface extraction of electromagnetic-potential scalar fields [S1]. It was developed to address the visual artifacts produced by raw scalar fields in plasma simulations, such as high-frequency variations that lead to noisy isosurfaces [S1]. The approach leverages GPU parallelism to apply the smoothing filter efficiently before the Marching Cubes extraction step [S1].
