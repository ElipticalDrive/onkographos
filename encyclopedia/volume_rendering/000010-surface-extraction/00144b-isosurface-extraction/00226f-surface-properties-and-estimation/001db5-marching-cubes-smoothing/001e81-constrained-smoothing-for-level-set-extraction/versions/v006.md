# Constrained Smoothing for Level-Set Extraction

Also called: Lempitsky CVPR10 smoothing

## Overview
Constrained smoothing is a method to smooth the 0.5 level-set of binary volumes to improve mesh quality while preserving fine details, implemented via constrained optimization of a discrete Laplacian energy [S1, unofficial]. It sets itself apart from Gaussian smoothing by enforcing hard constraints on the signed distance function to prevent the erosion of thin structures and fine details, at the cost of higher computational complexity and memory usage [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A binary volume array $B$ (values 0 or 1).
- Output: A smoothed signed distance function (SDF) volume $D$ with the same dimensions as $B$.

**Data Structures:**
- `binary_array`: 2D or 3D array of integers/booleans.
- `distance`: 2D or 3D float array representing the SDF.
- `band`: Boolean mask or list of indices identifying cells where $|D| \le \text{band\_radius}$.
- `filterq`: Sparse matrix representing the discrete Laplacian operator on the band variables. For 3D, it is constructed from a sparse matrix $Q$ where $Q^T Q$ forms the Laplacian. The matrix size is $3N \times N$ for 3D (or $2N \times N$ for 2D), where $N$ is the number of band cells.
- `x`: Vector of optimization variables, initialized with distance values for band cells.
- `lower_bound`, `upper_bound`: Vectors of hard constraints for each band cell.

**Steps:**

1. **Compute Signed Distance Function (SDF):**
   Calculate the Euclidean distance transform for the binary array. Let $d_1$ be the distance to the nearest 1, and $d_0$ be the distance to the nearest 0.
   $$
   D[i] = \begin{cases} 
   d_1[i] - 0.5 & \text{if } B[i] = 1 \\
   -d_0[i] + 0.5 & \text{if } B[i] = 0 
   \end{cases}
   $$
   [S1, unofficial]

2. **Define Band and Border:**
   Identify the optimization band. A cell $i$ is in the band if $|D[i]| \le \text{band\_radius}$. The border is implicitly handled by the constraints (cells with $|D| < 1$ are clamped).
   [S1, unofficial]

3. **Build Filter Matrix (`filterq`):**
   Construct the sparse matrix representing the discrete Laplacian energy on the band cells.
   - Let $N$ be the number of band cells.
   - Create a sparse matrix $Q$ of size $3N \times N$ (for 3D) or $2N \times N$ (for 2D).
   - For each band cell $k$ at coordinates $(i,j,k)$:
     - Initialize diagonal entry $Q[3k, k] = -2$ (3D) or $Q[2k, k] = -2$ (2D).
     - For each neighbor direction (e.g., $i-1, i+1, j-1, j+1, k-1, k+1$):
       - If the neighbor is within the band, set $Q[\text{row}, \text{neighbor\_index}] = 1$.
       - If the neighbor is out of bounds or not in the band, increment the diagonal entry $Q[\text{row}, k]$ by 1.
     - Repeat for all 3 (or 2) rows corresponding to each cell $k$.
   - Compute `filterq` = $Q^T Q$.
   [S1, unofficial]

4. **Initialize Variables and Constraints:**
   - Let $x$ be a vector of size $N$, initialized with $D[i]$ for all band cells $i$.
   - Compute `upper_bound` for each band cell:
     $$
     \text{upper\_bound}[k] = \begin{cases} 
     x[k] & \text{if } x[k] < 0 \\
     \infty & \text{otherwise}
     \end{cases}
     $$
     Clamp `upper_bound` to 0 if $|\text{upper\_bound}[k]| < 1$.
   - Compute `lower_bound` for each band cell:
     $$
     \text{lower\_bound}[k] = \begin{cases} 
     x[k] & \text{if } x[k] > 0 \\
     -\infty & \text{otherwise}
     \end{cases}
     $$
     Clamp `lower_bound` to 0 if $|\text{lower\_bound}[k]| < 1$.
   [S1, unofficial]

5. **Solve Constrained Minimization:**
   Minimize the energy $E = \frac{1}{2} x^T \text{filterq} \, x$ subject to $\text{lower\_bound} \le x \le \text{upper\_bound}$ using Jacobi iteration.
   - Precompute Jacobi preconditioner components:
     - $D_{jacobi} = \text{diag}(\text{filterq})^{-1}$
     - $R_{jacobi} = \text{filterq} - \text{diag}(\text{filterq})$
   - Initialize $x$ with band distances.
   - Compute initial energy $E_0 = \frac{1}{2} x^T \text{filterq} \, x$.
   - Iterate for `max_iters`:
     - Update: $x_{new} = - D_{jacobi} \cdot (R_{jacobi} \cdot x)$
     - Relax: $x = \text{weight} \cdot x_{new} + (1 - \text{weight}) \cdot x$
     - Apply constraints: $x = \max(x, \text{lower\_bound})$; $x = \min(x, \text{upper\_bound})$
     - Check stopping criterion every 10 iterations:
       - Compute $E_{new} = \frac{1}{2} x^T \text{filterq} \, x$
       - If $\frac{E_{before} - E_{new}}{E_{before}} < 1 - (1 - \text{rel\_tol})^{10}$, stop.
   [S1, unofficial]

6. **Write Back:**
   Update the original distance array $D$ with the optimized values $x$ for the band cells.

**Pseudocode:**

```python
import numpy as np
from scipy import sparse, ndimage

def constrained_smoothing(binary_array, band_radius=4, max_iters=500, rel_tol=1e-6, weight=0.5):
    """
    Smooths the 0.5 level-set of a binary volume using constrained optimization.
    """
    # Step 1: Compute Signed Distance Function
    # dist_func computes Euclidean distance transform
    # Assuming binary_array is 0/1
    dist_pos = ndimage.distance_transform_edt(binary_array)
    dist_neg = ndimage.distance_transform_edt(1 - binary_array)
    
    distance = np.where(binary_array, dist_pos - 0.5, -dist_neg + 0.5)
    
    # Step 2: Define Band
    band_mask = np.abs(distance) <= band_radius
    band_indices = np.argwhere(band_mask)
    N = len(band_indices)
    
    if N == 0:
        return distance
        
    # Map 3D coordinates to linear index for band cells
    band_map = np.full(distance.shape, -1, dtype=int)
    for idx, (i, j, k) in enumerate(band_indices):
        band_map[i, j, k] = idx
        
    # Step 3: Build Filter Matrix (Laplacian)
    # Construct Q matrix: size (3*N, N) for 3D
    Q = sparse.lil_matrix((3 * N, N))
    
    # Pad band_map for easy neighbor access
    padded_map = np.pad(band_map, 1, mode='constant', constant_values=-1)
    
    for count, (i, j, k) in enumerate(band_indices):
        # Local coordinates in padded map
        pi, pj, pk = i + 1, j + 1, k + 1
        
        # X-axis neighbors
        Q[3*count, count] = -2
        neighbor = padded_map[pi-1, pj, pk]
        if neighbor >= 0:
            Q[3*count, neighbor] = 1
        else:
            Q[3*count, count] += 1
            
        neighbor = padded_map[pi+1, pj, pk]
        if neighbor >= 0:
            Q[3*count, neighbor] = 1
        else:
            Q[3*count, count] += 1
            
        # Y-axis neighbors
        Q[3*count+1, count] = -2
        neighbor = padded_map[pi, pj-1, pk]
        if neighbor >= 0:
            Q[3*count+1, neighbor] = 1
        else:
            Q[3*count+1, count] += 1
            
        neighbor = padded_map[pi, pj+1, pk]
        if neighbor >= 0:
            Q[3*count+1, neighbor] = 1
        else:
            Q[3*count+1, count] += 1
            
        # Z-axis neighbors
        Q[3*count+2, count] = -2
        neighbor = padded_map[pi, pj, pk-1]
        if neighbor >= 0:
            Q[3*count+2, neighbor] = 1
        else:
            Q[3*count+2, count] += 1
            
        neighbor = padded_map[pi, pj, pk+1]
        if neighbor >= 0:
            Q[3*count+2, neighbor] = 1
        else:
            Q[3*count+2, count] += 1
            
    filterq = (Q.T).dot(Q).tocsr()
    
    # Step 4: Initialize Variables and Constraints
    x = distance[band_mask]
    
    upper_bound = np.where(x < 0, x, np.inf)
    lower_bound = np.where(x > 0, x, -np.inf)
    
    # Clamp constraints near the zero level set
    upper_bound = np.where(np.abs(upper_bound) < 1, 0, upper_bound)
    lower_bound = np.where(np.abs(lower_bound) < 1, 0, lower_bound)
    
    # Step 5: Solve Constrained Minimization
    jacobi_d = 1.0 / filterq.diagonal()
    jacobi_r = filterq.copy()
    jacobi_r.setdiag(0)
    jacobi_r = jacobi_r.tocsr()
    
    energy_now = 0.5 * np.dot(x, filterq.dot(x))
    
    check_each = 10
    cum_rel_tol = 1 - (1 - rel_tol)**check_each
    
    for i in range(max_iters):
        x_1 = - jacobi_d * jacobi_r.dot(x)
        x = weight * x_1 + (1 - weight) * x
        
        # Apply constraints
        x = np.maximum(x, lower_bound)
        x = np.minimum(x, upper_bound)
        
        if (i + 1) % check_each == 0:
            energy_before = energy_now
            energy_now = 0.5 * np.dot(x, filterq.dot(x))
            
            if energy_before > 0:
                rel_improvement = (energy_before - energy_now) / energy_before
                if rel_improvement < cum_rel_tol:
                    break
                    
    # Step 6: Write Back
    distance[band_mask] = x
    return distance
```

**Parameters:**
- `band_radius`: Radius of the band around the level-set for optimization variables. Default: 4 [S1, unofficial].
- `max_iters`: Maximum number of Jacobi iterations. Default: 500 [S1, unofficial].
- `rel_tol`: Relative tolerance for stopping criterion. Default: 1e-6 [S1, unofficial].
- `weight`: Relaxation weight for Jacobi iteration. Default: 0.5 [S1, unofficial].

**Edge Cases and Pitfalls:**
- If the binary array is empty or full, the band may be empty, resulting in no change.
- Precision issues may arise if the distance transform values are very small near the zero level set; clamping constraints to 0 if $|bound| < 1$ helps stabilize this [S1, unofficial].
- The method is memory-intensive due to the sparse matrix construction, limiting its use on very large volumes [S1, unofficial].

## Subtopics

### [Laplacian Smoothing](3736-laplacian-smoothing.md)
A mesh smoothing technique that reduces noise by moving vertices toward the average of neighbors. It is an isotropic filter that does not explicitly preserve sharp features. Choose this for post-processing meshes rather than volume-level-set extraction.

## Operating characteristics
- **Time Complexity:** Dominated by the Jacobi iterations and sparse matrix-vector multiplications. Each iteration is $O(N)$ where $N$ is the number of band cells, but the constant factor is high due to sparse matrix overhead.
- **Memory Complexity:** $O(N)$ for the band variables and constraints, plus $O(N)$ for the sparse matrix `filterq`. The matrix size is proportional to the number of band cells.
- **Measured Performance:** Recommended for arrays smaller than $(500, 500, 500)$ due to memory and time constraints [S1, unofficial].
- **Strengths:** Preserves fine details and thin structures better than Gaussian smoothing by enforcing hard constraints on the SDF [S1, unofficial].
- **Limitations:** Slower and requires more memory than Gaussian smoothing [S1, unofficial].
- **When to Use:** When mesh quality from a binary volume is critical and fine details must be preserved, and the volume size is manageable.
- **When Not to Use:** For very large volumes or real-time applications where speed is prioritized over detail preservation.

## Background
The method is based on "Surface Extraction from Binary Volumes with Higher-Order Smoothness" by Victor Lempitsky, presented at CVPR 2010 [S1, unofficial]. It was implemented in the PyMCubes library as an unofficial contribution [S1, unofficial].
