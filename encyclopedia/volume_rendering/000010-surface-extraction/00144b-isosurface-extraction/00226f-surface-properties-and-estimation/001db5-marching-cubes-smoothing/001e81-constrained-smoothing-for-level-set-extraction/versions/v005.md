# Constrained Smoothing for Level-Set Extraction
Also called: Lempitsky CVPR10 smoothing

## Overview
Constrained smoothing is a method to smooth the 0.5 level-set of binary volumes to improve mesh quality while preserving fine details, implemented via constrained optimization of a discrete Laplacian energy [S1, unofficial]. Unlike Gaussian smoothing, which blurs features globally, this method preserves fine details and structures by restricting optimization to a narrow band around the isosurface and enforcing hard constraints on the signed distance values [S1, unofficial].

## How it works
**Inputs:** A binary volume array `binary_array` (dtype bool or int 0/1).
**Outputs:** A smoothed signed distance function (SDF) array `distance` of the same shape as `binary_array`.

**Data Structures:**
*   `band`: A boolean mask or list of indices identifying voxels where `|distance| <= band_radius`.
*   `filterq`: A sparse matrix representing the discrete Laplacian operator squared ($L^T L$) restricted to the band variables.
*   `x`: A 1D array of optimization variables, initialized to the SDF values of the band cells.
*   `lower_bound`, `upper_bound`: 1D arrays defining the hard constraints for each variable in `x`.

**Steps:**

1.  **Compute Signed Distance Function (SDF):**
    Calculate the Euclidean distance transform for the foreground and background.
    $$
    \text{distance}[v] = \begin{cases} 
    \text{dist\_func}(\text{binary\_array})[v] - 0.5 & \text{if } \text{binary\_array}[v] = 1 \\
    -\text{dist\_func}(1 - \text{binary\_array})[v] + 0.5 & \text{if } \text{binary\_array}[v] = 0 
    \end{cases}
    $$
    Where `dist_func` computes the Euclidean distance to the nearest boundary voxel.

2.  **Define Band and Border:**
    Identify the optimization domain.
    *   **Band:** Cells where `|distance| <= band_radius`. Default `band_radius = 4`.
    *   **Border:** Cells where `|distance| < 1`. These cells are fixed and not optimized.

3.  **Build Filter Matrix (`filterq`):**
    Construct the sparse matrix $Q = L^T L$ for the band variables. For each voxel $v$ in the band with index $k$ in the optimization vector:
    *   Initialize diagonal entry $Q_{kk}$ based on neighbors.
    *   For each of the 6 neighbors (in 3D) or 4 neighbors (in 2D):
        *   If the neighbor is inside the band, add 1 to the off-diagonal entry $Q_{k, \text{neighbor\_index}}$.
        *   If the neighbor is outside the band (or out of bounds), add 1 to the diagonal entry $Q_{kk}$.
    *   The diagonal is initialized to -2 for each axis direction (total -6 in 3D, -4 in 2D) before neighbor adjustments.
    *   The resulting matrix is $Q = L^T L$, where $L$ is the discrete Laplacian restricted to the band.

4.  **Initialize Optimization Variables:**
    Set the initial values for the optimization vector `x` to the SDF values of the band cells:
    $$ x = \text{distance}[\text{band}] $$

5.  **Set Hard Constraints:**
    Define bounds to preserve the sign and magnitude near the border:
    *   `upper_bound`: For each $x_i$, if $x_i < 0$, `upper_bound[i] = x_i` clamped to 0 if $|x_i| < 1$. Else `upper_bound[i] = \infty`.
    *   `lower_bound`: For each $x_i$, if $x_i > 0$, `lower_bound[i] = x_i` clamped to 0 if $|x_i| < 1$. Else `lower_bound[i] = -\infty`.
    This ensures that voxels close to the zero-crossing (border) do not cross it or change sign significantly.

6.  **Solve Constrained Minimization:**
    Minimize the energy $E = \frac{1}{2} x^T Q x$ using Jacobi iteration with relaxation.
    *   Precompute Jacobi splitting: $D = \text{diag}(Q)$, $R = Q - D$.
    *   Iteration update:
        $$ x_{new} = \omega \left( -D^{-1} R x_{old} \right) + (1 - \omega) x_{old} $$
        where $\omega = 0.5$ is the relaxation weight.
    *   Apply constraints after each step:
        $$ x_{new} = \max(x_{new}, \text{lower\_bound}) $$
        $$ x_{new} = \min(x_{new}, \text{upper\_bound}) $$
    *   Stopping criterion: Check every 10 iterations. If relative energy improvement $\frac{E_{before} - E_{now}}{E_{before}} < 1 - (1 - \text{rel\_tol})^{10}$, stop. Default `rel_tol = 1e-6`, `max_iters = 500`.

7.  **Update Distance Field:**
    Write the optimized values back to the `distance` array at the band indices.

**Pseudocode:**

```python
import numpy as np
from scipy import sparse, ndimage

def constrained_smoothing(binary_array, band_radius=4, max_iters=500, rel_tol=1e-6):
    """
    Smooths the level-set of a binary volume using constrained optimization.
    """
    # 1. Compute Signed Distance Function
    # Assuming dist_func computes Euclidean distance transform
    # For foreground (1)
    dist_pos = ndimage.distance_transform_edt(binary_array)
    # For background (0)
    dist_neg = ndimage.distance_transform_edt(~binary_array)
    
    distance = np.where(binary_array, dist_pos - 0.5, -dist_neg + 0.5)
    
    # 2. Define Band
    band_mask = np.abs(distance) <= band_radius
    band_indices = np.argwhere(band_mask)
    num_vars = len(band_indices)
    
    if num_vars == 0:
        return distance
        
    # Map 3D coordinates to 1D variable index
    var_index_map = np.full(distance.shape, -1, dtype=int)
    for idx, (i, j, k) in enumerate(band_indices):
        var_index_map[i, j, k] = idx
        
    # 3. Build Filter Matrix (L^T L)
    # Using COO format for efficiency
    rows = []
    cols = []
    vals = []
    
    # Pad for boundary checks
    padded_map = np.pad(var_index_map, 1, mode='constant', constant_values=-1)
    
    for idx, (i, j, k) in enumerate(band_indices):
        # Local coordinates in padded map
        pi, pj, pk = i + 1, j + 1, k + 1
        
        # Diagonal initialization: -2 per axis
        diag_val = -6.0 # 3 axes * -2
        
        # Neighbors in 3D: +/- x, +/- y, +/- z
        neighbors = [
            (pi-1, pj, pk), (pi+1, pj, pk),
            (pi, pj-1, pk), (pi, pj+1, pk),
            (pi, pj, pk-1), (pi, pj, pk+1)
        ]
        
        for ni, nj, nk in neighbors:
            neighbor_idx = padded_map[ni, nj, nk]
            if neighbor_idx >= 0:
                # Neighbor is in band
                rows.append(idx)
                cols.append(neighbor_idx)
                vals.append(1.0)
            else:
                # Neighbor is out of band/bounds
                diag_val += 1.0
                
        rows.append(idx)
        cols.append(idx)
        vals.append(diag_val)
        
    filterq = sparse.coo_matrix((vals, (rows, cols)), shape=(num_vars, num_vars)).tocsr()
    # Note: The source code computes filterq.T.dot(filterq) on a specific L matrix.
    # The construction above directly builds the Laplacian matrix L.
    # The energy is x^T L x. The source code's filterq is actually L^T L?
    # Re-reading source: filterq is built as L, then returned as filterq.T.dot(filterq).
    # So the matrix to use in energy x^T Q x is Q = L^T L.
    # However, the Jacobi iteration described uses filterq directly as the system matrix.
    # Let's stick to the source's variable name 'filterq' which is L^T L.
    
    # Re-building Q = L^T L explicitly from the L matrix constructed above
    # Actually, the source code builds 'filterq' as L, then returns filterq.T @ filterq.
    # Let's construct L first.
    L_rows = []
    L_cols = []
    L_vals = []
    
    for idx, (i, j, k) in enumerate(band_indices):
        pi, pj, pk = i + 1, j + 1, k + 1
        neighbors = [
            (pi-1, pj, pk), (pi+1, pj, pk),
            (pi, pj-1, pk), (pi, pj+1, pk),
            (pi, pj, pk-1), (pi, pj, pk+1)
        ]
        for ni, nj, nk in neighbors:
            neighbor_idx = padded_map[ni, nj, nk]
            if neighbor_idx >= 0:
                L_rows.append(idx)
                L_cols.append(neighbor_idx)
                L_vals.append(1.0)
            else:
                L_rows.append(idx)
                L_cols.append(idx)
                L_vals.append(1.0)
        # Diagonal -6
        L_rows.append(idx)
        L_cols.append(idx)
        L_vals.append(-6.0)
        
    L = sparse.coo_matrix((L_vals, (L_rows, L_cols)), shape=(num_vars, num_vars)).tocsr()
    filterq = L.T.dot(L)
    
    # 4. Initialize x
    x = distance[band_mask]
    
    # 5. Set Constraints
    upper_bound = np.where(x < 0, np.minimum(x, 0.0), np.inf)
    lower_bound = np.where(x > 0, np.maximum(x, 0.0), -np.inf)
    
    # Clamp bounds if |x| < 1
    # The source says: clamped to 0 if np.abs(upper_bound) < 1
    # This logic applies to the initial x.
    # If x < 0, upper_bound = x. If |x| < 1, upper_bound = 0.
    # If x >= 0, upper_bound = inf.
    # Same for lower_bound.
    
    # 6. Jacobi Iteration
    D_inv = 1.0 / filterq.diagonal()
    R = filterq - sparse.diags(D_inv) # R = Q - D, but we need Q - D for Jacobi?
    # Jacobi: x_new = D^-1 (b - R x_old). Here b=0.
    # So x_new = - D^-1 R x_old.
    # R in standard splitting A = D + R_split. Here A = filterq.
    # R_split = filterq - diag(filterq).
    R_split = filterq - sparse.diags(filterq.diagonal())
    
    weight = 0.5
    check_each = 10
    cum_rel_tol = 1 - (1 - rel_tol)**check_each
    
    energy_now = 0.5 * np.dot(x, filterq.dot(x))
    
    for i in range(max_iters):
        # x_1 = - D^-1 R_split x
        x_1 = - D_inv * R_split.dot(x)
        x = weight * x_1 + (1 - weight) * x
        
        # Apply constraints
        x = np.maximum(x, lower_bound)
        x = np.minimum(x, upper_bound)
        
        if (i + 1) % check_each == 0:
            energy_before = energy_now
            energy_now = 0.5 * np.dot(x, filterq.dot(x))
            if energy_before > 0:
                rel_improvement = (energy_before - energy_now) / energy_before
                if rel_improvement < cum_rel_tol:
                    break
                    
    # 7. Update distance
    distance[band_mask] = x
    
    return distance
```

## Subtopics

### [Laplacian Smoothing](3736-laplacian-smoothing.md)
A mesh smoothing technique applied to vertex positions to reduce noise or jaggedness. It computes the average position of each vertex's immediate neighbors in the mesh graph and updates the vertex position to reduce jaggedness (stairstepping) while preserving overall shape.

## Operating characteristics
*   **Time Complexity:** Depends on the number of band voxels and Jacobi iterations. Each iteration involves a sparse matrix-vector multiplication. Convergence is linear.
*   **Memory Complexity:** Proportional to the number of band voxels for storing `filterq` and `x`.
*   **Performance:** Slower than Gaussian smoothing and requires more memory [S1, unofficial]. Recommended for arrays smaller than (500, 500, 500) [S1, unofficial].
*   **Strengths:** Preserves fine details and thin structures that are often eroded by other smoothing methods like Gaussian smoothing [S1, unofficial].
*   **Limitations:** Computationally expensive for large volumes. Requires careful tuning of `band_radius` and `rel_tol`.

## Background
The method is based on "Surface Extraction from Binary Volumes with Higher-Order Smoothness" by Victor Lempitsky, presented at CVPR 2010 [S1, unofficial]. It addresses the issue of jagged meshes (stairstepping) produced by standard Marching Cubes on binary volumes by smoothing the underlying level-set function before extraction.
