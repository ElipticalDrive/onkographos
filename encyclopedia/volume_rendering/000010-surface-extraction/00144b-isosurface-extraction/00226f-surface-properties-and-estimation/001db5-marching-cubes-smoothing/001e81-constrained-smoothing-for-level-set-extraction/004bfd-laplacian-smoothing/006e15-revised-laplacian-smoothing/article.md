# Revised Laplacian Smoothing
Also called: Improved Laplacian smoothing

## Overview
Revised Laplacian Smoothing is a post-processing technique applied to polygonal meshes (typically generated by Marching Cubes) to mitigate the volume shrinkage and detail loss inherent in standard Laplacian smoothing [S1]. While standard smoothing reduces high-frequency noise, it often causes the mesh to contract inward, distorting the original geometry [S1]. This method differs from its siblings by explicitly constructing a cost function based on the distance between the smoothed mesh and the original source data, minimizing this error to recover lost details while maintaining structural integrity [S1].

## How it works
**Inputs:**
*   A smoothed polygonal mesh $M_{smooth}$ with vertex positions $P$.
*   The original source data (e.g., binary mask volume or original mesh $M_{orig}$) used to define the target surface [S1].
*   Mesh topology information (connectivity) [S1].

**Outputs:**
*   A revised mesh $M_{revised}$ where vertex positions are adjusted to minimize the cost function [S1].

**Data Structures:**
*   Vertex list: Stores 3D coordinates $(x, y, z)$ for each node.
*   Face list: Stores connectivity (indices of vertices forming triangles/quadrilaterals).
*   Normal vector: Per-vertex normal $\mathbf{P}_{normal}$, calculated from adjacent faces [S1].

**Parameters:**
*   $\alpha$: An increase parameter used to prevent excessive mesh structural changes during the correction step [S1].
*   $q$: Number of quadrilaterals sharing a node [S1].
*   $t$: Number of triangles sharing a node [S1].
*   $\omega$: Angle (in degrees) in the surface tangent plane at a boundary node filled by the surface [S1].

**Step-by-Step Method:**

1.  **Calculate Ideal Valence:**
    For each node, determine the ideal valence based on the local mesh topology. For internal nodes, the ideal valence $\nu_i$ is calculated as:
    $$ \nu_i = \frac{12(q + t)}{3q + 2t} $$
    For boundary nodes, the ideal valence $\nu_b$ is:
    $$ \nu_b = \nu_i + 1 $$
    These values are used to weight the smoothing influence, where weights $\omega$ are derived from the angle $\omega$ in the tangent plane [S1].

2.  **Compute Projector Vectors:**
    For each vertex $p$ in the smoothed mesh, identify the corresponding location in the original data (e.g., the containing cells in the volume mask or the closest point on the original mesh) [S1].
    Calculate the projector vectors $\mathbf{V}_{p_i-p}$ from the current vertex $p$ to all relevant points $p_i$ in the original data's containing cells [S1].

3.  **Calculate Total Projector Vector ($\mathbf{V}_t$):**
    Sum the projector vectors for vertex $p$:
    $$ \mathbf{V}_t = \sum_{i=0}^{n} (\mathbf{V}_{p_i-p}) $$
    where $n$ is the number of points in the containing cells [S1].

4.  **Determine Movement Direction ($\mathbf{V}_{Dir}$):**
    Compute the direction vector for moving the vertex back toward the original surface:
    $$ \mathbf{V}_{Dir} = \mathbf{P}_{normal} + \mathbf{V}_t \cdot \alpha $$
    where $\mathbf{P}_{normal}$ is the normal vector at vertex $p$, and $\alpha$ is the increase parameter [S1].

5.  **Construct Cost Function:**
    Define the cost function $j(\theta)$ to quantify the deviation from the original geometry. The goal is to minimize this function [S1]:
    $$ j(\theta) = \sum_{i=1}^{m} (d_1 + d_2 + \dots + d_n) $$
    where $m$ is the number of vertices being optimized [S1].

6.  **Calculate Distance Terms ($d_n$):**
    For each point, calculate the projector distance $d_n$ using the dot product relationship:
    $$ d_n = |\mathbf{V}_{Point}| \cdot |\mathbf{V}_{normal}| \cdot \cos(a) $$
    where $\mathbf{V}_{Point}$ is the vector from the original mesh to the current point, $\mathbf{V}_{normal}$ is the normal vector, and $a$ is the angle between them [S1].

7.  **Adjust Node Positions:**
    Update vertex positions along $\mathbf{V}_{Dir}$ such that the cost function $j(\theta)$ is minimized. This projection ensures the node remains constrained to the surface geometry defined by the original data, preventing the shrinkage typical of unconstrained Laplacian smoothing [S1].

**Edge Cases and Pitfalls:**
*   **Precision:** The calculation of $\cos(a)$ requires accurate normal vectors. Degenerate faces in the smoothed mesh may produce unstable normals.
*   **Boundaries:** Boundary nodes require special handling for valence calculation ($\nu_b$) and angle $\omega$ [S1].
*   **Shrinkage:** If $\alpha$ is too small, the correction may be insufficient to counteract shrinkage. If too large, it may introduce artifacts or overshoot the original surface [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the number of vertices $m$ and the number of points in containing cells $n$. The summation for $\mathbf{V}_t$ and the cost function evaluation are linear with respect to these counts [S1].
*   **Memory Complexity:** Requires storage for the mesh, normals, and access to the original data structure [S1].
*   **Performance:** In liver reconstruction tests, the Revised Laplacian Smoothing achieved a mean ratio of Revised/Original (R/O) volume of $1.002 \pm 0.007$, compared to $0.948 \pm 0.015$ for standard Laplacian Smoothing (L/O), showing a statistically significant improvement ($p<0.001$) [S1].
*   **Strengths:** Effectively recovers lost details and reduces shrinkage, bringing the smoothed mesh volume closer to the original source data [S1].
*   **Limitations:** Requires access to the original source data (mask or mesh) for the cost function calculation. May introduce slight structural changes if $\alpha$ is not tuned carefully [S1].

## Background
Revised Laplacian Smoothing was introduced in the context of three-dimensional liver reconstruction from CT or MRI images [S1]. Standard Laplacian smoothing, while effective for reducing noise in polygonal meshes generated by the Marching Cubes algorithm, suffers from the "shrinkage" problem, where the mesh volume becomes smaller than the original segmented data [S1]. This method was developed to address this disadvantage by constructing a cost function after the smoothing process to make up for lost important details [S1]. The work was supported by the Beijing Natural Science Foundation (4132080) and published by Atlantis Press in 2016 [S1].
