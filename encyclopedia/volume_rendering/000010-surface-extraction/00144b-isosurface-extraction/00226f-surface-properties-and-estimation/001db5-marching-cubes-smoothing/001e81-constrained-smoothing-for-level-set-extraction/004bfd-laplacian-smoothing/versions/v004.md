# Laplacian Smoothing
Also called: Isotropic spatial filter, Laplacian Relaxation, Laplacian Smooth
## Overview
Laplacian Smoothing is a mesh smoothing technique that reduces noise and jaggedness (such as stairstepping artifacts) by moving each vertex toward the average position of its immediate neighbors in the mesh graph [S3, unofficial]. It serves as an isotropic spatial filter that promotes smooth gradients and reduces anisotropy in surface representations [S1]. Unlike edge-aware filters, it does not explicitly preserve sharp features, often oversmoothing edges and converging slowly near piecewise smooth boundaries [S1].
## How it works
**Inputs and Outputs:**
- Input: A mesh defined by a list of vertices $V$ and a list of triangular faces $F$.
- Output: A modified mesh with updated vertex positions $V'$.

**Data Structures:**
- `vertices`: A list of $N$ vertices, where each vertex $i$ has a position vector $p_i \in \mathbb{R}^3$.
- `neighbors`: An adjacency list, typically a vector of vectors `neighbors[N]`, where `neighbors[i]` contains the indices of vertices directly connected to vertex $i$ via mesh edges.

**Steps:**
1. **Build Adjacency List:**
   Iterate through all triangles in the mesh. For each triangle with vertex indices $(a, b, c)$, add bidirectional edges between $a$ and $b$, $b$ and $c$, and $c$ and $a$ to the `neighbors` list. Ensure no duplicate neighbors are added for any vertex [S3, unofficial].

2. **Iterative Smoothing:**
   For a specified number of iterations `smoothIter`:
   a. Store the current vertex positions in a temporary array `old_pos` to ensure updates are based on the previous iteration's state [S3, unofficial].
   b. For each vertex $i$ from $0$ to $N-1$:
      i. Check if `neighbors[i]` is empty. If so, skip the vertex to prevent division by zero [S3, unofficial].
      ii. Calculate the average position $avg$ of the neighbors:
          $$ avg = \frac{1}{|N_i|} \sum_{j \in N_i} old\_pos_j $$
          where $N_i$ is the set of neighbor indices for vertex $i$, and $|N_i|$ is the count of neighbors.
      iii. Update the vertex position. In the basic form, the new position is set to the average:
          $$ p_i^{new} = avg $$
          Alternatively, a weighted blend can be used (e.g., Conservative Mesh Smoothing):
          $$ p_i^{new} = \alpha \cdot old\_pos_i + (1 - \alpha) \cdot avg $$
          where $\alpha$ is the weight for the original position [S3, unofficial].

**Parameters:**
- `smoothIter`: Number of smoothing iterations. Default is 0 [S2, unofficial].
- $\lambda$ (lambda): Smoothing strength parameter. In the context of gradient preconditioning, it appears in the operator $(I + \lambda L)^{-1}$, where $L$ is the Laplacian matrix [S1].
- Weights: In conservative variants, $\alpha = 0.6$ for the original position and $1-\alpha = 0.4$ for the neighbor average [S3, unofficial]. Other implementations may pass parameters like 0.1 and 0.5 to internal smoothing functions [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Isolated Vertices:** Vertices with no neighbors (empty adjacency list) must be skipped to avoid division by zero errors [S3, unofficial].
- **Oversmoothing:** The method is isotropic and tends to oversmooth sharp edges and corners, leading to slow convergence near piecewise smooth targets [S1].
- **Precision:** Repeated averaging can lead to numerical drift if not handled carefully, though standard floating-point arithmetic is generally sufficient for typical mesh sizes.

**Pseudocode:**
```python
def laplacian_smooth(vertices, faces, smooth_iter=1, alpha=1.0):
    """
    vertices: List of Vec3 positions [v0, v1, ...]
    faces: List of tuples (i, j, k) representing triangles
    smooth_iter: Number of iterations
    alpha: Weight for original position (1.0 = pure Laplacian, 0.6 = conservative)
    """
    n = len(vertices)
    
    # Step 1: Build adjacency list
    neighbors = [[] for _ in range(n)]
    for (a, b, c) in faces:
        # Add bidirectional edges, avoiding duplicates
        if b not in neighbors[a]: neighbors[a].append(b)
        if a not in neighbors[b]: neighbors[b].append(a)
        if c not in neighbors[b]: neighbors[b].append(c)
        if b not in neighbors[c]: neighbors[c].append(b)
        if a not in neighbors[c]: neighbors[c].append(a)
        if c not in neighbors[a]: neighbors[a].append(c)

    for iteration in range(smooth_iter):
        old_pos = [v.copy() for v in vertices]
        
        for i in range(n):
            if not neighbors[i]:
                continue # Skip isolated vertices
            
            # Calculate average of neighbors
            avg = Vec3(0, 0, 0)
            for j in neighbors[i]:
                avg += old_pos[j]
            avg /= len(neighbors[i])
            
            # Update position
            # If alpha=1.0, the term alpha * old_pos[i] is ignored in the blend formula
            # derived from conservative smoothing: p_new = alpha * p_old + (1-alpha) * avg
            # For pure Laplacian smoothing as described in [S3, unofficial] basic update, 
            # the assignment is often just p_new = avg. 
            # However, [S3, unofficial] explicitly mentions 0.6/0.4 weights for "Conservative Mesh Smoothing".
            # Standard Laplacian smoothing [S3, unofficial] implies direct assignment to avg if no alpha is specified.
            # We implement the general blend here.
            vertices[i] = alpha * old_pos[i] + (1.0 - alpha) * avg

    return vertices
```
## Subtopics

### [Volume-Adaptive Active Interface Model](13766-volume-adaptive-active-interface-model.md)
A mesh smoothing technique that reconstructs piecewise linear material interfaces from volume fraction data by iteratively balancing internal Laplacian smoothing forces with external volume-adaptive forces. It solves the problem of accurately representing multi-material junctions and complex topologies in volume fraction fields, where traditional methods like PLIC fail due to manifold constraints. Unlike standard Laplacian Smoothing, which only reduces noise, this method adaptively pushes the interface to match known material volumes, preventing the shrinkage inherent in pure Laplacian smoothing. It differs from Constrained Laplacian Fairing by using stochastic single-material force selection per iteration to handle multi-material junctions. [Volume-Adaptive Active Interface Model](13766-volume-adaptive-active-interface-model.md)

### [Constrained Laplacian Fairing](14502-constrained-laplacian-fairing.md)
A mesh fairing method inspired by Laplacian smoothing that replaces vertices with centroids of incident face centers, constrained to remain within their initial dual-grid cell to bound error. [Constrained Laplacian Fairing](14502-constrained-laplacian-fairing.md)

### Conservative Mesh Smoothing
A variant of Laplacian Smoothing that uses a weighted blend of the original vertex position and the neighbor average to preserve more of the original geometry. It uses smoothing weights of 0.6 for the original vertex position and 0.4 for the averaged neighbor position [S3, unofficial].

## Operating characteristics
- **Time Complexity:** $O(I \cdot E)$, where $I$ is the number of iterations and $E$ is the number of edges (or $O(I \cdot V)$ if adjacency is precomputed and averaged efficiently).
- **Memory Complexity:** $O(V + E)$ for storing the mesh and adjacency list.
- **Strengths:** Simple to implement; effective at reducing high-frequency noise and jaggedness; converges rapidly for smooth targets [S1].
- **Limitations:** Oversmooths sharp edges and features; converges slowly near edges for piecewise smooth targets; does not preserve volume or area constraints inherently [S1].
- **When to use:** When the primary goal is noise reduction on smooth surfaces and computational simplicity is preferred.
- **When not to use:** When sharp features, edges, or specific geometric constraints (like volume preservation) must be maintained; consider edge-aware filters or constrained variants instead [S1].
## Background
Laplacian smoothing has been applied to gradients in inverse rendering contexts, often combined with optimizers like Adam to smooth out sparse gradients [S1]. It is well-known in the context of the screened Poisson equation, where the smoothing operator $(I + \lambda L)^{-1}$ acts as an isotropic spatial filter related to the modified Bessel function of the second kind [S1]. Various discrete Laplacian operators, such as the cotangent Laplacian, have been explored for micro-mesh construction, though their benefits in standard inverse rendering may be limited [S1]. Adaptive kernel sizes have also been proposed to preserve high-frequency features, though the fundamental nature remains isotropic [S1].
