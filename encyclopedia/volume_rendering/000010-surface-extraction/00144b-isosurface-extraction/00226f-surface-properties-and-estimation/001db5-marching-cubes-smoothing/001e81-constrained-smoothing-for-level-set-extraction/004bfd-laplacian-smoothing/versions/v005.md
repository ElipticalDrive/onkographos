# Laplacian Smoothing

Also called: Isotropic spatial filter, Laplacian Relaxation, Laplacian Smooth

## Overview
Laplacian Smoothing is a mesh smoothing technique that reduces geometric noise and jaggedness (such as the stairstepping artifact in isosurfaces) by moving each vertex toward the average position of its immediate neighbors [S3, unofficial]. It acts as an isotropic spatial filter, effectively applying a low-pass filter to the vertex positions to promote smooth gradients [S1]. Unlike edge-aware filters (e.g., cross-bilateral filters), it does not explicitly preserve sharp features and may oversmooth edges if applied excessively [S1].

## How it works
**Inputs:** A mesh defined by a list of vertices $V$ and a list of triangles $T$.
**Outputs:** A smoothed mesh with updated vertex positions $V'$.

**Data Structures:**
- `vertices`: Array of 3D vectors $[x, y, z]$.
- `triangles`: Array of triplets of vertex indices $[i, j, k]$.
- `neighbors`: Adjacency list, typically a vector of vectors or hash map, where `neighbors[i]` contains the unique indices of vertices connected to vertex $i$ by an edge.

**Parameters:**
- $\lambda$ (smoothing strength): Controls the step size. In the preconditioner form $(I + \lambda L)^{-1}$, $\lambda$ controls smoothing strength [S1]. In iterative relaxation, this is often implicit in the blend weight.
- `smoothIter`: Number of smoothing iterations. Default is 0 (no smoothing) [S2, unofficial].
- `weight` (blend factor): The fraction of the neighbor average to apply. In the conservative variant, this is 0.4 for the average and 0.6 for the original position [S3, unofficial].

**Steps:**
1. **Build Adjacency List:**
   Iterate through all triangles. For each triangle with vertex indices $a, b, c$, add bidirectional edges: add $b$ to `neighbors[a]` and $a$ to `neighbors[b]`, and similarly for $(b,c)$ and $(c,a)$. Ensure no duplicate neighbors are added for each vertex [S3, unofficial].

2. **Iterative Smoothing:**
   For `smoothIter` iterations:
   a. Store current vertex positions in `old_pos` [S3, unofficial].
   b. For each vertex $i$:
      i. If `neighbors[i]` is empty, skip vertex $i$ (prevents division by zero) [S3, unofficial].
      ii. Compute the average position of neighbors:
          $$ \text{avg}_i = \frac{1}{|N_i|} \sum_{j \in N_i} \text{old\_pos}_j $$
          where $N_i$ is the set of neighbors of vertex $i$, and $|N_i|$ is the count of neighbors.
      iii. Update the vertex position. The standard Laplacian relaxation moves the vertex to the average. A weighted blend (Conservative Mesh Smoothing) updates as:
          $$ \text{new\_pos}_i = (1 - w) \cdot \text{old\_pos}_i + w \cdot \text{avg}_i $$
          where $w$ is the smoothing weight (e.g., 0.4) [S3, unofficial].

**Pseudocode:**
```python
def laplacian_smooth(vertices, triangles, smooth_iter=1, weight=0.4):
    # 1. Build adjacency list
    neighbors = [[] for _ in range(len(vertices))]
    for tri in triangles:
        a, b, c = tri
        # Add bidirectional edges, avoiding duplicates
        if b not in neighbors[a]: neighbors[a].append(b)
        if a not in neighbors[b]: neighbors[b].append(a)
        if c not in neighbors[b]: neighbors[b].append(c)
        if b not in neighbors[c]: neighbors[c].append(b)
        if a not in neighbors[c]: neighbors[c].append(a)
        if c not in neighbors[a]: neighbors[a].append(c)
    
    # 2. Iterative smoothing
    for _ in range(smooth_iter):
        old_pos = [v.copy() for v in vertices]
        
        for i in range(len(vertices)):
            if not neighbors[i]:
                continue # Skip isolated vertices
            
            # Calculate average of neighbors
            avg = [0.0, 0.0, 0.0]
            count = len(neighbors[i])
            for j in neighbors[i]:
                for k in range(3):
                    avg[k] += old_pos[j][k]
            
            for k in range(3):
                avg[k] /= count
            
            # Update position with weighted blend
            for k in range(3):
                vertices[i][k] = (1.0 - weight) * old_pos[i][k] + weight * avg[k]
                
    return vertices
```

## Subtopics

### Conservative Mesh Smoothing
A variant of Laplacian Smoothing that uses a weighted blend (e.g., 60% original, 40% neighbor average) instead of fully replacing the vertex position with the average [S3, unofficial]. This reduces the rate of convergence and prevents excessive shrinkage or drift, making it suitable for preserving the overall volume while reducing noise [S3, unofficial].

### [Volume-Adaptive Active Interface Model](13766-volume-adaptive-active-interface-model.md)
A technique that balances internal Laplacian smoothing forces with external volume-adaptive forces to reconstruct piecewise linear material interfaces from volume fraction data. Unlike standard Laplacian Smoothing, which only reduces noise, this method adaptively pushes the interface to match known material volumes, preventing the shrinkage artifact inherent in pure Laplacian smoothing. It is chosen for multi-material junctions in VOF simulations where traditional methods fail due to manifold constraints.

### [Constrained Laplacian Fairing](14502-constrained-laplacian-fairing.md)
A mesh smoothing technique that strictly bounds positional error by constraining vertex movement to the dual-grid cell of origin. It differs from standard Laplacian smoothing by preventing the mesh from drifting arbitrarily far from the extracted topology. It serves as the primary smoothing step for the SurfaceNet extraction method, addressing jaggedness in non-manifold mesh extraction from multi-material volumes.

## Operating characteristics
- **Time Complexity:** $O(I \cdot E)$, where $I$ is the number of iterations and $E$ is the number of edges (or $O(I \cdot V)$ if adjacency is precomputed and dense). Each iteration processes each vertex and its neighbors [S3, unofficial].
- **Memory Complexity:** $O(V + E)$ for storing the mesh and adjacency list [S3, unofficial].
- **Strengths:** Simple to implement; effective at removing high-frequency noise and jaggedness from isosurfaces; isotropic smoothing promotes smooth gradients [S1][S3, unofficial].
- **Limitations:** Oversmooths sharp edges and features; converges slowly near edges for piecewise smooth targets; does not preserve volume or topology strictly without constraints [S1].
- **When to use:** When the primary goal is noise reduction on smooth surfaces and edge preservation is not critical.
- **When not to use:** When sharp features must be preserved (use edge-aware filters) or when volume preservation is critical (use constrained variants) [S1].

## Background
Laplacian smoothing has been applied to gradients in inverse rendering as a preconditioner of the form $(I + \lambda L)^{-1}$, where $L$ is the Laplacian matrix [S1]. It is well-known that this operation acts as an isotropic spatial filter, related to the solution of the screened Poisson equation [S1]. In mesh processing, it is a standard technique for reducing jaggedness in extracted surfaces [S3, unofficial]. Variants like the cotangent Laplacian have been explored for micro-mesh construction but offer limited benefits in standard inverse rendering [S1].
