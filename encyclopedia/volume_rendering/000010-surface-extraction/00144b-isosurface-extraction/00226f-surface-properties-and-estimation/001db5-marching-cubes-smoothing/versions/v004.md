# Marching Cubes Smoothing

Also called: Smoothing Binary Embeddings, mcubes.smooth

## Overview
Marching Cubes Smoothing transforms a binary embedding array into a continuous signed distance-like field to eliminate the jagged artifacts inherent in extracting isosurfaces directly from discrete binary masks [S1, unofficial]. Unlike standard smoothing techniques that erode fine details and thin structures, this method preserves the original topological information by assigning negative values to background regions and positive values to foreground regions, allowing for a high-quality mesh extraction at the zero-levelset [S1, unofficial]. It addresses the specific problem of jagged meshes produced when passing binary masks directly to the marching cubes algorithm [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 2D or 3D binary array (embedding) where voxel values are strictly `0` (background) or `1` (foreground) [S1, unofficial].
*   **Output:** A 2D or 3D floating-point array of the same dimensions, containing negative values where the input was `0` and positive values where the input was `1` [S1, unofficial].

**Data Structures:**
*   The input is typically a NumPy array of integer or boolean type [S1, unofficial].
*   The output is a NumPy array of floating-point type (e.g., `float32` or `float64`) [S1, unofficial].

**Algorithm Steps:**
1.  **Accept Binary Input:** Receive a binary array $B$ where $B_{i,j,k} \in \{0, 1\}$ [S1, unofficial].
2.  **Generate Smooth Embedding:** Compute a smooth embedding array $S$ from $B$. The transformation ensures that regions corresponding to `0` in $B$ become negative in $S$, and regions corresponding to `1` in $B$ become positive in $S$ [S1, unofficial].
3.  **Preserve Topology:** The smoothing process keeps all information from the original embedding function, specifically avoiding the erosion of fine details and thin structures common in other methods [S1, unofficial].
4.  **Extract Isosurface:** Use the resulting array $S$ as input to the marching cubes algorithm with an isovalue of `0` [S1, unofficial].

## Subtopics

### [Gaussian Smoothing for Level-Set Extraction](1605-gaussian-smoothing-for-level-set-extraction.md)
A fast smoothing method applied to binary volumes by converting them to float, subtracting 0.5, and applying a Gaussian filter. It differs from Constrained Smoothing by using direct linear convolution, making it faster but less precise in preserving thin structures.

### [Constrained Smoothing for Level-Set Extraction](1784-constrained-smoothing-for-level-set-extraction.md)
A method that smooths the 0.5 level-set of binary volumes via constrained optimization of a discrete Laplacian energy. It sets itself apart by enforcing hard constraints to prevent erosion of thin structures, at the cost of higher computational complexity.

## Background
The method is part of the `PyMCubes` library, which provides Python bindings for the marching cubes algorithm [S1, unofficial]. The specific function `mcubes.smooth` was introduced to address the common issue of jagged meshes resulting from binary embeddings in segmentation tasks [S1, unofficial]. The library utilizes Cython for performance-critical components [S1, unofficial].
