# Incremental Isosurface Extraction

Also called: Incremental extraction, Incremental search

## Overview
Incremental isosurface extraction is an optimization for isosurface extraction that reuses the state from a previous query (with isovalue $q$) to accelerate a new query (with isovalue $q'$), avoiding full re-scanning of the data structure by tracking active/inactive cell boundaries via markers [S1, unofficial]. It builds on [Fixed-Sized Buckets for Isosurface Extraction](1252-fixed-sized-buckets-for-isosurface-extraction.md) by maintaining boundary markers that allow the algorithm to skip over cells whose active status is known to be unchanged, rather than re-evaluating every cell in the active range [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: The fixed-sized bucket data structure (min-dictionary, cell records, and optional marker cells), the previous isovalue $q$, the new isovalue $q'$, and the previous set of active buckets/cells.
- Output: The set of active cells for isovalue $q'$.

**Data Structures:**
The method relies on the data structure from Fixed-Sized Buckets, extended with markers for incremental operation [S1, unofficial]:
- **Cell Records:** $N$ records, one for each cell in the dataset.
- **Min-Dictionary:** $N/B + 1$ values, storing the minimum intensity value for each bucket.
- **Marker Cells:** $N/B + 1$ additional cells (one per bucket) used to track the boundary between active and inactive cells within a bucket. These are only required if incremental extraction is used [S1, unofficial].
- **Memory Complexity:** $O(N + 2 \cdot N/B + 2) = O(N)$ [S1, unofficial].

**Parameters:**
- $B$: Bucket size (number of cells per bucket). Typical value is 4096. Empirical results show average active cell lookup time decreases toward 4096 and increases past 8192. The optimal choice is not related to input data size [S1, unofficial].

**Algorithm Steps:**
The algorithm distinguishes between increasing isovalue ($q' > q$) and decreasing isovalue ($q' < q$). Let $c^*_0, \dots, c^*_a$ be the set of active buckets for the previous isovalue $q$, and $c^*_0, \dots, c^*_{a'}$ be the set for the new isovalue $q'$.

### Increasing Isovalue ($q' > q$)
The buckets to visit fall into three categories [S1, unofficial]:

1.  **Buckets $c^*_0 \dots c^*_{a-1}$ remain active:**
    - These buckets were active in the previous query and remain active.
    - Markers are pushed upward (t higher indices) to deactivate cells that are no longer active.
    - Only the max-criterion is checked when updating markers because the bucket satisfies the min-criterion (it is already known to be active) [S1, unofficial].

2.  **The former last active bucket $c^*_a$:**
    - This bucket now has a single contiguous block of active cells and a single contiguous block of inactive cells.
    - Cells are traversed one by one to determine activation/deactivation status [S1, unofficial].

3.  **Buckets $c^*_{a+1} \dots c^*_{a'}$ have just become active:**
    - These buckets were inactive in the previous query but are now active.
    - The full extraction method is applied starting at bucket $c^*_{a+1}$ rather than $c^*_0$ [S1, unofficial].

### Decreasing Isovalue ($q' < q$)
The buckets to visit fall into three categories [S1, unofficial]:

1.  **Buckets $c^*_0 \dots c^*_{a'-1}$ remain active:**
    - These buckets were active in the previous query and remain active.
    - Markers are pushed downward (to lower indices) to activate cells that are newly active.
    - Only the max-criterion is checked in updating markers [S1, unofficial].

2.  **The new last active bucket $c^*_{a'}$:**
    - This bucket contains non-contiguous blocks of cells that must be activated and deactivated.
    - Cells are traversed to determine status [S1, unofficial].

3.  **Buckets $c^*_{a'+1} \dots c^*_a$ have become inactive:**
    - These buckets were active in the previous query but are now inactive.
    - The full extraction method is applied starting at bucket $c^*_{a'+1}$, but instead of activating cells, the visited cells are deactivated [S1, unofficial].

**Pseudocode:**
```python
def incremental_extraction(prev_buckets, prev_markers, new_isovalue, bucket_size, min_dict, cell_records):
    """
    Performs incremental isosurface extraction.
    
    Args:
        prev_buckets: List of active bucket indices from the previous query.
        prev_markers: List of marker indices for each bucket from the previous query.
        new_isovalue: The new isovalue q'.
        bucket_size: B, the number of cells per bucket.
        min_dict: Array of minimum values for each bucket.
        cell_records: Array of cell records, each containing intensity value.
        
    Returns:
        List of active cell indices for the new isovalue.
    """
    # Determine new set of active buckets based on min_dict and new_isovalue
    # This step assumes a helper function to find buckets where min_value <= isovalue
    new_buckets = find_active_buckets(new_isovalue, min_dict, bucket_size)
    
    active_cells = []
    
    # Determine direction of change
    if new_isovalue > prev_isovalue:
        # Increasing Isovalue
        # 1. Buckets that remain active (excluding the last one)
        for i in range(len(prev_buckets) - 1):
            bucket_idx = prev_buckets[i]
            # Push marker upward to deactivate cells
            active_cells.extend(push_marker_up(bucket_idx, prev_markers[i], new_isovalue, bucket_size, min_dict, cell_records))
            
        # 2. The former last active bucket
        if prev_buckets:
            last_bucket_idx = prev_buckets[-1]
            # Traverse cells to determine activation/deactivation
            active_cells.extend(traverse_last_bucket(last_bucket_idx, new_isovalue, bucket_size, min_dict, cell_records))
            
        # 3. Buckets that have just become active
        # Start from the first new bucket that was not in prev_buckets
        start_idx = len(prev_buckets)
        if start_idx < len(new_buckets):
            for i in range(start_idx, len(new_buckets)):
                bucket_idx = new_buckets[i]
                # Apply full extraction method starting at this bucket
                active_cells.extend(full_extraction(bucket_idx, new_isovalue, bucket_size, min_dict, cell_records))
                
    else:
        # Decreasing Isovalue
        # 1. Buckets that remain active (excluding the new last one)
        for i in range(len(new_buckets) - 1):
            bucket_idx = new_buckets[i]
            # Push marker downward to activate cells
            active_cells.extend(push_marker_down(bucket_idx, prev_markers[i], new_isovalue, bucket_size, min_dict, cell_records))
            
        # 2. The new last active bucket
        if new_buckets:
            last_bucket_idx = new_buckets[-1]
            # Traverse cells to determine activation/deactivation
            active_cells.extend(traverse_last_bucket(last_bucket_idx, new_isovalue, bucket_size, min_dict, cell_records))
            
        # 3. Buckets that have become inactive
        # Start from the first bucket that was in prev_buckets but not in new_buckets
        # These cells must be deactivated
        start_idx = len(new_buckets)
        if start_idx < len(prev_buckets):
            for i in range(start_idx, len(prev_buckets)):
                bucket_idx = prev_buckets[i]
                # Apply full extraction method but deactivate cells
                active_cells.extend(deactivate_cells(bucket_idx, new_isovalue, bucket_size, min_dict, cell_records))
                
    return active_cells

def push_marker_up(bucket_idx, marker_idx, isovalue, bucket_size, min_dict, cell_records):
    """
    Pushes the marker upward in a bucket that remains active.
    Deactivates cells above the new marker position.
    """
    # Get the start index of the bucket
    start_idx = bucket_idx * bucket_size
    end_idx = min(start_idx + bucket_size, len(cell_records))
    
    active_cells = []
    # Check cells from marker_idx down to start_idx
    # Only max-criterion needs to be checked because the bucket is active (min-criterion satisfied)
    for i in range(marker_idx, start_idx, -1):
        if cell_records[i].value > isovalue:
            # Cell is inactive, marker moves up
            marker_idx = i - 1
        else:
            # Cell is active, add to active cells
            active_cells.append(i)
            
    # Update marker for this bucket (stored in prev_markers or returned)
    # For simplicity, we assume the marker is updated in the caller's state
    return active_cells

def push_marker_down(bucket_idx, marker_idx, isovalue, bucket_size, min_dict, cell_records):
    """
    Pushes the marker downward in a bucket that remains active.
    Activates cells below the new marker position.
    """
    start_idx = bucket_idx * bucket_size
    end_idx = min(start_idx + bucket_size, len(cell_records))
    
    active_cells = []
    # Check cells from marker_idx up to end_idx
    # Only max-criterion needs to be checked
    for i in range(marker_idx, end_idx):
        if cell_records[i].value <= isovalue:
            # Cell is active, add to active cells
            active_cells.append(i)
        else:
            # Cell is inactive, marker moves down
            marker_idx = i + 1
            
    return active_cells

def traverse_last_bucket(bucket_idx, isovalue, bucket_size, min_dict, cell_records):
    """
    Traverses the last active bucket to determine activation/deactivation.
    """
    start_idx = bucket_idx * bucket_size
    end_idx = min(start_idx + bucket_size, len(cell_records))
    
    active_cells = []
    # Check both min and max criteria for every cell
    for i in range(start_idx, end_idx):
        if min_dict[bucket_idx] <= isovalue and cell_records[i].value <= isovalue:
            active_cells.append(i)
            
    return active_cells

def full_extraction(bucket_idx, isovalue, bucket_size, min_dict, cell_records):
    """
    Applies the full extraction method to a bucket.
    """
    start_idx = bucket_idx * bucket_size
    end_idx = min(start_idx + bucket_size, len(cell_records))
    
    active_cells = []
    # Check min-dictionary first
    if min_dict[bucket_idx] > isovalue:
        return active_cells
        
    # Check max-criterion for each cell
    for i in range(start_idx, end_idx):
        if cell_records[i].value <= isovalue:
            active_cells.append(i)
            
    return active_cells

def deactivate_cells(bucket_idx, isovalue, bucket_size, min_dict, cell_records):
    """
    Applies the full extraction method but deactivates cells.
    """
    start_idx = bucket_idx * bucket_size
    end_idx = min(start_idx + bucket_size, len(cell_records))
    
    # Cells that were active before are now inactive
    # This function is called for buckets that have become inactive
    # The caller should handle the logic of removing these cells from the active set
    # For the purpose of this pseudocode, we return the cells that need to be deactivated
    cells_to_deactivate = []
    for i in range(start_idx, end_idx):
        # If the cell was active before, it needs to be deactivated
        # We assume the caller has a way to know which cells were active
        # Here we just return all cells in the bucket for simplicity
        cells_to_deactivate.append(i)
        
    return cells_to_deactivate
```

**Edge Cases and Pitfalls:**
- **Pathological Worst-Case:** If only one cell is active and located at the bottom of the last bucket, the algorithm traverses $N/B$ buckets and $B$ inactive cells. This is extremely rare in real application data [S1, unofficial].
- **Precision:** Standard floating-point comparisons should be used. No specific precision issues are noted in the sources [S1, unofficial].

## Operating characteristics
- **Time Complexity:**
    - **Average-Case:** $O(K + B)$, where $K$ is the number of active cells and $B$ is the bucket size. This is derived from at most three comparisons per cell in a normal bucket (one max-criterion per active cell, one min-dictionary check, one failed max-criterion check per bucket) and at most two comparisons per cell in the last active bucket (bounded by $B$). Total: $O(3K + 2B) = O(K + B)$ [S1, unofficial].
    - **Worst-Case:** $O(N)$, if only one cell is active and located at the bottom of the last bucket, traversing $N/B$ buckets and $B$ inactive cells [S1, unofficial]. If $B = \sqrt{N}$, the average and worst case extraction is upper-bounded to $O(K + \sqrt{N})$ [S1, unofficial].
- **Memory Complexity:** $O(N)$, with a constant factor increase of $3 + 1/B$ without incremental extraction markers and $3 + 2/B$ with incremental extraction markers [S1, unofficial].
- **Measured Performance:**
    - **RockerArm Dataset:** Full extraction average search time 0.967 ms; Incremental extraction 0.444 ms; Coherence 63% [S1, unofficial].
    - **Engine Dataset:** Full extraction average search time 2.285 ms; Incremental extraction 0.432 ms; Coherence 88% [S1, unofficial].
- **Strengths:** Competitive with the interval tree method, an optimal technique. Achieves $O(K)$ performance on average for real datasets [S1, unofficial].
- **Limitations:** Performance depends on the coherence of the data. Pathological worst-case is rare but possible [S1, unofficial].
- **When to Use:** When isovalue changes are small and coherent, incremental extraction provides significant speedups. When isovalue changes are large or incoherent, full extraction may be more appropriate [S1, unofficial].

## Background
Incremental isosurface extraction was proposed in the paper "Isosurface Extraction Using Fixed-Sized Buckets" (2005) as an optimization for the fixed-sized bucket method [S1, unofficial]. It was designed to improve performance in scenarios where isovalue changes are frequent and coherent, such as in interactive visualization or animation [S1, unofficial]. The method is competitive with the interval tree method, which is considered an optimal technique for isosurface extraction [S1, unofficial].
