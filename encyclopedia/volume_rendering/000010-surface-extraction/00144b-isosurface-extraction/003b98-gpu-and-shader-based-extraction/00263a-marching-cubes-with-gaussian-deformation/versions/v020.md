# Marching Cubes with Gaussian Deformation

Also called: Geometry Shader Marching Cubes, Marching Cubes Geometry Shader Variant, Marching Cubes with Brush Deformation

## Overview
This method extracts a triangle mesh from a scalar field defined by a sphere function using a Geometry Shader, applying a Gaussian-based deformation along a user-provided force vector to simulate real-time terrain or mesh interaction [S1, unofficial]. It differs from standard static Marching Cubes implementations by integrating the deformation calculation directly into the geometry shader pipeline, allowing for dynamic, GPU-accelerated surface modification without CPU-side mesh regeneration [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A point primitive buffer where each point represents a voxel grid position (center of a cube) [S1, unofficial]. Uniforms include `gridSize` (float, typically 0.25f), `i_force` (vec3, deformation direction and magnitude), and `sigma` (float, typically 0.8) [S1, unofficial].
*   **Output:** A `TriangleStream` of vertices containing positions, normals, and UVs [S2, unofficial].

**Data Structures:**
*   **Edge Table (`edgeTableTex`):** A 2D texture of size 256×1 storing 16-bit integers, accessed via `texelFetch(tex, ivec2(index, 0), 0).r` [S1, unofficial]. Index `i` contains the bitmask of intersected edges for cube index `i` [S1, unofficial].
*   **Triangle Table (`triTableTex`):** A 2D texture of size 256×1 storing 24 integers per cube index, accessed via `texelFetch(tex, ivec2(index, 0), 0).r` [S1, unofficial]. Maps cube index to a list of triangle vertex indices terminated by -1 [S1, unofficial].
*   **Edge Vertex Indices (`cube_diff_indices`):** A static integer array of size 24, mapping edge index `i` to two vertex indices: `cube_diff_indices[i*2]` and `cube_diff_indices[i*2+1]` [S1, unofficial]. Values: `0,1, 1,2, 2,3, 3,0, 4,5, 5,6, 6,7, 7,4, 0,4, 1,5, 2,6, 3,7` [S1, unofficial].
*   **GS Input/Output Structure:** Contains `float4 pos`, `float3 normal`, `float2 tex0` [S2, unofficial].

**Steps:**

1.  **Vertex Shader:**
    *   Pass the input vertex position, normal, and texture coordinates unchanged to the Geometry Shader [S2, unofficial].

2.  **Geometry Shader (Per Voxel):**
    *   **Cube Index Calculation:**
        *   Let `p_center` be the input vertex position (voxel center) [S1, unofficial].
        *   Let `s` be `gridSize` [S1, unofficial].
        *   For each of the 8 corners `k` (0 to 7) of the cube centered at `p_center`:
            *   Compute corner position `c_k = p_center + offset_k * s`, where `offset_k` is the standard MC corner offset vector (e.g., `(-1,-1,-1)`, `(1,-1,-1)`, etc.) [G].
            *   Evaluate scalar field `f(c_k)` using the sphere function (see Formula below) [S1, unofficial].
            *   If `f(c_k) < 0.0`, set bit `k` in `cube_index` [S1, unofficial].
    *   **Edge Intersection Check:**
        *   Fetch the edge mask from `edgeTableTex` using `cube_index` [S1, unofficial].
        *   If the mask is 0, discard the primitive [S1, unofficial].
    *   **Vertex Interpolation:**
        *   For each of the 12 edges `i` (0 to 11):
            *   If bit `i` is set in the edge mask:
                *   Get the two corner indices `v1_idx` and `v2_idx` from `cube_diff_indices` [S1, unofficial].
                *   Retrieve corner positions `p1` and `p2` and field values `f1` and `f2` [G].
                *   Compute interpolation factor `alpha = |f1| / (|f1| + |f2|)` [S1, unofficial].
                *   Compute interpolated position `v_interpolated = (1 - alpha) * p1 + alpha * p2` [S1, unofficial].
                *   Store `v_interpolated` in an array `edge_vertices[i]` [G].
    *   **Triangle Generation and Deformation:**
        *   Fetch the triangle list from `triTableTex` using `cube_index` [S1, unofficial].
        *   Iterate through the list in steps of 3 [S1, unofficial].
        *   For each valid triangle vertex index `idx`:
            *   Retrieve the undeformed position `p_undeformed` from `edge_vertices[idx]` [G].
            *   Apply Gaussian deformation to `p_undeformed` (see Formula below) to get `p_deformed` [S1, unofficial].
            *   Transform `p_deformed` to clip space using `MVP * p_deformed` [S2, unofficial].
            *   Emit the vertex with the transformed position, normal, and UV [S2, unofficial].
        *   After emitting 3 vertices, call `outStream.RestartStrip()` [S2, unofficial].

**Formulas:**

*   **Scalar Field Evaluation:**
    $$f(\mathbf{p}) = \|\mathbf{p} - \mathbf{c}\| - (r + s\sqrt{3})$$
    Where:
    *   $\mathbf{p}$ is the point being evaluated [S1, unofficial].
    *   $\mathbf{c} = (0, 0, -20)$ is the center of the sphere [S1, unofficial].
    *   $r = 4.0$ is the radius [S1, unofficial].
    *   $s$ is the grid size (`gridSize`) [S1, unofficial].

*   **Linear Interpolation on an Edge:**
    $$\mathbf{v} = (1 - \alpha)\mathbf{p}_1 + \alpha\mathbf{p}_2$$
    Where:
    *   $\alpha = \frac{|f(\mathbf{p}_1)|}{|f(\mathbf{p}_1)| + |f(\mathbf{p}_2)|}$ [S1, unofficial].

*   **Gaussian Deformation:**
    $$\mathbf{p}' = \mathbf{p} + \mathbf{F} \cdot 5 \cdot \mathcal{N}(\sigma, d_{\perp}^2)$$
    Where:
    *   $\mathbf{p}$ is the undeformed vertex position [S1, unofficial].
    *   $\mathbf{F}$ is the force vector (`i_force`) [S1, unofficial].
    *   $\sigma$ is the Gaussian width (typically 0.8) [S1, unofficial].
    *   $\mathcal{N}(\sigma, x) = \frac{e^{-x / (2\sigma^2)}}{\sigma\sqrt{2\pi}}$ is the Gaussian distribution function [S1, unofficial].
    *   $d_{\perp}^2 = \|\mathbf{p} - \mathbf{c}\|^2 - \frac{((\mathbf{p} - \mathbf{c}) \cdot \mathbf{F})^2}{\|\mathbf{F}\|^2}$ is the squared perpendicular distance from the point to the force vector axis [S1, unofficial].
    *   If the dot product of the displacement vector and force is non-positive, the deformation is skipped to prevent backward pushing [S1, unofficial].

**Pseudocode:**

```python
# Constants from evidence
CUBE_DIFF_INDICES = [0,1, 1,2, 2,3, 3,0, 4,5, 5,6, 6,7, 7,4, 0,4, 1,5, 2,6, 3,7]
EDGE_TABLE = [0] * 256  # Populated at runtime from edgeTableTex
TRI_TABLE = [0] * (256 * 24)  # Populated at runtime from triTableTex

def vertex_shader(vertex):
    return {'pos': vertex.pos, 'normal': vertex.normal, 'tex0': vertex.tex0}

def geometry_shader(input_vertex, grid_size, i_force, sigma, center, radius, mvp_matrix):
    p_center = input_vertex.pos
    s = grid_size
    F = i_force
    
    cube_index = 0
    corners = []
    f_vals = []
    
    offsets = [vec3(-1,-1,-1), vec3(1,-1,-1), vec3(1,1,-1), vec3(-1,1,-1),
               vec3(-1,-1,1), vec3(1,-1,1), vec3(1,1,1), vec3(-1,1,1)]
    
    for k in range(8):
        c_k = p_center + offsets[k] * s
        f_c = length(c_k - center) - (radius + s * sqrt(3))
        corners.append(c_k)
        f_vals.append(f_c)
        if f_c < 0.0:
            cube_index |= (1 << k)
            
    edge_mask = EDGE_TABLE[cube_index]
    if edge_mask == 0:
        return []
        
    edge_verts = [None] * 12
    for i in range(12):
        if (edge_mask >> i) & 1:
            v1 = CUBE_DIFF_INDICES[i * 2]
            v2 = CUBE_DIFF_INDICES[i * 2 + 1]
            p1, p2 = corners[v1], corners[v2]
            f1, f2 = f_vals[v1], f_vals[v2]
            denom = abs(f1) + abs(f2)
            alpha = abs(f1) / denom if denom > 0.0 else 0.0
            edge_verts[i] = (1 - alpha) * p1 + alpha * p2
            
    tri_base = cube_index * 24
    out_stream = []
    i = 0
    while i < 24:
        idx0 = TRI_TABLE[tri_base + i]
        if idx0 == -1:
            break
        idx1 = TRI_TABLE[tri_base + i + 1]
        idx2 = TRI_TABLE[tri_base + i + 2]
        i += 3
        
        p0 = edge_verts[idx0]
        p1 = edge_verts[idx1]
        p2 = edge_verts[idx2]
        
        p0_d = apply_deform(p0, F, sigma, center)
        p1_d = apply_deform(p1, F, sigma, center)
        p2_d = apply_deform(p2, F, sigma, center)
        
        clip0 = mvp_matrix @ p0_d
        clip1 = mvp_matrix @ p1_d
        clip2 = mvp_matrix @ p2_d
        
        out_stream.append({'pos': clip0, 'normal': input_vertex.normal, 'tex0': input_vertex.tex0})
        out_stream.append({'pos': clip1, 'normal': input_vertex.normal, 'tex0': input_vertex.tex0})
        out_stream.append({'pos': clip2, 'normal': input_vertex.normal, 'tex0': input_vertex.tex0})
        out_stream.append('RESTART_STRIP')
        
    return out_stream

def apply_deform(p, F, sigma, center):
    if length(F) == 0:
        return p
    diff = p - center
    dot_pf = dot(diff, F)
    F_sq = dot(F, F)
    d_perp_sq = dot(diff, diff) - (dot_pf * dot_pf) / F_sq
    gauss = exp(-d_perp_sq / (2 * sigma * sigma)) / (sigma * sqrt(2 * 3.14159265359))
    p_deformed = p + F * 5.0 * gauss
    if dot(p_deformed - p, F) <= 0:
        return p
    return p_deformed
```

**Edge Cases and Pitfalls:**
*   If the force vector is zero, division by `length(F)` in the deformation formula causes a NaN. The code does not explicitly guard against this, so an external check is required [S1, unofficial].
*   If both scalar field values at an edge's endpoints are exactly 0.0, the interpolation denominator becomes 0.0, causing a division by zero. The code does not handle this degenerate case [S1, unofficial].
*   The source code uses `mul(UNITY_MATRIX_MVP, unity_WorldToObject)` for clip-space transformation, which multiplies MVP by WorldToObject. Standard transformation is `VP * World * Vertex`, so this code likely produces incorrect clip-space positions [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** O(1) per voxel processed by the geometry shader, as it performs a fixed number of texture fetches and arithmetic operations regardless of grid resolution. Total complexity is O(N) for N voxels [S1, unofficial].
*   **Memory Complexity:** O(1) per voxel for the geometry shader state. The lookup tables (`edgeTableTex`, `triTableTex`) are stored in GPU memory and are constant size (256 entries each) [S1, unofficial].
*   **Measured Performance:** Implemented in a custom OpenGL 3.3+ application. Performance is dependent on the GPU's geometry shader throughput and the resolution of the voxel grid [S1, unofficial].
*   **Strengths:** Real-time deformation capability; GPU-accelerated; simple implementation using standard Marching Cubes tables.
*   **Limitations:** The matrix multiplication order in the source code is noted as unusual and likely incorrect for standard MVP transformation [S2, unofficial]. Degenerate cases (zero force, zero field values) are not explicitly guarded against in the source code, potentially causing NaNs or division by zero [S1, unofficial].
*   **When to Use:** Real-time deformable terrain or mesh interaction where the deformation is localized and Gaussian-based.
*   **When Not to Use:** When high precision is required for the transformation matrices, or when the force vector can be zero (requires external guarding).

## Background
This method was implemented in the NtslMaterial geometry shader for real-time deformable terrain/mesh interaction in a custom OpenGL 3.3+ application [S1, unofficial]. It is a variant of the Marching Cubes algorithm that integrates Gaussian deformation directly into the geometry shader pipeline [S1, unofficial]. The source code is part of the `ntsl-graphics` repository [S1, unofficial]. A related Unity-based implementation exists in `UnityGPUMarchingCubes`, which uses a similar geometry shader approach but with different matrix transformation logic [S2, unofficial].
