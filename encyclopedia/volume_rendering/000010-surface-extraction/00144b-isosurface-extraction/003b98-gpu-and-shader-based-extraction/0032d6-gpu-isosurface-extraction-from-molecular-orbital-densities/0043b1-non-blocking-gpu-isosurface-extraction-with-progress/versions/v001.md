# Non-blocking GPU Isosurface Extraction with Progress

Also called: gto-iso-gpu-opt

## Overview
This method extracts isosurface meshes from molecular orbital and density fields on the GPU using a non-blocking job API, allowing the render thread to continue execution while computation proceeds [S1, unofficial]. It distinguishes itself from blocking extraction pipelines by capping per-frame processing time and job age, ensuring that long computations do not stall the application [S1, unofficial]. It builds on [GPU Isosurface Extraction from Molecular Orbital Densities](6862-gpu-isosurface-extraction-from-molecular-orbital-densities.md) by adding asynchronous job management and selective flooding for specific field types.

## How it works
**Inputs and Outputs:**
*   **Input:** A molecular field (electron density, orbital, etc.) and a mesh key. The field may be marked with `md_gto_iso_field_set_maxima_at_atoms` [S1, unofficial].
*   **Output:** An updated isosurface mesh.

**Data Structures:**
*   **Job State:** Tracks job age, completion status, and cancellation flags.
*   **Field Markers:** A boolean flag indicating if the field is an electron density marked for flooding [S1, unofficial].

**Parameters:**
*   `max_wait_per_frame`: 3 ms. The maximum duration the job allows itself to block or process during a single poll [S1, unofficial].
*   `max_job_age`: 12 ms. Jobs older than this are not processed further in the current frame cycle [S1, unofficial].
*   `profiler_warmup_runs`: 5. The number of extraction runs performed before a timed profile to stabilize GPU clocks [S1, unofficial].

**Steps:**
1.  **Job Initialization:** When a mesh's key changes, a new extraction job is created [S1, unofficial].
2.  **Polling:** Each frame, the job is polled. If the job is superseded by a new job for the same mesh, it is cancelled [S1, unofficial].
3.  **Time Check:** The job checks its age. If the job age exceeds `max_job_age` (12 ms), processing stops for this frame [S1, unofficial].
4.  **Processing:** The job processes the extraction for up to `max_wait_per_frame` (3 ms) [S1, unofficial].
    *   If the field is marked `md_gto_iso_field_set_maxima_at_atoms`, the extraction uses a flooding technique starting from atom positions, evaluating the field only around the surface [S1, unofficial].
    *   For other fields (attachment, detachment, transition densities, orbitals), the method extracts the field exactly via full volume evaluation [S1, unofficial].
5.  **Completion:** If the job completes within the time limit, the mesh is updated. If not, the job remains active for the next frame poll [S1, unofficial].
6.  **Profiling (Optional):** For benchmarking, the extraction runs 5 times before the timed profile run to account for GPU clock variations, and the report provides the median with min and max values [S1, unofficial].

**Pseudocode:**
```python
class IsoMeshJob:
    def __init__(self, mesh_key, field, is_electron_density):
        self.mesh_key = mesh_key
        self.field = field
        self.is_electron_density = is_electron_density
        self.age_ms = 0.0
        self.completed = False
        self.cancelled = False
        self.max_wait_per_frame_ms = 3.0
        self.max_job_age_ms = 12.0

    def update(self, dt_ms, current_job_for_mesh):
        """
        Called each frame.
        dt_ms: time elapsed since last frame.
        current_job_for_mesh: the active job for this mesh key (if any).
        """
        if self.cancelled or self.completed:
            return

        # Check for supersession
        if current_job_for_mesh is not None and current_job_for_mesh is not self:
            self.cancelled = True
            return

        self.age_ms += dt_ms

        # Check job age limit
        if self.age_ms > self.max_job_age_ms:
            return

        # Process for up to max_wait_per_frame
        start_time = get_time_ms()
        remaining_time = self.max_wait_per_frame_ms

        # Perform partial extraction step
        # Note: The exact internal step logic (e.g., octree traversal, ray marching)
        # is defined in the parent method [GPU Isosurface Extraction from Molecular Orbital Densities].
        # This method only controls the timing and flooding selection.
        if self.is_electron_density:
            # Flooding: start from atom positions, evaluate field only around surface
            extract_flooding(self.field, remaining_time)
        else:
            # Exact extraction: full volume evaluation
            extract_exact(self.field, remaining_time)

        elapsed = get_time_ms() - start_time
        if elapsed >= remaining_time:
            # Time limit reached, job continues next frame
            pass
        else:
            # Job completed within time limit
            self.completed = True
```

**Edge Cases and Pitfalls:**
*   **GPU Clock Variations:** On GPUs that lower their clocks between bursts (e.g., RTX 3080), single timing measurements can vary 3-4x. To handle this, profiling should run the extraction 5 times before the timed profile run, reporting the median with min and max values [S1, unofficial].
*   **Superseded Jobs:** If a new job is started for the same mesh before the previous one completes, the old job must be cancelled to avoid redundant work [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The extraction time is bounded by `max_job_age` (12 ms) per frame, ensuring predictable frame times [S1, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** The method is designed for real-time visualization in molecular dynamics, as used in the viamd project [S1, unofficial].
*   **Strengths:** Non-blocking nature prevents render thread stalls; flooding optimization reduces computation for electron densities [S1, unofficial].
*   **Limitations:** Profiling results can be noisy due to GPU clock variations; requires careful job management to handle supersession [S1, unofficial].
*   **When to Use:** Real-time visualization of molecular dynamics where responsiveness is critical [S1, unofficial].
*   **When Not to Use:** When exact, full-volume extraction is required for all field types without approximation [S1, unofficial].

## Background
This method is part of the viamd project (Visual Interactive Analysis of Molecular Dynamics) [S1, unofficial]. It was developed as an optimized GPU isosurface extraction technique, specifically addressing the need for non-blocking computation in interactive applications [S1, unofficial]. The flooding technique for electron densities was introduced to improve performance by limiting field evaluation to the surface region [S1, unofficial].
