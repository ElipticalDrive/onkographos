# Domain Search Isosurface Extraction


## Overview
Domain Search Isosurface Extraction is a tetrahedral marching method that extracts an isosurface by iterating through a volumetric grid, decomposing each voxel into tetrahedra, and generating vertices via linear interpolation at the isovalue [S1, unofficial]. It sets itself apart from its siblings by using a direct, brute-force enumeration of all tetrahedral cases within a fixed-size buffer, relying on explicit index bit-masking rather than spatial hierarchies or adaptive traversal [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A volumetric grid defined by dimensions $x\_axis, y\_axis, z\_axis$ (typical value: $256 \times 256 \times 256$) [S1, unofficial].
*   **Input:** An `isolevel` (float) defining the target isosurface value [S1, unofficial].
*   **Input:** An array `Vertices` of size $2^{24}$ containing the 3D coordinates of the grid vertices [S1, unofficial].
*   **Input:** A vector `col` of size 4 storing the scalar field values for the four vertices of the current tetrahedron [S1, unofficial].
*   **Output:** An array `newvert` of size $256 \times 256 \times 400$ storing the extracted 3D positions [S1, unofficial].
*   **Output:** An integer `p` tracking the current write index in `newvert` [S1, unofficial].

**Data Structures:**
*   `Vertices`: Array of 3D points, size $2^{24}$ [S1, unofficial].
*   `newvert`: Array of 3D points, pre-allocated with size $256 \times 256 \times 400$ [S1, unofficial].
*   `col`: Vector of 4 scalars, holding values for the current tetrahedron's vertices [S1, unofficial].
*   `index`: 8-bit unsigned integer used to store the case mask [S1, unofficial].

**Algorithm Steps:**
1.  **Iterate** through all voxels in the grid. For each voxel, decompose it into tetrahedra defined by vertices $a, b, c, d$ [S1, unofficial].
2.  **Compute Case Index:** Initialize `index = 0`. For $i \in \{0, 1, 2, 3\}$, if `col[i] < isolevel`, set bit $i$ in `index`: `index |= (1 << i)` [S1, unofficial].
3.  **Check Buffer Bounds:** Before generating vertices, check if `p < (ind - 20)`. If false, skip vertex generation for this cell to prevent buffer overflow [S1, unofficial].
4.  **Handle Case:** Based on `index`, generate interpolated vertices and append them to `newvert` at index `p`, incrementing `p` by the number of vertices generated:
    *   **Case 0x00 (0000) and 0x0F (1111):** All vertices are outside or inside. Do nothing. `break` [S1, unofficial].
    *   **Case 0x01 (0001):** Only vertex $a$ (index 0) is inside. Generate 3 vertices by interpolating edges $(a,b)$, $(a,d)$, $(a,c)$ using scalar pairs `(col[0],col[1])`, `(col[0],col[3])`, `(col[0],col[2])`. Increment `p` by 3 [S1, unofficial].
    *   **Case 0x02 (0010):** Only vertex $b$ (index 1) is inside. Generate 3 vertices from edges $(b,a)$, $(b,c)$, $(b,d)$ using scalar pairs `(col[1],col[0])`, `(col[1],col[2])`, `(col[1],col[3])`. Increment `p` by 3 [S1, unofficial].
    *   **Case 0x04 (0100):** Only vertex $c$ (index 2) is inside. Generate 3 vertices from edges $(c,a)$, $(c,d)$, $(c,b)$ using scalar pairs `(col[2],col[0])`, `(col[2],col[3])`, `(col[2],col[1])`. Increment `p` by 3 [S1, unofficial].
    *   **Case 0x08 (1000):** Only vertex $d$ (index 3) is inside. Generate 3 vertices from edges $(d,b)$, $(d,c)$, $(d,a)$ using scalar pairs `(col[3],col[1])`, `(col[3],col[2])`, `(col[3],col[0])`. Increment `p` by 3 [S1, unofficial].
    *   **Case 0x03 (0011):** Vertices $a, b$ inside. Generate 6 vertices by interpolating edges $(a,d)$, $(a,c)$, $(b,d)$, $(a,c)$, $(c,b)$, $(b,d)$ [S1, unofficial]. Increment `p` by 6 [S1, unofficial].
    *   **Case 0x05 (0101):** Vertices $a, c$ inside. Generate 6 vertices by interpolating edges $(a,b)$, $(a,d)$, $(b,c)$, $(c,b)$, $(a,d)$, $(d,c)$ [S1, unofficial]. Increment `p` by 6 [S1, unofficial].
    *   **Case 0x09 (1001):** Vertices $a, d$ inside. Generate 6 vertices by interpolating edges $(a,b)$, $(b,d)$, $(a,c)$, $(d,b)$, $(c,d)$, $(a,c)$ [S1, unofficial]. Increment `p` by 6 [S1, unofficial].
    *   **Case 0x06 (0110):** Vertices $b, c$ inside. Generate 6 vertices by interpolating edges $(a,b)$, $(b,d)$, $(a,c)$, $(a,c)$, $(b,d)$, $(d,c)$ [S1, unofficial]. Increment `p` by 6 [S1, unofficial].
    *   **Case 0x0C (1100):** Vertices $c, d$ inside. Generate 6 vertices by interpolating edges $(d,b)$, $(a,d)$, $(a,c)$, $(a,c)$, $(b,d)$, $(b,c)$ [S1, unofficial]. Increment `p` by 6 [S1, unofficial].
    *   **Case 0x0A (1010):** Vertices $b, d$ inside. Generate 6 vertices by interpolating edges $(a,b)$, $(a,d)$, $(b,c)$, $(c,b)$, $(a,d)$, $(d,c)$ [S1, unofficial]. Increment `p` by 6 [S1, unofficial].

**Interpolation Formula:**
For an edge between vertices with coordinates $(x_1, y_1, z_1)$ and $(x_2, y_2, z_2)$ and scalar values $a$ and $b$:
*   If $a == b$, the intersection is the midpoint: $z = (x + y) / 2.0$ [S1, unofficial].
*   Otherwise, calculate $t = \frac{|isolevel - a|}{|b - a|}$, then $z = x(1 - t) + yt$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Division by Zero:** If scalar values $a$ and $b$ are equal, the code uses the midpoint formula instead of linear interpolation to avoid division by zero [S1, unofficial].
*   **Buffer Overflow:** The array `newvert` has a fixed size. The code checks `p < (ind - 20)` before writing. If this condition fails, vertices are skipped, potentially resulting in an incomplete mesh [S1, unofficial].
*   **Degenerate Input:** The method uses strict inequality (`col[i] < isolevel`) to determine if a vertex is inside. Vertices exactly on the isosurface are treated as outside, which may cause gaps if the isovalue aligns with grid points [S1, unofficial].

**Pseudocode:**
```python
class Vector3:
    def __init__(self, x, y, z):
        self.x = x
        self.y = y
        self.z = z

def interpolate(p1, p2, val1, val2, isolevel):
    if val1 == val2:
        return Vector3((p1.x + p2.x) / 2.0, (p1.y + p2.y) / 2.0, (p1.z + p2.z) / 2.0)
    interp = abs((isolevel - val1) / (val2 - val1))
    one_minus_interp = 1.0 - interp
    return Vector3(
        p1.x * one_minus_interp + p2.x * interp,
        p1.y * one_minus_interp + p2.y * interp,
        p1.z * one_minus_interp + p2.z * interp
    )

def process_tetrahedron(Vertices, col, isolevel, ind, newvert, p):
    a, b, c, d = 0, 1, 2, 3
    index = 0
    if col[0] < isolevel: index |= 1
    if col[1] < isolevel: index |= 2
    if col[2] < isolevel: index |= 4
    if col[3] < isolevel: index |= 8

    if p < (ind - 20):
        if index == 0x00 or index == 0x0F:
            pass
        elif index == 0x01:
            newvert[p] = interpolate(Vertices[a], Vertices[b], col[0], col[1], isolevel); p += 1
            newvert[p] = interpolate(Vertices[a], Vertices[d], col[0], col[3], isolevel); p += 1
            newvert[p] = interpolate(Vertices[a], Vertices[c], col[0], col[2], isolevel); p += 1
        elif index == 0x02:
            newvert[p] = interpolate(Vertices[b], Vertices[a], col[1], col[0], isolevel); p += 1
            newvert[p] = interpolate(Vertices[b], Vertices[c], col[1], col[2], isolevel); p += 1
            newvert[p] = interpolate(Vertices[b], Vertices[d], col[1], col[3], isolevel); p += 1
        elif index == 0x04:
            newvert[p] = interpolate(Vertices[c], Vertices[a], col[2], col[0], isolevel); p += 1
            newvert[p] = interpolate(Vertices[c], Vertices[d], col[2], col[3], isolevel); p += 1
            newvert[p] = interpolate(Vertices[c], Vertices[b], col[2], col[1], isolevel); p += 1
        elif index == 0x08:
            newvert[p] = interpolate(Vertices[d], Vertices[b], col[3], col[1], isolevel); p += 1
            newvert[p] = interpolate(Vertices[d], Vertices[c], col[3], col[2], isolevel); p += 1
            newvert[p] = interpolate(Vertices[d], Vertices[a], col[3], col[0], isolevel); p += 1
        elif index == 0x03:
            newvert[p] = interpolate(Vertices[a], Vertices[d], col[0], col[3], isolevel); p += 1
            newvert[p] = interpolate(Vertices[a], Vertices[c], col[0], col[2], isolevel); p += 1
            newvert[p] = interpolate(Vertices[b], Vertices[d], col[1], col[3], isolevel); p += 1
            newvert[p] = interpolate(Vertices[a], Vertices[c], col[0], col[2], isolevel); p += 1
            newvert[p] = interpolate(Vertices[c], Vertices[b], col[2], col[1], isolevel); p += 1
            newvert[p] = interpolate(Vertices[b], Vertices[d], col[1], col[3], isolevel); p += 1
        elif index == 0x05:
            newvert[p] = interpolate(Vertices[a], Vertices[b], col[0], col[1], isolevel); p += 1
            newvert[p] = interpolate(Vertices[a], Vertices[d], col[0], col[3], isolevel); p += 1
            newvert[p] = interpolate(Vertices[b], Vertices[c], col[1], col[2], isolevel); p += 1
            newvert[p] = interpolate(Vertices[c], Vertices[b], col[2], col[1], isolevel); p += 1
            newvert[p] = interpolate(Vertices[a], Vertices[d], col[0], col[3], isolevel); p += 1
            newvert[p] = interpolate(Vertices[d], Vertices[c], col[3], col[2], isolevel); p += 1
        elif index == 0x09:
            newvert[p] = interpolate(Vertices[a], Vertices[b], col[0], col[1], isolevel); p += 1
            newvert[p] = interpolate(Vertices[b], Vertices[d], col[1], col[3], isolevel); p += 1
            newvert[p] = interpolate(Vertices[a], Vertices[c], col[0], col[2], isolevel); p += 1
            newvert[p] = interpolate(Vertices[d], Vertices[b], col[3], col[1], isolevel); p += 1
            newvert[p] = interpolate(Vertices[c], Vertices[d], col[2], col[3], isolevel); p += 1
            newvert[p] = interpolate(Vertices[a], Vertices[c], col[0], col[2], isolevel); p += 1
        elif index == 0x06:
            newvert[p] = interpolate(Vertices[a], Vertices[b], col[0], col[1], isolevel); p += 1
            newvert[p] = interpolate(Vertices[b], Vertices[d], col[1], col[3], isolevel); p += 1
            newvert[p] = interpolate(Vertices[a], Vertices[c], col[0], col[2], isolevel); p += 1
            newvert[p] = interpolate(Vertices[a], Vertices[c], col[0], col[2], isolevel); p += 1
            newvert[p] = interpolate(Vertices[b], Vertices[d], col[1], col[3], isolevel); p += 1
            newvert[p] = interpolate(Vertices[d], Vertices[c], col[3], col[2], isolevel); p += 1
        elif index == 0x0C:
            newvert[p] = interpolate(Vertices[d], Vertices[b], col[3], col[1], isolevel); p += 1
            newvert[p] = interpolate(Vertices[a], Vertices[d], col[0], col[3], isolevel); p += 1
            newvert[p] = interpolate(Vertices[a], Vertices[c], col[0], col[2], isolevel); p += 1
            newvert[p] = interpolate(Vertices[a], Vertices[c], col[0], col[2], isolevel); p += 1
            newvert[p] = interpolate(Vertices[b], Vertices[d], col[1], col[3], isolevel); p += 1
            newvert[p] = interpolate(Vertices[b], Vertices[c], col[1], col[2], isolevel); p += 1
        elif index == 0x0A:
            newvert[p] = interpolate(Vertices[a], Vertices[b], col[0], col[1], isolevel); p += 1
            newvert[p] = interpolate(Vertices[a], Vertices[d], col[0], col[3], isolevel); p += 1
            newvert[p] = interpolate(Vertices[b], Vertices[c], col[1], col[2], isolevel); p += 1
            newvert[p] = interpolate(Vertices[c], Vertices[b], col[2], col[1], isolevel); p += 1
            newvert[p] = interpolate(Vertices[a], Vertices[d], col[0], col[3], isolevel); p += 1
            newvert[p] = interpolate(Vertices[d], Vertices[c], col[3], col[2], isolevel); p += 1
    return newvert, p
```

## Subtopics

### [Octree-Based Isosurface Extraction](7786-octree-based-isosurface-extraction.md)
Octree-Based Isosurface Extraction accelerates isosurface generation by spatially partitioning the volume into an octree and pruning branches where the isovalue lies outside the data range. It differs from Domain Search by using implicit spatial hierarchy rather than value-based indexing, which reduces memory overhead but makes active cell identification slower than kd-tree approaches when data is not spatially clustered.

### [LOD-Aware Hierarchical Isosurface Search](10909-lod-aware-hierarchical-isosurface-search.md)
LOD-Aware Hierarchical Isosurface Search (DYNAISOLOD) is a method for extracting isosurfaces from structured grid data by searching a multi-resolution voxel tree (LODTree) for cells containing the isovalue at a user-specified level-of-detail (LOD). It solves the problem of interactive exploration of large simulation datasets where the isosurface threshold is unknown or dynamic, allowing scientists to select the detail of the resulting surface to maintain interactive frame rates. Unlike Octree-Based Isosurface Extraction which operates in geometry space assuming stable underlying geometry, DYNAISOLOD operates in voxel space, representing LOD as differently sized virtual voxels (e.g., 1x1x1, 2x2x2). This approach is necessary because dynamic isosurface thresholds imply no stable underlying geometry.

### Distance Field Computation with BVH
Distance Field Computation with BVH computes distance fields for isosurfaces using bounding volume hierarchies (BVH-trees) accelerated by a pre-computed upper bound from heuristic sampling [S2]. It uses a downsampling factor of 8 in each dimension for distance fields [S2]. Lower resolution distance fields (downscale 8) introduce an average difference of 1.5% in similarity map entries compared to higher resolution (downscale 4), which is deemed acceptable for performance [S2]. Downscaling by 8 reduces computation time significantly; increasing accuracy to a downscale of 4 increases total time 3.5-fold and similarity map calculation 7.8× longer [S2]. Using downscale 8 instead of 4 yields a 7.8× speedup for similarity map calculation at the cost of a 1.5% average difference in map entries [S2].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of tetrahedra, as each cell is processed independently [S1, unofficial].
*   **Memory Complexity:** $O(V)$ where $V$ is the size of the output vertex buffer, dominated by the pre-allocated array of size $256 \times 256 \times 400$ [S1, unofficial].
*   **Performance:** The method is simple to implement and parallelize due to the independence of tetrahedra [S1, unofficial].
*   **Strengths:** Simple logic, no complex data structures required, easy to debug [S1, unofficial].
*   **Limitations:** Fixed buffer size can lead to overflow or wasted space [S1, unofficial]. No connectivity information is generated (only vertices) [S1, unofficial].
