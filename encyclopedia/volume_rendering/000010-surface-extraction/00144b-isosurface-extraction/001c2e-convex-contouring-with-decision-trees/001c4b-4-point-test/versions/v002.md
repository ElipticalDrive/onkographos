# 4-point test
## Overview
The 4-point test is a geometric filtering method used in convex contouring to identify which triangles from a set of candidate triangulations belong to the convex contour of volumetric data [S1]. It solves the ambiguity of surface configuration by enforcing the convex hull property, ensuring that all edge intersections and negative corners lie on one side of any triangle in the contour [S1].
## How it works
**Inputs:** Four distinct edge intersection points $V_1, V_2, V_3, V_4$ in 3D space [S1].
**Outputs:** A set of ruled-out triangles from the candidate set $S$ [S1].

**Data Structures:** Points $V_i$ are 3D coordinates $(x_i, y_i, z_i)$ [S1]. No additional bit packing or layout is specified in the sources [G]. The "front-facing side" of a triangle $(A, B, C)$ is determined by the sign of the scalar triple product (or the dot product of the normal with the vector to the test point) [G].

**Steps:**
1. Calculate the normal vector $N$ of triangle $(V_1, V_2, V_3)$ and the signed distance $D$ of $V_4$ onto $N$ [S1].
2. Check the sign of $D$ to determine if $V_4$ lies on the front-facing side of $(V_1, V_2, V_3)$ [S1].
3. Rule out triangles based on the result: if $V_4$ is front-facing, rule out $(V_1, V_3, V_2)$, $(V_1, V_2, V_4)$, $(V_2, V_3, V_4)$, and $(V_3, V_1, V_4)$ [S1]. If $V_4$ is not front-facing, rule out $(V_1, V_2, V_3)$, $(V_1, V_4, V_2)$, $(V_2, V_4, V_3)$, and $(V_1, V_3, V_4)$ [S1].
4. If all four vertices lie on the same plane, either choice of ruling out triangles can be made [S1].

**Formulas:**
Let $N$ be the normal vector of triangle $(V_1, V_2, V_3)$:
$$ N = (V_2 - V_1) \times (V_3 - V_1) $$
Let $D$ be the signed distance (or projection) of $V_4$ onto this normal:
$$ D = N \cdot (V_4 - V_1) $$
All symbols are defined in the steps above [S1].

**Parameters:** None. The test is purely geometric [S1].

**Edge cases and pitfalls:** If $V_1, V_2, V_3, V_4$ are coplanar, the normal is zero or the distance is zero, and either choice of ruling out triangles can be made [S1]. Floating-point errors in the dot product calculation may cause misclassification of points that are theoretically coplanar or on the boundary; a small epsilon tolerance may be required in practice, though not specified in the source [G]. The definition of "front-facing" must be consistent with the winding order of the triangle vertices $(V_1, V_2, V_3)$ [G].

**Pseudocode:**
```python
def cross_product(a, b):
    return [
        a[1]*b[2] - a[2]*b[1],
        a[2]*b[0] - a[0]*b[2],
        a[0]*b[1] - a[1]*b[0]
    ]

def dot_product(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def subtract(a, b):
    return [a[0]-b[0], a[1]-b[1], a[2]-b[2]]

def four_point_test(V1, V2, V3, V4):
    edge1 = subtract(V2, V1)
    edge2 = subtract(V3, V1)
    normal = cross_product(edge1, edge2)
    vec_v1_v4 = subtract(V4, V1)
    distance = dot_product(normal, vec_v1_v4)
    
    ruled_out = []
    
    if distance > 0:
        ruled_out.append((V1, V3, V2))
        ruled_out.append((V1, V2, V4))
        ruled_out.append((V2, V3, V4))
        ruled_out.append((V3, V1, V4))
    elif distance < 0:
        ruled_out.append((V1, V2, V3))
        ruled_out.append((V1, V4, V2))
        ruled_out.append((V2, V4, V3))
        ruled_out.append((V1, V3, V4))
    else:
        ruled_out.append((V1, V3, V2))
        ruled_out.append((V1, V2, V4))
        ruled_out.append((V2, V3, V4))
        ruled_out.append((V3, V1, V4))
        
    return ruled_out
```

## Operating characteristics
* **Time Complexity:** $O(1)$ per test, involving a constant number of vector operations (cross product, dot product) [G].
* **Memory Complexity:** $O(1)$ [G].
* **Performance:** The test is designed for speed to allow the construction of decision trees that distinguish triangulations with a minimal set of tests [S1].
* **Strengths:** It efficiently reduces the search space of possible triangulations by enforcing the convex hull property locally [S1].
* **Limitations:** It only rules out specific triangles; the correct triangulation is found by applying a sequence of such tests (via a decision tree) until a unique solution remains [S1].
* **When to use:** When implementing convex contouring for isosurface extraction where the convex hull property must be enforced on edge intersections [S1].
## Background
The 4-point test was introduced in the context of convex contouring of volumetric data [S1]. It differentiates the correct triangulation from others by looking at edge intersections and ensuring they satisfy the convex hull property [S1]. Each test rules out triangles from the set $S$ of all possible triangulations that contain any of the four back-facing triangles [S1]. Since any two triangulations differ in at least one triangle shared by a boundary edge, the correct triangulation can be distinguished from every other triangulation in $S$ through appropriate 4-point tests [S1]. For best performance, a decision tree can be built to distinguish each triangulation through a minimal set of tests [S1].
