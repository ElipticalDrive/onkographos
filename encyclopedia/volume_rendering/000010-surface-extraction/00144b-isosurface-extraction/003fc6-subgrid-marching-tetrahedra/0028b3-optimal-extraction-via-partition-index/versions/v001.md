# Optimal Extraction via Partition Index

Also called: OptimalExtraction, Saddle-based Partitioning

## Overview
Optimal Extraction via Partition Index is a method for extracting isosurfaces from a tetrahedral grid that guarantees visiting only the tetrahedra actually intersected by the level set, thereby achieving optimal runtime complexity for the extraction phase [S1, unofficial]. It distinguishes itself from standard marching tetrahedra by pre-processing the mesh into partitions separated by saddle contours, allowing the algorithm to jump directly to connected components of the isosurface via a partition index [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A tetrahedral mesh with a scalar field defined on vertices; an isovalue ($v_{iso}$).
*   **Output:** A set of triangles forming the isosurface, guaranteed to be connected components without self-intersections.

**Data Structures**
1.  **Partition:** A collection of vertices belonging to a region where the isosurface is a single connected component.
    *   **Layout:** `std::set<std::pair<VertexID, ScalarValue>>` [S1, unofficial].
    *   **Ordering:** Ordered by `ScalarValue` (ascending) [S1, unofficial].
2.  **PartitionIndex:** An interval table mapping scalar value ranges to the partitions intersecting those ranges.
    *   **Layout:** Similar to `TetIndex` but maps intervals to `Partition` objects instead of tetrahedra [S1, unofficial].

**Definitions**
*   **Regular Vertex:** A vertex where the set of neighbors with function values lower than the vertex forms a single connected component AND the set of neighbors with function values higher than the vertex forms a single connected component [S1, unofficial].
*   **Saddle Vertex:** Any vertex that is not regular. This includes minima, maxima, and vertices where the lower/higher neighbor groups are disconnected [S1, unofficial].
*   **Saddle Contour:** The boundary separating regions of regular vertices, passing through saddle vertices [S1, unofficial].

**Algorithm Steps**

1.  **Identify Saddles:** Iterate over all vertices in the mesh. For each vertex, check the connectivity of its neighbors with values strictly lower and strictly higher than the vertex's value. If either group is not a single connected component, mark the vertex as a saddle [S1, unofficial].
2.  **Partition the Mesh:**
    *   Initialize an empty list of partitions and a `visited` set for vertices.
    *   Iterate through all regular vertices. If a vertex is not visited:
        *   Create a new `Partition`.
        *   Perform a flood fill (BFS/DFS) starting from this vertex.
        *   Add a neighbor to the current partition if and only if the edge connecting the current vertex and the neighbor does **not** cross a saddle contour. An edge crosses a saddle contour if one endpoint is a saddle and the other is not, or if the edge connects two saddles in a way that separates regions (specifically, the partition grows only through edges between regular vertices that do not cross the "saddle barrier") [S1, unofficial]. *Note: The source specifies growing from regular vertices and adding neighbors if the edge crosses no saddle contour.*
        *   Mark all added vertices as visited and add them to the partition.
    *   Repeat until all regular vertices are assigned to a partition. Saddle vertices themselves are typically not included in the partition sets or handled as boundaries [S1, unofficial].
3.  **Build PartitionIndex:**
    *   For each partition, determine the minimum and maximum scalar values among its vertices.
    *   Insert an entry into the `PartitionIndex` interval table mapping the interval $[min\_val, max\_val]$ to the partition [S1, unofficial].
4.  **Query Intersected Partitions:**
    *   Given $v_{iso}$, query the `PartitionIndex` to retrieve all partitions whose scalar range contains $v_{iso}$ [S1, unofficial].
5.  **Find Seed Vertices and Tetrahedra:**
    *   For each intersected partition:
        *   Use `std::set::lower_bound()` on the partition's vertex set to find the vertex with the smallest function value $\ge v_{iso}$. This is the **seed vertex** [S1, unofficial].
        *   Identify all tetrahedra containing the seed vertex.
        *   Check each tetrahedron using `IsCellOnLevelSet()` (i.e., does the tetrahedron's min/max scalar range bracket $v_{iso}$?) [S1, unofficial].
        *   Select one such tetrahedron as the **seed tetrahedron** [S1, unofficial].
6.  **Extract Contour:**
    *   Call `ExtractContour(seed_tetrahedron)` for each seed tetrahedron found [S1, unofficial].
    *   `ExtractContour` implementation:
        *   Initialize a queue $Q$ with the seed tetrahedron ID.
        *   Maintain a `visited_tetrahedra` set.
        *   While $Q$ is not empty:
            *   Pop tetrahedron $T$ from $Q$.
            *   If $T$ is in `visited_tetrahedra`, continue.
            *   Mark $T$ as visited.
            *   Compute the intersection of $T$ with the isosurface (e.g., using `ComputePartialIntersection()`) [S1, unofficial].
            *   For each neighbor $T'$ of $T$:
                *   If $T'$ is not in `visited_tetrahedra` AND $T'$'s scalar range intersects $v_{iso}$ (checked via `IsCellOnLevelSet()` or similar span check):
                    *   Push $T'$ to $Q$ [S1, unofficial].

**Pseudocode**

```python
def OptimalExtraction(mesh, scalar_field, isovalue):
    # Step 1: Identify Saddles
    saddles = set()
    for vertex in mesh.vertices:
        lower_neighbors = [n for n in vertex.neighbors if scalar_field[n] < scalar_field[vertex]]
        higher_neighbors = [n for n in vertex.neighbors if scalar_field[n] > scalar_field[vertex]]
        
        # Check connectivity of lower neighbors
        lower_connected = is_connected(lower_neighbors, mesh.edges)
        # Check connectivity of higher neighbors
        higher_connected = is_connected(higher_neighbors, mesh.edges)
        
        if not (lower_connected and higher_connected):
            saddles.add(vertex)
            
    # Step 2: Partition Mesh
    partitions = []
    visited_vertices = set()
    
    for vertex in mesh.vertices:
        if vertex in saddles:
            continue
        if vertex in visited_vertices:
            continue
            
        current_partition = set()
        queue = [vertex]
        visited_vertices.add(vertex)
        
        while queue:
            curr = queue.pop(0)
            current_partition.add(curr)
            
            for neighbor in curr.neighbors:
                if neighbor in visited_vertices:
                    continue
                if neighbor in saddles:
                    continue
                
                # Check if edge crosses saddle contour
                # An edge (u, v) crosses a saddle contour if one is saddle and other is not,
                # or if it separates regions. Based on source: "add neighbor if edge crosses no saddle contour"
                # Implementation detail: The source implies growing through regular vertices.
                # We assume the partition grows only between regular vertices not separated by saddles.
                # A simple heuristic for "crosses saddle contour" in this context:
                # If the edge connects two regular vertices, it is part of the partition.
                # If it connects to a saddle, it is a boundary.
                # The source says "add neighbor... if edge crosses no saddle contour".
                # Since we only iterate regular vertices and skip saddles in the loop,
                # we only consider edges between regular vertices.
                
                # Re-reading source: "grow a region starting from a regular vertex and add each of its neighbors
                # to the partition if the corresponding edge crosses no saddle contour."
                # This implies we might check neighbors that are saddles? No, saddles are boundaries.
                # Let's assume we only add regular neighbors.
                
                # To be precise: The partition is a set of regular vertices.
                # The boundary is defined by saddles.
                
                if is_edge_crossing_saddle_contour(curr, neighbor, saddles):
                    continue
                    
                visited_vertices.add(neighbor)
                queue.append(neighbor)
                
        partitions.append(current_partition)
        
    # Step 3: Build PartitionIndex
    partition_index = IntervalTable()
    for partition in partitions:
        min_val = min(scalar_field[v] for v in partition)
        max_val = max(scalar_field[v] for v in partition)
        partition_index.insert(min_val, max_val, partition)
        
    # Step 4 & 5: Query and Find Seeds
    intersected_partitions = partition_index.query(isovalue)
    seed_tetrahedra = []
    
    for partition in intersected_partitions:
        # Find seed vertex using lower_bound
        # partition is a set of (vertex_id, value) or just vertices ordered by value
        # Assuming partition is a list/set of vertices sorted by value
        seed_vertex = None
        for v in partition:
            if scalar_field[v] >= isovalue:
                seed_vertex = v
                break
        if seed_vertex is None:
            seed_vertex = partition[0] # Fallback, though logic suggests >= exists
            
        # Find seed tetrahedron
        tetrahedra_containing_seed = mesh.get_tetrahedra_containing_vertex(seed_vertex)
        for tet in tetrahedra_containing_seed:
            if is_cell_on_level_set(tet, scalar_field, isovalue):
                seed_tetrahedra.append(tet)
                break # Pick one arbitrarily
                
    # Step 6: Extract Contours
    all_triangles = []
    visited_tets = set()
    
    for seed_tet in seed_tetrahedra:
        triangles = extract_contour(seed_tet, scalar_field, isovalue, visited_tets)
        all_triangles.extend(triangles)
        
    return all_triangles

def extract_contour(seed_tet, scalar_field, isovalue, visited_tets):
    queue = [seed_tet]
    triangles = []
    
    while queue:
        tet = queue.pop(0)
        if tet in visited_tets:
            continue
        visited_tets.add(tet)
        
        # Compute intersection
        tri = compute_partial_intersection(tet, scalar_field, isovalue)
        if tri:
            triangles.append(tri)
            
        for neighbor in tet.neighbors:
            if neighbor not in visited_tets:
                if is_cell_on_level_set(neighbor, scalar_field, isovalue):
                    queue.append(neighbor)
                    
    return triangles

def is_connected(vertices, edges):
    if not vertices:
        return True
    start = next(iter(vertices))
    visited = set()
    queue = [start]
    visited.add(start)
    while queue:
        curr = queue.pop(0)
        for neighbor in curr.neighbors:
            if neighbor in vertices and neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    return len(visited) == len(vertices)

def is_edge_crossing_saddle_contour(u, v, saddles):
    # If either endpoint is a saddle, the edge is on the boundary
    if u in saddles or v in saddles:
        return True
    return False
```

**Parameters and Edge Cases**
*   **Isovalue:** Must be within the range of the scalar field.
*   **Degenerate Input:** If the scalar field has no regular vertices (all saddles), the partitioning step yields no partitions. The algorithm may fail to extract anything unless saddle vertices are handled separately (not specified in source) [S1, unofficial].
*   **Precision:** Floating point comparisons for `scalar_field[v] >= isovalue` should use a small epsilon if necessary, though the source uses exact comparisons [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The extraction phase is optimal, visiting only intersected tetrahedra. The pre-processing (partitioning) is $O(V+E)$ where $V$ is vertices and $E$ is edges, due to flood fill [S1, unofficial].
*   **Memory Complexity:** Requires storing partitions and the partition index. The partition index is an interval table, typically $O(P)$ where $P$ is the number of partitions [S1, unofficial].
*   **Strengths:** Avoids visiting non-intersected tetrahedra, which is a significant speedup for sparse isosurfaces or high-resolution grids where most cells do not intersect the level set [S1, unofficial].
*   **Limitations:** Requires pre-processing the mesh to identify saddles and build partitions. This adds overhead for single-frame extraction or dynamic scalar fields that change frequently [S1, unofficial].

## Background
This method originates from visualization exercises and educational materials on isosurface extraction, specifically associated with Julien Tierny [S1, unofficial]. It is presented as a "simplest to implement" optimal algorithm compared to more complex adaptive methods, leveraging the topological properties of saddle points to decompose the mesh [S1, unofficial].
