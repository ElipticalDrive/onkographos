# Adaptive Octree Marching Tetrahedra


## Overview
An isosurface extraction method that uses an adaptive octree to subdivide a 3D volume only where the scalar field contains the target isovalue, applying the Marching Tetrahedra algorithm at leaf nodes to generate the mesh [S1, unofficial]. It differs from its parent [Marching Tetrahedrons](3720-marching-tetrahedrons.md) by introducing spatial adaptivity via octree subdivision, reducing computation in empty regions, and from [Naive Isosurface Extraction](4328-naive-isosurface-extraction.md) by avoiding uniform grid traversal [S1, unofficial].

## How it works
**Inputs:**
- A 3D scalar field stored in a 1D array `teapotColour` of size $X \times Y \times Z$ (source assumes fixed $256^3$) [S1, unofficial].
- Target isovalue `iso` [S1, unofficial].
- Volume bounds defined by `topLeftFront` and `bottomRightBack` points [S1, unofficial].

**Outputs:**
- A list of vertices (`newvert`) representing the isosurface mesh [S1, unofficial].

**Data Structures:**
- `Point`: Struct with fields `int x`, `int y`, `int z`. Default constructor initializes to $(-1, -1, -1)$ [S1, unofficial].
- `OctreeNode`:
  - `Point topLeftFront`: Minimum corner of the node's bounding box [S1, unofficial].
  - `Point bottomRightBack`: Maximum corner of the node's bounding box [S1, unofficial].
  - `Point point`: If `NULL`, the node is internal; if $(-1, -1, -1)$, the node is empty [S1, unofficial].
  - `children`: Array of 8 child pointers [S1, unofficial].

**Algorithm Steps:**

1. **Build Octree (`make` function):**
   - Calculate midpoints: `midx = (topLeftFront.x + bottomRightBack.x) / 2`, `midy = (topLeftFront.y + bottomRightBack.y) / 2`, `midz = (topLeftFront.z + bottomRightBack.z) / 2` [S1, unofficial].
   - Iterate through all voxels in the node's bounds to find `min_iso` and `max_iso` from `teapotColour` using index `z * 256 * 256 + y * 256 + x` [S1, unofficial].
   - If node dimensions are greater than 1 (checked by `(bottomRightBack.x - midx) > 1 || (bottomRightBack.y - midy) > 1 || (midz - topLeftFront.z) > 1`), create 8 child octants [S1, unofficial].
   - Child indices (0-7) are defined by their bounding boxes relative to midpoints:
     - Child 0: `(x1,y1,z1)` to `(midx,midy,midz)` [S1, unofficial].
     - Child 1: `(midx,y1,z1)` to `(x2,midy,midz)` [S1, unofficial].
     - Child 2: `(x1,midy,z1)` to `(midx,y2,midz)` [S1, unofficial].
     - Child 3: `(midx,midy,z1)` to `(x2,y2,midz)` [S1, unofficial].
     - Child 4: `(x1,y1,midz)` to `(midx,midy,z2)` [S1, unofficial].
     - Child 5: `(midx,y1,midz)` to `(x2,midy,z2)` [S1, unofficial].
     - Child 6: `(x1,midy,midz)` to `(midx,y2,z2)` [S1, unofficial].
     - Child 7: `(midx,midy,midz)` to `(x2,y2,z2)` [S1, unofficial].
   - Recursively call `make()` on children if their dimensions > 1 [S1, unofficial].

2. **Leaf Processing (`explore` function):**
   - When a leaf node is reached (dimensions equal 1, i.e., `(-topLeftFront.x + bottomRightBack.x) == 1 && ...`), identify the 8 vertices of the cube [S1, unofficial].
   - Indices into `teapotColour` (assuming $256^3$ grid):
     - `a` (BottomLeftFront): `topLeftFront.z*256*256 + topLeftFront.y*256 + topLeftFront.x` [S1, unofficial].
     - `b` (BottomRightFront): `a + 1` [S1, unofficial].
     - `c` (TopLeftFront): `a + 257` [S1, unofficial].
     - `d` (BottomLeftBack): `a + 256` [S1, unofficial].
     - `e` (TopLeftBack): `256*256 + a` [S1, unofficial].
     - `f` (TopRightFront): `e + 1` [S1, unofficial].
     - `g` (TopRightBack): `e + 257` [S1, unofficial].
     - `h` (TopLeftBack): `e + 256` [S1, unofficial].
   - Decompose the cube into 5 tetrahedra. For each tetrahedron, pass the scalar values of its 4 vertices to the `tetra` function [S1, unofficial].
     - Tet 1: Vertices `h, g, c, f` [S1, unofficial].
     - Tet 2: Vertices `h, c, d, b` [S1, unofficial].
     - Tet 3: Vertices `d, a, e, b` [S1, unofficial].
     - Tet 4: Vertices `h, d, e, b` [S1, unofficial].
     - Tet 5: Vertices `h, c, f, b` [S1, unofficial].

3. **Marching Tetrahedra Logic (`tetra` function):**
   - Determine the case index based on which vertices are inside the isosurface (`val > isolevel`) [S1, unofficial].
   - For each case, compute intersection points on the edges using linear interpolation:
     $$ \text{interpolate}(v1, v2, \text{isolevel}, col1, col2) = v1 + \frac{\text{isolevel} - col1}{col2 - col1} (v2 - v1) $$
   - Store resulting `Vector3f` in `newvert` array [S1, unofficial].
   - Example Case `0x0C` (vertices `d, b, a, c` inside):
     - Intersect edge `d-b`: `interpolate(Vertices[d], Vertices[b], isolevel, col[3], col[1])` [S1, unofficial].
     - Intersect edge `a-d`: `interpolate(Vertices[a], Vertices[d], isolevel, col[0], col[3])` [S1, unofficial].
     - Intersect edge `a-c`: `interpolate(Vertices[a], Vertices[c], isolevel, col[0], col[2])` [S1, unofficial].

**Pseudocode:**

```python
class Point:
    def __init__(self, x=-1, y=-1, z=-1):
        self.x = x
        self.y = y
        self.z = z

class OctreeNode:
    def __init__(self, topLeftFront, bottomRightBack):
        self.topLeftFront = topLeftFront
        self.bottomRightBack = bottomRightBack
        self.point = Point(-1, -1, -1)
        self.children = [None] * 8

def interpolate(v1, v2, isolevel, col1, col2):
    if col2 == col1:
        return v1
    t = (isolevel - col1) / (col2 - col1)
    return Point(v1.x + t * (v2.x - v1.x),
                 v1.y + t * (v2.y - v1.y),
                 v1.z + t * (v2.z - v1.z))

def get_index(x, y, z, width=256):
    return z * width * width + y * width + x

def make_octree(node, teapot_color):
    mid_x = (node.topLeftFront.x + node.bottomRightBack.x) // 2
    mid_y = (node.topLeftFront.y + node.bottomRightBack.y) // 2
    mid_z = (node.topLeftFront.z + node.bottomRightBack.z) // 2
    
    # Check if subdivision is needed
    if (node.bottomRightBack.x - mid_x > 1 or 
        node.bottomRightBack.y - mid_y > 1 or 
        mid_z - node.topLeftFront.z > 1):
        
        bounds = [
            (node.topLeftFront, Point(mid_x, mid_y, mid_z)),
            (Point(mid_x, node.topLeftFront.y, node.topLeftFront.z), Point(node.bottomRightBack.x, mid_y, mid_z)),
            (Point(node.topLeftFront.x, mid_y, node.topLeftFront.z), Point(mid_x, node.bottomRightBack.y, mid_z)),
            (Point(mid_x, mid_y, node.topLeftFront.z), Point(node.bottomRightBack.x, node.bottomRightBack.y, mid_z)),
            (Point(node.topLeftFront.x, node.topLeftFront.y, mid_z), Point(mid_x, mid_y, node.bottomRightBack.z)),
            (Point(mid_x, node.topLeftFront.y, mid_z), Point(node.bottomRightBack.x, mid_y, node.bottomRightBack.z)),
            (Point(node.topLeftFront.x, mid_y, mid_z), Point(mid_x, node.bottomRightBack.y, node.bottomRightBack.z)),
            (Point(mid_x, mid_y, mid_z), node.bottomRightBack)
        ]
        
        for i, (tl, br) in enumerate(bounds):
            node.children[i] = OctreeNode(tl, br)
            make_octree(node.children[i], teapot_color)
    else:
        explore_leaf(node, teapot_color)

def explore_leaf(node, teapot_color):
    a_idx = get_index(node.topLeftFront.x, node.topLeftFront.y, node.topLeftFront.z)
    b_idx = a_idx + 1
    c_idx = a_idx + 257
    d_idx = a_idx + 256
    e_idx = 256*256 + a_idx
    f_idx = e_idx + 1
    g_idx = e_idx + 257
    h_idx = e_idx + 256
    
    col = [
        teapot_color[h_idx], teapot_color[g_idx], teapot_color[c_idx], teapot_color[f_idx],
        teapot_color[d_idx], teapot_color[b_idx], teapot_color[a_idx], teapot_color[e_idx]
    ]
    
    verts = [
        Point(node.topLeftFront.x, node.topLeftFront.y, node.topLeftFront.z), # a
        Point(node.topLeftFront.x+1, node.topLeftFront.y, node.topLeftFront.z), # b
        Point(node.topLeftFront.x, node.topLeftFront.y+1, node.topLeftFront.z), # c
        Point(node.topLeftFront.x, node.topLeftFront.y, node.topLeftFront.z+1), # d
        Point(node.topLeftFront.x, node.topLeftFront.y+1, node.topLeftFront.z+1), # e
        Point(node.topLeftFront.x+1, node.topLeftFront.y+1, node.topLeftFront.z), # f
        Point(node.topLeftFront.x+1, node.topLeftFront.y+1, node.topLeftFront.z+1), # g
        Point(node.topLeftFront.x, node.topLeftFront.y, node.topLeftFront.z+1) # h
    ]
    
    tetra(col, verts, [h_idx, g_idx, c_idx, f_idx])
    tetra(col, verts, [h_idx, c_idx, d_idx, b_idx])
    tetra(col, verts, [d_idx, a_idx, e_idx, b_idx])
    tetra(col, verts, [h_idx, d_idx, e_idx, b_idx])
    tetra(col, verts, [h_idx, c_idx, f_idx, b_idx])

def tetra(col, verts, indices, output_vertices):
    case = 0
    for i in range(4):
        if col[indices[i]] > isolevel:
            case |= (1 << i)
            
    if case == 0x0C:
        output_vertices.append(interpolate(verts[indices[3]], verts[indices[1]], isolevel, col[indices[3]], col[indices[1]]))
        output_vertices.append(interpolate(verts[indices[0]], verts[indices[3]], isolevel, col[indices[0]], col[indices[3]]))
        output_vertices.append(interpolate(verts[indices[0]], verts[indices[2]], isolevel, col[indices[0]], col[indices[2]]))
```

**Parameters:**
- `iso`: Target isovalue [S1, unofficial].
- Grid dimensions: `x_axis`, `y_axis`, `z_axis` (source uses fixed 256) [S1, unofficial].

**Edge Cases and Pitfalls:**
- Grid indexing assumes a fixed width of 256 for index calculation (`z * 256 * 256 + y * 256 + x`), which fails for volumes with different Y-axis dimensions [S1, unofficial].
- Vertex labeling ambiguity: Variable names `a` through `h` in `explore` do not directly correspond to the `Vertices[a]`...`Vertices[h]` used in the `tetra` switch cases in the provided snippet [S1, unofficial].
