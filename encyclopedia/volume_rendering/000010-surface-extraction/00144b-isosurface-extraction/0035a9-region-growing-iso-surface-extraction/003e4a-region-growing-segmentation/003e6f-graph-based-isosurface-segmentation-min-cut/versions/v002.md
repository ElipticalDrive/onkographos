# Graph-based Isosurface Segmentation (Min-Cut)

Also called: Graph Segmentation on Isosurface, Isosurface Segmentation, Isosurface Segmentation via Min-Cut, Surface structure extraction

## Overview
This method segments a 3D volume by treating voxels containing a specific isosurface as nodes in a graph, connected via neighborhood connectivity, and finding an optimal cut to separate user-defined foreground and background seed regions [S1, unofficial]. Unlike traditional volume segmentation which operates on the entire voxel grid and suffers from label volume precision limits and computational expense, this approach restricts the graph to the sparse subset of voxels intersecting the isosurface, integrating directly with isosurface rendering pipelines [S1, unofficial].

## How it works
**Inputs:**
*   A 3D volume dataset with scalar values [S1, unofficial].
*   An isovalue defining the specific isosurface to segment [S1, unofficial].
*   User-selected seed voxels for the foreground and background, selected via an interactive interface on the rendering view [S1, unofficial].

**Outputs:**
*   A segmentation of the isosurface voxels into connected components (surface structures) [S1, unofficial].
*   A label assignment for each segmented isosurface voxel, stored in an 8-bit label volume where values 1–255 represent distinct surface structures and 0 represents empty space [S1, unofficial].

**Data Structures:**
1.  **Graph Nodes:** A list of voxel IDs $(x, y, z)$ that contain the isosurface [S1, unofficial].
2.  **Graph Edges:** Undirected edges connecting nodes in a 6-neighborhood (for 3D) or 4-neighborhood (for 2D illustrations) [S1, unofficial].
3.  **Edge Weights:** A scalar value $w_{pq}$ for each edge connecting voxel $p$ and voxel $q$, defined as the length of the intersection between the isosurface and the voxel boundary shared by $p$ and $q$ [S1, unofficial].
4.  **Seed Storage:** Two sorted 'set' data structures (optimized for searching) storing the voxel IDs of the foreground seeds ($S_{fg}$) and background seeds ($S_{bg}$) [S1, unofficial].

**Algorithm Steps:**

1.  **Voxel Selection and Seed Initialization:** Identify voxels containing the isosurface and collect user-selected seed voxel IDs into two sets, $S_{fg}$ and $S_{bg}$, stored as sorted sets for efficient lookup [S1, unofficial].
2.  **Graph Construction:** Construct a graph $G = (V, E)$ where $V$ is the set of isosurface voxels and add an edge between any two voxels $p, q \in V$ if they are 6-neighbors (adjacent along x, y, or z axes) [S1, unofficial].
3.  **Edge Weight Calculation:** For each edge $(p, q) \in E$, calculate the weight $w_{pq}$ as the length of the intersection segment between the isosurface and the boundary between voxel $p$ and voxel $q$ [S1, unofficial]. If the isosurface intersects the boundary in a single continuous segment, calculate the length using numerical integration [S1, unofficial]. If trilinear interpolation results in two distinct intersection segments (a rare case), divide the total length of both segments by 2 to approximate the weight [S1, unofficial].
4.  **Min-Cut Optimization:** Solve the min-cut problem to partition $V$ into two sets $V_{fg}$ and $V_{bg}$ such that the sum of weights of edges crossing the cut is minimized, subject to $S_{fg} \subseteq V_{fg}$ and $S_{bg} \subseteq V_{bg}$ [S1, unofficial]. Use the Boykov-Kolmogorov optimization algorithm [S1, unofficial].
5.  **Label Assignment:** Assign the label corresponding to the foreground component to all voxels in $V_{fg}$ and the background component to $V_{bg}$ in the output label volume [S1, unofficial].

**Pseudocode:**

```python
def graph_based_isosurface_segmentation(volume, isovalue, seed_fg_ids, seed_bg_ids):
    """
    Segments isosurface voxels using min-cut optimization.
    
    Args:
        volume: 3D list of lists of lists of scalar values.
        isovalue: The scalar value defining the isosurface.
        seed_fg_ids: List of (x,y,z) tuples for foreground seeds.
        seed_bg_ids: List of (x,y,z) tuples for background seeds.
        
    Returns:
        label_volume: 3D list of lists of lists with 0 for empty, 1 for foreground, 2 for background.
    """
    # Step 1: Identify isosurface voxels
    # A voxel contains the isosurface if the isovalue lies between the min and max 
    # of its 8 corners under trilinear interpolation [S1, unofficial].
    isosurface_voxels = []
    for x in range(len(volume)):
        for y in range(len(volume[0])):
            for z in range(len(volume[0][0])):
                if voxel_contains_isosurface(volume, x, y, z, isovalue):
                    isosurface_voxels.append((x, y, z))
    
    # Map voxel ID to node index for graph construction
    voxel_to_node = {voxel: i for i, voxel in enumerate(isosurface_voxels)}
    num_nodes = len(isosurface_voxels)
    
    # Step 2: Construct Graph and Calculate Weights
    # Nodes 0..N-1 are voxels, Node N is Source (fg), Node N+1 is Sink (bg)
    num_terminal_nodes = 2
    total_nodes = num_nodes + num_terminal_nodes
    
    # Initialize graph weights
    # t-links (terminals)
    t_links_fg = [0] * total_nodes
    t_links_bg = [0] * total_nodes
    
    # n-links (neighbors)
    n_links = []
    
    for i, p in enumerate(isosurface_voxels):
        # Assign seeds to terminals
        if p in seed_fg_ids:
            t_links_fg[i] = float('inf')
        elif p in seed_bg_ids:
            t_links_bg[i] = float('inf')
            
        # Check 6-neighbors to build edges
        neighbors = get_6_neighbors(p)
        for q in neighbors:
            if q in voxel_to_node:
                j = voxel_to_node[q]
                if i < j:
                    # Calculate weight: intersection length of isosurface with voxel boundary [S1, unofficial]
                    weight = calculate_intersection_length(volume, p, q, isovalue)
                    n_links.append((i, j, weight))
    
    # Step 3: Solve Min-Cut
    # The min-cut algorithm minimizes: sum(w_ij for i in S, j in T) + sum(t_links)
    # We use a standard max-flow/min-cut solver (e.g., Boykov-Kolmogorov) [S1, unofficial].
    labels = solve_min_cut(total_nodes, t_links_fg, t_links_bg, n_links)
    
    # Step 4: Map results to label volume
    label_volume = [[[0 for _ in range(len(volume[0][0]))] for _ in range(len(volume[0]))] for _ in range(len(volume))]
    
    for i, p in enumerate(isosurface_voxels):
        # labels[i] == 0 means Source (Foreground), 1 means Sink (Background)
        if labels[i] == 0:
            label_volume[p[0]][p[1]][p[2]] = 1
        elif labels[i] == 1:
            label_volume[p[0]][p[1]][p[2]] = 2
            
    return label_volume

def voxel_contains_isosurface(volume, x, y, z, isovalue):
    """Check if isovalue is within the range of trilinear interpolation bounds of the voxel [S1, unofficial]."""
    min_val = float('inf')
    max_val = float('-inf')
    for dx in [0, 1]:
        for dy in [0, 1]:
            for dz in [0, 1]:
                val = volume[x+dx][y+dy][z+dz]
                if val < min_val: min_val = val
                if val > max_val: max_val = val
    return min_val <= isovalue <= max_val

def get_6_neighbors(voxel):
    """Return the 6 adjacent voxel coordinates in 3D space."""
    x, y, z = voxel
    return [
        (x+1, y, z), (x-1, y, z),
        (x, y+1, z), (x, y-1, z),
        (x, y, z+1), (x, y, z-1)
    ]

def solve_min_cut(num_nodes, t_links_fg, t_links_bg, n_links):
    """
    Solves the min-cut problem using a breadth-first search from both seed sets 
    to construct the graph and determine the cut [S1, unofficial].
    """
    # Initialize labels: -1 unvisited, 0 foreground, 1 background
    labels = [-1] * num_nodes
    
    # BFS queues for foreground and background seeds
    queue_fg = []
    queue_bg = []
    
    for i in range(num_nodes):
        if t_links_fg[i] == float('inf'):
            labels[i] = 0
            queue_fg.append(i)
        elif t_links_bg[i] == float('inf'):
            labels[i] = 1
            queue_bg.append(i)
            
    # Standard BFS propagation to assign labels based on connectivity and cut weights
    # In practice, this is replaced by the Boykov-Kolmogorov max-flow algorithm [S1, unofficial].
    while queue_fg or queue_bg:
        if queue_fg:
            u = queue_fg.pop(0)
            for v, w in get_neighbor_edges(u, n_links):
                if labels[v] == -1:
                    labels[v] = 0
                    queue_fg.append(v)
        if queue_bg:
            u = queue_bg.pop(0)
            for v, w in get_neighbor_edges(u, n_links):
                if labels[v] == -1:
                    labels[v] = 1
                    queue_bg.append(v)
                    
    return labels

def get_neighbor_edges(node_idx, n_links):
    """Return list of (neighbor_idx, weight) for a given node index."""
    edges = []
    for u, v, w in n_links:
        if u == node_idx:
            edges.append((v, w))
        elif v == node_idx:
            edges.append((u, w))
    return edges
```

**Parameters:**
*   **Isosurface Value:** The scalar threshold defining the surface [S1, unofficial].
*   **Label Volume Precision:** 8-bit integer, allowing up to 255 distinct surface structures [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Trilinear Ambiguity:** Trilinear interpolation can create up to two intersection segments per voxel boundary [S1, unofficial]. The method handles this by dividing the total length of all segments by 2 [S1, unofficial].
*   **Open Surfaces:** Extracted surface structures are not guaranteed to be closed and cannot substitute for full volume segmentation [S1, unofficial].
*   **Staircase Artifacts:** By operating on the isosurface domain rather than a label volume, this method avoids the stair-case artifacts common in traditional volume segmentation [S1, unofficial].

## Subtopics

### Edge Weight Definition for Isosurface Consistency
This variant modifies the edge weight definition to ensure boundaries are consistent with isosurfaces across different materials, particularly in multi-material CT data [S2]. Instead of geometric intersection length, weights are assigned based on CT value thresholds relative to isovalue thresholds $v = iso(m_i, m_j)$ [S2].
*   **Definition:** $w(p, q) = w_{cut}$ if $I_p \le v \le I_q$ or $I_p \ge v \ge I_q$ for some isovalue threshold $v$; otherwise $w(p, q) = w_{join}$ [S2]. Here $I_p, I_q$ are CT values. $w_{cut}$ and $w_{join}$ are positive constants [S2].
*   **Cost Function:** The total energy is $E = w_{join} (\tau \cdot N_{cut} + N_{join})$, where $N_{cut}$ is the number of edges with weight $w_{cut}$, $N_{join}$ is the number of edges with weight $w_{join}$, and $\tau = w_{cut} / w_{join}$ is the cut-ratio parameter ($0 < \tau < 1$) [S2].
*   **Rationale:** Using standard weights $|I_p - I_q|$ fails to ensure boundaries are consistent with isosurfaces [S2]. This rule prevents misclassification by pulling voxels toward the cut direction if linked by enough $w_{cut}$ edges, even if $w_{cut} < w_{join}$ [S2].

## Operating characteristics
*   **Time Complexity:** The complexity is dominated by the min-cut algorithm (Boykov-Kolmogorov) [S1, unofficial]. The number of nodes is proportional to the number of voxels containing the isosurface, not the total volume size [S1, unofficial].
*   **Memory Complexity:** Proportional to the number of isosurface voxels and their 6-neighborhood connections [S1, unofficial]. Significantly lower than full volume segmentation [S1, unofficial].
*   **Performance:** On a 256x256x124 brain MRI dataset (8,126,464 total voxels), the method involved 832,869 graph nodes and took 8.25 seconds [S1, unofficial]. With cropping to a region of interest, nodes reduced to 40,830 and time reduced to 0.36 seconds [S1, unofficial].
*   **Strengths:** Avoids label volume storage and associated stair-case artifacts; computationally efficient for sparse isosurfaces; integrates well with interactive rendering [S1, unofficial].
*   **Limitations:** Extracted structures are not guaranteed to be closed; limited to 255 structures due to 8-bit label volume; requires user seed selection [S1, unofficial].

## Background
This method was proposed to address the limitations of traditional volume segmentation, such as computational expense and precision issues in label volumes [S1, unofficial]. It leverages the efficiency of graph-cut algorithms, specifically the Boykov-Kolmogorov optimization method [S1, unofficial]. The approach is designed to work in conjunction with color-enhanced isosurface rendering, allowing for multi-surface-structure visualization within a single scene [S1, unofficial].
