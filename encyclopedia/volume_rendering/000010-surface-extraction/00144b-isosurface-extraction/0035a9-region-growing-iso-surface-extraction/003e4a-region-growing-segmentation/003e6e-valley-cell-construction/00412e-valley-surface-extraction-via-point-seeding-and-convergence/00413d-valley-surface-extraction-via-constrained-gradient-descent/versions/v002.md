# Valley Surface Extraction via Constrained Gradient Descent

Also called: Gradient descent in non-manifold regions, Slope-line extraction

## Overview
A mesh-free surface extraction method that extracts valley surfaces (maximal convexity ridges) in complex scalar fields by handling non-manifold regions where standard surface growing fails [S1, unofficial]. It identifies branching locations (partial umbilics) and connects them using constrained gradient-based integration, specifically addressing areas of ambiguous convexity where the gradient has a distinct and consistent direction [S1, unofficial]. Unlike flow-based surface integration, which is numerically unstable due to substantially varying gradient directions close to separation structures, this approach uses constrained gradient descent only in these ambiguous regions [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar field $f$, an existing partial valley surface (point cloud with connectivity), and a convergence tolerance $\epsilon$ [S1, unofficial].
*   **Output:** An extended point cloud representing the connected valley surface graph, including connector structures in non-manifold regions [S1, unofficial].

**Data Structures:**
*   **Surface Point:** Contains position $\mathbf{p}$, normal $\mathbf{n}$, and curvature information (eigenvalues $\lambda_1, \lambda_2, \lambda_3$ and eigenvectors $\mathbf{e}_1, \mathbf{e}_2, \mathbf{e}_3$ of the Hessian) [S1, unofficial].
*   **Connectivity:** Neighborhood relations between points to guide surface growth and triangulation [S1, unofficial].

**Definitions:**
*   $\lambda_1, \lambda_2, \lambda_3$: Eigenvalues of the Hessian matrix, ordered such that $\lambda_1 \le \lambda_2 \le \lambda_3$ [S1, unofficial]. $\lambda_3$ corresponds to the direction of maximal convexity (valley direction), $\lambda_2$ to medium curvature, and $\lambda_1$ to minimal curvature [S1, unofficial].
*   $\mathbf{e}_1, \mathbf{e}_2, \mathbf{e}_3$: Corresponding eigenvectors [S1, unofficial].
*   $\nabla f$: Gradient of the scalar field [S1, unofficial].
*   $\nabla f_p$: Gradient projected onto the plane of convergence spanned by $\mathbf{e}_2$ and $\mathbf{e}_3$ [S1, unofficial].
*   $\delta$: Threshold for identifying partial umbilics [S1, unofficial].

**Steps:**

1.  **Identify Partial Umbilics:** Scan the boundary of the existing surface to find locations where $\frac{\lambda_2}{\lambda_3} > 1 - \delta$ and a change in main curvature direction was detected during previous convergence steps [S1, unofficial]. These locations mark branching points [S1, unofficial].
2.  **Handle Degenerate Line Boundaries (Case 1):** If new child points fail to converge due to a degenerate line boundary, the inverse gradient direction points towards the branching region, describing a flow separation line [S1, unofficial].
    *   Constrain the gradient descent to a plane orthogonal to the direction of minimal curvature ($\mathbf{e}_1$) [S1, unofficial].
    *   On this projection plane, the vector field degenerates to a source point where the crease line intersects [S1, unofficial].
    *   Step along the negative gradient direction as long as $\lambda_2 > 0$ until meeting the maximal convexity ridge at a crease line point [S1, unofficial].
    *   Merge the created start and end positions of these connector lines into the existing valley structure and update point neighborhood relations [S1, unofficial].
3.  **Handle Junction-like Regions (Case 2):** If the surface continues growing tangentially to the minimal and medium curvature directions and crosses the junction-like region, it indicates a nearby valley surface [S1, unofficial].
    *   Seed a set of points in the neighborhood to ensure all nearby structures are recovered by the extraction algorithm [S1, unofficial].
    *   These seeded points require an additional convergence step to meet the valley surface [S1, unofficial].
4.  **Extract Connector Structures near Degenerate Lines:** If $\lambda_2 \gg 0$ close to a degenerate line, extract the connector structure by replacing $\lambda_3$ in the standard valley line equation with $\lambda_2$ [S1, unofficial]. This merges corresponding crease lines with degenerate lines [S1, unofficial].
5.  **Convergence:** Use constrained Newton iteration or quadratic approximation to find the field minimum on the plane spanned by $\mathbf{e}_2$ and $\mathbf{e}_3$ [S1, unofficial]. The projected gradient $\nabla f_p$ is used for this optimization [S1, unofficial].

**Pseudocode:**

```python
def extract_valley_surface(surface_points, scalar_field, epsilon, delta):
    """
    Extracts valley surfaces using constrained gradient descent in non-manifold regions.
    
    Args:
        surface_points: List of Point objects with pos, normal, eigenvalues (l1, l2, l3), 
                        eigenvectors (e1, e2, e3), is_boundary flag, and prev_e1 direction.
        scalar_field: Function f(p) returning scalar value at position p.
        epsilon: Convergence tolerance.
        delta: Threshold for partial umbilic detection.
        
    Returns:
        Updated list of surface_points.
    """
    new_points = []
    
    for point in surface_points:
        # Step 1: Identify partial umbilics on boundary
        if point.is_boundary and has_curvature_direction_change(point):
            if point.l3 != 0 and point.l2 / point.l3 > 1 - delta:
                branching_location = point.pos
                
                # Case 1: Handle degenerate line boundary
                if fails_to_converge(point, scalar_field):
                    plane_normal = point.e1
                    current_pos = point.pos
                    active_point = point
                    
                    # Step along negative gradient as long as lambda2 > 0
                    while active_point.l2 > 0:
                        grad = compute_gradient(current_pos, scalar_field)
                        # Project gradient to plane spanned by e2, e3
                        grad_proj = grad - dot(grad, plane_normal) * plane_normal
                        
                        # Constrained Newton iteration to find minimum on plane
                        next_pos = constrained_newton_step(current_pos, grad_proj, active_point, scalar_field, epsilon)
                        
                        new_point = compute_point_properties(next_pos, scalar_field)
                        new_points.append(new_point)
                        
                        if is_crease_line_point(new_point):
                            break
                            
                        current_pos = next_pos
                        active_point = new_point
                    
                    # Merge start and end positions into structure
                    merge_connector_lines(point.pos, current_pos, surface_points)
                    
                # Case 2: Handle junction-like region
                elif crosses_junction(point, scalar_field):
                    neighborhood_points = seed_points_in_neighborhood(point.pos, scalar_field)
                    new_points.extend(neighborhood_points)
                    
                    for np in neighborhood_points:
                        converge_to_valley(np, scalar_field, epsilon)
                        
                # Connector structure extraction near degenerate lines
                if is_close_to_degenerate_line(point) and point.l2 > 1.0:
                    connector = extract_connector_with_lambda2(point.pos, scalar_field, point.l2)
                    new_points.append(connector)
                    
    return surface_points + new_points

def has_curvature_direction_change(point):
    """Checks if the main curvature direction changed compared to the previous step."""
    if point.prev_e1 is None:
        return False
    return abs(dot(normalize(point.e1), normalize(point.prev_e1))) < 0.9

def fails_to_converge(point, scalar_field):
    """Returns True if the point's neighborhood shows stagnation or divergence."""
    # Implementation checks if gradient norm remains high over consecutive steps
    return norm(compute_gradient(point.pos, scalar_field)) > 1e-3

def crosses_junction(point, scalar_field):
    """Returns True if surface growth aligns tangentially to e1 and e2."""
    grad = compute_gradient(point.pos, scalar_field)
    return abs(dot(normalize(grad), point.e1)) < 0.1 and abs(dot(normalize(grad), point.e2)) < 0.1

def is_close_to_degenerate_line(point):
    """Returns True if point is near a known degenerate line or curvature ratio is near 1."""
    return point.l2 / point.l3 > 0.95

def is_crease_line_point(point):
    """Checks if point lies on a crease line (gradient parallel to minimal eigenvector)."""
    grad = compute_gradient(point.pos, scalar_field)
    return abs(dot(normalize(grad), normalize(point.e1))) > 0.99

def seed_points_in_neighborhood(center_pos, scalar_field):
    """Generates a set of points on a small adaptive ellipsoid around center_pos."""
    points = []
    for angle in range(0, 360, 30):
        rad = angle * 3.14159 / 180
        offset = Vector3(cos(rad) * 0.01, sin(rad) * 0.01, 0)
        points.append(compute_point_properties(center_pos + offset, scalar_field))
    return points

def converge_to_valley(point, scalar_field, epsilon):
    """Runs constrained Newton iteration until the projected gradient norm is below epsilon."""
    current_pos = point.pos
    active_point = point
    for _ in range(100):
        grad = compute_gradient(current_pos, scalar_field)
        grad_proj = grad - dot(grad, active_point.e1) * active_point.e1
        if norm(grad_proj) < epsilon:
            break
        next_pos = constrained_newton_step(current_pos, grad_proj, active_point, scalar_field, epsilon)
        active_point = compute_point_properties(next_pos, scalar_field)
        current_pos = next_pos
    point.pos = current_pos
    point.l1, point.l2, point.l3 = active_point.l1, active_point.l2, active_point.l3
    point.e1, point.e2, point.e3 = active_point.e1, active_point.e2, active_point.e3

def extract_connector_with_lambda2(pos, scalar_field, l2_val):
    """Creates a connector point by stepping along the medium curvature direction."""
    # Replaces lambda3 with lambda2 in the valley line equation [S1, unofficial]
    grad = compute_gradient(pos, scalar_field)
    step_dir = normalize(grad)
    return compute_point_properties(pos + step_dir * 0.01, scalar_field)

def compute_point_properties(pos, scalar_field):
    """Computes gradient, Hessian, eigenvalues, and eigenvectors at a position."""
    grad = compute_gradient(pos, scalar_field)
    H = compute_hessian(pos, scalar_field)
    l1, e1 = eigendecompose(H, 0)
    l2, e2 = eigendecompose(H, 1)
    l3, e3 = eigendecompose(H, 2)
    return Point(pos, grad, l1, l2, l3, e1, e2, e3)

def compute_gradient(pos, scalar_field):
    """Computes gradient using central finite differences."""
    h = 1e-5
    dx = (scalar_field(pos + Vector3(h, 0, 0)) - scalar_field(pos - Vector3(h, 0, 0))) / (2 * h)
    dy = (scalar_field(pos + Vector3(0, h, 0)) - scalar_field(pos - Vector3(0, h, 0))) / (2 * h)
    dz = (scalar_field(pos + Vector3(0, 0, h)) - scalar_field(pos - Vector3(0, 0, h))) / (2 * h)
    return Vector3(dx, dy, dz)

def compute_hessian(pos, scalar_field):
    """Computes Hessian matrix using central finite differences."""
    h = 1e-5
    f0 = scalar_field(pos)
    fxx = (scalar_field(pos + Vector3(h, 0, 0)) - 2*f0 + scalar_field(pos - Vector3(h, 0, 0))) / (h*h)
    fyy = (scalar_field(pos + Vector3(0, h, 0)) - 2*f0 + scalar_field(pos - Vector3(0, h, 0))) / (h*h)
    fzz = (scalar_field(pos + Vector3(0, 0, h)) - 2*f0 + scalar_field(pos - Vector3(0, 0, h))) / (h*h)
    fxy = (scalar_field(pos + Vector3(h, h, 0)) - scalar_field(pos + Vector3(h, -h, 0)) - scalar_field(pos - Vector3(h, h, 0)) + scalar_field(pos - Vector3(h, -h, 0))) / (4*h*h)
    fxz = (scalar_field(pos + Vector3(h, 0, h)) - scalar_field(pos + Vector3(h, 0, -h)) - scalar_field(pos - Vector3(h, 0, h)) + scalar_field(pos - Vector3(h, 0, -h))) / (4*h*h)
    fyz = (scalar_field(pos + Vector3(0, h, h)) - scalar_field(pos + Vector3(0, h, -h)) - scalar_field(pos - Vector3(0, h, h)) + scalar_field(pos - Vector3(0, h, -h))) / (4*h*h)
    return Matrix3(fxx, fxy, fxz, fxy, fyy, fyz, fxz, fyz, fzz)

def constrained_newton_step(current_pos, grad_proj, point, scalar_field, epsilon):
    """Performs one Newton step constrained to the plane orthogonal to e1."""
    H = compute_hessian(current_pos, scalar_field)
    # Project Hessian to 2D basis (e2, e3)
    H_proj = Matrix2(dot(H * point.e2, point.e2), dot(H * point.e2, point.e3),
                     dot(H * point.e3, point.e2), dot(H * point.e3, point.e3))
    # Solve H_proj * step = -grad_proj
    step = solve_linear_system(H_proj, -grad_proj)
    return current_pos + step[0] * point.e2 + step[1] * point.e3

def solve_linear_system(A, b):
    """Solves Ax = b for a 2x2 system using Cramer's rule or direct inversion."""
    det = A[0][0] * A[1][1] - A[0][1] * A[1][0]
    x0 = (A[1][1] * b[0] - A[0][1] * b[1]) / det
    x1 = (A[0][0] * b[1] - A[1][0] * b[0]) / det
    return Vector2(x0, x1)

def dot(v1, v2):
    return v1.x * v2.x + v1.y * v2.y + v1.z * v2.z

def norm(v):
    return dot(v, v) ** 0.5

def normalize(v):
    n = norm(v)
    return Vector3(v.x / n, v.y / n, v.z / n) if n > 0 else Vector3(0, 0, 0)

def Vector3(x, y, z):
    return type('Vector3', (), {'x': x, 'y': y, 'z': z})

def Vector2(x, y):
    return type('Vector2', (), {'x': x, 'y': y})

    return type('Matrix2', (), {'m': [[m00, m01], [m10, m11]]})

class Point:
    def __init__(self, pos, grad=None, l1=0, l2=0, l3=0, e1=None, e2=None, e3=None, is_boundary=False, prev_e1=None):
        self.pos = pos
        self.grad = grad
        self.l1 = l1
        self.l2 = l2
        self.l3 = l3
        self.e1 = e1 if e1 else Vector3(1, 0, 0)
        self.e2 = e2 if e2 else Vector3(0, 1, 0)
        self.e3 = e3 if e3 else Vector3(0, 0, 1)
        self.is_boundary = is_boundary
```

**Parameters:**
*   $\epsilon$: Convergence tolerance. Typical value: $10^{-8}$ [S1, unofficial].
*   $\delta$: Threshold for partial umbilic detection. Value not given in the sources.

**Edge Cases and Pitfalls:**
*   **Flat Medium Curvature:** The extraction technique is numerically not reliable in regions where the field is flat in the direction of medium curvature ($\lambda_2 \approx 0$), as this causes deviations in the approximated medium curvature direction [S1, unofficial].
*   **Noisy Data:** Surface quality is reduced in noisy data sets due to less accurate curvature and ridge normal computations [S1, unofficial].
*   **Resolution Artifacts:** Decreasing resolution causes curved areas to show edge artifacts due to lack of curvature adaptivity and increased edge lengths [S1, unofficial].

## Subtopics

### [Triangulation of Valley Surfaces](10463-triangulation-of-valley-surfaces.md)
A procedure to triangulate the point cloud representing a connected surface graph created by the extraction algorithm, using local Delaunay triangles and specific handling for non-manifold regions bounded by crease and degenerate lines. It uses the neighborhood relations from the extraction phase to create local Delaunay triangles, ensuring that crease lines form edges in the triangulation via edge swapping.

It uses a view-aligned cylindrical selection tool to mark regions for refinement or growing, with visual highlighting performed by OpenGL stencil-buffering [S1, unofficial].
