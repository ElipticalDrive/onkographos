# Valley Cell Construction

Also called: Region growing from maxima, Valley cell decomposition

## Overview
Valley Cell Construction decomposes a feature space (typically a 2D density plot or scalar field) into non-overlapping regions called valley cells, where each cell contains exactly one isolated local maximum. It solves the problem of structuring the feature space for clustering or segmentation by identifying the boundaries between basins of attraction for local maxima. It differs from [Graph-based Isosurface Segmentation (Min-Cut)](9748-graph-based-isosurface-segmentation-min-cut.md) by using topological region growing from maxima rather than global cut optimization, and from [Restricted Region Growing](9750-restricted-region-growing.md) by explicitly handling topological degeneracies (multi-maximum saddles) via node duplication to ensure a valid cell decomposition.

## How it works
**Inputs:** A discretized feature space represented as a 2D triangular mesh with scalar values at vertices. The mesh enforces a piecewise linear approximation of the density function.
**Outputs:** A set of valley cells, each associated with a unique maximum, and a map of saddle correspondences including persistence values.

**Data Structures:**
*   **Mesh:** Triangular mesh $T$. Each triangle has 3 vertices.
*   **Vertices:** Store scalar value $v$.
*   **Saddles:** Identified critical points. Store a set of associated maxima $\mathcal{M}_S$.
*   **Cells:** Set of triangles belonging to a specific maximum.

**Steps:**

1.  **Identify Critical Points:** Identify local maxima, minima, and saddles on the mesh. A saddle is an extreme where two ridge lines and two valley lines meet.
2.  **Region Growing:**
    *   Initialize a cell for each maximum $m$.
    *   For each maximum, recursively add neighboring triangles to its cell.
    *   **Stopping Condition:** Stop growing a cell when the boundary reaches a valley line or a triangle whose vertices are all minima.
    *   During growth, track the correspondence between the growing cell and the saddles encountered on its boundary.
3.  **Saddle Update and Persistence Calculation:**
    *   After growing, each saddle $S$ has a set of connected maxima $\mathcal{M}_S$.
    *   Calculate the **persistence** of saddle $S$ relative to a maximum $m \in \mathcal{M}_S$ as the difference in scalar values:
        $$ p(S, m) = v(m) - v(S) $$
    *   The persistence of the saddle $S$ is defined as the minimum difference between the saddle value and its associated maximum values:
        $$ p(S) = \min_{m \in \mathcal{M}_S} (v(m) - v(S)) $$
4.  **Handle Degeneracies (Saddle Duplication):**
    *   In degenerate cases (e.g., multiple valley lines meeting at a saddle, or paths ending at a junction), a single saddle may belong to more than two cells (associated with $k > 2$ maxima).
    *   To resolve this, duplicate the saddle node $k-1$ times.
    *   Replace the original saddle $S$ with $k$ distinct saddle instances $S_1, S_2, \dots, S_k$.
    *   Each instance $S_i$ is associated with exactly one maximum from $\mathcal{M}_S$.
    *   *Note:* This is similar to unfolding a $k$-fold saddle but only duplicates the node, not the paths [S1].
5.  **Boundary Persistence Calculation:**
    *   Each boundary between two adjacent valley cells is associated with at least one saddle.
    *   Calculate the **boundary persistence** as the minimum persistence of all saddles associated with that boundary:
        $$ p_{boundary} = \min_{S \in \text{Boundary}} p(S) $$

**Pseudocode:**

```python
def construct_valley_cells(mesh):
    # 1. Identify critical points
    maxima = find_local_maxima(mesh)
    saddles = find_saddles(mesh)
    
    # 2. Region Growing
    cells = {} # Map: max_id -> set of triangles
    saddle_max_map = {} # Map: saddle_id -> set of max_ids
    
    for m in maxima:
        cells[m.id] = set()
        grow_cell(mesh, m, cells[m.id], saddle_max_map)
        
    # 3. Update Saddle Correspondences and Persistence
    for s in saddles:
        # Calculate persistence for each associated maximum
        s.persistance_values = {}
        for m_id in s.associated_maxima:
            m_val = mesh.vertices[m_id].value
            s_val = mesh.vertices[s.id].value
            s.persistance_values[m_id] = m_val - s_val
            
        # Global persistence is min over all associated maxima
        s.persistence = min(s.persistance_values.values())
        
    # 4. Resolve Degeneracies via Duplication
    new_saddles = []
    for s in saddles:
        k = len(s.associated_maxima)
        if k > 2:
            # Duplicate saddle k-1 times
            for i in range(1, k):
                new_s = create_duplicate_saddle(s)
                new_s.associated_maxima = {s.associated_maxima[i]}
                new_s.persistence = s.persistance_values[s.associated_maxima[i]]
                new_saddles.append(new_s)
            # Keep original for first max
            s.associated_maxima = {s.associated_maxima[0]}
            new_saddles.append(s)
        else:
            new_saddles.append(s)
            
    # 5. Calculate Boundary Persistence
    boundaries = find_adjacent_cell_boundaries(cells)
    for b in boundaries:
        b.persistence = min(s.persistence for s in b.saddles)
        
    return cells, new_saddles, boundaries

def grow_cell(mesh, start_max, cell_triangles, saddle_max_map):
    stack = [start_max]
    visited_triangles = set()
    
    while stack:
        current = stack.pop()
        # Assuming current is a triangle or vertex; logic depends on mesh traversal
        # Recursively add neighbors
        for neighbor in mesh.get_neighbors(current):
            if neighbor not in visited_triangles:
                # Check stopping condition: valley line or min triangle
                if is_valley_boundary(neighbor) or is_min_triangle(neighbor):
                    # Update saddle correspondence if boundary is a saddle
                    if is_saddle(neighbor):
                        saddle_max_map[neighbor.id].add(start_max.id)
                else:
                    visited_triangles.add(neighbor)
                    cell_triangles.add(neighbor)
                    stack.append(neighbor)
```

## Subtopics

### [Valley Surface Extraction via Point Seeding and Convergence](10401-valley-surface-extraction-via-point-seeding-and-convergence.md)
A mesh-free method that grows a surface by seeding points on an adaptive ellipsoid around existing surface points and converging them to the valley surface (maximal convexity ridge) using polynomial approximation or Newton iteration.

## Operating characteristics
*   **Complexity:** Linear with respect to the number of triangles in the mesh for the region growing phase, assuming efficient neighbor traversal. Saddle duplication is proportional to the number of degenerate saddles.
*   **Strengths:** Provides a clear topological decomposition of the feature space. Explicitly handles noise and discretization artifacts through boundary persistence, allowing for cell simplification.
*   **Limitations:** Degenerate cases (multi-fold saddles, junctions) require special handling (duplication). The method relies on the quality of the underlying mesh and critical point identification.
*   **Use Cases:** Automating transfer function design by clustering 2D density plots; isolating semantic features in volume data.

## Background
The method is inspired by the Morse complex construction scheme described in [EHZ03]. It was formalized for automating transfer function design in the context of 2D density plots for volume exploration [S1]. The approach uses region growing from maxima [HP74] to tessellate the feature space into valley cells, ensuring each cell contains an isolated maximum.
