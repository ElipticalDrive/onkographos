# Tandem Algorithm

Also called: Attali et al. tandem algorithm

## Overview
The Tandem Algorithm is a memory-constrained isosurface extraction method that alternates between extracting a new layer of geometry and simplifying the accumulated surface to maintain a bounded memory footprint [S1, S2]. It solves the problem of storing the entire intermediate triangulation by performing incremental simplification using edge collapses, ensuring that the number of vertices and triangles remains manageable during the extraction process [S1]. Unlike methods that extract the full volume before simplifying, or pure streaming approaches that discard history, the Tandem Algorithm maintains a global view of the surface for simplification while restricting the "active" geometry to a sliding window near the extraction front [S1].

## How it works
The algorithm processes a volumetric dataset by iterating through cross-sections (layers) along a specific extraction direction (e.g., the $z$-axis). It maintains two priority queues: $Q$ for edge collapse candidates and $W$ for blocked edges.

### Inputs and Outputs
- **Input**: Volumetric dataset $V$, isovalue $\tau$, maximum shape error threshold $E_0$, isotropy parameter $\alpha$, extraction direction (defining cross-sections $k=1 \dots N$).
- **Output**: Simplified isosurface mesh $M$.

### Data Structures
1.  **Priority Queue $Q$**: Stores edge candidates for collapse, ordered by their global cost $\varepsilon_\alpha(c)$ (ascending).
2.  **Priority Queue $W$**: Stores blocked edges, ordered by their reach value (ascending).
3.  **Mesh State**: Current triangulation $M$, including vertices with attributes:
    -   $height(u)$: Rank of vertex $u$ along extraction direction.
    -   $rad(u)$: Radius of vertex $u$.
    -   $reach(u)$: Reach value of vertex $u$.
    -   $\mathbf{H}_u$: Positive definite matrix for shape measure.
    -   $W_u$: Weight (sum of areas) for shape measure.
    -   $\mathbf{G}_u$: Matrix for isotropy measure.
    -   $W$: Global weight for isotropy normalization.

### Formulas
**Shape Measure** [S1]:
The shape measure of a point $x$ relative to patch $U_c$ (neighboring triangles of $c$) is:
$$ h_c(x) = \frac{1}{W_c} \sum_{t \in U_c} w_t d^2(x, P_t) = \frac{1}{W_c} x^T \mathbf{H}_c x $$
where $P_t$ is the plane of triangle $t$, $w_t$ is its area, $W_c = \sum_{t \in U_c} w_t$, and $\mathbf{H}_c$ is a positive definite matrix.
For edge contraction $a,b \to c$:
$$ \mathbf{H}_c = \mathbf{H}_a + \mathbf{H}_b, \quad W_c = W_a + W_b $$

**Mesh Isotropy Criterion** [S1]:
To prevent long, skinny triangles, the isotropy criterion for point $c$ (result of collapsing $a,b$) is:
$$ g_c(x) = \sum_{t \in S_{ab}} w_t (||x - \hat{t}||^2 + avg(t)) = x^T \mathbf{G}_c x $$
where $S_{ab}$ is the set of triangles containing $a$, $b$, or both, $\hat{t}$ is the barycenter of $t$, and $avg(t) = \frac{1}{12} (||p||^2+||q||^2+||r||^2)$ with $p,q,r$ vectors from $\hat{t}$ to vertices of $t$.
The term $g_c$ is normalized by $W = 3 \times \text{area}(S_{ab}) / W_c^{1/2} / E_0$ to balance influence with $h_c$ [S1].

**Global Cost** [S1]:
$$ \varepsilon_\alpha(c) = \sqrt{c^T \left[ (1-\alpha)\frac{\mathbf{H}_c}{W_c} + \alpha\frac{\mathbf{G}_c}{W} \right]} $$
where $\alpha$ is the isotropy parameter (typical value 0.4) [S1].

**Edge Contraction Updates** [S1]:
When collapsing edge $a,b \to c$:
$$ height(c) = \frac{height(a) + height(b)}{2} $$
$$ rad(c) = \frac{||a - b|| + rad(a) + rad(b)}{2} $$
$$ reach(c) = height(c) + rad(c) $$
For new vertices introduced by extraction, $rad(u) = 1$ [S1].

### Parameters
-   **$E_0$**: Maximum shape error allowed. A candidate edge collapse is rejected if its shape measure $\varepsilon_0(c)$ exceeds $E_0$ [S1].
-   **$\alpha$**: Isotropy parameter balancing shape and anisotropy criteria. Typical value: 0.4 [S1].

### Algorithm Steps
1.  **Initialize**: Create empty mesh $M$, empty queues $Q$ and $W$. Initialize vertex attributes for boundary vertices if necessary.
2.  **Loop** for $k$ from 1 to $N-1$ (where $N$ is the number of cross-sections):
    1.  **Extract($k$)**:
        -   Perform Marching Cubes on the volume slice between cross-section $k-1$ and $k$.
        -   Add new vertices, edges, and triangles to $M$.
        -   For each new vertex $u$: set $height(u) = k$, $rad(u) = 1$, $reach(u) = k + 1$.
        -   Compute $\mathbf{H}_u, W_u, \mathbf{G}_u, W$ for new vertices.
    2.  **Delay($k$)**:
        -   Identify all edges in the newly extracted layer $k$.
        -   For each edge $e=(a,b)$ in layer $k$:
            -   Calculate $reach(e)$.
            -   If $reach(e) \ge k$ (blocked by advancing front), add $e$ to $W$ ordered by reach value.
            -   Else, add $e$ to $Q$ ordered by cost $\varepsilon_\alpha$.
    3.  **Activate($k$)**:
        -   While $W$ is not empty and $reach(\text{top}(W)) < k$:
            -   Pop edge $e$ from $W$.
            -   Add $e$ to $Q$ ordered by cost $\varepsilon_\alpha$.
    4.  **Simplify($E_0$)**:
        -   While $Q$ is not empty:
            -   Pop edge $e=(a,b)$ with lowest cost $\varepsilon_\alpha$ from $Q$.
            -   Calculate shape measure $\varepsilon_0(c)$ for the resulting vertex $c$.
            -   If $\varepsilon_0(c) \le E_0$:
                -   Perform edge collapse: merge $a,b$ into $c$.
                -   Update mesh $M$ (remove $a,b$, add $c$, update connectivity).
                -   Update attributes for $c$ using formulas above.
                -   Update neighbors' $\mathbf{H}, \mathbf{G}, W$ values.
                -   Re-evaluate costs for affected edges and update $Q$ (or insert new candidates).
            -   Else:
                -   Discard $e$ (or keep in $Q$ if lazy deletion is used, but standard implementation removes invalid candidates).
3.  **Finalize**:
    -   **Activate($\infty$)**:
        -   While $W$ is not empty:
            -   Pop edge $e$ from $W$.
            -   Add $e$ to $Q$.
    -   **Simplify($E_0$)**:
        -   Empty $Q$ completely as in step 2.4.

### Edge Cases and Pitfalls
-   **Blocked Edges**: Contraction of an edge is prevented if its reach value is greater than or equal to the rank of the advancing front. This prevents artifacts from blocked edges on the last extracted layer [S1].
-   **Precision**: The shape measure $\varepsilon_0(c)$ must be compared against $E_0$. If $E_0$ is too small, the mesh may not simplify enough, leading to high memory usage. If too large, geometric fidelity is lost [S1].
-   **Degenerate Input**: Noisy datasets may produce many small disconnected components. The Tandem Algorithm handles this, but the Extended Tandem Algorithm is recommended for such cases to dump components to disk [S2].

## Subtopics

### [Extended Tandem Algorithm](4308-extended-tandem-algorithm.md)
The Extended Tandem Algorithm is a parallel, bloc-wise extension of the Tandem Algorithm designed to extract and simplify isosurfaces from very large volumetric datasets while minimizing memory consumption. It solves the scalability bottleneck of the sequential Tandem Algorithm, where queue updates and simplification steps become too memory-intensive for high-resolution data, such as generating 1,250,000 triangles per layer on a $1626 \times 7028 \times 2000$ dataset. Unlike the parent method, which processes the entire volume in a single pass, this method splits the dataset into blocks, distributes them across computing nodes, and employs a component dumping mechanism to persist finalized surface components to disk. This allows the extraction process to continue on sub-parts of the dataset without losing previously computed geometry, making it suitable for geophysical datasets with numerous small, disconnected components.

### Components Dumping
A mechanism that frees memory by migrating independent surface components to disk along with meta-data (oriented bounding box, volume) as soon as they are extracted, simplified, and detected as finished [S2]. It detects when a surface component is finished (simplification complete), dumps the completed surface component to disk, and stores meta-data with the dumped component, including oriented bounding box and volume, for later filtering and exploration [S2]. This is useful for noisy datasets or when the isovalue is not well determined, leading to many small disconnected components [S2]. Meta-data allows filtering, such as discarding components with too small volumes or selecting aligned ones [S2].

## Operating characteristics
-   **Time Complexity**: The algorithm performs one pass over the cross-sections. Each extraction step is $O(N_{layer})$ where $N_{layer}$ is the number of cells in the layer. Simplification involves edge collapses, each taking time proportional to the degree of the vertices involved. The total time is dominated by the number of edge collapses, which is bounded by the number of triangles in the final mesh.
-   **Memory Complexity**: The memory usage is bounded by the size of the current layer plus the simplified history. The Tandem Algorithm ensures that the number of vertices and triangles in memory is proportional to the surface area of the extracted portion, not the volume. The memory constraint is controlled by $E_0$ and the simplification rate [S1].
-   **Measured Performance**: On a noisy dataset of size $1626 \times 7028 \times 2000$, the sequential Tandem Algorithm generated 1,250,000 triangles per layer, leading to memory bottlenecks in queue updates and simplification [S1, S2]. The Extended Tandem Algorithm addresses this by distributing work and dumping components [S2].
-   **Strengths**: Reduces memory consumption significantly compared to global extraction. Maintains global simplification quality.
-   **Limitations**: Sequential version does not scale well to extremely large datasets due to queue management overhead. Requires careful tuning of $E_0$ and $\alpha$ [S1].

## Background
The Tandem Algorithm was proposed by Attali et al. [S1]. It revisits the quadratic metric of Garland and Heckbert for edge collapse simplification, introducing a shape measure and a mesh isotropy criterion [S1]. The algorithm alternates extraction and simplification to reduce memory occupancy [S1]. The Extended Tandem Algorithm was later proposed to address scalability issues on very large datasets, particularly in geophysics, by introducing parallel processing and component dumping [S2].
