# Dual Contouring and Surface Nets


## Overview
Dual Contouring and Surface Nets are isosurface extraction algorithms that generate a single vertex per active grid cell (voxel) rather than placing vertices on cell edges like Marching Cubes [G]. This family prioritizes mesh sparsity and feature preservation over topological simplicity, producing watertight meshes with fewer triangles [G]. Dual Contouring optimizes vertex position via a Quadratic Error Function (QEF) to preserve sharp features [Dual Contouring](778-dual-contouring.md), while Surface Nets uses a weighted average of intersection points for a faster, normal-free approximation [Surface Nets](921-surface-nets.md).

## Shared principles
All methods in this family operate on a discretized domain, typically a regular grid, where each cell contains scalar values or occupancy states at its vertices or centers [G]. The core mechanism involves traversing the grid cells and evaluating the data to determine which parts of the domain constitute the surface [G]. A cell is "active" if the scalar field values at its vertices straddle the isosurface [G]. Unlike Marching Cubes, which may produce multiple vertices per cell, these methods produce exactly one vertex per active cell [Dual Contouring](778-dual-contouring.md)[Surface Nets](921-surface-nets.md).

The core mechanism involves:
1. **Cell Traversal**: Iterating over all cells $(x, y, z)$ and determining intersection status via vertex signs relative to $I$ [G].
2. **Vertex Placement**: Computing a single 3D position $V$ for each active cell.
    * In **Dual Contouring**, $V$ minimizes the error $\|AV - b\|^2$, where rows of $A$ are surface normals and $b_i = n_i \cdot P_i$ [Dual Contouring](778-dual-contouring.md).
    * In **Surface Nets**, $V$ is the centroid of intersection points on the cell edges [Surface Nets](921-surface-nets.md).
3. **Topology Construction**: Connecting the single vertex of each active cell to form the mesh. This typically involves identifying shared edges between cells and forming quads or triangles from the vertices of the adjacent cells [G].

```python
import numpy as np

def extract_dual_mesh(grid, dims, isovalue=0.0, method='dual_contouring'):
    """
    Extracts a dual mesh from a scalar grid.
    grid: 3D numpy array of shape (Nx, Ny, Nz)
    dims: tuple (Nx, Ny, Nz)
    isovalue: float, threshold for isosurface
    method: 'dual_contouring' or 'surface_nets'
    Returns: vertices, faces
    """
    Nx, Ny, Nz = dims
    vertices = []
    faces = []
    cell_vertex_map = {}

    # 12 edges of a unit cube defined by corner indices (0-7)
    CUBE_EDGES = [
        (0, 1), (1, 3), (3, 2), (2, 0),
        (4, 5), (5, 7), (7, 6), (6, 4),
        (0, 4), (1, 5), (2, 6), (3, 7)
    ]

    for z in range(Nz - 1):
        for y in range(Ny - 1):
            for x in range(Nx - 1):
                # Sample 8 corners
                corners = [
                    grid[x, y, z], grid[x+1, y, z], grid[x, y+1, z], grid[x+1, y+1, z],
                    grid[x, y, z+1], grid[x+1, y, z+1], grid[x, y+1, z+1], grid[x+1, y+1, z+1]
                ]
                # Compute mask
                mask = 0
                for i, val in enumerate(corners):
                    if val < isovalue:
                        mask |= (1 << i)
                if mask == 0 or mask == 255:
                    continue

                # Vertex placement
                sum_pos = np.array([0.0, 0.0, 0.0])
                count = 0
                if method == 'surface_nets':
                    # Compute intersection points on edges
                    for j, (a, b) in enumerate(CUBE_EDGES):
                        if (mask >> a) & 1 != (mask >> b) & 1:
                            val_a, val_b = corners[a], corners[b]
                            denom = val_b - val_a
                            if abs(denom) < 1e-6:
                                continue
                            t = (isovalue - val_a) / denom
                            # Interpolate position
                            p_a = np.array([x + (a&1), y + ((a>>1)&1), z + ((a>>2)&1)])
                            p_b = np.array([x + (b&1), y + ((b>>1)&1), z + ((b>>2)&1)])
                            p_int = p_a + t * (p_b - p_a)
                            sum_pos += p_int
                            count += 1
                    if count > 0:
                        V = sum_pos / count
                    else:
                        V = np.array([x + 0.5, y + 0.5, z + 0.5])
                elif method == 'dual_contouring':
                    # Collect Hermite data
                    hermite_data = []
                    for j, (a, b) in enumerate(CUBE_EDGES):
                        if (mask >> a) & 1 != (mask >> b) & 1:
                            val_a, val_b = corners[a], corners[b]
                            denom = val_b - val_a
                            if abs(denom) < 1e-6:
                                continue
                            t = (isovalue - val_a) / denom
                            p_a = np.array([x + (a&1), y + ((a>>1)&1), z + ((a>>2)&1)])
                            p_b = np.array([x + (b&1), y + ((b>>1)&1), z + ((b>>2)&1)])
                            p_int = p_a + t * (p_b - p_a)
                            # Compute normal (gradient)
                            grad = compute_gradient(grid, p_int)
                            n = grad / (np.linalg.norm(grad) + 1e-12)
                            hermite_data.append((p_int, n))
                    
                    # Solve QEF: min ||AV - b||^2
                    if len(hermite_data) > 0:
                        A = np.array([n for _, n in hermite_data])
                        b = np.array([np.dot(n, p) for p, n in hermite_data])
                        ATA = A.T @ A
                        ATb = A.T @ b
                        # Regularization
                        ATA += 1e-2 * np.eye(3)
                        ATb += 1e-2 * np.mean([p for p, _ in hermite_data], axis=0)
                        V = np.linalg.solve(ATA, ATb)
                        V = np.clip(V, [x, y, z], [x+1, y+1, z+1])
                    else:
                        V = np.array([x + 0.5, y + 0.5, z + 0.5])
                
                vertices.append(V)
                cell_vertex_map[(x, y, z)] = len(vertices) - 1

    # Topology construction (simplified quad generation)
    for (x, y, z), v_idx in cell_vertex_map.items():
        # Check neighbors to form quads
        for dx, dy, dz in [(1,0,0), (0,1,0), (0,0,1)]:
            neighbor = (x+dx, y+dy, z+dz)
            if neighbor in cell_vertex_map:
                n_idx = cell_vertex_map[neighbor]
                # Form quad with other neighbors to close the loop
                # Omitted for brevity; standard dual graph traversal connects adjacent cell vertices
                pass
    return np.array(vertices), np.array(faces)

def compute_gradient(grid, p):
    x, y, z = p
    dx = grid[min(x+1, grid.shape[0]-1), y, z] - grid[max(x-1, 0), y, z]
    dy = grid[x, min(y+1, grid.shape[1]-1), z] - grid[x, max(y-1, 0), z]
    dz = grid[x, y, min(z+1, grid.shape[2]-1)] - grid[x, y, max(z-1, 0)]
    return np.array([dx, dy, dz])
```

## Subtopics

### [Dual Contouring](778-dual-contouring.md)
Places a vertex inside each intersected cell by minimizing a QEF derived from Hermite data (intersection points and normals). It preserves sharp features and produces manifold meshes but requires solving linear systems and handling rank deficiency. Choose when feature preservation is critical.

### [Surface Nets](921-surface-nets.md)
Places a vertex at the weighted average of edge intersection points. It requires no normals or linear solves, resulting in a sparser, faster mesh than Marching Cubes, but yields less accurate vertex placement than Dual Contouring. Choose for performance-critical applications where sharp features are not paramount.

### [Sparse Dual Marching Cubes](3801-sparse-dual-marching-cubes.md)
Generates a quad-based mesh from sparse voxel SDFs. Each active voxel generates a dual vertex at its center, connected across shared marching cube edges. It is optimized for sparse data structures. Choose when working with sparse voxel grids.

## Background
Dual Contouring was introduced as an improvement over Marching Cubes to handle sharp features and non-manifold geometries [Dual Contouring](778-dual-contouring.md). Surface Nets was proposed as a simplified alternative to Dual Contouring that avoids the computational cost of QEF solving [Surface Nets](921-surface-nets.md). Sparse Dual Marching Cubes extends these concepts to sparse voxel representations [Sparse Dual Marching Cubes](3801-sparse-dual-marching-cubes.md).
