# Mass Point QEF Minimization

Also called: Minimizing towards a mass point

## Overview
Mass Point QEF Minimization is a vertex placement strategy for Dual Contouring that computes the dual vertex position by minimizing the distance to a "mass point" rather than the cube center [S1, unofficial]. The mass point is defined as the average of the exact intersection points on the cube edges, guaranteeing it lies within the generating cube [S1, unofficial]. This method addresses the limitation of standard QEF minimization, which may place the vertex outside the solution space or far from the surface when the implicit function is complex, by ensuring the solution remains interior to the cube [S1, unofficial]. It differs from [Anchor Group](9328-anchor-group.md) by using a geometric average of edge intersections rather than a weighted average of plane intersections for centering.

## How it works
**Inputs:**
- QEF system $Ax = B$, where $A$ is the matrix of plane normals and $B$ is the vector of plane offsets.
- Mass point $p$, represented by four floats: $\{\sum x_i, \sum y_i, \sum z_i, n\}$, where $n$ is the count of intersection points and the sums are the coordinates of those points [S1, unofficial].

**Outputs:**
- Vertex position $x$.

**Data Structures:**
- The mass point is stored as a tuple of 4 floats. When merging QEFs upward in an octree, the components are summed: $\sum x_{new} = \sum x_{left} + \sum x_{right}$, etc. [S1, unofficial].

**Steps:**
1. Compute the mass point $p$ from the intersection points of the implicit function with the cube edges.
2. Let $x = c + p$, where $c$ is the correction vector.
3. Compute $c$ using the pseudoinverse of $A^T A$:
   $$c = (A^T A)^+ (A^T B - A^T A p)$$
   [S1, unofficial]
4. If $A^T A$ is full rank, $(A^T A)^+ = (A^T A)^{-1}$. Otherwise, use the Moore-Penrose pseudoinverse.
5. Compute $x = c + p$.

**Pseudocode:**
```python
def mass_point_qef_minimization(A, B, mass_point_sum_x, mass_point_sum_y, mass_point_sum_z, n):
    """
    Computes the dual vertex position by minimizing distance to the mass point.
    
    Args:
        A: Matrix of plane normals (m x 3).
        B: Vector of plane offsets (m).
        mass_point_sum_x: Sum of x-coordinates of edge intersections.
        mass_point_sum_y: Sum of y-coordinates of edge intersections.
        mass_point_sum_z: Sum of z-coordinates of edge intersections.
        n: Number of edge intersections.
        
    Returns:
        x: The computed vertex position.
    """
    # Compute mass point p
    if n == 0:
        # Fallback if no intersections: use cube center or handle error
        # [G] Standard practice is to use cube center if n=0, but method assumes n>0
        return [0.5, 0.5, 0.5] 
    
    p_x = mass_point_sum_x / n
    p_y = mass_point_sum_y / n
    p_z = mass_point_sum_z / n
    p = [p_x, p_y, p_z]
    
    # Compute A^T A
    AtA = matrix_multiply(transpose(A), A)
    
    # Compute A^T B
    AtB = matrix_multiply(transpose(A), B)
    
    # Compute A^T A p
    AtAp = matrix_multiply(AtA, p)
    
    # Compute residual vector: A^T B - A^T A p
    residual = vector_subtract(AtB, AtAp)
    
    # Compute pseudoinverse of A^T A
    # [G] Use numpy.linalg.pinv or similar for general case
    AtA_pinv = pseudoinverse(AtA)
    
    # Compute correction c
    c = matrix_multiply(AtA_pinv, residual)
    
    # Compute final position x = c + p
    x = vector_add(c, p)
    
    return x
```

**Edge Cases and Pitfalls:**
- If $n=0$, the mass point is undefined. [G] A common fallback is to use the cube center, but this reverts to standard centering behavior.
- When merging QEFs upward in an octree, summing mass point components can produce a mass point far from the actual solution space if large numbers of cubes are collapsed, causing artifacts similar to minimizing towards the cube center [S1, unofficial].

## Subtopics

### Mass Point Fallback for Non-Manifold Geometry
A strategy for handling non-manifold geometry (intersecting surface pieces) by using the mass point position instead of the QEF minimizer to avoid surface spikes [S1, unofficial]. It is chosen when the signed grid indicates a non-manifold configuration at a cube [S1, unofficial]. The steps are: 1. Detect non-manifold configuration using signs at the eight corners of the cube in the signed grid. 2. If non-manifold, position the vertex at the mass point instead of the QEF minimizer [S1, unofficial]. Using the QEF minimizer for non-manifold geometry results in 'spikes' in the surface because the minimizer may lie outside the cube or in an undesirable location [S1, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
- Time: Dominated by solving the linear system $Ax=B$, which is $O(m^3)$ for $m$ planes if using direct inversion, or $O(m^2)$ with iterative methods. The mass point computation is $O(1)$ if pre-aggregated.
- Memory: Adds 4 floats per QEF for the mass point representation [S1, unofficial].

**Measured Performance:**
- Not given in the sources.

**Scaling:**
- The method scales with the number of planes in the QEF. Merging QEFs in an octree requires summing mass point components, which is linear in the number of merged cubes [S1, unofficial].

**Strengths and Limitations:**
- Strengths: Guarantees the vertex lies inside the generating cube, preventing folding artifacts [S1, unofficial]. Handles non-manifold geometry by falling back to the mass point [S1, unofficial].
- Limitations: When merging QEFs upward in an octree, large collapses can produce mass points far from the solution space, leading to artifacts [S1, unofficial].

**When to Use:**
- Use when the solution space is expected to be near the edge intersections and interiority is critical.
- Use for non-manifold geometry to avoid spikes.

**When Not to Use:**
- Avoid when merging large numbers of cubes in an octree without feature detection, as the mass point may drift [S1, unofficial].

## Background
Originated in the paper "Dual Contouring: The Secret Sauce" by Schaefer and Warren [S1, unofficial]. The method was developed to improve vertex placement in Dual Contouring by ensuring the solution remains interior to the cube, addressing issues with standard QEF minimization where the solution could lie outside the cube or far from the surface. It is used in mesh generation from implicit functions, particularly in scenarios requiring robust handling of complex topologies.
