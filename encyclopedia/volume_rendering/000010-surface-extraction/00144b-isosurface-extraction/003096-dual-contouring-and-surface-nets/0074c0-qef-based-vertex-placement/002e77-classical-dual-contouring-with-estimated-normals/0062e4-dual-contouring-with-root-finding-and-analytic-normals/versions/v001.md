# Dual Contouring with Root Finding and Analytic Normals


## Overview
A dual contouring variant that improves feature crispness by using root finding to locate exact surface crossings on edges and computing normals analytically at those points, rather than interpolating or using grid-based approximations [S1, unofficial]. It sets itself apart from its parent [Classical Dual Contouring with Estimated Normals](5802-classical-dual-contouring-with-estimated-normals.md) by replacing estimated or interpolated normals with analytic normals derived from the closest brush point, and from [Radial Dual Contouring](17425-radial-dual-contouring.md) by relying on continuous swept-SDF evaluation rather than radial projection.

## How it works
**Inputs and outputs:**
- Input: A continuous swept-SDF evaluator $f(t)$, a grid of vertices, and a set of "brush" points $C$ (one per cell or region, representing the implicit surface approximation).
- Output: A polygonal mesh representing the isosurface at level $\text{iso} = 10^{-3}$ [S1, unofficial].

**Data structures:**
- `CV_argmins`: A map or array storing the argmin time $t$ for each grid vertex, representing the nearest point on the continuous surface (CS) [S1, unofficial].
- `brush_points`: A collection of points $C$ associated with the local geometry [S1, unofficial].

**Steps:**
1. **Identify Edge Crossings:** For each edge in the dual contouring grid where the sign of the SDF changes, identify it as a crossing edge.
2. **Root Finding:** Perform root finding using bisection on the sign-changing edge using the continuous SDF to locate the exact intersection point $P$ [S1, unofficial].
   - The bisection operates on the continuous swept-SDF evaluator.
   - To ensure efficiency, reuse the continuation's own per-point optimizer (e.g., `gradient_descent_test` on the same $f(t)/gf(t)$) [S1, unofficial].
   - Warm-start the optimizer from the nearest grid vertex's argmin time $CV\_argmins$ [S1, unofficial].
   - This ensures each edge-point evaluation is a cheap local descent, not a cold global search, so the value matches the continuous surface (CS) [S1, unofficial].
3. **Compute Analytic Normal:** At the intersection point $P$, compute the normal as $P - C$, where $C$ is the closest brush point at the tangent time [S1, unofficial].
   - Because the surface is the iso=$10^{-3}$ level set, the crossing sits $\sim \text{iso}$ off the brush, so $P - C$ is well-defined and represents the outward brush normal [S1, unofficial].
4. **Quadrilateral Generation:** Use the computed vertices and normals to generate quadrilaterals within each cell, following the standard dual contouring topology, but using the precise $P$ and analytic normal for feature preservation [S1, unofficial].

**Parameters:**
- Isovalue: $10^{-3}$ [S1, unofficial].
- Bisection tolerance: Not given in the sources.
- Optimizer steps: Not given in the sources.

**Edge cases and pitfalls:**
- **Precision:** The method relies on the continuity of the swept-SDF. Discontinuities may break the bisection.
- **Boundary:** Ensure $CV\_argmins$ is valid for all grid vertices; otherwise, the warm-start may fail.
- **Degenerate Input:** If the brush point $C$ coincides with $P$, the normal $P-C$ is zero. This is unlikely given the iso-level offset, but should be guarded against [G].

## Subtopics

### Varadhan et al. Extended Dual Contouring
An improved reconstruction algorithm for accurate polygonization of implicit surfaces from volumetric data, capable of reconstructing thin features while avoiding creation of additional handles [S2]. It uses directed distances (distance along a direction) to perform an exact edge intersection test to detect intersections of the edge with a surface [S2]. The algorithm combines this edge intersection test with the original dual contouring algorithm, takes into account the characteristics of the grid and considers complex edges, enumerates all intersections along the edges, separates them into components, and reconstructs the isosurface locally within each cell [S2].

## Operating characteristics
- **Time Complexity:** Not given in the sources. The root finding adds a logarithmic factor per edge due to bisection.
- **Memory Complexity:** Not given in the sources. Requires storage for `cv_argmins` and `brush_points`.
- **Measured Performance:** Not given in the sources.
- **Strengths:** Recovers sharp features that grid-gradient normals round off; the demo DC surface is visibly crisper [S1, unofficial].
- **Limitations:** Requires a continuous swept-SDF evaluator; not applicable to methods like Marching Cubes where linear-interpolation crossings already sit at the tolerance floor [S1, unofficial].
- **When to use:** When crisp features are critical and a continuous SDF is available.
- **When not to use:** When performance is critical and features are not sharp, or when the SDF is not continuous.

## Background
The method originates from work on swept volumes and dual contouring, specifically exploring the benefits of root finding for feature preservation [S1, unofficial]. It builds on the classical dual contouring approach but enhances it with analytic normals derived from the closest brush point. The extended dual contouring by Varadhan et al. provides a theoretical foundation for handling complex edges and thin features [S2].
