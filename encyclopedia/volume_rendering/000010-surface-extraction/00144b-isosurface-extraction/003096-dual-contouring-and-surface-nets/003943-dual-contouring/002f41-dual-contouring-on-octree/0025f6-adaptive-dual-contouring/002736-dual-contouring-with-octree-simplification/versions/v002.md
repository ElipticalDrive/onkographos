# Dual Contouring with Octree Simplification

Also called: Octree DC, Dual Contouring (Octree-based), Octree Simplification for Dual Contouring

## Overview
Dual Contouring with Octree Simplification is a surface extraction method that combines adaptive octree traversal with topological simplification to generate a manifold mesh from a scalar field [S2, unofficial]. It solves a Quadratic Error Function (QEF) at each node to determine vertex positions, then recursively collapses internal octree nodes into 'pseudo-leaf' nodes if the resulting QEF error is below a threshold, preserving sharp features defined by the sign configuration of child nodes [S1, S4, unofficial]. Unlike standard Dual Contouring which places one vertex per leaf voxel, this method reduces vertex count by merging internal nodes, producing a coarser but topologically consistent mesh suitable for real-time rendering or further processing [S2, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   A scalar density function $f(\mathbf{p})$ [S2, S4, unofficial].
*   Root octree parameters: minimum position $\mathbf{min}$, size $S$ (must be a power of two, typically 64) [S2, unofficial].
*   Simplification threshold $\tau$ (QEF error tolerance, typically $10^{-6}$) [S1, S2, unofficial].
*   Material thresholds (e.g., $\{-1.0, 0.1, 1.0, 10.0, 50.0\}$) for multi-material support, or a single threshold for binary solid/air [S2, S4, unofficial].

**Outputs:**
*   A simplified octree where nodes are either `Node_Leaf`, `Node_Pseudo`, or `Node_Internal` (pruned) [S2, unofficial].
*   A vertex buffer containing positions and average normals for all leaf and pseudo-leaf nodes [S2, unofficial].
*   An index buffer containing triangle indices generated by contouring the simplified octree [S2, unofficial].

### Data Structures
**OctreeNode**
*   `type`: Enum (`Node_None`, `Node_Internal`, `Node_Pseudo`, `Node_Leaf`) [S2, unofficial].
*   `min`: Vector3, world-space minimum corner of the cell [S2, unofficial].
*   `size`: int, side length of the cell [S2, unofficial].
*   `children`: Array of 8 `OctreeNode` references, ordered by `CHILD_MIN_OFFSETS` [S2, unofficial].
*   `drawInfo`: `OctreeDrawInfo` instance containing position, normals, QEF coefficients, and corner bitmask [S2, unofficial].

**OctreeDrawInfo**
*   `index`: int, index in the global vertex buffer [S2, unofficial].
*   `corners`: int, 8-bit bitmask where bit $i$ is 1 if corner $i$ is SOLID, 0 if AIR [S2, S4, unofficial].
*   `position`: Vector3, vertex position computed by QEF [S2, unofficial].
*   `averageNormal`: Vector3, normalized average of child normals [S2, unofficial].
*   `qef`: QEF data structure (coefficients $A, \mathbf{b}, c$) [S2, unofficial].

**QEF Data**
*   `ata`: float[6], symmetric upper triangle of matrix $A$ ($A_{00}, A_{01}, A_{02}, A_{11}, A_{12}, A_{22}$) [S3, unofficial].
*   `atb`: float[3], vector $\mathbf{b}$ [S3, unofficial].
*   `btb`: float, scalar $c$ [S3, unofficial].
*   `massPoint`: Vector3, centroid of constraints [S2, unofficial].

**Lookup Tables**
*   `CHILD_MIN_OFFSETS[8][3]`: Integer offsets for children relative to parent min. Index 0: $(0,0,0)$, Index 1: $(0,0,1)$, ..., Index 7: $(1,1,1)$ [S2, S4, unofficial].
*   `edgevmap[12][2]`: Maps edge index to two corner indices. X-axis (0-3): `{2,4},{1,5},{2,6},{3,7}`. Y-axis (4-7): `{0,2},{1,3},{4,6},{5,7}`. Z-axis (8-11): `{0,1},{2,3},{4,5},{6,7}` [S2, S4, unofficial].
*   `vertMap[8][3]`: Binary coordinates for corners 0-7 [S2, unofficial].
*   `faceMap[6][4]`: Maps face index to 4 corner indices [S2, unofficial].
*   `cellProcFaceMask[12][3]`, `cellProcEdgeMask[6][5]`, `faceProcFaceMask[3][4][3]`, `faceProcEdgeMask[3][4][6]`, `edgeProcEdgeMask[3][2][5]`, `processEdgeMask[3][4]`: Arrays driving the recursive contouring traversal [S2, unofficial].

### Parameters
*   `QEF_ERROR`: Convergence threshold for QEF solver. Default: $10^{-6}$ [S1, S2, unofficial].
*   `QEF_SWEEPS`: Number of Givens rotation sweeps. Default: 4 [S1, S2, unofficial].
*   `H`: Step size for finite difference normal calculation. Default: $0.001$ [S2, unofficial].
*   `steps`: Number of steps for zero-crossing approximation. Default: 8 [S2, unofficial].

### Algorithm Steps

#### 1. Octree Construction
Build the octree recursively. If node size is 1, construct a leaf; otherwise, create 8 children with half the size and offset by `CHILD_MIN_OFFSETS`. Return null if no children are non-null [S4, unofficial].

```python
def construct_octree(min_pos, size, threshold):
    if size == 1:
        return construct_leaf(min_pos, threshold)
    children = []
    for i in range(8):
        child_min = min_pos + CHILD_MIN_OFFSETS[i] * (size / 2)
        child = construct_octree(child_min, size / 2, threshold)
        if child is not None:
            children.append(child)
        else:
            children.append(None)
    if all(c is None for c in children):
        return None
    return OctreeNode(type=Node_Internal, min=min_pos, size=size, children=children)

def construct_leaf(min_pos, threshold):
    corners = 0
    qef = QefSolver()
    avg_normal = Vector3(0, 0, 0)
    edge_count = 0
    for i in range(8):
        p = min_pos + CHILD_MIN_OFFSETS[i]
        density = f(p)
        material = MATERIAL_SOLID if density < 0 else MATERIAL_AIR
        corners |= (material << i)
    if corners == 0 or corners == 255:
        return None
    for i in range(12):
        c1, c2 = edgevmap[i]
        p1 = min_pos + CHILD_MIN_OFFSETS[c1]
        p2 = min_pos + CHILD_MIN_OFFSETS[c2]
        m1 = (corners >> c1) & 1
        m2 = (corners >> c2) & 1
        if m1 != m2:
            p_cross = approximate_zero_crossing(p1, p2)
            n = calculate_surface_normal(p_cross)
            qef.add_constraint(p_cross, n)
            avg_normal += n
            edge_count += 1
    qef_position, error = qef.solve(QEF_ERROR, QEF_SWEEPS)
    if is_out_of_bounds(qef_position, min_pos, size):
        qef_position = qef.get_mass_point()
    if edge_count > 0:
        avg_normal = avg_normal / edge_count
    avg_normal = normalize(avg_normal)
    draw_info = OctreeDrawInfo(index=-1, corners=corners, position=qef_position, averageNormal=avg_normal, qef=qef.get_data())
    return OctreeNode(type=Node_Leaf, min=min_pos, size=size, children=None, drawInfo=draw_info)
```

#### 2. Octree Simplification
Recursively simplify the octree. An internal node can be collapsed into a pseudo-leaf if all its children are leaves or pseudo-leaves (not internal) and the aggregated QEF error is below the threshold [S4, unofficial].

```python
def simplify_octree(node, threshold):
    if node is None or node.type != Node_Internal:
        return node
    for i in range(8):
        node.children[i] = simplify_octree(node.children[i], threshold)
    is_collapsible = True
    for child in node.children:
        if child is None:
            continue
        if child.type == Node_Internal:
            is_collapsible = False
            break
    if not is_collapsible:
        return node
    qef = QefSolver()
    signs = [-1] * 8
    midsign = 0
    for i in range(8):
        child = node.children[i]
        if child is None:
            continue
        qef.add(child.drawInfo.qef)
        midsign = (child.drawInfo.corners >> 7) & 1
        for j in range(8):
            if signs[j] == -1:
                signs[j] = (child.drawInfo.corners >> j) & 1
    qef_position, error = qef.solve(QEF_ERROR, QEF_SWEEPS)
    if is_out_of_bounds(qef_position, node.min, node.size):
        qef_position = qef.get_mass_point()
    if error > threshold:
        return node
    new_corners = 0
    for i in range(8):
        sign = midsign if signs[i] == -1 else signs[i]
        new_corners |= (sign << i)
    avg_normal = Vector3(0, 0, 0)
    for child in node.children:
        if child is not None and child.type in (Node_Leaf, Node_Pseudo):
            avg_normal += child.drawInfo.averageNormal
    avg_normal = normalize(avg_normal)
    draw_info = OctreeDrawInfo(index=-1, corners=new_corners, position=qef_position, averageNormal=avg_normal, qef=qef.get_data())
    node.children = None
    node.type = Node_Pseudo
    node.drawInfo = draw_info
    return node
```

#### 3. Mesh Generation
Generate vertices and indices from the simplified octree.

```python
def generate_vertex_indices(node, vertex_buffer):
    if node is None:
        return
    if node.type == Node_Internal:
        for child in node.children:
            generate_vertex_indices(child, vertex_buffer)
    else:
        node.drawInfo.index = len(vertex_buffer)
        vertex_buffer.append(MeshVertex(position=node.drawInfo.position, normal=node.drawInfo.averageNormal))

def generate_mesh_from_octree(root, vertex_buffer, index_buffer):
    vertex_buffer.clear()
    index_buffer.clear()
    generate_vertex_indices(root, vertex_buffer)
    contour_cell_proc(root, index_buffer)
```

#### 4. Contouring
Traverse the simplified octree to generate triangle indices. This step assumes the octree has been simplified and only Leaf/Pseudo nodes contain geometry.

```python
def contour_cell_proc(node, index_buffer):
    if node is None:
        return
    if node.type == Node_Internal:
        for child in node.children:
            contour_cell_proc(child, index_buffer)
        for i in range(12):
            c0, c1, dir = cellProcFaceMask[i]
            contour_face_proc([node.children[c0], node.children[c1]], dir, index_buffer)
        for i in range(6):
            c0, c1, c2, c3, dir = cellProcEdgeMask[i]
            contour_edge_proc([node.children[c0], node.children[c1], node.children[c2], node.children[c3]], dir, index_buffer)

def contour_face_proc(nodes, dir, index_buffer):
    if nodes[0].type != Node_Internal and nodes[1].type != Node_Internal:
        for i in range(4):
            c0, c1, c2, c3, c4, c5 = faceProcEdgeMask[dir][i]
            order = [0, 0, 1, 1] if i < 2 else [0, 1, 0, 1]
            edge_nodes = [nodes[order[j]] if nodes[order[j]].type != Node_Internal else nodes[order[j]].children[c] for j, c in enumerate([c0, c1, c2, c3])]
            contour_edge_proc(edge_nodes, c5, index_buffer)
    else:
        for i in range(4):
            c0, c1, new_dir = faceProcFaceMask[dir][i]
            face_nodes = [nodes[0].children[c0] if nodes[0].type == Node_Internal else nodes[0],
                          nodes[1].children[c1] if nodes[1].type == Node_Internal else nodes[1]]
            contour_face_proc(face_nodes, new_dir, index_buffer)
        for i in range(4):
            c0, c1, c2, c3, c4, c5 = faceProcEdgeMask[dir][i]
            order = [0, 0, 1, 1] if i < 2 else [0, 1, 0, 1]
            edge_nodes = [nodes[order[j]] if nodes[order[j]].type != Node_Internal else nodes[order[j]].children[c] for j, c in enumerate([c0, c1, c2, c3])]
            contour_edge_proc(edge_nodes, c5, index_buffer)

def contour_edge_proc(nodes, dir, index_buffer):
    if all(n.type != Node_Internal for n in nodes):
        contour_process_edge(nodes, dir, index_buffer)
    else:
        for i in range(2):
            c0, c1, c2, c3, new_dir = edgeProcEdgeMask[dir][i]
            edge_nodes = [nodes[j] if nodes[j].type != Node_Internal else nodes[j].children[c] for j, c in enumerate([c0, c1, c2, c3])]
            contour_edge_proc(edge_nodes, new_dir, index_buffer)

def contour_process_edge(nodes, dir, index_buffer):
    min_size = float('inf')
    min_index = 0
    indices = [-1] * 4
    flip = False
    sign_change = [False] * 4
    for i in range(4):
        edge_idx = processEdgeMask[dir][i]
        c1, c2 = edgevmap[edge_idx]
        m1 = (nodes[i].drawInfo.corners >> c1) & 1
        m2 = (nodes[i].drawInfo.corners >> c2) & 1
        if nodes[i].size < min_size:
            min_size = nodes[i].size
            min_index = i
            flip = (m1 != MATERIAL_AIR)
        indices[i] = nodes[i].drawInfo.index
        sign_change[i] = (m1 == MATERIAL_AIR and m2 != MATERIAL_AIR) or (m1 != MATERIAL_AIR and m2 == MATERIAL_AIR)
    if sign_change[min_index]:
        if not flip:
            index_buffer.extend([indices[0], indices[1], indices[3], indices[0], indices[3], indices[2]])
        else:
            index_buffer.extend([indices[0], indices[3], indices[1], indices[0], indices[2], indices[3]])
```

### Edge Cases and Pitfalls
*   **Boundary Violation:** The QEF solution may fall outside the cell bounds. Always clamp to the mass point (centroid) if this occurs [S2, S4, unofficial].
*   **Degenerate Cells:** If a cell has no edge intersections (all solid or all air), it returns null and is not processed [S4, unofficial].
*   **Collapsibility:** An internal node cannot be simplified if any child is still internal. This ensures topological consistency during simplification [S4, unofficial].
*   **Missing Children:** During simplification, if a child is null, its sign is -1. The code uses `midsign` (from the first valid child's corner $7-i$) to fill the corner bitmask for the pseudo-leaf [S4, unofficial].
*   **Precision:** Use double precision for QEF accumulation if single precision leads to instability, though sources use float with $10^{-6}$ tolerance [S1, S2, unofficial].

## Operating characteristics

*   **Time Complexity:** $O(N)$ where $N$ is the number of octree nodes, assuming constant-time QEF solve (fixed sweeps). The simplification step is linear in the number of nodes. Contouring is linear in the number of leaf/pseudo nodes [S2, unofficial].
*   **Memory Complexity:** $O(N)$ for octree storage. Vertex and index buffers are proportional to the number of leaf/pseudo nodes [S2, unofficial].
*   **Performance:** Depends heavily on the simplification threshold. A higher threshold reduces vertex count but may lose detail. Typical performance on modern hardware is real-time for moderate resolutions (e.g., 64^3 root) [S2, unofficial].
*   **Strengths:** Produces manifold meshes, preserves sharp features via QEF, reduces vertex count via simplification, adaptive resolution [S2, unofficial].
*   **Limitations:** QEF solve can be expensive if not optimized (Givens rotations). Simplification may introduce artifacts if threshold is too high. Boundary handling requires care [S2, unofficial].
*   **When to use:** Real-time rendering, level-of-detail generation, mesh simplification from signed distance fields [S2, unofficial].
*   **When not to use:** When exact geometric fidelity is required without simplification, or when the scalar field is not available for normal calculation [S2, unofficial].

## Background

Dual Contouring was introduced by Tao Ju et al. in 2002 [S3, unofficial]. The method places one vertex per intersected voxel and positions it by minimizing a QEF formed by intersection points and normals. The octree-based simplification variant was implemented in the "DualContouringSample" by Nick Gilden (2011) and ported to C# by Tuckbone (2011) [S1, S2, unofficial]. It is used for high-quality surface reconstruction from signed distance fields or grid data [S3, unofficial].
