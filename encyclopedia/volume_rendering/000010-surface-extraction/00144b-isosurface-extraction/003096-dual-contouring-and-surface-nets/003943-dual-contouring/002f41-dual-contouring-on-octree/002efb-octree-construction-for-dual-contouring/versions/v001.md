# Octree Construction for Dual Contouring
Also called: Recursive Octree Construction for Dual Contouring

## Overview
This method constructs the spatial hierarchy required for Dual Contouring by recursively subdividing a volume into an octree, pruning branches that do not intersect the isosurface. It differs from sibling methods like [Mesh Extraction from K-D Tree](4607-mesh-extraction-from-k-d-tree.md) by using a fixed-depth hierarchical grid structure rather than a binary spatial partition, and from [Isomesh Octree Build and Clustering](4984-isomesh-octree-build-and-clustering.md) by focusing on single-vertex-per-leaf extraction logic rather than clustering. It solves the problem of efficiently identifying which voxels contain surface geometry to minimize memory usage and processing time for sparse volumes.

## How it works
### Inputs and Outputs
**Inputs:**
- A root `OctreeNode` representing the entire volume bounding box.
- A scalar field function `Density_Func(p)` returning the density at position `p`.
- Constants: `MATERIAL_SOLID` (density < 0), `MATERIAL_AIR` (density >= 0), `MAX_CROSSINGS` (6), `H` (0.001f), `steps` (8).

**Outputs:**
- A pruned octree where leaf nodes (`Node_Leaf`) contain `OctreeDrawInfo` with vertex position, normal, and QEF data. Internal nodes (`Node_Internal`) contain pointers to children. Nodes with no surface intersection are deleted (`nullptr`).

### Data Structures
**OctreeNode**
- `type` (`enum`): `Node_None`, `Node_Internal`, `Node_Psuedo`, `Node_Leaf`.
- `min` (`ivec3`): Minimum corner of the node's bounding box in voxel coordinates.
- `size` (`int`): Side length of the cube in voxels.
- `children` (`OctreeNode* [8]`): Pointers to 8 child nodes.
- `drawInfo` (`OctreeDrawInfo*`): Pointer to drawing data; `nullptr` for internal nodes.

**OctreeDrawInfo**
- `index` (`int`): Vertex buffer index.
- `corners` (`int`): Bitmask of corner states (bit `i` is 1 if solid, 0 if air).
- `position` (`vec3`): Calculated vertex position.
- `averageNormal` (`vec3`): Normalized sum of edge normals.
- `qef` (`QEF`): Quadric Error Function solver state.

**Constants**
- `CHILD_MIN_OFFSETS` (`ivec3 [8]`): Offsets for child bounding box minimums relative to parent. Indices 0-7 map to `(0,0,0)` through `(1,1,1)`.

### Algorithm Steps

1. **Recursive Construction**: Call `ConstructOctreeNodes` on the root.
2. **Leaf Evaluation**: If `node->size == 1`, call `ConstructLeaf`.
3. **Child Creation**: If `node->size > 1`, create 8 children. For child `i`:
   - `child->size = node->size / 2`
   - `child->min = node->min + (CHILD_MIN_OFFSETS[i] * child->size)`
   - `child->type = Node_Internal`
   - Recursively call `ConstructOctreeNodes(child)`.
4. **Pruning**: If all 8 children return `nullptr`, delete the current node and return `nullptr`. Otherwise, return the node.
5. **Corner Sampling**: In `ConstructLeaf`, sample `Density_Func` at 8 corners. Corner `i` position is `leaf->min + CHILD_MIN_OFFSETS[i]`. Set bit `i` of `corners` to 1 if density < 0, else 0.
6. **Discard Check**: If `corners == 0` (all air) or `corners == 255` (all solid), delete leaf and return `nullptr`.
7. **Edge Intersection**: Iterate 12 edges defined by `edgevmap[i][0]` and `edgevmap[i][1]` (corner indices).
   - Check material states `m1` and `m2` from `corners`.
   - If `m1 == m2`, skip edge.
   - Otherwise, calculate zero crossing position `p` and normal `n` for the edge.
   - Store `p` and `n` in `positions[edgeCount]` and `normals[edgeCount]`. Increment `edgeCount`. Stop if `edgeCount == MAX_CROSSINGS`.
8. **Zero Crossing Approximation**: For edge endpoints `p0` and `p1`:
   - Sample 8 points along the segment. `t` ranges from 0 to 1 in steps of `1/8`.
   - `p = p0 + (p1 - p0) * t`
   - Find `t` minimizing `abs(Density_Func(p))`.
   - Return `p0 + (p1 - p0) * t`.
9. **Normal Calculation**: For intersection point `p`:
   - `dx = Density_Func(p + (H,0,0)) - Density_Func(p - (H,0,0))`
   - `dy = Density_Func(p + (0,H,0)) - Density_Func(p - (0,H,0))`
   - `dz = Density_Func(p + (0,0,H)) - Density_Func(p - (0,0,H))`
   - `n = normalize(vec3(dx, dy, dz))`
10. **QEF Solve**: Initialize QEF with `edgeCount`, `normals`, and `positions`. Solve for `position`.
11. **Clamping**: If `position` is outside `leaf`'s bounding box (`min` to `min + size`), clamp `position` to `qef.masspoint` (average of input positions).
12. **Finalize**: Sum `normals`, normalize to get `averageNormal`. Set `leaf->type = Node_Leaf`. Assign `drawInfo`.

### Pseudocode

```python
# Constants
MATERIAL_SOLID = -1
MATERIAL_AIR = 0
MAX_CROSSINGS = 6
H = 0.001
STEPS = 8

# Helper: Calculate surface normal using central finite difference
def calculate_surface_normal(p, density_func):
    dx = density_func(p + vec3(H, 0, 0)) - density_func(p - vec3(H, 0, 0))
    dy = density_func(p + vec3(0, H, 0)) - density_func(p - vec3(0, H, 0))
    dz = density_func(p + vec3(0, 0, H)) - density_func(p - vec3(0, 0, H))
    return normalize(vec3(dx, dy, dz))

# Helper: Approximate zero crossing position on an edge
def approximate_zero_crossing_position(p0, p1, density_func):
    min_val = 100000.0
    best_t = 0.0
    increment = 1.0 / STEPS
    current_t = 0.0
    while current_t <= 1.0:
        p = p0 + (p1 - p0) * current_t
        density = abs(density_func(p))
        if density < min_val:
            min_val = density
            best_t = current_t
        current_t += increment
    return p0 + (p1 - p0) * best_t

# Main Recursive Construction
def construct_octree_nodes(node):
    if node is None:
        return None

    if node.size == 1:
        return construct_leaf(node)

    child_size = node.size // 2
    has_children = False

    for i in range(8):
        child = OctreeNode()
        child.size = child_size
        child.min = node.min + (CHILD_MIN_OFFSETS[i] * child_size)
        child.type = Node_Internal
        
        child_node = construct_octree_nodes(child)
        node.children[i] = child_node
        has_children = has_children or (child_node is not None)

    if not has_children:
        delete node
        return None

    return node

# Leaf Construction
def construct_leaf(leaf):
    corners = 0
    # Sample 8 corners
    for i in range(8):
        corner_pos = leaf.min + CHILD_MIN_OFFSETS[i]
        density = density_func(corner_pos)
        if density < 0:
            corners |= (1 << i)
    
    # Discard if no surface intersection
    if corners == 0 or corners == 255:
        delete leaf
        return None

    positions = [vec3() for _ in range(MAX_CROSSINGS)]
    normals = [vec3() for _ in range(MAX_CROSSINGS)]
    edge_count = 0

    # Iterate 12 edges
    for i in range(12):
        c1 = edgevmap[i][0]
        c2 = edgevmap[i][1]
        
        m1 = (corners >> c1) & 1
        m2 = (corners >> c2) & 1
        
        # Skip if both endpoints are same material
        if m1 == m2:
            continue
        
        if edge_count >= MAX_CROSSINGS:
            break

        p1 = leaf.min + CHILD_MIN_OFFSETS[c1]
        p2 = leaf.min + CHILD_MIN_OFFSETS[c2]
        
        # Find intersection point
        p = approximate_zero_crossing_position(p1, p2, density_func)
        
        # Calculate normal at intersection
        n = calculate_surface_normal(p, density_func)
        
        positions[edge_count] = p
        normals[edge_count] = n
        edge_count += 1

    # Solve QEF
    draw_info = OctreeDrawInfo()
    draw_info.qef.initialize(edge_count, normals, positions)
    draw_info.position = draw_info.qef.solve()
    
    # Clamp position to bounding box
    min_v = vec3(leaf.min)
    max_v = vec3(leaf.min + ivec3(leaf.size))
    
    if (draw_info.position.x < min_v.x or draw_info.position.x > max_v.x or
        draw_info.position.y < min_v.y or draw_info.position.y > max_v.y or
        draw_info.position.z < min_v.z or draw_info.position.z > max_v.z):
        draw_info.position = draw_info.qef.masspoint

    # Calculate average normal
    avg_normal = vec3(0, 0, 0)
    for i in range(edge_count):
        avg_normal += normals[i]
    draw_info.average_normal = normalize(avg_normal)
    
    draw_info.corners = corners
    leaf.type = Node_Leaf
    leaf.draw_info = draw_info
    
    return leaf
```

### Edge Cases and Pitfalls
- **Precision**: The zero-crossing approximation uses only 8 samples. This may miss narrow features or introduce positional error [S1, unofficial].
- **QEF Solution Outside Box**: The QEF solver may produce a vertex outside the leaf's bounding box. This must be clamped to the masspoint to maintain topological consistency [S1, unofficial].
- **Memory**: The algorithm constructs all internal nodes before pruning leaves, leading to wasted memory for empty branches [S1, unofficial].

## Operating characteristics
- **Time Complexity**: $O(N)$ where $N$ is the number of nodes in the full octree up to the leaf level, as every node is visited. Pruning reduces the number of leaf evaluations.
- **Memory Complexity**: Proportional to the number of nodes in the pruned octree. Internal nodes consume memory even if they contain no surface data until the bottom-up pruning step.
- **Strengths**: Simple to implement; hierarchical structure allows for efficient culling of empty space.
- **Limitations**: Inefficient memory usage due to pre-construction of internal nodes; fixed sampling rate for zero-crossing may lack accuracy for complex surfaces [S1, unofficial].

## Background
This method is described in an unofficial blog post by Nigel Gildea, which provides a simple implementation of Dual Contouring [S1, unofficial]. It diverges from the reference implementation's class hierarchy by using a single `OctreeNode` class with a type enum. The approach is designed for simplicity rather than optimal performance, explicitly acknowledging the wastefulness of constructing parent nodes before evaluating leaves [S1, unofficial].
