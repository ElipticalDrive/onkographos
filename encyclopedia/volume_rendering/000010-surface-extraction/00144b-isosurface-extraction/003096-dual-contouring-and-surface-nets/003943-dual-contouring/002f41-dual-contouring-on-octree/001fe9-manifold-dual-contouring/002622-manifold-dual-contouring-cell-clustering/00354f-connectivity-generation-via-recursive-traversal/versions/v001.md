# Connectivity Generation via Recursive Traversal

Also called: CellProc, FaceProc, EdgeProc algorithm

## Overview
This algorithm extracts surface connectivity from an octree-based dual contouring representation by traversing the tree to enumerate minimal edges intersected by the surface [S1]. It establishes a one-to-one relationship between surface patches and these minimal edges, ensuring manifold output [S1]. It differs from sibling methods by focusing exclusively on topological traversal and patch generation via recursive cell, face, and edge processing, rather than index processing or triangle generation [S1, 3699-manifold-dual-contouring-index-processing-and-triangle-gener.md].

## How it works
**Inputs and Outputs:**
*   **Input:** An octree structure where cells can be subdivided. The octree contains dual nodes (minimizers) localized within each cell [S1].
*   **Output:** A set of surface patches (quads or triangles) defined by their connectivity to minimal edges [S1].

**Data Structures:**
*   **Octree Cell:** Represents a voxel or subdivision. Contains references to sub-cells (children) and dual nodes [S1].
*   **Dual Node:** A point located within a cell, typically derived from the centroid of the volume component inside that cell [S1].

**Definitions:**
*   **Minimal Edge:** An edge that does not contain any other edge in a neighboring octree cell [S1]. In other words, it is the smallest edge unit in the octree hierarchy at that location [S1].
*   **Uniform Case:** All four cells sharing an edge are of the same size [S1].
*   **Adaptive Case:** One of the four cells is repeated (effectively three distinct cells) due to differing subdivision levels [S1].

**Algorithm Steps:**
The algorithm uses three mutually recursive functions: `CellProc`, `FaceProc`, and `EdgeProc`.

1.  **`CellProc(c)`:** Receives a cell $c$.
    *   Recursively call `CellProc` for every sub-cell (child) of $c$.
    *   Make 12 calls to `FaceProc`. Each call passes a pair of face-adjacent sub-cells of $c$ [S1].
    *   Make 6 calls to `EdgeProc`. Each call passes the four sub-cells of $c$ that share a common edge [S1].

2.  **`FaceProc(c1, c2)`:** Receives two cells $c1$ and $c2$ sharing a common face $f$.
    *   Recursively call `FaceProc` four times. Each call passes a pair of sub-cells of $c1$ and $c2$ that share a face contained within $f$ [S1].
    *   Make 4 calls to `EdgeProc`. Each call passes the four sub-cells of $c1$ and $c2$ that share an edge contained within $f$ [S1].

3.  **`EdgeProc(c1, c2, c3, c4)`:** Receives four edge-adjacent cells (in the uniform case) or three distinct cells (in the adaptive case, with one cell repeated) [S1].
    *   Make 2 recursive calls to `EdgeProc`. Each call passes the four sub-cells sharing a half-edge contained in the edge defined by the input cells [S1].
    *   **Patch Generation:** If the input cells share a **minimal edge** (i.e., no further subdivision exists for this edge in the neighborhood):
        *   Connect the dual nodes in the input cells that are related to this minimal edge [S1].
        *   If the case is **uniform** (4 distinct cells), form a **quad** patch [S1].
        *   If the case is **adaptive** (3 distinct cells, one repeated), form a **triangle** patch [S1].

**Pseudocode:**

```python
def CellProc(cell):
    # 1. Recurse into sub-cells
    for sub_cell in cell.children:
        CellProc(sub_cell)
    
    # 2. Process faces between adjacent sub-cells
    # There are 12 pairs of face-adjacent sub-cells in an octant
    for pair in get_face_adjacent_sub_cell_pairs(cell):
        FaceProc(pair[0], pair[1])
        
    # 3. Process edges shared by all 4 sub-cells
    # There are 6 edges in a cube, each shared by 4 sub-cells
    for edge in cell.edges:
        sub_cells_sharing_edge = get_sub_cells_sharing_edge(cell, edge)
        EdgeProc(sub_cells_sharing_edge[0], sub_cells_sharing_edge[1], 
                 sub_cells_sharing_edge[2], sub_cells_sharing_edge[3])

def FaceProc(cell_a, cell_b):
    # cell_a and cell_b share a common face f
    
    # 1. Recurse into face-adjacent sub-cell pairs within f
    # There are 4 such pairs
    for pair in get_face_adjacent_sub_cell_pairs_across_face(cell_a, cell_b):
        FaceProc(pair[0], pair[1])
        
    # 2. Process edges contained within f shared by 4 sub-cells
    # There are 4 such edges
    for edge in cell_a.face_edges: # Edges of the shared face
        sub_cells_sharing_edge = get_sub_cells_sharing_edge_across_face(cell_a, cell_b, edge)
        EdgeProc(sub_cells_sharing_edge[0], sub_cells_sharing_edge[1], 
                 sub_cells_sharing_edge[2], sub_cells_sharing_edge[3])

def EdgeProc(c1, c2, c3, c4):
    # c1, c2, c3, c4 are edge-adjacent cells
    # In adaptive case, one cell is repeated (e.g., c4 == c3)
    
    # Check if this edge is minimal
    if is_minimal_edge(c1, c2, c3, c4):
        # Generate patch
        dual_nodes = [c1.dual_node, c2.dual_node, c3.dual_node, c4.dual_node]
        
        # Determine if uniform or adaptive
        if is_uniform_case(c1, c2, c3, c4):
            # Uniform: 4 distinct cells -> Quad
            create_quad_patch(dual_nodes)
        else:
            # Adaptive: 3 distinct cells -> Triangle
            # Remove duplicate node
            unique_nodes = get_unique_nodes(dual_nodes)
            create_triangle_patch(unique_nodes)
    else:
        # Recurse to children
        # There are 2 half-edges in the edge shared by these 4 cells
        for half_edge in get_half_edges(c1, c2, c3, c4):
            sub_cells_sharing_half_edge = get_sub_cells_sharing_half_edge(c1, c2, c3, c4, half_edge)
            EdgeProc(sub_cells_sharing_half_edge[0], sub_cells_sharing_half_edge[1], 
                     sub_cells_sharing_half_edge[2], sub_cells_sharing_half_edge[3])

def is_minimal_edge(c1, c2, c3, c4):
    # A minimal edge does not contain any other edge in a neighboring octree cell
    # This implies no child cells exist that further subdivide this specific edge
    # in the immediate neighborhood.
    # [G] Implementation detail: Check if any of the cells have children 
    # that share this edge. If none do, it is minimal.
    for cell in [c1, c2, c3, c4]:
        if cell.has_children_sharing_edge():
            return False
    return True

def is_uniform_case(c1, c2, c3, c4):
    # Returns true if all 4 cells are distinct
    return len({id(c1), id(c2), id(c3), id(c4)}) == 4
```

**Edge Cases and Pitfalls:**
*   **Adaptive Boundary:** In the adaptive case, `EdgeProc` receives one cell repeated. The algorithm must correctly identify the three unique dual nodes to form a triangle [S1].
*   **Minimal Edge Detection:** The definition of a minimal edge relies on the absence of smaller edges in neighboring cells. Failure to correctly identify this leads to incorrect patch generation or gaps [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources. The algorithm is recursive and traverses the octree structure.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Localizes nodes inside cells, providing freedom to place surface nodes close to features of the volume [S1]. Ensures manifold output through the one-to-one relationship with minimal edges [S1].
*   **Limitations:** Requires an octree structure. Performance depends on the depth and adaptivity of the octree [S1].

## Background
The algorithm is based on a method proposed in "Dual Contouring" [4] (referenced in [S1]) and adapted for use with octrees in "Adaptive surface extraction from anisotropic volumetric data: contouring on generalized octrees" by Ricardo Uribe Lobello, Florence Denis, and Florent Dupont [S1]. It is used in dual contouring algorithms to extract the connectivity of the surface by traversing the octree [S1].
