# Dual Contouring 2D (CUDA)

Also called: KDualContour2, cudc2

## Overview
Dual Contouring 2D (CUDA) is a GPU-accelerated implementation of the dual contouring algorithm designed to extract 2D isosurfaces (polygonal meshes) from scalar fields. It solves the problem of generating manifold 2D meshes with sharp feature preservation by constructing a single vertex per grid cell that minimizes a Quadratic Error Function (QEF) derived from intersection points and surface normals. It differs from its sibling [Dual Contouring (2D Grid Implementation)](3764-dual-contouring-2d-grid-implementation.md) by utilizing CUDA parallelism with tiled thread blocks, atomic operations for global indexing, and a parallel prefix sum (scan) for vertex and edge generation, rather than a sequential or CPU-based grid approach.

## How it works
The method processes the scalar field in tiled blocks of grid cells. Each thread block handles a tile of cells, computing intersection points, constructing QEFs, solving for vertex positions, and generating edges.

### Inputs and Outputs
**Inputs:**
- Scalar field function $f(x, y)$ accessible via `Sample2<FT>`.
- Grid bounds: $x \in [xs, xt]$, $y \in [ys, ys + \text{range}]$.
- Grid resolution: $n_x$ points in X, $n_y$ points in Y.
- Isosurface value: $0$ (implicit in the source code checks).
- Parameters: `TILE_WIDTH` = 32, `TILE_HEIGHT` = 32, `BLOCK_SIZE` = 1024, `dh` = $10^{-5}$, `EPS` = $10^{-6}$, `EPS_SVD` = $10^{-1}$.

**Outputs:**
- Vertex buffer: Array of 2D coordinates $(x, y)$.
- Edge buffer: Array of integer pairs $(v_1, v_2)$ referencing vertex indices.
- Index buffers (`ibuffer`) used for connectivity tracking between tiles.

### Data Structures
- **`ibuffer`**: A 2D array of integers with dimensions $(n_x - 1) \times (n_y - 1)$. It stores the global vertex index generated for each cell. It is double-buffered per tile row to handle boundary conditions between adjacent tile rows. Initialized to $-1$.
- **`edges`**: A flat array of integers storing edge connectivity as pairs of vertex indices.
- **`pcnt`**: A global atomic counter tracking the total number of generated vertices.

### Steps

1. **Grid Sampling**:
   Each thread $(tx, ty)$ within a block assigned to cell $(tx, ty)$ computes the scalar values at the four corners of its cell:
   $$
   \begin{aligned}
   x_0 &= xs + tx \cdot x_{step}, & y_0 &= ys + ty \cdot y_{step} \\
   x_1 &= x_0 + x_{step}, & y_1 &= y_0 + y_{step}
   \end{aligned}
   $$
   Values: $s_0 = f(x_0, y_0)$, $s_1 = f(x_1, y_0)$, $s_2 = f(x_0, y_1)$, $s_3 = f(x_1, y_1)$.

2. **Intersection Detection**:
   Count intersections with the isosurface ($0$) along the four edges. An edge intersects if the signs of the corner values differ:
   $$
   \text{IsIntersected}(a, b) = \begin{cases} 1 & \text{if } (a < 0 \land b \ge 0) \lor (a \ge 0 \land b < 0) \\ 0 & \text{otherwise} \end{cases}
   $$
   Total intersections:
   $$
   I = \text{IsIntersected}(s_0, s_1) + \text{IsIntersected}(s_0, s_2) + \text{IsIntersected}(s_2, s_3) + \text{IsIntersected}(s_1, s_3)
   $$
   A cell is active if it has at least 2 intersections.

3. **Global Indexing (Parallel Prefix Sum)**:
   - Compute the number of active cells in the block using `__syncthreads_count`.
   - Use `atomicAdd` on a global counter `pcnt` to get the base offset for the block's vertices.
   - Perform a parallel prefix sum (scan) within the block to assign a local rank to each active cell.
   - The global vertex index for the cell is:
     $$
     v_{idx} = \text{base} + \text{local\_rank} - 1
     $$
   - Store $v_{idx}$ in `ibuffer` for the current cell. If no vertex is generated, store $-1$.

4. **Intersection Point Calculation**:
   For each intersected edge, find the exact intersection point $(x, y)$ using binary search (bisection) between the endpoints with negative and non-negative scalar values. Iterate until $|f(x, y)| < \text{EPS}$ ($10^{-6}$).

5. **Gradient Estimation**:
   Estimate the normalized gradient $\mathbf{n} = (dx, dy)$ at each intersection point using central finite differences with step size $dh = 10^{-5}$:
   $$
   dx = \frac{f(x+dh, y) - f(x-dh, y)}{2 \cdot dh}, \quad dy = \frac{f(x, y+dh) - f(x, y-dh)}{2 \cdot dh}
   $$
   Normalize:
   $$
   \mathbf{n} = \frac{(dx, dy)}{\sqrt{dx^2 + dy^2}}
   $$

6. **QEF Construction**:
   For a cell with $k$ intersected edges, construct the QEF $E(\mathbf{v}) = \|A\mathbf{v} - \mathbf{b}\|^2$.
   - Matrix $A$ is $2 \times k$, where column $i$ is the gradient $\mathbf{n}_i = [dx_i, dy_i]^T$.
   - Vector $\mathbf{b}$ is size $k$, where $b_i = \mathbf{n}_i \cdot \mathbf{p}_i$, and $\mathbf{p}_i$ is the intersection point.
   - Compute the sums:
     $$
     A^T A = \sum_{i=0}^{k-1} \mathbf{n}_i \mathbf{n}_i^T, \quad A^T \mathbf{b} = \sum_{i=0}^{k-1} b_i \mathbf{n}_i
     $$
   - Compute the centroid (mass point) $\mathbf{c}_{mass} = \frac{1}{k} \sum_{i=0}^{k-1} \mathbf{p}_i$.

7. **QEF Solving**:
   Solve for the vertex position $\mathbf{v}$ that minimizes the QEF. The implementation uses a pseudo-inverse method:
   - Let $M = A^T A = \begin{bmatrix} f[0] & f[1] \\ f[1] & f[2] \end{bmatrix}$.
   - Compute $M \mathbf{c}_{mass}$.
   - Compute residual $\mathbf{d} = A^T \mathbf{b} - M \mathbf{c}_{mass}$.
   - Compute the pseudo-inverse $M^+$ using SVD.
   - The solution is $\mathbf{v} = M^+ \mathbf{d} + \mathbf{c}_{mass}$.

8. **SVD Implementation**:
   The $2 \times 2$ SVD of $M$ is computed analytically:
   - $e = 0.5(M_{00} + M_{11})$, $f = 0.5(M_{00} - M_{11})$, $g = 0.5(M_{01} + M_{10})$, $h = 0.5(M_{01} - M_{10})$.
   - Singular values: $S_{0,1} = \sqrt{e^2 + g^2} \pm \sqrt{f^2 + h^2}$.
   - Handle degenerate cases where $S_i < \text{EPS\_SVD}$ ($10^{-1}$) by setting inverse to 0.
   - Construct rotation matrices $U$ and $V^T$ using angles derived from `atan2`.

9. **Edge Generation**:
   After vertices are generated, a second pass (or integrated step) generates edges. For each cell with a vertex:
   - Check neighbors (left, down) in the `ibuffer`.
   - If a neighbor has a valid vertex index, create an edge between the current cell's vertex and the neighbor's vertex.
   - Use parallel prefix sums to determine the global edge index.

### Pseudocode

```python
# CUDA Kernel: KDualContour2
# Grid: (num_tiles_x, 1), Block: (TILE_WIDTH, TILE_HEIGHT)
def KDualContour2(xs, xt, n_x, ys, ys_end, n_y, pd, pcap, pcntd, ibuffer, edges, ecnt):
    tx = blockIdx.x * TILE_WIDTH + threadIdx.x
    ty = threadIdx.y
    ti = threadIdx.y * TILE_WIDTH + threadIdx.x
    
    # Check if thread is within valid cell range
    active = (tx < n_x - 1) and (ty < n_y - 1)
    
    if not active:
        return

    # 1. Grid Sampling
    x0 = xs + tx * (xt - xs) / (n_x - 1)
    y0 = ys + ty * (ys_end - ys) / (n_y - 1)
    x1 = x0 + (xt - xs) / (n_x - 1)
    y1 = y0 + (ys_end - ys) / (n_y - 1)
    
    s0 = Sample2(x0, y0)
    s1 = Sample2(x1, y0)
    s2 = Sample2(x0, y1)
    s3 = Sample2(x1, y1)
    
    # 2. Intersection Detection
    def IsIntersected(a, b):
        return 1 if (a < 0 and b >= 0) or (a >= 0 and b < 0) else 0
        
    intersections = (IsIntersected(s0, s1) + IsIntersected(s0, s2) + 
                     IsIntersected(s2, s3) + IsIntersected(s1, s3))
    
    pred = active and (intersections >= 2)
    
    # 3. Global Indexing (Parallel Prefix Sum)
    # Count active threads in block
    total_active = __syncthreads_count(pred)
    
    # Get base offset for this block
    base = 0
    if (threadIdx.x == 0 and threadIdx.y == 0):
        base = atomicAdd(pcntd, total_active)
        
    # Shared memory for scan
    s = shared_memory_array(BLOCK_SIZE)
    s[ti] = 1 if pred else 0
    
    __syncthreads()
    
    # Up-sweep (Reduction)
    for stride in [1, 2, 4, 8, 16, 32, 64, 128, 256, 512]:
        if stride <= BLOCK_SIZE / 2:
            index = (ti + 1) * stride * 2 - 1
            if index < BLOCK_SIZE:
                s[index] += s[index - stride]
        __syncthreads()
        
    # Down-sweep (Scan)
    for stride in [512, 256, 128, 64, 32, 16, 8, 4, 2, 1]:
        if stride > 0:
            index = (ti + 1) * stride * 2 - 1
            if index + stride < BLOCK_SIZE:
                s[index + stride] += s[index]
        __syncthreads()
        
    # Compute global vertex index
    pi = base + s[ti] - 1
    
    # Store index in ibuffer
    which = tileY % 2
    ibuffer_stride = (n_x - 1) * TILE_HEIGHT
    bi = which * ibuffer_stride + ty * (n_x - 1) + tx
    
    if active:
        ibuffer[bi] = pi if pred else -1
        
    # 4. Generate Vertex if Active
    if pred:
        k = 0
        cx, cy = 0.0, 0.0
        A = [0.0] * 8  # 2x4 max intersections
        b = [0.0] * 4
        
        # Process edges
        edges_list = [(s0, s1, x0, y0, x1, y0), (s0, s2, x0, y0, x0, y1), 
                      (s2, s3, x0, y1, x1, y1), (s1, s3, x1, y0, x1, y1)]
                      
        for i, (sa, sb, xa, ya, xb, yb) in enumerate(edges_list):
            if IsIntersected(sa, sb):
                # Binary search for intersection
                xlow, ylow = (xa, ya) if sa < sb else (xb, yb)
                xhigh, yhigh = (xb, yb) if sa < sb else (xa, ya)
                
                x, y = SolveIntersection2(xlow, ylow, xhigh, yhigh)
                
                # Gradient estimation
                dx, dy = SampleGradient2(x, y)
                
                A[2*k] = dx
                A[2*k+1] = dy
                cx += x
                cy += y
                b[k] = dx * x + dy * y
                k += 1
                
        # QEF Construction
        f = [0.0] * 7
        f[0] = A[0]**2 + A[2]**2 + A[4]**2 + A[6]**2
        f[1] = A[0]*A[1] + A[2]*A[3] + A[4]*A[5] + A[6]*A[7]
        f[2] = A[1]**2 + A[3]**2 + A[5]**2 + A[7]**2
        f[3] = A[0]*b[0] + A[2]*b[1] + A[4]*b[2] + A[6]*b[3]
        f[4] = A[1]*b[0] + A[3]*b[1] + A[5]*b[2] + A[7]*b[3]
        f[5] = cx / k
        f[6] = cy / k
        
        # QEF Solving
        ATA = [f[0], f[1], f[1], f[2]]
        pinv = PseudoInverse2(ATA)
        
        ATAg = [ATA[0]*f[5] + ATA[1]*f[6], ATA[2]*f[5] + ATA[3]*f[6]]
        d = [f[3] - ATAg[0], f[4] - ATAg[1]]
        
        c = [pinv[0]*d[0] + pinv[1]*d[1], pinv[2]*d[0] + pinv[3]*d[1]]
        px = c[0] + f[5]
        py = c[1] + f[6]
        
        # Store vertex (pd is pointer to vertex buffer, pcap is pointer to count)
        # Note: In actual CUDA, this would be atomicAdd to pcap and write to pd
        vertex_idx = atomicAdd(pcap, 1)
        pd[vertex_idx * 2] = px
        pd[vertex_idx * 2 + 1] = py

# Helper: PseudoInverse2 using SVD
def PseudoInverse2(M):
    # M is [m00, m01, m10, m11]
    e = 0.5 * (M[0] + M[3])
    f = 0.5 * (M[0] - M[3])
    g = 0.5 * (M[1] + M[2])
    h = 0.5 * (M[1] - M[2])
    
    r1 = sqrt(e*e + g*g)
    r2 = sqrt(f*f + h*h)
    
    S0 = r1 + r2
    S1 = r1 - r2
    
    # Handle singular values
    if S0 < EPS_SVD: S0 = 1e-10 # Avoid div by zero, treat as zero inverse
    if S1 < EPS_SVD: S1 = 1e-10
    
    invS0 = 1.0 / S0
    invS1 = 1.0 / S1
    
    # Compute angles
    theta = atan2(g, f) if (f != 0 or g != 0) else 0.0
    phi = atan2(h, r2) if (r2 != 0) else 0.0
    
    # Construct U and V^T (simplified for 2x2 symmetric M)
    # For symmetric M, U = V. 
    # This is a simplified analytical SVD reconstruction for the pseudo-inverse
    # The source code constructs U and VT explicitly. 
    # Here we return the pseudo-inverse matrix directly.
    
    # Reconstruct M^+ = V * diag(1/S) * U^T
    # Given the complexity of full SVD reconstruction in pseudocode, 
    # we assume PseudoInverse2 returns the 2x2 inverse matrix.
    
    # Actual implementation from source:
    # Computes U, VT, then pinv = VT^T * diag(1/S) * U^T
    # For brevity, we state the result is the pseudo-inverse.
    
    # To be fully implementable, we must provide the matrix math:
    cos_theta = cos(theta)
    sin_theta = sin(theta)
    cos_phi = cos(phi)
    sin_phi = sin(phi)
    
    # U matrix
    U00 = cos_theta * cos_phi - sin_theta * sin_phi
    U01 = -cos_theta * sin_phi - sin_theta * cos_phi
    U10 = sin_theta * cos_phi + cos_theta * sin_phi
    U11 = -sin_theta * sin_phi + cos_theta * cos_phi
    
    # V^T is same as U^T for symmetric M
    # M^+ = U * diag(1/S) * U^T
    pinv00 = U00*U00*invS0 + U01*U01*invS1
    pinv01 = U00*U10*invS0 + U01*U11*invS1
    pinv10 = U10*U00*invS0 + U11*U01*invS1
    pinv11 = U10*U10*invS0 + U11*U11*invS1
    
    return [pinv00, pinv01, pinv10, pinv11]
```

### Edge Cases and Pitfalls
- **Singular Value Zero**: If a singular value $S_i < \text{EPS\_SVD}$ ($10^{-1}$), the inverse is set to 0.0 to prevent division by zero. This occurs when the QEF is degenerate (e.g., all gradients are parallel or zero).
- **Atan2 Domain**: If both arguments to `atan2` are 0.0, it returns 0.0 to handle isotropic or zero matrices.
- **Boundary Conditions**: Cells on the grid boundary may have fewer than 4 edges. The code checks `active` status to avoid out-of-bounds sampling.
- **Tile Boundaries**: The `ibuffer` is double-buffered to handle vertex sharing between adjacent tile rows. The `which` variable determines which buffer is read/written.

## Operating characteristics
- **Time Complexity**: $O(N)$ where $N$ is the number of grid cells, as each cell is processed by one thread. The prefix sum adds a logarithmic factor per block, but is efficient on GPU.
- **Memory Complexity**: $O(N)$ for vertex and edge buffers, plus $O(\text{tile size})$ for shared memory and temporary buffers.
- **Performance**: Optimized for CUDA GPUs with 1024 threads per block. Performance scales with the number of SMs and memory bandwidth.
- **Strengths**: Parallel processing, sharp feature preservation via QEF, efficient memory access patterns with tiled processing.
- **Limitations**: Limited to 2D, requires careful handling of boundary conditions between tiles, numerical stability depends on SVD implementation.

## Background
Dual Contouring 2D (CUDA) was developed as a final project for CS 217 (GPU Architecture and Programming) at the University of California, Riverside, in Fall 2015. It was made public in December 2015. The project aims to provide a GPU-accelerated alternative to CPU-based dual contouring implementations, leveraging CUDA's parallel architecture for real-time or high-performance 2D isosurface extraction.
