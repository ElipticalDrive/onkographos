# Dual Contouring Edge Normal Calculation

Also called: Dual Contouring Edge Normal, Edge Normal Calculation via Vertex Gradient Averaging

## Overview
This method computes the surface normal for a grid edge intersected by an isosurface by averaging the normals of the two vertices defining the edge [S2, unofficial].

## How it works
**Inputs:**
- Two 3D grid vertices $p_0$ and $p_1$ defining the edge [S1, S2, unofficial].
- A scalar density function $d(x, y, z)$ returning values for grid coordinates [S1, S2, unofficial].
- The isovalue $isoLevel$ [S1, S2, unofficial].

**Outputs:**
- A 3D normal vector $\mathbf{n}_{edge}$ for the intersection point on the edge [S2, unofficial].

**Data Structures:**
- `data`: A 3D vector or tuple storing $(d(p_0), d(p_1), isoLevel)$ [S1, S2, unofficial].

**Steps:**
1. **Sample Edge Densities:** Retrieve $d_0 = d(p_0)$ and $d_1 = d(p_1)$, then store them with $isoLevel$ as `data = (d_0, d_1, isoLevel)` [S1, S2, unofficial].
2. **Calculate Vertex Gradient at $p_0$:** Compute $\mathbf{n}_0$ using forward differences of $d$: $\mathbf{n}_0 = (d(p_0.x+1, p_0.y, p_0.z) - d_0, \ d(p_0.x, p_0.y+1, p_0.z) - d_0, \ d(p_0.x, p_0.y, p_0.z+1) - d_0)$ [S1, S2, unofficial].
3. **Calculate Vertex Gradient at $p_1$:** Compute $\mathbf{n}_1$ similarly: $\mathbf{n}_1 = (d(p_1.x+1, p_1.y, p_1.z) - d_1, \ d(p_1.x, p_1.y+1, p_1.z) - d_1, \ d(p_1.x, p_1.y, p_1.z+1) - d_1)$ [S1, S2, unofficial].
4. **Interpolate Edge Normal:** Interpolate between $\mathbf{n}_0$ and $\mathbf{n}_1$ using the edge density data: $\mathbf{n}_{edge} = \text{LerpByDensity}(\mathbf{n}_0, \mathbf{n}_1, \text{data})$ [S2, unofficial].

**Pseudocode:**
```python
def calculate_edge_normal(p0, p1, density_func, iso_level):
    # Step 1: Sample densities at vertices
    d0 = density_func(p0[0], p0[1], p0[2])
    d1 = density_func(p1[0], p1[1], p1[2])
    data = (d0, d1, iso_level)
    
    # Step 2: Calculate gradient at p0 using forward differences
    n0 = (
        density_func(p0[0] + 1, p0[1], p0[2]) - d0,
        density_func(p0[0], p0[1] + 1, p0[2]) - d0,
        density_func(p0[0], p0[1], p0[2] + 1) - d0
    )
    
    # Step 3: Calculate gradient at p1 using forward differences
    n1 = (
        density_func(p1[0] + 1, p1[1], p1[2]) - d1,
        density_func(p1[0], p1[1] + 1, p1[2]) - d1,
        density_func(p1[0], p1[1], p1[2] + 1) - d1
    )
    
    # Step 4: Interpolate edge normal
    # LerpByDensity is not defined in the sources; standard linear interpolation 
    # weighted by distance to the isovalue is used [G]
    t = (iso_level - d0) / (d1 - d0) if d1 != d0 else 0.5
    n_edge = (
        (1 - t) * n0[0] + t * n1[0],
        (1 - t) * n0[1] + t * n1[1],
        (1 - t) * n0[2] + t * n1[2]
    )
    return n_edge
```

**Edge Cases and Pitfalls:**
- Interpolating normals may result in incorrect normals; advice suggests calculating per-face normals instead, though this requires triangle generation first [S1, S2, unofficial].
- Forward differences assume unit grid spacing; non-unit spacing requires scaling [G].
- Boundary vertices lack forward neighbors; out-of-bounds access must be handled [G].

## Operating characteristics
- Time and memory complexity: Not given in the sources.
- Strengths and limitations: The method is straightforward but interpolating vertex gradients for edge normals may produce incorrect results [S1, S2, unofficial].
