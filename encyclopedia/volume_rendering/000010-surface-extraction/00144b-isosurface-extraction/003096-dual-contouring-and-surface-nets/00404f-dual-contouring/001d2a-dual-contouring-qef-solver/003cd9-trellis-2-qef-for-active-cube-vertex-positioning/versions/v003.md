# TRELLIS.2 QEF for Active Cube Vertex Positioning

Also called: TRELLIS.2 preprocessing QEF

## Overview
TRELLIS.2 QEF is a vertex positioning method used in the preprocessing stage of the TRELLIS.2 framework [S1]. It solves the problem of determining the optimal position for dual vertices within active cubes identified by intersecting an input mesh, enabling the subsequent extraction of high-quality meshes via Dual Contouring [S1]. It distinguishes itself from standard Dual Contouring QEF solvers by explicitly incorporating boundary edge constraints and regularization terms to handle sharp features and intricate internal structures [S1].

## How it works
**Inputs:**
*   An input ground-truth (GT) mesh [S1].
*   A grid of cubes (voxels) covering the domain [G].
*   Parameters: $\lambda_{\text{bound}}$ (boundary weight), $\lambda_{\text{reg}}$ (regularization weight) [S1].

**Outputs:**
*   A set of active cubes [S1].
*   For each active cube, an edge intersection flag vector $\in \{0, 1\}^3$ indicating surface intersections along the $x, y, z$ axes [S1].
*   For each active cube, a dual vertex position $v$ computed by minimizing the QEF [S1].

**Data Structures:**
*   **Active Cube:** A cube in the grid where at least one edge intersects the input mesh [S1].
*   **Edge Intersection Flag:** A 3-bit integer or boolean vector $(f_x, f_y, f_z)$, where $f_k=1$ if the cube has a surface intersection along axis $k$, and $0$ otherwise [S1].
*   **Intersection Data:** For each intersection point $\mathbf{p}_i$ on the cube boundary, store the surface normal $\mathbf{n}_i$ [G].
*   **Boundary Edge Data:** For each boundary edge of the cube that intersects the mesh, store the edge origin $\mathbf{o}_j$ and direction $\mathbf{d}_j$ [G].

**Algorithm Steps:**

1.  **Identify Active Cubes:** Iterate over all cubes in the grid. For each cube, detect intersections between its edges and the input mesh. If any intersection is found, mark the cube as active [S1].
2.  **Assign Edge Intersection Flags:** For each active cube, determine the presence of surface intersections along the three principal axes ($x, y, z$). Assign a flag vector $\in \{0, 1\}^3$ to the cube [S1].
3.  **Compute Dual Vertex Position:** For each active cube, solve for the dual vertex position $v$ by minimizing the following Quadric Error Function (QEF) [S1]:

    $$
    \min_{v \in \text{voxel}} e(v) = \sum_i d_{\text{II},i}^2 + \lambda_{\text{bound}} \sum_j d_{L,j}^2 + \lambda_{\text{reg}} d_q^2
    $$

    Where:
    *   $v$ is the dual vertex position.
    *   The first term is the **plane alignment error**:
        $$
        d_{\text{II},i}^2 = (\mathbf{n}_i \cdot (v - \mathbf{p}_i))^2
        $$
        Here, $\mathbf{p}_i$ is the intersection point on the cube boundary, and $\mathbf{n}_i$ is the surface normal at $\mathbf{p}_i$ [S1].
    *   The second term is the **boundary constraint**:
        $$
        d_{L,j}^2 = \| (v - \mathbf{o}_j) - ((v - \mathbf{o}_j) \cdot \mathbf{d}_j)\mathbf{d}_j \|^2
        $$
        Here, $\mathbf{o}_j$ is the origin and $\mathbf{d}_j$ is the direction of the $j$-th boundary edge [S1].
    *   The third term is the **regularization term**:
        $$
        d_q^2 = \| v - \bar{v} \|^2
        $$
        Here, $\bar{v}$ is the centroid (or mass point) of the intersection points $\{\mathbf{p}_i\}$ [S1].

    The minimization yields the optimal $v$ for the active cube [S1].

**Pitfalls:**
*   **Floating-Point Precision:** The determination of edge intersection flags is susceptible to floating-point precision errors inherent in ray-intersection tests, which may lead to erroneous intersection judgments [S1].

**Pseudocode:**

```python
import math

def trellis2_qef_vertex_positioning(input_mesh_triangles, grid_cubes, lambda_bound, lambda_reg):
    """
    Computes active cubes, flags, and dual vertices using TRELLIS.2 QEF.
    
    Args:
        input_mesh_triangles: List of triangles, each defined by 3 vertices (p0, p1, p2).
        grid_cubes: List of cube objects with attributes: center (x,y,z), size (float), 
                    edges (list of 12 segments, each (p1, p2)), id.
        lambda_bound: Weight for boundary constraint.
        lambda_reg: Weight for regularization term.
        
    Returns:
        active_cubes: List of active cube objects.
        flags: Dictionary mapping cube_id to (f_x, f_y, f_z) flag vector.
        vertices: Dictionary mapping cube_id to dual vertex position v.
    """
    active_cubes = []
    flags = {}
    vertices = {}

    def ray_triangle_intersect(ray_o, ray_d, tri):
        """[G] Möller–Trumbore ray-triangle intersection."""
        v0, v1, v2 = tri
        e1 = (v1[0]-v0[0], v1[1]-v0[1], v1[2]-v0[2])
        e2 = (v2[0]-v0[0], v2[1]-v0[1], v2[2]-v0[2])
        h = (ray_d[1]*e2[2]-ray_d[2]*e2[1], ray_d[2]*e2[0]-ray_d[0]*e2[2], ray_d[0]*e2[1]-ray_d[1]*e2[0])
        a = e1[0]*h[0] + e1[1]*h[1] + e1[2]*h[2]
        if a < 1e-9: return None
        f = 1.0/a
        s = (ray_o[0]-v0[0], ray_o[1]-v0[1], ray_o[2]-v0[2])
        u = f * (s[0]*h[0] + s[1]*h[1] + s[2]*h[2])
        if u < 0.0 or u > 1.0: return None
        q = (s[1]*e2[2]-s[2]*e2[1], s[2]*e2[0]-s[0]*e2[2], s[0]*e2[1]-s[1]*e2[0])
        v = f * (ray_d[0]*q[0] + ray_d[1]*q[1] + ray_d[2]*q[2])
        if v < 0.0 or u + v > 1.0: return None
        t = f * (e2[0]*q[0] + e2[1]*q[1] + e2[2]*q[2])
        if t < 1e-9: return None
        hit = (ray_o[0]+t*ray_d[0], ray_o[1]+t*ray_d[1], ray_o[2]+t*ray_d[2])
        n = (e1[1]*e2[2]-e1[2]*e2[1], e1[2]*e2[0]-e1[0]*e2[2], e1[0]*e2[1]-e1[1]*e2[0])
        len_n = math.sqrt(n[0]**2+n[1]**2+n[2]**2)
        if len_n > 1e-9: n = (n[0]/len_n, n[1]/len_n, n[2]/len_n)
        return hit, n

    for cube in grid_cubes:
        intersections = []
        has_intersection = False
        edge_flags = [False, False, False] # x, y, z

        # Step 1 & 2: Identify active cubes and assign flags
        for edge in cube.edges:
            ray_o = edge[0]
            ray_d = (edge[1][0]-edge[0][0], edge[1][1]-edge[0][1], edge[1][2]-edge[0][2])
            len_d = math.sqrt(ray_d[0]**2+ray_d[1]**2+ray_d[2]**2)
            if len_d > 1e-9: ray_d = (ray_d[0]/len_d, ray_d[1]/len_d, ray_d[2]/len_d)
            
            for tri in input_mesh_triangles:
                result = ray_triangle_intersect(ray_o, ray_d, tri)
                if result:
                    has_intersection = True
                    intersections.append(result)
                    if abs(ray_d[0]) > 0.9: edge_flags[0] = True
                    elif abs(ray_d[1]) > 0.9: edge_flags[1] = True
                    else: edge_flags[2] = True
                    break 

        if not has_intersection:
            continue

        active_cubes.append(cube)
        flags[cube.id] = (int(edge_flags[0]), int(edge_flags[1]), int(edge_flags[2]))

        # Step 3: Compute dual vertex position
        boundary_edges = []
        for edge in cube.edges:
            ray_o = edge[0]
            ray_d = (edge[1][0]-edge[0][0], edge[1][1]-edge[0][1], edge[1][2]-edge[0][2])
            len_d = math.sqrt(ray_d[0]**2+ray_d[1]**2+ray_d[2]**2)
            if len_d > 1e-9:
                ray_d = (ray_d[0]/len_d, ray_d[1]/len_d, ray_d[2]/len_d)
                boundary_edges.append((ray_o, ray_d))

        # Centroid for regularization
        if intersections:
            points = [p for p, n in intersections]
            centroid = (sum(p[0] for p in points)/len(points),
                        sum(p[1] for p in points)/len(points),
                        sum(p[2] for p in points)/len(points))
        else:
            centroid = cube.center

        # Build least squares system: min ||A v - b||^2
        A = []
        b = []

        # Term 1: Plane alignment
        for p, n in intersections:
            A.append(n)
            b.append(n[0]*p[0] + n[1]*p[1] + n[2]*p[2])

        # Term 2: Boundary constraint
        sqrt_lb = math.sqrt(lambda_bound)
        for o, d in boundary_edges:
            M00 = 1 - d[0]*d[0]; M01 = -d[0]*d[1]; M02 = -d[0]*d[2]
            M10 = -d[1]*d[0]; M11 = 1 - d[1]*d[1]; M12 = -d[1]*d[2]
            M20 = -d[2]*d[0]; M21 = -d[2]*d[1]; M22 = 1 - d[2]*d[2]
            A.append((sqrt_lb*M00, sqrt_lb*M01, sqrt_lb*M02))
            A.append((sqrt_lb*M10, sqrt_lb*M11, sqrt_lb*M12))
            A.append((sqrt_lb*M20, sqrt_lb*M21, sqrt_lb*M22))
            mo = (M00*o[0] + M01*o[1] + M02*o[2],
                  M10*o[0] + M11*o[1] + M12*o[2],
                  M20*o[0] + M21*o[1] + M22*o[2])
            b.append(sqrt_lb*mo[0])
            b.append(sqrt_lb*mo[1])
            b.append(sqrt_lb*mo[2])

        # Term 3: Regularization
        sqrt_lr = math.sqrt(lambda_reg)
        A.append((sqrt_lr, 0.0, 0.0))
        A.append((0.0, sqrt_lr, 0.0))
        A.append((0.0, 0.0, sqrt_lr))
        b.append(sqrt_lr * centroid[0])
        b.append(sqrt_lr * centroid[1])
        b.append(sqrt_lr * centroid[2])

        # Solve 3x3 normal equations: (A^T A) v = A^T b
        n = 3
        ATA = [[sum(A[i][k]*A[i][j] for i in range(len(A))) for j in range(n)] for k in range(n)]
        ATb = [sum(A[i][k]*b[i] for i in range(len(A))) for k in range(n)]
        aug = [ATA[i] + [ATb[i]] for i in range(n)]
        for i in range(n):
            pivot = aug[i][i]
            for j in range(i+1, n):
                if abs(aug[j][i]) > abs(aug[i][i]):
                    aug[i], aug[j] = aug[j], aug[i]
            if abs(aug[i][i]) < 1e-12:
                v = [0.0, 0.0, 0.0]
                break
            for j in range(i+1, n):
                factor = aug[j][i] / aug[i][i]
                for k in range(i, n+1):
                    aug[j][k] -= factor * aug[i][k]
        else:
            v = [0.0, 0.0, 0.0]
            for i in range(n-1, -1, -1):
                v[i] = (aug[i][n] - sum(aug[i][j]*v[j] for j in range(i+1, n))) / aug[i][i]

        vertices[cube.id] = v

    return active_cubes, flags, vertices
```

## Background
TRELLIS.2 was introduced by Xiang et al. in 2025 [S1]. It is part of a framework for 3D AIGC data preprocessing [S1]. The method is used in the data preprocessing stage to generate active cubes and their associated geometric attributes conditioned on input images, which are then used to train a Sparse Voxel Diffusion Transformer [S1]. The 3D mesh is extracted using Dual Contouring after this preprocessing step [S1].
