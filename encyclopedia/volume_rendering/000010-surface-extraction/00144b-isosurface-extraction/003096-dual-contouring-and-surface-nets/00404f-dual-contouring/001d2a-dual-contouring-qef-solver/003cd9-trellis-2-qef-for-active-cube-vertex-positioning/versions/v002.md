# TRELLIS.2 QEF for Active Cube Vertex Positioning

Also called: TRELLIS.2 preprocessing QEF

## Overview
TRELLIS.2 QEF is a vertex positioning method used in the preprocessing stage of the TRELLIS.2 framework [S1]. It solves the problem of determining the optimal position for dual vertices within active cubes identified by intersecting an input mesh, enabling the subsequent extraction of high-quality meshes via Dual Contouring [S1]. It distinguishes itself from standard Dual Contouring QEF solvers by explicitly incorporating boundary edge constraints and regularization terms to handle sharp features and intricate internal structures [S1].

## How it works
**Inputs:**
*   An input ground-truth (GT) mesh [S1].
*   A grid of cubes (voxels) covering the domain [G].
*   Parameters: $\lambda_{\text{bound}}$ (boundary weight), $\lambda_{\text{reg}}$ (regularization weight) [S1].

**Outputs:**
*   A set of active cubes [S1].
*   For each active cube, an edge intersection flag vector $\in \{0, 1\}^3$ indicating surface intersections along the $x, y, z$ axes [S1].
*   For each active cube, a dual vertex position $v$ computed by minimizing the QEF [S1].

**Data Structures:**
*   **Active Cube:** A cube in the grid where at least one edge intersects the input mesh [S1].
*   **Edge Intersection Flag:** A 3-bit integer or boolean vector $(f_x, f_y, f_z)$, where $f_k=1$ if the cube has a surface intersection along axis $k$, and $0$ otherwise [S1].
*   **Intersection Data:** For each intersection point $\mathbf{p}_i$ on the cube boundary, store the surface normal $\mathbf{n}_i$ [G].
*   **Boundary Edge Data:** For each boundary edge of the cube that intersects the mesh, store the edge origin $\mathbf{o}_j$ and direction $\mathbf{d}_j$ [G].

**Algorithm Steps:**

1.  **Identify Active Cubes:** Iterate over all cubes in the grid. For each cube, detect intersections between its 12 edges and the input mesh. If any intersection is found, mark the cube as active [S1].
2.  **Assign Edge Intersection Flags:** For each active cube, determine the presence of surface intersections along the three principal axes ($x, y, z$). Assign a flag vector $\in \{0, 1\}^3$ to the cube. This flag indicates which axes have intersections, facilitating subsequent mesh polygonization [S1].
3.  **Compute Dual Vertex Position:** For each active cube, solve for the dual vertex position $v$ by minimizing the following Quadric Error Function (QEF) [S1]:

    $$
    \min_{v \in \text{voxel}} e(v) = \sum_i d_{\text{II},i}^2 + \lambda_{\text{bound}} \sum_j d_{L,j}^2 + \lambda_{\text{reg}} d_q^2
    $$

    Where:
    *   $v$ is the dual vertex position.
    *   The first term is the **plane alignment error**:
        $$
        d_{\text{II},i}^2 = (\mathbf{n}_i \cdot (v - \mathbf{p}_i))^2
        $$
        Here, $\mathbf{p}_i$ is the intersection point on the cube boundary, and $\mathbf{n}_i$ is the surface normal at $\mathbf{p}_i$. This term measures the squared distance from $v$ to the tangent plane defined by $\mathbf{p}_i$ and $\mathbf{n}_i$ [S1].
    *   The second term is the **boundary constraint**:
        $$
        d_{L,j}^2 = \| (v - \mathbf{o}_j) - ((v - \mathbf{o}_j) \cdot \mathbf{d}_j)\mathbf{d}_j \|^2
        $$
        Here, $\mathbf{o}_j$ is the origin and $\mathbf{d}_j$ is the direction of the $j$-th boundary edge. This term measures the squared distance from $v$ to the $j$-th boundary edge. It is weighted by $\lambda_{\text{bound}}$ [S1].
    *   The third term is the **regularization term**:
        $$
        d_q^2 = \| v - \bar{v} \|^2
        $$
        Here, $\bar{v}$ is the centroid (or mass point) of the intersection points $\{\mathbf{p}_i\}$ [S1]. This term penalizes deviation from the centroid and is weighted by $\lambda_{\text{reg}}$ [S1].

    The minimization yields the optimal $v$ for the active cube [S1].

**Pitfalls:**
*   **Floating-Point Precision:** The determination of edge intersection flags is susceptible to floating-point precision errors inherent in ray-intersection tests. This may lead to erroneous intersection judgments, affecting the correctness of the active cube identification and flag assignment [S1].

**Pseudocode:**

```python
import math

def trellis2_qef_vertex_positioning(input_mesh, grid_cubes, lambda_bound, lambda_reg):
    """
    Computes active cubes, flags, and dual vertices using TRELLIS.2 QEF.
    
    Args:
        input_mesh: Object representing the input GT mesh.
        grid_cubes: List of cube objects, each with properties:
                    - center: (x, y, z)
                    - size: float (edge length)
                    - edges: List of 12 edge segments (each defined by two endpoints)
        lambda_bound: Weight for boundary constraint.
        lambda_reg: Weight for regularization term.
        
    Returns:
        active_cubes: List of active cube objects.
        flags: Dictionary mapping cube_id to (f_x, f_y, f_z) flag vector.
        vertices: Dictionary mapping cube_id to dual vertex position v.
    """
    active_cubes = []
    flags = {}
    vertices = {}
    
    for cube in grid_cubes:
        intersections = []
        has_intersection = False
        
        # Step 1: Identify Active Cubes
        for edge in cube.edges:
            # [G] Standard ray-segment intersection test against mesh triangles
            hits = input_mesh.ray_intersect(edge.start, edge.end)
            if hits:
                has_intersection = True
                for hit_point, hit_normal in hits:
                    intersections.append((hit_point, hit_normal))
        
        if not has_intersection:
            continue
            
        active_cubes.append(cube)
        
        # Step 2: Assign Edge Intersection Flags
        flag_x = False
        flag_y = False
        flag_z = False
        
        for hit_point, hit_normal in intersections:
            axis = _get_edge_axis(cube, hit_point)
            if axis == 'x':
                flag_x = True
            elif axis == 'y':
                flag_y = True
            elif axis == 'z':
                flag_z = True
                
        flags[cube.id] = (int(flag_x), int(flag_y), int(flag_z))
        
        # Step 3: Compute Dual Vertex Position via QEF Minimization
        boundary_edges = []
        for edge in cube.edges:
            hits = input_mesh.ray_intersect(edge.start, edge.end)
            if hits:
                origin = edge.start
                direction = (edge.end[0] - edge.start[0], 
                             edge.end[1] - edge.start[1], 
                             edge.end[2] - edge.start[2])
                length = math.sqrt(direction[0]**2 + direction[1]**2 + direction[2]**2)
                if length > 1e-9:
                    direction = (direction[0]/length, direction[1]/length, direction[2]/length)
                boundary_edges.append((origin, direction))
                
        # Compute centroid of intersection points for regularization
        if intersections:
            points = [p for p, n in intersections]
            centroid = (sum(p[0] for p in points)/len(points),
                        sum(p[1] for p in points)/len(points),
                        sum(p[2] for p in points)/len(points))
        else:
            centroid = cube.center
            
        # Solve QEF: min e(v) = sum(d_II^2) + lambda_bound * sum(d_L^2) + lambda_reg * d_q^2
        # Formulate as least squares: min ||A v - b||^2
        A = []
        b = []
        
        # Term 1: Plane alignment error
        for p, n in intersections:
            A.append(n)
            b.append(n[0]*p[0] + n[1]*p[1] + n[2]*p[2])
            
        # Term 2: Boundary constraint
        sqrt_lambda_bound = math.sqrt(lambda_bound)
        for o, d in boundary_edges:
            # M = I - d*d^T
            M00 = 1 - d[0]*d[0]; M01 = -d[0]*d[1]; M02 = -d[0]*d[2]
            M10 = -d[1]*d[0]; M11 = 1 - d[1]*d[1]; M12 = -d[1]*d[2]
            M20 = -d[2]*d[0]; M21 = -d[2]*d[1]; M22 = 1 - d[2]*d[2]
            
            # Add M rows scaled by sqrt(lambda_bound)
            A.append((sqrt_lambda_bound*M00, sqrt_lambda_bound*M01, sqrt_lambda_bound*M02))
            A.append((sqrt_lambda_bound*M10, sqrt_lambda_bound*M11, sqrt_lambda_bound*M12))
            A.append((sqrt_lambda_bound*M20, sqrt_lambda_bound*M21, sqrt_lambda_bound*M22))
            
            mo = (M00*o[0] + M01*o[1] + M02*o[2],
                  M10*o[0] + M11*o[1] + M12*o[2],
                  M20*o[0] + M21*o[1] + M22*o[2])
            b.append(sqrt_lambda_bound*mo[0])
            b.append(sqrt_lambda_bound*mo[1])
            b.append(sqrt_lambda_bound*mo[2])
            
        # Term 3: Regularization
        sqrt_lambda_reg = math.sqrt(lambda_reg)
        A.append((sqrt_lambda_reg, 0.0, 0.0))
        A.append((0.0, sqrt_lambda_reg, 0.0))
        A.append((0.0, 0.0, sqrt_lambda_reg))
        b.append(sqrt_lambda_reg * centroid[0])
        b.append(sqrt_lambda_reg * centroid[1])
        b.append(sqrt_lambda_reg * centroid[2])
        
        # Solve least squares: v = (A^T A)^{-1} A^T b
        # [G] Standard linear algebra solver for overdetermined systems
        v = _solve_lstsq(A, b)
        
        vertices[cube.id] = v
        
    return active_cubes, flags, vertices

def _get_edge_axis(cube, point):
    """[G] Determine which axis the intersected edge is parallel to."""
    eps = cube.size * 1e-6
    min_x, max_x = cube.center[0] - cube.size/2, cube.center[0] + cube.size/2
    min_y, max_y = cube.center[1] - cube.size/2, cube.center[1] + cube.size/2
    min_z, max_z = cube.center[2] - cube.size/2, cube.center[2] + cube.size/2
    
    if abs(point[0] - min_x) < eps or abs(point[0] - max_x) < eps:
        return 'x'
    if abs(point[1] - min_y) < eps or abs(point[1] - max_y) < eps:
        return 'y'
    if abs(point[2] - min_z) < eps or abs(point[2] - max_z) < eps:
        return 'z'
    return 'x'  # Fallback

def _solve_lstsq(A, b):
    """[G] Solve min ||Av - b||^2 using normal equations."""
    n = len(A[0])
    # Compute A^T A
    ATA = [[sum(A[i][k]*A[i][j] for i in range(len(A))) for j in range(n)] for k in range(n)]
    # Compute A^T b
    ATb = [sum(A[i][k]*b[i] for i in range(len(A))) for k in range(n)]
    # Solve ATA * v = ATb via Gaussian elimination
    # [G] Standard linear system solver
    v = [0.0, 0.0, 0.0]
    # Simple 3x3 solve for brevity; production code uses LU/Cholesky
    # ... (omitted for brevity, standard implementation)
    return v
```

## Background
TRELLIS.2 was introduced by Xiang et al. in 2025 [S1]. It is part of a framework for 3D AIGC (Artificial Intelligence Generated Content) data preprocessing [S1]. The method is used in the data preprocessing stage to generate active cubes and their associated geometric attributes conditioned on input images, which are then used to train a Sparse Voxel Diffusion Transformer [S1]. The 3D mesh is extracted using Dual Contouring after this preprocessing step [S1].
