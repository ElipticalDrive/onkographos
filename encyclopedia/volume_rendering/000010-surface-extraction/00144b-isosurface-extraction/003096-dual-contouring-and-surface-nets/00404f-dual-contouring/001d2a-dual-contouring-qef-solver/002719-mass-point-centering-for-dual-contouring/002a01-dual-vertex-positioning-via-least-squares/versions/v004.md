# Dual Vertex Positioning via Least Squares

Also called: Dual Vertex Localization via Quadratic Error Minimization, Ju et al. 2002 Method, Least Squares Dual Vertex, Minimizing Distance to Intersections, Quadratic Error Function (QEF) Vertex Placement

## Overview
This method computes the position of a dual vertex within a voxel cell by minimizing the squared Euclidean distance to all edge intersection points on the isosurface boundary of that cell [S1, unofficial]. It solves the problem of accurately placing a representative point for the isosurface within a grid cell when multiple edges are intersected. It sets itself apart from simpler centroid-based methods by incorporating surface normals to constrain the vertex to the local tangent plane of the implicit function, and from full dual contouring QEF solvers by often being paired with mass point centering to improve numerical stability [S1, unofficial].

## How it works
**Inputs:**
*   A voxel cell $V$ intercepted by the isosurface $\partial V$.
*   Scalar field values at voxel corners.
*   A method to compute normals (specifically the Prewitt operator as described in the source).

**Outputs:**
*   The position $x$ of the dual vertex.

**Data Structures:**
*   $p_i$: Coordinate of the $i$-th edge intersection point.
*   $n_i$: Normal vector at the $i$-th intersection point.
*   $A$: An $n \times 3$ matrix where each row $i$ is the normal vector $n_i^T$.
*   $b$: An $n$-dimensional vector where each element $i$ is the scalar value $n_i \cdot p_i$.
*   $p$: The center of mass (mean) of all intersection coordinates $p_i$.
*   $c$: The correction vector.

**Steps:**

1.  **Identify Intersections and Compute Normals:**
    For each edge of the cell intercepted by the isosurface $\partial V$:
    a.  Identify the two transition voxels (adjacent voxels with different signs of the scalar field) belonging to that edge.
    b.  Calculate the intersection point $p_i$ using linear interpolation between the two transition voxels based on their coordinates and scalar values.
    c.  Calculate the normal $n_i$ at $p_i$ by applying the Prewitt operator. The Prewitt operator is a difference operator that approximates the gradient by convolving $3 \times 3 \times 3$ masks with the volume data [S1, unofficial].

2.  **Construct the Linear System:**
    Assemble the matrix $A$ and vector $b$ from the collected intersection points and normals:
    $$A = \begin{bmatrix} n_1^T \\ n_2^T \\ \vdots \\ n_n^T \end{bmatrix}, \quad b = \begin{bmatrix} n_1 \cdot p_1 \\ n_2 \cdot p_2 \\ \vdots \\ n_n \cdot p_n \end{bmatrix}$$
    where $n$ is the number of intersected edges [S1, unofficial].

3.  **Compute Center of Mass:**
    Calculate the center of mass $p$ of the intersection points:
    $$p = \frac{1}{n} \sum_{i=1}^{n} p_i$$
    [S1, unofficial]

4.  **Solve for Correction Vector $c$:**
    Compute the Moore-Penrose pseudo-inverse $(A^T A)^+$ of the matrix $A^T A$ using Singular Value Decomposition (SVD).
    Calculate the correction vector $c$ using the formula:
    $$c = (A^T A)^+ (A^T b - A^T A p)$$
    [S1, unofficial]

5.  **Compute Final Position:**
    The dual vertex position $x$ is:
    $$x = c + p$$
    [S1, unofficial]

6.  **Boundary Check:**
    If the resulting position $x$ falls outside the spatial bounds of the cell, discard $x$ and use the center of mass $p$ directly as the dual vertex position [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def compute_dual_vertex(cell_voxels, cell_bounds):
    """
    Computes the dual vertex position for a cell intercepted by the isosurface.
    
    Args:
        cell_voxels: 2x2x2 array of scalar values at the cell corners.
        cell_bounds: Tuple (min_corner, max_corner) defining the cell's spatial bounds.
        
    Returns:
        x: The position of the dual vertex.
    """
    intersections = []
    normals = []
    
    # 1. Identify intersections and normals
    # Iterate over all 12 edges of the cube
    edges = get_cube_edges() # Helper to return list of (v1_idx, v2_idx)
    
    for v1_idx, v2_idx in edges:
        val1 = cell_voxels[v1_idx]
        val2 = cell_voxels[v2_idx]
        
        # Check if edge is bipolar (signs differ)
        if val1 * val2 < 0:
            # Get coordinates of the two corners
            p1 = get_corner_coord(v1_idx, cell_bounds)
            p2 = get_corner_coord(v2_idx, cell_bounds)
            
            # Linear interpolation for intersection point p_i
            # t = val1 / (val1 - val2)
            t = val1 / (val1 - val2)
            p_i = p1 + t * (p2 - p1)
            
            # Compute normal n_i using Prewitt operator
            # Note: In a real implementation, this requires accessing neighboring voxels
            # outside the current cell. Here we assume a function exists.
            n_i = compute_prewitt_normal(p_i, cell_voxels, cell_bounds)
            
            intersections.append(p_i)
            normals.append(n_i)
            
    if not intersections:
        # Cell not intercepted
        return None
        
    # 2. Construct A and b
    A = np.array(normals) # Shape (n, 3)
    b = np.array([np.dot(n, p) for n, p in zip(normals, intersections)]) # Shape (n,)
    
    # 3. Compute Center of Mass p
    p = np.mean(intersections, axis=0)
    
    # 4. Solve for c
    # Compute A^T A
    ATA = A.T @ A
    
    # Compute Moore-Penrose pseudo-inverse using SVD
    # (A^T A)^+
    U, S, Vt = np.linalg.svd(ATA)
    # Handle small singular values to avoid division by zero
    S_inv = np.where(S > 1e-10, 1.0 / S, 0.0)
    ATA_pinv = Vt.T @ np.diag(S_inv) @ U.T
    
    # Calculate c = (A^T A)^+ (A^T b - A^T A p)
    ATb = A.T @ b
    term = ATb - ATA @ p
    c = ATA_pinv @ term
    
    # 5. Compute final position
    x = c + p
    
    # 6. Boundary Check
    if not is_inside_cell(x, cell_bounds):
        return p
        
    return x

def get_cube_edges():
    # Returns indices of the 12 edges of a 2x2x2 grid
    # Vertices are indexed 0-7
    return [
        (0,1), (1,3), (3,2), (2,0), # Bottom face
        (4,5), (5,7), (7,6), (6,4), # Top face
        (0,4), (1,5), (2,6), (3,7)  # Vertical edges
    ]

def get_corner_coord(idx, bounds):
    # Helper to map index 0-7 to 3D coordinate
    min_c, max_c = bounds
    x = min_c[0] if (idx & 1) == 0 else max_c[0]
    y = min_c[1] if (idx & 2) == 0 else max_c[1]
    z = min_c[2] if (idx & 4) == 0 else max_c[2]
    return np.array([x, y, z])

def compute_prewitt_normal(p, cell_voxels, bounds):
    # Placeholder for Prewitt operator implementation
    # Requires access to 3x3x3 neighborhood. 
    # This is a simplified placeholder as the full volume access is not provided in the method signature.
    # In practice, this would convolve the 3x3x3 mask with the scalar field.
    return np.array([1.0, 0.0, 0.0]) # [G] Dummy normal for structure validity

def is_inside_cell(point, bounds):
    min_c, max_c = bounds
    return np.all(point >= min_c) and np.all(point <= max_c)
```

## Subtopics

## Operating characteristics
*   **Time Complexity:** Dominated by the SVD of the $3 \times 3$ matrix $A^T A$. SVD on a small fixed-size matrix is $O(1)$ per cell.
*   **Memory Complexity:** $O(1)$ per cell, storing the intersection points and normals.
*   **Strengths:** Provides a more accurate vertex position than simple centroids by respecting surface normals. The use of the pseudo-inverse handles degenerate cases (e.g., collinear normals) gracefully, though the result may be less stable without centering.
*   **Limitations:** The raw least-squares solution $x$ can fall outside the cell bounds, requiring a fallback to the center of mass. The accuracy depends heavily on the quality of the normal estimation (Prewitt operator is a first-order approximation).
*   **When to use:** When high-quality normal information is available and the cell is well-intersected by the isosurface. It is often used in conjunction with mass point centering to mitigate numerical instability.

## Background
The method originates from the work of Ju et al. (2002) on robust marching cubes [S1, unofficial]. It is based on minimizing a quadratic error function (QEF) as introduced by Garland and Heckbert (1998) [S1, unofficial]. The specific implementation described in the source uses the Prewitt operator for normal estimation and Moore-Penrose pseudo-inverse via SVD for solving the linear system [S1, unofficial]. It is a core component of Dual Contouring algorithms, specifically for the localization of dual vertices before connectivity processing.
