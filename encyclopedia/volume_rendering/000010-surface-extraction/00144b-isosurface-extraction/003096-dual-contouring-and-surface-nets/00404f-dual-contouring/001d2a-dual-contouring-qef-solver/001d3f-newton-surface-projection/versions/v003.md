# Newton Surface Projection
Also called: isosurface projection, vertex projection
## Overview
Newton Surface Projection is a post-processing step that projects extracted vertices exactly onto the isosurface defined by an implicit function, achieving machine precision accuracy [S1, unofficial]. It uses Newton's method to minimize the distance to the zero-level set, ensuring all output vertices lie precisely on the surface [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: A set of vertex positions extracted by the Dual Contouring QEF Solver, and an implicit function $f: \mathbb{R}^3 \to \mathbb{R}$ defining the isosurface [S1, unofficial].
- Output: A set of projected vertex positions where $f(v'_i) \approx 0$ [S1, unofficial].

**Data Structures:**
- Vertices: Array of shape $(N, 3)$, dtype float64 [S1, unofficial].
- Implicit Function: Callable returning values and gradients for batched inputs [S1, unofficial].

**Steps:**
1. For each vertex $v_i$ in the extracted mesh:
2. Initialize $x_0 = v_i$.
3. Iterate Newton's method for $k = 0, 1, \dots$ until convergence:
   a. Evaluate $f(x_k)$ and $\nabla f(x_k)$ (the gradient) [G].
   b. Compute the update step:
      $$ \Delta x = - \frac{f(x_k)}{\|\nabla f(x_k)\|^2} \nabla f(x_k) $$
   c. Update position: $x_{k+1} = x_k + \Delta x$ [G].
   d. Check convergence: if $\| \Delta x \| < \epsilon$ or $|f(x_{k+1})| < \epsilon$, stop [G].
4. Set $v'_i = x_{k+1}$ [S1, unofficial].

**Parameters:**
- $\epsilon$: Convergence threshold. Not given in the sources.
- Max iterations: Not given in the sources.

**Edge Cases and Pitfalls:**
- If $\nabla f(x_k)$ is near zero, the denominator becomes small, causing instability. A guard should clamp the denominator or fall back to a safe step [G].
- The method requires the implicit function to be differentiable at the evaluation points [G].

**Pseudocode:**
```python
def newton_surface_projection(vertices, implicit_func, tol, max_iter):
    """
    Projects vertices onto the isosurface f(x)=0 using Newton's method.
    
    Args:
        vertices: List of (x, y, z) tuples or arrays of vertex positions.
        implicit_func: Callable that takes a single (x, y, z) point and returns (f_val, grad).
                       f_val: float.
                       grad: (x, y, z) tuple or array of partial derivatives.
        tol: Convergence tolerance for |f(x)| and ||delta_x||.
        max_iter: Maximum number of Newton iterations.
        
    Returns:
        projected_vertices: List of projected (x, y, z) positions.
    """
    projected = []
    for v in vertices:
        x = list(v)
        for _ in range(max_iter):
            f_val, grad = implicit_func(x)
            if abs(f_val) < tol:
                break
            grad_norm_sq = sum(g * g for g in grad)
            if grad_norm_sq < 1e-20:
                break
            delta = [- (f_val / grad_norm_sq) * g for g in grad]
            x = [x[i] + delta[i] for i in range(3)]
            if sum(d * d for d in delta) < tol * tol:
                break
        projected.append(x)
    return projected
```

### [DCCVT Projection of 0-crossing Voronoi vertices](9893-dccvt-projection-of-0-crossing-voronoi-vertices.md)
Projects Voronoi vertices (defined as tetrahedron circumcenters) onto the Signed Distance Function zero-level set to correct geometric errors caused by distant circumcenters. Unlike naive barycentric interpolation or explicit tetrahedron containment searches, it fits a plane to the projected sites of the enclosing tetrahedron and projects the vertex onto that plane. Choose it as a robust post-processing step for Dual Contouring vertices extracted from a Clipped Centroidal Voronoi Tessellation.
