# Manifold Dual Contouring - Cell Clustering

Also called: ClusterCell, MDC, Manifold Dual Contouring (Java Implementation)

## Overview
Manifold Dual Contouring - Cell Clustering is a vertex aggregation step within the Manifold Dual Contouring pipeline that consolidates vertices from an octree cell's children into a single manifold-compliant vertex per topological feature [S2, unofficial]. It solves the problem of non-manifold geometry and redundant vertices that arise when multiple child nodes intersect the same surface edge or face, ensuring the output mesh maintains a valid 2-manifold structure [S2, unofficial]. It differs from standard Dual Contouring by explicitly tracking surface indices and collapsing vertices across child boundaries using parent pointers and Euler characteristic constraints, building on [Manifold Dual Contouring](2138-manifold-dual-contouring.md) [S2, unofficial].

## How it works
**Inputs:** An octree node (`MdcOctreeNode`) representing a cell, which may contain child nodes (`MdcOctreeNode`) and existing vertices (`MdcVertex`) [S2, unofficial]. The implicit field values at the cell corners are stored in `node.corners` (bitmask) [S2, unofficial].
**Outputs:** The input node’s `vertices` array is replaced with a new array of aggregated `MdcVertex` objects [S2, unofficial]. Each new vertex represents a collapsed cluster of child vertices [S2, unofficial].

**Data Structures:**
*   `MdcOctreeNode`:
    *   `Type`: Enum (`Node_Internal`, `Node_Leaf`) [S2, unofficial].
    *   `min`: `Vec3i` (position) [S2, unofficial].
    *   `size`: `int` (side length) [S2, unofficial].
    *   `corners`: `byte` (8-bit mask, bit $i$ is 1 if corner $i$ is inside, 0 otherwise) [S2, unofficial].
    *   `vertices`: `MdcVertex[]` [S2, unofficial].
    *   `children`: `MdcOctreeNode[8]` [S2, unofficial].
    *   `child_index`: `int` (index of this node among its parent's children) [S2, unofficial].
*   `MdcVertex`:
    *   `parent`: `MdcVertex` (pointer to the vertex it collapsed into) [S2, unofficial].
    *   `surface_index`: `int` (unique ID for the surface feature this vertex belongs to; -1 if unassigned) [S2, unofficial].
    *   `qef`: `QEFData` (Quadratic Error Function data, solved via `LevenQefSolver`) [S2, unofficial].
    *   `normal`: `Vec3f` (accumulated normal) [S2, unofficial].
    *   `eis`: `int[12]` (Edge Intersection Signs, counts of intersections for the 12 cell edges) [S2, unofficial].
    *   `euler`: `int` (Euler characteristic contribution) [S2, unofficial].
    *   `in_cell`: `int` (index of the cell this vertex originated from) [S2, unofficial].
    *   `face_prop2`: `boolean` (flag indicating specific face topology validity) [S2, unofficial].
    *   `pos`: `Vec3f` (position, solved from QEF) [S2, unofficial].
    *   `error`: `float` [S2, unofficial].
    *   `index`: `int` [S2, unofficial].
    *   `collapsible`: `boolean` [S2, unofficial].

**Pseudocode:**
```python
def ClusterCell(node):
    if node.Type != Node_Internal:
        return  # [S2, unofficial]
    
    signs = [-1] * 8
    mid_sign = -1
    is_collapsible = True
    
    # 1. Recursive child processing & sign propagation
    for i in range(8):
        if node.children[i] is None:
            continue  # [S2, unofficial]
        ClusterCell(node.children[i])  # [S2, unofficial]
        if node.children[i].Type == Node_Internal:
            is_collapsible = False  # [S2, unofficial]
        else:
            mid_sign = (node.children[i].corners >> (7 - i)) & 1  # [S2, unofficial]
            signs[i] = (node.children[i].corners >> i) & 1  # [S2, unofficial]
            
    node.corners = 0
    for i in range(8):
        if signs[i] == -1:
            node.corners |= (mid_sign << i)  # [S2, unofficial]
        else:
            node.corners |= (signs[i] << i)  # [S2, unofficial]
            
    surface_counter = 0
    collected_vertices = []
    
    # 2. Face and Edge Clustering Initialization
    for i in range(12):  # 6 Euclidean edges -> 12 face references
        c1, c2 = Utilities.EdgePairs[i][0], Utilities.EdgePairs[i][1]  # [S2, unofficial]
        face_nodes = [node.children[c1], node.children[c2]]  # [S2, unofficial]
        ClusterFace(face_nodes, Utilities.EdgePairs[i][2], surface_counter, collected_vertices)  # [S2, unofficial]
        
    for i in range(6):  # Internal edges
        edge_nodes = [node.children[Utilities.TCellProcEdgeMask[i][j]] for j in range(4)]  # [S2, unofficial]
        ClusterEdge(edge_nodes, Utilities.TCellProcEdgeMask[i][4], surface_counter, collected_vertices)  # [S2, unofficial]
        
    # 3. Stray Vertex Assignment
    highest_index = surface_counter
    if highest_index == -1:
        highest_index = 0  # [S2, unofficial]
        
    for n in node.children:
        if n is None:
            continue  # [S2, unofficial]
        for v in n.vertices:
            if v is None:
                continue  # [S2, unofficial]
            if v.surface_index == -1:
                v.surface_index = highest_index
                highest_index += 1
                collected_vertices.append(v)  # [S2, unofficial]
                
    # 4. Vertex Aggregation and QEF Solving
    new_vertices = []
    for i in range(highest_index + 1):
        qef = QEFData(LevenQefSolver())  # [S2, unofficial]
        normal = Vec3f(0)
        count = 0
        edges = [0] * 12
        euler = 0
        e = 0
        
        for v in collected_vertices:
            if v.surface_index == i:
                for k in range(3):
                    edge = Utilities.TExternalEdges[v.in_cell][k]  # [S2, unofficial]
                    edges[edge] += v.eis[edge]  # [S2, unofficial]
                for k in range(9):  # 0..8
                    edge = Utilities.TInternalEdges[v.in_cell][k]  # [S2, unofficial]
                    e += v.eis[edge]  # [S2, unofficial]
                euler += v.euler  # [S2, unofficial]
                qef.add(v.qef)  # [S2, unofficial]
                normal = normal.add(v.normal)  # [S2, unofficial]
                count += 1  # [S2, unofficial]
                
        if count == 0:
            continue  # [S2, unofficial]
            
        face_prop2 = True
        for f in range(6):  # 0..5
            intersections = 0
            for ei in range(4):  # 0..3
                intersections += edges[Utilities.TFaces[f][ei]]  # [S2, unofficial]
            if intersections != 0 and intersections != 2:
                face_prop2 = False  # [S2, unofficial]
                
        new_vertex = MdcVertex()
        normal = normal.div(count)  # [S2, unofficial]
        normal.normalize()  # [S2, unofficial]
        new_vertex.normal = normal  # [S2, unofficial]
        new_vertex.qef = qef  # [S2, unofficial]
        new_vertex.eis = edges  # [S2, unofficial]
        new_vertex.euler = euler - e / 4  # [S2, unofficial]
        new_vertex.in_cell = node.child_index  # [S2, unofficial]
        new_vertex.face_prop2 = face_prop2  # [S2, unofficial]
        new_vertices.append(new_vertex)  # [S2, unofficial]
        
        # Set Parent Pointers
        for v in collected_vertices:
            if v.surface_index == i:
                if v != new_vertex:
                    v.parent = new_vertex  # [S2, unofficial]
                else:
                    v.parent = None  # [S2, unofficial]
                    
    if len(collected_vertices) == 0:
        return  # [S2, unofficial]
        
    for v2 in collected_vertices:
        v2.surface_index = -1  # [S2, unofficial]
        
    node.vertices = new_vertices  # [S2, unofficial]

def ClusterFace(nodes, direction, surface_counter, collected_vertices):
    if nodes[0] is None or nodes[1] is None:
        return  # [S2, unofficial]
    if nodes[0].Type != Node_Leaf or nodes[1].Type != Node_Leaf:
        for i in range(4):
            face_nodes = [None, None]
            for j in range(2):
                if nodes[j] is None:
                    continue
                if nodes[j].Type != Node_Internal:
                    face_nodes[j] = nodes[j]
                else:
                    face_nodes[j] = nodes[j].children[Utilities.TFaceProcFaceMask[direction][i][j]]  # [S2, unofficial]
            ClusterFace(face_nodes, Utilities.TFaceProcFaceMask[direction][i][2], surface_counter, collected_vertices)  # [S2, unofficial]
            
    orders = [[0, 0, 1, 1], [0, 1, 0, 1]]  # [S2, unofficial]
    for i in range(4):
        edge_nodes = [None] * 4
        for j in range(4):
            src_node_idx = nodes[orders[Utilities.TFaceProcEdgeMask[direction][i][0]][j]]  # [S2, unofficial]
            if src_node_idx is None:
                continue
            if src_node_idx.Type != Node_Internal:
                edge_nodes[j] = src_node_idx
            else:
                edge_nodes[j] = src_node_idx.children[Utilities.TFaceProcEdgeMask[direction][i][1 + j]]  # [S2, unofficial]
        ClusterEdge(edge_nodes, Utilities.TFaceProcEdgeMask[direction][i][5], surface_counter, collected_vertices)  # [S2, unofficial]

def ClusterEdge(edge_nodes, direction, surface_counter, collected_vertices):
    for n in edge_nodes:
        if n is None:
            return  # [S2, unofficial]
    if all(n.Type == Node_Leaf for n in edge_nodes):
        ProcessIndexes(edge_nodes, direction, surface_counter, collected_vertices)  # [S2, unofficial]
    else:
        for i in range(2):
            sub_edge_nodes = [edge_nodes[Utilities.EdgeProcEdgeMask[i][j]] for j in range(4)]  # [S2, unofficial]
            ClusterEdge(sub_edge_nodes, Utilities.EdgeProcEdgeMask[i][4], surface_counter, collected_vertices)  # [S2, unofficial]

def ProcessIndexes(vertices, direction, surface_counter, collected_vertices):
    v_count = 0
    found_vertices = [None] * 4
    for i in range(4):
        edge = Utilities.TProcessEdgeMask[direction][i]  # [S2, unofficial]
        c1, c2 = Utilities.EdgePairs[edge][0], Utilities.EdgePairs[edge][1]  # [S2, unofficial]
        m1 = (vertices[i].corners >> c1) & 1  # [S2, unofficial]
        m2 = (vertices[i].corners >> c2) & 1  # [S2, unofficial]
        
        index = 0
        skip = False
        for k in range(16):
            e = Utilities.TransformedEdgesTable[vertices[i].corners][k]  # [S2, unofficial]
            if e == -1:
                index += 1
                continue
            if e == -2:
                if not ((m1 == 0 and m2 != 0) or (m1 != 0 and m2 == 0)):
                    skip = True  # [S2, unofficial]
                break
            if e == edge:
                break  # [S2, unofficial]
                
        if not skip and index < len(vertices[i].vertices):
            found_vertices[i] = vertices[i].vertices[index]
            while found_vertices[i].parent is not None:
                found_vertices[i] = found_vertices[i].parent  # [S2, unofficial]
            v_count += 1  # [S2, unofficial]
            
    if v_count == 0:
        return  # [S2, unofficial]
        
    surface_index = -1
    for v in found_vertices:
        if v is None:
            continue
        if v.surface_index != -1:
            if surface_index != -1 and surface_index != v.surface_index:
                AssignSurface(collected_vertices, v.surface_index, surface_index)  # [S2, unofficial]
            elif surface_index == -1:
                surface_index = v.surface_index  # [S2, unofficial]
                
    for v in found_vertices:
        if v is None:
            continue
        if v.surface_index == -1:
            collected_vertices.append(v)  # [S2, unofficial]
        v.surface_index = surface_index  # [S2, unofficial]

def AssignSurface(vertices, from_idx, to_idx):
    for v in vertices:
        if v is not None and v.surface_index == from_idx:
            v.surface_index = to_idx  # [S2, unofficial]
```

**Formulas:**
*   **Intersection Point (used in child leaf construction):**
    $$p = p_1 + \frac{-d_1}{d_2 - d_1} (p_2 - p_1)$$
    Where $p_1, p_2$ are endpoints of an edge, and $d_1, d_2$ are scalar field values at those endpoints [S2, unofficial].
*   **Surface Normal (used in child leaf construction):**
    $$n = \frac{1}{2H} [f(x+H,y,z)-f(x-H,y,z), f(x,y+H,z)-f(x,y-H,z), f(x,y,z+H)-f(x,y,z-H)]^T$$
    Normalized, where $H=1$ [S2, unofficial].

**Parameters:**
*   `EnforceManifold`: Boolean flag controlling manifold enforcement; default value is `true` [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Null Children:** The algorithm skips null children in loops [S2, unofficial]. If all children are null, the function returns early without processing vertices [S2, unofficial].
*   **Face Property 2:** The check `intersections != 0 && intersections != 2` validates that the face has exactly two edge intersections, a requirement for manifold validity in this topology [S2, unofficial].
*   **Parent Traversal:** Vertices are resolved to their highest valid parent before clustering to prevent duplicate manifold violations [S2, unofficial].

## Subtopics

### [Manifold Dual Contouring - Index Processing and Triangle Generation](3699-manifold-dual-contouring-index-processing-and-triangle-gener.md)
This method processes the vertices of a single octree cell to determine the triangle indices that form the mesh geometry for that cell. It resolves vertex conflicts by traversing parent pointers to find the highest valid vertex and generates triangles based on the sign changes of the contouring bits at the cell's corners. It differs from standard dual contouring by enforcing manifold constraints through parent traversal and specific flip logic, building on [Manifold Dual Contouring - Cell Clustering](3677-manifold-dual-contouring-cell-clustering.md).

### [Connectivity Generation via Recursive Traversal](7454-connectivity-generation-via-recursive-traversal.md)
This algorithm extracts the topological connectivity of a surface represented by an octree by enumerating the minimal edges intersected by the surface. It establishes a one-to-one relationship between surface patches and these minimal edges, serving as the connectivity generation phase for Manifold Dual Contouring. Unlike methods that rely on global optimization, it uses local recursive traversal to identify where surface patches should be formed, enabling the subsequent placement of dual nodes.

## Operating characteristics
*   **Time Complexity:** Not given in the sources. The recursive nature means it processes each node once [S2, unofficial].
*   **Memory Complexity:** Not given in the sources. It creates a new list of vertices per cell [S2, unofficial].
*   **Strengths:** Ensures manifold output by design, handles adaptive octree structures efficiently, and simplifies the mesh by collapsing redundant vertices [S2, unofficial].
*   **Limitations:** Relies on specific topology masks (`Utilities` tables) which are complex and hard-coded [S2, unofficial]. The manifold enforcement may fail or produce artifacts if the implicit field sampling is inconsistent or if the octree structure is invalid [S2, unofficial].
*   **When to use:** When a manifold mesh is required from an adaptive octree-based implicit field, and topological correctness is prioritized over raw speed [S2, unofficial].
*   **When not to use:** When non-manifold geometry is acceptable or desired, or when a simpler, faster method like Marching Cubes is sufficient [S2, unofficial].

## Background
Originated from the work of John Lin20, as implemented in the Java repository `proton2/Manifold-dual-contouring-Java` [S2, unofficial]. It is a variant of Dual Contouring that integrates topology constraints to maintain manifold surfaces, building on the general concept of isosurface extraction using octrees [S1]. It is used in 3D visualization for constructing manifold surfaces from implicit fields like SimplexNoise [S2, unofficial].
