# Gradient-Consistent Quadrilateral Splitting

Also called: dual vertex quad triangulation, gamma-based quad splitting

## Overview
Gradient-Consistent Quadrilateral Splitting is a post-processing method for converting the quadrilateral meshes produced by Simplified Dual Contouring into triangle meshes. It resolves the ambiguity of quad triangulation by selecting diagonal splits based on gradient consistency between opposite vertices, ensuring the resulting triangles align with the underlying scalar field's geometry. It differs from sibling methods by using a fixed gamma-based heuristic rather than adaptive geometric criteria.

## How it works
The method takes the quadrilateral mesh generated by Simplified Dual Contouring and splits each quad into triangles. It operates on quads formed by four dual vertices that share a common surface edge in the voxel grid.

**Inputs:**
- `vd_idx`: Tensor of dual vertex indices.
- `surf_edges_mask`: Boolean mask identifying edges intersected by the surface.
- `edge_counts`: Count of cubes sharing each edge.
- `normals`: Surface normals at dual vertices (optional, used if gradient function is not provided).
- `dual_vertices`: 3D coordinates of dual vertices.
- `grad_func`: Optional gradient function to compute normals. If `None`, normals are taken from input.
- `training`: Boolean flag. If `True`, uses differentiable splitting for gradient-based optimization; if `False`, uses hard selection.

**Outputs:**
- `faces`: Tensor of triangle indices (shape $(-1, 3)$).
- `vertices`: Updated vertex buffer (only in training mode, contains new center vertices).

**Data Structures:**
- `quad_vd_idx`: Shape $(-1, 4)$ long tensor. Stores indices of the 4 dual vertices forming each quadrilateral in counter-clockwise order.
- `quad_gamma`: Shape $(-1, 4, 3)$ tensor. Stores normalized gradient vectors at the 4 vertices of each quad.

**Steps:**

1.  **Identify Surface Quads:**
    Identify edges shared by exactly 4 cubes (internal surface edges) that are also part of the surface.
    $$ \text{group\_mask} = (\text{edge\_counts} == 4) \land \text{surf\_edges\_mask} $$
    Gather the dual vertex indices associated with these edges, sort them stably, and reshape into quads:
    $$ \text{quad\_vd\_idx} = \text{vd\_idx}[\text{indices}].\text{reshape}(-1, 4) $$

2.  **Enforce Consistent Winding:**
    Ensure all quads have consistent counter-clockwise winding. Check the sign of the first component of the surface normal at the quad's first edge ($s\_edges[:, 0]$).
    - If $s\_edges[:, 0] > 0$, reorder vertices to $[0, 1, 3, 2]$.
    - Otherwise, reorder vertices to $[2, 3, 1, 0]$.

3.  **Compute Gradient Consistency (Gamma):**
    Compute the "gamma" values, which represent the dot product of normalized gradients at opposite vertices.
    - If `grad_func` is provided, compute normalized gradients at the dual vertices and index them into `quad_gamma` of shape $(-1, 4, 3)$.
    - Compute dot products for diagonals $(0, 2)$ and $(1, 3)$:
      $$ \gamma_{02} = \sum_{k} \text{quad\_gamma}[:, 0, k] \cdot \text{quad\_gamma}[:, 2, k] $$
      $$ \gamma_{13} = \sum_{k} \text{quad\_gamma}[:, 1, k] \cdot \text{quad\_gamma}[:, 3, k] $$
    - If `grad_func` is `None`, use pre-computed normals similarly.

4.  **Split Quads:**
    - **Inference Mode (`not training`):**
      Compare $\gamma_{02}$ and $\gamma_{13}$.
      - If $\gamma_{02} > \gamma_{13}$, split along diagonal $(1, 3)$ using indices `self.quad_split_1`.
      - Else, split along diagonal $(0, 2)$ using indices `self.quad_split_2`.
      - Reshape the resulting face tensor from $(-1, 6)$ to $(-1, 3)$ triangles.
    - **Training Mode (`training`):**
      Compute diagonal midpoints:
      $$ v_{02} = \frac{v_0 + v_2}{2}, \quad v_{13} = \frac{v_1 + v_3}{2} $$
      Calculate a weighted center vertex $v_c$:
      $$ v_c = \frac{v_{02} \cdot \gamma_{02} + v_{13} \cdot \gamma_{13}}{\gamma_{02} + \gamma_{13} + \epsilon} $$
      where $\epsilon = 10^{-8}$ [S1, unofficial].
      Append $v_c$ to the vertex buffer. Split each quad into 4 triangles sharing $v_c$ using `self.quad_split_train`.

```python
def gradient_consistent_quad_splitting(
    vd_idx, 
    edge_counts, 
    surf_edges_mask, 
    dual_vertices, 
    normals=None, 
    grad_func=None, 
    training=False
):
    """
    Splits quadrilaterals from Simplified Dual Contouring into triangles
    based on gradient consistency.
    
    Args:
        vd_idx: Tensor of shape (num_edges, 4) or similar structure mapping edges to quad vertices.
                Note: In practice, this requires gathering indices from a map as per [S1, unofficial].
                For this pseudocode, we assume `quad_vd_idx` is pre-computed as (-1, 4) long tensor.
        edge_counts: Tensor of edge counts.
        surf_edges_mask: Boolean mask of surface edges.
        dual_vertices: Tensor of vertex positions (num_verts, 3).
        normals: Tensor of normals at dual vertices (num_verts, 3). Used if grad_func is None.
        grad_func: Optional callable to compute normals from scalar field.
        training: Boolean flag for differentiable splitting.
        
    Returns:
        faces: Tensor of triangle indices (num_faces, 3).
        new_vertices: Tensor of updated vertices (only if training=True).
    """
    # Step 1: Identify quads
    # Note: The exact gathering logic from [S1, unofficial] involves mapping cube edges to unique surface edges.
    # Here we assume quad_vd_idx is already shaped (-1, 4) representing valid quads.
    # In a full implementation, one would:
    # 1. Identify edges with count == 4 and in surf_edges_mask.
    # 2. Gather vd_idx for these edges.
    # 3. Reshape to (-1, 4).
    
    # Placeholder for the gathering logic described in [S1, unofficial]
    # group_mask = (edge_counts == 4) & surf_edges_mask
    # quad_vd_idx = gather_and_reshape(vd_idx, group_mask) 
    
    # Step 2: Enforce consistent winding
    # We need the normals at the vertices of the quads to check winding.
    # Let's assume we have normals for all vertices.
    quad_normals = normals[quad_vd_idx] # Shape (-1, 4, 3)
    
    # Check sign of first component of normal at first vertex of each quad
    # [S1, unofficial] checks s_edges[:, 0] > 0. Assuming s_edges refers to the normal vector.
    first_normal = quad_normals[:, 0] # Shape (-1, 3)
    reorder_mask = first_normal[:, 0] > 0
    
    # Define reorder indices
    # If mask is True: [0, 1, 3, 2]
    # If mask is False: [2, 3, 1, 0]
    reorder_indices = torch.where(reorder_mask[:, None], 
                                  torch.tensor([0, 1, 3, 2]), 
                                  torch.tensor([2, 3, 1, 0]))
    
    # Gather vertices in correct order
    quad_vd_idx = quad_vd_idx[reorder_indices] # Shape (-1, 4)
    quad_normals = quad_normals[reorder_indices] # Shape (-1, 4, 3)
    
    # Step 3: Compute Gamma (Gradient Consistency)
    # Normalize gradients
    quad_normals_norm = torch.nn.functional.normalize(quad_normals, dim=-1)
    
    # Dot products for diagonals (0,2) and (1,3)
    # gamma_02: dot product of normal at vertex 0 and vertex 2
    gamma_02 = (quad_normals_norm[:, 0] * quad_normals_norm[:, 2]).sum(dim=-1, keepdim=True) # Shape (-1, 1)
    gamma_13 = (quad_normals_norm[:, 1] * quad_normals_norm[:, 3]).sum(dim=-1, keepdim=True) # Shape (-1, 1)
    
    # Step 4: Split Quads
    if not training:
        # Inference: Hard split
        # Split 1: Diagonal (1, 3) -> Triangles (0,1,3), (1,2,3) ? 
        # [S1, unofficial] refers to self.quad_split_1 and self.quad_split_2.
        # Standard quad splitting into 2 triangles:
        # Split 1 (gamma_02 > gamma_13): usually split along the diagonal with lower consistency?
        # [S1, unofficial] says: apply self.quad_split_1 where gamma_02 > gamma_13.
        # Let's assume split 1 corresponds to diagonal (0,2) and split 2 to (1,3) or vice versa.
        # Based on typical "gamma-based" logic, we split along the diagonal that minimizes gradient discontinuity.
        # However, [S1, unofficial] explicitly maps the condition to specific indices.
        # We will define the indices explicitly.
        
        # Assuming split_1 is triangles [0,1,2] and [0,2,3] (diagonal 0-2)
        # Assuming split_2 is triangles [0,1,3] and [1,2,3] (diagonal 1-3)
        
        split_1_indices = torch.tensor([[0, 1, 2], [0, 2, 3]]) # Diagonal 0-2
        split_2_indices = torch.tensor([[0, 1, 3], [1, 2, 3]]) # Diagonal 1-3
        
        # Select split based on gamma
        # [S1, unofficial]: apply self.quad_split_1 where gamma_02 > gamma_13
        faces_1 = quad_vd_idx[:, split_1_indices] # Shape (-1, 2, 3)
        faces_2 = quad_vd_idx[:, split_2_indices] # Shape (-1, 2, 3)
        
        # Combine
        faces = torch.where(gamma_02 > gamma_13, faces_1, faces_2)
        faces = faces.reshape(-1, 3)
        
        return faces, None
    else:
        # Training: Differentiable split with new center vertex
        v0 = dual_vertices[quad_vd_idx[:, 0]]
        v1 = dual_vertices[quad_vd_idx[:, 1]]
        v2 = dual_vertices[quad_vd_idx[:, 2]]
        v3 = dual_vertices[quad_vd_idx[:, 3]]
        
        # Diagonal midpoints
        v_02 = (v0 + v2) / 2.0
        v_13 = (v1 + v3) / 2.0
        
        # Weighted center
        epsilon = 1e-8
        weights = gamma_02 + gamma_13 + epsilon
        v_center = (v_02 * gamma_02 + v_13 * gamma_13) / weights
        
        # Append new vertices
        # Note: In a real implementation, you would manage a global vertex buffer.
        # Here we return the new vertices and their indices relative to the quad.
        new_v_indices = torch.arange(quad_vd_idx.shape[0], device=quad_vd_idx.device)
        
        # Split into 4 triangles sharing the center
        # Triangles: (0,1,c), (1,2,c), (2,3,c), (3,0,c)
        # Indices: 0,1,2,3 are original, 4 is center
        quad_split_train_indices = torch.tensor([
            [0, 1, 4],
            [1, 2, 4],
            [2, 3, 4],
            [3, 0, 4]
        ])
        
        # Construct faces
        # We need to map local indices to global indices
        # Original vertices: quad_vd_idx
        # New vertices: v_center
        
        # Create a tensor of shape (-1, 4, 3) for the 4 triangles
        # Each triangle uses 2 original vertices and the center vertex (index 4)
        
        # To return a flat list of faces, we expand the quad indices
        faces = quad_vd_idx[:, quad_split_train_indices[:, :2]] # Shape (-1, 4, 2)
        center_indices = new_v_indices[:, None, None].expand(-1, 4, 1) # Shape (-1, 4, 1)
        faces = torch.cat([faces, center_indices], dim=-1) # Shape (-1, 4, 3)
        faces = faces.reshape(-1, 3)
        
        return faces, v_center
```

**Parameters:**
- `epsilon`: $10^{-8}$ [S1, unofficial]. Added to the denominator in training mode to prevent division by zero.

**Edge Cases and Pitfalls:**
- **Degenerate Gradients:** If gradients are zero or near-zero, gamma values may be unstable. The epsilon in training mode handles this. In inference, if gammas are equal, the split is arbitrary (defaulting to `split_2` due to `>`).
- **Boundary Edges:** The method only processes edges shared by exactly 4 cubes. Boundary edges are ignored, leaving the mesh open or requiring separate handling.
- **Winding Inconsistency:** If the input normals are inconsistent, the winding correction may fail to produce a manifold mesh.

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of quads. The operations involve tensor indexing, dot products, and conditional assignments, all of which are efficient on GPUs.
- **Memory Complexity:** Linear. Requires storing gamma values and intermediate tensors for each quad.
- **Strengths:** Produces triangles that align well with the scalar field's gradient, reducing visual artifacts. Simple to implement as a post-processing step.
- **Limitations:** Only works on internal surface edges (quads). Does not handle boundary conditions. The hard split in inference mode is not differentiable, limiting its use in gradient-based optimization without the training mode variant.

## Background
Gradient-Consistent Quadrilateral Splitting is a technique used in the context of isosurface extraction, specifically as a refinement step for Simplified Dual Contouring. It was introduced in the context of differentiable surface extraction methods, allowing for gradient-based optimization of the isosurface. The method leverages the consistency of gradients across quad faces to determine the optimal triangulation.
