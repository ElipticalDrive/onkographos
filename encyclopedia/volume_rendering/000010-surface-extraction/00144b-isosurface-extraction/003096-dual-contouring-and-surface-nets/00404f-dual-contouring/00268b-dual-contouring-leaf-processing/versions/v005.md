# Dual Contouring Leaf Processing

Also called: Leaf Voxel Contouring, QEF Vertex Placement

## Overview
Dual Contouring Leaf Processing is the atomic step in adaptive dual contouring that generates a single mesh vertex and its associated normal for a leaf voxel containing an isosurface intersection [S1, unofficial]. It differs from sibling methods by operating strictly on voxels of size 1, using a specific edge-intersection and QEF-minimization pipeline to place the vertex, whereas siblings like [Topologically Accurate Dual Isosurfacing Using Ray Intersection](800-topologically-accurate-dual-isosurfacing-using-ray-intersect.md) or [Linear Edge Intersection for Dual Contouring](926-linear-edge-intersection-for-dual-contouring.md) may handle topology or intersection geometry differently [S1, unofficial].

## How it works
**Inputs:** A leaf voxel node of size 1 containing an implicit density field function $D(\mathbf{p})$ [S1, unofficial].
**Outputs:** An `OctreeDrawInfo` structure containing the vertex position $\mathbf{v}$ and normal $\mathbf{n}$, or `nullptr` if the voxel is empty [S1, unofficial].

**Data Structures:**
*   `OctreeNode`: Contains `type` (enum: `Node_Leaf`, `Node_Internal`, etc.), `corners` (8-bit bitmask), `drawInfo` (position, normal), and children pointers [S1, unofficial].
*   `OctreeDrawInfo`: Contains `position` (vec3) and `normal` (vec3) [S1, unofficial].
*   `QEF Solver`: Accumulates linear constraints $A\mathbf{x} = \mathbf{b}$ derived from surface intersections [G].

**Parameters:**
*   `QEF_SWEEPS`: Number of iterations for the QEF solver (e.g., 10-20) [S1, unofficial].
*   `QEF_ERROR`: Convergence threshold for the solver [S1, unofficial].
*   `H`: Finite difference step size for normal calculation (e.g., 0.001) [S1, unofficial].
*   `steps`: Discretization steps for zero-crossing approximation (e.g., 8) [S1, unofficial].

**Steps:**
1.  **Validation:** If the voxel size is not 1, return `nullptr` [S1, unofficial].
2.  **Corner Classification:** Iterate over the 8 corners of the voxel. For each corner $\mathbf{c}_i$, evaluate density $D(\mathbf{c}_i)$. If $D(\mathbf{c}_i) < 0$, classify as `MATERIAL_SOLID`; otherwise `MATERIAL_AIR`. Pack these into an 8-bit `corners` bitmask [S1, unofficial].
3.  **Empty Check:** If `corners` is 0 (all solid) or 255 (all air), the voxel contains no surface. Delete the leaf and return `nullptr` [S1, unofficial].
4.  **Initialization:** Initialize `edgeCount = 0`, `averageNormal = (0,0,0)`, and a `QEF` solver instance [S1, unofficial].
5.  **Edge Intersection Loop:** Iterate over the 12 edges of the cube. For each edge $i$:
    a. Get corner indices $c_1, c_2$ from the edge mapping [S1, unofficial].
    b. Extract materials $m_1, m_2$ from the `corners` bitmask. If $m_1 == m_2$, skip (no zero crossing) [S1, unofficial].
    c. Compute endpoints $\mathbf{p}_1, \mathbf{p}_2$ [S1, unofficial].
    d. Find intersection point $\mathbf{p}$ using `ApproximateZeroCrossingPosition($\mathbf{p}_1, \mathbf{p}_2$)` [S1, unofficial].
    e. Compute normal $\mathbf{n} = \nabla D(\mathbf{p})$ using `CalculateSurfaceNormal($\mathbf{p}$)` [S1, unofficial].
    f. Add constraint $(\mathbf{n}, \mathbf{n} \cdot \mathbf{p})$ to the QEF solver [S1, unofficial].
    g. Accumulate $\mathbf{n}$ to `averageNormal` [S1, unofficial].
    h. Increment `edgeCount` [S1, unofficial].
6.  **QEF Solution:** Solve the QEF to find vertex position $\mathbf{v}$. Let the result be `qefPosition` [S1, unofficial].
7.  **Boundary Check:** If $\mathbf{v}$ lies outside the voxel bounds $[\mathbf{min}, \mathbf{max}]$, replace $\mathbf{v}$ with the QEF mass point (centroid of constraints) to prevent out-of-bounds artifacts [S1, unofficial].
8.  **Finalize:** Create `OctreeDrawInfo`. Set `position` to $\mathbf{v}$. Set `normal` to $\mathbf{n}_{\text{avg}} = \text{normalize}\left(\frac{\text{averageNormal}}{\text{edgeCount}}\right)$ [S1, unofficial]. Set `corners`, `type = Node_Leaf`, and `drawInfo`. Return the leaf node [S1, unofficial].

**Pseudocode:**
```python
def process_leaf(voxel_node, density_func):
    # Step 1: Validation
    if voxel_node.size != 1:
        return None

    # Step 2: Corner Classification
    corners_bitmask = 0
    for i in range(8):
        pos = voxel_node.corners[i]
        if density_func(pos) < 0:
            corners_bitmask |= (1 << i)

    # Step 3: Empty Check
    if corners_bitmask == 0 or corners_bitmask == 255:
        return None

    # Step 4: Initialization
    edge_count = 0
    average_normal = vec3(0, 0, 0)
    qef = QEF()

    # Step 5: Edge Intersection Loop
    for i in range(12):
        c1, c2 = CubeEdgeMap[i]
        m1 = (corners_bitmask >> c1) & 1
        m2 = (corners_bitmask >> c2) & 1
        
        if m1 == m2:
            continue
            
        p1 = voxel_node.corners[c1]
        p2 = voxel_node.corners[c2]
        
        # Step 5d: Approximate Zero Crossing
        p = approximate_zero_crossing(p1, p2, density_func)
        
        # Step 5e: Calculate Normal
        n = calculate_surface_normal(p, density_func)
        
        # Add QEF constraint: n . x = n . p
        qef.add_constraint(n, dot(n, p))
        
        average_normal += n
        edge_count += 1

    # Step 6: QEF Solution
    qef_position = qef.solve()

    # Step 7: Boundary Check
    if not is_inside_voxel(qef_position, voxel_node):
        qef_position = qef.get_mass_point()

    # Step 8: Finalize
    draw_info = OctreeDrawInfo()
    draw_info.position = qef_position
    
    if edge_count > 0:
        draw_info.normal = normalize(average_normal / edge_count)
    else:
        draw_info.normal = vec3(0, 0, 1)

    voxel_node.type = Node_Leaf
    voxel_node.draw_info = draw_info
    voxel_node.corners = corners_bitmask
    
    return voxel_node

def approximate_zero_crossing(p0, p1, density_func):
    min_val = 100000.0
    best_t = 0.0
    steps = 8
    increment = 1.0 / steps
    current_t = 0.0
    
    while current_t <= 1.0:
        p = p0 + (p1 - p0) * current_t
        density = abs(density_func(p))
        if density < min_val:
            min_val = density
            best_t = current_t
        current_t += increment
        
    return p0 + (p1 - p0) * best_t

def calculate_surface_normal(p, density_func):
    H = 0.001
    dx = density_func(p + vec3(H, 0, 0)) - density_func(p - vec3(H, 0, 0))
    dy = density_func(p + vec3(0, H, 0)) - density_func(p - vec3(0, H, 0))
    dz = density_func(p + vec3(0, 0, H)) - density_func(p - vec3(0, 0, H))
    return normalize(vec3(dx, dy, dz))

class QEF:
    def __init__(self):
        self.A = mat3(0)
        self.b = vec3(0)
        self.points = []
        
    def add_constraint(self, n, d):
        # Accumulate normal equations: sum(n_i * n_i^T) x = sum(d_i * n_i)
        self.A += outer_product(n, n)
        self.b += d * n
        self.points.append(d)
        
    def solve(self):
        # Solve Ax = b using standard least-squares [G]
        return solve_linear_system(self.A, self.b)
        
    def get_mass_point(self):
        # Centroid of intersection points [G]
        if not self.points:
            return vec3(0)
        return sum(self.points) / len(self.points)

CubeEdgeMap = [
    (0, 1), (1, 3), (3, 2), (2, 0),  # Bottom face
    (4, 5), (5, 7), (7, 6), (6, 4),  # Top face
    (0, 4), (1, 5), (3, 7), (2, 6)   # Vertical edges
]

def is_inside_voxel(p, node):
    return all(node.min[i] <= p[i] <= node.max[i] for i in range(3))
```

## Operating characteristics
*   **Time Complexity:** $O(1)$ per leaf voxel, as it processes a fixed number of edges (12) and corners (8) [S1, unofficial].
*   **Memory Complexity:** $O(1)$ auxiliary memory per leaf for the QEF solver and temporary vectors [G].
*   **Strengths:** Simple to implement; robust for uniform or adaptive grids; handles varying surface orientations via QEF [S1, unofficial].
*   **Limitations:** The zero-crossing approximation is not exact (uses discrete sampling), which may introduce slight positional errors compared to analytical intersection methods [S1, unofficial]. The QEF solution may require careful handling of degenerate cases (e.g., all normals parallel) [G].
*   **When to use:** When implementing adaptive dual contouring where leaf voxels are processed individually [S1, unofficial].
*   **When not to use:** If exact topological correctness is required without post-processing, consider [Topologically Accurate Dual Isosurfacing Using Ray Intersection](800-topologically-accurate-dual-isosurfacing-using-ray-intersect.md) [S1, unofficial].

## Background
This method is derived from the dual contouring framework, specifically the leaf processing stage described in the `nickgildea/DualContouringSample` repository [S1, unofficial]. It builds on the general dual contouring principle of placing vertices inside cells to minimize a QEF [Parent].
