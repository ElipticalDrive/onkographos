# Grid Topology Generation (Edge Building)

Also called: Edge Indexing, Topology Construction

## Overview
This method generates the edge connectivity for the extracted mesh in a 2D Dual Contouring implementation by determining which grid vertices are connected based on cell intersection counts and tile boundaries [S1, unofficial]. It operates on a tiled grid structure, using shared memory reductions and parallel prefix sums to efficiently compute global edge indices for a CUDA kernel [S1, unofficial]. It differs from its sibling [Dual Contouring with NDC Constraint](4410-dual-contouring-with-ndc-constraint.md) by focusing specifically on the low-level parallel topology construction for standard 2D grid cells without additional non-directional constraint handling [S1, unofficial].

## How it works
**Inputs:**
- `ibuffer`: Device memory array storing vertex indices. Layout: `int` array of size `(n - 1) * TILE_HEIGHT * 2`, initialized to `-1` [S1, unofficial]. It stores indices for the current, left, and down vertices relative to the processing tile [S1, unofficial].
- `n`: Number of mesh grid vertices along one axis [S1, unofficial].
- `TILE_WIDTH`, `TILE_HEIGHT`: Compile-time constants defining CUDA block dimensions [S1, unofficial].
- `ecnt`: Device integer pointer for global edge count, initialized to 0 [S1, unofficial].
- `edges`: Device integer array for output edges, capacity `ecap` [S1, unofficial].

**Outputs:**
- `edges`: Array of integers storing edge connections. The array is filled sequentially based on computed global offsets [S1, unofficial].
- `ecnt`: Updated global count of generated edges [S1, unofficial].

**Data Structures:**
- `s[BLOCK_SIZE]`: Shared memory array used for parallel reduction and prefix sum. Indexed by `ti = threadIdx.y * TILE_WIDTH + threadIdx.x` [S1, unofficial]. `BLOCK_SIZE` equals `TILE_WIDTH * TILE_HEIGHT`.

**Steps:**
1. **Fetch Indices:** Each thread fetches the vertex indices for the current cell (`self`), the left neighbor (`left`), and the down neighbor (`down`) from `ibuffer`. If a neighbor is outside the grid or tile boundary, the index is `-1` [S1, unofficial].
2. **Count Connections:** Compute the number of valid connections for the current cell: `count = (left != -1) + (down != -1)` if `self != -1`; otherwise `count = 0` [S1, unofficial].
3. **Shared Memory Reduction:** Perform a block-level reduction in shared memory to count how many threads have `count == 1` and `count == 2`: `total1 = reduction_count(s, count == 1)`, `total2 = reduction_count(s, count == 2)` [S1, unofficial]. The total edges contributed by this tile is `total = total1 + total2 * 2` [S1, unofficial].
4. **Global Offset:** Compute the global starting index for this tile's edges using an atomic add: `base = atomic_add(ecnt, total)` [S1, unofficial].
5. **Prefix Sum:** Execute a parallel inclusive prefix sum (scan) on the `count` values stored in `s` to determine local edge indices [S1, unofficial]. The local edge index for a thread is `ei = base + s[ti] - count` [S1, unofficial].
6. **Write Edges:** Write the edges to the `edges` array based on `ei` [S1, unofficial]. The source specifies: "first edge connects `self` to `left` (or `down`), second edge connects `self` to `down`" [S1, unofficial]. Specifically, if `left != -1`, write `(self, left)` at `edges[ei]` and `edges[ei + 1]` [S1, unofficial]. If `count == 2`, write the second edge `(self, down)` at `edges[ei + 2]` and `edges[ei + 3]` [S1, unofficial]. If `count == 1`, only the first edge is written [S1, unofficial].

**Pseudocode:**
```python
# Kernel entry for a single thread block
BLOCK_SIZE = TILE_WIDTH * TILE_HEIGHT
ti = (thread_idx_y * TILE_WIDTH) + thread_idx_x
s = [0] * BLOCK_SIZE  # Shared memory array

# 1. Fetch indices from ibuffer
self_idx = ibuffer[ti]
left_idx = ibuffer[ti + 1] if (thread_idx_x + 1 < TILE_WIDTH) else -1
down_idx = ibuffer[ti + TILE_WIDTH] if (thread_idx_y + 1 < TILE_HEIGHT) else -1

# 2. Count connections
count = 0
if self_idx != -1:
    if left_idx != -1: count += 1
    if down_idx != -1: count += 1
s[ti] = count

# 3. Shared memory reduction (standard parallel vote primitive [G])
total1 = sum(1 for c in s if c == 1)
total2 = sum(1 for c in s if c == 2)
total = total1 + total2 * 2

# 4. Global offset (parallel atomic primitive [G])
base = ecnt + total  # In hardware: atomicAdd(ecnt, total)

# 5. Parallel inclusive prefix sum (standard parallel scan primitive [G])
prefix_sum = [0] * BLOCK_SIZE
running = 0
for i in range(BLOCK_SIZE):
    running += s[i]
    prefix_sum[i] = running
ei = base + prefix_sum[ti] - count

# 6. Write edges
idx = ei
if left_idx != -1:
    edges[idx] = self_idx
    edges[idx + 1] = left_idx
    idx += 2
if count == 2:
    edges[idx] = self_idx
    edges[idx + 1] = down_idx
```

**Parameters:**
- `TILE_WIDTH`, `TILE_HEIGHT`: Typical values depend on GPU architecture, often powers of 2 (e.g., 16x16, 32x32) [S1, unofficial].

**Edge Cases:**
- Boundary vertices: Indices are `-1` and must be handled to avoid writing invalid edges [S1, unofficial].
- Degenerate cells: If `self` is `-1`, `count` is 0, and no edges are written [S1, unofficial].

## Subtopics

### DCx Mesh Generation Pipeline
DCx (Dual Contouring over Expanded Cubes) extends this topology generation methodology to 3D UDFs [S2]. It applies a thinning algorithm to refine active cubes predicted by generative models like TRELLIS.2 [S2]. It constructs mesh topology by connecting dual vertices via a V2M (Voxel-to-Mesh) look-up table over expanded cubes [S2]. It includes a post-processing step to eliminate residual topological noise [S2]. Unlike Faithful Contouring (FC), which uses standard QEF and suffers from artifacts, DCx uses an optimization-based projection strategy and the V2M lookup table, yielding cleaner topology with fewer spurious non-manifold artifacts and topological holes [S2].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of grid cells, $O(N)$, due to the parallel nature of the reduction and prefix sum [S1, unofficial].
- **Memory Complexity:** $O(N)$ for the `edges` array and $O(BLOCK\_SIZE)$ for shared memory `s` [S1, unofficial].
- **Strengths:** High parallelism, handles tile boundaries gracefully, avoids race conditions via atomic operations [S1, unofficial].
- **Limitations:** Requires sufficient grid resolution to resolve details; lower resolutions may lead to topological ambiguities [S2].

## Background
This method originates from the `cudc` project, an unofficial CUDA implementation of Dual Contouring for 2D grids [S1, unofficial]. It is part of the pipeline for extracting polygonal meshes from scalar fields defined on 2D grids [S1, unofficial].
