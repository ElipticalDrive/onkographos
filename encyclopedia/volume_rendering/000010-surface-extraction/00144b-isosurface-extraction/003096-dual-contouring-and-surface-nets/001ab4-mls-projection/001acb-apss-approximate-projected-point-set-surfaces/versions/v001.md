# APSS (Approximate Projected Point Set Surfaces)

Also called: MLS projection via Approximate Projected Point Set Surfaces

## Overview
APSS is an iterative method to project a query point onto a surface defined by a point set with normals, using Moving Least Squares (MLS) [S1, unofficial]. It appears to compute a local coordinate system or higher-order approximation using vectors u123, u4, u0, sum_1, sum_4, sum_2, sum_3, and sum_weight, though the full update logic is cut off in the provided text [S1, unofficial].

## How it works
**Inputs:**
- `inputPositions`: Array of 3D points defining the surface.
- `inputNormals`: Array of 3D normals corresponding to `inputPositions`.
- `inputPointsetKdTree`: A KD-tree structure built from `inputPositions` for efficient nearest neighbor search.
- `queryPoint`: The 3D point to project onto the surface.
- `knn`: Number of nearest neighbors to consider. Default value is 20 [S1, unofficial].
- `radius`: The radius parameter for the kernel function used to weight neighbors in the MLS computation [S1, unofficial].
- `numberOfIterations`: The number of iterations for the MLS algorithm loop [S1, unofficial].

**Outputs:**
- `outputPoint`: The projected point on the surface.
- `outputNormal`: The normal at the projected point.

**Data Structures:**
- `id_nearest_neighbors`: Array of indices into `inputPositions` for the `knn` nearest neighbors.
- `square_distances_to_neighbors`: Array of squared distances from the current query point to the `knn` nearest neighbors.
- Accumulators:
  - `u123`: 3D vector, initialized to (0,0,0).
  - `u4`: Scalar, initialized to 0.0.
  - `u0`: Scalar, initialized to 0.0.
  - `sum_1`: Scalar, initialized to 0.0.
  - `sum_4`: Scalar, initialized to 0.0.
  - `sum_2`: 3D vector, initialized to (0,0,0).
  - `sum_3`: 3D vector, initialized to (0,0,0).
  - `sum_weight`: Scalar, initialized to 0.0.

**Steps:**
1. Initialize `outputPoint` to `queryPoint` [S1, unofficial].
2. Initialize `outputNormal` to (0,0,1) or another default [G].
3. Loop for `iter` from 0 to `numberOfIterations-1`:
   a. Find the `knn` nearest neighbors to the current `outputPoint` using `inputPointsetKdTree.knearest` method, retrieving `id_nearest_neighbors` and `square_distances_to_neighbors` [S1, unofficial].
   b. Initialize accumulators: `u123=(0,0,0)`, `u4=0.0`, `u0=0.0`, `sum_1=0.0`, `sum_4=0.0`, `sum_2=(0,0,0)`, `sum_3=(0,0,0)`, `sum_weight=0.0` [S1, unofficial].
   c. Loop over `i` from 0 to `knn-1`:
      i. Get neighbor position `p` from `inputPositions` using `id_nearest_neighbors[i]` [S1, unofficial].
      ii. Get neighbor normal `n` from `inputNormals` using `id_nearest_neighbors[i]` [S1, unofficial].
      iii. Compute weight `w` based on `square_distances_to_neighbors[i]` and `radius` [G]. A common choice is a polynomial kernel: $w = \max(0, 1 - \frac{d^2}{r^2})^2$ or similar, where $d^2$ is the squared distance and $r$ is the radius.
      iv. Update accumulators:
          - `sum_weight += w`
          - `sum_1 += w`
          - `sum_2 += w * p`
          - `sum_3 += w * (p - outputPoint)`
          - `sum_4 += w * (p - outputPoint)^2`
          - `u0 += w * (n . (p - outputPoint))`
          - `u4 += w * (n . n)`
