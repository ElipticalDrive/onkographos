# Moving Least Squares Implicit Surface Reconstruction

Also called: MLS implicit method

## Overview
Moving Least Squares (MLS) Implicit Surface Reconstruction is a technique for reconstructing a surface from an unordered 3D point cloud by creating an implicit function field using Moving Least Squares, from which isosurfaces are extracted [S1, unofficial].

## How it works
**Inputs:** An unordered 3D point cloud $V$ (vertices) and a neighbor count $k$ for normal estimation [S1, unofficial].
**Outputs:** A triangular mesh representing the isosurface [S1, unofficial].

**Data Structures:**
*   $V$: Matrix of size $N \times 3$, where $N$ is the number of input points.
*   $N_{norm}$: Matrix of size $N \times 3$, storing per-vertex normals.
*   $C$: Constraint points matrix. Size $(3N) \times 3$.
*   $D$: Constraint values vector. Size $3N$.
*   $k$: Number of nearest neighbors for PCA.
*   $\epsilon$: Small offset distance for constraint generation.

**Steps:**

1.  **Normal Estimation:** For each vertex $v_i \in V$, compute the normal $n_i$ using Principal Component Analysis (PCA) on its $k$-nearest neighbors [S1, unofficial].
    *   Find $k$ nearest neighbors of $v_i$.
    *   Compute the centroid $m$ of these neighbors.
    *   Center the neighbor points: $P_{centered} = P_{neighbors} - m$.
    *   Compute the covariance matrix $S = P_{centered}^T P_{centered}$.
    *   Perform eigenvalue decomposition on $S$.
    *   Select the eigenvector corresponding to the smallest eigenvalue as the normal $n_i$ [S1, unofficial].

2.  **Constraint Generation:** Generate constraints for the implicit function. For each vertex $v_i$ with normal $n_i$:
    *   **Constraint 1 (Vertex):** Point $c_1 = v_i$, Value $d_1 = 0$.
    *   **Constraint 2 (Outside):** Point $c_2 = v_i + \epsilon n_i$, Value $d_2 = \epsilon$.
    *   **Constraint 3 (Inside):** Point $c_3 = v_i - \epsilon n_i$, Value $d_3 = -\epsilon$ [S1, unofficial].

3.  **Implicit Function Evaluation:** Evaluate the MLS implicit function $f(x)$ at grid vertices. The function is defined by minimizing the weighted least squares error of the constraints $C$ and $D$ [S1, unofficial]. For a query point $x$, the value $f(x)$ is derived from the local quadratic fit that best approximates the signed distance function defined by the constraints. The specific MLS formulation involves weighting constraints by distance to $x$ and solving a local linear system to determine the function value and gradient [S1, unofficial].

4.  **Isosurface Extraction:** Extract the zero-level set of the implicit function field using Marching Tetrahedra. This method divides the grid into tetrahedra and determines intersections with the isosurface within each tetrahedron, offering fewer configurations and no ambiguity compared to Marching Cubes [S1, unofficial].

import math

def mls_implicit_reconstruction(V, k, epsilon, grid_bounds, grid_res):
    """
    V: List of Nx3 points
    k: number of neighbors for normal estimation
    epsilon: offset distance for constraints
    grid_bounds: (min_x, min_y, min_z, max_x, max_y, max_z)
    grid_res: integer resolution per axis
    Returns: List of triangles (each triangle is a list of 3 vertex indices)
    """
    N = len(V)
    normals = [[0.0, 0.0, 0.0] for _ in range(N)]

    # Step 1: Normal Estimation via PCA
    for i in range(N):
        p = V[i]
        nn_indices, _ = find_k_nearest_neighbors(V, p, k)
        nn_points = [V[idx] for idx in nn_indices]
        
        # Centroid
        m = [sum(nn_points[j][d] for j in range(k)) / k for d in range(3)]
        
        # Centered points
        P_c = [[nn_points[j][d] - m[d] for d in range(3)] for j in range(k)]
        
        # Covariance S = P_c^T P_c
        S = [[sum(P_c[j][d1] * P_c[j][d2] for j in range(k)) for d2 in range(3)] for d1 in range(3)]
        
        # Eigen decomposition (3x3)
        eigenvalues, eigenvectors = eigen_decompose_3x3(S)
        
        # Normal is eigenvector with smallest eigenvalue
        min_idx = 0
        if eigenvalues[1] < eigenvalues[min_idx]: min_idx = 1
        if eigenvalues[2] < eigenvalues[min_idx]: min_idx = 2
        normals[i] = eigenvectors[min_idx]

    # Step 2: Constraint Generation
    C = []
    D = []
    for i in range(N):
        p = V[i]
        n = normals[i]
        C.append(p); D.append(0.0)
        C.append([p[d] + epsilon * n[d] for d in range(3)]); D.append(epsilon)
        C.append([p[d] - epsilon * n[d] for d in range(3)]); D.append(-epsilon)

    # Step 3: Implicit Function Evaluation
    grid_points = generate_grid_points(grid_bounds, grid_res)
    f_values = []
    for x in grid_points:
        f_values.append(evaluate_mls_implicit(x, C, D))

    # Step 4: Marching Tetrahedra
    mesh = marching_tetrahedra(grid_points, f_values, grid_bounds, grid_res)
    return mesh

def find_k_nearest_neighbors(V, p, k):
    dists = [(math.dist(p, q), idx) for idx, q in enumerate(V)]
    dists.sort(key=lambda x: x[0])
    return [d[1] for d in dists[:k]], [d[0] for d in dists[:k]]

def eigen_decompose_3x3(M):
    # Standard analytical 3x3 eigen solver [G]
    a, b, c = M[0][0], M[1][1], M[2][2]
    d, e, f = M[0][1], M[0][2], M[1][2]
    p1 = a + b + c
    p2 = a*b - d*d + a*c - f*f + b*c - e*e
    p3 = a*b*c + 2*d*e*f - a*e*e - b*f*f - c*d*d
    q = (p1*p1 - 3*p2) / 9.0
    r = (2*p1*p1*p1 - 9*p1*p2 + 27*p3) / 54.0
    t = r*r - q*q*q
    if t >= 0:
        S = math.cbrt(r + math.sqrt(t))
        T = math.cbrt(r - math.sqrt(t))
        e1 = p1/3.0 - 2*math.sqrt(q)*math.cos(math.acos(r/math.sqrt(q*q*q))/3.0)
        e2 = p1/3.0 - 2*math.sqrt(q)*math.cos(math.acos(r/math.sqrt(q*q*q))/3.0 - 2*math.pi/3.0)
        e3 = p1/3.0 - 2*math.sqrt(q)*math.cos(math.acos(r/math.sqrt(q*q*q))/3.0 + 2*math.pi/3.0)
    else:
        theta = math.acos(r / math.sqrt(q*q*q))
        e1 = p1/3.0 - 2*math.sqrt(q)*math.cos(theta/3.0)
        e2 = p1/3.0 - 2*math.sqrt(q)*math.cos((theta + 2*math.pi)/3.0)
        e3 = p1/3.0 - 2*math.sqrt(q)*math.cos((theta + 4*math.pi)/3.0)
    eigenvalues = [e1, e2, e3]
    # Eigenvectors via (M - lambda*I)v = 0 [G]
    eigenvectors = []
    for lam in eigenvalues:
        A = [[M[i][j] - lam*(1 if i==j else 0) for j in range(3)] for i in range(3)]
        # Cross product of first two rows to get normal
        v = [A[0][1]*A[1][2] - A[0][2]*A[1][1],
             A[0][2]*A[1][0] - A[0][0]*A[1][2],
             A[0][0]*A[1][1] - A[0][1]*A[1][0]]
        norm = math.sqrt(sum(x*x for x in v))
        if norm < 1e-8: v = [1.0, 0.0, 0.0]
        else: v = [x/norm for x in v]
        eigenvectors.append(v)
    return eigenvalues, eigenvectors

def evaluate_mls_implicit(x, C, D):
    # Standard MLS implicit evaluation [G]
    # Weights w_j = 1 / (||x - c_j||^2 + delta^2)
    delta = 1e-6
    weights = [1.0 / (math.dist(x, c)**2 + delta) for c in C]
    
    # Basis functions for quadratic: [1, x, y, z, x^2, xy, xz, y^2, yz, z^2]
    # Simplified to linear + normal direction for signed distance approximation [G]
    # Fit q(y) = a^T y + y^T B y to constraints
    # Solve weighted least squares A * alpha = b
    A = [[0.0]*3 for _ in range(3)]
    b = [0.0]*3
    for j, (c, d) in enumerate(zip(C, D)):
        w = weights[j]
        dx = [c[d_i] - x[d_i] for d_i in range(3)]
        for i1 in range(3):
            for i2 in range(3):
                A[i1][i2] += w * dx[i1] * dx[i2]
            b[i1] += w * dx[i1] * d
            A[i1][i1] += w * dx[i1]**2 # Regularization
            b[i1] += w * d * dx[i1]
            
    # Newton iteration to find root of q(y)=0 near x
    y = list(x)
    for _ in range(5):
        dy = [y[d_i] - x[d_i] for d_i in range(3)]
        val = sum(A[i][j] * dy[i] * dy[j] for i in range(3) for j in range(3))
        grad = [2 * sum(A[i][j] * dy[j] for j in range(3)) for i in range(3)]
        norm_g = math.sqrt(sum(g*g for g in grad))
        if norm_g < 1e-8: break
        step = -val / (norm_g**2 + 1e-8)
        y = [y[d_i] + step * grad[d_i]/norm_g for d_i in range(3)]
        
    return math.sqrt(sum((y[d_i] - x[d_i])**2 for d_i in range(3)))

    return points
