# MLS Projection

Also called: MLS projection via Hermite Point Set Surfaces, Moving Least Squares Surface, Parabolic Case Triangulation

## Overview

MLS Projection is an iterative algorithm that projects a query point onto a surface defined by a set of input points and their associated normals (Hermite data) [S2, unofficial]. It constructs a local Moving Least Squares (MLS) approximation to determine the closest point on the implicit surface and its normal [S2, unofficial]. Unlike [Dual Contouring](778-dual-contouring.md) which minimizes a global linear system per cell, or [Surface Nets](921-surface-nets.md) which uses simple centroids, MLS Projection computes a non-linear, locally weighted projection that adapts to the local geometry's curvature [S2, unofficial]. It is primarily used to generate smooth, noise-resistant implicit fields or to refine vertex positions in surface reconstruction pipelines [S3].

## How it works

**Inputs and Outputs:**
*   **Input:** A query point $P_{in}$ (Vec3), a set of input points $P_{input}$ (Vec3), a set of input normals $N_{input}$ (Vec3), a K-D tree for spatial indexing, kernel type, radius $h$, number of neighbors $knn$, and maximum iterations $I_{max}$.
*   **Output:** A projected point $P_{out}$ (Vec3) and a projected normal $N_{out}$ (Vec3).

**Data Structures:**
*   **K-D Tree:** Stores $P_{input}$ and $N_{input}$ for efficient nearest-neighbor queries.
*   **Accumulators:** Floating-point scalars and 3D vectors used to aggregate weighted contributions from neighbors.

**Parameters:**
*   $knn$: Number of nearest neighbors. Default: 20 [S2, unofficial].
*   $h$ (radius): Radius for the kernel function [S2, unofficial].
*   $I_{max}$ (numberOfIterations): Maximum iterations. Default: 10–20 [S2, unofficial].
*   kernel_type: 0=Gaussian, 1=Wendland, 2=Singular [S2, unofficial].

**Algorithm Steps:**

1.  **Initialization:** Set current point $P = P_{in}$ and current normal $N = N_{in}$ (if provided, otherwise derived or zero).
2.  **Iteration Loop:** For $iter$ from 0 to $I_{max}-1$:
    a.  **Neighbor Search:** Find the $knn$ nearest neighbors of $P$ in the input point set using the K-D tree. Retrieve their indices $idx_i$ and squared distances $d^2_i$ for $i \in [0, knn-1]$.
    b.  **Accumulator Reset:** Initialize accumulators:
        *   $S_w = 0.0$
        *   $S_{pos} = (0,0,0)$
        *   $S_{norm} = (0,0,0)$
        *   $S_1 = 0.0$
        *   $S_2 = (0,0,0)$
        *   $S_3 = (0,0,0)$
        *   $S_4 = 0.0$
    c.  **Weighted Summation:** For each neighbor $i$:
        *   Get neighbor position $Q_i = P_{input}[idx_i]$ and normal $V_i = N_{input}[idx_i]$.
        *   Compute distance $r_i = \sqrt{d^2_i}$.
        *   Compute weight $w_i = K(r_i, h)$ based on kernel type.
        *   Update accumulators:
            *   $S_w \leftarrow S_w + w_i$
            *   $S_1 \leftarrow S_1 + w_i (Q_i \cdot V_i)$
            *   $S_2 \leftarrow S_2 + w_i Q_i$
            *   $S_3 \leftarrow S_3 + w_i V_i$
            *   $S_4 \leftarrow S_4 + w_i (Q_i \cdot Q_i)$
    d.  **Polynomial Coefficient Calculation:** Compute coefficients for the local quadratic fit $f(x) = u_4 x^T x + u_{123}^T x + u_0$:
        *   $u_4 = 0.5 \frac{S_1 - \frac{S_2 \cdot S_3}{S_w}}{S_4 - \frac{S_2 \cdot S_2}{S_w}}$
        *   $u_{123} = \frac{S_3 - 2 u_4 S_2}{S_w}$
        *   $u_0 = -\frac{S_2 \cdot u_{123} + u_4 S_4}{S_w}$
    e.  **Normal Estimation:** The gradient of the fitted polynomial at $P$ gives the new normal:
        *   $N_{new} = u_{123} + 2 u_4 P$
        *   Normalize $N_{new}$ to get $N$.
    f.  **Point Projection:** Project $P$ onto the tangent plane defined by $N$ at the estimated surface location. The displacement is calculated as:
        *   $diff = (u_0 + u_{123} \cdot P + u_4 (P \cdot P)) N$
        *   $P_{new} = P - diff$
    g.  **Update:** Set $P = P_{new}$ and $N = N_{new}$.
3.  **Final Output:** Return $P_{out} = P$ and $N_{out} = N$.

**Parabolic Case Handling:**
In specific surface fitting contexts (e.g., APSS or specific dual contouring variants), if the quadratic form's eigenvalues are $\lambda_1 > 0$ and $\lambda_2 = 0$, the surface is parabolic. The transformation from canonical form $p(\bar{x}, \bar{y}) = \bar{x}^2$ to the function $f$ uses the map:
$$
\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} \frac{1}{\sqrt{\lambda_1}} e_{11} & 0 \\ \frac{1}{\sqrt{\lambda_1}} e_{12} & 0 \end{pmatrix} \begin{pmatrix} \bar{x} \\ \bar{y} \end{pmatrix}
$$
where $e_1 = (e_{11}, e_{12})$ is the first normalized eigenvector [S1, unofficial]. The error profile for a line segment is determined by its projection onto $e_1$, with length at most $\sqrt{4\epsilon/\lambda_1}$. Vertices are placed below the surface by $\epsilon$ if $\lambda_1 > 0$, or above if $\lambda_1 < 0$ [S1, unofficial].

**Pseudocode:**

```python
def mls_projection(input_point, input_positions, input_normals, kd_tree, 
                   kernel_type, radius, knn, max_iterations):
    """
    Projects input_point onto the surface defined by input_positions/normals.
    Returns (projected_point, projected_normal).
    """
    current_point = input_point
    current_normal = Vec3(0, 0, 0) # Initialize normal; often derived from first iteration or provided
    
    for iter in range(max_iterations):
        # 1. Find nearest neighbors
        indices, squared_distances = kd_tree.knearest(current_point, knn)
        
        # 2. Initialize accumulators
        sum_weight = 0.0
        sum_1 = 0.0
        sum_2 = Vec3(0, 0, 0)
        sum_3 = Vec3(0, 0, 0)
        sum_4 = 0.0
        
        # 3. Accumulate weighted sums
        for i in range(knn):
            neighbor_pos = input_positions[indices[i]]
            neighbor_norm = input_normals[indices[i]]
            dist = sqrt(squared_distances[i])
            
            # Get kernel weight
            weight = get_kernel(kernel_type, dist, radius)
            
            sum_weight += weight
            sum_1 += weight * dot(neighbor_pos, neighbor_norm)
            sum_2 += weight * neighbor_pos
            sum_3 += weight * neighbor_norm
            sum_4 += weight * dot(neighbor_pos, neighbor_pos)
            
        # 4. Compute polynomial coefficients
        # Avoid division by zero if sum_weight is 0 (should not happen with valid knn)
        if sum_weight == 0:
            break
            
        denom = sum_4 - dot(sum_2, sum_2) / sum_weight
        if abs(denom) < 1e-9:
            # Degenerate case: fallback to simple averaging or break
            break
            
        u4 = 0.5 * (sum_1 - dot(sum_2, sum_3) / sum_weight) / denom
        u123 = (sum_3 - 2 * u4 * sum_2) / sum_weight
        u0 = -(dot(sum_2, u123) + u4 * sum_4) / sum_weight
        
        # 5. Compute new normal (gradient of quadratic at current_point)
        new_normal = u123 + 2 * u4 * current_point
        new_normal = normalize(new_normal)
        
        # 6. Project point
        # Value of polynomial at current_point
        val = u0 + dot(u123, current_point) + u4 * dot(current_point, current_point)
        
        # Displacement along normal
        diff = val * new_normal
        current_point = current_point - diff
        current_normal = new_normal
        
    return current_point, current_normal

def get_kernel(kernel_type, r, h):
    if kernel_type == 0: # Gaussian
        return exp(-(r * r) / (h * h))
    elif kernel_type == 1: # Wendland
        if r >= h:
            return 0.0
        return (1 - r/h)**4 * (1 + 4*r/h)
    elif kernel_type == 2: # Singular
        return (r/h)**(-2) # w=2 is common default for singular, check source for exact w
    else:
        return 0.0
```

## Subtopics

### [APSS (Approximate Projected Point Set Surfaces)](843-apss-approximate-projected-point-set-surfaces.md)
APSS is an iterative method that projects a query point onto a surface defined by a point set with normals, using Moving Least Squares. It builds on [MLS Projection](823-mls-projection.md) by computing a local coordinate system and higher-order approximations via weighted accumulators, distinguishing it from standard MLS by explicitly tracking cross-product and dot-product terms for refined surface fitting. Choose APSS when higher-order continuity or more accurate curvature representation is needed compared to standard MLS.

### [Moving Least Squares Implicit Surface Reconstruction](5328-moving-least-squares-implicit-surface-reconstruction.md)
Moving Least Squares (MLS) Implicit Surface Reconstruction is a technique for reconstructing a surface from an unordered 3D point cloud by creating an implicit function field using Moving Least Squares, from which isosurfaces are extracted. It differs from its parent [MLS Projection](823-mls-projection.md) by constructing a global implicit field defined by local quadratic fits rather than iteratively projecting query points, and from its sibling [APSS](843-apss-approximate-projected-point-set-surfaces.md) by relying on a standard MLS approximation of the signed distance function rather than approximate projected point set surfaces.

### Kernel Functions for MLS
A set of kernel functions used to weight neighbors in MLS surface reconstruction based on distance $r$ and scale $h$ [S2, unofficial].
*   **Gaussian** (`kernel_type=0`): $K(r) = e^{-r^2/h^2}$ [S2, unofficial].
*   **Wendland** (`kernel_type=1`): $K(r) = (1 - r/h)^4 (1 + 4r/h)$ [S2, unofficial].
*   **Singular** (`kernel_type=2`): $K(r) = (r/h)^{-w}$ [S2, unofficial].

## Operating characteristics

*   **Time Complexity:** $O(I_{max} \cdot knn \cdot \log N)$ per query point, where $N$ is the number of input points, due to K-D tree search and $knn$ neighbor iterations.
*   **Memory Complexity:** $O(N)$ to store the input point set and K-D tree.
*   **Strengths:** Produces very smooth surfaces; robust to noise in input normals and positions; handles varying point densities well via local radius/weighting [S3].
*   **Limitations:** Computationally expensive per point compared to linear methods like Surface Nets; requires careful tuning of $knn$ and $h$; iterative nature can be slow for large point clouds [S3].
*   **When to use:** High-quality surface reconstruction from noisy point clouds; when smooth normals are critical.
*   **When not to use:** Real-time applications requiring immediate feedback; extremely large datasets where linear approximations suffice.

## Background

MLS Projection was developed as part of the Hermite Point Set Surfaces (HPSS) framework [S2, unofficial]. It is based on the Moving Least Squares method for implicit surface reconstruction, which fits local polynomials to weighted data points [S3]. The method was popularized in the context of dual contouring and surface nets to provide a robust way to evaluate the implicit function and its gradient at grid vertices or query points [S2, unofficial]. The parabolic case handling is described in multiresolution modeling literature for scientific visualization [S1, unofficial].
