# Remeshing

Also called: post-processing remeshing, mesh sharpening

## Overview
Remeshing is a post-processing step applied to offset meshes generated by methods such as Alpha Wrapping or Minkowski sum approximations to reduce distance error ($\varepsilon_m$) and normal deviation ($\sigma_m$) from the exact offset, reconstruct sharp features (e.g., concave creases), and improve triangle shape quality [S1]. Unlike Alpha Wrapping, which does not recover sharp features, this step reconstructs concave creases and reduces discretization error [S1]. Compared to Minkowski sum approximations, it produces significantly fewer triangles and eliminates self-intersections present in the raw Minkowski outputs [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** An offset mesh (e.g., from Alpha Wrapping or Minkowski sum approximation) and a maximum normal deviation parameter $\sigma_{max}$ [S1].
*   **Output:** A remeshed mesh with reduced error and improved quality [S1].

**Data Structures:**
The method operates on the mesh topology (vertices, edges, faces) of the input offset mesh [S1]. No specific auxiliary data structures are defined in the sources beyond the mesh itself [S1].

**Parameters:**
*   $\sigma_{max}$: Maximum normal deviation parameter used to control refinement during remeshing. Typical values include $3^\circ, 5^\circ, 10^\circ, 15^\circ, 20^\circ$ depending on the offset radius $\delta$ ($5\%, 10\%, 15\%$) [S1].
*   $\delta$: Offset radius (contextual parameter for the input mesh generation, not directly a remeshing parameter, but influences $\sigma_{max}$ selection) [S1].

**Steps:**
1.  **Initialize:** Set the current mesh $M$ to the input offset mesh [S1]. Initialize iteration counter $k = 0$ [G].
2.  **Iterate:** While convergence criteria are not met (typically a small number of iterations, e.g., 6–9), apply remeshing operations to $M$ to reduce distance and normal deviation [S1]. Increment $k$ [G].
3.  **Terminate:** Output the final mesh $M$ [S1].

**Formulas:**
*   $\varepsilon_m$: Discretization error (distance error) [S1].
*   $\sigma_m$: Normal deviation [S1].
*   Both $\sigma_m$ and $\varepsilon_m$ correlate to $\sigma_{max}$, independent of the offset radius $\delta$ [S1].

**Edge Cases and Pitfalls:**
*   **Over-refinement:** Over-refinement in convex regions is avoided by setting a maximum normal deviation limit (e.g., $15^\circ$) during remeshing [S1].
*   **Self-intersections:** While the remeshing step removes self-intersections present in Minkowski sum approximations, it cannot guarantee the absence of self-intersections caused by offset meshes that are topologically different from the exact offset [S1].
*   **Predictability:** The running time is hard to predict because the number and size of features in the offset surface are unknown a priori [S1].

## Operating characteristics
*   **Time Complexity:** The running time is hard to predict because the number and size of features in the offset surface are unknown a priori [S1].
*   **Memory Complexity:** Not given in the sources [S1].
*   **Measured Performance:**
    *   On the anchor model with $\delta = 2\%$ and $\sigma_{max} = 3^\circ$, remeshing reduces $\varepsilon_m$ from $1.59\%$ to $0.09\%$ and $\sigma_m$ from $4.86^\circ$ to $1.02^\circ$ after 9 steps [S1].
    *   On the degree-three corner model, remeshing reduces $\sigma_m$ from $6.5^\circ$ to $2.6^\circ$ and $\varepsilon_m$ from $14\%$ to $0.7\%$ [S1].
    *   On the screw nut model, remeshing reduces $\sigma_m$ from $10^\circ$ to $2.8^\circ$ and $\varepsilon_m$ from $13\%$ to $0.9\%$ [S1].
    *   For an absolute offset of $0.035$, the Minkowski sum approximation has $1,051,354$ triangles, while the proposed method yields $65,528$ triangles [S1]. After remeshing the Minkowski output, complexity reduces to $73,772$ triangles [S1].
*   **Strengths:** Reduces discretization error, reconstructs sharp features (concave creases), improves triangle shape quality, and eliminates self-intersections from Minkowski sum approximations [S1].
*   **Limitations:** Cannot guarantee the absence of self-intersections if the offset mesh is topologically different from the exact offset; running time is unpredictable; strict upper bound on Hausdorff error is an open problem [S1].
*   **When to use:** When post-processing offset meshes from Alpha Wrapping or Minkowski sum approximations to improve mesh quality and remove self-intersections [S1].
*   **When not to use:** When a strict upper bound on Hausdorff error is required or when the input offset mesh has topological differences from the exact offset that cannot be resolved by post-processing [S1].

## Background
*   **Origin:** The remeshing method was introduced in the paper "Feature-Preserving Offset Mesh Generation from Topology-Adapted Octrees" by D. Zint, N. Maruani, P. Alliez, and M. Rouxel-Labbé, submitted to the Eurographics Symposium on Geometry Processing (2023) [S1].
*   **History:** It is part of a pipeline that first applies Dual Contouring on an adaptive octree and then applies this remeshing step to reconstruct sharp features and reduce deviation [S1].
*   **Usage:** It is applied to outputs of Alpha Wrapping [PRH*22] and Minkowski sum approximations [CK10b] [S1].
