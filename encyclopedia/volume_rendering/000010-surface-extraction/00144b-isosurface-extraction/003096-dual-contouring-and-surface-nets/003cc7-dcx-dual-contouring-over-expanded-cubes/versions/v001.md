# DCx (Dual Contouring over Expanded Cubes)
Also called: Dual Contouring over Expanded Cubes

## Overview
DCx is an isosurface extraction method designed to reconstruct zero-level sets from neural Unsigned Distance Functions (UDFs), addressing the fundamental lack of sign information in UDFs which prevents standard Dual Contouring from functioning [S1]. It differs from its siblings by replacing sign-based active cube detection with an optimization-based projection strategy and operating on 2x2x2 "expanded cubes" with a voxel-to-mesh lookup table, enabling robust reconstruction of non-manifold structures in a single-layer mesh [S1]. Unlike [Surface Nets](921-surface-nets.md) which rely on edge intersections, or [Dual Contouring](778-dual-contouring.md) which requires sign changes, DCx projects voxel centroids to the zero-level set to define active regions and aggregates connectivity over overlapping 2x2x2 blocks to handle sparse or irregular active cube distributions [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A neural Unsigned Distance Function (UDF) $u(\mathbf{x})$ defined on a regular 3D grid of resolution $N \times N \times N$.
*   **Output:** A single-layer triangle mesh representing the zero-level set $\{ \mathbf{x} \mid u(\mathbf{x}) = 0 \}$.

**Data Structures:**
*   **Grid:** A 3D array storing UDF values $u_{i,j,k}$ at voxel centers $(i,j,k)$ for $0 \le i,j,k < N$.
*   **Expanded Cube:** A 2x2x2 block of voxels. Adjacent expanded cubes overlap, sharing 2x2x1 voxels.
*   **V2M Lookup Table:** A mapping from the binary configuration of 8 voxels (active/inactive) within an expanded cube to a set of mesh connectivity patterns (faces/edges) on the dual cube vertices.
*   **Point Set:** A set of 3D points $\mathcal{P}$ representing projected centroids.

**Parameters:**
*   **Grid Resolution ($N$):** Typically 256 [S1].
*   **Threshold $\tau_0$:** Initial selection threshold. $\tau_0 = 1.5/N$ [S1].
*   **Threshold $\tau_1$:** Supplementary sampling threshold. $\tau_1 = 0.5/N$ [S1].
*   **Optimizer:** Vector Adam [Ling et al. 2022] [S1].
    *   Learning rate: 0.01 [S1].
    *   Iterations: 200 [S1].

**Algorithm Steps:**

1.  **Sampling and Optimization (Active Cube Definition):**
    Since UDFs lack sign changes, active cubes are defined by occupancy of projected points.
    1.  Initialize point set $\mathcal{P}_{init}$: For each voxel centroid $\mathbf{c}_{i,j,k}$, if $u(\mathbf{c}_{i,j,k}) \le \tau_0$, add $\mathbf{c}_{i,j,k}$ to $\mathcal{P}_{init}$ [S1].
    2.  Optimize points: For each point $\mathbf{p}_i \in \mathcal{P}_{init}$, restrict motion to the gradient direction $\nabla u(\mathbf{p}_i)$ to ensure uniformity and stability [S1]. Solve the 1D line search:
        $$ \min_{s_i} u(\mathbf{p}_i + s_i \nabla u(\mathbf{p}_i)) $$
        using the vector Adam optimizer for 200 iterations with learning rate 0.01 [S1]. Let the optimized points be $\mathcal{P}_{op}$ [S1].
    3.  Mark Active Cubes: A cube is active if its centroid's projection (from $\mathcal{P}_{op}$) lies within the cube. The computed dual vertex is naturally confined within the local region, eliminating the need for corrective clamping [S1].

2.  **Supplementary Sampling:**
    To improve completeness near under-sampled boundary regions, perform additional sampling. For voxel centroids where $u(\mathbf{c}) < \tau_1$, add them to the point set and repeat the optimization step (Step 1.2) [S1].

3.  **Thinning (Noise and Artifact Removal):**
    Remove redundant voxels to enforce unit-thickness and resolve Case 8 structural constraints [S1].
    *   **Condition 1 (Reconstruction Failure):** Iterate over all expanded cubes classified as Case 8. If a voxel fails to meet structural requirements for Case 8, delete that voxel. Repeat until no further voxels are removed [S1].
    *   **Condition 2 (Redundant Non-manifold):** For every active cube and its 3x3x3 neighborhood, remove a redundant voxel if all edges connected to the active voxel are boundary edges and at least one endpoint is on non-manifold edges. Repeat until no such voxels are removed [S1].

4.  **Meshing via V2M Lookup Table:**
    1.  Examine all 2x2x2 expanded cubes spanning the grid [S1].
    2.  For each expanded cube, determine the binary configuration of its 8 voxels (active/inactive) [S1].
    3.  Consult the V2M Lookup Table to retrieve the corresponding mesh connectivity pattern (faces/edges) for the dual cube vertices (the 8 cubes in the expanded cube) [S1].
    4.  Generate faces by connecting all active vertices corresponding to active cubes within the expanded cube [S1].
    5.  Aggregate case IDs of adjacent expanded cubes to achieve a polygonization criterion with an effective receptive field of 4x4x4, ensuring consistency across overlapping regions [S1].

5.  **Post-processing:**
    Refine the extracted mesh using the optimization procedure from DCUDF to decrease Chamfer Distance (only if the input is a learned neural UDF, not ground-truth) [S1]. This step removes residual redundant non-manifold elements and enhances mesh quality [S1].

## Subtopics

### [DCx Limitations and Constraints](9345-dcx-limitations-and-constraints.md)
DCx faces inherent topological and resolution constraints that prevent it from guaranteeing strictly manifold surfaces. It cannot natively support arbitrary non-manifold structures without post-processing, and its ability to resolve geometric details is strictly bound by grid resolution.

## Operating characteristics
*   **Time Complexity:** The method involves iterating over all voxels for sampling and optimization, and then over all expanded cubes for meshing. The projection step is the most expensive, scaling with the number of initial points and iterations.
*   **Memory Complexity:** Requires storing the UDF grid, optimized point sets, and the V2M lookup table. The lookup table size is constant ($2^8$ entries), but the mesh size scales with the number of active cubes.
*   **Measured Performance:** At resolution $N=256$, the runtime breakdown is: UDF Computation 22ms, Projection 5984ms, Voxelization 71ms, Thinning 519ms, Supplementary Sampling 1566ms, V2M LUT 107ms, Post-processing 1588ms [S1]. At $N=512$, Projection takes 14414ms and Post-processing 4929ms [S1]. At $N=1024$, Projection takes 61749ms and Post-processing 27011ms [S1].
*   **Strengths:** Produces single-layer, intersection-free meshes for both manifold and non-manifold inputs without supervision. More robust to noise and local minima than NDF (which uses SGD) and avoids the double-layer entanglement of DCUDF [S1].
*   **Limitations:** High-curvature regions can cause topological artifacts due to ambiguity between high-curvature features and non-manifold geometry. Increasing grid resolution mitigates these errors but increases computational cost [S1]. Cannot guarantee strictly manifold surfaces [S1].
*   **When to use:** When extracting surfaces from neural UDFs where non-manifold structures are present and a single-layer mesh is required.
*   **When not to use:** When strict manifold topology is required without post-processing, or when computational resources are limited for high-resolution grids.

## Background
DCx was proposed as an extension of the standard Dual Contouring algorithm [Ju et al. 2002] to address the challenges of extracting meshes from neural Unsigned Distance Functions (UDFs) [S1]. Standard Dual Contouring relies on sign changes in Signed Distance Functions (SDFs) to identify active cubes, which is not possible with UDFs. DCx introduces optimization-based active cube detection and expanded cube face construction to handle the lack of sign information and support non-manifold structures [S1]. The method was developed by researchers including Ying He from Nanyang Technological University [S1].
