# Surface Nets

Also called: Naive Surface Nets

## Overview
Surface Nets is an isosurface extraction algorithm that constructs a mesh by placing a single vertex per active voxel (cube) at the weighted average of the grid points on the cube's edges that cross the isosurface [S1, unofficial][S2, unofficial][S3, unofficial]. Unlike [Marching Cubes](774-marching-cubes.md), which interpolates along every intersected edge and can produce multiple vertices per cell, Surface Nets generates exactly one vertex per voxel where the surface passes through, resulting in a sparser mesh with fewer vertices and triangles [S1, unofficial]. Compared to [Dual Contouring](778-dual-contouring.md), it requires no normals or linear solves but yields less accurate vertex placement [S2, unofficial].

## How it works
**Inputs:** A 3D scalar field grid `data` of dimensions `dims[0] x dims[1] x dims[2]`, an isovalue `level`, and a boolean `storeFlag` indicating whether to store geometry or count it [S1, unofficial].
**Outputs:** A mesh structure containing a list of vertices `p` (float3) and a list of triangle indices `t` (int3) [S1, unofficial].

**Data Structures:**
*   `edge_table[256]`: A lookup table mapping the 8-bit vertex configuration mask of a voxel to a 12-bit mask indicating which of the 12 cube edges are intersected by the isosurface [S1, unofficial].
*   `cube_edges[24]`: An array storing the indices of the two vertices defining each of the 12 edges of a unit cube, used to unpack edge geometry [S1, unofficial].
*   `buffer`: A temporary storage mapping voxel coordinates to vertex indices, used to facilitate triangle generation without global vertex merging [S1, unofficial].

**Preprocessing:**
1.  Call `init_surfacenets()` to populate `cube_edges` and `edge_table` [S1, unofficial].
    *   `cube_edges` is populated by iterating all 8 vertices `i` and finding neighbors `p` that differ by exactly one bit (Hamming distance 1), storing pairs `(i, p)` [S1, unofficial].
    *   `edge_table` is computed by iterating all 256 masks. For each mask, it checks all 12 edges defined in `cube_edges`. An edge is marked as intersected if the signs of the two corner vertices differ (i.e., `!(i & (1<<e0)) != !(i & (1<<e1))`) [S1, unofficial].

**Algorithm Steps:**
1.  Initialize `vertices_length = 0`, `faces_length = 0`, and `buf_no = 1` [S1, unofficial].
2.  Define stride arrays `R` for the grid: `R[0] = 1`, `R[1] = dims[0] + 1`, `R[2] = (dims[0] + 1) * (dims[1] + 1)` [S1, unofficial].
3.  Iterate through each voxel cube in the grid with coordinates `x` from `0` to `dims[0]-2`, `y` from `0` to `dims[1]-2`, and `z` from `0` to `dims[2]-2` [S1, unofficial].
4.  For each voxel, sample the 8 corner values into a local `grid` array and compute a binary `mask` where bit `g` is set if `data[idx] - level < 0` [S1, unofficial].
5.  If `mask` is `0` or `0xff` (all corners on the same side of the isosurface), skip the voxel [S1, unofficial].
6.  Retrieve the intersected edges for the current mask: `edge_mask = edge_table[mask]` [S1, unofficial].
7.  Initialize a vertex accumulator `v` to `(0,0,0)` and an edge counter `e_count` to `0` [S1, unofficial].
8.  Iterate through the 12 edges of the cube (index `i` from `0` to `11`) [S1, unofficial]:
    *   If the `i`-th bit of `edge_mask` is not set, skip the edge [S1, unofficial].
    *   Increment `e_count` [S1, unofficial].
    *   Unpack the two corner indices `e0` and `e1` from `cube_edges[i*2]` and `cube_edges[i*2+1]` [S1, unofficial].
    *   Retrieve their grid values `g0` and `g1` [S1, unofficial].
    *   Compute the interpolation parameter `t`. If `|g0 - g1| > 1e-6`, set `t = g0 / (g0 - g1)`; otherwise, skip this edge's contribution to avoid division by zero [S1, unofficial].
    *   Accumulate the interpolated point into `v`. For each dimension `j` (0 to 2):
        *   Check if the edge spans dimension `j` by comparing bits of `e0` and `e1` at position `j` [S1, unofficial].
        *   If they differ, add `1.0 - t` if `e0` has the bit set, else add `t` [S1, unofficial].
        *   If they do not differ, add `1.0` if `e0` has the bit set, else add `0` [S1, unofficial].
9.  Compute the final vertex position: `v[j] = x[j] + (1.0 / e_count) * v[j]` for each dimension `j` [S1, unofficial].
10. Store the vertex index in `buffer` at position `m` (where `m` tracks the voxel's position in the flattened grid structure) and increment `vertices_length` [S1, unofficial]. If `storeFlag` is true, store the coordinates in `vertices[vertices_length-1]` [S1, unofficial].
11. Generate triangles for the voxel. Iterate through the first 3 edges (indices `0`, `1`, `2`) of the cube [S1, unofficial]:
    *   If the edge is not intersected (`!(edge_mask & (1<<i))`), skip [S1, unofficial].
    *   Determine two adjacent edges `iu = (i+1)%3` and `iv = (i+2)%3` [S1, unofficial].
    *   If either adjacent edge lies on a boundary (coordinate `0` in that dimension), skip triangle generation for this combination to avoid out-of-bounds access [S1, unofficial].
    *   Compute relative strides `du = R[iu]` and `dv = R[iv]` [S1, unofficial].
    *   Create two triangles using the current vertex index `buffer[m]` and the buffered indices of the adjacent voxels [S1, unofficial]:
        *   If `mask & 1` is true (corner `0` is below isosurface):
            *   Triangle 1: `(buffer[m], buffer[m-du-dv], buffer[m-du])` [S1, unofficial].
            *   Triangle 2: `(buffer[m], buffer[m-dv], buffer[m-du-dv])` [S1, unofficial].
        *   Else:
            *   Triangle 1: `(buffer[m], buffer[m-du], buffer[m-du-dv])` [S1, unofficial].
            *   Triangle 2: `(buffer[m], buffer[m-du-dv], buffer[m-dv])` [S1, unofficial].
    *   Increment `faces_length` by 2 for each pair [S1, unofficial].
12. After processing all voxels, set `mesh->np = vertices_length` and `mesh->nt = faces_length` [S1, unofficial].

**Pseudocode:**
```python
def init_surfacenets():
    cube_edges = []
    for i in range(8):
        for j in [1, 2, 4]:
            p = i ^ j
            if i <= p:
                cube_edges.append(i)
                cube_edges.append(p)
    
    edge_table = [0] * 256
    for i in range(256):
        em = 0
        for j in range(0, 24, 2):
            e0 = cube_edges[j]
            e1 = cube_edges[j+1]
            # Check if edge crosses surface: signs of vertices differ
            # Assuming mask bit g is 1 if data < level
            val0 = (i & (1 << e0)) == 0
            val1 = (i & (1 << e1)) == 0
            if val0 != val1:
                em |= (1 << (j >> 1))
        edge_table[i] = em
    return cube_edges, edge_table

def surface_nets(data, dims, level, store_flag):
    cube_edges, edge_table = init_surfacenets()
    
    vertices = []
    triangles = []
    buffer = {} # Map from voxel coordinate tuple to vertex index
    
    # Strides for 3D grid indexing
    R = [1, dims[0] + 1, (dims[0] + 1) * (dims[1] + 1)]
    
    for x in range(dims[0] - 1):
        for y in range(dims[1] - 1):
            for z in range(dims[2] - 1):
                # Sample 8 corners
                grid = []
                mask = 0
                for k in range(2):
                    for j in range(2):
                        for i in range(2):
                            idx = x + i + dims[0] * (y + j + dims[1] * (z + k))
                            val = data[idx] - level
                            grid.append(val)
                            if val < 0:
                                mask |= (1 << (k * 4 + j * 2 + i))
                
                if mask == 0 or mask == 0xFF:
                    continue
                
                edge_mask = edge_table[mask]
                v_accum = [0.0, 0.0, 0.0]
                e_count = 0
                
                for i in range(12):
                    if not (edge_mask & (1 << i)):
                        continue
                    
                    e_count += 1
                    e0 = cube_edges[i * 2]
                    e1 = cube_edges[i * 2 + 1]
                    g0 = grid[e0]
                    g1 = grid[e1]
                    
                    diff = g0 - g1
                    if abs(diff) > 1e-6:
                        t = g0 / diff
                    else:
                        continue
                    
                    # Accumulate weighted position
                    # Check which dimensions the edge spans
                    for dim in range(3):
                        bit = 1 << dim
                        has_e0 = (e0 & bit) != 0
                        has_e1 = (e1 & bit) != 0
                        
                        if has_e0 != has_e1:
                            # Edge spans this dimension
                            if has_e0:
                                v_accum[dim] += 1.0 - t
                            else:
                                v_accum[dim] += t
                        else:
                            # Edge does not span this dimension
                            if has_e0:
                                v_accum[dim] += 1.0
                            else:
                                v_accum[dim] += 0.0
                
                # Average and offset by voxel position
                if e_count > 0:
                    inv_count = 1.0 / e_count
                    vertex_pos = [
                        x + inv_count * v_accum[0],
                        y + inv_count * v_accum[1],
                        z + inv_count * v_accum[2]
                    ]
                else:
                    vertex_pos = [x + 0.5, y + 0.5, z + 0.5] # Fallback [G]
                
                vertex_idx = len(vertices)
                buffer[(x, y, z)] = vertex_idx
                
                if store_flag:
                    vertices.append(vertex_pos)
                
                # Generate triangles
                for i in range(3):
                    if not (edge_mask & (1 << i)):
                        continue
                    
                    iu = (i + 1) % 3
                    iv = (i + 2) % 3
                    
                    # Check boundary: if coordinate in dimension iu or iv is 0, skip
                    coord_iu = [x, y, z][iu]
                    coord_iv = [x, y, z][iv]
                    if coord_iu == 0 or coord_iv == 0:
                        continue
                    
                    # Neighbor coordinates (subtract 1 in respective dimensions)
                    nx1 = x - (1 if iu == 0 else 0)
                    ny1 = y - (1 if iu == 1 else 0)
                    nz1 = z - (1 if iu == 2 else 0)
                    
                    nx2 = x - (1 if iv == 0 else 0)
                    ny2 = y - (1 if iv == 1 else 0)
                    nz2 = z - (1 if iv == 2 else 0)
                    
                    nx3 = x - (1 if iu == 0 else 0) - (1 if iv == 0 else 0)
                    ny3 = y - (1 if iu == 1 else 0) - (1 if iv == 1 else 0)
                    nz3 = z - (1 if iu == 2 else 0) - (1 if iv == 2 else 0)
                    
                    idx1 = buffer[(nx1, ny1, nz1)]
                    idx2 = buffer[(nx2, ny2, nz2)]
                    idx3 = buffer[(nx3, ny3, nz3)]
                    
                    if mask & 1:
                        triangles.append((vertex_idx, idx3, idx2))
                        triangles.append((vertex_idx, idx2, idx1))
                    else:
                        triangles.append((vertex_idx, idx2, idx3))
                        triangles.append((vertex_idx, idx3, idx1))

    return vertices, triangles
```

## Subtopics

### [JSurfaceNets](1040-jsurfacenets.md)
An isosurface extraction algorithm that generates a quad-mesh by placing vertices at the average of edge-crossing points on the grid cells, serving as a substitute for Marching Cubes. It differs from the standard triangle-based Surface Nets by outputting quads.

## Operating characteristics
**Time Complexity:** $O(N)$ where $N$ is the number of voxels, as it iterates through each voxel a constant number of times (12 edge checks, 3 triangle checks) [S3, unofficial].
**Memory Complexity:** $O(N)$ for storing the vertex and triangle buffers [S1, unofficial].
**Performance:** The method is generally faster and uses less memory than Marching Cubes due to the reduced number of vertices and triangles [S1, unofficial].
**Strengths:** Simplicity of implementation; no need for normals or linear solvers [S2, unofficial].
**Limitations:** Less accurate vertex placement compared to Dual Contouring or Marching Cubes; can produce artifacts if the isosurface is not well-sampled within the voxel [S2, unofficial].
**When to use:** When vertex count reduction is prioritized over geometric accuracy, or when normals/solvers are unavailable [S1, unofficial][S2, unofficial].
**When not to use:** When high geometric accuracy or smooth shading is required [S2, unofficial].

## Background
Surface Nets was introduced by [Mikola Lysenko](http://0fps.net/2012/07/12/smooth-voxel-terrain-part-2/) in 2012 for smooth voxel terrain generation [S1, unofficial]. It was later translated to C by Roberto Toro [S1, unofficial]. The method is based on the principle of placing dual vertices at the centroid of intersection points, a concept related to dual contouring but without the optimization step [S2, unofficial].
