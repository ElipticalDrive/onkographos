# Critical Isovalue Detection

Also called: Detecting Critical Isovalues

## Overview
Critical isovalues are specific scalar field values at which the topology of the isosurface undergoes a fundamental change, such as the creation or vanishing of surface components, the merging of disjoint components, or the formation of holes (changes in genus) [S1]. This method detects these values in scalar fields defined by piecewise trilinear interpolation over a rectilinear grid, enabling efficient exploration of large datasets by highlighting topologically significant features [S1]. It differs from general isosurface extraction by focusing solely on identifying the scalar values where topological events occur, rather than generating the geometry itself, and relies on the assumption that the subsequent extraction method (e.g., a topologically correct Marching Cubes variant) preserves the trilinear topology [S1].

## How it works
**Inputs and Outputs:**
- **Input:** A scalar field $f(\mathbf{x})$ defined on a regular rectilinear grid, where values are given at vertices. The field is interpolated using piecewise trilinear interpolation within cells.
- **Output:** A set of critical isovalues and their corresponding locations (vertices, faces, or cell interiors) where topological changes occur.

**Data Structures and Assumptions:**
- The grid is a regular rectilinear grid.
- Interpolation is piecewise trilinear.
- **Restriction:** Function values at vertices connected by an edge must differ ($f(v_i) \neq f(v_j)$ for edge-connected $v_i, v_j$) to avoid degenerate cases where an entire edge becomes critical [S1].
- Maxima and minima can only occur at cell vertices due to the convex hull property of trilinear interpolation [S1].
- Saddles can occur at vertices, on cell faces, or in cell interiors, but not on cell edges (due to the edge value restriction) [S1].

**Steps:**

1.  **Classify Edges:**
    - Apply Lemma 1: All points on edges with distinct edge-connected values are regular points. No critical isovalues exist on edges under the given restriction [S1].

2.  **Classify Vertices:**
    - For each vertex $v$, consider its 6 edge-connected neighbors.
    - Construct a local implicit tetrahedrization using $v$ and subsets of its neighbors [S1].
    - Apply the local implicit tetrahedrization criterion (Lemma 3) [S1]:
        - Determine the signs of the function values at the neighbors relative to $f(v)$.
        - Use the case table derived from Gerstner and Pajarola's criterion for connected components in an edge graph, which has $2^6 = 64$ entries [S1].
        - Classify $v$ as a local maximum, local minimum, or saddle based on the connectivity of the positive and negative regions in the implicit tetrahedron [S1].
        - If classified as a critical point, record $f(v)$ as a critical isovalue [S1].

3.  **Classify Faces:**
    - For each cell face, the interpolation reduces to bilinear interpolation [S1].
    - Check for bilinear saddles on the face. A bilinear saddle exists if the signs of the four face vertices allow for a hyperbolic contour separation (standard bilinear ambiguity check) [S1].
    - Apply Lemma 4: A face saddle is a trilinear saddle if and only if:
        - The bilinear saddle condition holds.
        - The connectivity signs in the two adjacent cells sharing the face match. Specifically, both adjacent cells must connect the same two disjoint regions (either both connect the two positive regions or both connect the two negative regions) [S1].
        - If both conditions are met, the saddle value on the face is a critical isovalue [S1].

4.  **Classify Cell Interiors:**
    - Detect critical values inside cells. Interior saddles of the trilinear interpolant are always saddles of the piecewise trilinear interpolant [S1].
    - Compute interior saddles using the equations provided by Nielson [S1].
    - Note: Trilinear interpolation assigns constant values to certain boundary configurations; ensure that interior saddles coinciding with boundaries are not double-counted or misclassified as piecewise saddles if they are not true saddles of the global piecewise function [S1].

**Edge Cases and Pitfalls:**
- **Equal Edge Values:** If two edge-connected vertices have equal values, the entire edge may be critical, making local determination impossible. The method imposes a restriction that these values must differ [S1].
- **Implicit Disambiguation Incompatibility:** If 'implicit disambiguation' (Montani et al.) is used for isosurface extraction, determining if a vertex is critical requires considering more vertices than for the correct trilinear contour. ## Subtopics

### Critical Point Detection in Piecewise Trilinear Interpolation
A method to detect critical isovalues for piecewise trilinear scalar fields on rectilinear grids, which are generally only C0-continuous. It restricts detection to vertices and cell interiors/faces, excluding edges. It imposes the restriction that function values at vertices connected by an edge must differ to avoid degenerate edge cases. Edges with distinct edge-connected values are classified as regular points (Lemma 1). Vertices are classified using the local implicit tetrahedrization criterion (Lemma 3) based on the 6 edge-connected neighbors. Faces are checked for saddles where trilinear interpolation reduces to bilinear interpolation; a face saddle is a trilinear saddle if the bilinear saddle condition holds AND the connectivity signs in adjacent cells match (Lemma 4). Cell interiors are detected using Nielson's equations. Maxima and minima can only occur at cell vertices due to the convex hull property. If two edge-connected vertices have equal values, the entire edge may be critical, making local determination impossible [S1].

## Operating characteristics
- **Time Complexity:** Not explicitly given in the sources. The method involves iterating over vertices, faces, and cells, with constant-time classification per element (e.g., 64-entry lookup for vertices, bilinear check for faces).
- **Memory Complexity:** Not explicitly given. Requires storage for the grid, values, and the set of critical isovalues.
- **Strengths:** Provides a complete set of topological changes for trilinear fields, aiding in efficient data exploration by highlighting "interesting" isosurface behavior. It is compatible with topologically correct Marching Cubes variants.
- **Limitations:** Requires the restriction that edge-connected vertex values differ. Not compatible with implicit disambiguation methods without modification. Boundary handling is not fully specified.
- **When to use:** When exploring large trivariate datasets and needing to identify topological changes in isosurfaces defined by trilinear interpolation.
- **When not to use:** When using implicit disambiguation for isosurface extraction, or when the data contains equal values at edge-connected vertices without pre-processing.

## Background
The method was presented by researchers from the University of Kaiserslautern, Germany, and the University of California, Davis, U.S.A. It is described in the paper "Exploring Scalar Fields Using Critical Isovalues" [S1]. The work builds on the Marching Cubes (MC) algorithm introduced by Lorensen and Cline, aiming to preserve the topology of the trilinear interpolant. It reviews varieties of MC and combines them with critical isovalue detection to aid in data exploration. The method references Nielson for interior saddle computation and Gerstner and Pajarola for the vertex classification criterion [S1].
