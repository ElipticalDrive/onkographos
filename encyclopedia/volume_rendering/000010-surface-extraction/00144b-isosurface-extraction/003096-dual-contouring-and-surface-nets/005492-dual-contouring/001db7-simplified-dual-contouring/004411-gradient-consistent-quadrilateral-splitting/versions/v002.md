# Gradient-Consistent Quadrilateral Splitting

Also called: dual vertex quad triangulation, gamma-based quad splitting

## Overview
Gradient-Consistent Quadrilateral Splitting is a post-processing step that splits quadrilaterals formed by four neighboring dual vertices into triangles using a gamma parameter derived from gradient consistency or scalar field values [S1, unofficial]. It resolves quad triangulation ambiguity by selecting diagonal splits based on the dot product of normalized gradients at opposite vertices, differing from sibling methods by relying on this fixed gamma-based heuristic rather than adaptive geometric criteria [S1, unofficial].

## How it works
The method takes the quadrilateral mesh generated by Simplified Dual Contouring and splits each quad into triangles [S1, unofficial]. It operates on quads formed by four dual vertices that share a common surface edge in the voxel grid [S1, unofficial].

**Inputs:**
- `vd_idx`: Tensor of dual vertex indices.
- `edge_counts`: Count of cubes sharing each edge.
- `surf_edges_mask`: Boolean mask identifying edges intersected by the surface.
- `normals`: Surface normals at dual vertices (used if gradient function is not provided).
- `dual_vertices`: 3D coordinates of dual vertices.
- `grad_func`: Optional gradient function to compute normals. If `None`, normals are taken from input.
- `training`: Boolean flag. If `True`, uses differentiable splitting for gradient-based optimization; if `False`, uses hard selection [S1, unofficial].

**Outputs:**
- `faces`: Tensor of triangle indices (shape $(-1, 3)$).
- `vertices`: Updated vertex buffer (only in training mode, contains new center vertices) [S1, unofficial].

**Data Structures:**
- `quad_vd_idx`: Shape $(-1, 4)$ long tensor. Stores indices of the 4 dual vertices forming each quadrilateral in counter-clockwise order [S1, unofficial].
- `quad_gamma`: Shape $(-1, 4, 3)$ tensor. Stores normalized gradient vectors at the 4 vertices of each quad [S1, unofficial].

**Steps:**

1.  **Identify Surface Quads:**
    Identify edges shared by exactly 4 cubes (internal surface edges) that are also part of the surface using a boolean mask:
    $$ \text{group\_mask} = (\text{edge\_counts} == 4) \land \text{surf\_edges\_mask} $$
    Gather the dual vertex indices associated with these edges, sort them stably, and reshape into quads:
    $$ \text{quad\_vd\_idx} = \text{vd\_idx}[\text{indices}].\text{reshape}(-1, 4) $$

2.  **Enforce Consistent Winding:**
    Ensure all quads have consistent counter-clockwise winding by checking the sign of the first component of the surface normal at the quad's first edge ($s\_edges[:, 0]$).
    - If $s\_edges[:, 0] > 0$, reorder vertices to $[0, 1, 3, 2]$.
    - Otherwise, reorder vertices to $[2, 3, 1, 0]$.

3.  **Compute Gradient Consistency (Gamma):**
    Compute the "gamma" values, which represent the dot product of normalized gradients at opposite vertices.
    - If `grad_func` is provided, compute normalized gradients at the dual vertices and index them into `quad_gamma` of shape $(-1, 4, 3)$.
    - Compute dot products for diagonals $(0, 2)$ and $(1, 3)$:
      $$ \gamma_{02} = \sum_{k} \text{quad\_gamma}[:, 0, k] \cdot \text{quad\_gamma}[:, 2, k] $$
      $$ \gamma_{13} = \sum_{k} \text{quad\_gamma}[:, 1, k] \cdot \text{quad\_gamma}[:, 3, k] $$
    - If `grad_func` is `None`, use pre-computed normals similarly [S1, unofficial].

4.  **Split Quads:**
    - **Inference Mode (`not training`):**
      Compare $\gamma_{02}$ and $\gamma_{13}$. Create a zero-initialized face tensor of shape $(-1, 6)$. Apply `self.quad_split_1` indices where $\gamma_{02} > \gamma_{13}$, else apply `self.quad_split_2`. Reshape the resulting face tensor from $(-1, 6)$ to $(-1, 3)$ triangles [S1, unofficial].
    - **Training Mode (`training`):**
      Compute diagonal midpoints:
      $$ v_{02} = \frac{v_0 + v_2}{2}, \quad v_{13} = \frac{v_1 + v_3}{2} $$
      Calculate a weighted center vertex $v_c$:
      $$ v_c = \frac{v_{02} \cdot \gamma_{02} + v_{13} \cdot \gamma_{13}}{\gamma_{02} + \gamma_{13} + 10^{-8}} $$
      Append $v_c$ to the vertex buffer. Split each quad into 4 triangles sharing $v_c$ using `self.quad_split_train` [S1, unofficial].

**Pseudocode:**

```python
def gradient_consistent_quad_splitting(quad_vd_idx, dual_vertices, normals, training=False):
    """
    Splits quadrilaterals from Simplified Dual Contouring into triangles
    based on gradient consistency.
    
    Args:
        quad_vd_idx: Tensor of shape (-1, 4) storing quad vertex indices.
        dual_vertices: Tensor of vertex positions (num_verts, 3).
        normals: Tensor of normals at dual vertices (num_verts, 3).
        training: Boolean flag for differentiable splitting.
        
    Returns:
        faces: Tensor of triangle indices (num_faces, 3).
        new_vertices: Tensor of updated vertices (only if training=True).
    """
    # Step 1: Identify quads (assumed pre-filtered as per source logic)
    # group_mask = (edge_counts == 4) & surf_edges_mask
    # quad_vd_idx = vd_idx[indices].reshape(-1, 4)
    
    # Step 2: Enforce consistent winding
    first_norm = normals[quad_vd_idx[:, 0]]
    reorder_mask = first_norm[:, 0] > 0
    reorder_idx = [[0, 1, 3, 2] if m else [2, 3, 1, 0] for m in reorder_mask]
    quad_vd_idx = quad_vd_idx[reorder_idx]
    quad_normals = normals[quad_vd_idx]
    
    # Step 3: Compute Gamma (Gradient Consistency)
    # Normalize gradients
    norms = quad_normals.norm(dim=-1, keepdim=True)
    quad_normals_norm = quad_normals / (norms + 1e-8)
    
    # Dot products for diagonals (0,2) and (1,3)
    gamma_02 = (quad_normals_norm[:, 0] * quad_normals_norm[:, 2]).sum(dim=-1, keepdim=True)
    gamma_13 = (quad_normals_norm[:, 1] * quad_normals_norm[:, 3]).sum(dim=-1, keepdim=True)
    
    # Step 4: Split Quads
    if not training:
        # Inference: Hard split
        # Split 1: Diagonal (0,2) -> Triangles (0,1,2), (0,2,3)
        # Split 2: Diagonal (1,3) -> Triangles (0,1,3), (1,2,3)
        split_1 = [[0, 1, 2], [0, 2, 3]]
        split_2 = [[0, 1, 3], [1, 2, 3]]
        
        faces = []
        for i in range(len(quad_vd_idx)):
            if gamma_02[i] > gamma_13[i]:
                faces.extend([quad_vd_idx[i][split_1[0]], quad_vd_idx[i][split_1[1]]])
            else:
                faces.extend([quad_vd_idx[i][split_2[0]], quad_vd_idx[i][split_2[1]]])
        return faces, None
    else:
        # Training: Differentiable split with new center vertex
        v0 = dual_vertices[quad_vd_idx[:, 0]]
        v1 = dual_vertices[quad_vd_idx[:, 1]]
        v2 = dual_vertices[quad_vd_idx[:, 2]]
        v3 = dual_vertices[quad_vd_idx[:, 3]]
        
        # Diagonal midpoints
        v_02 = (v0 + v2) / 2.0
        v_13 = (v1 + v3) / 2.0
        
        # Weighted center
        epsilon = 1e-8
        weights = gamma_02 + gamma_13 + epsilon
        v_center = (v_02 * gamma_02 + v_13 * gamma_13) / weights
        
        # Append new vertices to global buffer (Not given in the sources.)
        # new_vertices_buffer.append(v_center)
        
        # Split into 4 triangles sharing the center
        faces = []
        for i in range(len(quad_vd_idx)):
            c = v_center[i]
            faces.extend([quad_vd_idx[i][0], quad_vd_idx[i][1], c],
                         [quad_vd_idx[i][1], quad_vd_idx[i][2], c],
                         [quad_vd_idx[i][2], quad_vd_idx[i][3], c],
                         [quad_vd_idx[i][3], quad_vd_idx[i][0], c])
        return faces, v_center
```

**Parameters:**
- `1e-8`: A small constant added to the weight sum denominator in training mode to prevent division by zero when gamma values are near zero [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Degenerate Gradients:** If gradients are zero or near-zero, gamma values may be unstable. The `1e-8` epsilon in training mode handles this. In inference, if gammas are equal, the split defaults to the `else` branch [S1, unofficial].
- **Boundary Edges:** The method only processes edges shared by exactly 4 cubes. Boundary edges are ignored, leaving the mesh open or requiring separate handling [S1, unofficial].
- **Winding Inconsistency:** If the input normals are inconsistent, the winding correction may fail to produce a manifold mesh [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Measured Performance:** Not given in the sources.
- **Strengths:** Produces triangles that align well with the scalar field's gradient, reducing visual artifacts. Simple to implement as a post-processing step [S1, unofficial].
- **Limitations:** Only works on internal surface edges (quads). Does not handle boundary conditions. The hard split in inference mode is not differentiable, limiting its use in gradient-based optimization without the training mode variant [S1, unofficial].

## Background
Gradient-Consistent Quadrilateral Splitting is a technique used in the context of isosurface extraction, specifically as a refinement step for Simplified Dual Contouring [S1, unofficial]. It was introduced in the context of differentiable surface extraction methods, allowing for gradient-based optimization of the isosurface [S1, unofficial]. The method leverages the consistency of gradients across quad faces to determine the optimal triangulation [S1, unofficial].
