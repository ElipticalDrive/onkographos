# Hierarchical Iso-Surface Extraction
Also called: KdTreeExtraction

## Overview
Hierarchical Iso-Surface Extraction adaptively subdivides a domain using a k-d tree to identify active cells containing an isosurface within a scalar field represented by an Implicit Neural Representation (INR), querying the INR only at active cell corners to reduce computation [S1].

## How it works
**Inputs:**
*   $f_\theta$: An INR mapping $\mathbb{R}^3 \rightarrow \mathbb{R}$ representing the scalar field [S1].
*   $x_l, x_u \in \mathbb{R}^3$: The lower and upper bounds of the domain [S1].
*   $c$: The target iso-value [S1].
*   $t$: Hyperparameter controlling the confidence interval width [S1].
*   $D_{max}$: Maximum depth of the k-d tree [S1].

**Outputs:**
*   $A$: A set of active cells, where each cell is defined by its lower and upper bounds $(x_l, x_u)$ [S1].

**Data Structures:**
*   **PAF (Probabilistic Affine Form):** A vector representing a region as an affine combination of uniformly distributed random variables [S1]. A 3D box centered at $x_c$ with half-widths $x_1, y_1, z_1$ is represented by $\hat{X} = x_c + V \epsilon$, where $V$ is a diagonal matrix of orthogonal axes and $\epsilon$ represents normalized random variables [S1].

**Parameters:**
*   $t$: Controls the confidence interval $[\mu - t\sigma, \mu + t\sigma]$ [S1]. Larger $t$ yields more conservative bounds and smaller $t$ yields tighter bounds [S1].
*   $D_{max}$: Must be a multiple of 3 to ensure active cells are cubes, which is required for standard marching cubes implementations [S1].

**Steps:**
1.  **Calculate Node Representation:** Compute the node center $x_c = (x_l + x_u)/2$ [S1]. Compute the diagonal matrix $V$ for orthogonal axes, where the diagonal elements are $\frac{1}{\sqrt{3}}(x_u - x_c)$ [S1]. Construct the PAF vector $\hat{X} = x_c + V \epsilon$ [S1].
2.  **Uncertainty Propagation:** Propagate $\hat{X}$ through the INR $f_\theta$ to obtain the output PAF $\hat{Y}$ [S1]. This involves sequentially applying linear and activation functions to the PAF [S1].
3.  **Estimate Distribution:** Apply the Central Limit Theorem (CLT) to $\hat{Y}$ to estimate the mean $\mu$ and standard deviation $\sigma$ of the scalar values within the node region, assuming a Gaussian distribution [S1].
4.  **Check Confidence Interval:** If $c < \mu - t\sigma$ or $c > \mu + t\sigma$, the node is non-active and the algorithm returns the empty set $\emptyset$ [S1].
5.  **Check Depth:** If the current depth equals $D_{max}$, the node is an active cell and the algorithm returns the set $\{(x_l, x_u)\}$ [S1].
6.  **Subdivide:** If not at max depth, split the bounding box along the widest dimension into $x_l'$ and $x_u'$ [S1]. Recursively call the algorithm on both children and return the union of their results [S1].
7.  **Mesh Extraction:** After collecting all active cells, query the INR for scalar values at the grid corners of these cells and apply the marching cubes algorithm to extract triangle meshes [S1].

**Pseudocode:**
```python
def KdTreeExtraction(f_theta, x_l, x_u, c, t, max_depth, current_depth):
    # 1. Calculate Node Center and PAF scale
    x_c = (x_l + x_u) / 2.0
    scale = (x_u - x_c) / (3.0 ** 0.5)  # V diagonal elements
    
    # 2. Uncertainty Propagation (Standard affine arithmetic forward pass) [G]
    mu, sigma = propagate_uncertainty(f_theta, x_c, scale)
    
    # 3. Check Confidence Interval
    if c < (mu - t * sigma) or c > (mu + t * sigma):
        return set()
    
    # 4. Check Max Depth
    if current_depth >= max_depth:
        return {(x_l, x_u)}
    
    # 5. Subdivide along widest dimension
    dims = [x_u[i] - x_l[i] for i in range(3)]
    widest_dim = max(range(3), key=lambda i: dims[i])
    mid = (x_l[widest_dim] + x_u[widest_dim]) / 2.0
    
    x_l_left, x_u_left = x_l[:], x_u[:]
    x_u_left[widest_dim] = mid
    x_l_right, x_u_right = x_l[:], x_u[:]
    x_l_right[widest_dim] = mid
    
    # 6. Recurse and union
    A_left = KdTreeExtraction(f_theta, x_l_left, x_u_left, c, t, max_depth, current_depth + 1)
    A_right = KdTreeExtraction(f_theta, x_l_right, x_u_right, c, t, max_depth, current_depth + 1)
    return A_left.union(A_right)

def propagate_uncertainty(f_theta, center, scale):
    """Forward-passes a PAF (center + scale) through f_theta using affine arithmetic [G].
    Returns the output mean mu and standard deviation sigma."""
    # Standard implementation applies each layer's linear transform and activation
    # to the affine form, accumulating center and scale terms [G].
    # For brevity, this is marked as a standard operation [G].
    return f_theta.affine_forward(center, scale)

def extract_mesh(active_cells, f_theta):
    """Queries INR at corners of active cells and runs marching cubes [G]."""
    all_vertices = []
    all_faces = []
    
    for (x_l, x_u) in active_cells:
        corners = get_corners(x_l, x_u)
        values = [f_theta(corner) for corner in corners]
        # Standard marching cubes algorithm applied to the 2x2x2 grid [G]
        cell_faces = marching_cubes(values, corners)
        all_faces.extend(cell_faces)
        
    return all_vertices, all_faces

def get_corners(x_l, x_u):
    """Returns the 8 grid corners of a bounding box."""
    corners = []
    for i in range(2):
        for j in range(2):
            for k in range(2):
                corners.append([x_l[0] if i == 0 else x_u[0],
                                x_l[1] if j == 0 else x_u[1],
                                x_l[2] if k == 0 else x_u[2]])
    return corners
```

**Pitfalls:**
*   **Cube Constraint:** The maximum depth must be a multiple of 3 to ensure that the resulting active cells are cubes, which is likely required for standard marching cubes implementations [S1].

## Operating characteristics
*   **Time Complexity:** Proportional to the number of active cells and the cost of uncertainty propagation per node [S1].
*   **Memory Complexity:** Proportional to the number of active cells and the k-d tree depth [S1].
*   **Strengths:** Reduces computation by querying the INR only at active cell corners instead of performing dense reconstruction [S1].
*   **Limitations:** Uncertainty propagation through INR layers is computationally heavier than a single INR query [S1].
*   **When to use:** When INR evaluation is expensive and adaptive subdivision is beneficial [S1].
*   **When not to use:** Not given in the sources.

## Background
The method was proposed in "Improving Efficiency of Iso-Surface Extraction on Implicit Neural Representations Using Uncertainty Propagation" (2024), published in IEEE Transactions on Visualization and Computer Graphics [S1]. It addresses the inefficiency of dense reconstruction from INRs by using a k-d tree to adaptively subdivide the domain and estimate value distributions through uncertainty propagation [S1].
