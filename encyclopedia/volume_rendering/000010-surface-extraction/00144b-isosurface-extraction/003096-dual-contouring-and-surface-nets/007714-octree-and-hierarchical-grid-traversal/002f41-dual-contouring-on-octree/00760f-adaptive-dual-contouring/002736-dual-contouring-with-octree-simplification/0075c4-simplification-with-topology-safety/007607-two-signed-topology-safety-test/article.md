# Two-Signed Topology Safety Test

Also called: Manifold safety test, Two-material simplification safety

## Overview
The Two-Signed Topology Safety Test is a verification method used during the simplification of an octree in adaptive dual contouring. It guarantees that the topological connectivity of the dual contour and its associated textured regions is preserved when collapsing an interior node whose eight children are leaves. It distinguishes itself from generic simplification by explicitly rejecting collapses that would alter the manifold status or topological equivalence of the surface, preventing artifacts such as merged components or broken textures [S1, unofficial].

## How it works
The test operates on a coarse cube defined by eight leaf cubes. The signs (or indices) at the corners of these leaves define a $3 \times 3 \times 3$ grid of values, where the corners of this grid define a $2 \times 2 \times 2$ coarse grid. The test consists of three phases. If any phase fails, the collapse is unsafe and must be aborted [S1, unofficial].

### Inputs and Outputs
*   **Input**: The sign configuration at the 27 vertices of the $3 \times 3 \times 3$ grid surrounding the coarse cube.
*   **Output**: Boolean result (`True` if safe to collapse, `False` otherwise).

### Data Structures
*   **Sign Grid**: A $3 \times 3 \times 3$ array of signed integers (or boolean values). Let $S_{i,j,k}$ denote the sign at grid coordinates $(i,j,k)$ where $i,j,k \in \{0, 1, 2\}$.
*   **Manifold Lookup Table**: A pre-computed table of size $2^8$ (for two-signed case) or $4^8$ (for multi-material case). The index is derived from the 8 corner signs/indices of the coarse cube.

### Steps

#### Phase 1: Coarse Manifold Check
Test whether the dual contour generated by the coarse $2 \times 2 \times 2$ grid is a manifold.
1.  Extract the 8 corner signs of the coarse cube from the $3 \times 3 \times 3$ grid. These are $S_{0,0,0}, S_{0,0,2}, S_{0,2,0}, S_{0,2,2}, S_{2,0,0}, S_{0,2,2}, S_{2,2,0}, S_{2,2,2}$.
2.  Compute the lookup index from these 8 values.
3.  Check the pre-computed table. If the table entry indicates non-manifold, return `False`.

*Manifold Check Logic [G]*: The manifold property is determined by collapsing edges of the cube whose endpoints have the same sign. The contour is manifold if and only if the result of this reduction is a single edge. This logic is pre-computed for all $2^8$ sign configurations [S1, unofficial].

#### Phase 2: Fine Manifold Check
Test whether the dual contour for each individual fine cube (leaf) is a manifold.
1.  For each of the 8 leaf cubes, extract its 8 corner signs from the $3 \times 3 \times 3$ grid.
2.  Perform the same manifold check as in Phase 1 for each leaf.
3.  If any leaf cube fails the manifold check, return `False`.

*Note*: This check can be omitted if the fine leaf cubes are themselves the results of a previous collapse, as they are assumed to be manifold [S1, unofficial].

#### Phase 3: Topological Equivalence Check
Test whether the fine contour is topologically equivalent to the coarse contour on each sub-face and interior of the coarse cube. This is implemented via sign comparisons on the $3 \times 3 \times 3$ grid.

1.  **Edge Check**: For each of the 12 edges of the coarse cube:
    *   Identify the sign in the middle of the coarse edge (e.g., for the edge along the x-axis from $(0,0,0)$ to $(2,0,0)$, the middle sign is $S_{1,0,0}$).
    *   Identify the signs at the two endpoints of the coarse edge (e.g., $S_{0,0,0}$ and $S_{2,0,0}$).
    *   Condition: The middle sign must agree with at least one of the endpoint signs.
    *   Formula: $S_{mid} == S_{end1} \lor S_{mid} == S_{end2}$.
    *   If this fails for any edge, return `False`.

2.  **Face Check**: For each of the 6 faces of the coarse cube:
    *   Identify the sign in the middle of the coarse face (e.g., for the face $z=0$, the middle sign is $S_{1,1,0}$).
    *   Identify the signs at the four corners of the coarse face.
    *   Condition: The middle sign must agree with at least one of the four corner signs.
    *   Formula: $S_{mid} == S_{corner1} \lor S_{mid} == S_{corner2} \lor S_{mid} == S_{corner3} \lor S_{mid} == S_{corner4}$.
    *   If this fails for any face, return `False`.

3.  **Interior Check**: For the interior of the coarse cube:
    *   Identify the sign in the middle of the coarse cube ($S_{1,1,1}$).
    *   Identify the signs at the eight corners of the coarse cube.
    *   Condition: The middle sign must agree with at least one of the eight corner signs.
    *   Formula: $\exists c \in \{corners\} : S_{1,1,1} == c$.
    *   If this fails, return `False`.

If all checks pass, return `True`.

def is_safe_to_collapse(sign_grid_3x3x3):
    """
    sign_grid_3x3x3: 3x3x3 array of signs (e.g., -1 or 1)
    Returns True if the dual contour topology is preserved, False otherwise.
    """
    
    # Helper to get corner signs of a coarse cube defined by grid bounds
    def get_coarse_corners(grid):
        # Corners of the 2x2x2 coarse grid within the 3x3x3 fine grid
        # Indices: 0 and 2
        return [
            grid[0,0,0], grid[0,0,2], grid[0,2,0], grid[0,2,2],
            grid[2,0,0], grid[2,0,2], grid[2,2,0], grid[2,2,2]
        ]

    # Phase 1: Coarse Manifold Check
    coarse_corners = get_coarse_corners(sign_grid_3x3x3)
    if not is_manifold(coarse_corners):
        return False

    # Phase 2: Fine Manifold Check
    # Iterate over the 8 leaf cubes
    for i in range(0, 3, 2):
        for j in range(0, 3, 2):
            for k in range(0, 3, 2):
                # Extract 8 corners of the leaf cube starting at (i,j,k)
                # The leaf cube spans indices i to i+2, j to j+2, k to k+2
                leaf_corners = []
                for di in [0, 2]:
                    for dj in [0, 2]:
                        for dk in [0, 2]:
                            leaf_corners.append(sign_grid_3x3x3[i+di, j+dj, k+dk])
                
                if not is_manifold(leaf_corners):
                    return False

    # Phase 3: Topological Equivalence Check
    
    # Edge Check
    # There are 12 edges. We check midpoints against endpoints.
    # Edges parallel to X:
    for j in [0, 2]:
        for k in [0, 2]:
            mid = sign_grid_3x3x3[1, j, k]
            end1 = sign_grid_3x3x3[0, j, k]
            end2 = sign_grid_3x3x3[2, j, k]
            if not (mid == end1 or mid == end2):
                return False
    # Edges parallel to Y:
    for i in [0, 2]:
        for k in [0, 2]:
            mid = sign_grid_3x3x3[i, 1, k]
            end1 = sign_grid_3x3x3[i, 0, k]
            end2 = sign_grid_3x3x3[i, 2, k]
            if not (mid == end1 or mid == end2):
                return False
    # Edges parallel to Z:
    for i in [0, 2]:
        for j in [0, 2]:
            mid = sign_grid_3x3x3[i, j, 1]
            end1 = sign_grid_3x3x3[i, j, 0]
            end2 = sign_grid_3x3x3[i, j, 2]
            if not (mid == end1 or mid == end2):
                return False

    # Face Check
    # There are 6 faces. We check face centers against corners.
    # Faces perpendicular to X (i=0, i=2)
    for i in [0, 2]:
        mid = sign_grid_3x3x3[i, 1, 1]
        corners = [
            sign_grid_3x3x3[i, 0, 0], sign_grid_3x3x3[i, 0, 2],
            sign_grid_3x3x3[i, 2, 0], sign_grid_3x3x3[i, 2, 2]
        ]
        if not any(mid == c for c in corners):
            return False
    # Faces perpendicular to Y (j=0, j=2)
    for j in [0, 2]:
        mid = sign_grid_3x3x3[1, j, 1]
        corners = [
            sign_grid_3x3x3[0, j, 0], sign_grid_3x3x3[0, j, 2],
            sign_grid_3x3x3[2, j, 0], sign_grid_3x3x3[2, j, 2]
        ]
        if not any(mid == c for c in corners):
            return False
    # Faces perpendicular to Z (k=0, k=2)
    for k in [0, 2]:
        mid = sign_grid_3x3x3[1, 1, k]
        corners = [
            sign_grid_3x3x3[0, 0, k], sign_grid_3x3x3[0, 2, k],
            sign_grid_3x3x3[2, 0, k], sign_grid_3x3x3[2, 2, k]
        ]
        if not any(mid == c for c in corners):
            return False

    # Interior Check
    mid = sign_grid_3x3x3[1, 1, 1]
    corners = get_coarse_corners(sign_grid_3x3x3)
    if not any(mid == c for c in corners):
        return False

    return True

## Subtopics

### Multi-Material Topology Safety Test
A test for multi-material regions where a contour is a 'quasi-manifold' if the boundary of each material's region is a manifold. This is equivalent to being a manifold in the two-material case. The test consists of three phases identical to the two-material test, except phases 1 and 2 check for quasi-manifold instead of manifold. The quasi-manifold check for a multi-material cube involves collapsing each edge of the cube whose endpoints have the same index. The contour is a quasi-manifold if and only if the collapsed edge graph is a simplex (i.e., a point, a segment, a triangle, or a tetrahedron). The index tests in phase 3 remain unchanged from the two-material case (sign comparisons on the grid). The lookup table size for the quasi-manifold test is $4^8$. If a cube has 5 or more distinct indices, its edge graph cannot collapse to a simplex [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: The test involves a constant number of operations relative to the grid size (fixed $3 \times 3 \times 3$ grid). Phase 1 and 2 involve table lookups ($O(1)$). Phase 3 involves checking 12 edges, 6 faces, and 1 interior cell, each requiring a constant number of comparisons. Total time is $O(1)$ per node collapse attempt.
*   **Memory Complexity**: Requires a pre-computed lookup table. For the two-signed case, size is $2^8 = 256$ entries. For the multi-material case, size is $4^8 = 65,536$ entries.
*   **Strengths**: Guarantees topological safety, preventing artifacts like merged components or broken textures during simplification. Efficient due to pre-computation and simple sign comparisons.
*   **Limitations**: Restricts simplification to manifold (or quasi-manifold) contours. Non-manifold contours arising from unsafe simplification or complex geometry may be rejected, potentially limiting compression ratios. The multi-material table size ($4^8$) is significantly larger than the two-signed case.
*   **When to use**: When topological integrity of the dual contour and its textures is critical, and the geometry is predominantly manifold or quasi-manifold.
*   **When not to use**: When the geometry contains significant non-manifold features that must be preserved or simplified, or when memory constraints prohibit the $4^8$ lookup table for multi-material cases.

## Background
The Two-Signed Topology Safety Test was introduced in the context of dual contouring of Hermite data. It addresses the problem of topological changes during octree simplification, such as the merging of components in Chinese character recognition examples. The method builds on the manifold test described by Gerstner and Pajarola (2000) for determining if a contour associated with a single cube is a manifold. The test ensures that the dual contour generated by a coarse grid is topologically equivalent to the fine grid's contour on sub-faces and interiors.
