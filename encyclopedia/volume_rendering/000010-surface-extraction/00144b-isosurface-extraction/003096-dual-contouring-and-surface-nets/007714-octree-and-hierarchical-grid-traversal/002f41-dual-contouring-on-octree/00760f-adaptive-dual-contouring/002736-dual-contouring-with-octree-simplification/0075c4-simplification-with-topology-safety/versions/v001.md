# Simplification with Topology Safety

Also called: Safe Simplification, Topology-Preserving Simplification

## Overview
This method guarantees that the topological connectivity of the dual contour and its textured regions is preserved when collapsing an interior octree node into a pseudo-leaf node [S1, unofficial]. It prevents distinct parts of the contour from merging, which would otherwise change topology and make features difficult to recognize [S1, unofficial]. It sets itself apart from standard dual contouring simplification by introducing explicit safety tests based on sign/index configurations before allowing a collapse [S1, unofficial].

## How it works
**Inputs:** An interior octree node whose eight children are leaves. For each child leaf, the sign (in the two-material case) or material index (in the multi-material case) at the corner shared with the coarse node is required.
**Outputs:** A boolean indicating whether the collapse is safe, and if so, the permission to proceed with the standard QEF-based vertex placement defined in [Dual Contouring with Octree Simplification](3685-dual-contouring-with-octree-simplification.md).

**Data Structures:**
1.  **Sign/Index Grid:** A $3 \times 3 \times 3$ grid of values representing the signs or indices at the corners of the eight leaf cubes. The corners of this grid define a $2 \times 2 \times 2$ coarse grid.
2.  **Manifold Lookup Table:** A pre-computed table of size $2^8$ for the two-signed case.
3.  **Quasi-Manifold Lookup Table:** A pre-computed table of size $4^8$ for the multi-material case.

**Algorithm:**
The safety test proceeds in three phases. If any phase fails, the simplification is aborted.

### Phase 1: Coarse Manifold Check
Test if the dual contour for the coarse cube (the $2 \times 2 \times 2$ grid) is a manifold.
*   **Two-signed case:** Use the pre-computed $2^8$ lookup table.
*   **Multi-material case:** Use the quasi-manifold test (see below).
*   If not manifold, stop.

### Phase 2: Fine Manifold Check
Test if the dual contour for each individual fine cube (the eight leaf cubes) is a manifold.
*   **Two-signed case:** Use the pre-computed $2^8$ lookup table for each leaf.
*   **Multi-material case:** Use the quasi-manifold test for each leaf.
*   If any fine cube is not manifold, stop.
*   *Note:* This check can be skipped if the fine leaf cubes are themselves the results of a previous collapse [S1, unofficial].

### Phase 3: Topological Equivalence Check
Test if the fine contour is topologically equivalent to the coarse contour on each sub-face of the coarse cube (edges, faces, and interior). This is implemented via sign comparisons on the $3 \times 3 \times 3$ grid.

1.  **Edge Check:** For each of the 12 coarse edges, the sign in the middle of the coarse edge must agree with the sign of at least one of the edge’s two endpoints.
2.  **Face Check:** For each of the 6 coarse faces, the sign in the middle of the coarse face must agree with the sign of at least one of the face’s four corners.
3.  **Interior Check:** For the coarse cube interior, the sign in the middle of the coarse cube must agree with the sign of at least one of the cube’s eight corners.

If any check fails, stop. Otherwise, safely collapse.

**Manifold/Quasi-Manifold Test Implementation:**
For a single cube (either coarse or fine), the manifold status is determined by collapsing edges.
*   **Two-signed case:** Repeatedly collapse edges of the cube whose corners have the same sign to a single vertex. The contour is manifold if and only if the result is a single edge.
*   **Multi-material case:** A multi-material contour is a quasi-manifold if the boundary of each material's region is a manifold. The test collapses each edge of the cube whose endpoints have the same index. The contour is a quasi-manifold if and only if the collapsed edge graph is a simplex (a point, segment, triangle, or tetrahedron). If a cube has 5 or more distinct indices, it cannot be a quasi-manifold [S1, unofficial].

**Pseudocode:**

```python
def is_safe_to_collapse(sign_grid_3x3x3, is_multi_material=False):
    """
    sign_grid_3x3x3: 3x3x3 array of signs (0/1) or material indices.
    is_multi_material: Boolean flag for material type.
    """
    # Extract coarse grid (2x2x2) from corners of 3x3x3
    coarse_grid = extract_coarse_grid(sign_grid_3x3x3)
    
    # Phase 1: Coarse Manifold Check
    if is_multi_material:
        if not is_quasi_manifold(coarse_grid):
            return False
    else:
        if not is_manifold(coarse_grid):
            return False

    # Phase 2: Fine Manifold Check
    # Iterate over the 8 leaf cubes defined by the 3x3x3 grid
    for leaf_cube in get_leaf_cubes(sign_grid_3x3x3):
        if is_multi_material:
            if not is_quasi_manifold(leaf_cube):
                return False
        else:
            if not is_manifold(leaf_cube):
                return False

    # Phase 3: Topological Equivalence Check
    # Edge Check
    for edge in coarse_edges:
        mid_sign = sign_grid_3x3x3[edge.midpoint]
        end_signs = [sign_grid_3x3x3[edge.endpoint_i] for endpoint_i in edge.endpoints]
        if not any(mid_sign == s for s in end_signs):
            return False

    # Face Check
    for face in coarse_faces:
        mid_sign = sign_grid_3x3x3[face.midpoint]
        corner_signs = [sign_grid_3x3x3[face.corner_i] for corner_i in face.corners]
        if not any(mid_sign == s for s in corner_signs):
            return False

    # Interior Check
    mid_sign = sign_grid_3x3x3[1, 1, 1] # Center of 3x3x3 grid
    corner_signs = [sign_grid_3x3x3[c] for c in coarse_corners]
    if not any(mid_sign == s for s in corner_signs):
        return False

    return True

def is_manifold(cube_signs_2x2x2):
    """
    cube_signs_2x2x2: 2x2x2 array of signs.
    Returns True if manifold, False otherwise.
    Uses pre-computed lookup table of size 2^8.
    """
    # Flatten 2x2x2 to 8-bit integer
    index = flatten_to_index(cube_signs_2x2x2)
    return MANIFOLD_LOOKUP_TABLE[index]

def is_quasi_manifold(cube_indices_2x2x2):
    """
    cube_indices_2x2x2: 2x2x2 array of material indices.
    Returns True if quasi-manifold, False otherwise.
    Uses pre-computed lookup table of size 4^8.
    """
    # Check for > 4 distinct indices
    if len(set(flatten(cube_indices_2x2x2))) > 4:
        return False
    
    # Flatten 2x2x2 to 8-element tuple of indices
    index = flatten_to_tuple(cube_indices_2x2x2)
    return QUASI_MANIFOLD_LOOKUP_TABLE[index]

def extract_coarse_grid(grid_3x3x3):
    """
    Extracts the 2x2x2 coarse grid from the corners of the 3x3x3 grid.
    """
    coarse = [[[[grid_3x3x3[i][j][k] 
                 for k in [0, 2]] 
                for j in [0, 2]] 
               for i in [0, 2]]]
    return coarse

def get_leaf_cubes(grid_3x3x3):
    """
    Returns the 8 leaf cubes defined by the 3x3x3 grid.
    Each leaf cube is a 2x2x2 subgrid.
    """
    leaves = []
    for i in [0, 1]:
        for j in [0, 1]:
            for k in [0, 1]:
                leaf = [[[grid_3x3x3[i*2+di][j*2+dj][k*2+dk] 
                          for dk in [0, 1]] 
                         for dj in [0, 1]] 
                        for di in [0, 1]]
                leaves.append(leaf)
    return leaves
```

**Parameters:**
*   Lookup table sizes: $2^8$ for two-signed, $4^8$ for multi-material.
*   Distinct index limit: 4 (if 5 or more distinct indices, quasi-manifold test fails immediately) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Non-manifold contours:** Standard dual contouring can produce non-manifold vertices in ambiguous sign configurations. The safety test explicitly rejects these to maintain manifold properties [S1, unofficial].
*   **Distinct parts merging:** Unsafe simplification can cause distinct parts of the contour to merge, changing topology and making features difficult to recognize (e.g., distinct parts of a Chinese character merging) [S1, unofficial].
*   **Multi-material complexity:** In multi-material cases, the test ensures that the boundary of *each* material's region is a manifold (quasi-manifold condition) [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The safety test involves a constant number of checks per node collapse (Phase 1, 2, and 3). The manifold/quasi-manifold checks use pre-computed lookup tables, making them $O(1)$. The topological equivalence checks involve iterating over a fixed number of edges (12), faces (6), and the interior (1) of the coarse cube, also $O(1)$.
*   **Memory Complexity:** Requires storage for two lookup tables: $2^8$ entries for the two-signed case and $4^8$ entries for the multi-material case.
*   **Strengths:** Guarantees topological preservation, preventing artifacts like merging features.
*   **Limitations:** May prevent simplification in cases where the topology would change but the user might accept it. The restriction to manifold/quasi-manifold contours may reject valid simplifications if the underlying contour is non-manifold due to other reasons (though the source notes that non-manifold contours usually arise from unsafe simplification) [S1, unofficial].
*   **When to use:** When topological correctness of the mesh and its textured regions is critical.
*   **When not to use:** When performance is paramount and topological changes are acceptable, or when the contour is inherently non-manifold and cannot be made manifold by other means.

## Background
This method was introduced by Tao Ju, Steven Schaefer, and Joe Warren in their work on Dual Contouring [S1, unofficial]. It addresses the issue that standard simplification in dual contouring can alter the topological connectivity of the contour and its textured regions. The method builds on the manifold test described by Gerstner and Pajarola (2000) for determining if a contour associated with a single cube is a manifold [S1, unofficial].
