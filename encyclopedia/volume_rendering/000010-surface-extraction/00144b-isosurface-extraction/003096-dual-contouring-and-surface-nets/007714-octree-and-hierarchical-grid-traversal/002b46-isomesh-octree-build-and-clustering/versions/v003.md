# Isomesh Octree Build and Clustering

Also called: Voxel Level of Detail with Dual Contouring

## Overview
Isomesh Octree Build and Clustering is a hierarchical mesh generation method that constructs an octree over a uniform grid and extracts a manifold surface by clustering vertices at every node level (leaves, edges, faces, and cells) using Disjoint Set Union (DSU) and Quadratic Error Function (QEF) solvers [S1, S2, unofficial]. It enables efficient Level of Detail (LOD) generation by treating octree branches as leaves at coarser levels, minimizing reconstruction error while preserving material properties [S1, S2, unofficial]. Unlike standard dual contouring which processes only leaf nodes, this method merges geometric primitives across the hierarchy to reduce vertex count and optimize rendering, though it introduces complexity in stitching meshes between different LOD levels [S2, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
- A scalar field function $f(\mathbf{p})$ and its gradient $\nabla f(\mathbf{p})$ defined over a 3D domain.
- A grid size $N$ (must be a power of two, $2 \le N \le 1024$) [S1, unofficial].
- A global scale factor $S_{global}$ and a clipping epsilon $\epsilon$ [S1, unofficial].

**Outputs:**
- A hierarchical octree structure where each node stores vertices, normals, materials, and QEF states.
- A final triangle mesh with indices, generated by traversing the octree and resolving clustered vertices [S1, S2, unofficial].

### Data Structures

**UniformGrid:**
- `m_mat`: A raw array of `Material` with size $(N+1)^3$. Indices are computed in Z-major order:
  $$ \text{idx} = ((y + \frac{N}{2}) \cdot (N+1) + (x + \frac{N}{2})) \cdot (N+1) + (z + \frac{N}{2}) $$
  where $(x,y,z)$ are integer grid coordinates relative to the center [S1, unofficial].
- `m_size`: The integer grid dimension $N$.
- `m_halfSize`: $N/2$.

**Octree Node:**
- `m_vertices`: A vector of vertex structures. Each vertex contains:
  - `m_position`: `glm::vec3` position.
  - `m_normal`: `glm::vec3` normal.
  - `m_material`: Material enum.
  - `m_error`: Float, the QEF evaluation error at the position.
  - `m_qef`: QEF state object.
  - `m_parent`: Pointer to the parent node's vertex (for clustering hierarchy).
  - `m_surfaceIdx`: Index into the surface vertex list during clustering.
- `m_vertexMask`: An 8-bit integer (or boolean array) indicating which of the 8 cell corners are solid (non-empty) [S1, unofficial].
- `m_isLeaf`: Boolean flag.

**Edge/Cell Storage:**
- `storages[kCellEdgeDirection[i]]`: Hash maps or lists storing edge intersections found during grid filling. Each entry stores `surfacePoint()`, `surfaceNormal()`, and `solidEndpointMaterial()` [S1, unofficial].

### Algorithm Steps

#### 1. Grid Filling
Populate the `UniformGrid` with material data and detect edge intersections.

1.  Compute values for all $(N+1)^3$ vertices. Iterate $y, x, z$ from $-m\_halfSize$ to $m\_halfSize$.
2.  Compute world position $\mathbf{p} = \text{localToGlobal}(x, y, z)$.
3.  Evaluate $v = f(\mathbf{p})$.
4.  Set `values[idx] = v`.
5.  If $v > 0$, set `m_mat[idx] = Material::Empty`. Else, set `m_mat[idx] = f.material(\mathbf{p}, v)` [S1, unofficial].

**Edge Intersection Detection:**
Iterate through all edges of the grid cells. For each axis (X, Y, Z):
1.  Identify edge endpoints with indices `idx1` and `idx2`.
2.  Check signs: $s_1 = (values[idx1] \le 0.0)$, $s_2 = (values[idx2] \le 0.0)$.
3.  If $s_1 \neq s_2$, an intersection exists.
4.  Compute intersection point $\mathbf{p}_{int}$ along the axis using linear interpolation or a solver `findAlongX/Y/Z`.
5.  Compute gradient $\mathbf{g} = \nabla f(\mathbf{p}_{int})$.
6.  Compute offset along the axis: $o = (\mathbf{p}_{int}.axis - \text{start}) / m\_gridStep$.
7.  Determine material and store in `m_edgeX/Y/Z` storage with parameters $(x, y, z, \mathbf{g}, o, 0, s_1, \text{mat})$ [S1, unofficial].

#### 2. Octree Build Phase
Recursively subdivide the grid and build leaf nodes.

1.  Call `buildNode(root, min_corner, size)`.
2.  If `size == 1`:
    -   Call `buildLeaf(node, min_corner)` [S1, unofficial].
3.  Else:
    -   `node->subdivide()`.
    -   `child_size = size / 2`.
    -   For $i$ from 0 to 7:
        -   `child_min_corner = min_corner + child_size * kCellCornerOffset[i]`.
        -   `buildNode(node->child(i), child_min_corner, child_size)` [S1, unofficial].

**Leaf Construction (`buildLeaf`):**
1.  Get `corners` from `args.grid.materialsOfCell(args.grid.pointToIndex(min_corner))`.
2.  Compute `vertex_mask`: set bit $i$ if `corners[i] != Material::Empty` [S1, unofficial].
3.  `node->setCorners(corners)`, `node->setVertexMask(vertex_mask)`.
4.  Initialize `solver[4]`, `filter[4]`, `avg_normal[4]`.
5.  Initialize `corner_used[8]` to false [S1, unofficial].

**Leaf Edge Processing & QEF Accumulation:**
1.  Iterate $i$ from 0 to 11 (12 edges of a cube).
2.  Get `idx = kMdcEdgeSetIndex[vertex_mask][i]`. If `idx < 0`, continue.
3.  Get `storage` from `storages[kCellEdgeDirection[i]]`.
4.  Calculate `edge_pos = min_corner + kCellCornerOffset[kCellEdgeEndpoint[i][0]]`.
5.  Find edge iterator `iter = storage.findEdge(edge_pos.x, edge_pos.y, edge_pos.z)`.
6.  Get `point = iter->surfacePoint()`, `normal = iter->surfaceNormal()`.
7.  `solver[idx].addPlane(point, normal)`.
8.  `avg_normal[idx] += normal`.
9.  Determine `mat = iter->solidEndpointMaterial()`.
10. Determine `corner_idx`: if `iter->isLesserEndpointSolid()`, `corner_idx = kCellEdgeEndpoint[i][0]`, else `corner_idx = kCellEdgeEndpoint[i][1]`.
11. If `!corner_used[corner_idx]`:
    -   `filter[idx].add(mat)`.
    -   `corner_used[corner_idx] = true` [S1, unofficial].

**Leaf Vertex Solving:**
1.  `surface_cnt = max(idx + 1)` from the loop above.
2.  `node->m_vertices.resize(surface_cnt)`.
3.  `lower_bound = min_corner`, `upper_bound = min_corner + size`.
4.  For $i$ from 0 to `surface_cnt - 1`:
    -   `point = solver[i].solve(lower_bound, upper_bound)`.
    -   `node->m_vertices[i].m_position = point`.
    -   `node->m_vertices[i].m_normal = glm::normalize(avg_normal[i])`.
    -   `node->m_vertices[i].m_material = filter[i].select()`.
    -   `node->m_vertices[i].m_error = solver[i].eval(point)`.
    -   `node->m_vertices[i].m_qef = solver[i].state()` [S1, unofficial].

#### 3. Cell Clustering
Merge vertices from children into parent nodes to support LOD.

1.  Call `clusterCell(root, min_corner, size)`.
2.  If `node->isLeaf()`, return.
3.  Recursively call `clusterCell` on all 8 children with `sub_size = size / 2` and `sub_pos = min_corner + sub_size * kCellCornerOffset[i]` [S1, unofficial].
4.  Initialize `DSU dsu` and `VertexArray vertices`.
5.  Call `callSubClusterFace(0)`, `callSubClusterFace(1)`, `callSubClusterFace(2)`, `callSubClusterEdge(0)`, `callSubClusterEdge(1)`, `callSubClusterEdge(2)` [S1, unofficial].

**Edge/Face Clustering Logic:**
In `clusterEdge` and `clusterFace`:
1.  Iterate children using `kEdgeProcChildTable[D]` or `kFaceProcChildTable[D]`.
2.  If child `n` is subdivided, get specific child `sub[i] = n->child(k...[i][1])` and set `all_leaves = false`. Else `sub[i] = n`.
3.  If `all_leaves`, call `clusterEdgeLeaves<D>(nodes, dsu, vertices)` and return.
4.  Otherwise, call `callSubClusterEdge(D)` or `callSubClusterFace(D)` [S1, unofficial].

**Vertex Merging in Cell:**
1.  Map DSU sets to new indices. Initialize `set_idx` vector of size `dsu.size()` with `kBadIndex`.
2.  Iterate $i$ from 0 to `dsu.size()-1`.
3.  Get `leader = dsu.getSetLeader(i)`.
4.  If `set_idx[leader] == kBadIndex`, set `set_idx[leader] = new_cnt` and increment `new_cnt`.
5.  Set `set_idx[i] = set_idx[leader]`.
6.  `node->m_vertices.resize(new_cnt)` [S1, unofficial].

**Solving Clustered Vertices:**
1.  Initialize `solver` vector of size `new_cnt` with copies of `orig_solver`.
2.  Initialize `filter` and `avg_normal` vectors of size `new_cnt`.
3.  Iterate $v$ in `vertices`.
4.  Get `idx = set_idx[v->m_surfaceIdx]`.
5.  `v->m_surfaceIdx = kBadIndex`.
6.  `solver[idx].merge(v->m_qef)`.
7.  `avg_normal[idx] += v->m_normal`.
8.  `filter[idx].add(v->m_material)`.
9.  `v->m_parent = &node->m_vertices[idx]` [S1, unofficial].

**Final Vertex Assignment:**
1.  Iterate $i$ from 0 to `new_cnt - 1`.
2.  `point = solver[i].solve(lower_bound, upper_bound)`.
3.  `node->m_vertices[i].m_position = point`.
4.  `node->m_vertices[i].m_normal = glm::normalize(avg_normal[i])`.
5.  `node->m_vertices[i].m_material = filter[i].select()`.
6.  `node->m_vertices[i].m_error = solver[i].eval(point)`.
7.  `node->m_vertices[i].m_qef = solver[i].state()` [S1, unofficial].

#### 4. Contour Generation
Generate the final mesh.

1.  Scale epsilon: `scaled_epsilon = epsilon / (m_globalScale * m_globalScale)`.
2.  Create `Mesh mesh`.
3.  Call `addVerticesToMesh(&m_root, mesh, scaled_epsilon)`.
4.  Call `cellProc(&m_root, mesh)` to generate indices.
5.  Set global position and scale on mesh.
6.  Return mesh [S1, unofficial].

### Pseudocode

```python
def build_octree_and_cluster(grid, root, min_corner, size):
    if size == 1:
        build_leaf(root, grid, min_corner)
    else:
        root.subdivide()
        child_size = size // 2
        for i in range(8):
            child_min = min_corner + child_size * kCellCornerOffset[i]
            build_octree_and_cluster(grid, root.child(i), child_min, child_size)
        
        # After children are built, cluster them into this node
        cluster_cell(root, min_corner, size)

def build_leaf(node, grid, min_corner):
    corners = grid.materials_of_cell(grid.point_to_index(min_corner))
    node.set_corners(corners)
    
    vertex_mask = 0
    for i in range(8):
        if corners[i] != Material.Empty:
            vertex_mask |= (1 << i)
    node.set_vertex_mask(vertex_mask)
    
    solvers = [QEF_Solver() for _ in range(4)]
    filters = [MaterialFilter() for _ in range(4)]
    avg_normals = [vec3(0,0,0) for _ in range(4)]
    corner_used = [False] * 8
    
    for edge_idx in range(12):
        qef_idx = kMdcEdgeSetIndex[vertex_mask][edge_idx]
        if qef_idx < 0:
            continue
            
        storage = get_edge_storage(kCellEdgeDirection[edge_idx])
        edge_pos = min_corner + kCellCornerOffset[kCellEdgeEndpoint[edge_idx][0]]
        iter = storage.find_edge(edge_pos.x, edge_pos.y, edge_pos.z)
        
        if iter is None:
            continue
            
        point = iter.surface_point()
        normal = iter.surface_normal()
        
        solvers[qef_idx].add_plane(point, normal)
        avg_normals[qef_idx] += normal
        
        mat = iter.solid_endpoint_material()
        if iter.is_lesser_endpoint_solid():
            corner_idx = kCellEdgeEndpoint[edge_idx][0]
        else:
            corner_idx = kCellEdgeEndpoint[edge_idx][1]
            
        if not corner_used[corner_idx]:
            filters[qef_idx].add(mat)
            corner_used[corner_idx] = True
            
    surface_cnt = max(qef_idx + 1 for qef_idx in range(4) if not solvers[qef_idx].is_empty())
    node.m_vertices = []
    
    lower = min_corner
    upper = min_corner + size
    
    for i in range(surface_cnt):
        point = solvers[i].solve(lower, upper)
        node.m_vertices.append(Vertex(
            position=point,
            normal=normalize(avg_normals[i]),
            material=filters[i].select(),
            error=solvers[i].eval(point),
            qef=solvers[i].state()
        ))

def cluster_cell(node, min_corner, size):
    if node.is_leaf():
        return
        
    sub_size = size // 2
    for i in range(8):
        sub_pos = min_corner + sub_size * kCellCornerOffset[i]
        cluster_cell(node.child(i), sub_pos, sub_size)
        
    dsu = DisjointSetUnion()
    vertices = []
    
    # Cluster faces and edges
    for d in range(3):
        call_sub_cluster_face(d, node, dsu, vertices)
        call_sub_cluster_edge(d, node, dsu, vertices)
        
    # Map DSU sets to new indices
    set_idx = [-1] * dsu.size()
    new_cnt = 0
    for i in range(dsu.size()):
        leader = dsu.get_set_leader(i)
        if set_idx[leader] == -1:
            set_idx[leader] = new_cnt
            new_cnt += 1
        set_idx[i] = set_idx[leader]
        
    node.m_vertices.resize(new_cnt)
    
    # Merge QEFs and solve
    solvers = [copy_solver(orig_solver) for orig_solver in node.orig_solvers] # Assuming orig_solvers stored
    filters = [MaterialFilter() for _ in range(new_cnt)]
    avg_normals = [vec3(0,0,0) for _ in range(new_cnt)]
    
    for v in vertices:
        idx = set_idx[v.m_surfaceIdx]
        v.m_surfaceIdx = -1
        solvers[idx].merge(v.m_qef)
        avg_normals[idx] += v.m_normal
        filters[idx].add(v.m_material)
        v.m_parent = &node.m_vertices[idx]
        
    lower = min_corner
    upper = min_corner + size
    
    for i in range(new_cnt):
        point = solvers[i].solve(lower, upper)
        node.m_vertices[i].position = point
        node.m_vertices[i].normal = normalize(avg_normals[i])
        node.m_vertices[i].material = filters[i].select()
        node.m_vertices[i].error = solvers[i].eval(point)
        node.m_vertices[i].qef = solvers[i].state()
```

## Subtopics

### Octree Mesh Construction
A topological approach to mesh generation from the octree structure. It places vertices at the center of octree edges where the scalar function signs differ at the endpoints. Segments connect these vertices on each face. Closed chains of segments on cell boundaries are triangulated: nested loops are connected to form annuli, and other loops are closed as topological disks [S3]. This method ensures isotopic approximation but differs from the QEF-based dual contouring approach by relying on topological connectivity rather than least-squares vertex optimization [S3].

## Operating characteristics

**Time Complexity:**
- Grid filling: $O(N^3)$ where $N$ is the grid dimension.
- Octree Build: $O(N^3)$ for leaf construction.
- Clustering: Depends on the depth of the octree and the number of shared edges/faces. In the worst case, it is proportional to the number of nodes in the octree, which is $O(N^3)$. However, clustering reduces the final vertex count, potentially speeding up rendering [S1, S2, unofficial].
- Recalculation: Changing the LOD of one chunk requires recalculating the "skirt" (border) of that chunk and its six neighbors. This is significantly faster than recalculating the entire mesh [S2, unofficial].

**Memory Complexity:**
- Grid: $O(N^3)$ for the uniform grid material array.
- Octree: $O(N^3)$ in the worst case (full tree), but typically much less for sparse data. Each node stores vertices and QEF states. The VBO indexing optimization allows the index array to remain static while vertex data changes, reducing memory churn [S2, unofficial].

**Performance:**
- The method enables efficient LOD rendering by reducing triangle count at a distance [S2, unofficial].
- Frustum culling is optimized by extracting 6 planes from the camera projection matrix and testing bounding spheres. This requires only 6 dot products, additions, and comparisons per sphere, making it very fast. False negatives are acceptable, but false positives (meshes disappearing) are not [S2, unofficial].
- Stitching polygons between different LOD levels is difficult and requires handling specific topological cases (e.g., annuli) with extra triangles to ensure continuity [S2, unofficial][S3].

**Strengths:**
- Supports hierarchical LOD natively.
- Material properties are preserved during clustering.
- Efficient frustum culling.
- VBO indexing allows partial updates for small terrain changes [S2, unofficial].

**Limitations:**
- Complex implementation due to DSU and QEF merging logic.
- Stitching between LOD levels is non-trivial [S2, unofficial].
- Grid size is constrained to powers of two up to 1024 [S1, unofficial].

## Background

The method originates from the "Isomesh" project, an open-source implementation of dual contouring on an octree structure [S1, unofficial]. It was further popularized in the context of voxel game development by Parker Lawrence, who described "Voxel Level of Detail" techniques for optimizing terrain rendering in games [S2, unofficial]. The theoretical underpinnings of topological mesh construction from octrees are discussed in research on isotopic approximation of implicit curves and surfaces [S3]. The technique is used in voxel engines and terrain rendering systems where dynamic LOD and material preservation are critical [S1, S2, unofficial].
