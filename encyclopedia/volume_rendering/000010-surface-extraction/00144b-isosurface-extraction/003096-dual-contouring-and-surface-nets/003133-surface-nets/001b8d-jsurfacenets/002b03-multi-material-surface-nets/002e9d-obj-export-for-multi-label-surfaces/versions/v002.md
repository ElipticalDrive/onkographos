# OBJ Export for Multi-Label Surfaces

Also called: Export to OBJ, OBJ Export

## Overview
This method exports the geometry generated by [Multi-Material Surface Nets](4930-multi-material-surface-nets.md) as a set of surfaces, with each surface enclosing a single material [S1, unofficial]. It differs from single-material exporters by organizing geometry per material label and ensuring consistent vertex winding to support rendering logic that distinguishes between inside and outside faces [S1, unofficial].

## How it works
**Inputs and Outputs:**
The input consists of a set of surfaces where each surface encloses a single material, stored as a `std::vector` of floating-point vertex positions and a `std::vector` of integer triangle indices, where each index references a vertex in the vertex vector [S1, unofficial]. The output is a `.obj` file containing geometry for all materials [S1, unofficial].

**Steps:**
1. Iterate through each material surface.
2. Write the OBJ object header `o Material_<Label>` to identify the object group.
3. Write each vertex position $(x, y, z)$ as a `v` line.
4. Write each triangle using 1-based indices as an `f` line.
5. Ensure vertices are ordered consistently in counterclockwise order to distinguish between inside and outside faces for rendering [S1, unofficial].

**Pseudocode:**
```python
def export_multi_label_obj(vertices, triangles, output_path):
    """
    vertices: list of (x, y, z) tuples
    triangles: list of (i0, i1, i2) tuples referencing vertex indices
    """
    with open(output_path, 'w') as f:
        for v in vertices:
            f.write(f"v {v[0]} {v[1]} {v[2]}\n")
        for tri in triangles:
            f.write(f"f {tri[0]+1} {tri[1]+1} {tri[2]+1}\n")
```

**Parameters:**
* **Index Base:** 1-based (standard OBJ convention) [G].
