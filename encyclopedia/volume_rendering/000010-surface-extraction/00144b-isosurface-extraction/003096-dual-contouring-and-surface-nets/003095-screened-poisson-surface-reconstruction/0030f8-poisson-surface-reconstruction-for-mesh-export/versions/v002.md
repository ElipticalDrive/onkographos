# Poisson Surface Reconstruction for Mesh Export

Also called: Oriented point cloud meshing, Poisson mesh extraction

## Overview
Poisson Surface Reconstruction for Mesh Export is a method to export watertight, colored triangle meshes from 3D Gaussians by solving a Poisson equation on an oriented point cloud derived from the Gaussian splats [S1, unofficial]. It differs from marching cubes, which can produce non-watertight meshes and requires searching for an ideal level set threshold, by always producing a watertight manifold surface [S1, unofficial].

## How it works
**Inputs:** Optimized 3D Gaussian parameters (centers, covariances, view-dependent colors, opacities) [S1, unofficial]. Training view camera poses and intrinsics [S1, unofficial].
**Outputs:** A watertight, colored triangle mesh [S1, unofficial].
**Data Structures:**
*   **Oriented Point Cloud:** A list of points $P = \{p_j\}$, where each $p_j$ contains position $\mathbf{p} = (x, y, z)$, normal $\bar{\mathbf{n}}$ (unit vector), and color $\mathbf{c}$ (RGB) [S1, unofficial].
*   **Poisson Tree:** A hierarchical spatial data structure (octree or similar) used to solve the linear system [G].

**Steps:**
1.  **Render Point Cloud:** Render the object from all training views to produce point locations $\mathbf{p} = (x, y, z)$ [S1, unofficial].
2.  **Compute Normals:** Estimate the normal $\bar{\mathbf{n}}$ for each point using one of two methods [S1, unofficial]:
    *   *Rasterization Locality:* Take horizontal ($\mathbf{p}_x$) and vertical ($\mathbf{p}_y$) screen-space neighbors for each point $\mathbf{p}$ [S1, unofficial]. Calculate:
        $$ \bar{\mathbf{n}} = \frac{(\mathbf{p} - \mathbf{p}_x) \times (\mathbf{p} - \mathbf{p}_y)}{\|(\mathbf{p} - \mathbf{p}_x) \times (\mathbf{p} - \mathbf{p}_y)\|} $$
        [S1, unofficial]
    *   *Gaussian Normal Blending (Preferred):* Reuse the alpha compositing equation to blend local normal estimates $\mathbf{n}_i$ from all Gaussians [S1, unofficial]. The local normal estimate for Gaussian $i$ is:
        $$ \mathbf{n}_i = \frac{\Sigma^{-1}(\mathbf{v}t_i - \mu_i)}{\|\Sigma^{-1}(\mathbf{v}t_i - \mu_i)\|} $$
        where $\Sigma$ is the covariance, $\mathbf{v}$ is the view direction, $t_i$ is the center of the Gaussian in view space, and $\mu_i$ is the mean [S1, unofficial]. The final normal is the alpha-composited result of these $\mathbf{n}_i$ values [S1, unofficial].
3.  **Assign Signs:** Ensure the sign of the normal faces the camera that created the point [S1, unofficial].
4.  **Filter Intersections:** Reject intersections that fail a quality threshold. For a direct intersection, check if $\max_i(w_i) \leq \epsilon$, where $w_i$ is the weight of Gaussian $i$ and $\epsilon$ is typically $0.9$ [S1, unofficial].
5.  **Solve Poisson Equation:** Solve the Poisson equation to produce the watertight mesh:
    $$ \nabla \cdot \nabla \chi = \nabla \cdot \mathbf{V} $$
    where $\chi$ is the indicator function, $\mathbf{V}$ is the vector field estimated from the oriented point cloud, and $\nabla$ is the gradient operator [S1, unofficial]. This is solved via well-conditioned sparse linear systems with Dirichlet boundary constraints [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def poisson_mesh_export(gaussians, cameras, tree_depth, epsilon=0.9):
    """
    Export a watertight mesh from 3D Gaussians using Poisson Surface Reconstruction.
    """
    oriented_points = []
    
    for camera in cameras:
        # Step 1: Render point cloud from training view
        screen_points = rasterize_gaussians(gaussians, camera)
        
        for sp in screen_points:
            p_world = sp['position']
            
            # Step 2: Compute Normal
            px_world, py_world = get_screen_neighbors(sp, screen_points)
            if px_world is not None and py_world is not None:
                # Rasterization Locality
                vec_x = p_world - px_world
                vec_y = p_world - py_world
                normal = normalize(np.cross(vec_x, vec_y))
            else:
                # Gaussian Normal Blending (Preferred)
                normal = blend_normals_alpha_compositing(gaussians, camera, p_world)
            
            # Step 3: Assign Sign
            view_dir = normalize(camera.position - p_world)
            if np.dot(normal, view_dir) < 0:
                normal = -normal
            
            # Step 4: Filter Intersections
            max_weight = get_max_gaussian_weight(sp, gaussians)
            if max_weight <= epsilon:
                continue
            
            color = sp['color']
            oriented_points.append({'pos': p_world, 'normal': normal, 'color': color})
            
    # Step 5: Solve Poisson Equation
    vector_field = build_vector_field(oriented_points)
    # Solve sparse linear system for indicator field [G]
    indicator_field = solve_poisson_system(vector_field, tree_depth)
    # Extract mesh from indicator field [G]
    mesh = extract_mesh_from_indicator(indicator_field)
    return mesh

def rasterize_gaussians(gaussians, camera):
    points = []
    for g in gaussians:
        t_view = transform_to_view_space(g.center, camera.pose)
        x, y = project_to_screen(t_view, camera.intrinsics)
        if is_inside_image(x, y, camera.width, camera.height):
            points.append({'position': g.center, 'screen_pos': (x, y), 'color': g.color, 'gaussians': [g]})
    return points

def get_screen_neighbors(sp, screen_points):
    px, py = None, None
    for other in screen_points:
        dx = abs(other['screen_pos'][0] - sp['screen_pos'][0])
        dy = abs(other['screen_pos'][1] - sp['screen_pos'][1])
        if dx < 1.5 and dy > 0.5: px = other['position']
        if dy < 1.5 and dx > 0.5: py = other['position']
    return px, py

def blend_normals_alpha_compositing(gaussians, camera, point_world):
    point_view = transform_to_view_space(point_world, camera.pose)
    total_alpha = 0.0
    blended_normal = np.array([0.0, 0.0, 0.0])
    sorted_gaussians = sort_gaussians_by_depth(gaussians, camera)
    for g in sorted_gaussians:
        t_i = transform_to_view_space(g.center, camera.pose)
        v = normalize(camera.position - point_world)
        mu_i = g.mean
        # Source formula: ni = Σ⁻¹(vti - μi) / ||...||
        vec = np.linalg.solve(g.covariance, v * t_i - mu_i)
        normal_i = normalize(vec)
        alpha = g.opacity * gaussian_weight(point_view, g)
        blended_normal = alpha_composite_vector(blended_normal, normal_i, alpha, total_alpha)
        total_alpha += alpha * (1 - total_alpha)
    return normalize(blended_normal)

    return max(g.opacity for g in sp['gaussians'])

def transform_to_view_space(point, pose):
    return pose @ np.append(point, 1)

def project_to_screen(point_view, intrinsics):
    return intrinsics @ point_view

def is_inside_image(x, y, w, h):
    return 0 <= x < w and 0 <= y < h

def normalize(v):
    return v / np.linalg.norm(v)

def sort_gaussians_by_depth(gaussians, camera):
    return sorted(gaussians, key=lambda g: np.linalg.norm(g.center - camera.position))

def gaussian_weight(point_view, g):
    return np.exp(-0.5 * (point_view - g.center).T @ np.linalg.inv(g.covariance) @ (point_view - g.center))

def alpha_composite_vector(bg, fg, alpha, bg_alpha):
    return bg * (1 - alpha) + fg * alpha
```

**Parameters:**
*   **Tree Depth:** Controls detail vs. noise. Figure 9 shows tree depths of 6 through 10 [S1, unofficial]. Deeper trees produce more detailed reconstruction but also amplify noise and artifacts [S1, unofficial].
*   **Epsilon ($\epsilon$):** Quality threshold for intersection rejection. Typically $0.9$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Rasterization Locality:** Produces poor results on discontinuities [S1, unofficial].
*   **Noise Amplification:** Deeper Poisson tree depths amplify noise and artifacts [S1, unofficial].
*   **Boundary Conditions:** Dirichlet boundary constraints are required for solving the Poisson equation [S1, unofficial].

## Subtopics

### Surface Recovery via Alpha Thresholding and Poisson Reconstruction
A method to generate high-quality meshes post-training by identifying surface points from high-gradient regions and performing Poisson surface reconstruction [S2, unofficial]. Uses an alpha threshold of $0.95$ to identify surface points by sampling high-gradient regions [S2, unofficial]. NeRF and Instant-NGP produce noisy reconstructions with floating artifacts because they are designed for novel-view synthesis instead of surface reconstruction [S2, unofficial]. Interior features are not well reconstructed by NeRF, Instant-NGP, and NeuS due to limited visibility; NeRFifyMesh captures these via geometry-based sampling [S2, unofficial]. NeRFifyMesh outperforms NeRF and Instant-NGP on all four tested objects, and outperforms NeuS on 3 of 4 objects, based on Chamfer Distance [S2, unofficial].

### LiDARsim
Point cloud meshing step is implemented based on the Poisson surface reconstruction algorithm, which is a modification from the original author’s Surfel-based meshing [S3]. The performance of Poisson surface reconstruction is sensitive to hyperparameters: maximum depth of the tree and the weight threshold for selecting mesh vertices. Grid search is performed on the training set and best parameter selected on the test set [S3].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Produces watertight meshes and handles genus changes, whereas marching cubes can produce non-watertight meshes and requires searching for an ideal level set threshold [S1, unofficial].
*   **Limitations:** Sensitive to noise (amplified by deeper trees); rasterization-based normals fail on discontinuities [S1, unofficial].
*   **When to Use:** When a watertight, manifold mesh is required for downstream applications (e.g., Blender import) [S1, unofficial].

## Background
Poisson Surface Reconstruction was originally developed by Kazhdan, Bolitho, and Hoppe [G]. It has been adapted for 3D Gaussians and neural surfaces to provide an alternative to marching cubes for mesh export [S1, unofficial]. The method leverages the surface definition used by the underlying differentiable renderer [S1, unofficial].
