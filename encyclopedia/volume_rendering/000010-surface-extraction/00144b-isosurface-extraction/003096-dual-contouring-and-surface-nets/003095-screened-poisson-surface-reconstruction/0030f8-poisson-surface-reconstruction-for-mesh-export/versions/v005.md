# Poisson Surface Reconstruction for Mesh Export

Also called: Mesh Extraction Methods, Oriented point cloud meshing, Poisson Surface Reconstruction, Poisson mesh extraction, Screened Poisson Reconstruction, TSDF Fusion and Screened Poisson Reconstruction

## Overview
Poisson Surface Reconstruction for Mesh Export is a method to generate watertight, colored triangle meshes from implicit surface representations, such as 3D Gaussians, by solving a Poisson equation on an oriented point cloud [S1, unofficial]. It differs from marching cubes, which evaluates a volumetric grid and often produces non-watertight meshes or requires searching for an ideal level-set threshold [S1, unofficial]. This method builds on [Screened Poisson Surface Reconstruction](6315-screened-poisson-surface-reconstruction.md) by leveraging the surface definition of the underlying differentiable renderer to create an oriented point set, which is then interpolated into a manifold surface [S1, unofficial].

## How it works
**Inputs:**
*   An implicit surface representation (e.g., 3D Gaussians with means $\mu_i$, covariances $\Sigma_i$, and colors) [S1, unofficial].
*   Training views (camera poses and intrinsics) [S1, unofficial].

**Outputs:**
*   A watertight, colored triangle mesh [S1, unofficial].

**Data Structures:**
*   **Oriented Point Cloud:** A list of points $P = \{p_j\}$ where each $p_j = (x, y, z)$ has an associated normal vector $\bar{n}_j$ and color $c_j$ [S1, unofficial].
*   **Vector Field $V$:** Estimated from the oriented point cloud, representing the gradient of the indicator function [S1, unofficial].
*   **Indicator Function $\chi$:** A scalar field where $\chi=1$ inside the surface and $\chi=0$ outside [S1, unofficial].

**Steps:**

1.  **Render Point Cloud:** Render the object's point cloud from all training views to obtain point locations $p = (x, y, z)$ [S1, unofficial].
2.  **Compute Normals:** Estimate the normal $\bar{n}$ for each point. Two methods are described:
    *   *Rasterization Locality:* For a point $p$, identify its horizontal screen-space neighbor $p_x$ and vertical neighbor $p_y$. Compute the normal as:
        $$ \bar{n} = \frac{(p - p_x) \times (p - p_y)}{\|(p - p_x) \times (p - p_y)\|} $$
        [S1, unofficial]. The sign of the normal must face the camera that created it [S1, unofficial].
    *   *Gaussian Normal Blending (Alpha Compositing):* For 3D Gaussians, blend local normal estimates $n_i$ from all contributing Gaussians using alpha compositing. The local normal estimate for Gaussian $i$ is:
        $$ \vec{n}_i = \frac{\Sigma^{-1}(v t_i - \mu_i)}{\|\Sigma^{-1}(v t_i - \mu_i)\|} $$
        where $\Sigma$ is the covariance, $v$ is the view direction, $t_i$ is the center of the Gaussian in view space, and $\mu_i$ is the mean [S1, unofficial]. This method is preferred for view consistency and requires no neighbors [S1, unofficial].
3.  **Quality Filtering:** Reject intersections that fail a quality threshold. If $w_i$ is the weight of Gaussian $i$, reject if $\max_i(w_i) \le \epsilon$, where $\epsilon$ is typically 0.9 [S1, unofficial].
4.  **Solve Poisson Equation:** Solve the Poisson equation to produce the watertight mesh:
    $$ \nabla \cdot \nabla \chi = \nabla \cdot V $$
    [S1, unofficial]. This is solved via well-conditioned sparse linear systems with Dirichlet boundary constraints [S1, unofficial]. The solution produces a surface that is a 2-manifold folded in $\mathbb{R}^3$ [S1, unofficial].
5.  **Density Culling:** Identify vertices to remove where densities are below the 10th percentile: `vertices_to_remove = densities < np.quantile(densities, 0.1)` [S3, unofficial]. Remove low-density vertices: `mesh.remove_vertices_by_mask(vertices_to_remove)` [S3, unofficial].
6.  **Laplacian Smoothing:** Apply Laplacian smoothing: `mesh.filter_smooth_laplacian(number_of_iterations=laplacian_iters, filter_scope=o3d.geometry.FilterScope.Vertex)` [S3, unofficial]. Compute vertex normals after smoothing: `cleaned_mesh.compute_vertex_normals()` [S3, unofficial].

**Parameters:**
*   **Poisson Tree Depth:** Controls the resolution of the reconstruction. Deeper trees produce more detail but amplify noise and artifacts [S1, unofficial]. Typical values range from 6 to 10 for standard scenes, with 12 used in some implementations for high detail [S3, unofficial].
*   **Quality Threshold ($\epsilon$):** Typically 0.9 [S1, unofficial].

## Subtopics

### [Surface Recovery via Alpha Thresholding and Poisson Reconstruction](10552-surface-recovery-via-alpha-thresholding-and-poisson-reconstr.md)
A method to generate high-quality, watertight triangle meshes from trained neural radiance field representations by identifying surface points through alpha thresholding and reconstructing geometry via Poisson surface reconstruction. It serves as a post-training surface extraction technique, contrasting with methods designed primarily for novel-view synthesis which often produce noisy artifacts. It is distinct from the conventional Structure-from-Motion (SfM) and Multi-View Stereo (MVS) baseline, which relies on external stereo reconstruction pipelines rather than internal neural field gradients.

### LiDARsim
A variant used in LiDAR simulation pipelines where point cloud meshing is implemented based on Poisson surface reconstruction, modified from the original author’s Surfel-based meshing [S5]. The performance is sensitive to hyperparameters, specifically the maximum depth of the tree and the weight threshold for selecting mesh vertices, which are tuned via grid search on the training set and selected on the test set [S5]. The resulting mesh is used for mesh-ray intersection via Intel Embree using the Open3D library [S5].

### Meshing Post-Processing
A naive meshing approach applied to 3D Gaussian Splatting outputs that often produces noisy results [S3, unofficial]. It requires specific parameter tuning, such as setting `poisson_depth` to 12 for best results, as higher values produce infeasible meshes [S3, unofficial]. Mitigation strategies include setting a bounding box to mesh specific parts of the scene or applying Laplacian smoothing in tools like CloudCompare if the mesh is too sharp [S3, unofficial]. For higher accuracy, SuGaR is recommended over this naive approach [S3, unofficial].

### Initial Mesh Reconstruction
A training-free initialization process using a coarse mesh, which can be generated from various methods like image-to-3D models followed by Poisson surface reconstruction [S6]. In experiments, MASt3R and Screened Poisson are used for mesh initialization, though the framework is agnostic to the specific reconstruction method [S6].

## Operating characteristics
*   **Time Complexity:** Solving the Poisson equation involves sparse linear systems, which are generally efficient but scale with the number of points in the oriented point cloud [S1, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Produces watertight meshes and handles genus changes, which marching cubes cannot guarantee [S1, unofficial]. It does not require searching for an ideal level-set threshold [S1, unofficial].
*   **Limitations:** Rasterization locality normal estimation produces poor results on discontinuities [S1, unofficial]. Deeper Poisson tree depths amplify noise and artifacts [S1, unofficial]. The method is sensitive to hyperparameters like tree depth and weight thresholds [S4].

## Background
Poisson Surface Reconstruction was originally introduced by Kazhdan, Bolitho, and Hoppe [31, 32], who proposed solving a Poisson equation to reconstruct a surface from an oriented point cloud [S1, unofficial]. The method has been adapted for modern differentiable rendering pipelines, such as 3D Gaussian Splatting, to export explicit meshes from implicit representations [S1, unofficial]. It is commonly used to export meshes for import into 3D software like Blender [S1, unofficial].
