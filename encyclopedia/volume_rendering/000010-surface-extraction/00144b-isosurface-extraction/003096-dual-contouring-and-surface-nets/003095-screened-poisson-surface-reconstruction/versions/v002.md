# Screened Poisson Surface Reconstruction

Also called: Poisson Surface Reconstruction, SPSR, Surface Extraction via Screened Poisson Surface Reconstruction

## Overview
Screened Poisson Surface Reconstruction (SPSR) is an optimization-based method that fits a surface directly to a single oriented point cloud without prior training [S2]. It solves a Poisson equation to reconstruct a watertight manifold surface, contrasting with marching cubes which may produce non-watertight meshes and require searching for an ideal level set threshold [S1, unofficial]. It is particularly suited for extracting explicit surfaces from 3D Gaussian splats or optimized surfel representations [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** An oriented point cloud $\{ (c_i, n_i) \}_{i=1}^N$, where $c_i$ is the position and $n_i$ is the unit normal vector [S1, unofficial].
*   **Output:** A watertight triangle mesh [S1, unofficial].

**Data Structures:**
The method operates on a discretized domain, typically a regular grid, where scalar values are computed at cell centers or vertices [G]. The core data structure is a sparse grid representing the indicator function's gradient field.

**Steps:**
1.  **Gradient Field Definition:** Define a vector field $F$ such that $F(c_i) \approx n_i$ for each point $c_i$. This is achieved by minimizing the energy:
    $$ E(F) = \int_{\Omega} \| F(x) - f(x) \|^2 dx + \lambda \int_{\Omega} \| \nabla \times F(x) \|^2 dx $$
    where $f(x)$ is the interpolated normal field from the point cloud, and $\lambda$ is a regularization parameter. The term $\nabla \times F$ enforces that $F$ is a gradient field ($F = \nabla \phi$) [G].
2.  **Poisson Solve:** Solve the Poisson equation $\Delta \phi = \nabla \cdot F$ for the scalar potential $\phi$. The surface is defined as the zero-level set of $\phi$ [G].
3.  **Screening:** Apply a screening mechanism to the indicator function to handle noise and under-sampled regions. This involves modifying the interpolation weight (e.g., `pointWeight`) to relax the interpolation constraint, preventing artifacts in sparse areas [S1, unofficial].
4.  **Mesh Extraction:** Extract the mesh from the zero-level set of $\phi$ using a standard isosurface extraction algorithm (e.g., Marching Cubes) [G].

**Parameters:**
*   **pointWeight:** Controls the interpolation weight. Reducing this parameter mitigates under-sampling artifacts by relaxing the constraint that the surface must pass exactly through the points [S1, unofficial].
*   **$\lambda$:** Regularization parameter for the curl-free constraint. Not given in the sources.
*   **Grid Resolution:** Determines the discretization of the domain. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Under-sampled regions:** In areas where the partition-of-unity condition is not met (e.g., surface boundaries), Shepard normalization acts as a kernel regression (Nadaraya–Watson estimator) rather than an interpolant. This causes surfel centers to deviate from the true surface. SPSR with high interpolation weight may produce artifacts here [S1, unofficial].
*   **Sparse or corrupted inputs:** The method struggles with sparse or heavily corrupted inputs [S2].

**Pseudocode:**
```python
def screened_poisson_surface_reconstruction(points, normals, grid_resolution, point_weight):
    """
    Reconstruct a watertight mesh from an oriented point cloud.
    
    Args:
        points: Array of shape (N, 3) containing point positions c_i.
        normals: Array of shape (N, 3) containing unit normal vectors n_i.
        grid_resolution: Integer specifying the grid dimensions.
        point_weight: Float scalar for interpolation weight relaxation.
        
    Returns:
        vertices: Array of shape (V, 3) for mesh vertices.
        faces: Array of shape (F, 3) for mesh faces.
    """
    # Step 1: Interpolate normal field f(x) from points and normals
    # Use Shepard interpolation or similar kernel method with point_weight
    # f(x) = sum_i (w_i(x) * n_i) / sum_i (w_i(x))
    # where w_i(x) depends on distance and point_weight
    def interpolate_normal(x):
        weights = compute_weights(points, x, point_weight)
        weighted_normals = sum(weights[i] * normals[i] for i in range(len(points)))
        sum_weights = sum(weights)
        if sum_weights == 0:
            return [0, 0, 0]
        return weighted_normals / sum_weights

    # Step 2: Define vector field F(x) = f(x) on the grid
    # Compute divergence of F on the grid
    # div_F = sum_j (F_j(x + e_j) - F_j(x - e_j)) / (2 * dx)
    div_F = compute_divergence_on_grid(interpolate_normal, grid_resolution)

    # Step 3: Solve Poisson equation Delta phi = div_F
    # Use iterative solver (e.g., Conjugate Gradient)
    phi = solve_poisson(div_F, grid_resolution)

    # Step 4: Extract mesh from zero-level set of phi
    # Use Marching Cubes or similar algorithm
    vertices, faces = extract_mesh(phi, grid_resolution)

    return vertices, faces

def compute_weights(points, query_point, point_weight):
    """
    Compute interpolation weights for Shepard interpolation.
    """
    weights = []
    for p in points:
        dist = norm(query_point - p)
        # Weight function depends on point_weight and distance
        # Typical form: w = 1 / (dist^2 + epsilon) ^ point_weight
        # Note: Exact weight function not specified in sources [G]
        w = 1.0 / (dist**2 + 1e-6) ** point_weight
        weights.append(w)
    return weights

def compute_divergence_on_grid(interpolate_normal, grid_resolution):
    """
    Compute divergence of the interpolated normal field on the grid.
    """
    # Initialize grid for divergence
    div_grid = zeros(grid_resolution)
    # Iterate over grid cells and compute divergence
    for x in grid_cells(grid_resolution):
        F = interpolate_normal(x)
        # Approximate divergence using finite differences
        # div_F approx sum_j (F_j(x + e_j) - F_j(x - e_j)) / (2 * dx)
        div_val = 0.0
        for j in range(3):
            F_plus = interpolate_normal(x + grid_step[j])
            F_minus = interpolate_normal(x - grid_step[j])
            div_val += (F_plus[j] - F_minus[j]) / (2 * grid_step_size)
        div_grid[x] = div_val
    return div_grid

def solve_poisson(div_F, grid_resolution):
    """
    Solve Delta phi = div_F using an iterative solver.
    """
    # Initialize phi
    phi = zeros(grid_resolution)
    # Use Conjugate Gradient or similar solver
    # phi = solve(A * phi = b, A=laplacian, b=div_F)
    # Note: Exact solver implementation details not specified in sources [G]
    phi = iterative_solver(laplacian_matrix(grid_resolution), div_F.flatten())
    return phi.reshape(grid_resolution)

def extract_mesh(phi, grid_resolution):
    """
    Extract mesh from zero-level set of phi using Marching Cubes.
    """
    # Use standard Marching Cubes algorithm
    vertices, faces = marching_cubes(phi)
    return vertices, faces
```

## Subtopics

### [Poisson Surface Reconstruction for Mesh Export](6401-poisson-surface-reconstruction-for-mesh-export.md)
Poisson Surface Reconstruction for Mesh Export is a method to export watertight, colored triangle meshes from 3D Gaussians by solving a Poisson equation on an oriented point cloud derived from the Gaussian splats. It differs from marching cubes, which can produce non-watertight meshes and requires searching for an ideal level set threshold, by always producing a watertight manifold surface.

## Operating characteristics
*   **Time Complexity:** Depends on the grid resolution and the number of points. Solving the Poisson equation is typically $O(N \log N)$ or $O(N)$ with iterative solvers, where $N$ is the number of grid cells. Interpolating the normal field is $O(N \cdot M)$, where $M$ is the number of points.
*   **Memory Complexity:** Proportional to the grid resolution and the number of points.
*   **Strengths:** Produces watertight, manifold surfaces. Handles noisy data well with appropriate screening. Suitable for inverse rendering and physics simulation [S1, unofficial].
*   **Limitations:** Struggles with sparse or heavily corrupted inputs [S2]. Artifacts can occur in under-sampled regions if interpolation weight is not adjusted [S1, unofficial].
*   **When to use:** When a watertight mesh is required from an oriented point cloud, especially for downstream tasks like physics simulation or integration into mesh-based rendering pipelines [S1, unofficial].
*   **When not to use:** For sparse or heavily corrupted inputs where other approximation-based approaches with smoothness priors (e.g., NKSR) might be better suited [S1, unofficial].

## Background
SPSR was introduced by Kazhdan and Hoppe in 2013 [S1, unofficial]. It builds upon the original Poisson Surface Reconstruction method by Hoppe et al. (1992) [S1, unofficial]. The method has been widely used in computer graphics for surface reconstruction from point clouds, including recent applications in 3D Gaussian splatting and inverse rendering [S1, unofficial].
