# Dual Contouring Feature Point Iterative Projection

Also called: Feature Point Iterative Projection, Iterative Feature Point Projection

## Overview
This method computes the single vertex position for an active voxel cell in dual contouring by iteratively projecting a point onto planes defined by intersecting edge midpoints and their surface normals [S1, S2, unofficial]. It serves as an alternative to solving the full least-squares system in standard Dual Contouring, offering a simpler, fixed-iteration approach that approximates the feature point by averaging projections [S1, S2, unofficial]. Unlike Surface Nets, which uses geometric centroids of intersections, this method uses local gradient information (normals) to converge toward a point that minimizes distance to the local surface approximation [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A voxel cell with $k$ intersecting edges. For each intersecting edge $i$, the input includes the edge midpoint $M_i$ and the surface normal $N_i$ at that midpoint. The normal $N_i$ is typically derived from the scalar field gradient.
*   **Output:** A single 3D vertex position $V$ for the cell.

**Data Structures:**
The method operates on a set of planes. Each plane $P_i$ is defined by an origin (the edge midpoint $M_i$) and a normal vector $N_i$.
*   Plane representation: A plane can be stored as $(N_i, d_i)$ where $d_i = -N_i \cdot M_i$, or explicitly as origin and normal.
*   Point representation: A 3D vector $C$ (current point).

**Parameters:**
*   **Iterations ($I$):** The number of projection steps. A typical value is 5 [S1, S2, unofficial].
*   **Step Size Factor ($\alpha$):** A multiplier for the averaged displacement vector. A typical value is 0.7 [S1, S2, unofficial]. Note that convergence may occur without scaling ($\alpha=1.0$), but scaling can stabilize the process [S1, S2, unofficial].

**Algorithm Steps:**
1.  **Initialization:** Set the current point $C$ to the center of the voxel cell, $C_0 = \text{Center}$.
2.  **Plane Construction:** For each of the $k$ intersecting edges in the cell, create a plane $P_i$ using the edge midpoint $M_i$ as the origin and the edge normal $N_i$ as the normal.
3.  **Iteration:** Repeat for $i = 1$ to $I$:
    a.  **Distance Calculation:** For each plane $P_j$ ($j=0 \dots k-1$), calculate the signed distance from the current point $C$ to the plane.
        $$ d_j = N_j \cdot (C - M_j) $$
        Alternatively, if the plane is stored as $(N_j, d_{plane,j})$ where $d_{plane,j} = -N_j \cdot M_j$, then:
        $$ d_j = N_j \cdot C + d_{plane,j} $$
    b.  **Displacement Vector Calculation:** Calculate the shortest distance vector $v_j$ from $C$ to plane $P_j$. This vector points from $C$ towards the plane along the normal.
        $$ v_j = d_j \cdot N_j $$
    c.  **Averaging:** Compute the average of all displacement vectors:
        $$ \bar{v} = \frac{1}{k} \sum_{j=0}^{k-1} v_j $$
    d.  **Update:** Update the current point by subtracting the averaged displacement vector scaled by $\alpha$:
        $$ C_{new} = C - \alpha \cdot \bar{v} $$
        $$ C \leftarrow C_{new} $$
4.  **Result:** Return $C$ as the feature point vertex.

**Mathematical Equivalence:**
The update step can be viewed as projecting the point $C$ onto each plane individually and then averaging the projected points. The projection of $C$ onto plane $P_j$ is:
$$ P_j(C) = C - d_j N_j $$
Averaging these projections:
$$ C_{new} = \frac{1}{k} \sum_{j=0}^{k-1} (C - d_j N_j) = C - \frac{1}{k} \sum_{j=0}^{k-1} d_j N_j = C - \bar{v} $$
This confirms that subtracting the average displacement vector is mathematically equivalent to averaging the projected points [S1, S2, unofficial].

**Pseudocode:**
```python
def compute_feature_point(itersecting_edges, cell_center, iterations=5, step_factor=0.7):
    """
    Computes the feature point for a voxel cell using iterative projection.
    
    Args:
        intersecting_edges: List of objects/tuples, each containing:
            - mid: Vector3 (edge midpoint)
            - normal: Vector3 (surface normal at midpoint, normalized)
        cell_center: Vector3 (center of the voxel)
        iterations: int (number of projection steps)
        step_factor: float (scaling factor for the update step)
        
    Returns:
        Vector3 (the computed feature point)
    """
    # Initialize current point to cell center
    c = cell_center
    
    # Pre-calculate plane parameters if desired, or compute on the fly
    # Plane j is defined by origin M_j and normal N_j
    
    for i in range(iterations):
        avg_displacement = Vector3(0, 0, 0)
        
        for edge in intersecting_edges:
            m = edge.mid
            n = edge.normal
            
            # Calculate signed distance from c to the plane defined by m and n
            # distance = dot(n, c - m)
            distance = dot(n, c - m)
            
            # Calculate displacement vector: distance * normal
            # This vector points from c towards the plane along the normal direction
            displacement = distance * n
            
            avg_displacement += displacement
        
        # Average the displacement vectors
        k = len(intersecting_edges)
        if k > 0:
            avg_displacement = avg_displacement / k
            
            # Update the current point
            # Subtracting the average displacement moves the point towards the planes
            c = c - step_factor * avg_displacement
            
        else:
            # No intersecting edges? Return center or handle as error
            # [G] If no edges intersect, the cell is not active or degenerate.
            # Return center as fallback.
            pass
            
    return c
```

**Edge Cases and Pitfalls:**
*   **Non-intersecting Planes:** If the planes defined by the edge normals do not intersect (e.g., due to noisy normals or a highly curved surface approximated by few edges), the iterative projection may fail to converge to a single point or may converge outside the voxel [S1, S2, unofficial].
*   **Direction of Update:** It is critical to *subtract* the averaged displacement vector. Adding it moves the point away from the intersection minimum [S1, S2, unofficial].
*   **Convergence Stability:** Using a step factor $\alpha < 1.0$ (e.g., 0.7) can help stabilize convergence, especially if the normals are inconsistent or the surface is complex [S1, S2, unofficial]. Without scaling, the method may still converge but might oscillate or diverge in some cases.
*   **Number of Edges:** The method averages over all intersecting edges. If the number of intersecting edges varies significantly between cells, the behavior may differ. Standard dual contouring cells typically have 3 to 12 intersecting edges depending on the topology.

## Operating characteristics
*   **Time Complexity:** $O(I \cdot k)$ per cell, where $I$ is the number of iterations and $k$ is the number of intersecting edges per cell. This is generally faster than solving the least-squares system in standard Dual Contouring, which involves matrix operations ($O(k^3)$ or $O(k^2)$ depending on implementation) per cell.
*   **Memory Complexity:** $O(1)$ per cell, as it only requires storing the current point and accumulating displacement vectors. No large matrices are needed.
*   **Strengths:** Simple to implement, computationally efficient, does not require solving linear systems.
*   **Limitations:** Approximate solution; may not converge to the exact least-squares solution. Quality depends on the accuracy of the normals and the number of iterations. May fail if planes do not intersect consistently.
*   **When to Use:** When computational resources are limited, or when a good approximation of the feature point is sufficient. Useful for real-time applications or when normals are already available and reliable.
*   **When Not to Use:** When high accuracy is required, or when the surface geometry is complex and the least-squares solution is necessary to preserve sharp features.
