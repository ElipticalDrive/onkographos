# Edge Contouring for Dual Contouring

Also called: ContourEdgeProc, ContourProcessEdge

## Overview
Edge Contouring is a recursive procedure that processes the edges of an adaptive octree to generate triangle indices for a dual contouring mesh [S1, unofficial]. It handles both leaf/pseudo-leaf nodes and internal nodes by recursing into children, ensuring that geometry is generated only at the boundaries between solid and air regions [S1, unofficial]. It builds on [Manifold Dual Contouring - Index Processing and Triangle Generation](3699-manifold-dual-contouring-index-processing-and-triangle-gener.md) by providing the specific octree-aware traversal logic required for adaptive volumetric data.

## How it works
**Inputs:**
- `nodes`: An array of 4 `OctreeNode*` pointers representing the nodes associated with the edge being processed.
- `dir`: An integer representing the edge direction (0, 1, or 2).
- `indexBuffer`: A reference to an index buffer or list where generated triangle indices are appended.

**Outputs:**
- Updates `indexBuffer` with triangle indices.

**Data Structures:**
- `edgeProcEdgeMask`: A 3D array of integers with layout `[3][2][5]`. It maps edge direction `dir`, sub-edge index `i`, and mask components.
  - Components 0-3: Child indices for the four nodes in the current level.
  - Component 4: The sub-direction for the recursive call.
- `Node` types: `Node_Leaf`, `Node_Pseudo` (or `Node_Psuedo`), `Node_Internal`.

**Steps:**
1. **Base Case:** If any of the 4 input nodes in `nodes` is `null`, return immediately [S1, unofficial].
2. **Leaf/Pseudo Case:** If all 4 nodes are not `Node_Internal` (i.e., they are `Node_Leaf` or `Node_Pseudo`), call `ContourProcessEdge(node, dir, indexBuffer)` [S1, unofficial]. Note: The specific implementation of `ContourProcessEdge` is defined in the parent article [3699-manifold-dual-contouring-index-processing-and-triangle-gener.md].
3. **Internal Case:** If any node is `Node_Internal`, iterate `i` from 0 to 1:
   a. Extract child indices `c[0..3]` from `edgeProcEdgeMask[dir][i][0..3]` [S1, unofficial].
   b. Create a new array `edgeNodes` of size 4.
   c. For each `j` from 0 to 3:
      - If `nodes[j]` is `null`, `edgeNodes[j]` remains `null`.
      - If `nodes[j]` is `Node_Leaf` or `Node_Pseudo`, set `edgeNodes[j] = nodes[j]`.
      - If `nodes[j]` is `Node_Internal`, set `edgeNodes[j] = nodes[j]->children[c[j]]`.
   d. Recurse: Call `ContourEdgeProc(edgeNodes, edgeProcEdgeMask[dir][i][4], indexBuffer)` [S1, unofficial].

**Pseudocode:**
```python
def ContourEdgeProc(nodes, dir, indexBuffer):
    # nodes: list of 4 OctreeNode or None
    # dir: int (0, 1, 2)
    # indexBuffer: list of ints
    
    # Base case: if any node is null, return
    for node in nodes:
        if node is None:
            return

    # Leaf/Pseudo case: if all nodes are not Internal
    all_leaf_or_pseudo = True
    for node in nodes:
        if node.type == Node_Internal:
            all_leaf_or_pseudo = False
            break
            
    if all_leaf_or_pseudo:
        # Call the edge processing function defined in parent article
        ContourProcessEdge(nodes, dir, indexBuffer)
        return

    # Internal case: recurse into children
    for i in range(2):
        # Extract child indices from mask
        # edgeProcEdgeMask[dir][i][0..3] are child indices
        # edgeProcEdgeMask[dir][i][4] is the sub-direction
        child_indices = edgeProcEdgeMask[dir][i][0:4]
        sub_dir = edgeProcEdgeMask[dir][i][4]
        
        edge_nodes = [None] * 4
        for j in range(4):
            if nodes[j] is None:
                edge_nodes[j] = None
            elif nodes[j].type in (Node_Leaf, Node_Pseudo):
                edge_nodes[j] = nodes[j]
            else:
                # Node is Internal, get child
                child_idx = child_indices[j]
                edge_nodes[j] = nodes[j].children[child_idx]
                
        # Recurse
        ContourEdgeProc(edge_nodes, sub_dir, indexBuffer)
```

**Parameters:**
- `edgeProcEdgeMask`: A 3D array `[3][2][5]` mapping edge direction `dir`, sub-edge index `i`, and mask components. Components 0-3 are child indices, component 4 is the sub-direction [S1, unofficial].

**Edge Cases and Pitfalls:**
- Null nodes: The algorithm explicitly checks for null nodes at the start and handles them by skipping recursion for that branch [S1, unofficial].
- Pseudo-leaf nodes: Nodes converted from internal to pseudo-leaf (e.g., due to QEF mass point projection) are treated as leaves for contouring purposes [S1, unofficial].

### [Octree-based Dual Contouring Edge/Face Processing](4297-octree-based-dual-contouring-edge-face-processing.md)
This method is a recursive procedure that processes the edges and faces of an adaptive octree to generate triangle indices for a dual contouring mesh. It handles both leaf and pseudo-leaf nodes by descending into children when necessary, ensuring that geometry is generated only at the boundaries between solid and air regions. It builds on [Edge Contouring for Dual Contouring](3711-edge-contouring-for-dual-contouring.md) by providing the specific octree-aware traversal and edge processing logic required for adaptive volumetric data.

### Manifold Dual Contouring - Edge Clustering
If all four nodes in the nodes array are either null or `Node_Leaf` (not `Node_Internal`), call `ClusterIndexes(nodes, direction, intHolder, collected_vertices)` [S2, unofficial]. Else, loop `i` from 0 to 1. Create `edge_nodes` array size 4. Loop `j` from 0 to 3: if `nodes[j]` is null, continue. If `nodes[j].Type == Node_Leaf`, `edge_nodes[j] = nodes[j]`. Else, `edge_nodes[j] = nodes[j].children[Utilities.TEdgeProcEdgeMask[direction][i][j]]` [S2, unofficial].
