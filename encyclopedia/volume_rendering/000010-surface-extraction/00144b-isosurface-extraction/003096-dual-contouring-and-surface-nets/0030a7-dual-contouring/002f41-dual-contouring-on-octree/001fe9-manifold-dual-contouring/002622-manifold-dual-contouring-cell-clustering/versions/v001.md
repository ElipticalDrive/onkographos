# Manifold Dual Contouring - Cell Clustering

Also called: ClusterCell, MDC, Manifold Dual Contouring (Java Implementation)

## Overview
Manifold Dual Contouring - Cell Clustering is the topological consolidation phase of the Manifold Dual Contouring algorithm, responsible for merging vertices from child octree nodes into a single manifold-compliant vertex per contour component within a parent node. It differs from standard dual contouring by enforcing manifold constraints through explicit vertex collapsing and edge processing, ensuring the resulting mesh is a valid 2-manifold without self-intersections or non-manifold edges [S1, unofficial]. It builds on [Manifold Dual Contouring](2138-manifold-dual-contouring.md) by handling the adaptive octree structure's internal consistency.

## How it works
**Inputs and Outputs:**
- Input: An octree node (`MdcOctreeNode`) of type `Node_Internal` or `Node_Leaf`, and a scalar error threshold (unused in the core clustering logic shown, but passed as `error`).
- Output: The input node's `vertices` array is updated to contain the clustered `MdcVertex` objects. Child nodes are traversed but not modified in structure; their vertices are consumed.

**Data Structures:**
- `MdcOctreeNode`:
  - `Type`: Enum (`Node_Internal`, `Node_Leaf`).
  - `children`: Array of 8 `MdcOctreeNode` references.
  - `vertices`: Array of `MdcVertex`.
  - `corners`: Integer bitmask representing the sign of the implicit field at the 8 corners of the node.
- `MdcVertex`:
  - `surface_index`: Integer identifier for the contour component this vertex belongs to. Initialized to -1.
  - `parent`: Reference to another `MdcVertex` (used for collapsing).
  - `qef`: `QEFData` object containing the Quadratic Error Function matrix and vector.
  - `normal`: `Vec3f` (accumulated surface normal).
  - `eis`: Integer array of size 12, storing edge intersection counts (Edge Intersection Signs/Counts).
  - `euler`: Integer, Euler characteristic contribution.
  - `in_cell`: Integer, index of the child cell this vertex originated from.
  - `face_prop2`: Boolean, flag for face property validation.
  - `pos`: `Vec3f`, position (solved from QEF later).
  - `error`: Float, QEF error value.
- `Utilities`: Static class containing lookup tables:
  - `EdgePairs`: `int[12][2]`, maps edge index to two corner indices.
  - `TCellProcEdgeMask`: `int[6][5]`, maps internal edge index to 4 child node indices and a direction.
  - `TFaces`: `int[6][4]`, maps face index to 4 edge indices.
  - `TExternalEdges`: `int[8][3]`, maps corner index to 3 external edge indices.
  - `TInternalEdges`: `int[8][8]`, maps corner index to 8 internal edge indices.

**Algorithm Steps:**

1. **Recursive Child Processing:**
   - If `node.Type != Node_Internal`, return.
   - Initialize `signs` array of size 8 to -1.
   - Initialize `mid_sign` to -1.
   - Initialize `is_collapsible` to `true`.
   - For `i` from 0 to 7:
     - If `node.children[i]` is `null`, continue.
     - Recursively call `ClusterCell(node.children[i], error)`.
     - If `node.children[i].Type == Node_Internal`, set `is_collapsible = false`.
     - Else (Leaf):
       - `mid_sign = (node.children[i].corners >> (7 - i)) & 1`
       - `signs[i] = (node.children[i].corners >> i) & 1`
   - Reset `node.corners` to 0.
   - For `i` from 0 to 7:
     - If `signs[i] == -1`, `node.corners |= (byte)(mid_sign << i)`.
     - Else, `node.corners |= (byte)(signs[i] << i)`.

2. **Face and Edge Clustering:**
   - Initialize `surface_index` to 0.
   - Initialize `collected_vertices` list.
   - Initialize `new_vertices` list.
   - For `i` from 0 to 11 (6 Euclidean edges, mapped to 12 half-edges or similar):
     - Get `c1, c2` from `Utilities.EdgePairs[i]`.
     - Set `face_nodes[0] = node.children[c1]`, `face_nodes[1] = node.children[c2]`.
     - Call `ClusterFace(face_nodes, Utilities.EdgePairs[i][2], surface_index, collected_vertices)`.
   - For `i` from 0 to 5 (internal edges):
     - Get `edge_nodes` from `node.children` using `Utilities.TCellProcEdgeMask[i][0..3]`.
     - Call `ClusterEdge(edge_nodes, Utilities.TCellProcEdgeMask[i][4], surface_index, collected_vertices)`.

3. **Stray Vertex Collection:**
   - Set `highest_index = surface_index`. If `highest_index == -1`, set `highest_index = 0`.
   - For each child `n` in `node.children`:
     - If `n` is `null`, continue.
     - For each vertex `v` in `n.vertices`:
       - If `v` is `null`, continue.
       - If `v.surface_index == -1`:
         - Set `v.surface_index = highest_index++`.
         - Add `v` to `collected_vertices`.

4. **Vertex Clustering and QEF Assembly:**
   - Initialize `clustered_count = 0`.
   - If `collected_vertices.size() > 0`:
     - For `i` from 0 to `highest_index`:
       - Create `QEFData qef` with `LevenQefSolver`.
       - Initialize `normal = Vec3f(0)`, `count = 0`.
       - Initialize `edges` array of size 12 to 0.
       - Initialize `euler = 0`, `e = 0`.
       - For each `v` in `collected_vertices`:
         - If `v.surface_index == i`:
           - For `k` from 0 to 2:
             - `edge = Utilities.TExternalEdges[v.in_cell][k]`
             - `edges[edge] += v.eis[edge]`
           - For `k` from 0 to 8:
             - `edge = Utilities.TInternalEdges[v.in_cell][k]`
             - `e += v.eis[edge]`
           - `euler += v.euler`
           - `qef.add(v.qef)`
           - `normal = normal.add(v.normal)`
           - `count++`
       - If `count == 0`, continue to next `i`.
       - **Face Property Check:**
         - Set `face_prop2 = true`.
         - For `f` from 0 to 5:
           - If `face_prop2`:
             - `intersections = 0`
             - For `ei` from 0 to 3:
               - `intersections += edges[Utilities.TFaces[f][ei]]`
             - If `intersections != 0` and `intersections != 2`, set `face_prop2 = false`.
       - Create `new_vertex`.
       - `normal = normal.div(count)`.
       - `normal.normalize()`.
       - `new_vertex.normal = normal`.
       - `new_vertex.qef = qef`.
       - `new_vertex.eis = edges`.
       - `new_vertex.euler = euler - e / 4`.
       - `new_vertex.in_cell = node.child_index`.
       - `new_vertex.face_prop2 = face_prop2`.
       - Add `new_vertex` to `new_vertices`.
       - **Parent Pointer Assignment:**
         - For each `v` in `collected_vertices`:
           - If `v.surface_index == i`:
             - If `v.parent != new_vertex`:
               - `v.parent = new_vertex`
             - Else:
               - `v.parent = null`

5. **Finalization:**
   - If `collected_vertices.size() == 0`, return.
   - For each `v2` in `collected_vertices`:
     - Set `v2.surface_index = -1`.
   - Set `node.vertices = new_vertices`.

**Pseudocode:**

```python
def ClusterCell(node: MdcOctreeNode, error: float):
    if node.Type != Node_Internal:
        return

    signs = [-1] * 8
    mid_sign = -1
    is_collapsible = True

    for i in range(8):
        child = node.children[i]
        if child is None:
            continue
        ClusterCell(child, error)
        if child.Type == Node_Internal:
            is_collapsible = False
        else:
            mid_sign = (child.corners >> (7 - i)) & 1
            signs[i] = (child.corners >> i) & 1

    node.corners = 0
    for i in range(8):
        if signs[i] == -1:
            node.corners |= (mid_sign << i)
        else:
            node.corners |= (signs[i] << i)

    surface_index = 0
    collected_vertices = []
    new_vertices = []

    # Process 12 faces/edges
    for i in range(12):
        c1, c2 = Utilities.EdgePairs[i][0], Utilities.EdgePairs[i][1]
        face_nodes = [node.children[c1], node.children[c2]]
        direction = Utilities.EdgePairs[i][2]
        ClusterFace(face_nodes, direction, surface_index, collected_vertices)

    # Process 6 internal edges
    for i in range(6):
        edge_nodes = [node.children[idx] for idx in Utilities.TCellProcEdgeMask[i][:4]]
        direction = Utilities.TCellProcEdgeMask[i][4]
        ClusterEdge(edge_nodes, direction, surface_index, collected_vertices)

    highest_index = surface_index
    if highest_index == -1:
        highest_index = 0

    # Gather stray vertices
    for child in node.children:
        if child is None:
            continue
        for v in child.vertices:
            if v is None:
                continue
            if v.surface_index == -1:
                v.surface_index = highest_index
                highest_index += 1
                collected_vertices.append(v)

    # Cluster vertices
    if len(collected_vertices) > 0:
        for i in range(highest_index):
            qef = QEFData(LevenQefSolver())
            normal = Vec3f(0, 0, 0)
            count = 0
            edges = [0] * 12
            euler = 0
            e = 0

            for v in collected_vertices:
                if v.surface_index == i:
                    for k in range(3):
                        edge_idx = Utilities.TExternalEdges[v.in_cell][k]
                        edges[edge_idx] += v.eis[edge_idx]
                    for k in range(8):
                        edge_idx = Utilities.TInternalEdges[v.in_cell][k]
                        e += v.eis[edge_idx]
                    euler += v.euler
                    qef.add(v.qef)
                    normal = normal.add(v.normal)
                    count += 1

            if count == 0:
                continue

            face_prop2 = True
            for f in range(6):
                if face_prop2:
                    intersections = 0
                    for ei in range(4):
                        intersections += edges[Utilities.TFaces[f][ei]]
                    if intersections != 0 and intersections != 2:
                        face_prop2 = False

            new_vertex = MdcVertex()
            normal = normal.div(count)
            normal.normalize()
            new_vertex.normal = normal
            new_vertex.qef = qef
            new_vertex.eis = edges
            new_vertex.euler = euler - e / 4.0
            new_vertex.in_cell = node.child_index
            new_vertex.face_prop2 = face_prop2
            new_vertices.append(new_vertex)

            for v in collected_vertices:
                if v.surface_index == i:
                    if v.parent != new_vertex:
                        v.parent = new_vertex
                    else:
                        v.parent = None

    if len(collected_vertices) == 0:
        return

    for v2 in collected_vertices:
        v2.surface_index = -1

    node.vertices = new_vertices
```

**Formulas:**
- Intersection Point (used in leaf construction, referenced by clustering context):
  $$p = p_1 + \frac{-d_1}{d_2 - d_1} (p_2 - p_1)$$
  where $p_1, p_2$ are endpoints, $d_1, d_2$ are scalar values at endpoints [S1, unofficial].
- Surface Normal (used in leaf construction):
  $$n = \frac{1}{2H} [f(x+H,y,z)-f(x-H,y,z), f(x,y+H,z)-f(x,y-H,z), f(x,y,z+H)-f(x,y,z-H)]^T$$
  normalized, where $H=1$ [S1, unofficial].

**Parameters:**
- `EnforceManifold`: Boolean flag controlling manifold enforcement; default value is `true` [S1, unofficial].

**Edge Cases and Pitfalls:**
- Null children: The algorithm skips `null` children in all loops. If all children are null, the node remains empty.
- Zero count: If no vertices are collected for a specific `surface_index`, the loop continues, preventing division by zero in normal averaging.
- Face Property 2: The check `intersections != 0 and intersections != 2` ensures manifold consistency on faces. If this fails, `face_prop2` is set to false, which may affect downstream triangle generation [S1, unofficial].

## Subtopics

### Manifold Dual Contouring - Face Clustering
This method processes a face shared by two octree nodes (or a node and null) to cluster vertices along the face's edges. It recursively processes sub-faces if the input nodes are internal, and then processes the 4 edges of the face using `ClusterEdge`. It differs from cell clustering by operating on a 2D face subset, ensuring manifold constraints are maintained across face boundaries. It is called by `ClusterCell` for each of the 12 face edges. [S1, unofficial]

### Manifold Dual Contouring - Edge Clustering
This method processes an edge shared by four octree nodes. It collects vertices from the 4 child nodes, resolves conflicts by traversing parent pointers to find the highest valid vertex, and assigns a `surface_index` to group vertices belonging to the same contour component. It uses `TProcessEdgeMask` to determine edge indices and `TransformedEdgesTable` to resolve vertex conflicts based on corner signs. It is called by `ClusterCell` for each of the 6 internal edges and by `ClusterFace` for the 4 face edges. [S1, unofficial]

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of vertices in the octree leaves, as each vertex is processed a constant number of times during clustering. The recursive traversal is proportional to the number of octree nodes.
- **Memory Complexity:** Proportional to the number of vertices in the octree, as vertices are stored in node arrays and collected into lists during clustering.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales well with adaptive octree depth, as clustering is performed locally per node.
- **Strengths:** Ensures manifold output, handles adaptive resolution, simplifies topology.
- **Limitations:** Complex implementation, relies on specific lookup tables, may produce degenerate geometry if face property checks fail.
- **When to use:** When a manifold mesh is required from an implicit field with adaptive resolution.
- **When not to use:** When non-manifold geometry is acceptable or when performance is critical and manifold constraints can be relaxed.

## Background
Originated from the Java implementation by John Lin20, available on GitHub [S1, unofficial]. It is a variant of Dual Contouring that integrates manifold constraints into the vertex clustering process. It is used in real-time rendering applications where manifold meshes are required for correct shading and rendering.
