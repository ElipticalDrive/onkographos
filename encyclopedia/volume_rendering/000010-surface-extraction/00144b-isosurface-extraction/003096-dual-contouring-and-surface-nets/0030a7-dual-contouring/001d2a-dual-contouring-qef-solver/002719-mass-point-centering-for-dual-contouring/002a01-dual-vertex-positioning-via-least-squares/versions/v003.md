# Dual Vertex Positioning via Least Squares

Also called: Dual Vertex Localization via Quadratic Error Minimization, Ju et al. 2002 Method, Least Squares Dual Vertex, Minimizing Distance to Intersections, Quadratic Error Function (QEF) Vertex Placement

## Overview
This method computes the position of a dual vertex within a voxel cell by minimizing the squared distance to all edge intersection points on the isosurface boundary of that cell [S1, unofficial]. It sets itself apart from simpler centering methods by using a weighted least-squares fit of the local surface geometry (normals and intersections) rather than just averaging coordinates, providing a more accurate representation of the underlying isosurface [S1, unofficial]. It builds on [Mass Point Centering for Dual Contouring](3939-mass-point-centering-for-dual-contouring.md) by centering the linear system solution around the centroid of the sample points to improve numerical stability [S1, unofficial].

## How it works
**Inputs:**
- A voxel cell intercepted by the isosurface $\partial V$ [S1, unofficial].
- The scalar field values at the voxel corners [S1, unofficial].
- The scalar field volume data for gradient computation [S1, unofficial].

**Outputs:**
- The 3D position $x$ of the dual vertex associated with the cell [S1, unofficial].

**Data Structures:**
- $p_i$: 3D coordinate of the $i$-th edge intersection point [S1, unofficial].
- $n_i$: 3D normal vector at the $i$-th intersection point [S1, unofficial].
- $A$: An $n \times 3$ matrix where each row $i$ is the normal vector $n_i^T$ [S1, unofficial].
- $b$: An $n$-dimensional vector where each element $b_i = n_i \cdot p_i$ [S1, unofficial].
- $p$: The center of mass (mean) of all intersection points $p_i$ [S1, unofficial].

**Steps:**
1. **Identify Intersections and Normals:** For each edge of the cell intercepted by the isosurface $\partial V$, identify the two transition voxels belonging to that edge [S1, unofficial]. Calculate the intersection point $p_i$ using linear interpolation between these two voxels based on their coordinates and scalar values [S1, unofficial]. Calculate the normal $n_i$ at $p_i$ by applying the Prewitt operator to the volume data, which approximates the gradient by convolving $3 \times 3 \times 3$ masks with the volume [S1, unofficial].
2. **Compute Center of Mass:** Calculate $p$, the center of mass of the intersection points: $p = \frac{1}{n} \sum_{i=1}^{n} p_i$ [S1, unofficial].
3. **Construct Linear System:** Construct the matrix $A$ and vector $b$ as defined above [S1, unofficial]. The goal is to solve the overdetermined system $Ax = b$ in the least-squares sense, which minimizes the error function $E[x] = \sum_i (n_i \cdot (x - p_i))^2$ [S1, unofficial].
4. **Solve for Offset:** Compute the offset $c$ from the center of mass using the Moore-Penrose pseudo-inverse of $A^T A$: $c = (A^T A)^+ (A^T b - A^T A p)$ [S1, unofficial]. The pseudo-inverse $(A^T A)^+$ is computed via Singular Value Decomposition (SVD) [S1, unofficial].
5. **Compute Final Position:** Calculate the dual vertex position: $x = c + p$ [S1, unofficial].
6. **Boundary Check:** If the resulting position $x$ falls outside the spatial bounds of the cell, use the center of mass $p$ directly as the dual vertex position [S1, unofficial].

**Pseudocode:**
```python
def compute_dual_vertex(cell_edges, scalar_field, voxel_size, iso_value=0.0):
    intersections = []
    normals = []
    
    # Step 1: Identify Intersections and Normals
    for p1, s1, p2, s2 in cell_edges:
        if abs(s2 - s1) < 1e-9:
            continue
        t = (iso_value - s1) / (s2 - s1)
        t = max(0.0, min(1.0, t))
        p_i = [p1[k] + t * (p2[k] - p1[k]) for k in range(3)]
        intersections.append(p_i)
        
        # [G] Approximate normal via central differences on the scalar field
        gx = (scalar_field[grid_idx(p_i)[0]+1] - scalar_field[grid_idx(p_i)[0]-1]) / (2.0 * voxel_size)
        gy = (scalar_field[grid_idx(p_i)[1]+1] - scalar_field[grid_idx(p_i)[1]-1]) / (2.0 * voxel_size)
        gz = (scalar_field[grid_idx(p_i)[2]+1] - scalar_field[grid_idx(p_i)[2]-1]) / (2.0 * voxel_size)
        n_i = normalize([gx, gy, gz])
        normals.append(n_i)
        
    n = len(intersections)
    if n == 0:
        return None
        
    # Step 2: Compute Center of Mass
    p = [sum(intersections[i][k] for i in range(n)) / n for k in range(3)]
    
    # Step 3: Construct Linear System Ax = b
    A = normals
    b = [dot(normals[i], intersections[i]) for i in range(n)]
    
    # Step 4: Solve for Offset c
    AtA = mat_mul(transpose(A), A)
    Atb = mat_mul(transpose(A), b)
    AtA_p = mat_mul(AtA, p)
    rhs = [Atb[i] - AtA_p[i] for i in range(3)]
    
    # [G] Standard SVD routine for 3x3 symmetric matrix. Returns U, S, Vt.
    U, S, Vt = svd(AtA)
    S_inv = [1.0/s if s > 1e-9 else 0.0 for s in S]
    # Pseudo-inverse of symmetric matrix: V @ diag(S_inv) @ V^T
    pseudo_inv = mat_mul(mat_mul(Vt, diag(S_inv)), transpose(Vt))
    c = mat_mul(pseudo_inv, rhs)
    
    # Step 5: Compute Final Position
    x = [c[i] + p[i] for i in range(3)]
    
    # Step 6: Boundary Check
    if not is_inside_cell(x, cell_edges):
        return p
    return x

def dot(a, b): return sum(a[i]*b[i] for i in range(len(a)))
def normalize(v): l = dot(v, v)**0.5; return [x/l for x in v] if l > 0 else [0,0,0]
def transpose(M): return [[M[j][i] for j in range(len(M))] for i in range(len(M[0]))]
def mat_mul(A, B):
    if isinstance(B[0], list):
        return [[dot(A[i], [B[j][k] for j in range(len(B))]) for k in range(len(B[0]))] for i in range(len(A))]
    else:
        return [dot(A[i], B) for i in range(len(A))]
def diag(v): return [[v[i] if i==j else 0 for j in range(len(v))] for i in range(len(v))]
def svd(M): pass  # [G] Standard SVD routine for 3x3 symmetric matrix. Returns U, S, Vt.
def grid_idx(p): return [int(round(p[k] / voxel_size)) for k in range(3)]
def is_inside_cell(x, cell_edges):
    min_c, max_c = [float('inf')]*3, [float('-inf')]*3
    for p1, _, p2, _ in cell_edges:
        for k in range(3):
            min_c[k] = min(min_c[k], p1[k], p2[k])
            max_c[k] = max(max_c[k], p1[k], p2[k])
    return all(min_c[k] <= x[k] <= max_c[k] for k in range(3))
```

## Background
This method originates from the work of Ju et al. (2002) and is based on the Quadratic Error Function (QEF) minimization introduced by Garland and Heckbert (1998) [S1, unofficial]. It is a standard approach in dual contouring for locating dual vertices [S1, unofficial]. The specific implementation described here uses the Prewitt operator for gradient estimation and centers the solution around the cell's center of mass for numerical stability [S1, unofficial].
