# Dual Contouring with Octree Simplification

Also called: Octree DC, Dual Contouring (Octree-based), Octree Simplification for Dual Contouring

## Overview
Dual Contouring with Octree Simplification is a surface extraction method that combines adaptive octree traversal with topological simplification to generate a manifold mesh from a scalar field. It solves a Quadratic Error Function (QEF) at each node to determine vertex positions, then recursively collapses internal octree nodes into 'pseudo-leaf' nodes if the resulting QEF error is below a threshold, preserving sharp features defined by the sign configuration of child nodes [S1, S4, unofficial]. Unlike standard Dual Contouring which places one vertex per leaf voxel, this method reduces vertex count by merging internal nodes, producing a coarser but topologically consistent mesh suitable for real-time rendering or further processing [S2, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   A scalar density function $f(\mathbf{p})$ [S2, S4, unofficial].
*   Root octree parameters: minimum position $\mathbf{min}$, size $S$ (must be a power of two, typically 64) [S2, unofficial].
*   Simplification threshold $\tau$ (QEF error tolerance, typically $10^{-6}$) [S1, S2, unofficial].
*   Material thresholds (e.g., $\{-1.0, 0.1, 1.0, 10.0, 50.0\}$) for multi-material support, or a single threshold for binary solid/air [S2, S4, unofficial].

**Outputs:**
*   A simplified octree where nodes are either `Node_Leaf`, `Node_Pseudo`, or `Node_Internal` (pruned) [S2, unofficial].
*   A vertex buffer containing positions and average normals for all leaf and pseudo-leaf nodes [S2, unofficial].
*   An index buffer containing triangle indices generated by contouring the simplified octree [S2, unofficial].

### Data Structures

**OctreeNode**
*   `type`: Enum (`Node_None`, `Node_Internal`, `Node_Pseudo`, `Node_Leaf`) [S2, unofficial].
*   `min`: Vector3, world-space minimum corner of the cell [S2, unofficial].
*   `size`: int, side length of the cell [S2, unofficial].
*   `children`: Array of 8 `OctreeNode*` pointers, ordered by `CHILD_MIN_OFFSETS` [S2, unofficial].
*   `drawInfo`: Pointer to `OctreeDrawInfo` (null for internal nodes) [S2, unofficial].

**OctreeDrawInfo**
*   `index`: int, index in the global vertex buffer [S2, unofficial].
*   `corners`: int, 8-bit bitmask where bit $i$ is 1 if corner $i$ is SOLID, 0 if AIR [S2, S4, unofficial].
*   `position`: Vector3, vertex position computed by QEF [S2, unofficial].
*   `averageNormal`: Vector3, normalized average of child normals [S2, unofficial].
*   `qef`: QEF data structure (coefficients $A, \mathbf{b}, c$) [S2, unofficial].

**QEF Data**
*   `ata`: float[6], symmetric upper triangle of matrix $A$ ($A_{00}, A_{01}, A_{02}, A_{11}, A_{12}, A_{22}$) [S3, unofficial].
*   `atb`: float[3], vector $\mathbf{b}$ [S3, unofficial].
*   `btb`: float, scalar $c$ [S3, unofficial].
*   `massPoint`: Vector3, centroid of constraints [S2, unofficial].

**Lookup Tables**
*   `CHILD_MIN_OFFSETS[8][3]`: Integer offsets for children relative to parent min. Index 0: $(0,0,0)$, Index 1: $(0,0,1)$, ..., Index 7: $(1,1,1)$ [S2, S4, unofficial].
*   `edgevmap[12][2]`: Maps edge index to two corner indices.
    *   X-axis (0-3): $\{(0,4), (1,5), (2,6), (3,7)\}$
    *   Y-axis (4-7): $\{(0,2), (1,3), (4,6), (5,7)\}$
    *   Z-axis (8-11): $\{(0,1), (2,3), (4,5), (6,7)\}$ [S2, S4, unofficial].
*   `vertMap[8][3]`: Binary coordinates for corners 0-7 [S2, unofficial].
*   `faceMap[6][4]`: Maps face index to 4 corner indices [S2, unofficial].
*   `cellProcFaceMask[12][3]`, `cellProcEdgeMask[6][5]`, `faceProcFaceMask[3][4][3]`, `faceProcEdgeMask[3][4][6]`, `edgeProcEdgeMask[3][2][5]`, `processEdgeMask[3][4]`: Arrays driving the recursive contouring traversal [S2, unofficial].

### Parameters
*   `QEF_ERROR`: Convergence threshold for QEF solver. Default: $10^{-6}$ [S1, S2, unofficial].
*   `QEF_SWEEPS`: Number of Givens rotation sweeps. Default: 4 [S1, S2, unofficial].
*   `H`: Step size for finite difference normal calculation. Default: $0.001$ [S2, unofficial].
*   `steps`: Number of steps for zero-crossing approximation. Default: 8 [S2, unofficial].

### Algorithm Steps

#### 1. Octree Construction
Build the octree recursively. If node size is 1, construct a leaf; otherwise, create 8 children with half the size and offset by `CHILD_MIN_OFFSETS`. Return null if no children are non-null [S4, unofficial].

**ConstructLeaf(node, min, size, threshold):**
1.  Sample density at 8 corners using `CHILD_MIN_OFFSETS`.
2.  Determine material for each corner: `MATERIAL_SOLID` if $f(\mathbf{p}) < \text{threshold}$, else `MATERIAL_AIR` [S4, unofficial].
3.  Pack materials into `corners` bitmask: `corners |= (material << i)` [S2, unofficial].
4.  If `corners == 0` (all air) or `corners == 255` (all solid), return `null` [S4, unofficial].
5.  Initialize `QefSolver` and `averageNormal = (0,0,0)`.
6.  Iterate 12 edges. For edge $i$:
    a.  Get corner indices $c_1, c_2$ from `edgevmap[i]`.
    b.  Check if materials differ: `(material[c1] != material[c2])`.
    c.  If different:
        i.  Compute zero-crossing position $\mathbf{p}$ using `ApproximateZeroCrossingPosition`.
        ii. Compute normal $\mathbf{n}$ using `CalculateSurfaceNormal`.
        iii. Add constraint to QEF: $A \leftarrow A + \mathbf{n}\mathbf{n}^T$, $\mathbf{b} \leftarrow \mathbf{b} + (\mathbf{p} \cdot \mathbf{n})\mathbf{n}$, $c \leftarrow c + (\mathbf{p} \cdot \mathbf{n})^2$.
        iv. Accumulate normal: `averageNormal += n`.
7.  Solve QEF to get `qefPosition` and `error` [S2, unofficial].
8.  **Boundary Check:** If `qefPosition` is outside `[min, min + size]`, set `position = qef.getMassPoint()` [S2, S4, unofficial].
9.  Normalize `averageNormal` by dividing by edge count [S2, unofficial].
10. Create `OctreeDrawInfo` with `position`, `qef`, `averageNormal`, `corners`. Set `node.type = Node_Leaf` [S2, unofficial].

**ApproximateZeroCrossingPosition(p0, p1):**
1.  Initialize `minValue = infinity`, `t = 0`.
2.  Iterate $k$ from 0 to `steps` (8):
    a.  $t_k = k / \text{steps}$.
    b.  $\mathbf{p} = \mathbf{p}_0 + (\mathbf{p}_1 - \mathbf{p}_0) t_k$.
    c.  $d = |f(\mathbf{p})|$.
    d.  If $d < \text{minValue}$, `minValue = d`, `t = t_k`.
3.  Return $\mathbf{p}_0 + (\mathbf{p}_1 - \mathbf{p}_0) t$ [S2, unofficial].

**CalculateSurfaceNormal(p):**
1.  Compute gradient using central differences with step $H=0.001$:
    *   $dx = f(\mathbf{p} + (H,0,0)) - f(\mathbf{p} - (H,0,0))$
    *   $dy = f(\mathbf{p} + (0,H,0)) - f(\mathbf{p} - (0,H,0))$
    *   $dz = f(\mathbf{p} + (0,0,H)) - f(\mathbf{p} - (0,0,H))$
2.  Return normalized $(dx, dy, dz)$ [S2, unofficial].

#### 2. Octree Simplification
Recursively simplify the octree. An internal node can be collapsed into a pseudo-leaf if all its children are leaves or pseudo-leaves (not internal) and the aggregated QEF error is below the threshold [S4, unofficial].

**SimplifyOctree(node, threshold):**
1.  If `node` is null or `node.type != Node_Internal`, return `node` [S1, S2, unofficial].
2.  Recursively simplify all 8 children: `node.children[i] = SimplifyOctree(node.children[i], threshold)` [S1, unofficial].
3.  Check collapsibility:
    a.  If any child is `null`, skip it.
    b.  If any child is `Node_Internal`, set `isCollapsible = false` and return `node` unchanged [S1, S4, unofficial].
4.  If not collapsible, return `node` [S4, unofficial].
5.  Initialize `QefSolver` and `signs[8] = -1`.
6.  Iterate 8 children. For each non-null child:
    a.  Add child's QEF data to solver: $A \leftarrow A + A_{child}$, $\mathbf{b} \leftarrow \mathbf{b} + \mathbf{b}_{child}$, $c \leftarrow c + c_{child}$ [S1, unofficial].
    b.  Extract corner signs from `child.drawInfo.corners`. For corner $i$, extract bit $i$. For corner $7-i$, extract bit $7-i$ into `midsign` (used for filling gaps) [S1, S4, unofficial].
    c.  Update `signs` array based on child's corner bitmask [S4, unofficial].
7.  Solve QEF to get `position` and `error` [S2, unofficial].
8.  **Boundary Check:** If `position` is outside `[node.min, node.min + node.size]`, set `position = qef.getMassPoint()` [S1, S2, unofficial].
9.  If `error > threshold`, return `node` (do not collapse) [S4, unofficial].
10. Create new `OctreeDrawInfo`:
    a.  `corners = 0`. For $i=0$ to 7: if `signs[i] == -1`, use `midsign` (from first valid child's corner $7-i$), else use `signs[i]`. `corners |= (sign << i)` [S4, unofficial].
    b.  `averageNormal = (0,0,0)`. Sum `child.drawInfo.averageNormal` for all valid leaf/pseudo children. Normalize result [S1, S2, unofficial].
    c.  `position` = solved position.
    d.  `qef` = aggregated QEF data.
11. Destroy old children. Set `node.type = Node_Pseudo`. Store `drawInfo` [S2, S4, unofficial].
12. Return `node` [S4, unofficial].

#### 3. Mesh Generation
Generate vertices and indices from the simplified octree.

**GenerateVertexIndices(node, vertexBuffer):**
1.  If `node` is null, return.
2.  If `node.type == Node_Internal`, recurse into all 8 children [S2, unofficial].
3.  If `node.type != Node_Internal` (Leaf or Pseudo):
    a.  Set `node.drawInfo.index = vertexBuffer.size()` [S2, unofficial].
    b.  Add `MeshVertex(node.drawInfo.position, node.drawInfo.averageNormal)` to `vertexBuffer` [S2, unofficial].

**GenerateMeshFromOctree(root, vertexBuffer, indexBuffer):**
1.  Clear buffers.
2.  Call `GenerateVertexIndices(root, vertexBuffer)` [S2, unofficial].
3.  Call `ContourCellProc(root, indexBuffer)` [S2, unofficial].

#### 4. Contouring
Traverse the simplified octree to generate triangle indices. This step assumes the octree has been simplified and only Leaf/Pseudo nodes contain geometry.

**ContourCellProc(node, indexBuffer):**
1.  If `node` is null, return.
2.  If `node.type == Node_Internal`:
    a.  Recurse into 8 children.
    b.  Iterate 12 faces. For each face $i$:
        i.  Get two child nodes via `cellProcFaceMask[i]`.
        ii. Call `ContourFaceProc(faceNodes, cellProcFaceMask[i][2], indexBuffer)`.
    c.  Iterate 6 edges. For each edge $i$:
        i.  Get four child nodes via `cellProcEdgeMask[i]`.
        ii. Call `ContourEdgeProc(edgeNodes, cellProcEdgeMask[i][4], indexBuffer)`.

**ContourFaceProc(node[2], dir, indexBuffer):**
1.  If both nodes are not internal:
    a.  Iterate 4 edges on the face. For each edge, get nodes via `faceProcEdgeMask` and order array.
    b.  Call `ContourEdgeProc(edgeNodes, faceProcEdgeMask[...][5], indexBuffer)`.
2.  If either node is internal:
    a.  Recurse into children defined by `faceProcFaceMask`.
    b.  Iterate 4 edges. For each edge, retrieve nodes using `faceProcEdgeMask` and order array, then recurse `ContourEdgeProc` [S2, unofficial].

**ContourEdgeProc(node[4], dir, indexBuffer):**
1.  If all 4 nodes are not internal:
    a.  Call `ContourProcessEdge(node, dir, indexBuffer)` [S2, unofficial].
2.  Otherwise:
    a.  Iterate 2 sub-edges defined by `edgeProcEdgeMask`.
    b.  For each sub-edge, retrieve appropriate child nodes.
    c.  Recurse `ContourEdgeProc` [S2, unofficial].

**ContourProcessEdge(node[4], dir, indexBuffer):**
1.  Initialize `minSize = infinity`, `minIndex = 0`, `indices[4] = -1`, `flip = false`, `signChange[4] = false`.
2.  Iterate $i$ from 0 to 3:
    a.  Get edge index `edge = processEdgeMask[dir][i]`.
    b.  Get corner indices $c_1, c_2$ from `edgevmap[edge]`.
    c.  Extract materials $m_1, m_2$ from `node[i].drawInfo.corners` using bit shifts: `m1 = (corners >> c1) & 1`, `m2 = (corners >> c2) & 1`.
    d.  If `node[i].size < minSize`:
        i.  `minSize = node[i].size`.
        ii. `minIndex = i`.
        iii. `flip = (m1 != MATERIAL_AIR)` [S2, unofficial].
    e.  `indices[i] = node[i].drawInfo.index`.
    f.  `signChange[i] = (m1 == MATERIAL_AIR && m2 != MATERIAL_AIR) || (m1 != MATERIAL_AIR && m2 == MATERIAL_AIR)` [S2, unofficial].
3.  If `signChange[minIndex]`:
    a.  If `!flip`:
        i.  Add indices: $(0,1,3), (0,3,2)$ [S2, unofficial].
    b.  Else:
        i.  Add indices: $(0,3,1), (0,2,3)$ [S2, unofficial].

### Edge Cases and Pitfalls
*   **Boundary Violation:** The QEF solution may fall outside the cell bounds. Always clamp to the mass point (centroid) if this occurs [S2, S4, unofficial].
*   **Degenerate Cells:** If a cell has no edge intersections (all solid or all air), it returns null and is not processed [S4, unofficial].
*   **Collapsibility:** An internal node cannot be simplified if any child is still internal. This ensures topological consistency during simplification [S4, unofficial].
*   **Missing Children:** During simplification, if a child is null, its sign is -1. The code uses `midsign` (from the first valid child's corner $7-i$) to fill the corner bitmask for the pseudo-leaf [S4, unofficial].
*   **Precision:** Use double precision for QEF accumulation if single precision leads to instability, though sources use float with $10^{-6}$ tolerance [S1, S2, unofficial].

## Operating characteristics

*   **Time Complexity:** $O(N)$ where $N$ is the number of octree nodes, assuming constant-time QEF solve (fixed sweeps). The simplification step is linear in the number of nodes. Contouring is linear in the number of leaf/pseudo nodes.
*   **Memory Complexity:** $O(N)$ for octree storage. Vertex and index buffers are proportional to the number of leaf/pseudo nodes.
*   **Performance:** Depends heavily on the simplification threshold. A higher threshold reduces vertex count but may lose detail. Typical performance on modern hardware is real-time for moderate resolutions (e.g., 64^3 root) [S2, unofficial].
*   **Strengths:** Produces manifold meshes, preserves sharp features via QEF, reduces vertex count via simplification, adaptive resolution.
*   **Limitations:** QEF solve can be expensive if not optimized (Givens rotations). Simplification may introduce artifacts if threshold is too high. Boundary handling requires care.
*   **When to use:** Real-time rendering, level-of-detail generation, mesh simplification from signed distance fields.
*   **When not to use:** When exact geometric fidelity is required without simplification, or when the scalar field is not available for normal calculation.

## Background

Dual Contouring was introduced by Tao Ju et al. in 2002 [S3, unofficial]. The method places one vertex per intersected voxel and positions it by minimizing a QEF formed by intersection points and normals. The octree-based simplification variant was implemented in the "DualContouringSample" by Nick Gilden (2011) and ported to C# by Tuckbone (2011) [S1, S2, unofficial]. It is used for high-quality surface reconstruction from signed distance fields or grid data [S3, unofficial].
