# Quadric Error Function (QEF) for Sharp Features

Also called: QEF Solver

## Overview
This method computes the optimal vertex position for sharp features (corners and edges) in dual contouring by minimizing the distance to multiple intersecting planes defined by sample points and their normals [S1, unofficial]. It distinguishes itself from standard dual contouring by explicitly handling underdetermined systems (sharp edges) via least-squares minimization, ensuring the resulting vertex lies equidistant from all contributing planes [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $k$ intersection points $\{P_i\}$ and their corresponding surface normals $\{N_i\}$ within a voxel cell. $k$ is typically 3 for corners or 4 for edges.
*   **Output:** A single 3D point $x$ representing the sharp feature.

**Data Structures:**
The method constructs a linear system $Ax = B$ (or $Ax \approx B$ for QEF) using the following layouts:
*   `matrix_A`: A dense matrix of size $k \times 3$. Each row $i$ stores the normal vector components $(n_{ix}, n_{iy}, n_{iz})$.
*   `vector_B`: A dense vector of size $k$. Each entry $i$ stores the dot product $N_i \cdot P_i$.

**Steps:**
1.  **Collect Intersections:** Identify all grid edges intersecting the isosurface within the voxel. For each intersection, compute the point $P_i$ and the normal $N_i$ at that point.
2.  **Populate Matrix A and Vector B:**
    For each intersection point $i$ from $0$ to $k-1$:
    *   Set `matrix_A[i][0] = N_i.x`
    *   Set `matrix_A[i][1] = N_i.y`
    *   Set `matrix_A[i][2] = N_i.z`
    *   Set `vector_B[i] = P_i.x * N_i.x + P_i.y * N_i.y + P_i.z * N_i.z`
3.  **Solve via SVD:**
    Perform Singular Value Decomposition on $A$ to obtain $U, D, V^T$ such that $A = U D V^T$.
    Solve the system $U D V^T x = B$ for $x$. This yields the least-squares solution that minimizes the quadric error function $E[x] = \|Ax - B\|^2$ [S1, unofficial].

**Formulas:**
For a sharp corner (3 points), the exact solution satisfies:
$$ N_i \cdot (x - P_i) = 0 \quad \text{for } i=1,2,3 $$
Which expands to the linear system $Ax = B$ where:
$$ A = \begin{bmatrix} N_1^T \\ N_2^T \\ N_3^T \end{bmatrix}, \quad B = \begin{bmatrix} N_1 \cdot P_1 \\ N_2 \cdot P_2 \\ N_3 \cdot P_3 \end{bmatrix} $$

For a sharp edge (underdetermined system, e.g., 4 points defining 2 planes), the system is solved via QEF:
$$ E[x] = \|Ax - B\|^2 $$
The solution is found using SVD:
$$ x = V D^{-1} U^T B $$
*(Note: $D^{-1}$ involves inverting non-zero singular values; zero singular values are treated as zero to find the minimum norm solution)* [S1, unofficial].

**Parameters:**
*   **Epsilon:** A small value (e.g., $0.001$) may be used for numerical stability when checking for degenerate cases or determining if a system is underdetermined [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Degenerate Normals:** If normals are collinear or nearly parallel, the matrix $A$ becomes ill-conditioned. SVD handles this better than direct inversion, but precision loss may occur.
*   **Underdetermined Systems:** Standard linear solvers fail for sharp edges (fewer independent constraints than dimensions). QEF is required.
*   **Boundary Violations:** The unconstrained QEF solution may lie outside the voxel cell. This method does not inherently constrain the result to the cell; boundary constraints are handled by a separate strategy (see [QEF Boundary Constrained Vertex Placement](1740-qef-boundary-constrained-vertex-placement.md)) [S1, unofficial].

**Pseudocode:**
```python
def solve_qef_sharp_features(intersection_points, normals):
    """
    Solves for the optimal vertex position using QEF for sharp features.
    
    Args:
        intersection_points: List of 3D vectors [P0, P1, ..., Pk-1]
        normals: List of 3D vectors [N0, N1, ..., Nk-1]
        
    Returns:
        newPoint: 3D vector representing the sharp feature location
    """
    k = len(intersection_points)
    if k == 0:
        return None # Or handle as error
        
    # Initialize matrix A (k x 3) and vector B (k)
    matrix_A = [[0.0, 0.0, 0.0] for _ in range(k)]
    vector_B = [0.0] * k
    
    # Populate A and B
    for i in range(k):
        P = intersection_points[i]
        N = normals[i]
        
        # Row i of A is the normal vector
        matrix_A[i][0] = N.x
        matrix_A[i][1] = N.y
        matrix_A[i][2] = N.z
        
        # Entry i of B is the dot product N . P
        vector_B[i] = P.x * N.x + P.y * N.y + P.z * N.z
        
    # Solve Ax = B using SVD
    # A = U * D * V^T
    # x = V * D^-1 * U^T * B
    U, D, Vt = svd(matrix_A)
    
    # Construct D^-1 (pseudoinverse of diagonal matrix D)
    # Handle zero singular values to avoid division by zero
    D_inv = [[0.0] * 3 for _ in range(3)]
    for i in range(3):
        if D[i][i] > 1e-10: # Epsilon threshold
            D_inv[i][i] = 1.0 / D[i][i]
        else:
            D_inv[i][i] = 0.0
            
    # Compute x = V * D_inv * U^T * B
    # Step 1: U^T * B
    UtB = mat_mul_transpose(U, vector_B)
    
    # Step 2: D_inv * (U^T * B)
    D_inv_UtB = mat_mul(D_inv, UtB)
    
    # Step 3: V * (D_inv * U^T * B)
    newPoint = mat_mul(Vt.T, D_inv_UtB) # Vt.T is V
    
    return newPoint

def mat_mul(A, B):
    """Standard matrix multiplication."""
    rows_A, cols_A = len(A), len(A[0])
    rows_B, cols_B = len(B), len(B[0])
    C = [[0.0] * cols_B for _ in range(rows_A)]
    for i in range(rows_A):
        for j in range(cols_B):
            for k in range(cols_A):
                C[i][j] += A[i][k] * B[k][j]
    return C

def mat_mul_transpose(A, B):
    """Computes A^T * B where B is a vector (treated as column matrix)."""
    rows_A, cols_A = len(A), len(A[0])
    # A^T is cols_A x rows_A
    # B is rows_B x 1 (vector)
    # Result is cols_A x 1
    result = [0.0] * cols_A
    for i in range(cols_A):
        for j in range(rows_A):
            result[i] += A[j][i] * B[j]
    return result
```

## Subtopics

### [QEF Boundary Constrained Vertex Placement](1740-qef-boundary-constrained-vertex-placement.md)
A fallback strategy for vertex placement when the QEF solution lies outside the voxel cell. It constrains the search space hierarchically (interior -> faces -> edges -> corners) to find a valid point within boundaries. Choose this when the unconstrained QEF result is invalid for mesh topology.

## Operating characteristics
*   **Time Complexity:** Dominated by SVD, typically $O(k^3)$ for small $k$ (constant for fixed voxel size). Very fast for $k \le 4$.
*   **Memory Complexity:** $O(k)$ for storing $A$ and $B$. Minimal overhead.
*   **Strengths:** Robustly handles sharp features (edges/corners) that standard linear solvers cannot. Produces vertices equidistant from contributing planes.
*   **Limitations:** Does not guarantee the result lies within the voxel cell. Requires SVD implementation.
*   **When to Use:** When extracting meshes from implicit surfaces with sharp features (e.g., boxes, cylinders) using dual contouring.
*   **When Not to Use:** For smooth surfaces where standard dual contouring or marching cubes suffices, or when strict boundary constraints are required without additional fallback logic.

## Background
The Quadric Error Function (QEF) for sharp features was introduced in the context of dual contouring for isosurface extraction. The method was described in an unofficial source detailing the implementation of an isosurface polygonizer, specifically addressing the limitation of linear systems when dealing with sharp edges where the system is underdetermined [S1, unofficial].
