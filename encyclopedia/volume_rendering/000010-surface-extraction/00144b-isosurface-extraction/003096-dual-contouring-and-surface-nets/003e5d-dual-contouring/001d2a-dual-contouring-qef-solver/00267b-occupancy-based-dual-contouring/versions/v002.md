# Occupancy-Based Dual Contouring

Also called: ODC

## Overview
Occupancy-Based Dual Contouring (ODC) is a dual contouring method designed to extract meshes from neural implicit functions defined in continuous 3D space, such as Occupancy Networks, IM-NET, or DeepSDF [S1, unofficial]. It modifies the computation of grid edge points and grid cell points to avoid relying on distance information, which is often unavailable or unreliable in occupancy fields [S1, unofficial]. By introducing auxiliary 2D points to compute local surface normals, ODC identifies 3D points via the Quadric Error Function (QEF) and utilizes fast, parallelizable search algorithms for 1D, 2D, and 3D points [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** An implicit function $f: \mathbb{R}^3 \to \mathbb{R}$, bounding box $\mathcal{P}$ defined by `min_coord` and `max_coord`, grid resolution `num_grid`, isolevel, and search parameters [S1, unofficial].
*   **Output:** Vertices tensor $(N, 3)$ and triangles tensor $(N, 3)$ representing the extracted mesh [S1, unofficial].

**Data Structures:**
*   **pfvtab:** A lookup table for dual contouring vertex configurations. It is a list of 64 entries (indices 0-63) [S1, unofficial]. Each entry is a list of one or more lists of integers representing vertex indices [S1, unofficial]. The integers range from 1 to 24 [S1, unofficial]. Example entry at index 1: `[[13, 2, 17, 3, 15, 1, 13]]` [S1, unofficial].

**Parameters:**
*   `min_coord`: Minimum coordinates of $\mathcal{P}$. Default: `[-0.5, -0.5, -0.5]` [S1, unofficial].
*   `max_coord`: Maximum coordinates of $\mathcal{P}$. Default: `[0.5, 0.5, 0.5]` [S1, unofficial].
*   `num_grid`: Resolution for each axis. Default: `128` [S1, unofficial].
*   `isolevel`: Iso-level to extract. Default: `0.0`. Use `0.5` for occupancy functions, `0.0` for SDF [S1, unofficial].
*   `imp_func_cplx`: GPU VRAM usage of the implicit function for querying one point. Default: `3` [S1, unofficial].
*   `outside`: Boolean flag. True if a larger value indicates outside. Default: `True` [S1, unofficial].
*   `BINARY_SEARCH`: Number of iterations for 1D point search. Default: `15` [S1, unofficial].
*   `VERTICAL_RANGE`: Range for step (1) of the 2D point search. Default: `0.8` [S1, unofficial].
*   `VERTICAL_LINEAR_SEARCH`: Number of linear iterations for step (1) of the 2D point search. Default: `4` [S1, unofficial].
*   `VERTICAL_BINARY_SEARCH`: Number of binary iterations for step (1) of the 2D point search. Default: `11` [S1, unofficial].
*   `HORIZNTL_RANGE`: Range for step (2) of the 2D point search. Default: `0.71` [S1, unofficial].
*   `HORIZNTL_LINEAR_SEARCH`: Number of linear iterations for step (2) of the 2D point search. Default: `3` [S1, unofficial].
*   `HORIZNTL_BINARY_SEARCH`: Number of binary iterations for step (2) of the 2D point search. Default: `12` [S1, unofficial].
*   `ERR`: Error level tolerance. Default: `3e-7` [S1, unofficial].
*   `SEP`: Minimum separation of a 3D point from the grid face. Default: `1e-3` [S1, unofficial].
*   `QEF_REG`: Regularization coefficient for QEF. Default: `0.05` [S1, unofficial].

**Algorithm Steps:**
The method processes the grid in parallel across edges, faces, and cells [S1, unofficial].

1.  **Grid Initialization:** Define the 3D grid within $\mathcal{P}$ with resolution `num_grid` [G]. Evaluate the implicit function $f$ at all grid vertices to determine occupancy status relative to `isolevel` [S1, unofficial].
2.  **1D Point Search (Grid Edges):** For each grid edge intersecting the isosurface, search for the intersection point [S1, unofficial]. The search uses `BINARY_SEARCH` iterations [S1, unofficial]. The point is constrained to the edge segment [S1, unofficial].
3.  **2D Point Search (Grid Faces):** For each grid face intersecting the isosurface, search for an auxiliary 2D point [S1, unofficial]. This search consists of two steps:
    *   Step (1): Vertical search using `VERTICAL_LINEAR_SEARCH` linear iterations followed by `VERTICAL_BINARY_SEARCH` binary iterations within `VERTICAL_RANGE` [S1, unofficial].
    *   Step (2): Horizontal search using `HORIZNTL_LINEAR_SEARCH` linear iterations followed by `HORIZNTL_BINARY_SEARCH` binary iterations within `HORIZNTL_RANGE` [S1, unofficial].
    *   These 2D points are used to compute local surface normals along with the 1D points [S1, unofficial].
4.  **3D Point Search (Grid Cells):** For each grid cell containing the isosurface, search for the 3D vertex position [S1, unofficial]. The search utilizes the 1D points and 2D points (and their associated normals) to formulate a Quadric Error Function (QEF) [S1, unofficial]. The QEF is solved with regularization coefficient `QEF_REG` [S1, unofficial]. The resulting point must satisfy the separation constraint `SEP` from the grid face [S1, unofficial].
5.  **Mesh Construction:** Use the `pfvtab` lookup table to determine the vertex configuration for each cell based on the occupancy status of its corners [S1, unofficial]. Connect the computed 3D points to form triangles [S1, unofficial].

**Pseudocode:**
```python
import torch
import math

def occupancy_dual_contouring(implicit_function, device="cuda:0",
                              min_coord=torch.tensor([-0.5, -0.5, -0.5]),
                              max_coord=torch.tensor([0.5, 0.5, 0.5]),
                              num_grid=128, isolevel=0.0,
                              outside=True, BINARY_SEARCH=15,
                              VERTICAL_RANGE=0.8, VERTICAL_LINEAR_SEARCH=4,
                              VERTICAL_BINARY_SEARCH=11,
                              HORIZNTL_RANGE=0.71, HORIZNTL_LINEAR_SEARCH=3,
                              HORIZNTL_BINARY_SEARCH=12,
                              ERR=3e-7, SEP=1e-3, QEF_REG=0.05):
    """
    Extracts mesh from implicit function using ODC.
    """
    # 1. Grid Setup
    # Create grid vertices within min_coord and max_coord
    x = torch.linspace(min_coord[0], max_coord[0], num_grid + 1, device=device)
    y = torch.linspace(min_coord[1], max_coord[1], num_grid + 1, device=device)
    z = torch.linspace(min_coord[2], max_coord[2], num_grid + 1, device=device)
    X, Y, Z = torch.meshgrid(x, y, z, indexing='ij')
    grid_pts = torch.stack([X, Y, Z], dim=-1).reshape(-1, 3)
    
    # Evaluate implicit_function at grid vertices
    grid_vals = implicit_function(grid_pts)
    
    # Determine binary occupancy based on isolevel and outside flag
    occ = (grid_vals > isolevel) if outside else (grid_vals < isolevel)
    occ_int = occ.int()
    
    # Preallocate storage for points
    n_edges = num_grid * (num_grid + 1) * 3
    n_faces = num_grid * num_grid * 3
    n_cells = num_grid ** 3
    p1d = torch.zeros((n_edges, 3), device=device)
    p2d = torch.zeros((n_faces, 3), device=device)
    n2d = torch.zeros((n_faces, 3), device=device)
    p3d = torch.zeros((n_cells, 3), device=device)
    
    # 2. Parallel Processing
    # Process edges:
    #   For each edge, perform 1D binary search (BINARY_SEARCH iters)
    #   to find intersection point p1d.
    for axis in range(3):
        for i in range(num_grid + 1):
            for j in range(num_grid + 1):
                for k in range(num_grid):
                    idx = k + (j * (num_grid + 1) + i) * num_grid
                    if axis == 0:
                        p0 = grid_pts[k, j * (num_grid + 1) + i]
                        p1 = grid_pts[k + 1, j * (num_grid + 1) + i]
                    elif axis == 1:
                        p0 = grid_pts[k * (num_grid + 1) + i, j]
                        p1 = grid_pts[k * (num_grid + 1) + i, j + 1]
                    else:
                        p0 = grid_pts[k * (num_grid + 1) * (num_grid + 1) + i * (num_grid + 1) + j]
                        p1 = grid_pts[k * (num_grid + 1) * (num_grid + 1) + i * (num_grid + 1) + j + 1]
                    
                    o0 = occ_int[k * (num_grid + 1) * (num_grid + 1) + i * (num_grid + 1) + j]
                    o1 = occ_int[(k + 1) * (num_grid + 1) * (num_grid + 1) + i * (num_grid + 1) + j] if axis == 0 else \
                         occ_int[k * (num_grid + 1) * (num_grid + 1) + i * (num_grid + 1) + (j + 1)] if axis == 1 else \
                         occ_int[k * (num_grid + 1) * (num_grid + 1) + i * (num_grid + 1) + j + 1]
                    
                    if o0 != o1:
                        # Binary search for root
                        lo, hi = 0.0, 1.0
                        for _ in range(BINARY_SEARCH):
                            mid = (lo + hi) / 2.0
                            pm = p0 + (p1 - p0) * mid
                            fm = implicit_function(pm)
                            if (fm > isolevel) if outside else (fm < isolevel):
                                hi = mid
                            else:
                                lo = mid
                        p1d[idx] = p0 + (p1 - p0) * ((lo + hi) / 2.0)
    
    # Process faces:
    #   For each face, perform 2D search:
    for axis in range(3):
        for i in range(num_grid):
            for j in range(num_grid):
                for k in range(num_grid):
                    idx = k * num_grid * num_grid + j * num_grid + i
                    if axis == 0:
                        v0, v1, v2, v3 = grid_pts[k * (num_grid+1)**2 + i*(num_grid+1) + j], \
                                         grid_pts[k * (num_grid+1)**2 + i*(num_grid+1) + j+1], \
                                         grid_pts[(k+1) * (num_grid+1)**2 + i*(num_grid+1) + j], \
                                         grid_pts[(k+1) * (num_grid+1)**2 + i*(num_grid+1) + j+1]
                        p1d_ref = p1d[k * (num_grid+1) * (num_grid+1) + i * (num_grid+1) + j]
                    elif axis == 1:
                        v0, v1, v2, v3 = grid_pts[k * (num_grid+1)**2 + i*(num_grid+1) + j], \
                                         grid_pts[k * (num_grid+1)**2 + (i+1)*(num_grid+1) + j], \
                                         grid_pts[k * (num_grid+1)**2 + i*(num_grid+1) + j+1], \
                                         grid_pts[k * (num_grid+1)**2 + (i+1)*(num_grid+1) + j+1]
                        p1d_ref = p1d[k * (num_grid+1) * (num_grid+1) + i * (num_grid+1) + j]
                    else:
                        v0, v1, v2, v3 = grid_pts[k * (num_grid+1)**2 + i*(num_grid+1) + j], \
                                         grid_pts[k * (num_grid+1)**2 + (i+1)*(num_grid+1) + j], \
                                         grid_pts[k * (num_grid+1)**2 + i*(num_grid+1) + j+1], \
                                         grid_pts[k * (num_grid+1)**2 + (i+1)*(num_grid+1) + j+1]
                        p1d_ref = p1d[k * (num_grid+1) * (num_grid+1) + i * (num_grid+1) + j]
                    
                    # Step 1: Vertical search
                    lo_v, hi_v = 0.0, VERTICAL_RANGE
                    for _ in range(VERTICAL_LINEAR_SEARCH):
                        mid = (lo_v + hi_v) / 2.0
                        pm = v0 + (v1 - v0) * mid
                        if implicit_function(pm) > isolevel: hi_v = mid
                        else: lo_v = mid
                    for _ in range(VERTICAL_BINARY_SEARCH):
                        mid = (lo_v + hi_v) / 2.0
                        pm = v0 + (v1 - v0) * mid
                        if implicit_function(pm) > isolevel: hi_v = mid
                        else: lo_v = mid
                    mid_v = (lo_v + hi_v) / 2.0
                    
                    # Step 2: Horizontal search
                    lo_h, hi_h = 0.0, HORIZNTL_RANGE
                    for _ in range(HORIZNTL_LINEAR_SEARCH):
                        mid = (lo_h + hi_h) / 2.0
                        pm = v0 + (v2 - v0) * mid
                        if implicit_function(pm) > isolevel: hi_h = mid
                        else: lo_h = mid
                    for _ in range(HORIZNTL_BINARY_SEARCH):
                        mid = (lo_h + hi_h) / 2.0
                        pm = v0 + (v2 - v0) * mid
                        if implicit_function(pm) > isolevel: hi_h = mid
                        else: lo_h = mid
                    mid_h = (lo_h + hi_h) / 2.0
                    
                    p2d[idx] = v0 + (v1 - v0) * mid_v + (v2 - v0) * mid_h
                    
                    # Compute normal n2d at p2d using p1d and p2d.
                    vec = p2d[idx] - p1d_ref
                    norm = torch.norm(vec)
                    if norm < 1e-6:
                        n2d[idx] = torch.tensor([0.0, 0.0, 1.0], device=device)
                    else:
                        n2d[idx] = vec / norm
    
    # Process cells:
    #   For each cell, formulate QEF using p1d points and (p2d, n2d) pairs.
    #   Solve QEF with regularization QEF_REG.
    #   Check separation constraint SEP.
    #   Find 3D point p3d.
    for k in range(num_grid):
        for j in range(num_grid):
            for i in range(num_grid):
                idx = k * num_grid * num_grid + j * num_grid + i
                # Build QEF from intersecting edges/faces
                A = []
                b = []
                # Add constraints from 1D points on edges
                # Add constraints from 2D points and normals on faces
                # (Standard QEF assembly [G])
                A_mat = torch.stack(A) if A else torch.eye(3, device=device)
                b_vec = torch.stack(b) if b else torch.zeros(3, device=device)
                
                # Solve regularized QEF: (A^T A + QEF_REG * I) x = A^T b
                AtA = A_mat.T @ A_mat + QEF_REG * torch.eye(3, device=device)
                Atb = A_mat.T @ b_vec
                p3d[idx] = torch.linalg.solve(AtA, Atb)
                
                # Check separation constraint SEP from grid face [G]
                # (Clamp or adjust if distance < SEP)
    
    # 3. Mesh Generation
    #   Use pfvtab (64-entry lookup table) to map cell occupancy to vertex indices.
    #   Construct triangles from p3d points.
    vertices = []
    triangles = []
    for k in range(num_grid):
        for j in range(num_grid):
            for i in range(num_grid):
                idx = k * num_grid * num_grid + j * num_grid + i
                # Compute cell occupancy pattern (0-63)
                pattern = 0
                for d in range(8):
                    cx, cy, cz = i + (d & 1), j + ((d >> 1) & 1), k + ((d >> 2) & 1)
                    if occ_int[cx * (num_grid+1) * (num_grid+1) + cy * (num_grid+1) + cz]:
                        pattern |= (1 << d)
                
                # Lookup pfvtab and connect vertices
                config = pfvtab[pattern]
                for tri in config:
                    triangles.append([p3d[idx] + v_offset for v_offset in tri])
    
    # Return vertices, triangles
    return torch.stack(vertices), torch.tensor(triangles, dtype=torch.int64)
```

## Operating characteristics
*   **Time Complexity:** The method is designed for GPU parallelization, achieving computation times of a few seconds for typical resolutions [S1, unofficial].
*   **Memory Complexity:** Depends on `batch_size` (GPU capacity) and `imp_func_cplx` (VRAM usage per query) [S1, unofficial].
*   **Strengths:** Learning-free, state-of-the-art performance for occupancy functions, avoids staircase artifacts of Marching Cubes, and handles continuous 3D space effectively [S1, unofficial].
*   **Limitations:** Requires an implicit function that can be queried; performance depends on GPU VRAM [S1, unofficial].
*   **When to use:** When extracting meshes from neural occupancy fields (e.g., Occupancy Networks, DeepSDF) where distance information is not available or reliable [S1, unofficial].

## Background
Occupancy-Based Dual Contouring was introduced by the KAIST Visual AI Group [S1, unofficial]. It is based on Manifold Dual Contouring (MDC) but modified specifically for neural implicit representations [S1, unofficial]. The method addresses the bottleneck in converting occupancy functions to meshes, which traditional methods like Marching Cubes struggle with due to staircase artifacts [S1, unofficial].
