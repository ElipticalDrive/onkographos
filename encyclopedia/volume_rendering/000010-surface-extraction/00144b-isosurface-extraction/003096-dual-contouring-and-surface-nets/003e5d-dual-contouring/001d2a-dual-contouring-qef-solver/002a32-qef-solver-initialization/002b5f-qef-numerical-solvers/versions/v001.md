# QEF Numerical Solvers


## Overview
A suite of linear algebra functions for solving Quadratic Error Function (QEF) systems and related eigenvalue problems, specifically designed for the Dual Contouring pipeline. It provides methods for Jacobi eigenvalue decomposition, pseudo-inverse matrix inversion, QR decomposition, rank estimation, and L2 residual calculation [S1, unofficial]. It is distinguished from general-purpose solvers by its focus on small (3x3) symmetric matrices typical of voxel-based surface extraction and its inclusion of heuristic iterative refinement [S1, unofficial].

## How it works
**Inputs and Outputs:**
The suite operates on 3x3 symmetric matrices and 3D vectors. The primary solver `calcPoint` takes the compressed QEF system components: `halfA` (compressed $A^T A$), `b` ($A^T B$), `btb` ($B^T B$), a `midpoint` (target point), and a `box` (voxel bounding box). It outputs `rvalue` (the minimizer position) and returns the L2 error [S1, unofficial].

**Data Structures:**
- `halfA`: Array of 9 floats representing the symmetric matrix $A^T A$.
- `b`: Array of 3 floats representing the vector $A^T B$.
- `btb`: Scalar float representing $B^T B$.
- `midpoint`: Array of 3 floats.
- `rvalue`: Array of 3 floats for the result.
- `box`: Bounding box structure with `begin` and `end` vectors.

**Formulas:**
The QEF system to solve is:
$$ (A^T A) x = A^T B $$
The residual error is calculated as the L2 norm related to $B^T B$ [S1, unofficial].

**Parameters:**
- `TOLERANCE`: Default value `0.000001f` (used in QR decomposition) or `0.0001f` (used in iterative refinement convergence check) [S1, unofficial].

**Steps:**
1.  **Initialization**: Copy `midpoint` to `guess` [S1, unofficial].
2.  **Iterative Refinement (Method 0 or 2)**:
    -   Compute residual $r = B - A \cdot guess$.
    -   Compute $\delta = ||r||^2$.
    -   Loop while $\delta > \delta_0$ (where $\delta_0 = \delta \cdot TOLERANCE^2$) and iterations $< n$:
        -   Compute $div = r^T (A \cdot r)$.
        -   If $|div| < 10^{-7}$, break.
        -   Compute step $\alpha = \delta / div$.
        -   Update $guess = guess + \alpha \cdot r$.
        -   Recompute $r$ and $\delta$.
    -   If `guess` is within `box`, return [S1, unofficial].
3.  **Heuristic Correction (Method 0 or 1)**:
    -   Compute trace $c = \text{trace}(A)$.
    -   If $c == 0$, return.
    -   Set $c = 0.75 / c$.
    -   Loop $n$ times:
        -   Compute $r = B - A \cdot guess$.
        -   Update $guess = guess + c \cdot r$.
        -   Recompute $r$ [S1, unofficial].
4.  **Matrix Inversion (Pseudo-inverse)**:
    -   Use `matInverse` to compute pseudo-inverse of $A^T A$.
    -   Decompose $A^T A$ into eigenvalues $w$ and eigenvectors $u$.
    -   Compute inverse eigenvalues for pseudo-inverse.
    -   Reconstruct inverse matrix [S1, unofficial].
5.  **QR Decomposition**:
    -   Use `qr` to decompose system matrix.
    -   Default tolerance `0.000001f` [S1, unofficial].
6.  **Rank Estimation**:
    -   Use `estimateRank` to determine numerical rank of matrix [S1, unofficial].
7.  **Jacobi Eigen Solver**:
    -   Use `jacobi` to compute eigenvalues/vectors of 3x3 symmetric matrix.
    -   Destroys input matrix.
    -   Outputs sorted eigenvalues and eigenvectors [S1, unofficial].

**Pseudocode:**
```python
def calcPoint(halfA, b, btb, midpoint, rvalue, box):
    # Initialize guess
    guess = midpoint.copy()
    
    # Method 0 or 2: Iterative Refinement
    # Note: 'n' is not defined in sources; assumed to be a max iteration count [G]
    n = 10 
    tolerance = 0.0001f
    
    for method in [2, 0]:
        r = [0.0, 0.0, 0.0]
        delta = 0.0
        i = 0
        
        # Compute initial residual
        for k in range(3):
            sum_val = 0.0
            for j in range(3):
                sum_val += halfA[k*3 + j] * guess[j]
            r[k] = b[k] - sum_val
        delta = r[0]**2 + r[1]**2 + r[2]**2
        delta0 = delta * tolerance * tolerance
        
        while i < n and delta > delta0:
            div = 0.0
            for k in range(3):
                sum_val = 0.0
                for j in range(3):
                    sum_val += halfA[k*3 + j] * r[j]
                div += r[k] * sum_val
            
            if abs(div) < 0.0000001f:
                break
                
            alpha = delta / div
            newPoint = [guess[k] + alpha * r[k] for k in range(3)]
            guess = newPoint
            
            # Recompute residual
            for k in range(3):
                sum_val = 0.0
                for j in range(3):
                    sum_val += halfA[k*3 + j] * guess[j]
                r[k] = b[k] - sum_val
            delta = r[0]**2 + r[1]**2 + r[2]**2
            i += 1
            
        # Check bounds
        if (box.begin.x <= guess[0] <= box.end.x and
            box.begin.y <= guess[1] <= box.end.y and
            box.begin.z <= guess[2] <= box.end.z):
            rvalue = guess
            return computeL2Error(halfA, b, btb, guess)

    # Method 0 or 1: Heuristic Correction
    c = halfA[0] + halfA[4] + halfA[8] # Trace
    if c == 0:
        return computeL2Error(halfA, b, btb, guess)
    
    c = 0.75f / c
    guess = midpoint.copy()
    
    for i in range(n):
        r = [0.0, 0.0, 0.0]
        for k in range(3):
            sum_val = 0.0
            for j in range(3):
                sum_val += halfA[k*3 + j] * guess[j]
            r[k] = b[k] - sum_val
        
        guess = [guess[k] + c * r[k] for k in range(3)]
        
        # Recompute residual for next iteration
        for k in range(3):
            sum_val = 0.0
            for j in range(3):
                sum_val += halfA[k*3 + j] * guess[j]
            r[k] = b[k] - sum_val

    rvalue = guess
    return computeL2Error(halfA, b, btb, guess)

def computeL2Error(halfA, b, btb, x):
    # Residual error calculation as L2 norm of Transpose[B].B
    # Note: Exact formula from sources is ambiguous; btb is B^T B
    # Standard QEF error is ||Ax - B||^2 = x^T A^T A x - 2 x^T A^T B + B^T B
    # Using halfA for A^T A and b for A^T B
    error = 0.0
    for i in range(3):
        sum_val = 0.0
        for j in range(3):
            sum_val += halfA[i*3 + j] * x[j]
        error += x[i] * (sum_val - b[i])
    return error + btb
```

## Operating characteristics
- **Time Complexity**: $O(1)$ per voxel due to fixed 3x3 matrix operations and limited iterations.
- **Memory Complexity**: $O(1)$ auxiliary space.
- **Strengths**: Fast, lightweight, no external dependencies.
- **Limitations**: Heuristic methods may not converge to exact minimum; iterative refinement depends on initial guess and tolerance.
- **When to use**: Real-time dual contouring where performance is critical.
- **When not to use**: High-precision requirements where exact pseudo-inverse is needed.

## Background
Originated from the `aewallin/dualcontouring` repository, an unofficial implementation of dual contouring for volume rendering. It provides a self-contained linear algebra suite for solving the QEF systems central to the dual contouring algorithm [S1, unofficial].
