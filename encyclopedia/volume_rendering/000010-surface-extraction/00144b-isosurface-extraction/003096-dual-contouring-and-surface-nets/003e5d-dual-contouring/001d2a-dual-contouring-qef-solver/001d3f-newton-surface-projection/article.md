# Newton Surface Projection
Also called: isosurface projection, vertex projection
## Overview
Newton Surface Projection is a post-processing step for Dual Contouring that projects extracted vertices exactly onto the isosurface defined by an implicit function, achieving machine precision accuracy [S1, unofficial]. It distinguishes itself from approximate projection methods by using Newton's method to minimize the distance to the zero-level set, ensuring all output vertices lie precisely on the surface [S1, unofficial]. This method builds on [Dual Contouring QEF Solver](1424-dual-contouring-qef-solver.md) by refining the coarse vertex positions generated by the QEF solver.
## How it works
**Inputs and Outputs:**
- Input: A set of vertex positions $V = \{v_1, \dots, v_N\}$ extracted by the Dual Contouring QEF Solver, and an implicit function $f: \mathbb{R}^3 \to \mathbb{R}$ defining the isosurface (typically $f(x)=0$).
- Output: A set of projected vertex positions $V' = \{v'_1, \dots, v'_N\}$ where $f(v'_i) \approx 0$.

**Data Structures:**
- Vertices: Array of shape $(N, 3)$, dtype float64.
- Implicit Function: Callable returning values and gradients for batched inputs.

**Steps:**
1. For each vertex $v_i$ in the extracted mesh:
2. Initialize $x_0 = v_i$.
3. Iterate Newton's method for $k = 0, 1, \dots$ until convergence:
   a. Evaluate $f(x_k)$ and $\nabla f(x_k)$ (the gradient).
   b. Compute the update step:
      $$ \Delta x = - \frac{f(x_k)}{\|\nabla f(x_k)\|^2} \nabla f(x_k) $$
   c. Update position: $x_{k+1} = x_k + \Delta x$.
   d. Check convergence: if $\| \Delta x \| < \epsilon$ or $|f(x_{k+1})| < \epsilon$, stop.
4. Set $v'_i = x_{k+1}$.

**Parameters:**
- $\epsilon$: Convergence threshold, typically $10^{-8}$ or machine epsilon for float64 [S1, unofficial].
- Max iterations: Not given in the sources.

**Edge Cases and Pitfalls:**
- If $\nabla f(x_k)$ is near zero, the denominator becomes small, causing instability. A guard should clamp the denominator or fall back to a safe step [G].
- The method assumes the implicit function is differentiable and the initial vertex is within the basin of attraction of the nearest surface point [S1, unofficial].

**Pseudocode:**

```python
def newton_surface_projection(vertices, implicit_func, tol=1e-8, max_iter=50):
    """
    Projects vertices onto the isosurface f(x)=0 using Newton's method.
    
    Args:
        vertices: (N, 3) array of vertex positions.
        implicit_func: Callable that takes (N, 3) array and returns (values, gradients).
                       values: (N,) array of f(x).
                       gradients: (N, 3) array of df/dx.
        tol: Convergence tolerance.
        max_iter: Maximum number of Newton iterations.
        
    Returns:
        projected_vertices: (N, 3) array of projected positions.
    """
    projected = vertices.copy()
    N = vertices.shape[0]
    
    for i in range(N):
        x = projected[i].copy()
        for _ in range(max_iter):
            # Evaluate implicit function at current point
            # Note: implicit_func is designed for batched input, so we pass a single point
            # reshaped to (1, 3)
            val, grad = implicit_func(x.reshape(1, 3))
            f_val = val[0]
            grad_vec = grad[0]
            
            # Check convergence
            if abs(f_val) < tol:
                break
                
            # Compute gradient magnitude squared
            grad_norm_sq = np.dot(grad_vec, grad_vec)
            
            # Guard against division by zero
            if grad_norm_sq < 1e-20:
                break
                
            # Newton step
            delta_x = - (f_val / grad_norm_sq) * grad_vec
            x = x + delta_x
            
            # Check step size convergence
            if np.linalg.norm(delta_x) < tol:
                break
                
        projected[i] = x
        
    return projected
```
## Subtopics
## Operating characteristics
**Time Complexity:** $O(N \cdot K)$, where $N$ is the number of vertices and $K$ is the average number of Newton iterations per vertex. $K$ is typically small (often < 10) due to quadratic convergence near the solution [S1, unofficial].
**Memory Complexity:** $O(N)$ for storing vertices and gradients.
**Measured Performance:** The method is implemented in the `isomesh` library, which uses a Rust core with Python bindings for zero-copy numpy array exchange and batch evaluation, suggesting high performance for large meshes [S1, unofficial].
**Strengths:** Achieves machine precision accuracy; simple to implement; robust for smooth surfaces.
**Limitations:** Requires differentiable implicit function; may fail if gradient is zero or if initial vertex is too far from the surface; not suitable for non-differentiable features without modification.
**When to use:** When exact vertex placement on the isosurface is critical, such as for high-quality rendering or further geometric processing.
**When not to use:** When the implicit function is not differentiable or when performance is critical and approximate projection is acceptable.
## Background
Newton Surface Projection is used in the `isomesh` library, a Rust-based isosurface extraction tool with Python bindings [S1, unofficial]. It serves as a post-processing step to refine vertices extracted by Dual Contouring, ensuring they lie exactly on the isosurface [S1, unofficial]. The method leverages Newton's method for root-finding, applied to the implicit function defining the surface.
