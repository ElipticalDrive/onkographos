# Geometry Cleaning

Also called: Clean-up, Geometry Filter, PolyData Geometry Cleaning, vtkPVGeometryFilter [S2, unofficial]

## Overview
Geometry Cleaning is a post-processing step for polygonal meshes extracted from volumetric data, designed to remove artifacts introduced by snapping and polygonization [S1, unofficial][S2, unofficial]. It eliminates duplicate points, unused points, and degenerate or double triangles to yield a valid manifold mesh [S1, unofficial][S2, unofficial]. Unlike Connected Component Filtering, which discards isolated fragments based on connectivity, Geometry Cleaning focuses on topological validity by removing redundant and invalid geometric primitives [S1, unofficial][S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A `vtkPolyData` object containing a mesh with potential duplicates, unused points, and degenerate cells, typically the output of a contouring filter like `vtkMarchingCubes` [S2, unofficial].
- Output: A cleaned `vtkPolyData` object with valid manifold topology [S1, unofficial][S2, unofficial].

**Steps:**
1. Create a geometry cleaning filter instance (e.g., `vtkPVGeometryFilter`) [S2, unofficial].
2. Connect the input polydata to the filter using the `SetInput` method [S2, unofficial].
3. Execute the filter, which internally performs:
   - Identifies and merges points with identical coordinates into a single vertex [S2, unofficial].
   - Deletes points not referenced by any cell in the mesh [S2, unofficial].
   - Identifies and removes degenerate cells (zero-area triangles) and double triangles produced by non-injective snapping [S1, unofficial][S2, unofficial].
4. Retrieve the cleaned mesh from the filter's output [S2, unofficial].

**Pseudocode:**
```python
def geometry_cleaning(points, cells):
    """
    Cleans up a polydata mesh by removing duplicates, unused points, and degenerate/double triangles.
    Implements the logical steps of VTK geometry cleaning without library internals.
    """
    # Step 3a: Merge duplicate points
    unique_points = []
    point_map = {}
    for i, p in enumerate(points):
        key = tuple(p)
        if key not in point_map:
            point_map[key] = len(unique_points)
            unique_points.append(key)
            
    # Step 3b: Remap cells to unique points
    remapped_cells = []
    for cell in cells:
        remapped_cells.append([point_map[tuple(points[idx])] for idx in cell])
        
    # Step 3c: Remove unused points
    used_indices = set()
    for cell in remapped_cells:
        used_indices.update(cell)
    final_points = [p for i, p in enumerate(unique_points) if i in used_indices]
    
    # Step 3d: Remove degenerate and double triangles
    valid_cells = []
    seen_cells = set()
    for cell in remapped_cells:
        # Remove degenerate triangles (coincident vertices)
        if len(set(cell)) < 3:
            continue
        # Remove double triangles (same vertex set)
        cell_key = tuple(sorted(cell))
        if cell_key in seen_cells:
            continue
        seen_cells.add(cell_key)
        valid_cells.append(cell)
        
    return final_points, valid_cells
```

**Edge Cases and Pitfalls:**
- **Snapping Non-Injectivity:** Snapping algorithms map voxel surfaces to triangle meshes but are not injective, inherently producing degenerate and double triangles [S1, unofficial].
- **Manifold Validity:** The cleaning step removes degenerate and double triangles to yield a valid manifold mesh, but does not address non-manifold edges or vertices beyond duplicate removal [S1, unofficial].
- **Empty Output:** If the input mesh consists entirely of degenerate cells, the output will be empty [G].

- **Strengths:** Optimizes meshes after polygonization by removing redundant geometry and yields a valid manifold mesh suitable for rendering [S1, unofficial][S2, unofficial].
- **Limitations:** Does not remove isolated components, which requires Connected Component Filtering [G]. Does not perform mesh quality optimization like vertex smoothing unless an additional step is applied [S1, unofficial].
- **When to Use:** After isosurface extraction or polygonization when the source algorithm produces degenerate or duplicate geometry [S1, unofficial][S2, unofficial].

## Background
Geometry Cleaning is implemented in VTK (Visualization Toolkit) as filters such as `vtkPVGeometryFilter` [S2, unofficial]. It is routinely applied after polygonization steps like `vtkMarchingCubes` to ensure the resulting surface mesh is valid for rendering and analysis [S2, unofficial]. The necessity for cleaning arises because snapping algorithms, which triangulate exterior voxel surfaces, are generally not injective and produce degenerate and double triangles that must be removed to achieve watertight topology [S1, unofficial].
