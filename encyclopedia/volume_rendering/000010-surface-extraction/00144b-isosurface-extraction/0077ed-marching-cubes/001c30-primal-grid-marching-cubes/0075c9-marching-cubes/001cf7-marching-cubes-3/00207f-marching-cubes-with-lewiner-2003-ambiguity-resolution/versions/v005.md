# Marching Cubes with Lewiner 2003 Ambiguity Resolution

Also called: Lewiner Marching Cubes, Marching Cubes 2003

## Overview
This method is a variant of the Marching Cubes algorithm that resolves topological ambiguities (ambiguous faces and internal ambiguities) present in the original 1987 algorithm to guarantee a manifold surface [S3, unofficial]. It differs from standard Marching Cubes by using a face ambiguity test and interior point checks to disambiguate cases where the sign configuration at cube vertices does not uniquely determine the topology [S1][S3, unofficial].

## How it works
**Inputs:**
- 3D scalar field data `getData(x, y, z)` with dimensions `dim[0]`, `dim[1]`, `dim[2]` [S3, unofficial].
- Isovalue `isoValue` [S3, unofficial].
- Grid spacing `spacing[0]`, `spacing[1]`, `spacing[2]` [S3, unofficial].
- Boolean `reverseGradientDirection` (default `false`) [S3, unofficial].

**Outputs:**
- List of vertices `vertices` (position, normal) [S3, unofficial].
- List of triangle indices `triangles` [S3, unofficial].

**Data Structures:**
- `xDirectionInterpolatedVertexIndex`, `yDirectionInterpolatedVertexIndex`, `zDirectionInterpolatedVertexIndex`: Maps from grid coordinates `(i, j, k)` to vertex indices for interpolated points on edges parallel to x, y, z axes respectively [S3, unofficial].
- `centerInterpolatedVertexIndex`: Maps from grid coordinates to vertex indices for center vertices created in specific ambiguous cases [S3, unofficial].
- `vertices`: Vector of `Vertex` structs containing position and normal [S3, unofficial].
- `triangles`: Vector of triangle index triplets [S3, unofficial].
- Lookup Tables: `cases` (maps 256 configuration indices to 15 base cases and sub-class indices), `test3`, `test4`, `test6`, `test7` (specify which face/interior to test), `tiling1` through `tiling7` (specify triangulations) [S3, unofficial].

**Vertex Indexing:**
Vertices are indexed relative to cube corner 0. Moving in the +x direction adds 1, +y adds 3, +z adds 4. Internal center points are labeled 12 [S3, unofficial].

**Steps:**

1. **Initialization:** Clear `vertices`, `triangles`, and all vertex index maps. Initialize bounding box `bmin` to max float and `bmax` to min float [S3, unofficial].

2. **Pre-compute Interpolated Vertices:** Iterate over all edges of the volume. For each edge connecting vertices $V_0$ and $V_1$ with values $val_0$ and $val_1$, if $(val_0 - isoValue)$ and $(val_1 - isoValue)$ have opposite signs, compute the interpolated vertex position and store it in the appropriate direction map (`xDirectionInterpolatedVertexIndex`, etc.) indexed by the cube's corner 0 [S3, unofficial].
   - *Pitfall:* If a vertex value equals `isoValue`, the difference is 0. Set the difference to `FLT_EPSILON` to prevent interpolation errors (triangle collapse or missing vertices) [S3, unofficial].

3. **Cube Iteration:** Iterate `i` from 0 to `dim[0]-2`, `j` from 0 to `dim[1]-2`, `k` from 0 to `dim[2]-2`. This loop is parallelized using OpenMP (`#pragma omp parallel for`) with locks (`vertexLock`, `triangleLock`) to protect shared `vertices` and `triangles` lists [S3, unofficial].

4. **Configuration Index Calculation:** For each cube, determine the 8-bit configuration index. For vertex `l` (0-7), calculate grid coordinates:
   $$x = i + ((l \oplus (l \gg 1)) \& 1)$$
   $$y = j + ((l \gg 1) \& 1)$$
   $$z = k + ((l \gg 2) \& 1)$$
   Get data value $val = getData(x, y, z)$. If $val > 0$, set bit `l` in `configurationIndex` [S3, unofficial].

5. **Case Lookup:** Retrieve `caseIdx` and `configurationIndexInCase` from the `cases` table using `configurationIndex` [S3, unofficial].

6. **Triangulation based on Case:**
   - **Case 0:** No triangles added [S3, unofficial].
   - **Case 1:** Add 1 triangle using `tiling1` table at index `configurationIndexInCase` [S3, unofficial].
   - **Case 2:** Add 2 triangles using `tiling2` table at index `configurationIndexInCase` [S3, unofficial].
   - **Case 3:** Test 1 face. Call `testFace(i, j, k, cube, test3[configurationIndexInCase])`. If result < 0, add 2 triangles from `tiling3_1`. Else, add 4 triangles from `tiling3_2` [S3, unofficial].
   - **Case 4:** Test 1 interior point. Call `testInterior(i, j, k, cube, caseIdx, test4[configurationIndexInCase], 1)`. If result < 0, add 2 triangles from `tiling4_1`. Else, add 6 triangles from `tiling4_2` [S3, unofficial].
   - **Case 5:** Add 3 triangles using `tiling5` table at index `configurationIndexInCase` [S3, unofficial].
   - **Case 6:** Test 1 face and 1 interior. Call `testFace` with `test6[configurationIndexInCase][0]`. If < 0 (Case 6.1), call `testInterior` with `test6[configurationIndexInCase][1]` and `test6[configurationIndexInCase][2]`. If interior < 0, add 3 triangles from `tiling6_1_1`. Else, add 9 triangles from `tiling6_1_2`. If face >= 0, add 5 triangles from `tiling6_2` [S3, unofficial].
   - **Case 7:** Test 3 faces and 1 interior. Build `subconfig` bitmask by calling `testFace` for three faces defined in `test7[configurationIndexInCase][0..2]`. Add 1 if face 0 < 0, add 2 if face 1 < 0, add 4 if face 2 < 0. Switch on `subconfig`: 0->3 triangles (`tiling7_1`), 1/2/4->5 triangles (`tiling7_2` variants), 3/5->9 triangles (`tiling7_3` variants) [S3, unofficial].

7. **Center Vertex Creation (Ambiguity Resolution):** For cases requiring a center vertex (e.g., Case 6.1.2), create a center vertex by averaging all existing interpolated vertices on the cube's edges. `addCenterVertex` sums vertices from x, y, and z edge maps, divides by count `cnt`, normalizes the normal, and adds it to the vertex list [S3, unofficial].
   - *Pitfall:* If `cnt == 0`, the center vertex calculation fails. Assert false and print error [S3, unofficial].

**Face Ambiguity Test (`testFace`):**
For a face with vertices A, B, C, D (where A and C are opposite, B and D are opposite), compute $AC - BD$.
- If $|AC - BD| < \text{FLT\_EPSILON}$, return `face >= 0` [S2, S3, unofficial].
- Else, return `face * A * (AC - BD) >= 0` [S2, S3, unofficial].
- *Pitfall:* If the test value is exactly zero and handled incorrectly, adjacent cubes may generate duplicate/overlapping faces [S2, unofficial].

**Interior Ambiguity Test (`testInterior`):**
Check if a middle cross-section exists such that $AC > BD$. If found, it proves the middle region is connected, determining the internal topology [S3, unofficial].

**Gradient and Normal Calculation:**
- **Gradient (Interior):** For $0 < i < dim[0]-1$, $g_x = \frac{getData(i+1, j, k) - getData(i-1, j, k)}{2 \cdot spacing[0]}$. Similar for Y and Z [S3, unofficial].
- **Gradient (Boundary):** For $i=0$, $g_x = \frac{getData(i+1, j, k) - getData(i, j, k)}{spacing[0]}$. For $i=dim[0]-1$, $g_x = \frac{getData(i, j, k) - getData(i-1, j, k)}{spacing[0]}$ [S3, unofficial].
- **Normal:** $\vec{n} = d \cdot (g_x, g_y, g_z)$, where $d = -1$ if `reverseGradientDirection` is true, else $1$. Normalize $\vec{n}$ [S3, unofficial].

**Pseudocode:**

```python
import math
import threading

def compute_gradient(data, i, j, k, spacing, dim):
    if i == 0:
        gx = (data[i+1, j, k] - data[i, j, k]) / spacing[0]
    elif i == dim[0] - 1:
        gx = (data[i, j, k] - data[i-1, j, k]) / spacing[0]
    else:
        gx = (data[i+1, j, k] - data[i-1, j, k]) / (2 * spacing[0])

    if j == 0:
        gy = (data[i, j+1, k] - data[i, j, k]) / spacing[1]
    elif j == dim[1] - 1:
        gy = (data[i, j, k] - data[i, j-1, k]) / spacing[1]
    else:
        gy = (data[i, j+1, k] - data[i, j-1, k]) / (2 * spacing[1])

    if k == 0:
        gz = (data[i, j, k+1] - data[i, j, k]) / spacing[2]
    elif k == dim[2] - 1:
        gz = (data[i, j, k] - data[i, j, k-1]) / spacing[2]
    else:
        gz = (data[i, j, k+1] - data[i, j, k-1]) / (2 * spacing[2])

    return (gx, gy, gz)

def test_face(A, B, C, D, face_sign):
    val = A * C - B * D
    if abs(val) < 1e-6:
        return face_sign >= 0
    return face_sign * A * val >= 0

def test_interior(A, B, C, D):
    return A * C > B * D

def get_vertex_index(map_dict, i, j, k, direction):
    if direction == 'x':
        return map_dict.get((i + 1, j, k), -1)
    elif direction == 'y':
        return map_dict.get((i, j + 1, k), -1)
    elif direction == 'z':
        return map_dict.get((i, j, k + 1), -1)
    return -1

def marching_cubes_lewiner(data, iso_value, spacing, reverse_gradient):
    dim = data.shape
    vertices = []
    triangles = []
    x_map = {}
    y_map = {}
    z_map = {}
    center_map = {}

    vertex_lock = threading.Lock()
    triangle_lock = threading.Lock()

    # Pre-compute interpolated vertices
    for i in range(dim[0] - 1):
        for j in range(dim[1] - 1):
            for k in range(dim[2] - 1):
                # X-edges
                v0 = data[i, j, k] - iso_value
                v1 = data[i+1, j, k] - iso_value
                if v0 == 0: v0 = 1e-6
                if v1 == 0: v1 = 1e-6
                if v0 * v1 < 0:
                    t = v0 / (v0 - v1)
                    pos = (i + t, j, k)
                    gx, gy, gz = compute_gradient(data, i + t, j, k, spacing, dim)
                    if reverse_gradient:
                        gx, gy, gz = -gx, -gy, -gz
                    norm = math.sqrt(gx*gx + gy*gy + gz*gz)
                    if norm > 0:
                        gx, gy, gz = gx/norm, gy/norm, gz/norm
                    idx = len(vertices)
                    vertices.append({'pos': pos, 'normal': (gx, gy, gz)})
                    x_map[(i, j, k)] = idx

                # Y-edges
                v0 = data[i, j, k] - iso_value
                v1 = data[i, j+1, k] - iso_value
                if v0 == 0: v0 = 1e-6
                if v1 == 0: v1 = 1e-6
                if v0 * v1 < 0:
                    t = v0 / (v0 - v1)
                    pos = (i, j + t, k)
                    gx, gy, gz = compute_gradient(data, i, j + t, k, spacing, dim)
                    if reverse_gradient:
                        gx, gy, gz = -gx, -gy, -gz
                    norm = math.sqrt(gx*gx + gy*gy + gz*gz)
                    if norm > 0:
                        gx, gy, gz = gx/norm, gy/norm, gz/norm
                    idx = len(vertices)
                    vertices.append({'pos': pos, 'normal': (gx, gy, gz)})
                    y_map[(i, j, k)] = idx

                # Z-edges
                v0 = data[i, j, k] - iso_value
                v1 = data[i, j, k+1] - iso_value
                if v0 == 0: v0 = 1e-6
                if v1 == 0: v1 = 1e-6
                if v0 * v1 < 0:
                    t = v0 / (v0 - v1)
                    pos = (i, j, k + t)
                    gx, gy, gz = compute_gradient(data, i, j, k + t, spacing, dim)
                    if reverse_gradient:
                        gx, gy, gz = -gx, -gy, -gz
                    norm = math.sqrt(gx*gx + gy*gy + gz*gz)
                    if norm > 0:
                        gx, gy, gz = gx/norm, gy/norm, gz/norm
                    idx = len(vertices)
                    vertices.append({'pos': pos, 'normal': (gx, gy, gz)})
                    z_map[(i, j, k)] = idx

    # Cube iteration
    for i in range(dim[0] - 1):
        for j in range(dim[1] - 1):
            for k in range(dim[2] - 1):
                config = 0
                for l in range(8):
                    x = i + ((l ^ (l >> 1)) & 1)
                    y = j + ((l >> 1) & 1)
                    z = k + ((l >> 2) & 1)
                    val = data[x, y, z] - iso_value
                    if val == 0: val = 1e-6
                    if val > 0:
                        config |= (1 << l)

                case_idx, sub_idx = cases_table[config]

                if case_idx == 0:
                    pass
                elif case_idx == 1:
                    for tri in tiling1[sub_idx]:
                        triangles.append(tri)
                elif case_idx == 2:
                    for tri in tiling2[sub_idx]:
                        triangles.append(tri)
                elif case_idx == 3:
                    face_test = test3[sub_idx]
                    # face_test contains indices for vertices A, B, C, D and face_sign
                    # Resolve actual scalar values from data or precomputed maps
                    res = test_face(1, -1, 1, -1, 1) # Placeholder for actual vertex values
                    if res < 0:
                        for tri in tiling3_1[sub_idx]:
                            triangles.append(tri)
                    else:
                        for tri in tiling3_2[sub_idx]:
                            triangles.append(tri)
                # Cases 4-7 follow similar pattern using test4, test6, test7 tables
                # and corresponding tiling tables.

                with vertex_lock:
                    pass # Vertex addition handled in pre-compute
                with triangle_lock:
                    pass # Triangle addition handled above

    return vertices, triangles
```

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of voxels, as each voxel is processed once. Parallelization with OpenMP reduces wall-clock time [S3, unofficial].
- **Memory Complexity:** $O(N)$ for storing interpolated vertices and triangles. Using `unordered_map` for vertex indexing saves memory compared to 3D arrays [S3, unofficial].
- **Performance:** On a dataset with isoValue 800, 4,256,478 vertices, and 8,165,228 faces, the algorithm takes ~9s with OMP acceleration. File I/O takes ~21s. Total ~30s [S3, unofficial].
- **Strengths:** Guarantees manifold surfaces by resolving topological ambiguities [S3, unofficial].
- **Limitations:** Larger lookup tables compared to standard MC. Degenerate cases (zero ambiguity test value) require careful handling to avoid duplicate faces [S2, unofficial].

## Background
- **Origin:** Thomas Lewiner, 2003. Paper: "Efficient implementation of Marching Cubes’ cases with topological guarantees" [S3, unofficial].
- **History:** The original Marching Cubes (Lorensen 1987) did not resolve ambiguities, leading to cracks and non-manifold geometry [S3, unofficial]. Lewiner's method addresses this by testing faces and interior points [S1][S3, unofficial].
- **Usage:** Used in `skimage.measure.marching_cubes_lewiner` [S3, unofficial]. Also implemented in `upupming/marching-cubes` [S3, unofficial].
