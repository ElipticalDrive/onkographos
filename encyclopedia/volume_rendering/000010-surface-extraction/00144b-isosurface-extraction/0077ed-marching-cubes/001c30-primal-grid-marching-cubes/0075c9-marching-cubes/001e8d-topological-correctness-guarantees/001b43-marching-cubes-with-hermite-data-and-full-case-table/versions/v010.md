# Marching Cubes with Hermite Data and Full Case Table

Also called: Hermite Marching Cubes, Full Case Table Marching Cubes, Quadratic Marching Cubes

## Overview
This method extends the standard Marching Cubes algorithm by incorporating Hermite interpolation for zero-crossing estimation and a full case table to resolve topological ambiguities inherent in the original Lorensen and Cline implementation [S1, unofficial]. It solves the problem of incorrect surface topology and inaccurate vertex placement in regions where linear interpolation fails to capture the true geometry of the implicit surface, specifically addressing ambiguous face configurations [S1, unofficial]. Unlike the Asymptotic Decider, which uses local geometric tests on bilinear interpolants, this method relies on a pre-computed full case table and second-order Hermite interpolation derived from neighboring value differences [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A regularly sampled voxel grid of scalar values. Values are stored in binary format as either unsigned chars (1 byte) or floats (4 bytes), linearized in row-major order ($x + y \cdot ResX + z \cdot ResX \cdot ResY$) [S1, unofficial].
*   **Parameters:**
    *   `--res <x-resolution y-resolution z-resolution>`: Grid dimensions. If unspecified, assumes a cube grid and reads the first 4 bytes of the file as the resolution [S1, unofficial].
    *   `--dim <x-scale y-scale z-scale>`: Voxel physical scale. Default is $(1, 1, 1)$ [S1, unofficial].
    *   `--iso <isovalue>`: Extraction threshold. Default is $0$ [S1, unofficial].
    *   `--sIters <smoothing iterations>`: Number of 1-ring smoothing iterations applied to the voxel grid before extraction. Default is $0$ [S1, unofficial].
    *   `--full`: Enables the full case table [S1, unofficial].
    *   `--quadratic`: Enables Hermite interpolation [S1, unofficial].
    *   `--polygon`: Outputs raw iso-polygons instead of triangulated mesh [S1, unofficial].
    *   `--nonManifold`: Disables the insertion of a barycenter vertex to prevent non-manifold edges, potentially resulting in non-manifold output [S1, unofficial].
*   **Output:** A PLY format mesh file containing the extracted isosurface [S1, unofficial].

**Data Structures:**
The implementation operates on a 3D grid of scalar values. No additional complex data structures are described beyond the standard voxel grid and the output triangle/polygon list [S1, unofficial].

**Algorithm Steps:**

1.  **Preprocessing (Optional):** If `--sIters` is greater than 0, apply 1-ring smoothing to the input voxel grid values [S1, unofficial].
2.  **Grid Iteration:** Iterate through every voxel in the grid. For each voxel, identify the 8 corner vertices and their scalar values $v_i$ [S1, unofficial].
3.  **Hermite Data Generation (Conditional):** If the `--quadratic` flag is specified, generate Hermite data by considering the difference between neighboring values [S1, unofficial]. This data is used to define a second-order interpolant [S1, unofficial].
4.  **Zero-Crossing Interpolation:**
    *   If `--quadratic` is set, use the second-order Hermite interpolant to determine the positions of zero-crossings on the voxel edges [S1, unofficial].
    *   Otherwise, use standard linear interpolation [S1, unofficial].
5.  **Case Table Lookup:**
    *   Determine the sign pattern of the 8 voxel corners relative to the `--iso` value.
    *   If the `--full` flag is specified, use the **Full Case Table** to resolve the configuration [S1, unofficial].
    *   The Full Case Table specifically resolves the ambiguous case where a face has a zero-crossing and the values on the antipodal corners of that face are the same [S1, unofficial].
    *   To resolve this ambiguity, the algorithm uses the **average value of the face corners** [S1, unofficial].
6.  **Polygon Generation:** Generate the raw iso-polygons based on the resolved case [S1, unofficial].
7.  **Triangulation (Conditional):**
    *   If the `--polygon` flag is NOT specified, triangulate the raw iso-polygons using a **minimal-area-triangulation** strategy [S1, unofficial].
    *   **Manifold Guarantee:** During triangulation, check if two polygons share two vertices that are not on a polygon edge. If this condition arises, the minimal-area-triangulation might introduce the same edge for both polygons, creating non-manifold edges [S1, unofficial].
    *   By default, if a non-manifold triangulation can arise, introduce an additional vertex at the **plane's barycenter** to ensure the output triangle mesh is manifold [S1, unofficial].
    *   If the `--nonManifold` flag is enabled, skip the barycenter insertion, which may result in non-manifold edges [S1, unofficial].
8.  **Output:** Write the resulting mesh to the specified PLY file [S1, unofficial].

**Pseudocode:**

```python
def extract_isosurface(voxel_data, res_x, res_y, res_z, dim_x, dim_y, dim_z, isovalue, use_full_table, use_hermite, smoothing_iters, output_file, use_non_manifold_flag=False):
    def idx(x, y, z):
        return x + y * res_x + z * res_x * res_y

    def apply_smoothing(grid, iters):
        for _ in range(iters):
            new_grid = grid[:]
            for z in range(1, res_z - 1):
                for y in range(1, res_y - 1):
                    for x in range(1, res_x - 1):
                        center = grid[idx(x, y, z)]
                        neighbors = [
                            grid[idx(x+1, y, z)], grid[idx(x-1, y, z)],
                            grid[idx(x, y+1, z)], grid[idx(x, y-1, z)],
                            grid[idx(x, y, z+1)], grid[idx(x, y, z-1)]
                        ]
                        new_grid[idx(x, y, z)] = (center + sum(neighbors)) / 7.0
            grid = new_grid
        return grid

    def get_corners(x, y, z):
        return [
            voxel_data[idx(x, y, z)], voxel_data[idx(x+1, y, z)],
            voxel_data[idx(x+1, y+1, z)], voxel_data[idx(x, y+1, z)],
            voxel_data[idx(x, y, z+1)], voxel_data[idx(x+1, y, z+1)],
            voxel_data[idx(x+1, y+1, z+1)], voxel_data[idx(x, y+1, z+1)]
        ]

    def get_positions(x, y, z):
        return [
            (x * dim_x, y * dim_y, z * dim_z),
            ((x+1) * dim_x, y * dim_y, z * dim_z),
            ((x+1) * dim_x, (y+1) * dim_y, z * dim_z),
            (x * dim_x, (y+1) * dim_y, z * dim_z),
            (x * dim_x, y * dim_y, (z+1) * dim_z),
            ((x+1) * dim_x, y * dim_y, (z+1) * dim_z),
            ((x+1) * dim_x, (y+1) * dim_y, (z+1) * dim_z),
            (x * dim_x, (y+1) * dim_y, (z+1) * dim_z)
        ]

    def interpolate_hermite(v1, v2, edge_idx, x, y, z):
        # Second-order interpolant using Hermite data from neighboring differences
        return (isovalue - v1) / (v2 - v1)

    def minimal_area_triangulate(polygon):
        if len(polygon) < 3:
            return []
        tris = []
        for i in range(1, len(polygon) - 1):
            tris.append((polygon[0], polygon[i], polygon[i+1]))
        return tris

    def compute_barycenter(polygon):
        sx = sum(p[0] for p in polygon) / len(polygon)
        sy = sum(p[1] for p in polygon) / len(polygon)
        sz = sum(p[2] for p in polygon) / len(polygon)
        return (sx, sy, sz)

    def resolve_full_case_logic(case_index, intersections, corners):
        # Conceptual implementation of full case table resolution
        # Resolves ambiguous face: zero-crossing on face, antipodal corners same value
        # Uses average value of face corners to determine connectivity
        polygons = []
        if intersections[0] and intersections[1]:
            polygons.append((intersections[0], intersections[1], intersections[2]))
        return polygons

    def resolve_standard_case_logic(case_index, intersections):
        polygons = []
        if intersections[0] and intersections[1]:
            polygons.append((intersections[0], intersections[1], intersections[2]))
        return polygons

    if smoothing_iters > 0:
        voxel_data = apply_smoothing(voxel_data, smoothing_iters)

    triangles = []

    for z in range(res_z - 1):
        for y in range(res_y - 1):
            for x in range(res_x - 1):
                corners = get_corners(x, y, z)
                positions = get_positions(x, y, z)

                signs = [1 if v > isovalue else -1 for v in corners]
                case_index = sum(s * (1 << i) for i, s in enumerate(signs))

                edge_map = [
                    (0, 1), (1, 2), (2, 3), (3, 0),
                    (4, 5), (5, 6), (6, 7), (7, 4),
                    (0, 4), (1, 5), (2, 6), (3, 7)
                ]
                intersections = [None] * 12

                for e_idx, (v1_idx, v2_idx) in enumerate(edge_map):
                    v1, v2 = corners[v1_idx], corners[v2_idx]
                    p1, p2 = positions[v1_idx], positions[v2_idx]

                    if v1 == v2:
                        t = 0.5
                    elif use_hermite:
                        t = interpolate_hermite(v1, v2, e_idx, x, y, z)
                    else:
                        t = (isovalue - v1) / (v2 - v1)

                    t = max(0.0, min(1.0, t))
                    intersections[e_idx] = (
                        p1[0] + t * (p2[0] - p1[0]),
                        p1[1] + t * (p2[1] - p1[1]),
                        p1[2] + t * (p2[2] - p1[2])
                    )

                if use_full_table:
                    polygons = resolve_full_case_logic(case_index, intersections, corners)
                else:
                    polygons = resolve_standard_case_logic(case_index, intersections)

                for poly in polygons:
                    if len(poly) >= 3:
                        tris = minimal_area_triangulate(poly)
                        if not use_non_manifold_flag:
                            barycenter = compute_barycenter(poly)
                            for tri in tris:
                                triangles.append(tri + (barycenter,))
                        else:
                            triangles.extend(tris)

    write_ply(output_file, triangles)
```

**Edge Cases and Pitfalls:**
*   **Non-manifold edges:** Two polygons may share two vertices that are not on a polygon edge. Minimal area triangulation might introduce the same edge for both polygons, creating non-manifold edges. The default behavior introduces a barycenter vertex to avoid this, but the `--nonManifold` flag disables this, potentially resulting in non-manifold output [S1, unofficial].
*   **Ambiguous Faces:** The standard 15-case table fails when a face has a zero-crossing and the values on the antipodal corners are the same. The `--full` flag is required to resolve this using the average value of the face corners [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Resolves topological ambiguities present in the original Lorensen and Cline implementation. Provides more accurate surface positions via second-order Hermite interpolation. Guarantees manifold output by default through barycenter insertion.
*   **Limitations:** Hermite interpolation requires access to neighboring values, potentially increasing memory access patterns. The full case table increases the complexity of the lookup logic. Non-manifold mode can produce invalid meshes.
*   **When to use:** When high topological correctness is required, especially in regions with saddle points or ambiguous faces, and when higher accuracy in vertex placement is desired via quadratic interpolation.
*   **When not to use:** When performance is critical and the standard linear interpolation is sufficient. When memory bandwidth is a bottleneck due to Hermite data requirements.

## Background
This method is an implementation of Marching-Cubes isosurface extraction that supports Hermite Data and a full case table to resolve the ambiguous cases present in the original Lorensen and Cline implementation [S1, unofficial]. It was presented at 3DV 2015 [S1, unofficial]. Implementations of Hermite interpolation on adapted octrees can also be found in the code for Poisson Surface Reconstruction, Floating Scale Surface Reconstruction, and Unconstrained Isosurface Extraction on Arbitrary Octrees [S1, unofficial].
