# Topology-aware mesh quality improvement for Marching Cubes 33

Also called: Labelle and Shewchuk integration with Extended MC33, Topology-preserving skinny triangle removal

## Overview
This method improves the aspect ratio of triangulations generated by Marching Cubes 33 by modifying scalar field values near isosurface intersections, while preventing topological errors using a verification step [S1]. It combines the topological guarantees of Extended Marching Cubes 33 with the skinny triangle removal strategy of Labelle and Shewchuk [S1]. Unlike Raman and Wenger, this method correctly represents the topology of the trilinear interpolant even when $\lambda=0$, whereas Raman and Wenger cannot represent it correctly even at $\lambda=0$ [S1].

## How it works
**Inputs:**
- A scalar field grid $V$.
- An isovalue $\alpha$.
- A parameter $\lambda \in [0, 0.5]$ determining the threshold for collapsing intersection points [S1].

**Outputs:**
- A manifold triangle mesh homeomorphic to the trilinear interpolant of the input scalar field [S1].

**Data Structures:**
- **Grid:** A 3D array of scalar values.
- **Cube Status:** A boolean mask for each cube indicating if it is "blocked" (preventing mesh improvement) [S1].
- **Collapsed Vertices:** A set of grid vertex coordinates identified for scalar field modification [S1].

**Steps:**

1. **Grid Preprocessing:**
   Eliminate ambiguous configurations that cause non-manifold edges in the Chernyaev lookup table by splitting faces at critical points where grid vertex scalar values equal the isovalue [S1]. The source proposes splitting all faces in the grid slice containing the problematic configuration to ensure robust handling [S1].

2. **Scalar Field Modification:**
   Detect all intersected edges. If an intersection point is at distance $d < \lambda \cdot L$ from a grid vertex (where $L$ is the edge length), collapse the intersection point to the nearest grid vertex by modifying the scalar field value at that vertex [S1]. This modifies the grid $V$ to $V'$.

3. **Topology Verification:**
   To prevent undesired topological changes caused by the scalar field modification, track isosurface topology changes in the interior of each cube [S1]. If a configuration is detected that could modify the global isosurface topology, mark the cube and its immediate neighbors as "blocked" [S1].

4. **Mesh Extraction:**
   Run the Marching Cubes 33 algorithm with the extended triangulation on the modified grid $V'$ [S1]. Mesh improvements (triangle collapsing) are performed only in the cubes that are not in the neighborhood of the blocked cubes [S1].

5. **Geometry Preservation:**
   Move each isosurface vertex located on a grid vertex (due to collapsing) to the location of the closest isosurface vertex in the original grid to preserve the original geometry [S1].

**Quality Measure:**
Triangle quality is measured using the radii ratio $q(t)$:
$$ q(t) = \frac{r_{in}}{r_{out}} $$
where $r_{in}$ is the incircle radius and $r_{out}$ is the circumcircle radius of triangle $t$ [S1]. The value $q(t) \in [0, 0.5]$, where 0 is degenerate and 0.5 is equilateral [S1].

def topology_aware_mc33(grid, isovalue, lambda_param):
    """
    grid: 3D list of scalar values
    isovalue: float
    lambda_param: float in [0, 0.5]
    """
    Nx, Ny, Nz = len(grid), len(grid[0]), len(grid[0][0])
    original_grid = [row[:] for row in grid]
    modified_grid = [row[:] for row in grid]
    blocked = [[[False for _ in range(Nx-1)] for _ in range(Ny-1)] for _ in range(Nz-1)]
    vertices_to_collapse = set()

    # Step 1: Preprocessing
    # [G] Split faces at critical points where vertex values equal isovalue
    # to resolve Chernyaev lookup table ambiguities.

    # Step 2: Scalar Field Modification
    for z in range(Nz - 1):
        for y in range(Ny - 1):
            for x in range(Nx - 1):
                # 12 edges of a cube
                edges = [
                    ((x, y, z), (x+1, y, z)), ((x, y, z), (x, y+1, z)), ((x, y, z), (x, y, z+1)),
                    ((x+1, y, z), (x+1, y+1, z)), ((x+1, y, z), (x+1, y, z+1)),
                    ((x, y+1, z), (x+1, y+1, z)), ((x, y+1, z), (x, y+1, z+1)),
                    ((x, y, z+1), (x+1, y, z+1)), ((x, y, z+1), (x, y+1, z+1)),
                    ((x+1, y, z+1), (x+1, y+1, z+1)), ((x+1, y, z+1), (x+1, y, z)),
                    ((x, y+1, z+1), (x+1, y+1, z+1))
                ]
                for v0, v1 in edges:
                    val0, val1 = grid[v0[0]][v0[1]][v0[2]], grid[v1[0]][v1[1]][v1[2]]
                    if (val0 - isovalue) * (val1 - isovalue) <= 0:
                        if val0 == val1:
                            continue
                        t = (isovalue - val0) / (val1 - val0)
                        # Assume unit grid spacing L=1. Distance to v0 is t, to v1 is 1-t.
                        if t < lambda_param:
                            vertices_to_collapse.add(v0)
                        if (1.0 - t) < lambda_param:
                            vertices_to_collapse.add(v1)

    for v in vertices_to_collapse:
        modified_grid[v[0]][v[1]][v[2]] = isovalue

    # Step 3: Topology Verification
    for z in range(Nz - 1):
        for y in range(Ny - 1):
            for x in range(Nx - 1):
                if topology_differs(original_grid, modified_grid, (x, y, z), isovalue):
                    blocked[z][y][x] = True
                    for dz in range(-1, 2):
                        for dy in range(-1, 2):
                            for dx in range(-1, 2):
                                nz, ny, nx = z+dz, y+dy, x+dx
                                if 0 <= nz < Nz-1 and 0 <= ny < Ny-1 and 0 <= nx < Nx-1:
                                    blocked[nz][ny][nx] = True

    # Step 4 & 5: Mesh Extraction & Geometry Preservation
    mesh = []
    for z in range(Nz - 1):
        for y in range(Ny - 1):
            for x in range(Nx - 1):
                use_grid = original_grid if blocked[z][y][x] else modified_grid
                tri = mc33_extended_triangulation(use_grid, (x, y, z), isovalue)
                for v in tri.vertices:
                    if v in vertices_to_collapse:
                        v.pos = find_closest_isosurface_vertex(original_grid, v.grid_pos, isovalue)
                mesh.extend(tri)
    return mesh

## Operating characteristics
- **Performance:** In the Bonsai dataset with $\lambda=0.2$ and isovalue 39.5, only 0.63% of cubes intersected by the isosurface were blocked [S1]. For a randomly generated scalar field on a 6x6x6 grid, 6.73% of cubes were blocked for $\lambda=0.1$, and 31.1% were blocked for $\lambda=0.2$ [S1].
- **Strengths:** Correctly represents the topology of the trilinear interpolant even when $\lambda=0$ [S1]. Improves aspect ratio of triangles [S1].
- **Limitations:** The verification step can block a significant portion of cubes in random or highly complex fields (up to 31.1% in tested random fields) [S1].

## Background
This method was proposed by the author of [S1] as an extension to Marching Cubes 33. It integrates the Labelle and Shewchuk algorithm [S1] with the Extended MC33 triangulation. The work addresses issues with the Chernyaev lookup table and non-manifold triangulations [S1].
