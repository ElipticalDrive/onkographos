# Topology/Normal Consistency Loss

Also called: Topology Consistency Loss

## Overview
This method computes a differentiable loss function to enforce consistency between predicted triangle probabilities, connectivity, and surface normals in a learned Marching Cubes network [S1, unofficial]. Unlike deterministic topological correctness methods that resolve ambiguities via geometric tests or vertex insertion, this approach integrates topology constraints directly into the training objective of a neural network [S1, unofficial].

## How it works
The method operates on the output of a neural network predicting vertex offsets and topology probabilities for a voxel grid [S1, unofficial]. It constructs a weighted connectivity matrix from predicted probabilities and penalizes deviations from a consistent normal field [S1, unofficial].

**Inputs and Outputs:**
*   **Inputs:**
    *   `topology`: Tensor of raw topology logits.
    *   `offset`: Tensor of predicted vertex offsets for the current grid cell, used to derive triangle normals [S1, unofficial].
    *   `connected_inner`: Binary or weight matrix indicating valid connections between triangles [S1, unofficial].
    *   `topology_to_triangle`: Integer mapping array expanding topology indices to triangle indices [S1, unofficial].
*   **Outputs:**
    *   `loss`: Scalar loss value for the current grid cell [S1, unofficial].

**Data Structures:**
*   `topology_to_triangle`: A 1D integer array mapping each topology class index to one or more triangle indices [S1, unofficial].
*   `connected_inner`: A 2D matrix where $W_{ij}$ indicates valid connections between triangles $i$ and $j$ [S1, unofficial].

**Steps:**
1.  **Compute Topology Probabilities:** Apply softmax along the class dimension to the raw topology logits to obtain probabilities $p_{topo}$ [S1, unofficial].
    $$ p_{topo} = \text{softmax}(topology, \text{dim}=0) $$
2.  **Expand to Triangle Probabilities:** Map the topology probabilities to triangle probabilities $p_1$ using the `topology_to_triangle` mapping [S1, unofficial].
    $$ p_1 = p_{topo}[topology\_to\_triangle] $$
3.  **Construct Connectivity Matrix:** Compute the outer product of the triangle probabilities to form a joint probability matrix, then mask it with the connectivity mask `connected_inner` to create the weight matrix $W$ [S1, unofficial].
    $$ p_{outer} = p_1 \otimes p_1^T $$
    $$ W = p_{outer} \odot connected\_inner $$
    where $\otimes$ denotes the outer product and $\odot$ denotes element-wise multiplication [S1, unofficial].
4.  **Compute Normal Vectors:** Extract normal vectors $N$ for the current grid cell using the predicted offsets [S1, unofficial]. The normals are normalized to unit length [S1, unofficial].
    $$ N = \text{normalize}(\text{offsets\_to\_normals}(offset)) $$
5.  **Compute Loss:** Calculate the loss term using the trace of the product of the normal matrix and the weight matrix [S1, unofficial].
    $$ L_{\text{topo}} = 2 \sum W - 2 \text{tr}(N^T W N) $$
    where $\sum W$ is the sum of all elements in $W$, and $\text{tr}(\cdot)$ is the matrix trace [S1, unofficial].

**Formula:**
$$ L_{\text{topo}} = 2\sum W - 2\text{tr}(N^T W N) $$
where $W$ is the probability-weighted connectivity matrix and $N$ contains normalized triangle normals [S1, unofficial].

**Parameters:**
*   `topology_to_triangle`: Integer mapping array [S1, unofficial].
*   `connected_inner`: Binary or weight matrix [S1, unofficial].
*   `offset`: Predicted vertex offsets [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** The softmax operation can suffer from numerical instability if logits are very large or small [S1, unofficial].
*   **Boundary Conditions:** The source code initializes a `neg_weight` based on grid boundaries, assuming outside faces are free, but this is not integrated into the loss function itself [S1, unofficial].
*   **Degenerate Input:** If `offset` results in zero-length normals, normalization will fail. A small epsilon should be added to the norm denominator [G].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def topology_normal_consistency_loss(topology, offset, connected_inner, topology_to_triangle):
    """
    Computes the topology/normal consistency loss.
    
    Args:
        topology: Tensor of raw topology logits.
        offset: Tensor of predicted vertex offsets.
        connected_inner: Tensor of shape (T, T), connectivity mask.
        topology_to_triangle: Tensor of shape (C,), mapping topology indices to triangle indices.
        
    Returns:
        loss: Scalar tensor.
    """
    # Step 1: Compute topology probabilities
    # Source applies softmax along dimension 0 of the cell slice: F.softmax(topology[i_,:], dim=0)
    p_topo = F.softmax(topology, dim=-1)

    # Step 2: Expand to triangle probabilities
    # Source: p1 = p1[topology_to_triangle]
    p1 = torch.gather(p_topo, -1, topology_to_triangle)

    # Step 3: Construct connectivity matrix
    # Source: p_outer = torch.ger(p1, p1); W = p_outer * connected_inner
    p_outer = torch.ger(p1, p1)
    W = p_outer * connected_inner

    # Step 4: Compute normal vectors
    # Source: norm1 = offset_to_normal(offset, x_idx, y_idx, z_idx, 6)
    # The exact implementation of offset_to_normal is not provided in the sources.
    # We assume it extracts triangle normals from predicted vertex offsets [G].
    # For a self-contained example, we assume offset directly provides normal vectors.
    norm1 = offset

    # Source: norm1 = norm1 / ||norm1||_2
    norms = torch.norm(norm1, 2, dim=-1, keepdim=True)
    norms = torch.clamp(norms, min=1e-8) # Guard against zero-length normals [G]
    norm1 = norm1 / norms

    # Step 5: Compute loss
    # Source: tmp3 = norm1^T @ W @ norm1
    tmp3 = torch.mm(torch.mm(norm1.t(), W), norm1)

    # Source: loss1 = 2 * sum(W) - 2 * trace(tmp3)
    loss1 = 2 * torch.sum(W) - 2 * torch.trace(tmp3)

    return loss1
```
