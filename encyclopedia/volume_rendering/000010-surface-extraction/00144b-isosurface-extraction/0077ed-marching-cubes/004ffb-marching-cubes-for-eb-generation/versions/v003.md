# Marching Cubes for EB Generation

Also called: MC33, Marching-Cubes Geometry Generation

## Overview
This method generates Embedded Boundary (EB) geometry on 3D Cartesian grids by resolving a surface using the Marching Cubes 33 (MC33) lookup tables, computing volume/area fractions, centroids, normals, and connectivity [S1, unofficial]. It improves upon the legacy EB generation method by providing a more accurate single-valued representation of the boundary [S1, unofficial]. It is distinguished from standard isosurface extraction by its integration into the AMReX EB framework, specifically handling exact edge intersections via root finding or STL intersection, caching these intersections in `MCFab` structures for downstream aperture construction, and enforcing single-valued topological constraints [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs**: A geometry source defined as either an implicit function $f(\mathbf{x})$ or a triangulated surface (STL) [S1, unofficial]. A 3D Cartesian grid with cubic cells ($dx = dy = dz$) [S1, unofficial].
*   **Outputs**: A single-valued EB dataset including volume fractions, area fractions, centroids, boundary normals, and connectivity [S1, unofficial]. Resolved MC33 face-connectivity decisions stored in `MCFab` structures [S1, unofficial].

**Data Structures**
*   **MCFab**: A data structure storing resolved MC33 face-connectivity decisions and cached edge intersections (normalized crossing locations) [S1, unofficial]. These cached intersections are shared by downstream geometry calculations including MC vertices, face apertures, edge centroids, and cell moments, including for ambiguous MC33 faces [S1, unofficial].
*   **Level Set**: A nodal level set built from the geometry source [S1, unofficial]. For implicit functions, this is the function value [S1, unofficial]. For STL, a narrow-band level set is used where exact distance values are retained on cut-cell interpolation and vertex-normal stencils, while only inside/outside classification is retained farther from the interface [S1, unofficial].

**Algorithm Steps**

1.  **Grid Validation**: Verify the grid is 3D and cubic ($dx == dy == dz$) [S1, unofficial]. Reject if non-cubic, even when the geometry is all regular [S1, unofficial]. Verify `BuildMultiValuedMultiCut` is not requested, as the method is incompatible with it [S1, unofficial].
2.  **Level Set Construction**: If the source is an implicit function, sample $f(\mathbf{x})$ at grid nodes without clamping sample positions to the domain [S1, unofficial]. Snap nodes that lie on the surface within roundoff to exact zero [S1, unofficial]. If the source is STL, construct a narrow-band level set where exact distance values are retained near the interface and binary inside/outside classification is retained farther away [S1, unofficial].
3.  **Exact Edge Intersection Computation**: For every Cartesian edge where the sign of the level set changes, compute the exact intersection location instead of relying on linear interpolation of sampled level-set values [S1, unofficial]. For implicit functions, find the crossing of every sign-changing edge by Brent root finding on the function [S1, unofficial]. For STL input, intersect the edge with the original triangles [S1, unofficial]. If root finding fails, fall back to linear interpolation [S1, unofficial]. Store the normalized crossing location in the `MCFab` [S1, unofficial]. If cleanup places the interface exactly on an edge endpoint, use the exact-zero endpoint value [S1, unofficial].
4.  **Case Index Calculation**: For each voxel, determine the 8-bit case index $C$ based on the signs of the level set values $V_i$ at the 8 vertices $v_i$ relative to the isovalue (typically 0 for implicit functions, or the narrow-band threshold for STL) [S1, unofficial]. Bit $i$ of $C$ is set to 1 if $V(v_i) < 0$ (or $> 0$, depending on convention), else 0 [S1, unofficial]. The bit assignment must match the vertex ordering assumed by the LUT generation [S1, unofficial].
5.  **Topology Resolution and Connectivity**: Use the MC33 lookup tables (`edgeTable`, `triangleTable`) to determine the triangulation for the voxel based on $C$ [S1, unofficial]. For ambiguous cases (46, 47, 98, 99, 210, 213, 214, 215), resolve the topology consistently using the cached edge intersections stored in `MCFab` [S1, unofficial]. This ensures that ambiguous Cartesian faces use the same resolved topology when building face apertures as when generating MC triangles [S1, unofficial]. Store the resolved face-connectivity decisions in `MCFab` [S1, unofficial].
6.  **Geometry Computation**: Compute MC vertices using the cached exact edge intersections [S1, unofficial]. Compute face apertures, edge centroids, and cell moments using the cached intersections and resolved connectivity [S1, unofficial]. Compute boundary normals and volume/area fractions [S1, unofficial].
7.  **Single-Valued Consistency Checks and Repair**: Check for single-valued representation violations: faces containing more than one resolved fluid aperture [S1, unofficial]; cells with invalid MC topology, multiple fluid components, or MC33 "tunnel" tilings where fluid regions are joined only through the cell interior [S1, unofficial]; invalid face or cell geometry records [S1, unofficial]; cut cells with volume fraction below `eb2.small_volfrac` [S1, unofficial]. Small cells (below `eb2.small_volfrac`) are removed automatically by moving incident fluid nodes to the interface [S1, unofficial]. Other unsupported geometry (e.g., multi-valued cuts) requires `eb2.cover_multiple_cuts = 1` to cover the geometry, matching the existing behavior for non-single-valued cells [S1, unofficial]. Iteratively remove small cells and unsupported geometry using `eb2.cover_multiple_cuts` and `eb2.maxiter` [S1, unofficial].
8.  **Output**: Generate the final EB dataset [S1, unofficial]. Optionally write the MC triangulation as an ASCII STL file if `eb2.mc_stl_file` is specified [S1, unofficial].

**Pseudocode**

```python
import math

def generate_eb_marching_cubes(grid, geometry_source, params):
    # 1. Validation
    if grid.dim != 3:
        raise ValueError("Marching Cubes EB generation requires 3D grid")
    if not grid.is_cubic():
        raise ValueError("Marching Cubes EB generation requires cubic cells (dx == dy == dz)")

    # 2. Level Set Construction
    level_set = build_nodal_level_set(grid, geometry_source)
    level_set = snap_to_zero(level_set, tol=1e-12)

    # 3. Exact Edge Intersection Computation
    mcfab = MCFab()
    for edge in grid.edges:
        v0 = level_set[edge.node0]
        v1 = level_set[edge.node1]
        if (v0 < 0) != (v1 < 0):  # Sign change
            if geometry_source.type == "implicit":
                t = brent_root_find(edge.start, edge.end, geometry_source.func)
                if t is None:
                    t = linear_interpolate(v0, v1)
            else:  # STL
                t = stltools_fill_marching_cubes_edge_intersections(edge, geometry_source.triangles)
            if t is not None:
                mcfab.set_edge_intersection(edge, t)
            elif abs(v0) < 1e-12:
                mcfab.set_edge_intersection(edge, 0.0)
            elif abs(v1) < 1e-12:
                mcfab.set_edge_intersection(edge, 1.0)

    # 4. Case Index Calculation & Topology Resolution
    for cell in grid.cells:
        values = [level_set[cell.vertices[i]] for i in range(8)]
        C = compute_case_index(values, 0.0)
        connectivity = resolve_mc33_topology(C, mcfab.get_cached_intersections(cell.edges))
        mcfab.set_face_connectivity(cell, connectivity)

    # 5. Geometry Computation
    eb_dataset = EBDataset()
    for cell in grid.cells:
        eb_dataset.compute_cell_moments(cell, mcfab)
        eb_dataset.compute_face_apertures(cell, mcfab)
        eb_dataset.compute_boundary_normals(cell, mcfab)

    # 6. Single-Valued Consistency Checks and Repair
    max_iter = params.get('eb2.maxiter', 10)
    small_volfrac = params.get('eb2.small_volfrac', 1e-6)
    cover_multi = params.get('eb2.cover_multiple_cuts', 0)

    for iteration in range(max_iter):
        violations = check_single_valued_consistency(eb_dataset, mcfab)
        if not violations:
            break
        for violation in violations:
            if violation['type'] == 'small_cell':
                if violation['cell'].volume_fraction < small_volfrac:
                    repair_small_cell(violation['cell'], mcfab)
            elif violation['type'] == 'unsupported_geometry':
                if cover_multi:
                    cover_unsupported_geometry(violation['cell'], mcfab)
                else:
                    raise ValueError("Unsupported geometry detected and eb2.cover_multiple_cuts is 0")

    # 7. Output
    if params.get('eb2.mc_stl_file'):
        write_eb_surface_stl(eb_dataset, params['eb2.mc_stl_file'])
    return eb_dataset

def build_nodal_level_set(grid, geometry_source):
    level_set = [0.0] * len(grid.nodes)
    if geometry_source.type == "implicit":
        for i, node in enumerate(grid.nodes):
            level_set[i] = geometry_source.func(node.position)
    else:  # STL
        narrow_band_width = 1.0
        for i, node in enumerate(grid.nodes):
            dist = geometry_source.distance(node.position)
            if abs(dist) < narrow_band_width:
                level_set[i] = dist
            else:
                level_set[i] = math.copysign(narrow_band_width, dist)
    return level_set

def snap_to_zero(values, tol=1e-12):
    return [0.0 if abs(v) < tol else v for v in values]

def linear_interpolate(v0, v1):
    if v1 == v0:
        return 0.5
    return v0 / (v0 - v1)

def brent_root_find(start, end, func):
    a, b = 0.0, 1.0
    fa, fb = func(start), func(end)
    if fa * fb > 0:
        return None
    for _ in range(50):
        mid = (a + b) / 2.0
        fm = func(start + mid * (end - start))
        if abs(fm) < 1e-12 or (b - a) < 1e-12:
            return mid
        if fa * fm < 0:
            b, fb = mid, fm
        else:
            a, fa = mid, fm
    return (a + b) / 2.0

def stltools_fill_marching_cubes_edge_intersections(edge, triangles):
    for tri in triangles:
        t = intersect_ray_triangle(edge.start, edge.end, tri)
        if t is not None and 0.0 <= t <= 1.0:
            return t
    return None

def intersect_ray_triangle(origin, direction, tri):
    v0, v1, v2 = tri
    e1 = [v1[j] - v0[j] for j in range(3)]
    e2 = [v2[j] - v0[j] for j in range(3)]
    h = [direction[j] * e2[1] - direction[1] * e2[j] for j in range(3)]
    a = [e1[j] * h[j] for j in range(3)]
    det = sum(a[j] * direction[j] for j in range(3))
    if abs(det) < 1e-12:
        return None
    inv_det = 1.0 / det
    s = [origin[j] - v0[j] for j in range(3)]
    u = sum(s[j] * h[j] for j in range(3)) * inv_det
    if u < 0.0 or u > 1.0:
        return None
    q = [s[j] * e2[1] - s[1] * e2[j] for j in range(3)]
    v = sum(direction[j] * q[j] for j in range(3)) * inv_det
    if v < 0.0 or u + v > 1.0:
        return None
    t = sum(e1[j] * q[j] for j in range(3)) * inv_det
    return t

def compute_case_index(values, isovalue):
    case_index = 0
    for i in range(8):
        if values[i] < isovalue:
            case_index |= (1 << i)
    return case_index

def resolve_mc33_topology(case_index, cached_intersections):
    edge_table = [0] * 256  # Precomputed from parent article
    triangle_table = [[-1] * 16 for _ in range(256)]  # Precomputed from parent article
    tri_indices = triangle_table[case_index]
    triangles = []
    for i in range(0, 16, 3):
        if tri_indices[i] == -1:
            break
        e1 = tri_indices[i]
        e2 = tri_indices[i + 1]
        e3 = tri_indices[i + 2]
        p1 = cached_intersections[e1]
        p2 = cached_intersections[e2]
        p3 = cached_intersections[e3]
        triangles.append((p1, p2, p3))
    return triangles

def check_single_valued_consistency(eb_dataset, mcfab):
    violations = []
    for face in eb_dataset.faces:
        if face.num_fluid_apertures > 1:
            violations.append({'type': 'multi_aperture', 'face': face})
    for cell in eb_dataset.cells:
        if not is_valid_mc_topology(cell):
            violations.append({'type': 'invalid_topology', 'cell': cell})
        if cell.num_fluid_components > 1:
            violations.append({'type': 'multi_component', 'cell': cell})
        if is_tunnel_tiling(cell):
            violations.append({'type': 'tunnel_tiling', 'cell': cell})
        if cell.volume_fraction < params.get('eb2.small_volfrac', 1e-6):
            violations.append({'type': 'small_cell', 'cell': cell})
    return violations

def is_valid_mc_topology(cell):
    return cell.triangles is not None and len(cell.triangles) > 0

def is_tunnel_tiling(cell):
    return cell.fluid_regions_joined_only_through_interior

def repair_small_cell(cell, mcfab):
    for node in cell.fluid_nodes:
        node.position = mcfab.get_interface_point(node)

def cover_unsupported_geometry(cell, mcfab):
    cell.mark_as_solid()

def write_eb_surface_stl(eb_dataset, filepath):
    with open(filepath, 'w') as f:
        f.write("solid eb_surface\n")
        for cell in eb_dataset.cells:
            for tri in cell.triangles:
                f.write(f"  facet normal {tri.normal[0]} {tri.normal[1]} {tri.normal[2]}\n")
                f.write("    outer loop\n")
                for v in tri.vertices:
                    f.write(f"      vertex {v[0]} {v[1]} {v[2]}\n")
                f.write("    endloop\n")
                f.write("  endfacet\n")
        f.write("endsolid eb_surface\n")
```

## Operating characteristics
*   **Time Complexity**: Not given in the sources.
*   **Memory Complexity**: Proportional to the number of voxels and edges, storing the `MCFab` data structure with cached edge intersections and connectivity decisions [S1, unofficial].
*   **Measured Performance**: The EB produced by Marching Cubes is much better than the existing legacy method [S1, unofficial].
*   **Strengths**: Exact edge intersections avoid inconsistencies from linear interpolation of sampled level-set values [S1, unofficial]. Consistent handling of ambiguous cases prevents cracks or holes [S1, unofficial]. Integration with AMReX EB framework allows for efficient single-valued representation [S1, unofficial].
*   **Limitations**: Only available in 3D on Cartesian grids with cubic cells [S1, unofficial]. Incompatible with `BuildMultiValuedMultiCut` [S1, unofficial]. Requires iterative cleanup for small cells and unsupported geometry [S1, unofficial].
*   **When to Use**: When high-fidelity EB geometry is required on 3D Cartesian grids with cubic cells, and the geometry source is an implicit function or STL [S1, unofficial].
*   **When Not to Use**: On non-cubic grids, in 2D, or when multi-valued cuts are required [S1, unofficial].

## Background
This method was introduced in the AMReX framework via Pull Request #5607 by ankithadas in August 2026 [S1, unofficial]. It extends the Marching Cubes algorithm to EB generation, addressing limitations of the legacy EB construction method [S1, unofficial]. It is used in AMReX for EB generation on 3D Cartesian grids with cubic cells, including tests for box, sphere, gyroid, parser implicit functions, STL geometries (cube, multiple cubes, Stanford bunny), periodic domains, and CNS Sod MarchingCubes_3d test [S1, unofficial].
