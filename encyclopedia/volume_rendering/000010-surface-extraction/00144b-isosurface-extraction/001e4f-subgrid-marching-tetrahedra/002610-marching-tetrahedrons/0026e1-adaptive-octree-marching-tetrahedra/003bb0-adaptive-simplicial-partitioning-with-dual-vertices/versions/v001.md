# Adaptive Simplicial Partitioning with Dual Vertices

Also called: Adaptive simplicial partitioning, Dual vertex placement on simplicial partitions

## Overview
Adaptive Simplicial Partitioning with Dual Vertices is an isosurface extraction method that constructs a simplicial complex from an adaptive octree to facilitate mesh generation. It differs from standard Marching Tetrahedra by introducing "dual vertices" within octree cells (cubes, faces, edges) rather than using only the grid vertices. These dual vertices are positioned to minimize distance to local tangent planes, allowing for better approximation of sharp features and reducing the sliver triangles common in naive tetrahedralizations. It builds on [Adaptive Octree Marching Tetrahedra](3897-adaptive-octree-marching-tetrahedra.md) by refining the geometric representation within the leaf nodes and their shared boundaries.

## How it works
**Inputs:** An adaptive octree representing a scalar field $F(\mathbf{p})$, a target isovalue $I$, and a small epsilon $\epsilon$ (e.g., $10^{-6}$) to prevent boundary degeneracy.
**Outputs:** A set of tetrahedra forming the isosurface mesh.

**Data Structures:**
*   **Octree Node:** Contains spatial bounds, scalar values at vertices, and a flag indicating if it is a leaf (minimal 3-cell).
*   **Dual Vertex:** A 4D point $\bar{p} = \langle \mathbf{p}, F(\mathbf{p}) \rangle \in \mathbb{R}^4$, where $\mathbf{p} \in \mathbb{R}^3$ is the spatial position and $F(\mathbf{p})$ is the function value.
    *   For 0-cells (vertices), $\bar{p}$ coincides with the octree vertex.
    *   For $m$-cells ($m > 0$), $\mathbf{p}$ is constrained to lie strictly inside the cell, scaled by $1-\epsilon$.

**Algorithm Steps:**

1.  **Identify Minimal Cells:** Traverse the octree to find all minimal $m$-cells. A minimal $m$-cell is a cell of dimension $m$ that does not contain any other cells of dimension $m$ as a subset.
    *   Minimal 3-cells are leaf cubes.
    *   Minimal 2-cells are faces shared by adjacent leaf cubes (or exposed faces of the domain).
    *   Minimal 1-cells are edges shared by adjacent minimal faces.
    *   Minimal 0-cells are vertices.

2.  **Sample Field Data:** For each minimal $m$-cell, sample the scalar field $F(\mathbf{p})$ and the normal vector $\bar{n}_i = \langle \nabla F(\mathbf{p}_i), -1 \rangle$ at each octree vertex $\mathbf{p}_i$ on the boundary of the cell.
    *   If $m < 3$, restrict the gradient $\nabla F(\mathbf{p}_i)$ to the subspace defined by the cell by projecting it onto that subspace [S1].

3.  **Compute Dual Vertices:** For each minimal $m$-cell, compute the dual vertex $\bar{x} = \langle \mathbf{x}, F(\mathbf{x}) \rangle$ by minimizing the squared distance to the tangent planes defined by the boundary samples.
    *   The tangent plane at vertex $\mathbf{p}_i$ is defined by normal $\bar{n}_i$ and point $\bar{p}_i$.
    *   Solve the constrained optimization problem:
        $$ \min_{\bar{x}} \sum_i (\bar{n}_i \cdot \bar{x} - \bar{n}_i \cdot \bar{p}_i)^2 $$
        subject to the constraint that the spatial coordinates $\mathbf{x}$ lie within the cell scaled by $1-\epsilon$ [S1].
    *   This is a quadratic minimization with box constraints. A standard method for solving this is described by Lindstrom et al. [LS01].
    *   **Pitfall:** In regions of high curvature, the function value $F(\mathbf{x})$ derived from this plane intersection may be a poor estimate (consistently high or low), potentially causing dimpling. [S1]

4.  **Recursive Tetrahedralization:** Construct the simplicial complex recursively based on dimension $m$:
    *   **Base Case ($m=0$):** Each minimal 0-cell (vertex) is a 0-simplex (point) consisting of its dual vertex.
    *   **Recursive Step:** For each minimal $(i+1)$-cell with a dual vertex, connect this dual vertex to all $i$-simplices defined on the boundary of the $(i+1)$-cell. This forms a set of $(i+1)$-simplices.
        *   Example: Edges (1-simplices) are formed by connecting edge-dual vertices to the 0-simplices (vertices) at their endpoints.
        *   Example: Faces (2-simplices) are formed by connecting face-dual vertices to the 1-simplices (edges) on their boundary.
        *   Example: Cubes (3-simplices/tetrahedra) are formed by connecting cube-dual vertices to the 2-simplices (faces) on their boundary.

5.  **Isosurface Extraction:** Apply the standard Marching Tetrahedra algorithm [DK91] to the resulting tetrahedra (3-simplices) to extract the isosurface. The scalar values at the dual vertices are used to determine which edges of the tetrahedra intersect the isovalue.

    """
    Extracts isosurface using adaptive simplicial partitioning.
    
    Args:
        octree: The adaptive octree structure.
        isovalue: The target scalar value for the isosurface.
        epsilon: Small value to constrain dual vertices away from cell boundaries.
        
    Returns:
        List of tetrahedra (each defined by 4 indices into the dual vertex list).

    # Step 2 & 3: Compute dual vertices

            # Normal vector in 4D: <grad, -1>

        b = []

            # We only care about spatial coordinates for the position x

            # n_i . p_i (4D dot product)

            # or use the plane intersection. The source is ambiguous on the exact F(x) assignment
            # beyond the minimization of spatial position. 
            # [G] Standard practice in this specific paper is to use the function value 
            # corresponding to the dual vertex position. If F is not easily evaluable at x,

            # So 12 tetrahedra per cube?

            # This implies the output of the recursive step is a set of tetrahedra.
            # We must decompose the 3-simplices (which are actually pyramids over faces) into tetrahedra.
            
            # Let's assume the "3-simplex" in the source context refers to the volume element.
            # To be precise: The recursive step builds the complex.
            # For a cube (3-cell), we have a dual vertex.
            # We connect it to the 2-simplices (faces).
            # This forms 6 pyramids.
            # Each pyramid has a triangular or quadrilateral base?
            # The 2-simplices are triangles (if the face was triangulated) or quads?
            # The source says "Face-dual simplices are added to each adjacent line segment to form...".
            # It doesn't explicitly triangulate the faces.
            # However, Marching Tetrahedra operates on tetrahedra.
            # We must decompose the cube's volume into tetrahedra.
            # A common way is to split the cube into 5 or 6 tetrahedra.
            # Given the dual vertex, we can split each face into triangles if it isn't already.
            # Then connect the dual vertex to each triangle to form a tetrahedron.
            
            # Check if faces are triangles. If not, triangulate.
            for b_cell in boundary_2_cells:
                face_vertices = simplices[2][b_cell.id]
                if len(face_vertices) == 4: # Quad
                    # Split quad into 2 triangles

                    tetrahedra.append([dual_vertices[cell.id]] + t2)
                else: # Triangle
                    tetrahedra.append([dual_vertices[cell.id]] + face_vertices)

    # Step 5: Isosurface Extraction
    # Apply Marching Tetrahedra to each tetrahedron
    mesh = []
    for tet in tetrahedra:
        # tet is a list of 4 dual vertices
        # Get scalar values
        vals = [v.w for v in tet]
        # Check if isovalue crosses any edge
        # Standard MT logic
        intersections = marching_tetrahedra_step(tet, vals, isovalue)
        mesh.extend(intersections)
        
    return mesh

## Subtopics

### [Triangulation Improvement via Isosurface Projection](9051-triangulation-improvement-via-isosurface-projection.md)
A post-processing step to reduce sliver triangles by moving dual vertices onto the isosurface while keeping them within their respective cells.

## Operating characteristics
*   **Time Complexity:** Dominated by the octree traversal and the solution of the least-squares problem for each minimal cell. The least-squares problem is small (constant size per cell) but involves solving a constrained quadratic program.
*   **Memory Complexity:** Proportional to the number of minimal cells in the octree, as each requires storing a dual vertex.
*   **Strengths:** Better approximation of sharp features compared to standard grid-based methods; reduces T-intersections by constraining dual vertices within cells; adaptive resolution allows for efficient representation of complex geometries.
*   **Limitations:** The function value estimation at dual vertices can be inaccurate in high-curvature regions, leading to visual artifacts like dimpling. The recursive tetrahedralization and subsequent Marching Tetrahedra step add complexity.
*   **When to use:** When high-quality isosurfaces with sharp features are required from adaptive data, and standard Marching Cubes/Tetrahedra produce insufficiently smooth or accurate results.

## Background
The method was introduced by Lindstrom et al. in the paper "Isosurfaces Over Simplicial Partitions of Multiresolution Grids" [S1]. It extends the concept of simplicial partitions to multiresolution grids (octrees), allowing for adaptive refinement. The approach addresses the limitations of uniform grid methods and standard adaptive methods by providing a more flexible geometric representation within the cells.
