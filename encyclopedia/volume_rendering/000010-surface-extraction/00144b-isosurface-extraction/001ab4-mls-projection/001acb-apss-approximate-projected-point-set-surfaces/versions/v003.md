# APSS (Approximate Projected Point Set Surfaces)

Also called: MLS projection via Approximate Projected Point Set Surfaces

## Overview
APSS is an iterative method to project a query point onto a surface defined by a point set with normals, using Moving Least Squares (MLS) [S1, unofficial]. It builds on [MLS Projection](823-mls-projection.md) by computing a local coordinate system and higher-order approximations via weighted accumulators, distinguishing it from standard MLS by explicitly tracking cross-product and dot-product terms for refined surface fitting [S1, unofficial].

## How it works
**Inputs:**
- `inputPositions`: Array of 3D points defining the surface [S1, unofficial].
- `inputNormals`: Array of 3D normals corresponding to `inputPositions` [S1, unofficial].
- `inputPointsetKdTree`: A KD-tree structure built from `inputPositions` for efficient nearest neighbor search [S1, unofficial].
- `queryPoint`: The 3D point to project onto the surface [S1, unofficial].
- `knn`: Number of nearest neighbors to consider. Default value is 20 [S1, unofficial].
- `radius`: The radius parameter for the kernel function used to weight neighbors in the MLS computation [S1, unofficial].
- `numberOfIterations`: The number of iterations for the MLS algorithm loop [S1, unofficial].

**Outputs:**
- `outputPoint`: The projected point on the surface [S1, unofficial].
- `outputNormal`: The normal at the projected point [S1, unofficial].

**Data Structures:**
- `id_nearest_neighbors`: Array of `knn` indices into `inputPositions` [S1, unofficial].
- `square_distances_to_neighbors`: Array of `knn` squared distances from the current query point to the neighbors [S1, unofficial].
- Accumulators (scalars or 3D vectors, initialized to zero): `u123`, `u4`, `u0`, `sum_1`, `sum_4`, `sum_2`, `sum_3`, `sum_weight` [S1, unofficial].

**Steps:**
1. Initialize `outputPoint` to `queryPoint` [S1, unofficial].
2. Initialize `outputNormal` to a default vector (e.g., `(0,0,1)`) [G].
3. Loop `iter` from `0` to `numberOfIterations - 1`:
   a. Find the `knn` nearest neighbors to `outputPoint` using `inputPointsetKdTree.knearest`, retrieving `id_nearest_neighbors` and `square_distances_to_neighbors` [S1, unofficial].
   b. Initialize accumulators to zero: `u123=(0,0,0)`, `u4=0.0`, `u0=0.0`, `sum_1=0.0`, `sum_4=0.0`, `sum_2=(0,0,0)`, `sum_3=(0,0,0)`, `sum_weight=0.0` [S1, unofficial].
   c. Loop `i` from `0` to `knn - 1`:
      i. Retrieve neighbor position `p` from `inputPositions` using `id_nearest_neighbors[i]` [S1, unofficial].
      ii. Retrieve neighbor normal `n` from `inputNormals` using `id_nearest_neighbors[i]` [S1, unofficial].
      iii. Compute weight `w` from `square_distances_to_neighbors[i]` and `radius` [G].
      iv. Update accumulators: `sum_weight += w`, `sum_1 += w`, `sum_2 += w * p`, `sum_3 += w * (p - outputPoint)`, `sum_4 += w * |p - outputPoint|^2`, `u0 += w * (n · (p - outputPoint))`, `u4 += w * |n|^2`, `u123 += w * (n × (p - outputPoint))` [G].

- Weight computation: $w = \max(0, 1 - d^2/r^2)^2$, where $d^2$ is the squared distance and $r$ is the radius [G].
