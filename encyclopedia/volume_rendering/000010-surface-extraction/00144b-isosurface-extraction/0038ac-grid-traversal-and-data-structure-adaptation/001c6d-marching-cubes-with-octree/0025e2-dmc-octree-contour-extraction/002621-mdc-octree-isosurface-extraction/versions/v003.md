# MDC Octree Isosurface Extraction

Also called: MDC, Multi-Dimensional Cell Octree

## Overview
MDC (Multi-Dimensional Cell) Octree Isosurface Extraction is an adaptive surface reconstruction algorithm that uses an octree data structure to recursively subdivide a 3D volume and generate a triangle mesh [S1, unofficial]. It solves the problem of extracting isosurfaces from volumetric data with varying density, handling topology via vertex clustering and collapse logic to ensure manifold connectivity [S1, unofficial]. It sets itself apart from standard marching cubes by dynamically collapsing vertices in low-error regions and clustering boundary vertices to maintain watertight topology without explicit post-processing [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   A 3D volumetric dataset (implicitly accessed via the octree nodes) [G].
*   `root_size`: The size of the root octree node. Must be a power of two [S1, unofficial].
*   `global_pos`: The world coordinate position of the octree root [S1, unofficial].
*   `global_scale`: The global scale factor applied to octree coordinates [S1, unofficial].
*   `epsilon`: A threshold for vertex collapsibility [S1, unofficial].

**Outputs:**
*   A triangle mesh (list of vertices and indices) [S1, unofficial].

### Data Structures

**MDC_OctreeNode**
*   `m_vertices`: List of `MDC_Vertex` objects associated with this node [S1, unofficial].
*   `vertexMask`: Bitmask indicating which vertices are present/valid [S1, unofficial].
*   `isSubdivided`: Boolean flag indicating if the node has children [S1, unofficial].
*   `depth`: Integer tracking octree depth for flip direction calculation [G].

**MDC_Vertex**
*   `m_position`: 3D position vector [S1, unofficial].
*   `m_normal`: Normal vector [S1, unofficial].
*   `m_material`: Enum `Material` (e.g., `Empty`, `Solid`) [S1, unofficial].
*   `m_error`: Scalar error value [S1, unofficial].
*   `m_collapsible`: Boolean flag [S1, unofficial].
*   `m_vertexIdx`: Index in the output mesh. Initialized to `kBadIndex` [S1, unofficial].
*   `m_surfaceIdx`: Index used for Disjoint Set Union (DSU) clustering [S1, unofficial].
*   `highestCollapsibleAncestor`: Pointer to the nearest ancestor vertex that is collapsible [S1, unofficial].

**Constants**
*   `kBadIndex`: `0xFFFFFFFF`, indicating an invalid vertex index [S1, unofficial].
*   `kEdgeProcSharedEdge[D][i]`: Lookup table for shared edge indices for dimension `D` and node `i` [S1, unofficial].
*   `kMdcEdgeSetIndex[n][m]`: Lookup table mapping edge mask and edge index to vertex index within a node [S1, unofficial].
*   `kCellEdgeEndpoint[myedge][0]`: Endpoint index of the edge in the cell [S1, unofficial].

### Parameters
*   `root_size`: Power of two. If not, an exception is thrown [S1, unofficial].
*   `epsilon`: Threshold for marking non-leaf vertices as collapsible if `error <= epsilon` [S1, unofficial].

### Algorithm Steps

1.  **Initialization**: Construct the `MDC_Octree` with `root_size`, `global_pos`, and `global_scale`. Validate `root_size` is a power of two [S1, unofficial].
2.  **Vertex Collection (`addVerticesToMesh`)**: Recursively traverse the octree [S1, unofficial]. For each node, iterate through its vertices [S1, unofficial]. If the node is a leaf, mark vertices as collapsible [S1, unofficial]. If not a leaf, mark vertices as collapsible if `error <= epsilon` [S1, unofficial]. If a vertex is collapsible and has no collapsible ancestor, add it to the mesh, assign a unique index, and update `m_vertexIdx` [S1, unofficial]. Otherwise, assign `kBadIndex` to `m_vertexIdx` [S1, unofficial]. Recurse into children if the node is subdivided [S1, unofficial].
3.  **Cell Processing (`cellProc`)**: If the node is a leaf, return [S1, unofficial]. Otherwise, recursively process all 8 children [S1, unofficial]. Then, call sub-face processing for dimensions 0, 1, and 2: `callSubFaceProc(0)`, `callSubFaceProc(1)`, `callSubFaceProc(2)` [S1, unofficial]. Then, call sub-edge processing for dimensions 0, 1, and 2: `callSubEdgeProc(0)`, `callSubEdgeProc(1)`, `callSubEdgeProc(2)` [S1, unofficial].
4.  **Edge Processing (`edgeProc`)**: For a given dimension `D`, take the 4 nodes sharing the edge [S1, unofficial]. Resolve children if subdivided [S1, unofficial]. If all 4 are leaves, call `edgeProcLeaves` [S1, unofficial]. Otherwise, call `callSubEdgeProc(D)` [S1, unofficial].
5.  **Edge Processing Leaves (`edgeProcLeaves`)**: For dimension `D` and 4 nodes, get the shared edge index for each node using `kEdgeProcSharedEdge[D][i]` [S1, unofficial]. Get the vertex index from the node's vertex list using `kMdcEdgeSetIndex[nodes[i]->vertexMask()][myedge]` [S1, unofficial]. If the index is invalid (`kBadIndex`) or out of bounds, return [S1, unofficial]. Get the highest collapsible ancestor for each vertex [S1, unofficial]. If any vertex's ancestor is null, return [S1, unofficial]. Determine flip direction: find the deepest node among the 4 [S1, unofficial]. Check if the corner at `kCellEdgeEndpoint[myedge][0]` is `Material::Empty` [S1, unofficial]. If so, `flip = true` [S1, unofficial]. Add two triangles to the mesh using the vertex indices, respecting the `flip` flag [S1, unofficial].
6.  **Face Processing (`faceProc`)**: For a given dimension `D`, take the 2 nodes sharing the face [S1, unofficial]. Resolve children if subdivided [S1, unofficial]. If all are leaves, return [S1, unofficial]. Otherwise, call `callSubFaceProc(D)` [S1, unofficial]. Then, recursively call `callSubEdgeProc` for dimensions `(D+1)%3` and `(D+2)%3` [S1, unofficial].
7.  **Vertex Clustering (`clusterEdgeLeaves`)**: For dimension `D` and 4 nodes, get shared edge indices [S1, unofficial]. Get the highest ancestor vertex for each of the 4 nodes [S1, unofficial]. If a vertex's `surfaceIdx` is `kBadIndex`, add it to the vertices list and create a new set in the Disjoint Set Union (DSU) [S1, unofficial]. Merge the sets: `vertex[0]` with `vertex[1]`, `vertex[2]` with `vertex[3]`, and `vertex[0]` with `vertex[2]` [S1, unofficial].
8.  **Edge Clustering (`clusterEdge`)**: For dimension `D`, take 4 nodes [S1, unofficial]. Resolve children if subdivided [S1, unofficial]. If all are leaves, call `clusterEdgeLeaves` [S1, unofficial]. Otherwise, call `callSubClusterEdge(D)` [S1, unofficial].
9.  **Face Clustering (`clusterFace`)**: For dimension `D`, take 2 nodes [S1, unofficial]. Resolve children if subdivided [S1, unofficial]. If all are leaves, return [S1, unofficial]. Otherwise, call `callSubClusterFace(D)` [S1, unofficial].

### Pseudocode

```python
kBadIndex = 0xFFFFFFFF
epsilon = 0.0  # Parameter
mesh = []      # List of triangles
dsu = DSU()    # Disjoint Set Union structure

def addVerticesToMesh(node, highest_collapsible_ancestor=None):
    is_collapsible = node.is_leaf or node.m_error <= epsilon
    for vertex in node.m_vertices:
        vertex.m_collapsible = is_collapsible
        if is_collapsible and highest_collapsible_ancestor is None:
            highest_collapsible_ancestor = vertex
        if vertex.m_collapsible and highest_collapsible_ancestor is vertex:
            vertex.m_vertexIdx = len(mesh)
            mesh.append((vertex.m_position, vertex.m_normal))
            vertex.m_surfaceIdx = kBadIndex
        else:
            vertex.m_vertexIdx = kBadIndex
        vertex.highestCollapsibleAncestor = highest_collapsible_ancestor
    if node.isSubdivided:
        for child in node.children:
            addVerticesToMesh(child, highest_collapsible_ancestor)

def cellProc(node):
    if node.is_leaf:
        return
    for child in node.children:
        cellProc(child)
    for dim in range(3):
        callSubFaceProc(node, dim)
    for dim in range(3):
        callSubEdgeProc(node, dim)

def edgeProc(node, dim):
    nodes = get_nodes_sharing_edge(node, dim)
    if all(n.is_leaf for n in nodes):
        edgeProcLeaves(nodes, dim)
    else:
        callSubEdgeProc(node, dim)

def edgeProcLeaves(nodes, dim):
    vertex_indices = []
    for i, n in enumerate(nodes):
        myedge = kEdgeProcSharedEdge[dim][i]
        v_idx = kMdcEdgeSetIndex[n.vertexMask()][myedge]
        if v_idx == kBadIndex or v_idx >= len(n.m_vertices):
            return
        vertex_indices.append(n.m_vertices[v_idx])

    for v in vertex_indices:
        if v.highestCollapsibleAncestor is None:
            return

    deepest_node = max(nodes, key=lambda n: n.depth)
    myedge = kEdgeProcSharedEdge[dim][0]
    if deepest_node.material_at(kCellEdgeEndpoint[myedge][0]) == Material.Empty:
        flip = True
    else:
        flip = False

    v0 = vertex_indices[0].highestCollapsibleAncestor
    v1 = vertex_indices[1].highestCollapsibleAncestor
    v2 = vertex_indices[2].highestCollapsibleAncestor
    v3 = vertex_indices[3].highestCollapsibleAncestor

    if not flip:
        mesh.append((v0, v1, v2))
        mesh.append((v1, v3, v2))
    else:
        mesh.append((v0, v2, v1))
        mesh.append((v1, v2, v3))

def faceProc(node, dim):
    nodes = get_nodes_sharing_face(node, dim)
    if all(n.is_leaf for n in nodes):
        return
    callSubFaceProc(node, dim)
    callSubEdgeProc(node, (dim + 1) % 3)
    callSubEdgeProc(node, (dim + 2) % 3)

def clusterEdgeLeaves(nodes, dim):
    ancestors = []
    for i, n in enumerate(nodes):
        myedge = kEdgeProcSharedEdge[dim][i]
        v_idx = kMdcEdgeSetIndex[n.vertexMask()][myedge]
        v = n.m_vertices[v_idx]
        ancestors.append(v.highestCollapsibleAncestor)

    for anc in ancestors:
        if anc.m_surfaceIdx == kBadIndex:
            anc.m_surfaceIdx = dsu.new_set()

    dsu.union(ancestors[0], ancestors[1])
    dsu.union(ancestors[2], ancestors[3])
    dsu.union(ancestors[0], ancestors[2])

def clusterEdge(node, dim):
    nodes = get_nodes_sharing_edge(node, dim)
    if all(n.is_leaf for n in nodes):
        clusterEdgeLeaves(nodes, dim)
    else:
        callSubClusterEdge(node, dim)

def clusterFace(node, dim):
    nodes = get_nodes_sharing_face(node, dim)
    if all(n.is_leaf for n in nodes):
        return
    callSubClusterFace(node, dim)

# Helper definitions
def get_nodes_sharing_edge(node, dim):
    if node.is_leaf:
        return [node, node, node, node]
    return [node.children[0], node.children[1], node.children[2], node.children[3]]

def get_nodes_sharing_face(node, dim):
    if node.is_leaf:
        return [node, node]
    return [node.children[0], node.children[1]]

def callSubFaceProc(node, dim):
    if node.isSubdivided:
        for child in node.children:
            faceProc(child, dim)

def callSubEdgeProc(node, dim):
    if node.isSubdivided:
        for child in node.children:
            edgeProc(child, dim)

def callSubClusterEdge(node, dim):
    if node.isSubdivided:
        for child in node.children:
            clusterEdge(child, dim)

def callSubClusterFace(node, dim):
    if node.isSubdivided:
        for child in node.children:
            clusterFace(child, dim)
```

### Edge Cases and Pitfalls
*   **Winding Order**: The algorithm assumes the lower endpoint of the minimal edge is solid. If this is not the case, the triangles' winding order must be flipped to remain facing outside the surface. This is handled by the `flip` boolean in `edgeProcLeaves` [S1, unofficial].
*   **Invalid Vertex Index**: If the calculated vertex index for an edge is negative or out of bounds for the node's vertex list, the processing for that edge/face/cell is skipped (return) [S1, unofficial].
*   **Root Size**: `root_size` must be a power of two. If not, an exception is thrown [S1, unofficial].

*   **Strengths**: Adaptive subdivision allows for high detail where needed and coarser resolution elsewhere. Vertex clustering ensures manifold topology [S1, unofficial].
*   **Limitations**: Complexity of implementation due to recursive traversal and DSU management [S1, unofficial].
*   **When to use**: When adaptive resolution is required for isosurface extraction [S1, unofficial].
*   **When not to use**: When a simpler, non-adaptive method like standard Marching Cubes is sufficient [G].

## Background
The MDC Octree Isosurface Extraction method is part of the Isomesh library, developed by Pavel Asyutchenko [S1, unofficial]. It is an adaptation of isosurface extraction techniques to work efficiently with octree data structures, allowing for hierarchical representation of volumetric data [S1, unofficial].
