# Marching Lines

Also called: Marching Lines for Volumetric Contour Extraction, Crest Line Extraction, Surface Intersection Tracing

## Overview
Marching Lines extracts the 1D intersection curves (contours) formed by two implicit scalar fields within a 3D volume [S1]. It serves as the volumetric counterpart to Marching Cubes, producing closed loops or open segments representing crest lines or general surface intersections [S1].

## How it works
**Inputs and Outputs:**
- **Input:** Two implicit scalar functions, $f(\mathbf{x})$ and $c(\mathbf{x})$, defined on a regular 3D grid.
- **Output:** A set of 1D line segments in 3D space, which form closed loops or open curves representing the intersection where $f(\mathbf{x}) = 0$ and $c(\mathbf{x}) = 0$ [S1].

**Data Structures:**
- **Grid:** 3D arrays storing scalar values for $f$ and $c$ at integer coordinates $(i, j, k)$.
- **Visited Flags:** A boolean array per voxel to track whether a contour loop has already been processed to avoid duplication [S1, G].

**Algorithm Steps:**
1. Locate cubes containing zeros of both $f$ and $c$ [S1].
2. Find intersections of the two implicit functions on the faces of the cube, using linear interpolation based on the values at the eight corners [S1].
3. Find any intersections between these two sets of lines on each face [S1].
4. Connect the resulting points on the faces of the cube to yield segments of the contour [S1].
5. Walk through voxels that contain more than one line segment in an arbitrary but consistent manner to ensure complete loops are formed [S1]. Move to the cell adjacent to the face containing one of the intersection points and repeat until returning to the seed cell [S1].

**Formulas:**
Linear interpolation on an edge between vertices $\mathbf{v}_1$ and $\mathbf{v}_2$ with scalar values $v_1$ and $v_2$:
$$ \mathbf{p} = \mathbf{v}_1 + \frac{0 - v_1}{v_2 - v_1} (\mathbf{v}_2 - \mathbf{v}_1) $$
[S1]

**Pseudocode:**
```python
def marching_lines(grid_f, grid_c, dims):
    nx, ny, nz = dims
    visited = [[[False]*nz for _ in range(ny)] for _ in range(nx)]
    all_segments = []

    def interp_edge(v1, p1, v2, p2):
        if abs(v2 - v1) < 1e-9: return None
        t = -v1 / (v2 - v1)
        if 0 <= t <= 1: return (p1[0] + t*(p2[0]-p1[0]), p1[1] + t*(p2[1]-p1[1]), p1[2] + t*(p2[2]-p1[2]))
        return None

    def seg_intersect_2d(s1, s2):
        p1, p2 = s1[0], s1[1]
        p3, p4 = s2[0], s2[1]
        denom = (p1[0]-p2[0])*(p3[1]-p4[1]) - (p1[1]-p2[1])*(p3[0]-p4[0])
        if abs(denom) < 1e-9: return None
        t = ((p1[0]-p3[0])*(p3[1]-p4[1]) - (p1[1]-p3[1])*(p3[0]-p4[0])) / denom
        u = -((p1[0]-p2[0])*(p1[1]-p3[1]) - (p1[1]-p2[1])*(p1[0]-p3[0])) / denom
        if 0 <= t <= 1 and 0 <= u <= 1:
            return (p1[0] + t*(p2[0]-p1[0]), p1[1] + t*(p2[1]-p1[1]), p1[2] + t*(p2[2]-p1[2]))
        return None

    for i in range(nx - 1):
        for j in range(ny - 1):
            for k in range(nz - 1):
                if visited[i][j][k]: continue

                f_vals = [grid_f[i+dx][j+dy][k+dz] for dx in (0,1) for dy in (0,1) for dz in (0,1)]
                c_vals = [grid_c[i+dx][j+dy][k+dz] for dx in (0,1) for dy in (0,1) for dz in (0,1)]
                if not (any(v < 0 for v in f_vals) and any(v > 0 for v in f_vals)): continue
                if not (any(v < 0 for v in c_vals) and any(v > 0 for v in c_vals)): continue

                face_pts = []
                faces = [('x', 0), ('x', 1), ('y', 0), ('y', 1), ('z', 0), ('z', 1)]
                for axis, val in faces:
                    if axis == 'x':
                        pts = [(i+val, j, k), (i+val, j+1, k), (i+val, j+1, k+1), (i+val, j, k+1)]
                        fv = [grid_f[p[0]][p[1]][p[2]] for p in pts]
                        cv = [grid_c[p[0]][p[1]][p[2]] for p in pts]
                    elif axis == 'y':
                        pts = [(i, j+val, k), (i+1, j+val, k), (i+1, j+val, k+1), (i, j+val, k+1)]
                        fv = [grid_f[p[0]][p[1]][p[2]] for p in pts]
                        cv = [grid_c[p[0]][p[1]][p[2]] for p in pts]
                    else:
                        pts = [(i, j, k+val), (i+1, j, k+val), (i+1, j+1, k+val), (i, j+1, k+val)]
                        fv = [grid_f[p[0]][p[1]][p[2]] for p in pts]
                        cv = [grid_c[p[0]][p[1]][p[2]] for p in pts]

                    edges = [(0,1), (1,2), (2,3), (3,0)]
                    f_seg_pts = []
                    c_seg_pts = []
                    for e_idx in edges:
                        p1, p2 = pts[e_idx], pts[edges[e_idx][1]]
                        if (fv[e_idx] < 0) != (fv[edges[e_idx][1]] < 0):
                            f_seg_pts.append(interp_edge(fv[e_idx], p1, fv[edges[e_idx][1]], p2))
                        if (cv[e_idx] < 0) != (cv[edges[e_idx][1]] < 0):
                            c_seg_pts.append(interp_edge(cv[e_idx], p1, cv[edges[e_idx][1]], p2))

                    if len(f_seg_pts) == 2 and len(c_seg_pts) == 2:
                        pt = seg_intersect_2d((f_seg_pts[0], f_seg_pts[1]), (c_seg_pts[0], c_seg_pts[1]))
                        if pt: face_pts.append((axis, val, pt))

                voxel_segs = []
                if len(face_pts) == 2:
                    voxel_segs.append((face_pts[0][2], face_pts[1][2], (i,j,k)))
                elif len(face_pts) == 4:
                    voxel_segs.append((face_pts[0][2], face_pts[1][2], (i,j,k)))
                    voxel_segs.append((face_pts[2][2], face_pts[3][2], (i,j,k)))

                if voxel_segs:
                    for seg in voxel_segs:
                        if not visited[i][j][k]:
                            loop = trace_loop(seg, grid_f, grid_c, dims, visited)
                            all_segments.extend(loop)
    return all_segments

def trace_loop(start_seg, grid_f, grid_c, dims, visited):
    nx, ny, nz = dims
    loop = []
    current_seg = start_seg
    current_voxel = start_seg[2]
    visited[current_voxel[0]][current_voxel[1]][current_voxel[2]] = True

    while True:
        loop.append(current_seg)
        p = current_seg[1]
        i, j, k = current_voxel
        if abs(p[0] - (i+1)) < 1e-6: face = ('x', 1)
        elif abs(p[0] - i) < 1e-6: face = ('x', 0)
        elif abs(p[1] - (j+1)) < 1e-6: face = ('y', 1)
        elif abs(p[1] - j) < 1e-6: face = ('y', 0)
        elif abs(p[2] - (k+1)) < 1e-6: face = ('z', 1)
        else: face = ('z', 0)

        if face[0] == 'x': next_v = (current_voxel[0] + (1 if face[1]==1 else -1), current_voxel[1], current_voxel[2])
        elif face[0] == 'y': next_v = (current_voxel[0], current_voxel[1] + (1 if face[1]==1 else -1), current_voxel[2])
        else: next_v = (current_voxel[0], current_voxel[1], current_voxel[2] + (1 if face[1]==1 else -1))

        if not (0 <= next_v[0] < nx-1 and 0 <= next_v[1] < ny-1 and 0 <= next_v[2] < nz-1): break

        # Re-evaluate the shared face in the adjacent voxel to find the matching segment
        axis, val = face
        if axis == 'x':
            pts = [(next_v[0], next_v[1], next_v[2]), (next_v[0], next_v[1]+1, next_v[2]), (next_v[0], next_v[1]+1, next_v[2]+1), (next_v[0], next_v[1], next_v[2]+1)]
            fv = [grid_f[p[0]][p[1]][p[2]] for p in pts]
            cv = [grid_c[p[0]][p[1]][p[2]] for p in pts]
        elif axis == 'y':
            pts = [(next_v[0], next_v[1], next_v[2]), (next_v[0]+1, next_v[1], next_v[2]), (next_v[0]+1, next_v[1], next_v[2]+1), (next_v[0], next_v[1], next_v[2]+1)]
            fv = [grid_f[p[0]][p[1]][p[2]] for p in pts]
            cv = [grid_c[p[0]][p[1]][p[2]] for p in pts]
        else:
            pts = [(next_v[0], next_v[1], next_v[2]), (next_v[0]+1, next_v[1], next_v[2]), (next_v[0]+1, next_v[1]+1, next_v[2]), (next_v[0], next_v[1]+1, next_v[2])]
            fv = [grid_f[p[0]][p[1]][p[2]] for p in pts]
            cv = [grid_c[p[0]][p[1]][p[2]] for p in pts]

        edges = [(0,1), (1,2), (2,3), (3,0)]
        f_seg_pts = []
        c_seg_pts = []
        for e_idx in edges:
            p1, p2 = pts[e_idx], pts[edges[e_idx][1]]
            if (fv[e_idx] < 0) != (fv[edges[e_idx][1]] < 0):
                f_seg_pts.append(interp_edge(fv[e_idx], p1, fv[edges[e_idx][1]], p2))
            if (cv[e_idx] < 0) != (cv[edges[e_idx][1]] < 0):
                c_seg_pts.append(interp_edge(cv[e_idx], p1, cv[edges[e_idx][1]], p2))

        next_seg = None
        if len(f_seg_pts) == 2 and len(c_seg_pts) == 2:
            pt = seg_intersect_2d((f_seg_pts[0], f_seg_pts[1]), (c_seg_pts[0], c_seg_pts[1]))
            if pt: next_seg = (current_seg[0], pt, next_v)

        if next_seg is None: break
        visited[next_v[0]][next_v[1]][next_v[2]] = True
        current_voxel = next_v
        current_seg = next_seg
        if current_voxel == start_seg[2] and current_seg == start_seg: break
    return loop
```

**Parameters:**
- **Threshold:** Implicitly 0 for both functions $f$ and $c$ [S1].
- **Interpolation:** Linear interpolation is standard [S1].

**Edge Cases and Pitfalls:**
- **Degenerate Cases:** Parallel or coincident intersection lines on a face yield undefined or infinite intersections; standard geometric intersection checks handle this [G].
- **Precision:** Linear interpolation assumes well-behaved implicit functions within the voxel [G].
- **Seed Selection:** The algorithm requires at least one valid seed cell for every loop [S1].

## Subtopics

### Cutting Plane Intersection
This variant renders lines for the intersection of a single isosurface ($f=0$) with six axis-aligned cutting planes (two per axis, representing positive and negative bounds) [S1]. It uses the same Marching Lines logic by treating the cutting plane as a second implicit function $c(\mathbf{x})$ defined by the plane equation [S1].

## Operating characteristics
- **Time Complexity:** Output-sensitive, $O(m)$ where $m$ is the total length of all loops in terms of voxels traversed [S1].
- **Space Complexity:** $O(n^3)$ for the grid storage plus $O(m)$ for the output [G].
- **Performance:** Efficient for sparse contours where $m \ll n^3$. In typical cases, $m$ is $O(n)$ in an $n^3$ volume [S1].
- **Strengths:** Direct extraction of 1D features; output-sensitive; generalizable to any two implicit functions [S1].
- **Limitations:** Requires finding seed voxels [S1].

## Background
Marching Lines was originally presented by Thirion and Gourdon in 1996 as an adaptation of the Marching Cubes technique for extracting crest lines on surfaces [S1]. It was later generalized to extract the intersection of isosurfaces of any two implicit functions [S1]. The method is widely used in volume rendering for extracting silhouettes, contours, and other 1D features from volumetric data [S1].
