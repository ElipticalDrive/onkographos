# Grid Traversal and Data Structures

Also called: Adaptive Grid Traversal, Hierarchical Isosurface Extraction

## Overview
This family encompasses methods that adapt the domain traversal and data structures of isosurface extraction to handle sparse, hierarchical, or multi-resolution volumetric data, avoiding the memory and computational costs of dense regular grids [S1]. Unlike standard grid-based methods that iterate over fixed arrays, these techniques traverse octrees, sparse point sets, or adaptive mesh refinement (AMR) boundaries, dynamically gathering scalar values and generating geometry only where necessary [S1]. They are distinguished from their siblings by their specific approach to handling topological discontinuities, such as cracks at level boundaries, through mechanisms like uniform node sizing, dynamic lookup, or explicit stitch cell generation.

## Shared principles
All methods in this family operate on a discretized domain, typically a regular grid (Cartesian, octree, or tetrahedral) where each cell contains scalar values or occupancy states at its vertices or centers. The core mechanism involves traversing the grid cells and evaluating the data to determine which parts of the domain constitute the surface [G].

1.  **Domain Traversal**: The algorithm iterates over the volume data structure [G]. For regular grids, this often involves checking each cell or voxel [G].
2.  **Surface Determination**: A criterion is applied to identify surface locations. In isosurface methods, this involves comparing scalar values against a threshold (isovalue) to detect sign changes or equality [30-isosurface-extraction.md]. In blocky meshing, this involves checking occupancy states or material IDs to identify exposed boundaries [31-blocky-meshing.md].
3.  **Primitive Generation**: Geometric primitives (vertices, edges, faces) are generated based on the determined surface locations [G].
4.  **Mesh Coherence**: Adjacent primitives are merged or connected to form a coherent mesh, often requiring vertex merging to avoid duplicates and ensure watertightness [30-isosurface-extraction.md].

## Subtopics

### [Octree-based Isosurfacing](1247-octree-based-isosurfacing.md)
Replaces the uniform Cartesian grid with an octree spatial subdivision to enable adaptive resolution. It sets itself apart by decoupling spatial resolution from global grid density, though it sacrifices the topological guarantees of uniform grids, potentially introducing cracks if the octree is not sufficiently adapted to the surface geometry. Choose this when the scalar field is sparse or has varying feature scales.

### [Grid Traversal and Data Structure Adaptation](8340-grid-traversal-and-data-structure-adaptation.md)
A broad category for adapting traversal to sparse, hierarchical, or AMR data. It distinguishes itself through specific crack-prevention strategies employed by its children, such as uniform node sizing or dynamic lookup. Choose this as the conceptual framework for implementing custom adaptive extractors.

### [Crack-free Isosurface Extraction from AMR Data](9981-crack-free-isosurface-extraction-from-amr-data.md)
Extracts watertight isosurfaces from block-structured AMR data in distributed-memory parallel environments. It solves the problem of T-junctions (cracks) arising from standard Marching Cubes on hierarchical data by using ghost cells and a dual-grid representation. Choose this when processing data from codes like BoxLib or Chombo where memory efficiency and parallel scalability are critical.

## Background
The need for adaptive grid traversal arises from the limitations of uniform grids in representing complex, sparse, or multi-scale phenomena efficiently. Standard isosurface extraction methods, such as Marching Cubes, assume a regular topology, which leads to excessive memory usage and computation when applied to large volumes with localized features. The development of octree-based and AMR-aware extraction methods allows for the representation of fine details near the isosurface while coarsening the representation in empty or uniform regions. This family of techniques is essential in scientific visualization, particularly for data generated by adaptive mesh refinement codes in fluid dynamics and astrophysics.
