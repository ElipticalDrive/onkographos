# MDC Octree Isosurface Extraction

Also called: MDC, Multi-Dimensional Cell Octree

## Overview
MDC (Multi-Dimensional Cell) Octree Isosurface Extraction is an adaptive surface reconstruction algorithm that uses an octree data structure to recursively subdivide a 3D volume and generate a triangle mesh [S1, unofficial]. It solves the problem of extracting isosurfaces from volumetric data with varying density, handling topology via vertex clustering and collapse logic to ensure manifold connectivity [S1, unofficial]. It sets itself apart from its sibling [DMC Octree Contour Extraction](3661-dmc-octree-contour-extraction.md) by explicitly managing vertex clustering across shared edges and faces to resolve topological ambiguities in complex subdivisions, whereas DMC relies on a different contour extraction logic [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   A 3D volumetric dataset (implicitly accessed via the octree nodes).
*   `root_size`: The size of the root octree node. Must be a power of two [S1, unofficial].
*   `global_pos`: The world coordinate position of the octree root [S1, unofficial].
*   `global_scale`: The global scale factor applied to octree coordinates [S1, unofficial].
*   `epsilon`: A threshold for vertex collapsibility [S1, unofficial].

**Outputs:**
*   A triangle mesh (list of vertices and indices).

### Data Structures

**MDC_OctreeNode**
*   `m_vertices`: List of `MDC_Vertex` objects associated with this node.
*   `vertexMask`: Bitmask indicating which vertices are present/valid.
*   `isSubdivided`: Boolean flag indicating if the node has children.

**MDC_Vertex**
*   `m_position`: 3D position vector.
*   `m_normal`: Normal vector.
*   `m_material`: Enum `Material` (e.g., `Empty`, `Solid`) [S1, unofficial].
*   `m_error`: Scalar error value.
*   `m_collapsible`: Boolean flag.
*   `m_vertexIdx`: Index in the output mesh. Initialized to `kBadIndex`.
*   `m_surfaceIdx`: Index used for Disjoint Set Union (DSU) clustering.
*   `highestCollapsibleAncestor`: Pointer to the nearest ancestor vertex that is collapsible.

**Constants**
*   `kBadIndex`: `UINT32_MAX`, indicating an invalid vertex index [S1, unofficial].
*   `kEdgeProcSharedEdge[D][i]`: Lookup table for shared edge indices for dimension `D` and node `i`.
*   `kMdcEdgeSetIndex[n][m]`: Lookup table mapping edge mask and edge index to vertex index within a node.
*   `kCellEdgeEndpoint[myedge][0]`: Endpoint index of the edge in the cell.

### Parameters
*   `root_size`: Power of two. If not, an exception is thrown [S1, unofficial].
*   `epsilon`: Threshold for marking non-leaf vertices as collapsible if `error <= epsilon` [S1, unofficial].

### Algorithm Steps

1.  **Initialization**: Construct the `MDC_Octree` with `root_size`, `global_pos`, and `global_scale`. Validate `root_size` is a power of two [S1, unofficial].

2.  **Vertex Collection (`addVerticesToMesh`)**:
    Recursively traverse the octree. For each node, iterate through its vertices:
    *   If the node is a leaf, mark vertices as collapsible.
    *   If the node is not a leaf, mark vertices as collapsible if `error <= epsilon`.
    *   If a vertex is collapsible and has no collapsible ancestor, add it to the mesh, assign a unique index, and update `m_vertexIdx`.
    *   Otherwise, assign `kBadIndex` to `m_vertexIdx`.
    *   Recurse into children if the node is subdivided [S1, unofficial].

3.  **Cell Processing (`cellProc`)**:
    *   If the node is a leaf, return.
    *   Recursively process all 8 children.
    *   Call sub-face processing for dimensions 0, 1, and 2: `callSubFaceProc(0)`, `callSubFaceProc(1)`, `callSubFaceProc(2)`.
    *   Call sub-edge processing for dimensions 0, 1, and 2: `callSubEdgeProc(0)`, `callSubEdgeProc(1)`, `callSubEdgeProc(2)` [S1, unofficial].

4.  **Edge Processing (`edgeProc`)**:
    For a given dimension `D`:
    *   Take the 4 nodes sharing the edge.
    *   Resolve children if subdivided.
    *   If all 4 are leaves, call `edgeProcLeaves`.
    *   Otherwise, call `callSubEdgeProc(D)` [S1, unofficial].

5.  **Edge Processing Leaves (`edgeProcLeaves`)**:
    For dimension `D` and 4 nodes:
    *   Get the shared edge index for each node using `kEdgeProcSharedEdge[D][i]`.
    *   Get the vertex index from the node's vertex list using `kMdcEdgeSetIndex[nodes[i]->vertexMask()][myedge]`.
    *   If the index is invalid (`kBadIndex`) or out of bounds, return.
    *   Get the highest collapsible ancestor for each vertex. If any vertex's ancestor is null, return.
    *   Determine flip direction: Find the deepest node among the 4. Check if the corner at `kCellEdgeEndpoint[myedge][0]` is `Material::Empty`. If so, `flip = true`.
    *   Add two triangles to the mesh using the vertex indices, respecting the `flip` flag [S1, unofficial].

6.  **Face Processing (`faceProc`)**:
    For a given dimension `D`:
    *   Take the 2 nodes sharing the face.
    *   Resolve children if subdivided.
    *   If all are leaves, return.
    *   Otherwise, call `callSubFaceProc(D)`.
    *   Recursively call `callSubEdgeProc` for dimensions `(D+1)%3` and `(D+2)%3` [S1, unofficial].

7.  **Vertex Clustering (`clusterEdgeLeaves`)**:
    For dimension `D` and 4 nodes:
    *   Get shared edge indices.
    *   Get the highest ancestor vertex for each of the 4 nodes.
    *   If a vertex's `surfaceIdx` is `kBadIndex`, add it to the vertices list and create a new set in the Disjoint Set Union (DSU).
    *   Merge the sets: `vertex[0]` with `vertex[1]`, `vertex[2]` with `vertex[3]`, and `vertex[0]` with `vertex[2]` [S1, unofficial].

8.  **Edge Clustering (`clusterEdge`)**:
    For dimension `D`:
    *   Take 4 nodes. Resolve children if subdivided.
    *   If all are leaves, call `clusterEdgeLeaves`.
    *   Otherwise, call `callSubClusterEdge(D)` [S1, unofficial].

9.  **Face Clustering (`clusterFace`)**:
    For dimension `D`:
    *   Take 2 nodes. Resolve children if subdivided.
    *   If all are leaves, return.
    *   Otherwise, call `callSubClusterFace(D)` [S1, unofficial].

def addVerticesToMesh(node, parent_ancestor=None):
    """
    Recursively traverse octree and assign vertex indices.
    """
    current_ancestor = parent_ancestor
    
    # Determine if current node's vertices are collapsible
    is_collapsible = False
    if node.is_leaf:
        is_collapsible = True
    else:
        # Check error threshold for non-leaf nodes
        if node.error <= epsilon:
            is_collapsible = True
            
    for vertex in node.m_vertices:
        # Update highest collapsible ancestor
        if is_collapsible:
            current_ancestor = vertex
            
        if vertex.m_collapsible and current_ancestor == vertex:
            # Add to mesh and assign index
            vertex.m_vertexIdx = mesh.add_vertex(vertex.m_position, vertex.m_normal)
            vertex.m_surfaceIdx = kBadIndex # Reset for clustering phase
        else:
            vertex.m_vertexIdx = kBadIndex
            
        # Store pointer to highest collapsible ancestor for edge processing
        vertex.highestCollapsibleAncestor = current_ancestor

    # Recurse
    if node.isSubdivided:
        for child in node.children:

### Edge Cases and Pitfalls
*   **Winding Order**: The algorithm assumes the lower endpoint of the minimal edge is solid. If this is not the case, the triangles' winding order must be flipped to remain facing outside the surface. This is handled by the `flip` boolean in `edgeProcLeaves` [S1, unofficial].
*   **Invalid Vertex Index**: If the calculated vertex index for an edge is negative or out of bounds for the node's vertex list, the processing for that edge/face/cell is skipped (return) [S1, unofficial].
*   **Root Size**: `root_size` must be a power of two. If not, an exception is thrown [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: Not given in the sources.
*   **Memory Complexity**: Not given in the sources.

*   **Scaling**: Not given in the sources.
*   **Strengths**: Adaptive subdivision allows for high detail where needed and coarser resolution elsewhere. Vertex clustering ensures manifold topology.
*   **Limitations**: Complexity of implementation due to recursive traversal and DSU management.
*   **When to use**: When adaptive resolution is required for isosurface extraction.
*   **When not to use**: When a simpler, non-adaptive method like standard Marching Cubes is sufficient.

## Background
The MDC Octree Isosurface Extraction method is part of the Isomesh library, developed by Pavel Asyutchenko [S1, unofficial]. It is an adaptation of isosurface extraction techniques to work efficiently with octree data structures, allowing for hierarchical representation of volumetric data [S1, unofficial].
