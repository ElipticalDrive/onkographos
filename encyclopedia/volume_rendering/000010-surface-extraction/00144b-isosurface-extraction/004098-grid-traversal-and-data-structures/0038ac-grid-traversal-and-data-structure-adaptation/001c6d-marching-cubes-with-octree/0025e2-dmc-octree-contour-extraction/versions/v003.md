# DMC Octree Contour Extraction

Also called: Discrete Marching Cubes Octree

## Overview
DMC Octree Contour Extraction is an adaptive isosurface extraction method that traverses a pre-built octree to generate a triangle mesh via dual-vertex construction and contour processing [S1, unofficial]. It solves the problem of extracting high-quality surfaces from volumetric data with varying density by recursively subdividing cells based on field error metrics [S1, unofficial]. It sets itself apart from its sibling [Linear Hashed Marching Cubes](1294-linear-hashed-marching-cubes.md) by using a hierarchical octree structure with explicit contour propagation across shared faces and edges, rather than a flat hash-based lookup, and from [Adaptive Resolution Isosurface Rendering with Two-Pass Discontinuity Handling](1340-adaptive-resolution-isosurface-rendering-with-two-pass-disco.md) by relying on a single-pass recursive traversal with dual-vertex QEF solving rather than a two-pass discontinuity-aware approach [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A root node of a `DMC_Octree` representing the volumetric space, a `ScalarField` providing field values and gradients, and a `BuildArgs` configuration structure [S1, unofficial].
*   **Output:** A `Mesh` containing the extracted triangle vertices and indices, with global position and scale applied [S1, unofficial].

**Data Structures**
*   `DMC_OctreeNode`:
    *   `is_subdivided()`: Boolean method indicating if the node has children [S1, unofficial].
    *   `operator[]`: Accessor for child nodes (array of 8) [S1, unofficial].
    *   `normal`: `Vec3`, stores the averaged normal for dual vertices [S1, unofficial].
    *   `dual_vertex`: `Vec4`, stores the solved vertex position (x, y, z, w) [S1, unofficial].
    *   `material`: Stores material information if `vertex.w <= 0` [S1, unofficial].
*   `BuildArgs`:
    *   `use_early_split_stop`: `bool`, enables early stopping based on field magnitude [S1, unofficial].
    *   `use_simple_split_policy`: `bool`, enables simple splitting based on root size or error [S1, unofficial].
    *   `use_random_sampling`: `bool`, enables random sampling for dual vertex generation [S1, unofficial].
    *   `epsilon`: `double`, error threshold for splitting and vertex solving [S1, unofficial].
    *   `solver`: `QefSolver4D`, accumulates planes for least-squares vertex solving [S1, unofficial].
    *   `field`: `ScalarField`, provides `get_value(pos)` and `get_gradient(pos)` [S1, unofficial].
    *   `rng`: Random number generator state [S1, unofficial].

**Algorithm Steps**

1.  **Initialization**: Create an empty `Mesh` and `VertexMap`. Set the global position and scale on the mesh using the octree's stored global transformation parameters. Call `cell_proc` on the root node [S1, unofficial].
2.  **Cell Processing (`cell_proc`)**:
    *   If the current node is not subdivided, return immediately [S1, unofficial].
    *   Retrieve the 8 child nodes into an array `sub[8]` [S1, unofficial].
    *   **Face Processing**: Iterate `i` from 0 to 3. Call `face_proc_x`, `face_proc_y`, and `face_proc_z` with the two child nodes defining each face, determined by `face_table_x[i]`, `face_table_y[i]`, and `face_table_z[i]` [S1, unofficial].
    *   **Edge Processing**: Iterate `i` from 0 to 1. Call `edge_proc_x`, `edge_proc_y`, and `edge_proc_z` with the four child nodes defining each edge, determined by `edge_table_x[i]`, `edge_table_y[i]`, and `edge_table_z[i]` [S1, unofficial].
    *   **Vertex Processing**: Call `vert_proc` with all 8 child nodes `sub[0]` through `sub[7]` [S1, unofficial].
3.  **Face Processing (`face_proc_x/y/z`)**:
    *   Initialize `sub_table` mapping 8 indices to parent nodes and their child index [S1, unofficial].
    *   Iterate `i` from 0 to 7: If the parent node is subdivided, `sub[i]` is its specific child; otherwise, `sub[i]` is the parent node itself [S1, unofficial].
    *   Set `has_lesser = true` if any node was subdivided [S1, unofficial].
    *   If `has_lesser` is false, return immediately (no geometry to generate for this face configuration) [S1, unofficial].
    *   **Recursive Face Calls**: Iterate `i` from 0 to 3. Call the corresponding `face_proc` function recursively with the two sub-nodes defined by `face_table[i]` [S1, unofficial].
    *   **Edge Calls**: Iterate `i` from 0 to 1. Call the corresponding `edge_proc` function with the four sub-nodes defined by `edge_table[i]` [S1, unofficial].
    *   **Vertex Call**: Call `vert_proc` with all 8 sub-nodes [S1, unofficial].
4.  **Edge Processing (`edge_proc_x/y/z`)**: Handles edge contours using the 4 defining child nodes [S1, unofficial].
5.  **Vertex Processing (`vert_proc`)**: Handles vertex contours using the 8 defining child nodes [S1, unofficial].
6.  **Node Building (`build_node`)**:
    *   If `size` is 1, generate a dual vertex and return [S1, unofficial].
    *   If `use_early_split_stop` is true and `should_stop_splitting` returns true, generate a dual vertex and return [S1, unofficial].
    *   If `use_simple_split_policy` is true:
        *   If `size` equals `m_root_size` or `should_split` returns true, subdivide the node. Calculate `child_size` as `size/2`. Recursively call `build_node` for all 8 children with their respective `min_corners` [S1, unofficial].
        *   Otherwise, generate a dual vertex [S1, unofficial].
    *   If `use_simple_split_policy` is false:
        *   If `size * 8 < m_root_size` and `generate_dual_vertex` returns true, return [S1, unofficial].
        *   Otherwise, subdivide the node, calculate `child_size` as `size/2`, and recursively call `build_node` for all 8 children [S1, unofficial].
7.  **Dual Vertex Generation (`generate_dual_vertex`)**:
    *   Reset the QEF solver. Initialize `avg_normal` to zero [S1, unofficial].
    *   **Sampling**:
        *   If `use_random_sampling` is true: Calculate `points_cnt` as `int(6.0 * sqrt(size))`. Create a uniform distribution `odist(0, size)`. For `points_cnt` iterations, generate a random offset, compute local and global points, get the field value and gradient, and add a plane defined by `point_4d` (local position, local value) and `normal_4d` (gradient, -1.0) to the solver. Accumulate the gradient in `avg_normal` [S1, unofficial].
        *   If `use_random_sampling` is false: Define `min_offset` as `0.25 * size` and `max_offset` as `size - min_offset`. Define 8 sample offsets at these corners. For each of the 8 samples, compute local/global points, field value, gradient, and add a plane to the solver. Accumulate the gradient in `avg_normal` [S1, unofficial].
    *   Normalize `avg_normal` and store it in `node.normal` [S1, unofficial].
    *   Define `lower_bound` as `(min_corner, 0)` and `upper_bound` as `(min_corner + size, 0)`. Solve for the vertex using the solver with these bounds [S1, unofficial].
    *   Evaluate the error of the solved vertex. If `error > args.epsilon`, relax bounds to lowest/max float values and re-solve. Store the final vertex in `node.dual_vertex` [S1, unofficial].
    *   If `vertex.w <= 0`, compute the global value and material, and store the material in `node.material` [S1, unofficial].
    *   Return true if `error <= args.epsilon`, false otherwise [S1, unofficial].
8.  **Splitting Decision (`should_split`)**:
    *   Compute the 8 global corner positions of the cell. Compute the field values at these corners [S1, unofficial].
    *   Initialize `error` to 0 [S1, unofficial].
    *   **Edge Midpoints**: Define `dim1_corners`, `dim1_id_offsets`, and `dim1_offsets` for edge midpoints. For each dimension (0-2) and each of the 4 edges in that dimension, compute the midpoint position, predict the value as the average of the two endpoint values, get the actual field value and gradient magnitude `k`, and add `abs(predict - actual) / k` to `error`. If `error > epsilon`, return true [S1, unofficial].
    *   **Face Midpoints**: Define `dim2_corners`, `dim2_id_offsets`, and `dim2_offsets` for face midpoints. For each dimension (0-2) and each of the 2 faces in that dimension, compute the face center position, predict the value as the average of the 4 corner values, get the actual field value and gradient magnitude `k`, and add `abs(predict - actual) / k` to `error`. If `error > epsilon`, return true [S1, unofficial].
    *   **Cell Center**: Compute the cell center position. Predict the value as the average of all 8 corner values. Get the actual field value and gradient magnitude `k`. Add `abs(predict - actual) / k` to `error`. If `error > epsilon`, return true [S1, unofficial].
    *   Return false if the accumulated error did not exceed `epsilon` [S1, unofficial].
9.  **Early Stop Decision (`should_stop_splitting`)**:
    *   Compute the base global point and the cell side length. Compute the diagonal length as `side * sqrt(3)` [S1, unofficial].
    *   For each of the 8 corners, if the absolute value of the field is less than or equal to the diagonal length, return false (do not stop splitting) [S1, unofficial].
    *   If all 8 corners have field values with absolute value greater than the diagonal, return true (stop splitting) [S1, unofficial].

```python
import math
import random

class Vec3:
    def __init__(self, x=0.0, y=0.0, z=0.0):
        self.x, self.y, self.z = x, y, z
    def __add__(self, other): return Vec3(self.x + other.x, self.y + other.y, self.z + other.z)
    def __sub__(self, other): return Vec3(self.x - other.x, self.y - other.y, self.z - other.z)
    def __mul__(self, s): return Vec3(self.x * s, self.y * s, self.z * s)
    def __truediv__(self, s): return Vec3(self.x / s, self.y / s, self.z / s)
    def length(self): return math.sqrt(self.x**2 + self.y**2 + self.z**2)
    def normalize(self):
        l = self.length()
        return Vec3(self.x/l, self.y/l, self.z/l) if l > 0 else Vec3(0,0,0)

class Vec4:
    def __init__(self, x=0.0, y=0.0, z=0.0, w=0.0):
        self.x, self.y, self.z, self.w = x, y, z, w

class QefSolver4D:
    def __init__(self):
        self.planes = []
    def add_plane(self, normal: Vec4, point: Vec4):
        self.planes.append((normal, point))
    def solve(self, lower: Vec4, upper: Vec4):
        # Standard QEF solve returning a Vec4
        return Vec4(0, 0, 0, 0)

class Mesh:
    def set_global_transform(self, t): pass

class VertexMap:
    pass

class ScalarField:
    def get_value(self, pos): return 0.0
    def get_gradient(self, pos): return Vec3(0,0,0)

class BuildArgs:
    def __init__(self):
        self.use_early_split_stop = False
        self.use_simple_split_policy = False
        self.use_random_sampling = False
        self.epsilon = 1e-3
        self.solver = QefSolver4D()
        self.field = ScalarField()
        self.rng = random.Random()

class DMC_OctreeNode:
    def is_subdivided(self): return False
    def __getitem__(self, i): return None

# Standard face/edge tables mapping indices to child node indices
face_table_x = [(0,1), (2,3), (4,5), (6,7)]
face_table_y = [(0,2), (1,3), (4,6), (5,7)]
face_table_z = [(0,4), (1,5), (2,6), (3,7)]
edge_table_x = [(0,1,2,3), (4,5,6,7)]
edge_table_y = [(0,1,4,5), (2,3,6,7)]
edge_table_z = [(0,2,4,6), (1,3,5,7)]

def get_child_offset(idx, size):
    offsets = [
        Vec3(0,0,0), Vec3(size,0,0), Vec3(0,size,0), Vec3(size,size,0),
        Vec3(0,0,size), Vec3(size,0,size), Vec3(0,size,size), Vec3(size,size,size)
    ]
    return offsets[idx]

class DMCOctreeContour:
    def __init__(self, root_node, field, args):
        self.root = root_node
        self.field = field
        self.args = args
        self.mesh = Mesh()
        self.vertex_map = VertexMap()
        self.m_root_size = 1.0 # Placeholder for root size

    def extract(self):
        self.mesh.set_global_transform(self.root.global_transform)
        self.cell_proc(self.root)
        return self.mesh

    def cell_proc(self, node):
        if not node.is_subdivided():
            return
        sub = [node[i] for i in range(8)]
        for i in range(4):
            self.face_proc_x(sub[face_table_x[i][0]], sub[face_table_x[i][1]])
            self.face_proc_y(sub[face_table_y[i][0]], sub[face_table_y[i][1]])
            self.face_proc_z(sub[face_table_z[i][0]], sub[face_table_z[i][1]])
        for i in range(2):
            self.edge_proc_x(sub[edge_table_x[i][0]], sub[edge_table_x[i][1]], sub[edge_table_x[i][2]], sub[edge_table_x[i][3]])
            self.edge_proc_y(sub[edge_table_y[i][0]], sub[edge_table_y[i][1]], sub[edge_table_y[i][2]], sub[edge_table_y[i][3]])
            self.edge_proc_z(sub[edge_table_z[i][0]], sub[edge_table_z[i][1]], sub[edge_table_z[i][2]], sub[edge_table_z[i][3]])
        self.vert_proc(sub)

    def face_proc_x(self, parent, node_a, node_b):
        sub_table = []
        has_lesser = False
        for i in range(8):
            if parent.is_subdivided():
                sub_table.append(parent[i])
                has_lesser = True
            else:
                sub_table.append(parent)
        if not has_lesser:
            return
        for i in range(4):
            self.face_proc_x(sub_table[face_table_x[i][0]], sub_table[face_table_x[i][1]])
        for i in range(2):
            self.edge_proc_y(sub_table[edge_table_y[i][0]], sub_table[edge_table_y[i][1]], sub_table[edge_table_y[i][2]], sub_table[edge_table_y[i][3]])
        for i in range(2):
            self.edge_proc_z(sub_table[edge_table_z[i][0]], sub_table[edge_table_z[i][1]], sub_table[edge_table_z[i][2]], sub_table[edge_table_z[i][3]])
        self.vert_proc(sub_table)

    def face_proc_y(self, parent, node_a, node_b):
        sub_table = []
        has_lesser = False
        for i in range(8):
            if parent.is_subdivided():
                sub_table.append(parent[i])
                has_lesser = True
            else:
                sub_table.append(parent)
        if not has_lesser:
            return
        for i in range(4):
            self.face_proc_y(sub_table[face_table_y[i][0]], sub_table[face_table_y[i][1]])
        for i in range(2):
            self.edge_proc_x(sub_table[edge_table_x[i][0]], sub_table[edge_table_x[i][1]], sub_table[edge_table_x[i][2]], sub_table[edge_table_x[i][3]])
        for i in range(2):
            self.edge_proc_z(sub_table[edge_table_z[i][0]], sub_table[edge_table_z[i][1]], sub_table[edge_table_z[i][2]], sub_table[edge_table_z[i][3]])
        self.vert_proc(sub_table)

    def face_proc_z(self, parent, node_a, node_b):
        sub_table = []
        has_lesser = False
        for i in range(8):
            if parent.is_subdivided():
                sub_table.append(parent[i])
                has_lesser = True
            else:
                sub_table.append(parent)
        if not has_lesser:
            return
        for i in range(4):
            self.face_proc_z(sub_table[face_table_z[i][0]], sub_table[face_table_z[i][1]])
        for i in range(2):
            self.edge_proc_x(sub_table[edge_table_x[i][0]], sub_table[edge_table_x[i][1]], sub_table[edge_table_x[i][2]], sub_table[edge_table_x[i][3]])
        for i in range(2):
            self.edge_proc_y(sub_table[edge_table_y[i][0]], sub_table[edge_table_y[i][1]], sub_table[edge_table_y[i][2]], sub_table[edge_table_y[i][3]])
        self.vert_proc(sub_table)

    def build_node(self, node, size, min_corner):
        if size == 1:
            self.generate_dual_vertex(node, min_corner, size)
            return
        if self.args.use_early_split_stop and self.should_stop_splitting(node, min_corner, size):
            self.generate_dual_vertex(node, min_corner, size)
            return
        if self.args.use_simple_split_policy:
            if size == self.m_root_size or self.should_split(node, min_corner, size):
                child_size = size / 2.0
                for i in range(8):
                    child_min = min_corner + get_child_offset(i, child_size)
                    self.build_node(node[i], child_size, child_min)
            else:
                self.generate_dual_vertex(node, min_corner, size)
        else:
            if size * 8 < self.m_root_size and self.generate_dual_vertex(node, min_corner, size):
                return
            child_size = size / 2.0
            for i in range(8):
                child_min = min_corner + get_child_offset(i, child_size)
                self.build_node(node[i], child_size, child_min)

    def generate_dual_vertex(self, node, min_corner, size):
        solver = QefSolver4D()
        avg_normal = Vec3(0, 0, 0)
        if self.args.use_random_sampling:
            points_cnt = int(6.0 * math.sqrt(size))
            for _ in range(points_cnt):
                offset = self.args.rng.uniform(0, size)
                local_pos = min_corner + Vec3(offset, offset, offset)
                global_pos = self.transform(local_pos)
                val = self.field.get_value(global_pos)
                grad = self.field.get_gradient(global_pos)
                k = grad.length()
                if k > 0:
                    normal_4d = Vec4(grad.x, grad.y, grad.z, -1.0)
                    point_4d = Vec4(local_pos.x, local_pos.y, local_pos.z, val)
                    solver.add_plane(normal_4d, point_4d)
                    avg_normal = avg_normal + grad
        else:
            min_offset = 0.25 * size
            max_offset = size - min_offset
            offsets = [
                Vec3(min_offset, min_offset, min_offset), Vec3(max_offset, min_offset, min_offset),
                Vec3(min_offset, max_offset, min_offset), Vec3(max_offset, max_offset, min_offset),
                Vec3(min_offset, min_offset, max_offset), Vec3(max_offset, min_offset, max_offset),
                Vec3(min_offset, max_offset, max_offset), Vec3(max_offset, max_offset, max_offset)
            ]
            for off in offsets:
                local_pos = min_corner + off
                global_pos = self.transform(local_pos)
                val = self.field.get_value(global_pos)
                grad = self.field.get_gradient(global_pos)
                k = grad.length()
                if k > 0:
                    normal_4d = Vec4(grad.x, grad.y, grad.z, -1.0)
                    point_4d = Vec4(local_pos.x, local_pos.y, local_pos.z, val)
                    solver.add_plane(normal_4d, point_4d)
                    avg_normal = avg_normal + grad
        avg_normal = avg_normal.normalize()
        node.normal = avg_normal
        lower_bound = Vec4(min_corner.x, min_corner.y, min_corner.z, 0)
        upper_bound = Vec4(min_corner.x + size, min_corner.y + size, min_corner.z + size, 0)
        vertex = solver.solve(lower_bound, upper_bound)
        error = self.evaluate_error(vertex, min_corner, size)
        if error > self.args.epsilon:
            lower_bound = Vec4(-float('inf'), -float('inf'), -float('inf'), 0)
            upper_bound = Vec4(float('inf'), float('inf'), float('inf'), 0)
            vertex = solver.solve(lower_bound, upper_bound)
        node.dual_vertex = vertex
        if vertex.w <= 0:
            global_val = self.field.get_value(self.transform(Vec3(vertex.x, vertex.y, vertex.z)))
            node.material = self.compute_material(global_val)
        return error <= self.args.epsilon

    def should_split(self, node, min_corner, size):
        corners = [min_corner + get_child_offset(i, size) for i in range(8)]
        corner_vals = [self.field.get_value(self.transform(c)) for c in corners]
        error = 0.0
        # Edge midpoints: indices for edge endpoints and face centers are implementation-specific lookup tables [S1, unofficial].
        for dim in range(3):
            for edge in range(4):
                p1_idx, p2_idx = self.get_edge_endpoints(dim, edge)
                mid_pos = (corners[p1_idx] + corners[p2_idx]) / 2.0
                predicted_val = (corner_vals[p1_idx] + corner_vals[p2_idx]) / 2.0
                actual_val = self.field.get_value(self.transform(mid_pos))
                grad = self.field.get_gradient(self.transform(mid_pos))
                k = grad.length()
                if k > 0:
                    error += abs(predicted_val - actual_val) / k
                if error > self.args.epsilon:
                    return True
        for dim in range(3):
            for face in range(2):
                face_indices = self.get_face_indices(dim, face)
                mid_pos = sum([corners[i] for i in face_indices], Vec3(0,0,0)) / 4.0
                predicted_val = sum([corner_vals[i] for i in face_indices]) / 4.0
                actual_val = self.field.get_value(self.transform(mid_pos))
                grad = self.field.get_gradient(self.transform(mid_pos))
                k = grad.length()
                if k > 0:
                    error += abs(predicted_val - actual_val) / k
                if error > self.args.epsilon:
                    return True
        center_pos = sum([corners[i] for i in range(8)], Vec3(0,0,0)) / 8.0
        predicted_val = sum(corner_vals) / 8.0
        actual_val = self.field.get_value(self.transform(center_pos))
        grad = self.field.get_gradient(self.transform(center_pos))
        k = grad.length()
        if k > 0:
            error += abs(predicted_val - actual_val) / k
        return error > self.args.epsilon

    def should_stop_splitting(self, node, min_corner, size):
        side = size
        diagonal = side * math.sqrt(3)
        corners = [min_corner + get_child_offset(i, size) for i in range(8)]
        for c in corners:
            global_pos = self.transform(c)
            val = self.field.get_value(global_pos)
            if abs(val) <= diagonal:
                return False
        return True
```

**Parameters**
*   `epsilon`: The error threshold for dual vertex generation and splitting decisions [S1, unofficial].
*   `use_early_split_stop`: Boolean flag to enable early stopping of subdivision based on field value magnitude relative to cell diagonal [S1, unofficial].
*   `use_simple_split_policy`: Boolean flag to enable simple splitting policy based on root size or `should_split` result [S1, unofficial].
*   `use_random_sampling`: Boolean flag to enable random sampling for dual vertex generation instead of fixed corner sampling [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Precision**: The QEF solver uses 4D planes. If the gradient magnitude `k` is zero, the plane addition is skipped to avoid division by zero in error calculation [S1, unofficial].
*   **Boundaries**: If the initial QEF solve fails (error > epsilon), bounds are relaxed to infinity to ensure a solution is found, potentially at the cost of accuracy [S1, unofficial].
*   **Degenerate Input**: If `size` is 1, a dual vertex is generated immediately without sampling, which may lead to artifacts if the field is not well-behaved at the smallest scale [S1, unofficial].

## Subtopics

### [MDC Octree Isosurface Extraction](3676-mdc-octree-isosurface-extraction.md)
MDC (Multi-Dimensional Cell) Octree Isosurface Extraction is an adaptive surface reconstruction algorithm that uses an octree data structure to recursively subdivide a 3D volume and generate a triangle mesh. It solves the problem of extracting isosurfaces from volumetric data with varying density, handling topology via vertex clustering and collapse logic to ensure manifold connectivity. It sets itself apart from its sibling [DMC Octree Contour Extraction](3661-dmc-octree-contour-extraction.md) by explicitly managing vertex clustering across shared edges and faces to resolve topological ambiguities in complex subdivisions, whereas DMC relies on a different contour extraction logic.
