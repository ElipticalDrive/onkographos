# Marching Cubes with Octree

## Overview
Marching Cubes with Octree extracts a triangle mesh from an implicit scalar field defined over an adaptive octree structure, replacing the uniform Cartesian grid of standard Marching Cubes [S1]. It sets itself apart from its siblings by relying on a generic domain interface (`MC_Domain`) that decouples the traversal logic from the specific octree implementation, allowing for arbitrary split predicates and parallel execution via `CGAL::Parallel_if_available_tag` [S1]. Unlike uniform grid methods, it adapts resolution to the field's complexity, but it lacks inherent guarantees against topological cracks if the octree depth varies discontinuously around the isosurface [S1].

## How it works
The method operates by constructing an octree based on a split predicate, defining a domain that links the octree to a scalar function, and invoking the marching cubes algorithm which traverses the octree to generate triangles [S1].

**Inputs:**
*   `bbox`: A 3D bounding box defined by minimum and maximum coordinates $(x_{min}, y_{min}, z_{min})$ and $(x_{max}, y_{max}, z_{max})$ [S1].
*   `split_predicate`: A function or object that determines whether an octree node should be subdivided, typically based on the scalar field's variation or gradient [S1].
*   `scalar_function`: A function $f: \mathbb{R}^3 \rightarrow \mathbb{R}$ that evaluates the implicit field at any point [S1].
*   `isovalue`: The scalar threshold $I$ at which the isosurface is extracted [S1].

**Outputs:**
*   `points`: A container of 3D vertices forming the mesh [S1].
*   `triangles`: A container of triangle indices referencing the vertices [S1].

**Data Structures:**
1.  **Octree**: A hierarchical spatial partitioning structure where each node represents a cubic volume [S1]. The root covers the `bbox` and nodes are refined recursively if `split_predicate` returns true [S1].
2.  **Values**: An object holding the `scalar_function` and a reference to the `octree` [S1]. It provides the interface for the domain to query field values at specific locations, leveraging the octree's hierarchy for efficient evaluation [S1].
3.  **MC_Domain**: An abstraction layer that implements the interface expected by the marching cubes algorithm [S1]. It maps the algorithm's requests for cell vertices and edge intersections to the underlying octree structure and scalar function [S1].

**Algorithm Steps:**

1.  **Initialize Bounding Box**: Define the root cube of the octree using the input `bbox` points [S1].
2.  **Construct Octree**: Create an `Octree` object initialized with the bounding box points [S1].
3.  **Refine Octree**: Call `octree.refine(split_predicate)` to recursively subdivide nodes based on the scalar field's behavior within the node [S1].
4.  **Create Values Object**: Instantiate a `Values` object containing the `scalar_function` and the constructed `octree` [S1].
5.  **Initialize Output Containers**: Create empty containers `Point_range points` and `Polygon_range triangles` to store the resulting vertices and triangles [S1].
6.  **Construct Domain**: Instantiate an `MC_Domain` object, passing the `octree` and `values` objects to bind the geometric structure and scalar field to the marching cubes interface [S1].
7.  **Execute Marching Cubes**: Call `CGAL::Isosurfacing::marching_cubes` with the `MC_Domain`, `isovalue`, and output ranges, using `Parallel_if_available_tag` to enable parallel processing if supported [S1].

def marching_cubes_octree(bbox, split_predicate, scalar_function, isovalue):
    # 1. Define bounding box points
    bbox_points = [
        Point(bbox.xmin, bbox.ymin, bbox.zmin),
        Point(bbox.xmax, bbox.ymax, bbox.zmax)
    ]
    
    # 2. Construct Octree
    octree = Octree(bbox_points)
    
    # 3. Refine the octree using the split predicate
    octree.refine(split_predicate)
    
    # 4. Initialize output containers
    points = []
    triangles = []
    
    # 5. Traverse leaf nodes and apply Marching Cubes logic
    for leaf in octree.leaves():
        # Evaluate scalar field at 8 vertices of the leaf cube
        vals = [scalar_function(leaf.vertex(i)) for i in range(8)]
        
        # Determine cube case by comparing signs with isovalue
        case = 0
        for i in range(8):
            if vals[i] >= isovalue:
                case |= (1 << i)
        
        # Skip empty or full cases
        if case == 0 or case == 255:
            continue
            
        # Compute edge intersections where signs differ
        edges = []
        for e in range(12):
            v1, v2 = leaf.edge_vertices(e)
            val1, val2 = vals[leaf.edge_vertex_indices(e)]
            if (val1 - isovalue) * (val2 - isovalue) < 0:
                t = (isovalue - val1) / (val2 - val1)
                p = v1 + t * (v2 - v1)
                edges.append(p)
            else:
                edges.append(None)
                
        # Map case to triangle configuration (standard MC table)
        tri_indices = TRIMESH[case]
        for i in range(0, len(tri_indices), 3):
            idx1, idx2, idx3 = tri_indices[i], tri_indices[i+1], tri_indices[i+2]
            if idx1 != -1 and idx2 != -1 and idx3 != -1:
                triangles.append((edges[idx1], edges[idx2], edges[idx3]))
                
    return points, triangles
