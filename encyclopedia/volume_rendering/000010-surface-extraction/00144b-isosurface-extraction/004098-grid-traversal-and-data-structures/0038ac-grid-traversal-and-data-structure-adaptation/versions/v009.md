# Grid Traversal and Data Structure Adaptation
## Overview
This family covers methods that extract manifold isosurfaces from sparse, adaptive, or hierarchical scalar fields by adapting the data structure and traversal logic to avoid processing empty regions [G]. It sets itself apart from sibling methods by its specific approach to handling topology and connectivity across adapted grids to ensure crack-free surfaces [G].
## Shared principles
All methods in this family extract a manifold isosurface from a scalar field without processing the entire volume [G]. They share the following mechanisms:
1. **Selective Traversal/Processing:** The algorithm identifies a subset of "active" elements (voxels, nodes, or faces) that intersect the isosurface or contain significant field variation, rather than iterating over a dense grid [G].
2. **Local Marching Cubes Application:** For each active element, the standard Marching Cubes (MC) algorithm is applied locally [G]. This involves evaluating or retrieving scalar values at the 8 corners of a voxel/cube, computing a cube index $C = \sum_{j=0}^{7} \text{bit}_j \cdot 2^j$ where $\text{bit}_j = 1$ if $v_j < \text{iso}$ else $0$, interpolating vertex positions on intersecting edges, and generating triangles based on the MC lookup table for index $C$ [G].
3. **Global Mesh Assembly:** Local triangles and vertices are merged into a global mesh [G]. Consistency at shared boundaries (corners, edges, faces) is critical to ensure a watertight surface, often requiring averaging corner values or using specific stitching techniques [G].
## Subtopics

### [Marching Cubes with Octree](1259-marching-cubes-with-octree.md)
Extracts a manifold isosurface by applying standard MC selectively over an octree refined by a split predicate. It sets itself apart by using hierarchical decomposition and relying on CGAL `MC_Domain` for automatic mesh assembly. Choose it when processing large volumes efficiently by skipping empty regions, provided uniform depth around the isosurface is maintained to avoid cracks.

### [Sparse Marching Cubes](3825-sparse-marching-cubes.md)
Extracts the zero-level set from signed distance values at the eight corners of surface-intersecting active voxels to produce a watertight surface. It sets itself apart by operating on an explicitly defined set of voxel coordinates and their corner values, avoiding dense grid memory overhead. Choose it when working with sparse voxel lists rather than hierarchical trees.

### [Hierarchical Marching Cubes Enumeration](5223-hierarchical-marching-cubes-enumeration.md)
Recursively traverses an octree to extract manifold isosurface meshes by enumerating voxel faces, edges, and vertices, delegating to standard MC only at leaf nodes. It sets itself apart by explicitly separating traversal logic into specialized functions for faces, edges, and vertices to ensure consistent mesh connectivity across varying tree depths. Choose it when handling mismatched tree depths or complex hierarchical structures.

### [2D Stitching](10249-2d-stitching.md)
Index-based tessellation scheme that fills topological gaps between dual grids of different AMR levels using "stitch cells," allowing seamless merging without subdividing boundary elements. It sets itself apart by avoiding quadrilateral subdivision, which is non-unique and causes cracks in 3D extraction. Choose it when working with AMR data to connect coarse and fine grids.
