# 3D AMR Grid Stitching

Also called: 3D AMR Grid Connection, 3D Stitching, Stitch Cell Generation, Stitching 3D Grids

## Overview
3D AMR Grid Stitching is a method for generating crack-free isosurfaces from Adaptive Mesh Refinement (AMR) data by filling topological gaps between different refinement levels. It generalizes the 2D index-based stitching approach to three dimensions, connecting the vertices, edges, and quadrilaterals of fine grids to the coarse grid structure [S1]. Unlike methods that require subdividing boundary elements or re-sampling data, this technique constructs intermediate "stitch cells" (pyramids, deformed prisms, and hexahedra) to ensure seamless topology [S1]. It builds on [2D Stitching](10249-2d-stitching.md) by extending the connection logic to 3D volumes and handling the increased complexity of vertex and edge interactions in three-dimensional space [S1].

## How it works
The method operates on an AMR hierarchy where fine grids are embedded within coarse grids. The core task is to generate a set of unstructured geometry cells that bridge the gap between the fine grid surface and the coarse grid surface, ensuring that the resulting mesh is watertight and suitable for isosurface extraction (e.g., via Marching Cubes) [S1, S2].

### Inputs and Outputs
*   **Input:** An AMR hierarchy consisting of coarse grids and embedded fine grids. The input includes the geometric positions of the grid vertices and the refinement relationships (which fine cells lie within which coarse cells).
*   **Output:** A set of "stitch cells" that connect the fine grid boundaries to the coarse grid boundaries. These cells are typically tetrahedra, pyramids, triangular prisms, or deformed hexahedra [S1].

### Data Structures
The method relies on identifying the topological relationship between fine and coarse elements.
*   **Fine Grid Elements:** Vertices ($V_f$), Edges ($E_f$), and Quadrilaterals ($Q_f$).
*   **Coarse Grid Elements:** Vertices ($V_c$), Edges ($E_c$), and Quadrilaterals ($Q_c$).
*   **Stitch Cells:** The output geometry is defined by the vertices of the fine and coarse grids. No new intermediate vertices are created; the stitch cells are formed directly from existing grid points [S1].

### Algorithm Steps

1.  **Identify Boundary Elements:** For each fine grid embedded in a coarse grid, identify the fine grid elements that lie on the boundary of the fine grid region (i.e., those not fully contained within another finer grid). These are the fine quadrilaterals ($Q_f$), edges ($E_f$), and vertices ($V_f$) that need to be connected to the coarse grid [S1].

2.  **Process Fine Quadrilaterals ($Q_f$):**
    For each fine quadrilateral $Q_f$ embedded in the coarse grid:
    *   Determine the connection type in two orthogonal directions implied by the quadrilateral's geometry.
    *   In each direction, decide whether the connection is to a coarse vertex ($V_c$) or a coarse edge ($E_c$).
    *   Based on the combination of connections in the two directions, generate one of the following stitch cells [S1]:
        *   **Pyramid:** If $Q_f$ connects to a single coarse vertex $V_c$ in both directions (or effectively reduces to a point connection). The base of the pyramid is $Q_f$, and the apex is $V_c$. This results in a hexahedral cell if the coarse point is refined, but the stitch cell itself is a pyramid connecting the fine quad to the coarse vertex [S1].
        *   **Deformed Triangle Prism:** If $Q_f$ connects to a coarse edge $E_c$ in one direction and a vertex or edge in the other. The prism connects the fine quadrilateral to the coarse line segment [S1].
        *   **Deformed Hexahedral Cell:** If $Q_f$ connects to another coarse quadrilateral $Q_c$. This forms a volume between the fine quad and the coarse quad [S1].

3.  **Process Fine Edges ($E_f$):**
    For each fine edge $E_f$ on the boundary:
    *   View the edge as appearing as a point in the direction parallel to the edge.
    *   Connect the edge to two perpendicular coarse edges ($E_{c1}, E_{c2}$) or two coarse quadrilaterals ($Q_{c1}, Q_{c2}$).
    *   **Case 1:** If connected to two perpendicular coarse edges, generate **two tetrahedra**.
    *   **Case 2:** If connected to two coarse quadrilaterals, generate **two deformed triangle prisms** [S1].

4.  **Process Fine Vertices ($V_f$):**
    For each fine vertex $V_f$ on the boundary:
    *   Connect the vertex to three coarse quadrilaterals ($Q_{c1}, Q_{c2}, Q_{c3}$) that meet at the corresponding coarse vertex location.
    *   Generate **pyramid cells** for each connection, where the base is the coarse quadrilateral and the apex is the fine vertex [S1].

5.  **Handle Multiple Fine Grids Refining One Coarse Grid:**
    When multiple fine grids refine the same coarse grid region, check each coarse-grid point for refinement status.
    *   **Edge Promotion:** An edge might be "upgraded" to a quadrilateral case if adjacent edges are refined. For a hexahedral cell, this occurs if grid points 2 and 3 or grid points 4 and 5 (in a local canonical numbering) are refined [S1].
    *   **Vertex Promotion:** A fine vertex can be promoted to an edge if any of the coarse grid points 3, 5, or 6 (in a local canonical numbering) is refined. It can be promoted to a quadrilateral if more than two grids meet at the location [S1].

6.  **Tessellate Deformed Hexahedral Cells:**
    For cases where fine elements connect to coarse quadrilaterals, eight points are identified (4 from the fine quad, 4 from the coarse quad), forming a deformed hexahedral cell.
    *   Each face of this hexahedron corresponds to a 2D refinement configuration (as defined in [2D Stitching](10249-2d-stitching.md)).
    *   Determine the tessellation of the hexahedron by subdividing its faces using the canonical tessellations from the 2D case.
    *   This face subdivision implies a volumetric tessellation of the hexahedron into pyramids, triangular prisms, and tetrahedra.
    *   **Pyramid Case:** If a refined coarse point is replaced by a fine quadrilateral, the result is a hexahedral cell.
    *   **Triangular Prism Case:** If refined coarse points are replaced by fine edges. If both coarse points of a triangular prism are refined, the resulting hexahedral cell does not need further splitting [S1].

### Parameters and Edge Cases
*   **Refinement Ratios:** The method works with commonly used refinement ratios. General refinement ratios do not add more refinement configurations because the fundamental connection strategies remain the same [S1].
*   **Non-planar Boundaries:** 2D refinement configurations that produce subdivided quadrilaterals also yield non-planar cell boundaries. The method handles this by subdividing the faces of the deformed hexahedron using canonical tessellations, which implies the volumetric tessellation [S1].
*   **Viewing Direction:** The edge case logic assumes a viewing direction parallel to the edge. If the viewing direction changes, the topological connection might need to be re-evaluated, but the stitch cells are generated based on the grid topology, not the view [S1].
*   **Precision:** The method relies on exact topological connections. Degenerate inputs (e.g., zero-length edges) should be handled by the grid generation phase before stitching [G].

## Subtopics

### Stitching cells algorithm
An algorithm that utilizes stitching cells to construct an unstructured geometry across AMR levels to fill gaps between hierarchy levels. It is used when re-sampling or using redundant coarse data is not feasible or desired. It effectively eliminates cracks that appear in standard isosurface extraction from AMR data [S2].

## Operating characteristics
*   **Time Complexity:** The complexity is linear with respect to the number of boundary elements between refinement levels. The number of stitch cells generated is proportional to the surface area of the fine grids embedded in the coarse grid.
*   **Memory Complexity:** The memory usage is proportional to the number of stitch cells generated. Each stitch cell stores references to the vertices of the fine and coarse grids.
*   **Performance:** On a standard PC with a 700MHz Pentium III processor, generating stitch cells for two levels of hierarchy (root and first level, both 32x32x32) took approximately 55ms. For three levels (adding a second level with 12 grids of varying dimensions), it took approximately 340ms. Isosurface extraction took approximately 250ms for two levels and 600ms for three levels [S1].
*   **Strengths:** Produces crack-free isosurfaces without subdividing boundary elements or re-sampling data. It preserves the original data values at the grid vertices.
*   **Limitations:** The method is specific to AMR hierarchies with regular refinement ratios. It may require significant preprocessing to identify boundary elements and determine connections. The generated unstructured geometry can be complex, potentially impacting rendering performance if not optimized [S1, S2].
*   **When to use:** Use when crack-free visualization of AMR data is required and the AMR hierarchy has regular refinement ratios. It is suitable for offline visualization or when the overhead of stitch cell generation is acceptable.
*   **When not to use:** Avoid if the AMR hierarchy has irregular refinement ratios or if real-time performance is critical and the overhead of stitch cell generation is too high. Alternative methods like re-sampling or using redundant coarse data may be more suitable in those cases [S1, S2].

## Background
The method was introduced in the paper "Extraction of Crack-free Isosurfaces from Adaptive Mesh Refinement Data" by Greg Bryan, Anthony Yeung, and Michael L. Steinman, published in the Proceedings of the VisSymposium 2001 [S1]. It generalizes the 2D stitching approach to 3D, addressing the challenge of gaps between hierarchy levels in AMR data. The method has been used in scientific visualization applications, particularly in cosmology and fluid dynamics, where AMR data is common [S1]. The data set used in the original paper was courtesy of Greg Bryan from the Massachusetts Institute of Technology, Theoretical Cosmology Group [S1].
