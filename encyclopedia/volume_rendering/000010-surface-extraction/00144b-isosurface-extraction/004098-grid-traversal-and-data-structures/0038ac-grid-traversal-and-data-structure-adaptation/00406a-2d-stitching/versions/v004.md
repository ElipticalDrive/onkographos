# 2D Stitching
Also called: Stitching 2D Grids

## Overview
2D Stitching is an index-based tessellation scheme that fills topological gaps between dual grids of different Adaptive Mesh Refinement (AMR) levels using "stitch cells," allowing seamless merging of levels without subdividing boundary elements [S1]. It is distinguished from constrained Delaunay triangulation by avoiding the subdivision of quadrilateral boundary faces, which is non-unique and causes cracks in 3D Marching Cubes extraction [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Two adjacent 2D AMR grids: a coarse grid $\Lambda_{coarse}$ and a fine grid $\Lambda_{fine}$ with refinement ratio $r$. The grids are represented by their dual grid vertices and edges.
*   **Output:** A set of "stitch cells" (triangles and deformed quadrilaterals) that connect the boundary of the fine grid to the coarse grid, forming a watertight mesh interface.

**Data Structures:**
The method operates on the dual grid representation.
*   **Vertices:** Defined by their grid coordinates $(i, j)$.
*   **Edges:** Defined by pairs of vertices.
*   **Stitch Cells:** Geometric primitives (triangles, quads) defined by the vertices they connect. No new vertices are generated; only existing vertices from the coarse and fine grids are used [S1].

**Steps:**
1.  **Identify Boundary:** Determine the edges and vertices of the fine grid that lie on the boundary with the coarse grid.
2.  **Generate Edge Stitch Cells:** For each boundary edge of the fine grid, generate stitch cells connecting it to the coarse grid based on the refinement ratio $r$ and the refinement status of the coarse grid points.
3.  **Generate Vertex Stitch Cells:** For each boundary vertex of the fine grid, generate stitch cells connecting it to the coarse grid.
4.  **Assemble Mesh:** Combine the original dual grid elements and the generated stitch cells into a single mesh.

**Formulas and Logic:**

**Refinement Ratio:**
Let $r$ be the integer refinement ratio ($r \ge 2$). $r$ fine grid cells fit into one coarse grid cell [S1].

**Edge Connections (General $r$):**
For a boundary edge of the fine grid, the connection to the coarse grid depends on $r$:
*   Connect $(r-1)$ consecutive fine edge segments to one common coarse-grid point.
*   Connect every $r$-th fine edge to a coarse edge [S1].

**Edge Connections ($r=2$ Specifics):**
For $r=2$, each fine edge is connected alternatingly to either a vertex or an edge of the coarse grid [S1]. The specific topology depends on whether the coarse grid points adjacent to the connection are refined:
*   **Case 1: Coarse point is not refined.** Connect the fine edge to the coarse point/edge directly. This yields triangles and deformed quadrilaterals [S1].
*   **Case 2: Coarse point is refined.**
    *   If a fine edge connects to a refined coarse point, connect it to another fine edge to form a rectilinear cell (quadrilateral) [S1].
    *   If both endpoints of a coarse edge are refined, connect the fine edge to another fine edge [S1].
    *   If only one endpoint of a coarse edge is refined, treat it as an edge case using the same tessellation as other edge cases (consistent with the unrefined case logic but accounting for the refined neighbor) [S1].

**Vertex Connections:**
For a boundary vertex $v$ of the fine grid:
*   Connect the vertex to the coarse grid via two triangles.
*   Connect each edge of the vertex to the two coarse edges that are "visible" from it [S1].
*   **Refinement Check:** If either of the adjacent coarse grid points is refined, "promote" the border vertex to a border-edge segment by connecting it to the other refined grid point. Treat this segment as an edge and use the edge connection configurations (Case 1 or 2 above) [S1].

**Parameters:**
*   **Refinement ratio $r$:** An integer specifying how many fine grid cells fit into a coarse grid cell. Typical values are 2 and 4 [S1].

**Edge Cases and Pitfalls:**
*   **Quadrilateral Subdivision:** Quadrilaterals formed by stitching must not be subdivided. Subdivision is not unique and causes cracks in 3D [S1].
*   **Mixed Refinement:** Cases where only one endpoint of a coarse edge is refined must be handled consistently with other edge cases to avoid topological errors [S1].

## Subtopics

### [3D AMR Grid Stitching](10250-3d-amr-grid-stitching.md)
Generalizes the 2D index-based stitching to 3D volumes by constructing intermediate "stitch cells" (pyramids, deformed prisms, hexahedra) to connect fine grid vertices/edges to the coarse grid. It handles the increased complexity of 3D vertex and edge interactions.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of boundary elements between the coarse and fine grids. The index-based approach is efficient as it avoids global optimization or Delaunay triangulation [S1].
*   **Memory Complexity:** Proportional to the number of stitch cells generated. No new vertices are stored, only references to existing ones [S1].
*   **Strengths:** Ensures crack-free isosurfaces in 3D by avoiding non-unique quadrilateral subdivision. Efficient due to regular structure exploitation.
*   **Limitations:** Requires dual grid representation. Limited to integer refinement ratios.
*   **When to use:** When extracting isosurfaces from AMR data where crack-free connectivity between different refinement levels is critical.
*   **When not to use:** When the grid structure is not hierarchical AMR or when non-integer refinement ratios are required.

## Background
The method was introduced in the context of extracting crack-free isosurfaces from Adaptive Mesh Refinement (AMR) data [S1]. It addresses the problem of gaps between dual grids of different AMR levels that lead to discontinuities in the extracted isosurface. The approach was chosen over constrained Delaunay triangulation because the latter requires subdividing quadrilateral boundary faces, which is problematic for 3D Marching Cubes extraction [S1].
