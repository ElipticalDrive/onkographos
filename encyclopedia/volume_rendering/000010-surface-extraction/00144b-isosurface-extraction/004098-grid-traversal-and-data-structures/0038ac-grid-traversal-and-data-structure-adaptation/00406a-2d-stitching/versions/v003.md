# 2D Stitching
Also called: Stitching 2D Grids

## Overview
2D Stitching is an index-based tessellation scheme that fills topological gaps between dual grids of different Adaptive Mesh Refinement (AMR) levels using "stitch cells," merging levels seamlessly without subdividing boundary elements [S1]. It sets itself apart from constrained Delaunay triangulation by avoiding the subdivision of quadrilateral boundary faces, which is non-unique and causes cracks in 3D isosurface extraction [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Two adjacent 2D AMR grids: a coarse grid $\Lambda_l$ and a fine grid $\Lambda_{l+1}$ with refinement ratio $r$. The grids are represented by their dual grid vertices and edges.
*   **Output:** A set of "stitch cells" (triangles and deformed quadrilaterals) that connect the boundary of the fine grid to the coarse grid, forming a continuous mesh.

**Data Structures:**
The method operates on the indices of the dual grid vertices. No new vertices are generated; only existing vertices from the coarse and fine grids are used [S1].

**Parameters:**
*   $r$: Refinement ratio, an integer specifying how many fine grid cells fit into a coarse grid cell. Typical values are 2 and 4 [S1].

**Steps:**
1.  **Identify Boundary:** Determine the edges and vertices of the fine grid that lie on the boundary with the coarse grid.
2.  **Check Refinement Status:** For each coarse grid point (vertex) adjacent to the fine grid boundary, determine if it is refined by another fine grid. This determines whether the connection is to a coarse vertex or a fine vertex [S1].
3.  **Generate Edge Stitch Cells:** For each fine grid edge $e$ on the boundary:
    *   If $r=2$: Connect the fine edge alternatingly to either a vertex or an edge of the coarse grid [S1].
    *   If $r>2$: Connect $(r-1)$ consecutive fine edge segments to one common coarse-grid point. Every $r$-th fine edge is connected to a coarse edge [S1].
    *   **Refinement Check:**
        *   If the coarse point being connected to is **not refined**: Create triangles or deformed quadrilaterals connecting the fine edge to the coarse edge/vertex [S1].
        *   If the coarse point **is refined**: The fine edge must be connected to another fine edge to form a rectilinear cell (quadrilateral) [S1].
        *   **Edge Cases (One Endpoint Refined):** If only one endpoint of a coarse edge is refined, apply the same tessellation logic as other edge cases (connecting to the nearest fine grid point) [S1].
4.  **Generate Vertex Stitch Cells:** For each fine grid vertex $v$ on the boundary:
    *   Connect the vertex to the coarse grid via two triangles.
    *   Connect each edge of the fine vertex to the two coarse edges that are "visible" from it [S1].
    *   **Refinement Check:** If a coarse grid point is refined, promote the border vertex to a border-edge segment by connecting it to the other refined grid point, then treat it as an edge case using the logic from Step 3 [S1].

**Edge Cases and Pitfalls:**
*   **Quadrilateral Subdivision:** Quadrilaterals formed by stitching must not be subdivided. Subdivision is not unique and causes cracks in 3D isosurface extraction [S1].
*   **Mixed Refinement:** Cases where only one endpoint of a coarse edge is refined must be handled consistently with other edge cases to avoid topological errors [S1].
*   **Vertex Promotion:** When a coarse vertex is refined, it must be promoted to an edge segment to maintain consistent tessellation logic [S1].

## Subtopics

### [3D AMR Grid Stitching](10250-3d-amr-grid-stitching.md)
Generalizes the 2D index-based stitching to 3D volumes, using stitch cells (pyramids, deformed prisms, hexahedra) to connect fine grids to coarse grids. It handles the increased complexity of vertex and edge interactions in 3D space.

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Index-based approach is efficient as it exploits the regular structure of AMR boundaries. It avoids the insertion of new vertices, which is crucial for dual-grid isosurface extraction [S1].
*   **Limitations:** Limited to 2D grids in this specific method. Requires careful handling of refinement status checks for coarse grid points [S1].
*   **When to Use:** When extracting crack-free isosurfaces from 2D AMR data using dual grids.
*   **When Not to Use:** When 3D stitching is required (use 3D AMR Grid Stitching) or when constrained Delaunay triangulation is acceptable and cracks are not a concern (though Delaunay is less efficient for this specific regular structure) [S1].

## Background
The method was introduced in the paper "Extraction of Crack-free Isosurfaces from Adaptive Mesh Refinement Data" [S1]. It addresses the problem of cracks in extracted isosurfaces caused by gaps between AMR grids. The authors chose an index-based approach over constrained Delaunay triangulation because Delaunay requires subdividing quadrilateral boundary faces, which causes cracks in MC-based isosurface extraction [S1].
