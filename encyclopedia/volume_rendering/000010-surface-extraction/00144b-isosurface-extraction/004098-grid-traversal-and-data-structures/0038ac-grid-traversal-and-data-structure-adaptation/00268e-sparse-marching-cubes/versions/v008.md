# Sparse Marching Cubes

Also called: Sparse Marching Cubes from Points

## Overview
Sparse Marching Cubes generates a triangle mesh from a sparse set of 3D points with associated scalar values (e.g., Signed Distance Fields), avoiding the memory overhead of dense 3D grids [S1, unofficial]. It differs from standard Marching Cubes by dynamically gathering corner values for active voxels via lookup, rather than iterating over a fixed dense volume [S1, unofficial].

## How it works
**Inputs:**
1. `coords`: Integer tensor of shape $[N, 3]$ containing the $(x, y, z)$ coordinates of active voxels [S1, unofficial].
2. `corners` OR `point_values`:
   * Option A: `corners` Float tensor of shape $[N, 8]$ containing pre-computed scalar values at the 8 corners of each voxel [S1, unofficial].
   * Option B: `point_values` Float tensor of shape $[N]$ or $[N, 1]$ containing scalar values at the coordinates in `coords` [S1, unofficial].
3. `iso`: Float value representing the iso-level to contour at [S1, unofficial].
4. `default_value`: Float value assumed for corner points not present in the input `coords` (used only in Option B). The sources specify a default of $1.0$ [S1, unofficial].
5. `ensure_consistency`: Boolean flag; if `True`, averages corner values at shared locations to ensure topological consistency [S1, unofficial].

**Outputs:**
1. `verts`: Float tensor of shape $[V, 3]$ with vertex positions [S1, unofficial].
2. `tris` (or `faces`): Int tensor of shape $[T, 3]$ with triangle indices [S1, unofficial].

**Algorithm:**
1. **Voxel Identification**: Identify the set of active voxels from the provided `coords` tensor [S1, unofficial].
2. **Corner Value Gathering**: For each active voxel, determine the scalar values at its 8 corners [S1, unofficial]. If `corners` are provided, use them directly [S1, unofficial]. If `point_values` are provided, look up the scalar value for each of the 8 corner coordinates in the input set [S1, unofficial]. If a corner coordinate is not in the input set, assign `default_value` [S1, unofficial].
3. **Consistency Check (Optional)**: If `ensure_consistency` is `True`, identify shared corners between adjacent active voxels [S1, unofficial]. Average the scalar values at these shared locations to ensure that neighboring voxels agree on the field value at the shared vertex [S1, unofficial].
4. **Case Index Calculation**: For each voxel, compute the marching cubes case index (0-255) based on the 8 corner values relative to `iso` [S1, unofficial]. Let $v_i$ be the scalar value at corner $i$ ($i=0..7$).
   $$ b_i = \begin{cases} 1 & \text{if } v_i < iso \\ 0 & \text{otherwise} \end{cases} $$
   $$ \text{index} = \sum_{i=0}^{7} b_i 2^i $$
   [S1, unofficial]
5. **Mesh Generation**: For each voxel, use the standard Marching Cubes lookup table to generate triangles based on the `index` [S1, unofficial]. Vertices are interpolated along edges where the sign changes (or crosses `iso`) [G]. Adjacent voxels share edge vertices, which are merged by coordinate to form a coherent mesh [G].

**Pseudocode (Python-like):**
```python
def sparse_marching_cubes(coords, corners, iso, ensure_consistency=False):
    # coords: list of [x, y, z] integer tuples, length N
    # corners: list of lists of 8 floats, length N
    # iso: float
    # ensure_consistency: bool
    # Returns: verts (list of [x, y, z] floats), tris (list of [i, j, k] ints)
    
    if ensure_consistency:
        corner_values = {}
        for i in range(len(coords)):
            cx, cy, cz = coords[i]
            for j in range(8):
                dx, dy, dz = (j >> 0) & 1, (j >> 1) & 1, (j >> 2) & 1
                key = (cx + dx, cy + dy, cz + dz)
                if key not in corner_values:
                    corner_values[key] = []
                corner_values[key].append(corners[i][j])
        avg_values = {k: sum(v) / len(v) for k, v in corner_values.items()}
        for i in range(len(coords)):
            cx, cy, cz = coords[i]
            for j in range(8):
                dx, dy, dz = (j >> 0) & 1, (j >> 1) & 1, (j >> 2) & 1
                key = (cx + dx, cy + dy, cz + dz)
                corners[i][j] = avg_values[key]

    indices = []
    for i in range(len(coords)):
        idx = 0
        for j in range(8):
            if corners[i][j] < iso:
                idx |= (1 << j)
        indices.append(idx)

    # Standard Marching Cubes edge table (12 edges) and case table (256 cases) [G]
    EDGE_VERTS = [
        (0,1), (1,2), (2,3), (3,0), (4,5), (5,6), (6,7), (7,4),
        (0,4), (1,5), (2,6), (3,7)
    ]
    # CASE_TABLE maps index 0-255 to list of triangle vertex indices (3 ints per triangle) [G]
    
    verts = []
    tris = []
    for i in range(len(coords)):
        idx = indices[i]
        cx, cy, cz = coords[i]
        edge_verts = []
        for e_idx, (v0, v1) in enumerate(EDGE_VERTS):
            if (idx >> e_idx) & 1:
                v0_val = corners[i][v0]
                v1_val = corners[i][v1]
                t = (iso - v0_val) / (v1_val - v0_val)
                x = (cx + (v0 & 1)) + t * ((v1 & 1) - (v0 & 1))
                y = (cy + ((v0 >> 1) & 1)) + t * (((v1 >> 1) & 1) - ((v0 >> 1) & 1))
                z = (cz + ((v0 >> 2) & 1)) + t * (((v1 >> 2) & 1) - ((v0 >> 2) & 1))
                edge_verts.append((x, y, z))
        for tri in CASE_TABLE.get(idx, []):
            tris.append(tuple(edge_verts[v] for v in tri))
            
    return verts, tris

def sparse_marching_cubes_from_points(coords, point_values, iso, default_value=1.0):
    lookup = {coords[i]: point_values[i] for i in range(len(coords))}
    N = len(coords)
    corners = []
    for i in range(N):
        cx, cy, cz = coords[i]
        voxel_corners = []
        for j in range(8):
            dx, dy, dz = (j >> 0) & 1, (j >> 1) & 1, (j >> 2) & 1
            key = (cx + dx, cy + dy, cz + dz)
            voxel_corners.append(lookup.get(key, default_value))
        corners.append(voxel_corners)
    return sparse_marching_cubes(coords, corners, iso, ensure_consistency=False)
```

## Subtopics

### Sparse Marching Cubes from SRF
Extracts 3D meshes from Sparse Radiance Fields (SRF) by performing one pass of Marching Cubes on the 3D voxel space, as models like SPARF and SuRFNet operate within this space [S2].

## Operating characteristics
* **Time Complexity**: Linear with respect to the number of active voxels $N$, assuming constant-time lookup for corner values [G].
* **Memory Complexity**: Proportional to the number of active voxels and their corners, significantly less than dense grid methods which scale with the volume resolution $R^3$ [G].
* **Performance**: Accelerated via CUDA, processing thousands of voxels simultaneously [S1, unofficial].
* **Strengths**: Ideal for sparse SDF representations where only a list of points and values are available; avoids dense grid memory overhead [S1, unofficial].

## Background
Sparse Marching Cubes is implemented in libraries such as `spcumc` (Sparse Marching Cubes) to handle sparse voxel data efficiently on GPUs [S1, unofficial]. It is used in contexts involving sparse SDFs and is applicable to extracting meshes from Sparse Radiance Fields (SRF) like those generated by SPARF and SuRFNet [S2].
