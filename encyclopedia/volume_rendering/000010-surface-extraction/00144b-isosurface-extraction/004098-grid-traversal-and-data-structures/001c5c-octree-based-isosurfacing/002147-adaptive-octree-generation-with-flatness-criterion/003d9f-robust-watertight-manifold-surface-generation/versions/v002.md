# Robust Watertight Manifold Surface Generation

Also called: Octree-based manifold generation, ShapeNet manifold pipeline

## Overview
This method converts an input triangle mesh into a watertight 2-manifold surface with roughly uniformly distributed vertices using an octree-based signed distance field representation and isosurface extraction [S1, unofficial]. It differs from uniform grid marching cubes by adaptively refining only the volume near the surface, reducing storage and computation linearly with the final mesh size [S1, unofficial]. Unlike sibling methods that fit explicit surface primitives or use complex occlusion handling, this pipeline guarantees topological correctness for tested ShapeNet models by defining "positive" space via boundary-connected BFS and resolving non-manifold ambiguities through vertex/edge splitting [S1, unofficial].

## How it works
**Inputs:** A triangle mesh $M$ with vertices and faces [S1, unofficial].
**Outputs:** A watertight 2-manifold triangle mesh with vertices projected onto the original geometry [S1, unofficial].

**Data Structures:**
*   **Octree Node:**
    *   `bbox`: Axis-aligned bounding box (min/max coordinates).
    *   `triangles`: List of triangles from $M$ contained in or intersecting `bbox`.
    *   `status`: Enum {"Empty", "Occupied"}.
    *   `children`: Array of 8 child nodes (only present if `status` is "Occupied" and resolution < target).
    *   `volume_type`: Enum {"Positive", "Negative", None} for classification.
*   **Connection Map:** Implicitly built during traversal; stores adjacency between neighboring nodes (empty or occupied) to facilitate face extraction [S1, unofficial].

**Parameters:**
*   **Target Resolution:** Unit cube length $L = 0.01$ in the normalized space, ensuring the output mesh has $>10,000$ triangles [S1, unofficial].
*   **Root Bounding Box:** Extends from $-1.1$ to $1.1$ in each dimension to fully contain the normalized mesh (range $-1$ to $1$) [S1, unofficial].

**Steps:**

1.  **Normalization:** Translate and uniformly scale $M$ so its geometric center is at the origin and its bounding box dimensions range from $-1$ to $1$ [S1, unofficial].
2.  **Octree Construction:** Initialize root node with `bbox` $[-1.1, 1.1]^3$ and `triangles` = all triangles in $M$ [S1, unofficial]. Recursively subdivide any node with `status` = "Occupied" and `bbox` side length $> 0.01$ into 8 children, reassigning intersecting triangles to each child [S1, unofficial]. If a child has no triangles, set `status` = "Empty"; otherwise "Occupied" [S1, unofficial]. Do not subdivide empty nodes [S1, unofficial].
3.  **Connection Building:** Recursively traverse the octree to build adjacency information between neighboring nodes [S1, unofficial]. For each node, process its 8 children, then for each of the 12 pairs of neighboring children (corresponding to the 12 edges of a cube), call `ConnectNodes` [S1, unofficial]. In `ConnectNodes(Nl, Nr)`, if both are "Empty", return [S1, unofficial]. If `Nl` is "Empty", set `SubNl` = $\{Nl, Nl, Nl, Nl\}$; else `SubNl` = `Nl.children` $\{s_1, s_2, s_3, s_4\}$ (the 4 children adjacent to the interface) [S1, unofficial]. If `Nr` is "Empty", set `SubNr` = $\{Nr, Nr, Nr, Nr\}$; else `SubNr` = `Nr.children` $\{s_5, s_6, s_7, s_8\}$ (the 4 children adjacent to the interface) [S1, unofficial]. Recursively call `ConnectNodes(SubNl[i], SubNr[i])` for $i=1 \dots 4$ [S1, unofficial].
4.  **Volume Classification:** Define "positive" cubes as those having a path to the boundary not occupied by any triangle [S1, unofficial]. Initialize all boundary cubes as "Positive" and apply BFS to expand "Positive" cubes [S1, unofficial]. All remaining non-occupied cubes are "Negative" [S1, unofficial].
5.  **Isosurface Extraction:** Extract the isosurface as faces between "Positive" cubes and "Occupied" cubes by recursively visiting all occupied nodes and their neighbors to detect occupied-"Positive" connections [S1, unofficial].
6.  **Non-Manifold Resolution:** Resolve ambiguities where two cubes meet at a single vertex or share an edge connecting 4 faces by splitting the vertex into three or the edge into two, assuming volumes are always connected [S1, unofficial].
7.  **Vertex Projection:** Project extracted vertices onto the original mesh to achieve high precision by computing the nearest triangle to each vertex using the stored relation between occupied cubes and triangles [S1, unofficial]. Iteratively move vertices closer to their nearest triangles along the direction parallel to their normals with a fixed small step [S1, unofficial]. Apply Laplacian smoothing after each projection step to prevent face flips [S1, unofficial].

**Pseudocode:**

```python
class OctreeNode:
    def __init__(self):
        self.bbox = None
        self.triangles = []
        self.status = "Empty"
        self.children = [None] * 8
        self.volume_type = None

def BuildOctree(triangles, bbox):
    node = OctreeNode()
    node.bbox = bbox
    node.triangles = triangles
    if not triangles:
        node.status = "Empty"
        return node
    node.status = "Occupied"
    if bbox.side_length() <= 0.01:
        return node
    sub_bboxes = get_sub_bboxes(bbox)
    for i in range(8):
        sub_triangles = ContainedBy(triangles, sub_bboxes[i])
        node.children[i] = BuildOctree(sub_triangles, sub_bboxes[i])
    return node

def BuildConnection(node):
    if node.status == "Empty":
        return
    for child in node.children:
        if child:
            BuildConnection(child)
    neighbor_pairs = [
        (0,1), (2,3), (4,5), (6,7),
        (0,2), (1,3), (4,6), (5,7),
        (0,4), (1,5), (2,6), (3,7)
    ]
    for idx1, idx2 in neighbor_pairs:
        ConnectNodes(node.children[idx1], node.children[idx2])

def ConnectNodes(Nl, Nr):
    if Nl.status == "Empty" and Nr.status == "Empty":
        return
    # s1..s4 and s5..s8 are the 4 children adjacent to the shared interface
    SubNl = [Nl, Nl, Nl, Nl] if Nl.status == "Empty" else [Nl.children[s1], Nl.children[s2], Nl.children[s3], Nl.children[s4]]
    SubNr = [Nr, Nr, Nr, Nr] if Nr.status == "Empty" else [Nr.children[s5], Nr.children[s6], Nr.children[s7], Nr.children[s8]]
    for i in range(4):
        ConnectNodes(SubNl[i], SubNr[i])

def ClassifyVolumes(root):
    queue = []
    for node in get_boundary_empty_nodes(root):
        node.volume_type = "Positive"
        queue.append(node)
    while queue:
        current = queue.pop(0)
        for neighbor in get_neighbors(current):
            if neighbor.volume_type is None and neighbor.status == "Empty":
                neighbor.volume_type = "Positive"
                queue.append(neighbor)
    for node in all_empty_nodes(root):
        if node.volume_type is None:
            node.volume_type = "Negative"

def ExtractSurface(root):
    faces = []
    for node in all_occupied_nodes(root):
        for neighbor in get_neighbors(node):
            if neighbor.volume_type == "Positive":
                faces.append(GenerateInterfaceFace(node, neighbor))
    return faces

def ProjectVertices(vertices, original_mesh):
    for vertex in vertices:
        nearest_tri = FindNearestTriangle(vertex, original_mesh)
        for _ in range(10):
            vertex = vertex + step_size * nearest_tri.normal
            ApplyLaplacianSmoothing(vertex, get_neighbors(vertex))
    return vertices
```

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of triangles in the final mesh, as the octree resolution is coarser in empty volumes [S1, unofficial].
*   **Memory Complexity:** Linear with respect to the final mesh size, significantly less than a uniform grid for large volumes with thin surfaces [S1, unofficial].
*   **Performance:** Guarantees correct 2-manifold topology for all tested ShapeNet models, though approximately 5% may contain face flips due to thin structures [S1, unofficial].
*   **Limitations:** Approximately 5% of models may contain face flips, primarily due to thin face structures in the original mesh [S1, unofficial].
*   **When to use:** When a watertight, manifold representation is required from a potentially non-manifold or noisy input mesh, and uniform grid storage is prohibitive [S1, unofficial].
*   **When not to use:** When high-frequency geometric details are lost due to the coarse resolution in empty space, or when the input mesh has extreme thin structures that cause projection failures [S1, unofficial].

## Background
The method was introduced in a paper focusing on processing ShapeNet models [S1, unofficial]. It builds on the concept of isosurface extraction (similar to Marching Cubes [Lorensen and Cline 1987]) but uses an octree to represent the signed distance field, inspired by Meagher's octree encoding [Meagher 1982]. The pipeline was designed to handle the variety of ShapeNet models, including those with holes and thin structures, ensuring topological correctness [S1, unofficial].
