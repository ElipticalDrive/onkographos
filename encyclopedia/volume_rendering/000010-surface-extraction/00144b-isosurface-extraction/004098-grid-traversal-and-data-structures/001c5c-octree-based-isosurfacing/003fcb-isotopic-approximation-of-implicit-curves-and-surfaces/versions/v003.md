# Isotopic Approximation of Implicit Curves and Surfaces

Also called: ApproximateCurve, Isotopic Approximation

## Overview
The Isotopic Approximation algorithm generates a piecewise linear approximation of an implicit curve in $\mathbb{R}^2$ or surface in $\mathbb{R}^3$ that is regularly isotopic to the original manifold [S1]. Unlike grid-based schemes that may miss critical details and fail to guarantee correct topology, this method uses interval arithmetic to adaptively subdivide space via a quadtree (curves) or octree (surfaces), ensuring every leaf cell is locally parametrizable [S1]. It is distinguished from sibling methods by its reliance on a simple interval test to guarantee isotopy without computing critical points, making it fast and suitable for visualization and time-dependent surface morphing [S1].

## How it works
### Inputs and Outputs
**Inputs:**
1. $F: \mathbb{R}^n \to \mathbb{R}$ ($n=2$ for curves, $n=3$ for surfaces): A smooth implicit function where $0$ is a regular value, meaning $\nabla F$ is non-zero at every point on $S = F^{-1}(0)$ [S1].
2. $B$: A bounding square (in $\mathbb{R}^2$) or cube (in $\mathbb{R}^3$) containing the implicit manifold $S$ [S1].

**Outputs:**
A piecewise linear approximation of $S$ consisting of line segments (curves) or triangles (surfaces) [S1].

### Data Structures
**Interval:** A pair of floats `[lo, hi]` representing a closed range with error bounds [S1].
**Point:** A tuple of $n$ floats representing coordinates in $\mathbb{R}^n$ [G].
**Cell:** A tree node containing:
- `bounds`: A tuple of $n$ `Interval` objects defining the spatial extent.
- `children`: A list of $2^n$ `Cell` objects, or `None` if leaf.
- `is_leaf`: Boolean flag.
- `level`: Integer depth of subdivision.

### Algorithm Steps
1. **Initialization**: Initialize a quadtree/octree $T$ with a root `Cell` representing the bounding box $B$ [S1].
2. **Adaptive Subdivision**: Recursively subdivide $T$ until all leaf cells $C$ satisfy the termination condition: $0 \notin \Box F(C) \lor \langle \Box \nabla F(C), \Box \nabla F(C) \rangle > 0$ [S1].
3. **Balancing**: Balance $T$ so that neighboring cells differ in size by at most a factor of two [S1].
4. **Vertex Placement**: For each edge of the tree structure, evaluate $F$ at its two endpoints [S1]. If the signs of $F$ at the endpoints are opposite, construct a vertex at the midpoint of the edge [S1].
5. **Mesh Construction**: For each leaf cell $C$, identify the vertices placed on its boundary [S1]. If the leaf contains exactly two vertices, connect them by a line segment [S1]. If it contains four vertices, find the two vertices on the same side and connect each of them to one of the other two vertices [S1].

### Formulas
- **Inclusion Function**: An inclusion function $\Box f$ satisfies $x \in I \implies f(x) \in \Box f(I)$ for any interval $I$ [S1].
- **Convergent Squaring**: For $f(x) = x^2$ on interval $[a, b]$, the convergent inclusion function is:
  $$\Box f([a,b]) = \begin{cases} [\min(a^2, b^2), \max(a^2, b^2)], & a \cdot b \geq 0 \\ [0, \max(a^2, b^2)], & a \cdot b < 0 \end{cases}$$ [S1]
- **Gradient Condition**: $\langle \Box \nabla F(C), \Box \nabla F(C) \rangle > 0$ implies at least one component squared interval (e.g., $F_x(C)^2$) does not contain $0$ [S1]. This means $F$ is strictly monotonic in that axis direction, making the cell locally parametrizable [S1].

class Interval:
    def __init__(self, lo, hi):
        self.lo = lo
        self.hi = hi

def interval_add(a, b): return Interval(a.lo + b.lo, a.hi + b.hi)
def interval_mul(a, b):
    p1 = a.lo * b.lo; p2 = a.lo * b.hi; p3 = a.hi * b.lo; p4 = a.hi * b.hi
    return Interval(min(p1, p2, p3, p4), max(p1, p2, p3, p4))
def interval_square(a):
    if a.lo * a.hi >= 0:
        return Interval(min(a.lo**2, a.hi**2), max(a.lo**2, a.hi**2))
    else:
        return Interval(0, max(a.lo**2, a.hi**2))

def interval_eval(func, bounds):
    # Standard corner-based inclusion function [G]
    corners = []
    for mask in range(1 << len(bounds)):
        pt = []
        for d, b in enumerate(bounds):
            pt.append(b.lo if (mask >> d) & 1 else b.hi)
        corners.append(tuple(pt))
    vals = [func(p) for p in corners]
    return Interval(min(vals), max(vals))

        self.bounds = bounds
        self.level = level
        self.children = None
        self.is_leaf = True

        child_bounds = []

            idx = (i >> d) & 1
            child_bounds.append(new_bounds[d * 2 + idx])
        children.append(Cell(bounds=tuple(child_bounds), level=cell.level + 1))

def collect_all_edges(cell, edges=None, parent=None):
    if edges is None: edges = []
    if cell.children is None: return edges
    dim = len(cell.bounds)
    for i in range(1 << dim):

def group_by_side(vertices, bounds):
    # Group vertices by which face/edge of the cell they lie on [G]
    sides = [[] for _ in range(2 * len(bounds))]
    for v in vertices:
        for d, b in enumerate(bounds):
            if abs(v[d] - b.lo) < 1e-9:
                sides[d].append(v)
            elif abs(v[d] - b.hi) < 1e-9:
                sides[d + len(bounds)].append(v)
    return [s for s in sides if s]

def isotopic_approximation(F, grad_F, B, max_depth=10):
    root = Cell(bounds=B, level=0)
    queue = [root]
    while queue:
        cell = queue.pop(0)
        if cell.level >= max_depth:
            cell.is_leaf = True
            continue
        F_val = interval_eval(F, cell.bounds)
        grad_vals = [interval_eval(g, cell.bounds) for g in grad_F]
        zero_not_in_F = F_val.lo > 0 or F_val.hi < 0
        grad_norm_sq = Interval(0, 0)
        for g in grad_vals:
            grad_norm_sq = interval_add(grad_norm_sq, interval_square(g))
        grad_positive = grad_norm_sq.lo > 0
        if zero_not_in_F or grad_positive:
            cell.is_leaf = True
        else:
            cell.is_leaf = False
            children = subdivide_cell(cell)
            cell.children = children
            queue.extend(children)
    balance_tree(root)
    edges = collect_all_edges(root)
    vertices = []
    for e in edges:
        v1, v2 = e[0], e[1]
        if (F(v1) <= 0 and F(v2) > 0) or (F(v1) > 0 and F(v2) <= 0):
            mid = tuple((a + b) / 2.0 for a, b in zip(v1, v2))
            vertices.append((mid, e))
    mesh = []
    for leaf in collect_leaves(root):
        leaf_edges = set()
        for child in leaf.children if leaf.children else []:
            leaf_edges.update(collect_all_edges(child))
        leaf_verts = [v for v, e in vertices if e in leaf_edges]
        if len(leaf_verts) == 2:
            mesh.append((leaf_verts[0], leaf_verts[1]))
        elif len(leaf_verts) == 4:
            sides = group_by_side(leaf_verts, leaf.bounds)
            side_with_two = [s for s in sides if len(s) == 2][0]
            others = [v for s in sides if len(s) == 1 for v in s]
            mesh.append((side_with_two[0], others[0]))
            mesh.append((side_with_two[1], others[1]))
    return mesh

def collect_leaves(cell):
    if cell.children is None: return [cell]
    leaves = []
    for child in cell.children:
        leaves.extend(collect_leaves(child))
    return leaves

### Parameters
- **Minimal Subdivision Level**: Can be defined to improve the Hausdorff distance between the surface and the approximation [S1].
- **Maximal Subdivision Level**: Can be used to improve the speed of the meshing process and to handle surfaces with singularities [S1].

### Edge Cases and Pitfalls
- **Singularities**: If $F$ has singularities (where $\nabla F = 0$), the condition $\langle \nabla F, \nabla F \rangle > 0$ may never be met, leading to infinite subdivision. A maximal subdivision level must be enforced, and color coding can identify regions where the approximation might be topologically incorrect [S1].
- **Boundary Conditions**: A single side of a cell may consist of two tree edges if the neighboring cell is subdivided. Each cell is therefore surrounded by four to eight tree edges [S1].
- **Precision**: Interval arithmetic must be used to prevent rounding errors that could incorrectly classify a cell as containing zero or not [S1].

## Subtopics

## Operating characteristics
- **Time Complexity**: The subdivision process terminates because cells shrink towards a point, and for a regular curve/surface, at least one of the two clauses ($0 \notin F(C)$ or $\langle \nabla F, \nabla F \rangle > 0$) converges to a non-zero value [S1]. The algorithm is fast because it uses a simple interval test and adds little overhead compared to other enumeration methods [S1].
- **Memory Complexity**: Proportional to the number of leaf nodes in the balanced quadtree/octree [G].
- **Strengths**: Guarantees correct topology (regular isotopy); does not require computing critical points; fast due to simple interval tests; flexible adaptive resolution [S1].
- **Limitations**: Requires $F$ to be smooth and $0$ to be a regular value (gradient non-zero on surface); singularities require special handling (max depth); interval arithmetic can be computationally expensive if not optimized [S1].
- **When to Use**: Visualization of implicit surfaces where piecewise linear approximations are required; constructing initial meshes for time-dependent surfaces (e.g., morphing) [S1].
- **When Not to Use**: When the implicit function has singularities and high precision is required without fallback strategies; when performance is critical and interval arithmetic overhead is prohibitive [S1].

## Background
The Isotopic Approximation algorithm was introduced as one of the first methods to guarantee isotopy for implicit surface meshing [S1]. It falls into the category of enumeration methods but distinguishes itself by using a fast and simple interval test to decide subdivision, avoiding the need to compute critical points of the implicit function [S1]. The method is based on a quadtree (for curves) or octree (for surfaces) and uses interval arithmetic to ensure that leaf cells are locally parametrizable [S1]. The approach was developed to address the limitations of grid-based schemes, which can miss important surface details and fail to guarantee correct topology [S1].
