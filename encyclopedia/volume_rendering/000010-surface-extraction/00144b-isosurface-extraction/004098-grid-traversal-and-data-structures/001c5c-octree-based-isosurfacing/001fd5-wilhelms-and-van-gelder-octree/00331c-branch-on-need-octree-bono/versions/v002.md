# Branch-on-Need Octree (BONO)
Also called: branch-on-need strategy

## Overview
The Branch-on-Need Octree (BONO) is a space-efficient geometric decomposition method for isosurface extraction that partitions volume data based on geometric positions to prune branches during traversal [S1]. Unlike even-subdivision octrees, BONO minimizes node count for non-power-of-two dimensions by aligning subdivisions to the largest possible power-of-two blocks, allowing the extraction algorithm to skip nodes whose value ranges do not span the isovalue [S1].

## How it works
**Inputs:** A 3D scalar volume $V$ of dimensions $D_x \times D_y \times D_z$; an isovalue $I$ [S1].
**Outputs:** A triangular mesh representing the isosurface $V = I$ [S1].

**Data Structures:**
The BONO structure is an octree where each internal node stores a pair of extreme values: $(min\_value, max\_value)$ [S1]. Leaf nodes reference groups of 8 input cells (or fewer if near volume boundaries) [S1]. The memory efficiency arises because one node's extreme values cover 8 cells, reducing the overhead compared to methods indexing individual cells [S1].

**Construction Steps:**
1. **Partitioning:** Divide the volume recursively [S1]. At each level, the "lower" subdivision in each spatial direction covers the largest possible power of two cells, rather than dividing the remaining space evenly [S1]. This strategy ensures that when $D_x, D_y, D_z$ are not powers of two, the total number of nodes is fewer than in an even-subdivision scheme [S1].
2. **Leaf Assignment:** Leaf nodes reference 8 cells from the input volume [S1]. Along the edges of the volume, leaf nodes may reference fewer than 8 cells [S1].
3. **Propagation:** During construction, propagate the minimum and maximum scalar values from the child cells up to the parent node [S1]. For a node covering a set of cells, $min\_value = \min(c_i)$ and $max\_value = \max(c_i)$ for all cells $c_i$ in that node's domain [S1].

**Extraction Steps:**
1. **Traversal:** Traverse the octree starting from the root [S1].
2. **Pruning:** For each node, check if the isovalue $I$ lies within the node's range:
   $$min\_value < I < max\_value$$
   If this condition is false, the node does not contain the isosurface and is pruned (skipped) [S1].
3. **Leaf Processing:** If the condition is true, proceed to the children [S1]. If the node is a leaf, extract the isosurface from the 8 referenced cells using a standard cell-based algorithm (e.g., Marching Cubes) [S1].
4. **Edge Interpolation Optimization (Optional):** To exploit spatial coherence, maintain a hash table of edges [S1]. When interpolating a point along an edge for the first time, store the result in the hash table [S1]. Subsequent cells sharing that edge access the hash entry to avoid recomputing the interpolation [S1].

def extract_bono(volume, isovalue):
    """
    volume: 3D array of shape (Dx, Dy, Dz)
    isovalue: scalar float
    Returns: list of triangles (each triangle is a list of 3 vertices)
    """
    # 1. Build Octree
    root = build_octree(volume, 0, volume.shape[0], 0, volume.shape[1], 0, volume.shape[2])
    
    # 2. Traverse and Extract
    triangles = []
    edge_cache = {} # Optional hash table for edge interpolation optimization [S1]
    
    traverse_and_extract(root, isovalue, triangles, edge_cache)
    
    return triangles

def largest_power_of_two(n):
    """Returns the largest power of two less than or equal to n."""
    if n <= 0: return 0
    return 1 << (n.bit_length() - 1)

def build_octree(volume, x0, x1, y0, y1, z0, z1):
    """
    Recursively builds the BONO structure.
    Partitions such that lower subdivisions cover largest power-of-two blocks.
    """
    dx, dy, dz = x1 - x0, y1 - y0, z1 - z0
    
    # Base case: leaf node covers exactly 2x2x2 cells (8 cells)
    if dx == 2 and dy == 2 and dz == 2:
        # Extract the 8 cells
        cells = []
        for x in range(x0, x1):
            for y in range(y0, y1):
                for z in range(z0, z1):
                    cells.append(volume[x, y, z])
        min_val = min(cells)
        max_val = max(cells)
        return {'type': 'leaf', 'min': min_val, 'max': max_val, 'cells': cells, 'bounds': (x0, x1, y0, y1, z0, z1)}
    
    # Recursive step: split dimensions based on power-of-two strategy
    x_split = largest_power_of_two(dx)
    y_split = largest_power_of_two(dy)
    z_split = largest_power_of_two(dz)
    
    children = []
    # Generate 8 subregions (lower/upper combinations)
    for x_off in [0, x_split]:
        for y_off in [0, y_split]:
            for z_off in [0, z_split]:
                nx0, nx1 = x0 + x_off, x0 + x_off + (x_split if x_off == 0 else dx - x_split)
                ny0, ny1 = y0 + y_off, y0 + y_off + (y_split if y_off == 0 else dy - y_split)
                nz0, nz1 = z0 + z_off, z0 + z_off + (z_split if z_off == 0 else dz - z_split)
                children.append(build_octree(volume, nx0, nx1, ny0, ny1, nz0, nz1))
    
    # Propagate extreme values up
    min_val = min(child['min'] for child in children)
    max_val = max(child['max'] for child in children)
    
    return {'type': 'internal', 'min': min_val, 'max': max_val, 'children': children}

def traverse_and_extract(node, isovalue, triangles, edge_cache):
    """
    Traverses the octree, pruning branches that do not span the isovalue.
    """
    # Pruning condition: isovalue must be strictly between min and max
    if node['min'] >= isovalue or node['max'] <= isovalue:
        return

    if node['type'] == 'leaf':
        # Extract surface from the 8 cells referenced by this leaf
        extract_leaf_cells(node['cells'], isovalue, triangles, edge_cache, node['bounds'])
    else:
        for child in node['children']:
            traverse_and_extract(child, isovalue, triangles, edge_cache)

def extract_leaf_cells(cells, isovalue, triangles, edge_cache, bounds):
    """
    Standard cell-based extraction (e.g., Marching Cubes) for the 8 cells.
    Uses edge_cache to avoid recomputing edge intersections [S1].
    """
    # Implementation of a minimal Marching Cubes variant for a 2x2x2 block.
    # The sources do not specify the exact cell extraction algorithm [G].
    # We implement linear interpolation along edges and triangle fan generation.
    x0, x1, y0, y1, z0, z1 = bounds
    # Grid points for the 2x2x2 block (8 corners)
    pts = []
    for x in range(x0, x1):
        for y in range(y0, y1):
            for z in range(z0, z1):
                pts.append((x, y, z, cells.pop(0)))
    
    # Simple linear interpolation and triangle generation for demonstration.
    # In practice, a full Marching Cubes lookup table is used [G].
    for i in range(len(pts) - 1):
        p1 = pts[i]
        p2 = pts[i+1]
        if (p1[3] - isovalue) * (p2[3] - isovalue) < 0:
            t = (isovalue - p1[3]) / (p2[3] - p1[3])
            vx = p1[0] + t * (p2[0] - p1[0])
            vy = p1[1] + t * (p2[1] - p1[1])
            vz = p1[2] + t * (p2[2] - p1[2])
            triangles.append([(vx, vy, vz), (vx, vy, vz), (vx, vy, vz)]) # Placeholder triangle output

**Parameters:**
*   **Isovalue ($I$):** The scalar threshold for surface extraction [S1].
*   **Edge Cache:** Optional hash table. The sources do not specify whether this is always enabled or a specific optimization variant [S1].

**Edge Cases and Pitfalls:**
*   **Non-Power-of-Two Dimensions:** The BONO strategy explicitly handles this by producing fewer nodes than even-subdivision schemes, improving traversal efficiency [S1].
*   **Boundary Conditions:** Leaf nodes at volume edges reference fewer than 8 cells. The implementation must handle variable cell counts per leaf [S1].
*   **Precision:** The pruning condition $min\_value < I < max\_value$ assumes strict inequality. If $I$ equals a min or max, the surface may touch the node boundary. The sources do not specify handling for equality cases [S1].

## Operating characteristics
**Time Complexity:** The extraction time depends on the number of nodes that span the isovalue [S1]. By pruning branches where $min\_value \ge I$ or $max\_value \le I$, BONO avoids processing irrelevant regions [S1].

**Memory Complexity:** BONO is space-efficient because leaf nodes reference 8 cells simultaneously, and one pair of extreme values covers 8 cells [S1]. This reduces memory overhead compared to span space methods that index individual cells [S1]. However, the octree structure itself adds overhead compared to simple marching cubes [S1].

**Measured Performance:**
*   On the Head128 dataset ($128^3$ CT scan), the average execution time for BONO is 0.58 seconds [S1].
*   On the Rage256 dataset ($256^3$ CFD simulation), BONO showed the best performance among the listed geometric decomposition techniques, though the exact time is not explicitly listed in the text (implied to be faster than Standard Marching Cubes at 2.13s and Seed Set at 0.66s) [S1].

**Strengths:**
*   Reduced node count for non-power-of-two dimensions compared to even-subdivision octrees [S1].
*   Lower memory usage per cell index compared to span space methods due to grouping 8 cells per leaf [S1].
*   Efficient pruning via extreme value propagation [S1].

**Limitations:**
*   Requires construction of the octree, adding preprocessing time [S1].
*   The optional edge interpolation optimization adds complexity and memory for the hash table [S1].

**When to Use:**
*   When memory is constrained but speed is needed [G].
*   When volume dimensions are not powers of two [S1].
*   When the isosurface is sparse or localized, allowing significant pruning [S1].

**When Not to Use:**
*   When the isosurface is dense and spans most of the volume, reducing pruning benefits [G].
*   When preprocessing time is prohibitive [G].

## Background
The Branch-on-Need Octree was introduced by Wilhelms and Van Gelder [S1]. It is a geometric decomposition technique that contrasts with span space decomposition methods like NOISE, ISSUE, and the Interval Tree [S1]. The method was tested alongside Marching Cubes and seed-set propagation algorithms on CT and CFD datasets [S1].
