# Simplified Marching Cubes

Also called: SMC discretization, binarized Marching Cubes

## Overview
Simplified Marching Cubes (SMC) is a surface extraction method that generates isosurfaces using only the vertices of the underlying voxel grid, eliminating the need for linear interpolation and large lookup tables [S1]. It produces meshes with approximately half the vertices and triangles of standard Marching Cubes (MC) and Cuberille, significantly reducing memory usage while maintaining manifold topology [S1]. Unlike standard MC, which interpolates intersection points, SMC relies on integer arithmetic and a deterministic analysis of node counts and cumulative coordinates to classify configurations [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar field $F(x, y, z)$ defined on a regular 3D grid (cuberille grid) and a threshold value $\lambda$.
*   **Output:** A triangular mesh consisting of vertices located at grid coordinates and indices defining the triangles.

**Data Structures:**
*   **Vertex:** Stored as 3 short integers (2 bytes each), representing integer coordinates $(x, y, z)$ where coordinates are $< 65535$ [S1].
*   **Triangle:** Stored as 3 long integers (4 bytes each), representing indices into the vertex array [S1].
*   **Cube Configuration:** For each cube, the algorithm determines the binary status of its 8 vertices. The vertex index $n$ ($0 \dots 7$) relates to normalized coordinates $c_x^n \in \{0, 1\}$ via:
    $$c_i^n = n \% 2, \quad c_j^n = (n \% 4) / 2, \quad c_k^n = n / 4$$
    where $x \in \{i, j, k\}$ represents the three axes [S1].

**Core Logic:**
The algorithm binarizes the input field:
$$F_B = \begin{cases} 1 & \text{if } F(x, y, z) \geq \lambda \\ 0 & \text{else} \end{cases}$$
Positive vertices (value $\geq \lambda$) are called "nodes". Negative vertices are "non-nodes" [S1]. The algorithm iterates over every cube in the grid. For each cube, it identifies the set of nodes and computes specific metrics to determine the triangle configuration without using a lookup table [S1].

**Key Formulas:**
1.  **Cumulative Coordinate ($C_x$):** The sum of the coordinates of all nodes along axis $x$.
    $$C_x = \sum_{n \in \{\text{nodes}\}} c_x^n$$
    This value helps identify subcases (e.g., nodes lying on a specific face) [S1].
2.  **Neighbor Count ($N_x(n)$):** The number of node neighbors for vertex $n$ along axis $x$ in 6-connectivity.
    $$N_i(n) = \overline{c_i^n} + 2 \times c_j^n + 4 \times c_k^n$$
    where $\overline{c}$ is the complement to 1 of $c$ (i.e., $1-c$). An interface node is a node with fewer than 3 node neighbors in 6-connectivity [S1].
3.  **Triangle Classification Criterion ($C_L$):** Used to distinguish triangle types based on vertex coordinates.
    $$C_L(n_1, n_2, n_3) = \sum_{l=1}^3 \sum_{m=l+1}^3 \left( \sum_{x=i,j,k} (c_x^{n_i} - c_x^{n_m})^2 \right)^2$$
    *   Type I (isosceles-right): $C_L = 6$
    *   Type II (right): $C_L = 14$
    *   Type III (equilateral): $C_L = 12$ [S1]

**Numbered Steps:**
For each cube:
1.  Identify all positive vertices (nodes). Let $N_{nodes}$ be the count.
2.  If $N_{nodes} \in \{0, 1, 2, 8\}$, output no triangles.
3.  If $N_{nodes} = 3$:
    *   If $C_x = 0$ or $3$ for any axis $x \in \{i, j, k\}$, output one Type I triangle (nodes lie on a single face).
    *   Otherwise, no triangle is output (this corresponds to ambiguous or non-surface configurations in the reduced set, though the source implies specific handling for cases 5,6,7; specifically, only the face-aligned case yields a triangle in the simplified description, while others are handled by the "switch status" logic or yield no triangles in the strict SMC patch interpretation). *Note: The source states "Only the first subcase leads to one triangle... It corresponds to three nodes on a cube face". 4.  If $N_{nodes} = 4$:
    *   **Case 8:** If $C_x = 0$ or $4$ for any axis $x$, output two Type I triangles on that face.
    *   **Cases 10/13:** If $C_x = 2$ for all axes $x$, output no triangles.
    *   **Case 9:** Identify the single non-interface node (via exhaustive test of neighbor counts). Output one Type III triangle formed by the remaining three interface nodes.
    *   **Case 12:** Identify the singular node with only negative neighbors. Switch its status to positive (temporarily), re-process as 3 nodes (Case 8 logic) to build one Type I triangle, then revert status.
    *   **Cases 11/14:** Output two Type II triangles. Identify by nested loops over the 4 nodes.
5.  If $N_{nodes} = 5$:
    *   **Case 17:** If $C_x = 1$ or $4$ for any axis $x$, output two Type II triangles (identified by nested loops).
    *   **Case 15:** Identify singular node with only negative neighbors. Switch status, re-process as 3 nodes (Case 9 logic) to build one Type III triangle.
    *   **Case 16:** Identify Type III triangle via nested loops. Find the negative vertex with node neighbors, switch its status, re-process as 6 nodes (Case 20 logic) to build remaining triangles (two Type II, one Type III).
6.  If $N_{nodes} = 6$:
    *   **Cases 18/19:** Identify two negative vertices that have only node neighbors (exhaustive test). Build two Type III triangles formed by their respective neighbors.
    *   **Case 20:** Output two Type II triangles formed by correctly ordered interface nodes.
7.  If $N_{nodes} = 7$:
    *   Identify the single negative vertex. Form one Type III triangle using its three neighbors (which are interface nodes).

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of voxels, as each cube is processed once. SMC is faster than standard MC, with speedup increasing as the internal surface area increases [S1].
*   **Memory Complexity:** Vertex memory is 6 bytes per vertex (3 shorts). Triangle memory is 12 bytes per triangle (3 longs). Total memory is approximately half that of standard MC (which uses 12 bytes per vertex for floats) and Cuberille [S1].
*   **Accuracy:** SMC accuracy is lower than standard MC but higher than Cuberille. For a discretized sphere, SMC surface error converges to 7%, while MC converges to ~0.4% [S1]. Normal RMS error is ~10-12 degrees for SMC, compared to ~4-6 degrees for MC on smooth images [S1].
*   **Bias:** SMC systematically produces negative volume biases for convex objects (negative surface bias) and positive surface bias for concave objects. The volume bias is larger than in MC or Cuberille [S1].
*   **Strengths:** No interpolation, integer arithmetic, guaranteed manifold meshes, lower memory, faster for large images with high surface area [S1].
*   **Limitations:** Lower geometric accuracy than MC, fixed vertex positions (no smooth approximation) [S1].

## Background
Simplified Marching Cubes was developed for materials science simulations, specifically for modeling matrix deposition in Chemical Vapor Infiltration (CVI) and ablation in carbon/carbon composites [S1]. It was introduced to provide an efficient discretization scheme that guarantees manifold meshes and allows for integer arithmetic, facilitating large-scale simulations of diffusion-reaction processes in evolving porous media [S1]. The method is based on the "MC-patch" logic to resolve ambiguities in standard MC configurations [S1].
