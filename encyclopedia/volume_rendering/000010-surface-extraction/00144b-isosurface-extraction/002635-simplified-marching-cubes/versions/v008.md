# Simplified Marching Cubes

Also called: SMC discretization, binarized Marching Cubes

## Overview
Simplified Marching Cubes (SMC) is a surface extraction method that produces meshes using only vertices from the regular 3D grid, eliminating interpolation and lookup tables [S1]. It generates approximately half the vertices and triangles of standard Marching Cubes (MC) and Cuberille, reducing memory usage by 50% while maintaining intermediate accuracy [S1]. Unlike MC, SMC guarantees manifold meshes without holes by treating symmetric configurations identically and using integer arithmetic exclusively [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar field $F(x, y, z)$ and a threshold $\lambda$.
*   **Output:** A mesh consisting of triangles with vertices at integer grid coordinates.

**Data Structures:**
*   **Vertex:** 3 `short` (2-byte) integers representing integer coordinates $(x, y, z)$. Coordinates must be $< 65535$ [S1].
*   **Triangle:** 3 `long` (4-byte) integers representing indices into the vertex array [S1].
*   **Cube State:** For each cube, the algorithm determines the triangle configuration based on the binary status of its 8 vertices. No global lookup table is stored; configurations are computed on-the-fly or via a small local table [S1].

**Vertex Status and Coordinates:**
Vertices are classified as **nodes** (positive, $F \ge \lambda$) or **negative** (fluid, $F < \lambda$) [S1].
For a cube, vertices $n \in \{0, \dots, 7\}$ have normalized coordinates $c_x^n \in \{0, 1\}$ for axes $x \in \{i, j, k\}$:
$$ c_i^n = n \% 2 $$
$$ c_j^n = (n \% 4) / 2 $$
$$ c_k^n = n / 4 $$
[S1]

**Cumulative Coordinates:**
The sum of coordinates of all nodes along axis $x$:
$$ C_x = \sum_{n \in \{\text{nodes}\}} c_x^n $$
[S1]

**Neighbor Count:**
The number of node neighbors of vertex $n$ along axis $x$ in 6-connectivity:
$$ N_x(n) = \overline{c_x^n} + 2 c_y^n + 4 c_z^n $$
where $\overline{c}$ is the bitwise NOT of $c$ (complement to 1), and $y, z$ are the other two axes. An **interface node** is a node with fewer than 3 node neighbors [S1].

**Triangle Types and Classification:**
SMC produces three triangle types based on edge lengths and areas [S1]:
1.  **Type I:** Isosceles-right triangle.
2.  **Type II:** Right triangle.
3.  **Type III:** Equilateral triangle.

To distinguish types without floating-point geometry, use the integer criterion $C_L$:
$$ C_L(n_1, n_2, n_3) = \sum_{l=1}^3 \sum_{m=l+1}^3 \left( \sum_{x=i,j,k} (c_x^{n_l} - c_x^{n_m})^2 \right)^2 $$
*   $C_L = 6 \implies$ Type I
*   $C_L = 14 \implies$ Type II
*   $C_L = 12 \implies$ Type III
[S1]

**Algorithm Steps:**
For each cube in the volume:
1.  **Binarize:** Determine the status of each of the 8 vertices relative to $\lambda$.
2.  **Count Nodes:** Let $N$ be the number of nodes in the cube.
3.  **Handle Trivial Cases:** If $N \in \{0, 1, 2, 8\}$, output no triangles.
4.  **Identify Subcases:** Use $N$ and $C_x$ to identify the specific topological case.
5.  **Generate Triangles:** Apply the rules below.

**Case Rules:**

*   **3 Nodes ($N=3$):**

def get_interface_nodes(nodes, cube_vertices, threshold):
    # A node is interface if it has at least one negative neighbor
    interface = []
    for n in nodes:
        if has_negative_neighbor(n, cube_vertices, threshold):
            interface.append(n)
    return interface

def count_node_neighbors(vertex_idx, node_list):
    # Count how many neighbors of vertex_idx are in node_list
    count = 0
    for axis in ['i', 'j', 'k']:
        # Get neighbor index
        neighbor = get_neighbor(vertex_idx, axis)
        if neighbor in node_list:
            count += 1
    return count

def get_neighbors(vertex_idx, node_list):
    # Return neighbors that are in node_list
    neighbors = []
    for axis in ['i', 'j', 'k']:
        neighbor = get_neighbor(vertex_idx, axis)
        if neighbor in node_list:
            neighbors.append(neighbor)
    return neighbors

def get_neighbor(vertex_idx, axis):
    # Get neighbor along axis
    # i: change bit 0
    # j: change bit 1
    # k: change bit 2
    if axis == 'i':
        return vertex_idx ^ 1
    elif axis == 'j':
        return vertex_idx ^ 2
    elif axis == 'k':
        return vertex_idx ^ 4

def compute_CL(triangle_nodes):
    # triangle_nodes: tuple of 3 indices
    c = [(n % 2, (n % 4) // 2, n // 4) for n in triangle_nodes]
    total = 0
    for l in range(3):
        for m in range(l + 1, 3):
            dist_sq = sum((c[l][x] - c[m][x])**2 for x in range(3))
            total += dist_sq**2
    return total

## Operating characteristics
*   **Time Complexity:** Faster than standard MC. Speedup increases as internal surface area increases [S1].
*   **Memory Complexity:** Half of MC and Cuberille. Vertices use 6 bytes (3 shorts), triangles use 12 bytes (3 longs) [S1].
*   **Accuracy:** Lower than MC but higher than Cuberille. Surface area errors are intermediate. For a discretized sphere, SMC surface error converges to 7%, while MC converges to ~0.4% [S1]. Normal RMS error is ~10-12 degrees for SMC vs ~4-6 degrees for MC on smooth images [S1].
*   **Bias:** SMC systematically produces negative volume biases for convex objects (negative surface bias) and positive surface bias for concave objects. The volume bias is larger than MC or Cuberille [S1].
*   **Strengths:** Integer arithmetic only, no interpolation, guaranteed manifold meshes, low memory, fast for large images [S1].
*   **Limitations:** Lower geometric accuracy than MC, fixed bias on surface estimation [S1].

## Background
SMC was developed for materials science simulations, specifically Chemical Vapor Infiltration (CVI) and ablation modeling, where efficient surface evolution in large 3D blocks is required [S1]. It was proposed as a discretization scheme that avoids the interpolation and lookup tables of standard MC, relying instead on the binarization of the scalar field and integer grid vertices [S1].
