# Simplified Marching Cubes

Also called: SMC discretization, binarized Marching Cubes

## Overview
Simplified Marching Cubes (SMC) is a surface extraction method that produces meshes using only vertices from the regular 3D grid, eliminating interpolation and lookup tables [S1]. It reduces memory and triangle count by approximately half compared to standard Marching Cubes and Cuberille, at the cost of lower geometric accuracy [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar field $F(x, y, z)$ sampled on a regular grid.
*   **Output:** A manifold mesh consisting of triangles whose vertices are grid points.

**Data Structures:**
*   **Vertex:** 3 short integers (2 bytes each), representing integer coordinates $< 65535$ [S1].
*   **Triangle:** 3 long integers (4 bytes each), representing vertex indices [S1].
*   **Cube State:** For each cube, a case indicator (1 byte) and coefficients for up to two planes $hx + ky + lz + m = 0$ (2 bytes for $h,k,l \in \{-1,0,1\}^3$ and 4 bytes for $m \in \mathbb{N}$), totaling 7 bytes per cube [S1].

**Algorithm Steps:**
1.  **Binarization:** Convert $F$ to binary $F_B$ using threshold $\lambda$:
    $$F_B(x,y,z) = \begin{cases} 1 & \text{if } F(x,y,z) \geq \lambda \\ 0 & \text{otherwise} \end{cases}$$
    Positive vertices ($F_B=1$) are called "nodes". Negative vertices ($F_B=0$) are "fluid" [S1].
2.  **Neighbor Definition:** Use 6-connectivity. Vertex $n$ coordinates are $c_i^n = n\%2$, $c_j^n = (n\%4)/2$, $c_k^n = n/4$ [S1]. The number of node neighbors along axis $x$ for vertex $n$ is:
    $$N_x(n) = \overline{c_x^n} + 2 c_{x'}^n + 4 c_{x''}^n$$
    where $\overline{c}$ is the bitwise NOT (complement to 1) of $c$, and $x', x''$ are the other axes [S1]. An interface node is a node with $<3$ node neighbors [S1].
3.  **Cumulative Coordinates:** For each cube, compute $C_x = \sum_{n \in \text{nodes}} c_x^n$ for $x \in \{i,j,k\}$ [S1].
4.  **Triangle Classification Criterion:** To distinguish triangle types, compute:
    $$C_L(n_1, n_2, n_3) = \sum_{l=1}^3 \sum_{m=l+1}^3 \left( \sum_{x=i,j,k} (c_x^{n_l} - c_x^{n_m})^2 \right)^2$$
    Values: Type I (isosceles-right) = 6, Type II (rectangle) = 14, Type III (equilateral) = 12 [S1].
5.  **Configuration Processing:** Determine the number of nodes $N$ in the cube.
    *   If $N \in \{0, 1, 2, 8\}$: Output no triangles [S1].
    *   If $N = 3$: If $C_x = 0$ or $3$ for any axis, output one Type I triangle [S1].
    *   If $N = 4$:
        *   If $C_x = 0$ or $4$ for any axis: Output two Type I triangles [S1].
        *   If $C_x = 2$ for all axes: Output no triangles [S1].
        *   If one node is not an interface node (exhaustive test): Output one Type III triangle formed by the other three [S1].
        *   If one node has only negative neighbors: Switch its status to positive, re-process as $N=3$ (Case 8 logic) to build one Type I triangle [S1].
        *   Otherwise: Output two Type II triangles via nested loops [S1].
    *   If $N = 5$:
        *   If $C_x = 1$ or $4$ for any axis: Output two Type II triangles via nested loops [S1].
        *   If one node has only negative neighbors: Switch its status, re-process as $N=3$ (Case 9 logic) to build one Type III triangle [S1].
        *   Otherwise: Identify Type III triangle via loops. Find negative vertex with node neighbors, switch status, re-process as $N=6$ (Case 20) to build remaining triangles (two Type II, one Type III) [S1].
    *   If $N = 6$:
        *   If two negative vertices have only node neighbors (exhaustive test): Build two Type III triangles from their neighbors [S1].
        *   Otherwise: Output two Type II triangles from correctly ordered interface nodes [S1].
    *   If $N = 7$: Find the single negative vertex. Form one Type III triangle using its three neighbors [S1].

## Operating characteristics
*   **Memory:** Uses half the memory of standard MC and Cuberille. Vertices use 6 bytes (3 shorts), triangles use 12 bytes (3 longs) [S1].
*   **Speed:** Faster than standard MC, with speedup increasing as internal surface area increases [S1].
*   **Accuracy:** Lower than MC but higher than Cuberille. Surface error for a sphere converges to 7% (vs 0.4% for MC) [S1]. Normal RMS error is ~10-12 degrees for binarized images, similar to MC, but higher than MC for smooth images [S1].
*   **Bias:** Systematically produces negative volume bias for convex objects and positive for concave objects. Volume bias is larger than MC [S1].
*   **Topology:** Guarantees manifold meshes without holes by avoiding MC ambiguities (treating cases 11 and 14 as identical) [S1].

## Background
SMC was developed for materials science simulations, specifically Chemical Vapor Infiltration (CVI) and ablation modeling, where efficient surface evolution in large 3D blocks is required [S1]. It was proposed as an efficient alternative to MC for simulations of deposition/ablation in complex media [S1].
