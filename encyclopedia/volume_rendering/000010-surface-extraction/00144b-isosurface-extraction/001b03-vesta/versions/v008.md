# VESTA
Also called: Marching VESTA, Original VESTA

## Overview
VESTA (Volume-Enclosing Surface exTraction) is an isosurface extraction algorithm that constructs non-degenerate, closed 3D surfaces from voxel data by generating N-cycles from 3-cell configurations [S1, unofficial]. Unlike template-based methods such as Marching Cubes, VESTA uses a single building block based on vector decomposition to resolve 3D cell ambiguities at voxel face junctures, guaranteeing surfaces that are hole-free, non-self-intersecting, and volume-enclosing [S1, unofficial]. The original VESTA processes the entire dataset at once, while the marching VESTA variant scans 2x2x2 voxel neighborhoods (3-cells) to generate surface tiles, with all resulting cycles confined to these local neighborhoods [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D scalar field defined on a regular cubic lattice. Each voxel has a scalar value (e.g., temperature, density) [S1, unofficial].
*   **Parameters:**
    *   `iso_value`: Threshold separating active ($v \ge \text{iso\_value}$) and inactive voxels [S2, unofficial].
    *   `connectivity_mode`: Global or local mode for handling Points of Ambiguity (POA). Options: `disconnect`, `connect`, or `mixed` [S1, unofficial].
    *   `resolution_mode`: Determines triangulation detail. Options: `Low` (L, no extra points) or `High` (H, uses average points) [S1, unofficial].
*   **Output:** A mesh of oriented triangles (2-simplices) forming the isosurface.

**Data Structures:**
1.  **Voxel Grid:** 3D array of scalar values [G].
2.  **Boundary Face Vectors (VFVs):** For each boundary face between an active and inactive voxel, four vectors connect the face center to the four edge midpoints (junctures) in counter-clockwise order relative to the range vector [S1, unofficial].
3.  **Vector Path Table:** A lookup table mapping a quadrant ID and orientation ($\oplus$ or $\ominus$) to a path sequence of junctures. The table stores 24 directed paths (half due to symmetry) [S1, unofficial]. Columns: `Center ID`, `Orientation` ($\oplus/\ominus$), `Path` (sequence of juncture indices). Example (ID 0): $\oplus$ Path: $13 \to 0 \to 12$; $\ominus$ Path: $12 \to 0 \to 13$ [S1, unofficial].
4.  **Support Points:** Initially the centers of boundary faces. May be displaced within range vectors for isosurface accuracy [S1, unofficial].
5.  **Junctures:** Endpoints of VFVs (edge midpoints) where multiple VFVs meet [S1, unofficial].
6.  **Points of Ambiguity (POA):** Junctures where multiple valid connections exist (typically where voxels share only an edge or corner) [S1, unofficial].

**Algorithm Steps:**
1.  **Segmentation:** Classify voxels as active ($v \ge \text{iso\_value}$) or inactive ($v < \text{iso\_value}$) [S2, unofficial].
2.  **Identify Boundary Faces:** For each active voxel, check its 6 neighbors. If a neighbor is inactive, record the shared face as a boundary face [S1, unofficial].
3.  **Define VFVs:** For each boundary face, define the face center (support point) and four VFVs connecting the center to the four edge midpoints (junctures) in counter-clockwise order [S1, unofficial].
4.  **Connect VFVs (Cycle Formation):** Traverse the boundary faces. At each juncture, connect the origin of a VFV to the tip of a VFV from a neighboring boundary face [S1, unofficial]. **Ambiguity Resolution:** If a juncture is a POA, apply the `connectivity_mode`: `disconnect` connects VFVs belonging to the *same* voxel; `connect` connects VFVs belonging to *different* voxels; `mixed` uses local gray-level thresholds to decide per POA [S1, unofficial]. Replace connected VFV pairs with **VESTA cycle vectors** connecting support points [S1, unofficial]. Group vectors into closed cycles (N-cycles) [S1, unofficial].
5.  **Displacement (Optional for Isosurfaces):** Displace support points (face centers) along the range vector (from active voxel center to inactive neighbor center) based on linear interpolation of field values [S1, unofficial].
6.  **Triangulation (Decomposition):** Decompose N-cycles into triangles (3-cycles) [S1, unofficial]. **Low Resolution (L):** For N > 3, insert antiparallel vector pairs to break cycles into 3-cycles without adding new vertices [S1, unofficial]. **High Resolution (H):** For N > 3, calculate an additional point (average of all cycle support points) and connect it to the cycle vertices to form triangles [S1, unofficial].
7.  **Filtering:** Discard unphysical triangles (e.g., if corner points have negative radial/temporal values) [S1, unofficial].

**Formulas:**
The total normal vector $d\Sigma_\mu$ for an N-cycle is calculated as the sum of the individual triangle normal vectors $d\sigma^i_\mu$, associated with the average point of the N-cycle [S1, unofficial].

**Pseudocode:**
```python
def vesta_extract(volume, iso_value, connectivity_mode, resolution_mode):
    """
    volume: 3D numpy array of scalars
    iso_value: float threshold
    connectivity_mode: 'disconnect', 'connect', or 'mixed'
    resolution_mode: 'L' or 'H'
    Returns: list of triangles, each triangle is a tuple of 3 support points (x,y,z)
    """
    dims = volume.shape
    active = set()
    for i in range(dims[0]):
        for j in range(dims[1]):
            for k in range(dims[2]):
                if volume[i, j, k] >= iso_value:
                    active.add((i, j, k))
                    
    boundary_faces = []
    vfv_id_counter = 0
    for voxel in active:
        for d in range(6):
            neighbor = get_neighbor(voxel, d)
            if neighbor is not None and neighbor not in active:
                face_center = get_face_center(voxel, d)
                junctures = get_face_junctures(voxel, d)
                vfvs = []
                for idx, juncture in enumerate(junctures):
                    vfv = {'id': vfv_id_counter, 'origin': face_center, 'tip': juncture, 'voxel': voxel, 'juncture_idx': idx}
                    vfvs.append(vfv)
                    vfv_id_counter += 1
                boundary_faces.append({'center': face_center, 'vfvs': vfvs, 'voxel': voxel, 'direction': d})
                
    juncture_map = {}
    for face in boundary_faces:
        for vfv in face['vfvs']:
            tip = vfv['tip']
            if tip not in juncture_map:
                juncture_map[tip] = []
            juncture_map[tip].append(vfv)
            
    visited_vfvs = set()
    cycles = []
    
    for face in boundary_faces:
        for vfv in face['vfvs']:
            if vfv['id'] in visited_vfvs:
                continue
                
            cycle = []
            current_vfv = vfv
            while current_vfv is not None and current_vfv['id'] not in visited_vfvs:
                visited_vfvs.add(current_vfv['id'])
                cycle.append(current_vfv)
                
                tip = current_vfv['tip']
                candidates = juncture_map.get(tip, [])
                
                if len(candidates) == 0:
                    break
                if len(candidates) == 1:
                    next_vfv = candidates[0]
                else:
                    next_vfv = select_next_vfv(candidates, current_vfv, connectivity_mode, juncture_map, tip)
                    
                if next_vfv is None:
                    break
                current_vfv = next_vfv
                
            if len(cycle) > 0:
                cycles.append(cycle)
                
    # Displace support points for isosurfaces
    if resolution_mode == 'H':
        for cycle in cycles:
            for vfv in cycle:
                vfv['origin'] = displace_point(vfv['origin'], vfv['voxel'], volume)
                
    triangles = []
    for cycle in cycles:
        n = len(cycle)
        if n == 3:
            p0, p1, p2 = cycle[0]['origin'], cycle[1]['origin'], cycle[2]['origin']
            triangles.append((p0, p1, p2))
        else:
            if resolution_mode == 'L':
                p0 = cycle[0]['origin']
                for i in range(1, n - 1):
                    p1 = cycle[i]['origin']
                    p2 = cycle[i+1]['origin']
                    triangles.append((p0, p1, p2))
            else:
                avg = calculate_average(cycle)
                for i in range(n):
                    p1 = cycle[i]['origin']
                    p2 = cycle[(i + 1) % n]['origin']
                    triangles.append((avg, p1, p2))
                    
    return triangles

def get_neighbor(voxel, d):
    i, j, k = voxel
    if d == 0: return (i+1, j, k)
    if d == 1: return (i-1, j, k)
    if d == 2: return (i, j+1, k)
    if d == 3: return (i, j-1, k)
    if d == 4: return (i, j, k+1)
    if d == 5: return (i, j, k-1)
    return None

def get_face_center(voxel, d):
    i, j, k = voxel
    if d == 0: return (i+0.5, j, k)
    if d == 1: return (i-0.5, j, k)
    if d == 2: return (i, j+0.5, k)
    if d == 3: return (i, j-0.5, k)
    if d == 4: return (i, j, k+0.5)
    if d == 5: return (i, j, k-0.5)
    return None

def get_face_junctures(voxel, d):
    i, j, k = voxel
    if d == 0: return [(i+0.5, j+0.5, k), (i+0.5, j-0.5, k), (i+0.5, j-0.5, k+1), (i+0.5, j+0.5, k+1)]
    if d == 1: return [(i-0.5, j-0.5, k), (i-0.5, j+0.5, k), (i-0.5, j+0.5, k+1), (i-0.5, j-0.5, k+1)]
    if d == 2: return [(i+0.5, j+0.5, k), (i-0.5, j+0.5, k), (i-0.5, j-0.5, k), (i+0.5, j-0.5, k)]
    if d == 3: return [(i-0.5, j-0.5, k), (i+0.5, j-0.5, k), (i+0.5, j+0.5, k), (i-0.5, j+0.5, k)]
    if d == 4: return [(i+0.5, j, k+0.5), (i-0.5, j, k+0.5), (i-0.5, j, k-0.5), (i+0.5, j, k-0.5)]
    if d == 5: return [(i-0.5, j, k-0.5), (i+0.5, j, k-0.5), (i+0.5, j, k+0.5), (i-0.5, j, k+0.5)]
    return []

def select_next_vfv(candidates, current_vfv, mode, juncture_map, tip):
    next_candidates = [v for v in juncture_map.get(tip, []) if v['origin'] == tip]
    if len(next_candidates) == 1:
        return next_candidates[0]
    if mode == 'disconnect':
        for v in next_candidates:
            if v['voxel'] == current_vfv['voxel']:
                return v
    elif mode == 'connect':
        for v in next_candidates:
            if v['voxel'] != current_vfv['voxel']:
                return v
    elif mode == 'mixed':
        # Mixed mode uses local gray-level thresholds to decide per POA [G]
        return next_candidates[0] if next_candidates else None
    return next_candidates[0] if next_candidates else None

def displace_point(point, voxel, volume):

    # The exact interpolation formula is not given in the sources. [G]
    return point

def calculate_average(cycle):
    n = len(cycle)
    avg = [0.0, 0.0, 0.0]
    for vfv in cycle:
        p = vfv['origin']
        avg[0] += p[0]
        avg[1] += p[1]
        avg[2] += p[2]
    return (avg[0]/n, avg[1]/n, avg[2]/n)
```

## Subtopics

### [STEVE Hypersurface Generation](9503-steve-hypersurface-generation.md)
STEVE (Space-Time-Enclosing Volume Extraction) is an algorithm for extracting iso-valued hypersurfaces from 4D data sets, guaranteeing that the resulting hypersurface is free from accidental rifts and fully encloses a region in 4D space. It generates simplex-based manifolds of codimension 1, specifically consisting purely of 3-simplices (tetrahedrons) embedded in 4D space. Unlike methods that extrude 4D data to 5D, STEVE works directly in 4D. It builds on the VESTA framework, using a similar flowchart for mesh features, data segmentation, and ambiguity handling, but extends the vector path logic to four dimensions.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of active voxels and boundary faces. The marching variant processes 2x2x2 neighborhoods independently, allowing for parallelization [S1, unofficial].
*   **Memory Complexity:** Original VESTA requires storing the entire dataset and all cycles in memory, which can be high for large volumes [S1, unofficial]. Marching VESTA reduces memory usage by processing local 3-cells [S1, unofficial].
*   **Performance:** In benchmarks on 200 x-ray microtomography images (256x256 pixels, ~512k active voxels), Original VESTA L took 5.34s, Mixed L took 4.62s, and MCA L took 4.71s [S1, unofficial]. VESTA generates significantly fewer support points than MCA (e.g., 932k points vs 5.5M points for the same triangle count), reducing redundancy [S1, unofficial].
*   **Strengths:** Guarantees hole-free, non-self-intersecting, volume-enclosing surfaces. No template management required. Robust against topological ambiguities [S1, unofficial].
*   **Limitations:** Does not connect voxels sharing only a single point (corner contact) by default, which may require post-processing or template insertion for weak connectivity [S1, unofficial]. High-resolution mode requires calculating average points, adding computational overhead [S1, unofficial].

## Background
VESTA was introduced as a novel volume-enclosing surface extraction technique for 3D data sets on cubic lattices [S1, unofficial]. It was developed to address the limitations of the Marching Cubes Algorithm (MCA), particularly the generation of holes and the need for extensive template sets to handle ambiguities [S1, unofficial]. The method is analogous to the 2D DICONEX algorithm [S1, unofficial]. It has been applied to computer tomographic scan data and relativistic hydrodynamic simulation data [S1, unofficial].
