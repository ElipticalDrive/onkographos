# Unstructured and Arbitrary Grid Methods


## Overview
This family extracts isosurfaces from scalar fields defined on non-Cartesian domains, including arbitrary polyhedral cells and hybrid unstructured grids [G]. It sets itself apart by operating directly on complex cell geometries without requiring decomposition into tetrahedra or reliance on predefined configuration tables for ambiguous faces [G].

## Shared principles
All methods in this family operate on a discretized domain where each cell contains scalar values at its vertices [G]. The core mechanism involves traversing the grid cells, evaluating the scalar field against an isovalue to detect intersections, and generating geometric primitives (polygons or polynomial patches) at those intersections [G]. Adjacent primitives are connected to form a coherent mesh [G].

## Subtopics

### [Isosurface extraction on arbitrary polyhedral grids](951-isosurface-extraction-on-arbitrary-polyhedral-grids.md)
This method extracts isosurfaces from scalar fields defined on arbitrary polyhedral cells (convex, non-convex, planar, or non-planar) by approximating the surface locally at each cell as a polygonal surface (isopolygon) [951-isosurface-extraction-on-arbitrary-polyhedral-grids.md]. It solves the topological inconsistencies and holes inherent in standard Marching Cubes on ambiguous faces by treating face boundaries systematically using general polygon tracing rules, rather than relying on predefined configuration tables [951-isosurface-extraction-on-arbitrary-polyhedral-grids.md]. Unlike Marching Tetrahedra, it operates directly on arbitrary polyhedra without decomposing them into tetrahedra [951-isosurface-extraction-on-arbitrary-polyhedral-grids.md].

**Inputs:**
- Scalar field values $\phi_{ip}$ at every vertex $ip$ of the grid.
- Isovalue $\tilde{\phi}$ defining the surface.
- Geometric coordinates $\mathbf{x}_{ip}$ of every vertex.
- Connectivity data: for each cell, the list of faces, and for each face, the list of vertices defining its boundary.

**Outputs:**
- A set of isopolygons, where each polygon is defined by an ordered sequence of 3D points (vertices) lying on the cell edges.

**Data Structures:**
- `IA[ip]`: Integer tag for vertex $ip$. $IA(ip) = 1$ if $\phi_{ip} > \tilde{\phi}$, else $0$. Strict inequality is used to prevent division by zero [951-isosurface-extraction-on-arbitrary-polyhedral-grids.md].
- `IPVINT[j, i']`: Index of the $\tilde{\phi}$-vertex inserted on the $i'$-th edge of face boundary $j$.
- `visited(ip1, ip2)`: Boolean flag to track if an edge has been processed to avoid double-counting shared edges between faces [951-isosurface-extraction-on-arbitrary-polyhedral-grids.md].

**Steps:**
1. **Tagging:** For every vertex $ip$ in the grid, compute $IA(ip) = 1$ if $\phi_{ip} > \tilde{\phi}$, else $0$ [951-isosurface-extraction-on-arbitrary-polyhedral-grids.md].
2. **Cell Selection:** Identify cells where the scalar field crosses the isovalue. A cell is selected if $\max(\phi) > \tilde{\phi}$ and $\min(\phi) < \tilde{\phi}$ [951-isosurface-extraction-on-arbitrary-polyhedral-grids.md].
3. **Vertex Insertion (Indexing):** For each selected cell, iterate through all face boundaries $j$. For each edge $i'$ in face $j$, defined by vertices $ip1 = IPV(j, i)$ and $ip2 = IPV(j, i+1)$ (with wrap-around):
   - If $IA(ip1) \neq IA(ip2)$, the edge is intersected.
   - If the edge has not been visited, assign a new unique index to this intersection point and mark the edge as visited. If already visited, retrieve the existing index.
   - Store this index in `IPVINT[j, i']`.
   - If $IA(ip2) == 1$, mark the inserted vertex as a "key vertex" [951-isosurface-extraction-on-arbitrary-polyhedral-grids.md].
4. **Vertex Arrangement (Tracing):** Construct the isopolygons by linking the inserted vertices.
   - Initialize the first vertex of the first isopolygon to the first inserted vertex index [951-isosurface-extraction-on-arbitrary-polyhedral-grids.md].
   - Recursively find the next vertex: For the current vertex index, find the face boundary $j$ where this vertex is a "key vertex".
   - The next vertex in the polygon is the vertex preceding the current one in that face boundary's intersection list: `prev_φ = IPVINT(j, i'-1)` (handling wrap-around) [951-isosurface-extraction-on-arbitrary-polyhedral-grids.md].
   - If `prev_φ` is not the first vertex of the current polygon, add it to the polygon.
   - If the loop closes (next vertex equals the first vertex), start a new isopolygon if unassigned vertices remain [951-isosurface-extraction-on-arbitrary-polyhedral-grids.md].
5. **Positioning:** For each $\tilde{\phi}$-vertex on an edge defined by $ip1$ and $ip2$, compute its 3D position $\tilde{\mathbf{x}}_\phi$ using linear interpolation [951-isosurface-extraction-on-arbitrary-polyhedral-grids.md]:
   $$
   \tilde{\mathbf{x}}_\phi = \mathbf{x}_{ip2} - \frac{\phi_{ip2} - \tilde{\phi}}{\phi_{ip2} - \phi_{ip1}} (\mathbf{x}_{ip2} - \mathbf{x}_{ip1})
   $$
   Strict inequalities in step 1 ensure $\phi_{ip2} \neq \phi_{ip1}$, preventing division by zero [951-isosurface-extraction-on-arbitrary-polyhedral-grids.md].

**Pseudocode:**
```python
def extract_isosurface(vertices, scalar_values, cell_faces, isovalue):
    """
    vertices: List of 3D coordinates [x, y, z]
    scalar_values: List of scalar values at each vertex
    cell_faces: List of cells, where each cell is a list of faces, 
                and each face is a list of vertex indices
    isovalue: The threshold scalar value
    """
    IA = [1 if s > isovalue else 0 for s in scalar_values]
    all_isopolygons = []
    
    for cell in cell_faces:
        cell_scalars = [scalar_values[v] for v in cell]
        if max(cell_scalars) <= isovalue or min(cell_scalars) >= isovalue:
            continue
            
        n_faces = len(cell)
        IPVINT = [[None] * len(face) for face in cell]
        visited_edges = {}
        phi_vertices = []
        phi_is_key = []
        
        # Step 3: Vertex Insertion
        for j in range(n_faces):
            face = cell[j]
            n_face = len(face)
            for i in range(n_face):
                ip1 = face[i]
                ip2 = face[(i + 1) % n_face]
                if IA[ip1] != IA[ip2]:
                    edge_key = tuple(sorted((ip1, ip2)))
                    if edge_key not in visited_edges:
                        visited_edges[edge_key] = len(phi_vertices)
                        phi_vertices.append((ip1, ip2))
                        phi_is_key.append(IA[ip2] == 1)
                        IPVINT[j][i] = visited_edges[edge_key]
                    else:
                        IPVINT[j][i] = visited_edges[edge_key]
                        
        # Step 4: Vertex Arrangement
        assigned = [False] * len(phi_vertices)
        for start in range(len(phi_vertices)):
            if assigned[start]:
                continue
            polygon = []
            curr = start
            while True:
                polygon.append(curr)
                assigned[curr] = True
                if not phi_is_key[curr]:
                    break
                found = False
                for j in range(n_faces):
                    for i in range(len(cell[j])):
                        if IPVINT[j][i] == curr:
                            prev_i = (i - 1) % len(cell[j])
                            prev_idx = IPVINT[j][prev_i]
                            if prev_idx == polygon[0]:
                                all_isopolygons.append(polygon)
                                found = True
                                break
                            if not assigned[prev_idx]:
                                curr = prev_idx
                                found = True
                                break
                    if found:
                        break
                if not found:
                    break
                    
    # Step 5: Positioning
    result_polygons = []
    for poly_indices in all_isopolygons:
        poly_points = []
        for phi_idx in poly_indices:
            ip1, ip2 = phi_vertices[phi_idx]
            x1, y1, z1 = vertices[ip1]
            x2, y2, z2 = vertices[ip2]
            s1, s2 = scalar_values[ip1], scalar_values[ip2]
            t = (s2 - isovalue) / (s2 - s1)
            px = x2 - t * (x2 - x1)
            py = y2 - t * (y2 - y1)
            pz = z2 - t * (z2 - z1)
            poly_points.append((px, py, pz))
        result_polygons.append(poly_points)
    return result_polygons
```

### [Gallagher-Nagtegaal Bicubic Method](5321-gallagher-nagtegaal-bicubic-method.md)
The Gallagher-Nagtegaal Bicubic Method is an isosurface extraction technique that replaces the triangular facets of traditional marching cubes with visually continuous bicubic polynomial patches [5321-gallagher-nagtegaal-bicubic-method.md]. It solves the problem of geometric discontinuity and aliasing artifacts on unstructured or rectilinear grids by processing each volume element in isolation [5321-gallagher-nagtegaal-bicubic-method.md]. Unlike sibling methods that rely on linear interpolation or global mesh coherence, this method prioritizes local smoothness and independent element processing to facilitate efficient microcoding and parallelization [5321-gallagher-nagtegaal-bicubic-method.md].

### Direct Isosurface Extraction from Pentahedral Elements
**Definition**: A method for extracting isosurfaces of scalar fields defined on hybrid unstructured grids containing pentahedral elements (square pyramids and right triangular prisms) directly, avoiding the need to subdivide non-tetrahedral cells into tetrahedra or use indirect triangulation methods [S1].
**Steps**: Construct look-up tables for square pyramidal cells with accurate topological considerations, and construct look-up tables for triangular prismatic cells with accurate topological considerations [S1].
**Comparison**: Unlike indirect methods that subdivide non-tetrahedral cells into tetrahedra to use marching tetrahedra, or triangulate intersection points using standard algorithms, this method processes nearly all types of hybrid unstructured grids directly without subdivision [S1].
**History**: The method is based on the basic ideas underlying the well-established marching cubes and marching tetrahedra algorithms, which are applied to hexahedral and tetrahedral elements, respectively [S1].

## Background
Standard approaches often require converting unstructured data into tetrahedral or hexahedral elements, which can introduce topological errors or computational overhead [S1]. The Gallagher-Nagtegaal method addresses the visual quality issues of linear interpolation by fitting bicubic patches, while the polyhedral and pentahedral methods extend robustness to complex cell types [G].
