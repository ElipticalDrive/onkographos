# Gallagher-Nagtegaal Bicubic Method
Also called: GN Bicubic, Unstructured mesh marching cubes variant
## Overview
The Gallagher-Nagtegaal Bicubic Method is an isosurface extraction technique that generates visually continuous bicubic polynomial patches instead of planar triangles [S1, unofficial]. It extends the marching cubes paradigm to operate on both unstructured and rectilinear meshes [S1, unofficial]. Unlike sibling methods that rely on linear interpolation or fixed topological cases, this method prioritizes geometric smoothness and data locality by processing each volume element in isolation [S1, unofficial].
## How it works
The method operates on a discretized domain where each cell contains scalar values at its vertices [G]. It traverses the grid cells, evaluates the scalar field against an isovalue to detect intersections, and generates bicubic polynomial patches at those intersections [G]. Adjacent patches are connected to form a coherent mesh [G].

**Inputs:**
- A scalar field defined on a grid (rectilinear or unstructured).
- Scalar values at the vertices of each volume element.
- An isovalue threshold.

**Outputs:**
- A mesh composed of bicubic polynomial patches representing the isosurface.

**Data Structures:**
- Each volume element (cell) is processed independently.
- For a standard hexahedral element, the scalar values are stored at the 8 vertices.
- The bicubic patch is defined by the scalar values and potentially their derivatives or Hermite coefficients derived from the vertex values [G].

**Steps:**
1. Iterate through each volume element in the dataset.
2. Determine if the isosurface intersects the current element by comparing vertex scalar values to the isovalue.
3. If an intersection exists, compute the bicubic polynomial patch that approximates the isosurface within the element.
   - The patch is constructed to ensure visual continuity with adjacent elements [S1, unofficial].
   - The specific construction of the bicubic polynomial from vertex values is not detailed in the provided sources [G].
4. Output the generated patch.
5. Repeat for all elements.

**Parameters:**
- Isovalue: The scalar threshold for surface extraction.
- Grid type: Rectilinear or unstructured.

**Edge Cases:**
- Elements with no intersection are skipped.
- Continuity at element boundaries relies on the consistent construction of the bicubic patches [S1, unofficial].

## Subtopics
## Operating characteristics
The method processes each volume element in isolation, minimizing the amount of information accessed in the inner loop [S1, unofficial]. This characteristic makes the algorithm suitable for efficient microcoding on a single workstation [S1, unofficial]. Additionally, the independent treatment of elements lends the algorithm to parallel implementations [S1, unofficial]. The use of bicubic polynomials provides visually continuous surfaces, which is a trade-off for potentially higher computational cost per element compared to linear triangle-based methods [S1, unofficial].
## Background
The method was described by Gallagher and Nagtegaal in 1989 [S1, unofficial]. It builds upon the "marching cubes" method but adapts it for unstructured and rectilinear meshes using bicubic polynomials [S1, unofficial].
