# Tetrahedral Marching Cubes Neighbor Lookup

Also called: Vertex Neighbor Lookup Table, Vertex neighbor lookup table around cube corner

## Overview
The Tetrahedral Marching Cubes Neighbor Lookup is a lookup table providing anchor displacements ($\Delta_i$) and neighbor tetrahedron offsets ($t_i$) for vertices surrounding a specific cube corner, used to map tetrahedra for isosurface extraction [S1]. It is a performance optimization component of the Tetrahedral Marching Cubes method [S1].

## How it works
### Inputs and Outputs
- **Input**: A cube corner $c = (c_x, c_y, c_z) \in \{0, 1\}^3$ [S1].
- **Output**: A set of entries, each containing an index range $i$, an anchor displacement $\Delta_i = (\Delta_{x,i}, \Delta_{y,i}, \Delta_{z,i})$, and a neighbor tetrahedron offset $t_i$ [S1].

### Data Structures
The core data structure is a lookup table (referred to as Table A8 in the source) [S1]. The table columns are the index range $i$, $\Delta_x$, $\Delta_y$, $\Delta_z$, and $t_i$ [S1]. Rows group indices sharing the same configuration [S1]. For the canonical corner $c=(0,0,0)$, the entries are: $i=1–6$ has $\Delta=(-1,-1,-1)$ and $t_i=-5$; $i=7–8$ has $\Delta=(-1,-1,0)$ and $t_i=1,2$; $i=9–10$ has $\Delta=(-1,0,-1)$ and $t_i=0,5$; $i=11–12$ has $\Delta=(-1,0,0)$ and $t_i=0,1$; $i=13–14$ has $\Delta=(0,-1,-1)$ and $t_i=3,4$; $i=15–16$ has $\Delta=(0,-1,0)$ and $t_i=2,3$; $i=17–18$ has $\Delta=(0,0,-1)$ and $t_i=4,5$; $i=19–24$ has $\Delta=(0,0,0)$ and $t_i=0–5$ [S1].

### Steps
1. **Select Cube Corner**: Identify the cube corner $c = (c_x, c_y, c_z) \in \{0, 1\}^3$ for the lookup [S1].
2. **Retrieve Base Entries**: Look up the base entries in the lookup table corresponding to the canonical corner (e.g., $(0,0,0)$) [S1].
3. **Adjust Displacements**: For each entry, adjust the anchor displacement to account for the specific cube corner by adding the corner coordinates: $\Delta_i \leftarrow \Delta_i + c$ [S1].
4. **Map Tetrahedra**: Use the adjusted configurations $(\Delta_i, t_i)$ to map tetrahedra for isosurface extraction [S1].

### Parameters
- **Cube Corner $c$**: A 3D vector with components in $\{0, 1\}$ [S1]. The table is defined per cube corner because vertices of each tetrahedron can be mapped to a cube corner [S1].

### Edge Cases and Pitfalls
- **Self Configuration Coincidence**: For a specific cube corner $c$ and tetrahedron offset $t$, one row in the lookup table may coincide with the self configuration $(\Delta_0=(0, 0, 0), t_0=t)$ [S1].

### Pseudocode
```python
def get_neighbor_lookup(c):
    """
    Retrieve and adjust the neighbor lookup table for a given cube corner c.
    
    Args:
        c (tuple): The cube corner coordinates (cx, cy, cz), each in {0, 1}.
        
    Returns:
        list: A list of tuples, each containing (start_i, end_i, delta_x, delta_y, delta_z, t_i).
    """
    # Base lookup table for corner (0, 0, 0) as defined in the source
    # Format: (start_index, end_index, delta_x, delta_y, delta_z, t_i_values)
    base_table = [
        (1, 6, -1, -1, -1, [-5]),
        (7, 8, -1, -1, 0, [1, 2]),
        (9, 10, -1, 0, -1, [0, 5]),
        (11, 12, -1, 0, 0, [0, 1]),
        (13, 14, 0, -1, -1, [3, 4]),
        (15, 16, 0, -1, 0, [2, 3]),
        (17, 18, 0, 0, -1, [4, 5]),
        (19, 24, 0, 0, 0, [0, 1, 2, 3, 4, 5])
    ]
    
    adjusted_entries = []
    
    for start_i, end_i, dx, dy, dz, t_vals in base_table:
        # Adjust displacements by adding the cube corner coordinates
        adj_dx = dx + c[0]
        adj_dy = dy + c[1]
        adj_dz = dz + c[2]
        
        # Yield each t_i value for the current displacement
        for t in t_vals:
            adjusted_entries.append((start_i, end_i, adj_dx, adj_dy, adj_dz, t))
            
    return adjusted_entries
```

## Subtopics

### Tetrahedral Marching Cubes (5-tetrahedra method)
The parent method that decomposes a cube into five tetrahedra for isosurface extraction. It differs by performing the actual surface extraction rather than just neighbor lookup. Choose it when extracting surfaces on tetrahedral grids. [Tetrahedral Marching Cubes (5-tetrahedra method)](4547-tetrahedral-marching-cubes-5-tetrahedra-method.md)
