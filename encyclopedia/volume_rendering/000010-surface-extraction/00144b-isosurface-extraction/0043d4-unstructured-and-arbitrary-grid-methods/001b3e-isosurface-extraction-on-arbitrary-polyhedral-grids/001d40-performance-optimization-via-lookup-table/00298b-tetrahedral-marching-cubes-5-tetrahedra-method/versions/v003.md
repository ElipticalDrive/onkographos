# Tetrahedral Marching Cubes (5-tetrahedra method)

Also called: 5-tetrahedra-per-cube extraction, SurfaceExtractorTetrahedra

## Overview
This method extracts an isosurface from a scalar field defined on a regular voxel grid by decomposing each cube into five tetrahedra and performing linear interpolation within each tetrahedron [S1, unofficial]. It covers all 81 possible sign patterns of the vertex values, including degenerate cases where vertices lie exactly on the isosurface [S1, unofficial]. Unlike the standard [Marching Cubes](52-marching-cubes.md) which relies on a 256-entry lookup table and resolves ambiguities via topology checks, this method is deterministic and topology-agnostic, solving the equation $V - L = 0$ directly [S1, unofficial].

## How it works
**Inputs:** A 3D scalar field $V$ defined on a grid of voxels, and a scalar level $L$ [S1, unofficial].
**Outputs:** A set of vertices and triangles forming a manifold mesh [S1, unofficial].

**Data Structures:**
The implementation replaces standard associative containers with maps keyed by canonical strings to ensure deterministic ordering and exact arithmetic [S1, unofficial].
*   **Vertices:** Stored in a map keyed by a canonical string representation of the rational coordinates (reduced to lowest terms) [S1, unofficial]. Vertex indices are assigned in insertion order [S1, unofficial].
*   **Edges/Triangles:** Stored in maps keyed by canonical strings [S1, unofficial]. Sorted at the end by a custom `operator<` to match `std::set` iteration order [S1, unofficial].
*   **Arithmetic:** Uses `int64_t` for internal calculations, mapping onto IEEE doubles [S1, unofficial]. This remains exact as long as products stay within the safe-integer range ($2^{63}$) [S1, unofficial].

**Algorithm Steps:**
1.  **Decomposition:** For each voxel cube, decompose it into 5 tetrahedra (four corner tetrahedra plus one central tetrahedron) [S1, unofficial].
2.  **Sign Pattern Evaluation:** Determine the signs of the scalar field values at the 8 vertices of the cube relative to the level $L$ [S1, unofficial].
3.  **Intersection Calculation:** For each tetrahedron in the cube, identify edges where the scalar value crosses the level $L$ (sign change), compute the intersection point on these edges using linear interpolation, and form triangles from the intersection points [S1, unofficial].
4.  **Gradient and Orientation:** Calculate the gradient at intersection points to determine triangle orientation [S1, unofficial].
5.  **Mesh Assembly:** Collect all generated triangles [S1, unofficial]. Sort edges and triangles by their canonical keys to ensure consistent ordering [S1, unofficial].

**Formulas:**
*   Isosurface equation: $V - L = 0$ [S1, unofficial].
*   Linear interpolation on an edge between vertices $A$ and $B$ with values $v_A$ and $v_B$: $P = A + \frac{L - v_A}{v_B - v_A}(B - A)$ [G].
*   Odd-parity gradient cutting plane: $dx + dy + dz = 2$, where $dx, dy, dz$ are fractional offsets within the voxel [S1, unofficial].

**Parameters:**
*   Level $L$: Threshold for surface extraction. Not given in the sources.
*   Grid dimensions: Determined by the input scalar field resolution. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Degenerate patterns:** Zero-valued vertices (sign = 0) are explicitly handled across all 81 sign patterns [S1, unofficial].
*   **Odd-parity gradient bug:** In the original implementation, the `GetGradient` function for odd-parity cubes used `dx + dy + dz >= 0` to select the central tetrahedron (index 6572) [S1, unofficial]. Since $dx, dy, dz \in [0, 1]$, this sum is always $\ge 0$, making the branch for the central tetrahedron (index 0752) unreachable [S1, unofficial]. The fix changes the condition to `dx + dy + dz >= 2` because the cutting plane through vertices $(1,1,0), (1,0,1), (0,1,1)$ is defined by $dx + dy + dz = 2$ [S1, unofficial].

**Pseudocode:**
```python
import math

def gcd(a, b):
    return a if b == 0 else gcd(b, a % b)

def canonical_string(coord):
    # Formats coordinates as reduced rational strings for deterministic ordering
    x, y, z = coord
    gx, gy, gz = gcd(x, 1), gcd(y, 1), gcd(z, 1)
    return f"{x//gx},{y//gy},{z//gz}"

def extract_tetrahedral(field, level, grid_dims):
    vertex_map = {}  # canonical_string -> index
    triangle_set = {} # canonical_string -> True
    vertices = []
    triangles = []

    for x in range(grid_dims.x - 1):
        for y in range(grid_dims.y - 1):
            for z in range(grid_dims.z - 1):
                # Sample 8 corners
                v = [field[x+i, y+j, z+k] for i in (0,1) for j in (0,1) for k in (0,1)]
                signs = [1 if val > level else (-1 if val < level else 0) for val in v]

                # Decompose cube into 5 tetrahedra (indices refer to 8 corners)
                tets = [
                    [0, 1, 3, 7], [1, 3, 2, 7], [1, 2, 6, 7], [2, 6, 3, 7], [3, 6, 7, 0]
                ]
                
                for tet in tets:
                    tet_signs = [signs[i] for i in tet]
                    if not (all(s >= 0 for s in tet_signs) or all(s <= 0 for s in tet_signs)):
                        edges = []
                        for i in range(4):
                            for j in range(i+1, 4):
                                if tet_signs[i] * tet_signs[j] < 0:
                                    edges.append((i, j))
                        
                        points = []
                        for e in edges:
                            i, j = e
                            t = (level - v[tet[i]]) / (v[tet[j]] - v[tet[i]])
                            # Extract corner coordinates
                            xi, yi, zi = (tet[i] >> 2) & 1, (tet[i] >> 1) & 1, tet[i] & 1
                            xj, yj, zj = (tet[j] >> 2) & 1, (tet[j] >> 1) & 1, tet[j] & 1
                            pt = (x + xi + t * (xj - xi), y + yi + t * (yj - yi), z + zi + t * (zj - zi))
                            points.append(pt)
                        
                        if len(points) == 3:
                            tris = [points]
                        elif len(points) == 4:
                            tris = [points[:3], [points[0], points[2], points[3]]]
                        else:
                            tris = []
                            
                        for tri in tris:
                            tri_indices = []
                            for p in tri:
                                key = canonical_string(p)
                                if key not in vertex_map:
                                    vertex_map[key] = len(vertices)
                                    vertices.append(p)
                                tri_indices.append(vertex_map[key])
                            tri_key = canonical_string(sorted(tri_indices))
                            if tri_key not in triangle_set:
                                triangle_set[tri_key] = True
                                triangles.append(tri_indices)

    triangles.sort(key=lambda t: canonical_string(sorted(t)))
    return vertices, triangles
```

## Subtopics

### SurfaceExtractorCubes
Cube-based surface extraction using a vertex-edge table (VETable) and ear-clipping [S1, unofficial]. It resolves the four-cut face ambiguity by evaluating the sign of the determinant $f_{00}f_{11} - f_{01}f_{10}$, adding a branch point when $\det == 0$ [S1, unofficial]. Unlike the tetrahedra extractor which solves $V - L = 0$, the cubes extractor solves $2V - (2L+1) = 0$ [S1, unofficial]. To extract the same surface, voxels must be doubled and the level set to $2L+1$ [S1, unofficial].
