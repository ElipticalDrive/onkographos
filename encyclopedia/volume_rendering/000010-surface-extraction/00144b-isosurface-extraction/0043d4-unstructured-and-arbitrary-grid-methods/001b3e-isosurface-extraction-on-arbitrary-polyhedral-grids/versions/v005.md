# Isosurface extraction on arbitrary polyhedral grids

Also called: General polygon tracing procedure, Generalized marching cubes for arbitrary grids, Isopolygon extraction, Isosurface extraction on arbitrary polyhedral cells, Method for isosurface extraction on arbitrary polyhedral cells

## Overview
This method extracts isosurfaces from scalar fields defined on arbitrary polyhedral cells (convex, non-convex, planar, or non-planar faces) by approximating the local isosurface as a polygonal surface (isopolygon) using a general polygon tracing procedure [S1]. It solves the topological inconsistencies and non-2-manifold artifacts inherent in standard [Marching Cubes](52-marching-cubes.md) when handling ambiguous face configurations by systematically treating face boundaries and avoiding reliance on predefined configuration lookup tables [S1]. Unlike [Marching Tetrahedra](52-marching-tetrahedra.md), it operates directly on arbitrary polyhedra without decomposing cells into tetrahedra, offering geometric flexibility at the cost of higher computational complexity per cell [S1].

## How it works
The method extracts an isosurface for a given isovalue $\tilde{\phi}$ from a scalar field $\phi$ defined on the vertices of an arbitrary polyhedral grid. The output is a set of non-planar polygons (isopolygons) representing the isosurface within each intersected cell [S1].

### Inputs and Outputs
*   **Input:**
    *   Grid geometry: List of cells, where each cell is defined by a list of faces, and each face by a list of vertex indices.
    *   Scalar field: Values $\phi_{ip}$ at each vertex $ip$.
    *   Isovalue: $\tilde{\phi}$ (scalar threshold).
*   **Output:**
    *   List of isopolygons, where each polygon is defined by an ordered sequence of 3D position vectors $\tilde{\mathbf{x}}_{\tilde{\phi}}$.

### Data Structures
For each cell, the algorithm uses the following structures (based on [S1]):
*   `IA[ip]`: Integer tag for vertex $ip$. $1$ if $\phi_{ip} > \tilde{\phi}$, $0$ otherwise. Strict inequality prevents division by zero in interpolation.
*   `IPV(j, i)`: Index of the $i$-th vertex of face boundary $j$.
*   `NIPV(j)`: Number of vertices in face boundary $j$.
*   `IPVINT(j, i)`: Stores the global index $\tilde{\phi}$ of the intersection point on the $i$-th edge of face boundary $j$. If the edge is not intersected, this value is undefined or zero.
*   `NIPVINT(j)`: Count of intersected edges on face boundary $j$.
*   `visited(ip1, ip2)`: Boolean flag to track if the edge between vertices $ip1$ and $ip2$ has been processed to avoid double-counting shared edges.
*   `key[tilde_phi_index]`: Boolean flag marking a $\tilde{\phi}$-vertex as a "key" vertex. A vertex is key if it lies on an edge $(ip1, ip2)$ where $IA(ip2) = 1$ [S1].
*   `IPVISO(k, ik)`: 2D array storing the global index of the $ik$-th vertex of the $k$-th isopolygon.

### Steps

1.  **Tagging:** For every vertex $ip$ in the grid, compute $IA(ip) = 1$ if $\phi_{ip} > \tilde{\phi}$, else $0$ [S1].
2.  **Cell Selection:** Identify cells where the scalar field crosses the isovalue. A cell is selected if $\max(\phi_{vertices}) > \tilde{\phi}$ and $\min(\phi_{vertices}) < \tilde{\phi}$ [S1].
3.  **Insertion of $\tilde{\phi}$-vertex indices:** Iterate through all faces of all selected cells to identify intersected edges and assign global indices to intersection points [S1].
4.  **Arrangement of $\tilde{\phi}$-vertices:** Trace the boundaries of the isosurface within each cell to order the intersection points into closed polygons (isopolygons) [S1].
5.  **Positioning:** Compute the 3D coordinates of each $\tilde{\phi}$-vertex using linear interpolation [S1].

#### Step 3: Insertion of $\tilde{\phi}$-vertex indices
For each selected cell, iterate through its face boundaries $j = 1 \dots N_{faces}$. For each face, iterate through its edges $i = 1 \dots NIPV(j)$. Let $ip1 = IPV(j, i)$ and $ip2 = IPV(j, i+1)$ (with wrap-around for the last edge).

1.  Check if the edge is intersected: if $IA(ip1) \neq IA(ip2)$.
2.  If intersected:
    *   Check if the edge $(ip1, ip2)$ has been visited.
    *   If not visited:
        *   Increment global counter $\tilde{\phi}_{count}$.
        *   Mark edge $(ip1, ip2)$ as visited.
        *   Assign new index $\tilde{\phi} = \tilde{\phi}_{count}$.
    *   If already visited:
        *   Retrieve existing index $\tilde{\phi}$ for edge $(ip1, ip2)$.
    *   Store this index in `IPVINT(j, i) = \tilde{\phi}`.
    *   Mark this $\tilde{\phi}$-vertex as a "key" vertex if $IA(ip2) = 1$ [S1].
    *   Increment `NIPVINT(j)`.

#### Step 4: Arrangement of $\tilde{\phi}$-vertices
This step orders the $\tilde{\phi}$-vertices into polygons. It assumes an anticlockwise order when viewed from the outside of the region with positive scalar field ($IA=1$) [S1].

1.  Initialize polygon counter $k=1$ and vertex index within polygon $i_k=1$.
2.  Select the first unassigned $\tilde{\phi}$-vertex index as the start of the first polygon: `IPVISO(k, 1) = 1` (assuming index 1 is unassigned, or finding the first unassigned) [S1].
3.  Loop while there are unassigned $\tilde{\phi}$-vertices:
    *   Let current vertex index be `curr = IPVISO(k, i_k)`.
    *   Find the face boundary $j$ and edge index $i'$ such that `IPVINT(j, i') == curr` AND `curr` is marked as a key vertex [S1].
    *   The next vertex in the polygon is the previous vertex on that face boundary: `prev_idx = IPVINT(j, i'-1)` (with wrap-around modulo `NIPVINT(j)`) [S1].
    *   If `prev_idx` is not the start vertex of the current polygon (`IPVISO(k, 1)`):
        *   Increment $i_k$.
        *   Set `IPVISO(k, i_k) = prev_idx`.
        *   Mark `prev_idx` as assigned.
    *   Else (loop closed):
        *   If there are still unassigned $\tilde{\phi}$-vertices:
            *   Increment $k$.
            *   Set $i_k = 1$.
            *   Find the next unassigned $\tilde{\phi}$-vertex index.
            *   Set `IPVISO(k, 1) = next_unassigned`.
        *   Else:
            *   Terminate loop.

#### Step 5: Positioning by interpolation
For each $\tilde{\phi}$-vertex with global index $\tilde{\phi}$, located on the edge between vertices $ip1$ and $ip2$:
$$ \tilde{\mathbf{x}}_{\tilde{\phi}} = \mathbf{x}_{ip2} - \frac{\phi_{ip2} - \tilde{\phi}}{\phi_{ip2} - \phi_{ip1}} (\mathbf{x}_{ip2} - \mathbf{x}_{ip1}) $$
where $\mathbf{x}_{ip1}, \mathbf{x}_{ip2}$ are the 3D positions and $\phi_{ip1}, \phi_{ip2}$ are the scalar values [S1].

### Pseudocode

```python
def extract_isosurface_arbitrary_polyhedra(cells, vertices, scalar_field, isovalue):
    """
    cells: List of cells. Each cell is a list of faces. Each face is a list of vertex indices.
    vertices: List of 3D position vectors.
    scalar_field: List of scalar values corresponding to vertices.
    isovalue: The threshold value for the isosurface.
    Returns: List of polygons. Each polygon is a list of 3D position vectors.
    """
    
    # Step 1: Tagging
    # IA[ip] = 1 if scalar_field[ip] > isovalue, else 0
    # Using strict inequality to prevent division by zero in interpolation
    IA = [1 if s > isovalue else 0 for s in scalar_field]
    
    # Step 2: Cell Selection
    # Identify cells where max(scalar) > isovalue and min(scalar) < isovalue
    selected_cells = []
    for cell in cells:
        cell_vertices = []
        for face in cell:
            cell_vertices.extend(face)
        cell_scalars = [scalar_field[v] for v in cell_vertices]
        if max(cell_scalars) > isovalue and min(cell_scalars) < isovalue:
            selected_cells.append(cell)
            
    # Data structures for Step 3
    # Global counter for phi-vertices
    phi_vertex_count = 0
    # Map edge (min(ip1, ip2), max(ip1, ip2)) -> phi_index
    edge_to_phi_index = {}
    # Map phi_index -> is_key (boolean)
    is_key_vertex = {}
    # Store intersected edges per face: face_idx -> list of phi_indices
    # Note: The algorithm processes face boundaries sequentially. 
    # We need to store the phi_index for each edge of each face to facilitate tracing.
    # Structure: face_boundary_list[face_idx][edge_idx] = phi_index
    face_boundary_phi_indices = []
    
    # Step 3: Insertion of phi-vertex indices
    for cell in selected_cells:
        current_face_phi_indices = []
        for face in cell:
            n_verts = len(face)
            face_phi_list = []
            for i in range(n_verts):
                ip1 = face[i]
                ip2 = face[(i + 1) % n_verts]
                
                # Check if edge is intersected
                if IA[ip1] != IA[ip2]:
                    # Normalize edge key to avoid double counting
                    edge_key = (min(ip1, ip2), max(ip1, ip2))
                    
                    if edge_key not in edge_to_phi_index:
                        phi_vertex_count += 1
                        edge_to_phi_index[edge_key] = phi_vertex_count
                        is_key_vertex[phi_vertex_count] = (IA[ip2] == 1)
                    else:
                        phi_vertex_count = edge_to_phi_index[edge_key] # Reuse existing
                    
                    face_phi_list.append(phi_vertex_count)
            
            current_face_phi_indices.append(face_phi_list)
        face_boundary_phi_indices.append(current_face_phi_indices)

    # Step 4: Arrangement of phi-vertices
    # We need to trace polygons within each cell.
    # The algorithm in [S1] describes a recursive tracing procedure.
    # We will implement it per cell.
    
    all_polygons = []
    
    for cell_idx, cell in enumerate(selected_cells):
        # Get phi indices for this cell's faces
        cell_face_phi = face_boundary_phi_indices[cell_idx]
        
        # Track assigned phi vertices for this cell
        assigned_phi = set()
        
        # Find first unassigned phi vertex in this cell
        # Flatten all phi indices in this cell
        cell_phi_indices = []
        for face_phi in cell_face_phi:
            cell_phi_indices.extend(face_phi)
        
        cell_phi_indices = list(set(cell_phi_indices)) # Unique
        
        k = 1
        while cell_phi_indices:
            # Find first unassigned
            start_phi = None
            for phi in cell_phi_indices:
                if phi not in assigned_phi:
                    start_phi = phi
                    break
            
            if start_phi is None:
                break
                
            # Start new polygon
            polygon_vertices = [start_phi]
            assigned_phi.add(start_phi)
            current_phi = start_phi
            
            # Trace loop
            while True:
                # Find face boundary j and edge index i' where IPVINT(j, i') == current_phi AND is_key
                found_next = False
                next_phi = None
                
                for j, face_phi in enumerate(cell_face_phi):
                    for i, phi in enumerate(face_phi):
                        if phi == current_phi and is_key_vertex.get(phi, False):
                            # This is a key vertex. The next vertex is the previous one in this face boundary.
                            # i' is i. Previous is i-1.
                            prev_i = (i - 1) % len(face_phi)
                            prev_phi = face_phi[prev_i]
                            
                            if prev_phi == start_phi:
                                # Loop closed
                                found_next = False
                                break
                            else:
                                next_phi = prev_phi
                                found_next = True
                                break
                    if found_next:
                        break
                
                if not found_next:
                    # Loop closed or no key vertex found (should not happen if logic is correct)
                    break
                
                assigned_phi.add(next_phi)
                polygon_vertices.append(next_phi)
                current_phi = next_phi
            
            # Convert phi indices to 3D positions
            polygon_3d = []
            for phi_idx in polygon_vertices:
                # Find which edge this phi_idx belongs to
                # We need to reverse lookup edge_to_phi_index
                # This is inefficient but correct for implementation from text.
                # In practice, store edge->pos during insertion.
                pos = get_position_from_phi_index(phi_idx, vertices, scalar_field, isovalue, edge_to_phi_index)
                polygon_3d.append(pos)
            
            all_polygons.append(polygon_3d)
            
            # Remove assigned from list
            for phi in assigned_phi:
                if phi in cell_phi_indices:
                    cell_phi_indices.remove(phi)

    return all_polygons

def get_position_from_phi_index(phi_idx, vertices, scalar_field, isovalue, edge_to_phi_index):
    """
    Helper to find the 3D position of a phi vertex given its global index.
    """
    # Find the edge corresponding to this phi index
    target_edge = None
    for edge, idx in edge_to_phi_index.items():
        if idx == phi_idx:
            target_edge = edge
            break
    
    if target_edge is None:
        raise ValueError("Phi index not found")
        
    ip1, ip2 = target_edge
    
    # Interpolation formula
    # x_tilde = x_ip2 - (phi_ip2 - isovalue) / (phi_ip2 - phi_ip1) * (x_ip2 - x_ip1)
    x_ip1 = vertices[ip1]
    x_ip2 = vertices[ip2]
    phi_ip1 = scalar_field[ip1]
    phi_ip2 = scalar_field[ip2]
    
    # Strict inequality ensures phi_ip2 != phi_ip1
    t = (phi_ip2 - isovalue) / (phi_ip2 - phi_ip1)
    
    # Vector subtraction
    diff = [x_ip2[i] - x_ip1[i] for i in range(3)]
    scaled_diff = [t * d for d in diff]
    
    pos = [x_ip2[i] - scaled_diff[i] for i in range(3)]
    return pos
```

### Parameters and Edge Cases
*   **Isovalue ($\tilde{\phi}$):** Typical value is $0$ for signed distance fields or volume fractions [S1].
*   **Division by Zero:** Prevented by using strict inequalities ($IA(ip)=1$ if $\phi_{ip} > \tilde{\phi}$) to determine intersected edges. This ensures one vertex is strictly above and one strictly below $\tilde{\phi}$, so $\phi_{ip2} \neq \phi_{ip1}$ [S1].
*   **Double-Counting:** Handled by checking if an edge was previously visited during the sequential traversal of face boundaries. If already visited, the existing index is reused [S1].
*   **Ambiguities:** Discrete data may introduce ambiguities (e.g., interpolation issues). The method handles this via general tracing rules rather than configuration tables, ensuring consistent results even in ambiguous configurations that cause holes in Marching Cubes [S1].
*   **Non-Planar Polygons:** The resulting isopolygons may be non-planar. Most visualization applications can handle these, or they can be decomposed into triangles [S1].

## Subtopics

### [Livnat et al. algorithm for unstructured tetrahedral grids](1321-livnat-et-al-algorithm-for-unstructured-tetrahedral-grids.md)
This method extracts isosurfaces from unstructured 3D scalar fields defined on tetrahedral meshes by streaming cells directly into graphics hardware, computing triangles during rendering time without storing them explicitly. It sets itself apart from CPU-based extraction by leveraging vertex shaders for immediate feedback on isovalue changes, and from brute-force GPU methods by optionally using a hybrid CPU/GPU interval tree to pre-select intersecting cells, achieving up to 7x speedup over brute-force GPU rendering. Unlike structured grid methods (e.g., [Marching Cubes](52-marching-cubes.md)), it handles arbitrary tetrahedral connectivity by processing each cell's vertices through a vertex program that classifies them relative to the isovalue and outputs intersection points directly.

### [Performance Optimization via Lookup Table](1448-performance-optimization-via-lookup-table.md)
This method accelerates isosurface extraction on arbitrary polyhedral grids by replacing on-the-fly topological analysis with rapid table lookups. It solves the problem of high computational cost in general cell geometries by pre-computing vertex connectivity for all possible sign configurations. Unlike the standard [Marching Cubes](52-marching-cubes.md) which relies on a fixed 256-entry table for cubes, this approach is geometry-agnostic, allowing the same optimization strategy to be applied to arbitrary cell types.

## Operating characteristics
*   **Time Complexity:** The method is generally slower than optimized [Marching Cubes](52-marching-cubes.md) due to the lack of pre-computed lookup tables for arbitrary geometries. On an iMac Pro (2017) with 2.3 GHz Intel Xeon W, gcc -O3, the proposed method is on average 1.8 times slower than Marching Cubes with an extended lookup table (21 patterns) [S1].
*   **Parallelization:** The algorithm can be parallelized using the OpenMP API to speed up operations over grids, achieving up to a 6x speedup with all available threads [S1].
*   **Memory:** Requires storage for cell geometry, scalar field, and intermediate structures for edge intersection tracking and polygon tracing.
*   **Strengths:** Handles arbitrary polyhedral grids (convex/non-convex, planar/non-planar faces) without cell decomposition. Avoids topological inconsistencies (holes, non-2-manifold surfaces) common in Marching Cubes on ambiguous faces.
*   **Limitations:** Slower than lookup-table-based methods on regular grids. Produces non-planar polygons which may require decomposition for some rendering pipelines.
*   **When to use:** When working with unstructured or arbitrary polyhedral grids where topological consistency is critical and cell decomposition (e.g., Marching Tetrahedra) is undesirable or too costly.
*   **When not to use:** When maximum performance on regular hexahedral grids is required and topological ambiguities are not a concern (use [Marching Cubes](52-marching-cubes.md)).

## Background
The method was proposed to address the limitations of standard [Marching Cubes](52-marching-cubes.md) and [Marching Tetrahedra](52-marching-tetrahedra.md) when applied to complex unstructured grids. Marching Cubes suffers from topological inconsistencies in ambiguous configurations, while Marching Tetrahedra requires decomposing complex polyhedral cells into tetrahedra, adding computational cost [S1]. The method is implemented in the open-source library `isoap` (GPLv3 license) for interface reconstruction in Volume of Fluid (VOF) methods, CFD visualization, and medical imaging [S1]. It is used in advanced PLIC (Piecewise Linear Interface Calculation) schemes and for visualization with conventional graphics-rendering tools [S1].
