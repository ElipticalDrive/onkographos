# Modified Marching Cubes with Triangle Decimation

Also called: 3D Isosurface Generation (Marching Cubes), Marching Cubes with Decimation

## Overview
This method generates an isosurface from a 3D scalar field using a modified Marching Cubes algorithm that explicitly resolves topological ambiguities and reduces polygon count via triangle decimation [S1, unofficial]. It differs from standard Marching Cubes by adding a post-processing decimation step that collapses triangles with large aspect ratios and re-triangulates, and by using harmonic weighted averages for vertex normals [S1, unofficial]. It builds on [Marching Cubes Lookup and Configuration](2518-marching-cubes-lookup-and-configuration.md) for the base surface extraction.

## How it works
**Inputs:**
*   A 3D scalar field defined on a structured grid (FDS grid).
*   An isovalue $L$.
*   Data uncertainty bounds $\Delta T$ for each grid node.

**Outputs:**
*   A mesh of triangles representing the isosurface.
*   Vertex positions and associated normal vectors.

**Data Structures:**
*   **Cube Vertices:** 8 corners per voxel, indexed 0–7. The indexing must match the convention used by the parent article's lookup tables [S1, S12, unofficial].
*   **Case Index:** An 8-bit integer ($0 \dots 255$) derived from the scalar values at the 8 corners relative to $L$.
*   **Triangle List:** Stores vertex coordinates and edge indices.

**Algorithm Steps:**

1.  **Grid Partitioning:** Split the region to be contoured into cubes aligned with the underlying grid [S1, unofficial].
2.  **Case Index Calculation:** For each cube:
    *   Number corners 0 to 7 [S1, unofficial].
    *   For each corner $i$, assign bit $i$ of the case index $C$ to 1 if the scalar value $V_i > L$, and 0 otherwise [S1, unofficial].
    *   Use $C$ to look up the triangulation configuration in the `triangleTable` from the parent article [S1, S12, unofficial].
3.  **Triangulation:** Generate triangles for the cube surface using the lookup table, storing vertex locations and edge numbers [S1, unofficial].
4.  **Triangle Decimation:** Reduce the number of triangles by eliminating small triangles with large aspect ratios [S1, unofficial].
    *   Identify triangles where two or more vertices are closest to the same grid node [S1, unofficial].
    *   Remove these triangles.
    *   Create a new vertex at the average coordinates of the removed vertices [S1, unofficial].
    *   Re-triangulate the affected region using this new vertex [S1, unofficial].
5.  **Normal Estimation:** Calculate vertex normals using a harmonic weighted average based on triangle area [S1, unofficial].

**Formulas:**

*   **Uncertainty Bound:** The uncertainty in isosurface location $\Delta x$ between two node data value pairs $(x_1, T_1)$ and $(x_2, T_2)$ is bounded by [S1, unofficial]:
    $$ \left| \frac{\Delta x}{x_2 - x_1} \right| \leq \frac{\max(|\Delta T_1|, |\Delta T_2|)}{|T_2 - T_1|} $$
    where $\Delta T_1$ and $\Delta T_2$ are the uncertainties in $T_1$ and $T_2$ at $x_1$ and $x_2$ respectively.

*   **Vertex Normal:** The averaged normal vector $V_i$ for vertex $i$ is determined by summing over all triangles $n$ connected to vertex $i$ [S1, unofficial]:
    $$ V_i = \sum_n \frac{U_n}{A_n} / \sum_n \frac{1}{A_n} = \sum_n \frac{u_n \times v_n}{\|u_n \times v_n\|^2} / \sum_n \frac{1}{\|u_n \times v_n\|} $$
    where for the $n$-th triangle, $u_n$ and $v_n$ are two sides, $A_n = \|u_n \times v_n\|$ is the triangle area, and $U_n = u_n \times v_n / A_n$ is a unit vector normal to the triangle.

**Edge Cases and Pitfalls:**
*   **Ambiguities:** Standard Marching Cubes has ambiguous cases (46, 47, 98, 99, 210, 213, 214, 215). This method claims to "remove ambiguities" [S1, unofficial], but the specific resolution technique (e.g., topological healing, neighbor consistency) is not detailed in the provided notes beyond the decimation step. Implementers must ensure the lookup table or a post-processing step handles these saddle points to prevent cracks [S7, S8, unofficial].
*   **Precision:** Linear interpolation assumes smooth fields. High uncertainty $\Delta T$ leads to larger positional error $\Delta x$ [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Dominated by the Marching Cubes pass $O(N)$ where $N$ is the number of voxels, plus the decimation pass which requires spatial queries to find "closest grid nodes" and re-triangulation.
*   **Memory Complexity:** $O(M)$ where $M$ is the number of output triangles. Decimation reduces $M$ compared to standard MC.
*   **Strengths:** Reduces storage requirements and improves visual quality by removing high-aspect-ratio triangles [S1, unofficial]. Harmonic normals provide smoother shading than flat normals.
*   **Limitations:** The decimation logic ("two or more vertices closest to the same node") is vague and may be difficult to implement robustly without additional spatial indexing [S1, unofficial]. Ambiguity handling is claimed but not detailed.

## Background
This method is described in the Smokeview Technical Reference Guide, used for visualizing Fire Dynamics Simulation (FDS) data [S1, unofficial]. It modifies the original Marching Cubes algorithm [15] to address visual quality and storage efficiency in the context of fire simulation data.
