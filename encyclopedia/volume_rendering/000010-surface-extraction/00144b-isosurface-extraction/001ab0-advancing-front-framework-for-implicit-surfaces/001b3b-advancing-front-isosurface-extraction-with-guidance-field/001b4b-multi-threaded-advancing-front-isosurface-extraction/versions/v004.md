# Multi-threaded Advancing Front Isosurface Extraction

Also called: Parallel Advancing Front Isosurface Extraction

## Overview
This method parallelizes the Advancing Front Isosurface Extraction with Guidance Field [947-advancing-front-isosurface-extraction-with-guidance-field.md] by distributing the work of projecting points onto the advancing fronts across a set of worker threads [S1]. Compared to Marching Cubes [Marching Cubes](Marching Cubes.md) or Marching Tetrahedra [Marching Tetrahedra](Marching Tetrahedra.md), the algorithm is slower but generates meshes requiring negligible or no downstream processing, unlike MC/MT results [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** An implicit function $f(\mathbf{x})$ defined over a domain, a target isovalue $k$, and a guidance field $g(\mathbf{x})$ computed from parameters $\rho$ and $\eta$ [S1]. The function must admit well-defined gradient $\nabla f(\mathbf{x})$ and Hessian $H_f(\mathbf{x})$ [S1].
*   **Output:** A triangular mesh approximating the isosurface $f(\mathbf{x}) = k$ with bounded distance error and bounded normal error [S1].

**Data Structures:**
*   **Front:** A shared set of vertices and edges defining the extracted surface boundary. It requires thread-safe access for concurrent updates [G].
*   **Task Queue:** A shared collection of candidate points awaiting projection onto the front [G].
*   **Thread Pool:** A fixed set of $N$ worker threads that independently pop tasks, project points, and update the front [S1].

**Parameters:**
*   **Thread Count ($N$):** The number of worker threads. Experiments use $N=4$ [S1].
*   **$\rho, \eta$:** Guidance field parameters controlling edge length constraints based on surface curvature [S1].

**Numbered Steps:**
1.  **Parallel Guidance Field and Culling:** Compute the guidance field $g(\mathbf{x})$ for the domain and perform culling entirely in parallel [S1].
2.  **Task Distribution:** Distribute the work of projecting points onto the advancing fronts across the worker threads [S1].
3.  **Parallel Projection:** Each worker thread projects candidate points onto the advancing fronts to satisfy $f(\mathbf{x}) \approx k$ [S1].
4.  **Synchronization:** Threads synchronize when modifying the shared front structure; advancing front algorithms are mostly local, allowing decisions and actions to be taken independently of the reconstruction of distant surface parts [S1].
5.  **Termination:** The process repeats until the front is closed or no valid points remain in the queue [G].

**Pseudocode:**
```python
import threading
import queue

def multi_threaded_advancing_front_extraction(f, k, g_func, N_threads, domain_bounds, grid_spacing):
    # 1. Parallel guidance field computation and culling [S1]
    candidates = []
    for x in range(domain_bounds[0][0], domain_bounds[0][1], grid_spacing):
        for y in range(domain_bounds[1][0], domain_bounds[1][1], grid_spacing):
            for z in range(domain_bounds[2][0], domain_bounds[2][1], grid_spacing):
                point = (x, y, z)
                # Culling threshold not specified in sources [G]
                if g_func(point) < 2.0:
                    candidates.append(point)

    # 2. Initialize front and task queue [G]
    front = []
    task_queue = queue.Queue()
    for p in candidates:
        task_queue.put(p)
    front_lock = threading.Lock()

    def worker():
        while not task_queue.empty():
            try:
                point = task_queue.get_nowait()
            except queue.Empty:
                break

            # 3. Parallel Projection: Project point to isosurface f(x) = k [S1]
            # Projection algorithm details not specified in sources [G]
            projected_point = point

            # Update front and distribute new tasks [S1]
            with front_lock:
                front.append(projected_point)
                # Neighbor generation strategy not specified in sources [G]

    # 4. Distribute work across worker threads [S1]
    threads = []
    for _ in range(N_threads):
        t = threading.Thread(target=worker)
        threads.append(t)
        t.start()
    for t in threads:
        t.join()

    return front
```

**Edge Cases and Pitfalls:**
*   **Non-Regular Surfaces:** The method requires the implicit function to admit a well-defined gradient and Hessian. Sharp corners do not admit a regular isosurface representation (where $f(\mathbf{x}) = k$ and $\nabla f(\mathbf{x}) \neq 0$) [S1].
*   **Thread Safety:** The front structure must be protected during concurrent updates [G].
*   **Precision:** High-order meshes (degree ~10) may have high-frequency features. The method is oblivious to the underlying mesh but relies on accurate gradient/Hessian computation [S1].

## Subtopics

### Advancing Front Isosurface Extraction with Guidance Field
The single-threaded parent method [947-advancing-front-isosurface-extraction-with-guidance-field.md] that uses a scalar field $g(\mathbf{x})$ to constrain edge lengths based on surface curvature and user parameters [S1]. Choose this when parallelization is unnecessary or when running on a single core.

### Advancing Front Meshing with Curvature Guidance
A method for generating high-quality triangle meshes using a curvature-based guidance field [S2, unofficial]. It modifies the guidance field to minimize both geometric error and the number of required samples [S2, unofficial]. Choose this when minimizing sample count while preserving geometric accuracy is prioritized over pure speed.

### Marching Cubes
A grid-based polygonization method [Marching Cubes](Marching Cubes.md). Choose this when real-time performance is critical and high mesh quality is secondary.

### Marching Tetrahedra
A variant of Marching Cubes that avoids topological ambiguity by subdividing cubes into tetrahedra [Marching Tetrahedra](Marching Tetrahedra.md). Choose this when topological correctness on grid data is required without downstream processing.

## Operating characteristics
*   **Time Complexity:** The algorithm is slower than Marching Cubes (MC) or Marching Tetrahedra (MT) implementations [S1]. Running times are typically several minutes for larger datasets [S1].
*   **Memory Complexity:** Not given in the sources [G].
*   **Measured Performance:** Experiments were conducted on a PC with two dual-core AMD Opteron processors at 2.25GHz, 4GB RAM, SuSE Linux 10.0 [S1]. Four threads were used for all experiments [S1]. Running times include 5:18 for Aneurism BS, 12:16 for Engine BS, and 5:50 for Skull CR [S1].
*   **Scaling:** The method scales with the number of threads by distributing the projection work. The source notes that advancing front algorithms are "mostly local," which facilitates parallelization [S1].
*   **Strengths:** Generates high-quality meshes with bounded distance and normal error. 99% of triangles have quality at least half of optimal, and the median quality is within 3% of optimal across different models, $\rho$, $\eta$, and surface definitions [S1]. Triangle counts are often less than MC. The meshes require negligible or no downstream processing [S1].
*   **Limitations:** Slower than MC/MT. Requires well-defined gradient and Hessian. Not suitable for sharp corners [S1].
*   **When to Use:** When high-quality, high-fidelity triangulation is required, and the implicit function is smooth (band-limited) [S1].
*   **When Not to Use:** When real-time performance is critical, or when the input data contains sharp corners or non-smooth features that violate the regular isosurface assumption [S1].

## Background
The method is described in "High-Quality Extraction of Isosurfaces from Regular and Irregular Grids" [S1]. It builds on the Advancing Front Framework for Implicit Surfaces and specifically the guidance-field-based approach [S1]. The authors implemented the algorithm in C++ and tested it on various models including Catmull-Rom splines and B-splines, as well as unstructured meshes like Nielson interpolation and MLS approximation [S1]. The technique is generalizable to any surface formulation that admits gradient and Hessian computation, making it applicable to high-order meshes (typically degree ~10) [S1].
