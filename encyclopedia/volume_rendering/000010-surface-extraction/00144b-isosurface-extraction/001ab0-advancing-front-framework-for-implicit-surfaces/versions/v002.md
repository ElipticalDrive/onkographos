# Advancing Front Framework for Implicit Surfaces
Also called: Continuation, Surface Tracking

## Overview
The Advancing Front Framework is an isosurface extraction method that constructs a triangulated mesh by growing a front across the implicit surface, starting from a seed point and extending it edge-by-edge [S1]. Unlike numerical simulation meshing which starts with well-defined domain representations and increases primitive dimension, this method operates without a pre-defined description of volume components, requiring the algorithm to dynamically chart the reconstructed surface [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** An implicit surface defined by a scalar field $f(\mathbf{x}) = 0$, where the gradient $\nabla f$ and Hessian $H_f$ are non-zero everywhere [S1]. A seed point on the surface [S1].
*   **Output:** A triangulated mesh representing the isosurface [S1].

**Data Structures:**
*   **Front:** A list of edges forming the boundary of the generated mesh [S1]. Exact field layouts, sizes, and bit packing are not given in the sources.
*   **Mesh:** A collection of triangles [S1]. Exact field layouts, sizes, and bit packing are not given in the sources.

**Algorithm Steps:**
1.  **Initialization:** Place the seed point on the surface and create an initial front edge set [G].
2.  **Front Selection:** Choose an edge from the current front [S1].
3.  **Triangle Construction:** Create a new triangle attached to the chosen edge [S1].
4.  **Intersection Handling:** If the new triangle causes the front to intersect itself, split it into two separate fronts [S1]. If it intersects a different front, merge the two fronts [S1]. If no intersection occurs, add the triangle to the mesh and update the front by removing the chosen edge and adding the new edges [G].
5.  **Termination:** Repeat steps 2–4 until the front is empty or the surface is fully enclosed [G].

## Background
The advancing front technique originated in the mesh generation community for numerical simulation, where it was used to create high-quality meshes for well-defined domains [S1]. The application to implicit surfaces, where no pre-defined volume description exists, was a significant extension [S1]. Key references include work by Borouchaki et al. on gradation control and other early works on implicit surface triangulation [S1].
