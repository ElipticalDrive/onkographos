# Interior Volume Tetrahedralization

Also called: dual contouring interior tets, pyramid subdivision tets

## Overview
Interior Volume Tetrahedralization is a mesh generation technique that converts the interior of a discretized grid volume into a tetrahedral mesh by subdividing pyramids around surface edges and connecting inside cubes to adjacent cells [S1, unofficial]. It differs from standard Marching Tetrahedra by explicitly generating a volumetric tetrahedralization rather than just an isosurface triangle mesh, and it differs from Dual Contouring by handling the interior volume connectivity via a deterministic lookup of shared faces between adjacent cubes [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Input**: A scalar field $S$ defined on a regular 3D grid with vertices $V_{grid}$, and optionally a gradient function $G$.
- **Output**: A tetrahedral mesh consisting of vertices $V_{mesh}$ and tetrahedra indices $T_{mesh}$.

**Data Structures**
- `cube_fx8`: A tensor of shape $(N_{cubes}, 8)$ containing the indices of the 8 grid vertices for each cube.
- `occ_n`: Boolean tensor of shape $(N_{verts})$, where `occ_n[i]` is true if $S[i] < 0$.
- `occ_fx8`: Boolean tensor of shape $(N_{cubes}, 8)$, derived from `occ_n` using `cube_fx8`.
- `surf_cubes`: Boolean mask of cubes intersecting the surface.
- `inside_cubes`: Boolean mask of cubes where all 8 vertices have negative SDF values.
- `vd_idx_map`: Lookup table mapping cube cases and edge indices to dual vertex indices.
- `tet_table`, `dir_faces_table`, `edge_dir_table`: Precomputed lookup tables for deterministic tetrahedralization [S1, unofficial].

**Steps**

1.  **Identify Surface and Inside Cubes**:
    Compute occupancy for all grid vertices:
    $$ occ\_n = S < 0 $$
    Map occupancy to cubes:
    $$ occ\_fx8 = occ\_n[cube\_fx8.reshape(-1)].reshape(-1, 8) $$
    Identify surface cubes (mixed signs):
    $$ occ\_sum = \sum_{j=0}^{7} occ\_fx8[:, j] $$
    $$ surf\_cubes = (occ\_sum > 0) \land (occ\_sum < 8) $$
    Identify inside cubes (all negative):
    $$ inside\_cubes = (occ\_sum == 8) $$

2.  **Generate Surface Vertices and Mapping**:
    Identify unique surface-intersecting edges. For each cube, determine which of its 12 edges intersect the surface. Create a mapping from grid vertices to new mesh vertex indices.
    $$ mapping\_inside\_verts[occ\_n] = \text{arange}(occ\_n.sum()) + V_{mesh}.shape[0] $$
    *Note: The exact generation of surface vertices $V_{surf}$ involves linear interpolation or dual contouring optimization at zero-crossings. If gradients are available, vertices are optimized to minimize deviation [S1, unofficial].*

3.  **Generate Surface Tetrahedra (Pyramid Subdivision)**:
    For each surface cube, form pyramids around surface edges.
    - Identify edges connecting vertices with different signs.
    - Connect one grid vertex to 4 mesh vertices corresponding to that edge.
    - Split the pyramid into 2 tetrahedra.
    $$ T_{surface} = \text{cat}([faces, inside\_verts\_idx.unsqueeze(-1)], -1) $$
    *Note: The specific triangulation of the surface patch depends on the cube case (1-255). The method uses `vd_idx_map` to resolve dual vertex indices for the pyramid apexes.*

4.  **Compute Inside Cube Centers**:
    For each inside cube, compute the center vertex:
    $$ inside\_cubes\_center = \text{mean}(V_{grid}[cube\_fx8[inside\_cubes]], dim=1) $$
    Assign new indices to these centers starting after inside vertices.

5.  **Build Edge-to-Vertex Lookup**:
    Construct `edge_center_vertex_idx` of shape $(N_{edges}, 13)$.
    - Indices 0-11: Dual vertex indices from `vd_idx_map` for surface cubes.
    - Index 12: Inside cube center indices.

6.  **Identify Shared Faces and Build Inside Tetrahedra**:
    - Identify shared faces between adjacent cubes using direction tables:
      $$ shared\_faces\_4x2 = dir\_faces\_table[edge\_dir].reshape(-1) $$
    - Use a case lookup table to find the mesh vertex on the shared face:
      $$ vertex\_on\_face = tet\_table[cases, shared\_faces\_4x2] $$
    - Filter valid inside tetrahedra where both quad edges are valid (not -1):
      $$ mask = (\text{quad\_edge} == -1).sum(-1) == 0 $$
    - Combine with inside edge indices:
      $$ T_{inside} = \text{cat}([quad\_edge, inside\_edge], -1)[mask] $$

7.  **Finalize Mesh**:
    Concatenate surface and inside tetrahedra:
    $$ T_{mesh} = \text{cat}([T_{surface}, T_{inside}]) $$
    Concatenate all vertex types:
    $$ V_{mesh} = \text{cat}([V_{surf}, inside\_verts, inside\_cubes\_center]) $$

**Pseudocode**
```python
def interior_volume_tetrahedralization(S, cube_fx8, grid_vertices, grad_func=None):
    # 1. Identify cubes
    occ_n = S < 0
    occ_fx8 = occ_n[cube_fx8.reshape(-1)].reshape(-1, 8)
    occ_sum = occ_fx8.sum(dim=1)
    surf_cubes = (occ_sum > 0) & (occ_sum < 8)
    inside_cubes = (occ_sum == 8)
    
    # 2. Surface Vertices (Simplified: Linear Interpolation)
    # In practice, this involves identifying unique edges and interpolating zero-crossings
    # or optimizing dual vertices if grad_func is provided.
    # For this implementation, we assume a helper `generate_surface_vertices` exists
    # which returns V_surf and a mapping from grid edges to vertex indices.
    V_surf, edge_to_vd_idx = generate_surface_vertices(S, cube_fx8, grid_vertices, grad_func)
    
    # 3. Inside Vertices (Grid Vertices mapped)
    # Map inside grid vertices to new indices
    inside_vert_indices = torch.arange(occ_n.sum()) + V_surf.shape[0]
    mapping_inside_verts = torch.full_like(occ_n, -1, dtype=torch.long)
    mapping_inside_verts[occ_n] = inside_vert_indices
    inside_verts = grid_vertices[occ_n]
    
    # 4. Inside Cube Centers
    inside_cube_centers = grid_vertices[cube_fx8[inside_cubes]].mean(dim=1)
    inside_center_indices = torch.arange(inside_cube_centers.shape[0]) + V_surf.shape[0] + inside_verts.shape[0]
    
    # 5. Surface Tetrahedra
    # For each surf_cubes, determine the case and generate tets
    # This requires a detailed lookup table based on the cube case and edge intersections
    T_surface = generate_surface_tetrahedra(surf_cubes, cube_fx8, edge_to_vd_idx, grid_vertices)
    
    # 6. Inside Tetrahedra
    # Build edge-to-vertex lookup for adjacent cubes
    # Identify shared faces and use tet_table to resolve connectivity
    T_inside = generate_inside_tetrahedra(inside_cubes, cube_fx8, inside_center_indices, inside_vert_indices)
    
    # 7. Concatenate
    T_mesh = torch.cat([T_surface, T_inside])
    V_mesh = torch.cat([V_surf, inside_verts, inside_cube_centers])
    
    return V_mesh, T_mesh
```

**Parameters**
- `tet_table`, `dir_faces_table`, `edge_dir_table`, `adj_pairs`, `cube_edges`: Precomputed lookup tables mapping edge directions, cube cases, and adjacency pairs to mesh vertex indices for deterministic tetrahedralization [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Linear with respect to the number of grid cells, $O(N_{cells})$, due to the local nature of the tetrahedralization and lookup tables.
- **Memory Complexity**: Linear with respect to the number of grid cells, $O(N_{cells})$, for storing the tetrahedra and vertices.
- **Strengths**: Produces a valid volumetric tetrahedral mesh suitable for finite element analysis or volume rendering. It handles complex topologies and is deterministic.
- **Limitations**: The method is specific to regular grids. It requires precomputed lookup tables which can be large. The quality of the tetrahedra depends on the distribution of the surface and the interpolation method used for surface vertices.
- **When to use**: When a volumetric tetrahedral mesh is required from a scalar field on a regular grid.
- **When not to use**: For unstructured grids or when only a surface mesh is needed (use Marching Cubes or Dual Contouring).

## Background
The method is described in the context of isosurface extraction comparison, specifically as a technique for generating interior volume tetrahedralizations [S1, unofficial]. It builds on the principles of dual contouring and marching tetrahedra, extending them to handle the interior volume connectivity.
