# Marching Cubes with QEF Vertex Optimization

Also called: MC-QEF, Optimized Marching Cubes

## Overview
Marching Cubes with QEF Vertex Optimization is a surface extraction method that computes vertex positions using a Quadric Error Function (QEF) minimization for ambiguous cases, while using a 2D linear/binomial search for non-ambiguous cases, to produce a watertight mesh from a voxel grid [S1, unofficial]. It builds on [Isosurface extraction](30-isosurface-extraction.md) by replacing the standard linear interpolation of classic Marching Cubes with a geometric optimization step that minimizes distance to supporting planes, thereby reducing artifacts in ambiguous topological configurations [S1, unofficial].

## How it works
The method processes voxel indices by splitting them into two groups based on their position in the flattened grid index space: a "fast" group for non-ambiguous cases and a "slow" group for ambiguous cases requiring QEF optimization [S1, unofficial].

**Inputs and Outputs:**
*   **Input:** A 3D occupancy grid `occs` (binary or scalar), grid dimensions `GRID`, `GRID2`, `GRID3` (where `GRID3 = GRID * GRID * GRID`), and an isovalue threshold (implicit in occupancy).
*   **Output:** A list of vertex positions `val_pnts` and connectivity information derived from the Marching Cubes lookup tables.

**Data Structures:**
*   `occs`: 3D array of occupancy bits.
*   `pidx1`: Flattened indices of voxels to process.
*   `val_pnts`: Array to store computed vertex positions.
*   `qvntab`, `pfvtab`, `vitogi`, `axd_tab`, `ax0_tab`, `ax1_tab`, `cas_tab`, `amb_chks`: Precomputed lookup tables for Marching Cubes topology, vertex coordinates, edge indices, axis directions, and ambiguity checks [S1, unofficial].
*   `cstrtab`: Constraint planes for ray intersection [S1, unofficial].

**Algorithm Steps:**

1.  **Filter Indices:** Separate `pidx1` into `pidx1_fast` (indices in range `[3*GRID3, 9*GRID3)`) and `pidx1_slow` (indices `>= 9*GRID3`) [S1, unofficial]. Initialize `start_idx` to 0.

2.  **Process Fast Group (Non-Ambiguous):**
    For each index in `pidx1_fast`:
    a.  Compute the 8-neighbor occupancy pattern `val_` by summing weighted occupancy bits:
        $$val_ = occs[pidx3] + 2 \cdot occs[pidx3 + axis1] + 4 \cdot occs[pidx3 + axis0] + 8 \cdot occs[pidx3 + axis2]$$
        where `pidx3` is the 3D coordinate, and `axis0`, `axis1` are direction vectors from lookup tables [S1, unofficial].
    b.  Apply ambiguity correction: If `amb_chks[pidx3]` is true, set `val_ = 15 - val_` [S1, unofficial].
    c.  Compute vertex positions using `_2d_search(pidx3, axdir, axis0, axis1, val_, cases)` [S1, unofficial].
    d.  Store results in `val_pnts` at `start_idx` and increment `start_idx` by the count of processed vertices [S1, unofficial].

3.  **Process Slow Group (Ambiguous):**
    For each index in `pidx1_slow`:
    a.  Call `_solve_QEF(pidx3, val_, cases)` where `cases` is derived from `pidx1 / GRID3 - 9` [S1, unofficial].
    b.  Store results in `val_pnts` at `start_idx` [S1, unofficial].

**Detailed QEF Solution (`_solve_QEF`):**

1.  **Retrieve Geometry:** For each vertex index `i` from 3 to 7, find indices `idx` where `qvntab[val_, cases] == i` [S1, unofficial]. Retrieve vertex coordinates `vtcs` from `pfvtab[val0_, cas, :2*i+1]` and edge indices `vitg` from `vitogi[vtcs]` [S1, unofficial].

2.  **Compute 3D Positions:** Calculate global positions `pnti` using grid offsets:
    $$pnti = vitg[:,:,3] \cdot GRID3 + (pid3[:,0] + vitg[:,:,0]) \cdot GRID2 + (pid3[:,1] + vitg[:,:,1]) \cdot GRID + (pid3[:,2] + vitg[:,:,2])$$
    Get global indices `pidx` and retrieve pre-computed vertex positions `vert = val_pnts[pidx]`. Add local offsets `vitg[:,:3]` to `vert` [S1, unofficial].

3.  **Compute QEF Normals:**
    a.  Extract vertex vectors: `_1vt = vert[:, 1::2]` [S1, unofficial].
    b.  Compute normals via cross products: `qnrm = cross(_1vt - vert[:, :-1:2], _1vt - vert[:, 2::2])` [S1, unofficial].
    c.  Compute centroid: `cntr = mean(_1vt, dim=1)` [S1, unofficial].
    d.  Normalize `qnrm`. Handle zero-length edges (degenerate cases) by checking against an `ERR` threshold; if degenerate, set normal to zero or handle via fallback [S1, unofficial].

4.  **Solve QEF System:**
    a.  Construct matrix `A` and vector `b`:
        $$A = \begin{bmatrix} qnrm \\ QEF\_REG \cdot I \end{bmatrix}, \quad b = \begin{bmatrix} \sum (\_1vt \cdot qnrm) \\ QEF\_REG \cdot cntr \end{bmatrix}$$
        where $I$ is the identity matrix and $QEF\_REG$ is a regularization constant [S1, unofficial].
    b.  Solve least squares: `qefr = lstsq(A, b).solution` [S1, unofficial].
    c.  If all normals are degenerate (`cndt` all true), use `cntr` instead of `qefr` [S1, unofficial].

5.  **Ray Intersection and Clamping:**
    a.  Compute ray direction `ctoq = qefr - cpnt` and length `leng` [S1, unofficial].
    b.  Compute intersection parameter `t` with constraint planes defined by `cstrtab` [S1, unofficial].
    c.  Concatenate boundary parameters `(1-cpnt)/ctoq` and `-cpnt/ctoq` with `t` [S1, unofficial].
    d.  Handle NaNs and negative values by setting `t` to `leng + SEP` [S1, unofficial].
    e.  Normalize by `leng` and clamp to `[0, 1]` [S1, unofficial].
    f.  Final vertex: `cpnt + t * ctoq` [S1, unofficial].

**Pseudocode:**

```python
def solve_qef_vertex_optimization(occs, pidx1, GRID, GRID2, GRID3, 
                                  axd_tab, ax0_tab, ax1_tab, cas_tab, 
                                  amb_chks, qvntab, pfvtab, vitogi, 
                                  cstrtab, ERR, QEF_REG, SEP):
    val_pnts = [] # List of vertex positions
    start_idx = 0
    
    # Split indices
    pidx1_fast = [p for p in pidx1 if 3 * GRID3 <= p < 9 * GRID3]
    pidx1_slow = [p for p in pidx1 if p >= 9 * GRID3]
    
    # Process Fast Group
    for pidx in pidx1_fast:
        pidx3 = pidx_to_pidx3(pidx)
        csidx = pidx // GRID3 - 3
        axdir = axd_tab[csidx]
        axis0 = ax0_tab[csidx]
        axis1 = ax1_tab[csidx]
        cases = cas_tab[csidx]
        axis2 = axis0 + axis1
        
        # Compute occupancy pattern
        val_ = (occs[pidx3[0], pidx3[1], pidx3[2]] +
                2 * occs[pidx3[0] + axis1[0], pidx3[1] + axis1[1], pidx3[2] + axis1[2]] +
                4 * occs[pidx3[0] + axis0[0], pidx3[1] + axis0[1], pidx3[2] + axis0[2]] +
                8 * occs[pidx3[0] + axis2[0], pidx3[1] + axis2[1], pidx3[2] + axis2[2]])
        
        # Ambiguity correction
        if amb_chks[pidx3]:
            val_ = 15 - val_
            
        # 2D Search for non-ambiguous cases
        verts = _2d_search(pidx3, axdir, axis0, axis1, val_, cases)
        
        # Store results
        for v in verts:
            val_pnts.append(v)
        start_idx += len(verts)

    # Process Slow Group
    for pidx in pidx1_slow:
        pidx3 = pidx_to_pidx3(pidx)
        csidx = pidx // GRID3 - 9
        cases = cas_tab[csidx] # Note: source uses pidx1/GRID3 - 9 for cases in slow group
        
        # Compute occupancy pattern (simplified, assuming similar structure)
        # In source, val_ is passed to _solve_QEF, derived from occupancy
        val_ = compute_occupancy_pattern(occs, pidx3) 
        
        verts = _solve_QEF(pidx3, val_, cases, qvntab, pfvtab, vitogi, 
                           cstrtab, ERR, QEF_REG, SEP, GRID, GRID2, GRID3)
        
        for v in verts:
            val_pnts.append(v)
        start_idx += len(verts)
            
    return val_pnts

def _solve_QEF(pidx3, val_, cases, qvntab, pfvtab, vitogi, cstrtab, ERR, QEF_REG, SEP, GRID, GRID2, GRID3):
    verts = []
    # Iterate vertex indices 3 to 7
    for i in range(3, 8):
        idx = find_idx(qvntab, val_, cases, i)
        if idx is None: continue
        
        vtcs = pfvtab[val_, cases, :2*i+1]
        vitg = vitogi[vtcs]
        
        # Compute 3D positions
        pnti = (vitg[:,:,3] * GRID3 + 
                (pidx3[:,0] + vitg[:,:,0]) * GRID2 + 
                (pidx3[:,1] + vitg[:,:,1]) * GRID + 
                (pidx3[:,2] + vitg[:,:,2]))
        
        # Get global indices and pre-computed positions
        pidx = get_global_indices(pnti)
        vert = val_pnts[pidx] # Assuming val_pnts is accessible or passed
        vert += vitg[:,:3]
        
        # Compute QEF normals
        _1vt = vert[:, 1::2]
        qnrm = cross(_1vt - vert[:, :-1:2], _1vt - vert[:, 2::2])
        cntr = mean(_1vt, dim=1)
        
        # Normalize
        leng = norm(qnrm, dim=1, keepdim=True)
        cndt = leng < ERR
        leng[cndt] = 1.0
        qnrm = qnrm / leng
        
        # Solve QEF
        A = cat([qnrm, QEF_REG * eye(3)])
        b = cat([sum(_1vt * qnrm, dim=1), QEF_REG * cntr])
        qefr = lstsq(A, b).solution
        
        # Fallback for degenerate normals
        if all(cndt):
            qefr = cntr
            
        # Ray intersection
        cpnt = get_centroid(pidx3) # Placeholder for cpnt definition
        ctoq = qefr - cpnt
        leng = norm(ctoq)
        
        # Compute t with constraints
        t = compute_intersection_t(ctoq, cstrtab)
        
        # Handle NaNs and negatives
        boundary_params = cat([(1-cpnt)/ctoq, -cpnt/ctoq])
        t = cat([boundary_params, t])
        t[isnan(t) | (t < 0)] = leng + SEP
        t = t / leng
        t = clamp(t, 0, 1)
        
        final_vert = cpnt + t * ctoq
        verts.append(final_vert)
        
    return verts
```

## Subtopics

### QEM-based Vertex Relocation
A vertex relocation method used in the Mesh Generation phase to move vertices to the isosurface, using the Quadric Error Metric (QEM) instead of full QEF minimization to reduce computational complexity and register usage on parallel hardware [S2, unofficial]. Unlike pseudoinverse QEF minimization which is complex and penalizes performance on parallel hardware due to register limits, QEM minimization is stable with supporting planes and produces accurate results sufficient for volume preservation [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** The method splits processing into two paths. The fast path uses 2D linear/binomial search, which is $O(1)$ per vertex. The slow path involves solving a least-squares system for QEF, which is more expensive but only applied to ambiguous cases [S1, unofficial].
*   **Memory Complexity:** Requires storage for occupancy grid, lookup tables, and vertex positions. The QEF step requires temporary storage for matrices $A$ and $b$ [S1, unofficial].
*   **Performance:** QEF minimization is complex and penalizes performance on parallel hardware due to register limits compared to simpler metrics [S2, unofficial]. QEM is a lighter alternative for volume preservation [S2, unofficial].
*   **Strengths:** Produces watertight meshes; handles ambiguous cases better than standard linear interpolation; preserves volume [S1, unofficial][S2, unofficial].
*   **Limitations:** Higher computational cost for ambiguous cases; register usage can be high on GPUs [S2, unofficial].
*   **When to use:** When high-quality surface reconstruction is needed for ambiguous topologies in voxel grids [S1, unofficial].
*   **When not to use:** When performance is critical and ambiguous cases are rare or can be approximated [S2, unofficial].

## Background
The method originates from the ODC (Octree-based Data Compression) project by KAIST Visual AI Group [S1, unofficial]. It was developed to improve surface extraction quality from voxel data by optimizing vertex positions using QEF [S1, unofficial]. The QEM-based variant was proposed for terrain visualization to reduce computational complexity on parallel hardware [S2, unofficial].
