# Marching Cubes with QEF Vertex Optimization

Also called: MC-QEF, Optimized Marching Cubes

## Overview
Marching Cubes with QEF Vertex Optimization is a surface extraction method that computes vertex positions using a Quadric Error Function (QEF) minimization for ambiguous cases, while using a 2D linear/binomial search for non-ambiguous cases, to produce a watertight mesh from a voxel grid [S1, unofficial]. It distinguishes itself from standard Marching Cubes by replacing the linear interpolation of vertex positions with geometric optimization in topologically ambiguous regions, thereby reducing artifacts and improving surface fidelity without the computational overhead of full dual contouring [S1, unofficial].

## How it works
The method processes a voxel grid by classifying cells into two groups based on their topological complexity: simple cases handled by fast 2D search and ambiguous cases handled by QEF optimization.

**Inputs and Outputs**
*   **Input:** A 3D occupancy grid `occs` (binary or scalar values indicating inside/outside), grid dimensions `GRID`, `GRID2`, `GRID3` (powers of 2), and an isovalue threshold.
*   **Output:** A list of vertex positions `val_pnts` and connectivity information (implied by the search results).

**Data Structures**
*   `occs`: 3D array of occupancy bits.
*   `pidx1`: Linear indices of active cells.
*   `pidx3`: 3D coordinates `(x, y, z)` of active cells.
*   `val_pnts`: Array storing computed vertex positions.
*   `qvntab`, `pfvtab`, `vitogi`, `cstrtab`, `axd_tab`, `cas_tab`: Lookup tables for QEF and connectivity (details depend on implementation, see [S1, unofficial]).

**Parameters**
*   `GRID`, `GRID2`, `GRID3`: Grid scaling factors.
*   `ERR`: Threshold for degenerate edge detection.
*   `QEF_REG`: Regularization weight for QEF least squares.
*   `SEP`, `VERTICAL_RANGE`, `HORIZNTL_RANGE`: Search range parameters.
*   `VERTICAL_LINEAR_SEARCH`, `VERTICAL_BINARY_SEARCH`, `HORIZNTL_LINEAR_SEARCH`, `HORIZNTL_BINARY_SEARCH`: Flags controlling search modes.

**Algorithm Steps**

1.  **Classification:** Filter voxel indices `pidx1` into two groups:
    *   Group 1 (Simple): Indices in range `[3*GRID3, 9*GRID3)`.
    *   Group 2 (Ambiguous): Indices `>= 9*GRID3`.
    *   Initialize `start_idx` to 0.

2.  **Process Group 1 (Simple Cases):**
    *   For each cell in Group 1, compute the 8-neighbor occupancy value `val_` by summing weighted occupancy bits:
        $$ val\_ = occs[pidx3] + 2 \cdot occs[pidx3+axis1] + 4 \cdot occs[pidx3+axis0] + 8 \cdot occs[pidx3+axis2] $$
    *   Apply ambiguity correction: If `tmp = amb_chks[pidx3]` is true, set `val\_ = 15 - val\_`.
    *   Compute vertex positions using `_2d_search(pidx3, axdir, axis0, axis1, val_, cases)` and store in `val_pnts` at `start_idx`.
    *   Increment `start_idx` by the count of processed cells.

3.  **Process Group 2 (Ambiguous Cases):**
    *   For each cell in Group 2, call `_solve_QEF(pidx3, val_, cases)` where `val_` is the integer occupancy pattern and `cases` is derived from `pidx1 / GRID3 - 9`.
    *   Store results in `val_pnts` at `start_idx`.

**Detailed QEF Solution (`_solve_QEF`)**

1.  **Retrieve Geometry:** For each vertex index `i` from 3 to 7, find indices `idx` where `qvntab[val_, cases] == i`. Retrieve vertex coordinates `vtcs` from `pfvtab[val0_, cas, :2*i+1]` and edge indices `vitg` from `vitogi[vtcs]`.
2.  **Compute 3D Positions:** Calculate positions `pnti` using grid offsets:
    $$ pnti = vitg[:,:,3] \cdot GRID3 + (pid3[:,0]+vitg[:,:,0]) \cdot GRID2 + (pid3[:,1]+vitg[:,:,1]) \cdot GRID + (pid3[:,2]+vitg[:,:,2]) $$
    Get global indices `pidx` and retrieve pre-computed vertex positions `vert = val_pnts[pidx]`. Add local offsets `vitg[:,:3]` to `vert`.
3.  **Compute QEF Normals:** Calculate normals `qnrm` using cross products of edge vectors:
    $$ \_1vt = vert[:, 1::2] $$
    $$ qnrm = cross(\_1vt - vert[:, :-1:2], \_1vt - vert[:, 2::2]) $$
    Compute centroid `cntr = mean(\_1vt, dim=1)`. Normalize `qnrm` handling zero-length edges with `ERR` threshold.
4.  **Solve QEF System:** Solve the least squares system:
    $$ A = cat(qnrm, QEF\_REG \cdot eye) $$
    $$ b = cat(sum(\_1vt \cdot qnrm), QEF\_REG \cdot cntr) $$
    Solution `qefr = lstsq(A, b).solution`. If all normals are degenerate (`cndt` all true), use `cntr` instead.
5.  **Ray Intersection:** Compute ray direction `ctoq = qefr - cpnt` and length `leng`. Compute intersection parameter `t` with constraint planes defined by `cstrtab`. Concatenate boundary parameters `(1-cpnt)/ctoq` and `-cpnt/ctoq` with `t`. Handle NaNs and negative values by setting `t` to `leng + SEP`, then normalize by `leng` and clamp to `[0, 1]`. Final vertex is `cpnt + t \cdot ctoq`.

**Pseudocode**

```python
def solve_qef(pidx3, val_, cases, occs, GRID, GRID2, GRID3, val_pnts, ERR, QEF_REG):
    """
    Solves the QEF for ambiguous Marching Cubes cases.
    """
    # Retrieve geometry data from lookup tables
    # Note: Implementation details for qvntab, pfvtab, vitogi depend on specific table layouts
    # Assuming these are global or passed context
    vtcs = get_vertex_coords_from_tables(val_, cases) 
    vitg = get_edge_indices_from_tables(vtcs)
    
    # Compute 3D positions
    # pid3 is pidx3 converted to float
    pnti = vitg[:,:,3]*GRID3 + (pid3[:,0]+vitg[:,:,0])*GRID2 + (pid3[:,1]+vitg[:,:,1])*GRID + (pid3[:,2]+vitg[:,:,2])
    
    # Get global indices and pre-computed positions
    pidx = get_global_indices(pnti)
    vert = val_pnts[pidx]
    
    # Add local offsets
    vert = vert + vitg[:,:3]
    
    # Compute QEF normals
    _1vt = vert[:, 1::2]
    qnrm = cross(_1vt - vert[:, :-1:2], _1vt - vert[:, 2::2])
    cntr = mean(_1vt, dim=1)
    
    # Normalize normals
    leng = norm(qnrm, dim=1, keepdim=True)
    cndt = leng < ERR
    leng[cndt] = 1.0
    qnrm = qnrm / leng
    
    # Solve QEF system
    # A = [qnrm; QEF_REG * I]
    # b = [sum(_1vt * qnrm); QEF_REG * cntr]
    A = concatenate([qnrm, QEF_REG * eye(qnrm.shape[1])], dim=0)
    b = concatenate([sum(_1vt * qnrm, dim=1, keepdim=True), QEF_REG * cntr], dim=0)
    
    qefr = least_squares_solve(A, b)
    
    # Handle degenerate cases
    if all(cndt):
        qefr = cntr
        
    # Ray intersection
    ctoq = qefr - cpnt
    leng = norm(ctoq, dim=1, keepdim=True)
    
    # Compute t with constraints
    t = compute_intersection_t(ctoq, cstrtab, cpnt)
    
    # Handle NaNs and negatives
    t = where(isnan(t) | (t < 0), leng + SEP, t)
    t = t / leng
    t = clamp(t, 0, 1)
    
    return cpnt + t * ctoq

def process_simple_cases(pidx1, occs, GRID, GRID2, GRID3, val_pnts, amb_chks, axd_tab, cas_tab):
    """
    Processes non-ambiguous cases using 2D search.
    """
    pidx1_simple = pidx1[(3 * GRID3 <= pidx1) & (pidx1 < 9 * GRID3)]
    count_idx = len(pidx1_simple)
    
    csidx = floor_div(pidx1_simple, GRID3) - 3
    axdir = axd_tab[csidx]
    axis0 = ax0_tab[csidx]
    axis1 = ax1_tab[csidx]
    cases = cas_tab[csidx]
    axis2 = axis0 + axis1
    
    pidx3 = pidx1_to_pidx3(pidx1_simple)
    
    # Compute occupancy value
    val_ = occs[pidx3[:, 0], pidx3[:, 1], pidx3[:, 2]] + \
           2 * occs[pidx3[:, 0] + axis1[:, 0], pidx3[:, 1] + axis1[:, 1], pidx3[:, 2] + axis1[:, 2]] + \
           4 * occs[pidx3[:, 0] + axis0[:, 0], pidx3[:, 1] + axis0[:, 1], pidx3[:, 2] + axis0[:, 2]] + \
           8 * occs[pidx3[:, 0] + axis2[:, 0], pidx3[:, 1] + axis2[:, 1], pidx3[:, 2] + axis2[:, 2]]
           
    # Ambiguity correction
    tmp = amb_chks[pidx3]
    val_ = where(tmp, 15 - val_, val_)
    
    # Compute vertex positions
    start_idx = 0
    for i in range(count_idx):
        pnt = _2d_search(pidx3[i], axdir[i], axis0[i], axis1[i], val_[i], cases[i])
        val_pnts[start_idx + i] = pnt
        
    return start_idx + count_idx
```

## Subtopics

### QEM-based Vertex Relocation
A vertex relocation method used in the Mesh Generation phase to move vertices to the isosurface, using the Quadric Error Metric (QEM) instead of full QEF minimization to reduce computational complexity and register usage on parallel hardware [S2, unofficial]. Unlike pseudoinverse QEF minimization which is complex and penalizes performance on parallel hardware due to register limits, QEM minimization is stable with supporting planes and produces accurate results sufficient for volume preservation [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of active cells, but with a higher constant factor for ambiguous cases due to least-squares solving. The 2D search for simple cases is $O(1)$ per cell.
*   **Memory Complexity:** Requires storage for the occupancy grid, lookup tables, and the output vertex array. QEF solving requires temporary storage for matrices $A$ and $b$.
*   **Performance:** The QEF approach is more computationally expensive than standard Marching Cubes but less expensive than full Dual Contouring. The use of QEM as an alternative can further reduce register pressure on GPUs [S2, unofficial].
*   **Strengths:** Produces higher quality surfaces in ambiguous regions, reducing artifacts like "popping" or incorrect topology. Maintains watertightness.
*   **Limitations:** More complex to implement than standard Marching Cubes. Requires careful handling of degenerate cases and numerical stability in least-squares solving.

## Background
The method originates from the ODC (Octree-based Discretized Contouring) implementation by the KAIST Visual AI Group [S1, unofficial]. It builds upon the classic Marching Cubes algorithm [30-isosurface-extraction.md] by incorporating geometric optimization techniques. The Quadric Error Function (QEF) was originally introduced by Garland and Heckbert for mesh simplification [GH97], and its application to isosurface extraction was adapted to handle topological ambiguities more robustly [S1, unofficial]. The QEM variant was proposed to address performance issues on parallel hardware [S2, unofficial].
