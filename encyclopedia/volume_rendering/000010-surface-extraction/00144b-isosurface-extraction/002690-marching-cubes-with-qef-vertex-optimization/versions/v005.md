# Marching Cubes with QEF Vertex Optimization

Also called: MC-QEF, Optimized Marching Cubes

## Overview
Marching Cubes with QEF Vertex Optimization is a surface extraction method that computes vertex positions using a Quadric Error Function (QEF) minimization for ambiguous cases, while using a 2D linear/binomial search for non-ambiguous cases, to produce a watertight mesh from a voxel grid [S1, unofficial]. It builds on [Isosurface extraction](30-isosurface-extraction.md) by replacing the standard linear interpolation of classic Marching Cubes with a constrained optimization step that preserves volume and handles topological ambiguities more robustly [S1, unofficial]. Unlike [Dual Contouring and Surface Nets](6319-dual-contouring-and-surface-nets.md), which solve a QEF per cell to place a single vertex, this method retains the Marching Cubes topology (one vertex per edge intersection) but optimizes the position of those vertices to lie precisely on the implicit surface defined by the voxel data [S1, unofficial].

## How it works
The method processes a voxel grid of occupancy values. It classifies cells into two groups based on their index to optimize performance: "fast" cells (indices in range $[3 \cdot G^3, 9 \cdot G^3)$) and "ambiguous" cells (indices $\ge 9 \cdot G^3$), where $G$ is the grid dimension [S1, unofficial].

### Data Structures
*   **`occs`**: 3D array of occupancy bits (0 or 1) at grid vertices.
*   **`val_pnts`**: Array storing computed vertex positions.
*   **`amb_chks`**: Boolean array indicating cells requiring ambiguity correction.
*   **`qvntab`**: Lookup table mapping occupancy patterns and cases to vertex indices.
*   **`pfvtab`**: Pre-computed vertex frame table containing local offsets.
*   **`vitogi`**: Edge-to-vertex index mapping.
*   **`cstrtab`**: Constraint tables for boundary planes.

### Algorithm Steps

1.  **Filter and Classify**: Separate voxel indices `pidx1` into two groups:
    *   Group A: `3*GRID3 <= pidx1 < 9*GRID3` (Fast 2D search).
    *   Group B: `pidx1 >= 9*GRID3` (QEF optimization).
    Initialize `start_idx` to 0.

2.  **Process Group A (Fast 2D Search)**:
    For each index in Group A:
    a. Compute the 8-neighbor occupancy value `val_` by summing weighted occupancy bits:
       $$val_ = occs[pidx3] + 2 \cdot occs[pidx3 + axis1] + 4 \cdot occs[pidx3 + axis0] + 8 \cdot occs[pidx3 + axis2]$$
       where `axis0`, `axis1`, `axis2` are basis vectors derived from the cell's orientation.
    b. Apply ambiguity correction: If `amb_chks[pidx3]` is true, set `val_ = 15 - val_`.
    c. Compute vertex positions using a 2D linear/binomial search `_2d_search(pidx3, axdir, axis0, axis1, val_, cases)`.
    d. Store results in `val_pnts` at `start_idx` and increment `start_idx` by the count of processed cells.

3.  **Process Group B (QEF Optimization)**:
    For each index in Group B:
    a. Call `_solve_QEF(pidx3, val_, cases)` where `val_` is the integer occupancy pattern and `cases` is derived from `pidx1 / GRID3 - 9`.
    b. Store results in `val_pnts` at `current start_idx`.

    **Detailed `_solve_QEF` Procedure**:
    a. For each vertex index `i` from 3 to 7:
       i. Find indices `idx` where `qvntab[val_, cases] == i`.
       ii. Retrieve vertex coordinates `vtcs` from `pfvtab[val0_, cas, :2*i+1]`.
       iii. Retrieve edge indices `vitg` from `vitogi[vtcs]`.
    b. Compute 3D positions `pnti` for the vertices using grid offsets:
       $$pnti = vitg[:,:,3] \cdot G^3 + (pid3[:,0] + vitg[:,:,0]) \cdot G^2 + (pid3[:,1] + vitg[:,:,1]) \cdot G + (pid3[:,2] + vitg[:,:,2])$$
       Get global indices `pidx` and retrieve pre-computed vertex positions `vert = val_pnts[pidx]`.
    c. Add local offsets `vitg[:,:3]` to `vert`.
    d. Compute QEF normals `qnrm` using cross products of edge vectors:
       $$\_1vt = vert[:, 1::2]$$
       $$qnrm = \text{cross}(\_1vt - vert[:, :-1:2], \_1vt - vert[:, 2::2])$$
       Compute centroid `cntr = \text{mean}(\_1vt, \text{dim}=1)`.
       Normalize `qnrm` handling zero-length edges with `ERR` threshold.
    e. Solve the QEF system using least squares:
       $$A = \text{cat}(qnrm, QEF\_REG \cdot I)$$
       $$b = \text{cat}(\text{sum}(\_1vt \cdot qnrm), QEF\_REG \cdot cntr)$$
       Solution `qefr = \text{lstsq}(A, b).\text{solution}`.
       If all normals are degenerate (`cndt` all true), use `cntr` instead.
    f. Compute ray direction `ctoq = qefr - cpnt` and length `leng`.
    g. Compute intersection parameter `t` with constraint planes defined by `cstrtab`.
       Concatenate boundary parameters $(1-cpnt)/ctoq$ and $-cpnt/ctoq$ with `t`.
       Handle NaNs and negative values by setting `t` to `leng + SEP`, then normalize by `leng` and clamp to $[0, 1]$.
    h. Final vertex is `cpnt + t * ctoq`.

### Pseudocode

```python
def solve_qef(pidx3, val_, cases, occs, GRID3, GRID2, GRID, GRID3_, axd_tab, ax0_tab, ax1_tab, cas_tab, qvntab, pfvtab, vitogi, val_pnts, ERR, QEF_REG, cstrtab, cpnt):
    """
    Solves the QEF for ambiguous Marching Cubes cases.
    """
    # Retrieve orientation and case info
    csidx = pidx3 // GRID3 - 9
    axdir = axd_tab[csidx]
    axis0 = ax0_tab[csidx]
    axis1 = ax1_tab[csidx]
    cases = cas_tab[csidx]
    axis2 = axis0 + axis1
    
    # Compute occupancy pattern
    val_ = (occs[pidx3[:, 0], pidx3[:, 1], pidx3[:, 2]] +
            2 * occs[pidx3[:, 0] + axis1[:, 0], pidx3[:, 1] + axis1[:, 1], pidx3[:, 2] + axis1[:, 2]] +
            4 * occs[pidx3[:, 0] + axis0[:, 0], pidx3[:, 1] + axis0[:, 1], pidx3[:, 2] + axis0[:, 2]] +
            8 * occs[pidx3[:, 0] + axis2[:, 0], pidx3[:, 1] + axis2[:, 1], pidx3[:, 2] + axis2[:, 2]])
            
    # Ambiguity correction
    # Note: amb_chks logic is handled in the caller for Group A, 
    # but for Group B, the cases table typically encodes the ambiguity resolution.
    # If explicit correction is needed:
    # if amb_chks[pidx3]: val_ = 15 - val_

    # Initialize output array
    num_vertices = len(pidx3)
    final_vertices = np.zeros((num_vertices, 3))
    
    for i in range(3, 8): # Vertex indices 3 to 7
        # Find indices where the vertex index matches i
        # qvntab maps (val_, case) -> vertex_index
        # This step assumes qvntab is pre-computed for the specific val_ and cases
        mask = (qvntab[val_, cases] == i)
        if not np.any(mask):
            continue
            
        # Retrieve pre-computed vertex frame data
        # pfvtab[val0_, cas, :2*i+1] contains local offsets
        # vitogi maps vertex coordinates to edge indices
        vtcs = pfvtab[val_, cases, :2*i+1]
        vitg = vitogi[vtcs]
        
        # Compute 3D positions using grid offsets
        # pid3 is the base grid index for the current cell
        pnti = (vitg[:,:,3] * GRID3 + 
                (pidx3[:,0] + vitg[:,:,0]) * GRID2 + 
                (pidx3[:,1] + vitg[:,:,1]) * GRID + 
                (pidx3[:,2] + vitg[:,:,2]))
        
        # Get global indices and retrieve pre-computed positions
        # Note: pidx calculation depends on specific grid layout
        pidx = compute_global_indices(pnti, GRID)
        vert = val_pnts[pidx]
        
        # Add local offsets
        vert += vitg[:,:3]
        
        # Compute QEF normals
        _1vt = vert[:, 1::2]
        qnrm = np.cross(_1vt - vert[:, :-1:2], _1vt - vert[:, 2::2])
        
        # Compute centroid
        cntr = np.mean(_1vt, axis=1)
        
        # Normalize normals
        leng = np.linalg.norm(qnrm, axis=1, keepdims=True)
        cndt = leng < ERR
        leng[cndt] = 1.0
        qnrm = qnrm / leng
        
        # Solve QEF using least squares
        # A = [qnrm; QEF_REG * I]
        # b = [sum(_1vt * qnrm); QEF_REG * cntr]
        # This is a simplified representation; actual implementation uses stack/concat
        A = np.vstack([qnrm, QEF_REG * np.eye(3)])
        b = np.vstack([np.sum(_1vt * qnrm, axis=1, keepdims=True), QEF_REG * cntr])
        
        # Solve least squares
        # qefr = argmin ||Ax - b||^2
        qefr = np.linalg.lstsq(A, b, rcond=None)[0]
        
        # Handle degenerate normals
        if np.all(cndt):
            qefr = cntr
            
        # Compute ray direction and intersection
        ctoq = qefr - cpnt
        leng = np.linalg.norm(ctoq, axis=1, keepdims=True)
        
        # Compute intersection parameter t with constraint planes
        # cstrtab defines the boundary planes
        # This step involves solving for t in plane equations
        # Simplified: t is computed based on constraints
        t = compute_intersection_t(ctoq, cstrtab, cpnt)
        
        # Handle NaNs and negative values
        # Set t to leng + SEP if invalid
        t = np.where(np.isnan(t) | (t < 0), leng + SEP, t)
        
        # Normalize and clamp
        t = np.clip(t / leng, 0, 1)
        
        # Final vertex
        final_vertices[:, :] = cpnt + t * ctoq
        
    return final_vertices

def process_fast_cells(pidx1, occs, GRID3, GRID, GRID2, GRID3_, axd_tab, ax0_tab, ax1_tab, cas_tab, amb_chks, val_pnts, start_idx):
    """
    Processes non-ambiguous cells using 2D linear/binomial search.
    """
    pidx3 = pidx1_to_pidx3(pidx1)
    csidx = pidx1 // GRID3 - 3
    axdir = axd_tab[csidx]
    axis0 = ax0_tab[csidx]
    axis1 = ax1_tab[csidx]
    cases = cas_tab[csidx]
    axis2 = axis0 + axis1
    
    # Compute occupancy pattern
    val_ = (occs[pidx3[:, 0], pidx3[:, 1], pidx3[:, 2]] +
            2 * occs[pidx3[:, 0] + axis1[:, 0], pidx3[:, 1] + axis1[:, 1], pidx3[:, 2] + axis1[:, 2]] +
            4 * occs[pidx3[:, 0] + axis0[:, 0], pidx3[:, 1] + axis0[:, 1], pidx3[:, 2] + axis0[:, 2]] +
            8 * occs[pidx3[:, 0] + axis2[:, 0], pidx3[:, 1] + axis2[:, 1], pidx3[:, 2] + axis2[:, 2]])
            
    # Ambiguity correction
    if np.any(amb_chks[pidx3]):
        val_[amb_chks[pidx3]] = 15 - val_[amb_chks[pidx3]]
        
    # Compute vertex positions using 2D search
    # _2d_search returns the optimized vertex positions
    vertices = _2d_search(pidx3, axdir, axis0, axis1, val_, cases)
    
    # Store in val_pnts
    count = len(pidx1)
    val_pnts[start_idx:start_idx+count] = vertices
    return start_idx + count

def main_extraction(occs, GRID, GRID3, GRID2, GRID3_, axd_tab, ax0_tab, ax1_tab, cas_tab, amb_chks, qvntab, pfvtab, vitogi, val_pnts, cstrtab, cpnt, ERR, QEF_REG, SEP):
    """
    Main extraction function.
    """
    # Filter indices
    pidx1 = get_all_voxel_indices()
    
    # Group A: Fast 2D search
    mask_a = (3 * GRID3 <= pidx1) & (pidx1 < 9 * GRID3)
    pidx1_a = pidx1[mask_a]
    
    # Group B: QEF optimization
    mask_b = pidx1 >= 9 * GRID3
    pidx1_b = pidx1[mask_b]
    
    start_idx = 0
    
    # Process Group A
    if len(pidx1_a) > 0:
        start_idx = process_fast_cells(pidx1_a, occs, GRID3, GRID, GRID2, GRID3_, axd_tab, ax0_tab, ax1_tab, cas_tab, amb_chks, val_pnts, start_idx)
        
    # Process Group B
    if len(pidx1_b) > 0:
        pidx3_b = pidx1_to_pidx3(pidx1_b)
        # Compute val_ and cases for Group B
        # ... (similar to Group A but with different offset logic)
        vertices_b = solve_qef(pidx3_b, val_, cases, occs, GRID3, GRID2, GRID, GRID3_, axd_tab, ax0_tab, ax1_tab, cas_tab, qvntab, pfvtab, vitogi, val_pnts, ERR, QEF_REG, cstrtab, cpnt)
        val_pnts[start_idx:start_idx+len(pidx1_b)] = vertices_b
        
    return val_pnts
```

### Parameters
*   `ERR`: Threshold for zero-length edges. Typical value: $10^{-6}$.
*   `QEF_REG`: Regularization weight for QEF. Typical value: $10^{-4}$.
*   `SEP`: Separation constant for boundary handling.
*   `GRID`, `GRID2`, `GRID3`: Grid dimensions and their squares/cubes.

### Edge Cases and Pitfalls
*   **Degenerate Normals**: If all edge vectors are zero-length, the QEF system is singular. The method falls back to the centroid of the vertex frame [S1, unofficial].
*   **Ambiguity Correction**: The 8-neighbor occupancy value must be corrected if the cell is marked as ambiguous (`amb_chks` is true). Failure to do so results in topological errors [S1, unofficial].
*   **Boundary Conditions**: The intersection parameter `t` must be clamped to $[0, 1]$ to ensure vertices remain within the cell bounds. NaNs and negative values are handled by setting `t` to `leng + SEP` [S1, unofficial].

## Subtopics

### QEM-based Vertex Relocation
A vertex relocation method used in the Mesh Generation phase to move vertices to the isosurface, using the Quadric Error Metric (QEM) instead of full QEF minimization to reduce computational complexity and register usage on parallel hardware [S2, unofficial]. Unlike pseudoinverse QEF minimization which is complex and penalizes performance on parallel hardware due to register limits, QEM minimization is stable with supporting planes and produces accurate results sufficient for volume preservation [S2, unofficial].

## Operating characteristics
*   **Time Complexity**: The method is $O(N)$ where $N$ is the number of voxels, as it processes each cell once. The QEF step involves a small constant-time least squares solve (3x3 system) per vertex, which is more expensive than linear interpolation but still linear in the number of vertices.
*   **Memory Complexity**: $O(N)$ for storing the voxel grid and the output vertex positions. The lookup tables (`qvntab`, `pfvtab`, etc.) are constant size.
*   **Performance**: The separation into "fast" and "ambiguous" groups allows for optimized processing of the majority of cells using a fast 2D search, reserving the more expensive QEF optimization only for ambiguous cases [S1, unofficial].
*   **Strengths**: Produces watertight meshes with vertices precisely on the isosurface, handling topological ambiguities better than standard Marching Cubes [S1, unofficial].
*   **Limitations**: More complex to implement than standard Marching Cubes due to the QEF solving and ambiguity handling. The QEF step is computationally heavier than linear interpolation.
*   **When to Use**: When high-quality, watertight meshes are required from voxel data, and topological ambiguities are present.
*   **When Not to Use**: When performance is critical and the voxel data is simple (no ambiguities), standard Marching Cubes may be sufficient.

## Background
The method originates from the ODC (Octree-based Density Compression) project by KAIST Visual AI Group [S1, unofficial]. It was developed to address the limitations of standard Marching Cubes in handling ambiguous cases and producing vertices that lie precisely on the implicit surface. The QEF optimization step is inspired by the work of Garland and Heckbert on Quadric Error Metrics [S2, unofficial], adapted for the specific context of Marching Cubes vertex placement.
