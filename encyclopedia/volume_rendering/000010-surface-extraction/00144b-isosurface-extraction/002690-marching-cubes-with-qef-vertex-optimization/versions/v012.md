# Marching Cubes with QEF Vertex Optimization

Also called: MC-QEF, Optimized Marching Cubes

## Overview
Marching Cubes with QEF Vertex Optimization is a surface extraction method that produces watertight meshes from voxel grids by combining fast 2D linear/binomial search for non-ambiguous cases with Quadric Error Function (QEF) minimization for ambiguous cases [S1, unofficial]. It sets itself apart from standard [Marching Cubes Lookup and Configuration](2518-marching-cubes-lookup-and-configuration.md) by explicitly resolving topological ambiguities (cases 46, 47, 98, 99, 210, 213, 214, 215) through geometric optimization rather than fixed triangulation, thereby preventing cracks and holes [S1, unofficial]. Unlike [Snap Marching Cubes](2181-snap-marching-cubes.md) which snaps vertices to grid edges, this method projects vertices onto the implicit surface defined by the scalar field using least-squares minimization [S1, unofficial].

## How it works
The method processes voxel indices in two distinct groups based on their case index to balance performance and accuracy. It relies on the precomputed structures from [Marching Cubes Lookup and Configuration](2518-marching-cubes-lookup-and-configuration.md): `edgeTable`, `triangleTable`, and the case index calculation logic.

### Inputs and Outputs
*   **Inputs**:
    *   `occs`: 3D array of binary occupancy values (0 or 1) for the voxel grid.
    *   `GRID`, `GRID2`, `GRID3`: Grid dimensions ($N_x, N_y, N_z$).
    *   `sel_pidx1`: List of voxel indices to process.
    *   `pfvtab`: Precomputed vertex frame table mapping case/vertex to local offsets.
    *   `qvntab`: Quantized table mapping case/vertex to edge indices.
    *   `amb_chks`: Boolean array indicating ambiguous cases.
    *   `cstrtab`: Constraint planes for boundary intersection.
    *   `QEF_REG`: Regularization parameter for QEF least squares.
    *   `ERR`: Epsilon threshold for degenerate checks.
*   **Outputs**:
    *   `val_pnts`: Array of optimized 3D vertex positions.

### Data Structures
*   **Case Index ($C$)**: 8-bit integer derived from `occs`. Bit $i$ is 1 if `occs[v_i] == 1`, else 0.
*   **Ambiguity Check**: Cases 46, 47, 98, 99, 210, 213, 214, 215 are flagged in `amb_chks` [S1, unofficial].

### Algorithm Steps

1.  **Partition Indices**:
    Split `sel_pidx1` into:
    *   `pidx1_fast`: Indices in range $[3 \cdot GRID3, 9 \cdot GRID3)$. These correspond to non-ambiguous or easily resolvable cases.
    *   `pidx1_slow`: Indices $\ge 9 \cdot GRID3$. These correspond to ambiguous cases requiring QEF optimization [S1, unofficial].

2.  **Process Fast Group (2D Search)**:
    For each voxel index $p$ in `pidx1_fast`:
    a.  **Compute Occupancy Pattern ($val_$)**:
        Let $p_3$ be the 3D coordinates $(x,y,z)$ of the voxel.
        Let $axis0, axis1$ be the primary axes of the case configuration (precomputed in `ax0_tab`, `ax1_tab`).
        $$ val_ = occs[p_3] + 2 \cdot occs[p_3 + axis1] + 4 \cdot occs[p_3 + axis0] + 8 \cdot occs[p_3 + axis2] $$
        where $axis2 = axis0 + axis1$.
        If `amb_chks[p_3]` is true, correct the pattern: $val_ = 15 - val_$ [S1, unofficial].
    b.  **2D Search**:
        Call `_2d_search(p_3, axdir, axis0, axis1, val_, cases)` to find the intersection point.
        *   This function performs a binomial/linear search along the dominant axes to find the precise intersection on the cube edges/faces [S1, unofficial].
        *   It calculates a midpoint $spnt$ and normal $vnorm$.
        *   It refines the position using horizontal and vertical searches constrained by the scalar field values at neighbors [S1, unofficial].
    c.  **Store Result**:
        Store the resulting vertex in `val_pnts` at `start_idx`. Increment `start_idx` by the count of fast voxels [S1, unofficial].

3.  **Process Slow Group (QEF Optimization)**:
    For each voxel index $p$ in `pidx1_slow`:
    a.  **Derive Case**:
        $cas = p / GRID3 - 9$.
        Retrieve $val_$ (occupancy pattern) and configuration data [S1, unofficial].
    b.  **Solve QEF**:
        Call `_solve_QEF(p_3, val_, cas)` [S1, unofficial].
        i.  **Identify Vertices**:
            For each vertex index $i \in [3, 7]$ (vertices involved in ambiguous topology):
            Find edge indices $idx$ where `qvntab[val_, cas] == i`.
            Retrieve local vertex coordinates $vtcs$ from `pfvtab[val0_, cas, :2*i+1]` and edge indices $vitg$ [S1, unofficial].
        ii. **Compute Global Positions**:
            Calculate local 3D positions $pnti$ using grid offsets:
            $$ pnti = vitg[:,:,3] \cdot GRID3 + (pid3[:,0]+vitg[:,:,0]) \cdot GRID2 + (pid3[:,1]+vitg[:,:,1]) \cdot GRID + (pid3[:,2]+vitg[:,:,2]) $$
            Retrieve global pre-computed positions $vert = val\_pnts[pidx]$ and add local offsets $vitg[:,:3]$ [S1, unofficial].
        iii. **Compute QEF Normals**:
            Let $\_1vt = vert[:, 1::2]$ and $\_0vt = vert[:, :-1:2]$.
            Compute normals via cross products of edge vectors:
            $$ qnrm = \text{cross}(\_1vt - \_0vt, \_1vt - \_2vt) $$
            Compute centroid $cntr = \text{mean}(\_1vt, \text{dim}=1)$.
            Normalize $qnrm$, handling zero-length edges with threshold $ERR$ [S1, unofficial].
        iv. **Solve Least Squares**:
            Construct matrix $A$ and vector $b$:
            $$ A = \text{cat}(qnrm, QEF\_REG \cdot I) $$
            $$ b = \text{cat}(\text{sum}(\_1vt \cdot qnrm), QEF\_REG \cdot cntr) $$
            Solve $qefr = \text{lstsq}(A, b)$.
            If all normals are degenerate, use $cntr$ instead [S1, unofficial].
        v.  **Project to Surface**:
            Compute ray direction $ctoq = qefr - cpnt$ and length $leng$.
            Compute intersection parameter $t$ with constraint planes $cstrtab$.
            Concatenate boundary parameters $(1-cpnt)/ctoq$ and $-cpnt/ctoq$ with $t$.
            Handle NaNs/negatives by setting $t = leng + SEP$.
            Normalize by $leng$ and clamp to $[0, 1]$.
            Final vertex: $cpnt + t \cdot ctoq$ [S1, unofficial].

### Pseudocode

```python
def solve_qef_vertices(occs, GRID, GRID2, GRID3, sel_pidx1, pfvtab, qvntab, 
                       amb_chks, cstrtab, QEF_REG, ERR):
    """
    Optimized Marching Cubes with QEF vertex optimization.
    """
    val_pnts = []
    start_idx = 0
    
    # Partition indices
    fast_mask = (sel_pidx1 >= 3 * GRID3) & (sel_pidx1 < 9 * GRID3)
    pidx1_fast = sel_pidx1[fast_mask]
    pidx1_slow = sel_pidx1[~fast_mask]
    
    # Process Fast Group
    if len(pidx1_fast) > 0:
        csidx = (pidx1_fast // GRID3) - 3
        axdir = axd_tab[csidx]
        axis0 = ax0_tab[csidx]
        axis1 = ax1_tab[csidx]
        cases = cas_tab[csidx]
        axis2 = axis0 + axis1
        
        pidx3 = pidx1_to_pidx3(pidx1_fast)
        
        # Compute occupancy pattern
        val_ = (occs[pidx3[:, 0], pidx3[:, 1], pidx3[:, 2]] +
                2 * occs[pidx3[:, 0] + axis1[:, 0], pidx3[:, 1] + axis1[:, 1], pidx3[:, 2] + axis1[:, 2]] +
                4 * occs[pidx3[:, 0] + axis0[:, 0], pidx3[:, 1] + axis0[:, 1], pidx3[:, 2] + axis0[:, 2]] +
                8 * occs[pidx3[:, 0] + axis2[:, 0], pidx3[:, 1] + axis2[:, 1], pidx3[:, 2] + axis2[:, 2]])
        
        # Ambiguity correction
        amb = amb_chks[pidx3[:, 0], pidx3[:, 1], pidx3[:, 2]]
        val_[amb] = 15 - val_[amb]
        
        # 2D Search
        fast_vertices = _2d_search(pidx3, axdir, axis0, axis1, val_, cases)
        val_pnts.extend(fast_vertices)
        start_idx += len(fast_vertices)
        
    # Process Slow Group (QEF)
    if len(pidx1_slow) > 0:
        csidx_slow = (pidx1_slow // GRID3) - 9
        # Retrieve necessary tables for slow group
        # ... (similar table lookups as fast group)
        
        pidx3_slow = pidx1_to_pidx3(pidx1_slow)
        # Compute val_ for slow group similarly
        
        slow_vertices = []
        for p_idx, p3, val_val, cas in zip(pidx1_slow, pidx3_slow, val_slow, cas_slow):
            # Solve QEF for this voxel
            v = _solve_QEF(p3, val_val, cas, pfvtab, qvntab, val_pnts, GRID, GRID2, GRID3, cstrtab, QEF_REG, ERR)
            slow_vertices.append(v)
        
        val_pnts.extend(slow_vertices)
        
    return val_pnts

def _solve_QEF(p3, val_, cas, pfvtab, qvntab, val_pnts, GRID, GRID2, GRID3, cstrtab, QEF_REG, ERR):
    """
    Solves QEF for ambiguous cases.
    """
    vertices = []
    # Iterate over relevant vertices (indices 3 to 7 typically)
    for i in range(3, 8):
        # Find edge indices for this vertex
        idx = find_indices(qvntab[val_, cas], i)
        
        # Retrieve local offsets
        vtcs = pfvtab[val_, cas, :2*i+1]
        vitg = vitogi[vtcs]
        
        # Compute global positions
        # pnti calculation involves grid offsets
        pnti = vitg[:,:,3]*GRID3 + (p3[:,0]+vitg[:,:,0])*GRID2 + (p3[:,1]+vitg[:,:,1])*GRID + (p3[:,2]+vitg[:,:,2])
        
        # Get global pre-computed positions
        pidx = get_global_indices(pnti)
        vert = val_pnts[pidx]
        vert += vitg[:,:3]
        
        # Compute QEF normals
        _1vt = vert[:, 1::2]
        _0vt = vert[:, :-1:2]
        _2vt = vert[:, 2::2]
        
        qnrm = cross(_1vt - _0vt, _1vt - _2vt)
        cntr = mean(_1vt, dim=1)
        
        # Normalize
        leng = norm(qnrm, dim=1, keepdim=True)
        cndt = leng < ERR
        leng[cndt] = 1.0
        qnrm = qnrm / leng
        
        # Solve Least Squares
        A = concatenate([qnrm, QEF_REG * eye(qnrm.shape[1])], dim=0)
        b = concatenate([sum(_1vt * qnrm, dim=1), QEF_REG * cntr], dim=0)
        
        qefr = lstsq(A, b).solution
        
        # Handle degenerate normals
        if all(cndt):
            qefr = cntr
            
        # Project to surface
        cpnt = centroid(p3) # Or specific center point
        ctoq = qefr - cpnt
        leng = norm(ctoq)
        
        # Intersection with constraint planes
        t = compute_intersection(ctoq, cstrtab)
        
        # Boundary handling
        bound_params = concatenate([(1-cpnt)/ctoq, -cpnt/ctoq])
        t = concatenate([bound_params, t])
        
        # Handle NaNs and negatives
        t[isnan(t) | (t < 0)] = leng + SEP
        t = t / leng
        t = clamp(t, 0, 1)
        
        final_v = cpnt + t * ctoq
        vertices.append(final_v)
        
    return vertices
```

### Parameters
*   `QEF_REG`: Regularization weight for the least-squares solver. Not given in the sources.
*   `ERR`: Epsilon for degenerate edge/normal checks. Not given in the sources.
*   `SEP`: Separation constant for boundary handling. Not given in the sources.

### Edge Cases and Pitfalls
*   **Degenerate Normals**: If all QEF normals are zero-length (degenerate geometry), the method falls back to the centroid [S1, unofficial].
*   **Ambiguity Correction**: For ambiguous cases in the "fast" group, the occupancy pattern is inverted ($15 - val_$) to resolve topology correctly [S1, unofficial].
*   **Boundary Conditions**: The QEF solution must be projected onto constraint planes to ensure the vertex lies within the voxel bounds. NaNs and negative intersection parameters are handled by clamping or using a separation constant [S1, unofficial].

## Subtopics

### QEM-based Vertex Relocation
A variant used in mesh generation that replaces full QEF minimization with Quadric Error Metric (QEM) minimization [S2, unofficial]. Unlike QEF, which requires solving a complex least-squares system (penalizing register usage on parallel hardware), QEM is computationally simpler and stable with supporting planes [S2, unofficial]. It is chosen when volume preservation is the primary goal and extreme geometric accuracy is less critical than performance on parallel architectures [S2, unofficial].

## Operating characteristics
*   **Time Complexity**: The method splits work into $O(1)$ 2D search for non-ambiguous cases and $O(k)$ QEF least-squares solving for ambiguous cases, where $k$ is the number of vertices per ambiguous voxel. Overall complexity is linear with respect to the number of voxels, but with a higher constant factor for ambiguous regions [S1, unofficial].
*   **Memory Complexity**: Requires storage for `val_pnts`, precomputed tables (`pfvtab`, `qvntab`), and intermediate arrays for QEF solving. Memory usage scales linearly with the number of voxels and vertices [S1, unofficial].
*   **Performance**: The 2D search branch is fast and suitable for real-time applications. The QEF branch is more expensive due to matrix operations but ensures watertightness [S1, unofficial].
*   **Strengths**: Produces watertight meshes; resolves topological ambiguities correctly; handles sharp features better than simple linear interpolation [S1, unofficial].
*   **Limitations**: Computationally heavier than standard Marching Cubes due to QEF solving; sensitive to the choice of regularization parameter `QEF_REG` [S1, unofficial].
*   **When to Use**: When watertightness and topological correctness are critical, and computational resources allow for per-voxel optimization [S1, unofficial].
*   **When Not to Use**: For real-time applications with strict latency constraints where approximate topology is acceptable, or when hardware register limits prevent efficient QEF solving (consider QEM variant) [S2, unofficial].

## Background
The method originates from the Open Data Cube (ODC) project, specifically the KAIST Visual AI Group's implementation for efficient surface extraction from large-scale voxel data [S1, unofficial]. It was developed to address the limitations of standard Marching Cubes in handling ambiguous cases without introducing cracks, while maintaining performance through a hybrid approach of fast search and optimized QEF solving [S1, unofficial]. The QEM variant was introduced to further optimize performance on parallel hardware by reducing register pressure [S2, unofficial].
