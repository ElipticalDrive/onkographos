# Marching Cubes with Narrow-Band Filtering

Also called: MeshReconstruction::MarchCube

## Overview
This method reconstructs a triangle mesh from a Signed Distance Function (SDF) by evaluating the field on a grid of cubes, filtering out cubes that are too far from the surface (narrow-band filtering), and applying the standard Marching Cubes algorithm to the remaining cubes [S1, unofficial]. It sets itself apart from naive Marching Cubes implementations by skipping the vast majority of voxels that do not intersect the isosurface, significantly reducing computational cost for sparse or bounded domains [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A domain bounding box (`Rect3`), a scalar field function `sdf(Vec3) -> double` (typically an SDF), an `isoLevel` (default 0.0), and optional gradient function `sdfGrad(Vec3) -> Vec3`.
*   **Output:** A triangle mesh (list of vertices and indices).

**Data Structures:**
*   **Cube:** Represents a single voxel in the grid.
    *   `pos[8]`: Array of 8 vertex coordinates (`Vec3`).
    *   `sdf[8]`: Array of 8 scalar field values at the vertices (`double`).
    *   `intersect`: Bitmask or list of intersected edges (derived from `edgeTable`).
*   **Edge Table:** Standard 256-entry lookup table mapping case indices to 12-bit edge intersection masks [S1, S4, S12, unofficial].
*   **Triangle Table:** Standard 256x16 lookup table mapping case indices to triangle vertex edge indices [S1, S8, S12, unofficial].

**Parameters:**
*   `NumCubes`: Integer constant, default 50. Used to determine grid resolution.
*   `cubeSize`: Derived from `domain.size / NumCubes`.
*   `isoLevel`: The isovalue for extraction. Default 0.0.
*   `sdfGrad`: Optional gradient function. If `nullptr`, numerical approximation is used for normals [S1, unofficial].

**Steps:**

1.  **Grid Setup:**
    Calculate grid dimensions:
    $$ NumX = \lceil \frac{domain.size.x}{cubeSize.x} \rceil $$
    $$ NumY = \lceil \frac{domain.size.y}{cubeSize.y} \rceil $$
    $$ NumZ = \lceil \frac{domain.size.z}{cubeSize.z} \rceil $$
    Calculate geometric constants:
    $$ HalfCubeDiag = \frac{\|cubeSize\|}{2.0} $$
    $$ HalfCubeSize = cubeSize \times 0.5 $$

2.  **Voxel Iteration:**
    Iterate over grid indices $ix, iy, iz$ from $0$ to $NumX-1$, etc.
    Calculate the minimum corner of the cube in domain space:
    $$ min = domain.min + \{ ix \cdot cubeSize.x, iy \cdot cubeSize.y, iz \cdot cubeSize.z \} $$
    Calculate the cube center:
    $$ cubeCenter = min + HalfCubeSize $$

3.  **Narrow-Band Filtering (Pitfall Guard):**
    Evaluate the distance from the cube center to the isosurface:
    $$ dist = |sdf(cubeCenter) - isoLevel| $$
    If $dist > HalfCubeDiag$, the cube cannot intersect the isosurface. Continue to the next cube [S1, unofficial].

4.  **Cube Construction:**
    Construct a `Cube` object. Sample the SDF at the 8 vertices of the cube:
    $$ pos[v] = min + \{ (v\&1)*cubeSize.x, (v\&2)*cubeSize.y, (v\&4)*cubeSize.z \} \quad \text{for } v \in [0,7] $$
    $$ sdf[v] = sdf(pos[v]) $$

5.  **Intersection:**
    Determine the case index $C$ based on the signs of $sdf[v]$ relative to $isoLevel$.
    Use `edgeTable[C]` to identify intersected edges.
    For each intersected edge $(e_i, e_j)$, calculate the intersection point using linear interpolation:
    $$ \mu = \frac{isoLevel - sdf[e_i]}{sdf[e_j] - sdf[e_i]} $$
    $$ P_{intersect} = pos[e_i] + \mu \cdot (pos[e_j] - pos[e_i]) $$
    *Edge Case:* If $|sdf[e_i] - isoLevel| < \epsilon$ or $|sdf[e_i] - sdf[e_j]| < \epsilon$, return $pos[e_i]$ [S1, unofficial].

6.  **Triangulation:**
    Use `triangleTable[C]` to retrieve triplets of edge indices $(a, b, c)$.
    For each triplet, generate a triangle using the previously calculated intersection points.
    Add the triangle to the mesh.
    *Note:* The source implementation uses a specific edge numbering convention where edge flags are powers of 2 ($1, 2, 4, \dots, 2048$) corresponding to edges $0..11$ [S1, unofficial].

**Pseudocode:**

```python
def marching_cubes_narrow_band(sdf, domain, iso_level=0.0, num_cubes=50, sdf_grad=None):
    # 1. Grid Setup
    cube_size = domain.size / num_cubes
    half_cube_diag = cube_size.norm() / 2.0
    half_cube_size = cube_size * 0.5
    
    num_x = ceil(domain.size.x / cube_size.x)
    num_y = ceil(domain.size.y / cube_size.y)
    num_z = ceil(domain.size.z / cube_size.z)
    
    mesh = Mesh()
    
    # 2. Voxel Iteration
    for ix in range(num_x):
        for iy in range(num_y):
            for iz in range(num_z):
                # Calculate cube min corner
                min_corner = domain.min + Vec3(ix * cube_size.x, iy * cube_size.y, iz * cube_size.z)
                cube_center = min_corner + half_cube_size
                
                # 3. Narrow-Band Filtering
                dist = abs(sdf(cube_center) - iso_level)
                if dist > half_cube_diag:
                    continue
                
                # 4. Cube Construction
                cube_vertices = []
                cube_sdf_vals = []
                for v in range(8):
                    # Vertex offset based on binary representation of v
                    offset = Vec3(
                        (v & 1) * cube_size.x,
                        (v & 2) * cube_size.y,
                        (v & 4) * cube_size.z
                    )
                    pos = min_corner + offset
                    cube_vertices.append(pos)
                    cube_sdf_vals.append(sdf(pos))
                
                # 5. Intersection & 6. Triangulation
                # Determine case index C
                case_index = 0
                for v in range(8):
                    if cube_sdf_vals[v] < iso_level: # Convention: < iso is inside/1
                        case_index |= (1 << v)
                
                # Get intersected edges from edgeTable
                edge_mask = edge_table[case_index]
                
                # Calculate intersection points for active edges
                intersections = {}
                for e_idx in range(12):
                    if (edge_mask >> e_idx) & 1:
                        e = edges[e_idx] # e.vert0, e.vert1
                        v1_idx = e.vert0
                        v2_idx = e.vert1
                        
                        val1 = cube_sdf_vals[v1_idx]
                        val2 = cube_sdf_vals[v2_idx]
                        p1 = cube_vertices[v1_idx]
                        p2 = cube_vertices[v2_idx]
                        
                        eps = 1e-5
                        if abs(iso_level - val1) < eps:
                            pt = p1
                        elif abs(val1 - val2) < eps:
                            pt = p1
                        else:
                            mu = (iso_level - val1) / (val2 - val1)
                            pt = p1 + (p2 - p1) * mu
                        intersections[e_idx] = pt
                
                # Generate triangles from triangleTable
                tri_indices = triangle_table[case_index]
                i = 0
                while i < len(tri_indices) and tri_indices[i] != -1:
                    a = tri_indices[i]
                    b = tri_indices[i+1]
                    c = tri_indices[i+2]
                    i += 3
                    
                    # Add triangle to mesh
                    mesh.add_triangle(intersections[a], intersections[b], intersections[c])
                    
    return mesh
```

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of voxels in the grid, but effectively much faster due to narrow-band filtering. The constant factor is reduced by the fraction of voxels intersecting the surface.
*   **Memory Complexity:** $O(V + F)$ where $V$ is the number of vertices and $F$ is the number of triangles in the output mesh. The grid storage is $O(N)$.
*   **Strengths:** Significantly faster than brute-force Marching Cubes for sparse fields or large domains with small objects. Simple to implement.
*   **Limitations:** Requires the SDF to be evaluated at arbitrary points (function pointer). The narrow-band threshold (`HalfCubeDiag`) is a heuristic; if the surface is highly curved or the grid is too coarse, intersections might be missed or artifacts introduced.
*   **When to use:** When reconstructing meshes from SDFs where the domain is large but the object is small, or when performance is critical and the SDF is expensive to evaluate.
*   **When not to use:** When the domain is small and dense, or when the SDF is not available and only discrete voxel data is present.
