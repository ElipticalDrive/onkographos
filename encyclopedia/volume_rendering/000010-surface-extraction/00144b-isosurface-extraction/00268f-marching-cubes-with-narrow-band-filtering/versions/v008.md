# Marching Cubes with Narrow-Band Filtering

Also called: MeshReconstruction::MarchCube

## Overview
This method reconstructs a triangle mesh from a Signed Distance Function (SDF) by evaluating the SDF on a regular grid of cubes, filtering out cubes that are too far from the surface (narrow-band filtering), and applying the standard Marching Cubes algorithm only to the intersected cubes [S1, unofficial]. It differs from standard Marching Cubes by skipping the vast majority of the domain volume, significantly reducing computation time for sparse or bounded surfaces [S1, unofficial].

## How it works
**Inputs:**
- `domain`: A bounding box defined by `min` (Vec3) and `size` (Vec3).
- `sdf`: A function `Fun3s` returning a scalar distance for any 3D position.
- `cubeSize`: The dimensions of each grid cell (Vec3). If not provided, defaults to `domain.size / 50` [S1, unofficial].
- `isoLevel`: The isovalue for surface extraction, defaulting to 0 [S1, unofficial].
- `sdfGrad`: An optional gradient function for vertex normals. If `nullptr`, numerical approximation is used [G].

**Outputs:**
- `mesh`: A triangle mesh containing vertices and indices.

**Data Structures:**
- `Cube`: Represents a single grid cell.
  - `pos[8]`: Array of 8 vertex positions (Vec3).
  - `sdf[8]`: Array of 8 SDF values (double) at the vertices.
- `signConfigToIntersectedEdges`: A lookup table of 256 integers (12-bit bitmasks). Index is the configuration of signs (positive/negative) at the 8 vertices. Value indicates which of the 12 edges are intersected [S1, unofficial].
- `edges`: An array of 12 `Edge` structs.
  - `edgeFlag`: 12-bit integer ($2^i$ for edge $i$).
  - `vert0`, `vert1`: Indices of the two vertices defining the edge (0-7).

**Numbered Steps:**

1.  **Calculate Grid Dimensions:**
    Compute the number of cubes along each axis:
    $$
    \text{NumX} = \lceil \text{domain.size.x} / \text{cubeSize.x} \rceil
    $$
    $$
    \text{NumY} = \lceil \text{domain.size.y} / \text{cubeSize.y} \rceil
    $$
    $$
    \text{NumZ} = \lceil \text{domain.size.z} / \text{cubeSize.z} \rceil
    $$

2.  **Calculate Geometric Constants:**
    $$
    \text{HalfCubeDiag} = \|\text{cubeSize}\| / 2.0
    $$
    $$
    \text{HalfCubeSize} = \text{cubeSize} \times 0.5
    $$

3.  **Iterate Grid:**
    Loop over indices $ix \in [0, \text{NumX})$, $iy \in [0, \text{NumY})$, $iz \in [0, \text{NumZ})$.

4.  **Compute Cube Geometry:**
    Calculate the minimum corner of the current cube in domain space:
    $$
    \text{min} = \text{domain.min} + \{ ix \cdot \text{cubeSize.x}, iy \cdot \text{cubeSize.y}, iz \cdot \text{cubeSize.z} \}
    $$
    Calculate the cube center:
    $$
    \text{cubeCenter} = \text{min} + \text{HalfCubeSize}
    $$

5.  **Narrow-Band Filter:**
    Calculate the distance from the cube center to the isosurface:
    $$
    \text{dist} = | \text{sdf}(\text{cubeCenter}) - \text{isoLevel} |
    $$
    If $\text{dist} > \text{HalfCubeDiag}$, the cube cannot intersect the surface. Continue to the next cube [S1, unofficial].

6.  **Sample SDF:**
    Construct a `Cube` object. Sample the SDF at the 8 vertices of the cube to populate `Cube.sdf[8]` and store positions in `Cube.pos[8]` [S1, unofficial].

7.  **Intersect:**
    Call `cube.Intersect(isoLevel)`:
    - Determine the sign configuration $C$ based on `Cube.sdf[8]`.
    - Look up intersected edges using `signConfigToIntersectedEdges[C]`.
    - For each intersected edge $i$, calculate the intersection point using linear interpolation:
      $$
      \mu = \frac{\text{isoLevel} - \text{sdf}[v_0]}{\text{sdf}[v_1] - \text{sdf}[v_0]}
      $$
      $$
      P_{\text{intersect}} = P_{v_0} + \mu (P_{v_1} - P_{v_0})
      $$
      where $v_0, v_1$ are the vertex indices of edge $i$. Handle edge cases where denominators are near zero or values are exactly equal to `isoLevel` using a small epsilon ($10^{-5}$) [S1, unofficial].

8.  **Triangulate:**
    Call `Triangulate(intersect, sdfGrad, mesh)`:
    - Use the standard Marching Cubes lookup table (or the provided `signConfigToIntersectedEdges` logic extended to triangles) to determine which triangles to form from the intersection points.
    - Generate vertex normals using `sdfGrad` if provided, otherwise compute via numerical gradient [G].
    - Add triangles to `mesh` [S1, unofficial].

**Pseudocode:**

```python
def MarchingCubesNarrowBand(domain, sdf, cubeSize=None, isoLevel=0.0, sdfGrad=None):
    if cubeSize is None:
        cubeSize = domain.size / 50.0

    numX = ceil(domain.size.x / cubeSize.x)
    numY = ceil(domain.size.y / cubeSize.y)
    numZ = ceil(domain.size.z / cubeSize.z)

    halfCubeDiag = length(cubeSize) / 2.0
    halfCubeSize = cubeSize * 0.5

    mesh = Mesh()

    for ix in range(numX):
        for iy in range(numY):
            for iz in range(numZ):
                # Calculate cube min corner
                minCorner = domain.min + Vec3(ix * cubeSize.x, iy * cubeSize.y, iz * cubeSize.z)
                cubeCenter = minCorner + halfCubeSize

                # Narrow-band filter
                dist = abs(sdf(cubeCenter) - isoLevel)
                if dist > halfCubeDiag:
                    continue

                # Sample vertices
                vertices = []
                sdfValues = []
                for vx in range(2):
                    for vy in range(2):
                        for vz in range(2):
                            pos = minCorner + Vec3(vx * cubeSize.x, vy * cubeSize.y, vz * cubeSize.z)
                            vertices.append(pos)
                            sdfValues.append(sdf(pos))

                # Determine configuration
                config = 0
                for i in range(8):
                    if sdfValues[i] < isoLevel:
                        config |= (1 << i)

                # Get intersected edges
                intersectedEdgesMask = signConfigToIntersectedEdges[config]
                intersectionPoints = []

                for edgeIdx in range(12):
                    if (intersectedEdgesMask >> edgeIdx) & 1:
                        edge = edges[edgeIdx]
                        v0 = vertices[edge.vert0]
                        v1 = vertices[edge.vert1]
                        s0 = sdfValues[edge.vert0]
                        s1 = sdfValues[edge.vert1]

                        # Linear interpolation
                        denom = s1 - s0
                        if abs(denom) < 1e-5:
                            # Fallback if values are equal or isoLevel matches exactly
                            if abs(s0 - isoLevel) < 1e-5:
                                intersectionPoints.append(v0)
                            else:
                                intersectionPoints.append(v0) # Arbitrary, but consistent
                            continue
                        
                        mu = (isoLevel - s0) / denom
                        p = v0 + mu * (v1 - v0)
                        intersectionPoints.append(p)

                # Triangulate
                # Note: Standard MC triangulation logic maps the 12 intersection points 
                # (indexed by edge index) to triangles based on the config.
                # This implementation assumes a helper function handles the specific 
                # triangle topology for the given config.
                triangles = TriangulateFromConfig(config, intersectionPoints)
                mesh.add_triangles(triangles)

    return mesh
```

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of cubes in the narrow band. Standard Marching Cubes is $O(V)$ where $V$ is the total volume. For sparse surfaces, this method is significantly faster.
- **Memory Complexity:** $O(N)$ for the mesh output. The grid traversal is iterative, requiring minimal auxiliary memory [S1, unofficial].
- **Strengths:** Fast execution due to skipping empty space; simple implementation; no dependencies [S1, unofficial].
- **Limitations:** Requires a valid SDF; narrow-band threshold must be chosen carefully to avoid missing thin features; standard Marching Cubes artifacts (e.g., ambiguity cases) are not resolved [S1, unofficial].

## Background
This method is implemented in the `MeshReconstruction` library by Magnus2 [S1, unofficial]. It leverages the standard Marching Cubes algorithm [S1, unofficial] and optimizes it for SDF-based reconstruction by filtering cubes based on distance to the surface. The library is self-contained, uses precomputed lookup tables, and is licensed under MIT [S1, unofficial].
