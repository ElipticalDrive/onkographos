# Marching Cubes with Narrow-Band Filtering

Also called: MeshReconstruction::MarchCube

## Overview
This method reconstructs a triangle mesh from a Signed Distance Function (SDF) by evaluating the function on a regular grid of cubes, filtering out cubes that are too far from the surface (narrow-band filtering), and applying the standard Marching Cubes algorithm to the remaining intersected cubes [S1, unofficial]. It differs from standard Marching Cubes by skipping the vast majority of the domain volume, significantly reducing computation time for sparse or bounded surfaces [S1, unofficial].

## How it works
**Inputs:**
- `domain`: A 3D bounding box defined by `min` (Vec3) and `size` (Vec3).
- `sdf`: A function `Fun3s` that returns a scalar distance value for any 3D position.
- `cubeSize`: The dimensions of each grid cell (Vec3). If not provided, defaults to `domain.size / 50` [S1, unofficial].
- `isoLevel`: The isovalue for surface extraction, defaulting to 0 [S1, unofficial].
- `sdfGrad`: An optional gradient function for vertex normals. If `nullptr`, numerical approximation is used [S1, unofficial].

**Outputs:**
- `mesh`: A triangle mesh containing vertices and indices.

**Data Structures:**
- `Cube`: Represents a single grid cell.
  - `pos[8]`: Array of 8 vertex positions (Vec3).
  - `sdf[8]`: Array of 8 scalar SDF values at the vertices.
- `Edge`: Defines an edge of the cube.
  - `edgeFlag`: 12-bit integer flag (powers of 2: 1, 2, 4, ..., 2048).
  - `vert0`, `vert1`: Indices of the two vertices connected by the edge (0-7).
- `signConfigToIntersectedEdges`: A lookup table of 256 integers (32-bit). Each integer is a bitmask where the $k$-th bit is set if the $k$-th edge intersects the isosurface.

**Algorithm Steps:**

1.  **Calculate Grid Dimensions:**
    Compute the number of cubes along each axis:
    $$
    \text{NumX} = \lceil \text{domain.size.x} / \text{cubeSize.x} \rceil
    $$
    $$
    \text{NumY} = \lceil \text{domain.size.y} / \text{cubeSize.y} \rceil
    $$
    $$
    \text{NumZ} = \lceil \text{domain.size.z} / \text{cubeSize.z} \rceil
    $$

2.  **Calculate Geometric Constants:**
    $$
    \text{HalfCubeDiag} = \|\text{cubeSize}\| / 2.0
    $$
    $$
    \text{HalfCubeSize} = \text{cubeSize} \times 0.5
    $$

3.  **Iterate Grid:**
    For each grid index $(ix, iy, iz)$ where $0 \le ix < \text{NumX}$, $0 \le iy < \text{NumY}$, $0 \le iz < \text{NumZ}$:

    a.  **Calculate Cube Corner:**
        $$
        \text{min} = \text{domain.min} + \{ ix \cdot \text{cubeSize.x}, iy \cdot \text{cubeSize.y}, iz \cdot \text{cubeSize.z} \}
        $$

    b.  **Calculate Cube Center and Distance:**
        $$
        \text{cubeCenter} = \text{min} + \text{HalfCubeSize}
        $$
        $$
        \text{dist} = | \text{sdf}(\text{cubeCenter}) - \text{isoLevel} |
        $$

    c.  **Narrow-Band Filter:**
        If $\text{dist} > \text{HalfCubeDiag}$, the cube is too far from the surface to intersect it. Continue to the next cube [S1, unofficial].

    d.  **Construct Cube:**
        Create a `Cube` object. Sample the SDF at the 8 vertices of the cube to populate `Cube.sdf[8]` and store positions in `Cube.pos[8]`.

    e.  **Intersect:**
        Call `cube.Intersect(isoLevel)` to determine which edges intersect the isosurface. This uses the `signConfigToIntersectedEdges` lookup table based on the signs of the 8 vertex SDF values relative to `isoLevel`.

    f.  **Triangulate:**
        Call `Triangulate(intersect, sdfGrad, mesh)` to generate triangles from the intersection points and add them to the mesh.

**Pseudocode:**

```python
def marching_cubes_narrow_band(domain, sdf, cube_size=None, iso_level=0.0, sdf_grad=None):
    if cube_size is None:
        cube_size = domain.size / 50.0

    num_x = ceil(domain.size.x / cube_size.x)
    num_y = ceil(domain.size.y / cube_size.y)
    num_z = ceil(domain.size.z / cube_size.z)

    half_cube_diag = length(cube_size) / 2.0
    half_cube_size = cube_size * 0.5

    mesh = Mesh()

    for ix in range(num_x):
        for iy in range(num_y):
            for iz in range(num_z):
                # Calculate cube minimum corner
                min_corner = domain.min + Vec3(ix * cube_size.x, iy * cube_size.y, iz * cube_size.z)
                
                # Calculate cube center
                cube_center = min_corner + half_cube_size
                
                # Calculate distance to isosurface at center
                dist = abs(sdf(cube_center) - iso_level)
                
                # Narrow-band filter: skip if too far
                if dist > half_cube_diag:
                    continue
                
                # Construct cube and sample SDF at 8 vertices
                cube = Cube(min_corner, cube_size, sdf)
                
                # Find intersection vertices on cube edges
                intersect = cube.intersect(iso_level)
                
                # Generate triangles and add to mesh
                triangulate(intersect, sdf_grad, cube, mesh)
                
    return mesh

class Cube:
    def __init__(self, min_corner, size, sdf):
        self.pos = [
            min_corner,
            min_corner + Vec3(size.x, 0, 0),
            min_corner + Vec3(size.x, size.y, 0),
            min_corner + Vec3(0, size.y, 0),
            min_corner + Vec3(0, 0, size.z),
            min_corner + Vec3(size.x, 0, size.z),
            min_corner + Vec3(size.x, size.y, size.z),
            min_corner + Vec3(0, size.y, size.z)
        ]
        self.sdf = [sdf(p) for p in self.pos]

    def intersect(self, iso_level):
        # Determine sign configuration
        config = 0
        for i in range(8):
            if self.sdf[i] > iso_level:
                config |= (1 << i)
        
        # Lookup intersected edges
        edge_mask = sign_config_to_intersected_edges[config]
        
        intersections = []
        for edge_idx in range(12):
            if edge_mask & (1 << edge_idx):
                edge = edges[edge_idx]
                # Linear interpolation to find intersection point
                p1 = self.pos[edge.vert0]
                p2 = self.pos[edge.vert1]
                v1 = self.sdf[edge.vert0]
                v2 = self.sdf[edge.vert1]
                
                # Handle degenerate cases
                if abs(iso_level - v1) < 1e-5:
                    point = p1
                elif abs(v1 - v2) < 1e-5:
                    point = p1
                else:
                    mu = (iso_level - v1) / (v2 - v1)
                    point = p1 + (p2 - p1) * mu
                intersections.append(point)
        return intersections
```

**Parameters:**
- `NumCubes`: Integer constant defaulting to 50, used to calculate default `cubeSize` as `domain.size * (1.0 / NumCubes)` [S1, unofficial].
- `isoLevel`: Default 0. Changing this moves the reconstructed surface [S1, unofficial].
- `sdfGrad`: Optional gradient function. If `nullptr`, numerical approximation is used [S1, unofficial].

**Pitfalls:**
- **Narrow-band filtering threshold:** If the distance from the cube center to the isosurface (`dist`) exceeds the half-diagonal of the cube (`HalfCubeDiag`), the cube cannot intersect the surface. Skipping these cubes is critical for performance but requires accurate SDF evaluation at the center [S1, unofficial].
- **Precision:** Linear interpolation uses a small epsilon ($10^{-5}$) to handle cases where vertex values are very close to the isovalue or each other [S1, unofficial].

## Subtopics

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of cubes in the narrow band. Standard Marching Cubes is $O(V)$ where $V$ is the total volume of voxels. For sparse surfaces, this method is significantly faster.
- **Memory Complexity:** Proportional to the number of intersected cubes and resulting triangles.
- **Performance:** The library is described as "fast" due to precomputed lookup tables and the narrow-band approach which excludes cubes far from the surface [S1, unofficial].
- **Strengths:** Efficient for bounded surfaces; avoids processing empty space.
- **Limitations:** Requires a valid SDF. Performance degrades if the narrow band is too wide (i.e., surface is dense or fills the domain).

## Background
This method is implemented in the `MeshReconstruction` C++ library by Magnus2 [S1, unofficial]. It combines the classic Marching Cubes algorithm with a narrow-band filtering optimization. The library is self-contained, requires C++14, and is licensed under MIT [S1, unofficial].
