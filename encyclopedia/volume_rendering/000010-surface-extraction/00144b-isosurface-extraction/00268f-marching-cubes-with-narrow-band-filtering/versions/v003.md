# Marching Cubes with Narrow-Band Filtering

Also called: MeshReconstruction::MarchCube

## Overview
This method reconstructs a triangle mesh from a Signed Distance Function (SDF) by evaluating the field on a grid of cubes, filtering out cubes that are too far from the surface (narrow-band filtering), and applying the standard Marching Cubes algorithm to the remaining cubes [S1, unofficial]. It differs from standard Marching Cubes by skipping the vast majority of voxels that do not intersect the isosurface, significantly reducing computation time for sparse or bounded domains [S1, unofficial].

## How it works
**Inputs:**
*   `sdf`: A function or data structure evaluating the signed distance to the surface at any 3D point.
*   `domain`: A bounding box (`Rect3`) defined by `min` and `size` vectors, enclosing the region of interest [S1, unofficial].
*   `cubeSize`: The side length of the cubic voxels. If not provided, it is derived from `NumCubes` (default 50) as `domain.size / NumCubes` [S1, unofficial].
*   `isoLevel`: The isovalue for extraction (default 0 for SDFs) [S1, unofficial].
*   `sdfGrad`: An optional gradient function for vertex normals. If `nullptr`, normals are computed numerically [S1, unofficial].

**Data Structures:**
*   `Cube`: Represents a single voxel. Stores the 8 vertex positions (`pos[8]`) and 8 SDF values (`sdf[8]`) relative to the domain space [S1, unofficial].
*   `Edge`: Defines the 12 edges of a cube. Each edge has a 12-bit bitmask flag, and indices for its two vertices (`vert0`, `vert1`) [S1, unofficial].
    *   Edge 0: vertices (0,1), flag 1
    *   Edge 1: vertices (1,2), flag 2
    *   Edge 2: vertices (2,3), flag 4
    *   Edge 3: vertices (3,0), flag 8
    *   Edge 4: vertices (4,5), flag 16
    *   Edge 5: vertices (5,6), flag 32
    *   Edge 6: vertices (6,7), flag 64
    *   Edge 7: vertices (7,4), flag 128
    *   Edge 8: vertices (0,4), flag 256
    *   Edge 9: vertices (1,5), flag 512
    *   Edge 10: vertices (2,6), flag 1024
    *   Edge 11: vertices (3,7), flag 2048 [S1, unofficial].
*   `signConfigToIntersectedEdges`: A lookup table of 256 integers. Each integer is a 12-bit bitmask where bit $k$ is set if the isosurface intersects edge $k$ [S1, unofficial].

**Algorithm Steps:**

1.  **Grid Setup**: Calculate grid dimensions:
    $$ \text{NumX} = \lceil \text{domain.size.x} / \text{cubeSize.x} \rceil $$
    $$ \text{NumY} = \lceil \text{domain.size.y} / \text{cubeSize.y} \rceil $$
    $$ \text{NumZ} = \lceil \text{domain.size.z} / \text{cubeSize.z} \rceil $$
    Calculate geometric constants:
    $$ \text{HalfCubeDiag} = \|\text{cubeSize}\| / 2.0 $$
    $$ \text{HalfCubeSize} = \text{cubeSize} \times 0.5 $$
    [S1, unofficial].

2.  **Voxel Iteration**: Iterate over grid indices $ix, iy, iz$.
    *   Calculate cube minimum corner:
        $$ \text{min} = \text{domain.min} + \{ ix \cdot \text{cubeSize.x}, iy \cdot \text{cubeSize.y}, iz \cdot \text{cubeSize.z} \} $$
    *   Calculate cube center:
        $$ \text{cubeCenter} = \text{min} + \text{HalfCubeSize} $$
    *   Evaluate distance to isosurface:
        $$ \text{dist} = | \text{sdf}(\text{cubeCenter}) - \text{isoLevel} | $$
    [S1, unofficial].

3.  **Narrow-Band Filtering**: If $\text{dist} > \text{HalfCubeDiag}$, the cube is too far from the surface to intersect it. Continue to the next cube [S1, unofficial].

4.  **Cube Construction**: For cubes passing the filter, construct a `Cube` object.
    *   Sample the SDF at the 8 vertices of the cube to populate `Cube.sdf[8]`.
    *   Store vertex positions in `Cube.pos[8]` [S1, unofficial].

5.  **Intersection**: Call `cube.Intersect(isoLevel)`.
    *   Compute the case index $C$ by checking the sign of each vertex's SDF value relative to `isoLevel`.
    *   Use `signConfigToIntersectedEdges[C]` to determine which edges are intersected.
    *   For each intersected edge, calculate the intersection point using linear interpolation:
        $$ \mu = \frac{\text{isoLevel} - \text{sdf}[i_1]}{\text{sdf}[i_2] - \text{sdf}[i_1]} $$
        $$ \text{point} = \text{pos}[i_1] + (\text{pos}[i_2] - \text{pos}[i_1]) \cdot \mu $$
        [S1, unofficial].
    *   Handle edge cases: If $|\text{isoLevel} - \text{sdf}[i]| < \epsilon$ (where $\epsilon = 10^{-5}$), the vertex is on the surface; return the vertex position directly [S1, unofficial].

6.  **Triangulation**: Call `Triangulate(intersect, sdfGrad, mesh)`.
    *   Use the standard Marching Cubes `triangleTable` (from parent article) to generate triangles from the intersection points.
    *   Compute vertex normals using `sdfGrad` if provided, otherwise approximate numerically [S1, unofficial].
    *   Add generated triangles to the output mesh [S1, unofficial].

    half_cube_diag = vector_norm(cube_size) / 2.0
    half_cube_size = cube_size * 0.5
    
    num_x = ceil(domain.size.x / cube_size.x)
    num_y = ceil(domain.size.y / cube_size.y)
    num_z = ceil(domain.size.z / cube_size.z)
    
    mesh = Mesh()
    
    # 2. Voxel Iteration
    for ix in range(num_x):
        for iy in range(num_y):
            for iz in range(num_z):
                # Calculate cube min corner
                min_corner = domain.min + vec3(ix * cube_size.x, iy * cube_size.y, iz * cube_size.z)
                
                # Calculate cube center
                cube_center = min_corner + half_cube_size
                
                # Distance to isosurface
                dist = abs(sdf(cube_center) - iso_level)
                
                # 3. Narrow-Band Filtering
                if dist > half_cube_diag:
                    continue
                
                # 4. Cube Construction
                cube = Cube(min_corner, cube_size, sdf)
                
                # 5. Intersection
                intersections = cube.intersect(iso_level)
                
                # 6. Triangulation
                triangulate(intersections, sdf_grad, mesh)
                
    return mesh

## Operating characteristics
*   **Time Complexity**: $O(N)$ where $N$ is the number of voxels in the grid, but the constant factor is significantly reduced by the narrow-band filter. Only voxels within a distance of `HalfCubeDiag` from the surface are processed [S1, unofficial].
*   **Memory Complexity**: $O(1)$ auxiliary memory per voxel, plus $O(T)$ for the output mesh where $T$ is the number of triangles [S1, unofficial].
*   **Performance**: The library is described as "fast" due to the narrow-band approach excluding cubes far from the surface [S1, unofficial].
*   **Strengths**: Efficient for SDFs where the surface is localized within a larger domain. Avoids processing empty space.
*   **Limitations**: Requires the SDF to be available for arbitrary queries (not just grid samples). The narrow-band threshold (`HalfCubeDiag`) is fixed; if the surface has high-frequency details smaller than the cube size, they may be missed or aliased.
