# Marching Cubes with Narrow-Band Filtering

Also called: MeshReconstruction::MarchCube

## Overview
A method to reconstruct a triangle mesh from a signed distance function (SDF) by evaluating the SDF on a grid of cubes, filtering cubes based on distance to the surface (narrow-band), and applying the Marching Cubes algorithm to intersected cubes [S1, unofficial]. It sets itself apart from standard Marching Cubes by skipping cells that are too far from the isosurface, significantly reducing the number of cells processed for sparse or localized surfaces [S1, unofficial].

## How it works
**Inputs:**
- `domain`: A bounding box defined by `min` (Vec3) and `size` (Vec3).
- `sdf`: A function `Fun3s` that returns a scalar distance for a given 3D position.
- `cubeSize`: The dimensions of each cubic cell (Vec3). If not provided, calculated from `NumCubes` (default 50) as `domain.size * (1.0 / NumCubes)` [S1, unofficial].
- `isoLevel`: The scalar value defining the surface (default 0) [S1, unofficial].
- `sdfGrad`: Optional gradient function for vertex normals. If `nullptr`, numerical approximation is used [S1, unofficial].

**Outputs:**
- `mesh`: A triangle mesh containing vertices and indices.

**Data Structures:**
- `Cube`: Represents a single grid cell.
  - `pos[8]`: Array of 8 vertex positions (Vec3).
  - `sdf[8]`: Array of 8 scalar SDF values at vertices.
  - `space`: The domain bounding box (Rect3).
- `Edge`: Defines an edge of the cube.
  - `edgeFlag`: 12-bit integer flag (powers of 2: 1, 2, 4, ..., 2048).
  - `vert0`, `vert1`: Indices of the two vertices connected by the edge (0-7).
- `signConfigToIntersectedEdges`: Lookup table of 256 integers (12-bit bitstrings). Maps the 8-bit sign configuration of a cube's vertices to the set of intersected edges [S1, unofficial].

**Steps:**
1.  **Calculate Grid Dimensions:**
    $$ \text{NumX} = \lceil \text{domain.size.x} / \text{cubeSize.x} \rceil $$
    $$ \text{NumY} = \lceil \text{domain.size.y} / \text{cubeSize.y} \rceil $$
    $$ \text{NumZ} = \lceil \text{domain.size.z} / \text{cubeSize.z} \rceil $$
    [S1, unofficial]

2.  **Calculate Geometric Constants:**
    $$ \text{HalfCubeDiag} = \|\text{cubeSize}\| / 2.0 $$
    $$ \text{HalfCubeSize} = \text{cubeSize} \times 0.5 $$
    [S1, unofficial]

3.  **Iterate Grid:**
    For each grid index $(i_x, i_y, i_z)$:
    a.  Calculate cube minimum corner:
        $$ \text{min} = \text{domain.min} + \{ i_x \cdot \text{cubeSize.x}, i_y \cdot \text{cubeSize.y}, i_z \cdot \text{cubeSize.z} \} $$
        [S1, unofficial]
    b.  Calculate cube center:
        $$ \text{cubeCenter} = \text{min} + \text{HalfCubeSize} $$
        [S1, unofficial]
    c.  Calculate distance to isosurface:
        $$ \text{dist} = | \text{sdf}(\text{cubeCenter}) - \text{isoLevel} | $$
        [S1, unofficial]
    d.  **Narrow-Band Filter:** If $\text{dist} > \text{HalfCubeDiag}$, the cube is too far from the surface to intersect it. Continue to the next cube [S1, unofficial].

4.  **Construct Cube:**
    Create a `Cube` object using `domain` and `sdf`. Sample the SDF at the 8 vertices of the cube to populate `Cube.sdf` and `Cube.pos` [S1, unofficial].

5.  **Intersect:**
    Call `cube.Intersect(isoLevel)`.
    a.  Determine the sign configuration (256 cases) based on the signs of `Cube.sdf[0..7]` relative to `isoLevel`.
    b.  Use `signConfigToIntersectedEdges` to identify which of the 12 edges are intersected.
    c.  For each intersected edge, calculate the intersection point using linear interpolation:
        $$ \mu = \frac{\text{isoLevel} - \text{sdf}[i_1]}{\text{sdf}[i_2] - \text{sdf}[i_1]} $$
        $$ \text{point} = \text{pos}[i_1] + (\text{pos}[i_2] - \text{pos}[i_1]) \cdot \mu $$
        Handle edge cases where $\text{sdf}[i_1] \approx \text{isoLevel}$ or $\text{sdf}[i_2] \approx \text{isoLevel}$ (return vertex) or $\text{sdf}[i_1] \approx \text{sdf}[i_2]$ (return $p_1$) [S1, unofficial].

6.  **Triangulate:**
    Call `Triangulate(intersect, sdfGrad, mesh)`.
    a.  Generate triangles from the intersection points based on the standard Marching Cubes lookup table (implied by "precomputed lookup tables" [S1, unofficial]).
    b.  Calculate vertex normals using `sdfGrad` if provided, otherwise approximate [S1, unofficial].
    c.  Add triangles to `mesh` [S1, unofficial].

**Pseudocode:**

    if cube_size is None:
        num_cubes = 50
        cube_size = domain.size * (1.0 / num_cubes)

    half_cube_diag = norm(cube_size) / 2.0
    half_cube_size = cube_size * 0.5

    num_x = ceil(domain.size.x / cube_size.x)
    num_y = ceil(domain.size.y / cube_size.y)
    num_z = ceil(domain.size.z / cube_size.z)

    mesh = Mesh()

    for ix in range(num_x):
        for iy in range(num_y):
            for iz in range(num_z):
                min_corner = domain.min + vec3(ix * cube_size.x, iy * cube_size.y, iz * cube_size.z)
                cube_center = min_corner + half_cube_size
                dist = abs(sdf(cube_center) - iso_level)

                if dist > half_cube_diag:
                    continue

                cube = Cube(domain, sdf)
                cube.min_corner = min_corner
                cube.cube_size = cube_size
                cube.sample_sdf()

                intersect_points = cube.intersect(iso_level)
                if intersect_points is not None:
                    triangulate(intersect_points, sdf_grad, mesh)

    return mesh

## Operating characteristics
- **Time Complexity:** Proportional to the number of cubes in the narrow band, not the entire volume. This makes it significantly faster than standard Marching Cubes for sparse SDFs [S1, unofficial].
- **Memory Complexity:** Depends on the number of intersected cubes and the resulting mesh size. The lookup tables are small (256 integers for edge flags, 12 edges) [S1, unofficial].
- **Strengths:** Fast due to precomputed lookup tables and narrow-band filtering which excludes cubes far from the surface [S1, unofficial]. Self-contained, no dependencies [S1, unofficial].
- **Limitations:** Requires a Signed Distance Function (SDF). The narrow-band approach may miss thin structures if the cube size is too large relative to the feature size, as cubes far from the center might be skipped even if they intersect the surface (though the `HalfCubeDiag` check is a conservative bound) [S1, unofficial].
