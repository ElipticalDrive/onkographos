# Trilinear Isosurface Intersection

Also called: Cubic root finding for isosurface, Dual Isosurfacing using Ray Intersection, Isosurface Intersection via Cubic Polynomial, Ray Intersection for Dual Isosurfacing, Ray-Isosurface Intersection Method, isoCrossing

## Overview
Trilinear Isosurface Intersection detects if a ray crosses an isosurface defined by a threshold value within a hexahedral cell of a structured grid [S1, S2, S3]. It solves for the ray position where the trilinear interpolation of the eight cell corner values yields the desired isovalue [S2, S3]. Unlike Dual Contouring which requires Hermite data (normals) to determine point placement, this method computes intersection points directly using cell diagonals or arbitrary rays, relying solely on vertex scalar values [S4]. It differs from [Binary Search IsoSurface Extraction](1316-binary-search-isosurface-extraction.md) by solving an analytical cubic equation rather than iteratively narrowing intervals, and from [Hybrid Implicit Isosurface Ray Tracing](3832-hybrid-implicit-isosurface-ray-tracing.md) by using the exact trilinear interpolant for the intersection test rather than a simplified or hybrid approximation.

## How it works
**Inputs:**
*   Ray origin $\mathbf{O}$ and direction $\mathbf{D}$.
*   Eight scalar values $v_{ijk}$ at the cell corners $(i,j,k) \in \{0,1\}^3$.
*   Isosurface threshold value $I$ (default 0.0f) [S1].

**Outputs:**
*   Boolean indicating intersection.
*   Parameter $t$ of the first positive root.
*   Output value $v$ at the crossing point [S1].

**Data Structures:**
The cell is represented in parametric coordinates $(u,v,w) \in [0,1]^3$ with vertices at $(0,0,0)$ to $(1,1,1)$ [S4]. The scalar field is defined by the corner values.

**Steps:**

1.  **Pre-check:** Compute the minimum and maximum of the eight corner values. If the isovalue $I$ is not within $[min, max]$, no intersection exists in this cell [S2, S3].
2.  **Formulate Trilinear Equation:** Define the trilinear interpolant $f(u,v,w)$ such that $f(u,v,w) = I$ [S4].
    The parametric form is:
    $$ f(u, v, w) = \sum_{i=0}^1 \sum_{j=0}^1 \sum_{k=0}^1 (1 - U_i)(1 - V_j)(1 - W_k) v_{ijk} $$
    where $U_i = |u - u_i|$, $V_j = |v - v_j|$, and $W_k = |w - w_k|$ [S4].
    Alternatively, using local coordinates relative to the cell minimum $(x_{min}, y_{min}, z_{min})$:
    $$ f(x, y, z) = \left( \sum_{i, j, k=\{0,1\}} x_i y_j z_k v_{ijk} \right) - I = 0 $$
    where $x_0 = x_{min} - x$, $x_1 = x - x_{min}$ (and similarly for $y, z$) [S5, unofficial].
3.  **Substitute Ray:** Represent the ray as $\mathbf{r}(t) = \mathbf{O} + t\mathbf{D}$. Substitute the parametric ray coordinates into the trilinear equation to form a cubic polynomial in $t$:
    $$ G_3 t^3 + G_2 t^2 + G_1 t + G_0 = 0 $$
    The coefficients $G_0, G_1, G_2, G_3$ are derived from the corner values and ray parameters [S4].
4.  **Solve Cubic:** Determine the real roots of the polynomial in the interval $t \in [0, 1]$.
    *   If $G_3 = 0$, solve the quadratic $G_2 t^2 + G_1 t + G_0 = 0$ using discriminant $D_2 = G_1^2 - 4G_2G_0$ [S4].
    *   If $G_3 \neq 0$, compute the discriminant $D_3$ to determine root nature [S4]:
        $$ \delta^2 = \frac{G_2^2 - 3G_3G_1}{9G_3^2} $$
        $$ (x_N, y_N) = \left( -\frac{G_2}{3G_3}, G_3x_N^3 + G_2^2x_N^2 + G_1x_N + G_0 \right) $$
        $$ D_3 = y_N^2 - 4G_3^2 \delta^3 $$
        *   $D_3 > 0$: 1 real, 2 imaginary.
        *   $D_3 = 0$: 3 equal real (if $y_N=0$) or 1 distinct real, 2 equal real (if $y_N \neq 0$).
        *   $D_3 < 0$: 3 distinct real roots [S4].
    *   **Root Finding Strategy:** Sources differ on the optimal solver. Parker et al. use an analytical solver based on Schwarze's method [S2, S3][S5, unofficial]. Marmitt et al. and subsequent implementations (e.g., [S2, S3][S5, unofficial]) use the Neubauer iterative root finder, which iteratively re-parameterizes the ray into sub-intervals until a sign change is detected. The iterative method is cited as slightly faster and numerically stable in single precision [S2, S3][S5, unofficial].
5.  **Select Hit:** Evaluate the ray $\mathbf{r}(t)$ at the smallest positive root $t$ to find the intersection point [S2, S3][S5, unofficial].

**Pseudocode:**
```python
def trilinear_isosurface_intersection(ray_origin, ray_dir, corner_values, isovalue):
    """
    ray_origin: (x, y, z)
    ray_dir: (dx, dy, dz)
    corner_values: list of 8 floats, indexed by (i,j,k) where i,j,k in {0,1}
    isovalue: float
    Returns: (hit: bool, t: float)
    """
    # 1. Pre-check
    min_val = min(corner_values)
    max_val = max(corner_values)
    if not (min_val <= isovalue <= max_val):
        return False, 0.0

    # 2. Compute Cubic Coefficients G3, G2, G1, G0
    # The coefficients depend on the specific expansion of the trilinear form
    # substituted with the ray equation.
    # Let the ray be x(t) = ox + t*dx, y(t) = oy + t*dy, z(t) = oz + t*dz.
    # The trilinear function is f(x,y,z) = sum( w_ijk * x_i * y_j * z_k )
    # where x_0 = x_min - x, x_1 = x - x_min, etc.
    # This results in a cubic polynomial in t.
    # Implementation note: The exact expansion of G0..G3 from corner values
    # and ray parameters is complex. Standard references [S4] provide the
    # derivation in Appendix A. For implementation, one typically expands
    # the polynomial terms directly.
    
    # Simplified representation of coefficient calculation based on [S4] structure:
    # G3, G2, G1, G0 = compute_cubic_coefficients(ray_origin, ray_dir, corner_values)
    # Note: Actual computation requires expanding the trilinear basis functions.
    # We assume a helper function exists that performs this algebraic expansion.
    G3, G2, G1, G0 = compute_cubic_coefficients(ray_origin, ray_dir, corner_values)

    # 3. Solve for roots
    roots = []
    
    if abs(G3) < 1e-9:
        # Quadratic case
        if abs(G2) < 1e-9:
            # Linear case G1*t + G0 = 0
            if abs(G1) > 1e-9:
                t = -G0 / G1
                if 0.0 <= t <= 1.0:
                    roots.append(t)
        else:
            D2 = G1**2 - 4 * G2 * G0
            if D2 >= 0:
                sqrt_D2 = sqrt(D2)
                t1 = (-G1 + sqrt_D2) / (2 * G2)
                t2 = (-G1 - sqrt_D2) / (2 * G2)
                if 0.0 <= t1 <= 1.0: roots.append(t1)
                if 0.0 <= t2 <= 1.0: roots.append(t2)
    else:
        # Cubic case
        # Using Cardan's method or Neubauer iterative approach
        # Here we outline the discriminant logic from [S4]
        delta_sq = (G2**2 - 3 * G3 * G1) / (9 * G3**2)
        x_N = -G2 / (3 * G3)
        y_N = G3 * x_N**3 + G2**2 * x_N**2 + G1 * x_N + G0
        D3 = y_N**2 - 4 * G3**2 * delta_sq**1.5 # Note: delta^3 in source, delta_sq is delta^2
        
        # Source [S4] states: D3 = y_N^2 - 4 * G3^2 * delta^3
        # Since delta^2 is computed, delta^3 = delta * delta^2. 
        # However, standard Cardan uses discriminant Delta = (y_N/2)^2 + (delta/3)^3 ?
        # We follow the source's specific discriminant definition for root classification.
        
        # For implementation, one would use a robust cubic solver (e.g., from [S2, S3][S5, unofficial])
        # that handles the cases D3 > 0, D3 = 0, D3 < 0.
        roots = solve_cubic_roots(G3, G2, G1, G0)

    # 4. Select smallest positive root
    valid_roots = [t for t in roots if 0.0 < t <= 1.0]
    if valid_roots:
        t_hit = min(valid_roots)
        return True, t_hit
    else:
        return False, 0.0

def compute_cubic_coefficients(ox, oy, oz, dx, dy, dz, v):
    """
    Computes G3, G2, G1, G0 for the trilinear isosurface intersection.
    v is the array of 8 corner values v[i][j][k].
    This function encapsulates the algebraic expansion described in [S4] Appendix A.
    """
    # The trilinear interpolant in parametric space (u,v,w) is:
    # f(u,v,w) = sum_{i,j,k} (1-U_i)(1-V_j)(1-W_k) v_ijk
    # where U_i = |u - u_i|. In the unit cube, u_i is 0 or 1.
    # (1-U_i) is (1-u) if i=0, u if i=1.
    # Let x(u) = ox + t*dx. We map x to u in [0,1].
    # Assuming the cell is axis-aligned and unit sized for simplicity of coefficient derivation:
    # u = x - ox, v = y - oy, w = z - oz (if ray starts at 0,0,0)
    # Generally, u(t) = (ox + t*dx - xmin) / (xmax - xmin)
    
    # For the purpose of this article, we assume the cell is normalized to [0,1]^3
    # and the ray is transformed into this space.
    # The coefficients are derived from the polynomial expansion of:
    # sum_{i,j,k} basis_i(u) basis_j(v) basis_k(w) v_ijk - I = 0
    
    # Basis functions:
    # b0(u) = 1-u, b1(u) = u
    # u(t) = ux + t*du
    # b0(u(t)) = 1 - (ux + t*du) = (1-ux) - t*du
    # b1(u(t)) = ux + t*du
    
    # The product of three linear terms in t yields a cubic.
    # G3 is the coefficient of t^3.
    # G2 is the coefficient of t^2.
    # G1 is the coefficient of t^1.
    # G0 is the constant term (t^0).
    
    # This requires expanding the sum.
    # Let du, dv, dw be the ray direction components in parametric space.
    # Let ux, vy, wz be the ray origin components in parametric space.
    
    # We define the basis coefficients for each dimension
    # For dim u:
    # b0_0 = 1 - ux, b0_1 = -du
    # b1_0 = ux, b1_1 = du
    
    # The polynomial is sum_{i,j,k} (b_i0 + b_i1*t)(b_j0 + b_j1*t)(b_k0 + b_k1*t) * v_ijk - I = 0
    
    # Initialize coefficients
    G0 = -I
    G1 = 0.0
    G2 = 0.0
    G3 = 0.0
    
    for i in [0, 1]:
        for j in [0, 1]:
            for k in [0, 1]:
                val = v[i][j][k]
                # Coefficients for u
                u0 = (1 - ux) if i == 0 else ux
                u1 = -du if i == 0 else du
                # Coefficients for v
                v0 = (1 - vy) if j == 0 else vy
                v1 = -dv if j == 0 else dv
                # Coefficients for w
                w0 = (1 - wz) if k == 0 else wz
                w1 = -dw if k == 0 else dw
                
                # Expand (u0 + u1*t)(v0 + v1*t)(w0 + w1*t)
                # Constant term
                G0 += val * u0 * v0 * w0
                # t term
                G1 += val * (u1*v0*w0 + u0*v1*w0 + u0*v0*w1)
                # t^2 term
                G2 += val * (u1*v1*w0 + u1*v0*w1 + u0*v1*w1)
                # t^3 term
                G3 += val * u1 * v1 * w1
                
    return G3, G2, G1, G0
```

## Subtopics

### No-Body-Saddle Midpoint Transformation
A normalization technique for cubes with no body saddles, mapping the theoretical saddle point $m$ into the block via linear scaling and analyzing gradients to constrain topology [S6, S6, unofficial]. It computes the theoretical midpoint $m = (-c/a - d/a, -b/a)$. If $m$ is outside the block, linear transformations are applied to scale the block so $m$ is inside. It assumes $T_{mmm} = 0$ and that gradients along midpoint lines are constant [S6, S6, unofficial]. This variant is used to resolve topological ambiguities in the absence of body saddles by constraining the possible face saddle configurations [S6, S6, unofficial].

### Smooth Trilinear Isosurface
A rendering technique that uses fast trilinear interpolation for ray intersection search but uses the gradient from tricubic interpolation for normal calculation to avoid visual discontinuities at node boundaries [S7]. It performs ray intersection search using the trilinear interpolant, which is faster than tricubic. Tricubic coefficients are stored only at nodes containing the isosurface. Surface normals are calculated using the gradient of the tricubic interpolant instead of the trilinear gradient [S7]. This avoids the grid pattern visual discontinuities caused by trilinear gradient discontinuities [S7].

## Operating characteristics
*   **Time Complexity:** Solving the cubic equation is $O(1)$ per cell intersection. The Neubauer iterative method [S2, S3][S5, unofficial] is cited as slightly faster than analytical solvers like Schwarze's method [S2, S3][S5, unofficial].
*   **Memory Complexity:** $O(1)$ per cell, requiring storage of 8 corner values and ray parameters.
*   **Performance:** Single-precision implementations are numerically stable [S2, S3][S5, unofficial].
*   **Strengths:** Does not require Hermite data (normals) [S4]; handles multiple intersections per cell (up to 3) [S4]; topologically correct via look-up tables for cell configurations [S4].
*   **Limitations:** Trilinear interpolation lacks gradient continuity, causing visual artifacts if normals are derived from it [S7]. Ambiguous faces require additional analysis (asymptotic decider) [S4].
*   **When to use:** When Hermite data is unavailable or expensive to compute, and exact trilinear intersection is required.
*   **When not to use:** When smooth shading is critical and tricubic normals are not available [S7].

## Background
The method originates from the need to extract isosurfaces from scalar fields defined on hexahedral grids without relying on vertex normals [S4]. It is based on the trilinear Lagrangian interpolant [S5, unofficial]. The formulation of the cubic equation from ray substitution is detailed in [S4][S5, unofficial]. The use of cell diagonals as rays and the classification of cells/edges based on vertex signs are described in [S4]. The iterative root finder (Neubauer) was proposed by Marmitt et al. [S2, S3][S5, unofficial] as an alternative to analytical solvers [S2, S3][S5, unofficial]. The topological analysis using look-up tables for 31 configurations is based on Lopes and Brodlie (2003) [S4].
