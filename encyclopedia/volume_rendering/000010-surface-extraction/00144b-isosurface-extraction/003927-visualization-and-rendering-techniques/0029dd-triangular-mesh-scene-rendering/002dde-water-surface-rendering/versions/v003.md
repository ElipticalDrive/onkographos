# Water Surface Rendering
Also called: Triangle fan water rendering
## Overview
A rendering technique for water surfaces using a triangle fan geometry with vertex positions in 3D space ($x, 0, y$), rendered with various shader uniforms for visual effects [S1, unofficial].
## How it works
**Inputs and Outputs:**
*   **Input:** A 2D grid of vertices representing the water surface.
*   **Output:** A rendered water surface with color, foam, ripple, and motion effects.

**Data Structures:**
*   **Vertex Buffer Object (VBO):** Contains 3D vertices derived from 2D input by setting the $y$-coordinate to $0$, resulting in positions $(x, 0, z)$ [S1, unofficial].
*   **Vertex Array Object (VAO):** Manages vertex attributes and binds the VBO to attribute location $0$ for position [G].

**Parameters:**
*   **Default Water Color:** $\text{vec4}(0.025, 0.125, 0.15, 1.0)$ [S1, unofficial].
*   **Default Visibility:** $3.6$ [S1, unofficial].
*   **Foam:** $0.5$ [S1, unofficial].
*   **Motion:** $0.5$ [S1, unofficial].
*   **Ripple:** $0.5$ [S1, unofficial].
*   **Wave:** $0.5$ [S1, unofficial].
*   **Rings:** $\text{vec4}(0, 0, 0, 0)$ [S1, unofficial].
*   **Ring Count:** $0$ [S1, unofficial].

**Steps:**
1.  **Initialization (Constructor):**
    *   Convert the 2D vertex array to 3D by setting the $y$-component to $0$ for all vertices [S1, unofficial].
    *   Create a VBO containing these 3D vertices [S1, unofficial].
    *   Link the vertex position attribute to attribute index $0$ [S1, unofficial].
2.  **Rendering (Draw):**
    *   Compute the Model-View-Projection (MVP) matrix: $MVP = \text{camera.vp\_matrix} \times \text{translate}(\text{position})$ [S1, unofficial].
    *   Push the following uniforms to the shader: $uFar$, $uInvFar$, $uNear$, $uMvpMatrix$, $uOldStableVpMatrix$, $uStableVpMatrix$, $uCameraPos$, $uPixelSize$, $uFoamTexture$ (texture unit $5$), $uRings$, $uWaterColor$, $uVisibility$, $uFoam$, $uMotion$, $uRipple$, $uWave$, $uRingCount$, $uRndFrame$ [S1, unofficial].
    *   Bind the VAO [S1, unofficial].
    *   Call `glDrawArrays` with primitive type `GL_TRIANGLE_FAN` [S1, unofficial].

**Pseudocode:**
```python
def multiply_matrices(a, b):
    return [[sum(a[i][k] * b[k][j] for k in range(4)) for j in range(4)] for i in range(4)]

def translate_matrix(pos):
    return [[1, 0, 0, pos[0]], [0, 1, 0, pos[1]], [0, 0, 1, pos[2]], [0, 0, 0, 1]]

def set_uniform(name, value):
    pass  # Shader uniform assignment

def bind_vao(vao):
    pass  # Bind vertex array object

def draw_arrays(primitive_type, count):
    pass  # Issue draw call

class WaterRender:
    def __init__(self, vertices_2d):
        # Convert 2D vertices to 3D by setting y=0
        self.vertices_3d = [(v.x, 0.0, v.z) for v in vertices_2d]
        # Create VBO containing these 3D vertices
        self.vbo = self.vertices_3d
        # Create VAO and link vertex position attribute at index 0
        self.vao = {"buffer": self.vbo, "attribs": {0: "position"}}

    def draw(self, camera, position):
        # Compute MVP matrix: camera.vp_matrix * translate(position)
        mvp_matrix = multiply_matrices(camera.vp_matrix, translate_matrix(position))

        # Push uniforms to shader
        set_uniform("uFar", camera.far)  # Not given in sources
        set_uniform("uInvFar", 1.0 / camera.far)  # Not given in sources
        set_uniform("uNear", camera.near)  # Not given in sources
        set_uniform("uMvpMatrix", mvp_matrix)
        set_uniform("uOldStableVpMatrix", camera.old_stable_vp_matrix)  # Not given in sources
        set_uniform("uStableVpMatrix", camera.stable_vp_matrix)  # Not given in sources
        set_uniform("uCameraPos", camera.position)
        set_uniform("uPixelSize", camera.pixel_size)  # Not given in sources
        set_uniform("uFoamTexture", 5)  # texture unit 5
        set_uniform("uRings", (0.0, 0.0, 0.0, 0.0))
        set_uniform("uWaterColor", (0.025, 0.125, 0.15, 1.0))
        set_uniform("uVisibility", 3.6)
        set_uniform("uFoam", 0.5)
        set_uniform("uMotion", 0.5)
        set_uniform("uRipple", 0.5)
        set_uniform("uWave", 0.5)
        set_uniform("uRingCount", 0)
        set_uniform("uRndFrame", camera.frame_number)  # Not given in sources

        # Bind VAO and call glDrawArrays with GL_TRIANGLE_FAN
        bind_vao(self.vao)
        draw_arrays(primitive_type="GL_TRIANGLE_FAN", count=len(self.vertices_3d))
```
## Subtopics

### [Planar Water Reflection and Refraction](10908-planar-water-reflection-and-refraction.md)
Renders a voxel water surface by generating separate reflection and refraction textures via Framebuffer Objects (FBOs), which are then blended on a water surface shader. It handles both planar ocean water and placed water blocks by separating them into distinct rendering buckets. Choose this for voxel environments where water surfaces are typically axis-aligned, as it uses fixed horizontal clip planes and a single sea-level reference for geometric culling.
