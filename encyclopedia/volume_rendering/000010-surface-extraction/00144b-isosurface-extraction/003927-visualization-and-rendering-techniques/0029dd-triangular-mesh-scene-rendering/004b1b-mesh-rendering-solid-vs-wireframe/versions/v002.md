# Mesh Rendering (Solid vs Wireframe)
Also called: Face rendering, Triangle mesh draw

## Overview
Mesh rendering draws a triangular mesh either as solid filled faces or as wireframe edges [S1, unofficial]. Solid mode renders each face as a thick triangle, while wireframe mode renders each face's edges as capsules [S1, unofficial].

## How it works
**Inputs:**
- `vertices`: Array of 3D points.
- `faces`: Array of triplets of vertex indices.
- `mesh_center`: 3D point defining the mesh origin.
- `scale_factor`: Scalar multiplier for mesh size.
- `bounds_center`: 3D point defining the target bounds origin.
- `mode`: Enum `SOLID` or `WIREFRAME` [S1, unofficial].

**Outputs:**
- Rendered primitives or image [S1, unofficial].

**Data Structures:**
- `CuboidGeometry`: Struct containing `v1` (start point), `v2` (end point or second vertex), and `isWireframe` (boolean) [S1, unofficial].

**Steps:**
1. Transform each vertex $v$ using $v' = (v - \text{mesh\_center}) \times \text{scale\_factor} + \text{bounds\_center}$ [S1, unofficial].
2. If `mode` is `WIREFRAME`: iterate all unique vertex pairs $(i, j)$ per face where $i \in \{0, 1\}$ and $j \in \{i, 1, 2\}$ [S1, unofficial]. Draw a capsule between the transformed vertices $i$ and $j$ [S1, unofficial].
3. If `mode` is `SOLID`: draw a filled triangle for each face using the three transformed vertices [S1, unofficial].

**Parameters:**
- `scale_factor`: Scalar controlling mesh size [S1, unofficial].
- `maxScale`: Maximum scale factor from transformation. Used for potential culling or LOD [S1, unofficial].

**Pseudocode:**
```python
def render_mesh(vertices, faces, mesh_center, scale_factor, bounds_center, mode):
    """
    Render a triangle mesh as solid or wireframe.
    
    Args:
        vertices: List of 3D vectors.
        faces: List of tuples (i, j, k) of vertex indices.
        mesh_center: 3D vector for mesh origin.
        scale_factor: Scalar multiplier.
        bounds_center: 3D vector for target bounds origin.
        mode: 'SOLID' or 'WIREFRAME'.
    """
    # Transform vertices: v' = (v - mesh_center) * scale_factor + bounds_center [S1, unofficial]
    transformed = [(v - mesh_center) * scale_factor + bounds_center for v in vertices]

    if mode == 'WIREFRAME':
        for face in faces:
            i, j, k = face
            # Iterate unique vertex pairs per face [S1, unofficial]
            for a, b in [(i, j), (i, k), (j, k)]:
                draw_capsule(transformed[a], transformed[b])
    elif mode == 'SOLID':
        for face in faces:
            i, j, k = face
            draw_triangle(transformed[i], transformed[j], transformed[k])
```

## Subtopics

### Wireframe Cube Rendering
Creates a mesh cube with a wireframe modifier and a solid color material [S2, unofficial]. Steps: Add a primitive cube using `bpy.ops.mesh.primitive_cube_add(size=1, enter_editmode=False, align="WORLD", location=position)` [S2, unofficial]. Set scale and rotation via `cube.scale = scale; cube.rotation_euler = rotation` [S2, unofficial]. Apply transforms with `bpy.ops.object.transform_apply(location=True, rotation=True, scale=True)` [S2, unofficial]. Add a wireframe modifier using `bpy.ops.object.modifier_add(type="WIREFRAME")` and set thickness to `wireframe_scale` [S2, unofficial]. Create a material with `bpy.data.materials.new(name="CubeMaterial"); material.use_nodes = False; material.diffuse_color = color` [S2, unofficial]. Assign the material to the mesh via `if len(cube.data.materials) > 0: cube.data.materials[0] = material else: cube.data.materials.append(material)` [S2, unofficial].

### Wireframe Contour Display
A visualization mode that displays only a subset of lines in a triangular mesh, specifically those representing the intersection of the XY, YZ, and XZ grid planes with the contour surface [S3].
