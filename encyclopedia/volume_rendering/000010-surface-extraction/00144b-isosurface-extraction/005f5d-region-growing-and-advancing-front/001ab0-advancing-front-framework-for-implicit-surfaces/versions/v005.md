# Advancing Front Framework for Implicit Surfaces

Also called: Continuation, Surface Tracking

## Overview
This method extracts a triangulated mesh from an implicit surface by growing a front from a seed point, creating new triangles attached to front edges [S1]. It differs from numerical simulation meshing by operating without a well-defined description of volume components, requiring chart creation for the reconstructed surface [S1].

## How it works
**Inputs:** An implicit function $f(\mathbf{x}) = 0$ defining the surface; a seed point $\mathbf{p}_0$ on the surface [S1].
**Outputs:** A manifold triangle mesh approximating the surface [S1].
**Assumptions:** The implicit surface is defined such that its gradient $\nabla f$ and Hessian $H_f$ are non-zero everywhere [S1].

**Data Structures:**
*   **Front:** A list of edges forming the boundary of the generated mesh [S1].
*   **Mesh:** A set of triangles already generated and accepted [S1].

**Algorithm Steps:**
1.  **Initialization:** Find a seed point $\mathbf{p}_0$ on the surface $f(\mathbf{x})=0$. Create an initial triangle or edge at $\mathbf{p}_0$ to start the front [G]. The initial front consists of the boundary edges of this starting geometry.
2.  **Edge Selection:** Choose an edge $e = (\mathbf{v}_i, \mathbf{v}_j)$ from the current front [S1].
3.  **Triangle Creation:** Compute a new vertex $\mathbf{v}_{new}$ to form a triangle $T = (\mathbf{v}_i, \mathbf{v}_j, \mathbf{v}_{new})$ attached to $e$ [S1]. The position of $\mathbf{v}_{new}$ is determined by local surface geometry (gradient/Hessian) and desired edge length [G].
4.  **Self-Intersection Check:** Test if triangle $T$ intersects any existing front edge or triangle [S1].
    *   If $T$ causes the front to intersect itself, split the front into two separate fronts at the intersection point [S1]. The new edge created by the split becomes part of the new front boundaries [G].
5.  **Cross-Front Intersection Check:** Test if $T$ intersects a different, non-adjacent front [S1].
    *   If $T$ intersects a different front, merge the two fronts [S1]. The shared boundary edges are removed from the front list, and the new edges formed by the merge are added [G].
6.  **Update:** Add $T$ to the mesh. Update the front list by removing edge $e$ and adding the new boundary edges created by $T$ [G].
7.  **Termination:** Repeat steps 2–6 until the front is empty or a coverage criterion is met [G].

**Pseudocode:**
```python
def advancing_front_meshing(f, p_seed):
    # Initialize front with initial triangle/edge at p_seed [G]
    front = [(p_seed, p_seed)]
    mesh = []

    while len(front) > 0:
        # Select an edge from the current front [S1]
        edge = front.pop(0)
        v_i, v_j = edge

        # Compute new vertex v_new to form triangle T attached to edge [G]
        # Position determined by local surface geometry (gradient/Hessian) and edge length constraints
        v_new = find_vertex_on_surface(f, v_i, v_j) # [G]

        T = (v_i, v_j, v_new)

        # Check if T causes the front to intersect itself [S1]
        if check_self_intersection(T, front):
            # Split front into two separate fronts [S1]
            front = split_front(front, T)
            continue

        # Check if T intersects a different front [S1]
        if check_cross_front_intersection(T, front):
            # Merge the two fronts [S1]
            front = merge_fronts(front, T)

        # Add T to mesh and update front [G]
        mesh.append(T)
        front.remove(edge)
        front.extend(get_new_boundary_edges(T))

    return mesh
```

## Subtopics

### [Advancing Front Isosurface Extraction with Guidance Field](947-advancing-front-isosurface-extraction-with-guidance-field.md)
Extracts isosurfaces using an advancing front guided by a scalar field $g(\mathbf{x})$ that constrains edge lengths based on surface curvature and user parameters. Solves front interference detection and poor triangle shaping inherent in standard adaptive algorithms by providing a theoretical foundation for edge size selection. Uses the guidance field to bound the Hausdorff distance and aspect ratio of triangles, ensuring robust front intersection tests.

### [Advancing Front Isosurface Meshing](20014-advancing-front-isosurface-meshing.md)
Generates a triangular mesh from fixed isosurface nodes by connecting them, adapted from the classical advancing front technique to avoid deleting pre-computed nodes. Constructs meshes of isosurface segments separately for each intersected cube, ensuring local consistency before merging. Particularly suited for applications requiring high-quality visualizations of computed isosurfaces, such as in boundary element method (BEM) post-processing, where the preservation of existing node data is critical.

## Operating characteristics
*   **Complexity:** Not given in the sources.
*   **Strengths:** Capable of generating high-quality meshes for general implicit surfaces without predefined volume descriptions [S1]. Handles complex topology through front splitting and merging [S1].
*   **Limitations:** Requires non-zero gradient and Hessian everywhere [S1]. Base framework relies on ad hoc steps for edge sizing [S1].
*   **When to use:** When extracting meshes from general implicit functions where topological changes (splitting/merging) are expected and high-quality element shapes are required [S1].

## Background
Advancing front algorithms, also known as surface tracking and continuation, have a substantial history in mesh generation for numerical simulation [S1]. In that context, algorithms start with well-defined domain representations and increase dimension (edges, triangles, tetrahedra) [S1]. The application to implicit surfaces, as described in [S1], addresses the challenge of operating without a well-defined description of volume components, requiring chart creation for the reconstructed surface. Previous works in this area include [8, 23, 24] for implicit surface triangulation and [7, 46] for general mesh generation [S1].
