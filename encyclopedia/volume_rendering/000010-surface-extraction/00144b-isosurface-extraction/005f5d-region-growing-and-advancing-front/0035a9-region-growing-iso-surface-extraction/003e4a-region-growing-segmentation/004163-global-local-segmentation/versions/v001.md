# Global/Local Segmentation

Also called: Global Segmentation via Mask, Mask-constrained Segmentation

## Overview
Global/Local Segmentation is a region-growing technique that mitigates errors from local decision-making by confining automatic segmentation to a user-specified mask [S1]. It sets itself apart from siblings like [Restricted Region Growing](9750-restricted-region-growing.md) by explicitly decoupling the spatial search domain (defined globally by the user) from the boundary optimization logic (which may use global criteria like dynamic programming) [S1].

## How it works
**Inputs and Outputs:**
- Input: A 3D volume $V$.
- Input: A binary mask volume $M$ of the same dimensions as $V$, where $M(x,y,z)=1$ indicates voxels allowed for segmentation and $0$ otherwise [S1].
- Output: A segmented surface or volume $D_p$ [S1].

**Data Structures:**
- The mask $M$ is typically sparse or thin; a "shell" around the boundary of interest is sufficient to minimize user interaction time [S1].
- The output volume $D_p$ stores boundary likelihood values for voxels in the mask $V_1$ and $0$ for voxels outside $V_1$ [S1].

**Steps:**
1. **User Interaction:** The user interactively indicates a subset of $V$ to serve as the mask $M$ [S1].
2. **Confinement:** Automatic segmentation algorithms are restricted to operate only within the voxels where $M=1$ [S1].
3. **Boundary Optimization (Optional):** Within the mask, globally optimal boundaries are found using 2D dynamic programming [S1].

**Formulas:**
Let $V_1$ be the set of voxels in the mask shell. Let $B_i$ be the operator finding the optimal boundary within $V_1$. The resulting scene $D_p$ is defined as:
$$
D_p(x,y,z) = 
\begin{cases} 
\text{boundary likelihood value} & \text{if } (x,y,z) \in V_1 \\
0 & \text{if } (x,y,z) \notin V_1 
\end{cases}
$$
[S1]

**Parameters:**
- Mask size: A shell around the boundary is often all that is needed [S1].

**Pitfalls:**
- If the mask is too large, user interaction time increases. If too small, the dynamic programming search may be constrained incorrectly [S1].

## Subtopics

### Global Threshold Segmentation
A segmentation technique that applies a single intensity threshold uniformly across all voxels or slices of a dataset to isolate a target structure [S2].
- **Definition:** Uses a single threshold value for the entire specimen, adjusted iteratively by visual inspection using a Region of Interest tool [S2].
- **Parameters:** For in vivo hyoid bones, the threshold range is 105–170 HU, with a mean of 131.10 HU [S2]. This is narrower and lower than region-specific thresholding (85–354 HU, mean 173.87 HU) [S2].
- **Pitfalls:** Applying a threshold derived from an adjacent anatomical structure (e.g., mandible) causes significant portions of the target structure, especially thin extensions like cornua, to be excluded from the 3D model [S2].
- **Comparison:** Global thresholding uses lower mean, median, and mode values compared to region-specific methods [S2].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Considerable success reported in automatically finding globally optimal boundaries using 2D dynamic programming when the search is confined to a mask [S1]. User interaction time can be kept to a minimum [S1].
- **Limitations:** Relies on user-provided masks; automatic mask generation is noted as a useful but separate problem to pursue [S1].
- **When to use:** When local decision-making leads to errors and a rough spatial prior (mask) is available [S1].

## Background
Originated in the context of imaging transforms for visualizing surfaces and volumes [S1]. The approach addresses the difficulty of designing global criteria to ward off errors caused by local decision-making in scene segmentation [S1]. It is applied in various visualization applications where automatic boundary finding is required within a constrained region [S1].
