# RGVis Region Growing

Also called: RGVis, Region Growing Based Visualization

## Overview
RGVis is an interactive volume visualization technique that uses region growing to assist in the classification and assessment of features of interest [S1, unofficial]. It solves the problem of iterative trial-and-error in defining transfer functions and boundary surfaces by deriving a 2D transfer function from the statistical properties of a partially segmented region or constructing a complete boundary surface from a full segmentation [S1, unofficial]. Unlike dual-domain interactive methods that highlight histogram points for manual editing, RGVis suggests a transfer function derived from region growing statistics, and its resulting boundary surfaces represent features more completely than isosurfaces by capturing fine parts that isosurfaces might miss [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D volume data (scalar values), user interaction (seed point or line segment selection on a slice), and user-specified constant $k$ [S1, unofficial].
*   **Output:** A set of connected voxels (region), a derived 2D transfer function (for partial growing), or a polygonal boundary surface (for full growing) [S1, unofficial].

**Data Structures:**
*   **Volume Data:** 3D array of scalar values $v$ and precomputed or on-the-fly gradient magnitudes $g$ [G].
*   **Region Set:** A collection of voxel coordinates $(x, y, z)$ belonging to the current region [G].
*   **Queue/Stack:** Used for the recursive or iterative expansion of the region (26-connectivity) [G].
*   **Statistics:** Running mean and standard deviation of data values ($\sigma_v$) and gradient magnitudes ($\sigma_g$) for the voxels collected so far [S1, unofficial].

**Parameters:**
*   $k$: A constant specified by the user, used in the cost function $f_{ca}$ [S1, unofficial].
*   $v_s$: Data value of the seed voxel [S1, unofficial].
*   $\sigma_v$: Standard deviation of the data values of the neighbors (or collected voxels) [S1, unofficial].
*   $\sigma_g$: Standard deviation of gradient magnitudes [S1, unofficial].
*   $p$: A parameter continuously recomputed using voxels collected so far for the adaptive criterion [S1, unofficial].

**Steps:**
1.  **Seed Selection:** The user slices through the volume data and selects a region of interest by plotting a line segment over it [S1, unofficial]. *Point Seed:* The user clicks a point on the slice [S1, unofficial]. The system highlights the point and its 26 neighbors on a 2D scatterplot (scalar vs. gradient magnitude) [S1, unofficial]. A blue rectangle shows the standard deviation of data values ($\sigma_v$) and gradient magnitudes ($\sigma_g$) of the neighbors [S1, unofficial]. *Line Seed:* The user plots a line segment of 3D points [S1, unofficial]. The interface displays properties of these points divided into preclassified zones [S1, unofficial]. The user selects a zone to determine the seed [S1, unofficial]. *Initialization:* The growing starts from a voxel in the proximity of the seed point, chosen based on distance or statistical properties of the neighborhood [S1, unofficial].
2.  **Region Growing Expansion:** Initialize the region with the starting voxel [S1, unofficial]. For each voxel in the region, visit its 26 immediate neighbors [S1, unofficial]. For each neighbor, evaluate the cost functions [S1, unofficial]. If the neighbor satisfies the criteria, add it to the region and the queue/stack for further expansion [S1, unofficial]. Update statistics ($\sigma_v, \sigma_g, p$) using the voxels collected so far if using the adaptive criterion [S1, unofficial].
3.  **Termination:** The process continues until the queue is empty (all reachable voxels examined) or a specific termination criterion is met [S1, unofficial].
4.  **Post-Processing (Optional):** *Partial Growing:* Use the statistical properties of the extracted region to derive a 2D transfer function [S1, unofficial]. *Full Growing:* Construct a boundary surface from the collected data points [S1, unofficial].

**Formulas:**
A voxel is included in the region if the value returned by the cost function is less than 1 [S1, unofficial]. Three functions are defined [S1, unofficial]:

1.  **Cost Function $f_{ca}$:**
    $$ f_{ca} = \frac{|v - v_s|}{k \sigma_v} $$
    Where:
    *   $v$: Data value of the current voxel.
    *   $v_s$: Data value of the seed voxel.
    *   $k$: User-specified constant.
    *   $\sigma_v$: Standard deviation of the data values of the neighbors (or collected voxels for the adaptive variant) [S1, unofficial].

2.  **Cost Function $f_{cb}$:** Defined in the source but the explicit formula is not provided in the text [S1, unofficial]. It is used alongside $f_{ca}$ and $f_{cc}$ [S1, unofficial].

3.  **Adaptive Criterion $f_{cc}$:** The criterion is made adaptive by adjusting it during the course of growing [S1, unofficial]. $\sigma_v$, $\sigma_g$, and $p$ are continuously recomputed using the voxels collected so far [S1, unofficial]. The explicit formula for $f_{cc}$ is not provided in the text, but it relies on these dynamic statistics [S1, unofficial].

**Pseudocode:**
```python
def compute_gradient_magnitude(vol, idx):
    # Standard central difference gradient magnitude [G]
    x, y, z = idx
    gx = (vol[x+1, y, z] - vol[x-1, y, z]) / 2.0 if 0 < x < vol.shape[0]-1 else 0.0
    gy = (vol[x, y+1, z] - vol[x, y-1, z]) / 2.0 if 0 < y < vol.shape[1]-1 else 0.0
    gz = (vol[x, y, z+1] - vol[x, y, z-1]) / 2.0 if 0 < z < vol.shape[2]-1 else 0.0
    return (gx**2 + gy**2 + gz**2)**0.5

def rgvis_region_growing(volume, seed_voxel, k, max_voxels=None):
    """
    Performs region growing on volume data starting from a voxel near seed_voxel.
    """
    # Select starting voxel near seed based on distance or neighborhood statistics [S1, unofficial]
    start_voxel = seed_voxel
    region = {start_voxel}
    queue = [start_voxel]
    region_values = [volume[start_voxel]]
    region_grads = [compute_gradient_magnitude(volume, start_voxel)]

    # 26-connectivity offsets
    offsets = [(dx, dy, dz) for dx in (-1, 0, 1) for dy in (-1, 0, 1) for dz in (-1, 0, 1) if not (dx == 0 and dy == 0 and dz == 0)]

    while queue:
        current_voxel = queue.pop(0)
        if max_voxels and len(region) >= max_voxels:
            break

        # Recompute statistics continuously using voxels collected so far for adaptive criterion [S1, unofficial]
        n = len(region_values)
        mean_v = sum(region_values) / n
        var_v = sum((x - mean_v) ** 2 for x in region_values) / n
        sigma_v = var_v ** 0.5
        mean_g = sum(region_grads) / n
        var_g = sum((x - mean_g) ** 2 for x in region_grads) / n
        sigma_g = var_g ** 0.5
        # p is continuously recomputed but formula not given [S1, unofficial]

        # Guard against division by zero in f_ca [G]
        if sigma_v == 0:
            sigma_v = 1e-9

        v_s = volume[seed_voxel]

        for dx, dy, dz in offsets:
            nx, ny, nz = current_voxel[0] + dx, current_voxel[1] + dy, current_voxel[2] + dz
            if not (0 <= nx < volume.shape[0] and 0 <= ny < volume.shape[1] and 0 <= nz < volume.shape[2]):
                continue
            neighbor_voxel = (nx, ny, nz)
            if neighbor_voxel in region:
                continue

            v_n = volume[neighbor_voxel]
            g_n = compute_gradient_magnitude(volume, neighbor_voxel)

            # Evaluate cost functions [S1, unofficial]
            f_ca = abs(v_n - v_s) / (k * sigma_v)
            # f_cb and f_cc formulas are not provided in the source [S1, unofficial]
            # The source states a voxel is included if the cost function value is < 1.
            if f_ca < 1.0:
                region.add(neighbor_voxel)
                queue.append(neighbor_voxel)
                region_values.append(v_n)
                region_grads.append(g_n)

    return region
```

**Edge Cases and Pitfalls:**
*   **Division by Zero:** If $\sigma_v$ is zero (e.g., all voxels in the region have the same value), the cost function $f_{ca}$ will divide by zero. A small epsilon or alternative handling is required [G].
*   **Noise:** Noise can cause the region to grow into irrelevant areas if the criteria are not tight enough. The adaptive criterion helps prevent this by adjusting based on collected voxels [S1, unofficial].
*   **Disconnected Features:** Full region growing may miss disconnected features of the same type [S1, unofficial]. Partial region growing is used to derive a transfer function that can capture these disconnected features throughout the volume [S1, unofficial].

## Subtopics

### [Partial Region Growing for Transfer Function Generation](14373-partial-region-growing-for-transfer-function-generation.md)
A semi-automatic technique that derives a 2D transfer function from the statistical properties of a partially segmented region to visualize similar, disconnected features throughout the entire volume. Unlike full region growing which segments all connected components, this method performs growth on only a subset of the data or a small subset of regions, significantly reducing computation time while providing a robust classifier for the whole dataset. It is particularly useful when features of the same type are disconnected in the volume, preventing a single region growing pass from capturing all instances.

## Operating characteristics
*   **Time Complexity:** Not explicitly given, but partial region growing on a confocal microscopy ganglion data set (64×300×400 voxels) took 0.03 seconds and extracted 5,000 voxels [S1, unofficial].
*   **Memory Complexity:** Depends on the size of the region extracted [G]. The region set stores coordinates of all voxels in the region [G].
*   **Performance:** The partial region growing approach is efficient, allowing for quick derivation of transfer functions [S1, unofficial].
*   **Strengths:** Assists users in locating and defining features of interest more quickly and accurately [S1, unofficial]. Derives transfer functions automatically, reducing manual editing iterations [S1, unofficial]. Boundary surfaces generated by full region growing represent features more completely than isosurfaces, including fine parts [S1, unofficial].
*   **Limitations:** Requires user interaction for seed selection [S1, unofficial]. Full region growing may be computationally expensive for large volumes if the region is large [G]. The explicit formulas for $f_{cb}$ and $f_{cc}$ are not provided in the source, limiting reproducibility of the exact cost function logic [S1, unofficial].
*   **When to Use:** When exploring volume data to locate features of interest and define transfer functions or boundary surfaces, especially in medical applications and confocal microscopy [S1, unofficial].
*   **When Not to Use:** Not given in the sources.

## Background
RGVis (Region Growing Based Visualization) was developed at UC Davis [S1, unofficial]. It is based on the paper "RGVis: Region Growing Based Visualization Techniques for Volume Visualization" [S1, unofficial]. The technique is similar to the volume seedling method introduced by Cohen et al. [S1, unofficial]. It has been applied to confocal microscopy ganglion data sets and medical applications [S1, unofficial].
