# RGVis Region Growing

Also called: RGVis, Region Growing Based Visualization

## Overview
RGVis is an interactive volume visualization technique that uses region growing to assist in the classification and assessment of features of interest [S1, unofficial]. It solves the problem of iterative trial-and-error in defining transfer functions and boundary surfaces by deriving a 2D transfer function from the statistical properties of a partially segmented region or constructing a complete boundary surface from a full segmentation [S1, unofficial]. Unlike dual-domain interactive methods that highlight histogram points for manual editing, RGVis suggests a transfer function derived from region growing statistics, and its resulting boundary surfaces represent features more completely than isosurfaces by capturing fine parts that isosurfaces might miss [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D volume data (scalar values), user interaction (seed point or line segment selection on a slice), and user-specified constant $k$.
*   **Output:** A set of connected voxels (region), a derived 2D transfer function (for partial growing), or a polygonal boundary surface (for full growing).

**Data Structures:**
*   **Volume Data:** 3D array of scalar values $v$ and precomputed or on-the-fly gradient magnitudes $g$.
*   **Region Set:** A collection of voxel coordinates $(x, y, z)$ belonging to the current region.
*   **Queue/Stack:** Used for the recursive or iterative expansion of the region (26-connectivity).
*   **Statistics:** Running mean and standard deviation of data values ($\sigma_v$) and gradient magnitudes ($\sigma_g$) for the voxels collected so far.

**Parameters:**
*   $k$: A constant specified by the user, used in the cost function $f_{ca}$ [S1, unofficial].
*   $v_s$: Data value of the seed voxel [S1, unofficial].
*   $\sigma_v$: Standard deviation of data values of the neighbors (or collected voxels) [S1, unofficial].
*   $\sigma_g$: Standard deviation of gradient magnitudes [S1, unofficial].
*   $p$: A parameter continuously recomputed using voxels collected so far for the adaptive criterion [S1, unofficial].

**Steps:**

1.  **Seed Selection:**
    *   The user slices through the volume data and selects a region of interest.
    *   *Point Seed:* The user clicks a point on the slice. The system highlights the point and its 26 neighbors on a 2D scatterplot (scalar vs. gradient magnitude). A blue rectangle shows the standard deviation of data values ($\sigma_v$) and gradient magnitudes ($\sigma_g$) of the neighbors [S1, unofficial].
    *   *Line Seed:* The user plots a line segment of 3D points. The interface displays properties of these points divided into preclassified zones. The user selects a zone to determine the seed [S1, unofficial].
    *   *Initialization:* The growing starts from a voxel in the proximity of the seed point, chosen based on distance or statistical properties of the neighborhood [S1, unofficial].

2.  **Region Growing Expansion:**
    *   Initialize the region with the starting voxel.
    *   For each voxel in the region, visit its 26 immediate neighbors.
    *   For each neighbor, evaluate the cost functions.
    *   If the neighbor satisfies the criteria, add it to the region and the queue/stack for further expansion.
    *   Update statistics ($\sigma_v, \sigma_g, p$) using the voxels collected so far if using the adaptive criterion [S1, unofficial].

3.  **Termination:**
    *   The process continues until the queue is empty (all reachable voxels examined) or a specific termination criterion is met [S1, unofficial].

4.  **Post-Processing (Optional):**
    *   *Partial Growing:* Use the statistical properties of the extracted region to derive a 2D transfer function [S1, unofficial].
    *   *Full Growing:* Construct a boundary surface from the collected data points [S1, unofficial].

**Formulas:**
A voxel is included in the region if the value returned by the cost function is less than 1. Three functions are defined [S1, unofficial]:

1.  **Cost Function $f_{ca}$:**
    $$ f_{ca} = \frac{|v - v_s|}{k \sigma_v} $$
    Where:
    *   $v$: Data value of the current voxel.
    *   $v_s$: Data value of the seed voxel.
    *   $k$: User-specified constant.
    *   $\sigma_v$: Standard deviation of the data values of the neighbors (or collected voxels) [S1, unofficial].

2.  **Cost Function $f_{cb}$:**
    *   Defined in the source but the explicit formula is not provided in the text. It is used alongside $f_{ca}$ and $f_{cc}$ [S1, unofficial].

3.  **Adaptive Criterion $f_{cc}$:**
    *   The criterion is made adaptive by adjusting it during the course of growing.
    *   $\sigma_v$, $\sigma_g$, and $p$ are continuously recomputed using the voxels collected so far [S1, unofficial].
    *   The explicit formula for $f_{cc}$ is not provided in the text, but it relies on these dynamic statistics [S1, unofficial].

**Pseudocode:**

```python
def rgvis_region_growing(volume, seed_voxel, k, max_voxels=None):
    """
    Performs region growing on volume data starting from seed_voxel.
    
    Args:
        volume: 3D array of scalar values.
        seed_voxel: Tuple (x, y, z) of the starting voxel.
        k: User-specified constant for cost function f_ca.
        max_voxels: Optional limit on the number of voxels to grow.
        
    Returns:
        region: Set of voxel coordinates belonging to the region.
    """
    # Initialize region and queue
    region = set()
    queue = [seed_voxel]
    region.add(seed_voxel)
    
    # Get seed value
    v_s = volume[seed_voxel]
    
    # Statistics for adaptive criterion
    # Note: Exact formula for f_cc and f_cb not provided in sources.
    # We assume f_ca is the primary homogeneity check based on the text.
    # The text mentions f_ca, f_cb, and f_cc. 
    # We implement f_ca as described.
    
    # Precompute neighbors offsets for 26-connectivity
    neighbors_offsets = []
    for dx in [-1, 0, 1]:
        for dy in [-1, 0, 1]:
            for dz in [-1, 0, 1]:
                if dx == 0 and dy == 0 and dz == 0:
                    continue
                neighbors_offsets.append((dx, dy, dz))
    
    # To compute sigma_v dynamically, we need to track values in the region
    region_values = [v_s]
    
    while queue:
        current_voxel = queue.pop(0)
        
        # Check max voxels if specified
        if max_voxels and len(region) >= max_voxels:
            break
            
        # Recompute statistics for adaptive criterion
        # sigma_v is standard deviation of region_values
        if len(region_values) > 1:
            mean_v = sum(region_values) / len(region_values)
            variance_v = sum((x - mean_v) ** 2 for x in region_values) / len(region_values)
            sigma_v = variance_v ** 0.5
        else:
            sigma_v = 1.0 # Avoid division by zero if only seed is present
            
        # If sigma_v is 0, use a small epsilon to prevent division by zero
        if sigma_v == 0:
            sigma_v = 1e-9
            
        # Visit 26 neighbors
        for dx, dy, dz in neighbors_offsets:
            nx, ny, nz = current_voxel[0] + dx, current_voxel[1] + dy, current_voxel[2] + dz
            
            # Boundary check
            if not is_inside_volume(nx, ny, nz, volume.shape):
                continue
                
            neighbor_voxel = (nx, ny, nz)
            
            # Skip if already in region
            if neighbor_voxel in region:
                continue
                
            # Get neighbor value
            v_n = volume[neighbor_voxel]
            
            # Evaluate cost function f_ca
            # f_ca = |v - v_s| / (k * sigma_v)
            f_ca = abs(v_n - v_s) / (k * sigma_v)
            
            # Note: f_cb and f_cc formulas are not provided in the source text.
            # The text states: "If the value returned by the cost function is less than 1, 
            # then the voxel under consideration is within the region."
            # It mentions three functions: f_ca, f_cb, f_cc.
            # Without explicit formulas for f_cb and f_cc, we assume f_ca is the 
            # primary criterion described in detail. 
            # In a real implementation, one would need the specific definitions of f_cb and f_cc.
            # For this pseudocode, we assume a simplified check using f_ca < 1.
            # If f_cb or f_cc were required, they would be evaluated here.
            
            if f_ca < 1.0:
                # Add to region
                region.add(neighbor_voxel)
                queue.append(neighbor_voxel)
                region_values.append(v_n)
                
    return region

def is_inside_volume(x, y, z, shape):
    return 0 <= x < shape[0] and 0 <= y < shape[1] and 0 <= z < shape[2]
```

**Edge Cases and Pitfalls:**
*   **Division by Zero:** If $\sigma_v$ is zero (e.g., all voxels in the region have the same value), the cost function $f_{ca}$ will divide by zero. A small epsilon or alternative handling is required [G].
*   **Noise:** Noise can cause the region to grow into irrelevant areas if the criteria are not tight enough. The adaptive criterion helps prevent this by adjusting based on collected voxels [S1, unofficial].
*   **Disconnected Features:** Full region growing may miss disconnected features of the same type. Partial region growing is used to derive a transfer function that can capture these disconnected features throughout the volume [S1, unofficial].

## Subtopics

### [Partial Region Growing for Transfer Function Generation](14373-partial-region-growing-for-transfer-function-generation.md)
A semi-automatic technique that derives a 2D transfer function from the statistical properties of a partially segmented region to visualize similar, disconnected features throughout the entire volume. Unlike full region growing which segments all connected components, this method performs growth on only a subset of the data or a small subset of regions, significantly reducing computation time while providing a robust classifier for the whole dataset. It is particularly useful when features of the same type are disconnected in the volume, preventing a single region growing pass from capturing all instances.

## Operating characteristics
*   **Time Complexity:** Not explicitly given, but partial region growing on a confocal microscopy ganglion data set (64×300×400 voxels) took 0.03 seconds and extracted 5,000 voxels [S1, unofficial].
*   **Memory Complexity:** Depends on the size of the region extracted. The region set stores coordinates of all voxels in the region.
*   **Performance:** The partial region growing approach is efficient, allowing for quick derivation of transfer functions [S1, unofficial].
*   **Strengths:**
    *   Assists users in locating and defining features of interest more quickly and accurately [S1, unofficial].
    *   Derives transfer functions automatically, reducing manual editing iterations [S1, unofficial].
    *   Boundary surfaces generated by full region growing represent features more completely than isosurfaces, including fine parts [S1, unofficial].
*   **Limitations:**
    *   Requires user interaction for seed selection [S1, unofficial].
    *   Full region growing may be computationally expensive for large volumes if the region is large [G].
    *   The explicit formulas for $f_{cb}$ and $f_{cc}$ are not provided in the source, limiting reproducibility of the exact cost function logic [S1, unofficial].
*   **When to Use:** When exploring volume data to locate features of interest and define transfer functions or boundary surfaces, especially in medical applications and confocal microscopy [S1, unofficial].
*   **When Not to Use:** When fully automatic segmentation without user interaction is required, or when the features are not clustered or scattered in a way that region growing can effectively capture [S1, unofficial].

## Background
RGVis (Region Growing Based Visualization) was developed at UC Davis [S1, unofficial]. It is based on the paper "RGVis: Region Growing Based Visualization Techniques for Volume Visualization" [S1, unofficial]. The technique is similar to the volume seedling method introduced by Cohen et al. [S1, unofficial]. It has been applied to confocal microscopy ganglion data sets and medical applications [S1, unofficial].
