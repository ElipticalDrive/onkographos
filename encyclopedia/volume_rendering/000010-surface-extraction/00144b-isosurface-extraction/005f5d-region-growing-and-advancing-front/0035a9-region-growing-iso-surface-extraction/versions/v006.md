# Region-growing Iso-surface Extraction

Also called: Normal consistency constrained marching triangles, Novel region-growing algorithm, Region-growing based iso-surface extraction algorithm

## Overview
Region-growing Iso-surface Extraction is a surface extraction method that generates high-quality, curvature-adaptive semi-regular meshes while preserving sharp features and extracting all disjoint components of an iso-surface [S1]. It improves upon the original Marching Triangles algorithm by introducing a novel normal consistency constraint, which ensures robustness for complex topologies by guaranteeing that the intersection of the Delaunay sphere of a new triangle and the iso-surface is a topological disk [S1]. Unlike the original Marching Triangles algorithm, which does not adapt well to local surface properties, this method uses prioritized seed initialization and normal consistency checks to handle large-scale volumetric datasets [S1].

## How it works
The algorithm operates on a volumetric dataset to extract an iso-surface defined by a threshold value [S1]. It produces a triangular mesh where triangle sizes adapt to local surface curvature [S1].

**Inputs:**
*   Volumetric dataset $V$ (scalar field) [S1].
*   Iso-surface threshold value $T$ [S1].

**Outputs:**
*   Triangular mesh $M$ representing the iso-surface [S1].

**Data Structures:**
*   **Boundary Particles:** A set of points on the iso-surface [G]. Each particle $p$ stores its 3D position $\mathbf{p}$, its surface normal $\mathbf{n}$, and a status flag (e.g., unvisited, visited, boundary) [G].
*   **Growth Queue:** A priority queue storing candidate triangles or edges for expansion [G]. Prioritization is based on local curvature and feature strength [S1].
*   **Visited Set:** A hash map or grid-based structure tracking processed boundary particles to prevent re-processing [G].

**Algorithm Steps:**

1.  **Boundary Particle Sampling and Classification:** Sample points on the iso-surface from the volume [S1]. Classify them based on local geometric properties to identify potential seed locations and feature points [S1].
2.  **Feature Position Extraction:** Identify sharp features and high-curvature regions [S1]. These positions are marked as high-priority seeds to ensure sharp features are preserved in the final mesh [S1].
3.  **Prioritized Seed Initialization:** Initialize the growth front by selecting seed triangles from the high-priority feature positions and other classified boundary particles [S1]. Seeds are added to the growth queue with priorities determined by their geometric significance [S1].
4.  **Front Propagation:** Loop until the queue is empty or all disjoint components are extracted [S1]:
    a.  Dequeue the highest-priority candidate triangle $t_{new}$.
    b.  **Normal Consistency Check:** Verify that the normal vector of $t_{new}$ is consistent with the normals of its neighboring existing triangles on the front [S1]. Specifically, ensure that the intersection of the Delaunay sphere of $t_{new}$ and the iso-surface is a topological disk [S1]. This constraint is more robust than the original Marching Triangles' Delaunay face property check alone [S1].
    c.  If the check passes, add $t_{new}$ to the mesh $M$.
    d.  Generate new candidate triangles from the boundary edges of $t_{new}$.
    e.  Classify and prioritize these new candidates based on local curvature and feature strength.
    f.  Add valid candidates to the growth queue.
5.  **Visited Boundary Particle Identification:** Mark particles associated with added triangles as visited [S1]. Ensure that particles belonging to disjoint components are identified and initialized as new seeds if they were not reached by the current front [S1].

**Pseudocode:**

```python
def region_growing_iso_surface_extraction(volume, threshold):
    # Step 1: Boundary particle sampling and classification
    # [G] Standard grid traversal to find iso-surface intersections and compute normals
    boundary_particles = []
    for cell in volume.cells:
        if cell.intersects_iso_surface(threshold):
            p = cell.compute_intersection(threshold)
            n = cell.compute_normal(p)
            boundary_particles.append({'pos': p, 'normal': n, 'status': 'unvisited', 'id': len(boundary_particles)})

    # Step 2: Feature position extraction
    # [S1] Identify sharp features and high-curvature regions
    feature_positions = [p for p in boundary_particles if is_sharp_feature(p, volume)]

    # Step 3: Prioritized seed initialization
    growth_queue = []
    visited = set()
    mesh = []

    for pos in feature_positions:
        t = create_seed_triangle(pos, boundary_particles)
        growth_queue.append({'tri': t, 'priority': 0}) # 0 = HIGH
        visited.add(pos['id'])

    for p in boundary_particles:
        if p['id'] not in visited and is_seed_candidate(p):
            t = create_seed_triangle(p, boundary_particles)
            growth_queue.append({'tri': t, 'priority': 1}) # 1 = LOW
            visited.add(p['id'])

    # Step 4 & 5: Front propagation and visited identification
    # [S1] Loop from Steps 3 to 5 until all iso-surfaces are extracted
    while growth_queue:
        growth_queue.sort(key=lambda x: x['priority'])
        candidate = growth_queue.pop(0)['tri']

        # Normal consistency constraint check
        # [S1] Ensure intersection of Delaunay sphere and iso-surface is a topological disk
        if is_normal_consistent(candidate, mesh) and is_topological_disk(candidate.delaunay_sphere, volume, threshold):
            mesh.append(candidate)

            # Generate new candidates from boundary edges
            new_edges = get_boundary_edges(candidate)
            for edge in new_edges:
                if edge['id'] not in visited:
                    priority = calculate_priority(edge, volume)
                    growth_queue.append({'tri': edge, 'priority': priority})
                    visited.add(edge['id'])

    # [S1] Explicitly check for unvisited particles to extract all disjoint components
    for p in boundary_particles:
        if p['status'] == 'unvisited':
            t = create_seed_triangle(p, boundary_particles)
            growth_queue.append({'tri': t, 'priority': 0})
            visited.add(p['id'])

    return mesh
```

**Edge Cases and Pitfalls:**
*   **Disjoint Components:** The algorithm must explicitly check for unvisited boundary particles after the main loop to ensure all disjoint components are extracted [S1].
*   **Topological Ambiguity:** The normal consistency constraint is critical for handling complex topologies where standard Delaunay checks might fail [S1].

## Subtopics

### [3D reconstruction based on edge growth](8730-3d-reconstruction-based-on-edge-growth.md)
A variant that reconstructs surfaces by propagating from seed triangles through a queue of "growth edges". It solves topological ambiguity and hole-generation by explicitly tracking connectivity across cube boundaries, using specific topological configurations for triangle and quadrangle edges.

### [Region Growing Segmentation](9712-region-growing-segmentation.md)
A semi-automatic technique that extracts connected regions of interest from a 3D volume by iteratively adding neighboring voxels to a user-selected seed point based on statistical similarity criteria. It distinguishes itself by relying on local homogeneity rather than global cut optimization.

## Background
The algorithm was proposed by Jian Xi and Ye Duan in 2008 [S1]. It builds on the concept of the marching triangles algorithm, which generates higher quality evenly-sized and quasi-equilateral meshes by iteratively joining new triangles to the current region boundary [S1]. The original marching triangles algorithm did not adapt well to local surface properties, requiring many small triangles for surfaces with large curvature variations [S1]. This new algorithm improves upon it by using a prioritized seed initialization scheme and normal consistency constraints [S1].
