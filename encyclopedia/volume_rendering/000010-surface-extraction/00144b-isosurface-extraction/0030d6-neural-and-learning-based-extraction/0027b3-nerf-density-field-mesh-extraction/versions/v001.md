# NeRF Density Field Mesh Extraction

Also called: Density Field Meshing

## Overview
Extracts a triangle mesh from a trained Neural Radiance Field (NeRF) by evaluating the learned volume density ($\sigma$) on a structured 3D grid and applying the Marching Cubes algorithm [S1, unofficial]. It differs from sibling methods like MISE, which adaptively query points to minimize mesh complexity, and FlexiCubes, which uses differentiable cube-based optimization; this method relies on a uniform grid and a fixed threshold, prioritizing implementation simplicity and speed over geometric precision or texture fidelity [S1, unofficial].

## How it works
**Inputs:**
- A trained NeRF model (typically a coarse MLP) capable of querying volume density $\sigma$ at 3D positions.
- `scene_scale`: Half-extent of the bounding box containing the scene.
- `resolution`: Integer side length of the query grid.
- `sigma_threshold`: Density value defining the isosurface.
- `chunk`: Batch size for neural network queries.

**Outputs:**
- `verts`: Array of vertex positions in world coordinates.
- `faces`: Array of triangle indices.
- `normals`: Array of vertex normals.

**Data Structures:**
- `pts`: Tensor of shape $[N, 3]$ where $N = \text{resolution}^3$, containing 3D query points.
- `sigma_grid`: Tensor of shape $[\text{resolution}, \text{resolution}, \text{resolution}]$ containing density values.

**Steps:**
1.  **Grid Generation**: Create a 1D linear space of coordinates from $-\text{scene\_scale}$ to $\text{scene\_scale}$ with `resolution` points. Generate a 3D meshgrid from these coordinates. Stack the axes into a point cloud tensor. Note: The Y and Z axes are swapped during stacking to align with the NeRF coordinate convention (where Y is up and Z is forward/backward depending on the specific implementation, but the source explicitly swaps them) [S1, unofficial].
2.  **Density Query**: Evaluate the NeRF model at the grid points. To manage memory, query the model in chunks of size `chunk`. The model returns the density $\sigma$ for each point.
3.  **Reshaping**: Reshape the flattened density array into a 3D grid of shape $[\text{resolution}, \text{resolution}, \text{resolution}]$.
4.  **Marching Cubes**: Apply the Marching Cubes algorithm to the `sigma_grid` using `sigma_threshold` as the isovalue. This extracts the zero-level set (isosurface) of the density field.
5.  **Coordinate Rescaling**: The Marching Cubes algorithm typically returns vertices in grid index space $[0, \text{resolution}-1]$. Rescale these vertices to world coordinates using the formula:
    $$
    \mathbf{v}_{world} = \frac{\mathbf{v}_{grid}}{\text{resolution} - 1} \times (2 \times \text{scene\_scale}) - \text{scene\_scale}
    $$

**Pseudocode:**
```python
import torch
import numpy as np
from skimage import measure

def extract_mesh(coarse_model, scene_scale, resolution, sigma_threshold, chunk, device):
    # 1. Create 1D coordinate array
    lin = torch.linspace(-scene_scale, scene_scale, resolution, device=device)
    
    # 2. Create 3D grid
    xx, yy, zz = torch.meshgrid(lin, lin, lin, indexing="ij")
    
    # 3. Stack and reshape to points
    # Swap Y/Z to match NeRF convention as per source [S1, unofficial]
    pts = torch.stack([xx, zz, yy], dim=-1).reshape(-1, 3)
    
    # 4. Query density in chunks
    sigma_list = []
    num_points = pts.shape[0]
    for i in range(0, num_points, chunk):
        end_idx = min(i + chunk, num_points)
        # Dummy directions are required by some NeRF implementations but ignored for density-only query
        dummy_dirs = torch.zeros((end_idx - i, 3), device=device) 
        _, sigma = coarse_model(pts[i:end_idx], dummy_dirs)
        sigma_list.append(sigma)
    
    # 5. Concatenate and reshape to [resolution, resolution, resolution]
    sigma_flat = torch.cat(sigma_list, dim=0)
    sigma_grid = sigma_flat.reshape(resolution, resolution, resolution)
    
    # 6. Run marching cubes
    # measure.marching_cubes expects a numpy array or tensor
    verts_grid, faces, normals, _ = measure.marching_cubes(sigma_grid.cpu().numpy(), level=sigma_threshold)
    
    # 7. Rescale vertices from [0, resolution] to world coordinates
    # Formula: v_world = (v_grid / (resolution - 1)) * (2 * scene_scale) - scene_scale
    verts = verts_grid / (resolution - 1) * (2 * scene_scale) - scene_scale
    
    return verts, faces, normals
```

**Parameters:**
- `resolution`: Voxel grid resolution. Default: 128 [S1, unofficial].
- `scene_scale`: Half-extent of the query box. Default: 1.5 [S1, unofficial].
- `sigma_threshold`: Iso-value for the surface. Default: 50.0 [S1, unofficial].
- `chunk`: Number of points queried per batch. Default: 32768 [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Coordinate Convention**: The Y and Z axes must be swapped during grid creation to match the NeRF's internal coordinate system; failure to do so results in a rotated mesh [S1, unofficial].
- **Threshold Sensitivity**: The choice of `sigma_threshold` significantly affects the mesh quality. Too low may result in noisy, fragmented surfaces; too high may cause the mesh to shrink or disappear [S1, unofficial].
- **Memory Usage**: Querying a high-resolution grid (e.g., 256^3) requires significant GPU memory for both the grid storage and the batched neural network queries.

## Subtopics

### [NeRF-based Mesh Extraction with Color Fusion](7372-nerf-based-mesh-extraction-with-color-fusion.md)
A pipeline that extends basic density meshing by adding texture. After extracting the geometry via Marching Cubes on the density field, it colors the mesh vertices by querying the NeRF's color output along vertex normals or by fusing colors from multiple training views weighted by occlusion and depth [7372-nerf-based-mesh-extraction-with-color-fusion.md].

### Differentiable Marching Tetrahedrons (DMTet)
A differentiable surface extraction method used to create a triangle mesh from a Signed Distance Field (SDF) rather than a density field [S2, unofficial]. Introduced by Shen et al. in 2021, it is used in frameworks like JOC to generate triangle meshes initialized by an SDF from a neural field, allowing for gradient-based optimization of the geometry [S2, unofficial].

## Operating characteristics
- **Time Complexity**: $O(N \cdot T)$ where $N$ is the number of grid points ($\text{resolution}^3$) and $T$ is the time per neural network query. The Marching Cubes step is $O(N)$.
- **Memory Complexity**: $O(N)$ for storing the grid and density values.
- **Strengths**: Simple to implement; leverages robust, standard Marching Cubes implementation; fast for moderate resolutions.
- **Limitations**: Uniform grid is inefficient for sparse scenes or complex details (high resolution needed everywhere); texture is not extracted by this specific method (requires separate color fusion step); sensitive to the density threshold choice.
- **When to use**: When a quick, approximate geometric mesh is needed from a NeRF without the complexity of adaptive sampling or differentiable optimization.

## Background
Originating from the standard NeRF pipeline, this method leverages the fact that NeRFs learn a continuous volume density field. While NeRFs are primarily used for novel view synthesis, the density field implicitly encodes the scene geometry. Extracting a mesh from this field allows for the use of standard 3D graphics pipelines for rendering, simulation, or 3D printing. The approach is documented in community implementations such as `yashtmy/nerf-3d-vision` [S1, unofficial].
