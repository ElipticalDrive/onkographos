# Image-to-Mesh Extraction via Neural Implicit Fields

Also called: Batch Image-to-Mesh via TripoSR, TripoSR Mesh Extraction

## Overview
This method converts a single 2D input image into a 3D triangle mesh with vertex colors using the TripoSR neural model and Marching Cubes extraction [S1, unofficial]. It is designed to batch-process multiple images through the TripoSR model in a single forward pass to generate 3D meshes with vertex colors [S1, unofficial]. It builds on [NeRF-based Mesh Extraction with Color Fusion](7372-nerf-based-mesh-extraction-with-color-fusion.md) by replacing the explicit NeRF training and querying pipeline with a direct implicit field prediction from a single view, eliminating the need for multi-view optimization or volume density grid queries [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A list of tuples `(image_path, output_path)`, where `image_path` is a string to a 2D image file and `output_path` is the desired output mesh file path.
- Output: A list of tuples `(output_path, success: bool, error_message: str | None)` indicating the result of each export, and the exported `.glb` or default format mesh files.

**Data Structures:**
- `processed_images`: A list of PIL `Image.Image` objects, preprocessed and resized to square.
- `scene_codes`: A tensor containing the latent codes predicted by the TripoSR encoder for each input image.
- `meshes`: A list of `trimesh.Trimesh` objects extracted from the scene codes.

**Parameters:**
- `mc_resolution`: Integer specifying the Marching Cubes resolution for mesh extraction. Default: 256. Higher values increase geometric detail [S1, unofficial].
- `foreground_ratio`: Float used during preprocessing to determine foreground segmentation. Default: 0.85 [S1, unofficial].
- `chunk_size`: Integer for renderer chunking. Default: 8192 [S1, unofficial].

**Steps:**

1. **Device Detection and Model Loading:**
   Detect the available device, preferring MPS (Apple Silicon), then CUDA, then CPU [S1, unofficial]. Load the TripoSR model from the Hugging Face repository `stabilityai/TripoSR` using config `config.yaml` and weights `model.ckpt` [S1, unofficial]. Cache the model by device key [S1, unofficial]. Set the renderer chunk size to 8192 using `model.renderer.set_chunk_size(8192)` and move the model to the detected device [S1, unofficial].

2. **Image Preprocessing:**
   For each input image:
   a. Open the image and convert to RGBA [S1, unofficial].
   b. Resize maintaining aspect ratio to fit within a square canvas of size 512x512, padding with white background (255, 255, 255, 255) [S1, unofficial].
   c. Remove the background using `rembg` and composite the subject onto a white background [S1, unofficial].
   d. Apply stylization:
      i. Convert to grayscale and detect the subject mask (non-white pixels, threshold < 240) [S1, unofficial].
      ii. Compute the subject centroid [S1, unofficial].
      iii. Compute distance transform from subject edges [S1, unofficial].
      iv. Compute radial distance from centroid [S1, unofficial].
      v. Generate a light map simulating a top-left light source and combine with ambient occlusion based on edge distance [S1, unofficial].
   e. Append the processed image to `processed_images` and the original tuple to `valid_items` [S1, unofficial]. If an exception occurs, record the failure and continue [S1, unofficial].

3. **Batch Inference:**
   Run inference in evaluation mode using `torch.no_grad()` [S1, unofficial]. Pass the list of `processed_images` to the model on the target device to obtain `scene_codes` [S1, unofficial].

4. **Mesh Extraction:**
   Extract meshes from `scene_codes` by calling `model.extract_mesh(scene_codes, has_vertex_color=True, resolution=mc_resolution)` [S1, unofficial]. This uses Marching Cubes to extract the isosurface [S1, unofficial].

5. **Export:**
   Iterate through the extracted meshes and `valid_items` [S1, unofficial]. For each:
   a. Create the output directory if it does not exist [S1, unofficial].
   b. If the output suffix is `.glb`, export the mesh as GLB; otherwise, export using the default format [S1, unofficial].
   c. Record success or failure in the results list [S1, unofficial].

**Pseudocode:**

```python
import torch
import numpy as np
from PIL import Image
import trimesh
from pathlib import Path
import argparse
import platform

# Assume TripoSR model class and preprocess_for_triposr are imported from the library
# from triposr import TripoSRModel, preprocess_for_triposr

def detect_device():
    if torch.backends.mps.is_available():
        return torch.device("mps")
    elif torch.cuda.is_available():
        return torch.device("cuda")
    else:
        return torch.device("cpu")

def load_model(device):
    # Load from Hugging Face 'stabilityai/TripoSR'
    # config: 'config.yaml', weights: 'model.ckpt'
    # Cache by device key
    model = TripoSRModel.from_pretrained("stabilityai/TripoSR")
    model.renderer.set_chunk_size(8192)
    model.to(device)
    model.eval()
    return model

def preprocess_image(image_path, foreground_ratio=0.85):
    img = Image.open(image_path).convert("RGBA")
    # Resize to square 512x512 with white padding
    w, h = img.size
    size = 512
    scale = size / max(w, h)
    new_w, new_h = int(w * scale), int(h * scale)
    img = img.resize((new_w, new_h), Image.LANCZOS)
    result = Image.new("RGBA", (size, size), (255, 255, 255, 255))
    offset_x = (size - new_w) // 2
    offset_y = (size - new_h) // 2
    result.paste(img, (offset_x, offset_y), img)
    
    # Remove background
    from rembg import remove
    result = remove(result)
    white = Image.new("RGBA", result.size, (255, 255, 255, 255))
    result = Image.alpha_composite(white, result)
    
    # Stylization
    arr = np.array(result).astype(np.float32)
    h, w = arr.shape[:2]
    gray = np.mean(arr[:, :, :3], axis=2)
    white_thresh = 240
    subject_mask = np.any(arr[:, :, :3] < white_thresh, axis=2).astype(np.float32)
    
    if subject_mask.sum() < 100:
        return result
        
    coords = np.argwhere(subject_mask > 0)
    cy, cx = coords.mean(axis=0)
    
    import scipy.ndimage as ndimage
    dist_from_edge = ndimage.distance_transform_edt(subject_mask)
    max_dist = dist_from_edge.max()
    dist_norm = dist_from_edge / max_dist if max_dist > 0 else dist_from_edge
    
    yy, xx = np.mgrid[0:h, 0:w]
    radial = np.sqrt((xx - cx) ** 2 + (yy - cy) ** 2)
    max_radial = radial[subject_mask > 0].max() if subject_mask.sum() > 0 else 1.0
    radial_norm = np.clip(radial / max(max_radial, 1.0), 0, 1)
    
    light_dir_x, light_dir_y = -0.3, -0.5
    light_map = 1.0 - 0.15 * (
        light_dir_x * (xx - cx) / max(max_radial, 1) +
        light_dir_y * (yy - cy) / max(max_radial, 1)
    )
    light_map = np.clip(light_map, 0.7, 1.15)
    
    ao = 0.85 + 0.15 * dist_norm
    ao = ndimage.gaussian_filter(ao, sigma=10)
    
    stylized = arr.copy()
    stylized[:, :, :3] = stylized[:, :, :3] * light_map[:, :, np.newaxis] * ao[:, :, np.newaxis]
    
    return Image.fromarray(stylized.astype(np.uint8), "RGBA")

def batch_image_to_mesh(image_paths, output_paths, mc_resolution=256, foreground_ratio=0.85):
    device = detect_device()
    model = load_model(device)
    
    processed_images = []
    valid_items = []
    results = []
    
    for img_path, out_path in zip(image_paths, output_paths):
        try:
            img = preprocess_image(img_path, foreground_ratio)
            processed_images.append(img)
            valid_items.append((img_path, out_path))
        except Exception as e:
            results.append((out_path, False, str(e)))
            
    if not processed_images:
        return results
        
    with torch.no_grad():
        scene_codes = model(processed_images, device=device)
        
    meshes = model.extract_mesh(scene_codes, has_vertex_color=True, resolution=mc_resolution)
    
    for mesh, (img_path, out_path) in zip(meshes, valid_items):
        try:
            Path(out_path).parent.mkdir(parents=True, exist_ok=True)
            if out_path.endswith('.glb'):
                mesh.export(out_path, file_type='glb')
            else:
                mesh.export(out_path)
            results.append((out_path, True, None))
        except Exception as e:
            results.append((out_path, False, str(e)))
            
    return results

if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("--images", nargs="+", required=True)
    parser.add_argument("--outputs", nargs="+", required=True)
    parser.add_argument("--resolution", type=int, default=256)
    parser.add_argument("--foreground-ratio", type=float, default=0.85)
    args = parser.parse_args()
    
    results = batch_image_to_mesh(args.images, args.outputs, args.resolution, args.foreground_ratio)
    for res in results:
        print(res)
```

**Edge Cases and Pitfalls:**
- If the subject mask sum is less than 100 pixels, the stylization step is skipped, and the image is returned as-is [S1, unofficial].
- Font loading for emoji rendering is not part of the core mesh extraction but may be relevant if input images are generated programmatically [S1, unofficial].
- Precision issues may arise if the Marching Cubes resolution is too low, resulting in loss of geometric detail [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of input images due to batch inference [S1, unofficial].
- **Memory Complexity:** Depends on the batch size and the resolution of the Marching Cubes extraction [S1, unofficial].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales with batch size; larger batches may require more memory [S1, unofficial].
- **Strengths:** Fast single-view reconstruction; batch processing capability; vertex color support [S1, unofficial].
- **Limitations:** Quality depends on the single input view; may struggle with complex geometries or occlusions not visible in the input [S1, unofficial].
- **When to use:** When a quick 3D mesh from a single image is needed, and multi-view data is unavailable [S1, unofficial].
- **When not to use:** When high geometric accuracy or multi-view consistency is required [S1, unofficial].

## Background
The method is based on the TripoSR model, which is a neural implicit field approach for 3D reconstruction from a single image [S1, unofficial]. It was developed by Stability AI and released on Hugging Face [S1, unofficial]. The method leverages the power of neural networks to predict implicit fields directly from 2D images, bypassing the need for explicit volume rendering or multi-view optimization [S1, unofficial].
