# Voxel2Mesh

Also called: 3D Mesh Model Generation from Volumetric Data

## Overview
Voxel2Mesh is a CNN-based architecture that generates 3D surface meshes directly from 3D image volumes without post-processing, avoiding artifacts and enabling end-to-end training [S1, unofficial]. It sets itself apart from standard voxel rendering or segmentation methods by outputting explicit surface representations (vertices and faces) rather than labeled voxel grids, allowing for differentiable mesh operations and better accuracy in biomedical segmentation tasks [S1, unofficial].

## How it works
**Inputs and Outputs:**
The input is a volumetric tensor $x$ of shape $(B, C_{in}, D, H, W)$ for 3D data or $(B, C_{in}, H, W)$ for 2D data, where $B$ is batch size, $C_{in}$ is input channels, and $D, H, W$ are spatial dimensions [S1, unofficial]. The output is a list of meshes, one per semantic class (excluding background) [S1, unofficial]. Each mesh consists of vertices $V$ (shape $[B, 3, N]$), faces $F$ (shape $[B, 3, F]$), and latent features $L$ (shape $[B, C, N]$) [S1, unofficial].

**Data Structures:**
*   **Encoder:** A U-Net encoder with `config.steps + 1` layers [S1, unofficial].
*   **Decoder:** Iterative refinement stages that deform a template sphere [S1, unofficial].
*   **Mesh State:** At each stage $i$, the state includes current vertices, faces, and latent features [S1, unofficial].
*   **Skip Connections:** Feature maps from the encoder are upsampled and concatenated with decoder features [S1, unofficial].

**Parameters:**
*   `config.ndims`: 2 or 3, determining convolution dimensionality [S1, unofficial].
*   `config.first_layer_channels`: Base channel count for the U-Net [S1, unofficial].
*   `config.steps`: Number of downsampling/upsampling steps [S1, unofficial].
*   `config.num_classes`: Number of semantic classes. The loop runs for $k \in \{1, \dots, \text{num\_classes}-1\}$ [S1, unofficial].
*   `unpool`: List specifying mesh subdivisions per stage. Default: `[0, 1, 1, 1, 1]` [S1, unofficial].

**Algorithm Steps:**

1.  **Initialization:**
    Load a pre-loaded icosahedron sphere with 162 vertices [S1, unofficial]. Normalize vertices to unit length:
    $$ V_{init} = \frac{V_{sphere}}{\sqrt{\sum_{j} V_{sphere,j}^2}} $$
    Initialize prediction list $pred[k]$ for each class $k$ with $V_{init}$, initial faces (icosahedron topology), and reference sphere vertices [S1, unofficial].

2.  **Encoding:**
    Encode the input volume $x$ using the U-Net encoder [S1, unofficial].
    *   Layer 0: Input channels $C_{in}$, Output channels $C_{first} = \text{config.first\_layer\_channels}$ [S1, unofficial].
    *   Layer $i$ ($1 \le i \le S$): Input channels $C_{first} \cdot 2^{i-1}$, Output channels $C_{first} \cdot 2^i$ [S1, unofficial].
    *   Apply max pooling before each layer except the first [S1, unofficial].
    *   Store encoder outputs as $down\_outputs$ [S1, unofficial].

3.  **Iterative Decoding and Refinement:**
    For each class $k$ from $1$ to $\text{num\_classes}-1$:
    For each decoder stage $i$ from $0$ to $S$:
    
    a. **Feature Retrieval:**
       Retrieve current vertices $V$, faces $F$, and latent features $L$ from $pred[k][i]$ [S1, unofficial].
       Retrieve skip connection feature map $x_{skip}$ from $down\_outputs$ in reverse order ($down\_outputs[::-1]$) [S1, unofficial].
       
    b. **Skip Connection Processing:**
       If $i > 0$:
       1. Upsample $x_{skip}$ using `grid_upconv_layer` (ConvTranspose) [S1, unofficial].
       2. Crop and merge with the corresponding encoder output $down\_output$ [S1, unofficial].
       3. Pass through `grid_unet_layer` [S1, unofficial].
       If $i == 0$: $x_{skip}$ is simply the encoder output [S1, unofficial].
       
    c. **Mesh Unpooling (Subdivision):**
       If `config.unpool[i] > 0`, apply `uniform_unpool` to $V$, $F$, and $L$ to increase resolution by subdividing faces and averaging vertex positions/features [S1, unofficial].
       
    d. **Graph Construction:**
       Compute adjacency matrix $A$ and degree matrix $D$ for the current mesh topology $(V, F)$ using `adjacency_matrix(V, F)` [S1, unofficial].
       
    e. **Feature Aggregation:**
       1. Compute skip features: Pass cropped $x_{skip}$ (first `skip_amount` channels) and current vertices $V$ through `skip_connection` module:
          $$ F_{skip} = \text{skip\_connection}(x_{skip}[:, :skip\_amount], V) $$
       2. Concatenate features along dimension 2:
          $$ F_{input} = \begin{cases} \text{cat}(L, F_{skip}, V) & \text{if } L \text{ is not None} \\ \text{cat}(F_{skip}, V) & \text{otherwise} \end{cases} $$
          
    f. **Graph Convolution:**
       Process $F_{input}$ through `graph_unet_layer` using $A$, $D$, $V$, and $F$ to update latent features $L_{new}$ [S1, unofficial].
       
    g. **Vertex Displacement:**
       Predict vertex displacements $\Delta V$ using `feature2vertex` layer on $L_{new}$ and mesh topology [S1, unofficial].
       
    h. **Vertex Update:**
       Update vertices:
       $$ V_{new} = V + \Delta V $$
       
    i. **Storage:**
       Store $V_{new}$, $F$, $L_{new}$, and reference $V_{sphere}$ in $pred[k][i+1]$ for the next iteration [S1, unofficial].

4.  **Inference:**
    Extract final predicted vertices and faces for each class [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def voxel2mesh_forward(x, config, down_outputs):
    """
    x: Input volume tensor [B, C_in, D, H, W] or [B, C_in, H, W]
    config: Configuration object with ndims, first_layer_channels, steps, num_classes, unpool
    down_outputs: List of encoder feature maps from U-Net, length steps+1
    """
    # 1. Initialize Sphere
    # Load icosahedron vertices (162 vertices)
    sphere_vertices = torch.randn(162, 3) # Placeholder for pre-loaded icosahedron
    # Normalize to unit length
    sphere_vertices = sphere_vertices / torch.sqrt(torch.sum(sphere_vertices**2, dim=1)[:, None])
    sphere_vertices = sphere_vertices[None] # Add batch dim [1, 162, 3]
    
    # Initialize faces (icosahedron topology)
    sphere_faces = torch.randint(0, 162, (162, 3)) # Placeholder for pre-loaded faces
    sphere_faces = sphere_faces[None] # Add batch dim [1, 162, 3]
    
    # Reference vertices for normalization/loss
    ref_vertices = sphere_vertices.clone()
    
    # Initialize predictions for each class (excluding background 0)
    num_classes = config.num_classes
    pred = {}
    for k in range(1, num_classes):
        pred[k] = []
        B = x.shape[0]
        N_init = sphere_vertices.shape[1]
        C_feat = config.first_layer_channels
        latent_init = torch.zeros(B, C_feat, N_init, device=x.device)
        
        pred[k].append({
            'vertices': sphere_vertices.clone(),
            'faces': sphere_faces.clone(),
            'latent_features': latent_init,
            'ref_vertices': ref_vertices.clone()
        })

    # 2. Decoder Loop
    for i in range(config.steps + 1): # Stages 0 to steps
        # Get skip connection from reversed encoder outputs
        x_skip = down_outputs[::-1][i]
            
        if i > 0:
            # Upsample using ConvTranspose
            x_skip = F.conv_transpose3d(x_skip, weight=torch.ones(1,1,2,2,2), stride=2, padding=1)
            # Crop and merge with corresponding encoder output
            x_enc = down_outputs[::-1][i-1]
            # Crop spatial dimensions to match x_skip
            crop_d, crop_h, crop_w = x_skip.shape[2:]
            x_enc = x_enc[:, :, :crop_d, :crop_h, :crop_w]
            x_skip = torch.cat([x_skip, x_enc], dim=1)
            # Pass through grid unet layer (standard conv block)
            x_skip = F.relu(F.conv3d(x_skip, weight=torch.ones(1, x_skip.shape[1], 3, 3, 3), padding=1))
        # If i == 0, x_skip remains the encoder output

        # Process each class
        for k in range(1, num_classes):
            state = pred[k][-1]
            V = state['vertices']
            faces = state['faces']
            L = state['latent_features']
            
            # Unpooling
            if config.unpool[i] > 0:
                V, faces, L = uniform_unpool(V, faces, L)
            
            # Graph Construction
            A, D = adjacency_matrix(V, faces)
            
            # Skip Features
            skip_amount = config.first_layer_channels
            x_skip_cropped = x_skip[:, :skip_amount]
            F_skip = skip_connection(x_skip_cropped, V)
            
            # Concatenate
            if L is not None and L.shape[1] > 0:
                F_input = torch.cat([L, F_skip, V], dim=2)
            else:
                F_input = torch.cat([F_skip, V], dim=2)
                
            # Graph Convolution
            L_new = graph_unet_layer(F_input, A, D, V, faces)
            
            # Vertex Displacement
            delta_V = feature2vertex(L_new, V, faces)
            
            # Update Vertices
            V_new = V + delta_V
            
            # Store for next stage
            pred[k].append({
                'vertices': V_new,
                'faces': faces,
                'latent_features': L_new,
                'ref_vertices': state['ref_vertices']
            })

    # 3. Output
    meshes = []
    for k in range(1, num_classes):
        final_state = pred[k][-1]
        meshes.append({
            'vertices': final_state['vertices'],
            'faces': final_state['faces'],
            'class_id': k
        })
    return meshes

# Helper definitions (self-contained, standard operations [G])
def uniform_unpool(V, faces, L):
    """Subdivides faces into 4, adds midpoints, averages vertex positions/features."""
    # Standard subdivision: split each face into 4 triangles
    # New vertices: original + 3 midpoints per face
    mid_V = (V[:, :, faces[:, :, 0]] + V[:, :, faces[:, :, 1]] + V[:, :, faces[:, :, 2]]) / 3.0
    mid_L = (L[:, :, faces[:, :, 0]] + L[:, :, faces[:, :, 1]] + L[:, :, faces[:, :, 2]]) / 3.0
    # Topology update omitted for brevity; standard face splitting [G]
    return V, faces, L

def adjacency_matrix(V, faces):
    """Computes adjacency A and degree D matrices from faces."""
    # Standard graph construction: A[i,j] = 1 if vertices i and j share a face [G]
    # Implementation omitted for brevity; standard sparse matrix construction [G]
    return torch.zeros_like(V), torch.ones_like(V)

def skip_connection(x_feat, V):
    """Passes cropped feature map and vertices through a small MLP/Conv."""
    # Concatenate spatial features with vertex coordinates [G]
    return F.relu(torch.cat([x_feat, V], dim=1))

def graph_unet_layer(F_input, A, D, V, faces):
    """Processes features through graph convolution blocks."""
    # Standard graph convolution: L_new = D^{-1} A L_input W + bias [G]
    return F.relu(F.linear(F_input.transpose(1, 2)).transpose(1, 2))

def feature2vertex(L_new, V, faces):
    """Predicts vertex displacements from latent features."""
    # MLP projecting latent features to 3D displacement [G]
    return torch.tanh(F.linear(L_new.transpose(1, 2)).transpose(1, 2)) * 0.1
```

**Pitfalls:**
*   Missing faces on output mesh due to inconsistent vertex winding order (some faces clockwise, others anti-clockwise). Handled by setting back-face color same as front-face in the mesh viewer, or by writing a function to correct face orientations [S1, unofficial].
*   GPU memory exhaustion during evaluation due to high vertex count. Mitigated by reducing unpool values (e.g., `[0, 1, 0, 1, 1]` or `[0, 1, 0, 1, 0]`) [S1, unofficial].
*   Shuffled slice order in loaded image stacks on certain systems. Resolved by applying a system-specific fix [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the number of classes, decoder steps, and mesh resolution (number of vertices $N$) [G]. Graph convolutions are typically $O(E)$ where $E$ is edges, roughly proportional to $N$ [G].
*   **Memory Complexity:** High. GPU memory exhaustion is a known issue during evaluation due to high vertex counts, especially with default unpooling settings [S1, unofficial].
*   **Performance:** Evaluated on Electron Microscopy, MRI brain images, and CT liver scans. Outperforms state-of-the-art segmentation methods (CNN baseline + post-processing) in accuracy [S1, unofficial].
*   **Strengths:** End-to-end differentiable training, no post-processing artifacts, explicit surface representation [S1, unofficial].
*   **Limitations:** High GPU memory usage; sensitive to vertex winding order (faces may be clockwise or anti-clockwise inconsistently); potential slice order issues in input stacks [S1, unofficial].
*   **When to use:** When explicit 3D meshes are required from volumetric data and end-to-end training is desired [S1, unofficial].
*   **When not to use:** When GPU memory is limited (reduce unpooling values) or when consistent face orientation is critical without post-processing correction [S1, unofficial].

## Background
Voxel2Mesh was introduced by Udaranga Wickramasinghe, Edoardo Remelli, Graham Knott, and Pascal Fua in the MICCAI 2020 proceedings [S1, unofficial]. It addresses the limitation of CNN-based volumetric methods that label individual voxels, which require post-processing to obtain 3D surface representations, introducing artifacts and preventing end-to-end training [S1, unofficial].
