# Mesh Extraction from NeRF

Also called: Density Field Meshing, Geometry Extraction via Marching Cubes, Marching Cubes on NeRF, Mesh Extraction from Neural Volume, NeRF Density Field Mesh Extraction

## Overview
Mesh Extraction from NeRF converts a trained Neural Radiance Field (NeRF) into an explicit triangle mesh by treating the network's volume density output as a scalar field, extracting the isosurface via the Marching Cubes algorithm, and coloring the resulting vertices using the NeRF's color prediction [S2][S4]. It differs from sibling methods like [MISE](977-mise-meshing-isosurfaces-by-extracting.md) and [FlexiCubes](3669-flexicubes.md) by operating directly on the raw density field $\sigma$ rather than a learned Signed Distance Field (SDF) or a differentiable parametric representation, making it a post-processing step rather than a joint optimization objective [S2][S4].

## How it works
**Inputs:** A trained NeRF model mapping 3D coordinates and viewing directions to density $\sigma$ and color $\mathbf{c}$, a 3D bounding box defining the region of interest, a grid resolution, and a density threshold [S3, unofficial][S4].
**Outputs:** A triangle mesh $\mathcal{M}$ with vertex positions, face indices, and vertex colors (or UV coordinates for texture mapping) [S4][S6].

**Data Structures:**
1. **Coordinate Grid:** A 3D tensor of shape $(R, R, R)$ where $R$ is the resolution [S3, unofficial].
2. **Density Field:** A 3D tensor of shape $(R, R, R)$ storing $\sigma$ values [S4].
3. **Mesh:** Standard triangle mesh format (vertices $V$, faces $F$) [S4].

**Steps:**

1.  **Grid Generation:**
    Define a 1D linear space for each axis spanning the scene scale [S3, unofficial].
    $$ \text{lin} = \text{linspace}(-\text{scene\_scale}, \text{scene\_scale}, \text{resolution}) $$
    Create a 3D meshgrid. NeRF conventions often swap Y and Z axes relative to standard Cartesian grids [S3, unofficial].
    $$ x, z, y = \text{meshgrid}(\text{lin}, \text{lin}, \text{lin}, \text{indexing}=\text{"ij"}) $$
    Stack and reshape to a list of 3D points $P$:
    $$ P = \text{stack}([x, z, y]).\text{reshape}(-1, 3) $$

2.  **Density Evaluation:**
    Query the NeRF model for density $\sigma$ at each point $p_i \in P$ [S4]. Since NeRF requires viewing directions, dummy directions (e.g., all zeros) are passed if the model does not use direction for density prediction [S3, unofficial].
    $$ \sigma(p_i) = \text{NeRF}_\sigma(p_i, \mathbf{d}_{\text{dummy}}) $$
    To manage memory, this is done in chunks of size $C$ (default 32768) [S3, unofficial].
    Reshape the flattened density array back into a 3D grid $\Sigma$ of shape $(R, R, R)$ [S3, unofficial].

3.  **Isosurface Extraction:**
    Apply the Marching Cubes algorithm to the density grid $\Sigma$ using a threshold $\sigma_{\text{threshold}}$ [S4].
    $$ \mathcal{M} = \text{MarchingCubes}(\Sigma, \sigma_{\text{threshold}}) $$
    This yields vertices $V$, faces $F$, and normals $N$ in grid coordinates [S3, unofficial].

4.  **Coordinate Rescaling:**
    Convert vertices from grid indices $[0, R-1]$ to world coordinates $[-\text{scene\_scale}, \text{scene\_scale}]$ [S3, unofficial].
    $$ v_{\text{world}} = \frac{v_{\text{grid}}}{R - 1} \times (2 \times \text{scene\_scale}) - \text{scene\_scale} $$

5.  **Coloring:**
    For each vertex $v_j$ in $\mathcal{M}$, construct a viewing ray $r_j$ and query the NeRF for color [S4].
    $$ \mathbf{c}(v_j) = \text{NeRF}_c(v_j, r_j) $$

6.  **Texture Mapping (Optional):**
    Perform UV unwrapping on the vertex-colored mesh [S6]. To minimize distortion, Least Squares Conformal Mapping (LSCM) can be used to minimize conformal energy [S4]:
    $$ E(u, v) = \int_{\Omega} (|\nabla u|^2 + |\nabla v|^2) dA $$
    Where $(u, v)$ are 2D texture coordinates, $\Omega$ is the surface, and $dA$ is the differential area element [S4].

**Parameters:**
*   `resolution`: Voxel grid resolution. Default: 128 [S3, unofficial].
*   `scene_scale`: Half-extent of the query box. Default: 1.5 [S3, unofficial].
*   `sigma_threshold`: Iso-value for the surface. Default: 50.0 [S3, unofficial].
*   `chunk`: Batch size for NeRF queries. Default: 32768 [S3, unofficial].

**Pitfalls:**
*   **Axis Swapping:** Failing to swap Y/Z axes during grid creation results in a rotated or flipped mesh due to NeRF's coordinate convention [S3, unofficial].
*   **Internal Noise:** The generation of voxels and mesh within the object envelope creates internal noise that complicates error quantification and requires external tools for semi-automatic removal [S2].
*   **Memory:** Dense volumetric sampling requires $O(R^3)$ memory for the grid and $O(R^3)$ queries to the NeRF, which can be prohibitive for high resolutions [S3, unofficial][S4].

```python
import torch
import numpy as np
from skimage import measure

def extract_mesh_from_nerf(coarse_model, resolution=128, scene_scale=1.5, sigma_threshold=50.0, chunk=32768):
    """
    Extract a mesh from a trained NeRF model using Marching Cubes on the density field.
    
    Args:
        coarse_model: A NeRF model instance with a forward method.
        resolution: Integer, grid resolution.
        scene_scale: Float, half-extent of the bounding box.
        sigma_threshold: Float, density threshold for Marching Cubes.
        chunk: Integer, batch size for model queries.
        
    Returns:
        verts: Tensor of shape (N, 3) in world coordinates.
        faces: Tensor of shape (M, 3) of vertex indices.
        normals: Tensor of shape (N, 3).
    """
    # 1. Grid Generation
    lin = torch.linspace(-scene_scale, scene_scale, resolution, device=coarse_model.device)
    xx, zz, yy = torch.meshgrid(lin, lin, lin, indexing="ij")
    pts = torch.stack([xx, zz, yy], dim=-1).reshape(-1, 3)
    
    # 2. Density Evaluation
    sigma_grid_flat = []
    for i in range(0, pts.shape[0], chunk):
        chunk_pts = pts[i:i+chunk]
        dummy_dirs = torch.zeros_like(chunk_pts)
        _, sigma = coarse_model(chunk_pts, dummy_dirs)
        sigma_grid_flat.append(sigma.detach().cpu())
        
    sigma_grid = torch.cat(sigma_grid_flat, dim=0).reshape(resolution, resolution, resolution)
    
    # 3. Isosurface Extraction
    verts, faces, normals, _ = measure.marching_cubes(sigma_grid.numpy(), level=sigma_threshold)
    
    # 4. Coordinate Rescaling
    verts = verts / (resolution - 1) * (2 * scene_scale) - scene_scale
    
    return verts, faces, normals
```

## Subtopics

### [Differentiable Marching Tetrahedrons (DMTet)](7130-differentiable-marching-tetrahedrons-dmtet.md)
Differentiable Marching Tetrahedrons (DMTet) is a surface extraction method that generates a triangle mesh from a learned Signed Distance Field (SDF) by applying the Marching Tetrahedra algorithm on an adaptive tetrahedral grid. It is distinguished from its sibling [Mesh Extraction from NeRF](12441-mesh-extraction-from-nerf.md), which typically relies on Marching Cubes (MC) on fixed grids, by producing meshes with lower Chamfer distance, fewer holes, and reduced noise or floaters, even when compared to MC at higher uniform resolutions.

### [NeRF-based Mesh Extraction with Color Fusion](7372-nerf-based-mesh-extraction-with-color-fusion.md)
This method extracts a textured 3D mesh from a trained Neural Radiance Field (NeRF) by converting the volume density into a scalar field, extracting the isosurface via Marching Cubes, and coloring vertices by fusing colors from multiple training views weighted by occlusion and depth. It distinguishes itself from simple vertex-normal querying by aggregating color information from all visible training cameras, reducing view-dependent artifacts and providing more robust colorization for complex geometries.

### [Error-based Mesh Subdivision](15172-error-based-mesh-subdivision.md)
Error-based Mesh Subdivision is an iterative adaptive refinement strategy for explicit meshes used in joint optimization with Gaussian Splats. It addresses the problem of uniform triangle density by densifying faces in high-geometry-frequency areas and maintaining low complexity in smooth regions, thereby decoupling geometry optimization from appearance modeling. It differs from sibling methods by using vertex gradient projections onto face normals as the primary error metric for subdivision, rather than image-space gradient variation or color fusion.

### Neural SDF Mesh Extraction with Texture Synthesis
Extracts a mesh from an optimized neural SDF using the marching cube algorithm [S7]. Computes UV mapping using the Blender Smart UV Project tool [S7]. Generates material textures by densely sampling points on the triangle meshes using trilinearly interpolated UV coordinates, querying material networks at these sampled surface points to get material parameters, and splatting these per-point material parameters to texture images using their interpolated UV coordinates [S7].

### Neural Duplex Radiance Field Training & Mesh Extraction
Extracts two geometry proxies from a trained teacher NeRF model using marching cubes with specific threshold values [S8]. Automatically removes isolated mesh parts based on their diameter to ensure clean geometry for feature aggregation [S8]. Tested threshold values include $10^{-4}$, $5 \times 10^{-4}$, $10^{-3}$, $5 \times 10^{-3}$, and $10^{-2}$ [S8]. On Synthetic-NeRF Ficus data, a single-surface baseline with threshold $10^{-2}$ achieves PSNR 27.05, SSIM 0.935, LPIPS 0.069, while the proposed duplex method achieves PSNR 32.67, SSIM 0.975, LPIPS 0.024 [S8]. On Synthetic-NeRF Chair data, distilling from TensoRF yields PSNR 34.73, SSIM 0.981, LPIPS 0.013, and distilling from Instant-NGP yields PSNR 34.30, SSIM 0.979, LPIPS 0.010 [S8]. Fine-tuning a single extracted mesh threshold improves metrics slightly but fails to match duplex radiance fields due to inaccurate geometry representation [S8].

### Mesh Extraction from Nerflets
Creates point samples on a regular grid and evaluates density, semantic, and instance information for each point using the nerflets [S9]. Estimates point normals using the 5 nearest neighbors [S9]. Generates a mesh using screened Poisson surface reconstruction [S9]. Colors mesh triangles according to the semantic and instance labels of their vertices [S9].

## Operating characteristics
*   **Time Complexity:** $O(R^3)$ for grid generation and density evaluation, where $R$ is the resolution [S3, unofficial][S4]. The Marching Cubes step is linear in the number of voxels [S4].
*   **Memory Complexity:** $O(R^3)$ to store the density grid and intermediate point tensors [S3, unofficial][S4]. High resolutions (e.g., $R=256$) require significant VRAM for the grid and batched NeRF queries [S3, unofficial][S4].
*   **Performance:** Depends heavily on the NeRF inference speed [S2]. Hash-encoded NeRFs (e.g., Instant-NGP) significantly accelerate the density evaluation step [S2]. The extraction of a mesh takes around 3-5 minutes [S6].
*   **Strengths:** Simple to implement; leverages mature Marching Cubes libraries; produces watertight meshes [S2].
*   **Limitations:** The density field is not a true SDF, leading to potential topological errors or "blobby" surfaces if the threshold is not carefully chosen [S2]. It does not support differentiable rendering directly during extraction, unlike [Differentiable Marching Cubes](9774-differentiable-marching-cubes.md) [S2].

## Background
The method originates from the standard post-processing pipeline for NeRFs, where the implicit density field is converted to an explicit mesh for downstream applications like 3D printing or game engines [S2][S4]. The foundational NeRF papers established the density-based representation [S1][S4]. The specific use of Marching Cubes on NeRF density grids is a common technique cited in various implementations and tutorials [S2][S4]. Variations involving SDFs and differentiable extraction have been developed to address the limitations of raw density fields [S3, unofficial][S7].
