# Error-based Mesh Subdivision

Also called: Gradient-based subdivision

## Overview
Error-based Mesh Subdivision is an iterative adaptive refinement strategy for explicit meshes used in joint optimization with Gaussian Splats [S1]. It addresses uniform triangle density by densifying faces in high-geometry-frequency areas and maintaining low complexity in smooth regions, thereby decoupling geometry optimization from appearance modeling [S1]. It differs from sibling methods by using vertex gradient projections onto face normals as the primary error metric for subdivision, rather than image-space gradient variation or color fusion [S1][S2, unofficial].

## How it works
**Inputs:** A coarse initial mesh $M$, a loss function $L$, and a subdivision count parameter $k$ [S1].
**Outputs:** A refined mesh with adaptive triangle density and initialized Gaussian Splat parameters for new vertices [S1].

**Data Structures:**
*   **Mesh:** Set of vertices $V$ and faces $F$. Each face $f_j$ has a normal $n_{f_j}$ and a list of incident vertices $v_i \in f_j$ [S1].
*   **Error Map:** A scalar value $e(f_j)$ for each face $f_j \in F$ [S1].
*   **Gaussian Parameters:** For each vertex, a set of parameters (position, covariance, opacity, spherical harmonics) stored in a structure compatible with the Gaussian Splatting renderer [S1].

**Steps:**

1.  **Compute Gradient Normals:** For every vertex $v_i$ in the mesh, compute the gradient of the loss function with respect to the vertex position, denoted $\nabla_{v_i} L$ [S1].
2.  **Project to Face Normals:** For each face $f_j$ with vertices $v_i \in f_j$, project the vertex gradients onto the face normal $n_{f_j}$ to compute the error contribution [S1]. The error $e(f_j)$ for face $f_j$ is the sum of these projections:
    $$ e(f_j) = \sum_{v_i \in f_j} (\nabla_{v_i} L) \cdot n_{f_j} $$
    [S1]
3.  **Identify Subdivision Candidates:** Sort all faces $f_j$ by their error $e(f_j)$ in descending order [S1]. Select the top-$k$ faces with the largest accumulated gradient magnitudes [S1].
4.  **Midpoint Subdivision:** Perform one iteration of the midpoint subdivision algorithm on the selected top-$k$ faces [S1].
5.  **Initialize New Gaussians:** For each newly generated vertex (and its associated Gaussian Splat), initialize its parameters by transferring values from the nearest previously optimized Gaussian Splat [S1]. This preserves learned features and accelerates convergence [S1].
6.  **Iterate:** Repeat steps 1–5 for a predetermined number of iterations [S1].

**Pseudocode:**

```python
def error_based_subdivision(vertices, faces, loss_fn, k, num_iterations):
    """
    vertices: list of dicts with keys 'pos' (list of floats), 'gaussian_params' (list or None)
    faces: list of dicts with keys 'vertices' (list of 3 vertex indices), 'normal' (list of 3 floats)
    loss_fn: callable returning dict {v_idx: grad_vec} for current vertex positions
    k: number of faces to subdivide per iteration
    num_iterations: total number of subdivision rounds
    """
    for _ in range(num_iterations):
        # 1. Compute gradients
        gradients = loss_fn(vertices)
        
        # 2. Compute face errors
        face_errors = {}
        for f in faces:
            error_sum = 0.0
            for v_idx in f['vertices']:
                grad = gradients[v_idx]
                normal = f['normal']
                error_sum += sum(g * n for g, n in zip(grad, normal))
            face_errors[f] = error_sum
            
        # 3. Select top-k faces
        sorted_faces = sorted(face_errors.items(), key=lambda x: x[1], reverse=True)
        to_subdivide = [f for f, _ in sorted_faces[:k]]
        
        # 4. Subdivide selected faces
        new_vertices = []
        new_faces = []
        next_idx = len(vertices)
        
        for f in to_subdivide:
            v0, v1, v2 = f['vertices']
            p0, p1, p2 = vertices[v0]['pos'], vertices[v1]['pos'], vertices[v2]['pos']
            
            # Calculate midpoints
            m01 = [(a + b) / 2.0 for a, b in zip(p0, p1)]
            m12 = [(a + b) / 2.0 for a, b in zip(p1, p2)]
            m20 = [(a + b) / 2.0 for a, b in zip(p2, p0)]
            
            # Create new vertex entries
            nv01 = {'pos': m01, 'gaussian_params': None, 'idx': next_idx}
            nv12 = {'pos': m12, 'gaussian_params': None, 'idx': next_idx + 1}
            nv20 = {'pos': m20, 'gaussian_params': None, 'idx': next_idx + 2}
            next_idx += 3
            new_vertices.extend([nv01, nv12, nv20])
            
            # Create 4 child faces sharing the new vertices
            new_faces.extend([
                {'vertices': [v0, nv01['idx'], nv20['idx']], 'normal': f['normal']},
                {'vertices': [v1, nv12['idx'], nv01['idx']], 'normal': f['normal']},
                {'vertices': [v2, nv20['idx'], nv12['idx']], 'normal': f['normal']},
                {'vertices': [nv01['idx'], nv12['idx'], nv20['idx']], 'normal': f['normal']}
            ])
            
        # Update mesh topology
        vertices.extend(new_vertices)
        faces = [f for f in faces if f not in to_subdivide] + new_faces
        
        # 5. Initialize Gaussian parameters for new vertices
        for nv in new_vertices:
            min_dist = float('inf')
            nearest = None
            for v in vertices:
                if v['gaussian_params'] is not None:
                    dist = sum((a - b) ** 2 for a, b in zip(v['pos'], nv['pos']))
                    if dist < min_dist:
                        min_dist = dist
                        nearest = v
            if nearest is not None:
                nv['gaussian_params'] = nearest['gaussian_params'].copy()
            else:
                nv['gaussian_params'] = [0.0] * 10  # [G] Default initialization fallback

    return vertices, faces
```

**Parameters:**
*   $k$: Number of faces to subdivide per iteration. Typical values are not given in the sources. [Not given in the sources.]
*   `num_iterations`: Number of subdivision rounds. Typical values are not given in the sources. [Not given in the sources.]

**Edge Cases and Pitfalls:**
*   **Extraneous Geometry:** The initial coarse mesh may contain triangles not present in the actual scene, leading to inconsistencies between Gaussian Splats and mesh triangles [S1]. The method addresses this via a separate mesh faces removal strategy [S1].
*   **Gradient Noise:** If the loss landscape is noisy, vertex gradients may not be robust indicators of geometry frequency [S1].
*   **Initialization:** New Gaussian parameters must be initialized carefully to preserve learned features; transferring from the nearest optimized Gaussian is the recommended approach [S1].

## Subtopics

### Gradient-Guided Triangle Densification
A preprocessing step used in CF-Splat to improve spatial resolution before appearance estimation [S2, unofficial]. It subdivides triangles with high image-space gradient variation [S2, unofficial]. Unlike Error-based Mesh Subdivision which uses vertex loss gradients, this method uses pixel-to-triangle correspondence to measure multiview image-space variation $S_j$ [S2, unofficial]. The variation is calculated as $S_j \triangleq \sum_{k=1}^K \sum_{p \in \Omega_{k,j}} \|\nabla I_k(p)\|^2$, where $\Omega_{k,j}$ is the set of pixels covered by triangle $f_j$ in view $O_k$ [S2, unofficial]. Triangles with large $S_j$ are selected for subdivision [S2, unofficial]. For each selected triangle, covered pixels are mapped to the surface using barycentric weights, and a new vertex is placed at the mean of these samples [S2, unofficial]. The parent triangle is replaced by three child triangles sharing the new vertex [S2, unofficial]. The refined mesh is re-rasterized after each densification round and the process terminates after a set number of rounds [S2, unofficial]. This densification must be completed before appearance estimation to avoid extra iterations in the global Least Squares Solve [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Dominated by the differentiable rendering pass required to compute loss gradients per iteration [S1]. Subdivision itself scales linearly with the number of selected faces [S1].
*   **Memory Complexity:** Increases with each subdivision round due to added vertices, faces, and corresponding Gaussian parameters [S1].
*   **Strengths:** Adaptively refines geometry where needed, decoupling geometry and appearance optimization [S1]. Preserves learned features by initializing new Gaussians from neighbors [S1].
*   **Limitations:** Requires a differentiable rendering pipeline to compute gradients [S1]. Initial mesh quality affects results due to extraneous geometry [S1]. Performance depends on the choice of $k$ and iteration count [S1].
*   **When to use:** When high-frequency geometric details are present and a uniform mesh is insufficient [S1]. When joint optimization with Gaussian Splats is employed [S1].
*   **When not to use:** When computational resources are limited and a coarse approximation is sufficient [G]. When the initial mesh contains significant extraneous geometry without a removal step [S1].

## Background
The method builds on the coarse-to-fine mesh refinement strategy from NeRF2Mesh [S1]. It is designed to adaptively densify triangle faces based on vertex gradients, which serve as robust indicators of high-geometry frequency areas [S1]. It is used within joint optimization frameworks that explicitly couple mesh geometry with Gaussian Splat appearance modeling [S1].
