# Uncertainty Propagation for Iso-Surface Extraction

Also called: Uncertainty Propagation

## Overview
Uncertainty Propagation (UP) is a hierarchical iso-surface extraction method for Implicit Neural Representations (INRs) that estimates the output distribution of the network to predict active cells in a kd-tree, thereby skipping inactive nodes to reduce computation time [S1]. It sets itself apart from dense reconstruction and Range Analysis (RA) baselines by modeling the INR output as a Gaussian distribution derived from propagated uncertainty, allowing for a "soft" bound that balances extraction speed against the risk of missing iso-surface components [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** An Implicit Neural Representation (INR) defined by a Multi-Layer Perceptron (MLP), a target grid resolution, and a confidence level hyperparameter $t$ [S1].
*   **Output:** A triangle mesh representing the iso-surface, generated only within predicted "active" cells [S1].

**Data Structures:**
*   **INR Model:** An MLP with 8 layers and 32 neurons per layer [S1]. The architecture is not fixed by the method but this configuration is used in the source evaluation [S1].
*   **kd-tree:** A hierarchical spatial partitioning structure where leaf nodes correspond to grid cells at the target resolution [S1].
*   **Active Cell Prediction:** A boolean mask or list of indices indicating which leaf nodes contain the iso-surface [S1].

**Parameters:**
*   **Target Resolution:** The grid resolution for extraction [S1]. Typical values: $256^3$ (vortex, ethanediol), $512^3$ (combustion), $1024^3$ (isotropic) [S1].
*   **Confidence Level ($t$):** A hyperparameter controlling the tightness of the soft bound [S1]. Range tested: 1 to 10 [S1]. Default experimental values: 2, 5, 10 [S1]. Higher $t$ increases extraction time linearly but decreases missed iso-voxels exponentially [S1].
*   **Threshold ($t$):** The source uses $t$ as a threshold controlling uncertainty magnitude [S1]. In the context of the bound calculation, $t$ scales the uncertainty [S1].

**Algorithm Steps:**

1.  **Initialize Hierarchical Traversal:** Start at the root of the kd-tree [S1].
2.  **Uncertainty Estimation (Active Cell Prediction):** For each node in the kd-tree:
    a.  Determine the spatial bounds of the node (min/max coordinates) [S1].
    b.  Propagate the input uncertainty through the INR to estimate the mean $\mu$ and variance $\sigma^2$ of the scalar output over the node's volume [S1].
    c.  Calculate the "soft" bound for the iso-surface threshold $T$ (typically $T=0$ for SDFs, but generalizable) [S1]. The bound is defined as $[\mu - t\sigma, \mu + t\sigma]$ [S1].
    d.  **Decision:** If the interval $[\mu - t\sigma, \mu + t\sigma]$ does not contain the target iso-value $T$, mark the node as **inactive** (skip) [S1]. If it contains $T$, mark as **active** [S1].
    e.  If active and not a leaf, recurse to children [S1]. If active and leaf, add to the list of active cells [S1].
3.  **Network Inference:** For each active leaf cell, perform a standard forward pass of the INR to get the scalar value at the cell center (or necessary points for marching cubes) [S1].
4.  **Mesh Generation:** Apply a parallel Marching Cubes algorithm to the active cells to generate the triangle mesh [S1].

**Formulas:**
*   **Soft Bound:** The predicted range of the INR output $f(x)$ for $x$ in a cell $C$ is approximated as a Gaussian $\mathcal{N}(\mu_C, \sigma_C^2)$ [S1]. The active cell condition is:
    $$ T \in [\mu_C - t \cdot \sigma_C, \mu_C + t \cdot \sigma_C] $$
    where $T$ is the iso-value, $\mu_C$ is the mean output, $\sigma_C$ is the standard deviation, and $t$ is a hyperparameter controlling the tightness of the soft bound [S1].
*   **False Positive Rate (FPR):**
    $$ \text{FPR} = \frac{FP}{FP + TN} $$
*   **False Negative Rate (FNR):**
    $$ \text{FNR} = \frac{FN}{FN + TP} $$
    where $FP$ is false positives (non-active predicted as active), $TN$ is true negatives, $FN$ is false negatives (active predicted as non-active), and $TP$ is true positives [S1].
*   **KL Divergence:** Used to evaluate distribution estimation accuracy:
    $$ D_{KL}(P \| Q) = \int_{-\infty}^{\infty} p(x) \log \frac{p(x)}{q(x)} dx $$
    where $P$ is the true distribution (from Monte Carlo) and $Q$ is the estimated Gaussian [S1].

def predict_active_cells(root_node, t, iso_value):
    """
    Recursively traverse kd-tree to find active cells using uncertainty propagation.
    Fixed bug: Original hardcoded iso_value=0.0 and used undefined helpers, 
    causing failures on non-zero thresholds and missing mesh generation.
    """
    active_cells = []
    
    def traverse(node):
        bounds_min, bounds_max = node.get_bounds()
        
        # Standard first-order uncertainty propagation [G]
        # Computes mean and std dev of INR output over the node's bounding box
        mu, sigma = _propagate_uncertainty(bounds_min, bounds_max)
        
        # Numerical stability guard for sigma
        if sigma < 1e-8:
            sigma = 1e-8
            
        lower_bound = mu - t * sigma
        upper_bound = mu + t * sigma
        
        # Check if iso-value falls within soft bound
        if lower_bound <= iso_value <= upper_bound:
            if node.is_leaf():
                active_cells.append(node)
            else:
                for child in node.children:
                    traverse(child)
        # Else: inactive, skip node
        
    traverse(root_node)
    return active_cells

def extract_mesh(active_cells, inr_func, iso_value):
    """
    Perform Marching Cubes on active cells.
    Implements standard MC lookup [G].
    """
    mesh_vertices = []
    mesh_faces = []
    
    for cell in active_cells:
        corners = cell.get_corners()
        values = jnp.array([inr_func(c) for c in corners])
        
        # Standard Marching Cubes step [G]
        triangles = _standard_marching_cubes(corners, values, iso_value)
        
        mesh_vertices.extend(triangles.vertices)
        mesh_faces.extend(triangles.faces)
        
    return mesh_vertices, mesh_faces

**Edge Cases and Pitfalls:**
*   **Non-Gaussian Distributions:** If the INR output is not Gaussian distributed, the true data distribution may exceed the predicted soft bounds, leading to false negatives (missed iso-surface components) [S1].
*   **Overestimated Variance:** If the predicted variance is much larger than the true variance, it leads to false positives (unnecessary computation) [S1].
*   **Topology Errors:** False negatives can change the topology of the extracted iso-surface, which is critical for geometry analysis but acceptable for visualization [S1].
*   **Network Size:** Active cell prediction error increases with the size of the network (number of parameters), as larger networks are less likely to satisfy Central Limit Theorem (CLT) assumptions required for the Gaussian approximation [S1].

## Operating characteristics
**Time and Memory Complexity:**
*   **Time:** In dense reconstruction, extraction time increases cubically with resolution ($O(N^3)$) [S1]. In UP, extraction time increases quadratically with resolution ($O(N^2)$) because the number of active cells (surface area) is roughly quadratic to the resolution [S1].
*   **Relative Inference Time:** UP is approximately 99.8 times more expensive than a single scalar evaluation of the INR [S1]. This is slower than some Range Analysis (RA) variants (e.g., RA-Fixed at 19.6x) but faster than RA-Full (126.2x) [S1].
*   **Total Time:** UP is consistently faster than dense reconstruction and vanilla RA due to significant skipping of non-active nodes [S1]. Average skipped volume is $7 \times 10^{-4}$, ~20 times that of RA-Full [S1].

**Measured Performance:**
*   **Hardware:** A100 GPU, 16-core 2.3GHz processor [S1].
*   **Accuracy:** Missed cell percentages are very low: 0.000102% on Ethanediol (9/87,966 cells), 0.000010% on Isotropic (231/24,044,239 cells) [S1].
*   **Distribution Fit:** UP has significantly lower KL divergence compared to RA-UA and slightly lower than limited sample baselines, indicating a better fit to the true output distribution [S1].

**Strengths and Limitations:**
*   **Strengths:** High efficiency for large INRs; suitable for fast preview and visualization; lower FPR than RA baselines [S1].
*   **Limitations:** Cannot guarantee correct extraction results (topology errors possible); not suitable for precise geometry or topology analysis; implementation is tied to JAX in the source [S1].
*   **When to Use:** Fast visualization of large INR data [S1].
*   **When Not to Use:** Applications requiring guaranteed topological correctness or precise geometric analysis [S1].

## Background
**Origin:** The method was introduced in the paper "Improving Efficiency of Iso-Surface Extraction on Implicit Neural Representations Using Uncertainty Propagation" [S1].
**History:** It is compared against Range Analysis (RA) and its variants (RA-UA, RA-Full, etc.) and a Monte Carlo baseline (SAMPLE) [S1]. The approach leverages the JAX framework for efficient automatic differentiation and GPU acceleration [S1].
**Usage:** It is positioned as a trade-off between speed and accuracy, prioritizing speed for visualization over the rigorous guarantees of dense or range-analysis-based methods [S1].
