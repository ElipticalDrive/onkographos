# FlexiCubes

Also called: FlexiCubes Surface Extraction with Gradient-Based Optimization, Flexible Isosurface Extraction for Gradient-Based Mesh Optimization

## Overview
FlexiCubes is a differentiable isosurface extraction method that extracts a triangle mesh from a Signed Distance Field (SDF) defined on a voxel grid by optimizing learnable weight parameters within each voxel cube [S1, S2, unofficial]. It is designed specifically for gradient-based mesh optimization, allowing the surface to adapt to geometric, visual, or physical objectives [S2, unofficial]. Unlike standard Marching Cubes which uses fixed lookup tables, FlexiCubes learns local deformation weights (beta, alpha, gamma) to minimize reconstruction error and improve mesh quality, such as reducing floaters and ensuring developability [S2, unofficial]. It builds on [Isosurface extraction](30-isosurface-extraction.md) by replacing the static topology determination with a differentiable, optimization-driven process.

## How it works
**Inputs:**
- Input mesh (OBJ format) or known SDF values.
- Voxel grid resolution $R$ (integer, $4 \le R \le 512$) [S1, unofficial].
- Optimization parameters: learning rate, max iterations, convergence threshold, clamp value, and regularizer weights [S1, S2, unofficial].

**Outputs:**
- Extracted triangle mesh (vertices and faces).
- Optional: Optimized weight tensors and loss values.

**Data Structures:**
1.  **Voxel Grid:** Constructed at resolution $R$. Contains:
    -   `x_nx3`: Vertex positions of shape $(N_v, 3)$, where $N_v = (R+1)^3$.
    -   `cube_fx8`: Cube connectivity of shape $(N_c, 8)$, where $N_c = R^3$, listing the 8 vertex indices for each cube.
2.  **Learnable Parameters:**
    -   `sdf`: Tensor of shape $(N_v,)$, representing SDF values at grid vertices [S2, unofficial].
    -   `deform`: Tensor of shape $(N_v, 3)$, representing vertex displacement offsets [S2, unofficial].
    -   `weight`: Tensor of shape $(N_c, 21)$, split into:
        -   `beta`: Indices 0–11, shape $(N_c, 12)$ [S1, S2, unofficial].
        -   `alpha`: Indices 12–19, shape $(N_c, 8)$ [S1, S2, unofficial].
        -   `gamma`: Index 20, shape $(N_c,)$ [S1, S2, unofficial].
3.  **TriangleMeshDistance (TMD):** A query structure built from the input mesh vertices and faces to compute SDF values [S1, unofficial].

**Steps:**

1.  **Initialization:**
    -   If starting from a mesh: Load OBJ, normalize to unit cube, and compute scale factor [S1, unofficial].
    -   Construct TMD structure from input mesh vertices and faces [S1, unofficial].
    -   Construct voxel grid at resolution $R$ to get `x_nx3` and `cube_fx8` [S1, S2, unofficial].
    -   Initialize `sdf`: If not provided, sample from uniform distribution and subtract 0.1 [S2, unofficial]. If provided, use known SDF [S2, unofficial].
    -   Initialize `deform` to zeros [S2, unofficial].
    -   Initialize `weight` (beta, alpha, gamma) to zeros [S1, S2, unofficial].

2.  **Deformation Calculation:**
    -   Compute deformed grid vertices `grid_verts` using:
        $$ \text{grid\_verts} = \mathbf{x} + \frac{2 - 10^{-8}}{2R} \tanh(\text{deform}) $$
        where $\mathbf{x}$ are the original grid vertex positions `x_nx3` [S2, unofficial]. The factor $(2 - 10^{-8})$ avoids numerical issues at boundaries [S2, unofficial].

3.  **Surface Extraction (Differentiable):**
    -   Call the FlexiCubes extraction function with `grid_verts`, `sdf`, `cube_fx8`, resolution $R$, and weights `beta`, `alpha`, `gamma`.
    -   Set `training=True` to produce 4 triangles per quad for better mesh quality; otherwise, 2 triangles per quad [S1, S2, unofficial].
    -   The function returns the extracted mesh, the Laplacian deviation loss $L_{dev}$, and gradients with respect to the weights [S1, S2, unofficial].

4.  **Loss Computation:**
    -   **SDF Regularization:** Compute mean SDF regularization loss $L_{sdf}$ on grid edges, weighted by `sdf_weight` (default 0.2) [S2, unofficial].
    -   **Laplacian Deviation:** Add $L_{dev}$ weighted by `opt_l_dev_weight` (default 0.5) [S2, unofficial].
    -   **Weight Regularization:** Add L1 regularization on `beta` and `alpha` (indices 0–19), weighted by 0.1 [S2, unofficial].
    -   **Optional SDF Loss:** If optimizing SDF values, sample points on the ground truth mesh, compute MSE between predicted and ground truth SDF, weighted by $2 \times 10^3$ [S2, unofficial].
    -   **Optional Developability:** If enabled, add mesh developability regularization [S2, unofficial].
    -   Total Loss $L = L_{sdf} + L_{dev} + L_{weight\_reg} + \dots$ [S2, unofficial].

5.  **Optimization Loop:**
    -   For each iteration:
        -   Compute gradients of $L$ with respect to `beta`, `alpha`, `gamma` via backpropagation through the extraction step [S1, S2, unofficial].
        -   Update weights using gradient descent (or Adam optimizer with default LR 0.01) [S1, S2, unofficial]:
            $$ \beta \leftarrow \beta - \eta \nabla_\beta L $$
            $$ \alpha \leftarrow \alpha - \eta \nabla_\alpha L $$
            $$ \gamma \leftarrow \gamma - \eta \nabla_\gamma L $$
        -   If `opt_clamp` > 0, clamp weights to $[-\text{opt\_clamp}, \text{opt\_clamp}]$ [S1, S2, unofficial].
        -   Check convergence: If $|\text{prev\_loss} - \text{current\_loss}| < \text{opt\_convergence}$ and iteration > 5, break [S1, S2, unofficial].
        -   Update `prev_loss` [S1, unofficial].

6.  **Final Extraction:**
    -   If optimization is disabled, extract surface directly without gradients [S1, unofficial].
    -   Return final mesh [S1, S2, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def flexicubes_extract(input_mesh_path, resolution, opt_iterations=100, learning_rate=0.01, 
                       opt_convergence=1e-4, opt_clamp=0.0, opt_l_dev_weight=0.5, 
                       sdf_weight=0.2, training=True):
    """
    Extracts mesh from input mesh using FlexiCubes with optional optimization.
    """
    # Step 1: Load and normalize input mesh
    # Assume load_obj returns vertices (V, 3) and faces (F, 3)
    verts, faces = load_obj(input_mesh_path)
    scale, verts = normalize_to_unit_cube(verts)
    
    # Step 2: Build TMD structure (simplified as a function for SDF query)
    tmd = TriangleMeshDistance(verts, faces)
    
    # Step 3: Construct voxel grid
    # grid_verts_init: (R+1)^3, 3)
    # cube_fx8: (R^3, 8)
    grid_verts_init, cube_fx8 = construct_voxel_grid(resolution)
    num_vertices = grid_verts_init.shape[0]
    num_cubes = cube_fx8.shape[0]
    
    # Step 4: Initialize learnable parameters
    sdf = torch.randn(num_vertices, requires_grad=True) - 0.1
    deform = torch.zeros(num_vertices, 3, requires_grad=True)
    weight = torch.zeros(num_cubes, 21, requires_grad=True)
    
    beta = weight[:, :12]
    alpha = weight[:, 12:20]
    gamma = weight[:, 20]
    
    prev_loss = float('inf')
    
    for iter in range(opt_iterations):
        # Step 5: Compute deformed grid vertices
        # Formula: grid_verts = x + (2 - 1e-8) / (2 * R) * tanh(deform)
        grid_verts = grid_verts_init + (2 - 1e-8) / (2 * resolution) * torch.tanh(deform)
        
        # Step 6: Extract surface with gradients
        # Returns: mesh, L_dev, gradients
        # Note: In a real implementation, this calls the C++/CUDA kernel
        mesh, L_dev, grads = fc_extract_surface_with_grads(
            grid_verts, sdf, cube_fx8, resolution,
            beta, alpha, gamma, training=training
        )
        
        # Step 7: Compute losses
        # SDF regularization
        L_sdf = compute_sdf_reg_loss(sdf, grid_verts) * sdf_weight
        
        # Laplacian deviation
        L_dev_term = L_dev.mean() * opt_l_dev_weight
        
        # Weight L1 regularization
        L_weight_reg = weight[:, :20].abs().mean() * 0.1
        
        # Optional: SDF loss against ground truth (if optimizing SDF)
        # L_sdf_gt = compute_sdf_mse_loss(sdf, tmd) * 2000
        
        total_loss = L_sdf + L_dev_term + L_weight_reg # + L_sdf_gt
        
        # Step 8: Backpropagation
        total_loss.backward()
        
        # Step 9: Update weights
        with torch.no_grad():
            beta -= learning_rate * grads.d_beta
            alpha -= learning_rate * grads.d_alpha
            gamma -= learning_rate * grads.d_gamma
            
            if opt_clamp > 0.0:
                beta.clamp_(-opt_clamp, opt_clamp)
                alpha.clamp_(-opt_clamp, opt_clamp)
                gamma.clamp_(-opt_clamp, opt_clamp)
        
        # Step 10: Check convergence
        loss_change = abs(prev_loss - total_loss.item())
        if loss_change < opt_convergence and iter > 5:
            break
        prev_loss = total_loss.item()
        
        # Clear gradients for next iteration
        grads.zero_grad()
        
    # Final extraction without gradients for output
    final_grid_verts = grid_verts_init + (2 - 1e-8) / (2 * resolution) * torch.tanh(deform.detach())
    final_mesh, _, _ = fc_extract_surface_with_grads(
        final_grid_verts, sdf.detach(), cube_fx8, resolution,
        beta.detach(), alpha.detach(), gamma.detach(), training=False
    )
    
    return final_mesh
```

**Parameters:**
-   `resolution`: Voxel grid resolution. Range: $[4, 512]$. Default: 64 [S1, S2, unofficial].
-   `learning_rate`: Adam optimizer learning rate. Default: 0.01 [S2, unofficial].
-   `opt_iterations`: Max optimization iterations [S1, unofficial].
-   `opt_convergence`: Threshold for loss change to stop. [S1, unofficial].
-   `opt_clamp`: Max absolute value for weight clamping. If > 0, weights are clamped to $[-\text{opt\_clamp}, \text{opt\_clamp}]$ [S1, unofficial].
-   `opt_l_dev_weight`: Weight for Laplacian deviation loss. Default: 0.5 [S2, unofficial].
-   `sdf_weight`: Weight for SDF regularization loss. Default: 0.2 [S2, unofficial].
-   `training`: Boolean. If True, produces 4 triangles per quad; if False, 2 triangles per quad [S1, S2, unofficial].

**Edge Cases and Pitfalls:**
-   **Boundary Numerical Issues:** The deformation scaling factor uses $(2 - 10^{-8})$ instead of 2 to avoid numerical instability at the grid boundaries [S2, unofficial].
-   **Resolution Scaling:** FlexiCubes voxel grid with resolution $R$ has $(R+1)^3$ vertices. For comparison with tetrahedral grids (e.g., DMTet), a 4:5 resolution ratio is recommended to match triangle counts (e.g., $64^3$ FlexiCubes $\approx$ $80^3$ DMTet) [S2, unofficial].
-   **Regularization Weights:** Strong regularization can hinder convergence. Start with low weights and incrementally increase if artifacts appear [S2, unofficial].

## Operating characteristics
-   **Time Complexity:** Depends on the number of optimization iterations. Each iteration involves a forward pass through the voxel grid ($O(R^3)$) and a backward pass. The extraction itself is linear in the number of cubes [S1, S2, unofficial].
-   **Memory Complexity:** $O(R^3)$ for the voxel grid and weight tensors. The weight tensor is $(R^3, 21)$, which is significant for high resolutions [S2, unofficial].
-   **Performance:** On a $64^3$ grid, FlexiCubes generates approximately the same number of triangles as an $80^3$ DMTet grid, but with higher computational cost due to the denser vertex count $(R+1)^3$ vs $(R/2+1)^3$ for tets [S2, unofficial].
-   **Strengths:** High-quality mesh output, differentiable, supports complex regularizers (developability, floaters removal), integrates well with gradient-based optimization pipelines [S2, unofficial].
-   **Limitations:** Computationally expensive due to optimization loop, sensitive to regularization weights, requires careful tuning of learning rate and convergence criteria [S2, unofficial].
-   **When to Use:** When optimizing a mesh against visual or geometric objectives (e.g., image-based reconstruction, generative 3D) where differentiability is required [S2, unofficial].
-   **When Not to Use:** When real-time extraction from a fixed SDF is needed without optimization, or when memory is constrained for high-resolution grids [S2, unofficial].

## Background
FlexiCubes was introduced by Tianchang Shen et al. in 2023 in the paper "Flexible Isosurface Extraction for Gradient-Based Mesh Optimization" published in ACM Transactions on Graphics [S2, unofficial]. It was developed by researchers at NVIDIA Research and the University of Toronto [S2, unofficial]. The method builds upon previous work on differentiable surface extraction, such as DMTet, but uses a voxel grid with learnable weights to provide more flexibility and higher quality meshes [S2, unofficial]. It is now used in NVIDIA applications like nvdiffrec and GET3D for photogrammetry and 3D generative pipelines [S2, unofficial].
