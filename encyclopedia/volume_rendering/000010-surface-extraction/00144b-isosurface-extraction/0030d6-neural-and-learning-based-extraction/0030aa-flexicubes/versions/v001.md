# FlexiCubes

Also called: FlexiCubes Surface Extraction with Gradient-Based Optimization, Flexible Isosurface Extraction for Gradient-Based Mesh Optimization

## Overview
FlexiCubes is a high-quality isosurface extraction method designed specifically for gradient-based mesh optimization with respect to geometric, visual, or physical objectives [S2, unofficial]. It extracts a triangle mesh from a Signed Distance Field (SDF) defined on a voxel grid by using learnable cube weights (beta, alpha, gamma) and optional vertex deformations [S1, unofficial]. Unlike static extraction methods, FlexiCubes allows the topology and geometry to be refined via backpropagation, making it suitable for differentiable rendering pipelines [S2, unofficial]. It sets itself apart from siblings like [MISE](977-mise-meshing-isosurfaces-by-extracting.md) by providing a differentiable, weight-optimized representation that can be directly integrated into optimization loops for generative 3D tasks [S2, unofficial].

## How it works
**Inputs:**
- Input mesh (OBJ format) or ground truth SDF.
- Voxel grid resolution $R$ (integer, $4 \le R \le 512$) [S1, unofficial].
- Optimization parameters: learning rate, max iterations, convergence threshold, clamp limits, regularization weights [S1, unofficial].

**Outputs:**
- Extracted triangle mesh (vertices and faces).
- Optional optimized weights and SDF values.

**Data Structures:**
1. **Voxel Grid:** Constructed via `fc.construct_voxel_grid(R)`.
   - `x_nx3`: Vertex positions of shape $(N, 3)$, where $N = (R+1)^3$.
   - `cube_fx8`: Cube connectivity of shape $(F, 8)$, where $F = R^3$, listing the 8 vertex indices for each cube.
2. **TriangleMeshDistance (TMD):** A query structure built from flat arrays of input mesh vertices and faces for SDF computation [S1, unofficial].
3. **Learnable Parameters:**
   - `sdf`: Tensor of shape $(N,)$ representing SDF values at grid vertices [S2, unofficial].
   - `deform`: Tensor of shape $(N, 3)$ representing vertex displacements [S2, unofficial].
   - `weight`: Tensor of shape $(F, 21)$ containing cube weights [S2, unofficial].
     - `beta`: Indices $0-11$, shape $(F, 12)$ [S1, unofficial].
     - `alpha`: Indices $12-19$, shape $(F, 8)$ [S1, unofficial].
     - `gamma`: Index $20$, shape $(F,)$ [S1, unofficial].

**Algorithm Steps:**

1. **Initialization:**
   - If optimizing from a mesh: Load OBJ mesh, normalize to unit cube, and compute scale factor [S1, unofficial].
   - Flatten mesh vertices and faces for TMD construction [S1, unofficial].
   - Construct TMD structure [S1, unofficial].
   - Construct voxel grid with resolution $R$ [S1, unofficial].
   - Compute initial SDF values at grid vertices by querying TMD: $SDF_i = \text{TMD.signed\_distance}(x_i)$ [S1, unofficial].
   - If optimizing from scratch (no input mesh): Initialize `sdf` by sampling from a uniform distribution and subtracting 0.1 [S2, unofficial].
   - Initialize `weight` tensor to zeros [S2, unofficial].
   - Initialize `deform` tensor to zeros [S2, unofficial].

2. **Deformation Calculation:**
   - Compute deformed grid vertices $V'$ using the formula:
     $$ V' = x + \frac{2 - 10^{-8}}{2R} \tanh(\text{deform}) $$
     The factor $(2 - 10^{-8})$ avoids numerical issues at the boundary [S2, unofficial].

3. **Surface Extraction with Gradients:**
   - Call `fc.extract_surface_with_grads(V', sdf, cube_fx8, R, beta, alpha, gamma, training=True)`.
   - This returns the extracted mesh, the deviation loss $L_{dev}$, and gradients for `beta`, `alpha`, `gamma`, `sdf`, and `deform` [S1, unofficial][S2, unofficial].
   - `training=True` ensures 4 triangles per quad for better mesh quality; `False` yields 2 [S1, unofficial].

4. **Loss Computation:**
   - **SDF Regularization:** $L_{sdf} = \text{mean}(L_{sdf\_reg}(sdf, \text{grid\_edges})) \times w_{sdf}$ [S2, unofficial]. Default $w_{sdf} = 0.2$ [S2, unofficial].
   - **Deviation Loss:** $L_{dev\_mean} = \text{mean}(L_{dev})$ [S2, unofficial].
   - **Weight Regularization:** $L_{weight\_L1} = \text{mean}(|\text{weight}[:, :20]|) \times 0.1$ [S2, unofficial].
   - **Developability Regularization (Optional):** If enabled, add mesh developable regularization, deform L1, and weight L1 terms [S2, unofficial].
   - **SDF Loss (Optional):** If ground truth SDF is available, sample points on the mesh, compute GT SDF, and add MSE loss $\times 2000$ [S2, unofficial].
   - **Total Loss:** $L_{total} = L_{sdf} + L_{dev\_mean} \times 0.5 + L_{weight\_L1} + \dots$ [S2, unofficial].

5. **Optimization Loop:**
   - Update parameters using gradient descent (e.g., Adam with LR 0.01) [S2, unofficial].
   - Clamp weights if `opt_clamp > 0`: $\text{weight} = \text{clamp}(\text{weight}, -\text{opt\_clamp}, \text{opt\_clamp})$ [S1, unofficial].
   - Repeat extraction and loss computation.
   - Convergence check: Break if $|\text{prev\_loss} - \text{current\_loss}| < \text{opt\_convergence}$ and iteration $> 5$ [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def flexicubes_extract_and_optimize(
    input_mesh_path=None,
    resolution=64,
    opt_iterations=100,
    opt_lr=0.01,
    opt_convergence=1e-4,
    opt_clamp=0.0,
    sdf_weight=0.2,
    l_dev_weight=0.0,
    training_mode=True
):
    # 1. Initialization
    if input_mesh_path:
        # Load and normalize mesh to unit cube
        verts, faces = load_obj(input_mesh_path)
        verts, scale = normalize_to_unit_cube(verts)
        # Build TMD structure (pseudo-code for external library)
        tmd = build_triangle_mesh_distance(verts, faces)
        # Compute SDF at grid vertices
        grid_verts_base = construct_voxel_grid_vertices(resolution)
        sdf = torch.zeros(grid_verts_base.shape[0])
        for i in range(grid_verts_base.shape[0]):
            sdf[i] = tmd.signed_distance(grid_verts_base[i])
    else:
        # Random initialization
        grid_verts_base = construct_voxel_grid_vertices(resolution)
        sdf = torch.rand(grid_verts_base.shape[0]) - 0.1
    
    # Construct cube connectivity
    cube_fx8 = construct_voxel_grid_cubes(resolution)
    num_cubes = cube_fx8.shape[0]
    num_verts = grid_verts_base.shape[0]
    
    # Initialize learnable parameters
    weight = torch.zeros(num_cubes, 21, requires_grad=True)
    deform = torch.zeros(num_verts, 3, requires_grad=True)
    
    # 2. Optimization Loop
    prev_loss = float('inf')
    
    for iter in range(opt_iterations):
        # Compute deformed vertices
        # Formula: grid_verts = x + (2-1e-8) / (R * 2) * tanh(deform)
        scale_factor = (2.0 - 1e-8) / (resolution * 2)
        grid_verts = grid_verts_base + scale_factor * torch.tanh(deform)
        
        # Extract surface with gradients
        # Returns: mesh_vertices, mesh_faces, L_dev, gradients
        mesh_v, mesh_f, L_dev, grads = flexicubes_extract_with_grads(
            grid_verts, sdf, cube_fx8, resolution,
            beta=weight[:, :12],
            alpha=weight[:, 12:20],
            gamma=weight[:, 20],
            training=training_mode
        )
        
        # Compute Losses
        # SDF Regularization (pseudo-code for specific reg function)
        grid_edges = compute_grid_edges(resolution)
        reg_loss_sdf = sdf_reg_loss(sdf, grid_edges).mean() * sdf_weight
        
        # Deviation Loss
        reg_loss_dev = L_dev.mean() * 0.5
        
        # Weight L1 Regularization
        reg_loss_weight = weight[:, :20].abs().mean() * 0.1
        
        total_loss = reg_loss_sdf + reg_loss_dev + reg_loss_weight
        
        # Backpropagation
        total_loss.backward()
        
        # Update weights
        with torch.no_grad():
            weight -= opt_lr * weight.grad
            deform -= opt_lr * deform.grad
            sdf -= opt_lr * sdf.grad
            
            # Zero gradients
            weight.grad.zero_()
            deform.grad.zero_()
            sdf.grad.zero_()
            
            # Clamp weights if enabled
            if opt_clamp > 0.0:
                weight.clamp_(-opt_clamp, opt_clamp)
        
        # Convergence Check
        loss_change = abs(prev_loss - total_loss.item())
        if loss_change < opt_convergence and iter > 5:
            break
        prev_loss = total_loss.item()
        
    return mesh_v, mesh_f
```

## Subtopics

### DMTet Comparison
FlexiCubes uses a voxel grid $(R+1)^3$ vertices, whereas DMTet uses a tetrahedral grid with $(R/2+1)^3$ vertices for the same edge length $1/R$. To match triangle counts, a 4:5 resolution ratio is recommended (e.g., $64^3$ FlexiCubes $\approx$ $80^3$ DMTet) [S2, unofficial].

### Regularization Strategies
Common regularizers include floaters removal (SDF reg), flat area smoothing (L_dev), and fabricability (developability) [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Dominated by the iterative optimization loop. Each iteration involves SDF queries (if from mesh), voxel grid construction, and differentiable surface extraction. Complexity scales with $O(R^3)$ for grid operations and optimization steps [S1, unofficial][S2, unofficial].
- **Memory Complexity:** $O(R^3)$ for storing grid vertices, cubes, and learnable parameters (SDF, deform, weights) [S1, unofficial].
- **Performance:** Higher resolution yields higher quality but increases computational cost significantly. Switching from DMTet to FlexiCubes at the same resolution results in denser output meshes and higher cost [S2, unofficial].
- **Strengths:** High-quality mesh output, differentiable, supports complex regularization, robust to non-manifold inputs via TMD [S2, unofficial].
- **Limitations:** Computationally expensive due to iterative optimization; requires careful tuning of regularization weights to avoid artifacts or hindered convergence [S2, unofficial].
- **When to Use:** Gradient-based 3D generation, shape optimization, differentiable rendering pipelines [S2, unofficial].
- **When Not to Use:** Real-time static extraction without optimization needs; scenarios requiring minimal memory footprint [S2, unofficial].

## Background
FlexiCubes was introduced by Tianchang Shen et al. in 2023, published in ACM Transactions on Graphics [S2, unofficial]. It was developed as a flexible isosurface extraction method for gradient-based mesh optimization, building upon previous work like DMTet [S2, unofficial]. It is used in NVIDIA applications such as nvdiffrec and GET3D for photogrammetry and generative AI [S2, unofficial].
