# MISE (Meshing Isosurfaces by Extracting)
Also called: DVR Mesh Generation via MISE, Meshing Isosurfaces by Extracting

## Overview
MISE generates a 3D mesh from a trained Differentiable Volumetric Rendering (DVR) model by querying an implicit occupancy field using an adaptive resolution strategy [S1, unofficial]. It avoids the computational cost of evaluating the field on a uniform high-resolution grid [S1, unofficial].

## How it works
**Inputs:**
- A trained DVR model $f: \mathbb{R}^3 \rightarrow \mathbb{R}$ [S1, unofficial].
- A bounding box defining the spatial domain [G].
- Parameters: `threshold`, `resolution0`, `upsampling_steps`, `padding`, `points_batch_size` [S1, unofficial].

**Outputs:**
- A 3D mesh extracted via marching cubes on a dense grid [S1, unofficial].

**Data Structures:**
- `points`: A tensor of shape $(N, 3)$ containing 3D coordinates [S1, unofficial].
- `values`: A tensor of shape $(N, 1)$ containing model outputs (logits) [S1, unofficial].
- MISE hierarchy structure managing active points and grid levels [S1, unofficial].

**Steps:**
1. **Threshold Conversion:** Convert the float occupancy threshold $t$ to log-odds space for the model output:
   $$ t_{\text{logit}} = \ln(t) - \ln(1 - t) $$
   [S1, unofficial]

2. **Initialization:**
   - If `upsampling_steps` is 0: generate a uniform grid of points using `make_3d_grid` with resolution $n_x = \text{resolution0}$, evaluate them, and reshape to a 3D grid [S1, unofficial].
   - If `upsampling_steps` > 0: initialize the MISE extractor with `resolution0`, `upsampling_steps`, and $t_{\text{logit}}$ [S1, unofficial].

3. **Adaptive Querying Loop:**
   - Query points from the MISE extractor: `points = mesh_extractor.query()` [S1, unofficial].
   - While `points.shape[0] != 0`: normalize `points` to the bounding box coordinates, evaluate the model in batches of size `points_batch_size`, update the MISE structure with the evaluated values, and query the next set of points [S1, unofficial].

4. **Densification:**
   - Convert the MISE structure to a dense 3D grid using `mesh_extractor.to_dense()` [S1, unofficial].
   - Apply marching cubes on the dense grid using the original float threshold $t$ [S1, unofficial].

**Parameters:**
- `threshold`: Occupancy threshold for marching cubes. Default: 0.5 [S1, unofficial].
- `resolution0`: Starting resolution for MISE. Default: 16 [S1, unofficial].
- `upsampling_steps`: Number of upsampling steps. Default: 3 [S1, unofficial].
- `padding`: Padding added to the bounding box size. Default: 0.1 [S1, unofficial].
- `points_batch_size`: Batch size for point evaluation. Default: 100000 [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Sub-linear in the volume of the domain, as it only queries points near the isosurface [G]. Complexity depends on the number of active points in the MISE hierarchy [G].
- **Memory Complexity:** Proportional to the number of points queried and the final dense grid size [G]. The dense grid size is determined by the final resolution after upsampling steps [G].
- **Strengths:** Adaptive resolution, efficient memory usage for complex shapes [G].
- **Limitations:** Requires iterative querying, which may be slower for simple shapes compared to uniform grid methods [G]. Sensitive to the choice of `resolution0` and `upsampling_steps` [G].
- **When to use:** When extracting high-fidelity meshes from neural implicit representations where uniform grid evaluation is too expensive [S1, unofficial].
- **When not to use:** For simple shapes where a low-resolution uniform grid suffices, or when real-time extraction is required and the overhead of adaptive querying is prohibitive [G].

## Background
MISE was introduced in the context of Differentiable Volumetric Rendering (DVR) for neural implicit surface reconstruction [S1, unofficial]. It provides a method to efficiently extract meshes from the learned occupancy fields without the computational cost of evaluating the field on a dense uniform grid [S1, unofficial]. The method leverages the hierarchical nature of the MISE algorithm to focus computation on regions of interest near the isosurface [S1, unofficial].
