# NDC Ground Truth LOD Generation via Least-Squares Plane Fitting

Also called: LOD ground truth computation

## Overview
This method generates multi-resolution ground truth data for training Neural Distance Fields (NDC) by fitting planes to surface intersection points within grid cells. It solves the problem of creating accurate per-cell labels (signs and plane parameters) from high-resolution voxel and intersection data, which are then used to train a CNN to predict Marching Cubes configurations. It differs from gradient-based methods by explicitly using computed intersection points and their normals for least-squares fitting [S1, unofficial].

## How it works
**Inputs:**
1.  Object file (`.obj`).
2.  External executables: `VOXGen`, `SDFGen`, `IntersectionXYZpn`.
3.  Configuration parameters: `grid_size_list` (e.g., `[32, 64]`), `cell_voxel_size` (8.0).

**Outputs:**
HDF5 file containing datasets for each `grid_size` in `grid_size_list`:
*   `{grid_size}_int`: Shape `[grid_size+1, grid_size+1, grid_size+1, 1]`, `np.uint8`. Stores the sign grid.
*   `{grid_size}_float`: Shape `[grid_size+1, grid_size+1, grid_size+1, 3]`, `np.float32`. Stores plane fitting results (initialized to -10.0).
*   `{grid_size}_sdf`: Shape `[grid_size+1, grid_size+1, grid_size+1]`, `np.float32`. Downsampled SDF.
*   `{grid_size}_voxel`: Shape `[grid_size+1, grid_size+1, grid_size+1]`, `np.uint8`. Downsampled voxels.

**Data Structures:**
*   `reference_V`: Buffer storing intersection points and normals for a cell. Layout: `[N, 6]`, where columns 0-2 are positions $(X, Y, Z)$ and columns 3-5 are normals $(n_x, n_y, n_z)$.
*   `LOD_gt_int`: Integer array for sign bits.
*   `LOD_gt_float`: Float array for plane parameters.

**Steps:**

1.  **Initialize Output Arrays:**
    Create `LOD_gt_int` and `LOD_gt_float` with shape `[grid_size+1, grid_size+1, grid_size+1, num_params]` for each `grid_size`. Initialize `LOD_gt_float` with -10.0.

2.  **Generate Raw Data:**
    For each object, run:
    *   `./VOXGen <obj> 1024 0` -> Generates 1025x1025x1025 voxel grid.
    *   `./SDFGen <obj> 128 0` -> Generates 129x129x129 SDF grid.
    *   `./IntersectionXYZpn <obj> 128 0` -> Generates intersection points (X, Y, Z planes) with normals.

3.  **Read Input Data:**
    Load the SDF (129x129x129), Intersection points, and Voxels (1025x1025x1025).

4.  **Downsample for Target Resolution:**
    For each `grid_size` in `grid_size_list`:
    a.  Calculate downscale factor:
        $$ downscale = 1024 // (grid\_size \times cell\_voxel\_size) $$
        Note: `cell_voxel_size` is 8.
    b.  **Downsample Voxels:** Sample `voxel_1025` at stride `downscale`.
    c.  **Downsample SDF:** Sample `sdf_129` at stride `downscale`.
    d.  **Downsample Intersections:** Filter intersection points where coordinates are multiples of `downscale`. Divide coordinates by `downscale`.

5.  **Compute Input Voxel Grid:**
    Use `cutils.get_input_voxel` to compute the input voxel grid for the target `grid_size`.

6.  **Organize Intersections:**
    Use `cutils.get_intersection_points_normals_in_cells` to organize downsampled intersection points into a cell-based data structure, creating pointers and data arrays.

7.  **Compute Sign Grid:**
    $$ tmp\_sign = (tmp\_sdf \le 0).astype(np.uint8) $$
    Store `tmp_sign` in `LOD_gt_int`.

8.  **Iterate Over Grid Cells:**
    For each cell $(i, j, k)$ from $0$ to $grid\_size-1$:
    a.  **Check Surface Intersection:**
        Check the 2x2x2 corner signs:
        $$ max\_sign = \max(tmp\_sign[i:i+2, j:j+2, k:k+2]) $$
        $$ min\_sign = \min(tmp\_sign[i:i+2, j:j+2, k:k+2]) $$
        If $max\_sign \neq min\_sign$, the cell intersects the surface. Proceed to plane fitting. Otherwise, skip.
    b.  **Retrieve Points:**
        Use `cutils.retrieve_intersection_points_normals_from_cells` to get intersection points and normals into `reference_V`.
    c.  **Handle Empty Cells:**
        If `reference_V` is empty (length 0), skip the cell.
    d.  **Construct Linear System:**
        Construct $A$ and $b$ for least-squares plane fitting:
        $$ A = reference\_V[:, 3:6] $$
        $$ b = reference\_V[:, 3:6] \times reference\_V[:, 0:3] $$
        (Element-wise multiplication of normals and positions).
    e.  **Regularization:**
        Initialize `reg_scale = 1e-6`.
        Calculate `reg_pos` as the mean position of intersection points.
        Add regularization rows to $A$ and $b$ to avoid singular matrices.
    f.  **Solve Least Squares:**
        $$ x = \text{lstsq}(A, b)[0] $$
    g.  **Boundary Adjustment:**
        If any component of $x$ is outside $[0, 1]$:
        i.  Initialize `tmp_scale = 1`.
        ii. While $x$ is out of bounds:
            *   Increase `reg_scale` by `tmp_scale`.
            *   Recompute $A$ and $b$ with new `reg_scale`.
            *   Solve for $x$.
            *   If `reg_scale > 1000`, break and reset `reg_scale = 1e-6`.
        iii. If still out of bounds:
            *   Loop 10 times:
                *   Decrease `reg_scale` by `tmp_scale / 2`.
                *   Recompute $A$ and $b$.
                *   Solve for $x$.
            *   If still out of bounds, perform one final solve with current `reg_scale`.
    h.  **Store Result:**
        Store $x$ into `LOD_gt_float[i, j, k]`.

9.  **Save Data:**
    Save all generated arrays to an HDF5 file with the specified dataset names and shapes.

**Pseudocode:**

```python
import numpy as np
import h5py
import subprocess
import os

def generate_ndc_gt(obj_path, grid_size_list, cell_voxel_size=8.0, output_hdf5_path="output.hdf5"):
    # Step 2: Generate raw data
    subprocess.run(['./VOXGen', obj_path, '1024', '0'])
    subprocess.run(['./SDFGen', obj_path, '128', '0'])
    subprocess.run(['./IntersectionXYZpn', obj_path, '128', '0'])
    
    # Step 3: Read input data
    # Assuming helper functions exist to read the generated files
    sdf_129 = read_sdf('SDFGen_output.dat')  # Shape (129, 129, 129)
    voxels_1025 = read_voxels('VOXGen_output.dat')  # Shape (1025, 1025, 1025)
    intersections = read_intersections('IntersectionXYZpn_output.dat')  # List of points with normals
    
    with h5py.File(output_hdf5_path, 'w') as f:
        for grid_size in grid_size_list:
            # Step 4: Downsample
            downscale = 1024 // (grid_size * cell_voxel_size)
            
            # Downsample voxels
            voxels_ds = voxels_1025[::downscale, ::downscale, ::downscale]
            
            # Downsample SDF
            sdf_ds = sdf_129[::downscale, ::downscale, ::downscale]
            
            # Downsample intersections
            # Filter points where coordinates are multiples of downscale
            valid_mask = (intersections[:, 0] % downscale == 0) & \
                         (intersections[:, 1] % downscale == 0) & \
                         (intersections[:, 2] % downscale == 0)
            intersections_ds = intersections[valid_mask] / downscale
            
            # Step 5: Compute input voxel grid (placeholder for cutils.get_input_voxel)
            input_voxel = get_input_voxel(grid_size, voxels_ds)
            
            # Step 6: Organize intersections into cells (placeholder for cutils.get_intersection_points_normals_in_cells)
            cell_intersections = get_intersection_points_normals_in_cells(intersections_ds, grid_size)
            
            # Step 7: Compute sign grid
            tmp_sign = (sdf_ds <= 0).astype(np.uint8)
            
            # Initialize output arrays
            # LOD_gt_int: [grid_size+1, grid_size+1, grid_size+1, 1]
            lod_gt_int = np.zeros((grid_size + 1, grid_size + 1, grid_size + 1, 1), dtype=np.uint8)
            lod_gt_int[:, :, :, 0] = tmp_sign
            
            # LOD_gt_float: [grid_size+1, grid_size+1, grid_size+1, 3]
            lod_gt_float = np.full((grid_size + 1, grid_size + 1, grid_size + 1, 3), -10.0, dtype=np.float32)
            
            # Step 8: Iterate over cells
            for i in range(grid_size):
                for j in range(grid_size):
                    for k in range(grid_size):
                        # Check surface intersection
                        corner_signs = tmp_sign[i:i+2, j:j+2, k:k+2]
                        if np.max(corner_signs) != np.min(corner_signs):
                            # Retrieve points for this cell
                            ref_v = cell_intersections.get_cell_points(i, j, k)
                            
                            if ref_v is None or len(ref_v) == 0:
                                continue
                            
                            # Construct linear system
                            A = ref_v[:, 3:6]  # Normals
                            b = A * ref_v[:, 0:3]  # Dot product of normals and positions
                            
                            reg_scale = 1e-6
                            reg_pos = np.mean(ref_v[:, 0:3], axis=0)
                            
                            # Solve least squares
                            x = solve_least_squares(A, b, reg_scale, reg_pos)
                            
                            # Boundary adjustment
                            if not np.all((x >= 0) & (x <= 1)):
                                tmp_scale = 1.0
                                while not np.all((x >= 0) & (x <= 1)):
                                    reg_scale += tmp_scale
                                    if reg_scale > 1000:
                                        reg_scale = 1e-6
                                        break
                                    x = solve_least_squares(A, b, reg_scale, reg_pos)
                                
                                if not np.all((x >= 0) & (x <= 1)):
                                    for _ in range(10):
                                        reg_scale -= tmp_scale / 2
                                        x = solve_least_squares(A, b, reg_scale, reg_pos)
                                    x = solve_least_squares(A, b, reg_scale, reg_pos)
                            
                            lod_gt_float[i, j, k] = x
            
            # Save datasets
            f.create_dataset(f'{grid_size}_int', data=lod_gt_int)
            f.create_dataset(f'{grid_size}_float', data=lod_gt_float)
            f.create_dataset(f'{grid_size}_sdf', data=sdf_ds)
            f.create_dataset(f'{grid_size}_voxel', data=voxels_ds)

def solve_least_squares(A, b, reg_scale, reg_pos):
    # Add regularization rows to A and b
    # This is a placeholder for the specific regularization implementation
    # Typically involves adding rows like [reg_scale, 0, 0] to A and [reg_scale * reg_pos[0]] to b
    A_reg = np.vstack([A, np.eye(3) * reg_scale])
    b_reg = np.concatenate([b, reg_pos * reg_scale])
    
    # Solve using numpy least squares
    x, _, _, _ = np.linalg.lstsq(A_reg, b_reg, rcond=None)
    return x
```

## Operating characteristics
*   **Time Complexity:** Dominated by the iteration over all grid cells and the least-squares solve for each surface-intersecting cell. The number of cells is $O(grid\_size^3)$. The least-squares solve is $O(N)$ where $N$ is the number of intersection points per cell, which is typically small.
*   **Memory Complexity:** $O(grid\_size^3)$ for storing the ground truth arrays. The HDF5 file size scales with the number of grid resolutions and the object count.
*   **Strengths:** Provides explicit geometric ground truth (plane parameters) which is robust for training CNNs to predict Marching Cubes configurations. Handles multi-resolution LODs efficiently.
*   **Limitations:** Relies on external executables for SDF and intersection generation. The regularization and boundary adjustment loop can be computationally expensive if many cells have ill-conditioned intersection sets.
*   **When to use:** When training Neural Distance Fields that require explicit plane fitting ground truth for surface representation.
*   **When not to use:** When real-time generation is required, or when the external executables are not available.

## Background
This method is part of the Neural Distance Fields (NDC) framework, specifically designed to generate training data for CNNs that predict Marching Cubes configurations. It was introduced in the context of the NDC project [S1, unofficial]. The method uses explicit intersection points and normals for plane fitting, distinguishing it from methods that might use SDF gradients directly.
