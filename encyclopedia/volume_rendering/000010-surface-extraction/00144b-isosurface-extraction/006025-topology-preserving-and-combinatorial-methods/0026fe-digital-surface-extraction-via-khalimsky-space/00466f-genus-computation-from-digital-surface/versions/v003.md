# Genus Computation from Digital Surface


## Overview
This method computes the genus $g$ of a digital surface $\partial O_\alpha$, which is a 2-manifold without boundary derived from a Majority Interpolation (MI) reconstruction [S1, unofficial]. It calculates the topological invariant directly from local neighbor counts of surface points, avoiding global connectivity analysis [S1, unofficial]. It differs from general mesh-based genus algorithms by relying on the combinatorial properties of the Khalimsky space and the manifold guarantee of the MI reconstruction [S1, unofficial].

## How it works
**Inputs:**
- A digital surface $\partial O_\alpha$, which is a 2-manifold without boundary, extracted from a scalar field using Majority Interpolation with threshold $\alpha$ [S1, unofficial].
- The set of surface points constituting $\partial O_\alpha$ [S1, unofficial].

**Outputs:**
- The genus $g$, an integer topological invariant representing the number of handles of the surface [S1, unofficial].

**Data Structures:**
- The digital surface is represented as a set of points in the Khalimsky grid graph $G'$ [G].
- Each point $s \in \partial O_\alpha$ maintains a count of its neighbors within the surface set [S1, unofficial].

**Steps:**
1. Identify the set of surface points $\partial O_\alpha$ [S1, unofficial].
2. For each point $s \in \partial O_\alpha$, count the number of its neighbors that are also in $\partial O_\alpha$ [S1, unofficial].
3. Aggregate the counts into three buckets: $|N_3|$ (points with exactly 3 neighbors), $|N_5|$ (points with exactly 5 neighbors), and $|N_6|$ (points with exactly 6 neighbors) [S1, unofficial].
4. Compute the genus using the formula: $g = 1 + (|N_5| + 2|N_6| - |N_3|)/8$ [S1, unofficial].
5. Return $g$ [S1, unofficial].

**Pseudocode:**
```python
def compute_genus(surface_points):
    """Computes the genus of a digital surface derived from Majority Interpolation."""
    count_3 = 0
    count_5 = 0
    count_6 = 0
    for s in surface_points:
        # Count neighbors of s within the surface set.
        # The exact adjacency rule follows the Khalimsky topology defined in the parent article.
        neighbor_count = 0
        for dx in (-1, 0, 1):
            for dy in (-1, 0, 1):
                for dz in (-1, 0, 1):
                    if dx == 0 and dy == 0 and dz == 0:
                        continue
                    neighbor = (s[0] + dx, s[1] + dy, s[2] + dz)
                    if neighbor in surface_points:
                        neighbor_count += 1
        if neighbor_count == 3:
            count_3 += 1
        elif neighbor_count == 5:
            count_5 += 1
        elif neighbor_count == 6:
            count_6 += 1
    numerator = count_5 + 2 * count_6 - count_3
    genus = 1 + numerator // 8
    return genus
```

**Parameters:**
- $|N_i|$: The number of surface points in $\partial O_\alpha$ that have exactly $i$ neighbors [S1, unofficial].
- $g$: The surface genus [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Non-manifold configurations:** The formula assumes $\partial O_\alpha$ is a 2-manifold without boundary [S1, unofficial].
- **Precision:** The result $g$ must be an integer; the numerator is always divisible by 8 for valid manifolds [G].
- **Disconnected components:** The formula computes the genus for the entire surface [S1, unofficial]. If the surface consists of multiple disconnected components, the result represents the sum of the genera of all components [S1, unofficial]. To compute per-component invariants, one must first isolate connected components of $O_\alpha$ and apply the formula to each [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of surface points, as each point is visited once to count neighbors [G].
- **Memory Complexity:** $O(N)$ to store the surface points and their neighbor counts [G].
- **Strengths:** Extremely fast and simple to implement [G]. Does not require mesh traversal or complex topological data structures [G].
- **Limitations:** Only computes the genus and does not provide information about the location of topological errors [S1, unofficial]. Assumes the surface is a valid 2-manifold [S1, unofficial].
- **When to use:** When a quick topological invariant check is needed for MI-reconstructed surfaces [S1, unofficial].
- **When not to use:** When detailed topological error localization is required (use Topology Verification using Digital Surfaces instead) [S1, unofficial].

## Background
The method was proposed by Chen and Rong [5] as a direct formula for computing the genus of digital surfaces derived from Majority Interpolation [S1, unofficial]. The boundary $\partial O_\alpha$ of the MI reconstruction $O_\alpha$ is guaranteed to be a 2-manifold, which allows for the application of this specific combinatorial formula [S1, unofficial]. This method is part of the broader effort to provide rigorous topological guarantees for isosurface extraction in digital volumes [S1, unofficial].
