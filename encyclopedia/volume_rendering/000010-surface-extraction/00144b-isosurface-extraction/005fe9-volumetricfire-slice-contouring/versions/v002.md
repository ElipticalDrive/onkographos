# VolumetricFire Slice Contouring

Also called: Slice-based contouring, active edge list contouring, VolumetricFire contouring

## Overview
VolumetricFire Slice Contouring is a slice-based contouring algorithm that extracts isosurfaces from volumetric data by processing slices sequentially [S1, unofficial]. It maintains an active edge list and handles topology changes via split and merge operations to generate triangle fans for each slice [S1, unofficial]. It is used in the VolumetricFire class for rendering volumetric fire effects [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Corner positions (`posCorners`), corner texture coordinates (`texCorners`), corner distances (`cornerDistance`), slice spacing (`sliceSpacing`), minimum distance (`minDistance`), maximum corner index (`maxCorner`), corner neighbor indices (`cornerNeighbors`), and incoming edge mappings (`incomingEdges`) [S1, unofficial].
*   **Output:** Buffers of vertex positions (`points`), texture coordinates (`texCoords`), and triangle indices (`indexes`) [S1, unofficial].

**Data Structures:**
*   **Active Edge (`activeEdge`):** An object with the following fields:
    *   `expired`: Boolean, indicates if the edge is no longer active [S1, unofficial].
    *   `startIndex`: Number, index of the starting corner [S1, unofficial].
    *   `endIndex`: Number, index of the ending corner [S1, unofficial].
    *   `deltaPos`: Vector3, position increment per slice [S1, unofficial].
    *   `deltaTex`: Vector3, texture coordinate increment per slice [S1, unofficial].
    *   `pos`: Vector3, current position of the edge intersection [S1, unofficial].
    *   `tex`: Vector3, current texture coordinate of the edge intersection [S1, unofficial].
    *   `cur`: Number, index in the `activeEdges` array [S1, unofficial].
    *   `prev`: Number, index of the previous edge in the linked list [S1, unofficial].
    *   `next`: Number, index of the next edge in the linked list [S1, unofficial].
*   **Active Edges Array (`activeEdges`):** A fixed-size array (capacity 12) storing references to `activeEdge` objects [S1, unofficial].
*   **Priority Queue (`expirations`):** Stores edges with their expiration priority (`cornerDistance[endIndex]`) [S1, unofficial].

**Algorithm Steps:**

1.  **Initialization:**
    *   Initialize `firstEdge` to 0, `edgeIdx` to 0, and `expirations` as an empty priority queue [S1, unofficial].
    *   For each of the 3 corner neighbors of `maxCorner` (indexed `i` from 0 to 2):
        *   Call `createEdge(maxCorner, cornerNeighbors[maxCorner][i])` to generate an initial edge [S1, unofficial].
        *   Set `activeEdge.prev = (i + 2) % 3` and `activeEdge.next = (i + 1) % 3` to form the initial linked list cycle [S1, unofficial].

2.  **Slice Iteration:**
    *   Initialize `sliceDistance` to `maxCorner` [G].
    *   Iterate while `sliceDistance > minDistance` [S1, unofficial].

3.  **Edge Expiration and Topology Management:**
    *   While `expirations` is not empty and `expirations.top().priority >= sliceDistance`:
        *   Pop the edge `edge` from `expirations` [S1, unofficial].
        *   If `edge.expired` is true, continue to the next iteration [S1, unofficial].
        *   Check if `edge.endIndex` differs from both `activeEdges[edge.prev].endIndex` and `activeEdges[edge.next].endIndex` [S1, unofficial]:
            *   **Split:** If different, the edge must split.
                *   Mark `edge.expired = true` [S1, unofficial].
                *   Create `activeEdge1` using `createEdge(edge.endIndex, incomingEdges[edge.endIndex][edge.startIndex])` [S1, unofficial].
                *   Set `activeEdge1.prev = edge.prev` and update `activeEdges[edge.prev].next = edgeIdx - 1` [S1, unofficial].
                *   Set `activeEdge1.next = edgeIdx` [S1, unofficial].
                *   Create `activeEdge2` using `createEdge(edge.endIndex, incomingEdges[edge.endIndex][activeEdge1.endIndex])` [S1, unofficial].
                *   Set `activeEdge2.prev = edgeIdx - 2` and `activeEdge2.next = edge.next` [S1, unofficial].
                *   Update `activeEdges[activeEdge2.next].prev = edgeIdx - 1` [S1, unofficial].
                *   Set `firstEdge = edgeIdx - 1` [S1, unofficial].
            *   **Merge:** If `edge.endIndex` matches either neighbor's `endIndex`:
                *   Identify `prev` and `next` edges to be merged based on which neighbor matches [S1, unofficial].
                *   Mark both `prev.expired = true` and `next.expired = true` [S1, unofficial].
                *   Create a new `activeEdge` using `createEdge(edge.endIndex, incomingEdges[edge.endIndex][prev.startIndex])` [S1, unofficial].
                *   Update links: `activeEdge.prev = prev.prev`, `activeEdges[activeEdge.prev].next = edgeIdx - 1`, `activeEdge.next = next.next`, `activeEdges[activeEdge.next].prev = edgeIdx - 1` [S1, unofficial].
                *   Set `firstEdge = edgeIdx - 1` [S1, unofficial].

4.  **Vertex Collection:**
    *   Initialize `cur = firstEdge` and `count = 0` [S1, unofficial].
    *   Do-While loop while `cur != firstEdge`:
        *   Increment `count` [S1, unofficial].
        *   Retrieve `activeEdge = activeEdges[cur]` [S1, unofficial].
        *   Push `activeEdge.pos` components to `points` buffer [S1, unofficial].
        *   Push `activeEdge.tex` components to `texCoords` buffer [S1, unofficial].
        *   Update `activeEdge.pos += activeEdge.deltaPos` and `activeEdge.tex += activeEdge.deltaTex` [S1, unofficial].
        *   Set `cur = activeEdge.next` [S1, unofficial].

5.  **Index Generation:**
    *   For `i` from 2 to `count - 1`:
        *   Push indices `(nextIndex, nextIndex + i - 1, nextIndex + i)` to `indexes` buffer to form triangle fans [S1, unofficial].
        *   Increment `nextIndex` by 1 [G].

**Pseudocode:**

```python
import heapq

def volumetric_fire_slice_contouring(pos_corners, tex_corners, corner_distance, slice_spacing, min_distance, max_corner, corner_neighbors, incoming_edges):
    active_edges = [None] * 12
    expirations = []
    first_edge = 0
    edge_idx = 0
    points = []
    tex_coords = []
    indexes = []
    next_index = 0

    class Vector3:
        def __init__(self, x=0.0, y=0.0, z=0.0):
            self.x, self.y, self.z = x, y, z
        def sub(self, a, b):
            self.x, self.y, self.z = a.x - b.x, a.y - b.y, a.z - b.z
            return self
        def add(self, a, b):
            self.x, self.y, self.z = a.x + b.x, a.y + b.y, a.z + b.z
            return self
        def mul_scalar(self, s):
            self.x *= s; self.y *= s; self.z *= s
            return self
        def clone(self):
            return Vector3(self.x, self.y, self.z)
        def copy(self, v):
            self.x, self.y, self.z = v.x, v.y, v.z
            return self
        def add_inplace(self, v):
            self.x += v.x; self.y += v.y; self.z += v.z
            return self

    def create_edge(start_index, end_index):
        nonlocal edge_idx
        if edge_idx >= 12:
            return None

        range_val = corner_distance[start_index] - corner_distance[end_index]
        delta_pos = Vector3()
        delta_tex = Vector3()
        pos = Vector3()
        tex = Vector3()

        if range_val != 0.0:
            irange = 1.0 / range_val
            delta_pos.sub(pos_corners[end_index], pos_corners[start_index]).mul_scalar(irange)
            delta_tex.sub(tex_corners[end_index], tex_corners[start_index]).mul_scalar(irange)

            step = corner_distance[start_index] - slice_distance
            pos.add(delta_pos.clone().mul_scalar(step), pos_corners[start_index])
            tex.add(delta_tex.clone().mul_scalar(step), tex_corners[start_index])

            delta_pos.mul_scalar(slice_spacing)
            delta_tex.mul_scalar(slice_spacing)
        else:
            delta_pos.mul_scalar(0.0)
            delta_tex.mul_scalar(0.0)
            pos.copy(pos_corners[start_index])
            tex.copy(tex_corners[start_index])

        edge_obj = {
            'expired': False, 'startIndex': start_index, 'endIndex': end_index,
            'deltaPos': delta_pos, 'deltaTex': delta_tex, 'pos': pos, 'tex': tex,
            'cur': edge_idx, 'prev': 0, 'next': 0
        }

        heapq.heappush(expirations, (corner_distance[end_index], edge_obj))
        active_edges[edge_idx] = edge_obj
        edge_idx += 1
        return edge_obj

    for i in range(3):
        active_edge = create_edge(max_corner, corner_neighbors[max_corner][i])
        active_edge['prev'] = (i + 2) % 3
        active_edge['next'] = (i + 1) % 3

    slice_distance = max_corner

    while slice_distance > min_distance:
        while expirations and expirations[0][0] >= slice_distance:
            _, edge = heapq.heappop(expirations)
            if edge['expired']:
                continue

            prev_edge = active_edges[edge['prev']]
            next_edge_obj = active_edges[edge['next']]

            if edge['endIndex'] != prev_edge['endIndex'] and edge['endIndex'] != next_edge_obj['endIndex']:
                edge['expired'] = True
                active_edge1 = create_edge(edge['endIndex'], incoming_edges[edge['endIndex']][edge['startIndex']])
                active_edge1['prev'] = edge['prev']
                active_edges[edge['prev']]['next'] = edge_idx - 1
                active_edge1['next'] = edge_idx

                active_edge2 = create_edge(edge['endIndex'], incoming_edges[edge['endIndex']][active_edge1['endIndex']])
                active_edge2['prev'] = edge_idx - 2
                active_edge2['next'] = edge['next']
                active_edges[active_edge2['next']]['prev'] = edge_idx - 1
                first_edge = edge_idx - 1
            else:
                if edge['endIndex'] == prev_edge['endIndex']:
                    prev = prev_edge
                    nxt = edge
                else:
                    prev = edge
                    nxt = next_edge_obj

                prev['expired'] = True
                nxt['expired'] = True

                active_edge = create_edge(edge['endIndex'], incoming_edges[edge['endIndex']][prev['startIndex']])
                active_edge['prev'] = prev['prev']
                active_edges[active_edge['prev']]['next'] = edge_idx - 1
                active_edge['next'] = nxt['next']
                active_edges[active_edge['next']]['prev'] = edge_idx - 1
                first_edge = edge_idx - 1

        cur = first_edge
        count = 0
        if cur < 12 and active_edges[cur] is not None:
            while True:
                count += 1
                active_edge = active_edges[cur]
                points.extend([active_edge['pos'].x, active_edge['pos'].y, active_edge['pos'].z])
                tex_coords.extend([active_edge['tex'].x, active_edge['tex'].y, active_edge['tex'].z])

                active_edge['pos'].add_inplace(active_edge['deltaPos'])
                active_edge['tex'].add_inplace(active_edge['deltaTex'])

                cur = active_edge['next']
                if cur == first_edge:
                    break

        for i in range(2, count):
            indexes.append(next_index)
            indexes.append(next_index + i - 1)
            indexes.append(next_index + i)
            next_index += 1

        slice_distance -= slice_spacing

    return points, tex_coords, indexes
```

**Parameters:**
*   `sliceSpacing`: The distance between consecutive slices [S1, unofficial].
*   `minDistance`: The minimum slice distance to process [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Division by Zero:** If `range` (difference between corner distances) is zero, interpolation is skipped, and the edge position/texture is set to the start corner values [S1, unofficial].
*   **Boundary Conditions:** The algorithm assumes valid `incomingEdges` and `cornerNeighbors` structures [S1, unofficial]. If `edgeIdx` exceeds 11, `createEdge` returns `None`, which may break the linked list if not handled [S1, unofficial].

## Subtopics

### Triangular Mesh Surface Construction from Slices
A method to construct a 3D surface from volumetric radar cross section (RCS) data by forming triangular patches between consecutive slices of data, specifically handling concave contours [S2, unofficial]. It preprocesses data points along each contour by forming a convex hull, establishes a closest distance relation between points on adjacent contours, and steps around the contour pair to triangulate closest points [S2, unofficial]. The process converts magnitude from centibels to decibels, maps coordinates into spherical coordinates, and doubles the right hemisphere slice data to generate the left hemisphere [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Not explicitly given in the sources [S1, unofficial]. The algorithm iterates through slices and processes edges, with split/merge operations being constant time per edge [S1, unofficial].
*   **Memory Complexity:** Not explicitly given in the sources [S1, unofficial]. Uses a fixed-size active edge list (up to 12 edges) and buffers for output [S1, unofficial].
*   **Strengths:** Optimized for volumetric fire rendering and handles topology changes dynamically across slices [S1, unofficial].
*   **Limitations:** Specific to the VolumetricFire implementation and not designed as a general-purpose isosurface extractor [S1, unofficial].
*   **When to use:** When rendering volumetric fire effects where slice-based contouring is sufficient [S1, unofficial].
*   **When not to use:** For general isosurface extraction requiring robust topology handling across complex volumes [S1, unofficial].
