# Marching Cubes with Narrow-Band Filtering

Also called: MeshReconstruction::MarchCube

## Overview
This method reconstructs a triangle mesh from a Signed Distance Function (SDF) by evaluating the SDF on a grid of cubes, filtering cubes based on their distance to the surface (narrow-band filtering), and applying the Marching Cubes algorithm to intersected cubes [S1, unofficial]. It sets itself apart from standard Marching Cubes by skipping voxels where the distance from the center to the surface exceeds the cube's geometric bounds, significantly accelerating reconstruction for sparse or bounded SDFs [S1, unofficial].

## How it works
**Inputs:**
*   `sdf`: A function $S: \mathbb{R}^3 \to \mathbb{R}$ representing the Signed Distance Function [S1, unofficial].
*   `domain`: A `Rect3` structure defining the bounding box of the reconstruction volume, with fields `min` (Vec3) and `size` (Vec3) [S1, unofficial].
*   `cubeSize`: A Vec3 defining the dimensions of each voxel/cube. If not provided, it is calculated from `NumCubes` as `domain.size * (1.0 / NumCubes)` [S1, unofficial].
*   `isoLevel`: The scalar value defining the isosurface (typically 0 for SDFs) [S1, unofficial].
*   `sdfGrad`: An optional gradient function for vertex normals. If `nullptr`, a numerical approximation is used [S1, unofficial].

**Outputs:**
*   `mesh`: A triangle mesh data structure containing vertices and indices [G].

**Data Structures:**
*   `Rect3`: Contains `min` (Vec3) and `size` (Vec3) [S1, unofficial].
*   `Cube`: Contains `pos[8]` (Vec3 array of vertex positions) and `sdf[8]` (double array of SDF values at vertices) [S1, unofficial].
*   `signConfigToIntersectedEdges`: A static array of 256 integers (bitmasks) mapping vertex sign configurations to intersected edges [S1, unofficial].
*   `edges`: A static array of 12 `Edge` structs. Each `Edge` has `edgeFlag` (12-bit integer, powers of 2: 1, 2, 4... 2048), `vert0` (int 0-7), and `vert1` (int 0-7) [S1, unofficial].

**Parameters:**
*   `NumCubes`: Integer constant, default 50. Used to calculate default `cubeSize` as `domain.size * (1.0 / NumCubes)` [S1, unofficial].
*   `isoLevel`: Default 0 [S1, unofficial].

**Steps:**
1.  **Calculate Grid Dimensions:**
    $$ \text{NumX} = \lceil \text{domain.size.x} / \text{cubeSize.x} \rceil $$
    $$ \text{NumY} = \lceil \text{domain.size.y} / \text{cubeSize.y} \rceil $$
    $$ \text{NumZ} = \lceil \text{domain.size.z} / \text{cubeSize.z} \rceil $$ [S1, unofficial].
2.  **Calculate Geometric Constants:**
    $$ \text{HalfCubeDiag} = \|\text{cubeSize}\| / 2.0 $$
    $$ \text{HalfCubeSize} = \text{cubeSize} \times 0.5 $$ [S1, unofficial].
3.  **Iterate Grid:** For each grid index $(ix, iy, iz)$ where $0 \le ix < \text{NumX}$, etc.:
    a. Calculate cube minimum corner:
       $$ \text{min} = \text{domain.min} + \{ ix \cdot \text{cubeSize.x}, iy \cdot \text{cubeSize.y}, iz \cdot \text{cubeSize.z} \} $$ [S1, unofficial].
    b. Calculate cube center:
       $$ \text{cubeCenter} = \text{min} + \text{HalfCubeSize} $$ [S1, unofficial].
    c. Evaluate SDF at center and calculate distance to isosurface:
       $$ \text{dist} = | \text{sdf}(\text{cubeCenter}) - \text{isoLevel} | $$ [S1, unofficial].
    d. **Narrow-Band Filter:** If $\text{dist} > \text{HalfCubeDiag}$, the cube cannot intersect the isosurface. Continue to next cube [S1, unofficial].
    e. Construct `Cube` object:
       i. Set `Cube.pos[v]` for $v \in [0,7]$ to the 8 vertices of the cube defined by `min` and `cubeSize` [S1, unofficial].
       ii. Set `Cube.sdf[v] = sdf(Cube.pos[v])` [S1, unofficial].
    f. **Classify Cube:** Compute vertex signs $s_v = \text{sign}(\text{Cube.sdf}[v] - \text{isoLevel})$. Form an 8-bit configuration index $C = \sum_{v=0}^{7} s_v \cdot 2^v$ [S1, unofficial].
    g. **Find Intersections:** Use `signConfigToIntersectedEdges[C]` to identify intersected edges. For each intersected edge $e$ (defined by `edges[e_idx]`):
       i. Interpolate intersection point $P$ on the edge between vertices $v_0 = \text{Cube.pos}[e.\text{vert0}]$ and $v_1 = \text{Cube.pos}[e.\text{vert1}]$ with SDF values $d_0 = \text{Cube.sdf}[v_0]$ and $d_1 = \text{Cube.sdf}[v_1]$:
          $$ \mu = \frac{\text{isoLevel} - d_0}{d_1 - d_0} $$
          $$ P = v_0 + (v_1 - v_0) \cdot \mu $$
          The source handles near-zero denominators and exact matches with an epsilon $\epsilon = 10^{-5}$: if $|\text{isoLevel} - d_0| < \epsilon$ return $v_0$; if $|\text{isoLevel} - d_1| < \epsilon$ return $v_1$; if $|d_0 - d_1| < \epsilon$ return $v_0$ [S1, unofficial].
    h. **Triangulate:** Call `Triangulate(intersect, sdfGrad, mesh)` to generate triangles from the intersection points and add them to the mesh [S1, unofficial]. This step uses the standard Marching Cubes `triangleTable` from the parent article [Parent].

def lerp_vertex(isoLevel, v1, v2, p1, p2, eps=1e-5):
    if abs(isoLevel - v1) < eps: return p1
    if abs(isoLevel - v2) < eps: return p2
    if abs(v1 - v2) < eps: return p1
    mu = (isoLevel - v1) / (v2 - v1)
    return p1 + (p2 - p1) * mu

def marching_cubes_narrow_band(sdf, domain, cubeSize=None, isoLevel=0.0, NumCubes=50):
    if cubeSize is None:
        cubeSize = domain.size * (1.0 / NumCubes)
    numX = math.ceil(domain.size.x / cubeSize.x)
    numY = math.ceil(domain.size.y / cubeSize.y)
    numZ = math.ceil(domain.size.z / cubeSize.z)
    halfCubeDiag = cubeSize.norm() / 2.0
    halfCubeSize = cubeSize * 0.5
    mesh = Mesh()
    for ix in range(numX):
        for iy in range(numY):
            for iz in range(numZ):
                min_corner = domain.min + Vec3(ix * cubeSize.x, iy * cubeSize.y, iz * cubeSize.z)
                cubeCenter = min_corner + halfCubeSize
                dist = abs(sdf(cubeCenter) - isoLevel)
                if dist > halfCubeDiag: continue
                pos = [
                    min_corner, min_corner + Vec3(cubeSize.x, 0, 0),
                    min_corner + Vec3(cubeSize.x, cubeSize.y, 0), min_corner + Vec3(0, cubeSize.y, 0),
                    min_corner + Vec3(0, 0, cubeSize.z), min_corner + Vec3(cubeSize.x, 0, cubeSize.z),
                    min_corner + Vec3(cubeSize.x, cubeSize.y, cubeSize.z), min_corner + Vec3(0, cubeSize.y, cubeSize.z)
                ]
                sdf_vals = [sdf(p) for p in pos]
                config = 0
                for v in range(8):
                    if sdf_vals[v] < isoLevel: config |= (1 << v)
                intersected_mask = signConfigToIntersectedEdges[config]
                edge_to_inter = {}
                for e_idx, edge in enumerate(edges):
                    if intersected_mask & edge["edgeFlag"]:
                        v0_idx, v1_idx = edge["vert0"], edge["vert1"]
                        edge_to_inter[e_idx] = lerp_vertex(isoLevel, sdf_vals[v0_idx], sdf_vals[v1_idx], pos[v0_idx], pos[v1_idx])

## Subtopics

### SDF to PLY Conversion
Converts SDF data directly to PLY format rather than OBJ, focusing on output compatibility [G]. It sets itself apart by prioritizing point-cloud-derived mesh export over direct grid triangulation [G]. Choose it when the downstream pipeline requires PLY [G]. [SDF to PLY Conversion](2343-sdf-to-ply-conversion.md)

### Two-Step Surface Reconstruction Method
Uses a low-cost approximation to screen voxels before high-accuracy evaluation, offering a different acceleration strategy than simple distance filtering [G]. It sets itself apart by combining coarse and fine SDF evaluations rather than relying solely on geometric bounds [G]. Choose it when SDF evaluation is expensive and a two-pass approach yields better performance [G]. [Two-Step Surface Reconstruction Method](7364-two-step-surface-reconstruction-method.md)

## Operating characteristics
*   **Time Complexity**: $O(N)$ where $N$ is the number of voxels in the grid, but effectively much less due to narrow-band filtering skipping non-intersecting cubes [S1, unofficial].
*   **Memory Complexity**: $O(1)$ auxiliary space per cube, plus $O(V)$ for the output mesh where $V$ is the number of vertices [G].
*   **Performance**: Fast due to precomputed lookup tables and narrow-band approach excluding cubes far from the surface [S1, unofficial].
*   **Measured Performance**: Not given in the sources.
*   **Strengths**: Efficient for SDFs where the surface is localized; avoids evaluating SDF for all voxels [S1, unofficial].
*   **Limitations**: Requires SDF or a function that can be evaluated at arbitrary points; grid resolution affects accuracy [G].
*   **When to use**: When reconstructing meshes from SDFs or implicit functions where the domain is large but the surface is confined [G].
*   **When not to use**: When the surface fills the entire domain or when SDF evaluation is extremely expensive and narrow-band filtering doesn't skip enough cubes [G].
