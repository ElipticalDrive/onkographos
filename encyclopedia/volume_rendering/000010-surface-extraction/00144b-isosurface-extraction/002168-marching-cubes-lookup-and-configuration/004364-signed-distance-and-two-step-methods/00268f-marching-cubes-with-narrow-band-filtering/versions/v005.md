# Marching Cubes with Narrow-Band Filtering

Also called: MeshReconstruction::MarchCube

## Overview
This method reconstructs a triangle mesh from a Signed Distance Function (SDF) by evaluating the field on a structured grid, filtering out cubes that are too far from the isosurface (narrow-band filtering), and applying the standard Marching Cubes algorithm to the remaining cubes [S1, unofficial]. It differs from naive Marching Cubes by skipping the vast majority of voxels that do not intersect the surface, significantly reducing computation time for sparse or bounded domains [S1, unofficial].

## How it works
**Inputs:**
*   `domain`: A bounding box defined by `min` (Vec3) and `size` (Vec3) [S1, unofficial].
*   `sdf`: A function `Vec3 -> double` returning the signed distance at a point [S1, unofficial].
*   `cubeSize`: The dimensions of a single voxel (Vec3) [S1, unofficial].
*   `isoLevel`: The isovalue for extraction, typically 0 for SDFs [S1, unofficial].
*   `sdfGrad`: Optional gradient function `Vec3 -> Vec3`. If null, numerical approximation is used [S1, unofficial].

**Outputs:**
*   `mesh`: A triangle mesh containing vertices and indices [S1, unofficial].

**Data Structures:**
*   `Cube`: Represents a single voxel. Stores the 8 vertex positions (`pos[8]`) and 8 SDF values (`sdf[8]`) [S1, unofficial].
*   `Edge`: Struct with `edgeFlag` (12-bit bitmask), `vert0` (int), `vert1` (int) [S1, unofficial].
*   `signConfigToIntersectedEdges`: Array of 256 integers (hex constants). Maps the 8-bit vertex sign configuration to a 12-bit bitmask of intersected edges [S1, unofficial].
*   `edges`: Array of 12 `Edge` structs defining the geometry of the 12 cube edges [S1, unofficial].

**Algorithm Steps:**

1.  **Grid Calculation**: Determine the number of cubes along each axis:
    $$ NumX = \lceil domain.size.x / cubeSize.x \rceil $$
    $$ NumY = \lceil domain.size.y / cubeSize.y \rceil $$
    $$ NumZ = \lceil domain.size.z / cubeSize.z \rceil $$ [S1, unofficial]

2.  **Constants**:
    $$ HalfCubeSize = cubeSize \times 0.5 $$
    $$ HalfCubeDiag = \|cubeSize\| / 2.0 $$ [S1, unofficial]

3.  **Iteration**: Loop over grid indices $ix, iy, iz$ from $0$ to $NumX-1$, etc.

4.  **Cube Geometry**:
    *   Calculate minimum corner:
        $$ min = domain.min + \{ ix \cdot cubeSize.x, iy \cdot cubeSize.y, iz \cdot cubeSize.z \} $$ [S1, unofficial]
    *   Calculate cube center:
        $$ cubeCenter = min + HalfCubeSize $$ [S1, unofficial]
    *   Calculate distance to isosurface:
        $$ dist = |sdf(cubeCenter) - isoLevel| $$ [S1, unofficial]

5.  **Narrow-Band Filter**:
    *   If $dist > HalfCubeDiag$, the cube cannot intersect the isosurface. Continue to the next cube [S1, unofficial].

6.  **Sample Vertices**:
    *   Construct the `Cube` object.
    *   Store the 8 vertex positions relative to `min` (e.g., $min + \{0,0,0\}$ to $min + cubeSize$) [S1, unofficial].
    *   Evaluate `sdf` at each of the 8 vertices and store in `Cube.sdf[8]` [S1, unofficial].

7.  **Intersection**:
    *   Compute the case index $C$ by checking if $sdf[v_i] < isoLevel$ (or $> isoLevel$, depending on convention; the source uses `abs(sdf - isoLevel)` for filtering but implies standard sign-based LUT lookup) [S1, unofficial].
    *   Look up `signConfigToIntersectedEdges[C]` to get the bitmask of intersected edges [S1, unofficial].
    *   For each set bit $k$ in the mask, find the intersection point on edge $k$ using linear interpolation:
        $$ \mu = \frac{isoLevel - sdf[v_{start}]}{sdf[v_{end}] - sdf[v_{start}]} $$
        $$ p_{intersect} = p_{start} + \mu (p_{end} - p_{start}) $$ [S1, unofficial]
        *   Guard: If $|isoLevel - sdf[v_{start}]| < \epsilon$ or $|sdf[v_{start}] - sdf[v_{end}]| < \epsilon$, return $p_{start}$ [S1, unofficial].

8.  **Triangulation**:
    *   Use the standard `triangleTable` (from parent article) to map intersected edges to triangles [S1, Parent, unofficial].
    *   Generate triangles using the intersection points calculated in Step 7.
    *   Compute normals: Use `sdfGrad` if provided, otherwise approximate numerically [S1, unofficial].
    *   Add triangles to `mesh` [S1, unofficial].

**Pseudocode:**

```python
def MarchingCubesNarrowBand(domain, sdf, cubeSize, isoLevel=0.0, sdfGrad=None):
    # 1. Grid Dimensions
    numX = ceil(domain.size.x / cubeSize.x)
    numY = ceil(domain.size.y / cubeSize.y)
    numZ = ceil(domain.size.z / cubeSize.z)

    # 2. Constants
    halfCubeSize = cubeSize * 0.5
    halfCubeDiag = length(cubeSize) / 2.0

    mesh = Mesh()

    # 3. Iterate Grid
    for iz in range(numZ):
        for iy in range(numY):
            for ix in range(numX):
                # 4. Cube Geometry
                minCorner = domain.min + Vec3(ix * cubeSize.x, iy * cubeSize.y, iz * cubeSize.z)
                cubeCenter = minCorner + halfCubeSize

                # 5. Narrow-Band Filter
                dist = abs(sdf(cubeCenter) - isoLevel)
                if dist > halfCubeDiag:
                    continue

                # 6. Sample Vertices
                # Define 8 vertices relative to minCorner
                vertices = [
                    minCorner,
                    minCorner + Vec3(cubeSize.x, 0, 0),
                    minCorner + Vec3(cubeSize.x, cubeSize.y, 0),
                    minCorner + Vec3(0, cubeSize.y, 0),
                    minCorner + Vec3(0, 0, cubeSize.z),
                    minCorner + Vec3(cubeSize.x, 0, cubeSize.z),
                    minCorner + cubeSize,
                    minCorner + Vec3(0, cubeSize.y, cubeSize.z)
                ]

                sdfValues = [sdf(v) for v in vertices]

                # 7. Intersection
                # Calculate Case Index C
                # Convention: bit i is 1 if sdfValues[i] < isoLevel (or >, must match LUT)
                # Assuming standard: bit i set if sdfValues[i] < isoLevel
                caseIndex = 0
                for i in range(8):
                    if sdfValues[i] < isoLevel:
                        caseIndex |= (1 << i)

                # Get intersected edges bitmask
                edgeMask = signConfigToIntersectedEdges[caseIndex]

                # Find intersection points
                intersections = {}
                for edgeIdx in range(12):
                    if (edgeMask >> edgeIdx) & 1:
                        edge = edges[edgeIdx] # Predefined Edge struct
                        v1 = vertices[edge.vert0]
                        v2 = vertices[edge.vert1]
                        s1 = sdfValues[edge.vert0]
                        s2 = sdfValues[edge.vert1]

                        # Linear Interpolation
                        eps = 1e-5
                        if abs(isoLevel - s1) < eps:
                            p = v1
                        elif abs(s1 - s2) < eps:
                            p = v1
                        else:
                            mu = (isoLevel - s1) / (s2 - s1)
                            p = v1 + (v2 - v1) * mu
                        intersections[edgeIdx] = p

                # 8. Triangulation
                # Use triangleTable from parent article
                # triangleTable[caseIndex] contains triplets of edge indices
                triTable = triangleTable[caseIndex]
                i = 0
                while triTable[i] != -1:
                    e1 = triTable[i]
                    e2 = triTable[i+1]
                    e3 = triTable[i+2]
                    
                    p1 = intersections[e1]
                    p2 = intersections[e2]
                    p3 = intersections[e3]

                    # Normal calculation
                    if sdfGrad is not None:
                        n1 = sdfGrad(p1)
                        n2 = sdfGrad(p2)
                        n3 = sdfGrad(p3)
                    else:
                        # Numerical approximation [G]
                        n1 = numericalGradient(sdf, p1)
                        n2 = numericalGradient(sdf, p2)
                        n3 = numericalGradient(sdf, p3)

                    mesh.addTriangle(p1, p2, p3, n1, n2, n3)
                    i += 3

    return mesh
```

**Parameters:**
*   `NumCubes`: Integer constant, default 50. Used to derive `cubeSize` as `domain.size / NumCubes` if not explicitly provided [S1, unofficial].
*   `isoLevel`: Default 0. Changing this moves the reconstructed surface [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Narrow-Band Threshold**: If `dist > HalfCubeDiag`, the cube is skipped. This is the primary optimization but requires the grid to be dense enough to capture the surface [S1, unofficial].
*   **Precision**: Use epsilon comparisons for SDF values close to `isoLevel` to avoid division by zero or unstable interpolation [S1, unofficial].
*   **Ambiguity**: Standard Marching Cubes ambiguity cases (46, 47, etc.) are not resolved by this method alone; they rely on the parent's LUT configuration [Parent].

## Operating characteristics
*   **Time Complexity**: $O(N)$ where $N$ is the number of cubes in the domain, but effectively much faster due to narrow-band filtering. The number of processed cubes is proportional to the surface area times the inverse cube size, rather than the volume [S1, unofficial].
*   **Memory Complexity**: $O(1)$ auxiliary memory per cube (excluding the output mesh) [S1, unofficial].
*   **Performance**: Fast due to precomputed lookup tables and exclusion of non-intersecting cubes [S1, unofficial].
*   **Strengths**: Efficient for SDFs where the surface is localized; no need to process empty space [S1, unofficial].
*   **Limitations**: Requires a structured grid; performance degrades if the surface is extremely complex or fills the volume [S1, unofficial].

## Background
This method is implemented in the `MeshReconstruction` C++ library by Magnus2 [S1, unofficial]. It combines the classic Marching Cubes algorithm with a narrow-band filtering strategy to optimize performance for SDF-based reconstruction [S1, unofficial].
