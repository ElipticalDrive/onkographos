# Two-Step Surface Reconstruction Method

Also called: Improved signed marching cubes method, Signed Marching Cubes (SMC), Signed Marching Cubes with FMM, Two-Step Surface Reconstruction Method Using Signed Marching Cubes, Two-step reconstruction

## Overview
The Two-Step Surface Reconstruction Method accelerates isosurface extraction from implicit functions by filtering non-intersecting voxels using a low-cost rough evaluation before performing accurate evaluation only on potential boundary voxels [S1]. It solves the excessive computation time of traditional Marching Cubes, which evaluates all voxels regardless of their proximity to the surface [S1]. Unlike surface-following methods that require seed voxels and may miss disconnected components, this method guarantees complete isosurface recovery without seed dependencies [S1].

## How it works
**Inputs:**
*   A set of $N$ interpolation points $\{x_1, ..., x_N\}$ with associated signs (interior, exterior, or on surface) or scalar values [S1].
*   Reconstruction parameters: Voxel size $S_c$, lower expansion order $p_0$, higher expansion order $p$ [S1].

**Outputs:**
*   A triangular mesh representing the target isosurface [S1].

**Data Structures:**
*   **Implicit Function:** Defined by Radial Basis Function (RBF) interpolation:
    $$s(x) = \sum_{j=1}^{N} \omega_j \Phi(x, x_j) + p(x)$$
    where $\Phi$ is the radial basis kernel, $\omega_j$ are weight coefficients, and $p(x)$ is a polynomial part (e.g., $p(x) = c_1 + c_2 x + c_3 y + c_4 z$) [S1].
*   **FMM Approximation:** The kernel $\Phi(x, y)$ is approximated using a finite series of order $p$:
    $$\Phi(x, y) = \sum_{n=1}^{p} \phi_n(x)\psi_n(y) + R_p(x, y)$$
    where $R_p(x, y)$ is the residual [S1].
*   **Estimating Function:** The approximated function value at point $x$ using order $p$ is:
    $$s_p(x) = \sum_{n=1}^{p} \Psi_n(y)\phi_n(x)$$
    where $\Psi_n(y) = \sum_{j=1}^{N} \omega_j \psi_n(y_j)$ are pre-computed moments [S1].
*   **Evaluation Error:** The bound for the approximation error is:
    $$\varepsilon_p = \sum_{j=1}^{N} \omega_j R_p(x, y_j)$$
    [S1].
*   **Voxel Grid:** A structured 3D grid covering the minimum bounding box of the sampling data, divided into voxels $C$ with size $S_c$ [S1].

**Algorithm Steps:**

1.  **Parameter Specification:**
    Determine the voxel size $S_c$ based on the model's minimum bounding box dimensions ($l_1, l_2, l_3$) [S1]. Calculate a reference length $l_0$ based on the relative lengths of the bounding box axes [S1]:
    $$
    l_0 = \begin{cases} 
    0.1 l_2 & \text{if } l_3 < 0.1 l_2 \\
    0.05 l_3 & \text{if } 0.1 l_2 \le l_3 \le 0.5 l_2 \\
    0.025 l_3 & \text{if } l_3 > 0.5 l_2 
    \end{cases}
    $$
    Then set $S_c$ according to desired accuracy: coarse ($S_c = 5l_0$), general ($S_c = l_0$), or fine ($S_c = 0.3l_0$) [S1]. Select $p_0$ (lower order) and $p$ (higher order) [S1].

2.  **Precomputation:**
    Precompute the moments $\Psi_n(y)$ for both expansion orders $p_0$ and $p$ using the black-box Fast Multipole Method (FMM) to accelerate RBF evaluation [S1].

3.  **Implicit Function Construction:**
    Solve the interpolation constraints from the sampling data to determine weights $\omega_j$ and polynomial coefficients, defining the implicit function $f(x)$ [S1].

4.  **Grid Generation:**
    Determine the reconstruction region using the minimum bounding box of the sampling data [S1]. Divide this region into voxels $C$ [S1].

5.  **Rough Evaluation (Step 1):**
    Traverse all voxels $C$. For each vertex of each voxel, estimate the sign of the function value using the estimating function $s_{p_0}(x)$ with the lower expansion order $p_0$ [S1].

6.  **Screening (Step 2):**
    Classify voxels based on the rough evaluation results [S1]. A voxel is classified as:
    *   **Exterior ($C_{ext}$):** If for all vertices, $s_{p_0}(x) = \sigma > 0$ and $s_{p_0}(x) - \varepsilon_{p_0} > 0$. This requires $\varepsilon_{p_0-1} > \sigma > \varepsilon_{p_0} > \varepsilon_e$ [S1].
    *   **Interior ($C_{int}$):** If for all vertices, $s_{p_0}(x) = \sigma < 0$ and $s_{p_0}(x) + \varepsilon_{p_0} < 0$. This requires $\varepsilon_{p_0-1} > |\sigma| > \varepsilon_{p_0} > \varepsilon_e$ [S1].
    *   **Boundary ($C_{bou}$):** If the sign is ambiguous (i.e., $s_{p_0}(x) - \varepsilon_{p_0} \le 0$ for positive check or $s_{p_0}(x) + \varepsilon_{p_0} \ge 0$ for negative check) or the value is near zero [S1].
    Eliminate $C_{ext}$ and $C_{int}$ to obtain the set of possible boundary voxels $C_{bou}$ [S1].

7.  **Exact Evaluation (Step 3):**
    Traverse only the voxels in $C_{bou}$. Compute accurate function values for the vertices using the estimating function $s_p(x)$ with the higher expansion order $p$ [S1].

8.  **Marching Cubes (Step 4):**
    Apply the standard Marching Cubes algorithm to each boundary voxel in $C_{bou}$ using the accurate function values to determine edge intersections and generate triangles [S1].

9.  **Mesh Assembly:**
    Unite the triangular facets from all boundary voxels to obtain the complete triangular mesh [S1].

**Pseudocode:**

```python
def two_step_surface_reconstruction(points, weights, phi_func, psi_func, residual_func, poly_func, voxel_size, p_low, p_high):
    # Step 1 & 4: Determine bounding box and generate voxel grid
    min_coords = [min(p[i] for p in points) for i in range(3)]
    max_coords = [max(p[i] for p in points) for i in range(3)]
    
    grid = []
    x = min_coords[0]
    while x < max_coords[0]:
        y = min_coords[1]
        while y < max_coords[1]:
            z = min_coords[2]
            while z < max_coords[2]:
                grid.append((x, y, z))
                z += voxel_size
            y += voxel_size
        x += voxel_size

    # Step 2: Precompute moments for low and high orders
    moments_low = []
    for n in range(1, p_low + 1):
        m_n = sum(w * psi_func(n, p) for p, w in zip(points, weights))
        moments_low.append(m_n)
        
    moments_high = []
    for n in range(1, p_high + 1):
        m_n = sum(w * psi_func(n, p) for p, w in zip(points, weights))
        moments_high.append(m_n)

    boundary_voxels = []
    
    # Step 5 & 6: Rough Evaluation and Screening
    for (x, y, z) in grid:
        vertices = [
            (x, y, z), (x+voxel_size, y, z), (x, y+voxel_size, z), (x+voxel_size, y+voxel_size, z),
            (x, y, z+voxel_size), (x+voxel_size, y, z+voxel_size), (x, y+voxel_size, z+voxel_size), (x+voxel_size, y+voxel_size, z+voxel_size)
        ]
        
        is_boundary = False
        for v in vertices:
            # Evaluate s_p0(v)
            val_low = sum(m * phi_func(n, v) for n, m in enumerate(moments_low, 1)) + poly_func(v)
            # Evaluate error bound epsilon_p0
            err_low = sum(abs(w) * residual_func(n, v, p) for p, w in zip(points, weights))
            
            # Check sign ambiguity per evidence: if conditions not met, sign is ambiguous
            if not (val_low > err_low or val_low < -err_low):
                is_boundary = True
                break
        
        if is_boundary:
            boundary_voxels.append((x, y, z))
            
    # Step 7: Exact Evaluation
    accurate_values = {}
    for (x, y, z) in boundary_voxels:
        vertices = [
            (x, y, z), (x+voxel_size, y, z), (x, y+voxel_size, z), (x+voxel_size, y+voxel_size, z),
            (x, y, z+voxel_size), (x+voxel_size, y, z+voxel_size), (x, y+voxel_size, z+voxel_size), (x+voxel_size, y+voxel_size, z+voxel_size)
        ]
        for v in vertices:
            val_high = sum(m * phi_func(n, v) for n, m in enumerate(moments_high, 1)) + poly_func(v)
            accurate_values[v] = val_high
            
    # Step 8 & 9: Marching Cubes and Assembly
    mesh_triangles = []
    for (x, y, z) in boundary_voxels:
        vertices = [
            (x, y, z), (x+voxel_size, y, z), (x, y+voxel_size, z), (x+voxel_size, y+voxel_size, z),
            (x, y, z+voxel_size), (x+voxel_size, y, z+voxel_size), (x, y+voxel_size, z+voxel_size), (x+voxel_size, y+voxel_size, z+voxel_size)
        ]
        values = [accurate_values[v] for v in vertices]
        
        # Compute case index from signs relative to 0
        case_index = 0
        for i, val in enumerate(values):
            if val > 0:
                case_index |= (1 << i)

        edge_intersections = []
        
        for edge_idx, edge_pair in enumerate(MC_EDGE_TABLE):
            if (case_index >> edge_idx) & 1:
                v1, v2 = vertices[edge_pair[0]], vertices[edge_pair[1]]
                val1, val2 = values[edge_pair[0]], values[edge_pair[1]]
                t = val1 / (val1 - val2)
                intersection = (v1[0] + t*(v2[0]-v1[0]), v1[1] + t*(v2[1]-v1[1]), v1[2] + t*(v2[2]-v1[2]))
                edge_intersections.append(intersection)
```

**Parameters:**
*   **Expansion Order ($p$):** The order of the finite series in FMM [S1]. Higher $p$ increases accuracy but consumes more time [S1]. Recommended $p$ (higher) is 9–12. Recommended $p_0$ (lower) is 5–8 [S1].
*   **Voxel Size ($S_c$):** Determines reconstruction precision [S1]. Coarse: $5l_0$, General: $l_0$, Fine: $0.3l_0$ [S1].
*   **Evaluation Error ($\varepsilon_p$):** The residual error of the FMM approximation, used as a threshold for sign determination [S1].

**Edge Cases and Pitfalls:**
*   **Ambiguous Sign:** If the rough evaluation $s_{p_0}(x)$ is close to zero such that $s_{p_0}(x) - \varepsilon_{p_0} \le 0$ (for positive check) or $s_{p_0}(x) + \varepsilon_{p_0} \ge 0$ (for negative check), the sign cannot be determined reliably [S1]. These voxels are treated as boundary voxels requiring exact evaluation [S1].
*   **Small Objects:** If the target object size is smaller than the specified voxel size $S_c$, the object may not intersect any voxels, leading to failure reconstruction [S1]. A smaller $S_c$ is required to recover undetected objects [S1].
*   **Sharp Features:** Like standard Marching Cubes, this method may struggle to recover sharp geometric features [S1].
*   **Seed Dependency:** Unlike voxel growing, this method does not depend on seed voxels, ensuring complete recovery of disconnected components [S1].

## Operating characteristics
*   **Time Complexity:** Traditional Marching Cubes requires $O(N)$ operations per point for direct RBF evaluation [S1]. The Two-Step method reduces total time by avoiding high-precision FMM (high $p$) for non-boundary voxels [S1]. The number of evaluations with the higher expansion order is significantly reduced compared to the total number of voxels [S1].
*   **Measured Performance:** In tests with $N=10,704$ points and $S_c=5$, the ratio of high-precision evaluations to total evaluations was 1.92% [S1]. For $N=6,999$ and $S_c=2$, the ratio was 22.53% [S1]. Efficiency improvements were more obvious with smaller voxel sizes [S1].
*   **Strengths:** Eliminates invalid evaluation of non-boundary voxels; does not require seed voxels; guarantees complete isosurface recovery for disconnected parts [S1].
*   **Limitations:** May fail to detect objects smaller than the voxel size; struggles with sharp geometry features; requires careful selection of expansion orders and voxel sizes [S1].

## Background
The method was presented by J. Zhang and D. Zhong in *Applied Sciences* in 2022 [S1]. It builds on the Signed Marching Cubes (SMC) concept, which uses FMM to accelerate RBF evaluation [S1]. The core innovation is the two-step filtering process using different expansion orders to distinguish boundary from non-boundary voxels [S1]. It is implemented using FMM libraries for evaluation operations and standard visualization toolkits [S1].
