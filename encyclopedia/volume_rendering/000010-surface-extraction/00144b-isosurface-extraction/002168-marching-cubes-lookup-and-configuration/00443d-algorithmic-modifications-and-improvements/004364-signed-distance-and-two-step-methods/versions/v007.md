# Signed Distance and Two-Step Methods
## Overview
This family extends standard isosurface extraction by leveraging Signed Distance Field (SDF) properties or optimizing implicit function evaluation [G]. It addresses computational inefficiency and memory overhead for large-scale implicit data [G]. It differs from siblings by filtering voxels via distance bounds (Narrow-Band) or decoupling evaluation from extraction via multi-order approximation (Two-Step), while [Snap Marching Cubes](2181-snap-marching-cubes.md) targets topological correctness and [Lookup Table and Case Reduction](15794-lookup-table-and-case-reduction.md) targets table simplification [G].

## Subtopics

### [SDF to PLY Conversion](2343-sdf-to-ply-conversion.md)
Converts a raw SDF grid to a PLY mesh by sampling the implicit function and applying Marching Cubes. It differs from siblings by explicitly handling voxel-to-world coordinate transformations and managing memory during evaluation via chunking. Choose this for exporting neural network outputs or analytical SDFs where full grid evaluation ensures topological correctness at the zero-level set.

### [Marching Cubes with Narrow-Band Filtering](3826-marching-cubes-with-narrow-band-filtering.md)
Reconstructs a mesh from an SDF by filtering out cubes too far from the isosurface before applying Marching Cubes. It differs from siblings by skipping voxels that cannot intersect the surface, making it significantly faster for sparse or well-defined SDFs. Choose this when the surface is localized and voxel size is small enough to capture details within the narrow band.

### [Two-Step Surface Reconstruction Method](7364-two-step-surface-reconstruction-method.md)
Accelerates isosurface extraction by filtering non-intersecting voxels using a low-cost rough evaluation before performing accurate evaluation only on potential boundary voxels. It differs from siblings by guaranteeing complete isosurface recovery without seed dependencies, unlike surface-following methods. Choose this when the implicit function evaluation (e.g., via RBF interpolation) is the primary computational bottleneck.

## Background
The use of SDFs for surface extraction has become prevalent with neural implicit representations [G]. Standard Marching Cubes evaluates every voxel, which is inefficient for large domains [G]. Narrow-band filtering exploits the property that an SDF's zero-crossing is confined to a band of width equal to the voxel diagonal [G]. The Two-Step method originates from accelerating RBF-based implicit reconstruction using Fast Multipole Methods (FMM) .
