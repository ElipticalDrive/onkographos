# Signed Distance and Two-Step Methods

Also called: SDF-based Marching Cubes, Narrow-Band MC, Two-Step Reconstruction

## Overview
This family extends standard isosurface extraction by leveraging the geometric properties of Signed Distance Functions (SDFs) or by optimizing the evaluation of implicit fields. It solves the problem of computational inefficiency in dense grids and the memory overhead of high-resolution implicit function evaluation. It sets itself apart from siblings by either filtering voxels based on distance bounds (Narrow-Band) or using a two-stage approximation/exact evaluation pipeline (Two-Step), whereas others modify the lookup table or connectivity.

## Shared principles
All methods in this family operate on a structured 3D grid and produce a triangle mesh, building on [Marching Cubes Lookup and Configuration](2518-marching-cubes-lookup-and-configuration.md). The core mechanism remains the determination of edge intersections via a case index derived from vertex signs relative to an isovalue (typically 0 for SDFs). However, the computation of this index is optimized: either by skipping cubes that cannot intersect the surface based on geometric bounds or by deferring expensive implicit function evaluations until a coarse pass identifies relevant boundary voxels.

## Subtopics

### [SDF to PLY Conversion](2343-sdf-to-ply-conversion.md)
Converts an implicit function to a PLY mesh. Prioritizes memory management via chunked evaluation. Choose when exporting high-resolution SDFs to standard mesh formats.

### [Marching Cubes with Narrow-Band Filtering](3826-marching-cubes-with-narrow-band-filtering.md)
Filters cubes based on distance to the surface center. Choose for sparse or bounded SDFs to accelerate reconstruction by skipping distant voxels.

### [Two-Step Surface Reconstruction Method](7364-two-step-surface-reconstruction-method.md)
Uses a low-cost rough evaluation to filter invalid voxels, then accurately evaluates only boundary voxels. Choose for scattered interpolation points where full-grid evaluation is prohibitive.

## Background
The integration of Signed Distance Functions with Marching Cubes is a standard technique in computer graphics for extracting clean, watertight meshes from implicit representations. The "Two-Step" approach specifically addresses the computational cost of evaluating complex implicit fields (such as those defined by Radial Basis Functions) over large domains, a problem prevalent in geometric modeling and reverse engineering.
