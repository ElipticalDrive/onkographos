# Marching Cubes with Narrow-Band Filtering

Also called: MeshReconstruction::MarchCube

## Overview
This method reconstructs a triangle mesh from a Signed Distance Function (SDF) by evaluating the SDF on a structured grid and applying the Marching Cubes algorithm only to cubes intersecting the surface [S1, unofficial]. It differs from standard Marching Cubes by filtering out cubes whose centers are too far from the isosurface, significantly reducing the number of expensive geometric evaluations [S1, unofficial].

## How it works
**Inputs:**
- `domain`: A bounding box defined by `min` and `size` vectors.
- `sdf`: A function `Vec3 -> double` evaluating the signed distance at any point.
- `cubeSize`: The dimensions of each voxel (optional; defaults to `domain.size / 50` [S1, unofficial]).
- `isoLevel`: The isovalue for surface extraction (default 0) [S1, unofficial].
- `sdfGrad`: An optional gradient function `Vec3 -> Vec3`. If null, numerical approximation is used [S1, unofficial].

**Outputs:**
- A triangle mesh containing vertices and indices.

**Data Structures:**
- `Cube`: Represents a voxel. Stores 8 vertex positions (`pos[8]`) and 8 SDF values (`sdf[8]`).
- `signConfigToIntersectedEdges`: A lookup table of 256 integers (12-bit bitmasks) mapping vertex sign configurations to intersected edges [S1, unofficial].
- `edges`: An array of 12 `Edge` structs. Each `Edge` contains a 12-bit `edgeFlag` (powers of 2: $1, 2, 4, \dots, 2048$) and two vertex indices `vert0`, `vert1` (0–7) [S1, unofficial].

**Steps:**

1.  **Calculate Grid Dimensions:**
    $$ \text{NumX} = \lceil \text{domain.size.x} / \text{cubeSize.x} \rceil $$
    $$ \text{NumY} = \lceil \text{domain.size.y} / \text{cubeSize.y} \rceil $$
    $$ \text{NumZ} = \lceil \text{domain.size.z} / \text{cubeSize.z} \rceil $$
    [S1, unofficial]

2.  **Calculate Geometric Constants:**
    $$ \text{HalfCubeDiag} = \|\text{cubeSize}\| / 2.0 $$
    $$ \text{HalfCubeSize} = \text{cubeSize} \times 0.5 $$
    [S1, unofficial]

3.  **Iterate Grid:**
    For each integer index $(i_x, i_y, i_z)$ in $[0, \text{NumX}) \times [0, \text{NumY}) \times [0, \text{NumZ})$:
    
    a.  **Compute Cube Corner:**
        $$ \text{min} = \text{domain.min} + \{ i_x \cdot \text{cubeSize.x}, i_y \cdot \text{cubeSize.y}, i_z \cdot \text{cubeSize.z} \} $$
        [S1, unofficial]

    b.  **Compute Center and Distance:**
        $$ \text{cubeCenter} = \text{min} + \text{HalfCubeSize} $$
        $$ \text{dist} = | \text{sdf}(\text{cubeCenter}) - \text{isoLevel} | $$
        [S1, unofficial]

    c.  **Narrow-Band Filter:**
        If $\text{dist} > \text{HalfCubeDiag}$, the cube cannot intersect the surface. Continue to the next cube [S1, unofficial].

    d.  **Sample Vertices:**
        Construct a `Cube` object. Evaluate `sdf` at the 8 corners of the cube defined by `min` and `cubeSize`. Store positions in `pos[8]` and values in `sdf[8]` [S1, unofficial].

    e.  **Determine Case Index:**
        Compute an 8-bit configuration index $C$. For vertex $k \in [0, 7]$, if $\text{sdf}[k] < \text{isoLevel}$, set bit $k$ of $C$ to 1, else 0 [S1, unofficial].

    f.  **Find Intersected Edges:**
        Retrieve the bitmask $M = \text{signConfigToIntersectedEdges}[C]$ [S1, unofficial].
        For each edge $e \in [0, 11]$:
        If $(M \gg e) \& 1$:
        Let $v_0 = \text{edges}[e].\text{vert0}$ and $v_1 = \text{edges}[e].\text{vert1}$.
        Compute intersection point $P$ by linear interpolation:
        $$ \mu = \frac{\text{isoLevel} - \text{sdf}[v_0]}{\text{sdf}[v_1] - \text{sdf}[v_0]} $$
        $$ P = \text{pos}[v_0] + \mu (\text{pos}[v_1] - \text{pos}[v_0]) $$
        [S1, unofficial]
        *Note: Handle division by zero or near-zero denominator by returning one of the endpoints if $|\text{sdf}[v_1] - \text{sdf}[v_0]| < \epsilon$ [S1, unofficial].*

    g.  **Triangulate:**
        Use the standard Marching Cubes lookup (derived from $C$) to determine which triangles to form from the intersection points. Add triangles to the mesh [S1, unofficial].

**Pseudocode:**

        for iy in range(num_y):
            for iz in range(num_z):
                # 3a. Cube Minimum Corner
                min_corner = (
                    domain_min.x + ix * cube_size.x,
                    domain_min.y + iy * cube_size.y,
                    domain_min.z + iz * cube_size.z
                )
                
                # 3b. Cube Center and Distance
                center = (
                    min_corner[0] + half_cube_size[0],
                    min_corner[1] + half_cube_size[1],
                    min_corner[2] + half_cube_size[2]
                )
                dist_val = sdf(center)
                dist = abs(dist_val - iso_level)

                # 3c. Narrow-Band Filter
                if dist > half_cube_diag:
                    continue

                # 3d. Sample Vertices
                # Define 8 vertices relative to min_corner
                vertices = []
                sdf_vals = []
                for vx in (0, 1):
                    for vy in (0, 1):
                        for vz in (0, 1):
                            pos = (
                                min_corner[0] + vx * cube_size.x,
                                min_corner[1] + vy * cube_size.y,
                                min_corner[2] + vz * cube_size.z
                            )
                            vertices.append(pos)
                            sdf_vals.append(sdf(pos))

                # 3e. Determine Case Index
                config = 0
                for k in range(8):
                    if sdf_vals[k] < iso_level:
                        config |= (1 << k)

                # 3f. Find Intersected Edges
                edge_mask = sign_config_to_edges[config]
                intersections = []
                
                for e_idx in range(12):
                    if (edge_mask >> e_idx) & 1:
                        v0_idx = edges[e_idx].vert0
                        v1_idx = edges[e_idx].vert1
                        
                        v0 = vertices[v0_idx]
                        v1 = vertices[v1_idx]
                        s0 = sdf_vals[v0_idx]
                        s1 = sdf_vals[v1_idx]
                        
                        # Linear Interpolation
                        denom = s1 - s0
                        if abs(denom) < 1e-5:
                            # Fallback if denominator is near zero
                            p = v0
                        else:
                            mu = (iso_level - s0) / denom
                            p = (
                                v0[0] + mu * (v1[0] - v0[0]),
                                v0[1] + mu * (v1[1] - v0[1]),
                                v0[2] + mu * (v1[2] - v0[2])
                            )
                        intersections.append(p)

                # 3g. Triangulate
                # Standard Marching Cubes logic using 'config' and 'intersections'
                # This part depends on the specific triangulation table implementation
                # which is not fully detailed in the source notes but is implied by
                # the use of signConfigToIntersectedEdges and standard MC.

                mesh.add_triangles(triangles)

    return mesh

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of voxels in the grid, but the constant factor is reduced by the narrow-band filter. Only voxels within distance $\text{HalfCubeDiag}$ of the surface are processed [S1, unofficial].
- **Memory Complexity:** $O(N)$ for the grid iteration state, plus $O(T)$ for the output mesh where $T$ is the number of triangles. The lookup table is constant size (256 integers) [S1, unofficial].
- **Performance:** The library is described as "fast" due to the narrow-band approach excluding cubes far from the surface [S1, unofficial].
- **Strengths:** Efficient for sparse SDFs or when the surface is localized. Avoids evaluating the SDF and performing geometry for empty space.
- **Limitations:** Requires the SDF to be available for arbitrary queries. The narrow-band threshold must be chosen carefully; if too small, parts of the surface may be missed if the grid resolution is coarse relative to the surface curvature [S1, unofficial].
- **When to use:** When reconstructing surfaces from SDFs where the domain is large but the object is small, or when SDF evaluation is expensive.
