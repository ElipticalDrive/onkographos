# Marching Cubes with Narrow-Band Filtering

Also called: MeshReconstruction::MarchCube

## Overview
This method reconstructs a triangle mesh from a Signed Distance Function (SDF) by evaluating the SDF on a structured grid of cubes, filtering out cubes that are too far from the isosurface (narrow-band filtering), and applying the Marching Cubes algorithm only to the intersected cubes [S1, unofficial]. It builds on [Marching Cubes Lookup and Configuration](2518-marching-cubes-lookup-and-configuration.md) but optimizes performance by skipping voxels that cannot intersect the surface, making it significantly faster for sparse or well-defined SDFs compared to brute-force Marching Cubes [S1, unofficial].

## How it works
**Inputs:**
- `domain`: A 3D bounding box defined by `min` (Vec3) and `size` (Vec3) [S1, unofficial].
- `sdf`: A function $f: \mathbb{R}^3 \to \mathbb{R}$ returning the signed distance [S1, unofficial].
- `cubeSize`: The dimensions of each voxel (Vec3) [S1, unofficial].
- `isoLevel`: The scalar value defining the surface (default 0.0) [S1, unofficial].
- `sdfGrad`: Optional gradient function for vertex normals; if null, numerical approximation is used [S1, unofficial].

**Outputs:**
- A triangle mesh (list of vertices and indices) [S1, unofficial].

**Data Structures:**
- `Cube`: Represents a voxel. Contains:
  - `pos[8]`: Array of 8 vertex positions (Vec3) [S1, unofficial].
  - `sdf[8]`: Array of 8 SDF values (double) [S1, unofficial].
- `signConfigToIntersectedEdges`: Lookup table of size 256, mapping vertex sign configurations to a 12-bit bitmask indicating intersected edges [S1, unofficial].
- `edges`: Array of 12 `Edge` structs, each containing:
  - `edgeFlag`: 12-bit integer (powers of 2: 1, 2, 4, ..., 2048) [S1, unofficial].
  - `vert0`, `vert1`: Indices of the two vertices defining the edge (0-7) [S1, unofficial].

**Steps:**

1.  **Grid Setup:**
    Calculate grid dimensions:
    $$
    \text{NumX} = \lceil \text{domain.size.x} / \text{cubeSize.x} \rceil
    $$
    $$
    \text{NumY} = \lceil \text{domain.size.y} / \text{cubeSize.y} \rceil
    $$
    $$
    \text{NumZ} = \lceil \text{domain.size.z} / \text{cubeSize.z} \rceil
    $$
    [S1, unofficial]

2.  **Geometric Constants:**
    Calculate half-cube diagonal and half-cube size:
    $$
    \text{HalfCubeDiag} = \|\text{cubeSize}\| / 2.0
    $$
    $$
    \text{HalfCubeSize} = \text{cubeSize} \times 0.5
    $$
    [S1, unofficial]

3.  **Iterate Grid:**
    For each voxel index $(ix, iy, iz)$ where $0 \le ix < \text{NumX}$, $0 \le iy < \text{NumY}$, $0 \le iz < \text{NumZ}$:
    
    a.  **Calculate Cube Bounds:**
        $$
        \text{min} = \text{domain.min} + \{ ix \cdot \text{cubeSize.x}, iy \cdot \text{cubeSize.y}, iz \cdot \text{cubeSize.z} \}
        $$
        [S1, unofficial]
        
    b.  **Narrow-Band Filter (Pruning):**
        Calculate cube center:
        $$
        \text{cubeCenter} = \text{min} + \text{HalfCubeSize}
        $$
        Calculate distance from center to isosurface:
        $$
        \text{dist} = | \text{sdf}(\text{cubeCenter}) - \text{isoLevel} |
        $$
        If $\text{dist} > \text{HalfCubeDiag}$, the cube is too far from the surface to intersect it. Skip to the next cube [S1, unofficial].
        
    c.  **Sample Vertices:**
        Construct a `Cube` object. Evaluate `sdf` at the 8 vertices of the cube. Store positions in `pos[8]` and SDF values in `sdf[8]` [S1, unofficial].
        
    d.  **Determine Intersections:**
        Call `Intersect(isoLevel)` on the cube. This uses the `signConfigToIntersectedEdges` lookup table to determine which edges are intersected based on the signs of the 8 vertex SDF values relative to `isoLevel` [S1, unofficial].
        
    e.  **Generate Triangles:**
        Call `Triangulate(intersect, sdfGrad, mesh)`. For each intersected edge, calculate the intersection point using linear interpolation. Generate triangles from the intersection points and add them to the mesh. If `sdfGrad` is provided, use it for vertex normals; otherwise, compute normals numerically [S1, unofficial].

    # Edge definitions: (edge_flag, vert0, vert1)
    edges = [

                center_y = min_y + half_cube_size[1]
                center_z = min_z + half_cube_size[2]
                
                dist_to_iso = abs(sdf(center_x, center_y, center_z) - iso_level)
                
                if dist_to_iso > half_cube_diag:
                    continue  # Skip this cube
                
                # Step 3c: Sample Vertices
                # Define the 8 vertices of the cube
                vertices = [
                    (min_x, min_y, min_z),
                    (min_x + cube_size.x, min_y, min_z),
                    (min_x + cube_size.x, min_y + cube_size.y, min_z),
                    (min_x, min_y + cube_size.y, min_z),
                    (min_x, min_y, min_z + cube_size.z),
                    (min_x + cube_size.x, min_y, min_z + cube_size.z),
                    (min_x + cube_size.x, min_y + cube_size.y, min_z + cube_size.z),
                    (min_x, min_y + cube_size.y, min_z + cube_size.z)

                        config |= (1 << i)
                
                # Step 3d: Determine Intersections
                intersected_edges_mask = sign_config_to_edges[config]
                
                if intersected_edges_mask == 0:
                    continue  # No intersections
                
                # Calculate intersection points
                intersection_points = []
                for edge_idx in range(12):
                    if intersected_edges_mask & (1 << edge_idx):
                        edge_flag, v0_idx, v1_idx = edges[edge_idx]
                        p0 = vertices[v0_idx]
                        p1 = vertices[v1_idx]
                        s0 = sdf_values[v0_idx]
                        s1 = sdf_values[v1_idx]
                        
                        # Linear interpolation

                            point = p0
                        elif abs(s1 - iso_level) < eps:
                            point = p1

**Parameters:**
- `NumCubes`: Integer constant, default 50. Used to calculate default `cubeSize` as `domain.size * (1.0 / NumCubes)` [S1, unofficial].
- `isoLevel`: Default 0.0. Changing this moves the reconstructed surface [S1, unofficial].
- `sdfGrad`: Optional. If null, numerical approximation is used for normals [S1, unofficial].

**Pitfalls:**
- **Narrow-Band Filtering:** If `dist > HalfCubeDiag`, the cube is skipped. Ensure `cubeSize` is small enough to capture the surface detail, otherwise the narrow band may exclude relevant cubes [S1, unofficial].
- **Precision:** Use a small epsilon (e.g., $10^{-5}$) when comparing SDF values to `isoLevel` to handle floating-point inaccuracies [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of voxels in the grid. However, due to narrow-band filtering, the constant factor is significantly reduced for sparse SDFs, as only voxels near the surface are processed [S1, unofficial].
- **Memory Complexity:** $O(N)$ for the grid, plus $O(M)$ for the output mesh where $M$ is the number of triangles. The lookup table is constant size (256 entries) [S1, unofficial].
- **Performance:** The library is described as "fast" due to the narrow-band approach excluding cubes far from the surface [S1, unofficial].
- **Strengths:** Efficient for SDFs where the surface is localized; avoids processing empty space.
- **Limitations:** Requires an SDF input. Performance degrades if the surface is very complex or fills the entire domain, as the narrow-band filter becomes less effective.
- **When to use:** When reconstructing meshes from SDFs, especially when the SDF is expensive to evaluate or the domain is large but the surface is small.
- **When not to use:** When the input is not an SDF, or when the surface is extremely dense and fills the volume.
