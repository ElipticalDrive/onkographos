# Unbounded TSDF Mesh Extraction

Also called: Command Line Mesh Extraction, Unbounded TSDF Mesh Extraction with Contraction

## Overview
Extracts a triangle mesh from an unbounded scene by contracting infinite space into a bounded volume, performing adaptive TSDF fusion, and applying Marching Cubes [S1, unofficial][S2, unofficial]. It sets itself apart from standard bounded extraction by handling scenes with no predefined depth limits through space contraction and adaptive truncation, avoiding the need for a single massive global grid [S1, unofficial][S2, unofficial].

## How it works
**Inputs:** 3D Gaussian parameters (position, covariance, opacity, spherical harmonics), camera poses and intrinsics, `mesh_res` (grid resolution, default 1024), `num_cluster` (clusters to keep, default 50) [S1, unofficial].

**Outputs:** A triangle mesh (vertices and faces) with diffuse vertex colors [S2, unofficial].

**Data Structures:**
- **TSDF Volume:** A 3D grid of floats storing fused signed distance values, evaluated implicitly or chunked in unbounded mode [S2, unofficial].
- **Bounding Box:** Defined by radius $R$ in contracted space [S1, unofficial].

**Steps:**

1.  **Define Contraction Functions:**
    Space is contracted to fit within a unit sphere [S1, unofficial][S2, unofficial].
    $$
    \text{contract}(x) = \begin{cases} 
    x & \text{if } \|x\| < 1 \\
    \left(2 - \frac{1}{\|x\|}\right) \frac{x}{\|x\|} & \text{otherwise}
    \end{cases}
    $$
    $$
    \text{uncontract}(y) = \begin{cases} 
    y & \text{if } \|y\| < 1 \\
    \frac{1}{2 - \|y\|} \frac{y}{\|y\|} & \text{otherwise}
    \end{cases}
    $$
    [S1, unofficial][S2, unofficial]

2.  **Determine Bounding Box Radius ($R$):**
    - Project all Gaussian centers to contracted space: $x_c = \text{contract}(x)$ [S1, unofficial][S2, unofficial].
    - Compute the norm of each contracted center: $n_i = \|x_{c,i}\|$ [S1, unofficial][S2, unofficial].
    - Calculate the 95th percentile of these norms: $R_{raw} = \text{quantile}(n, 0.95)$ [S1, unofficial][S2, unofficial].
    - Set final radius: $R = \min(R_{raw} + 0.01, 1.9)$ [S1, unofficial][S2, unofficial].

3.  **Setup Grid Parameters:**
    - Resolution $N = \text{mesh\_res}$ (default 1024) [S1, unofficial].
    - Voxel size in contracted space: $\text{voxel\_size} = \frac{2R}{N}$ [S1, unofficial][S2, unofficial].
    - Define normalization/unnormalization for mapping between contracted space $[-R, R]$ and normalized space $[-1, 1]$:
      $$ \text{normalize}(x) = \frac{x - \text{center}}{\text{radius}} $$
      $$ \text{unnormalize}(x) = x \cdot \text{radius} + \text{center} $$
      Where $\text{center}=0, \text{radius}=R$ [S1, unofficial][S2, unofficial].
    - Define inverse contraction: $\text{inv\_contraction}(x) = \text{unnormalize}(\text{uncontract}(x))$ [S1, unofficial][S2, unofficial].

4.  **Define SDF/TSDF Function:**
    Create a function `sdf_function(point)` that returns the TSDF value at a given 3D point in contracted space [S2, unofficial].
    - **Input:** Point $p$ in contracted space.
    - **Process:**
        1.  Initialize `tsdf_value = 0.0`, `weight_sum = 0.0` [S2, unofficial].
        2.  For each camera $k$ in the training set:
            a.  Project $p$ to screen space:
                $$ p_{hom} = [p_x, p_y, p_z, 1] $$
                $$ p_{clip} = p_{hom} \cdot \text{view\_proj} $$
                $$ \text{pix\_coords} = p_{clip}[:, :2] / p_{clip}[:, 3:4] $$
                $$ z = p_{clip}[:, 3:4] $$
            b.  Check visibility: If $\text{pix\_coords} \in [-1, 1]$ and $z > 0$ (in front of camera) [S2, unofficial]:
                i.  Sample depth $d_k$ from the rendered depth map at $\text{pix\_coords}$ using bilinear interpolation [S2, unofficial].
                ii. Compute SDF: $s_k = d_k - z$ [S2, unofficial].
                iii. Compute adaptive truncation $\tau$:
                    - Initial $\tau = 5 \cdot \text{voxel\_size}$ [S2, unofficial].
                    - If $\|p\| > 1$ (outside unit sphere in contracted space):
                      $$ \tau = \frac{\tau}{2 - \|p\|} $$
                      (Clamped to max norm 1.9 to avoid division by zero) [S2, unofficial].
                iv. Truncate SDF: $s'_k = \max(-\tau, \min(\tau, s_k))$ [S1, unofficial].
                v.  Accumulate weighted average using Gaussian visibility weights $w_k$ [G]:
                    $$ \text{tsdf\_value} += s'_k \cdot w_k $$
                    $$ \text{weight\_sum} += w_k $$
        3.  If $\text{weight\_sum} > 0$:
            $$ \text{tsdf\_value} = \frac{\text{tsdf\_value}}{\text{weight\_sum}} $$
        4.  Return $\text{tsdf\_value}$ [S2, unofficial].

5.  **Run Marching Cubes with Contraction:**
    - Call `marching_cubes_with_contraction` with:
        - `sdf_function` defined above.
        - `bounding_box_min = (-R, -R, -R)`, `bounding_box_max = (R, R, R)` [S1, unofficial][S2, unofficial].
        - `level = 0`.
        - `resolution = N`.
        - `inv_contraction` function [S1, unofficial][S2, unofficial].
    - This generates vertices $V$ and faces $F$ in contracted space [S1, unofficial][S2, unofficial].

6.  **Inverse Contraction:**
    - Apply $\text{inv\_contraction}$ to all vertices $V$ to map them back to the original unbounded space [S1, unofficial][S2, unofficial].

7.  **Color the Mesh:**
    - For each vertex $v$ in the mesh, compute its RGB value using the unbounded TSDF function with `return_rgb=True` [S1, unofficial][S2, unofficial].

8.  **Post-Processing:**
    - Find connected components in the mesh.
    - Keep the largest `num_cluster` clusters (default 50) [S1, unofficial].
    - Discard remaining vertices and faces [S1, unofficial].

import torch
import numpy as np

def contract(x: torch.Tensor) -> torch.Tensor:
    """Contract space to unit sphere."""
    norm = torch.norm(x, dim=-1, keepdim=True)
    mask = norm < 1.0
    safe_norm = torch.where(mask, torch.ones_like(norm), norm)
    return torch.where(mask, x, (2.0 - 1.0 / safe_norm) * (x / safe_norm))

def uncontract(y: torch.Tensor) -> torch.Tensor:
    """Uncontract space from unit sphere."""
    norm = torch.norm(y, dim=-1, keepdim=True)
    mask = norm < 1.0
    safe_norm = torch.where(mask, torch.ones_like(norm), norm)
    return torch.where(mask, y, (1.0 / (2.0 - safe_norm)) * (y / safe_norm))

def compute_bounding_radius(gaussians_xyz: torch.Tensor) -> float:
    """Compute R based on 95th percentile of contracted Gaussian centers."""
    contracted = contract(gaussians_xyz)
    norms = torch.norm(contracted, dim=1)
    R_raw = torch.quantile(norms, 0.95)
    return min(R_raw.item() + 0.01, 1.9)

def get_sdf_function(gaussians, cameras, voxel_size: float, R: float):
    """Returns a function that computes TSDF at points in contracted space."""
    def sdf_at_points(points: torch.Tensor) -> torch.Tensor:
        """points: (M, 3) in contracted space."""
        tsdf_val = torch.zeros(points.shape[0], device=points.device)
        weight_sum = torch.zeros(points.shape[0], device=points.device)
        
        for cam in cameras:
            # Project to screen space
            p_hom = torch.cat([points, torch.ones_like(points[..., :1])], dim=-1)
            p_clip = p_hom @ cam.full_proj_transform.T
            
            pix_coords = p_clip[..., :2] / p_clip[..., 3:4]
            z = p_clip[..., 3:4]
            
            # Visibility mask
            mask_proj = ((pix_coords > -1.0) & (pix_coords < 1.0) & (z > 0.0)).all(dim=-1)
            if not mask_proj.any():
                continue
                
            # Sample depth using bilinear grid sampling
            sampled_depth = torch.nn.functional.grid_sample(
                cam.depth_map.unsqueeze(0).unsqueeze(0),
                pix_coords[mask_proj].unsqueeze(1),
                mode='bilinear',
                padding_mode='border',
                align_corners=True
            ).reshape(-1, 1)
            
            # Compute SDF
            sdf = sampled_depth - z[mask_proj]
            
            # Adaptive truncation
            tau = 5.0 * voxel_size
            norms_p = torch.norm(points[mask_proj], dim=-1, keepdim=True)
            mask_outside = norms_p > 1.0
            if mask_outside.any():
                safe_norm_out = torch.clamp(norms_p[mask_outside], max=1.9)
                tau[mask_outside] = tau / (2.0 - safe_norm_out)
            
            # Truncate SDF
            sdf_truncated = torch.clamp(sdf, min=-tau, max=tau)
            
            # Gaussian visibility weight [G]
            w = gaussians.opacity[mask_proj].unsqueeze(-1)
            
            # Incremental TSDF fusion
            tsdf_val[mask_proj] = (tsdf_val[mask_proj] * w.squeeze(-1) + sdf_truncated.squeeze(-1)) / (weight_sum[mask_proj] + w.squeeze(-1))
            weight_sum[mask_proj] += w.squeeze(-1)
            
        return tsdf_val

    return sdf_at_points

## Subtopics

### [Marching Cubes with Contraction](11247-marching-cubes-with-contraction.md)
Extracts a 3D mesh from a Signed Distance Field (SDF) by processing the volume in fixed-size chunks to manage memory, applying the Marching Cubes algorithm locally, and applying an inverse contraction transformation to the final vertices. It sets itself apart from standard Marching Cubes by handling unbounded scenes through space contraction and chunked evaluation, avoiding the need for a single massive global grid.

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Performance:** Depends heavily on `mesh_res` and number of cameras [S1, unofficial]. High resolution (1024) is computationally expensive [S1, unofficial].
- **Strengths:** Handles unbounded scenes without manual depth culling or bounding box estimation [S1, unofficial]. Adaptive truncation handles varying Gaussian densities [S1, unofficial][S2, unofficial].
- **Limitations:** Slow for high resolutions [S1, unofficial]. SDF evaluation is noisy if cameras are sparse [S1, unofficial].
- **When to use:** When the scene has no clear bounds or extends far beyond the camera frustum [S1, unofficial].
- **When not to use:** For bounded scenes where `extract_mesh_bounded` is faster and simpler [S1, unofficial].

## Background
Implemented in the `2d-gaussian-splatting` repository [S1, unofficial] and adapted in VGVGGT [S2, unofficial] for mesh extraction from unbounded scenes. It builds on the concept of space contraction used in neural implicit representations to handle infinite domains [S2, unofficial].
