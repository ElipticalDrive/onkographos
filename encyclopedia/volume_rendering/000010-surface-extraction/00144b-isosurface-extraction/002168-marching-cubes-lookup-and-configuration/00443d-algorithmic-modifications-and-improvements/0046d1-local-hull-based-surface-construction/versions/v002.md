# Local Hull-Based Surface Construction

Also called: 3D hull based surface generation, Local convex classification, Local convex classification and 3D hull based surface generation

## Overview
Local Hull-Based Surface Construction is a surface extraction method that addresses the concavity limitations of standard convex hull algorithms by decomposing an imperfect initial surface into local convex regions, constructing a hull for each, and aggregating the results. It differs from its siblings, such as [Snap Marching Cubes](2181-snap-marching-cubes.md) and [Marching Cubes Revisited](10126-marching-cubes-revisited.md), by replacing global or local linear interpolation with a two-stage process: first classifying local convexities from an initial Marching Cubes (MC) surface, and second, applying a 3D convex hull algorithm to these classified subsets to preserve concave features that standard hull methods would flatten.

## How it works
The method operates on volumetric data derived from silhouettes, using an octree to manage spatial structure and an initial MC surface to seed the convexity classification.

### Inputs and Outputs
*   **Inputs:** A set of thresholded silhouette images from multiple viewpoints; projection matrices for these viewpoints; an isovalue threshold for the initial Voting MC (VMC) step.
*   **Outputs:** A triangle mesh representing the 3D surface.

### Data Structures
1.  **Octree:** A hierarchical data structure where each node represents an octant of the 3D space.
    *   **Fields:** `is_intersection` (boolean), `children` (array of 8 octants or null), `vertices` (list of 3D coordinates).
    *   **Layout:** Root node covers the entire volume. Nodes are split into 8 sub-octants if classified as intersection.
2.  **Tree Table:** Stores connectivity information between clusters of vertices.
    *   **Fields:** `cluster_id`, `parent_cluster_id`, `child_cluster_ids`.
3.  **Local Convex Vertices Table:** Maps each identified local convex region to its constituent vertices.
    *   **Fields:** `local_hull_id`, `vertex_indices`.

### Steps

1.  **Initial Data Preparation (Octree Construction):**
    *   For each octant in the current level of the octree:
        *   Backproject the octant onto every silhouette image plane. The backprojection is approximated as a 2D rectangle [S1].
        *   If the rectangle intersects any silhouette in *any* view, classify the octant as `intersection`.
        *   If the rectangle intersects *no* silhouettes in *any* view, classify as `background` and remove (do not split).
        *   If classified as `intersection`, split into 8 sub-octants and repeat recursively until a minimum voxel size or depth is reached [S1].

2.  **Estimate Initial MC Vertices:**
    *   Generate an initial surface using Voting Marching Cubes (VMC).
    *   The VMC decision function determines if a vertex is outside:
        $$ \sum_{i=0}^{n} c_i(\theta_i, \vec{x}_{3d}) - v_{th} \le 0 $$
        where $n$ is the number of views, $c_i$ is the classification (1 if outside, 0 if inside) for view $i$, $\vec{x}_{3d}$ is the 3D position, and $v_{th}$ is the threshold ($0 \le v_{th} < n$) [S1].
    *   Extract the vertices from this initial MC surface. These serve as the seed points for convexity classification.

3.  **Local Convex Classification:**
    *   **Slicing:** Slice the octree and the MC surface along the z-axis.
        *   Define the 3D delta function:
            $$ \delta(x, y, z) = \begin{cases} 1 & \text{if } x = y = z = 0 \\ 0 & \text{otherwise} \end{cases} $$
        *   The $i$-th sliced data of an octree $S_{ioc}(m, n)$ is defined as:
            $$ S_{ioc}(m, n) = o(x, y, z)\delta(x - mT, y - nT, z - iT) $$
            where $o(x,y,z)$ is 1 if the octant contains a point, $T$ is the slicing interval, and $i,m,n$ are integer indices [S1].
        *   Quantize the octree slice to treat points from the same octant equally:
            $$ S_{iocq}[u, v] = \bigvee_{j,k=0}^{1} S_{ioc}(u + j, v + k) $$
            This results in a binary image plane where a nonzero point represents an octant [S1].
    *   **MC Slice Representation:** Create a binary image plane $S_{imcq}[u, v]$ for MC vertices. A value is 1 if an MC vertex is found within the spatial bounds $uT \le x < (u+1)T$, $vT \le y < (v+1)T$, and $iT \le z < (i+1)T$ [S1].
    *   **Classification:** Estimate cluster conditional probability density functions (PDFs) from every octree slice to classify the initial MC vertices into local convex regions. This step identifies which vertices belong to the same local convexity [S1].
    *   **Output:** Generate the `Tree Table` (cluster connections) and `Local Convex Vertices Table` [S1].

4.  **3D Hull-Based Surface Construction:**
    *   For each local convex region identified:
        *   If the region has multiple connections (e.g., 1:n or n:1 topology), divide it into $n$ separate 1:1 local convexities [S1].
        *   Apply a 3D convex hull algorithm (such as QuickHull or Graham Scan in 3D) to the vertices of the local convexity to generate the local surface triangles.
    *   **Aggregation:** Combine all local surfaces. Ensure connectivity by checking that each edge is traversed twice (once for each adjacent patch) to avoid dangling edges and holes, satisfying the property that the surface covers the object tightly [S1].

### Parameters
*   **Rotational Angle ($\theta$):** Set to 6 degrees in the experimental setup [S1].
*   **Number of Projection Matrices:** 60, corresponding to 60 image planes [S1].
*   **VMC Threshold ($v_{th}$):** $0 \le v_{th} < n$, where $n$ is the number of views. The specific value affects the initial surface quality [S1].

### Edge Cases and Pitfalls
*   **Concavity:** Standard convex hull algorithms fail on concave objects. This method mitigates this by local convexity classification, but if the classification fails (e.g., due to noisy silhouettes), concave regions may be incorrectly filled [S1].
*   **Dangling Edges:** If the surface is not closed, edges may be traversed only once. The aggregation step must check for this and ensure each edge is traversed twice [S1].
*   **Multiple Connections:** Local convexities with 1:n or n:1 connections must be explicitly divided into 1:1 convexities before hull construction. Failure to do so results in incorrect local surfaces [S1].
*   **Precision:** The quantization of octree slices ($S_{iocq}$) assumes that every four points in a slice come from the same octant. This relies on the slicing interval $T$ and the octree structure being aligned [S1].

## Operating characteristics
*   **Time Complexity:** Dominated by the octree construction ($O(N \log N)$ for $N$ voxels) and the 3D convex hull computation for each local region. The number of local regions depends on the object's complexity.
*   **Memory Complexity:** Requires storage for the octree, silhouette images, and the local convex vertices table. The octree can be large for high-resolution volumes.
*   **Strengths:** Handles concave shapes better than global convex hull methods; preserves surface details from the initial MC surface; robust to some noise via the voting mechanism.
*   **Limitations:** Computationally expensive due to octree construction and multiple hull computations; sensitive to the quality of the initial VMC surface; requires multiple views (silhouettes) for input.
*   **When to Use:** When reconstructing 3D objects from silhouettes where concavity is significant and standard MC or global hull methods fail.
*   **When Not to Use:** For real-time applications due to computational cost; when only a single view is available.

## Background
The method was proposed to address the limitations of 3D Delaunay Triangulation (DT) and Constrained Delaunay Triangulation (CDT), which are designed for convex shapes and struggle with concavity. It builds on [Marching Cubes Lookup and Configuration](2518-marching-cubes-lookup-and-configuration.md) by using MC to generate an initial surface, which is then refined using local convex hulls. The approach was introduced in a paper by [S1] in 2008, aiming to combine the tight fitting of hull methods with the concavity handling of local classification.
