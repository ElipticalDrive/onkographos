# Improved Marching Cubes with New Table and Displacement

Also called: Improved Macet, MC with displacement edge transform, MC with new table

## Overview
This method improves the worst-case triangle quality of the Marching Cubes (MC) algorithm by combining a modified lookup table that avoids specific edge groups responsible for poor triangles with a non-linear displacement of cut points on edges [S1]. It sets itself apart from standard MC by explicitly optimizing for triangle aspect ratio bounds rather than just topological correctness, and from methods like [Snap Marching Cubes](2181-snap-marching-cubes.md) by using a gain function for displacement rather than projection-based snapping [S1].

## How it works
The method operates on a structured 3D grid of scalar values. It produces a triangle mesh where vertices are displaced from their linear interpolation positions and connectivity is determined by a new lookup table.

### Data Structures
*   **Scalar Grid**: A 3D array $V$ of scalar values.
*   **New MC Table**: A lookup table mapping the 256 case indices to triangle configurations. The table is reformulated to exclude entries that utilize "edge group 2" (the group identified as responsible for the worst triangles) where possible [S1].
*   **Gain Function Parameter**: A scalar value $g = 0.3$ [S1].

### Steps
1.  **Case Index Calculation**: For each voxel, determine the case index $I$ by comparing the scalar values at the 8 vertices to the isovalue $T$. If $V_i \ge T$, the $i$-th bit is 1; otherwise, 0.
2.  **Edge Intersection Identification**: Identify which of the 12 edges of the voxel are intersected by the isosurface based on the sign changes of the vertex values.
3.  **Displacement Calculation**: For each intersected edge, calculate the intersection point. Instead of linear interpolation, apply a non-linear displacement using a gain function.
    *   Let the edge connect vertices $A$ and $B$ with scalar values $V_A$ and $V_B$.
    *   Let $t$ be the linear interpolation parameter: $t = \frac{T - V_A}{V_B - V_A}$.
    *   Apply the gain function to modulate the position. The source cites a "gain function described in [29]" with parameter $g=0.3$ [S1]. The function applies greater displacement closer to the endpoints. ### Pitfalls
*   **Edge Group 2**: It is not always possible to remove undesirable edge groups (specifically edge group 2) from the MC table cases. Some cases must always have at least one triangle from edge group 2, such as convex polygons [S1].
*   **Maximum Distance**: The maximum absolute distance to the isosurface does not change with displacement modulation because the cut point involved in the maximum distance is not affected by the operation [S1].
*   **Noisy Data**: In noisy datasets (e.g., Engine), the improvement in worst triangle quality is less substantial [S1].

## Operating characteristics
*   **Triangle Quality**: The quality of the worst triangle improved by at least an order of magnitude in three datasets (Silicium, Bonsai, Lobster) compared to the original MC table [S1].
*   **Comparison to Macet**: In Bonsai, Lobster, and Silicium, the improved Macet with the new table is closer to twice as better in worst triangle quality compared to old Macet with the old table [S1].
*   **Quality Bounds**: The minimum quality of transformed edge groups in Macet is 0.272 (edge group 2), corresponding to a triangle with a minimal internal angle of 18 degrees [S1].
*   **Overall Minimum Quality**: In all experiments, the minimum triangle quality was above 0.19 [S1].
*   **Comparison to State-of-the-Art**: Unlike methods by Schreiner et al., Dey and Levine, and Meyer et al., which report worst triangle quality from 0.02 to 0.4, this method retains the performance advantages and simplicity of MC [S1].
*   **Distance Error**: The maximum absolute distance to the isosurface remains nearly the same as the original MC table [S1].
*   **Limitations**: The method is intrinsically based on MC and cannot generate meshes that adapt to surface features such as curvature [S1].

## Background
*   **Origin**: The method is described in "Edge Groups: An Approach to Understanding the Mesh Quality of Marching Methods" [S1].
*   **Development**: The work identifies that one edge group is responsible for most of the worst triangles generated by MC. It reformulates the MC table entries to avoid this group and introduces a gain function for displacement [S1].
*   **Context**: It builds on the analysis of edge groups to measure quality bounds. It contrasts with works by Nielson (connection tables for locally functions) and extended tables for ambiguity, focusing instead on triangle quality [S1].
