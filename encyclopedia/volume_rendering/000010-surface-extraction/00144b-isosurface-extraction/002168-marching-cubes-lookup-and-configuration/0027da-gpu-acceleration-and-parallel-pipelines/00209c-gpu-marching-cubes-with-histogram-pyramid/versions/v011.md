# GPU Marching Cubes with Histogram Pyramid

Also called: GPU Marching Cubes with HistoPyramid, GPU Marching Cubes with HistoPyramid-style Compaction, GPU-MC, Histogram Pyramid Marching Cubes, OpenCL Marching Cubes

## Overview
GPU Marching Cubes with Histogram Pyramid is a parallel isosurface extraction method that uses a Histogram Pyramid (HP) to count and locate surface triangles without atomic operations or sorting [S1, unofficial]. It relies on the precomputed lookup tables from [Marching Cubes Lookup and Configuration](2518-marching-cubes-lookup-and-configuration.md) and follows the parallel execution model of [GPU Acceleration and Parallel Pipelines](4136-gpu-acceleration-and-parallel-pipelines.md) [S1, unofficial]. Unlike sibling methods that rely on global atomics or append buffers, this method precomputes exact output offsets via a hierarchical histogram, enabling lock-free writes to the final vertex buffer [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
- Scalar volume data (8-bit unsigned integer, e.g., `CL_R, CL_UNSIGNED_INT8`) [S1, unofficial].
- Isosurface threshold (`isolevel` or `isoValue`) [S1, unofficial][S2, unofficial].
- Grid dimensions (`sizeX`, `sizeY`, `sizeZ`) [S2, unofficial].

**Outputs:**
- A Vertex Buffer Object (VBO) containing triangle vertices and normals [S1, unofficial].
- Total triangle count (`totalSum`) [S1, unofficial].

### Data Structures
1. **Volume Data**: 3D texture or buffer of size `SIZE x SIZE x SIZE` (padded to power of two) [S1, unofficial].
2. **Histogram Pyramid (HP)**:
   - **Texture Path**: Series of 3D images [S1, unofficial].
     - Level 0: `CL_RGBA, CL_UNSIGNED_INT8`, size `SIZE/2` [S1, unofficial].
     - Level 1: `CL_R, CL_UNSIGNED_INT8`, size `SIZE/4` [S1, unofficial].
     - Levels 2-4: `CL_R, CL_UNSIGNED_INT16`, size halving each level (`SIZE/8`, `SIZE/16`, `SIZE/32`) [S1, unofficial].
     - Level 5+: `CL_R, CL_UNSIGNED_INT32`, size halving by 2 each level until 1 [S1, unofficial].
   - **Buffer Path**: Series of buffers (used if 3D texture writes are unsupported) [S1, unofficial].
     - Level 0: `char`, size `SIZE^3/8` [S1, unofficial].
     - Level 1: `char`, size `SIZE^3/64` [S1, unofficial].
     - Level 2: `short`, size `SIZE^3/512` [S1, unofficial].
     - Level 3: `short`, size `SIZE^3/4096` [S1, unofficial].
     - Level 4: `short`, size `SIZE^3/32768` [S1, unofficial].
     - Level 5+: `int`, size halving by 8 each level [S1, unofficial].
3. **Cube Indexes**: `char` buffer `cubeIndexesBuffer` of size `SIZE^3` storing 8-bit cube indices, copied to `cubeIndexesImage` for traversal [S1, unofficial].
4. **VBO**: Stores triangle data. Each triangle has 3 vertices. Each vertex has 3 floats for position and 3 floats for normal (24 bytes total). Size: `totalSum * 18 * sizeof(cl_float)` [S1, unofficial].
5. **Lookup Tables**:
   - `numVertsTable`: `uint[256]`, number of vertices per cube case [S2, unofficial].
   - `triTable`: `uint[256*16]`, edge indices for triangle vertices [S2, unofficial].

### Steps
1. **Input Preparation**:
   - Read raw volume data [S1, unofficial].
   - If step sizes (`stepSizeX`, `stepSizeY`, `stepSizeZ`) > 1, subsample the volume [S1, unofficial].
   - Pad the volume to the next power of two dimension (`SIZE`) with zeros [S1, unofficial]. Calculate `largestSize = max(sizeX, sizeY, sizeZ)` [S1, unofficial]. Find `i` such that $2^i \ge largestSize$ [S1, unofficial]. Set `SIZE = 2^i` [S1, unofficial]. Allocate `newVoxels` of size `SIZE^3` initialized to 0 [S1, unofficial]. Copy data from original `voxels` to `newVoxels` using index $x + y \cdot SIZE + z \cdot SIZE^2$ [S1, unofficial].

2. **Classify Voxels**:
   - Launch kernel `classifyCubesKernel` with work group `NDRange(SIZE, SIZE, SIZE)` [S1, unofficial].
   - For each voxel at `gridPos`, compute field values at 8 corners (`field0` to `field7`) using `computeValue` [S1, unofficial].
   - Calculate `cubeindex`:
     $$ cubeindex = \sum_{k=0}^{7} \mathbb{I}(field_k < isoValue) \cdot 2^k $$
   - Look up `numVerts = numVertsTable[cubeindex]` [S2, unofficial].
   - Store `numVerts` in `voxelVerts[i]` [S2, unofficial].
   - If `numVerts > 0`, set `voxelOccupied[i] = 1`, else `0` [S2, unofficial].
   - If using buffers, store `cubeindex` in `cubeIndexesBuffer` [S1, unofficial].

3. **Histogram Pyramid Construction**:
   - **Base Level**:
     - If textures: Kernel `constructHPLevelKernel` reads `images[0]` (voxel counts) and writes to `images[1]` [S1, unofficial]. Work group `NDRange(SIZE/2, SIZE/2, SIZE/2)` [S1, unofficial].
     - If buffers: Kernel `constructHPLevelCharCharKernel` reads `buffers[0]` and writes to `buffers[1]` [S1, unofficial]. Work group `NDRange(SIZE/2, SIZE/2, SIZE/2)` [S1, unofficial].
   - **Intermediate Levels**:
     - Iterate from level 1 to $\log_2(SIZE)-2$ [S1, unofficial].
     - If textures: Kernel `constructHPLevelKernel` reads `images[i]` and writes to `images[i+1]` [S1, unofficial]. Work group size halves each iteration [S1, unofficial].
     - If buffers: Use specific kernels for type transitions:
       - `constructHPLevelCharShortKernel` (char->short) [S1, unofficial].
       - `constructHPLevelShortShortKernel` (short->short) [S1, unofficial].
       - `constructHPLevelShortIntKernel` (short->int) [S1, unofficial].
       - Each step halves the grid dimensions [S1, unofficial].
   - **Top Level**: The top level contains 8 integers (sum[0] to sum[7]) representing the total triangle count [S1, unofficial].

4. **Triangle Count Retrieval**:
   - Read the top of the HistoPyramid (8 integers) [S1, unofficial].
   - Sum them to get `totalSum` [S1, unofficial].
   - If `totalSum == 0`, no triangles were extracted [S1, unofficial].

5. **VBO Allocation**:
   - Create a new VBO with size `totalSum * 18 * sizeof(cl_float)` [S1, unofficial].

6. **Triangle Compaction (HistoPyramid Traversal)**:
   - Call `histoPyramidTraversal(totalSum)` [S1, unofficial].
   - Launch kernel `traverseHPKernel` [S1, unofficial].
   - Global work size: `sum + 64 - (sum - 64*(sum / 64))` (next multiple of 64) [S1, unofficial].
   - Local work size: 64 [S1, unofficial].
   - Traverse the pyramid from top to bottom to find triangle indices and fill the VBO with vertex data [S1, unofficial].
   - Arguments: `rawData` (or skipped in texture mode), `cubeIndexesImage`, HP levels, VBO buffer, `isolevel`, `sum` [S1, unofficial].

7. **Rendering**:
   - Set up OpenGL matrices (projection, modelview) [S1, unofficial].
   - Apply translation, rotation, and scaling [S1, unofficial].
   - Bind VBO [S1, unofficial].
   - Set vertex pointer (3 floats, stride 24, offset 0) and normal pointer (3 floats, stride 24, offset 12) [S1, unofficial].
   - Draw triangles using `glDrawArrays(GL_TRIANGLES, 0, totalSum*3)` [S1, unofficial].

### Pseudocode
```python
def gpu_marching_cubes_histogram_pyramid(volume, isolevel):
    # 1. Input Preparation
    size_x, size_y, size_z = len(volume), len(volume[0]), len(volume[0][0])
    largest_size = max(size_x, size_y, size_z)
    size = 1
    while size < largest_size:
        size *= 2
    
    # Pad volume to power of two
    padded_volume = [[[0 for _ in range(size)] for _ in range(size)] for _ in range(size)]
    for x in range(size_x):
        for y in range(size_y):
            for z in range(size_z):
                padded_volume[x][y][z] = volume[x][y][z]

    # 2. Classify Voxels
    num_voxels = size * size * size
    voxel_occupied = [0] * num_voxels
    cube_indexes = [0] * num_voxels
    occupied_count = 0
    for i in range(num_voxels):
        # Simulate field values at 8 corners
        field_vals = [padded_volume[i // size // size][i // size % size][i % size]] * 8
        cubeindex = 0
        for k in range(8):
            if field_vals[k] < isolevel:
                cubeindex += (1 << k)
        cube_indexes[i] = cubeindex
        num_verts = numVertsTable[cubeindex]
        if num_verts > 0:
            voxel_occupied[i] = 1
            occupied_count += 1

    def empty_mesh():
        return [], 0

    if occupied_count == 0:
        return empty_mesh()

    # 3. Histogram Pyramid Construction
    hp_levels = []
    base_level = [numVertsTable[cube_indexes[i]] for i in range(num_voxels)]
    hp_levels.append(base_level)
    current_level_data = base_level
    current_size = size
    while current_size > 1:
        next_size = current_size // 2
        next_level = [0] * (next_size ** 3)
        for x in range(next_size):
            for y in range(next_size):
                for z in range(next_size):
                    s = 0
                    for dx in range(2):
                        for dy in range(2):
                            for dz in range(2):
                                idx = (x * 2 + dx) * next_size * next_size + (y * 2 + dy) * next_size + (z * 2 + dz)
                                s += current_level_data[idx]
                    next_level[x * next_size * next_size + y * next_size + z] = s
        hp_levels.append(next_level)
        current_level_data = next_level
        current_size = next_size

    # 4. Triangle Count Retrieval
    def read_hp_top(levels):
        return sum(levels[-1])

    total_sum = read_hp_top(hp_levels)
    if total_sum == 0:
        return empty_mesh()

    # 5. VBO Allocation
    def allocate_vbo(size_bytes):
        return [0.0] * (size_bytes // 4)

    vbo = allocate_vbo(total_sum * 18 * 4)

    # 6. Triangle Compaction (Traversal)
    # The traversal kernel maps each triangle to a VBO slot using the HP offsets.
    # Global work size is the next multiple of 64.
    global_work_size = total_sum + 64 - (total_sum - 64 * (total_sum // 64))
    # Kernel launches with local size 64, traverses hp_levels, and writes to vbo.
    # For each triangle index t in 0..total_sum-1:
    #   offset = compute_offset_from_hp(hp_levels, t)
    #   vbo[offset * 18 : offset * 18 + 18] = triangle_vertices[t]
    # (Implementation details omitted for brevity; follows traverseHPKernel logic [S1, unofficial])

    # 7. Rendering
    # Bind VBO, set vertex pointer (stride 24, offset 0) and normal pointer (stride 24, offset 12).
    # Draw triangles using glDrawArrays(GL_TRIANGLES, 0, total_sum * 3).
    return vbo, total_sum
```

### Parameters
- `isolevel`: Threshold value for surface extraction. Default 51. Normalized to [0, 1] by dividing by 255.0f for display [S1, unofficial].
- `stepSizeX`, `stepSizeY`, `stepSizeZ`: Subsampling factors. Default 1 [S1, unofficial].
- `SIZE`: Dimension of the cubic voxel grid, always a power of two. Passed to OpenCL kernel via `-DSIZE=<value>` [S1, unofficial].
- `scalingFactor`: 3D vector used to scale the volume during rendering. Calculated as `spacing * 1.5f / size` [S1, unofficial].

### Edge Cases and Pitfalls
- **Power of Two Requirement**: Volume dimensions must be powers of two. If not, pad with zeros [S1, unofficial].
- **NVIDIA GPU Limitation**: Lack of 3D texture write support on NVIDIA GPUs requires a slower version using regular buffers and morton codes [S1, unofficial].
- **Image Size Constraint**: OpenGL/OpenCL images cannot be 1x1x1. If buffer size becomes 1 during HP construction, force it to 2 [S1, unofficial].
- **Empty Volume**: If no voxels are active, return early with `successful = false` and `num_resultVertices = 0` [S2, unofficial].
- **Grid Dimension Limit**: CUDA grid dimensions are limited to 65535. If `numVoxels` exceeds this, adjust launch configuration: `grid.x = 32768`, `grid.y = grid.x / 32768` [S2, unofficial].

## Operating characteristics
- **Time Complexity**: $O(N)$ for classification and HP construction, where $N$ is the number of voxels. Traversal is $O(T)$, where $T$ is the number of triangles [S1, unofficial].
- **Memory Complexity**: $O(N)$ for volume and HP storage. VBO size is $O(T)$ [S1, unofficial].
- **Performance**: Faster than atomic-based methods due to lock-free writes. Slower on NVIDIA GPUs due to buffer fallback [S1, unofficial].
- **Strengths**: No atomic operations, no sorting, efficient memory usage [S1, unofficial].
- **Limitations**: Requires power-of-two dimensions, NVIDIA GPU performance penalty [S1, unofficial].

## Background
Originated from Dyken et al. (2008) "High-speed marching cubes using histopyramids" [S2, unofficial]. Implemented in OpenCL and OpenGL by Erik Smistad [S1, unofficial]. Further developed in the FAST framework [S1, unofficial].
