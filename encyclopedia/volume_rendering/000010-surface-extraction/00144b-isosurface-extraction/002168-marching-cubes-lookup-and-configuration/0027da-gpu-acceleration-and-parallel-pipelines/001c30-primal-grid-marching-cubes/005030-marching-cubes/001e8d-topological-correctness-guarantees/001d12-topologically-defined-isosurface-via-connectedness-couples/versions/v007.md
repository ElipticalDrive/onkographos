# Topologically Defined Isosurface via Connectedness Couples

Also called: MC with (alpha, lambda) couples, Marching-Cubes with topological constraints

## Overview
This method extracts a topologically correct isosurface from a binary volumetric image by enforcing valid **connectedness couples** $(\alpha, \lambda)$ between foreground and background voxels, ensuring the resulting surface is a closed, oriented manifold without singularities or self-crossings [S1]. Unlike standard Marching Cubes which may produce ambiguous or non-manifold geometries on saddle faces, this approach defines the local triangulation based on the global connectivity constraints of the input data, allowing for $O(s)$ surface tracking complexity rather than the $O(n^3)$ voxel traversal of naive implementations [S1].

## How it works
The method constructs the isosurface as the canonical embedding of a **complete graph** $G_\lambda(I)$ derived from the binary image $I$. This graph is formed by aggregating local graphs from all $8$-cubes (voxels) in the volume. The topology is guaranteed by restricting the extraction to valid connectedness couples, where $\alpha$ defines the foreground connectivity and $\lambda$ defines the background connectivity [S1].

### Inputs and Outputs
*   **Input:** A binary volumetric image $I$ of size $n \times n \times n$.
*   **Output:** A triangulated surface mesh representing the isosurface $\Sigma_{\alpha,\lambda}(I)$.

### Data Structures
1.  **Local Configuration Table:** A precomputed lookup table for each of the 256 possible voxel configurations. There are four such tables, one for each valid connectedness couple: $(26, 6)$, $(18, 6)$, $(6, 26)$, and $(6, 18)$ [S1].
2.  **Complete Graph $G_\lambda(I)$:** An oriented two-dimensional combinatorial manifold without boundary, composed of oriented loops representing the surface edges [S1].
3.  **Local Triangulated Manifold $S_\lambda(C_8)$:** The subdivision of the local graph for a single cube $C_8$, defined by cases based on $\alpha$ and adjacency properties [S1].

### Valid Connectedness Couples
A pair $(\alpha, \lambda)$ is valid if it satisfies specific adjacency constraints that prevent topological singularities. The valid couples are:
*   $(\alpha=26, \lambda=6)$
*   $(\alpha=18, \lambda=6)$
*   $(\alpha=6, \lambda=26)$
*   $(\alpha=6, \lambda=18)$ [S1]

### Algorithm Steps

#### 1. Precomputation of Local Tables
For each valid connectedness couple, precompute the triangulation for all 256 voxel configurations using the `Build-Local_Surface` procedure [S1].

#### 2. Surface Extraction (Global)
The global surface is built by traversing the volume and assembling the local manifolds. To achieve optimal performance, the complete graph $G_\lambda(I)$ is constructed using surface tracking, which identifies surfels (surface elements) and their adjacencies [S1].

#### 3. Local Triangulation (`Build-Local_Surface`)
For a given voxel configuration $C$ and connectivity $\alpha$, the local surface is constructed as follows [S1]:

1.  Initialize edge set $E \leftarrow \emptyset$.
2.  For all inner 6-faces $F$ of $C$:
    *   Extract edges $E_F \leftarrow \text{Extract\_edges}(F, g, 6)$.
    *   $E \leftarrow E \cup E_F$.
3.  Extract loops $L \leftarrow \text{Extract\_loops}(E)$.
4.  Compute the convex hull $H \leftarrow \text{Convex\_Hull}(\text{get\_vertices}(E) \cup \text{get\_1-voxels}(C))$.
5.  While $L$ contains a loop of length $> 3$:
    *   Remove a loop $L$ of length $> 3$ from $L$. Let $L = (a_1, \dots, a_k)$.
    *   Initialize `exit` $\leftarrow$ false, $i \leftarrow 1$, $j \leftarrow i + 2$.
    *   Repeat:
        *   If the chord $(a_i, a_j)$ is inside $H$:
            *   `exit` $\leftarrow$ true.
        *   Else:
            *   $j \leftarrow j + 1$.
            *   If $j = k$:
                *   $i \leftarrow i + 1$.
                *   $j \leftarrow i + 2$.
    *   Until `exit` is true.
    *   Insert subdivided loop $(a_1, \dots, a_i, a_j, \dots, a_k)$ into $L$.
    *   Insert chord loop $(a_i, \dots, a_j)$ into $L$.
6.  If $C$ has **strict 26-adjacency** and $\alpha = 26$:
    *   Replace the current loops with special loops generated by $\text{build\_special\_loops\_26-adj}(L)$ [S1].
    *   [G] If $\alpha = 18$, the local graph is not modified in this case.
7.  Return the triangulated manifold $S_\lambda(C_8)$ defined by the final loops [S1].

### Pseudocode

```python
def build_local_surface(configuration: Config, alpha: int) -> TriangulatedManifold:
    """
    Computes the local triangulated manifold for a voxel configuration.
    
    Args:
        configuration: The 8-cube voxel configuration (binary values at 8 vertices).
        alpha: Foreground connectivity (6, 18, or 26).
        
    Returns:
        A set of triangles forming the local surface S_lambda(C8).
    """
    # 1. Extract edges from inner 6-faces
    E = set()
    for face in configuration.inner_6_faces:
        EF = extract_edges(face, grid=6, connectivity=6)
        E.update(EF)
        
    # 2. Extract loops from edges
    L = extract_loops(E)
    
    # 3. Compute convex hull of relevant vertices
    # get_vertices(E) returns endpoints of edges in E
    # get_1-voxels(C) returns foreground voxels in the configuration
    vertices = get_vertices(E)
    voxels = get_1_voxels(configuration)
    H = convex_hull(vertices.union(voxels))
    
    # 4. Subdivide long loops
    while L.contains_loop_with_length_greater_than(3):
        L_long = L.remove_loop_with_length_greater_than(3)
        # L_long is an ordered set (a1, ..., ak)
        k = len(L_long)
        exit_flag = False
        i = 1
        j = i + 2
        
        while not exit_flag:
            # Check if chord (ai, aj) is inside the convex hull H
            if is_chord_inside_hull(L_long[i], L_long[j], H):
                exit_flag = True
            else:
                j += 1
                if j == k:
                    i += 1
                    j = i + 2
        
        # Insert subdivided loop and chord
        # Loop 1: a1...ai, aj...ak
        loop1 = L_long[0:i] + L_long[j-1:] # Adjust indices for 0-based or 1-based as needed
        # Loop 2: ai...aj
        loop2 = L_long[i-1:j] # Adjust indices
        
        L.insert(loop1)
        L.insert(loop2)
        
    # 5. Handle strict 26-adjacency special case
    if configuration.has_strict_26_adjacency() and alpha == 26:
        L = build_special_loops_26_adj(L)
        
    # 6. Convert loops to triangles
    # The canonical embedding of the oriented manifold defined by L
    triangles = loops_to_triangles(L)
    return triangles

def is_chord_inside_hull(p1, p2, hull):
    """
    Checks if the line segment (p1, p2) lies within the convex hull H.
    [G] Implementation detail: This typically involves checking if the midpoint
    or all points on the segment satisfy the half-space inequalities of H.
    """
    # Placeholder for geometric containment test
    return hull.contains_segment(p1, p2)
```

### Parameters and Edge Cases
*   **Strict 26-adjacency:** If a configuration exhibits strict 26-adjacency (foreground voxels connected via face, edge, or vertex sharing in a specific dense pattern) and $\alpha=26$, the standard loop subdivision is replaced by `build_special_loops_26-adj` [S1]. If $\alpha=18$, this case is handled by the standard subdivision [S1].
*   **Precision:** The method relies on the binary nature of the input. Floating-point errors in thresholding the input volume before binarization can lead to invalid connectedness couples [S1].
*   **Complexity:** The precomputation is constant. The extraction complexity is $O(s)$, where $s$ is the number of surfels (typically $O(n^2)$), significantly faster than the $O(n^3)$ complexity of standard voxel-by-voxal Marching Cubes [S1].

## Operating characteristics
*   **Time Complexity:** $O(s)$ for surface extraction, where $s$ is the number of surfels. Precomputation is $O(1)$ (256 configurations $\times$ constant work) [S1].
*   **Memory Complexity:** $O(n^3)$ for storing the input volume. The lookup tables require constant memory (4 tables of 256 entries each) [S1].
*   **Strengths:** Guarantees a topologically correct, closed, oriented manifold without singularities or self-crossings. Compatible with standard Marching Cubes optimizations [S1].
*   **Limitations:** Requires the input to be binarized and to satisfy valid connectedness couples. May not be suitable for direct extraction from continuous scalar fields without careful thresholding [S1].
*   **When to use:** Ideal for binary segmentation results, particularly in medical imaging (e.g., CT scans) where topological integrity is critical [S1].
*   **When not to use:** Not suitable for direct isosurface extraction from continuous scalar volumes without a binarization step, or when the data does not conform to the valid connectedness couples [S1].

## Background
This method was introduced by [S1] as a formally proved approach for extracting consistent isosurfaces from volumetric images. It establishes the identity between the underlying graph of the isosurface and the surfel-adjacency graph of the digital surface. The work builds on the theory of digital topology and combinatorial manifolds, specifically addressing the ambiguity problem in Marching Cubes by enforcing global connectivity constraints [S1]. It has been implemented and validated with synthetic data and is used in the segmentation of medical images, such as CT scans with resolutions like $256 \times 256 \times 113$ [S1].
