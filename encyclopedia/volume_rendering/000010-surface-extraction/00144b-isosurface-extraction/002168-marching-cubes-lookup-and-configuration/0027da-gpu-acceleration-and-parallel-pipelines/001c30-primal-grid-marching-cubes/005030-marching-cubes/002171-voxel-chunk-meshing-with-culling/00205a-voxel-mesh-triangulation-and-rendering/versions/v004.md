# Voxel Mesh Triangulation and Rendering

Also called: ChunkMesher, Dynamic Voxel Mesh Triangulation, Marching Cubes Triangulation, Marching Cubes Voxel Mesher, MarchingCubes::triangulateFieldGPU, VoxelMeshProcessor

## Overview
This method generates a triangle mesh from a 3D voxel grid of density values using the Marching Cubes algorithm, optimized for GPU execution [S1, S3, unofficial]. It converts a scalar field into a surface by iterating over internal cubes, determining intersection cases via a lookup table, and interpolating vertex positions on cube edges [S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D voxel grid of density values (scalar field), a cutoff threshold ($m_{Cutoff}$), a transformation matrix, and grid dimensions ($m_{Samples}.x, m_{Samples}.y, m_{Samples}.z$) [S1, S3, unofficial].
*   **Output:** A triangle mesh consisting of vertices (position, normal, UV) and an index buffer [S3, unofficial].

**Data Structures:**
*   **Density Grid:** A 1D array or SSBO (Shader Storage Buffer Object) storing density values [S1, S3, unofficial]. The sample ID for a 3D position $(x, y, z)$ is mapped to a 1D index using:
    $$ id = y + (x \cdot m_{Samples}.y) + (z \cdot m_{Samples}.y \cdot m_{Samples}.x) $$
    [S3, unofficial]
*   **Vertex Buffer:** A flat array of floats [S3, unofficial]. Each vertex occupies 8 floats: indices 0–2 for position $(x, y, z)$, indices 3–5 for normal $(n_x, n_y, n_z)$, and indices 6–7 for UV $(u, v)$ [S3, unofficial].
*   **Lookup Tables:**
    *   `triTable[256][16]`: Maps the 256 possible cube cases (bitmasks) to a list of triangle edge indices. Entries are terminated by -1 [S3, unofficial].
    *   `sidesTable[12][2]`: Maps an edge index (0–11) to the two corner indices (0–7) that define that edge [S3, unofficial].
*   **Vertex Map:** A hash map or lookup table used for vertex deduplication [S3, unofficial]. Keys are generated from edge corner indices to ensure consistent ordering (e.g., $id_A < id_B$) [S3, unofficial].

**Parameters:**
*   **$m_{Cutoff}$:** The density threshold. Samples with density $< m_{Cutoff}$ are considered "inside" the surface (bit set in caseID) [S3, unofficial].
*   **$\delta$:** Finite difference step size for gradient calculation. Value: $127 \cdot 0.05$ [S3, unofficial].
*   **Transformation Matrix:** A $4 \times 4$ matrix applied to mesh vertices [S1, unofficial]. Calculated as:
    $$ M = \text{translate}(\text{minPoint}) \cdot \text{scale}(\text{cellSize}) \cdot \text{translate}(-0.5 \cdot \text{cellSize}) $$
    [S1, unofficial]

**Algorithm Steps:**
1.  **Initialization:** Reserve vertex buffer capacity equal to $m_{Samples}.x \cdot m_{Samples}.y \cdot m_{Samples}.z \cdot 5 \cdot 3 \cdot 8$ floats [S3, unofficial]. Initialize an empty vertex map and index list [G].
2.  **Loop over Internal Cubes:** Iterate $z$ from 1 to $m_{Samples}.z - 2$, $y$ from 1 to $m_{Samples}.y - 2$, and $x$ from 1 to $m_{Samples}.x - 2$ [S3, unofficial]. This skips boundary cubes to avoid out-of-bounds access [S3, unofficial].
3.  **Sample Corners:** For the current cube at $(x, y, z)$, define 8 corner positions relative to grid indices $(lx, ly, lz)$ where $lx=x-1, ly=y-1, lz=z-1$ [S3, unofficial]. The corners are ordered as:
    *   0: $(lx, ly, lz+1)$
    *   1: $(lx+1, ly, lz+1)$
    *   2: $(lx+1, ly, lz)$
    *   3: $(lx, ly, lz)$
    *   4: $(lx, ly+1, lz+1)$
    *   5: $(lx+1, ly+1, lz+1)$
    *   6: $(lx+1, ly+1, lz)$
    *   7: $(lx, ly+1, lz)$
    [S3, unofficial]
    Retrieve the density value for each corner using the sample ID mapping [S3, unofficial].
4.  **Compute Case ID:** Initialize `caseID = 0` [S3, unofficial]. Iterate $i$ from 0 to 7. If `cornerDensityValues[i] < m_Cutoff`, set bit $i$:
    $$ caseID \ |= \ (1 \ll i) $$
    [S3, unofficial]
5.  **Skip Empty Cases:** If `caseID` is 0 (all corners inside) or 255 (all corners outside), skip to the next cube [S3, unofficial].
6.  **Generate Triangles:** Iterate through `triTable[caseID]` in steps of 3 [S3, unofficial]. For each triplet of edge indices:
    a. If the edge index is -1, break the loop [S3, unofficial].
    b. For each edge index in the triplet, determine the two corner positions defining that edge using `sidesTable[edge_index]` [S3, unofficial].
    c. Call `GetOrAddVertexIndex` for each corner to interpolate the vertex position and normal [S3, unofficial].
    d. Add the three resulting vertex indices to the index list [S3, unofficial].
7.  **Vertex Interpolation (`GetOrAddVertexIndex`):**
    a. Given two corners with positions $pos_A, pos_B$ and densities $val_A, val_B$:
    b. Calculate interpolation parameter:
        $$ t = \frac{m_{Cutoff} - val_A}{val_B - val_A} $$
        [S3, unofficial]
    c. Calculate interpolated position:
        $$ pos = pos_A + t \cdot (pos_B - pos_A) $$
        [S3, unofficial]
    d. Calculate normal using central differences:
        $$ dx = \text{GetDensity}(worldPos + (\delta, 0, 0)) - \text{GetDensity}(worldPos - (\delta, 0, 0)) $$
        $$ dy = \text{GetDensity}(worldPos + (0, \delta, 0)) - \text{GetDensity}(worldPos - (0, \delta, 0)) $$
        $$ dz = \text{GetDensity}(worldPos + (0, 0, \delta)) - \text{GetDensity}(worldPos - (0, 0, \delta)) $$
        $$ normal = \text{normalize}(-vec3(dx, dy, dz)) $$
        [S3, unofficial]
    e. Check if the vertex already exists in the vertex map (using a key derived from the edge corners) [S3, unofficial]. If not, push the vertex (position, normal, UV 0,0) to the buffer, store the index in the map, and return it [S3, unofficial].

**Pseudocode:**
```python
import math

def triangulate_voxel_chunk(density_grid, samples_x, samples_y, samples_z, cutoff, cell_size, min_point):
    """
    Generates a triangle mesh from a voxel density grid using Marching Cubes.
    
    Args:
        density_grid: 1D array of density values.
        samples_x, samples_y, samples_z: Dimensions of the voxel grid.
        cutoff: Density threshold for surface extraction.
        cell_size: Size of each voxel in world units.
        min_point: World position of the grid's minimum corner.
        
    Returns:
        vertices: List of [x, y, z, nx, ny, nz, u, v] floats.
        indices: List of integer vertex indices.
    """
    vertices = []
    indices = []
    vertex_map = {}
    
    # Standard Marching Cubes lookup tables (Resources::triTable and Resources::sidesTable)
    # triTable[case_id] returns a list of edge indices, terminated by -1
    # sidesTable[edge_idx] returns (corner_idx_1, corner_idx_2)
    # These are standard constants provided by the algorithm implementation.
    tri_table = {} # Populated with standard Marching Cubes tables
    sides_table = {} # Populated with standard Marching Cubes tables
    
    def get_density(x, y, z):
        # Evidence: id = position.y + (position.x * m_Samples.y) + (position.z * m_Samples.y * m_Samples.x)
        idx = y + (x * samples_y) + (z * samples_y * samples_x)
        return density_grid[idx]
    
    def grid_to_world(gx, gy, gz):
        return [
            min_point[0] + gx * cell_size,
            min_point[1] + gy * cell_size,
            min_point[2] + gz * cell_size
        ]

    def calculate_normal(world_pos):
        delta = 127 * 0.05
        # Evidence: dx = GetDensity(worldPos + (delta,0,0)) - GetDensity(worldPos - (delta,0,0))
        # We approximate grid coordinates for sampling
        def sample_at_world(wx, wy, wz):
            gx = (wx - min_point[0]) / cell_size
            gy = (wy - min_point[1]) / cell_size
            gz = (wz - min_point[2]) / cell_size
            return get_density(round(gx), round(gy), round(gz))
            
        dx = sample_at_world(world_pos[0] + delta, world_pos[1], world_pos[2]) - sample_at_world(world_pos[0] - delta, world_pos[1], world_pos[2])
        dy = sample_at_world(world_pos[0], world_pos[1] + delta, world_pos[2]) - sample_at_world(world_pos[0], world_pos[1] - delta, world_pos[2])
        dz = sample_at_world(world_pos[0], world_pos[1], world_pos[2] + delta) - sample_at_world(world_pos[0], world_pos[1], world_pos[2] - delta)
        length = math.sqrt(dx*dx + dy*dy + dz*dz)
        if length == 0:
            return [0, 0, 1]
        return [-dx/length, -dy/length, -dz/length]

    def get_or_add_vertex(c1_grid, d1, c2_grid, d2):
        # Evidence: Vertex deduplication relies on consistent ordering of edge endpoints (idA < idB)
        key = tuple(sorted([c1_grid, c2_grid]))
        
        if key in vertex_map:
            return vertex_map[key]
        
        # Convert grid corners to world positions
        p1 = grid_to_world(c1_grid[0], c1_grid[1], c1_grid[2])
        p2 = grid_to_world(c2_grid[0], c2_grid[1], c2_grid[2])
        
        # Interpolate position
        if d2 == d1:
            t = 0.0
        else:
            t = (cutoff - d1) / (d2 - d1)
            
        pos = [
            p1[0] + t * (p2[0] - p1[0]),
            p1[1] + t * (p2[1] - p1[1]),
            p1[2] + t * (p2[2] - p1[2])
        ]
        
        # Calculate normal
        normal = calculate_normal(pos)
        
        # Create vertex (pos + normal + uv)
        vertex = pos + normal + [0.0, 0.0]
        
        # Store
        v_idx = len(vertices)
        vertices.append(vertex)
        vertex_map[key] = v_idx
        
        return v_idx

    # Iterate over internal cubes only
    for z in range(1, samples_z - 1):
        for y in range(1, samples_y - 1):
            for x in range(1, samples_x - 1):
                # Define 8 corners relative to (x-1, y-1, z-1)
                lx, ly, lz = x - 1, y - 1, z - 1
                corners = [
                    (lx, ly, lz + 1), (lx + 1, ly, lz + 1), (lx + 1, ly, lz), (lx, ly, lz),
                    (lx, ly + 1, lz + 1), (lx + 1, ly + 1, lz + 1), (lx + 1, ly + 1, lz), (lx, ly + 1, lz)
                ]
                
                # Get densities
                densities = [get_density(c[0], c[1], c[2]) for c in corners]
                
                # Compute caseID
                case_id = 0
                for i in range(8):
                    if densities[i] < cutoff:
                        case_id |= (1 << i)
                
                # Skip empty cases
                if case_id == 0 or case_id == 255:
                    continue
                
                # Process triangles
                edge_list = tri_table.get(case_id, [])
                for i in range(0, len(edge_list), 3):
                    edge1, edge2, edge3 = edge_list[i], edge_list[i+1], edge_list[i+2]
                    if edge1 == -1:
                        break
                    
                    vertex_indices = []
                    for edge_idx in (edge1, edge2, edge3):
                        c1_idx, c2_idx = sides_table[edge_idx]
                        v_idx = get_or_add_vertex(corners[c1_idx], densities[c1_idx], 
                                                  corners[c2_idx], densities[c2_idx])
                        vertex_indices.append(v_idx)
                    
                    indices.extend(vertex_indices)

    return vertices, indices
```

**Edge Cases and Pitfalls:**
*   **Boundary Access:** The algorithm loops from index 1 to $m_{Samples}-2$ to avoid accessing neighbors outside the grid bounds [S3, unofficial].
*   **Vertex Deduplication:** Consistent ordering of edge endpoints (e.g., $id_A < id_B$) is required to generate the same hash key regardless of edge direction [S3, unofficial].
*   **Precision:** Integer coordinates are used for grid indexing, but floating-point interpolation is used for vertex positions [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of voxels, as each internal cube is processed once [S3, unofficial].
*   **Memory Complexity:** $O(V)$ for vertex storage, where $V$ is the number of generated vertices [G].
*   **Performance:** GPU acceleration is typical, using SSBOs for grid data and compute shaders for parallel cube processing [S1, unofficial].
*   **Strengths:** Produces smooth, organic surfaces; handles complex topology better than face-culling [S3, unofficial].

## Background
The method originates from the Marching Cubes algorithm by Lorensen and Cline (1987) [S3, unofficial]. It has been adapted for voxel-based games and simulations, with implementations like `VoxelFragmentML` and `Forgex_engine` optimizing it for GPU execution and dynamic voxel updates [S1, S3, unofficial].
