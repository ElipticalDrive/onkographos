# Cubical Marching Squares

Also called: CMS

## Overview
Cubical Marching Squares (CMS) is an adaptive surface extraction method that converts 3D Hermite data into a polygonal mesh by unfolding each cube into six 2D faces, applying Marching Squares to generate isocurves, and reconnecting these segments in 3D [S1]. It eliminates inter-cell dependency and crack patching by sampling sharp features on faces, allowing for consistent adaptive subdivision without the edge-flipping artifacts found in methods like Edge Matching Cubes (EMC) [S1].

## How it works
**Inputs and Outputs**
*   **Input:** Hermite data $H$, defined on a uniform grid of resolution $n_k \times n_k \times n_k$. Each edge of the grid is tagged with exact intersection points (sample points) and their corresponding normals (sample normals) [S1].
*   **Output:** A triangle mesh representing the isosurface [S1].

**Data Structures**
*   **Adaptive Signed Octree:** Built from a coarse base grid. Nodes represent cells or faces.
    *   **Leaf Cell:** A cell with no subcells.
    *   **Leaf Face:** A face with no subfaces.
    *   **Transition Face:** A face shared by two cells subdivided at different levels.
*   **Segment:** A line segment on a face connecting two sample points.
*   **Component:** A closed loop of segments within a cell.

**Parameters**
*   $n_0$: Base grid resolution exponent. The base grid $B$ is $n_0 \times n_0 \times n_0$. Typical value: 8 [S1].
*   $k$: Maximal level of subdivision. Finest resolution is $n_k = 2^k \cdot n_0$ [S1].

**Algorithm Steps**

1.  **Initialize Base Grid:** Create a uniform grid $B$ of size $n_0 \times n_0 \times n_0$ [S1].
2.  **Build Adaptive Octree:** For each cell $c$ in $B$, call `SUBDIVIDECELL(H, c)` [S1].
    *   **Subdivision Condition 1 (Edge Ambiguity):** Subdivide if any edge of the cell contains more than one sample point [S1].
    *   **Subdivision Condition 2 (Complexity Heuristic):** Subdivide if the maximal spanning angle between any pair of sample normals inside the cell exceeds a predefined threshold [S1].
    *   **Subdivision Process:** Subdivide faces first into four subfaces. Record relationships between subcells and subfaces. Stop if level $k$ is exceeded [S1].
3.  **Generate Segments:** For each leaf face $f$, call `GENERATESEGMENT(f)` [S1]. For non-leaf faces, segments are the union of segments of their subfaces [S1].
    *   **Lookup:** Check vertex sign patterns against the Marching Squares lookup table [S1].
        *   Case 0: No segments.
        *   Cases 1, 2: One segment.
        *   Case 3: Two segments (Face Ambiguity) [S1].
    *   **Resolve Face Ambiguity (Case 3):** If two segments exist, call `RESOLVEFACEAMBIGUITY(f)` [S1].
        *   Detect sharp features on potential segments. A sharp feature is detected if the angle between the two normals at the segment's endpoints is large enough [S1].
        *   Choose the assignment where sharp features do NOT overlap. Overlapping features imply self-intersection, which is invalid for volume data [S1].
    *   **Tag Sharp Features:** For each resulting segment, if a sharp feature exists, tag the segment and store the feature position [S1].
4.  **Extract Surface:** For each leaf cell $c$, call `EXTRACTSURFACE(c)` [S1].
    *   **Collect Segments:** Gather all segments from the cell's six faces using `GETSEGMENT(fi)` for each face $f_i$ [S1].
    *   **Trace Components:** Call `TRACECOMPONENTS(l)` to group segments into circles (components). Start from an edge and sequentially find the next edge sharing an endpoint [S1].
    *   **Internal Ambiguity Check:** Check if the set of components $O$ has internal ambiguity using `HasInternalAmbiguity(O)` [S1].
        *   If yes, call `RESOLVEINTERNALAMBIGUITY(O)`. This involves checking if cone-like volumes formed around 3D sharp features of two components overlap [S1].
        *   If no, proceed to triangulation [S1].
    *   **Sample 3D Sharp Features:** For each component, solve $[n_i]^T p = [n_i s_i]$ for $p$ using Singular Value Decomposition (SVD), where $s_i$ is the sample point location, $n_i$ is the sample normal, and $p$ is the sharp feature location [S1].
    *   **Triangulation:**
        *   If a component has a sharp feature $p$, create a triangle fan centered at $p$ using vertices $v_1 \dots v_n$: triangles $pv_1v_2, pv_2v_3, \dots, pvn-1vn, pvnv_1$ [S1].
        *   If no sharp feature exists, calculate the average point of all sample points on the component and use it as the center for the triangle fan [S1].

**Pseudocode**

```python
def CubicalMarchingSquares(HermiteData H):
    # Stage 1: Build Adaptive Octree
    B = InitializeBaseGrid(n0=8)
    for c in B:
        SubdivideCell(H, c)

    # Stage 2: Generate Segments for Faces
    for f in LeafFaces():
        GenerateSegment(f)

    # Stage 3: Extract Surface for Cells
    for c in LeafCells():
        ExtractSurface(c)

def SubdivideCell(H, c):
    if c.level >= k:
        return
    
    # Condition 1: Edge Ambiguity
    if HasEdgeAmbiguity(c):
        SubdivideFaces(c)
        return

    # Condition 2: Complexity Heuristic
    if MaxSpanningAngle(c) > threshold:
        SubdivideFaces(c)
        return

def SubdivideFaces(c):
    for f in c.faces:
        f.subdivide()
    c.subdivide()

def GenerateSegment(f):
    # Non-leaf faces inherit segments from subfaces
    if not f.is_leaf():
        f.segments = UnionOfSubfaceSegments(f)
        return

    # Marching Squares Lookup
    case = LookupMarchingSquares(f.vertex_signs)
    
    if case == 0:
        f.segments = []
    elif case in [1, 2]:
        l = CreateSingleSegment(f)
        f.segments = [l]
        DetectFaceSharpFeature(f.segments)
    elif case == 3:
        # Face Ambiguity Resolution
        segs_option_1 = CreateSegmentsOption1(f)
        segs_option_2 = CreateSegmentsOption2(f)
        
        features_1 = DetectSharpFeatures(segs_option_1)
        features_2 = DetectSharpFeatures(segs_option_2)
        
        if FeaturesOverlap(features_1):
            f.segments = segs_option_2
            DetectFaceSharpFeature(f.segments)
        else:
            f.segments = segs_option_1
            DetectFaceSharpFeature(f.segments)

def DetectFaceSharpFeature(segments):
    for seg in segments:
        angle = AngleBetweenNormals(seg.endpoints)
        if angle > sharp_feature_threshold:
            seg.has_sharp_feature = True
            seg.sharp_feature_pos = ComputeSharpFeaturePosition(seg)

def ExtractSurface(c):
    segments = []
    for fi in c.faces:
        segments.extend(GetSegment(fi))
    
    components = TraceComponents(segments)
    
    for o in components:
        DetectSharpFeature(o)
        
    if HasInternalAmbiguity(components):
        ResolveInternalAmbiguity(components)
    else:
        for o in components:
            Triangulate(o)

def TraceComponents(segments):
    components = []
    visited = set()
    for seg in segments:
        if seg.id not in visited:
            current_component = [seg]
            visited.add(seg.id)
            current_end = seg.endpoints[1]
            
            while True:
                next_seg = FindNextSegment(current_end, segments, visited)
                if next_seg is None or next_seg.id == segments[0].id:
                    break
                current_component.append(next_seg)
                visited.add(next_seg.id)
                current_end = next_seg.endpoints[1]
            components.append(current_component)
    return components

def DetectSharpFeature(component):
    # Solve [ni]^T p = [ni si] using SVD
    A = []
    b = []
    for seg in component:
        for endpoint in seg.endpoints:
            A.append(endpoint.normal)
            b.append(dot(endpoint.normal, endpoint.position))
    p = SolveSVD(A, b)
    component.sharp_feature = p

def Triangulate(component):
    if component.has_sharp_feature:
        p = component.sharp_feature
        vertices = component.vertices
        for i in range(len(vertices)):
            j = (i + 1) % len(vertices)
            CreateTriangle(p, vertices[i], vertices[j])
    else:
        center = AveragePoint(component.sample_points)
        vertices = component.vertices
        for i in range(len(vertices)):
            j = (i + 1) % len(vertices)
            CreateTriangle(center, vertices[i], vertices[j])
```

## Operating characteristics
*   **Time Complexity:** Generally slightly slower than standard Marching Cubes due to the overhead of face-based processing and component tracing [S1].
*   **Memory Complexity:** Requires storage for the adaptive octree and segment lists. The adaptive nature allows for lower memory usage on smooth regions compared to uniform grids [S1].
*   **Strengths:**
    *   Eliminates inter-cell dependency by sampling sharp features on faces, removing the need for edge flipping [S1].
    *   Guarantees crack-free meshes on transition faces because every segment is shared by exactly two components from neighboring cells [S1].
    *   Handles face ambiguity effectively for volume data using sharp feature overlap tests [S1].
*   **Limitations:**
    *   May produce different results than asymptotic deciders in ambiguity cases [S1].
    *   Requires Hermite data (sample points and normals) on a fine grid as input [S1].
*   **When to use:** When adaptive surface extraction is required, and inter-cell dependency or crack patching is a concern. Particularly suitable for volume data where sharp features need to be preserved without topology errors [S1].
*   **When not to use:** When maximum performance is critical and adaptive refinement is not needed (standard Marching Cubes may be faster) [S1].

## Background
Cubical Marching Squares was introduced by [S1] as an adaptive surface extraction method. It builds upon the concept of converting Marching Cubes lookups into six Marching Squares lookups [S1]. The method addresses limitations in previous algorithms like Edge Matching Cubes (EMC) and Dual Contouring (DC), which suffer from inter-cell dependency and topology errors [S1]. The Hermite data format used is based on work by Ju et al. [JLSW02] and Kobbelt et al. [KBSS01].
