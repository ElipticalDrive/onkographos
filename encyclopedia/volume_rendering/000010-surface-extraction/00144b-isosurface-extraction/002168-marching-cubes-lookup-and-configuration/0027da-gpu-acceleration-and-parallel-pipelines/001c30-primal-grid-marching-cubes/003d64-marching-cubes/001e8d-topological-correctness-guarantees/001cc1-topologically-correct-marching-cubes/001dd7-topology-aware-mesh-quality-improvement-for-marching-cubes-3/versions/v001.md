# Topology-aware mesh quality improvement for Marching Cubes 33

Also called: Labelle and Shewchuk integration with Extended MC33, Topology-preserving skinny triangle removal

## Overview
This method improves the aspect ratio of triangulations generated by Marching Cubes 33 by modifying scalar field values near isosurface intersections, while preventing topological errors using a verification step [S1]. It combines the topological guarantees of Extended Marching Cubes 33 with the skinny triangle removal strategy of Labelle and Shewchuk [S1]. Unlike Raman and Wenger, this method correctly represents the topology of the trilinear interpolant even when $\lambda=0$, whereas Raman and Wenger cannot represent it correctly even at $\lambda=0$ [S1].

## How it works
**Inputs:**
- A scalar field grid $V$ with dimensions $N_x \times N_y \times N_z$.
- An isovalue $\alpha$.
- A parameter $\lambda \in [0, 0.5]$ determining the threshold for collapsing intersection points [S1].

**Outputs:**
- A manifold triangle mesh homeomorphic to the trilinear interpolant of the input scalar field [S1].

**Data Structures:**
- **Grid:** A 3D array of scalar values.
- **Cube Status:** A boolean flag for each cube indicating if it is "blocked" (preventing mesh improvement) [S1].
- **Intersection Points:** For each edge of a cube, the parametric position $t \in [0, 1]$ where the isosurface intersects the edge, or a flag indicating no intersection.

**Steps:**

1. **Grid Preprocessing:**
   Eliminate ambiguous configurations that cause non-manifold edges in the Chernyaev lookup table. Specifically, split faces at critical points where grid vertex scalar values equal the isovalue [S1]. The source proposes splitting all faces in the grid slice containing the problematic configuration to ensure robust handling [S1].

2. **Scalar Field Modification (Labelle and Shewchuk Strategy):**
   Detect all intersected edges. For each edge with length $L$, if an intersection point is at distance $d < \lambda \cdot L$ from a grid vertex, collapse the intersection point to that nearest grid vertex by setting the scalar value at that vertex to the isovalue $\alpha$ [S1]. This modifies the grid $V$ to $V'$.

3. **Topology Verification (Blocking):**
   To prevent undesired topological changes caused by the scalar field modification, track isosurface topology changes in the interior of each cube [S1].
   - For each cube, determine if the modified scalar field $V'$ would result in a different topology than the original field $V$ relative to the Extended MC33 triangulation.
   - If a configuration is detected that could modify the global isosurface topology, mark the cube and its immediate neighbors as "blocked" [S1].
   - [G] The verification typically involves comparing the connectivity of the isosurface segments within the cube before and after modification, or checking for the emergence/disappearance of critical points.

4. **Mesh Extraction:**
   Run the Marching Cubes 33 algorithm with the extended triangulation on the modified grid $V'$ [S1].
   - For cubes marked as "blocked", perform standard triangulation without applying the vertex collapsing logic from Step 2 (or revert to original field values for those cubes) to preserve topology [S1].
   - For non-blocked cubes, use the modified field $V'$ where intersections near vertices have been collapsed.

5. **Geometry Preservation:**
   Move each isosurface vertex located on a grid vertex (due to collapsing) to the location of the closest isosurface vertex in the original grid (from $V$) to preserve the original geometry [S1].

**Quality Measure:**
Triangle quality is measured using the radii ratio $q(t)$:
$$ q(t) = \frac{r_{in}}{r_{out}} $$
where $r_{in}$ is the incircle radius and $r_{out}$ is the circumcircle radius of triangle $t$ [S1]. The value $q(t) \in [0, 0.5]$, where 0 is degenerate and 0.5 is equilateral [S1].

## Operating characteristics
- **Time Complexity:** The method adds a verification step per cube, increasing computational cost over standard MC33. The verification involves comparing topologies, which is constant per cube but adds overhead.
- **Memory Complexity:** Requires storing the original grid and a boolean mask for blocked cubes.
- **Performance:** In the Bonsai dataset with $\lambda=0.2$ and isovalue 39.5, only 0.63% of cubes intersected by the isosurface were blocked [S1]. For a randomly generated scalar field on a 6x6x6 grid, 6.73% of cubes were blocked for $\lambda=0.1$, and 31.1% were blocked for $\lambda=0.2$ [S1].
- **Strengths:** Correctly represents the topology of the trilinear interpolant even when $\lambda=0$ [S1]. Improves aspect ratio of triangles [S1].
- **Limitations:** The verification step can block a significant portion of cubes in random or highly complex fields (up to 31.1% in tested random fields) [S1].

## Background
This method was proposed by the author of [S1] as an extension to Marching Cubes 33. It integrates the Labelle and Shewchuk algorithm [S1] with the Extended MC33 triangulation. The work addresses issues with the Chernyaev lookup table and non-manifold triangulations [S1].
