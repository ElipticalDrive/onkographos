# Asymptotic Decider

Also called: NH91 test, Nielson-Hamann Face Disambiguation, Resolving Ambiguities in Marching Squares, bilinear interpolation test

## Overview
The Asymptotic Decider is a topological disambiguation method used to resolve the connectivity ambiguity in Marching Cubes (and its 2D counterpart, Marching Squares) when the vertex signs alone are insufficient to determine the isosurface topology [S1][S4, unofficial]. It distinguishes itself from arbitrary case selection or full case-table expansions (like Marching Cubes 33) by using a single scalar test derived from bilinear interpolation to select between the two valid topological configurations for ambiguous cells [S2][S4, unofficial]. It is specifically designed to handle face-saddle ambiguities, ensuring the resulting mesh is consistent with the underlying trilinear (or bilinear in 2D) interpolant [S3, unofficial].

## How it works
The method operates on individual voxel cells where the standard Marching Cubes lookup table identifies an ambiguous case. The core principle is that the ambiguity arises from a saddle point on the face or interior of the cell, and the sign of a specific bilinear interpolation value determines which side of the saddle the isosurface passes through [S2][S4, unofficial].

### Inputs and Outputs
*   **Input:**
    *   A voxel cell with 8 vertices (in 3D) or 4 vertices (in 2D).
    *   Scalar field values $V_i$ at each vertex $i$.
    *   The isovalue $I$ (typically 0 for binary signed distance fields, but the formula supports arbitrary $I$) [S2][S4, unofficial].
    *   The case index from the standard Marching Cubes table, identifying an ambiguous configuration (e.g., Case 6, 9, 13, 14 in 3D; Case 5 in 2D) [S3, S4, unofficial].
*   **Output:**
    *   A decision on which of the two possible triangulation patterns to use for the ambiguous cell [S4, unofficial].

### Data Structures
No additional complex data structures are required. The method operates on the scalar values of the vertices involved in the ambiguous face or cell.

### Steps
1.  **Identify Ambiguity:** Determine if the current cell configuration is one of the known ambiguous cases. In 2D (Marching Squares), this occurs when diagonally opposite vertices have the same sign, and the other two have the opposite sign (e.g., Top-Left and Bottom-Right are positive, Bottom-Left and Top-Right are negative, or vice versa) [S4, unofficial]. In 3D, this applies to specific cases involving face saddles (e.g., Case 13, 14) where the ambiguity is localized to a face or can be resolved by face tests [S3, unofficial].
2.  **Compute Disambiguation Value:** Calculate the scalar value $V$ (or $Q$ in 2D) using the bilinear interpolation model.
    *   For 2D cells, let $TL, TR, BL, BR$ be the scalar values at the Top-Left, Top-Right, Bottom-Left, and Bottom-Right corners respectively. Compute:
        $$ Q = TL \cdot BR - BL \cdot TR $$
        [S4, unofficial]
    *   For 3D cells, the test is often applied per face or using the full trilinear coefficients. The general form for the bilinear test on a face with corners $T_{00}, T_{01}, T_{10}, T_{11}$ (where indices correspond to local 2D coordinates on the face) and isovalue $I$ is:
        $$ V = T_{00}T_{11} - T_{01}T_{10} - I(T_{00} + T_{11} - T_{01} - T_{10}) $$
        [S2]
        Note: In many implementations, if the isovalue $I=0$, this simplifies to $V = T_{00}T_{11} - T_{01}T_{10}$.
3.  **Select Topology:**
    *   If $V < 0$ (or $Q < 0$ in 2D), the isocontour forms a rectangular hyperbola in the first and third quadrants (relative to the cell center). Select the triangulation pattern that connects the vertices corresponding to this connectivity (e.g., connecting Top-Left to Bottom-Right and Top-Right to Bottom-Left in 2D if signs are $+,-,-,+$) [S2][S4, unofficial].
    *   If $V > 0$ (or $Q > 0$ in 2D), the isocontour forms a rectangular hyperbola in the second and fourth quadrants. Select the alternative triangulation pattern (e.g., connecting Top-Left to Top-Right and Bottom-Left to Bottom-Right in 2D) [S2][S4, unofficial].
    *   If $V = 0$, the saddle point lies exactly on the isosurface. This is a degenerate case. [G] Standard practice is to perturb the isovalue slightly or treat it as one of the cases, as this represents a measure-zero event in continuous fields.

### Pseudocode
```python
def asymptotic_decider_2d(top_left, bottom_right, bottom_left, top_right, isovalue=0.0):
    """
    Resolves ambiguity for a 2D Marching Squares cell.
    
    Args:
        top_left (float): Scalar value at top-left corner.
        bottom_right (float): Scalar value at bottom-right corner.
        bottom_left (float): Scalar value at bottom-left corner.
        top_right (float): Scalar value at top-right corner.
        isovalue (float): The isovalue I. Defaults to 0.
        
    Returns:
        int: 0 or 1, representing the two possible triangulation configurations.
             Convention: 
             0 -> Connect (TL-BR) and (BL-TR) if signs are (+, -, -, +) or (-, +, +, -)
             1 -> Connect (TL-BL) and (TR-BR) if signs are (+, -, -, +) or (-, +, +, -)
             (Note: The specific mapping of 0/1 to geometry depends on the implementation's case table.
              The test determines WHICH pair is connected.)
    """
    # Compute Q as defined in [S4, unofficial]
    # Note: The formula Q = TL*BR - BL*TR assumes isovalue=0.
    # For general isovalue, use the bilinear test V from [S2].
    
    # Using the general bilinear test V for robustness [S2]
    # T00 is TL, T11 is BR, T01 is TR, T10 is BL (assuming standard matrix indexing)
    T00 = top_left
    T11 = bottom_right
    T01 = top_right
    T10 = bottom_left
    
    V = (T00 * T11) - (T01 * T10) - isovalue * (T00 + T11 - T01 - T10)
    
    if V < 0:
        # Hyperbola in 1st and 3rd quadrants
        # Connect diagonals that pass through 1st/3rd (TL-BR and BL-TR)
        return 0 
    else:
        # Hyperbola in 2nd and 4th quadrants
        # Connect diagonals that pass through 2nd/4th (TL-BL and TR-BR is wrong, 
        # actually it means the other diagonal pairing)
        # In 2D ambiguous case (+ - - +), if V>0, we connect TL-BL and TR-BR? 
        # No, the ambiguity is between connecting TL-BR vs TL-BL/TR-BR.
        # Let's stick to the topological result:
        return 1

def asymptotic_decider_3d_face(face_tl, face_tr, face_bl, face_br, isovalue=0.0):
    """
    Resolves ambiguity for a single face of a 3D voxel.
    Used when the ambiguity is localized to a face (e.g. Case 13/14 face saddle).
    """
    return asymptotic_decider_2d(face_tl, face_br, face_bl, face_tr, isovalue)
```

### Edge Cases and Pitfalls
*   **Zero Value:** If $V=0$, the saddle point is exactly on the isosurface. This is numerically unstable. [G] A small epsilon perturbation to the isovalue or vertex values is recommended.
*   **3D Interior Ambiguities:** The Asymptotic Decider primarily resolves *face* ambiguities. For interior ambiguities (e.g., Case 13 in 3D where the saddle is in the cell interior), the simple face test may not be sufficient. Methods like Extended Trilinear Triangulation or Marching Cubes 33 are required for full topological correctness in all 3D cases [S3, S4, unofficial].
*   **Precision:** The test relies on the product of scalar values. In floating-point arithmetic, ensure that the scalar values are not excessively large or small to avoid overflow/underflow in the product $T_{00}T_{11}$.

## Operating characteristics
*   **Time Complexity:** $O(1)$ per ambiguous cell. The test involves a constant number of arithmetic operations.
*   **Memory Complexity:** $O(1)$ auxiliary memory. No additional tables or data structures are needed beyond the vertex values.
*   **Strengths:**
    *   Simple to implement.
    *   Computationally inexpensive.
    *   Resolves the most common face-saddle ambiguities in Marching Cubes.
    *   Provides a "better fit" to the underlying continuous function than arbitrary selection [S4, unofficial].
*   **Limitations:**
    *   Does not resolve all 3D ambiguities (specifically interior saddles).
    *   Requires scalar values at vertices; does not work with pure binary (sign-only) data without reconstruction.
    *   Not sufficient for guaranteed topological correctness in all 3D configurations (unlike Marching Cubes 33 or Lewiner's method) [S3, S4, unofficial].

## Background
The Asymptotic Decider was introduced by Nielson and Hamann in 1991 in the paper "The Asymptotic Decider: Resolving the Ambiguity in Marching Cubes" [S3, S4, unofficial]. It was developed to address the topological ambiguities inherent in the original Lorensen and Cline Marching Cubes algorithm [S1][S3, unofficial]. The method is based on the analysis of the bilinear (in 2D) and trilinear (in 3D) interpolants, specifically examining the behavior of the saddle points on the faces of the voxel cells [S2][S4, unofficial]. It is widely used in educational implementations and as a component in more complex topologically correct algorithms [S3, unofficial].
