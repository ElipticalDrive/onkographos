# Marching Cubes with Lewiner 2003 Ambiguity Resolution

Also called: Lewiner 2003, Lewiner implementation, Marching Cubes with Interior/Face Tests, Marching Cubes with Lewiner/Nielson-Hamann Ambiguity Resolution, skimage.measure.marching_cubes_lewiner [S1, unofficial]

## Overview
This method is an implementation of the Marching Cubes algorithm that resolves topological ambiguities (Ambiguous face and Internal ambiguity) present in the original 1987 algorithm to guarantee a manifold surface [S1, unofficial]. It is a volumetric surface extraction method that resolves topological ambiguities in the standard Marching Cubes algorithm by testing faces and interior points of the cube, based on the Lewiner 2003 paper [S1, unofficial]. Unlike the original MC which may produce cracks and non-manifold geometry, Lewiner's method guarantees manifold surfaces at the cost of larger lookup tables [S1, unofficial].

## How it works
**Inputs:**
- `data`: 3D scalar field array of dimensions `dim[0] x dim[1] x dim[2]` [S1, unofficial].
- `isoValue`: Scalar threshold for isosurface extraction [S1, unofficial].
- `spacing`: 3D vector of voxel spacings $(s_x, s_y, s_z)$ [S1, unofficial].
- `reverseGradientDirection`: Boolean flag (default `false`) to invert normal direction [S1, unofficial].

**Outputs:**
- `vertices`: List of 3D points (interpolated edge midpoints and center points) [S1, unofficial].
- `triangles`: List of triangle indices (each triangle is 3 vertex indices) [S1, unofficial].
- `normals`: List of normal vectors corresponding to vertices [S1, unofficial].

**Data Structures:**
- `xDirectionInterpolatedVertexIndex`, `yDirectionInterpolatedVertexIndex`, `zDirectionInterpolatedVertexIndex`: Maps from grid coordinates `(i, j, k)` to vertex indices in the `vertices` list [S1, unofficial]. These store pre-computed interpolated vertices for edges where vertex signs differ [S1, unofficial].
- `centerInterpolatedVertexIndex`: Map from grid coordinates to vertex indices for center points created during ambiguity resolution [S1, unofficial].
- `vertices`: Vector of `Vertex` structs containing position and normal [S1, unofficial].
- `triangles`: Vector of integer triplets [S1, unofficial].
- `cases`: Lookup table mapping 256 configuration indices to 15 base cases and their sub-class indices [S1, unofficial].
- `tiling1`...`tiling7_*`: Lookup tables defining triangle vertex indices for each case/sub-case [S1, unofficial].
- `test3`, `test4`, `test6`, `test7`: Lookup tables specifying which faces or interior points to test for ambiguity resolution [S1, unofficial].

**Steps:**
1. **Initialization:** Clear all vertex index maps and vertex/triangle lists. Initialize bounding box `bmin` to max float and `bmax` to min float [S1, unofficial].
2. **Pre-compute Interpolated Vertices:** Scan the volume to calculate interpolated edge midpoints for all edges where vertex signs differ. Store points in maps indexed by the cube's corner 0 and direction (x, y, z) [S1, unofficial].
3. **Cube Iteration:** Iterate `i` from 0 to `dim[0]-2`, `j` from 0 to `dim[1]-2`, `k` from 0 to `dim[2]-2` in parallel [S1, unofficial].
4. **Configuration Index Calculation:** For each cube, determine the 8-bit configuration index. For vertex `l` (0-7), calculate grid coordinates: $x = i + ((l \oplus (l \gg 1)) \& 1)$, $y = j + ((l \gg 1)) \& 1)$, $z = k + ((l \gg 2)) \& 1)$. If `data[x, y, z] > isoValue`, set bit `l` in `configurationIndex` [S1, unofficial].
5. **Case Lookup:** Retrieve `caseIdx` and `configurationIndexInCase` from the `cases` table using `configurationIndex` [S1, unofficial].
6. **Ambiguity Resolution & Triangulation:** Based on `caseIdx`, test faces or interior points using the `test` tables. Map results to sub-classes and add triangles from the corresponding `tiling` tables [S1, unofficial].
7. **Center Vertex Creation:** For specific sub-cases (e.g., Case 6.1.2), create a center vertex by averaging all existing interpolated vertices on the cube's edges, normalize the normal, and add it to the vertex list [S1, unofficial].

**Formulas:**
- **Vertex Coordinate Mapping:** For vertex index $l \in [0,7]$, the grid coordinates $(x,y,z)$ relative to cube origin $(i,j,k)$ are: $x = i + ((l \oplus (l \gg 1)) \& 1)$, $y = j + ((l \gg 1)) \& 1)$, $z = k + ((l \gg 2)) \& 1)$ [S1, unofficial].
- **Gradient Calculation (Interior):** For interior points ($0 < i < dim[0]-1$), the x-gradient is $\frac{data[i+1, j, k] - data[i-1, j, k]}{2 \cdot spacing[0]}$. Similar formulas apply for Y and Z axes [S1, unofficial].
- **Gradient Calculation (Boundary):** For boundary points ($i=0$), x-gradient is $\frac{data[i+1, j, k] - data[i, j, k]}{spacing[0]}$. For $i=dim[0]-1$, it is $\frac{data[i, j, k] - data[i-1, j, k]}{spacing[0]}$ [S1, unofficial].
- **Normal Vector:** The normal is computed as $\vec{n} = d \cdot (g_x, g_y, g_z)$, where $g_x, g_y, g_z$ are the gradients and $d = -1$ if `reverseGradientDirection` is true, else $1$ [S1, unofficial].
- **Face Ambiguity Test:** Calculate $AC - BD$ using values at the four corners of the face. If $AC - BD < 0$, the topology is resolved as 'separated' [S1, unofficial].
- **Interior Ambiguity Test:** Check if a middle cross-section exists such that $AC > BD$. If found, it proves the middle region is connected [S1, unofficial].

**Parameters:**
- `reverseGradientDirection`: Boolean flag used to invert the computed normal vector direction. Default is false [S1, unofficial].
- `isoValue`: The scalar threshold value used to determine if a data point is inside or outside the surface [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Vertex Value Equals IsoValue:** If a cube vertex value equals the isoValue, the difference becomes 0, causing interpolation errors. Handle by setting the difference to `FLT_EPSILON` [S1, unofficial].
- **Center Vertex Degeneracy:** If no edge vertices exist for a cube (`cnt == 0`), the center vertex calculation fails. The code asserts false and prints an error [S1, unofficial].
- **Thread Safety:** The algorithm uses locks (`vertexLock`, `triangleLock`) initialized in the constructor and destroyed in the destructor to protect concurrent access to the shared `vertices` and `triangles` lists [S1, unofficial].

**Pseudocode:**
```python
import math
import threading

class MarchingCubesLewiner:
    def __init__(self, data, spacing, iso_value, reverse_gradient_direction=False):
        self.data = data
        self.spacing = spacing
        self.iso_value = iso_value
        self.reverse_gradient_direction = reverse_gradient_direction
        self.dim = data.shape
        self.vertices = []
        self.triangles = []
        self.x_map = {}
        self.y_map = {}
        self.z_map = {}
        self.center_map = {}
        self.vertex_lock = threading.Lock()
        self.triangle_lock = threading.Lock()
        self.bmin = [float('inf'), float('inf'), float('inf')]
        self.bmax = [float('-inf'), float('-inf'), float('-inf')]
        # Lookup tables populated from source [S1, unofficial]
        self.cases = {}
        self.tiling1 = self.tiling2 = self.tiling3_1 = self.tiling3_2 = []
        self.tiling4_1 = self.tiling4_2 = self.tiling5 = []
        self.tiling6_1_1 = self.tiling6_1_2 = self.tiling6_2 = []
        self.tiling7_1 = self.tiling7_2 = self.tiling7_3 = []
        self.test3 = self.test4 = self.test6 = self.test7 = []

    def run(self):
        self._precompute_interpolated_vertices()
        threads = []
        for i in range(self.dim[0] - 1):
            for j in range(self.dim[1] - 1):
                for k in range(self.dim[2] - 1):
                    t = threading.Thread(target=self._process_cube, args=(i, j, k))
                    threads.append(t)
                    t.start()
        for t in threads:
            t.join()

    def _precompute_interpolated_vertices(self):
        for i in range(self.dim[0] - 1):
            for j in range(self.dim[1] - 1):
                for k in range(self.dim[2] - 1):
                    if self._sign(i, j, k) != self._sign(i + 1, j, k):
                        self._add_edge_vertex(i, j, k, 0)
                    if self._sign(i, j, k) != self._sign(i, j + 1, k):
                        self._add_edge_vertex(i, j, k, 1)
                    if self._sign(i, j, k) != self._sign(i, j, k + 1):
                        self._add_edge_vertex(i, j, k, 2)

    def _sign(self, i, j, k):
        val = self.data[i, j, k]
        if abs(val - self.iso_value) < 1e-9:
            val = self.iso_value + 1e-9
        return 1 if val > self.iso_value else -1

    def _add_edge_vertex(self, i, j, k, direction):
        v0_val = self.data[i, j, k]
        if direction == 0: v1_val = self.data[i + 1, j, k]
        elif direction == 1: v1_val = self.data[i, j + 1, k]
        else: v1_val = self.data[i, j, k + 1]
        if abs(v1_val - v0_val) < 1e-9:
            t = 0.5
        else:
            t = (self.iso_value - v0_val) / (v1_val - v0_val)
        if direction == 0:
            p0 = [i * self.spacing[0], j * self.spacing[1], k * self.spacing[2]]
            p1 = [(i + 1) * self.spacing[0], j * self.spacing[1], k * self.spacing[2]]
        elif direction == 1:
            p0 = [i * self.spacing[0], j * self.spacing[1], k * self.spacing[2]]
            p1 = [i * self.spacing[0], (j + 1) * self.spacing[1], k * self.spacing[2]]
        else:
            p0 = [i * self.spacing[0], j * self.spacing[1], k * self.spacing[2]]
            p1 = [i * self.spacing[0], j * self.spacing[1], (k + 1) * self.spacing[2]]
        pos = [p0[d] + t * (p1[d] - p0[d]) for d in range(3)]
        gx, gy, gz = self._compute_gradient(i, j, k)
        normal = self._compute_normal(gx, gy, gz)
        idx = len(self.vertices)
        self.vertices.append({'pos': pos, 'normal': normal})
        key = (i, j, k)
        if direction == 0: self.x_map[key] = idx
        elif direction == 1: self.y_map[key] = idx
        else: self.z_map[key] = idx

    def _compute_gradient(self, i, j, k):
        if i == 0: gx = (self.data[i + 1, j, k] - self.data[i, j, k]) / self.spacing[0]
        elif i == self.dim[0] - 1: gx = (self.data[i, j, k] - self.data[i - 1, j, k]) / self.spacing[0]
        else: gx = (self.data[i + 1, j, k] - self.data[i - 1, j, k]) / (2 * self.spacing[0])
        if j == 0: gy = (self.data[i, j + 1, k] - self.data[i, j, k]) / self.spacing[1]
        elif j == self.dim[1] - 1: gy = (self.data[i, j, k] - self.data[i, j - 1, k]) / self.spacing[1]
        else: gy = (self.data[i, j + 1, k] - self.data[i, j - 1, k]) / (2 * self.spacing[1])
        if k == 0: gz = (self.data[i, j, k + 1] - self.data[i, j, k]) / self.spacing[2]
        elif k == self.dim[2] - 1: gz = (self.data[i, j, k] - self.data[i, j, k - 1]) / self.spacing[2]
        else: gz = (self.data[i, j, k + 1] - self.data[i, j, k - 1]) / (2 * self.spacing[2])
        return gx, gy, gz

    def _compute_normal(self, gx, gy, gz):
        d = -1 if self.reverse_gradient_direction else 1
        normal = [d * gx, d * gy, d * gz]
        norm_len = math.sqrt(normal[0]**2 + normal[1]**2 + normal[2]**2)
        if norm_len > 0:
            normal = [n / norm_len for n in normal]
        return normal

    def _get_edge_vertex_index(self, i, j, k, edge_idx):
        if edge_idx == 0: return self.x_map.get((i, j, k))
        elif edge_idx == 1: return self.y_map.get((i, j, k))
        elif edge_idx == 2: return self.z_map.get((i, j, k))
        elif edge_idx == 3: return self.y_map.get((i + 1, j, k))
        elif edge_idx == 4: return self.z_map.get((i + 1, j, k))
        elif edge_idx == 5: return self.x_map.get((i, j + 1, k))
        elif edge_idx == 6: return self.z_map.get((i, j + 1, k))
        elif edge_idx == 7: return self.z_map.get((i + 1, j + 1, k))
        elif edge_idx == 8: return self.x_map.get((i, j, k + 1))
        elif edge_idx == 9: return self.y_map.get((i, j, k + 1))
        elif edge_idx == 10: return self.y_map.get((i + 1, j, k + 1))
        elif edge_idx == 11: return self.x_map.get((i + 1, j, k + 1))
        return None

    def _test_face(self, i, j, k, face_idx):
        faces = [
            [(i,j,k), (i+1,j,k), (i+1,j+1,k), (i,j+1,k)],
            [(i,j,k+1), (i+1,j,k+1), (i+1,j+1,k+1), (i,j+1,k+1)],
            [(i,j,k), (i+1,j,k), (i+1,j,k+1), (i,j,k+1)],
            [(i,j+1,k), (i+1,j+1,k), (i+1,j+1,k+1), (i,j+1,k+1)],
            [(i,j,k), (i,j+1,k), (i,j+1,k+1), (i,j,k+1)],
            [(i+1,j,k), (i+1,j+1,k), (i+1,j+1,k+1), (i+1,j,k+1)]
        ]
        corners = faces[face_idx]
        vals = [self.data[c[0], c[1], c[2]] for c in corners]
        return vals[0] * vals[2] - vals[1] * vals[3]

    def _test_interior(self, i, j, k, case_idx, test_val):
        center_val = 0.0
        for l in range(8):
            x = i + ((l ^ (l >> 1)) & 1)
            y = j + ((l >> 1) & 1)
            z = k + ((l >> 2) & 1)
            center_val += self.data[x, y, z]
        center_val /= 8.0
        return -1 if center_val > self.iso_value else 1

    def _add_center_vertex(self, i, j, k):
        edge_vertices = []
        for e_idx in range(12):
            v_idx = self._get_edge_vertex_index(i, j, k, e_idx)
            if v_idx is not None:
                edge_vertices.append(self.vertices[v_idx])
        cnt = len(edge_vertices)
        if cnt == 0:
            return None
        center_pos = [sum(v['pos'][d] for v in edge_vertices) / cnt for d in range(3)]
        avg_normal = [sum(v['normal'][d] for v in edge_vertices) / cnt for d in range(3)]
        norm_len = math.sqrt(avg_normal[0]**2 + avg_normal[1]**2 + avg_normal[2]**2)
        if norm_len > 0:
            avg_normal = [n / norm_len for n in avg_normal]
        idx = len(self.vertices)
        self.vertices.append({'pos': center_pos, 'normal': avg_normal})
        self.center_map[(i,j,k)] = idx
        return idx

    def _process_cube(self, i, j, k):
        config_idx = 0
        for l in range(8):
            x = i + ((l ^ (l >> 1)) & 1)
            y = j + ((l >> 1) & 1)
            z = k + ((l >> 2) & 1)
            if self.data[x, y, z] > self.iso_value:
                config_idx |= (1 << l)
        case_idx, sub_idx = self.cases.get(config_idx, (0, 0))
        
        def add_triangles(tiling_table, index):
            tri_data = tiling_table[index]
            for t in range(len(tri_data) // 3):
                self._add_triangle(tri_data[t*3], tri_data[t*3+1], tri_data[t*3+2])
                
        def get_vertex_idx(local_idx):
            if local_idx == 12:
                return self.center_map.get((i,j,k))
            return self._get_edge_vertex_index(i, j, k, local_idx)
            
        if case_idx == 0: return
        elif case_idx == 1: add_triangles(self.tiling1, sub_idx)
        elif case_idx == 2: add_triangles(self.tiling2, sub_idx)
        elif case_idx == 3:
            test_val = self.test3[sub_idx]
            sign = 1 if test_val > 0 else -1
            result = sign * self._test_face(i, j, k, abs(test_val))
            if result < 0: add_triangles(self.tiling3_1, sub_idx)
            else: add_triangles(self.tiling3_2, sub_idx)
        elif case_idx == 4:
            test_val = self.test4[sub_idx]
            sign = 1 if test_val > 0 else -1
            result = sign * self._test_interior(i, j, k, case_idx, test_val)
            if result < 0: add_triangles(self.tiling4_1, sub_idx)
            else: add_triangles(self.tiling4_2, sub_idx)
        elif case_idx == 5: add_triangles(self.tiling5, sub_idx)
        elif case_idx == 6:
            test_face_val = self.test6[sub_idx][0]
            face_sign = 1 if test_face_val > 0 else -1
            face_result = face_sign * self._test_face(i, j, k, abs(test_face_val))
            if face_result < 0:
                test_int_1 = self.test6[sub_idx][1]
                test_int_2 = self.test6[sub_idx][2]
                int_sign = 1 if test_int_1 > 0 else -1
                interior_result = int_sign * self._test_interior(i, j, k, case_idx, test_int_1)
                if interior_result < 0: add_triangles(self.tiling6_1_1, sub_idx)
                else: add_triangles(self.tiling6_1_2, sub_idx)
            else: add_triangles(self.tiling6_2, sub_idx)
        elif case_idx == 7:
            subconfig = 0
            test_faces = self.test7[sub_idx][0:3]
            for f_idx, test_face_val in enumerate(test_faces):
                f_sign = 1 if test_face_val > 0 else -1
                res = f_sign * self._test_face(i, j, k, abs(test_face_val))
                if res < 0: subconfig |= (1 << f_idx)
            if subconfig == 0: add_triangles(self.tiling7_1, sub_idx)
            elif subconfig in [1, 2, 4]: add_triangles(self.tiling7_2, sub_idx + subconfig)
            elif subconfig in [3, 5]: add_triangles(self.tiling7_3, sub_idx + subconfig)

    def _add_triangle(self, idx0, idx1, idx2):
        self.triangles.append((idx0, idx1, idx2))
```

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of voxels, as each voxel is processed once [S1, unofficial].
- **Memory Complexity:** $O(N)$ for storing interpolated vertices and triangles. The source notes that using `unordered_map` for vertex indexing saves memory compared to 3D arrays [S1, unofficial].
- **Performance:** With OpenMP acceleration, the algorithm takes ~9s for a dataset with isoValue 800, 4,256,478 vertices, and 8,165,228 faces. File I/O takes ~21s. Total ~30s [S1, unofficial].
- **Strengths:** Guarantees manifold surfaces by resolving topological ambiguities [S1, unofficial].
- **Limitations:** Larger lookup tables compared to original MC. Requires pre-computation of interpolated vertices. Thread safety requires locks to protect concurrent access to shared lists [S1, unofficial].
- **When to use:** When a manifold surface is required and topological correctness is critical [S1, unofficial].
- **When not to use:** When performance is paramount and topological errors are acceptable, or when memory is extremely constrained [S1, unofficial].

## Background
The original Marching Cubes algorithm by Lorensen and Cline (1987) did not resolve ambiguities, leading to cracks and non-manifold geometry [S1, unofficial]. The Lewiner 2003 paper, "Efficient implementation of Marching Cubes’ cases with topological guarantees," resolved these ambiguities by testing faces and interior points, guaranteeing manifold surfaces [S1, unofficial]. This method is implemented in `skimage.measure.marching_cubes_lewiner` [S1, unofficial].
