# Asymptotic Decider

Also called: NH91 test, Resolving Ambiguities in Marching Squares, bilinear interpolation test

## Overview
The Asymptotic Decider is a test used to resolve topological ambiguities in Marching Cubes (specifically the 2D case, Marching Squares) by computing a value $V$ using bilinear interpolation to determine the correct topology of the isocontour within a cell [S1, unofficial][S2, unofficial]. It sets itself apart from arbitrary case selection by using the scalar values at the cell vertices to shift the output, ensuring the selected connectivity matches the underlying continuous function defined by bilinear interpolation [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** The scalar values at the four corners of a square cell ($T_{00}, T_{01}, T_{10}, T_{11}$) and the isovalue $I$.
*   **Outputs:** A decision on which of the two ambiguous topological configurations to select for the isocontour within the cell.

**Data Structures:**
The method operates on a single 2D cell (square) with four vertices. The scalar values are stored as floating-point numbers. No additional data structures are required beyond the vertex values and the isovalue.

**Numbered Steps:**
1.  **Identify Ambiguous Cases:** Determine if the cell configuration is ambiguous. A cell is ambiguous if the diagonal corners have the same sign, and the other diagonal corners have the opposite sign. Specifically, the cell is ambiguous if:
    *   $T_{00} > 0$ AND $T_{11} > 0$ AND $T_{01} < 0$ AND $T_{10} < 0$
    *   OR
    *   $T_{00} < 0$ AND $T_{11} < 0$ AND $T_{01} > 0$ AND $T_{10} > 0$
    [S2, unofficial]
    If the cell is not ambiguous, proceed with the standard Marching Squares case selection.
2.  **Compute the Decider Value:** Calculate the value $V$ using the formula:
    $$V = T_{00}T_{11} - T_{01}T_{10} - I(T_{00} + T_{11} - T_{01} - T_{10})$$
    where $T_{ij}$ are the scalar values at the cell corners and $I$ is the isovalue [S1, unofficial].
3.  **Select Topology:**
    *   If $V < 0$, the isocontour is a rectangular hyperbola in the first and third quadrants relative to the cell center. Select the configuration that connects the top-left and bottom-right vertices (the positive diagonal) or bottom-left and top-right vertices (the negative diagonal) based on the specific quadrant interpretation. Specifically, $V < 0$ implies the isocontour separates the positive corners from each other and the negative corners from each other [S1, unofficial].
    *   If $V > 0$, the isocontour is a rectangular hyperbola in the second and fourth quadrants. Select the configuration that connects the positive corners together and the negative corners together [S1, unofficial].
    *   If $V = 0$, the isocontour passes through the center of the cell. This is a degenerate case; typically, one of the adjacent configurations is selected arbitrarily or based on a small epsilon tolerance [G].

**Formulas:**
*   **Decider Value:** $V = T_{00}T_{11} - T_{01}T_{10} - I(T_{00} + T_{11} - T_{01} - T_{10})$ [S1, unofficial].
*   **Alternative Formulation (Q):** Some sources define a value $Q = T_{00}T_{11} - T_{01}T_{10}$ (where $T_{00}$ is top-left, $T_{11}$ is bottom-right, etc.) and use its sign to determine connectivity [S2, unofficial]. Note that this $Q$ is equivalent to $V$ when $I=0$. For $I \neq 0$, the full formula for $V$ must be used [S1, unofficial].

**Parameters:**
*   **Isovalue ($I$):** The threshold value for the scalar field. Typical values depend on the specific dataset.
*   **Vertex Values ($T_{ij}$):** Numerical scalars associated with each vertex. Positive values indicate solid regions, and negative values indicate empty regions [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** Floating-point precision issues may arise when $V$ is very close to zero. A small epsilon tolerance should be used to handle this [G].
*   **Boundaries:** The method assumes a regular grid cell. For non-regular cells, the bilinear interpolation model may not accurately represent the underlying function.
*   **Degenerate Input:** If all vertex values are equal, the cell is not ambiguous, and the standard case applies. If the isovalue $I$ is exactly equal to one of the vertex values, the vertex lies on the isosurface, and the standard case applies.

**Pseudocode:**
```python
def asymptotic_decider(top_left, bottom_right, bottom_left, top_right, isovalue):
    """
    Resolves topological ambiguity in a Marching Squares cell.
    
    Args:
        top_left (float): Scalar value at the top-left corner.
        bottom_right (float): Scalar value at the bottom-right corner.
        bottom_left (float): Scalar value at the bottom-left corner.
        top_right (float): Scalar value at the top-right corner.
        isovalue (float): The isovalue for the scalar field.
        
    Returns:
        int: 0 if the isocontour connects top-left and bottom-right,
             1 if it connects bottom-left and top-right.
             Returns None if the cell is not ambiguous.
    """
    # Check for ambiguity
    # Ambiguous if diagonals have the same sign and the other diagonal has the opposite sign
    is_ambiguous = False
    if (top_left > 0 and bottom_right > 0 and bottom_left < 0 and top_right < 0):
        is_ambiguous = True
    elif (top_left < 0 and bottom_right < 0 and bottom_left > 0 and top_right > 0):
        is_ambiguous = True
    
    if not is_ambiguous:
        return None
    
    # Compute the decider value V
    # V = T00*T11 - T01*T10 - I*(T00 + T11 - T01 - T10)
    # Mapping: T00=top_left, T11=bottom_right, T01=top_right, T10=bottom_left
    V = (top_left * bottom_right) - (top_right * bottom_left) - isovalue * (top_left + bottom_right - top_right - bottom_left)
    
    # Select topology based on V
    # If V < 0, isocontour is in 1st and 3rd quadrants (connects top-left and bottom-right)
    # If V > 0, isocontour is in 2nd and 4th quadrants (connects bottom-left and top-right)
    if V < 0:
        return 0  # Connect top-left and bottom-right
    else:
        return 1  # Connect bottom-left and top-right
```

## Operating characteristics
*   **Time Complexity:** $O(1)$ per cell, as it involves a constant number of arithmetic operations.
*   **Memory Complexity:** $O(1)$ additional memory per cell.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales linearly with the number of cells in the grid.
*   **Strengths:** Simple to implement, computationally inexpensive, and provides a more accurate representation of the underlying scalar field than arbitrary case selection.
*   **Limitations:** Only resolves ambiguities in 2D (Marching Squares). For 3D (Marching Cubes), more complex methods are required.
*   **When to use:** When working with 2D scalar fields and Marching Squares, and when topological correctness is important.
*   **When not to use:** When working with 3D scalar fields, or when computational resources are extremely limited and topological correctness is not critical.

## Background
The Asymptotic Decider was introduced by Nielson and Hamann in the paper "The Asymptotic Decider: Resolving Ambiguities in Marching Cubes" [S1, unofficial][S2, unofficial]. It was developed to address the issue of topological ambiguities in Marching Squares, which can lead to incorrect surface reconstructions. The method has since been widely adopted in 2D isosurface extraction algorithms.
