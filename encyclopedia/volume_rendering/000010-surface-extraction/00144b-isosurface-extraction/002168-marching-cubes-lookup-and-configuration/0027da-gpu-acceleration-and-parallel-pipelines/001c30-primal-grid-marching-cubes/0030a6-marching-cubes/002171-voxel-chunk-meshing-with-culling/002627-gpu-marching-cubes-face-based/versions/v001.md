# GPU Marching Cubes (Face-based)
Also called: Chunk-based Surface Extraction

## Overview
A GPU-based surface extraction method that generates a triangle mesh from a voxel grid by processing each voxel independently on the GPU [S1, unofficial]. It outputs vertices and indices into global buffers using atomic counters for parallel write safety. Unlike traditional Marching Cubes which interpolates vertices along edges, this method generates axis-aligned quads (two triangles) at voxel boundaries where a solid voxel meets an empty neighbor, effectively performing face-based culling in parallel [S1, unofficial]. It builds on [Voxel Chunk Meshing with Culling](2523-voxel-chunk-meshing-with-culling.md).

## How it works
### Inputs and Outputs
**Inputs:**
*   **Voxel Grid:** A 3D array of voxel states, where a state $> 0$ indicates a solid voxel and $0$ indicates empty [S1, unofficial].
*   **Chunk Configuration:** The dimension of the voxel chunk processed by the compute shader, typically $CHUNK\_SIZE = 80$ [S1, unofficial].
*   **Feedback Data:** Per-chunk feedback structures containing current vertex and index offsets and counts [S1, unofficial].

**Outputs:**
*   **Vertex Buffer:** A global buffer containing vertex data (position, texcoord, normal) [S1, unofficial].
*   **Index Buffer:** A global buffer containing triangle indices [S1, unofficial].
*   **Updated Feedback:** Updated vertex and index offsets and counts for each chunk [S1, unofficial].

### Data Structures
**Vertex Layout:**
Each vertex consists of 10 floats:
*   `position`: $(px, py, pz)$ [S1, unofficial]
*   `texcoord`: $(tx, ty)$ [S1, unofficial]
*   `normal`: $(nx, ny, nz)$ [S1, unofficial]

**Chunk Feedback Layout:**
*   `vertexOffset`: `uint` [S1, unofficial]
*   `vertexCount`: `uint` [S1, unofficial]
*   `indexOffset`: `uint` [S1, unofficial]
*   `indexCount`: `uint` [S1, unofficial]

**Draw Command Layout:**
*   `indexCount`: `uint` [S1, unofficial]
*   `instanceCount`: `uint` [S1, unofficial]
*   `firstIndex`: `uint` [S1, unofficial]
*   `vertexOffset`: `int` [S1, unofficial]
*   `firstInstance`: `uint` [S1, unofficial]

### Algorithm Steps
1.  **Initialization:** Thread 0 in each workgroup calculates the chunk index from `gl_WorkGroupID` using the formula:
    $$ sChunkIndex = gl\_WorkGroupID.x + 10 \times (gl\_WorkGroupID.y + 10 \times gl\_WorkGroupID.z) $$
    It then loads the chunk's `vertexOffset`, `indexOffset`, `vertexCount`, and `indexCount` from the `uChunkFeedback` buffer into shared memory variables `sVertexOffset`, `sIndexOffset`, `sVertexCount`, and `sIndexCount` [S1, unofficial].

2.  **Voxel Check:** Each thread calculates its global voxel index using the 1D index formula:
    $$ idx = x + CHUNK\_SIZE \times (y + CHUNK\_SIZE \times z) $$
    where $x, y, z$ are the 3D coordinates within the chunk derived from `gl_GlobalInvocationID` [S1, unofficial]. If `uVoxels.data[globalVoxelIndex] > 0`, the thread proceeds to extract faces; otherwise, it skips [S1, unofficial].

3.  **Face Extraction:** For each of the 6 faces of the current voxel, the thread checks if the immediate neighbor in that direction is empty. The neighbor check includes a boundary check to ensure coordinates are within $[0, CHUNK\_SIZE)$ [S1, unofficial].
    *   If the neighbor is empty, the thread allocates 4 vertices and 6 indices using `atomicAdd` on `sVertexOffset` and `sIndexOffset` [S1, unofficial].
    *   The 4 vertices are set at positions relative to the current voxel coordinate, forming a quad on the voxel boundary.
    *   The normal is set to the face direction (e.g., $(1.0, 0.0, 0.0)$ for +X) [S1, unofficial].
    *   The indices are set to `[0, 1, 2, 2, 3, 0]`, forming two triangles [S1, unofficial].

    The 6 face checks are:
    *   **+X:** Neighbor at `coord + ivec3(1, 0, 0)` is empty. Normal: $(1.0, 0.0, 0.0)$ [S1, unofficial].
    *   **-X:** Neighbor at `coord + ivec3(-1, 0, 0)` is empty. Normal: $(-1.0, 0.0, 0.0)$ [S1, unofficial].
    *   **+Y:** Neighbor at `coord + ivec3(0, 1, 0)` is empty. Normal: $(0.0, 1.0, 0.0)$ [S1, unofficial].
    *   **-Y:** Neighbor at `coord + ivec3(0, -1, 0)` is empty. Normal: $(0.0, -1.0, 0.0)$ [S1, unofficial].
    *   **+Z:** Neighbor at `coord + ivec3(0, 0, 1)` is empty. Normal: $(0.0, 0.0, 1.0)$ [S1, unofficial].
    *   **-Z:** Neighbor at `coord + ivec3(0, 0, -1)` is empty. Normal: $(0.0, 0.0, -1.0)$ [S1, unofficial].

4.  **Feedback Update:** After all threads in the workgroup have processed their voxels, the updated `sVertexOffset`, `sIndexOffset`, `sVertexCount`, and `sIndexCount` are written back to the `ChunkFeedbackBuffer` [S1, unofficial].

### Pseudocode
```python
# Shared memory variables (initialized by Thread 0)
sVertexOffset: uint
sIndexOffset: uint
sVertexCount: uint
sIndexCount: uint

# Constants
CHUNK_SIZE = 80

# Helper to convert 3D coord to 1D index
def to1D(x, y, z):
    return x + CHUNK_SIZE * (y + CHUNK_SIZE * z)

# Helper to check if a voxel exists and is solid
def hasVoxel(x, y, z):
    if x < 0 or x >= CHUNK_SIZE or y < 0 or y >= CHUNK_SIZE or z < 0 or z >= CHUNK_SIZE:
        return False
    return uVoxels.data[to1D(x, y, z)] > 0

# Main compute shader entry point
def main():
    # Thread 0 initialization
    if gl_LocalInvocationID.x == 0 and gl_LocalInvocationID.y == 0 and gl_LocalInvocationID.z == 0:
        sChunkIndex = gl_WorkGroupID.x + 10 * (gl_WorkGroupID.y + 10 * gl_WorkGroupID.z)
        feedback = uChunkFeedback[sChunkIndex]
        sVertexOffset = feedback.vertexOffset
        sIndexOffset = feedback.indexOffset
        sVertexCount = feedback.vertexCount
        sIndexCount = feedback.indexCount

    # Synchronize to ensure shared memory is loaded
    barrier()

    # Calculate global voxel index
    globalVoxelIndex = to1D(gl_GlobalInvocationID.x, gl_GlobalInvocationID.y, gl_GlobalInvocationID.z)
    
    # Check if voxel is solid
    if uVoxels.data[globalVoxelIndex] > 0:
        # Extract faces for each of the 6 directions
        # +X
        if not hasVoxel(gl_GlobalInvocationID.x + 1, gl_GlobalInvocationID.y, gl_GlobalInvocationID.z):
            vOffset = atomicAdd(sVertexOffset, 4)
            iOffset = atomicAdd(sIndexOffset, 6)
            # Write 4 vertices with normal (1.0, 0.0, 0.0)
            # Write 6 indices [0,1,2, 2,3,0] relative to vOffset and iOffset
        
        # -X
        if not hasVoxel(gl_GlobalInvocationID.x - 1, gl_GlobalInvocationID.y, gl_GlobalInvocationID.z):
            vOffset = atomicAdd(sVertexOffset, 4)
            iOffset = atomicAdd(sIndexOffset, 6)
            # Write 4 vertices with normal (-1.0, 0.0, 0.0)
            # Write 6 indices [0,1,2, 2,3,0] relative to vOffset and iOffset

        # +Y
        if not hasVoxel(gl_GlobalInvocationID.x, gl_GlobalInvocationID.y + 1, gl_GlobalInvocationID.z):
            vOffset = atomicAdd(sVertexOffset, 4)
            iOffset = atomicAdd(sIndexOffset, 6)
            # Write 4 vertices with normal (0.0, 1.0, 0.0)
            # Write 6 indices [0,1,2, 2,3,0] relative to vOffset and iOffset

        # -Y
        if not hasVoxel(gl_GlobalInvocationID.x, gl_GlobalInvocationID.y - 1, gl_GlobalInvocationID.z):
            vOffset = atomicAdd(sVertexOffset, 4)
            iOffset = atomicAdd(sIndexOffset, 6)
            # Write 4 vertices with normal (0.0, -1.0, 0.0)
            # Write 6 indices [0,1,2, 2,3,0] relative to vOffset and iOffset

        # +Z
        if not hasVoxel(gl_GlobalInvocationID.x, gl_GlobalInvocationID.y, gl_GlobalInvocationID.z + 1):
            vOffset = atomicAdd(sVertexOffset, 4)
            iOffset = atomicAdd(sIndexOffset, 6)
            # Write 4 vertices with normal (0.0, 0.0, 1.0)
            # Write 6 indices [0,1,2, 2,3,0] relative to vOffset and iOffset

        # -Z
        if not hasVoxel(gl_GlobalInvocationID.x, gl_GlobalInvocationID.y, gl_GlobalInvocationID.z - 1):
            vOffset = atomicAdd(sVertexOffset, 4)
            iOffset = atomicAdd(sIndexOffset, 6)
            # Write 4 vertices with normal (0.0, 0.0, -1.0)
            # Write 6 indices [0,1,2, 2,3,0] relative to vOffset and iOffset

    # Synchronize to ensure all atomics are complete
    barrier()

    # Thread 0 writes back feedback
    if gl_LocalInvocationID.x == 0 and gl_LocalInvocationID.y == 0 and gl_LocalInvocationID.z == 0:
        uChunkFeedback[sChunkIndex].vertexOffset = sVertexOffset
        uChunkFeedback[sChunkIndex].indexOffset = sIndexOffset
        uChunkFeedback[sChunkIndex].vertexCount = sVertexCount
        uChunkFeedback[sChunkIndex].indexCount = sIndexCount
```

### Parameters
*   **CHUNK_SIZE:** The dimension of the voxel chunk processed by the compute shader. Default value is 80 [S1, unofficial].

### Edge Cases and Pitfalls
*   **Boundary Check:** The `hasVoxel` function explicitly checks if coordinates are within $[0, CHUNK\_SIZE)$ to prevent out-of-bounds access when checking neighbors at chunk edges [S1, unofficial].
*   **Atomic Contention:** High density of solid voxels near chunk boundaries can lead to atomic contention on `sVertexOffset` and `sIndexOffset`.

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of voxels in the chunk, as each voxel is processed by one thread.
*   **Memory Complexity:** $O(V + I)$ where $V$ is the number of vertices and $I$ is the number of indices generated. The vertex buffer size is $10 \times V$ floats, and the index buffer size is $6 \times I$ integers.
*   **Performance:** Performance depends on the density of the voxel grid and the number of exposed faces. High-density grids with few exposed faces may have lower throughput due to atomic contention and memory bandwidth limits.
*   **Strengths:** Parallel processing on GPU, simple logic, no need for complex data structures like linked lists or hash maps for mesh generation.
*   **Limitations:** Generates non-manifold geometry if not careful with shared edges (though this implementation generates quads per face, which may result in duplicate vertices for shared faces if not deduplicated). The method does not handle internal faces, which is correct for surface extraction.
*   **When to use:** When real-time voxel mesh generation is required on the GPU, and the voxel grid is dense.
*   **When not to use:** When memory bandwidth is a bottleneck and the voxel grid is sparse, as the atomic operations and buffer writes can be expensive.

## Background
This method is implemented in the `UnityVoxelMeshGPU` repository by artnas [S1, unofficial]. It is designed for use in Unity's High Definition Render Pipeline (HDRP) for unlit materials [S1, unofficial].
