# Asymptotic Decider

Also called: NH91 test, Resolving Ambiguities in Marching Squares, bilinear interpolation test

## Overview
The Asymptotic Decider is a test used to resolve topological ambiguities in Marching Cubes (specifically the 2D case, Marching Squares) by computing a value $V$ using bilinear interpolation to determine the correct topology of the isocontour within a cell [S1][S2, unofficial]. It sets itself apart from arbitrary case selection by using the scalar values at the cell vertices to shift the output, ensuring the selected connectivity matches the underlying continuous function defined by bilinear interpolation [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** The scalar values at the four corners of a square cell ($T_{00}, T_{01}, T_{10}, T_{11}$) and the isovalue $I$ [S1][S2, unofficial].
*   **Outputs:** A decision on which of the two ambiguous topological configurations to select for the isocontour within the cell [S2, unofficial].

**Data Structures:**
The method operates on a single 2D cell (square) with four vertices [S2, unofficial]. The scalar values are stored as floating-point numbers [G]. No additional data structures are required beyond the vertex values and the isovalue [S2, unofficial].

**Numbered Steps:**
1.  **Identify Ambiguous Cases:** Determine if the cell configuration is ambiguous [S2, unofficial]. A cell is ambiguous if the diagonal corners have the same sign, and the other diagonal corners have the opposite sign [S2, unofficial]. Specifically, the cell is ambiguous if:
    *   $T_{00} > 0$ AND $T_{11} > 0$ AND $T_{01} < 0$ AND $T_{10} < 0$
    *   OR
    *   $T_{00} < 0$ AND $T_{11} < 0$ AND $T_{01} > 0$ AND $T_{10} > 0$ [S2, unofficial].
    If the cell is not ambiguous, proceed with the standard Marching Squares case selection [S2, unofficial].
2.  **Compute the Decider Value:** Calculate the value $V$ using the formula:
    $$V = T_{00}T_{11} - T_{01}T_{10} - I(T_{00} + T_{11} - T_{01} - T_{10})$$
    where $T_{ij}$ are the scalar values at the cell corners and $I$ is the isovalue [S1].
3.  **Select Topology:**
    *   If $V < 0$, the isocontour is a rectangular hyperbola in the first and third quadrants [S1]. Select the configuration corresponding to this topology [S2, unofficial].
    *   If $V > 0$, the isocontour is a rectangular hyperbola in the second and fourth quadrants [S1]. Select the configuration corresponding to this topology [S2, unofficial].
    *   If $V = 0$, the isocontour passes through the center of the cell [G]. This is a degenerate case; typically, one of the adjacent configurations is selected arbitrarily or based on a small epsilon tolerance [G].

**Formulas:**
*   **Decider Value:** $V = T_{00}T_{11} - T_{01}T_{10} - I(T_{00} + T_{11} - T_{01} - T_{10})$ [S1].
*   **Alternative Formulation (Q):** Some sources define a value $Q = T_{00}T_{11} - T_{01}T_{10}$ (where $T_{00}$ is top-left, $T_{11}$ is bottom-right, etc.) and use its sign to determine connectivity [S2, unofficial]. Note that this $Q$ is equivalent to $V$ when $I=0$ [G].

**Parameters:**
*   **Isovalue ($I$):** The threshold value for the scalar field [S1][S2, unofficial].
*   **Vertex Values ($T_{ij}$):** Numerical scalars associated with each vertex [S2, unofficial]. Positive values indicate solid regions, and negative values indicate empty regions [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** Floating-point precision issues may arise when $V$ is very close to zero [G]. A small epsilon tolerance should be used to handle this [G].
*   **Boundaries:** The method assumes a regular grid cell [G]. For non-regular cells, the bilinear interpolation model may not accurately represent the underlying function [G].
*   **Degenerate Input:** If all vertex values are equal, the cell is not ambiguous, and the standard case applies [G]. If the isovalue $I$ is exactly equal to one of the vertex values, the vertex lies on the isosurface, and the standard case applies [G].

**Pseudocode:**
```python
def asymptotic_decider(top_left, bottom_right, bottom_left, top_right, isovalue):
    """
    Resolves topological ambiguity in a Marching Squares cell.
    
    Args:
        top_left (float): Scalar value at the top-left corner ($T_{00}$).
        bottom_right (float): Scalar value at the bottom-right corner ($T_{11}$).
        bottom_left (float): Scalar value at the bottom-left corner ($T_{10}$).
        top_right (float): Scalar value at the top-right corner ($T_{01}$).
        isovalue (float): The isovalue for the scalar field ($I$).
        
    Returns:
        int: 0 if the isocontour follows the first ambiguous topology,
             1 if it follows the second ambiguous topology.
             Returns None if the cell is not ambiguous.
    """
    # Check for ambiguity
    # Ambiguous if diagonals have the same sign and the other diagonal has the opposite sign
    is_ambiguous = False
    if (top_left > 0 and bottom_right > 0 and bottom_left < 0 and top_right < 0):
        is_ambiguous = True
    elif (top_left < 0 and bottom_right < 0 and bottom_left > 0 and top_right > 0):
        is_ambiguous = True
    
    if not is_ambiguous:
        return None
    
    # Compute the decider value V
    # V = T00*T11 - T01*T10 - I*(T00 + T11 - T01 - T10)
    V = (top_left * bottom_right) - (top_right * bottom_left) - isovalue * (top_left + bottom_right - top_right - bottom_left)
    
    # Select topology based on V
    # If V < 0, isocontour is in 1st and 3rd quadrants
    # If V > 0, isocontour is in 2nd and 4th quadrants
    if V < 0:
        return 0  # First ambiguous topology
    else:
        return 1  # Second ambiguous topology
```

## Operating characteristics
*   **Time Complexity:** $O(1)$ per cell, as it involves a constant number of arithmetic operations [G].
*   **Memory Complexity:** $O(1)$ additional memory per cell [G].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales linearly with the number of cells in the grid [G].
*   **Strengths:** Simple to implement, computationally inexpensive, and provides a more accurate representation of the underlying scalar field than arbitrary case selection [G].
*   **Limitations:** Only resolves ambiguities in 2D (Marching Squares) [G]. For 3D (Marching Cubes), more complex methods are required [G].
*   **When to use:** When working with 2D scalar fields and Marching Squares, and when topological correctness is important [G].
*   **When not to use:** When working with 3D scalar fields, or when computational resources are extremely limited and topological correctness is not critical [G].

## Background
The Asymptotic Decider was introduced by Nielson and Hamann in the paper "The Asymptotic Decider: Resolving Ambiguities in Marching Cubes" [S1][S2, unofficial]. It was developed to address the issue of topological ambiguities in Marching Squares, which can lead to incorrect surface reconstructions [S2, unofficial]. The method has since been widely adopted in 2D isosurface extraction algorithms [S2, unofficial].
