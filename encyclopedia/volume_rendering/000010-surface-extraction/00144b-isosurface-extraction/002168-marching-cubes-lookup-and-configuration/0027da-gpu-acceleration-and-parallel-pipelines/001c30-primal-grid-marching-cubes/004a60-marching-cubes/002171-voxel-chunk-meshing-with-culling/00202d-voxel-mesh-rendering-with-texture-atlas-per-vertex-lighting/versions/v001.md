# Voxel Mesh Rendering with Texture Atlas & Per-Vertex Lighting

Also called: Chunk Mesh Rendering, Voxel Meshing with Atlas UVs

## Overview
This method renders voxel chunks as triangle meshes by mapping block faces to a horizontal texture atlas and applying per-vertex lighting with ambient occlusion (AO) in the fragment shader [S1, unofficial]. It differs from [Naive Voxel Meshing](2376-naive-voxel-meshing.md) by using a shared atlas to reduce texture bind calls, and from [GPU Marching Cubes (Face-based)](3674-gpu-marching-cubes-face-based.md) by relying on axis-aligned quads rather than isosurfaces, allowing for simpler vertex attributes and deterministic lighting [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Input**: A voxel chunk (grid of blocks), a set of 16x16 tile images for block faces, and camera matrices (Model-View-Projection).
- **Output**: A rendered image with opaque, two-sided, and transparent geometry sorted by depth and material properties.

**Data Structures**
The vertex structure contains the following fields [S1, unofficial]:
- `pos`: `Vec4<f32>` (position in world space, w=1.0).
- `uv`: `Vec2<f32>` (local UV coordinates within the tile, typically 0.0 to 1.0).
- `normal`: `Vec3<f32>` (face normal).
- `ao`: `f32` (ambient occlusion, normalized).
- `smooth_light`: `f32` (smooth lighting value, normalized).
- `block`: `MyBlock` (enum identifying the block type).
- `atlas_offset`: `f32` (U-offset in the atlas strip, representing the tile index).
- `two_sided`: `bool` (flag for backface culling behavior).

The interpolated vertex shader output (`VsOut`) passed to the fragment shader includes [S1, unofficial]:
- `uv`: `Vec2<f32>`
- `normal`: `Vec3<f32>`
- `atlas_u_offset`: `f32`
- `ao`: `f32`
- `smooth_light`: `f32`

**Texture Atlas Layout**
The atlas is a `Buffer2d` (2D texture) constructed by concatenating 16x16 tile images horizontally [S1, unofficial].
- **Width**: `tiles.len() * 16`
- **Height**: `16`
- Each block type and face direction maps to a specific U-offset (0.0 to 14.0 for 15 tiles, representing the tile index) [S1, unofficial]. For example, cactus blocks may use different offsets for top/bottom faces versus side faces.

**Numbered Steps**
1. **Build Texture Atlas**: Load individual 16x16 tile images and concatenate them into a single horizontal strip [S1, unofficial].
2. **Generate Mesh**: For each visible face in the chunk (processed via [Voxel Chunk Meshing with Culling](2523-voxel-chunk-meshing-with-culling.md)):
   a. Determine the block type and face orientation.
   b. Calculate the `atlas_offset` based on block type and face direction [S1, unofficial].
   c. Determine if the geometry is `two_sided` (e.g., diagonal faces or facades) [S1, unofficial].
   d. Compute vertex attributes:
      - Position: World space coordinates.
      - UV: Local tile UVs.
      - Normal: Face normal.
      - AO: Raw AO value divided by 3.0 [S1, unofficial].
      - Smooth Light: Raw light value divided by 15.0 [S1, unofficial].
   e. Use anisotropy-corrected indices to ensure proper interpolation of AO across shared vertices [S1, unofficial].
3. **Render Opaque Geometry**: Draw non-two-sided vertices with backface culling enabled [S1, unofficial].
4. **Render Two-Sided Geometry**: Draw two-sided vertices (e.g., cross-shaped billboards, facades) without backface culling [S1, unofficial].
5. **Render Transparent Geometry**: Draw transparent blocks (if any) with appropriate blending [S1, unofficial].

**Formulas**
The lighting calculation in the fragment shader is [S1, unofficial]:

$$
shade = (ambient + (1.0 - ambient) \cdot \max(0.0, \mathbf{n} \cdot \mathbf{l})) \cdot ao + smooth\_light \cdot 0.6
$$

Where:
- $ambient = 0.35$ [S1, unofficial]
- $\mathbf{l} = \text{normalize}(0.4, 0.7, 0.5)$ [S1, unofficial]
- $\mathbf{n}$ is the interpolated vertex normal.
- $ao$ is the interpolated ambient occlusion value.
- $smooth\_light$ is the interpolated smooth light value.

**Parameters**
- `ambient`: 0.35 [S1, unofficial]
- `light_dir`: (0.4, 0.7, 0.5) [S1, unofficial]
- `smooth_light_weight`: 0.6 [S1, unofficial]
- `tile_size`: 16x16 pixels [S1, unofficial]

**Edge Cases and Pitfalls**
- **Atlas UV Wrapping**: Use `rem_euclid(1.0)` to handle UV wrapping and clamp to `atlas_size[0] - 1` to prevent out-of-bounds texture fetches [S1, unofficial].
- **Alpha Blending**: Use a threshold of 0.01 to skip blending for near-zero alpha values, preventing visual artifacts [S1, unofficial].
- **AO Interpolation**: Ensure indices are anisotropy-corrected to avoid incorrect AO values at shared vertices between faces with different orientations [S1, unofficial].

**Pseudocode**
```python
def render_voxel_chunk(chunk, atlas, camera):
    # 1. Build Atlas (if not already built)
    # atlas = concatenate_horizontal([load_tile(img) for img in tile_images])
    
    # 2. Generate Vertices
    vertices = []
    for quad in mesh_chunk(chunk):
        lit_block = quad.block
        two_sided = is_diagonal(quad) or is_facades(lit_block.shape)
        atlas_off = get_atlas_u_offset(lit_block.block, quad.face)
        
        # Get anisotropy-corrected indices for proper AO interpolation
        indices = quad.get_ao_indices()
        
        for idx in indices:
            pos = quad.positions[idx]
            uv = quad.uvs[idx]
            normal = quad.normal
            ao = quad.ao[idx] / 3.0
            smooth_light = quad.light[idx] / 15.0
            
            vertices.append(Vertex(
                pos=pos,
                uv=uv,
                normal=normal,
                ao=ao,
                smooth_light=smooth_light,
                block=lit_block.block,
                atlas_offset=atlas_off,
                two_sided=two_sided
            ))
    
    # 3. Render Opaque Geometry
    opaque_verts = [v for v in vertices if not v.two_sided and is_opaque(v.block)]
    render_mesh(opaque_verts, atlas, camera, cull_mode=BACKFACE)
    
    # 4. Render Two-Sided Geometry
    two_sided_verts = [v for v in vertices if v.two_sided]
    render_mesh(two_sided_verts, atlas, camera, cull_mode=NONE)
    
    # 5. Render Transparent Geometry
    transparent_verts = [v for v in vertices if is_transparent(v.block)]
    render_mesh(transparent_verts, atlas, camera, cull_mode=NONE, blend=True)

def fragment_shader(uv, normal, atlas_u_offset, ao, smooth_light):
    # Calculate atlas UV
    atlas_width = atlas.get_width()
    atlas_height = atlas.get_height()
    
    # Remap UV to atlas space
    tile_u = atlas_u_offset * 16.0
    atlas_uv = vec2((uv.x + tile_u) / atlas_width, uv.y / atlas_height)
    
    # Clamp to prevent wrapping artifacts
    atlas_uv.x = min(atlas_uv.x, (atlas_width - 1) / atlas_width)
    
    # Sample texture
    color = atlas.sample(atlas_uv)
    
    # Lighting
    ambient = 0.35
    light_dir = normalize(vec3(0.4, 0.7, 0.5))
    smooth_light_weight = 0.6
    
    diffuse = max(0.0, dot(normal, light_dir))
    shade = (ambient + (1.0 - ambient) * diffuse) * ao + smooth_light * smooth_light_weight
    
    # Alpha blending threshold
    if color.a < 0.01:
        return color * shade
    
    return color * shade
```

## Operating characteristics
- **Time Complexity**: Linear with respect to the number of visible faces in the chunk. Mesh generation is $O(N)$ where $N$ is the number of voxels, but only visible faces are processed. Rendering is $O(F)$ where $F$ is the number of faces.
- **Memory Complexity**: $O(F)$ for vertex storage. The atlas is fixed size $O(T \times 16 \times 16)$ where $T$ is the number of tiles.
- **Performance**: Efficient for static or semi-static scenes due to reduced draw calls (single atlas). Per-vertex lighting is cheaper than per-pixel but may show artifacts on low-resolution meshes.
- **Strengths**: Simple implementation, low memory overhead for textures, deterministic lighting.
- **Limitations**: Limited to axis-aligned faces (no curved surfaces), lighting is not physically based, AO is baked/per-vertex.
- **When to Use**: Voxel-based games, Minecraft-like environments, real-time rendering with many small blocks.
- **When Not to Use**: Scenes requiring high-fidelity lighting, curved surfaces, or dynamic global illumination.

## Background
This method is derived from the `finnbear/voxmesh` repository, which implements a voxel meshing pipeline for real-time rendering [S1, unofficial]. It builds upon [Voxel Chunk Meshing with Culling](2523-voxel-chunk-meshing-with-culling.md) for geometry generation and extends it with texture atlas mapping and per-vertex lighting.
