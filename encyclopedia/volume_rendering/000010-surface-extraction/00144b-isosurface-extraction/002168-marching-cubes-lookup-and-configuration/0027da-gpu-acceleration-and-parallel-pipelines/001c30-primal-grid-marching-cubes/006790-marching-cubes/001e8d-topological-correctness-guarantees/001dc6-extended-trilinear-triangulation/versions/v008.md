# Extended Trilinear Triangulation

Also called: Extended MC33, Extended Marching Cubes 33, Extended triangulation to the Marching Cubes 33 algorithm

## Overview
Extended Trilinear Triangulation (also known as Extended Marching Cubes 33) is a topologically correct isosurface extraction method that resolves the ambiguity problem and eliminates degenerate triangles by introducing a three-state vertex classification (+, -, =) and constructing triangulations via convex hulls of intersection points [S1]. Unlike standard Marching Cubes 33, which assumes strict inequality for vertex signs, this method explicitly handles vertices equal to the isovalue to prevent zero-area triangles, while using an interior test to distinguish between topologically distinct configurations (e.g., tunnels vs. simple leaves) that share identical boundary connectivity [S1]. It builds on [Topological Correctness Guarantees](1796-topological-correctness-guarantees.md) by extending the lookup table to cover all 33 cases with explicit handling of the "=" label, addressing the limitations of earlier extended tables like Raman and Wenger's which failed to represent topology correctly for ambiguous configurations [S1].

## How it works
### Inputs and Outputs
- **Input**: A rectilinear grid $H$ with a scalar field $f: D \subset \mathbb{R}^3 \to \mathbb{R}$, an isovalue $\alpha$, and a unit cube defined by 8 vertices $v_0, \dots, v_7$.
- **Output**: A triangular mesh approximating the isosurface $\bar{S}_\alpha = \{x \in \mathbb{R}^3 | g(x) = \alpha\}$ within the cube, where $g(x)$ is the trilinear interpolant [S1].

### Data Structures
- **Vertex Labels**: Each vertex $v_i$ is assigned a label $L(v_i) \in \{+, -, =\}$ based on $f(v_i)$ relative to $\alpha$.
- **Groups**:
  - **Group of Vertices (GV)**: A set of vertices in the same cube connected by a path of vertices with the same label (positive or negative) along the cube's edges or faces [S1].
  - **Group of Edges (GE)**: A set of edges intersected by the isosurface that are incident to vertices in the same GV [S1].
- **Intersection Points**: The midpoint of each intersected edge is used as a representative point for the convex hull construction [S1].

### Formulas
The trilinear interpolant $g(x,y,z)$ for a unit cube is:
$$
g(x,y,z) = (1-x)(1-y)(1-z)f(v_0) + (1-x)(1-y)zf(v_4) + (1-x)y(1-z)f(v_3) + (1-x)yzf(v_7) + x(1-y)(1-z)f(v_1) + x(1-y)zf(v_5) + xy(1-z)f(v_2) + xyzf(v_6)
$$
where $v_0$ is at $(0,0,0)$ and $v_7$ is at $(1,1,1)$ [S1].

### Parameters
- **Isovalue ($\alpha$)**: The scalar threshold for the isosurface.
- **Interior Test**: The Chernyaev/Custodio test is used to determine the internal connectivity of vertex groups [S1].

### Steps
1. **Classify Vertices**: For each vertex $v_i$ of the cube, determine its label:
   - $L(v_i) = +$ if $f(v_i) > \alpha$
   - $L(v_i) = -$ if $f(v_i) < \alpha$
   - $L(v_i) = =$ if $f(v_i) = \alpha$ [S1]
2. **Classify Cube**: Count the number of vertices with labels $+$ or $=$.
   - If count $\le 4$, the cube is **Positive**.
   - Otherwise, the cube is **Negative** [S1].
3. **Identify Groups**:
   - For a Positive cube, identify **Groups of Vertices (GV)**: sets of $+$ vertices connected by paths of $+$ vertices on the cube's edges/faces.
   - Identify **Groups of Edges (GE)**: sets of intersected edges incident to vertices in the same GV [S1].
   - (Analogous definitions apply for Negative cubes).
4. **Interior Test**: Use the Chernyaev/Custodio interior test to determine if the groups of vertices are separated or joined inside the cube. Classify the cube into one of three categories:
   - **Simple Leaf**: Groups are separated.
   - **Tunnel**: Groups are joined.
   - **Interior Point**: Complex internal saddle point structure [S1].
5. **Generate Triangulation**: Based on the category and specific case (e.g., Case 13 subcases), apply one of the following triangulation methods:

   **A. Simple Leaves Triangulation** (for Simple Leaf category):
   - For each group $i$, let $G_i = GV_i \cup GE_i$.
   - Let $W_i$ be the set of intersection points (midpoints of edges in $GE_i$) and vertices in $GV_i$ labeled $+$ or $=$.
   - Compute the convex hull $C_i = \text{conv}(W_i)$.
   - If $C_i$ is 3D: Triangulate the boundary $\partial C_i$. Remove triangles that lie entirely on the cube faces.
   - If $C_i$ is 2D (contained in faces): Return the triangulation of $C_i$, unless all cube vertices are $=$ (in which case, return no triangles to avoid duplicates).
   - Track grid faces to prevent duplicate triangulation between adjacent cubes [S1].

   **B. Tunnel Triangulation** (for Tunnel category):
   - Let $W$ be the set of midpoints of all intersected edges.
   - Compute $C = \text{conv}(W)$.
   - If $C$ is 3D: Triangulate $\partial C$. Remove triangles where all three vertices belong to the same Group of Edges $GE_i$.
   - The remaining triangles form the tunnel surface [S1].

   **C. Interior Point Leaves Triangulation** (for Interior Point category):
   - If a face has all four edges intersected, connect the intersection points based on the bilinear interpolant behavior on that face to form a polygonal curve.
   - Add a vertex at the cube center.
   - Form triangles connecting the center vertex to the segments of the polygonal curve [S1].

   **D. Case 13 Specifics**:
   - **Case 13.3**: One group of 4 positive vertices. Use the incident negative vertex. Apply Interior Point Leaves triangulation combined with Simple Leaves triangulation on the single negative vertex group [S1].
   - **Case 13.5.1**: Two groups of vertices. Apply Simple Leaves triangulation to both groups [S1].
   - **Case 13.5.2**: Two groups of vertices connected by the interior, with signal change diagonally opposite to one vertex group. Apply Tunnel triangulation combined with Simple Leaves triangulation in the region diagonally opposite to the one vertex positive group [S1].

### Edge Cases and Pitfalls
- **Degenerate Triangles**: Standard Marching Cubes creates degenerate triangles when a vertex equals the isovalue because it is classified as positive, causing three incident edges to be intersected at the same point. Extended Trilinear Triangulation avoids this by explicitly labeling such vertices as "=" and handling them in the convex hull construction, which naturally excludes zero-area triangles [S1].
- **Skinny Triangles**: Generated when two vertices of a triangle are close to a grid vertex while the third is far. The method improves quality by respecting the regions defined by the trilinear interpolant [S1].
- **Duplicate Faces**: If a cube has all vertices equal to "=", no triangulation is generated. Additionally, the algorithm tracks grid faces already triangulated to prevent a cube face from being triangulated twice by adjacent cubes [S1].
- **Topology Ambiguity**: Cases 6.1.1 and 6.1.2 have different interpolant topology but identical vertex/edge groups. The interior test is required to distinguish them; without it, the topology would be incorrect [S1].

## Operating characteristics
- **Time Complexity**: The method involves graph traversal for group identification, an interior test, and convex hull computation. The interior test is $O(1)$ per cube. Convex hull computation for a small number of points (max 8 vertices + 12 edge midpoints) is also $O(1)$. Thus, the overall complexity is linear with respect to the number of cubes, $O(N)$, similar to standard Marching Cubes.
- **Memory Complexity**: Requires storage for vertex labels, groups, and intersection points per cube. This is $O(1)$ per cube, with a small constant factor compared to standard Marching Cubes due to the additional data structures for groups and the interior test state.
- **Measured Performance**: In a 5x5x5 piecewise-trilinear field test, the method produced correct Betti numbers (b0=1, b1=0, b2=1), whereas Raman and Wenger's method produced incorrect values (b0=4, b1=0, b2=4) [S1].
- **Strengths**: Guarantees topological correctness for all 33 cases, including ambiguous ones. Eliminates degenerate triangles. Improves mesh quality by avoiding skinny triangles.
- **Limitations**: More complex implementation than standard Marching Cubes due to the need for group identification and interior testing. The convex hull computation adds overhead, though it is minimal for small point sets.
- **When to Use**: When topological correctness is critical and degenerate triangles must be avoided. Suitable for medical imaging and scientific visualization where accurate topology is required.
- **When Not to Use**: When performance is the sole concern and topological errors are acceptable. Standard Marching Cubes or Marching Cubes 33 may be faster and simpler to implement.

## Background
- **Origin**: The base Marching Cubes algorithm was proposed by Lorensen and Cline in 1987 [S1]. Marching Cubes 33, which guarantees topological correctness, was proposed by Chernyaev in 1995 [S1]. The extended lookup table concept was introduced by Raman and Wenger in 2008, but their method only covered 23 of 33 possible behaviors and failed to represent topology correctly for ambiguous configurations [S1]. Extended Trilinear Triangulation extends the topologically correct Marching Cubes 33 table to handle the "=" label, preserving topology while avoiding degenerate triangles [S1].
- **Development**: The method was developed to address the lingering problems of triangle quality and topology correctness in Marching Cubes. It builds on the work of Chernyaev and Custodio for the interior test and extends the lookup table to include the "=" label [S1].
- **Usage**: Used in isosurface extraction for volumetric data visualization, particularly in applications requiring high topological fidelity and mesh quality [S1].
