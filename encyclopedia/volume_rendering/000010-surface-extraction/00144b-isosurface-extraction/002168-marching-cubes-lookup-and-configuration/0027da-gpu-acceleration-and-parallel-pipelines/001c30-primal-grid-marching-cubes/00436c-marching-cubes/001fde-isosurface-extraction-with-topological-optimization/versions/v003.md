# Isosurface Extraction with Topological Optimization

Also called: Topological Optimization for Marching Cubes

## Overview
Isosurface Extraction with Topological Optimization is a global strategy for extracting a polygonal mesh from a 3D scalar field that optimizes topological and combinatorial measures—specifically triangle count, genus, and number of shells—by resolving topological ambiguities globally rather than locally [S1]. Unlike standard Marching Cubes, which uses local lookup tables to resolve ambiguous configurations, this method identifies "X-faces" and "X-cubes" and uses auxiliary data structures (X-face graph, Merge Tree) to make consistent decisions that minimize global complexity [S1].

## How it works
The algorithm operates on a regular, axis-aligned 3D lattice [S1]. It classifies grid nodes, identifies ambiguous configurations, and resolves them to ensure a two-manifold mesh while optimizing topological properties [S1].

### Inputs and Outputs
- **Input**: A regular 3D grid of nodes. Each node $N$ is classified as **black** (inside or on the boundary of the object) or **white** (outside) based on a scalar field threshold or voxelization [S1].
- **Output**: A triangle mesh $M$ approximating the boundary of the object. The mesh is guaranteed to be two-manifold and topologically valid [S1].

### Data Structures
1.  **Grid**: A regular 3D lattice. Nodes are binary (black/white). Cubes span the interstice between 8 nodes and have 12 edges [S1].
2.  **X-face Graph**: Captures the global connectivity of ambiguous faces to ensure consistent slashing decisions across neighboring cubes [S1].
3.  **Merge Tree**: Tracks equivalence classes of loops to manage connections between loops in X-cubes [S1].

### Definitions
- **Border Edge**: An edge of the mesh $M$ lying on a face of a cube. It connects two mesh vertices [S1].
- **X-face**: A face of a cube with alternating black and white corners (e.g., Black-White-Black-White) [S1]. Such a face contains four mesh vertices and two possible border edges [S1].
- **X-cube**: A cube that has **no** X-faces but contains **more than one loop** of border edges [S1].
- **Loop**: A simple cycle of border edges bounding a "sheet" (a connected component of the mesh within a cube). A cube can have 0 to 4 loops [S1].

### Vertex Placement
Vertices of the isosurface mesh are placed at the **midpoints** of lattice edges joining a black node and a white node [S1].
- *Note*: If the scalar field is not binary, vertices may be adjusted along the lattice edge to improve geometric fidelity (e.g., flat regions), provided no self-intersection occurs and the topological separation of interior/exterior is preserved [S1].

### Algorithm Steps

1.  **Classify Nodes**: For each node in the grid, determine if it is black (scalar $\ge$ threshold) or white (scalar $<$ threshold) [S1].
2.  **Identify Border Edges on Faces**:
    - For each face of each cube, examine the 4 corner nodes [G].
    - If corners are monochromatic (all black or all white), there are 0 border edges on this face [S1].
    - If corners are mixed but not alternating (e.g., 3 black, 1 white), there is exactly 1 border edge connecting the two adjacent mixed-color nodes. This edge is a **border edge** shared by the two cubes incident to this face [S1].
    - If corners are alternating (Black-White-Black-White), the face is an **X-face** [S1]. It contains 4 mesh vertices and 2 potential border edges (diagonals). The choice of diagonal is deferred [S1].
3.  **Identify X-faces and X-cubes**:
    - Mark all faces identified in Step 2 as X-faces if they have alternating corners [S1].
    - For each cube, count the number of loops formed by the border edges identified so far [S1].
    - If a cube has no X-faces but has $>1$ loop, it is an **X-cube** [S1].
4.  **Resolve X-faces (Global Decision)**:
    - Construct the **X-face graph** where nodes are X-faces and edges represent adjacency between X-faces sharing a cube [S1].
    - Traverse the graph to make consistent slashing decisions [S1]. The goal is to minimize global metrics (e.g., triangle count, genus) [S1].
    - For each X-face, select one of the two diagonals as the border edge. This decision must be consistent for all cubes sharing that face [S1].
5.  **Resolve X-cubes (Global Decision)**:
    - For each X-cube, decide whether to keep the loops separate (creating multiple sheets) or connect them (creating a single sheet with a handle/tunnel) [S1].
    - Use the **Merge Tree** to manage equivalence classes of loops. Connecting loops merges their equivalence classes [S1].
    - Decisions in X-cubes are independent of X-face decisions because X-cubes have no X-faces [S1].
6.  **Triangulate Sheets**:
    - For each cube, after resolving X-faces and X-cube connections, the border edges form one or more closed loops [S1].
    - Each loop bounds a sheet (a 2-manifold with boundary) [S1].
    - Triangulate each sheet within the cube. The triangulation must ensure that all triangles lie entirely within the cube [S1].
7.  **Exclude Face Triangles**:
    - Deliberately exclude any triangles that lie on a face of a cube. This ensures topological validity and allows for vertex sliding along lattice edges without breaking manifold properties [S1].

### Pseudocode

```python
def extract_isosurface(grid, threshold):
    """
    grid: 3D numpy array of scalar values.
    threshold: float, the isolevel.
    Returns: List of triangles (v1, v2, v3) where v are edge-midpoint indices.
    """
    colors = (grid >= threshold).astype(int)
    Dx, Dy, Dz = grid.shape
    triangles = []
    edge_vertices = []  # List of (v1, v2) for each edge index
    edge_idx = 0

    def add_edge(v1, v2):
        nonlocal edge_idx
        edge_vertices.append((v1, v2))
        idx = edge_idx
        edge_idx += 1
        return idx

    def get_face_corners(axis, i, j, k):
        if axis == 0: return [(i,j,k), (i,j+1,k), (i,j+1,k+1), (i,j,k+1)]
        if axis == 1: return [(i,j,k), (i+1,j,k), (i+1,j,k+1), (i,j,k+1)]
        return [(i,j,k), (i+1,j,k), (i+1,j+1,k), (i,j+1,k)]

    # Step 2: Identify border edges on non-X faces
    cube_edges = {}  # cube_idx -> list of edge indices
    x_faces = set()

    for axis in range(3):
        for i in range(Dx if axis == 0 else Dx - 1):
            for j in range(Dy if axis == 1 else Dy - 1):
                for k in range(Dz if axis == 2 else Dz - 1):
                    corners = get_face_corners(axis, i, j, k)
                    vals = [colors[c] for c in corners]
                    if vals[0] != vals[1] and vals[1] != vals[2] and vals[2] != vals[3] and vals[3] != vals[0]:
                        x_faces.add((axis, i, j, k))
                    else:
                        for e in range(4):
                            n1, n2 = corners[e], corners[(e+1)%4]
                            if colors[n1] != colors[n2]:
                                e_idx = add_edge(n1, n2)
                                if axis == 0: cubes = [(i-1, j, k), (i, j, k)]
                                elif axis == 1: cubes = [(i, j-1, k), (i, j, k)]
                                else: cubes = [(i, j, k-1), (i, j, k)]
                                for c in cubes:
                                    if 0 <= c[0] < Dx-1 and 0 <= c[1] < Dy-1 and 0 <= c[2] < Dz-1:
                                        cube_edges.setdefault(c, []).append(e_idx)
                                break

    # Step 3: Identify X-cubes
    x_cubes = []
    for c, edges in cube_edges.items():
        loops = count_cycles(edges, edge_vertices)
        if len(loops) > 1:
            x_cubes.append(c)

    # Step 4: Resolve X-faces
    x_face_decisions = {}
    for f in x_faces:
        axis, i, j, k = f
        x_face_decisions[f] = (i + j + k) % 2

    # Step 5: Resolve X-cubes
    x_cube_decisions = {}
    for c in x_cubes:
        x_cube_decisions[c] = 'separate'

    # Step 6 & 7: Generate triangles
    for c in cube_edges:
        final_edges = list(cube_edges[c])
        faces = [(0,c[0]-1,c[1],c[2]), (0,c[0],c[1],c[2]),
                 (1,c[0],c[1]-1,c[2]), (1,c[0],c[1],c[2]),
                 (2,c[0],c[1],c[2]-1), (2,c[0],c[1],c[2])]
        for f in faces:
            if f in x_faces:
                diag = x_face_decisions[f]
                corners = get_face_corners(*f)
                v1 = corners[0] if diag == 0 else corners[1]
                v2 = corners[2] if diag == 0 else corners[3]
                final_edges.append(add_edge(v1, v2))

        if c in x_cubes and x_cube_decisions[c] == 'connect':
            final_edges = merge_loops(final_edges, edge_vertices)

        sheets = form_sheets(final_edges, edge_vertices)
        for sheet in sheets:
            if len(sheet) >= 3:
                v0 = sheet[0]
                for m in range(1, len(sheet) - 1):
                    triangles.append((v0, sheet[m], sheet[m+1]))
    return triangles

def count_cycles(edges, edge_vertices):
    adj = {}
    for e in edges:
        v1, v2 = edge_vertices[e]
        adj.setdefault(v1, []).append(v2)
        adj.setdefault(v2, []).append(v1)
    visited = set()
    cycles = []
    for v in adj:
        if v not in visited:
            cycle = []
            curr, prev = v, None
            while True:
                cycle.append(curr)
                visited.add(curr)
                neighbors = [n for n in adj[curr] if n != prev]
                if not neighbors or neighbors[0] == v:
                    break
                prev, curr = curr, neighbors[0]
            cycles.append(cycle)
    return cycles

def merge_loops(edges, edge_vertices):
    parent = {v: v for e in edges for v in edge_vertices[e]}
    def find(x):
        while parent[x] != x: parent[x] = parent[parent[x]]; x = parent[x]
        return x
    def union(a, b):
        ra, rb = find(a), find(b)
        if ra != rb: parent[ra] = rb
    for e in edges:
        union(*edge_vertices[e])
    return edges

def form_sheets(edges, edge_vertices):
    return count_cycles(edges, edge_vertices)
```

### Parameters
- **Threshold**: The scalar value separating black and white nodes. [S1]
- **Vertex Placement**: Midpoints of lattice edges. Can be adjusted along the edge for geometric criteria if no self-intersection occurs. [S1]

### Edge Cases and Pitfalls
- **X-faces**: Ambiguous faces where corners are alternating black/white. Handled by global decision on which of the two possible border edges to select. [S1]
- **X-cubes**: Cubes with no X-faces but >1 loop. Handled by global decision to connect or separate loops. [S1]
- **Self-intersection**: Adjusting vertex positions along lattice edges must not produce self-intersections. [S1]
- **Face Triangles**: Triangles lying on a face of a cube must be excluded to ensure topological validity and freedom of vertex sliding. [S1]

## Operating characteristics
- **Time Complexity**: Described as "very efficient" [S1]. The algorithm uses efficient implementations and auxiliary data structures (X-face graph, Merge Tree) [S1].
- **Memory Complexity**: Requires storage for the X-face graph and Merge Tree [S1].
- **Strengths**: Guarantees a two-manifold mesh. Optimizes global topological properties (genus, triangle count, number of shells) which local methods cannot control [S1].
- **Limitations**: Requires global data structures and traversal, which may be more complex to implement than local lookup tables. [S1]
- **When to use**: When global topological properties (e.g., minimizing genus) are critical. [S1]
- **When not to use**: When local simplicity is preferred and global topology is not a concern. [S1]

## Background
The method was introduced in the paper "Optimizing the topological and combinatorial complexity of isosurfaces" [S1]. It addresses the limitations of local disambiguation methods (e.g., preferred polarity, tetrahedra decomposition) which cannot control global properties like genus or triangle count [S1]. The algorithm identifies degrees of freedom in isosurface extraction (X-faces and X-cubes) and uses them to optimize topological properties [S1].
