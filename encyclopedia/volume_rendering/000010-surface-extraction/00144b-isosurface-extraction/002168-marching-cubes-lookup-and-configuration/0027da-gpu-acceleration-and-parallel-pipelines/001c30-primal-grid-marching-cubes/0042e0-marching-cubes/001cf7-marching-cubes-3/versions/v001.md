# Marching Cubes 3

## Overview
Marching Cubes 3 is a specific implementation variant of the Marching Cubes algorithm for extracting polygonal meshes from 3D scalar fields [S1, unofficial]. It builds on the primal grid processing of [Marching Cubes](774-marching-cubes.md) but is distinguished by its specific software interface and internal configuration for handling the lookup and vertex generation steps [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A 3D scalar field array `arr` of dimensions `numx` $\times$ `numy` $\times$ `numz`.
- **Input:** Lower and upper bounds for the scalar field values (`lower`, `upper`).
- **Input:** The target `isovalue` for surface extraction.
- **Output:** A list of `vertices` (3D coordinates).
- **Output:** A list of `polygons` (indices into the vertices list).

**Data Structures:**
The scalar field is accessed via a callback function `PyArrayToCFunc(arr)` which maps grid coordinates $(i, j, k)$ to scalar values [S1, unofficial]. The output structures are dynamic lists (or vectors) that grow as triangles are generated.

**Steps:**
1. **Validation:** Verify the input data is 3-dimensional [S1, unofficial].
2. **Preparation:** Extract the shape of the input array to determine `numx`, `numy`, and `numz` [S1, unofficial].
3. **Bounds:** Compute or validate the `lower` and `upper` bounds of the scalar field values [S1, unofficial].
4. **Initialization:** Initialize empty containers for `vertices` and `polygons` [S1, unofficial].
5. **Execution:** Call the core algorithm function `mc::marching_cubes3<double>` with the prepared parameters [S1, unofficial].

**Pseudocode:**
```python
def marching_cubes_3_impl(arr, isovalue):
    # Step 1: Validate 3D
    if arr.ndim != 3:
        raise ValueError("Input must be a 3D array")

    # Step 2: Extract shape
    numx, numy, numz = arr.shape

    # Step 3: Compute bounds
    lower = float(arr.min())
    upper = float(arr.max())

    # Step 4: Initialize outputs
    vertices = []
    polygons = []

    # Step 5: Call core algorithm
    # Note: PyArrayToCFunc is a helper to access array elements by index
    mc_marching_cubes3_double(
        lower=lower,
        upper=upper,
        numx=numx,
        numy=numy,
        numz=numz,
        get_value=PyArrayToCFunc(arr),
        isovalue=isovalue,
        vertices=vertices,
        polygons=polygons
    )

    return vertices, polygons
```

**Parameters:**
- `isovalue`: The scalar threshold. Typical values depend on the data range, often normalized to $[0, 1]$ or $[-1, 1]$ [S1, unofficial].
- `lower`, `upper`: Scalar bounds. If not provided, they are computed as the min/max of the array [S1, unofficial].

**Edge Cases:**
- If the array is not 3D, the method fails validation [S1, unofficial].
- Precision issues may arise if `isovalue` is exactly equal to a vertex value; standard MC implementations handle this via epsilon comparisons or specific edge cases in the lookup table [G].

## Operating characteristics
**Time and Memory Complexity:**
Linear with respect to the number of voxels $N = numx \times numy \times numz$ for the traversal, but output size depends on surface complexity [S1, unofficial].

**Strengths and Limitations:**
- **Strengths:** Simple implementation, fast execution for moderate resolutions [S1, unofficial].
- **Limitations:** Standard MC may produce non-manifold geometry or cracks in ambiguous cases [S1, unofficial].

**When to use:**
Use for general-purpose isosurface extraction where topological ambiguity resolution is handled separately or is not critical [S1, unofficial].

## Background
Marching Cubes 3 is identified as a variant within the `differentiable_volumetric_rendering` repository [S1, unofficial]. It is part of the broader family of primal grid marching cubes methods [S1, unofficial].
