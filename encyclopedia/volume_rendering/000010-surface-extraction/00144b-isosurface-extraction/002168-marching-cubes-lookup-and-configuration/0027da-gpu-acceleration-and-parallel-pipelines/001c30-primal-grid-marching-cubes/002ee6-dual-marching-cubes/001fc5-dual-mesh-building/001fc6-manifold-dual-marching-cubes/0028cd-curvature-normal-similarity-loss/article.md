# Curvature/Normal Similarity Loss

Also called: topology-aware normal consistency loss

## Overview
A differentiable loss function that enforces normal vector alignment between triangles in adjacent grid cells, weighted by the joint probability of their topological configurations [S1, unofficial]. It addresses the discontinuity and noise in extracted surfaces by ensuring that neighboring triangles share consistent orientations, which is critical for smooth surface reconstruction in differentiable isosurfacing pipelines [S1, unofficial]. It sets itself apart from sibling methods by explicitly modeling the probabilistic nature of topology selection (via softmax over 256 cases) rather than relying on deterministic hard assignments or purely geometric penalties [S1, unofficial].

## How it works
The method computes a loss term $L_{\text{curv}}$ by iterating over all grid cells and their spatial neighbors, calculating the weighted alignment of normal vectors derived from predicted offset fields.

### Inputs and Outputs
**Inputs:**
- `topology`: A tensor of shape $(N^3, 256)$ containing unnormalized logits or probabilities for each of the 256 marching cube topology cases per cell, where $N$ is `args.num_cells` [S1, unofficial].
- `offset`: A tensor representing the predicted offset field for grid vertices, used to compute triangle normals [S1, unofficial].
- `topology_to_triangle`: A lookup table (numpy array) mapping each of the 256 topology indices to a list of triangle indices generated by the marching cube lookup table [S1, unofficial].
- `connected_x`, `connected_y`, `connected_z`, `connected_inner`: Binary or integer weight matrices of shape $(M, M)$, where $M$ is the maximum number of triangles per cell, indicating valid adjacency pairs between triangles in neighboring cells [S1, unofficial].
- `args.num_cells`: Integer, number of grid divisions per spatial dimension [S1, unofficial].
- `args.len_cell`: Float, physical size of each grid cell [S1, unofficial].

**Output:**
- `loss`: A scalar tensor representing the total curvature/normal similarity loss [S1, unofficial].

### Data Structures
- **Topology Probabilities**: Softmax output over the 256 topology classes for a cell.
- **Triangle Probabilities**: Expanded from topology probabilities using `topology_to_triangle`.
- **Joint Probability Matrix ($W$)**: Outer product of triangle probabilities from adjacent cells, masked by connectivity.
- **Normal Vectors ($N_1, N_2$)**: L2-normalized normal vectors for triangles in the current and neighbor cells, derived from the offset field.

### Steps
1. **Initialize Loss**: Set `loss = 0`.
2. **Iterate Grid Cells**: Loop over each grid cell indexed by $(x_, y_, z_)$ where $0 \le x_, y_, z_ < \text{args.num\_cells}$ [S1, unofficial].
3. **Compute Topology Probabilities**:
   - For the current cell at $(x_, y_, z_)$, compute $p_1$ as the softmax of `topology` logits along the last dimension [S1, unofficial].
   - For the neighbor cell in the $+x$ direction (or appropriate direction for each axis), compute $p_2$ similarly [S1, unofficial].
   - *Note*: The source code uses `.data` to detach topology from the gradient graph before softmax, treating topology as constant weights during gradient computation [S1, unofficial].
4. **Expand to Triangle Probabilities**:
   - Expand $p_1$ and $p_2$ from topology class probabilities to triangle probabilities using `topology_to_triangle`. Let $T_1$ and $T_2$ be the resulting vectors of triangle probabilities [S1, unofficial].
5. **Compute Joint Probability Matrix ($W$)**:
   - Compute the outer product $p_{\text{outer}} = T_1 \otimes T_2$ [S1, unofficial].
   - For each spatial direction $d \in \{x, y, z, \text{inner}\}$, multiply $p_{\text{outer}}$ element-wise by the corresponding connection mask $C_d$ (e.g., `connected_x`) to obtain the weight matrix $W_d$ [S1, unofficial].
6. **Extract Normal Vectors**:
   - Compute normal vectors $N_1$ for triangles in the current cell using the `offset_to_normal` function with grid coordinates $(x_, y_, z_)$ [S1, unofficial].
   - Compute normal vectors $N_2$ for triangles in the neighbor cell using `offset_to_normal` with coordinates $(x_+1, y_, z_)$ for the $x$-direction (and similarly for $y, z$) [S1, unofficial].
   - Normalize $N_1$ and $N_2$ to unit length via L2 normalization: $N_1 = N_1 / \|N_1\|_2$, $N_2 = N_2 / \|N_2\|_2$ [S1, unofficial].
7. **Compute Loss Contribution**:
   - Compute the weighted normal alignment term: $\text{tmp3} = N_1^\top W_d N_2$ [S1, unofficial].
   - Calculate the loss contribution: $\text{loss1} = 2 \sum W_d - 2 \operatorname{tr}(\text{tmp3})$ [S1, unofficial].
   - Accumulate $\text{loss1}$ into `loss` [S1, unofficial].
8. **Return Loss**: Return the accumulated `loss` [S1, unofficial].

### Formula
The total loss is defined as:
$$
L_{\text{curv}} = \sum_{c \in \text{cells}} \sum_{d \in \{x,y,z,\text{inner}\}} \left( 2 \sum_{i,j} W_{ij} - 2 \operatorname{tr}(N_1^\top W N_2) \right)
$$
where:
- $W = (p_1 \otimes p_2) \odot C_d$
- $p_1, p_2$ are softmax topology probabilities expanded to triangles
- $C_d$ is the connection mask for direction $d$
- $N_1, N_2$ are L2-normalized normal vectors [S1, unofficial]

    """
    Computes the curvature/normal similarity loss.
    
    Args:
        topology: Tensor of shape (num_cells^3, 256)
        offset: Tensor of offset field values
        topology_to_triangle: Array mapping topology indices to triangle indices
        connected_x, connected_y, connected_z, connected_inner: Connectivity masks
        num_cells: Integer, grid divisions per dimension
        len_cell: Float, physical size of each cell
        x_grids, y_grids, z_grids: Arrays of grid coordinates
        dtype: Data type for tensors (e.g., torch.cuda.FloatTensor)
        dtype_long: Data type for long tensors (e.g., torch.cuda.LongTensor)
        
    Returns:
        loss: Scalar tensor
    """
    loss = 0.0
    
    # Pre-convert topology_to_triangle to long tensor for indexing
    t2t_long = torch.LongTensor(topology_to_triangle).to(dtype_long)
    
    for x_ in range(num_cells):
        for y_ in range(num_cells):
            for z_ in range(num_cells):
                # Get cell index
                cell_idx = x_ * num_cells * num_cells + y_ * num_cells + z_
                
                # Compute topology probabilities for current cell
                # Detach topology to prevent gradients flowing through discrete topology selection
                p1_logits = topology[cell_idx, :]
                p1 = F.softmax(p1_logits.detach(), dim=0).to(dtype)
                
                # Compute topology probabilities for neighbor cell in +x direction
                neighbor_idx_x = (x_ + 1) * num_cells * num_cells + y_ * num_cells + z_
                if neighbor_idx_x < num_cells * num_cells * num_cells:
                    p2_logits_x = topology[neighbor_idx_x, :]
                    p2_x = F.softmax(p2_logits_x.detach(), dim=0).to(dtype)
                else:
                    continue # Skip boundary if no neighbor
                
                # Expand to triangle probabilities
                p1_tri = p1[t2t_long]
                p2_tri_x = p2_x[t2t_long]
                
                # Compute joint probability matrix for x-direction
                p_outer_x = torch.ger(p1_tri, p2_tri_x)
                W_x = torch.mul(p_outer_x, connected_x.to(dtype))
                
                # Extract normal vectors
                # Note: offset_to_normal is a helper function defined elsewhere
                # It computes normals from the offset field for triangles in a cell
                norm1 = offset_to_normal(offset, 
                                         np.where(x_grids == x_)[0][0], 
                                         np.where(y_grids == y_)[0][0], 
                                         np.where(z_grids == z_)[0][0], 
                                         0)
                norm2_x = offset_to_normal(offset, 
                                           np.where(x_grids == x_ + 1)[0][0], 
                                           np.where(y_grids == y_)[0][0], 
                                           np.where(z_grids == z_)[0][0],

                norm1_norm = torch.norm(norm1, 2, 1, keepdim=True)

                norm2_x = torch.div(norm2_x, norm2_x_norm.expand_as(norm2_x))

                loss += loss1_x

### Parameters
- `args.num_cells`: Integer, number of grid divisions per spatial dimension. Controls the iteration range for $x_, y_, z_$. Typical values depend on the desired resolution [S1, unofficial].
- `args.len_cell`: Float, physical size of each grid cell. Used to define grid coordinates and cell boundaries [S1, unofficial].

### Edge Cases and Pitfalls
- **Gradient Flow**: Topology is treated as a constant weight matrix during gradient computation to prevent gradients from flowing through the discrete topology selection. The code explicitly detaches topology before softmax using `.data` [S1, unofficial].
- **Boundary Conditions**: Neighbor cells outside the grid boundary should be handled appropriately (e.g., skipped or padded) to avoid index errors [S1, unofficial].
- **Zero Normals**: Normal vectors with zero magnitude should be handled to avoid division by zero during normalization [G].
- **Empty Cells**: Cells with no triangles (empty topology) should be handled to avoid undefined behavior in normal extraction [G].

## Operating characteristics
- **Time Complexity**: $O(N^3 \cdot M^2)$, where $N$ is `args.num_cells` and $M$ is the maximum number of triangles per cell (256 topology cases expanded to triangles). The outer product and matrix multiplication dominate the cost [S1, unofficial].
- **Memory Complexity**: $O(N^3 \cdot 256)$ for storing topology probabilities, plus $O(M^2)$ for the weight matrices [S1, unofficial].
- **Strengths**: Enforces smoothness and consistency in extracted surfaces by leveraging probabilistic topology information [S1, unofficial].
- **Limitations**: Computationally expensive due to the outer product and matrix operations over 256 topology cases [S1, unofficial]. Sensitive to the quality of the offset field and topology predictions [S1, unofficial].
- **When to Use**: When smooth, continuous surfaces are required, and the computational budget allows for the additional cost [S1, unofficial].
- **When Not to Use**: When real-time performance is critical, or when the topology predictions are unreliable [S1, unofficial].

## Background
The Curvature/Normal Similarity Loss was introduced in the context of differentiable isosurfacing, specifically for the Deep Marching Cubes method [S1, unofficial]. It aims to improve the quality of extracted surfaces by ensuring normal consistency across cell boundaries, which is a common issue in traditional marching cubes implementations [S1, unofficial]. The method is part of a broader effort to make surface extraction differentiable and trainable end-to-end [S1, unofficial].
