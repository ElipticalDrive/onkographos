# Curvature/Normal Similarity Loss

Also called: topology-aware normal consistency loss

## Overview
A differentiable loss function that enforces normal vector alignment between triangles in adjacent grid cells, weighted by the joint probability of their topological configurations [S1, unofficial]. It addresses discontinuity and noise in extracted surfaces by ensuring neighboring triangles share consistent orientations, which is critical for smooth surface reconstruction in differentiable isosurfacing pipelines [S1, unofficial]. It sets itself apart from sibling methods by explicitly modeling the probabilistic nature of topology selection via softmax over 256 cases rather than relying on deterministic hard assignments or purely geometric penalties [S1, unofficial]. It builds on [Manifold Dual Marching Cubes](2135-manifold-dual-marching-cubes.md).

## How it works
The method computes a loss term $L_{\text{curv}}$ by iterating over all grid cells and their spatial neighbors, calculating the weighted alignment of normal vectors derived from predicted offset fields [S1, unofficial].

### Inputs and Outputs
**Inputs:**
- `topology`: A tensor of shape $(N^3, 256)$ containing unnormalized logits or probabilities for each of the 256 marching cube topology cases per cell, where $N$ is `args.num_cells` [S1, unofficial].
- `offset`: A tensor representing the predicted offset field for grid vertices, used to compute triangle normals [S1, unofficial].
- `topology_to_triangle`: A lookup table mapping each of the 256 topology indices to a list of triangle indices generated by the marching cube lookup table [S1, unofficial].
- `connected_x`, `connected_y`, `connected_z`, `connected_inner`: Binary or integer weight matrices of shape $(M, M)$, where $M$ is the maximum number of triangles per cell, indicating valid adjacency pairs between triangles in neighboring cells [S1, unofficial].
- `args.num_cells`: Integer, number of grid divisions per spatial dimension [S1, unofficial].
- `args.len_cell`: Float, physical size of each grid cell [S1, unofficial].
- `x_grids`, `y_grids`, `z_grids`: Arrays of grid coordinates aligned with spatial indices [S1, unofficial].

**Output:**
- `loss`: A scalar tensor representing the total curvature/normal similarity loss [S1, unofficial].

### Data Structures
- **Topology Probabilities**: Softmax output over the 256 topology classes for a cell [S1, unofficial].
- **Triangle Probabilities**: Expanded from topology probabilities using `topology_to_triangle` [S1, unofficial].
- **Joint Probability Matrix ($W$)**: Outer product of triangle probabilities from adjacent cells, masked by connectivity [S1, unofficial].
- **Normal Vectors ($N_1, N_2$)**: L2-normalized normal vectors for triangles in the current and neighbor cells, derived from the offset field [S1, unofficial].

### Steps
1. **Initialize Loss**: Set `loss = 0` [S1, unofficial].
2. **Iterate Grid Cells**: Loop over each grid cell indexed by $(x_, y_, z_)$ where $0 \le x_, y_, z_ < \text{args.num\_cells}$ [S1, unofficial].
3. **Compute Topology Probabilities**: For the current cell at $(x_, y_, z_)$, compute $p_1$ as the softmax of `topology` logits along the last dimension [S1, unofficial]. For the neighbor cell in the target direction, compute $p_2$ similarly [S1, unofficial]. The source code detaches topology from the gradient graph before softmax to treat it as constant weights during gradient computation [S1, unofficial].
4. **Expand to Triangle Probabilities**: Expand $p_1$ and $p_2$ from topology class probabilities to triangle probabilities using `topology_to_triangle` [S1, unofficial].
5. **Compute Joint Probability Matrix ($W$)**: Compute the outer product $p_{\text{outer}} = p_1 \otimes p_2$ [S1, unofficial]. Multiply $p_{\text{outer}}$ element-wise by the corresponding connection mask $C_d$ (e.g., `connected_x`) to obtain the weight matrix $W$ [S1, unofficial].
6. **Extract Normal Vectors**: Compute normal vectors $N_1$ for triangles in the current cell using the predicted offset field [S1, unofficial]. Compute normal vectors $N_2$ for triangles in the neighbor cell using the offset field [S1, unofficial]. Normalize $N_1$ and $N_2$ to unit length via L2 normalization [S1, unofficial].
7. **Compute Loss Contribution**: Compute the weighted normal alignment term: $\text{tmp3} = N_1^\top W N_2$ [S1, unofficial]. Calculate the loss contribution: $\text{loss1} = 2 \sum W - 2 \operatorname{tr}(\text{tmp3})$ [S1, unofficial]. Accumulate $\text{loss1}$ into `loss` [S1, unofficial].
8. **Return Loss**: Return the accumulated `loss` [S1, unofficial].

### Formula
The total loss is defined as:
$$
L_{\text{curv}} = \sum_{c \in \text{cells}} \sum_{d \in \{x,y,z,\text{inner}\}} \left( 2 \sum_{i,j} W_{ij} - 2 \operatorname{tr}(N_1^\top W N_2) \right)
$$
where:
- $W = (p_1 \otimes p_2) \odot C_d$
- $p_1, p_2$ are softmax topology probabilities expanded to triangles
- $C_d$ is the connection mask for direction $d$
- $N_1, N_2$ are L2-normalized normal vectors [S1, unofficial]

def curvature_normal_similarity_loss(topology, offset, topology_to_triangle,
                                     connected_x, connected_y, connected_z,
                                     connected_inner, num_cells, len_cell,
                                     x_grids, y_grids, z_grids):
    """
    Computes the curvature/normal similarity loss.
    
    Args:
        topology: Tensor of shape (num_cells^3, 256)
        offset: Tensor of offset field values
        topology_to_triangle: List of lists mapping topology indices to triangle indices
        connected_x, connected_y, connected_z, connected_inner: Connectivity masks
        num_cells: Integer, grid divisions per dimension
        len_cell: Float, physical size of each cell
        x_grids, y_grids, z_grids: Arrays of grid coordinates
        dtype: Data type for tensors (e.g., torch.cuda.FloatTensor)
        dtype_long: Data type for long tensors (e.g., torch.cuda.LongTensor)
        
    Returns:
        loss: Scalar tensor
    """
    loss = 0.0
    
    # Pre-convert topology_to_triangle to integer indices
    t2t_indices = [list(map(int, row)) for row in topology_to_triangle]
    
    # Directions: (name, dx, dy, dz, mask, dir_flag)
    directions = [
        ('x', 1, 0, 0, connected_x, 0),
        ('y', 0, 1, 0, connected_y, 0),
        ('z', 0, 0, 1, connected_z, 0),
        ('inner', 0, 0, 0, connected_inner, 1)
    ]
    
    for x_ in range(num_cells):
        for y_ in range(num_cells):
            for z_ in range(num_cells):
                cell_idx = x_ * num_cells * num_cells + y_ * num_cells + z_
                
                for dir_name, dx, dy, dz, mask, dir_flag in directions:
                    nx, ny, nz = x_ + dx, y_ + dy, z_ + dz
                    if not (0 <= nx < num_cells and 0 <= ny < num_cells and 0 <= nz < num_cells):
                        continue
                        
                    neighbor_idx = nx * num_cells * num_cells + ny * num_cells + nz
                    
                    # Softmax probabilities (detached from gradient graph)
                    p1 = softmax(topology[cell_idx, :])
                    p2 = softmax(topology[neighbor_idx, :])
                    
                    # Expand to triangle probabilities
                    p1_tri = [p1[i] for i in t2t_indices[cell_idx]]
                    p2_tri = [p2[i] for i in t2t_indices[neighbor_idx]]
                    
                    # Joint probability matrix
                    p_outer = outer_product(p1_tri, p2_tri)
                    W = elementwise_multiply(p_outer, mask)
                    
                    # Extract and normalize normals
                    x_coord = x_grids[x_]
                    y_coord = y_grids[y_]
                    z_coord = z_grids[z_]
                    x_coord_n = x_grids[nx]
                    y_coord_n = y_grids[ny]
                    z_coord_n = z_grids[nz]
                    
                    norm1 = l2_normalize(offset_to_normal(offset, x_coord, y_coord, z_coord, dir_flag))
                    norm2 = l2_normalize(offset_to_normal(offset, x_coord_n, y_coord_n, z_coord_n, dir_flag))
                    
                    # Loss contribution
                    tmp3 = trace(matmul(matmul(norm1.transpose(), W), norm2))
                    loss1 = 2.0 * sum(W) - 2.0 * tmp3
                    loss += loss1
                    
    return loss

def softmax(logits):
    max_val = max(logits)
    exp_vals = [math.exp(l - max_val) for l in logits]
    sum_exp = sum(exp_vals)
    return [e / sum_exp for e in exp_vals]

def outer_product(a, b):
    return [[a[i] * b[j] for j in range(len(b))] for i in range(len(a))]

def elementwise_multiply(A, B):
    return [[A[i][j] * B[i][j] for j in range(len(B[0]))] for i in range(len(A))]

def l2_normalize(v):
    norm = math.sqrt(sum(x**2 for x in v))
    if norm == 0:
        return v
    return [x / norm for x in v]

def matmul(A, B):
    rows_A, cols_A = len(A), len(A[0])
    rows_B, cols_B = len(B), len(B[0])
    C = [[0.0] * cols_B for _ in range(rows_A)]
    for i in range(rows_A):
        for j in range(cols_B):
            for k in range(cols_A):
                C[i][j] += A[i][k] * B[k][j]
    return C

def trace(M):
    return sum(M[i][i] for i in range(len(M)))

### Edge Cases and Pitfalls
- **Gradient Flow**: Topology is treated as a constant weight matrix during gradient computation to prevent gradients from flowing through the discrete topology selection [S1, unofficial]. The code explicitly detaches topology before softmax using `.data` [S1, unofficial].
- **Boundary Conditions**: Neighbor cells outside the grid boundary should be skipped to avoid index errors [S1, unofficial].
- **Zero Normals**: Normal vectors with zero magnitude should be handled to avoid division by zero during normalization [G].
- **Empty Cells**: Cells with no triangles (empty topology) should be handled to avoid undefined behavior in normal extraction [G].

## Background
The Curvature/Normal Similarity Loss was introduced in the context of differentiable isosurfacing, specifically for the Deep Marching Cubes method [S1, unofficial]. It aims to improve the quality of extracted surfaces by ensuring normal consistency across cell boundaries, which is a common issue in traditional marching cubes implementations [S1, unofficial]. The method is part of a broader effort to make surface extraction differentiable and trainable end-to-end [S1, unofficial].
