# Voxel Visibility Map Computation

Also called: Face Visibility Culling, Voxel Block Visibility Types, VoxelOcclusionOptimizer.ComputeVisibleFaces, VoxelVisibility

## Overview
Voxel Visibility Map Computation is a preprocessing step in voxel meshing that determines which faces of solid voxels are exposed to empty space or the chunk boundary, producing a 3D map of visible face flags [S3, unofficial]. It differs from sibling methods by explicitly computing a per-voxel bitmask of visible faces rather than generating mesh primitives directly; [Culled Voxel Meshing](2392-culled-voxel-meshing.md) and [GPU Voxel Mesh Generation](3670-gpu-voxel-mesh-generation.md) may integrate this map or perform visibility checks inline, while [Face Visibility Check](3701-face-visibility-check.md) describes the atomic predicate used within this algorithm.

## How it works
**Inputs and outputs:**
- Input: A voxel chunk containing a 3D grid of voxels, where each voxel has a solid or transparent state [S3, unofficial].
- Output: A 3D array `visibilityMap` of type `VoxelFace[,,]` with dimensions `chunk.XDepth`, `chunk.YDepth`, `chunk.ZDepth`, storing a bitmask of visible faces for each voxel [S3, unofficial].

**Data structures:**
- `VoxelFace`: A bitmask enum with flags `Zpos`, `Zneg`, `Xneg`, `Xpos`, `Ypos`, `Yneg` representing the six faces of a voxel, and `None` representing no visible faces [S3, unofficial].
- `VoxelVisibility`: An enum with variants `Empty`, `Translucent`, `Opaque` used to decide face visibility [S1, unofficial].
- `VoxelBlock`: An enum representing `Opaque`, `Translucent`, or `Empty` blocks, used to decide face visibility [S1, unofficial].
- `visibilityMap`: A 3D array `VoxelFace[,,]` storing the computed visibility flags for each voxel in the chunk [S3, unofficial].

**Steps:**
1. Iterate through every coordinate $(x, y, z)$ in the chunk using ascending order for X, Y, and Z axes [S3, unofficial].
2. For each coordinate, retrieve the voxel at $(x, y, z)$ [S3, unofficial].
3. If the voxel is not solid (i.e., `voxel.IsSolid` is false), set `visibilityMap[x, y, z]` to `VoxelFace.None` and continue to the next coordinate [S3, unofficial].
4. Initialize `visibleFaces` to `VoxelFace.None` [S3, unofficial].
5. Check the neighbor at $(x, y, z+1)$. If `IsAdjacentVoxelTransparent` returns true, set the `Zpos` flag in `visibleFaces` [S3, unofficial].
6. Check the neighbor at $(x, y, z-1)$. If `IsAdjacentVoxelTransparent` returns true, set the `Zneg` flag in `visibleFaces` [S3, unofficial].
7. Check the neighbor at $(x-1, y, z)$. If `IsAdjacentVoxelTransparent` returns true, set the `Xneg` flag in `visibleFaces` [S3, unofficial].
8. Check the neighbor at $(x+1, y, z)$. If `IsAdjacentVoxelTransparent` returns true, set the `Xpos` flag in `visibleFaces` [S3, unofficial].
9. Check the neighbor at $(x, y+1, z)$. If `IsAdjacentVoxelTransparent` returns true, set the `Ypos` flag in `visibleFaces` [S3, unofficial].
10. Check the neighbor at $(x, y-1, z)$. If `IsAdjacentVoxelTransparent` returns true, set the `Yneg` flag in `visibleFaces` [S3, unofficial].
11. Store the computed `visibleFaces` in `visibilityMap[x, y, z]` [S3, unofficial].

**Pseudocode:**
```python
import enum

class VoxelFace(enum.IntFlag):
    NONE = 0
    Xneg = 1
    Xpos = 2
    Yneg = 4
    Ypos = 8
    Zneg = 16
    Zpos = 32

def compute_visibility_map(chunk):
    """
    Computes the visibility map for a voxel chunk.
    
    Args:
        chunk: An object representing the voxel chunk with attributes:
            - XDepth: int, width of the chunk in voxels
            - YDepth: int, height of the chunk in voxels
            - ZDepth: int, depth of the chunk in voxels
            - GetVoxel(x, y, z): returns the voxel at (x, y, z)
            - IsSolid(voxel): returns True if the voxel is solid, False otherwise
    
    Returns:
        visibility_map: A 3D list of VoxelFace bitmasks with dimensions [XDepth, YDepth, ZDepth]
    """
    x_depth = chunk.XDepth
    y_depth = chunk.YDepth
    z_depth = chunk.ZDepth
    
    # Initialize visibility map with NONE (no visible faces)
    visibility_map = [[[VoxelFace.NONE for _ in range(z_depth)] for _ in range(y_depth)] for _ in range(x_depth)]
    
    # Iterate through every coordinate in ascending order
    for x in range(x_depth):
        for y in range(y_depth):
            for z in range(z_depth):
                voxel = chunk.GetVoxel(x, y, z)
                
                # If voxel is not solid, mark as no visible faces
                if not chunk.IsSolid(voxel):
                    visibility_map[x][y][z] = VoxelFace.NONE
                    continue
                
                # Initialize visible faces to NONE
                visible_faces = VoxelFace.NONE
                
                # Check neighbor at (x, y, z+1) -> Zpos face
                if chunk.IsAdjacentVoxelTransparent(x, y, z, x, y, z + 1):
                    visible_faces |= VoxelFace.Zpos
                
                # Check neighbor at (x, y, z-1) -> Zneg face
                if chunk.IsAdjacentVoxelTransparent(x, y, z, x, y, z - 1):
                    visible_faces |= VoxelFace.Zneg
                
                # Check neighbor at (x-1, y, z) -> Xneg face
                if chunk.IsAdjacentVoxelTransparent(x, y, z, x - 1, y, z):
                    visible_faces |= VoxelFace.Xneg
                
                # Check neighbor at (x+1, y, z) -> Xpos face
                if chunk.IsAdjacentVoxelTransparent(x, y, z, x + 1, y, z):
                    visible_faces |= VoxelFace.Xpos
                
                # Check neighbor at (x, y+1, z) -> Ypos face
                if chunk.IsAdjacentVoxelTransparent(x, y, z, x, y + 1, z):
                    visible_faces |= VoxelFace.Ypos
                
                # Check neighbor at (x, y-1, z) -> Yneg face
                if chunk.IsAdjacentVoxelTransparent(x, y, z, x, y - 1, z):
                    visible_faces |= VoxelFace.Yneg
                
                # Store the computed visible faces
                visibility_map[x][y][z] = visible_faces
    
    return visibility_map
```

**Edge cases and pitfalls:**
- When checking adjacent voxels, if the neighbor coordinate is out of the chunk bounds, it is treated as transparent, resulting in a visible face [S3, unofficial].

## Operating characteristics
- Time complexity: $O(N)$ where $N$ is the number of voxels in the chunk, as each voxel is processed once with a constant number of neighbor checks [S3, unofficial].
- Memory complexity: $O(N)$ for the `visibilityMap` array, where each voxel stores a `VoxelFace` bitmask [S3, unofficial].
- Measured performance: Not given in the sources.
- Scaling: Linear with chunk size [S3, unofficial].
- Strengths: Simple, deterministic, and easy to implement; produces a clear map for subsequent meshing steps [S3, unofficial].
- Limitations: Requires storing the full visibility map; may be less efficient for very large chunks if memory is constrained [S3, unofficial].
- When to use: When you need a precomputed visibility map for subsequent meshing or culling steps [S3, unofficial].

## Background
- Origin: The method is part of the VoxelMeshOptimizerLibrary, a .NET 8 library for voxel mesh optimization [S3, unofficial].
- History and development: The library includes features such as occlusion culling, disjoint-set quad merging, and an OBJ exporter [S3, unofficial]. It targets engine-agnostic use and includes a benchmark suite [S3, unofficial].
- Where it is used: In voxel meshing pipelines that require efficient culling of non-visible voxel faces [S3, unofficial].
