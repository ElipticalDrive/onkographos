# Dual Methods

Also called: Dual schemes, dual isosurface extraction

## Overview
Dual methods are a class of isosurface extraction algorithms that generate surface topology by creating an $(n-1)$-cell for every edge crossing the boundary in 3D, resulting in a mesh where topology is completely determined by the sample complex [S1, unofficial]. Unlike primal methods such as Marching Cubes, which suffer from topological ambiguity in non-simplicial cells, dual methods resolve ambiguities by construction, though they may produce non-manifold vertices [S1, unofficial].

## How it works
**Inputs and outputs:**
- Input: A volumetric mesh (sample complex) defined by scalar field values at grid nodes [S1, unofficial].
- Output: A dual isosurface mesh [S1, unofficial].

**Data structures:**
The method constructs a mesh where vertices correspond to $n$-cells (voxels in 3D) and faces correspond to boundary-crossing edges [S1, unofficial]. No explicit lookup tables are required; the topology is derived directly from the sample complex structure [S1, unofficial].

**Steps:**
1. Identify all $n$-cells (e.g., voxels) intersected by the isosurface [S1, unofficial].
2. For every $n$-cell intersecting the boundary, create a vertex in the dual mesh [S1, unofficial]. The position of this vertex is assigned based on a specific rule [S1, unofficial].
3. For every $d$-dimensional cell in the sample complex that crosses the boundary, create an $(n-d)$-cell in the dual mesh [S1, unofficial].
   - Specifically, for every edge crossing the boundary, create a face (in 3D) [S1, unofficial].
   - For every face crossing the boundary, create an edge (in 3D) [S1, unofficial].
4. Connect the vertices and cells according to the dual incidence relations defined by the sample complex [S1, unofficial].

**Parameters:**
- Vertex assignment rule: Determines the position of the dual vertex within the $n$-cell. Not given in the sources.

**Edge cases and pitfalls:**
- Non-manifold vertices: The construction may result in non-manifold geometry, which can be problematic for certain rendering or simulation pipelines [S1, unofficial].

**Pseudocode:**
```python
def dual_extract(isosurface_value, grid_values, cells, edges):
    """
    Extracts an isosurface using a dual method.
    Args:
        isosurface_value: Scalar threshold.
        grid_values: Array of scalar values at grid nodes.
        cells: List of cells, each a list of vertex indices.
        edges: List of edges, each a list of vertex indices.
    Returns:
        vertices: List of 3D coordinates.
        faces: List of faces, each a list of vertex indices.
    """
    vertices = []
    faces = []
    cell_to_vertex_idx = {}

    # Step 1 & 2: Create a vertex for every n-cell intersecting the boundary
    for i, cell in enumerate(cells):
        if cell_intersects_boundary(cell, grid_values, isosurface_value):
            # Vertex assignment rule is the tricky part of dual methods [S1, unofficial]
            # Not given in the sources.
            vertex_pos = [0.0, 0.0, 0.0] 
            vertices.append(vertex_pos)
            cell_to_vertex_idx[i] = len(vertices) - 1

    # Step 3: Create cells based on boundary-crossing lower-dimensional elements
    # For every edge crossing the boundary, create a face (in 3D)
    for edge in edges:
        if edge_intersects_boundary(edge, grid_values, isosurface_value):
            # Identify the adjacent cells (n-cells) connected to this edge
            adjacent_cells = []
            for j, cell in enumerate(cells):
                if set(edge).issubset(set(cell)):
                    adjacent_cells.append(j)
            
            # Create a face connecting the dual vertices of these adjacent cells
            face_vertex_indices = []
            for cell_idx in adjacent_cells:
                if cell_idx in cell_to_vertex_idx:
                    face_vertex_indices.append(cell_to_vertex_idx[cell_idx])
            if len(face_vertex_indices) >= 3:
                faces.append(face_vertex_indices)

    return vertices, faces

def cell_intersects_boundary(cell, grid_values, isosurface_value):
    min_val = min(grid_values[v] for v in cell)
    max_val = max(grid_values[v] for v in cell)
    return min_val <= isosurface_value <= max_val

def edge_intersects_boundary(edge, grid_values, isosurface_value):
    v1_val = grid_values[edge[0]]
    v2_val = grid_values[edge[1]]
    return (v1_val - isosurface_value) * (v2_val - isosurface_value) < 0
```

## Background
The first dual method, Surface Nets, was proposed by Sarah Frisken Gibson in 1999 [S1, unofficial]. Research into dual schemes has continued since the 1980s, with a focus on exploring different rules for assigning vertices to $n$-cells [S1, unofficial].
