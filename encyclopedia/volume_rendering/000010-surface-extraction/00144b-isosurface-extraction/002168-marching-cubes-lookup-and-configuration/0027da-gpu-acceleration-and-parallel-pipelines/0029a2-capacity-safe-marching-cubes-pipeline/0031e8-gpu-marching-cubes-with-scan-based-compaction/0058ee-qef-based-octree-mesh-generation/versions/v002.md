# QEF-based Octree Mesh Generation

Also called: Compute-based Isosurface Extraction, GPU Mesh Compaction Pipeline

## Overview
A GPU compute pipeline that converts an octree of leaf nodes (extracted from a density field) into a compact triangle mesh using parallel index generation, prefix-sum compaction, and vertex attribute assembly [S1, unofficial]. It builds on [GPU Marching Cubes with Scan-Based Compaction](6632-gpu-marching-cubes-with-scan-based-compaction.md) by handling the final assembly of vertex attributes and index compaction for the extracted geometry [S1, unofficial].

## How it works
**Inputs:**
- `octree`: Contains `d_vertexPositions`, `d_vertexNormals`, `d_nodeMaterials` [S1, unofficial].
- `clipmapNodeSize`: Spatial resolution of the current octree chunk [S1, unofficial].
- `CLIPMAP_LEAF_SIZE`: Constant defining the leaf node size [S1, unofficial].
- `MAX_MESH_TRIANGLES`, `MAX_MESH_VERTICES`: Implementation limits for buffer allocation [S1, unofficial].

**Outputs:**
- `meshBuffer`: A `MeshBufferGPU` structure containing the final mesh data [S1, unofficial].

**Data Structures:**
- `MeshBufferGPU`:
  - `vertices`: GPU buffer of type `MeshVertex` [S1, unofficial].
  - `countVertices`: `int` [S1, unofficial].
  - `triangles`: GPU buffer of `int` indices [S1, unofficial].
  - `countTriangles`: `int` [S1, unofficial].
- `MeshVertex`: Struct containing:
  - `position`: `vec4` [S1, unofficial].
  - `normal`: `vec4` [S1, unofficial].
  - `material`: `vec4` [S1, unofficial].

**Steps:**
1. Allocate `d_indexBuffer` of size `numVertices * 6 * 3` and `d_trianglesValid` of size `numVertices * 3` [S1, unofficial].
2. Perform an exclusive scan on `d_trianglesValid` to produce `d_trianglesScan` and compute `numTriangles` [S1, unofficial].
3. If `numTriangles <= 0`, return early (0 indicates success with no triangles, <0 indicates error) [S1, unofficial].
4. Multiply `numTriangles` by 2 [S1, unofficial].
5. Assert `numTriangles < MAX_MESH_TRIANGLES` and `numVertices < MAX_MESH_VERTICES` [S1, unofficial].
6. Allocate `d_compactIndexBuffer` of size `numTriangles * 3` [S1, unofficial].
7. Launch `CompactMeshTriangles` kernel with global size `trianglesValidSize`, passing `d_trianglesValid`, `d_trianglesScan`, `d_indexBuffer`, `d_compactIndexBuffer` [S1, unofficial].
8. Allocate `d_vertexBuffer` of size `sizeof(MeshVertex) * numVertices` [S1, unofficial].
9. Compute `colour = ColourForMinLeafSize(clipmapNodeSize / CLIPMAP_LEAF_SIZE)` and pack into `cl_float4 d_colour = {colour.x, colour.y, colour.z, 0.f}` [S1, unofficial].
10. Launch `GenerateMeshVertexBuffer` kernel with global size `numVertices`, passing `octree.d_vertexPositions`, `octree.d_vertexNormals`, `octree.d_nodeMaterials`, `d_colour`, `d_vertexBuffer` [S1, unofficial].
11. Assign `d_vertexBuffer` to `meshBuffer->vertices`, `numVertices` to `meshBuffer->countVertices`, `d_compactIndexBuffer` to `meshBuffer->triangles`, and `numTriangles` to `meshBuffer->countTriangles` [S1, unofficial].

    buf = MeshBufferGPU()
    buf.countVertices = 0

def generate_mesh(octree, clipmapNodeSize, CLIPMAP_LEAF_SIZE, MAX_MESH_TRIANGLES, MAX_MESH_VERTICES, numVertices):
    # Step 1
    d_indexBuffer = [0] * (numVertices * 6 * 3)
    d_trianglesValid = [0] * (numVertices * 3)

    # Step 2
    d_trianglesScan, numTriangles = exclusive_scan(d_trianglesValid)

    # Step 3
    if numTriangles <= 0:
        return create_empty_mesh_buffer()

    # Step 4
    numTriangles *= 2

    # Step 5
    assert numTriangles < MAX_MESH_TRIANGLES
    assert numVertices < MAX_MESH_VERTICES

    # Step 6
    d_compactIndexBuffer = [0] * (numTriangles * 3)

    # Step 7
    trianglesValidSize = numVertices * 3
    launch_kernel(CompactMeshTriangles, trianglesValidSize,
                  [d_trianglesValid, d_trianglesScan, d_indexBuffer, d_compactIndexBuffer])

    # Step 8
    d_vertexBuffer = [MeshVertex() for _ in range(numVertices)]

    # Step 9
    ratio = clipmapNodeSize / CLIPMAP_LEAF_SIZE
    colour = ColourForMinLeafSize(ratio)
    d_colour = [colour[0], colour[1], colour[2], 0.0]

    # Step 10
    launch_kernel(GenerateMeshVertexBuffer, numVertices,
                  [octree['d_vertexPositions'], octree['d_vertexNormals'],
                   octree['d_nodeMaterials'], d_colour, d_vertexBuffer])

    # Step 11
    meshBuffer = MeshBufferGPU()
    meshBuffer.vertices = d_vertexBuffer
    meshBuffer.countVertices = numVertices
    meshBuffer.triangles = d_compactIndexBuffer
    meshBuffer.countTriangles = numTriangles

    return meshBuffer
