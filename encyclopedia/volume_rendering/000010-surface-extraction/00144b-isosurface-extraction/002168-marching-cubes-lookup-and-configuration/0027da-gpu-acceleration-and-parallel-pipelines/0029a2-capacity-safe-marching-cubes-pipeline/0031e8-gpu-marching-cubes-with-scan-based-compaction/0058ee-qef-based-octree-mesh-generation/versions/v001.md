# QEF-based Octree Mesh Generation

Also called: Compute-based Isosurface Extraction, GPU Mesh Compaction Pipeline

## Overview
A GPU compute pipeline that converts an octree of leaf nodes (extracted from a density field) into a compact triangle mesh using parallel index generation, prefix-sum compaction, and vertex attribute assembly [S1, unofficial]. It builds on [GPU Marching Cubes with Scan-Based Compaction](6632-gpu-marching-cubes-with-scan-based-compaction.md) by handling the final assembly of vertex attributes and index compaction for the extracted geometry.

## How it works
**Inputs:**
- `octree`: Contains `d_vertexPositions`, `d_vertexNormals`, `d_nodeMaterials`.
- `clipmapNodeSize`: Spatial resolution of the current octree chunk.
- `CLIPMAP_LEAF_SIZE`: Constant defining the leaf node size.
- `MAX_MESH_TRIANGLES`, `MAX_MESH_VERTICES`: Hardware or implementation limits.

**Outputs:**
- `meshBuffer`: A `MeshBufferGPU` structure containing the final mesh data.

**Data Structures:**
- `MeshBufferGPU`:
  - `vertices`: `cl::Buffer` (or equivalent GPU buffer) of type `MeshVertex`.
  - `countVertices`: `int`.
  - `triangles`: `cl::Buffer` of `int` indices.
  - `countTriangles`: `int`.
- `MeshVertex`: Struct containing:
  - `position`: `vec4` (or equivalent 4-component vector).
  - `normal`: `vec4` (or equivalent 4-component vector).
  - `material`: `vec4` (or equivalent 4-component vector).

**Steps:**
1. Allocate `d_indexBuffer` of size `numVertices * 6 * 3` and `d_trianglesValid` of size `numVertices * 3` [S1, unofficial].
2. Perform an exclusive scan on `d_trianglesValid` to produce `d_trianglesScan` and compute `numTriangles` [S1, unofficial].
3. If `numTriangles <= 0`, return early (0 indicates success with no triangles, <0 indicates error) [S1, unofficial].
4. Multiply `numTriangles` by 2 [S1, unofficial].
5. Assert `numTriangles < MAX_MESH_TRIANGLES` and `numVertices < MAX_MESH_VERTICES` [S1, unofficial].
6. Allocate `d_compactIndexBuffer` of size `numTriangles * 3` [S1, unofficial].
7. Launch `CompactMeshTriangles` kernel with global size `trianglesValidSize`, passing `d_trianglesValid`, `d_trianglesScan`, `d_indexBuffer`, `d_compactIndexBuffer` [S1, unofficial].
8. Allocate `d_vertexBuffer` of size `sizeof(MeshVertex) * numVertices` [S1, unofficial].
9. Compute `colour = ColourForMinLeafSize(clipmapNodeSize / CLIPMAP_LEAF_SIZE)` and pack into `cl_float4 d_colour = {colour.x, colour.y, colour.z, 0.f}` [S1, unofficial].
10. Launch `GenerateMeshVertexBuffer` kernel with global size `numVertices`, passing `octree.d_vertexPositions`, `octree.d_vertexNormals`, `octree.d_nodeMaterials`, `d_colour`, `d_vertexBuffer` [S1, unofficial].
11. Assign `d_vertexBuffer` to `meshBuffer->vertices`, `numVertices` to `meshBuffer->countVertices`, `d_compactIndexBuffer` to `meshBuffer->triangles`, and `numTriangles` to `meshBuffer->countTriangles` [S1, unofficial].

**Pseudocode:**
```python
def generate_mesh(octree, clipmapNodeSize, CLIPMAP_LEAF_SIZE, MAX_MESH_TRIANGLES, MAX_MESH_VERTICES):
    # Step 1: Allocate buffers for index generation and validity tracking
    # Note: numVertices is assumed to be known from previous stages (e.g., voxel classification)
    d_indexBuffer = allocate_buffer(numVertices * 6 * 3)
    d_trianglesValid = allocate_buffer(numVertices * 3)

    # Step 2: Exclusive scan to determine triangle counts
    d_trianglesScan, numTriangles = exclusive_scan(d_trianglesValid)

    # Step 3: Early exit if no triangles
    if numTriangles <= 0:
        return create_empty_mesh_buffer()

    # Step 4: Scale triangle count (implementation-specific scaling)
    numTriangles *= 2

    # Step 5: Assert bounds
    assert numTriangles < MAX_MESH_TRIANGLES
    assert numVertices < MAX_MESH_VERTICES

    # Step 6: Allocate compact index buffer
    d_compactIndexBuffer = allocate_buffer(numTriangles * 3)

    # Step 7: Compact triangles
    trianglesValidSize = numVertices * 3
    launch_kernel(CompactMeshTriangles, global_size=trianglesValidSize,
                  args=[d_trianglesValid, d_trianglesScan, d_indexBuffer, d_compactIndexBuffer])

    # Step 8: Allocate vertex buffer
    d_vertexBuffer = allocate_buffer(sizeof(MeshVertex) * numVertices)

    # Step 9: Compute color for material assignment
    ratio = clipmapNodeSize / CLIPMAP_LEAF_SIZE
    colour = ColourForMinLeafSize(ratio)
    d_colour = [colour.x, colour.y, colour.z, 0.0]

    # Step 10: Generate vertex attributes
    launch_kernel(GenerateMeshVertexBuffer, global_size=numVertices,
                  args=[octree.d_vertexPositions, octree.d_vertexNormals,
                        octree.d_nodeMaterials, d_colour, d_vertexBuffer])

    # Step 11: Assemble final mesh buffer
    meshBuffer = MeshBufferGPU()
    meshBuffer.vertices = d_vertexBuffer
    meshBuffer.countVertices = numVertices
    meshBuffer.triangles = d_compactIndexBuffer
    meshBuffer.countTriangles = numTriangles

    return meshBuffer
```

**Edge Cases and Pitfalls:**
- `numTriangles <= 0`: Handled by early return [S1, unofficial].
- Buffer overflows: Asserted against `MAX_MESH_TRIANGLES` and `MAX_MESH_VERTICES` [S1, unofficial].
- Precision: Not given in the sources.
