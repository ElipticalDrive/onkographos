# Marching Cubes Chunk Generation Pipeline

Also called: Chunk-based Marching Cubes, Procedural Terrain Generation with Marching Cubes

## Overview
This method is a procedural terrain generation pipeline that divides a 3D volume into overlapping chunks, populates them with noise-derived node values, and prepares chunk meshes for Marching Cubes surface extraction [S1, unofficial]. It builds on [GPU Marching Cubes Terrain Pipeline with Indirect Rendering](3803-gpu-marching-cubes-terrain-pipeline-with-indirect-rendering.md) by handling the CPU-side data preparation and chunk management required for the GPU-accelerated extraction [G]. Unlike single-volume extraction, this approach manages spatial locality and boundary continuity through overlapping node grids, ensuring seamless transitions between adjacent chunks [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Inputs**: Chunk dimensions (`xChunks`, `yChunks`, `zChunks`), resolution enum (`cubeResolution`), noise parameters (`seed`, `scale`, `octaves`, `persistence`, `lacunarity`, `dim`), and isovalue threshold (`surfaceLevel`) [S1, unofficial].
- **Outputs**: A collection of `ChunkMatrix` objects, each containing a 3D array of `Node` structures with position and value, ready for the Marching Cubes lookup and configuration step [S1, unofficial].

**Data Structures**
1.  **`Node`**: A struct containing:
    -   `position`: `Vector3` representing the 3D coordinate in world space.
    -   `value`: `float` representing the scalar field value at that node.
2.  **`ChunkMatrix`**: A class containing:
    -   `nodes`: 3D array of `Node` objects. Dimensions are `(xChunkCubeLength + 2) x (yChunkCubeLength + 2) x (zChunkCubeLength + 2)` to include overlapping boundary nodes [S1, unofficial].
    -   `vertices`: List of `Vector3` for generated mesh vertices.
    -   `indices`: List of `int` for generated mesh indices.
    -   `chunkObj`: Reference to the GameObject representing the chunk.
    -   `chunkMesh`: Reference to the MeshFilter/Mesh component.
    -   `chunksIndex`: `int[3]` storing the chunk's grid coordinates (x, y, z).
    -   `position`: `Vector3` storing the chunk's world-space origin.
3.  **`mapNoise`**: A 3D `float` array of size `[xMatrix, yMatrix, zMatrix]` storing precomputed noise values for the entire volume [S1, unofficial].

**Parameters**
-   `cubeResolution`: Enum controlling voxel density per chunk. Values: `INSANE=8`, `HIGH=4`, `MED=2`, `LOW=1` [S1, unofficial].
-   `surfaceLevel`: Isovalue threshold for Marching Cubes. Range `[0, 1]`, default `0.6f` [S1, unofficial].
-   `xChunks`, `yChunks`, `zChunks`: Number of chunks in each dimension. Defaults: `1` [S1, unofficial].
-   `seed`: Noise generation seed. Default `0` [S1, unofficial].
-   `scale`: Noise frequency multiplier. Default `0.15f`. Scaled by `cubeResolution` during initialization [S1, unofficial].
-   `octaves`: Number of noise octaves. Range `[0, 6]`, default `4` [S1, unofficial].
-   `persistence`: Amplitude multiplier per octave. Range `[0, 1]`, default `0.5f` [S1, unofficial].
-   `lacunarity`: Frequency multiplier per octave. Range `[0, 10]`, default `2` [S1, unofficial].
-   `dim`: Noise type selector. Options: `TWO_DIMENSIONAL_NOISE` (heightmap), `THREE_DIMENSIONAL_NOISE` (volumetric), `HALF_FULL` (binary split) [S1, unofficial].
-   `openMiddle`: Parameter for 2D heightmap noise generation. Default `10f` [S1, unofficial].
-   `softEdge`: Boolean flag enabling interpolation between voxels. Default `true` [S1, unofficial].

**Steps**
1.  **Calculate Global Dimensions**: Compute the total matrix dimensions for the noise map.
    $$xMatrix = (xChunkCubeLength - 2) \times xChunks + 2$$
    Apply the same formula for $yMatrix$ and $zMatrix$, where $xChunkCubeLength$ is the base chunk resolution derived from `cubeResolution` [S1, unofficial].
2.  **Generate Noise Map**: Call `Noise.Generate2DNoise`, `Generate3DNoise`, or `GenerateHallFullField` based on the `dim` enum. Fill the `mapNoise` array with dimensions `[xMatrix, yMatrix, zMatrix]` [S1, unofficial].
3.  **Iterate Chunks**: Loop through chunk coordinates $y$ from $0$ to $yChunks$, $z$ from $0$ to $zChunks$, and $x$ from $0$ to $xChunks$. For each chunk, call `CreateChunkMatrix(x, y, z)` [S1, unofficial].
4.  **Initialize Chunk Nodes**: Inside `CreateChunkMatrix`, loop over the chunk dimensions. Instantiate `Node(Vector3.zero, 0f)` for each grid position [S1, unofficial].
5.  **Set Chunk Position**: Calculate the world-space position of the chunk.
    $$currChunkMatrix.position = \left( \frac{x \times xChunkCubeLength}{cubeResolution}, \frac{y \times yChunkCubeLength}{cubeResolution}, \frac{z \times zChunkCubeLength}{cubeResolution} \right)$$
    Note: The source code divides by `cubeResolution` to normalize coordinates, implying `xChunkCubeLength` is in voxel units relative to the resolution enum [S1, unofficial].
6.  **Populate Node Values**: Assign values to each node by sampling from `mapNoise` using global coordinates calculated from the chunk's local offset and grid position, which naturally handles both internal and boundary nodes to ensure overlap with adjacent chunks [S1, unofficial]. If `softEdge` is true, apply interpolation between voxels [S1, unofficial].
7.  **Initialize Winding Order**: Set `windingOrder = new int[] { 2, 1, 0 }` to demonstrate triangle direction consistency [S1, unofficial].

**Pseudocode**
```python
class Vector3:
    def __init__(self, x, y, z):
        self.x = x
        self.y = y
        self.z = z

class Node:
    def __init__(self, position, value):
        self.position = position
        self.value = value

class ChunkMatrix:
    def __init__(self):
        self.nodes = None
        self.vertices = []
        self.indices = []
        self.chunk_obj = None
        self.chunk_mesh = None
        self.chunks_index = [0, 0, 0]
        self.position = Vector3(0, 0, 0)

def generate_chunks(x_chunks, y_chunks, z_chunks, cube_resolution, surface_level, seed, scale, octaves, persistence, lacunarity, dim, open_middle, soft_edge):
    # cube_resolution is an enum string; map to float for division
    res_map = {'INSANE': 8.0, 'HIGH': 4.0, 'MED': 2.0, 'LOW': 1.0}
    cube_res_val = res_map[cube_resolution]
    chunk_cube_length = cube_res_val

    x_matrix = (chunk_cube_length - 2) * x_chunks + 2
    y_matrix = (chunk_cube_length - 2) * y_chunks + 2
    z_matrix = (chunk_cube_length - 2) * z_chunks + 2

    # Sources do not provide the noise generation algorithm.
    map_noise = [[[0.0 for _ in range(z_matrix)] for _ in range(y_matrix)] for _ in range(x_matrix)]

    chunks = []
    for y in range(y_chunks):
        for z in range(z_chunks):
            for x in range(x_chunks):
                chunk = create_chunk_matrix(x, y, z, chunk_cube_length, cube_res_val, map_noise, soft_edge, x_matrix, y_matrix, z_matrix)
                chunks.append(chunk)
    return chunks

def create_chunk_matrix(x, y, z, chunk_cube_length, cube_res_val, map_noise, soft_edge, x_matrix, y_matrix, z_matrix):
    chunk_x_len = chunk_cube_length + 2
    chunk_y_len = chunk_cube_length + 2
    chunk_z_len = chunk_cube_length + 2

    nodes = [[[None for _ in range(chunk_x_len)] for _ in range(chunk_z_len)] for _ in range(chunk_y_len)]

    pos_x = (x * chunk_cube_length) / cube_res_val
    pos_y = (y * chunk_cube_length) / cube_res_val
    pos_z = (z * chunk_cube_length) / cube_res_val
    position = Vector3(pos_x, pos_y, pos_z)

    for i in range(chunk_y_len):
        for j in range(chunk_z_len):
            for k in range(chunk_x_len):
                global_x = x * (chunk_cube_length - 2) + k
                global_y = y * (chunk_cube_length - 2) + i
                global_z = z * (chunk_cube_length - 2) + j

                # Guard against out-of-bounds at volume edges
                global_x = min(global_x, x_matrix - 1)
                global_y = min(global_y, y_matrix - 1)
                global_z = min(global_z, z_matrix - 1)

                noise_value = map_noise[global_x][global_y][global_z]

                node_pos = Vector3(
                    pos_x + (k / cube_res_val),
                    pos_y + (i / cube_res_val),
                    pos_z + (j / cube_res_val)
                )
                nodes[i][j][k] = Node(node_pos, noise_value)

    chunk = ChunkMatrix()
    chunk.nodes = nodes
    chunk.position = position
    chunk.chunks_index = [x, y, z]
    chunk.vertices = []
    chunk.indices = []
    return chunk
```

**Edge Cases and Pitfalls**
-   **Chunk Boundary Seams**: Without overlapping boundary nodes, transitions between chunks will show artifacts. This is solved by adding 2 extra nodes per dimension to each chunk's node grid, which are filled with noise from the global `mapNoise` array [S1, unofficial].
-   **Resolution Scaling Mismatch**: Brush interaction or editing values must be scaled by `cubeResolution` to maintain consistent behavior across different voxel densities [S1, unofficial].

## Background
This method originates from an educational Marching Cubes project by millerc3, designed to be readable and followable for learners transitioning from C/C++ to Unity/C# [S1, unofficial]. It is based heavily on Paul Bourke's original Marching Cubes algorithm and the Scrawk repository implementation [S1, unofficial]. The project aims to provide a clear, unoptimized reference implementation for understanding the algorithm and engine integration [S1, unofficial].
