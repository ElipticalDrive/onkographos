# Capacity-safe slab-based Marching Cubes

Also called: Capacity-safe slab-based isososurface extraction, Capacity-safe slab-based isosurface extraction pipeline, Capacity-safe tiled Marching Cubes, Two-pass tiled Marching Cubes, inclusive slab partitioning with exact allocation, slab-based two-pass GPU isosurface extraction

## Overview
A GPU-accelerated isosurface extraction pipeline that partitions the z-axis into slabs using inclusive indexing to eliminate boundary cracks and employs a two-pass counting/exact allocation strategy to prevent output-buffer overflow. Unlike standard Marching Cubes which requires fixed-size buffers or atomic counters, this method computes the exact vertex count per slab via a prefix-sum scan, allowing for zero-copy streaming of geometry directly into CUDA–OpenGL interoperable buffers without intermediate CPU-side copies.

## How it works
**Inputs and Outputs**
*   **Input**: A 3D scalar volume $V$ defined on a grid of dimensions $N_x \times N_y \times N_z$, where $V: \{0, \dots, N_x-1\} \times \{0, \dots, N_y-1\} \times \{0, \dots, N_z-1\} \to \mathbb{R}$. An isovalue $\tau \in \mathbb{R}$.
*   **Output**: A Vertex Buffer Object (VBO) containing two arrays: `pos` (positions) and `nrm` (normals). The total capacity is $N$ vertices, where $N$ is the exact sum of vertices generated by all cells. Each triangle writes 3 consecutive vertices. For each vertex, `pos` stores a 3D vector and `nrm` stores a 3D vector.

**Data Structures**
*   **Linear Index**: Cells are mapped to a linear index for array storage:
    $$ \text{lin}(x,y,z) = (z N_y + y) N_x + x $$
    where $N_x, N_y, N_z$ are grid dimensions. Note that Marching Cubes operates on cells, so valid cell indices are $0 \le i \le N_x-2$, $0 \le j \le N_y-2$, $0 \le k \le N_z-2$.
*   **Slab Definition**: The z-axis is partitioned into slabs of thickness $S$. For slab $s$, the set of valid cells $\mathcal{K}_s$ is defined as the closed interval:
    $$ \mathcal{K}_s = \{ k \mid k_{\text{begin}}(s) \le k \le k_{\text{end}}(s) \} $$
    This inclusive indexing ensures that the $k+1$ corner access required by MC remains valid at slab boundaries.
*   **Count Array**: A temporary array `countss` indexed by linear cell index $\ell = \text{lin}(i,j,k)$ stores the number of vertices $n_{ijk}$ generated by cell $(i,j,k)$.
*   **Offset Array**: An array `offsets` storing the exclusive prefix-sum of `countss` for the current slab.

**Parameters**
*   **Slab Thickness ($S$)**: Recommended range $[48, 96]$ for a $512^3$ grid [S1].
*   **Partial Slabs**: If $N_z-1$ is not divisible by $S$, the final slab is processed as a partial slab without padding. Its upper cell index is clamped to $N_z-2$ [S1].

**Algorithm Steps**
1.  **Pass 1: Classify and Scan**
    For each slab $s$:
    1.  Initialize `countss` to zero.
    2.  For each cell $(i,j,k)$ where $k \in \mathcal{K}_s$:
        a. Compute the MC case index $c = \text{caseIndex}(V, i, j, k, \tau)$ based on the sign configuration of the 8 vertices relative to $\tau$.
        b. Retrieve the vertex count $n_{ijk} = \text{numVerts}[c]$ from the standard Marching Cubes lookup table.
        c. Store $n_{ijk}$ in `countss[lin(i,j,k)]`.
    3.  Compute an exclusive prefix-sum (scan) over `countss` to generate `offsets`.
    4.  Calculate the slab-level total $N_s = \text{offsets}[\text{last}] + \text{countss}[\text{last}]$.
    5.  Accumulate the global total $N = \sum_s N_s$.
    6.  Determine the base offset for the slab: $\text{base}[s] = \sum_{t < s} N_t$.

2.  **Allocation**
    Allocate an interoperable VBO with exactly $N$ vertex capacity for both positions and normals [S1].

3.  **Pass 2: Generate**
    For each slab $s$:
    1.  For each cell $(i,j,k)$ where $k \in \mathcal{K}_s$:
        a. Compute $c = \text{caseIndex}(V, i, j, k, \tau)$.
        b. If $\text{numVerts}[c] \neq 0$:
            i. Compute edge intersection vertices via linear interpolation: $\text{edgeVerts}[0..11] \leftarrow \text{edge\_lerp}(V, i, j, k, \tau)$. The interpolation parameter for an edge between vertices with values $v_1$ and $v_2$ is $\text{param} = \frac{\tau - v_1}{v_2 - v_1}$, and the position is $\text{pos} = \text{lerp}(\text{vertex}_1, \text{vertex}_2, \text{param})$.
            ii. Determine the destination address in the VBO: $\text{dst} = \text{base}[s] + \text{offsets}[\text{lin}(i,j,k)]$.
            iii. Iterate through the triangle edge list $\text{triTable}[c][t..t+2]$ for $t$ from $0$ to $\text{numVerts}[c]-1$ with step 3.
            iv. If any edge index $e_0, e_1, e_2$ is $< 0$, break the loop (handles empty triangles) [S1].
            v. Retrieve vertices $\mathbf{p}_0, \mathbf{p}_1, \mathbf{p}_2$ from $\text{edgeVerts}$.
            vi. Compute the face normal $\mathbf{n}$ to enforce counterclockwise winding:
                $$ \mathbf{n} = \frac{(\mathbf{p}_1 - \mathbf{p}_0) \times (\mathbf{p}_2 - \mathbf{p}_0)}{\|(\mathbf{p}_1 - \mathbf{p}_0) \times (\mathbf{p}_2 - \mathbf{p}_0)\|} $$
            vii. Write positions $\{\mathbf{p}_0, \mathbf{p}_1, \mathbf{p}_2\}$ to `pos[dst:dst+2]` and normals $\{\mathbf{n}, \mathbf{n}, \mathbf{n}\}$ to `nrm[dst:dst+2]`.
            viii. Increment $\text{dst}$ by 3.

    """
    V: 3D array of scalar values, shape (Nx, Ny, Nz)

    tau: Isovalue
    S: Slab thickness
    Returns: pos (N, 3), nrm (N, 3)
    """

    numVerts = [0] * 256
    triTable = [[[] for _ in range(256)] for _ in range(5)] # Simplified structure
    # Note: In implementation, these are standard MC lookup tables.

    # Pass 1: Classify and Scan
    global_N = 0
    slab_bases = []
    
    # Determine slab ranges
    # k ranges from 0 to Nz-2 (cells)
    num_cells_z = Nz - 1
    slabs = []
    k = 0
    while k < num_cells_z:
        k_end = min(k + S - 1, num_cells_z - 1)
        slabs.append((k, k_end))
        k = k_end + 1

    for s_idx, (k_start, k_end) in enumerate(slabs):
        slab_N = 0
        # Temporary arrays for this slab
        # Map linear index to local index for scan
        # Linear index lin(i,j,k) = (k*Ny + y)*Nx + x
        # We only need to process cells in this slab
        
        # We can use a flat array for counts if we map linear indices, 
        # but for simplicity, we assume a dense array or hash map for counts.
        # Given Nx*Ny*Nz can be large, we process cell by cell.
        
        # To perform scan, we need an array of counts indexed by linear position.
        # Let's assume we allocate a buffer for the slab's cells.
        
        slab_counts = [] # List of (linear_index, count)
        
        for k in range(k_start, k_end + 1):
            for j in range(Ny - 1):
                for i in range(Nx - 1):
                    c = caseIndex(V, i, j, k, tau)
                    n = numVerts[c]
                    lin_idx = (k * Ny + j) * Nx + i
                    slab_counts.append((lin_idx, n))
                    slab_N += n
        
        # Sort by linear index to perform scan
        slab_counts.sort(key=lambda x: x[0])
        
        # Exclusive scan
        offsets = []
        current_offset = 0
        for lin_idx, n in slab_counts:
            offsets.append((lin_idx, current_offset))
            current_offset += n
            
        slab_bases.append(global_N)
        global_N += slab_N

    # Allocate output buffers
    N = global_N
    pos = [None] * N
    nrm = [None] * N

    # Pass 2: Generate
    for s_idx, (k_start, k_end) in enumerate(slabs):
        base_offset = slab_bases[s_idx]
        
        # Re-generate counts and offsets for this slab to avoid storing all
        # Or reuse the computed offsets if stored. Here we recompute for clarity.
        slab_counts = []
        for k in range(k_start, k_end + 1):
            for j in range(Ny - 1):
                for i in range(Nx - 1):
                    c = caseIndex(V, i, j, k, tau)
                    n = numVerts[c]
                    lin_idx = (k * Ny + j) * Nx + i
                    slab_counts.append((lin_idx, n))
        
        slab_counts.sort(key=lambda x: x[0])
        
        # Compute offsets again
        current_offset = 0
        for lin_idx, n in slab_counts:
            offset = current_offset
            current_offset += n
            
            if n > 0:
                # Find i, j, k from lin_idx
                # lin_idx = (k*Ny + j)*Nx + i
                # k = lin_idx // (Ny * Nx)
                # rem = lin_idx % (Ny * Nx)
                # j = rem // Nx
                # i = rem % Nx
                k = lin_idx // (Ny * Nx)
                rem = lin_idx % (Ny * Nx)
                j = rem // Nx
                i = rem % Nx
                
                # Compute edge vertices
                edge_verts = edge_lerp(V, i, j, k, tau)
                
                dst = base_offset + offset
                
                # Iterate triangles
                tri_list = triTable[c] # List of edge triplets
                t = 0
                while t < len(tri_list):
                    e0, e1, e2 = tri_list[t], tri_list[t+1], tri_list[t+2]
                    
                    if e0 < 0 or e1 < 0 or e2 < 0:
                        break
                        
                    p0 = edge_verts[e0]
                    p1 = edge_verts[e1]
                    p2 = edge_verts[e2]
                    
                    # Compute normal
                    v1 = p1 - p0
                    v2 = p2 - p0
                    cross = cross_product(v1, v2)
                    norm = normalize(cross)
                    
                    # Write to buffers
                    pos[dst] = p0
                    pos[dst+1] = p1
                    pos[dst+2] = p2
                    
                    nrm[dst] = norm
                    nrm[dst+1] = norm
                    nrm[dst+2] = norm
                    
                    dst += 3
                    t += 3

    return pos, nrm

**Edge Cases and Pitfalls**
*   **Boundary Cracks**: Using inclusive slab indexing ($\mathcal{K}_s$ includes $k_{\text{end}}(s)$) ensures that the $k+1$ corner access required by MC is valid at slab boundaries, eliminating omissions/duplications and cracks caused by off-by-one inconsistencies [S1].
*   **Empty Triangles**: The algorithm checks if edge indices $e_0, e_1, e_2$ are $< 0$. If so, it breaks the triangle loop, handling cases where the triangle table entry indicates no triangle for that specific triplet [S1].
*   **Partial Slabs**: If $N_z-1$ is not divisible by $S$, the final slab is processed as a partial slab without padding, with its upper cell index clamped to $N_z-2$ [S1].

## Operating characteristics
*   **Time Complexity**: $O(M)$ for both passes, where $M = (N_x-1)(N_y-1)(N_z-1)$ is the number of cells [S1].
*   **Memory Complexity**: The additional storage consists of slab-local count and offset arrays. The output buffers are allocated according to the exact number of generated vertices $N$. For a $512^3$ grid, GPU memory usage is less than 11 GB [S1].
*   **Performance**: On electromagnetic-potential fields with resolutions up to $512^3$, the method generates approximately 42.81 million vertices in 44.7 ms, using less than 11 GB of GPU memory, and renders the resulting geometry at 28.6 FPS [S1].
*   **Strengths**: Prevents buffer overruns by exact allocation; eliminates boundary cracks via inclusive indexing; enables zero-copy streaming to OpenGL buffers; suitable for large scalar grids.
*   **Limitations**: Less suitable for sharp-feature preservation than methods such as Dual Contouring or MC33 [S1]. Limited to volumes that fit within the memory of a single GPU [S1].

## Background
The method was introduced in a framework for visualizing 3D plasma simulation data (fusion-plasma electromagnetic potential) on GPUs with CUDA–OpenGL interoperability [S1]. It addresses the limitations of standard Marching Cubes, which suffers from topological discontinuities and holes due to boundary inconsistencies, and differs from HistoPyramids/Flying Edges by specializing counting/compaction for tightly coupled extraction, rendering, and engine integration [S1]. It is used in a standalone renderer and integrated into Unreal Engine for volume rendering, explicit-isosurface inspection, particle-trajectory visualization, clipping, and VR-based spatial exploration [S1].
