# Capacity-safe slab-based Marching Cubes

Also called: Capacity-safe slab-based isososurface extraction, Capacity-safe slab-based isosurface extraction pipeline, Capacity-safe tiled Marching Cubes, Two-pass tiled Marching Cubes, inclusive slab partitioning with exact allocation, slab-based two-pass GPU isosurface extraction

## Overview
This method is a GPU-accelerated isosurface extraction pipeline that partitions the z-axis into slabs and uses a two-pass counting/exact allocation strategy to prevent slab-boundary omissions and output-buffer overflow for large scalar grids [S1]. It differs from standard Marching Cubes by resolving topological discontinuities and holes via boundary-consistent slab processing, and differs from HistoPyramids/Flying Edges by specializing counting/compaction for tightly coupled extraction, rendering, and engine integration [S1]. Unlike implicit isosurface raycasting, this method generates explicit geometric assets (vertices/normals) suitable for mesh-based interaction tools and OBJ export [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A 3D scalar volume $V$ defined on a grid of dimensions $N_x \times N_y \times N_z$, and an isovalue $\tau$.
*   **Output:** A Vertex Buffer Object (VBO) containing two arrays: `pos` (positions) and `nrm` (normals). The total capacity is $N$ vertices, where $N$ is the exact sum of vertices generated by all cells. Each triangle writes 3 consecutive vertices. For each vertex, `pos` stores a 3D vector and `nrm` stores a 3D vector [S1].

**Data Structures**
*   **Grid Dimensions:** $N_x, N_y, N_z$ (samples).
*   **Cell Indices:** $(i,j,k)$ where $0 \le i \le N_x-2$, $0 \le j \le N_y-2$, $0 \le k \le N_z-2$.
*   **Linear Index:** $\text{lin}(x,y,z) = (z N_y + y) N_x + x$ [S1].
*   **Slab Parameters:** Slab thickness $S$. The z-axis is partitioned into slabs. For slab $s$, the valid cells are defined by the closed interval $\mathcal{K}_s = \{k \mid k_{\text{begin}}(s) \le k \le k_{\text{end}}(s)\}$ [S1].
*   **Count Arrays:**
    *   `countss`: Array indexed by linear cell index $\text{lin}(i,j,k)$, storing $n_{ijk} = \text{numVerts}[c]$.
    *   `offsets`: Exclusive prefix-sum of `countss` for the current slab.
*   **Global State:**
    *   $N_s$: Total vertices generated in slab $s$.
    *   $N$: Global total vertices, $N = \sum_s N_s$.
    *   `base[s]`: Cumulative vertex offset for slab $s$, $\sum_{t < s} N_t$ [S1].

**Parameters**
*   **Slab Thickness ($S$):** Recommended range $[48, 96]$ for a $512^3$ grid [S1].
*   **Boundary Handling:** If $N_z-1$ is not divisible by $S$, the final slab is processed as a partial slab without padding, with its upper cell index clamped to $N_z-2$ [S1].

**Algorithm Steps**
1.  **Pass 1 (Classify/Scan):**
    *   Initialize global vertex count $N \leftarrow 0$.
    *   For each slab $s$:
        *   For each cell $(i,j,k)$ with $k \in \mathcal{K}_s$:
            *   Compute case index $c = \text{caseIndex}(V, i, j, k, \tau)$.
            *   Compute vertex count $n_{ijk} = \text{numVerts}[c]$.
            *   Store $n_{ijk}$ in `countss[lin(i,j,k)]`.
        *   Compute exclusive prefix-sum (scan) over `countss` to generate `offsets`.
        *   Calculate slab total $N_s = \text{offsets}[\text{last}] + \text{countss}[\text{last}]$.
        *   Set slab base offset $\text{base}[s] \leftarrow N$.
        *   Update global count $N \leftarrow N + N_s$.
    *   Allocate an interoperable Vertex Buffer Object (VBO) with exactly $N$ vertex capacity [S1].

2.  **Pass 2 (Generate):**
    *   For each slab $s$:
        *   For each cell $(i,j,k)$ with $k \in \mathcal{K}_s$:
            *   Compute case index $c = \text{caseIndex}(V, i, j, k, \tau)$.
            *   If $\text{numVerts}[c] \neq 0$:
                *   Compute edge vertices via linear interpolation: $\text{edgeVerts}[0..11] \leftarrow \text{edge\_lerp}(V, i, j, k, \tau)$.
                *   Compute destination address: $\text{dst} = \text{base}[s] + \text{offsets}[\text{lin}(i,j,k)]$.
                *   Iterate through the triangle edge list $\text{triTable}[c][t..t+2]$ for $t$ from $0$ to $\text{numVerts}[c]-1$ with step 3.
                *   If any edge index $e_0, e_1, e_2$ is $< 0$, break the loop.
                *   Retrieve vertices $\mathbf{p}_0, \mathbf{p}_1, \mathbf{p}_2$ from $\text{edgeVerts}$.
                *   Compute face normal $\mathbf{n} = \text{normalize}((\mathbf{p}_1 - \mathbf{p}_0) \times (\mathbf{p}_2 - \mathbf{p}_0))$ to enforce counterclockwise winding.
                *   Write positions $\{\mathbf{p}_0, \mathbf{p}_1, \mathbf{p}_2\}$ and normals $\{\mathbf{n}, \mathbf{n}, \mathbf{n}\}$ to $\text{pos}[\text{dst}:\text{dst}+2]$ and $\text{nrm}[\text{dst}:\text{dst}+2]$.
                *   Increment $\text{dst}$ by 3 [S1].

**Pseudocode**
```python
def capacity_safe_slab_marching_cubes(V, Nx, Ny, Nz, tau, S):
    # Pass 1: Classify and Scan
    global_N = 0
    slab_bases = []
    
    # Determine slab ranges
    num_slabs = (Nz - 1 + S - 1) // S  # Ceiling division for number of slabs
    
    for s in range(num_slabs):
        k_begin = s * S
        k_end = min(k_begin + S - 1, Nz - 2) # Clamp to valid cell index
        
        # Initialize slab-local count array
        # Size depends on number of cells in slab: Nx-1, Ny-1, and (k_end - k_begin + 1)
        slab_height = k_end - k_begin + 1
        slab_cell_count = (Nx - 1) * (Ny - 1) * slab_height
        countss = [0] * slab_cell_count
        offsets = [0] * slab_cell_count
        
        # Classify cells in this slab
        idx = 0
        for k in range(k_begin, k_end + 1):
            for j in range(Ny - 1):
                for i in range(Nx - 1):
                    c = case_index(V, i, j, k, tau)
                    n_ijk = num_verts[c]
                    lin_idx = (k * Ny + j) * Nx + i
                    # Note: lin_idx is global, but we store in slab-local array
                    # The source uses lin(i,j,k) as index into countss. 
                    # Assuming countss is indexed by global linear index for simplicity 
                    # or mapped appropriately. The source says "indexed by the linear cell index lin(i,j,k)".
                    # However, scan is per slab. We assume countss is sized to cover the slab's cells.
                    # To be precise with source "countss[lin(i,j,k)]", we might need a global count array 
                    # or map local index. The source implies a slab-local scan.
                    # Let's assume countss is indexed by a local linear index for the slab, 
                    # or the source implies a global array but only scans the slab range.
                    # Given "exclusive prefix-sum ... for the slab", we use a local array.
                    
                    # Mapping global lin to local index for the slab array:
                    # local_lin = ((k - k_begin) * (Ny - 1) + j) * (Nx - 1) + i
                    local_lin = ((k - k_begin) * (Ny - 1) + j) * (Nx - 1) + i
                    countss[local_lin] = n_ijk
        
        # Exclusive Scan
        if slab_cell_count > 0:
            offsets[0] = 0
            for i in range(1, slab_cell_count):
                offsets[i] = offsets[i-1] + countss[i-1]
        
        # Slab total
        last_idx = slab_cell_count - 1
        N_s = offsets[last_idx] + countss[last_idx]
        
        slab_bases.append(global_N)
        global_N += N_s
        
    # Allocate VBO
    vbo_pos = [None] * global_N
    vbo_nrm = [None] * global_N
    
    # Pass 2: Generate
    for s in range(num_slabs):
        k_begin = s * S
        k_end = min(k_begin + S - 1, Nz - 2)
        
        slab_height = k_end - k_begin + 1
        slab_cell_count = (Nx - 1) * (Ny - 1) * slab_height
        
        # Re-compute offsets or store them from Pass 1. 
        # For implementation from text, we re-scan or assume stored.
        # Here we re-scan for self-containment.
        countss = [0] * slab_cell_count
        offsets = [0] * slab_cell_count
        
        idx = 0
        for k in range(k_begin, k_end + 1):
            for j in range(Ny - 1):
                for i in range(Nx - 1):
                    c = case_index(V, i, j, k, tau)
                    n_ijk = num_verts[c]
                    local_lin = ((k - k_begin) * (Ny - 1) + j) * (Nx - 1) + i
                    countss[local_lin] = n_ijk
                    
        if slab_cell_count > 0:
            offsets[0] = 0
            for i in range(1, slab_cell_count):
                offsets[i] = offsets[i-1] + countss[i-1]
                
        base_s = slab_bases[s]
        
        for k in range(k_begin, k_end + 1):
            for j in range(Ny - 1):
                for i in range(Nx - 1):
                    c = case_index(V, i, j, k, tau)
                    if num_verts[c] != 0:
                        edge_verts = edge_lerp(V, i, j, k, tau)
                        local_lin = ((k - k_begin) * (Ny - 1) + j) * (Nx - 1) + i
                        dst = base_s + offsets[local_lin]
                        
                        num_tri_verts = num_verts[c]
                        t = 0
                        while t < num_tri_verts:
                            e0 = tri_table[c][t]
                            e1 = tri_table[c][t+1]
                            e2 = tri_table[c][t+2]
                            
                            if e0 < 0 or e1 < 0 or e2 < 0:
                                break
                                
                            p0 = edge_verts[e0]
                            p1 = edge_verts[e1]
                            p2 = edge_verts[e2]
                            
                            # Compute normal
                            v1 = p1 - p0
                            v2 = p2 - p0
                            cross = cross_product(v1, v2)
                            norm = normalize(cross)
                            
                            # Write to VBO
                            vbo_pos[dst] = p0
                            vbo_nrm[dst] = norm
                            vbo_pos[dst+1] = p1
                            vbo_nrm[dst+1] = norm
                            vbo_pos[dst+2] = p2
                            vbo_nrm[dst+2] = norm
                            
                            dst += 3
                            t += 3
                            
    return vbo_pos, vbo_nrm

def case_index(V, i, j, k, tau):
    # Standard MC case index calculation
    # Assuming V is indexed by (x,y,z)
    # Vertices 0-7 correspond to corners of cell (i,j,k)
    # Bit i is set if V(vertex_i) < tau (or > tau, convention dependent)
    # This matches the parent article's definition.
    c = 0
    # Vertex 0: (i, j, k)
    if V[i, j, k] < tau: c |= 1
    # Vertex 1: (i+1, j, k)
    if V[i+1, j, k] < tau: c |= 2
    # Vertex 2: (i+1, j+1, k)
    if V[i+1, j+1, k] < tau: c |= 4
    # Vertex 3: (i, j+1, k)
    if V[i, j+1, k] < tau: c |= 8
    # Vertex 4: (i, j, k+1)
    if V[i, j, k+1] < tau: c |= 16
    # Vertex 5: (i+1, j, k+1)
    if V[i+1, j, k+1] < tau: c |= 32
    # Vertex 6: (i+1, j+1, k+1)
    if V[i+1, j+1, k+1] < tau: c |= 64
    # Vertex 7: (i, j+1, k+1)
    if V[i, j+1, k+1] < tau: c |= 128
    return c

def edge_lerp(V, i, j, k, tau):
    # Returns 12 edge intersection points
    # Edge 0: (0,1) -> (i,j,k) to (i+1,j,k)
    # Linear interpolation: P = V0 + (tau - V0) / (V1 - V0) * (P1 - P0)
    # Assuming unit cube coordinates for vertices
    edges = [None] * 12
    
    # Helper for linear interpolation
    def lerp(v0, v1, p0, p1):
        if abs(v1 - v0) < 1e-9:
            return (p0 + p1) / 2.0
        t = (tau - v0) / (v1 - v0)
        return p0 + t * (p1 - p0)
        
    # Bottom face (z=k)
    v0 = V[i, j, k]; v1 = V[i+1, j, k]; v2 = V[i+1, j+1, k]; v3 = V[i, j+1, k]
    edges[0] = lerp(v0, v1, (i, j, k), (i+1, j, k))
    edges[1] = lerp(v1, v2, (i+1, j, k), (i+1, j+1, k))
    edges[2] = lerp(v2, v3, (i+1, j+1, k), (i, j+1, k))
    edges[3] = lerp(v3, v0, (i, j+1, k), (i, j, k))
    
    # Top face (z=k+1)
    v4 = V[i, j, k+1]; v5 = V[i+1, j, k+1]; v6 = V[i+1, j+1, k+1]; v7 = V[i, j+1, k+1]
    edges[4] = lerp(v4, v5, (i, j, k+1), (i+1, j, k+1))
    edges[5] = lerp(v5, v6, (i+1, j, k+1), (i+1, j+1, k+1))
    edges[6] = lerp(v6, v7, (i+1, j+1, k+1), (i, j+1, k+1))
    edges[7] = lerp(v7, v4, (i, j+1, k+1), (i, j, k+1))
    
    # Vertical edges
    edges[8] = lerp(v0, v4, (i, j, k), (i, j, k+1))
    edges[9] = lerp(v1, v5, (i+1, j, k), (i+1, j, k+1))
    edges[10] = lerp(v2, v6, (i+1, j+1, k), (i+1, j+1, k+1))
    edges[11] = lerp(v3, v7, (i, j+1, k), (i, j+1, k+1))
    
    return edges

def cross_product(a, b):
    return (a[1]*b[2] - a[2]*b[1], a[2]*b[0] - a[0]*b[2], a[0]*b[1] - a[1]*b[0])

def normalize(v):
    mag = (v[0]**2 + v[1]**2 + v[2]**2)**0.5
    if mag == 0: return (0,0,0)
    return (v[0]/mag, v[1]/mag, v[2]/mag)
```

**Edge Cases and Pitfalls**
*   **Boundary Cracks:** Using inclusive slab indexing ($\mathcal{K}_s$ includes $k_{\text{end}}(s)$) ensures that the $k+1$ corner access required by MC remains valid at slab boundaries, eliminating omissions/duplications and cracks caused by off-by-one inconsistencies [S1].
*   **Empty Triangles:** The algorithm checks if edge indices $e_0, e_1, e_2$ are $< 0$. If so, it breaks the triangle loop, handling cases where the triangle table entry indicates no triangle for that specific triplet [S1].
*   **Partial Slabs:** If $N_z-1$ is not divisible by $S$, the final slab is processed as a partial slab without padding, with its upper cell index clamped to $N_z-2$ [S1].

## Operating characteristics
*   **Time Complexity:** $O(M)$ for both passes, where $M = (N_x-1)(N_y-1)(N_z-1)$ is the number of cells [S1].
*   **Memory Complexity:** The additional storage consists of the slab-local count and offset arrays. The output buffers are allocated according to the exact number of generated vertices $N$ [S1].
*   **Measured Performance:** On electromagnetic-potential fields with resolutions up to $512^3$, the method generates approximately 42.81 million vertices in 44.7 ms, uses less than 11 GB of GPU memory, and renders the resulting geometry at 28.6 FPS [S1].
*   **Strengths:** Prevents buffer overruns, guarantees crack-free surfaces at slab boundaries, and enables zero-copy streaming to OpenGL buffers [S1].
*   **Limitations:** Less suitable for sharp-feature preservation than methods such as Dual Contouring or MC33. Limited to volumes that fit within the memory of a single GPU [S1].

## Background
This method was presented in a paper describing a GPU-accelerated visualization framework for interactive exploration of fusion-plasma simulation data [S1]. The primary technical contribution is a capacity-safe isosurface-extraction pipeline that combines inclusive slab partitioning with a two-pass counting and exact allocation strategy [S1]. It is used in a standalone renderer and integrated into Unreal Engine for volume rendering, explicit-isosurface inspection, particle-trajectory visualization, clipping, and VR-based spatial exploration [S1].
