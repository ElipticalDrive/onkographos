# Capacity-safe slab-based Marching Cubes

Also called: Capacity-safe slab-based isososurface extraction, Capacity-safe slab-based isosurface extraction pipeline, Capacity-safe tiled Marching Cubes, Two-pass tiled Marching Cubes, inclusive slab partitioning with exact allocation, slab-based two-pass GPU isosurface extraction

## Overview
This method is a GPU-accelerated isosurface extraction pipeline that partitions the z-axis into slabs and uses a two-pass counting/exact allocation strategy to prevent output-buffer overflow and eliminate boundary cracks in large scalar grids [S1]. It differs from standard parallel Marching Cubes by using inclusive slab indexing to ensure topological consistency at slab boundaries, and differs from histogram-pyramid approaches by specializing the counting phase for exact, zero-copy buffer allocation suitable for engine integration [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D scalar volume $V$ defined on a grid of dimensions $N_x \times N_y \times N_z$, and an isovalue $\tau$.
*   **Output:** A Vertex Buffer Object (VBO) containing two arrays: `pos` (positions) and `nrm` (normals). The total capacity is $N$ vertices, where $N$ is the exact sum of vertices generated by all cells. Each triangle writes 3 consecutive vertices. For each vertex, `pos` stores a 3D vector and `nrm` stores a 3D vector [S1].

**Data Structures:**
*   **Lookup Tables:** Uses the standard `edgeTable` and `triangleTable` (or `triTable`) from [Marching Cubes Lookup and Configuration](2518-marching-cubes-lookup-and-configuration.md). `triTable[c][t..t+2]` stores the edge indices for the $t$-th triangle of case $c$. `numVerts[c]` is the number of vertices for case $c$ [S1].
*   **Slab Partitioning:** The z-axis is partitioned into slabs of thickness $S$. The set of valid cells for slab $s$ is defined as the closed interval $\mathcal{K}_s = \{k \mid k_{begin}(s) \le k \le k_{end}(s)\}$. This inclusive indexing ensures that the $k+1$ corner access required by MC remains valid at slab boundaries [S1].
*   **Count/Offset Arrays:** Per-slab arrays `countss` and `offsets` indexed by the linear cell index $\ell = lin(i,j,k)$ [S1].

**Linear Index Formula:**
$$ lin(x,y,z) = (z N_y + y) N_x + x $$
where $N_x, N_y, N_z$ are the grid dimensions [S1].

**Parameters:**
*   **Slab Thickness ($S$):** Recommended range $[48, 96]$ for a $512^3$ grid [S1].
*   **Boundary Handling:** If $N_z - 1$ is not divisible by $S$, the final slab is processed as a partial slab without padding, with its upper cell index clamped to $N_z - 2$ [S1].

**Algorithm Steps:**

1.  **Pass 1: Classify and Scan (Counting)**
    *   Initialize global vertex count $N \leftarrow 0$.
    *   For each slab $s$:
        *   For each cell $(i,j,k)$ where $k \in \mathcal{K}_s$:
            *   Compute case index $c = \text{caseIndex}(V, i, j, k, \tau)$.
            *   Get vertex count $n_{ijk} = \text{numVerts}[c]$.
            *   Store $n_{ijk}$ in `countss[lin(i,j,k)]`.
        *   Compute exclusive prefix-sum (scan) over `countss` to generate `offsets`.
        *   Calculate slab-level total $N_s = \text{offsets}[\text{last}] + \text{countss}[\text{last}]$.
        *   Calculate slab base offset $\text{base}[s] = N$.
        *   Update global count $N \leftarrow N + N_s$.
    *   Allocate VBO with exactly $N$ vertex capacity [S1].

2.  **Pass 2: Generate (Geometry)**
    *   For each slab $s$:
        *   For each cell $(i,j,k)$ where $k \in \mathcal{K}_s$:
            *   Compute $c = \text{caseIndex}(V, i, j, k, \tau)$.
            *   If $\text{numVerts}[c] \neq 0$:
                *   Compute edge vertices: $\text{edgeVerts}[0..11] \leftarrow \text{edge\_lerp}(V, i, j, k, \tau)$.
                *   Determine destination address: $\text{dst} = \text{base}[s] + \text{offsets}[lin(i,j,k)]$.
                *   Iterate through triangle edge list `triTable[c][t..t+2]` for $t$ from $0$ to $\text{numVerts}[c]-1$ with step 3:
                    *   Let $(e_0, e_1, e_2)$ be the edge indices.
                    *   If any edge index $< 0$, break loop [S1].
                    *   Retrieve vertices $\mathbf{p}_0, \mathbf{p}_1, \mathbf{p}_2$ from `edgeVerts`.
                    *   Compute face normal $\mathbf{n} = \frac{(\mathbf{p}_1 - \mathbf{p}_0) \times (\mathbf{p}_2 - \mathbf{p}_0)}{\|(\mathbf{p}_1 - \mathbf{p}_0) \times (\mathbf{p}_2 - \mathbf{p}_0)\|}$ to enforce counterclockwise winding [S1].
                    *   Write positions $\{\mathbf{p}_0, \mathbf{p}_1, \mathbf{p}_2\}$ to `pos[dst:dst+2]`.
                    *   Write normals $\{\mathbf{n}, \mathbf{n}, \mathbf{n}\}$ to `nrm[dst:dst+2]`.
                    *   Increment $\text{dst} \leftarrow \text{dst} + 3$ [S1].

**Pseudocode:**
```python
def capacity_safe_slab_marching_cubes(V, Nx, Ny, Nz, tau, S):
    # Pass 1: Classify and Scan
    global_N = 0
    slab_bases = []
    slab_counts = [] # Store Ns for each slab
    
    # Pre-allocate count arrays for each slab (simplified for logic)
    # In GPU implementation, these are local to thread blocks or shared memory
    for s in range(num_slabs):
        k_start, k_end = get_slab_range(s, Nz, S)
        slab_local_count = {}
        
        for k in range(k_start, k_end + 1):
            for j in range(Ny - 1):
                for i in range(Nx - 1):
                    c = case_index(V, i, j, k, tau)
                    n_verts = num_verts[c]
                    lin_idx = (k * Ny + j) * Nx + i
                    slab_local_count[lin_idx] = n_verts
        
        # Exclusive scan
        offsets = exclusive_scan(slab_local_count)
        
        # Slab total
        last_lin = (k_end * Ny + (Ny - 2)) * Nx + (Nx - 2)
        # Note: last index depends on grid bounds, simplified here
        # In practice, scan returns array of same size as input
        slab_Ns = offsets[last_lin] + slab_local_count[last_lin]
        
        slab_bases.append(global_N)
        global_N += slab_Ns
        slab_counts.append(slab_Ns)

    # Allocate VBO
    pos_buffer = allocate_buffer(global_N * 3)
    nrm_buffer = allocate_buffer(global_N * 3)

    # Pass 2: Generate
    for s in range(num_slabs):
        k_start, k_end = get_slab_range(s, Nz, S)
        base_offset = slab_bases[s]
        
        # Retrieve offsets for this slab (from Pass 1)
        slab_offsets = get_offsets_for_slab(s)

        for k in range(k_start, k_end + 1):
            for j in range(Ny - 1):
                for i in range(Nx - 1):
                    c = case_index(V, i, j, k, tau)
                    n_verts = num_verts[c]
                    
                    if n_verts == 0:
                        continue
                    
                    # Intersect edges
                    edge_verts = edge_lerp(V, i, j, k, tau)
                    
                    lin_idx = (k * Ny + j) * Nx + i
                    dst = base_offset + slab_offsets[lin_idx]
                    
                    # Generate triangles
                    tri_idx = 0
                    while tri_idx < n_verts:
                        e0, e1, e2 = tri_table[c][tri_idx], tri_table[c][tri_idx+1], tri_table[c][tri_idx+2]
                        
                        if e0 < 0 or e1 < 0 or e2 < 0:
                            break
                        
                        p0 = edge_verts[e0]
                        p1 = edge_verts[e1]
                        p2 = edge_verts[e2]
                        
                        # Compute normal
                        v1 = p1 - p0
                        v2 = p2 - p0
                        normal = normalize(cross(v1, v2))
                        
                        # Write to buffers
                        pos_buffer[dst] = p0
                        pos_buffer[dst+1] = p1
                        pos_buffer[dst+2] = p2
                        
                        nrm_buffer[dst] = normal
                        nrm_buffer[dst+1] = normal
                        nrm_buffer[dst+2] = normal
                        
                        dst += 3
                        tri_idx += 3

    return pos_buffer, nrm_buffer
```

**Edge Cases and Pitfalls:**
*   **Boundary Cracks:** Using inclusive slab indexing ($\mathcal{K}_s$ includes $k_{end}(s)$) ensures that the $k+1$ corner access required by MC is valid at slab boundaries, eliminating omissions/duplications and cracks caused by off-by-one inconsistencies [S1].
*   **Empty Triangles:** The algorithm checks if edge indices $e_0, e_1, e_2$ are $< 0$. If so, it breaks the triangle loop, handling cases where the triangle table entry indicates no triangle for that specific triplet [S1].
*   **Partial Slabs:** If $N_z - 1$ is not divisible by $S$, the final slab is processed as a partial slab without padding, with its upper cell index clamped to $N_z - 2$ [S1].

## Operating characteristics
*   **Time Complexity:** $O(M)$ for both passes, where $M = (N_x-1)(N_y-1)(N_z-1)$ is the number of cells [S1].
*   **Memory Complexity:** The additional storage consists of slab-local count and offset arrays. The output buffers are allocated according to the exact number of generated vertices, preventing overflow [S1].
*   **Performance:** On electromagnetic-potential fields with resolution $512^3$, the method generates approximately 42.81 million vertices in 44.7 ms, uses less than 11 GB of GPU memory, and renders the resulting geometry at 28.6 FPS [S1].
*   **Strengths:** Prevents buffer overruns, eliminates boundary cracks, and enables zero-copy streaming to OpenGL buffers via CUDA-OpenGL interoperability [S1].
*   **Limitations:** Less suitable for sharp-feature preservation than methods such as Dual Contouring or MC33. Limited to volumes that fit within the memory of a single GPU [S1].

## Background
The method was introduced in a paper presenting a GPU-accelerated visualization framework for interactive exploration of fusion-plasma simulation data [S1]. It addresses the challenges of large-scale scalar grids (hundreds of gigabytes to terabytes) by combining inclusive slab partitioning with a two-pass counting and exact allocation strategy [S1]. The pipeline is integrated into a standalone renderer and Unreal Engine for volume rendering, explicit-isosurface inspection, particle-trajectory visualization, clipping, and VR-based spatial exploration [S1].
