# Capacity-safe slab-based Marching Cubes

Also called: Capacity-safe slab-based isososurface extraction, Capacity-safe slab-based isosurface extraction pipeline, Capacity-safe tiled Marching Cubes, Two-pass tiled Marching Cubes, inclusive slab partitioning with exact allocation, slab-based two-pass GPU isosurface extraction

## Overview
This method is a GPU-accelerated isosurface extraction pipeline that partitions the z-axis into slabs and uses a two-pass counting/exact allocation strategy to prevent slab-boundary omissions and output-buffer overflow for large scalar grids [S1]. It differs from standard Marching Cubes by resolving topological discontinuities and holes via boundary-consistent slab processing, and differs from HistoPyramids/Flying Edges by specializing counting/compaction for tightly coupled extraction, rendering, and engine integration [S1].

## How it works
**Inputs and Outputs**
*   **Input**: A 3D scalar volume $V$ defined on a grid of dimensions $N_x \times N_y \times N_z$, and an isovalue $\tau$.
*   **Output**: An explicit mesh consisting of vertex positions and normals, stored in a CUDA-OpenGL interoperable Vertex Buffer Object (VBO).

**Data Structures**
1.  **Lookup Tables**: Inherits `edgeTable` (256 entries, 12-bit masks) and `triangleTable` (256x16 integers) from [Lookup Table and Ambiguity Handling](10327-lookup-table-and-ambiguity-handling.md).
2.  **Count Array**: A temporary array `count_s` indexed by linear cell index $\ell$, storing the number of vertices generated by each cell in slab $s$.
3.  **Offset Array**: An exclusive prefix-sum array `offset` derived from `count_s`, storing the starting write index for each cell's output within the slab.
4.  **VBO**: A buffer with capacity $N$ (total vertices), containing two arrays: `pos` (3D vectors) and `nrm` (3D vectors).

**Parameters**
*   **Slab Thickness ($S$)**: Recommended range $[48, 96]$ for a $512^3$ grid [S1].
*   **Boundary Handling**: If $N_z - 1$ is not divisible by $S$, the final slab is processed as a partial slab without padding, with its upper cell index clamped to $N_z - 2$ [S1].

**Algorithm Steps**
1.  **Slab Partitioning**: Partition the z-axis into slabs. For slab $s$, define the set of valid cells $\mathcal{K}_s = \{k \mid k_{begin}(s) \le k \le k_{end}(s)\}$. This inclusive indexing ensures that the $k+1$ corner access required by MC remains valid at slab boundaries, eliminating cracks [S1].
2.  **Pass 1 (Classify/Scan)**:
    *   For each slab $s$ and each cell $(i,j,k) \in \mathcal{K}_s$:
        *   Compute case index $c = \text{caseIndex}(V, i, j, k, \tau)$.
        *   Compute vertex count $n_{ijk} = \text{numVerts}[c]$.
        *   Store $n_{ijk}$ in `count_s[lin(i,j,k)]`.
    *   Compute exclusive prefix-sum (scan) over `count_s` to generate `offset[ℓ]` for each cell $\ell$.
    *   Calculate slab total $N_s = \text{offsets[last]} + \text{countss[last]}$.
    *   Calculate global total $N = \sum_s N_s$.
3.  **Allocation**: Allocate an interoperable VBO with exactly $N$ vertex capacity [S1].
4.  **Pass 2 (Generate)**:
    *   For each slab $s$ and each cell $(i,j,k) \in \mathcal{K}_s$:
        *   Compute $c$ and $n_{ijk}$.
        *   If $n_{ijk} \neq 0$:
            *   Compute edge vertices: $\text{edgeVerts}[0..11] \leftarrow \text{edge\_lerp}(V, i, j, k, \tau)$.
            *   Compute destination address: $\text{dst} = \text{base}[s] + \text{offsets}[\text{lin}(i,j,k)]$, where $\text{base}[s] = \sum_{t<s} N_t$.
            *   Iterate through `triTable[c]` in triplets $(e_0, e_1, e_2)$.
            *   If any edge index $< 0$, break the loop.
            *   Retrieve vertices $\mathbf{p}_0, \mathbf{p}_1, \mathbf{p}_2$ from `edgeVerts`.
            *   Compute face normal $\mathbf{n} = \frac{(\mathbf{p}_1 - \mathbf{p}_0) \times (\mathbf{p}_2 - \mathbf{p}_0)}{\|(\mathbf{p}_1 - \mathbf{p}_0) \times (\mathbf{p}_2 - \mathbf{p}_0)\|}$.
            *   Write positions $\{\mathbf{p}_0, \mathbf{p}_1, \mathbf{p}_2\}$ and normals $\{\mathbf{n}, \mathbf{n}, \mathbf{n}\}$ to `pos[dst:dst+2]` and `nrm[dst:dst+2]`.
            *   Increment $\text{dst}$ by 3.

def capacity_safe_slab_marching_cubes(V, Nx, Ny, Nz, tau, S):
    # 1. Partition Slabs
    # Determine slab boundaries. 
    # k ranges from 0 to Nz-2 (cells).
    # Slab s covers k in [k_begin(s), k_end(s)] inclusive.
    slabs = []
    k = 0
    while k <= Nz - 2:
        k_end = min(k + S - 1, Nz - 2)
        slabs.append((k, k_end))
        k = k_end + 1

    # 2. Pass 1: Classify and Scan
    global_N = 0
    slab_bases = []
    
    # Temporary storage for counts and offsets per slab
    # In GPU implementation, these are allocated per slab or in a large buffer
    for (k_start, k_end) in slabs:
        # Initialize count array for this slab
        # Size depends on number of cells in slab: (Nx-1)*(Ny-1)*(k_end - k_start + 1)
        count_s = []
        
        for i in range(Nx - 1):
            for j in range(Ny - 1):
                for k in range(k_start, k_end + 1):
                    # Compute case index
                    c = case_index(V, i, j, k, tau)
                    # Get vertex count from LUT
                    n_ijk = num_verts[c]
                    
                    # Linear index within the slab's cell set
                    # Note: lin(i,j,k) maps to global index, but we store in slab-local array
                    # For simplicity in pseudocode, we assume a flat list of cells in slab order
                    count_s.append(n_ijk)
        
        # Exclusive prefix sum
        offsets = exclusive_scan(count_s)
        
        # Slab total
        if len(count_s) > 0:
            N_s = offsets[-1] + count_s[-1]
        else:
            N_s = 0
            
        slab_bases.append(global_N)
        global_N += N_s

    # 3. Allocate VBO
    # VBO capacity = global_N
    # pos array size = global_N * 3 floats
    # nrm array size = global_N * 3 floats

    # 4. Pass 2: Generate
    for s, (k_start, k_end) in enumerate(slabs):
        base_s = slab_bases[s]
        
        # Re-scan or use stored offsets? 
        # The source implies offsets are computed per slab. 
        # We need to re-compute or store offsets. 
        # Assuming we re-compute or have access to slab-local offsets.
        # For correctness, we re-iterate to generate.
        
        # We need the offsets array for this slab again. 
        # In a real implementation, this would be stored or recomputed.
        # Here we assume we have 'offsets_s' for the current slab.
        # To make this self-contained, we re-run the scan logic or store it.
        # Let's assume we stored 'slab_offsets' list.
        
        count_s = []
        for i in range(Nx - 1):
            for j in range(Ny - 1):
                for k in range(k_start, k_end + 1):
                    c = case_index(V, i, j, k, tau)
                    count_s.append(num_verts[c])
        
        offsets_s = exclusive_scan(count_s)
        
        cell_idx = 0
        for i in range(Nx - 1):
            for j in range(Ny - 1):
                for k in range(k_start, k_end + 1):
                    c = case_index(V, i, j, k, tau)
                    n_ijk = num_verts[c]
                    
                    if n_ijk != 0:
                        # Compute edge intersections
                        edge_verts = edge_lerp(V, i, j, k, tau)
                        
                        # Destination address
                        dst = base_s + offsets_s[cell_idx]
                        
                        # Generate triangles
                        tri_list = tri_table[c]
                        t = 0
                        while t < len(tri_list):
                            e0 = tri_list[t]
                            e1 = tri_list[t+1]
                            e2 = tri_list[t+2]
                            
                            if e0 < 0 or e1 < 0 or e2 < 0:
                                break
                            
                            p0 = edge_verts[e0]
                            p1 = edge_verts[e1]
                            p2 = edge_verts[e2]
                            
                            # Compute normal
                            v1 = p1 - p0
                            v2 = p2 - p0
                            n = normalize(cross(v1, v2))

                            pos[dst] = p0
                            pos[dst+1] = p1
                            pos[dst+2] = p2
                            
                            nrm[dst] = n
                            nrm[dst+1] = n
                            nrm[dst+2] = n
                            
                            dst += 3
                            t += 3
                            
                    cell_idx += 1

def case_index(V, i, j, k, tau):
    # Standard MC case index calculation
    # V is sampled at vertices (i,j,k) to (i+1,j+1,k+1)
    # Bit i is set if V(vertex_i) < tau (or > tau, depending on convention)
    # This matches the convention in [Lookup Table and Ambiguity Handling](10327-lookup-table-and-ambiguity-handling.md)
    idx = 0
    # Vertices 0..7
    # 0: (i,j,k), 1: (i+1,j,k), 2: (i+1,j+1,k), 3: (i,j+1,k)
    # 4: (i,j,k+1), 5: (i+1,j,k+1), 6: (i+1,j+1,k+1), 7: (i,j+1,k+1)
    # Note: Vertex ordering must match LUT generation.
    vertices = [
        V[i, j, k], V[i+1, j, k], V[i+1, j+1, k], V[i, j+1, k],
        V[i, j, k+1], V[i+1, j, k+1], V[i+1, j+1, k+1], V[i, j+1, k+1]
    ]
    for v_idx, v in enumerate(vertices):
        if v < tau: # Convention: < tau sets bit
            idx |= (1 << v_idx)
    return idx

def edge_lerp(V, i, j, k, tau):
    # Interpolate intersection points on the 12 edges
    # Edge 0: (0,1) -> (i,j,k) to (i+1,j,k)
    # ...
    # Returns array of 12 vertices
    verts = [None] * 12
    
    # Helper for linear interpolation
    def lerp(v1, v2, t):
        return v1 + t * (v2 - v1)
    
    # Vertex values
    v = [
        V[i, j, k], V[i+1, j, k], V[i+1, j+1, k], V[i, j+1, k],
        V[i, j, k+1], V[i+1, j, k+1], V[i+1, j+1, k+1], V[i, j+1, k+1]
    ]
    
    # Edge definitions (vertex indices)
    edges = [
        (0, 1), (1, 2), (2, 3), (3, 0), # Bottom
        (4, 5), (5, 6), (6, 7), (7, 4), # Top
        (0, 4), (1, 5), (2, 6), (3, 7)  # Vertical
    ]
    
    for e_idx, (v1_idx, v2_idx) in enumerate(edges):
        # Calculate interpolation factor
        # t = (tau - v1) / (v2 - v1)
        # Only if signs differ (which is guaranteed if edge is in edgeTable)
        # But we compute for all to fill array, or only for active edges?
        # Source says "edgeVerts[0..11] <- edge_lerp", implying all are computed or accessed.
        # To be safe, we compute all.
        denom = v[v2_idx] - v[v1_idx]
        if denom == 0:
            t = 0.0
        else:
            t = (tau - v[v1_idx]) / denom
        
        # Interpolate coordinates
        # x, y, z coordinates of vertices
        # v1: (i, j, k), v2: (i+1, j, k) etc.
        # This requires accessing coordinate arrays or computing on fly.
        # Assuming unit grid spacing for simplicity, or V is on grid.
        # Let's assume we have grid coordinates.
        # For a general implementation, we need x,y,z arrays.
        # Here we assume unit spacing and origin at 0.
        
        x1, y1, z1 = i, j, k
        x2, y2, z2 = i+1, j+1, k+1
        
        # Map vertex index to coord
        def get_coord(v_idx):
            # 0:(0,0,0), 1:(1,0,0), 2:(1,1,0), 3:(0,1,0)
            # 4:(0,0,1), 5:(1,0,1), 6:(1,1,1), 7:(0,1,1) relative to (i,j,k)
            rx = (v_idx & 1)
            ry = (v_idx & 2) >> 1
            rz = (v_idx & 4) >> 2
            return (i + rx, j + ry, k + rz)
            
        c1 = get_coord(v1_idx)
        c2 = get_coord(v2_idx)
        
        verts[e_idx] = (
            lerp(c1[0], c2[0], t),
            lerp(c1[1], c2[1], t),
            lerp(c1[2], c2[2], t)
        )
    return verts

def exclusive_scan(arr):
    # Standard exclusive prefix sum
    if not arr:
        return []
    n = len(arr)
    out = [0] * n
    current_sum = 0
    for i in range(n):
        out[i] = current_sum
        current_sum += arr[i]
    return out

def normalize(v):
    mag = (v[0]**2 + v[1]**2 + v[2]**2)**0.5
    if mag == 0:
        return (0,0,0)
    return (v[0]/mag, v[1]/mag, v[2]/mag)

def cross(a, b):
    return (
        a[1]*b[2] - a[2]*b[1],
        a[2]*b[0] - a[0]*b[2],
        a[0]*b[1] - a[1]*b[0]
    )

**Edge Cases and Pitfalls**
*   **Boundary Cracks**: Using inclusive slab indexing ($\mathcal{K}_s$ includes $k_{end}(s)$) ensures that the $k+1$ corner access required by MC is valid at slab boundaries, eliminating omissions/duplications and cracks caused by off-by-one inconsistencies [S1].
*   **Empty Triangles**: The algorithm checks if edge indices $e_0, e_1, e_2$ are $< 0$. If so, it breaks the triangle loop, handling cases where the triangle table entry indicates no triangle for that specific triplet [S1].
*   **Partial Slabs**: If $N_z - 1$ is not divisible by $S$, the final slab is processed as a partial slab without padding, with its upper cell index clamped to $N_z - 2$ [S1].

## Operating characteristics
*   **Time Complexity**: $O(M)$ for both passes, where $M = (N_x-1)(N_y-1)(N_z-1)$ is the number of cells [S1].
*   **Memory Complexity**: The additional storage consists of the slab-local count and offset arrays. The output buffers are allocated according to the exact number of generated vertices $N$ [S1].
*   **Performance**: On electromagnetic-potential fields with resolution $512^3$, the method generates approximately 42.81 million vertices in 44.7 ms, uses less than 11 GB of GPU memory, and renders the resulting geometry at 28.6 FPS [S1].
*   **Strengths**: Prevents buffer overruns, eliminates boundary cracks, and enables zero-copy streaming to OpenGL buffers [S1].
*   **Limitations**: Less suitable for sharp-feature preservation than methods such as Dual Contouring or MC33. Limited to volumes that fit within the memory of a single GPU [S1].

## Background
The method was introduced in a paper presenting a GPU-accelerated visualization framework for interactive exploration of fusion-plasma simulation data [S1]. It combines inclusive slab partitioning with a two-pass counting and exact allocation strategy to prevent slab-boundary omissions and output-buffer overflow while supporting large scalar grids [S1]. The generated positions and normals are written directly to CUDA-OpenGL interoperable buffers, enabling the standalone renderer to display explicit isosurfaces without an intermediate CPU-side copy [S1]. The method is integrated into Unreal Engine for volume rendering, explicit-isosurface inspection, particle-trajectory visualization, clipping, and VR-based spatial exploration [S1].
