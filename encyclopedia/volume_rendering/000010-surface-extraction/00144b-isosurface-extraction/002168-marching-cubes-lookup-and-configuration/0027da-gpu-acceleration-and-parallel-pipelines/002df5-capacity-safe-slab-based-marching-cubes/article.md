# Capacity-safe slab-based Marching Cubes

Also called: Capacity-safe slab-based isososurface extraction, Capacity-safe slab-based isosurface extraction pipeline, Capacity-safe tiled Marching Cubes, Two-pass tiled Marching Cubes, inclusive slab partitioning with exact allocation, slab-based two-pass GPU isosurface extraction

## Overview
This method is a GPU-accelerated isosurface extraction pipeline that partitions the z-axis into slabs to compute exact vertex counts per slab via a two-pass strategy (classify/scan then generate), allowing for exact buffer allocation and crack-free surfaces at slab boundaries [S1]. It differs from standard Marching Cubes by resolving topological discontinuities and holes via boundary-consistent slab processing, and differs from HistoPyramids/Flying Edges by specializing counting/compaction for tightly coupled extraction, rendering, and engine integration [S1]. Unlike implicit isosurface raycasting, this method generates explicit geometric assets (vertices/normals) suitable for mesh-based interaction tools and OBJ export [S1].

## How it works
**Inputs and Outputs**
*   **Input**: A 3D scalar volume $V$ defined on a uniform Cartesian grid with dimensions $N_x \times N_y \times N_z$ (samples), where $0 \le i \le N_x-1$, $0 \le j \le N_y-1$, $0 \le k \le N_z-1$. An isovalue $\tau \in \mathbb{R}$.
*   **Output**: A Vertex Buffer Object (VBO) containing two arrays: `pos` (positions) and `nrm` (normals). The total capacity is $N$ vertices, where $N$ is the exact sum of vertices generated by all cells. Each triangle writes 3 consecutive vertices. For each vertex, `pos` stores a 3D vector and `nrm` stores a 3D vector [S1].

**Data Structures**
1.  **Edge Intersection Table (`edgeTable`)**: As defined in [GPU Acceleration and Parallel Pipelines](4136-gpu-acceleration-and-parallel-pipelines.md).
2.  **Triangle Connection Table (`triangleTable`)**: As defined in [GPU Acceleration and Parallel Pipelines](4136-gpu-acceleration-and-parallel-pipelines.md).
3.  **Slab Configuration**: The z-axis is partitioned into slabs of thickness $S$. The set of valid cells for slab $s$ is defined as the closed interval $\mathcal{K}_s = \{k \mid k_{begin}(s) \le k \le k_{end}(s)\}$. This inclusive indexing ensures that the $k+1$ corner access required by MC remains valid at slab boundaries [S1].
4.  **Count/Offset Arrays**:
    *   `countss`: An array indexed by the linear cell index $\ell = lin(i,j,k)$, storing $n_{ijk} = numVerts[c]$ for each cell in the current slab.
    *   `offsets`: An exclusive prefix-sum array derived from `countss`, storing the starting offset for each cell's output within the slab.
    *   `base[s]`: The cumulative sum of vertex counts $N_t$ for all slabs $t < s$.

**Parameters**
*   **Slab thickness $S$**: Recommended value is in the range $[48, 96]$ for a $512^3$ grid [S1].
*   **Grid Resolution**: Tested up to $512^3$ [S1].
*   **Isovalue $\tau$**: The threshold for surface extraction [S1].

**Algorithm Steps**
The method executes a two-pass pipeline:

1.  **Pass 1 (Classify/Scan)**:
    *   Initialize global vertex count $N \leftarrow 0$.
    *   For each slab $s$:
        *   For each cell $(i,j,k)$ with $k \in [k_{begin}(s), k_{end}(s)]$:
            *   Compute case index $c = caseIndex(V, i, j, k, \tau)$.
            *   Compute vertex count $n_{ijk} = numVerts[c]$.
            *   Store $n_{ijk}$ in `countss[lin(i,j,k)]`.
        *   Compute exclusive prefix-sum (scan) over `countss` to generate `offsets`.
        *   Calculate slab-level total $N_s = offsets[last] + countss[last]$.
        *   Set slab base offset $base[s] \leftarrow N$.
        *   Update global count $N \leftarrow N + N_s$.
    *   Allocate an interoperable Vertex Buffer Object (VBO) with exactly $N$ vertex capacity [S1].

2.  **Pass 2 (Generate)**:
    *   For each slab $s$:
        *   For each cell $(i,j,k)$ with $k \in [k_{begin}(s), k_{end}(s)]$:
            *   Compute $c = caseIndex(V, i, j, k, \tau)$.
            *   If $numVerts[c] \neq 0$:
                *   Compute edge vertices via linear interpolation: $edgeVerts[0..11] \leftarrow edge\_lerp(V, i, j, k, \tau)$.
                *   Determine destination address: $dst = base[s] + offsets[lin(i,j,k)]$.
                *   Iterate through the triangle edge list $triTable[c][t..t+2]$ for $t$ from $0$ to $numVerts[c]-1$ with step 3.
                *   If any edge index $e_0, e_1, e_2$ is $< 0$, break the loop.
                *   Retrieve vertices $p_0, p_1, p_2$ from $edgeVerts$.
                *   Compute face normal $n = normalize((p_1-p_0) \times (p_2-p_0))$ to enforce counterclockwise winding.
                *   Write positions $\{p_0, p_1, p_2\}$ to `pos[dst:dst+2]` and normals $\{n, n, n\}$ to `nrm[dst:dst+2]`.
                *   Increment $dst$ by 3 [S1].

def capacity_safe_slab_marching_cubes(V, Nx, Ny, Nz, tau, S):
    """
    V: 3D array of scalar values, shape (Nx, Ny, Nz)
    Nx, Ny, Nz: Grid dimensions
    tau: Isovalue
    S: Slab thickness
    """
    # Precompute slab ranges
    slabs = []
    k = 0
    while k < Nz - 1:
        k_end = min(k + S - 1, Nz - 2)
        slabs.append((k, k_end))
        k = k_end + 1

    global_N = 0
    slab_bases = []
    slab_counts = []

    # Pass 1: Classify and Scan
    for s_idx, (k_start, k_end) in enumerate(slabs):
        # Local count array for this slab
        # We map linear index to a local array or use a global array with offset
        # For clarity, we assume a temporary array for the slab's cells
        slab_cells = []
        for k in range(k_start, k_end + 1):
            for j in range(Ny - 1):
                for i in range(Nx - 1):
                    slab_cells.append((i, j, k))
        
        counts = []
        for (i, j, k) in slab_cells:
            c = case_index(V, i, j, k, tau)
            n_verts = num_verts[c]
            counts.append(n_verts)
        
        # Exclusive prefix sum
        offsets = exclusive_scan(counts)
        
        # Slab total
        if counts:
            N_s = offsets[-1] + counts[-1]
        else:
            N_s = 0
            
        slab_bases.append(global_N)
        slab_counts.append(N_s)
        global_N += N_s

    # Allocate VBO
    # pos and nrm are arrays of size N * 3 (flattened) or N * 3 vectors
    pos = [None] * global_N
    nrm = [None] * global_N

    # Pass 2: Generate
    for s_idx, (k_start, k_end) in enumerate(slabs):
        base_offset = slab_bases[s_idx]
        
        # Re-iterate cells to generate geometry
        # Note: In a GPU implementation, this is done in parallel.
        # Here we simulate the logic.
        
        # We need the offsets for the specific cells in this slab.
        # In the GPU code, offsets are stored per cell index.
        # We reconstruct the linear indices and offsets.
        
        cell_idx = 0
        for k in range(k_start, k_end + 1):
            for j in range(Ny - 1):
                for i in range(Nx - 1):
                    c = case_index(V, i, j, k, tau)
                    n_verts = num_verts[c]
                    
                    if n_verts == 0:
                        cell_idx += 1
                        continue
                        
                    # Compute edge vertices
                    edge_verts = edge_lerp(V, i, j, k, tau)
                    
                    # Get offset for this cell within the slab
                    # In the algorithm, offsets[lin(i,j,k)] is used.
                    # Since we are iterating in the same order as Pass 1,
                    # we can track the current offset index.
                    current_offset = offsets[cell_idx]
                    dst = base_offset + current_offset
                    
                    # Generate triangles
                    tri_table_row = tri_table[c]
                    t = 0
                    while t < len(tri_table_row) - 1: # -1 for terminator
                        e0 = tri_table_row[t]
                        e1 = tri_table_row[t+1]
                        e2 = tri_table_row[t+2]
                        
                        if e0 < 0 or e1 < 0 or e2 < 0:
                            break
                            
                        p0 = edge_verts[e0]
                        p1 = edge_verts[e1]
                        p2 = edge_verts[e2]
                        
                        # Compute normal
                        v1 = p1 - p0
                        v2 = p2 - p0
                        normal = normalize(cross(v1, v2))
                        
                        # Write to VBO
                        pos[dst] = p0
                        pos[dst+1] = p1
                        pos[dst+2] = p2
                        
                        nrm[dst] = normal
                        nrm[dst+1] = normal
                        nrm[dst+2] = normal
                        
                        dst += 3
                        t += 3
                        
                    cell_idx += 1

    return pos, nrm

def case_index(V, i, j, k, tau):
    # Standard MC case index calculation
    # Bit i is set if V(i,j,k) < tau (or > tau, depending on convention)
    # Assuming standard convention: bit set if V < tau
    c = 0
    if V[i, j, k] < tau: c |= 1
    if V[i+1, j, k] < tau: c |= 2
    if V[i+1, j+1, k] < tau: c |= 4
    if V[i, j+1, k] < tau: c |= 8
    if V[i, j, k+1] < tau: c |= 16
    if V[i+1, j, k+1] < tau: c |= 32
    if V[i+1, j+1, k+1] < tau: c |= 64
    if V[i, j+1, k+1] < tau: c |= 128
    return c

def edge_lerp(V, i, j, k, tau):
    # Interpolate edge vertices for the 12 edges of the cube
    # Edge 0: (0,1) -> (i,j,k) to (i+1,j,k)
    # ...
    # Returns array of 12 vertices
    verts = [None] * 12
    # Helper for linear interpolation
    def lerp(v1, v2, t):
        return v1 + t * (v2 - v1)
    
    # Edge 0: (0,1)
    t0 = (tau - V[i, j, k]) / (V[i+1, j, k] - V[i, j, k])
    verts[0] = [i + t0, j, k]
    # Edge 1: (1,2)
    t1 = (tau - V[i+1, j, k]) / (V[i+1, j+1, k] - V[i+1, j, k])
    verts[1] = [i+1, j + t1, k]
    # Edge 2: (2,3)
    t2 = (tau - V[i+1, j+1, k]) / (V[i, j+1, k] - V[i+1, j+1, k])
    verts[2] = [i + t2, j+1, k]
    # Edge 3: (3,0)
    t3 = (tau - V[i, j+1, k]) / (V[i, j, k] - V[i, j+1, k])
    verts[3] = [i, j + t3, k]
    
    # Edge 4: (4,5)
    t4 = (tau - V[i, j, k+1]) / (V[i+1, j, k+1] - V[i, j, k+1])
    verts[4] = [i + t4, j, k+1]
    # Edge 5: (5,6)
    t5 = (tau - V[i+1, j, k+1]) / (V[i+1, j+1, k+1] - V[i+1, j, k+1])
    verts[5] = [i+1, j + t5, k+1]
    # Edge 6: (6,7)
    t6 = (tau - V[i+1, j+1, k+1]) / (V[i, j+1, k+1] - V[i+1, j+1, k+1])
    verts[6] = [i + t6, j+1, k+1]
    # Edge 7: (7,4)
    t7 = (tau - V[i, j+1, k+1]) / (V[i, j, k+1] - V[i, j+1, k+1])
    verts[7] = [i, j + t7, k+1]
    
    # Vertical Edges
    # Edge 8: (0,4)
    t8 = (tau - V[i, j, k]) / (V[i, j, k+1] - V[i, j, k])
    verts[8] = [i, j, k + t8]
    # Edge 9: (1,5)
    t9 = (tau - V[i+1, j, k]) / (V[i+1, j, k+1] - V[i+1, j, k])
    verts[9] = [i+1, j, k + t9]
    # Edge 10: (2,6)
    t10 = (tau - V[i+1, j+1, k]) / (V[i+1, j+1, k+1] - V[i+1, j+1, k])
    verts[10] = [i+1, j+1, k + t10]
    # Edge 11: (3,7)
    t11 = (tau - V[i, j+1, k]) / (V[i, j+1, k+1] - V[i, j+1, k])
    verts[11] = [i, j+1, k + t11]
    
    return verts

def exclusive_scan(arr):
    # Standard exclusive prefix sum
    if not arr:
        return []
    result = [0] * len(arr)
    current_sum = 0
    for i in range(len(arr)):
        result[i] = current_sum
        current_sum += arr[i]
    return result

def normalize(v):
    mag = sqrt(v[0]**2 + v[1]**2 + v[2]**2)
    if mag == 0: return [0,0,0]
    return [v[0]/mag, v[1]/mag, v[2]/mag]

def cross(v1, v2):
    return [
        v1[1]*v2[2] - v1[2]*v2[1],
        v1[2]*v2[0] - v1[0]*v2[2],
        v1[0]*v2[1] - v1[1]*v2[0]
    ]

**Edge Cases and Pitfalls**
*   **Boundary Cracks**: Using inclusive slab indexing ($\mathcal{K}_s$ includes $k_{end}(s)$) ensures that the $k+1$ corner access required by MC is valid at slab boundaries, eliminating omissions/duplications and cracks caused by off-by-one inconsistencies [S1].
*   **Partial Slabs**: If $N_z-1$ is not divisible by $S$, the final slab is processed as a partial slab without padding, with its upper cell index clamped to $N_z-2$ [S1].
*   **Empty Triangles**: The algorithm checks if edge indices $e_0, e_1, e_2$ are $< 0$. If so, it breaks the triangle loop, handling cases where the triangle table entry indicates no triangle for that specific triplet [S1].
*   **Memory Limits**: The current implementation is limited to volumes that fit within the memory of a single GPU [S1].

## Operating characteristics
*   **Time Complexity**: $O(M)$ for both passes, where $M = (N_x-1)(N_y-1)(N_z-1)$ is the number of cells [S1].
*   **Memory Complexity**: The additional storage consists of the slab-local count and offset arrays. The output buffers are allocated according to the exact number of generated vertices $N$ [S1].
*   **Performance**: On electromagnetic-potential fields with resolution $512^3$, the method generates approximately 42.81 million vertices in 44.7 ms, uses less than 11 GB of GPU memory, and renders the resulting geometry at 28.6 FPS [S1].
*   **Strengths**: Prevents slab-boundary omissions and output-buffer overflow. Enables zero-copy streaming to OpenGL via CUDA-OpenGL interoperability, avoiding intermediate CPU-side copies [S1].
*   **Limitations**: Less suitable for sharp-feature preservation than methods such as Dual Contouring or MC33 [S1]. Limited to volumes fitting in single GPU memory [S1].

## Background
This method was introduced in a paper presenting a GPU-accelerated visualization framework for interactive exploration of fusion-plasma simulation data [S1]. The primary technical contribution is a capacity-safe isosurface-extraction pipeline that combines inclusive slab partitioning with a two-pass counting and exact allocation strategy. It is integrated into a standalone renderer and Unreal Engine for volume rendering, explicit-isosurface inspection, particle-trajectory visualization, clipping, and VR-based spatial exploration [S1].
