# Marching Cubes with Gaussian Deformation

Also called: Geometry Shader Marching Cubes, Marching Cubes Geometry Shader Variant, Marching Cubes with Brush Deformation

## Overview
This method extracts an isosurface from a scalar field using the standard Marching Cubes topology but applies a continuous Gaussian deformation to the resulting vertices in the geometry shader [S1, S2, unofficial]. It differs from standard Marching Cubes by allowing real-time, user-driven distortion of the mesh via a force vector, and differs from CPU-based variants by performing the deformation and triangulation entirely on the GPU [S1, S2, unofficial]. It is best suited for real-time applications requiring interactive deformation of terrain or volumetric meshes [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A point cloud representing voxel grid centers (or a structured grid of points), a scalar field function $f(\mathbf{p})$, a deformation force vector $\mathbf{F}$, and the Marching Cubes lookup tables (`edgeTable`, `triangleTable`) stored in 2D textures [S1, S2, unofficial].
*   **Output:** A `TriangleStream` of deformed vertices with positions in clip space and normals/UVs passed to the fragment shader [S2, unofficial].

**Data Structures:**
1.  **Lookup Tables:** Stored as `isampler2D` textures (`edgeTableTex`, `triTableTex`) [S1, unofficial].
    *   `edgeTableTex`: Dimensions $256 \times 1$. Accessed via `texelFetch(tex, ivec2(index, 0), 0).r` to retrieve the 12-bit bitmask [S1, unofficial].
    *   `triTableTex`: Dimensions $256 \times 16$. Accessed similarly to retrieve the triangle connection indices [S1, unofficial].
2.  **Edge Vertex Map:** A static integer array `cube_diff_indices` of size 24, mapping edge index $i$ to its two vertex indices $v_a, v_b$ [S1, unofficial].
    *   Layout: `[0,1, 1,2, 2,3, 3,0, 4,5, 5,6, 6,7, 7,4, 0,4, 1,5, 2,6, 3,7]` [S1, unofficial].
3.  **Shader Structures:**
    *   **Vertex Shader Output / GS Input:** `float4 pos`, `float3 normal`, `float2 tex0` [S2, unofficial].
    *   **GS Output / FS Input:** `float4 pos` (clip space), `float3 normal`, `float2 uv`, `float4 col` [S2, unofficial].

**Parameters:**
*   `gridSize`: Uniform float, voxel edge length. Typical value: $0.25$ [S1, unofficial].
*   `sigma`: Constant float, Gaussian width. Value: $0.8$ [S1, unofficial].
*   `i_force`: Uniform `vec3`, deformation direction and magnitude [S1, unofficial].
*   `lightPos`: Light position in world space [S2, unofficial].

**Algorithm Steps:**

1.  **Scalar Field Evaluation:** For each input point (representing a voxel center), compute the cube index $C$. The scalar field is defined as:
    $$f(\mathbf{p}) = \|\mathbf{p} - \mathbf{c}\| - (r + s\sqrt{3})$$
    where $\mathbf{c} = (0, 0, -20)$, $r = 4.0$, and $s$ is the grid size [S1, unofficial].
    For each of the 8 corners $\mathbf{p}_i$ of the voxel, if $f(\mathbf{p}_i) < 0.0$, set bit $i$ of $C$ to 1 [S1, unofficial].

2.  **Edge Intersection Detection:** Fetch the bitmask from `edgeTableTex` using $C$. If the result is 0, discard the primitive [S1, unofficial].

3.  **Vertex Interpolation:** For each edge $k$ ($0 \le k \le 11$) where bit $k$ is set:
    *   Retrieve the two corner vertices $\mathbf{p}_1, \mathbf{p}_2$ using `cube_diff_indices`.
    *   Compute the interpolation factor:
        $$\alpha = \frac{|f(\mathbf{p}_1)|}{|f(\mathbf{p}_1)| + |f(\mathbf{p}_2)|}$$
    *   Compute the undeformed intersection point:
        $$\mathbf{v}_{undeformed} = (1 - \alpha)\mathbf{p}_1 + \alpha\mathbf{p}_2$$
    *   [G] Guard against division by zero if $f(\mathbf{p}_1) = f(\mathbf{p}_2) = 0.0$ by skipping the edge or using a default midpoint [G].

4.  **Gaussian Deformation:** Apply the deformation to $\mathbf{v}_{undeformed}$ to get $\mathbf{v}_{deformed}$:
    $$\mathbf{v}_{deformed} = \mathbf{v}_{undeformed} + \mathbf{F} \cdot 5 \cdot \mathcal{N}(\sigma, d_{\perp}^2)$$
    where:
    $$\mathcal{N}(\sigma, x) = \frac{e^{-x / (2\sigma^2)}}{\sigma\sqrt{2\pi}}$$
    $$d_{\perp}^2 = \|\mathbf{v}_{undeformed} - \mathbf{c}\|^2 - \frac{((\mathbf{v}_{undeformed} - \mathbf{c}) \cdot \mathbf{F})^2}{\|\mathbf{F}\|^2}$$
    [S1, unofficial].
    *   [G] Guard against $\mathbf{F} = \mathbf{0}$ by checking $\|\mathbf{F}\|^2 > \epsilon$ before division [G].
    *   [S1, unofficial] If $((\mathbf{v}_{undeformed} - \mathbf{c}) \cdot \mathbf{F}) \le 0$, skip deformation to prevent backward pushing [S1, unofficial].

5.  **Triangle Generation:** Fetch the triangle indices from `triTableTex` using $C$. Iterate through the table in steps of 3. For each valid triplet $(a, b, c)$:
    *   Retrieve the three undeformed vertices $\mathbf{v}_a, \mathbf{v}_b, \mathbf{v}_c$ from the interpolated edge points.
    *   Apply the Gaussian deformation to each vertex.
    *   Transform the deformed positions to clip space.
    *   Emit the three vertices as a triangle primitive [S1, S2, unofficial].

6.  **Transformation:**
    *   Vertex Shader: Transform vertex position to world space using `unity_ObjectToWorld` [S2, unofficial].
    *   Geometry Shader: Transform deformed vertex position to clip space.
    *   [S2, unofficial] **Pitfall:** The source code uses `mul(UNITY_MATRIX_MVP, unity_WorldToObject)`. Standard transformation is `VP * World * Vertex`. This specific multiplication order is likely incorrect for standard MVP transformation and may produce incorrect clip-space positions [S2, unofficial].

**Pseudocode:**

```python
# Constants
SIGMA = 0.8
CENTER = (0, 0, -20)
RADIUS = 4.0
GRID_SIZE = 0.25

# Helper: Gaussian Normal Distribution
def gaussian(sigma, x):
    return exp(-x / (2 * sigma**2)) / (sigma * sqrt(2 * pi))

# Helper: Scalar Field
def scalar_field(p):
    # p is a 3D vector
    dist = length(p - CENTER)
    return dist - (RADIUS + GRID_SIZE * sqrt(3))

# Helper: Deformation
def deform(p_undeformed, force):
    force_norm_sq = dot(force, force)
    if force_norm_sq < 1e-6:
        return p_undeformed # Guard against zero force
    
    diff = p_undeformed - CENTER
    proj_sq = dot(diff, force)**2 / force_norm_sq
    dist_sq = dot(diff, diff)
    d_perp_sq = dist_sq - proj_sq
    
    # Check for backward pushing
    if dot(diff, force) <= 0:
        return p_undeformed
        
    n_val = gaussian(SIGMA, d_perp_sq)
    return p_undeformed + force * 5.0 * n_val

# Geometry Shader Main Loop (per voxel primitive)
def process_voxel(voxel_center, force, edge_table_tex, tri_table_tex):
    # 1. Evaluate corners
    corners = []
    for i in range(8):
        # Determine corner position based on bit i
        # Assuming standard cube layout relative to voxel_center
        dx = (i & 1) * GRID_SIZE
        dy = (i & 2) * GRID_SIZE
        dz = (i & 4) * GRID_SIZE
        p = voxel_center + (dx, dy, dz)
        corners.append(p)
        
    # 2. Compute Cube Index
    cube_index = 0
    for i in range(8):
        if scalar_field(corners[i]) < 0.0:
            cube_index |= (1 << i)
            
    # 3. Fetch Edge Table
    edge_mask = texel_fetch(edge_table_tex, (cube_index, 0)).r
    
    if edge_mask == 0:
        return # No intersection
        
    # 4. Intersect Edges
    edge_points = []
    for k in range(12):
        if (edge_mask >> k) & 1:
            # Get vertex indices for edge k
            v_idx_a = cube_diff_indices[k * 2]
            v_idx_b = cube_diff_indices[k * 2 + 1]
            
            p1 = corners[v_idx_a]
            p2 = corners[v_idx_b]
            
            f1 = scalar_field(p1)
            f2 = scalar_field(p2)
            
            denom = abs(f1) + abs(f2)
            if denom < 1e-6:
                # Degenerate case: both zero
                alpha = 0.5
            else:
                alpha = abs(f1) / denom
                
            v_undeformed = (1 - alpha) * p1 + alpha * p2
            edge_points.append(deform(v_undeformed, force))
            
    # 5. Generate Triangles
    tri_data = texel_fetch(tri_table_tex, (cube_index, 0))
    # tri_data is a flat array of 16 integers
    
    idx = 0
    while idx < 15:
        a = tri_data[idx]
        b = tri_data[idx+1]
        c = tri_data[idx+2]
        
        if a == -1:
            break
            
        # Retrieve deformed vertices
        v1 = edge_points[a]
        v2 = edge_points[b]
        v3 = edge_points[c]
        
        # Transform to clip space
        # Note: Source uses incorrect MVP * WorldToObject order [S2, unofficial]
        # Correct standard: Clip = VP * World * Vertex
        # Assuming 'transform_to_clip' handles the matrix math correctly
        clip_v1 = transform_to_clip(v1)
        clip_v2 = transform_to_clip(v2)
        clip_v3 = transform_to_clip(v3)
        
        emit_triangle(clip_v1, clip_v2, clip_v3)
        
        idx += 3
```

## Operating characteristics
*   **Time Complexity:** $O(1)$ per voxel processed by the geometry shader, as it performs a fixed number of texture fetches and arithmetic operations regardless of grid resolution. Total complexity is $O(N)$ for $N$ voxels [S1, unofficial].
*   **Memory Complexity:** Depends on the input point cloud size ($O(N)$) and the lookup table textures (constant size: $256 \times 1$ shorts for edge table, $256 \times 16$ shorts for triangle table) [S1, unofficial].
*   **Strengths:** Real-time performance on GPU; interactive deformation via force vector; simple implementation within the geometry shader pipeline [S1, S2, unofficial].
*   **Limitations:** The deformation is applied per-vertex, which may cause visual artifacts if the deformation is large relative to voxel size; the source implementation contains a likely incorrect matrix multiplication order for clip-space transformation [S2, unofficial]; no explicit handling of the zero-force vector division by zero or zero-denominator interpolation in the source code [S1, unofficial].
*   **When to use:** Real-time deformable terrain or mesh interaction where interactive force application is required [S1, unofficial].
*   **When not to use:** High-fidelity static mesh extraction where CPU-side optimization or post-processing (like QEF) is needed; scenes requiring strict topological consistency without user deformation.

## Background
This variant was implemented in the `NtslMaterial` geometry shader for a custom OpenGL 3.3+ application, specifically for real-time deformable terrain/mesh interaction [S1, unofficial]. It utilizes a sphere-based scalar field and Gaussian deformation to simulate brush-like interactions [S1, unofficial]. The approach is documented in the `tink-expo/ntsl-graphics` repository [S1, unofficial]. A related Unity-based implementation exists in `kristofe/UnityGPUMarchingCubes`, which also uses a geometry shader for Marching Cubes, though with different shading and transformation logic [S2, unofficial].
