# Marching Cubes with Gaussian Deformation

Also called: Geometry Shader Marching Cubes, Marching Cubes Geometry Shader Variant, Marching Cubes with Brush Deformation

## Overview
This method implements the Marching Cubes isosurface extraction algorithm within a GPU Geometry Shader, applying a Gaussian-based deformation to the generated mesh vertices based on a user-provided force vector [S1, unofficial]. It solves the problem of real-time, deformable surface extraction from a scalar field, specifically targeting interactive applications where the surface topology must respond to external forces (e.g., terrain modification or soft-body interaction) [S1, unofficial]. It differs from standard static Marching Cubes implementations by integrating the deformation calculation directly into the geometry shader pipeline, avoiding the need for CPU-side mesh updates or additional post-processing passes for deformation [S1, unofficial]. It builds on [Marching Cubes Lookup and Configuration](2518-marching-cubes-lookup-and-configuration.md) for the core topology logic and [GPU Acceleration and Parallel Pipelines](4136-gpu-acceleration-and-parallel-pipelines.md) for the parallel dispatch model.

## How it works
**Inputs and Outputs:**
*   **Input:** A stream of point primitives, where each point represents the center of a voxel in a 3D grid. The grid is defined by a `gridSize` uniform [S1, unofficial].
*   **Uniforms:**
    *   `gridSize`: Float defining the voxel edge length (typical value: 0.25f) [S1, unofficial].
    *   `i_force`: `vec3` defining the deformation direction and magnitude [S1, unofficial].
    *   `sigma`: Constant float controlling the Gaussian falloff width (typical value: 0.8) [S1, unofficial].
    *   `edgeTableTex` and `triTableTex`: 2D integer textures storing the standard Marching Cubes lookup tables (256x16 and 256x12 respectively, or similar layout) [S1, unofficial].
*   **Output:** A `TriangleStream` of vertices in clip space, with positions deformed by the Gaussian force field [S1, unofficial].

**Data Structures:**
*   **Lookup Tables:** Stored in GPU textures (`edgeTableTex`, `triTableTex`) for efficient random access in the shader [S1, unofficial]. The `edgeTable` is accessed via `texelFetch(edgeTableTex, ivec2(cubeIndex, 0), 0).r` [S1, unofficial]. The `triTable` is accessed similarly to retrieve triangle vertex indices [S1, unofficial].
*   **Edge Vertex Mapping:** A static array `cube_diff_indices` of size 24 maps the 12 edge indices to the 8 cube vertex indices. Index $i$ of the edge table corresponds to vertices `cube_diff_indices[i*2]` and `cube_diff_indices[i*2+1]` [S1, unofficial]. The mapping is:
    *   Edges 0-3 (Bottom): (0,1), (1,2), (2,3), (3,0)
    *   Edges 4-7 (Top): (4,5), (5,6), (6,7), (7,4)
    *   Edges 8-11 (Vertical): (0,4), (1,5), (2,6), (3,7) [S1, unofficial].

**Algorithm Steps:**
1.  **Vertex Shader:** Transform the input voxel center position from object space to world space using `unity_ObjectToWorld` [S2, unofficial]. Pass normal and texture coordinates unchanged [S2, unofficial].
2.  **Geometry Shader Entry:** For each input point (voxel center $\mathbf{c}_{voxel}$):
    a.  **Scalar Field Evaluation:** Compute the scalar field value $f(\mathbf{p})$ at the 8 corners of the voxel. The scalar field is defined as a sphere function:
        $$ f(\mathbf{p}) = \|\mathbf{p} - \mathbf{c}\| - (r + s\sqrt{3}) $$
        where $\mathbf{c} = (0, 0, -20)$ is the sphere center, $r = 4.0$ is the radius, and $s$ is the `gridSize` [S1, unofficial].
    b.  **Case Index Calculation:** Construct the 8-bit case index $C$. If $f(\mathbf{p}_i) < 0.0$, set bit $i$ of $C$ to 1; otherwise 0 [S1, unofficial].
    c.  **Edge Intersection Check:** Fetch the edge mask from `edgeTableTex` using $C$. If the mask is 0, discard the primitive [S1, unofficial].
    d.  **Vertex Interpolation:** Iterate over the 12 edges. For each edge $k$ where the $k$-th bit of the mask is set:
        i.  Retrieve the two corner positions $\mathbf{p}_1, \mathbf{p}_2$ and their scalar values $f_1, f_2$ using `cube_diff_indices` [S1, unofficial].
        ii. Compute the interpolation factor $\alpha$:
            $$ \alpha = \frac{|f_1|}{|f_1| + |f_2|} $$
        iii. Compute the undeformed intersection point $\mathbf{v}$:
            $$ \mathbf{v} = (1 - \alpha)\mathbf{p}_1 + \alpha\mathbf{p}_2 $$
        iv. Store $\mathbf{v}$ in a temporary array `intersections[12]` [S1, unofficial].
    e.  **Triangle Generation:** Fetch the triangle configuration from `triTableTex` using $C$. Iterate through the table in steps of 3. For each valid triplet $(a, b, c)$:
        i.  Retrieve the undeformed positions $\mathbf{v}_a, \mathbf{v}_b, \mathbf{v}_c$ from `intersections` [S1, unofficial].
        ii. **Gaussian Deformation:** Apply the deformation to each vertex $\mathbf{v}$:
            $$ \mathbf{p}' = \mathbf{v} + \mathbf{F} \cdot 5 \cdot \mathcal{N}(\sigma, d_{\perp}^2) $$
            where $\mathbf{F}$ is the `i_force` vector, and $\mathcal{N}$ is the Gaussian function:
            $$ \mathcal{N}(\sigma, x) = \frac{e^{-x / (2\sigma^2)}}{\sigma\sqrt{2\pi}} $$
            The squared perpendicular distance $d_{\perp}^2$ is calculated as:
            $$ d_{\perp}^2 = \|\mathbf{v} - \mathbf{c}\|^2 - \frac{((\mathbf{v} - \mathbf{c}) \cdot \mathbf{F})^2}{\|\mathbf{F}\|^2} $$
            where $\mathbf{c}$ is the sphere center $(0, 0, -20)$ [S1, unofficial].
        iii. **Backward Push Guard:** If $((\mathbf{v} - \mathbf{c}) \cdot \mathbf{F}) \le 0$, skip deformation (return $\mathbf{v}$) to prevent backward pushing [S1, unofficial].
        iv. Set the output position to $\mathbf{p}'$, compute the normal (via cross product of triangle edges or interpolated vertex normals), and emit the vertex [S1, S2, unofficial].
    f.  **Primitive Emission:** After emitting three vertices, call `outStream.RestartStrip()` [S2, unofficial].

**Pseudocode:**
```python
# Geometry Shader Pseudocode (GLSL-like)

# Uniforms
uniform float gridSize;
uniform vec3 i_force;
uniform float sigma = 0.8;
uniform isampler2D edgeTableTex;
uniform isampler2D triTableTex;

# Constants
const vec3 sphere_center = vec3(0.0, 0.0, -20.0);
const float sphere_radius = 4.0;
const int cube_diff_indices[24] = int[](
    0, 1, 1, 2, 2, 3, 3, 0, # Bottom
    4, 5, 5, 6, 6, 7, 7, 4, # Top
    0, 4, 1, 5, 2, 6, 3, 7  # Vertical
);

# Helper: Scalar Field
float scalarField(vec3 p) {
    float s = gridSize;
    return length(p - sphere_center) - (sphere_radius + s * sqrt(3.0));
}

# Helper: Gaussian Deformation
vec3 deform(vec3 p) {
    if (length(i_force) == 0.0) return p; # Guard against NaN [S1, unofficial]
    
    vec3 diff = p - sphere_center;
    float dot_prod = dot(diff, i_force);
    
    # Backward push guard [S1, unofficial]
    if (dot_prod <= 0.0) return p;
    
    float force_len_sq = dot(i_force, i_force);
    float d_perp_sq = dot(diff, diff) - (dot_prod * dot_prod) / force_len_sq;
    
    float gaussian = exp(-d_perp_sq / (2.0 * sigma * sigma)) / (sigma * sqrt(2.0 * 3.14159265358979323846));
    
    return p + i_force * 5.0 * gaussian;
}

# Geometry Shader Main
void main() {
    vec3 voxel_center = input[0].pos;
    
    # 1. Evaluate Scalar Field at 8 corners
    float vals[8];
    for (int i = 0; i < 8; i++) {
        vec3 corner = voxel_center + vec3(
            float((i & 1) != 0),
            float((i & 2) != 0),
            float((i & 4) != 0)
        ) * gridSize;
        vals[i] = scalarField(corner);
    }
    
    # 2. Compute Case Index
    int cubeIndex = 0;
    for (int i = 0; i < 8; i++) {
        if (vals[i] < 0.0) {
            cubeIndex |= (1 << i);
        }
    }
    
    # 3. Check Edge Table
    int edgeMask = texelFetch(edgeTableTex, ivec2(cubeIndex, 0), 0).r;
    if (edgeMask == 0) return;
    
    # 4. Intersect Edges
    vec3 intersections[12];
    for (int i = 0; i < 12; i++) {
        if ((edgeMask & (1 << i)) != 0) {
            int v1_idx = cube_diff_indices[i * 2];
            int v2_idx = cube_diff_indices[i * 2 + 1];
            
            vec3 p1 = voxel_center + vec3(
                float((v1_idx & 1) != 0),
                float((v1_idx & 2) != 0),
                float((v1_idx & 4) != 0)
            ) * gridSize;
            
            vec3 p2 = voxel_center + vec3(
                float((v2_idx & 1) != 0),
                float((v2_idx & 2) != 0),
                float((v2_idx & 4) != 0)
            ) * gridSize;
            
            float f1 = vals[v1_idx];
            float f2 = vals[v2_idx];
            
            # Guard against division by zero [S1, unofficial]
            float denom = abs(f1) + abs(f2);
            if (denom == 0.0) {
                intersections[i] = p1; # Fallback
            } else {
                float alpha = abs(f1) / denom;
                intersections[i] = (1.0 - alpha) * p1 + alpha * p2;
            }
        }
    }
    
    # 5. Generate Triangles
    for (int i = 0; i < 16; i += 3) {
        int idx1 = texelFetch(triTableTex, ivec2(cubeIndex, i), 0).r;
        int idx2 = texelFetch(triTableTex, ivec2(cubeIndex, i + 1), 0).r;
        int idx3 = texelFetch(triTableTex, ivec2(cubeIndex, i + 2), 0).r;
        
        if (idx1 == -1) break;
        
        vec3 p1 = deform(intersections[idx1]);
        vec3 p2 = deform(intersections[idx2]);
        vec3 p3 = deform(intersections[idx3]);
        
        # Compute Normal
        vec3 normal = normalize(cross(p2 - p1, p3 - p1));
        
        # Emit Vertices
        # Note: Standard MVP transformation should be applied here, 
        # but the source code uses an incorrect order [S2, unofficial].
        # For correct implementation: gl_Position = MVP * vec4(p, 1.0);
        gl_Position = vec4(p1, 1.0); 
        EmitVertex();
        
        gl_Position = vec4(p2, 1.0);
        EmitVertex();
        
        gl_Position = vec4(p3, 1.0);
        EmitVertex();
        
        EndPrimitive();
    }
}
```

## Operating characteristics
*   **Time Complexity:** $O(1)$ per voxel processed by the geometry shader, as it performs a fixed number of texture fetches and arithmetic operations regardless of grid resolution [S1, unofficial]. Total complexity is $O(N)$ for $N$ voxels [S1, unofficial].
*   **Memory Complexity:** Low. The lookup tables are stored in GPU textures (256x16 and 256x12 integers), requiring minimal memory [S1, unofficial]. No additional buffers are required for deformation [S1, unofficial].
*   **Performance:** Real-time performance is achieved on modern GPUs due to the parallel nature of the geometry shader [S1, unofficial]. Performance scales linearly with the number of voxels [S1, unofficial].
*   **Strengths:**
    *   Real-time deformation without CPU-GPU synchronization [S1, unofficial].
    *   Simple implementation within the graphics pipeline [S1, unofficial].
    *   Smooth deformation via Gaussian function [S1, unofficial].
*   **Limitations:**
    *   The deformation is applied per-vertex, which may cause discontinuities at triangle boundaries if the force field varies rapidly [S1, unofficial].
    *   The scalar field is hardcoded to a sphere function in the reference implementation, limiting generalizability [S1, unofficial].
    *   The matrix multiplication order in the reference implementation is incorrect, leading to incorrect clip-space positions [S2, unofficial].
    *   Degenerate cases (zero force, zero denominator in interpolation) are not robustly handled in the reference code [S1, unofficial].

## Background
This method was implemented in the NtslMaterial geometry shader for real-time deformable terrain/mesh interaction in a custom OpenGL 3.3+ application [S1, unofficial]. It is part of the `ntsl-graphics` project, which explores various graphics techniques [S1, unofficial]. The Gaussian deformation technique is inspired by brush-based deformation methods used in sculpting software, adapted for real-time GPU execution [S1, unofficial].
