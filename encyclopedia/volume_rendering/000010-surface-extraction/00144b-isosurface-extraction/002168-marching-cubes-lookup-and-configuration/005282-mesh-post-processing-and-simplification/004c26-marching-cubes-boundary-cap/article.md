# Marching Cubes Boundary Cap

Also called: MC boundary cap, box-face crossing cap

## Overview
Marching Cubes Boundary Cap is a post-processing step for Marching Cubes (MC) that closes open mesh boundaries when the isosurface exits the sample-cube boundary [S1, unofficial]. It solves the problem of non-watertight meshes (IsWatertight = false) caused by insufficient bounding ranges, ensuring the output is a closed 2-manifold suitable for 3D printing [S1, unofficial]. It differs from auto-sizing the bounding box by allowing users to force a too-small range while still producing a watertight mesh, and differs from general mesh simplification by specifically targeting boundary closure rather than complexity reduction [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: The mesh $M$ generated by the Marching Cubes algorithm, consisting of vertices $V$, triangles $T$, and adjacency information. The scalar field values are already sampled on the face vertices from the MC pass [S1, unofficial].
- Output: A closed 2-manifold mesh where boundary edges on the cube faces are triangulated and welded to the existing MC boundary vertices [S1, unofficial].

**Data Structures:**
- The mesh $M$ consists of vertices $V$ and triangles $T$.
- Adjacency information is derived from the `edgeTable` and `triangleTable` of the parent Marching Cubes Lookup and Configuration [Lookup Table and Ambiguity Handling](10327-lookup-table-and-ambiguity-handling.md).
- Boundary edges are identified as edges shared by only one triangle [S1, unofficial].

**Steps:**
1.  **Check for Interior Surface:** If the bounding range is auto-sized to enclose the set, the surface remains interior to the cube. In this case, the cap method is a no-op to maintain byte-identical output and performance [S1, unofficial].
2.  **Iterate Cube Faces:** For each of the 6 cube faces, identify the cross-section polygon(s) where the scalar field intersects the face [S1, unofficial].
3.  **2D Contour Extraction:** Run a 2D Marching Squares contour algorithm on the face grid to extract the contour lines of the intersection between the isosurface and the cube face [S1, unofficial].
4.  **Triangulate Cap:** Triangulate the interior (or exterior, depending on the field sign convention relative to the iso value) region enclosed by the contour lines to create a cap mesh [S1, unofficial].
5.  **Weld Vertices:** Weld the vertices of the generated cap triangles to the existing boundary vertices of the MC mesh on that face to form a single closed 2-manifold [S1, unofficial].

    """
    Closes open boundaries of a Marching Cubes mesh if the isosurface exits the cube.
    
    Args:
        mesh: Object containing vertices V, triangles T, and adjacency info.
        scalar_field: Function or array providing scalar values at grid points.
        cube_bounds: Bounding box of the sample cube.
        iso_value: The isovalue used for Marching Cubes.
        
    Returns:
        Closed 2-manifold mesh.
    """
    # Step 1: Check if surface is interior (no-op case)
    # If the bounding range was auto-sized to enclose the set, the surface is interior.
    # This check ensures byte-identical output for the standard case.
    if is_surface_interior(mesh, cube_bounds, iso_value):
        return mesh

    # Step 2: Iterate over the 6 faces of the cube
    for face in cube_faces(cube_bounds):
        # Step 3: Extract contour on the face using 2D Marching Squares
        # The scalar field values are already sampled on the face vertices.
        contour_lines = marching_squares_2d(face.grid_vertices, scalar_field, iso_value)
        
        # Step 4: Triangulate the region enclosed by the contour lines
        # Determine interior vs exterior based on field sign convention relative to iso_value.
        cap_triangles = triangulate_contour(contour_lines, iso_value)

        boundary_vertices = get_boundary_vertices(mesh, face)
        welded_mesh = weld_vertices(mesh, cap_triangles, boundary_vertices)
        mesh = welded_mesh

    return mesh

## Subtopics

### Mesh-Open2-Closed Algorithm
An algorithm to universally enclose open reconstructed mesh surfaces (specifically those with a single hole) by appending a base plane, creating a closed mesh suitable for MPM/FEM simulation [S2]. It differs from the standard MC boundary cap by not relying on the grid structure of the Marching Cubes output, but rather on the boundary edges of any reconstructed mesh. It is chosen when the input mesh is not from a regular grid or when the boundary is not aligned with a cube face [S2]. Input: Mesh vertices $\mathcal{V}$ and triangles $\mathcal{F}$ structured in 2D arrays [S2]. Steps: 1. Construct boundary edges and organize in a list. 2. Classify edges using a non-manifold test (manifold edges are in 2 triangles; non-manifold are boundary edges). 3. Conduct BFS to sort boundary vertices into an ordered list. 4. Iteratively build a base plane of the soft tissue surface in the shape of the open mesh boundary. 5. Loop for each vertex $v$ in the ordered edge list: find the projection of $v$ in the appended base. 6. Connect the projection of the last $v$, the projection of the current $v$, and the center of the base plane to create new faces [S2]. Pitfall: Designed for input meshes with a single 'hole' (one connected edge). If there are two disjoint surfaces, run the algorithm separately for each surface [S2].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of boundary edges on the cube faces. The 2D Marching Squares pass is linear with respect to the number of cells on the face.
- **Memory Complexity:** Linear with respect to the number of boundary edges, as new triangles are added for the cap.
- **Measured Performance:** In a validation test case with a sphere of radius $r=1.8$ inside a cube with half-extent 1.6, the uncapped MC mesh had 648 boundary edges and was not watertight. After capping, the mesh was watertight [S1, unofficial].
- **Strengths:** Ensures watertightness even with undersized bounding boxes. Maintains byte-identical output for the standard auto-sized case.
- **Limitations:** Only applies to boundaries on the cube faces. Does not handle holes in the interior of the mesh.
- **When to use:** When 3D printing or simulation requires a closed 2-manifold, and the bounding box cannot be guaranteed to enclose the entire isosurface.
- **When not to use:** When the bounding box is auto-sized to enclose the set, as the cap is a no-op and adds unnecessary complexity.

## Background
Origin: The method was developed as part of the FracturingFog project, specifically in issue #422 and fixed in #425 by AloneButUnsober [S1, unofficial]. It was implemented in the `UserBulbMeshExporter` and validated by `MeshValidator` to ensure `SignedVolume > 0` and outward winding [S1, unofficial]. The default mitigation was to auto-size the cube (`UserBulbMeshExporter.ProbeBoundingRange`), but this method allows users to force a too-small range while still producing a watertight mesh [S1, unofficial].
