# Marching Cubes with QEF Vertex Optimization

Also called: MC-QEF, Optimized Marching Cubes

## Overview
Marching Cubes with QEF Vertex Optimization is a surface extraction method that computes vertex positions by minimizing a Quadric Error Function (QEF) for ambiguous topological cases, while employing a fast 2D linear/binomial search for non-ambiguous cases, to produce a watertight mesh from a voxel grid [S1, unofficial]. It sets itself apart from standard Marching Cubes by replacing linear interpolation with geometric optimization that respects local surface curvature, and distinguishes itself from other post-processing methods by integrating this optimization directly into the vertex generation phase rather than as a separate mesh simplification step [S1, unofficial].

## How it works
The method processes voxel grid indices directly to generate optimized vertex coordinates, building on the parent algorithm's fixed topology [Vertex Position Optimization and Error Minimization](10991-vertex-position-optimization-and-error-minimization.md).

### Inputs and Outputs
**Inputs:**
- Voxel grid occupancy array `occs` of shape $(H, W, D)$, where values are binary (0 or 1) [S1, unofficial].
- Grid dimensions $H, W, D$ and constants `GRID`, `GRID2`, `GRID3` [S1, unofficial].
- Pre-computed lookup tables: `axd_tab`, `ax0_tab`, `ax1_tab`, `cas_tab`, `lctab_2d`, `qvntab`, `pfvtab`, `vitogi`, `cstrtab` [S1, unofficial].
- Parameters: `QEF_REG` (regularization weight), `ERR` (numerical threshold), `VERTICAL_RANGE`, `HORIZNTL_RANGE`, `VERTICAL_LINEAR_SEARCH`, `VERTICAL_BINARY_SEARCH`, `HORIZNTL_LINEAR_SEARCH`, `HORIZNTL_BINARY_SEARCH` [S1, unofficial].
- `sel_pidx1`: Array of linear voxel indices to process [S1, unofficial].

**Outputs:**
- Array `val_pnts` containing the optimized 3D coordinates for all generated vertices [S1, unofficial].

### Data Structures
- `pidx1`: Array of linear indices identifying candidate voxel positions [S1, unofficial].
- `pidx3`: Array of 3D indices $(x, y, z)$ derived from `pidx1` [S1, unofficial].
- `val_`: Integer occupancy pattern (0-15) for a voxel, computed from `occs` [S1, unofficial].
- `cases`: Integer case index derived from the voxel configuration [S1, unofficial].
- `axdir`, `axis0`, `axis1`: Direction vectors and axes associated with the case [S1, unofficial].

### Algorithm Steps

1.  **Filter and Group Voxels:**
    Filter voxel indices `pidx1` into two groups:
    - Group A (Fast Search): Indices in range $[3 \times GRID3, 9 \times GRID3)$ [S1, unofficial].
    - Group B (QEF Optimization): Indices $\ge 9 \times GRID3$ [S1, unofficial].
    Initialize `start_idx` to 0 [S1, unofficial].

2.  **Process Group A (Non-Ambiguous/Fast Search):**
    For each index in Group A:
    a. Compute the 8-neighbor occupancy value `val_` by summing weighted occupancy bits:
       $$ val\_ = occs[pidx3] + 2 \cdot occs[pidx3 + axis1] + 4 \cdot occs[pidx3 + axis0] + 8 \cdot occs[pidx3 + axis2] $$
       where `axis0`, `axis1`, `axis2` are direction vectors for the current case [S1, unofficial].
    b. Apply ambiguity correction: If `amb_chks[pidx3]` is true, set `val\_ = 15 - val\_` [S1, unofficial].
    c. Compute vertex positions using `_2d_search(pidx3, axdir, axis0, axis1, val_, cases)` and store in `val_pnts` at `start_idx`, then increment `start_idx` by the count of processed vertices [S1, unofficial].

3.  **Process Group B (Ambiguous Cases via QEF):**
    For each index in Group B:
    a. Call `_solve_QEF(pidx3, val_, cases)` where `val_` is the integer occupancy pattern and `cases` is derived from $pidx1 / GRID3 - 9$ [S1, unofficial].
    b. Store results in `val_pnts` at `start_idx` [S1, unofficial].

4.  **QEF Solving (`_solve_QEF`):**
    a. For each vertex index $i$ from 3 to 7:
       i. Find indices `idx` where `qvntab[val_, cases] == i` [S1, unofficial].
       ii. Retrieve vertex coordinates `vtcs` from `pfvtab[val_, cases, :2*i+1]` and edge indices `vitg` from `vitogi[vtcs]` [S1, unofficial].
    b. Compute 3D positions `pnti` for the vertices using grid offsets:
       $$ pnti = vitg[:,:,3] \cdot GRID3 + (pid3[:,0]+vitg[:,:,0]) \cdot GRID2 + (pid3[:,1]+vitg[:,:,1]) \cdot GRID + (pid3[:,2]+vitg[:,:,2]) $$
       Get global indices `pidx` and retrieve pre-computed vertex positions `vert = val_pnts[pidx]` [S1, unofficial].
    c. Add local offsets `vitg[:,:3]` to `vert` [S1, unofficial].
    d. Compute QEF normals `qnrm` using cross products of edge vectors:
       $$ \_1vt = vert[:, 1::2] $$
       $$ qnrm = cross(\_1vt - vert[:, :-1:2], \_1vt - vert[:, 2::2]) $$
       Compute centroid $cntr = mean(\_1vt, dim=1)$ [S1, unofficial].
    e. Normalize `qnrm` handling zero-length edges with `ERR` threshold [S1, unofficial].
    f. Solve the QEF system using least squares:
       $$ A = cat(qnrm, QEF\_REG \cdot I) $$
       $$ b = cat(sum(\_1vt \cdot qnrm), QEF\_REG \cdot cntr) $$
       Solution $qefr = lstsq(A, b).solution$. If all normals are degenerate (`cndt` all true), use $cntr$ instead [S1, unofficial].
    g. Compute ray direction $ctoq = qefr - cpnt$ and length $leng$ [S1, unofficial].
    h. Compute intersection parameter $t$ with constraint planes defined by `cstrtab`. Concatenate boundary parameters $(1-cpnt)/ctoq$ and $-cpnt/ctoq$ with $t$ [S1, unofficial].
    i. Handle NaNs and negative values by setting $t$ to $leng + SEP$, then normalize by $leng$ and clamp to $[0, 1]$. Final vertex is $cpnt + t \cdot ctoq$ [S1, unofficial].

    val_pnts = [None] * len(sel_pidx1)
    start_idx = 0
    
    # Group A: Fast 2D Search [3*GRID3, 9*GRID3)

                    4 * occs[pidx3[0] + axis0[0], pidx3[1] + axis0[1], pidx3[2] + axis0[2]] +
                    8 * occs[pidx3[0] + axis2[0], pidx3[1] + axis2[1], pidx3[2] + axis2[2]])
            
            if amb_chks[pidx3]:
                val_ = 15 - val_
                
            vertices = _2d_search(pidx3, axdir, axis0, axis1, val_, cases,
                                  lctab_2d, occs, GRID, GRID2, GRID3, ERR,
                                  VERTICAL_RANGE, HORIZNTL_RANGE,

                                  HORIZNTL_LINEAR_SEARCH, HORIZNTL_BINARY_SEARCH)

                    4 * occs[pidx3[0] + axis0[0], pidx3[1] + axis0[1], pidx3[2] + axis0[2]] +

def _solve_QEF(pidx3, val_, cases, qvntab, pfvtab, vitogi, val_pnts, 
               GRID, GRID2, GRID3, QEF_REG, ERR, cstrtab):
    """
    Solves QEF for ambiguous cases.
    """
    vertices = []
    
    for i in range(3, 8):
        idx = [k for k, v in enumerate(qvntab[val_, cases]) if v == i]
        if not idx:
            continue
            
        vtcs = pfvtab[val_, cases, :2*i+1]
        vitg = vitogi[vtcs]
        
        # Compute 3D positions using grid offsets
        pnti = (vitg[:, 3] * GRID3 + 
                (pidx3[0] + vitg[:, 0]) * GRID2 + 
                (pidx3[1] + vitg[:, 1]) * GRID + 
                (pidx3[2] + vitg[:, 2]))
        
        pidx = pnti.astype(int)
        vert = [val_pnts[p] for p in pidx]
        
        # Add local offsets
        vert = [v + vitg[j, :3] for j, v in enumerate(vert)]
        
        # Compute normals
        _1vt = [v[1] for v in vert]
        qnrm = [cross(_1vt[j] - vert[j][:-1:2], _1vt[j] - vert[j][2::2]) for j in range(len(vert))]
        cntr = [sum(_1vt[j]) / len(_1vt[j]) for j in range(len(vert))]
        
        # Normalize normals
        leng = [norm(q) for q in qnrm]
        cndt = [l < ERR for l in leng]
        qnrm = [q / max(l, 1.0) for q, l in zip(qnrm, leng)]
        
        # Solve QEF
        A = [concatenate([q, [QEF_REG, 0, 0], [0, QEF_REG, 0], [0, 0, QEF_REG]]) for q in qnrm]
        b = [concatenate([dot(v, q) for v, q in zip(vert, qnrm)], [QEF_REG * c]) for v, q, c in zip(vert, qnrm, cntr)]
        
        qefr = []
        for j in range(len(A)):
            try:
                sol = lstsq(A[j], b[j])
                qefr.append(sol)
            except:
                qefr.append(cntr[j])
                
        if all(cndt):
            qefr = cntr
            
        # Compute final vertex with constraint planes
        cpnt = mean(pidx3)
        ctoq = [q - cpnt for q in qefr]
        leng = [norm(c) for c in ctoq]
        
        # Compute intersection parameter t
        t = [compute_intersection_t(c, cstrtab, cpnt, l, ERR) for c, l in zip(ctoq, leng)]
        
        # Clamp t
        t = [clamp(val, 0, 1) for val in t]
        
        final_v = [cpnt + t[j] * ctoq[j] for j in range(len(ctoq))]
        vertices.extend(final_v)
        
    return vertices

### Edge Cases and Pitfalls
- **Degenerate Normals:** If all computed normals are zero-length (degenerate), the QEF solution falls back to the centroid of the vertex neighborhood [S1, unofficial].
- **Numerical Stability:** The `ERR` threshold is used to prevent division by zero when normalizing normals and computing intersection parameters [S1, unofficial].

## Subtopics

### [QEM-based Vertex Relocation](6398-qem-based-vertex-relocation.md)
A vertex relocation method used in the Mesh Generation phase to move vertices to the isosurface, using the Quadric Error Metric (QEM) instead of full QEF minimization to reduce computational complexity and register usage on parallel hardware [G]. Unlike pseudoinverse QEF minimization which is complex and penalizes performance on parallel hardware due to register limits, QEM minimization is stable with supporting planes and produces accurate results sufficient for volume preservation [G].

- **Strengths:** Produces watertight meshes with improved geometric accuracy for ambiguous cases compared to standard linear interpolation [S1, unofficial].
- **Limitations:** More computationally expensive than standard Marching Cubes due to the QEF solving step [S1, unofficial].
- **When to Use:** When high geometric fidelity is required for ambiguous topological cases in volume rendering, and computational resources allow for the additional cost of QEF solving [S1, unofficial].
- **When Not to Use:** When real-time performance is critical and the ambiguity cases are rare or can be approximated with linear interpolation [G].

The QEF approach is based on the Quadric Error Function minimization technique, which has been widely used in mesh simplification and reconstruction [S1, unofficial].
