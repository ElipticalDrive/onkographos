# QEM-based Vertex Relocation

Also called: Quadric Error Metric minimization for DMC, Vertex Relocation

## Overview
This method relocates mesh vertices to improve triangle shape and snap them onto sharp features (creases or corners) by minimizing a Quadric Error Metric (QEM) derived from tangential planes, combined with Laplace smoothing [S1]. Unlike the full Quadric Error Function (QEF) minimization used in its parent method, which requires complex pseudo-inverse computations that penalize performance on parallel hardware due to register limits, QEM minimization is computationally lighter and stable [S2, unofficial]. It is chosen when volume preservation is the primary goal and high-fidelity geometric accuracy is secondary to performance [S2, unofficial].

## How it works
**Inputs:**
*   A vertex $v$ at position $\mathbf{x}$.
*   The set of neighboring vertices $N(v)$ and their count $|N(v)|$.
*   For each triangle incident to $v$: the sampling point projection $\hat{\mathbf{s}}_i$ on the offset surface, the offset normal $\hat{\mathbf{n}}_i$, and the triangle area $a_i$.

**Outputs:**
*   The new optimized position $\mathbf{x}'$ for vertex $v$.

**Data Structures:**
*   Matrix $A$: A $3 \times 3$ symmetric matrix representing the sum of weighted outer products of normals.
*   Vector $\mathbf{b}$: A 3D vector representing the weighted sum of projections.
*   Vector $\mathbf{x}_0$: The initial guess for the vertex position (center of mass).

**Steps:**

1.  **Compute Center of Mass (Laplace Smoothing):**
    Calculate the average position of the 1-ring neighborhood to serve as the initial guess $\mathbf{x}_0$ [S1].
    $$ \mathbf{x}_0 = \frac{1}{|N(v)|} \sum_{\mathbf{x} \in N(v)} \mathbf{x} \quad (7) $$

2.  **Compute Weighted Error Quadrics:**
    For each sampling point $i$ associated with triangles incident to $v$, compute the contribution to matrix $A$ and vector $\mathbf{b}$ using the triangle area $a_i$, the offset normal $\hat{\mathbf{n}}_i$, and the sampling point $\hat{\mathbf{s}}_i$ [S1].
    $$ A = \sum_{i=1}^{n_{samples}} a_i \cdot \hat{\mathbf{n}}_i \hat{\mathbf{n}}_i^T \quad (9) $$
    $$ \mathbf{b} = \sum_{i=1}^{n_{samples}} a_i \cdot \hat{\mathbf{n}}_i^T \hat{\mathbf{s}}_i \quad (10) $$
    *Note: $\hat{\mathbf{n}}_i \hat{\mathbf{n}}_i^T$ denotes the outer product, resulting in a $3 \times 3$ matrix.*

3.  **Solve for Optimal Position:**
    Solve the linear system $A \mathbf{x}_{opt} = \mathbf{b}$ [S1].
    *   **Case 1: Full Rank.** If $A$ is invertible, compute $\mathbf{x}_{opt} = A^{-1} \mathbf{b}$.
    *   **Case 2: Singular/Planar Regions.** If $A$ does not have full rank (e.g., all normals are similar in planar regions), compute the pseudo-inverse $A^+$ using Singular Value Decomposition (SVD) as proposed by Lindström [S1]:
        $$ A = U \Sigma V^T \quad (11) $$
        $$ A^+ = V \Sigma^+ U^T \quad (12, 13) $$
        Then compute $\mathbf{x}_{opt} = A^+ \mathbf{b}$.

4.  **Final Relocation:**
    The new vertex position is determined by the result of the minimization. The method uses $\mathbf{x}_0$ as the starting position for the minimization. If the quadrics minimization yields a distinct minimum, the vertex moves to $\mathbf{x}_{opt}$. If it yields a line or plane of optimal points (degenerate case), the vertex remains at or near $\mathbf{x}_0$ to avoid instability [S1].

**Pseudocode:**

```python
def relocate_vertex(v, neighbors, incident_triangles):
    # Step 1: Laplace smoothing (Center of Mass)
    sum_pos = Vector3(0, 0, 0)
    for neighbor in neighbors:
        sum_pos += neighbor.position
    x0 = sum_pos / len(neighbors)

    # Step 2: Compute weighted error quadrics
    A = Matrix3x3.zeros()
    b = Vector3(0, 0, 0)
    
    for tri in incident_triangles:
        # Get pre-computed sampling data for this triangle relative to v
        # s_hat: projection of sampling point on offset surface
        # n_hat: offset normal at sampling point
        # area: area of the triangle
        s_hat = tri.sampling_point_projection
        n_hat = tri.offset_normal
        area = tri.area
        
        # Outer product n_hat * n_hat^T
        outer_product = n_hat.outer_product(n_hat)
        
        # Accumulate A and b
        # A += area * (n_hat * n_hat^T)
        A += area * outer_product
        
        # b += area * (n_hat^T * s_hat)
        # Note: n_hat^T * s_hat is a scalar dot product
        b += area * (n_hat.dot(s_hat) * n_hat)

    # Step 3: Solve linear system A * x_opt = b
    # Check if A is singular (rank deficient)
    if is_singular(A):
        # Use SVD pseudo-inverse
        U, Sigma, Vt = svd(A)
        # Compute Sigma+ (inverse of non-zero singular values)
        Sigma_inv = diag_matrix(1.0 / s if s > epsilon else 0.0 for s in Sigma.diagonal())
        A_pseudo_inv = Vt.transpose() * Sigma_inv * U.transpose()
        x_opt = A_pseudo_inv * b
    else:
        # Direct solve or inverse
        x_opt = solve_linear_system(A, b)

    # Step 4: Return optimized position
    # In degenerate cases where minimization yields a plane/line,
    # the method implies using x0 or a constrained move.
    # Here we assume x_opt is valid if A was solvable.
    return x_opt
```

**Parameters:**
*   $\epsilon$: Threshold for singular value decomposition to determine rank deficiency. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Planar Regions:** In flat areas, all normals $\hat{\mathbf{n}}_i$ are similar, causing $A$ to lose rank. The SVD pseudo-inverse handles this, but the solution may not be unique [S1].
*   **Performance:** Full QEF minimization (pseudoinverse) is complex and penalizes performance on parallel hardware due to register limits. QEM is chosen to avoid this [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Solving the $3 \times 3$ linear system is constant time per vertex. SVD adds overhead but is bounded.
*   **Memory Complexity:** Requires storage for $A$ ($3 \times 3$ matrix) and $\mathbf{b}$ (3D vector) per vertex.
*   **Strengths:** Lower computational complexity than full QEF minimization; stable with supporting planes; sufficient for volume preservation [S2, unofficial].
*   **Limitations:** Does not achieve the same geometric quality as full QEF minimization [S2, unofficial].
*   **When to use:** When volume preservation is critical and performance on parallel hardware is a concern, and high-fidelity feature preservation is not required [S2, unofficial].
*   **When not to use:** When high geometric accuracy and sharp feature preservation are required over performance [S2, unofficial].

## Background
The method is based on the Quadric Error Metric (QEM) introduced by Garland and Heckbert [GH97], adapted for vertex relocation in mesh generation [S1][S2, unofficial]. It was specifically applied in the context of feature-preserving offset mesh generation from topology-adapted octrees [S1] and for generating smooth high-quality isosurfaces for interactive modeling of complex terrains [S2, unofficial]. The approach was proposed to address the performance penalties of complex QEF computations on modern parallel hardware [S2, unofficial].
