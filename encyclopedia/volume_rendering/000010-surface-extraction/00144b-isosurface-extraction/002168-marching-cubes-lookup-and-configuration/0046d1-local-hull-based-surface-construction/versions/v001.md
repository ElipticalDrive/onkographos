# Local Hull-Based Surface Construction

Also called: 3D hull based surface generation, Local convex classification, Local convex classification and 3D hull based surface generation

## Overview
Local Hull-Based Surface Construction is a surface reconstruction method that addresses the concavity limitations of standard convex hull algorithms by combining Marching Cubes (MC) with local convex classification [S1]. It generates a watertight surface by first estimating an initial MC surface, classifying its vertices into local convex regions, and then applying a 3D convex hull algorithm to each region individually before aggregating the results [S1]. Unlike standard 3D Delaunay triangulation or convex hull methods which struggle with non-convex shapes, this approach preserves the topological flexibility of MC while leveraging the geometric robustness of hull-based generation [S1].

## How it works
The method operates in two main phases: Local Convex Classification and 3D Hull-Based Surface Construction. It relies on an initial octree structure derived from silhouette backprojection and an initial MC surface (typically from Voting MC) [S1].

### Inputs and Outputs
*   **Inputs**:
    *   A set of silhouette images and their corresponding projection matrices [S1].
    *   An initial octree data structure [S1].
    *   An initial MC surface vertex set (obtained from Voting MC) [S1].
*   **Outputs**:
    *   A complete, aggregated 3D surface mesh [S1].
    *   Intermediate: A tree table storing cluster connection information and a local convex vertices table [S1].

### Data Structures
1.  **Octree**: Hierarchical subdivision of space. Each octant is classified as "intersection" (split into 8 suboctants) or "background" (removed) based on 2D silhouette intersection tests [S1].
2.  **Octree Slices ($S_{oc}$)**: Planar slices of the octree data along the z-axis [S1].
3.  **Quantised Octree Slice ($S_{iocq}$)**: A binary image plane where a nonzero point represents an octant [S1].
4.  **MC Slice ($S_{mc}$)**: Planar slices of the MC vertex data [S1].
5.  **Quantised MC Slice ($S_{imcq}$)**: A binary image plane where a vertex is marked if found within the spatial bounds of a quantised octant [S1].
6.  **Tree Table**: Stores information on how local convex clusters connect [S1].
7.  **Local Convex Vertices Table**: Stores the vertices belonging to each classified local convex region [S1].

### Numbered Steps

1.  **Initial Data Preparation**:
    *   Construct an octree by backprojecting each octant onto every silhouette image [S1].
    *   If the backprojected rectangle intersects a silhouette, classify the octant as "intersection" and split it into 8 suboctants [S1].
    *   If there is no intersection, classify as "background" and remove the octant [S1].
    *   Estimate initial MC vertices from the octree, typically using the best Voting MC (VMC) result [S1].

2.  **Local Convex Classification**:
    *   Slice the octree and MC data along the z-axis to create $S_{oc}$ and $S_{mc}$ [S1].
    *   Define the $i$-th sliced data of an octree $S_{ioc}(m, n)$ using the 3D delta function $\delta(x, y, z)$:
        $$ S_{ioc}(m, n) = o(x, y, z)\delta(x - mT, y - nT, z - iT) $$
        where $o(x, y, z)$ is 1 if an octant contains a 3D point $(x, y, z)$ and 0 otherwise, $i, m, n$ are integer indices, and $T$ is the slicing interval [S1].
    *   Quantise the octree slice $S_{iocq}[u, v]$ to treat points from the same octant equally:
        $$ S_{iocq}[u, v] = \bigvee_{j,k=0}^{1} S_{ioc}(u + j, v + k) $$
        where $\bigvee$ denotes logical OR (or sum in binary context) [S1].
    *   Create the quantised MC slice $S_{imcq}[u, v]$ by setting it to 1 when an MC vertex is found within the bounds $uT \le x < (u+1)T$, $vT \le y < (v+1)T$, and $iT \le z < (i+1)T$ [S1].
    *   Estimate cluster conditional probability density functions (pdfs) from every octree slice to classify the initial MC vertices into local convex regions [S1].
    *   Generate the tree table (cluster connections) and the local convex vertices table [S1].

3.  **3D Hull-Based Surface Construction**:
    *   For each local convex region identified in the previous step, apply a 3D convex hull algorithm to generate the local surface [S1].
    *   Handle multiple connections (e.g., 1:n or n:1) by dividing them into $n$ separate 1:1 local convexities before creating the local hull [S1].
    *   Aggregate all locally constructed surfaces to form the final complete surface estimation [S1].

### Parameters
*   **Rotational Angle ($\theta$)**: Set to 6 degrees in the experimental setup [S1].
*   **Number of Projection Matrices**: 60, corresponding to sixty image planes [S1].
*   **VMC Threshold ($v_{th}$)**: Used in the initial Voting MC step. The decision function is:
    $$ \sum_{i=0}^{n} c_i(\theta_i, \vec{x}_{3d}) - v_{th} \le 0, \quad 0 \le v_{th} < n $$
    where $c_i$ is the classification vote [S1].

### Edge Cases and Pitfalls
*   **Multiple Connections**: Local convexities with complex connections (1:n or n:1) must be explicitly divided into $n$ 1:1 convexities before hull generation to ensure correct topology [S1].
*   **Threshold Sensitivity**: The initial VMC threshold $v_{th}$ affects the initial surface quality; choosing an inappropriate threshold can lead to variations even for convex objects [S1].
*   **Slicing Interval ($T$)**: The choice of $T$ affects the resolution of the octree slices and the quantisation process [S1].

## Subtopics

### Voting MC (VMC)
A variant of MC that uses voting from multiple projections to determine vertex classification, serving as the source for the initial surface in this method [S1].

### 3D Convex Hull
The geometric algorithm used to generate the local surfaces from classified convex vertex sets [S1].

### Octree-Based Reconstruction
The spatial data structure used for initial volume classification and slicing [S1].

## Operating characteristics
*   **Complexity**: Not given in the sources.
*   **Performance**: The method produces fewer triangular patches than Delaunay triangulation because it only stores surface triangles without internal ones [S1].
*   **Strengths**: It copes with concavity, which is a limitation of standard 3D hull algorithms, while preserving the advantages of hull-based generation (fewer internal triangles) [S1]. It ensures connectivity (watertightness) by traversing edges twice [S1].
*   **Limitations**: The initial VMC threshold selection is difficult and affects results even for convex objects [S1]. The method requires silhouette images and projection matrices, limiting it to specific acquisition scenarios [S1].
*   **When to use**: When reconstructing surfaces from silhouettes where concavity is present and a watertight mesh is required [S1].

## Background
The method was proposed to address the limitations of 3D Delaunay Triangulation (DT) and Convex Hull algorithms, which are designed for convex shapes and struggle with concavity [S1]. It builds on the concept of Voting MC (VMC) and integrates local convex classification with 3D hull generation [S1]. The approach premises two properties of 3D objects: connectivity (watertightness) and piecewise convexity (continuity of local convex shapes) [S1].
