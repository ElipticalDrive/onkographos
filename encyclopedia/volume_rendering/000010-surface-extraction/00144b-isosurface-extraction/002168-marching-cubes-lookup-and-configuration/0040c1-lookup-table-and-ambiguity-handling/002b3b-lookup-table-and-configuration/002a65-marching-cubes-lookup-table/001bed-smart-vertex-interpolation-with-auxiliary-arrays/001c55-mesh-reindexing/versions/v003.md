# Mesh Reindexing

Also called: Global ID Assignment, Isosurface Point Deduplication, Vertex Deduplication via Mapping

## Overview
Mesh Reindexing deduplicates vertices generated during isosurface extraction by assigning contiguous global IDs to geometrically unique points and reconstructing the final vertex and index buffers [S1, S2, unofficial]. It ensures that vertices shared by adjacent cells share the same index in the final output, preventing duplicate geometry [S1, S2, unofficial].

## How it works
**Inputs:**
- `vertexMapping`: A mapping from local edge or cell identifiers to vertex coordinates. In [S1, unofficial], this is a `std::map<size_t, IdPoint>` where `IdPoint` contains `id`, `x`, `y`, `z` [S1, unofficial]. In [S2, unofficial], vertices are stored in a structure allowing lookup by coordinate string keys [S2, unofficial].
- `triangles`: A list of triangles, where each triangle references vertices by their local identifiers [S1, unofficial].

**Outputs:**
- `vertices`: An array of unique vertex positions [S1, S2, unofficial].
- `normals`: An array of unique vertex normals (if computed) [S1, unofficial].
- `faces`: An array of triangle indices referencing the unique `vertices` array [S1, unofficial].

**Data Structures:**
- `PointIdMapping` (from [S1, unofficial]): `std::map<size_t, IdPoint>`. Key is a unique edge ID (e.g., `edgeId(x, y, z, edgeIndex, xDim, yDim)`) [S1, unofficial]. Value is `IdPoint` struct with `size_t id` and `float x, y, z` [S1, unofficial].
- `pointIndex` (from [S2, unofficial]): A hash map or dictionary mapping a string representation of coordinates (e.g., `toString()`) to a global integer index [S2, unofficial].
- `isosurfacePoints` (from [S2, unofficial]): A list or vector of unique vertex coordinates [S2, unofficial].
- `isosurfaceTriangles` (from [S2, unofficial]): A list or vector of triangle structures containing three global vertex indices [S2, unofficial].

**Steps:**
1. **Initialize:** Initialize `nextId = 0` and prepare to iterate `vertexMapping` [S1, unofficial].
2. **Iterate and Deduplicate:**
   - For each entry in `vertexMapping` (or for each unique vertex coordinate):
   - **Method A ([S1, unofficial]):** Iterate through the `vertexMapping` map. Assign a sequential global ID to each vertex. `globalId = nextId++` [S1, unofficial]. Store the mapping from the local key to `globalId` [S1, unofficial].
   - **Method B ([S2, unofficial]):** Convert vertex coordinates to a string key using `toString()` [S2, unofficial]. If `key` is not in `pointIndex`, insert the point into `isosurfacePoints` and store the new index in `pointIndex` [S2, unofficial]. Increment `nextId` [S2, unofficial]. Else, retrieve the existing index from `pointIndex[key]` [S2, unofficial].
3. **Update Triangle Indices:**
   - For each triangle in the input list:
   - Replace each local vertex identifier with its corresponding global ID from the mapping established in Step 2 [S1, unofficial].
   - In [S1, unofficial], this involves looking up the global ID for each of the three points [S1, unofficial].
   - In [S2, unofficial], create a triangle structure using the deduplicated vertex indices and insert it into `isosurfaceTriangles` [S2, unofficial].
4. **Construct Final Buffers:**
   - Allocate a `Point` array for vertices and copy coordinates from the mapping or `isosurfacePoints` [S1, S2, unofficial].
   - Allocate a `size_t` array for triangle indices and copy the updated global point IDs from the triangles vector [S1, unofficial].
   - [S1, unofficial] also computes vertex normals by accumulating normals from adjacent triangles and normalizing them [S1, unofficial].

**Pseudocode:**
```python
def mesh_reindex(vertex_mapping, triangles):
    """
    vertex_mapping: dict mapping local_id -> (x, y, z)
    triangles: list of tuples (local_id_1, local_id_2, local_id_3)
    Returns: (vertices, faces)
    """
    local_to_global = {}
    next_id = 0
    vertices = []

    # Step 2: Iterate and assign global IDs
    for local_id in vertex_mapping:
        local_to_global[local_id] = next_id
        vertices.append(vertex_mapping[local_id])
        next_id += 1

    # Step 3: Update triangle indices
    faces = []
    for tri in triangles:
        global_ids = [local_to_global[local_id] for local_id in tri]
        faces.append(global_ids)

    return vertices, faces
```

**Edge Cases and Pitfalls:**
- **Degenerate Triangles:** Triangles with identical vertices (e.g., all three points are the same) should be filtered out before or during reindexing [S2, unofficial].
- **Precision:** Floating-point comparisons for deduplication must use a tolerance. Using string keys [S2, unofficial] implies a specific formatting precision; slight floating-point errors may cause duplicate vertices to be treated as distinct if not handled with a tolerance-based hash or spatial grid [G].
- **Boundary Conditions:** In [S1, unofficial], specific edge cases at grid boundaries (`x == xDim - 1`, etc.) are handled explicitly to ensure all relevant edges are processed [S1, unofficial].

## Background
Mesh Reindexing is a standard post-processing step in isosurface extraction algorithms like Marching Cubes [S1, unofficial] and Marching Tetrahedra [S2, unofficial]. It addresses the inherent redundancy in cell-based extraction methods where each cell independently computes vertices on shared edges [S1, S2, unofficial]. The technique is used in custom implementations like those in ilastik [S1, unofficial] and scientific visualization workflows involving VTK [S2, unofficial].
