# Marching Cubes with Disjoint Patch Decomposition

Also called: Disjoint patch MC, MC with edge grouping

## Overview
Marching Cubes with Disjoint Patch Decomposition is a surface extraction method that resolves topological ambiguities in standard Marching Cubes by decomposing the surface within each voxel into disjoint connected components (patches) [S1, unofficial]. Unlike standard implementations that select a single triangulation for ambiguous cases—potentially causing non-manifold edges or topological conflicts with neighbors—this method isolates ambiguities by ensuring topological correctness through graph-based edge coloring [S1, unofficial].

## How it works
The method processes each voxel independently to generate a set of disjoint surface patches, which are later assembled into a global mesh [S1, unofficial]. The core innovation is the decomposition of the cube's interior into a graph of edges, where ambiguous (uncut) edges are grouped into connected components to determine patch assignments for cut edges [S1, unofficial].

### Inputs and Outputs
- **Input**: A scalar field $V$ defined on a 3D grid, an isovalue $\theta$ (default 0.7 [S1, unofficial]), and the voxel corner indices.
- **Output**: A set of triangle vertices and indices for each voxel, organized by patch ID. The global mesh is formed by merging these patches, handling intersections in a subsequent step (see [Mesh Extraction](14720-mesh-extraction.md)) [S1, unofficial].

### Data Structures
For each voxel, the algorithm defines 15 points:
- **Vertices**: Indices 0–7, corresponding to the 8 corners of the cube [S1, unofficial].
- **Face Centers**: Indices 8–13, one for each of the 6 faces [S1, unofficial].
- **Cube Center**: Index 14 [S1, unofficial].

The cube faces are defined by vertex indices:
`CUBEFACES = [[0, 2, 6, 4], [1, 5, 7, 3], [0, 4, 5, 1], [2, 3, 7, 6], [0, 1, 3, 2], [4, 6, 7, 5]]` [S1, unofficial].

To decompose the cube for scalar evaluation, 24 tetrahedra are created [S1, unofficial]. For each face $f \in [0, 5]$, four tetrahedra are formed using vertices from the face, the face center ($8+f$), and the cube center (14):
`tet{CUBEFACES[f][(j+1)&3], CUBEFACES[f][j], 8+f, 14}` for $j=0..3$ [S1, unofficial].

An **edge map** is built to identify unique edges across the tetrahedra [S1, unofficial]. For each tetrahedron, iterate over its 6 edges defined by index pairs:
`i[6] = {0, 0, 0, 1, 1, 2}`
`j[6] = {1, 2, 3, 2, 3, 3}`
The edge ID is computed as `min(u, v) * 100 + max(u, v)` [S1, unofficial]. Unique edge IDs are mapped to sequential indices $0..N-1$ [S1, unofficial].

A **graph** of edges is constructed [S1, unofficial]. For each tetrahedron, for every pair of edges $(k, ks)$ where $ks > k$, an undirected edge is added between their mapped indices in an adjacency list `graph` [S1, unofficial].

The lookup code for each case is stored in an array `edgeGroup[256]`, where each integer encodes the 6 cube edges with 4 bits per edge (bits 0–3 for edge 0, etc.) [S1, unofficial].

### Algorithm Steps

1.  **Scalar Evaluation**: For a given 8-bit vertex sign pattern (case), compute scalar values for all 15 points [S1, unofficial].
    -   Vertices $0..7$ get values $0$ or $1$ based on the case bits relative to $\theta$ [S1, unofficial].
    -   Face centers $8..13$ get the average of their 4 vertex values [S1, unofficial].
    -   Cube center $14$ gets the average of its 8 vertex values [S1, unofficial].

2.  **Edge Marking**: For each of the 12 cube edges $(u, v)$:
    -   If `(vals[u] > theta) ^ (vals[v] > theta)` is false, mark the edge as `-1` (uncut/ambiguous) [S1, unofficial].
    -   Otherwise, mark the edge as `0` (cut) [S1, unofficial].

3.  **Connected Components of Uncut Edges**:
    -   Build an adjacency matrix $A$ where $A(u,v)=1$ if both $u$ and $v$ are uncut edges and are connected in the tetrahedral graph [S1, unofficial].
    -   Compute the transitive closure by iterating $A = \text{sign}(A*A)$ until convergence [S1, unofficial].

4.  **Patch Coloring**:
    -   Iterate over all cut edges (marked `0`) [S1, unofficial].
    -   If an edge is not yet colored, assign a new color ID (patch ID) [S1, unofficial].
    -   Propagate this color ID to all other cut edges connected to it in the graph, using the transitive closure matrix $A$ to determine connectivity through uncut edges [S1, unofficial].
    -   Increment the color ID for the next uncolored cut edge [S1, unofficial].

5.  **Lookup Code Generation**:
    -   For each of the 6 cube edges between vertices $(v_1, v_2 < 8)$, compute the cube edge index `ceid` [S1, unofficial].
    -   Map the patch mark `mkid`: if `-1` (uncut), map to `3`; else map to `mkid-1` [S1, unofficial].
    -   Pack these 4-bit values into a 24-bit integer code (6 edges $\times$ 4 bits) [S1, unofficial].

6.  **Vertex Generation**:
    -   For each cut edge, compute the intersection point using linear interpolation:
        $$ w = \frac{\theta - v_1}{v_2 - v_1} $$
        $$ P = (1-w)P_1 + wP_2 $$
    -   Vertices are grouped by patch ID. For each patch with $cnt[i] > 0$ vertices, the final vertex position is the average of the generated points:
        $$ P_{patch} = \frac{1}{cnt[i]} \sum_{j=1}^{cnt[i]} P_j $$
    -   Boundary conditions may clamp coordinates to the voxel bounds based on `cubeflag` [S1, unofficial].

7.  **Mesh Assembly**:
    -   The generated vertices are added to the mesh [S1, unofficial]. For ambiguous cases, the method may generate multiple patches per voxel [S1, unofficial]. These patches are later processed by [Mesh Extraction](14720-mesh-extraction.md) to resolve intersections and ensure manifold topology [S1, unofficial].

### Pseudocode

```python
CUBEFACES = [
    [0, 2, 6, 4], [1, 5, 7, 3], [0, 4, 5, 1],
    [2, 3, 7, 6], [0, 1, 3, 2], [4, 6, 7, 5]
]
TET_EDGE_INDICES = [(0,1), (0,2), (0,3), (1,2), (1,3), (2,3)]
CUBE_EDGES_12 = [
    (0,1), (2,3), (4,5), (6,7), # x-edges
    (0,2), (1,3), (4,6), (5,7), # y-edges
    (0,4), (1,5), (2,6), (3,7)  # z-edges
]
# The source specifies 6 edges for the lookup code generation step
CUBE_EDGES_LOOKUP = CUBE_EDGES_12[:6]

def marching_cubes_disjoint_patch(grid, level, voxel_size, origin):
    vertices = []
    
    for i in range(grid.shape[0] - 1):
        for j in range(grid.shape[1] - 1):
            for k in range(grid.shape[2] - 1):
                # 1. Scalar Evaluation
                v = [
                    grid[i, j, k], grid[i+1, j, k], grid[i, j+1, k], grid[i+1, j+1, k],
                    grid[i, j, k+1], grid[i+1, j, k+1], grid[i, j+1, k+1], grid[i+1, j+1, k+1]
                ]
                case = 0
                for bit in range(8):
                    if v[bit] > level:
                        case |= (1 << bit)
                
                points = v.copy()
                for f in range(6):
                    face_verts = CUBEFACES[f]
                    avg = sum(v[face_verts[m]] for m in range(4)) / 4.0
                    points.append(avg)
                avg_center = sum(v) / 8.0
                points.append(avg_center)
                
                # 2. Build edge map and graph
                edge_map = {}
                graph = {}
                all_tet_edges = []
                
                for f in range(6):
                    face_verts = CUBEFACES[f]
                    fc_idx = 8 + f
                    cc_idx = 14
                    for j_idx in range(4):
                        v1_idx = face_verts[(j_idx+1)&3]
                        v2_idx = face_verts[j_idx]
                        tet_verts = [v1_idx, v2_idx, fc_idx, cc_idx]
                        tet_edges_list = []
                        for e1, e2 in TET_EDGE_INDICES:
                            u = tet_verts[e1]
                            v = tet_verts[e2]
                            edge_id = min(u, v) * 100 + max(u, v)
                            if edge_id not in edge_map:
                                edge_map[edge_id] = len(edge_map)
                                graph[edge_map[edge_id]] = []
                            tet_edges_list.append(edge_map[edge_id])
                        all_tet_edges.append(tet_edges_list)
                
                for tet_edge_list in all_tet_edges:
                    for k in range(6):
                        for ks in range(k+1, 6):
                            u = tet_edge_list[k]
                            nbr = tet_edge_list[ks]
                            if u not in graph: graph[u] = []
                            if nbr not in graph: graph[nbr] = []
                            graph[u].append(nbr)
                            graph[nbr].append(u)
                
                # 3. Mark edges (12 cube edges)
                cube_edge_indices = []
                for e in CUBE_EDGES_12:
                    u, v = e
                    edge_id = min(u, v) * 100 + max(u, v)
                    cube_edge_indices.append(edge_map[edge_id])
                
                edge_marks = [-1] * 12
                for idx, edge_idx in enumerate(cube_edge_indices):
                    u = CUBE_EDGES_12[idx][0]
                    v = CUBE_EDGES_12[idx][1]
                    val_u = points[u]
                    val_v = points[v]
                    if (val_u > level) == (val_v > level):
                        edge_marks[idx] = -1
                    else:
                        edge_marks[idx] = 0
                
                # 4. Connected components of uncut edges
                uncut_edges = [i for i, m in enumerate(edge_marks) if m == -1]
                A = [[0]*12 for _ in range(12)]
                for u in uncut_edges:
                    for v in uncut_edges:
                        if u != v and v in graph.get(u, []):
                            A[u][v] = 1
                
                while True:
                    new_A = [[0]*12 for _ in range(12)]
                    for i in range(12):
                        for j in range(12):
                            new_A[i][j] = any(A[i][k] and A[k][j] for k in range(12))
                    if new_A == A:
                        break
                    A = new_A
                
                # 5. Patch Coloring
                patch_colors = [-1] * 12
                color_id = 0
                for idx in range(12):
                    if edge_marks[idx] == 0 and patch_colors[idx] == -1:
                        patch_colors[idx] = color_id
                        stack = [idx]
                        while stack:
                            curr = stack.pop()
                            for nbr in graph.get(curr, []):
                                if edge_marks[nbr] == 0 and patch_colors[nbr] == -1:
                                    if A[curr][nbr]:
                                        patch_colors[nbr] = color_id
                                        stack.append(nbr)
                        color_id += 1
                
                # 6. Lookup Code Generation (6 edges per notes)
                code = 0
                for idx in range(6):
                    u, v = CUBE_EDGES_LOOKUP[idx]
                    edge_id = min(u, v) * 100 + max(u, v)
                    orig_idx = cube_edge_indices.index(edge_id)
                    mkid = edge_marks[orig_idx]
                    mapped = 3 if mkid == -1 else mkid - 1
                    code |= (mapped << (4 * idx))
                
                # 7. Vertex Generation
                patch_counts = [0] * 4
                patch_points = [[0.0, 0.0, 0.0] for _ in range(4)]
                
                for idx in range(12):
                    if edge_marks[idx] == 0:
                        u, v = CUBE_EDGES_12[idx]
                        val_u = points[u]
                        val_v = points[v]
                        w = (level - val_u) / (val_v - val_u)
                        p1 = voxel_to_world(u, i, j, k, voxel_size, origin)
                        p2 = voxel_to_world(v, i, j, k, voxel_size, origin)
                        pt = lerp(p1, p2, w)
                        
                        patch_id = patch_colors[idx]
                        patch_counts[patch_id] += 1
                        patch_points[patch_id][0] += pt[0]
                        patch_points[patch_id][1] += pt[1]
                        patch_points[patch_id][2] += pt[2]
                
                for pid in range(4):
                    if patch_counts[pid] > 0:
                        avg_pt = [
                            patch_points[pid][0] / patch_counts[pid],
                            patch_points[pid][1] / patch_counts[pid],
                            patch_points[pid][2] / patch_counts[pid]
                        ]
                        vertices.append(avg_pt)
                        
    return vertices

def voxel_to_world(vertex_idx, i, j, k, voxel_size, origin):
    x = i * voxel_size[0] + (vertex_idx & 1) * voxel_size[0]
    y = j * voxel_size[1] + ((vertex_idx >> 1) & 1) * voxel_size[1]
    z = k * voxel_size[2] + ((vertex_idx >> 2) & 1) * voxel_size[2]
    return (x + origin[0], y + origin[1], z + origin[2])

def lerp(p1, p2, w):
    return (p1[0]*(1-w) + p2[0]*w, p1[1]*(1-w) + p2[1]*w, p1[2]*(1-w) + p2[2]*w)
```

### Edge Cases and Pitfalls
-   **Precision**: Floating-point comparisons for `vals[u] > theta` can be sensitive. The source uses strict inequality [S1, unofficial].
-   **Boundary Conditions**: The source mentions `cubeflag` for clamping coordinates at the domain boundaries. Ensure these flags are set correctly for voxels on the grid edge [S1, unofficial].
-   **Degenerate Input**: If all vertex values are equal to $\theta$, all edges are uncut. The algorithm should handle this by not generating any vertices for that voxel [S1, unofficial].
-   **Non-Manifold Geometry**: The disjoint patch approach isolates ambiguities, but the final mesh assembly must handle cases where patches from adjacent voxels intersect. This is delegated to [Mesh Extraction](14720-mesh-extraction.md) [S1, unofficial].

## Operating characteristics
-   **Time Complexity**: The graph construction and transitive closure are performed per voxel. The transitive closure on a small graph (12-15 nodes) is constant time, making the overall complexity linear with respect to the number of voxels $O(N)$ [S1, unofficial].
-   **Memory Complexity**: Requires storing the scalar field, the edge group lookup table, and temporary graph structures per voxel. Memory usage is $O(N)$ for the field and $O(1)$ per voxel for temporary structures [S1, unofficial].
-   **Performance**: The method is computationally more expensive than standard Marching Cubes due to the graph operations and patch coloring. However, it guarantees topological correctness without post-processing cleanup [S1, unofficial].
-   **Strengths**: Guarantees manifold topology for ambiguous cases. Isolates topological ambiguities, making the mesh assembly step more predictable [S1, unofficial].
-   **Limitations**: More complex implementation. Requires a subsequent step ([Mesh Extraction](14720-mesh-extraction.md)) to handle patch intersections [S1, unofficial].
-   **When to Use**: When topological correctness is critical and the scene contains ambiguous isosurface configurations. Not suitable for real-time applications where performance is paramount and topological errors can be tolerated or fixed later [S1, unofficial].

## Background
The method originates from the `uranix/mcubes` repository, an unofficial implementation of Marching Cubes with disjoint patch decomposition [S1, unofficial]. It addresses the limitations of the standard `triangleTable` in handling the 8 ambiguous cases by decomposing the surface into disjoint patches [S1, unofficial]. The approach is part of a broader family of topology-aware isosurface extraction methods [S1, unofficial].
