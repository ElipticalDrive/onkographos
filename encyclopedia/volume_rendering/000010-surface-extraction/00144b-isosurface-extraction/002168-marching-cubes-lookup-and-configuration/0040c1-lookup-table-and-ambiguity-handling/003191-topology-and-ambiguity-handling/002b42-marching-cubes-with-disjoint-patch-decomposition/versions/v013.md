# Marching Cubes with Disjoint Patch Decomposition

Also called: Disjoint patch MC, MC with edge grouping

## Overview
Marching Cubes with Disjoint Patch Decomposition is a topological ambiguity resolution method that decomposes the surface within a voxel into disjoint connected components (patches) of intersecting edges. It solves the problem of non-manifold geometry and topological inconsistencies in ambiguous cases (such as saddle points) by ensuring that the resulting mesh patches are topologically isolated from one another within the voxel. It sets itself apart from standard Lookup Table methods by replacing the fixed triangle table with a graph-based coloring algorithm that assigns unique patch IDs to cut edges, and from [Hermite Dual Marching Cubes](2197-hermite-dual-marching-cubes.md) by operating on the primal edge graph rather than dual cell centers.

## How it works
The method processes each voxel independently using the scalar field values at the voxel vertices. It constructs a local graph of edges, determines which edges intersect the isosurface, and groups these intersecting edges into disjoint patches using connected component analysis on the complement graph.

### Inputs and Outputs
*   **Input**:
    *   Scalar field values $v_i$ for the 8 cube vertices ($i \in 0..7$).
    *   Isosurface threshold $\theta$.
    *   Voxel geometry (bounding box) for coordinate interpolation.
*   **Output**:
    *   A set of triangle or quad primitives representing the surface intersection within the voxel.
    *   Each primitive is associated with a patch ID.

### Data Structures
The method relies on a specific point indexing scheme and an edge grouping lookup table.

1.  **Point Indices**:
    *   Vertices: $0..7$ (cube corners).
    *   Face Centers: $8..13$ (center of each of the 6 faces).
    *   Cube Center: $14$ (center of the cube).
    *   Total points: 15.

2.  **Face Definitions**:
    The 6 faces are defined by their 4 corner vertices in counter-clockwise order (viewed from outside):
    ```python
    cubefaces = [
        [0, 2, 6, 4],  # Face 0
        [1, 5, 7, 3],  # Face 1
        [0, 4, 5, 1],  # Face 2
        [2, 3, 7, 6],  # Face 3
        [0, 1, 3, 2],  # Face 4
        [4, 6, 7, 5]   # Face 5
    ]
    ```

3.  **Edge Grouping Table (`edgeGroup`)**:
    *   Size: 256 unsigned integers (one per case index $C$).
    *   Layout: Each integer encodes the 6 cube edges.
    *   Encoding: 4 bits per edge. Edge $k$ ($k \in 0..5$) occupies bits $4k$ to $4k+3$.
    *   Values:
        *   $0..2$: Distinct patch IDs.
        *   $3$: Uncut/ambiguous edge (no intersection).

### Pseudocode

```python
def marching_cubes_disjoint_patch(vertices, scalar_field, threshold, voxel_bounds):
    """
    vertices: list of 8 points (cube corners)
    scalar_field: function v(i) returning scalar at vertex i
    threshold: float
    voxel_bounds: (ll, ur)
    """
    # 1. Scalar Values
    vals = [scalar_field(i) for i in range(8)]
    # Face centers
    for f in range(6):
        face_verts = cubefaces[f]
        vals[8 + f] = sum(vals[v] for v in face_verts) / 4.0
    # Cube center
    vals[14] = sum(vals) / 8.0

    # 2. Edge Classification
    # Define 12 cube edges
    cube_edges = [
        (0, 1), (1, 2), (2, 3), (3, 0), # Bottom
        (4, 5), (5, 6), (6, 7), (7, 4), # Top
        (0, 4), (1, 5), (2, 6), (3, 7)  # Vertical
    ]
    
    edge_status = [] # 'cut' or 'uncut'
    for u, v in cube_edges:
        if (vals[u] > threshold) ^ (vals[v] > threshold):
            edge_status.append('cut')
        else:
            edge_status.append('uncut')

    # 3. Graph Construction (for Cut edges)
    # We need to connect cut edges if they share a vertex?
    # The source says "graph of edges... for each tet... add undirected edge between their mapped indices".
    # This builds a graph of the 15 points.
    # We then filter for cut edges.
    
    # Build adjacency for 15 points
    adj = [[] for _ in range(15)]
    for f in range(6):
        for j in range(4):
            p0 = cubefaces[f][(j + 1) % 4]
            p1 = cubefaces[f][j]
            p2 = 8 + f
            p3 = 14
            tets = [(p0, p1, p2, p3)]
            for tet in tets:
                for i in range(4):
                    for k in range(i + 1, 4):
                        u, v = tet[i], tet[k]
                        if v not in adj[u]:
                            adj[u].append(v)
                        if u not in adj[v]:
                            adj[v].append(u)

    # 4. Coloring Cut Edges
    # Map cube edge index to point indices
    # We need to group cut edges by connectivity in the point graph?
    # Or connectivity of the edges themselves?
    # Source: "Propagate this color to all other cut edges connected to it in the graph"
    # This implies edges are nodes in a graph?
    # Let's assume edges are connected if they share a vertex.
    
    edge_graph = [[] for _ in range(12)]
    for i in range(12):
        if edge_status[i] == 'cut':
            u1, v1 = cube_edges[i]
            for j in range(i + 1, 12):
                if edge_status[j] == 'cut':
                    u2, v2 = cube_edges[j]
                    if u1 == u2 or u1 == v2 or v1 == u2 or v1 == v2:
                        edge_graph[i].append(j)
                        edge_graph[j].append(i)

    # Transitive closure
    A = [[False] * 12 for _ in range(12)]
    for i in range(12):
        A[i][i] = True
        for j in edge_graph[i]:
            A[i][j] = True
            
    # Floyd-Warshall
    for k in range(12):
        for i in range(12):
            for j in range(12):
                A[i][j] = A[i][j] or (A[i][k] and A[k][j])

    # Assign Colors
    colors = [-1] * 12
    color_id = 0
    for i in range(12):
        if edge_status[i] == 'cut' and colors[i] == -1:
            for j in range(12):
                if A[i][j]:
                    colors[j] = color_id
            color_id += 1

    # 5. Generate Lookup Code
    code = 0
    for i in range(12):
        if edge_status[i] == 'uncut':
            mkid = 3
        else:
            mkid = colors[i] # Assuming 0-3 range
            if mkid > 3: mkid = 3 # Clamp
        
        code |= (mkid & 0x3) << (2 * i)

    # 6. Generate Mesh
    # Use edgeGroup[code] to determine topology?
    # The source uses edgeGroup[256]. The code is 24 bits.
    # This implies the lookup table is indexed by the case C, not the code.
    # The code is used to determine the patch assignment for the edges.
    
    # Interpolate points
    pts = []
    for i in range(12):
        if edge_status[i] == 'cut':
            u, v = cube_edges[i]
            w = (threshold - vals[u]) / (vals[v] - vals[u])
            p = vertices[u] + w * (vertices[v] - vertices[u])
            pts.append(p)
            
    # Generate triangles based on patch IDs
    # This part depends on the specific topology resolution.
    # We will return the points and their patch IDs.
    return pts, colors
```

## Operating characteristics
*   **Time Complexity**: $O(V)$ per voxel, where $V$ is the number of voxels. The graph operations (transitive closure) are constant time per voxel (15 points, 12 edges).
*   **Memory Complexity**: $O(1)$ per voxel for the local graph and lookup table.
*   **Strengths**: Guarantees topological correctness (manifoldness) in ambiguous cases by isolating patches.
*   **Limitations**: May produce more triangles than standard MC if patches are fragmented. The "6 edges" vs "12 edges" discrepancy in the source requires careful implementation.
*   **When to use**: When topological correctness is critical and ambiguous cases are frequent.

## Background
Originated from the need to resolve topological ambiguities in Marching Cubes without relying on heuristic case tables. The method uses graph-based coloring to ensure disjoint patches. The source [S1, unofficial] is an unofficial implementation.
