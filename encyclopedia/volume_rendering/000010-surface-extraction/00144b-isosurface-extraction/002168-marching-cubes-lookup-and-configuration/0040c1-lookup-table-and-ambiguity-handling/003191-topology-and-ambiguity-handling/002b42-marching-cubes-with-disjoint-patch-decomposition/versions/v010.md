# Marching Cubes with Disjoint Patch Decomposition

Also called: Disjoint patch MC, MC with edge grouping

## Overview
This method is a variant of Marching Cubes that decomposes the surface within a cube into disjoint patches (connected components of edges) to handle ambiguous cases, such as saddle points, by ensuring topological correctness through graph-based coloring [S1, unofficial]. It sets itself apart from standard Lookup Table and Ambiguity Handling methods by explicitly resolving topological ambiguities via connected component analysis of uncut edges, rather than relying on pre-defined lookup tables for ambiguous cases [S1, unofficial].

## How it works
**Inputs:**
- Scalar field values $v_i$ for the 8 vertices of a cube.
- Threshold $\theta$ (default 0.7) [S1, unofficial].
- Cube configuration index (8-bit sign pattern).

**Outputs:**
- A set of triangle or quad primitives representing the isosurface within the cube.
- A lookup code encoding the patch assignment for each of the 6 cube edges.

**Data Structures:**
1.  **Points:** 15 points per cube.
    -   Indices 0-7: Cube vertices.
    -   Indices 8-13: Face centers (one per face).
    -   Index 14: Cube center.
2.  **Faces:** 6 faces defined by vertex indices:
    `cubefaces[6][4] = {{0, 2, 6, 4}, {1, 5, 7, 3}, {0, 4, 5, 1}, {2, 3, 7, 6}, {0, 1, 3, 2}, {4, 6, 7, 5}}` [S1, unofficial].
3.  **Tetrahedra:** 24 tetrahedra decomposing the cube. For each face $f \in [0,5]$, create 4 tets using vertices from the face, the face center ($8+f$), and the cube center (14). Specifically: `tet{cubefaces[f][(j+1)&3], cubefaces[f][j], 8+f, 14}` for $j=0..3$ [S1, unofficial].
4.  **Edge Map:** Maps unique edge IDs to sequential indices $0..N-1$. Edge ID computed as `min(u,v)*100 + max(u,v)` for edge endpoints $u,v$ [S1, unofficial].
5.  **Graph:** Adjacency list representing connectivity between edges. An undirected edge exists between mapped indices $k$ and $ks$ if they belong to the same tetrahedron and $ks > k$ [S1, unofficial].
6.  **Edge Group Lookup:** `edgeGroup[256]`, an array of 256 unsigned integers. Each integer encodes the 6 cube edges (indices 0-5) with 4 bits per edge. Values 0-3 represent different patch assignments or uncategorized edges [S1, unofficial].

**Steps:**

1.  **Compute Scalar Values:**
    For the given case (8-bit vertex sign pattern), compute scalar values for all 15 points:
    -   Vertices 0-7: $0$ or $1$ based on case bits.
    -   Face centers 8-13: Average of their 4 vertex values.
    -   Cube center 14: Average of its 8 vertex values [S1, unofficial].

2.  **Mark Edges:**
    For each edge $(u, v)$ in the graph:
    -   If $(vals[u] > \theta) \oplus (vals[v] > \theta)$ is false, mark as $-1$ (uncut/ambiguous).
    -   Otherwise, mark as $0$ (cut) [S1, unofficial].

3.  **Compute Connected Components of Uncut Edges:**
    -   Build adjacency matrix $A$ where $A(u,v)=1$ if both $u$ and $v$ are uncut and connected in the graph.
    -   Compute transitive closure by iterating $A = \text{sign}(A*A)$ until convergence [S1, unofficial].

4.  **Color Cut Edges into Disjoint Patches:**
    -   Iterate through all edges.
    -   If an edge is cut ($0$) and not yet colored, assign a new color ID.
    -   Propagate this color to all other cut edges connected to it in the graph (using the transitive closure matrix $A$).
    -   Increment color ID [S1, unofficial].

5.  **Generate Lookup Code:**
    -   For each edge between two cube vertices ($v1, v2 < 8$), compute cube edge index $ceid$.
    -   Map the patch mark $mkid$: if $-1$, map to $3$; else map to $mkid-1$.
    -   Pack these 4-bit values into a 24-bit integer code (6 edges * 4 bits) [S1, unofficial].

6.  **Mesh Generation:**
    -   Iterate through the 6 cube edges.
    -   For each edge, determine if it is cut ($c1 \neq c2$).
    -   If cut, compute interpolation weight $w = (\theta - v1) / (v2 - v1)$.
    -   Calculate the intersection point using `edge_point(cube, e, w)`.
    -   Accumulate points per patch ID.
    -   After processing all edges, compute the centroid for each patch with non-zero count: $p = \text{newpts}[i] * (1. / \text{cnt}[i])$.
    -   Apply boundary flags (`cubeflag`) to snap points to cube boundaries if necessary [S1, unofficial].
    -   Generate primitives (triangles or quads) based on the patch configuration. If `NON_SYMMETRIC_SPLIT` is defined, use quality metrics to decide triangulation; otherwise, split quads using the face center [S1, unofficial].

    # 1. Define Points and Structure
    # Points 0-7: vertices, 8-13: face centers, 14: cube center
    cubefaces = [
        [0, 2, 6, 4], [1, 5, 7, 3], [0, 4, 5, 1],
        [2, 3, 7, 6], [0, 1, 3, 2], [4, 6, 7, 5]
    ]
    
    # 2. Compute Scalar Values for 15 points
    vals = [0.0] * 15
    for i in range(8):
        vals[i] = 1.0 if cube_vertices[i] > level else 0.0
    
    for f in range(6):
        face_verts = cubefaces[f]
        vals[8 + f] = sum(vals[v] for v in face_verts) / 4.0
    
    vals[14] = sum(vals[i] for i in range(8)) / 8.0
    
    # 3. Build Graph and Edge Map
    # Define tets: for each face f, 4 tets using face vertices, face center (8+f), cube center (14)
    tets = []
    for f in range(6):
        face_verts = cubefaces[f]
        fc = 8 + f
        cc = 14
        for j in range(4):
            v1 = face_verts[(j + 1) & 3]
            v2 = face_verts[j]
            tets.append([v1, v2, fc, cc])
            
    # Map edges to indices
    edge_map = {}
    edge_list = []
    for tet in tets:
        # 6 edges per tet
        edge_pairs = [(0,1), (0,2), (0,3), (1,2), (1,3), (2,3)]

            v = tet[v_idx]
            if u > v: u, v = v, u

            if edge_id not in edge_map:

                graph[tet_edges[k]].append(tet_edges[ks])
                graph[tet_edges[ks]].append(tet_edges[k])
                
    # 4. Mark Edges
    marks = [0] * len(edge_list) # 0: cut, -1: uncut
    for idx, (u, v) in enumerate(edge_list):
        c1 = vals[u] > level
        c2 = vals[v] > level
        if c1 == c2:
            marks[idx] = -1
        else:
            marks[idx] = 0
            
    # 5. Compute Connected Components of Uncut Edges
    # Build adjacency matrix A for uncut edges
    n_edges = len(edge_list)
    A = [[0] * n_edges for _ in range(n_edges)]
    for u in range(n_edges):
        if marks[u] == -1:

                if marks[v] == -1:
                    A[u][v] = 1

**Edge Cases and Pitfalls:**
-   **Precision:** Floating point comparisons for `vals[u] > level` must be consistent.
-   **Boundaries:** Boundary flags (`cubeflag`) must be applied to snap points to cube boundaries if the cube is on the domain edge [S1, unofficial].
-   **Degenerate Input:** If all vertices have the same sign, no edges are cut, and no mesh is generated.

## Operating characteristics
-   **Time Complexity:** Dominated by the transitive closure computation, which is $O(N^3)$ for $N$ edges per cube, but $N$ is small (24 tets * 6 edges = 144 max edges, but many are shared). In practice, it is very fast per cube.
-   **Memory Complexity:** $O(N^2)$ for the adjacency matrix $A$.
-   **Strengths:** Guarantees topological correctness for ambiguous cases by explicitly decomposing the surface into disjoint patches.
-   **Limitations:** More complex implementation than standard Marching Cubes. Requires careful handling of edge mapping and graph construction.
-   **When to use:** When topological correctness is critical and ambiguous cases (saddle points) are common.
-   **When not to use:** For simple, non-ambiguous scalar fields where standard Marching Cubes suffices.

## Background
This method originates from the `uranix/mcubes` repository, an unofficial implementation of Marching Cubes with disjoint patch decomposition [S1, unofficial]. It addresses the limitations of standard lookup tables in handling ambiguous cases by using a graph-based approach to ensure manifold output.
