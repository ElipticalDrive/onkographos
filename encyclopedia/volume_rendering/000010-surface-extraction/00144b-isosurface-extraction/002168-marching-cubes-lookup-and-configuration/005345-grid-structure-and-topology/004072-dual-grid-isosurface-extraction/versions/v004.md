# Dual Grid Isosurface Extraction

Also called: Dual Grid Marching Cubes

## Overview
Dual Grid Isosurface Extraction is a method for extracting crack-free isosurfaces from Adaptive Mesh Refinement (AMR) data by constructing a dual grid where cell centers serve as vertices [S1]. It solves the "dangling node" problem inherent in standard Marching Cubes when applied to resampled vertex-centered AMR data, where mismatched interpolation at coarse-fine boundaries causes topological discontinuities [S1]. Unlike sibling methods that fix cracks by post-processing polygons or collapsing polylines, this approach eliminates dangling nodes structurally by leveraging the geometric gap between coarse and fine dual grids [S1, 10500-dual-grid-isosurface-extraction-with-stitch-cells].

## How it works
**Inputs and Outputs:**
*   **Input:** An AMR dataset consisting of multiple hierarchical levels of cell-centered scalar fields.
*   **Output:** A continuous, manifold triangle mesh representing the isosurface.

**Data Structures:**
1.  **Dual Grid Vertices:** A set of vertices $V_{dual}$ where each vertex corresponds to the center of a cell in the original AMR grid.
2.  **Scalar Values:** The scalar field value $V_c$ associated with each cell center $c$.
3.  **Lookup Tables:** The `edgeTable` and `triangleTable` from [Marching Cubes Lookup and Configuration](2518-marching-cubes-lookup-and-configuration.md) are used on the dual grid vertices.

**Steps:**
1.  **Construct Dual Grid:** Map each cell center of the AMR grid to a vertex in the dual grid. The scalar value at each dual vertex is the value of the original cell [S1].
2.  **Identify Geometric Gap:** Recognize that the dual grid shrinks by one cell in each axial direction relative to the original grid boundaries. This creates a physical gap between the coarse grid's dual vertices and the embedded fine grid's dual vertices [S1].
3.  **Extract Isosurface:** Apply the standard Marching Cubes algorithm to the dual grid vertices. Because the dual grid vertices at the boundary of a fine region do not share edges with the coarse grid vertices (due to the shrinkage/gap), there are no dangling nodes. The isosurface extraction proceeds independently on each level without creating topological inconsistencies at the boundaries [S1].
4.  **Stitching (Implicit/Explicit):** The gap ensures no cracks form from dangling nodes. However, to merge the separate meshes from different hierarchy levels into a single watertight mesh, a "stitch cell" tessellation scheme is required to fill the gap between the coarse and fine dual grids [10500-dual-grid-isosurface-extraction-with-stitch-cells]. This step is distinct from the core extraction but necessary for the final output.

**Pseudocode:**
```python
def dual_grid_extraction(AMR_levels):
    # 1. Construct dual grid vertices and values
    dual_vertices = []
    dual_values = []
    
    for level in AMR_levels:
        for cell in level.cells:
            # Cell center becomes dual vertex
            center = cell.get_center()
            dual_vertices.append(center)
            dual_values.append(cell.scalar_value)
            
    # 2. Marching Cubes on Dual Grid
    # Note: Standard MC assumes a regular grid. For AMR, 
    # the dual grid is irregular. The algorithm must handle 
    # non-uniform spacing or use a local cube approximation.
    # The key is that boundary vertices of fine levels 
    # do not connect to coarse level vertices.
    
    triangles = []
    for voxel in dual_grid_voxels:
        # Get 8 corner values from dual grid
        values = get_voxel_values(voxel, dual_vertices, dual_values)
        
        # Calculate case index
        case_index = 0
        for i in range(8):
            if values[i] > isovalue:
                case_index |= (1 << i)
                
        # Lookup triangles
        if case_index in triangle_table:
            tri_indices = triangle_table[case_index]
            for tri in tri_indices:
                if tri == -1:
                    break
                # Interpolate edge intersections
                p1 = interpolate_edge(tri[0], values)
                p2 = interpolate_edge(tri[1], values)
                p3 = interpolate_edge(tri[2], values)
                triangles.append([p1, p2, p3])
                
    # 3. Stitching
    # Fill gaps between coarse and fine dual grids
    stitch_mesh = create_stitch_cells(AMR_levels)
    
    return merge_meshes(triangles, stitch_mesh)
```

**Edge Cases and Pitfalls:**
*   **Irregular Grid:** The dual grid is not a regular Cartesian grid. Standard MC implementations assume uniform spacing. The implementation must adapt edge interpolation to the actual geometric positions of the cell centers [S1].
*   **Stitching Complexity:** The gap between levels must be filled with a valid tessellation. If the stitching is not handled, the output will be a collection of disconnected meshes [10500-dual-grid-isosurface-extraction-with-stitch-cells].

## Subtopics

### [Dual Grid Isosurface Extraction with Stitch Cells](10500-dual-grid-isosurface-extraction-with-stitch-cells.md)
Extends the dual grid method by explicitly tessellating the gap between coarse and fine levels using "stitch cells" to produce a single watertight mesh. Choose this when a continuous, manifold surface is required from AMR data.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of cells in the AMR hierarchy, plus the cost of stitching.
*   **Memory Complexity:** Proportional to the number of cell centers (dual vertices).
*   **Strengths:** Eliminates cracks caused by dangling nodes without complex post-processing or ambiguity resolution at boundaries.
*   **Limitations:** Requires a stitching step to merge levels. The irregular nature of the dual grid may complicate standard MC implementations that assume regular grids.
*   **When to use:** AMR data where crack-free surfaces are critical and vertex-centered resampling is undesirable.

## Background
The method was introduced to address the topological inconsistencies in isosurface extraction from AMR data. Standard Marching Cubes on resampled vertex-centered data creates dangling nodes at coarse-fine boundaries, leading to cracks [S1]. The dual grid approach, defined by cell centers, naturally avoids these nodes due to the geometric shrinkage of the dual grid relative to the original grid [S1].
