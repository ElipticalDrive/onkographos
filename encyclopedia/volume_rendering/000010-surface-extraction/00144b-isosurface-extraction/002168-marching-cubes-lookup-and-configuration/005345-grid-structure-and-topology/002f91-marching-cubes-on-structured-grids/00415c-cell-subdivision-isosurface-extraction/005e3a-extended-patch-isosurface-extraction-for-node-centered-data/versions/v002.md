# Extended Patch Isosurface Extraction for Node-Centered Data

Also called: Extended Patch Pyramid Decomposition, Fang et al. (2004) method

## Overview
Extended Patch Isosurface Extraction is a method for extracting crack-free isosurfaces from node-centered Adaptive Mesh Refinement (AMR) data [S1, S2, unofficial]. It solves the problem of geometric discontinuities (cracks) at level boundaries by preserving the original patch structure and cell identity, enabling a user to determine to what particular patch cell a triangle of an isosurface belongs [S1, S2, unofficial]. The approach extends refined patches to handle dangling nodes and decomposes coarse cells at refinement boundaries into pyramids, ensuring that marching cubes applied to the resulting cell types produces no cracks [S1, S2, unofficial].

## How it works
**Inputs:**
- Node-centered scalar field values on a hierarchical AMR grid [S1, S2, unofficial].
- Patch hierarchy structure defining refinement levels and boundaries [S1, S2, unofficial].

**Outputs:**
- A set of triangles forming the isosurface [S1, S2, unofficial].
- Metadata linking each triangle to its source patch and cell identity [S1, S2, unofficial].

**Data Structures:**
The method operates on the existing AMR patch structure [S1, S2, unofficial]. No new global grid is created [G]. Instead, the geometry is redefined locally at boundaries:
- **Extended Patches:** Refined patches are logically extended to cover regions where dangling nodes exist, ensuring consistent value assignment [S1, S2, unofficial].
- **Pyramid Cells:** Coarse-level cells at the boundary to a finer level are decomposed into pyramids [S1, S2, unofficial]. Each pyramid connects the coarse cell center to the vertices of a subdivided face facet [S1, S2, unofficial].

**Steps:**

1. **Extend Refined Patches:**
   Extend the refined patches until it is possible to assign values to dangling nodes that are consistent with interpolation results in the coarser level [S1, S2, unofficial]. This ensures that the scalar field is well-defined at all node locations required for marching cubes [G].

2. **Decompose Coarse Cells at Boundaries:**
   For every coarse-level cell that is adjacent to a finer level, decompose the cell into a set of pyramids [S1, S2, unofficial].
   - Identify the boundary faces of the coarse cell that touch the finer level [G].
   - For each such face, subdivide it into facets corresponding to the finer grid resolution [G].
   - Create a separate pyramid for each facet of a subdivided face [S1, S2, unofficial].
   - Each pyramid connects the coarse cell center to the vertices of its corresponding facet [S1, S2, unofficial].

3. **Extract Isosurface:**
   Apply marching cubes to the resulting cell types using appropriate case tables for these new cell types [S1, S2, unofficial]. The decomposition ensures that marching cubes will not produce cracks in the extracted isosurface [S1, S2, unofficial].

            # Decompose coarse cells at boundary into pyramids

            for pyramid in pyramids:
                tri_list, pid = marching_cubes_pyramid(pyramid, isovalue)

## Subtopics

### Cell Subdivision Isosurface Extraction
The parent method that eliminates non-linear hanging nodes by subdividing boundary cells into pyramids [10502-cell-subdivision-isosurface-extraction.md]. Extended Patch Isosurface Extraction builds on this by preserving patch identity and extending patches for node-centered data [S1, S2, unofficial].

### Marching Cubes on Structured Grids
The base algorithm used for isosurface extraction within the cells (including pyramids) created by this method [S1, S2, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources. [G]
- **Memory Complexity:** Not given in the sources. [G]
- **Strengths:** Preserves original patch structure and cell identity, allowing users to determine which patch cell generated each triangle [S1, S2, unofficial]. Ensures crack-free isosurfaces at level boundaries [S1, S2, unofficial].
- **Limitations:** Requires implementation of specific case tables for pyramid cells [S1, S2, unofficial]. Relies on consistent interpolation for dangling node values [G].
- **When to Use:** When preserving patch identity is important and the data is node-centered [S1, S2, unofficial].
- **When Not to Use:** When cell-centered data is used, or when patch identity is not required [G].

## Background
Fang et al. (2004) presented this alternate isosurface extraction approach for node-centered AMR data [S1, S2, unofficial]. The method was developed to address the limitations of previous approaches that did not preserve cell identity or required complex handling of hanging nodes [G]. It is used in the context of volume rendering of AMR data, where maintaining the association between geometry and source data is valuable for analysis [S1, S2, unofficial].
