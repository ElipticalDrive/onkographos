# Cell Subdivision Isosurface Extraction

Also called: Keep Grid, Second Approach

## Overview
Cell Subdivision Isosurface Extraction is a method for extracting isosurfaces from Adaptive Mesh Refinement (AMR) data that retains the original identity of cells (vertex/node-centered data) to support debugging and patch tracking [S1, S2, unofficial]. Unlike dual-grid approaches that stitch cells together, this method eliminates non-linear hanging nodes by subdividing boundary cells into pyramids, allowing standard isosurface techniques (like Marching Cubes) to be applied directly to the subdivided geometry [S1, unofficial]. It is chosen when preserving cell-to-triangle mapping is critical, at the cost of increased geometric complexity due to pyramid decomposition [S1, S2, unofficial].

## How it works
**Inputs:**
- AMR dataset with vertex/node-centered scalar values.
- Hierarchy structure defining refinement levels and patch boundaries.
- Isosurface value $V_{iso}$.

**Outputs:**
- Triangle mesh representing the isosurface.
- Metadata linking triangles to original source cells/patches.

**Data Structures:**
- **Cell:** Defined by its vertices and center point.
- **Pyramid:** A polyhedral cell with a quadrilateral base (or multiple facets) and a common apex (the cell center).
- **Hanging Node:** A vertex on a coarse cell boundary that lies on an edge or face of a finer neighbor.

**Steps:**

1. **2D Face Subdivision (Edge Hanging Nodes):**
   For each coarse cell face adjacent to a finer level:
   - Subdivide the lower-resolution face to match the topology of the higher-resolution face.
   - Calculate values at newly created hanging nodes using linear interpolation from the coarse cell's vertex values.
   - This eliminates hanging nodes along edges [S1, unofficial].

2. **3D Cell Subdivision (Non-linear Hanging Nodes):**
   For each coarse cell at the boundary of a finer level:
   - Decompose the coarse cell into a set of pyramids.
   - The common apex for all pyramids is the cell center.
   - The base of each pyramid corresponds to a facet of the subdivided boundary faces.
   - For each facet of a subdivided face (a face at the boundary to a finer level), create a separate pyramid [S2, unofficial].
   - This ensures that the geometry is conformal and eliminates non-linear hanging nodes [S1, unofficial].

3. **Isosurface Extraction:**
   - Apply standard isosurface extraction algorithms (e.g., Marching Cubes) to each pyramid cell independently.
   - Since the pyramids are conformal and share vertices with the finer grid, no cracks are produced at the boundaries [S2, unofficial].

**Formulas:**
- Linear interpolation for hanging node value $V_h$ on an edge between vertices $A$ and $B$ with values $V_A$ and $V_B$, where the hanging node is at fraction $t$ from $A$:
  $$ V_h = (1 - t)V_A + tV_B $$
  where $t$ is determined by the geometric position of the hanging node relative to the coarse edge [S1, unofficial].

**Parameters:**
- Isosurface value $V_{iso}$: Scene-dependent.
- Interpolation method: Linear (default) [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** Linear interpolation may introduce slight inaccuracies in the isosurface position at hanging nodes, potentially causing minor visual artifacts if the scalar field is highly non-linear [S1, unofficial].
- **Degenerate Pyramids:** If a coarse cell has no boundary with a finer level, it is not subdivided. If a boundary face is fully covered by finer cells, the entire coarse cell is decomposed into pyramids based on the finer face topology [S2, unofficial].
- **Cracks:** The method explicitly avoids cracks by ensuring that each facet of a subdivided face generates a separate pyramid, maintaining conformality [S2, unofficial].

**Pseudocode:**
```python
def extract_isosurface_amr_keep_grid(cells, isovalue):
    """
    Extract isosurface from AMR data using Cell Subdivision (Keep Grid).
    """
    triangles = []
    
    # Step 1 & 2: Subdivide cells and create pyramids
    pyramids = []
    for cell in cells:
        if cell.is_boundary_to_finer_level():
            # Decompose coarse cell into pyramids
            # Apex is cell center
            apex = cell.center
            
            # Get boundary faces that touch finer levels
            boundary_faces = cell.get_boundary_faces_touching_finer()
            
            for face in boundary_faces:
                # Subdivide face if necessary to match finer resolution
                subdivided_face = subdivided_face_to_match_finer(face)
                
                # Create a pyramid for each facet of the subdivided face
                for facet in subdivided_face.facets:
                    pyramid = Pyramid(apex=apex, base=facet)
                    pyramids.append(pyramid)
        else:
            # Cell is not at boundary; treat as standard hexahedron or decompose into tetrahedra if needed
            # For simplicity, assume standard Marching Cubes on hexahedron or decomposition
            pyramids.append(cell.to_pyramids_or_tets())

    # Step 3: Apply standard isosurface extraction on pyramids
    for pyramid in pyramids:
        # Extract isosurface from pyramid
        # Note: Standard Marching Cubes is defined for hexahedra.
        # For pyramids, a specialized case table or decomposition into tetrahedra is required.
        # Here we assume a generic isosurface extractor for arbitrary polyhedra or tetrahedral decomposition.
        cell_triangles = extract_isosurface_from_polyhedron(pyramid, isovalue)
        triangles.extend(cell_triangles)
        
        # Store mapping to original cell for debugging
        for tri in cell_triangles:
            tri.source_cell_id = pyramid.source_cell_id
            
    return triangles

def subdivided_face_to_match_finer(face):
    """
    Subdivide a coarse face to match the topology of the adjacent finer face.
    Returns a list of facets (quadrilaterals or triangles) that cover the original face area.
    """
    # Identify hanging nodes on the face edges
    hanging_nodes = face.get_hanging_nodes()
    
    # Interpolate values at hanging nodes
    for node in hanging_nodes:
        node.value = linear_interpolate(node.edge, node.position)
        
    # Split the face geometry based on hanging node positions
    # This creates a conformal mesh of the face
    facets = split_face_geometry(face, hanging_nodes)
    return FacetContainer(facets)
```

## Subtopics

### Extended Patch Isosurface Extraction for Node-Centered Data
An isosurface extraction approach for node-centered AMR data that preserves original patch structure and cell identity by extending refined patches and decomposing coarse cells at boundaries [S2, unofficial]. It extends refined patches until it is possible to assign values to dangling nodes that are consistent with interpolation results in the coarser level [S2, unofficial]. It decomposes coarse-level cells at the boundary to a finer level into a set of pyramids that connect the cell center with all boundary faces [S2, unofficial]. For each facet of a subdivided face (a face at the boundary to a finer level), a separate pyramid is created, ensuring that marching cubes does not produce cracks [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Depends on the number of boundary cells and the depth of refinement. The subdivision step adds overhead proportional to the number of hanging nodes.
- **Memory Complexity:** Increases due to the creation of pyramid cells. The number of cells increases as coarse cells are decomposed.
- **Measured Performance:** Tested on star cluster formation simulation. First level: 44,332 cells, 10,456 triangles, 2.30 seconds. Multiple levels: 303,759 cells, 77,029 triangles, 7.73 seconds [S1, unofficial].
- **Strengths:** Preserves cell identity for debugging; eliminates cracks without complex stitching logic; compatible with standard isosurface algorithms after subdivision.
- **Limitations:** Increased geometric complexity; linear interpolation may reduce accuracy at hanging nodes; requires handling of non-standard cell types (pyramids) in the isosurface extractor.
- **When to use:** When debugging or tracking triangles back to source patches is required.
- **When not to use:** When performance is critical and cell identity is not needed; consider Flying Edges or Uniform Marching Cubes with Snapping instead.

## Background
Originated in the context of AMR visualization, specifically as the "Second Approach" or "Keep Grid" method [S1, unofficial]. It was developed to address the limitations of dual-grid approaches that lost cell identity [S1, unofficial]. The method builds on the idea of eliminating hanging nodes through subdivision, a technique also seen in other AMR visualization tools [S1, S2, unofficial]. It is used in tools like VisIt and ParaView for AMR data visualization [S1, unofficial].
