# Cell Subdivision Isosurface Extraction

Also called: Keep Grid, Second Approach

## Overview
Cell Subdivision Isosurface Extraction is a method for extracting isosurfaces from Adaptive Mesh Refinement (AMR) data that retains the original identity of cells (vertex/node-centered data) to support debugging and patch tracking [S1, unofficial]. Unlike dual-grid approaches that stitch cells together, this method eliminates non-linear hanging nodes by subdividing boundary cells into pyramids, allowing standard isosurface techniques to be applied directly to the subdivided geometry [S1, unofficial]. It is chosen when preserving cell-to-triangle mapping is critical, at the cost of increased geometric complexity due to pyramid decomposition [S1, unofficial].

## How it works
**Inputs:**
- AMR dataset with vertex/node-centered scalar values [S1, unofficial].
- Hierarchy structure defining refinement levels and patch boundaries [S1, unofficial].
- Isosurface value $V_{iso}$ [S1, unofficial].

**Outputs:**
- Triangle mesh representing the isosurface [S1, unofficial].
- Metadata linking triangles to original source cells/patches [S1, unofficial].

**Data Structures:**
- **Cell:** Defined by its vertices, center point, and scalar values.
- **Pyramid:** A polyhedral cell with a quadrilateral base (or multiple facets) and a common apex (the cell center).
- **Hanging Node:** A vertex on a coarse cell boundary that lies on an edge or face of a finer neighbor [S1, G, unofficial].

**Steps:**

1. **2D Face Subdivision (Edge Hanging Nodes):**
   For each coarse cell face adjacent to a finer level:
   - Subdivide the lower-resolution face to match the topology of the higher-resolution face, eliminating hanging nodes along edges [S1, unofficial].
   - Calculate values at newly created hanging nodes using linear interpolation from the coarse cell's vertex values [S1, unofficial].

2. **3D Cell Subdivision (Non-linear Hanging Nodes):**
   For each coarse cell at the boundary of a finer level:
   - Decompose the coarse cell into a set of pyramids with a common apex point (the cell center) [S1, unofficial].
   - The base of each pyramid corresponds to a facet of the subdivided boundary faces [S1, G, unofficial].
   - This ensures that the geometry is conformal and eliminates non-linear hanging nodes [S1, unofficial].

3. **Isosurface Extraction:**
   - Apply standard isosurface extraction algorithms to each pyramid cell independently [S1, unofficial].
   - Since the pyramids are conformal and share vertices with the finer grid, no cracks are produced at the boundaries [S1, G, unofficial].

**Formulas:**
- Linear interpolation for hanging node value $V_h$ on an edge between vertices $A$ and $B$ with values $V_A$ and $V_B$, where the hanging node is at fraction $t$ from $A$:
  $$ V_h = (1 - t)V_A + tV_B $$
  where $t$ is the relative geometric distance along the edge [G].

**Parameters:**
- Isosurface value $V_{iso}$: Scene-dependent [S1, unofficial].
- Interpolation method: Linear [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** Linear interpolation may introduce slight inaccuracies in the isosurface position at hanging nodes, potentially causing minor visual artifacts if the scalar field is highly non-linear [S1, G, unofficial].
- **Degenerate Pyramids:** If a coarse cell has no boundary with a finer level, it is not subdivided [S1, G, unofficial].
- **Cracks:** The method explicitly avoids cracks by ensuring that each facet of a subdivided face generates a separate pyramid, maintaining conformality [S1, G, unofficial].

**Pseudocode:**
```python
def extract_isosurface_amr_keep_grid(cells, isovalue):
    """
    Extract isosurface from AMR data using Cell Subdivision (Keep Grid).
    """
    triangles = []
    for cell in cells:
        if cell.is_boundary_to_finer_level():
            subdivided_faces = []
            for face in cell.boundary_faces:
                hanging_nodes = face.find_hanging_nodes()
                for node in hanging_nodes:
                    t = node['pos'] / node['edge_length']
                    node['value'] = (1.0 - t) * node['edge_vertex_A']['value'] + t * node['edge_vertex_B']['value']
                subdivided_faces.append(face.subdivide(hanging_nodes))

            for face in subdivided_faces:
                for facet in face.facets:
                    base_verts = facet['vertices']
                    base_vals = [v['value'] for v in base_verts]
                    pyramid = {'apex': cell.center, 'base_vertices': base_verts, 'base_values': base_vals}
                    cell_triangles = extract_isosurface_from_pyramid(pyramid, isovalue)
                    for tri in cell_triangles:
                        tri['source_cell_id'] = cell.id
                    triangles.extend(cell_triangles)
        else:
            cell_triangles = extract_isosurface_from_hexahedron(cell, isovalue)
            for tri in cell_triangles:
                tri['source_cell_id'] = cell.id
            triangles.extend(cell_triangles)
    return triangles

def extract_isosurface_from_pyramid(pyramid, isovalue):
    """Decompose pyramid into tetrahedra and extract isosurface."""
    tets = []
    n = len(pyramid['base_vertices'])
    apex = pyramid['apex']
    for i in range(n):
        v0 = pyramid['base_vertices'][i]
        v1 = pyramid['base_vertices'][(i + 1) % n]
        v_ref = pyramid['base_vertices'][0]
        tets.append({
            'verts': [apex, v0, v1, v_ref],
            'values': [apex['value'], v0['value'], v1['value'], v_ref['value']]
        })
    all_triangles = []
    for tet in tets:
        all_triangles.extend(extract_isosurface_from_tetrahedron(tet, isovalue))
    return all_triangles
```

## Subtopics

### [Extended Patch Isosurface Extraction for Node-Centered Data](17566-extended-patch-isosurface-extraction-for-node-centered-data.md)
An approach for extracting crack-free isosurfaces from node-centered AMR data by preserving patch structure and cell identity. It sets itself apart by explicitly decomposing coarse cells at refinement boundaries into pyramids, allowing standard marching cubes to run without t-junctions. Choose it when debugging or tracking triangles to source patches is required. [Extended Patch Isosurface Extraction for Node-Centered Data](17566-extended-patch-isosurface-extraction-for-node-centered-data.md)

## Operating characteristics
- **Time Complexity:** Depends on the number of boundary cells and the depth of refinement. The subdivision step adds overhead proportional to the number of hanging nodes [G].
- **Memory Complexity:** Increases due to the creation of pyramid cells. The number of cells increases as coarse cells are decomposed [G].
- **Measured Performance:** Tested on star cluster formation simulation. First level: 44,332 cells, 10,456 triangles, 2.30 seconds. Multiple levels: 303,759 cells, 77,029 triangles, 7.73 seconds [S1, unofficial].
- **Strengths:** Preserves cell identity for debugging; eliminates cracks without complex stitching logic; compatible with standard isosurface algorithms after subdivision [S1, unofficial].
- **Limitations:** Increased geometric complexity; linear interpolation may reduce accuracy at hanging nodes; requires handling of non-standard cell types (pyramids) in the isosurface extractor [G].
- **When to use:** When debugging or tracking triangles back to source patches is required [S1, unofficial].
- **When not to use:** When performance is critical and cell identity is not needed; consider Flying Edges or Uniform Marching Cubes with Snapping instead [G].

## Background
Originated in the context of AMR visualization, specifically as the "Second Approach" or "Keep Grid" method [S1, unofficial]. It was developed to address the limitations of dual-grid approaches that lost cell identity [S1, unofficial]. The method builds on the idea of eliminating hanging nodes through subdivision, a technique also seen in other AMR visualization tools [S1, unofficial].
