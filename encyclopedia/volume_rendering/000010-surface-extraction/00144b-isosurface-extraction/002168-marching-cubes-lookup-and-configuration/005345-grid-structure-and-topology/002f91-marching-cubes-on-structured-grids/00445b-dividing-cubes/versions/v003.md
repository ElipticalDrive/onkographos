# Dividing Cubes
## Overview
Dividing Cubes is an isosurface extraction method that replaces the triangular mesh primitives of Marching Cubes with 3D points [S3, unofficial]. It solves the problem of excessive triangle counts and the subsequent scan-conversion overhead by adaptively subdividing cells intersected by the surface until each subcell projects onto a single pixel [S3, unofficial][S4, unofficial].

## How it works
**Inputs:**
*   A structured volume dataset $V$ with scalar values [G].
*   An isovalue $I$ defining the surface [G].
*   Viewing direction and projection parameters to determine pixel coverage [S3, unofficial].

**Outputs:**
*   A set of 3D points representing the isosurface, each associated with an intensity or color value for rendering [S2, unofficial].

**Data Structures:**
*   **Subcell List:** A list of points $(x, y, z)$ and their corresponding scalar/intensity values [G].

**Steps:**
1.  **Identify Intersected Cells:** Scan the volume grid to identify all voxels (cubes) where the isosurface passes through [S4, unofficial].
2.  **Subdivide Intersected Cells:** For each identified voxel, recursively subdivide it into smaller subcells [S4, unofficial].
3.  **Determine Subdivision Depth:** Select the subdivision depth such that the resulting subcells are small enough to project onto exactly one pixel on the image plane [S4, unofficial].
4.  **Render Subcells as Points:** Project the calculated intensity for each subcell onto the viewing plane to form a gradient-shaded representation [S2, unofficial].

**Pseudocode:**
```python
def dividing_cubes(volume, isovalue, camera_params, image_width, image_height):
    points = []
    # [G] Standard volume traversal
    for x in range(volume.width - 1):
        for y in range(volume.height - 1):
            for z in range(volume.depth - 1):
                voxel = volume.get_cell(x, y, z)
                # [G] Check if isovalue crosses the voxel by comparing with vertex values
                if isovalue_exists_in_voxel(voxel, isovalue):
                    # [G] Compute depth so subcell projects to one pixel
                    depth = compute_subdivision_depth(voxel, camera_params, image_width, image_height)
                    subcells = subdivide_voxel(voxel, depth)
                    for subcell in subcells:
                        # [G] Linear interpolation to find intersection point on subcell edge
                        point = estimate_intersection(subcell, isovalue)
                        # [G] Intensity from subcell scalar value
                        intensity = subcell.scalar
                        points.append((point, intensity))
    return points
```

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** Voxels on the boundary of the volume must be handled correctly to avoid out-of-bounds access during subdivision and intersection estimation [G].

## Operating characteristics
*   **Time Complexity:** The complexity depends on the number of intersected voxels and the required subdivision depth [S2, unofficial].
*   **Strengths:** Eliminates scan conversion overhead; adapts to viewing angle and resolution; produces smooth, gradient-shaded images [S2, unofficial][S3, unofficial].
*   **Limitations:** Does not produce a connected mesh [S3, unofficial].
*   **When to Use:** When rendering large datasets for visualization where a connected mesh is not required, and performance of scan conversion is a bottleneck [S2, unofficial][S3, unofficial].

## Background
Dividing Cubes was developed as a variation of the Marching Cubes algorithm to address the computational cost of scan conversion when dealing with large numbers of small triangles [S1, unofficial][S2, unofficial]. It was introduced in the context of volume visualization, where the goal is to efficiently render complex surfaces from volumetric data [S3, unofficial].
