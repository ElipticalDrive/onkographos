# Marching Cubes Edge Intersection and Topology Test

Also called: Marching Cubes Case 1-11 Logic, testInterior

## Overview
This method resolves topological ambiguities for edge indices 0 through 10 (cases 1–11) in Marching Cubes by computing a bitmask from scalar field values at intersection points on an adjacent face [S1, unofficial]. It replaces a static lookup table entry with a runtime bitwise test and arithmetic evaluation [S1, unofficial].

## How it works
**Inputs and Outputs:**
- `cube`: An array of 8 scalar field values corresponding to the 8 vertices of a voxel [S1, unofficial].
- `edgeIdx`: The index of the edge being processed (0–10) [S1, unofficial].
- `alongEdgeIdx`: An integer identifier for the edge direction or topology context [S1, unofficial].
- **Output**: An integer representing the triangulation choice or edge orientation [S1, unofficial].

**Data Structures:**
- `cube`: `float[8]` or `double[8]` [S1, unofficial].
- `test`: `int`, bitmask accumulator [S1, unofficial].

**Numbered Steps:**
1. **Calculate Intersection Parameters and Points:** For the given `edgeIdx`, compute the interpolation parameter $t$ and the values $A_t, B_t, C_t, D_t$ using the formulas below [S1, unofficial].
2. **Compute Test Bitmask:** Initialize `test = 0` and accumulate powers of two based on the non-negativity of $A_t, B_t, C_t, D_t$ [S1, unofficial].
3. **Return Result:** Evaluate `test` against the conditional branches to return the signed `alongEdgeIdx` or the cross-product term scaled by `alongEdgeIdx` [S1, unofficial].

**Formulas for Edge Indices 0–10:**
- **Edge 0:** $t = \frac{cube[1]}{cube[1] - cube[0]}$; $A_t = 0$; $B_t = cube[0] + (cube[1] - cube[0]) \cdot t$; $C_t = cube[4] + (cube[5] - cube[4]) \cdot t$; $D_t = cube[5] + (cube[6] - cube[5]) \cdot t$ [S1, unofficial].
- **Edge 1:** $t = \frac{cube[2]}{cube[2] - cube[3]}$; $A_t = 0$; $B_t = cube[0] + (cube[1] - cube[0]) \cdot t$; $C_t = cube[5] + (cube[4] - cube[5]) \cdot t$; $D_t = cube[6] + (cube[7] - cube[6]) \cdot t$ [S1, unofficial].
- **Edge 2:** $t = \frac{cube[3]}{cube[3] - cube[0]}$; $A_t = 0$; $B_t = cube[1] + (cube[2] - cube[1]) \cdot t$; $C_t = cube[6] + (cube[5] - cube[6]) \cdot t$; $D_t = cube[7] + (cube[4] - cube[7]) \cdot t$ [S1, unofficial].
- **Edge 3:** $t = \frac{cube[4]}{cube[4] - cube[5]}$; $A_t = 0$; $B_t = cube[7] + (cube[6] - cube[7]) \cdot t$; $C_t = cube[3] + (cube[2] - cube[3]) \cdot t$; $D_t = cube[0] + (cube[1] - cube[0]) \cdot t$ [S1, unofficial].
- **Edge 4:** $t = \frac{cube[5]}{cube[5] - cube[6]}$; $A_t = 0$; $B_t = cube[4] + (cube[7] - cube[4]) \cdot t$; $C_t = cube[0] + (cube[3] - cube[0]) \cdot t$; $D_t = cube[1] + (cube[2] - cube[1]) \cdot t$ [S1, unofficial].
- **Edge 5:** $t = \frac{cube[6]}{cube[6] - cube[7]}$; $A_t = 0$; $B_t = cube[5] + (cube[4] - cube[5]) \cdot t$; $C_t = cube[1] + (cube[0] - cube[1]) \cdot t$; $D_t = cube[2] + (cube[3] - cube[2]) \cdot t$ [S1, unofficial].
- **Edge 6:** $t = \frac{cube[7]}{cube[7] - cube[4]}$; $A_t = 0$; $B_t = cube[6] + (cube[5] - cube[6]) \cdot t$; $C_t = cube[2] + (cube[1] - cube[2]) \cdot t$; $D_t = cube[3] + (cube[0] - cube[3]) \cdot t$ [S1, unofficial].
- **Edge 7:** $t = \frac{cube[0]}{cube[0] - cube[4]}$; $A_t = 0$; $B_t = cube[3] + (cube[7] - cube[3]) \cdot t$; $C_t = cube[2] + (cube[6] - cube[2]) \cdot t$; $D_t = cube[1] + (cube[5] - cube[1]) \cdot t$ [S1, unofficial].
- **Edge 8:** $t = \frac{cube[1]}{cube[1] - cube[5]}$; $A_t = 0$; $B_t = cube[0] + (cube[4] - cube[0]) \cdot t$; $C_t = cube[3] + (cube[7] - cube[3]) \cdot t$; $D_t = cube[2] + (cube[6] - cube[2]) \cdot t$ [S1, unofficial].
- **Edge 9:** $t = \frac{cube[2]}{cube[2] - cube[6]}$; $A_t = 0$; $B_t = cube[1] + (cube[5] - cube[1]) \cdot t$; $C_t = cube[0] + (cube[4] - cube[0]) \cdot t$; $D_t = cube[3] + (cube[7] - cube[3]) \cdot t$ [S1, unofficial].
- **Edge 10:** $t = \frac{cube[3]}{cube[3] - cube[7]}$; $A_t = 0$; $B_t = cube[2] + (cube[6] - cube[2]) \cdot t$; $C_t = cube[1] + (cube[5] - cube[1]) \cdot t$; $D_t = cube[0] + (cube[4] - cube[0]) \cdot t$ [S1, unofficial].

**Pseudocode:**
```python
def test_interior(cube, edge_idx, along_edge_idx):
    if edge_idx < 0 or edge_idx > 10:
        raise ValueError(f"testInterior got wrong edgeIdx: {edge_idx}")
    
    if edge_idx == 0:
        t = cube[1] / (cube[1] - cube[0])
        At = 0
        Bt = cube[0] + (cube[1] - cube[0]) * t
        Ct = cube[4] + (cube[5] - cube[4]) * t
        Dt = cube[5] + (cube[6] - cube[5]) * t
    elif edge_idx == 1:
        t = cube[2] / (cube[2] - cube[3])
        At = 0
        Bt = cube[0] + (cube[1] - cube[0]) * t
        Ct = cube[5] + (cube[4] - cube[5]) * t
        Dt = cube[6] + (cube[7] - cube[6]) * t
    elif edge_idx == 2:
        t = cube[3] / (cube[3] - cube[0])
        At = 0
        Bt = cube[1] + (cube[2] - cube[1]) * t
        Ct = cube[6] + (cube[5] - cube[6]) * t
        Dt = cube[7] + (cube[4] - cube[7]) * t
    elif edge_idx == 3:
        t = cube[4] / (cube[4] - cube[5])
        At = 0
        Bt = cube[7] + (cube[6] - cube[7]) * t
        Ct = cube[3] + (cube[2] - cube[3]) * t
        Dt = cube[0] + (cube[1] - cube[0]) * t
    elif edge_idx == 4:
        t = cube[5] / (cube[5] - cube[6])
        At = 0
        Bt = cube[4] + (cube[7] - cube[4]) * t
        Ct = cube[0] + (cube[3] - cube[0]) * t
        Dt = cube[1] + (cube[2] - cube[1]) * t
    elif edge_idx == 5:
        t = cube[6] / (cube[6] - cube[7])
        At = 0
        Bt = cube[5] + (cube[4] - cube[5]) * t
        Ct = cube[1] + (cube[0] - cube[1]) * t
        Dt = cube[2] + (cube[3] - cube[2]) * t
    elif edge_idx == 6:
        t = cube[7] / (cube[7] - cube[4])
        At = 0
        Bt = cube[6] + (cube[5] - cube[6]) * t
        Ct = cube[2] + (cube[1] - cube[2]) * t
        Dt = cube[3] + (cube[0] - cube[3]) * t
    elif edge_idx == 7:
        t = cube[0] / (cube[0] - cube[4])
        At = 0
        Bt = cube[3] + (cube[7] - cube[3]) * t
        Ct = cube[2] + (cube[6] - cube[2]) * t
        Dt = cube[1] + (cube[5] - cube[1]) * t
    elif edge_idx == 8:
        t = cube[1] / (cube[1] - cube[5])
        At = 0
        Bt = cube[0] + (cube[4] - cube[0]) * t
        Ct = cube[3] + (cube[7] - cube[3]) * t
        Dt = cube[2] + (cube[6] - cube[2]) * t
    elif edge_idx == 9:
        t = cube[2] / (cube[2] - cube[6])
        At = 0
        Bt = cube[1] + (cube[5] - cube[1]) * t
        Ct = cube[0] + (cube[4] - cube[0]) * t
        Dt = cube[3] + (cube[7] - cube[3]) * t
    elif edge_idx == 10:
        t = cube[3] / (cube[3] - cube[7])
        At = 0
        Bt = cube[2] + (cube[6] - cube[2]) * t
        Ct = cube[1] + (cube[5] - cube[1]) * t
        Dt = cube[0] + (cube[4] - cube[0]) * t
    
    test = 0
    if At >= 0:
        test += 1
    if Bt >= 0:
        test += 2
    if Ct >= 0:
        test += 4
    if Dt >= 0:
        test += 8
        
    if test <= 4:
        return -along_edge_idx
    elif test == 5:
        return (At * Ct - Bt * Dt) * along_edge_idx
    elif test == 6:
        return -along_edge_idx
    elif test == 7:
        return along_edge_idx
    elif test <= 9:
        return -along_edge_idx
    elif test == 10:
        return -(At * Ct - Bt * Dt) * along_edge_idx
    elif test == 11:
        return along_edge_idx
    elif test == 12:
        return -along_edge_idx
    else:
        return along_edge_idx
```

**Parameters:**
- `cube`: Array of 8 floats [S1, unofficial].
- `edge_idx`: Integer 0–10 [S1, unofficial].
- `along_edge_idx`: Integer, context-dependent [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Division by Zero:** If `cube[i] - cube[j] == 0`, the calculation of $t$ produces infinity or NaN [G].
- **Invalid Edge Index:** The source asserts failure if `edgeIdx` is not 0–10 [S1, unofficial].
- **Zero Values:** If any `cube` value is exactly 0, the intersection lies at the vertex [G].

## Subtopics

### [Marching Cubes Edge Processing Logic](3702-marching-cubes-edge-processing-logic.md)
This method generates two triangles for a voxel edge based on sign changes between the corners of four adjacent nodes, using `processEdgeMask` to identify the specific edge. It differs from standard Marching Cubes by relying on a directional mask and sign-change detection rather than a full 256-case lookup table, and is typically used in dual contouring or octree-based surface extraction where edge topology is managed via node indices.

## Operating characteristics
- **Time Complexity:** $O(1)$ per edge, as it involves a fixed number of arithmetic operations and comparisons [S1, unofficial].
- **Memory Complexity:** $O(1)$, requiring only a few temporary variables [S1, unofficial].
- **Strengths:** Avoids the memory overhead of a 256-entry lookup table and provides deterministic resolution for ambiguous cases [S1, unofficial].
- **Limitations:** The logic is specific to the implementation in [S1, unofficial] and does not cover edge index 11 [S1, unofficial].
- **When to use:** When implementing the specific runtime bitmask test variant described in [S1, unofficial] [S1, unofficial].
- **When not to use:** When using a standard 256-case lookup table or when edge index 11 requires processing [S1, unofficial].

## Background
This method originates from an implementation in the `upupming/marching-cubes` repository [S1, unofficial]. It represents a specific approach to resolving topological ambiguities by using a bitwise test on interpolated values rather than a precomputed lookup table [S1, unofficial]. Custodio et al. (2013) later proposed a correction to Chernyaev's interior ambiguity test to resolve failures in case 13 [S2].
