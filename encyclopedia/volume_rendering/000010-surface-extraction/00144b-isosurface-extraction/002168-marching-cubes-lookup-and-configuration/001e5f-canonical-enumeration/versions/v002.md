# Canonical Enumeration

Also called: Linear Scan, Sequential Enumeration

## Overview
Canonical Enumeration is the fundamental baseline algorithm for isosurface extraction that sequentially visits every cell in a discretized volume to identify those containing the surface. It solves the cell extraction problem by checking if a target isovalue lies within the scalar range of each cell, serving as the reference point against which accelerated hierarchical methods are measured. Unlike [Isosurface Propagation from Seed Cells](6942-isosurface-propagation-from-seed-cells.md), which skips empty regions using hierarchical structures, Canonical Enumeration guarantees no cell is missed but processes all cells regardless of occupancy.

## How it works
**Inputs and Outputs:**
*   **Input:** A volume data structure $V$ defined on a regular grid, where each cell $C_{i,j,k}$ has scalar values $V_{i,j,k}$ at its vertices. A scalar isovalue $t \in \mathbb{R}$.
*   **Output:** A list of "active" cells $C_{i,j,k}$ where the isosurface intersects the cell.

**Data Structures:**
*   **Volume Data:** A 3D array or linearized buffer storing vertex scalar values. No auxiliary structures (like octrees or bounding volume hierarchies) are required [S1, unofficial].
*   **Variables:** Temporary variables for storing $v_{min}$, $v_{max}$, and the current cell index.

**Steps:**
1.  Iterate through every cell $C_{i,j,k}$ in the volume grid.
2.  For each cell, determine the minimum scalar value $v_{min}$ and maximum scalar value $v_{max}$ among its vertices.
3.  Evaluate the condition $t \in [v_{min}, v_{max})$.
4.  If the condition is true, mark $C_{i,j,k}$ as an active cell and proceed to surface triangulation (e.g., Marching Cubes). If false, skip the cell.

**Formulas:**
The range of the interpolation function $\hat{f}$ in a cell is defined as:
$$ \hat{f}(C_{i,j,k}) = [v_{min}, v_{max}] $$
where:
$$ v_{min} = \min(V_{i,j,k}) $$
$$ v_{max} = \max(V_{i,j,k}) $$

The cell extraction condition is:
$$ t \in [v_{min}, v_{max}) $$

**Parameters:**
*   **Isovalue ($t$):** The threshold scalar value defining the surface.
*   **Grid Dimensions:** $N_x, N_y, N_z$ defining the total number of cells $n$.

**Edge Cases and Pitfalls:**
*   **Interval Boundary:** The sources specify using the half-open interval $[v_{min}, v_{max})$ rather than the closed interval $[v_{min}, v_{max}]$. This choice forces an extraction algorithm to report specific boundary conditions consistently, avoiding ambiguity when $t$ exactly equals $v_{max}$ of one cell and $v_{min}$ of an adjacent cell [S1, unofficial].
*   **Precision:** Floating-point comparisons for $t \ge v_{min}$ and $t < v_{max}$ must handle precision errors near the boundaries.
*   **Degenerate Input:** If $v_{min} = v_{max}$, the interval is a single point. If $t = v_{min}$, the cell is active under the half-open rule.

**Pseudocode:**
```python
def canonical_enumeration(volume_data, isovalue, grid_dims):
    """
    volume_data: 3D array of scalar values at vertices.
    grid_dims: Tuple (Nx, Ny, Nz) defining the number of cells.
    isovalue: The scalar threshold t.
    Returns: List of active cell indices (i, j, k).
    """
    active_cells = []
    Nx, Ny, Nz = grid_dims
    
    # Iterate over all cells in the volume
    for k in range(Nz):
        for j in range(Ny):
            for i in range(Nx):
                # Get vertex values for cell (i, j, k)
                # Assuming volume_data stores values at vertices, 
                # cell (i,j,k) involves vertices (i,j,k) to (i+1,j+1,k+1)
                # This depends on specific data layout; generic access:
                cell_vertices = get_cell_vertices(volume_data, i, j, k)
                
                # Calculate min and max scalar values in the cell
                vmin = min(cell_vertices)
                vmax = max(cell_vertices)
                
                # Check if isovalue is in the half-open interval [vmin, vmax)
                if vmin <= isovalue < vmax:
                    active_cells.append((i, j, k))
                    
    return active_cells
```

## Subtopics

### [Isosurface Propagation from Seed Cells](6942-isosurface-propagation-from-seed-cells.md)
A geometric decomposition technique that identifies sparse "seed" cells and propagates extraction to neighbors, skipping empty regions. Choose this when the volume is sparse or large, as it offers near-optimal worst-case time complexity by avoiding full enumeration.

## Operating characteristics
*   **Time Complexity:** $O(n)$, where $n$ is the total number of cells in the volume data [S1, unofficial]. This is the lowest possible worst-case extraction time for any method based solely on isovalue comparisons without auxiliary spatial structures.
*   **Memory Complexity:** $O(1)$ auxiliary space. It requires only storage for the original volume data and a small constant amount for variables [S1, unofficial].
*   **Strengths:** Simplicity of implementation; no preprocessing or auxiliary data structure construction required; optimal worst-case time for unstructured search.
*   **Limitations:** Inefficient for sparse volumes or large datasets where the surface occupies a tiny fraction of the volume, as it processes every cell regardless of whether it contains the surface.
*   **When to use:** Small volumes, dense surfaces, or as a baseline for correctness verification.
*   **When not to use:** Large-scale volumes with sparse surfaces where acceleration via hierarchical subdivision (e.g., octrees) is necessary.

## Background
Canonical Enumeration is the elementary method for cell extraction, historically used in the original "Marching Cubes" paper by Lorenson and Cline [S1, unofficial]. It serves as the foundational reference for evaluating the performance of more complex isosurface extraction algorithms, particularly those employing hierarchical spatial subdivisions like octrees [S1, unofficial].
