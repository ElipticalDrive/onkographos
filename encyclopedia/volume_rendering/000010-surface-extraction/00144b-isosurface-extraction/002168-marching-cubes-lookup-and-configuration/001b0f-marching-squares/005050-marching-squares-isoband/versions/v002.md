# Marching Squares (Isoband)
## Overview
Marching Squares (Isoband) is a surface extraction algorithm that generates filled contour bands (isobands) between an upper and lower threshold value, producing polygonal fragments from a 2D scalar field [S1]. It extends [Marching Squares](918-marching-squares.md) by classifying grid cells into three states (below, within, or above the band) rather than two, allowing for the creation of continuous filled regions rather than just isoline segments [S1].

## How it works
**Inputs:** A 2D scalar field $V$ defined on a regular grid; a lower threshold $T_{low}$ and an upper threshold $T_{high}$ defining the band interval $[T_{low}, T_{high}]$ [S1].
**Outputs:** A list of polygonal fragments (polygons with 3–8 sides) representing the filled isobands [S1].

**Data Structures:**
*   **Cell Index:** A ternary integer (base-3) constructed from 4 "trit" values, one for each corner of the square cell [S1].
*   **Trit Value:** $0$ if corner value $< T_{low}$, $1$ if $T_{low} \le$ corner value $\le T_{high}$, $2$ if corner value $> T_{high}$ [S1].
*   **Index Construction:** Trits are appended clockwise around the cell, with the most-significant trit at the top-left corner and the least-significant trit at the bottom-left corner, yielding $3^4 = 81$ possible indices [S1].

**Algorithm Steps:**
1.  **Classify Corners:** For each cell, compare the scalar value at each of the four corners against $T_{low}$ and $T_{high}$ to determine the trit for each corner [S1].
2.  **Compute Index:** Construct the 4-digit ternary index $I$ from the trits [S1].
3.  **Determine Category:** Classify the cell as Empty if $I = 0$ (0000) or $I = 80$ (2222), generating no fragments; otherwise classify as Not Empty [S1].
4.  **Generate Geometry for Not Empty Cells:** Walk around the cell, adding corner positions that are within the band and interpolating along relevant edges to connect the points [S1]. The specific connectivity is determined by the index $I$ [S1].
    *   **Slope Cases:** Build a single polygon fragment with 3–7 sides [S1].
    *   **Saddle Cases:** These cases require disambiguation because the topology is not determined solely by the corner values [S1]. Calculate the average cell center value $V_c = \frac{1}{4}\sum V_{corners}$ [S1]. Use $I$ and $V_c$ to determine the topology [S1]. Build 1 or 2 polygonal fragments with a total of 6, 7, or 8 sides [S1].
5.  **Edge Interpolation:** For edges where one endpoint is within the band and the other is not, or where endpoints are on opposite sides of the band boundaries, perform linear interpolation to find the intersection points [S1]. The intersection point $P$ on an edge between corners with values $V_1$ and $V_2$ and positions $P_1$ and $P_2$ is calculated as:
    $$ P = P_1 + \frac{T - V_1}{V_2 - V_1} (P_2 - P_1) $$
    where $T$ is the relevant threshold ($T_{low}$ or $T_{high}$) depending on which boundary is being crossed [S1].

**Pseudocode:**
```python
def marching_squares_isoband(grid, T_low, T_high):
    polygons = []
    rows, cols = grid.shape
    for r in range(rows - 1):
        for c in range(cols - 1):
            # 1. Classify corners (top-left, top-right, bottom-right, bottom-left)
            corners = [grid[r, c], grid[r, c+1], grid[r+1, c+1], grid[r+1, c]]
            trits = []
            for v in corners:
                if v < T_low: trits.append(0)
                elif v <= T_high: trits.append(1)
                else: trits.append(2)
            # 2. Compute index (base-3)
            I = trits[0]*27 + trits[1]*9 + trits[2]*3 + trits[3]
            # 3. Determine category
            if I == 0 or I == 80: continue # Empty
            # 4. Generate geometry
            points = []
            # Add corners within band
            for i, v in enumerate(corners):
                if 0 < trits[i] < 2: points.append(corners[i])
            # Interpolate edges
            edges = [(0,1), (1,2), (2,3), (3,0)]
            for i, j in edges:
                v1, v2 = corners[i], corners[j]
                p1, p2 = corners[i], corners[j]
                if (v1 < T_low and v2 >= T_low) or (v1 > T_high and v2 <= T_high):
                    T = T_low if v2 >= T_low else T_high
                    t = (T - v1) / (v2 - v1)
                    points.append(p1 + t * (p2 - p1))
                elif (v1 < T_low and v2 > T_high) or (v1 > T_high and v2 < T_low):
                    t_low = (T_low - v1) / (v2 - v1)
                    t_high = (T_high - v1) / (v2 - v1)
                    points.append(p1 + t_low * (p2 - p1))
                    points.append(p1 + t_high * (p2 - p1))
            # 5. Build polygons based on I and category
            if is_saddle_case(I):
                V_c = sum(corners) / 4.0
                # Disambiguate using I and V_c, build 1 or 2 fragments
                polygons.extend(build_saddle_polygons(I, V_c, points))
            else:
                # Slope case
                polygons.append(build_slope_polygon(I, points))
    return polygons
```
*Note: The lookup tables for `is_saddle_case`, `build_saddle_polygons`, and `build_slope_polygon` are not provided in the sources; they map the 81 ternary indices to specific vertex connectivity patterns based on the slope/saddle classification and center value thresholds [S1].*

**Pitfalls and Edge Cases:**
*   **Missing 6-Sided Saddle:** A specific 6-sided saddle case is omitted because the central value configuration required for it cannot occur in a valid scalar field interpolation [S1].
*   **Omitted 7-Sided Saddle:** A valid 7-sided saddle case exists where the central value is dominated by a single extreme value [S1]. The resulting geometric structure is too complex to fit the simple model of two convex fragments [S1]. This case is merged with the case where the central value is within the band [S1]. Linear interpolation in this merged case produces a plausible single heptagon [S1].
*   **Planarity:** In 3D space, a quadrilateral embedded in 3D is not necessarily planar, requiring a choice of geometric interpolation scheme for banded surfaces, though the 2D algorithm assumes planarity [S1].

## Subtopics

### Marching Squares Performance Optimization
This variant focuses on reducing computational overhead and output size [S1]. It caches interpolation results to avoid redundant calculations; a single-threaded serial version only needs to cache interpolated results for one row of the input grid [S1]. It reduces output size by using indexed geometric primitives, creating an array of 2D vertices and specifying polygons with short integer offsets into the array [S1]. It is designed as an embarrassingly parallel algorithm assuming shared read-only input scalar field and shared append-only geometry output stream [S1]. Choose this variant when processing large grids where memory bandwidth and vertex duplication are bottlenecks.

## Operating characteristics
*   **Complexity:** A naive implementation performs linear interpolation four times per edge for isobands, resulting in 4 copies of vertices for polygons [S1].
*   **Parallelism:** The algorithm is embarrassingly parallel because all cells are processed independently [S1].
*   **Memory:** A naive implementation produces 4 copies of 2D vertices for polygons (isobands) due to independent cell processing [S1]. Indexed primitives can reduce this significantly [S1].
*   **Strengths:** Simple to implement; produces filled regions; embarrassingly parallel [S1].
*   **Limitations:** Naive implementation has high vertex duplication; saddle cases require center value calculation and complex logic; omitted cases may lead to topological inaccuracies in specific scalar field configurations [S1].

## Background
The Marching Squares algorithm was originally developed for isoline extraction [S1]. The isoband variant extends this to filled contours [S1]. The algorithm is widely used in geographic information systems (GIS) for contour mapping and in scientific visualization for scalar field analysis [S1]. The specific handling of saddle cases and the omission of certain complex topologies were detailed in discussions of substitope algorithms and geometric design [S1].
