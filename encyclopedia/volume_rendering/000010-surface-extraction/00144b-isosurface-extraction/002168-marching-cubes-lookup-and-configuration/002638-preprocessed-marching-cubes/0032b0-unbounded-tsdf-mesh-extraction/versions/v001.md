# Unbounded TSDF Mesh Extraction

Also called: Command Line Mesh Extraction

## Overview
Extracts a triangle mesh from an unbounded 3D Gaussian Splatting scene by contracting the infinite space into a bounded unit volume, performing adaptive Truncated Signed Distance Function (TSDF) fusion within that contracted space, and applying Marching Cubes. It differs from bounded extraction by handling scenes without a predefined bounding box through spatial contraction, allowing the method to isolate the largest object and fill internal bubbles via the preprocessing steps inherited from [Preprocessed Marching Cubes](3765-preprocessed-marching-cubes.md).

## How it works
**Inputs:** A trained 3D Gaussian Splatting model (positions, covariances, SH coefficients, opacities), camera poses, and command-line arguments controlling resolution and truncation.
**Outputs:** A `.ply` triangle mesh file containing vertices, normals, and diffuse colors.

**Data Structures:**
*   **Gaussian Model:** Stores $N$ Gaussians. Each Gaussian has position $\mathbf{x} \in \mathbb{R}^3$, covariance matrix $\mathbf{\Sigma} \in \mathbb{R}^{3 \times 3}$ (or rotation/scale), SH coefficients $\mathbf{c}_l$, and opacity $\alpha$.
*   **TSDF Volume:** A 3D grid of size $N \times N \times N$. Each voxel stores a weighted average distance and a weight sum.
*   **Mesh:** A collection of triangles with vertex attributes (position, normal, color).

**Formulas and Definitions:**
1.  **Contraction Function:** Maps unbounded space $\mathbf{x}$ to a bounded unit sphere.
    $$
    \text{contract}(\mathbf{x}) = \begin{cases} 
    \mathbf{x} & \text{if } \|\mathbf{x}\| < 1 \\
    \left(2 - \frac{1}{\|\mathbf{x}\|}\right) \frac{\mathbf{x}}{\|\mathbf{x}\|} & \text{otherwise}
    \end{cases}
    $$
2.  **Uncontraction Function:** Maps the bounded space back to unbounded space.
    $$
    \text{uncontract}(\mathbf{y}) = \begin{cases} 
    \mathbf{y} & \text{if } \|\mathbf{y}\| < 1 \\
    \frac{1}{2 - \|\mathbf{y}\|} \frac{\mathbf{y}}{\|\mathbf{y}\|} & \text{otherwise}
    \end{cases}
    $$
3.  **Normalization:**
    $$
    \text{normalize}(\mathbf{x}) = \frac{\mathbf{x} - \text{center}}{\text{radius}}
    $$
4.  **Unnormalization:**
    $$
    \text{unnormalize}(\mathbf{x}) = \mathbf{x} \cdot \text{radius} + \text{center}
    $$
5.  **Inverse Contraction:** Combines uncontraction and unnormalization.
    $$
    \text{inv\_contraction}(\mathbf{x}) = \text{unnormalize}(\text{uncontract}(\mathbf{x}))
    $$

**Parameters:**
*   `resolution` / `mesh_res`: Grid resolution for Marching Cubes. Default: 1024 [S1, unofficial].
*   `depth_trunc`: Maximum depth range for TSDF fusion. If negative, auto-calculated as $2 \cdot \text{radius}$ [S1, unofficial].
*   `voxel_size`: Physical size of a voxel. If negative, auto-calculated as $\text{depth\_trunc} / \text{mesh\_res}$ [S1, unofficial].
*   `sdf_trunc`: Truncation distance for the TSDF. If negative, auto-calculated as $5.0 \cdot \text{voxel\_size}$ [S1, unofficial].
*   `num_cluster`: Number of largest connected components to keep during post-processing. Default: 50 [S1, unofficial].

**Algorithm Steps:**

1.  **Determine Bounding Box Radius ($R$):**
    *   Compute the contracted positions of all Gaussians: $\mathbf{p}'_i = \text{contract}(\mathbf{p}_i)$.
    *   Calculate the norm $\|\mathbf{p}'_i\|$ for all $i$.
    *   Find the 95th percentile of these norms.
    *   Set $R = \min(1.9, \text{percentile} + 0.01)$ [S1, unofficial].

2.  **Define SDF Function:**
    *   Create a function `sdf_function(x)` that evaluates the signed distance field at point $\mathbf{x}$ by querying the Gaussian splatting model. This typically involves projecting Gaussians onto the ray from the camera or evaluating the density field directly. In the context of TSDF fusion, this often implies rendering depth maps from multiple viewpoints and fusing them into a volume, or evaluating a continuous SDF approximation derived from the Gaussians. The source implies calling `marching_cubes_with_contraction` with an `sdf_function` [S1, unofficial].

3.  **Execute Marching Cubes with Contraction:**
    *   Call `marching_cubes_with_contraction` with:
        *   `sdf_function`: The function defined in Step 2.
        *   `bounding_box_min`: $-R$
        *   `bounding_box_max`: $R$
        *   `level`: 0 (isosurface value)
        *   `resolution`: `mesh_res`
        *   `inv_contraction`: The function defined in Formula 5.
    *   This function samples the SDF on a grid in the contracted space, runs Marching Cubes, and applies `inv_contraction` to the resulting vertices to map them back to world space [S1, unofficial].

4.  **Color the Mesh:**
    *   For each vertex $\mathbf{v}$ in the extracted mesh, query the TSDF function or the Gaussian model to retrieve the RGB color value.
    *   Set `active_sh_degree` to 0 to export only the diffuse texture component, ignoring higher-order spherical harmonics [S1, unofficial].

5.  **Post-Processing:**
    *   Identify connected components (clusters) in the mesh.
    *   Keep the largest `num_cluster` clusters.
    *   Discard all other vertices and faces [S1, unofficial].

    factor = torch.where(inside, torch.ones_like(norm), 2.0 - 1.0 / norm)

    """Uncontraction function mapping unit sphere to unbounded space."""

## Operating characteristics
*   **Time Complexity:** Dominated by the TSDF fusion or SDF evaluation at each grid point. With resolution $N$, there are $N^3$ points. Each point requires querying the Gaussian model, which is $O(M)$ where $M$ is the number of Gaussians, or $O(\log M)$ with spatial indexing. Total: $O(N^3 \cdot M)$ or $O(N^3 \cdot \log M)$.
*   **Memory Complexity:** $O(N^3)$ for the TSDF volume and $O(M)$ for the Gaussian model.
*   **Performance:** The contraction allows handling unbounded scenes without arbitrary clipping. The 95th percentile radius $R$ adapts to the scene's extent.
*   **Strengths:** Handles unbounded scenes naturally; isolates the main object via clustering; fills internal bubbles via preprocessing.
*   **Limitations:** High memory usage for high resolutions; SDF evaluation from Gaussians can be noisy or inaccurate if not properly fused; relies on the quality of the Gaussian model.

## Background
Originated in the context of 3D Gaussian Splatting, specifically the 2D-Gaussian-Splatting implementation by Huang et al. [S1, unofficial]. It addresses the limitation of standard Marching Cubes which requires a bounded volume, by introducing a space contraction technique. This allows for the extraction of meshes from scenes that extend to infinity or have no clear bounding box.
