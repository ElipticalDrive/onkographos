# Preprocessed Marching Cubes

Also called: Marching Cubes with preprocessing, meshify, niimath meshify

## Overview
Preprocessed Marching Cubes extracts a triangle mesh from a 3D scalar volume by applying optional preprocessing steps—such as Gaussian smoothing, connected-component filtering, and edge darkening—before running the standard Marching Cubes algorithm [S1, unofficial]. It is designed to isolate the largest object, fill internal bubbles, and improve surface boundary detection in noisy or fragmented data [S1, unofficial]. Unlike standard Marching Cubes, which may produce fragmented meshes or miss boundary details, this method ensures topological consistency and robust boundary handling through explicit preprocessing and post-processing stages [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A 3D scalar volume `img` of dimensions `NX x NY x NZ`, an `isolevel` threshold, and boolean flags `preSmooth`, `onlyLargest`, and `fillBubbles`.
- **Output:** A vertex list `pts` (array of `vec3s`), a triangle list `tris` (array of indices), and counts `npt` and `ntri`.

**Data Structures:**
- `vec3s`: A struct containing three `float` fields (`x`, `y`, `z`), totaling 12 bytes.
- `mask`: A 1D boolean array of size `NX * NY * NZ`, used to track connected components.
- `lo`, `hi`: 3-element integer arrays defining the bounding box of the region of interest.

**Steps:**
1. **Pre-smoothing:** If `preSmooth` is true, apply a Gaussian blur to `img` using `quick_smooth(img, NX, NY, NZ)` [S1, unofficial].
2. **Intensity Range Calculation:** Compute the minimum (`mn`) and maximum (`mx`) intensity values in `img`. If `mn == mx`, return `EXIT_FAILURE` [S1, unofficial].
3. **Isoslevel Clamping:** If `isolevel <= mn` or `isolevel > mx`, clamp `isolevel` to `0.5 * (mn + mx)` and print a warning [S1, unofficial].
4. **Connected Component Filtering:**
   - Allocate `mask` of size `NX * NY * NZ` and initialize to zero.
   - Set `mask[i] = 1` where `img[i] >= isolevel`.
   - Call `bwlabel(mask, 18, dim, onlyLargest, fillBubbles)` to label connected components [S1, unofficial].
   - If `fillBubbles` is true, set `img[i] = fmax(img[i], isolevel)` for all voxels where `mask[i] != 0` [S1, unofficial].
   - If `onlyLargest` is true, dilate the mask by one voxel, then set `img[i] = mn` for all voxels where `mask[i] == 0` [S1, unofficial].
   - Free `mask` [S1, unofficial].
5. **Edge Darkening and Bounding Box Calculation:**
   - Compute `edgeMax = 0.75 * (mn + isolevel)` [S1, unofficial].
   - Initialize `lo[3] = {NX, NY, NZ}` and `hi[3] = {0, 0, 0}`.
   - Iterate through all voxels `vx` (indexed by `z, y, x`):
     - If `img[vx] >= isolevel`, update `lo` and `hi` to include `x, y, z` [S1, unofficial].
     - If the voxel is on the boundary (`x==0 || y==0 || z==0 || x==NX-1 || y==NY-1 || z==NZ-1`), set `img[vx] = fminf(edgeMax, img[vx])` [S1, unofficial].
6. **Bounding Box Expansion:** Expand the bounding box by 1 voxel in all directions: `lo[i] = MAX(lo[i] - 1, 0)` and `hi[i] = MIN(hi[i] + 2, dim[i])` for `i` in `0..2` [S1, unofficial].
7. **Marching Cubes Extraction:** Run `marchingCubes(img, dim, lo, hi, originalMC, isolevel, &pts, &tris, &npt, &ntri)` on the cropped volume [S1, unofficial]. Return `EXIT_FAILURE` on error.
8. **Post-processing:**
   - Unify vertices: `npt = unify_vertices(&pts, tris, npt, ntri, verbose)` [S1, unofficial].
   - Remove degenerate triangles: `ntri = remove_degenerate_triangles(pts, &tris, ntri, verbose)` [S1, unofficial].
9. **Output Assignment:** Assign `*t = tris`, `*p = pts`, `*nt = ntri`, `*np = npt`. Return `EXIT_SUCCESS` [S1, unofficial].

**Pseudocode:**
```python
def preprocessed_marching_cubes(img, NX, NY, NZ, isolevel, preSmooth, onlyLargest, fillBubbles):
    # Step 1: Pre-smoothing
    if preSmooth:
        img = quick_smooth(img, NX, NY, NZ)

    # Step 2: Intensity Range
    mn = img[0]
    mx = img[0]
    for i in range(NX * NY * NZ):
        mn = min(mn, img[i])
        mx = max(mx, img[i])
    
    if mn == mx:
        return EXIT_FAILURE

    # Step 3: Isoslevel Clamping
    if isolevel <= mn or isolevel > mx:
        isolevel = 0.5 * (mn + mx)
        print("Warning: Isoslevel clamped to 0.5 * (mn + mx)")

    # Step 4: Connected Component Filtering
    mask = [0] * (NX * NY * NZ)
    for i in range(NX * NY * NZ):
        if img[i] >= isolevel:
            mask[i] = 1
    
    bwlabel(mask, 18, (NX, NY, NZ), onlyLargest, fillBubbles)
    
    if fillBubbles:
        for i in range(NX * NY * NZ):
            if mask[i] != 0:
                img[i] = max(img[i], isolevel)
    
    if onlyLargest:
        dilate(mask, (NX, NY, NZ), True)
        for i in range(NX * NY * NZ):
            if mask[i] == 0:
                img[i] = mn
    
    # Step 5: Edge Darkening and Bounding Box
    edgeMax = 0.75 * (mn + isolevel)
    lo = [NX, NY, NZ]
    hi = [0, 0, 0]
    
    vx = 0
    for z in range(NZ):
        for y in range(NY):
            for x in range(NX):
                if img[vx] >= isolevel:
                    lo[0] = min(x, lo[0])
                    lo[1] = min(y, lo[1])
                    lo[2] = min(z, lo[2])
                    hi[0] = max(x, hi[0])
                    hi[1] = max(y, hi[1])
                    hi[2] = max(z, hi[2])
                
                if x == 0 or y == 0 or z == 0 or x == NX - 1 or y == NY - 1 or z == NZ - 1:
                    img[vx] = min(edgeMax, img[vx])
                
                vx += 1

    # Step 6: Bounding Box Expansion
    dim = (NX, NY, NZ)
    for i in range(3):
        lo[i] = max(lo[i] - 1, 0)
        hi[i] = min(hi[i] + 2, dim[i])

    # Step 7: Marching Cubes Extraction
    pts, tris, npt, ntri = marchingCubes(img, dim, lo, hi, originalMC, isolevel)
    if not pts or not tris:
        return EXIT_FAILURE

    # Step 8: Post-processing
    npt = unify_vertices(pts, tris, npt, ntri, verbose=True)
    ntri = remove_degenerate_triangles(pts, tris, ntri, verbose=True)

    # Step 9: Output
    return tris, pts, ntri, npt, EXIT_SUCCESS
```

**Parameters:**
- `preSmooth`: Boolean flag to apply Gaussian blur. Typical: `false` [S1, unofficial].
- `onlyLargest`: Boolean flag to extract only the largest connected component. Typical: `false` [S1, unofficial].
- `fillBubbles`: Boolean flag to fill internal voids. Typical: `false` [S1, unofficial].
- `isolevel`: Scalar threshold. Default: `0.5 * (mn + mx)` if out of range [S1, unofficial].
- `edgeMax`: Intensity cap for boundary voxels, calculated as `0.75 * (mn + isolevel)` [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Constant Intensity:** If `mn == mx`, Marching Cubes fails; handled by returning `EXIT_FAILURE` [S1, unofficial].
- **Out-of-Range Isoslevel:** Clamped to `0.5 * (mn + mx)` to prevent incorrect extraction [S1, unofficial].
- **Boundary Voxels:** May be missed if not darkened; handled by setting boundary voxels to `fminf(edgeMax, img[vx])` [S1, unofficial].
- **Subvoxel Edge Preservation:** Lost when cropping; handled by dilating the mask by one voxel before extracting the largest component [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Dominated by the connected component labeling (`bwlabel`) and the Marching Cubes extraction. The preprocessing steps (smoothing, filtering) add overhead but reduce the effective volume size for Marching Cubes.
- **Memory Complexity:** Requires additional memory for the `mask` array (`NX * NY * NZ` bytes) and the expanded bounding box.
- **Performance:** Improves robustness in noisy data by isolating the largest object and filling bubbles. May be slower than standard Marching Cubes due to preprocessing steps.
- **Strengths:** Handles fragmented data, fills internal voids, and ensures boundary voxels are included.
- **Limitations:** May lose fine details if `preSmooth` is enabled. The dilation step may slightly alter the surface position.
- **When to Use:** When the input volume is noisy, fragmented, or contains internal voids that need to be filled.
- **When Not to Use:** When preserving exact subvoxel edge positions is critical, or when performance is paramount and the data is already clean.

## Background
Preprocessed Marching Cubes is an extension of the standard Marching Cubes algorithm, incorporating preprocessing steps to improve the quality of the extracted mesh. It is commonly used in medical imaging and scientific visualization where data may be noisy or fragmented [S1, unofficial]. The method is implemented in tools like `niimath` and is referred to as "meshify" in some contexts [S1, unofficial].
