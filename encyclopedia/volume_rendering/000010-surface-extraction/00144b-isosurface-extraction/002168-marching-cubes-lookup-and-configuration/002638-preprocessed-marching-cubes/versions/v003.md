# Preprocessed Marching Cubes

Also called: Marching Cubes with preprocessing, meshify, niimath meshify

## Overview
Preprocessed Marching Cubes extracts a triangle mesh from a 3D scalar volume by applying optional preprocessing steps—such as Gaussian smoothing, connected-component filtering, and edge darkening—to the input data before running the standard Marching Cubes algorithm [S1, unofficial]. It solves the problem of noisy scalar fields producing fragmented meshes, internal bubbles, or missing boundary surfaces by isolating the largest coherent object and enforcing surface continuity at volume boundaries [S1, unofficial]. Unlike standard Marching Cubes, which operates directly on raw voxel data, this method modifies the scalar field topology and intensity distribution to ensure robust surface detection and watertightness [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input**: A 3D scalar volume `img` of dimensions $N_X \times N_Y \times N_Z$, an isovalue `isolevel`, and boolean flags `preSmooth`, `onlyLargest`, and `fillBubbles` [S1, unofficial].
*   **Outputs**: A list of vertices `pts` (array of `vec3`), a list of triangles `tris` (array of indices), and counts `npt`, `ntri` [S1, unofficial].

**Data Structures**
*   `vec3`: A struct containing three single-precision floats `x`, `y`, `z` (12 bytes) [S1, unofficial].
*   `mask`: A boolean or integer array of size $N_X \times N_Y \times N_Z$ used for connected-component labeling [S1, unofficial].
*   `lo`, `hi`: 3-element integer arrays defining the bounding box of the region of interest [S1, unofficial].

**Algorithm Steps**

1.  **Preprocessing (Smoothing)**: If `preSmooth` is true, apply a Gaussian blur to `img` using a function `quick_smooth(img, N_X, N_Y, N_Z)` [S1, unofficial]. [G] The specific kernel size and sigma are not defined in the source; a standard 3x3x3 or 5x5x5 Gaussian kernel is implied by "quick_smooth".

2.  **Intensity Range Calculation**: Compute the minimum (`mn`) and maximum (`mx`) values in `img` [S1, unofficial].
    $$ mn = \min_{i} img[i], \quad mx = \max_{i} img[i] $$
    If $mn == mx$, return failure (constant image) [S1, unofficial].

3.  **Isolevel Clamping**: If `isolevel` $\le mn$ or `isolevel` $> mx$, clamp `isolevel` to the midpoint:
    $$ isolevel = 0.5 \times (mn + mx) $$
    Print a warning [S1, unofficial].

4.  **Connected Component Filtering**: If `onlyLargest` or `fillBubbles` is true:
    a. Allocate `mask` of size $N_X \times N_Y \times N_Z$ and initialize to 0 [S1, unofficial].
    b. Set `mask[i] = 1` where `img[i] >= isolevel`, else 0 [S1, unofficial].
    c. Perform 18-connected component labeling on `mask` using `bwlabel(mask, 18, dim, onlyLargest, fillBubbles)` [S1, unofficial].
    d. If `fillBubbles` is true: For all voxels where `mask[i] != 0` (part of the largest component or its interior), set `img[i] = \max(img[i], isolevel)` [S1, unofficial]. This ensures internal voids are filled with values above the isovalue.
    e. If `onlyLargest` is true: Dilate the `mask` by 1 voxel (to preserve subvoxel edge information as noted in pitfalls) [S1, unofficial]. Then, for all voxels where `mask[i] == 0` (outside the largest component), set `img[i] = mn` [S1, unofficial].
    f. Free `mask` [S1, unofficial].

5.  **Edge Darkening**: Compute `edgeMax`:
    $$ edgeMax = 0.75 \times (mn + isolevel) $$
    Initialize `lo[3] = \{N_X, N_Y, N_Z\}` and `hi[3] = \{0, 0, 0\}` [S1, unofficial].
    Iterate over all voxels $(x, y, z)$:
    a. If `img[vx] >= isolevel`:
       $$ lo[x] = \min(x, lo[0]), \quad lo[y] = \min(y, lo[1]), \quad lo[z] = \min(z, lo[2]) $$
       $$ hi[x] = \max(x, hi[0]), \quad hi[y] = \max(y, hi[1]), \quad hi[z] = \max(z, hi[2]) $$
    b. If the voxel is on the boundary of the volume ($x=0$ or $x=N_X-1$ or $y=0$ or $y=N_Y-1$ or $z=0$ or $z=N_Z-1$):
       $$ img[vx] = \min(edgeMax, img[vx]) $$
    This step caps the intensity of boundary voxels to ensure they are below the isovalue (assuming `edgeMax < isolevel` or close to it, though the formula suggests it's a significant reduction), preventing the surface from being clipped by the volume boundary [S1, unofficial].

6.  **Bounding Box Expansion**: Expand the computed bounding box `lo`, `hi` by 1 voxel in all directions to ensure boundary voxels are included in the crop:
    $$ lo[i] = \max(lo[i] - 1, 0) $$
    $$ hi[i] = \min(hi[i] + 2, dim[i]) $$
    for $i \in \{0, 1, 2\}$ [S1, unofficial].

7.  **Marching Cubes Extraction**: Run the standard Marching Cubes algorithm on the cropped sub-volume defined by `lo` and `hi` [S1, unofficial].
    $$ \text{marchingCubes}(img, dim, lo, hi, originalMC, isolevel, \&pts, \&tris, \&npt, \&ntri) $$
    Return failure on error [S1, unofficial].

8.  **Post-processing**:
    a. **Vertex Unification**: Merge duplicate vertices within a tolerance to ensure mesh coherence:
       $$ npt = \text{unify\_vertices}(\&pts, tris, npt, ntri, verbose) $$
    b. **Degenerate Triangle Removal**: Remove triangles with zero area or repeated indices:
       $$ ntri = \text{remove\_degenerate\_triangles}(pts, \&tris, ntri, verbose) $$

9.  **Return**: Assign `*t = tris`, `*p = pts`, `*nt = ntri`, `*np = npt` and return success [S1, unofficial].

**Pseudocode**

```python
def preprocessed_marching_cubes(img, NX, NY, NZ, isolevel, preSmooth=False, onlyLargest=False, fillBubbles=False):
    # 1. Preprocessing
    if preSmooth:
        img = quick_smooth(img, NX, NY, NZ) # [G] Implementation of quick_smooth not provided

    # 2. Intensity Range
    mn = img[0]
    mx = img[0]
    for i in range(NX * NY * NZ):
        mn = min(mn, img[i])
        mx = max(mx, img[i])

    if mn == mx:
        return EXIT_FAILURE # Constant image

    # 3. Isolevel Clamping
    if isolevel <= mn or isolevel > mx:
        isolevel = 0.5 * (mn + mx)
        print("Warning: Isolevel clamped to midpoint")

    # 4. Connected Component Filtering
    if onlyLargest or fillBubbles:
        mask = [0] * (NX * NY * NZ)
        for i in range(NX * NY * NZ):
            if img[i] >= isolevel:
                mask[i] = 1
        
        # 18-connected labeling
        labels = bwlabel(mask, 18, (NX, NY, NZ), onlyLargest, fillBubbles)
        
        # Identify largest component label
        # [G] bwlabel returns a label map; we need to find the label with the most voxels if onlyLargest is true
        # The source implies bwlabel handles the logic of "onlyLargest" and "fillBubbles" internally or via flags
        # We assume labels[i] is the component ID for voxel i
        
        if fillBubbles:
            for i in range(NX * NY * NZ):
                if labels[i] != 0: # Part of the largest component (or interior)
                    img[i] = max(img[i], isolevel)
        
        if onlyLargest:
            # Dilate mask by 1 voxel to preserve subvoxel edge info
            dilated_mask = dilate(mask, (NX, NY, NZ), 1)
            for i in range(NX * NY * NZ):
                if dilated_mask[i] == 0:
                    img[i] = mn
        
        # Free mask (handled by language runtime or explicit delete)

    # 5. Edge Darkening and Bounding Box
    edgeMax = 0.75 * (mn + isolevel)
    lo = [NX, NY, NZ]
    hi = [0, 0, 0]
    
    for z in range(NZ):
        for y in range(NY):
            for x in range(NX):
                vx = z * NX * NY + y * NX + x
                if img[vx] >= isolevel:
                    lo[0] = min(x, lo[0])
                    lo[1] = min(y, lo[1])
                    lo[2] = min(z, lo[2])
                    hi[0] = max(x, hi[0])
                    hi[1] = max(y, hi[1])
                    hi[2] = max(z, hi[2])
                
                # Boundary check
                if x == 0 or x == NX - 1 or y == 0 or y == NY - 1 or z == 0 or z == NZ - 1:
                    img[vx] = min(edgeMax, img[vx])

    # 6. Expand Bounding Box
    for i in range(3):
        lo[i] = max(lo[i] - 1, 0)
        hi[i] = min(hi[i] + 2, [NX, NY, NZ][i])

    # 7. Marching Cubes
    # Crop img to [lo, hi]
    cropped_img = crop(img, lo, hi)
    cropped_dim = [hi[i] - lo[i] + 1 for i in range(3)]
    
    pts, tris, npt, ntri = marching_cubes(cropped_img, cropped_dim, isolevel)
    
    if pts is None:
        return EXIT_FAILURE

    # 8. Post-processing
    pts, tris, npt, ntri = unify_vertices(pts, tris, npt, ntri)
    tris, ntri = remove_degenerate_triangles(pts, tris, ntri)

    return tris, pts, ntri, npt
```

## Subtopics

### [Unbounded TSDF Mesh Extraction](6832-unbounded-tsdf-mesh-extraction.md)
Extracts a triangle mesh from an unbounded 3D Gaussian Splatting scene by contracting the infinite space into a bounded unit volume, performing adaptive Truncated Signed Distance Function (TSDF) fusion within that contracted space, and applying Marching Cubes. It differs from bounded extraction by handling scenes without a predefined bounding box through spatial contraction, allowing the method to isolate the largest object and fill internal bubbles via the preprocessing steps inherited from [Preprocessed Marching Cubes](3765-preprocessed-marching-cubes.md).

## Operating characteristics
*   **Time Complexity**: Dominated by the connected-component labeling ($O(N_X N_Y N_Z)$) and the Marching Cubes traversal ($O(N_{cells})$). The preprocessing steps (smoothing, labeling) add linear overhead relative to the volume size.
*   **Memory Complexity**: Requires storage for the input volume, the mask array (same size as volume), and the output mesh. The mask allocation is the primary additional memory cost [S1, unofficial].
*   **Strengths**: Robustly handles noisy data by smoothing; isolates the primary object of interest by filtering small components; prevents surface clipping at volume boundaries via edge darkening; fills internal voids to create watertight meshes [S1, unofficial].
*   **Limitations**: The preprocessing steps are lossy (smoothing changes geometry); the method assumes a regular grid; the specific parameters for smoothing and dilation are not tunable in the basic description [S1, unofficial].
*   **When to use**: When the input scalar volume contains noise, small artifacts, or when the object of interest is not the only structure above the isovalue. Particularly useful for medical imaging or scientific data where the largest object is the target [S1, unofficial].
*   **When not to use**: When preserving fine geometric details is critical (smoothing blurs edges); when the volume boundary contains meaningful surface data that should not be darkened [S1, unofficial].

## Background
Preprocessed Marching Cubes is an implementation variant of the Marching Cubes algorithm, specifically associated with the `niimath` tool and the `meshify` utility [S1, unofficial]. It was documented in an unofficial GitHub repository (TRTUZ8/TRTUZ8.github.io) in 2026 [S1, unofficial]. The method extends the classic Marching Cubes algorithm by integrating preprocessing steps commonly used in image processing (Gaussian blur, connected-component analysis) to improve the quality of the extracted mesh for real-world noisy data [S1, unofficial].
