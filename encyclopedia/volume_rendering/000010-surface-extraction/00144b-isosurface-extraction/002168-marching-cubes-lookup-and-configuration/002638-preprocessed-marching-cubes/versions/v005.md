# Preprocessed Marching Cubes

Also called: Marching Cubes with preprocessing, meshify, niimath meshify

## Overview
Preprocessed Marching Cubes extracts a triangle mesh from a 3D scalar volume by applying optional preprocessing steps—such as Gaussian smoothing, connected-component filtering, and edge darkening—to the input data before running the standard Marching Cubes algorithm [S1, unofficial]. It is designed to isolate the largest object, fill internal bubbles (voids), and improve surface boundary detection in noisy or fragmented volumes [S1, unofficial]. Unlike standard Marching Cubes, which may produce fragmented meshes or miss boundary surfaces due to discretization artifacts, this method ensures mesh coherence and completeness through explicit topological and intensity corrections [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A 3D scalar volume `img` of dimensions $NX \times NY \times NZ$, an isovalue `isolevel`, and boolean flags `preSmooth`, `onlyLargest`, and `fillBubbles`.
- **Output:** A set of vertices `pts` (array of `vec3s`), a set of triangles `tris` (array of indices), and counts `npt`, `ntri`.

**Data Structures:**
- `vec3s`: A struct containing three single-precision floats `x`, `y`, `z` (12 bytes total) [S1, unofficial].
- `mask`: A boolean or integer array of size $NX \times NY \times NZ$ used for connected-component labeling [S1, unofficial].
- `lo[3]`, `hi[3]`: Integer arrays storing the bounding box coordinates of the region of interest [S1, unofficial].

**Algorithm Steps:**

1.  **Pre-smoothing (Optional):**
    If `preSmooth` is true, apply a Gaussian blur to the input volume `img` using a function `quick_smooth(img, NX, NY, NZ)` [S1, unofficial].

2.  **Intensity Range Calculation:**
    Compute the minimum (`mn`) and maximum (`mx`) intensity values in the volume:
    $$ mn = img[0], \quad mx = img[0] $$
    Iterate over all $nvox = NX \times NY \times NZ$ voxels:
    $$ mn = \min(mn, img[i]), \quad mx = \max(mx, img[i]) $$
    If $mn == mx$, the volume has constant intensity; return `EXIT_FAILURE` [S1, unofficial].

3.  **Isolevel Clamping:**
    If `isolevel` $\le mn$ or `isolevel` $> mx$, clamp `isolevel` to the midpoint:
    $$ isolevel = 0.5 \times (mn + mx) $$
    Print a warning indicating the adjustment [S1, unofficial].

4.  **Connected-Component Filtering and Bubble Filling (Optional):**
    If `onlyLargest` or `fillBubbles` is true:
    a. Allocate `mask[nvox]` and initialize to 0.
    b. Set `mask[i] = 1` where $img[i] \ge isolevel$.
    c. Perform binary labeling using 18-connectivity (in 3D, this typically implies face and edge connectivity, i.e., 26-connectivity neighbors excluding diagonals? Note: The source specifies `bwlabel(mask, 18, dim, onlyLargest, fillBubbles)`. In 3D, 18-connectivity usually refers to face+edge neighbors, while 26 is face+edge+corner. We follow the source's parameter `18`):
       $$ \text{bwlabel}(mask, 18, dim, onlyLargest, fillBubbles) $$
    d. If `fillBubbles` is true, for all voxels where `mask[i] != 0` (part of the largest component or filled region), update the image:
       $$ img[i] = \max(img[i], isolevel) $$
       This fills internal voids with intensity at or above the isovalue [S1, unofficial].
    e. If `onlyLargest` is true, dilate the `mask` by 1 voxel (to preserve subvoxel edge information as per pitfalls), then set $img[i] = mn$ for all voxels where `mask[i] == 0` (removing smaller components) [S1, unofficial].
    f. Free `mask` [S1, unofficial].

5.  **Edge Darkening:**
    Compute `edgeMax`:
    $$ edgeMax = 0.75 \times (mn + isolevel) $$
    Initialize bounding box limits:
    $$ lo[0]=lo[1]=lo[2] = \max(NX, NY, NZ) \quad (\text{or } \infty) $$
    $$ hi[0]=hi[1]=hi[2] = 0 $$
    Iterate over all voxels $(x, y, z)$ with index $vx$:
    a. If $img[vx] \ge isolevel$:
       $$ lo[0] = \min(x, lo[0]), \quad lo[1] = \min(y, lo[1]), \quad lo[2] = \min(z, lo[2]) $$
       $$ hi[0] = \max(x, hi[0]), \quad hi[1] = \max(y, hi[1]), \quad hi[2] = \max(z, hi[2]) $$
    b. If the voxel is on the boundary of the volume ($x=0$ or $x=NX-1$ or $y=0$ or $y=NY-1$ or $z=0$ or $z=NZ-1$):
       $$ img[vx] = \min(edgeMax, img[vx]) $$
       This "darkens" boundary voxels to ensure they are below the isovalue if they were borderline, preventing the Marching Cubes algorithm from missing surface intersections at the volume edge [S1, unofficial].

6.  **Bounding Box Expansion:**
    Expand the computed bounding box by 1 voxel in all directions to ensure surface details near the crop boundary are not lost:
    $$ lo[i] = \max(lo[i] - 1, 0) $$
    $$ hi[i] = \min(hi[i] + 2, dim[i]) $$
    for $i \in \{0, 1, 2\}$ [S1, unofficial].

7.  **Marching Cubes Extraction:**
    Run the standard Marching Cubes algorithm on the cropped sub-volume defined by `lo` and `hi`:
    $$ \text{marchingCubes}(img, dim, lo, hi, \text{originalMC}, isolevel, \&pts, \&tris, \&npt, \&ntri) $$
    Return `EXIT_FAILURE` if this step fails [S1, unofficial].

8.  **Vertex Unification:**
    Merge duplicate vertices to ensure mesh coherence:
    $$ npt = \text{unify\_vertices}(\&pts, tris, npt, ntri, \text{verbose}) $$
    This step removes redundant vertices and updates triangle indices [S1, unofficial].

9.  **Degenerate Triangle Removal:**
    Remove triangles with zero area or invalid vertex indices:
    $$ ntri = \text{remove\_degenerate\_triangles}(pts, \&tris, ntri, \text{verbose}) $$
    [S1, unofficial].

10. **Output Assignment:**
    Assign the final results to the output pointers:
    $$ *t = tris, \quad *p = pts, \quad *nt = ntri, \quad *np = npt $$
    Return `EXIT_SUCCESS` [S1, unofficial].

**Pseudocode:**

```python
def preprocessed_marching_cubes(img, NX, NY, NZ, isolevel, preSmooth=False, onlyLargest=False, fillBubbles=False):
    # 1. Pre-smoothing
    if preSmooth:
        img = quick_smooth(img, NX, NY, NZ)

    # 2. Intensity Range
    mn = img[0]
    mx = img[0]
    for i in range(NX * NY * NZ):
        mn = min(mn, img[i])
        mx = max(mx, img[i])
    
    if mn == mx:
        return EXIT_FAILURE

    # 3. Isolevel Clamping
    if isolevel <= mn or isolevel > mx:
        isolevel = 0.5 * (mn + mx)
        print("Warning: Isolevel clamped to midpoint")

    # 4. Connected-Component Filtering
    if onlyLargest or fillBubbles:
        mask = [0] * (NX * NY * NZ)
        for i in range(NX * NY * NZ):
            if img[i] >= isolevel:
                mask[i] = 1
        
        # bwlabel with 18-connectivity
        labels = bwlabel(mask, 18, (NX, NY, NZ), onlyLargest, fillBubbles)
        
        if fillBubbles:
            for i in range(NX * NY * NZ):
                if labels[i] != 0: # Part of the largest component or filled
                    img[i] = max(img[i], isolevel)
        
        if onlyLargest:
            # Dilate mask by 1 voxel to preserve subvoxel edges
            dilated_mask = dilate(labels, (NX, NY, NZ), 1)
            for i in range(NX * NY * NZ):
                if dilated_mask[i] == 0:
                    img[i] = mn
        
        del mask, labels, dilated_mask

    # 5. Edge Darkening and Bounding Box Calculation
    edgeMax = 0.75 * (mn + isolevel)
    lo = [NX, NY, NZ] # Initialize to max possible
    hi = [0, 0, 0]
    
    for z in range(NZ):
        for y in range(NY):
            for x in range(NX):
                vx = z * NY * NX + y * NX + x
                if img[vx] >= isolevel:
                    lo[0] = min(x, lo[0])
                    lo[1] = min(y, lo[1])
                    lo[2] = min(z, lo[2])
                    hi[0] = max(x, hi[0])
                    hi[1] = max(y, hi[1])
                    hi[2] = max(z, hi[2])
                
                # Boundary check
                if x == 0 or x == NX - 1 or y == 0 or y == NY - 1 or z == 0 or z == NZ - 1:
                    img[vx] = min(edgeMax, img[vx])

    # 6. Expand Bounding Box
    dim = [NX, NY, NZ]
    for i in range(3):
        lo[i] = max(lo[i] - 1, 0)
        hi[i] = min(hi[i] + 2, dim[i])

    # 7. Marching Cubes
    pts, tris, npt, ntri = marchingCubes(img, dim, lo, hi, originalMC, isolevel)
    if pts is None:
        return EXIT_FAILURE

    # 8. Vertex Unification
    npt = unify_vertices(pts, tris, npt, ntri)

    # 9. Remove Degenerate Triangles
    ntri = remove_degenerate_triangles(pts, tris, ntri)

    # 10. Output
    return tris, pts, ntri, npt, EXIT_SUCCESS
```

**Parameters:**
- `preSmooth`: Boolean flag to apply Gaussian blur. Typical value: `false` [S1, unofficial].
- `onlyLargest`: Boolean flag to extract only the largest connected component. Typical value: `false` [S1, unofficial].
- `fillBubbles`: Boolean flag to fill internal voids within the largest component. Typical value: `false` [S1, unofficial].
- `isolevel`: Scalar threshold. Default: $0.5 \times (mn + mx)$ if out of range [S1, unofficial].
- `edgeMax`: Intensity cap for boundary voxels, calculated as $0.75 \times (mn + isolevel)$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Constant Intensity:** If $mn == mx$, Marching Cubes fails; the algorithm returns `EXIT_FAILURE` [S1, unofficial].
- **Out-of-Range Isolevel:** If `isolevel` is outside $[mn, mx]$, it is clamped to the midpoint to prevent incorrect extraction [S1, unofficial].
- **Boundary Misses:** Boundary voxels may be missed by Marching Cubes if their intensity is exactly at the isovalue. Darkening them to `edgeMax` ensures they are below the threshold, forcing the algorithm to detect the surface intersection at the boundary [S1, unofficial].
- **Subvoxel Edge Preservation:** Cropping the volume can cut off surface details. Dilating the mask by one voxel before extracting the largest component helps preserve these subvoxel edges [S1, unofficial].

## Subtopics

### [Unbounded TSDF Mesh Extraction](6832-unbounded-tsdf-mesh-extraction.md)
Extracts a triangle mesh from an unbounded 3D Gaussian Splatting scene by contracting the infinite space into a bounded unit volume, performing adaptive Truncated Signed Distance Function (TSDF) fusion within that contracted space, and applying Marching Cubes. It differs from bounded extraction by handling scenes without a predefined bounding box through spatial contraction, allowing the method to isolate the largest object and fill internal bubbles via the preprocessing steps inherited from [Preprocessed Marching Cubes](3765-preprocessed-marching-cubes.md).

## Operating characteristics
- **Time Complexity:** Dominated by the volume traversal for intensity calculation ($O(N)$), connected-component labeling ($O(N)$), and Marching Cubes on the cropped volume ($O(N_{crop})$). The preprocessing steps add linear overhead relative to the volume size.
- **Memory Complexity:** Requires storage for the input volume, the mask array ($O(N)$), and the output mesh. The mask is freed after use.
- **Strengths:** Robust against noise and fragmentation; ensures watertightness by filling bubbles and isolating the largest component; handles boundary artifacts via edge darkening.
- **Limitations:** The preprocessing steps (smoothing, dilation) may slightly blur fine details or alter the exact surface location. The method assumes a regular grid structure.
- **When to Use:** When the input volume is noisy, contains small artifacts, or has internal voids that should be filled. Ideal for medical imaging or 3D reconstruction from sparse data where the largest object is the target.
- **When Not to Use:** When preserving exact subvoxel geometry is critical and preprocessing artifacts are unacceptable. When the volume contains multiple distinct objects of interest and `onlyLargest` is not desired.

## Background
Preprocessed Marching Cubes is an extension of the classic Marching Cubes algorithm [30-isosurface-extraction.md]. It was developed to address common issues in volume rendering and surface extraction, such as noise, fragmented surfaces, and boundary artifacts. The method is implemented in the `niimath` tool and is used in various image processing pipelines to prepare scalar volumes for mesh generation. The specific implementation details, including the `bwlabel` function with 18-connectivity and the edge darkening heuristic, are documented in the source code and documentation of the `TRTUZ8` project [S1, unofficial].
