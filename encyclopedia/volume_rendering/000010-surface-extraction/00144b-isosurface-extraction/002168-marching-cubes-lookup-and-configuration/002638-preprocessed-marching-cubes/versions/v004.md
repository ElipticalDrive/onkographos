# Preprocessed Marching Cubes

Also called: Marching Cubes with preprocessing, meshify, niimath meshify

## Overview
Preprocessed Marching Cubes extracts a triangle mesh from a 3D scalar volume by applying optional preprocessing steps—such as Gaussian smoothing, connected-component filtering, and boundary darkening—before running the standard Marching Cubes algorithm [S1, unofficial]. It solves the problem of noisy scalar fields producing fragmented meshes, internal bubbles, or missing boundary surfaces by isolating the largest object and filling voids prior to extraction [S1, unofficial]. It differs from standard Marching Cubes by explicitly handling topological noise and boundary artifacts through volumetric preprocessing, and from [Snap Marching Cubes](2181-snap-marching-cubes.md) by operating on the scalar field values directly rather than snapping vertices to high-frequency features [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input**: A 3D scalar volume `img` of dimensions $NX \times NY \times NZ$, an isovalue `isolevel`, and boolean flags `preSmooth`, `onlyLargest`, `fillBubbles`.
*   **Output**: A list of vertices `pts` (array of `vec3`), a list of triangles `tris` (array of integer triplets), and counts `npt`, `ntri`.

**Data Structures**
*   `img`: 1D array or 3D array of floats representing scalar values.
*   `mask`: 1D boolean or integer array of size $NX \times NY \times NZ$, used for connected component labeling.
*   `lo`, `hi`: 3-element integer arrays defining the bounding box of the region of interest.
*   `vec3`: Struct with fields `x`, `y`, `z` (floats).
*   `tris`: Array of integer triplets, where each triplet $(a, b, c)$ refers to indices in `pts`.

**Algorithm Steps**

1.  **Pre-smoothing**: If `preSmooth` is true, apply a Gaussian blur to `img` using a function `quick_smooth(img, NX, NY, NZ)` [S1, unofficial].
2.  **Intensity Range Calculation**:
    *   Initialize `mn` and `mx` to `img[0]`.
    *   Iterate over all $nvox = NX \times NY \times NZ$ voxels.
    *   Update `mn = min(mn, img[i])` and `mx = max(mx, img[i])`.
    *   If `mn == mx`, return failure (constant image) [S1, unofficial].
3.  **Isolevel Clamping**:
    *   If `isolevel <= mn` or `isolevel > mx`, clamp `isolevel` to $0.5 \times (mn + mx)$ and issue a warning [S1, unofficial].
4.  **Connected Component Filtering**:
    *   If `onlyLargest` or `fillBubbles` is true:
        *   Allocate `mask` of size $nvox$, initialized to 0.
        *   Set `mask[i] = 1` if `img[i] >= isolevel`, else 0.
        *   Call `bwlabel(mask, 18, dim, onlyLargest, fillBubbles)` to label connected components using 18-connectivity in 3D [S1, unofficial].
        *   If `fillBubbles` is true: For all voxels where `mask[i] != 0`, set `img[i] = max(img[i], isolevel)`. This fills internal voids within the largest component [S1, unofficial].
        *   If `onlyLargest` is true:
            *   Dilate the mask of the largest component by 1 voxel (to preserve subvoxel edge information) [S1, unofficial].
            *   Set `img[i] = mn` for all voxels where `mask[i] == 0` (removing smaller components) [S1, unofficial].
        *   Free `mask` [S1, unofficial].
5.  **Boundary Darkening**:
    *   Compute `edgeMax = 0.75 * (mn + isolevel)` [S1, unofficial].
    *   Initialize `lo[3] = {NX, NY, NZ}` and `hi[3] = {0, 0, 0}`.
    *   Iterate over all voxels $(x, y, z)$:
        *   Let $vx = x + y \times NX + z \times NX \times NY$.
        *   If `img[vx] >= isolevel`:
            *   Update bounding box:
                *   `lo[0] = min(x, lo[0])`, `lo[1] = min(y, lo[1])`, `lo[2] = min(z, lo[2])`
                *   `hi[0] = max(x, hi[0])`, `hi[1] = max(y, hi[1])`, `hi[2] = max(z, hi[2])`
        *   If the voxel is on the boundary of the volume ($x=0$ or $x=NX-1$ or $y=0$ or $y=NY-1$ or $z=0$ or $z=NZ-1$):
            *   Set `img[vx] = min(img[vx], edgeMax)` [S1, unofficial].
6.  **Bounding Box Expansion**:
    *   Expand the bounding box by 1 voxel in all directions:
        *   For $i \in \{0, 1, 2\}$:
            *   `lo[i] = max(lo[i] - 1, 0)`
            *   `hi[i] = min(hi[i] + 2, dim[i])` [S1, unofficial].
7.  **Marching Cubes Extraction**:
    *   Run standard Marching Cubes on the cropped volume defined by `lo` and `hi` using the parent method [Marching Cubes Lookup and Configuration](2518-marching-cubes-lookup-and-configuration.md) [S1, unofficial].
    *   Inputs to MC: `img`, `dim`, `lo`, `hi`, `isolevel`.
    *   Outputs: `pts`, `tris`, `npt`, `ntri` [S1, unofficial].
8.  **Post-processing**:
    *   **Unify Vertices**: Call `unify_vertices(pts, tris, npt, ntri)` to merge duplicate vertices [S1, unofficial].
    *   **Remove Degenerates**: Call `remove_degenerate_triangles(pts, tris, ntri)` to remove triangles with zero area [S1, unofficial].
9.  **Return**: Output `pts`, `tris`, `npt`, `ntri` [S1, unofficial].

**Pseudocode**

```python
def preprocessed_marching_cubes(img, NX, NY, NZ, isolevel, preSmooth=False, onlyLargest=False, fillBubbles=False):
    # Step 1: Pre-smoothing
    if preSmooth:
        img = quick_smooth(img, NX, NY, NZ)

    # Step 2: Intensity Range
    mn = img[0]
    mx = img[0]
    nvox = NX * NY * NZ
    for i in range(nvox):
        mn = min(mn, img[i])
        mx = max(mx, img[i])

    if mn == mx:
        return EXIT_FAILURE

    # Step 3: Isolevel Clamping
    if isolevel <= mn or isolevel > mx:
        isolevel = 0.5 * (mn + mx)
        print("Warning: Isolevel clamped to", isolevel)

    # Step 4: Connected Component Filtering
    if onlyLargest or fillBubbles:
        mask = [0] * nvox
        for i in range(nvox):
            if img[i] >= isolevel:
                mask[i] = 1
        
        # bwlabel implementation detail: 18-connectivity in 3D
        # Returns labels and identifies largest component
        labels, largest_label = bwlabel(mask, 18, (NX, NY, NZ), onlyLargest, fillBubbles)
        
        if fillBubbles:
            for i in range(nvox):
                if labels[i] != 0:
                    img[i] = max(img[i], isolevel)
        
        if onlyLargest:
            # Dilate mask of largest component by 1 voxel
            dilated_mask = [0] * nvox
            for i in range(nvox):
                if labels[i] == largest_label:
                    dilated_mask[i] = 1
            dilated_mask = dilate_3d(dilated_mask, (NX, NY, NZ), 1)
            
            for i in range(nvox):
                if dilated_mask[i] == 0:
                    img[i] = mn

    # Step 5: Boundary Darkening and Bounding Box
    edgeMax = 0.75 * (mn + isolevel)
    lo = [NX, NY, NZ]
    hi = [0, 0, 0]
    
    for z in range(NZ):
        for y in range(NY):
            for x in range(NX):
                vx = x + y * NX + z * NX * NY
                if img[vx] >= isolevel:
                    lo[0] = min(x, lo[0])
                    lo[1] = min(y, lo[1])
                    lo[2] = min(z, lo[2])
                    hi[0] = max(x, hi[0])
                    hi[1] = max(y, hi[1])
                    hi[2] = max(z, hi[2])
                
                # Boundary check
                if x == 0 or x == NX - 1 or y == 0 or y == NY - 1 or z == 0 or z == NZ - 1:
                    img[vx] = min(img[vx], edgeMax)

    # Step 6: Expand Bounding Box
    lo[0] = max(lo[0] - 1, 0)
    lo[1] = max(lo[1] - 1, 0)
    lo[2] = max(lo[2] - 1, 0)
    hi[0] = min(hi[0] + 2, NX)
    hi[1] = min(hi[1] + 2, NY)
    hi[2] = min(hi[2] + 2, NZ)

    # Step 7: Marching Cubes
    # Extract sub-volume or pass bounds to MC function
    pts, tris, npt, ntri = marching_cubes(img, (NX, NY, NZ), lo, hi, isolevel)

    # Step 8: Post-processing
    pts, tris, npt, ntri = unify_vertices(pts, tris, npt, ntri)
    tris, ntri = remove_degenerate_triangles(pts, tris, ntri)

    return pts, tris, npt, ntri
```

**Parameters**
*   `preSmooth`: Boolean. Applies Gaussian blur. Typical: `false` [S1, unofficial].
*   `onlyLargest`: Boolean. Extracts only the largest connected component. Typical: `false` [S1, unofficial].
*   `fillBubbles`: Boolean. Fills internal voids within the largest component. Typical: `false` [S1, unofficial].
*   `isolevel`: Scalar threshold. Default: $0.5 \times (mn + mx)$ if out of range [S1, unofficial].
*   `edgeMax`: Intensity cap for boundary voxels, calculated as $0.75 \times (mn + isolevel)$ [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Constant Image**: If `mn == mx`, Marching Cubes fails. The method returns `EXIT_FAILURE` [S1, unofficial].
*   **Out-of-Range Isolevel**: If `isolevel` is outside `[mn, mx)`, it is clamped to the midpoint to prevent incorrect extraction [S1, unofficial].
*   **Boundary Artifacts**: Boundary voxels may be missed if not darkened. The method sets boundary voxels to `min(img[vx], edgeMax)` to ensure they are below the isovalue if they are near the edge, preventing incomplete surfaces [S1, unofficial].
*   **Subvoxel Edge Preservation**: Cropping the volume can lose subvoxel edge information. The method dilates the mask by one voxel before extracting the largest component to mitigate this [S1, unofficial].

### [Unbounded TSDF Mesh Extraction](6832-unbounded-tsdf-mesh-extraction.md)
Extracts a mesh from an unbounded 3D Gaussian Splatting scene by contracting space into a bounded unit volume, performing adaptive TSDF fusion, and applying Marching Cubes. It uses the preprocessing steps of Preprocessed Marching Cubes to isolate the largest object and fill internal bubbles in the contracted space.

## Operating characteristics
*   **Time Complexity**: Dominated by the connected component labeling (`bwlabel`) and the Marching Cubes extraction. `bwlabel` is $O(N)$ where $N$ is the number of voxels. Marching Cubes is proportional to the number of voxels intersecting the isosurface. Preprocessing (smoothing) adds $O(N)$ with a constant factor depending on kernel size.
*   **Memory Complexity**: $O(N)$ for the input volume, mask, and output mesh. The mask is temporary and can be freed after preprocessing.
*   **Performance**: The preprocessing steps add overhead but significantly reduce noise and artifacts, leading to cleaner meshes with fewer triangles in post-processing. The boundary darkening step is $O(N)$ and prevents missing surfaces.
*   **Strengths**: Robust to noise, handles disconnected components, fills internal voids, prevents boundary artifacts.
*   **Limitations**: Requires additional memory for the mask. Smoothing may blur fine details. The method is designed for scalar volumes, not directly for point clouds or meshes.
*   **When to Use**: When the input scalar volume is noisy, contains small artifacts, or has boundary issues. When the goal is to extract the dominant object.
*   **When Not to Use**: When preserving fine, noisy details is critical. When memory is extremely constrained. When the input is not a scalar volume.

## Background
Preprocessed Marching Cubes is an implementation of the Marching Cubes algorithm with additional preprocessing steps, as described in the `niimath` tool's `meshify` command [S1, unofficial]. It is used in medical imaging and scientific visualization to clean up scalar fields before surface extraction. The method addresses common issues in Marching Cubes such as noise-induced artifacts and boundary effects [S1, unofficial].
