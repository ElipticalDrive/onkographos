# Uniform Marching Cubes with Snapping

Also called: Uniform Marching Cubes

## Overview
Uniform Marching Cubes with Snapping is a uniform-grid polygonization algorithm that computes cell topology masks from coarse grid vertex signs and optionally snaps iso-surface vertices to edges by minimizing distance to grid vertices [S1, unofficial]. It builds on [Marching Cubes on Structured Grids](6051-marching-cubes-on-structured-grids.md) by introducing a snapping mechanism that reduces geometric error, distinguishing it from standard UMC and other siblings like [Bitwise Marching Cubes](7374-bitwise-marching-cubes.md) which prioritize bitwise operations over positional accuracy.

## How it works
**Inputs and Outputs:**
*   **Input:** A structured grid of scalar values, represented by `grid_signs` (signs of values relative to an isovalue), `grid_verts` (vertex positions), and `edges` (edge definitions).
*   **Output:** A list of output vertex indices (`i_out`) and vertex attributes (`v_out`), stored in a `UMC_Chunk` structure.

**Data Structures:**
The core state is held in `struct UMC_Chunk` [S1, unofficial]:
*   `dim`: `uint32_t` grid dimensions.
*   `pem`: `int` flag enabling/disabling snapping mode.
*   `snap_threshold`: `float` threshold for snapping behavior.
*   `grid_signs`: `pointer` to grid vertex signs.
*   `grid_verts`: `pointer` to grid vertex positions.
*   `edges`: `pointer` to edge data.
*   `edge_v_indexes`: `pointer` to edge vertex indices.
*   `v_out`: `pointer` to output vertex buffer.
*   `n_out`: `pointer` to output normal buffer.
*   `vn_size`: `uint32_t` vertex buffer size.
*   `vn_next`: `uint32_t` next vertex index.
*   `i_out`: `pointer` to output index buffer.
*   `i_size`: `uint32_t` index buffer size.
*   `i_next`: `uint32_t` next index index.
*   `v_count`: `uint32_t` vertex count.
*   `p_count`: `uint32_t` primitive count.
*   `snapped_count`: `uint32_t` count of snapped vertices.
*   `indexed_primitives`: `int` flag for indexed rendering.
*   `initialized`: `int` initialization flag.
*   `vao`, `ibo`, `v_vbo`, `n_vbo`: `GLuints` for OpenGL resources.

**Parameters:**
*   `ISOLEVEL`: Fixed at `0.0f` for sign comparison [S1, unofficial].
*   `snap_threshold`: Float parameter controlling snapping threshold [S1, unofficial].
*   `pem`: Integer flag to enable/disable snapping [S1, unofficial].

**Algorithm Steps:**

1.  **Initialization:** Initialize `UMC_Chunk` with `pem` and `snap_threshold` [S1, unofficial].
2.  **Topology Mask Computation:** For each cell, compute the topology mask by reading `grid_signs` at subdivided coordinates. The coordinates are calculated as `(x+xoff)>>1`, `(y+yoff)>>1`, `(z+zoff)>>1` [S1, unofficial]. Set bit `m` in the mask based on the sign of the vertex [S1, unofficial].
3.  **Snapping Logic (if `pem` is enabled):**
    *   Extract a 2-bit vertex state `v` from `grid_signs` [S1, unofficial].
    *   Add `v*m` to the mask [S1, unofficial].
    *   If `v==1`, store a pointer to the corresponding grid vertex index in `cell.iso_verts[idx]` [S1, unofficial].
4.  **Edge Snapping:** For each edge:
    *   Check if endpoints differ (`e->grid_v0 != e->grid_v1`) [S1, unofficial].
    *   Check if edge length is strictly positive [S1, unofficial].
    *   Check if the edge is not already snapped [S1, unofficial].
    *   Compute the normalized distance from the iso vertex to the grid vertex [S1, unofficial].
    *   Track the minimum distance edge for snapping [S1, unofficial].
    *   Update the maximum edge length [S1, unofficial].
5.  **Output Storage:** Append output indices to a dynamically resized array `i_out`. If `out_ind_size` is reached, double it via `realloc` before storing the next index [S1, unofficial].

**Edge Cases and Pitfalls:**
*   Edge snapping requires checking that edge endpoints differ (`e->grid_v0 != e->grid_v1`), length is strictly positive, and the edge is not already snapped to avoid degenerate or double-snapped vertices [S1, unofficial].
*   Dynamic resizing of output buffers must handle `realloc` correctly to avoid memory leaks or corruption [S1, unofficial].
