# Marching Cubes with Narrow-Band Filtering
Also called: MeshReconstruction::MarchCube

## Overview
A method to reconstruct a triangle mesh from a Signed Distance Function (SDF) by evaluating the SDF on a grid of cubes, filtering cubes based on distance to the surface (narrow-band), and applying the Marching Cubes algorithm to intersected cubes [S1, unofficial]. It sets itself apart from standard Marching Cubes by skipping voxels that are too far from the isosurface, significantly reducing the number of processed voxels for sparse or bounded SDFs [S1, unofficial].

## How it works
**Inputs:**
*   `domain`: A bounding box (`Rect3`) defined by `min` and `size` vectors.
*   `sdf`: A function `Vec3 -> double` returning the signed distance at a point.
*   `cubeSize`: A `Vec3` defining the dimensions of each voxel. If not provided, defaults to `domain.size / 50` [S1, unofficial].
*   `isoLevel`: The scalar value for surface extraction, defaulting to `0.0` [S1, unofficial].
*   `sdfGrad`: An optional gradient function `Vec3 -> Vec3`. If `nullptr`, normals are computed numerically [S1, unofficial].

**Outputs:**
*   `mesh`: A triangle mesh containing vertices and indices.

**Data Structures:**
*   `signConfigToIntersectedEdges`: An array of 256 integers (12-bit bitmasks). Index $C$ (0–255) maps to the edges intersected by the isosurface for that vertex configuration. The bitmasks correspond to the 12 edges of the cube.
*   `edges`: An array of 12 `Edge` structs. Each struct contains:
    *   `edgeFlag`: A 12-bit integer ($2^k$) representing the bit position for the $k$-th edge.
    *   `vert0`, `vert1`: The indices (0–7) of the two vertices defining the edge.
*   `Cube`: A temporary object holding the 8 vertex positions (`pos[8]`) and 8 SDF values (`sdf[8]`) for a specific voxel.

**Steps:**

1.  **Grid Setup**: Calculate grid dimensions:
    $$ \text{NumX} = \lceil \text{domain.size.x} / \text{cubeSize.x} \rceil $$
    $$ \text{NumY} = \lceil \text{domain.size.y} / \text{cubeSize.y} \rceil $$
    $$ \text{NumZ} = \lceil \text{domain.size.z} / \text{cubeSize.z} \rceil $$
    Calculate geometric constants:
    $$ \text{HalfCubeDiag} = \|\text{cubeSize}\| / 2.0 $$
    $$ \text{HalfCubeSize} = \text{cubeSize} \times 0.5 $$

2.  **Voxel Iteration**: Iterate over grid indices $ix \in [0, \text{NumX})$, $iy \in [0, \text{NumY})$, $iz \in [0, \text{NumZ})$.

3.  **Cube Geometry**: Calculate the minimum corner of the current cube:
    $$ \text{min} = \text{domain.min} + \{ ix \cdot \text{cubeSize.x}, iy \cdot \text{cubeSize.y}, iz \cdot \text{cubeSize.z} \} $$
    Calculate the cube center:
    $$ \text{cubeCenter} = \text{min} + \text{HalfCubeSize} $$

4.  **Narrow-Band Filtering**: Evaluate the SDF at the center:
    $$ \text{dist} = | \text{sdf}(\text{cubeCenter}) - \text{isoLevel} | $$
    If $\text{dist} > \text{HalfCubeDiag}$, the cube cannot intersect the isosurface. Continue to the next cube [S1, unofficial].

5.  **Vertex Sampling**: Construct a `Cube` object. Sample the SDF at the 8 vertices of the cube:
    $$ \text{pos}[i] = \text{min} + \text{vertex\_offset}[i] \times \text{cubeSize} $$
    $$ \text{sdf}[i] = \text{sdf}(\text{pos}[i]) $$
    where $\text{vertex\_offset}[i]$ corresponds to the binary representation of $i$ (e.g., $i=0 \to (0,0,0)$, $i=7 \to (1,1,1)$).

6.  **Case Index Calculation**: Compute the 8-bit case index $C$. If $\text{sdf}[i] < \text{isoLevel}$ (or $> \text{isoLevel}$, depending on convention; the source implies standard sign check), set bit $i$ of $C$ to 1.

7.  **Intersection Detection**: Look up the intersected edges using `signConfigToIntersectedEdges[C]`. For each set bit $k$ in the result:
    *   Retrieve the edge definition from `edges[k]`.
    *   Calculate the intersection point using linear interpolation between the two vertices of the edge:
        $$ \mu = \frac{\text{isoLevel} - \text{sdf}[v_0]}{\text{sdf}[v_1] - \text{sdf}[v_0]} $$
        $$ \text{intersect\_point} = \text{pos}[v_0] + \mu (\text{pos}[v_1] - \text{pos}[v_0]) $$
    *   Handle precision edge cases: If $|\text{isoLevel} - \text{sdf}[v_0]| < \epsilon$ or $|\text{sdf}[v_1] - \text{sdf}[v_0]| < \epsilon$, return the respective vertex position directly [S1, unofficial].

8.  **Triangulation**: Use the `triangleTable` (from parent article) to determine which triangles to form from the intersection points. Add these triangles to the `mesh`.

9.  **Normal Calculation**: For each vertex in the generated triangles, compute the normal. If `sdfGrad` is provided, use $\nabla \text{SDF}(\text{vertex})$. Otherwise, use a numerical approximation [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N)$ where $N$ is the number of voxels in the grid. However, the constant factor is reduced by the narrow-band filter. The number of processed voxels is proportional to the surface area of the object times the inverse cube size, rather than the volume.
*   **Memory Complexity**: $O(1)$ auxiliary space per voxel during iteration, plus $O(V)$ for the output mesh where $V$ is the number of vertices.
*   **Performance**: Significantly faster than standard Marching Cubes for SDFs where the surface occupies a small fraction of the domain volume [S1, unofficial].
*   **Limitations**: Requires the SDF to be defined over the entire domain. If the domain is too small, the surface may be clipped. The narrow-band threshold (`HalfCubeDiag`) is a heuristic; if the surface has high curvature or the grid is coarse, some intersections might be missed if the center is far but edges are close (though mathematically, if the center is further than the half-diagonal, no edge can intersect the isosurface for a convex shape like a cube, but for non-convex SDFs, this might need verification). The source states `dist > HalfCubeDiag` implies no intersection [S1, unofficial].

## Background
The method is part of the `MeshReconstruction` library by Magnus2, which provides a self-contained C++14 implementation of Marching Cubes with narrow-band optimization [S1, unofficial]. It is designed for fast SDF-to-mesh conversion, particularly useful in real-time applications or when processing large bounding boxes with sparse surfaces.
