# Marching Cubes with Narrow-Band Filtering

Also called: MeshReconstruction::MarchCube

## Overview
This method reconstructs a triangle mesh from a Signed Distance Function (SDF) by restricting the Marching Cubes algorithm to a "narrow band" of voxels close to the zero-level set [S1, unofficial]. It solves the performance bottleneck of standard Marching Cubes, which processes every voxel in the domain regardless of distance to the surface [S1, unofficial]. By skipping cubes where the center distance exceeds the cube's half-diagonal, it reduces computational load significantly for sparse or localized SDFs [S1, unofficial].

## How it works
The method iterates over a structured grid covering the SDF domain. For each voxel, it determines if the isosurface intersects the cube by comparing the distance from the cube center to the isosurface against the cube's geometric extent. If an intersection is possible, it samples the SDF at the eight vertices, determines edge intersections via linear interpolation, and generates triangles using the lookup tables defined in [Marching Cubes Lookup and Configuration](2518-marching-cubes-lookup-and-configuration.md).

### Inputs and Outputs
*   **Input**:
    *   `sdf`: A function or data structure returning the signed distance value for any 3D point.
    *   `domain`: A bounding box (`Rect3`) defined by `min` and `size` vectors.
    *   `cubeSize`: The dimensions of a single voxel (cube).
    *   `isoLevel`: The scalar value defining the surface (typically 0 for SDFs).
    *   `sdfGrad`: (Optional) A function returning the gradient of the SDF at a point. If null, normals are approximated numerically [S1, unofficial].
*   **Output**:
    *   `mesh`: A triangle mesh containing vertices and indices.

### Data Structures
The implementation relies on the standard Marching Cubes lookup tables from the parent article [Marching Cubes Lookup and Configuration](2518-marching-cubes-lookup-and-configuration.md):
1.  **`signConfigToIntersectedEdges`** (256 entries): Maps the 8-bit vertex sign configuration to a 12-bit bitmask indicating which of the 12 cube edges are intersected. The bitmasks correspond to powers of 2 ($2^0$ to $2^{11}$) representing edges $e_0$ through $e_{11}$ [S1, unofficial].
2.  **`edges`** (12 entries): Defines the vertex indices for each of the 12 edges of a cube. Edge $k$ connects vertex $v_{start}$ to $v_{end}$ [S1, unofficial].

### Parameters
*   `NumCubes`: Integer constant (default 50) used to derive `cubeSize` if not explicitly provided: `cubeSize = domain.size / NumCubes` [S1, unofficial].
*   `isoLevel`: Default 0.0 [S1, unofficial].

### Algorithm Steps

1.  **Grid Initialization**:
    Calculate the number of cubes along each axis:
    $$ N_x = \lceil \frac{domain.size.x}{cubeSize.x} \rceil $$
    $$ N_y = \lceil \frac{domain.size.y}{cubeSize.y} \rceil $$
    $$ N_z = \lceil \frac{domain.size.z}{cubeSize.z} \rceil $$
    Calculate geometric constants:
    $$ HalfCubeSize = cubeSize \times 0.5 $$
    $$ HalfCubeDiag = \frac{\|cubeSize\|}{2.0} $$

2.  **Voxel Iteration**:
    Iterate over grid indices $i_x \in [0, N_x)$, $i_y \in [0, N_y)$, $i_z \in [0, N_z)$.

3.  **Narrow-Band Filtering**:
    Calculate the cube's minimum corner position in world space:
    $$ min = domain.min + \{ i_x \cdot cubeSize.x, i_y \cdot cubeSize.y, i_z \cdot cubeSize.z \} $$
    Calculate the cube center:
    $$ cubeCenter = min + HalfCubeSize $$
    Evaluate the SDF at the center:
    $$ dist = |sdf(cubeCenter) - isoLevel| $$
    **Pitfall**: If $dist > HalfCubeDiag$, the cube is too far from the surface to intersect it. Skip this cube and continue to the next iteration [S1, unofficial].

4.  **Vertex Sampling**:
    Construct the cube geometry. The 8 vertices $v_0 \dots v_7$ are located at the corners of the cube defined by `min` and `cubeSize`. The standard vertex ordering (consistent with the parent article's edge table) is:
    *   $v_0$: $(min.x, min.y, min.z)$
    *   $v_1$: $(min.x+sx, min.y, min.z)$
    *   $v_2$: $(min.x+sx, min.y+sy, min.z)$
    *   $v_3$: $(min.x, min.y+sy, min.z)$
    *   $v_4$: $(min.x, min.y, min.z+sz)$
    *   $v_5$: $(min.x+sx, min.y, min.z+sz)$
    *   $v_6$: $(min.x+sx, min.y+sy, min.z+sz)$
    *   $v_7$: $(min.x, min.y+sy, min.z+sz)$
    Evaluate $S_i = sdf(v_i)$ for $i=0..7$.

5.  **Case Index Calculation**:
    Compute the 8-bit case index $C$. If $S_i < isoLevel$ (or $> isoLevel$, depending on the specific LUT convention; the source uses a specific mapping where the sign determines the bit), set bit $i$ of $C$ to 1.
    *Note: The source code implies a specific bit-to-vertex mapping. Implementers must ensure the vertex ordering in step 4 matches the LUT generation assumptions [S1, unofficial].*

6.  **Edge Intersection**:
    Retrieve the intersected edge mask $M = signConfigToIntersectedEdges[C]$.
    For each edge $k \in [0, 11]$:
    If bit $k$ of $M$ is set:
    *   Get the edge endpoints $v_a, v_b$ from the `edges` table.
    *   Calculate the intersection point $P_{int}$ by linear interpolation:
        $$ \mu = \frac{isoLevel - S_a}{S_b - S_a} $$
        $$ P_{int} = v_a + \mu (v_b - v_a) $$
    *   Store $P_{int}$ in a list of intersection vertices for this cube.

7.  **Triangulation**:
    Use the `triangleTable` from the parent article [Marching Cubes Lookup and Configuration](2518-marching-cubes-lookup-and-configuration.md) indexed by $C$.
    *   Read triplets of edge indices $(e_a, e_b, e_c)$ until the terminator `-1` is reached.
    *   For each triplet, retrieve the corresponding intersection vertices calculated in Step 6.
    *   Add a triangle to the mesh with these vertices.
    *   If `sdfGrad` is provided, compute normals at vertices using the gradient; otherwise, approximate normals (e.g., from the SDF gradient at the vertex position) [S1, unofficial].

### Pseudocode

```python
def marching_cubes_narrow_band(sdf, domain, cube_size, iso_level=0.0, sdf_grad=None):
    """
    Reconstruct mesh from SDF using narrow-band filtering.
    """
    # 1. Grid Initialization
    num_x = ceil(domain.size.x / cube_size.x)
    num_y = ceil(domain.size.y / cube_size.y)
    num_z = ceil(domain.size.z / cube_size.z)
    
    half_cube_size = cube_size * 0.5
    half_cube_diag = norm(cube_size) / 2.0
    
    mesh = Mesh()
    
    # Pre-load lookup tables from parent article
    edge_table = load_edge_table() # 256 entries
    triangle_table = load_triangle_table() # 256 x 16 entries
    edge_vertices = [
        (0, 1), (1, 2), (2, 3), (3, 0), # Bottom
        (4, 5), (5, 6), (6, 7), (7, 4), # Top
        (0, 4), (1, 5), (2, 6), (3, 7)  # Vertical
    ]
    
    for ix in range(num_x):
        for iy in range(num_y):
            for iz in range(num_z):
                # 2. Voxel Iteration & 3. Narrow-Band Filtering
                min_corner = domain.min + vec3(ix * cube_size.x, iy * cube_size.y, iz * cube_size.z)
                cube_center = min_corner + half_cube_size
                
                dist_to_surface = abs(sdf(cube_center) - iso_level)
                
                if dist_to_surface > half_cube_diag:
                    continue
                
                # 4. Vertex Sampling
                # Define 8 vertices relative to min_corner
                vertices = [
                    min_corner,
                    min_corner + vec3(cube_size.x, 0, 0),
                    min_corner + vec3(cube_size.x, cube_size.y, 0),
                    min_corner + vec3(0, cube_size.y, 0),
                    min_corner + vec3(0, 0, cube_size.z),
                    min_corner + vec3(cube_size.x, 0, cube_size.z),
                    min_corner + vec3(cube_size.x, cube_size.y, cube_size.z),
                    min_corner + vec3(0, cube_size.y, cube_size.z)
                ]
                
                sdf_values = [sdf(v) for v in vertices]
                
                # 5. Case Index Calculation
                # Assuming bit i is set if sdf_values[i] < iso_level (check LUT convention)
                case_index = 0
                for i in range(8):
                    if sdf_values[i] < iso_level:
                        case_index |= (1 << i)
                
                # 6. Edge Intersection
                edge_mask = edge_table[case_index]
                intersection_points = []
                
                for edge_idx in range(12):
                    if (edge_mask >> edge_idx) & 1:
                        v1_idx, v2_idx = edge_vertices[edge_idx]
                        p1 = vertices[v1_idx]
                        p2 = vertices[v2_idx]
                        s1 = sdf_values[v1_idx]
                        s2 = sdf_values[v2_idx]
                        
                        # Linear interpolation
                        # Guard against division by zero if s1 == s2
                        if abs(s1 - s2) < 1e-9:
                            # If both are on the same side or exactly on iso, 
                            # standard MC handles this via the mask, but numerically:
                            # If mask is set, they must straddle. Use midpoint or p1.
                            # Source uses epsilon check: if abs(iso - v1) < Eps return p1
                            if abs(iso_level - s1) < 1e-5:
                                intersection_points.append(p1)
                            else:
                                intersection_points.append(p1) # Fallback
                        else:
                            mu = (iso_level - s1) / (s2 - s1)
                            p_int = p1 + mu * (p2 - p1)
                            intersection_points.append(p_int)
                
                # 7. Triangulation
                tri_indices = triangle_table[case_index]
                for k in range(0, 15, 3):
                    e1 = tri_indices[k]
                    e2 = tri_indices[k+1]
                    e3 = tri_indices[k+2]
                    
                    if e1 == -1:
                        break
                    
                    # Retrieve vertices from intersection_points list
                    # Note: intersection_points is ordered by edge index 0..11
                    p1 = intersection_points[e1]
                    p2 = intersection_points[e2]
                    p3 = intersection_points[e3]
                    
                    # Compute normal
                    if sdf_grad:
                        n1 = sdf_grad(p1)
                        n2 = sdf_grad(p2)
                        n3 = sdf_grad(p3)
                    else:
                        # Numerical approximation or geometric normal
                        # [G] Standard fallback: use cross product of edges if gradient unavailable
                        # However, SDFs usually allow gradient evaluation. 
                        # If not, approximate using neighbors or default to geometric.
                        # For strict implementation from source: "numerical approximation is used"
                        n1 = approximate_normal(sdf, p1)
                        n2 = approximate_normal(sdf, p2)
                        n3 = approximate_normal(sdf, p3)
                        
                    mesh.add_triangle(p1, p2, p3, n1, n2, n3)

    return mesh

def approximate_normal(sdf, point, h=1e-4):
    """Central difference gradient approximation."""
    dx = vec3(h, 0, 0)
    dy = vec3(0, h, 0)
    dz = vec3(0, 0, h)
    grad = vec3(
        sdf(point + dx) - sdf(point - dx),
        sdf(point + dy) - sdf(point - dy),
        sdf(point + dz) - sdf(point - dz)
    ) / (2 * h)
    return normalize(grad)
```

### Edge Cases and Pitfalls
*   **Narrow-Band Threshold**: The condition `dist > HalfCubeDiag` is critical. If `cubeSize` is large, this filter is less effective. If `cubeSize` is small, it may exclude valid cubes if the SDF is noisy [S1, unofficial].
*   **Ambiguity**: Cases 46, 47, 98, 99, 210, 213, 214, 215 contain topological ambiguities. The standard LUT resolves these with a fixed triangulation, which may cause cracks if adjacent voxels are processed inconsistently. This method does not inherently resolve ambiguity; it relies on the parent article's LUT [S7, S8, unofficial].
*   **Gradient Approximation**: If `sdfGrad` is null, numerical differentiation introduces error proportional to the grid resolution. For high-quality normals, an analytical gradient is preferred [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N_{cubes})$ where $N_{cubes}$ is the number of cubes in the narrow band. In the worst case (dense surface filling the domain), it is $O(N_x N_y N_z)$. In typical sparse SDF scenarios, it is significantly faster than full-domain Marching Cubes [S1, unofficial].
*   **Memory Complexity**: $O(N_{triangles})$ for the output mesh. The algorithm uses $O(1)$ auxiliary memory per cube (constant size LUTs and local variables) [S1, unofficial].
*   **Performance**: The narrow-band approach excludes cubes far from the surface, reducing the number of SDF evaluations and triangle generations [S1, unofficial].
*   **Strengths**: Fast for localized surfaces; simple implementation; no dependencies [S1, unofficial].
*   **Limitations**: Requires the SDF to be defined over the entire domain. Performance degrades if the narrow band is too wide (i.e., the surface is dense). Does not handle topological ambiguities automatically [S7, S8, unofficial].

## Background
The method is implemented in the `MeshReconstruction` library by Magnus2, which provides a self-contained C++14 implementation of the Marching Cubes algorithm with narrow-band filtering [S1, unofficial]. It is designed for efficiency and ease of use, exporting to Wavefront OBJ format [S1, unofficial]. The narrow-band optimization is a common technique in level-set methods to reduce computational cost when the interface is confined to a thin region [S1, unofficial].
