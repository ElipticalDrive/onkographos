# Marching Cubes with Narrow-Band Filtering

Also called: MeshReconstruction::MarchCube

## Overview
This method reconstructs a triangle mesh from a Signed Distance Function (SDF) by restricting the standard Marching Cubes algorithm to a "narrow band" of grid cells near the zero-level set. It solves the performance bottleneck of processing the entire volume by skipping cubes that are geometrically too far from the surface to intersect it. Unlike standard Marching Cubes which iterates over all voxels, this approach filters cubes based on the distance from the cube center to the isosurface, significantly reducing the number of intersection calculations required.

## How it works
**Inputs:**
- `domain`: A 3D bounding box defined by `min` (Vec3) and `size` (Vec3).
- `sdf`: A function `Fun3s` mapping a 3D position to a scalar distance value.
- `cubeSize`: The side length of the cubic grid cells (Vec3). If not provided, it is derived from `NumCubes` (default 50) as `domain.size / NumCubes`.
- `isoLevel`: The scalar value defining the surface (default 0).
- `sdfGrad`: Optional gradient function for vertex normals. If `nullptr`, normals are approximated numerically.

**Outputs:**
- `mesh`: A triangle mesh containing vertices and indices.

**Data Structures:**
- `Cube`: Represents a single grid cell.
  - `pos[8]`: Array of 8 vertex positions (Vec3).
  - `sdf[8]`: Array of 8 SDF values (double) at the vertices.
- `Edge`: Defines an edge of the cube.
  - `edgeFlag`: 12-bit integer representing the edge index (powers of 2: 1, 2, 4, ..., 2048).
  - `vert0`, `vert1`: Indices of the two vertices connected by the edge (0-7).
- `signConfigToIntersectedEdges`: A lookup table of 256 integers (12-bit bitstrings). Index is the configuration of signs at the 8 vertices. Value is a bitmask of intersected edges.

**Constants:**
- `HalfCubeSize`: `cubeSize * 0.5`.
- `HalfCubeDiag`: `cubeSize.Norm() / 2.0` (half the diagonal length of the cube).

**Algorithm Steps:**

1.  **Grid Initialization**:
    Calculate grid dimensions:
    $$ NumX = \lceil domain.size.x / cubeSize.x \rceil $$
    $$ NumY = \lceil domain.size.y / cubeSize.y \rceil $$
    $$ NumZ = \lceil domain.size.z / cubeSize.z \rceil $$

2.  **Iteration**:
    Iterate over grid indices $ix, iy, iz$ from $0$ to $NumX-1$, $NumY-1$, $NumZ-1$ respectively.

3.  **Cube Construction**:
    Calculate the minimum corner of the current cube in domain space:
    $$ min = domain.min + \{ ix \cdot cubeSize.x, iy \cdot cubeSize.y, iz \cdot cubeSize.z \} $$
    Calculate the cube center:
    $$ cubeCenter = min + HalfCubeSize $$
    Calculate the distance from the cube center to the isosurface:
    $$ dist = |sdf(cubeCenter) - isoLevel| $$

4.  **Narrow-Band Filtering**:
    If $dist > HalfCubeDiag$, the cube is too far from the surface to intersect it. Continue to the next cube. [S1, unofficial]

5.  **Vertex Sampling**:
    Construct the `Cube` object. Sample the SDF at the 8 vertices of the cube to populate `Cube.sdf[8]`. Store vertex positions in `Cube.pos[8]`.

6.  **Intersection**:
    Call `cube.Intersect(isoLevel)`.
    - Determine the sign configuration $C$ based on the signs of `Cube.sdf[8]` relative to `isoLevel`.
    - Look up intersected edges using `signConfigToIntersectedEdges[C]`.
    - For each intersected edge, calculate the intersection point using linear interpolation:
      $$ \mu = \frac{isoLevel - sdf[i_1]}{sdf[i_2] - sdf[i_1]} $$
      $$ P_{intersect} = pos[i_1] + (pos[i_2] - pos[i_1]) \cdot \mu $$
      Handle edge cases where $|isoLevel - sdf[i]| < \epsilon$ or $|sdf[i_1] - sdf[i_2]| < \epsilon$ by returning the vertex position directly. [S1, unofficial]

7.  **Triangulation**:
    Call `Triangulate(intersect, sdfGrad, mesh)`.
    - Use the standard Marching Cubes lookup table to determine which triangles to form from the intersection points.
    - If `sdfGrad` is provided, use it for vertex normals. Otherwise, compute normals numerically.
    - Add generated triangles to `mesh`.

**Pseudocode:**

```python
def MarchingCubesNarrowBand(domain, sdf, cube_size=None, iso_level=0.0, sdf_grad=None):
    if cube_size is None:
        num_cubes = 50
        cube_size = domain.size / num_cubes

    half_cube_size = cube_size * 0.5
    half_cube_diag = cube_size.norm() / 2.0

    num_x = ceil(domain.size.x / cube_size.x)
    num_y = ceil(domain.size.y / cube_size.y)
    num_z = ceil(domain.size.z / cube_size.z)

    mesh = Mesh()

    for ix in range(num_x):
        for iy in range(num_y):
            for iz in range(num_z):
                min_corner = domain.min + Vec3(ix * cube_size.x, iy * cube_size.y, iz * cube_size.z)
                cube_center = min_corner + half_cube_size
                
                dist = abs(sdf(cube_center) - iso_level)
                
                if dist > half_cube_diag:
                    continue

                cube = Cube(domain, sdf, min_corner, cube_size)
                cube.intersect(iso_level)
                cube.triangulate(sdf_grad, mesh)

    return mesh
```

## Operating characteristics
- **Time Complexity**: $O(N_{active})$, where $N_{active}$ is the number of cubes within the narrow band. This is significantly faster than $O(N_{total})$ for sparse surfaces or large volumes.
- **Memory Complexity**: Proportional to the number of active cubes and the resulting mesh size.
- **Strengths**: High performance for SDFs where the surface occupies a small fraction of the volume. No dependencies.
- **Limitations**: Requires a valid SDF. The narrow-band filter assumes the surface is smooth enough that a cube center far from the surface implies no intersection. If the surface is highly oscillatory or the grid is too coarse, intersections might be missed if the cube center is far but the surface passes through the cube corners. [S1, unofficial]

## Background
This method is implemented in the `MeshReconstruction` library by Magnus2. It leverages the standard Marching Cubes algorithm with a precomputed lookup table for edge intersections. The narrow-band optimization is specific to Signed Distance Functions, utilizing the geometric property that the distance from the cube center to the surface must be less than the cube's half-diagonal for an intersection to occur. The library is self-contained, requires C++14, and is licensed under MIT. [S1, unofficial]
