# Marching Cubes with Narrow-Band Filtering

Also called: MeshReconstruction::MarchCube

## Overview
This method reconstructs a triangle mesh from a Signed Distance Function (SDF) by restricting the Marching Cubes algorithm to a narrow band of voxels surrounding the zero-level set, thereby excluding cubes too far from the surface [S1, unofficial]. It differs from standard Marching Cubes by skipping the evaluation and triangulation of empty space, significantly reducing computational cost for sparse or bounded domains [S1, unofficial].

## How it works
**Inputs:**
*   `sdf`: A function or callable returning the signed distance value for any 3D point.
*   `domain`: A bounding box defined by `min` (Vec3) and `size` (Vec3).
*   `cubeSize`: The side length of the cubic voxels (Vec3). If not provided, defaults to `domain.size / 50` [S1, unofficial].
*   `isoLevel`: The isovalue for surface extraction, typically `0` for SDFs [S1, unofficial].
*   `sdfGrad`: An optional gradient function for vertex normals. If `nullptr`, normals are computed numerically [S1, unofficial].

**Data Structures:**
*   **Cube**: A class encapsulating the 8 vertex positions (`pos[8]`), 8 SDF values (`sdf[8]`), and the domain space.
*   **Edge**: A struct defining the 12 edges of a cube. Each edge has a 12-bit bitmask flag, and indices for its two vertices (`vert0`, `vert1`).
    *   Edge 0: `flag=1`, vertices `(0,1)`
    *   Edge 1: `flag=2`, vertices `(1,2)`
    *   ...
    *   Edge 11: `flag=2048`, vertices `(3,7)`
*   **signConfigToIntersectedEdges**: A lookup table of 256 integers (hexadecimal). Index $C$ (0–255) maps the 8-bit vertex sign configuration to a 12-bit bitmask of intersected edges.
    *   Example entries: `0x0`, `0x109`, `0x203`, ..., `0xf00` [S1, unofficial].
    *   Note: The source provides the full table but does not explicitly link it to the standard `edgeTable` topology; however, the bitmask logic matches the standard edge intersection definition.

**Algorithm Steps:**

1.  **Grid Setup**:
    Calculate grid dimensions:
    $$ NumX = \lceil domain.size.x / cubeSize.x \rceil $$
    $$ NumY = \lceil domain.size.y / cubeSize.y \rceil $$
    $$ NumZ = \lceil domain.size.z / cubeSize.z \rceil $$
    Calculate geometric constants:
    $$ HalfCubeDiag = \frac{\|cubeSize\|}{2.0} $$
    $$ HalfCubeSize = cubeSize \times 0.5 $$

2.  **Iterate Voxels**:
    Loop over grid indices $ix \in [0, NumX)$, $iy \in [0, NumY)$, $iz \in [0, NumZ)$.

3.  **Cube Positioning**:
    Calculate the minimum corner of the current cube:
    $$ min = domain.min + \{ ix \cdot cubeSize.x, iy \cdot cubeSize.y, iz \cdot cubeSize.z \} $$
    Calculate the cube center:
    $$ cubeCenter = min + HalfCubeSize $$

4.  **Narrow-Band Filter**:
    Evaluate the distance of the cube center to the isosurface:
    $$ dist = |sdf(cubeCenter) - isoLevel| $$
    If $dist > HalfCubeDiag$, the cube cannot intersect the isosurface. Continue to the next cube [S1, unofficial].

5.  **Vertex Sampling**:
    Construct a `Cube` object. Sample the SDF at the 8 vertices of the cube. Let $v_i$ be the position of vertex $i$ and $S_i = sdf(v_i)$ for $i=0..7$.

6.  **Case Index Calculation**:
    Determine the 8-bit case index $C$. If $S_i < isoLevel$ (or $> isoLevel$, depending on specific implementation convention, but standard is usually $< isoLevel$ for negative inside), set bit $i$ of $C$ to 1.
    $$ C = \sum_{i=0}^{7} \text{bit}_i $$
    *Note: The source code implies a specific bit ordering consistent with the `signConfigToIntersectedEdges` table.*

7.  **Edge Intersection**:
    Retrieve the intersected edges bitmask:
    $$ mask = signConfigToIntersectedEdges[C] $$
    For each edge $k \in [0, 11]$:
    If $(mask \gg k) \& 1$:
    Let $e$ be the $k$-th edge in the `edges` array.
    Calculate the intersection point $P$ on the edge using linear interpolation:
    $$ \mu = \frac{isoLevel - S_{e.vert0}}{S_{e.vert1} - S_{e.vert0}} $$
    $$ P = pos[e.vert0] + \mu \cdot (pos[e.vert1] - pos[e.vert0]) $$
    Store $P$ as the vertex for this edge.
    *Precision Guard*: If $|isoLevel - S_{e.vert0}| < \epsilon$ (where $\epsilon = 10^{-5}$), return $pos[e.vert0]$. If $|S_{e.vert0} - S_{e.vert1}| < \epsilon$, return $pos[e.vert0]$ [S1, unofficial].

8.  **Triangulation**:
    Use the `triangleTable` (from parent article) indexed by $C$ to determine triangle vertex indices (which refer to the 12 edges).
    For each triangle triplet $(a, b, c)$:
    Retrieve intersection points $P_a, P_b, P_c$.
    Compute normal $N$:
    If `sdfGrad` is provided:
    $$ N = sdfGrad(P_a) $$
    Else:
    $$ N = \text{numerical approximation} $$
    Add triangle $(P_a, P_b, P_c)$ with normal $N$ to the mesh.

## Operating characteristics
*   **Time Complexity**: $O(N_{active})$, where $N_{active}$ is the number of cubes within the narrow band. This is significantly faster than $O(N_{total})$ for large domains with small surfaces.
*   **Memory Complexity**: Proportional to the number of active cubes and the resulting mesh size.
*   **Strengths**: High performance for SDFs where the surface occupies a small fraction of the volume. No need to store the full grid if the SDF is evaluated on the fly.
*   **Limitations**: Requires the SDF to be available as a function. The narrow-band threshold (`HalfCubeDiag`) must be chosen carefully; if too small, the surface may be truncated.
*   **When to use**: When reconstructing meshes from implicit functions (SDFs) where the domain is large but the object is small.
*   **When not to use**: When the SDF is not available or too expensive to evaluate repeatedly, or when the surface is dense and fills most of the volume.
