# Marching Cubes with Narrow-Band Filtering

Also called: MeshReconstruction::MarchCube

## Overview
This method reconstructs a triangle mesh from a Signed Distance Function (SDF) by evaluating the field on a structured grid, filtering out cubes that are too distant from the isosurface (narrow-band filtering), and applying the standard Marching Cubes algorithm to the remaining cubes. It differs from naive Marching Cubes by skipping the vast majority of voxels that do not intersect the surface, significantly reducing computational cost for sparse or bounded domains. It builds on [Marching Cubes Lookup and Configuration](2518-marching-cubes-lookup-and-configuration.md).

## How it works
**Inputs:**
- `domain`: A 3D bounding box defined by `min` (Vec3) and `size` (Vec3).
- `sdf`: A function `Vec3 -> double` returning the signed distance at a point.
- `cubeSize`: The side length of the cubic grid cells (Vec3). If not provided, defaults to `domain.size / 50`.
- `isoLevel`: The scalar value defining the surface (default 0.0).
- `sdfGrad`: Optional function `Vec3 -> Vec3` returning the SDF gradient. If null, numerical approximation is used [S1, unofficial].

**Outputs:**
- `mesh`: A triangle mesh containing vertices and indices.

**Data Structures:**
1.  **Cube Object**:
    -   `pos[8]`: Array of 8 vertex positions (Vec3).
    -   `sdf[8]`: Array of 8 SDF values (double) at the vertices.
    -   `edges[12]`: Predefined edge definitions mapping edge index to vertex pairs and bit flags.
2.  **Lookup Tables**:
    -   `signConfigToIntersectedEdges[256]`: 12-bit bitmask array mapping the 256 vertex sign configurations to intersected edges. Bit $k$ corresponds to edge $k$ [S1, unofficial].
    -   `triangleTable`: Standard 256x16 table mapping case indices to triangle vertex edge indices [Parent].

**Parameters:**
-   `NumCubes`: Integer constant, default 50. Used to derive default `cubeSize` as `domain.size / NumCubes` [S1, unofficial].
-   `HalfCubeDiag`: `cubeSize.Norm() / 2.0`. The maximum distance from the cube center to any vertex [S1, unofficial].
-   `HalfCubeSize`: `cubeSize * 0.5` [S1, unofficial].
-   `Eps`: Precision epsilon, default $10^{-5}$ [S1, unofficial].

**Algorithm Steps:**

1.  **Grid Initialization**:
    Calculate grid dimensions:
    $$ N_x = \lceil \text{domain.size.x} / \text{cubeSize.x} \rceil $$
    $$ N_y = \lceil \text{domain.size.y} / \text{cubeSize.y} \rceil $$
    $$ N_z = \lceil \text{domain.size.z} / \text{cubeSize.z} \rceil $$
    [S1, unofficial]

2.  **Iterate Voxels**:
    For each grid index $(i_x, i_y, i_z)$ where $0 \le i_x < N_x$, etc.:
    a.  Calculate cube minimum corner:
        $$ \text{min} = \text{domain.min} + (i_x \cdot \text{cubeSize.x}, i_y \cdot \text{cubeSize.y}, i_z \cdot \text{cubeSize.z}) $$
        [S1, unofficial]
    b.  Calculate cube center:
        $$ \text{cubeCenter} = \text{min} + \text{HalfCubeSize} $$
        [S1, unofficial]
    c.  **Narrow-Band Filter**:
        Calculate distance from center to isosurface:
        $$ \text{dist} = | \text{sdf}(\text{cubeCenter}) - \text{isoLevel} | $$
        If $\text{dist} > \text{HalfCubeDiag}$, the cube cannot intersect the isosurface. Continue to next voxel [S1, unofficial].

3.  **Sample Vertices**:
    Construct the `Cube` object. Evaluate `sdf` at the 8 corners:
    $$ \text{pos}[k] = \text{min} + (b_0 \cdot \text{cubeSize.x}, b_1 \cdot \text{cubeSize.y}, b_2 \cdot \text{cubeSize.z}) $$
    where $b_0, b_1, b_2$ are the bits of $k$ (0-7).
    $$ \text{sdf}[k] = \text{sdf}(\text{pos}[k]) $$
    [S1, unofficial]

4.  **Determine Case Index**:
    Compute the 8-bit case index $C$. If $\text{sdf}[k] < \text{isoLevel}$ (or $> \text{isoLevel}$, consistent with LUT generation), set bit $k$ of $C$ to 1.
    [Parent, S1]

5.  **Intersect Edges**:
    Look up `intersectMask = signConfigToIntersectedEdges[C]`.
    For each edge $e$ (0-11):
    If `(intersectMask >> e) & 1`:
    a.  Identify vertex indices $v_0, v_1$ from `edges[e]`.
    b.  Calculate intersection point using linear interpolation:
        $$ \mu = \frac{\text{isoLevel} - \text{sdf}[v_0]}{\text{sdf}[v_1] - \text{sdf}[v_0]} $$
        $$ \text{intersectPoint} = \text{pos}[v_0] + \mu \cdot (\text{pos}[v_1] - \text{pos}[v_0]) $$
        Handle division by zero or near-zero denominator ($|\text{sdf}[v_1] - \text{sdf}[v_0]| < \text{Eps}$) by returning $\text{pos}[v_0]$ [S1, unofficial].
        Handle cases where $\text{sdf}[v_0] \approx \text{isoLevel}$ or $\text{sdf}[v_1] \approx \text{isoLevel}$ by returning the respective vertex [S1, unofficial].
    c.  Store the intersection point.

6.  **Triangulate**:
    Look up triangle definitions in `triangleTable[C]`.
    For each triplet $(a, b, c)$ in the table (terminated by -1):
    a.  Retrieve the three intersection points corresponding to edge indices $a, b, c$.
    b.  Compute vertex normal:
        If `sdfGrad` is provided, evaluate $\nabla \text{sdf}$ at the vertex.
        Otherwise, approximate numerically [S1, unofficial].
    c.  Add triangle to `mesh`.

**Pseudocode:**

```python
def marching_cubes_narrow_band(domain, sdf, cube_size=None, iso_level=0.0, sdf_grad=None):
    if cube_size is None:
        cube_size = domain.size / 50.0

    half_cube_diag = cube_size.norm() / 2.0
    half_cube_size = cube_size * 0.5
    eps = 1e-5

    num_x = ceil(domain.size.x / cube_size.x)
    num_y = ceil(domain.size.y / cube_size.y)
    num_z = ceil(domain.size.z / cube_size.z)

    mesh = Mesh()

    for ix in range(num_x):
        for iy in range(num_y):
            for iz in range(num_z):
                # Calculate cube bounds
                min_corner = domain.min + Vec3(ix * cube_size.x, iy * cube_size.y, iz * cube_size.z)
                cube_center = min_corner + half_cube_size

                # Narrow-band filter
                dist_to_surface = abs(sdf(cube_center) - iso_level)
                if dist_to_surface > half_cube_diag:
                    continue

                # Sample 8 vertices
                vertices = []
                sdf_values = []
                for k in range(8):
                    # Bit decomposition for vertex position
                    bx = (k >> 0) & 1
                    by = (k >> 1) & 1
                    bz = (k >> 2) & 1
                    pos = min_corner + Vec3(bx * cube_size.x, by * cube_size.y, bz * cube_size.z)
                    vertices.append(pos)
                    sdf_values.append(sdf(pos))

                # Calculate case index C
                # Convention: bit k is 1 if sdf_values[k] < iso_level (must match LUT)
                case_index = 0
                for k in range(8):
                    if sdf_values[k] < iso_level:
                        case_index |= (1 << k)

                # Get intersected edges mask
                intersected_mask = sign_config_to_intersected_edges[case_index]

                # Find intersection points on edges
                intersection_points = {}
                for edge_idx in range(12):
                    if (intersected_mask >> edge_idx) & 1:
                        v0_idx = edges[edge_idx].vert0
                        v1_idx = edges[edge_idx].vert1
                        p0 = vertices[v0_idx]
                        p1 = vertices[v1_idx]
                        s0 = sdf_values[v0_idx]
                        s1 = sdf_values[v1_idx]

                        # Linear interpolation
                        if abs(iso_level - s0) < eps:
                            pt = p0
                        elif abs(iso_level - s1) < eps:
                            pt = p1
                        elif abs(s1 - s0) < eps:
                            pt = p0
                        else:
                            mu = (iso_level - s0) / (s1 - s0)
                            pt = p0 + (p1 - p0) * mu
                        intersection_points[edge_idx] = pt

                # Triangulate
                triangles = triangle_table[case_index]
                for i in range(0, len(triangles), 3):
                    e0 = triangles[i]
                    e1 = triangles[i+1]
                    e2 = triangles[i+2]
                    if e0 == -1:
                        break
                    
                    p0 = intersection_points[e0]
                    p1 = intersection_points[e1]
                    p2 = intersection_points[e2]

                    # Normals
                    if sdf_grad:
                        n0 = sdf_grad(p0)
                        n1 = sdf_grad(p1)
                        n2 = sdf_grad(p2)
                    else:
                        # Numerical approximation placeholder [G]
                        n0 = numerical_gradient(sdf, p0)
                        n1 = numerical_gradient(sdf, p1)
                        n2 = numerical_gradient(sdf, p2)

                    mesh.add_triangle(p0, p1, p2, n0, n1, n2)

    return mesh
```

## Operating characteristics
-   **Time Complexity**: $O(N)$ where $N$ is the number of voxels in the grid. However, the narrow-band filter reduces the constant factor significantly by skipping non-intersecting cubes. The number of processed cubes is proportional to the surface area of the isosurface times the inverse of the cube size [S1, unofficial].
-   **Memory Complexity**: $O(N)$ for the grid iteration state, but $O(1)$ auxiliary memory per voxel. The output mesh size is proportional to the surface area.
-   **Performance**: The narrow-band approach excludes cubes far from the surface, making it much faster than naive Marching Cubes for sparse SDFs or large domains with small objects [S1, unofficial].
-   **Strengths**: Fast for bounded surfaces; simple implementation; low memory overhead for the extraction process itself.
-   **Limitations**: Requires the SDF to be defined over the entire domain; narrow-band threshold must be chosen carefully (too small misses parts of the surface, too large reduces benefits); does not handle topology ambiguities inherently (relies on parent LUT) [S1, Parent, unofficial].
-   **When to use**: When extracting a surface from a known bounded SDF where most of the volume is empty or irrelevant.
-   **When not to use**: When the domain is unbounded or the surface is extremely complex and fills the volume (filtering provides little benefit).

## Background
The method is implemented in the `MeshReconstruction` library by Magnus2, which provides a self-contained C++14 implementation [S1, unofficial]. It combines the classic Marching Cubes algorithm [S1, unofficial] with a narrow-band filtering strategy to optimize performance. The library exports to Wavefront OBJ format [S1, unofficial].
