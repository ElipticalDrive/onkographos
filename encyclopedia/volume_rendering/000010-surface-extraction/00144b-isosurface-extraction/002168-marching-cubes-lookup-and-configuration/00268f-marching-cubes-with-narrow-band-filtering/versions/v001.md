# Marching Cubes with Narrow-Band Filtering

Also called: MeshReconstruction::MarchCube

## Overview
A method to reconstruct a triangle mesh from a signed distance function (SDF) by evaluating the SDF on a grid of cubes, filtering cubes based on distance to the surface (narrow-band), and applying the Marching Cubes algorithm to intersected cubes [S1, unofficial]. It builds on [Marching Cubes Lookup and Configuration](2518-marching-cubes-lookup-and-configuration.md) by adding a spatial culling step that excludes cubes far from the surface, significantly reducing the number of cells processed [S1, unofficial].

## How it works
**Inputs:**
- `domain`: A 3D bounding box defined by `min` (Vec3) and `size` (Vec3).
- `sdf`: A function `Fun3s` taking a `Vec3` position and returning a scalar distance.
- `cubeSize`: A `Vec3` defining the dimensions of each grid cell. Defaults to `domain.size / 50` [S1, unofficial].
- `isoLevel`: The scalar value for the isosurface, defaulting to 0 [S1, unofficial].
- `sdfGrad`: An optional gradient function for vertex normals. If `nullptr`, numerical approximation is used [S1, unofficial].

**Outputs:**
- `mesh`: A triangle mesh containing the reconstructed surface.

**Data Structures:**
- `Cube`: Represents a single grid cell.
  - `pos[8]`: Array of 8 `Vec3` vertex positions in domain space.
  - `sdf[8]`: Array of 8 scalar SDF values at the vertices.
- `Edge`: Defines an edge of the cube.
  - `edgeFlag`: 12-bit integer flag (powers of 2: 1, 2, 4, ..., 2048).
  - `vert0`, `vert1`: Indices (0-7) of the cube's vertices connected by this edge.
- `signConfigToIntersectedEdges`: A lookup table of 256 integers (12-bit bitstrings), mapping the 8-bit sign configuration of the cube's vertices to the set of intersected edges [S1, unofficial].

**Geometric Constants:**
- `HalfCubeDiag = cubeSize.Norm() / 2.0`
- `HalfCubeSize = cubeSize * 0.5`

**Numbered Steps:**
1.  **Calculate Grid Dimensions:**
    Compute the number of cubes along each axis:
    $$NumX = \lceil domain.size.x / cubeSize.x \rceil$$
    $$NumY = \lceil domain.size.y / cubeSize.y \rceil$$
    $$NumZ = \lceil domain.size.z / cubeSize.z \rceil$$
    [S1, unofficial]

2.  **Iterate Grid:**
    Loop over indices $ix \in [0, NumX)$, $iy \in [0, NumY)$, $iz \in [0, NumZ)$.

3.  **Compute Cube Geometry:**
    Calculate the minimum corner of the current cube in domain space:
    $$min = domain.min + \{ix \cdot cubeSize.x, iy \cdot cubeSize.y, iz \cdot cubeSize.z\}$$
    Calculate the cube center:
    $$cubeCenter = min + HalfCubeSize$$
    [S1, unofficial]

4.  **Narrow-Band Filter:**
    Evaluate the SDF at the center: $d = sdf(cubeCenter)$.
    Calculate distance to the iso-surface:
    $$dist = |d - isoLevel|$$
    If $dist > HalfCubeDiag$, the cube is too far from the surface to intersect it. Continue to the next cube without processing [S1, unofficial].

5.  **Construct Cube:**
    Create a `Cube` object for the current cell. Sample the SDF at the 8 vertices to populate `Cube.sdf` and store vertex positions in `Cube.pos` [S1, unofficial].

6.  **Intersect:**
    Call `cube.Intersect(isoLevel)`. This determines which edges are intersected by the isosurface using the sign configuration of the 8 vertices and the `signConfigToIntersectedEdges` lookup table. It computes the exact intersection points on the edges via linear interpolation [S1, unofficial].

7.  **Triangulate:**
    Call `Triangulate(intersect, sdfGrad, mesh)`. Generate triangles from the intersection points and add them to the mesh. If `sdfGrad` is provided, use it for normals; otherwise, compute normals numerically [S1, unofficial].

**Pseudocode:**

```python
import math

def marching_cubes_narrow_band(domain_min, domain_size, cube_size, sdf, iso_level=0.0, sdf_grad=None):
    # 1. Calculate Grid Dimensions
    num_x = math.ceil(domain_size.x / cube_size.x)
    num_y = math.ceil(domain_size.y / cube_size.y)
    num_z = math.ceil(domain_size.z / cube_size.z)

    # 2. Geometric Constants
    half_cube_diag = math.sqrt(cube_size.x**2 + cube_size.y**2 + cube_size.z**2) / 2.0
    half_cube_size = (cube_size.x / 2.0, cube_size.y / 2.0, cube_size.z / 2.0)

    mesh = Mesh()

    # 3. Iterate Grid
    for ix in range(num_x):
        for iy in range(num_y):
            for iz in range(num_z):
                # 4. Compute Cube Geometry
                min_corner = (
                    domain_min.x + ix * cube_size.x,
                    domain_min.y + iy * cube_size.y,
                    domain_min.z + iz * cube_size.z
                )
                cube_center = (
                    min_corner[0] + half_cube_size[0],
                    min_corner[1] + half_cube_size[1],
                    min_corner[2] + half_cube_size[2]
                )

                # 5. Narrow-Band Filter
                dist_to_surface = abs(sdf(cube_center) - iso_level)
                if dist_to_surface > half_cube_diag:
                    continue

                # 6. Construct Cube
                cube = Cube(min_corner, cube_size, sdf)

                # 7. Intersect
                intersect = cube.intersect(iso_level)

                # 8. Triangulate
                triangulate(intersect, sdf_grad, mesh)

    return mesh

class Cube:
    def __init__(self, min_corner, cube_size, sdf):
        self.pos = []
        self.sdf_vals = []
        # Generate 8 vertices
        for i in range(8):
            x = min_corner[0] + ((i & 1) * cube_size.x)
            y = min_corner[1] + ((i & 2) * cube_size.y)
            z = min_corner[2] + ((i & 4) * cube_size.z)
            self.pos.append((x, y, z))
            self.sdf_vals.append(sdf((x, y, z)))

    def intersect(self, iso_level):
        # Determine sign configuration
        config = 0
        for i in range(8):
            if self.sdf_vals[i] > iso_level:
                config |= (1 << i)

        # Lookup intersected edges
        # signConfigToIntersectedEdges is a global lookup table of 256 entries
        intersected_edges_mask = signConfigToIntersectedEdges[config]

        intersections = []
        for edge_idx in range(12):
            if intersected_edges_mask & (1 << edge_idx):
                # Edge definition: edges[edge_idx] contains edgeFlag, vert0, vert1
                # Note: The source uses bit flags 1, 2, 4... corresponding to 1<<0, 1<<1...
                # We check if the bit corresponding to the edge index is set.
                # The source table maps config to a bitmask where bit k corresponds to edge k.
                # However, the source defines edges with flags 1, 2, 4... which are 1<<0, 1<<1...
                # So we check if (intersected_edges_mask >> edge_idx) & 1
                if (intersected_edges_mask >> edge_idx) & 1:
                    v0_idx = edges[edge_idx].vert0
                    v1_idx = edges[edge_idx].vert1
                    pt = lerp_vertex(iso_level, v0_idx, v1_idx)
                    intersections.append(pt)
        return intersections

def lerp_vertex(iso_level, i1, i2, pos, sdf_vals):
    eps = 1e-5
    v1 = sdf_vals[i1]
    v2 = sdf_vals[i2]
    p1 = pos[i1]
    p2 = pos[i2]

    if abs(iso_level - v1) < eps:
        return p1
    if abs(iso_level - v2) < eps:
        return p2
    if abs(v1 - v2) < eps:
        return p1

    mu = (iso_level - v1) / (v2 - v1)
    return (
        p1[0] + (p2[0] - p1[0]) * mu,
        p1[1] + (p2[1] - p1[1]) * mu,
        p1[2] + (p2[2] - p1[2]) * mu
    )
