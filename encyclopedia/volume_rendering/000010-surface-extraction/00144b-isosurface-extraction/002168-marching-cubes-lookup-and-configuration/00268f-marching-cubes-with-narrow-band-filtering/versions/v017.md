# Marching Cubes with Narrow-Band Filtering

Also called: MeshReconstruction::MarchCube

## Overview
This method reconstructs a triangle mesh from a Signed Distance Function (SDF) by evaluating the SDF on a regular grid of cubes, filtering out cubes that are too far from the surface (narrow-band filtering), and applying the standard Marching Cubes algorithm only to the intersected cubes [S1, unofficial]. It differs from standard Marching Cubes by skipping the vast majority of the domain volume, significantly reducing computation time for sparse or bounded surfaces, at the cost of requiring an SDF input rather than arbitrary scalar field data [S1, unofficial].

## How it works
**Inputs:**
- `domain`: A 3D bounding box defined by `min` (Vec3) and `size` (Vec3).
- `sdf`: A function `Fun3s` mapping a 3D position to a scalar distance value.
- `cubeSize`: The side length of the cubic grid cells (Vec3). If not provided, it is derived from `NumCubes` (default 50) as `domain.size / NumCubes` [S1, unofficial].
- `isoLevel`: The isovalue for surface extraction (default 0) [S1, unofficial].
- `sdfGrad`: An optional gradient function for vertex normals. If `nullptr`, numerical approximation is used [S1, unofficial].

**Outputs:**
- `mesh`: A collection of triangles (vertices and indices) representing the isosurface.

**Data Structures:**
- `Cube`: Represents a single grid cell.
  - `pos[8]`: Array of 8 vertex positions (Vec3).
  - `sdf[8]`: Array of 8 SDF values (double) at the vertices.
  - `edgeFlag`: 12-bit integer indicating which of the 12 edges are intersected.
- `edges[12]`: Static array defining the 12 edges of a cube. Each entry contains:
  - `edgeFlag`: Bitmask (1, 2, 4, ..., 2048).
  - `vert0`, `vert1`: Indices of the two vertices forming the edge (0-7).
- `signConfigToIntersectedEdges[256]`: Lookup table mapping the 8-bit sign configuration of the cube vertices to the 12-bit edge intersection mask [S1, unofficial].

**Algorithm Steps:**

1.  **Calculate Grid Dimensions:**
    Compute the number of cubes along each axis:
    $$
    \text{NumX} = \lceil \text{domain.size.x} / \text{cubeSize.x} \rceil
    $$
    $$
    \text{NumY} = \lceil \text{domain.size.y} / \text{cubeSize.y} \rceil
    $$
    $$
    \text{NumZ} = \lceil \text{domain.size.z} / \text{cubeSize.z} \rceil
    $$ [S1, unofficial]

2.  **Calculate Geometric Constants:**
    $$
    \text{HalfCubeSize} = \text{cubeSize} \times 0.5
    $$
    $$
    \text{HalfCubeDiag} = \|\text{cubeSize}\| / 2.0
    $$ [S1, unofficial]

3.  **Iterate Grid Cells:**
    For each grid index $(i_x, i_y, i_z)$ where $0 \le i_x < \text{NumX}$, etc.:
    
    a.  **Calculate Cube Position:**
        $$
        \text{min} = \text{domain.min} + \{i_x \cdot \text{cubeSize.x}, i_y \cdot \text{cubeSize.y}, i_z \cdot \text{cubeSize.z}\}
        $$
        $$
        \text{cubeCenter} = \text{min} + \text{HalfCubeSize}
        $$ [S1, unofficial]

    b.  **Narrow-Band Filter:**
        Calculate the distance from the cube center to the isosurface:
        $$
        \text{dist} = |\text{sdf}(\text{cubeCenter}) - \text{isoLevel}|
        $$
        If $\text{dist} > \text{HalfCubeDiag}$, the cube cannot intersect the surface. Continue to the next cube [S1, unofficial].

    c.  **Construct Cube Data:**
        Sample the SDF at the 8 vertices of the cube to populate `cube.sdf[8]`. Store vertex positions in `cube.pos[8]` [S1, unofficial].

    d.  **Determine Intersections:**
        Compute the sign configuration index $I$ by checking the sign of `cube.sdf[v]` relative to `isoLevel` for each vertex $v \in [0,7]$.
        Retrieve the intersected edges mask:
        $$
        \text{intersectedEdges} = \text{signConfigToIntersectedEdges}[I]
        $$ [S1, unofficial]

    e.  **Intersect Edges:**
        For each edge $e \in [0,11]$ where `(intersectedEdges >> e) & 1`:
        Get the edge definition `edges[e]`.
        Calculate the intersection point using linear interpolation:
        $$
        \mu = \frac{\text{isoLevel} - \text{sdf}[v_0]}{\text{sdf}[v_1] - \text{sdf}[v_0]}
        $$
        $$
        \text{point} = \text{pos}[v_0] + \mu (\text{pos}[v_1] - \text{pos}[v_0])
        $$
        Handle edge cases: if $|\text{isoLevel} - \text{sdf}[v_0]| < \epsilon$, return $\text{pos}[v_0]$. If $|\text{sdf}[v_0] - \text{sdf}[v_1]| < \epsilon$, return $\text{pos}[v_0]$ [S1, unofficial].

    f.  **Triangulate:**
        Use the standard Marching Cubes lookup table (based on `intersectedEdges`) to determine which triangles to form from the intersection points. Add these triangles to `mesh` [S1, unofficial].

    num_y = math.ceil(domain_size.y / cube_size.y)
    num_z = math.ceil(domain_size.z / cube_size.z)
    
    half_cube_size = cube_size * 0.5
    half_cube_diag = math.sqrt(cube_size.x**2 + cube_size.y**2 + cube_size.z**2) / 2.0

    # 2. Iterate Grid Cells
    for ix in range(num_x):
        for iy in range(num_y):

                # Define 8 vertices relative to min_corner
                vertices = [

                    min_corner + (cube_size.x, 0, 0),
                    min_corner + (cube_size.x, cube_size.y, 0),
                    min_corner + (0, cube_size.y, 0),
                    min_corner + (0, 0, cube_size.z),
                    min_corner + (cube_size.x, 0, cube_size.z),

**Edge Cases and Pitfalls:**
- **Precision:** Use a small epsilon ($\epsilon = 10^{-5}$) when comparing SDF values to the isovalue to avoid division by zero or unstable interpolation [S1, unofficial].
- **Boundary Conditions:** The grid traversal must strictly cover the `domain` without gaps or overlaps. `ceil` ensures full coverage [S1, unofficial].
- **Narrow-Band Limit:** If the surface is highly convoluted or the grid is too coarse, `HalfCubeDiag` filtering might exclude cubes that actually intersect the surface if the center is far but edges cross. However, for SDFs, the distance to the surface from the center is a reliable proxy for intersection likelihood [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of cubes in the grid. However, the constant factor is significantly reduced because only cubes within `HalfCubeDiag` of the surface are processed. For sparse surfaces, this is much faster than full volume Marching Cubes.
- **Memory Complexity:** $O(1)$ auxiliary space per cube (excluding the output mesh). The lookup tables are small and static.
- **Performance:** The method is described as "fast" due to the narrow-band approach excluding distant cubes and the use of precomputed lookup tables [S1, unofficial].
- **Strengths:** High performance for bounded surfaces; simple implementation; no dependencies [S1, unofficial].
- **Limitations:** Requires a Signed Distance Function (SDF) as input, not arbitrary scalar fields; mesh quality depends on grid resolution; may produce artifacts if the grid is too coarse relative to surface curvature [S1, unofficial].
- **When to use:** When reconstructing surfaces from SDFs (e.g., from implicit models, neural networks, or voxel data) where the surface is localized within a known bounding box.
- **When not to use:** When the input is not an SDF; when the surface extends beyond the bounding box; when high-fidelity geometry requires adaptive refinement not provided by this fixed-grid approach.

## Background
The method is implemented in the `MeshReconstruction` library by Magnus2, released under the MIT License [S1, unofficial]. It builds upon the classic Marching Cubes algorithm [S1, unofficial]. The library is self-contained, requires C++14, and has been tested on Windows 10 with Visual Studio 2017, though it is portable [S1, unofficial]. The narrow-band filtering technique is a common optimization in isosurface extraction to reduce computational load when the surface occupies a small fraction of the domain volume.
