# Marching Cubes with Narrow-Band Filtering

Also called: MeshReconstruction::MarchCube

## Overview
This method reconstructs a triangle mesh from a Signed Distance Function (SDF) by evaluating the function on a regular grid of cubes, filtering out cubes that are too far from the surface (narrow-band filtering), and applying the standard Marching Cubes algorithm to the remaining cubes. It differs from standard Marching Cubes by skipping the vast majority of the domain volume, significantly reducing computation time for sparse or bounded surfaces, at the cost of requiring an SDF input rather than arbitrary scalar field data.

## How it works
**Inputs and Outputs:**
- **Input:** A signed distance function $SDF(\mathbf{p})$, a bounding domain defined by minimum corner $\mathbf{min}$ and size vector $\mathbf{size}$, a target isovalue (typically $0$), and optional gradient function $SDFGrad(\mathbf{p})$.
- **Output:** A triangle mesh (list of vertices and indices).

**Data Structures:**
- **Cube:** Represents a single voxel in the grid.
  - `pos[8]`: Array of 8 vertex positions in world space.
  - `sdf[8]`: Array of 8 SDF values at the vertices.
  - `intersect[12]`: Array of 12 intersection points on the cube edges.
- **Edge Table:** A lookup table `signConfigToIntersectedEdges[256]` mapping the 8-bit sign configuration of cube vertices to a 12-bit bitmask indicating which of the 12 cube edges are intersected by the isosurface.
- **Edge Definitions:** An array `edges[12]` defining the 12 edges of a cube. Each edge entry contains:
  - `edgeFlag`: A 12-bit integer power of 2 ($2^0$ to $2^{11}$) corresponding to the bit position in the lookup table.
  - `vert0`, `vert1`: Indices (0-7) of the two vertices defining the edge.

**Parameters:**
- `NumCubes`: Integer constant, default 50. Determines grid resolution. Cube size is calculated as $\mathbf{size} / NumCubes$.
- `isoLevel`: The scalar value defining the surface. Default 0.
- `sdfGrad`: Optional function for vertex normals. If null, normals are not computed or approximated numerically.

**Algorithm Steps:**

1.  **Calculate Grid Dimensions:**
    Compute the number of cubes along each axis:
    $$ N_x = \lceil \frac{\mathbf{size}.x}{\mathbf{cubeSize}.x} \rceil $$
    $$ N_y = \lceil \frac{\mathbf{size}.y}{\mathbf{cubeSize}.y} \rceil $$
    $$ N_z = \lceil \frac{\mathbf{size}.z}{\mathbf{cubeSize}.z} \rceil $$
    Where $\mathbf{cubeSize} = \mathbf{size} / NumCubes$.

2.  **Calculate Geometric Constants:**
    $$ \mathbf{HalfCubeSize} = \mathbf{cubeSize} \times 0.5 $$
    $$ \mathbf{HalfCubeDiag} = \frac{\|\mathbf{cubeSize}\|}{2.0} $$

3.  **Iterate Grid:**
    For each grid index $(i_x, i_y, i_z)$ where $0 \le i_x < N_x$, $0 \le i_y < N_y$, $0 \le i_z < N_z$:

    a.  **Calculate Cube Bounds:**
        $$ \mathbf{min} = \mathbf{domain.min} + (i_x \cdot \mathbf{cubeSize}.x, i_y \cdot \mathbf{cubeSize}.y, i_z \cdot \mathbf{cubeSize}.z) $$
        $$ \mathbf{cubeCenter} = \mathbf{min} + \mathbf{HalfCubeSize} $$

    b.  **Narrow-Band Filter:**
        Calculate the distance from the cube center to the isosurface:
        $$ dist = |SDF(\mathbf{cubeCenter}) - isoLevel| $$
        If $dist > \mathbf{HalfCubeDiag}$, the cube cannot intersect the isosurface. Continue to the next cube. [S1, unofficial]

    c.  **Sample Vertices:**
        Construct the cube geometry. The 8 vertices $\mathbf{v}_k$ ($k=0..7$) are the corners of the cube defined by $\mathbf{min}$ and $\mathbf{min} + \mathbf{cubeSize}$.
        Evaluate $SDF(\mathbf{v}_k)$ for all 8 vertices.

    d.  **Determine Configuration:**
        Create an 8-bit integer `config`. For each vertex $k$, if $SDF(\mathbf{v}_k) < isoLevel$, set bit $k$ to 1; otherwise 0.

    e.  **Find Intersections:**
        Look up `mask = signConfigToIntersectedEdges[config]`.
        For each edge $e$ from 0 to 11:
        If `(mask >> e) & 1` is true:
        Let the edge connect vertices $v_a$ and $v_b$.
        Calculate the intersection point $\mathbf{p}_{int}$ using linear interpolation:
        $$ \mu = \frac{isoLevel - SDF(\mathbf{v}_a)}{SDF(\mathbf{v}_b) - SDF(\mathbf{v}_a)} $$
        $$ \mathbf{p}_{int} = \mathbf{v}_a + \mu (\mathbf{v}_b - \mathbf{v}_a) $$
        Store $\mathbf{p}_{int}$ in the cube's intersection array for this edge.
        *Note: Handle division by zero or near-zero denominator by returning one of the endpoints if $|SDF(\mathbf{v}_a) - SDF(\mathbf{v}_b)| < \epsilon$.* [S1, unofficial]

    f.  **Triangulate:**
        Use the standard Marching Cubes lookup table (derived from `config` and `mask`) to determine which triangles to form from the intersection points. Add these triangles to the output mesh.

**Pseudocode:**

```python
import math

def marching_cubes_narrow_band(sdf, domain_min, domain_size, num_cubes=50, iso_level=0.0, sdf_grad=None):
    """
    Reconstruct mesh from SDF using narrow-band filtering.
    """
    # 1. Calculate Grid Dimensions
    cube_size = domain_size / num_cubes
    num_x = math.ceil(domain_size.x / cube_size.x)
    num_y = math.ceil(domain_size.y / cube_size.y)
    num_z = math.ceil(domain_size.z / cube_size.z)
    
    half_cube_size = cube_size * 0.5
    half_cube_diag = math.sqrt(cube_size.x**2 + cube_size.y**2 + cube_size.z**2) / 2.0
    
    mesh_vertices = []
    mesh_faces = []
    
    # Predefined Marching Cubes edge table and edge definitions
    # signConfigToIntersectedEdges[256] and edges[12] as defined in sources
    # For brevity, assume these are available as global constants or lookups
    # edges[e] = (edge_flag, vert0_idx, vert1_idx)
    
    for ix in range(num_x):
        for iy in range(num_y):
            for iz in range(num_z):
                # 2. Calculate Cube Bounds
                min_corner = domain_min + (ix * cube_size.x, iy * cube_size.y, iz * cube_size.z)
                cube_center = min_corner + half_cube_size
                
                # 3. Narrow-Band Filter
                dist_to_surface = abs(sdf(cube_center) - iso_level)
                if dist_to_surface > half_cube_diag:
                    continue
                
                # 4. Sample Vertices
                # Generate 8 corners of the cube
                corners = []
                for dx in [0, 1]:
                    for dy in [0, 1]:
                        for dz in [0, 1]:
                            p = min_corner + (dx * cube_size.x, dy * cube_size.y, dz * cube_size.z)
                            corners.append(p)
                            
                sdf_values = [sdf(p) for p in corners]
                
                # 5. Determine Configuration
                config = 0
                for k in range(8):
                    if sdf_values[k] < iso_level:
                        config |= (1 << k)
                        
                # 6. Find Intersections
                mask = signConfigToIntersectedEdges[config]
                intersections = [None] * 12
                
                for e in range(12):
                    if (mask >> e) & 1:
                        edge_flag, v0_idx, v1_idx = edges[e]
                        p0 = corners[v0_idx]
                        p1 = corners[v1_idx]
                        s0 = sdf_values[v0_idx]
                        s1 = sdf_values[v1_idx]
                        
                        # Linear interpolation
                        denom = s1 - s0
                        if abs(denom) < 1e-5:
                            # Degenerate case, return one endpoint
                            intersections[e] = p0
                        else:
                            mu = (iso_level - s0) / denom
                            intersections[e] = p0 + (p1 - p0) * mu
                            
                # 7. Triangulate
                # Standard Marching Cubes logic based on config and intersections
                # This part depends on the specific triangulation table for the 256 cases
                # Assuming a function triangulate_cube(config, intersections, mesh) exists
                triangulate_cube(config, intersections, mesh_vertices, mesh_faces)
                
    return mesh_vertices, mesh_faces
```

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of cubes in the narrow band. The narrow-band filter reduces the effective $N$ from the total volume grid size to only those cubes intersecting the surface.
- **Memory Complexity:** $O(N)$ for storing the cube data and output mesh.
- **Performance:** Significantly faster than standard Marching Cubes for large volumes with small surface areas because it avoids processing empty space. [S1, unofficial]
- **Strengths:** Fast, simple, produces watertight meshes if the SDF is well-behaved. [S1, unofficial]
- **Limitations:** Requires a Signed Distance Function. Cannot handle arbitrary scalar fields directly. Resolution is limited by the grid size (`NumCubes`). [S1, unofficial]
