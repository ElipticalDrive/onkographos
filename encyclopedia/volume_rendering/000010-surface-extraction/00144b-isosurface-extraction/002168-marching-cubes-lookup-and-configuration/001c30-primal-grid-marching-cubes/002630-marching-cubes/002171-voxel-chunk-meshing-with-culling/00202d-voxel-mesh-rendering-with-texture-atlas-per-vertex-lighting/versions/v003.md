# Voxel Mesh Rendering with Texture Atlas & Per-Vertex Lighting

Also called: Chunk Mesh Rendering, Voxel Meshing with Atlas UVs

## Overview
This method renders voxel chunks as triangle meshes using a horizontal texture atlas for block faces, applying per-vertex ambient occlusion (AO) and smooth light in the fragment shader with directional lighting [S1]. It differs from [Naive Voxel Meshing](2376-naive-voxel-meshing.md) by using a shared atlas to reduce texture bind calls, and from [GPU Marching Cubes (Face-based)](3674-gpu-marching-cubes-face-based.md) by relying on axis-aligned quads rather than isosurfaces [S1].

## How it works
**Inputs and Outputs**
- **Input**: A voxel chunk, a set of 16×16 tile images for block faces, and camera matrices [S1].
- **Output**: A rendered image containing opaque, two-sided, and transparent geometry [S1].

**Data Structures**
The vertex structure contains the following fields [S1]:
- `pos`: `Vec4<f32>` (position in world space, w=1.0).
- `uv`: `Vec2<f32>` (local UV coordinates within the tile, typically 0.0 to 1.0).
- `normal`: `Vec3<f32>` (face normal).
- `ao`: `f32` (ambient occlusion, normalized).
- `smooth_light`: `f32` (smooth lighting value, normalized).
- `block`: `MyBlock` (enum identifying the block type).
- `atlas_offset`: `f32` (U-offset in the atlas strip, representing the tile index).
- `two_sided`: `bool` (flag for backface culling behavior).

The interpolated vertex shader output (`VsOut`) passed to the fragment shader includes [S1]:
- `uv`: `Vec2<f32>`
- `normal`: `Vec3<f32>`
- `atlas_u_offset`: `f32`
- `ao`: `f32`
- `smooth_light`: `f32`

**Texture Atlas Layout**
The atlas is a `Buffer2d` (2D texture) constructed by concatenating 16×16 tile images horizontally [S1].
- **Width**: `tiles.len() * 16`
- **Height**: `16`
- Each block type and face direction maps to a specific U-offset (0.0 to 14.0 representing the tile index) [S1]. Cactus blocks use different offsets for top/bottom faces versus side faces [S1].

**Numbered Steps**
1. **Build Texture Atlas**: Load individual 16×16 tile images and concatenate them into a single horizontal strip [S1].
2. **Generate Mesh**: For each visible face in the chunk (processed via [Voxel Chunk Meshing with Culling](2523-voxel-chunk-meshing-with-culling.md)):
   a. Determine the block type and face orientation [S1].
   b. Calculate the `atlas_offset` based on block type and face direction [S1].
   c. Determine if the geometry is `two_sided` (diagonal faces or facades) [S1].
   d. Compute vertex attributes: position, UV, normal, AO (raw value divided by 3.0), smooth light (raw value divided by 15.0), block type, atlas offset, and two-sided flag [S1].
   e. Use anisotropy-corrected indices to ensure proper interpolation of AO across shared vertices [S1].
3. **Render Opaque Geometry**: Draw non-two-sided vertices with backface culling enabled [S1].
4. **Render Two-Sided Geometry**: Draw two-sided vertices (cross-shaped billboards, facades) without backface culling [S1].
5. **Render Transparent Geometry**: Draw transparent blocks with appropriate blending [S1].

**Formulas**
The lighting calculation in the fragment shader is [S1]:

$$
shade = (ambient + (1.0 - ambient) \cdot \max(0.0, \mathbf{n} \cdot \mathbf{l})) \cdot ao + smooth\_light \cdot 0.6
$$

Where:
- $ambient = 0.35$ [S1]
- $\mathbf{l} = \text{normalize}(0.4, 0.7, 0.5)$ [S1]
- $\mathbf{n}$ is the vertex normal [S1]
- $ao \in [0, 1]$ is the interpolated ambient occlusion value [S1]
- $smooth\_light \in [0, 1]$ is the interpolated smooth light value [S1]

**Parameters**
- `ambient`: 0.35 [S1]
- `light_dir`: (0.4, 0.7, 0.5) [S1]
- `smooth_light_weight`: 0.6 [S1]
- `tile_size`: 16 [S1]

**Edge Cases and Pitfalls**
- **Atlas UV Wrapping**: Use `rem_euclid(1.0)` to handle UV wrapping and clamp to `atlas_size[0] - 1` to prevent out-of-bounds texture fetches [S1].
- **Alpha Blending**: Use a threshold of 0.01 to skip blending for near-zero alpha values, preventing visual artifacts [S1].
- **AO Interpolation**: Ensure indices are anisotropy-corrected to avoid incorrect AO values at shared vertices between faces with different orientations [S1].

**Pseudocode**
```python
def render_voxel_chunk(chunk, tile_images, mvp):
    # 1. Build Texture Atlas
    num_tiles = len(tile_images)
    atlas_width = num_tiles * 16
    atlas_height = 16
    atlas = [[0.0] * atlas_width for _ in range(atlas_height)]
    for i, tile in enumerate(tile_images):
        for y in range(16):
            for x in range(16):
                atlas[y][i * 16 + x] = tile[y][x]

    # 2. Generate Vertices
    vertices = []
    for quad in chunk.visible_quads:
        lit_block = quad.block
        two_sided = quad.is_diagonal or quad.shape == "FACADE"
        atlas_off = quad.block.u_offset(quad.face)

        indices = quad.anisotropy_corrected_indices()
        for idx in indices:
            vertices.append({
                "pos": [quad.positions[idx].x, quad.positions[idx].y, quad.positions[idx].z, 1.0],
                "uv": quad.uvs[idx],
                "normal": quad.normal,
                "ao": quad.ao[idx] / 3.0,
                "smooth_light": quad.light[idx] / 15.0,
                "block": lit_block,
                "atlas_offset": atlas_off,
                "two_sided": two_sided
            })

    # 3. Render Opaque Geometry
    opaque = [v for v in vertices if not v["two_sided"] and v["block"].is_opaque]
    # Standard MVP transformation, backface culling, and triangle rasterization [G]
    rasterize(opaque, atlas, mvp, cull_mode="BACK")

    # 4. Render Two-Sided Geometry
    two_sided = [v for v in vertices if v["two_sided"]]
    # Standard MVP transformation, no culling, and triangle rasterization [G]
    rasterize(two_sided, atlas, mvp, cull_mode="NONE")

    # 5. Render Transparent Geometry
    transparent = [v for v in vertices if v["block"].is_transparent]
    # Standard MVP transformation, no culling, alpha blending, and rasterization [G]
    rasterize(transparent, atlas, mvp, cull_mode="NONE", blend=True)

def fragment_shader(uv, normal, atlas_u_offset, ao, smooth_light, atlas, num_tiles):
    atlas_width = len(atlas[0])
    atlas_height = len(atlas)

    tile_u = atlas_u_offset * 16.0
    atlas_uv_x = (uv[0] + tile_u) / atlas_width
    atlas_uv_y = uv[1] / atlas_height

    # Clamp to valid width to prevent out-of-bounds fetches [S1]
    atlas_uv_x = min(atlas_uv_x, (atlas_width - 1) / atlas_width)

    color = sample_atlas(atlas, atlas_uv_x, atlas_uv_y)

    ambient = 0.35
    light_dir = normalize([0.4, 0.7, 0.5])
    smooth_light_weight = 0.6

    diffuse = max(0.0, dot(normal, light_dir))
    shade = (ambient + (1.0 - ambient) * diffuse) * ao + smooth_light * smooth_light_weight

    # Skip blending for near-zero alpha to prevent artifacts [S1]
    if color[3] < 0.01:
        return [c * shade for c in color]
    return [c * shade for c in color]

def sample_atlas(atlas, u, v):
    # Standard point sample from 2D texture array [G]
    width = len(atlas[0])
    height = len(atlas)
    u_idx = int(u * width) % width
    v_idx = int(v * height) % height
    return atlas[v_idx][u_idx]
```
