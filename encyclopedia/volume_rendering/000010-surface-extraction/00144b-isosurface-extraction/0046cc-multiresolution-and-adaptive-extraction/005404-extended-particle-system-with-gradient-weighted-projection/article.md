# Extended Particle System with Gradient-Weighted Projection

Also called: decoupled particle iteration

## Overview
A surface extraction method using a particle system where repulsive and attractive forces are decoupled in time, using gradient-weighted projection to settle particles on the isosurface and Voronoi diagrams for incremental insertion [S1, unofficial]. It sets itself apart from sibling methods by explicitly separating the temporal dynamics of attraction (projection to the isosurface) and repulsion (distribution optimization), allowing for adaptive weighting between grayscale and second-order gradient terms during the projection phase [S1, unofficial].

## How it works
**Inputs:**
*   A discretized scalar field $f(\mathbf{x})$ defined on a voxel pyramid (multiresolution grid).
*   A target isosurface scalar value $f_0$.
*   Parameters: $\alpha$ (dynamic weight for grayscale projection), $\beta$ (dynamic weight for Laplacian projection).

**Outputs:**
*   A set of particle positions $\{\mathbf{p}_i\}$ representing the extracted isosurface.

**Data Structures:**
*   **Particle:** Contains position $\mathbf{p}$, velocity (implicit in displacement $\Delta \mathbf{p}$), and status.
*   **Voxel Pyramid:** Hierarchical grid levels from coarse to fine.
*   **Gradient Field:** First-order gradient $\nabla f(\mathbf{p})$ interpolated from the scalar field.
*   **Laplacian Field:** Second-order gradient (Laplacian) $\nabla^2 f(\mathbf{p})$ interpolated from the scalar field.

**Algorithm Steps:**

1.  **Pyramid Construction:** Construct a voxel pyramid from the input scalar field. [S1, unofficial]
2.  **Initialization:**
    *   Traverse the coarsest scale of the voxel pyramid.
    *   Identify "response units" (cells indicating surface presence).
    *   For each response unit, create one particle at the approximate position corresponding to the mesh center generated by the Marching Cubes (MC) algorithm lookup table for that cell. [S1, unofficial]
    *   Apply small random perturbations to initial particle positions using the Mersenne Twister algorithm to avoid local extrema caused by symmetry. [S1, unofficial]
3.  **Iteration Loop (until equilibrium or max levels):**
    *   **Gradient-Weighted Projection (Attraction):**
        *   Define deviation: $\phi(\mathbf{p}) = f(\mathbf{p}) - f_0$ [S1, unofficial].
        *   Compute first-order Taylor expansion: $\phi(\mathbf{p} + \Delta \mathbf{p}) \approx \phi(\mathbf{p}) + \nabla f(\mathbf{p}) \cdot \Delta \mathbf{p}$ [S1, unofficial].
        *   Set approximation to zero and solve for displacement direction using gradient $\nabla f(\mathbf{p})$: $\Delta \mathbf{p} = \lambda \nabla f(\mathbf{p})$ [S1, unofficial].
        *   Compute grayscale projection term $\Delta \mathbf{p}_{grayscale}$ and Laplacian projection term $\Delta \mathbf{p}_{lapdaction}$ (based on second-order gradient/zero-crossings) [S1, unofficial].
        *   Combine with dynamic weights: $\Delta \mathbf{p} = \alpha \cdot \Delta \mathbf{p}_{grayscale} + \beta \cdot \Delta \mathbf{p}_{lapdaction}$ [S1, unofficial].
        *   Update particle position: $\mathbf{p} \leftarrow \mathbf{p} + \Delta \mathbf{p}$.
        *   *Weight Scheduling:* In early iterations, $\alpha$ is high and $\beta$ is low (grayscale dominates for fast convergence). In late iterations, $\alpha$ decreases and $\beta$ increases (Laplacian dominates for fine edge adjustment) [S1, unofficial].
    *   **Repulsion (Distribution Optimization):**
        *   Treat repulsion as a local short-range force.
        *   Extract the tangential component of the repulsive force relative to the surface normal.
        *   Apply this tangential component to optimize particle distribution among neighbors. [S1, unofficial]
    *   **Equilibrium Check:**
        *   Calculate average particle displacement across the system.
        *   If average displacement > threshold, continue iteration. [S1, unofficial]
4.  **Incremental Insertion:**
    *   When equilibrium is reached at a given scale, construct a Voronoi diagram of the current particle set.
    *   Identify regions with high curvature or large Voronoi cell areas.
    *   Insert new particles in these regions to refine the surface representation. [S1, unofficial]
5.  **Refinement:**
    *   Move to the next finer level of the voxel pyramid.
    *   Repeat steps 3-4 using the refined particle set as initialization for the finer scale. [S1, unofficial]

**Pseudocode:**

> **Unverified code.** The code below did not pass a test run against a reference implementation, or no test fits it, so it may contain errors.

```python
def extended_particle_system_extraction(scalar_field, f0, pyramid_levels):
    # 1. Initialize particles at coarsest level
    particles = []
    coarsest_grid = pyramid_levels[0]
    
    for cell in coarsest_grid.cells:
        if is_response_unit(cell):
            # Get approximate center from MC lookup table
            p = get_mc_mesh_center(cell)
            # Add small random perturbation using Mersenne Twister
            p += mersenne_twister_random_small_vector()
            particles.append(Particle(position=p))
            
    # 2. Iterate through pyramid levels
    for level in pyramid_levels:
        while not is_equilibrium(particles):
            for particle in particles:
                p = particle.position
                grad = interpolate_gradient(scalar_field, p)
                laplacian = interpolate_laplacian(scalar_field, p)
                
                # Gradient-Weighted Projection
                # Compute grayscale and laplacian displacement components
                # Note: Exact formulas for delta_p_grayscale and delta_p_lapdaction 
                # are derived from Newton iteration and zero-crossing logic [S1, unofficial]
                delta_p_grayscale = compute_grayscale_projection(p, grad, f0)
                delta_p_lapdaction = compute_laplacian_projection(p, laplacian, f0)
                
                # Dynamic weights: alpha high early, beta high late
                alpha = get_dynamic_alpha(iteration_count)
                beta = get_dynamic_beta(iteration_count)
                
                delta_p = alpha * delta_p_grayscale + beta * delta_p_lapdaction
                particle.position += delta_p
                
            # Repulsion: Tangential component extraction
            for particle in particles:
                neighbors = get_nearby_particles(particle, short_range_radius)
                for neighbor in neighbors:
                    repulsive_force = compute_repulsion(particle.position, neighbor.position)
                    # Extract tangential component relative to surface normal
                    normal = interpolate_gradient(scalar_field, particle.position)
                    tangential_force = extract_tangential_component(repulsive_force, normal)
                    particle.position += tangential_force * repulsion_weight
                    
        # 3. Incremental Insertion via Voronoi
        voronoi = construct_voronoi_diagram(particles)
        for cell in voronoi.cells:
            if is_high_curvature(cell) or cell.area > threshold:
                new_p = get_voronoi_cell_center(cell)
                new_p += mersenne_twister_random_small_vector()
                particles.append(Particle(position=new_p))
                
    return particles
```

**Parameters:**
*   $\alpha$: Dynamic weight coefficient for the grayscale projection term. High in early iteration, low in late iteration [S1, unofficial].
*   $\beta$: Dynamic weight coefficient for the Laplacian projection term. Low in early iteration, high in late iteration [S1, unofficial].
*   Threshold for equilibrium: Not given in the sources.
*   Short-range radius for repulsion: Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Symmetry:** Initial particle distribution symmetry can cause local extrema traps. Mitigated by Mersenne Twister perturbations [S1, unofficial].
*   **Gradient Magnitude:** In regions with small gradients, step size is enlarged to accelerate convergence; in large gradients, step size is reduced for accuracy [S1, unofficial].
*   **Equilibrium Definition:** Average particle displacement is used as an approximation of the 'energy gradient' [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Decoupling forces allows for better distribution optimization and precise surface settling. Gradient-weighted projection provides adaptive convergence speed and accuracy. Voronoi-based insertion allows for local refinement in high-curvature areas. [S1, unofficial]
*   **Limitations:** Requires construction of voxel pyramid and gradient/Laplacian fields. Equilibrium checking may be computationally expensive if convergence is slow. [S1, unofficial]
*   **When to use:** Suitable for industrial CT data and other scalar fields where precise surface extraction and adaptive refinement are needed. [S1, unofficial]

## Background
Originated in the paper "Surface Extraction for Industrial CT Based On Adaptive Particle System" [S1, unofficial]. The method builds on traditional particle system-based surface extraction algorithms but introduces decoupled force mechanisms and gradient-weighted projection. It is designed for industrial CT data, leveraging multiresolution voxel pyramids for efficient processing. [S1, unofficial]
