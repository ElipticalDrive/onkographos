# Extended Particle System with Gradient-Weighted Projection

Also called: decoupled particle iteration

## Overview
A surface extraction method using a particle system where repulsive and attractive forces are decoupled in time, using gradient-weighted projection to settle particles on the isosurface and Voronoi diagrams for incremental insertion [S1, unofficial]. It sets itself apart from sibling methods by explicitly separating the temporal dynamics of attraction (projection to the isosurface) and repulsion (distribution optimization), allowing for adaptive weighting between grayscale and second-order gradient terms during the projection phase [S1, unofficial]. The method builds on traditional particle system-based surface extraction algorithms but introduces decoupled force mechanisms and gradient-weighted projection [S1, unofficial].

## How it works
**Inputs:**
*   A discretized scalar field $f(\mathbf{x})$ defined on a voxel pyramid (multiresolution grid) [S1, unofficial].
*   A target isosurface scalar value $f_0$ [S1, unofficial].
*   Dynamic weight coefficients $\alpha$ (grayscale projection) and $\beta$ (Laplacian projection) [S1, unofficial].

**Outputs:**
*   A set of particle positions $\{\mathbf{p}_i\}$ representing the extracted isosurface [S1, unofficial].

**Data Structures:**
*   **Particle:** Stores position $\mathbf{p}$ and tracks displacement $\Delta \mathbf{p}$ per iteration [S1, unofficial].
*   **Voxel Pyramid:** Hierarchical grid levels from coarse to fine, storing scalar values at vertices/centers [G].
*   **Gradient Field:** First-order gradient $\nabla f(\mathbf{p})$ interpolated from the scalar field [G].
*   **Laplacian Field:** Second-order gradient $\nabla^2 f(\mathbf{p})$ interpolated from the scalar field [G].

**Algorithm Steps:**

1.  **Pyramid Construction:** Construct a voxel pyramid from the input scalar field [S1, unofficial].
2.  **Initialization:** Traverse the coarsest scale of the voxel pyramid, identify response units (cells containing the isosurface), and create one particle per unit at the approximate position corresponding to the mesh center generated by the Marching Cubes (MC) algorithm lookup table for that cell [S1, unofficial]. Apply small random perturbations to initial particle positions using the Mersenne Twister algorithm to avoid local extrema caused by symmetry [S1, unofficial].
3.  **Iteration Loop (until equilibrium or finest level):**
    *   **Gradient-Weighted Projection (Attraction):** Define deviation $\phi(\mathbf{p}) = f(\mathbf{p}) - f_0$ [S1, unofficial]. Construct a Newton iteration scheme based on first-order Taylor expansion: $\phi(\mathbf{p} + \Delta \mathbf{p}) \approx \phi(\mathbf{p}) + \nabla f(\mathbf{p}) \cdot \Delta \mathbf{p}$ [S1, unofficial]. Set the approximation to zero and solve for displacement direction using the gradient vector: $\Delta \mathbf{p} = \lambda \nabla f(\mathbf{p})$ [S1, unofficial]. Compute grayscale projection term $\Delta \mathbf{p}_{\text{grayscale}}$ and Laplacian projection term $\Delta \mathbf{p}_{\text{laplacian}}$ (based on second-order gradient zero-crossings) [S1, unofficial]. Combine with dynamic weights: $\Delta \mathbf{p} = \alpha \cdot \Delta \mathbf{p}_{\text{grayscale}} + \beta \cdot \Delta \mathbf{p}_{\text{laplacian}}$ [S1, unofficial]. Update particle position: $\mathbf{p} \leftarrow \mathbf{p} + \Delta \mathbf{p}$ [S1, unofficial]. Schedule weights dynamically: in early iterations $\alpha$ is high and $\beta$ is low (grayscale dominates for fast convergence); in late iterations $\alpha$ decreases and $\beta$ increases (Laplacian dominates for fine edge adjustment) [S1, unofficial].
    *   **Repulsion (Distribution Optimization):** Treat repulsion as a local short-range force [S1, unofficial]. Extract the tangential component of the repulsive force relative to the surface normal [S1, unofficial]. Apply this tangential component to optimize particle distribution among neighbors [S1, unofficial].
    *   **Equilibrium Check:** Calculate average particle displacement across the system [S1, unofficial]. If average displacement exceeds a threshold, continue iteration; otherwise, proceed to insertion [S1, unofficial].
4.  **Incremental Insertion:** When equilibrium is reached at a given scale, construct a Voronoi diagram of the current particle set [S1, unofficial]. Identify regions with high curvature or large Voronoi cell areas [S1, unofficial]. Insert new particles in these regions to refine the surface representation [S1, unofficial].
5.  **Refinement:** Move to the next finer level of the voxel pyramid and repeat steps 3–4 using the refined particle set as initialization for the finer scale [S1, unofficial].

**Pseudocode:**
```python
import math
import random

class Particle:
    def __init__(self, pos):
        self.pos = list(pos)

def interpolate_field(field, p):
    # [G] Trilinear interpolation of scalar field at p
    return field.trilinear(p)

def gradient_field(field, p):
    # [G] Trilinear gradient computation at p
    return field.gradient(p)

def laplacian_field(field, p):
    # [G] Trilinear Laplacian computation at p
    return field.laplacian(p)

def compute_voronoi(particles):
    # [G] Standard Voronoi tessellation of particle set
    return voronoi_tessellation(particles)

def extended_particle_extraction(scalar_field, f0, pyramid_levels, alpha_init=0.9, beta_init=0.1,
                               eq_threshold=1e-4, rep_radius=0.5, insert_threshold=0.1):
    particles = []
    coarsest = pyramid_levels[0]

    # 1. Initialization
    for cell in coarsest.cells:
        if min(cell.values) <= f0 <= max(cell.values):  # [G] is_response_unit
            center = cell.mc_mesh_center  # [S1, unofficial]
            perturbation = [random.gauss(0, 1e-3) for _ in range(3)]  # [G] Mersenne Twister
            particles.append(Particle([center[i] + perturbation[i] for i in range(3)]))

    # 2. Multiresolution Iteration
    for level_idx, level in enumerate(pyramid_levels):
        alpha = alpha_init
        beta = beta_init
        iteration = 0
        while True:
            total_disp = 0.0
            for p_obj in particles:
                p = p_obj.pos
                grad = gradient_field(scalar_field, p)
                phi = interpolate_field(scalar_field, p) - f0

                # Gradient-Weighted Projection
                grad_norm_sq = sum(g*g for g in grad)
                delta_gray = [-phi * g / grad_norm_sq for g in grad] if grad_norm_sq > 1e-12 else [0.0, 0.0, 0.0]

                # Laplacian projection term based on second-order gradient [S1, unofficial]
                # [Comment: Exact vector formulation for delta_p_laplacian not specified in sources; implemented as Laplacian-scaled gradient step]
                lap_val = laplacian_field(scalar_field, p)
                delta_lap = [lap_val * g for g in grad]

                # Dynamic weights: alpha high early, beta high late [S1, unofficial]
                alpha = alpha_init * (0.9 ** iteration)
                beta = 1.0 - alpha

                delta_p = [alpha * delta_gray[i] + beta * delta_lap[i] for i in range(3)]
                p_obj.pos = [p[i] + delta_p[i] for i in range(3)]
                total_disp += math.sqrt(sum(d*d for d in delta_p))

            avg_disp = total_disp / len(particles) if particles else 0.0
            if avg_disp < eq_threshold:  # [G] is_equilibrium
                break
            iteration += 1

            # Repulsion (Tangential component) [S1, unofficial]
            for i, p_obj in enumerate(particles):
                p = p_obj.pos
                grad = gradient_field(scalar_field, p)
                grad_norm = math.sqrt(sum(g*g for g in grad))
                if grad_norm < 1e-12: continue
                normal = [g / grad_norm for g in grad]
                for j, n_obj in enumerate(particles):
                    if i == j: continue
                    dist = math.sqrt(sum((p[k] - n_obj.pos[k])**2 for k in range(3)))
                    if dist < rep_radius:
                        rep_vec = [p[k] - n_obj.pos[k] for k in range(3)]
                        rep_norm = math.sqrt(sum(r*r for r in rep_vec))
                        if rep_norm < 1e-12: continue
                        rep_unit = [r / rep_norm for r in rep_vec]
                        proj = sum(rep_unit[m]*normal[m] for m in range(3))
                        tangential = [rep_unit[k] - proj*normal[k] for k in range(3)]
                        p_obj.pos = [p[k] + tangential[k] * 0.1 for k in range(3)]

        # 3. Incremental Insertion [S1, unofficial]
        voronoi_cells = compute_voronoi(particles)
        for cell in voronoi_cells:
            if cell.area > insert_threshold:
                new_p = cell.center
                perturbation = [random.gauss(0, 1e-3) for _ in range(3)]
                particles.append(Particle([new_p[i] + perturbation[i] for i in range(3)]))

    return [p.pos for p in particles]
```

**Parameters:**
*   $\alpha$: Dynamic weight coefficient for the grayscale projection term. High in early iteration, low in late iteration [S1, unofficial].
*   $\beta$: Dynamic weight coefficient for the Laplacian projection term. Low in early iteration, high in late iteration [S1, unofficial].
*   Equilibrium threshold: Not given in the sources [G].
*   Repulsion radius: Not given in the sources [G].

**Edge Cases and Pitfalls:**
*   **Symmetry:** Initial particle distribution symmetry can cause local extrema traps. Mitigated by Mersenne Twister perturbations [S1, unofficial].
*   **Gradient Magnitude:** In regions with small gradients, step size is enlarged to accelerate convergence; in large gradients, step size is reduced to ensure accuracy [S1, unofficial].
*   **Equilibrium Definition:** Average particle displacement is used as an approximation of the 'energy gradient' [S1, unofficial].
