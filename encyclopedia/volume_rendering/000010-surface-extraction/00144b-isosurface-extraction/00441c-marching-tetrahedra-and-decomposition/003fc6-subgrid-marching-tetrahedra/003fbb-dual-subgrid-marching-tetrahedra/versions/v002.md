# Dual Subgrid Marching Tetrahedra
Also called: dual subgrid method
## Overview
Dual Subgrid Marching Tetrahedra is a surface reconstruction technique that improves the geometric accuracy of the parent [Subgrid Marching Tetrahedra](1737-subgrid-marching-tetrahedra.md) method by allowing output vertices to be placed freely in 3D space rather than restricted to grid edges [S1]. This preserves topologically distinct features when a single tetrahedron contains multiple surface components [S1]. It differs from [Dual Contouring](link) by associating vertices with primal polygons rather than grid cells, and from [Marching Tetrahedrons](3720-marching-tetrahedrons.md) by utilizing the subgrid connectivity and dual placement strategy [S1].
## How it works
The method operates in two phases: constructing the dual mesh connectivity and computing the vertex coordinates [S1]. It assumes the input is the set of closed boundary loops $\Gamma$ generated by the primal subgrid marching tetrahedra algorithm for each tetrahedron in the grid [S1].

### Inputs and Outputs
*   **Input**: A set of closed boundary loops $\Gamma$. Each loop $\Gamma$ is a sequence of $k$ edge intersection points $x_i \in \mathbb{R}^3$ and their corresponding unit surface normals $N_i \in \mathbb{R}^3$, where $k \ge 3$ [S1].
*   **Output**: A triangle mesh representing the isosurface [S1].

### Data Structures
1.  **Primal Loop**: A list of tuples $(x_i, N_i)$ for $i=1 \dots k$ [S1].
2.  **Dual Connectivity Map**:
    *   `dual_vertices`: A dictionary mapping each primal polygon (identified by its loop ID) to a dual vertex index [G].
    *   `dual_edges`: A list of pairs of dual vertex indices [G].
    *   `dual_faces`: A list of triangles, where each triangle is a triplet of dual vertex indices [G].
3.  **Vertex Positions**: A list of 3D coordinates for each dual vertex [S1].

### Steps
1.  **Construct Primal Loops**: Generate the closed boundary loops $\Gamma$ for each tetrahedron using the standard subgrid marching tetrahedra connectivity logic [S1]. Do not triangulate these loops yet [S1].
2.  **Build Poincaré Dual Connectivity**:
    *   Create a dual vertex for each primal polygon (loop) generated in Step 1 [S1].
    *   Identify interior primal edges (edges shared by two adjacent primal polygons). For each interior primal edge, create a dual edge connecting the two dual vertices corresponding to the adjacent polygons [S1].
    *   Identify interior primal vertices (vertices shared by multiple primal polygons). For each interior primal vertex, create a dual polygon whose vertices are the dual vertices associated with the primal polygons incident to that primal vertex [S1].
    *   Triangulate each dual polygon created in the previous sub-step without inserting any new vertices [S1].
3.  **Compute Dual Vertex Coordinates**: For each dual vertex $v$ associated with a primal polygon (loop) $\Gamma$ containing $k$ points $\{x_1, \dots, x_k\}$ and normals $\{N_1, \dots, N_k\}$, solve for the vertex position $p$ that minimizes the regularized Quadratic Error Function (QEF) [S1].

### Formulas
**Quadratic Error Function (QEF)**:
$$ \mathcal{Q}(p) := \frac{1}{k} \sum_{i=1}^k \langle N_i, p - x_i \rangle^2 $$
where:
*   $x_i \in \mathbb{R}^3$ are the edge intersection points along the loop [S1].
*   $N_i$ are the unit normals at $x_i$ [S1].
*   $p \in \mathbb{R}^3$ is the candidate vertex position [S1].
*   $\langle \cdot, \cdot \rangle$ denotes the dot product [S1].

**Regularized QEF**:
$$ Q_\lambda(p) := \mathcal{Q}(p) + \lambda \|p - \bar{x}\|^2 $$
where:
*   $\bar{x} := \frac{1}{k} \sum_{i=1}^k x_i$ is the centroid of the intersection points [S1].
*   $\lambda$ is the regularization weight [S1].

**Solution for $p$**:
To minimize $Q_\lambda(p)$, we solve the linear system $A p = b$, where:
$$ A = \frac{1}{k} \sum_{i=1}^k N_i N_i^T + \lambda I $$
$$ b = \frac{1}{k} \sum_{i=1}^k (N_i^T x_i) N_i + \lambda \bar{x} $$
Here, $I$ is the $3 \times 3$ identity matrix [S1]. The term $\frac{1}{k}$ is a constant scaling factor that does not change the minimizer but is retained for numerical consistency with the source definition [S1].

### Parameters
*   **Regularization weight $\lambda$**: $0.1$ [S1].

### Edge Cases and Pitfalls
*   **Nearly Coplanar Planes**: If the normals $N_i$ are nearly parallel (planes are nearly coplanar), the unregularized QEF matrix becomes singular or ill-conditioned, potentially placing the minimizer far from the loop and outside the tetrahedron [S1]. The regularizer term $\lambda \|p - \bar{x}\|^2$ ensures the matrix is positive definite, pulling the solution toward the mean intersection point $\bar{x}$ and ensuring a unique minimum [S1].
*   **Normal Orientation**: The input normals $N_i$ do not need to be consistently oriented. The energy term $\langle N_i, p - x_i \rangle^2$ is invariant to sign flips of $N_i$ [S1].
*   **Degenerate Loops**: Loops with $k=1$ or $k=2$ vertices do not arise in this context because a closed boundary loop on a tetrahedral grid must have at least three vertices [S1].
*   **Triangulation**: Dual polygons must be triangulated without adding new vertices (Steiner points) [S1]. The dual vertices around each primal vertex must be ordered cyclically to produce a manifold mesh [G].

### Pseudocode
```python
import numpy as np

def solve_dual_vertex(intersection_points, normals, lambda_reg=0.1):
    """
    Computes the position of a dual vertex by minimizing the regularized QEF.
    
    Args:
        intersection_points: List of k points (x_i) in R^3.
        normals: List of k unit normals (N_i) in R^3.
        lambda_reg: Regularization weight lambda.
        
    Returns:
        p: Optimal vertex position in R^3.
    """
    k = len(intersection_points)
    if k == 0:
        return np.zeros(3)
    
    x_bar = np.mean(intersection_points, axis=0)
    A = np.zeros((3, 3))
    b = np.zeros(3)
    
    for i in range(k):
        x_i = np.array(intersection_points[i])
        N_i = np.array(normals[i])
        A += np.outer(N_i, N_i)
        b += np.dot(N_i, x_i) * N_i
        
    A /= k
    b /= k
    A += lambda_reg * np.eye(3)
    b += lambda_reg * x_bar
    
    return np.linalg.solve(A, b)

def dual_subgrid_marching_tetrahedra(primal_loops):
    """
    Reconstructs the dual mesh from primal loops.
    
    Args:
        primal_loops: List of primal loops. Each loop is a dict/object containing:
            - 'id': Unique identifier for the primal polygon.
            - 'points': List of intersection points (x_i).
            - 'normals': List of normals (N_i).
            - 'vertices': List of primal vertex indices involved in this loop.
            - 'edges': List of primal edge indices involved in this loop.
            
    Returns:
        dual_vertices: List of 3D coordinates.
        dual_faces: List of triangles (triplets of vertex indices).
    """
    dual_vertex_map = {}
    dual_vertex_positions = []
    
    for loop in primal_loops:
        idx = len(dual_vertex_positions)
        dual_vertex_map[loop['id']] = idx
        dual_vertex_positions.append(solve_dual_vertex(loop['points'], loop['normals']))
        
    edge_to_loops = {}
    vertex_to_loops = {}
    
    for loop in primal_loops:
        for edge_idx in loop['edges']:
            edge_to_loops.setdefault(edge_idx, []).append(loop['id'])
        for vert_idx in loop['vertices']:
            vertex_to_loops.setdefault(vert_idx, []).append(loop['id'])
            
    dual_edges = []
    dual_faces = []
    
    for edge_idx, loop_ids in edge_to_loops.items():
        if len(loop_ids) == 2:
            dual_edges.append((dual_vertex_map[loop_ids[0]], dual_vertex_map[loop_ids[1]]))
            
    for vert_idx, loop_ids in vertex_to_loops.items():
        if len(loop_ids) < 3:
            continue
            
        dual_v_indices = [dual_vertex_map[lid] for lid in loop_ids]
        
        # Compute approximate primal vertex position from incident loop points
        all_pts = []
        for lid in loop_ids:
            for loop in primal_loops:
                if loop['id'] == lid:
                    all_pts.extend(loop['points'])
                    break
        primal_pos = np.mean(all_pts, axis=0)
        
        # Sort dual vertices cyclically around the primal vertex [G]
        vecs = np.array([dual_vertex_positions[v] - primal_pos for v in dual_v_indices])
        if len(vecs) >= 2:
            normal = np.cross(vecs[0], vecs[1])
            if np.linalg.norm(normal) < 1e-8:
                normal = np.array([0.0, 0.0, 1.0])
            # Project vectors to the plane orthogonal to normal
            proj = vecs - np.outer(np.dot(vecs, normal), normal)
            # Compute angles in the projection plane
            angles = np.arctan2(np.dot(np.cross(normal, proj), normal), np.dot(proj, proj))
            sorted_indices = np.argsort(angles)
            dual_v_indices = [dual_v_indices[i] for i in sorted_indices]
            
        # Fan triangulation of the ordered dual polygon
        for i in range(1, len(dual_v_indices) - 1):
            dual_faces.append((dual_v_indices[0], dual_v_indices[i], dual_v_indices[i+1]))
            
    return dual_vertex_positions, dual_faces
```
## Operating characteristics
*   **Time Complexity**: The dominant cost is solving the $3 \times 3$ linear system for each dual vertex, which is $O(1)$ per vertex [S1]. Connectivity construction requires iterating over primal edges and vertices, which is linear in the number of primal polygons and edges [S1]. Overall, the method is linear in the size of the output mesh [S1].
*   **Memory Complexity**: Requires storing the dual connectivity map and the vertex positions [S1]. The memory overhead is proportional to the number of primal polygons (which become dual vertices) and the number of primal edges/vertices (which become dual edges/faces) [S1].
*   **Strengths**: Produces smoother and more accurate surfaces than primal subgrid marching, especially for thin features and sharp creases, because vertices are not constrained to grid edges [S1]. Capable of preserving topologically distinct features within a single tetrahedron, which primal methods might merge or distort [S1]. The regularization term ensures a unique solution even in degenerate cases (e.g., parallel normals) [S1].
*   **Limitations**: The dual connectivity construction is more complex than primal marching, requiring careful handling of polygon triangulation and adjacency [S1]. If the primal mesh is non-manifold, the dual construction may produce non-manifold dual meshes, requiring additional processing [G]. Slightly higher per-vertex cost due to QEF minimization compared to simple edge interpolation [S1].
## Background
The method is inspired by dual contouring [Ju et al. 2002] and dual marching [Schaefer and Warren 2004] [S1]. It was introduced as part of the Subgrid Marching Tetrahedra framework to address the limitations of primal methods in handling complex topology within grid cells [S1]. The key insight is that while dual contouring associates one vertex per cell, dual marching associates a vertex per polygon, making it suitable for subgrid methods where multiple polygons can exist per tetrahedron [S1].
