# Local Surface Construction


## Overview
Local Surface Construction is the core geometric engine of Subgrid Marching Tetrahedra, responsible for generating a local, intersection-free triangle soup from a single tetrahedron's edge intersections and curve topology [S1, unofficial]. It solves the problem of ambiguous surface configurations within a tetrahedron by classifying intersection curves into open, scoop, and normal types, ensuring the resulting mesh is globally embeddable without self-intersections [S1, unofficial]. It builds on [Subgrid Marching Tetrahedra](1737-subgrid-marching-tetrahedra.md) by handling the interior reconstruction step, and differs from [Dual Subgrid Marching Tetrahedra](10072-dual-subgrid-marching-tetrahedra.md) by operating on the primal grid structure [S1, unofficial].

## How it works
**Inputs:**
- Tetrahedron vertex positions and indices [S1, unofficial].
- Edge intersection t-values (normalized distances along edges) [S1, unofficial].
- Curve type classification (open, scoop, normal) for each tetrahedron [S1, unofficial].
- Configuration options: `opts.scoop_mid_vertices` (controls mid-vertex placement), `opts.scoop_bulge` (controls bulging parameter) [S1, unofficial].

**Outputs:**
- A `TriangleSoup` containing local triangles for the tetrahedron [S1, unofficial].

**Data Structures:**
- `TriangleSoup`: A container for triangles, with a merge flag `COMB_MERGE` to handle shared vertices [S1, unofficial].
- `local_counts`: Array of 6 integers, counting intersections per local edge [S1, unofficial].
- `local_ts`: Array of 6 vectors of doubles, storing intersection t-values per local edge [S1, unofficial].

**Steps:**
1. **Global Count Aggregation:** Compute global intersection counts for all edges in the grid [S1, unofficial].
2. **Global T-Value Generation:** Generate global t-values for all edges using the counts and a seed/random flag [S1, unofficial].
3. **Local Mapping:** For each tetrahedron, map global edges to the local 6-edge frame using `ALL_TET_PAIRS` [S1, unofficial].
4. **Retrieve Local Data:** Fetch `local_counts` and `local_ts` for each local edge by looking up the global edge key `ge = make_edge(tet.idx[li], tet.idx[lj])` [S1, unofficial].
5. **Curve Classification:** Classify the intersection curves within the tetrahedron into three types: open, scoop, and normal [S1, unofficial].
6. **Local Reconstruction:** Construct the local triangle soup using the classified curves [S1, unofficial]. For scoop curves, apply `opts.scoop_mid_vertices` and `opts.scoop_bulge` to control vertex placement and bulging [S1, unofficial].
7. **Merge:** Combine local triangle soups from all tetrahedra into a global `TriangleSoup`, using `COMB_MERGE` to handle shared vertices [S1, unofficial].

**Formulas:**
- Intersection point on edge $e$ between vertices $V_0$ and $V_1$: $P = V_0 + t \cdot (V_1 - V_0)$, where $t \in [0, 1]$ [G].
- T-value distribution for $n$ intersections on an edge: $t_k = \frac{k + 1.0}{n + 1.0}$ for $k = 0 \dots n-1$ [S1, unofficial].

**Parameters:**
- `opts.scoop_mid_vertices`: Controls mid-vertex placement for scoop curves [S1, unofficial].
- `opts.scoop_bulge`: Controls bulging parameter for scoop curves [S1, unofficial].

**Pitfalls:**
- If the even-sum condition is not satisfied (tracked via `non_even_tets > 0`), the output mesh may not be orientable and may contain open holes, indicating a non-watertight input or grid edge-intersection issue [S1, unofficial].

**Pseudocode:**
```python
def local_surface_construction(tetrahedra, opts):
    ALL_TET_PAIRS = [(0, 1), (0, 2), (0, 3), (1, 2), (1, 3), (2, 3)]
    def make_edge(i, j): return tuple(sorted((i, j)))

    # Step 1: Global count aggregation
    global_counts = {}
    for tet in tetrahedra:
        for li, lj in ALL_TET_PAIRS:
            ge = make_edge(tet.idx[li], tet.idx[lj])
            global_counts[ge] = global_counts.get(ge, 0) + 1

    # Step 2: Global t-value generation
    global_ts = {}
    for ge, n in global_counts.items():
        global_ts[ge] = [(k + 1.0) / (n + 1.0) for k in range(n)]

    TriangleSoup.COMB_MERGE = opts.use_comb_merge
    combined_soup = TriangleSoup()

    # Step 3-6: Process each tetrahedron
    for tet in tetrahedra:
        local_counts = [0] * 6
        local_ts = [[] for _ in range(6)]

        # Map global edges to local 6-edge frame
        for ei in range(6):
            li, lj = ALL_TET_PAIRS[ei]
            ge = make_edge(tet.idx[li], tet.idx[lj])
            local_counts[ei] = global_counts.get(ge, 0)
            local_ts[ei] = global_ts.get(ge, [])

        # Classify curve type based on total intersections
        total_intersections = sum(local_counts)
        curve_type = "open" if total_intersections == 2 else ("scoop" if total_intersections == 4 else "normal")

        # Compute intersection points
        points = []
        for ei in range(6):
            if local_counts[ei] > 0:
                v0 = tet.pos[tet.idx[ALL_TET_PAIRS[ei][0]]]
                v1 = tet.pos[tet.idx[ALL_TET_PAIRS[ei][1]]]
                for t in local_ts[ei]:
                    points.append(v0 + t * (v1 - v0))

        # Local Reconstruction: Construct the local triangle soup using the classified curves
        # The sources do not provide the exact triangle assembly logic for open, scoop, and normal curves.
        # It is handled by the Primal Reconstruction Algorithm or internal C++ routines [S1, unofficial].
        local_soup = TriangleSoup()
        # Assembly logic omitted per source documentation
        combined_soup.merge(local_soup)

    return combined_soup
```

## Subtopics

### [Primal Reconstruction Algorithm](10073-primal-reconstruction-algorithm.md)
The Primal Reconstruction Algorithm is a surface reconstruction method that recursively subdivides tetrahedra to construct piecewise linear surfaces, guaranteeing global embedding (no self-intersections) in $\mathbb{R}^3$. It distinguishes itself from standard marching tetrahedra by explicitly handling non-normal curves via smeared polygons, contraction, and recursive subdivision to resolve ambiguous configurations that would otherwise produce self-intersecting or invalid meshes. It builds on [Local Surface Construction](1787-local-surface-construction.md) by providing the geometric resolution logic for the interior of the tetrahedra.

## Operating characteristics
- **Time Complexity:** Not given in the sources [S1, unofficial].
- **Memory Complexity:** Not given in the sources [S1, unofficial].
- **Strengths:** Guarantees intersection-free output; handles ambiguous configurations robustly [S1, unofficial].
- **Limitations:** Requires careful handling of the even-sum condition to avoid non-orientable meshes [S1, unofficial].
- **When to use:** When extracting isosurfaces from tetrahedral grids with ambiguous configurations [S1, unofficial].
- **When not to use:** When input data is non-watertight or grid edge-intersection issues are present [S1, unofficial].

## Background
Local Surface Construction is part of the Subgrid Marching Tetrahedra method, developed by H. Baktash et al. [S1, unofficial]. It builds on the principles of marching tetrahedra but introduces specialized handling for ambiguous cases to ensure global embedding [S1, unofficial].
