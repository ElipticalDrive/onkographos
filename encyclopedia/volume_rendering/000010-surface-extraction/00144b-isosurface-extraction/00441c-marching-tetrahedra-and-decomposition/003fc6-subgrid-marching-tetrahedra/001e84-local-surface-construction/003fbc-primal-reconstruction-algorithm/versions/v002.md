# Primal Reconstruction Algorithm

Also called: Subgrid Marching Tetrahedra primal reconstruction

## Overview
The Primal Reconstruction Algorithm is a surface reconstruction method that recursively subdivides tetrahedra to construct piecewise linear surfaces, guaranteeing global embedding (no self-intersections) in $\mathbb{R}^3$ [S1]. It distinguishes itself from standard marching tetrahedra by explicitly handling non-normal curves via smeared polygons, contraction, and recursive subdivision to resolve ambiguous configurations that would otherwise produce self-intersecting or invalid meshes [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A tetrahedron with scalar field values at its vertices, defining an isosurface intersection pattern [S1].
*   **Output:** A set of non-intersecting, piecewise linear surface patches (triangles, smeared polygons, or curves) contained within the tetrahedron [S1].

**Data Structures:**
The algorithm operates on the topological state of the tetrahedron's faces [S1]. The key state variable is the pair of integers $(d_1, d_2)$ representing the connectivity pattern of normal curves on a triangle-free face, where $0 \leq d_2 \leq d_1$ [S1]. Edge coordinates on a face $ijk$ after extracting/removing triangles are given by $e_{ij} = q_{ik} + q_{il}$, $e_{jk} = q_{ik} + q_{ij}$, $e_{ki} = q_{ij} + q_{il}$, where at least one $q$ value is zero [S1]. The remaining two $q$ values are denoted $d_1$ and $d_2$, yielding edge coordinates $d_1, d_2, d_1+d_2$ [S1].

**Algorithm Steps:**
1.  **Classify Surface Type:** Determine if the current configuration consists of corner triangles, contractible non-normal curves, corner-type non-normal curves, or diagonal-type curves [S1]. Surfaces are classified and processed in this specific order to prove intersection freedom [S1].
2.  **Handle Corner Triangles:** Extract and remove triangles at vertices [S1].
3.  **Handle Contractible Non-Normal Curves:** Apply the contraction operation to pull the curve tight at non-normal segments until it becomes normal [S1]. Discrete implementation: on any edge where the curve has a scoop, reduce the edge coordinate by 2 [S1]. Repeat until the curve is normal [S1]. Smeared polygons remain smeared or are removed; no new intersections are introduced [S1].
4.  **Handle Non-Normal Curves (Subdivision):** If non-normal curves persist, check the edge coordinates $(d_1, d_2)$ on the faces [S1].
    *   **Termination Check:** If $d_1 = d_2$, the configuration is an explicit octagon case handled without further subdivision [S1].
    *   **Recursive Subdivision:** If $d_1 > d_2$, split the tetrahedron [S1]. Splitting creates a new vertex with incident edge coordinates $d_1, d_2, 2d_2, d_1-d_2$ [S1]. The maximum edge coordinate strictly decreases, ensuring progress [S1].
5.  **Connectivity Analysis:** To determine the number of connected components for a $(d_1, d_2)$ pattern, apply a shortening operation analogous to the Euclidean algorithm: repeatedly replace $(d_1, d_2)$ with $(d_1-d_2, d_2)$ by moving the first $2d_2$ points toward their bottom-pairs until they merge [S1]. Terminate when the pair reaches $(d, 0)$ where $d = \gcd(d_1, d_2)$ [S1]. The number of connected components is $d$ [S1].
6.  **Compute Component Length:** For a $(d_1, d_2)$ pattern, the length $\ell$ of every connected component is $\ell = \frac{4(d_1+d_2)}{\gcd(d_1, d_2)}$ [S1]. When $d_1, d_2 \geq 1$, the number of segments is at least 8 [S1].
7.  **Scoop Construction Guard:** Scoops are constructed only when residual points on an edge violate the triangle inequality, ensuring no conflicting 2D corner segments form at the opposite vertex [S1]. This prevents path crossings inside scoops [S1].

**Pseudocode:**
```python
def primal_reconstruct(vertices, edges, faces, scalars, iso_value):
    # Initialize edge coordinates for each face
    face_edge_coords = {}
    for face in faces:
        # Compute crossings on each edge of the face
        e_ij, e_jk, e_ki = compute_edge_crossings(face, edges, scalars, iso_value)
        face_edge_coords[face] = (e_ij, e_jk, e_ki)

    triangles = []
    surfaces = []

    # Step 1 & 2: Classify and handle corner triangles
    for face in faces:
        # Extract corner triangles at vertices crossing the iso-value
        corner_tris = extract_corner_triangles(face, scalars, iso_value)
        triangles.extend(corner_tris)
        # Update face coordinates after triangle removal per Theorem B.3
        e_ij, e_jk, e_ki = face_edge_coords[face]
        # At least one q is zero; remaining two are d1, d2
        # e_ij = q_ik + q_il, e_jk = q_ik + q_ij, e_ki = q_ij + q_il
        # This step adjusts coordinates to reflect removed triangles
        face_edge_coords[face] = adjust_coords_after_triangles(e_ij, e_jk, e_ki)

    # Step 3: Handle non-normal curves via contraction
    for face in faces:
        e_ij, e_jk, e_ki = face_edge_coords[face]
        # Contraction: pull curve tight at non-normal segments until normal
        while has_scoop(e_ij, e_jk, e_ki):
            # Discrete implementation: reduce edge coordinate by 2 for each scoop
            if e_ij + e_jk <= e_ki: e_ki -= 2
            if e_jk + e_ki <= e_ij: e_ij -= 2
            if e_ki + e_ij <= e_jk: e_jk -= 2
            face_edge_coords[face] = (e_ij, e_jk, e_ki)

    # Step 4: Handle remaining non-normal curves (subdivision or octagon)
    for face in faces:
        e_ij, e_jk, e_ki = face_edge_coords[face]
        # Sort to ensure 0 <= d2 <= d1
        coords = sorted([e_ij, e_jk, e_ki])
        d2, d1 = coords[0], coords[1]

        if d1 == d2:
            # Step 4a: Termination check - explicit octagon case
            surfaces.append(construct_octagon_surface(face, d1, d2))
        else:
            # Step 4b: Recursive subdivision
            # Split creates new vertex with incident coords d1, d2, 2*d2, d1-d2
            new_tets = split_tetrahedron(vertices, edges, faces, d1, d2)
            for new_tet in new_tets:
                triangles.extend(primal_reconstruct(*new_tet))

    return triangles + surfaces
```

**Edge Cases and Pitfalls:**
*   **Precision:** The algorithm relies on integer arithmetic for edge coordinates and connectivity [S1].
*   **Boundary Conditions:** The algorithm assumes the tetrahedron is part of a larger mesh, and global embedding is guaranteed because surfaces are contained within their respective tetrahedra (up to $\epsilon$-perturbation) [S1].
*   **Degenerate Input:** If $d_1 = d_2$, the algorithm terminates without recursion, handling the octagon case explicitly [S1].

## Operating characteristics
*   **Time Complexity:** The algorithm terminates after $O(n)$ subdivisions for a tetrahedron with sum of edge coordinates $n$, running in linear time [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Guarantees a globally embedded, intersection-free mesh [S1]. Handles ambiguous non-normal configurations that standard marching tetrahedra fail to resolve correctly [S1].
*   **Limitations:** Requires recursive subdivision [S1].
*   **When to use:** When topological correctness and non-intersection are critical [S1].
*   **When not to use:** Not given in the sources.

## Background
The Primal Reconstruction Algorithm is part of the Subgrid Marching Tetrahedra method [S1]. It was introduced to address the limitations of standard marching tetrahedra, which can produce self-intersecting or ambiguous configurations [S1]. The algorithm's theoretical foundation includes proofs of termination (Theorem C.1) and the no-intersection property (Theorem D.1) [S1].
