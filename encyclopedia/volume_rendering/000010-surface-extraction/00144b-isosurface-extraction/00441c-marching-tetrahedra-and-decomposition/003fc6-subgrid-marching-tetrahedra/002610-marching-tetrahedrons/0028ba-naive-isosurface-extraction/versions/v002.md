# Naive Isosurface Extraction

Also called: Simple Isosurface Extraction, Naive Tetrahedral Isosurface Extraction

## Overview
Naive Isosurface Extraction is a surface extraction algorithm that processes each tetrahedron in a tetrahedral mesh independently to generate a collection of individual, unconnected polygons [S1, unofficial]. Unlike optimized variants that ensure manifold connectivity through vertex reuse, this method creates new vertices for every intersection point, resulting in non-manifold surfaces with cracks at shared edges [S1, unofficial].

## How it works
**Inputs:**
*   A tetrahedral mesh (tet-mesh) consisting of a list of tetrahedra [S1, unofficial].
*   A scalar field defined at the vertices of the mesh [S1, unofficial].
*   A target isovalue (level set value) [S1, unofficial].

**Outputs:**
*   An output surface representation containing the intersection polygons [S1, unofficial].

**Data Structures:**
*   **Input Tetrahedron:** Defined by 4 vertex indices [S1, unofficial].
*   **Output Points:** A list of 3D coordinates where new vertices are inserted [S1, unofficial].
*   **Output Cells:** A list of polygons, each defined by a list of vertex indices pointing to the Output Points [S1, unofficial].

**Algorithm Steps:**

1.  **Initialization:** Initialize empty lists for output points and output cells.
2.  **Loop over Tetrahedra:** Iterate through every tetrahedron $T$ in the input mesh [S1, unofficial].
3.  **Check Intersection:** For each tetrahedron $T$, determine if it is intersected by the isovalue using `IsCellOnLevelSet()` [S1, unofficial].
4.  **Compute Intersection Polygon:** If intersected, compute the intersection polygon using `ComputeSimpleIntersection()` [S1, unofficial].
    *   Initialize an empty list `pointIds` to store vertex indices [S1, unofficial].
    *   **Loop over Edges:** Iterate through the 6 edges of the tetrahedron [S1, unofficial].
    *   **Check Edge Intersection:** For each edge, determine if it is intersected by the isovalue using `IsCellOnLevelSet()` [S1, unofficial].
    *   **Compute Intersection Point:** If the edge is intersected, calculate the intersection point using `ComputeEdgeIntersection()` [S1, unofficial].
    *   **Create Vertex:** Insert point $P$ into the output points list. Let the returned index be $id$ [S1, unofficial].
    *   **Store ID:** Append $id$ to `pointIds` [S1, unofficial].
    *   **Reorder Vertices:** Reorder the vertex IDs in `pointIds` to ensure a consistent winding order around the tetrahedron to prevent visual artifacts like cracks [S1, unofficial].
    *   **Insert Cell:** Insert a new polygon cell into the output using `pointIds` [S1, unofficial].

**Pseudocode:**

```python
def naive_isosurface_extraction(tet_mesh, vertex_positions, scalar_field, isovalue):
    """
    Extracts isosurface from a tetrahedral mesh using the naive approach.
    
    Args:
        tet_mesh: List of tuples, each containing 4 vertex indices.
        vertex_positions: List of 3D coordinates (x, y, z) for each vertex.
        scalar_field: List of scalar values corresponding to mesh vertices.
        isovalue: The target scalar value for the isosurface.
        
    Returns:
        output_points: List of 3D coordinates for the surface vertices.
        output_cells: List of polygons, where each polygon is a list of vertex indices.
    """
    output_points = []
    output_cells = []
    
    def is_cell_on_level_set(vertex_indices):
        """Returns True if the cell defined by vertex_indices is intersected by the isovalue."""
        scalars = [scalar_field[i] for i in vertex_indices]
        return min(scalars) <= isovalue <= max(scalars)

    def compute_edge_intersection(v1_idx, v2_idx):
        """Computes the intersection point of the edge connecting v1 and v2 with the isovalue."""
        p1 = vertex_positions[v1_idx]
        p2 = vertex_positions[v2_idx]
        s1 = scalar_field[v1_idx]
        s2 = scalar_field[v2_idx]
        
        denom = s2 - s1
        t = (isovalue - s1) / denom if abs(denom) > 1e-9 else 0.0
        return (p1[0] + t * (p2[0] - p1[0]),
                p1[1] + t * (p2[1] - p1[1]),
                p1[2] + t * (p2[2] - p1[2]))

    def reorder_tet_edges(intersection_points):
        """
        Reorders intersection points to ensure consistent winding.
        Uses deterministic coordinate sorting as a gap-filler since the source 
        requires consistent winding but does not specify the exact algorithm [G].
        """
        return sorted(intersection_points, key=lambda p: (p[0], p[1], p[2]))

    for tet_vertices in tet_mesh:
        if is_cell_on_level_set(tet_vertices):
            point_ids = []
            edges = [
                (tet_vertices[0], tet_vertices[1]),
                (tet_vertices[0], tet_vertices[2]),
                (tet_vertices[0], tet_vertices[3]),
                (tet_vertices[1], tet_vertices[2]),
                (tet_vertices[1], tet_vertices[3]),
                (tet_vertices[2], tet_vertices[3])
            ]
            
            intersection_points = []
            for v1, v2 in edges:
                if is_cell_on_level_set([v1, v2]):
                    intersection_points.append(compute_edge_intersection(v1, v2))
            
            ordered_points = reorder_tet_edges(intersection_points)
            
            start_idx = len(output_points)
            for point in ordered_points:
                output_points.append(point)
            point_ids = list(range(start_idx, len(output_points)))
            
            output_cells.append(point_ids)
            
    return output_points, output_cells
```

**Parameters:**
*   **Isovalue:** The scalar threshold [S1, unofficial].
*   **Tolerance:** A small epsilon should be used for floating-point comparisons in `is_cell_on_level_set` to handle precision issues [G].

**Edge Cases and Pitfalls:**
*   **Non-Manifold Surfaces:** The naive approach creates duplicate vertices at shared edges because each tetrahedron generates its own intersection points independently, leading to cracks and non-manifold geometry [S1, unofficial].
*   **Inconsistent Winding:** The order of vertices in the generated polygon may be inconsistent across adjacent tetrahedra, causing visual artifacts like cracks [S1, unofficial].
*   **Performance:** The algorithm is slow compared to optimized implementations because it does not reuse vertices or use spatial indexing [S1, unofficial].

## Subtopics

### Appropriate Isosurface Extraction (Vertex Reuse)
An isosurface extraction algorithm that reuses intersection vertices created by neighboring tetrahedra to ensure manifold connectivity and avoid duplicate vertices [S1, unofficial]. Unlike the naive approach, which has quadratic complexity if vertex merging is attempted without spatial indexing, this approach avoids quadratic complexity by reusing vertices directly via neighbor lookup [S1, unofficial]. It requires pre-computing neighbor tetrahedra for each tetrahedron during mesh loading and storing vertex IDs within each tetrahedron's data structure to enable efficient reuse [S1, unofficial]. It is chosen when manifold connectivity and performance are required, whereas the naive approach is used for simplicity [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of tetrahedra for the basic loop, but the lack of vertex reuse means the output size is proportional to the number of intersected tetrahedra times the average number of intersection points per tetrahedron [S1, unofficial]. The naive approach is described as "slow" compared to optimized implementations [S1, unofficial].
*   **Memory Complexity:** Proportional to the number of intersected tetrahedra, as vertices are not shared [S1, unofficial].
*   **Strengths:** Simple to implement; no need for complex data structures like spatial indices or vertex hash maps [S1, unofficial].
*   **Limitations:** Produces non-manifold surfaces with cracks; inconsistent vertex winding causes visual artifacts; inefficient memory usage due to duplicate vertices; slow performance due to lack of optimization [S1, unofficial].
*   **When to Use:** Educational purposes or when the output is only used for visualization where cracks are tolerable [S1, unofficial].
*   **When Not to Use:** When manifold connectivity is required (e.g., for simulation, 3D printing, or accurate rendering) or when performance is critical [S1, unofficial].

## Background
The naive isosurface extraction method is presented as a foundational exercise in isosurface generation specifically within the context of tetrahedral meshes [S1, unofficial]. The exercise highlights the common pitfalls of naive implementations, such as non-manifold geometry and inconsistent winding, to motivate the development of more robust algorithms like the "Appropriate Isosurface Extraction" variant [S1, unofficial].
