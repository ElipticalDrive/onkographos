# Barycentric Mapping for Material Interfaces (2D Triangular Grids)
Also called: Triangle case material boundary reconstruction

## Overview
This method determines material interface line segments within a single 2D triangular grid cell by mapping the triangle's barycentric coordinates to a reference barycentric triangle and intersecting with Voronoi cell boundaries [S1]. It sets itself apart from standard isosurface extraction by operating directly on volume-fraction data in unstructured triangular meshes, using the geometric properties of Voronoi cells in barycentric space to define interfaces rather than scalar field thresholds [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 2D triangular cell $T$ with vertices $v_1, v_2, v_3$ in physical space, and associated material values (volume fractions) $f_1, f_2, f_3$ at each vertex [S1].
*   **Output:** A list of line segments representing the material boundary within $T$ [S1].

**Data Structures:**
*   **Barycentric Coordinates:** A point $P$ in $T$ is represented by $(\lambda_1, \lambda_2, \lambda_3)$ such that $P = \lambda_1 v_1 + \lambda_2 v_2 + \lambda_3 v_3$ and $\sum \lambda_i = 1$ [S1].
*   **Reference Triangle $T'$:** The unit barycentric triangle in $\mathbb{R}^3$ defined by vertices $(1,0,0), (0,1,0), (0,0,1)$ [S1].
*   **Voronoi Boundaries:** Line segments $l_{12}, l_{13}, l_{23}$ in $T'$ bounding the Voronoi cells [S1]. These are defined by the conditions where material values are equal [G].
*   **Center:** The triangle center is $c = (1/3, 1/3, 1/3)$ [S1].

**Steps:**
1.  **Map to Barycentric Space:** Map the physical triangle $T$ to the reference barycentric triangle $T'$ [S1]. The vertices of $T'$ correspond to the basis vectors of the barycentric coordinate system [S1]. The material values $f_1, f_2, f_3$ at the vertices define the Voronoi boundaries in $T'$ [S1].
2.  **Identify Intersections in $T'$:** Determine the intersection of the material interface region with the edges of $T'$ [S1]. The material interface in $T'$ is defined by the intersections of the edges of $T'$ with the Voronoi cell boundary line segments $l_{12}, l_{13}, l_{23}$ [S1].
3.  **Map Intersections Back to Physical Space:** Map the calculated intersection points from $T'$ back to the original triangle $T$ in physical space [S1]. If an intersection point in $T'$ has barycentric coordinates $(\lambda_1, \lambda_2, \lambda_3)$, the corresponding point in $T$ is $P = \lambda_1 v_1 + \lambda_2 v_2 + \lambda_3 v_3$ [S1]. This uses the same linear parameters (barycentric weights) [S1].
4.  **Construct Boundary Segments:** There are three distinct cases based on the position of the interface region in $T'$ relative to the center $c(1/3, 1/3, 1/3)$ and the Voronoi lines [S1]:
    *   **Case 1: No Intersection.** If $T'$ does not intersect any of the Voronoi boundary lines ($l_{12}, l_{13}, l_{23}$), no material boundary exists in $T$ [S1]. This occurs if only one material is present at all three vertices [S1].
    *   **Case 2: Edge Intersections Only (Center Outside).** If $T'$ intersects at least one Voronoi line but the center $c$ is not inside the interface region, calculate the edge intersections in $T$ corresponding to the intersections of $T'$ with the Voronoi lines [S1]. The triangle $T'$ intersects at most two of these lines [S1]. Connect these edge intersections to form the material boundary line segments [S1].
    *   **Case 3: Interior Point (Center Inside).** If the center $c(1/3, 1/3, 1/3)$ lies inside the interface region, calculate three edge intersections in $T$ (corresponding to $T'$ intersections with $l_{12}, l_{13}, l_{23}$) and one interior point in $T$ (corresponding to $c$ in $T'$) [S1]. Define the material boundaries as three line segments connecting the edge intersections to the interior face point [S1].

**Pitfalls and Edge Cases:**
*   **Zero Volume Fraction:** If any vertex has a material value of zero, all points map to an edge of the barycentric triangle, reducing the problem to a two-material case [S1].
*   **Single Material:** If only one material is present at all three vertices, no intersections are calculated, and no boundary is generated [S1].
*   **Precision:** Care must be taken when determining if the center $c$ lies inside the interface region due to floating-point precision [G].

**Pseudocode:**
```python
def barycentric_mapping_2d(triangle_vertices, material_values):
    """
    triangle_vertices: List of 3 vectors [v1, v2, v3] in physical space.
    material_values: List of 3 floats [f1, f2, f3].
    Returns: List of line segments [(p1, p2), ...] in physical space.
    """
    v1, v2, v3 = triangle_vertices
    f1, f2, f3 = material_values

    # Single material case: no boundary exists
    if f1 == f2 == f3:
        return []

    # Reference triangle vertices in barycentric space
    p1, p2, p3 = (1, 0, 0), (0, 1, 0), (0, 0, 1)
    c = (1/3, 1/3, 1/3)

    # Voronoi boundaries in T' (standard for volume fractions) [G]
    # l_ij is the line lambda_i = lambda_j
    def get_intersection_on_edge(edge, i, j):
        # edge is a tuple of two barycentric vertices
        # On edge p1-p2: lambda3=0, lambda1+lambda2=1. Intersection with lambda1=lambda2 is (0.5, 0.5, 0)
        # On edge p2-p3: lambda1=0, lambda2+lambda3=1. Intersection with lambda2=lambda3 is (0, 0.5, 0.5)
        # On edge p3-p1: lambda2=0, lambda3+lambda1=1. Intersection with lambda3=lambda1 is (0.5, 0, 0.5)
        if edge == (p1, p2): return (0.5, 0.5, 0)
        if edge == (p2, p3): return (0, 0.5, 0.5)
        if edge == (p3, p1): return (0.5, 0, 0.5)
        return None

    edges = [(p1, p2), (p2, p3), (p3, p1)]
    intersections = []
    for i, j in [(1, 2), (1, 3), (2, 3)]:
        for edge in edges:
            pt = get_intersection_on_edge(edge, i, j)
            if pt is not None:
                intersections.append(pt)

    # Remove duplicates and sort for deterministic ordering
    unique_intersections = sorted(list(set(intersections)))

    # Check if center c is inside the interface region [G]
    # c is inside if no single material dominates at the center
    center_inside = not (f1 >= f2 and f1 >= f3) and not (f2 >= f1 and f2 >= f3) and not (f3 >= f1 and f3 >= f2)

    if not unique_intersections:
        return []

    # Map barycentric points to physical space
    def to_physical(bary):
        return bary[0]*v1 + bary[1]*v2 + bary[2]*v3

    physical_intersections = [to_physical(pt) for pt in unique_intersections]

    if center_inside:
        # Case 3: Connect edge intersections to interior point (mapped from c)
        interior_point = to_physical(c)
        segments = [(pt, interior_point) for pt in physical_intersections]
        return segments
    else:
        # Case 2: Connect edge intersections to each other
        # T' intersects at most two lines, yielding at most two intersection points
        segments = []
        for i in range(len(physical_intersections)):
            for j in range(i + 1, len(physical_intersections)):
                segments.append((physical_intersections[i], physical_intersections[j]))
        return segments
```
