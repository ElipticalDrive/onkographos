# Triangulation Improvement via Isosurface Projection

Also called: Moving dual vertices to the isosurface, Surface triangulation improvement

## Overview
A post-processing step for isosurface extraction that reduces sliver triangles by moving dual vertices onto the isosurface while keeping them within their respective cells [S1]. It differs from standard Marching Tetrahedra by explicitly correcting vertex positions to minimize geometric error, addressing the issue where vertices pass close to the isosurface and create numerous small, sliver triangles [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A simplicial partition with dual vertices $x$ located within cells, and a scalar field $F(p)$ [S1].
*   **Output:** An improved mesh where dual vertices lie on the isosurface $F(p)=0$, with degenerate triangles removed [S1].

**Data Structures:**
*   Dual vertices: Stored with their associated cell dimension $m$ (0 for vertex, 1 for edge, 2 for face, 3 for cube) [S1].
*   Boundary graph: Adjacency list or Union-Find structure for topological testing [S1].

**Parameters:**
*   $\epsilon$: Small constant used in the parent method to scale cells, which defines cell boundaries [S1].
*   Bisection tolerance: Not given in the sources.

**Steps:**
1.  **Ordering:** Process cells from highest dimension $m$ to lowest dimension $0$ (3 to 0) [S1]. This ensures that when a vertex is processed, its position is independent of lower-dimensional vertices that might depend on it [S1].
2.  **Topological Safety Test:** Before moving a dual vertex $x$ in an $m$-cell, verify that the portion of the isosurface intersecting the cell is a topological disk [S1]. Build a graph of edges on the cell boundary connecting dual vertices of dimension $i < m$ [S1].
    *   For $m=1$ (edge): Test that the two boundary vertices have opposite signs [S1].
    *   For $m=2$ (face): Check that there are exactly two sign changes along the boundary ring [S1].
    *   For $m=3$ (cube): Use the Union-Find algorithm to find connected components in the boundary graph [S1]. The test passes if the boundary forms a connected sheet with two disjoint inside/outside vertex sets [S1].
    *   If the test fails, do not move the vertex [S1].
3.  **Direction Selection:** If the test passes, evaluate the error at each dual vertex on the boundary (dimension $i < m$) that has an opposite sign to $x$ [S1]. Choose the boundary vertex $v_{bound}$ with the smallest error [S1]. The error metric is defined by Equation 1 in the source, which is not provided here [S1].
4.  **Bisection:** Perform a bisection algorithm between the current dual vertex $x$ and the chosen boundary vertex $v_{bound}$ to find a new position $x_{new}$ such that $F(x_{new}) = 0$ and $x_{new}$ lies on the isosurface [S1].
5.  **Update:** Replace $x$ with $x_{new}$ [S1].
6.  **Degeneracy Removal:** After all vertices are processed, remove any triangles that become degenerate due to the vertex movement [S1].

**Pseudocode:**
```python
def improve_triangulation(dual_vertices, scalar_field, boundary_graphs):
    # Process from m=3 down to m=0
    for m in [3, 2, 1, 0]:
        for cell in dual_vertices:
            if cell.dimension != m:
                continue
            x = cell.vertex
            boundary_vertices = get_boundary_vertices(cell)  # Not given in the sources.
            
            # Topological Safety Test
            if not is_topologically_safe(cell, boundary_vertices, scalar_field):
                continue
            
            # Find best direction
            opposite_vertices = [v for v in boundary_vertices 
                                 if scalar_field(v) * scalar_field(x) < 0]
            
            if not opposite_vertices:
                continue
                
            # Select vertex with smallest error (Equation 1 not provided in sources)
            v_bound = min(opposite_vertices, key=lambda v: compute_error(v, x))  # Not given in the sources.
            
            # Bisection to find isosurface intersection
            x_new = bisection_isosurface(x, v_bound, scalar_field)
            
            # Update vertex position
            cell.vertex = x_new

    # Remove degenerate triangles
    remove_degenerate_triangles(dual_vertices)  # Not given in the sources.

def is_topologically_safe(cell, boundary_vertices, scalar_field):
    m = cell.dimension
    if m == 1:
        if len(boundary_vertices) != 2:
            return False
        return scalar_field(boundary_vertices[0]) * scalar_field(boundary_vertices[1]) < 0
    elif m == 2:
        sign_changes = 0
        for i in range(len(boundary_vertices)):
            v1 = boundary_vertices[i]
            v2 = boundary_vertices[(i + 1) % len(boundary_vertices)]
            if scalar_field(v1) * scalar_field(v2) < 0:
                sign_changes += 1
        return sign_changes == 2
    elif m == 3:
        graph = build_boundary_graph(cell)  # Not given in the sources.
        components = union_find_components(graph)  # Standard Union-Find [G].
        if len(components) != 1:
            return False
        signs = [scalar_field(v) for v in graph.nodes]
        has_pos = any(s > 0 for s in signs)
        has_neg = any(s < 0 for s in signs)
        return has_pos and has_neg
    return True

def bisection_isosurface(x1, x2, scalar_field, tol=1e-6):
    while distance(x1, x2) > tol:  # Standard Euclidean distance [G].
        mid = (x1 + x2) / 2.0
        f_mid = scalar_field(mid)
        if f_mid == 0:
            return mid
        if scalar_field(x1) * f_mid < 0:
            x2 = mid
        else:
            x1 = mid
    return x1
```

**Edge Cases and Pitfalls:**
*   Moving vertices can change topology, creating non-manifold geometry if the portion of the isosurface intersecting the cell is not a topological disk [S1]. The topological safety test is required to prevent this [S1].
*   The value at the dual vertices and the magnitude of the gradient cannot be used to indicate proximity to the isosurface because no restrictions are placed on $F(p)$ [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the bisection iterations and the Union-Find operations [S1]. The Union-Find algorithm takes nearly linear time to find connected components in a graph [S1].
*   **Memory Complexity:** Requires storing the boundary graph for topological testing [S1].
*   **Strengths:** Reduces sliver triangles; preserves sharp features; exact topological safety test [S1].
*   **Limitations:** Can create non-manifold geometry if the safety test is skipped; requires careful handling of degenerate triangles [S1].

## Background
Developed for isosurfaces over simplicial partitions of multiresolution grids [S1]. It adapts a technique similar to Hall et al. [HW90] [S1]. The method addresses the issue of sliver triangles in Marching Tetrahedra-like methods where vertices pass close to the isosurface [S1].
