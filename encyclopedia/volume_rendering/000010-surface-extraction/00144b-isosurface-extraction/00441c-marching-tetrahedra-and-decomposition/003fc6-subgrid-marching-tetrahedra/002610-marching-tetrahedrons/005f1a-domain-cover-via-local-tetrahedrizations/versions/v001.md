# Domain Cover via Local Tetrahedrizations

Also called: Local Tetrahedrization for Domain Cover, Localized approach to visualize scattered data, Marching Stencil Tetrahedrization, Point-sampling isosurface extraction, Stencil Tetrahedrization

## Overview
Domain Cover via Local Tetrahedrizations is an isosurface generation algorithm designed for large-scale volumetric scattered data that avoids global tessellation or resampling [S1, unofficial]. It solves the domain cover problem by constructing a set of local tetrahedrizations over stencil point sets, ensuring their union covers the convex hull of the outer layer points [S1, unofficial]. Unlike its parent [Marching Tetrahedrons](3720-marching-tetrahedrons.md), which operates on a regular grid, this method adapts to irregular point distributions by regularizing the data via an octree-based binning grid and applying point-based contouring within each local tetrahedrization [S1, unofficial]. It differs from [Naive Isosurface Extraction](4328-naive-isosurface-extraction.md) by guaranteeing domain coverage without requiring a global mesh, and from [Adaptive Octree Marching Tetrahedra](3897-adaptive-octree-marching-tetrahedra.md) by using local stencils rather than hierarchical subdivision for surface approximation.

## How it works
The method extracts isosurfaces from scattered data by generating local tetrahedral meshes on-the-fly, applying marching tetrahedra to obtain initial triangle approximations, and projecting these triangles to the implicit surface defined by an interpolant (typically Radial Basis Functions) using Newton-Raphson iteration [S1, unofficial].

### Inputs and Outputs
*   **Input:** A set of scattered data points $P = \{p_i\}$, where each point has a 3D position and a scalar function value $f(p_i)$. An interpolation scheme (e.g., RBF) capable of evaluating $f(x)$ and its gradient $\nabla f(x)$ at arbitrary positions [S1, unofficial].
*   **Output:** A continuous point-based isosurface representation for a specified isovalue $v$ [S1, unofficial].

### Data Structures
1.  **Binning Grid:** A regular grid of size $2^{l_b} \times 2^{l_b} \times 2^{l_b}$ cells, where $l_b$ is the binning grid level. Each cell contains at least one data point (original or added). [S1, unofficial]
2.  **Stencil Point Set:** A subset of points from the binning grid corresponding to a $3 \times 3 \times 3$ block of cells. [S1, unofficial]
3.  **Local Tetrahedrization:** A Delaunay tetrahedralization of the Stencil Point Set. This is generated on-the-fly and discarded after use. [S1, unofficial]

### Algorithm Steps

1.  **Regularization and Binning Grid Construction:**
    *   Rescale all data points to fit inside an axis-aligned unit cube (the root node of an octree) [S1, unofficial].
    *   Refine the octree adaptively until each leaf cell contains at most one data point [S1, unofficial].
    *   Determine the binning grid level $l_b$:
        *   Traverse the octree in a depth-first fashion.
        *   Append the level of any node reached that contains at least one empty child node to a list $L$.
        *   If a leaf cell is encountered (a node containing only empty children), add its level to $L$.
        *   Select the median level of $L$ as $l_b$. [S1, unofficial]
        *   *Note:* Using the average level of $L$ results in a grid that is often too fine [S1, unofficial].
    *   Trim or augment the $2^{l_b} \times 2^{l_b} \times 2^{l_b}$ grid such that a single layer of cells surrounds the axis-aligned bounding box of the data points [S1, unofficial].
    *   Fill empty cells of the binning grid with a single data point at the center of the cell. Determine its function value by interpolating using the original data points. These additional points are used for tetrahedrization but not for evaluating the approximation [S1, unofficial].

2.  **Stencil Selection:**
    *   Define stencils centered in alternate cells of the binning grid to avoid excessive tetrahedrization overlap [S1, unofficial].
    *   Each stencil covers a $3 \times 3 \times 3$ block of binning grid cells [S1, unofficial].

3.  **Local Tetrahedrization Generation:**
    *   For each stencil, collect all points residing in the $3 \times 3 \times 3$ block of cells [S1, unofficial].
    *   Construct a Delaunay tetrahedralization of these points [S1, unofficial].
    *   *Note:* Local meshes do not need to conform to achieve domain cover; they may overlap or conform at boundaries [S1, unofficial].

4.  **Isosurface Contouring (Point-Based):**
    *   Apply marching tetrahedra to the local tetrahedrization to generate an initial set of triangles approximating the isosurface $f(x) = v$ [S1, unofficial].
    *   Decompose these triangles into a set of points [S1, unofficial].
    *   Project each point $x_0$ to the actual isosurface using Newton-Raphson iteration:
        $$ x_{k+1} = x_k - \frac{f(x_k) - v}{\|\nabla f(x_k)\|^2} \nabla f(x_k) $$
        where $f(x_k)$ is the interpolated scalar value and $\nabla f(x_k)$ is the interpolated gradient at $x_k$ [S1, unofficial].
    *   Converge the iteration when the displacement $\|x_{k+1} - x_k\|$ is less than a user-defined threshold (typically 0.01) [S1, unofficial].
    *   Discard the local tetrahedrization when the stencil is no longer needed [S1, unofficial].

5.  **Domain Cover Verification:**
    *   The union of the stencil tetrahedrizations covers the box formed by the outer layer points, which contains the domain of the data points. This ensures that the scattered data domain is appropriately covered [S1, unofficial].

### Pseudocode

```python
def domain_cover_local_tetrahedrization(scattered_points, isovalue, interpolation_method, convergence_threshold=0.01):
    """
    Extracts isosurface from scattered data using local tetrahedrizations.
    
    Args:
        scattered_points: List of (position, value) tuples.
        isovalue: The scalar value for the isosurface.
        interpolation_method: Function f(x) and gradient grad_f(x) for interpolation.
        convergence_threshold: Threshold for Newton-Raphson convergence.
        
    Returns:
        List of points representing the continuous isosurface.
    """
    
    # Step 1: Regularization and Binning Grid Construction
    # Rescale points to unit cube
    min_pos = min(p.position for p in scattered_points)
    max_pos = max(p.position for p in scattered_points)
    range_pos = max_pos - min_pos
    scale_factor = 1.0 / max(range_pos.x, range_pos.y, range_pos.z)
    
    rescaled_points = []
    for p in scattered_points:
        new_pos = (p.position - min_pos) * scale_factor
        rescaled_points.append(PointData(new_pos, p.value))
        
    # Build Octree
    octree = Octree(root_node=UnitCube())
    for p in rescaled_points:
        octree.insert(p)
        
    # Determine binning grid level lb
    levels_list = []
    traverse_octree_depth_first(octree.root, levels_list)
    
    if not levels_list:
        lb = 0 # Fallback if no empty children found, though unlikely with scattered data
    else:
        lb = median(levels_list)
        
    # Create Binning Grid
    grid_size = 2 ** lb
    binning_grid = Grid(size=grid_size, origin=min_pos, scale=range_pos)
    
    # Distribute points to cells
    for p in rescaled_points:
        cell = binning_grid.get_cell(p.position)
        if cell is not empty:
            cell.add_point(p)
        else:
            cell.add_point(p)
            
    # Fill empty cells
    for cell in binning_grid.all_cells():
        if cell.is_empty():
            center = cell.center()
            # Interpolate value at center using original scattered points
            value = interpolation_method.evaluate(center)
            # Map center back to original scale if needed, or keep in rescaled space
            # For consistency with interpolation, we assume interpolation works on rescaled coords
            # or we map back. The source implies interpolation is done on the data domain.
            # Let's assume interpolation_method handles the coordinate system.
            added_point = PointData(center, value)
            cell.add_point(added_point)
            
    # Ensure single layer of cells surrounds bounding box
    # This is handled by the grid construction logic in the source description
    # "Trim or augment the 2^lb x 2^lb x 2^lb grid such that a single layer of cells 
    # of the binning grid surrounds the axis-aligned bounding box of the data points."
    # Implementation detail: Expand grid boundaries by one cell layer if necessary.
    
    # Step 2 & 3: Stencil Selection and Local Tetrahedrization
    isosurface_points = []
    
    # Iterate over alternate cells for stencils
    for cell in binning_grid.cells_with_stride(2):
        stencil_points = get_points_in_3x3x3_stencil(binning_grid, cell)
        
        # Generate Delaunay Tetrahedrization
        tetrahedra = delaunay_tetrahedrization(stencil_points)
        
        # Step 4: Isosurface Contouring
        initial_triangles = marching_tetrahedra(tetrahedra, isovalue)
        
        # Decompose triangles into points
        triangle_points = decompose_triangles(initial_triangles)
        
        # Project points to implicit surface
        for pt in triangle_points:
            projected_pt = newton_raphson_project(pt, isovalue, interpolation_method, convergence_threshold)
            isosurface_points.append(projected_pt)
            
    return isosurface_points

def traverse_octree_depth_first(node, levels_list):
    """
    Traverses octree to find levels for binning grid determination.
    """
    if node.is_leaf():
        # Leaf node contains only empty children (or is a leaf in the adaptive sense)
        # Source: "If a leaf cell is encountered, its level is also added to the list."
        levels_list.append(node.level)
        return
        
    has_empty_child = False
    for child in node.children:
        if child.is_empty():
            has_empty_child = True
        else:
            traverse_octree_depth_first(child, levels_list)
            
    if has_empty_child:
        levels_list.append(node.level)

def newton_raphson_project(point, isovalue, interpolation_method, threshold):
    """
    Projects a point to the isosurface f(x) = isovalue using Newton-Raphson.
    """
    current_pt = point
    while True:
        f_val = interpolation_method.evaluate(current_pt)
        grad = interpolation_method.gradient(current_pt)
        
        # Avoid division by zero if gradient is zero
        grad_norm_sq = dot(grad, grad)
        if grad_norm_sq < 1e-10:
            break
            
        displacement = (f_val - isovalue) / grad_norm_sq
        next_pt = current_pt - displacement * grad
        
        dist = distance(next_pt, current_pt)
        current_pt = next_pt
        
        if dist < threshold:
            break
            
    return current_pt
```

### Parameters
*   **Stencil Size:** $3 \times 3 \times 3$ binning grid cells [S1, unofficial].
*   **Binning Grid Level ($l_b$):** Determined as the median of node levels encountered during depth-first octree traversal where nodes have empty children or are leaves [S1, unofficial].
*   **Stencil Configuration:** Stencils are centered in alternate cells [S1, unofficial].
*   **Convergence Threshold:** Set to 0.01 for Newton-Raphson iteration [S1, unofficial].

### Pitfalls
*   **Binning Grid Level Selection:** Using the average level of the octree traversal list for $l_b$ can result in a binning grid that is often too fine, increasing computational cost [S1, unofficial].
*   **Discontinuity:** Initial triangles from local tetrahedrization may be discontinuous, but discontinuities disappear after projection to the implicit surface [S1, unofficial].
*   **Interpolation Cost:** The method's performance is sensitive to the computational requirements of the interpolation method, which is slow for scattered data [S1, unofficial].

## Subtopics

### Point-Based Isosurface Contouring
A method to construct isosurfaces from scattered data by using marching tetrahedra on local tetrahedrizations to get an initial triangle approximation, then decomposing triangles into points and projecting them to the implicit surface defined by the RBF interpolant [S1, unofficial]. It performs isosurface generation in a streaming fashion, storing only the current stencil tetrahedrization in main memory [S1, unofficial]. Compared to resampling techniques and trilinear interpolation, this method is slower but retains original data information and context without introducing biases [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The method is sensitive to the computational requirements of the interpolation method, which is generally slow for large-scale scattered data [S1, unofficial]. The local tetrahedrizations are generated on-the-fly, avoiding global mesh construction costs.
*   **Memory Complexity:** Low memory requirement for storing tetrahedrizations because they are generated on-the-fly and discarded when the stencil is no longer needed [S1, unofficial]. Only the current stencil tetrahedrization needs to be stored in main memory at any given time [S1, unofficial].
*   **Scaling:** The technique scales to large parallel computational systems and can be easily modified to utilize new interpolation methods [S1, unofficial]. A parallel version was implemented using a master-slave architecture with MPI [S1, unofficial].
*   **Strengths:** Produces faithful renderings of large-scale scientific data; makes very few assumptions about the density of the point distribution; constructs visual representations directly without global tessellation or resampling; retains original data information and context [S1, unofficial].
*   **Limitations:** Slower than resampling techniques and trilinear interpolation; performance is heavily dependent on the speed of the underlying interpolation scheme [S1, unofficial].

## Background
The method was presented by Christopher S. Co and Ken Joy in the paper "Isosurface Generation for Large-Scale Scattered Data Visualization" [S1, unofficial]. It addresses the limitations of global tessellation and resampling methods for scattered data, which can introduce biases or lose context. The approach builds on point-based and meshless isosurface generation techniques, adapting marching tetrahedra for local stencil-based processing [S1, unofficial].
