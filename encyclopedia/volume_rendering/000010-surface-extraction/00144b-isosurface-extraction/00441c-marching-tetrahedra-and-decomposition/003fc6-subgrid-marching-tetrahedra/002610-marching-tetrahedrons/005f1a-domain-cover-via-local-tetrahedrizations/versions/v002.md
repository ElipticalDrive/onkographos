# Domain Cover via Local Tetrahedrizations

Also called: Local Tetrahedrization for Domain Cover, Localized approach to visualize scattered data, Marching Stencil Tetrahedrization, Point-sampling isosurface extraction, Stencil Tetrahedrization

## Overview
Domain Cover via Local Tetrahedrizations is an isosurface generation algorithm designed for large-scale volumetric scattered data that avoids global tessellation or resampling [S1, unofficial]. It solves the domain cover problem by constructing a set of local tetrahedrizations over stencil point sets, ensuring their union covers the convex hull of the outer layer points [S1, unofficial]. Unlike its parent [Marching Tetrahedrons](3720-marching-tetrahedrons.md), which operates on a regular grid, this method adapts to irregular point distributions by regularizing the data via an octree-based binning grid and applying point-based contouring within each local tetrahedrization [S1, unofficial]. It differs from [Naive Isosurface Extraction](4328-naive-isosurface-extraction.md) by guaranteeing domain coverage without requiring a global mesh, and from [Adaptive Octree Marching Tetrahedra](3897-adaptive-octree-marching-tetrahedra.md) by using local stencils rather than hierarchical subdivision for surface approximation [G].

## How it works
The method extracts isosurfaces from scattered data by generating local tetrahedral meshes on-the-fly, applying marching tetrahedra to obtain initial triangle approximations, and projecting these triangles to the implicit surface defined by an interpolant using Newton-Raphson iteration [S1, unofficial].

### Inputs and Outputs
*   **Input:** A set of scattered data points $P = \{p_i\}$, where each point has a 3D position and a scalar function value $f(p_i)$ [S1, unofficial]. An interpolation scheme (e.g., Radial Basis Functions) capable of evaluating $f(x)$ at arbitrary positions [S1, unofficial].
*   **Output:** A continuous point-based isosurface representation for a specified isovalue $v$ [S1, unofficial].

### Data Structures
1.  **Binning Grid:** A regular grid of size $2^{l_b} \times 2^{l_b} \times 2^{l_b}$ cells, where $l_b$ is the binning grid level [S1, unofficial]. Each cell contains at least one data point (original or added) [S1, unofficial].
2.  **Stencil Point Set:** A subset of points from the binning grid corresponding to a $3 \times 3 \times 3$ block of cells [S1, unofficial].
3.  **Local Tetrahedrization:** A Delaunay tetrahedralization of the Stencil Point Set [S1, unofficial]. This is generated on-the-fly and discarded after use [S1, unofficial].

### Algorithm Steps

1.  **Regularization and Binning Grid Construction:**
    *   Rescale all data points to fit inside an axis-aligned unit cube (the root node of an octree) [S1, unofficial].
    *   Refine the octree adaptively until each leaf cell contains at most one data point [S1, unofficial].
    *   Determine the binning grid level $l_b$:
        *   Traverse the octree in a depth-first fashion [S1, unofficial].
        *   Append the level of any node reached that contains at least one empty child node to a list $L$ [S1, unofficial].
        *   If a leaf cell is encountered (a node containing only empty children), add its level to $L$ [S1, unofficial].
        *   Select the median level of $L$ as $l_b$ [S1, unofficial].
        *   *Note:* Using the average level of $L$ results in a grid that is often too fine [S1, unofficial].
    *   Trim or augment the $2^{l_b} \times 2^{l_b} \times 2^{l_b}$ grid such that a single layer of cells surrounds the axis-aligned bounding box of the data points [S1, unofficial].
    *   Fill empty cells of the binning grid with a single data point at the center of the cell [S1, unofficial]. Determine its function value by interpolating using the original data points [S1, unofficial]. These additional points are used for tetrahedrization but not for evaluating the approximation [S1, unofficial].

2.  **Stencil Selection:**
    *   Define stencils centered in alternate cells of the binning grid to avoid excessive tetrahedrization overlap [S1, unofficial].
    *   Each stencil covers a $3 \times 3 \times 3$ block of binning grid cells [S1, unofficial].

3.  **Local Tetrahedrization Generation:**
    *   For each stencil, collect all points residing in the $3 \times 3 \times 3$ block of cells [S1, unofficial].
    *   Construct a Delaunay tetrahedralization of these points [S1, unofficial].
    *   *Note:* Local meshes do not need to conform to achieve domain cover; they may overlap or conform at boundaries [S1, unofficial].

4.  **Isosurface Contouring (Point-Based):**
    *   Apply marching tetrahedra to the local tetrahedrization to generate an initial set of triangles approximating the isosurface $f(x) = v$ [S1, unofficial].
    *   Decompose these triangles into a set of points [S1, unofficial].
    *   Project each point $x_0$ to the actual isosurface using Newton-Raphson iteration [S1, unofficial]. The update step follows the standard implicit surface projection $x_{k+1} = x_k - \frac{f(x_k) - v}{\|\nabla f(x_k)\|^2} \nabla f(x_k)$ [G].
    *   Converge the iteration when the displacement $\|x_{k+1} - x_k\|$ is less than a user-defined threshold (typically 0.01) [S1, unofficial].
    *   Discard the local tetrahedrization when the stencil is no longer needed [S1, unofficial].

5.  **Domain Cover Verification:**
    *   The union of the stencil tetrahedrizations covers the box formed by the outer layer points, which contains the domain of the data points [S1, unofficial]. This ensures that the scattered data domain is appropriately covered [S1, unofficial].

class PointData:

        self.position = position
        self.value = value

class OctreeNode:
    def __init__(self, level, bounds, children=None, points=None):
        self.level = level
        self.bounds = bounds
        self.children = children if children else []
        self.points = points if points else []
        self.is_leaf = len(self.children) == 0

    def is_empty(self):
        return len(self.points) == 0 and all(c.is_empty() for c in self.children)

def build_octree(points, level=0, bounds=(0,0,0, 1,1,1)):
    node = OctreeNode(level, bounds, points=points)
    if level < 10:
        mid = [(bounds[i] + bounds[i+3]) / 2 for i in range(3)]
        children = []
        for dx in (0, 1):
            for dy in (0, 1):
                for dz in (0, 1):
                    child_bounds = (
                        bounds[0] + dx*mid[0], bounds[1] + dy*mid[1], bounds[2] + dz*mid[2],
                        mid[0] + dx*(bounds[3]-mid[0]), mid[1] + dy*(bounds[4]-mid[1]), mid[2] + dz*(bounds[5]-mid[2])
                    )
                    child_pts = [p for p in points if 
                                 bounds[0] + dx*mid[0] <= p.position[0] < mid[0] + dx*(bounds[3]-mid[0]) and
                                 bounds[1] + dy*mid[1] <= p.position[1] < mid[1] + dy*(bounds[4]-mid[1]) and
                                 bounds[2] + dz*mid[2] <= p.position[2] < mid[2] + dz*(bounds[5]-mid[2])]
                    children.append(build_octree(child_pts, level + 1, child_bounds))
        node.children = children
    return node

def traverse_octree_depth_first(node, levels_list):
    if node.is_leaf:
        levels_list.append(node.level)
        return
    has_empty_child = any(c.is_empty() for c in node.children)

def newton_raphson_project(point, isovalue, interp_func, threshold):
    current_pt = point
    for _ in range(100):
        f_val = interp_func(current_pt)
        grad = interp_func.gradient(current_pt)
        grad_norm_sq = sum(g*g for g in grad)
        if grad_norm_sq < 1e-10:
            break
        displacement = (f_val - isovalue) / grad_norm_sq
        next_pt = tuple(current_pt[i] - displacement * grad[i] for i in range(3))

def domain_cover_local_tetrahedrization(scattered_points, isovalue, interpolation_method, convergence_threshold=0.01):
    # Step 1: Regularization and Binning Grid Construction
    min_pos = tuple(min(p.position[i] for p in scattered_points) for i in range(3))
    max_pos = tuple(max(p.position[i] for p in scattered_points) for i in range(3))
    range_pos = tuple(max_pos[i] - min_pos[i] for i in range(3))
    scale_factor = 1.0 / max(range_pos)
    
    rescaled_points = [PointData(tuple((p.position[i] - min_pos[i]) * scale_factor for i in range(3)), p.value) for p in scattered_points]
    
    octree = build_octree(rescaled_points)
    
    levels_list = []
    traverse_octree_depth_first(octree, levels_list)
    lb = statistics.median(levels_list) if levels_list else 0
    
    grid_size = 2 ** lb
    binning_grid_cells = [[[[[] for _ in range(grid_size)] for _ in range(grid_size)] for _ in range(grid_size)] for _ in range(grid_size)]
    
    for p in rescaled_points:
        idx = tuple(int(p.position[i] * grid_size) for i in range(3))
        idx = tuple(min(i, grid_size - 1) for i in idx)
        binning_grid_cells[idx[0]][idx[1]][idx[2]].append(p)
        
    for x in range(grid_size):
        for y in range(grid_size):
            for z in range(grid_size):
                if not binning_grid_cells[x][y][z]:
                    center = tuple((x + 0.5) / grid_size for _ in range(3))
                    value = interpolation_method.evaluate(center)
                    binning_grid_cells[x][y][z].append(PointData(center, value))
                    
    # Ensure single layer of cells surrounds bounding box (handled by grid bounds in practice)
    
    # Step 2 & 3: Stencil Selection and Local Tetrahedrization
    isosurface_points = []
    
    for x in range(0, grid_size, 2):
        for y in range(0, grid_size, 2):
            for z in range(0, grid_size, 2):
                stencil_points = get_points_in_3x3x3_stencil(type('Grid', (), {'size': grid_size, 'cells': binning_grid_cells})(), type('Cell', (), {'index': (x,y,z)})())
                tetrahedra = delaunay_tetrahedrization(stencil_points)
                initial_triangles = marching_tetrahedra(tetrahedra, isovalue)
                triangle_points = decompose_triangles(initial_triangles)
                
                for pt in triangle_points:
                    projected_pt = newton_raphson_project(pt, isovalue, interpolation_method, convergence_threshold)
                    isosurface_points.append(projected_pt)
                    
    return isosurface_points

### Parameters
*   **Stencil Size:** $3 \times 3 \times 3$ binning grid cells [S1, unofficial].
*   **Binning Grid Level ($l_b$):** Determined as the median of node levels encountered during depth-first octree traversal where nodes have empty children or are leaves [S1, unofficial].
*   **Stencil Configuration:** Stencils are centered in alternate cells [S1, unofficial].
*   **Convergence Threshold:** Set to 0.01 for Newton-Raphson iteration [S1, unofficial].

### Pitfalls
*   **Binning Grid Level Selection:** Using the average level of the octree traversal list for $l_b$ can result in a binning grid that is often too fine, increasing computational cost [S1, unofficial].
*   **Discontinuity:** Initial triangles from local tetrahedrization may be discontinuous, but discontinuities disappear after projection to the implicit surface [S1, unofficial].
*   **Interpolation Cost:** The method's performance is sensitive to the computational requirements of the interpolation method, which is slow for scattered data [S1, unofficial].

## Subtopics

### Point-Based Isosurface Contouring
A method to construct isosurfaces from scattered data by using marching tetrahedra on local tetrahedrizations to get an initial triangle approximation, then decomposing triangles into points and projecting them to the implicit surface defined by the RBF interpolant [S1, unofficial]. It performs isosurface generation in a streaming fashion, storing only the current stencil tetrahedrization in main memory [S1, unofficial]. Compared to resampling techniques and trilinear interpolation, this method is slower but retains original data information and context without introducing biases [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The method is sensitive to the computational requirements of the interpolation method, which is generally slow for large-scale scattered data [S1, unofficial]. The local tetrahedrizations are generated on-the-fly, avoiding global mesh construction costs [S1, unofficial].
*   **Memory Complexity:** Low memory requirement for storing tetrahedrizations because they are generated on-the-fly and discarded when the stencil is no longer needed [S1, unofficial]. Only the current stencil tetrahedrization needs to be stored in main memory at any given time [S1, unofficial].
*   **Scaling:** The technique scales to large parallel computational systems and can be easily modified to utilize new interpolation methods [S1, unofficial]. A parallel version was implemented using a master-slave architecture with MPI [S1, unofficial].
*   **Strengths:** Produces faithful renderings of large-scale scientific data; makes very few assumptions about the density of the point distribution; constructs visual representations directly without global tessellation or resampling; retains original data information and context [S1, unofficial].
*   **Limitations:** Slower than resampling techniques and trilinear interpolation; performance is heavily dependent on the speed of the underlying interpolation scheme [S1, unofficial].

## Background
The method was presented by Christopher S. Co and Ken Joy in the paper "Isosurface Generation for Large-Scale Scattered Data Visualization" [S1, unofficial]. It addresses the limitations of global tessellation and resampling methods for scattered data, which can introduce biases or lose context [S1, unofficial]. The approach builds on point-based and meshless isosurface generation techniques, adapting marching tetrahedra for local stencil-based processing [S1, unofficial].
