# Error Analysis via Marching Tetrahedra

Also called: Isosurface Error Evaluation

## Overview
Error Analysis via Marching Tetrahedra is a metric for evaluating the geometric and topological approximation error when fusing two child tetrahedra into a single parent tetrahedron within a multiresolution tetrahedral framework [S1]. It determines whether the simplification of the mesh preserves the isosurface geometry defined by a specific threshold [S1]. Unlike sibling methods that may rely on view-dependent projection or generic distance bounds, this method explicitly calculates the physical displacement of isosurface intersection points along specific segments within the tetrahedron, ensuring topological consistency during fusion [S1].

## How it works
The method evaluates the error introduced by replacing two fine-resolution tetrahedra with one coarse tetrahedron. It assumes that the density field within any tetrahedron is evaluated using trilinear interpolation of vertex densities [S1]. The error is defined as the maximum physical distance between the isosurface intersection points generated by the fine mesh versus the coarse mesh [S1].

### Inputs and Outputs
*   **Input**: A parent tetrahedron $T$ and its two child tetrahedra (or the configuration resulting from their subdivision). The density values at all vertices of the tetrahedra. The isosurface threshold value $V_{iso}$.
*   **Output**: A scalar error value $E$. If $E$ exceeds a user-defined tolerance, fusion is forbidden.

### Data Structures
The method operates on the geometric and scalar properties of a single tetrahedron.
*   **Vertices**: Four vertices $v_0, v_1, v_2, v_3$.
*   **Densities**: Scalar density values $d_0, d_1, d_2, d_3$ associated with each vertex.
*   **Dividing Point**: A point $p_{div}$ on an edge $L$ where the isosurface intersects. This point is calculated via linear interpolation between the endpoints of edge $L$ based on the isovalue.

### Steps
1.  **Sign Assignment**: Assign a sign to each vertex density relative to the isosurface threshold $V_{iso}$.
    *   Sign is **positive** if $d_i > V_{iso}$.
    *   Sign is **negative** if $d_i \le V_{iso}$ [S1].

2.  **Topological Change Check**:
    *   Identify edge $L$ bisected by the isosurface in the child configuration. Let the endpoints of $L$ be $u$ and $v$, and the dividing point be $p_{div}$.
    *   Check if the endpoints $u$ and $v$ have the **same sign** and the dividing point $p_{div}$ has the **opposite sign**. This corresponds to cases where the isosurface topology changes upon fusion (specifically Cases a2, b2, c3 in the source figures) [S1].
    *   If this condition is met, return a sufficiently large error value (effectively infinity) to forbid fusion [S1].

3.  **Geometric Error Calculation**:
    *   If no topological change is detected, define four segments connecting the dividing point $p_{div}$ to each of the four vertices of the tetrahedron: $S_i = (p_{div}, v_i)$ for $i=0..3$ [S1].
    *   For each segment $S_i$:
        *   Determine the sign of the endpoints under two density assumptions:
            1.  Using the actual density of the dividing point $d(p_{div})$.
            2.  Using the average density of the edge endpoints of $L$ (denoted as $d_{avg}$) [S1].
        *   If the endpoints of segment $S_i$ have **different signs** under either assumption, calculate the distance between the isosurface intersection point computed using $d(p_{div})$ and the intersection point computed using $d_{avg}$ [S1].
        *   If the endpoints have the **same sign** under both assumptions, the distance is zero [S1].
    *   The approximation error $E$ is the maximum of all calculated distances across the four segments [S1].

### Parameters
*   **Error Metric**: Physical distance between iso-points. Projected (viewpoint-dependent) distance is an alternative, but physical distance was found efficient in experiments [S1].
*   **Threshold**: A user-defined tolerance. If the calculated error exceeds this, fusion is rejected [S1].

### Edge Cases and Pitfalls
*   **Topological Changes**: If the endpoints of edge $L$ have the same sign and the dividing point has the opposite sign, the isosurface topology changes. This must be detected and forbidden by returning a large error value [S1].
*   **Precision**: Linear interpolation assumes a smooth density field. Discontinuities in the volume data may lead to inaccurate iso-point calculations [S1].
*   **Degenerate Input**: If vertex densities are identical, the dividing point calculation may involve division by zero. The topological check should handle cases where no intersection occurs [S1].

## Operating characteristics
*   **Time Complexity**: Subdivision time is constant and independent of data values (e.g., 90 seconds for $129^3$ resolution) [S1]. Fusion time varies depending on data complexity and the number of error evaluations required (e.g., 19–55 seconds for $129^3$) [S1].
*   **Memory Complexity**: Depends on the number of tetrahedra retained after fusion. Higher error tolerances lead to fewer tetrahedra and triangles [S1].
*   **Measured Performance**:
    *   **Box Data ($129^3$)**: Initial mesh has 1,646,568 tetrahedra and 182,376 triangles. With error=4.0, it reduces to 114,556 tetrahedra and 51,490 triangles (93.04% fusion) [S1].
    *   **CT Head Data ($129^3$)**: Initial mesh has 5,390,896 tetrahedra and 255,256 triangles. With error=4.0, it reduces to 304,468 tetrahedra and 89,300 triangles (94.35% fusion) [S1].
*   **Strengths**: Efficient physical distance calculation; preserves smooth changes along boundaries of different levels-of-detail [S1].
*   **Limitations**: Fusion time depends on data complexity; topological changes must be explicitly guarded against [S1].

## Background
The method was introduced in the context of multiresolution tetrahedral frameworks for visualizing regular volume data. It builds upon the Marching Tetrahedra algorithm [ZCT95] to provide a robust error metric for mesh simplification. The approach was implemented in C with OpenGL and tested on SGI Power Challenge hardware [S1].
