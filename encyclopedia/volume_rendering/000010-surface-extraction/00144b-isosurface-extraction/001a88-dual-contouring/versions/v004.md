# Dual Contouring

Also called: Ju's method, Ju et al. 2002 dual contouring, Dual Contouring of Hermite Data, QEF-based Dual Contouring, Dual Contouring with QEF Vertex Optimization

## Overview

Dual Contouring is an isosurface extraction algorithm that places a single vertex inside each grid cell intersected by the surface, optimizing its position by minimizing a Quadratic Error Function (QEF) derived from Hermite data (intersection points and surface normals) [S1, S2, S7]. Unlike Marching Cubes, which places vertices on cell edges, Dual Contouring preserves sharp features and produces manifold, watertight meshes [S5, S9].

## How it works

### Inputs and Outputs
**Inputs:**
- A scalar field $f(x, y, z)$ or Signed Distance Field (SDF) [S1, S2].
- Grid dimensions and bounds $[x_{min}, x_{max}) \times [y_{min}, y_{max}) \times [z_{min}, z_{max})$ [S4].
- Optional: Pre-computed Hermite data (intersection points and normals) [S7].
- Parameters: Regularization weight ($reg$), SVD tolerance ($svd\_tol$), clamp flag ($clamp$), iteration counts ($outer\_iters, inner\_iters$), SDF weights ($\mu, hermite\_weight, update\_weight$), and convergence tolerance ($tol$) [S7].

**Outputs:**
- A list of vertices and a list of faces (quads or triangles) forming the mesh [S1, S2, S3].
- Data structures: `vert_indices` mapping cell coordinates $(x, y, z)$ to vertex indices [S4].

### Data Structures

**Intersection Struct** [S7]:
- `points`: `NDArray<float3>` of intersection points $(N, 3)$.
- `normals`: `NDArray<float3>` of surface normals $(N, 3)$.
- `edges`: `NDArray<uint2>` identifying the edges crossed.
- `cell_indices`: `NDArray<uint>` mapping intersections to cells.
- `cell_offsets`: `NDArray<uint>` offsets for cell-based iteration.
- `is_out`: `NDArray<bool>` status flags.
- `_has_normals`: `bool` indicating if normals are present.

**QEF Matrix** (per cell) [S1]:
- Matrix $A$ of size $k \times 3$, where $k$ is the number of intersection points. Each row $i$ is the normal vector $n_i$ [S1].
- Vector $b$ of size $k$, where $b_i = \text{dot}(n_i, P_i)$ [S1].

### Steps

1. **Grid Traversal and Intersection Detection**: Iterate over all cells $(x, y, z)$ in the grid range [S4]. For each cell, evaluate the scalar field at the 8 corners $v_{dx,dy,dz} = f(x+dx, y+dy, z+dz)$ where $dx, dy, dz \in \{0, 1\}$ [S4]. Identify edges where the sign of the field changes (i.e., $v_{start} > 0 \neq v_{end} > 0$) [S4]. If fewer than 2 sign-changing edges exist, skip the cell (no vertex created) [S4, pitfall].
2. **Intersection Point and Normal Computation**: For each intersected edge, compute the intersection point $P$ using linear interpolation [S4]:
   $$ P = V_a + t(V_b - V_a), \quad t = \frac{I - f(V_a)}{f(V_b) - f(V_a)} $$
   where $V_a, V_b$ are the edge endpoints, $f(V_a), f(V_b)$ are the scalar field values at the endpoints, and $I$ is the isovalue [S4]. Normals are typically pre-computed or derived from the gradient of the scalar field [S7].
3. **QEF Construction**: For each cell, construct the QEF system $A V = b$ [S1]. Rows of $A$ are the normals $n_i$ at intersection points $P_i$ [S1]. Elements of $b$ are $b_i = \text{dot}(n_i, P_i)$ [S1].
4. **Vertex Placement (QEF Solution)**: Solve for vertex position $V$ by minimizing $\| A V - b \|^2$ [S1]. Use Jacobi SVD eigendecomposition for the symmetric positive semi-definite system [S9]. Use mass-point bias for rank-deficient cases (e.g., coplanar normals) [S9]. If $clamp$ is true, the vertex position is constrained to the cell bounds [S7].
5. **Mesh Generation (Quad/Triangle Creation)**: For each sign-changing minimal grid edge, identify the 4 cells sharing that edge [S5]. Each cell contributes its computed vertex to form a quad [S5]. Split quads into triangles [S5].

### Pseudocode

```python
import math

def dual_contouring(grid, level=0.0, reg=1e-2, svd_tol=1e-6, clamp=True, bias_strength=0.0):
    """
    Extracts isosurface from grid using Dual Contouring.
    grid: 3D array of scalar values.
    level: Iso-value (default 0.0).
    reg: Regularization weight for QEF.
    svd_tol: SVD tolerance.
    clamp: Clamp vertex to cell bounds.
    bias_strength: Weight for mass-point bias to handle rank deficiency.
    """
    vertices = []
    faces = []
    vert_indices = {}
    shape = grid.shape
    
    def dot(a, b): return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]
    def lerp(p0, p1, t): return [p0[d] + t*(p1[d]-p0[d]) for d in range(3)]
    def clamp_val(v, min_v, max_v): return max(min_v, min(max_v, v))
    
    def find_edges(corners, level):
        edges = []
        edge_pairs = [(0,1), (0,2), (0,4), (1,3), (1,5), (2,3), (2,6), (3,7), (4,5), (4,6), (5,7), (6,7)]
        for i, j in edge_pairs:
            if (corners[i] - level) * (corners[j] - level) < 0:
                edges.append((i, j))
        return edges

    def compute_normal(grid, p, shape):
        ix = clamp_val(int(round(p[0])), 1, shape[0]-2)
        iy = clamp_val(int(round(p[1])), 1, shape[1]-2)
        iz = clamp_val(int(round(p[2])), 1, shape[2]-2)
        fx = (grid[ix+1, iy, iz] - grid[ix-1, iy, iz]) / 2.0
        fy = (grid[ix, iy+1, iz] - grid[ix, iy-1, iz]) / 2.0
        fz = (grid[ix, iy, iz+1] - grid[ix, iy, iz-1]) / 2.0
        norm = math.sqrt(fx**2 + fy**2 + fz**2)
        if norm == 0: return [0, 0, 1]
        return [fx/norm, fy/norm, fz/norm]

    def solve_qef(A, b, reg, tol):
        # Solve normal equations (A^T A) V = A^T b with regularization
        AtA = [[0.0]*3 for _ in range(3)]
        Atb = [0.0]*3
        for k in range(len(A)):
            for i in range(3):
                for j in range(3):
                    AtA[i][j] += A[k][i] * A[k][j]
                Atb[i] += A[k][i] * b[k]
        for i in range(3):
            AtA[i][i] += reg
            
        # Gaussian elimination
        M = [AtA[i] + [Atb[i]] for i in range(3)]
        for i in range(3):
            pivot = M[i][i]
            if abs(pivot) < tol:
                pivot = tol
            for j in range(i+1, 3):
                factor = M[j][i] / pivot
                for k in range(i, 4):
                    M[j][k] -= factor * M[i][k]
        V = [0.0]*3
        for i in range(2, -1, -1):
            V[i] = M[i][3]
            for j in range(i+1, 3):
                V[i] -= M[i][j] * V[j]
            V[i] /= M[i][i]
        return V

    for x in range(shape[0] - 1):
        for y in range(shape[1] - 1):
            for z in range(shape[2] - 1):
                corners = [
                    grid[x, y, z], grid[x+1, y, z], grid[x, y+1, z], grid[x+1, y+1, z],
                    grid[x, y, z+1], grid[x+1, y, z+1], grid[x, y+1, z+1], grid[x+1, y+1, z+1]
                ]
                edge_indices = find_edges(corners, level)
                if len(edge_indices) < 2:
                    continue
                
                intersections = []
                for i, j in edge_indices:
                    v0, v1 = corners[i], corners[j]
                    t = (level - v0) / (v1 - v0) if abs(v1 - v0) > 1e-9 else 0.5
                    p0 = [x + (i&1), y + ((i>>1)&1), z + (i>>2)]
                    p1 = [x + (j&1), y + ((j>>1)&1), z + (j>>2)]
                    P = lerp(p0, p1, t)
                    n = compute_normal(grid, P, shape)
                    intersections.append((P, n))
                
                A = [n for _, n in intersections]
                b = [dot(n, P) for P, n in intersections]
                
                # Mass-point bias for rank deficiency
                if bias_strength > 0:
                    centroid = [sum(p[d] for p, _ in intersections) / len(intersections) for d in range(3)]
                    for d in range(3):
                        axis_normal = [0.0, 0.0, 0.0]
                        axis_normal[d] = bias_strength
                        A.append(axis_normal)
                        b.append(dot(axis_normal, centroid))
                
                V = solve_qef(A, b, reg, svd_tol)
                
                if clamp:
                    V = [clamp_val(V[d], x, x+1) for d in range(3)]
                
                cell_key = (x, y, z)
                vert_indices[cell_key] = len(vertices)
                vertices.append(V)

    # Face generation: iterate over all grid edges to form quads/triangles
    edge_cells = {}
    for x in range(shape[0] - 1):
        for y in range(shape[1] - 1):
            for z in range(shape[2] - 1):
                if (x, y, z) not in vert_indices: continue
                for dx, dy, dz in [(1,0,0), (0,1,0), (0,0,1)]:
                    ex, ey, ez = min(x, x+dx), min(y, y+dy), min(z, z+dz)
                    edge_key = (ex, ey, ez, dx, dy, dz)
                    if edge_key not in edge_cells:
                        edge_cells[edge_key] = []
                    edge_cells[edge_key].append((x, y, z))

    for edge_key, cells in edge_cells.items():
        if len(cells) == 0: continue
        cells.sort(key=lambda c: c[0]+c[1]+c[2])
        verts = [vert_indices[c] for c in cells]
        if len(verts) == 4:
            faces.append([verts[0], verts[1], verts[2]])
            faces.append([verts[0], verts[2], verts[3]])
        elif len(verts) == 3:
            faces.append(verts)
                
    return vertices, faces
```

### Parameters

- `reg`: Regularization weight for QEF. Default: $10^{-2}$ [S7].
- `svd_tol`: SVD tolerance for solving QEF. Default: $10^{-6}$ [S7].
- `clamp`: Whether to clamp vertex position to cell bounds. Default: `true` [S7].
- `outer_iters`: Number of outer iteration steps (for SDF variants). Default: 100 [S7].
- `inner_iters`: Number of inner iteration steps. Default: 100 [S7].
- `mu`: Weight parameter for SDF constraint. Default: 0.1 [S7].
- `hermite_weight`: Weight for Hermite data in QEF. Default: 0.02 [S7].
- `update_weight`: Weight for updating Hermite data. Default: 0.2 [S7].
- `hermite_update`: Whether to update Hermite data during iterations. Default: `true` [S7].
- `qef_assignment`: Whether to use QEF assignment. Default: `true` [S7].
- `band`: Bandwidth parameter for SDF processing (in cell diagonals). Default: 3.0 [S7].
- `tol`: Convergence tolerance. Default: $10^{-5}$ [S7].

### Edge Cases and Pitfalls

- **Degenerate Cells**: If fewer than 2 sign-changing edges exist in a cell, no vertex is created [S4, pitfall].
- **Rank Deficiency**: If normals are coplanar or collinear, the QEF matrix is singular. Use SVD truncation or mass-point bias [S9].
- **Boundary Handling**: Edges on the grid boundary are shared by fewer than 4 cells, requiring triangle generation instead of quads [S5].
- **Vertex Clamping**: The unconstrained QEF solution may lie outside the cell, which helps recover sharp features but might create self-intersections. Users can constrain the vertex inside the cell [S12].

## Subtopics

### [Topologically Accurate Dual Isosurfacing Using Ray Intersection](800-topologically-accurate-dual-isosurfacing-using-ray-intersect.md)
Determines the topology of an analytical isosurface within a voxel cell using trilinear interpolation and ray intersection along specific diagonals. Optimizes computation by finding exactly one intersection point per disjoint isosurface component, except for complex features like tunnels which require multiple points. Choose when topological correctness is critical for complex implicit surfaces.

### [Linear Edge Intersection for Dual Contouring](926-linear-edge-intersection-for-dual-contouring.md)
Computes edge-surface intersections for dual contouring by finding where grid edges cross the iso-surface and computing intersection points using linear interpolation. Returns an `Intersection` object containing points and normals. Choose when Hermite data needs to be pre-computed efficiently before QEF solving.

### [Dual Contouring with Octree](1271-dual-contouring-with-octree.md)
Applies dual contouring on an adaptive octree structure, refining cells based on normal angle spread and gradient variation. Choose when processing large datasets with varying detail requirements to save memory and computation.

### [Dual Contouring QEF Solver](1424-dual-contouring-qef-solver.md)
Specialized solver for the Quadratic Error Function in dual contouring, handling rank deficiency and boundary constraints. Choose when robust vertex placement is required for noisy or sparse Hermite data.

### [Simplified Dual Contouring](1580-simplified-dual-contouring.md)
Places a single vertex at the center of every voxel cell where the scalar field values at the eight corners exhibit a sign change along any axis-aligned edge, and constructs a quad mesh by connecting these vertices based on their relative positions in the grid. Choose when computational simplicity and speed are prioritized over sharp feature recovery.

## Operating characteristics

- **Time Complexity**: Not given in the sources.
- **Memory Complexity**: Not given in the sources.
- **Strengths**: Preserves sharp features, watertight meshes on adaptive grids [S5, S9].
- **Limitations**: Feature placement can be sensitive to the quality of input data [S6]. Does not guarantee 2-manifold or watertight output by default [S12].

## Background

Dual Contouring was introduced by Ju et al. in 2002 as "Hermite Dual Contouring" [S7]. It was later extended to Signed Distance Fields by Carrera et al. in 2026 [S7].
