# Dual Contouring

Also called: Ju's method, Hermite Dual Contouring, Dual Contouring of Hermite Data, Ju et al. 2002 dual contouring, Carrera et al. 2026 dual contouring, Dual Contouring 3D, Dual Contouring of Signed Distance Data, Dual Contouring on Adaptive Octree, Isomesh, SDF Dual Contouring

## Overview

Dual Contouring is an isosurface extraction algorithm that generates a mesh by placing a single vertex inside each grid cell intersected by the surface, rather than on the cell edges like Marching Cubes [S1, S2, S3]. It solves a Quadratic Error Function (QEF) to determine the optimal vertex position based on Hermite data (intersection points and surface normals) or Signed Distance Field (SDF) samples [S1, S2]. This approach preserves sharp features and allows for watertight meshes on adaptive grids, distinguishing it from linear interpolation methods [S3].

## How it works

### Inputs and Outputs
**Inputs:**
- A scalar field $f(x, y, z)$ or Signed Distance Field (SDF) [S1, S2].
- Grid dimensions and bounds $[x_{min}, x_{max}) \times [y_{min}, y_{max}) \times [z_{min}, z_{max})$ [S1].
- Optional: Pre-computed Hermite data (intersection points and normals) [S2].
- Parameters: Regularization weight ($reg$), SVD tolerance ($svd\_tol$), clamp flag ($clamp$), iteration counts ($outer\_iters, inner\_iters$), SDF weights ($\mu, hermite\_weight, update\_weight$), and convergence tolerance ($tol$) [S2].

**Outputs:**
- A list of vertices and a list of faces (quads or triangles) forming the mesh [S1, S2, S3].
- Data structures: `vert_indices` mapping cell coordinates $(x, y, z)$ to vertex indices [S1].

### Data Structures

**Intersection Struct** [S2]:
- `points`: `NDArray<float3>` of intersection points $(N, 3)$.
- `normals`: `NDArray<float3>` of surface normals $(N, 3)$.
- `edges`: `NDArray<uint2>` identifying the edges crossed.
- `cell_indices`: `NDArray<uint>` mapping intersections to cells.
- `cell_offsets`: `NDArray<uint>` offsets for cell-based iteration.
- `is_out`: `NDArray<bool>` status flags.
- `_has_normals`: `bool` indicating if normals are present.

**QEF Matrix** (per cell/component) [S1, S3]:
- Matrix $A$ of size $k \times 3$, where $k$ is the number of intersection points. Each row $i$ is the normal vector $n_i$ [S1, S3].
- Vector $b$ of size $k$, where $b_i = \text{dot}(n_i, P_i)$ [S1, S3].

### Steps

1. **Grid Traversal and Intersection Detection**:
   Iterate over all cells $(x, y, z)$ in the grid range [S1]. For each cell, evaluate the scalar field at the 8 corners $v_{dx,dy,dz} = f(x+dx, y+dy, z+dz)$ where $dx, dy, dz \in \{0, 1\}$ [S1]. Identify edges where the sign of the field changes (i.e., $v_{start} > 0 \neq v_{end} > 0$) [S1]. If fewer than 2 sign-changing edges exist, skip the cell (no vertex created) [S1, pitfall].

2. **Intersection Point and Normal Computation**:
   For each intersected edge, compute the intersection point $P$ using linear interpolation [S1, S2]:
   $$ P = (1-t)V_0 + tV_1 $$
   where $V_0, V_1$ are the edge endpoints, and $t$ is derived from the field values (e.g., $t = \frac{|V_0|}{|V_0| + |V_1|}$ for zero-crossing) [S1]. If normals are not provided, compute them using central differences or gradient estimation from the grid values [S1, S2].

3. **QEF Construction**:
   For each cell (or component within a cell in adaptive octrees), construct the QEF system $A V = b$ [S1].
   - Rows of $A$ are the normals $n_i$ at intersection points $P_i$ [S1, S3].
   - Elements of $b$ are $b_i = \text{dot}(n_i, P_i)$ [S1, S3].
   - If using SDF-based dual contouring (Carrera et al. 2026), the QEF may incorporate SDF values directly or update Hermite data iteratively [S2].

4. **Vertex Placement (QEF Solution)**:
   Solve for vertex position $V$ by minimizing $\| A V - b \|^2$ [S1].
   - Use Jacobi SVD eigendecomposition or truncated pseudo-inverse for symmetric positive semi-definite matrices [S2].
   - Eigenvalues below $tol \times \lambda_{max}$ are treated as zero to handle rank-deficient cases (e.g., coplanar normals) [S2].
   - Apply regularization weight $reg$ to the diagonal of $A^T A$ if needed [S2].
   - If $clamp$ is true, the vertex position is clamped (exact bounds not specified in sources) [S2].

5. **Newton Projection (Optional but Recommended)**:
   Project the computed vertex $V$ exactly onto the zero-isosurface using one Newton step [S3]:
   $$ V_{new} = V - \frac{f(V)}{\nabla f(V)} $$
   This step corrects errors from linear interpolation and QEF approximation [S3].

6. **Mesh Generation (Quad/Triangle Creation)**:
   Iterate over adjacent cells sharing a face or edge [S1, S3].
   - For shared edges, if the scalar field values on the two sides differ (indicating the surface crosses the edge), create a quad connecting the vertices of the two adjacent cells [S1].
   - In adaptive octree implementations, force surface leaves to max depth to eliminate T-junctions and ensure watertightness [S3].
   - Use canonical-edge iteration with flatness-based triangulation if quads are split into triangles [S3].

### Pseudocode

```python
import math

def dual_contouring(grid, level=0.0, compute_normals=True, reg=1e-2, svd_tol=1e-6, clamp=True):
    """
    Extracts isosurface from grid using Dual Contouring.
    grid: 3D array of scalar values.
    level: Iso-value (default 0.0).
    compute_normals: If True, compute normals from grid.
    reg: Regularization weight for QEF.
    svd_tol: SVD tolerance.
    clamp: Clamp vertex to cell bounds.
    """
    vertices = []
    faces = []
    vert_indices = {}
    shape = grid.shape
    
    def dot(a, b): return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]
    def lerp(p0, p1, t): return [p0[d] + t*(p1[d]-p0[d]) for d in range(3)]
    
    def find_edges(corners, level):
        edges = []
        edge_pairs = [(0,1), (0,2), (0,4), (1,3), (1,5), (2,3), (2,6), (3,7), (4,5), (4,6), (5,7), (6,7)]
        for i, j in edge_pairs:
            if (corners[i] - level) * (corners[j] - level) < 0:
                edges.append((i, j))
        return edges

    def compute_normal(grid, p, shape):
        eps = 1.0 / max(shape)
        ix, iy, iz = int(p[0]), int(p[1]), int(p[2])
        fx = (grid[ix+1, iy, iz] - grid[ix-1, iy, iz]) / (2*eps)
        fy = (grid[ix, iy+1, iz] - grid[ix, iy-1, iz]) / (2*eps)
        fz = (grid[ix, iy, iz+1] - grid[ix, iy, iz-1]) / (2*eps)
        norm = math.sqrt(fx**2 + fy**2 + fz**2)
        if norm == 0: return [0, 0, 1]
        return [fx/norm, fy/norm, fz/norm]

    def solve_qef(A, b, reg, tol):
        AtA = [[0.0]*3 for _ in range(3)]
        Atb = [0.0]*3
        for i in range(3):
            for j in range(3):
                for k in range(len(A)):
                    AtA[i][j] += A[k][i] * A[k][j]
            for k in range(len(A)):
                Atb[i] += A[k][i] * b[k]
        for i in range(3):
            AtA[i][i] += reg
        M = [AtA[i] + [Atb[i]] for i in range(3)]
        for i in range(3):
            pivot = M[i][i]
            for j in range(i+1, 3):
                factor = M[j][i] / pivot
                for k in range(i, 4):
                    M[j][k] -= factor * M[i][k]
        V = [0.0]*3
        for i in range(2, -1, -1):
            V[i] = M[i][3]
            for j in range(i+1, 3):
                V[i] -= M[i][j] * V[j]
            V[i] /= M[i][i]
        return V

    for x in range(shape[0] - 1):
        for y in range(shape[1] - 1):
            for z in range(shape[2] - 1):
                corners = [
                    grid[x, y, z], grid[x+1, y, z], grid[x, y+1, z], grid[x+1, y+1, z],
                    grid[x, y, z+1], grid[x+1, y, z+1], grid[x, y+1, z+1], grid[x+1, y+1, z+1]
                ]
                edge_indices = find_edges(corners, level)
                if len(edge_indices) < 2:
                    continue
                
                intersections = []
                for i, j in edge_indices:
                    v0, v1 = corners[i], corners[j]
                    t = abs(v0 - level) / (abs(v0 - level) + abs(v1 - level))
                    p0 = [x + (i&1), y + ((i>>1)&1), z + (i>>2)]
                    p1 = [x + (j&1), y + ((j>>1)&1), z + (j>>2)]
                    P = lerp(p0, p1, t)
                    if compute_normals:
                        n = compute_normal(grid, P, shape)
                    else:
                        n = [0, 0, 1]
                    intersections.append((P, n))
                
                A = [n for _, n in intersections]
                b = [dot(n, P) for P, n in intersections]
                
                V = solve_qef(A, b, reg, svd_tol)
                
                if clamp:
                    V = [max(0, min(shape[d]-1, V[d])) for d in range(3)]
                
                # Newton projection
                fV = grid[int(V[0])][int(V[1])][int(V[2])] - level
                grad = compute_normal(grid, V, shape)
                denom = dot(grad, grad) + 1e-8
                V = [V[d] - (fV / denom) * grad[d] for d in range(3)]
                
                cell_key = (x, y, z)
                vert_indices[cell_key] = len(vertices)
                vertices.append(V)

    # Face generation: iterate over shared faces between adjacent cells
    # Canonical-edge iteration connects vertices of intersected cells to form quads/triangles
    # Implementation details depend on specific topology rules [S3]
    pass
                
    return vertices, faces
```

### Parameters

- `reg`: Regularization weight for QEF. Default: $10^{-2}$ [S2].
- `svd_tol`: SVD tolerance for solving QEF. Default: $10^{-6}$ [S2].
- `clamp`: Whether to clamp vertex position to cell bounds. Default: `true` [S2].
- `outer_iters`: Number of outer iteration steps (for SDF variants). Default: 100 [S2].
- `inner_iters`: Number of inner iteration steps. Default: 100 [S2].
- `mu`: Weight parameter for SDF constraint. Default: 0.1 [S2].
- `hermite_weight`: Weight for Hermite data in QEF. Default: 0.02 [S2].
- `update_weight`: Weight for updating Hermite data. Default: 0.2 [S2].
- `hermite_update`: Whether to update Hermite data during iterations. Default: `true` [S2].
- `qef_assignment`: Whether to use QEF assignment. Default: `true` [S2].
- `band`: Bandwidth parameter for SDF processing (in cell diagonals). Default: 3.0 [S2].
- `tol`: Convergence tolerance. Default: $10^{-5}$ [S2].

### Edge Cases and Pitfalls

- **Degenerate Cells**: If fewer than 2 sign-changing edges exist in a cell, no vertex is created [S1, pitfall].
- **Rank Deficiency**: If normals are coplanar or collinear, the QEF matrix is singular. Use SVD truncation or regularization [S2, S3].
- **Sharp Features**: Newton projection may degrade edge/corner placement if normals diverge significantly. Detect sharp components using pairwise dot product of normals and skip projection for sharp features [S4].
- **T-Junctions**: In adaptive octrees, ensure surface leaves are forced to max depth to maintain watertightness [S3].

## Subtopics

### Linear Edge Intersection for Dual Contouring
A structure storing edge-surface intersection points and normals for dual contouring, created by `get_intersection()` and used by `dual_contouring()` [S2]. It computes edge-surface intersections by finding where grid edges cross the iso-surface and computing intersection points using linear interpolation [S2]. Returns an `Intersection` object containing points and normals [S2]. Parameters include `grid` (input scalar field), `level` (iso-value, default 0.0), and `compute_normals` (default `false`) [S2]. `get_points` returns an $(N, 3)$ float32 tensor of intersection points, and `get_normals` returns an $(N, 3)$ float32 tensor of surface normals [S2].

## Operating characteristics

- **Time Complexity**: Not given in the sources.
- **Memory Complexity**: Not given in the sources.
- **Performance**: Benchmark comparisons show Dual Contouring (Isomesh) vs Marching Cubes (PyMCubes) at equivalent resolution (depth 6 = 64 cells/axis) [S3]. Dual Contouring is generally slower due to QEF solving but produces higher quality meshes with fewer artifacts [S3].
- **Strengths**: Preserves sharp features, watertight meshes on adaptive grids, fewer vertices than Marching Cubes for similar accuracy [S3].
- **Limitations**: More complex implementation, sensitive to normal estimation errors, requires careful handling of degenerate cases [S1, S2, S3].
- **When to Use**: When sharp feature preservation and watertightness are critical, or when using adaptive grids [S3].
- **When Not to Use**: For simple, smooth surfaces where Marching Cubes is sufficient and faster [S3].

## Background

Dual Contouring was introduced by Ju et al. in 2002 as "Hermite Dual Contouring" [S2]. It was later extended to Signed Distance Fields by Carrera et al. in 2026 [S2].
