# Simulation Grid Cell Skipping

Also called: Surface Extraction with Simulation Grid

## Overview
Simulation Grid Cell Skipping is an optimization technique for surface extraction that accelerates iteration over voxel columns by skipping over empty and fully occupied simulation grid cells, processing only partially filled cells [S1]. It builds on the THREAD System's ray-marching framework [3743-thread-system.md] to bypass uniform regions during extraction.

## How it works
**Inputs and Outputs:**
- Input: A regular simulation grid where each cell is classified as empty, full, or partial; view rays for each voxel column [S1].
- Output: A sequence of voxels located within partially filled cells, ready for surface extraction [S1].

**Data Structures:**
- Simulation Grid: A regular 3D grid storing a status flag per cell (`EMPTY`, `FULL`, or `PARTIAL`) [S1].
- Voxel Column: A linear sequence of voxels aligned with a view ray [S1].
- Packed Machine Words: Bitmasks representing voxel occupancy or cell status, processed in chunks to leverage hardware bit-counting intrinsics [S1].

**Numbered Steps:**
1. For each voxel column, initialize a ray marcher along the corresponding view ray [S1].
2. Iterate over packed machine words rather than single bits, using bit counting intrinsics to quickly determine the next relevant bits to be considered [S1].
3. March along the view ray through the simulation grid [S1].
4. Keep marching through full or empty simulation grid cells until encountering a succession of partially filled cells [S1].
5. Interrupt ray marching to iterate over the corresponding voxels when partially filled cells are encountered [S1].
6. When the iteration reaches the end of the current set of connected partially filled cells, resume ray marching in the simulation grid [S1].

**Formulas:**
- Logarithmic Depth Partitioning: Cell extent ratios are kept constant so that $\alpha$ remains uniform throughout the perspective grid, allowing all but one logarithm to be precomputed [S1].
- Cell Status Classification: A cell is marked `PARTIAL` if it contains particles overlapping its boundaries; `FULL` if entirely filled with incompressible fluid particles; `EMPTY` otherwise [S1].

**Parameters:**
- Bit Counting Intrinsics: Hardware-dependent operations (e.g., `__builtin_popcount` on GCC/Clang) used to count set bits in packed words [S1].

**Edge Cases and Pitfalls:**
- Do not skip cells that have partially filled neighbors to avoid cutting off detailed boundary surfaces potentially formed by particles overlapping cell boundaries; only inner full and empty cells may be skipped [S1].
- Ray marching precision must be sufficient to correctly identify cell boundaries when resuming iteration after skipping uniform regions [G].

**Pseudocode:**
```python
EMPTY, FULL, PARTIAL = 0, 1, 2

def simulate_grid_cell_skipping(simulation_grid, voxel_columns):
    voxels_to_process = []
    for ray in voxel_columns:
        current_cell = ray.start_cell
        while current_cell is not None:
            # Check if any neighbor is partial; if so, do not skip this cell
            has_partial_neighbor = any(
                simulation_grid[n].status == PARTIAL
                for n in get_26_neighbors(current_cell)
            )
            if current_cell.status in (EMPTY, FULL) and not has_partial_neighbor:
                # Skip uniform region by advancing ray to next cell
                current_cell = advance_ray_to_next_cell(current_cell, ray.direction, simulation_grid)
                continue
            # Process voxels in the current cell
            voxels = iterate_voxels_in_cell(current_cell, ray)
            voxels_to_process.extend(voxels)
            # Move to next cell
            current_cell = advance_ray_to_next_cell(current_cell, ray.direction, simulation_grid)
    return voxels_to_process

def get_26_neighbors(cell):
    return [(cell.x + dx, cell.y + dy, cell.z + dz)
            for dx in (-1, 0, 1) for dy in (-1, 0, 1) for dz in (-1, 0, 1)
            if not (dx == 0 and dy == 0 and dz == 0)]

def advance_ray_to_next_cell(current_cell, direction, simulation_grid):
    # Step along the ray direction in grid coordinates
    step_x = 1 if direction.x > 0 else (-1 if direction.x < 0 else 0)
    step_y = 1 if direction.y > 0 else (-1 if direction.y < 0 else 0)
    step_z = 1 if direction.z > 0 else (-1 if direction.z < 0 else 0)
    next_pos = (current_cell.x + step_x, current_cell.y + step_y, current_cell.z + step_z)
    if not (0 <= next_pos[0] < simulation_grid.width and
            0 <= next_pos[1] < simulation_grid.height and
            0 <= next_pos[2] < simulation_grid.depth):
        return None
    return simulation_grid[next_pos[0], next_pos[1], next_pos[2]]

def iterate_voxels_in_cell(cell, ray):
    # Iterate over packed machine words rather than single bits,
    # using bit counting intrinsics to quickly determine the next relevant bits
    voxels = []
    packed_words = cell.packed_occupancy_words
    for word in packed_words:
        while word != 0:
            # Find index of least significant set bit (hardware intrinsic equivalent)
            bit_index = (word & -word).bit_length() - 1
            voxels.append(ray.get_voxel(bit_index))
            # Clear the processed bit
            word &= word - 1
    return voxels
```
