# Simulation Grid Cell Skipping

Also called: Surface Extraction with Simulation Grid

## Overview
Simulation Grid Cell Skipping is an optimization technique for surface extraction that accelerates iteration over voxel columns by skipping over empty and fully occupied simulation grid cells, processing only partially filled cells [S1]. It differs from standard voxel traversal by leveraging coarse-grained cell status to bypass uniform regions, building on the THREAD System's ray-marching framework [3743-thread-system.md].

## How it works
**Inputs and Outputs:**
- Input: A simulation grid with cell status (empty, full, or partial); view rays for each voxel column [S1].
- Output: A list of voxels within partially filled cells for surface extraction [S1].

**Data Structures:**
- Simulation Grid: A regular 3D grid where each cell stores a status flag: `EMPTY`, `FULL`, or `PARTIAL` [S1].
- Voxel Column: A sequence of voxels along a view ray [S1].
- Packed Machine Words: Bits representing voxel occupancy or cell status, processed in chunks for efficiency [S1].

**Numbered Steps:**
1. For each voxel column, initialize a ray marcher along the view ray corresponding to that column [S1].
2. Iterate over packed machine words rather than single bits, using bit counting intrinsics to quickly determine the next relevant bits to be considered [S1].
3. March along the view ray through the simulation grid [S1].
4. Keep marching through full or empty simulation grid cells until encountering a succession of partially filled cells [S1].
5. Interrupt ray marching to iterate over the corresponding voxels when partially filled cells are encountered [S1].
6. When the iteration reaches the end of the current set of connected partially filled cells, resume ray marching in the simulation grid [S1].

**Formulas:**
- Cell Status Determination: During simulation, determine if a cell is empty, full, or partial based on particle presence [S1].
- Ray Marching Step: Advance ray by cell extent ratio, keeping $\alpha$ constant throughout the perspective grid using logarithmic depth partitioning [S1].

**Parameters:**
- Cell Status Thresholds: Not given in the sources.
- Bit Counting Intrinsics: Hardware-dependent (e.g., `__builtin_popcount` on GCC/Clang) [S1].

**Edge Cases and Pitfalls:**
- Do not skip cells that have partially filled neighbors to avoid cutting off detailed boundary surfaces potentially formed by particles overlapping cell boundaries; only inner full and empty cells may be skipped [S1].
- Precision issues in ray marching may cause missed intersections if cell boundaries are not handled correctly [G].

**Pseudocode:**

def simulate_grid_cell_skipping(simulation_grid, voxel_columns):
    voxels_to_process = []
    for ray in voxel_columns:
        current_cell = ray.start_cell
        while current_cell is not None:
            has_partial_neighbor = any(
                simulation_grid[n].status == PARTIAL for n in get_26_neighbors(current_cell)
            )
            if current_cell.status in (EMPTY, FULL) and not has_partial_neighbor:
                current_cell = advance_ray_to_next_cell(current_cell, ray.direction, simulation_grid)
                continue
            voxels = iterate_voxels_in_cell(current_cell, ray)
            voxels_to_process.extend(voxels)
            current_cell = advance_ray_to_next_cell(current_cell, ray.direction, simulation_grid)
    return voxels_to_process

def get_26_neighbors(cell):
    return [(cell.x + dx, cell.y + dy, cell.z + dz)
            for dx in (-1, 0, 1) for dy in (-1, 0, 1) for dz in (-1, 0, 1)
            if not (dx == 0 and dy == 0 and dz == 0)]

def advance_ray_to_next_cell(current_cell, direction, simulation_grid):
    next_pos = (current_cell.x + direction.x * current_cell.extent,
                current_cell.y + direction.y * current_cell.extent,
                current_cell.z + direction.z * current_cell.extent)
    if not (0 <= next_pos[0] < simulation_grid.width and
            0 <= next_pos[1] < simulation_grid.height and
            0 <= next_pos[2] < simulation_grid.depth):
        return None
    return simulation_grid[next_pos[0], next_pos[1], next_pos[2]]
