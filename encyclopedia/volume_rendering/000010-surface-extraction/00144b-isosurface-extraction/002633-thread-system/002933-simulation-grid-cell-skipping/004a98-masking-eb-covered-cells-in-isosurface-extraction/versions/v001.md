# Masking EB-covered cells in isosurface extraction

Also called: EB cell masking, Volume fraction masking

## Overview
This method excludes simulation grid cells fully covered by an Embedded Boundary (EB) from isosurface extraction by checking the volume fraction field, ensuring the extracted surface respects the boundary geometry defined by volume fractions. It differs from sibling optimizations like [Simulation Grid Cell Skipping](4474-simulation-grid-cell-skipping.md) by specifically targeting EB-covered cells (volume fraction == 0) rather than just empty or fully occupied cells, and it requires specific ghost cell handling to avoid artifacts at AMR coarse/fine boundaries.

## How it works
**Inputs:**
- Plotfile distribution map containing the `volFrac` field.
- Boolean flag `USE_EB`.

**Outputs:**
- Isosurface mesh excluding triangles from cells where `volFrac == 0`.

**Data Structures:**
- `volFrac`: A scalar field on the simulation grid, where each cell stores the fraction of its volume occupied by the fluid (1.0) or solid (0.0).
- `USE_EB`: A boolean configuration parameter.

**Steps:**
1. Check if `USE_EB` is TRUE. If FALSE, proceed with standard extraction without EB masking.
2. Read the `volFrac` field from the plotfile distribution map.
3. Fill the ghost cells of `volFrac` using `FillPatch` from the coarser level with piecewise constant interpolation. This step is critical for handling coarse/fine boundaries in Adaptive Mesh Refinement (AMR).
4. Iterate over all cells in the domain.
5. For each cell, read its `volFrac` value.
6. If `volFrac == 0`, exclude the cell from the surface extraction process.
7. If `volFrac > 0`, include the cell in the extraction process.

**Pseudocode:**
```python
def extract_isosurface_with_eb_masking(plotfile, use_eb):
    if not use_eb:
        return standard_isosurface_extraction(plotfile)
    
    # Read volume fraction field
    volFrac = plotfile.read_field("volFrac")
    
    # Fill ghost cells using FillPatch with piecewise constant interpolation
    # This handles coarse/fine boundaries correctly
    fill_patch_ghost_cells(volFrac, coarser_level=True, interpolation="piecewise_constant")
    
    triangles = []
    
    # Iterate over all cells (untiled loop to match development behavior)
    for cell in all_cells:
        # Check volume fraction
        if volFrac[cell] == 0:
            # Fully covered by EB, skip extraction
            continue
        
        # Extract surface for this cell
        cell_triangles = extract_cell_surface(cell)
        triangles.extend(cell_triangles)
        
    return triangles
```

**Parameters:**
- `USE_EB`: Boolean flag. When TRUE, enables EB-specific logic including `volFrac` reading and masking. Default value not specified in sources.

**Edge Cases and Pitfalls:**
- **Ghost Cell Handling:** If ghost cells are filled only with `FillBoundary` instead of `FillPatch`, ghost cells at coarse/fine boundaries remain 0. This causes every cell touching them to be masked, creating a crack along the coarse/fine boundary. In a two-level test with `volFrac = 1`, this resulted in 377 missing triangles (-4% area) [S1, unofficial].
- **Tiling:** The element-extraction loop must be untiled. Using a tiled loop (e.g., `MFIter(states[lev], TilingIfNotGPU())`) processes boxes larger than one tile several times, causing extra elements and a slightly different area. With 32³ boxes, this gave 3 extra elements [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not specified in the sources.
- **Memory Complexity:** Not specified in the sources.
- **Performance:** In a two-level test with `volFrac = 1`, using `FillPatch` for ghost cells resulted in byte-identical output to the development baseline for both non-EB and EB cases with 3D boxes of size 16³ and 32³, with refinement ratios of 2 and 4 [S1, unofficial].
- **Hardware Support:** Not supported on GPU because the extraction and output operations are implemented as host loops over device memory [S1, unofficial].
- **Strengths:** Ensures surface geometry respects EB boundary geometry defined by volume fractions.
- **Limitations:** CPU-only implementation; requires careful ghost cell handling to avoid artifacts at AMR boundaries.
- **When to Use:** When extracting isosurfaces from simulations using Embedded Boundary methods and accurate boundary representation is required.
- **When Not to Use:** When GPU acceleration is needed or when EB boundary geometry is not relevant to the extraction.

## Background
This method was introduced in PR #93 (Part 8 of 9) of the PeleAnalysis repository by terencelehmann on September 30, 2026 [S1, unofficial]. It addresses the need to correctly handle Embedded Boundaries in isosurface extraction, ensuring that fully covered cells are excluded from the surface mesh. The method was developed to fix artifacts caused by incorrect ghost cell handling at coarse/fine boundaries in AMR simulations.
