# Simplified Dual Contouring

Also called: Dual Contouring (Simplified/Naive), naive dual contouring

## Overview
Simplified Dual Contouring is an isosurface extraction method that generates a quad mesh by placing a single vertex at the center of every voxel cell where the scalar field values at the eight corners exhibit a sign change along any axis-aligned edge [S1, unofficial]. It constructs the mesh by connecting these vertices based on their relative grid positions using a fixed set of plane basis vectors [S1, unofficial].

## How it works
**Inputs and Outputs:** The method takes an input implementing the `DCInput` trait, which provides scalar values and gradients at integer grid coordinates, and returns a `DCOutput` struct containing vertex positions, normals, and triangle indices [S1, unofficial].

**Data Structures:** `DCBounds` defines the processing volume with fields `x`, `y`, and `z`, each a tuple `(i32, i32)` representing inclusive start and exclusive end bounds [S1, unofficial]. `DCInput` requires `get_bounds() -> DCBounds`, `get_value(x, y, z) -> f32`, and `get_gradient(x, y, z) -> [f32; 3]` [S1, unofficial]. `DCOutput` contains `vertices: Vec<[f32; 3]>`, `normals: Vec<[f32; 3]>`, and `indices: Vec<u32>` [S1, unofficial]. Auxiliary structures include `vertex_map` (`HashMap<IVec3, u32>` mapping grid positions to vertex indices), `vertex_buffer` (`Vec<[f32; 3]>`), `normal_buffer` (`Vec<[f32; 3]>`), and `index_list` (`Vec<u32>`) [S1, unofficial].

**Algorithm Steps:**
1. Initialize `vertex_buffer`, `normal_buffer`, `index_list` as empty vectors, and `vertex_map` as an empty hash map [S1, unofficial].
2. Define the fixed plane basis vectors: `planes = [(IVec3::X, IVec3::Y), (IVec3::Z, IVec3::X), (IVec3::Y, IVec3::Z)]` [S1, unofficial].
3. Iterate over grid cells `(x, y, z)` where `x` ranges from `bounds.x.0` to `bounds.x.1 - 2`, `y` from `bounds.y.0` to `bounds.y.1 - 2`, and `z` from `bounds.z.0` to `bounds.z.1 - 2` [S1, unofficial].
4. Call `dc_place_vertex(input, x, y, z)` [S1, unofficial].
5. If the result is `Some(vertex)`, let `position = IVec3::new(x, y, z)`, insert `position` into `vertex_map` with value `vertex_buffer.len() as u32`, append `vertex` to `vertex_buffer`, and append `input.get_gradient(x, y, z)` to `normal_buffer` [S1, unofficial].
6. For each `(basis_1, basis_2)` in `planes`, call `check_quad(input, vertex_map, position, basis_1, basis_2, &mut index_list)` [S1, unofficial].
7. `dc_place_vertex` collects the 8 corner scalar values of the voxel in a fixed order, iterates `index` from 0 to 6, and returns `Some([x + 0.5, y + 0.5, z + 0.5])` if `sign_change(points[index], points[index + 1])` is true; otherwise returns `None` [S1, unofficial].
8. `check_quad` computes neighbor positions (`top_left`, `top_right`, `bottom_left`, `bottom_right`), verifies `bottom_left` is strictly greater than the lower bounds, checks that `top_left`, `bottom_left`, and `bottom_right` exist in `vertex_map`, and calls `create_quad` with the mapped indices and a `cw` flag derived from `input.get_value(position) > 0` [S1, unofficial].
9. `sign_change(a, b)` returns true if `(a.max(b) > 0. && a.min(b) < 0.) || (a == 0. && b != 0.) || (a != 0. && b == 0.)` [S1, unofficial].

**Pseudocode:**
```python
def dc_meshing(input, bounds):
    vertex_buffer = []
    normal_buffer = []
    index_list = []
    vertex_map = {}

    # Fixed plane basis vectors; order cannot be changed without inverting faces [S1, unofficial]
    planes = [((1, 0, 0), (0, 1, 0)), ((0, 0, 1), (1, 0, 0)), ((0, 1, 0), (0, 0, 1))]

    for x in range(bounds.x[0], bounds.x[1] - 1):
        for y in range(bounds.y[0], bounds.y[1] - 1):
            for z in range(bounds.z[0], bounds.z[1] - 1):
                vertex = dc_place_vertex(input, x, y, z)
                if vertex is not None:
                    position = (x, y, z)
                    vertex_map[position] = len(vertex_buffer)
                    vertex_buffer.append(vertex)
                    normal_buffer.append(input.get_gradient(x, y, z))

                    for basis_1, basis_2 in planes:
                        check_quad(input, vertex_map, position, basis_1, basis_2, bounds, index_list)

    return vertex_buffer, normal_buffer, index_list

def dc_place_vertex(input, x, y, z):
    points = [
        input.get_value(x, y, z),
        input.get_value(x + 1, y, z),
        input.get_value(x + 1, y + 1, z),
        input.get_value(x, y + 1, z),
        input.get_value(x, y, z + 1),
        input.get_value(x + 1, y, z + 1),
        input.get_value(x + 1, y + 1, z + 1),
        input.get_value(x, y + 1, z + 1)
    ]
    for index in range(7):
        if sign_change(points[index], points[index + 1]):
            return (x + 0.5, y + 0.5, z + 0.5)
    return None

def sign_change(a, b):
    return (max(a, b) > 0.0 and min(a, b) < 0.0) or (a == 0.0 and b != 0.0) or (a != 0.0 and b == 0.0)

def check_quad(input, vertex_map, position, basis_1, basis_2, bounds, index_list):
    top_left = (position[0] - basis_1[0], position[1] - basis_1[1], position[2] - basis_1[2])
    top_right = position
    bottom_left = (position[0] - basis_1[0] - basis_2[0], position[1] - basis_1[1] - basis_2[1], position[2] - basis_1[2] - basis_2[2])
    bottom_right = (position[0] - basis_2[0], position[1] - basis_2[1], position[2] - basis_2[2])

    if (bottom_left[0] > bounds.x[0] and bottom_left[1] > bounds.y[0] and bottom_left[2] > bounds.z[0] and
        top_left in vertex_map and bottom_left in vertex_map and bottom_right in vertex_map):
        cw = input.get_value(position[0], position[1], position[2]) > 0.0
        create_quad(vertex_map[top_left], vertex_map[top_right], vertex_map[bottom_right], vertex_map[bottom_left], cw, index_list)

def create_quad(i0, i1, i2, i3, cw, index_list):
    # Triangulate quad into two triangles; cw flag controls winding order [G]
    if cw:
        index_list.extend([i0, i1, i2])
        index_list.extend([i0, i2, i3])
    else:
        index_list.extend([i0, i2, i1])
        index_list.extend([i0, i3, i2])
```

**Parameters:** Grid bounds from `DCBounds`; plane basis order fixed as `[(X, Y), (Z, X), (Y, Z)]` [S1, unofficial].

**Edge Cases and Pitfalls:** Face inversion occurs if `planes` order is changed [S1, unofficial]. Zero values are handled explicitly by `sign_change` [S1, unofficial]. Boundary checks require `bottom_left` coordinates to be strictly greater than lower bounds [S1, unofficial].
