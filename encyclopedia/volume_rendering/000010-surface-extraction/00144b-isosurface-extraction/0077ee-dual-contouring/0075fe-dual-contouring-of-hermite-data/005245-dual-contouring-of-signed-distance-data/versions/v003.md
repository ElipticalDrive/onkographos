# Dual Contouring of Signed Distance Data

Also called: DCSDD

## Overview
Dual Contouring of Signed Distance Data (DCSDD) is an algorithm for reconstructing explicit polygonal meshes from discretely sampled Signed Distance Function (SDF) data, specifically designed to recover sharp features [S1, unofficial]. It builds on [Dual Contouring and Surface Nets](6319-dual-contouring-and-surface-nets.md) by solving a quadratic optimization problem to determine optimal vertex placement within each grid cell, relying solely on discrete SDF samples without requiring gradient information or arbitrary function access [S1, unofficial]. Unlike [Dual Contouring](778-dual-contouring.md) which typically requires Hermite data (positions and normals) as input, DCSDD derives the necessary constraints directly from the SDF values, setting a new state of the art for medium and high-resolution SDF reconstruction [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A regular 3D grid of discretely sampled Signed Distance Function (SDF) values [S1, unofficial].
- Output: An explicit polygonal mesh (vertices and faces) [S1, unofficial].

**Data Structures:**
- **SDF Grid:** A 3D array storing scalar distance values at grid vertices [S1, unofficial].
- **Hermite Data:** For each grid cell intersecting the isosurface, the algorithm maintains Hermite data (position and normal) at the intersection points, derived from the SDF samples rather than provided as input [S1, unofficial].
- **Vertex Position:** A 3D vector $v$ representing the reconstructed vertex position within the grid cell, determined by optimization [S1, unofficial].
- **Energy Terms:** The optimization minimizes a composite energy function involving Hermite consistency and regularization terms [S1, unofficial].

**Parameters:**
- `outer_iters`: Number of iterations in the outer loop. Default: 100 [S1, unofficial].
- `inner_iters`: Number of iterations in the inner loop (local energy minimization). Default: 100 [S1, unofficial].
- `hermite_update`: Boolean flag indicating whether to refine Hermite positions from the mesh. Default: `True` [S1, unofficial].
- `mu`: Regularization weight. Default: 0.1 [S1, unofficial].
- `dc_weight`: Weight of the Dual Contouring (Hermite) energy term. Default: 0.02 [S1, unofficial].
- `new_hermite_pos_weight`: Blend weight for updating Hermite positions. Default: 0.2 [S1, unofficial].
- `new_hermite_normal_weight`: Blend weight for updating Hermite normals. Default: 0.2 [S1, unofficial].
- `new_face_pos_weight`: Blend weight for updating face positions. Default: 0.2 [S1, unofficial].
- `batch_size`: Number of SDF grid points processed per batch. Default: 200000 [S1, unofficial].
- `verbose`: Boolean flag to print per-iteration energy values. Default: `False` [S1, unofficial].

**Algorithm Steps:**
1. **Initialization:** For each grid cell, identify the edges intersecting the zero-level set of the SDF [G]. Compute initial Hermite data (intersection position and normal) for these edges using linear interpolation and finite differences or gradient approximation from the SDF grid [G].
2. **Outer Loop:** Iterate `outer_iters` times:
   a. **Hermite Update (if `hermite_update` is True):** Refine the Hermite positions and normals based on the current mesh state or SDF data, blending new estimates with existing ones using `new_hermite_pos_weight`, `new_hermite_normal_weight`, and `new_face_pos_weight` [S1, unofficial].
   b. **Inner Loop (Local Energy Minimization):** For each grid cell containing a vertex to be placed:
      i. Define the local energy function $E(v)$ for the vertex position $v$ [G].
      ii. Solve the quadratic optimization problem for $v$ using `inner_iters` iterations [G].
      iii. Update the vertex position $v$ in the cell [G].
   c. **Mesh Generation:** After placing vertices in all cells, generate the mesh topology by connecting vertices within each cell according to the dual contouring scheme (typically forming a convex polyhedron or triangle fan) [S1, unofficial].
3. **Output:** Return the generated mesh [S1, unofficial].

**Formulas:**
The specific quadratic energy function $E(v)$ is not explicitly detailed in the provided sources, but it is described as a combination of Hermite energy (weighted by `dc_weight`) and regularization (weighted by `mu`) [S1, unofficial]. The optimization solves for $v$ that minimizes this energy [S1, unofficial]. Standard dual contouring formulates this as $E(v) = \sum_{i} \|v - p_i\|^2 + \mu \|v - c\|^2$, where $p_i$ are Hermite positions and $c$ is the cell center [G]. The gradient is $\nabla E(v) = 2 \sum_{i} (v - p_i) + 2\mu(v - c)$, and the iterative update follows $v \leftarrow v - \alpha \nabla E(v)$ [G].

**Edge Cases and Pitfalls:**
- **Boundaries:** Cells at the grid boundary may have fewer intersecting edges, requiring special handling for Hermite data generation [G].
- **Platform:** The implementation was tested on macOS only; issues may arise on other platforms [S1, unofficial].

**Pseudocode:**
```python
def vec_add(a, b): return [a[i] + b[i] for i in range(3)]
def vec_sub(a, b): return [a[i] - b[i] for i in range(3)]
def vec_scale(a, s): return [a[i] * s for i in range(3)]
def vec_dot(a, b): return sum(a[i] * b[i] for i in range(3))
def vec_norm(a): 
    d = vec_dot(a, a)
    return vec_scale(a, 1.0 / (d ** 0.5 + 1e-8))

def dual_contouring_sdf(sdf_grid, options):
    Nx, Ny, Nz = len(sdf_grid), len(sdf_grid[0]), len(sdf_grid[0][0])
    vertices = []
    faces = []
    hermite_data = {}

    # 1. Initialization: find zero-crossing edges and compute Hermite data [G]
    for x in range(Nx - 1):
        for y in range(Ny - 1):
            for z in range(Nz - 1):
                cell_id = (x, y, z)
                edges = []
                corners = [(x,y,z), (x+1,y,z), (x,y+1,z), (x,y,z+1),
                           (x+1,y+1,z), (x+1,y,z+1), (x,y+1,z+1), (x+1,y+1,z+1)]
                edge_pairs = [(0,1), (0,2), (0,3), (1,4), (1,5), (2,4), (2,6), (3,5), (3,6), (4,7), (5,7), (6,7)]
                for i, j in edge_pairs:
                    p1 = sdf_grid[corners[i][0]][corners[i][1]][corners[i][2]]
                    p2 = sdf_grid[corners[j][0]][corners[j][1]][corners[j][2]]
                    if p1 * p2 < 0:
                        t = abs(p1) / (abs(p1) + abs(p2))
                        pos = vec_add(vec_scale(corners[i], 1.0 - t), vec_scale(corners[j], t))
                        # Central difference normal with boundary clamping [G]
                        grad = [0.0, 0.0, 0.0]
                        for k in range(3):
                            idx = list(corners[i])
                            if idx[k] > 0: grad[k] -= sdf_grid[max(0,idx[k]-1)][idx[1-(k==1)]][idx[2-(k==2)]]
                            if idx[k] < [Nx,Ny,Nz][k]-1: grad[k] += sdf_grid[min([Nx,Ny,Nz][k]-1,idx[k]+1)][idx[1-(k==1)]][idx[2-(k==2)]]
                        normal = vec_norm(grad)
                        edges.append({'pos': pos, 'normal': normal})
                if len(edges) >= 2:
                    hermite_data[cell_id] = edges

    # 2. Outer Loop
    for outer_iter in range(options.outer_iters):
        if options.hermite_update:
            # Refine Hermite data using blend weights [G]
            for cell_id, edges in hermite_data.items():
                for edge in edges:
                    edge['pos'] = vec_add(vec_scale(edge['pos'], 1.0 - options.new_hermite_pos_weight),
                                          vec_scale(edge['pos'], options.new_hermite_pos_weight))
                    edge['normal'] = vec_add(vec_scale(edge['normal'], 1.0 - options.new_hermite_normal_weight),
                                             vec_scale(edge['normal'], options.new_hermite_normal_weight))

        current_vertices = []
        for cell_id, edges in hermite_data.items():
            c = [cell_id[0] + 0.5, cell_id[1] + 0.5, cell_id[2] + 0.5] # Cell center [G]
            v = [0.0, 0.0, 0.0] # Initial guess [G]
            
            # 2b. Inner Loop: Solve quadratic optimization for v [S1, unofficial]
            for _ in range(options.inner_iters):
                grad = [0.0, 0.0, 0.0]
                for e in edges:
                    diff = vec_sub(v, e['pos'])
                    grad = vec_add(grad, vec_scale(diff, 2.0 * options.dc_weight))
                grad = vec_add(grad, vec_scale(vec_sub(v, c), 2.0 * options.mu))
                v = vec_sub(v, vec_scale(grad, 0.01)) # Fixed learning rate [G]
            current_vertices.append(v)

        # 2c. Mesh Generation: connect vertex to crossing edges [G]
        for i, cell_id in enumerate(hermite_data.keys()):
            v_idx = len(vertices) + i
            edges = hermite_data[cell_id]
            for j in range(len(edges)):
                p1 = edges[j]['pos']
                p2 = edges[(j + 1) % len(edges)]['pos']
                faces.append([v_idx, p1, p2])
        vertices.extend(current_vertices)

        if options.verbose:
            print(f"Outer iteration {outer_iter}, Vertices: {len(vertices)}")

    return vertices, faces
```

## Subtopics

### [Dual Contouring](778-dual-contouring.md)
Traditional dual contouring using Hermite data (positions and normals) as input. Choose when Hermite data is available or can be accurately computed.

### [MLS Projection](823-mls-projection.md)
Uses Moving Least Squares to project points onto the surface. Choose for smooth surfaces with scattered points.

### [Surface Nets](921-surface-nets.md)
Simpler method placing vertices at grid cell centers. Choose for speed and simplicity, not sharp features.

### [DCX Mesh Extraction via UDF and Marching Cubes](3778-dcx-mesh-extraction-via-udf-and-marching-cubes.md)
Uses Unsigned Distance Functions with Marching Cubes. Choose for UDF data.

### [Sparse Dual Marching Cubes](3801-sparse-dual-marching-cubes.md)
Optimized Marching Cubes for sparse data. Choose for large, sparse grids.

### [Screened Poisson Surface Reconstruction](6315-screened-poisson-surface-reconstruction.md)
Volumetric method for oriented point clouds. Choose for noisy point clouds with normals.

### [Dual Contouring Feature Point Iterative Projection](8388-dual-contouring-feature-point-iterative-projection.md)
Iterative projection for feature points in dual contouring. Choose for enhanced feature preservation.

### [Dual Contouring Edge Normal Calculation](8397-dual-contouring-edge-normal-calculation.md)
Specific method for calculating edge normals in dual contouring. Choose for normal accuracy.

### [DCx (Dual Contouring over Expanded Cubes)](9342-dcx-dual-contouring-over-expanded-cubes.md)
Dual contouring on expanded cubes for better topology. Choose for complex topologies.

## Operating characteristics
- **Time Complexity:** Depends on the number of grid cells and the number of iterations (`outer_iters` * `inner_iters`) [S1, unofficial].
- **Memory Complexity:** Not given in the sources [G].
- **Measured Performance:** Sets a new state of the art for medium and high-resolution SDF reconstruction [S1, unofficial]. Specific performance metrics are not provided [S1, unofficial].
- **Scaling:** Scales with grid resolution and number of iterations. Batch processing (`batch_size`) allows handling large grids [S1, unofficial].
- **Strengths:** Recovers sharp features effectively; does not require gradient information or arbitrary SDF access; works with discrete SDF data [S1, unofficial].
- **Limitations:** Requires careful tuning of parameters (e.g., `mu`, `dc_weight`); implementation tested only on macOS; performance may vary on other platforms [S1, unofficial].
- **When to Use:** When reconstructing meshes from SDF data with sharp features, and gradient information is not available or difficult to compute [S1, unofficial].
- **When Not to Use:** Not given in the sources [G].

## Background
The method was proposed by Xian Acerra et al. and is available in the repository `xianacarrera/dual-contouring-of-signed-distance-data` [S1, unofficial]. It builds on traditional Dual Contouring of Hermite Data, adapting it to work directly with SDF data [S1, unofficial]. The specific origin date and publication venue are not provided in the sources, but the code is described as the only maintained version of this approach [S1, unofficial].
