# SNeRG
Also called: Deferred Shading NeRF, SNeRG (Deferred Shading NeRF), Sparse Neural Radiance Fields with View-dependent Effects

## Overview
SNeRG reduces the computational cost of Neural Radiance Fields by decomposing the radiance field into a deferred shading model, limiting Multilayer Perceptron evaluations to one per ray [S1]. Unlike standard NeRF which queries view-dependent color for every sample, SNeRG caches diffuse colors and uses a small network for view-dependent effects, enabling real-time rendering [S2, unofficial].

## How it works
**Inputs:** Camera poses, intrinsics, and training images [G].
**Outputs:** Rendered images and an optimized scene representation [G].

**Data Structures:**
1. **Sparse 3D Grid:** Stores density ($\sigma$) and diffuse color ($c_d$) at voxel centers, using a hash map or sparse array for memory efficiency [S2, unofficial].
2. **3D Texture Atlas:** Caches baked diffuse colors for fast lookup [S2, unofficial].
3. **Feature Vectors ($f$):** Stored per voxel or interpolated, used to modulate view-dependent effects [S1].
4. **Small Network:** A lightweight MLP that computes view-dependent color from position and view direction [G].

**Steps:**
1. **Ray Marching:** For each pixel, cast a ray and use the sparse 3D grid to quickly locate surface boundaries and skip empty space [S2, unofficial].
2. **Sample Query:** For each sample point $x$ along the ray:
   a. Query the eight neighbors of $x$ on the low-resolution 3D grid [S1].
   b. Project $x$ onto three axis-aligned planes and query four neighbors on each high-resolution 2D grid [S1].
   c. Trilinearly interpolate density $\sigma$ and diffuse color $c_d$ from the 3D neighbors, and bilinearly interpolate from the 2D projections [S1].
   d. Interpolate feature vectors $f$ if used [S1].
3. **Deferred Shading:**
   a. Compute transmittance $T$ and accumulated density using standard volume rendering integration [G].
   b. The base color is the interpolated diffuse color $c_d$ [G].
   c. Pass the interpolated features, position, and view direction to the small network to compute the final view-dependent color [G].
4. **Rendering:** Composite the final color using the accumulated transmittance and the view-dependent color [G].
5. **Optimization:** Minimize the difference between rendered and ground truth images, applying a sparsity loss to reduce the VRAM usage of sparse voxels [S2, unofficial].

**Formulas:**
The radiance field is decomposed into density $\sigma$, diffuse color $c_d$, and features $f$ [S1].
The final color $C(r)$ for a ray $r$ is:
$$ C(r) = \sum_{i=1}^{N} T_i (1 - e^{-\sigma_i \delta_i}) c_i $$
where $T_i = e^{-\sum_{j=1}^{i-1} \sigma_j \delta_j}$, $\delta_i$ is the distance between adjacent samples, and $c_i$ is the view-dependent color computed by the small network [S1].

**Parameters:**
* Grid resolution: Low-resolution 3D grid with high-resolution 2D projections [S1].
* Network size: Small MLP for view-dependent effects [S2, unofficial].

**Edge Cases:**
* Boundaries: Sparse grid boundaries require careful handling to avoid artifacts [G].

## Operating characteristics
* **Time Complexity:** Reduced compared to standard NeRF due to fewer MLP evaluations [S1].
* **Memory Complexity:** Reduced VRAM usage via sparse voxels and caching [S2, unofficial].
* **Performance:** Enables real-time view synthesis [S2, unofficial].
* **Strengths:** Fast rendering and memory efficiency [S1][S2, unofficial].
* **When to use:** Real-time applications and large scenes [S2, unofficial].

## Background
SNeRG was introduced by Hedman et al. in "Baking Neural Radiance Fields for Real-Time View Synthesis" (ICCV 2021) [S2, unofficial]. It builds on the original NeRF work parameterized by an MLP [S1]. The method addresses the high computational cost of NeRF by decomposing the radiance field and using deferred shading [S1].
