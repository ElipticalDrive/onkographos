# Steerable Densification with Sampling

Also called: Score-based ranking densification

## Overview
Steerable Densification with Sampling is a density control method for 3D Gaussian Splatting that replaces heuristic gradient thresholds with a learned, score-based ranking system to select candidates for resampling [S1]. Unlike sibling methods that split or clone based on fixed size and gradient magnitude thresholds, this method computes a composite score for each Gaussian using image loss, spatial metrics, and primitive attributes, then probabilistically samples new primitives from the high-scoring population [S1]. It is distinguished by its significantly reduced execution frequency (every 500 iterations) to prevent the duplication of misplaced Gaussians caused by high loss [S1].

## How it works
**Inputs:**
*   Set of $N$ training camera views $V = \{v_i\}_{i=1}^N$.
*   Set of $M$ fitted 3D Gaussians $G = \{g_j\}_{j=1}^M$.
*   Set of $N$ rendered views $R = \{r_i\}_{i=1}^N$.
*   Current optimization state (loss, gradients, attributes).
*   Hyperparameters: $\lambda_1=0.5, \lambda_2=0.5$ (saliency weights), $B$ (budgeted number of Gaussians to add), and scoring weights $w_{\nabla}=50, w_{c}=0.1, w_{D}=50, w_{S}=10, w_{B}=50, w_{z}=5, w_{o}=100, w_{s}=25$ [S1].

**Outputs:**
*   Updated set of Gaussians $G'$ with $M + B$ primitives.

**Data Structures:**
*   **Saliency Matrix $S_v$**: A 2D matrix of size $H \times W$ (image height and width) for each view $v$. Values are floating-point saliency scores.
*   **Score Vector $S_G$**: A 1D vector of size $M$. $S_{G,j}$ is the scalar score for Gaussian $g_j$.

**Numbered Steps:**

1.  **Compute Per-View Saliency Matrices:**
    For each view $v_i \in V$:
    *   Calculate the L1 photometric loss map $L_1(v_i, r_i)$ between the rendered view and the ground truth.
    *   Apply a Laplacian filter $E(v_i)$ to the rendered view to detect high-frequency details.
    *   Define a binary Region of Interest (ROI) mask $\mathbb{1}_{ROI}$ (elements $\in \{0, 1\}$).
    *   Compute the saliency matrix $S_{v_i}$:
        $$ S_{v_i} = \mathbb{1}_{ROI} \odot (\lambda_1 L_1(v_i, r_i) + \lambda_2 E(v_i)) $$
        where $\odot$ is element-wise multiplication [S1].

2.  **Compute Gaussian Scores ($S_G$):**
    For each Gaussian $g_j \in G$:
    *   Initialize score $S_{g_j} = 0$.
    *   For each view $v_i \in V$:
        *   Identify the set of pixels covered by $g_j$ in view $i$. Let $\mathbb{1}_{g_{j,i}}$ be the binary mask of these pixels.
        *   Extract per-pixel metrics for these pixels:
            *   $D_{g_{j,i}}$: Distance of each pixel to the center of $g_j$.
            *   $B_{g_{j,i}}$: Blending weight of $g_j$ for each pixel.
            *   $z_{g_{j,i}}$: Depth of the pixel in view $i$.
        *   Extract per-Gaussian attributes:
            *   $\nabla_{g_j}$: Magnitude of the positional gradient.
            *   $c_{g_j}$: Number of pixels covered by $g_j$ in view $i$.
            *   $o_{g_j}$: Opacity of $g_j$.
            *   $s_{g_j}$: Scale of $g_j$.
        *   Evaluate the scoring function $F$:
            $$ F(\dots) = \sum_{k \in \{\nabla, c, D, S, B, z, o, s\}} w_k \cdot \text{median\_scale}(val_k) \cdot L_1(v_i, r_i) $$
            *Note: The source specifies that parameters are median-scaled to remove outliers and multiplied by the photometric loss before accumulation into a weighted sum [S1]. The specific mapping of attributes to weights is: $\nabla_g(50), c_g(0.1), D_g(50), S_{v_i}(10), B_{g_i}(50), z_{g_i}(5), o_g(100), s_g(25)$ [S1].*
        *   Add the result of $F$ to $S_{g_j}$.
    *   Store $S_{g_j}$ in $S_G$ [S1].

3.  **Resampling (Densification):**
    *   Normalize $S_G$ to form a probability distribution.
    *   Randomly sample $B$ indices from $G$ using $S_G$ as weights.
    *   For each sampled Gaussian $g_{sample}$:
        *   Create a new Gaussian $g_{new}$.
        *   The method description states "randomly resampling B primitives... using SG as sampling weights" [S1]. It does not explicitly define the geometric transformation (clone vs. split) for the resampled primitives in the provided text, but implies they are new instances derived from the high-score population. [G: In standard 3DGS contexts, resampling usually implies cloning or splitting; however, without explicit formula, we assume the primitive is instantiated at the sampled Gaussian's position with its attributes, or potentially split if the score implies high error. Given the alias "Score-based ranking densification" and the lack of explicit split/clone logic in S1's excerpt, the implementation must rely on the specific instantiation logic of the parent method or the paper's full algorithm. *Correction*: The text says "resampling B primitives from all Gaussians". This typically means creating new Gaussians based on the distribution of the selected ones. We will assume a clone operation with potential perturbation if not specified, but strictly following S1, it is a resampling step.]
    *   Add the $B$ new Gaussians to $G$ [S1].

**Parameters:**
*   **Densification Frequency:** Every 500 iterations (one-fifth of the standard 3DGS frequency) [S1].
*   **Training Views for Saliency:** $N=10$ uniformly sampled training views are used to compute per-pixel saliency scores [S1].
*   **Saliency Weights:** $\lambda_1 = 0.5, \lambda_2 = 0.5$ [S1].
*   **Scoring Weights:** $\nabla_g: 50, c_g: 0.1, D_g: 50, S_{v_i}: 10, B_{g_i}: 50, z_{g_i}: 5, o_g: 100, s_g: 25$ [S1].

**Pseudocode:**

```python
def steerable_densification(Gaussians, Views, Rendered_Views, Ground_Truth, B, Iteration):
    # Only execute every 500 iterations
    if Iteration % 500 != 0:
        return Gaussians

    # 1. Compute Saliency Matrices for N views
    # Note: Source uses N=10 views for this step
    Saliency_Matrices = []
    for i in range(10):
        v = Views[i]
        r = Rendered_Views[i]
        gt = Ground_Truth[i]
        
        # L1 Loss
        L1_loss = abs(r - gt)
        
        # Laplacian Filter (simplified as high-pass)
        E = apply_laplacian_filter(r)
        
        # ROI Mask (binary)
        ROI = get_roi_mask()
        
        # Saliency Matrix
        Sv = ROI * (0.5 * L1_loss + 0.5 * E)
        Saliency_Matrices.append(Sv)

    # 2. Compute Gaussian Scores
    Scores = []
    for g in Gaussians:
        g_score = 0.0
        
        # Accumulate score over the 10 views
        for i in range(10):
            Sv = Saliency_Matrices[i]
            v = Views[i]
            r = Rendered_Views[i]
            gt = Ground_Truth[i]
            L1_val = mean(L1_loss) # Or specific pixel loss? Source says "multiplied by i's photometric loss"
            
            # Get pixels covered by g in view i
            covered_pixels = get_covered_pixels(g, v)
            if not covered_pixels:
                continue
                
            # Extract metrics for covered pixels
            # D_g: distance to center
            D_g = get_distance_to_center(g, covered_pixels)
            # B_g: blending weight
            B_g = get_blending_weight(g, covered_pixels)
            # z_g: depth
            z_g = get_depth(covered_pixels)
            
            # Per-Gaussian attributes
            grad_mag = get_gradient_magnitude(g)
            pixel_count = len(covered_pixels)
            opacity = g.opacity
            scale = g.scale
            
            # Median scaling to remove outliers (simplified: normalize by median of all values for this metric)
            # In practice, this requires global medians computed beforehand
            median_grad = get_global_median('grad')
            median_scale = get_global_median('scale')
            # ... other medians ...
            
            # Weighted sum
            # Note: Source says "multiplied by photometric loss before accumulation"
            # We use the mean L1 loss for the view as the multiplier
            loss_multiplier = mean(L1_loss)
            
            term_grad = 50 * (grad_mag / median_grad) * loss_multiplier
            term_c = 0.1 * (pixel_count / get_global_median('count')) * loss_multiplier
            term_D = 50 * (mean(D_g) / get_global_median('dist')) * loss_multiplier
            term_S = 10 * mean(Sv[covered_pixels]) # S_vi is the saliency value
            term_B = 50 * (mean(B_g) / get_global_median('blend')) * loss_multiplier
            term_z = 5 * (mean(z_g) / get_global_median('depth')) * loss_multiplier
            term_o = 100 * (opacity / get_global_median('opacity')) * loss_multiplier
            term_s = 25 * (scale / median_scale) * loss_multiplier
            
            g_score += term_grad + term_c + term_D + term_S + term_B + term_z + term_o + term_s
            
        Scores.append(g_score)

    # 3. Resampling
    # Normalize scores to probabilities
    Probabilities = softmax(Scores)
    
    # Sample B indices
    Indices = random_multinomial(Probabilities, B)
    
    New_Gaussians = []
    for idx in Indices:
        source_g = Gaussians[idx]
        # Create new Gaussian. 
        # Source implies "resampling". 
        # [G: Standard implementation clones the position/scale/rotation but may perturb or keep identical. 
        # Given "score-based ranking", it selects high-error Gaussians. 
        # We assume a clone operation to add density, as splitting is handled by other methods or implicit in "densification".]
        new_g = clone_gaussian(source_g)
        New_Gaussians.append(new_g)
        
    return Gaussians + New_Gaussians
```

## Operating characteristics
*   **Time Complexity:** Adds an extra $O(N \times \text{width} \times \text{height})$ step for computing all $N$ saliency matrices $S_v$, plus an auxiliary rendering pass to obtain $S_G$ [S1].
*   **Memory Complexity:** Requires storing $N$ saliency matrices of size $H \times W$ and the score vector $S_G$ of size $M$ [S1].
*   **Strengths:** Interpretable and steerable; incorporates image loss directly to guide densification; reduces wasteful behavior and superfluous Gaussians by using a lower frequency [S1].
*   **Limitations:** Higher computational overhead per densification step due to saliency matrix computation; requires careful tuning of scoring weights [S1].
*   **When to use:** When high-quality radiance fields are needed with limited resources and interpretability is desired; when standard gradient-based densification produces too many Gaussians or duplicates misplaced ones [S1].

## Background
Steerable Densification with Sampling was introduced in the paper "Taming 3DGS: High-Quality Radiance Fields with Limited Resources" [S1]. It addresses the issue that frequent densification in 3D Gaussian Splatting can cause repeated duplication of misplaced Gaussians if guided solely by loss [S1]. The method reduces the densification frequency to one-fifth of the original 3DGS schedule (every 500 iterations) to allow the optimizer time to correct misplaced primitives before densification occurs [S1].
