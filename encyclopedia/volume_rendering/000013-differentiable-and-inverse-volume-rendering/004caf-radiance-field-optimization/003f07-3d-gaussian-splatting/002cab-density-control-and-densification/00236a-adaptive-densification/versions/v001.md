# Adaptive Densification

Also called: Adaptive Density Control, Gaussian Cloning, Splitting, and Pruning, Gradient-based densification

## Overview
Adaptive Densification is a mechanism that dynamically adjusts the number, position, and scale of 3D Gaussians during optimization to improve reconstruction quality while maintaining a fixed budget [S2]. It addresses the limitation of standard gradient descent, which can only move, stretch, or fade existing primitives but cannot create new ones in empty regions or cleanly remove useless ones [S1, unofficial]. By inspecting view-space positional gradients at fixed intervals, the method triggers cloning, splitting, or pruning actions to ensure model capacity follows image error, densifying exactly where the scene is complex and staying lean where it is simple [S1, unofficial]. It is distinguished from its siblings by its specific reliance on average gradient magnitude combined with scale thresholds to classify Gaussians into "under-reconstructed" (clone) or "over-reconstructed" (split) categories, rather than using loss accumulation or fixed-pool relocation [S1, unofficial][S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   $\mu \in \mathbb{R}^{n \times d}$: Mean positions of $n$ Gaussians.
    *   $\sigma \in \mathbb{R}^{n \times 1}$: Standard deviations (scales) of Gaussians.
    *   $I \in \mathbb{R}^{n \times 1}$: Intensities (or opacities) of Gaussians.
    *   $\mu.grad$: Accumulated view-space positional gradients for the means.
    *   $n_{max}$: Maximum allowed quantity of Gaussians (default 500,000) [S2].
    *   $\tau$: Minimum gradient value threshold for densification (default $2 \times 10^{-4}$) [S2].
    *   $\theta$: Threshold for classifying Gaussians as small or large, defined as 0.005 of the body diagonal length (default 0.005) [S2].
    *   $size$: Box size of each Gaussian (default 17) [S2].
    *   $max\_iter$: Total number of training iterations.
*   **Outputs:**
    *   Updated $\mu, \sigma, I$ arrays after densification steps.

**Data Structures:**
The method operates on arrays of Gaussian parameters. The number of Gaussians $n$ changes dynamically. Arrays are resized by concatenation (for cloning/splitting) or filtering (for pruning).

**Parameters:**
*   $n_{max} = 500,000$ [S2].
*   $\tau = 2 \times 10^{-4}$ [S2].
*   $\theta = 0.005 \times \text{body diagonal}$ [S2].
*   $size = 17$ [S2].
*   Densification interval: Every 100 iterations, starting from iteration 100 [S2].

**Algorithm Steps:**
The densification process is executed periodically. For each densification step:

1.  **Calculate Average Gradient:** Compute the average gradient magnitude for each Gaussian to normalize for training duration:
    $$ \text{avg\_grad}_i = \frac{\|\mu.grad_i\|}{\text{iteration}} $$
    [S2]

2.  **Clone Phase (Under-reconstructed regions):**
    *   Identify candidates where $\text{avg\_grad}_i \ge \tau$ AND $\sigma_i \le \theta$ [S2].
    *   Calculate available slots: $n_{avail} = n_{max} - n$ [S2].
    *   Determine number of clones: $n_{clone} = \min(n_{avail}, \text{count}(\text{candidates}))$ [S2].
    *   Select top $n_{clone}$ candidates based on descending $\text{avg\_grad}$ [S2].
    *   For each selected Gaussian $i$:
        *   Create a clone with identical position $\mu_{clone} = \mu_i$ and covariance/scale $\sigma_{clone} = \sigma_i$ [S2].
        *   Halve the intensity: $I_{clone} = I_i / 2$ [S2].
        *   Detach gradients from the clone (set to zero) to prevent immediate re-densification of the copy [S2].
        *   Append clone parameters to the arrays.
        *   Update $n \leftarrow n + 1$ [S2].

3.  **Split Phase (Over-reconstructed regions):**
    *   Identify candidates where $\text{avg\_grad}_i \ge \tau$ AND $\sigma_i > \theta$ [S2].
    *   Recalculate available slots: $n_{avail} = n_{max} - n$ [S2].
    *   Determine number of splits: $n_{split} = \min(n_{avail}, \text{count}(\text{candidates}))$ [S2].
    *   Select top $n_{split}$ candidates based on descending $\text{avg\_grad}$ [S2].
    *   For each selected Gaussian $i$:
        *   Sample new positions $\mu_{new}$ from the Probability Density Function (PDF) of the original Gaussian [S2].
        *   Reduce scale to maintain volume: $\sigma_{new} = \sigma_i / (\sqrt{3}/2)$ [S2].
        *   Assign intensity $I_{new} = I_i$ [S2].
        *   Remove the original Gaussian $i$ from the arrays.

4.  **Prune Phase:**
    *   Identify Gaussians to remove where $\text{avg\_grad}_i \le \tau$ OR $\sigma_i > 3 \times size$ [S2].
    *   Filter arrays $\mu, \sigma, I$ to retain only Gaussians not in the prune mask [S2].
    *   Update $n$ to the new count [S2].

**Pseudocode:**

```python
def adaptive_densification(mu, sigma, I, mu_grad, iteration, n_max=500000, tau=2e-4, theta=0.005, size=17):
    """
    Performs one step of adaptive densification.
    mu: array of shape (n, d)
    sigma: array of shape (n, 1)
    I: array of shape (n, 1)
    mu_grad: array of shape (n, d)
    iteration: current training iteration number
    """
    n = len(mu)
    
    # 1. Calculate average gradient
    # Note: mu_grad is accumulated. We divide by iteration to get average.
    # We use L2 norm for magnitude.
    grad_magnitudes = np.linalg.norm(mu_grad, axis=1) / iteration
    
    # 2. Clone Phase
    # Condition: avg_grad >= tau AND sigma <= theta
    # theta is a scalar threshold for sigma (assuming sigma is scalar or we take norm)
    # Assuming sigma is scalar standard deviation for simplicity as per source
    small_mask = (grad_magnitudes >= tau) & (sigma.flatten() <= theta)
    
    available = n_max - n
    candidates = np.where(small_mask)[0]
    n_clone = min(available, len(candidates))
    
    if n_clone > 0:
        # Sort candidates by gradient descending
        sorted_indices = candidates[np.argsort(-grad_magnitudes[candidates])]
        clone_indices = sorted_indices[:n_clone]
        
        # Halve intensity
        I[clone_indices] /= 2.0
        
        # Create clones: copy params, detach gradients (set to 0 in grad array for next step, 
        # but here we just create new entries with 0 grad)
        mu_clone = mu[clone_indices].copy()
        sigma_clone = sigma[clone_indices].copy()
        I_clone = I[clone_indices].copy()
        
        # Append to arrays
        mu = np.concatenate([mu, mu_clone], axis=0)
        sigma = np.concatenate([sigma, sigma_clone], axis=0)
        I = np.concatenate([I, I_clone], axis=0)
        
        # Reset gradients for clones to zero (they are new, so their accumulated grad is 0, 
        # but we must ensure they don't inherit the grad of the parent for the *current* step's 
        # accumulation if we were doing incremental. Here we just append. 
        # The source says "gradients of cloned Gaussians are set to zero".
        # Since we append new rows, we need to append zero gradients.
        mu_grad = np.concatenate([mu_grad, np.zeros((n_clone, mu_grad.shape[1]))], axis=0)
        
        n += n_clone

    # 3. Split Phase
    # Condition: avg_grad >= tau AND sigma > theta
    large_mask = (grad_magnitudes >= tau) & (sigma.flatten() > theta)
    
    available = n_max - n
    candidates = np.where(large_mask)[0]
    n_split = min(available, len(candidates))
    
    if n_split > 0:
        sorted_indices = candidates[np.argsort(-grad_magnitudes[candidates])]
        split_indices = sorted_indices[:n_split]
        
        # Sample new positions from PDF
        # Assuming 3D Gaussian PDF sampling
        mu_new = sample_from_gaussian_pdf(mu[split_indices], sigma[split_indices], count=2 * n_split)
        
        # Reduce scale: sigma_new = sigma / (sqrt(3)/2)
        sigma_new = sigma[split_indices] / (np.sqrt(3) / 2)
        sigma_new = np.tile(sigma_new, (2, 1)) # Duplicate for the two new Gaussians
        
        # Intensity remains same for each new Gaussian? Source says Inew = I[masksplit]
        # If splitting 1 into 2, and Inew = I, then total intensity doubles? 
        # Source [S2] says "Inew = I[masksplit]". It does not say halve. 
        # However, standard 3DGS often halves intensity. 
        # The source [S2] explicitly says for Clone: halve intensity. 
        # For Split: "Inew = I[masksplit]". This implies no halving for split.
        I_new = I[split_indices]
        I_new = np.tile(I_new, (2, 1))
        
        # Remove original split Gaussians
        # We need to remove indices in split_indices from mu, sigma, I, mu_grad
        # Create a mask of indices to keep
        all_indices = np.arange(n)
        keep_mask = np.ones(n, dtype=bool)
        keep_mask[split_indices] = False
        
        mu = mu[keep_mask]
        sigma = sigma[keep_mask]
        I = I[keep_mask]
        mu_grad = mu_grad[keep_mask]
        
        # Append new Gaussians
        mu = np.concatenate([mu, mu_new], axis=0)
        sigma = np.concatenate([sigma, sigma_new], axis=0)
        I = np.concatenate([I, I_new], axis=0)
        
        # New Gaussians have 0 accumulated gradient initially
        mu_grad = np.concatenate([mu_grad, np.zeros((n_split * 2, mu_grad.shape[1]))], axis=0)
        
        n += n_split # Net increase is n_split (since we removed n_split and added 2*n_split)

    # 4. Prune Phase
    # Condition: avg_grad <= tau OR sigma > 3 * size
    prune_mask = (grad_magnitudes <= tau) | (sigma.flatten() > 3 * size)
    
    mu = mu[~prune_mask]
    sigma = sigma[~prune_mask]
    I = I[~prune_mask]
    mu_grad = mu_grad[~prune_mask]
    
    n = len(mu)
    
    return mu, sigma, I, mu_grad

def sample_from_gaussian_pdf(mu, sigma, count):
    """
    Samples 'count' points from the Gaussian distribution defined by mu and sigma.
    mu: (k, d)
    sigma: (k, 1)
    Returns: (count, d)
    """
    k = mu.shape[0]
    # We need 2 samples per Gaussian if we are splitting k Gaussians into 2k
    # But the function is called with count = 2 * n_split
    # We can sample k * 2 points
    samples = np.random.normal(loc=mu, scale=sigma, size=(count, mu.shape[1]))
    return samples
```

**Edge Cases and Pitfalls:**
*   **Blurry Backgrounds:** If splitting is disabled, over-large Gaussians remain unbroken, causing blurry backgrounds [S1, unofficial].
*   **Lost Thin Structures:** If cloning is disabled, under-covered thin structures (e.g., bicycle spokes) are lost [S1, unofficial].
*   **Unbounded Growth:** The $n_{max}$ constraint is critical to prevent memory overflow [S2].
*   **Gradient Normalization:** Using average gradient ($\mu.grad / iteration$) prevents early iterations from dominating the densification decision [S2].

## Operating characteristics
*   **Time Complexity:** The densification step itself is $O(n)$ for gradient calculation and mask creation, and $O(n \log n)$ for sorting [S2]. The overall training complexity is dominated by the rendering step, but densification adds a periodic overhead.
*   **Memory Complexity:** Memory usage is bounded by $n_{max}$ Gaussians [S2].
*   **Performance:** The method allows the representation to adapt to scene complexity, improving reconstruction quality in detailed regions while keeping the model size manageable [S1, unofficial][S2].
*   **Strengths:** Dynamically adjusts capacity; handles both under- and over-reconstructed regions; prevents floating artifacts via pruning [S1, unofficial][S2].
*   **Limitations:** Requires careful tuning of thresholds ($\tau, \theta$); periodic densification can cause transient visual artifacts if not smoothed [S1, unofficial][S2].
*   **When to use:** When training 3D Gaussian Splatting models where the initial point cloud is sparse or the scene has varying levels of detail [S1, unofficial][S2].
*   **When not to use:** When a fixed number of Gaussians is strictly required and no adaptation is allowed, or when computational resources are extremely limited and periodic densification overhead is prohibitive.

## Background
Adaptive Densification was inspired by the adaptive density control utilized in 3D Gaussian Splatting [S1, unofficial][S2]. It was implemented for Discretized Gaussian Representation (DGR) for tomographic reconstruction to densify Gaussians within the discretized 3D volume during optimization [S2]. The method addresses the fundamental limitation of gradient-based optimization in sparse representations, which cannot create new primitives [S1, unofficial]. The specific parameters and logic (cloning small high-gradient Gaussians, splitting large high-gradient Gaussians, pruning low-gradient/oversized ones) are derived from the original 3D Gaussian Splatting paper and adapted for volume rendering contexts [S1, unofficial][S2].
