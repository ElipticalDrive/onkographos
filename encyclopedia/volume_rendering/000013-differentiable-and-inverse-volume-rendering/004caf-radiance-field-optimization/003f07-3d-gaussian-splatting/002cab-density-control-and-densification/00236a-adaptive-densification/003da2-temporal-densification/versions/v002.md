# Temporal Densification

Also called: Temporal Splitting

## Overview
Temporal densification is a strategy for 3D Gaussian Splatting that detects and resolves reconstruction errors caused by object or camera motion by splitting Gaussians based on the variance of their normalized image error across time segments [S1]. It addresses the limitation of static spatial densification, which assumes Gaussians are stationary, by identifying Gaussians whose error fluctuates significantly between keyframes, indicating they fail to track motion [S1].

## How it works
**Inputs:**
- A set of 3D Gaussians $\mathcal{G}$ [S1].
- A sequence of training images indexed by time $t$ [S1].
- Hyperparameters: temporal threshold $\tau_{time}$, KNN count $K=10$, minimum segment length $l_{seg}$ [S1].

**Outputs:**
- An updated set of Gaussians $\mathcal{G}'$ with new Gaussians added via splitting for those exhibiting high temporal error variation [S1].

**Data Structures:**
- **Keyframe List:** For each Gaussian $g$, a sorted list of keyframe indices $[t_0^g, t_1^g, \dots, t_m^g]$ that partition the frame sequence into segments [S1].
- **Error Buffer:** For each Gaussian $g$ and image $I$, the scalar image error $e_{g,I}$ and the number of projected pixels $N_{g,I}^p$ [S1].
- **Weights:** Precomputed weights $w_{g,I}$ for each Gaussian-image pair, derived from the optimization loss weighting scheme [S1].

**Steps:**

1.  **Segment Definition:** Divide the frame sequence for Gaussian $g$ into segments using its keyframes $t_i^g$ such that $t_i^g \le t < t_{i+1}^g$ [S1]. If $g$ has only one keyframe $t_0^g$, the segment covers all frames $t \ge t_0^g$ [S1].
2.  **Normalized Error Calculation:** For each Gaussian $g$ and image $I$, compute the normalized image error $\bar{e}_{g,I}$ by dividing the raw error $e_{g,I}$ by the number of projected pixels $N_{g,I}^p$ to normalize for projected area [S1]:
    $$
    \bar{e}_{g,I} = \frac{e_{g,I}}{N_{g,I}^p} \quad (24)
    $$
3.  **Weighted Mean and Variance:** Compute the weighted mean normalized error $\bar{e}_g$ and the standard deviation $\sigma_{\bar{e}_g}$ for each segment using weights $w_{g,I}$ [S1]:
    $$
    \bar{e}_g = \frac{\sum_{I \in \mathcal{I}} \bar{e}_{g,I} w_{g,I}}{\sum_{I \in \mathcal{I}} w_{g,I}} \quad (25)
    $$
    $$
    \sigma_{\bar{e}_g} = \sqrt{\frac{\sum_{I \in \mathcal{I}} \bar{e}_{g,I}^2 w_{g,I}}{\sum_{I \in \mathcal{I}} w_{g,I}} - \bar{e}_g^2} \quad (26)
    $$
4.  **Variation Ratio:** Calculate the variation ratio $\rho_g = \sigma_{\bar{e}_g} / \bar{e}_g$ for each segment [S1].
5.  **Splitting Criterion:** Mark $g$ for splitting if $\rho_g > \tau_{time}$ for any segment [S1]. Also mark $g$ if any of its $K=10$ nearest neighbors satisfies the criterion, to handle uniformly colored areas where error variation is naturally low [S1].
6.  **Keyframe Management:** For marked Gaussians, add a keyframe at the frame index $I_{\text{max}}$ with the maximum error $e_{g,I}$ in the relevant segment [S1]. If $I_{\text{max}}$ coincides with the left keyframe $t_i^g$, insert the segment midpoint instead [S1]. Skip insertion if the resulting segments would be shorter than $l_{seg}$ [S1].
7.  **Execution:** Perform the split operation on all marked Gaussians [S1]. The split direction and plane follow the standard spatial splitting logic from the parent article [G].

**Pseudocode:**

```python
def temporal_densification(gaussians, frames, keyframes_dict, weights, threshold_tau, k_nn=10, min_seg_len=10):
    to_split = set()
    new_keyframes = []

    for g in gaussians:
        gid = g['id']
        kf_list = keyframes_dict[gid]
        if not kf_list:
            continue

        segments = []
        for i in range(len(kf_list) - 1):
            segments.append((kf_list[i], kf_list[i+1]))
        if len(kf_list) == 1:
            segments.append((kf_list[0], max(frames) + 1))

        split_candidate = False
        max_e_in_seg = -1.0
        max_frame_in_seg = None
        trigger_seg_idx = -1

        for seg_idx, (t_start, t_end) in enumerate(segments):
            seg_norm_errors = []
            seg_weights = []

            for f_idx in frames:
                if t_start <= f_idx < t_end:
                    e = g['errors'].get(f_idx, 0.0)
                    n_p = g['projected_pixels'].get(f_idx, 1)
                    if n_p == 0: n_p = 1
                    norm_err = e / n_p
                    w = weights.get((gid, f_idx), 1.0)
                    seg_norm_errors.append(norm_err)
                    seg_weights.append(w)

            if not seg_weights:
                continue

            sum_w = sum(seg_weights)
            if sum_w == 0:
                continue

            mean_err = sum(e * w for e, w in zip(seg_norm_errors, seg_weights)) / sum_w
            var_err = sum(e**2 * w for e, w in zip(seg_norm_errors, seg_weights)) / sum_w - mean_err**2
            std_err = (var_err ** 0.5) if var_err > 0 else 0.0

            rho = std_err / mean_err if mean_err != 0 else 0.0

            if rho > threshold_tau:
                split_candidate = True
                trigger_seg_idx = seg_idx
                for f_idx in frames:
                    if t_start <= f_idx < t_end:
                        e = g['errors'].get(f_idx, 0.0)
                        if e > max_e_in_seg:
                            max_e_in_seg = e
                            max_frame_in_seg = f_idx
                break

        if not split_candidate:
            dists = []
            for nb in gaussians:
                if nb['id'] != gid:
                    dx = nb['pos'][0] - g['pos'][0]
                    dy = nb['pos'][1] - g['pos'][1]
                    dz = nb['pos'][2] - g['pos'][2]
                    dists.append((dx*dx + dy*dy + dz*dz, nb))
            dists.sort()
            for _, nb in dists[:k_nn]:
                if nb.get('rho', 0.0) > threshold_tau:
                    split_candidate = True
                    break

        if split_candidate:
            to_split.add(gid)
            if max_frame_in_seg is not None and trigger_seg_idx != -1:
                t_left, t_right = segments[trigger_seg_idx]
                new_kf = max_frame_in_seg if max_frame_in_seg != t_left else (t_left + t_right) // 2
                if new_kf - t_left >= min_seg_len and t_right - new_kf >= min_seg_len:
                    new_keyframes.append((gid, new_kf))

    for g in gaussians:
        if g['id'] in to_split:
            # Perform standard spatial split operation from parent article [G]
            pass
    for gid, kf in new_keyframes:
        if gid in keyframes_dict:
            keyframes_dict[gid].append(kf)
            keyframes_dict[gid].sort()
```

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Requires storing error statistics and weights per Gaussian per frame, increasing memory usage compared to static splatting [S1].
- **Strengths:** Effectively reconstructs scenes with oscillatory or complex motion where static Gaussians fail [S1]. The method is interleaved with spatial densification every 2 epochs to balance spatial detail and temporal tracking [S1].
- **Limitations:** Computationally expensive due to per-frame error aggregation and sensitive to the choice of $\tau_{time}$ and $l_{seg}$ [S1].
- **When to use:** Scenes with significant camera or object motion [S1].

## Background
Temporal densification was introduced in "Adaptive Spatio-Temporal 3D Gaussian Splatting for Scenes with Oscillatory Motion" to address the inability of standard 3D Gaussian Splatting to handle non-rigid or oscillatory motion [S1]. It extends the adaptive densification framework by incorporating temporal variance analysis, allowing Gaussians to split not just based on spatial gradient but also on temporal error fluctuation [S1].
