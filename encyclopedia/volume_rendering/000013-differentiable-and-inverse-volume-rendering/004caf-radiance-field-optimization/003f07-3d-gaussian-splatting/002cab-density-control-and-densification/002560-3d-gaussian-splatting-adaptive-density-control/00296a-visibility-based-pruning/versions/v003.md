# Visibility-Based Pruning

Also called: Gradient-based Pruning, Zero-gradient Pruning

## Overview
Visibility-Based Pruning removes surfels that were never reached during the backward pass, which occurs when they are persistently occluded, lie outside all camera frustums, or fail the kernel cutoff test at every pixel [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A set of surfels $S$, each tracking its cumulative screen-space gradient magnitude across all training views, along with a flag indicating the end of a training epoch [S1, unofficial].
- Output: A pruned subset $S' \subset S$ containing only surfels that received non-zero gradients [S1, unofficial].

**Data Structures:**
- Each surfel stores geometric and appearance parameters, plus a floating-point field tracking the cumulative screen-space gradient magnitude accumulated over the epoch [S1, unofficial]. The exact field name is implementation-defined [G].

**Steps:**
1. **Accumulate Gradients:** During the training epoch, for each surfel $i$ rendered in view $v$, compute the loss gradient projected to screen space and add its magnitude to the surfel's cumulative field [S1, unofficial].
2. **Check Zero Gradient:** At the epoch boundary, iterate through all surfels in $S$ [S1, unofficial].
3. **Prune:** Remove any surfel whose cumulative screen-space gradient magnitude equals zero [S1, unofficial].

**Formula:**
$$ S' = \{ s_i \in S \mid \sum_{v \in \text{Views}} \|\nabla_{\text{screen}} \mathcal{L}_i^{(v)}\| > 0 \} $$
Where:
- $S$: Set of surfels at the start of the epoch.
- $S'$: Set of surfels after pruning.
- $s_i$: The $i$-th surfel.
- $\nabla_{\text{screen}} \mathcal{L}_i^{(v)}$: Screen-space gradient of the loss for surfel $i$ in view $v$.
[S1, unofficial]

**Parameters:**
- Threshold: $0.0$ (exact zero check) [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Numerical Precision:** The source specifies an exact zero check, implying any non-zero accumulation survives pruning [S1, unofficial]. Implementers should ensure gradients are not artificially clamped to zero during accumulation [G].
- **First Epoch:** If a surfel is initialized but never rendered (e.g., completely outside all frustums), its gradient remains zero and it is pruned immediately, which is intended behavior [S1, unofficial].

**Pseudocode:**
```python
def visibility_based_pruning(surfels, epoch_end_flag):
    """
    Removes surfels with zero cumulative screen-space gradient magnitude.
    """
    if not epoch_end_flag:
        return surfels
    
    pruned_surfels = []
    for surfel in surfels:
        if surfel.cumulative_gradient > 0.0:
            pruned_surfels.append(surfel)
        surfel.cumulative_gradient = 0.0  # Reset for next epoch [G]
        
    return pruned_surfels
```

## Subtopics

### Isolation-Based Pruning
Removes surfels lacking neighbors within their kernel support radius, identifying geometrically degenerate single-surfel groups that cannot form coherent surface layers [S1, unofficial]. It sets itself apart from visibility pruning by targeting spatial isolation rather than gradient absence [S1, unofficial]. Choose it when surface coherence is critical and isolated noise points are present [S1, unofficial].

### Anchor Pruning with View-Frequency
Removes redundant and ineffective anchors that cause floaters by evaluating view-frequency instead of opacity alone [S2]. It sets itself apart by correlating anchor selection probability in training views with received gradients [S2]. Choose it when insufficiently optimized anchors degrade rendering quality and storage overhead [S2].

## Operating characteristics
Time and memory complexity are not given in the sources. The method adds negligible overhead to the standard rendering pass [G]. It is strictly a training-time optimization and is not used for real-time inference without training [G]. It efficiently removes primitives that carry no scene information [S1, unofficial].

## Background
It is part of the adaptive density control strategy for 3D Gaussian Splatting variants that use surfels [S1, unofficial]. The method leverages the fact that surfels not reached in the backward pass carry no scene information [S1, unofficial].
