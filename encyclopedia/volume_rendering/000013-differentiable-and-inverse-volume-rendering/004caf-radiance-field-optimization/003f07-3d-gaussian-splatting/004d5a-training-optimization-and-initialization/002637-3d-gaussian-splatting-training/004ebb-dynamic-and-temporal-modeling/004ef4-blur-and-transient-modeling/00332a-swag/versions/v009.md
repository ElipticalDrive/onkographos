# SWAG

Also called: SWAG: Unsupervised Transient Gaussian Splatting, Unsupervised Transient Gaussians

## Overview
SWAG extends 3D Gaussian Splatting (3DGS) by conditioning Gaussians on learned appearance embeddings to handle dynamic scenes with transient occluders [S1][S2, unofficial]. It distinguishes itself from sibling methods like Neural Transient Field (NeTF) by operating directly in the Gaussian primitive space rather than a continuous neural field, using unsupervised transient Gaussians to ignore occluders [S1][S2, unofficial].

## How it works
SWAG modifies the standard 3DGS pipeline to support temporal dynamics and transient removal without explicit segmentation masks.

**Inputs and Outputs:**
*   **Inputs:** A set of images $\{I_t\}$ captured at different times $t$, camera poses, and intrinsics.
*   **Outputs:** A set of 3D Gaussians $\mathcal{G}$ with time-dependent attributes and appearance embeddings.

**Data Structures:**
Each Gaussian $g_i$ in the set $\mathcal{G}$ stores:
*   Mean position $\mu_i \in \mathbb{R}^3$
*   Covariance $\Sigma_i \in \mathbb{R}^{3 \times 3}$ (or rotation $\mathbf{q}_i \in \mathbb{R}^4$ and scale $\mathbf{s}_i \in \mathbb{R}^3$)
*   Opacity $\alpha_i \in [0, 1]$
*   Spherical Harmonics coefficients for color $\mathbf{c}_i$
*   **Appearance Embedding** $\mathbf{e}_i \in \mathbb{R}^d$: A learnable vector associated with the Gaussian to capture appearance variations across time.

**Method Steps:**
1.  **Initialization:** Initialize Gaussians from a structure-from-motion (SfM) point cloud, similar to standard 3DGS [S1][S2, unofficial].
2.  **Appearance Conditioning:** Associate each Gaussian with a learnable appearance embedding $\mathbf{e}_i$. The color of a Gaussian is not static but is predicted by a small network or lookup based on $\mathbf{e}_i$ and the current time $t$ or view direction [S1][S2, unofficial].
3.  **Transient Gaussian Training:** Introduce "transient Gaussians" or modify the optimization of existing Gaussians to be unsupervised regarding transients. The method trains Gaussians to ignore occluders (transients) by leveraging the appearance embeddings. If a Gaussian's appearance deviates significantly from the learned embedding for a given time/view, it is treated as transient and its contribution is suppressed or it is pruned [S1][S2, unofficial].
4.  **Rendering:** Render the scene using standard differentiable rasterization of Gaussians. The color of each Gaussian is modulated by its appearance embedding, allowing the same geometry to appear differently at different times [S1][S2, unofficial].
5.  **Optimization:** Minimize photometric loss between rendered and ground truth images. The appearance embeddings allow the model to disentangle static geometry from transient effects without explicit labels [S1][S2, unofficial].

**Parameters:**
*   Embedding dimension $d$: Not given in the sources.
*   Learning rate: Not given in the sources.

**Edge Cases:**
*   **Precision:** Standard 3DGS precision issues apply.
*   **Boundaries:** Transient objects that persist across all views/times may be incorrectly modeled as static geometry.

## Subtopics

### Neural Transient Field (NeTF)
Uses a neural network to model transient fields explicitly in continuous space, contrasting with SWAG's discrete Gaussian approach. See [Neural Transient Field (NeTF)](4692-neural-transient-field-netf.md).

## Operating characteristics
*   **Time and Memory Complexity:** Inherits the complexity of 3DGS, which is generally efficient for rendering but requires significant memory for large numbers of Gaussians. Training time depends on the number of Gaussians and the complexity of the appearance embedding network.
*   **Measured Performance:** Yields state-of-the-art results on diverse photo scenes with transients [S1][S2, unofficial].
*   **Strengths:** Unsupervised handling of transients; fast render times; robust to casual captures.
*   **Limitations:** Relies on the effectiveness of appearance embeddings to separate static and transient components.
*   **When to use:** When reconstructing dynamic scenes with transient occluders (e.g., people, cars) from casual photo collections without manual segmentation.

## Background
SWAG was introduced as an extension to 3D Gaussian Splatting to address the challenge of transient objects in dynamic scene reconstruction. It builds on the principles of 3DGS and introduces unsupervised transient modeling via appearance embeddings. It is cited in surveys of 3D Gaussian Splatting applications [S1][S2, unofficial].
