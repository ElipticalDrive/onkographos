# On-the-Fly Dynamic NeRF Training

Also called: OD-NeRF

## Overview
On-the-fly dynamic NeRF training is a method for reconstructing dynamic scenes by training a neural radiance field concurrently with the acquisition of training frames, enabling the streaming of the scene as the event unfolds [S1]. Unlike standard dynamic NeRFs that require full video sequences for offline 4D reconstruction, this approach estimates the radiance field for the current time step $t_k$ using only the images up to $t_k$ and the radiance field from the previous step $t_{k-1}$ [S1]. It distinguishes itself by applying a first-order Markov assumption to limit the dependency history, allowing for minimal optimization iterations per frame and interactive-speed streaming [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A sequence of multi-view forward-facing images $C_{0:K}$ captured over time $t_{0:K}$; the radiance field $F_{k-1}$ estimated at the previous time step.
*   **Outputs:** The updated radiance field function $F_k$ at the current time step $t_k$, which maps spatial coordinates $\mathbf{x} \in \mathbb{R}^3$, viewing directions $\mathbf{d} \in \mathbb{R}^3$, and time $t$ to volume density $\sigma \in \mathbb{R}$ and RGB color $\mathbf{c} \in \mathbb{R}^3$ [S1].

**Data Structures:**
*   **Radiance Field $F$:** A neural network (typically an MLP) parameterized by weights $\theta$. The input is $(\mathbf{x}, \mathbf{d}, t)$ and the output is $(\sigma, \mathbf{c})$.
*   **Occupancy Grid $G$:** A sparse data structure used for efficient ray sampling, updated via a transition function $P(G_k | G_{k-1})$ [S1].

**Algorithm Steps:**
1.  **Initialization:** Initialize the radiance field $F_0$ and occupancy grid $G_0$ using the first set of images $C_0$.
2.  **Iterative Training:** For each subsequent time step $k = 1, \dots, K$:
    a.  **Markov Simplification:** Assume conditional independence $F_k \perp\!\!\!\perp \{C_{0:k-1}, F_{0:k-2}\} \mid \{C_k, F_{k-1}\}$. This reduces the estimation problem to finding $F_k$ conditioned only on the current images $C_k$ and the previous field $F_{k-1}$ [S1].
    b.  **Transition:** Update the occupancy grid $G_k$ from $G_{k-1}$ to maintain efficient sampling for the dynamic scene [S1].
    c.  **Optimization:** Minimize the rendering loss between the rendered image $\hat{C}_k$ and the ground truth image $C_k$ for the current time step:
        $$ F_k = \arg\min_{F_k} \sum_{r \in R} ||\hat{C}_k(r) - C_k(r)||^2_2 $$
        where $R$ is the set of rays corresponding to the pixels in $C_k$ [S1].
    d.  **Rendering:** Compute $\hat{C}_k(r)$ using volume rendering for each ray $r$:
        $$ \hat{C}(r) = \sum_{i=0}^{N-1} T_i (1 - \exp(-\sigma_i \delta_i)) c_i $$
        $$ T_i = \exp\left(-\sum_{j=0}^{i-1} \sigma_j \delta_j\right) $$
        where $N$ is the number of sample points along the ray, $\delta_i$ is the interval between points, and $(\sigma_i, c_i)$ are the density and color queried from $F_k$ at the deformed or time-conditioned coordinate [S1].

**Pseudocode:**
```python
def on_the_fly_training(images_sequence, initial_params):
    """
    images_sequence: List of image batches [C_0, C_1, ..., C_K]
    initial_params: Initial weights for F_0 and G_0
    """
    # Initialize radiance field F and occupancy grid G
    F = NeuralRadianceField(initial_params)
    G = OccupancyGrid(initial_params)
    
    # Train for the first frame
    F, G = optimize_step(F, G, images_sequence[0], time_step=0)
    
    # Iterate through subsequent frames
    for k in range(1, len(images_sequence)):
        # Apply Markov assumption: condition only on current image and previous field
        # F_k depends on C_k and F_{k-1}
        current_images = images_sequence[k]
        
        # Update occupancy grid for efficient sampling
        G = update_occupancy_grid(G, F, k)
        
        # Optimize radiance field for current time step
        F, G = optimize_step(F, G, current_images, time_step=k)
        
        # F is now ready to render novel views for time t_k
        yield F, k

def optimize_step(F, G, images, time_step):
    """
    Minimizes rendering loss for the current time step.
    """
    # Sample rays from images
    rays = sample_rays(images)
    
    # Render images using current F and G
    rendered_images = render_volume(F, G, rays, time_step)
    
    # Compute loss
    loss = compute_mse_loss(rendered_images, images)
    
    # Gradient descent step
    F = F.update_gradients(loss)
    
    return F, G

def render_volume(F, G, rays, time_step):
    """
    Standard volume rendering with time-conditioned queries.
    """
    rendered = []
    for ray in rays:
        # Sample points along ray using G
        points = sample_points(ray, G)
        
        # Query density and color from F at (point, direction, time_step)
        densities = []
        colors = []
        for p in points:
            sigma, c = F(p, ray.direction, time_step)
            densities.append(sigma)
            colors.append(c)
            
        # Aggregate using volume rendering formula
        alpha = 1.0 - exp(-densities * ray.delta)
        transmittance = exp(-cumsum(densities * ray.delta))
        color = sum(transmittance * alpha * colors)
        rendered.append(color)
    return rendered
```

**Edge Cases and Pitfalls:**
*   **Scalability:** Estimating $F_k$ conditioned on all previous images $C_{0:k}$ is not scalable as $t_k$ increases. The Markov assumption is critical to prevent complexity growth [S1].
*   **Camera Setup:** The method is limited to multi-view forward-facing cameras. Monocular setups require camera movement which is cumbersome for prolonged streaming, and 360-degree setups require dozens of cameras [S1].
*   **Initialization:** The quality of $F_k$ depends heavily on the transition from $F_{k-1}$. Poor initialization or large deformations between frames may require more optimization iterations [S1].

## Subtopics

### Deformation Field Modeling
Uses a neural network to warp dynamic coordinates to a canonical space. This is a common technique in dynamic NeRFs like D-NeRF, which OD-NeRF builds upon [S1, 8660-d-nerf.md].

### D-NeRF
A foundational method for dynamic NeRFs using space-time 4D representations. OD-NeRF differs by training on-the-fly rather than offline [S1, 8660-d-nerf.md].

### DaReNeRF
Focuses on deformable radiance fields. OD-NeRF shares the goal of dynamic reconstruction but differs in the training paradigm [S1, 13782-darenerf.md].

### Blur and Transient Modeling
Handles motion blur and transient objects. OD-NeRF focuses on the training speed and streaming aspect, potentially requiring integration with these techniques for robustness [S1, 13851-blur-and-transient-modeling.md].

### Projected Color-Guided Dynamic NeRF
Uses projected color to guide dynamic NeRF training. OD-NeRF uses a Markov-based optimization approach [S1, 7523-projected-color-guided-dynamic-nerf.md].

## Operating characteristics
*   **Time Complexity:** The method aims for interactive speed by minimizing optimization iterations per frame. The complexity per step is reduced by the Markov assumption, avoiding the accumulation of all previous data [S1].
*   **Memory Complexity:** Memory usage is bounded by the current radiance field $F_k$ and occupancy grid $G_k$, plus the current image batch. It does not store the full history of radiance fields or images, unlike offline methods [S1].
*   **Performance:** Enables streaming of dynamic scenes in real-time or near real-time, suitable for social media, VR/AR, and gaming [S1].
*   **Strengths:** Real-time streaming capability; minimal optimization per frame; scalable to long sequences due to Markov assumption.
*   **Limitations:** Limited to multi-view forward-facing cameras; requires careful initialization and transition between frames; may suffer from error accumulation if the Markov assumption is violated significantly [S1].
*   **When to Use:** When real-time or near real-time streaming of a dynamic scene is required, and the scene can be captured with multi-view forward-facing cameras.
*   **When Not to Use:** When offline reconstruction with higher quality is acceptable, or when the scene involves complex camera movements (monocular) or requires 360-degree coverage with many cameras [S1].

## Background
On-the-fly dynamic NeRF training was introduced in the paper "OD-NeRF: Efficient Training of On-the-Fly Dynamic Neural Radiance Fields" [S1]. The work addresses the limitation of existing dynamic NeRFs that focus on reconstructing scenes given full training videos, which cannot stream the event while it is happening [S1]. The method formulates the training process as estimating hidden states in a Hidden Markov Model (HMM), where the radiance fields are hidden states and the images are observations [S1]. This approach leverages recent successes in NeRF acceleration to achieve interactive speeds [S1].
