# Dynamic and Temporal Modeling

Also called: Dynamic Scene Reconstruction, 4D Modeling, Time-Dependent Radiance Fields

## Overview
Dynamic and Temporal Modeling extends static 3D reconstruction to 4D spatiotemporal volumes $D(x, y, z, t)$, enabling the synthesis of novel views at arbitrary time instants from multi-view image sequences captured over time [S1, S3]. It distinguishes itself from static reconstruction methods by explicitly modeling non-static elements—such as non-rigid motion, emerging/vanishing content, or optical blurs—as dynamic components, rather than treating them as noise or artifacts [S1, S3]. Unlike sibling methods in the 3D Gaussian Splatting Training family that focus on optimization efficiency or static geometry, this family addresses the fundamental challenge of representing and optimizing time-varying geometry and appearance, ranging from neural deformation fields to explicit temporal parameterizations of Gaussian attributes [S1, S2, S3].

## Shared principles
All methods in this family address the problem of representing a 4D spatiotemporal volume $D(x, y, z, t)$ using a set of input images captured at different times $t$. The core mechanism involves decomposing the scene into static and dynamic components or modeling the temporal evolution of attributes directly.

1.  **Temporal Parameterization:** Attributes that vary with time (position $\mathbf{c}$, rotation $\mathbf{q}$, opacity $\alpha$, density $\sigma$) are expressed as functions of time $t$. Common functional forms include:
    *   **Polynomial/Linear:** $\mathbf{q}(t) = \mathbf{q}_0 + \mathbf{m}t$ [S2].
    *   **Fourier Series:** $\mathbf{c}(t) = \mathbf{c}_0 + \sum_{k=0}^{K} (\mathbf{a}_k \cos(k \omega t) + \mathbf{b}_k \sin(k \omega t))$ [S2].
    *   **Neural Deformation:** A neural network $\Psi_t(x, t)$ predicts displacement $\Delta x$ to warp points to a canonical space [S1, S3].
    *   **Implicit Fields:** Time-dependent NeRFs map $(x, d, t)$ to density and color, often using local neighborhoods of frames [S4].

2.  **Canonical Space Mapping:** Many methods (e.g., D-NeRF, Nerfies) introduce a canonical configuration (usually at $t=0$) where the scene is static. A deformation network maps dynamic coordinates $x$ at time $t$ to canonical coordinates $x'$:
    $$ x' = x + \Psi_t(x, t) $$
    The radiance field is then queried in the canonical space: $[\sigma, c] = \Psi_x(x', d)$ [S1, S3].

3.  **Rendering with Dynamics:** The rendering process integrates the time-dependent attributes. For Gaussians, the position and rotation are computed for the specific time $t$ of the camera ray before rasterization [S2]. For NeRFs, the density $\sigma$ and color $c$ are queried at the deformed or time-conditioned point [S1, S4].

4.  **Loss Functions:** Optimization typically minimizes photometric loss (L1 or LPIPS) between rendered and ground truth images [S1, S2]. Additional constraints often include:
    *   **Temporal Smoothness:** Penalizing abrupt changes in attributes between adjacent frames [S1].
    *   **Rigid/Flow Constraints:** Using optical flow or KNN rigid loss to guide deformation [S1].
    *   **Regularization:** Elastic or background regularization to prevent overfitting in deformation fields [S5].

## Subtopics

### [Projected Color-Guided Dynamic NeRF](7523-projected-color-guided-dynamic-nerf.md)
Projected Color-Guided Dynamic NeRF (OD-NeRF) is an on-the-fly training method for dynamic scenes that replaces temporal deformation fields with a NeRF model conditioned on multi-view projected colors. Unlike sibling methods that rely on explicit temporal parameterization or deformation networks which extrapolate poorly to unseen times, OD-NeRF leverages the relative invariance of projected colors to implicitly track point correspondence between consecutive frames, enabling rapid convergence with minimal optimization iterations per frame.

### [On-the-Fly Dynamic NeRF Training](7582-on-the-fly-dynamic-nerf-training.md)
On-the-fly Dynamic NeRF Training (OD-NeRF) is a method for training a dynamic Neural Radiance Field concurrently with the acquisition of training frames, enabling the streaming of a dynamic scene while it unfolds. Unlike standard dynamic NeRFs that require full video sequences for offline 4D reconstruction, this approach estimates the radiance field for the current time step $t_k$ using only the images up to $C_{0:k}$ and the radiance field from the previous step $F_{0:k-1}$. It is distinguished by its use of a first-order Markov assumption to limit computational complexity, allowing for frame-by-frame optimization with minimal iterations.

### [D-NeRF](8660-d-nerf.md)
D-NeRF synthesizes novel views at arbitrary time instants for dynamic scenes with complex non-rigid geometries, optimizing a deformable volumetric function from a sparse set of monocular input images without requiring ground-truth geometry or multi-view stereo data. It distinguishes itself from naive time-extended NeRFs by decomposing the representation into a canonical static radiance field and a learned deformation field, effectively exploiting temporal redundancy to handle rigid, articulated, and non-rigid motions.

### [DaReNeRF](13782-darenerf.md)
DaReNeRF is a differentiable volume rendering method for novel view synthesis of dynamic scenes that replaces standard plane-based decompositions with a direction-aware representation based on the Dual-Tree Complex Wavelet Transform (DTCWT). It solves the shift variance and poor direction selectivity inherent in Discrete Wavelet Transform (DWT) approaches, which cause ghosting artifacts and instability in dynamic regions with motion. Unlike sibling methods that rely on neural deformation fields to warp coordinates to a canonical space, DaReNeRF directly models the 4D spatiotemporal volume using learned complex wavelet coefficients, offering a more robust frequency-domain representation of motion.

### [Blur and Transient Modeling](13851-blur-and-transient-modeling.md)
This family addresses the degradation of reconstruction quality in dynamic scenes and real-world captures caused by temporal inconsistencies (transients) and optical blurs (motion/defocus). It distinguishes itself from static reconstruction methods by explicitly modeling non-static elements as separate entities or incorporating blur kernels into the rendering pipeline, rather than treating them as noise or artifacts.

### [Deformation Field Modeling](13852-deformation-field-modeling.md)
Deformation Field Modeling represents a 4D spatiotemporal volume $D(x, y, z, t)$ by mapping dynamic coordinates to a static canonical space via a learned displacement field, enabling the reconstruction of non-rigidly moving scenes from multi-view image sequences. It distinguishes itself from explicit parametric methods (like Fourier-based Gaussian splatting) by using a neural network to predict continuous displacement vectors, allowing for complex, non-periodic deformations without assuming specific motion priors.

### Temporal 3D Gaussian Splatting
- [S1] A method that introduces a temporal radial basis function to represent temporal opacity, modeling emerging or vanishing content. Polynomial functions model motion and rotation.
- [S1] Spherical harmonics are replaced with features consisting of base color, view-related feature, and time-related feature. The latter two are translated into residual color through an MLP added to the base color.
- [S1] During optimization, new 3D Gaussians are sampled at under-optimized positions based on training error and coarse depth.

### SWAGS
- [S1] A method that divides the dynamic sequence into different windows based on motion amount, training separate dynamic 3DGS models in different windows with different canonical spaces and deformation fields.
- [S1] The deformation field uses a tunable MLP that focuses more on modeling the dynamic part of the scene.
- [S1] Fine-tuning ensures temporal consistency between windows using overlapping frames to add constraints. The MLP is fixed and only the canonical representation is optimized during fine-tuning.

### 3DGStream
- [S1] A method that allows online training of 3DGS into dynamic scene reconstruction by modeling the transformation between frames as a neural transformation cache and adaptively adding 3D Gaussians to handle emerging objects.

### Multi-scale Motion-Compensated Reconstruction
- [S2] A procedure coupled with the two-step DynART/P-DVC algorithm to handle large displacement amplitudes by resolving large-scale features first and progressively enriching with finer details.
- [S2] Resolve large-scale features of both microstructure and motion.

### Time-dependent NeRF
- [S3] A NeRF variant that represents scene geometry and appearance at each specific time step t, trained using neighboring frames around time t, to capture local scene geometry and motion.
- [S3] Represent scene appearance using mapping function c = ϕc(x, d) taking point x ∈ R3 and viewing direction d ∈ R2 to predict color c ∈ R3.
- [S3] Represent scene geometry via mapping function s = ϕg(x) which maps a 3D point x to a signed distance value s ∈ R.
- [S3] For a camera ray r(h) = o + hd, sample K 3D points {xi(r) = r(hi) | i = 1, ..., K, hi < hi+1}.
- [S3] Use the time-dependent NeRF to compute SDF flows, which are used to constrain the learning of continuous camera motion via the linear relationship between SDF flow and scene flow.
- [S3] Convert signed distance si to density σi using: σi = max((Φ(si) - Φ(si+1))/Φ(si), 0), where Φ(s) = 1/(1+e^(1-γs)), γ is a learnable parameter, and i is the point index.
- [S3] Render pixel color Ĉ(r) via volume rendering: Ĉ(r) = Σ(i=1 to K) Li σi ci, where Li = Π(j=1 to i-1) (1 - σj) is the accumulated transmittance.

## Background
Dynamic scene reconstruction has evolved from explicit parametric models to implicit neural representations. D-NeRF [S1, S2] was a pioneering work that decomposed dynamic scenes into a canonical static field and a learned deformation field, enabling the handling of complex non-rigid motions from sparse monocular inputs. Subsequent works like OD-NeRF [S1] introduced on-the-fly training strategies using Markov assumptions to enable streaming reconstruction. More recently, methods like DaReNeRF [S1] have explored frequency-domain representations using wavelet transforms to address artifacts in dynamic regions. In the context of 3D Gaussian Splatting, dynamic modeling has been adapted through temporal parameterizations of Gaussian attributes (e.g., Temporal 3D Gaussian Splatting [S1]), window-based deformation (SWAGS [S1]), and online streaming (3DGStream [S1]). These methods are applied in various domains, including medical imaging [S1] and general novel view synthesis [S1, S3].
