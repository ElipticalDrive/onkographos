# Projected Color-Guided Dynamic NeRF
Also called: OD-NeRF

## Overview
Projected Color-Guided Dynamic NeRF (OD-NeRF) is an on-the-fly training method for dynamic scenes that conditions the radiance field on multi-view projected color statistics rather than explicit temporal coordinates [S1]. It solves the problem of slow convergence and poor temporal extrapolation in existing dynamic NeRFs by leveraging the relative invariance of projected colors for corresponding 3D points across consecutive frames, thereby implicitly tracking point correspondence without deformation fields [S1]. Unlike siblings that rely on temporal input dimensions or deformation fields which extrapolate poorly to unseen time and require many optimization iterations, this method requires the minimum number of optimization iterations for each new frame [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A sequence of multi-view images representing dynamic scenes. For synthetic datasets, the method builds upon the TiNeuVox architecture; for real-world datasets, it builds upon InstantNGP (via NerfAcc) [S1].
*   **Outputs:** A radiance field model capable of rendering novel views at arbitrary timestamps with interactive speed (6 FPS on synthetic scenes) [S1].

**Data Structures:**
1.  **Occupancy Grid:** A sparse grid tracking scene occupancy to guide efficient sampling. It is updated from the previous frame's grid using a transition and update algorithm [S1].
2.  **Hash Voxel Grid:** Replaces the multi-scale voxel grid used in the base TiNeuVox model. Implemented using `tiny-cuda-nn` [S1].
3.  **NeRF MLP:** A Multi-Layer Perceptron that predicts density and color. Its input is modified to include projected color statistics [S1].

**Numbered Steps:**

1.  **Initialization:**
    *   For synthetic datasets, remove the temporal deformation model and temporal information enhancement from the base TiNeuVox model [S1].
    *   Replace the multi-scale voxel grid with a hash voxel grid [S1].
    *   Apply a 2-second warm-up duration for the first frame to compensate for the slower convergence of hashed voxels compared to multi-scale voxels [S1].
    *   For real-world datasets, use the NerfAcc implementation of InstantNGP [S1].

2.  **Projected Color Computation:**
    *   For each sampled 3D point $\mathbf{x}$ along a ray, compute its projected color from all available training views.
    *   Calculate the mean $\mu_c$ and variance $\sigma_c^2$ of these projected colors [S1].

3.  **Feature Concatenation:**
    *   Query the spatial feature $\mathbf{f}_{spatial}$ from the voxel grid (hash grid for real-world, or the modified grid for synthetic) at $\mathbf{x}$ [S1].
    *   Concatenate the projected color statistics with the spatial feature: $\mathbf{f}_{input} = [\mathbf{f}_{spatial}, \mu_c, \sigma_c^2]$ [S1].

4.  **Radiance Field Prediction:**
    *   Input $\mathbf{f}_{input}$ into the NeRF MLP to predict density $\sigma$ and color $\mathbf{c}$ [S1].

5.  **Efficient Sampling (Occupancy Grid Transition):**
    *   Use the occupancy grid from the previous frame to guide sampling for the current frame.
    *   Implement rejection sampling based on the transited and updated occupancy grid. A sample $\mathbf{x}_i$ at index $i$ along the ray is rejected if:
        $$ \text{reject } \mathbf{x}_i \text{ if } (\sigma_{occ}(\mathbf{x}_i) < \sigma_{min}) \land \neg(i \mod R \equiv R // 2) $$
        where $\sigma_{occ}$ is the occupancy value, $\sigma_{min}$ is a density threshold, and $R$ is a fixed interval [S1].

6.  **Regularization (Real-world Datasets Only):**
    *   For real-world datasets, apply depth smoothness regularization to handle large planar backgrounds with constant colors.
    *   For any $3 \times 3$ patch of rays, calculate the loss:
        $$ L_{depth} = \frac{\text{std}(d_{far} / d_{3 \times 3})}{\text{std}(c_{3 \times 3})} $$
        where $d_{far}$ is the depth of the farthest sample, $d_{3 \times 3}$ is the mean depth of the patch, and $c_{3 \times 3}$ is the mean color of the patch [S1].

7.  **Optimization:**
    *   Optimize the model parameters frame-by-frame.
    *   Decay the optimization learning rate or related parameter from 1 (at frame 1) to 0.05 (at frame 10) to ensure better convergence at the start [S1].

**Pseudocode:**

```python
def train_od_nerf_frame(frame_index, images, rays, prev_occupancy_grid):
    """
    Train one frame of OD-NeRF.
    Args:
        frame_index: Current frame number.
        images: List of multi-view images for the current frame.
        rays: List of rays to render for the current frame.
        prev_occupancy_grid: Occupancy grid from the previous frame.
    Returns:
        updated_occupancy_grid, model_state
    """
    # Step 1: Update Occupancy Grid
    # Transition and update the occupancy grid from the previous frame.
    # Implementation detail: The specific transition algorithm is described in [S1]
    # but not fully detailed in the provided notes. We assume a function exists.
    current_occupancy_grid = transition_occupancy_grid(prev_occupancy_grid, images)

    # Step 2: Sample Points with Rejection
    sampled_points = []
    for ray in rays:
        # Generate uniform samples along the ray
        uniform_samples = generate_uniform_samples(ray, num_samples=256)
        for i, point in enumerate(uniform_samples):
            # Get occupancy value at point
            occ_val = query_occupancy(current_occupancy_grid, point)
            
            # Apply rejection sampling rule
            # reject if (sigma_occ < sigma_min) AND NOT (i mod R == R // 2)
            if occ_val < sigma_min and not (i % R == R // 2):
                continue
            
            sampled_points.append((point, i))

    # Step 3: Compute Projected Color Statistics
    # For each sampled point, compute mean and variance of projected colors
    # from all training views.
    features = []
    for point, idx in sampled_points:
        # Query spatial feature from hash voxel grid
        spatial_feat = query_hash_grid(point)
        
        # Compute projected colors from all views
        projected_colors = []
        for view_image in images:
            # Project point to view and sample color
            color = project_and_sample_color(point, view_image)
            projected_colors.append(color)
        
        # Calculate mean and variance
        mu_c = mean(projected_colors)
        sigma_c_sq = variance(projected_colors)
        
        # Concatenate features
        input_feat = concatenate([spatial_feat, mu_c, sigma_c_sq])
        features.append((input_feat, point))

    # Step 4: Forward Pass through MLP
    # Predict density and color
    predictions = []
    for input_feat, point in features:
        sigma, color = mlp_forward(input_feat)
        predictions.append((sigma, color, point))

    # Step 5: Compute Loss
    # Render image and compare with ground truth
    rendered_image = volume_render(predictions, rays)
    gt_image = get_ground_truth_image(frame_index)
    
    loss = compute_loss(rendered_image, gt_image)
    
    # Add depth regularization for real-world datasets
    if is_real_world_dataset:
        depth_loss = compute_depth_regularization(sampled_points, rays)
        loss += depth_loss_weight * depth_loss

    # Step 6: Backpropagate and Update
    # Decay learning rate from 1.0 to 0.05 over first 10 frames
    lr = max(0.05, 1.0 - (frame_index - 1) * 0.95 / 9.0) if frame_index <= 10 else 0.05
    optimizer.step(loss, lr)

    return current_occupancy_grid, model_state
```

**Parameters:**
*   **Warm-up Duration:** 2 seconds for the first frame in synthetic datasets [S1].
*   **Learning Rate Decay:** From 1 (frame 1) to 0.05 (frame 10) [S1].
*   **Rejection Sampling Interval ($R$):** Not given in the sources.
*   **Density Threshold ($\sigma_{min}$):** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Specular Surfaces:** Specular surfaces violate the relative invariance of projected color, causing artifacts [S1].
*   **Occluded Points:** Occluded points also violate the invariance, leading to artifacts [S1].
*   **Convergence on Real-World Data:** The NerfAcc implementation of InstantNGP may not converge well on forward-facing dynamic datasets (e.g., MeetRoom, DyNeRF) due to large planar backgrounds with constant colors, necessitating the depth smoothness regularization [S1].

## Operating characteristics
*   **Time Complexity:** The method achieves an interactive speed of 6 FPS for training and rendering on synthetic dynamic scenes on-the-fly [S1]. It requires the minimum number of optimization iterations for each new frame compared to models with temporal input dimensions or deformation fields [S1].
*   **Memory Complexity:** Uses a hash voxel grid (via `tiny-cuda-nn`) which is more memory-efficient than dense voxel grids, though specific memory usage figures are not provided [S1].
*   **Strengths:** Excellent temporal extrapolation capability; significantly faster on-the-fly training compared to state-of-the-art methods on real-world dynamic scenes; maintains comparable rendering quality [S1].
*   **Limitations:** Performance degrades on specular surfaces and occluded points due to the reliance on projected color invariance [S1].
*   **When to Use:** When efficient on-the-fly training of dynamic scenes is required, especially for synthetic data where the 2-second warm-up is acceptable, or real-world data where the depth regularization can mitigate planar background issues.
*   **When Not to Use:** For scenes with significant specularities or heavy occlusion where projected color invariance is frequently violated, unless additional filtering or occlusion detection is implemented (which incurs significant computational cost) [S1].

## Background
*   **Origin:** Proposed in "OD-NeRF: Efficient Training of On-the-Fly Dynamic Neural Radiance Fields" [S1].
*   **History:** The method addresses the limitations of existing dynamic NeRFs that focus on reconstructing scenes from full training videos and struggle with on-the-fly training. It builds on the observation that projected colors of corresponding 3D points remain relatively invariant across frames, allowing for implicit correspondence tracking without explicit temporal modeling [S1].
*   **Usage:** Implemented on top of TiNeuVox for synthetic datasets and InstantNGP (via NerfAcc) for real-world datasets [S1].
