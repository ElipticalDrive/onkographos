# SWAG
Also called: SWAG: Unsupervised Transient Gaussian Splatting, Unsupervised Transient Gaussians
## Overview
SWAG is a method for unsupervised transient modeling in 3D Gaussian Splatting (3DGS) that recovers static scene geometry and appearance by explicitly identifying and ignoring transient occluders [S1][S2, unofficial]. It sets itself apart from siblings like NeTF by conditioning Gaussians on learned appearance embeddings and training dedicated transient Gaussians to filter out dynamic elements, rather than modeling transients as a separate neural field [S1][S2, unofficial].
## How it works
Inputs: A set of multi-view images of a scene containing transient objects.
Outputs: A set of 3D Gaussians representing the static scene, and a set of transient Gaussians representing occluders.

Data Structures:
- Static Gaussians: Standard 3DGS parameters (position $\mathbf{p}$, covariance $\mathbf{\Sigma}$, opacity $\alpha$, spherical harmonics coefficients $\mathbf{c}$).
- Transient Gaussians: A separate set of Gaussians with similar parameters, trained to capture transient content.
- Appearance Embeddings: Learned per-Gaussian or per-view feature vectors used to condition appearance.

Steps:
1. Initialize a set of 3D Gaussians from the input images using standard 3DGS initialization [S1][S2, unofficial].
2. Learn appearance embeddings for the Gaussians. These embeddings allow the model to distinguish between static and transient appearances based on consistency across views [S1][S2, unofficial].
3. Train the static Gaussians and transient Gaussians jointly. The transient Gaussians are optimized to capture pixels that do not belong to the static scene geometry [S1][S2, unofficial].
4. During rendering, the transient Gaussians are used to identify occluders. The static scene is reconstructed by ignoring the contributions of the transient Gaussians [S1][S2, unofficial].

Parameters:
- Learning rate for Gaussians: Not given in the sources.
- Learning rate for embeddings: Not given in the sources.
- Number of transient Gaussians: Not given in the sources.

Edge cases and pitfalls:

Pseudocode:
```python
# Initialize static and transient Gaussians
static_gaussians = initialize_3dgs(images)
transient_gaussians = initialize_transient_gaussians(images)

# Learn appearance embeddings
embeddings = learn_embeddings(static_gaussians, images)

# Joint optimization
for step in range(num_steps):
    # Render static and transient contributions
    static_render = render(static_gaussians, embeddings)
    transient_render = render(transient_gaussians, embeddings)
    
    # Compute loss
    loss = compute_loss(static_render, transient_render, images)
    
    # Update Gaussians and embeddings
    update(static_gaussians, transient_gaussians, embeddings, loss)
```

Time and memory complexity: Not given in the sources.
Measured performance: Yields state-of-the-art results on diverse photo scenes [S1][S2, unofficial].
Scaling: Not given in the sources.

## Background
Origin: SWAG was introduced in the paper "From Volume Rendering to 3D Gaussian Splatting: Theory and Applications" [S1][S2, unofficial].
History and development: It extends 3DGS by conditioning Gaussians on learned appearance embeddings and training unsupervised transient Gaussians [S1][S2, unofficial].
Where it is used: Used for static scene reconstruction in the presence of transient occluders [S1][S2, unofficial].
