# Projected Color-Guided Dynamic NeRF

Also called: OD-NeRF

## Overview
Projected Color-Guided Dynamic NeRF (OD-NeRF) is an on-the-fly training method for dynamic scenes that replaces temporal deformation fields with a NeRF model conditioned on multi-view projected colors [S1]. Unlike sibling methods that rely on explicit temporal parameterization or deformation networks which extrapolate poorly to unseen times, OD-NeRF leverages the relative invariance of projected colors to implicitly track point correspondence between consecutive frames, enabling rapid convergence with minimal optimization iterations per frame [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A sequence of multi-view images captured at different times. For each new frame, the model receives the current view images and the radiance field representation (voxel grid and MLP) estimated from previous frames.
*   **Outputs:** A rendered image for the current frame and an updated radiance field representation for the next frame.

**Data Structures:**
The method uses a hash voxel grid (from InstantNGP) implemented via `tiny-cuda-nn` [S1].
*   **Hash Voxel Grid:** Stores spatial features. The specific bit-packing or hash function details are not provided in the sources, but it replaces the multi-scale voxel grid used in the base TiNeuVox model [S1].
*   **Occupancy Grid:** Used for efficient sampling. It stores occupancy values $\sigma_{occ}$ for spatial locations [S1].

**Algorithm Steps:**
The method operates on a frame-by-frame basis. For each new frame $t$:

1.  **Transition and Update:** Use the occupancy grid from the previous frame to guide sampling for the current frame. The occupancy grid is updated to reflect the scene state at time $t$ [S1].
2.  **Ray Sampling:** Sample points along rays. The method employs rejection sampling based on the occupancy grid to filter uniform samples [S1].
    *   Let $x_i$ be the $i$-th sample point along a ray.
    *   Let $\sigma_{occ}(x_i)$ be the occupancy value at $x_i$ from the occupancy grid.
    *   Let $\sigma_{min}$ be a density threshold.
    *   Let $R$ be a fixed interval.
    *   Reject $x_i$ if:
        $$ \sigma_{occ}(x_i) < \sigma_{min} \quad \text{AND} \quad \neg(i \mod R \equiv R // 2) $$
        [S1]
3.  **Feature Extraction:** For each accepted sample point $x$:
    *   Query the spatial feature $f_{spatial}$ from the hash voxel grid at $x$ [S1].
    *   Compute the projected color statistics (mean $\mu_c$ and variance $\sigma_c^2$) of the sample point $x$ from the multi-view training images. This involves projecting $x$ into the training views and collecting the color values [S1].
4.  **NeRF Forward Pass:** Concatenate the projected color statistics with the spatial feature:
    $$ \text{input} = [f_{spatial}, \mu_c, \sigma_c^2] $$
    Pass this concatenated vector into the NeRF Multi-Layer Perceptron (MLP) to predict density $\sigma$ and color $c$ [S1].
5.  **Rendering:** Render the image using standard volume rendering integration with the predicted $\sigma$ and $c$ [S1].
6.  **Optimization:** Update the hash voxel grid and MLP parameters by minimizing the photometric loss between the rendered image and the ground truth image for the current frame [S1].
    *   For real-world datasets, add a depth smoothness regularization loss $L_{depth}$ calculated over $3 \times 3$ patches of rays:
        $$ L_{depth} = \frac{\text{std}(d_{far} / d_{3 \times 3})}{\text{std}(c_{3 \times 3})} $$
        where $d_{far}$ is the depth of the farthest sample, $d_{3 \times 3}$ is the mean depth of the $3 \times 3$ patch, and $c_{3 \times 3}$ is the mean color of the $3 \times 3$ patch [S1].
7.  **Warm-up (Synthetic Datasets Only):** For the first frame of synthetic datasets, apply a 2-second warm-up duration to compensate for the slower convergence of hashed voxels compared to multi-scale voxels [S1].

**Pseudocode:**
```python
# OD-NeRF On-the-Fly Training Step
# Assumes: prev_occupancy_grid, hash_voxel_grid, nerf_mlp are maintained state
# Assumes: current_view_images, camera_params are inputs for frame t
# Assumes: prev_view_images, prev_camera_params are inputs from frame t-1

def od_nerf_step(prev_occupancy_grid, hash_voxel_grid, nerf_mlp, 
                 current_view_images, camera_params, 
                 prev_view_images, prev_camera_params):
    
    # 1. Transition and Update Occupancy Grid
    # The occupancy grid is updated based on the previous frame's data
    # and the current frame's observations.
    current_occupancy_grid = transition_occupancy_grid(
        prev_occupancy_grid, current_view_images, camera_params
    )
    
    # 2. Initialize Optimization
    # For synthetic datasets, apply warm-up for the first frame
    if is_first_frame and dataset_type == "synthetic":
        apply_warmup(duration_seconds=2.0)
        
    # 3. Render and Optimize
    # Perform optimization steps for the current frame
    for optimization_step in range(num_optimization_steps):
        rendered_image = render_frame(
            hash_voxel_grid, nerf_mlp, current_occupancy_grid, 
            current_view_images, camera_params, prev_view_images, prev_camera_params
        )
        
        # Calculate Loss
        photometric_loss = calculate_photometric_loss(rendered_image, current_view_images)
        
        # Add depth smoothness regularization for real-world datasets
        if dataset_type == "real_world":
            depth_loss = calculate_depth_smoothness_loss(rendered_image, current_view_images)
            total_loss = photometric_loss + depth_loss
        else:
            total_loss = photometric_loss
            
        # Update Model Parameters
        update_parameters(hash_voxel_grid, nerf_mlp, total_loss)
        
    # 4. Return Updated State
    return rendered_image, current_occupancy_grid, hash_voxel_grid, nerf_mlp

def render_frame(hash_voxel_grid, nerf_mlp, occupancy_grid, 
                 current_view_images, camera_params, 
                 prev_view_images, prev_camera_params):
    
    rendered_image = zeros_like(current_view_images)
    
    for each pixel in current_view_images:
        ray = generate_ray(camera_params, pixel)
        samples = sample_along_ray(ray, occupancy_grid)
        
        # Rejection Sampling
        valid_samples = []
        for i, sample_point in enumerate(samples):
            sigma_occ = query_occupancy(occupancy_grid, sample_point)
            if not (sigma_occ < sigma_min and not (i % R == R // 2)):
                valid_samples.append(sample_point)
        
        # Feature Extraction and NeRF Forward Pass
        densities = []
        colors = []
        for sample_point in valid_samples:
            # Query spatial feature from hash voxel grid
            f_spatial = query_hash_voxel(hash_voxel_grid, sample_point)
            
            # Compute projected color statistics from multi-view images
            # Project sample_point into prev_view_images and current_view_images
            projected_colors = get_projected_colors(sample_point, prev_view_images, prev_camera_params, 
                                                  current_view_images, camera_params)
            mu_c = mean(projected_colors)
            sigma_c_sq = variance(projected_colors)
            
            # Concatenate features
            input_feature = concatenate([f_spatial, mu_c, sigma_c_sq])
            
            # Predict density and color
            sigma, color = nerf_mlp(input_feature)
            
            densities.append(sigma)
            colors.append(color)
            
        # Volume Rendering
        alpha = 1.0 - exp(-densities * ray_step_size)
        weight = alpha * cumprod(1.0 - alpha[:-1])
        rendered_color = sum(weight * colors)
        
        rendered_image[pixel] = rendered_color
        
    return rendered_image

def get_projected_colors(sample_point, view_images, camera_params_list):
    colors = []
    for view_img, cam_params in zip(view_images, camera_params_list):
        # Project 3D point to 2D image coordinates
        u, v = project_3d_to_2d(sample_point, cam_params)
        # Check if projection is within image bounds
        if is_within_bounds(u, v, view_img.shape):
            color = view_img[v, u]
            colors.append(color)
    return colors
```

**Parameters:**
*   $\sigma_{min}$: Density threshold for rejection sampling. Value not given in the sources.
*   $R$: Fixed interval for rejection sampling. Value not given in the sources.
*   Warm-up duration: 2 seconds for the first frame in synthetic datasets [S1].
*   Optimization iterations: The method requires the minimum number of optimization iterations for each new frame compared to temporal deformation models [S1].

**Edge Cases and Pitfalls:**
*   **Specular Surfaces:** Specular surfaces violate the relative invariance of projected color, causing artifacts [S1].
*   **Occluded Points:** Occluded points violate the relative invariance of projected color, causing artifacts [S1].
*   **Convergence on Real-World Data:** The NerfAcc implementation of InstantNGP may not converge well on forward-facing dynamic datasets with large planar backgrounds (e.g., walls, tables) due to constant colors. This is mitigated by the depth smoothness regularization [S1].

## Operating characteristics
*   **Time Complexity:** The method achieves an interactive speed of 6 FPS for training and rendering on synthetic dynamic scenes on-the-fly [S1]. It requires significantly fewer optimization iterations per frame compared to methods using temporal deformation fields [S1].
*   **Memory Complexity:** Uses a hash voxel grid (InstantNGP) which is generally more memory-efficient than multi-scale voxel grids for high-resolution details, but converges slower initially [S1].
*   **Strengths:** Excellent temporal extrapolation capability; requires minimal optimization iterations for each new frame; efficient on-the-fly training [S1].
*   **Limitations:** Performance degrades on specular surfaces and occluded points due to the assumption of projected color invariance [S1].
*   **When to Use:** Suitable for on-the-fly dynamic scene reconstruction where rapid frame-by-frame training is required, particularly for synthetic datasets or real-world datasets without significant specularities or occlusions.
*   **When Not to Use:** Not suitable for scenes with prominent specular reflections or heavy occlusions where projected color invariance is violated [S1].

## Background
OD-NeRF was introduced in the paper "OD-NeRF: Efficient Training of On-the-Fly Dynamic Neural Radiance Fields" [S1]. It addresses the challenge of efficient on-the-fly training where the radiance field is trained and rendered frame-by-frame. The method builds on the observation that projected colors of corresponding 3D points remain relatively invariant across consecutive frames, allowing the model to implicitly track correspondence without explicit temporal deformation [S1]. It is implemented on top of TiNeuVox for synthetic datasets and InstantNGP (via NerfAcc) for real-world datasets [S1].
