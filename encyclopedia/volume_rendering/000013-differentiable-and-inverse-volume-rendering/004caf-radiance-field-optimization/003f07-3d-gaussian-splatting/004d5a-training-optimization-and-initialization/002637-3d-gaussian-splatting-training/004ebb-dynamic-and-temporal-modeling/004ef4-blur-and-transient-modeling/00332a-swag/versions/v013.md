# SWAG

Also called: Unsupervised Transient Gaussian Splatting, Unsupervised Transient Gaussians

## Overview
SWAG extends 3D Gaussian Splatting (3DGS) to handle dynamic scenes with transient occluders by conditioning Gaussians on learned appearance embeddings and training unsupervised transient Gaussians to ignore occluders [S1][S2, unofficial]. It distinguishes itself from sibling methods like NeTF by maintaining a unified Gaussian representation rather than a neural field, yielding state-of-the-art results on diverse photo scenes without requiring explicit transient labels [S1][S2, unofficial].

## How it works
SWAG modifies the standard 3DGS pipeline to separate static geometry from transient artifacts.

**Inputs and Outputs:**
*   **Inputs:** A set of unposed or loosely posed images containing static scene content and transient occluders (e.g., people, vehicles).
*   **Outputs:** A set of 3D Gaussians representing the static scene, robust to transient distractors.

**Data Structures:**
The method maintains two distinct sets of Gaussians:
1.  **Static Gaussians:** Represent the persistent scene geometry. Each Gaussian $i$ is defined by standard 3DGS parameters: mean $\mu_i$, covariance $\Sigma_i$, opacity $\alpha_i$, and spherical harmonics coefficients for view-dependent color. Crucially, these Gaussians are conditioned on **learned appearance embeddings** $e_i$. These embeddings allow the static Gaussians to adapt their appearance based on viewing conditions or lighting, decoupling them from transient occlusion effects [S1][S2, unofficial].
2.  **Transient Gaussians:** A separate set of Gaussians optimized to model transient occluders. These use standard 3DGS parameters without appearance embeddings, focusing purely on capturing the moving or temporary objects [S1][S2, unofficial].

**Algorithm Steps:**
1.  **Initialization:** Initialize a set of static Gaussians and transient Gaussians from the input images (e.g., using standard 3DGS initialization). Assign a unique appearance embedding $e_i$ to each static Gaussian.
2.  **Rendering:** Render the scene by compositing contributions from both static and transient Gaussians. The color of a static Gaussian is determined by its base color and its appearance embedding $e_i$, allowing it to remain consistent even if partially occluded by transients in some views.
3.  **Loss Calculation:** Compute the photometric loss between the rendered image and the ground truth image.
4.  **Joint Optimization:** Optimize the parameters of both static and transient Gaussians, along with the appearance embeddings, using gradient descent. The optimization is structured to prevent static Gaussians from absorbing transient artifacts. This is achieved by allowing transient Gaussians to "compete" for pixel coverage, effectively ignoring occluders in the static representation [S1][S2, unofficial].
5.  **Regularization:** Apply depth regularization and visibility maps to constrain the geometry of the static Gaussians and mitigate transient effects, ensuring the static scene remains coherent [S1][S2, unofficial].

**Parameters:**
*   **Appearance Embedding Dimension:** Not given in the sources.
*   **Number of Transient Gaussians:** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Precision:** The separation between static and transient Gaussians relies on the optimization process. If the transient objects are persistent across many views, they may be incorrectly absorbed into the static representation [S1][S2, unofficial].
*   **Boundaries:** The method assumes that transient occluders are distinct from the static scene. If the scene contains long-term dynamic elements, the method may struggle to distinguish them from static geometry [S1][S2, unofficial].

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:** SWAG yields state-of-the-art results on diverse photo scenes [S1][S2, unofficial].
*   **Strengths:** Robust to transient occluders; does not require explicit transient labels; leverages the efficiency of 3DGS.
*   **Limitations:** Performance may degrade if transient objects are persistent or if the scene contains complex long-term dynamics.
*   **When to use:** When reconstructing static scenes from images containing transient occluders (e.g., crowds, vehicles) without ground truth transient masks.
*   **When not to use:** When the scene contains significant long-term dynamic elements that should be part of the reconstruction.

## Background
SWAG was introduced as an extension to 3D Gaussian Splatting to address the challenge of transient occluders in novel view synthesis. It builds on the principles of artifact decomposition and extended Gaussian attributes shared by the family of methods in Blur and Transient Modeling [S1][S2, unofficial]. The method was developed to provide a robust solution for casual captures where transient distractors are common [S1][S2, unofficial].
