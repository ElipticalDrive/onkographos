# Dynamic Object Embedding in Static Scenes

Also called: Lightweight Dynamic NeRF Modeling via Local Deformation Field, Local deformation field model

## Overview
This method integrates dynamic advertising objects into static NeRF scenes by ensuring perspective consistency through spatial alignment and joint rendering with alpha blending [S1]. It differs from traditional dynamic NeRF approaches (e.g., DyNeRF) that require independent models per time step and over 100M parameters, by using a static NeRF for static areas and a lightweight deformation field for dynamic regions, reducing parameters by 95% [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Sparse video frames of the static scene (exhibition stand + background), sparse video frames of the dynamic object (e.g., rotating watch), and four corresponding marking points (e.g., stand corners) in both domains for alignment.
*   **Outputs:** A static NeRF model $F_{static}$, a local deformation field $\Delta(x, t)$, and rendered frames $C(r)$ for dynamic scenes.

**Data Structures:**
1.  **Static NeRF ($F_{static}$):** A neural network mapping spatial coordinates $\mathbf{x}$ and viewing direction $\mathbf{d}$ to volume density $\sigma$ and color $\mathbf{c}$. No time dimension.
2.  **Deformation Field ($\Delta$):** A 3-layer MLP with hidden layer dimension 128. Total parameters: 5M [S1].
    *   Input: Spatial coordinate $\mathbf{x}$ and time $t$.
    *   Output: Displacement vector $\Delta(\mathbf{x}, t)$.

**Numbered Steps:**
1.  **Static Scene Reconstruction:** Generate a static NeRF model for the advertising scene using sparse input reconstruction. Parameters are fixed, and no time dimension calculation is required [S1].
2.  **Dynamic Object Modeling:** Collect 25-30 frames of video for the dynamic object. Train a local deformation field model to model motion displacement. The model uses a 3-layer MLP with 128 hidden units, resulting in 5M parameters [S1].
3.  **Spatial Alignment:** Select four marking points (e.g., exhibition stand corners) in both the static scene and the dynamic object. Use the RANSAC algorithm to align the coordinate system of the dynamic object with the static scene. This ensures perspective consistency with an alignment error of less than 1 pixel [S1].
4.  **Joint Rendering:** For a given time $t$ and ray $r$:
    *   Calculate the deformation position of the dynamic object using $\Delta(\mathbf{x}, t)$.
    *   Input the deformed coordinates $\mathbf{x} + \Delta(\mathbf{x}, t)$ into the static NeRF model to obtain color and density.
    *   Fuse the dynamic object with the static scene using alpha blending with a blending factor of 0.95 [S1].

**Formulas:**
The dynamic radiation field $F(\mathbf{x}, t)$ is expressed as [S1]:
$$ F(\mathbf{x}, t) = F_{static}(\mathbf{x} + \Delta(\mathbf{x}, t)) $$

The final rendered color $C(r)$ involves alpha blending [S1]:
$$ C_{final} = \alpha_{obj} C_{obj} + (1 - \alpha_{obj}) C_{static} $$
where $\alpha_{obj}$ is the blending factor (0.95) [S1].

**Parameters:**
*   Deformation Field Architecture: 3-layer MLP, hidden dimension 128 [S1].
*   Blending Factor: 0.95 [S1].
*   Alignment Error: <1 pixel [S1].
*   Temporal Consistency Loss: Ensures smooth dynamic transitions, target SSIM $\ge$ 0.92 [S1].

**Edge Cases and Pitfalls:**
*   **Sparse Input:** The method relies on sparse input reconstruction, which may affect quality if insufficient frames are provided [S1].
*   **Alignment:** Incorrect selection of marking points or failure of RANSAC to find a robust transformation can lead to perspective inconsistencies [S1].
*   **Dynamic Region Size:** The method is designed for dynamic regions comprising $\le$20% of the scene [S1]. Larger dynamic regions may require different approaches.

## Subtopics

### Neural Transient Field (NeTF)
Models light transport over time explicitly. Choose when dynamic effects involve complex lighting changes rather than just geometric deformation [4692-neural-transient-field-netf.md].

### Projected Color-Guided Dynamic NeRF
Uses color guidance for dynamic regions. Choose when color consistency is critical for dynamic objects [7523-projected-color-guided-dynamic-nerf.md].

### On-the-Fly Dynamic NeRF Training
Updates the radiance field incrementally. Choose for real-time streaming scenarios [7582-on-the-fly-dynamic-nerf-training.md].

### D-NeRF
Uses a canonical space with deformation fields but requires more parameters. Choose when higher accuracy is needed and computational resources are abundant [8660-d-nerf.md].

## Operating characteristics
*   **Time and Memory Complexity:** The deformation field has 5M parameters, which is 95% less than DyNeRF's 100M+ parameters [S1]. This makes it suitable for VR devices [S1].
*   **Measured Performance:** PSNR increased by 2.3±0.2 dB under sparse input (mean±std over 10 trials) [S1]. Temporal consistency loss ensures SSIM $\ge$ 0.92 [S1].
*   **Scaling:** The method is designed for dynamic regions comprising $\le$20% of the scene [S1].
*   **Strengths:** Lightweight (5M parameters), suitable for VR, perspective consistency via alignment [S1].
*   **Limitations:** Relies on sparse input, requires manual marking points for alignment, limited to small dynamic regions [S1].
*   **When to Use:** VR advertising with sparse input, dynamic objects occupying a small portion of the scene [S1].
*   **When Not to Use:** Scenes with large dynamic regions, dense input data where full dynamic NeRF might be more accurate [S1].

## Background
This method was proposed in "Efficient Sparse Input Scene Reconstruction and Real-Time Rendering for VR Advertising Using Optimized NeRF Framework" (2026) [S1]. It addresses the limitations of traditional dynamic NeRF methods like DyNeRF, which require over 100M parameters and independent models per time step, making them unsuitable for VR devices [S1]. The approach combines static NeRF for static areas and a lightweight deformation field for dynamic regions, reducing parameters by 95% [S1].
