# 3D Gaussian Splatting Training

Also called: 3DGS Learning, G Splats

## Overview
3D Gaussian Splatting Training is the iterative optimization process that adjusts the parameters of a set of 3D Gaussian primitives to minimize the difference between rendered images and ground truth views [S2][S6, unofficial]. It solves the problem of reconstructing high-fidelity 3D scenes from 2D images by optimizing position, rotation, scale, opacity, and appearance (spherical harmonics) attributes [S5, S6, unofficial]. What sets it apart from implicit radiance fields like NeRF is its use of explicit, differentiable Gaussian primitives with adaptive density control, allowing for significantly faster training and real-time rendering speeds while maintaining comparable image quality [S2][S5, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ input images (or video frames) with known camera poses (extrinsics $R_{cw}, t_{cw}$ and intrinsics $K$) and initial 3D Gaussian estimates derived from Structure from Motion (SfM) [S2][S6, unofficial].
*   **Outputs:** Optimized 3D Gaussian parameters (positions $\mathbf{p}$, rotations $q$, scales $\mathbf{s}$, opacities $\alpha$, and spherical harmonic coefficients $h$) stored in a format such as PLY [S4, S6, unofficial].

**Data Structures:**
Each Gaussian primitive $i$ is defined by:
*   Position $\mathbf{p}_i \in \mathbb{R}^3$
*   Rotation $q_i \in \mathbb{R}^4$ (unit quaternion)
*   Scale $\mathbf{s}_i \in \mathbb{R}^3$
*   Opacity $\alpha_i \in [0, 1]$
*   Appearance parameters $h_i$ (Spherical Harmonic coefficients) [Parent]

**Parameters:**
*   `numIters`: Total optimization steps. Default: 30,000 [S3, S4, unofficial].
*   `sh_degree`: Spherical harmonic degree. Default: 3 [S3, S4, unofficial].
*   `shDegreeInterval`: Steps between increasing SH degree. Default: 1,000 [S3, S4, unofficial].
*   `densifyFrom`: Step after which densification begins. Default: 500 [S3, unofficial].
*   `densifyUntil`: Step after which densification stops. Default: $\min(15000, \text{numIters}/2)$ [S3, unofficial].
*   `refineEvery`: Frequency of refinement (densification/pruning). Default: 500 [S3, unofficial].
*   `densify_grad_thresh`: Gradient threshold for densification. Default: 0.0002 [S4, unofficial].
*   `densify_size_thresh`: Size threshold for densification. Default: 0.01 [S4, unofficial].
*   `split_screen_size`: Screen size threshold for splitting. Default: 0.05 [S4, unofficial].
*   `stop_screen_size_at`: Step at which screen-size splitting stops. Default: 4,000 [S4, unofficial].
*   `ssim_weight`: Weight for SSIM loss. Default: 0.2 [S3, S4, unofficial].
*   `maxGaussians`: Maximum number of Gaussians. Default: 5,000,000 [S3, unofficial].
*   `downScaleFactor`: Initial image scaling. Default: 1.0 [S3, S4, unofficial].
*   `numDownscales`: Number of resolution scales. Default: 0 or 2 depending on implementation [S3, S4, unofficial].
*   `resolutionSchedule`: Steps between doubling resolution. Default: 3,000 [S3, unofficial].

**Initialization:**
1.  **Position:** Initialize $\mathbf{p}_i$ using sparse point clouds from SfM (e.g., COLMAP) [S2][S6, unofficial].
2.  **Rotation:** Initialize $q_i$ as unit quaternions [S2].
3.  **Scale:** Initialize $\mathbf{s}_i$ with values between 0 and 1 [S2].
4.  **Opacity:** Initialize $\alpha_i$ as constants [S6, unofficial].
5.  **Color:** Initialize $h_i$ via `InitAttributes()` [S2].

**Forward Rendering:**
1.  **Projection:** Project 3D Gaussians to 2D screen space using the camera matrix. The 2D covariance $\Sigma'$ is derived from the 3D covariance $\Sigma$ and the Jacobian of the affine approximation of the projection [S6, unofficial].
2.  **Sorting:** Sort Gaussians by depth for each pixel [Parent].
3.  **Alpha Blending:** Compute pixel color $\gamma_j$ via alpha blending:
    $$ \gamma_j = \sum_{i \in N} \alpha'_{ij} c_i \tau_{ij}, \quad \tau_{ij} = \prod_{k=1}^{i-1} (1 - \alpha'_{kj}) $$
    where $\alpha'_{ij} = g \alpha_i$, $g = \exp(-0.5 \omega'_0 d_0^2 - 0.5 \omega'_2 d_1^2 - \omega'_1 d_0 d_1)$, and $\omega'$ are elements of the inverse 2D covariance matrix [S6, unofficial].

**Loss Function:**
Minimize $\mathcal{L}$:
$$ \mathcal{L} = (1 - \lambda) \mathcal{L}_1 + \lambda \mathcal{L}_{D-SSIM} $$
where $\lambda$ is the SSIM weight (default 0.2) [S6, unofficial].

**Backpropagation:**
Compute gradients for each parameter using the chain rule [S6, unofficial]:
*   $\frac{\partial \mathcal{L}}{\partial q_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \sigma'_i} \frac{\partial \sigma'_i}{\partial \sigma_i} \frac{\partial \sigma_i}{\partial q_i}$
*   $\frac{\partial \mathcal{L}}{\partial s_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \sigma'_i} \frac{\partial \sigma'_i}{\partial \sigma_i} \frac{\partial \sigma_i}{\partial s_i}$
*   $\frac{\partial \mathcal{L}}{\partial h_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial c_i} \frac{\partial c_i}{\partial h_i}$
*   $\frac{\partial \mathcal{L}}{\partial \alpha_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \alpha'_{ij}} \frac{\partial \alpha'_{ij}}{\partial \alpha_i}$
*   $\frac{\partial \mathcal{L}}{\partial p_{w,i}}$ involves three terms accounting for depth sorting, color, and covariance changes [S6, unofficial].

**Adaptive Density Control (Densification):**
Performed every `refineEvery` steps [S2]:
1.  **Pruning:** If $\alpha_i < \epsilon$ or the Gaussian is too large ($||\mathbf{s}_i|| > \tau_S$), prune it [S2].
2.  **Densification Check:** If positional gradient $\nabla_{\mathbf{p}} \mathcal{L} > \tau_p$ (default 0.0002) [S2][S4, unofficial]:
    *   **Over-reconstruction:** If $||\mathbf{s}_i|| > \tau_S$ (default 0.01), split the Gaussian into two [S2][S4, unofficial].
    *   **Under-reconstruction:** Else, clone the Gaussian [S2].

**Pseudocode:**
```python
# Initialization
M = SfM_points() # Positions
S, C, A = InitAttributes() # Scales, Colors (SH), Opacities
q = UnitQuaternions() # Rotations
step = 0
numIters = 30000
densifyFrom = 500
densifyUntil = min(15000, numIters // 2)
refineEvery = 500
densify_grad_thresh = 0.0002
densify_size_thresh = 0.01

# Camera Iterator
cam_indices = list(range(num_cameras))
shuffle(cam_indices)
cam_iter = Iterator(cam_indices)

while step <= numIters:
    # 1. Sample View
    cam = get_camera(cam_iter.next())
    gt_image = get_ground_truth(cam, downscale_factor(step))
    
    # 2. Forward Pass
    rendered_image = rasterize(M, S, C, A, q, cam)
    
    # 3. Loss Computation
    loss = (1 - ssim_weight) * L1(rendered_image, gt_image) + ssim_weight * D_SSIM(rendered_image, gt_image)
    
    # 4. Backward Pass
    gradients = compute_gradients(loss, M, S, C, A, q)
    
    # 5. Optimization Step
    update_parameters(M, S, C, A, q, gradients, optimizer="Adam")
    
    # 6. Adaptive Density Control
    if step >= densifyFrom and step <= densifyUntil and step % refineEvery == 0:
        for i in range(len(M)):
            grad_mag = norm(gradients['pos'][i])
            scale_norm = norm(S[i])
            
            # Pruning
            if A[i] < epsilon or scale_norm > densify_size_thresh:
                prune(i)
                continue
            
            # Densification
            if grad_mag > densify_grad_thresh:
                if scale_norm > densify_size_thresh:
                    split(i) # Over-reconstruction
                else:
                    clone(i) # Under-reconstruction
    
    # 7. Schedule Updates
    if step % shDegreeInterval == 0:
        increase_sh_degree()
    if step % resolutionSchedule == 0:
        increase_resolution()
        
    step += 1
```

## Subtopics

### [Physical Parameter Optimization](4111-physical-parameter-optimization.md)

### [WildGaussians](6064-wildgaussians.md)
Models image-dependent appearance variations via a lightweight MLP and separates static scene geometry from transient occluders using learnable opacity variation, solving photometric inconsistency in unconstrained photo collections [6064-wildgaussians.md].

### [Non-Pinhole Camera Training](6088-non-pinhole-camera-training.md)
Adapts 3DGS to non-pinhole cameras (e.g., with lens distortion) by leveraging a differentiable rasterizer that accommodates arbitrary camera projection models [6088-non-pinhole-camera-training.md].

### AbsGS
Uses absolute sums of positional gradients across multiple views to prevent gradient cancellation, addressing the smoothing of fine details and thin structures [6127-absgs.md].

### [Densification Strategy](6234-densification-strategy.md)
Manages the dynamic lifecycle of Gaussians (splitting, cloning, pruning) based on optimization metrics to balance reconstruction quality and computational cost [6234-densification-strategy.md].

### [Regularization and Geometry Constraints](6269-regularization-and-geometry-constraints.md)
Introduces auxiliary constraints beyond pixel-color matching to enforce geometric plausibility, prevent over-reconstruction (floaters), and stabilize convergence [6269-regularization-and-geometry-constraints.md].

### [GSP Training Loss](9156-gsp-training-loss.md)

### [GPS-Gaussian](9197-gps-gaussian.md)

### HUGS
Creates a coarse-to-fine deformation module using linear blend skinning and local learning-based refinement for virtual human avatars, utilizing tri-plane representation to factorize canonical space [S1].

### Wolf et al. Stereo Method
Trains 3DGS to render stereo-calibrated views, applies stereo depth estimation, and fuses dense depth maps via Truncated Signed Distance Function (TSDF) to form a triangular mesh [S1].

### Pseudo Ground Truth Acquisition for Gaussians
Generates Gaussian-specific pseudo ground truth labels from original point cloud labels, accounting for densification and pruning processes [S8, unofficial].

### Cross-View Pruning Mechanism
Uses a Cross-View Consistency Loss and adaptive pruning to reduce Gaussian redundancy and ensure geometric validity by selecting adjacent view pairs with SSIM > 0.6 [S9, unofficial].

### Structure-View Co-learning
Combines structural and view-dependent gradients for robust joint optimization of Gaussian positions and appearance, minimizing $\mathcal{L} = \lambda (\lambda_V \mathcal{L}_V + \lambda_S \mathcal{L}_S)$ [S9, unofficial].

### Single-view Mini-batch Strategy
Organizes data per viewpoint and samples mini-batches from only a single viewpoint to improve training efficiency [S10, unofficial].

## Operating characteristics
*   **Time Complexity:** Training typically takes 15–60 minutes for standard datasets (e.g., Mip-NeRF 360, Tanks & Temples) on modern GPUs, significantly faster than NeRF which can take hours [S2][S5, unofficial].
*   **Memory Complexity:** Memory usage scales with the number of Gaussians. Default limit is 5,000,000 Gaussians [S3, unofficial]. High-resolution scenes can exceed VRAM limits without optimization strategies [9264-optimization-and-training-efficiency.md].
*   **Performance:** Achieves real-time rendering speeds (30–100+ FPS) at 1080p or higher, comparable to or better than NeRF in visual quality (PSNR, SSIM) [S2][S5, unofficial].
*   **Strengths:** Fast training, real-time rendering, high visual fidelity, explicit representation allows for easy editing and compression [S2][S5, unofficial].
*   **Limitations:** Can produce "floaters" or artifacts in unstructured scenes; requires careful tuning of densification parameters; memory intensive for very large scenes [S2, 9264-optimization-and-training-efficiency.md].
*   **Hardware:** Primarily GPU-accelerated (CUDA, Metal). CPU execution is ~100x slower [S3, S4, unofficial].

## Background
3D Gaussian Splatting was introduced by Kerbl et al. in 2023 [9]. It builds on the concept of volumetric rendering but uses explicit 3D Gaussians as primitives instead of implicit neural fields. The method was developed to address the slow training and rendering speeds of NeRFs while maintaining high visual quality. It has since become a standard baseline for 3D reconstruction and novel view synthesis [S2][S5, unofficial].
