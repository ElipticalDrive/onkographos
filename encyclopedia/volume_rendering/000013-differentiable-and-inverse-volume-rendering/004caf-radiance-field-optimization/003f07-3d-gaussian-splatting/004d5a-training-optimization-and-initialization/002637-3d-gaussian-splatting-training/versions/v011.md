# 3D Gaussian Splatting Training

Also called: 3DGS Learning, G Splats

## Overview
3D Gaussian Splatting Training is the iterative optimization process that adjusts the parameters of a set of 3D Gaussian primitives to minimize the difference between rendered images and ground truth views [S2][S6, unofficial]. It solves the problem of reconstructing high-fidelity 3D scenes from 2D images by optimizing position, rotation, scale, opacity, and appearance (spherical harmonics) attributes [S5, unofficial]. Unlike static initialization methods, this method uses adaptive density control to dynamically add, split, or prune Gaussians based on optimization metrics, balancing reconstruction quality against computational cost [S2]. It differs from NeRF-based methods by offering significantly faster training and inference speeds while achieving comparable image quality [S2][S5, unofficial].

## How it works
**Inputs:** A set of $N$ input images (or video frames) with known camera poses (extrinsics $R_{cw}, t_{cw}$ and intrinsics $K$) and ground truth pixel values $\gamma^{gt}$ [S6, unofficial]. Initial 3D Gaussian parameters are derived from Structure from Motion (SfM) point clouds [S2][S6, unofficial].

**Outputs:** A set of optimized 3D Gaussian primitives $\mathcal{G} = \{ \mu_i, q_i, s_i, \alpha_i, h_i \}_{i=1}^M$ and their associated attributes [S6, unofficial].

**Data Structures:**
Each Gaussian $i$ is defined by:
*   Position $\mu_i \in \mathbb{R}^3$ (initialized from SfM points) [S2][S6, unofficial].
*   Rotation $q_i \in \mathbb{R}^4$ (unit quaternion, initialized as constant) [S2][S6, unofficial].
*   Scale $s_i \in \mathbb{R}^3$ (initialized between 0 and 1) [S2][S6, unofficial].
*   Opacity $\alpha_i \in [0, 1]$ (initialized as constant) [S2][S6, unofficial].
*   Appearance $h_i$ (Spherical Harmonic coefficients, initialized from SfM) [S2][S6, unofficial].
*   Covariance $\Sigma_i$ is computed from $q_i$ and $s_i$ [S2].

**Parameters:**
*   `numIters`: Total optimization steps. Default: 30,000 [S3, S4, unofficial].
*   `sh_degree`: Max spherical harmonic degree. Default: 3 [S4, unofficial].
*   `sh_degree_interval`: Steps between increasing SH degree. Default: 1,000 [S4, unofficial].
*   `resolutionSchedule`: Steps between doubling image resolution. Default: 3,000 [S3, S4, unofficial].
*   `densifyFrom`: Step after which densification begins. Default: 500 [S3, unofficial].
*   `densifyUntil`: Step after which densification stops. Default: $\min(15,000, \text{numIters}/2)$ [S3, unofficial].
*   `refineEvery`: Steps between densification/pruning operations. Default: 500 [S3, unofficial].
*   `densify_grad_thresh`: Gradient threshold for densification. Default: 0.0002 [S4, unofficial].
*   `densify_size_thresh`: Size threshold for splitting. Default: 0.01 [S4, unofficial].
*   `split_screen_size`: Screen size threshold for splitting. Default: 0.05 [S4, unofficial].
*   `stop_screen_size_at`: Step at which screen-size splitting stops. Default: 4,000 [S4, unofficial].
*   `maxGaussians`: Maximum number of Gaussians. Default: 5,000,000 [S3, unofficial].
*   `ssim_weight`: Weight for SSIM loss. Default: 0.2 [S4, unofficial].
*   `bg_color`: Background color [R, G, B]. Default: [0.613, 0.010, 0.398] (magenta) [S4, unofficial].

**Step-by-Step Method:**

1.  **Initialization:**
    *   Initialize positions $\mu$ in normalized bounds $[-1, 1]$ [S2].
    *   Initialize scales $s$ between 0 and 1 [S2].
    *   Initialize rotations $q$ as unit quaternions [S2].
    *   Initialize opacities $\alpha$ and colors $h$ via `InitAttributes()` [S2].
    *   Set iteration count $i = 0$ [S2].

2.  **Training Loop:**
    For each step $step$ from 1 to `numIters`:
    1.  **Camera Selection:** Select the next training camera $V$ and ground truth image $\hat{I}$ using a round-robin schedule with periodic shuffling [S4, unofficial]. Apply a downscale factor based on the current step [S4, unofficial].
    2.  **Rendering:**
        *   Project 3D Gaussians to 2D screen space using camera $V$. The projection uses the covariance matrix $\Sigma$ derived from $q$ and $s$ [S2].
        *   Sort Gaussians by depth.
        *   Alpha blend to compute rendered image $I$. Pixel color $\gamma_j$ is:
            $$ \gamma_j = \sum_{i \in N} \alpha'_{ij} c_i \tau_{ij}, \quad \tau_{ij} = \prod_{k=1}^{i-1} (1 - \alpha'_{kj}) $$
            where $\alpha'_{ij} = g \alpha_i$ is the effective opacity, $g$ is the 2D Gaussian weight, and $c_i$ is the color [S6, unofficial].
    3.  **Loss Computation:**
        Compute loss $\mathcal{L}$ between $I$ and $\hat{I}$:
        $$ \mathcal{L} = (1 - \lambda) \mathcal{L}_1 + \lambda \mathcal{L}_{D-SSIM} $$
        where $\lambda$ is `ssim_weight` (default 0.2) [S6, unofficial].
    4.  **Backpropagation:**
        Compute gradients $\frac{\partial \mathcal{L}}{\partial \theta}$ for all parameters $\theta \in \{ \mu, q, s, h, \alpha \}$ using the chain rule [S6, unofficial]. Key Jacobians include:
        *   Rotation: $\frac{\partial \mathcal{L}}{\partial q_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \sigma'_i} \frac{\partial \sigma'_i}{\partial \sigma_i} \frac{\partial \sigma_i}{\partial q_i}$ [S6, unofficial].
        *   Scale: $\frac{\partial \mathcal{L}}{\partial s_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \sigma'_i} \frac{\partial \sigma'_i}{\partial \sigma_i} \frac{\partial \sigma_i}{\partial s_i}$ [S6, unofficial].
        *   Position: $\frac{\partial \mathcal{L}}{\partial p_{w,i}}$ involves terms for depth sorting, color, and covariance changes [S6, unofficial].
    5.  **Optimizer Step:**
        Update parameters using the Adam optimizer [S2][S6, unofficial].
    6.  **Adaptive Density Control (Refinement):**
        If $step$ is a refinement iteration (e.g., every `refineEvery` steps) and $step >$ `densifyFrom`:
        *   **Pruning:** If $\alpha_i < \epsilon$ or the Gaussian is too large ($||S|| > \tau_S$), prune the Gaussian [S2].
        *   **Densification:** If the positional gradient $\nabla_p \mathcal{L} > \tau_p$ (default 0.0002):
            *   **Over-reconstruction:** If $||S|| > \tau_S$ (default 0.01), split the Gaussian into two [S2].
            *   **Under-reconstruction:** Else, clone the Gaussian [S2].
        *   **Screen Size Splitting:** If $step <$ `stop_screen_size_at` and the Gaussian's screen size exceeds `split_screen_size`, split it [S4, unofficial].
    7.  **Progression:**
        *   Increment $step$.
        *   Update SH degree if $step$ is a multiple of `sh_degree_interval` [S4, unofficial].
        *   Increase image resolution if $step$ is a multiple of `resolutionSchedule` [S4, unofficial].
        *   Reset opacities if $step$ is a multiple of `reset_alpha_every` (default 30) [S4, unofficial].

**Pseudocode:**

```python
def train_3dgs(training_data, config):
    # 1. Initialization
    gaussians = initialize_gaussians_from_sfm(training_data.sfm_points)
    # Initialize q, s, alpha as constants, mu, h from SfM
    optimizer = Adam(gaussians.parameters())
    step = 0
    cam_iter = InfiniteRandomIterator(training_data.cameras)
    
    # 2. Training Loop
    while step <= config.numIters:
        # Camera Selection
        cam = cam_iter.next()
        downscale = get_downscale_factor(step, config.resolutionSchedule)
        gt_image = training_data.get_image(cam, downscale)
        
        # Rendering
        rendered_image = rasterize(gaussians, cam, downscale)
        
        # Loss Computation
        loss = compute_loss(rendered_image, gt_image, config.ssim_weight)
        
        # Backpropagation
        loss.backward()
        
        # Optimizer Step
        optimizer.step()
        optimizer.zero_grad()
        
        # Adaptive Density Control
        if is_refinement_iteration(step, config.refineEvery) and step > config.densifyFrom:
            for g in gaussians:
                # Pruning
                if g.opacity < config.opacity_threshold or g.scale_norm > config.size_threshold:
                    gaussians.remove(g)
                    continue
                
                # Densification
                if g.position_gradient > config.grad_threshold:
                    if g.scale_norm > config.size_threshold:
                        # Over-reconstruction: Split
                        gaussians.split(g)
                    else:
                        # Under-reconstruction: Clone
                        gaussians.clone(g)
                
                # Screen Size Splitting
                if step < config.stop_screen_size_at:
                    screen_size = get_screen_size(g, cam)
                    if screen_size > config.split_screen_size:
                        gaussians.split(g)
        
        # Progression
        step += 1
        if step % config.sh_degree_interval == 0:
            increase_sh_degree(gaussians, config.sh_degree)
        if step % config.resolutionSchedule == 0:
            increase_resolution(downscale)
        if step % config.reset_alpha_every == 0:
            reset_opacities(gaussians)
            
    return gaussians
```

### HUGS
HUGS creates a coarse-to-fine deformation module using linear blend skinning and local learning-based refinement for animating virtual human avatars [S1]. It utilizes a tri-plane representation to factorize the canonical space, allowing reconstruction from monocular video (50-100 frames) within 30 minutes, achieving 20 FPS rendering [S1].

### Wolf et al. Stereo Method
This method trains a 3DGS to render stereo-calibrated novel views, applies stereo depth estimation on the rendered views, and fuses the estimated dense depth maps using a Truncated Signed Distance Function (TSDF) to form a triangular mesh [S1].

### Pseudo Ground Truth Acquisition for Gaussians
A labeling pipeline that generates Gaussian-specific pseudo ground truth labels from original point cloud labels, accounting for the densification and pruning processes of 3D-GS optimization [S8, unofficial].

### Cross-View Pruning Mechanism
A mechanism comprising a Cross-View Consistency Loss and adaptive pruning to reduce Gaussian redundancy and ensure geometric validity [S9, unofficial]. It selects adjacent view pairs with SSIM > 0.6, computes a Cross-View Consistent Loss ($L_{CVC}$) to penalize residual discrepancies, and prunes Gaussians based on depth/distance consistency conditions ($d^i_p < 0.01 \land d^j_p < 0.5 \lor d^i_p > 3\sigma$) [S9, unofficial].

### Structure-View Co-learning
A module combining structural and view-dependent gradients for robust joint optimization of Gaussian positions and appearance [S9, unofficial]. It uses a loss $\mathcal{L} = \lambda (\lambda_V \mathcal{L}_V + \lambda_S \mathcal{L}_S)$, where $\mathcal{L}_V$ is view gradient loss and $\mathcal{L}_S$ is structure gradient loss [S9, unofficial].

### Single-view Mini-batch Strategy
A training data sampling strategy where data is organized per viewpoint, and a mini-batch consists of data from only a single viewpoint [S10, unofficial]. It collects pixel-color pairs $\{p_{ij}, C_{ij}\}$ for each viewpoint $i$, organizes them into $D = \{D_i\}$, and samples a mini-batch $B_{3DGS}$ from count=1 viewpoint [S10, unofficial].

## Operating characteristics
*   **Time Complexity:** Training typically takes 15-30 minutes for standard scenes (e.g., Mip-NeRF 360) on modern GPUs, significantly faster than NeRFs which can take hours [S2][S5, unofficial].
*   **Memory Complexity:** Memory usage scales with the number of Gaussians. Default max is 5,000,000 Gaussians [S3, unofficial]. Sinc splatting consumes less memory than standard Gaussians [S7].
*   **Performance:** Achieves real-time rendering speeds (100+ FPS) at 1080p resolution [S5, unofficial]. On the Replica dataset, SGS-SLAM achieves PSNR 34.15, SSIM 0.97, and LPIPS 0.096 [S1].
*   **Scaling:** Performance degrades on CPU, which is ~100x slower than GPU [S3, unofficial]. Resolution scaling is handled via downscale factors, increasing resolution every 3,000 steps [S4, unofficial].
*   **Strengths:** Fast training, real-time rendering, high fidelity [S2][S5, unofficial].
*   **Limitations:** Can produce "floaters" or over-reconstruction if not properly pruned [S2]. Requires careful tuning of densification thresholds [S4, unofficial].

## Background
3D Gaussian Splatting was introduced by Kerbl et al. [9] (cited in [S2][S6, unofficial]). It initializes positions using sparse point clouds from SfM tools like COLMAP [21] [S2][S6, unofficial]. The method falls under the category of radiance fields but differs from NeRFs by using explicit Gaussian primitives [S5, unofficial]. It has been widely adopted for real-time rendering, SLAM, and dynamic scene reconstruction [S1].
