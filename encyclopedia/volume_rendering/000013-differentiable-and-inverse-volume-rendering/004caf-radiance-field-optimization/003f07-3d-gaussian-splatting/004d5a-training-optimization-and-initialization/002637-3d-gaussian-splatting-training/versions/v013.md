# 3D Gaussian Splatting Training

Also called: 3DGS Learning, G Splats

## Overview
3D Gaussian Splatting Training is the iterative optimization process that adjusts the parameters of a set of 3D Gaussian primitives to minimize the photometric difference between rendered images and ground truth views [S2][S6, unofficial]. It solves the problem of reconstructing high-fidelity 3D scenes from 2D images by converting sparse Structure-from-Motion (SfM) points into a dense, differentiable radiance field [S5, unofficial]. Unlike static initialization methods, it employs adaptive density control to dynamically split, clone, or prune Gaussians based on gradient magnitude and opacity, ensuring detailed reconstruction without excessive floaters [S2]. It sets itself apart from NeRF-based methods by offering significantly faster training and real-time rendering speeds while achieving comparable image quality [S2][S5, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ input images (or video frames) with known camera poses (rotation $R_{cw}$, translation $t_{cw}$, intrinsic matrix $K$) and initial 3D Gaussian parameters derived from SfM [S6, unofficial].
*   **Outputs:** Optimized 3D Gaussian parameters: position $\mathbf{p}_w$, rotation $q$, scale $\mathbf{s}$, opacity $\alpha$, and spherical harmonic coefficients $h$ [S6, unofficial].

**Data Structures:**
Each Gaussian $i$ is defined by:
*   Position $\mathbf{p}_i \in \mathbb{R}^3$
*   Rotation $q_i \in \mathbb{R}^4$ (unit quaternion)
*   Scale $\mathbf{s}_i \in \mathbb{R}^3$
*   Opacity $\alpha_i \in [0, 1]$
*   Appearance parameters (Spherical Harmonic coefficients $h_i$) [Parent]

**Parameters:**
*   `numIters`: Total optimization steps. Default: 30,000 [S3, S4, unofficial].
*   `densifyFrom`: Step after which densification begins. Default: 500 [S3, unofficial].
*   `densifyUntil`: Step after which densification stops. Default: $\min(15000, \text{numIters} / 2)$ [S3, unofficial].
*   `refineEvery`: Steps between densification/pruning operations. Default: 500 [S3, unofficial].
*   `densify_grad_thresh`: Gradient threshold for densification. Default: 0.0002 [S4, unofficial].
*   `densify_size_thresh`: Size threshold for splitting. Default: 0.01 [S4, unofficial].
*   `split_screen_size`: Screen size threshold for splitting. Default: 0.05 [S4, unofficial].
*   `stop_screen_size_at`: Step at which screen-size splitting stops. Default: 4000 [S4, unofficial].
*   `sh_degree`: Spherical harmonic degree. Default: 3 [S4, unofficial].
*   `sh_degree_interval`: Steps between increasing SH degree. Default: 1000 [S4, unofficial].
*   `ssim_weight`: Weight for SSIM loss. Default: 0.2 [S4, unofficial].
*   `maxGaussians`: Maximum number of Gaussians. Default: 5,000,000 [S3, unofficial].

**Step-by-Step Method:**

1.  **Initialization:**
    *   Initialize positions $\mathbf{p}_w$ from SfM point cloud (e.g., COLMAP) within normalized bounds $[-1, 1]$ [S2][S6, unofficial].
    *   Initialize scales $\mathbf{s}$ between 0 and 1 [S2].
    *   Initialize rotations $q$ as unit quaternions [S2].
    *   Initialize opacities $\alpha$ and colors $h$ (via SH) [S2][S6, unofficial].
    *   Set iteration counter $i = 0$ [S2].

2.  **Camera Sampling:**
    *   Maintain a shuffled vector of training camera indices [S4, unofficial].
    *   Select the next camera $V$ using round-robin with periodic reshuffling [S4, unofficial].
    *   Compute downscale factor based on current step [S4, unofficial].

3.  **Rendering:**
    *   Project 3D Gaussians to 2D screen space using camera $V$ [S2].
    *   Sort Gaussians by depth [Parent].
    *   Alpha blend to produce rendered image $I$ [Parent].
    *   Pixel color $\gamma_j$ for pixel $j$ is computed as:
        $$ \gamma_j = \sum_{i \in N} \alpha'_{ij} c_i \tau_{ij} $$
        where $\tau_{ij} = \prod_{k=1}^{i-1} (1 - \alpha'_{kj})$ is the transmittance, $c_i$ is the color, and $\alpha'_{ij}$ is the effective opacity [S6, unofficial].
    *   Effective opacity $\alpha'_{ij} = g \alpha_i$, where $g = \exp(-0.5 \omega'_0 d_0^2 - 0.5 \omega'_2 d_1^2 - \omega'_1 d_0 d_1)$ accounts for 2D covariance projection [S6, unofficial].

4.  **Loss Computation:**
    *   Compute loss $\mathcal{L}$ between rendered image $I$ and ground truth $\hat{I}$:
        $$ \mathcal{L} = (1 - \lambda) \mathcal{L}_1 + \lambda \mathcal{L}_{D-SSIM} $$
        where $\lambda$ is the SSIM weight (default 0.2) [S6, S4, unofficial].

5.  **Backpropagation:**
    *   Compute gradients $\frac{\partial \mathcal{L}}{\partial \theta}$ for all parameters $\theta \in \{\mathbf{p}_w, q, \mathbf{s}, h, \alpha\}$ using the chain rule [S6, unofficial].
    *   Key Jacobians include:
        *   Rotation: $\frac{\partial \mathcal{L}}{\partial q_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \sigma'_i} \frac{\partial \sigma'_i}{\partial \sigma_i} \frac{\partial \sigma_i}{\partial q_i}$ [S6, unofficial].
        *   Position: $\frac{\partial \mathcal{L}}{\partial p_{w,i}}$ involves terms for depth sorting, color, and covariance changes [S6, unofficial].
    *   Update parameters using the Adam optimizer [S2][S6, unofficial].

6.  **Adaptive Density Control (Refinement):**
    *   If $i$ is a refinement iteration (every `refineEvery` steps) and $i > \text{densifyFrom}$:
        *   **Pruning:** If $\alpha_i < \epsilon$ or the Gaussian is too large ($\|\mathbf{S}\| > \tau_S$), prune the Gaussian [S2].
        *   **Densification:** If positional gradient $\nabla_{\mathbf{p}} \mathcal{L} > \tau_p$:
            *   **Over-reconstruction:** If $\|\mathbf{S}\| > \tau_S$, split the Gaussian into two [S2].
            *   **Under-reconstruction:** Else, clone the Gaussian [S2].
    *   Increment $i$ [S2].

**Pseudocode:**

```python
def train_3dgs(training_data, initial_gaussians, config):
    """
    training_data: List of (camera_pose, ground_truth_image) tuples
    initial_gaussians: List of Gaussian objects with p, q, s, alpha, h
    config: Dictionary of hyperparameters
    """
    gaussians = initial_gaussians
    num_iters = config.get('numIters', 30000)
    densify_from = config.get('densifyFrom', 500)
    refine_every = config.get('refineEvery', 500)
    densify_grad_thresh = config.get('densify_grad_thresh', 0.0002)
    ssim_weight = config.get('ssim_weight', 0.2)
    
    # Initialize optimizer
    optimizer = Adam(gaussians.parameters())
    
    # Camera iterator
    cam_indices = list(range(len(training_data)))
    shuffle(cam_indices)
    cam_iter = Iterator(cam_indices)
    
    for step in range(1, num_iters + 1):
        # 1. Camera Sampling
        cam_idx = cam_iter.next()
        if cam_iter.is_empty():
            shuffle(cam_indices)
            cam_iter.reset()
            cam_idx = cam_iter.next()
            
        camera, gt_image = training_data[cam_idx]
        
        # 2. Rendering
        rendered_image = rasterize(gaussians, camera)
        
        # 3. Loss Computation
        l1_loss = compute_l1(rendered_image, gt_image)
        ssim_loss = compute_ssim(rendered_image, gt_image)
        loss = (1 - ssim_weight) * l1_loss + ssim_weight * ssim_loss
        
        # 4. Backpropagation
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        # 5. Adaptive Density Control
        if step > densify_from and step % refine_every == 0:
            gaussians = adaptive_density_control(gaussians, densify_grad_thresh)
            
        # 6. SH Degree Increase
        if step % config.get('sh_degree_interval', 1000) == 0:
            increase_sh_degree(gaussians)
            
    return gaussians

def adaptive_density_control(gaussians, grad_thresh):
    """
    Prunes, splits, or clones Gaussians based on gradients and size.
    """
    new_gaussians = []
    for g in gaussians:
        # Pruning
        if g.opacity < 0.005 or g.scale_norm > 0.1: # Typical thresholds
            continue # Prune
            
        # Densification
        if g.position_gradient > grad_thresh:
            if g.scale_norm > 0.01: # Over-reconstruction
                # Split into two
                child1, child2 = split_gaussian(g)
                new_gaussians.append(child1)
                new_gaussians.append(child2)
            else: # Under-reconstruction
                # Clone
                clone = clone_gaussian(g)
                new_gaussians.append(clone)
        else:
            new_gaussians.append(g)
            
    return new_gaussians
```

## Subtopics

### [Physical Parameter Optimization](4111-physical-parameter-optimization.md)
Replaces standard SH color and empirical opacity with physical quantities (extinction, albedo, scattering) to enable dynamic relighting by solving the radiative transfer equation.

### [WildGaussians](6064-wildgaussians.md)
Models image-dependent appearance variations via a lightweight MLP and separates static scene geometry from transient occluders to handle "in-the-wild" photo collections.

### [Non-Pinhole Camera Training](6088-non-pinhole-camera-training.md)
Adapts 3DGS to non-pinhole cameras (e.g., with lens distortion) by leveraging a differentiable rasterizer that accommodates arbitrary camera projection models.

### [AbsGS](6127-absgs.md)
Uses absolute sums of positional gradients across multiple views to prevent gradient cancellation, improving the detection of "fence-sitting" Gaussians and sharpening edges.

### [Densification Strategy](6234-densification-strategy.md)
Manages the topology of the Gaussian set by dynamically adding, splitting, cloning, or removing primitives based on optimization metrics to balance quality and cost [13466-densification-and-splitting.md].

### [Regularization and Geometry Constraints](6269-regularization-and-geometry-constraints.md)
Introduces auxiliary constraints beyond photometric loss to enforce geometric plausibility, prevent over-reconstruction (floaters), and stabilize convergence.

### [Base 3DGS Optimization](7549-base-3dgs-optimization.md)
Incorporates an explicit normal attribute and normal consistency loss to accelerate convergence of editable Gaussian optimization by ensuring accurate surface geometry.

### [GSP Training Loss](9156-gsp-training-loss.md)
Extends the standard loss with normal consistency and anisotropy regularization to prevent artifacts from excessive kernel elongation in dynamic simulations.

### [GPS-Gaussian](9197-gps-gaussian.md)
Eliminates iterative optimization by regressing Gaussian parameters directly from sparse source views using Gaussian parameter maps and a depth estimation module.

### [Optimization and Training Efficiency](9264-optimization-and-training-efficiency.md)
Encompasses computational strategies, memory management, and hardware-specific optimizations (half-precision, fused kernels) to handle billions of primitives.

### [Dynamic and Temporal Modeling](9265-dynamic-and-temporal-modeling.md)
Extends static 3DGS to handle non-rigid geometry and appearance variations by parameterizing Gaussian attributes as time-dependent functions.

### [Compression and Representation Efficiency](9266-compression-and-representation-efficiency.md)
Methods to reduce memory and computational costs through compression techniques like vector quantization or sparse representations.

### [SLAM and Mapping](9268-slam-and-mapping.md)
Integrates Simultaneous Localization and Mapping (SLAM) with 3DGS for real-time 3D reconstruction and localization in dynamic environments.

### [Application-Specific Reconstructions](9269-application-specific-reconstructions.md)
Modifies the training loop for domain-specific challenges like dynamic human avatars, using custom priors and deformation mechanisms.

### [Geometry and Surface Priors](9270-geometry-and-surface-priors.md)
Enforces geometric consistency by coupling Gaussian representation with continuous signals like SDFs or monocular depth estimates.

### [Neural Network and Feed-Forward Approaches](9526-neural-network-and-feed-forward-approaches.md)
Methods that replace iterative optimization with feed-forward neural networks to predict Gaussian parameters directly from input images.

### [ClipGS](9546-clipgs.md)
A framework for volumetric medical data visualization that uses CLIP features and an Adaptive Adjustment Model to handle dynamic clipping planes.

### [Representation and Kernel Modifications](10145-representation-and-kernel-modifications.md)
Alters the fundamental primitives (e.g., negative colors, voxel-based interpolation, alternative RBFs) to improve shape expressivity and handle optical phenomena.

### [TideGS Trajectory Ordering](10176-tidegs-trajectory-ordering.md)
Replaces randomized view shuffling with a trajectory-aware ordered sequence (TSP) to improve optimization stability for large-scale scenes.

### [Gradient Computation and Back-Propagation](10202-gradient-computation-and-back-propagation.md)
Defines the mathematical mechanisms for propagating loss gradients to Gaussian parameters and camera poses, enabling end-to-end training.

### [VisibilitySplat](10927-visibilitysplat.md)
Augments the rasterization pipeline with a sparse visibility oracle (BVH-accelerated ray tracer) to estimate transmittance-weighted occlusion for material-light decomposition.

### [MCMC-based 3D Gaussian Splatting](11914-mcmc-based-3d-gaussian-splatting.md)
Reforms training as a Markov Chain Monte Carlo process, replacing heuristic densification with stochastic exploration to avoid local minima.

### [3D Gaussian Splatting as Markov Chain Monte Carlo (MCMC)](11915-3d-gaussian-splatting-as-markov-chain-monte-carlo-mcmc.md)
Reinterprets training as sampling from a target distribution, treating structural changes as valid state transitions to preserve probability mass.

### [Sliced Wasserstein-based Gaussian Cloning Update](11919-sliced-wasserstein-based-gaussian-cloning-update.md)
Determines scale updates for cloned Gaussians by minimizing the difference in integrated color along 1D slices, ensuring rasterization integral conservation.

### [Cross-Structure Collaboration Module](12071-cross-structure-collaboration-module.md)
Integrates global tri-plane features with local context-aware grid features to generate Hierarchical Dense Embedded (HDE) features for large-scale scenes.

### HUGS
Creates a coarse-to-fine deformation module using linear blend skinning and local learning-based refinement for animating virtual human avatars based on 3DGS. It utilizes tri-plane representation to factorize the canonical space, reconstructing from monocular video (50-100 frames) within 30 minutes at 20 FPS [S1].

### Wolf et al. Stereo Method
Trains a 3DGS to render stereo-calibrated novel views, applies stereo depth estimation on the rendered views, and fuses the estimated dense depth maps using Truncated Signed Distance Function (TSDF) to form a triangular mesh [S1].

### Pseudo Ground Truth Acquisition for Gaussians
A labeling pipeline that generates Gaussian-specific pseudo ground truth labels from original point cloud labels, accounting for the densification and pruning processes of 3D-GS optimization [S8, unofficial].

### Cross-View Pruning Mechanism
Comprises a Cross-View Consistency Loss and adaptive pruning to reduce Gaussian redundancy. It selects adjacent view pairs with SSIM > 0.6, computes a consistency loss to penalize residual discrepancies, and prunes Gaussians based on depth/distance consistency conditions [S9, unofficial].

### Structure-View Co-learning
A module combining structural and view-dependent gradients for robust joint optimization. The loss is defined as $\mathcal{L} = \lambda (\lambda_V \mathcal{L}_V + \lambda_S \mathcal{L}_S)$, where $\mathcal{L}_V$ is view gradient loss and $\mathcal{L}_S$ is structure gradient loss [S9, unofficial].

### Single-view Mini-batch Strategy
A training data sampling strategy where data is organized per viewpoint, and a mini-batch consists of data from only a single viewpoint. This involves collecting pixel-color pairs for each viewpoint $i$ into dataset $D_i$, organizing them into $D = \{D_i\}$, and sampling a mini-batch $B_{3DGS}$ from a single $D_i$ [S10, unofficial].

## Operating characteristics
*   **Time Complexity:** Training typically requires 30,000 iterations [S3, S4, unofficial]. CPU execution is ~100x slower than GPU [S3, unofficial].
*   **Memory Complexity:** Scales with the number of Gaussians, which can reach millions (default max 5,000,000) [S3, unofficial]. Sinc splatting consumes less memory than standard Gaussians [S7].
*   **Performance:** Achieves comparable image quality to NeRF but with significantly faster training and real-time rendering speeds [S2][S5, unofficial]. On the Replica dataset, SGS-SLAM achieves PSNR 34.15, SSIM 0.97, and LPIPS 0.096 [S1].
*   **Strengths:** Real-time rendering, fast training, high fidelity.
*   **Limitations:** Sensitive to initialization, prone to "floaters" in empty space, requires careful densification tuning [S1, S2].
*   **When to use:** When real-time rendering and fast reconstruction from images are required.
*   **When not to use:** When explicit surface geometry is strictly required without post-processing, or when computational resources are extremely limited (CPU-only).

## Background
3D Gaussian Splatting was introduced by Kerbl et al. [9] in 2023. It initializes positions using sparse point clouds from SfM tools like COLMAP [21] [S2][S6, unofficial]. The method falls under the category of radiance fields, similar to NeRFs, but uses explicit Gaussian primitives instead of implicit neural networks [S5, unofficial]. It has since been extended to various domains including SLAM, dynamic scenes, and human avatars [S1].
