# 3D Gaussian Splatting Training

Also called: 3DGS Learning, G Splats

## Overview
3D Gaussian Splatting Training is the iterative optimization process that adjusts the parameters of a set of 3D Gaussian primitives to minimize the difference between rendered images and ground truth views [S2][S6, unofficial]. It solves the problem of reconstructing high-fidelity 3D scenes from 2D images by optimizing position, rotation, scale, opacity, and appearance (e.g., spherical harmonics) [S5, unofficial]. Unlike NeRF-based methods which optimize implicit neural fields, 3DGS training operates on explicit, differentiable volumetric primitives, offering significantly faster training and real-time rendering speeds while achieving comparable image quality [S2][S5, unofficial]. It builds on [Base 3DGS Optimization](7549-base-3d-gaussian-splatting-optimization.md) by incorporating adaptive density control to dynamically manage the primitive population [S2].

## How it works
**Inputs:** A set of $N$ input images (or video frames) with known camera poses (extrinsics $R_{cw}, t_{cw}$ and intrinsics $K$) [S6, unofficial]. Initial 3D Gaussian parameters derived from Structure from Motion (SfM) or other initialization methods [S2][S6, unofficial].

**Outputs:** Optimized 3D Gaussian primitives $\mathcal{G} = \{ \mathbf{p}_i, q_i, \mathbf{s}_i, \alpha_i, h_i \}_{i=1}^{M}$, where $M$ is the final number of Gaussians [S6, unofficial].

**Data Structures:**
*   **Gaussian Attributes:** Each Gaussian $i$ stores:
    *   Position $\mathbf{p}_i \in \mathbb{R}^3$ (initialized from SfM points) [S6, unofficial].
    *   Rotation $q_i \in \mathbb{R}^4$ (unit quaternion, initialized as constant) [S6, unofficial].
    *   Scale $\mathbf{s}_i \in \mathbb{R}^3$ (initialized uniformly between 0 and 1) [S2][S6, unofficial].
    *   Opacity $\alpha_i \in [0, 1]$ (initialized as constant) [S6, unofficial].
    *   Appearance $h_i$ (Spherical Harmonic coefficients, initialized from SfM colors) [S6, unofficial].
*   **Covariance Matrix:** The 3D covariance $\Sigma_i$ is computed from scale and rotation: $\Sigma_i = R_i S_i S_i^T R_i^T$, where $R_i$ is the rotation matrix derived from $q_i$ and $S_i$ is the diagonal scale matrix [S2].
*   **Rotation Matrix:** Derived from quaternion $q = (q_r, q_i, q_j, q_k)$ [S2]:
    $$
    R(q) = 2 \begin{bmatrix} \frac{1}{2} - (q_j^2 + q_k^2) & q_i q_j - q_r q_k & q_i q_k + q_r q_j \\ q_i q_j + q_r q_k & \frac{1}{2} - (q_i^2 + q_k^2) & q_j q_k - q_r q_i \\ q_i q_k - q_r q_j & q_j q_k + q_r q_i & \frac{1}{2} - (q_i^2 + q_j^2) \end{bmatrix}
    $$
    [S2]

**Parameters:**
*   `numIters`: Total optimization steps. Default: 30,000 [S3, S4, unofficial].
*   `sh_degree`: Spherical harmonic degree. Default: 3 [S4, unofficial].
*   `sh_degree_interval`: Steps between increasing SH degree. Default: 1,000 [S4, unofficial].
*   `densifyFrom`: Step after which densification begins. Default: 500 [S3, unofficial].
*   `densifyUntil`: Step after which densification stops. Default: $\min(15,000, \text{numIters}/2)$ [S3, unofficial].
*   `refineEvery`: Steps between densification/pruning operations. Default: 500 [S3, unofficial].
*   `densify_grad_thresh`: Gradient threshold for densification. Default: 0.0002 [S4, unofficial].
*   `densify_size_thresh`: Size threshold for splitting. Default: 0.01 [S4, unofficial].
*   `split_screen_size`: Screen size threshold for splitting. Default: 0.05 [S4, unofficial].
*   `stop_screen_size_at`: Step at which screen-size splitting stops. Default: 4,000 [S4, unofficial].
*   `maxGaussians`: Maximum number of Gaussians. Default: 5,000,000 [S3, unofficial].
*   `ssim_weight`: Weight for SSIM loss. Default: 0.2 [S4, unofficial].
*   `downscale_factor`: Initial image downscale. Default: 1.0 [S4, unofficial].
*   `num_downscales`: Number of resolution scales. Default: 2 [S4, unofficial].
*   `resolution_schedule`: Steps between doubling resolution. Default: 3,000 [S4, unofficial].

**Algorithm:**
The training loop minimizes the loss $\mathcal{L}$ between the rendered image $\gamma$ and ground truth $\gamma_{gt}$ using the Adam optimizer [S2][S6, unofficial]. The loss is a combination of L1 loss and D-SSIM loss [S6, unofficial]:
$$
\mathcal{L} = (1 - \lambda) \mathcal{L}_1 + \lambda \mathcal{L}_{D-SSIM}
$$
where $\lambda$ is the SSIM weight [S6, unofficial].

The optimization proceeds as follows:

1.  **Initialization:** Initialize Gaussian positions $\mathbf{p}$ from SfM points. Initialize rotation $q$, scale $\mathbf{s}$, and opacity $\alpha$ as constants. Initialize appearance $h$ from SfM colors [S2][S6, unofficial]. Set iteration counter $i = 0$ [S2].
2.  **Camera Sampling:** Select a training camera $V$ and its ground truth image $\hat{I}$ [S2]. Cameras are sampled via round-robin with periodic shuffling [S4, unofficial]. Image resolution is scaled by `downscale_factor` and increases according to `resolution_schedule` [S4, unofficial].
3.  **Rendering:** Rasterize the current Gaussians using camera $V$ to obtain rendered image $I$ [S2]. This involves projecting 3D Gaussians to 2D screen space, sorting by depth, and alpha blending [Parent].
4.  **Loss Computation:** Compute loss $\mathcal{L}$ between $I$ and $\hat{I}$ [S2].
5.  **Backpropagation:** Compute gradients $\nabla \mathcal{L}$ for all parameters ($\mathbf{p}, q, \mathbf{s}, h, \alpha$) using the chain rule [S6, unofficial]. The Jacobians for each parameter are computed as follows [S6, unofficial]:
    *   Rotation: $\frac{\partial \mathcal{L}}{\partial q_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \sigma'_i} \frac{\partial \sigma'_i}{\partial \sigma_i} \frac{\partial \sigma_i}{\partial q_i}$
    *   Scale: $\frac{\partial \mathcal{L}}{\partial s_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \sigma'_i} \frac{\partial \sigma'_i}{\partial \sigma_i} \frac{\partial \sigma_i}{\partial s_i}$
    *   Appearance: $\frac{\partial \mathcal{L}}{\partial h_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial c_i} \frac{\partial c_i}{\partial h_i}$
    *   Opacity: $\frac{\partial \mathcal{L}}{\partial \alpha_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \alpha'_{ij}} \frac{\partial \alpha'_{ij}}{\partial \alpha_i}$
    *   Position: $\frac{\partial \mathcal{L}}{\partial \mathbf{p}_{w,i}}$ involves three terms accounting for depth sorting, color, and covariance changes [S6, unofficial].
6.  **Optimizer Step:** Update parameters using Adam optimizer [S2].
7.  **Adaptive Density Control:** If $i$ is a refinement iteration (every `refineEvery` steps) and $i \ge \text{densifyFrom}$, perform densification and pruning [S2]:
    *   **Pruning:** If opacity $\alpha_i < \epsilon$ or the Gaussian is too large ($\|\mathbf{S}\| > \tau_S$), prune the Gaussian [S2].
    *   **Densification:** If positional gradient $\|\nabla_{\mathbf{p}} \mathcal{L}\| > \tau_p$:
        *   **Over-reconstruction:** If $\|\mathbf{S}\| > \tau_S$, split the Gaussian into two [S2].
        *   **Under-reconstruction:** If $\|\mathbf{S}\| \le \tau_S$, clone the Gaussian [S2].
8.  **Increment:** $i \leftarrow i + 1$. Repeat until convergence or `numIters` is reached [S2].

**Pseudocode:**
```python
def train_3dgs(training_data, config):
    # 1. Initialization
    gaussians = initialize_gaussians_from_sfm(training_data.sfm_points)
    # Initialize q, s, alpha as constants; h from SfM colors
    optimizer = Adam(gaussians.parameters(), lr=config.initial_lr)
    
    step = 0
    cam_iter = InfiniteRandomIterator(training_data.cameras)
    
    while step < config.num_iters:
        # 2. Camera Sampling
        cam = cam_iter.next()
        gt_image, gt_mask = training_data.get_image(cam, step)
        
        # 3. Rendering
        rendered_image = rasterize(gaussians, cam)
        
        # 4. Loss Computation
        loss = compute_loss(rendered_image, gt_image, gt_mask, config.ssim_weight)
        
        # 5. Backpropagation
        loss.backward()
        
        # 6. Optimizer Step
        optimizer.step()
        optimizer.zero_grad()
        
        # 7. Adaptive Density Control
        if is_refinement_iteration(step, config):
            densify_and_prune(gaussians, step, config)
            
        # 8. Increment
        step += 1
        update_schedulers(optimizer, step)
        
    return gaussians

def densify_and_prune(gaussians, step, config):
    # Pruning
    for g in gaussians:
        if g.opacity < config.opacity_threshold or is_too_large(g):
            gaussians.remove(g)
            
    # Densification
    if step >= config.densify_from:
        for g in gaussians:
            grad_norm = get_positional_gradient_norm(g)
            if grad_norm > config.densify_grad_thresh:
                if is_too_large(g):
                    split_gaussian(g)
                else:
                    clone_gaussian(g)
```

### HUGS
Creates a coarse-to-fine deformation module using linear blend skinning and local learning-based refinement for animating virtual human avatars based on 3DGS. It utilizes tri-plane representation to factorize canonical space, reconstructing from monocular video (50-100 frames) within 30 minutes at 20 FPS [S1].

### Wolf et al. Stereo Method
Trains a 3DGS to render stereo-calibrated novel views, applies stereo depth estimation on rendered views, and fuses dense depth maps via Truncated Signed Distance Function (TSDF) to form a triangular mesh [S1].

### Pseudo Ground Truth Acquisition for Gaussians
A labeling pipeline that generates Gaussian-specific pseudo ground truth labels from original point cloud labels, accounting for densification and pruning processes [S8, unofficial].

### Cross-View Pruning Mechanism
Uses a Cross-View Consistency Loss ($L_{CVC}$) and adaptive pruning to reduce redundancy. Selects adjacent view pairs with SSIM > 0.6, computes $L_{CVC}$ to penalize residual discrepancies, and prunes based on depth consistency $d^i_p < 0.01 \land d^j_p < 0.5 \lor d^i_p > 3\sigma$ [S9, unofficial].

### Structure-View Co-learning
Combines structural and view-dependent gradients for joint optimization. Loss: $\mathcal{L} = \lambda (\lambda_V \mathcal{L}_V + \lambda_S \mathcal{L}_S)$, where $\mathcal{L}_V$ is view gradient loss and $\mathcal{L}_S$ is structure gradient loss [S9, unofficial].

### Single-view Mini-batch Strategy
Organizes data per viewpoint $D_i$ and samples mini-batches from only a single viewpoint to improve training efficiency [S10, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time is significantly faster than NeRFs, often completing in under an hour for complex scenes [S5, unofficial]. The C++ implementation with Metal backend achieves training in ~90 seconds on M4 Max hardware [S4, unofficial]. CPU execution is ~100x slower than GPU [S3, unofficial].
*   **Memory Complexity:** Memory usage scales with the number of Gaussians $M$. Default max is 5,000,000 [S3, unofficial]. Sinc splatting variants consume less memory than standard Gaussians [S7].
*   **Performance:** Achieves comparable image quality to NeRFs with real-time rendering speeds [S2]. On Replica dataset, SGS-SLAM achieves PSNR 34.15, SSIM 0.97, LPIPS 0.096 [S1].
*   **Strengths:** Fast training, real-time rendering, high fidelity [S5, unofficial].
*   **Limitations:** Sensitive to initialization; prone to "floaters" if not regularized [S1]. Large-scale scenes may require significant VRAM [S4, unofficial].
*   **When to use:** When real-time rendering and fast training are required for static or mildly dynamic scenes.
*   **When not to use:** For scenes requiring explicit surface meshes without post-processing, or when computational resources are extremely limited (CPU-only).

## Background
3D Gaussian Splatting was introduced by Kerbl et al. [9] (cited in [S2][S6, unofficial]). It initializes positions using sparse point clouds from SfM tools like COLMAP [S2]. The method falls under the category of radiance fields but differs from NeRFs by using explicit Gaussian primitives [S5, unofficial]. It has been extended to SLAM [S1], dynamic scenes [S1], and various applications [S1].
