# Base 3DGS Optimization
Also called: Base 3DGS Optimization with Normal Attribute

## Overview
Base 3DGS Optimization initializes the geometric attributes of 3D Gaussian primitives to provide a robust geometric baseline for subsequent shading attribute optimization, such as in [iVR-GS Training](7578-ivr-gs-training.md) [S1]. It differs from standard 3DGS by incorporating an explicit normal attribute $n$ for each Gaussian and optimizing it via a normal consistency loss, despite the normal not affecting the final rendered color or alpha in the base stage [S1]. This initialization accelerates the convergence of editable Gaussian optimization by ensuring accurate surface geometry representation before decomposing color and lighting [S1].

## How it works
The method takes multi-view input images, camera poses, and initial Gaussian parameters as inputs, and outputs optimized Gaussian primitives with geometry and auxiliary normal attributes [S1].

**Data Structures:**
Each Gaussian $i$ is parameterized by the tuple $\{\mu_i, q_i, s_i, o_i, n_i, c_i\}$ [S1]:
*   $\mu_i \in \mathbb{R}^3$: Mean position.
*   $q_i \in \mathbb{R}^4$: Rotation quaternion.
*   $s_i \in \mathbb{R}^3$: Scale vector.
*   $o_i \in \mathbb{R}$: Opacity.
*   $n_i \in \mathbb{R}^3$: Normal attribute (unit vector).
*   $c_i$: View-dependent color, represented by Spherical Harmonic (SH) coefficients [S1].

**Algorithm Steps:**

1.  **Initialization:** Initialize Gaussians with standard 3DGS parameters $\{\mu_i, q_i, s_i, o_i, c_i\}$ and assign initial normal attributes $n_i$ [S1].
2.  **Rendering:** For a given viewpoint, render the depth map $D$ and normal map $N$ using the current Gaussian parameters [S1]. The rendering follows the alpha compositing equation [S1]:
    $$
    \{D, N\} = \sum_{i \in \mathcal{N}} T_i \alpha_i \{d_i, n_i\}
    $$
    where:
    *   $\mathcal{N}$ is the set of Gaussians sorted by depth [G].
    *   $T_i = \prod_{j < i} (1 - \alpha_j)$ is the accumulated transmittance [G].
    *   $\alpha_i$ is the opacity of the $i$-th Gaussian [G].
    *   $d_i$ is the depth of the $i$-th Gaussian [G].
    *   $n_i$ is the normal attribute of the $i$-th Gaussian rotated to camera space [G].
3.  **Pseudo-Normal Computation:** Compute a pseudo-normal map $\tilde{N}$ from the rendered depth map $D$ under the local planarity assumption [S1]. This involves estimating the surface normal from the depth gradient at each pixel [G].
4.  **Loss Calculation:** Compute the total loss as a combination of L1 and SSIM losses for the base 3DGS output color and alpha channels, along with the normal consistency loss [S1]. The normal consistency loss is defined as $\mathcal{L}_n = ||N - \tilde{N}||_2$ [S1].
5.  **Optimization:** Update all parameters $\{\mu_i, q_i, s_i, o_i, n_i, c_i\}$ using gradient descent [S1]. Adjusting $n$ does not affect the rendering results of base 3DGS; it is optimized only to accelerate convergence of editable Gaussian optimization [S1].
6.  **Iteration:** Repeat steps 2–5 for the specified number of iterations or until convergence [S1].

**Pseudocode:**

```python
def base_3dgs_optimization(gaussians, images, cameras, num_iterations):
    optimizer = Adam(gaussians.parameters(), lr=1e-3)
    for _ in range(num_iterations):
        idx = random.randint(0, len(images) - 1)
        gt_rgb = images[idx]
        camera = cameras[idx]

        D, N = render_depth_normal(gaussians, camera)
        C, alpha_map = render_rgb_alpha(gaussians, camera)
        N_tilde = compute_pseudo_normal(D)

        loss = compute_l1(C, gt_rgb) + compute_ssim(alpha_map, gt_rgb) + compute_l2(N, N_tilde)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
    return gaussians

def render_depth_normal(gaussians, camera):
    sorted_gaussians = sorted(gaussians, key=lambda g: project_depth(g.mu, camera))
    H, W = camera.image_shape
    D = np.zeros((H, W))
    N = np.zeros((H, W, 3))
    T = np.ones((H, W))
    for g in sorted_gaussians:
        d_i = project_depth(g.mu, camera)
        n_i = rotate_vector(g.n, g.q, camera.rotation)
        alpha_i = compute_gaussian_alpha(g, camera)
        weight = T * alpha_i
        D += weight * d_i
        N += weight * n_i
        T *= (1 - alpha_i)
        if np.max(T) < 1e-4:
            break
    return D, N

def compute_pseudo_normal(depth_map):
    dx, dy = np.gradient(depth_map)
    normal = np.stack([-dx, -dy, np.ones_like(depth_map)], axis=-1)
    return normal / np.linalg.norm(normal, axis=-1, keepdims=True)

def render_rgb_alpha(gaussians, camera):
    sorted_gaussians = sorted(gaussians, key=lambda g: project_depth(g.mu, camera))
    H, W = camera.image_shape
    C = np.zeros((H, W, 3))
    alpha_map = np.zeros((H, W))
    T = np.ones((H, W))
    for g in sorted_gaussians:
        alpha_i = compute_gaussian_alpha(g, camera)
        c_i = evaluate_sh(g.c, camera.view_dir)
        weight = T * alpha_i
        C += weight * c_i
        alpha_map += weight
        T *= (1 - alpha_i)
    return C, alpha_map

def compute_l1(a, b): return np.mean(np.abs(a - b))
def compute_l2(a, b): return np.mean((a - b) ** 2)
def compute_ssim(a, b): return 1.0  # Standard SSIM implementation [G]
```

**Parameters:**
*   Learning rate: Standard Adam optimizer settings (value not given in the sources).

**Edge Cases and Pitfalls:**
*   **Normal Irrelevance in Base Stage:** Adjusting the normal attribute $n$ does not affect the rendering results (color/alpha) of the base 3DGS. It is optimized solely to accelerate the convergence of subsequent editable Gaussian optimization [S1].
*   **Alpha Channel Optimization:** Unlike IBR methods that only synthesize RGB, 3DGS reconstructs per-pixel alpha. Optimizing the alpha channel can enhance reconstruction quality [S1].
*   **Pseudo-Normal Accuracy:** The pseudo-normal $\tilde{N}$ relies on the local planarity assumption. In regions with high curvature or noise, this approximation may be inaccurate, potentially leading to suboptimal normal initialization [S1].

## Subtopics

### [iVR-GS Training](7578-ivr-gs-training.md)
iVR-GS Training is a two-stage optimization procedure for Inverse Volume Rendering with 3D Gaussian Splatting (iVR-GS) that separates the initialization of scene geometry from the optimization of editable shading attributes. It builds on [Base 3DGS Optimization](7549-base-3dgs-optimization.md) by first establishing a robust geometric baseline and then refining Gaussian primitives for visual exploration. It differs from one-stage training by accelerating convergence and reducing the number of required primitives while maintaining comparable reconstruction quality.

### [3D Smoothing Filter](9588-3d-smoothing-filter.md)
The 3D smoothing filter prevents 3D Gaussian primitives from becoming smaller than the maximal sampling frequency induced by the training images, thereby mitigating aliasing artifacts when rendering at different sampling rates (e.g., varying focal length or camera distance). It sets a lower bound on Gaussian scale based on the highest spatial frequency captured during training. Unlike the 2D Mip filter which addresses projection aliasing, this filter operates in 3D space to constrain the intrinsic size of the Gaussians.

### Editable Gaussian Optimization
Editable Gaussian Optimization decomposes color and lighting from the scene using the Blinn-Phong model instead of SH coefficients, enabling scene editing [S1]. It assigns additional shading attributes to each Gaussian primitive optimized in base 3DGS: an offset color $\Delta c \in \mathbb{R}^3$, ambient/diffuse/specular coefficients $\{k_a, k_d, k_s\}$, and a shininess term $\beta$ [S1]. The voxel color $c_v$ is expressed as $c_p + \Delta c$, where $c_p \in \mathbb{R}^3$ is a palette color parameter shared by all Gaussians within a basic scene [S1]. $c_p$ is fixed as the mean color value of input multi-view images during training and can be adjusted during inference [S1]. To reduce model size, low-opacity Gaussians are removed periodically, and an L1 regularization term encourages low opacity to neutralize the tendency to use more Gaussians for compact surfaces due to normal-dependent color [S1]. Sparsity regularization (L1 loss of rendered offset color map) is added to $\Delta c$ to avoid significant palette color shiftings [S1].

### Geometry-Guided Optimization
Geometry-Guided Optimization is an optimization phase using Edge-Aware Normal Loss and Multi-Scale SSIM loss to ensure geometric accuracy without affecting RGB fidelity [S2, unofficial]. It computes a normal map $N$ from an unprojected depth map $D$ using the cross product of gradients: $N = (\nabla_x D \times \nabla_y D) / ||\nabla_x D \times \nabla_y D||$ [S2, unofficial]. It derives a curvature map $|\nabla N|$ and an edge map $|\nabla I|$ from the ground truth RGB image, then applies a weight function $\omega(x) = (x - 1)^q$ (where $q$ is a positive even integer) to balance edge influence on curvature [S2, unofficial]. The Edge-Aware Normal Loss is calculated as $L_{normal} = \frac{1}{HW} \sum |\nabla N| \otimes \omega(|\nabla I|)$ [S2, unofficial]. It replaces standard SSIM with Multi-Scale SSIM (MS-SSIM) and computes the composite loss as $L = (1 - \lambda_{ms-ssim})L_1 + \lambda_{ms-ssim}L_{ms-ssim} + \lambda_{normal}L_{normal}$ [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** The base 3DGS optimization provides a geometric baseline that accelerates the convergence of editable Gaussian optimization [S1].
*   **Strengths:** Provides accurate geometry initialization for subsequent shading decomposition; leverages normal consistency to improve geometric fidelity [S1].
*   **Limitations:** The normal attribute does not affect rendering in the base stage, so its optimization is purely for initialization purposes [S1]. Relies on local planarity assumption for pseudo-normal computation [S1].

## Background
Base 3DGS Optimization was introduced in the iVR-GS paper as a preliminary step for inverse volume rendering with editable 3D Gaussian Splatting [S1]. It adapts the original 3DGS framework by adding a normal attribute and optimizing it via a consistency loss, drawing inspiration from prior work on normal consistency [S1].
