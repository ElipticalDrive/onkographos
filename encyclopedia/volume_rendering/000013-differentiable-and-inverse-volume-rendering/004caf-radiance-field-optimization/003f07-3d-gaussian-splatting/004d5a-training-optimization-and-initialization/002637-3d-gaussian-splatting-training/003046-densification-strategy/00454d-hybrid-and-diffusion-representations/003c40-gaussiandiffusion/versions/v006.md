# GaussianDiffusion

Also called: GaussianCube

## Overview
GaussianDiffusion is a method that trains a 3D diffusion model based on a **GaussianCube** representation to generate 3D Gaussian fields directly from compact inputs [S1]. It solves the problem of generating consistent 3D structures without per-scene optimization by mapping a structured latent space to explicit Gaussian parameters [S1]. It sets itself apart from sibling methods like [TriplaneGaussian](7558-triplanegaussian.md) by using a voxel-based GaussianCube representation converted via optimal transport, rather than tri-plane feature querying [S1].

## How it works
**Inputs:** A compact input (e.g., image or text) and a target number of Gaussians $N$.
**Outputs:** A set of 3D Gaussians $\mathcal{G} = \{ \mu_i, \Sigma_i, \alpha_i, c_i \}_{i=1}^{N}$.

**Data Structures:**
1.  **GaussianCube:** A voxel grid representation where each voxel stores Gaussian parameters. It is derived from a constant number of Gaussians via voxelization and optimal transport [S1].
2.  **Diffusion Model:** A neural network that predicts noise in the GaussianCube latent space.

**Steps:**
1.  **GaussianCube Construction:** Convert a fixed set of $N$ Gaussians into a voxelized GaussianCube representation using optimal transport [S1].
2.  **Structured Noise Injection:** Incorporate structured noises from multiple viewpoints into the diffusion process to alleviate the Janus problem (inconsistent geometry from different angles) [S1].
3.  **Diffusion Training:** Train the 3D diffusion model to denoise the GaussianCube representation. The model learns to map noisy latent volumes to clean Gaussian parameters [S1].
4.  **Variational 3DGS Integration:** Use variational 3DGS principles during generation to mitigate floaters (artifacts) and improve generation quality [S1].
5.  **Sampling:** Sample from the trained diffusion model to generate the GaussianCube, then decode it back into the explicit Gaussian set $\mathcal{G}$ [S1].

**Parameters:**
*   Number of Gaussians $N$: Constant, determined by the GaussianCube resolution [S1].
*   Noise Schedule: Standard diffusion schedule, but with structured multi-view noise components [S1].

**Edge Cases and Pitfalls:**
*   **Janus Problem:** Without structured multi-view noise, the generated geometry may be inconsistent across viewpoints [S1].
*   **Floaters:** Standard diffusion may produce spurious Gaussians (floaters); variational 3DGS techniques are required to mitigate this [S1].

## Subtopics

### Gaussian Masking
A technique used to prune Gaussians at every densification step and for every 500 iterations after densification stops [S2]. It uses a Gaussian mask loss with weight $\lambda_m = 0.05$, a threshold $\epsilon_m = 0.05$, and a learning rate of 0.5 for the Gaussian masks [S2].

### Direct 3D Generation
A method that learns a feedforward or diffusion model to output Gaussian fields directly from text or images, without an explicit intermediate image set, amortizing reconstruction cost [S3].

## Background
GaussianDiffusion was proposed by [S1] as a method to generate 3D Gaussians using a diffusion model based on the GaussianCube representation. It addresses limitations in previous generation methods by incorporating structured noise and variational techniques [S1].
