# Training Objective and Densification

Also called: MeshGS Training, Tightly/Loosely-bound Training

## Overview
This method defines the loss function and densification strategy for **MeshGS** [S1], a variant of 3D Gaussian Splatting that aligns primitives with an explicit mesh surface. It solves the problem of Gaussian splats drifting away from geometry or expanding excessively by introducing surface-aware constraints. It differs from standard 3DGS [22] by splitting splats into **tightly-bound** ($G^t$) and **loosely-bound** ($G^l$) sets, applying mesh-specific losses only to $G^t$, and using mesh-based sampling for densification of $G^t$ [S1].

## How it works
**Inputs:**
- Rendered image $\hat{I}_i$ and ground truth image $I_i$.
- Set of tightly-bound Gaussians $G^t$ and loosely-bound Gaussians $G^l$.
- Mesh $M$ consisting of faces $F$, where each face $f_j$ has vertices $v_i$ and normal $n_f$.
- Gaussian parameters for each $i \in G^t \cup G^l$: center $P_i$, scale $S_i = (s_1, s_2, s_3)$, rotation $R_i$.

**Outputs:**
- Total loss $L$ for backpropagation.
- Updated Gaussian set via densification (cloning/splitting).

**Data Structures:**
- $G^t$: Gaussians within distance threshold $d_{th} = 0.01$ from mesh surface [S1].
- $G^l$: Gaussians outside $d_{th}$ [S1].

**Parameters:**
- $\lambda_{img} = 0.001$ [S1].
- $\lambda_{nc} = 0.1$ [S1].
- $\lambda_{min} = 0.1$ [S1].
- $\lambda_{max} = 10$ [S1].
- $\lambda_{proj} = 50$ [S1].
- $\rho = 0.1$ (scale threshold) [S1].
- Training iterations: 30,000 [S1].

**Steps:**

1.  **Compute Image Loss ($L_{img}$):**
    Calculate the combination of L1 loss and D-SSIM [S1]:
    $$ L_{img} = (1 - \lambda_{img}) L_1(\hat{I}_i, I_i) + \lambda_{img} SSIM(\hat{I}_i, I_i) $$
    Where $L_1$ is the mean absolute error and $SSIM$ is the structural similarity index [S1].

2.  **Compute Normal Consistency Loss ($L_{nc}$):**
    For each tightly-bound Gaussian $i \in G^t$:
    a. Identify the minimum scale axis index $k$ such that $s_k = \min(s_1, s_2, s_3)$ [S1].
    b. Compute the normal vector $n_i$ by applying rotation $R_i$ to the basis vector corresponding to axis $k$ [S1].
    c. Find the closest mesh face $f_j \in F$ to Gaussian $i$ [S1].
    d. Get the face normal $n_f$ of $f_j$ [S1].
    e. Accumulate loss:
    $$ L_{nc} = \sum_{i \in G^t, f \in F} (1 - n_i \cdot n_f) $$
    [S1]

3.  **Compute Scale Regularization Loss ($L_{scale}$):**
    For each tightly-bound Gaussian $i \in G^t$ with scales $S_i = (s_1, s_2, s_3)$ [S1]:
    $$ L_{scale} = \sum_{i \in G^t} \left( \lambda_{min} |\min(s_1, s_2, s_3)| + \lambda_{max} |\max(s_1, s_2, s_3) - \rho| \right) $$
    This suppresses excessive expansion and aligns scales with the mesh surface [S1].

4.  **Compute Projection Loss ($L_{proj}$):**
    For each tightly-bound Gaussian $i \in G^t$ [S1]:
    a. Identify the closest mesh face $f_j$ with vertex $v_i$ [S1].
    b. Calculate the projection of center $P_i$ onto the surface defined by $f_j$. The source formula is:
    $$ s_i = P_i + ((P_i - v_i) \cdot f_j) \cdot f_j $$
    [S1]
    *Note: The source formula uses $f_j$ as a vector in the projection term. In standard geometry, $f_j$ usually denotes the face, and the projection requires the face normal or plane equation. The source explicitly writes $f_j$ in the dot product and multiplication, implying $f_j$ might be treated as a normal vector or the source notation is simplified. We implement exactly as written in [S1].*
    c. Accumulate loss:
    $$ L_{proj} = \sum_{i \in G^t} \| s_i - P_i \|_2 $$
    [S1]

5.  **Compute Total Loss:**
    $$ L = L_{img} + \lambda_{nc} L_{nc} + L_{scale} + \lambda_{proj} L_{proj} $$
    [S1]

6.  **Densification Strategy:**
    Densification is applied differently based on the Gaussian type [S1]:
    - **Loosely-bound ($G^l$):** Follow the original 3DGS densification strategy (gradient-based cloning and splitting) [S1].
    - **Tightly-bound ($G^t$):**
        a. Identify the mesh triangle close to the Gaussian [S1].
        b. Perform point sampling from the triangle surface [S1].
        c. Use the sampled position to initialize new Gaussian splats [S1].
        d. **Cloning:** Copy additional attributes from the parent Gaussian to the new Gaussian [S1].
        e. **Splitting:** Divide the scale of the new Gaussian by a factor of 1.6 [S1].

**Pseudocode:**

```python
def compute_loss(G_t, G_l, mesh, rendered_image, gt_image, params):
    # 1. Image Loss
    l1_loss = L1(rendered_image, gt_image)
    ssim_loss = SSIM(rendered_image, gt_image)
    L_img = (1 - params.lambda_img) * l1_loss + params.lambda_img * ssim_loss

    # 2. Normal Consistency Loss
    L_nc = 0.0
    for g in G_t:
        # Find min scale axis
        scales = g.scale # (s1, s2, s3)
        min_idx = argmin(scales)
        # Compute normal from rotation and min scale axis
        # Basis vector for min_idx is e_min_idx
        n_i = apply_rotation(g.rotation, e_min_idx)
        
        # Find closest face f in mesh
        f = mesh.get_closest_face(g.center)
        n_f = f.normal
        
        L_nc += (1.0 - dot(n_i, n_f))
    L_nc = L_nc # Sum is implicit in loop accumulation if normalized, but source sums over i,f
    # Source: sum_{i in G^t, f in F} (1 - n_i . n_f). 
    # Implementation note: Source implies summing over all pairs or closest pairs?
    # Text says "corresponding face normals". We assume closest face per Gaussian.
    
    # 3. Scale Regularization Loss
    L_scale = 0.0
    for g in G_t:
        scales = g.scale
        min_s = min(scales)
        max_s = max(scales)
        term1 = params.lambda_min * abs(min_s)
        term2 = params.lambda_max * abs(max_s - params.rho)
        L_scale += (term1 + term2)
        
    # 4. Projection Loss
    L_proj = 0.0
    for g in G_t:
        f = mesh.get_closest_face(g.center)
        v_i = f.vertex # Source uses v_i, likely a vertex of the face
        # Source formula: s_i = P_i + ((P_i - v_i) . f_j) * f_j
        # Assuming f_j in formula refers to the face normal or vector used for projection
        # Given the ambiguity, we use the face normal as the projection direction if f_j is normal
        # OR if f_j is the vector from v_i to another vertex? 
        # Source eq 7: s_i = P_i + ((P_i - v_i) . f_j) * f_j
        # This is a projection onto the line defined by f_j? Or plane?
        # Standard projection onto plane with normal n: P - ((P-v).n)n
        # The source formula has a + sign and multiplies by f_j.
        # If f_j is the normal, this adds the component along the normal.
        # We implement exactly as source:
        f_j = f.normal # Assuming f_j represents the normal vector in the formula context
        diff = g.center - v_i
        projection_component = dot(diff, f_j) * f_j
        s_i = g.center + projection_component
        L_proj += norm(s_i - g.center)
        
    # 5. Total Loss
    L = L_img + params.lambda_nc * L_nc + L_scale + params.lambda_proj * L_proj
    return L

def densify(G_t, G_l, mesh, params):
    # Loosely-bound: Standard 3DGS
    G_l = densify_3dgs(G_l)
    
    # Tightly-bound: Mesh-based
    new_G_t = []
    for g in G_t:
        if needs_splitting(g):
            f = mesh.get_closest_face(g.center)
            # Sample point from triangle f
            p_sample = sample_triangle(f)
            # Create new Gaussian
            new_g = Gaussian()
            new_g.center = p_sample
            new_g.scale = g.scale / 1.6
            # Copy other attributes
            new_g.rotation = g.rotation
            new_g.color = g.color
            new_g.opacity = g.opacity
            new_G_t.append(new_g)
        elif needs_cloning(g):
            f = mesh.get_closest_face(g.center)
            p_sample = sample_triangle(f)
            new_g = Gaussian()
            new_g.center = p_sample
            # Copy attributes
            new_g.scale = g.scale
            new_g.rotation = g.rotation
            new_g.color = g.color
            new_g.opacity = g.opacity
            new_G_t.append(new_g)
            
    return G_t + new_G_t
```

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Performance:** Evaluated on Mip-NeRF360 and Deep Blending datasets [S1].
- **Strengths:** Prevents tightly-bound splats from expanding excessively or drifting from the mesh surface [S1].
- **Limitations:** Relies on an existing mesh $M$ [S1].
- **When to use:** When high-quality rendering aligned with an explicit mesh geometry is required [S1].
- **When not:** When no mesh is available or when loose geometry is acceptable [S1].

## Background
Originated in **MeshGS: Adaptive Mesh-Aligned Gaussian Splatting for High-Quality Rendering** [S1]. It builds on 3DGS [22] and LTM [7] for mesh extraction. The method distinguishes between tightly-bound and loosely-bound splats to apply mesh-specific constraints only where appropriate [S1].
