# Curriculum Learning with Slice and Voxel Supervision

Also called: Slice and Voxel Supervision Curriculum

## Overview
This method addresses the instability and incomplete volumetric reconstruction inherent in optimizing 3D Gaussian representations for shear-warp rendering by structuring the training process into distinct supervision phases [S1]. It sets itself apart from sibling methods like [Hybrid Coarse-to-Fine Strategy](7173-hybrid-coarse-to-fine-strategy.md) and [Training Objective and Densification](7448-training-objective-and-densification.md) by explicitly decoupling local planar constraint learning from global volumetric consistency, ensuring the Gaussian kernels align with the slice-based nature of the target renderer [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of multimodal volumetric datasets (e.g., MRI, Cryosection) represented as a voxel grid; a target number of Gaussian kernels $m$.
*   **Output:** A set of Gaussian kernels $\mathcal{G} = \{G_1, G_2, \dots, G_m\}$ optimized for shear-warp visualization [S1].

**Data Structures:**
Each Gaussian kernel $G_i$ is initialized at a sampled voxel position and contains learnable parameters:
*   Mean $\mu \in \mathbb{R}^3$: Center position in 3D space [S1].
*   Covariance $\Sigma \in \mathbb{R}^{3 \times 3}$: Shape and orientation (implied by "Gaussian kernels" and standard 3DGS literature, though specific parameterization is not detailed in the source text beyond "associated learnable parameters") [S1].
*   Opacity $\alpha \in [0, 1]$: Transparency (standard for Gaussian splatting, implied by rendering context) [S1].
*   Color $c \in \mathbb{R}^3$: Radiance (implied by "rendered views" and "texture continuity") [S1].

**Numbered Steps:**
1.  **Initialization:** Estimate $m$ voxel samples from the input voxel grid. Initialize one Gaussian kernel $G_i$ centered at each sampled voxel position $v_i$ [S1].
2.  **Phase 1: Slice Supervision:**
    *   In each training iteration, sample a plane with arbitrary orientation [S1].
    *   Select sparse pixels on the sampled plane [S1].
    *   Map each selected pixel to a 3D voxel coordinate [S1].
    *   Compute the rendering of the current Gaussian set through this plane (simulating a slice) and compare against the ground-truth voxel values at those coordinates [S1].
    *   Update Gaussian parameters to minimize the difference, leveraging the planar constraints to capture local geometric structure and texture continuity [S1].
3.  **Phase 2: Voxel Supervision:**
    *   After establishing structural stability via slices, introduce voxel supervision [S1].
    *   Perform random sampling with dense approximation across the volume [S1].
    *   Compute the rendering of the Gaussian set at these random 3D positions and compare against ground-truth voxel values [S1].
    *   Update Gaussian parameters to ensure global spatial guidance and volumetric consistency [S1].

**Formulas:**
The source text does not provide explicit loss functions or rendering equations. The optimization minimizes a loss $\mathcal{L}$ between the rendered slice/voxel values and ground truth. Let $R(G, p)$ be the rendered value at position $p$ given Gaussians $G$.
*   Slice Loss: $\mathcal{L}_{slice} = \sum_{p \in \text{slice pixels}} \| R(G, p) - V(p) \|^2$ [G: Standard MSE assumption for volumetric reconstruction].
*   Voxel Loss: $\mathcal{L}_{voxel} = \sum_{p \in \text{random voxels}} \| R(G, p) - V(p) \|^2$ [G: Standard MSE assumption].
*   Total Loss: $\mathcal{L} = \mathcal{L}_{slice} + \lambda \mathcal{L}_{voxel}$ [G: Weighting factor $\lambda$ is not specified in sources].

**Parameters:**
*   Number of Gaussians $m$: Not given in the sources.
*   Sampling density for slices: "Sparse pixels" [S1].
*   Sampling density for voxels: "Random sampling with dense approximation" [S1].
*   Training schedule: Phase 1 (Slices) followed by Phase 2 (Voxels) [S1].

**Edge Cases and Pitfalls:**
*   **Instability with Random Voxels First:** Applying random voxel supervision before stable global constraints are established leads to unstable learning of Gaussian parameters [S1].
*   **Lack of Global Guidance with Slices Only:** Using only slice supervision limits accurate reconstruction of the full volumetric structure because slices cover limited regions at each iteration, lacking global spatial guidance [S1].
*   **Arbitrary Plane Orientation:** The method samples planes with arbitrary orientation, which requires robust mapping from 2D pixel coordinates to 3D voxel coordinates [S1].

**Pseudocode:**
```python
def train_gaussian_volumetric(voxel_grid, num_gaussians, num_slice_iters, num_voxel_iters):
    # Initialize Gaussians from voxel samples
    voxel_samples = sample_voxels(voxel_grid, num_gaussians)
    gaussians = [Gaussian(center=v) for v in voxel_samples]
    
    # Phase 1: Slice Supervision
    for i in range(num_slice_iters):
        # Sample a plane with arbitrary orientation
        plane = sample_arbitrary_plane()
        # Select sparse pixels on the plane
        slice_pixels = select_sparse_pixels(plane)
        
        # Map pixels to 3D voxel coordinates
        voxel_coords = map_pixels_to_voxels(plane, slice_pixels)
        
        # Render and compute loss
        rendered_values = render_slice(gaussians, plane)
        ground_truth_values = get_voxel_values(voxel_grid, voxel_coords)
        loss_slice = compute_loss(rendered_values, ground_truth_values)
        
        # Update Gaussians
        update_gaussians(gaussians, loss_slice)
        
    # Phase 2: Voxel Supervision
    for i in range(num_voxel_iters):
        # Random sampling with dense approximation
        random_voxels = sample_random_voxels_dense(voxel_grid)
        
        # Render and compute loss
        rendered_values = render_voxels(gaussians, random_voxels)
        ground_truth_values = get_voxel_values(voxel_grid, random_voxels)
        loss_voxel = compute_loss(rendered_values, ground_truth_values)
        
        # Update Gaussians
        update_gaussians(gaussians, loss_voxel)
        
    return gaussians
```

## Subtopics

### Curriculum Learning with Sparse Voxel and Slice Sampling
This variant explicitly combines sparse voxel sampling (for global coverage) with slice-based sampling (for spatially correlated regions encoding geometric structure and texture continuity) [S1]. It aligns with shear-warp volume rendering, which generates images from stacks of 2D slices [S1]. In each iteration, a plane with arbitrary orientation is sampled, sparse pixels are selected, and each pixel is mapped to a 3D voxel coordinate, allowing the Gaussian representation to learn spatial continuity across neighboring regions [S1].

## Operating characteristics
**Time and Memory Complexity:**
Not given in the sources.

**Measured Performance:**
*   Combining slice and voxel supervision yields higher PSNR and SSIM compared to using only slice supervision [S1].
*   Using only slice supervision (A4) limits accurate reconstruction of the full volumetric structure due to lack of global spatial guidance [S1].
*   Random voxel sampling without structured slice supervision leads to unstable global approximation [S1].
*   MCE (Maximum Cell Error) based voxel supervision improves coverage of informative regions but shows lower performance in rendered views without slice supervision [S1].

**Strengths and Limitations:**
*   **Strengths:** Efficiently learns both global volumetric consistency and local anatomical details; aligns naturally with shear-warp rendering; supports real-time selective visualization for multimodal datasets (MRI, Cryosection) [S1].
*   **Limitations:** Requires careful sequencing of supervision phases; random voxel sampling alone is unstable; slice-only supervision lacks global context [S1].

**When to Use:**
Use when optimizing Gaussian representations for shear-warp visualization of volumetric data (e.g., medical imaging) where both global structure and local texture continuity are critical [S1].

## Background
This method was proposed in the context of Gaussian Volumetric Shear-Warp Visualization for efficient reconstruction and visualization of volumetric medical data [S1]. It builds on the principles of curriculum learning [37] (cited in S1) and 3D Gaussian Splatting [10] (cited in S1). The approach is applicable to multimodal volumetric datasets including MRI and Cryosection volumes [S1].
