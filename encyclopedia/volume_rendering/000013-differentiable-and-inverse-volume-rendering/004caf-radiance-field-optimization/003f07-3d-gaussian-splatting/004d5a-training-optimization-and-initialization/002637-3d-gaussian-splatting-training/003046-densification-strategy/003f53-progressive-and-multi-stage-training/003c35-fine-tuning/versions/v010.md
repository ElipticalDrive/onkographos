# Fine-tuning
Also called: 3DGS Fine-tuning, Gaussian Splatting Fine-tuning
## Overview
Fine-tuning is a training strategy for 3D Gaussian Splatting (3DGS) that initializes the scene representation using a direct feed-forward prediction of geometry and color attributes, followed by differentiable optimization to refine these primitives [S1]. It solves the problem of slow convergence and high memory overhead in standard 3DGS by leveraging pretrained priors to generate a redundant but high-quality initial set of Gaussians, which are then optimized and pruned [S1]. It sets itself apart from sibling methods like [Hybrid Coarse-to-Fine Strategy](7173-hybrid-coarse-to-fine-strategy.md) by replacing manual coarse-to-fine initialization with a learned feed-forward prior, and from [Training Objective and Densification](7448-training-objective-and-densification.md) by explicitly enabling growing and pruning during the fine-tuning phase to reduce the initial redundancy [S1].
## How it works
**Inputs:**
- A set of input images with known camera poses.
- A pretrained feed-forward network capable of predicting 3D Gaussian attributes (mean, covariance, opacity, spherical harmonics coefficients) from input views [S1].

**Outputs:**
- A refined set of 3D Gaussian primitives optimized for novel view synthesis [S1].

**Data Structures:**
- The scene is represented as a set of $N$ 3D Gaussians. Each Gaussian $i$ is defined by:
  - Mean position $\mu_i \in \mathbb{R}^3$
  - Covariance matrix $\Sigma_i \in \mathbb{R}^{3 \times 3}$ (parameterized as rotation $R_i \in SO(3)$ and scale $s_i \in \mathbb{R}^3$)
  - Opacity $\alpha_i \in [0, 1]$
  - Spherical Harmonics (SH) coefficients $c_{i, l}$ for color representation [S1].
- The feed-forward network outputs these attributes directly for initialization [S1].

**Steps:**
1. **Feed-Forward Initialization:** Pass the input images through the pretrained feed-forward network to predict an initial set of 3D Gaussian primitives. This step generates both geometry (means, covariances) and color attributes (opacity, SH coefficients) simultaneously [S1].
2. **Differentiable Optimization:** Optimize all geometry and color attributes of the initialized Gaussians using differentiable rasterization. The optimization follows the vanilla 3DGS pipeline, minimizing a loss function that typically includes photometric reconstruction loss and structural similarity (SSIM) loss [S1].
3. **Growing and Pruning:** Enable densification mechanisms during fine-tuning. Specifically:
   - **Pruning:** Remove redundant Gaussians that have low opacity or contribute negligibly to the scene, significantly reducing the total number of primitives compared to the initial feed-forward output [S1].
   - **Growing:** Insert new Gaussians in regions with high reconstruction error to capture details missed by the initial prediction [S1].
4. **Convergence:** Continue optimization until the model achieves photorealism, leveraging the pretrained priors for faster convergence compared to training from scratch [S1].

**Formulas:**
- The optimization minimizes a loss function $\mathcal{L}$:
  $$ \mathcal{L} = \mathcal{L}_{\text{recon}} + \lambda_{\text{ssim}} \mathcal{L}_{\text{ssim}} + \lambda_e \mathcal{L}_{\text{entropy}} $$
  where $\mathcal{L}_{\text{recon}}$ is the photometric loss, $\mathcal{L}_{\text{ssim}}$ is the SSIM loss, and $\mathcal{L}_{\text{entropy}}$ is an entropy regularization term [S1].
- $\lambda_{\text{ssim}}$ and $\lambda_e$ are weighting hyperparameters [S1].

**Parameters:**
- Optimizer: Adam [S1].
- Learning Rate: $1 \times 10^{-3}$ [S1].
- Libraries: `torchsparse` for 3D sparse convolution and `gsplat` for Gaussian rasterization [S1].

**Edge Cases and Pitfalls:**
- The initial feed-forward prediction may produce redundant Gaussians, requiring effective pruning to manage memory [S1].
- If the pretrained prior is not well-aligned with the target scene, the fine-tuning process may converge to a suboptimal local minimum [G].
- The balance between growing and pruning must be carefully tuned to avoid overfitting or under-representing the scene [S1].

**Pseudocode:**
```python
# Initialize scene with feed-forward network
gaussians = feed_forward_network(input_images)

# Define optimizer
optimizer = Adam(gaussians.parameters(), lr=1e-3)

# Training loop
for iteration in range(total_iterations):
    # Sample a random view
    view = sample_random_view(input_images)
    
    # Render the view using differentiable rasterization
    rendered_image = rasterize(gaussians, view)
    
    # Compute loss
    loss = compute_loss(rendered_image, view.target_image)
    
    # Backpropagate and update
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    
    # Periodic growing and pruning
    if iteration % densification_interval == 0:
        gaussians = densify_and_prune(gaussians, view)
```
Note: `densify_and_prune` implements the growing and pruning logic described in the parent article [Progressive and Multi-stage Training](9966-progressive-and-multi-stage-training.md) and specific to the EVolSplat implementation [S1].
## Subtopics

### [Exponentially Ascending Gradient Threshold](9684-exponentially-ascending-gradient-threshold.md)
A densification control mechanism that dynamically adjusts the gradient threshold for splitting and cloning Gaussians based on training progress, balancing early-stage convergence speed and late-stage overfitting.

### [Hard Gaussian Splatting](10590-hard-gaussian-splatting.md)
A strategy that identifies and refines "hard Gaussians" causing artifacts by using multi-view positional gradients and rendering error analysis, improving detail recovery in defective regions.

### [SplatFormer Training Objective & Refinement](11745-splatformer-training-objective-refinement.md)
A learning-based refinement module that predicts attribute residuals to improve generalization to out-of-distribution camera angles, ensuring geometric consistency.

### [MCMC-based 3DGS / SGLD for 3DGS](11917-mcmc-based-3dgs-sgld-for-3dgs.md)
A probabilistic approach that reformulates 3DGS updates as Stochastic Gradient Langevin Dynamics, removing the need for manual densification heuristics by introducing noise for sample exploration.

### [Deblurring 3D Gaussian Splatting](12318-deblurring-3d-gaussian-splatting.md)
A real-time framework that reconstructs sharp scenes from blurry inputs by manipulating Gaussian covariance and means via an MLP, handling defocus and motion blur.

### [Supplementary Point Addition for Sparse Point Clouds](12323-supplementary-point-addition-for-sparse-point-clouds.md)
A technique that supplements sparse SfM point clouds with synthetic points to improve coverage in far-end regions of defocus-blurry scenes.

### [Gaussian Volume Mask](12710-gaussian-volume-mask.md)
A strategy that reduces active Gaussians by applying binary masks to scale and opacity based on a learnable parameter, addressing excessive memory usage from redundant primitives.

## Operating characteristics
- **Time Complexity:** Faster convergence compared to training from scratch due to pretrained priors [S1].
- **Memory Complexity:** Initial memory usage is high due to redundant feed-forward predictions, but pruning reduces this significantly during fine-tuning [S1].
- **Performance:** Achieves photorealism on par with or surpassing other methods, particularly in urban view synthesis [S1].
- **Strengths:** Accelerated training, reduced memory consumption post-pruning, high fidelity [S1].
- **Limitations:** Relies on the quality of the pretrained feed-forward network; may require careful tuning of densification parameters [S1].
- **When to Use:** When fast convergence and high fidelity are required, and a suitable pretrained model is available [S1].
- **When Not to Use:** When the target scene domain differs significantly from the pretrained prior's training data, potentially leading to poor initialization [G].
## Background
Fine-tuning in the context of 3D Gaussian Splatting was introduced in the EVolSplat paper, which proposed using a direct feed-forward process to initialize 3D Gaussian primitives for efficient volume-based Gaussian Splatting in urban view synthesis [S1]. The method leverages pretrained weights to accelerate network training and enable faster convergence compared to test-time optimization methods [S1].
