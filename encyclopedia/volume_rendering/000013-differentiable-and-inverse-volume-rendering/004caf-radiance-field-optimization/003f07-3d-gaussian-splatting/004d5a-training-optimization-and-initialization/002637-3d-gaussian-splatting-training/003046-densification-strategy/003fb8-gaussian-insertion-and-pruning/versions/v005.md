# Gaussian Insertion and Pruning

Also called: Monocular Gaussian Initialization

## Overview
Gaussian Insertion and Pruning is a dynamic population management strategy used in monocular and RGB-D Gaussian Splatting SLAM systems to maintain a coherent 3D structure while tracking camera motion [S1, unofficial]. Unlike static densification methods that rely solely on gradient magnitude, this method inserts new Gaussians at keyframes to capture newly visible scene elements and prunes geometrically unstable primitives based on multi-view visibility consistency [S1, unofficial]. It addresses the problem of drift and floating artifacts in SLAM by ensuring that only Gaussians observed across multiple frames in the current keyframe window are retained [S1, unofficial].

## How it works
**Inputs:**
*   Current keyframe window $W_k$ of size $|W_k|$ (e.g., 10 for Replica, 8 for TUM) [S1, unofficial].
*   Rendered depth map $D$ for the current view [S1, unofficial].
*   Median depth $\hat{D}$ of the rendered image [S1, unofficial].
*   Depth standard deviation $\sigma_D$ [S1, unofficial].
*   Opacity threshold $\alpha_{min} = 0.7$ [S1, unofficial].
*   Pruning history: list of Gaussians inserted in the last 3 keyframes [S1, unofficial].

**Outputs:**
*   Updated set of 3D Gaussians $\mathcal{G}$ with new insertions and pruned entries.

**Data Structures:**
*   **Keyframe Window $W_k$:** A fixed-size buffer storing the most recent keyframes. Pruning only occurs once $|W_k|$ is full [S1, unofficial].
*   **Visibility Buffer:** A Gaussian is marked as visible from a view if it was used in rasterization and the ray's accumulated $\alpha$ had not yet reached 0.5 [S1, unofficial].

**Steps:**

1.  **Initialization of New Gaussians:**
    At every keyframe, new Gaussians are inserted to capture newly visible elements [S1, unofficial].
    *   **RGB-D Case:** If depth measurements are available, initialize Gaussian means $\mu_W$ by back-projecting the depth [S1, unofficial].
    *   **Monocular Case:** Render depth $D$ at the current frame. Initialize $\mu_W$ based on pixel depth availability:
        *   For pixels $p$ where rendered depth $D_p$ exists, sample depth from a normal distribution:
            $$ \mu_W \sim \mathcal{N}(D_p, 0.2\sigma_D) $$
        *   For unobserved regions (no depth estimate), initialize around the median depth $\hat{D}$ with high variance:
            $$ \mu_W \sim \mathcal{N}(\hat{D}, 0.5\sigma_D) $$
        [S1, unofficial]

2.  **Visibility-Based Pruning:**
    This step removes geometrically unstable Gaussians that fail to maintain multi-view consistency [S1, unofficial].
    *   **Condition:** Only perform this pruning once the keyframe window $W_k$ is full [S1, unofficial].
    *   **Target:** Gaussians inserted within the last 3 keyframes [S1, unofficial].
    *   **Criterion:** If a Gaussian is unobserved by at least 3 other frames within the current window $W_k$, it is pruned [S1, unofficial].

3.  **Opacity Pruning:**
    *   Remove all Gaussians with opacity $\alpha < 0.7$ [S1, unofficial].

**Pseudocode:**

```python
def gaussian_insertion_and_pruning(keyframe_window, current_depth_map, median_depth, depth_std_dev, opacity_threshold=0.7):
    """
    Inserts new Gaussians based on depth and prunes unstable ones based on visibility.
    
    Args:
        keyframe_window (list): List of recent keyframes.
        current_depth_map (array): Rendered depth D for the current view.
        median_depth (float): Median depth D_hat of the rendered image.
        depth_std_dev (float): Standard deviation sigma_D.
        opacity_threshold (float): Minimum opacity alpha_min.
        
    Returns:
        updated_gaussians (list): The modified set of Gaussians.
    """
    # Step 1: Insert new Gaussians
    new_gaussians = []
    for pixel in current_depth_map:
        if pixel.has_depth:
            # Sample from N(D_p, 0.2 * sigma_D)
            depth_sample = random_gaussian(pixel.depth, 0.2 * depth_std_dev)
        else:
            # Sample from N(D_hat, 0.5 * sigma_D)
            depth_sample = random_gaussian(median_depth, 0.5 * depth_std_dev)
        
        # Initialize Gaussian mean mu_W at this depth
        g_new = create_gaussian(mean=depth_sample)
        new_gaussians.append(g_new)
    
    # Add new Gaussians to the main set
    all_gaussians.extend(new_gaussians)
    
    # Step 2: Visibility-Based Pruning
    # Only prune if the keyframe window is full
    if len(keyframe_window) >= keyframe_window.max_size:
        # Identify Gaussians inserted in the last 3 keyframes
        recently_inserted = get_gaussians_inserted_in_last_n_keyframes(3)
        
        for g in recently_inserted:
            # Count how many frames in the window observed this Gaussian
            # Visibility defined as: used in rasterization AND accumulated alpha < 0.5
            observation_count = count_frames_observing_gaussian(g, keyframe_window)
            
            # Prune if unobserved by at least 3 other frames
            # Note: "unobserved by at least 3" implies observation_count <= (Window_Size - 3)
            # However, the source states "unobserved by at least 3 other frames",
            # which typically means it was seen in <= (Total_Frames - 3) frames.
            # Given the phrasing "unobserved by at least 3", we check if the number
            # of frames where it was NOT observed is >= 3.
            frames_unobserved = len(keyframe_window) - observation_count
            if frames_unobserved >= 3:
                mark_for_removal(g)
    
    # Step 3: Opacity Pruning
    for g in all_gaussians:
        if g.opacity < opacity_threshold:
            mark_for_removal(g)
            
    # Remove marked Gaussians
    updated_gaussians = remove_marked(all_gaussians)
    return updated_gaussians
```

## Operating characteristics
*   **Complexity:** Insertion is $O(P)$ where $P$ is the number of pixels processed for depth sampling. Pruning is $O(N \cdot |W_k|)$ where $N$ is the number of recently inserted Gaussians and $|W_k|$ is the window size, as each candidate must be checked against all frames in the window for visibility [S1, unofficial].
*   **Strengths:** Effectively removes "floaters" and geometrically unstable Gaussians in SLAM contexts without requiring strong depth priors [S1, unofficial]. The variance-based initialization accounts for incorrect depth estimates [S1, unofficial].
*   **Limitations:** Relies on the accuracy of rendered depth in monocular settings. Pruning is delayed until the keyframe window is full, which may allow unstable Gaussians to persist temporarily [S1, unofficial].
*   **When to use:** Monocular or RGB-D Gaussian Splatting SLAM systems where maintaining a consistent 3D map is critical [S1, unofficial].

## Background
This method was introduced in "Gaussian Splatting SLAM" [S1, unofficial]. It extends the static 3D Gaussian Splatting rendering technique to simultaneous localization and mapping (SLAM) by dynamically managing the Gaussian population. The approach is designed to handle the challenges of monocular depth estimation and multi-view consistency in real-time mapping [S1, unofficial].
