# Straight-Through Estimator (STE) for Confidence Scores

Also called: Straight-Through Estimator for Gradient Extension

## Overview
The Straight-Through Estimator (STE) for confidence scores is a gradient approximation technique used in voxel selection schemes to enable backpropagation through discrete selection decisions [S1, unofficial]. It extends gradients beyond the hard selection boundary to prevent optimization stalling [S2].

## How it works
The method is applied within a voxel selection framework where each voxel $v$ is assigned a learned confidence score $c_v$ [S1, unofficial].

**Inputs and Outputs:**
- Input: Confidence scores $\{c_v\}$ for candidate voxels.
- Output: A binary selection mask $m_v \in \{0, 1\}$ and gradients $\frac{\partial \mathcal{L}}{\partial c_v}$ for optimization [S1, unofficial].

**Data Structures:**
- Confidence scores: A tensor of floating-point values, typically in $[0, 1]$ [G].
- Selection mask: A binary tensor of the same shape as the confidence scores [G].

**Steps:**
1. **Forward Pass (Hard Selection):** Compute the binary mask $m_v$ using a threshold $\tau$:
   $$
   m_v = \begin{cases} 
   1 & \text{if } c_v > \tau \\
   0 & \text{otherwise}
   \end{cases}
   $$
   The rendering pipeline uses only voxels where $m_v = 1$ [S1, unofficial]. The threshold $\tau$ is a scalar cutoff value [G].
2. **Backward Pass (Straight-Through):** Compute gradients by ignoring the discontinuity of the thresholding operation, passing the upstream gradient directly to $c_v$ [G].

**Parameters:**
- Threshold $\tau$: A scalar cutoff value [G]. In comparative experiments, it is evaluated alongside opacity-based thresholding (OBT) which uses a predefined threshold of $0.005$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Limited Selection:** Simply applying STE to confidence scores results in selecting an extremely limited number of voxels, degrading rendering quality [S1, unofficial].
- **Optimization Stalling:** Without extending gradients beyond the primitive boundary, optimization may stall; STE handles this by allowing gradient flow even where the boundary is hard or truncated [S2].

**Pseudocode:**
```python
def ste_threshold_forward(confidence_scores, threshold):
    # Forward pass: hard thresholding to binary mask
    mask = (confidence_scores > threshold).float()
    return mask

def ste_threshold_backward(grad_output, confidence_scores, threshold):
    # Backward pass: straight-through estimator
    # Pass upstream gradient directly, ignoring the non-differentiable threshold
    return grad_output
```

## Subtopics

### Opacity-Based Thresholding (OBT)
Uses a fixed opacity threshold (e.g., 0.005) to select voxels [S1, unofficial]. It is simple but requires manual tuning and can be unreliable for object-centric selection [S1, unofficial].

### Gumbel-Sigmoid Relaxation
Uses a stochastic relaxation of the selection process to allow differentiable optimization [S1, unofficial]. It generally yields better voxel selection and rendering quality than STE [S1, unofficial].

### Deterministic Sigmoid
Replaces Gumbel-Sigmoid with a standard sigmoid function [S1, unofficial]. This fails to properly select object-centric voxels and leads to significant rendering quality drops [S1, unofficial].

## Operating characteristics
- **Time Complexity:** The forward pass is $O(N)$ where $N$ is the number of voxels [G]. The backward pass is also $O(N)$ as it involves a simple element-wise operation [G].
- **Memory Complexity:** $O(N)$ to store the confidence scores and the selection mask [G].
- **Performance:** On the CO3D dataset, using STE for voxel selection resulted in a PSNR of 14.71, SSIM of 0.814, and LPIPS of 0.317, with only 121 voxels selected [S1, unofficial]. This is significantly worse than the proposed VS-Splat method (PSNR 21.31, 19,587 voxels) [S1, unofficial].
- **Strengths:** Simple to implement; enables gradient flow through hard selection boundaries [G].
- **Limitations:** Can lead to very sparse voxel selection and poor rendering quality if not carefully tuned [S1, unofficial].

## Background
The Straight-Through Estimator is a common technique in differentiable programming to handle non-differentiable operations [G]. In the context of 3D Gaussian Splatting and voxel selection, it was explored as a variant of the VS-Splat framework to enable gradient flow to confidence scores [S1, unofficial]. It is also used in radiance field methods, such as Fourier Splatting, to extend gradients beyond primitive boundaries and prevent optimization stalling [S2].
