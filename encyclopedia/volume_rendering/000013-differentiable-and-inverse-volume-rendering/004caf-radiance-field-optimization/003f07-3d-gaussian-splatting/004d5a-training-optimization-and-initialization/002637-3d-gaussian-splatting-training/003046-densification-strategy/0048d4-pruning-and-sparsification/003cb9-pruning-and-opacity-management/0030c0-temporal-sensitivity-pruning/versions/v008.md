# Temporal Sensitivity Pruning


## Overview
Temporal Sensitivity Pruning (TSP) is a pruning method for dynamic 3D Gaussian Splatting that removes low-impact Gaussians by calculating a temporal sensitivity score approximating the second-order sensitivity to the L2 loss across all training views [S1, unofficial]. It sets itself apart from its siblings, such as [Spatially Constrained Optimization](13691-spatially-constrained-optimization.md) which focuses on static spatial density, by explicitly aggregating gradient information over time to identify primitives that are redundant across the temporal sequence of a dynamic scene [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D Gaussians $\mathcal{G} = \{\mathcal{G}_1, \dots, \mathcal{G}_N\}$, where each $\mathcal{G}_i$ includes parameters for position, scale, rotation, opacity, and color. A set of training poses and timesteps $\mathcal{P}_{gt}$.
*   **Output:** A binary mask or list of Gaussians to be pruned based on their computed sensitivity scores.

**Data Structures:**
*   **Sensitivity Buffer:** An array $U$ of size $N$, where $U_i$ stores the cumulative temporal sensitivity score $\tilde{U}_{\mathcal{G}_i}$ for each Gaussian.

**Steps:**
1.  **Initialize:** Set all sensitivity scores $\tilde{U}_{\mathcal{G}_i} = 0$ for $i = 1 \dots N$.
2.  **Iterate Training Data:** For each training pose $\phi$ and timestep $t$ in the set $\mathcal{P}_{gt}$:
    a. Render the scene using the current Gaussian parameters to obtain the image $I_{\mathcal{G}_t}(\phi)$.
    b. Compute the gradient of the rendered image with respect to the projected value $g_i$ of each Gaussian $\mathcal{G}_i$. Let this be $\nabla_{g_i} I_{\mathcal{G}_t}(\phi)$.
    c. Square this gradient: $(\nabla_{g_i} I_{\mathcal{G}_t}(\phi))^2$.
    d. Add the squared gradient to the cumulative score: $\tilde{U}_{\mathcal{G}_i} \leftarrow \tilde{U}_{\mathcal{G}_i} + (\nabla_{g_i} I_{\mathcal{G}_t}(\phi))^2$.
3.  **Prune:** Periodically during training, compare $\tilde{U}_{\mathcal{G}_i}$ against a threshold. Gaussians with scores below the threshold are removed from $\mathcal{G}$ to reduce neural inference load [S1, unofficial].

**Formula:**
The TSP score $\tilde{U}_{\mathcal{G}_i}$ for Gaussian $\mathcal{G}_i$ is defined as:
$$
\tilde{U}_{\mathcal{G}_i} \approx \nabla_{g_i}^2 L_2 \approx \sum_{\phi, t \in \mathcal{P}_{gt}} \left( \nabla_{g_i} I_{\mathcal{G}_t}(\phi) \right)^2
$$
Where:
*   $\tilde{U}_{\mathcal{G}_i}$ is the temporal sensitivity score.
*   $g_i$ is the value of $\mathcal{G}_i$ projected onto image space.
*   $\mathcal{P}_{gt}$ is the set of training poses and timesteps.
*   $I_{\mathcal{G}_t}(\phi)$ is the rendered image at pose $\phi$ and timestep $t$.
*   $\nabla_{g_i} I_{\mathcal{G}_t}(\phi)$ is the gradient of the rendered image with respect to the projected Gaussian value.

**Parameters:**
*   $\mathcal{P}_{gt}$: The set of training poses and timesteps used for sensitivity aggregation. The specific size or sampling strategy is not given in the sources [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Floaters:** TSP relies on gradients from discrete training frames. It may overlook "floaters"—unstable Gaussians that appear static in observed views but drift at unseen timestamps. This is a known limitation addressed by the sibling method [Temporal Sensitivity Sampling](11423-sensitivity-calculation-and-pruning.md) [S1, unofficial].
*   **Deformation Variance:** Since deformation updates vary across timesteps, gradients are inherently time-dependent. The score captures second-order effects of each Gaussian and its deformations on the dynamic scene reconstruction [S1, unofficial].

**Pseudocode:**
```python
def compute_temporal_sensitivity(Gaussians, P_gt):
    """
    Computes the temporal sensitivity score for each Gaussian.
    
    Args:
        Gaussians: List of Gaussian objects, each having a 'project_value' method 
                   and unique ID.
        P_gt: List of tuples (phi, t) representing training poses and timesteps.
        
    Returns:
        U: Dictionary mapping Gaussian ID to sensitivity score.
    """
    U = {g.id: 0.0 for g in Gaussians}
    
    for phi, t in P_gt:
        # Render scene to get image. 
        # Note: In a real implementation, this involves rasterization.
        # We assume a function 'render_scene' that returns the image and 
        # allows gradient computation w.r.t projected values.
        image, gradients = render_scene_with_gradients(Gaussians, phi, t)
        
        for g in Gaussians:
            # Get gradient of the image w.r.t the projected value of this Gaussian
            grad = gradients[g.id]
            
            # Square and accumulate
            U[g.id] += grad ** 2
            
    return U

def prune_low_sensitivity(Gaussians, U, threshold):
    """
    Removes Gaussians with sensitivity scores below the threshold.
    
    Args:
        Gaussians: List of Gaussian objects.
        U: Dictionary of sensitivity scores.
        threshold: Float. Gaussians with score < threshold are pruned.
        
    Returns:
        Remaining Gaussians.
    """
    remaining = []
    for g in Gaussians:
        if U[g.id] >= threshold:
            remaining.append(g)
        # Else: Gaussian is pruned
    return remaining
```

## Subtopics

### [Sensitivity Calculation and Pruning](11423-sensitivity-calculation-and-pruning.md)
This method eliminates 3D Gaussians that have no impact on training images by calculating a sensitivity score based on the gradient of the total image energy with respect to the Gaussian parameters. It sets itself apart from its parent, [Temporal Sensitivity Pruning](6350-temporal-sensitivity-pruning.md), by focusing on the static contribution to the loss rather than temporal consistency, and from [Statistical Sensitivity-Driven Online Sparsification](14437-statistical-sensitivity-driven-online-sparsification.md) by being a distinct pruning phase rather than an online maintenance mechanism.

## Operating characteristics
*   **Time Complexity:** The sensitivity calculation requires iterating over all training poses and timesteps in $\mathcal{P}_{gt}$ for every Gaussian. If $N$ is the number of Gaussians and $M$ is the number of samples in $\mathcal{P}_{gt}$, the cost is $O(N \cdot M)$ per pruning cycle, assuming constant-time gradient retrieval.
*   **Memory Complexity:** Requires storing the sensitivity score for each Gaussian, $O(N)$.
*   **Performance:** Integrating TSP into DeformableGS accelerates rendering by 6.78× on average while maintaining neural-field fidelity and using 10× fewer primitives [S1, unofficial].
*   **Strengths:** Reduces neural inference load and boosts rendering speed by removing redundant primitives [S1, unofficial]. Stabilizes temporal pruning.
*   **Limitations:** May overlook floaters that are unstable at unseen timestamps because it relies on gradients from discrete training frames [S1, unofficial].

## Background
Temporal Sensitivity Pruning was introduced in the context of Speedy Deformable 3D Gaussian Splatting (SpeeDe3DGS), which bridges the efficiency–fidelity gap in dynamic scene reconstruction [S1, unofficial]. It builds on DeformableGS and is designed to work alongside Temporal Sensitivity Sampling (TSS) and GroupFlow [S1, unofficial].
