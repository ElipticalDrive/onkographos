# Hybrid Gaussian Representation with Geometry-Guided Constraints

Also called: Adaptive Hybrid Representation and TensoSDF Constraints, Hybrid Gaussian Splatting with Geometry Guidance

## Overview
This method is a 3D Gaussian Splatting rendering technique that adaptively selects between 2D and 3D Gaussian primitives based on local geometric cues to reduce redundancy in planar structures while maintaining volumetric accuracy [S1]. It integrates TensoSDF for global geometric consistency, enforcing implicit surface constraints during optimization [S1]. Unlike standard 3DGS which uses only 3D ellipsoids, or 2DGS which uses only tangent planes, this method dynamically switches representations to better fit both thin surfaces and volumetric details [S1]. It builds on [TriplaneGaussian](7558-triplanegaussian.md) by introducing explicit geometry-guided constraints via TensoSDF rather than relying solely on tri-plane initialization [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   Input point cloud (for initialization and surface normals) [S1].
*   Camera poses and images for training [G].
*   Bounding box definition (default: 1m³) [S1].

**Outputs:**
*   Optimized hybrid Gaussian field (mix of 2D and 3D Gaussians) [S1].
*   Optimized TensoSDF tensor factors [S1].
*   Rendered images with improved geometric consistency and PSNR [S1].

### Data Structures

**1. 3D Gaussian Primitive**
*   Center: $\mu \in \mathbb{R}^3$ [S1].
*   Covariance: $\Sigma \in \mathbb{R}^{3 \times 3}$ (symmetric positive definite) [S1].
*   Opacity: $\alpha \in \mathbb{R}$ [S1].
*   Color: $c \in \mathbb{R}^3$ (or SH coefficients) [S1].
*   Type: `3D` [S1].

**2. 2D Gaussian Primitive**
*   Center: $\mu \in \mathbb{R}^3$ [S1].
*   Tangent Basis: $T = [t_1, t_2] \in \mathbb{R}^{3 \times 2}$ (orthonormal vectors spanning the tangent plane) [S1].
*   Surface Normal: $n \in \mathbb{R}^3$ (derived from $T$ or stored explicitly) [S1].
*   Scale Matrix: $\Lambda = \text{diag}(\sigma_1^2, \sigma_2^2) \in \mathbb{R}^{2 \times 2}$ [S1].
*   Opacity: $\alpha \in \mathbb{R}$ [S1].
*   Color: $c \in \mathbb{R}^3$ [S1].
*   Type: `2D` [S1].

**3. TensoSDF Tensor Factors**
*   $A_x \in \mathbb{R}^{N_x \times r}$, $A_y \in \mathbb{R}^{N_y \times r}$, $A_z \in \mathbb{R}^{N_z \times r}$ [S1].
*   Parameters: $N_x=N_y=N_z=128$, $r=32$ [S1].

### Parameters
*   $\tau$: Curvature threshold for initial type selection [S1].
*   $\tau_1$: Gradient magnitude threshold for flat geometry detection ($\tau_1 = 0.1$) [S1].
*   $\tau_2$: SDF value threshold for proximity to surface ($\tau_2 = 0.05$ m) [S1].
*   $\eta$: Update step size for Gaussian position fine-tuning [S1].
*   $\lambda$: Weight for gradient consistency in TensoSDF loss ($\lambda = 10$) [S1].
*   AR Threshold: Anisotropy Ratio threshold for conversion ($AR < 0.2$) [S1].
*   $\sigma_n$: Small variance added during 2D-to-3D conversion ($\sigma_n = 10^{-4}$) [S1].
*   $N_{neigh}$: Number of neighbors for 2D-to-3D angle check ($N_{neigh} = 10$) [S1].
*   $\theta_{thresh}$: Mean angle threshold for 2D-to-3D conversion ($30^\circ$) [S1].

### Steps

1.  **Initialization**: Establish a complete 3D Gaussian ellipsoidal field based on the input point cloud following the standard 3DGS workflow [S1]. Initialize TensoSDF tensor factors $A_x, A_y, A_z$ with random values from $\mathcal{N}(0, 0.01)$ [S1].
2.  **Curvature Estimation (Initial Type Selection)**: For each 3D Gaussian center $\mu$, perform PCA on the local point cluster to extract eigenvalues $\lambda_1 \ge \lambda_2 \ge \lambda_3$ of the cluster covariance matrix [S1]. Calculate local curvature: $\kappa = (\lambda_2 + \lambda_3) / \lambda_1$ [S1]. If $\kappa < \tau$, convert the 3D Gaussian to a 2D Gaussian (see Step 3). Otherwise, keep as 3D [S1].
3.  **2D Gaussian Initialization**: Set surface normal $n$ as the eigenvector corresponding to the smallest eigenvalue $\lambda_3$ [S1]. Derive tangent plane basis $T = [t_1, t_2]$ via Gram-Schmidt orthogonalization of two random vectors orthogonal to $n$ [S1]. Initialize scale matrix $\Lambda = \text{diag}(\sigma_p^2, \sigma_p^2)$ where $\sigma_p$ is an appropriate initial value [S1]. Keep color and opacity unchanged from the original 3D Gaussian [S1].
4.  **Adaptive Conversion (3D to 2D)**: For a 3D Gaussian at $\mu$, compute SDF value $d = F(\mu)$ and gradient $g = \nabla F(\mu) / \|\nabla F(\mu)\|$ [S1]. Check proximity: If $\|F(\mu)\| < \tau_2$, check flatness: If $\|\nabla F(\mu)\| < \tau_1$, calculate Anisotropy Ratio: $AR(\mu) = \min(\sigma_1, \sigma_2, \sigma_3) / \max(\sigma_1, \sigma_2, \sigma_3)$, where $\sigma_i$ are eigenvalues of $\Sigma$ [S1]. If $AR(\mu) < 0.2$, convert to 2D Gaussian using the initialization logic in Step 3 [S1].
5.  **Adaptive Conversion (2D to 3D)**: For a 2D Gaussian at $\mu$ with normal $n$, find $N_{neigh}=10$ neighboring Gaussians via k-nearest neighbors [S1]. Compute mean angle $\bar{\theta}$ between $n$ and neighbors' normals $n_i$: $\bar{\theta} = \frac{1}{N_{neigh}} \sum_{i=1}^{N_{neigh}} \arccos\left( \frac{n \cdot n_i}{\|n\| \|n_i\|} \right)$ [S1]. If $\bar{\theta} > 30^\circ$, convert to 3D Gaussian [S1]. Initialize new covariance: $\Sigma' = R(n) \Lambda R(n)^\top + 2\sigma_n^2 n n^\top$, where $\sigma_n = 10^{-4}$ [S1].
6.  **Gaussian Fine-Tuning (Geometry Guidance)**: For each Gaussian center $\mu$, compute SDF value $d = F(\mu)$ and normalized gradient $g = \nabla F(\mu) / \|\nabla F(\mu)\|$ [S1]. Update position: $\mu' = \mu - \eta \cdot d \cdot g$ [S1]. Update covariance: $\Sigma' = R(g) \Sigma R(g)^\top$, where $R(g)$ aligns the principal axis with $g$ [S1]. Compute $R(g)$ using Rodrigues' formula: $R(g) = \cos\theta \cdot I + (1 - \cos\theta) gg^\top + \sin\theta \cdot [g]_\times$, where $\theta = \arccos(v_{max}^\top g)$, $v_{max}$ is the eigenvector of $\Sigma$ corresponding to the largest eigenvalue, and $[g]_\times$ is the skew-symmetric matrix of $g$ [S1].
7.  **Training**: Optimize TensoSDF tensor factors and Gaussian field parameters (positions, covariances, opacities, colors) in parallel [S1]. Compute rendering loss (e.g., L1/SSIM) between rendered and input images [G]. Compute TensoSDF loss $\mathcal{L}_{SDF}$ (see Formulas) [S1]. Backpropagate gradients end-to-end [S1].

### Formulas

**3D Gaussian Density:**
$$ G_{3D}(x) = \exp\left(-\frac{1}{2} (x - \mu)^\top \Sigma^{-1} (x - \mu)\right) $$
where $\mu$ is the center and $\Sigma$ is the covariance matrix [S1].

**2D Gaussian Density:**
$$ G_{2D}(x) = \exp\left(-\frac{1}{2} (T^\top (x - \mu))^\top \Lambda^{-1} (T^\top (x - \mu))\right) $$
where $T = [t_1, t_2]$ is the tangent basis and $\Lambda = \text{diag}(\sigma_1^2, \sigma_2^2)$ is the scale matrix on the tangent plane [S1].

**Local Curvature:**
$$ \kappa = \frac{\lambda_2 + \lambda_3}{\lambda_1} $$
where $\lambda_1 \ge \lambda_2 \ge \lambda_3$ are eigenvalues from PCA on local point clusters [S1].

**Anisotropy Ratio:**
$$ AR(x) = \frac{\min(\sigma_1, \sigma_2, \sigma_3)}{\max(\sigma_1, \sigma_2, \sigma_3)} $$
where $\sigma_1, \sigma_2, \sigma_3$ are eigenvalues of $\Sigma$ sorted descending [S1].

**TensoSDF SDF Function:**
$$ F(x, y, z) \approx \sum_{i=1}^{r} A_x(x, i) \cdot A_y(y, i) \cdot A_z(z, i) $$
where $r$ is the decomposition rank and $A_x, A_y, A_z$ are tensor factors [S1].

**TensoSDF Loss Function:**
$$ \mathcal{L}_{SDF} = \frac{1}{M} \sum_{m=1}^{M} |F(\mu_m)|^2 + \lambda \cdot \frac{1}{M} \sum_{m=1}^{M} \|\nabla F(\mu_m) - n_m\|^2 $$
where $M$ is the number of surface points, $\mu_m$ are Gaussian centers near the surface, $n_m$ are precomputed point cloud normals, and $\lambda = 10$ [S1].

def compute_sdf(coords, Ax, Ay, Az):
    """Compute SDF value using CP decomposition [S1]."""
    # Ax, Ay, Az shape: (Nx, r), (Ny, r), (Nz, r)
    # Interpolate each factor at x, y, z coordinates
    val_x = trilinear_interpolate(Ax, coords[:, 0:1]) # shape (N, r)
    val_y = trilinear_interpolate(Ay, coords[:, 1:2])
    val_z = trilinear_interpolate(Az, coords[:, 2:3])
    # CP sum
    sdf = np.sum(val_x * val_y * val_z, axis=1)
    return sdf

def compute_sdf_gradient(coords, Ax, Ay, Az):
    """Compute gradient of SDF via partial derivatives of tensor factors [S1]."""
    # Compute dF/dx, dF/dy, dF/dz using trilinear derivatives [G]
    grad_x = np.sum(trilinear_interp_grad(Ax, coords[:, 0:1], axis=0) * 
                    trilinear_interpolate(Ay, coords[:, 1:2]) * 
                    trilinear_interpolate(Az, coords[:, 2:3]), axis=1)
    grad_y = np.sum(trilinear_interpolate(Ax, coords[:, 0:1]) * 
                    trilinear_interp_grad(Ay, coords[:, 1:2], axis=1) * 
                    trilinear_interpolate(Az, coords[:, 2:3]), axis=1)
    grad_z = np.sum(trilinear_interpolate(Ax, coords[:, 0:1]) * 
                    trilinear_interpolate(Ay, coords[:, 1:2]) * 
                    trilinear_interp_grad(Az, coords[:, 2:3], axis=2), axis=1)
    return np.stack([grad_x, grad_y, grad_z], axis=1)

def pca_local_cluster(points):
    """Perform PCA on local point cluster [S1]."""
    cov = np.cov(points.T)
    eigenvalues, eigenvectors = np.linalg.eigh(cov)
    idx = np.argsort(eigenvalues)[::-1]
    return eigenvalues[idx], eigenvectors[:, idx]

def gram_schmidt(v1, v2):
    """Orthogonalize v2 against v1 [S1]."""
    u = v2 - np.dot(v2, v1) * v1
    return u / np.linalg.norm(u)

def init_2d_gaussian(mu, eigenvalues, eigenvectors):
    """Initialize 2D Gaussian from PCA results [S1]."""
    n = eigenvectors[:, 2]
    random_vec = np.random.rand(3)
    if np.abs(np.dot(random_vec, n)) > 0.9:
        random_vec = np.array([1.0, 0.0, 0.0])
    t1 = np.cross(n, random_vec)
    t1 = t1 / np.linalg.norm(t1)
    t2 = np.cross(n, t1)
    T = np.column_stack((t1, t2))
    sigma_p = 0.1 # Appropriate initial value [S1]
    Lambda = np.diag([sigma_p**2, sigma_p**2])
    return T, Lambda, n

def rodrigues_rotation(g, v_max):
    """Compute rotation matrix R(g) aligning v_max to g [S1]."""
    cos_theta = np.clip(np.dot(v_max, g), -1.0, 1.0)
    sin_theta = np.sqrt(1 - cos_theta**2)
    if sin_theta < 1e-6:
        return np.eye(3)
    g = g / np.linalg.norm(g)
    g_x = np.array([[0, -g[2], g[1]], [g[2], 0, -g[0]], [-g[1], g[0], 0]])
    R = cos_theta * np.eye(3) + (1 - cos_theta) * np.outer(g, g) + sin_theta * g_x
    return R

def convert_3d_to_2d(gaussian, point_cloud_cluster, tau):
    """Convert 3D Gaussian to 2D if curvature is low [S1]."""
    eigenvalues, eigenvectors = pca_local_cluster(point_cloud_cluster)
    kappa = (eigenvalues[1] + eigenvalues[2]) / eigenvalues[0]
    if kappa < tau:
        T, Lambda, n = init_2d_gaussian(gaussian.mu, eigenvalues, eigenvectors)
        gaussian.type = '2D'
        gaussian.T = T
        gaussian.Lambda = Lambda
        gaussian.n = n
        return True
    return False

def convert_3d_to_2d_adaptive(gaussian, F, tau1, tau2):
    """Adaptive conversion based on TensoSDF cues [S1]."""
    mu = gaussian.mu
    d = F(mu)
    if np.abs(d) < tau2:
        grad = compute_sdf_gradient(mu, ...) # Requires full F impl
        grad_norm = np.linalg.norm(grad)
        if grad_norm < tau1:
            eigenvalues = np.sort(np.linalg.eigvalsh(gaussian.Sigma))[::-1]
            AR = np.min(eigenvalues) / np.max(eigenvalues)
            if AR < 0.2:
                n = grad / grad_norm
                random_vec = np.random.rand(3)
                if np.abs(np.dot(random_vec, n)) > 0.9:
                    random_vec = np.array([1.0, 0.0, 0.0])
                t1 = np.cross(n, random_vec)
                t1 = t1 / np.linalg.norm(t1)
                t2 = np.cross(n, t1)
                T = np.column_stack((t1, t2))
                sigma_p = 0.1
                Lambda = np.diag([sigma_p**2, sigma_p**2])
                gaussian.type = '2D'
                gaussian.T = T
                gaussian.Lambda = Lambda
                gaussian.n = n
                return True
    return False

def convert_2d_to_3d(gaussian, neighbors):
    """Convert 2D Gaussian to 3D if normals are inconsistent [S1]."""
    n = gaussian.n
    angles = []
    for neighbor in neighbors:
        n_i = neighbor.n
        cos_theta = np.dot(n, n_i) / (np.linalg.norm(n) * np.linalg.norm(n_i))
        angles.append(np.arccos(np.clip(cos_theta, -1.0, 1.0)))
    mean_angle = np.mean(angles)
    if mean_angle > np.deg2rad(30):
        random_vec = np.random.rand(3)
        if np.abs(np.dot(random_vec, n)) > 0.9:
            random_vec = np.array([1.0, 0.0, 0.0])
        t1 = np.cross(n, random_vec)
        t1 = t1 / np.linalg.norm(t1)
        t2 = np.cross(n, t1)
        R = np.column_stack((t1, t2, n))
        Lambda_3d = np.zeros((3, 3))
        Lambda_3d[:2, :2] = gaussian.Lambda
        sigma_n = 1e-4
        Sigma_new = R @ Lambda_3d @ R.T + 2 * (sigma_n**2) * np.outer(n, n)
        gaussian.type = '3D'
        gaussian.Sigma = Sigma_new
        return True
    return False

def fine_tune_gaussian(gaussian, F, eta):
    """Fine-tune Gaussian position and covariance using TensoSDF [S1]."""
    mu = gaussian.mu
    d = F(mu)
    grad = compute_sdf_gradient(mu, ...)
    grad_norm = np.linalg.norm(grad)
    if grad_norm < 1e-8:
        return
    g = grad / grad_norm
    gaussian.mu = mu - eta * d * g
    eigenvalues, eigenvectors = np.linalg.eigh(gaussian.Sigma)
    v_max = eigenvectors[:, np.argmax(eigenvalues)]
    R = rodrigues_rotation(g, v_max)
    gaussian.Sigma = R @ gaussian.Sigma @ R.T

## Operating characteristics

**Time and Memory Complexity:**
*   The method introduces additional storage overhead for TensoSDF tensor factors ($A_x, A_y, A_z$) and potentially more Gaussian primitives due to adaptive conversion [S1].
*   On the Mip-NeRF dataset, average memory consumption increased from 734MB (3DGS) to 845MB (proposed method), an increase of ~15.1% [S1].
*   Increases of 16.1% and 18.2% were observed on DeepBlending and Tanks&Temples datasets respectively [S1].
*   Training requires parallel optimization of Gaussian parameters and TensoSDF factors, adding computational cost per iteration [S1].

**Measured Performance:**
*   On NeRF-synthetic dataset, the method attained an average PSNR improvement of 6.1% over 3DGS [S1].
*   Outperforms 3DGS in global geometric consistency and reconstruction performance for highly reflective materials [S1].

**Strengths and Limitations:**
*   **Strengths:** Reduces redundancy in planar/thin structures; improves geometric consistency via TensoSDF; handles specular reflections better (Specular Module ablation shows significant enhancement) [S1].
*   **Limitations:** Suboptimal performance in highly transparent environments [S1]. Increased memory usage compared to standard 3DGS [S1].

**When to Use:**
*   Scenes with significant planar or thin structures where 3DGS redundancy is high [S1].
*   Applications requiring high geometric accuracy and consistency [S1].
*   Scenes with reflective materials [S1].

**When Not to Use:**
*   Highly transparent environments [S1].
*   Memory-constrained applications where the 15-18% overhead is unacceptable [S1].
