# HYDRA Densification

Also called: HYDRA, HYDRA: Hybrid Decomposition for Rendering-Aware Preservation

## Overview
HYDRA is a densification strategy for 3D Gaussian Splatting that decomposes complex, multi-lobed primitives into simpler constituents within the MCMC framework [S1]. It solves the problem of undersampled regions by subdividing primitives with high positional gradients while preserving the target distribution $P(g_{\text{new}}) \approx P(g_{\text{old}})$ [S1]. It distinguishes itself from standard splitting by using a learned decomposition for large primitives, enabling generalizable planar primitives to operate effectively within MCMC [S1].

## How it works
**Inputs:**
*   Current set of Gaussian primitives $g$.
*   Absolute gradient accumulation for each primitive (used to identify high-gradient regions) [S1].
*   Pre-trained MLP $f_\psi$ [S1].

**Outputs:**
*   Updated set of Gaussian primitives with increased density in high-gradient areas [S1].

**Data Structures:**
*   Primitive parameters: center $o$, covariance (encoded via scale/rotation or Fourier coefficients $\sigma, \{\phi_k\}, \{r_k\}$), color, opacity [S1].
*   Boundary representation for large primitives: radial function $r_i(\theta)$ sampled at $M$ angles [S1].

**Steps:**
1.  **Identify High-Gradient Primitives:** Compute absolute gradient accumulation for all primitives. Select those exceeding a threshold for densification [S1].
2.  **Classify Primitive Size:** Determine if the primitive is "small" or "large" based on its circumradius or complexity [S1].
3.  **Apply Splitting Strategy:**
    *   **Case (i) Scale-preserving split:** For smaller primitives, reduce the circumradius and place two children symmetrically offset in the parent's tangent plane. Apply mass-preserving relocation formulas with $N=2$ [S1].
    *   **Case (ii) Learned lobe decomposition:** For large primitives with complex, multi-lobed boundaries:
        a. Identify the $S$ deepest valleys along the boundary $r_i(\theta)$ sampled at $M$ angles [S1].
        b. Partition the boundary into $S$ angular segments [S1].
        c. For each segment, compute the center of mass $(r_M, \theta_M)$ and angular bounds $(\theta_{\min}, \theta_{\max})$ [S1].
        d. Use the pre-trained MLP $f_\psi$ to generate child primitive parameters:
           $$f_\psi : \left (\sigma ,\, \{\phi _k\},\, \{r_k\},\, r_M,\, \theta _M,\, \theta _{\min },\, \theta _{\max }\right ) \mapsto \left (\sigma ',\, \{\phi '_k\},\, \{r'_k\},\, \Delta r,\, \Delta \theta ,\, o',\, R'\right )$$
           where $(\Delta r, \Delta \theta)$ is the polar offset used to compute the child center in the parent’s tangent plane [S1].
        e. Children inherit color and orientation from the parent [S1].
        f. Remove the parent primitive [S1].
4.  **Update Count:** The net increase in primitives is $S-1$ for each decomposed large primitive [S1].

**Pseudocode:**
```python
def hydra_densification(primitives, gradients, mlp_f_psi):
    """
    Densify primitives using HYDRA strategy.
    primitives: List of Gaussian primitives.
    gradients: Absolute gradient accumulation per primitive.
    mlp_f_psi: Pre-trained MLP for learned decomposition.
    """
    new_primitives = []
    for prim in primitives:
        if gradients[prim.id] < threshold:
            new_primitives.append(prim)
            continue
        
        # Determine if small or large
        if is_small(prim):
            # Case (i): Scale-preserving split
            children = scale_preserving_split(prim, N=2)
            new_primitives.extend(children)
        else:
            # Case (ii): Learned lobe decomposition
            # Identify S deepest valleys in boundary r_i(theta)
            segments = identify_valleys_and_partition(prim, M=M)
            S = len(segments)
            
            for segment in segments:
                # Compute segment properties
                r_M, theta_M = compute_center_of_mass(segment)
                theta_min, theta_max = compute_angular_bounds(segment)
                
                # Get parent parameters
                sigma = prim.sigma
                phi_k = prim.phi_k
                r_k = prim.r_k
                
                # Use MLP to generate child parameters
                child_params = mlp_f_psi(
                    sigma, phi_k, r_k, 
                    r_M, theta_M, 
                    theta_min, theta_max
                )
                
                # child_params contains: sigma', phi_k', r_k', delta_r, delta_theta, o', R'
                sigma_prime, phi_k_prime, r_k_prime, delta_r, delta_theta, o_prime, R_prime = child_params
                
                # Compute child center in parent's tangent plane
                # [G] Assuming polar offset application:
                child_center = polar_to_cartesian(delta_r, delta_theta, o_prime)
                
                # Create child primitive
                child = Primitive(
                    center=child_center,
                    sigma=sigma_prime,
                    phi_k=phi_k_prime,
                    r_k=r_k_prime,
                    color=prim.color,  # Inherit color
                    orientation=prim.orientation,  # Inherit orientation
                    R=R_prime
                )
                new_primitives.append(child)
            
            # Parent is removed, net increase is S-1
            # (Parent was not added to new_primitives, S children were added)
            
    return new_primitives
```

**Parameters:**
*   $M$: Number of angles sampled for boundary representation. Not given in the sources.
*   $S$: Number of segments/lobes. Not given in the sources.
*   $\lambda$: Weight for D-SSIM loss. Not given in the sources.
*   $\lambda_{\text{dist}}$: Weight for depth distortion loss. Not given in the sources.
*   $\lambda_{\text{normal}}$: Weight for normal consistency loss. Not given in the sources.

**Edge Cases and Pitfalls:**
*   Precision issues in computing valleys and centers of mass for complex boundaries [S1].
*   Ensuring the MLP $f_\psi$ is properly trained and generalized [S1].
*   Handling degenerate primitives with no clear valleys [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the number of primitives, the complexity of boundary sampling ($M$), and the MLP inference cost. Not given in the sources.
*   **Memory Complexity:** Increases by $S-1$ primitives per large primitive decomposed. Not given in the sources.
*   **Measured Performance:** Achieves state-of-the-art rendering quality among planar-primitive frameworks and comparable perceptual metrics to leading volumetric representations on standard benchmarks [S1].
*   **Strengths:** Enables generalizable planar primitives within MCMC; handles complex, multi-lobed boundaries effectively [S1].
*   **Limitations:** Requires a pre-trained MLP; potentially higher computational cost for large primitives compared to simple splits [S1].
*   **When to use:** When rendering complex scenes with multi-lobed structures using planar primitives within an MCMC framework [S1].
*   **When not to use:** For simple scenes where standard splitting suffices; if computational resources are limited for MLP inference [S1].

## Background
HYDRA was introduced in "Fourier Splatting: Generalized Fourier encoded primitives for scalable radiance fields" by Jurca et al. [S1]. It is part of the Fourier Splatting framework, which uses Fourier encoded primitives for scalable radiance fields [S1]. The method aims to provide a versatile solution for bandwidth-constrained high-fidelity rendering [S1].
