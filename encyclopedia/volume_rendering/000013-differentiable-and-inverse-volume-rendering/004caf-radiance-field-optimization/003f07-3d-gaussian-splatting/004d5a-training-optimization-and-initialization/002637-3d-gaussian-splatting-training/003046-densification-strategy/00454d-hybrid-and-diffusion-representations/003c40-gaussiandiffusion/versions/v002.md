# GaussianDiffusion

Also called: GaussianCube

## Overview
GaussianDiffusion is a method that trains a 3D diffusion model based on a GaussianCube representation [S1]. It addresses the "Janus problem" (inconsistent geometry from different viewpoints) by incorporating structured noises from multiple viewpoints and mitigates "floaters" (spurious artifacts) by using variational 3D Gaussian Splatting (3DGS) [S1]. It differs from standard 3DGS generation by replacing the direct Gaussian parameterization with a voxelized, constant-size representation derived via optimal transport [S1].

## How it works
**Inputs:** A set of 2D images or a text prompt (for text-to-3D), and a target number of Gaussians $N$.
**Outputs:** A set of 3D Gaussians $\{G_i\}_{i=1}^N$ defined by position $\mathbf{t}_i$, covariance $\mathbf{\Sigma}_i$, opacity $\alpha_i$, and spherical harmonics coefficients $\mathbf{c}_i$.

**Data Structures:**
1.  **GaussianCube:** A voxel grid representation. The sources do not specify the exact voxel resolution or the bit-packing layout of the Gaussian attributes within the voxels.
2.  **Diffusion Model:** A standard 3D diffusion model (e.g., U-Net) conditioned on the GaussianCube.

**Steps:**
1.  **Initialization:** Start with a constant number of Gaussians $N$.
2.  **Voxelization via Optimal Transport:** Convert the $N$ Gaussians into the GaussianCube representation. This involves mapping the continuous Gaussian parameters to a discrete voxel grid using optimal transport to minimize reconstruction error [S1]. The exact cost function and transport algorithm are not specified in the sources.
3.  **Diffusion Training:** Train the 3D diffusion model to predict the GaussianCube.
    *   **Structured Noise:** During the diffusion process, add structured noise derived from multiple viewpoints to the latent space. This encourages consistency across views [S1].
    *   **Variational 3DGS:** Use a variational formulation of 3DGS during the denoising or reconstruction phase to regularize the output and reduce floaters [S1].
4.  **Inversion/Generation:** Use DDIM inversion (replacing DDPM) to invert the diffusion process. Supervision is applied from interval steps of the diffusion process to avoid high error in one-step reconstruction [S1].
5.  **Reconstruction:** Convert the denoised GaussianCube back to a set of 3D Gaussians. The exact inverse mapping (de-voxelization) is not specified in the sources.

**Parameters:**
*   Number of Gaussians $N$: Not given in the sources.
*   Diffusion steps: Not given in the sources.
*   Guidance scale: Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Janus Problem:** Without structured noise, the model may generate inconsistent geometry from different viewpoints [S1].
*   **Floaters:** Without variational 3DGS, the generated scene may contain spurious, low-opacity artifacts [S1].
*   **Optimal Transport Complexity:** The computational cost of optimal transport for voxelization is not quantified but is a potential bottleneck [S1].

## Subtopics

### Gaussian Masking
Gaussian Masking is a technique used to prune Gaussians during training [S2]. It is applied at every densification step and for every 500 iterations after densification stops [S2]. It uses a Gaussian mask to determine which Gaussians to retain.
*   **Parameters:**
    *   $\lambda_m$: Loss weight for Gaussian masking loss. Value is 0.05 [S2].
    *   $\epsilon_m$: Threshold for Gaussian masks. Value is 0.05 [S2].
    *   Learning rate for Gaussian masks: 0.5 [S2].
*   **Effect:** Reduces the number of Gaussians, improving efficiency and potentially reducing artifacts [S2].

## Operating characteristics
*   **Time Complexity:** Not given in the sources. The optimal transport step and diffusion training are likely computationally intensive.
*   **Memory Complexity:** Not given in the sources. The GaussianCube representation size depends on the voxel resolution and the number of attributes per voxel.
*   **Performance:** Not given in the sources.
*   **Strengths:** Alleviates the Janus problem and reduces floaters [S1]. Provides a structured representation (GaussianCube) that may be easier to manipulate or condition [S1].
*   **Limitations:** Requires optimal transport for voxelization, which may be complex to implement [S1]. The exact implementation details of the GaussianCube and its inverse mapping are not provided [S1].

## Background
GaussianDiffusion was proposed in reference [251] cited in [S1]. It is part of the broader effort to improve 3D generation using 3D Gaussian Splatting by incorporating diffusion priors. It is distinct from methods like GVGEN [S1] which use a 3D Gaussian volume representation, and from methods that use iterative optimization of the 3D model and diffusion prior [S1].
