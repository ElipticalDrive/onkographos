# Pixel-GS

Also called: Pixel-based densification, Projected area gradient scaling

## Overview
Pixel-GS is a densification strategy for 3D Gaussian Splatting that prioritizes splitting Gaussians based on their spatial impact on the rendered image [S1]. It scales the densification gradient by the number of pixels a Gaussian influences, ensuring that primitives affecting many pixels are split first [S2, unofficial]. Unlike standard 3DGS, it accounts for the projected area and depth during the splitting process [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** The set of 3D Gaussians $\{G_i\}$ from the previous training iteration, their positional gradients $\nabla_{pos} G_i$, and the camera parameters for all input viewpoints [G].
*   **Output:** A modified set of Gaussians where high-impact primitives are split or cloned, and low-impact primitives are retained [G].

**Data Structures:**
Each Gaussian $G_i$ maintains:
*   Position $\mathbf{p}_i \in \mathbb{R}^3$
*   Covariance $\Sigma_i$ (or rotation $\mathbf{q}_i$ and scale $\mathbf{s}_i$)
*   Opacity $\alpha_i$
*   Color coefficients
*   Accumulated gradient magnitude $g_i$ (initialized to 0)
*   Pixel coverage count $c_i$ (initialized to 0)
[G]

**Steps:**
1.  **Forward Pass & Pixel Counting:** Render the scene from all input viewpoints. For each Gaussian $G_i$ contributing to the image, determine the set of pixels $P_i$ it influences. Count the total pixels covered across all views:
    $$ c_i = \sum_{v \in \text{views}} |P_i^{(v)}| $$
    [S1]
2.  **Gradient Scaling:** Compute the standard positional gradient magnitude $||\nabla_{pos} G_i||$. Scale this gradient by the pixel coverage count $c_i$ and a depth-dependent factor $d_i$ to suppress floaters:
    $$ \tilde{g}_i = c_i \cdot ||\nabla_{pos} G_i|| \cdot d_i $$
    The depth factor $d_i$ scales the gradient according to the distance to the camera [S1].
3.  **Densification Decision:** Compare $\tilde{g}_i$ against a threshold $\tau$. If $\tilde{g}_i > \tau$, mark $G_i$ for splitting or cloning.
4.  **Splitting:** For marked Gaussians, create two new Gaussians by perturbing the position along the principal axes of the covariance matrix, halving the scale, and copying other attributes. Reset $g_i$ and $c_i$ for the new primitives.
5.  **Update:** Accumulate $\tilde{g}_i$ into the Gaussian's history for the next iteration.
[G]

**Parameters:**
*   Threshold $\tau$: Not given in the sources.
*   Depth factor $d_i$: Not given in the sources.
*   Number of viewpoints: All input views [S1].

**Edge Cases:**
*   **Boundaries:** Gaussians at the edge of the view frustum may have artificially low pixel counts; culling should be handled before counting [G].

**Pseudocode:**
```python
import numpy as np

def pixel_gs_densification(gaussians, cameras, threshold):
    # Reset counters
    for g in gaussians:
        g.pixel_count = 0
        g.accumulated_grad = 0.0

    # Render and count pixels for all views
    for cam in cameras:
        visibility_buffer = standard_rasterization(gaussians, cam)
        for g in gaussians:
            count = sum(1 for pid in visibility_buffer if pid == g.id)
            g.pixel_count += count

    # Compute scaled gradients
    for g in gaussians:
        pos_grad_mag = np.linalg.norm(g.position_gradient)
        dist = np.linalg.norm(cam.position - g.position)
        depth_factor = 1.0 / (1.0 + dist)
        scaled_grad = g.pixel_count * pos_grad_mag * depth_factor
        g.accumulated_grad += scaled_grad

    # Split Gaussians exceeding threshold
    new_gaussians = []
    for g in gaussians:
        if g.accumulated_grad > threshold:
            g1, g2 = standard_split(g)
            new_gaussians.append(g1)
            new_gaussians.append(g2)
        else:
            new_gaussians.append(g)
            
    return new_gaussians
```
