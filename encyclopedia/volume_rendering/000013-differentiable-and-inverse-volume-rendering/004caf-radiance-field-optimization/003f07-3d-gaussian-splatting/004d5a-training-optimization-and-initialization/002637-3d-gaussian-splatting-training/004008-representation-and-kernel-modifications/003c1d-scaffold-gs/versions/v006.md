# Scaffold-GS

Also called: Scaffold-Gaussian Splatting

## Overview
Scaffold-GS addresses the limitations of standard 3D Gaussian Splatting (3DGS) by replacing the explicit, unstructured storage of Gaussian attributes with a structured voxel grid backbone [S1]. Unlike standard 3DGS, which stores attributes directly on each primitive, Scaffold-GS determines all Gaussian attributes via interpolation from voxel features and lightweight neural networks, enabling more compact representation and structured optimization [S1].

## How it works
**Inputs:** Sparse Structure-from-Motion (SfM) point cloud; multi-view images.
**Outputs:** Rendered images; optimized voxel features and network weights.

**Data Structures:**
1.  **Voxel Grid:** A 3D grid where each voxel point $v$ holds learnable feature vectors. The grid resolution is a hyperparameter.
2.  **Lightweight Neural Networks:** Small MLPs or linear layers that map interpolated voxel features to specific Gaussian attributes (mean, covariance, opacity, color).

**Method:**
1.  **Initialization:** Initialize a voxel grid in the bounding volume of the SfM point cloud. Attach learnable feature vectors to each voxel point [S1].
2.  **Attribute Determination:** For each Gaussian $G_i$ in the scene:
    a.  Identify the surrounding voxels in the grid.
    b.  Interpolate features from these voxels based on the Gaussian's position.
    c.  Pass the interpolated features through lightweight neural networks to predict the Gaussian's attributes: mean $\boldsymbol{\mu}$, covariance $\boldsymbol{\Sigma}$, opacity $\alpha$, and color $\mathbf{c}$ [S1].
3.  **Rendering:** Project the Gaussians to 2D, sort by depth, and composite using alpha blending [Parent].
4.  **Optimization:** Backpropagate photometric loss to update the voxel features and neural network weights [S1].

**Parameters:**
*   Voxel grid resolution: Not given in the sources.
*   Network architecture: Lightweight neural networks (specifics not given in the sources).

**Edge Cases:**
*   Sparse regions: The method is designed to handle sparse initialization regions better than standard 3DGS by leveraging the structured grid [S1].
*   Precision: Interpolation accuracy depends on voxel resolution.

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Reduced compared to standard 3DGS due to structured voxel storage, though exact savings depend on grid resolution [S1].
*   **Strengths:** Better handling of sparse regions; structured representation [S1].
*   **Limitations:** Requires careful tuning of voxel grid resolution; introduces neural network inference overhead [S1].

## Background
Scaffold-GS was proposed in [S1] as a method to improve 3D Gaussian Splatting by modeling it with a voxel grid and predicting attributes with NeRF-like neural networks instead of Spherical Harmonic coefficients [S1]. It serves as a foundation for subsequent methods like Octree-GS [S1].
