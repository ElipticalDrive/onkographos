# Grid-based Blur Kernel
Also called: Sharpness-indexed Blur Kernels, Trainable Grid-based Blur Kernels

## Overview
Grid-based Blur Kernels replace MLP-generated blur kernels with a learnable tensor indexed by sharpness levels to model spatially-varying blurriness in neural radiance fields [S1]. Unlike [Negative Gaussian Splatting](9152-negative-gaussian-splatting.md) or [Scaffold-GS](9186-scaffold-gs.md) which modify primitive geometry or density, this method explicitly deconvolves defocus blur from the image domain during training, allowing the neural field to reconstruct sharp geometry from blurred inputs [S1].

## How it works
**Inputs and Outputs:**
- Input: A set of training views containing defocus-blurred images $I_{gt}$, camera poses, and a precomputed sharpness level map $L$ for each pixel.
- Output: A set of trainable blur kernels $\mathcal{B}$ and a neural field (e.g., MLP or grid-based) that renders a sharp image $I_b$ after convolution with the blur kernels.

**Data Structures:**
- $\mathcal{B}$: A tensor of shape $\mathbb{R}^{N_{img} \times N_k \times K \times K \times C}$ [S1].
  - $N_{img}$: Number of training views.
  - $N_k$: Number of unique sharpness groups (blur kernels).
  - $K$: Kernel size (spatial dimension).
  - $C$: Number of color channels.
- $L$: A map of the same spatial resolution as the image, where each pixel value is an integer index in $[0, N_k-1]$ representing its sharpness group [S1].
- $I_c'$: A cropped tensor of shape $P' \times P' \times K \times K$ derived from the clean (ground truth) image $I_c$ (see steps) [S1].

**Parameters:**
- $K$: Kernel size. Typical value: 11 [S1].
- $N_k$: Number of blur kernels. Typical value: 400 [S1].
- Learning rate for $\mathcal{B}$: 0.05 [S1].
- Initialization: 2D Gaussian distribution [S1].
- $P'$: Patch size dimension. Typical value: 22 (patch size $P=22$) [S1].

**Steps:**
1. **Preprocessing (Sharpness Prior):** Estimate a defocus map for every training view using a Defocus Map Estimation Network (DMENet) [S1]. Quantize the defocus map uniformly into $N_k$ values to create the sharpness level map $L$ [S1]. Optionally, segment the scene using depth information (e.g., from MIDAS) to assess focus levels within segments and refine $L$ [S1]. This step is performed once before training [S1].
2. **Kernel Indexing:** For each pixel $x$ (with coordinates $h, w$) in a training view, determine its sharpness level $L[h,w]$ [S1]. Retrieve the corresponding blur kernel $w_x$ from the grid $\mathcal{B}$ using the mapping function $F$:
   $$ w_x = F(\mathcal{B}, L, x) $$
   Specifically, $w_x$ is the tensor slice $\mathcal{B}[view\_index, L[h,w], :, :, :]$ [S1].
3. **Image Cropping:** Crop the ground truth sharp image $I_c$ along height and width with stride 1 to generate a tensor $I_c'$ of shape $P' \times P' \times K \times K$ [S1]. This tensor contains local neighborhoods for convolution [S1].
4. **Blurred Image Synthesis:** Compute the blurred image $I_b$ by convolving the cropped ground truth $I_c'$ with the indexed kernels $w_x$:
   $$ I_b[h,w] = \sum_{i=0}^{K} \sum_{j=0}^{K} I_c'[h,w,i,j] w_x[h,w,i,j] $$
   where $h, w$ are indices along the height and width [S1].
5. **Optimization:** Jointly optimize the neural field and the blur kernel grid $\mathcal{B}$ using the reconstruction loss:
   $$ \mathcal{L}_{recon} = ||I_b - I_{gt}||_2 $$
   where $I_{gt}$ is the ground truth sharp image [S1].

**Pseudocode:**
```python
# Initialization
# B: Tensor of shape (N_img, N_k, K, K, C), initialized with 2D Gaussian
# L: Tensor of shape (H, W), integer indices in [0, N_k-1], precomputed
# I_gt: Tensor of shape (H, W, C), ground truth sharp images
# I_c: Tensor of shape (H, W, C), same as I_gt (used for cropping)

def get_blur_kernel(B, L, h, w, view_idx):
    """Retrieve blur kernel for pixel (h,w) in view_idx."""
    sharpness_level = L[h, w]
    return B[view_idx, sharpness_level, :, :, :]

def crop_image(I_c, h, w, K):
    """Crop local neighborhood from I_c centered at (h,w)."""
    # Assuming boundary handling is required for edges
    # Returns tensor of shape (K, K, C)
    return I_c[h:h+K, w:w+K, :]

def compute_blurred_pixel(I_c, B, L, h, w, view_idx, K):
    """Compute the blurred value for a single pixel."""
    w_x = get_blur_kernel(B, L, h, w, view_idx) # Shape: (K, K, C)
    I_c_prime = crop_image(I_c, h, w, K)        # Shape: (K, K, C)
    
    # Convolution: sum over i, j
    blurred_val = 0.0
    for i in range(K):
        for j in range(K):
            blurred_val += I_c_prime[i, j, :] * w_x[i, j, :]
    return blurred_val

def train_step(I_gt, I_c, B, L, view_idx, patch_coords, K):
    """
    Compute loss for a patch of pixels.
    patch_coords: List of (h, w) tuples.
    """
    loss = 0.0
    for h, w in patch_coords:
        # Skip convolution for pixels in high sharpness groups if configured
        # (e.g., skip if L[h,w] corresponds to one of the 100 highest sharpness groups)
        if is_high_sharpness(L[h, w]):
            continue
            
        I_b_h_w = compute_blurred_pixel(I_c, B, L, h, w, view_idx, K)
        I_gt_h_w = I_gt[h, w, :]
        loss += torch.sum((I_b_h_w - I_gt_h_w) ** 2)
    return loss
```

**Edge Cases and Pitfalls:**
- **High Sharpness:** Pixels with very high sharpness (in-focus) may not require deblurring. The method skips convolution for pixels in 100 groups of each view with high sharpness values to save computation [S1].
- **Boundary Conditions:** The cropping operation $I_c'$ requires handling image boundaries where the kernel extends beyond the image bounds. Not specified in sources [G].
- **Quantization Artifacts:** Uniform quantization of the defocus map into $N_k$ groups may introduce discontinuities in sharpness levels. The method notes that any operator measuring sharpness can be used, implying robustness to the specific prior source [S1].

## Subtopics

### Sharpness Prior with Defocus Map Estimation
A preprocessing variant that estimates a spatially varying defocus map to determine the sharpness level of image pixels, which is used to group pixels for blur kernel assignment [S1]. It uses DMENet (an end-to-end CNN) to estimate the defocus map and MIDAS for depth information to segment the scene and assess focus levels within segments [S1]. The defocus map is quantized into $N_k$ values to create the sharpness level map $L$ [S1]. This step is performed once before training and does not affect training or testing times [S1].

## Operating characteristics
- **Time Complexity:** The method reduces the number of required neighboring rays per ray from $O(P'^2)$ in random ray sampling to $O((P'+K+1)^2/2)$ with random patch sampling, leveraging the transversal relation among neighboring rays [S1]. The sharpness prior computation takes less than a couple of minutes as a preprocessing step [S1].
- **Memory Complexity:** The blur kernel grid $\mathcal{B}$ has size $N_{img} \times N_k \times K \times K \times C$. With $N_{img}$ views, $N_k=400$, $K=11$, and $C=3$, this is a significant but fixed memory overhead compared to per-pixel kernels [S1].
- **Performance:** Successfully renders clean images even from harshly defocused regions [S1]. Improves expressivity by increasing grid size without extra computational cost to produce kernels [S1].
- **Strengths:** Joint optimization with neural fields; efficient indexing; handles spatially varying blur.
- **Limitations:** Requires accurate defocus map estimation; quantization of sharpness levels may limit smoothness.

## Background
Originated in "Sharp-NeRF: Grid-based Fast Deblurring Neural Radiance Fields using Sharpness Prior" (WACV 2024) [S1]. It addresses the limitation of NeRF and derived works that treat defocus blur as noise or ignore it, by explicitly modeling it with trainable kernels [S1]. It improves upon previous works using MLPs to generate blur kernels by using a grid-based approach for better expressivity and efficiency [S1].
