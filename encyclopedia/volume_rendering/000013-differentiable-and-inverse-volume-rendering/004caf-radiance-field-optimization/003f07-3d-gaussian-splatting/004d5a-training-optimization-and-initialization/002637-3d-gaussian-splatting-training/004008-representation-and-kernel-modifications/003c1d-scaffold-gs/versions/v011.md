# Scaffold-GS

Also called: Scaffold-Gaussian Splatting

## Overview
Scaffold-GS is a representation modification for 3D Gaussian Splatting that replaces the direct parameterization of Gaussian attributes with a voxel-based neural field. It solves the issue of inefficient memory usage and poor initialization in sparse regions by decoupling the geometric scaffold (voxels) from the radiance attributes (Gaussians) [S1]. Unlike standard 3DGS which stores attributes directly per Gaussian, Scaffold-GS determines all Gaussian attributes via interpolated features from a voxel grid and lightweight neural networks, enabling a more compact and structured representation [S1].

## How it works
**Inputs:** Sparse Structure-from-Motion (SfM) point cloud; camera poses and images.
**Outputs:** A set of 3D Gaussians defined by the voxel grid and neural networks, ready for differentiable rasterization.

**Data Structures:**
1.  **Voxel Grid:** A 3D grid where each voxel point stores learnable feature vectors. The grid resolution is a hyperparameter.
2.  **Lightweight Neural Networks:** Small MLPs that map interpolated voxel features to specific Gaussian attributes (position, scale, rotation, opacity, SH coefficients).

**Steps:**
1.  **Voxel Initialization:** Initialize a voxel grid covering the scene volume. Attach learnable feature vectors to each voxel point.
2.  **Feature Interpolation:** For any 3D Gaussian center, sample the voxel grid to retrieve interpolated features. This involves trilinear interpolation of the learnable features from the surrounding voxels.
3.  **Attribute Prediction:** Pass the interpolated features through lightweight neural networks to predict the full set of Gaussian attributes:
    *   Position offset (relative to voxel center or grid coordinate).
    *   Scale and Rotation.
    *   Opacity.
    *   View-dependent color (SH coefficients).
4.  **Optimization:** Optimize the voxel features and neural network weights via gradient descent, minimizing the rendering loss against input images. The Gaussians are effectively "scaffolded" by the voxel grid.

**Formulas:**
Let $V$ be the voxel grid with features $F_v$. For a Gaussian $i$ at position $\mathbf{p}_i$, the interpolated feature $\mathbf{f}_i$ is:
$$ \mathbf{f}_i = \text{TrilinearInterpolate}(V, \mathbf{p}_i) $$
The attributes $\mathbf{a}_i$ (scale, rotation, opacity, SH) are predicted by a network $N$:
$$ \mathbf{a}_i = N(\mathbf{f}_i) $$

**Parameters:**
*   Voxel grid resolution: Not given in the sources.
*   Network architecture: Lightweight MLPs. Specific layer sizes not given in the sources.

**Edge Cases:**
*   Sparse regions: The voxel grid provides a structured prior, mitigating the need for dense initial Gaussians in empty space [S1].
*   Precision: Interpolation smoothness depends on voxel resolution.

## Subtopics

### [Scaffold-GS Integration](12513-scaffold-gs-integration.md)
Applies DART and AGE modules to the Scaffold-GS backbone. It augments the anchor-seeding SfM cloud before optimization and gates primitive growth during it, without modifying the rendering path or the optimizer. This approach is distinct from representation-level changes by operating as a backbone-agnostic add-on that specifically targets sparse initialization regions.

## Operating characteristics
*   **Memory:** More memory-efficient than standard 3DGS in sparse regions due to the voxel grid structure, but requires additional memory for the voxel features and neural network weights.
*   **Performance:** Rendering performance is similar to standard 3DGS as the rasterization kernel is unchanged. Training may be slower due to the neural network inference for attribute prediction.
*   **Strengths:** Better handling of sparse initialization; structured representation.
*   **Limitations:** Requires careful tuning of voxel resolution; potential smoothing artifacts if resolution is too low.

## Background
Scaffold-GS was proposed in "Recent advances in 3D Gaussian splatting" [S1]. It builds on the idea of using neural fields to represent Gaussian attributes, similar to VDGS which uses NeRF-like networks, but specifically introduces a voxel grid scaffold to initialize and structure the Gaussians.
