# Grid-based Blur Kernel

Also called: Sharpness-indexed Blur Kernels, Trainable Grid-based Blur Kernels

## Overview
Grid-based Blur Kernels replace neural network-generated blur kernels with a learnable, indexed grid to model spatially-varying blurriness in differentiable rendering [S1]. Unlike methods that use Multi-Layer Perceptrons (MLPs) to predict kernel weights per pixel, this approach assigns pixels to discrete sharpness groups, allowing expressivity to scale with grid size without additional computational cost during inference [S1].

## How it works
**Inputs:**
*   Clean image patches $I_c$ (or initial render).
*   Sharpness level map $L$ (precomputed).
*   Ground truth image $I_{gt}$.

**Outputs:**
*   Blurred image $I_b$.
*   Optimized blur kernel tensor $\mathcal{B}$.

**Data Structures:**
*   $\mathcal{B}$: Tensor of shape $\mathbb{R}^{N_{img} \times N_k \times K \times K \times C}$.
    *   $N_{img}$: Number of training views.
    *   $N_k$: Number of unique sharpness groups (blur kernels).
    *   $K$: Kernel spatial size (e.g., 11).
    *   $C$: Number of channels.
*   $L$: Map of shape $P' \times P'$, where each pixel value is an integer index in $[0, N_k-1]$.
*   $I_c'$: Cropped image tensor of shape $P' \times P' \times K \times K$.

**Parameters:**
*   $K$: Kernel size. Default: 11 [S1].
*   $N_k$: Number of blur kernels. Default: 400 [S1].
*   Learning rate for $\mathcal{B}$: 0.05 [S1].
*   Initialization: 2D Gaussian distribution [S1].
*   $P'$: Patch size dimension. Default: 22 (patch size $P=22$) [S1].

**Steps:**
1.  **Preprocessing (Sharpness Prior):** Compute a sharpness level map $L$ for each training view. This involves estimating a defocus map and quantizing it into $N_k$ uniform values [S1].
2.  **Mapping:** For each pixel $(h,w)$ in the target patch, retrieve its sharpness index $l = L[h,w]$. Map this index to a specific blur kernel $w_x$ from the grid $\mathcal{B}$ using a mapping function $F$:
    $$ w_x = F(\mathcal{B}, L, x) $$
    Here, $w_x$ is the kernel corresponding to the sharpness group of pixel $x$ [S1].
3.  **Cropping:** Crop the clean image $I_c$ along height and width with stride 1 to generate the neighborhood tensor $I_c'$ of shape $P' \times P' \times K \times K$. This tensor contains the local neighborhoods for all pixels in the patch [S1].
4.  **Convolution:** Compute the blurred image $I_b$ by convolving $I_c'$ with the indexed kernels $w_x$:
    $$ I_b[h,w] = \sum_{i=0}^{K} \sum_{j=0}^{K} I_c'[h,w,i,j] w_x[h,w,i,j] $$
    where $h, w$ are indices along the height and width of the image [S1].
5.  **Optimization:** Minimize the reconstruction loss $\mathcal{L}_{recon}$ between the blurred image $I_b$ and the ground truth $I_{gt}$:
    $$ \mathcal{L}_{recon} = ||I_b - I_{gt}||_2 $$
    Optimize both the grid-based neural fields and the blur kernels $\mathcal{B}$ jointly [S1].

**Edge Cases and Pitfalls:**
*   **High Sharpness:** Pixels in groups with high sharpness values (clearly in focus) may not require convolution. The method skips convolution for pixels in 100 groups of each view with high sharpness values to save computation [S1].
*   **Initialization:** Kernels must be initialized with a 2D Gaussian distribution to ensure stable training from the first iteration [S1].

**Pseudocode:**

```python
def grid_based_blur_kernel_step(I_c, L, B, N_k, K, skip_groups):
    """
    Performs one step of grid-based blur kernel convolution and loss calculation.
    
    Args:
        I_c: Clean image tensor of shape (H, W, C).
        L: Sharpness level map of shape (H, W), integer indices in [0, N_k-1].
        B: Blur kernel grid of shape (N_img, N_k, K, K, C).
        N_k: Number of unique sharpness groups.
        K: Kernel size.
        skip_groups: Set of sharpness indices to skip convolution for.
        
    Returns:
        I_b: Blurred image tensor.
        loss: Reconstruction loss.
    """
    # 1. Crop I_c to get local neighborhoods
    # I_c' shape: (H, W, K, K, C)
    # Note: In practice, this is a sliding window view or explicit padding/cropping
    I_c_prime = crop_with_stride_1(I_c, K) 
    
    # 2. Retrieve kernels for each pixel based on L
    # B is indexed by [view_idx, sharpness_idx]
    # We assume we are processing a single view for this step, so view_idx is fixed.
    # Let B_view be B[view_idx] with shape (N_k, K, K, C)
    
    # Initialize blurred image
    H, W, C = I_c.shape
    I_b = torch.zeros((H, W, C), device=I_c.device)
    
    # 3. Iterate over sharpness groups to apply convolution
    for sharpness_idx in range(N_k):
        # Get kernel for this sharpness group
        # w_x shape: (K, K, C)
        w_x = B_view[sharpness_idx]
        
        # Create mask for pixels belonging to this group
        mask = (L == sharpness_idx)
        
        # Skip convolution for high sharpness groups if specified
        if sharpness_idx in skip_groups:
            # For skipped groups, the kernel is effectively identity or 1x1
            # Assuming the kernel is initialized as Gaussian, 
            # skipping implies using the original pixel value or a 1x1 kernel.
            # Based on source, we skip the convolution operation.
            # We assume the "clean" image is the target for sharp regions 
            # or the kernel acts as identity. 
            # Implementation detail [G]: If skipped, I_b[h,w] = I_c[h,w]
            I_b[mask] = I_c[mask]
            continue
            
        # Convolve pixels in this group
        # I_c_prime[mask] has shape (Num_Pixels, K, K, C)
        # w_x has shape (K, K, C)
        # We need to perform convolution: sum over i,j of I_c'[i,j] * w_x[i,j]
        
        # Efficient implementation using einsum or im2col
        # Reshape I_c_prime[mask] to (Num_Pixels, K*K, C)
        neighborhoods = I_c_prime[mask].reshape(-1, K*K, C)
        
        # Reshape w_x to (K*K, C)
        kernel_flat = w_x.reshape(K*K, C)
        
        # Dot product: (Num_Pixels, K*K) @ (K*K, C) -> (Num_Pixels, C)
        blurred_pixels = torch.einsum('pc,ck->pc', neighborhoods, kernel_flat)
        
        # Assign back to I_b
        # Flatten mask to get indices
        indices = torch.nonzero(mask.flatten(), as_tuple=False).squeeze()
        I_b_flat = I_b.flatten(0, 1) # (H*W, C)
        I_b_flat[indices] = blurred_pixels

    # 4. Compute Loss
    # L_recon = ||I_b - I_gt||_2
    loss = torch.mean((I_b - I_gt)**2)
    
    return I_b, loss
```

## Subtopics

### Sharpness Prior with Defocus Map Estimation
A preprocessing variant that estimates a spatially varying defocus map to determine the sharpness level $L$ used for kernel indexing [S1]. It uses DMENet (an end-to-end CNN) to estimate the defocus map for every training view, then quantizes the map uniformly into $N_k$ values to create the sharpness level map [S1]. To improve accuracy, it segments the scene based on depth information (from MIDAS) to assess the focus level within each segment [S1]. This step is performed once during preprocessing and does not affect training time [S1].

## Operating characteristics
*   **Complexity:** The method reduces the number of required neighboring rays per pixel from $K^2$ (in random ray sampling) to $\frac{K^2}{2}$ via random patch sampling, improving efficiency over NeRF-style ray fetching [S1].
*   **Performance:** Using 400 kernels ($N_k=400$) and a kernel size of 11 allows the model to successfully render clean images even from harshly defocused regions [S1].
*   **Scalability:** Expressivity improves by simply increasing the grid size ($N_k$) without extra computational cost to produce kernels, unlike MLP-based approaches [S1].
*   **Optimization:** Kernels are jointly optimized with grid-based neural fields from the first iteration. The learning rate for the kernel is set to 0.05 [S1].
*   **Speed:** The sharpness prior preprocessing takes less than a couple of minutes and does not affect subsequent training or testing times [S1].

## Background
The method is introduced in "Sharp-NeRF: Grid-based Fast Deblurring Neural Radiance Fields using Sharpness Prior" [S1]. It addresses the limitation of previous works that used MLPs to generate blur kernels, which are less expressive and more costly. By leveraging a sharpness prior (defocus map) and a grid-based kernel structure, it enables efficient modeling of spatially-varying blurriness in NeRFs.
