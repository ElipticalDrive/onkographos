# Representation and Kernel Modifications

Also called: Diff-Gaussian, Scaffold-GS, GeoGaussian, DARBF-Splatting, Grid-based Blur, Gaussian Wrapping, Gaussian Shell Maps

## Overview
Representation and Kernel Modifications alter the fundamental mathematical primitives or data structures of 3D Gaussian Splatting to address limitations in shape flexibility, memory efficiency, geometric consistency, and physical blur modeling. Unlike [Base 3DGS Optimization](7549-base-3d-gaussian-splatting.md), which relies on standard positive Gaussians with fixed kernel properties, this family introduces negative densities, voxel-based latent representations, non-Gaussian radial basis functions, and oriented surface elements. These modifications enable the modeling of high-frequency nonlinear structures, watertight surface extraction, and spatially-varying defocus blur that standard alpha-composited Gaussians cannot capture efficiently.

## Shared principles
All methods in this family retain the core differentiable rasterization pipeline of 3D Gaussian Splatting: projecting 3D primitives to 2D screen space, sorting by depth, and performing alpha compositing to render images. However, they diverge in the definition of the primitive's contribution to the color buffer.

1.  **Primitive Parameterization:** Standard Gaussians are defined by mean $\boldsymbol{\mu}$, covariance $\boldsymbol{\Sigma}$, opacity $\alpha$, and color $\mathbf{c}$. Modifications may allow $\mathbf{c}$ to be negative (Diff-Gaussian), replace direct storage with neural prediction (Scaffold-GS), or change the kernel function $K$ governing the density decay (DARBF, Grid-based Blur).
2.  **Rendering Equation:** The standard compositing equation $C = \sum c_i \alpha_i \prod (1-\alpha_j)$ is preserved or slightly adapted. For negative Gaussians, $c_i$ can be negative, allowing subtractive color blending. For oriented Gaussians, the opacity $\alpha$ is reinterpreted as occupancy/vacancy based on a half-space assumption.
3.  **Optimization:** All methods minimize a photometric loss (e.g., L1, SSIM) between rendered and ground-truth images via gradient descent. Specific methods add regularization terms (e.g., geometric smoothness in GeoGaussian) or consistency losses (e.g., Gaussian Wrapping).

## Subtopics

### [Negative Gaussian Splatting](9152-negative-gaussian-splatting.md)
[Negative Gaussian Splatting](9152-negative-gaussian-splatting.md) extends the standard framework by allowing the color coefficient $c_i$ to be negative, effectively modeling the scene as a difference of Gaussians (Diff-Gaussian). This allows for the approximation of complex nonlinear structures (e.g., donuts, moons) with fewer primitives than standard positive Gaussians. It sets itself apart by introducing subtractive color contributions, whereas siblings like Scaffold-GS focus on memory efficiency via voxel grids.

### [Scaffold-GS](9186-scaffold-gs.md)
[Scaffold-GS](9186-scaffold-gs.md) replaces the direct storage of Gaussian attributes with a voxel-based latent representation. It decouples the geometric scaffold (voxel grid) from the Gaussian primitives, using a neural network to predict Gaussian parameters from voxel features. This solves the problem of inefficient attribute storage and initialization. Unlike Negative Gaussian Splatting, which modifies the kernel's color sign, Scaffold-GS alters the data structure itself.

### [GeoGaussian](9187-geogaussian.md)
[GeoGaussian](9187-geogaussian.md) improves geometric consistency by densifying Gaussians on the tangent plane of existing primitives and enforcing smoothness of normals between neighbors. It prioritizes local geometric coherence and normal consistency during densification. This contrasts with Scaffold-GS, which focuses on memory efficiency, and Negative Gaussian Splatting, which focuses on shape flexibility via negative colors.

### [DARBF-Splatting](9911-darbf-splatting.md)
[DARBF-Splatting](9911-darbf-splatting.md) replaces the standard Gaussian reconstruction kernels with a generalized class of Decaying Anisotropic Radial Basis Functions (DARBFs), such as Half-Cosine or Inverse Multiquadric. It solves the limitation of existing splatting methods being restricted to the exponential family. Unlike standard 3DGS, which relies on closed-form integration properties, DARBF-Splatting introduces a correction factor $\psi$ to approximate this efficiency for non-exponential kernels.

### [Grid-based Blur Kernel](14244-grid-based-blur-kernel.md)
[Grid-based Blur Kernel](14244-grid-based-blur-kernel.md) replaces the MLP used to generate blur kernels with a set of learnable, indexed grid tensors. It models spatially-varying blurriness by assigning one of $N_k$ discrete blur kernels to each pixel based on a precomputed sharpness level. It differs from Negative Gaussian Splatting by explicitly handling defocus blur through a differentiable convolution operation rather than modifying the Gaussian primitive's covariance or opacity directly.

### Gaussian Wrapping
Gaussian Wrapping [S2] reinterprets 3D Gaussian primitives as oriented probabilistic surface elements representing geometry only within an oriented half-space. This allows the derivation of closed-form occupancy, vacancy, and normal fields for watertight mesh extraction.
*   **Definition:** The Gaussian models density decay on the outward-facing side of the boundary, while the inward-facing side is considered fully occupied.
*   **Steps:**
    1.  Model surface points with asymmetric primitives where the Gaussian models density decay on the outward-facing side, while the inward-facing side is considered fully occupied [S2].
    2.  Identify geometric gaps where the oriented surface assumption is violated and densify the representation to obtain a watertight shell of oriented primitives [S2].
    3.  Introduce a learnable oriented normal at each Gaussian element and define an adapted attenuation formulation to enable closed-form expressions for normal and occupancy fields [S2].
    4.  Introduce a novel consistency loss and a dedicated densification strategy to enforce Gaussians to wrap the entire surface by closing geometric holes [S2].
    5.  Modify the differentiable rasterizer to output depth as an isosurface of the continuous model [S2].
    6.  Use Primal Adaptive Meshing for Region-of-Interest meshing at arbitrary resolution [S2].

### Gaussian Shell Maps
Gaussian Shell Maps [S1] combine CNN-based generators with 3DGS to recreate virtual humans with sophisticated details such as clothing and accessories.

## Background
The standard 3D Gaussian Splatting method [Parent](3761-3d-gaussian-splatting-training.md) uses symmetric, positive Gaussians for fast differentiable rendering. However, this representation has limitations: it struggles with high-frequency details and complex topologies (requiring many primitives), lacks explicit geometric surface priors (making mesh extraction difficult), and assumes sharp focus.

*   **Negative Gaussians:** The concept of Difference-of-Gaussians (DoG) is well-established in image processing. NegGS [S1, S2] adapts this to 3DGS to allow subtractive color blending, improving shape flexibility.
*   **Scaffold-GS:** To address memory inefficiencies in storing millions of Gaussian attributes, Scaffold-GS [S1] introduces a voxel-based latent representation, decoupling geometry from attributes.
*   **GeoGaussian:** Standard 3DGS often produces noisy geometry. GeoGaussian [S1] introduces tangent-plane densification and normal smoothness regularization to improve surface reconstruction quality.
*   **DARBF-Splatting:** Standard Gaussians are restricted to the exponential family. DARBF-Splatting [S1] generalizes the kernel to other decaying functions (e.g., Half-Cosine) to improve convergence and memory usage, requiring a correction factor for integration.
*   **Grid-based Blur:** Real-world images often contain defocus blur. Grid-based Blur [S1] models this by learning a grid of blur kernels indexed by sharpness, replacing previous MLP-based approaches.
*   **Gaussian Wrapping:** [S2] introduces oriented Gaussians to enable watertight mesh extraction by treating primitives as half-space surface elements.
*   **Gaussian Shell Maps:** [S1] combines CNNs with 3DGS for detailed human avatars.
