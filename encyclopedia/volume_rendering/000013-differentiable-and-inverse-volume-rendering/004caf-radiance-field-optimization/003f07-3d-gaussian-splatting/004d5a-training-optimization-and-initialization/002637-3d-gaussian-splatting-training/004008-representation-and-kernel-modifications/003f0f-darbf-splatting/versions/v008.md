# DARBF-Splatting

Also called: DARB-Splatting, Decaying Anisotropic Radial Basis Functions Splatting

## Overview
DARBF-Splatting is a method for 3D Gaussian Splatting that replaces the standard Gaussian kernel with a class of non-exponential **Decaying Anisotropic Radial Basis Functions (DARBFs)** [S1]. It solves the limitation of standard 3DGS being restricted to the exponential family by enabling the use of kernels like half-cosine or inverse multiquadric, which offer faster training convergence and lower memory usage while maintaining comparable visual quality [S1]. Unlike standard 3DGS, which relies on the closed-form integration shortcut of Gaussians, DARBF-Splatting introduces a scalar correction factor to approximate this shortcut for non-Gaussian kernels, preserving computational efficiency [S1].

## How it works
**Inputs:**
*   A set of 3D primitives (ellipsoids) defined by mean position $\boldsymbol{\mu}$, covariance matrix $\boldsymbol{\Sigma}$, opacity $\alpha$, and spherical harmonic coefficients for color $\mathbf{c}$ [S1].
*   Camera parameters (view and projection matrices) [S1].
*   A selected DARBF kernel function $K(d_M)$ [S1].

**Outputs:**
*   A 2D color and opacity buffer for the rendered image [S1].

**Data Structures:**
*   **3D Covariance Matrix ($\boldsymbol{\Sigma}$):** A $3 \times 3$ symmetric positive-definite matrix defining the anisotropic shape and orientation of the primitive in 3D space [S1].
*   **2D Covariance Matrix ($\boldsymbol{\Sigma}'$):** A $2 \times 2$ matrix obtained by extracting the top-left $2 \times 2$ submatrix of the transformed 3D covariance matrix (skipping the third row and column) [S1]. This approximation allows the method to bypass costly 3D-to-2D integration [S1].
*   **Correction Factor ($\psi$):** A scalar value precomputed via closed-form regression to adjust the kernel's integral approximation [S1].

**Mahalanobis Distance:**
The distance metric used by all DARBFs is the Mahalanobis distance $d_M$ from a point $\mathbf{x}$ to the center $\boldsymbol{\mu}$ with covariance $\boldsymbol{\Sigma}$:
$$
d_M(\mathbf{x}; \boldsymbol{\mu}, \boldsymbol{\Sigma}) = [(\mathbf{x} - \boldsymbol{\mu})^T \boldsymbol{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})]^{\frac{1}{2}}
$$
where $\boldsymbol{\Sigma}$ is the covariance matrix [S1].

**Kernel Functions:**
DARBFs are non-negative, decaying functions of $d_M$. The paper highlights two specific variants:
1.  **Half-Cosine:** Defined as $\cos \left( \frac{d_M^2}{\xi} \right)$ for $d_M^2 < \frac{\xi \pi}{2}$, and 0 otherwise, where $\xi > 0$ is a scale parameter [S1]. It has finite support [S1].
2.  **Inverse Multiquadric (Inverse MQ):** A function with a wide spread and sharp peak, spanning a larger region with higher opacity for the same variance compared to Gaussians [S1].

**Algorithm Steps:**

1.  **Primitive Transformation:** Transform the 3D mean $\boldsymbol{\mu}$ and covariance $\boldsymbol{\Sigma}$ of each primitive into the camera coordinate system using the view matrix [S1].
2.  **2D Projection Approximation:** Compute the 2D covariance matrix $\boldsymbol{\Sigma}'$ by taking the top-left $2 \times 2$ submatrix of the transformed 3D covariance matrix [S1].
    *   *Note:* This step approximates the true projection integral, which is costly for non-Gaussian kernels [S1].
3.  **Splat Rasterization:** For each pixel covered by the projected 2D ellipse:
    a. Calculate the 2D Mahalanobis distance $d_M$ from the pixel center to the primitive's 2D mean using $\boldsymbol{\Sigma}'$ [S1].
    b. Evaluate the selected DARBF kernel $K(d_M)$ [S1].
    c. Apply the correction factor $\psi$ to the kernel value to approximate the closed-form integration advantage of Gaussians [S1].
    d. Accumulate the color and opacity contributions using alpha blending [S1].
4.  **Optimization:** Backpropagate the pixel error to update $\boldsymbol{\mu}$, $\boldsymbol{\Sigma}$, $\alpha$, and $\mathbf{c}$ [S1].

**Pseudocode:**

```python
import numpy as np

def darbf_splatting(primitives, camera_matrix, kernel_type='half_cosine', xi=1.0, psi=1.0):
    """
    Renders a scene using DARBF-Splatting.
    
    primitives: List of dicts, each containing:
        - mu: 3D mean position (np.array, shape (3,))
        - Sigma: 3x3 covariance matrix (np.array, shape (3, 3))
        - alpha: Opacity (float)
        - color: Color SH coefficients or RGB (np.array)
    camera_matrix: 3x3 projection matrix (np.array)
    kernel_type: String, 'half_cosine' or 'inverse_mq'
    xi: Scale parameter for half_cosine kernel
    psi: Scalar correction factor
    """
    # Initialize output buffers
    height, width = 1024, 1024 # Example resolution
    color_buffer = np.zeros((height, width, 3))
    alpha_buffer = np.zeros((height, width))
    
    # Sort primitives by depth for correct alpha blending
    primitives_sorted = sorted(primitives, key=lambda p: np.dot(p['mu'], camera_matrix[2, :3]))
    
    for prim in primitives_sorted:
        mu_3d = prim['mu']
        Sigma_3d = prim['Sigma']
        alpha = prim['alpha']
        color = prim['color']
        
        # 1. Transform to camera space
        # Assuming camera_matrix includes view and projection, 
        # or we extract the relevant transformation parts.
        # For simplicity, assume we have a 3x3 view-projection matrix M
        M = camera_matrix 
        
        # Transform mean
        mu_3d_hom = np.append(mu_3d, 1.0)
        mu_cam_hom = M @ mu_3d_hom
        if mu_cam_hom[2] <= 0:
            continue # Behind camera
        
        mu_2d = mu_cam_hom[:2] / mu_cam_hom[2]
        
        # Transform Covariance
        # J is the Jacobian of the projection
        # Simplified: Extract top-left 2x2 of transformed Sigma
        # In 3DGS, this involves the view matrix V and projection P.
        # Here we approximate the 2D Sigma from 3D Sigma via the standard 3DGS shortcut
        # which is valid for the approximation described in [S1].
        
        # Let V be the 3x3 view matrix part of M (or extracted separately)
        # For this pseudocode, we assume Sigma_3d is already in camera space or 
        # we apply a standard 3DGS-like projection step.
        # The paper states: "2x2 covariance matrix of the 2D Gaussian can be obtained by 
        # skipping the third row and column of the 3x3 covariance matrix of the 3D Gaussian"
        # This implies Sigma_3d is in camera coordinates.
        
        # If Sigma_3d is in world space, it must be rotated by the view matrix V:
        # Sigma_cam = V @ Sigma_3d @ V.T
        # Then take top-left 2x2.
        # We assume Sigma_3d is passed in camera space for this simplified example.
        
        Sigma_2d = Sigma_3d[:2, :2]
        
        # Check if Sigma_2d is positive definite
        if np.linalg.det(Sigma_2d) <= 0:
            continue
            
        # 2. Determine bounding box for the splat
        # Use 3-sigma rule for bounding box
        eigenvalues, eigenvectors = np.linalg.eigh(Sigma_2d)
        radius = 3.0 * np.sqrt(np.max(eigenvalues))
        
        x_min = int(max(0, mu_2d[0] - radius))
        x_max = int(min(width, mu_2d[0] + radius))
        y_min = int(max(0, mu_2d[1] - radius))
        y_max = int(min(height, mu_2d[1] + radius))
        
        # Precompute inverse of Sigma_2d
        Sigma_2d_inv = np.linalg.inv(Sigma_2d)
        
        # 3. Rasterize
        for y in range(y_min, y_max):
            for x in range(x_min, x_max):
                # 2D point
                p_2d = np.array([x, y])
                
                # Mahalanobis distance
                diff = p_2d - mu_2d
                d_M_sq = diff @ Sigma_2d_inv @ diff
                d_M = np.sqrt(d_M_sq)
                
                # Evaluate Kernel
                if kernel_type == 'half_cosine':
                    # cos(d_M^2 / xi) for d_M^2 < xi * pi / 2
                    if d_M_sq < (xi * np.pi / 2):
                        kernel_val = np.cos(d_M_sq / xi)
                    else:
                        kernel_val = 0.0
                elif kernel_type == 'inverse_mq':
                    # Standard Inverse Multiquadric: 1 / sqrt(1 + r^2)
                    # Or as per paper context, likely 1 / (1 + d_M^2) or similar
                    # The paper mentions "Inverse MQ" but doesn't give the exact formula in the snippet.
                    # Standard IMQ is 1 / sqrt(1 + (c*r)^2). 
                    # We use a standard form for demonstration.
                    kernel_val = 1.0 / (1.0 + d_M_sq)
                else:
                    kernel_val = 0.0
                
                # Apply Correction Factor
                weight = kernel_val * psi
                
                # Alpha blending
                # Standard 3DGS alpha blending:
                # C_out = C_in * (1 - alpha * weight) + C_prim * alpha * weight
                # Note: The paper implies the kernel value contributes to the opacity/weight.
                # In 3DGS, the Gaussian PDF value is used directly as the weight.
                
                current_alpha = alpha_buffer[y, x]
                current_color = color_buffer[y, x]
                
                # The effective opacity contribution of this splat
                splat_alpha = alpha * weight
                
                # Blend
                new_alpha = current_alpha + splat_alpha * (1 - current_alpha)
                new_color = (current_color * current_alpha + color * splat_alpha * (1 - current_alpha)) / new_alpha if new_alpha > 0 else current_color
                
                alpha_buffer[y, x] = new_alpha
                color_buffer[y, x] = new_color
                
    return color_buffer, alpha_buffer
```

**Parameters:**
*   $\xi$: Scale parameter for the half-cosine kernel. Typical value: Not given in the sources.
*   $\psi$: Scalar correction factor. Precomputed via closed-form regression experiments. Value: Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Unbounded Functions:** Functions that grow unbounded cause instability and are omitted; only decaying functions are used [S1].
*   **Integration Cost:** Using non-Gaussian kernels without the correction factor $\psi$ incurs costly integration processes, making them computationally inefficient [S1].
*   **Projection Approximation:** The shortcut of skipping the third row/column of the 3D covariance matrix is an approximation. While efficient, it may introduce inaccuracies compared to full integration, though the paper claims it preserves computational efficiency [S1].

## Operating characteristics
*   **Training Speed:** The half-cosine kernel variant achieves 34% faster training convergence compared to standard Gaussian kernels [S1].
*   **Memory Usage:** The half-cosine kernel reduces memory usage by 15% compared to standard Gaussian kernels [S1].
*   **Visual Quality:** Achieves comparable PSNR, SSIM, and LPIPS results to standard 3DGS [S1].
*   **Kernel Spread:** Half-cosine and Inverse MQ functions span a larger region with higher opacity for the same variance, reducing the need for multiple splats to achieve the same accumulated value [S1].
*   **Strengths:** Faster training, lower memory footprint, plug-and-play replacement for Gaussian kernels [S1].
*   **Limitations:** Relies on an approximation for 2D projection; requires precomputed correction factors for optimal performance [S1].

## Background
DARBF-Splatting was introduced by Hashiru Pramuditha, Vinasirajan Viruthshaan, Vishagar Arunan, Saeedha Nazar, Sameera Ramasinghe, Simon Lucey, and Ranga Rodrigo from the University of Moratuwa and University of Adelaide [S1]. It was published in 2026 [S1]. The method addresses the limitation of 3D Gaussian Splatting (3DGS) being restricted to the exponential family of functions, generalizing splatting to non-exponential decaying anisotropic radial basis functions [S1].
