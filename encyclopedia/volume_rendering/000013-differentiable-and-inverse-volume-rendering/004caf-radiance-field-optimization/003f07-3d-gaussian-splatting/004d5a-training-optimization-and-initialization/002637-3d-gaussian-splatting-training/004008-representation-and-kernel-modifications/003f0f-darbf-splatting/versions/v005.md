# DARBF-Splatting

Also called: DARB-Splatting, Decaying Anisotropic Radial Basis Functions Splatting

## Overview
DARBF-Splatting is a splatting-based 3D reconstruction method that replaces the standard Gaussian reconstruction kernel with a class of Decaying Anisotropic Radial Basis Functions (DARBFs) [S1]. It solves the limitation of 3D Gaussian Splatting (3DGS) being restricted to the exponential family, offering improved training convergence speed and reduced memory usage while maintaining comparable rendering quality [S1]. Unlike standard 3DGS, DARBF-Splatting allows non-exponential functions (e.g., half-cosine, inverse multiquadric) as kernels, which span a larger region with higher opacity for the same variance, thereby reducing the need for multiple splats [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Sparse 3D point cloud from Structure-from-Motion (SfM) (e.g., COLMAP), camera poses, and input images [S1].
*   **Outputs:** Optimized 3D DARBF primitives (ellipsoids) and their attributes (position, covariance, opacity, color) [S1].

**Data Structures:**
The 3D primitive is defined by a mean position $\boldsymbol{\mu}$ and a 3x3 covariance matrix $\boldsymbol{\Sigma}$ [S1]. The covariance matrix defines the anisotropic shape and orientation of the DARBF primitive [S1]. For 2D projection, the 2x2 covariance matrix is obtained by skipping the third row and column of the 3x3 covariance matrix [S1].

**Method Steps:**
1.  **Initialization:** Place 3D DARBF primitives at 3D points from the SfM pipeline [S1]. Each primitive acts as a reconstruction kernel [S1].
2.  **Transformation:** Transform the 3D DARBF primitives into the camera frame [S1].
3.  **Projection:** Project the 3D DARBF primitive onto the 2D image plane to create a footprint function (splat function) [S1]. This process exploits the property that the 2D covariance matrix can be obtained by skipping the third row and column of the 3D covariance matrix, bypassing costly integration [S1].
4.  **Kernel Evaluation:** Evaluate the DARBF kernel function based on the Mahalanobis distance $d_M$ [S1]. The Mahalanobis distance from a point $\mathbf{x}$ to the center $\boldsymbol{\mu}$ with covariance $\boldsymbol{\Sigma}$ is calculated as:
    $$d_M(\mathbf{x}; \boldsymbol{\mu}, \boldsymbol{\Sigma}) = [(\mathbf{x} - \boldsymbol{\mu})^T \boldsymbol{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})]^{\frac{1}{2}} \quad (1)$$
    [S1]
5.  **Correction Factor Application:** Apply a unique correction factor $\psi$ to approximate the Gaussian's closed-form integration shortcut, preserving computational efficiency [S1]. The sources indicate that a scalar $\psi$ precomputed from closed-form regression experiments is selected for computational efficiency [S1].
6.  **Rasterization:** Composite the splats using alpha blending to render the image [S1].
7.  **Optimization:** Backpropagate photometric loss to optimize the 3D DARBF parameters [S1].

**Pseudocode:**
```python
# DARBF-Splatting Kernel Evaluation
# Inputs:
#   x: 2D point on image plane (vector)
#   mu_2d: 2D mean of projected splat (vector)
#   Sigma_2d: 2x2 2D covariance matrix
#   kernel_type: string, e.g., 'half_cosine'
#   psi: scalar correction factor

def evaluate_darb_kernel(x, mu_2d, Sigma_2d, kernel_type, psi):
    # Calculate Mahalanobis distance squared
    diff = x - mu_2d
    # Inverse of 2x2 matrix Sigma_2d
    Sigma_inv = inverse_2x2(Sigma_2d)
    d_M_sq = dot(diff, dot(Sigma_inv, diff))
    
    # Evaluate kernel function based on type
    if kernel_type == 'half_cosine':
        # Half-cosine: cos(d_M^2 / xi) for d_M^2 < xi * pi / 2
        # Note: xi is a parameter of the kernel. 
        # The source mentions beta=2 for modified half-cosine in Table 1, 
        # but the formula uses xi. We assume xi is provided or derived.
        # For standard half-cosine as per text: cos(d_M^2 / xi)
        # The text says "cos(d_M^2 / xi) for d_M^2 < xi * pi / 2".
        # We need xi. Let's assume xi is a hyperparameter passed or fixed.
        # The source doesn't explicitly define xi's value in the text body, 
        # but mentions beta=2 for modified half-cosine. 
        # We will use a generic xi parameter.
        if d_M_sq < xi * pi / 2:
            value = cos(d_M_sq / xi)
        else:
            value = 0.0
    elif kernel_type == 'inverse_mq':
        # Inverse Multiquadric: 1 / (1 + d_M^2)
        # Source mentions "Inverse MQ" and "inverse multiquadrics"
        value = 1.0 / (1.0 + d_M_sq)
    elif kernel_type == 'radial_cosine':
        # Radial Cosine: similar to half-cosine but potentially different support
        # Source lists "radial Cosine" in Table 6.
        # Assuming similar form to half-cosine for demonstration.
        if d_M_sq < xi * pi / 2:
            value = cos(d_M_sq / xi)
        else:
            value = 0.0
    else:
        raise ValueError("Unsupported kernel type")
    
    # Apply correction factor
    return psi * value

def inverse_2x2(M):
    # M is 2x2 matrix [[a, b], [c, d]]
    a, b = M[0][0], M[0][1]
    c, d = M[1][0], M[1][1]
    det = a * d - b * c
    if det == 0:
        return [[0, 0], [0, 0]] # Guard against singular matrix
    return [[d/det, -b/det], [-c/det, a/det]]
```

**Parameters:**
*   $\xi$ (xi): Parameter for half-cosine kernel support. Not given in the sources.
*   $\psi$ (psi): Scalar correction factor. Precomputed from closed-form regression experiments [S1].

**Edge Cases and Pitfalls:**
*   Unbounded growing functions cause instability and are omitted in favor of DARBFs (decaying functions) [S1].
*   Using functions outside the Gaussian family typically incurs costly integration processes, making them computationally inefficient for splatting [S1]. DARBF-Splatting addresses this with the correction factor $\psi$ [S1].
*   The half-cosine kernel has finite support, defined as $\cos \left (\frac {d\_M^2}{\xi }\right )$ for $d\_M^2 < \frac {\xi \pi }{2}$ where $\xi > 0$ [S1].

## Subtopics

### Half-Cosine Kernel
A DARBF variant with finite support. It achieves 34% faster training convergence and 15% lower memory usage compared to standard Gaussian kernels, with comparable PSNR, SSIM, and LPIPS results [S1]. It spans a larger region with higher opacity for the same variance, reducing the need for multiple splats [S1].

### Inverse Multiquadric Kernel
A DARBF variant with a wide-spread area under the curve. It is preferable for densely-spanned kernels and reduces the need for multiple splats [S1].

## Operating characteristics
*   **Time Complexity:** DARBF-Splatting achieves 34% faster training convergence compared to standard Gaussian kernels [S1].
*   **Memory Complexity:** DARBF-Splatting reduces memory usage by 15% compared to standard Gaussian kernels [S1].
*   **Performance:** Comparable PSNR, SSIM, and LPIPS results to 3DGS [S1]. Half-cosine achieves 27.04 PSNR, 0.92 SSIM, and 27.06 LPIPS on Mip-NeRF 360 scenes with the correction factor $\psi$ [S1].
*   **Strengths:** Improved training speed and memory efficiency. Generalizes splatting to non-exponential functions.
*   **Limitations:** Requires a correction factor $\psi$ to approximate Gaussian integration properties. The specific values for kernel parameters like $\xi$ are not fully detailed in the provided text.

## Background
DARBF-Splatting was introduced by Hashiru Pramuditha, Vinasirajan Viruthshaan, Vishagar Arunan, Saeedha Nazar, Sameera Ramasinghe, Simon Lucey, and Ranga Rodrigo from the University of Moratuwa and University of Adelaide [S1]. It was published in 2026 [S1]. The method generalizes splatting techniques beyond the conventional exponential family, addressing the underexplored area of non-Gaussian reconstruction kernels in splatting-based 3D reconstruction [S1].
