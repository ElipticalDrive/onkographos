# Negative Gaussian Splatting

Also called: NegGS, Diff-Gaussian

## Overview
Negative Gaussian Splatting (NegGS) is a variant of 3D Gaussian Splatting that extends the primitive representation by incorporating "negative Gaussians"—ellipsoids with negative color values—into the optimization process [S1, S2]. It solves the limitation of standard Gaussian Splatting, which relies on positive-only components to model complex nonlinear structures and high-frequency elements, often requiring a large number of primitives and increasing time complexity [S2]. By allowing positive and negative Gaussians to cancel each other out, NegGS provides greater flexibility in shape representation and color modulation, particularly for rapid color transitions and shadows [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of calibrated multi-view images and camera poses.
*   **Output:** A joint family of Gaussian primitives $G_{NeGS}$ representing the 3D scene, optimized to minimize rendering loss.

**Data Structures:**
The method extends the standard 3DGS primitive tuple. Each primitive $i$ retains standard attributes (position $\mathbf{p}_i$, covariance $\Sigma_i$, opacity $\alpha_i$) but adds a color attribute $\mathbf{c}_i$ that can be negative.
*   **Primitive Tuple:** $(\mathbf{p}_i, \Sigma_i, \alpha_i, \mathbf{c}_i)$
*   **Mask:** A binary mask is used to track whether a Gaussian is positive or negative, preserving rendering speed [S1].

**Joint Family Definition:**
The scene is represented by a joint family of Gaussians:
$$ G_{NeGS} = G_{GS} \cup G_{-GS} $$
where $G_{GS}$ contains tuples with positive color values ($\mathbf{c}_i > 0$) and $G_{-GS}$ contains tuples with negative color values ($\mathbf{c}_i < 0$) [S1].

**Diff-Gaussian Concept:**
The method interprets the interaction between two Gaussians as a "Diff-Gaussian" distribution, defined by the ratio of their probability density functions (PDFs) [S2]. This allows the modeling of structures like donuts or moons, which are difficult for standard positive-only Gaussians [S2].

**Optimization Strategy:**
1.  **Initialization:** Initialize a set of Gaussians. The initial number of negative Gaussians is a critical hyperparameter, typically set to approximately 20% of the total Gaussians [S1].
2.  **Rasterization:** Render the scene using the differentiable rasterization pipeline. Negative colors are handled directly in the accumulation step, effectively subtracting radiance [S1].
3.  **Gradient Descent:** Optimize parameters (position, covariance, opacity, color) using gradient descent to minimize the difference between rendered and ground truth images [S1].
4.  **Pruning and Densification:**
    *   Gaussians with low opacity are pruned (reduced) [S1].
    *   New Gaussians are introduced into empty 3D regions to adapt the number of components dynamically [S1].
    *   The balance between positive and negative components is maintained through this dynamic adaptation [S1].

**Formulas:**
The optimal coefficient $c_{opt}$ for a Diff-Gaussian distribution formed by two Gaussians $f_{m_0, \Sigma_0}$ and $f_{m_1, \Sigma_1}$ is defined as [S1]:
$$ c_{opt} := \min_x \frac{f_{m_0, \Sigma_0}(x)}{f_{m_1, \Sigma_1}(x)} = \frac{f_{m_0, \Sigma_0}(w)}{f_{m_1, \Sigma_1}(w)} $$
if and only if $w$ satisfies [S1]:
$$ \Sigma_1^{-1}(w - m_1) = \Sigma_0^{-1}(w - m_0) $$
The vector $w$ minimizing the ratio is the argument that minimizes the quadratic function [S1]:
$$ q(x) = x^T A x + 2b^T x $$
where [S1]:
$$ A = \Sigma_1^{-1} - \Sigma_0^{-1} $$
$$ b = \Sigma_0^{-1} m_0 - \Sigma_1^{-1} m_1 $$
Assuming $A$ is positive semi-definite, $w$ is a solution to the linear system above [S1].

For diagonal covariance matrices $\Sigma_0 = \text{diag}(\sigma_1^2, \dots, \sigma_n^2)$ and $\Sigma_1 = \text{diag}(h_1 \sigma_1^2, \dots, h_n \sigma_n^2)$ with $0 < h_i \le 1$, the coordinates $w_i$ of the null density vector are [S1]:
1.  $w_i = \frac{m_{1,i} - h_i m_{0,i}}{1 - h_i}$ if $h_i < 1$
2.  $w_i \in \mathbb{R}$ if $h_i = 1$ and $m_{1,i} = m_{0,i}$

**Parameters:**
*   **Initial Negative Ratio:** ~20% of total Gaussians [S1].
*   **Hyperparameters:** Other hyperparameters are identical to standard Gaussian Splatting [S1].

**Pseudocode:**
```python
# NegGS Optimization Step
def optimize_neggs(scene_gaussians, images, cameras, learning_rate):
    """
    scene_gaussians: List of Gaussian primitives.
                     Each primitive has: position, covariance, opacity, color (can be negative).
                     A binary mask indicates if a primitive is positive or negative.
    images: Ground truth images.
    cameras: Camera parameters.
    learning_rate: Step size for optimization.
    """
    # 1. Render the scene
    # The rasterizer handles negative colors by subtracting their contribution
    # from the accumulated color, similar to how standard alpha blending works
    # but with signed values.
    rendered_images = render(scene_gaussians, cameras)
    
    # 2. Compute Loss
    # Standard photometric loss (e.g., L1 or LPIPS)
    loss = compute_loss(rendered_images, images)
    
    # 3. Backpropagate
    gradients = compute_gradients(loss, scene_gaussians)
    
    # 4. Update Parameters
    for gaussian in scene_gaussians:
        # Update position
        gaussian.position -= learning_rate * gradients.position
        
        # Update covariance (ensure positive semi-definite)
        gaussian.covariance -= learning_rate * gradients.covariance
        
        # Update opacity
        gaussian.opacity -= learning_rate * gradients.opacity
        
        # Update color (can be negative)
        gaussian.color -= learning_rate * gradients.color
        
    # 5. Pruning and Densification
    # Prune low opacity Gaussians
    scene_gaussians = prune_low_opacity(scene_gaussians, threshold=0.005)
    
    # Densify in empty regions
    scene_gaussians = densify_empty_regions(scene_gaussians, cameras, images)
    
    return scene_gaussians
```

**Edge Cases and Pitfalls:**
*   **Precision:** The use of negative colors requires careful handling of floating-point precision during accumulation to avoid artifacts [G].
*   **Initialization:** The initial proportion of negative Gaussians is critical; too few may not provide the benefit, while too many may destabilize optimization [S1].
*   **Degenerate Input:** If two Gaussians have identical parameters and inverse colors, they cancel out, which is a feature but may lead to redundancy if not managed [S1].

## Operating characteristics
*   **Time Complexity:** NegGS alleviates the time complexity increase associated with using many Gaussian components to model complex nonlinear structures [S2]. It leverages the original GS framework implementation, preserving the original GS rendering speed [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:**
    *   On Mip-NeRF360, NegGS-30K achieved an average PSNR of 27.39, SSIM of 0.812, and LPIPS of 0.219, compared to GS-30K's 27.21 PSNR, 0.815 SSIM, and 0.214 LPIPS [S1].
    *   On NeRF Synthetic, NegGS showed slight improvements or comparable performance to GS [S1].
*   **Strengths:**
    *   Better modeling of high-frequency elements with rapid color transitions [S1, S2].
    *   Improved representation of shadows [S2].
    *   More effective approximation of complex nonlinear structures (e.g., donuts, moons) [S2].
    *   Requires fewer total Gaussians for similar quality compared to standard GS [S1].
*   **Limitations:**
    *   Requires careful tuning of the initial number of negative Gaussians [S1].
    *   May introduce instability if the balance between positive and negative components is not maintained [S1].
*   **When to Use:** Use NegGS when the scene contains complex nonlinear structures, high-frequency details, or requires accurate shadow representation, and when standard GS requires an excessive number of primitives [S1, S2].
*   **When Not to Use:** For simple scenes with smooth color transitions, standard GS may be sufficient and simpler to tune [S2].

## Background
*   **Origin:** NegGS was introduced as the first paper to extend the simple ellipsoid shapes of Gaussian Splatting to more complex nonlinear structures [S2].
*   **History:** The method was developed to address the limitations of standard Gaussian Splatting in modeling complex 3D objects composed of curves and nonlinear structures [S2].
*   **Usage:** Evaluated on NeRF Synthetic, Mip-NeRF360, Tanks and Temples, Deep Blending, and Shiny Blender datasets [S1].
