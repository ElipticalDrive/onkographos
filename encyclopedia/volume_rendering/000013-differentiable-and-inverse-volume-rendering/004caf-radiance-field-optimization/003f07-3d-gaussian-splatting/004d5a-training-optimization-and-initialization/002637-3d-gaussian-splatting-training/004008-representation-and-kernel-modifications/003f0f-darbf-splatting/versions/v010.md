# DARBF-Splatting

Also called: DARB-Splatting, Decaying Anisotropic Radial Basis Functions Splatting

## Overview
DARBF-Splatting is a method for differentiable volume rendering that replaces the standard Gaussian reconstruction kernels of 3D Gaussian Splatting with a broader class of non-exponential functions called Decaying Anisotropic Radial Basis Functions (DARBFs) [S1]. It solves the limitation of splatting methods being restricted to the exponential family by enabling the use of kernels such as half-cosine and inverse multiquadric, which offer faster training convergence and lower memory usage while maintaining comparable visual quality [S1]. Unlike its siblings, it introduces a scalar correction factor to approximate the closed-form integration shortcut inherent to Gaussians, allowing efficient rasterization of these alternative kernels [S1].

## How it works
**Inputs and Outputs:**
The method takes the same inputs as standard 3D Gaussian Splatting: a set of 3D Gaussian primitives defined by mean position $\boldsymbol{\mu}$, covariance matrix $\boldsymbol{\Sigma}$, opacity $\alpha$, and spherical harmonic coefficients for color, along with camera parameters [S1]. The output is a rendered image generated by rasterizing these primitives using DARBF kernels [S1].

**Data Structures:**
The primitive representation retains the 3D covariance matrix $\boldsymbol{\Sigma}$, which is a $3 \times 3$ symmetric positive-definite matrix defining the anisotropic shape and orientation of the ellipsoid [S1]. For 2D projection, the $2 \times 2$ covariance matrix is obtained by skipping the third row and column of the $3 \times 3$ covariance matrix [S1].

**Mahalanobis Distance:**
The core of the DARBF kernel is the Mahalanobis distance $d_M$, which measures the distance from a point $\mathbf{x}$ to the center $\boldsymbol{\mu}$ with covariance $\boldsymbol{\Sigma}$ [S1]:

$$
d_M(\mathbf{x}; \boldsymbol{\mu}, \boldsymbol{\Sigma}) = [(\mathbf{x} - \boldsymbol{\mu})^T \boldsymbol{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})]^{\frac{1}{2}}
$$

**Kernel Functions:**
DARBFs are non-negative, decaying functions of $d_M$. The paper highlights two specific variants:
1.  **Half-Cosine:** Defined as $\cos \left (\frac {d_M^2}{\xi }\right )$ for $d_M^2 < \frac {\xi \pi }{2}$, where $\xi > 0$ is a scaling parameter [S1]. It has finite support [S1].
2.  **Inverse Multiquadric (Inverse MQ):** A function that spans a larger region with higher opacity for the same variance compared to Gaussians [S1].

**Correction Factor:**
Standard splatting relies on the property that the 2D projection of a 3D Gaussian is a 2D Gaussian, allowing for a closed-form integration shortcut [S1]. DARBFs do not possess this closure property. To approximate this efficiency, DARBF-Splatting introduces a correction factor $\psi$ [S1]. The authors evaluated using $\psi$ from an MLP and a precomputed scalar $\psi$ derived from closed-form regression experiments, selecting the scalar $\psi$ for computational efficiency [S1]. The rendered opacity contribution is adjusted by this factor [S1].

**Pseudocode:**
The following pseudocode outlines the rasterization step for a single pixel, assuming the standard 3DGS pipeline for projection and sorting, but replacing the Gaussian kernel evaluation with the DARBF logic.

```python
def render_darbf_splatting(scene_primitives, camera):
    """
    Renders a frame using DARBF-Splatting.
    scene_primitives: List of primitives, each with fields:
        - mu: 3D mean position (vec3)
        - Sigma: 3x3 covariance matrix (mat3)
        - alpha: opacity (float)
        - sh_coeffs: spherical harmonic coefficients (array)
        - kernel_type: string ('half_cosine' or 'inverse_mq')
        - xi: scaling parameter for half_cosine (float)
    camera: Camera object with projection matrix and view matrix.
    """
    # 1. Project 3D primitives to 2D
    # This step is identical to standard 3DGS:
    # - Transform mu to camera space.
    # - Compute 2D covariance Sigma_2d by taking the top-left 2x2 block of the 
    #   transformed 3x3 covariance matrix (skipping the third row/column).
    # - Compute the 2D bounding box for each splat.
    splats = []
    for prim in scene_primitives:
        # Standard 3DGS projection logic [S1]
        mu_3d = prim.mu
        Sigma_3d = prim.Sigma
        
        # Transform to camera space (details omitted, standard 3DGS)
        mu_2d, Sigma_2d = project_3d_to_2d(mu_3d, Sigma_3d, camera)
        
        # Calculate bounding box
        bbox = compute_bounding_box(Sigma_2d)
        
        splats.append({
            'mu_2d': mu_2d,
            'Sigma_2d': Sigma_2d,
            'alpha': prim.alpha,
            'sh_coeffs': prim.sh_coeffs,
            'kernel_type': prim.kernel_type,
            'xi': prim.xi,
            'bbox': bbox
        })
    
    # 2. Rasterize
    image = zeros_like(output_resolution)
    
    # Sort splats by depth (standard 3DGS)
    splats = sort_by_depth(splats)
    
    for splat in splats:
        # Iterate over pixels in the bounding box
        for pixel in splat.bbox:
            # Calculate 2D position relative to splat center
            x = pixel - splat.mu_2d
            
            # Calculate Mahalanobis distance squared
            # d_M^2 = x^T * Sigma_2d^-1 * x
            inv_Sigma_2d = inverse(splat.Sigma_2d)
            d_M_sq = dot(x, dot(inv_Sigma_2d, x))
            
            # Evaluate DARBF kernel
            if splat.kernel_type == 'half_cosine':
                # cos(d_M^2 / xi) for d_M^2 < xi * pi / 2, else 0
                threshold = splat.xi * pi / 2
                if d_M_sq < threshold:
                    kernel_val = cos(d_M_sq / splat.xi)
                else:
                    kernel_val = 0.0
            elif splat.kernel_type == 'inverse_mq':
                # Standard Inverse Multiquadric form: 1 / sqrt(1 + d_M^2)
                # Note: Exact formula for Inverse MQ in DARB context may vary,
                # but it is a decaying function of d_M [S1].
                # Using standard inverse multiquadric as representative:
                kernel_val = 1.0 / sqrt(1.0 + d_M_sq)
            else:
                kernel_val = 0.0
            
            # Apply correction factor psi
            # psi is a scalar precomputed from regression [S1]
            # The exact integration of the kernel is approximated by psi * kernel_val
            # In standard 3DGS, the integral of Gaussian is 1. Here, psi approximates 
            # the integral of the DARBF kernel to maintain energy consistency.
            corrected_kernel = splat.psi * kernel_val
            
            # Accumulate color and opacity
            # Standard alpha blending
            color = sample_sh(splat.sh_coeffs, x) # Sample SH based on view direction
            alpha_contribution = splat.alpha * corrected_kernel
            
            # Blend into image (standard 3DGS order-dependent blending)
            image[pixel] = blend(image[pixel], color, alpha_contribution)
            
    return image
```

**Edge Cases and Pitfalls:**
*   **Unbounded Functions:** Functions that grow unbounded cause instability and are omitted in favor of decaying functions [S1].
*   **Integration Cost:** Using functions outside the Gaussian family typically incurs costly integration processes, making them computationally inefficient if the correction factor is not used [S1].
*   **Finite Support:** Half-cosine kernels have finite support, requiring careful handling of the boundary condition $d_M^2 < \frac {\xi \pi }{2}$ [S1].

## Operating characteristics
*   **Time Complexity:** The half-cosine kernel variant achieves 34% faster training convergence compared to standard Gaussian kernels [S1].
*   **Memory Complexity:** The method reduces memory usage by 15% compared to standard Gaussian kernels [S1].
*   **Performance:** On Mip-NeRF 360 scenes, the half-cosine variant achieves comparable PSNR, SSIM, and LPIPS results to 3DGS [S1]. Specifically, Table 6 in [S1] shows PSNR of 27.04 (vs 27.45 for 3DGS-updated with correction), SSIM of 0.92, and LPIPS of 27.06.
*   **Strengths:** Faster training, lower memory footprint, ability to use wider-spread kernels (like half-cosine and Inverse MQ) which span a larger region with higher opacity for the same variance, reducing the need for multiple splats [S1].
*   **Limitations:** Requires a correction factor $\psi$ to approximate Gaussian integration efficiency; performance is sensitive to the choice of kernel and its parameters (e.g., $\xi$) [S1].

## Background
DARBF-Splatting was introduced by Hashiru Pramuditha, Vinasirajan Viruthshaan, Vishagar Arunan, Saeedha Nazar, Sameera Ramasinghe, Simon Lucey, and Ranga Rodrigo from the University of Moratuwa and University of Adelaide [S1]. The paper was published in 2026 [S1]. It generalizes the splatting techniques introduced in 3D Gaussian Splatting [11] by expanding the kernel family beyond the exponential family [S1].
