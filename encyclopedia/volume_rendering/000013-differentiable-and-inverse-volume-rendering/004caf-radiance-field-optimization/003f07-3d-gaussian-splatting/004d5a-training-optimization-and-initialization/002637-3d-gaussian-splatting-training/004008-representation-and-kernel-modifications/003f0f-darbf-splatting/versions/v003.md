# DARBF-Splatting

Also called: DARB-Splatting, Decaying Anisotropic Radial Basis Functions Splatting

## Overview
DARBF-Splatting is a method that replaces the standard Gaussian reconstruction kernels in 3D Gaussian Splatting with a generalized class of Decaying Anisotropic Radial Basis Functions (DARBFs) [S1]. It solves the limitation of existing splatting methods being restricted to the exponential family, offering improved training convergence speed and reduced memory usage while maintaining comparable visual quality [S1]. Unlike standard 3DGS, which relies on the closed-form integration properties of Gaussians, DARBF-Splatting introduces a correction factor to approximate this efficiency for non-exponential kernels [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Sparse 3D point cloud from Structure-from-Motion (SfM) (e.g., COLMAP), camera poses, and input images [S1].
*   **Output:** A set of optimized DARBF primitives (ellipsoids) defined by mean position, covariance, opacity, and color, capable of differentiable rendering [S1].

**Data Structures:**
The primitive representation follows the standard 3DGS structure but uses DARBF kernels instead of Gaussians [S1]:
*   **Mean Position ($\boldsymbol{\mu}$):** 3D vector $(x, y, z)$ [S1].
*   **Covariance Matrix ($\boldsymbol{\Sigma}$):** A $3 \times 3$ symmetric positive-definite matrix defining the anisotropic shape and orientation of the ellipsoid [S1]. In implementation, this is often parameterized by rotation (quaternion) and scale (vector) [S1].
*   **Opacity ($\alpha$):** Scalar value in $[0, 1]$ [S1].
*   **Color ($\mathbf{c}$):** Represented by spherical harmonics coefficients or RGB values [S1].

**The DARBF Kernel:**
The core of the method is the kernel function $K(d_M)$, which depends on the Mahalanobis distance $d_M$ [S1]. The distance from a point $\mathbf{x}$ to the center $\boldsymbol{\mu}$ with covariance $\boldsymbol{\Sigma}$ is:
$$ d_M(\mathbf{x}; \boldsymbol{\mu}, \boldsymbol{\Sigma}) = [(\mathbf{x} - \boldsymbol{\mu})^T \boldsymbol{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})]^{\frac{1}{2}} \quad (1) $$
DARBFs are non-negative, decaying functions of $d_M$ [S1]. Examples include:
*   **Half-Cosine:** $\cos \left (\frac {d_M^2}{\xi }\right )$ for $d_M^2 < \frac {\xi \pi }{2}$, where $\xi > 0$ [S1]. This function has finite support [S1].
*   **Inverse Multiquadric (Inverse MQ):** A function spanning a larger region with higher opacity for the same variance compared to Gaussians [S1].
*   **Modified Raised Cosine / Modular Sinc:** Other variants mentioned as part of the DARBF spectrum [S1].

**Projection and Correction Factor:**
Standard 3DGS exploits the property that the 2D covariance matrix for a projected Gaussian can be obtained by simply skipping the third row and column of the 3D covariance matrix, bypassing costly integration [S1]. DARBFs do not share this closure property. To address this, DARBF-Splatting introduces a correction factor $\psi$ to approximate the Gaussian's closed-form integration shortcut [S1].
*   The correction factor $\psi$ is implemented as a scalar precomputed from closed-form regression experiments, chosen for computational efficiency over matrix-based or MLP-based approaches [S1].
*   This factor is applied to the kernel evaluation to correct the opacity contribution, ensuring accurate rendering despite the lack of exact integration closure [S1].

**Rendering Pipeline:**
1.  **Transformation:** Transform 3D DARBF primitives into the camera coordinate frame [S1].
2.  **Projection:** Project the 3D covariance $\boldsymbol{\Sigma}$ to 2D. For implementation, the 2D covariance matrix is obtained by skipping the third row and column of the 3D covariance matrix (as in 3DGS), then applying the view transformation Jacobian [S1].
3.  **Splatting:** Compute the footprint function (splat) for each primitive on the 2D image plane using the DARBF kernel $K(d_M)$ and the correction factor $\psi$ [S1].
4.  **Compositing:** Render the image using alpha compositing:
    $$ C = \sum_{i \in N} c_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    where $\alpha_i$ is derived from the DARBF kernel value at the pixel location [S1].
5.  **Optimization:** Minimize photometric loss (e.g., L1/L2) between rendered and ground-truth images via gradient descent [S1].

    diff = x - mu

**Parameters:**
*   **$\xi$ (xi):** Width parameter for DARBFs (e.g., $\xi > 0$ for half-cosine) [S1].
*   **Correction Factor ($\psi$):** A scalar precomputed from closed-form regression experiments [S1].
*   **Kernel Type:** 'half_cosine', 'inverse_mq', etc. [S1].

**Edge Cases and Pitfalls:**
*   **Unbounded Functions:** Functions that grow unbounded cause instability and are omitted; only decaying functions are used [S1].
*   **Integration Cost:** Using functions outside the Gaussian family typically incurs costly integration processes. The correction factor $\psi$ is essential to approximate the Gaussian's closed-form integration shortcut and maintain computational efficiency [S1].
*   **Precision:** The finite support of kernels like half-cosine requires careful handling of boundary conditions to avoid artifacts at the edge of the splat [S1].

## Operating characteristics
*   **Time Complexity:** Training convergence is 34% faster compared to standard Gaussian kernels [S1].
*   **Memory Complexity:** Memory usage is reduced by 15% compared to standard Gaussian kernels [S1].
*   **Performance:** Achieves comparable PSNR, SSIM, and LPIPS results to 3DGS [S1].
*   **Strengths:** Faster training, lower memory footprint, ability to use a wider variety of kernel shapes (e.g., half-cosine, inverse MQ) that span larger regions with higher opacity, reducing the need for multiple splats [S1].
*   **Limitations:** Requires a correction factor $\psi$ to approximate integration closure, which adds a layer of complexity compared to the exact closure of Gaussians [S1]. The method is currently limited to specific DARBF variants (half-cosine, inverse MQ, etc.) [S1].
*   **When to use:** When computational savings (training time and memory) are critical, such as in repetitive industrial applications [S1].
*   **When not to use:** When the exact integration properties of Gaussians are required, or if the overhead of tuning the correction factor $\psi$ is undesirable [S1].

## Background
DARBF-Splatting was introduced by Hashiru Pramuditha, Vinasirajan Viruthshaan, Vishagar Arunan, Saeedha Nazar, Sameera Ramasinghe, Simon Lucey, and Ranga Rodrigo from the University of Moratuwa and University of Adelaide [S1]. It was published in 2026 [S1]. The method addresses the limitation of 3D Gaussian Splatting being restricted to the exponential family of functions, generalizing splatting to non-exponential decaying anisotropic radial basis functions [S1]. It builds on the 3DGS framework [S1].
