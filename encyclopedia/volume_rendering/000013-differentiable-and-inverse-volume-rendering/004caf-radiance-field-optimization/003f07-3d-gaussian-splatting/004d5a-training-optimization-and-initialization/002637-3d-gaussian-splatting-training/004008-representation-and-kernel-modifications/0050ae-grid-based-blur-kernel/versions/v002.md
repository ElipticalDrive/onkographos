# Grid-based Blur Kernel

Also called: Sharpness-indexed Blur Kernels, Trainable Grid-based Blur Kernels

## Overview
Grid-based Blur Kernels replace the Multi-Layer Perceptron (MLP) used in prior works to generate blur kernels with a set of learnable, indexed grid tensors [S1]. This method models spatially-varying blurriness by assigning one of $N_k$ discrete blur kernels to each pixel based on a precomputed sharpness level [S1]. It differs from sibling methods like Negative Gaussian Splatting by explicitly handling defocus blur through a differentiable convolution operation rather than modifying the Gaussian primitive's covariance or opacity directly [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Clean image patch $I_c$ (or rendered image), sharpness level map $L$, and the blur kernel grid $\mathcal{B}$.
*   **Output:** Blurred image $I_b$ and gradients for $\mathcal{B}$.

**Data Structures:**
The core data structure is the blur kernel grid $\mathcal{B}$, a tensor with layout:
$$ \mathcal{B} \in \mathbb{R}^{N_{img} \times N_k \times K \times K \times C} $$
*   $N_{img}$: Number of training views.
*   $N_k$: Number of unique sharpness groups (blur kernels).
*   $K$: Kernel size (spatial dimension).
*   $C$: Number of channels (e.g., 3 for RGB).

**Steps:**
1.  **Sharpness Prior Estimation (Preprocessing):**
    *   Estimate a defocus map for every training view using a Defocus Map Estimation Network (DMENet) [S1].
    *   Quantize the defocus map uniformly into $N_k$ values to create a sharpness level map $L$ [S1].
    *   Optionally, segment the scene using depth information (e.g., from MIDAS) to assess focus levels within segments [S1].
    *   *Note:* This step is performed once before training and does not affect training time [S1].

2.  **Kernel Indexing:**
    *   For each pixel $x$ (at coordinates $h, w$) in a training view, determine its sharpness level $L[h,w]$.
    *   Map the pixel to its corresponding blur kernel $w_x$ using the mapping function $F$:
        $$ w_x = F(\mathcal{B}, L, x) $$
    *   $w_x$ is a tensor of shape $K \times K \times C$ retrieved from $\mathcal{B}$ at indices corresponding to the view, sharpness group $L[h,w]$, and spatial coordinates.

3.  **Image Cropping:**
    *   Crop the clean image $I_c$ along height and width with stride 1 to extract local neighborhoods.
    *   Resulting tensor $I_c'$ has shape $P' \times P' \times K \times K \times C$, where $P'$ is the patch dimension.
    *   *Note:* The source mentions cropping $I_c$ to get $I_c'$, but the convolution formula uses $I_c'$ indexed by $h,w$. In implementation, for a specific pixel $(h,w)$, the neighborhood is extracted from $I_c$.

4.  **Blurred Image Convolution:**
    *   Compute the blurred image $I_b$ at pixel $(h,w)$ by convolving the local neighborhood with the indexed kernel:
        $$ I_b[h,w] = \sum_{i=0}^{K-1} \sum_{j=0}^{K-1} I_c'[h,w,i,j] \cdot w_x[h,w,i,j] $$
    *   Here, $I_c'[h,w,i,j]$ represents the pixel value in the clean image at offset $(i,j)$ from $(h,w)$, and $w_x[h,w,i,j]$ is the corresponding weight from the blur kernel.
    *   *Optimization:* Skip convolution for pixels in the 100 groups of each view with the highest sharpness values (assuming they are already sharp) [S1].

5.  **Loss Computation:**
    *   Calculate the reconstruction loss $\mathcal{L}_{recon}$ as the Mean Squared Error (MSE) between the blurred image $I_b$ and the ground truth image $I_{gt}$:
        $$ \mathcal{L}_{recon} = ||I_b - I_{gt}||_2^2 $$
    *   Optimize $\mathcal{B}$ and the neural fields jointly using gradient descent [S1].

**Parameters:**
*   $K$: Kernel size. Set to 11 in experiments [S1].
*   $N_k$: Number of blur kernels. Set to 400 in experiments [S1].
*   Learning Rate: 0.05 for the blur kernels [S1].
*   Initialization: Blur kernels are initialized with a 2D Gaussian distribution [S1].
*   Patch Sampling: Random patch sampling is used. Patch size $P=22$, sampling 28 patches per iteration [S1].

**Pseudocode:**
```python
def compute_blurred_image(I_c, L, B, N_k, K, C, skip_groups):
    """
    I_c: Clean image tensor of shape (H, W, C)
    L: Sharpness level map of shape (H, W) with values in [0, N_k-1]
    B: Blur kernel grid of shape (N_views, N_k, K, K, C)
    N_k: Number of sharpness groups
    K: Kernel size
    C: Number of channels
    skip_groups: Set of sharpness group indices to skip convolution for
    """
    H, W, C = I_c.shape
    I_b = torch.zeros_like(I_c)
    
    # Precompute kernel lookups for efficiency
    # B_view is the subset of B for the current view
    # B_view shape: (N_k, K, K, C)
    
    for h in range(H):
        for w in range(W):
            sharpness_idx = int(L[h, w])
            
            # Skip convolution for high sharpness groups
            if sharpness_idx in skip_groups:
                I_b[h, w] = I_c[h, w]
                continue
            
            # Get the blur kernel for this pixel's sharpness level
            # w_x shape: (K, K, C)
            w_x = B[sharpness_idx]
            
            # Extract local neighborhood from clean image
            # Handle boundary conditions (e.g., padding or clamping)
            # Neighborhood shape: (K, K, C)
            # Assuming zero-padding or reflection padding for simplicity
            neighborhood = get_patch(I_c, h, w, K)
            
            # Convolve
            # Element-wise multiplication and sum over spatial dimensions
            blurred_pixel = torch.sum(neighborhood * w_x)
            I_b[h, w] = blurred_pixel
            
    return I_b

def get_patch(I, h, w, K):
    """Extract KxK patch centered at (h,w) with padding."""
    pad = K // 2
    H, W, C = I.shape
    # Pad the image
    I_padded = torch.nn.functional.pad(I, (pad, pad, pad, pad, 0, 0), mode='reflect')
    # Extract patch
    # New coordinates in padded image
    h_p, w_p = h + pad, w + pad
    patch = I_padded[h_p - pad : h_p + pad + 1, w_p - pad : w_p + pad + 1, :]
    return patch
```

## Subtopics

### Sharpness Prior with Defocus Map Estimation
A preprocessing variant that estimates a spatially varying defocus map to determine the sharpness level of image pixels, which is used to group pixels for blur kernel assignment [S1]. It uses DMENet, an end-to-end CNN framework, to estimate the defocus map for every training view [S1]. The defocus map is quantized uniformly into $N_k$ values to create the sharpness level map $L$ [S1]. Additionally, it segments the scene based on depth information (from MIDAS) to assess focus levels within each segment [S1]. This step is generic and can use any operator that reliably measures sharpness [S1].

## Operating characteristics
*   **Time Complexity:** The sharpness prior is computed once during preprocessing, taking less than a couple of minutes [S1]. During training, the method uses random patch sampling, reducing the number of required neighboring rays per pixel from $K^2$ to $(P' + K + 1)^2 / P'^2$ compared to full-ray sampling [S1].
*   **Memory Complexity:** The blur kernel grid $\mathcal{B}$ requires memory proportional to $N_{img} \times N_k \times K^2 \times C$ [S1].
*   **Performance:** The method successfully renders clean images even from harshly defocused regions [S1]. It improves expressivity by increasing the grid size without extra computational cost to produce kernels [S1].
*   **Strengths:** Joint optimization with neural fields allows rapid convergence [S1]. The grid-based approach is more efficient than MLP-based kernel generation [S1].
*   **Limitations:** Requires a preprocessing step for sharpness estimation [S1]. The method assumes the sharpness prior is accurate [S1].
*   **When to use:** When dealing with scenes containing real or synthetic defocus blur, such as those in the DeblurNeRF dataset [S1].
*   **When not to use:** When sharpness is uniform or not a significant factor in the scene [S1].

## Background
The method was introduced in "Sharp-NeRF: Grid-based Fast Deblurring Neural Radiance Fields using Sharpness Prior" [S1]. It addresses the limitations of NeRF and its derivatives in handling defocus blur by leveraging a sharpness prior and grid-based blur kernels [S1]. The approach builds on the idea that different regions of an image have different levels of sharpness, which can be modeled by assigning specific blur kernels to pixels based on their sharpness level [S1].
