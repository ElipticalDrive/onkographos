# Grid-based Blur Kernel

Also called: Sharpness-indexed Blur Kernels, Trainable Grid-based Blur Kernels

## Overview
Grid-based Blur Kernels replace MLP-generated blur kernels with a learnable, spatially-indexed grid to model spatially-varying blurriness in radiance field optimization [S1]. Unlike siblings that modify primitive geometry or negative contributions, this method explicitly handles defocus blur by assigning one of $N_k$ trainable kernels to pixels based on a sharpness prior, improving reconstruction quality in defocused regions without increasing kernel generation cost [S1].

## How it works
**Inputs and Outputs:**
- Input: Clean image patch $I_c$ (or rendered image), sharpness level map $L$, grid of blur kernels $\mathcal{B}$.
- Output: Blurred image $I_b$ used for reconstruction loss.

**Data Structures:**
- $\mathcal{B}$: Tensor of shape $\mathbb{R}^{N_{img} \times N_k \times K \times K \times C}$ [S1].
  - $N_{img}$: Number of training views.
  - $N_k$: Number of unique sharpness groups/blur kernels.
  - $K$: Kernel size (spatial dimension).
  - $C$: Number of channels.
- $L$: Sharpness level map, quantized defocus map with values in $\{0, \dots, N_k-1\}$ [S1].
- $I_c'$: Cropped image tensor of shape $P' \times P' \times K \times K$ [S1].

**Parameters:**
- $K$: Kernel size. Typical value: 11 [S1].
- $N_k$: Number of blur kernels. Typical value: 400 [S1].
- Learning rate for $\mathcal{B}$: 0.05 [S1].
- Initialization: 2D Gaussian distribution [S1].
- $P'$: Patch size dimension. Typical value: 22 (patch size $P=22$ implies $P'=22$ or similar local window) [S1]. Note: The text specifies sampling 28 patches with patch size $P=22$ [S1].

**Steps:**
1. **Sharpness Prior Estimation (Preprocessing):**
   - Estimate a defocus map for every training view using a Defocus Map Estimation Network (DMENet) [S1].
   - Segment the scene based on depth information (e.g., from MIDAS) to assess focus levels within segments [S1].
   - Quantize the defocus map uniformly into $N_k$ values to create the sharpness level map $L$ [S1]. This step is performed once and does not affect training time [S1].

2. **Kernel Selection:**
   - For each pixel $x$ (indexed by $h, w$) in a training view, determine its sharpness level $L[h,w]$.
   - Select the corresponding blur kernel $w_x$ from the grid $\mathcal{B}$ using the mapping function $F$:
     $$ w_x = F(\mathcal{B}, L, x) $$
     where $w_x \in \mathbb{R}^{K \times K \times C}$ is the kernel assigned to pixel $x$ [S1].
   - Optimization: Pixels sharing the same sharpness level $L$ share the same blur kernel from the $N_k$ available kernels [S1].

3. **Image Cropping:**
   - Crop the clean image $I_c$ along height and width with stride 1 to obtain $I_c'$ of shape $P' \times P' \times K \times K$ [S1]. This captures the local neighborhood required for convolution [S1].

4. **Blurred Image Synthesis:**
   - Compute the blurred image $I_b$ by convolving $I_c'$ with the selected kernels $w_x$:
     $$ I_b[h,w] = \sum_{i=0}^{K} \sum_{j=0}^{K} I_c'[h,w,i,j] w_x[h,w,i,j] $$
     where $h, w$ are indices along the height and width of the image and blur kernels, and $i, j$ are kernel spatial indices [S1].
   - **Optimization:** Skip convolution for pixels in 100 groups of each view with high sharpness values (i.e., sharp regions) to save computation [S1].

5. **Loss Calculation:**
   - Compute the reconstruction loss $\mathcal{L}_{recon}$ as the Mean Squared Error (MSE) between the blurred image $I_b$ and the ground truth image $I_{gt}$:
     $$ \mathcal{L}_{recon} = ||I_b - I_{gt}||_2 $$
     [S1].
   - Optimize both the blur kernels $\mathcal{B}$ and the neural fields jointly from the first training iteration [S1].

**Pseudocode:**

```python
def crop_with_stride(I, stride, kernel_size):
    """
    Crops image I to include kernel neighborhoods.
    Returns tensor of shape (H, W, kernel_size, kernel_size, C).
    """
    # This operation extracts a local window for each pixel.
    # In practice, this is often done via unfold or padding + strided view.
    # For implementation clarity:
    # Pad I to handle boundaries
    pad = kernel_size // 2
    I_padded = torch.nn.functional.pad(I, (pad, pad, pad, pad, 0, 0), mode='reflect')
    
    # Use unfold to get neighborhoods
    # unfold expects (N, C, H, W). I is (H, W, C).
    I_perm = I_padded.permute(2, 0, 1) # (C, H+2pad, W+2pad)
    neighborhoods = torch.nn.functional.unfold(I_perm, kernel_size=kernel_size, stride=1)
    # neighborhoods shape: (C, H*W, K*K)
    
    # Reshape to (H, W, K, K, C)
    H_out = I.shape[0]
    W_out = I.shape[1]
    neighborhoods = neighborhoods.permute(1, 2, 0) # (H*W, K*K, C)
    neighborhoods = neighborhoods.view(H_out, W_out, kernel_size, kernel_size, I.shape[2])
    
    return neighborhoods
```

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** The cropping operation requires handling image boundaries. Padding (e.g., reflect) is necessary to maintain spatial dimensions [S1].
- **Sharpness Prior Accuracy:** The quality of the blur kernels depends on the accuracy of the defocus map estimation. If the sharpness prior is inaccurate, pixels may be assigned incorrect blur kernels [S1].
- **Group Skipping:** Skipping convolution for sharp groups requires careful handling of the output tensor to ensure the final image $I_b$ is correctly formed for the loss calculation [S1].

## Subtopics

### Sharpness Prior with Defocus Map Estimation
A preprocessing step that estimates a spatially varying defocus map to determine the sharpness level of image pixels, which is used to group pixels for blur kernel assignment [S1]. It uses DMENet (an end-to-end CNN framework) to estimate the defocus map and MIDAS for depth information to segment the scene and assess focus levels within segments [S1]. The defocus map is quantized into $N_k$ values to create the sharpness level map $L$ [S1]. This method is generic and can use any operator that reliably measures sharpness [S1].

## Operating characteristics
- **Time Complexity:** The sharpness prior is computed once during preprocessing, taking less than a couple of minutes, and does not affect training or testing times [S1]. During training, convolution is skipped for pixels in 100 groups of each view with high sharpness values, reducing computational cost [S1].
- **Memory Complexity:** The blur kernels $\mathcal{B}$ are stored as a tensor of shape $\mathbb{R}^{N_{img} \times N_k \times K \times K \times C}$ [S1]. With $N_k=400, K=11$, this is a fixed memory overhead independent of the number of pixels [S1].
- **Scaling:** Expressivity of the blur kernels can be improved by simply increasing the grid size ($N_k$) without extra cost to produce kernels [S1].
- **Strengths:** Successfully renders clean images even from harshly defocused regions [S1]. More efficient than per-pixel kernel generation via MLP [S1].
- **Limitations:** Relies on the accuracy of the sharpness prior (defocus map estimation) [S1].

## Background
Originated in "Sharp-NeRF: Grid-based Fast Deblurring Neural Radiance Fields using Sharpness Prior" [S1]. It addresses the limitation of previous works that used MLPs to generate blur kernels, which are less expressive and more costly [S1]. The method builds on the concept of spatially-varying blur in radiance fields, leveraging depth and defocus information to model blurriness [S1].
