# Dynamic and Temporal Modeling

Also called: Dynamic NeRF, 4D Radiance Fields, On-the-Fly Training

## Overview
Dynamic and Temporal Modeling extends static NeRF to reconstruct scenes that change over time, representing a 4D radiance field (3D space + time) [S1, S2]. It solves the problem of modeling non-rigid motion and temporal evolution, which static NeRF cannot handle [S1]. Unlike static methods, these approaches must explicitly or implicitly encode temporal dependencies, distinguishing them from [Training Ray Marching and Integration](2199-training-ray-marching-and-integration.md) which assumes a static scene.

## Shared principles
All methods in this family map input coordinates $(\mathbf{x}, \mathbf{d}, t)$ to density $\sigma$ and color $\mathbf{c}$ [S1, S2]. The core challenge is handling the temporal dimension $t$ without prohibitive memory or computational costs. Common strategies include:
1.  **Explicit Temporal Input:** Feeding $t$ directly into the MLP [S2].
2.  **Deformation Fields:** Mapping dynamic points to a static canonical space [S2].
3.  **On-the-Fly/Streaming:** Processing frames sequentially with a Markov assumption to avoid storing full history [S1].
4.  **Implicit Correspondence:** Using geometric or photometric cues (e.g., projected color) to track points across time without explicit deformation [S1].

## Subtopics

### [Neural Transient Field (NeTF)](4692-neural-transient-field-netf.md)
Models 5D transient light transport for Non-Line-of-Sight (NLOS) imaging using spherical wavefronts and MCMC sampling. Choose for NLOS reconstruction where sparse, unbalanced data requires robust sampling strategies.

### [Projected Color-Guided Dynamic NeRF](7523-projected-color-guided-dynamic-nerf.md)
Uses projected color statistics from previous frames to guide current frame training, avoiding explicit deformation fields. Choose for interactive, on-the-fly training of dynamic scenes where deformation fields are unstable or costly.

### [On-the-Fly Dynamic NeRF Training](7582-on-the-fly-dynamic-nerf-training.md)
Streams dynamic scenes frame-by-frame using a first-order Markov assumption. Choose for real-time reconstruction of forward-facing dynamic scenes where offline optimization is infeasible.

### [D-NeRF](8660-d-nerf.md)
Decomposes scenes into a static canonical template and a learned deformation field. Choose for offline reconstruction of scenes with complex non-rigid motion where a static prior is beneficial.

## Background
Dynamic NeRF was introduced by [D-NeRF](8660-d-nerf.md) [S1, S2], which proposed mapping dynamic observations to a static canonical space via a deformation field. This addressed the difficulty of learning complex motions directly in observation space [S1]. Subsequent work expanded to on-the-fly methods [S1] and specialized domains like NLOS [S1].
