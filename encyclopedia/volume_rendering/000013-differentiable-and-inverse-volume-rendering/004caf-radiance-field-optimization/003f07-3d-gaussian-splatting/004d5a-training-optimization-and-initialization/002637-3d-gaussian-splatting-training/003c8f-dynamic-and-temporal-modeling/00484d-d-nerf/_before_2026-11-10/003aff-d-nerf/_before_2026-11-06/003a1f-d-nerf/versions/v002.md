# D-NeRF

Also called: Deformable Neural Radiance Fields

## Overview
D-NeRF is a method for dynamic scene reconstruction that decomposes the scene into a static canonical template and a learned deformation field [S1, S2]. It differs from direct temporal modeling approaches (like DyNeRF) by mapping dynamic observations to a static space, allowing the use of static NeRF priors for radiance prediction [S1]. This approach addresses the difficulty of learning complex scene motions directly in the observation space [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D spatial coordinates $\mathbf{x}$, viewing direction $\mathbf{d}$, and time $t$.
*   **Outputs:** Volume density $\sigma$ and view-dependent color $\mathbf{c}$.

**Data Structures:**
1.  **Deformation Network ($\mathcal{D}$):** An MLP that maps a point from the observation space at time $t$ to the canonical space.
    *   Input: $(\mathbf{x}, t)$
    *   Output: $\mathbf{x}_c$ (canonical coordinate)
2.  **Radiance Field Network ($\mathcal{F}$):** A standard static NeRF MLP.
    *   Input: $(\mathbf{x}_c, \mathbf{d})$
    *   Output: $(\sigma, \mathbf{c})$

**Numbered Steps:**
1.  **Canonical Mapping:** For a sampled point $\mathbf{x}$ at time $t$, compute its canonical coordinate $\mathbf{x}_c$ using the deformation network:
    $$ \mathbf{x}_c = \mathcal{D}(\mathbf{x}, t) $$
    [S1, S2]
2.  **Radiance Prediction:** Query the static radiance field network using the canonical coordinate and viewing direction:
    $$ (\sigma, \mathbf{c}) = \mathcal{F}(\mathbf{x}_c, \mathbf{d}) $$
    [S1, S2]
3.  **Volume Rendering:** Integrate $\sigma$ and $\mathbf{c}$ along the ray using standard volume rendering equations to produce the final pixel color [S2].

**Parameters:**
*   Network architectures for $\mathcal{D}$ and $\mathcal{F}$ are not specified in the sources. [G: Typically, $\mathcal{D}$ uses a small MLP with positional encoding for $t$, and $\mathcal{F}$ uses the standard 8-layer NeRF MLP with positional encoding for $\mathbf{x}_c$ and $\mathbf{d}$.]

**Edge Cases and Pitfalls:**
*   **Complex Motions:** The deformation field is difficult to learn when scene motions are complex, leading to blurry results similar to Neural Volumes [S1].
*   **Topology Changes:** Deformation-based methods cannot simulate topological changes because the deformation field must be continuous, whereas topology changes require discontinuities [S2].

## Operating characteristics
*   **Strengths:** Leverages static NeRF priors for better detail preservation in the canonical space [S1].
*   **Limitations:** Struggles with complex scene motions, resulting in blurry outputs [S1]. Cannot handle topological changes due to the continuity constraint of the deformation field [S2].
*   **Performance:** Specific quantitative performance metrics (PSNR, SSIM) are not provided for D-NeRF in the sources, only comparative qualitative assessments [S1].

## Background
D-NeRF was proposed by Park et al. in 2021 [S1, S2]. It is a baseline method that treats time $t$ as an additional input for system rendering, controlling both camera view and time variables for dynamic rendering [S2]. It decomposes the dynamic scene into a static scene in the canonical space and a deformation field [S1].
