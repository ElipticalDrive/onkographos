# 3D Half-Gaussian Splatting Covariance Transformation and Regularization

Also called: 3D-HGS

## Overview
3D Half-Gaussian Splatting (3D-HGS) modifies the standard 3D Gaussian kernel into a half-ellipsoid to better model sharp surface boundaries and occlusions, effectively representing the sharp transitions between object surfaces and empty space [S1]. It achieves this by transforming the covariance matrix into a local basis aligned with a splitting plane normal, projecting the covariance to enforce near-zero variance along the normal direction, and then transforming it back to world space [S1]. This method builds on [Regularization and Geometry Constraints](6269-regularization-and-geometry-constraints.md) by applying a structural constraint to the Gaussian parameters themselves rather than an auxiliary loss term [G].

## How it works
### Inputs and Outputs
*   **Input**: The original 3D Gaussian covariance matrix $\Sigma$ (3x3 symmetric positive definite) and the splitting plane normal vector $n$ (3x1) [S1].
*   **Output**: The regularized covariance matrix $\sigma$ (3x3) representing the half-Gaussian [S1].

### Data Structures
The covariance matrix $\Sigma$ is stored as a 3x3 symmetric matrix [S1]. The normal vector $n$ is a 3-element unit vector [S1]. Not given in the sources.

### Algorithm Steps
The transformation is performed in the following steps [S1]. The transformation is applied every 5000 iterations during training [S1].

1.  **Normalize the normal vector**:
    $$ n \leftarrow \frac{n}{\|n\|} $$ [S1]

2.  **Construct the local basis**:
    Define two orthogonal vectors $v_1$ and $v_2$ that, together with $n$, form an orthonormal basis [S1].
    *   If $n_x = 0$ and $n_y = 0$ (i.e., $n$ is parallel to the Z-axis):
        $$ v_1 = (1, 0, 0) $$
        $$ v_2 = (0, 1, 0) $$ [S1]
    *   Otherwise:
        $$ v_1 \leftarrow \frac{(n_y, -n_x, 0)}{\|(n_y, -n_x, 0)\|} $$
        $$ v_2 \leftarrow \frac{n \times v_1}{\|n \times v_1\|} $$ [S1]
    *   Construct the basis matrix $B$ by concatenating these vectors as columns:
        $$ B = \begin{bmatrix} | & | & | \\ v_1 & v_2 & n \\ | & | & | \end{bmatrix} $$ [S1]

3.  **Transform covariance to local basis**:
    $$ \Sigma_{local} \leftarrow B^T \Sigma B $$ [S1]

4.  **Compute modified diagonal/off-diagonal elements**:
    Let $\Sigma_{local}$ elements be denoted as $cov_{i,j}$ [S1].
    $$ a' \leftarrow cov_{0,0} - \frac{cov_{0,2}^2}{cov_{2,2}} $$ [S1]
    $$ b' \leftarrow cov_{0,1} - \frac{cov_{0,2} \cdot cov_{1,2}}{cov_{2,2}} $$ [S1]
    $$ c' \leftarrow cov_{1,1} - \frac{cov_{1,2}^2}{cov_{2,2}} $$ [S1]

5.  **Construct the regularized local covariance**:
    Create a new 3x3 matrix $\Sigma_{reg\_local}$ [S1].
    $$ \Sigma_{reg\_local} = \begin{bmatrix} a' & b' & 0 \\ b' & c' & 0 \\ 0 & 0 & \min(a', c') / 100 \end{bmatrix} $$ [S1]
    This step projects the covariance onto the tangent plane (setting the normal component variance to near-zero) and scales the residual normal variance to prevent numerical instability [G].

6.  **Transform back to world space**:
    $$ \sigma \leftarrow B \Sigma_{reg\_local} B^T $$ [S1]

### Pseudocode
```python
import numpy as np

def transform_covariance_to_half_gaussian(cov_world: np.ndarray, normal: np.ndarray) -> np.ndarray:
    """
    Transforms a 3D Gaussian covariance matrix into a half-Gaussian covariance
    aligned with a splitting plane normal.
    
    Args:
        cov_world: 3x3 symmetric covariance matrix in world space.
        normal: 3x1 normal vector of the splitting plane.
        
    Returns:
        sigma: 3x3 regularized covariance matrix in world space.
    """
    # 1. Normalize normal
    n = normal / np.linalg.norm(normal)
    
    # 2. Construct basis vectors v1, v2
    if np.isclose(n[0], 0) and np.isclose(n[1], 0):
        v1 = np.array([1.0, 0.0, 0.0])
        v2 = np.array([0.0, 1.0, 0.0])
    else:
        v1 = np.array([n[1], -n[0], 0.0])
        v1 = v1 / np.linalg.norm(v1)
        v2 = np.cross(n, v1)
        v2 = v2 / np.linalg.norm(v2)
        
    # Construct rotation matrix B with columns v1, v2, n
    B = np.column_stack((v1, v2, n))
    
    # 3. Transform to local basis: cov_local = B^T * cov_world * B
    cov_local = B.T @ cov_world @ B
    
    # 4. Compute modified elements
    denom = cov_local[2, 2]
    if denom < 1e-8:
        denom = 1e-8  # [G] Guard against division by zero
        
    a_prime = cov_local[0, 0] - (cov_local[0, 2] ** 2) / denom
    b_prime = cov_local[0, 1] - (cov_local[0, 2] * cov_local[1, 2]) / denom
    c_prime = cov_local[1, 1] - (cov_local[1, 2] ** 2) / denom
    
    # 5. Construct regularized local covariance
    min_ac = min(a_prime, c_prime)
    sigma_local = np.array([
        [a_prime, b_prime, 0.0],
        [b_prime, c_prime, 0.0],
        [0.0, 0.0, min_ac / 100.0]
    ])
    
    # 6. Transform back to world space: sigma = B * sigma_local * B^T
    sigma = B @ sigma_local @ B.T
    
    return sigma
```

### Parameters
*   **Opacity Threshold for Densification/Pruning**: Increased to $0.01$ [S1].
*   **Opacity Reset for Half-Gaussians**: Set to $0.02$ [S1].
*   **Regularization Frequency**: The covariance transformation is applied every $5000$ iterations [S1].
*   **Normal Variance Scaling Factor**: The denominator for the residual normal variance is $100$ (i.e., $\min(a', c') / 100$) [S1].

### Edge Cases and Pitfalls
*   **Normal Alignment**: If the normal vector $n$ is parallel to the Z-axis, the standard cross-product method for finding $v_1$ fails (zero vector) [S1].
*   **Numerical Stability**: The term $cov_{2,2}$ in the denominator of the projection formulas must be checked for near-zero values to prevent division by zero [G].
*   **Positive Definiteness**: The resulting matrix $\sigma$ must remain positive semi-definite [G].
*   **Schur Complement Property**: The construction ensures the top-left 2x2 block is the Schur complement of the original covariance (which preserves positive definiteness if the original was PD), and the diagonal element is positive [G].

## Operating characteristics
*   **Time Complexity**: The transformation involves matrix multiplications and vector operations, which are $O(1)$ per Gaussian [G].
*   **Memory Complexity**: No additional memory is required beyond the standard Gaussian parameters [G].
*   **Performance**: On Mip-NeRF 360: 125 FPS, 29.66 PSNR with 3.8M kernels (vs 3DGS 3.2M kernels) [S1]. On Tank & Dengin: 160 FPS, 24.45 PSNR with 1.8M kernels (vs 3DGS 1.0M kernels) [S1]. On Tank & Blending: 126 FPS, 29.76 PSNR with 2.6M kernels (vs 3DGS 3.0M kernels) [S1].
*   **Strengths**: Consistently outperforms original 3DGS in PSNR and other metrics by better modeling sharp transitions [S1]. The efficient rasterizer integration provides significant speedups (e.g., 76 FPS to 125 FPS on Mip-NeRF 360) [S1].
*   **Limitations**: Requires more kernels than 3DGS to achieve comparable or better results, increasing memory usage [S1].

## Background
3D Half-Gaussian Splatting (3D-HGS) was introduced in the paper "3D-HGS: 3D Half-Gaussian Splatting" [S1]. It extends the 3D Gaussian Splatting framework by using half-ellipsoids to represent surfaces, which are more suitable for modeling sharp boundaries and occlusions than full ellipsoids [S1]. The method was evaluated against Scaffold, mip-splatting, and MCMC architectures [S1].
