# Depth Reinitialization

Also called: Depth-based densification

## Overview
Depth Reinitialization is a regularization strategy that alleviates 'overlapping' and 'under-reconstruction' artifacts in 3D Gaussian Splatting by leveraging dense depth information to reorganize the spatial distribution of Gaussians [S1]. It sets itself apart from sibling methods by rejecting standard alpha-blended depth maps in favor of geometric mid-point depths to generate clean, artifact-free point clouds for reinitialization [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D Gaussians, camera parameters, and ground truth color images [S1].
*   **Output:** A reorganized set of Gaussian positions and colors, initialized from a dense point cloud derived from rendered mid-point depth [S1].

**Data Structures:**
*   **Gaussian $G_i$:** Defined by center $\mathbf{c}_i$, scale $s_i = (s_{x,i}, s_{y,i}, s_{z,i})$, rotation matrix $R_i$, opacity $\alpha_i$, and spherical harmonics coefficients for color [S1].
*   **Ray $r(t)$:** Defined by origin $\mathbf{o}$ and direction $\mathbf{d}$, transformed into the local coordinate system of the Gaussian ellipsoid [S1].

**Formulas:**
The Gaussian is modeled as an ellipsoid in 3D space [S1]:
$$ g(x, y, z) = \frac{x^2}{s_x} + \frac{y^2}{s_y^2} + \frac{z^2}{s_z} = 1 $$
where $s = (s_x, s_y, s_z)$ is the scale [S1]. The depth of the mid-point for Gaussian $G_i$, denoted $d_{mid}^i$, is calculated by finding the intersection of the transformed ray with this ellipsoid surface [S1]. For multiple Gaussians contributing to a pixel, the method selects the Gaussian with the maximum contribution weight to avoid alpha blending artifacts [S1]:
$$ i_{max} = \arg \max_i w_i $$
$$ d_{mid} = d_{mid}^{i_{max}} $$
where $w_i$ is the contribution weight of Gaussian $i$ to the pixel [S1].

**Parameters:**
*   **Total number of sampled points:** Empirically set at around 3.5 million for each scene [S1].

**Numbered Steps:**
1.  **Render Depth Map:** For each pixel, identify the Gaussian $G_{i_{max}}$ with the maximum contribution $w_i$ [S1]. Calculate the mid-point depth $d_{mid}$ of this Gaussian using the ellipsoid intersection method [S1]. Store this as the depth value for the pixel [S1].
    *   *Pitfall:* Do not use standard blending depth $d_{blend} = \sum_{i=1}^N w_i \cdot d_i$ (where $d_i$ is center depth), as it produces misleading depth maps with artifacts like depth collapse, object misalignment, and blending boundaries [S1].
2.  **Reproject to World Space:** Convert the 2D depth map values $d_{mid}$ back into 3D world coordinates using the camera intrinsic and extrinsic parameters [S1]. This generates a dense set of 3D points [S1].
3.  **Sample Initial Points:** Randomly select a subset of these reprojected points [S1]. The total number of sampled points is approximately 3.5 million per scene [S1].
4.  **Assign Colors:** Assign the ground truth color from the corresponding pixel in the input image to each sampled point [S1].
5.  **Reinitialize:** During optimization, repeatedly reinitialize the Gaussian representation (positions and colors) with these sampled points to reorganize the spatial distribution of Gaussians [S1].

**Pseudocode:**
```python
import math
import random

def rotate_vector(vec, rot_mat):
    return [sum(rot_mat[i][j] * vec[j] for j in range(3)) for i in range(3)]

def generate_ray(u, v, cam_K_inv, cam_center):
    dir_world = rotate_vector([u, v, 1.0], cam_K_inv)
    norm = math.sqrt(sum(c*c for c in dir_world))
    dir_world = [c/norm for c in dir_world]
    return list(cam_center), dir_world

def reproject_to_world(u, v, depth, cam_K_inv, cam_center):
    dir_world = rotate_vector([u, v, 1.0], cam_K_inv)
    norm = math.sqrt(sum(c*c for c in dir_world))
    dir_world = [c/norm for c in dir_world]
    depth_vec = [depth * c for c in dir_world]
    return [cam_center[i] + depth_vec[i] for i in range(3)]

def compute_contribution(g, u, v):
    # Simplified weight proxy for the Gaussian's contribution to the pixel
    return g.alpha

def calculate_midpoint_depth(ray_o, ray_d, g):
    local_o = rotate_vector([ray_o[i] - g.center[i] for i in range(3)], g.rot_mat)
    local_d = rotate_vector(ray_d, g.rot_mat)
    inv_s = [1.0/g.scale[0], 1.0/(g.scale[1]**2), 1.0/g.scale[2]]
    a = sum(local_d[i]**2 * inv_s[i] for i in range(3))
    b = 2.0 * sum(local_d[i] * local_o[i] * inv_s[i] for i in range(3))
    c = sum(local_o[i]**2 * inv_s[i] for i in range(3)) - 1.0
    disc = b**2 - 4*a*c
    if disc < 0:
        return None
    t1 = (-b - math.sqrt(disc)) / (2*a)
    t2 = (-b + math.sqrt(disc)) / (2*a)
    return (t1 + t2) / 2.0

def depth_reinitialization_step(gaussians, cameras, gt_images, num_samples=3500000):
    world_points = []
    world_colors = []
    for cam in cameras:
        for u, v in cam.pixel_coords:
            ray_o, ray_d = generate_ray(u, v, cam.K_inv, cam.center)
            max_w = -1.0
            best_depth = None
            for G in gaussians:
                t_mid = calculate_midpoint_depth(ray_o, ray_d, G)
                if t_mid is not None:
                    w = compute_contribution(G, u, v)
                    if w > max_w:
                        max_w = w
                        best_depth = t_mid
            if best_depth is not None:
                p_world = reproject_to_world(u, v, best_depth, cam.K_inv, cam.center)
                world_points.append(p_world)
                world_colors.append(gt_images[cam.id][u, v])
    indices = list(range(len(world_points)))
    random.shuffle(indices)
    selected = indices[:num_samples]
    sampled_pts = [world_points[i] for i in selected]
    sampled_cols = [world_colors[i] for i in selected]
    for i, G in enumerate(gaussians):
        G.center = sampled_pts[i % len(sampled_pts)]
        G.color = sampled_cols[i % len(sampled_cols)]
```

**Edge Cases and Pitfalls:**
*   **Blending Depth Artifacts:** Using standard blending depth $d_{blend} = \sum w_i d_i$ introduces noise from depth artifacts (depth collapse, object misalignment) which degrades reinitialization quality [S1].
*   **Center vs. Mid-point:** While depth from Gaussian centers yields comparable rendering metrics (SSIM/PSNR) to mid-point, mid-point yields superior dense point cloud reconstruction [S1]. Mid-point is preferred for reinitialization [S1].
*   **Precision:** The discriminant check in ellipsoid intersection is crucial to handle non-intersecting rays [S1].

## Operating characteristics
*   **Time Complexity:** The method adds overhead during the optimization loop for rendering depth maps and reprojecting points [S1].
*   **Memory Complexity:** Requires storing the depth map and the sampled point cloud (3.5M points) [S1].
*   **Measured Performance:** Adding Depth Reinitialization to Blur Split increases the number of Gaussians from 3.74M to 4.32M, SSIM from 0.819 to 0.832, and LPIPS from 0.195 to 0.175 [S1].
*   **Strengths:** Alleviates overlapping and under-reconstruction; produces dense and uniform point distributions; improves LPIPS (human perception) [S1].
*   **Limitations:** Increases Gaussian count; relies on accurate depth rendering; sensitive to the choice of depth metric (mid-point vs center vs blend) [S1].
*   **When to use:** When high-quality dense point cloud reconstruction is desired alongside rendering, or when facing severe overlapping/under-reconstruction issues [S1].
*   **When not to use:** When computational resources are extremely limited and Gaussian count must be kept low, or if depth accuracy is poor [S1].

## Background
Depth Reinitialization was introduced in the context of "Mini-Splatting," a method to represent scenes with a constrained number of Gaussians [S1]. It builds on the observation that utilizing depth to enhance neural rendering is effective, as seen in NeRF-based algorithms [S1]. The specific formulation using mid-point depths for 3D Gaussian Splatting was proposed to address the limitations of alpha-blended depth maps in Gaussian-based representations [S1].
