# NeuSG

Also called: NeuS-Gaussian Splatting, NeuS-3DGS

## Overview
NeuSG [S1] integrates the NeuS [S170] implicit surface reconstruction framework into the 3D Gaussian Splatting (3DGS) representation to transfer explicit surface properties to the discrete Gaussian primitives. It solves the problem of vanilla 3DGS producing "floating ellipsoids" rather than coherent surfaces by enforcing geometric consistency. Unlike siblings that use monocular depth or explicit mesh extraction, NeuSG directly couples a NeuS-style Signed Distance Function (SDF) with a Gaussian rasterizer [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of calibrated images, initial 3D Gaussian parameters (position $\mathbf{c}_i$, covariance $\Sigma_i$, opacity $\alpha_i$, color $\mathbf{c}$), and a NeuS network initialized to predict SDF and opacity.
*   **Outputs:** Optimized 3D Gaussians and a NeuS network that jointly render photorealistic images and a consistent surface.

**Data Structures:**
1.  **3D Gaussians:** Standard 3DGS representation. Each Gaussian $i$ has center $\mathbf{c}_i$, rotation quaternion $\mathbf{q}_i$, scale $\mathbf{s}_i$, opacity $\alpha_i$, and spherical harmonics coefficients for color.
2.  **NeuS Network:** A multi-layer perceptron (MLP) taking 3D position $\mathbf{x}$ and viewing direction $\mathbf{v}$ as input. It outputs a raw SDF value $\sigma(\mathbf{x})$ and an opacity weight $\omega(\mathbf{x})$. The SDF is transformed into opacity via a differentiable volume rendering integral [S1].

**Numbered Steps:**
1.  **Initialization:** Initialize 3D Gaussians from sparse points (e.g., COLMAP). Initialize NeuS MLP with random weights.
2.  **Rendering:** Render the scene using the 3DGS rasterizer to produce RGB images. Simultaneously, sample points along rays through the NeuS network to compute volume-rendered depth and normal maps [S1].
3.  **Geometric Loss ($\mathcal{L}_{geo}$):** For each Gaussian $i$, query the NeuS network for its signed distance value $d_i = \sigma(\mathbf{c}_i)$. Encourage these values to be zero, ensuring Gaussian centers lie on the zero-level set of the SDF [S1].
    $$ \mathcal{L}_{geo} = \sum_i |d_i| $$
4.  **Normal Consistency Loss ($\mathcal{L}_{norm}$):** Compute the normal vector $\mathbf{n}_{gs,i}$ for each Gaussian from its covariance matrix (or rotation quaternion). Compute the surface normal $\mathbf{n}_{neuS,i}$ from the gradient of the NeuS SDF at $\mathbf{c}_i$: $\mathbf{n}_{neuS,i} = \nabla \sigma(\mathbf{c}_i) / \|\nabla \sigma(\mathbf{c}_i)\|$. Minimize the angular difference between them [S1].
    $$ \mathcal{L}_{norm} = \sum_i (1 - \mathbf{n}_{gs,i} \cdot \mathbf{n}_{neuS,i}) $$
5.  **Photometric Loss:** Compute the standard L1 or SSIM loss between rendered RGB images and ground truth images [S1].
6.  **Optimization:** Minimize the total loss:
    $$ \mathcal{L}_{total} = \mathcal{L}_{rgb} + \lambda_{geo} \mathcal{L}_{geo} + \lambda_{norm} \mathcal{L}_{norm} $$
    where $\lambda_{geo}$ and $\lambda_{norm}$ are hyperparameters [S1].

**Pseudocode:**
```python
def neusg_step(gaussians, neus_mlp, gt_image, gt_depth, lambda_geo, lambda_norm):
    # 1. Render RGB via 3DGS rasterizer
    rendered_rgb = rasterize_gaussians(gaussians)
    
    # 2. Sample points for NeuS SDF and compute gradients
    # Sample points along rays or at Gaussian centers
    sdf_values = []
    normals_neus = []
    normals_gs = []
    
    for g in gaussians:
        # Query NeuS SDF at Gaussian center
        d = neus_mlp(g.position)
        sdf_values.append(d)
        
        # Compute NeuS normal via finite differences or autograd
        n_neus = normalize(gradient(neus_mlp, g.position))
        normals_neus.append(n_neus)
        
        # Compute Gaussian normal from covariance/rotation
        n_gs = get_normal_from_gaussian(g)
        normals_gs.append(n_gs)
        
    sdf_values = torch.stack(sdf_values)
    normals_neus = torch.stack(normals_neus)
    normals_gs = torch.stack(normals_gs)
    
    # 3. Compute Geometric Loss: encourage SDF to be zero at Gaussian centers
    l_geo = torch.mean(torch.abs(sdf_values))
    
    # 4. Compute Normal Consistency Loss
    dot_product = torch.sum(normals_neus * normals_gs, dim=1)
    l_norm = torch.mean(1.0 - dot_product)
    
    # 5. Compute Photometric Loss
    l_rgb = l1_loss(rendered_rgb, gt_image)
    
    # 6. Total Loss
    total_loss = l_rgb + lambda_geo * l_geo + lambda_norm * l_norm
    
    return total_loss
```

**Parameters:**
*   $\lambda_{geo}$: Weight for geometric loss. Not given in the sources.
*   $\lambda_{norm}$: Weight for normal consistency loss. Not given in the sources.

**Edge Cases:**
*   **Precision:** SDF values near zero are sensitive to initialization. [G] Ensure NeuS is initialized to predict a large positive SDF outside the object and negative inside to avoid local minima.
*   **Boundaries:** Gaussians far from the surface may have noisy SDF gradients. [G] Consider masking Gaussians with low opacity or high distance from the zero-level set.

## Subtopics

### GSDF
Uses a similar SDF consistency approach but derives the surface from accumulated opacity rather than a separate NeuS network [S1].

### Surface and Geometry Alignment
Focuses on aligning Gaussians with explicit mesh normals or depth maps, often using post-processing or differentiable mesh rendering [S1].

### Monocular Depth Scale Alignment
Aligns 3DGS with monocular depth estimates without an explicit SDF network [S1].

### Sparse-view 3D Gaussian Splatting with Depth Priors
Uses depth priors to regularize geometry in sparse views, potentially using SDF but not necessarily NeuS [S1].

## Operating characteristics
*   **Time Complexity:** Higher than vanilla 3DGS due to the additional NeuS network forward and backward passes for every Gaussian or ray sample. Not given in the sources.
*   **Memory Complexity:** Increased by the storage of the NeuS MLP weights and intermediate SDF values. Not given in the sources.
*   **Strengths:** Produces clean, watertight surfaces suitable for mesh extraction. Aligns Gaussian orientation with the true surface normal.
*   **Limitations:** Slower training due to the coupled optimization. Requires careful tuning of $\lambda_{geo}$ and $\lambda_{norm}$. [S2, unofficial]
*   **When to use:** When a high-quality mesh is required for downstream applications (e.g., physics, DCC). [S2, unofficial]
*   **When not to use:** When real-time rendering speed is the primary concern and surface fidelity is less critical than appearance.

## Background
NeuSG was introduced as a method to combine the surface reconstruction capabilities of NeuS [S170] with the rendering efficiency of 3DGS [S1]. It addresses the limitation of vanilla 3DGS, which lacks explicit geometric constraints, by transferring the surface property from NeuS to the Gaussian representation. The method is cited in surveys of recent advances in 3D Gaussian Splatting [S1].
