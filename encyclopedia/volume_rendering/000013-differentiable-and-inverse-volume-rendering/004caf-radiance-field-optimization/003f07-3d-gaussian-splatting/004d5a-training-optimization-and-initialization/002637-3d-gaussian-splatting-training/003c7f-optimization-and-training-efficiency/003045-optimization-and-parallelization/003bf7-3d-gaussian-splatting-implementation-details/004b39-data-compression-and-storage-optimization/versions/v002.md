# Data Compression and Storage Optimization

Also called: Gaussian Compression, 3DGS Storage Reduction

## Overview
This family addresses the excessive memory footprint and storage requirements of 3D Gaussian Splatting (3DGS), which often exceeds 1GB for large scenes [12927-compact-3d-gaussian-representation-c3dgs.md]. It reduces data volume through attribute compression, structural pruning, and efficient encoding. It differs from [Sorting and Rendering Pipeline Optimization](12180-sorting-and-rendering-pipeline-optimization.md) by focusing on data representation size rather than rendering throughput, and from [Gaussian Representation and Truncation](12855-gaussian-representation-and-truncation.md) by employing global compression schemes rather than local primitive simplification.

## Shared principles
All methods in this family aim to reduce the storage size of Gaussian primitives. Standard 3DGS stores position, opacity, scale, rotation, and Spherical Harmonics (SH) coefficients per Gaussian [12927-compact-3d-gaussian-representation-c3dgs.md]. Compression techniques replace or encode these high-dimensional attributes using codebooks, hash grids, or ASCII representations [11820-ascii-based-data-compression.md][12167-sensitivity-aware-vector-clustering.md][12927-compact-3d-gaussian-representation-c3dgs.md].

## Subtopics

### [ASCII-Based Data Compression](11820-ascii-based-data-compression.md)
Compresses floating-point and integer values into ASCII strings to accelerate training I/O. It targets transmission speed rather than final storage size [11820-ascii-based-data-compression.md].

### [Sensitivity-Aware Vector Clustering](12167-sensitivity-aware-vector-clustering.md)
Reduces storage by clustering SH and shape parameters into codebooks using sensitivity-weighted k-Means. It prioritizes parameters that significantly affect rendering quality [12167-sensitivity-aware-vector-clustering.md].

### [Compact 3D Gaussian Representation (C3DGS)](12927-compact-3d-gaussian-representation-c3dgs.md)
Reduces memory by pruning redundant Gaussians and replacing per-Gaussian attributes with a hash-based neural field for color and a codebook for geometry [12927-compact-3d-gaussian-representation-c3dgs.md].

## Background
3D Gaussian Splatting [12927-compact-3d-gaussian-representation-c3dgs.md] generates large numbers of primitives, leading to high memory usage. Standard storage requires significant disk space and memory bandwidth. These optimization methods were developed to make 3DGS scalable for large scenes and efficient for deployment.
