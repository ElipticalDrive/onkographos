# Sensitivity-Aware Vector Clustering

Also called: Color Compression, Sensitivity-Aware Scene Compression, Sensitivity-aware k-Means

## Overview
Sensitivity-Aware Vector Clustering is a compression scheme for 3D Gaussian Splatting that reduces storage requirements by clustering spherical harmonic (SH) coefficients and Gaussian shape features (scale and rotation) into compact codebooks [S1]. It distinguishes itself from standard vector quantization by incorporating a sensitivity measure $S$ that weights the distance between vectors and centroids, prioritizing the preservation of parameters that significantly affect image quality [S1]. This method enables compression rates of up to 31× with minimal visual degradation [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of optimized 3D Gaussian kernels, each defined by position, opacity, SH coefficients (representing color), and shape parameters (rotation and scale).
*   **Output:** Two codebooks (one for color/SH, one for shape) and, for each Gaussian, two indices pointing to entries in these codebooks [S1].

**Data Structures:**
*   **Codebook Entry (Shape):** 4 scalar values for a quaternion (rotation) plus 3 scalar values for scaling [S1].
*   **Codebook Entry (Color):** SH coefficients (treated as vectors) [S1].
*   **Indices:** 32-bit unsigned integers stored alongside Gaussian data [S1].

**Sensitivity Calculation:**
The sensitivity $S(p)$ of a parameter $p$ is calculated based on its contribution to the training images [S1].
1.  Compute the total image energy $E$ (sum of RGB components) for each training image $i$.
2.  Compute the gradient of $E$ with respect to parameter $p$ using a single backward pass [S1].
3.  The sensitivity for parameter $p$ is defined as [S1]:
    $$ S(p) = \frac{\sum_{i=1}^{N} \frac{\partial E_i}{\partial p_i}}{\sum_{i=1}^{N} P_i} $$
    where $N$ is the number of training images, $P_i$ is the number of pixels in image $i$, and $\frac{\partial E_i}{\partial p_i}$ is the gradient magnitude [S1].
4.  For a vector $x$ with components $x_d$, the sensitivity $S(x)$ is the maximum sensitivity over its components [S1]:
    $$ S(x) = \max_d S(x_d) $$

**Clustering Algorithm:**
The method uses two separate codebooks: one for SH coefficients (Color Compression) and one for Gaussian shape features (Gaussian Shape Compression) [S1].

1.  **Initialization:** Initialize codebook centroids randomly with a uniform distribution within the minimum and maximum values of each parameter [S1].
2.  **Thresholding (Outliers):**
    *   For SH coefficients: Identify vectors with sensitivity higher than threshold $\beta_c$. These are not clustered but added directly to the codebook [S1].
    *   For Shape parameters: Identify Gaussians with maximum sensitivity over threshold $\beta_g$. These are also excluded from clustering and added directly to the codebook [S1].
3.  **Weighted Distance:** For the remaining vectors, the distance $D$ between a vector $x$ and a centroid $c_k$ is weighted by the vector's sensitivity [S1]:
    $$ D(x, c_k) = S(x) \|x - c_k\|_2^2 $$
4.  **Assignment:** Assign each vector $x$ to the centroid $c_k$ with the minimum weighted distance [S1].
5.  **Centroid Update:** Update each centroid $c_k$ using the weighted average of assigned vectors $A(k)$ [S1]:
    $$ c_k = \frac{1}{\sum_{x_i \in A(k)} S(x_i)} \sum_{x_i \in A(k)} S(x_i) x_i $$
6.  **Batched Strategy:** To improve performance, a random subset of vectors is picked in each update step. Centroids are updated using a moving average with decay factor $\lambda_d$ [S1].
7.  **Renormalization:** Due to floating-point errors, clustering normalized covariance matrices may result in non-unit scaling vectors. Each codebook vector is re-normalized after each update step by dividing it through the trace of the covariance metric [S1].
8.  **Decomposition:** After clustering, each codebook entry (covariance matrix) is decomposed into rotation (quaternion) and scale parameters using eigenvalue decomposition for quantization-aware training [S1].

**Pseudocode:**

```python
def sensitivity_aware_clustering(gaussians, num_iterations, batch_size, codebook_size, decay_factor, beta_c, beta_g):
    """
    Performs sensitivity-aware vector clustering for 3D Gaussian Splatting.
    
    Args:
        gaussians: List of Gaussian objects with attributes:
                   - sh_coeffs: Array of SH coefficients
                   - cov_matrix: 3x3 covariance matrix
                   - pos: Position
        num_iterations: Number of clustering iterations
        batch_size: Number of vectors to process per batch
        codebook_size: Number of centroids K
        decay_factor: Lambda_d for moving average update
        beta_c: Sensitivity threshold for SH coefficients
        beta_g: Sensitivity threshold for shape parameters
        
    Returns:
        color_codebook: List of SH coefficient vectors
        shape_codebook: List of shape parameters (quaternion, scale)
        indices: List of tuples (color_idx, shape_idx) for each Gaussian
    """
    
    # 1. Calculate Sensitivity
    # Compute sensitivity for each parameter/component
    # S(p) = sum(grad_E_i / P_i) / sum(P_i)
    # S(x) = max_d(S(x_d))
    sensitivities = {}
    for g in gaussians:
        # Compute gradient of image energy w.r.t parameters
        # This requires a backward pass over training images
        grad_sh = compute_gradient(g.sh_coeffs, training_images)
        grad_shape = compute_gradient(g.cov_matrix, training_images)
        
        # Normalize by pixel counts
        sens_sh = compute_sensitivity_vector(grad_sh)
        sens_shape = compute_sensitivity_vector(grad_shape)
        
        sensitivities[g.id] = {
            'sh_sens': sens_sh,
            'shape_sens': sens_shape,
            'max_sh_sens': max(sens_sh),
            'max_shape_sens': max(sens_shape)
        }

    # 2. Separate Outliers
    color_vectors = []
    shape_vectors = []
    outlier_indices = []
    
    for g in gaussians:
        s_sh = sensitivities[g.id]['max_sh_sens']
        s_shape = sensitivities[g.id]['max_shape_sens']
        
        # Add high-sensitivity items directly to codebooks
        if s_sh > beta_c:
            color_codebook_outliers.append(g.sh_coeffs)
        else:
            color_vectors.append(g.sh_coeffs)
            
        if s_shape > beta_g:
            shape_codebook_outliers.append(g.cov_matrix)
        else:
            # Store normalized covariance for clustering
            shape_vectors.append(normalize_covariance(g.cov_matrix))
            
    # 3. Initialize Codebooks
    # Random uniform initialization within min/max of parameters
    color_codebook = initialize_codebook(color_vectors, codebook_size)
    shape_codebook = initialize_codebook(shape_vectors, codebook_size)
    
    # 4. Iterative Clustering
    for iteration in range(num_iterations):
        # Sample batch
        batch_color = random_sample(color_vectors, batch_size)
        batch_shape = random_sample(shape_vectors, batch_size)
        
        # Update Color Codebook
        color_codebook = update_codebook_step(
            color_codebook, 
            batch_color, 
            sensitivities, 
            decay_factor
        )
        
        # Update Shape Codebook
        shape_codebook = update_codebook_step(
            shape_codebook, 
            batch_shape, 
            sensitivities, 
            decay_factor
        )
        
        # Renormalize shape codebook entries
        for i in range(len(shape_codebook)):
            shape_codebook[i] = renormalize_covariance(shape_codebook[i])
            
    # 5. Decomposition and Finalization
    # Decompose shape codebook entries into quaternion and scale
    final_shape_codebook = []
    for cov in shape_codebook:
        q, s = eigen_decompose(cov)
        final_shape_codebook.append({'q': q, 's': s})
        
    # Combine outliers with clustered codebooks
    final_color_codebook = color_codebook + color_codebook_outliers
    final_shape_codebook = final_shape_codebook + shape_codebook_outliers # Assuming outliers stored as matrices or decomposed
    
    # 6. Assign Indices
    indices = []
    for g in gaussians:
        # Find closest centroid in final codebooks
        c_idx = find_closest_centroid(g.sh_coeffs, final_color_codebook, sensitivities[g.id]['sh_sens'])
        s_idx = find_closest_centroid(normalize_covariance(g.cov_matrix), final_shape_codebook, sensitivities[g.id]['shape_sens'])
        indices.append((c_idx, s_idx))
        
    return final_color_codebook, final_shape_codebook, indices

def compute_sensitivity_vector(grad):
    """Computes sensitivity S(p) for a vector of parameters."""
    # S(p) = sum(grad_i / P_i) / sum(P_i)
    # Assuming P_i is normalized or constant for simplicity in this step
    # In practice, sum over all training images
    return sum(grad) / len(grad) # Placeholder for actual pixel-weighted sum

def normalize_covariance(cov_matrix):
    """Normalizes covariance matrix to unit scaling."""
    # Normalize such that trace is 1 or similar metric
    # As per source: divide through trace of covariance metric
    trace = np.trace(cov_matrix)
    return cov_matrix / trace

def renormalize_covariance(cov_matrix):
    """Re-normalizes codebook vector after update."""
    trace = np.trace(cov_matrix)
    return cov_matrix / trace
```

**Parameters:**
*   $\lambda_d$: Decay factor for the moving average in batched clustering. Typical value: 0.8 [S1].
*   Batch size for color features: $2^{18}$ [S1].
*   Batch size for Gaussian parameters: $2^{20}$ [S1].
*   Codebook size $K$: 4096 [S1].
*   $\beta_c$: Sensitivity threshold for SH coefficients. Typical value: $6 \times 10^{-7}$ [S1].
*   $\beta_g$: Sensitivity threshold for shape parameters. Typical value: $3 \times 10^{-6}$ [S1].
*   Optimization steps for quantization-aware fine-tuning: 5000 [S1].

**Edge Cases and Pitfalls:**
*   **Floating Point Errors:** Clustering normalized covariance matrices can lead to non-unit scaling vectors due to floating-point errors. This is handled by re-normalizing each codebook vector after each update step by dividing it through the trace of the covariance metric [S1].
*   **High Sensitivity Outliers:** A small percentage (< 5%) of SH coefficients may have very high sensitivity. These must be excluded from clustering and added directly to the codebook to prevent significant rendering errors [S1].

## Operating characteristics
*   **Compression Rate:** Achieves up to 31× compression on real-world scenes with minimal visual quality degradation [S1].
*   **Rendering Performance:** Enables real-time rendering on lightweight GPUs, achieving up to 4× higher framerates compared to optimized GPU compute pipelines for uncompressed scenes [S1].
*   **Storage:** Reduces storage requirements by mapping continuous parameters to discrete indices in compact codebooks [S1].
*   **Strengths:** Significant reduction in memory consumption; improved rendering efficiency on low-power devices; robustness across multiple datasets [S1].
*   **Limitations:** Requires quantization-aware fine-tuning (5000 steps) to recover information lost during clustering [S1].

## Background
*   **Origin:** Proposed in "Compressed 3D Gaussian Splatting for Accelerated Novel View Synthesis" (CVPR 2024) [S1].
*   **Development:** Inspired by volumetric radiance field compression and deep network weight quantization [S1]. It addresses the need for reduced memory consumption and improved rendering efficiency for applications like network streaming and low-power device rendering [S1].
