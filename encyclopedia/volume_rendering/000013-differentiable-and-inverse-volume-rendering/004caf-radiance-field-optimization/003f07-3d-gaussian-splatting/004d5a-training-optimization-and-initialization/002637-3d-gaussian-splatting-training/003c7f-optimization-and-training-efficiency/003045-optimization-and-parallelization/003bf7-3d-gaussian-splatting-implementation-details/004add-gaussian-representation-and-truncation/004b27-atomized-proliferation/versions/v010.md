# Atomized Proliferation

Also called: Atom Gaussian Densification

## Overview
Atomized Proliferation is a training optimization strategy for 3D Gaussian Splatting that enhances geometric precision by constraining Gaussians representing fine details into "Atom Gaussians" (isotropic spheroids with uniform size) and prioritizing their proliferation to align with scene geometry [S1, unofficial]. It differs from standard 3DGS densification by using a warm-up phase that aggressively densifies initially, followed by merging of large smooth surfaces, leading to a stabilizing Gaussian count and superior mesh quality [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of 3D Gaussians defined by mean $\mu$, covariance $\Sigma$, color $c$, and opacity $\alpha$; input Structure-from-Motion (SfM) points; hyperparameters $\tau_c, \tau_s, \epsilon, S, t_a, t_w$.
*   **Outputs:** An optimized set of Gaussians where fine details are represented by fixed-size Atom Gaussians and smooth surfaces are merged.

**Data Structures:**
The algorithm iterates over the Gaussian set $(M, S, C, A)$ representing means, covariances, colors, and opacities [S1, unofficial].
*   **Atom Scale ($S$):** A scalar threshold derived from SfM points. $S = P_i(d)$, where $P_i$ is the $i$-th percentile of ordered distances between SfM points. Typically $i=1$ (first percentile) [S1, unofficial].
*   **Atom Gaussian:** An isotropic spheroid with uniform size $s = \sqrt[3]{S}$ [S1, unofficial].

**Parameters:**
*   **Clone Threshold ($\tau_c$):** Threshold for cloning based on loss gradient. Typical value: $0.002$ [S1, unofficial].
*   **Split Threshold ($\tau_s$):** Base threshold for splitting. Typical value: $0.002$ [S1, unofficial].
*   **Prune Threshold ($\epsilon$):** Opacity threshold for pruning. Typical value: $0.005$ (or $0.5$ for object-centered datasets like DTU) [S1, unofficial].
*   **Atom Scale ($S$):** Maximum allowed minimum covariance norm for atomization. Calculated as $P_1(d)$ [S1, unofficial].
*   **Atomized Proliferation Duration ($t_a$):** Iteration limit for atomization. Typical value: $7000$ [S1, unofficial].
*   **Warm-Up Duration ($t_w$):** Iteration limit for the warm-up phase. Typical value: $7000$ [S1, unofficial].

**Algorithm Steps:**
1.  **Initialization:** Calculate Atom Scale $S$ from SfM points. Initialize iteration counter $i=0$.
2.  **Iteration Loop:** For each iteration $i$ from $0$ to $t_a$:
    3.  **Atom Scale Progression:** Update the effective atom scale if $i < t_a$. The scale decreases via geometric progression: $S_n = S_{n-1} \cdot r^{n-1}$, where $r = \sqrt[t_a]{p}$ and $p$ is the final proportion to the initial $S$ [S1, unofficial]. *Note: The exact value of $p$ is not specified in the sources.*
    4.  **Process Each Gaussian:** For each Gaussian $g$ with properties $(\mu, \Sigma, c, \alpha)$:
        5.  **Pruning:** If $\alpha < \epsilon$ OR $\Sigma$ is excessively large (defined by helper `IsTooLarge`), remove $g$ [S1, unofficial].
        6.  **Cloning:** If the pixel-space loss gradient $\nabla_p L \ge \tau_c$, clone $g$ [S1, unofficial].
        7.  **Splitting:** If $\nabla_p L \ge \min(\frac{i}{t_w}\tau_s, \tau_s)$ AND $\|\Sigma\|_{\max} > S$, split $g$ into two smaller Gaussians [S1, unofficial]. The threshold $\min(\frac{i}{t_w}\tau_s, \tau_s)$ implements a linear warm-up, increasing the likelihood of splitting during the initial phase [S1, unofficial].
        8.  **Atomization:** If $\|\Sigma\|_{\min} \le S$ AND $i < t_a$, designate $g$ as an Atom Gaussian. Set its size to $s = \sqrt[3]{S}$. Fix its scale parameters (no backprop optimization). Update its scale in subsequent iterations via the geometric progression defined in Step 3 [S1, unofficial].

**Pseudocode:**
```python
def atomized_proliferation(gaussians, sfm_points, tau_c, tau_s, epsilon, ta, tw):
    # Calculate Atom Scale S from SfM points
    distances = compute_pairwise_distances(sfm_points)
    S = percentile(distances, 1) # First percentile
    
    # Initial scale for geometric progression
    # Note: 'p' (final proportion) is not defined in sources [G]
    # Assuming p=1 for initial state or derived from context not provided
    p = 1.0 
    r = p ** (1.0 / ta)
    current_atom_scale = S
    
    for i in range(ta):
        # Update atom scale via geometric progression
        # Sn = Sn-1 * r^(n-1) implies cumulative multiplication
        # If r is constant ratio per step:
        if i > 0:
            current_atom_scale = current_atom_scale * r 
            
        for g in gaussians:
            mu, Sigma, c, alpha = g.properties
            
            # 1. Pruning
            if alpha < epsilon or is_too_large(Sigma):
                gaussians.remove(g)
                continue
                
            # 2. Cloning
            if g.loss_gradient >= tau_c:
                clone(g)
                
            # 3. Splitting (Warm-up phase)
            # Threshold increases linearly from 0 to tau_s during tw iterations
            split_threshold = min((i / tw) * tau_s, tau_s)
            if g.loss_gradient >= split_threshold and max_covariance_norm(Sigma) > current_atom_scale:
                split(g)
                
            # 4. Atomization
            if min_covariance_norm(Sigma) <= current_atom_scale and i < ta:
                atomize(g, current_atom_scale)
                # Fix scale, no backprop
                g.scale_fixed = True
```

**Edge Cases and Pitfalls:**
*   **Object-Centered Datasets:** For datasets like DTU, the Prune Threshold $\epsilon$ should be increased to $0.5$ to prevent over-pruning of valid geometry [S1, unofficial].
*   **Scale Learning Rate:** To maximize geometric accuracy, the scale learning rate $\eta_s$ should be set to $0$ [S1, unofficial].
*   **Precision:** The distinction between Atom Gaussians (isotropic) and traditional Gaussians (anisotropic) relies on the norm of the covariance matrix. Precision in computing $\|\Sigma\|_{\min}$ and $\|\Sigma\|_{\max}$ is critical for correct classification [S1, unofficial].

## Subtopics

### Geometry-Guided Optimization
A complementary method that uses normal maps to compactly model smooth surfaces while retaining primitives for fine details. It addresses the issue of Gaussians not adhering to underlying geometric structures [S1, unofficial].

### Atom Gaussian Primitive
The specific primitive type used in this method, defined as an isotropic spheroid with uniform size $s = \sqrt[3]{S}$, contrasting with the anisotropic ellipsoids of standard 3DGS [S1, unofficial].

## Operating characteristics
*   **Time and Memory:** On the Mip-NeRF360 dataset, AtomGS achieves an average training time of 0.28 hours and a final model size of 749MB, compared to 3DGS's 0.40 hours and 869MB [S1, unofficial].
*   **Scaling:** The method employs a proliferation trend that initially increases Gaussian count aggressively (due to warm-up splitting) and then declines/stabilizes (due to merging/pruning), unlike standard 3DGS which struggles to stabilize [S1, unofficial].
*   **Strengths:** Superior geometric precision, cleaner 3D meshes, and reduced training time/model size [S1, unofficial].
*   **Limitations:** Requires careful tuning of $\epsilon$ for different dataset types (e.g., DTU vs. Mip-NeRF360) [S1, unofficial].

## Background
Atomized Proliferation was introduced in the "AtomGS" paper by Liu, Xu, Hu, Chen, and Feng. It addresses the limitations of standard 3D Gaussian Splatting, which can produce noisy meshes and blurry artifacts due to Gaussians not adhering to underlying geometric structures [S1, unofficial].
