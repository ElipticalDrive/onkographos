# First-order Spherical Harmonics Distillation

Also called: Mobile-GS SH Distillation, SH Knowledge Distillation, SH Order Reduction via Distillation, SH degree reduction, Spherical Harmonics degree reduction

## Overview
First-order Spherical Harmonics Distillation reduces the spherical harmonics (SH) degree of 3D Gaussian primitives from third-order to first-order to decrease parameter count and rendering computation cost [S1][S2, unofficial]. Unlike standard degree reduction which may suffer from significant quality loss, this method uses a distillation strategy where a student model with first-order SH approximates the directional radiance of a pretrained third-order teacher model [S2, unofficial]. It sets itself apart from siblings like [Spherical Harmonics Vector Quantization](14181-spherical-harmonics-vector-quantization.md) by focusing on order reduction via knowledge transfer rather than codebook-based compression, and from [Explicit Camera Jacobian Derivation](10077-explicit-camera-jacobian-derivation.md) by targeting appearance representation efficiency rather than gradient computation speed.

## How it works
**Inputs and Outputs:**
- Input: A pretrained teacher 3D Gaussian Splatting model using third-order SH (16 coefficients per color channel, $3 \times 16$ total per Gaussian) and a student model initialized with first-order SH (4 coefficients per color channel, $3 \times 4$ total per Gaussian).
- Output: Optimized first-order SH coefficients for the student model.

**Data Structures:**
- Teacher SH Coefficients $\mathbf{C}^{tea}$: For each Gaussian $i$, a vector of size $3 \times 16$ (RGB $\times$ 16 SH coefficients).
- Student SH Coefficients $\mathbf{C}$: For each Gaussian $i$, a vector of size $3 \times 4$ (RGB $\times$ 4 SH coefficients).
- Rendered Pixel Color $\mathbf{C}_p$: The final color at pixel $p$ computed via volume rendering.
- Rendered Depth $\hat{\mathbf{D}}_p$: The accumulated depth at pixel $p$.

**Numbered Steps:**
1. **Initialization**: Initialize the student model's SH coefficients $\mathbf{C}$ randomly or by projecting the teacher's coefficients onto the first-order basis. The student model retains the same Gaussian positions, scales, rotations, and opacities as the teacher to isolate the SH approximation error [S2, unofficial].
2. **Rendering**: Render images from the student model to obtain pixel colors $\mathbf{C}_p$ and depths $\hat{\mathbf{D}}_p$. Simultaneously, render images from the fixed teacher model to obtain $\mathbf{C}_p^{tea}$ and $\hat{\mathbf{D}}_p^{tea}$ [S2, unofficial].
3. **Loss Calculation**: Compute the distillation loss $\mathcal{L}_{\text{distill}}$ and the scale-invariant depth distillation loss $\mathcal{L}_{\text{depth}}$ [S2, unofficial].
4. **Optimization**: Update the student's SH coefficients $\mathbf{C}$ using gradient descent to minimize the total loss.
5. **Iteration**: Repeat steps 2-4 until convergence.

**Formulas:**
The radiance $L(\mathbf{v})$ for a Gaussian in direction $\mathbf{v}$ is computed using first-order SH basis functions $\mathbf{Y}(\mathbf{v})$ and coefficients $\mathbf{c}$:
$$
L(\mathbf{v}) = \sum_{m=0}^{3} c_m \cdot Y_m(\mathbf{v})
$$
where $m$ indexes the 4 first-order SH coefficients per color channel [S2, unofficial].

The distillation loss is calculated as:
$$
\mathcal{L}_{\text{distill}} = \frac{1}{|P|} \sum_{p \in P} \|\mathbf{C}_p^{tea} - \mathbf{C}_p\|
$$
where $P$ is the set of pixels, $\mathbf{C}_p^{tea}$ is the rendered pixel color from the teacher, and $\mathbf{C}_p$ is the rendered pixel color from the student [S2, unofficial].

The scale-invariant depth distillation loss is:
$$
\mathcal{L}_{\text{depth}}(\mathbf{D}, \mathbf{D}^{tea}) = \frac{1}{|P|} \sum_{p \in P} \left( \log(\hat{\mathbf{D}}_p) - \log(\hat{\mathbf{D}}_p^{tea}) \right)^2 - \frac{1}{|P|^2} \left( \sum_{p \in P} \left( \log(\hat{\mathbf{D}}_p) - \log(\hat{\mathbf{D}}_p^{tea}) \right) \right)^2
$$
where $\hat{\mathbf{D}}_p^{tea} = \mathbf{D}^{tea} + \epsilon$ and $\epsilon = 10^{-8}$ for training stability [S2, unofficial].

**Parameters:**
- Target SH degree: 1 (first-order) [S1][S2, unofficial].
- Epsilon $\epsilon$: $10^{-8}$ [S2, unofficial].

**Pseudocode:**
```python
def first_order_sh_distillation(teacher_gaussians, student_gaussians, images, cameras, num_iterations):
    """
    Distill third-order SH from teacher to first-order SH in student.
    
    Args:
        teacher_gaussians: Pretrained 3DGS model with 3rd-order SH.
        student_gaussians: 3DGS model with 1st-order SH, same positions/scales/rotations/opacities as teacher.
        images: Ground truth images for supervision (optional, if using only distillation).
        cameras: Camera poses for rendering.
        num_iterations: Number of optimization steps.
        
    Returns:
        Optimized student_gaussians with first-order SH coefficients.
    """
    epsilon = 1e-8
    
    for iteration in range(num_iterations):
        # 1. Render from teacher (fixed)
        teacher_colors, teacher_depths = render_gaussians(teacher_gaussians, cameras)
        
        # 2. Render from student (trainable SH)
        student_colors, student_depths = render_gaussians(student_gaussians, cameras)
        
        # 3. Compute Distillation Loss (Color)
        # L_dstill = mean(||C_tea - C_stu||)
        color_diff = teacher_colors - student_colors
        l_distill = mean(square(color_diff))
        
        # 4. Compute Depth Distillation Loss (Scale-invariant)
        # D_tea_hat = D_tea + epsilon
        teacher_depths_hat = teacher_depths + epsilon
        
        # log_diff = log(D_stu) - log(D_tea_hat)
        log_diff = log(student_depths) - log(teacher_depths_hat)
        
        # L_depth = mean(log_diff^2) - mean(log_diff)^2
        l_depth = mean(square(log_diff)) - square(mean(log_diff))
        
        # 5. Total Loss
        # Note: Sources do not specify weighting factors between L_distill and L_depth.
        # [G] Assuming equal weighting or a small weight for depth if not specified.
        total_loss = l_distill + l_depth
        
        # 6. Backpropagate and update student SH coefficients
        gradients = compute_gradients(total_loss, student_gaussians)
        update_parameters(student_gaussians, gradients)
        
    return student_gaussians
```

**Edge Cases and Pitfalls:**
- **Depth Reliability**: The teacher's depth may not always be reliable, hence the use of scale-invariant loss rather than strict L1/L2 depth loss [S2, unofficial].
- **Precision**: The epsilon value $10^{-8}$ is critical for numerical stability in the log-depth calculation [S2, unofficial].
- **Degenerate Input**: If the student is initialized poorly, the distillation may fail to converge to a good approximation. Initialization via projection or random initialization with sufficient iterations is required.

## Subtopics

### SH Degree Reduction (General)
Reducing SH degree from 3 to 2 or 1 without distillation. Results in -36% parameters and -35% computation for 3→2, and -61% parameters and -52% computation for 3→1, with PSNR drops of -0.17 dB and -0.48 dB respectively [S1].

### Neural Vector Quantization (NVQ)
Compresses the distilled SH features using lightweight neural decoders after distillation, providing additional compression [S2, unofficial].

## Operating characteristics
- **Time Complexity**: Rendering complexity is reduced by 52% when moving from 3rd-order to 1st-order SH [S1]. The distillation training time depends on the number of iterations but is generally faster than full 3DGS training due to the fixed teacher and simplified student representation.
- **Memory Complexity**: Parameter count is reduced by 61% (from 16 to 4 coefficients per channel) [S1].
- **Measured Performance**: On standard datasets, 3→1 SH distillation results in a 0.48 dB PSNR drop compared to the original 3rd-order model [S1]. When combined with other compression methods (pruning, VQ), it contributes to a 51.6× overall compression [S1].
- **Strengths**: Significant reduction in storage and rendering speed, suitable for mobile devices [S2, unofficial].
- **Limitations**: Quality loss (0.48 dB PSNR drop) compared to full 3rd-order SH [S1].
- **When to use**: When deploying 3DGS on resource-constrained devices (mobile, edge hardware) where rendering speed and memory footprint are critical [S1][S2, unofficial].
- **When not to use**: When maximum visual fidelity is required and computational resources are abundant.

## Background
First-order Spherical Harmonics Distillation was introduced in the context of Mobile-GS, a method for real-time Gaussian Splatting on mobile devices [S2, unofficial]. It addresses the high parameter count and storage burden of the original 3DGS which uses third-order SH [S2, unofficial]. The method builds on the concept of knowledge distillation, where a smaller student model learns from a larger teacher model [S2, unofficial]. It is part of a broader effort to compress 3DGS for efficient deployment, alongside techniques like iterative pruning and neural vector quantization [S1][S2, unofficial].
