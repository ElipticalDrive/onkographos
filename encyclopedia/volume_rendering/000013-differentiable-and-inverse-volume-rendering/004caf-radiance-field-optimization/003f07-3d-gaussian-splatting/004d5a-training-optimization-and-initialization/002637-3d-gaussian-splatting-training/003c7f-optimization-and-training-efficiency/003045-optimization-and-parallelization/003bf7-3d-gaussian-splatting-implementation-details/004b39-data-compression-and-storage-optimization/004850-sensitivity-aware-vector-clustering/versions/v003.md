# Sensitivity-Aware Vector Clustering

Also called: Color Compression, Sensitivity-Aware Scene Compression, Sensitivity-aware k-Means

## Overview
Sensitivity-Aware Vector Clustering is a compression scheme for 3D Gaussian Splatting that reduces storage requirements by clustering Spherical Harmonic (SH) coefficients and Gaussian shape features (scale and rotation) into compact codebooks using sensitivity-aware vector quantization [S1]. It sets itself apart from standard post-training quantization by deriving a sensitivity measure to guide the clustering process, prioritizing the preservation of parameters that significantly affect image quality [S1]. Unlike [ASCII-Based Data Compression](11820-ascii-based-data-compression.md) which relies on ASCII representations, or [Compact 3D Gaussian Representation (C3DGS)](12927-compact-3d-gaussian-representation-c3dgs.md) which uses hash grids, this method explicitly weights the distance metric in k-Means clustering based on the gradient of the rendering error [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of optimized 3D Gaussian kernels, each defined by position, opacity, scale, rotation, and SH coefficients. A set of training images with known camera parameters.
*   **Output:** Two codebooks (one for color/SH, one for shape/rotation-scale) and a list of Gaussians where each Gaussian is represented by two indices (one for each codebook) instead of the full parameter vectors.

**Data Structures:**
1.  **Codebook (Color):** A list of $K$ vectors, where each vector contains the SH coefficients for a Gaussian.
2.  **Codebook (Shape):** A list of $K$ covariance matrices (or their decomposed forms). Each entry is stored as 4 scalar values for a quaternion (rotation) plus 3 scalar values for scaling [S1].
3.  **Gaussian Representation:** For each Gaussian, store two 32-bit unsigned integers representing the indices into the Color Codebook and Shape Codebook, respectively [S1].

**Sensitivity Calculation:**
The sensitivity $S(p)$ of a parameter $p$ is calculated to determine its impact on image quality. It is defined as the sum of the gradients of the total image energy $E$ with respect to $p$, normalized by the number of pixels [S1]:

$$ S(p) = \frac{\sum_{i=1}^{N} \frac{\partial E_i}{\partial p_i}}{\sum_{i=1}^{N} P_i} $$

Where:
*   $N$ is the number of training images.
*   $E_i$ is the total image energy (sum of RGB components) for image $i$.
*   $P_i$ is the number of pixels in image $i$.
*   The gradient $\frac{\partial E_i}{\partial p_i}$ is computed via a single backward pass over each training image [S1].

For a vector $x$ (e.g., a set of SH coefficients or a shape parameter vector), the sensitivity $S(x)$ is defined as the maximum sensitivity among its components $d$:

$$ S(x) = \max_d S(x_d) $$

**Clustering Algorithm:**
The method uses two separate codebooks: one for SH coefficients (Color) and one for Gaussian shape features (Shape) [S1].

1.  **Initialization:** Initialize codebook centroids randomly with a uniform distribution within the minimum and maximum values of each parameter [S1].
2.  **Thresholding (High Sensitivity):** Identify vectors with sensitivity higher than a threshold $\beta_c$ (for SH) or $\beta_g$ (for shape). These vectors are not clustered but are added directly to the respective codebook to preserve high-impact features [S1].
3.  **Weighted Distance:** For the remaining vectors, the distance between a vector $x$ and a centroid $c_k$ is weighted by the sensitivity of $x$:
    $$ D(x, c_k) = S(x) \|x - c_k\|_2^2 $$
4.  **Assignment:** Assign each vector $x$ to the centroid $c_k$ that minimizes $D(x, c_k)$ [S1].
5.  **Centroid Update:** Update each centroid $c_k$ using the weighted average of the assigned vectors $A(k)$:
    $$ c_k = \frac{1}{\sum_{x_i \in A(k)} S(x_i)} \sum_{x_i \in A(k)} S(x_i) x_i $$
6.  **Batched Strategy:** To improve performance, a random subset of vectors is picked in each update step. Centroids are updated using a moving average with a decay factor $\lambda_d$ [S1].
7.  **Renormalization (Shape Codebook):** For the shape codebook, clustering normalized covariance matrices can lead to non-unit scaling vectors due to floating-point errors. After each update step, each codebook vector is re-normalized by dividing it through the trace of the covariance metric [S1].
8.  **Decomposition:** After clustering, each codebook entry in the shape codebook (covariance matrix) is decomposed into rotation (quaternion) and scale parameters using eigenvalue decomposition. This is required for quantization-aware training [S1].

**Parameters:**
*   $\lambda_d$: Decay factor for the moving average in batched clustering. Typical value: 0.8 [S1].
*   Batch size for color features: $2^{18}$ [S1].
*   Batch size for Gaussian parameters: $2^{20}$ [S1].
*   Codebook size $K$: 4096 [S1].
*   $\beta_c$: Sensitivity threshold for SH coefficients. Gaussians with sensitivity $> \beta_c$ are excluded from clustering and added directly to the codebook. Typical value: $6 \times 10^{-7}$ [S1].
*   $\beta_g$: Sensitivity threshold for shape parameters. Typical value: $3 \times 10^{-6}$ [S1].

**Edge Cases and Pitfalls:**
*   **Floating Point Errors:** Clustering normalized covariance matrices can lead to non-unit scaling vectors due to floating-point errors. This is handled by re-normalizing each codebook vector after each update step by dividing it through the trace of the covariance metric [S1].
*   **High Sensitivity Vectors:** A small percentage of SH coefficients (< 5%) have high sensitivity. These must be identified and added directly to the codebook to prevent significant rendering error [S1].

## Operating characteristics
*   **Compression Rate:** Achieves up to 31× compression on real-world scenes with minimal visual degradation [S1].
*   **Rendering Speed:** Enables real-time rendering on lightweight GPUs, up to 4× higher framerates than the baseline via an optimized GPU compute pipeline [S1].
*   **Memory:** Significantly reduces memory consumption, making it suitable for network streaming and low-power devices [S1].
*   **Training:** Requires quantization-aware fine-tuning (e.g., 5000 optimization steps) to recover information lost during clustering [S1].
*   **Strengths:** High compression ratio, real-time rendering capability, robustness across multiple datasets [S1].
*   **Limitations:** Requires additional complexity in the renderer (GPU sorting and rasterization) and training pipeline (sensitivity calculation, clustering, fine-tuning) [S1].

## Background
Sensitivity-Aware Vector Clustering was proposed in the paper "Compressed 3D Gaussian Splatting for Accelerated Novel View Synthesis" [S1]. It builds on the observation that SH coefficients and Gaussian shape parameters in 3D Gaussian Splatting are highly redundant and take up the majority of storage space [S1]. The method is inspired by volumetric radiance field compression and deep network weight quantization [S1]. It was demonstrated on datasets like Mip-NeRF 360, Tanks&Temples, and Deep Blending [S1].
