# Data Compression and Storage Optimization

Also called: Gaussian Compression, 3DGS Storage Optimization

## Overview
Data Compression and Storage Optimization addresses the excessive memory footprint and storage requirements of 3D Gaussian Splatting (3DGS) models, which store dense per-primitive attributes for position, scale, rotation, opacity, and view-dependent color [S1]. This family of methods reduces these costs by exploiting spatial redundancy, quantizing parameters, or encoding data in compact formats, distinguishing itself from rendering pipeline optimizations by focusing on the representation and serialization of the Gaussian primitives themselves [S1].

## Shared principles
All methods in this family aim to reduce the number of bits required to store or transmit Gaussian attributes without significantly degrading rendering quality [S1]. The core mechanisms involve:
1.  **Quantization/Clustering:** Mapping continuous parameters (e.g., SH coefficients, scale, rotation) to discrete indices pointing to a smaller codebook [S1, S2].
2.  **Spatial Interpolation:** Replacing per-Gaussian attributes with values retrieved from a global structure (e.g., hash grid) based on position [S3].
3.  **Encoding:** Converting numerical values into compact string or binary representations to reduce serialization overhead [S1].

## Subtopics

### [ASCII-Based Data Compression](11820-ascii-based-data-compression.md)
Encodes numerical attributes into compact ASCII strings (base-94/95) to optimize data transmission speed during training, targeting serialization latency rather than memory footprint.

### [Sensitivity-Aware Vector Clustering](12167-sensitivity-aware-vector-clustering.md)
Reduces storage by clustering SH coefficients and shape parameters into codebooks using a sensitivity-weighted k-Means algorithm, preserving high-impact parameters.

### [Compact 3D Gaussian Representation (C3DGS)](12927-compact-3d-gaussian-representation-c3dgs.md)
Achieves high compression (~25×) by replacing per-Gaussian color storage with a hash-based neural field and geometry with a codebook, exploiting spatial redundancy.

## Background
3D Gaussian Splatting introduces a large number of primitives, leading to significant storage overhead compared to traditional radiance fields [S1]. Recent research has focused on compressing these attributes to enable efficient storage and transmission, particularly for real-time applications and large-scale scenes [S1].
