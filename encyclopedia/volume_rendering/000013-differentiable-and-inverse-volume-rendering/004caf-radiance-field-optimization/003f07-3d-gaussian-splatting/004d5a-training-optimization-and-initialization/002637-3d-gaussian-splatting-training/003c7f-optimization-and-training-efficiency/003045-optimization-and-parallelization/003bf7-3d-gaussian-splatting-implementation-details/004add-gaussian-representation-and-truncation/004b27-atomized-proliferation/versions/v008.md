# Atomized Proliferation

Also called: Atom Gaussian Densification

## Overview
Atomized Proliferation is a densification and refinement strategy for 3D Gaussian Splatting that enhances geometric precision by constraining Gaussians representing fine details into "Atom Gaussians" (isotropic spheroids with uniform size) and prioritizing their proliferation to align with scene geometry, followed by pruning to merge large smooth surfaces [S1, unofficial]. Unlike standard 3D Gaussian Splatting, which struggles to stabilize densification and often results in noisy meshes or blurry artifacts, Atomized Proliferation uses a warm-up strategy that aggressively densifies initially, then merges, leading to a declining and stabilizing trend in Gaussian count [S1, unofficial]. It builds on [Gaussian Representation and Truncation](12855-gaussian-representation-and-truncation.md) by introducing specific constraints on Gaussian shape and scale evolution during the training process.

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D Gaussians defined by mean position $\mu$, covariance $\Sigma$, color $c$, and opacity $\alpha$; input Structure-from-Motion (SfM) points; hyperparameters $\tau_c, \tau_s, \varepsilon, S, t_a, t_w$.
*   **Output:** An optimized set of Gaussians with refined geometry, where fine details are represented by Atom Gaussians and smooth surfaces by merged, larger Gaussians.

**Data Structures:**
The Gaussian set is represented as four parallel arrays or structures:
*   $M$: Mean positions $\mu$ (3D vector).
*   $S$: Covariance matrices $\Sigma$ (3x3 symmetric positive definite matrix, or parameterized by scale $s$ and rotation $q$).
*   $C$: Colors $c$ (RGB or spherical harmonics coefficients).
*   $A$: Opacities $\alpha$ (scalar).

**Parameters:**
*   $\tau_c$: Clone Threshold. Typical value: 0.002 [S1, unofficial].
*   $\tau_s$: Base Split Threshold. Typical value: 0.002 [S1, unofficial].
*   $\varepsilon$: Prune Threshold (opacity). Typical value: 0.005 (0.5 for DTU dataset) [S1, unofficial].
*   $S$: Atom Scale. Defined as the $i$-th percentile of distances from input SfM points, $S = P_i(d)$. Typically $i=1$ (first percentile) [S1, unofficial].
*   $t_a$: Atomized Proliferation Duration (iteration limit for atomization). Typical value: 7000 [S1, unofficial].
*   $t_w$: Warm-Up Duration (iteration limit for dynamic split threshold). Typical value: 7000 [S1, unofficial].
*   $p$: Final proportion to initial $S$ for geometric progression. Not given in the sources.
*   $r$: Geometric progression ratio, $r = p^{1/t_a}$ [S1, unofficial].

**Algorithm Steps:**
1.  **Initialization:** Calculate Atom Scale $S$ from input SfM points. $S = P_i(d)$, where $d$ are ordered distances between SfM points.
2.  **Iteration Loop:** For each training iteration $i$ from 1 to total iterations:
    3.  **Process Each Gaussian:** Iterate through all Gaussians in the set $(M, S, C, A)$.
    4.  **Pruning:** If opacity $\alpha < \varepsilon$ OR the covariance $\Sigma$ is excessively large (determined by `IsTooLarge(Σ)`), prune the Gaussian [S1, unofficial].
    5.  **Cloning:** If the loss gradient $\nabla_p L \ge \tau_c$, clone the Gaussian [S1, unofficial].
    6.  **Splitting:** If $\nabla_p L \ge \min(\frac{i}{t_w}\tau_s, \tau_s)$ AND the maximum norm of the covariance $\|\Sigma\|_{max} > S$, split the Gaussian [S1, unofficial]. The threshold $\min(\frac{i}{t_w}\tau_s, \tau_s)$ implements a linear warm-up, increasing from 0 to $\tau_s$ over $t_w$ iterations.
    7.  **Atomization:** If the minimum norm of the covariance $\|\Sigma\|_{min} \le S$ AND $i < t_a$, atomize the Gaussian [S1, unofficial].
        *   **Atomization Details:**
            *   Designate the Gaussian as an Atom Gaussian.
            *   Set its size $s = S^{1/3}$ (assuming isotropic scaling where $s_1=s_2=s_3$) [S1, unofficial].
            *   Fix the scale for backpropagation optimization (no gradient update to scale).
            *   Update the scale via geometric progression: $S_n = S_{n-1} \cdot r^{n-1}$, where $r = p^{1/t_a}$ [S1, unofficial]. This ensures the atom scale decreases over iterations, enhancing fine detail representation.
    8.  **Opacity Resetting:** Increase the frequency of opacity resetting during training to facilitate merging of Gaussians depicting large, simple surfaces [S1, unofficial].

**Pseudocode:**
```python
def atomized_proliferation(gaussians, sfm_points, tau_c, tau_s, epsilon, S_atom, t_a, t_w, p):
    """
    gaussians: List of Gaussian objects with attributes mu, Sigma, c, alpha, grad_L
    sfm_points: List of 3D points from SfM
    tau_c: Clone threshold
    tau_s: Base split threshold
    epsilon: Prune threshold (opacity)
    S_atom: Atom scale threshold (e.g., 1st percentile of SfM distances)
    t_a: Total atomization iterations
    t_w: Warm-up iterations
    p: Final proportion factor for geometric progression
    """
    # Calculate geometric progression ratio
    # r = p^(1/t_a)
    r = p ** (1.0 / t_a)
    
    # Current atom scale for progression
    current_atom_scale = S_atom
    
    for i in range(1, total_iterations + 1):
        # Linear warm-up for split threshold
        # threshold_s = min((i / t_w) * tau_s, tau_s)
        if i < t_w:
            threshold_s = (i / t_w) * tau_s
        else:
            threshold_s = tau_s
            
        for gaussian in gaussians:
            # 1. Pruning
            if gaussian.alpha < epsilon or is_too_large(gaussian.Sigma):
                remove_gaussian(gaussian)
                continue
                
            # 2. Cloning
            if gaussian.grad_L >= tau_c:
                clone_gaussian(gaussian)
                
            # 3. Splitting
            # Check max norm of covariance
            max_norm = get_max_norm(gaussian.Sigma)
            if gaussian.grad_L >= threshold_s and max_norm > S_atom:
                split_gaussian(gaussian)
                
            # 4. Atomization
            # Check min norm of covariance
            min_norm = get_min_norm(gaussian.Sigma)
            if min_norm <= S_atom and i < t_a:
                atomize_gaussian(gaussian, current_atom_scale)
                
        # Update atom scale for next iteration if within atomization phase
        if i < t_a:
            current_atom_scale = current_atom_scale * r

def atomize_gaussian(gaussian, scale_value):
    """
    Convert Gaussian to Atom Gaussian with fixed scale.
    """
    gaussian.is_atom = True
    # Set isotropic scale s = S^(1/3)
    s = scale_value ** (1.0 / 3.0)
    gaussian.scale = [s, s, s]
    # Fix scale for optimization (no gradient)
    gaussian.scale.requires_grad = False
```

**Edge Cases and Pitfalls:**
*   **SfM Point Quality:** The Atom Scale $S$ depends on the density and distribution of input SfM points. Poor SfM reconstruction may lead to inappropriate $S$ values.
*   **Dataset Specifics:** For object-centered datasets (e.g., DTU), the Prune Threshold $\varepsilon$ should be increased (e.g., to 0.5) to avoid over-pruning [S1, unofficial]. The Atom Scale $S$ may also be adjusted (e.g., $P_{10}(d)$) [S1, unofficial].
*   **Scale Learning Rate:** For object-centered datasets, set scale learning rate $\eta_s = 0$ to maximize geometric accuracy [S1, unofficial].
*   **Warm-up Phase:** The linear warm-up for the split threshold is critical for aggressive initial densification. If $t_w$ is too short, the method may not densify sufficiently; if too long, it may delay necessary splitting.

## Operating characteristics
*   **Time Complexity:** Similar to standard 3D Gaussian Splatting per iteration, but with additional checks for atomization and geometric progression updates. The warm-up phase may increase initial densification overhead.
*   **Memory Complexity:** Depends on the final number of Gaussians. The method aims to stabilize Gaussian count, potentially reducing memory usage compared to standard 3DGS which may retain excessive Gaussians [S1, unofficial].
*   **Measured Performance:** On Mip-NeRF360, AtomGS achieved an average training time of 0.28 hours and a final model size of 749MB, compared to 3DGS's 0.40 hours and 869MB [S1, unofficial].
*   **Strengths:** Enhances geometric precision, reduces noisy meshes and blurry artifacts, stabilizes Gaussian proliferation, and achieves superior quality with potentially smaller model sizes [S1, unofficial].
*   **Limitations:** Requires careful tuning of hyperparameters ($\tau_c, \tau_s, \varepsilon, S, t_a, t_w$) and SfM point quality. May not be optimal for scenes with very different scale characteristics without adjustment.
*   **When to Use:** When high-fidelity geometric reconstruction is required, especially for scenes with intricate details. Particularly effective for object-centered datasets with adjustments.
*   **When Not to Use:** If training time or memory is extremely constrained and standard 3DGS quality is sufficient. If SfM points are sparse or unreliable.

## Background
Atomized Proliferation was proposed in the paper "AtomGS: Atomizing Gaussian Splatting for High-Fidelity Radiance Field" by Liu, Xu, Hu, Chen, and Feng [S1, unofficial]. It addresses issues in standard 3D Gaussian Splatting where Gaussians may not adhere to underlying geometric structures, leading to noisy 3D meshes, blurry artifacts, and slower convergence speeds [S1, unofficial]. The method introduces Atom Gaussians and a geometry-guided optimization strategy to compactly model smooth surfaces while retaining primitives for fine details [S1, unofficial].
