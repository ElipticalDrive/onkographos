# SWAG (Splatting in the Wild images with Appearance-conditioned Gaussians)


## Overview
SWAG is an extension of 3D Gaussian Splatting (3DGS) designed to handle unstructured, in-the-wild image collections by modeling appearance variations and handling transient objects (occluders) without supervision [S1]. It sets itself apart from standard 3DGS by disentangling static scene geometry from dynamic appearance and transient occluders, using image-dependent embeddings and opacity modulation to prevent the "blurry elongated Gaussians" and floaters typical of view-dependent 3DGS in unconstrained settings [S1]. It builds on [3D Gaussian Splatting Implementation Details](9128-3d-gaussian-splatting-implementation-details.md) by adding a conditioning mechanism for color and opacity.

## How it works
SWAG modifies the 3DGS representation by introducing per-image conditioning for color and opacity, allowing the model to adapt to lighting changes and exclude transient objects like tourists or clouds [S1].

### Inputs and Outputs
*   **Inputs:** A set of unstructured images $I_i$ with known camera poses, and an initial sparse point cloud from Structure-from-Motion (SfM) [S1].
*   **Outputs:** A set of 3D Gaussians representing the static scene, and a mechanism to identify and optionally remove transient Gaussians [S1].

### Data Structures
For each Gaussian $g$, SWAG optimizes the standard 3DGS parameters plus additional conditioning parameters [S1]:
1.  **Centroid:** $\mathbf{x} \in \mathbb{R}^3$
2.  **Scale:** $\mathbf{s} \in \mathbb{R}^3$
3.  **Rotation:** $\mathbf{q} \in \mathbb{R}^4$ (quaternion)
4.  **Base Opacity:** $\alpha \in \mathbb{R}$
5.  **Base Color:** $\mathbf{c}$ encoded in spherical harmonic (SH) coefficients [S1].
6.  **Hash Grid Encoding:** A hash table $H$ encoding the Gaussian center $\mathbf{x}$ into a feature vector $\text{emb}(\mathbf{x})$ [S1].
7.  **Per-Image Embedding:** A latent vector $\mathbf{l}_I \in \mathbb{R}^{d_{emb}}$ for each training image $I$ [S1].
8.  **MLP Parameters:** Weights and biases for an MLP $F_\theta$ [S1].

**Hash Grid Layout:**
*   Hash table size $T = 2^{19}$ [S1].
*   Finest resolution $N_{max} = 2048$ [S1].
*   Coarsest resolution $N_{min} = 16$ [S1].
*   Number of levels $L = 12$ [S1].
*   The encoding $\text{emb}(\mathbf{x})$ is the concatenation of features from all levels [S1].

**MLP Layout ($F_\theta$):**
*   Input dimension: 3 (base color $\mathbf{c}$) + $d_{emb}$ (image embedding $\mathbf{l}_I$) + $d_{hash}$ (encoded center $\text{emb}(\mathbf{x})$). Note: The source specifies "Input dimension: 3" for the MLP, but also states it takes $\mathbf{c}$, $\mathbf{l}_I$, and $\text{emb}(\mathbf{x})$. Given $\mathbf{c}$ is typically 3 channels, and $\mathbf{l}_I$ is 24, and $\text{emb}(\mathbf{x})$ is derived from the hash grid, the total input dimension is $3 + 24 + d_{hash}$. The source lists "Input dimension: 3" likely referring to the color component or a specific simplified view, but explicitly lists the three inputs. We assume the MLP takes the concatenation of these three vectors [S1].
*   Number of layers: 8 [S1].
*   Hidden layers size: 51 [S1].
*   Output dimension: 64 (to produce $\mathbf{c}_I$ and $\Delta \alpha_I$) [S1].

### Numbered Steps

1.  **Initialization:** Initialize 3D Gaussians from SfM points with standard 3DGS parameters [S1]. Initialize the Hash Grid $H$, per-image embeddings $\mathbf{l}_I$, and MLP $F_\theta$ [S1].
2.  **Feature Encoding:** For each Gaussian $g$ with center $\mathbf{x}$, compute the hash grid encoding $\text{emb}(\mathbf{x}) = H(\mathbf{x})$ [S1].
3.  **Conditioning:** For a training image $I$ with embedding $\mathbf{l}_I$:
    *   Concatenate the Gaussian's base color $\mathbf{c}$, the image embedding $\mathbf{l}_I$, and the center encoding $\text{emb}(\mathbf{x})$ [S1].
    *   Pass the concatenated vector through the MLP $F_\theta$ to obtain an output vector $\mathbf{v}$ [S1].
    *   Split $\mathbf{v}$ into an image-dependent color $\mathbf{c}_I$ and an image-dependent opacity variation parameter $\Delta \alpha_I$ [S1].
4.  **Opacity Modulation:**
    *   Sample the opacity variation $\Delta \tilde{\alpha}_I$ from a concrete distribution (Gumbel-Softmax) using $\Delta \alpha_I$ as the location variable [S1].
    *   Compute the final opacity $\alpha_{final} = \alpha \cdot \Delta \tilde{\alpha}_I$ (or similar modulation, source implies $\Delta \alpha_I$ modulates opacity) [S1].
    *   *Note:* The source states $\Delta \alpha_I$ is the location variable of a concrete distribution. The concrete distribution typically maps a real value to $[0,1]$. The final opacity is derived from this sample [S1].
5.  **Rendering:** Render the image using the standard 3DGS rasterization pipeline, using $\mathbf{c}_I$ for color and $\alpha_{final}$ for opacity [S1].
6.  **Optimization:**
    *   Minimize the reconstruction loss (e.g., L1 + SSIM) between the rendered image and the ground truth image $I$ [S1].
    *   Update Gaussians parameters ($\mathbf{x}, \mathbf{s}, \mathbf{q}, \alpha, \mathbf{c}$), Hash Grid $H$, image embeddings $\mathbf{l}_I$, and MLP $F_\theta$ using Adam optimizer [S1].
7.  **Transient Detection (Post-Training or Inference):**
    *   Compute the variance of the sampled opacity variations $\Delta \tilde{\alpha}_I$ across all training images for each Gaussian [S1].
    *   Gaussians with high variance are identified as transient [S1].
    *   To remove transient objects, Gaussians can be filtered based on a threshold $\lambda$ [S1].

### Formulas
*   **MLP Output:**
    $$ [\mathbf{c}_I, \Delta \alpha_I] = F_\theta([\mathbf{c}; \mathbf{l}_I; \text{emb}(\mathbf{x})]) $$
    where $[\cdot; \cdot]$ denotes concatenation [S1].
*   **Opacity Sampling:**
    $$ \Delta \tilde{\alpha}_I \sim \text{Concrete}(\Delta \alpha_I, \tau) $$
    where $\tau$ is the temperature parameter of the concrete distribution [S1].
*   **Final Opacity:**
    $$ \alpha_{final} = \alpha \cdot \Delta \tilde{\alpha}_I $$
    (Inferred from "modulate the final opacity" and "opacity variation parameter") [S1].
*   **Transient Variance:**
    $$ \text{Var}(\Delta \tilde{\alpha}_I) = \frac{1}{N} \sum_{i=1}^{N} (\Delta \tilde{\alpha}_{I_i} - \bar{\Delta \alpha}_I)^2 $$
    where $N$ is the number of training images [S1].

### Parameters
*   **Iterations:** 60,000 [S1].
*   **Densification Interval:** 2,000 [S1].
*   **Densification End:** 30,000 [S1].
*   **Image Embedding Dimension ($d_{emb}$):** 24 [S1].
*   **Learning Rate (Image Embeddings):** 0.0025 [S1].
*   **Hash Grid Learning Rate:** 0.0025 [S1].
*   **MLP Learning Rate:** 0.0025 [S1].
*   **MLP Hidden Size:** 51 [S1].
*   **MLP Output Dimension:** 64 [S1].

### Edge Cases and Pitfalls
*   **Holes in Transient-Rich Areas:** In scenes with frequent transient objects (e.g., clouds, tourists), removing all transient Gaussians can leave holes (black spots) in the static scene [S1].
*   **Threshold Tuning:** To mitigate holes, an adaptive threshold $\lambda$ can be used to remove Gaussians based on $\text{Var}(\Delta \tilde{\alpha}_I) < \lambda$, but this requires manual tuning of $\lambda$ [S1].
*   **Performance:** Training time almost doubles compared to 3DGS; inference time per frame is 10 times longer than 3DGS [S1].

import torch
import torch.nn as nn
import torch.nn.functional as F

class SWAG:
    def __init__(self, num_images, hash_table_size=2**19, n_max=2048, n_min=16, num_levels=12, 
                 emb_dim=24, mlp_hidden=51, mlp_layers=8, mlp_output=64):
        # Hash Grid Encoder (simplified implementation detail)
        self.hash_grid = HashGridEncoder(hash_table_size, n_max, n_min, num_levels)
        
        # Per-image embeddings
        self.image_embeddings = nn.Embedding(num_images, emb_dim)
        
        # MLP for conditioning
        # Input: color (3) + image_emb (24) + hash_emb (hash_grid.output_dim)
        hash_emb_dim = self.hash_grid.output_dim
        input_dim = 3 + emb_dim + hash_emb_dim
        
        layers = []
        for _ in range(mlp_layers):
            layers.append(nn.Linear(input_dim if not layers else mlp_hidden, mlp_hidden))
            layers.append(nn.ReLU())
            input_dim = mlp_hidden
        layers.append(nn.Linear(mlp_hidden, mlp_output))
        self.mlp = nn.Sequential(*layers)
        
        # Gaussians parameters (initialized from SfM)
        self.centroids = None # (N, 3)
        self.scales = None    # (N, 3)
        self.rotations = None # (N, 4)
        self.base_opacities = None # (N,)
        self.base_colors = None # (N, 3) in SH coefficients or RGB
        
        # Optimizers
        self.optimizer = torch.optim.Adam([
            {'params': self.hash_grid.parameters()},
            {'params': self.image_embeddings.parameters()},
            {'params': self.mlp.parameters()},
            {'params': self.centroids},
            {'params': self.scales},
            {'params': self.rotations},
            {'params': self.base_opacities},
            {'params': self.base_colors}
        ], lr=0.0025)

    def get_hash_encoding(self, centroids):
        return self.hash_grid(centroids)

    def condition_gaussian(self, base_color, image_idx, hash_encoding):
        # base_color: (N, 3)
        # image_idx: (N,) tensor of image indices
        # hash_encoding: (N, hash_emb_dim)
        
        image_emb = self.image_embeddings(image_idx) # (N, emb_dim)
        
        # Concatenate: color, image_emb, hash_encoding
        # Note: Source says MLP takes c, lI, emb(x). 
        # Assuming batched operation where each Gaussian is conditioned by the image it is rendered for.
        # In a typical rasterization loop, we process Gaussians visible in a specific image.
        
        # For a single image rendering, we filter Gaussians visible in that image.
        # Let's assume inputs are for Gaussians visible in image I.
        
        combined = torch.cat([base_color, image_emb, hash_encoding], dim=-1)
        mlp_out = self.mlp(combined) # (N, mlp_output)
        
        # Split into color and opacity variation parameter
        c_I = mlp_out[:, :3]
        delta_alpha_I = mlp_out[:, 3:4]
        
        return c_I, delta_alpha_I

    def sample_opacity(self, delta_alpha_I, temperature=1.0):
        # Sample from Concrete distribution
        # Using Gumbel-Softmax approximation
        # Concrete distribution for [0, 1]
        u = torch.rand_like(delta_alpha_I)
        # Gumbel noise
        g = -torch.log(-torch.log(u + 1e-10) + 1e-10)
        # Concrete sample
        # y = sigmoid((log(u) - log(1-u) + delta_alpha_I) / temperature)
        # This is a standard approximation. The source says "location variable".
        # We assume a standard concrete distribution implementation.
        
        # Simplified Concrete Sample
        logits = delta_alpha_I / temperature
        u = torch.rand_like(logits)
        g = -torch.log(-torch.log(u + 1e-10) + 1e-10)
        y = torch.sigmoid((logits + g) / temperature)
        
        return y

    def render_image(self, image_idx, cameras, gaussians):
        # 1. Get Gaussians visible in this image
        visible_gaussians = get_visible_gaussians(gaussians, cameras[image_idx])
        
        # 2. Get features
        base_color = visible_gaussians.base_color
        hash_encoding = self.get_hash_encoding(visible_gaussians.centroids)
        
        # 3. Condition
        c_I, delta_alpha_I = self.condition_gaussian(base_color, image_idx, hash_encoding)
        
        # 4. Sample opacity variation
        delta_alpha_sample = self.sample_opacity(delta_alpha_I)
        
        # 5. Final opacity
        alpha_final = visible_gaussians.base_opacity * delta_alpha_sample
        
        # 6. Render using 3DGS rasterizer
        # Use c_I for color and alpha_final for opacity
        rendered_image = rasterize_gaussians(
            gaussians=visible_gaussians,
            cameras=cameras[image_idx],
            colors=c_I,
            opacities=alpha_final,
            scales=visible_gaussians.scales,
            rotations=visible_gaussians.rotations
        )
        
        return rendered_image

    def train_step(self, image_idx, ground_truth_image):
        rendered_image = self.render_image(image_idx, self.cameras, self.gaussians)
        loss = compute_loss(rendered_image, ground_truth_image)
        self.optimizer.zero_grad()
        loss.backward()
        self.optimizer.step()
        return loss

    def identify_transient_gaussians(self, num_iterations=1000):
        # Sample opacity variations for all training images
        variances = []
        for i in range(len(self.image_embeddings)):
            # Get all Gaussians
            hash_encoding = self.get_hash_encoding(self.gaussians.centroids)
            c_I, delta_alpha_I = self.condition_gaussian(self.gaussians.base_color, i, hash_encoding)
            delta_alpha_sample = self.sample_opacity(delta_alpha_I, temperature=0.1) # Low temp for deterministic sample
            variances.append(delta_alpha_sample)
        
        variances = torch.stack(variances, dim=0) # (NumImages, NumGaussians)
        variance_per_gaussian = torch.var(variances, dim=0) # (NumGaussians,)
        
        return variance_per_gaussian

## Subtopics

### SWAG-A (No Transient Detection)
A variant that only includes appearance modeling. It produces colors closer to ground truth than 3DGS but still suffers from floaters caused by transient objects [S1].

### SWAG-T (No Appearance Modeling)
A variant that only includes transient detection. It eliminates floaters and produces an occluder-free scene but suffers from color alterations (averaging) similar to 3DGS [S1].

## Operating characteristics
*   **Training Time:** Almost doubles compared to standard 3DGS [S1].
*   **Inference Time:** 10 times longer per frame than 3DGS [S1].
*   **Memory:** Increased memory usage due to Hash Grid, Image Embeddings, and MLP parameters [S1].
*   **Strengths:** Handles unstructured in-the-wild data, models appearance variations, removes transient objects without supervision, faster than previous implicit in-the-wild baselines [S1].
*   **Limitations:** Slower training and inference than 3DGS, requires manual tuning of threshold $\lambda$ for transient removal to avoid holes, less than 20% of Gaussians capture transient objects on average [S1].
*   **When to Use:** When reconstructing scenes from unstructured, in-the-wild photo collections with varying lighting and transient occluders [S1].
*   **When Not to Use:** When real-time rendering speed is critical and the scene is static and well-controlled (use standard 3DGS) [S1].

## Background
SWAG was introduced by H. Dahmani et al. in 2024 [S1]. It is designed to extend 3D Gaussian Splatting to handle the challenges of in-the-wild scenarios, such as photometric variations and transient occluders, which standard 3DGS struggles with [S1]. It was evaluated on the Phototourism Dataset (Brandenburg Gate, Sacré Cœur, Trevi Fountain) and the NeRF-OSR Dataset [S1].
