# 3D Gaussian Splatting to Point Cloud

Also called: 3DGS to Point Cloud Conversion, 3DGS-to-PC, Gaussian Splatting Point Cloud Generation, Gaussian Splatting to Dense Point Clouds

## Overview
This method converts a trained 3D Gaussian Splatting (3DGS) scene into a dense, high-quality point cloud that approximates the original volumetric representation, enabling compatibility with standard 3D software that lacks native 3DGS support [S1, unofficial]. It distinguishes itself from sibling methods like [SuGaR Mesh Extraction](12580-sugar-mesh-extraction.md) by focusing on faithful point cloud generation from the original optimized Gaussians rather than learning a new explicit representation, optionally incorporating rendered camera views to weight contributions and filter surface proximity [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3DGS scene file (PLY or splat format) containing Gaussian parameters (means $\mathbf{p}_i$, scales, rotations, colors, opacities, and Spherical Harmonics coefficients), and optionally camera transforms (COLMAP or transform files) for color rendering.
*   **Output:** A Point Cloud file (PLY) containing points, colors, and optionally normals. Optionally, a mesh (PLY) if mesh generation is enabled.

**Data Structures:**
The implementation uses a `GaussPointCloudSettings` configuration and internal Gaussian storage.
*   `GaussPointCloudSettings`: A named tuple or configuration object containing:
    *   `renderer_type` (str): 'cuda' or 'python'.
    *   `num_points` (int): Total target points (Default: 10,000,000).
    *   `exact_num_points` (bool): Enforce exact count (Default: False).
    *   `prioritise_visible_gaussians` (bool): Weight sampling by visibility (Default: True).
    *   `mahalanobis_distance_std` (float): Max distance for sampling (Default: 2.0).
    *   `visibility_threshold` (float): Min contribution to include Gaussian (Default: 0.05).
    *   `min_opacity` (float): Min opacity filter (Default: 0.0).
    *   `cull_gaussian_sizes` (float): Percentage of largest Gaussians to remove (Default: 0.0).
    *   `bounding_box_min` / `bounding_box_max` (list): Spatial filters.
    *   `surface_distance_std` (float): Threshold for surface culling (Default: Disabled).
    *   `generate_mesh` (bool): Enable mesh output (Default: False).
    *   `no_calculate_normals` (bool): Skip normal calculation (Default: False).
    *   `colour_quality` (str): 'tiny', 'low', 'medium', 'high', 'ultra', 'original' (Default: 'high').
*   `PointCloudData`: A named tuple containing:
    *   `points` (torch.Tensor): Shape $(N, 3)$.
    *   `colours` (torch.Tensor): Shape $(N, 3)$.
    *   `normals` (torch.Tensor): Shape $(N, 3)$, if calculated.

**Steps:**

1.  **Load and Validate Gaussians:**
    Load Gaussian parameters from the input file. Validate covariance matrices to ensure they are positive semidefinite. If invalid (due to floating-point errors), clamp them or remove the Gaussian [S1, unofficial].
    *   Compute eigenvalues of the covariance matrix $\Sigma_i$.
    *   If any eigenvalue $< \epsilon$, clamp or cull the Gaussian [S1, unofficial].

2.  **Pre-Sampling Culling:**
    Filter Gaussians based on user-defined constraints before sampling:
    *   **Opacity:** Remove Gaussians where $\alpha_i < \text{min\_opacity}$ [S1, unofficial].
    *   **Bounding Box:** Remove Gaussians where $\mathbf{p}_i$ is outside $[\text{bounding\_box\_min}, \text{bounding\_box\_max}]$ [S1, unofficial].
    *   **Size:** Remove the largest $\text{cull\_gaussian\_sizes}$ fraction of Gaussians based on their surface area [S1, unofficial].
    *   **Visibility (Optional):** If `prioritise_visible_gaussians` is True, render the scene from provided camera views to compute the total contribution (visibility) of each Gaussian. Remove Gaussians with total contribution $< \text{visibility\_threshold}$ [S1, unofficial].

3.  **Calculate Sampling Weights:**
    Determine the number of points to sample from each Gaussian.
    *   Compute the surface area $A_i$ of the Gaussian ellipsoid using its eigenvalues $\lambda_1, \lambda_2, \lambda_3$ (where $a=\sqrt{\lambda_1}, b=\sqrt{\lambda_2}, c=\sqrt{\lambda_3}$):
        $$
        A_i \approx 4\pi \left( \frac{a^p b^p + a^p c^p + b^p c^p}{3} \right)^{1/p}, \quad p=1.6075
        $$
    *   Calculate magnitude $M_i$:
        $$
        M_i = \sqrt{A_i} \times C_i
        $$
        where $C_i$ is the visibility contribution (if enabled) or opacity $\alpha_i$ (if disabled) [S1, unofficial].

4.  **Sample Points:**
    For each remaining Gaussian $i$:
    *   Determine the number of samples $n_i$ proportional to $M_i$, normalized to sum to `num_points`.
    *   If `exact_num_points` is False, use a fixed number of attempts (e.g., 5) per Gaussian; if True, use more attempts (e.g., 100) to ensure exact counts [S1, unofficial].
    *   Sample points $\mathbf{x}$ from the multivariate normal distribution $\mathcal{N}(\mathbf{p}_i, \Sigma_i)$.
    *   Reject samples where the Mahalanobis distance $d_M = \sqrt{(\mathbf{x} - \mathbf{p}_i)^T \Sigma_i^{-1} (\mathbf{x} - \mathbf{p}_i)}$ exceeds `mahalanobis_distance_std` (Default: 2.0) [S1, unofficial].
    *   Add the mean $\mathbf{p}_i$ as a point for every Gaussian [S1, unofficial].

5.  **Color and Normal Assignment:**
    *   **Colors:** If `no_render_colours` is False, render the scene using the selected `renderer_type` ('cuda' or 'python') at the resolution defined by `colour_quality` [S1, unofficial]. Map the rendered colors to the generated points. If rendering is skipped, original Gaussian colors are used (may appear inconsistent) [S1, unofficial].
    *   **Normals:** If `no_calculate_normals` is False, compute normals for each point. Normals can be derived from the gradient of the density field or estimated from the local orientation of the Gaussian covariance matrix [S1, unofficial].

6.  **Post-Processing (Optional):**
    *   **Clean Point Cloud:** If `clean_pointcloud` is True, remove outliers using Open3D [S1, unofficial].
    *   **Mesh Generation:** If `generate_mesh` is True:
        *   Identify surface Gaussians using `surface_distance_std` [S1, unofficial].
        *   Cull non-surface Gaussians.
        *   Generate a separate point cloud with a fixed average of 25 points per surface Gaussian, capped at half the total requested points [S1, unofficial].
        *   Apply Poisson Surface Reconstruction with `poisson_depth` (Default: 10) [S1, unofficial].
        *   Apply Laplacian smoothing with `laplacian_iterations` (Default: 10) [S1, unofficial].

import numpy as np

def convert_3dgs_to_pointcloud(gaussians, settings):
    """
    Convert 3DGS to Point Cloud.
    gaussians: Dict with keys 'xyz', 'scales', 'rots', 'colors', 'opacities', 'sh_coeffs', 'covariances'
    settings: GaussPointCloudSettings object
    """
    # 1. Load and Validate
    xyz = gaussians['xyz']
    covariances = gaussians['covariances']
    opacities = gaussians['opacities']
    
    # Validate positive semidefiniteness
    valid_mask = validate_covariances(covariances)

    if settings.bounding_box_max is not None:

            valid_mask = valid_mask.clone()
            valid_mask[largest_indices] = False
            
    xyz = xyz[valid_mask]
    covariances = covariances[valid_mask]
    opacities = opacities[valid_mask]
    
    if len(xyz) == 0:
        raise Exception("No Gaussians remain after culling.")

            opacities = opacities[valid_mask]
            contributions = contributions[valid_mask]

    if contributions is None:

    surface_areas = compute_surface_area(covariances)

    # Normalize magnitudes to sum to num_points

    else:

    all_points = []
    all_colors = []

        mean = xyz[i]
        cov = covariances[i]
        n_samples = int(num_samples_per_gaussian[i].item())
        if n_samples < 1:
            n_samples = 1
            
        # Sample from Multivariate Normal
        samples = torch.distributions.MultivariateNormal(mean, cov).sample((n_samples,))
        
        # Mahalanobis distance filtering
        diff = samples - mean
        # Compute inverse covariance for Mahalanobis distance
        try:
            inv_cov = torch.linalg.inv(cov)
            dist_sq = (diff @ inv_cov * diff).sum(dim=1)
            mask = dist_sq <= (settings.mahalanobis_distance_std ** 2)
            samples = samples[mask]

            pass
            
        all_points.append(samples)

def compute_surface_area(covariances):
    """Compute approximate surface area of ellipsoids defined by covariances."""
    eigvals = torch.linalg.eigvals(covariances).real
    a = torch.sqrt(eigvals[:, 0])
    b = torch.sqrt(eigvals[:, 1])
    c = torch.sqrt(eigvals[:, 2])
    p = 1.6075
    radicand = (torch.pow(a*b, p) + torch.pow(a*c, p) + torch.pow(b*c, p)) / 3.0
    surface_area = 4.0 * torch.pi * torch.pow(radicand, 1.0/p)
    return surface_area

def validate_covariances(covariances, epsilon=1e-6):
    """Check if covariances are positive semidefinite."""
    eigvals = torch.linalg.eigvals(covariances).real
    return (eigvals >= -epsilon).all(dim=1)

## Operating characteristics
*   **Time Complexity:** Dominated by the visibility rendering step if enabled, which is $O(N \cdot C \cdot R)$ where $N$ is the number of Gaussians, $C$ is the number of cameras, and $R$ is the resolution. Sampling is $O(N \cdot K)$ where $K$ is the average samples per Gaussian.
*   **Memory Complexity:** $O(N + P)$ where $P$ is the number of generated points. Storing the full point cloud requires significant memory for large `num_points` (e.g., 10M points).
*   **Performance:** The CUDA renderer is significantly faster than the Python renderer. Color quality settings ('tiny' to 'ultra') directly impact rendering time.
*   **Strengths:** Produces high-quality point clouds that closely mimic the original 3DGS appearance. Flexible culling and sampling strategies allow for noise reduction and density control.
*   **Limitations:** The resulting point cloud is not a true surface representation; it is a volumetric sampling. Mesh generation is an additional step and may not be perfect for complex geometries. Requires camera poses for optimal color weighting.

## Background
The method originates from the need to bridge the gap between specialized 3DGS renderers and general-purpose 3D software that supports standard point clouds or meshes. The primary source is an unofficial implementation by Lewis-Stuart, presented in the context of 3DGS-to-PC conversion tools [S1, unofficial]. It builds on the principles of 3DGS, where the scene is represented as a collection of anisotropic Gaussians [S1, unofficial].
