# Atomized Proliferation

Also called: Atom Gaussian Densification

## Overview
Atomized Proliferation is a densification and refinement strategy for 3D Gaussian Splatting that enhances geometric precision by constraining Gaussians representing fine details into isotropic "Atom Gaussians" and prioritizing their proliferation to align with scene geometry [S1, unofficial]. Unlike standard 3D Gaussian Splatting, which struggles to stabilize densification and often produces noisy meshes or blurry artifacts, this method uses a warm-up phase to aggressively densify initially, followed by a merging phase that stabilizes the Gaussian count and improves surface fidelity [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of 3D Gaussians defined by mean position $\mu$, covariance $\Sigma$, color $c$, and opacity $\alpha$; input Structure-from-Motion (SfM) points; loss gradients $\nabla_p L$ with respect to the Gaussian parameters.
*   **Outputs:** An updated set of Gaussians with refined positions, scales, opacities, and colors.

**Data Structures and Parameters:**
The method operates on the standard 3D Gaussian Splatting representation. Key parameters include:
*   **Atom Scale ($S$):** The maximum allowed minimum covariance norm for atomization. Calculated as the $i$-th percentile of ordered distances from input SfM points, $S = P_i(d)$. Default: $i=1$ (first percentile) [S1, unofficial].
*   **Clone Threshold ($\tau_c$):** Threshold for cloning based on loss gradient. Default: 0.002 [S1, unofficial].
*   **Split Threshold ($\tau_s$):** Base threshold for splitting. Default: 0.002 [S1, unofficial].
*   **Prune Threshold ($\epsilon$):** Opacity threshold for pruning. Default: 0.005 (0.5 for DTU dataset) [S1, unofficial].
*   **Atomized Proliferation Duration ($t_a$):** Iteration limit for atomization. Default: 7000 [S1, unofficial].
*   **Warm-Up Duration ($t_w$):** Iteration limit for the warm-up phase. Default: 7000 [S1, unofficial].
*   **Final Proportion ($p$):** The final proportion of the initial scale $S$ after atomization iterations. Not explicitly defined in sources, but used in the geometric progression formula [S1, unofficial].

**Algorithm Steps:**
1.  **Initialization:** Calculate the Atom Scale $S$ from the input SfM points. Initialize iteration counter $i=0$.
2.  **Iteration Loop:** For each training iteration $i$ from 0 to the total training iterations:
    a.  **Atom Scale Decay:** If $i < t_a$, update the effective atom scale $S_i$ using geometric progression: $S_i = S_{i-1} \cdot r^{i-1}$, where $r = p^{1/t_a}$ [S1, unofficial]. Note: The source formula $S_n = S_{n-1} \cdot r^{n-1}$ implies the scale decreases over time if $p < 1$.
    b.  **Process Each Gaussian:** For each Gaussian $g$ in the set $(\mu, \Sigma, c, \alpha)$:
        i.  **Pruning:** If opacity $\alpha < \epsilon$ OR the covariance $\Sigma$ is "excessively large" (function `IsTooLarge`), remove the Gaussian [S1, unofficial].
        ii. **Cloning:** If the loss gradient magnitude $\|\nabla_p L\| \ge \tau_c$, clone the Gaussian [S1, unofficial].
        iii. **Splitting:** If $\|\nabla_p L\| \ge \min(\frac{i}{t_w}\tau_s, \tau_s)$ AND the maximum norm of the covariance $\|\Sigma\|_{\max} > S$, split the Gaussian [S1, unofficial]. The threshold $\min(\frac{i}{t_w}\tau_s, \tau_s)$ implements a linear warm-up, starting from 0 and increasing to $\tau_s$ over $t_w$ iterations.
        iv. **Atomization:** If the minimum norm of the covariance $\|\Sigma\|_{\min} \le S$ AND $i < t_a$, atomize the Gaussian [S1, unofficial].
3.  **Atomization Details:**
    *   A Gaussian is designated as an "Atom Gaussian" if $\|\Sigma\|_{\min} \le S$.
    *   Atom Gaussians are isotropic spheroids with uniform size $s = S^{1/3}$ (assuming $S$ represents a volume-like metric or the source implies $s^3 \approx S$) [S1, unofficial].
    *   Once atomized, the scale is fixed and no longer optimized via backpropagation. Instead, it follows the geometric progression defined by $S_i$ [S1, unofficial].
4.  **Opacity Resetting:** Increase the frequency of opacity resetting during training to merge Gaussians depicting large, simple surfaces, rather than eliminating noisy ones near the camera [S1, unofficial].

def atomize_gaussian(g, S):
    """
    Designate Gaussian as Atom Gaussian.
    Set scale to isotropic s = S^(1/3).
    Fix scale for backpropagation.
    """
    g.is_atom = True
    g.scale = S ** (1/3)
    g.scale_requires_grad = False # Fix scale
    # Ensure isotropic covariance
    g.Sigma = create_isotropic_covariance(g.scale)

def compute_pairwise_distances(points):
    """
    Compute all pairwise distances between SfM points.
    """
    n = len(points)
    dists = []
    for i in range(n):
        for j in range(i + 1, n):
            dists.append(distance(points[i], points[j]))
    return dists

def percentile(values, p):
    """
    Return the p-th percentile of the sorted values.
    """
    sorted_vals = sorted(values)
    k = (len(sorted_vals) - 1) * (p / 100.0)
    f = int(k)
    c = f + 1
    if c >= len(sorted_vals):
        return sorted_vals[f]
    d0 = sorted_vals[f] * (c - k)
    d1 = sorted_vals[c] * (k - f)
    return d0 + d1

**Edge Cases and Pitfalls:**
*   **Precision:** The geometric progression for scale decay requires careful handling of floating-point precision, especially for large $t_a$.
*   **Boundary Conditions:** The warm-up phase threshold $\min(\frac{i}{t_w}\tau_s, \tau_s)$ must handle $i=0$ correctly (threshold is 0, so splitting is immediate if gradient > 0).
*   **SfM Point Quality:** The Atom Scale $S$ depends on the density and distribution of input SfM points. Sparse SfM points may lead to an overly large $S$, preventing atomization of fine details.
*   **Dataset Specifics:** For object-centered datasets like DTU, the Prune Threshold $\epsilon$ should be increased (e.g., to 0.5) to avoid pruning valid Gaussians [S1, unofficial].

## Subtopics

### Atom Gaussian Primitive
Isotropic spheroids with uniform size, designed to fill geometric gaps more accurately than anisotropic ellipsoids. Chosen when fine geometric detail is critical. [Link to Atom Gaussian Primitive](12924-atomized-proliferation.md#atom-gaussian-primitive)

### Geometry-Guided Optimization
A complementary method that compactly models smooth surfaces while retaining primitives for fine details. Chosen when surface smoothness is a priority. [Link to Geometry-Guided Optimization](12924-atomized-proliferation.md#geometry-guided-optimization)

## Operating characteristics
*   **Time Complexity:** Training time is comparable to or slightly faster than standard 3D Gaussian Splatting. On Mip-NeRF360, AtomGS averaged 0.28 hours vs. 0.40 hours for 3DGS [S1, unofficial].
*   **Memory Complexity:** Model size is reduced. On Mip-NeRF360, AtomGS resulted in 749MB vs. 869MB for 3DGS [S1, unofficial].
*   **Scaling:** The method scales with the number of Gaussians, which is dynamically adjusted. The warm-up strategy leads to a declining and stabilizing trend in Gaussian count, improving efficiency over time [S1, unofficial].
*   **Strengths:** Improved geometric precision, reduced noisy meshes, blurred artifacts, and faster convergence. Stabilizes densification.
*   **Limitations:** Requires input SfM points. Performance may vary with SfM point density.
*   **When to Use:** When high-fidelity geometric reconstruction is required, especially for scenes with intricate details.
*   **When Not to Use:** When SfM points are unavailable or of poor quality. When computational resources are extremely limited and the overhead of densification management is prohibitive.

## Background
Atomized Proliferation was introduced in the paper "AtomGS: Atomizing Gaussian Splatting for High-Fidelity Radiance Field" by Liu, Xu, Hu, Chen, and Feng [S1, unofficial]. It addresses the limitations of standard 3D Gaussian Splatting, which often fails to adhere to underlying geometric structures, leading to noisy meshes and slower convergence. The method was developed to provide a more compact and accurate representation of radiance fields by combining atomization of fine details with geometry-guided optimization for smooth surfaces.
