# SplatQ

Also called: SplatQ: Post-training Gaussian pruning via QUBO

## Overview
SplatQ is a post-training Gaussian pruning framework that partitions 3D Gaussians into size-limited blocks based on spatial and appearance similarity, allocates retention quotas to these blocks to prevent spatial quality imbalance, and jointly selects which Gaussians to retain within each block using a Quadratic Unconstrained Binary Optimization (QUBO) model [S1, unofficial]. It differs from global Top-K methods by solving a combinatorial optimization problem within each block rather than ranking all Gaussians globally by independent scores, and it differs from methods that only consider individual deletion errors by modeling pairwise interactions and joint effects via a quadratic objective [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A pretrained 3D Gaussian Splatting (3DGS) model $\mathcal{G}$ containing $N$ Gaussians, and a target retention count $K$ [S1, unofficial].
*   **Output:** A pruned set of $K$ Gaussians $\mathcal{G}' \subset \mathcal{G}$ [S1, unofficial].

**Data Structures:**
*   **Gaussian Representation:** Each Gaussian $G_i$ is defined by the tuple $(\mu_i, s_i, r_i, c_i, h_i, o_i)$, where $\mu_i$ is the center, $s_i$ is the scale, $r_i$ is the rotation quaternion, $c_i$ is the zeroth-order (DC) spherical harmonic coefficient, $h_i$ is the higher-order spherical harmonic coefficients, and $o_i$ is the opacity [S1, unofficial].
*   **Blocks:** The set of Gaussians is partitioned into blocks $\{C_b\}$. Each block $C_b$ contains at most $M$ members [S1, unofficial].
*   **Response Matrix:** For each block $C_b$, a response matrix $R_b$ is computed. This matrix estimates individual deletion effects and pairwise interactions [S1, unofficial].
*   **Retention Quotas:** Each block $C_b$ is assigned a retention quota $K_b$, such that $\sum_b K_b = K$ [S1, unofficial].

**Parameters:**
*   $N$: Total number of Gaussians in the pretrained model [S1, unofficial].
*   $K$: Exact number of Gaussians to retain after pruning [S1, unofficial].
*   $M$: Maximum size (number of members) of each block $C_b$ [S1, unofficial].
*   $K_b$: Retention quota for block $b$ [S1, unofficial].

**Steps:**

1.  **Partitioning:** Divide the $N$ Gaussians into several size-limited blocks $\{C_b\}$ of at most $M$ members each, based on spatial proximity and appearance similarity [S1, unofficial]. This is typically achieved using a 3D grid and Morton ordering to efficiently group related Gaussians without quadratic pairwise comparisons [S1, unofficial].
2.  **Opacity Response Modeling:** For each block $C_b$, compute the response matrix $R_b$ using sampled pixels from multiple views. This matrix estimates the individual deletion effects and pairwise interactions of the Gaussians within the block [S1, unofficial].
3.  **Budget Allocation:** Assign a retention quota $K_b$ to every block such that $\sum_b K_b = K$. This is done by deriving an initial quota from importance estimates and adjusting the distribution to reduce the risk of concentrating the budget in a few blocks (preventing spatial quality imbalance) [S1, unofficial].
4.  **Quadratic Selection:** For each block $C_b$, formulate a QUBO objective incorporating individual responses, pairwise interactions, and quota penalties. Solve the QUBO using Simulated Annealing (SA) or a Coherent Ising Machine (CIM) to determine which $K_b$ block members to retain [S1, unofficial].
5.  **Fine-tuning:** Fine-tune the attributes of the retained Gaussians without changing their count to recover rendering quality [S1, unofficial].

**Pseudocode:**

```python
def splatq_prune(G, N, K, M, num_views=10):
    """
    Prune a 3D Gaussian Splatting model using SplatQ.
    
    Args:
        G: List of N Gaussian objects, each with attributes (mu, s, r, c, h, o).
        N: Total number of Gaussians.
        K: Target number of Gaussians to retain.
        M: Maximum block size.
        num_views: Number of views to sample for response matrix estimation.
        
    Returns:
        G_pruned: List of K Gaussian objects.
    """
    
    # Stage 1: Partitioning
    # Group Gaussians into blocks based on spatial proximity and appearance similarity.
    # Implementation detail: Use 3D grid and Morton ordering to assign Gaussians to blocks.
    blocks = partition_gaussians(G, M)
    
    # Stage 2: Opacity Response Modeling
    # Compute response matrix Rb for each block.
    response_matrices = {}
    for b, block in enumerate(blocks):
        # Sample pixels from multiple views to estimate deletion effects
        # Rb[i, j] represents the interaction between Gaussian i and Gaussian j in block b
        Rb = compute_response_matrix(block, num_views)
        response_matrices[b] = Rb
        
    # Stage 3: Budget Allocation
    # Assign retention quota Kb to each block such that sum(Kb) = K.
    # Initial quotas based on importance, smoothed to prevent concentration.
    quotas = allocate_budget(blocks, response_matrices, K)
    
    # Stage 4: Quadratic Selection
    # Solve QUBO for each block to select Kb Gaussians.
    selected_gaussians = []
    for b, block in enumerate(blocks):
        Kb = quotas[b]
        Rb = response_matrices[b]
        
        # Formulate QUBO objective:
        # Minimize: sum_i (w_i * x_i) + sum_{i<j} (w_ij * x_i * x_j) + penalty(x)
        # where x_i is binary variable (1 if retained, 0 if deleted)
        # w_i: individual deletion cost/response
        # w_ij: pairwise interaction cost/response
        # penalty: ensures exactly Kb are selected
        
        # Solve QUBO using Simulated Annealing (SA) or Coherent Ising Machine (CIM)
        # Returns binary selection vector x of length len(block)
        selection_vector = solve_qubo(Rb, Kb)
        
        # Select Gaussians based on selection vector
        for i, selected in enumerate(selection_vector):
            if selected:
                selected_gaussians.append(block[i])
                
    # Stage 5: Fine-tuning
    # Fine-tune attributes of retained Gaussians without changing count.
    G_pruned = fine_tune(selected_gaussians, num_views)
    
    return G_pruned

def partition_gaussians(G, M):
    """
    Partition Gaussians into blocks of size at most M based on spatial and appearance similarity.
    Uses 3D grid and Morton ordering.
    """
    # Assign each Gaussian to a 3D grid cell based on mu_i
    grid_cells = assign_to_grid(G)
    
    # Sort cells and Gaussians within cells using Morton order
    sorted_cells = sort_morton(grid_cells)
    
    # Form blocks from sorted Gaussians
    blocks = []
    current_block = []
    for cell in sorted_cells:
        for g in cell.gaussians:
            current_block.append(g)
            if len(current_block) == M:
                blocks.append(current_block)
                current_block = []
    if current_block:
        blocks.append(current_block)
        
    return blocks

def compute_response_matrix(block, num_views):
    """
    Compute response matrix Rb for a block.
    Rb[i, j] estimates the joint effect of deleting Gaussian i and Gaussian j.
    """
    n = len(block)
    Rb = np.zeros((n, n))
    
    # Sample pixels from multiple views
    views = sample_views(num_views)
    
    for v in views:
        # Render image with full block
        img_full = render_block(block, v)
        
        for i in range(n):
            # Render image with Gaussian i removed
            img_minus_i = render_block(block_without_i(block, i), v)
            
            # Compute individual response (deletion error)
            # This can be used to initialize diagonal of Rb
            # Rb[i, i] = error(img_full, img_minus_i)
            
            for j in range(i + 1, n):
                # Render image with both Gaussian i and j removed
                img_minus_ij = render_block(block_without_ij(block, i, j), v)
                
                # Compute pairwise interaction response
                # Rb[i, j] = error(img_full, img_minus_ij) - error(img_full, img_minus_i) - error(img_full, img_minus_j)
                # Or similar quadratic approximation
                Rb[i, j] = compute_interaction_error(img_full, img_minus_i, img_minus_j, img_minus_ij)
                Rb[j, i] = Rb[i, j]
                
    return Rb

def allocate_budget(blocks, response_matrices, K):
    """
    Assign retention quotas Kb to each block such that sum(Kb) = K.
    Uses importance estimates and smooths distribution.
    """
    # Estimate importance for each block (e.g., sum of individual responses)
    importances = [sum(np.diag(Rb)) for Rb in response_matrices]
    
    # Initial quotas proportional to importance
    total_importance = sum(importances)
    quotas = [int(K * imp / total_importance) for imp in importances]
    
    # Adjust to ensure sum(quotas) = K and prevent concentration
    # This step smooths the distribution to avoid concentrating budget in few blocks
    quotas = adjust_quotas(quotas, K)
    
    return quotas

def solve_qubo(Rb, Kb):
    """
    Solve QUBO for a block to select Kb Gaussians.
    Uses Simulated Annealing (SA) or Coherent Ising Machine (CIM).
    """
    n = len(Rb)
    
    # Define QUBO objective
    # Minimize: sum_i (w_i * x_i) + sum_{i<j} (w_ij * x_i * x_j) + lambda * (sum(x_i) - Kb)^2
    # where w_i = Rb[i, i] (individual cost)
    # w_ij = Rb[i, j] (pairwise interaction cost)
    # lambda is a large penalty coefficient
    
    # Initialize random binary vector x
    x = np.random.randint(0, 2, n)
    
    # Ensure initial x has Kb ones (or use penalty to enforce)
    # If using penalty, no need to enforce initially
    
    # Simulated Annealing
    best_x = x
    best_energy = compute_energy(x, Rb, Kb)
    temperature = 1.0
    cooling_rate = 0.99
    
    while temperature > 1e-4:
        # Generate neighbor
        new_x = x.copy()
        # Flip a random bit or swap a 0 and 1 to maintain Kb if not using penalty
        # If using penalty, just flip a random bit
        idx = np.random.randint(n)
        new_x[idx] = 1 - new_x[idx]
        
        new_energy = compute_energy(new_x, Rb, Kb)
        
        # Acceptance probability
        delta_e = new_energy - best_energy
        if delta_e < 0 or np.random.rand() < np.exp(-delta_e / temperature):
            x = new_x
            if new_energy < best_energy:
                best_x = x
                best_energy = new_energy
        
        temperature *= cooling_rate
        
    return best_x

def compute_energy(x, Rb, Kb):
    """
    Compute QUBO energy for binary vector x.
    """
    n = len(x)
    energy = 0.0
    
    # Individual terms
    for i in range(n):
        energy += Rb[i, i] * x[i]
        
    # Pairwise terms
    for i in range(n):
        for j in range(i + 1, n):
            energy += Rb[i, j] * x[i] * x[j]
            
    # Quota penalty
    sum_x = np.sum(x)
    energy += 1000 * (sum_x - Kb)**2  # Large penalty coefficient
    
    return energy

def fine_tune(G_pruned, num_views):
    """
    Fine-tune attributes of retained Gaussians without changing count.
    """
    # Re-train the pruned model using standard 3DGS optimization
    # on sampled views for a few iterations
    G_fine_tuned = optimize_3dgs(G_pruned, num_views, iterations=1000)
    return G_fine_tuned
```

**Edge Cases and Pitfalls:**
*   **Spatial Quality Imbalance:** Global ranking can lead to spatial quality imbalance where the limited budget concentrates in regions with consistently higher scores, leaving other regions with insufficient representational capacity [S1, unofficial]. SplatQ addresses this by partitioning and allocating quotas [S1, unofficial].
*   **Joint Deletion Effects:** Independent scoring fails to capture joint rendering effects because multiple Gaussians may jointly support the same pixel or make overlapping contributions, meaning degradation from removing multiple Gaussians is not strictly additive [S1, unofficial]. SplatQ addresses this by modeling pairwise interactions via a quadratic objective [S1, unofficial].
*   **Computational Cost:** The response matrix computation requires rendering images with subsets of Gaussians removed, which can be computationally expensive for large blocks. The number of views sampled should be balanced between accuracy and cost [S1, unofficial].
*   **QUBO Solving:** Solving QUBO is NP-hard. Simulated Annealing provides a heuristic solution, but the quality depends on parameters like temperature schedule and cooling rate. Coherent Ising Machines (CIM) may offer faster solutions but require specialized hardware [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The partitioning step is approximately linear in $N$ using grid-based methods [S1, unofficial]. The response matrix computation is $O(B \cdot M^2 \cdot V)$, where $B$ is the number of blocks, $M$ is the block size, and $V$ is the number of views [S1, unofficial]. The QUBO solving step is heuristic and depends on the solver (SA or CIM) [S1, unofficial].
*   **Memory Complexity:** The response matrices require $O(B \cdot M^2)$ memory [S1, unofficial].
*   **Strengths:** Ensures balanced reconstruction quality across the scene by controlling regional budget allocation [S1, unofficial]. Captures joint deletion effects through pairwise interactions [S1, unofficial].
*   **Limitations:** Requires additional computation for response matrix estimation and QUBO solving [S1, unofficial]. The quality of the pruning depends on the accuracy of the response matrix estimation [S1, unofficial].
*   **When to Use:** When balanced quality across the entire scene is critical, and the computational cost of response matrix estimation and QUBO solving is acceptable [S1, unofficial].
*   **When Not to Use:** When real-time pruning is required, or when the scene has very few Gaussians (making block partitioning unnecessary) [S1, unofficial].
