# Data Compression and Storage Optimization

Also called: 3DGS Compression, Gaussian Quantization, Compact 3DGS

## Overview
This family of methods addresses the excessive memory footprint and storage requirements of 3D Gaussian Splatting (3DGS), which often exceeds 1GB for large scenes due to the storage of high-precision attributes for every Gaussian [S1, 12927-compact-3d-gaussian-representation-c3dgs.md]. The core problem is the redundancy in geometric and radiometric data across millions of primitives. These methods distinguish themselves from sibling optimization techniques (e.g., [Sorting and Rendering Pipeline Optimization](12180-sorting-and-rendering-pipeline-optimization.md)) by focusing on data representation density rather than rendering throughput, utilizing techniques ranging from character-level encoding to neural field-based color storage and sensitivity-aware vector quantization [S1, 12927-compact-3d-gaussian-representation-c3dgs.md].

## Shared principles
All methods in this family aim to reduce the storage size of the Gaussian representation $\{G_i\}$ while maintaining rendering fidelity. The general approach involves replacing per-Gaussian high-precision storage with compact indices, shared codebooks, or global fields. The common mathematical goal is to minimize the storage size $S$ subject to a rendering error constraint $\mathcal{L} < \epsilon$.

## Subtopics

### [ASCII-Based Data Compression](11820-ascii-based-data-compression.md)
Compresses numerical attributes into ASCII strings using base-95/94 encoding. It focuses on transmission bandwidth reduction through character-level encoding rather than spatial redundancy.

### [Sensitivity-Aware Vector Clustering](12167-sensitivity-aware-vector-clustering.md)
Reduces storage by clustering SH coefficients and shape features into compact codebooks using sensitivity-aware vector quantization. It weights the distance metric with a sensitivity measure derived from the gradient of the rendering error, prioritizing parameters that significantly affect image quality.

### [Compact 3D Gaussian Representation (C3DGS)](12927-compact-3d-gaussian-representation-c3dgs.md)
Decouples storage size from the number of Gaussians by using a grid-based neural field for view-dependent color and a codebook for geometric attributes. It exploits spatial redundancy in color and geometry, eliminating redundant Gaussians via a learnable mask.

## Background
Standard 3DGS stores unique high-precision values for every Gaussian, leading to storage sizes that scale linearly with the number of Gaussians $N$ [S1, 12927-compact-3d-gaussian-representation-c3dgs.md]. Recent developments have introduced compression schemes to mitigate this, including ASCII encoding for transmission [S1, 11820-ascii-based-data-compression.md], sensitivity-aware clustering for quantization [S1, 12167-sensitivity-aware-vector-clustering.md], and hybrid representations using hash grids and codebooks [S1, 12927-compact-3d-gaussian-representation-c3dgs.md].
