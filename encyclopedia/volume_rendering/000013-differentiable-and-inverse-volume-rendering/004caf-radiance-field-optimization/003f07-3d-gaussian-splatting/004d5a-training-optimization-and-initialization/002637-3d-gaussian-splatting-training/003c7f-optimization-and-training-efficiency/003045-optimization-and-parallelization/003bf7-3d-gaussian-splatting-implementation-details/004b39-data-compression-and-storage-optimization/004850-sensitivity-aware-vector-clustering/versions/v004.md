# Sensitivity-Aware Vector Clustering

Also called: Color Compression, Sensitivity-Aware Scene Compression, Sensitivity-aware k-Means

## Overview
Sensitivity-Aware Vector Clustering is a compression scheme for 3D Gaussian Splatting that reduces storage requirements by clustering spherical harmonic (SH) coefficients and Gaussian shape features (scale and rotation) into compact codebooks using sensitivity-aware vector quantization [S1]. It sets itself apart from standard k-Means or post-training quantization by weighting the distance metric during clustering based on a computed sensitivity measure, prioritizing the preservation of parameters that significantly affect image quality [S1]. This method builds on [Data Compression and Storage Optimization](12943-data-compression-and-storage-optimization.md) by providing a specific algorithm for deriving these codebooks.

## How it works
**Inputs and Outputs:**
*   **Input:** A set of optimized 3D Gaussian primitives $G_i$, each defined by position $\mathbf{p}$, opacity $\alpha$, scale $\mathbf{s}$, rotation $\mathbf{q}$, and SH coefficients $\mathbf{c}$. A set of $N$ training images with known camera parameters.
*   **Output:** Two codebooks: $C_{color}$ containing clustered SH coefficient vectors, and $C_{shape}$ containing clustered shape parameters (rotation and scale). Each Gaussian is represented by two indices (one for each codebook) instead of the raw parameters.

**Data Structures:**
*   **Codebook Entry (Color):** A vector of SH coefficients. The dimension $D$ depends on the SH degree $L$ ($D = 3(L+1)^2$).
*   **Codebook Entry (Shape):** A structure containing 4 scalar values for the quaternion (rotation) and 3 scalar values for the scaling vector. The scaling vector is derived from the normalized covariance matrix [S1].
*   **Indices:** 32-bit unsigned integers pointing to entries in $C_{color}$ and $C_{shape}$ [S1].

**Sensitivity Calculation:**
The sensitivity $S(p)$ of a parameter $p$ is calculated to determine its impact on rendering quality. It is defined as the sum of the gradients of the total image energy $E$ with respect to $p$, normalized by the number of pixels [S1]:

$$ S(p) = \frac{\sum_{i=1}^{N} \frac{\partial E_i}{\partial p_i}}{\sum_{i=1}^{N} P_i} $$

Where:
*   $N$ is the number of training images.
*   $E_i$ is the total image energy (sum of RGB components) for image $i$.
*   $P_i$ is the number of pixels in image $i$.
*   $\frac{\partial E_i}{\partial p_i}$ is the gradient of the energy with respect to parameter $p$ for image $i$.

For a vector $\mathbf{x}$ with components $x_d$, the sensitivity $S(\mathbf{x})$ is the maximum sensitivity among its components [S1]:

$$ S(\mathbf{x}) = \max_d S(x_d) $$

This sensitivity is computed via a single backward pass over each training image [S1].

**Clustering Algorithm:**
The clustering is performed separately for color (SH coefficients) and shape (scale/rotation) parameters.

1.  **Initialization:** Initialize codebook centroids $\mathbf{c}_k$ randomly with a uniform distribution within the minimum and maximum values of each parameter [S1].
2.  **Sensitivity Thresholding:** Identify vectors with sensitivity higher than a threshold $\beta_c$ (for SH coefficients) or $\beta_g$ (for shape parameters). These high-sensitivity vectors are excluded from the clustering process and added directly to the codebook to preserve critical details [S1].
3.  **Batched Clustering:** For the remaining vectors, use a batched strategy to compute centroids:
    *   Pick a random subset (batch) of vectors.
    *   Compute pairwise weighted distances between vectors $\mathbf{x}$ and centroids $\mathbf{c}_k$.
    *   Assign each vector to the centroid with the minimum distance.
    *   Update centroids using a moving average with decay factor $\lambda_d$ [S1].

**Weighted Distance and Centroid Update:**
The distance between a vector $\mathbf{x}$ and a centroid $\mathbf{c}_k$ is weighted by the sensitivity of $\mathbf{x}$ [S1]:

$$ D(\mathbf{x}, \mathbf{c}_k) = S(\mathbf{x}) \|\mathbf{x} - \mathbf{c}_k\|_2^2 $$

The centroid $\mathbf{c}_k$ is updated as the weighted average of the vectors assigned to it [S1]:

$$ \mathbf{c}_k = \frac{1}{\sum_{\mathbf{x}_i \in A(k)} S(\mathbf{x}_i)} \sum_{\mathbf{x}_i \in A(k)} S(\mathbf{x}_i) \mathbf{x}_i $$

Where $A(k)$ is the set of vectors assigned to centroid $\mathbf{c}_k$.

**Shape Parameter Handling:**
Gaussian shape is parameterized by a rotation matrix $\mathbf{R}$ and a scaling vector $\mathbf{s}$. The scaling vector is decomposed into a scalar factor $\eta = \|\mathbf{s}\|_2$ and a normalized vector $\hat{\mathbf{s}} = \eta^{-1}\mathbf{s}$. The normalized covariance matrix is $\hat{\mathbf{S}} = \text{diag}(\hat{\mathbf{s}})$ [S1]. Clustering is performed on these normalized representations. Due to floating-point errors, the resulting covariance matrices may have non-unit scaling vectors. To correct this, each codebook vector is re-normalized after each update step by dividing it through the trace of the covariance metric [S1]. After clustering, each codebook entry is decomposed into rotation (quaternion) and scale parameters using eigenvalue decomposition for quantization-aware training [S1].

**Pseudocode:**

```python
import numpy as np

def compute_sensitivity(optimization_state, training_images, param_indices):
    """
    Computes sensitivity S(p) for a set of parameters.
    optimization_state: Contains current Gaussian parameters.
    training_images: List of training images and camera poses.
    param_indices: Indices of parameters to compute sensitivity for.
    Returns: Dictionary mapping param_index to sensitivity value.
    """
    sensitivities = {}
    total_pixels = sum(img.num_pixels for img in training_images)
    
    # Compute gradients for all training images
    # This requires a single backward pass per image or batched backward pass
    gradients = compute_gradients(optimization_state, training_images)
    
    for idx in param_indices:
        grad_sum = sum(grads[idx] for grads in gradients)
        sensitivities[idx] = grad_sum / total_pixels
    return sensitivities

def get_vector_sensitivity(vector, component_sensitivities):
    """
    Returns the maximum sensitivity among the components of a vector.
    """
    return max(component_sensitivities[d] for d in range(len(vector)))

def sensitivity_aware_kmeans(vectors, sensitivities, k, batch_size, decay_factor, max_iterations):
    """
    Performs sensitivity-aware k-Means clustering.
    vectors: Array of shape (N, D)
    sensitivities: Array of shape (N,)
    k: Number of centroids
    batch_size: Size of random subsets for update
    decay_factor: Lambda_d for moving average
    max_iterations: Max number of update steps
    Returns: Centroids array of shape (k, D)
    """
    # Initialize centroids randomly within min/max of vectors
    centroids = np.random.uniform(vectors.min(axis=0), vectors.max(axis=0), size=(k, D))
    
    for iteration in range(max_iterations):
        # Pick random subset
        indices = np.random.choice(len(vectors), size=batch_size, replace=False)
        batch_vectors = vectors[indices]
        batch_sensitivities = sensitivities[indices]
        
        # Compute distances
        # D(x, ck) = S(x) * ||x - ck||^2
        # We need to assign each vector in batch to the closest centroid
        distances = np.zeros((batch_size, k))
        for i, x in enumerate(batch_vectors):
            s_x = batch_sensitivities[i]
            diff = x - centroids  # Shape (k, D)
            sq_dist = np.sum(diff**2, axis=1)  # Shape (k,)
            distances[i] = s_x * sq_dist
            
        assignments = np.argmin(distances, axis=1)
        
        # Update centroids using moving average
        new_centroids = np.zeros_like(centroids)
        for j in range(k):
            mask = assignments == j
            if np.sum(mask) > 0:
                assigned_vectors = batch_vectors[mask]
                assigned_sensitivities = batch_sensitivities[mask]
                weighted_sum = np.sum(assigned_vectors * assigned_sensitivities[:, np.newaxis], axis=0)
                weight_total = np.sum(assigned_sensitivities)
                new_centroid = weighted_sum / weight_total
                # Moving average update
                centroids[j] = decay_factor * centroids[j] + (1 - decay_factor) * new_centroid
            else:
                # If no vectors assigned, keep old centroid or reinitialize [G]
                pass
                
    return centroids

def decompose_covariance(covariance_matrix):
    """
    Decomposes a normalized covariance matrix into rotation (quaternion) and scale.
    """
    # Eigenvalue decomposition
    eigenvalues, eigenvectors = np.linalg.eigh(covariance_matrix)
    # Scale is sqrt of eigenvalues (or derived from diagonal)
    scale = np.sqrt(eigenvalues)
    # Rotation is derived from eigenvectors
    rotation = matrix_to_quaternion(eigenvectors)
    return rotation, scale

def cluster_shape_parameters(shape_vectors, shape_sensitivities, k, batch_size, decay_factor, beta_g):
    """
    Clusters shape parameters (scale/rotation) with sensitivity awareness.
    """
    # Separate high sensitivity vectors
    high_sens_mask = shape_sensitivities > beta_g
    high_sens_vectors = shape_vectors[high_sens_mask]
    low_sens_vectors = shape_vectors[~high_sens_mask]
    low_sens_sensitivities = shape_sensitivities[~high_sens_mask]
    
    # Cluster low sensitivity vectors
    centroids = sensitivity_aware_kmeans(low_sens_vectors, low_sens_sensitivities, k, batch_size, decay_factor, max_iterations=800)
    
    # Add high sensitivity vectors to codebook
    final_codebook = np.vstack([centroids, high_sens_vectors])
    
    # Re-normalize and decompose
    decomposed_codebook = []
    for entry in final_codebook:
        # Re-normalize if necessary (trace correction)
        # Decompose into quaternion and scale
        rot, scl = decompose_covariance(entry)
        decomposed_codebook.append((rot, scl))
        
    return decomposed_codebook
```

**Parameters:**
*   $\lambda_d$: Decay factor for the moving average in batched clustering. Typical value: 0.8 [S1].
*   Batch size for color features: $2^{18}$ [S1].
*   Batch size for Gaussian parameters: $2^{20}$ [S1].
*   Codebook size $K$: 4096 [S1].
*   $\beta_c$: Sensitivity threshold for SH coefficients. Gaussians with sensitivity $> \beta_c$ are excluded from clustering. Typical value: $6 \times 10^{-7}$ [S1].
*   $\beta_g$: Sensitivity threshold for shape parameters. Typical value: $3 \times 10^{-6}$ [S1].
*   Optimization steps for quantization-aware fine-tuning: 5000 [S1].

**Edge Cases and Pitfalls:**
*   **Floating Point Errors:** Clustering normalized covariance matrices can lead to non-unit scaling vectors due to floating-point errors. This is handled by re-normalizing each codebook vector after each update step by dividing it through the trace of the covariance metric [S1].
*   **High Sensitivity Vectors:** A small percentage of SH coefficients (< 5%) have high sensitivity. These must be identified and added directly to the codebook to prevent significant rendering errors [S1].

## Operating characteristics
*   **Time Complexity:** The clustering process is iterative. The sensitivity calculation requires a backward pass over training images. The clustering itself uses a batched strategy, making it scalable to large numbers of Gaussians. The number of update steps is typically 800 for Gaussians and 100 for SH coefficients [S1].
*   **Memory Complexity:** The storage is reduced by a factor of up to 31× on real-world scenes [S1]. Each Gaussian stores two 32-bit indices instead of full SH coefficients and shape parameters.
*   **Performance:** The compressed representation can be rendered with hardware rasterization on lightweight GPUs at up to 4× higher framerates than the uncompressed baseline [S1].
*   **Strengths:** Significant compression ratio with minimal visual degradation. Efficient rendering on low-power devices.
*   **Limitations:** Requires an initial optimization step to compute sensitivities. The clustering process adds overhead to the compression pipeline.

## Background
Sensitivity-Aware Vector Clustering was proposed in the paper "Compressed 3D Gaussian Splatting for Accelerated Novel View Synthesis" [S1]. It addresses the high memory consumption of 3D Gaussian Splatting, which limits its use in applications like network streaming and rendering on low-power devices. The method draws inspiration from volumetric radiance field compression and deep network weight quantization [S1]. It was demonstrated on datasets such as Mip-NeRF 360, Tanks&Temples, and Deep Blending [S1].
