# First-order Spherical Harmonics Distillation

Also called: Mobile-GS SH Distillation, SH Knowledge Distillation, SH Order Reduction via Distillation, SH degree reduction, Spherical Harmonics degree reduction

## Overview
First-order Spherical Harmonics Distillation reduces the spherical harmonics (SH) degree of Gaussian elements from third-order to first-order to decrease parameter count and computation cost [S1][S2, unofficial]. It employs a distillation strategy where a pretrained high-degree teacher model guides the optimization of a low-degree student model, minimizing the difference in rendered outputs rather than coefficient values directly [S2, unofficial]. This approach achieves faster rendering speeds and lower storage usage compared to the original third-order SH representation [S2, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A pretrained teacher model with third-order SH coefficients (3 channels $\times$ 16 coefficients per Gaussian) [S2, unofficial].
- **Output:** A student model with first-order SH coefficients (3 channels $\times$ 4 coefficients per Gaussian) [S2, unofficial].

**Data Structures:**
- **Teacher Coefficients:** For each Gaussian, a vector of size $3 \times (3+1)^2 = 48$ floats (R, G, B channels, each with $(L+1)^2$ coefficients for $L=3$) [S2, Parent, unofficial].
- **Student Coefficients:** For each Gaussian, a vector of size $3 \times (1+1)^2 = 12$ floats (R, G, B channels, each with $(L+1)^2$ coefficients for $L=1$) [S2, Parent, unofficial].

**Numbered Steps:**
1. **Initialize Student:** Initialize the student model's first-order SH coefficients. These can be initialized randomly or by projecting the teacher's coefficients, but the distillation process refines them [S2, unofficial].
2. **Render Teacher:** Render the scene using the teacher model to obtain reference pixel colors $\mathbf{C}_p^{tea}$ and depth maps $\mathbf{D}^{tea}$ for a set of pixels $P$ [S2, unofficial].
3. **Render Student:** Render the scene using the student model to obtain predicted pixel colors $\mathbf{C}_p$ and depth maps $\hat{\mathbf{D}}_p$ for the same pixels $P$ [S2, unofficial].
4. **Compute Distillation Loss:** Calculate the color distillation loss $\mathcal{L}_{\text{dstill}}$ [S2, unofficial]:
   $$
   \mathcal{L}_{\text{dstill}} = \frac{1}{|P|} \sum_{p \in P} \|\mathbf{C}_p^{tea} - \mathbf{C}_p\|
   $$
   where $\mathbf{C}_p^{tea}$ is the rendered pixel color from the teacher, $\mathbf{C}_p$ is the rendered pixel color from the student, and $|P|$ is the number of pixels [S2, unofficial].
5. **Compute Depth Distillation Loss:** Calculate the scale-invariant depth distillation loss $\mathcal{L}_{\text{depth}}$ [S2, unofficial]:
   $$
   \mathcal{L}_{\text{depth}}(\mathbf{D}, \mathbf{D}^{tea}) = \frac{1}{|P|} \sum_{p \in P} \left( \log(\hat{\mathbf{D}}_p) - \log(\hat{\mathbf{D}}_p^{tea}) \right)^2 - \frac{1}{|P|^2} \left( \sum_{p \in P} \left( \log(\hat{\mathbf{D}}_p) - \log(\hat{\mathbf{D}}_p^{tea}) \right) \right)^2
   $$
   where $\hat{\mathbf{D}}_p^{tea} = \mathbf{D}^{tea} + \epsilon$ and $\epsilon = 10^{-8}$ for training stability [S2, unofficial].
6. **Optimize:** Update the student model's first-order SH coefficients by minimizing the combined loss $\mathcal{L}_{\text{dstill}} + \lambda \mathcal{L}_{\text{depth}}$, where $\lambda$ is a weighting factor (not specified in sources) [S2, unofficial].

**Pseudocode:**
```python
def first_order_sh_distillation(teacher_model, student_model, pixels, epsilon=1e-8):
    """
    Distill third-order SH to first-order SH using teacher-student framework.
    
    Args:
        teacher_model: Pretrained 3DGS model with 3rd-order SH.
        student_model: 3DGS model with 1st-order SH to be optimized.
        pixels: Set of pixels P for which to compute loss.
        epsilon: Stability constant for depth log.
        
    Returns:
        Optimized student_model with 1st-order SH coefficients.
    """
    # Step 2: Render Teacher
    teacher_colors = teacher_model.render(pixels)  # C_p^tea
    teacher_depths = teacher_model.render_depth(pixels)  # D^tea
    
    # Step 3: Render Student (initially)
    student_colors = student_model.render(pixels)  # C_p
    student_depths = student_model.render_depth(pixels)  # D_p
    
    # Step 4: Compute Color Distillation Loss
    # L_dstill = (1/|P|) * sum(||C_p^tea - C_p||)
    color_diff = teacher_colors - student_colors
    l_dstill = mean(norm(color_diff, axis=-1))
    
    # Step 5: Compute Depth Distillation Loss
    # D_p^tea = D^tea + epsilon
    teacher_depths_stable = teacher_depths + epsilon
    
    # log_diff = log(D_p) - log(D_p^tea)
    log_diff = log(student_depths) - log(teacher_depths_stable)
    
    # L_depth = mean(log_diff^2) - mean(log_diff)^2
    l_depth = mean(log_diff ** 2) - mean(log_diff) ** 2
    
    # Step 6: Optimize
    # Total loss = L_dstill + lambda * L_depth
    # Update student_model parameters using gradient descent on total loss
    total_loss = l_dstill + l_depth  # lambda assumed to be 1 or tuned
    student_model.optimize(total_loss)
    
    return student_model
```

**Parameters:**
- **Target SH Degree:** 1 [S1][S2, unofficial].
- **Epsilon ($\epsilon$):** $10^{-8}$ for depth stability [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Depth Reliability:** The teacher model's depth may not always be reliable, so strict L1/L2 depth losses are avoided in favor of scale-invariant loss [S2, unofficial].
- **Precision:** Using log depth requires ensuring depth values are positive; adding $\epsilon$ handles near-zero depths [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Rendering complexity is reduced due to fewer SH coefficients. Third-order SH requires 16 coefficients per channel, while first-order requires 4. This reduces the computation per Gaussian by 75% for the SH projection part [S1][S2, unofficial].
- **Memory Complexity:** Parameter count is reduced by 61% when going from degree 3 to 1 (from 48 to 12 coefficients per Gaussian per color channel) [S1].
- **Measured Performance:**
  - Degree 3→2: -21 elements, -36% parameters, -35% computation, -0.17 dB PSNR [S1].
  - Degree 2→1: -15 elements, -25% parameters, -17% computation, -0.31 dB PSNR [S1].
  - Degree 3→1: -36 elements, -61% parameters, -52% computation, -0.48 dB PSNR [S1].
- **Strengths:** Significant reduction in storage and computation, enabling real-time rendering on mobile devices [S2, unofficial].
- **Limitations:** Quality degradation (PSNR drop) increases with greater degree reduction [S1].
- **When to Use:** When deploying 3DGS on resource-constrained devices like mobile phones [S2, unofficial].
- **When Not to Use:** When high-fidelity view-dependent effects are critical and computational resources are abundant [S2, unofficial].

## Background
First-order Spherical Harmonics Distillation was introduced in the Mobile-GS paper as part of a suite of compression techniques for 3D Gaussian Splatting [S2, unofficial]. It addresses the high parameter count and storage burden of the original third-order SH representation in 3DGS [S2, unofficial]. The method builds on the concept of knowledge distillation, where a smaller student model learns from a larger teacher model [S2, unofficial].
