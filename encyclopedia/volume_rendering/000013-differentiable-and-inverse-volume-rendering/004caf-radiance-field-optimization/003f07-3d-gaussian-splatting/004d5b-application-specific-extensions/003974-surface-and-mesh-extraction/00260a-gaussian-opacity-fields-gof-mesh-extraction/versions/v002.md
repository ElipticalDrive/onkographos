# Gaussian Opacity Fields (GOF) Mesh Extraction

Also called: GOF-style 3-D mesh extraction, mesh extraction from standard 3-D Gaussian Splatting

## Overview
A method to extract a 3-D triangulated mesh from a trained Gaussian model (3-D Gaussian Splatting) without retraining, by building a volumetric density field and extracting an isosurface [S1, unofficial]. It builds on [Surface and Mesh Extraction](8498-surface-and-mesh-extraction.md) by treating the Gaussian opacity field as a continuous volumetric density function, distinct from sibling methods that rely on distance fields or direct point-cloud reconstruction.

## How it works
**Inputs:** A trained 3D Gaussian Splatting model $\mathcal{G} = \{G_i\}_{i=1}^M$ where each Gaussian $G_i$ has position $\mathbf{p}_i$, covariance $\mathbf{\Sigma}_i$, and opacity $\alpha_i$ [S1, unofficial].
**Outputs:** A PLY mesh file containing vertices, faces, and per-vertex colors [S1, unofficial].

**Data Structures:**
1.  **Voxel Grid:** A 3D array of size $R \times R \times R$ (where $R$ is resolution) storing density values.
2.  **KD-Tree:** Built on the positions $\{\mathbf{p}_i\}$ of all Gaussians for nearest-neighbor color lookup.

**Parameters:**
*   `resolution` ($R$): Voxel grid resolution. Default: 256 [S1, unofficial].
*   `density_threshold` ($T$): Marching cubes isosurface level. Default: 1.0 [S1, unofficial].

**Steps:**
1.  **Initialize Density Field:** Create a zero-filled 3D array $D$ of size $R^3$. Determine the bounding box of the scene or the union of all Gaussian extents.
2.  **Splat Gaussians to Voxel Grid:** For each Gaussian $G_i$:
    *   Compute the bounding box of the Gaussian truncated at $3\sigma$ along each axis using the eigenvalues of $\mathbf{\Sigma}_i$.
    *   Iterate over all voxels $(x, y, z)$ within this bounding box.
    *   For each voxel center $\mathbf{v}$, compute the density contribution using the Gaussian opacity field formula [S1, unofficial]:
        $$ f_i(\mathbf{v}) = \alpha_i \cdot \exp\left(-\frac{1}{2} (\mathbf{v} - \mathbf{p}_i)^\top \mathbf{\Sigma}_i^{-1} (\mathbf{v} - \mathbf{p}_i)\right) $$
    *   Accumulate the contribution into the voxel grid: $D[x][y][z] \leftarrow D[x][y][z] + f_i(\mathbf{v})$.
3.  **Extract Isosurface:** Apply the marching cubes algorithm (specifically `skimage.measure.marching_cubes`) to the density field $D$ using the threshold $T$ [S1, unofficial]. This yields a set of vertices $\mathcal{V}$ and faces $\mathcal{F}$.
4.  **Assign Colors:** For each vertex $\mathbf{v} \in \mathcal{V}$:
    *   Find the nearest Gaussian $G_k$ to $\mathbf{v}$ using the KD-tree.
    *   Extract the DC (zeroth-order) spherical harmonic coefficient $\mathbf{c}_{k,0}$ from $G_k$.
    *   Assign $\mathbf{c}_{k,0}$ as the color of vertex $\mathbf{v}$ [S1, unofficial].
5.  **Save Mesh:** Write the mesh to a PLY file named `<model_path>/mesh_iter{N}_res{R}_thr{T}.ply` [S1, unofficial].

**Pseudocode:**
```python
import numpy as np
from scipy.spatial import KDTree
from skimage import measure

def extract_mesh(gaussian_model, resolution=256, density_threshold=1.0):
    """
    Extract mesh from Gaussian Opacity Fields.
    
    Args:
        gaussian_model: Object containing attributes:
            - positions: (M, 3) array of Gaussian means
            - covariances: (M, 3, 3) array of covariance matrices
            - opacities: (M,) array of alpha values
            - sh_coeffs: (M, 3) array of DC spherical harmonic coefficients (RGB)
        resolution: int, voxel grid size
        density_threshold: float, marching cubes level
        
    Returns:
        vertices: (V, 3) array
        faces: (F, 3) array
        colors: (V, 3) array
    """
    M = gaussian_model.positions.shape[0]
    positions = gaussian_model.positions
    covariances = gaussian_model.covariances
    opacities = gaussian_model.opacities
    sh_coeffs = gaussian_model.sh_coeffs
    
    # Initialize density field
    density_field = np.zeros((resolution, resolution, resolution), dtype=np.float32)
    
    # Precompute inverse covariances
    inv_covs = np.linalg.inv(covariances)
    
    # Determine bounds for voxel grid
    # [G] Assuming the scene is normalized to [-1, 1] or similar. 
    # If not, bounds should be derived from positions.
    min_bound = np.min(positions, axis=0) - 1.0
    max_bound = np.max(positions, axis=0) + 1.0
    
    # Create voxel centers
    voxel_centers = np.linspace(min_bound, max_bound, resolution)
    X, Y, Z = np.meshgrid(voxel_centers, voxel_centers, voxel_centers, indexing='ij')
    voxel_coords = np.stack([X, Y, Z], axis=-1).reshape(-1, 3)
    
    # Splat each Gaussian to the voxel grid
    for i in range(M):
        mu = positions[i]
        cov_inv = inv_covs[i]
        alpha = opacities[i]
        
        # Compute Mahalanobis distance squared for all voxels
        # diff: (N, 3)
        diff = voxel_coords - mu
        # dist_sq: (N,)
        dist_sq = np.sum(diff @ cov_inv * diff, axis=1)
        
        # Density contribution
        density = alpha * np.exp(-0.5 * dist_sq)
        
        # Reshape and add to 3D grid
        density_field += density.reshape(resolution, resolution, resolution)
        
    # Extract isosurface
    # [G] marching_cubes returns (verts, faces, normals, values)
    verts, faces, _, _ = measure.marching_cubes(density_field, level=density_threshold)
    
    # Map voxel indices back to world coordinates for vertices
    # The vertices returned by marching_cubes are in voxel space [0, resolution]
    # We need to scale them to world space
    voxel_to_world = (max_bound - min_bound) / (resolution - 1)
    verts_world = verts * voxel_to_world + min_bound
    
    # Build KD-tree for color lookup
    tree = KDTree(positions)
    
    # Find nearest Gaussian for each vertex
    # [G] query returns (distances, indices)
    _, indices = tree.query(verts_world)
    
    # Assign colors from DC SH coefficients
    colors = sh_coeffs[indices]
    
    return verts_world, faces, colors
```

**Edge Cases and Pitfalls:**
*   **Precision:** Floating-point accumulation in the density field may cause overflow if many Gaussians overlap significantly. Use `float32` or `float64` appropriately.
*   **Boundaries:** The bounding box must encompass all Gaussians contributing to the surface. Truncating at $3\sigma$ is standard but may miss thin structures if $\sigma$ is small relative to voxel size [S1, unofficial].
*   **Degenerate Input:** If the density field is entirely below the threshold, no mesh is generated.

## Subtopics

### Mesh-3DGS Hybrid Representation
A representation where one flat Gaussian is allocated to each triangle of an extracted mesh, combining mesh geometry with Gaussian splatting [S2, unofficial]. It differs from standard GOF extraction by adding a second training stage to refine the hybrid representation. Choose this when view-dependent appearance and physically-based rendering (PBR) are required alongside the mesh geometry [S2, unofficial].
*   **Stage 1:** Train vanilla 3DGS (40k steps: 30k vanilla + 10k SDF regularization). Apply opacity culling. Apply SDF-based regularization to flatten Gaussians. Apply masked opacity regularization. Extract level set from trained 3DGS. Apply Poisson reconstruction to obtain surface mesh. Apply mesh cleanup (duplicate removal) [S2, unofficial].
*   **Stage 2:** Allocate one flat Gaussian to each triangle of the extracted mesh. Train non-PBR parameters (mesh geometry/location/shape, opacity, radiance SH coefficients, scale) [S2, unofficial].
*   **Parameters:** Stage 1: 40k steps. Stage 2: 10k steps [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(M \cdot R^3)$ for density field construction, where $M$ is the number of Gaussians and $R$ is the resolution. Marching cubes is $O(R^3)$. Color lookup is $O(V \log M)$ where $V$ is the number of vertices.
*   **Memory Complexity:** $O(R^3)$ for the density field. $O(M)$ for the KD-tree.
*   **Performance:** Default resolution 256 balances quality and speed. Higher resolutions improve mesh detail but increase memory and time linearly [S1, unofficial].
*   **Strengths:** Simple, no retraining required, produces watertight meshes.
*   **Limitations:** Mesh quality depends on Gaussian distribution; may produce noisy surfaces if Gaussians are sparse or misaligned. Color assignment is based on nearest neighbor, which may cause artifacts at boundaries [S1, unofficial].

## Background
Originated from the Gaussian Opacity Fields (GOF) method by Yu et al., SIGGRAPH Asia 2024 [S1, unofficial]. It was implemented as an extension to the EOGS (Efficient Opacity Gaussian Splatting) framework to provide state-of-the-art mesh extraction from standard 3DGS without retraining [S1, unofficial].
