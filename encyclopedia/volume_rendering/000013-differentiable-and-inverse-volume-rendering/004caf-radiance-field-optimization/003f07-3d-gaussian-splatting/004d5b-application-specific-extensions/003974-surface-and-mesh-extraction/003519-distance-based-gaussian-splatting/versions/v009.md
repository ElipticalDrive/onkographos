# Distance-based Gaussian Splatting

Also called: Mesh-based Gaussian Splatting, Tightly/Loosely-bound Gaussian Splatting

## Overview
Distance-based Gaussian Splatting (also known as MeshGS) connects a large-scale triangular mesh with 3D Gaussian splats by classifying splats as tightly-bound or loosely-bound based on their distance to the mesh surface, and masking out splats occluded by the mesh [S1]. It solves the problem of redundant Gaussian splats in distorted regions of a mesh and the lack of explicit surface topology in standard 3D Gaussian Splatting (3DGS) [S1]. Unlike [Gaussian Opacity Fields (GOF) Mesh Extraction](3692-gaussian-opacity-fields-gof-mesh-extraction.md) which accumulates density into a voxel grid, this method explicitly aligns Gaussian primitives to a pre-existing mesh geometry, using distance thresholds to separate surface-aligned splats from those capturing view-dependent appearance or mesh artifacts [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A triangular mesh $M$ with $K$ triangles (where $K$ is typically $10^3$ to $10^6$) [S1]. A set of training views with camera poses and images.
*   **Output:** A set of 3D Gaussian splats $\mathcal{G}$, classified into tightly-bound ($G_t$) and loosely-bound ($G_l$) subsets, optimized to render the scene while adhering to the mesh geometry [S1].

**Data Structures:**
Each Gaussian primitive $g_i$ is defined by:
*   Center position $p_i \in \mathbb{R}^3$ [S1].
*   3D covariance matrix $\Sigma_i \in \mathbb{R}^{3 \times 3}$ in world space [S1].
*   Opacity $o_i \in [0, 1]$ [S1].
*   Spherical Harmonics (SH) coefficients $\mathbf{c}_i$ for view-dependent color $c_i$ [S1].
*   Classification flag: Tightly-bound ($G_t$) or Loosely-bound ($G_l$) [S1].

The covariance is parameterized using a scaling vector $S_i \in \mathbb{R}^3$ and a rotation matrix $R_i \in \mathbb{R}^{3 \times 3}$ (encoded by a quaternion $q \in \mathbb{R}^4$) such that $\Sigma_i = R_i S_i S_i^T R_i^T$ [S1].

**Numbered Steps:**

1.  **Initialization:** Initialize a 3D Gaussian splat at the center $m_j$ of each triangle $f_j$ of the mesh $M$ [S1].
2.  **Occlusion Masking (Pre-training/Render):** For a given viewpoint $P_i$, render a depth map $D_i$ from the mesh. Assume the mesh surface is entirely opaque. Mask out Gaussian splats that are occluded by the mesh surface in the rendered depth map [S1]. Specifically, if the depth $d_k$ of a Gaussian splat is greater than the depth $d_j$ of the mesh surface at that pixel, the splat is considered behind the surface and excluded from rendering [S1].
3.  **Visibility Assessment:** Assess the visibility of all Gaussian splats across all training views. Identify splats located behind the mesh surface that are never observed by any training view [S1].
4.  **Pruning:** Remove all redundant Gaussian splats situated behind the mesh surface at specific training iterations. The sources specify pruning occurs every 500 training iterations [S1].
5.  **Distance Calculation:** Calculate the Euclidean distance $d_i$ between each Gaussian splat’s center $p_i$ and the corresponding closest mesh face $f_j$ [S1].
6.  **Classification:** Classify Gaussian splats based on the distance $d_i$ and a threshold $d_{th}$:
    *   Tightly-bound splats ($G_t$): $d_i < d_{th}$ [S1].
    *   Loosely-bound splats ($G_l$): $d_i > d_{th}$ [S1].
    The threshold $d_{th}$ is set to 0.01 [S1].
7.  **Alignment (Tightly-bound):** Flatten $G_t$ and align these splats with the mesh surface. This involves applying a normal consistency loss to refine $G_t$ to align with the corresponding mesh surface normals [S1].
8.  **Rendering:** Render the image using alpha blending. The 3D Gaussians are projected into camera space ($p_{ci} = R_{cw} p_i + t_{cw}$, $\Sigma_{ic} = R_{cw} \Sigma_i R_{cw}^T$) and then into ray space using an affine transformation $J_i \in \mathbb{R}^{2 \times 3}$ defined by $p_{ci}$ [S1]. The 2D covariance in ray space is $\Sigma'_i = J_i \Sigma_{ic} J_i^T$ [S1]. The 2D Gaussian is $g_i(x) = e^{-\frac{1}{2}(x-p'_i)^T {\Sigma'_i}^{-1}(x-p'_i)}$ [S1]. The final color is $c = \sum_{i=1}^{n} c_i \alpha_i \prod_{j=1}^{i-1}(1-\alpha_j)$, where $\alpha_i = o_i g_i(x)$ [S1].

**Pseudocode:**

```python
def distance_based_gaussian_splatting(mesh, training_views, num_iterations=30000):
    """
    Implements Distance-based Gaussian Splatting (MeshGS).
    
    Args:
        mesh: Triangular mesh M with faces f_j and centers m_j.
        training_views: List of camera poses and images.
        num_iterations: Total training iterations.
        
    Returns:
        Optimized set of Gaussian splats G.
    """
    # Parameters
    d_th = 0.01  # Distance threshold for tight/loose binding [S1]
    prune_interval = 500  # Pruning interval [S1]
    lambda_img = 0.001  # Image loss weight [S1]
    lambda_nc = 0.1  # Normal consistency loss weight [S1]
    
    # Initialization: One Gaussian per triangle center [S1]
    G = []
    for triangle in mesh.faces:
        center = triangle.center
        # Initialize Gaussian properties (position, covariance, opacity, SH)
        # Covariance parameterization: Sigma = R S S^T R^T [S1]
        gaussian = Gaussian(center=center)
        G.append(gaussian)
        
    for iteration in range(1, num_iterations + 1):
        # Step 2 & 3: Occlusion Masking and Visibility Assessment
        # Render depth from mesh for each view [S1]
        # Mask out splats occluded by mesh surface (assuming opaque mesh) [S1]
        # Identify splats behind mesh not observed by any view [S1]
        
        # Step 4: Pruning redundant splats behind mesh [S1]
        if iteration % prune_interval == 0:
            G = prune_behind_mesh_splats(G, mesh, training_views)
            
        # Step 5 & 6: Distance Calculation and Classification
        for gaussian in G:
            # Calculate distance from center p_i to closest mesh face f_j [S1]
            dist = calculate_distance_to_mesh(gaussian.center, mesh)
            if dist < d_th:
                gaussian.type = "tightly_bound"
            else:
                gaussian.type = "loosely_bound"
                
        # Step 8: Rendering and Loss Computation
        total_loss = 0
        for view in training_views:
            # Project 3D Gaussians to 2D [S1]
            # Camera space: p_ci = R_cw p_i + t_cw, Sigma_ic = R_cw Sigma_i R_cw^T [S1]
            # Ray space: Sigma'_i = J_i Sigma_ic J_i^T [S1]
            # 2D Gaussian: g_i(x) = exp(-0.5 (x-p'_i)^T Sigma'_i^-1 (x-p'_i)) [S1]
            
            rendered_image = render_gaussians(G, view.camera)
            
            # Image Loss: L_img = (1-lambda_img)*L1 + lambda_img*SSIM [S1]
            img_loss = compute_image_loss(rendered_image, view.gt_image, lambda_img)
            total_loss += img_loss
            
            # Normal Consistency Loss for Tightly-bound splats [S1]
            # Estimate normals n_i for Gaussian splats (min scale axis) [S1]
            # Refine G_t to align with mesh surface normals [S1]
            nc_loss = compute_normal_consistency_loss(G, mesh, lambda_nc)
            total_loss += nc_loss
            
        # Optimization Step (e.g., SGD/Adam)
        optimize(G, total_loss)
        
    return G

def prune_behind_mesh_splats(G, mesh, views):
    """
    Removes Gaussian splats located behind the mesh surface that are 
    never observed by any training view [S1].
    """
    visible_splats = set()
    for view in views:
        # Render depth from mesh [S1]
        mesh_depth_map = render_mesh_depth(mesh, view.camera)
        
        for gaussian in G:
            # Check if gaussian is occluded by mesh in this view [S1]
            # If depth of gaussian > depth of mesh, it is occluded [S1]
            if not is_occluded_by_mesh(gaussian, mesh_depth_map, view.camera):
                visible_splats.add(gaussian)
                
    # Keep only visible splats
    return [g for g in G if g in visible_splats]
```

**Edge Cases and Pitfalls:**
*   **Mesh Artifacts:** Strictly binding all splats to the mesh surface can suffer rendering performance when addressing severe mesh artifacts. The loosely-bound splats ($G_l$) are used to capture these inaccuracies and view-dependent appearance [S1].
*   **Redundancy:** Allocating redundant Gaussian splats to distorted regions of a mesh (e.g., high triangle count) leads to rapid GPU memory usage increase [S1]. Pruning is essential to mitigate this [S1].
*   **Depth Offset:** When applying distance-based Gaussian splatting, 0.01 is added to the depth $D_i$ to handle precision or occlusion boundary issues [S1].

## Operating characteristics
*   **Time Complexity:** Rendering is $O(N)$ per pixel where $N$ is the number of visible Gaussians, similar to standard 3DGS [S1]. Training involves additional overhead for mesh distance calculations and visibility assessments [S1].
*   **Memory Complexity:** Memory usage is proportional to the number of Gaussians. By initializing one Gaussian per triangle and pruning redundant ones, memory usage is controlled relative to the mesh complexity $K$ [S1]. However, large meshes (e.g., 44 million triangles) can still require significant memory if not pruned effectively [S1].
*   **Performance:** The method is designed for high-quality rendering of large-scale scenes with lightweight meshes (e.g., $10^3$ to $10^6$ triangles) [S1]. It balances geometric fidelity (via tightly-bound splats) and appearance detail (via loosely-bound splats) [S1].
*   **Strengths:** Explicitly connects mesh geometry with Gaussian splats, reducing redundancy and improving rendering quality in distorted regions [S1].
*   **Limitations:** Relies on the quality of the input mesh. Severe mesh artifacts may require loose binding, potentially compromising geometric accuracy [S1].
*   **When to use:** When a high-quality, lightweight mesh is available and the goal is to render the scene with high fidelity while maintaining a connection to the explicit geometry [S1].
*   **When not to use:** When no mesh is available, or when the mesh quality is too poor to serve as a reliable geometric prior [S1].

## Background
Distance-based Gaussian Splatting, as presented in MeshGS, was introduced by Jaehoon et al. in 2024 [S1]. It builds upon the original 3D Gaussian Splatting (3DGS) method [S1]. The method addresses the limitations of previous approaches like LTM (Lightweight Triangular Mesh) and SuGaR, which either lack detailed geometry or require a significant number of vertices/triangles to faithfully represent complex scenes [S1]. The approach is particularly relevant for large-scale scene reconstruction where mesh quality and rendering efficiency are critical [S1].
