# Radiative Gaussian Splatting

Also called: Radiative Gaussians

## Overview
Radiative Gaussian Splatting is a scene representation method that uses a set of learnable 3D Gaussian kernels to model isotropic density fields for tomographic reconstruction [S1]. It replaces the view-dependent color and opacity of standard 3D Gaussian Splatting (3DGS) with a central density parameter, making it suitable for X-ray imaging where attenuation depends only on isotropic density [S1]. Unlike standard 3DGS, which is designed for RGB rendering, this method enables the retrieval of a 3D density volume and supports both 2D image rendering and 3D volume reconstruction [S1].

## How it works
**Inputs:**
*   A set of $N$ X-ray projections $\{I_i\}_{i=1}^N$ captured from different angles [S1].
*   Initial sparse 3D points obtained via Structure-from-Motion (SfM) [S1].

**Outputs:**
*   A rendered RGB image $I_{rgb}$ (for visualization/loss calculation) [S1].
*   A final 3D density volume $\sigma(\mathbf{x})$ [S1].

**Data Structures:**
The scene is represented by a set of $M$ 3D Gaussian kernels $\mathcal{G}_3 = \{G_{3i}\}_{i=1}^M$ [S1]. Each kernel $G_{3i}$ is defined by the following learnable parameters:
*   $\rho_i \in \mathbb{R}$: Central density [S1].
*   $\mathbf{p}_i \in \mathbb{R}^3$: Position [S1].
*   $\mathbf{R}_i \in \mathbb{R}^{3 \times 3}$: Rotation matrix (orthonormal) [S1].
*   $\mathbf{S}_i \in \mathbb{R}^{3 \times 3}$: Scale matrix (diagonal) [S1].
*   $\mathbf{c}_i \in \mathbb{R}^3$: Color (retained for RGB rendering, though not used for density) [S1].
*   $\alpha_i \in \mathbb{R}$: Opacity (retained for RGB rendering, though not used for density) [S1].

The covariance matrix $\mathbf{\Sigma}_i$ is computed as:
$$ \mathbf{\Sigma}_i = \mathbf{R}_i \mathbf{S}_i \mathbf{S}_i^\top \mathbf{R}_i^\top $$
[S1]

**Algorithm Steps:**

1.  **Initialization:** Initialize the $M$ 3D Gaussians using the sparse points from SfM [S1].
2.  **Transformation:** Transform each 3D Gaussian into ray space. This aligns the viewing rays with the coordinate axis to enhance computational efficiency [S1]. Let the transformed parameters be denoted with a hat (e.g., $\hat{\mathbf{p}}_i, \hat{\mathbf{\Sigma}}_i$) [S1].
3.  **Projection:** Project the 3D Gaussians onto the 2D image plane to obtain 2D Gaussians $G_{2i}$ [S1].
    *   The projected 2D covariance $\hat{\mathbf{\Sigma}}_i$ is derived from the transformed 3D covariance [S1].
    *   The projected 2D Gaussian retains the same opacity $\alpha_i$ and color $\mathbf{c}_i$ as the 3D counterpart [S1].
    *   The position and covariance omit the third row and column corresponding to the depth axis [S1].
4.  **Rendering (RGB):** Render an RGB image $I_{rgb}$ by compositing the 2D Gaussians using alpha-blending [S1]:
    $$ I_{rgb} = \mathcal{C}(G_2) $$
    where $\mathcal{C}$ is the composition module [S1].
5.  **Optimization:** Optimize the kernel parameters ($\rho_i, \mathbf{p}_i, \mathbf{R}_i, \mathbf{S}_i$) using photometric losses (L1, DSSIM) between the rendered image and the ground truth, and Total Variation (TV) regularization on the density volume [S1].
    *   The adaptive control strategy dynamically densifies Gaussians during training to improve scene representation [S1].
6.  **Volume Retrieval:** Retrieve the final 3D density volume $\sigma(\mathbf{x})$ using a differentiable voxelizer [S1]. The density at any point $\mathbf{x}$ is the sum of contributions from all kernels:
    $$ \sigma(\mathbf{x}) = \sum_{i=1}^M G_{3i}(\mathbf{x} | \rho_i, \mathbf{p}_i, \mathbf{\Sigma}_i) $$
    [S1]

**Formulas:**

The 3D Gaussian kernel function is defined as [S1]:
$$ G_{3i}(\mathbf{x} | \rho_i, \mathbf{p}_i, \mathbf{\Sigma}_i) = \rho_i \cdot \exp\left(-\frac{1}{2} (\mathbf{x} - \mathbf{p}_i)^\top \mathbf{\Sigma}_i^{-1} (\mathbf{x} - \mathbf{p}_i)\right) $$
where $\rho_i$ is the central density, $\mathbf{p}_i$ is the position, and $\mathbf{\Sigma}_i$ is the covariance matrix [S1].

The normalized density $\hat{\rho}_i$ used in the projection step is calculated as [S1]:
$$ \hat{\rho}_i = \rho_i \frac{\sqrt{2\pi |\hat{\mathbf{\Sigma}}_i|}}{|\hat{\mathbf{\Sigma}}_i|} $$
where $\hat{\rho}_i$ is the normalized density, $\rho_i$ is the central density, and $\hat{\mathbf{\Sigma}}_i$ is the projected 2D covariance [S1].

**Parameters:**
*   $N$: Number of different angles from which X-ray projections are captured [S1].
*   $M$: Number of 3D Gaussian kernels in the set $\mathcal{G}_3$ [S1].
*   $\rho_i$: Learnable parameter representing the central density of the $i$-th Gaussian kernel [S1].
*   $\mathbf{p}_i$: Learnable parameter representing the position of the $i$-th Gaussian kernel [S1].
*   $\mathbf{\Sigma}_i$: Learnable parameter representing the covariance matrix of the $i$-th Gaussian kernel [S1].
*   $\mathbf{R}_i$: Rotation matrix used to decompose the covariance matrix $\mathbf{\Sigma}_i$ [S1].
*   $\mathbf{S}_i$: Scale matrix used to decompose the covariance matrix $\mathbf{\Sigma}_i$ [S1].

**Edge Cases and Pitfalls:**
*   Real-world X-ray projections contain minor anisotropic physical effects such as Compton scattering. These are not explicitly modeled but are treated as noise during reconstruction [S1].
*   Standard 3DGS opacity is empirically designed for RGB rendering, leading to challenges when extracting 3D models such as meshes from Gaussians. Radiative Gaussians address this by using a density-based formulation [S1].

## Subtopics

### Radiative Gaussian Point Cloud Model
A variant that defines the set of radiative Gaussian point clouds $\mathcal{G}_x$ for X-ray novel view synthesis [S2]. It is defined by position, covariance, opacity, and a radiative feature vector $\mathbf{f}_i \in \mathbb{R}^{N_f}$ [S2]. The formulation is $\mathcal{G}_x = \{G(\boldsymbol{\mu}_i, \boldsymbol{\Sigma}_i, \alpha_i, \mathbf{f}_i) \mid i = 1, \dots, N_p\}$ [S2]. This approach excludes view direction dependence, matching the isotropic nature of X-ray imaging, and avoids complex spherical harmonic computations, making it faster than original 3DGS [S2].

### X-Gaussian
A sibling method that uses simplified isotropic Gaussians [S1]. In contrast, Radiative Gaussian Splatting employs a general Gaussian distribution with anisotropic covariance, offering more flexibility and precision in modeling complex structures [S1].

## Operating characteristics
*   **Time Complexity:** The method leverages the differentiable rasterization of 3DGS, which is efficient for rendering. The use of a general Gaussian distribution (anisotropic covariance) is more computationally intensive than simplified isotropic Gaussians but provides higher precision [S1]. The X-Gaussian variant is noted to be faster than original 3DGS due to the exclusion of view direction and spherical harmonics [S2].
*   **Memory Complexity:** Depends on the number of Gaussians $M$. Each Gaussian stores position, rotation, scale, density, color, and opacity [S1].
*   **Strengths:** Enables tomographic reconstruction from X-ray projections; allows retrieval of 3D density volumes; more flexible than isotropic Gaussian variants [S1].
*   **Limitations:** Does not explicitly model physical effects like Compton scattering [S1]; relies on adaptive densification which may require careful tuning [S1].
*   **When to use:** When the goal is tomographic reconstruction or X-ray novel view synthesis from sparse projections [S1, S2].
*   **When not to use:** When view-dependent effects are significant and cannot be ignored, or when explicit modeling of scattering physics is required [S1].

## Background
Radiative Gaussian Splatting was introduced to address the limitations of standard 3DGS in the context of X-ray imaging. Standard 3DGS uses view-dependent color and opacity, which are not suitable for X-ray attenuation that depends only on isotropic density [S1]. The method was developed to enable both 2D image rendering and 3D volume reconstruction using a unified Gaussian representation [S1]. It builds on the 3DGS framework [23] but modifies the kernel formulation and optimization strategy for tomographic applications [S1].
