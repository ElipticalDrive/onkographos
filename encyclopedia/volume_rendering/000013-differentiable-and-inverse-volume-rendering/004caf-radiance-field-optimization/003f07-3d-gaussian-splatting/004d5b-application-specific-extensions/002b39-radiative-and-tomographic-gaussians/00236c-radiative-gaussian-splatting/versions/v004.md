# Radiative Gaussian Splatting

Also called: Radiative Gaussians

## Overview
Radiative Gaussian Splatting adapts the 3D Gaussian Splatting (3DGS) framework to model isotropic density fields for tomographic reconstruction, replacing the view-dependent color and opacity attributes of standard 3DGS with a learnable central density parameter [S1]. It solves the problem of reconstructing a 3D density volume $\sigma(\mathbf{x})$ from a set of 2D X-ray projections $\{I_i\}_{i=1}^N$ captured at different angles, enabling both differentiable rendering of synthetic projections and direct extraction of a discrete density volume [S1]. Unlike standard 3DGS, which optimizes for RGB appearance, this method optimizes for physical consistency with X-ray attenuation, treating anisotropic effects like Compton scattering as noise rather than modeling them explicitly [S1].

## How it works
**Inputs:**
*   A set of $N$ X-ray projection images $\{I_i\}_{i=1}^N$, typically logarithmic projections where pixel values represent density integrals along ray paths [S1].
*   Camera poses (extrinsic and intrinsic matrices) corresponding to the $N$ projection angles [S1].
*   Initial sparse point cloud from Structure-from-Motion (SfM) [S1].

**Outputs:**
*   A set of $M$ learnable 3D Gaussian kernels $\mathcal{G}_3 = \{G_{3i}\}_{i=1}^M$ [S1].
*   A reconstructed 3D density volume $\sigma(\mathbf{x})$ [S1].

**Data Structures:**
Each Gaussian kernel $G_{3i}$ is defined by the following learnable parameters:
*   $\mathbf{p}_i \in \mathbb{R}^3$: Position (mean) of the Gaussian [S1].
*   $\rho_i \in \mathbb{R}$: Central density scalar [S1].
*   $\mathbf{R}_i \in \mathbb{R}^{3 \times 3}$: Rotation matrix [S1].
*   $\mathbf{S}_i \in \mathbb{R}^{3 \times 3}$: Scale matrix [S1].
*   The covariance matrix is decomposed as $\mathbf{\Sigma}_i = \mathbf{R}_i \mathbf{S}_i \mathbf{S}_i^\top \mathbf{R}_i^\top$ [S1].

**Rendering Pipeline:**
The rendering process transforms 3D Gaussians into a 2D representation suitable for alpha-compositing, similar to the geometric projection in standard 3DGS [S1].

1.  **Transformation:** Transform 3D Gaussians into ray space. This aligns viewing rays with a coordinate axis (typically the Z-axis) to enhance computational efficiency [S1].
2.  **Projection:** Project the 3D Gaussians onto the image plane to obtain 2D Gaussians $G_{2i}$. The projected 2D covariance $\mathbf{\hat{\Sigma}}_i$ is computed using the Jacobian $J$ of the affine approximation of the projection and the rotation part $W$ of the extrinsic matrix:
    $$ \mathbf{\hat{\Sigma}}_i = J W \mathbf{\Sigma}_i W^T J^T $$
    The projected 2D Gaussian retains the central density $\rho_i$ but omits the third row and column of the position and covariance matrices relative to the ray space [S1].
3.  **Normalization:** Compute the normalized density $\hat{\rho}_i$ for the 2D Gaussian:
    $$ \hat{\rho}_i = \rho_i \frac{\sqrt{2\pi |\mathbf{\hat{\Sigma}}_i|}}{|\mathbf{\hat{\Sigma}}_i|} $$
    *Note: The source formula for $\hat{\rho}_i$ contains a dimensional inconsistency in the denominator ($|\mathbf{\hat{\Sigma}}_i|$ vs $\sqrt{|\mathbf{\hat{\Sigma}}_i|}$). Standard 2D Gaussian normalization involves $\sqrt{|\mathbf{\hat{\Sigma}}_i|}$. The source text explicitly writes $\rho_i * (2\pi|\mathbf{\hat{\Sigma}}_i|)^{1/2} / |\mathbf{\hat{\Sigma}}_i|$ [S1]. This implementation detail is preserved as written in the source, though it may require verification against standard Gaussian definitions.* [S1].
4.  **Composition:** Render the synthetic X-ray projection $I_{rgb}$ (or density projection) by compositing the 2D Gaussians using alpha-blending [S1].

**Optimization:**
The kernel parameters are optimized using photometric losses and regularization:
1.  **Loss Functions:** Minimize the difference between rendered projections and real X-ray projections using L1 loss and DSSIM (Deep Structure Similarity) [S1].
2.  **Regularization:** Apply Total Variation (TV) regularization on the density volume to enforce smoothness and structural integrity [S1].
3.  **Adaptive Control:** Use an adaptive control strategy to dynamically densify Gaussians during training, improving scene representation where needed [S1].

**Volume Retrieval:**
After optimization, the final 3D density volume is retrieved using a differentiable voxelizer, which aggregates the contributions of the 3D Gaussians into a discrete grid [S1].

## Subtopics

### Radiative Gaussian Point Cloud Representation
A variant used for X-ray novel view synthesis [S2]. It defines the set of radiative Gaussian point clouds $\mathcal{G}_x$ using position $\boldsymbol{\mu}_i$, covariance $\boldsymbol{\Sigma}_i$, opacity $\alpha_i$, and a radiative feature vector $\mathbf{f}_i \in \mathbb{R}^{N_f}$ [S2]. Unlike the density-only model in [S1], this representation includes a feature vector and opacity, potentially allowing for view-independent color or material properties encoded in $\mathbf{f}_i$, while still excluding view direction dependence to match the isotropic nature of X-ray imaging [S2]. The forward and backward processes are faster than original 3DGS as it avoids complex spherical harmonic computations [S2].

## Operating characteristics
*   **Time Complexity:** Rendering is $O(M)$ per pixel, where $M$ is the number of Gaussians, similar to standard 3DGS. Optimization involves densification steps which increase $M$ over time.
*   **Memory Complexity:** Stores $M$ Gaussians, each with position (3), density (1), rotation (9), and scale (9) parameters, totaling roughly 22 floats per Gaussian.
*   **Performance:** The method is designed for tomographic reconstruction. It is faster than concurrent work using simplified isotropic Gaussians due to the use of general anisotropic covariance [S1]. The radiative Gaussian point cloud variant is faster than original 3DGS by avoiding spherical harmonics [S2].
*   **Strengths:** Enables differentiable tomographic reconstruction; allows extraction of 3D density volumes; handles anisotropic structures better than isotropic variants [S1].
*   **Limitations:** Does not explicitly model physical effects like Compton scattering, treating them as noise [S1]; standard 3DGS opacity is not suitable for mesh extraction, though radiative Gaussians address this by using density [S1].
*   **When to use:** When the goal is tomographic reconstruction from X-ray projections or novel view synthesis of X-ray data [S1, S2].
*   **When not to use:** When view-dependent appearance (e.g., specular highlights) is required for visible light rendering [S1].

## Background
Radiative Gaussian Splatting was introduced to bridge the gap between differentiable rendering and tomographic reconstruction [S1]. Standard 3DGS uses view-dependent color and opacity, which are not physically meaningful for X-ray attenuation that depends on isotropic density [S1]. The method was developed to allow the use of efficient Gaussian splatting rasterization for X-ray data, enabling both 2D image rendering and 3D volume reconstruction [S1]. It builds on the 3DGS framework [23] but modifies the attribute representation and loss functions [S1].
