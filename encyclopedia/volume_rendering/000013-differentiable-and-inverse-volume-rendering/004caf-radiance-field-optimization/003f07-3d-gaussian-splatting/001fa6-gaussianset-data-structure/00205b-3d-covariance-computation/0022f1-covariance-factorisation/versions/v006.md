# Covariance Factorisation

Also called: Covariance Decomposition, RQ Decomposition for Covariance, Rotation and Scale Parameterization

## Overview
Covariance Factorisation is a parameterization technique for 3D Gaussian Splatting that decomposes the covariance matrix $\boldsymbol{\Sigma}$ into a rotation component and a scale component, ensuring the matrix remains positive semi-definite (PSD) during unconstrained gradient descent [S1, unofficial][S2, S5]. It solves the problem of numerical instability in inverse volume rendering, where direct optimization of the symmetric covariance matrix can yield non-PSD results, violating physical interpretation [S5]. It sets itself apart from sibling methods like [Pre-computed Covariance and Color Buffer Generation](2817-pre-computed-covariance-and-color-buffer-generation.md) by enabling end-to-end differentiable optimization of geometry rather than relying on pre-computed static structures.

## How it works
**Inputs and Outputs:**
- **Input:** Unconstrained learnable parameters representing rotation (typically a quaternion $\mathbf{q}$ or rotation matrix $\mathbf{R}$) and scale (a vector $\mathbf{s}$ or diagonal matrix $\mathbf{S}$).
- **Output:** A valid, positive semi-definite 3D covariance matrix $\boldsymbol{\Sigma}$.

**Data Structures:**
The method relies on two primary learnable vectors/matrices per Gaussian primitive:
1.  **Rotation:** A unit quaternion $\mathbf{q} \in \mathbb{R}^4$ (normalized to unit length) or a $3 \times 3$ rotation matrix $\mathbf{R} \in \mathbb{R}^{3 \times 3}$ [S5].
2.  **Scale:** A 3D vector $\mathbf{s} \in \mathbb{R}^3$ with positive entries, or a diagonal matrix $\mathbf{S} = \text{diag}(\mathbf{s})$ [S2, S5].

**Formulas:**
The covariance matrix is reconstructed as [S2, S5]:
$$ \boldsymbol{\Sigma} = \mathbf{R} \mathbf{S} \mathbf{S}^T \mathbf{R}^T $$
Since $\mathbf{S}$ is diagonal, $\mathbf{S} \mathbf{S}^T = \mathbf{S}^2 = \text{diag}(s_1^2, s_2^2, s_3^2)$. Thus:
$$ \boldsymbol{\Sigma} = \mathbf{R} \begin{bmatrix} s_1^2 & 0 & 0 \\ 0 & s_2^2 & 0 \\ 0 & 0 & s_3^2 \end{bmatrix} \mathbf{R}^T $$

**Steps:**
1.  **Initialize:** Initialize rotation parameters (e.g., identity quaternion) and scale parameters (e.g., small positive values derived from SfM point cloud spacing) [S5].
2.  **Optimize:** During training, optimize $\mathbf{q}$ and $\mathbf{s}$ directly via back-propagation. Do not optimize $\boldsymbol{\Sigma}$ directly [S5].
3.  **Reconstruct:** For each rendering or gradient computation step, reconstruct $\boldsymbol{\Sigma}$ using the formula above [S2, S5].
4.  **Gradient Derivation:** To avoid the computational cost of automatic differentiation through the complex graph $\mathbf{q}, \mathbf{s} \rightarrow \boldsymbol{\Sigma} \rightarrow \boldsymbol{\Sigma}' \rightarrow \alpha$, derive gradients for $\mathbf{q}$ and $\mathbf{s}$ analytically or via custom autograd functions [S5].

**Pitfalls:**
-   **Non-PSD Matrices:** Directly optimizing $\boldsymbol{\Sigma}$ can result in non-PSD matrices, which are physically invalid for Gaussian distributions [S5]. Factorisation guarantees PSD by construction because $\mathbf{S}\mathbf{S}^T$ is PSD and congruence transformation $\mathbf{R}(\cdot)\mathbf{R}^T$ preserves eigenvalues [S1, unofficial][S5].
-   **Quaternion Normalization:** The quaternion $\mathbf{q}$ must be normalized to unit length after every update to ensure $\mathbf{R}$ is a valid rotation matrix [S5].
-   **Scale Positivity:** Scale values $s_i$ must remain positive. In practice, this is often enforced by optimizing $\log(s_i)$ or using a softplus activation [G].

**Pseudocode:**
```python
import torch

def quaternion_to_rotation_matrix(q):
    """Convert a unit quaternion [w, x, y, z] to a 3x3 rotation matrix."""
    # q is shape (N, 4)
    w, x, y, z = q[:, 0], q[:, 1], q[:, 2], q[:, 3]
    
    # Precompute products
    xx, yy, zz = x*x, y*y, z*z
    xy, xz, yz = x*y, x*z, y*z
    wx, wy, wz = w*x, w*y, w*z
    
    # Construct rotation matrix
    R = torch.stack([
        1 - 2*(yy + zz), 2*(xy - wz),     2*(xz + wy),
        2*(xy + wz),     1 - 2*(xx + zz), 2*(yz - wx),
        2*(xz - wy),     2*(yz + wx),     1 - 2*(xx + yy)
    ], dim=-1).reshape(-1, 3, 3)
    return R

def compute_covariance(q, s):
    """
    Compute covariance matrix from quaternion q and scale vector s.
    q: (N, 4) unit quaternion
    s: (N, 3) positive scale values
    Returns: (N, 3, 3) covariance matrix Sigma
    """
    # Normalize quaternion to ensure valid rotation
    q = q / torch.norm(q, dim=1, keepdim=True)
    
    # Get rotation matrix R
    R = quaternion_to_rotation_matrix(q)
    
    # Create scaling matrix S = diag(s)
    # s is (N, 3), we need S such that S @ S^T = diag(s^2)
    s_sq = s * s  # (N, 3)
    
    # Construct Sigma = R @ S @ S^T @ R^T
    # Since S is diagonal, S @ S^T is just diag(s^2)
    # We can compute this as R @ diag(s^2) @ R^T
    
    # Efficiently compute R @ diag(s^2)
    # Scale columns of R by s
    R_scaled = R * s_sq.unsqueeze(1)  # (N, 3, 3)
    
    # Sigma = R_scaled @ R^T
    Sigma = torch.bmm(R_scaled, R.transpose(1, 2))
    
    return Sigma
```

## Subtopics

### [Cholesky Parameterisation for Gaussian Splats](3120-cholesky-parameterisation-for-gaussian-splats.md)
Cholesky Parameterisation represents the covariance matrix using the Cholesky decomposition, guaranteeing positive-definiteness by construction. It parameterizes the covariance using $D(D+1)/2$ elements per splat (6 for 3D) and applies a softplus activation with a minimum standard deviation floor $\sigma_{min} = 1/\sqrt{12}$ voxels to the diagonal, while bounding amplitudes with a configurable maximum $a_{max}$. Choose this when strict positive-definiteness is required without the overhead of quaternion normalization, or when the scene benefits from lower-dimensional parameterization.

### Gamma-Decomposed Covariance Update
A numerical stability technique for computing the new covariance matrix after recycling, replacing the unsupported $\beta()$ function with $\Gamma()$ and $\ln(\Gamma())$ to prevent overflow [S3]. Use this in implementations involving Taylor expansions of density updates where exponential terms might exceed floating-point limits.

### Covariance Matrix Normalization
A technique to transform a covariance matrix $\Sigma$ into a normalized form $\hat{\Sigma}$ by dividing it by its trace, separating the scaling vector $\mathbf{s}$ from the rotation matrix $\mathbf{R}$ [S4]. The formula is $\hat{\Sigma} = \frac{\Sigma}{\text{Tr}(\Sigma)} = \mathbf{R} \frac{\mathbf{S}^2}{\|\mathbf{s}\|_2^2} \mathbf{R}^T = \mathbf{R} \hat{\mathbf{S}}^2 \mathbf{R}^T$, where $\|\mathbf{s}\|_2^2 = \text{Tr}(\Sigma)$ [S4]. This is useful for clustering or compression tasks where relative shape matters more than absolute size.

### Quaternion-Scale Covariance Parameterization
This is the standard parameterization used in 3D Gaussian Splatting, optimizing a quaternion $\mathbf{q}$ and a 3D scale vector $\mathbf{s}$ directly via back-propagation [S5]. It avoids the computational cost of automatic differentiation through the complex graph $\mathbf{q}, \mathbf{s} \rightarrow \boldsymbol{\Sigma} \rightarrow \boldsymbol{\Sigma}' \rightarrow \alpha$ by deriving gradients for $\mathbf{q}$ and $\mathbf{s}$ directly [S5]. Choose this for standard 3DGS rendering pipelines.

## Operating characteristics
-   **Time Complexity:** $O(1)$ per Gaussian for reconstruction, as it involves a fixed-size $3 \times 3$ matrix multiplication. The dominant cost is the quaternion-to-matrix conversion and the subsequent EWA projection, which is also constant per primitive.
-   **Memory Complexity:** $O(1)$ per Gaussian. Stores 4 floats for the quaternion and 3 floats for the scale, totaling 7 floats per primitive, compared to 6 floats for a symmetric matrix if PSD constraints were handled differently (though factorisation adds the overhead of normalization).
-   **Strengths:** Guarantees positive semi-definiteness, enabling stable unconstrained optimization. Physically interpretable parameters (rotation and scale).
-   **Limitations:** Requires careful handling of quaternion normalization. The mapping from $\mathbf{q}, \mathbf{s}$ to $\boldsymbol{\Sigma}$ is non-linear, which can complicate gradient analysis if not implemented with custom derivatives [S5].
-   **When to use:** Standard 3D Gaussian Splatting training and rendering.
-   **When not to use:** If memory is extremely constrained and a lower-dimensional parameterization (like Cholesky) is preferred, or if the scene does not require anisotropic Gaussians.

## Background
Covariance Factorisation was introduced as a core component of 3D Gaussian Splatting (3DGS) by Kerbl et al. in 2023 [S1, unofficial]. It addresses the instability of optimizing symmetric covariance matrices directly by decomposing them into rotation and scale components [S1, unofficial][S5]. The method has since become a standard technique in differentiable volume rendering and inverse graphics, influencing variants like Cholesky parameterization and quaternion-scale optimizations [S1, unofficial][S5].
