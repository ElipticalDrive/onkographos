# Gabor Fields
## Overview
Gabor Fields are a continuous volumetric representation that decomposes a signal into a low-pass Gaussian base and a residual of anisotropic Gabor kernels, enabling orientation-selective level-of-detail and accelerated rendering via control variates [S1]. Unlike standard Gaussian-based representations, Gabor Fields achieve approximately 2 dB higher PSNR at equal primitive counts and render up to 1.4× faster at equal variance by concentrating spectral energy in specific frequency bands and orientations [S1].
## How it works
**Inputs and Outputs:**
*   **Input:** A target signal or volume to be represented [S1].
*   **Output:** A set of Gabor primitives $\{g_i\}$, each defined by a Gaussian envelope and a cosine modulation, plus a low-pass Gaussian base [S1].

**Data Structures:**
Each Gabor primitive $i$ is defined by the following parameters [G]:
*   **Position:** $\mathbf{c}_i \in \mathbb{R}^3$ (center) [G].
*   **Covariance:** $\mathbf{\Sigma}_i \in \mathbb{R}^{3 \times 3}$ (symmetric positive-definite matrix defining the Gaussian envelope's shape and orientation) [G].
*   **Frequency Vector:** $\boldsymbol{\omega}_i \in \mathbb{R}^3$ (direction and magnitude of the cosine modulation) [G].
*   **Amplitude/Opacity:** $\alpha_i \in \mathbb{R}$ (scalar weight) [G].
*   **Color/Value:** $\mathbf{c}_i^{val} \in \mathbb{R}^3$ (RGB or scalar value) [G].
*   **Sizes and bit packing:** Not given in the sources.

The decomposition consists of two sets [S1]:
1.  **Gaussian Base:** A high-density set of primitives where $\boldsymbol{\omega}_i = \mathbf{0}$ [S1].
2.  **Gabor Residuals:** A set of primitives where $\boldsymbol{\omega}_i \neq \mathbf{0}$ [S1].

**Mathematical Definition:**
The value $V(\mathbf{x})$ of the Gabor Field at point $\mathbf{x}$ is the sum of the Gaussian base $G(\mathbf{x})$ and the Gabor residuals $R(\mathbf{x})$ [S1]:
$$ V(\mathbf{x}) = G(\mathbf{x}) + R(\mathbf{x}) = \sum_{i \in \text{Base}} \alpha_i e^{-\frac{1}{2}(\mathbf{x}-\mathbf{c}_i)^T \mathbf{\Sigma}_i^{-1} (\mathbf{x}-\mathbf{c}_i)} + \sum_{j \in \text{Residuals}} \alpha_j e^{-\frac{1}{2}(\mathbf{x}-\mathbf{c}_j)^T \mathbf{\Sigma}_j^{-1} (\mathbf{x}-\mathbf{c}_j)} \cos(\boldsymbol{\omega}_j \cdot (\mathbf{x}-\mathbf{c}_j)) $$
In the Fourier domain, each Gabor kernel consists of two symmetric lobes at $\pm \boldsymbol{\omega}_j$, concentrating the spectrum in a specific frequency band and orientation, unlike a plain Gaussian which spills across all frequencies [S1].

**Rendering Algorithm (Control Variate Path Tracing):**
The rendering leverages the Gaussian base as a control variate to reduce variance and accelerate intersection tests [S1].

1.  **Preprocessing:**
    *   Compute the power spectrum for each Gabor kernel analytically [S1].
    *   Group residuals by frequency band and orientation [G].
    *   Split frequency bands into oriented, steerable sub-bands to enable ray-space masking [S1].

2.  **Ray Tracing Loop:**
    For each pixel, cast a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ [G].
    
    a. **Integrate Gaussian Base (Control Variate):**
    Always trace and analytically integrate the contribution of the Gaussian base primitives along the ray [S1]. This accounts for the majority of the density and low-frequency structure [S1].
    
    b. **Stochastic Selection of Residuals:**
    For each sample point along the ray, stochastically select which Gabor residuals to include in the estimate [S1].
    *   **Masking:** Before intersection, mask kernels that cannot contribute to the ray [S1]. This is done by checking if the ray direction aligns with the kernel's wave direction $\boldsymbol{\omega}_j$ (where contributions collapse due to cancellation) or if the kernel's frequency is above the current LOD cutoff [S1].
    *   **Probability:** Select residuals based on a power-law probability over frequency [S1]. A parameter $\beta$ trades high-frequency error for speed [S1].
    
    c. **Closed-Form Integration:**
    For each selected Gabor residual, integrate its contribution in closed form along the ray segment [S1].
    
    d. **Estimator:**
    The final pixel value is the sum of the deterministic Gaussian base integration and the stochastic sum of selected Gabor residuals [S1].

**Pseudocode:**
```python
def render_gabor_field(ray_o, ray_d, lod_cutoff, beta):
    # 1. Analytically integrate Gaussian base (control variate)
    base_color = integrate_gaussian_base(ray_o, ray_d)
    
    # 2. Stochastically select Gabor residuals
    residual_sum = 0.0
    for sample in ray_samples:
        for kernel in gabor_residuals:
            # Masking: skip kernels that cannot contribute
            if is_masked(kernel, ray_d, lod_cutoff):
                continue
            # Power-law probability selection
            if random() < power_law_probability(kernel.frequency, beta):
                # Closed-form integration along ray segment
                residual_sum += integrate_gabor_kernel(kernel, ray_o, ray_d, sample)
    
    # 3. Combine deterministic base and stochastic residuals
    return base_color + residual_sum

def is_masked(kernel, ray_d, lod_cutoff):
    # Ray alignment: contributions collapse when ray aligns with wave direction
    if abs(dot(normalize(ray_d), normalize(kernel.omega))) > 0.95:
        return True
    # LOD cutoff: mask kernels above frequency threshold
    if kernel.frequency > lod_cutoff:
        return True
    return False

def power_law_probability(freq, beta):
    return (1.0 / (1.0 + freq)) ** beta

def integrate_gaussian_base(ray_o, ray_d):
    # Standard volumetric integration of Gaussian base
    return sum(kernel.alpha * kernel.color * gaussian_ray_intersection(kernel, ray_o, ray_d) for kernel in gaussian_base)

def integrate_gabor_kernel(kernel, ray_o, ray_d, sample):
    # Standard closed-form integration of Gabor kernel along ray
    return kernel.alpha * kernel.color * gabor_ray_intersection(kernel, ray_o, ray_d, sample)
```

**Parameters:**
*   **$\beta$:** A parameter for the power-law probability selection of Gabor residuals. Higher $\beta$ prioritizes lower frequencies, trading high-frequency accuracy for speed [S1].

**Edge Cases and Pitfalls:**
*   **Ray Alignment:** When a ray aligns with a Gabor kernel's wave direction $\boldsymbol{\omega}_j$, the positive and negative lobes cancel, causing the contribution to collapse [S1]. The algorithm must handle this via orientation-selective masking to avoid unnecessary intersection tests [S1].
*   **LOD Cutoff:** As the frequency cutoff shrinks for LOD, kernels are masked before tracing [S1]. This must be done continuously to avoid popping artifacts [S1].

## Operating characteristics
*   **Time Complexity:** Rendering is accelerated by reducing the number of primitive intersections per ray [S1]. The Gaussian base (~2% of total primitives) is always traced, while Gabor residuals are stochastically sampled [S1].
*   **Memory Complexity:** Maintains two orders of magnitude compression over voxel grids [S1]. No extra storage for mipmaps or pyramids is required due to continuous LOD [S1].
*   **Performance:**
    *   In the Disney Cloud scene, unbiased reference rendering took 977 s [S1]. Control Variate PLA (Power-Law Accumulating) reduced this to 623 s [S1]. Zero NEE (Next-Event Estimation) further reduced it to 522 s, achieving nearly 2× the speed of the Control Variate PLA baseline with close to the same appearance [S1].
    *   Gabor Fields achieve ~2 dB higher PSNR at equal primitive count compared to Gaussian-based representations [S1].
    *   Gabor Fields render up to ~1.4× faster at equal variance compared to Gaussian-based representations [S1].
*   **Strengths:** Continuous LOD without re-fitting or extra storage; orientation-selective masking; efficient control variate acceleration; high PSNR [S1].
*   **Limitations:** Stochastic nature introduces variance (mitigated by control variates); requires careful tuning of $\beta$ for speed/accuracy trade-off [S1].

## Background
Gabor Fields were introduced by Jorge Condor, Nicolai Hermann, Mehmet Ata Yurtsever, and Piotr Didyk in "Gabor Fields: Orientation-Selective Level-of-Detail for Volume Rendering," published in ACM Transactions on Graphics (SIGGRAPH 2026) [S1]. The method builds on Gaussian-based representations by introducing anisotropic Gabor kernels to capture directional high-frequency details, enabling new forms of acceleration and LOD control [S1].
