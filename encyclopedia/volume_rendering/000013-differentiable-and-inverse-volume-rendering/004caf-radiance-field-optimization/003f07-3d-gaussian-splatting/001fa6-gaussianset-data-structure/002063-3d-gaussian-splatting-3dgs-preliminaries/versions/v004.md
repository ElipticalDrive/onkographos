# 3D Gaussian Splatting (3DGS) Preliminaries

Also called: 3D Gaussian Splatting (3D-GS), 3D Gaussian Splatting (3DGS) Representation, 3D-GS, Standard 3DGS representation, Vanilla 3D Gaussian Splatting

## Overview
3D Gaussian Splatting (3DGS) is a scene representation method that replaces implicit neural fields with an explicit set of anisotropic 3D Gaussian primitives, enabling real-time rendering via GPU rasterization without ray marching [S1, S2][S5, S7, unofficial][S9]. It solves the trade-off between the high visual quality of neural radiance fields (NeRFs) and the speed of explicit geometry by representing the scene as millions of splats (ellipsoids) that are projected and alpha-composited [S5, S6, unofficial][S8]. Unlike NeRFs, which require per-pixel network queries and volume integration, 3DGS uses a differentiable sort-and-blend rasterizer, allowing for end-to-end optimization of geometric and photometric attributes [S9][S12, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:** A sparse point cloud (typically from Structure-from-Motion, e.g., COLMAP) providing initial positions, and a set of $N$ training images with known camera poses $P$ [S12, unofficial].
*   **Outputs:** A rendered image $\hat{I}$ for a novel view, and a set of optimized 3D Gaussian parameters $\{\mu_k, q_k, s_k, \alpha_k, \text{SH}_k\}_{k=1}^K$ [S1][S12, unofficial].

**Data Structures**
Each Gaussian primitive $k$ stores the following parameters, which are optimized via gradient descent:
1.  **Mean Position:** $\boldsymbol{\mu}_k \in \mathbb{R}^3$ [S2][S9][S15, unofficial].
2.  **Rotation:** A unit quaternion $\mathbf{q}_k \in \mathbb{R}^4$ ($\|\mathbf{q}_k\|=1$) [S9][S14, S16, unofficial].
3.  **Scale:** A vector $\mathbf{s}_k \in \mathbb{R}^3$ representing the scaling factors along the principal axes. These are stored in logarithmic space ($\log \mathbf{s}_k$) to ensure positivity during optimization [S9][S14, unofficial].
4.  **Opacity:** A scalar raw logit $\alpha_k \in \mathbb{R}$. The effective opacity is obtained via a Sigmoid activation: $\hat{\alpha}_k = \sigma(\alpha_k)$ [S12, unofficial].
5.  **Color:** Spherical Harmonics (SH) coefficients $\mathbf{c}_k \in \mathbb{R}^{3 \times (\ell+1)^2}$, where $\ell$ is the degree. Vanilla 3DGS uses degree $\ell=3$, resulting in 16 coefficients per channel (48 floats total) [S12, unofficial].

The covariance matrix $\boldsymbol{\Sigma}_k \in \mathbb{R}^{3 \times 3}$ is derived from rotation and scale:
$$ \boldsymbol{\Sigma}_k = \mathbf{R}_k \mathbf{S}_k \mathbf{S}_k^\top \mathbf{R}_k^\top $$
where $\mathbf{R}_k$ is the rotation matrix constructed from $\mathbf{q}_k$, and $\mathbf{S}_k = \text{diag}(\mathbf{s}_k)$ [S7, unofficial][S9][S16, unofficial].

**Rendering Pipeline**
1.  **Culling:** Gaussians outside the view frustum or behind the camera are discarded [S12, unofficial].
2.  **Projection:** Each 3D Gaussian is projected to the 2D image plane [S2]. The 2D mean $\boldsymbol{\mu}'_k$ is computed via the projection matrix [S2]. The 2D covariance $\boldsymbol{\Sigma}'_k$ is approximated using the Jacobian of the projective transformation $J$ and the world-to-camera matrix $W$:
    $$ \boldsymbol{\Sigma}'_k = J W \boldsymbol{\Sigma}_k W^\top J^\top $$
    [S2][S9][S16, unofficial].
3.  **Bounding Box:** A 2D axis-aligned bounding box (AABB) is computed for each Gaussian based on $\boldsymbol{\Sigma}'_k$ (typically expanding the ellipse to cover $3\sigma$) [S7, S12, unofficial].
4.  **Tiling and Sorting:** Gaussians are binned into tiles (e.g., $16 \times 16$ pixels) [S12, unofficial]. Within each tile, Gaussians are sorted front-to-back by their depth (center depth) [S7, S12, unofficial].
5.  **Rasterization and Compositing:** For each pixel, the contributing Gaussians are alpha-composited [S7, unofficial]. The color $C(\mathbf{p})$ at pixel $\mathbf{p}$ is:
    $$ C(\mathbf{p}) = \sum_{k \in N} \mathbf{c}_k(\mathbf{d}_k) \, \hat{\alpha}_k \, G_k^{2D}(\mathbf{p}) \prod_{j < k} \left( 1 - \hat{\alpha}_j \, G_j^{2D}(\mathbf{p}) \right) $$
    where $N$ is the set of sorted Gaussians covering the pixel, $\mathbf{d}_k$ is the view direction, and $G_k^{2D}(\mathbf{p})$ is the 2D Gaussian kernel value:
    $$ G_k^{2D}(\mathbf{p}) = \exp\left( -\frac{1}{2} (\mathbf{p} - \boldsymbol{\mu}'_k)^\top (\boldsymbol{\Sigma}'_k)^{-1} (\mathbf{p} - \boldsymbol{\mu}'_k) \right) $$
    [S4][S7, unofficial][S9][S16, unofficial]. The term $\hat{\alpha}_k G_k^{2D}(\mathbf{p})$ represents the effective alpha of the $k$-th splat at the pixel [S12, unofficial].
6.  **Loss and Optimization:** The rendered image is compared to the ground truth using a combined L1 and SSIM loss:
    $$ \mathcal{L} = (1 - \lambda) \|\hat{I} - I\|_1 + \lambda (1 - \text{SSIM}(\hat{I}, I)) $$
    with $\lambda = 0.2$ [S12, unofficial]. Gradients are backpropagated through the rasterizer to update $\boldsymbol{\mu}, \mathbf{q}, \mathbf{s}, \alpha, \text{SH}$ using the Adam optimizer [S12, unofficial].

**Adaptive Density Control (ADC)**
To handle local minima and varying detail, 3DGS employs periodic densification and pruning every $K$ iterations (typically every 100 iterations within a window of 500–15,000) [S7, S12, unofficial]:
*   **Gradient Tracking:** The magnitude of the 2D position gradient $\|\nabla_{\boldsymbol{\mu}_{2D}} \mathcal{L}\|$ is tracked for each Gaussian [S12, unofficial].
*   **Clone:** If a Gaussian has small scale and high gradient, it is cloned (duplicated with perturbed position) to fill under-reconstructed areas [S12, unofficial].
*   **Split:** If a Gaussian has large scale and high gradient, it is replaced by two smaller Gaussians (clones with halved scale) to increase resolution [S12, unofficial].
*   **Prune:** Gaussians with opacity below a threshold $\epsilon_\alpha \approx 0.005$ are removed [S12, unofficial].
*   **Opacity Reset:** Every 3,000 iterations, all opacities are reset to a low value (e.g., 0.01) to escape local minima where Gaussians are opaque but incorrect [S12, unofficial].

**Pseudocode**

```python
import numpy as np

def quaternion_to_rotation_matrix(q):
    """Converts a unit quaternion [w, x, y, z] to a 3x3 rotation matrix."""
    w, x, y, z = q
    return np.array([
        [1 - 2*y*y - 2*z*z, 2*x*y - 2*z*w, 2*x*z + 2*y*w],
        [2*x*y + 2*z*w, 1 - 2*x*x - 2*z*z, 2*y*z - 2*x*w],
        [2*x*z - 2*y*w, 2*y*z + 2*x*w, 1 - 2*x*x - 2*y*y]
    ])

def project_gaussian_3d_to_2d(mu_3d, Sigma_3d, camera_matrix):
    """Projects a 3D Gaussian to 2D image plane. Returns mu_2d, Sigma_2d, depth, valid."""
    W = camera_matrix[:3, :]
    mu_c = W @ np.append(mu_3d, 1.0)
    if mu_c[2] <= 0:
        return None, None, 0, False
    J = np.array([
        [camera_matrix[0,0]/mu_c[2], 0, -camera_matrix[0,0]*mu_c[0]/mu_c[2]**2],
        [0, camera_matrix[1,1]/mu_c[2], -camera_matrix[1,1]*mu_c[1]/mu_c[2]**2]
    ])
    Sigma_2d = J @ (W @ Sigma_3d @ W.T) @ J.T
    mu_2d = J @ mu_c[:2]
    return mu_2d, Sigma_2d, mu_c[2], True

def evaluate_sh(coeffs, direction):
    """Evaluates spherical harmonics coefficients for a given view direction."""
    x, y, z = direction
    c0 = coeffs[0:3]
    c1 = coeffs[3:6]
    c2 = coeffs[6:9]
    c3 = coeffs[9:12]
    return c0 + c1*y + c2*z + c3*x

def render_gaussians(gaussians, camera_matrix, image_width, image_height, tile_size=16):
    projected_gaussians = []
    for g in gaussians:
        R = quaternion_to_rotation_matrix(g.q)
        S = np.diag(np.exp(g.s))
        Sigma_3d = R @ (S @ S.T) @ R.T
        mu_2d, Sigma_2d, depth, valid = project_gaussian_3d_to_2d(g.mu, Sigma_3d, camera_matrix)
        if not valid or depth < 0:
            continue
        alpha = 1.0 / (1.0 + np.exp(-g.alpha_raw))
        eigenvalues, _ = np.linalg.eigh(Sigma_2d)
        max_extent = 3.0 * np.sqrt(np.max(eigenvalues))
        min_x = int(np.floor((mu_2d[0] - max_extent) / tile_size))
        max_x = int(np.ceil((mu_2d[0] + max_extent) / tile_size))
        min_y = int(np.floor((mu_2d[1] - max_extent) / tile_size))
        max_y = int(np.ceil((mu_2d[1] + max_extent) / tile_size))
        projected_gaussians.append({
            'mu_2d': mu_2d, 'Sigma_2d': Sigma_2d, 'alpha': alpha,
            'sh_coeffs': g.sh_coeffs, 'depth': depth,
            'tile_min': (min_x, min_y), 'tile_max': (max_x, max_y)
        })
    num_tiles_x = (image_width + tile_size - 1) // tile_size
    num_tiles_y = (image_height + tile_size - 1) // tile_size
    tiles = {}
    for pg in projected_gaussians:
        for tx in range(pg['tile_min'][0], pg['tile_max'][0] + 1):
            for ty in range(pg['tile_min'][1], pg['tile_max'][1] + 1):
                if 0 <= tx < num_tiles_x and 0 <= ty < num_tiles_y:
                    key = (tx, ty)
                    if key not in tiles:
                        tiles[key] = []
                    tiles[key].append(pg)
    image = np.zeros((image_height, image_width, 3))
    for (tx, ty), pg_list in tiles.items():
        pg_list.sort(key=lambda x: x['depth'])
        x_start, y_start = tx * tile_size, ty * tile_size
        x_end, y_end = min(x_start + tile_size, image_width), min(y_start + tile_size, image_height)
        for y in range(y_start, y_end):
            for x in range(x_start, x_end):
                T, color = 1.0, np.zeros(3)
                for pg in pg_list:
                    diff = np.array([x, y]) - pg['mu_2d']
                    dist = diff @ np.linalg.inv(pg['Sigma_2d']) @ diff
                    G_2d = np.exp(-0.5 * dist)
                    alpha_eff = pg['alpha'] * G_2d
                    if alpha_eff < 1e-4: continue
                    d = np.array([x, y, 1.0]) / np.linalg.norm(np.array([x, y, 1.0]))
                    c = evaluate_sh(pg['sh_coeffs'], d)
                    color += c * alpha_eff * T
                    T *= (1.0 - alpha_eff)
                    if T < 1e-4: break
                image[y, x] = color
    return image

def optimize_gaussians(gaussians, training_images, camera_poses, num_iterations=30000):
    params = [g.mu for g in gaussians] + [g.q for g in gaussians] + [g.s for g in gaussians] + [g.alpha_raw for g in gaussians] + [g.sh_coeffs for g in gaussians]
    m = {p: np.zeros_like(p) for p in params}
    v = {p: np.zeros_like(p) for p in params}
    lr, beta1, beta2, eps = 1e-4, 0.9, 0.999, 1e-8
    t = 0
    for iteration in range(num_iterations):
        idx = np.random.randint(len(training_images))
        rendered_img = render_gaussians(gaussians, camera_poses[idx], training_images[idx].width, training_images[idx].height)
        loss = np.mean(np.abs(rendered_img - training_images[idx].data))
        gradients = compute_gradients(loss, gaussians)
        t += 1
        for p in params:
            m[p] = beta1 * m[p] + (1 - beta1) * gradients[p]
            v[p] = beta2 * v[p] + (1 - beta2) * gradients[p]**2
            m_hat = m[p] / (1 - beta1**t)
            v_hat = v[p] / (1 - beta2**t)
            p -= lr * m_hat / (np.sqrt(v_hat) + eps)
        if 500 < iteration < 15000 and iteration % 100 == 0:
            gaussians = densify_and_prune(gaussians, threshold=2e-4)
        if iteration % 3000 == 0:
            for g in gaussians:
                g.alpha_raw = np.log(0.01)
        if iteration % 1000 == 0 and iteration > 0:
            increase_sh_degree(gaussians)

def densify_and_prune(gaussians, threshold):
    grads = compute_gradient_magnitude(gaussians, 'mu_2d')
    new_gaussians = []
    for g in gaussians:
        if np.exp(g.s).max() < 0.01 and grads[g.id] > threshold:
            clone = copy_gaussian(g)
            clone.mu += np.random.randn(3) * 0.01
            new_gaussians.append(clone)
        elif np.exp(g.s).max() > 0.1 and grads[g.id] > threshold:
            for _ in range(2):
                split = copy_gaussian(g)
                split.s = g.s - np.log(2)
                split.mu += np.random.randn(3) * 0.01
                new_gaussians.append(split)
        elif 1.0 / (1.0 + np.exp(-g.alpha_raw)) > 0.005:
            new_gaussians.append(g)
    return new_gaussians
```

## Operating characteristics
*   **Performance:** Achieves real-time rendering speeds (e.g., 68.4 FPS at 1080p on an A100 GPU) [S1]. Training time is significantly faster than NeRF (30-60 minutes vs. hours/days) but slower than Instant-NGP (18.4 minutes to 95% PSNR vs. 2.4 minutes) [S1].
*   **Strengths:** Real-time novel view synthesis, high visual quality (PSNR 33.2 dB on Blender dataset), differentiable end-to-end optimization, simple data structure [S1][S5, unofficial][S9].
*   **Limitations:** Moderate surface accuracy (ellipsoids approximate geometry but do not conform to exact surfaces) [S1]. Popping artifacts can occur due to per-tile depth sorting using center depth rather than per-pixel depth [S12, unofficial]. Heuristic ADC can generate excessive overlapping Gaussians [S7, unofficial]. Not directly compatible with generalizable neural prediction due to non-differentiable pruning/splitting operations [S8].

## Background
3D Gaussian Splatting was introduced as a method to replace implicit neural representations with explicit 3D Gaussians, enabling real-time rendering through GPU rasterization [S1, S2]. It was developed to address the computational bottleneck of ray marching in NeRFs while maintaining high visual fidelity [S5, unofficial][S9]. The method initializes from a sparse Structure-from-Motion point cloud and optimizes parameters end-to-end [S1][S12, unofficial]. It has become a baseline for many subsequent variants in the 3DGS family [S3][S12, unofficial].
