# Temporal Point Cloud Initialization via Chamfer Distance Minimization

Also called: Temporal Chamfer Initialization

## Overview
This method reduces training time for dynamic video scenes by initializing the point cloud of the current frame using the learned model from the previous frame, leveraging temporal correlation between nearby frames [S1]. It sets itself apart from static initialization methods by explicitly optimizing geometric alignment between consecutive frames via Chamfer distance minimization before refining radiance parameters [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** An accurate point cloud $S_1$ with learned spherical harmonics (SH) parameters from the previous frame (frame 1) [S1]. An initial point cloud $S_2$ for the current frame (frame 2), generated using the standard initial generation scheme (e.g., from COLMAP or coarse estimation) [S1].
*   **Output:** A refined initial point cloud for frame 2 with optimized positions and initialized radiance field parameters [S1].

**Data Structures:**
*   $S_1$: Set of points $\{x\}$ with associated spherical harmonics coefficients.
*   $S_2$: Set of points $\{y\}$ with learnable position parameters $p_i$.

**Steps:**
1.  **Generate Initial Cloud:** Compute an initial point cloud $S_2$ for the next frame using the standard initialization scheme [S1].
2.  **Compute Chamfer Distance:** Calculate the Chamfer distance $CD(S_1, S_2)$ between the previous frame's cloud $S_1$ and the current frame's initial cloud $S_2$ [S1].
3.  **Optimize Positions:** Minimize the Chamfer distance via gradient descent using the Adam optimizer applied to the point positions in $S_2$ [S1]. This yields a more accurate initial point cloud for frame 2 in terms of geometry [S1].
4.  **Initialize Radiance Parameters:** After refining the positions $p_i$ in $S_2$, compute the top-$k$ closest points in $S_1$ for each point in $S_2$ [S1]. Choose the average of their corresponding spherical harmonics parameters as the initial radiance field parameter for the refined point $p_i$ [S1].

**Formula:**
The Chamfer distance $CD(S_1, S_2)$ is defined as [S1]:

$$
CD(S_1, S_2) = \frac{1}{|S_1|} \sum_{x \in S_1} \min_{y \in S_2} \|x - y\|_2^2 + \frac{1}{|S_2|} \sum_{y \in S_2} \min_{x \in S_1} \|x - y\|_2^2
$$

Where:
*   $|S_1|$ and $|S_2|$ are the number of points in clouds $S_1$ and $S_2$ respectively.
*   $\| \cdot \|_2$ denotes the Euclidean distance.

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Top-k:** The number of closest neighbors to average SH parameters. Not given in the sources.
*   **Learning Rate:** Not given in the sources.

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def temporal_chamfer_initialization(S1_points, S1_sh_params, S2_points_init):
    """
    Initialize frame 2 Gaussians using frame 1's learned model.
    
    Args:
        S1_points: Tensor of shape (N1, 3), positions of previous frame.
        S1_sh_params: Tensor of shape (N1, C), SH coefficients of previous frame.
        S2_points_init: Tensor of shape (N2, 3), initial positions of current frame.
        
    Returns:
        S2_points_refined: Refined positions for current frame.
        S2_sh_params_init: Initialized SH coefficients for current frame.
    """
    # Step 1: S2_points_init is already provided as input
    
    # Step 2 & 3: Minimize Chamfer Distance via Gradient Descent
    # We need to optimize S2_points. We assume S2_points is a leaf tensor or requires grad.
    # In practice, this is done within the training loop. Here we simulate one optimization step.
    
    # Note: In a real implementation, S2_points would be a parameter tensor.
    # For this self-contained function, we assume S2_points is the variable to optimize.
    # We use a simplified gradient step for demonstration.
    
    s2_points = S2_points_init.clone().detach().requires_grad_(True)
    optimizer = torch.optim.Adam([s2_points], lr=0.01) # Learning rate not given in sources [G]
    
    # Perform a few optimization steps to minimize Chamfer Distance
    for _ in range(10): # Number of steps not given in sources [G]
        optimizer.zero_grad()
        
        # Compute Chamfer Distance
        cd = compute_chamfer_distance(S1_points, s2_points)
        
        # Backpropagate
        cd.backward()
        optimizer.step()
        
    S2_points_refined = s2_points.detach()
    
    # Step 4: Initialize Radiance Parameters (SH)
    # Compute distances between all pairs
    dist_matrix = torch.cdist(S2_points_refined, S1_points) # Shape (N2, N1)
    
    # Find top-k closest points in S1 for each point in S2
    # k is not specified in sources [G]. Using k=1 for simplicity if not provided.
    k = 1 
    top_k_indices = torch.topk(dist_matrix, k, dim=1, largest=False).indices # Shape (N2, k)
    
    # Gather SH parameters from S1 based on top-k indices
    # S1_sh_params: (N1, C)
    # top_k_indices: (N2, k)
    # Gathered SH: (N2, k, C)
    gathered_sh = S1_sh_params[top_k_indices] 
    
    # Average the SH parameters
    S2_sh_params_init = gathered_sh.mean(dim=1) # Shape (N2, C)
    
    return S2_points_refined, S2_sh_params_init

def compute_chamfer_distance(S1, S2):
    """
    Computes Chamfer Distance between two point clouds.
    """
    # Distances from S1 to S2
    dist_s1_s2 = torch.cdist(S1, S2) # Shape (N1, N2)
    min_dist_s1_s2, _ = torch.min(dist_s1_s2, dim=1) # Shape (N1,)
    
    # Distances from S2 to S1
    dist_s2_s1 = torch.cdist(S2, S1) # Shape (N2, N1)
    min_dist_s2_s1, _ = torch.min(dist_s2_s1, dim=1) # Shape (N2,)
    
    # Average squared distances
    cd = torch.mean(min_dist_s1_s2**2) + torch.mean(min_dist_s2_s1**2)
    
    return cd
```

## Subtopics

### Gaussian Point Constraint (GPC)
An inter-frame point constraint that uses a Gaussian kernel function to measure distances between inter-frame point clouds, enhancing robustness against depth noise [S2]. It replaces Chamfer distance to be less sensitive to noise [S2]. The weight $w_{ij}$ between points $p_i^m$ and $p_j^{m+1}$ is calculated as $w_{ij} = \exp\left(-\frac{\|p_i^m - p_j^{m+1}\|^2}{2\sigma_{pc}^2}\right)$, where $\sigma_{pc}$ is the standard deviation of the Gaussian kernel function [S2]. The standard deviation $\sigma_{pc}$ is empirically set to 1 [S2]. This constraint is incorporated to provide constraints for inter-frame pose optimization and refinement [S2].

## Operating characteristics
*   **Time Complexity:** The method achieves a 4x improvement in training runtime compared to training each frame from scratch [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Reduces training time significantly by leveraging temporal correlation [S1]. Produces cleaner object boundaries and finer detail, especially with significant object motion [S1].
*   **Limitations:** Chamfer distance can be sensitive to noise in estimated depth maps, as it imposes a strong constraint on point clouds and penalizes small deviations [S2]. This is addressed by variants like GPC [S2].
*   **When to use:** Dynamic video scenes where nearby frames are temporally correlated [S1].
*   **When not to use:** Static scenes where temporal correlation is not applicable, or scenes with high noise in depth estimation where Chamfer distance might fail (use GPC instead) [S2].

## Background
This method was proposed by Zhang et al. in the paper "Differentiable Point-Based Radiance Fields for Efficient View Synthesis" [S1]. It was presented at the SA ’22 Conference Papers, December 6–9, 2022, Daegu, Republic of Korea [S1]. The method is part of the broader effort to improve computational efficiency in point-based radiance representations for novel view synthesis [S1].
