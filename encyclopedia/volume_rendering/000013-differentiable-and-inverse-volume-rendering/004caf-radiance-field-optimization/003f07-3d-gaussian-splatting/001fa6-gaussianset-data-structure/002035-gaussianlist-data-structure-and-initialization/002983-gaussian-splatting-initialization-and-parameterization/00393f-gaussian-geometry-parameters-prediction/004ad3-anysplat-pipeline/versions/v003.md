# AnySplat Pipeline

Also called: Feed-forward 3D Gaussian Splatting from Unconstrained Views

## Overview
AnySplat is a feed-forward neural network that predicts a set of 3D Gaussians directly from uncalibrated input images, enabling novel-view synthesis without iterative optimization [S1, unofficial]. It differs from inverse methods by using a transformer-based encoder-decoder architecture to predict Gaussian parameters, depth, and camera poses in a single forward pass, bypassing the need for per-scene optimization [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A tensor of uncalibrated images with shape $[1, K, 3, 448, 448]$ (batch, views, channels, height, width) [S1, unofficial].
*   **Outputs:** A set of 3D Gaussians (defined by mean $\mu$, covariance $\sigma$, rotation $r$, scale $s$, and color $c$) and predicted camera poses $p$ [S1, unofficial].

**Data Structures:**
The method constructs pixel-wise 3D Gaussians from the predicted parameters. These are then processed by a Differentiable Voxelization module to create pre-voxel 3D Gaussians [S1, unofficial]. The specific internal layout of the Gaussian parameter tensor is not detailed in the sources, but the inference function returns `gaussians` and `pred_context_pose` [S1, unofficial].

**Algorithm Steps:**
1.  **Encoding:** Input images are passed through a transformer-based geometry encoder [S1, unofficial].
2.  **Prediction:** Three decoder heads ($F_G, F_D, F_C$) predict:
    *   Gaussian parameters: mean $\mu$, covariance $\sigma$, rotation $r$, scale $s$, and color $c$ [S1, unofficial].
    *   Depth map $D$ [S1, unofficial].
    *   Camera poses $p$ [S1, unofficial].
3.  **Gaussian Construction:** The predicted parameters are used to construct a set of pixel-wise 3D Gaussians [S1, unofficial].
4.  **Voxelization:** The pixel-wise Gaussians are voxelized into pre-voxel 3D Gaussians using a Differentiable Voxelization module [S1, unofficial].
5.  **Rendering:** Multi-view images and depth maps are rendered from the voxelized Gaussians [S1, unofficial].
6.  **Loss Computation:**
    *   **RGB Loss:** Rendered images are supervised against ground truth images [S1, unofficial].
    *   **Geometry Loss:** Rendered depth maps, decoded depth $D$, and poses $p$ are used to compute geometry losses [S1, unofficial].
7.  **Pseudo-Geometry Supervision:** Geometries are supervised by pseudo-geometry priors obtained from a pretrained VGGT model [S1, unofficial].

## Subtopics

### [SubSplat](13524-subsplat.md)
SubSplat is a method for high-resolution novel-view synthesis that resolves the trade-off between network computational cost and rendering fidelity in pixel-aligned 3D Gaussian Splatting. It solves the problem of insufficient Gaussian density and artifacts when using low-resolution backbone inputs by introducing a Sub-pixel Gaussian Reparameterizer (SPGR). Unlike prior methods limited by fixed grids or image-space upsamplers, SubSplat subdivides each grid-anchored primary Gaussian into multiple fine-grained sub-pixel primitives, restoring structural density directly from low-resolution features while maintaining stable network latency.

### [Deformable Radial Kernel (DRK)](13699-deformable-radial-kernel-drk.md)
Deformable Radial Kernel (DRK) Splatting is a 3D scene representation method that replaces the fixed radial symmetry of Gaussian primitives with a flexible planar kernel defined by multiple radial basis functions. It solves the overparameterization and geometric fidelity limitations of Gaussian Splatting by allowing adaptive stretching, rotation, and sharp boundary control, enabling high-fidelity rendering with significantly fewer primitives. Unlike standard 2D Gaussian Splatting, which relies on smooth, elliptical distributions, DRK supports straight edges and sharp corners through L1/L2 norm blending and piecewise edge sharpening.
