# Random Large-Variance Initialization

Also called: RAIN-GS, RAIN-GS Initialization, Sparse-Large-Variance Init

## Overview
Random Large-Variance Initialization (RAIN-GS) relaxes the strict Structure-from-Motion (SfM) point cloud assumption required by standard 3D Gaussian Splatting by introducing sparse, large-variance random initialization [S1, unofficial]. Unlike standard methods that rely solely on dense SfM points, this approach allows optimization to proceed even when SfM data is sparse or absent, serving as a fallback or complementary initialization strategy [S1, unofficial].

## How it works
**Inputs:**
- A set of $N$ 3D points $Q = \{q_1, \dots, q_N\}$ from a SfM reconstruction, where each $q_i \in \mathbb{R}^3$ [S2].
- A scaling constant $k$ [S2].

**Outputs:**
- A set of 3D triangles, each defined by three vertices $\{v_1, v_2, v_3\}$, centered around each SfM point [S2].

**Data Structures:**
- Each triangle is represented by three 3D vertex positions $v_i \in \mathbb{R}^3$ [S2].
- Additional learnable parameters per triangle include sharpness $\sigma$, opacity $o$, and spherical harmonic color coefficients $c$ [S2].

**Steps:**
1. For each SfM point $q \in Q$:
   a. Identify the three nearest neighbors of $q$ in the point cloud [S2].
   b. Calculate $d$, the average Euclidean distance from $q$ to these three nearest neighbors [S2].
   c. Sample three vertices $\{u_1, u_2, u_3\}$ uniformly at random from the unit sphere ($\|u_i\| = 1$) [S2].
   d. Scale the sampled vertices by $d$ and translate them by $q$ to create the triangle vertices:
      $$v_i = q + k \cdot d \cdot u_i, \quad i \in \{1, 2, 3\}$$
   e. This results in an approximately equilateral, randomly oriented triangle centered at $q$ with size proportional to local point density $d$ [S2].

**Parameters:**
- $k$: Scaling constant determining triangle size relative to neighbor distance $d$. Typical values are not given in the sources.

**Edge Cases and Pitfalls:**
- If $d=0$ (e.g., duplicate points), the triangle collapses [G]. A guard should handle $d \approx 0$ by using a minimum distance threshold or skipping the point [G].
- Uniform sampling on the unit sphere must be done correctly (e.g., using spherical coordinates with $\cos \theta$ uniform) to avoid clustering at poles [G].

**Pseudocode:**
```python
import numpy as np

def sample_uniform_sphere(n):
    """Sample n points uniformly on the unit sphere."""
    phi = np.random.uniform(0, 2 * np.pi, n)
    cos_theta = np.random.uniform(-1, 1, n)
    sin_theta = np.sqrt(1 - cos_theta**2)
    return np.stack([sin_theta * np.cos(phi), sin_theta * np.sin(phi), cos_theta], axis=-1)

def random_large_variance_init(points, k=1.0):
    """
    Initialize triangles around SfM points using sparse large-variance random init.
    
    Args:
        points: Array of shape (N, 3) containing SfM 3D points.
        k: Scaling constant for triangle size.
        
    Returns:
        triangles: Array of shape (N, 3, 3) containing vertices for each triangle.
    """
    N = points.shape[0]
    triangles = np.zeros((N, 3, 3))
    
    for i, q in enumerate(points):
        # Compute distances to all other points
        dists = np.linalg.norm(points - q, axis=1)
        # Exclude self from nearest neighbor search
        dists[i] = np.inf
        # Get indices of the 3 nearest neighbors
        nn_idx = np.argsort(dists)[:3]
        # Calculate average distance d
        d = np.mean(dists[nn_idx])
        
        # Guard against degenerate triangles when d is near zero
        if d < 1e-6:
            triangles[i] = q
            continue
            
        # Sample 3 vertices from unit sphere
        u = sample_uniform_sphere(3)
        
        # Scale and translate to form triangle
        triangles[i] = q + k * d * u
        
    return triangles
```

## Subtopics

### SfM-Based Triangle Initialization
This variant explicitly uses the SfM point cloud to define the initial geometry [S2]. It creates triangles centered at each SfM point, with size proportional to the local point density (average distance to nearest neighbors) [S2]. It is chosen when SfM data is available but sparse, allowing the model to explore a larger initial volume than point-based initialization [G]. It differs from pure random initialization by anchoring the geometry to known scene structure [G].

## Background
The method originated in the RAIN-GS approach, which relaxes the SfM-only initialization assumption [S1, unofficial]. The triangle-based initialization variant is detailed in "Triangle Splatting for Real-Time Radiance Field Rendering" [S2]. It is part of the broader effort to make Gaussian Splatting more robust to varying input data quality [G].
