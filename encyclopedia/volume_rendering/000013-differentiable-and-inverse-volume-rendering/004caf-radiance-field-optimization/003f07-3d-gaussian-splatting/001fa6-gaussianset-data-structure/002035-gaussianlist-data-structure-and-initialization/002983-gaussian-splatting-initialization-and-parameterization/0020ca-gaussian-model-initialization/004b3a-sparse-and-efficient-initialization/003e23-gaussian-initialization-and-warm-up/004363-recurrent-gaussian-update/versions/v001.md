# Recurrent Gaussian Update

Also called: Feedback Loop Update, ReSplat (Recurrent Gaussian Splatting), Recurrent Gaussian Splating, Recurrent Refinement

## Overview
Recurrent Gaussian Update is a gradient-free, feed-forward refinement method that iteratively corrects initial 3D Gaussian predictions by predicting incremental updates to Gaussian parameters and hidden states based on rendering errors from input views [S1]. It sets itself apart from standard 3D Gaussian Splatting (3DGS) optimization by eliminating gradient computation, achieving a 53× speedup in reconstruction time and converging in 4 iterations instead of 30,000 [S1]. Unlike single-step feed-forward models, it uses a recurrent error-correction loop to achieve higher parameter efficiency, where a smaller recurrent model outperforms significantly larger single-step models [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Initial set of 3D Gaussians $\mathcal{G}^0 = \{(\mathbf{g}_j^0, z_j^0)\}_{j=1}^M$ predicted by a feed-forward initialization network [S1]; a set of $N$ input views $\{I_i\}_{i=1}^N$ [S1].
*   **Outputs:** Refined set of 3D Gaussians $\mathcal{G}^T = \{(\mathbf{g}_j^T, z_j^T)\}_{j=1}^M$ after $T$ iterations [S1].

**Data Structures:**
*   **Gaussian Parameters ($\mathbf{g}_j$):** Vector of dimension $C_1$ representing the geometric and appearance properties of the $j$-th Gaussian [S1].
*   **Hidden State ($z_j$):** Vector of dimension $C_0$ used to store recurrent context for the $j$-th Gaussian [S1].
*   **Rendering Error ($\hat{\mathbf{E}}^t$):** A tensor of shape $N \times \frac{H}{4} \times \frac{W}{4} \times C_2$, where $C_2=256$ [S1].
*   **Aggregated Error ($\mathbf{E}^t$):** A list of vectors $\{\mathbf{e}_j^t\}_{j=1}^{N \times \frac{HW}{16}}$, where each $\mathbf{e}_j^t \in \mathbb{R}^{C_2}$ [S1].

**Parameters:**
*   $T$: Total number of iterations. Training: Randomly sampled between 1 and 4. Inference: Flexible (1–4), with convergence observed at 4 [S1].
*   $k$: Number of neighbors for kNN attention in the recurrent model. Value: 8 [S1].
*   $C_2$: Channel dimension of the feature-space error. Value: 256 [S1].
*   Spatial subsampling factor: 4× in 3D space (aligning with 1/4 resolution features) [S1].

**Algorithm Steps:**

1.  **Rendering:** Render the input views $\{\hat{I}_i^t\}_{i=1}^N$ using the current Gaussian parameters $\mathcal{G}^t$ at iteration $t$ [S1].
2.  **Pixel-Space Error Computation:**
    *   Compute pixel-space error: $\{\hat{I}_i^t - I_i\}_{i=1}^N$ [S1].
    *   Perform 4× spatial downsampling on the error using pixel unshuffle to align with the Gaussian count [S1].
3.  **Feature-Space Error Computation:**
    *   Extract the first three stage features (at 1/2, 1/4, and 1/8 resolutions) from an ImageNet pre-trained ResNet-18 for both rendered views $\{\hat{I}_i^t\}_{i=1}^N$ and ground-truth views $\{I_i\}_{i=1}^N$ [S1].
    *   Bilinearly resize the three scale features to the 1/4 resolution [S1].
    *   Concatenate the resized features [S1].
    *   Compute the difference: $\{\hat{F}_i^t - F_i\}_{i=1}^N$, where $\hat{F}_i^t, F_i \in \mathbb{R}^{\frac{H}{4} \times \frac{W}{4} \times C_2}$ [S1].
4.  **Error Combination:**
    *   Project the pixel-space error to the feature space using a linear layer followed by Layer Normalization [S1].
    *   Add the projected pixel-space error to the feature-space error [S1].
    *   Formula:
        $$ \hat{\mathbf{E}}^t = \{\hat{F}_i^t - F_i\}_{i=1}^N + \text{proj}(\{\hat{I}_i^t - I_i\}_{i=1}^N) $$
        where $\hat{\mathbf{E}}^t = \{\hat{e}_j^t\}_{j=1}^{N \times \frac{HW}{16}}$ and $\hat{e}_j^t \in \mathbb{R}^{C_2}$ [S1].
5.  **Error Propagation (Global Attention):**
    *   Apply global attention across all $N \times \frac{H}{4} \times \frac{W}{4}$ rendering errors $\hat{\mathbf{E}}^t$ to aggregate global context [S1].
    *   Output: $\mathbf{E}^t = \{\mathbf{e}_j^t\}_{j=1}^{N \times \frac{HW}{16}}$, where $\mathbf{e}_j^t$ is the aggregated error for the $j$-th element [S1].
6.  **Update Module Input:**
    *   Concatenate Gaussian parameters $\mathbf{g}_j^t$, hidden state $z_j^t$, and aggregated error $\mathbf{e}_j^t$ for each Gaussian $j$ [S1].
    *   Input: $\{(\mathbf{g}_j^t, z_j^t, \mathbf{e}_j^t)\}_{j=1}^M$ [S1].
7.  **Update Prediction:**
    *   Pass the input through four kNN attention blocks (with $k=8$) to model local structural details in 3D space [S1].
    *   Decode Gaussian updates $\Delta \mathbf{g}_j^t$ with a lightweight four-layer MLP head [S1].
    *   Predict hidden state updates $\Delta z_j^t$ [S1].
    *   Formula:
        $$ \{(\mathbf{g}_j^t, z_j^t, \mathbf{e}_j^t)\}_{j=1}^M \rightarrow \{(\Delta \mathbf{g}_j^t, \Delta z_j^t)\}_{j=1}^M $$
        [S1].
8.  **Parameter Update:**
    *   Update Gaussian parameters and hidden states using the incremental updates [S1].
    *   Formula:
        $$ \mathbf{g}_j^{t+1} = \mathbf{g}_j^t + \Delta \mathbf{g}_j^t, \quad z_j^{t+1} = z_j^t + \Delta z_j^t $$
        for $t = 0, \dots, T-1$ [S1].
9.  **Iteration:**
    *   Repeat steps 1–8 for $T$ iterations [S1].

**Pseudocode:**

```python
def recurrent_gaussian_update(initial_gaussians, input_views, num_iterations):
    """
    Refines initial 3D Gaussians using recurrent error feedback.
    
    Args:
        initial_gaussians: List of tuples (g_j, z_j) for j=1..M
        input_views: List of ground-truth images I_i for i=1..N
        num_iterations: Number of refinement steps T
        
    Returns:
        Refined list of tuples (g_j, z_j)
    """
    # Initialize current state
    current_gaussians = list(initial_gaussians)
    
    # Pre-compute feature extractor (ImageNet pre-trained ResNet-18)
    # Note: In implementation, this would be a loaded PyTorch model
    feature_extractor = load_resnet18_imagenet()
    
    for t in range(num_iterations):
        # 1. Render current Gaussians
        rendered_views = render_gaussians(current_gaussians, input_views)
        
        # 2. Compute Pixel-Space Error
        pixel_errors = [rendered - ground_truth for rendered, ground_truth in zip(rendered_views, input_views)]
        # Downsample using pixel unshuffle (4x)
        pixel_errors_downsampled = [pixel_unshuffle(error, factor=4) for error in pixel_errors]
        
        # 3. Compute Feature-Space Error
        # Extract features for rendered and ground truth views
        rendered_features = []
        gt_features = []
        for rendered, ground_truth in zip(rendered_views, input_views):
            # Extract stages 1, 2, 3 from ResNet-18
            r_feats = [stage(rendered) for stage in feature_extractor.stages[:3]]
            g_feats = [stage(ground_truth) for stage in feature_extractor.stages[:3]]
            
            # Resize all to 1/4 resolution
            r_feats_resized = [bilinear_resize(f, target_scale=0.25) for f in r_feats]
            g_feats_resized = [bilinear_resize(f, target_scale=0.25) for f in g_feats]
            
            # Concatenate features
            r_feat_concat = concatenate_channels(r_feats_resized)
            g_feat_concat = concatenate_channels(g_feats_resized)
            
            rendered_features.append(r_feat_concat)
            gt_features.append(g_feat_concat)
            
        # Compute difference
        feature_errors = [r_feat - g_feat for r_feat, g_feat in zip(rendered_features, gt_features)]
        
        # 4. Combine Errors
        # Project pixel errors to feature space (Linear + LayerNorm)
        projected_pixel_errors = [layer_norm(linear_project(error)) for error in pixel_errors_downsampled]
        
        # Element-wise addition
        combined_errors = [feat_err + proj_err for feat_err, proj_err in zip(feature_errors, projected_pixel_errors)]
        
        # Flatten errors to list of vectors e_hat_j
        # Shape: N x H/4 x W/4 x C2 -> List of N*H/4*W/4 vectors of dim C2
        flat_errors = flatten_spatial(combined_errors)
        
        # 5. Global Attention Propagation
        # Apply global attention to aggregate context
        # Input: flat_errors (list of vectors)
        # Output: aggregated_errors (list of vectors e_j)
        aggregated_errors = global_attention(flat_errors)
        
        # 6. Update Module
        updates = []
        for j in range(len(current_gaussians)):
            g_j, z_j = current_gaussians[j]
            e_j = aggregated_errors[j]
            
            # Concatenate inputs
            input_vector = concatenate([g_j, z_j, e_j])
            
            # Pass through kNN attention blocks (k=8) and MLP head
            # Note: kNN attention operates in 3D space based on Gaussian positions
            # This is a simplified representation of the recurrent block
            delta_g, delta_z = recurrent_block(input_vector, k=8)
            
            updates.append((delta_g, delta_z))
            
        # 7. Update Parameters
        new_gaussians = []
        for j in range(len(current_gaussians)):
            g_j, z_j = current_gaussians[j]
            delta_g, delta_z = updates[j]
            
            new_g = g_j + delta_g
            new_z = z_j + delta_z
            new_gaussians.append((new_g, new_z))
            
        current_gaussians = new_gaussians
        
    return current_gaussians
```

**Edge Cases and Pitfalls:**
*   **kNN Bottleneck:** The kNN operation during reconstruction is a primary bottleneck for inference speed and requires implementation-level optimization for faster deployment [S1].
*   **Resolution Alignment:** The 4× spatial downsampling is critical to align the pixel-space error with the number of 3D Gaussians; failure to align dimensions will cause shape mismatches in the error combination step [S1].
*   **Convergence:** The model converges after 4 iterations; using fewer iterations may result in suboptimal quality, while using more provides diminishing returns [S1].

## Operating characteristics
*   **Time Complexity:** Reconstruction time is significantly faster than 3DGS optimization. On DL3DV (8-view, 512×960), it is 100× faster than 3DGS optimization [S1]. On DL3DV (16-view, 540×960), reconstruction time is 1.2–1.7 seconds for 1–2 iterations [S1].
*   **Memory Complexity:** Compresses the number of Gaussians by 16× compared to previous per-pixel feed-forward models (e.g., MVSplat, DepthSplat), resulting in 4× faster rendering speed [S1]. For 8-view DL3DV, it uses 246K Gaussians; for 16-view DL3DV, it uses 518K Gaussians [S1].
*   **Measured Performance:**
    *   **DL3DV (8-view, 512×960):** 246K Gaussians, 100× faster than 3DGS optimization, 4× faster rendering than per-pixel models [S1].
    *   **DL3DV (16-view, 540×960):** 518K Gaussians, reconstruction time 1.2–1.7 sec for 1–2 iterations [S1].
    *   **RealEstate10K (2-view, 256×256):** Outperforms LVSM encoder-decoder by 1.1 dB PSNR, 20× faster rendering than 3DGS-free methods [S1].
*   **Strengths:** Gradient-free feed-forward architecture eliminates gradient computation, providing a 53× speedup in reconstruction time and converging in 4 iterations vs 30,000 [S1]. Recurrent error correction is more parameter-efficient; ReSplat-Small (77M params) outperforms ReSplat-Large (559M params) and WorldMirror (1263M params) after 4 iterations [S1].
*   **Limitations:** kNN operation slows down inference speed [S1].
*   **When to use:** When fast reconstruction is required and input views are available at test time to compute rendering errors [S1].
*   **When not to use:** When real-time inference with minimal latency is critical and the kNN bottleneck cannot be optimized [S1].

## Background
Recurrent Gaussian Update was introduced in the paper "ReSplat: Learning Recurrent Gaussian Splatting" [S1]. It builds on the Gaussian Model Initialization [S1] and is designed to refine initial Gaussian predictions without the need for per-scene optimization [S1]. It is evaluated on DL3DV (8-view, 16-view), RealEstate10K, and ACID datasets [S1].
