# SPZ Encoder


## Overview
The SPZ Encoder serializes Spherical Harmonics (SH) coefficients into a compact byte array [S1, unofficial]. It handles degree clamping, dimension mapping, and fixed-point quantization for view-dependent color data [S1, S2, unofficial].

## How it works
**Inputs and Outputs:** The method takes Spherical Harmonics coefficients (floating-point values) and a maximum SH degree as inputs [S1, unofficial]. It outputs a byte array containing the encoded SPZ data [S1, unofficial].

**Data Structures:** The encoder maintains internal state fields: `maxShDegree` (clamped degree), `fractional_bits` (u8), and `version` (u32, optional) [S1, unofficial]. The exact byte layout of the output array is not given in the sources.

**Steps:**
1. Clamp the input SH degree to the specified maximum SH degree [S1, unofficial].
2. Update the internal `maxShDegree` field to match the clamped value [S1, unofficial].
3. Initialize the encoder with the clamped degree, `fractional_bits`, and optional `version` [S1, unofficial].
4. Execute the encoding process to produce the final byte array [S1, unofficial].

**Formulas:** The unquantized SH coefficient $x$ is calculated from the quantized integer value $x_{int}$ as [S2, unofficial]:
$$ x = \frac{x_{int} - 128.0}{128.0} $$
The inverse operation to quantize a float $x$ to $x_{int}$ uses a fixed scaling factor of 128.0 [G].

**Parameters:** `fractional_bits` (u8) and `version` (u32, optional) [S1, unofficial]. Typical values are not given in the sources.

**Edge Cases and Pitfalls:** Unsupported SH degrees log an error and return 0 dimensions [S2, unofficial]. Precision loss occurs during quantization [G].

**Pseudocode:**
```python
def encode_spz(sh_coefficients: list[float], max_sh_degree: int, fractional_bits: int, version: int | None = None) -> bytes:
    # 1. Clamp SH degree
    clamped_degree = min(max_sh_degree, 3)
    
    # 2. Update internal state
    max_sh_degree = clamped_degree
    
    # 3. Map degree to dimensions
    dim_map = {0: 0, 1: 3, 2: 8, 3: 15}
    num_dims = dim_map.get(clamped_degree, 0)
    
    if num_dims == 0:
        raise ValueError(f"Unsupported SH degree: {max_sh_degree}")
        
    # 4. Quantize coefficients and serialize
    byte_array = bytearray()
    byte_array.append(clamped_degree)
    
    for coeff in sh_coefficients:
        # Inverse of x = (x_int - 128.0) / 128.0
        x_int = round(coeff * 128.0 + 128.0)
        # Clamp to unsigned byte range [0, 255]
        x_int = max(0, min(255, x_int))
        byte_array.append(x_int)
        
    return bytes(byte_array)
```

## Subtopics

### SPZ Spherical Harmonics Degree Dimension Mapping
Maps SH degree to dimension count: Degree 0 -> 0 dimensions, Degree 1 -> 3 dimensions, Degree 2 -> 8 dimensions, Degree 3 -> 15 dimensions. Unsupported SH degrees log an error and return 0 [S2, unofficial].

### SPZ Spherical Harmonics Unquantization
Reconstructs floating-point coefficients from quantized integers using the formula $x = \frac{x_{int} - 128.0}{128.0}$ [S2, unofficial].
