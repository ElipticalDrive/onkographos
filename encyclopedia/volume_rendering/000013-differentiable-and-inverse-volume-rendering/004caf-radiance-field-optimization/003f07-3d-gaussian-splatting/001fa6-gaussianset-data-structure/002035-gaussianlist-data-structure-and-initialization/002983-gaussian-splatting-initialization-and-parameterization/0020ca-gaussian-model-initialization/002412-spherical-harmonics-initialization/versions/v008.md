# Spherical Harmonics Initialization


## Overview
Spherical Harmonics Initialization sets the initial view-dependent color coefficients for 3D Gaussians in Gaussian Splatting by assigning the input RGB color to the zeroth-order (DC) spherical harmonic term while zeroing all higher-order terms [S1, unofficial]. It differs from [Spherical Harmonics Evaluation](3848-spherical-harmonics-evaluation.md) by preparing the data structure for rendering rather than computing color from an existing state, and from [Spherical Harmonics Rotation](3985-spherical-harmonics-rotation.md) by operating in the local Gaussian frame without camera-space transformation [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: An array of $N$ RGB colors, shape $(N, 3)$, with values typically in $[0, 1]$ or $[0, 255]$ depending on the pipeline's normalization.
- Output: A tensor of SH coefficients for $N$ Gaussians, shape $(N, 27)$, representing 9 coefficients per RGB channel.

**Data Structures:**
The SH coefficients are stored in a flat tensor of shape $(N, 27)$. The layout for each Gaussian $i$ is:
- Indices $0-8$: Red channel coefficients ($c_{r,0}$ to $c_{r,8}$).
- Indices $9-17$: Green channel coefficients ($c_{g,0}$ to $c_{g,8}$).
- Indices $18-26$: Blue channel coefficients ($c_{b,0}$ to $c_{b,8}$).
Within each 9-element block, index 0 is the DC term, and indices 1-8 are the first-order and second-order terms.

**Steps:**
1. Allocate a zero tensor $C \in \mathbb{R}^{N \times 3 \times 9}$ initialized to zeros.
2. For each Gaussian $i$ from $0$ to $N-1$:
   a. Retrieve the input RGB color vector $\mathbf{rgb}_i = [r_i, g_i, b_i]$.
   b. Normalize $\mathbf{rgb}_i$ if the input is not already in the range $[0, 1]$.
   c. Compute the DC coefficient $c_0$ using the normalization constant $\alpha = 0.28209479177387814$:
      $$ c_0 = \frac{\text{channel\_value}}{\alpha} $$
   d. Assign $c_0$ to the DC index (0) of the corresponding channel in $C[i]$.
   e. Leave indices 1-8 for each channel as zero.
3. Reshape $C$ from $(N, 3, 9)$ to $(N, 27)$ by flattening the last two dimensions.

**Pseudocode:**
```python
import numpy as np

def initialize_sh(rgb_colors: np.ndarray) -> np.ndarray:
    """
    Initialize spherical harmonic coefficients for Gaussian Splatting.
    
    Args:
        rgb_colors: Array of shape (N, 3) with RGB values in [0, 1].
        
    Returns:
        SH coefficients tensor of shape (N, 27).
    """
    N = rgb_colors.shape[0]
    # Allocate zero tensor for 3 channels, 9 SH coefficients each
    sh_coeffs = np.zeros((N, 3, 9))
    
    # Normalization constant for zeroth-order SH basis function
    alpha = 0.28209479177387814
    
    # Assign DC coefficients for each channel
    # Channel 0: Red, Channel 1: Green, Channel 2: Blue
    for c in range(3):
        sh_coeffs[:, c, 0] = rgb_colors[:, c] / alpha
        
    # Flatten to (N, 27)
    sh_coeffs_flat = sh_coeffs.reshape(N, 27)
    
    return sh_coeffs_flat
```

**Parameters:**
- $\alpha = 0.28209479177387814$: The normalization constant for the zeroth-order spherical harmonic basis function [S1, unofficial].

**Edge Cases and Pitfalls:**
- Input range: If RGB values are in $[0, 255]$, they must be normalized to $[0, 1]$ before division by $\alpha$ [S1, unofficial].
- Higher-order terms: All non-DC coefficients are initialized to zero, assuming neutral lighting initially [S1, unofficial].
- Precision: Use floating-point arithmetic for the division to avoid quantization errors in the DC term [G].

## Operating characteristics
- Time Complexity: $O(N)$, where $N$ is the number of Gaussians, as each Gaussian's coefficients are computed independently.
- Memory Complexity: $O(N)$, storing 27 floats per Gaussian.
- Strengths: Simple, fast, and provides a valid starting point for view-dependent optimization.
- Limitations: Does not account for view-dependent effects initially; relies on optimization to learn higher-order terms.
- When to use: Standard initialization for most Gaussian Splatting applications where view-dependent effects are learned during training.
- When not to use: If pre-computed view-dependent data is available or if a specific static color is desired without optimization.

## Background
Originated in the context of 3D Gaussian Splatting optimization, this method initializes the spherical harmonic coefficients to enable view-dependent rendering. It is based on the standard practice of setting the DC term to the average color and higher-order terms to zero [S1, unofficial].
