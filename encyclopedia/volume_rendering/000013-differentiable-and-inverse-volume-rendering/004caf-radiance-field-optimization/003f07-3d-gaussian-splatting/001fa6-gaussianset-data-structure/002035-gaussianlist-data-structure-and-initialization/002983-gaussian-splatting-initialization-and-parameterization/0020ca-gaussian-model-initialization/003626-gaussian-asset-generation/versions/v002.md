# Gaussian Asset Generation

Also called: Gaussian Splatting Asset Generation, PLY generation for SplatNode, Rainbow Sphere Splat Asset, Synthetic Gaussian Asset Generation

## Overview
Gaussian Asset Generation is a deterministic method for creating a reproducible 3D Gaussian Splatting PLY asset, specifically a dense "rainbow sphere" shell, without using randomness or external data [S1, unofficial]. It solves the problem of needing a standardized, visually recognizable test asset for validating parsers and renderers (such as SceneView's PlyParser) by generating a synthetic point cloud with specific color, scale, opacity, and rotation parameters [S1, unofficial]. It differs from other initialization methods like [Gaussian Model Initialization](2349-gaussian-model-initialization.md) or [DreamGaussian](5998-dreamgaussian.md) by being purely synthetic and deterministic, rather than derived from input images or learned optimization [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** Number of Gaussians $n$ (default 8000), output file path, radius $R$ (default 0.5), target opacity $p$ (default 0.80), target scale $\sigma$ (default 0.012) [S1, unofficial].
- **Outputs:** A binary PLY file (`binary_little_endian 1.0`) containing $n$ vertices [S1, unofficial].

**Data Structures:**
The PLY header defines an element `vertex` with 14 `float32` properties in this exact order:
1. `x`, `y`, `z` (position)
2. `f_dc_0`, `f_dc_1`, `f_dc_2` (DC spherical harmonic coefficients) [S1, unofficial]
3. `opacity` (logit-encoded) [S1, unofficial]
4. `scale_0`, `scale_1`, `scale_2` (log-encoded) [S1, unofficial]
5. `rot_0`, `rot_1`, `rot_2`, `rot_3` (quaternion, scalar-first $w,x,y,z$) [S1, unofficial]
The binary record is packed using `struct.Struct("<14f")` (little-endian, 14 floats) [S1, unofficial].

**Parameters:**
- $SH\_C0 = 0.28209479177387814$ [S1, unofficial].
- Golden angle $ga = \pi (3 - \sqrt{5})$ [S1, unofficial].
- Clamping bounds for opacity: $[10^{-4}, 1 - 10^{-4}]$ [S1, unofficial].

**Steps:**
1. **Generate Positions:** Distribute $n$ points on a sphere of radius $R$ using the Fibonacci sphere algorithm [S1, unofficial]. For each $i \in [0, n-1]$:
   $$ y_i = 1.0 - \frac{i}{n-1} \times 2.0 $$
   $$ r_i = \sqrt{\max(0.0, 1.0 - y_i^2)} $$
   $$ \theta_i = ga \times i $$
   $$ x_i = \cos(\theta_i) \times r_i \times R $$
   $$ z_i = \sin(\theta_i) \times r_i \times R $$
   $$ y_i = y_i \times R $$
2. **Calculate Color (f_dc):**
   - Compute azimuth: $\phi = \operatorname{atan2}(z_i, x_i)$ [S1, unofficial].
   - Compute hue: $h = \frac{\phi + \pi}{2\pi}$ [S1, unofficial].
   - Compute elevation: $e = \frac{y_i}{R}$ (normalized to $[-1, 1]$) [S1, unofficial].
   - Compute value: $v = 0.72 + 0.18 \times e$ [S1, unofficial].
   - Set saturation: $s = 0.95$ [S1, unofficial].
   - Convert HSV $(h, s, v)$ to sRGB $(c_r, c_g, c_b)$ using standard `colorsys.hsv_to_rgb` [S1, unofficial].
   - Convert sRGB to linear RGB $(c_{r,lin}, c_{g,lin}, c_{b,lin})$ using the sRGB gamma function [S1, unofficial]:
     $$ c_{lin} = \begin{cases} \frac{c}{12.92} & \text{if } c \le 0.04045 \\ \left(\frac{c + 0.055}{1.055}\right)^{2.4} & \text{otherwise} \end{cases} $$
   - Encode to $f\_dc$:
     $$ f\_dc_k = \frac{c_{k,lin} - 0.5}{SH\_C0} \quad \text{for } k \in \{r, g, b\} $$
3. **Encode Opacity:**
   - Clamp target opacity $p$ to $[10^{-4}, 1 - 10^{-4}]$ [S1, unofficial].
   - Compute logit:
     $$ \text{opacity}_{stored} = \ln\left(\frac{p}{1 - p}\right) $$
4. **Encode Scale:**
   - Compute natural log of target scale $\sigma$:
     $$ \text{scale}_{stored} = \ln(\sigma) $$
   - Assign to all three axes: $scale\_0 = scale\_1 = scale\_2 = \text{scale}_{stored}$ [S1, unofficial].
5. **Encode Rotation:**
   - Set identity quaternion in scalar-first order: $rot\_0 = 1.0, rot\_1 = 0.0, rot\_2 = 0.0, rot\_3 = 0.0$ [S1, unofficial].
6. **Write PLY:**
   - Write header with `ply`, `format binary_little_endian 1.0`, `element vertex n`, and property definitions [S1, unofficial].
   - Write binary body by packing the 14 floats for each vertex [S1, unofficial].

**Pseudocode:**
```python
import math
import struct
import colorsys

SH_C0 = 0.28209479177387814

def srgb_to_linear(c: float) -> float:
    if c <= 0.04045:
        return c / 12.92
    return ((c + 0.055) / 1.055) ** 2.4

def logit(p: float) -> float:
    p = min(max(p, 1e-4), 1.0 - 1e-4)
    return math.log(p / (1.0 - p))

def generate_gaussian_asset(n: int, out_path: str, radius: float = 0.5,
                            sigma: float = 0.012, opacity: float = 0.80):
    if n < 2:
        raise ValueError("n must be at least 2 to avoid division by zero in Fibonacci sphere distribution")
    ga = math.pi * (3.0 - math.sqrt(5.0))
    ln_sigma = math.log(sigma)
    logit_opacity = logit(opacity)

    header = (
        "ply\n"
        "format binary_little_endian 1.0\n"
        f"element vertex {n}\n"
        "property float x\n"
        "property float y\n"
        "property float z\n"
        "property float f_dc_0\n"
        "property float f_dc_1\n"
        "property float f_dc_2\n"
        "property float opacity\n"
        "property float scale_0\n"
        "property float scale_1\n"
        "property float scale_2\n"
        "property float rot_0\n"
        "property float rot_1\n"
        "property float rot_2\n"
        "property float rot_3\n"
        "end_header\n"
    )

    rec = struct.Struct("<14f")
    body = b""

    for i in range(n):
        y_norm = 1.0 - (i / float(n - 1)) * 2.0
        r_norm = math.sqrt(max(0.0, 1.0 - y_norm * y_norm))
        theta = ga * i

        x = math.cos(theta) * r_norm * radius
        y = y_norm * radius
        z = math.sin(theta) * r_norm * radius

        azimuth = math.atan2(z, x)
        hue = (azimuth + math.pi) / (2.0 * math.pi)
        elevation = y_norm
        val = 0.72 + 0.18 * elevation
        sat = 0.95

        sr, sg, sb = colorsys.hsv_to_rgb(hue, sat, val)
        r_lin = srgb_to_linear(sr)
        g_lin = srgb_to_linear(sg)
        b_lin = srgb_to_linear(sb)

        fdc0 = (r_lin - 0.5) / SH_C0
        fdc1 = (g_lin - 0.5) / SH_C0
        fdc2 = (b_lin - 0.5) / SH_C0

        body += rec.pack(
            x, y, z,
            fdc0, fdc1, fdc2,
            logit_opacity,
            ln_sigma, ln_sigma, ln_sigma,
            1.0, 0.0, 0.0, 0.0
        )

    with open(out_path, "wb") as f:
        f.write(header.encode("ascii"))
        f.write(body)
```

**Edge Cases and Pitfalls:**
- **Color Space:** Colors must be converted from sRGB to linear RGB before encoding into $f\_dc$ because the renderer applies a linear-to-sRGB display transform [S1, unofficial].
- **Activation Inversion:** The parser expects inverted activations. Scales are stored as $\ln(\sigma)$, $f\_dc$ as $(c_{lin}-0.5)/SH\_C0$, opacity as $\logit(p)$, and rotation as scalar-first $w,x,y,z$ [S1, unofficial].
- **Division by Zero:** The Fibonacci sphere formula uses $n-1$ in the denominator. If $n=1$, this causes a division by zero. The method assumes $n > 1$ [S1, G, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Performance:** The generation is instantaneous for typical $n$ (e.g., 8000 points) as it involves no optimization or external data loading [S1, unofficial].
- **Strengths:** Deterministic, reproducible, no external dependencies, small file size, easy to debug [S1, unofficial].
- **Limitations:** Only generates a synthetic sphere [S1, unofficial].
- **When to use:** For testing parsers, validating rendering pipelines, and creating demo assets [S1, unofficial].
- **When not to use:** For training or initializing models on real data [S1, unofficial].

## Background
Gaussian Asset Generation was introduced as part of the SceneView project to provide a standardized synthetic asset for testing the `SplatNode` and `PlyParser` components [S1, unofficial]. It was developed to ensure that the demo asset (`rainbow_sphere.ply`) is fully reproducible and does not rely on random seeds or external image data [S1, unofficial]. The method is specific to the INRIA binary PLY layout used by SceneView [S1, unofficial].
