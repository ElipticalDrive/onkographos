# Spherical Harmonics Initialization


## Overview
Spherical Harmonics Initialization sets the initial view-dependent appearance coefficients for 3D Gaussians in Gaussian Splatting by assigning input RGB colors to the zeroth-order (DC) spherical harmonic term [S1, unofficial]. It differs from [Spherical Harmonics Evaluation](3848-spherical-harmonics-evaluation.md), which computes full view-dependent color from existing coefficients, by establishing the baseline static color representation before training introduces higher-order view-dependent variations [S5, S7, unofficial].

## How it works
**Inputs and Outputs:**
- Input: An array of $N$ RGB color values, where each color is a vector $\mathbf{C} = [R, G, B]^T$ with values typically in the range $[0, 1]$.
- Output: A tensor of spherical harmonic coefficients for $N$ Gaussians.

**Data Structures:**
The coefficients are stored in a tensor of shape $(N, 27)$, representing $N$ Gaussians, 3 RGB channels, and 9 spherical harmonic coefficients (degree $L=3$). The coefficients are laid out such that for each Gaussian and channel, the first 9 elements correspond to the SH coefficients $c_{0}$ through $c_{8}$, ordered by increasing degree and order.

**Steps:**
1. Allocate a zero tensor $\mathbf{S}$ of shape $(N, 3, 9)$ to hold the spherical harmonic coefficients for all $N$ Gaussians and 3 color channels.
2. For each Gaussian $i$ from $0$ to $N-1$:
   a. Retrieve the input RGB color $\mathbf{C}_i = [R_i, G_i, B_i]^T$.
   b. Compute the zeroth-order (DC) coefficient $c_{0,i}$ for each channel using the normalization constant $\alpha = 0.28209479177387814$:
      $$ c_{0,i} = \frac{C_{i, \text{channel}}}{\alpha} $$
   c. Assign $c_{0,i}$ to the coefficient index 0 in the tensor $\mathbf{S}[i, \text{channel}, :]$.
   d. Leave coefficients at indices 1 through 8 as zero.
3. Reshape $\mathbf{S}$ from shape $(N, 3, 9)$ to $(N, 27)$ by flattening the last two dimensions.

**Formulas:**
The zeroth-order spherical harmonic basis function is a constant. The normalization constant $\alpha$ is derived from the integral of the basis function over the sphere:
$$ \alpha = \frac{1}{\sqrt{4\pi}} \approx 0.28209479177387814 $$
The DC coefficient $c_0$ for a given channel is calculated as:
$$ c_0 = \frac{\text{RGB}}{\alpha} $$
where $\text{RGB}$ is the input color value for that channel.

**Parameters:**
- $\alpha = 0.28209479177387814$: Normalization constant for the zeroth-order spherical harmonic basis function [S1, unofficial].

**Edge Cases and Pitfalls:**
- Precision: Ensure floating-point precision is sufficient to handle the division by $\alpha$ without significant loss, though standard float32 is typically adequate.
- Boundaries: Input RGB values should be normalized to $[0, 1]$. If input values are outside this range, the resulting coefficients may lead to unrealistic color intensities during rendering.
- Degenerate Input: If $N=0$, the output tensor is empty.

**Pseudocode:**
```python
import numpy as np

def initialize_sh(rgb_colors: np.ndarray) -> np.ndarray:
    """
    Initialize spherical harmonic coefficients for 3D Gaussian splatting.
    
    Args:
        rgb_colors: Array of shape (N, 3) containing RGB values in [0, 1].
        
    Returns:
        Array of shape (N, 27) containing SH coefficients.
    """
    N = rgb_colors.shape[0]
    # Allocate zero tensor of shape (N, 3, 9)
    sh_coeffs = np.zeros((N, 3, 9), dtype=np.float32)
    
    # Normalization constant for zeroth-order SH
    alpha = 0.28209479177387814
    
    # Assign scaled RGB values to the DC coefficient index (0)
    # rgb_colors has shape (N, 3), sh_coeffs[:, :, 0] has shape (N, 3)
    sh_coeffs[:, :, 0] = rgb_colors / alpha
    
    # Flatten the last two dimensions to produce a tensor of shape (N, 27)
    sh_coeffs_flat = sh_coeffs.reshape(N, 27)
    
    return sh_coeffs_flat
```

## Subtopics

### [Splat Initialization from Normalized Coordinates](3595-splat-initialization-from-normalized-coordinates.md)
This method initializes a single 3D Gaussian splat (spherical harmonic degree 3) from normalized input coordinates, mapping the unit cube $[-0.5, 0.5]^3$ to a scene of a specific physical size. It sets uniform scale, identity rotation, and full opacity, while deriving the zeroth-order spherical harmonic (DC) color from the normalized position itself, with a special case for the corner point $(-0.5, -0.5, -0.5)$. It differs from [Spherical Harmonics Initialization](3163-spherical-harmonics-initialization.md) by tying the initial color to the spatial coordinate rather than an external RGB value, and from [Spherical Harmonics Evaluation](3848-spherical-harmonics-evaluation.md) by being an initialization routine rather than a rendering step.

### Appearance Feature Initialization and Training Schedule
This variant integrates spherical harmonics initialization into a staged training schedule. Scale and rotation parameters are trained from the initial iteration. Appearance features are introduced at iteration 15K, where static appearance features are initialized using the spherical harmonics DC coefficients trained up to that point, and view-dependent appearance features are initialized as zero vectors. At iteration 20K, a simplification process incorporating local distinctiveness (LD) scoring with factor $\lambda=2$ is run. From iteration 29K to 30K, Sub-Vector Quantization (SVQ) is applied to per-Gaussian features using fixed K-means indices and optimized codebooks. This approach differs from standard initialization by dynamically updating the SH-based appearance features during training and applying quantization at the end.

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of Gaussians, as each Gaussian's DC coefficient is computed independently.
- **Memory Complexity:** $O(N)$, storing 27 coefficients per Gaussian.
- **Measured Performance:** Experiments using this initialization within the Mini-Splatting framework were conducted on an NVIDIA RTX 4090 [S2].
- **Strengths:** Simple, fast, and provides a reasonable starting point for color representation.
- **Limitations:** Does not account for view-dependent effects initially; higher-order coefficients must be learned during training.
- **When to use:** Standard initialization for Gaussian Splatting when RGB colors are available.
- **When not to use:** When view-dependent effects are critical from the start or when spatially correlated color initialization is preferred.

## Background
Spherical Harmonics Initialization is a core component of the 3D Gaussian Splatting method, introduced by Kerbl et al. in 2023 [S1, unofficial]. It leverages the mathematical properties of spherical harmonics to represent view-dependent appearance. The zeroth-order term represents the diffuse (DC) component of the color, which is invariant to viewing direction. This initialization strategy was adopted to provide a stable starting point for the optimization process, allowing higher-order terms to capture specularities and other view-dependent phenomena during training [S5, S7, unofficial].
