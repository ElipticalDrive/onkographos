# Spherical Harmonics Initialization
## Overview
Spherical Harmonics Initialization sets the initial view-dependent color representation for 3D Gaussians by populating only the zeroth-order (DC) spherical harmonic coefficients with the input RGB colors, while leaving higher-order coefficients at zero [S1, unofficial]. It provides a valid, differentiable starting point for color optimization in 3D Gaussian Splatting, focusing exclusively on color parameterization rather than the geometric pose and scale distribution handled by sibling methods like [Angle-pose Cuboid Uniform Initialization (ACUI)](4503-angle-pose-cuboid-uniform-initialization-acui.md) [G].

## How it works
**Inputs:**
- $N$: Number of 3D Gaussians.
- $\text{RGB} \in [0, 1]^3$: The initial RGB color for each Gaussian [S1, unofficial].

**Outputs:**
- $\mathbf{C} \in \mathbb{R}^{N \times 27}$: A tensor containing the initialized spherical harmonic coefficients for all Gaussians [S1, unofficial].

**Data Structures:**
- The SH coefficients are stored in a contiguous tensor with a shape of $(N, 3, 9)$ before flattening, resulting in $(N, 27)$ [S1, unofficial]. For each Gaussian, the coefficients for the three color channels (Red, Green, Blue) are grouped, where index 0 corresponds to the DC term and indices 1–8 correspond to higher-order terms [S1, unofficial].

**Steps:**
1. **Allocation:** Create a zero-filled tensor $\mathbf{C}$ of shape $(N, 3, 9)$ [S1, unofficial].
2. **DC Coefficient Calculation:** For each Gaussian $i$ and each color channel $c \in \{R, G, B\}$:
   - Let $v$ be the input color value for channel $c$ of Gaussian $i$.
   - Compute the DC coefficient $c_{0,i,c}$ using the formula:
     $$ c_{0} = \frac{\text{RGB}}{0.28209479177387814} $$
     where $c_0$ is the DC SH coefficient and RGB is the input color [S1, unofficial].
   - Assign $c_{0,i,c}$ to the coefficient at index 0 for channel $c$ in $\mathbf{C}$ [S1, unofficial].
3. **Flattening:** Flatten the last two dimensions of $\mathbf{C}$ from $(N, 3, 9)$ to $(N, 27)$ to produce the final output tensor [S1, unofficial].

**Parameters:**
- $0.28209479177387814$: Normalization constant for the zeroth-order spherical harmonic basis function [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Higher-Order Coefficients:** All coefficients with index $>0$ remain zero intentionally, as higher-order terms are optimized during training [S1, unofficial].
- **Color Range:** The input RGB values are assumed to be in the range $[0, 1]$ [G].
- **Precision:** The division by the normalization constant is a simple scaling operation; standard floating-point precision is sufficient [G].

**Pseudocode:**
```python
import numpy as np

def initialize_sh(rgb_colors: np.ndarray) -> np.ndarray:
    """
    Initialize spherical harmonic coefficients for 3D Gaussian splatting.
    
    Args:
        rgb_colors: Array of shape (N, 3) containing RGB values in [0, 1].
        
    Returns:
        Array of shape (N, 27) containing SH coefficients.
    """
    N = rgb_colors.shape[0]
    # Allocate zero tensor of shape (N, 3, 9)
    sh_coeffs = np.zeros((N, 3, 9))
    
    # Normalization constant for zeroth-order SH basis function
    k = 0.28209479177387814
    
    # Assign scaled RGB values to the DC coefficient index (0) for all channels
    sh_coeffs[:, :, 0] = rgb_colors / k
    
    # Flatten the last two dimensions to produce a tensor of shape (N, 27)
    sh_coeffs_flat = sh_coeffs.reshape(N, 27)
    
    return sh_coeffs_flat
```

## Subtopics

### Splat Initialization from Normalized Coordinates
This variant initializes a single splat object with specific geometric and color properties based on normalized coordinates [S2, unofficial]. It creates a splat object, sets position coordinates by scaling normalized inputs $(npx, npy, npz)$ with a constant `size`, sets uniform scale using a constant `baseScale`, sets an identity rotation quaternion $(0.0, 0.0, 0.0, 1.0)$, and sets opacity by converting a fixed alpha value of 1.0 [S2, unofficial]. Degree-0 spherical harmonic coefficients are set based on normalized coordinates, applying a special case for the exact point $(-0.5, -0.5, -0.5)$ which uses 0.1 instead of the coordinate offset; otherwise, the coefficient is computed as `colorToDirectCurrent(npx + 0.5)` for Red, `npy + 0.5` for Green, and `npz + 0.5` for Blue [S2, unofficial]. The fully configured splat is then appended to the target list [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of Gaussians, as the operation involves a single pass to compute the DC coefficient [G].
- **Memory Complexity:** $O(N)$, storing 27 coefficients per Gaussian [G].
- **Performance:** The initialization is extremely fast and negligible compared to the training time, performed once at the start of the optimization process [G].
- **Strengths:** Simple, deterministic, and provides a stable starting point for color optimization without requiring complex color estimation from sparse point clouds [G].
- **Limitations:** Does not account for view-dependent effects initially, as only the DC term is set; higher-order terms must be learned during training [G].
- **When to use:** Standard initialization for 3D Gaussian Splatting when no prior color information is available or when a simple baseline is desired [G].
- **When not to use:** If high-fidelity view-dependent effects are critical from the start, other methods might be preferred, though SH initialization remains the standard starting point [G].

## Background
Spherical Harmonics Initialization is a core component of the 3D Gaussian Splatting pipeline [S1, unofficial]. It leverages the mathematical properties of spherical harmonics to represent view-dependent colors in a compact and differentiable manner [G]. The zeroth-order term corresponds to the average color (DC component), which is sufficient for initial setup [G]. The method has become a standard practice in the field due to its simplicity and effectiveness [G].
