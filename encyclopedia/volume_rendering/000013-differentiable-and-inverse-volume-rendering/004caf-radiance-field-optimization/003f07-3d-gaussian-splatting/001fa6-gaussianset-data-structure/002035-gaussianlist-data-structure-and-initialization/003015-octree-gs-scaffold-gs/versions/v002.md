# Octree-GS / Scaffold-GS


## Overview
Octree-GS and Scaffold-GS are hierarchical level-of-detail (LoD) methods that anchor scene content to a sparse voxel grid or octree structure, using the grid as a scaffold to allocate Gaussians only in occupied regions [S1, unofficial]. This approach naturally adapts to view distance and significantly improves memory efficiency compared to flat Gaussian lists [S1, unofficial]. Unlike sibling methods that rely on population control or simple parameterization, these methods explicitly model spatial hierarchy to enable large size reduction and better generalization to extrapolated views [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of initial 3D Gaussians (from [GaussianList Data Structure and Initialization](2214-gaussianlist-data-structure-and-initialization.md)) or scene geometry [S1, unofficial].
*   **Output:** A hierarchical data structure (sparse voxel grid or octree) where nodes contain merged Gaussian parameters or neural decoders [S2, unofficial].

**Data Structures:**
1.  **Scaffold-GS:** Uses a sparse voxel grid. Each occupied voxel (anchor) is associated with a neural decoder that generates Gaussian parameters on the fly [S2, unofficial]. Exact field layouts and bit packing sizes are Not given in the sources.
2.  **Octree-GS:** Builds an octree over the scene. Each node stores a "merged Gaussian" that summarizes the radiance and opacity of its children [S1, unofficial]. Exact field layouts and bit packing sizes are Not given in the sources.

**Algorithm Steps:**
1.  **Scaffolding/Tree Construction:** Construct a sparse voxel grid representing the scene's occupied space for Scaffold-GS, or build an octree hierarchy for Octree-GS [S1, unofficial].
2.  **Anchor Association:** Allocate Gaussians only to occupied regions defined by the scaffold or octree nodes [S1, unofficial]. In Scaffold-GS, associate a neural decoder with each anchor [S2, unofficial].
3.  **Hierarchical Rendering:** Traverse the hierarchy based on view distance [S1, unofficial]. Render only the relevant Level-of-Detail (LoD) [S2, unofficial]. For Octree-GS, render the merged Gaussian at the appropriate node depth [S1, unofficial].

**Formulas:**
Not given in the sources. The core mechanism relies on spatial partitioning and hierarchical traversal rather than a single closed-form rendering equation distinct from standard Gaussian splatting [S1, unofficial].

**Parameters:**
*   **Voxel Grid Resolution / Octree Depth:** Not given in the sources.
*   **LoD Threshold:** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Extrapolation:** These methods show better generalization to extrapolated views compared to flat representations [S2, unofficial].
*   **Memory:** Significant size reduction is achieved, but the overhead of the hierarchy structure must be managed [S1, unofficial].

## Subtopics

### Context-GS
A method that adopts context-aware approaches that explicitly model hierarchical relationships among anchors to enhance representational capacity, building on anchor-based representation [S1, unofficial]. It improves upon basic Scaffold-GS by considering the context of neighboring anchors [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Real-time rendering is supported for very large datasets by storing a multi-resolution pyramid of Gaussians [S1, unofficial].
*   **Memory Complexity:** Achieves up to 99% reduction in memory usage at far distances [S2, unofficial]. Large size reduction is a key feature [S2, unofficial].
*   **Performance:** Enables efficient rendering by dynamically selecting appropriate detail levels [S1, unofficial].
*   **Strengths:** High memory efficiency, natural LoD adaptation, better generalization to extrapolated views [S1, unofficial][S2, unofficial].
*   **Limitations:** Complexity of hierarchy management; potential overhead in neural decoding for Scaffold-GS [S2, unofficial].
*   **When to use:** Large-scale scenes, streaming applications, or when memory is constrained [S1, unofficial][S2, unofficial].
*   **When not to use:** Small scenes where flat representation is sufficient and simpler to implement [S1, unofficial].

## Background
Originating from research in 2024 (SIGGRAPH), these methods address the scalability of 3D Gaussian Splatting for large scenes [S2, unofficial]. Scaffold-GS and Octree-GS were developed to avoid rendering millions of far-away, sub-pixel Gaussians by employing multi-resolution structures [S1, unofficial]. They represent a shift from flat Gaussian lists to hierarchical, anchor-based representations [S1, unofficial][S2, unofficial].
