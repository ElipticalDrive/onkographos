# Antimatter15 .splat File Parsing

Also called: Antimatter15 .splat file reader, Antimatter15 Splat Reader, Lazy ChunkSource for .splat

## Overview
This method implements a lazy `ChunkSource` for reading Antimatter15 `.splat` files, which are flat arrays of 32-byte binary records with no header [S1]. It decodes position, geometric (rotation, scale, opacity), and DC-only color layers on demand, supporting both contiguous chunk reads and scatter-gather reads [S1]. Unlike formats with spherical harmonic coefficients, `.splat` files carry no SH data, so the color layer is DC-only (constant per gaussian) [S1].

## How it works
**Inputs and Outputs:**
- Input: A file path or byte stream representing an Antimatter15 `.splat` file [S1].
- Output: A `ChunkSource` object that provides decoded Gaussian properties (position, geometric, color) via `read()` requests [S1].

**Data Structures:**
- **Record Layout (32 bytes):**
  - `position`: 3 × `Float32` at offsets 0, 4, 8 [S1].
  - `scale`: 3 × `Float32` at offsets 12, 16, 20 [S1].
  - `color`: 4 × `uint8` at offsets 24, 25, 26, 27 [S1].
  - `rotation`: 4 × `uint8` at offsets 28, 29, 30, 31 [S1].
- **Constants:**
  - `BYTES_PER_SPLAT = 32` [S1].
  - `SH_C0 = 0.28209479177387814` [S1].
  - `EPSILON = 1e-6` [S1].

**Steps:**
1. **Initialization:**
   - Check file size. If size is undefined, read all data into a resident buffer; otherwise use `source.size` [S1].
   - Validate that `size` is a multiple of 32 bytes and non-zero [S1].
   - Calculate `numGaussians = size / 32` [S1].
   - Calculate `chunkSize` from `pool.chunkSize` [S1]. Calculate `numChunks = max(1, ceil(numGaussians / chunkSize))` [S1].
   - Define available layers as a Set containing `'position'`, `'geometric'`, `'color'` [S1].
   - Define layouts: `position` (stride `POSITION_STRIDE`, fields `positionFields()`), `geometric` (stride `GEOMETRIC_STRIDE`, fields `geometricFields()`), `color` (stride `colorStride(0)`, fields `colorFields(0)`) [S1].
2. **Read Request Handling:**
   - On `read` request: if `lod != 0`, throw error [S1].
   - Extract `position`, `geometric`, `color` `Float32Arrays` from request [S1]. If none requested, return [S1].
   - **Gather Read Path:** If request has indices, sort slots by source row to coalesce reads [S1].
   - Iterate over `gatherRuns`, calculating `firstByte` and `byteLen` [S1].
   - If resident, use `subarray`; otherwise allocate/reuse `gatherScratch` and call `readExact` [S1].
   - Call `decode` with `srcRec` mapping [S1].
3. **Decoding (Contiguous Chunk Loop):**
   - Iterate `t` from 0 to `n-1` [S1].
   - Calculate byte offset `o = srcRec(t) * 32` [S1].
   - Calculate destination slot `d = dstRow(t)` [S1].
   - Call `decodePosition`, `decodeGeometric`, `decodeColor` if respective layers are requested [S1].

**Decoding Formulas:**
- **Position:** Read 3 floats from `DataView` at offset `o` with little-endian byte order [S1].
- **Rotation:**
  - Read 4 `uint8`s at offsets `o+28` to `o+31` [S1].
  - Map to `[-1, 1]` via $q_i = \frac{u8_i}{255} \times 2 - 1$ [S1].
  - Normalize quaternion: $q_{norm} = \frac{q}{\|q\|}$ [S1].
  - If $\|q\| = 0$, set to identity $(1, 0, 0, 0)$ [S1].
- **Scale:**
  - Read 3 floats from `DataView` at offsets `o+12`, `o+16`, `o+20` [S1].
  - Apply log: $s_i = \log(scale_i)$ [S1].
- **Opacity:**
  - Read `uint8` at `o+27` [S1].
  - Clamp to $[\epsilon, 1-\epsilon]$ where $\epsilon = 10^{-6}$ [S1].
  - Apply inverse sigmoid (logit): $\alpha = \log\left(\frac{\alpha_{clamp}}{1 - \alpha_{clamp}}\right)$ [S1].
- **Color:**
  - Read 3 `uint8`s at offsets `o+24`, `o+25`, `o+26` [S1].
  - Map to $[-0.5, 0.5]$ via $c_i = \frac{u8_i}{255} - 0.5$ [S1].
  - Divide by `SH_C0`: $C_i = \frac{c_i}{SH\_C0}$ [S1].

**Pseudocode:**
```python
import math
import struct

BYTES_PER_SPLAT = 32
SH_C0 = 0.28209479177387814
EPSILON = 1e-6

def decode_splat_record(data: bytes, offset: int) -> dict:
    """Decode a single 32-byte splat record according to the .splat layout."""
    # Position: 3 floats at 0, 4, 8 (little-endian)
    x, y, z = struct.unpack_from('<fff', data, offset)

    # Scale: 3 floats at 12, 16, 20
    sx, sy, sz = struct.unpack_from('<fff', data, offset + 12)
    sx = math.log(sx)
    sy = math.log(sy)
    sz = math.log(sz)

    # Opacity: 1 uint8 at 27
    alpha_u8 = data[offset + 27]
    alpha_clamped = max(EPSILON, min(1.0 - EPSILON, alpha_u8 / 255.0))
    opacity = math.log(alpha_clamped / (1.0 - alpha_clamped))

    # Rotation: 4 uint8 at 28, 29, 30, 31
    qx_u8, qy_u8, qz_u8, qw_u8 = data[offset + 28], data[offset + 29], data[offset + 30], data[offset + 31]
    qx = (qx_u8 / 255.0) * 2.0 - 1.0
    qy = (qy_u8 / 255.0) * 2.0 - 1.0
    qz = (qz_u8 / 255.0) * 2.0 - 1.0
    qw = (qw_u8 / 255.0) * 2.0 - 1.0
    norm = math.sqrt(qx**2 + qy**2 + qz**2 + qw**2)
    if norm == 0:
        qx, qy, qz, qw = 1.0, 0.0, 0.0, 0.0
    else:
        qx /= norm
        qy /= norm
        qz /= norm
        qw /= norm

    # Color: 3 uint8 at 24, 25, 26
    r_u8, g_u8, b_u8 = data[offset + 24], data[offset + 25], data[offset + 26]
    r = ((r_u8 / 255.0) - 0.5) / SH_C0
    g = ((g_u8 / 255.0) - 0.5) / SH_C0
    b = ((b_u8 / 255.0) - 0.5) / SH_C0

    return {
        'position': (x, y, z),
        'scale': (sx, sy, sz),
        'opacity': opacity,
        'rotation': (qx, qy, qz, qw),
        'color': (r, g, b)
    }

class AntimatterSplatSource:
    def __init__(self, file_data: bytes, chunk_size: int = 1000):
        self.resident_data = file_data
        self.size = len(file_data)
        if self.size == 0 or self.size % BYTES_PER_SPLAT != 0:
            raise ValueError("File size must be a non-zero multiple of 32 bytes")
        self.num_gaussians = self.size // BYTES_PER_SPLAT
        self.chunk_size = chunk_size
        self.num_chunks = max(1, math.ceil(self.num_gaussians / self.chunk_size))
        self.available_layers = {'position', 'geometric', 'color'}

    def read(self, chunk_idx: int, indices: list = None, lod: int = 0):
        if lod != 0:
            raise ValueError("Only LOD 0 is supported")
        if indices is None:
            # Contiguous chunk read
            start = chunk_idx * self.chunk_size
            end = min(start + self.chunk_size, self.num_gaussians)
            n = end - start
            dst_position = [None] * n
            dst_geometric = [None] * n
            dst_color = [None] * n
            src_rec = list(range(start, end))

            # Decode loop
            for t in range(n):
                o = src_rec[t] * BYTES_PER_SPLAT
                d = t
                record = decode_splat_record(self.resident_data, o)
                if 'position' in self.available_layers:
                    dst_position[d] = record['position']
                if 'geometric' in self.available_layers:
                    dst_geometric[d] = (record['scale'], record['opacity'], record['rotation'])
                if 'color' in self.available_layers:
                    dst_color[d] = record['color']
            return dst_position, dst_geometric, dst_color
        else:
            # Scatter-gather read path
            sorted_indices = sorted(enumerate(indices), key=lambda x: x[1])
            gather_runs = []
            current_run = [sorted_indices[0]]
            for i in range(1, len(sorted_indices)):
                if sorted_indices[i][1] == sorted_indices[i-1][1] + 1:
                    current_run.append(sorted_indices[i])
                else:
                    gather_runs.append(current_run)
                    current_run = [sorted_indices[i]]
            gather_runs.append(current_run)

            dst_position = [None] * len(indices)
            dst_geometric = [None] * len(indices)
            dst_color = [None] * len(indices)

            for run in gather_runs:
                first_byte = run[0][1] * BYTES_PER_SPLAT
                byte_len = len(run) * BYTES_PER_SPLAT
                chunk_data = self.resident_data[first_byte:first_byte + byte_len]

                for j, (_, src_idx) in enumerate(run):
                    record = decode_splat_record(chunk_data, j * BYTES_PER_SPLAT)
                    dst_position[src_idx] = record['position']
                    dst_geometric[src_idx] = (record['scale'], record['opacity'], record['rotation'])
                    dst_color[src_idx] = record['color']
            return dst_position, dst_geometric, dst_color
```

## Subtopics

### [Splatv Binary File Format Parser](7762-splatv-binary-file-format-parser.md)
The Splatv Binary File Format Parser is a method for loading `.splatv` files, a custom binary container format used by `gsplat.js` to store 3D Gaussian Splatting scene data. It solves the problem of parsing a structured binary stream that combines a magic header, JSON-encoded camera metadata, and binary splat data chunks into a usable scene graph. It is distinct from the Antimatter15 `.splat` parser because it handles a multi-chunk container with explicit type markers and embedded JSON metadata, rather than a flat, headerless array of records.

## Operating characteristics
- **Time Complexity:** Not given in the sources [S1].
- **Memory Complexity:** Not given in the sources [S1].
- **Performance:** Lazy loading reduces initial load time by deferring decoding until requested [S1].
- **Strengths:** Supports contiguous chunk reads and scatter-gather reads for efficient random access [S1].
- **Limitations:** Color is DC-only due to lack of spherical harmonic data [S1].
- **When to use:** When on-demand decoding and scatter-gather access are required [S1].
- **When not to use:** When full scene access is required and memory is sufficient, or when SH coefficients are needed [S1].

## Background
The Antimatter15 `.splat` format is a simple, headerless binary format for storing 3D Gaussian Splatting data [S1]. The format stores position, scale, rotation, opacity, and color in a fixed 32-byte record [S1].
