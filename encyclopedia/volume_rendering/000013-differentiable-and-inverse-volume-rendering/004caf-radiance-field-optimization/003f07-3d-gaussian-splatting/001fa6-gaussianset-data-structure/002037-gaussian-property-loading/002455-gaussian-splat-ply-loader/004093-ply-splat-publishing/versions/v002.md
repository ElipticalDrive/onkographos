# PLY Splat Publishing

Also called: PLY Splat Loading and Publishing

## Overview
PLY Splat Publishing is a process that loads 3D Gaussian Splat data from a PLY file, reconstructs full Gaussian parameters (covariance matrices and spherical harmonics), and publishes them as a ROS `SplatArray` message for visualization [S1, unofficial]. It builds on [Gaussian Splat PLY Loader](3254-gaussian-splat-ply-loader.md) by handling the specific ROS message serialization and QoS configuration required for real-time rendering pipelines [S1, unofficial].

## How it works
**Inputs:** A PLY file path (`ply_path`), a target spherical harmonics degree (`sh_degree`), a ROS timestamp (`stamp`), and a frame ID (`frame_id`, default 'map') [S1, unofficial].
**Outputs:** A ROS 2 `SplatArray` message published to the topic `/gaussian_splats` [S1, unofficial].

### Data Structures
The output is a `SplatArray` message containing a list of `Splat` messages [S1, unofficial]. Each `Splat` contains: `pose` (`PoseWithCovarianceStamped` with position $x,y,z$, orientation $w,x,y,z$ quaternion, plus covariance), `opacity` (`uint8`), `harmonics_deg` (`int`), and `spherical_harmonics` (list of floats) [S1, unofficial]. Spherical harmonics data is stored as a concatenated array of shape $(n, 3(1+\text{nrc\_to\_use}))$ where $\text{nrc\_to\_use}$ is derived from the SH degree [S1, unofficial].

### Steps
1. **Load PLY Data:** Read PLY vertices [S1, unofficial]. Identify properties starting with `f_rest_` to count `nrc` (rest SH coefficients per channel) [S1, unofficial].
2. **Determine SH Degree:** Calculate `file_degree`: 3 if `nrc >= 15`, 2 if `nrc >= 8`, 1 if `nrc >= 3`, else 0 [S1, unofficial]. Calculate `actual_degree = min(sh_degree, file_degree)` [S1, unofficial]. Calculate `nrc_to_use = (actual_degree + 1)^2 - 1` [S1, unofficial].
3. **Extract Position:** Read positions $x, y, z$ as float64 [S1, unofficial].
4. **Extract and Normalize Rotation:** Read quaternions $rot_0 \dots rot_3$ (w, x, y, z) [S1, unofficial]. Normalize by dividing by the norm if the norm is greater than $10^{-6}$ [S1, unofficial].
5. **Compute Covariance:** Square scales: $s^2 = \text{scales}^2$ [S1, unofficial]. Construct rotation matrix $R$ from the normalized quaternion [S1, unofficial]. Compute scaled rotation: $A = R \cdot s^2[:, \text{np.newaxis}, :]$ [S1, unofficial]. Compute covariance: $\text{cov3} = \text{einsum}('nrk, nck \rightarrow nrc', A, R)$ [S1, unofficial]. Flatten $\text{cov3}$ to $\text{cov36}$ of shape $(n, 36)$ by iterating $r, c \in 0 \dots 2$ and setting $\text{cov36}[:, r \cdot 6 + c] = \text{cov3}[:, r, c]$ [S1, unofficial].
6. **Convert Opacity:** Apply sigmoid to raw opacity, scale to 0-255, and clip to `uint8`: $\text{opacity\_u8} = \text{clip}(\sigma(\text{raw\_opacity}) \cdot 255.0, 0, 255).astype(\text{uint8})$ [S1, unofficial].
7. **Extract SH Coefficients:** DC term from `f_dc_0..2` [S1, unofficial]. Higher order terms from `f_rest_` properties [S1, unofficial]. Interleave R, G, B columns for each coefficient index $ci$ from $0$ to $\text{nrc\_to\_use} - 1$ [S1, unofficial]. Concatenate to `sh_all` of shape $(n, 3(1 + \text{nrc\_to\_use}))$ [S1, unofficial].
8. **Build and Publish:** Iterate $i$ from $0$ to $n-1$ [S1, unofficial]. Create `Splat` messages with pose, covariance, and SH data [S1, unofficial]. Assemble into `SplatArray` [S1, unofficial]. Publish to `/gaussian_splats` with QoS profile: depth=1, durability=TRANSIENT_LOCAL, reliability=RELIABLE [S1, unofficial].

### Pseudocode
```python
import numpy as np

def quaternion_to_rotation_matrix(q):
    """Convert quaternion [w, x, y, z] to 3x3 rotation matrix."""
    w, x, y, z = q
    return np.array([
        [1 - 2*(y**2 + z**2), 2*(x*y - w*z), 2*(x*z + w*y)],
        [2*(x*y + w*z), 1 - 2*(x**2 + z**2), 2*(y*z - w*x)],
        [2*(x*z - w*y), 2*(y*z + w*x), 1 - 2*(x**2 + y**2)]
    ])

def count_f_rest_properties(ply_data):
    """Count properties starting with 'f_rest_'."""
    return sum(1 for key in ply_data.keys() if key.startswith('f_rest_'))

def load_and_publish(ply_path, sh_degree=3, stamp=None, frame_id='map'):
    # 1. Load PLY
    # Assume ply_data is a dict of numpy arrays loaded from ply_path
    # If file not found, raise FileNotFoundError [S1, unofficial]
    
    # 2. Determine SH Degree
    nrc = count_f_rest_properties(ply_data)
    if nrc >= 15:
        file_degree = 3
    elif nrc >= 8:
        file_degree = 2
    elif nrc >= 3:
        file_degree = 1
    else:
        file_degree = 0
        
    actual_degree = min(sh_degree, file_degree)
    nrc_to_use = (actual_degree + 1)**2 - 1
    
    # 3. Extract Position
    positions = np.column_stack([ply_data['x'], ply_data['y'], ply_data['z']]).astype(np.float64)
    n = positions.shape[0]
    
    # 4. Extract and Normalize Rotation
    quats = np.column_stack([ply_data['rot_0'], ply_data['rot_1'], ply_data['rot_2'], ply_data['rot_3']])
    norms = np.linalg.norm(quats, axis=1, keepdims=True)
    valid_norms = np.maximum(norms, 1e-6)
    quats_normalized = quats / valid_norms
    
    # 5. Compute Covariance
    scales = np.column_stack([ply_data['scale_0'], ply_data['scale_1'], ply_data['scale_2']])
    s2 = scales**2
    
    cov36 = np.zeros((n, 36))
    for i in range(n):
        R = quaternion_to_rotation_matrix(quats_normalized[i])
        A = R * s2[i, np.newaxis, :]
        cov3 = A @ R.T
        for r in range(3):
            for c in range(3):
                cov36[i, r*6+c] = cov3[r, c]
                
    # 6. Convert Opacity
    raw_opacity = ply_data['opacity']
    sigmoid_opacity = 1.0 / (1.0 + np.exp(-raw_opacity))
    opacity_u8 = np.clip(sigmoid_opacity * 255.0, 0, 255).astype(np.uint8)
    
    # 7. Extract SH Coefficients
    dc_coeffs = np.column_stack([ply_data['f_dc_0'], ply_data['f_dc_1'], ply_data['f_dc_2']])
    
    sh_rest = []
    for ci in range(nrc_to_use):
        r_col = ply_data[f'f_rest_{ci}_0']
        g_col = ply_data[f'f_rest_{ci}_1']
        b_col = ply_data[f'f_rest_{ci}_2']
        sh_rest.append(np.column_stack([r_col, g_col, b_col]))
        
    if sh_rest:
        rest_coeffs = np.concatenate(sh_rest, axis=1)
        sh_all = np.concatenate([dc_coeffs, rest_coeffs], axis=1)
    else:
        sh_all = dc_coeffs
        
    # 8. Build Message
    splat_array = SplatArray()
    for i in range(n):
        splat = Splat()
        splat.pose.header.stamp = stamp
        splat.pose.header.frame_id = frame_id
        splat.pose.pose.position.x = positions[i, 0]
        splat.pose.pose.position.y = positions[i, 1]
        splat.pose.pose.position.z = positions[i, 2]
        splat.pose.pose.orientation.w = quats_normalized[i, 0]
        splat.pose.pose.orientation.x = quats_normalized[i, 1]
        splat.pose.pose.orientation.y = quats_normalized[i, 2]
        splat.pose.pose.orientation.z = quats_normalized[i, 3]
        splat.pose.covariance = cov36[i].tolist()
        splat.opacity = opacity_u8[i]
        splat.harmonics_deg = actual_degree
        splat.spherical_harmonics = sh_all[i].tolist()
        splat_array.splats.append(splat)
        
    publish(splat_array, topic='/gaussian_splats')

class SplatArray:
    def __init__(self):
        self.splats = []

class Splat:
    def __init__(self):
        self.pose = type('PoseWithCovarianceStamped', (), {
            'header': type('Header', (), {'stamp': None, 'frame_id': 'map'})(),
            'pose': type('Pose', (), {
                'position': type('Point', (), {'x': 0.0, 'y': 0.0, 'z': 0.0})(),
                'orientation': type('Quaternion', (), {'w': 1.0, 'x': 0.0, 'y': 0.0, 'z': 0.0})(),
                'covariance': []
            })()
        })()
        self.opacity = 0
        self.harmonics_deg = 0
        self.spherical_harmonics = []
```

### Parameters
- `ply_path`: File path to the PLY file. Default is 'splats/only_bonsai.ply' within the package share directory if not provided [S1, unofficial].
- `sh_degree`: The spherical harmonics degree, clamped between 0 and 3. Default is 3 [S1, unofficial].

### Pitfalls
- If the PLY file is not found, the publisher raises a `FileNotFoundError` [S1, unofficial].
- If a color key (e.g., `g_key`, `b_key`) is not in the property names, it defaults to zeros instead of raising an error [S1, unofficial].
- Precision issues may arise if quaternion norms are very small; a guard of $10^{-6}$ is used [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of splats $n$ for loading, covariance computation, and message construction [G].
- **Memory Complexity:** Linear with respect to $n$. The covariance matrix flattening creates an $(n, 36)$ array [G].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Not given in the sources.
- **Strengths:** Standardized ROS message format allows integration with existing RViz plugins and other ROS nodes [G].
- **Limitations:** Requires ROS 2 environment. The covariance flattening logic is specific to the ROS message layout and may not be directly portable to other formats without modification [G].
- **When to use:** When visualizing 3D Gaussian Splatting results in ROS-based robotics or simulation environments [G].
- **When not:** When not using ROS 2 or when real-time performance is critical and the overhead of ROS message serialization is unacceptable [G].

## Background
PLY Splat Publishing is part of the `gsplat_rviz_plugin` ecosystem, specifically the `splat-ros` project [S1, unofficial]. It enables the visualization of 3D Gaussian Splatting outputs in RViz, a popular 3D visualization tool for ROS [S1, unofficial]. The method was developed to bridge the gap between offline Gaussian Splatting training outputs (PLY files) and real-time ROS-based visualization pipelines [S1, unofficial].
