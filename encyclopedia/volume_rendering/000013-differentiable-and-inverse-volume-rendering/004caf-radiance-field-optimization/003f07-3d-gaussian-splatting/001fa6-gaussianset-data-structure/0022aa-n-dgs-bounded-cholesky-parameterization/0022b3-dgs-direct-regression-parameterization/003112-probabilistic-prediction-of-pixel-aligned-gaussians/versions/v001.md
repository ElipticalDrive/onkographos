# Probabilistic Prediction of Pixel-Aligned Gaussians

Also called: Discrete Depth Bucketing for Gaussians, Probabilistic Gaussian Prediction

## Overview
Probabilistic Prediction of Pixel-Aligned Gaussians is a method for predicting 3D Gaussian primitive parameters (mean $\boldsymbol{\mu}$, covariance $\boldsymbol{\Sigma}$, opacity $\alpha$, and spherical harmonics $\mathbf{S}$) from per-pixel features by predicting a discrete probability distribution over depth buckets and sampling from it [S1]. It solves the problem of local minima associated with directly regressing Gaussian center positions, which also prevents the use of non-differentiable spawning and pruning heuristics [S1]. Unlike direct regression baselines, this approach provides an approximate 1 dB PSNR performance boost by enabling differentiable optimization of the Gaussian position through a reparameterization trick [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Per-pixel feature vector $\mathbf{F}[\mathbf{u}]$ at pixel coordinate $\mathbf{u}$, camera origin $\mathbf{o}$ of the reference view, ray direction $\mathbf{d}_{\mathbf{u}}$, and depth buckets $\mathbf{b} \in \mathbb{R}^Z$.
*   **Outputs:** A tuple $(\boldsymbol{\mu}, \boldsymbol{\Sigma}, \alpha, \mathbf{S})$ representing the predicted Gaussian primitive.

**Data Structures:**
*   **Depth Buckets $\mathbf{b}$:** A vector of size $Z$ containing depth values discretized between near plane $d_{\text{near}}$ and far plane $d_{\text{far}}$. The $z$-th element $\mathbf{b}_z$ is defined in disparity space [S1]:
    $$
    \mathbf{b}_z = \left( \left(1 - \frac{z}{Z}\right) \left(\frac{1}{d_{\text{near}}} - \frac{1}{d_{\text{far}}}\right) + \frac{1}{d_{\text{far}}} \right)^{-1}
    $$
    where $z \in \{0, \dots, Z-1\}$ is the bucket index [S1].
*   **Probability Vector $\boldsymbol{\phi}$:** A vector of size $Z$ predicted by the network, normalized via softmax to sum to one. $\boldsymbol{\phi}_z$ represents the probability that a surface exists in depth bucket $\mathbf{b}_z$ [S1].
*   **Offset Vector $\boldsymbol{\delta}$:** A vector of size $Z$ with values in $[0, 1]$. $\boldsymbol{\delta}_z$ adjusts the depth of the Gaussian between bucket boundaries [S1].

**Parameters:**
*   $M$: Number of Gaussian primitives predicted per pixel. The method simplifies to $M=1$ for the core explanation [S1].
*   $Z$: Number of depth bins/buckets discretizing the depth range [S1].
*   $d_{\text{near}}, d_{\text{far}}$: Near and far planes defining the depth range [S1].

**Algorithm Steps:**
1.  Predict depth probabilities $\boldsymbol{\phi}$, per-bucket center offsets $\boldsymbol{\delta}$, covariance $\boldsymbol{\Sigma}$, and spherical harmonics coefficients $\mathbf{S}$ from the per-pixel feature $\mathbf{F}[\mathbf{u}]$ using a neural network $f$ [S1].
2.  Sample a depth bucket index $z$ from the discrete probability distribution parameterized by $\boldsymbol{\phi}$, denoted $z \sim p_{\boldsymbol{\phi}}(z)$ [S1].
3.  Compute the Gaussian mean $\boldsymbol{\mu}$ by unprojecting with the depth $\mathbf{b}_z$ adjusted by the bucket offset $\boldsymbol{\delta}_z$:
    $$
    \boldsymbol{\mu} = \mathbf{o} + (\mathbf{b}_z + \boldsymbol{\delta}_z)\mathbf{d}_{\mathbf{u}}
    $$
    where $\mathbf{o}$ is the camera origin and $\mathbf{d}_{\mathbf{u}}$ is the ray direction [S1].
4.  Set the Gaussian opacity $\alpha$ equal to the probability of the sampled depth bucket: $\alpha = \boldsymbol{\phi}_z$ [S1].
5.  Return the tuple $(\boldsymbol{\mu}, \boldsymbol{\Sigma}, \alpha, \mathbf{S})$ [S1].

**Pseudocode:**
```python
def probabilistic_prediction(F_u, b, o, d_u, f):
    """
    Predicts a single pixel-aligned Gaussian using probabilistic depth bucketing.
    
    Args:
        F_u: Per-pixel feature vector at coordinate u.
        b: Depth buckets vector of size Z in disparity space.
        o: Camera origin.
        d_u: Ray direction.
        f: Neural network that predicts (phi, delta, Sigma, S).
        
    Returns:
        Tuple (mu, Sigma, alpha, S) for the predicted Gaussian.
    """
    # Step 1: Predict parameters from features
    phi, delta, Sigma, S = f(F_u)
    
    # Step 2: Sample depth bucket index z from discrete distribution phi
    # Note: In implementation, this requires a differentiable sampler (e.g., Gumbel-Softmax)
    z = sample_discrete(phi)
    
    # Step 3: Compute mean mu
    # b_z is the depth value of the sampled bucket
    # delta_z is the offset for the sampled bucket
    mu = o + (b[z] + delta[z]) * d_u
    
    # Step 4: Set opacity alpha to the probability of the sampled bucket
    alpha = phi[z]
    
    # Step 5: Return parameters
    return mu, Sigma, alpha, S
```

**Backpropagation and Reparameterization:**
To backpropagate gradients into the probabilities $\boldsymbol{\phi}$, the method assigns the gradients of the loss $\mathcal{L}$ with respect to the opacity $\alpha$ to the gradients of the depth probability buckets $\boldsymbol{\phi}$ [S1]:
$$
\nabla_{\boldsymbol{\phi}} \mathcal{L} = \nabla_{\alpha} \mathcal{L}
$$
This reparameterization trick makes the sampling process differentiable [S1]. Intuitively, if sampling produces a correct depth, gradient descent increases the opacity, concentrating probability mass in the correct bucket. If the depth is incorrect, gradient descent decreases the opacity, lowering the probability of that bucket being sampled again [S1].

**Edge Cases and Pitfalls:**
*   **Local Minima:** Directly regressing the Gaussian center $\boldsymbol{\mu}$ is susceptible to local minima [S1].
*   **Non-differentiable Heuristics:** Direct regression prevents the use of spawning and pruning heuristics from 3D-GS because they are not differentiable [S1].
*   **Precision:** The depth buckets are defined in disparity space to handle the non-linear relationship between pixel coordinates and depth, ensuring uniform sampling in disparity rather than depth [S1].

## Operating characteristics
*   **Performance:** The probabilistic prediction method leads to an approximate 1 dB PSNR performance boost compared to the baseline of directly regressing the depth [S1].
*   **Complexity:** The method adds the overhead of predicting a probability distribution $\boldsymbol{\phi}$ and sampling from it, but remains computationally efficient as it operates per-pixel with a fixed number of buckets $Z$.
*   **Strengths:** Avoids local minima in optimization; enables differentiable training of Gaussian positions; compatible with gradient-based optimization.
*   **Limitations:** Requires discretization of depth into $Z$ buckets, which may limit depth resolution depending on $Z$; sampling introduces stochasticity, though mitigated by the reparameterization trick.

## Background
The method was introduced in the paper "PixelSplat: 3D Gaussian Splats from Image Pairs for Scalable Generalizable 3D Reconstruction" [S1]. It addresses limitations in previous light field rendering methods and direct regression approaches by providing a differentiable alternative for predicting Gaussian positions [S1]. The approach is part of the broader family of 3D Gaussian Splatting techniques, specifically extending the direct regression parameterization [S1].
