# Base 3DGS Optimization
Also called: Base 3DGS Optimization with Normal Attribute

## Overview
Base 3DGS Optimization initializes the geometric attributes of 3D Gaussian primitives to provide a robust geometric baseline for subsequent shading attribute optimization, such as in [iVR-GS Training](7578-ivr-gs-training.md). It differs from standard 3DGS by incorporating an explicit normal attribute $n$ for each Gaussian and optimizing it via a normal consistency loss, despite the normal not affecting the final rendered color or alpha in the base stage [S1]. This initialization accelerates the convergence of editable Gaussian optimization by ensuring accurate surface geometry representation before decomposing color and lighting [S1].

## How it works
**Inputs:** Multi-view input images, camera poses, and initial Gaussian parameters.
**Outputs:** Optimized Gaussian primitives with geometry and auxiliary normal attributes.

**Data Structures:**
Each Gaussian $i$ is parameterized by the tuple $\{\mu_i, q_i, s_i, o_i, n_i, c_i\}$ [S1]:
*   $\mu_i \in \mathbb{R}^3$: Mean position.
*   $q_i \in \mathbb{R}^4$: Rotation quaternion.
*   $s_i \in \mathbb{R}^3$: Scale vector.
*   $o_i \in \mathbb{R}$: Opacity.
*   $n_i \in \mathbb{R}^3$: Normal attribute (unit vector).
*   $c_i$: View-dependent color, represented by Spherical Harmonic (SH) coefficients [S1].

**Algorithm Steps:**

1.  **Initialization:** Initialize Gaussians with standard 3DGS parameters $\{\mu_i, q_i, s_i, o_i, c_i\}$ and assign initial normal attributes $n_i$ (e.g., based on local surface estimation or random initialization consistent with geometry) [S1].
2.  **Rendering:** For a given viewpoint, render the depth map $D$ and normal map $N$ using the current Gaussian parameters. The rendering follows the alpha compositing equation [S1]:
    $$
    \{D, N\} = \sum_{i \in \mathcal{N}} T_i \alpha_i \{d_i, n_i\}
    $$
    where:
    *   $\mathcal{N}$ is the set of sorted Gaussians contributing to the pixel.
    *   $T_i = \prod_{j < i} (1 - \alpha_j)$ is the accumulated transmittance.
    *   $\alpha_i$ is the opacity of the $i$-th Gaussian.
    *   $d_i$ is the depth of the $i$-th Gaussian (typically the depth of its mean $\mu_i$ projected or sampled).
    *   $n_i$ is the normal attribute of the $i$-th Gaussian, rotated to world space.
3.  **Pseudo-Normal Computation:** Compute a pseudo-normal map $\tilde{N}$ from the rendered depth map $D$ under the local planarity assumption [S1]. This typically involves estimating the surface normal from the depth gradient at each pixel.
4.  **Loss Calculation:** Compute the total loss $\mathcal{L}$ as a combination of color/alpha reconstruction losses and the normal consistency loss [S1]:
    $$
    \mathcal{L} = \mathcal{L}_{color} + \mathcal{L}_{alpha} + \lambda_n \mathcal{L}_n
    $$
    where:
    *   $\mathcal{L}_{color}$ is the L1 loss between rendered color and ground truth color.
    *   $\mathcal{L}_{alpha}$ is the SSIM loss (or L1) between rendered alpha and ground truth alpha (if available) or a regularization term [S1].
    *   $\mathcal{L}_n$ is the normal consistency loss:
        $$
        \mathcal{L}_n = ||N - \tilde{N}||_2
        $$
    *   $\lambda_n$ is a weighting factor for the normal loss (value not specified in sources) [S1].
5.  **Optimization:** Update all parameters $\{\mu_i, q_i, s_i, o_i, n_i, c_i\}$ using gradient descent (e.g., Adam) [S1]. Note that while $n_i$ is optimized, it does not influence the rendered color or alpha in this stage; it only influences $\mathcal{L}_n$ [S1].
6.  **Iteration:** Repeat steps 2-5 for the specified number of iterations or until convergence.

**Pseudocode:**

```python
def base_3dgs_optimization(gaussians, images, cameras, num_iterations, lambda_n):
    """
    Optimizes base 3DGS model with normal attribute.
    
    Args:
        gaussians: List of Gaussian objects with attributes {mu, q, s, o, n, c}
        images: List of ground truth RGB images
        cameras: List of camera poses
        num_iterations: Number of optimization steps
        lambda_n: Weight for normal consistency loss
        
    Returns:
        Optimized gaussians
    """
    optimizer = Adam(gaussians.parameters(), lr=1e-3)
    
    for iteration in range(num_iterations):
        # 1. Sample a random camera and corresponding image
        idx = random.randint(0, len(images) - 1)
        gt_image = images[idx]
        camera = cameras[idx]
        
        # 2. Render depth and normal maps
        # render_depth_normal returns D and N
        D, N = render_depth_normal(gaussians, camera)
        
        # 3. Compute pseudo-normal from depth
        # compute_pseudo_normal uses local planarity assumption on D
        N_tilde = compute_pseudo_normal(D)
        
        # 4. Compute losses
        # Render color map C using SH coefficients c
        C = render_color(gaussians, camera)
        
        # L1 loss for color
        loss_color = L1Loss(C, gt_image)
        
        # SSIM loss for color (or L1/SSIM for alpha if available)
        # Assuming alpha rendering is part of the standard 3DGS render
        alpha_map = render_alpha(gaussians, camera)
        # Note: Ground truth alpha might not be available in standard NeRF datasets.
        # The source mentions optimizing alpha channel enhances quality [S1].
        # If GT alpha exists, use L1/SSIM. Otherwise, this term might be omitted or
        # replaced by opacity regularization. We assume standard L1/SSIM on RGB.
        loss_alpha = SSIMLoss(C, gt_image) 
        
        # Normal consistency loss
        loss_normal = L2Loss(N, N_tilde)
        
        # Total loss
        loss = loss_color + loss_alpha + lambda_n * loss_normal
        
        # 5. Backpropagate and update
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
    return gaussians

def render_depth_normal(gaussians, camera):
    """
    Renders depth and normal maps using alpha compositing.
    Returns D (depth map) and N (normal map).
    """
    # Sort Gaussians by depth relative to camera
    sorted_gaussians = sort_by_depth(gaussians, camera)
    
    # Initialize output maps
    D = zeros_like(camera.image_shape)
    N = zeros_like(camera.image_shape)
    T = ones_like(camera.image_shape) # Transmittance
    
    for g in sorted_gaussians:
        # Project Gaussian to screen space
        # Get depth d_i and normal n_i in camera space
        d_i = project_depth(g.mu, camera)
        n_i = rotate_vector(g.n, g.q, camera.rotation)
        
        # Compute alpha contribution alpha_i
        alpha_i = compute_gaussian_alpha(g, camera)
        
        # Composite
        weight = T * alpha_i
        D += weight * d_i
        N += weight * n_i
        T *= (1 - alpha_i)
        
        # Early exit if T is negligible
        if T.max() < 1e-4:
            break
            
    return D, N

def compute_pseudo_normal(depth_map):
    """
    Computes pseudo-normal from depth map using local planarity.
    Typically involves finite differences to estimate surface gradient.
    """
    # Example: Sobel filters to get gradients
    dx, dy = sobel_gradients(depth_map)
    # Normal is proportional to (-dz/dx, -dz/dy, 1)
    # Normalize to unit vector
    N_tilde = normalize(vector(-dx, -dy, 1))
    return N_tilde
```

**Parameters:**
*   $\lambda_n$: Weight for normal consistency loss. Value not given in the sources.
*   Learning rate: Standard Adam optimizer settings (value not given in the sources).

**Edge Cases and Pitfalls:**
*   **Normal Irrelevance in Base Stage:** Adjusting the normal attribute $n$ does not affect the rendering results (color/alpha) of the base 3DGS. It is optimized solely to accelerate the convergence of subsequent editable Gaussian optimization [S1].
*   **Alpha Channel Optimization:** Unlike IBR methods that only synthesize RGB, 3DGS reconstructs per-pixel alpha. Optimizing the alpha channel can enhance reconstruction quality [S1].
*   **Pseudo-Normal Accuracy:** The pseudo-normal $\tilde{N}$ relies on the local planarity assumption. In regions with high curvature or noise, this approximation may be inaccurate, potentially leading to suboptimal normal initialization [S1].

## Subtopics

### [iVR-GS Training](7578-ivr-gs-training.md)
iVR-GS Training is a two-stage optimization procedure for Inverse Volume Rendering with 3D Gaussian Splatting (iVR-GS) that separates the initialization of scene geometry from the optimization of editable shading attributes. It builds on [Base 3DGS Optimization](7549-base-3dgs-optimization.md) by first establishing a robust geometric baseline and then refining Gaussian primitives for visual exploration. It differs from one-stage training by accelerating convergence and reducing the number of required primitives while maintaining comparable reconstruction quality.

### [3D Smoothing Filter](9588-3d-smoothing-filter.md)
The 3D smoothing filter prevents 3D Gaussian primitives from becoming smaller than the maximal sampling frequency induced by the training images, thereby mitigating aliasing artifacts when rendering at different sampling rates (e.g., varying focal length or camera distance). It sets a lower bound on Gaussian scale based on the highest spatial frequency captured during training. Unlike the 2D Mip filter which addresses projection aliasing, this filter operates in 3D space to constrain the intrinsic size of the Gaussians.

### Editable Gaussian Optimization
Editable Gaussian Optimization decomposes color and lighting from the scene using the Blinn-Phong model instead of SH coefficients, enabling scene editing [S1]. It assigns additional shading attributes to each Gaussian primitive optimized in base 3DGS: an offset color $\Delta c \in \mathbb{R}^3$, ambient/diffuse/specular coefficients $\{k_a, k_d, k_s\}$, and a shininess term $\beta$ [S1]. The voxel color $c_v$ is expressed as $c_p + \Delta c$, where $c_p \in \mathbb{R}^3$ is a palette color parameter shared by all Gaussians within a basic scene [S1]. $c_p$ is fixed as the mean color value of input multi-view images during training and can be adjusted during inference [S1]. To reduce model size, low-opacity Gaussians are removed periodically, and an L1 regularization term encourages low opacity to neutralize the tendency to use more Gaussians for compact surfaces due to normal-dependent color [S1]. Sparsity regularization (L1 loss of rendered offset color map) is added to $\Delta c$ to avoid significant palette color shiftings [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** The base 3DGS optimization provides a geometric baseline that accelerates the convergence of editable Gaussian optimization [S1].
*   **Strengths:** Provides accurate geometry initialization for subsequent shading decomposition; leverages normal consistency to improve geometric fidelity [S1].
*   **Limitations:** The normal attribute does not affect rendering in the base stage, so its optimization is purely for initialization purposes [S1]. Relies on local planarity assumption for pseudo-normal computation [S1].

## Background
Base 3DGS Optimization was introduced in the iVR-GS paper as a preliminary step for inverse volume rendering with editable 3D Gaussian Splatting [S1]. It adapts the original 3DGS framework by adding a normal attribute and optimizing it via a consistency loss, drawing inspiration from prior work on normal consistency [S1].
