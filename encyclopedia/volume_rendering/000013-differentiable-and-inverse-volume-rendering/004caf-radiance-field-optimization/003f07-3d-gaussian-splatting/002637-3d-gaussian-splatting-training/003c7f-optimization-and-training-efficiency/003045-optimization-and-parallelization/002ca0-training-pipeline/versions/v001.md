# Training Pipeline

Also called: Iterative optimization loop

## Overview
The training pipeline for 3D Gaussian Splatting is an iterative optimization loop that minimizes a photometric loss between rendered images and ground truth views [S1, unofficial]. It differs from static rendering by continuously updating Gaussian parameters (position, covariance, opacity, color) via gradients computed through a differentiable rasterizer [S1, unofficial].

## How it works
**Inputs:**
*   `sparsePointCloud`: Initial set of 3D points with attributes.
*   `pointCloudExtraFeatures`: Additional attributes (e.g., SH coefficients, masks).
*   `cameraPose`: Camera extrinsics and intrinsics for the current training step.
*   `ImageFromMultiViews`: Ground truth images corresponding to `cameraPose`.

**Data Structures:**
*   `WeightToTrain`: State object containing the mutable Gaussian parameters (`sparsePointCloud`, `pointCloudExtraFeatures`) [S1, unofficial].

**Steps:**
1.  **Rasterization:** Pass `sparsePointCloud`, `pointCloudExtraFeatures`, and `cameraPose` to the Rasterizer [S1, unofficial]. The Rasterizer performs alpha-blending to produce a `rasterized_image` [S1, unofficial].
2.  **Loss Computation:** Compare `rasterized_image` with `ImageFromMultiViews` using a Loss function (e.g., L1, SSIM) [S1, unofficial].
3.  **Gradient Calculation:** Compute gradients of the loss with respect to the parameters in `WeightToTrain` [S1, unofficial].
4.  **Update:** Apply gradients to update `WeightToTrain` [S1, unofficial].

**Pseudocode:**
```python
def training_step(sparsePointCloud, pointCloudExtraFeatures, cameraPose, ImageFromMultiViews):
    # 1. Rasterize
    rasterized_image = Rasterizer(sparsePointCloud, pointCloudExtraFeatures, cameraPose)
    
    # 2. Compute Loss
    loss = Loss(rasterized_image, ImageFromMultiViews)
    
    # 3. Backpropagate
    gradients = loss.backward()
    
    # 4. Update Weights
    WeightToTrain.update(gradients)
    
    return loss
```

## Background
The iterative optimization loop is a standard approach for training differentiable rendering models [S1, unofficial]. It relies on the differentiability of the rasterization process to enable gradient-based optimization of 3D scene representations [S1, unofficial].
