# MaskGaussian Gradient Computation

Also called: Gradient of Masks, Mask Gradient Backpropagation

## Overview
MaskGaussian Gradient Computation is a backpropagation technique used during the training of 3D Gaussian Splatting models that incorporate probabilistic masks [S1]. It computes the gradient of the loss $\mathcal{L}$ with respect to the mask values $\mathcal{M}_i$ for each Gaussian $i$ contributing to a pixel [S1]. Unlike standard 3D Gaussian Splatting which optimizes only Gaussian parameters, this method explicitly differentiates through the mask-modulated alpha blending process to allow the masks to be learned or refined [S1]. It sets itself apart by decomposing the pixel color into a Gaussian-contributed part and a background-contributed part, ensuring the gradient accounts for how the mask affects both the visibility of the Gaussian and the transmission of the background [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   $\mathcal{L}$: The scalar loss value.
*   $\frac{\partial \mathcal{L}}{\partial \mathbf{c}(\mathbf{x})}$: The gradient of the loss with respect to the final rendered pixel color $\mathbf{c}(\mathbf{x})$ (a 3D vector).
*   $\mathbf{x}$: The pixel coordinate.
*   $N$: The number of Gaussians sorted by depth for pixel $\mathbf{x}$.
*   For each Gaussian $i \in \{1, \dots, N\}$:
    *   $\mathcal{M}_i$: The mask value (scalar).
    *   $\alpha_i$: The opacity (scalar).
    *   $\mathbf{c}_i$: The color of the $i$-th Gaussian (3D vector).
*   $\mathbf{c}_{bg}$: The background color (3D vector).

**Outputs:**
*   $\frac{\partial \mathcal{L}}{\partial \mathcal{M}_i}$: The gradient of the loss with respect to the mask $\mathcal{M}_i$ for each Gaussian $i$ (scalar).

### Data Structures
The method requires storing intermediate rendering values during the forward pass to be used in the backward pass.
*   **Intermediate Colors $\mathbf{b}_i$**: An array of size $N+2$.
    *   $\mathbf{b}_{N+1} = \mathbf{c}_{bg}$ (or effectively the color accumulated after the last Gaussian, which is the background color modulated by transmittance if viewed from the back, but here defined as the base for the recursion). Note: The source defines $\mathbf{b}_i$ as the color rendered from the $i$-th Gaussian to the last. The recursion base is $\mathbf{b}_{N+1}$ which represents the color contribution from beyond the $N$-th Gaussian. In the context of Eq 11, $\mathbf{b}_{N+1}$ is the color passed to the last Gaussian blending step.
    *   $\mathbf{b}_i$ for $i=1 \dots N$: The accumulated color from Gaussian $i$ to $N$.
*   **Transmittances $T_i$**: An array of size $N+1$.
    *   $T_i = \prod_{j=1}^{i-1} (1 - \mathcal{M}_j \cdot \alpha_j)$.
    *   $T_1 = 1$.
    *   $T_{N+1} = \prod_{j=1}^{N} (1 - \mathcal{M}_j \cdot \alpha_j)$.

### Numbered Steps

1.  **Forward Pass (Implicit)**: Compute the intermediate colors $\mathbf{b}_i$ and transmittances $T_i$ for all $i$ from $N$ down to $1$.
    *   Initialize $\mathbf{b}_{N+1} = \mathbf{c}_{bg}$.
    *   For $i = N$ down to $1$:
        *   Compute $\mathbf{b}_i = \mathcal{M}_i \cdot \alpha_i \cdot \mathbf{c}_i + (1 - \mathcal{M}_i \cdot \alpha_i) \cdot \mathbf{b}_{i+1}$.
        *   Compute $T_i = T_{i+1} / (1 - \mathcal{M}_i \cdot \alpha_i)$? No, $T_i$ is defined as product up to $i-1$. It is easier to compute $T$ forward or store it. Let $T_1 = 1$. For $i=1$ to $N$, $T_{i+1} = T_i \cdot (1 - \mathcal{M}_i \cdot \alpha_i)$.
        *   The final transmittance is $T_{N+1}$.

2.  **Backward Pass Initialization**:
    *   Set $\frac{\partial \mathcal{L}}{\partial \mathbf{b}_1} = \frac{\partial \mathcal{L}}{\partial \mathbf{c}(\mathbf{x})}$. This is because $\mathbf{b}_1$ is the total color contributed by the Gaussians $\mathbf{c}_g(\mathbf{x})$, and the total pixel color is $\mathbf{c}(\mathbf{x}) = \mathbf{c}_g(\mathbf{x}) + \mathbf{c}_b(\mathbf{x})$. However, the gradient derivation in the source treats the mask gradient calculation by splitting the dependency. The source states $\frac{\partial \mathcal{L}}{\partial \mathbf{b}_1} = \frac{\partial \mathcal{L}}{\partial \mathbf{c}_g(\mathbf{x})} = \frac{\partial \mathcal{L}}{\partial \mathbf{c}(\mathbf{x})}$. This equality holds because $\mathbf{c}_g(\mathbf{x})$ is directly $\mathbf{b}_1$ in the alpha blending chain if we consider the background separate. Wait, Eq 9 says $\mathbf{c}(\mathbf{x}) = \mathbf{c}_g(\mathbf{x}) + \mathbf{c}_b(\mathbf{x})$. Eq 10 says $\mathbf{c}_b(\mathbf{x}) = T_{N+1} \mathbf{c}_{bg}$. The term $\mathbf{b}_1$ in Eq 11 is the color rendered from Gaussians. The source equates $\frac{\partial \mathcal{L}}{\partial \mathbf{b}_1}$ to $\frac{\partial \mathcal{L}}{\partial \mathbf{c}(\mathbf{x})}$. This implies that for the purpose of the Gaussian path gradient, the full color gradient is used.

3.  **Compute Gradient for Each Gaussian $i$**:
    For each Gaussian $i$ from $1$ to $N$:
    
    a.  **Calculate Transmittance Terms**:
        *   Retrieve $T_i$ (transmittance before Gaussian $i$).
        *   Retrieve $T_{N+1}$ (final transmittance after all Gaussians).
        
    b.  **Calculate Gaussian Path Gradient Component**:
        *   Compute the difference vector: $\Delta \mathbf{c}_i = \mathbf{c}_i - \mathbf{b}_{i+1}$.
        *   Compute the first term of the mask gradient:
            $$ \text{Term}_1 = \alpha_i \cdot T_i \cdot \frac{\partial \mathcal{L}}{\partial \mathbf{c}(\mathbf{x})} \cdot \Delta \mathbf{c}_i $$
            Note: The source writes $\alpha_i T_i \frac{\partial \mathcal{L}}{\partial \mathbf{c}(\mathbf{x})} (\mathbf{c}_i - \mathbf{b}_{i+1})$. Since $\frac{\partial \mathcal{L}}{\partial \mathbf{c}(\mathbf{x})}$ is a vector and $(\mathbf{c}_i - \mathbf{b}_{i+1})$ is a vector, this is an element-wise multiplication (Hadamard product) or scalar multiplication if the gradient is isotropic? The source uses standard vector notation. In Eq 15, it is written as a product. Given $\frac{\partial \mathcal{L}}{\partial \mathbf{c}(\mathbf{x})}$ is a vector $\mathbf{g}$, and $\mathbf{c}_i - \mathbf{b}_{i+1}$ is a vector $\mathbf{v}$, the term is $\alpha_i T_i (\mathbf{g} \odot \mathbf{v})$? Or is it a dot product?
            Let's look at dimensions. $\frac{\partial \mathcal{L}}{\partial \mathcal{M}_i}$ is a scalar. $\alpha_i, T_i$ are scalars. $\frac{\partial \mathcal{L}}{\partial \mathbf{c}(\mathbf{x})}$ is a 3D vector. $\mathbf{c}_i - \mathbf{b}_{i+1}$ is a 3D vector.
            Eq 14: $\frac{\partial \mathbf{b}_i}{\partial \mathcal{M}_i} = \alpha_i (\mathbf{c}_i - \mathbf{b}_{i+1})$. This is a vector.
            Eq 15: $\frac{\partial \mathcal{L}}{\partial \mathcal{M}_i} = \frac{\partial \mathcal{L}}{\partial \mathbf{b}_i} \frac{\partial \mathbf{b}_i}{\partial \mathcal{M}_i} + \dots$
            Here $\frac{\partial \mathcal{L}}{\partial \mathbf{b}_i}$ is a vector (gradient of scalar w.r.t vector). $\frac{\partial \mathbf{b}_i}{\partial \mathcal{M}_i}$ is a vector. The product of two vectors resulting in a scalar is a dot product.
            So, $\text{Term}_1 = \alpha_i T_i \left( \frac{\partial \mathcal{L}}{\partial \mathbf{c}(\mathbf{x})} \cdot (\mathbf{c}_i - \mathbf{b}_{i+1}) \right)$.
            
    c.  **Calculate Background Path Gradient Component**:
        *   Compute the denominator term: $D_i = 1 - \alpha_i \cdot \mathcal{M}_i$.
        *   Guard against division by zero: If $D_i$ is close to 0, handle appropriately [G].
        *   Compute the second term of the mask gradient:
            $$ \text{Term}_2 = \frac{-\alpha_i \cdot T_{N+1}}{D_i} \left( \frac{\partial \mathcal{L}}{\partial \mathbf{c}(\mathbf{x})} \cdot \mathbf{c}_{bg} \right) $$
            Similarly, this is a dot product between the color gradient and the background color.
            
    d.  **Combine**:
        $$ \frac{\partial \mathcal{L}}{\partial \mathcal{M}_i} = \text{Term}_1 + \text{Term}_2 $$

### Formulas

1.  **Total Pixel Color**:
    $$ \mathbf{c}(\mathbf{x}) = \mathbf{c}_g(\mathbf{x}) + \mathbf{c}_b(\mathbf{x}) $$
    $$ \mathbf{c}_b(\mathbf{x}) = T_{N+1} \cdot \mathbf{c}_{bg} $$

2.  **Intermediate Color (Alpha Blending with Mask)**:
    $$ \mathbf{b}_i = \mathcal{M}_i \cdot \alpha_i \cdot \mathbf{c}_i + (1 - \mathcal{M}_i \cdot \alpha_i) \cdot \mathbf{b}_{i+1} $$
    Where $\mathbf{b}_{N+1} = \mathbf{c}_{bg}$ (conceptually, the color passed through the stack of Gaussians to the background).

3.  **Transmittance**:
    $$ T_i = \prod_{j=1}^{i-1} (1 - \mathcal{M}_j \cdot \alpha_j) $$
    $$ T_{N+1} = \prod_{j=1}^{N} (1 - \mathcal{M}_j \cdot \alpha_j) $$

4.  **Gradient of Intermediate Color w.r.t. Previous Intermediate Color**:
    $$ \frac{\partial \mathbf{b}_j}{\partial \mathbf{b}_{j+1}} = (1 - \mathcal{M}_j \cdot \alpha_j) \mathbb{I}_3 $$

5.  **Gradient of Loss w.r.t. Intermediate Color $\mathbf{b}_i$**:
    $$ \frac{\partial \mathcal{L}}{\partial \mathbf{b}_i} = T_i \frac{\partial \mathcal{L}}{\partial \mathbf{c}(\mathbf{x})} $$

6.  **Gradient of Intermediate Color w.r.t. Mask $\mathcal{M}_i$**:
    $$ \frac{\partial \mathbf{b}_i}{\partial \mathcal{M}_i} = \alpha_i \cdot (\mathbf{c}_i - \mathbf{b}_{i+1}) $$

7.  **Gradient of Background Color w.r.t. Mask $\mathcal{M}_i$**:
    $$ \frac{\partial \mathbf{c}_b(\mathbf{x})}{\partial \mathcal{M}_i} = \frac{-\alpha_i \cdot T_{N+1}}{1 - \alpha_i \cdot \mathcal{M}_i} \mathbf{c}_{bg} $$

8.  **Final Gradient of Loss w.r.t. Mask $\mathcal{M}_i$**:
    $$ \frac{\partial \mathcal{L}}{\partial \mathcal{M}_i} = \alpha_i T_i \left( \frac{\partial \mathcal{L}}{\partial \mathbf{c}(\mathbf{x})} \cdot (\mathbf{c}_i - \mathbf{b}_{i+1}) \right) + \frac{-\alpha_i \cdot T_{N+1}}{1 - \alpha_i \cdot \mathcal{M}_i} \left( \frac{\partial \mathcal{L}}{\partial \mathbf{c}(\mathbf{x})} \cdot \mathbf{c}_{bg} \right) $$

### Parameters
*   $\lambda_m$: A scaling factor for the mask gradient or loss term. Value: $0.1$.
*   Iteration Range: Applied during training iterations 19,000 to 20,000 [S1].

### Edge Cases and Pitfalls
*   **Division by Zero**: The term $\frac{1}{1 - \alpha_i \cdot \mathcal{M}_i}$ in the background gradient component can explode if $\alpha_i \cdot \mathcal{M}_i \approx 1$. Implementers should add a small epsilon to the denominator or clamp the value [G].
*   **Precision**: The product of many transmittance terms $(1 - \mathcal{M}_j \alpha_j)$ can underflow to zero for large $N$. Standard 32-bit floats may lose precision. Using higher precision for transmittance accumulation is recommended [G].
*   **Ordering**: Gaussians must be sorted by depth (front-to-back) for the alpha blending and transmittance definitions to hold correctly [S1].

### Pseudocode

```python
def compute_mask_gradients(
    grad_color: np.ndarray,  # Shape (3,), dL/dc(x)
    gaussians: list,         # List of N Gaussian objects
    c_bg: np.ndarray,        # Shape (3,), background color
    eps: float = 1e-7        # Epsilon for numerical stability
):
    """
    Computes dL/dM_i for each Gaussian i.
    gaussians[i] has attributes: alpha, color, mask
    """
    N = len(gaussians)
    grad_mask = np.zeros(N)
    
    # Forward pass to compute b_i and T_i
    # b_i is the color accumulated from Gaussian i to N
    # We store b_i for i=1..N+1. b_{N+1} is effectively c_bg in the blending chain?
    # Eq 11: b_i = M_i * a_i * c_i + (1 - M_i * a_i) * b_{i+1}
    # This implies b_{N+1} is the color passed to the last Gaussian.
    # In standard volume rendering, the background is blended at the end.
    # The source defines c_b(x) = T_{N+1} * c_bg.
    # And b_1 is the Gaussian contribution c_g(x).
    # So b_{N+1} should be c_bg.
    
    b = np.zeros((N + 2, 3))
    b[N + 1] = c_bg
    
    T = np.zeros(N + 2)
    T[1] = 1.0
    
    for i in range(N - 1, -1, -1):
        # i is 0-indexed in list, corresponds to Gaussian i+1 in 1-indexed math
        # Let's use 1-based indexing for math correspondence
        idx = i + 1
        g = gaussians[i]
        
        # Compute T_{idx+1} from T_{idx}
        # T_{idx} = product_{j=1}^{idx-1} (1 - M_j a_j)
        # T_{idx+1} = T_{idx} * (1 - M_{idx} a_{idx})
        if idx == 1:
            T[idx + 1] = T[idx] * (1 - g.mask * g.alpha)
        else:
            # T[idx] is already computed in previous iteration? 
            # No, T is computed forward.
            pass
            
    # Recompute T properly forward
    T[1] = 1.0
    for i in range(N):
        idx = i + 1
        g = gaussians[i]
        T[idx + 1] = T[idx] * (1 - g.mask * g.alpha)
        
    # Compute b backward
    b[N + 1] = c_bg
    for i in range(N - 1, -1, -1):
        idx = i + 1
        g = gaussians[i]
        # b_i = M_i * a_i * c_i + (1 - M_i * a_i) * b_{i+1}
        b[idx] = g.mask * g.alpha * g.color + (1 - g.mask * g.alpha) * b[idx + 1]
        
    # Backward pass
    # dL/db_1 = dL/dc(x)
    # dL/db_i = T_i * dL/dc(x)
    
    for i in range(N):
        idx = i + 1
        g = gaussians[i]
        
        # Gradient of loss w.r.t b_i
        grad_b_i = T[idx] * grad_color
        
        # Term 1: Gaussian path
        # dL/dM_i_gauss = grad_b_i . db_i/dM_i
        # db_i/dM_i = alpha_i * (c_i - b_{i+1})
        diff_color = g.color - b[idx + 1]
        grad_b_i_to_M_gauss = g.alpha * diff_color
        term1 = np.dot(grad_b_i, grad_b_i_to_M_gauss)
        
        # Term 2: Background path
        # dL/dM_i_bg = dL/dc(x) . dc_b(x)/dM_i
        # dc_b(x)/dM_i = (-alpha_i * T_{N+1} / (1 - alpha_i * M_i)) * c_bg
        denom = 1 - g.alpha * g.mask
        if abs(denom) < eps:
            denom = eps * np.sign(denom)
            
        grad_c_bg_to_M = (-g.alpha * T[N + 1] / denom) * c_bg
        term2 = np.dot(grad_color, grad_c_bg_to_M)
        
        grad_mask[i] = term1 + term2
        
    return grad_mask
```

## Subtopics

### MaskGaussian
*   **What it is**: The primary method described in the source, which uses probabilistic masks to adaptively prune 3D Gaussians during training from scratch.
*   **Distinction**: Applies Gaussian pruning at the 20,000th iteration when training from scratch, unlike LightGaussian which compresses an already trained model.
*   **When to choose**: When training a 3DGS model from scratch and aiming for a compact representation with adaptive mask learning.
*   **Link**: [MaskGaussian](6234-maskgaussian.md)

### LightGaussian
*   **What it is**: A method for compressing an already trained 3D Gaussian Splatting model.
*   **Distinction**: Focuses on post-training compression rather than training-time mask optimization.
*   **When to choose**: When you have an existing trained 3DGS model and want to reduce its size without retraining from scratch.
*   **Link**: [LightGaussian](6235-lightgaussian.md)

## Operating characteristics

*   **Time Complexity**: The gradient computation requires a forward pass to compute intermediate colors and transmittances ($O(N)$) and a backward pass to compute gradients ($O(N)$), where $N$ is the number of Gaussians per pixel. This is linear with respect to the number of Gaussians.
*   **Memory Complexity**: Requires storing intermediate colors $\mathbf{b}_i$ and transmittances $T_i$ for all $N$ Gaussians per pixel during the backward pass, or recomputing them. This adds $O(N)$ memory overhead per pixel compared to standard 3DGS.
*   **Measured Performance**: On Mip-NeRF360, MaskGaussian achieves a PSNR of 27.44 and SSIM of 0.811 with 1.205M Gaussians, compared to 3DGS's 27.45 PSNR and 3.204M Gaussians [S1]. It is comparable in quality to LightGaussian (27.10 PSNR, 1.090M Gaussians) but with higher PSNR.
*   **Strengths**: Allows for adaptive pruning during training, leading to a more compact model without significant quality loss.
*   **Limitations**: Requires careful handling of numerical stability (division by zero). The additional gradient computation adds overhead to the training loop.
*   **When to use**: When training from scratch and model size is a constraint, and the hardware supports the additional memory/compute for mask gradients.
*   **When not to use**: When training time is extremely limited, or when using a pre-trained model where post-training compression (like LightGaussian) is preferred.

## Background

*   **Origin**: The method is described in the supplementary material of "MaskGaussian: Adaptive 3D Gaussian Representation from Probabilistic Masks" [S1].
*   **History**: The paper compares MaskGaussian against LightGaussian [S1]. LightGaussian is cited as a method to compress an already trained 3DGS model [S1]. MaskGaussian applies pruning at the 20,000th iteration during training from scratch [S1].
*   **Usage**: Used in the context of 3D Gaussian Splatting training to reduce the number of Gaussians while maintaining rendering quality.
