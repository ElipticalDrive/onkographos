# Atomized Proliferation

Also called: Atom Gaussian Densification

## Overview
Atomized Proliferation is a densification and refinement strategy for 3D Gaussian Splatting that enhances geometric precision by constraining Gaussians representing fine details into "Atom Gaussians" (isotropic spheroids with uniform size) and prioritizing their proliferation to align with scene geometry [S1, unofficial]. Unlike standard 3D Gaussian Splatting, which struggles to stabilize densification and often results in noisy meshes or blurry artifacts, Atomized Proliferation uses a warm-up strategy that aggressively densifies initially, then merges large smooth surfaces, leading to a declining and stabilizing trend in Gaussian count [S1, unofficial]. It builds on [3D Gaussian Splatting](9128-3d-gaussian-splatting-3d-gaussian-splatting.md) training mechanics but modifies the cloning, splitting, and pruning logic to favor geometric alignment over arbitrary scale optimization [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** A set of 3D Gaussians defined by mean position $\mu$, covariance $\Sigma$, color $c$, and opacity $\alpha$; input Structure-from-Motion (SfM) points; loss gradients $\nabla_p L$ with respect to pixel positions; hyperparameters $\tau_c, \tau_s, \epsilon, S, t_a, t_w$.
- **Outputs:** An updated set of Gaussians where fine details are represented by fixed-size Atom Gaussians and smooth surfaces are merged or pruned.

**Data Structures:**
The Gaussian set is represented as four parallel arrays or a struct of arrays:
- $M$: Mean positions ($\mathbb{R}^3$).
- $\Sigma$: Covariance matrices ($\mathbb{R}^{3 \times 3}$, symmetric positive definite).
- $C$: Colors (e.g., spherical harmonic coefficients or RGB).
- $A$: Opacities ($\mathbb{R}$, typically $[0, 1]$).

**Parameters:**
- $\tau_c$: Clone Threshold. Typical value: $0.002$ [S1, unofficial].
- $\tau_s$: Base Split Threshold. Typical value: $0.002$ [S1, unofficial].
- $\epsilon$: Prune Threshold (opacity). Typical value: $0.005$ (or $0.5$ for object-centered datasets like DTU) [S1, unofficial].
- $S$: Atom Scale. Defined as the $i$-th percentile of distances between nearest neighbors in the input SfM points, specifically $S = P_1(d)$ (first percentile) for general scenes, or $P_{10}(d)$ for DTU [S1, unofficial].
- $t_a$: Atomized Proliferation Duration (iteration limit for atomization). Typical value: $7000$ [S1, unofficial].
- $t_w$: Warm-Up Duration (iteration limit for dynamic split threshold). Typical value: $7000$ [S1, unofficial].
- $p$: Final proportion of the initial Atom Scale $S$ after atomization [S1, unofficial].

**Algorithm Steps:**
1.  **Initialize Atom Scale:** Calculate $S$ from the input SfM points. Let $d$ be the sorted distances between nearest neighbors in the SfM point cloud. $S = P_i(d)$, where $i$ is typically 1 (first percentile) [S1, unofficial].
2.  **Iterate:** For each training iteration $i$ from $1$ to total iterations:
    3.  **Compute Dynamic Split Threshold:** If $i < t_w$, the split threshold is linearly warmed up: $\tau_s^{(i)} = \min\left(\frac{i}{t_w}\tau_s, \tau_s\right)$. Otherwise, $\tau_s^{(i)} = \tau_s$ [S1, unofficial].
    4.  **Process Each Gaussian:** For every Gaussian $g$ in the set with properties $(\mu, \Sigma, c, \alpha)$:
        5.  **Pruning:** If $\alpha < \epsilon$ OR the covariance $\Sigma$ is "excessively large" (defined by a helper function `IsTooLarge`), remove $g$ [S1, unofficial].
        6.  **Cloning:** If the loss gradient magnitude $\|\nabla_p L\| \ge \tau_c$, clone $g$ [S1, unofficial].
        7.  **Splitting:** If $\|\nabla_p L\| \ge \tau_s^{(i)}$ AND the maximum eigenvalue (or norm) of the covariance $\|\Sigma\|_{\max} > S$, split $g$ into smaller Gaussians [S1, unofficial].
        8.  **Atomization:** If the minimum eigenvalue (or norm) of the covariance $\|\Sigma\|_{\min} \le S$ AND $i < t_a$:
            9.  Designate $g$ as an **Atom Gaussian**.
            10. Set its scale to $s = S^{1/3}$ (assuming isotropic scaling where $s_1=s_2=s_3=s$) [S1, unofficial].
            11. **Fix Scale:** Disable backpropagation for the scale parameters of this Atom Gaussian.
            12. **Update Scale via Geometric Progression:** Update the scale $s$ for subsequent iterations using $s_n = s_{n-1} \cdot r_{n-1}$, where $r = p^{1/t_a}$ [S1, unofficial]. This ensures the Atom Scale decreases over iterations, progressively enhancing fine detail representation [S1, unofficial].
    13. **Opacity Resetting:** Increase the frequency of opacity resetting during training to facilitate the merging of Gaussians depicting large, simple surfaces, rather than just eliminating noisy ones [S1, unofficial].

**Pseudocode:**

```python
def atomized_proliferation(gaussians, sfm_points, tau_c, tau_s, epsilon, p, ta, tw):
    """
    gaussians: List of Gaussian objects with attributes:
               - mu: mean position
               - sigma: covariance matrix
               - color: color data
               - alpha: opacity
               - grad: loss gradient magnitude (precomputed or passed)
    sfm_points: Array of 3D points from SfM
    tau_c: Clone threshold
    tau_s: Base split threshold
    epsilon: Prune threshold
    p: Final proportion of initial Atom Scale
    ta: Total atomization iterations
    tw: Warm-up duration
    """
    # 1. Calculate Atom Scale S from SfM points
    # Compute pairwise distances or nearest neighbor distances for sfm_points
    distances = compute_nearest_neighbor_distances(sfm_points)
    distances.sort()
    # S is the 1st percentile (index 0.01 * len(distances))
    S = distances[int(0.01 * len(distances))]
    
    # Precompute geometric progression factor
    # r = p^(1/ta)
    r = p ** (1.0 / ta)
    
    # Current Atom Scale state for progression (starts at S)
    current_atom_scale = S
    
    for i in range(1, ta + 1): # Iterate up to ta for atomization logic
        # 2. Compute dynamic split threshold
        if i < tw:
            tau_s_dynamic = min((i / tw) * tau_s, tau_s)
        else:
            tau_s_dynamic = tau_s
            
        # 3. Process each Gaussian
        for g in gaussians:
            # 4. Pruning
            if g.alpha < epsilon or is_too_large(g.sigma):
                mark_for_removal(g)
                continue
                
            # 5. Cloning
            if g.grad >= tau_c:
                clone_gaussian(g)
                
            # 6. Splitting
            # ||Sigma||_max > S
            if g.grad >= tau_s_dynamic and max_eigenvalue(g.sigma) > S:
                split_gaussian(g)
                
            # 7. Atomization
            if min_eigenvalue(g.sigma) <= S and i < ta:
                atomize_gaussian(g, current_atom_scale)
                
        # 8. Update Atom Scale for next iteration if atomization is active
        if i < ta:
            current_atom_scale = current_atom_scale * r
            
        # 9. Opacity Resetting (Implementation detail: frequency increased)
        reset_opacities(gaussians, frequency_factor=2.0) # [G] Placeholder for specific reset logic
        
    # Final cleanup of marked Gaussians
    gaussians = remove_marked(gaussians)
    return gaussians

def is_too_large(sigma):
    # [G] Heuristic for "excessively large" covariance. 
    # Typically checks if trace or max eigenvalue exceeds a scene-dependent bound.
    # Not explicitly defined in sources, but implied by Algorithm 1.
    return max_eigenvalue(sigma) > 10.0 * S # [G] Example threshold, not from source

def atomize_gaussian(g, scale_val):
    g.is_atom = True
    # Set scale to isotropic spheroid with size s = S^(1/3)
    # Assuming sigma is parameterized by scale vector s and rotation R
    # s_new = (scale_val)^(1/3)
    s_new = scale_val ** (1.0 / 3.0)
    g.scale = [s_new, s_new, s_new]
    g.requires_grad_scale = False # Fix scale, no backprop
```

**Edge Cases and Pitfalls:**
- **Precision:** The calculation of $S$ depends on the density of SfM points. Sparse SfM points may lead to an overly large $S$, causing premature atomization or incorrect scale [S1, unofficial].
- **Boundaries:** The condition `IsTooLarge(Σ)` is not explicitly defined in the sources. Implementers must define a threshold for "excessively large" covariance, potentially based on scene scale or a multiple of $S$ [S1, unofficial].
- **Degenerate Input:** If SfM points are missing or sparse, $S$ cannot be reliably calculated. The method assumes valid SfM input [S1, unofficial].
- **Dataset Specifics:** For object-centered datasets (e.g., DTU), the Prune Threshold $\epsilon$ should be increased to $0.5$ and Atom Scale $S$ to $P_{10}(d)$ to avoid over-pruning [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Similar to standard 3D Gaussian Splatting per iteration, but with additional checks for atomization and geometric progression updates. The warm-up phase may increase initial densification overhead [S1, unofficial].
- **Memory Complexity:** The final model size is comparable to or slightly smaller than standard 3DGS. On Mip-NeRF360, AtomGS achieved 749MB vs 869MB for 3DGS [S1, unofficial].
- **Measured Performance:** On Mip-NeRF360, average training time was 0.28 hours vs 0.40 hours for 3DGS [S1, unofficial].
- **Strengths:** Enhances geometric precision, reduces noisy meshes and blurry artifacts, stabilizes Gaussian count (declining trend after initial densification), and efficiently models fine details [S1, unofficial].
- **Limitations:** Requires high-quality SfM points for accurate $S$ calculation. May require dataset-specific tuning (e.g., $\epsilon$, $S$ percentile) for object-centered scenes [S1, unofficial].
- **When to Use:** When geometric fidelity and mesh extraction quality are critical, and SfM data is available. Particularly useful for scenes with intricate details [S1, unofficial].
- **When Not to Use:** If SfM points are sparse or unavailable, or if real-time training speed is the primary constraint without regard to geometric precision [S1, unofficial].

## Background
Atomized Proliferation was introduced in the paper "AtomGS: Atomizing Gaussian Splatting for High-Fidelity Radiance Field" by Liu, Xu, Hu, Chen, and Feng [S1, unofficial]. It addresses the limitations of standard 3D Gaussian Splatting, which often produces noisy 3D meshes, blurry artifacts, and suffers from slower convergence due to Gaussians not adhering to underlying geometric structures [S1, unofficial]. The method was developed to provide a more compact and geometrically accurate representation by distinguishing between fine details (Atom Gaussians) and broad background elements [S1, unofficial].
