# On-the-Fly Dynamic NeRF Training

Also called: OD-NeRF

## Overview
On-the-fly Dynamic NeRF Training (OD-NeRF) is a method for training dynamic Neural Radiance Fields concurrently with the acquisition of training frames, enabling the streaming of dynamic scenes as they unfold [S1]. Unlike standard dynamic NeRFs that require full video sequences for offline 4D reconstruction, this approach minimizes rendering loss at each time step $t_k$ using only the current frame and the radiance field from the previous step [S1]. It is distinguished by its application of a first-order Markov assumption to treat the radiance field as a hidden state in a Hidden Markov Model, allowing for incremental updates with minimal optimization iterations per frame [S1].

## How it works
**Inputs and Outputs**
*   **Inputs**: A sequence of multi-view forward-facing camera images $C_{0:K}$ arriving sequentially over time. The current input at step $k$ is the set of images $C_k$ and the previously estimated radiance field $F_{k-1}$.
*   **Outputs**: The updated radiance field function $F_k$ at time $t_k$, which maps spatial coordinates $\mathbf{x}$, viewing direction $\mathbf{d}$, and optionally time $t$ to volume density $\sigma$ and RGB color $\mathbf{c}$ [S1].

**Data Structures**
The radiance field $F$ is represented as a neural network function. The method utilizes an occupancy grid $G$ for efficient sampling, which is also updated via a transition function [S1]. Specific bit-packing or layout details for the grid or network weights are not given in the sources [S1].

**Algorithm Steps**
1.  **Initialization**: Start with an initial radiance field estimate $F_0$ (or empty state) and occupancy grid $G_0$.
2.  **Receive Frame**: Acquire the current set of multi-view images $C_k$ at time $t_k$.
3.  **Markov Simplification**: Apply the first-order Markov assumption to simplify the probability model. Assume conditional independence such that the current radiance field $F_k$ is independent of all previous images $\{C_{0:k-1}\}$ and fields $\{F_{0:k-2}\}$ given the current observation $C_k$ and previous field $F_{k-1}$ [S1]:
    $$ F_k \perp\!\!\!\perp \{C_{0:k-1}, F_{0:k-2}\} \mid \{C_k, F_{k-1}\} $$
    This reduces the estimation problem to:
    $$ F_k = \arg\max_{F_k} P(F_k \mid C_k, F_{k-1}) $$
    [S1]
4.  **Optimization Objective**: Find the radiance field $F_k$ that minimizes the rendering loss between the predicted color $\hat{C}_k(r)$ and the observed color $C_k(r)$ for rays $r \in R$ [S1]:
    $$ F_k = \arg\min_{F_k} \sum_{r \in R} ||\hat{C}_k(r) - C_k(r)||^2_2 $$
    [S1]
5.  **Volume Rendering**: For each ray $r$, compute the predicted color $\hat{C}_k(r)$ by aggregating $N$ points with interval $\delta$ along the ray [S1]:
    $$ \hat{C}(r) = \sum_{i=0}^{N-1} T_i (1 - \exp(-\sigma_i \delta_i)) c_i $$
    where the transmittance $T_i$ is:
    $$ T_i = \exp\left(-\sum_{j=0}^{i-1} \sigma_j \delta_j\right) $$
    [S1]
    Here, $\sigma_i$ and $c_i$ are the density and color predicted by $F_k$ at the $i$-th sample point.
6.  **Transition Update**: Update the occupancy grid $G$ using a simple transition function $P(G_k \mid G_{k-1})$ to maintain efficient sampling for the next step [S1].
7.  **Iterate**: Repeat for $k = 1$ to $K$.

**Pseudocode**
```python
def on_the_fly_training(images_sequence):
    # Initialize radiance field F and occupancy grid G
    F_prev = initialize_radiance_field()
    G_prev = initialize_occupancy_grid()
    
    for k, current_images in enumerate(images_sequence):
        # 1. Define loss function based on current images and previous field
        # Loss = sum over rays r of || rendered_color(r, F_prev) - observed_color(r, current_images) ||^2
        
        # 2. Optimize F to minimize loss
        # Note: Sources indicate "minimum optimization iterations" are required.
        # The specific optimizer (e.g., Adam) and learning rate are not detailed.
        F_curr = optimize_radiance_field(F_prev, current_images)
        
        # 3. Update occupancy grid for efficient sampling
        G_curr = update_occupancy_grid(G_prev, F_curr)
        
        # 4. Prepare for next step
        F_prev = F_curr
        G_prev = G_curr
        
        # The model can render novel views at time t_k using F_curr
        yield F_curr
```

**Parameters**
*   **Camera Setup**: Limited to multi-view forward-facing cameras [S1].
*   **Optimization Iterations**: Minimum iterations per frame are required for fast training, but the exact number is not specified [S1].

**Edge Cases and Pitfalls**
*   **Scalability**: Estimating $F_k$ conditioned on all previous images $C_{0:k}$ is not scalable as time $t_k$ increases. The Markov assumption is critical to mitigate this complexity growth [S1].
*   **Camera Constraints**: The method is limited to multi-view forward-facing cameras. Monocular setups require camera movement which is cumbersome for prolonged streaming, and 360-degree inward-facing setups require dozens of cameras and large spaces, which are difficult for most streamers to acquire [S1].

## Operating characteristics
*   **Time Complexity**: Designed for interactive speed. It requires minimum optimization iterations per frame compared to offline training on full sequences [S1].
*   **Memory Complexity**: Uses an occupancy grid $G$ for efficient sampling, which is updated incrementally [S1].
*   **Strengths**: Enables streaming of dynamic scenes while they happen, suitable for social media, VR/AR, and gaming [S1].
*   **Limitations**: Restricted to multi-view forward-facing camera setups [S1].
*   **When to use**: When real-time or near-real-time streaming of a dynamic scene is required, and the scene can be captured by a static multi-view forward-facing camera rig.
*   **When not to use**: For offline reconstruction of 4D space-time from full video sequences, or for scenes captured by monocular cameras requiring significant camera movement.

## Background
On-the-fly Dynamic NeRF Training (OD-NeRF) was introduced to address the limitation of existing dynamic NeRFs, which focus on reconstructing scenes given full training videos and cannot stream the event while it is happening [S1]. The method formulates the training process as estimating hidden states in a Hidden Markov Model, where radiance fields are hidden states and images are observations [S1]. It builds on the success of NeRF acceleration techniques that allow training small scenes in seconds [S1].
