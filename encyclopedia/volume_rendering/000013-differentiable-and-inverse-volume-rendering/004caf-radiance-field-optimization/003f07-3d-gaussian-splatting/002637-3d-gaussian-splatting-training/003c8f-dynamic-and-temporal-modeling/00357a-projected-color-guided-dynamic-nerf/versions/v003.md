# Projected Color-Guided Dynamic NeRF

Also called: OD-NeRF

## Overview
Projected Color-Guided Dynamic NeRF (OD-NeRF) is an on-the-fly training method for dynamic scenes that replaces explicit temporal inputs or deformation fields with conditioning on multi-view projected colors [S1]. By leveraging the invariance of projected color for corresponding 3D points across frames, it implicitly tracks correspondence, allowing the model to utilize radiance fields from previous frames to render the current frame with minimal optimization iterations [S1]. Unlike siblings such as [D-NeRF](8660-d-nerf.md) which rely on deformation fields that extrapolate poorly to unseen times, or [Neural Transient Field (NeTF)](4692-neural-transient-field-netf.md) which models transient artifacts explicitly, OD-NeRF achieves interactive speeds (6 FPS) by avoiding the computational overhead of temporal modeling [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A sequence of multi-view images (frames). For each frame, the method requires the camera parameters and the radiance field (density $\sigma$ and color $\mathbf{c}$) estimated from the previous frame.
*   **Outputs:** A rendered image for the current frame and an updated radiance field representation optimized for the current frame.

**Data Structures:**
1.  **Occupancy Grid:** A sparse grid storing occupancy values $\sigma_{occ}$ for spatial regions. Used for efficient sampling via rejection sampling [S1].
2.  **Hash Voxel Grid:** Replaces the multi-scale voxel grid used in the base TiNeuVox model. Implemented using `tiny-cuda-nn` [S1].
3.  **NeRF MLP:** A Multi-Layer Perceptron that outputs density and color. Its input is the concatenation of spatial features and projected color statistics [S1].

**Numbered Steps:**

1.  **Initialization (Frame 1):**
    *   For synthetic datasets, initialize the model by removing temporal components (temporal deformation model and temporal information enhancement) present in the base TiNeuVox architecture [S1].
    *   Replace the multi-scale voxel grid with a hash voxel grid [S1].
    *   Apply a warm-up duration of 2 seconds for the first frame to compensate for the slower convergence of hashed voxels compared to multi-scale voxels [S1].
    *   For real-world datasets, initialize using the NerfAcc implementation of InstantNGP [S1].

2.  **Projected Color Computation:**
    *   For a sampled 3D point $\mathbf{x}$, compute its projected color from the training views.
    *   Calculate the mean ($\mu_c$) and variance ($\sigma_c^2$) of these projected colors [S1].

3.  **Feature Concatenation:**
    *   Query the spatial feature $\mathbf{f}_{spatial}$ from the voxel grid (hash grid for real-world, or the modified grid for synthetic) at $\mathbf{x}$ [S1].
    *   Concatenate $\mathbf{f}_{spatial}$ with $\mu_c$ and $\sigma_c^2$ to form the input vector for the NeRF MLP [S1].

4.  **NeRF Evaluation:**
    *   Pass the concatenated input through the NeRF MLP to predict density $\sigma$ and color $\mathbf{c}$ [S1].

5.  **Efficient Sampling (Transition and Update):**
    *   Use the occupancy grid from the previous frame to guide sampling for the current frame.
    *   Perform rejection sampling on uniform ray samples. A sample $x_i$ at index $i$ along the ray is rejected if:
        $$ \text{reject } x_i \text{ if } (\sigma_{occ}(x_i) < \sigma_{min}) \land \neg(i \mod R \equiv R//2) $$
        where $\sigma_{min}$ is a density threshold and $R$ is a fixed interval [S1].
    *   Update the occupancy grid for the current frame based on the new samples [S1].

6.  **Optimization:**
    *   Optimize the NeRF parameters for the current frame using the rendered image and the ground truth image.
    *   For real-world datasets, apply a depth smoothness regularization loss $L_{depth}$ to handle large planar backgrounds:
        $$ L_{depth} = \frac{\text{std}(d_{far} / d_{3 \times 3})}{\text{std}(c_{3 \times 3})} $$
        where $d_{far}$ is the depth of the farthest sample, $d_{3 \times 3}$ is the mean depth of a $3 \times 3$ patch of rays, and $c_{3 \times 3}$ is the mean color of that patch [S1].
    *   Decay the optimization iterations or learning rate schedule from 1 (at frame 1) to 0.05 (at frame 10) to aid convergence [S1].

**Pseudocode:**

```python
def train_od_nerf_frame(prev_occupancy_grid, current_images, cameras, prev_nerf_mlp):
    """
    Trains the OD-NeRF model for a single frame on-the-fly.
    
    Args:
        prev_occupancy_grid: Occupancy grid from the previous frame.
        current_images: List of images for the current frame.
        cameras: Camera parameters for the current frame.
        prev_nerf_mlp: NeRF MLP from the previous frame (or initialized).
        
    Returns:
        current_nerf_mlp: Optimized NeRF MLP for the current frame.
        current_occupancy_grid: Updated occupancy grid.
    """
    # Step 1: Initialize or Load Model
    # For synthetic: Remove temporal components, use hash grid
    # For real-world: Use InstantNGP via NerfAcc
    nerf_mlp = prev_nerf_mlp.clone()
    
    # Step 2: Sampling Loop
    for ray in sample_rays(cameras):
        # Generate uniform samples along the ray
        uniform_samples = generate_uniform_samples(ray, num_samples=256)
        
        # Step 5: Efficient Sampling via Rejection
        valid_samples = []
        for i, x_i in enumerate(uniform_samples):
            # Query occupancy from previous frame's grid
            sigma_occ = query_occupancy(prev_occupancy_grid, x_i)
            
            # Rejection condition
            if sigma_occ < sigma_min and not (i % R == R // 2):
                continue
            
            valid_samples.append(x_i)
        
        # Step 3: Feature Computation
        features = []
        for x in valid_samples:
            # Query spatial feature from hash grid
            f_spatial = query_hash_grid(nerf_mlp.voxel_grid, x)
            
            # Compute projected color statistics from training views
            # Note: In practice, this might be pre-computed or approximated
            projected_colors = get_projected_colors(x, cameras, training_views)
            mu_c = mean(projected_colors)
            sigma_c = variance(projected_colors)
            
            # Concatenate features
            input_vector = concatenate([f_spatial, mu_c, sigma_c])
            features.append((input_vector, x))
        
        # Step 4: NeRF Evaluation
        densities = []
        colors = []
        for input_vector, x in features:
            sigma, c = nerf_mlp(input_vector)
            densities.append(sigma)
            colors.append(c)
        
        # Step 6: Optimization
        # Render image from densities and colors
        rendered_image = volume_rendering(densities, colors, ray)
        
        # Compute loss against ground truth
        loss = compute_loss(rendered_image, current_images[ray.camera_id])
        
        # Add depth regularization for real-world datasets
        if is_real_world_dataset:
            # Compute patch-based depth regularization
            patch_depths = get_patch_depths(valid_samples)
            patch_colors = get_patch_colors(valid_samples)
            depth_loss = compute_depth_smoothness_loss(patch_depths, patch_colors)
            loss += depth_loss_weight * depth_loss
        
        # Backpropagate and update MLP
        update_parameters(nerf_mlp, loss)
    
    # Update occupancy grid for next frame
    current_occupancy_grid = update_occupancy_grid(prev_occupancy_grid, valid_samples, densities)
    
    return nerf_mlp, current_occupancy_grid
```

**Parameters:**
*   **Warm-up duration:** 2 seconds for the first frame in synthetic datasets [S1].
*   **Density threshold ($\sigma_{min}$):** Not given in the sources.
*   **Fixed interval ($R$):** Not given in the sources.
*   **Optimization decay:** From 1 (frame 1) to 0.05 (frame 10) [S1].

**Edge Cases and Pitfalls:**
*   **Specular Surfaces:** Specular surfaces violate the relative invariance of projected color, leading to artifacts [S1].
*   **Occluded Points:** Occluded points also violate the invariance assumption, causing artifacts [S1].
*   **Convergence on Real-World Data:** The NerfAcc implementation of InstantNGP may not converge well on forward-facing dynamic datasets with large planar backgrounds (e.g., walls, tables) due to constant colors [S1]. This is mitigated by the depth smoothness regularization [S1].

## Operating characteristics
*   **Time Complexity:** The method achieves an interactive speed of 6 FPS for training and rendering on synthetic dynamic scenes on-the-fly [S1]. It requires the minimum number of optimization iterations for each new frame compared to models with temporal inputs or deformation fields [S1].
*   **Memory Complexity:** Uses a hash voxel grid (via `tiny-cuda-nn`) which is more memory-efficient than dense voxel grids, but converges slower than multi-scale voxels [S1].
*   **Strengths:** Excellent temporal extrapolation capability; does not require explicit deformation fields; efficient on-the-fly training [S1].
*   **Limitations:** Performance degrades on specular surfaces and occluded points; requires careful tuning of depth regularization for real-world datasets with large planar backgrounds [S1].
*   **When to Use:** When real-time or near-real-time training and rendering of dynamic scenes is required, and the scene does not contain significant specularities or complex occlusions [S1].
*   **When Not to Use:** When the scene contains many specular surfaces or heavy occlusions, as the projected color invariance assumption will be violated [S1].

## Background
OD-NeRF was introduced in the paper "OD-NeRF: Efficient Training of On-the-Fly Dynamic Neural Radiance Fields" [S1]. It addresses the challenge of efficient on-the-fly training where the radiance field is trained and rendered frame-by-frame. Previous dynamic NeRFs focused on reconstructing scenes from full training videos using space-time 4D or explicit deformation representations, which often extrapolate poorly to unseen times and require many optimization iterations [S1]. OD-NeRF proposes conditioning the NeRF on multi-view projected colors to implicitly track correspondence, enabling effective utilization of radiance fields from previous frames [S1]. It is implemented on top of TiNeuVox for synthetic datasets and InstantNGP (via NerfAcc) for real-world datasets [S1].
