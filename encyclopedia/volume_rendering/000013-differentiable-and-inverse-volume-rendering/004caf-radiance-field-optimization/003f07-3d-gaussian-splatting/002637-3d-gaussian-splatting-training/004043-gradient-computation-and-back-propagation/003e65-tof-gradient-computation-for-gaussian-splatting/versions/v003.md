# ToF Gradient Computation for Gaussian Splatting

Also called: Opacity gradient for ToF image formation, Recursive gradient for quad pixels

## Overview
This method computes the gradient of the loss function with respect to the opacity parameter $\alpha_k$ of the $k$-th Gaussian specifically for Time-of-Flight (ToF) image formation models, such as phasor or quad pixel signals [S1]. It extends the standard differentiable volume rendering chain rule by introducing recursive accumulation terms that account for the squared transmittance factors inherent in ToF signal integration [S1]. Unlike standard RGB rendering where the opacity gradient depends linearly on transmittance, ToF gradients require a modified recursion to correctly propagate gradients through the non-linear mixing of quad contributions [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** The loss gradient with respect to the rendered ToF signal, $\frac{\partial L}{\partial \mathbf{q}(\mathbf{x})}$ (or $\frac{\partial L}{\partial \mathbf{c}(\mathbf{x})}$ for color); the sorted list of $N$ Gaussians back-to-front; the opacity $\alpha_k$ and quad contribution $\mathbf{q}_k$ for each Gaussian $k$; and the transmittance $T_k$ up to Gaussian $k$.
*   **Output:** The gradient $\frac{\partial L}{\partial \alpha_k}$ for each Gaussian $k$.

**Data Structures:**
*   **Accumulator:** A scalar or vector variable $\text{acc}_k^q$ (for quad signals) or $\text{acc}_k$ (for color) that stores the aggregated contribution of all Gaussians $m > k$.
*   **Transmittance:** $T_k = \prod_{m < k} (1 - \alpha_m)$.

**Numbered Steps:**
1.  Initialize the accumulator for the last Gaussian ($k=N$) to zero:
    $$ \text{acc}_N^q = 0 $$
2.  Iterate backwards from $k = N-1$ down to $0$:
    a. Compute the recursive accumulation term using the squared transmittance factor:
    $$ \text{acc}_k^q = \alpha_{k+1} \mathbf{q}_{k+1} + (1 - \alpha_{k+1})^2 \text{acc}_{k+1}^q $$
    b. Compute the gradient of the signal with respect to opacity $\alpha_k$:
    $$ \frac{\partial \mathbf{q}(\mathbf{x})}{\partial \alpha_k} = T_k^2 \left( \mathbf{q}_k + 2(\alpha_k - 1)\text{acc}_k^q \right) $$
    c. Apply the chain rule to get the final loss gradient:
    $$ \frac{\partial L}{\partial \alpha_k} = \frac{\partial L}{\partial \mathbf{q}(\mathbf{x})} \cdot \frac{\partial \mathbf{q}(\mathbf{x})}{\partial \alpha_k} $$

**Formulas:**
The core gradient computation for ToF quad pixel signals $\mathbf{q}(\mathbf{x})$ is defined as [S1]:
$$ \frac{\partial \mathbf{q}(\mathbf{x})}{\partial \alpha_k} = T_k^2(\mathbf{q}_k + 2(\alpha_k - 1)\text{acc}_k^q) $$
where:
*   $T_k$ is the transmittance up to the $k$-th Gaussian.
*   $\mathbf{q}_k$ is the quad contribution of the $k$-th Gaussian.
*   $\text{acc}_k^q$ is the accumulated quad contribution from all subsequent Gaussians ($m > k$).

The accumulation term $\text{acc}_k^q$ is defined recursively as [S1]:
$$ \text{acc}_k^q = \begin{cases} \alpha_{k+1} \mathbf{q}_{k+1} + (1 - \alpha_{k+1})^2 \text{acc}_{k+1}^q, & k < N \\ 0, & k = N \end{cases} $$

For comparison, the standard 3DGS color rendering gradient uses a linear accumulation [S1]:
$$ \frac{\partial \mathbf{c}(\mathbf{x})}{\partial \alpha_k} = T_k(\mathbf{c}_k - \alpha \mathbf{c}_k) $$
$$ \text{acc}_k = \begin{cases} \alpha_{k+1} \mathbf{c}_{k+1} + (1 - \alpha_{k+1}) \text{acc}_{k+1}, & k < N \\ 0, & k = N \end{cases} $$
Note: The source [S1] writes the color gradient term as $\alpha \mathbf{c}_k$, which contextually refers to the interaction with the accumulated background, but the ToF derivation explicitly uses the squared transmittance $(1-\alpha_{k+1})^2$ in the recursion.

    return grad_alpha

**Parameters:**
*   $T_k$: Transmittance. Not given in the sources.
*   $\mathbf{q}_k$: Quad contribution. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Squared Transmittance:** The recursion involves $(1 - \alpha_{k+1})^2$, which makes the gradient computation less trivial than standard 3DGS [S1].
*   **Precision:** Squaring small transmittance values can lead to underflow or loss of precision if not handled carefully, though this is not explicitly detailed in the sources [S1].
*   **Boundary Conditions:** The base case $\text{acc}_N^q = 0$ must be strictly enforced [S1].

## Operating characteristics
*   **Time Complexity:** Linear in the number of Gaussians $N$ per pixel, as it requires a single backward pass to compute the accumulator and gradients.
*   **Memory Complexity:** Linear in $N$ to store the transmittances and gradients.
*   **Strengths:** Correctly handles the non-linear mixing of ToF signals (phasor/quad) which standard RGB gradients do not account for.
*   **Limitations:** More complex than standard RGB gradient computation due to the squared transmittance terms [S1].
*   **When to use:** Specifically for Time-of-Flight (ToF) image formation models in 3D Gaussian Splatting.

## Background
*   **Origin:** The method is described in "Time of the Flight of the Gaussians: Optimizing Depth Indirectly in Dynamic Radiance Fields" [S1].
*   **History:** It extends the original 3D Gaussian Splatting differentiable rendering framework to support ToF sensors.
*   **Usage:** Used in optimizing depth indirectly in dynamic radiance fields using ToF data.
