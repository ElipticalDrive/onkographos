# ToF Gradient Computation for Gaussian Splatting

Also called: Opacity gradient for ToF image formation, Recursive gradient for quad pixels

## Overview
This method computes the gradient of the loss function with respect to the opacity parameter $\alpha_k$ of the $k$-th Gaussian in Time-of-Flight (ToF) image formation models, specifically for phasor or quad pixel signals [S1]. It extends the standard 3D Gaussian Splatting (3DGS) opacity gradient by introducing squared transmittance terms in the recursive accumulation, addressing the non-linear interaction between opacity and ToF signal intensity [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Loss function $L$, opacity parameter $\alpha_k$, transmittance $T_k$, Gaussian quad contribution $\mathbf{q}_k$, and accumulated quad signal $\text{acc}_k^q$ from subsequent Gaussians.
*   **Output:** Gradient $\frac{\partial L}{\partial \alpha_k}$.

**Data Structures:**
*   $\alpha_k$: Scalar opacity of the $k$-th Gaussian.
*   $T_k$: Scalar transmittance up to the $k$-th Gaussian.
*   $\mathbf{q}_k$: Vector (or scalar per channel) representing the quad pixel contribution of the $k$-th Gaussian.
*   $\text{acc}_k^q$: Accumulator for quad contributions from Gaussians $k+1$ to $N$.

**Recursive Definitions:**
The computation relies on two recursive accumulators: one for standard color (used in the parent method) and one for ToF quad signals.

1.  **Standard Color Accumulation ($\text{acc}_k$):**
    $$ \text{acc}_k = \begin{cases} \alpha_{k+1} \mathbf{c}_{k+1} + (1 - \alpha_{k+1}) \text{acc}_{k+1}, & k < N \\ 0, & k = N \end{cases} $$
    where $\mathbf{c}_k$ is the color of the $k$-th Gaussian [S1].

2.  **ToF Quad Accumulation ($\text{acc}_k^q$):**
    $$ \text{acc}_k^q = \begin{cases} \alpha_{k+1} \mathbf{q}_{k+1} + (1 - \alpha_{k+1})^2 \text{acc}_{k+1}^q, & k < N \\ 0, & k = N \end{cases} $$
    where $\mathbf{q}_k$ is the quad contribution of the $k$-th Gaussian [S1].

**Gradient Formulas:**
The total gradient is computed via the chain rule:
$$ \frac{\partial L}{\partial \alpha_k} = \frac{\partial L}{\partial \mathbf{c}(\mathbf{x})} \frac{\partial \mathbf{c}(\mathbf{x})}{\partial \alpha_k} $$
Note: In the context of ToF, $\mathbf{c}(\mathbf{x})$ represents the signal vector (e.g., quad pixels $\mathbf{q}(\mathbf{x})$). The specific partial derivative $\frac{\partial \mathbf{c}(\mathbf{x})}{\partial \alpha_k}$ depends on the signal type.

1.  **Standard 3DGS Color Gradient:**
    $$ \frac{\partial \mathbf{c}(\mathbf{x})}{\partial \alpha_k} = T_k(\mathbf{c}_k - \alpha \mathbf{c}_k) $$
    *Note: The source text writes $\alpha \mathbf{c}_k$ in Eq. (S11). Given the context of standard 3DGS, this likely refers to the accumulated opacity term or a typo for $\alpha_k$, but the formula is reproduced exactly as cited [S1].*

2.  **ToF Quad Pixel Gradient:**
    $$ \frac{\partial \mathbf{q}(\mathbf{x})}{\partial \alpha_k} = T_k^2(\mathbf{q}_k + 2(\alpha_k - 1)\text{acc}_k^q) $$
    This formula accounts for the squared transmittance interaction inherent in ToF signal formation [S1].

**Pseudocode:**
The following Python-like pseudocode implements the backward pass for opacity gradients for a single pixel, processing Gaussians in back-to-front order ($k = N-1$ down to $0$).

```python
def compute_opacity_gradients(gaussians, loss_grad_signal):
    """
    gaussians: List of Gaussian objects, sorted back-to-front.
               Each has attributes: alpha, c (color), q (quad signal), T (transmittance).
    loss_grad_signal: Gradient of loss w.r.t. the final signal (color or quad).
    
    Returns:
    gradients_alpha: List of gradients dL/d_alpha_k for each Gaussian.
    """
    N = len(gaussians)
    gradients_alpha = [0.0] * N
    
    # Initialize accumulators
    acc_color = 0.0
    acc_quad = 0.0
    
    # Process Gaussians from last (N-1) to first (0)
    for k in range(N - 1, -1, -1):
        g = gaussians[k]
        
        # 1. Compute Standard Color Gradient Component
        # Formula: T_k * (c_k - alpha * c_k)
        # Note: Source uses 'alpha' in the term (alpha * c_k). 
        # Assuming this refers to the accumulated opacity or is a typo for g.alpha.
        # Based on standard 3DGS, the term is usually T_k * (c_k - acc_color_accumulated).
        # However, we follow the source text strictly: T_k * (c_k - alpha * c_k)
        # [G] Interpreting 'alpha' in source formula S11 as the current Gaussian's opacity g.alpha 
        # for consistency with variable naming, though standard 3DGS uses accumulated transmittance.
        # If 'alpha' refers to accumulated opacity, it would be derived from T. 
        # Given the ambiguity, we use g.alpha as the most direct variable available.
        grad_c_part = g.T * (g.c - g.alpha * g.c)
        
        # 2. Compute ToF Quad Gradient Component
        # Formula: T_k^2 * (q_k + 2 * (alpha_k - 1) * acc_k^q)
        grad_q_part = (g.T ** 2) * (g.q + 2 * (g.alpha - 1) * acc_quad)
        
        # 3. Combine based on signal type
        # If optimizing for color, use grad_c_part. If optimizing for ToF quad, use grad_q_part.
        # The source implies these are separate models or extensions.
        # For a unified ToF model, the loss gradient is w.r.t the quad signal.
        # dL/d_alpha_k = dL/d_signal * d_signal/d_alpha_k
        
        # Assuming we are computing the gradient for the ToF quad signal model:
        d_signal_d_alpha = grad_q_part
        
        # Chain rule: dL/d_alpha = dL/d_signal * d_signal/d_alpha
        gradients_alpha[k] = loss_grad_signal * d_signal_d_alpha
        
        # 4. Update Accumulators for the next iteration (k-1)
        # Standard Color Accumulator
        # acc_k = alpha_{k+1} * c_{k+1} + (1 - alpha_{k+1}) * acc_{k+1}
        # Note: In the loop, 'g' is the current Gaussian (k). The accumulator update 
        # uses the CURRENT Gaussian's parameters to contribute to the NEXT (k-1) accumulator.
        # The source defines acc_k based on k+1. So when moving from k to k-1, 
        # we update acc using k's data.
        acc_color = g.alpha * g.c + (1 - g.alpha) * acc_color
        
        # ToF Quad Accumulator
        # acc_k^q = alpha_{k+1} * q_{k+1} + (1 - alpha_{k+1})^2 * acc_{k+1}^q
        acc_quad = g.alpha * g.q + ((1 - g.alpha) ** 2) * acc_quad
        
    return gradients_alpha
```

**Parameters:**
*   $T_k$: Transmittance up to the $k$-th Gaussian.
*   $\mathbf{c}_k$: Color of the $k$-th Gaussian.
*   $\mathbf{q}_k$: Quad contribution of the $k$-th Gaussian.

**Edge Cases and Pitfalls:**
*   **Squared Terms:** The ToF gradient involves squared transmittance ($T_k^2$) and squared opacity terms in the accumulator ($(1-\alpha_{k+1})^2$), making it computationally more complex and potentially more sensitive to precision issues than standard 3DGS [S1].
*   **Recursion Order:** The accumulation must be computed in back-to-front order (from $N$ to $0$) to correctly propagate contributions from later Gaussians to earlier ones [S1].
*   **Ambiguity in Standard Formula:** The source text for the standard 3DGS gradient contains the term $\alpha \mathbf{c}_k$ without explicitly defining $\alpha$ as either $\alpha_k$ or accumulated opacity. This requires careful interpretation during implementation [S1].

## Operating characteristics
*   **Complexity:** The computation is $O(N)$ per pixel, where $N$ is the number of Gaussians, similar to standard 3DGS. However, the ToF variant requires additional multiplications for the squared terms.
*   **Performance:** The method is less trivial than standard chain rule gradients due to the recursive nature and squared terms [S1].
*   **Accuracy:** The approach provides reliable depth reconstruction without catastrophic failures, outperforming baselines on synthetic datasets like F-ToRF [S1].

## Background
This method was introduced in the paper "Time of the Flight of the Gaussians: Optimizing Depth Indirectly in Dynamic Radiance Fields" [S1]. It extends the original 3D Gaussian Splatting framework [13] to handle Time-of-Flight signals, specifically phasor and quad pixel models. The key innovation is the derivation of the opacity gradient for these non-linear signal models, which differs from the linear color accumulation in standard 3DGS.
