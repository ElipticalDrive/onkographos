# Opacity Split for Cloning

Also called: Cloning Strategy for Gaussian Splatting, Revising Densification Opacity Initialization

## Overview
Opacity Split for Cloning is a densification strategy in 3D Gaussian Splatting that clones a parent Gaussian into $N$ copies while preserving the rasterization outcome. It solves the problem of transmittance bias introduced when cloned children inherit the parent's opacity, which causes the parent-child pair to block subsequent primitives more than the parent alone did [S2]. It sets itself apart from standard cloning by analytically deriving opacity values that maintain transmittance consistency, whereas standard methods simply duplicate the parent's opacity [S1, S2].

## How it works
**Inputs:**
- Parent Gaussian $g_{old}$ with opacity $o_{old}$, covariance $\Sigma_{old}$, and central color $C_{old}(\mu)$ [S1].
- Number of clones $N$ [S1].

**Outputs:**
- $N$ cloned Gaussians $g_{new}^{(i)}$ for $i=1 \dots N$ [S1].

**Data Structures:**
- Each Gaussian $g$ stores:
  - $\mu \in \mathbb{R}^3$: Mean position [S1].
  - $\Sigma \in \mathbb{R}^{3 \times 3}$: Covariance matrix (often stored as rotation $R$ and scale $s$) [S1].
  - $o \in [0, 1]$: Opacity [S1].
  - $C \in \mathbb{R}^3$: Central color value [S1].

**Steps:**
1. **Initialize Geometry and Color:** Set the covariance and central color of all cloned Gaussians identical to the parent [S1]:
   $$ \Sigma_{new}^{(i)} = \Sigma_{old} $$
   $$ C_{new}^{(i)}(\mu) = C_{old}(\mu) $$
   [S1]

2. **Calculate Opacity:** Compute the new opacity $o_{new}$ for both the parent and the clones to preserve transmittance.
   - For $N=2$ clones (standard cloning), the opacity is derived from the transmittance equation $(1 - o_{new})^2 = 1 - o_{old}$ [S1, S2]:
     $$ o_{new} = 1 - \sqrt{1 - o_{old}} $$
     [S2]
   - For general $N$, the relationship is:
     $$ o_{new} = 1 - (1 - o_{old})^{1/N} $$
     [S1]
   - Assign $o_{new}$ to the parent $g_{old}$ and all $N$ clones $g_{new}^{(i)}$ [S1, S2].

3. **Adjust Covariance (Optional/Advanced):** The opacity adjustment alone is insufficient because Gaussians are not point sources; the covariance $\Sigma$ must also be altered to preserve the integrated rasterization along arbitrary slices [S1].
   - The objective is to minimize the squared error of integrated 1D slices passing through the Gaussian centers:
     $$ \text{minimize } \left\| \int_{-\infty}^{\infty} \mathbf{C}^{new}(x) dx - \int_{-\infty}^{\infty} \mathbf{C}^{old}(x) dx \right\|_2^2, \quad \forall \mathcal{S} $$
     [S1]
   - This integral constraint ensures that the total "mass" of the Gaussian along any slice through its center is conserved. While a full 3D MSE minimization is complex, this 1D slice approach provides an analytical solution for adjusting scales [S1].

**Parameters:**
- $N$: Number of clones. Typically $N=2$ in standard implementations [S1, S2].
- $o_{old}$: Parent opacity before cloning [S1].

**Edge Cases and Pitfalls:**
- **Transmittance Bias:** If cloned children inherit $o_{old}$, the combined transmittance of the parent and child becomes $(1-o_{old})^2$, which is lower than the parent's original transmittance $(1-o_{old})$. This causes the cloned pair to occlude subsequent Gaussians more aggressively, biasing the optimization [S2].
- **Point Source Assumption:** Equation $(1 - o^{new})^N = 1 - o^{old}$ preserves intensity at the center $\mu$ but does not preserve the full rasterization shape because Gaussians have extent [S1]. Covariance adjustment is required for full fidelity [S1].
- **Precision:** For $N > 2$, the exponent $1/N$ may introduce floating-point precision issues if $o_{old}$ is very close to 1 or 0. Guard against negative values inside the root if $o_{old} > 1$ due to numerical drift [G].

**Pseudocode:**
```python
def opacity_split_for_cloning(parent_gaussian, num_clones):
    """
    Clones a Gaussian into num_clones copies with adjusted opacity.
    
    Args:
        parent_gaussian: Object with attributes .opacity, .covariance, .color
        num_clones: Integer N >= 2
        
    Returns:
        list of new Gaussian objects
    """
    o_old = parent_gaussian.opacity
    # Clamp opacity to valid range [0, 1] to prevent numerical errors
    o_old = max(0.0, min(1.0, o_old))
    
    # Calculate new opacity using the derived formula
    # o_new = 1 - (1 - o_old)^(1/N)
    transmittance_old = 1.0 - o_old
    transmittance_new = transmittance_old ** (1.0 / num_clones)
    o_new = 1.0 - transmittance_new
    
    # Initialize clones
    clones = []
    for i in range(num_clones):
        clone = Gaussian()
        clone.opacity = o_new
        clone.covariance = parent_gaussian.covariance.copy()
        clone.color = parent_gaussian.color.copy()
        # Note: Mean position might be perturbed or kept identical depending on 
        # the specific densification trigger logic (not covered here)
        clones.append(clone)
        
    # Update parent opacity
    parent_gaussian.opacity = o_new
    
    return clones
```

## Operating characteristics
- **Time Complexity:** $O(1)$ per clone for opacity calculation. Covariance adjustment (if implemented) depends on the optimization method but is typically $O(1)$ if using the analytical slice solution [S1].
- **Memory Complexity:** Increases by $N \times \text{size}(g)$ per clone [S1].
- **Measured Performance:** Preserves rendering fidelity during densification, reducing artifacts caused by transmittance bias [S2].
- **Strengths:** Analytically correct opacity initialization; simple to implement [S1, S2].
- **Limitations:** Does not automatically adjust covariance; requires additional steps for full rasterization preservation [S1].
- **When to Use:** When cloning Gaussians to resolve under-reconstruction, especially if transmittance bias is observed [S2].
- **When Not to Use:** When computational resources are extremely limited and approximate cloning is acceptable, or when using methods that do not rely on alpha blending transmittance [G].

## Background
Originated from the need to fix transmittance bias in 3D Gaussian Splatting densification. Bulo et al. (2024) proposed the opacity split formula $o_{new} = 1 - \sqrt{1 - o_{old}}$ to equally split opacity between parent and child [S2]. The general $N$-clone formula and the slice-based covariance adjustment were derived in the context of 3D Gaussian Splatting as Markov Chain Monte Carlo [S1].
