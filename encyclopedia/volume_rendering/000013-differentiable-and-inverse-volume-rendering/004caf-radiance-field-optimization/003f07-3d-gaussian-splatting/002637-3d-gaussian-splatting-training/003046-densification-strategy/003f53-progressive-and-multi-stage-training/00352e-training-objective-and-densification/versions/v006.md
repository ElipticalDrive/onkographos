# Training Objective and Densification

Also called: MeshGS Training, Tightly/Loosely-bound Training

## Overview
This method defines the loss function and densification strategy for **MeshGS** [S1], a variant of 3D Gaussian Splatting that aligns primitives with an explicit mesh surface. It solves the problem of Gaussian splats drifting away from geometry or expanding excessively by introducing surface-aware regularization and projection losses. It differs from standard 3DGS [22] by splitting the primitive population into **tightly-bound** ($G^t$) and **loosely-bound** ($G^l$) sets, applying mesh-aligned constraints only to the former, while loosely-bound splats follow the original densification rules. It differs from [SuGaR](9138-fine-tuning.md) by using a specific projection loss to enforce proximity to the mesh surface rather than relying solely on normal consistency.

## How it works
**Inputs:**
*   Rendered image $\hat{I}_i$ and ground truth image $I_i$.
*   Set of tightly-bound Gaussian splats $G^t$ and loosely-bound splats $G^l$.
*   Mesh $M$ consisting of faces $F$, where each face $f_j$ has vertices $v_i$ and normal $n_f$.
*   For each Gaussian $i \in G^t$: center $P_i$, scale parameters $S_i = (s_1, s_2, s_3)$, and rotation matrix $R_i$.

**Outputs:**
*   Total loss $L$ used for gradient-based optimization.

**Data Structures:**
*   **Gaussian Splat:** Contains position $P_i$, scale $S_i$, rotation $R_i$, opacity, and color.
*   **Mesh Face:** Defined by vertices $v_i$ and normal $n_f$.

**Parameters:**
*   $\lambda_{img} = 0.001$ [S1]
*   $\lambda_{nc} = 0.1$ [S1]
*   $\lambda_{min} = 0.1$ [S1]
*   $\lambda_{max} = 10$ [S1]
*   $\lambda_{proj} = 50$ [S1]
*   $\rho = 0.1$ (scale threshold) [S1]
*   $d_{th} = 0.01$ (distance threshold for binding) [S1]
*   Split scale factor: $1.6$ [S1]
*   Training iterations: $30,000$ [S1]

**Steps:**

1.  **Image Loss Calculation:** Compute the difference between the rendered image $\hat{I}_i$ and the ground truth $I_i$ using a combination of L1 loss and D-SSIM [S1]:
    $$L_{img} = (1-\lambda_{img})L_{1}(\hat{I}_{i},I_{i}) + \lambda_{img}SSIM(\hat{I}_{i}, I_{i})$$

2.  **Normal Estimation for Tightly-Bound Splats:** For each $i \in G^t$, estimate the normal $n_i$ by identifying the axis corresponding to the minimum scale value in $S_i$, and applying the rotation matrix $R_i$ to transform this axis into world coordinates [S1].

3.  **Normal Consistency Loss:** Calculate the alignment between the estimated splat normals $n_i$ and the mesh face normals $n_f$ for all faces $f \in F$ associated with the splat [S1]:
    $$L_{nc} = \sum _{i \in G^{t},f \in F} (1 - n_{i} \cdot n_{f})$$

4.  **Scale Regularization:** Prevent tightly-bound splats from expanding excessively by regularizing their scale parameters $S_i = (s_1, s_2, s_3)$ [S1]:
    $$L_{scale} = \sum _{i \in G^{t}}(\lambda _{min}|\text {min}(s_{1}, s_{2}, s_{3})| + \lambda _{max}|\text {max}(s_{1}, s_{2}, s_{3}) - \rho |)$$
    This ensures the minimum scale is small and the maximum scale is close to the threshold $\rho$ [S1].

5.  **Projection Loss:** Project the center $P_i$ of each tightly-bound splat to the closest point $s_i$ on the mesh surface to ensure proximity [S1]. The projection is calculated as:
    $$s_{i} = P_{i} + ((P_{i} - v_{i}) \cdot f_{j}) \cdot f_{j}$$
    $$L_{proj} = \sum _{i \in G^{t}}\parallel s_{i} - P_{i} \parallel _{2}$$
    *Note: The source formula uses $f_j$ in the projection equation, implying $f_j$ represents the surface normal or vector component used for projection. In standard geometry, projecting to a plane with normal $n$ and point $v$ is $P - ((P-v)\cdot n)n$. The source notation $((P_i - v_i) \cdot f_j) \cdot f_j$ suggests $f_j$ acts as the normal vector in this context.*

6.  **Total Loss:** Combine all terms [S1]:
    $$L = L_{img} + \lambda _{nc} L_{nc} + L_{scale} +\lambda _{proj} L_{proj}$$

7.  **Densification Strategy:**
    *   **Loosely-Bound Splats ($G^l$):** Follow the original 3DGS densification strategy (cloning and splitting based on gradient magnitude) [S1].
    *   **Tightly-Bound Splats ($G^t$):** When cloning or splitting, initialize new Gaussian splats by sampling points from the corresponding mesh triangle [S1].
        *   **Cloning:** Copy additional attributes from the parent Gaussian to the new Gaussian [S1].
        *   **Splitting:** Divide the scale of the new Gaussians by a factor of $1.6$ [S1].

**Pseudocode:**

```python
def compute_loss(rendered_image, gt_image, tightly_bound_splats, mesh):
    # 1. Image Loss
    l1_loss = L1(rendered_image, gt_image)
    ssim_loss = SSIM(rendered_image, gt_image)
    l_img = (1 - 0.001) * l1_loss + 0.001 * ssim_loss
    
    l_nc = 0.0
    l_scale = 0.0
    l_proj = 0.0
    
    for splat in tightly_bound_splats:
        # 2. Normal Estimation
        # Identify min scale axis index
        min_scale_idx = argmin(splat.scale)
        # Get local axis (e.g., [1,0,0] for x, [0,1,0] for y, [0,0,1] for z)
        local_axis = identity_matrix[:, min_scale_idx]
        # Transform to world coordinates
        normal = splat.rotation @ local_axis
        normal = normalize(normal)
        
        # 3. Normal Consistency Loss
        # Find associated mesh faces (implementation detail: [G])
        associated_faces = get_associated_faces(splat, mesh)
        for face in associated_faces:
            l_nc += (1.0 - dot(normal, face.normal))
            
        # 4. Scale Regularization
        min_s = min(splat.scale)
        max_s = max(splat.scale)
        l_scale += 0.1 * abs(min_s) + 10.0 * abs(max_s - 0.1)
        
        # 5. Projection Loss
        # Find closest point on mesh surface
        closest_point, closest_face = get_closest_point_on_mesh(splat.position, mesh)
        # Formula from source: s_i = P_i + ((P_i - v_i) . f_j) . f_j
        # Assuming f_j is the normal of the closest face and v_i is a vertex of that face
        # Note: Source notation is ambiguous; standard projection uses normal.
        # We assume closest_face.normal is used as f_j and a vertex from closest_face as v_i
        v_i = closest_face.vertices[0]
        f_j = closest_face.normal
        projection_vector = dot(splat.position - v_i, f_j) * f_j
        s_i = splat.position + projection_vector
        l_proj += norm(s_i - splat.position)
        
    total_loss = l_img + 0.1 * l_nc + l_scale + 50.0 * l_proj
    return total_loss

def densify_tightly_bound_splats(splats, mesh, threshold=1.6):
    for splat in splats:
        if should_clone(splat):
            # Sample point from associated mesh triangle
            new_pos = sample_point_from_triangle(splat.associated_triangle)
            new_splat = clone_splat(splat)
            new_splat.position = new_pos
            # Copy additional attributes [G]
            add_splat(new_splat)
        elif should_split(splat):
            # Sample point from associated mesh triangle
            new_pos = sample_point_from_triangle(splat.associated_triangle)
            new_splat = clone_splat(splat)
            new_splat.position = new_pos
            # Divide scale by 1.6
            new_splat.scale = splat.scale / threshold
            add_splat(new_splat)
```

## Operating characteristics
*   **Time Complexity:** The projection loss requires finding the closest point on the mesh for every tightly-bound splat at every iteration, which can be computationally expensive if not optimized with spatial acceleration structures (e.g., BVH) [G].
*   **Memory Complexity:** Requires storing the mesh geometry and maintaining the separation between tightly and loosely bound splats.
*   **Strengths:** Prevents Gaussian splats from drifting away from the surface and controls their scale, leading to higher quality rendering on explicit mesh representations [S1].
*   **Limitations:** Relies on the quality of the input mesh. If the mesh is noisy or incomplete, the projection and normal consistency losses may introduce artifacts.
*   **When to use:** When rendering scenes with high-quality explicit mesh geometry is required, and standard 3DGS drifts or expands excessively.
*   **When not to use:** For scenes without an explicit mesh or where the mesh quality is poor.

## Background
This method originates from **MeshGS** (Adaptive Mesh-Aligned Gaussian Splatting for High-Quality Rendering) [S1]. It builds on the original 3DGS [22] densification strategy but adapts it for mesh-aligned rendering. The method was developed to address the limitations of standard 3DGS in maintaining geometric fidelity when bound to a mesh surface.
