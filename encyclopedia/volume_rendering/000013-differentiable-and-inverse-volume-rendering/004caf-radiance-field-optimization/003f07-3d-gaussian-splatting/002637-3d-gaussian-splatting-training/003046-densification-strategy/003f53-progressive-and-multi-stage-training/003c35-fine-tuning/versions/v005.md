# Fine-tuning
Also called: 3DGS Fine-tuning, Gaussian Splatting Fine-tuning

## Overview
Fine-tuning is a training phase in 3D Gaussian Splatting that optimizes geometry and color attributes of an initial set of primitives to achieve photorealistic reconstruction [S1]. It distinguishes itself by enabling the growing and pruning of 3D primitives during optimization, which significantly reduces the number of Gaussians compared to the initial feed-forward initialization while maintaining high fidelity [S1]. This process leverages pretrained priors to accelerate convergence and reduce memory consumption [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D Gaussian primitives initialized via a direct feed-forward process, where both geometry (mean, covariance, scale) and color attributes (SH coefficients) are pre-generated [S1].
*   **Output:** Optimized 3D Gaussian primitives with refined geometry and color, pruned of redundant primitives [S1].

**Data Structures:**
*   **Gaussian Set:** A collection of 3D Gaussians. Each Gaussian $\mathcal{G}_i$ contains:
    *   Mean position $\mu_i \in \mathbb{R}^3$
    *   Covariance matrix $\Sigma_i$ (or scale $s_i$ and rotation $q_i$)
    *   Opacity $\alpha_i$
    *   Spherical Harmonic coefficients for color $c_i$
*   **Optimizer State:** Adam optimizer state for all learnable parameters (geometry and color) [S1].

**Steps:**
1.  **Initialization:** Predict a set of 3D Gaussian primitives for initialization via a direct feed-forward process. Both geometry and color attributes are generated [S1].
2.  **Optimization Loop:** Optimize all geometry and color attributes directly following the vanilla 3DGS training procedure [S1].
    *   Use the Adam optimizer [S1].
    *   Compute the loss function, which typically includes SSIM and L1 loss, potentially with entropy regularization [S1].
    *   Render the scene using differentiable rasterization [S1].
    *   Backpropagate gradients to update parameters [S1].
3.  **Densification (Growing and Pruning):** Enable growing and pruning of 3D primitives during fine-tuning [S1].
    *   **Pruning:** Remove redundant Gaussians. The initial feed-forward Gaussians are often redundant, so pruning significantly reduces the Gaussian count [S1].
    *   **Growing:** Add new Gaussians in regions with high reconstruction error or insufficient detail, following standard 3DGS densification strategies (splitting/cloning based on gradient norms and screen size) [S1, Parent].
4.  **Convergence:** Continue until the model achieves photorealism, leveraging pretrained priors for faster convergence [S1].

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $1 \times 10^{-3}$ [S1].
*   **Loss Weights:** Not explicitly given in the provided text, but standard 3DGS uses $\lambda_{ssim}$ and $\lambda_{L1}$ [S1].
*   **Library:** `gsplat` for Gaussian rasterization [S1].

**Edge Cases and Pitfalls:**
*   **Redundancy:** The initial feed-forward initialization may produce redundant Gaussians, necessitating pruning to avoid excessive memory usage and slow training [S1].
*   **Convergence:** Without pretrained priors, convergence may be slower [S1].

**Pseudocode:**
```python
# Initialize Gaussians from feed-forward model
gaussians = feed_forward_predict(scene_data)

# Setup Adam optimizer for all parameters
optimizer = Adam(gaussians.parameters(), lr=1e-3)

# Fine-tuning loop
for step in range(num_steps):
    # Render current Gaussians
    rendered_image = rasterize(gaussians, camera)
    
    # Compute loss (SSIM + L1 + Entropy)
    loss = compute_loss(rendered_image, target_image)
    
    # Backpropagate
    loss.backward()
    optimizer.step()
    optimizer.zero_grad()
    
    # Periodic densification (growing and pruning)
    if step % refine_every == 0:
        gaussians = densify_and_prune(gaussians, step)
```

## Subtopics

### [Exponentially Ascending Gradient Threshold](9684-exponentially-ascending-gradient-threshold.md)
A densification control mechanism that uses an exponentially ascending gradient threshold to regulate splitting and cloning, balancing early-stage convergence speed and late-stage overfitting.

### [Hard Gaussian Splatting](10590-hard-gaussian-splatting.md)
Identifies "hard Gaussians" causing artifacts and grows them using multi-view significant positional gradients and rendering error analysis.

### [SplatFormer Training Objective & Refinement](11745-splatformer-training-objective-refinement.md)
A learning-based module that refines 3DGS representations to handle out-of-distribution camera angles using a point transformer network.

### [MCMC-based 3DGS / SGLD for 3DGS](11917-mcmc-based-3dgs-sgld-for-3dgs.md)
Reformulates 3DGS as MCMC samples from an underlying probability distribution.

## Operating characteristics
*   **Time Complexity:** Depends on the number of Gaussians and the cost of differentiable rasterization. Fine-tuning with pretrained priors accelerates convergence, reducing the total number of steps required [S1].
*   **Memory Complexity:** Reduced compared to naive initialization due to pruning of redundant primitives [S1].
*   **Strengths:** Achieves photorealism, reduces memory consumption, and accelerates training via pretrained priors [S1].
*   **Limitations:** Relies on the quality of the initial feed-forward initialization [S1].
*   **When to Use:** When high-fidelity reconstruction is needed and computational resources are limited, or when pretrained priors are available [S1].

## Background
Fine-tuning in the context of 3D Gaussian Splatting was introduced in EVolSplat, which applies fine-tuning to efficient volume-based Gaussian Splatting for urban view synthesis [S1]. It builds on the vanilla 3DGS optimization framework but incorporates densification and pruning to refine the initial feed-forward predictions [S1].
