# Curriculum Learning with Slice and Voxel Supervision

Also called: Slice and Voxel Supervision Curriculum

## Overview
This method structures the training of 3D Gaussian representations for volumetric data by alternating between two distinct supervision signals: sparse voxel sampling and structured slice-based sampling [S1]. It solves the problem of unstable global approximation and lack of structural continuity that arises when using either supervision type in isolation [S1]. Unlike siblings that rely on uniform random sampling or dense voxel grids, this approach aligns the learning process with the shear-warp rendering pipeline, ensuring the Gaussian kernels learn both global volumetric consistency and local anatomical details [S1].

## How it works
**Inputs:** A set of 3D volumetric data (e.g., MRI, Cryosection) and a target number of Gaussian kernels $m$.
**Outputs:** A set of Gaussian kernels $G = \{G_1, G_2, \dots, G_m\}$, where each $G_i$ has a mean $\mu_i$, covariance $\Sigma_i$, opacity $\alpha_i$, and spherical harmonics coefficients for color [S1].

**Data Structures:**
*   **Gaussian Set $G$:** A list of $m$ Gaussian primitives. Each primitive stores learnable parameters: mean $\mu \in \mathbb{R}^3$, covariance $\Sigma \in \mathbb{R}^{3 \times 3}$ (or its Cholesky factor/rotation/scale representation), opacity $\alpha \in [0, 1]$, and color coefficients [S1].
*   **Voxel Grid:** The source volumetric data, discretized into a 3D grid.
*   **Sampling State:** Tracks the current phase of the curriculum (Voxel Phase or Slice Phase).

**Numbered Steps:**
1.  **Initialization:** Initialize $m$ Gaussian kernels. One kernel is centered at each of $m$ sampled voxel positions from the input volume [S1].
2.  **Curriculum Phase 1 (Voxel Supervision):**
    *   Sample $m$ voxels randomly from the volume grid [S1].
    *   Render the current Gaussian representation to generate a synthetic volume or projection.
    *   Compute the reconstruction loss between the rendered output and the ground-truth voxel values at the sampled positions [S1].
    *   Optimize Gaussian parameters ($\mu, \Sigma, \alpha$, etc.) to minimize this loss [S1].
    *   *Note:* The sources describe "random sampling with dense approximation" for voxel supervision in the context of the final combined strategy, but the curriculum starts with establishing global spatial guidance [S1].
3.  **Curriculum Phase 2 (Slice Supervision):**
    *   In each training iteration, sample a plane with an arbitrary orientation [S1].
    *   Select sparse pixels on this sampled plane [S1].
    *   Map each selected pixel to a 3D voxel coordinate in the volume grid [S1].
    *   Render the Gaussian representation along the viewing direction corresponding to the slice plane [S1].
    *   Compute the loss between the rendered slice and the ground-truth slice data extracted from the volume [S1].
    *   Optimize Gaussian parameters to minimize this loss [S1].
4.  **Iteration:** Repeat steps 2 and 3, potentially interleaving them or transitioning from one to the other, until convergence [S1]. The curriculum ensures that slice supervision (which captures spatially correlated regions and texture continuity) is applied after or alongside voxel supervision (which provides global coverage) to prevent instability [S1].

**Formulas:**
*   **Gaussian Kernel:** $G_i(\mathbf{x}) = \alpha_i \exp\left(-\frac{1}{2}(\mathbf{x} - \mu_i)^T \Sigma_i^{-1} (\mathbf{x} - \mu_i)\right)$ [S1].
*   **Shear-Warp Rendering:** The rendering process projects the 3D volume into a stack of 2D slices. The loss is computed on these 2D slices [S1].
*   **Loss Function:** $\mathcal{L} = \mathcal{L}_{voxel} + \mathcal{L}_{slice}$, where $\mathcal{L}_{voxel}$ is the error at sampled voxel coordinates and $\mathcal{L}_{slice}$ is the error on sampled 2D planes [S1].

**Parameters:**
*   $m$: Number of Gaussian kernels. Not given in the sources.
*   Sampling rate for voxels and slices: Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Instability with Random Voxels:** Using only random voxel sampling without structured slice supervision can lead to unstable global approximation [S1].
*   **Lack of Global Guidance with Only Slices:** Using only slice supervision (A4) limits accurate reconstruction of the full volumetric structure because slices cover limited regions at each iteration, lacking global spatial guidance [S1].
*   **Ordering Sensitivity:** Applying slice supervision before stable global voxel constraints are established (A3) results in unstable learning of the volumetric structure, as the Gaussians are optimized using limited planar information initially [S1].

## Subtopics

### Curriculum Learning with Sparse Voxel and Slice Sampling
This variant explicitly defines the sampling strategy. Sparse voxels provide global coverage of the volume, while slice samples capture spatially correlated regions that encode geometric structure and texture continuity [S1]. The strategy aligns with shear-warp volume rendering, which generates images from stacks of 2D slices extracted from a 3D volume [S1]. In each iteration, a plane with arbitrary orientation is sampled, sparse pixels are selected on the plane, and each pixel is mapped to a 3D voxel coordinate [S1]. This allows the Gaussian representation to learn spatial continuity across neighboring regions [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** Combining both sparse voxel and slice supervision yields higher PSNR and SSIM compared to using only slice supervision (A4) or random voxel sampling alone [S1].
*   **Strengths:** Efficiently learns both global volumetric consistency and local anatomical details [S1]. Aligns naturally with the shear-warp rendering process [S1].
*   **Limitations:** Requires careful balancing of the curriculum phases to avoid instability. Random voxel sampling alone can destabilize learning [S1].
*   **When to Use:** Suitable for multimodal volumetric datasets like MRI and Cryosection volumes where both global structure and local texture continuity are important [S1].

## Background
This method was proposed in the context of Gaussian Volumetric Representation for Efficient Shear-Warp Visualization [S1]. It builds on the principles of curriculum learning [37] and 3D Gaussian Splatting [10]. The approach is designed to handle dense volumetric data efficiently by leveraging the structure of shear-warp rendering [S1].
