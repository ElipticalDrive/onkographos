# Fine-tuning
Also called: 3DGS Fine-tuning, Gaussian Splatting Fine-tuning

## Overview
Fine-tuning in 3D Gaussian Splatting (3DGS) refers to the phase where a pre-initialized set of 3D Gaussian primitives—often generated via a feed-forward network or sparse reconstruction—is optimized to match target images, enabling the growth and pruning of primitives to achieve high-fidelity rendering [S1]. It distinguishes itself from standard training by leveraging pretrained priors or initial geometric estimates to accelerate convergence and reduce memory consumption, while actively managing the Gaussian population density during the optimization process [S1].

## How it works
**Inputs and Outputs:**
- **Input:** A set of initialized 3D Gaussian primitives (geometry and color attributes) and a set of training images with known camera poses.
- **Output:** Optimized 3D Gaussian primitives (means, covariances, opacities, spherical harmonics coefficients) that minimize rendering error.

**Data Structures:**
The core data structure is the set of 3D Gaussians $\mathcal{G} = \{g_i\}_{i=1}^N$. Each Gaussian $g_i$ is defined by:
- Mean position $\mu_i \in \mathbb{R}^3$
- Covariance matrix $\Sigma_i \in \mathbb{R}^{3 \times 3}$ (often parameterized by rotation $R_i \in SO(3)$ and scale $s_i \in \mathbb{R}^3$)
- Opacity $\alpha_i \in [0, 1]$
- Spherical Harmonics (SH) coefficients $c_{i,lm}$ for view-dependent color.

**Numbered Steps:**
1. **Initialization:** Predict a set of 3D Gaussian primitives via a direct feed-forward process. Both geometry (position, scale, rotation) and color attributes (SH coefficients) are generated simultaneously [S1]. This step provides a dense but potentially redundant initial representation.
2. **Optimization Setup:** Initialize the optimizer (e.g., Adam) with a learning rate (typically $1 \times 10^{-3}$) [S1]. The loss function combines photometric error, SSIM, and entropy regularization, following the standard 3DGS formulation [S1]:
   $$ \mathcal{L} = (1 - \lambda_{ssim}) \mathcal{L}_1 + \lambda_{ssim} \mathcal{L}_{ssim} + \lambda_e \mathcal{L}_{entropy} $$
   where $\mathcal{L}_1$ is the L1 loss, $\mathcal{L}_{ssim}$ is the SSIM loss, and $\mathcal{L}_{entropy}$ encourages opacity to be binary [S1].
3. **Differentiable Rasterization:** Render the current set of Gaussians to image space using differentiable Gaussian splatting. This involves projecting 3D Gaussians to 2D ellipses, sorting them by depth, and compositing colors based on opacity [S1].
4. **Gradient Update:** Compute gradients of the loss with respect to all Gaussian parameters (means, covariances, opacities, SH coefficients) and update them using the optimizer [S1].
5. **Growing and Pruning:** During fine-tuning, actively manage the number of Gaussians:
   - **Growing:** Split or clone Gaussians in regions with high reconstruction error or low opacity to increase density where needed [S1].
   - **Pruning:** Remove Gaussians with low opacity or low contribution to the scene to reduce redundancy and memory usage [S1].
6. **Iteration:** Repeat steps 3–5 until convergence or a fixed number of iterations. The number of Gaussians typically decreases significantly during this phase as redundant primitives are pruned [S1].

**Parameters:**
- Learning rate: $1 \times 10^{-3}$ (Adam optimizer) [S1].
- Loss weights: $\lambda_{ssim}$ and $\lambda_e$ as per standard 3DGS [S1].
- SH degree: Typically 3 or 4, depending on the complexity of view-dependent effects [S1].

**Edge Cases and Pitfalls:**
- **Redundancy:** The initial feed-forward initialization may produce redundant Gaussians, leading to high memory usage if pruning is not aggressive enough [S1].
- **Convergence Speed:** While fine-tuning accelerates convergence compared to random initialization, poor initial geometry can lead to local minima if not properly regularized [S1].
- **Precision:** Floating-point precision issues may arise during the projection and compositing steps, especially for small Gaussians [G].

**Pseudocode:**
```python
def fine_tune_3dgs(initial_gaussians, training_images, camera_poses, num_iterations):
    """
    Fine-tune 3D Gaussian Splatting from an initial set of primitives.
    
    Args:
        initial_gaussians: List of Gaussian objects with initial means, covariances, opacities, SH coefficients.
        training_images: List of target images.
        camera_poses: List of camera pose matrices corresponding to training images.
        num_iterations: Number of optimization steps.
        
    Returns:
        Optimized list of Gaussian objects.
    """
    gaussians = initial_gaussians
    optimizer = Adam(gaussians.parameters(), lr=1e-3)
    
    for i in range(num_iterations):
        # Sample a random training image and its pose
        idx = random.randint(0, len(training_images) - 1)
        target_image = training_images[idx]
        camera_pose = camera_poses[idx]
        
        # Render the scene using current Gaussians
        rendered_image = render_gaussians(gaussians, camera_pose)
        
        # Compute loss
        loss = compute_loss(rendered_image, target_image, gaussians)
        
        # Backpropagate and update
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        # Growing and Pruning
        gaussians = manage_gaussian_population(gaussians, target_image, camera_pose)
        
    return gaussians

def manage_gaussian_population(gaussians, target_image, camera_pose):
    """
    Grow and prune Gaussians based on reconstruction error and opacity.
    """
    # Prune low-opacity Gaussians
    gaussians = [g for g in gaussians if g.opacity > threshold]
    
    # Grow Gaussians in high-error regions
    error_map = compute_rendering_error(render_gaussians(gaussians, camera_pose), target_image)
    high_error_regions = find_regions_with_high_error(error_map)
    
    for region in high_error_regions:
        gaussians = split_gaussians_in_region(gaussians, region)
        
    return gaussians
```

## Subtopics

### [Exponentially Ascending Gradient Threshold](9684-exponentially-ascending-gradient-threshold.md)
A densification control mechanism for 3D Gaussian Splatting that uses an exponentially ascending gradient threshold to regulate the splitting and cloning of Gaussians during training. It solves the trade-off between early-stage convergence speed and late-stage overfitting by allowing aggressive densification when few Gaussians exist and restricting it as the scene becomes dense. It sets itself apart from static threshold methods by dynamically adjusting the sensitivity of densification decisions based on the normalized training progress.

### [Hard Gaussian Splatting](10590-hard-gaussian-splatting.md)
Hard Gaussian Splatting (HGS) is a densification strategy for 3D Gaussian Splatting that identifies "hard Gaussians"—defective primitives causing blurring or needle-like artifacts—and grows them to recover missing scene details. Unlike standard 3DGS, which relies on averaged view-space positional gradients that smooth out local errors and hinder the growth of defective Gaussians, HGS uses multi-view significant positional gradients (PGHGS) and rendering error analysis (REHGS) to detect regions with high reconstruction error. It builds on [Fine-tuning](9138-fine-tuning.md) by refining the Gaussian distribution during the training phase to resolve artifacts that standard adaptive density control misses.

### [SplatFormer Training Objective & Refinement](11745-splatformer-training-objective-refinement.md)
SplatFormer is a learning-based, feed-forward 3D neural module that refines initial 3D Gaussian Splatting (3DGS) representations to enable robust novel view synthesis from out-of-distribution (OOD) camera angles. It addresses the bias of standard 3DGS optimization, which overfits to input views and fails to generalize to unseen high-elevation perspectives, by applying a point transformer network that predicts attribute residuals. Unlike 2D image restoration methods that suffer from multi-view inconsistencies, SplatFormer operates directly on 3D primitives, ensuring geometric consistency while recovering details lost in OOD views.

### [MCMC-based 3DGS / SGLD for 3DGS](11917-mcmc-based-3dgs-sgld-for-3dgs.md)
This method reformulates 3D Gaussian Splatting (3DGS) by treating the set of 3D Gaussians as random samples drawn from an underlying probability distribution describing the scene, specifically as Markov Chain Monte Carlo (MCMC) samples. It converts conventional 3DGS updates into Stochastic Gradient Langevin Dynamics (SGLD) updates by introducing a noise term to promote sample exploration, thereby removing the need for manual densification heuristics like cloning, splitting, and opacity resetting. Unlike sibling methods that rely on complex gradient thresholds or hard constraints, this approach relies on probabilistic state transitions and regularization to manage Gaussian population.

### [Deblurring 3D Gaussian Splatting](12318-deblurring-3d-gaussian-splatting.md)
Deblurring 3D Gaussian Splatting is a real-time deblurring framework that reconstructs sharp 3D scenes from blurry input images by manipulating the covariance matrices and means of 3D Gaussians using a small Multi-Layer Perceptron (MLP) during training. Unlike volumetric rendering-based methods like Deblur-NeRF which require seconds per image, this method uses differentiable rasterization to achieve real-time inference speeds (>800 FPS) while handling both defocus and camera motion blur. It addresses the sparse point clouds caused by blurry inputs through K-nearest-neighbor interpolation and depth-based pruning.

### [Supplementary Point Addition for Sparse Point Clouds](12323-supplementary-point-addition-for-sparse-point-clouds.md)
A densification technique designed to compensate for the sparsity of 3D Gaussians at the far end of scenes in defocus-blurry environments, where Structure-from-Motion (SfM) extraction is typically poor. It supplements the initial point cloud with synthetic points to ensure adequate coverage in regions where SfM fails to extract features, thereby improving reconstruction fidelity in large-depth-of-field scenarios.

### [Gaussian Volume Mask](12710-gaussian-volume-mask.md)
Gaussian Volume Mask is a densification strategy for 3D Gaussian Splatting that reduces the number of active Gaussians by applying binary masks to scale and opacity attributes based on a learnable parameter. It addresses the excessive memory and storage requirements caused by the proliferation of Gaussians during training, which often include redundant primitives with negligible volume or transparency. Unlike original 3DGS, which relies solely on opacity-based control and stops densifying in the middle of training, this method consistently masks out unessential Gaussians throughout the entire process by considering both geometric volume and transparency.

### [Error-Guided Gaussian Reallocation](13012-error-guided-gaussian-reallocation.md)
Error-Guided Gaussian Reallocation (EGR) is a training-stage module that redistributes a fixed budget of Gaussian primitives toward regions with persistent coarse-scale reconstruction errors, without increasing the total number of Gaussians. It refines post-densification Gaussian allocation by moving low-contribution (LC) Gaussians to high-error (HE) regions within a fixed Gaussian set, using contribution- and error-aware selection. Unlike methods using explicit rollback or separate re-correction modules, EGR uses adaptive relocation count, parameter reset, and continued optimization as its stabilization strategy.

### [Augmented Radiance Field](13218-augmented-radiance-field.md)
Augmented Radiance Field is a post-enhancement framework that improves 3D Gaussian Splatting (3DGS) scenes by adding Gaussian kernels with view-dependent opacity to explicitly model specular components. It solves the problem that standard spherical harmonics (SH) cannot decouple diffuse and specular radiance, leading to poor reconstruction of sharp highlights and material artifacts. Unlike standard 3DGS which assigns SH coefficients to every primitive, this method uses distinct primitives for diffuse and specular components, avoiding the memory and stability issues of high-order SH.

### ACO-EGR Framework
ACO-EGR is a unified framework that integrates ACO and EGR into a multi-scale 3DGS backbone to jointly address scale-dependent color mismatch and primitive-allocation imbalance [S2]. The framework augments a multi-scale 3DGS backbone with two training-stage modules: ACO and EGR [S2]. Unlike existing methods that keep fixed color and spatial allocation after densification, ACO-EGR adapts both Gaussian color and primitive allocation together [S2]. ACO-EGR improves rendering quality without modifying the inference-stage rendering process itself; it only changes the training/optimization of the Gaussian parameters [S2].

## Operating characteristics
- **Time Complexity:** Fine-tuning typically converges faster than training from random initialization due to the quality of the initial guess, but the exact speedup depends on the accuracy of the feed-forward initialization [S1].
- **Memory Complexity:** The initial feed-forward process may generate a large number of redundant Gaussians, increasing memory usage. However, the pruning step during fine-tuning significantly reduces the final number of Gaussians, leading to lower memory consumption compared to standard 3DGS [S1].
- **Performance:** Fine-tuning achieves photorealism on par with or surpassing other methods, leveraging powerful pretrained weights [S1].
- **Strengths:** Accelerated convergence, reduced memory consumption, high fidelity.
- **Limitations:** Dependence on the quality of the initial feed-forward initialization; potential for local minima if initialization is poor.
- **When to use:** When a good initial geometric estimate is available (e.g., from SfM or a feed-forward network) and computational resources are limited.
- **When not to use:** When the initial estimate is very poor, as it may lead to suboptimal convergence.

## Background
Fine-tuning in 3D Gaussian Splatting was introduced in the context of efficient volume-based Gaussian Splatting for urban view synthesis [S1]. It leverages pretrained priors to accelerate network training and enable faster convergence compared to other test-time optimization methods [S1]. The method builds on the standard 3DGS framework but adds a phase of active population management (growing and pruning) during the optimization process [S1].
