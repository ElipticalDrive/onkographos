# Training Objective and Densification

Also called: MeshGS Training, Tightly/Loosely-bound Training

## Overview
This method defines the loss function and densification protocol for **MeshGS** [S1], a variant of 3D Gaussian Splatting that aligns primitives with an explicit mesh surface. It solves the problem of Gaussian splats drifting away from geometry or expanding excessively by introducing projection, normal consistency, and scale regularization losses [S1]. It sets itself apart from standard 3DGS [22] and SuGaR [13] by explicitly distinguishing between "tightly-bound" splats (constrained to the mesh) and "loosely-bound" splats (free-floating), applying different densification strategies to each [S1].

## How it works

### Inputs and Outputs
*   **Inputs:**
    *   Set of Gaussian primitives $\mathcal{G} = \mathcal{G}^t \cup \mathcal{G}^l$, where $\mathcal{G}^t$ are tightly-bound splats and $\mathcal{G}^l$ are loosely-bound splats [S1].
    *   A mesh $M$ defined by faces $F$ and vertices $V$ [S1].
    *   Rendered image $\hat{I}_i$ and ground truth image $I_i$ [S1].
*   **Outputs:**
    *   Updated primitive set $\mathcal{G}$ after densification steps [S1].
    *   Gradients for optimization based on the total loss $L$ [S1].

### Data Structures
*   **Gaussian Primitive $i$:**
    *   $\mu_i$: Mean position [Parent].
    *   $S_i = (s_1, s_2, s_3) \in \mathbb{R}^3$: Scale parameters [S1].
    *   $R_i$: Rotation matrix [S1].
    *   $\alpha_i$: Opacity [Parent].
    *   $c_i$: Color/SH coefficients [Parent].
    *   Type flag: $t$ (tightly-bound) or $l$ (loosely-bound) [S1].
*   **Mesh Face $f_j$:**
    *   Vertices $v_i$ [S1].
    *   Face normal $n_f$ [S1].

### Parameters
*   $\lambda_{img} = 0.001$: Weight for SSIM in image loss [S1].
*   $\lambda_{nc} = 0.1$: Weight for normal consistency loss [S1].
*   $\lambda_{min} = 0.1$: Weight for minimum scale regularization [S1].
*   $\lambda_{max} = 10$: Weight for maximum scale regularization [S1].
*   $\lambda_{proj} = 50$: Weight for projection loss [S1].
*   $\rho = 0.1$: Threshold for maximum scale regularization [S1].
*   $d_{th} = 0.01$: Distance threshold to classify splats as tightly-bound [S1].
*   Training iterations: 30,000 [S1].
*   Densification frequency: Every 500 iterations [S1].

### Formulas
1.  **Image Loss** [S1]:
    $$L_{img} = (1-\lambda_{img})L_{1}(\hat{I}_{i},I_{i}) + \lambda_{img}SSIM(\hat{I}_{i}, I_{i})$$
2.  **Normal Consistency Loss** [S1]:
    $$L_{nc} = \sum_{i \in \mathcal{G}^t, f \in F} (1 - n_{i} \cdot n_{f})$$
    Where $n_i$ is the splat normal and $n_f$ is the face normal.
3.  **Scale Regularization Loss** [S1]:
    $$L_{scale} = \sum_{i \in \mathcal{G}^t}(\lambda_{min}|\min(s_{1}, s_{2}, s_{3})| + \lambda_{max}|\max(s_{1}, s_{2}, s_{3}) - \rho |)$$
4.  **Projection Loss** [S1]:
    $$s_{i} = P_{i} + ((P_{i} - v_{i}) \cdot f_{j}) \cdot f_{j}$$
    $$L_{proj} = \sum_{i \in \mathcal{G}^t}\| s_{i} - P_{i} \|_{2}$$
    Where $P_i$ is the Gaussian center and $s_i$ is the projection onto the mesh surface.
5.  **Total Loss** [S1]:
    $$L = L_{img} + \lambda_{nc} L_{nc} + L_{scale} + \lambda_{proj} L_{proj}$$

### Steps
1.  **Classification:** For each Gaussian $i$, calculate its distance to the nearest mesh surface. If distance $\le d_{th}$, classify as tightly-bound ($\mathcal{G}^t$); otherwise, loosely-bound ($\mathcal{G}^l$) [S1].
2.  **Loss Computation:**
    *   Compute $L_{img}$ using rendered and ground truth images [S1].
    *   For each $i \in \mathcal{G}^t$:
        *   Estimate normal $n_i$ by identifying the minimum scale axis in $S_i$ and applying rotation $R_i$ to transform it to world coordinates [S1].
        *   Find the closest mesh face $f_j$ and vertex $v_i$ [S1].
        *   Compute $L_{nc}$ using cosine similarity between $n_i$ and face normal $n_f$ [S1].
        *   Compute $L_{scale}$ using min/max of $S_i$ against $\rho$ [S1].
        *   Compute $L_{proj}$ by projecting $P_i$ to $s_i$ on the mesh [S1].
    *   Sum losses to get $L$ [S1].
3.  **Optimization:** Update Gaussian parameters using gradients from $L$ [S1].
4.  **Densification (Every 500 iterations):**
    *   **For $\mathcal{G}^l$:** Apply the original 3DGS densification strategy (gradient-based splitting/cloning) [S1].
    *   **For $\mathcal{G}^t$:**
        *   Identify the closest mesh triangle for each splat [S1].
        *   Perform random point sampling from the triangle surface [S1].
        *   **Cloning:** Copy the position of the sampled point to initialize a new Gaussian; copy other attributes (color, opacity, rotation) from the parent [S1].
        *   **Splitting:** Copy the position of the sampled point; initialize new scale by dividing the parent's scale by 1.6 [S1].

### Pseudocode

```python
def compute_loss(G_tight, G_loose, mesh, rendered_img, gt_img):
    # Image Loss
    l1_loss = L1(rendered_img, gt_img)
    ssim_loss = SSIM(rendered_img, gt_img)
    L_img = (1 - 0.001) * l1_loss + 0.001 * ssim_loss
    
    L_nc = 0.0
    L_scale = 0.0
    L_proj = 0.0
    
    for i in G_tight:
        # Estimate normal: min scale axis rotated to world
        min_axis_idx = argmin(i.scale)
        n_i = rotate_vector(i.rotation, get_basis_vector(min_axis_idx))
        
        # Find closest face f_j and vertex v_i
        f_j, v_i = mesh.get_closest_face_and_vertex(i.position)
        n_f = f_j.normal
        
        # Normal Consistency
        L_nc += (1.0 - dot(n_i, n_f))
        
        # Scale Regularization
        s_min = min(i.scale)
        s_max = max(i.scale)
        L_scale += (0.1 * abs(s_min) + 10.0 * abs(s_max - 0.1))
        
        # Projection Loss
        # Project P_i to surface defined by f_j
        # Note: Source formula uses f_j as a vector in projection, 
        # implying f_j might be the surface normal or a specific vector. 
        # Standard projection to plane uses normal. Source says: 
        # s_i = P_i + ((P_i - v_i) . f_j) * f_j. 
        # This implies f_j is the surface normal vector for the projection plane.
        p = i.position
        v = v_i
        n = f_j.normal # Assuming f_j provides normal for projection
        s_i = p + dot(p - v, n) * n
        L_proj += norm(s_i - p)
        
    L_total = L_img + 0.1 * L_nc + L_scale + 50.0 * L_proj
    return L_total

def densify(G_tight, G_loose, mesh, iteration):
    if iteration % 500 != 0:
        return
        
    # Loosely-bound: Standard 3DGS strategy
    G_loose = densify_3dgs(G_loose)
    
    # Tightly-bound: Mesh-aligned strategy
    new_tight = []
    for i in G_tight:
        # Find closest triangle
        triangle = mesh.get_closest_triangle(i.position)
        
        # Sample point from triangle
        sample_pos = random_sample_triangle(triangle)
        
        # Clone
        clone = Gaussian()
        clone.position = sample_pos
        clone.color = i.color
        clone.opacity = i.opacity
        clone.rotation = i.rotation
        clone.scale = i.scale # Copy scale for clone
        new_tight.append(clone)
        
        # Split
        split = Gaussian()
        split.position = sample_pos
        split.color = i.color
        split.opacity = i.opacity
        split.rotation = i.rotation
        split.scale = i.scale / 1.6 # Divide scale by 1.6
        new_tight.append(split)
        
    G_tight.extend(new_tight)
```

### Edge Cases and Pitfalls
*   **Projection Vector Ambiguity:** The source formula for $L_{proj}$ uses $f_j$ in the dot product and multiplication: $s_i = P_i + ((P_i - v_i) \cdot f_j) \cdot f_j$. In standard geometry, projecting a point to a plane requires the plane's *normal*. If $f_j$ refers to the face normal, the formula is a standard orthogonal projection. If $f_j$ refers to a face edge or vector, the formula is non-standard. Given the context of "closest point on mesh surface," $f_j$ is interpreted as the face normal [S1].
*   **Scale Division:** Splitting divides scale by 1.6. This is a fixed factor, not a learned parameter [S1].
*   **Normal Estimation:** Normals for tightly-bound splats are derived from the minimum scale axis, not from the gradient of the color or position. This assumes the smallest axis is perpendicular to the surface [S1].

## Operating characteristics
*   **Time Complexity:** Densification occurs every 500 iterations. The projection and normal consistency losses require finding the closest mesh face for each tightly-bound splat, which is $O(N \log M)$ with spatial indexing or $O(NM)$ without, where $N$ is splat count and $M$ is face count [S1].
*   **Memory Complexity:** Requires storing the mesh geometry and the additional loss terms for tightly-bound splats [S1].
*   **Strengths:** Prevents splats from drifting off the mesh surface; enforces geometric alignment [S1].
*   **Limitations:** Relies on the quality of the input mesh; tightly-bound splats are constrained to the mesh topology [S1].
*   **When to use:** When an explicit mesh is available and high-fidelity geometric alignment is required [S1].

## Background
This method originates from **MeshGS** (Adaptive Mesh-Aligned Gaussian Splatting for High-Quality Rendering) [S1]. It builds on the original 3D Gaussian Splatting [22] and SuGaR [13] by introducing a dual-strategy for densification based on the distance to a mesh surface. The method was proposed to improve rendering quality by ensuring Gaussian primitives remain aligned with the underlying geometry [S1].
