# MCMC Densification

Also called: Stochastic Gradient Langevin Dynamic (SGLD) Densification

## Overview
MCMC Densification is a Bayesian strategy for adjusting the number and distribution of 3D Gaussians during training, reformulating the densification process as a Stochastic Gradient Langevin Dynamic (SGLD) update rule [S1, unofficial]. Unlike traditional adaptive density control methods that rely on deterministic thresholds for cloning and splitting based on gradient magnitude, MCMC densification treats the set of 3D Gaussians as Markov Chain Monte Carlo (MCMC) samples [S2, unofficial]. It replaces explicit splitting and pruning steps with a re-localization scheme that adds noise to Gaussian center locations, allowing the system to explore the parameter space and converge to an optimal density distribution [S1, unofficial]. This approach reduces reliance on the initial point cloud, allows for specifying the target number of Gaussians prior to optimization, and generally leads to improved rendering quality [S2, unofficial].

## How it works
**Inputs:**
- Set of 3D Gaussians $\mathcal{G}$, where each Gaussian $n$ is defined by mean $\mu_n$, covariance $\Sigma_n$, opacity $\alpha_n$, and spherical harmonics coefficients.
- Current camera view $I$ and corresponding image.
- Hyperparameters: learning rate $\lambda_{lr}$, noise scale $\lambda_{noise}$.

**Outputs:**
- Updated set of 3D Gaussians $\mathcal{G}'$ with modified parameters, particularly the center locations $\mu_n$.

**Data Structures:**
- The Gaussian parameters are stored in a structure accessible for gradient computation. The noise term $\epsilon$ is typically drawn from a standard normal distribution $\mathcal{N}(0, I)$ for each dimension of the mean vector $\mu_n$.

**Steps:**
1. **Rasterization and Loss Computation:** Render the current view using the rasterizer. Compute the total loss $\mathcal{L}_{\text{total}}$ (e.g., combining L1, SSIM, and potentially regularization terms) between the rendered image and the ground truth [S1, unofficial].
2. **Gradient Computation:** Compute the gradient of the loss with respect to the Gaussian parameters $\mathcal{G}$, specifically focusing on the gradients with respect to the mean locations $\nabla_{\mu_n} \mathcal{L}_{\text{total}}$ [S1, unofficial].
3. **SGLD Update:** Update the Gaussian parameters using the SGLD rule. The update for the mean $\mu_n$ is given by:
   $$ \mu_n \leftarrow \mu_n - \lambda_{lr} \cdot \nabla_{\mu_n} \mathcal{L}_{\text{total}} + \lambda_{noise} \cdot \epsilon_n $$
   where $\epsilon_n \sim \mathcal{N}(0, I)$ is a noise vector added to the center location [S1, unofficial].
4. **Re-localization:** The noise injection effectively acts as a re-localization step. Gaussians that are in regions of high loss gradient are pushed away from their current position, while the noise helps escape local minima and explore the space [S2, unofficial].
5. **Parameter Update:** Apply the updated parameters to the Gaussian set. Other parameters (covariance, opacity, SH coefficients) are updated via standard gradient descent or other optimization steps as defined in the base training loop [S1, unofficial].

**Pseudocode:**
```python
def mcmc_densification_step(gaussians, camera_view, lambda_lr, lambda_noise):
    """
    Performs one step of MCMC densification.
    
    Args:
        gaussians: List of Gaussian objects with attributes .mu, .cov, .opacity, .sh.
        camera_view: Camera parameters for rasterization.
        lambda_lr: Learning rate for gradient descent.
        lambda_noise: Scale of the noise added to means.
        
    Returns:
        Updated list of Gaussian objects.
    """
    # 1. Rasterize and compute loss
    rendered_image = rasterize(gaussians, camera_view)
    ground_truth = get_ground_truth(camera_view)
    loss = compute_loss(rendered_image, ground_truth)
    
    # 2. Compute gradients
    # Note: In practice, this is done via automatic differentiation.
    # We assume a function that returns gradients for all Gaussian parameters.
    grads = compute_gradients(loss, gaussians)
    
    # 3. Update Gaussians using SGLD
    for i, gaussian in enumerate(gaussians):
        # Gradient for the mean
        grad_mu = grads[i].mu
        
        # Draw noise from standard normal distribution
        # Dimension of mu is typically 3 (x, y, z)
        noise = np.random.normal(0, 1, size=grad_mu.shape)
        
        # SGLD Update for mean
        gaussian.mu = gaussian.mu - lambda_lr * grad_mu + lambda_noise * noise
        
        # Update other parameters using standard gradient descent
        # (Assuming grads[i] contains gradients for cov, opacity, sh as well)
        gaussian.cov = gaussian.cov - lambda_lr * grads[i].cov
        gaussian.opacity = gaussian.opacity - lambda_lr * grads[i].opacity
        gaussian.sh = gaussian.sh - lambda_lr * grads[i].sh
        
    return gaussians
```

**Parameters:**
- $\lambda_{lr}$: Learning rate for the gradient descent step. Typical values depend on the overall training schedule.
- $\lambda_{noise}$: Noise scale hyperparameter applied to the center locations $\mu$. This controls the exploration capability of the MCMC process.
- $\epsilon$: Noise term drawn from $\mathcal{N}(0, I)$.

**Edge Cases and Pitfalls:**
- **Precision:** The addition of noise can lead to numerical instability if the learning rate or noise scale is too large. Careful tuning is required to ensure convergence [S1, unofficial].
- **Boundaries:** Gaussians may be pushed outside the scene bounds. Clamping or re-initialization strategies may be needed [G].
- **Degenerate Input:** If the initial point cloud is sparse, the noise injection helps in exploring the space, but convergence may be slower [S2, unofficial].

## Subtopics

### [HYDRA Densification](11088-hydra-densification.md)
A densification strategy that decomposes complex primitives into simpler constituents within the MCMC framework, enabling generalizable planar primitives to operate within MCMC [11088-hydra-densification.md].

### Fast MCMC Densification
An optimized implementation of the MCMC densification approach from 3DGS-MCMC [39], which treats 3D Gaussians as MCMC samples and uses SGLD updates [S2, unofficial]. It fuses the noise injection step into a single CUDA kernel to reduce the training time bottleneck [S2, unofficial]. On the Mip-NeRF360 dataset, the optimized version achieves 28.00 PSNR, 6m17s training time, and 7.2GiB VRAM, compared to the original 27.83 PSNR, 27m22s training time, and 8.9GiB VRAM [S2, unofficial]. The target number of Gaussians for the nine Mip-NeRF360 scenes (alphabetical order) are: 6131954, 1244819, 1222956, 3636448, 5834784, 1852335, 1593376, 4961797, 3783761 [S2, unofficial].

### Dynamic LoD Hierarchy Densification
A novel hierarchy densification strategy that allows Gaussian Level-of-Detail (LoD) hierarchies to evolve continuously during optimization, supporting stable refinement and restructuring without post-training hierarchy construction [S3, unofficial]. It maintains the hierarchy throughout training as Gaussian parameters and spatial distribution evolve dynamically, unlike methods that construct the hierarchy post-training [S3, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
- The base MCMC densification step involves computing gradients and adding noise, which is comparable in complexity to standard gradient descent but with the overhead of noise generation [S1, unofficial].
- The Fast MCMC Densification variant significantly reduces training time by fusing operations into a single CUDA kernel [S2, unofficial].

**Measured Performance:**
- On the Mip-NeRF360 dataset, the optimized Fast MCMC Densification achieves 28.00 PSNR with 6m17s training time and 7.2GiB VRAM, outperforming the original implementation in speed and memory usage while maintaining similar or slightly better quality [S2, unofficial].

**Strengths and Limitations:**
- **Strengths:** Reduces reliance on the initial point cloud, allows for specifying the number of Gaussians prior to optimization, and leads to improved rendering quality [S2, unofficial].
- **Limitations:** Requires careful tuning of hyperparameters ($\lambda_{lr}$, $\lambda_{noise}$) to ensure stability and convergence [S1, unofficial].

**When to Use:**
- Use when the initial point cloud is sparse or when a specific target number of Gaussians is desired [S2, unofficial].
- Use when computational resources are limited, and the optimized version is available [S2, unofficial].

## Background
MCMC Densification was introduced by Kheradmand et al. (2024) as an alternative Bayesian perspective to the densification strategy in Gaussian Splatting [S1, unofficial]. It reformulates the densification process as a Stochastic Gradient Langevin Dynamic (SGLD) update rule, adding noise to center locations to explore the parameter space [S1, unofficial]. This approach is part of the broader effort to improve the efficiency and quality of 3D Gaussian Splatting training [S2, unofficial].
