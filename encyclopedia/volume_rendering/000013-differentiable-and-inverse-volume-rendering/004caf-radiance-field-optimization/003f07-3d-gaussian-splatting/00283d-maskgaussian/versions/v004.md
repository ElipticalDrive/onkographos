# MaskGaussian

Also called: Masked Gaussian Splatting

## Overview
MaskGaussian is a differentiable pruning method for 3D Gaussian Splatting that models Gaussians as probabilistic entities rather than deterministically removing them based on static importance scores [S1]. It solves the problem of sub-optimal reconstruction caused by early pruning by introducing **masked-rasterization**, which allows gradients to flow to "masked-out" (inactive) Gaussians, enabling them to be re-evaluated and potentially reactivated as the scene evolves [S1]. Unlike sibling methods like [Compact3DGS](1398-compact3dgs.md) which use deterministic pruning or multiply masks with opacity/scale (blocking gradients), MaskGaussian applies masks during the alpha-blending stage, decoupling Gaussian existence from its geometric attributes [S1].

## How it works
MaskGaussian extends the standard 3D Gaussian Splatting pipeline by introducing learnable mask parameters for each Gaussian [S1]. The core innovation is a rasterization technique that applies these masks to the blending process, ensuring that even inactive Gaussians participate in the forward pass and receive gradient updates [S1].

### Inputs and Outputs
*   **Inputs:**
    *   Set of $N$ 3D Gaussians, each defined by position $\mathbf{p}_i$, covariance $\mathbf{\Sigma}_i$ (or rotation $\mathbf{R}_i$ and scale $\mathbf{s}_i$), color $\mathbf{c}_i$, and opacity $\alpha_i$ [G].
    *   Camera parameters (view and projection matrices) [G].
    *   Learnable mask scores $\mathbf{z}_i \in \mathbb{R}^2$ for each Gaussian $i$ [S1].
*   **Outputs:**
    *   Rendered image $\mathbf{I}$.
    *   Gradients for all Gaussian attributes and mask scores [S1].

### Data Structures
*   **Gaussian Attributes:** Standard 3DGS attributes (position, scale, rotation, SH coefficients, opacity) [G].
*   **Mask Scores:** For each Gaussian $i$, two learnable scalar values $\mathbf{z}_i = [z_{i,0}, z_{i,1}]$ [S1]. These are not probabilities but logits for a binary distribution [G].

### Numbered Steps
1.  **Mask Sampling:** For each Gaussian $i$, sample a binary mask $\mathcal{M}_i \in \{0, 1\}$ from the mask scores $\mathbf{z}_i$ using the Gumbel-Softmax trick to ensure differentiability [S1].
2.  **Standard Splatting (Alpha Computation):** Splat all $N$ Gaussians onto the image plane using standard 3DGS rasterization [S1]. Compute the splatted density $\alpha_i$ and transmittance $T_i$ for each Gaussian *without* applying the mask $\mathcal{M}_i$ to the opacity or scale [S1]. This ensures that all Gaussians, regardless of their mask value, pass through the alpha-filtering stage and are processed by the rasterizer [S1].
    *   $\alpha_i$: Splatted density of Gaussian $i$.
    *   $T_i$: Transmittance reaching Gaussian $i$, defined as $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ (assuming sorted order) [G].
3.  **Masked Rasterization (Color and Transmittance Blending):** Compute the final pixel color $\mathbf{c}(\mathbf{x})$ and update transmittance using the masks $\mathcal{M}_i$ [S1]. The mask is applied directly to the color accumulation and transmittance attenuation terms [S1].
    **Color Accumulation:**
    $$ \mathbf{c}(\mathbf{x}) = \sum_{i=1}^N \mathcal{M}_i \cdot \mathbf{c}_i \cdot \alpha_i \cdot T_i $$
    **Transmittance Update:**
    $$ T_{i+1} = \mathcal{M}_i \cdot (1 - \alpha_i) \cdot T_i + (1 - \mathcal{M}_i) \cdot T_i $$
    *   If $\mathcal{M}_i = 1$: The Gaussian contributes its color $\mathbf{c}_i \cdot \alpha_i \cdot T_i$ and attenuates transmittance by $(1-\alpha_i)$ [S1].
    *   If $\mathcal{M}_i = 0$: The Gaussian contributes no color, and transmittance is unchanged ($T_{i+1} = T_i$) [S1].
4.  **Loss Computation:** Compute the total loss $L$ [S1]:
    $$ L = L_{render} + \lambda_m \cdot L_m $$
    Where:
    *   $L_{render}$ is the standard rendering loss (e.g., L1 + SSIM) between the rendered image and the ground truth [G].
    *   $L_m$ is a squared loss on the average number of active Gaussians to constrain the model size:
        $$ L_m = \left( \frac{1}{N} \sum_{i=1}^N \mathcal{M}_i \right)^2 $$
    *   $\lambda_m$ is a balancing hyperparameter [S1].
5.  **Backpropagation:** Compute gradients for the mask scores $\mathbf{z}_i$ [S1]. The gradient of the loss with respect to the mask $\mathcal{M}_i$ is derived as:
    $$ \frac{\partial L}{\partial \mathcal{M}_i} = \alpha_i \cdot T_i \cdot \frac{\partial L}{\partial \mathbf{c}(\mathbf{x})} \cdot (\mathbf{c}_i - \mathbf{b}_{i+1}) $$
    Where $\mathbf{b}_{i+1}$ is the background color rendered behind the $i$-th Gaussian:
    $$ \mathbf{b}_{i+1} = \sum_{j=i+1}^N \mathcal{M}_j \cdot \mathbf{c}_j \cdot \alpha_j \cdot T_j $$
    The gradient flows through the Gumbel-Softmax operation to update $\mathbf{z}_i$ [S1]. This allows $\mathcal{M}_i=0$ Gaussians to receive meaningful gradients based on their potential contribution ($\mathbf{c}_i$) versus the background ($\mathbf{b}_{i+1}$) [S1].
6.  **Pruning Procedure:** Periodically, hard prune Gaussians with near-zero probability of existence [S1].
    *   Sample each Gaussian's mask 10 times [S1].
    *   If a Gaussian is never sampled (i.e., $\mathcal{M}_i=0$ in all 10 trials), remove it from the scene [S1].
    *   This is applied at every densification step and every 1000 iterations after densification [S1].

### Pseudocode
```python
import torch
import torch.nn.functional as F

def gumbel_softmax_sample(logits, temperature=1.0):
    """Samples from a Gumbel-Softmax distribution with straight-through estimator."""
    gumbels = -torch.empty_like(logits).exponential_().log()
    gumbels = (gumbels + logits) / temperature
    y_soft = F.softmax(gumbels, dim=-1)
    index = y_soft.max(1, keepdim=True)[1]
    y_hard = torch.zeros_like(logits, memory_format=torch.contiguous_format).scatter_(1, index, 1.0)
    return y_hard - y_soft.detach() + y_soft

def masked_rasterization(gaussians, camera, mask_scores, lambda_m, iteration, ground_truth):
    """Forward pass for MaskGaussian."""
    N = gaussians.num_gaussians
    
    # Step 1: Sample masks
    mask_samples = gumbel_softmax_sample(mask_scores) # Shape (N, 2)
    M = mask_samples[:, 1] # Probability of being active
    
    # Step 2: Standard Splatting (Alpha computation without mask)
    # Standard 3DGS projection and covariance computation [G]
    alpha, depth, indices = project_gaussians(gaussians.pos, gaussians.scales, gaussians.rotations, camera)
    # Sort by depth (back-to-front)
    alpha_sorted, indices_sorted = torch.sort(depth, dim=0, descending=True)
    
    # Compute Transmittance T_i for all Gaussians (without mask)
    alpha_flat = alpha_sorted.view(-1, alpha_sorted.shape[-1])
    T_flat = torch.cumprod(1 - alpha_flat, dim=1)
    T_flat = torch.cat([torch.ones_like(T_flat[:, :1]), T_flat[:, :-1]], dim=1)
    T = T_flat.view(alpha_sorted.shape)
    
    # Step 3: Masked Rasterization
    M_expanded = M.view(1, 1, -1).expand_as(alpha_sorted)
    
    # Get colors for each Gaussian (Standard SH evaluation [G])
    colors = evaluate_sh(gaussians.sh_coeffs, camera.view_dirs)
    
    # Apply Mask to Color Accumulation and Transmittance
    contribution = M_expanded * colors * alpha_sorted * T
    rendered_image = torch.sum(contribution, dim=2)
    
    # Step 4: Loss Computation
    L_render = torch.mean(torch.abs(rendered_image - ground_truth)) # L1 loss
    # SSIM is a standard differentiable metric added to L_render [G]
    
    avg_M = torch.mean(M)
    L_m = avg_M ** 2
    loss = L_render + lambda_m * L_m
    
    return rendered_image, loss, M
```

### Parameters
*   **$\lambda_m$**: Balancing weight for the squared loss $L_m$.
    *   Typical values:
        *   0.1 for iterations 19,000–20,000.
        *   0.0005 or 0.001 for iterations 0–30,000.
*   **Pruning Frequency**: Every densification step and every 1000 iterations after densification.
*   **Sampling Count for Pruning**: 10 samples per Gaussian to determine if it should be removed.

### Edge Cases and Pitfalls
*   **Gradient Blocking**: If masks are applied to opacity or scale (setting them to zero), the Gaussian's density $\alpha$ becomes zero. This causes the Gaussian to be filtered out before rasterization, preventing gradient updates. MaskGaussian avoids this by applying masks during blending [S1].
*   **Outdated Gaussians**: If masked Gaussians do not receive gradients, they remain static and may become outdated as the scene evolves. MaskGaussian ensures they receive gradients via masked-rasterization [S1].
*   **Fine Gaussians**: Methods that bind mask gradients to scales/opacity may disadvantage fine Gaussians if they receive negative gradients intended to shrink them. MaskGaussian decouples these [S1].

## Subtopics

### [Sparsity Regularization for Pruning](9357-sparsity-regularization-for-pruning.md)
A regularization technique applied to learnable mask parameters in 3D Gaussian Splatting to guide the pruning process and encourage condensed scene representations. It solves the problem of inefficient storage and rendering by promoting both fine-grained sparsity (removing non-essential individual Gaussians) and structural coherence (removing entire anchors). Unlike standard L1-style penalties which may leave anchors with only a few sparsely active Gaussians, hindering compactness, this method uses a group L2 norm to encourage switching off entire anchors cohesively. It builds on [MaskGaussian](4242-maskgaussian.md) by providing the optimization signal that determines which probabilistic entities should be deactivated.

## Operating characteristics
*   **Time Complexity**: Similar to standard 3DGS rasterization, with minor overhead for mask sampling and blending. The pruning step adds negligible overhead as it is performed periodically [G].
*   **Memory Complexity**: Adds $2N$ learnable parameters (mask scores) for $N$ Gaussians [G].
*   **Measured Performance**:
    *   **Mip-NeRF360**: 27.43 PSNR, 1.205M Gaussians, 384.7 FPS (vs. 3DGS: 27.45 PSNR, 3.204M Gaussians, 187.8 FPS). Pruning ratio: 62.4%. Speedup: 2.05x [S1].
    *   **Tanks & Temples**: 23.72 PSNR, 0.590M Gaussians, 558.3 FPS (vs. 3DGS: 23.74 PSNR, 1.825M Gaussians, 254.5 FPS). Pruning ratio: 67.7%. Speedup: 2.19x [S1].
    *   **Deep Blending**: 29.69 PSNR, 0.694M Gaussians, 637.1 FPS (vs. 3DGS: 29.53 PSNR, 2.815M Gaussians, 201.3 FPS). Pruning ratio: 75.3%. Speedup: 3.16x [S1].
*   **Strengths**:
    *   Achieves significant pruning ratios (62-75%) with minimal PSNR loss (0.02 dB) [S1].
    *   Enables real-time rendering with fewer Gaussians [S1].
    *   Allows dynamic re-evaluation of Gaussians, preventing premature pruning [S1].
*   **Limitations**:
    *   Requires modification of the rasterization code to implement masked-rasterization [S1].
    *   Hyperparameter $\lambda_m$ requires tuning for different scenes and training phases [S1].

## Background
MaskGaussian was introduced in the paper "MaskGaussian: Adaptive 3D Gaussian Representation from Probabilistic Masks" (CVPR 2025) [S1]. It builds upon [Compact3DGS](1398-compact3dgs.md) by extending its pruning approach from deterministic to probabilistic [S1]. The method addresses the limitations of previous mask-based pruning methods that multiply masks with Gaussian attributes (opacity/scale), which block gradient flow and lead to sub-optimal reconstruction [S1]. By treating pruning as a stochastic sampling process and introducing masked-rasterization, MaskGaussian allows for adaptive pruning that evolves with the scene [S1].
