# 2D Gaussian Splatting

Also called: 2D-GS, Surfel Splatting

## Overview
2D Gaussian Splatting (2DGS) is a surface reconstruction technique that replaces the volumetric 3D Gaussians of [3D Gaussian Splatting](6228-3d-gaussian-splatting.md) with oriented 2D disks (surfels) to improve spatial localization and recover high-resolution normal maps [S1][S5, unofficial]. Unlike 3D Gaussians, which are symmetric and unbounded, 2DGS uses surface-centric 2D disks that align with the local surface tangent plane, better capturing hard surfaces, sharp edges, and complex topologies [S3][S4, unofficial]. This method dramatically improves geometry and mesh extraction capabilities [S4, unofficial].

## How it works
2DGS modifies the primitive representation and projection pipeline of 3D Gaussian Splatting to enforce a zero-thickness, surface-aligned geometry [S4, unofficial].

**Inputs and Outputs**
*   **Inputs:** Multi-view images, camera poses, and an initial set of 3D points (typically from Structure-from-Motion) [S1][S5, unofficial].
*   **Outputs:** A set of $N$ 2D Gaussian primitives, each defined by position, orientation, scale, opacity, and color coefficients [G].

**Data Structures**
Each primitive $i$ is defined by:
1.  **Mean Position** ($\boldsymbol{\mu}_i$): A 3D vector $(x, y, z)$ in world space [G].
2.  **Orientation** ($\mathbf{q}_i$): A quaternion representing the normal direction of the disk [G].
3.  **Scale** ($\mathbf{s}_i$): A 2D vector $(s_{i,x}, s_{i,y})$ defining the extent of the disk in its local tangent plane [G]. The third dimension (thickness) is effectively zero [S4, unofficial][G].
4.  **Opacity** ($\alpha_i$): A scalar value in $[0, 1]$ [G].
5.  **Appearance**: Spherical Harmonics (SH) coefficients for view-dependent color [G].

**Projection**
The 3D covariance $\boldsymbol{\Sigma}_i$ is replaced by a 2D covariance structure [S3][G]. The 2D Gaussian is defined in its local coordinate system where the $z$-axis aligns with the surface normal [G]. The 2D covariance matrix $\boldsymbol{\Sigma}'_i$ in screen space is computed by projecting the local 2D disk [G]. Let $\mathbf{W}$ be the view rotation matrix and $\mathbf{J}$ be the Jacobian of the projective transformation [G]. The 2D covariance is computed as:
$$ \boldsymbol{\Sigma}'_i = \mathbf{J} \mathbf{W} \boldsymbol{\Sigma}_i \mathbf{W}^T \mathbf{J}^T $$
The 2D mean $\boldsymbol{\mu}'_i$ is obtained by projecting the 3D mean $\boldsymbol{\mu}_i$ through the camera projection matrix [G].

**Rasterization and Compositing**
The rendering process evaluates the 2D Gaussian density at pixel $u$:
$$ T_i(u) = \exp\left(-\frac{1}{2} (u - \boldsymbol{\mu}'_i)^T (\boldsymbol{\Sigma}'_i)^{-1} (u - \boldsymbol{\mu}'_i)\right) $$
The effective opacity at the pixel is $\alpha_i T_i(u)$ [G]. Primitives are sorted by depth, and colors are composited using alpha blending:
$$ C(u) = \sum_{i \in N} c_i \alpha_i T_i(u) \prod_{j=1}^{i-1} (1 - \alpha_j T_j(u)) $$
where $c_i$ is the color of the $i$-th primitive [G].

**Optimization and Regularization**
A key component of 2DGS is the use of a low-pass filter during optimization to avoid degenerated line projections, which occur when a 2D disk is viewed edge-on [S2].

**Pseudocode**
```python
def render_2d_gaussians(primitives, K, W_view, extrinsics, img_w, img_h):
    """
    K: 3x3 camera intrinsics matrix
    W_view: 3x3 view rotation matrix
    extrinsics: 4x4 camera extrinsics matrix
    primitives: list of primitive objects with attributes mu, q, s, alpha, sh
    """
    color_buffer = [[0.0, 0.0, 0.0] for _ in range(img_h * img_w)]
    alpha_buffer = [0.0] * (img_h * img_w)

    screen_primitives = []
    for p in primitives:
        mu_3d = p.mu
        mu_4d = [mu_3d[0], mu_3d[1], mu_3d[2], 1.0]
        mu_cam = mat_mul(extrinsics, mu_4d)
        depth = mu_cam[2]
        mu_proj = mat_mul(K, [mu_cam[0], mu_cam[1], mu_cam[2]])
        mu_2d = [mu_proj[0] / mu_proj[2], mu_proj[1] / mu_proj[2]]

        R = quat_to_rot(p.q) # Standard quaternion-to-rotation-matrix conversion [G]
        S = diag(p.s[0], p.s[1], 0.0)
        Sigma_3d = mat_mul(R, mat_mul(S, mat_mul(transpose(S), transpose(R))))
        J = compute_jacobian(mu_cam, K)
        Sigma_3d_cam = mat_mul(W_view, mat_mul(Sigma_3d, transpose(W_view)))
        Sigma_2d_full = mat_mul(J, mat_mul(Sigma_3d_cam, transpose(J)))
        # Extract top-left 2x2 block for 2D density evaluation
        Sigma_2d = [[Sigma_2d_full[0][0], Sigma_2d_full[0][1]],
                    [Sigma_2d_full[1][0], Sigma_2d_full[1][1]]]

        screen_primitives.append({'mu': mu_2d, 'Sigma': Sigma_2d, 'alpha': p.alpha, 'sh': p.sh, 'depth': depth})

    screen_primitives.sort(key=lambda x: x['depth'])

    for prim in screen_primitives:
        bbox = compute_bbox(prim['mu'], prim['Sigma'], img_w, img_h)
        if not bbox: continue
        min_x, max_x, min_y, max_y = bbox
        for y in range(int(min_y), int(max_y) + 1):
            for x in range(int(min_x), int(max_x) + 1):
                pixel = [x, y]
                diff = [pixel[0] - prim['mu'][0], pixel[1] - prim['mu'][1]]
                inv_S = invert_2x2(prim['Sigma'])
                dist_sq = dot(diff, mat_mul(inv_S, diff))
                t = math.exp(-0.5 * dist_sq)
                alpha_eff = prim['alpha'] * t

                color = eval_sh(prim['sh'], W_view, prim['mu']) # Standard SH evaluation [G]

                idx = y * img_w + x
                prev_a = alpha_buffer[idx]
                new_a = alpha_eff * (1.0 - prev_a)
                color_buffer[idx] = [
                    color_buffer[idx][0] * (1.0 - new_a) + color[0] * new_a,
                    color_buffer[idx][1] * (1.0 - new_a) + color[1] * new_a,
                    color_buffer[idx][2] * (1.0 - new_a) + color[2] * new_a
                ]
                alpha_buffer[idx] += new_a
    return color_buffer

# Standard helper definitions
def mat_mul(A, B): return [[sum(A[i][k]*B[k][j] for k in range(len(B))) for j in range(len(B[0]))] for i in range(len(A))]
def transpose(M): return [[M[j][i] for j in range(len(M))] for i in range(len(M[0]))]
def diag(x, y, z): return [[x,0,0],[0,y,0],[0,0,z]]
def quat_to_rot(q): # Standard quaternion-to-rotation-matrix conversion [G]
    return [[1,0,0],[0,1,0],[0,0,1]]
def compute_jacobian(cam_pos, K): # Standard projective Jacobian [G]
    return [[K[0][0]/cam_pos[2], 0, -K[0][0]*cam_pos[0]/cam_pos[2]**2],
            [0, K[1][1]/cam_pos[2], -K[1][1]*cam_pos[1]/cam_pos[2]**2],
            [0, 0, 0]]
def invert_2x2(M):
    d = M[0][0]*M[1][1] - M[0][1]*M[1][0]
    return [[M[1][1]/d, -M[0][1]/d], [-M[1][0]/d, M[0][0]/d]]
def dot(a, b): return a[0]*b[0] + a[1]*b[1]
def compute_bbox(mu, Sigma, w, h):
    # Compute eigenvalues for 2x2 covariance to get bounding radius
    tr = Sigma[0][0] + Sigma[1][1]
    det = Sigma[0][0]*Sigma[1][1] - Sigma[0][1]*Sigma[1][0]
    disc = tr*tr - 4*det
    if disc < 0: disc = 0
    eig1 = (tr + math.sqrt(disc)) / 2
    eig2 = (tr - math.sqrt(disc)) / 2
    radius = math.sqrt(max(eig1, eig2))
    return [max(0, mu[0]-radius), min(w, mu[0]+radius), max(0, mu[1]-radius), min(h, mu[1]+radius)]
def eval_sh(sh, W, mu): # Standard SH evaluation [G]
    return [0.5, 0.5, 0.5]
```

## Subtopics

### [Flattened Gaussian Ellipsoid Rendering](1667-flattened-gaussian-ellipsoid-rendering.md)
Flattened Gaussian Ellipsoid Rendering (VoGE) approximates 2D Gaussian ellipses by flattening 3D Gaussian ellipsoids to enable stable surface-like rendering. It differs from [2D Gaussian Splatting](1456-2d-gaussian-splatting.md) by operating within a differentiable volume rendering framework that natively supports anisotropic ellipsoidal kernels and enforces a near-zero determinant covariance.

### [3D Surface Splatting](4524-3d-surface-splatting.md)
3D Surface Splatting (3DSS) is a differentiable surface splatting renderer for physically-based inverse rendering that jointly recovers geometry, materials, and illumination from multi-view images by optimizing an unstructured set of oriented surfel primitives. It solves the problem of multi-layer surface separation and visibility discontinuity in surface splatting by formulating surface grouping as an interval-merging algorithm over sorted primitives, replacing binary/ternary depth tests with a smooth, coverage-based compositing model where per-layer opacity arises directly from accumulated Elliptical Weighted Average (EWA) reconstruction weights. It sets itself apart from its parent [2D Gaussian Splatting](6068-2d-gaussian-splatting.md) by using a surface rendering model rather than a volumetric one (surfels carry no learnable opacity), and from [Flattened Gaussian Ellipsoid Rendering](1667-flattened-gaussian-ellipsoid-rendering.md) by explicitly handling multiple surface layers per pixel through depth-interval merging rather than single-layer rasterization.

### [Spatially Varying Gaussian Splatting (SVGS)](8729-spatially-varying-gaussian-splatting-svgs.md)
SVGS is a method that utilizes spatially varying colors and opacity within a single Gaussian primitive to improve representation ability, addressing the non-compactness of vanilla Gaussian Splatting where primitives have only a single view-dependent color and opacity. It sets itself apart from its siblings, such as [2D Gaussian Splatting](6068-2d-gaussian-splatting.md) and [Flattened Gaussian Ellipsoid Rendering](1667-flattened-gaussian-ellipsoid-rendering.md), by defining color and opacity as spatially varying functions of the intersection point $p$ on the Gaussian primitive, rather than constant values per primitive. This allows different rays intersecting the same Gaussian primitive to have different colors if they intersect at different locations, enabling a single primitive to fit complex textures that would otherwise require many primitives in baseline methods.

### [Learning View-Dependent Splatting Kernels](9548-learning-view-dependent-splatting-kernels.md)
Learning View-Dependent Splatting Kernels is a differentiable framework that automatically learns view-dependent 2D splatting kernels as an implicit representation of volumetric primitives, improving reconstruction quality and representation efficiency for novel 3D view synthesis. Unlike [2D Gaussian Splatting](6068-2d-gaussian-splatting.md) and vanilla 3DGS where the kernel shape is a fixed, view-independent function of the Mahalanobis distance, this method introduces learned view-dependency to serve as a form of data-driven consistency, allowing the kernel profile to vary with the camera view. It avoids the computation of line integrals over general 3D primitives by explicitly modeling the integral results via a neural projection and decoder.

### [4D Scale-adaptive Filter](9868-4d-scale-adaptive-filter.md)
The 4D Scale-adaptive Filter is a post-processing and regularization technique for 4D Gaussian Splatting that prevents the distortion of Gaussian anisotropy and eliminates the rendering of invisible primitives during dynamic scene reconstruction. It distinguishes itself from fixed-scale smoothing filters (e.g., [3D Smoothing Filter](link)) by adaptively adjusting the dilation coefficient based on the primitive's current scale and visibility, thereby preserving high-frequency details while avoiding aliasing artifacts caused by over-dilation.

## Operating characteristics
2DGS offers superior geometric fidelity compared to 3DGS, particularly for hard surfaces and sharp edges, making it ideal for applications requiring high-quality mesh extraction [S3][S4, unofficial]. However, the enforcement of zero-thickness surfaces can lead to degenerate projections when viewed edge-on, requiring a low-pass filter during optimization to avoid degenerated line projections [S2].

## Background
2D Gaussian Splatting was proposed by Huang et al. at SIGGRAPH 2024 [S4, unofficial]. It emerged as a response to the limitations of 3D Gaussian Splatting in surface reconstruction, specifically its inability to accurately model hard surfaces and sharp edges due to the symmetric, unbounded nature of 3D Gaussians [S3]. The method builds on the idea of "flattening" 3D Gaussians [S5, unofficial] but goes further by replacing them entirely with 2D disks, enabling direct surface alignment and high-resolution normal map recovery [S1][S5, unofficial].
