# Inverse Rendering with Inter-reflections (IRGS)

Also called: GIR, GS-IR, Inverse Gaussian Splatting

## Overview
IRGS is an inverse-rendering framework that models inter-reflections by applying the full rendering equation without simplification, computing incident radiance on the fly via differentiable 2D Gaussian ray tracing [S2, unofficial]. It fixes inaccurate material and lighting estimates produced by earlier 3D Gaussian Splatting inverse-rendering methods like GS-IR and Relightable 3DG, which relied on simplified equations or learned light approximations [S2, unofficial]. GS-IR jointly optimizes Gaussian geometry and an environment light probe, using a differentiable rasterizer to backpropagate gradients through the rendering equation [S1, unofficial].

## How it works

**Method Steps:**
1. Compute incident radiance on each Gaussian surface element via differentiable 2D Gaussian ray tracing [S2, unofficial].
2. Apply the full rendering equation without simplification to model inter-reflections [S2, unofficial].
3. Backpropagate gradients through the rendering equation using a differentiable rasterizer [S1, unofficial].
4. Jointly optimize Gaussian geometry and environment light probe parameters [S1, unofficial].

**Pseudocode:**
```python
def irgs_optimize(images, initial_gaussians, initial_light_probe, num_iterations):
    gaussians = initial_gaussians
    light_probe = initial_light_probe

    for i in range(num_iterations):
        # 1. Compute incident radiance via differentiable 2D Gaussian ray tracing [S2, unofficial]
        # Sources do not specify the exact ray-tracing density evaluation [G]
        incident_radiance = standard_differentiable_ray_trace(gaussians, light_probe)

        # 2. Render image using full rendering equation (no simplification)
        # Sources do not specify the exact integration routine [G]
        rendered_image = standard_full_rendering_equation(gaussians, light_probe, incident_radiance)

        # 3. Compute loss against input images
        target = images[i % len(images)]
        loss = torch.sum((rendered_image - target) ** 2)  # Standard L2 loss [G]

        # 4. Backpropagate gradients through the rendering equation
        # Uses differentiable rasterizer/ray-tracer [S1, unofficial]
        grad_gaussians, grad_light_probe = torch.autograd.grad(loss, [gaussians, light_probe])

        # 5. Update parameters via gradient descent
        gaussians = gaussians - 0.01 * grad_gaussians
        light_probe = light_probe - 0.01 * grad_light_probe

    return gaussians, light_probe
```
