# Inverse Rendering with Gaussians (GS-IR / GIR)

Also called: GIR, GS-IR, GS-IR / GIR

## Overview
Inverse Rendering with Gaussians (GS-IR / GIR) adapts 3D Gaussian Splatting to recover physically accurate material and lighting properties from images by optimizing differentiable shading models [S2]. It distinguishes itself from sibling methods by employing a split-sum approximation to handle indirect lighting and specular reflections [S1, unofficial][S2].

## How it works
GS-IR extends the standard 3D Gaussian Splatting pipeline by replacing the static color attribute with a parameterized shading model [G]. The method optimizes geometry, appearance, and lighting simultaneously [G].

**Inputs and Outputs:**
*   **Inputs:** A set of multi-view images $\{I_k\}$, initial 3D Gaussian points (typically from Structure-from-Motion or a pre-trained 3DGS), and an initial environment light probe [G].
*   **Outputs:** Optimized 3D Gaussian attributes (position $\mathbf{p}$, covariance $\mathbf{\Sigma}$, opacity $\alpha$, albedo $\mathbf{c}_d$, roughness $\rho$) and a high-dynamic-range environment map $\mathbf{L}_e$ [G].

**Data Structures:**
Each Gaussian $i$ stores:
*   $\mathbf{p}_i \in \mathbb{R}^3$: Center position [G].
*   $\mathbf{\Sigma}_i \in \mathbb{R}^{3 \times 3}$: Covariance matrix (parameterized as rotation $\mathbf{R}$ and scale $\mathbf{s}$) [G].
*   $\alpha_i \in [0, 1]$: Opacity [G].
*   $\mathbf{c}_{d,i} \in \mathbb{R}^3$: Diffuse albedo [G].
*   $\rho_i \in [0, 1]$: Roughness parameter [G].
*   $\mathbf{L}_e$: Environment light probe, typically stored as a pre-filtered cubemap or spherical harmonics [G].

**Rendering Equation with Split-Sum Approximation:**
The method uses a split-sum approximation to decouple direct and indirect lighting [S1, unofficial]. The outgoing radiance is approximated as:
$$ L_o(\mathbf{x}, \omega_o) \approx L_{\text{diffuse}} + L_{\text{specular}} $$
Where:
$$ L_{\text{diffuse}} = \frac{\mathbf{c}_{d,i}}{\pi} \int_{\Omega} L_i(\omega_i) (\mathbf{n} \cdot \omega_i) d\omega_i $$
$$ L_{\text{specular}} = \int_{\Omega} L_i(\omega_i) f_r(\omega_i, \omega_o) (\mathbf{n} \cdot \omega_i) d\omega_i $$
The diffuse term integrates against the environment map directly, while the specular term uses a pre-filtered environment map or importance sampling to handle sharp reflections efficiently [G].

**Algorithm Steps:**
1.  **Initialization:** Initialize Gaussians from a sparse point cloud [G]. Set initial albedo to mean image color, roughness to a mid-range value (e.g., 0.5), and environment map to a uniform or captured probe [G].
2.  **Projection and Rasterization:** Project Gaussians to screen space using the camera matrix [G]. Sort primitives by depth within tiles to ensure correct front-to-back compositing [G].
3.  **Shading Evaluation:** For each pixel covered by a Gaussian, compute the normal $\mathbf{n}$ from the Gaussian's covariance [G]. Accurate normal estimation can be derived from computed depth maps or using the shortest direction axis of Gaussians [S2]. Evaluate the BRDF using the current albedo, roughness, and environment map $\mathbf{L}_e$ [G].
4.  **Compositing:** Accumulate colors using front-to-back alpha blending [G].
5.  **Loss Computation:** Compare rendered images with ground truth using $L_1$ and SSIM losses [G].
6.  **Optimization:** Update Gaussian attributes and environment map parameters using an Adam optimizer [G]. Regularization terms may be applied to stabilize normals and prevent overfitting [G].

**Pseudocode:**
```python
import math
import numpy as np

def render_gaussian_gir(gaussians, camera, env_map):
    # 1. Project Gaussians to screen space
    screen_gaussians = []
    for g in gaussians:
        cam_pos = camera.world_to_cam(g.position)
        screen_pos = camera.projection(cam_pos)
        screen_gaussians.append({**g, 'screen_pos': screen_pos})

    # 2. Sort by depth within tiles
    screen_gaussians.sort(key=lambda g: g['screen_pos'].z)

    rendered_image = np.zeros((camera.height, camera.width, 3))
    for y in range(camera.height):
        for x in range(camera.width):
            color = np.array([0.0, 0.0, 0.0])
            alpha = 0.0
            for g in screen_gaussians:
                if not gaussian_covers_pixel(g, x, y):
                    continue
                # Compute normal from Gaussian covariance
                n = compute_normal_from_covariance(g.covariance)
                # Split-sum shading
                diffuse = (g.albedo / math.pi) * integrate_env_map_diffuse(env_map, n)
                specular = evaluate_specular_brdf(n, camera.view_dir, g.roughness, env_map)
                radiance = diffuse + specular
                # Alpha blending
                weight = g.opacity * gaussian_pdf(g, x, y)
                color = color * (1 - weight) + radiance * weight
                alpha = alpha * (1 - weight) + weight
                if alpha > 0.99:
                    break
            rendered_image[y, x] = color
    return rendered_image

def optimize_gs_ir(images, gaussians, env_map, num_epochs=1000):
    for epoch in range(num_epochs):
        for image_path, camera in images:
            gt_image = load_image_from_disk(image_path)
            pred_image = render_gaussian_gir(gaussians, camera, env_map)
            loss = l1_loss(pred_image, gt_image) + ssim_loss(pred_image, gt_image)
            loss.backward()
            gaussians.optimizer.step()
            env_map.optimizer.step()
            gaussians.optimizer.zero_grad()
            env_map.optimizer.zero_grad()

# Standard helper operations [G]
def gaussian_covers_pixel(g, x, y): return True
def compute_normal_from_covariance(cov): return np.array([0.0, 0.0, 1.0])
def integrate_env_map_diffuse(env_map, normal): return np.array([0.5, 0.5, 0.5])
def evaluate_specular_brdf(normal, view_dir, roughness, env_map): return np.array([0.0, 0.0, 0.0])
def gaussian_pdf(g, x, y): return math.exp(-0.5)
def l1_loss(pred, gt): return np.mean(np.abs(pred - gt))
def ssim_loss(pred, gt): return 0.0
def load_image_from_disk(path): return np.zeros((100, 100, 3))
```

## Subtopics

### Inverse Rendering with 3DGS
Methods adapting inverse rendering techniques to 3DGS to handle specular reflections by simplifying the classical rendering equation [S2]. These approaches rely on accurate normal estimation, which can be derived from computed depth maps or using the shortest direction axis of Gaussians [S2]. The different lighting conditions are then encoded via integrated shading functions [S2]. While these 3DGS-based methods achieve rapid convergence, they still introduce substantial noise in geometry, material, and lighting, which remains a limitation for high-fidelity rendering [S2].

## Operating characteristics
*   **Time Complexity:** Optimization is significantly faster than NeRF-based inverse rendering methods due to the explicit representation and rasterization pipeline, but slower than standard 3DGS due to additional shading computations and environment map updates [G].
*   **Memory Complexity:** Requires storing additional attributes (albedo, roughness) per Gaussian and the environment map. The environment map size depends on the resolution of the pre-filtered cubemap or SH degree [G].
*   **Strengths:** Enables relighting and material editing; faster convergence than implicit methods; handles specular reflections better than standard 3DGS [G].
*   **Limitations:** Noise in geometry and material estimation can be substantial [S2].
*   **When to use:** When relighting or material recovery is required and real-time rendering speed is important [G].
*   **When not to use:** When high-fidelity, noise-free material recovery is critical without extensive post-processing or regularization [G].

## Background
Inverse rendering with Gaussians emerged as a natural extension of 3D Gaussian Splatting (3DGS) [KKLD23], aiming to add physical properties to the efficient explicit representation [G]. Early attempts to adapt inverse rendering to 3DGS focused on simplifying the classical rendering equation to handle specular reflections [S2]. These methods typically derive normals from depth maps or Gaussian axes and encode lighting via integrated shading functions [S2]. While they offer rapid convergence compared to NeRF-based approaches, they often suffer from noise in the recovered geometry and materials [S2]. The field continues to evolve with variants like IRGS that attempt to model inter-reflections more accurately.
