# Inverse Rendering with Gaussians (GS-IR / GIR)

Also called: GIR, GS-IR, GS-IR / GIR

## Overview
Inverse Rendering with Gaussians (GS-IR) is a method that recovers physically accurate material and lighting properties from images by optimizing 3D Gaussian primitives. It addresses the limitation of standard 3D Gaussian Splatting, which typically assumes fixed, view-dependent colors, by introducing differentiable shading models. GS-IR distinguishes itself from sibling methods like [3D Gaussian Splatting with BRDF Embedding](1174-3d-gaussian-splatting-with-brdf-embedding.md) by employing a split-sum approximation to handle indirect lighting, allowing for the separation of diffuse and specular components in the optimization process.

## How it works
GS-IR extends the standard 3D Gaussian Splatting pipeline by replacing the static color attribute with a parameterized shading model. The method optimizes geometry (position, covariance), appearance (albedo, roughness), and lighting (environment map) simultaneously.

**Inputs and Outputs:**
*   **Inputs:** A set of multi-view images $\{I_k\}$, initial 3D Gaussian points (often from Structure-from-Motion or a pre-trained 3DGS), and an initial environment light probe.
*   **Outputs:** Optimized 3D Gaussian attributes (position $\mathbf{p}$, covariance $\mathbf{\Sigma}$, opacity $\alpha$, albedo $\mathbf{c}_d$, roughness $\rho$) and a high-dynamic-range environment map $\mathbf{L}_e$.

**Data Structures:**
Each Gaussian $i$ stores:
*   $\mathbf{p}_i \in \mathbb{R}^3$: Center position.
*   $\mathbf{\Sigma}_i \in \mathbb{R}^{3 \times 3}$: Covariance matrix (often stored as rotation $\mathbf{R}$ and scale $\mathbf{s}$ for parameterization).
*   $\alpha_i \in [0, 1]$: Opacity.
*   $\mathbf{c}_{d,i} \in \mathbb{R}^3$: Diffuse albedo.
*   $\rho_i \in [0, 1]$: Roughness parameter.
*   $\mathbf{L}_e$: Environment light probe, typically represented as Spherical Harmonics (SH) or a pre-filtered cubemap.

**Rendering Equation with Split-Sum Approximation:**
The core innovation is the split-sum approximation of the rendering equation to decouple direct and indirect lighting. The outgoing radiance $L_o$ is approximated as:
$$ L_o(\mathbf{x}, \omega_o) \approx L_{diffuse} + L_{specular} $$
Where:
$$ L_{diffuse} = \frac{\mathbf{c}_{d,i}}{\pi} \int_{\Omega} L_i(\omega_i) (\mathbf{n} \cdot \omega_i) d\omega_i $$
$$ L_{specular} = \int_{\Omega} L_i(\omega_i) f_r(\omega_i, \omega_o) (\mathbf{n} \cdot \omega_i) d\omega_i $$
In practice, the diffuse term is often integrated against the environment map directly, while the specular term uses a pre-filtered environment map or importance sampling to handle sharp reflections efficiently.

**Algorithm Steps:**
1.  **Initialization:** Initialize Gaussians from a sparse point cloud. Set initial albedo to mean image color, roughness to a mid-range value (e.g., 0.5), and environment map to a uniform or captured probe.
2.  **Projection and Rasterization:** Project Gaussians to screen space using the camera matrix. Sort by depth within tiles.
3.  **Shading Evaluation:** For each pixel covered by a Gaussian, compute the normal $\mathbf{n}$ from the Gaussian's covariance. Evaluate the BRDF using the current albedo, roughness, and the environment map $\mathbf{L}_e$.
4.  **Compositing:** Accumulate colors using front-to-back alpha blending.
5.  **Loss Computation:** Compare rendered images with ground truth using $L_1$ and SSIM losses.
6.  **Optimization:** Update Gaussian attributes and environment map parameters using Adam optimizer. Regularization terms may be applied to stabilize normals and prevent overfitting.

**Pseudocode:**
```python
def render_gaussian_gir(gaussians, camera, env_map):
    """
    Renders a scene using GS-IR with split-sum approximation.
    """
    # 1. Project Gaussians to screen space
    screen_gaussians = project_to_screen(gaussians, camera)
    
    # 2. Sort and rasterize
    tiles = assign_to_tiles(screen_gaussians)
    for tile in tiles:
        sorted_gaussians = sort_by_depth(tile.gaussians)
        for pixel in tile.pixels:
            color = vec3(0.0)
            alpha = 0.0
            for g in sorted_gaussians:
                # Compute normal from Gaussian covariance
                n = compute_normal(g.covariance)
                
                # Split-sum shading
                # Diffuse: integrate albedo against environment map
                diffuse = (g.albedo / PI) * integrate_env_map(env_map, n)
                
                # Specular: evaluate BRDF with pre-filtered env map
                specular = evaluate_specular_brdf(
                    n, 
                    camera.view_direction, 
                    g.roughness, 
                    env_map.specular_lut
                )
                
                radiance = diffuse + specular
                
                # Alpha blending
                weight = g.opacity * gaussian_pdf(g, pixel)
                color = color * (1 - weight) + radiance * weight
                alpha = alpha * (1 - weight) + weight
                
                if alpha > 0.99:
                    break
            pixel.color = color
            pixel.alpha = alpha
    return rendered_image

def optimize_gs_ir(images, gaussians, env_map, lr=0.01):
    """
    Optimizes Gaussians and environment map.
    """
    for epoch in range(num_epochs):
        for image_path in images:
            gt_image = load_image(image_path)
            camera = get_camera_for_image(image_path)

            pred_image = render_gaussian_gir(gaussians, camera, env_map)
            
            # Loss calculation
            loss = l1_loss(pred_image, gt_image) + ssim_loss(pred_image, gt_image)
            
            # Backward pass
            loss.backward()
            
            # Update parameters
            gaussians.optimizer.step()
            env_map.optimizer.step()
            gaussians.optimizer.zero_grad()
            env_map.optimizer.zero_grad()
```

## Subtopics

### Inverse Rendering with 3DGS
Methods adapting inverse rendering techniques to 3DGS to handle specular reflections by simplifying the classical rendering equation [S2]. These approaches rely on accurate normal estimation, which can be derived from computed depth maps [LZF∗ 24] or using the shortest direction axis of Gaussians [JTL∗ 24, YHZ24]. The different lighting conditions are then encoded via integrated shading functions [S2]. While these 3DGS-based methods achieve rapid convergence, they still introduce substantial noise in geometry, material, and lighting, which remains a limitation for high-fidelity rendering [S2].

## Operating characteristics
*   **Time Complexity:** Optimization is significantly faster than NeRF-based inverse rendering methods due to the explicit representation and rasterization pipeline, but slower than standard 3DGS due to the additional shading computations and environment map updates.
*   **Memory Complexity:** Requires storing additional attributes (albedo, roughness) per Gaussian and the environment map. The environment map size depends on the resolution of the pre-filtered cubemap or SH degree.
*   **Strengths:** Enables relighting and material editing; faster convergence than implicit methods; handles specular reflections better than standard 3DGS.
*   **Limitations:** Noise in geometry and material estimation can be substantial [S2]; relies on accurate normal estimation which is challenging for Gaussians; split-sum approximation may introduce artifacts in complex lighting scenarios.
*   **When to use:** When relighting or material recovery is required and real-time rendering speed is important.
*   **When not to use:** When high-fidelity, noise-free material recovery is critical without extensive post-processing or regularization.

## Background
Inverse rendering with Gaussians emerged as a natural extension of 3D Gaussian Splatting (3DGS) [KKLD23], aiming to add physical properties to the efficient explicit representation. Early attempts to adapt inverse rendering to 3DGS focused on simplifying the classical rendering equation to handle specular reflections [S2]. These methods typically derive normals from depth maps or Gaussian axes and encode lighting via integrated shading functions [S2]. While they offer rapid convergence compared to NeRF-based approaches, they often suffer from noise in the recovered geometry and materials [S2]. The field continues to evolve with variants like IRGS that attempt to model inter-reflections more accurately.
