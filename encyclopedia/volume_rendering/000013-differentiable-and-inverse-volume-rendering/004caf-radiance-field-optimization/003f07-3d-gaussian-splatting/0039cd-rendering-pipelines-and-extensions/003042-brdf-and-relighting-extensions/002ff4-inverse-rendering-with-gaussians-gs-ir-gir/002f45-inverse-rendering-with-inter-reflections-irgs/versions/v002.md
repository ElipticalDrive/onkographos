# Inverse Rendering with Inter-reflections (IRGS)

Also called: GIR, GS-IR, Inverse Gaussian Splatting

## Overview
IRGS is an inverse-rendering framework that models inter-reflections by applying the full rendering equation without simplification, computing incident radiance on the fly via differentiable 2D Gaussian ray tracing [S2, unofficial]. It fixes inaccurate material and lighting estimates produced by earlier 3D Gaussian Splatting inverse-rendering methods like GS-IR and Relightable 3DG, which relied on simplified equations or learned light approximations [S2, unofficial]. GS-IR jointly optimizes Gaussian geometry and an environment light probe, using a differentiable rasterizer to backpropagate gradients through the rendering equation [S1, unofficial]. IRGS builds on [Inverse Rendering with Gaussians (GS-IR / GIR)](6153-inverse-rendering-with-gaussians-gs-ir-gir.md).

**Method Steps:**
1.  Compute incident radiance on each Gaussian surface element via differentiable 2D Gaussian ray tracing [S2, unofficial].
2.  Apply the full rendering equation without simplification to model inter-reflections [S2, unofficial].
3.  Backpropagate gradients through the rendering equation using a differentiable rasterizer [S1, unofficial].
