# NeRF with Softplus Activation and Importance Sampling

Also called: Original NeRF architecture with proposed reparameterization

## Overview
This method adapts the original Neural Radiance Fields (NeRF) architecture [4972-neural-radiance-fields.md] by replacing the ReLU output activation for volume density $\sigma$ with a Softplus function to ensure non-zero gradients, and employing an importance-sampling reparameterization for color estimation [S1, unofficial]. It differs from the standard NeRF baseline by using uniform weights for samples in the color estimate rather than a hierarchical fine network, and from [Explicit Radiance Fields](806-explicit-radiance-fields.md) by relying on a continuous grid representation [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N_{img}$ training images with known camera poses; a scene bounding box defining the ray segment $[t_n, t_f]$.
*   **Output:** A rendered color $\hat{C}(\mathbf{r})$ for a query ray $\mathbf{r}$, and optimized network weights.

**Data Structures:**
*   **Neural Network:** A Multi-Layer Perceptron (MLP) identical to the original NeRF architecture [4972-neural-radiance-fields.md], taking position $\mathbf{x}$ and viewing direction $\mathbf{d}$ as input.
*   **Output Layer:** The final layer outputs volume density $\sigma$ and color $\mathbf{c}$.
*   **Ray Sampling Grid:** A piecewise linear density approximation constructed by perturbing a uniform grid with $K=256$ knots [S1, unofficial].

**Algorithm Steps:**

1.  **Batch Construction:** Select a random subset of 64 training images. For each image, sample 64 rays [S1, unofficial].
2.  **Ray Sampling:** For each ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$, sample $N$ points $t_i$ along the segment $[t_n, t_f]$ using the perturbed uniform grid with 256 knots [S1, unofficial].
3.  **Network Forward Pass:** For each sample point $t_i$, query the MLP to obtain volume density $\sigma_i$ and color $\mathbf{c}_i$.
4.  **Density Activation:** Apply the Softplus activation to the raw network output $\sigma_{raw}$ to obtain the final density $\sigma_i$:
    $$ \sigma_i = \frac{1}{\beta} \ln(1 + \exp(\beta \cdot \sigma_{raw})) $$
    where $\beta = 10$ is the temperature parameter [S1, unofficial].
5.  **Opacity and Transmittance:** Compute opacity $\alpha_i$ and accumulated transmittance $T_i$ as defined in the parent article [4972-neural-radiance-fields.md]:
    $$ \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
    $$ T_i = \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    where $\delta_i$ is the distance to the next sample.
6.  **Color Estimation (Importance Sampling):** Estimate the expected color using $k$ samples with uniform weights [S1, unofficial]. The rendered color $\hat{C}(\mathbf{r})$ is calculated as:
    $$ \hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i $$
    *Note: The source describes this as "importance-sampling reparameterization" but explicitly states samples are weighted with uniform weights in the color estimate (Equation 10) [S1, unofficial]. The variance of this stochastic estimate is noted as a factor preventing fine optimum convergence [S1, unofficial].*

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def softplus_density(raw_sigma, beta=10.0):
    """
    Applies Softplus activation to volume density.
    Args:
        raw_sigma: Tensor of raw density outputs from MLP.
        beta: Temperature parameter (default 10).
    Returns:
        Tensor of activated density values.
    """
    return (1.0 / beta) * torch.log(1.0 + torch.exp(beta * raw_sigma))

def render_ray(ray_o, ray_d, t_near, t_far, num_samples, network, k_samples=32):
    """
    Renders a single ray using the NeRF architecture with Softplus and importance sampling.
    Args:
        ray_o: Origin of the ray (3,).
        ray_d: Direction of the ray (3,).
        t_near: Near plane distance.
        t_far: Far plane distance.
        num_samples: Number of points sampled along the ray (e.g., 256).
        network: The NeRF MLP model.
        k_samples: Number of samples used in the importance-sampling reparameterization.
    Returns:
        Rendered color (3,).
    """
    # 1. Sample points along the ray
    # Source [S1, unofficial] mentions perturbing a uniform grid with 256 knots.
    # For implementation, we use stratified sampling or uniform sampling on the segment.
    t_vals = torch.linspace(t_near, t_far, num_samples)
    # Add jitter for stratified sampling if desired, though source implies perturbed uniform grid.
    # Here we assume uniform spacing for the base grid as per "piecewise linear density approximation" description.
    deltas = t_vals[1:] - t_vals[:-1]
    deltas = torch.cat([deltas, torch.tensor([1e10])]) # Handle last delta
    
    # 2. Query Network
    # Construct positions and directions
    positions = ray_o.unsqueeze(0) + t_vals.unsqueeze(1) * ray_d.unsqueeze(0)
    # Directions are constant for straight rays
    directions = ray_d.unsqueeze(0).expand_as(positions)
    
    # Flatten for network input
    pos_flat = positions.reshape(-1, 3)
    dir_flat = directions.reshape(-1, 3)
    
    # Forward pass
    raw_sigma, raw_color = network(pos_flat, dir_flat)
    
    # Reshape back
    raw_sigma = raw_sigma.view(num_samples, 1)
    raw_color = raw_color.view(num_samples, 3)
    
    # 3. Apply Softplus Activation
    sigma = softplus_density(raw_sigma)
    
    # 4. Compute Opacity and Transmittance
    alpha = 1.0 - torch.exp(-sigma * deltas)
    transmittance = torch.cumprod(torch.cat([torch.ones(1, 1), 1.0 - alpha[:-1]]), dim=0)
    
    # 5. Compute Color
    # Source [S1, unofficial] states: "samples in our model are weighted with uniform weights"
    # and uses Equation 10 with k samples. The standard volume rendering equation is used.
    # The "importance sampling" refers to the reparameterization technique for gradient estimation,
    # but the final color estimate uses the sampled points with their natural weights.
    
    # Contribution of each sample
    contributions = transmittance * alpha * raw_color
    
    # Sum contributions
    color = torch.sum(contributions, dim=0)
    
    return color

def train_step(batch_images, batch_poses, network, optimizer):
    """
    Training step.
    Args:
        batch_images: Tensor of shape (64, H, W, 3) - 64 random training images.
        batch_poses: Tensor of camera poses for the batch.
        network: The NeRF MLP.
        optimizer: Optimizer for the network.
    """
    optimizer.zero_grad()
    
    # Source [S1, unofficial]: Select 64 images, 64 rays per image.
    # Construct rays from poses and pixel coordinates.
    rays_o, rays_d = construct_rays(batch_poses, batch_images.shape[1:])
    
    rendered_colors = []
    for i in range(rays_o.shape[0]):
        # Render each ray
        # Note: k_samples affects the variance of the gradient estimate during training.
        # Source uses k=32 for training.
        color = render_ray(rays_o[i], rays_d[i], t_near, t_far, 256, network, k_samples=32)
        rendered_colors.append(color)
        
    rendered_colors = torch.stack(rendered_colors)
    ground_truth = batch_images.reshape(-1, 3)
    
    # MSE Loss
    loss = F.mse_loss(rendered_colors, ground_truth)
    loss.backward()
    optimizer.step()
    
    return loss.item()
```

**Parameters:**
*   $\beta$ (Softplus temperature): 10 [S1, unofficial].
*   Grid knots: 256 [S1, unofficial].
*   Training batch: 64 images, 64 rays per image [S1, unofficial].
*   Training samples ($k$): 32 [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Variance:** The stochastic estimate variance prevents the model from finding the fine optimum, resulting in slightly worse quantitative results than NeRF without hierarchical sampling despite similar grid density [S1, unofficial].
*   **Inference Samples:** Noise artifacts are present in renders when the number of inference samples $k$ is low (e.g., $k=1, 2, 4$). Artifacts only disappear for $k \ge 8$ [S1, unofficial].
*   **Comparison to Hierarchical NeRF:** Unlike full NeRF which uses a second 'fine' network to re-weight output points, this model weights samples with uniform weights in the color estimate [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Rendering speed scales with the number of samples $k$. On an NVIDIA V100 GPU at 800x800 resolution, rendering time increases from 20.18s ($k=1$) to 25.74s ($k=64$) for the Lego scene [S1, unofficial].
*   **Memory Complexity:** Memory usage is relatively stable, ranging from 4.189 Gb ($k=1$) to 4.209 Gb ($k=64$) [S1, unofficial].
*   **Performance:** On the Lego scene (800x800, NVIDIA V100), the model with 32 samples achieved PSNR 30.72, SSIM 0.946, LPIPS 0.0801 [S1, unofficial]. Metrics saturate at approximately 16 samples [S1, unofficial].
*   **Strengths:** Slightly improves rendering time and memory footprint compared to the original NeRF implementation [S1, unofficial].
*   **Limitations:** Quantitative results are slightly worse than NeRF without hierarchical sampling due to the variance of the stochastic estimate [S1, unofficial].

## Background
This method is described in "Differentiable Rendering With Reparameterized Volume Sampling" [S1, unofficial]. It serves as a baseline comparison for hierarchical sampling methods, specifically evaluating the impact of the Softplus activation and importance-sampling reparameterization within the original NeRF framework [S1, unofficial].
