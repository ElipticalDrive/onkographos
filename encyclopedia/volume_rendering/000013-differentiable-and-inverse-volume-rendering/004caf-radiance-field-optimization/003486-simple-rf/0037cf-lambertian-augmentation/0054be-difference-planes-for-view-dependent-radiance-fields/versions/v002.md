# Difference Planes for View-Dependent Radiance Fields

Also called: Difference planes, Specular planes

## Overview
Difference Planes is a method for handling view-dependent information in radiance fields to mitigate the shape-radiance ambiguity, where high angular resolution of view-dependent colors leads to incorrect geometry [S1, unofficial]. It separates view-dependent and Lambertian components during training by associating a difference plane with each camera to capture deviations from the integrated Lambertian content of rays sent through the volume [S1, unofficial]. Unlike sibling methods that rely on explicit spherical harmonics or neural networks for view-dependence, this approach uses lightweight per-camera planes and optional non-stored voxel constraints to isolate specular highlights and view-dependent lighting, enabling reconstruction of scenes with highly specular components without explicit view-dependence handling [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of camera images (reference colors $r_i$), a voxel grid storing color ($c_j$) and density ($\sigma_j$) per cell, and a hierarchical shell of environment maps for foreground/background segmentation [S1, unofficial].
*   **Outputs:** Optimized voxel grid parameters (color, density) and difference plane values ($\alpha_{si}$) that minimize the reconstruction error [S1, unofficial].

**Data Structures**
1.  **Voxel Grid:** Stores color $c_j$ and density $\sigma_j$ for each voxel $j$ [S1, unofficial].
2.  **Difference Planes:** One plane per camera image, with identical resolution to the image [S1, unofficial]. Each plane stores one float value $\alpha_{si}$ per pixel $i$ [S1, unofficial].
3.  **Environment Maps:** A hierarchical shell surrounding the scene for segmentation [S1, unofficial].

**Parameters**
*   $\sigma_s$: A constant weight parameter that tunes how readily values are pushed into the specular planes [S1, unofficial]. Value: $0.002$ [S1, unofficial].
*   $\alpha_{si}$: The difference plane variable for pixel $i$ in camera $s$ [S1, unofficial]. Initialized to $0$ [S1, unofficial]. Grows during optimization if no acceptable solution is found using only Lambertian values [S1, unofficial].

**Formulas**
The volume rendering integrates color along a ray [S1, unofficial]:
$$ H = \sum_t T(t)(1 - e^{(-\sigma(t)\delta(t))})c(t) $$
where $T(t) = e^{(-\sum_{k}^{t} \sigma(t)\delta(t))}$ is accumulated throughput, $\sigma$ is density, $\delta$ is step distance, and $c$ is color [S1, unofficial].

The Lambertian part of the color accumulated from the ray traversing the volume through voxels $j$ is [S1, unofficial]:
$$ H_{di} = \sum_j e^{-V_j}(1.0 - e^{(-\sigma_j \delta_j)})c_j $$
where $V_j = \sum_{k=0}^{j-1} \sigma_k \delta_k$ [S1, unofficial].

The final accumulated color for a pixel is computed as [S1, unofficial]:
$$ \hat{H}_i = (1.0 - e^{(-\alpha_{si} \sigma_s)})(r_i - H_{di}) + H_{di} $$
where $r_i$ is the reference color and $\sigma_s$ is the constant weight [S1, unofficial].

The objective function to minimize is [S1, unofficial]:
$$ \hat{F} = 0.5 \sum_i \sum_{k=1}^3 (\hat{H}_{i,k} - r_{i,k})^2 $$
for all pixels $i$ and color channels $k$ [S1, unofficial].

**Algorithm Steps**
1.  **Initialize:** Set all difference plane values $\alpha_{si}$ to zero [S1, unofficial]. Initialize voxel grid color and density parameters [S1, unofficial].
2.  **Render Lambertian Component:** For each pixel $i$, traverse the ray through the voxel grid and compute the Lambertian accumulated color $H_{di}$ using the formula above [S1, unofficial].
3.  **Compute Final Color:** Calculate the final rendered color $\hat{H}_i$ using the difference plane value $\alpha_{si}$, the reference color $r_i$, and the Lambertian component $H_{di}$ [S1, unofficial].
4.  **Compute Loss:** Calculate the squared difference loss $\hat{F}$ between $\hat{H}_i$ and $r_i$ [S1, unofficial].
5.  **Compute Gradients:**
    *   For voxel colors $c_j$:
        $$ \frac{\partial F}{\partial c_j} = \sum_i (\hat{H}_i - r_i) \frac{\partial H_i}{\partial c_j} $$
        where
        $$ \frac{\partial H_i}{\partial c_j} = e^{(-\alpha_{si} \sigma_s)} \frac{\partial H_{di}}{\partial c_j} $$
        [S1, unofficial].
    *   For difference plane variables $\alpha_{si}$:
        $$ \frac{\partial H_i}{\partial \alpha_{si}} = -\sigma_s e^{(-\alpha_{si} \sigma_s)} (r_i - H_{di}) $$
        [S1, unofficial].
6.  **Update:** Update voxel parameters and difference plane values using gradient descent [S1, unofficial].
7.  **Non-Highlight Constraint (Optional):** If separation is difficult, compute a small view-dependent function per voxel to increase or decrease density per voxel to aid convergence [S1, unofficial]. These parameters are not stored [S1, unofficial].

**Pseudocode**
```python
import numpy as np

def compute_lambertian_and_grads(ray_voxels, step_size):
    """
    ray_voxels: list of dicts with keys 'sigma', 'c'
    step_size: float, delta for all steps
    Returns: H_di, grad_H_di_dc (list), grad_H_di_dsigma (list)
    """
    H_di = 0.0
    V_j = 0.0
    grad_H_di_dc = []
    grad_H_di_dsigma = []
    
    # Precompute future throughput for density gradients
    future_throughput = [0.0] * len(ray_voxels)
    acc = 0.0
    for j in range(len(ray_voxels) - 1, -1, -1):
        w_j = np.exp(-V_j) * (1.0 - np.exp(-ray_voxels[j]['sigma'] * step_size))
        acc += w_j * ray_voxels[j]['c']
        future_throughput[j] = acc
        V_j += ray_voxels[j]['sigma'] * step_size
        
    V_j = 0.0
    for j, v in enumerate(ray_voxels):
        sigma_j = v['sigma']
        c_j = v['c']
        delta_j = step_size
        
        w_j = np.exp(-V_j) * (1.0 - np.exp(-sigma_j * delta_j))
        H_di += w_j * c_j
        
        grad_H_di_dc.append(w_j)
        
        d_w_j_d_sigma = delta_j * np.exp(-V_j) * np.exp(-sigma_j * delta_j)
        grad_H_di_dsigma.append(c_j * d_w_j_d_sigma - delta_j * future_throughput[j])
        
        V_j += sigma_j * delta_j
        
    return H_di, grad_H_di_dc, grad_H_di_dsigma

def compute_difference_plane_color(H_di, r_i, alpha_si, sigma_s):
    return (1.0 - np.exp(-alpha_si * sigma_s)) * (r_i - H_di) + H_di

def compute_gradients(H_di, r_i, alpha_si, sigma_s, grad_H_di_dc, grad_H_di_dsigma):
    grad_alpha_si = -sigma_s * np.exp(-alpha_si * sigma_s) * (r_i - H_di)
    grad_c_j = np.exp(-alpha_si * sigma_s) * np.array(grad_H_di_dc)
    grad_sigma_j = np.exp(-alpha_si * sigma_s) * np.array(grad_H_di_dsigma)
    return grad_c_j, grad_sigma_j, grad_alpha_si

def optimize_step(voxel_grid, difference_planes, reference_images, rays, sigma_s, step_size, learning_rate):
    voxel_grads_sigma = {k: 0.0 for k in voxel_grid}
    voxel_grads_c = {k: 0.0 for k in voxel_grid}
    diff_plane_grads = {k: 0.0 for k in difference_planes}
    
    for cam_id, (ref_img, diff_plane, cam_rays) in enumerate(zip(reference_images, difference_planes, rays)):
        for pix_id, (ray_voxel_ids, r_i) in enumerate(zip(cam_rays, ref_img.flatten())):
            ray_data = [{'sigma': voxel_grid[v_id]['sigma'], 'c': voxel_grid[v_id]['c']} for v_id in ray_voxel_ids]
            
            H_di, grad_H_di_dc, grad_H_di_dsigma = compute_lambertian_and_grads(ray_data, step_size)
            alpha_si = diff_plane[pix_id]
            H_hat_i = compute_difference_plane_color(H_di, r_i, alpha_si, sigma_s)
            
            grad_c_j, grad_sigma_j, grad_alpha_si = compute_gradients(
                H_di, r_i, alpha_si, sigma_s, grad_H_di_dc, grad_H_di_dsigma
            )
            
            for idx, v_id in enumerate(ray_voxel_ids):
                voxel_grads_c[v_id] += grad_c_j[idx]
                voxel_grads_sigma[v_id] += grad_sigma_j[idx]
            diff_plane_grads[cam_id] += grad_alpha_si
            
    for v_id in voxel_grid:
        voxel_grid[v_id]['sigma'] -= learning_rate * voxel_grads_sigma[v_id]
        voxel_grid[v_id]['c'] -= learning_rate * voxel_grads_c[v_id]
    for cam_id in difference_planes:
        difference_planes[cam_id] -= learning_rate * diff_plane_grads[cam_id]
```

**Edge Cases and Pitfalls**
*   **Shape-Radiance Ambiguity:** If view-dependent colors are not separated, the geometry may become incorrect [S1, unofficial].
*   **Initialization:** $\alpha_{si}$ is initialized to zero [S1, unofficial]. If no acceptable solution is found with only Lambertian values, $\alpha_{si}$ grows [S1, unofficial].
*   **Non-Highlight Lighting:** For view-dependent lighting that does not behave like a highlight, a small view-dependent function per voxel is computed to aid convergence [S1, unofficial]. These parameters are not stored [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1, unofficial].
*   **Memory Complexity:** Adds one float value per pixel per camera for the difference planes [S1, unofficial]. The non-highlight view-dependent function parameters are not stored [S1, unofficial].
*   **Performance:** Small impact on performance and memory usage [S1, unofficial].
*   **Strengths:** Enables reconstruction of scenes with highly specular components without explicit handling of view-dependence such as Spherical Harmonics [S1, unofficial].
*   **Limitations:** Additional constraints are needed for NERF and other methods built on view-dependent radiance fields to work as an end-to-end pipeline for 3D reconstruction [S1, unofficial].
*   **When to use:** When dealing with scenes with highly specular components and shape-radiance ambiguity [S1, unofficial].
*   **When not to use:** Not given in the sources [S1, unofficial].

## Background
The method was proposed by Uffe Kjaerulff from Chalmers University of Technology, Gothenburg, Sweden [S1, unofficial]. It addresses the shape-radiance ambiguity in radiance fields, a problem where high angular resolution of view-dependent colors leads to incorrect geometry [S1, unofficial]. The method builds on previous work such as NERF, Plenoxels, DirectVoxGo, and PERF [S1, unofficial].
