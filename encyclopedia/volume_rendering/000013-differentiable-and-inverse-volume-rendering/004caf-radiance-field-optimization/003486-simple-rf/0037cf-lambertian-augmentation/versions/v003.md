# Lambertian Augmentation


## Overview
Lambertian Augmentation is a regularization technique within the Simple-RF framework that disables view-dependent radiance in the coarse NeRF to mitigate shape-radiance ambiguity and duplication artifacts [S1]. It addresses the problem where NeRF models with limited input images exploit view-dependent color variations to explain observed images, leading to incorrect geometry [S1]. By constraining an augmented, lower-capacity version of the model to output Lambertian (view-independent) colors, it provides a simpler ground truth that guides the main model toward correct geometric structures [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D point coordinates $p_i$ and the hidden state $h_i$ from the coarse density network [S1].
*   **Output:** Density $\sigma_i$ and Lambertian color $c_i$ for the augmented model [S1].

**Data Structures:**
The method operates on two parallel network branches within the augmented model:
1.  **Density Network ($N_{1l}$):** Takes the positional encoding of $p_i$ as input [S1].
2.  **Color Network ($N_{2l}$):** Takes the hidden state $h_i$ from the density network as input [S1].

**Positional Encoding:**
The positional encoding $\gamma$ is applied to the point $p_i$ [S1]. For the Lambertian augmentation, the angular components are zeroed out [S1].
*   Standard encoding for main model (for context): $\gamma(p_i, l_{ps}, l_p)$ and $\gamma(v_i, 0, l_v)$ [S1].
*   Lambertian encoding for augmented model: $\gamma(p_i, 0, l_p)$ [S1]. This disables high-frequency angular components for the view direction, effectively removing view-dependence from the input representation [S1].

**Numbered Steps:**
1.  **Compute Density:** Pass the positionally encoded point $p_i$ (with zero angular frequency) through the coarse density network $N_{1l}$ to obtain density $\sigma_i$ and hidden state $h_i$:
    $$ \sigma_i, h_i = N_{1l}(\gamma(p_i, 0, l_p)) $$
    [S1]
2.  **Compute Lambertian Color:** Pass the hidden state $h_i$ through the color network $N_{2l}$ to obtain the color $c_i$ [S1]. Note that $h_i$ already incorporates low-frequency positional encoding of $p_i$ from the density network step [S1]:
    $$ c_i = N_{2l}(h_i) $$
    [S1]
3.  **Supervision:** The output $(\sigma_i, c_i)$ from the augmented model is used to supervise the main model [S1]. The main model retains full view-dependence, while the augmented model forces a Lambertian assumption [S1]. The exact regularization mechanism is not detailed in the provided excerpt [G].

**Parameters:**
*   $l_p$: Low-frequency positional encoding length for position [S1].
*   $l_{ps}$: High-frequency positional encoding length for position (used in main model, not augmented) [S1].
*   $l_v$: Angular frequency length (set to 0 in augmented model) [S1].
*   Typical values: Not given in the sources [S1].

**Edge Cases and Pitfalls:**
*   **Specular Objects:** The augmented model is more accurate in Lambertian regions, while the main model is better equipped to handle specular objects [S1].
*   **Precision:** The method assumes that disabling angular components in the positional encoding effectively removes view-dependence [S1]. Implementation must ensure that the hidden state $h_i$ does not inadvertently leak view-direction information from other parts of the network [G].

**Pseudocode:**
```python
import math

def positional_encoding(x, l_p):
    """Standard positional encoding [G]."""
    out = []
    for i in range(l_p):
        freq = 2.0 ** i
        out.append(math.sin(freq * x))
        out.append(math.cos(freq * x))
    return out

def lambertian_augmentation_forward(p_i, N1l, N2l, l_p):
    """
    Computes Lambertian color and density for the augmented model.
    
    Args:
        p_i: 3D point coordinates (3,)
        N1l: Density network (takes encoded position, returns sigma and hidden state)
        N2l: Color network (takes hidden state, returns color)
        l_p: Length of low-frequency positional encoding for position
        
    Returns:
        sigma_i: Density scalar
        c_i: Lambertian color vector (3,)
    """
    # Apply positional encoding with zero angular frequency for view direction
    encoded_p = positional_encoding(p_i, l_p=l_p)
    
    # Compute density and hidden state
    # N1l outputs (sigma, h)
    sigma_i, h_i = N1l(encoded_p)
    
    # Compute Lambertian color from hidden state
    # h_i already includes low-frequency positional encoding of p_i [S1]
    c_i = N2l(h_i)
    
    return sigma_i, c_i
```

## Subtopics

## Operating characteristics
*   **Time Complexity:** Adds minimal overhead as it involves a forward pass through a smaller or parallel network branch [G].
*   **Memory Complexity:** Requires storing parameters for the augmented density and color networks ($N_{1l}, N_{2l}$) [G].
*   **Strengths:** Effectively reduces shape-radiance ambiguity in sparse input scenarios by forcing the model to learn geometry that is consistent across viewpoints [S1].
*   **Limitations:** Does not explicitly handle view-dependent effects in the augmented model; relies on the main model to capture specularities [S1].
*   **When to use:** When training NeRFs with few input images where shape-radiance ambiguity is prominent [S1].

## Background
Lambertian Augmentation was introduced in the Simple-RF paper by Zhang et al. (2024) as a method to regularize sparse input radiance fields [S1]. It builds on the observation that NeRFs can exploit view-dependent color to explain away geometric errors when data is scarce [S1].
