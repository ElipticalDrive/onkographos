# Planar Reflection-Aware NeRF
Also called: Planar reflection-aware novel view synthesis

## Overview
Planar Reflection-Aware NeRF is a variant of Neural Radiance Fields that jointly models planar reflectors (e.g., windows) and explicitly casts reflected rays to capture the source of high-frequency reflections, preventing the creation of false geometry along the primary ray [S1]. It differs from standard NeRF by decomposing the reflection into a primary view and a reflected view, using sparse edge regularization to ensure the reflected color originates from the true scene geometry rather than duplicating artifacts at the reflection plane [S1].

## How it works
**Inputs:** Multi-view capture data (images and camera poses); detected planar reflectors (e.g., window planes) [S1].
**Outputs:** Optimized radiance field parameters, attenuation field parameters, and plane parameters [S1].

**Data Structures:**
1.  **Radiance Field:** A neural network (MLP) taking 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$ as input, outputting volumetric density $\sigma$ and color $\mathbf{c}$ [S1].
2.  **Attenuation Field:** A neural network (or function) taking ray parameters as input, outputting an attenuation factor $A(\mathbf{r}')$ [S1].
3.  **Plane Parameters:** Defined by a point on the plane and a normal vector, used to compute intersections and reflections [S1].

**Numbered Steps:**
1.  **Detection:** Detect potential planar reflectors in the scene [S1].
2.  **Primary Ray Sampling:** For each camera ray $\mathbf{r}=(\mathbf{o}, \mathbf{d})$, sample 3D points and their viewing directions [S1].
3.  **Primary Query:** Query the radiance field at the sampled points to obtain volumetric density $\sigma$ and color $\mathbf{c}$ [S1].
4.  **Intersection:** Determine if the primary ray intersects a detected planar reflector at point $\mathbf{x}$ [S1].
5.  **Reflection Direction:** If an intersection occurs, compute the reflected ray direction $\mathbf{d}'$ using the law of reflection [S1].
6.  **Reflected Ray Casting:** Cast a reflected ray $\mathbf{r}'$ from the intersection point $\mathbf{x}$ with direction $\mathbf{d}'$ [S1].
7.  **Reflected Field Query:** Query the *same* radiance field along the reflected ray $\mathbf{r}'$ to obtain density and color [S1].
8.  **Reflected Rendering:** Perform volume rendering along $\mathbf{r}'$ to compute the reflected color $\mathbf{C}(\mathbf{r}')$ [S1].
9.  **Attenuation:** Query the attenuation field $A(\mathbf{r}')$ to model the Fresnel effect, account for HDR tonemapping, and absorb errors due to intensity clipping [S1].
10. **Composition:** Compute the final composited color $\mathbf{C}_{comp}(\mathbf{r})$ by adding the attenuated reflection to the primary color [S1]:
    $$
    \mathbf{C}_{comp}(\mathbf{r}) = \mathbf{C}(\mathbf{r}) + \mathbf{C}(\mathbf{r}') \cdot A(\mathbf{r}')
    $$
11. **Regularization:** Apply a sparse edge regularization loss $\mathcal{L}_{edge}$ between the primary color gradient $|\nabla \mathbf{C}(\mathbf{r})|$ and the reflected color gradient $||\nabla \mathbf{C}(\mathbf{r}')||$ to discourage false geometry [S1].
12. **Optimization:** Backpropagate the total loss (photometric and regularization) to update the radiance field, attenuation field, and plane parameters [S1].

**Formulas:**
*   **Law of Reflection:** The reflected direction $\mathbf{d}'$ is computed from the incident direction $\mathbf{d}$ and the plane normal $\mathbf{n}$ at intersection point $\mathbf{x}$ [S1]. The specific equation is referenced as Eq. (6) in the source, generally defined as $\mathbf{d}' = \mathbf{d} - 2(\mathbf{d} \cdot \mathbf{n})\mathbf{n}$ [G] (standard vector reflection formula).
*   **Composited Color:** $\mathbf{C}_{comp}(\mathbf{r}) = \mathbf{C}(\mathbf{r}) + \mathbf{C}(\mathbf{r}') A(\mathbf{r}')$ [S1].
*   **Edge Regularization:** $\mathcal{L}_{edge}$ is applied between $|\nabla \mathbf{C}(\mathbf{r})|$ and $||\nabla \mathbf{C}(\mathbf{r}')||$ [S1]. The exact mathematical form of the loss function (e.g., L1, L2, or correlation) is not specified in the provided text [S1].

**Parameters:**
*   **Plane Detection Threshold:** Not given in the sources [S1].
*   **Attenuation Field Capacity:** Not given in the sources [S1].
*   **Regularization Weight:** Not given in the sources [S1].

**Edge Cases and Pitfalls:**
*   **Intensity Clipping:** The attenuation field is explicitly introduced to absorb errors due to intensity clipping in the input data [S1].
*   **False Geometry:** Without edge regularization, the method may create duplicate geometry along the primary ray at the same depth as the reflection [S1].
*   **HDR Tonemapping:** The attenuation field accounts for HDR tonemapping artifacts [S1].

**Pseudocode:**
```python
def sample_ray(ray_o, ray_d, near, far, N):
    """Uniformly samples N points along the ray between near and far."""
    t = [near + i * (far - near) / (N - 1) for i in range(N)]
    pts = [(ray_o[0] + t[i]*ray_d[0], ray_o[1] + t[i]*ray_d[1], ray_o[2] + t[i]*ray_d[2]) for i in range(N)]
    dirs = [ray_d for _ in range(N)]
    return pts, dirs, t

def volume_render(sigmas, colors, t_vals):
    """Standard differentiable volume rendering (DVR)."""
    deltas = [t_vals[i+1] - t_vals[i] for i in range(len(t_vals)-1)] + [1e10]
    alpha = [1.0 - math.exp(-sigmas[i] * deltas[i]) for i in range(len(sigmas))]
    transmittance = [1.0]
    for i in range(len(alpha)-1):
        transmittance.append(transmittance[-1] * math.exp(-sigmas[i] * deltas[i]))
    color = sum(alpha[i] * transmittance[i] * colors[i] for i in range(len(alpha)))
    return color

def intersect_ray_plane(ray_o, ray_d, plane):
    """Returns intersection distance t, or float('inf') if no intersection."""
    denom = ray_d[0]*plane.normal[0] + ray_d[1]*plane.normal[1] + ray_d[2]*plane.normal[2]
    if abs(denom) < 1e-6:
        return float('inf')
    t = ((plane.point[0]-ray_o[0])*plane.normal[0] + (plane.point[1]-ray_o[1])*plane.normal[1] + (plane.point[2]-ray_o[2])*plane.normal[2]) / denom
    return t

def compute_gradient_magnitude(color_samples):
    """Computes gradient magnitude along the ray using finite differences."""
    grad = [math.sqrt(sum((color_samples[i][k] - color_samples[i-1][k])**2 for k in range(3))) for i in range(1, len(color_samples))]
    return grad

def edge_regularization_loss(grad_p, grad_r):
    """L1 loss between primary and reflected gradient magnitudes."""
    return sum(abs(grad_p[i] - grad_r[i]) for i in range(len(grad_p))) / len(grad_p)

def l1_loss(pred, target):
    """Standard L1 loss."""
    return sum(abs(pred[i] - target[i]) for i in range(len(pred))) / len(pred)

def planar_reflection_aware_nerf(ray_o, ray_d, planes, radiance_field, attenuation_field, near, far, N):
    """Renders a single ray with planar reflection awareness."""
    pts_p, dirs_p, t_p = sample_ray(ray_o, ray_d, near, far, N)
    sigmas_p, colors_p = radiance_field(pts_p, dirs_p)
    color_p = volume_render(sigmas_p, colors_p, t_p)
    
    min_t = float('inf')
    hit_pt, hit_n = None, None
    for plane in planes:
        t = intersect_ray_plane(ray_o, ray_d, plane)
        if 0 < t < min_t:
            min_t = t
            hit_pt = (ray_o[0]+t*ray_d[0], ray_o[1]+t*ray_d[1], ray_o[2]+t*ray_d[2])
            hit_n = plane.normal
            
    if hit_pt is not None:
        ref_d = (ray_d[0] - 2*(ray_d[0]*hit_n[0] + ray_d[1]*hit_n[1] + ray_d[2]*hit_n[2])*hit_n[0],
                 ray_d[1] - 2*(ray_d[0]*hit_n[0] + ray_d[1]*hit_n[1] + ray_d[2]*hit_n[2])*hit_n[1],
                 ray_d[2] - 2*(ray_d[0]*hit_n[0] + ray_d[1]*hit_n[1] + ray_d[2]*hit_n[2])*hit_n[2])
        pts_r, dirs_r, t_r = sample_ray(hit_pt, ref_d, near, far, N)
        sigmas_r, colors_r = radiance_field(pts_r, dirs_r)
        color_r = volume_render(sigmas_r, colors_r, t_r)
        att = attenuation_field(pts_r, dirs_r)
        comp_color = (color_p[0] + color_r[0]*att, color_p[1] + color_r[1]*att, color_p[2] + color_r[2]*att)
    else:
        comp_color = color_p
        
    return comp_color, color_p, color_r if hit_pt is not None else color_p
```

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1]. The method requires additional ray casting and volume rendering for reflected rays, increasing computational cost compared to standard NeRF [S1].
*   **Memory Complexity:** Not given in the sources [S1]. The method introduces an additional attenuation field and plane parameters [S1].
*   **Strengths:** Accurately reconstructs high-frequency planar reflections without creating false geometry; handles HDR tonemapping and intensity clipping errors via the attenuation field [S1].
*   **Limitations:** Requires detection of planar reflectors; computationally more expensive due to reflected ray casting [S1].
*   **When to use:** Scenes with significant planar reflections (e.g., windows, mirrors) where standard NeRF fails by duplicating geometry [S1].
*   **When not to use:** Scenes without planar reflectors or with complex non-planar reflections [S1].

## Background
Planar Reflection-Aware NeRF was introduced to address the limitation of standard NeRF in handling complex planar reflections, which are often interpreted as erroneous scene geometries [S1]. It builds on the differentiable volume rendering framework [44-radiance-field-optimization.md] and extends it with explicit reflection modeling [S1]. The method was proposed in "Planar Reflection-Aware Neural Radiance Fields" [S1].
