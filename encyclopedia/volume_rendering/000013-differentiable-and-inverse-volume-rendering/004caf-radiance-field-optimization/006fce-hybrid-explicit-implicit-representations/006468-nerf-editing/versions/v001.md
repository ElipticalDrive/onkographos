# NeRF-Editing

Also called: Geometry Editing of Neural Radiance Fields

## Overview
NeRF-Editing is a method that allows users to perform user-controlled shape deformation on the implicit representation of a scene (NeRF) and synthesizes novel view images of the edited scene without re-training the network [S1]. It is the first mesh-based shape deformation method, leveraging explicit representations for scene geometry edits and implicit representations for realistic rendering effects [S2]. Unlike EditingNeRF which is limited to color modification or removal of parts, and ObjectNeRF which only supports duplication, movement, or rotation, this method supports substantial shape deformation [S1].

## How it works
**Inputs:**
1.  A trained NeRF model (implicit representation) of a scene.
2.  Multi-view images used to train the NeRF.
3.  User-defined deformation constraints on an extracted explicit mesh.

**Outputs:**
1.  Rendered images of the edited scene from novel viewpoints.

**Data Structures:**
1.  **Triangular Mesh ($M_{tri}$):** An explicit surface representation extracted from the NeRF.
2.  **Tetrahedral Mesh ($M_{tet}$):** A volumetric proxy mesh wrapping around $M_{tri}$, used to propagate deformations into the surrounding space.
3.  **Deformation Field ($D(x)$):** A continuous vector field defined over the volume, derived from the discrete deformations of $M_{tet}$.

**Algorithm Steps:**

1.  **Extract Explicit Mesh:**
    Extract a triangular mesh representation ($M_{tri}$) from the trained NeRF. This is typically done using marching cubes on the predicted density field [S1, S2].

2.  **User-Driven Deformation:**
    Users apply intuitive deformations to $M_{tri}$ using classic mesh deformation methods, such as As-Rigid-As-Possible (ARAP) deformation [S2]. Let the deformed mesh be $M'_{tri}$.

3.  **Build Tetrahedral Proxy:**
    Construct a tetrahedral mesh ($M_{tet}$) that wraps around the original triangular mesh $M_{tri}$ [S1]. This mesh serves as a spatial proxy to propagate the surface deformation into the volume.

4.  **Propagate Deformation to Tetrahedral Mesh:**
    Drive the deformation of $M_{tet}$ based on the deformation of $M'_{tri}$. The vertices of $M_{tet}$ are displaced to reflect the geometric changes of the surface, creating a discrete deformation field [S1]. Let the deformed tetrahedral mesh be $M'_{tet}$.

5.  **Interpolate to Continuous Deformation Field:**
    Use tetrahedral vertex interpolation to transform the discrete deformation field from $M'_{tet}$ into a continuous deformation field $D(x)$ defined for any point $x$ in 3D space [S1, S2].
    *   For a query point $x$ inside a tetrahedron $T$ with vertices $v_i$ and deformation vectors $d_i$, the deformation $D(x)$ is computed by interpolating $d_i$ using the barycentric coordinates of $x$ within $T$ [S1].
    *   Points outside $M_{tet}$ are assumed to have zero deformation [G].

6.  **Ray Bending:**
    During rendering, for each camera ray, the path is bent according to the continuous deformation field $D(x)$ [S1].
    *   Instead of sampling points along a straight line, the ray is perturbed. If a ray passes through a region covered by $M_{tet}$, the sampling positions are displaced by $D(x)$ [S1].
    *   This ensures that the implicit NeRF is queried at locations corresponding to the deformed geometry, effectively "bending" the ray to match the user's edit [S1].

7.  **Rendering:**
    Perform standard volume rendering integration along the bent rays. The NeRF decoder predicts density $\sigma$ and color $c$ at the sampled points, and the final color is computed via alpha compositing [S1, G].

**Pseudocode:**

```python
def nerf_editing_render(ray_origin, ray_direction, nerf_model, tet_mesh, deformation_field_func):
    """
    Renders a single ray for the edited scene.
    
    Args:
        ray_origin: 3D vector, origin of the camera ray.
        ray_direction: 3D vector, direction of the camera ray.
        nerf_model: Function or object that queries NeRF for (sigma, color) at a point.
        tet_mesh: Data structure representing the tetrahedral proxy mesh.
        deformation_field_func: Function that returns deformation vector D(x) for any point x.
        
    Returns:
        color: 3D vector, the final rendered color.
    """
    # Standard ray marching parameters
    t_min = 0.1
    t_max = 10.0
    num_samples = 128
    t_vals = linspace(t_min, t_max, num_samples)
    
    # Initial straight-line sampling points
    points = ray_origin + outer_product(t_vals, ray_direction)
    
    # Step 1: Calculate deformation field at sampling points
    # The deformation field D(x) is derived from the tetrahedral mesh interpolation
    deformations = zeros_like(points)
    for i, p in enumerate(points):
        # Check if point is inside the tetrahedral mesh volume
        if is_inside_tet_mesh(p, tet_mesh):
            # Interpolate deformation from tetrahedral vertices
            deformations[i] = deformation_field_func(p, tet_mesh)
        else:
            deformations[i] = [0, 0, 0]
            
    # Step 2: Bend the ray by applying deformation to sampling positions
    bent_points = points + deformations
    
    # Step 3: Query NeRF at bent positions
    sigmas = []
    colors = []
    for p in bent_points:
        sigma, c = nerf_model(p)
        sigmas.append(sigma)
        colors.append(c)
        
    # Step 4: Standard Volume Rendering (Alpha Compositing)
    # Calculate transmittance
    alphas = 1.0 - exp(-sigmas * (t_vals[1] - t_vals[0])) # Assuming uniform spacing for simplicity
    transmittance = exp(-cumsum(sigmas) * (t_vals[1] - t_vals[0]))
    
    # Composite colors
    weights = alphas * transmittance
    color = sum(weights * colors)
    
    return color
```

**Parameters:**
*   **Deformation Method:** ARAP (As-Rigid-As-Possible) is used for the initial mesh deformation [S2].
*   **Interpolation:** Tetrahedral vertex interpolation (barycentric interpolation) is used to create the continuous field [S1].

**Edge Cases and Pitfalls:**
*   **Artifacts from Direct Interpolation:** Directly transferring deformation from the surface mesh to the implicit volume by simple interpolation (without the tetrahedral proxy) leads to obvious artifacts [S1]. The two-step strategy using a tetrahedral proxy is necessary to avoid these [S1].
*   **Boundary Handling:** Points outside the tetrahedral mesh volume are assumed to have zero deformation [G]. This must be handled explicitly to prevent undefined behavior.
*   **Precision:** The quality of the continuous deformation field depends on the resolution of the tetrahedral mesh. Coarse tetrahedral meshes may result in blocky or inaccurate deformations [G].

## Operating characteristics
*   **Time Complexity:** The method requires no network re-training, making the editing phase fast. The rendering phase involves an additional interpolation step for the deformation field, adding minor overhead to standard NeRF rendering [S1].
*   **Memory Complexity:** Requires storing the tetrahedral mesh and the deformation field data, which is additional to the NeRF model [S1].
*   **Strengths:** Supports substantial shape deformation (not just color or rigid transforms); works on arbitrary shapes (animals, man-made objects), not limited to humans [S1]. Intuitive user control via mesh editing [S2].
*   **Limitations:** Requires an initial mesh extraction step, which can be noisy or incomplete for complex scenes [G]. The quality of deformation propagation depends on the tetrahedral mesh generation [S1].
*   **When to use:** When substantial geometric changes to a NeRF scene are required without re-training.
*   **When not to use:** When only color or texture edits are needed (EditingNeRF is simpler); when rigid body transforms are sufficient (ObjectNeRF is simpler).

## Background
NeRF-Editing was proposed in 2022 [S1]. It is cited as the first mesh-based shape deformation method for NeRFs [S2]. It addresses the limitation of prior editing methods that were restricted to color modification, part removal, or rigid transformations (translation, rotation, scaling) [S1]. The method establishes a correspondence between an extracted explicit mesh and the implicit neural representation, allowing users to leverage well-developed mesh-based deformation tools [S1]. It is applicable to arbitrary shapes, including animal models and general man-made objects [S1].
