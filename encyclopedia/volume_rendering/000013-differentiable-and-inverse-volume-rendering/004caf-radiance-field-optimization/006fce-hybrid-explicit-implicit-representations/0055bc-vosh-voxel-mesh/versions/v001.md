# Vosh (VOxel-meSH)
Also called: Voxel-Mesh Hybrid Representation, Voxel-Mesh Hybrid Representation for Real-Time View Synthesis

## Overview
Vosh is a hybrid neural rendering representation that combines a voxel grid and a textured mesh to achieve real-time view synthesis on mobile devices [S1, unofficial]. It solves the trade-off between the high-quality rendering of complex geometry in voxels and the fast rendering speed of simple geometry in meshes by strategically converting portions of the volumetric density field into a mesh surface [S1, unofficial]. Unlike VMesh, which relies on Signed Distance Functions (SDF) and requires manual tuning of loss weights, Vosh uses only the implicit volumetric density field, avoiding low-quality reconstruction in complex backgrounds and eliminating scene-specific hyper-parameters [S1, unofficial].

## How it works
**Inputs:** A set of multi-view images of the target scene.
**Outputs:** A hybrid representation consisting of a sparse voxel grid and a textured mesh, exported as assets for WebGL rendering [S1, unofficial].

**Data Structures:**
1.  **Voxel Grid:** A 3D grid storing neural radiance field values (density and color) for volumetric regions. The grid is pruned during optimization to retain only relevant voxels [S1, unofficial].
2.  **Textured Mesh:** A triangular mesh representing surfaces where the rendering quality of the voxel grid is sufficient to be approximated by a surface. It stores vertex positions, connectivity, and texture coordinates [S1, unofficial].
3.  **Hybrid Ratio:** A flexible parameter controlling the balance between voxel and mesh components, allowing users to adjust the trade-off between rendering quality and speed [S1, unofficial].

**Training Procedure:**
The training phase consists of three stages [S1, unofficial]:

1.  **Grid Training for Initial Voxels:**
    Train a voxel grid model through volume rendering using the set of multi-view images. This establishes the initial implicit volumetric density field [S1, unofficial].

2.  **Meshing Density Field:**
    Determine the region of meshing in the density field based on the difference in rendering quality between the voxel grid and the potential surfaces it contains. Regions where the voxel grid's rendering quality is high (implying a well-defined surface) are converted into a mesh. This converts the initial voxel grid into a combination of voxel and mesh components [S1, unofficial].

3.  **Optimization:**
    Optimize the voxels and mesh through a training process involving hybrid rendering and voxel pruning. This refines the final hybrid representation [S1, unofficial].

**Inference Phase:**
Real-time hybrid rendering is implemented based on WebGL to enable view synthesis on mobile devices. The renderer combines rasterization of the textured mesh with volume rendering of the sparse voxels [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Complex Backgrounds:** Using SDF (as in VMesh) can lead to low-quality reconstruction in cluttered backgrounds [S1, unofficial]. Vosh avoids this by using only the density field.
*   **Mobile Constraints:** Unlike 3D Gaussian Splatting (3DGS), which relies on CUDA-specific APIs and has high memory usage, Vosh is designed to run on mobile devices without these constraints [S1, unofficial].

## Background
Vosh was proposed in the paper "Voxel-Mesh Hybrid Representation for Real-Time View Synthesis" [S1, unofficial]. The authors aim to address the limitations of using voxels or meshes individually in neural radiance fields, where voxels excel in quality but are slow, and meshes are fast but lack quality for complex scenes [S1, unofficial]. The method is compared against VMesh and 3D Gaussian Splatting (3DGS) [S1, unofficial].
