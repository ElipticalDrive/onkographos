# Hybrid Multi-Space Module

Also called: Hybrid MS Module, MS module for grid-based methods, MS-NeRF Hybrid MS Module, MS-TensoRF, MS-iNGP, multi-space iNGP

## Overview
The Hybrid Multi-Space Module extends grid-based Neural Radiance Field (NeRF) methods to handle scenes with complex light paths, such as reflections and refractions, by decomposing the rendering process into multiple sub-spaces [S1]. Unlike pure feature-field approaches that are incompatible with high-performance grid structures, this module integrates a small "Gate" MLP to compute composition weights while using multiple radiance fields (density and color) within the explicit grid backbone [S1]. It sets itself apart from siblings like [Hybrid Representation](7846-hybrid-representation.md) by explicitly modeling $K$ distinct radiance fields for sub-spaces rather than just feature fields, enabling accurate rendering of virtual images and refractive surfaces in grid-based frameworks like iNGP and TensoRF [S1].

## How it works
The method modifies the standard grid-based NeRF pipeline by introducing a parallel "Gate" MLP branch and expanding the output layer to support $K$ sub-spaces [S1].

**Inputs and Outputs:**
*   **Inputs:** Sampled 3D points $\{p_i\}$ along a ray, ray direction $d$, explicit grid parameters $V$ (from the parent [Hybrid Explicit-Implicit Representations](12240-hybrid-explicit-implicit-representations.md)), and positional encoding $\gamma(p_i)$ [S1].
*   **Outputs:** Final rendered color $C$ and optional per-sub-space color maps $\{C_k\}$ [S1].

**Data Structures:**
1.  **Explicit Grid ($V$):** Inherits the layout from the parent method (e.g., hash table or voxel grid) storing feature vectors [G].
2.  **Gate MLP ($\Theta_G$):** A small Multi-Layer Perceptron with parameters $\Theta_G$ [S1].
    *   Input dimension: Dimension of positional encoding $\gamma(p)$ [G].
    *   Hidden layer dimension: $h$ [S1].
    *   Output dimension: $d$ (feature vector size for gating) [S1].
3.  **Radiance Fields Branch:** The main grid-based NeRF backbone [S1].
    *   Output: For each sub-space $k \in \{1, \dots, K\}$, outputs density $\sigma_{ik}$ and color $c_{ik}$ for point $p_i$ [S1].

**Parameters:**
*   $K$: Total number of sub-spaces. Typical value: 4 [S1].
*   $d$: Dimension of output features for the Gate MLP. Typical value: 8 [S1].
*   $h$: Hidden layer dimension of the Gate MLP. Typical value: 32 [S1].
*   $\gamma(\cdot)$: Positional encoding function (as defined in standard NeRF literature, e.g., [S1] Eq. 1) [G].

**Algorithm Steps:**
1.  **Initialize Gate MLP:** Construct a small MLP $\Theta_G$ with hidden dimension $h$ and output dimension $d$, initializing it similarly to the main branch's MLP but with smaller capacity [S1].
2.  **Query Gate Features:** For each sampled point $p_i$ and view direction $d$, compute positional encoding $\gamma(p_i)$ [G]. Pass $\gamma(p_i)$ and $d$ through $\Theta_G$ to obtain a feature vector $f_i \in \mathbb{R}^d$ [S1]. One feature vector is recorded per position due to model capacity constraints [S1].
3.  **Query Radiance Fields:** For each sampled point $p_i$ and view direction $d$, retrieve the base feature vector $v_{p_i}$ from the explicit grid $V$ using query function $Q(V, p_i)$ [G]. Pass $v_{p_i}$ and $d$ through the main radiance field decoder to predict $K$ pairs of density and color: $\{(\sigma_{i1}, c_{i1}), \dots, (\sigma_{iK}, c_{iK})\}$ [S1].
4.  **Multi-Space Integration (Color Maps):** Perform volumetric rendering along the ray for each sub-space $k$ independently [S1]. Use the densities $\{\sigma_{ik}\}_i$ and colors $\{c_{ik}\}_i$ to compute transmittance and opacity [G]. Integrate to form $K$ color maps $\{C_k\}$ [S1]. *Formula:* $C_k = \sum_{i=1}^{N} T_{ik} (1 - e^{-\sigma_{ik} \delta_i}) c_{ik}$, where $T_{ik}$ is the accumulated transmittance up to point $i$ for sub-space $k$, and $\delta_i$ is the distance between samples [G].
5.  **Multi-Space Integration (Feature Maps):** Perform volumetric rendering using the Gate features $\{f_i\}$ and the sub-space densities $\{\sigma_{ik}\}_i$ [S1]. Compute $K$ feature maps $\{F_k\}$ for each sub-space [S1]. *Formula:* $F_k = \sum_{i=1}^{N} T_{ik} (1 - e^{-\sigma_{ik} \delta_i}) f_i$ [S1].
6.  **Decode Composition Weights:** Decode the pixel-wise composition weight map $\{w_k\}$ from the feature maps $\{F_k\}$ [S1]. *Formula:* $w_k = \text{Softmax}(\text{Reduce}(F_k))$, where $\text{Reduce}$ projects the $d$-dimensional feature map to a scalar (e.g., linear projection or sum) [G].
7.  **Compose Final Output:** Combine the $K$ color maps $\{C_k\}$ using the decoded weights $\{w_k\}$ [S1]. *Formula:* $C = \sum_{k=1}^{K} w_k C_k$ [S1].

**Pseudocode:**

```python
def hybrid_multi_space_render(ray_origin, ray_direction, grid_V, gate_mlp, radiance_decoder, K, d, h, t_near, t_far, N_samples):
    """
    Renders a single ray using the Hybrid Multi-Space Module.
    
    Args:
        ray_origin: (3,) float32, origin of the ray.
        ray_direction: (3,) float32, normalized direction of the ray.
        grid_V: Explicit feature storage (e.g., HashGrid or VoxelGrid).
        gate_mlp: Small MLP with hidden dim h, output dim d.
        radiance_decoder: Main decoder mapping grid features + direction to K (sigma, color) pairs.
        K: Number of sub-spaces.
        d: Output dimension of gate_mlp.
        h: Hidden dimension of gate_mlp.
        t_near, t_far: Ray bounds.
        N_samples: Number of samples per ray.
        
    Returns:
        final_color: (3,) float32, rendered color.
    """
    # 1. Sample points along the ray
    t_vals = t_near + (t_far - t_near) * np.arange(N_samples) / N_samples
    points = ray_origin + ray_direction * t_vals[:, np.newaxis]
    deltas = (t_far - t_near) / N_samples

    # 2. Compute Gate Features
    gamma_points = positional_encoding(points)
    directions = np.broadcast_to(ray_direction, (N_samples, 3))
    gate_input = np.concatenate([gamma_points, directions], axis=-1)
    gate_features = gate_mlp(gate_input) # Shape: (N_samples, d)

    # 3. Query Radiance Fields for K sub-spaces
    grid_features = grid_V.query(points)
    sigmas, colors = radiance_decoder(grid_features, ray_direction) # sigmas: (N, K), colors: (N, K, 3)

    # 4. Multi-Space Integration
    color_maps = np.zeros((K, 3))
    feature_maps = np.zeros((K, d))

    for k in range(K):
        sigma_k = sigmas[:, k]
        color_k = colors[:, k, :]
        alpha_k = 1.0 - np.exp(-sigma_k * deltas)
        transmittance_k = np.ones(N_samples)
        transmittance_k[1:] = np.cumprod(1.0 - alpha_k[:-1])
        sample_weights = transmittance_k * alpha_k

        color_maps[k] += np.sum(sample_weights[:, np.newaxis] * color_k, axis=0)
        feature_maps[k] += np.sum(sample_weights[:, np.newaxis] * gate_features, axis=0)

    # 5. Decode Composition Weights
    scalar_features = np.sum(feature_maps, axis=1)
    weights = softmax(scalar_features)

    # 6. Compose Final Result
    final_color = np.sum(weights[:, np.newaxis] * color_maps, axis=0)
    return final_color

def positional_encoding(points, num_frequencies=10):
    # Standard NeRF positional encoding
    scales = np.array([2**i for i in range(num_frequencies)])
    scaled_points = np.einsum('ij,k->ikj', points, scales)
    scaled_points = np.reshape(scaled_points, (scaled_points.shape[0], -1))
    return np.concatenate([np.sin(scaled_points), np.cos(scaled_points)], axis=-1)

def softmax(x):
    e_x = np.exp(x - np.max(x))
    return e_x / e_x.sum(axis=0)
```

**Edge Cases and Pitfalls:**
*   **Precision:** Grid-based feature retrieval assumes continuous variation; sharp discontinuities in sub-space boundaries may require higher grid resolution or specialized handling [G].
*   **Boundaries:** Points outside the defined storage domain must be handled (e.g., clamping or zero-padding) as per the parent method's requirements [G].
*   **Degenerate Input:** Empty regions in the scene may result in sparse feature storage, requiring efficient sparse data structures or padding strategies [S1].
*   **Weight Decoding:** The exact reduction of feature maps $F_k$ (size $d$) to scalar weights $w_k$ is not explicitly defined in the source text, only that they are "decoded" [S1]. Implementation requires a choice (e.g., linear projection or sum) [G].

## Subtopics

### MS-iNGP
An implementation of the Hybrid Multi-Space Module integrated with Instant Neural Graphics Primitives (iNGP) [S1]. It uses the iNGP hash grid and proposal estimator [S1]. Choose when rendering unbounded scenes with reflections/refractions requiring fast convergence [S1].

### MS-TensoRF
An implementation of the Hybrid Multi-Space Module integrated with Tensor Decomposition-based NeRF (TensoRF) [S1]. It uses 2D/3D tensor grids [S1]. Choose when rendering bounded scenes with complex light paths where memory efficiency of tensor decomposition is prioritized [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** On the MS-TensoRF-grid ablation, the method achieved PSNR 32.07 and SSIM 0.932 [S1]. In Mip-NeRF 360-based experiments, it showed a 4.15 dB PSNR improvement over baselines with minimal extra cost [S1].
*   **Strengths:** Compatible with high-performance grid-based methods (iNGP, TensoRF); handles reflections and refractions effectively; small Gate MLP keeps parameter count low [S1].
*   **Limitations:** Requires tuning of $K, d, h$; performance depends on the underlying grid's ability to resolve sub-space boundaries [S1].
*   **When to use:** Scenes with complex light paths (mirrors, glass) where grid-based methods are preferred for speed/memory [S1].
*   **When not to use:** Simple scenes without multi-space effects, where standard grid-based NeRF suffices [G].

## Background
The Hybrid Multi-Space Module was introduced in "MS-NeRF: Multi-Space Neural Radiance Fields" [S1]. It addresses the limitation of previous multi-space modules that relied on MLP-based feature fields, which are not compatible with the high-performance grid-based representations (like iNGP and TensoRF) that dominate modern NeRF optimization [S1]. By decomposing the multi-space composition information into a small MLP branch (Gate) and modeling the sub-spaces using multiple radiance fields within the grid, it enables efficient rendering of reflective and refractive surfaces in grid-based frameworks [S1].
