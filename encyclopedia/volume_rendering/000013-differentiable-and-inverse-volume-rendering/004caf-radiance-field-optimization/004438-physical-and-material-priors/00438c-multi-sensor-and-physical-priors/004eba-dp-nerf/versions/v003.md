# DP-NeRF

Also called: Deblurred Neural Radiance Field with Physical Scene Priors, Rigid Blur Kernel (RBK) & SE(3) Fields

## Overview
DP-NeRF is a framework for reconstructing clean 3D scenes from blurred input images (camera motion blur and defocus blur) by imposing two physical priors derived from the image acquisition process [S1]. It differs from prior methods like Deblur-NeRF by using 3D physical priors instead of 2D pixel-wise independent ray optimization, ensuring geometric and appearance consistency across views [S1]. Unlike Deblur-NeRF, which predicts a single blurred color, DP-NeRF employs two blurred color predictions to enable a coarse-to-fine optimization strategy [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of blurred RGB images $B_{sp}$ with known camera poses (calibrated via COLMAP) [S1].
*   **Outputs:** A trained "sharp" NeRF model capable of rendering clean novel views [S1].

**Data Structures:**
The method relies on the standard NeRF representation (MLPs for density $\sigma$ and color $\mathbf{c}$) augmented with two specific modules:
1.  **Rigid Blurring Kernel (RBK):**
    *   **Encoding Branch ($E$):** MLP with 4 fully-connected linear layers, each 64 dimensions, ReLU activation [S1].
    *   **Decoding Branches ($W, R, L$):** Each consists of one linear layer with 32 dimensions and an output linear layer [S1].
    *   **Outputs:**
        *   $m_s$: Motion weights, channel dimension $k$ (hyper-parameter controlling the number of rigid camera motions) [S1]. Normalized such that $\sum_{i=0}^{k} m_{s,i} = 1$ [S1].
        *   $r_s$: Rigid motion parameters, channel dimension $3k$ [S1].
        *   $v_s$: View-specific parameters, channel dimension $3k$ [S1].
    *   **Input:** View information $l_s$ embedded with 64 channels [S1].
2.  **Adaptive Weight Proposal (AWP):**
    *   Uses Feature Modulation (FM) and a Motion Feature Aggregation Module (MAM) [S1].
    *   **Inputs:** Depth features of samples for transformed rays, viewing direction, and view information [S1].
    *   **Outputs:** Refined composition weights $\tilde{m}_q$ for each pixel [S1].

**Numbered Steps:**

1.  **Coarse Scene Initialization:** Train a pure NeRF for 1200 iterations to obtain a coarse scene representation [S1].
2.  **RBK Processing:**
    *   For each view, embed view information $l_s$ into 64 dimensions [S1].
    *   Pass $l_s$ through Encoding Branch $E$ [S1].
    *   Pass the encoded features through Decoding Branches $W, R, L$ to generate $m_s, r_s, v_s$ [S1].
    *   Predict a scene-wise screw axis $S_q \in \mathbb{R}^6$ via MLP $T_\Psi(l_s)$, decompose it into rotation axis $r_q$ and angle $v_q$, and convert them to rotation matrix $e_{r_q}$ and translation matrix $p_q$ using Rodrigues' formula [S2].
    *   Transform ray $r$ to $r_q = e_{r_q} r + p_q$ [S2].
    *   Compute a coarse blurred color prediction $\hat{B}_{sp}$ using the deformation field and the NeRF samples [S1].
3.  **AWP Processing:**
    *   For each ray, compute depth features for the transformed samples [S1].
    *   Aggregate motion features using MAM based on depth features, viewing direction, and view information [S1].
    *   Refine the composition weights using Feature Modulation [S1].
    *   Compute a fine blurred color prediction $\tilde{B}_{sp}$ [S1].
4.  **Loss Calculation:**
    *   Compute the coarse reconstruction loss $L_c = ||B_{sp} - \hat{B}_{sp}||$ and fine reconstruction loss $L_f = ||B_{sp} - \tilde{B}_{sp}||$ [S1].
    *   Calculate the exponential decay weight $\lambda$ for the current iteration $e_c$:
        $$ \alpha = -\log(\lambda_s / \lambda_e) / (e_f - e_i) $$
        $$ \lambda = \lambda_s \exp(\alpha(e_c - e_i)) $$
        where $e_i$ is the initial iteration (1200), $e_f$ is the final iteration (200,000), $\lambda_s = 0.9$, and $\lambda_e = 0.1$ [S1].
    *   Compute the final loss:
        $$ L_{final} = \lambda L_c + (1 - \lambda) L_f $$
        [S1].
5.  **Joint Optimization:**
    *   Optimize the RBK, AWP, and the sharp NeRF parameters jointly using the Adam optimizer [S1].
    *   Use only the reconstruction loss from the blurred input as supervision [S1].
    *   Train for 200,000 iterations total [S1].
6.  **Inference:**
    *   Render clean novel views using only the trained sharp NeRF model, ignoring the RBK and AWP modules [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def rodrigues(axis, angle):
    """Convert rotation axis and angle to rotation matrix using Rodrigues' formula [G]."""
    axis = F.normalize(axis, dim=-1)
    c = torch.cos(angle)
    s = torch.sin(angle)
    t = 1 - c
    x, y, z = axis[..., 0:1], axis[..., 1:2], axis[..., 2:3]
    R = torch.zeros_like(axis).expand(-1, -1, 3)
    R[..., 0, 0] = t * x**2 + c
    R[..., 0, 1] = t * x * y - s * z
    R[..., 0, 2] = t * x * z + s * y
    R[..., 1, 0] = t * x * y + s * z
    R[..., 1, 1] = t * y**2 + c
    R[..., 1, 2] = t * y * z - s * x
    R[..., 2, 0] = t * x * z - s * y
    R[..., 2, 1] = t * y * z + s * x
    R[..., 2, 2] = t * z**2 + c
    return R

class RBK(nn.Module):
    def __init__(self, k):
        super().__init__()
        self.k = k
        self.enc = nn.Sequential(
            nn.Linear(64, 64), nn.ReLU(),
            nn.Linear(64, 64), nn.ReLU(),
            nn.Linear(64, 64), nn.ReLU(),
            nn.Linear(64, 64), nn.ReLU()
        )
        self.W = nn.Sequential(nn.Linear(64, 32), nn.Linear(32, k))
        self.R = nn.Sequential(nn.Linear(64, 32), nn.Linear(32, 3 * k))
        self.L = nn.Sequential(nn.Linear(64, 32), nn.Linear(32, 3 * k))

    def forward(self, l_s):
        h = self.enc(l_s)
        m_s = self.W(h)
        r_s = self.R(h)
        v_s = self.L(h)
        m_s = F.softmax(m_s, dim=-1)
        return m_s, r_s, v_s

class AWP(nn.Module):
    def __init__(self):
        super().__init__()
        self.mam = nn.Linear(64 + 3 + 64, 32)
        self.fm = nn.Linear(32, 1)

    def forward(self, depth_features, view_dir, view_info):
        feat = torch.cat([depth_features, view_dir, view_info], dim=-1)
        motion_feat = self.mam(feat)
        weights = torch.sigmoid(self.fm(motion_feat))
        return weights

class DPNeRF:
    def __init__(self, k=10, n_coarse=64, n_fine=64):
        self.k = k
        self.n_coarse = n_coarse
        self.n_fine = n_fine
        self.neural_nerf = nn.Sequential(
            nn.Linear(3, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 128), nn.ReLU(),
            nn.Linear(128, 4)  # [sigma, r, g, b]
        )
        self.rbk = RBK(k)
        self.awp = AWP()
        self.lambda_s = 0.9
        self.lambda_e = 0.1
        self.e_i = 1200
        self.e_f = 200000

    def volume_render(self, sigma, c, t_vals):
        """Standard volume rendering equation [G]."""
        dists = t_vals[..., 1:] - t_vals[..., :-1]
        alpha = 1.0 - torch.exp(-sigma * dists)
        trans = torch.cumsum(alpha[..., :-1], dim=-1)
        weights = alpha * (1.0 - trans + 1e-10)
        color = torch.sum(weights.unsqueeze(-1) * c, dim=-2)
        return color

    def apply_rigid_motion(self, ray_o, ray_d, r_s, v_s, m_s):
        """Apply SE(3) transformation to rays using Rodrigues' formula [S2]."""
        # r_s: [B, 3k], v_s: [B, 3k], m_s: [B, k]
        # Reshape for batch processing
        r_s = r_s.view(-1, self.k, 3)
        v_s = v_s.view(-1, self.k, 3)
        m_s = m_s.view(-1, self.k, 1)
        
        # Normalize angles to [0, pi] for Rodrigues
        angles = torch.norm(v_s, dim=-1, keepdim=True)
        axes = v_s / (angles + 1e-8)
        R_q = rodrigues(axes, angles)
        T_q = r_s  # Translation component
        
        # Transform ray origins and directions
        ray_o_deformed = torch.einsum('bki,bn->bnki', R_q, ray_o) + T_q.unsqueeze(1)
        ray_d_deformed = torch.einsum('bki,bn->bnki', R_q, ray_d)
        
        # Weighted composition of deformed rays
        m_s = m_s.unsqueeze(1)
        ray_o_final = torch.sum(m_s * ray_o_deformed, dim=2)
        ray_d_final = torch.sum(m_s * ray_d_deformed, dim=2)
        return ray_o_final, ray_d_final

    def compute_blurred_color(self, ray_o, ray_d, t_near, t_far, view_info):
        t_vals = torch.linspace(t_near, t_far, self.n_coarse + self.n_fine)
        xyz = ray_o.unsqueeze(0) + ray_d.unsqueeze(0) * t_vals.unsqueeze(1)
        
        # Standard NeRF forward pass
        out = self.neural_nerf(xyz.view(-1, 3))
        sigma = torch.relu(out[..., :1]).view(xyz.shape[:-1])
        c = torch.sigmoid(out[..., 1:4]).view(xyz.shape[:-1], 3)
        
        # RBK: Coarse prediction
        m_s, r_s, v_s = self.rbk(view_info)
        ray_o_deform, ray_d_deform = self.apply_rigid_motion(ray_o, ray_d, r_s, v_s, m_s)
        xyz_deform = ray_o_deform.unsqueeze(0) + ray_d_deform.unsqueeze(0) * t_vals.unsqueeze(1)
        out_deform = self.neural_nerf(xyz_deform.view(-1, 3))
        sigma_deform = torch.relu(out_deform[..., :1]).view(xyz_deform.shape[:-1])
        c_deform = torch.sigmoid(out_deform[..., 1:4]).view(xyz_deform.shape[:-1], 3)
        B_hat = self.volume_render(sigma_deform, c_deform, t_vals)
        
        # AWP: Fine prediction
        depth_features = t_vals.unsqueeze(-1)  # Depth proxy [G]
        view_dir = ray_d.unsqueeze(0).expand_as(depth_features)
        weights = self.awp(depth_features, view_dir, view_info)
        B_tilde = self.volume_render(sigma, c, t_vals) * weights
        
        return B_hat, B_tilde

    def train_step(self, ray_o, ray_d, t_near, t_far, view_info, gt_blurred_rgb, current_iter):
        B_hat, B_tilde = self.compute_blurred_color(ray_o, ray_d, t_near, t_far, view_info)
        L_c = torch.norm(gt_blurred_rgb - B_hat)
        L_f = torch.norm(gt_blurred_rgb - B_tilde)
        
        alpha = -torch.log(torch.tensor(self.lambda_s / self.lambda_e)) / (self.e_f - self.e_i)
        lam = self.lambda_s * torch.exp(alpha * (current_iter - self.e_i))
        
        L_final = lam * L_c + (1 - lam) * L_f
        return L_final
```

**Parameters:**
*   $\lambda_s$: Initial weight for coarse-to-fine optimization, set to 0.9 [S1].
*   $\lambda_e$: Final weight for coarse-to-fine optimization, set to 0.1 [S1].
*   $k$: Hyper-parameter controlling the number of rigid camera motions in the RBK. Output channel dimensions for $m_s, r_s, v_s$ are $k, 3k, 3k$ respectively [S1].
*   $N_c, N_f$: Number of coarse and fine samples, set to 64 each [S1].
*   Learning Rate: Exponentially decays from $5 \times 10^{-4}$ to $8 \times 10^{-5}$ [S1].
*   Optimizer: Adam with default parameters [S1].
*   Image Resolution: Resized to $600 \times 400$ [S1].
*   Total Iterations: 200,000 [S1].
*   RBK Training Start: After 1200 iterations of pure NeRF training [S1].

**Edge Cases and Pitfalls:**
*   **Object Motion Blur:** The model assumes a static scene. It fails to reconstruct correct geometry for moving objects because it lacks multi-view data for a specific time instance [S1].
*   **Complex Depth/Textures:** The RBK alone may lose detail in regions with complex depth or similar textures; the AWP is required to refine these areas [S1].
*   **Depth Prior Inaccuracy:** Blur in each image makes predicted depth inaccurate and inconsistent across multiple views, hindering the usability of external depth priors [S2].

## Operating characteristics
*   **Time Complexity:** Training involves joint optimization of NeRF, RBK, and AWP. The coarse-to-fine strategy stabilizes training but adds computational overhead due to the two parallel prediction paths (RBK and AWP) per ray [S1].
*   **Memory Complexity:** Standard NeRF memory usage plus overhead for RBK and AWP parameters. The RBK parameters are view-dependent but not ray-dependent, keeping memory usage manageable compared to per-pixel kernel methods [S1].
*   **Performance:** DP-NeRF achieves significant improvements in PSNR, SSIM, and LPIPS over Naive NeRF and Deblur-NeRF on synthetic and real scenes with camera motion and defocus blur [S1].
*   **Strengths:** Ensures 3D geometric and appearance consistency by using 3D physical priors (RBK) instead of 2D pixel-wise optimization [S1]. Handles both camera motion and defocus blur [S1].
*   **Limitations:** Cannot handle object motion blur due to the static scene assumption [S1]. Requires calibrated camera poses (COLMAP) [S1].

## Background
DP-NeRF is a NeRF framework for reconstructing clean 3D scenes from blurred inputs [S1]. It was developed to address the limitations of previous deblurring NeRF methods, specifically Deblur-NeRF, which relied on 2D pixel-wise independent ray optimization that broke 3D consistency [S1]. The method builds on the standard NeRF framework and incorporates physical priors derived from the camera blurring process [S1]. It is used for novel view synthesis on synthetic and real scenes with blur [S1].
