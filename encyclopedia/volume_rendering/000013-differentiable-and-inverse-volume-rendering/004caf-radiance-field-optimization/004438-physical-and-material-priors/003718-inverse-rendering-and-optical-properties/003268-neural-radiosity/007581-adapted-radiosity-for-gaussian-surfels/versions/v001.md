# Adapted Radiosity for Gaussian Surfels


## Overview
Adapted Radiosity for Gaussian Surfels is a forward rendering technique that solves the rendering equation for Gaussian surfels by assuming constant emission and BRDF within each kernel, and constant outgoing radiance within a kernel to derive a weighted residual solution. It differs from [Neural Radiosity](6755-neural-radiosity.md) by using explicit geometric primitives (Gaussian surfels) rather than a single neural network to represent the radiance field, allowing for efficient direct illumination rendering and geometry reconstruction.

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ Gaussian surfels (kernels). Each kernel $j$ is defined by its center $\mathbf{t}_j$, normal $\mathbf{n}_j$, transparency factor $\alpha_j$, and material properties (diffuse albedo $a^d$, specular albedo $a^s$, specular exponent $s$, mixing factor $k$).
*   **Output:** The outgoing radiance $L_O(\mathbf{x}, \omega_O)$ for points $\mathbf{x}$ within each kernel $i$.

**Data Structures:**
*   **Kernel $j$:**
    *   $\mathbf{t}_j \in \mathbb{R}^3$: Center position.
    *   $\mathbf{n}_j \in \mathbb{R}^3$: Surface normal.
    *   $\alpha_j \in [0, 1]$: Transparency factor.
    *   $a^d \in [0, 1]$: Diffuse albedo.
    *   $a^s \in [0, 1]$: Specular albedo.
    *   $s \in \mathbb{R}$: Specular exponent.
    *   $k \in [0, 1]$: Mixing factor.
*   **Spherical Harmonics (SH):** Coefficients $c_{lm}$ for the BRDF expansion, up to degree 9.

**Formulas:**
The outgoing radiance $L_O(\mathbf{x}, \omega_O)$ for a point $\mathbf{x}$ in kernel $i$ is defined as [S1]:
$$ L_O(\mathbf{x}, \omega_O) = E_i(\omega_O) + \alpha_i(\mathbf{x}) \int_{\omega} f_i(\omega_I, \omega_O) L_I(\mathbf{x}, \omega_I) |\mathbf{n}_i \cdot \omega_I| d\omega_I $$
where $\Omega = \{\omega_I : \omega_I \cdot \mathbf{n}_i < 0\}$ is the visible hemisphere and $\alpha_i$ is the transparency factor.

The incoming radiance $L_I(\mathbf{x}, \omega_I)$ is expanded as a sum over all kernels $j$ [S1]:
$$ L_I(\mathbf{x}, \omega_I) = \sum_{j=1}^N L_O(\mathbf{t}_j, \omega_I) \alpha_j(\mathbf{t}_j) \prod_{k=1}^{j-1} (1 - \alpha_k(\mathbf{t}_k)) $$

By swapping the integral and summation, the outgoing radiance is computed as [S1]:
$$ L_O(\mathbf{x}, \omega_O) = E_i(\omega_O) + \alpha_i(\mathbf{x}) \sum_{j=1}^N \int_{P_j} f_i(\omega_I, \omega_O) L_O(\mathbf{t}_j, \omega_I) v_{ji}(\mathbf{x}', \mathbf{x}) d\mathbf{x}' $$
where $v_{ji}$ is the decay component.

The decay component $v_{ji}(\mathbf{x}', \mathbf{x})$ is defined as [S1]:
$$ v_{ji}(\mathbf{x}', \mathbf{x}) = \alpha_j(\mathbf{t}_j) \prod_{k=1}^{j-1} (1 - \alpha_k(\mathbf{t}_k)) \frac{|\mathbf{n}_i \cdot \omega_I| |\mathbf{n}_j \cdot \omega_I|}{\|\mathbf{x} - \mathbf{x}'\|_2^2} $$
where $\omega_I = (\mathbf{x} - \mathbf{x}')/\|\mathbf{x} - \mathbf{x}'\|_2^2$.

The BRDF $f_i$ is expanded using Spherical Harmonics. The coefficient $c_{00}$ is calculated as [S1]:
$$ c_{00} = 4ka^d + (1 - k)a^s $$
The coefficient $c_{lm}$ for odd $l$ is calculated as [S1]:
$$ c_{lm} = (-1)^m (1 - k) \frac{(s+1)(s-1) \cdots (s-l+2)}{(s+2)(s+4) \cdots (s+l+1)} a^s $$
The coefficient $c_{lm}$ for even $l$ is calculated as [S1]:
$$ c_{lm} = (-1)^m (1 - k) \frac{s(s-2) \cdots (s-l+2)}{(s+3)(s+5) \cdots (s+l+1)} a^s $$

**Parameters:**
*   **Spherical Harmonics Degree:** Up to 9-degree basis is used for reasonably glossy materials [S1].
*   **Specular Clamping:** The specular part of the BRDF is clamped to be 0 at the invisible hemisphere [S1].

**Steps:**
1.  For each kernel $i$, initialize the outgoing radiance $L_O(\mathbf{x}, \omega_O)$ using the emission term $E_i(\omega_O)$.
2.  For each kernel $j$ (source of incoming light):
    a. Calculate the decay component $v_{ji}(\mathbf{x}', \mathbf{x})$ for points $\mathbf{x}'$ in kernel $j$ and $\mathbf{x}$ in kernel $i$.
    b. Integrate the product of the BRDF $f_i$, the outgoing radiance from kernel $j$'s center $L_O(\mathbf{t}_j, \omega_I)$, and the decay component $v_{ji}$ over the support $P_j$ of kernel $j$.
    c. Multiply the result by the transparency factor $\alpha_i(\mathbf{x})$ and add to $L_O(\mathbf{x}, \omega_O)$.
3.  Use the Spherical Harmonics coefficients $c_{lm}$ to represent the BRDF $f_i$ for efficient integration.

**Pseudocode:**
```python
def compute_outgoing_radiance(kernels, sh_degree=9):
    """
    Computes outgoing radiance for all kernels using Adapted Radiosity.
    kernels: List of Kernel objects, each with attributes:
        t: center position (vec3)
        n: normal (vec3)
        alpha: transparency factor (float)
        ad: diffuse albedo (float)
        as: specular albedo (float)
        s: specular exponent (float)
        k: mixing factor (float)
        Lo: outgoing radiance (initialized to emission)
    """
    N = len(kernels)
    
    # Precompute SH coefficients for each kernel's BRDF
    for i in range(N):
        kernels[i].sh_coeffs = compute_sh_coefficients(kernels[i].ad, kernels[i].as, kernels[i].s, kernels[i].k, sh_degree)
        
    # Iterate over each kernel to compute outgoing radiance
    for i in range(N):
        kernel_i = kernels[i]
        # Assume Lo is initialized to emission E_i
        # For each source kernel j
        for j in range(N):
            kernel_j = kernels[j]
            
            # Calculate decay component v_ji
            # Note: The integral over P_j is approximated by evaluating at the center t_j
            # and multiplying by the kernel's effective area or using the weighted residual form.
            # Based on the formula: L_O(x, w_O) = E_i + alpha_i * sum_j ( integral_{P_j} ... )
            # The integral term involves L_O(t_j, w_I).
            
            # Compute the integral term for kernel j contributing to kernel i
            # This requires integrating the BRDF * Lo(t_j) * v_ji over P_j.
            # In practice, this is often approximated or solved via the weighted residual method.
            # Here we show the direct application of the formula components.
            
            # Decay component at the center of kernel i (x = t_i) for simplicity in this step
            # In a full implementation, x varies over P_i.
            x = kernel_i.t
            x_prime = kernel_j.t
            
            # Vector from x' to x
            vec = x - x_prime
            dist_sq = dot(vec, vec)
            if dist_sq == 0:
                continue # Avoid division by zero
            
            dist = sqrt(dist_sq)
            omega_I = vec / dist
            
            # Visibility factor (product of alpha and occlusion)
            # Note: The formula uses product_{k=1}^{j-1} (1 - alpha_k(t_k))
            # This implies an ordering. We assume kernels are ordered.
            occlusion = 1.0
            for k in range(j):
                occlusion *= (1.0 - kernels[k].alpha)
            
            # Decay component v_ji
            # v_ji = alpha_j(t_j) * occlusion * |n_i . omega_I| * |n_j . omega_I| / ||x - x'||^2
            n_i_dot_omega = abs(dot(kernel_i.n, omega_I))
            n_j_dot_omega = abs(dot(kernel_j.n, omega_I))
            
            v_ji = kernel_j.alpha * occlusion * n_i_dot_omega * n_j_dot_omega / dist_sq
            
            # Integrate BRDF * Lo(t_j) * v_ji over P_j
            # This is the most complex part. The paper derives a weighted residual solution.
            # For implementation, one might use the SH coefficients to evaluate the integral.
            # Let's assume a helper function that computes the integral of BRDF * v_ji over P_j
            # using the SH expansion.
            integral_term = integrate_brdf_over_kernel(kernel_i, kernel_j, v_ji, sh_degree)
            
            # Add to outgoing radiance
            # L_O(x, w_O) += alpha_i(x) * integral_term
            # Note: alpha_i(x) varies within the kernel.
            # The paper assumes constant outgoing radiance within a kernel for the residual form.
            # So we update the kernel's Lo value.
            kernel_i.Lo += kernel_i.alpha * integral_term

def compute_sh_coefficients(ad, as_val, s, k, degree):
    """
    Computes Spherical Harmonics coefficients for the BRDF.
    """
    coeffs = []
    for l in range(degree + 1):
        for m in range(-l, l + 1):
            if l == 0:
                c_00 = 4 * k * ad + (1 - k) * as_val
                coeffs.append(c_00)
            else:
                # Calculate c_lm based on parity of l
                if l % 2 == 1: # Odd
                    numerator = 1.0
                    for term in range(l):
                        numerator *= (s + 1 - 2 * term) # (s+1)(s-1)...(s-l+2)
                    denominator = 1.0
                    for term in range(l):
                        denominator *= (s + 2 + 2 * term) # (s+2)(s+4)...(s+l+1)
                    c_lm = ((-1) ** m) * (1 - k) * (numerator / denominator) * as_val
                else: # Even
                    numerator = 1.0
                    for term in range(l // 2):
                        numerator *= (s - 2 * term) # s(s-2)...(s-l+2)
                    denominator = 1.0
                    for term in range(l // 2):
                        denominator *= (s + 3 + 2 * term) # (s+3)(s+5)...(s+l+1)
                    c_lm = ((-1) ** m) * (1 - k) * (numerator / denominator) * as_val
                coeffs.append(c_lm)
    return coeffs

def integrate_brdf_over_kernel(kernel_i, kernel_j, v_ji, sh_degree):
    """
    Approximates the integral of BRDF * v_ji over kernel j's support.
    This is a placeholder for the specific weighted residual integration method.
    """
    # The paper mentions deriving a weighted residual solution.
    # The exact integration depends on the kernel shape (Gaussian).
    # For simplicity, we assume the integral is approximated by the value at the center
    # multiplied by an effective area, or using the SH coefficients.
    # This is a gap filled with [G].
    return v_ji * kernel_j.alpha # Simplified approximation
```

## Subtopics

### [Direct Illumination Rendering with Gaussian Surfels](23273-direct-illumination-rendering-with-gaussian-surfels.md)
A rendering method for direct illumination using Gaussian surfels, where outgoing radiance is a weighted average of incident radiance from light sources over the kernel's local support P, using a kernel κ (e.g., Gaussian, Uniform, Dirac delta). It is chosen when only direct illumination is needed and is simpler than the full radiosity solution.

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Not given in the sources.
*   **Strengths:** Efficient forward rendering for Gaussian surfels; handles glossy materials via SH expansion.
*   **Limitations:** Assumes constant emission and BRDF within each kernel; assumes constant outgoing radiance within a kernel for the residual form.
*   **When to use:** When rendering scenes with Gaussian surfels and needing to account for indirect illumination and glossy materials.
*   **When not to use:** When high-frequency spatial variations in radiance within a kernel are critical and cannot be approximated by a constant value.

## Background
The method is described in "Differentiable Light Transport with Gaussian Surfels via Adapted Radiosity for Efficient Relighting and Geometry Reconstruction" by Abhik Ahuja, David McAllister, and Angjoo Kanazawa (2023) [S1]. It builds on the rendering equation and extends the concept of radiosity to Gaussian surfels.
