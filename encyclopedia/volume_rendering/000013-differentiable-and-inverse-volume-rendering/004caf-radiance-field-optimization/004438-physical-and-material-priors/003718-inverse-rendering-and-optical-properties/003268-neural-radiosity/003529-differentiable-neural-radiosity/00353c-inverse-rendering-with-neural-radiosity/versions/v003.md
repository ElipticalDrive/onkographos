# Inverse Rendering with Neural Radiosity


## Overview
Inverse rendering with Neural Radiosity optimizes scene parameters $p$ by minimizing an objective function $z(\cdot)$ that measures the distance between a candidate rendered image and a reference image [S1, unofficial]. It distinguishes itself from differentiable path tracing methods by caching the differential radiance distribution in a neural network, which amortizes the cost of resolving global light transport and avoids independent light transport simulations per optimization step [S1, unofficial].

## How it works
**Inputs:**
- Scene parameters $p$ (e.g., roughness, position, emission intensity) [S1, unofficial].
- Reference image [S1, unofficial].
- Pre-trained primal radiance network $L_\phi$ [S1, unofficial].
- Differential radiance network $\partial_p L_\theta$ [S1, unofficial].
- Camera geometry and scene primitives [G].

**Outputs:**
- Optimized scene parameters $p$ [S1, unofficial].
- Updated networks $\partial_p L_\theta$ and $L_\phi$ [S1, unofficial].

**Data Structures:**
- **Neural Networks:** MLPs with 6 fully-connected layers and 512 neurons per hidden layer [S1, unofficial].
- **Network Inputs:** Position $x$, outgoing direction $\omega_o$, surface normal, diffuse reflectance, and specular reflectance [S1, unofficial].
- **Sparse Grids:** Multiresolution learnable feature vectors stored in sparse grids within the scene [S1, unofficial].
- **Sampling:** Hemispherical samples $\omega_{i,j,k}$ for incident directions, importance sampled from emitter directions and BSDF distributions in primal space [S1, unofficial].

**Steps:**
1. Compute a non-differentiable candidate primal rendering $y = g(p)$ and calculate the loss $z$ (e.g., $L_2$ or $L_1$ distance) between $y$ and the reference image [S1, unofficial].
2. Compute the derivative of the loss with respect to the pixels of the primal image, $\frac{\partial z}{\partial y}$ [S1, unofficial].
3. Compute the gradient of the rendered image with respect to parameters, $\frac{\partial y}{\partial p}$, equivalent to the measurement vector $[\partial_p I_0 \dots \partial_p I_n]$ [S1, unofficial]. Trace rays from the sensor to find the first hit point $x$, query the differential radiance network $\partial_p L_\theta$, and integrate over the surface area $A$ and hemisphere $H^2$:
   $$ \partial_p I_{k,\theta} = \int_A \int_{H^2} W_k(x, \omega) \partial_p L_\theta(x'(x, \omega)) \, dx \, d\omega_{i\perp} $$
   where $W_k$ is the window function and $x'(x, \omega)$ is the point on the surface visible from $x$ in direction $\omega$ [S1, unofficial].
4. Compute the total gradient of the loss w.r.t. parameters $\frac{\partial z}{\partial p}$ by multiplying the gradients from steps 2 and 3:
   $$ \frac{\partial z}{\partial p} = \frac{\partial z}{\partial y} \cdot \frac{\partial y}{\partial p} $$
   [S1, unofficial].
5. Update scene parameters $p$ using an optimizer (e.g., Adam) and a learning rate [S1, unofficial].
6. Fine-tune the networks $\partial_p L_\theta$ and $L_\phi$ to adapt to the new parameter state [S1, unofficial].

**Pseudocode:**
```python
def inverse_rendering_step(p, I_ref, L_phi, dL_theta, camera, scene, optimizer, lr):
    # Step 1: Primal rendering
    y = render_primal(p, L_phi, camera, scene)  # [G]
    loss = compute_loss(y, I_ref)  # e.g., L2 or L1 distance [S1, unofficial]

    # Step 2: Pixel gradient
    dz_dy = compute_gradient(loss, y)  # [G]

    # Step 3: Differential radiance integration
    dy_dp = 0.0
    for each pixel k:
        x, omega = trace_ray(camera, k)  # [G]
        dL = dL_theta(x, omega)  # Query network [S1, unofficial]
        integral = integrate(W_k(x, omega) * dL, over=A, over=H2)  # [S1, unofficial]
        dy_dp += integral

    # Step 4: Gradient accumulation
    dz_dp = dz_dy * dy_dp  # [S1, unofficial]

    # Step 5: Parameter update
    p = optimizer.step(p, dz_dp, lr)  # [G]

    # Step 6: Network fine-tuning or RHS fallback
```

**Formulas:**
The differential radiance is reparameterized to separate the network output from the differential emission term [S1, unofficial]:
$$ \partial_p L_\theta(x, \omega_o) = N_\theta(x, \omega_o) + \partial_p E(x, \omega_o) $$
where $N_\theta$ is the network output and $E$ is emission [S1, unofficial].

The residual of the differential rendering equation $r_\theta$ is defined as:
$$ r_\theta(x, \omega_o) = N_\theta(x, \omega_o) - T\{N_\theta + \partial_p E\}(x, \omega_o) - T'\{N_\phi + E\}(x, \omega_o) $$
where $T$ and $T'$ are transport operators [S1, unofficial].

The transport operators are defined as integrals over the hemisphere $H^2$:
$$ T\{\partial_p L_\theta\}(x, \omega_o) = \int_{H^2} f(x, \omega_i, \omega_o) \partial_p L_\theta(x'(x, \omega_i), -\omega_i) \, d\omega_{i\perp} $$
$$ T'\{L_\phi\}(x, \omega_o) = \int_{H^2} \partial_p f(x, \omega_i, \omega_o) L_\phi(x'(x, \omega_i), -\omega_i) \, d\omega_{i\perp} $$
where $f$ is the BSDF and $L_\phi$ is the primal radiance [S1, unofficial].

**Parameters:**
- **Sampling:** Importance sample emitter directions and BSDF distributions in primal space to obtain incident directions $\omega_i$. Samples are detached (static w.r.t. perturbations in scene parameters) [S1, unofficial].
- **Optimizer:** Adam [S1, unofficial].
- **Network Architecture:** 6 fully-connected layers, 512 neurons per hidden layer [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Fine-tuning Bottleneck:** Fine-tuning networks after every parameter update is computationally expensive [S1, unofficial].
    - *Mitigation:* Keep networks intact in their initial state and use the Right-Hand Side (RHS) of the differential solution instead of fetching gradients from $\partial_p L_\theta$ [S1, unofficial]. The RHS adapts faster to parameter changes because it requires only one extra ray-tracing step with updated parameters, updating terms $\partial_p f$ and $f$ in scattering integrals [S1, unofficial]. This introduces bias but improves performance [S1, unofficial].
- **Gradient Computation:** All gradient terms, including $\partial_p f$ and $\partial_p E$, are computed using automatic differentiation frameworks during optimization [S1, unofficial].

## Subtopics

### [Volumetric Inverse Rendering via Neural Radiative Transfer](10840-volumetric-inverse-rendering-via-neural-radiative-transfer.md)
Performs volumetric inverse rendering by jointly optimizing a neural medium field and a neural light field. It uses a Volumetric Radiance Error (VRE) loss to integrate radiance along primary viewing rays, counteracting oversmoothing from local constraints, and amortizes global light transport resolution.

## Operating characteristics
- **Time Complexity:** Avoids the high cost of differentiating through generic Monte Carlo rendering by using an adjoint-like approach with a cached neural representation [S1, unofficial]. Fine-tuning networks at every iteration is a bottleneck [S1, unofficial]. Using the RHS approximation reduces this cost but introduces bias [S1, unofficial].
- **Memory Complexity:** Requires storing two neural networks (primal and differential) and sparse feature grids [S1, unofficial]. The computation graph size is vastly reduced compared to generic differentiable path tracing [S1, unofficial].
- **Performance:** Efficient for scenes where global light transport is complex, as it amortizes the transport solution [S1, unofficial]. Suitable for optimizing material properties (e.g., roughness) and illumination [S1, unofficial].
- **Strengths:** Avoids independent light transport simulations per scene instance; handles global illumination via the neural network; reduces computation graph size [S1, unofficial].
- **Limitations:** Fine-tuning bottleneck if not using the RHS approximation; potential bias from using the RHS approximation; requires pre-training of the primal radiance network [S1, unofficial].

## Background
The method is based on "Differentiable Neural Radiosity" by Hadadan et al. (2022) [S1, unofficial]. It builds on the Neural Radiosity method by Hadadan et al. (2021) [S1, unofficial]. The approach was developed to address the computational costs of differentiable rendering by caching the differential radiance distribution in a neural network [S1, unofficial].
