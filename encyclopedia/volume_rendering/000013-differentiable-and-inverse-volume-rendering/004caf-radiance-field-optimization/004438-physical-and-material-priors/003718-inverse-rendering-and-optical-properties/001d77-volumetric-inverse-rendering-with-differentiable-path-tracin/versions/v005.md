# Volumetric Inverse Rendering with Differentiable Path Tracing

Also called: Differentiable Volumetric Inverse Rendering, Differentiable Volumetric Path Tracing Optimization, Mitsuba 3 Volumetric Inverse Rendering, Mitsuba 3 Volumetric Inverse Rendering Tutorial, Volumetric Inverse Rendering with Differentiable Path Replay Backpropagation, Volumetric Path Tracing with Adjoint Differentiation

## Overview
This method optimizes a 3D volume density (extinction/scattering) stored on a regular grid to match a set of synthetic reference images [S2, S3, unofficial]. It accounts for direct and indirect illumination by using path replay backpropagation to compute derivatives of delta tracking and volumetric multiple scattering [S2, S3, unofficial]. It builds on [Inverse Rendering and Optical Properties](7914-inverse-rendering-and-optical-properties.md). Unlike standard differentiable volume rendering which often relies on analytic inversion or simple reverse-mode AD on discrete steps, this approach integrates the adjoint method directly into the path tracing loop, allowing for the optimization of complex volumetric properties while maintaining differentiability through stochastic sampling events [S2, S3, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   A set of reference images $\{I_{ref}^{(i)}\}$ captured from multiple viewpoints [S2, S3, unofficial].
*   A scene description containing a differentiable volumetric path tracer (e.g., `prbvolpath` in Mitsuba 3) [S2, S3, unofficial].
*   An initial guess for the volume density grid $\sigma_t$, typically a low constant value [S2, S3, unofficial].
*   Camera poses and intrinsics corresponding to the reference images [S2, S3, unofficial].

**Outputs:**
*   Optimized volume density grid $\sigma_t$ that minimizes the difference between rendered images and reference images [S2, S3, unofficial].

### Data Structures
*   **Volume Grid:** A 3D tensor (e.g., `TensorXf` in Dr.Jit) representing the extinction coefficient $\sigma_t$, with dimensions $(V_x, V_y, V_z, 1)$ [S2, S3, unofficial].
*   **Scene Parameters:** A traversed scene parameters map where the volume data is accessed via a specific key (e.g., `'object.interior_medium.sigma_t.data'`) [S2, S3, unofficial].
*   **Optimizer State:** Internal state for the Adam optimizer (momentum, variance) associated with the volume data [S2, S3, unofficial].

### Steps
1.  **Sensor Setup:** Create $N$ sensors (e.g., $N=5$) placed on a half-circle around the origin [S2, S3, unofficial]. For each sensor $i$, calculate the angle $\theta_i = \frac{180.0}{N} \cdot i - 90.0$ [S2, S3, unofficial]. Apply a rotation around the Y-axis by $\theta_i$, then apply a look-at transform from the origin $[0,0,0]$ to the camera origin $[0,0,4]$ with up vector $[0,1,0]$ [S2, S3, unofficial]. Load each sensor with type `'perspective'`, field of view 45, and a 64x64 HDR film with a tent filter [S2, S3, unofficial].
2.  **Reference Image Rendering:** Render the reference scene (containing the ground-truth volume) using the differentiable path tracer for each sensor [S2, S3, unofficial]. Store the resulting images in a list $\{I_{ref}^{(i)}\}$ [S2, S3, unofficial]. The number of samples per pixel (spp) for reference images is typically high (e.g., 512) to reduce noise in the target [S2, S3, unofficial].
3.  **Optimization Scene Initialization:** Create an optimization scene with a uniform volume grid of resolution $V \times V \times V \times 1$ (e.g., $16^3$) [S2, S3, unofficial]. Initialize the extinction coefficient $\sigma_t$ to a low constant value (e.g., 0.002) [S2, S3, unofficial]. This low initial value helps the optimizer by making it easier to increase density than to remove parts of a very dense volume [S2, S3, unofficial]. The container object (e.g., a cube) should have a `'null'` BSDF to prevent surface interactions [S2, S3, unofficial]. The volume scale parameter (e.g., 40.0) defines the range of extinction values [S2, S3, unofficial].
4.  **Parameter Extraction and Optimizer Setup:** Traverse the scene to extract the volume data parameter key (e.g., `'object.interior_medium.sigma_t.data'`) [S2, S3, unofficial]. Initialize an Adam optimizer with a learning rate (e.g., 0.02) and assign the volume data to it [S2, S3, unofficial].
5.  **Optimization Loop:** For each iteration:
    a. Initialize total loss to 0.0.
    b. For each sensor $i$:
        i. Render the scene using the differentiable path tracer with the current parameters, using a lower spp (e.g., 8) for efficiency [S2, S3, unofficial].
        ii. Compute the L2 loss: $L = \text{mean}((I_{rendered} - I_{ref}^{(i)})^2)$ [S2, S3, unofficial].
        iii. Backpropagate gradients using automatic differentiation [S2, S3, unofficial].
        iv. Take a gradient step with the optimizer [S2, S3, unofficial].
        v. Clamp the optimized density values to $[10^{-6}, 1.0]$ to prevent invalid values [S2, S3, unofficial].
        vi. Update scene parameters [S2, S3, unofficial].
        vii. Add loss to total loss [S2, S3, unofficial].
6.  **Volume Upsampling (Multi-resolution Strategy):** After initial optimization at low resolution, upsample the volume grid to a higher resolution (e.g., $64^3$) using a linear resampling filter [S2, S3, unofficial]. The linear filter is crucial to prevent overshooting and negative density values, which can occur with cubic filters [S3, unofficial]. The optimizer automatically resets its internal state (e.g., momentum) when the size of the optimized variable changes [S2, S3, unofficial]. Continue optimization at the higher resolution [S2, S3, unofficial].

### Pseudocode
```python
import drjit as dr
import mitsuba as mi

def setup_sensors(sensor_count=5):
    """Setup multiple sensors on a half-circle."""
    from mitsuba import ScalarTransform4f as T
    sensors = []
    for i in range(sensor_count):
        angle = 180.0 / sensor_count * i - 90.0
        sensor_rotation = T().rotate([0, 1, 0], angle)
        sensor_to_world = T().look_at(target=[0, 0, 0], origin=[0, 0, 4], up=[0, 1, 0])
        sensors.append(mi.load_dict({
            'type': 'perspective',
            'fov': 45,
            'to_world': sensor_rotation @ sensor_to_world,
            'film': {
                'type': 'hdrfilm',
                'width': 64, 'height': 64,
                'filter': {'type': 'tent'}
            }
        }))
    return sensors

def render_reference_images(scene_ref, sensors, ref_spp=512):
    """Render reference images from multiple viewpoints."""
    ref_images = []
    for i in range(len(sensors)):
        img = mi.render(scene_ref, sensor=sensors[i], spp=ref_spp)
        ref_images.append(img)
    return ref_images

def setup_optimization_scene(v_res=16, scale=40.0):
    """Create an optimization scene with a low-resolution uniform volume."""
    import drjit as dr
    import mitsuba as mi
    from mitsuba import ScalarTransform4f as T
    
    scene_dict = {
        'type': 'scene',
        'integrator': {'type': 'prbvolpath'},
        'object': {
            'type': 'cube',
            'interior': {
                'type': 'heterogeneous',
                'sigma_t': {
                    'type': 'gridvolume',
                    'grid': mi.VolumeGrid(dr.full(mi.TensorXf, 0.002, (v_res, v_res, v_res, 1))),
                    'to_world': T().translate(-1).scale(2.0)
                },
                'scale': scale,
            },
            'bsdf': {'type': 'null'}
        },
        'emitter': {'type': 'constant'}
    }
    return mi.load_dict(scene_dict)

def optimize_volume(scene, sensors, ref_images, iteration_count=20, spp=8, lr=0.02):
    """Optimize volume density to match reference images."""
    import drjit as dr
    import mitsuba as mi
    
    params = mi.traverse(scene)
    key = 'object.interior_medium.sigma_t.data'
    
    opt = mi.ad.Adam(lr=lr)
    opt[key] = params[key]
    params.update(opt)
    
    for it in range(iteration_count):
        total_loss = 0.0
        for sensor_idx in range(len(sensors)):
            img = mi.render(scene, params, sensor=sensors[sensor_idx], spp=spp, seed=it)
            loss = dr.mean(dr.square(img - ref_images[sensor_idx]))
            dr.backward(loss)
            opt.step()
            opt[key] = dr.clip(opt[key], 1e-6, 1.0)
            params.update(opt)
            total_loss += loss
        print(f"Iteration {it}: Loss = {total_loss}")

    # Multi-resolution upsampling
    opt[key] = dr.resample(opt[key], shape=(64, 64, 64, 1), filter='linear')
    params.update(opt)
    
    # Continue optimization at higher resolution
    for it in range(iteration_count):
        total_loss = 0.0
        for sensor_idx in range(len(sensors)):
            img = mi.render(scene, params, sensor=sensors[sensor_idx], spp=8*spp, seed=it)
            loss = dr.mean(dr.square(img - ref_images[sensor_idx]))
            dr.backward(loss)
            opt.step()
            opt[key] = dr.clip(opt[key], 1e-6, 1.0)
            params.update(opt)
            total_loss += loss
        print(f"Iteration {it}: Loss = {total_loss}")
```

### Edge Cases and Pitfalls
*   **Density Clamping:** Optimized density values must be clamped to a valid range (e.g., $[10^{-6}, 1.0]$) because the `scale` parameter scales the extinction [S2, S3, unofficial].
*   **Upsampling Filter Choice:** Using a cubic filter for upsampling can overshoot and produce negative density values. A linear filter should be used to preserve the value range [S3, unofficial].
*   **Optimizer State Reset:** When the size of the optimized variable changes (e.g., during upsampling), the optimizer automatically resets its internal state (e.g., momentum) [S2, S3, unofficial].
*   **Initial Density Value:** Initializing to a low constant value (e.g., 0.002) is preferred over a high value because it is easier for the optimizer to increase density than to remove parts of a very dense volume [S2, S3, unofficial].
*   **Multi-View Requirement:** Multiple viewpoints are needed to sufficiently constrain the reconstructed volume density. Using a single view is insufficient [S2, S3, unofficial].
