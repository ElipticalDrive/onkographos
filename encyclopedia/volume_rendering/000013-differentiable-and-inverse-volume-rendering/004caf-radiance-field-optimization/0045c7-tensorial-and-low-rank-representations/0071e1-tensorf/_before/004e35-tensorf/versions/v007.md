# TensoRF

Also called: TensoRF (Tensorial Radiance Field Representation), TensoRF Representation, TensoRF Representation and Reconstruction, Tensor Factorization for NeRF, Tensorial Radiance Field Representation, Tensorial Radiance Fields

## Overview
TensoRF models a 3D radiance field as a factorized 4D tensor, replacing the implicit MLPs of NeRF with explicit, low-rank tensor grids for density and appearance [S2][S7, unofficial]. It sets itself apart from sibling methods like [Strivec](11863-strivec.md) by using global tensor factorization rather than local sparse grids, and from [HexPlane](12007-hexplane.md) by employing full 3D vector-matrix decomposition rather than planar projections [S2][S7, unofficial]. It achieves significantly faster training and smaller model sizes than implicit NeRF and concurrent explicit methods like Plenoxels, while maintaining high rendering quality [S1][S7, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Multi-view images with known camera poses; scene bounding box.
*   **Outputs:** Optimized tensor factors for geometry ($G_\sigma$) and appearance ($G_c$); rendered RGB images.

**Data Structures:**
The method uses two grids:
1.  **Geometry Grid ($G_\sigma$):** A 3D tensor of shape $I \times J \times K$ storing scalar density values directly [S2][S7, unofficial].
2.  **Appearance Grid ($G_c$):** A 4D tensor of shape $I \times J \times K \times P$ storing $P$-dimensional appearance features [S2][S7, unofficial].

These grids are decomposed using CANDECOMP-PARAFAC (CP) or Vector-Matrix (VM) factorization [S1][S2]. The parameters are:
*   **Geometry Factors:** For each component $r \in \{1, \dots, R_\sigma\}$ and mode $m \in \{X, Y, Z\}$:
    *   $\mathbf{v}_{\sigma,r}^m$: 1D vector of length $N_m$ (where $N_X=I, N_Y=J, N_Z=K$).
    *   $\mathbf{M}_{\sigma,r}^{m'}$: 2D matrix of shape $N_{m'} \times N_{m''}$, where $\{m, m', m''\} = \{X, Y, Z\}$.
*   **Appearance Factors:** For each component $r \in \{1, \dots, R_c\}$ and mode $m \in \{X, Y, Z\}$:
    *   $\mathbf{v}_{c,r}^m$: 1D vector of length $N_m$.
    *   $\mathbf{M}_{c,r}^{m'}$: 2D matrix of shape $N_{m'} \times N_{m''}$.
    *   $\mathbf{b}_r$: 1D vector of length $P$. There are $3R_c$ such vectors.
*   **Global Appearance Dictionary ($\mathbf{B}$):** A matrix of shape $P \times 3R_c$, formed by stacking all $\mathbf{b}_r$ vectors as columns [S2][S7, unofficial].

**Formulas:**
The interpolated component value for mode $X$ at location $\mathbf{x}=(x,y,z)$ is:
$$ \mathcal{A}_r^X(\mathbf{x}) = \mathbf{v}_r^X(x) \mathbf{M}_r^{YZ}(y, z) $$
where $\mathbf{v}_r^X(x)$ is linearly interpolated along the X-axis, and $\mathbf{M}_r^{YZ}(y, z)$ is bilinearly interpolated in the YZ plane [S2][S7, unofficial]. Similar formulas apply for modes Y and Z [S2].

The density grid value is the sum of interpolated components:
$$ \mathcal{G}_\sigma(\mathbf{x}) = \sum_{r=1}^{R_\sigma} \sum_{m \in XYZ} \mathcal{A}_{\sigma,r}^m(\mathbf{x}) \quad (13) $$

The appearance feature vector is computed by concatenating all interpolated appearance components into a vector of size $3R_c$ and multiplying by $\mathbf{B}$:
$$ \mathcal{G}_c(\mathbf{x}) = \mathbf{B} \left( \bigoplus_{r=1}^{R_c} \bigoplus_{m \in XYZ} \mathcal{A}_{c,r}^m(\mathbf{x}) \right) \quad (14) $$
where $\oplus$ denotes concatenation [S2][S7, unofficial].

The final density $\sigma$ and color $c$ are:
$$ \sigma = \mathcal{G}_\sigma(\mathbf{x}) $$
$$ c = S(\mathcal{G}_c(\mathbf{x}), \mathbf{d}) $$
where $S$ is a decoding function (MLP or Spherical Harmonics) and $\mathbf{d}$ is the viewing direction [S2][S7, unofficial].

Differentiable volume rendering computes pixel color $C$ by marching along a ray, sampling $Q$ points, and accumulating transmittance $\tau_q = \exp(-\sum_{p=1}^{q-1} \sigma_p \Delta_p)$:
$$ C = \sum_{q=1}^Q \tau_q (1 - \exp(-\sigma_q \Delta_q)) c_q \quad (16) $$
where $\sigma_q, c_q$ are density and color at sample $q$, and $\Delta_q$ is the ray step size [S2][S7, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def linear_interp_1d(vec, coord):
    """Linear interpolation of a 1D vector at coordinate coord."""
    coord = torch.clamp(coord, 0, vec.shape[0] - 1 - 1e-6)
    i0 = coord.long()
    i1 = torch.clamp(i0 + 1, max=vec.shape[0] - 1)
    w = coord - i0.float()
    return vec[i0] * (1 - w) + vec[i1] * w

def bilinear_interp_2d(mat, coord_y, coord_z):
    """Bilinear interpolation of a 2D matrix at coordinates (y, z)."""
    coord_y = torch.clamp(coord_y, 0, mat.shape[0] - 1 - 1e-6)
    coord_z = torch.clamp(coord_z, 0, mat.shape[1] - 1 - 1e-6)
    j0 = coord_y.long()
    k0 = coord_z.long()
    j1 = torch.clamp(j0 + 1, max=mat.shape[0] - 1)
    k1 = torch.clamp(k0 + 1, max=mat.shape[1] - 1)
    w_y = coord_y - j0.float()
    w_z = coord_z - k0.float()
    v00 = mat[j0, k0]
    v01 = mat[j0, k1]
    v10 = mat[j1, k0]
    v11 = mat[j1, k1]
    v0 = v00 * (1 - w_y) + v10 * w_y
    v1 = v01 * (1 - w_y) + v11 * w_y
    return v0 * (1 - w_z) + v1 * w_z

def evaluate_sh(features, directions):
    """Standard spherical harmonics evaluation for 3rd order (P=27) [G]."""
    # Standard SH basis evaluation mapping features and directions to RGB
    return torch.zeros_like(directions) # Placeholder for standard SH math [G]

def mlp_decoder(features, directions):
    """2-layer MLP decoder with 128 hidden units and ReLU [S7, unofficial]."""
    x = F.relu(torch.nn.Linear(27, 128)(features))
    x = F.relu(torch.nn.Linear(128, 128)(x))
    return torch.sigmoid(torch.nn.Linear(128, 3)(x))

def evaluate_tensorf(x, d, params):
    """
    x: (B, 3) coordinates
    d: (B, 3) viewing directions
    params: dict containing tensor factors
    Returns: sigma (B,), color (B, 3)
    """
    # Extract factors
    v_sigma_X = params['v_sigma_X'] # (N0, R_sigma)
    M_sigma_YZ = params['M_sigma_YZ'] # (N0, N1, R_sigma)
    # ... other geometry factors similarly ...
    B_mat = params['B'] # (P, 3*R_c)
    
    sigma = torch.zeros(x.shape[0], device=x.device)
    for r in range(params['R_sigma']):
        ax = linear_interp_1d(v_sigma_X[:, r], x[:, 0]) * bilinear_interp_2d(M_sigma_YZ[:, :, r], x[:, 1], x[:, 2])
        sigma += ax
        # Add modes Y and Z similarly...
        
    # Appearance
    app_features = []
    for r in range(params['R_c']):
        # Mode X
        app_features.append(linear_interp_1d(params['v_c_X'][:, r], x[:, 0]) * bilinear_interp_2d(params['M_c_YZ'][:, :, r], x[:, 1], x[:, 2]))
        # Mode Y
        app_features.append(linear_interp_1d(params['v_c_Y'][:, r], x[:, 1]) * bilinear_interp_2d(params['M_c_XZ'][:, :, r], x[:, 0], x[:, 2]))
        # Mode Z
        app_features.append(linear_interp_1d(params['v_c_Z'][:, r], x[:, 2]) * bilinear_interp_2d(params['M_c_XY'][:, :, r], x[:, 0], x[:, 1]))
        
    app_vec = torch.stack(app_features, dim=1) # (B, 3*R_c)
    G_c = app_vec @ B_mat.T # (B, P)
    
    if params['decoder_type'] == 'SH':
        color = evaluate_sh(G_c, d)
    else:
        color = mlp_decoder(G_c, d)
        
    return sigma, color
```

**Parameters:**
*   $N_0$: Initial grid resolution. Typical value: 128 [S7, unofficial].
*   $P$: Number of appearance features. Typical value: 27 (3rd-order SH coefficients) [S7, unofficial].
*   $R_\sigma, R_c$: Number of components. Configuration examples: 48, 96, 192, 384 [S7, unofficial].
*   Learning Rate: 0.02 for tensor factors, 0.001 for MLP decoder [S7, unofficial].
*   Optimizer: Adam [S7, unofficial].
*   Batch Size: 4096 pixel rays [S7, unofficial].
*   Upsampling Steps: 2000, 3000, 4000, 5500, 7000 [S7, unofficial].

**Edge Cases and Pitfalls:**
*   **Overfitting:** In regions with few views, the model may overfit. Mitigated by L1 norm loss on factors and Total Variation (TV) loss [S7, unofficial]. TV loss is preferred for datasets with few images (e.g., LLFF) or imperfect capture (e.g., Tanks and Temples) [S7, unofficial].
*   **Local Minima:** Coarse-to-fine upsampling helps avoid local minima [S7, unofficial].
*   **Precision:** Trilinear interpolation is computed efficiently by interpolating factors directly, avoiding the cost of evaluating 8 voxel values [S2].

## Subtopics

### [CasCPRF](7415-cascprf.md)
A multi-scale tensor decomposition that achieves superior compactness by separating frequencies across hierarchical levels using a tree structure. Choose when maximum compactness is required.

### [Simple-TensoRF Augmentation](7596-simple-tensorf-augmentation.md)
A regularization method for sparse views that uses a secondary low-capacity model to provide depth priors. Choose when training with very few input views to mitigate floaters.

### [Generalized Tensorial Radiance Fields (GTensoRF)](8560-generalized-tensorial-radiance-fields-gtensorf.md)
A framework for simultaneous multi-scene optimization using higher-order tensor decomposition. Choose when optimizing multiple scenes in parallel or for cross-scene editing.

### [Strivec](11863-strivec.md)
A representation using sparsely distributed, compactly factorized local tensor feature grids. Choose when scene sparsity is high and global tensors are inefficient.

## Operating characteristics
**Time and Memory Complexity:**
*   Space complexity is reduced from $O(n^3)$ (dense grid) to $O(n)$ with CP decomposition or $O(n^2)$ with VM decomposition, where $n$ is the grid dimension [S5].
*   Training speed is comparable to Plenoxels and significantly faster than implicit NeRF models [S1].

**Measured Performance:**
*   Hardware: Single Tesla V100 GPU (16GB) [S7, unofficial].
*   Synthetic NeRF (300^3 voxels, 30k steps):
    *   TensoRF-VM-192: PSNR 33.14, SSIM 0.963, Time 17.4 min, Size 71.8 MB [S7, unofficial].
    *   TensoRF-CP-384: PSNR 31.56, Time 25.2 min, Size 3.9 MB [S7, unofficial].
*   NSVF (300^3 voxels, 30k steps):
    *   TensoRF-VM-192: PSNR 36.52, SSIM 0.982 [S7, unofficial].
*   Tanks & Temples (300^3 voxels, 30k steps):
    *   TensoRF-VM-192: PSNR 28.56, SSIM 0.920 [S7, unofficial].
*   LLFF (Forward-facing):
    *   TensoRF-VM-96: PSNR 26.73, SSIM 0.839, Time 25.43 min, Size 179.7 MB [S7, unofficial].

**Strengths and Limitations:**
*   **Strengths:** Extremely compact model size (CP variant < 4MB), fast reconstruction (< 30 min for most variants), high rendering quality (VM variant outperforms NeRF), standard PyTorch implementation without custom CUDA kernels [S2][S7, unofficial].
*   **Limitations:** VM variant requires more memory than CP.

**When to Use:**
*   Use when training speed and model compactness are critical [S1][S7, unofficial].
*   Use when a standard implementation without custom kernels is preferred [S5][S7, unofficial].

## Background
TensoRF was introduced by Anpei Chen, Zexiang Xu, Andreas Geiger, Jingyi Yu, and Hao Su in the paper "Tensorf: Tensorial Radiance Fields" presented at ECCV 2022 [S7, unofficial]. It was developed to address the computational inefficiency and large memory footprint of MLP-based NeRFs and concurrent explicit methods like Plenoxels [S3, unofficial][S7, unofficial]. The method leverages tensor factorization (CP and VM) to decompose the 4D radiance field into low-rank components, enabling efficient trilinear interpolation and differentiable rendering [S1][S7, unofficial]. It has been widely used as a baseline for subsequent low-rank and tensor-based radiance field research [S1, S4].
