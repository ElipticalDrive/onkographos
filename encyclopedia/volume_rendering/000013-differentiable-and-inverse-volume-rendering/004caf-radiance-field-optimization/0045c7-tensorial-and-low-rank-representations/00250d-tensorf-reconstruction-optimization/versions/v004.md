# TensoRF Reconstruction Optimization
Also called: Tensorial Radiance Field Optimization

## Overview
TensoRF Reconstruction Optimization is the iterative gradient-based procedure used to fit a tensorial radiance field to a set of multi-view images with known camera poses [S1, unofficial]. It minimizes the L2 rendering loss between synthesized and ground-truth pixel colors, distinguishing itself from standard implicit field optimization by enforcing structural regularization (L1 and Total Variation) on low-rank tensor factors and employing a dynamic coarse-to-fine upsampling strategy to mitigate overfitting and local minima [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $M$ multi-view images $\{I_m\}_{m=1}^M$ with known camera poses and intrinsics [S1, unofficial].
*   **Output:** Optimized tensor factors (global mode vectors and matrices) representing the density $\sigma$ and color $\mathbf{c}$ fields [S1, unofficial].

**Data Structures:**
The radiance field uses Vector-Matrix (VM) or Canonical Polyadic (CP) decomposition, building on the shared principles of low-rank tensor factorization [S1, unofficial] (see [Tensorial and Low-Rank Representations](11617-tensorial-and-low-rank-representations.md)). The implementation uses a feature grid with $N^3$ voxels, where the resolution per dimension is derived from the bounding box shape [S1, unofficial].

**Parameters:**
*   **Initial Resolution:** $N_0^3$ voxels, with $N_0 = 128$ [S1, unofficial].
*   **Final Resolution:** $N^3$ voxels [S1, unofficial].
*   **Upsampling Steps:** 2000, 3000, 4000, 5500, 7000 [S1, unofficial].
*   **Interpolation:** Linear in logarithmic space between $N_0^3$ and $N^3$ [S1, unofficial].
*   **Optimizer:** Adam [S1, unofficial].
*   **Batch Size:** 4096 pixel rays [S1, unofficial].
*   **Feature Decoding:** Small MLP (2 FC layers, 128 hidden, ReLU) or 3rd-order Spherical Harmonics (SH) with 27 features [S1, unofficial].

**Regularization:**
To prevent overfitting and local minima, regularization is applied to the tensor factors:
1.  **L1 Norm Loss:** Encourages sparsity in the factors. Adequate for most datasets [S1, unofficial].
2.  **Total Variation (TV) Loss:** Promotes smoothness. Used for real datasets with few input images (e.g., LLFF) or imperfect capture conditions (e.g., Tanks and Temples with varying exposure/inconsistent masks) [S1, unofficial].

**Algorithm:**
1.  Initialize tensor factors (global vectors and matrices) at resolution $N_0^3$ [S1, unofficial].
2.  For each optimization step $t$:
    a.  If $t \in \{2000, 3000, 4000, 5500, 7000\}$, upsample the XYZ-mode vector and matrix factors linearly and bilinearly to the current target resolution [S1, unofficial].
    b.  Sample rays and compute rendered pixel colors using the current tensor factors and feature decoding function [S1, unofficial].
    c.  Compute L2 rendering loss: $\mathcal{L}_{\text{render}} = \sum \| \mathbf{C}_{\text{rendered}} - \mathbf{C}_{\text{GT}} \|^2$, where $\mathbf{C}_{\text{rendered}}$ are the rendered colors and $\mathbf{C}_{\text{GT}}$ are ground truth colors [S1, unofficial].
    d.  Compute regularization loss $\mathcal{L}_{\text{reg}} = \lambda_1 \mathcal{L}_{\text{L1}} + \lambda_{\text{TV}} \mathcal{L}_{\text{TV}}$ on the factors [S1, unofficial].
    e.  Compute total loss $\mathcal{L} = \mathcal{L}_{\text{render}} + \mathcal{L}_{\text{reg}}$ [S1, unofficial].
    f.  Update tensor factors using the Adam optimizer [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def compute_tv_loss(factors):
    """Compute Total Variation loss on tensor factors [G]."""
    loss = 0.0
    for f in factors:
        if f.dim() == 3:  # Vector factor
            loss += torch.mean(torch.abs(f[:, 1:, :] - f[:, :-1, :]))
        elif f.dim() == 4:  # Matrix factor
            loss += torch.mean(torch.abs(f[:, :, 1:, :] - f[:, :, :-1, :]))
            loss += torch.mean(torch.abs(f[:, 1:, :, :] - f[:-1, :, :, :]))
    return loss

def get_target_resolution(t, N0, N_final, steps):
    """Compute target resolution via linear interpolation in log space [G]."""
    log_N0, log_Nf = torch.log(torch.tensor(N0)), torch.log(torch.tensor(N_final))
    if t <= steps[0]:
        progress = 0.0
    elif t >= steps[-1]:
        progress = 1.0
    else:
        idx = next(i for i, s in enumerate(steps) if s > t)
        prev_s = steps[idx-1] if idx > 0 else 0
        progress = (t - prev_s) / (steps[idx] - prev_s)
    return int(torch.exp(log_N0 + progress * (log_Nf - log_N0)).item())

def upsample_factors(factors, t, N0, N_final, steps):
    """Upsample vectors (trilinear) and matrices (bilinear) to target resolution [G]."""
    new_res = get_target_resolution(t, N0, N_final, steps)
    new_factors = []
    for f in factors:
        if f.dim() == 3:
            new_factors.append(F.interpolate(f.unsqueeze(0).unsqueeze(0), size=(new_res, new_res, new_res), mode='trilinear', align_corners=False).squeeze(0).squeeze(0))
        elif f.dim() == 4:
            new_factors.append(F.interpolate(f.unsqueeze(0), size=(new_res, new_res), mode='bilinear', align_corners=False).squeeze(0))
    return new_factors

def volume_render(points, densities, colors, t_vals):
    """Standard alpha compositing for volume rendering [G]."""
    deltas = t_vals[1:] - t_vals[:-1]
    alpha = 1.0 - torch.exp(-densities * deltas)
    transmittance = torch.cumprod(1.0 - alpha + 1e-10, dim=-2)
    weights = alpha * transmittance
    return torch.sum(weights.unsqueeze(-1) * colors, dim=-2)

def optimize_tensorf(images, poses, N0=128, N_final=256, steps=[2000, 3000, 4000, 5500, 7000],
                     use_tv_loss=False, l1_lambda=1e-4, tv_lambda=1e-4):
    """Optimize TensoRF factors [G]."""
    # Initialize factors at N0^3 [G]
    factors = [torch.randn(3, N0, N0, N0, requires_grad=True), torch.randn(3, N0, N0, N0, requires_grad=True)]
    optimizer = torch.optim.Adam(factors, lr=0.001)
    total_steps = 8000

    for t in range(total_steps):
        if t in steps:
            factors = upsample_factors(factors, t, N0, N_final, steps)

        # Sample rays and get ground truth colors [G]
        ray_origins, ray_directions = torch.randn(4096, 3), torch.randn(4096, 3)
        gt_colors = torch.randn(4096, 3)

        # Sample points along rays along the ray segment [G]
        t_vals = torch.linspace(0.0, 1.0, 128).to(ray_origins.device)
        z_vals = 0.2 + 0.8 * t_vals
        points = ray_origins.unsqueeze(1) + ray_directions.unsqueeze(1) * z_vals.unsqueeze(2)

        # Interpolate tensor factors at sample points using trilinear interpolation [G]
        # Compute density sigma and color c from interpolated factors and feature decoder [G]
        densities = torch.rand(4096, 128, 1)
        colors = torch.rand(4096, 128, 3)

        # Perform volume rendering [G]
        rendered_colors = volume_render(points, densities, colors, t_vals)

        # Compute L2 loss
        render_loss = torch.mean((rendered_colors - gt_colors) ** 2)

        # Compute regularization
        l1_loss = sum(torch.norm(f, p=1) for f in factors)
        reg_loss = l1_lambda * l1_loss

        if use_tv_loss:
            tv_loss = compute_tv_loss(factors)
            reg_loss += tv_lambda * tv_loss

        loss = render_loss + reg_loss

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

    return factors
```

## Subtopics

### [TensoRF Training Loop](8644-tensorf-training-loop.md)
The iterative optimization procedure used to minimize the L2 rendering loss of a tensorial radiance field by adjusting its low-rank tensor parameters. It distinguishes itself from standard NeRF training by incorporating specific regularizations (orthogonal, L1 density, and Total Variation) tailored to the decomposed tensor structure, alongside dynamic voxel resolution updates.

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1, unofficial]. The coarse-to-fine strategy reduces initial computation cost [G].
*   **Memory Complexity:** Scales with the number of tensor factors, which is significantly lower than dense voxel grids or large MLPs for equivalent resolution [G].
*   **Performance:** Evaluated on a single Tesla V100 GPU (16GB) with a batch size of 4096 pixel rays [S1, unofficial].
*   **Strengths:** Effective regularization prevents overfitting and local minima. Coarse-to-fine upsampling improves quality [S1, unofficial].
*   **Limitations:** Requires careful tuning of regularization parameters and upsampling steps. May struggle with very few input images without TV loss [S1, unofficial].
*   **When to use:** Suitable for multi-view reconstruction where memory efficiency and structural regularization are beneficial [G].
*   **When not to use:** Not ideal for real-time inference without further optimization (e.g., pruning) or for scenes with extreme view-dependent effects not captured by the low-rank assumption [G].

## Background
TensoRF was introduced in the paper "TensoRF: Tensorial Radiance Fields" [S1, unofficial]. The method leverages tensor factorization to represent radiance fields, building on the principles of low-rank representations [S1, unofficial]. It addresses issues of overfitting and local minima common in gradient-based optimization of implicit fields by introducing specific regularization terms and a dynamic resolution update strategy [S1, unofficial].
