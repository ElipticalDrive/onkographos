# TensoRF Decomposition Models
Also called: CP model, HY model, HY-S model, Rank-Residual Decomposition Models (CP, HY-S)

## Overview
This family defines the tensor decomposition strategies used to factorize the radiance field density and color fields in TensoRF, balancing storage efficiency against rendering quality [S1]. It differs from sibling methods like [NeuManifold](9771-neumanifold.md) or [StyleTRF](11815-styletrf.md) by explicitly structuring the low-rank approximation into discrete rank groups (rank-residual learning) and offering specific variants (CP, HY, HY-S) to control the ratio of vector- to matrix-based components [S1].

## Shared principles
The core mechanism is **Rank-Residual Decomposition**, where the radiance field is approximated as a sum of $M$ groups of components [S1]. Each group $m$ contains a specific number of rank components for density and color [S1]. The decomposition supports two types of components: **Vector-based (CP)** uses only 1D vectors for each spatial dimension [S1]. **Hybrid (HY)** uses both vector- and matrix-based components [S1]. The HY decomposition allows arbitrary adjustment of the ratio of vector- to matrix-based rank components, providing greater flexibility in model size control compared to TensoRF's fixed 1:1 VM ratio [S1]. A scalable variant of HY that allows adjustable model size [S1]. Both density and color initially use 96 vector components [S1]. Four additional groups for color append matrix components {4, 16, 32, 64} gradually [S1]. Total M=5 groups (first has 96 vector components) [S1]. The total field value at a point is the sum of contributions from all groups [G]. The model size is controlled by the number of groups $M$ and the rank distribution within each group [S1]. The decomposition is optimized using an Adam optimizer with an initial learning rate of 0.02 for the factorized matrices and 0.001 for the singular values [S1].

## Subtopics

### [Factorized Radiance Field with Fixed View-Dependent Components](17971-factorized-radiance-field-with-fixed-view-dependent-componen.md)
Reconstructs a radiance field from sparse input views by factorizing geometry and appearance tensors into a fixed number of components equal to the number of input views ($n$), rather than a small fixed constant. It differs from TensoRF by binding each tensor component to a specific input view, enabling robust point cloud fusion that substitutes inaccurate depth-derived points with accurate ones from other views. The approach uses Vector-Matrix (VM) decomposition for spatial factors and a global appearance dictionary to abstract commonalities across the scene.

### [Vector-Matrix-Matrix (VMM) Factorization](18288-vector-matrix-matrix-vmm-factorization.md)
Models radiance and geometry by decomposing feature probes into shared core factors and probe-specific basis factors. It distinguishes itself from standard CP decomposition by introducing a hybrid structure where a Vector-Matrix (VM) core captures multilinear interactions shared across local probes, while a Matrix (M) basis factor handles individual probe details, enabling efficient spatial sharing and multi-scale pyramid storage.

### [Multiscale Tensor Decomposition](19444-multiscale-tensor-decomposition.md)
Decomposes 3D tensors into plane and line features at multiple resolutions to reconstruct scenes from coarse to fine scales. It improves shape and appearance reconstruction accuracy and convergence speed over single-scale TensoRF while using fewer parameters. Unlike TensoRF, which performs decomposition at a single scale, MTD leverages multiscale representations to explore local smoothness at varying scales, allowing higher-resolution representations to capture richer details with fewer total parameters.

### Fourier-Bessel Kernel Tensor Decomposition
Initializes the shared basis $B$ with Fourier-Bessel (FB) bases for faster convergence, with the number of bases $r$ set to 6 by default [S2]. The bases $B$ are updated during training to make them specific to the scene [S2]. A smaller value of $r$ achieves a higher compression ratio [S2].

## Background
The Rank-Residual Decomposition models were introduced in "Compressible-Composable NeRF Via Rank-Residual Decomposition" [S1]. The work addresses the limitations of the standard TensoRF VM decomposition, which requires a fixed 1:1 ratio of vector- to matrix-based ranks, limiting flexibility in model size control [S1]. The HY decomposition allows arbitrary adjustment of this ratio, and the HY-S model provides a scalable range of model sizes without requiring retraining for optimal configurations [S1].
