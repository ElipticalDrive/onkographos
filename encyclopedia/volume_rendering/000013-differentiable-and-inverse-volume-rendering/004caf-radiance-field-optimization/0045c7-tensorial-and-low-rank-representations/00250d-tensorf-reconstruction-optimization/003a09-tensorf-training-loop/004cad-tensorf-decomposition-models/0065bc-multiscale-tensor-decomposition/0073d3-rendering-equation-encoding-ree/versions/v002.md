# Rendering Equation Encoding (REE)

Also called: Anisotropic Spherical Gaussian (ASG) Encoding, encode the rendering equation in the feature space

## Overview
Rendering Equation Encoding (REE) is a technique for modeling view-dependent effects by encoding the rendering equation directly into the feature space using predicted Anisotropic Spherical Gaussian (ASG) mixture parameters, rather than encoding view directions [S1]. Unlike standard NeRF approaches that use frequency or spherical harmonic encoding for view directions, REE allows the subsequent MLP to be aware of the underlying rendering physics, facilitating the learning of complex specular reflections [S1]. It builds on [Multiscale Tensor Decomposition](19444-multiscale-tensor-decomposition.md) by using the multiscale features to predict the physical parameters required for this encoding [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Spatial bottleneck feature vector $b$ (size 128) and a comprehensive feature vector $g$ formed by concatenating encoded feature vectors from $N$ samples [S1].
*   **Output:** Final color $c$ [S1].

**Data Structures:**
*   **Spatial Bottleneck Feature ($b$):** A vector of size 128 [S1].
*   **Feature Vector ($a_i$):** A vector of size 2 [S1].
*   **Parameters ($P$):** Predicted by the spatial MLP. Includes diffuse color $c_d$, specular weight $s$, surface normal $n$, spatial bottleneck $b$, ASG feature vectors $a_i$, and ASG bandwidths $\lambda_i, \mu_i$ for $i \in [0, N-1]$ [S1].

**Numbered Steps:**

1.  **Feature Aggregation:** Obtain the spatial bottleneck feature vector $b$ and the comprehensive feature vector $g$ from the multiscale tensor decomposition [S1]. The vector $g$ is formed by concatenating encoded feature vectors $g_i$ for all $N$ samples: $g = [g_0, g_1, ..., g_{N-1}]$ [S1].
2.  **Parameter Prediction:** Feed $b$ and $g$ into a spatial MLP to predict the parameter set $P = \{c_d, s, n, b, a_i, \lambda_i, \mu_i\}$ [S1]. The spatial MLP has 3 layers with 256 hidden units and ReLU activation [S1].
3.  **View Direction Reparameterization:** Reparameterize the view direction $\omega_o$ to align with the reflective direction [S1]. Let $d$ be the camera direction and $n$ be the surface normal predicted in Step 2 [S1]. Compute:
    $$ \omega_o = 2(d \cdot n)n - d $$
    This ensures $\omega_o$ aligns with the lobe direction $\omega_i$ for specular reflection [S1].
4.  **Sample Lobes:** Sample $N$ lobes on a unit sphere [S1]. In experiments, $N = 128$ (specifically $8 \times 16$) [S1]. For each sample $i$, define the primary axis $\omega_i = (\theta, \phi)$ [S1].
5.  **Define Orthonormal Axes:** For each $\omega_i$, define the tangent axis $\omega_{i\lambda} = (\theta + \pi/2)$ [S1]. Rotate $\omega_{i\lambda}$ around $\omega_i$ by $\pi/2$ using a quaternion operation to obtain the bi-tangent axis $\omega_{i\mu}$ [S1]. The axes $[\omega_i, \omega_{i\lambda}, \omega_{i\mu}]$ are predefined orthonormal axes satisfying $\omega_i \cdot \omega_{i\lambda} = \omega_i \cdot \omega_{i\mu} = \omega_{i\lambda} \cdot \omega_{i\mu} = 0$ [S1].
6.  **Compute Specular Feature Representation:** Calculate the feature representation of the specular integral $c'_s(\omega_o; x)$ using the ASG mixture model:
    $$ c'_s(\omega_o; x) = \sum_{i=0}^{N-1} a_i S(\omega_o; \omega_i) \exp\left(-\lambda_i (\omega_o \cdot \omega_{i\lambda})^2 - \mu_i (\omega_o \cdot \omega_{i\mu})^2\right) $$
    where $S(\omega_o; \omega_i) = \max(\omega_o \cdot \omega_i, 0)$, $a_i$ is the feature vector, and $\lambda_i, \mu_i > 0$ are the bandwidths [S1].
7.  **Predict Final Color:** Apply a directional MLP (6 layers, 256 hidden units, ReLU) to predict the specular color $c_s$ using the inputs $b$ and $g$ [S1]. The final color $c$ is computed as:
    $$ c = \text{Sigmoid}(c_d + s \odot c_s) $$
    where $\odot$ denotes element-wise multiplication [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import math

class REE:
    def __init__(self, N=128):
        self.N = N
        # Spatial MLP: 3 layers, 256 hidden units, ReLU [S1]
        self.spatial_mlp = nn.Sequential(
            nn.Linear(128 + N * 2, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU()
        )
        # Directional MLP: 6 layers, 256 hidden units, ReLU [S1]
        self.directional_mlp = nn.Sequential(
            nn.Linear(128 + N * 2, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 3)
        )

    def sample_lobes(self, N):
        """Sample N lobes and compute orthonormal axes [S1]."""
        phi = torch.rand(N) * 2 * math.pi
        cos_theta = torch.rand(N) * 2 - 1
        theta = torch.acos(cos_theta)
        
        omega_i = torch.stack([
            torch.sin(theta) * torch.cos(phi),
            torch.sin(theta) * torch.sin(phi),
            cos_theta
        ], dim=1)
        
        # Define tangent axis omega_i_lambda = (theta + pi/2) [S1]
        cos_theta_l = torch.cos(theta + math.pi / 2)
        sin_theta_l = torch.sin(theta + math.pi / 2)
        omega_i_lambda = torch.stack([
            sin_theta_l * torch.cos(phi),
            sin_theta_l * torch.sin(phi),
            cos_theta_l
        ], dim=1)
        
        # Rotate omega_i_lambda around omega_i by pi/2 to get omega_i_mu [S1]
        # For orthogonal unit vectors, cross product implements the pi/2 rotation [G]
        omega_i_mu = torch.cross(omega_i, omega_i_lambda, dim=1)
        return omega_i, omega_i_lambda, omega_i_mu

    def forward(self, b, g, d):
        # b: (128,), g: (N*2,), d: (3,) camera direction
        spatial_input = torch.cat([b, g], dim=0)
        spatial_out = self.spatial_mlp(spatial_input)
        
        # Unpack parameters P from spatial_out [G]
        # Assumed layout: cd(3), s(1), n(3), b(128), a_i(N*2), lambda_i(N), mu_i(N)
        offset = 0
        cd = spatial_out[offset:offset+3]; offset += 3
        s = spatial_out[offset:offset+1]; offset += 1
        n = spatial_out[offset:offset+3]; offset += 3
        b_pred = spatial_out[offset:offset+128]; offset += 128
        a_i = spatial_out[offset:offset+self.N*2].reshape(self.N, 2); offset += self.N*2
        lambda_i = spatial_out[offset:offset+self.N]; offset += self.N
        mu_i = spatial_out[offset:offset+self.N]; offset += self.N
        
        # Normalize normal for numerical stability [G]
        n = n / (torch.norm(n) + 1e-8)
        
        # Reparameterize view direction [S1]
        omega_o = 2 * torch.dot(d, n) * n - d
        
        # Sample lobes [S1]
        omega_i, omega_i_lambda, omega_i_mu = self.sample_lobes(self.N)
        
        # Compute ASG encoding [S1]
        dot_i = torch.sum(omega_o.unsqueeze(0) * omega_i, dim=1)
        S = torch.clamp(dot_i, min=0.0)
        dot_l = torch.sum(omega_o.unsqueeze(0) * omega_i_lambda, dim=1)
        exp_l = torch.exp(-lambda_i * dot_l ** 2)
        dot_m = torch.sum(omega_o.unsqueeze(0) * omega_i_mu, dim=1)
        exp_m = torch.exp(-mu_i * dot_m ** 2)
        
        weights = S * exp_l * exp_m
        c_prime_s = torch.sum(weights.unsqueeze(1) * a_i, dim=0)
        
        # Directional MLP predicts specular color cs [S1]
        directional_input = torch.cat([b, g], dim=0)
        cs = self.directional_mlp(directional_input)
        
        # Final color [S1]
        c = torch.sigmoid(cd + s * cs)
        return c
```

**Edge Cases and Pitfalls:**
*   **Precision:** The exponential terms in the ASG encoding can underflow if bandwidths $\lambda_i, \mu_i$ are large and dot products are small [G]. Ensure numerical stability in the exponential calculation.
*   **Boundary Conditions:** The reparameterization $\omega_o = 2(d \cdot n)n - d$ assumes $n$ is a unit vector [G]. Normalize $n$ if necessary.
*   **Degenerate Input:** The reparameterization of view direction depends on the accuracy of the predicted normal $n$ [S1]. If $d$ and $n$ are parallel, the reflection is straightforward. If they are orthogonal, the reflection direction is perpendicular to both [G]. The quaternion rotation for $\omega_{i\mu}$ requires $\omega_i$ and $\omega_{i\lambda}$ to be non-parallel [G]. Since $\omega_{i\lambda}$ is defined as $(\theta + \pi/2)$, it is orthogonal to $\omega_i$ on the sphere, so the cross product is well-defined [G].

## Operating characteristics
*   **Time Complexity:** The method involves sampling $N$ lobes and computing dot products and exponentials for each [S1]. With $N=128$, this is a constant overhead per point [S1]. The MLPs have fixed sizes (3 and 6 layers, 256 units) [S1].
*   **Memory Complexity:** The feature vectors $a_i$ (size 2) and bandwidths $\lambda_i, \mu_i$ (size 1) are stored for each lobe [S1]. The bottleneck $b$ is size 128 [S1].
*   **Performance:** The method uses 16 levels of multiscale tensor decomposition, with base resolution 16 and max resolution 512 [S1]. The number of feature channels is 4 for appearance and 2 for density [S1]. The spatial MLP has 3 layers, and the directional MLP has 6 layers, all with 256 hidden units [S1].
*   **Strengths:** Encodes the rendering equation in the feature space, making the MLP aware of rendering physics [S1]. Reduces the channels of the feature representation compared to direct color prediction [S1].
*   **Limitations:** Requires predicting additional parameters ($n, a_i, \lambda_i, \mu_i$) [S1]. The reparameterization of view direction depends on the accuracy of the predicted normal $n$ [S1].

## Background
Rendering Equation Encoding (REE) was proposed in the paper "Multiscale Tensor Decomposition and Rendering Equation Encoding for View Synthesis" (CVPR 2023) [S1]. It is part of the Neural Radiance Feature Field (NRFF) method, which combines multiscale tensor decomposition with learnable feature representations [S1]. The method addresses the limitation of standard NeRF approaches that encode view directions but neglect the rich information in the rendering equation [S1]. By encoding the rendering equation in the feature space, the method aims to better model complex view-dependent effects [S1].
