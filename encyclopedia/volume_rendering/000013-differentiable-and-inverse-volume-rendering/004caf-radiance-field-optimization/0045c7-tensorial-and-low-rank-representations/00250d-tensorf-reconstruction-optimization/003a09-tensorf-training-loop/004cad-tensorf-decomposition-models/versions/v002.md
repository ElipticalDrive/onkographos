# TensoRF Decomposition Models

Also called: CP model, HY model, HY-S model, Rank-Residual Decomposition Models (CP, HY-S)

## Overview
This family defines the factorization structures for the radiance field tensor in TensoRF, balancing storage efficiency against rendering quality by decomposing the 3D field into lower-rank components [S1]. Unlike the standard Vector-Matrix (VM) decomposition which enforces a fixed 1:1 ratio of vector to matrix ranks, these models allow arbitrary adjustment of this ratio, providing greater flexibility in model size control [S1].

## Shared principles
The core mechanism is Rank-Residual Decomposition [S1]. The radiance field is represented as a sum of groups, where each group contributes a specific rank to the overall factorization [S1]. This allows the model to start with a base configuration and incrementally add complexity (residuals) to improve quality without retraining from scratch [S1]. The decomposition separates the field into Density ($\sigma$) and Color ($c$) components [S1]. Each component is factorized into a set of basis vectors or matrices along the spatial axes [S1]. The total rank for a component is the sum of ranks contributed by the base group and any subsequent residual groups [S1]. Key parameters include vector-based ranks (1D basis vectors), matrix-based ranks (2D basis matrices), the number of additive groups ($M$), and the ratio of vector-based to matrix-based ranks [S1].

## Subtopics

### CP Model
The CP (Canonical Polyadic) model uses only vector-based rank components for both density and color [S1]. It minimizes storage footprint but requires higher total ranks to achieve comparable rendering quality, leading to increased GPU memory usage and slower querying speeds [S1].

* Configuration: Density uses 96 vector ranks, and color uses 384 vector ranks [S1]. Groups are set to $M=4$, with each group containing 96 color ranks [S1].
* When to choose: When storage is the primary constraint and query speed is less critical [S1].

### HY Model
The HY (Hybrid) model incorporates both vector- and matrix-based components [S1]. Matrix components consume more storage per rank but efficiently reduce the total number of ranks required for high quality, thereby lowering GPU memory usage compared to the CP model [S1].

* Configuration: Density uses 64 vector components and 16 matrix components [S1]. Color uses 256 vector components and 64 matrix components [S1]. Groups are set to $M=4$, with each group containing 64 vector components and 16 matrix components for color [S1].
* When to choose: When a balance between storage, memory usage, and rendering quality is needed [S1].

### HY-S Model
The HY-S (Hybrid-Scalable) model extends the HY structure to allow adjustable model size over a larger range [S1]. It starts with a base of vector components and gradually appends matrix components in subsequent groups [S1].

* Configuration: Density and color initially use 96 vector components [S1]. Four additional groups for color append matrix components with ranks $\{4, 16, 32, 64\}$ gradually [S1]. Total groups are $M=5$, where the first group has only 96 vector components and the subsequent four add matrix components [S1].
* When to choose: When flexible scaling of model capacity is required without retraining [S1].

### Comparison with VM Decomposition
The primary distinction between these models and the standard TensoRF VM decomposition is the rank ratio flexibility [S1]. VM decomposition requires a fixed 1:1 ratio of vector- to matrix-based ranks, limiting control over model size [S1]. The HY family allows arbitrary adjustment of this ratio, enabling more precise tuning of the trade-off between compression and quality [S1].

## Background
The Rank-Residual Decomposition models were introduced in "Compressible-Composable NeRF Via Rank-Residual Decomposition" [S1]. The work demonstrates that these methods reach near-optimal quality without needing retraining for optimal models, unlike baseline sort-and-truncate strategies [S1]. Training is typically performed for 30,000 iterations using the Adam optimizer with an initial learning rate of 0.02 for factorized matrices and 0.001 for singular values [S1].
