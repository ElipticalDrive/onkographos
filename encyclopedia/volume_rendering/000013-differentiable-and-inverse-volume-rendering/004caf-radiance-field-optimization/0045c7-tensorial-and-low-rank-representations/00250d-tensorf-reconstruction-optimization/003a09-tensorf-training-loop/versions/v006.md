# TensoRF Training Loop

Also called: TensoRF Optimization

## Overview
The TensoRF Training Loop is the iterative optimization procedure used to minimize the L2 rendering loss of a tensorial radiance field, using ground truth pixel colors as supervision [S1, unofficial]. It distinguishes itself from standard NeRF training by integrating specific regularization terms (orthogonal, L1 density, and Total Variation) and dynamic resolution updates via an alpha mask, which are critical for stabilizing the low-rank tensor decomposition [S1, unofficial]. It builds on [TensoRF Reconstruction Optimization](3453-tensorf-reconstruction-optimization.md).

## How it works

### Inputs and Outputs
**Inputs:**
*   Training dataset (images, poses, intrinsics) [S1, unofficial].
*   Model configuration parameters (see Parameters below) [S1, unofficial].
*   Optimizer (typically Adam) [S1, unofficial].

**Outputs:**
*   Optimized tensor factors (density and appearance) [S1, unofficial].
*   Rendered RGB, alpha, depth, and uncertainty maps for training batches [S1, unofficial].

### Data Structures
The model `tensorf` stores the radiance field as decomposed tensors. The specific layout depends on the [TensoRF Decomposition Models](13296-tensorf-decomposition-models.md) used (e.g., Vector-Matrix or Tri-Plane), but generally includes:
*   Density factors: Vectors/matrices representing the spatial density field [S1, unofficial].
*   Appearance factors: Vectors/matrices representing view-dependent color [S1, unofficial].
*   Positional Embeddings: Pre-computed or on-the-fly encoded position and view direction vectors (`pos_pe`, `view_pe`, `fea_pe`) [S1, unofficial].

### Parameters
*   `N_voxel_init`: Initial number of voxels for the feature grid [S1, unofficial].
*   `nSamples`: Number of samples per ray, calculated as `min(args.nSamples, cal_n_samples(reso_cur, args.step_ratio))` [S1, unofficial].
*   `lr_decay_target_ratio`: Target ratio for learning rate decay [S1, unofficial].
*   `Ortho_weight` (or `Ortho_reg_weight`): Weight for orthogonal regularization [S1, unofficial].
*   `L1_weight_inital`: Initial weight for L1 density regularization [S1, unofficial].
*   `TV_weight_density`: Initial weight for Total Variation (TV) density regularization [S1, unofficial].
*   `TV_weight_app`: Initial weight for TV appearance regularization [S1, unofficial]
*   `density_shift`: Shift applied to density values [S1, unofficial].
*   `alphaMask_thres`: Threshold for alpha mask updates [S1, unofficial].

### Steps
1.  **Initialization:** Load training and test data. Compute axis-aligned bounding box (`aabb`), near/far clipping planes (`near_far`), background flag (`white_bg`), and NDC ray coordinates if applicable [S1, unofficial]. Initialize the `tensorf` model with the configuration parameters [S1, unofficial]. Calculate the learning rate decay factor: `lr_factor = args.lr_decay_target_ratio**(1/args.lr_decay_iters)` [S1, unofficial].
2.  **Ray Filtering:** If not using NDC, filter rays to the bounding box: `allrays, allrgbs = tensorf.filtering_rays(allrays, allrgbs, bbox_only=True)` [S1, unofficial]. Initialize a `SimpleSampler` for batching [S1, unofficial].
3.  **Iteration Loop:**
    a.  **Sampling:** Get ray indices: `ray_idx = trainingSampler.nextids()`. Fetch rays and ground truth RGBs: `rays_train, rgb_train = allrays[ray_idx], allrgbs[ray_idx].to(device)` [S1, unofficial].
    b.  **Rendering:** Render the batch: `rgb_map, alphas_map, depth_map, weights, uncertainty = renderer(rays_train, tensorf, chunk=args.batch_size, N_samples=nSamples, white_bg=white_bg, ndc_ray=ndc_ray, device=device, is_train=True)` [S1, unofficial].
    c.  **Loss Computation:**
        *   Base Loss: `loss = torch.mean((rgb_map - rgb_train) ** 2)` [S1, unofficial].
        *   Orthogonal Regularization: If `Ortho_reg_weight > 0`, compute `loss_reg = tensorf.vector_comp_diffs()` and add `Ortho_reg_weight * loss_reg` to `total_loss` [S1, unofficial].
        *   L1 Density Regularization: If `L1_reg_weight > 0`, compute `loss_reg_L1 = tensorf.density_L1()` and add `L1_reg_weight * loss_reg_L1` to `total_loss` [S1, unofficial].
        *   TV Density Regularization: If `TV_weight_density > 0`, decay the weight by `lr_factor`, compute `loss_tv = tensorf.TV_loss_density(tvreg) * TV_weight_density`, and add to `total_loss` [S1, unofficial].
        *   TV Appearance Regularization: If `TV_weight_app > 0`, decay the weight by `lr_factor`, compute `loss_tv = tensorf.TV_loss_app(tvreg) * TV_weight_app`, and add to `total_loss` [S1, unofficial].
    d.  **Optimization:** Zero gradients, backpropagate, and step: `optimizer.zero_grad(); total_loss.backward(); optimizer.step()` [S1, unofficial].
    e.  **Learning Rate Update:** Update all parameter groups: `param_group['lr'] = param_group['lr'] * lr_factor` [S1, unofficial].
4.  **Evaluation and Updates:** Periodically evaluate test PSNR and log metrics [S1, unofficial]. If the current iteration is in `update_AlphaMask_list` and the current voxel count is less than $256^3$, update the volume resolution using the alpha mask [S1, unofficial].

### Pseudocode

```python
def train_tensorf(dataset, model_config, optimizer, num_iterations):
    # 1. Initialization
    aabb, near_far, white_bg, ndc_ray = dataset.get_aabb_and_params()
    tensorf = TensorFModel(**model_config)
    lr_factor = args.lr_decay_target_ratio ** (1 / args.lr_decay_iters)
    
    if not ndc_ray:
        allrays, allrgbs = tensorf.filtering_rays(dataset.allrays, dataset.allrgbs, bbox_only=True)
    else:
        allrays, allrgbs = dataset.allrays, dataset.allrgbs
        
    sampler = SimpleSampler(allrays)
    
    for iteration in range(num_iterations):
        # 2. Sampling
        ray_idx = sampler.nextids()
        rays_train = allrays[ray_idx].to(device)
        rgb_train = allrgbs[ray_idx].to(device)
        
        # 3. Rendering
        rgb_map, alphas_map, depth_map, weights, uncertainty = renderer(
            rays_train, tensorf, 
            chunk=args.batch_size, 
            N_samples=min(args.nSamples, cal_n_samples(tensorf.reso_cur, args.step_ratio)),
            white_bg=white_bg, 
            ndc_ray=ndc_ray, 
            device=device, 
            is_train=True
        )
        
        # 4. Loss Computation
        loss = torch.mean((rgb_map - rgb_train) ** 2)
        total_loss = loss
        
        if args.Ortho_reg_weight > 0:
            loss_reg = tensorf.vector_comp_diffs()
            total_loss += args.Ortho_reg_weight * loss_reg
            
        if args.L1_reg_weight > 0:
            loss_reg_L1 = tensorf.density_L1()
            total_loss += args.L1_reg_weight * loss_reg_L1
            
        if args.TV_weight_density > 0:
            tv_weight = args.TV_weight_density * lr_factor
            loss_tv = tensorf.TV_loss_density(tvreg) * tv_weight
            total_loss += loss_tv
            
        if args.TV_weight_app > 0:
            tv_weight = args.TV_weight_app * lr_factor
            loss_tv = tensorf.TV_loss_app(tvreg) * tv_weight
            total_loss += loss_tv
            
        # 5. Optimization
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
        
        # 6. LR Update
        for param_group in optimizer.param_groups:
            param_group['lr'] = param_group['lr'] * lr_factor
            
        # 7. Periodic Updates
        if iteration % eval_interval == 0:
            evaluate_test_psnr(dataset, tensorf)
            
        if iteration in update_AlphaMask_list and tensorf.voxel_count < 256**3:
            tensorf.update_alpha_mask()
```

### Edge Cases and Pitfalls
*   **Depth Supervision Limitations:** When using depth supervision, the improvement in PSNR may be minimal (e.g., 0.01 PSNR) because COLMAP key points are orders of magnitude fewer than color pixels, causing depth loss gradients to affect only a small portion of the voxel space [S2, unofficial].
*   **Low Data Performance:** Training with low data and low iterations (e.g., 2,500 iterations with 4x downsampling) results in significantly lower PSNR compared to full-data training [S2, unofficial].

## Subtopics

### [NeuManifold](9771-neumanifold.md)
NeuManifold is a three-stage pipeline for reconstructing neural watertight manifolds with efficient, high-quality rendering support. It solves the problem of generating high-fidelity 3D meshes from 2D images by combining the robust initialization of volume rendering with the geometric precision of differentiable rasterization. Unlike pure volumetric methods, it produces explicit triangle meshes; unlike pure mesh-based methods, it avoids the artifacts caused by linear interpolation in non-linear density fields by using a differentiable marching cubes algorithm.

### [Separable Component-Wise Convolution for Joint Pose Optimization](10576-separable-component-wise-convolution-for-joint-pose-optimiza.md)
This method enables robust joint optimization of camera poses and decomposed low-rank tensorial radiance fields by controlling the frequency spectrum of the scene representation. It prevents premature high-frequency signals in the voxel volume from causing camera poses to get stuck in local minima, a failure mode common in naive joint optimization. It sets itself apart from hash-encoding-based methods by specifically leveraging the separability of the input low-rank tensor signal, making it more efficient than traditional separable convolution kernels.

### [StyleTRF](11815-styletrf.md)
StyleTRF is a method for stylized view generation that decouples style adaptation from view capture by fine-tuning the appearance component of a pre-optimized Tensorial Radiance Field (TensoRF) using sparse stylized priors. It sets itself apart from joint optimization methods like SNeRF by freezing the geometric density parameters of the scene representation, thereby preserving crisp geometry while adapting appearance, and by using a deterministic CNN-based stylization module (Johnson et al.) to ensure 3D consistency across viewpoints.

### [TensoRF Decomposition Models](13296-tensorf-decomposition-models.md)
This family defines the factorization structures for the radiance field tensor in TensoRF, balancing storage efficiency against rendering quality by decomposing the 3D field into lower-rank components. Unlike the standard Vector-Matrix (VM) decomposition which enforces a fixed 1:1 ratio of vector to matrix ranks, these models allow arbitrary adjustment of this ratio, providing greater flexibility in model size control.

### [Coarse-to-fine feature grid](15277-coarse-to-fine-feature-grid.md)
A training optimization scheme that reduces initial training cost and regularizes feature representations by initializing a 3D feature grid at a coarse resolution and progressively upscaling it to higher resolutions. It improves model convergence and makes camera refinement more effective compared to training at full resolution from the start. Unlike static grid methods, this approach dynamically adapts the spatial detail of the feature representation during the optimization process.

### [Codec-Adaptive TriPlane Radiance Fields](17898-codec-adaptive-triplane-radiance-fields.md)
Codec-Adaptive TriPlane Radiance Fields (CATRF) is a compression framework for plane-factorized radiance fields that optimizes neural features directly in the decoded space of a standard video or image codec. It solves the problem of severe rendering degradation at low bitrates by integrating a real codec round-trip (JPEG, VP9, HEVC, or AV1) into the training loop via a Straight-Through Estimator (STE). Unlike Codec-Agnostic (CA) methods that compress features after training, or Learned-Codec-in-the-Loop (LCL) methods that require shipping scene-specific neural decoder parameters, CATRF adapts features to real codec distortions without introducing any learned codec parameters or entropy models.

### TensoRF Downsampling
Downsamples both train and test data by a factor of 4. Training iterations are reduced to 2,500 (vs. 30,000 in the original TensoRF paper) due to memory and time constraints. Tested on the synthetic Lego scene from the NeRF dataset with 100 training views and 200 test views [S2, unofficial].

### Depth Supervised TensoRF
Applies depth supervision loss during training. However, it suffers from low PSNR with low data and minimal improvement (0.01 PSNR) over non-depth supervised approaches because COLMAP key points are orders of magnitude fewer than color pixel comparisons, causing depth loss gradients to affect only a small portion of voxel space [S2, unofficial].

### TensoRF with PATA
Integrates Spiking Neural Networks (SNN) components. Parameters include: Maximum time step $T=8$, initial membrane time constant $\tau=2.0$, and firing threshold $0.5$. The spike-based color decoder receives 150-dimensional input on Synthetic-NeRF and 30-dimensional input on LLFF [S3, unofficial].

## Operating characteristics

### Time and Memory Complexity
*   **Memory:** The low-rank tensor decomposition significantly reduces memory usage compared to dense voxel grids or MLPs, scaling with the rank of the decomposition rather than the full 3D volume resolution [S1, unofficial].
*   **Time:** Training time is reduced by the efficiency of tensor operations and the coarse-to-fine grid updates. However, joint pose optimization or depth supervision may introduce additional computational overhead or require careful tuning to avoid local minima [S2, unofficial].

### Measured Performance
*   **Standard TensoRF:** Achieves high PSNR (e.g., ~29.92 test PSNR on Lego) with 30,000 iterations on full-resolution data [S2, unofficial].
*   **Downsampled TensoRF:** With 4x downsampling and 2,500 iterations, PSNR drops significantly (e.g., ~15.23 test PSNR on Lego) [S2, unofficial].
*   **Depth Supervised:** Shows minimal PSNR improvement (0.01) over non-depth supervised variants in low-data scenarios [S2, unofficial].

### Scaling
*   The method scales well with resolution due to the tensor decomposition, but performance is sensitive to the number of training views and iterations, especially in low-data regimes [S2, unofficial].

### Strengths and Limitations
*   **Strengths:** High rendering quality with lower memory footprint than NeRF; effective regularization techniques (Ortho, L1, TV) stabilize training; flexible decomposition models [S1, unofficial].
*   **Limitations:** Depth supervision is ineffective with sparse COLMAP points; low-data training yields poor results without sufficient iterations or data augmentation; joint pose optimization can be unstable without frequency control [S2, unofficial].

### When to Use
*   Use when memory is constrained but high-quality novel view synthesis is required [S1, unofficial].
*   Use when integrating with stylization (StyleTRF) or compression (CATRF) pipelines [S1, unofficial].

### When Not to Use
*   Avoid when depth accuracy is critical and ground truth depth is sparse (Depth Supervised TensoRF performs poorly) [S2, unofficial].
*   Avoid when training data is extremely limited and computational budget is very low (Downsampled TensoRF yields low PSNR) [S2, unofficial].

## Background
TensoRF was introduced in the ECCV 2022 paper "Tensorial Radiance Fields" [S1, unofficial]. It represents the radiance field as a tensor decomposed into lower-rank components, enabling efficient storage and rendering. The training loop incorporates specific regularizations to handle the low-rank constraints and dynamic resolution updates to refine the field during optimization [S1, unofficial]. Variants like NeuManifold, StyleTRF, and CATRF extend the base TensoRF framework for specific tasks like mesh extraction, stylization, and compression [S1, unofficial].
