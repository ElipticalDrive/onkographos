# TensoRF Training Loop

Also called: TensoRF Optimization

## Overview
The TensoRF Training Loop is the iterative optimization procedure used to minimize the L2 rendering loss of a tensorial radiance field by adjusting its low-rank tensor parameters [S1, unofficial]. It distinguishes itself from standard NeRF training by incorporating specific regularizations (orthogonal, L1 density, and Total Variation) tailored to the decomposed tensor structure, alongside dynamic voxel resolution updates via an alpha mask [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   Training dataset (images, poses, intrinsics) [S1, unofficial].
*   Model configuration parameters: `density_n_comp`, `appearance_n_comp`, `app_dim`, `near_far`, `shadingMode`, `alphaMask_thres`, `density_shift`, `distance_scale`, `pos_pe`, `view_pe`, `fea_pe`, `featureC`, `step_ratio`, `fea2denseAct` [S1, unofficial].
*   Optimization hyperparameters: `lr_decay_target_ratio`, `lr_decay_iters`, `Ortho_reg_weight`, `L1_reg_weight`, `TV_weight_density`, `TV_weight_app`, `batch_size`, `nSamples` [S1, unofficial].

**Outputs:**
*   Optimized tensor parameters for density and appearance fields [S1, unofficial].
*   Rendered images, alphas, depths, and weights for visualization/logging [S1, unofficial].

### Data Structures
The implementation relies on the following structures, derived from the source code [S1, unofficial]:

1.  **Ray Batch:**
    *   `rays_train`: Tensor of shape `(batch_size, 3)` representing ray origins and directions.
    *   `rgb_train`: Tensor of shape `(batch_size, 3)` representing ground truth pixel colors.
2.  **Model Parameters (`tensorf`):**
    *   Contains decomposed tensors for density and appearance.
    *   Specific fields accessed during regularization: `vector_comp_diffs` (for orthogonal loss), `density_L1` (for L1 loss), `TV_loss_density` and `TV_loss_app` (for TV losses) [S1, unofficial].
3.  **Sampler:**
    *   `SimpleSampler`: Manages ray index selection via `nextids()` [S1, unofficial].

### Numbered Steps

1.  **Initialization:**
    *   Load training and test data [S1, unofficial].
    *   Determine bounding box (`aabb`), near/far planes (`near_far`), background color assumption (`white_bg`), and NDC ray flag (`ndc_ray`) [S1, unofficial].
    *   Initialize the `tensorf` model with the specified configuration parameters [S1, unofficial].
    *   Calculate the learning rate decay factor:
        $$ lr\_factor = args.lr\_decay\_target\_ratio^{(1/args.lr\_decay\_its)} $$
        [S1, unofficial]
    *   If not using NDC rays, filter rays to the bounding box:
        `allrays, allrgbs = tensorf.filtering_rays(allrays, allrgbs, bbox_only=True)` [S1, unofficial].
    *   Initialize the `SimpleSampler` for ray batching [S1, unofficial].

2.  **Iteration Loop:**
    For each training iteration:
    1.  **Ray Sampling:**
        *   Get ray indices: `ray_idx = trainingSampler.nextids()` [S1, unofficial].
        *   Fetch rays and RGBs: `rays_train, rgb_train = allrays[ray_idx], allrgbs[ray_idx].to(device)` [S1, unofficial].
    2.  **Rendering:**
        *   Compute the number of samples per ray:
            $$ nSamples = \min(args.nSamples, cal\_n\_samples(reso\_cur, args.step\_ratio)) $$
            [S1, unofficial]
        *   Render the batch:
            `rgb_map, alphas_map, depth_map, weights, uncertainty = renderer(rays_train, tensorf, chunk=args.batch_size, N_samples=nSamples, white_bg=white_bg, ndc_ray=ndc_ray, device=device, is_train=True)` [S1, unofficial].
    3.  **Loss Computation:**
        *   Compute MSE loss:
            $$ loss = \text{mean}((rgb\_map - rgb\_train)^2) $$
            [S1, unofficial]
        *   Initialize `total_loss = loss` [S1, unofficial].
        *   **Orthogonal Regularization:** If `Ortho_reg_weight > 0`:
            $$ loss\_reg = tensorf.vector\_comp\_diffs() $$
            $$ total\_loss += Ortho\_reg\_weight \times loss\_reg $$
            [S1, unofficial]
        *   **L1 Density Regularization:** If `L1_reg_weight > 0`:
            $$ loss\_reg\_L1 = tensorf.density\_L1() $$
            $$ total\_loss += L1\_reg\_weight \times loss\_reg\_L1 $$
            [S1, unofficial]
        *   **TV Density Regularization:** If `TV_weight_density > 0`:
            *   Decay weight by `lr_factor`.
            *   Compute:
                $$ loss\_tv = tensorf.TV\_loss\_density(tvreg) \times TV\_weight\_density $$
                [S1, unofficial]
            *   Add to `total_loss`.
        *   **TV Appearance Regularization:** If `TV_weight_app > 0`:
            *   Decay weight by `lr_factor`.
            *   Compute:
                $$ loss\_tv = tensorf.TV\_loss\_app(tvreg) \times TV\_weight\_app $$
                [S1, unofficial]
            *   Add to `total_loss`.
    4.  **Optimization Step:**
        *   Zero gradients: `optimizer.zero_grad()` [S1, unofficial].
        *   Backpropagate: `total_loss.backward()` [S1, unofficial].
        *   Step optimizer: `optimizer.step()` [S1, unofficial].
    5.  **Learning Rate Update:**
        *   Update learning rate for all parameter groups:
            $$ param\_group['lr'] = param\_group['lr'] \times lr\_factor $$
            [S1, unofficial]
    6.  **Evaluation and Logging:**
        *   Periodically evaluate test PSNR and log metrics to TensorBoard [S1, unofficial].
    7.  **Alpha Mask Update:**
        *   If current iteration is in `update_AlphaMask_list` and current voxel count < $256^3$, update volume resolution [S1, unofficial].

### Pseudocode

```python
import torch
import torch.nn as nn

def train_tensorf_loop(dataset_config, model_config, optimizer_config):
    # 1. Initialization
    # Load data
    allrays, allrgbs = load_dataset(dataset_config)
    aabb, near_far, white_bg, ndc_ray = extract_scene_params(allrays, dataset_config)
    
    # Initialize model
    tensorf = TensoRFModel(model_config)
    tensorf.to(device)
    
    # Calculate LR decay
    lr_factor = args.lr_decay_target_ratio ** (1 / args.lr_decay_iters)
    
    # Filter rays if not NDC
    if not ndc_ray:
        allrays, allrgbs = tensorf.filtering_rays(allrays, allrgbs, bbox_only=True)
        
    # Initialize sampler
    trainingSampler = SimpleSampler(allrays)
    
    # Setup regularizations
    tvreg = TVLoss() # Assuming TVLoss class from source
    
    # 2. Iteration Loop
    for iteration in range(total_iterations):
        # Ray Sampling
        ray_idx = trainingSampler.nextids()
        rays_train = allrays[ray_idx].to(device)
        rgb_train = allrgbs[ray_idx].to(device)
        
        # Rendering
        nSamples = min(args.nSamples, cal_n_samples(tensorf.reso_cur, args.step_ratio))
        rgb_map, alphas_map, depth_map, weights, uncertainty = renderer(
            rays_train, tensorf, 
            chunk=args.batch_size, 
            N_samples=nSamples, 
            white_bg=white_bg, 
            ndc_ray=ndc_ray, 
            device=device, 
            is_train=True
        )
        
        # Loss Computation
        loss = torch.mean((rgb_map - rgb_train) ** 2)
        total_loss = loss
        
        # Orthogonal Regularization
        if args.Ortho_reg_weight > 0:
            loss_reg = tensorf.vector_comp_diffs()
            total_loss += args.Ortho_reg_weight * loss_reg
            
        # L1 Density Regularization
        if args.L1_reg_weight > 0:
            loss_reg_L1 = tensorf.density_L1()
            total_loss += args.L1_reg_weight * loss_reg_L1
            
        # TV Density Regularization
        if args.TV_weight_density > 0:
            current_tv_weight = args.TV_weight_density * lr_factor # Decay weight
            loss_tv = tensorf.TV_loss_density(tvreg) * current_tv_weight
            total_loss += loss_tv
            
        # TV Appearance Regularization
        if args.TV_weight_app > 0:
            current_tv_weight = args.TV_weight_app * lr_factor # Decay weight
            loss_tv = tensorf.TV_loss_app(tvreg) * current_tv_weight
            total_loss += loss_tv
            
        # Optimization Step
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
        
        # Learning Rate Update
        for param_group in optimizer.param_groups:
            param_group['lr'] = param_group['lr'] * lr_factor
            
        # Evaluation and Logging
        if iteration % eval_interval == 0:
            evaluate_test_set(tensorf, dataset_config)
            log_metrics(iteration, total_loss)
            
        # Alpha Mask Update
        if iteration in update_AlphaMask_list:
            if tensorf.current_voxel_count < 256**3:
                tensorf.update_volume_resolution()
```

### Parameters with Typical Values
*   `N_voxel_init`: Initial number of voxels. Not given in the sources.
*   `nSamples`: Number of samples per ray. Calculated as `min(args.nSamples, cal_n_samples(reso_cur, args.step_ratio))` [S1, unofficial].
*   `lr_decay_target_ratio`: Target learning rate ratio for decay. Not given in the sources.
*   `Ortho_reg_weight`: Weight for orthogonal regularization. Not given in the sources.
*   `L1_reg_weight`: Initial weight for L1 density regularization. Not given in the sources.
*   `TV_weight_density`: Initial weight for TV density regularization. Not given in the sources.
*   `TV_weight_app`: Initial weight for appearance regularization. Not given in the sources.

### Edge Cases and Pitfalls
*   **Depth Supervision Limitations:** When using depth supervision, low PSNR with low data is expected. The improvement over non-depth supervised approaches is minimal (0.01 PSNR) because COLMAP key points are orders of magnitude fewer than color pixel comparisons, causing depth loss gradients to affect only a small portion of the voxel space [S2, unofficial].
*   **Voxel Resolution:** The volume resolution is updated only if the current voxel count is less than $256^3$ during specific update iterations [S1, unofficial].

## Subtopics

### [NeuManifold](9771-neumanifold.md)
NeuManifold is a three-stage pipeline for reconstructing neural watertight manifolds with efficient, high-quality rendering support. It solves the problem of generating high-fidelity 3D meshes from 2D images by combining the robust initialization of volume rendering with the geometric precision of differentiable rasterization. Unlike pure volumetric methods, it produces explicit triangle meshes; unlike pure mesh-based methods, it avoids the artifacts caused by linear interpolation in non-linear density fields by using a differentiable marching cubes algorithm.

### [Separable Component-Wise Convolution for Joint Pose Optimization](10576-separable-component-wise-convolution-for-joint-pose-optimiza.md)
This method enables robust joint optimization of camera poses and decomposed low-rank tensorial radiance fields by controlling the frequency spectrum of the scene representation. It prevents premature high-frequency signals in the voxel volume from causing camera poses to get stuck in local minima, a failure mode common in naive joint optimization. It sets itself apart from hash-encoding-based methods by specifically leveraging the separability of the input low-rank tensor signal, making it more efficient than traditional separable convolution kernels.

### StyleTRF
StyleTRF is a method for stylized view generation that decouples style adaptation from view capture by fine-tuning the appearance component of a pre-optimized Tensorial Radiance Field (TensoRF) using sparse stylized priors [S1, unofficial]. It sets itself apart from joint optimization methods like SNeRF by freezing the geometric density parameters of the scene representation, thereby preserving crisp geometry while adapting appearance, and by using a deterministic CNN-based stylization module (Johnson et al.) to ensure 3D consistency across viewpoints [S1, unofficial].

### TensoRF Downsampling
Downsamples both train and test data by a factor of 4 [S2, unofficial]. Training iterations are reduced to 2,500 (vs. 30,000 in original TensoRF paper) due to memory and time constraints [S2, unofficial]. Tested on the synthetic Lego scene from the NeRF dataset [4] with 100 training views and 200 test views [S2, unofficial].

### Depth Supervised TensoRF
Applies depth supervision loss during training [S2, unofficial]. Pitfall: Low PSNR with low data. Minimal improvement (0.01 PSNR) over non-depth supervised approach because COLMAP key points are orders of magnitude fewer than color pixel comparisons, causing depth loss gradients to affect only a small portion of voxel space [S2, unofficial].

## Operating characteristics

*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:**
    *   Full Data TensoRF: Train PSNR 28.85, Test PSNR 29.92 [S2, unofficial].
    *   Low Data TensoRF: Train PSNR 26.32, Test PSNR 15.23 [S2, unofficial].
    *   Low Data TensoRF-DS: Train PSNR 29.93, Test PSNR 15.23 [S2, unofficial].
    *   Note: PSNR values for Low Data configurations were generated in 1000 iterations [S2, unofficial].
*   **Scaling:** Not given in the sources.
*   **Strengths:** Incorporates specific regularizations (orthogonal, L1, TV) tailored to tensor structure [S1, unofficial]. Supports dynamic voxel resolution updates [S1, unofficial].
*   **Limitations:** Depth supervision provides minimal improvement due to sparse keypoint data [S2, unofficial].
*   **When to use:** When optimizing tensorial radiance fields with specific regularization needs for density and appearance smoothness [S1, unofficial].
*   **When not to use:** When depth supervision is critical and data is sparse, as improvements are negligible [S2, unofficial].

## Background

*   **Origin:** The TensoRF method was introduced in the paper "Tensorial Radiance Fields" (ECCV 2022) [S1, unofficial].
*   **History:** The training loop described is based on the implementation provided in the GitHub repository `apchenstu/TensoRF` [S1, unofficial].
*   **Usage:** Used for reconstructing 3D scenes from 2D images using low-rank tensor decompositions [S1, unofficial].
