# TensoRF Training Loop

Also called: TensoRF Optimization

## Overview
The TensoRF Training Loop is the iterative optimization procedure used to minimize the L2 rendering loss of a tensorial radiance field, using ground truth pixel colors as supervision [S1, unofficial]. It distinguishes itself from standard NeRF training by incorporating specific regularization terms (orthogonal, L1 density, and Total Variation) tailored to the low-rank tensor decomposition structure, alongside a dynamic alpha mask update mechanism [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   Training dataset (images, poses, intrinsics) [S1, unofficial].
*   Model parameters: `density_n_comp`, `appearance_n_comp`, `app_dim`, `near_far`, `shadingMode`, `alphaMask_thres`, `density_shift`, `distance_scale`, `pos_pe`, `view_pe`, `fea_pe`, `featureC`, `step_ratio`, `fea2denseAct` [S1, unofficial].
*   Hyperparameters: `N_voxel_init` (initial voxel count), `nSamples` (samples per ray), `lr_decay_target_ratio`, `Ortho_weight`, `L1_weight_inital`, `TV_weight_density`, `TV_weight_app` [S1, unofficial].

**Outputs:**
*   Optimized tensor factors representing the radiance field [S1, unofficial].
*   Rendered RGB maps, alphas, depths, weights, and uncertainty estimates [S1, unofficial].

### Data Structures
*   **Rays:** Stored as tensors `allrays` and `allrgbs`. If NDC is not used, rays are filtered using `tensorf.filtering_rays` with `bbox_only=True` [S1, unofficial].
*   **Sampler:** `SimpleSampler` manages ray batching via `nextids()` [S1, unofficial].
*   **Model:** `tensorf` object containing the decomposed tensor components [S1, unofficial].
*   **Renderer:** `renderer` function that takes rays, model, chunk size, and sampling parameters to produce outputs [S1, unofficial].

### Numbered Steps

1.  **Initialization:** Load train/test data. Determine `aabb`, `near_far`, `white_bg`, and `ndc_ray` flags [S1, unofficial]. Initialize the `tensorf` model with the specified parameters [S1, unofficial].
2.  **Learning Rate Setup:** Calculate the per-iteration decay factor:
    $$ lr\_factor = args.lr\_decay\_target\_ratio^{(1/args.lr\_decay\_its)} $$
    [S1, unofficial]
3.  **Ray Filtering:** If not using NDC, filter rays to the bounding box:
    ```python
    allrays, allrgbs = tensorf.filtering_rays(allrays, allrgbs, bbox_only=True)
    ```
    [S1, unofficial]
4.  **Iteration Loop:** For each iteration:
    a.  **Sample Rays:** Get ray indices and fetch data:
        ```python
        ray_idx = trainingSampler.nextids()
        rays_train, rgb_train = allrays[ray_idx], allrgbs[ray_idx].to(device)
        ```
        [S1, unofficial]
    b.  **Render:** Compute the rendering output:
        ```python
        rgb_map, alphas_map, depth_map, weights, uncertainty = renderer(
            rays_train, tensorf, chunk=args.batch_size, 
            N_samples=nSamples, white_bg=white_bg, 
            ndc_ray=ndc_ray, device=device, is_train=True
        )
        ```
        [S1, unofficial]
    c.  **Compute Base Loss:** Calculate Mean Squared Error (MSE):
        $$ loss = \text{mean}((rgb\_map - rgb\_train)^2) $$
        [S1, unofficial]
    d.  **Regularization:**
        *   **Orthogonal:** If `Ortho_reg_weight > 0`:
            $$ loss\_reg = tensorf.vector\_comp\_diffs() $$
            $$ total\_loss += Ortho\_reg\_weight \times loss\_reg $$
            [S1, unofficial]
        *   **L1 Density:** If `L1_reg_weight > 0`:
            $$ loss\_reg\_L1 = tensorf.density\_L1() $$
            $$ total\_loss += L1\_reg\_weight \times loss\_reg\_L1 $$
            [S1, unofficial]
        *   **TV Density:** If `TV_weight_density > 0`:
            Decay weight by `lr_factor`. Compute:
            $$ loss\_tv = tensorf.TV\_loss\_density(tvreg) \times TV\_weight\_density $$
            Add to `total_loss` [S1, unofficial].
        *   **TV Appearance:** If `TV_weight_app > 0`:
            Decay weight by `lr_factor`. Compute:
            $$ loss\_tv = tensorf.TV\_loss\_app(tvreg) \times TV\_weight\_app $$
            Add to `total_loss` [S1, unofficial].
    e.  **Backpropagation:**
        ```python
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
        ```
        [S1, unofficial]
    f.  **Learning Rate Update:**
        ```python
        for param_group in optimizer.param_groups:
            param_group['lr'] = param_group['lr'] * lr_factor
        ```
        [S1, unofficial]
5.  **Evaluation:** Periodically evaluate test PSNR and log metrics to TensorBoard [S1, unofficial].
6.  **Alpha Mask Update:** If the current iteration is in `update_AlphaMask_list` and the current voxel count is less than $256^3$, update the volume resolution [S1, unofficial].

### Pseudocode

```python
# Initialization
dataset = load_dataset()
tensorf = initialize_tensorf(
    density_n_comp=args.density_n_comp,
    appearance_n_comp=args.appearance_n_comp,
    app_dim=args.app_dim,
    near_far=args.near_far,
    shadingMode=args.shadingMode,
    alphaMask_thres=args.alphaMask_thres,
    density_shift=args.density_shift,
    distance_scale=args.distance_scale,
    pos_pe=args.pos_pe,
    view_pe=args.view_pe,
    fea_pe=args.fea_pe,
    featureC=args.featureC,
    step_ratio=args.step_ratio,
    fea2denseAct=args.fea2denseAct
)

# Learning rate setup
lr_factor = args.lr_decay_target_ratio ** (1.0 / args.lr_decay_iters)

# Ray filtering
if not ndc_ray:
    allrays, allrgbs = tensorf.filtering_rays(allrays, allrgbs, bbox_only=True)

sampler = SimpleSampler()

for iteration in range(total_iterations):
    # 1. Sample Rays
    ray_idx = sampler.nextids()
    rays_train = allrays[ray_idx].to(device)
    rgb_train = allrgbs[ray_idx].to(device)
    
    # 2. Render
    rgb_map, alphas_map, depth_map, weights, uncertainty = renderer(
        rays_train, tensorf, 
        chunk=args.batch_size, 
        N_samples=min(args.nSamples, cal_n_samples(reso_cur, args.step_ratio)),
        white_bg=white_bg, 
        ndc_ray=ndc_ray, 
        device=device, 
        is_train=True
    )
    
    # 3. Base Loss
    loss = torch.mean((rgb_map - rgb_train) ** 2)
    total_loss = loss
    
    # 4. Regularization
    if Ortho_reg_weight > 0:
        loss_reg = tensorf.vector_comp_diffs()
        total_loss += Ortho_reg_weight * loss_reg
        
    if L1_reg_weight > 0:
        loss_reg_L1 = tensorf.density_L1()
        total_loss += L1_reg_weight * loss_reg_L1
        
    if TV_weight_density > 0:
        tvreg = ... # TV regularization object/state
        loss_tv = tensorf.TV_loss_density(tvreg) * TV_weight_density
        total_loss += loss_tv
        TV_weight_density *= lr_factor # Decay weight
        
    if TV_weight_app > 0:
        loss_tv = tensorf.TV_loss_app(tvreg) * TV_weight_app
        total_loss += loss_tv
        TV_weight_app *= lr_factor # Decay weight
        
    # 5. Backpropagation
    optimizer.zero_grad()
    total_loss.backward()
    optimizer.step()
    
    # 6. Update Learning Rate
    for param_group in optimizer.param_groups:
        param_group['lr'] *= lr_factor
        
    # 7. Alpha Mask Update
    if iteration in update_AlphaMask_list:
        if current_voxel_count < 256**3:
            update_volume_resolution()
            
    # 8. Evaluation
    if iteration % eval_interval == 0:
        evaluate_test_psnr()
        log_to_tensorboard()
```

### Parameters
*   `N_voxel_init`: Initial number of voxels [S1, unofficial].
*   `nSamples`: Number of samples per ray, calculated as $\min(args.nSamples, cal\_n\_samples(reso\_cur, args.step\_ratio))$ [S1, unofficial].
*   `lr_decay_target_ratio`: Target learning rate ratio for decay [S1, unofficial].
*   `Ortho_weight`: Weight for orthogonal regularization [S1, unofficial].
*   `L1_weight_inital`: Initial weight for L1 density regularization [S1, unofficial].
*   `TV_weight_density`: Initial weight for TV density regularization [S1, unofficial].
*   `TV_weight_app`: Initial weight for appearance regularization [S1, unofficial].

### Edge Cases and Pitfalls
*   **Alpha Mask Resolution:** The volume resolution update is conditional on the voxel count being less than $256^3$ [S1, unofficial].
*   **TV Weight Decay:** TV regularization weights decay by `lr_factor` at each step where they are applied [S1, unofficial].
*   **NDC Filtering:** Ray filtering is skipped if NDC rays are used [S1, unofficial].

## Subtopics

### [NeuManifold](9771-neumanifold.md)
NeuManifold is a three-stage pipeline for reconstructing neural watertight manifolds with efficient, high-quality rendering support. It solves the problem of generating high-fidelity 3D meshes from 2D images by combining the robust initialization of volume rendering with the geometric precision of differentiable rasterization. Unlike pure volumetric methods, it produces explicit triangle meshes; unlike pure mesh-based methods, it avoids the artifacts caused by linear interpolation in non-linear density fields by using a differentiable marching cubes algorithm.

### [Separable Component-Wise Convolution for Joint Pose Optimization](10576-separable-component-wise-convolution-for-joint-pose-optimiza.md)
This method enables robust joint optimization of camera poses and decomposed low-rank tensorial radiance fields by controlling the frequency spectrum of the scene representation. It prevents premature high-frequency signals in the voxel volume from causing camera poses to get stuck in local minima, a failure mode common in naive joint optimization. It sets itself apart from hash-encoding-based methods by specifically leveraging the separability of the input low-rank tensor signal, making it more efficient than traditional separable convolution kernels.

### [StyleTRF](11815-styletrf.md)
StyleTRF is a method for stylized view generation that decouples style adaptation from view capture by fine-tuning the appearance component of a pre-optimized Tensorial Radiance Field (TensoRF) using sparse stylized priors. It sets itself apart from joint optimization methods like SNeRF by freezing the geometric density parameters of the scene representation, thereby preserving crisp geometry while adapting appearance, and by using a deterministic CNN-based stylization module (Johnson et al.) to ensure 3D consistency across viewpoints.

### [TensoRF Decomposition Models](13296-tensorf-decomposition-models.md)
This family defines the factorization structures for the radiance field tensor in TensoRF, balancing storage efficiency against rendering quality by decomposing the 3D field into lower-rank components. Unlike the standard Vector-Matrix (VM) decomposition which enforces a fixed 1:1 ratio of vector to matrix ranks, these models allow arbitrary adjustment of this ratio, providing greater flexibility in model size control.

### [Coarse-to-fine feature grid](15277-coarse-to-fine-feature-grid.md)
A training optimization scheme that reduces initial training cost and regularizes feature representations by initializing a 3D feature grid at a coarse resolution and progressively upscaling it to higher resolutions. It improves model convergence and makes camera refinement more effective compared to training at full resolution from the start. Unlike static grid methods, this approach dynamically adapts the spatial detail of the feature representation during the optimization process.

### TensoRF Downsampling
Downsamples both train and test data by a factor of 4. Training iterations are reduced to 2,500 (vs. 30,000 in original TensoRF paper) due to memory and time constraints. Tested on the synthetic Lego scene from the NeRF dataset with 100 training views and 200 test views [S2, unofficial].

### Depth Supervised TensoRF
Applies depth supervision loss during training. A key pitfall is low PSNR with low data. Minimal improvement (0.01 PSNR) over non-depth supervised approach because COLMAP key points are orders of magnitude fewer than color pixel comparisons, causing depth loss gradients to affect only a small portion of voxel space [S2, unofficial].

### TensoRF with PATA
Uses spike-based modules. TensoRF T: Maximum time step set to 8. Initial membrane time constant $\tau = 2.0$. Firing threshold = 0.5. TensoRF Input Dimensions: Spike-based color decoder receives 150-dimensional input on Synthetic-NeRF and 30-dimensional input on LLFF [S3, unofficial].

## Background
The TensoRF Training Loop originates from the TensoRF paper (ECCV 2022) [S1, unofficial]. It is used in conjunction with various extensions such as NeuManifold, Joint Pose Optimization, StyleTRF, and PATA [S1, S2, S3, unofficial].
