# LOD Generation
Also called: Hierarchical LOD creation
## Overview
LOD Generation creates multiple levels of detail from a trained finest-resolution radiance field model to reduce resource usage for distant scene blocks while maintaining high-quality rendering from elevated viewpoints [S1]. It avoids the prohibitive cost and appearance inconsistency of retraining the entire scene from scratch at lower resolutions [S1]. By leveraging the compressibility of rank-residual models, it also enables dynamic LOD adjustment per object to balance rendering quality and storage/performance in composed scenes [S2].

## How it works
The method operates on a scene decomposed into blocks (e.g., voxels or triplanes) with an associated deferred MLP. It generates coarser LODs by merging fine-grained blocks and adapting the query function.

**Inputs:**
*   Trained finest-resolution model consisting of submodels (query functions $f^k$) and a shared deferred MLP $\Phi$.
*   Scene geometry divided into $M \times M$ blocks.
*   Virtual grid storing rendering attributes (simulated during training) [S1].

**Outputs:**
*   A hierarchy of LOD models, where LOD $l$ consists of merged blocks and adapted parameters.
*   Baked texture assets for rendering [S1].

**Data Structures:**
*   **Virtual Grid:** Stores rendering attributes (density, color features) for each block. Resolution is downsampled by a factor of 2 for each LOD level [S1].
*   **Submodels:** Contain the frozen query function $f^k$ for each block or merged block group [S1].
*   **Deferred MLP ($\Phi^{k,l}$):** A shared MLP retrained for each LOD level $l$ to map the downsampled features to final radiance [S1].

**Steps:**
1.  **Virtual Grid Simulation:** During the initial training of the finest LOD, simulate a virtual grid to store rendering attributes for each block, similar to the MERF approach [S1].
2.  **Block Merging:** To generate LOD $l$, merge $2^l \times 2^l$ fine blocks into a single coarser block. For LOD 1, this involves merging $2 \times 2$ blocks [S1].
3.  **Grid Downsampling:** Downsample the resolution of the virtual grid within each merged block by a factor of 2 relative to the previous LOD level [S1].
4.  **Freeze Query Function:** Freeze the training of the query function $f^k$ within the submodels corresponding to the merged blocks. This preserves the learned spatial features without retraining them from scratch [S1].
5.  **Retrain Deferred MLP:** Retrain a new shared deferred MLP $\Phi^{k,l}$ across the merged blocks. This MLP adapts to the lower-resolution voxels and triplanes resulting from the downsampling [S1].
6.  **Joint Optimization:** Jointly optimize the frozen submodels and the newly trained deferred MLP $\Phi^{k,l}$ to ensure consistency and quality at the lower resolution [S1].
7.  **Baking (Optional):** For LOD $l$, bake the $2^l \times 2^l$ merged blocks into a single texture asset. This allows a single shader to render the entire merged region during inference [S1].

*   **Appearance Consistency:** Retraining from scratch for extrapolated views causes inconsistency. This method mitigates it by freezing query functions [S1].
*   **Resource Usage:** Distant blocks should use higher LODs to save resources [S1].
*   **Baking Threshold:** Samples with opacity and weight values above a certain threshold are retained during baking to ensure quality [S1].

## Subtopics

### Dynamic Level of Detail (LOD) Adjustment
A scene composition technique that dynamically adjusts the model size (LOD) per object to balance rendering quality and storage/performance, leveraging the compressibility of rank-residual models [S2]. It assigns the full model to primary objects requiring high detail and truncates the model to a smaller LOD for secondary/scaled-down objects [S2]. This allows composing objects in a scene using their respective LODs. For example, a high LOD model size of 68.9 MB can be reduced to 1.5 MB for a low LOD model, demonstrated on bulldozer objects from nerf-synthetic composed into a barn scene from Tanks And Temples [S2].

## Operating characteristics
*   **Time Complexity:** Generating LODs is significantly faster than retraining from scratch, as it freezes query functions and only retrains the deferred MLP [S1].
*   **Memory Complexity:** Higher LODs use less memory due to downsampled virtual grids and merged blocks [S1]. Dynamic LOD adjustment can reduce model size from 68.9 MB to 1.5 MB [S2].
*   **Performance:** Enables real-time rendering of large-scale scenes on the web by reducing resource usage for distant blocks [S1].
*   **Strengths:** Avoids retraining from scratch; maintains appearance consistency; supports dynamic scene composition [S1, S2].
*   **Limitations:** Requires initial training with a virtual grid simulation [S1]. Quality may degrade if the deferred MLP is not properly optimized [S1].

## Background
LOD Generation was introduced in the context of real-time neural rendering of large-scale scenes on the web [S1]. It addresses the challenge of rendering large scenes captured from aerial or top-down perspectives, where appearance consistency across models trained separately is difficult to ensure [S1]. The method builds on the principles of tensorial and low-rank representations, specifically utilizing the compressibility of rank-residual models [S2].
