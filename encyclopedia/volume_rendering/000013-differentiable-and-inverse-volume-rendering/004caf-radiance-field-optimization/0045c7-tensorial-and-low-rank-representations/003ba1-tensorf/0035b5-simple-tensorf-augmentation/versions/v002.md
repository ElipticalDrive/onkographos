# Simple-TensoRF Augmentation

Also called: Augmented TensoRF, Low Data TensoRF, Simple-TensoRF

## Overview
Simple-TensoRF Augmentation is a regularization method for [TensoRF](3026-tensorf.md) designed to mitigate overfitting and geometric distortions (such as floaters and incorrect object placement) when training with sparse input views [S2]. The method consists of two coupled models: a **Main Model** (standard TensoRF) and an **Augmented Model** (Simple-TensoRF) [S2]. The Augmented Model is trained with reduced capacity to prevent it from learning complex, noisy artifacts [S2]. Its predicted depth is then used to regularize the Main Model [S2]. Unlike vanilla TensoRF or simple depth-supervised variants (DS-TensoRF), this approach explicitly constrains the model capacity to force simpler solutions, significantly improving depth estimation accuracy and view-synthesis quality in few-shot scenarios [S2].

## How it works

### Inputs and Outputs
*   **Inputs:** Sparse set of input images (e.g., 3 views) and their camera poses [S2].
*   **Outputs:**
    *   Main Model: High-quality rendered images and accurate depth maps [S2].
    *   Augmented Model: Regularized depth maps used for supervision [S2].

### Data Structures
The method builds on the TensoRF tensor factorization structure [S2].

**Main Model Parameters:**
*   Density Tensor Components ($R_\sigma$): Number of rank-1 components for density [S2].
*   Color Tensor Components ($R_c$): Number of rank-1 components for color features [S2].
*   Grid Resolution ($N_{vox}$): Resolution of the voxel grid for tensor decomposition [S2].
*   Bounding Box ($b$): Defined as $b = (b_{x1}, b_{x2}, b_{y1}, b_{y2}, b_{z1}, b_{z2})$ [S2].
*   MLP Depth ($D$): Depth of the small MLP for color decoding [S2].
*   View-dependent layers ($l_v$): Number of view-dependent layers [S2].

**Augmented Model Parameters:**
*   Density Components ($R_{\sigma s}$): Reduced number of components [S2].
*   Grid Resolution ($N_{vox}^s$): Reduced voxel grid resolution [S2].
*   Bounding Box Z-min ($b_{zs1}$): Increased (shifted inward) Z-min to exclude near-camera artifacts [S2].
*   Mass Concentration Intervals ($N_{mc}$): Number of intervals for entropy loss [S2].
*   Depth Supervision Parameters ($k, \epsilon_\tau$): Used to filter reliable depth estimates [S2].

### Numbered Steps
1.  **Initialize Models:** Initialize Main TensoRF with full capacity parameters and Augmented TensoRF with reduced capacity parameters [S2].
2.  **Preprocessing:** Downsample training and test datasets by a factor of 4 [S1, unofficial].
3.  **Augmented Model Training:** Train the Augmented Model concurrently with the Main Model. Apply the **Mass Concentration Loss** ($L_{mc}$) to encourage hard object surfaces and reduce cloudy volumes [S2]. The loss is calculated by grouping ray samples into $N_{mc}$ intervals and minimizing the entropy of the mass within each interval [S2].
4.  **Depth Reliability Filtering:** Compute depth estimates from the Augmented Model. Filter these depths to identify "reliable" estimates by checking consistency with the closest training view [S2]. Regions visible in only one training view may lack reliable supervision, leading to persistent transparent floaters [S2].
5.  **Main Model Training:** Train the Main Model using the standard photometric loss ($L_m$) and the depth supervision loss ($L_{aug}$) derived from the Augmented Model's reliable depth estimates [S2]. Enable the augmentation loss $L_{aug}$ after 5,000 iterations [S2]. The total loss for the Main Model includes photometric, depth supervision, sparse depth, mass concentration, and consistency terms [S2].
6.  **Optimization:** Use the Adam Optimizer. Train for a total of 25,000 iterations on a single GPU [S2].

### Pseudocode
```python
import math

class TensoRFModel:
    """Simplified representation of the TensoRF radiance field."""
    def __init__(self, R_sigma, R_color, N_vox, b, D, l_v):
        self.R_sigma = R_sigma
        self.R_color = R_color
        self.N_vox = N_vox
        self.b = b
        self.D = D
        self.l_v = l_v
    def forward(self, rays):
        # Returns density, color, depth, and weights for each ray.
        # Implementation details of tensor factorization are in [TensoRF](3026-tensorf.md).
        return self._query(rays)

class Optimizer:
    def __init__(self, params, lr):
        self.params = params
        self.lr = lr
    def zero_grad(self):
        pass # Framework handles gradient clearing
    def step(self):
        pass # Framework handles gradient update
    def update_lr(self, new_lr):
        self.lr = new_lr

def downsample_data(data, factor):
    # Standard downsampling by taking every `factor`-th pixel/voxel
    return data[::factor]

def compute_photometric_loss(predicted_color, target_color):
    # Mean squared error between predicted and target RGB values [G]
    return math.mean((predicted_color - target_color) ** 2)

def compute_depth_supervision_loss(predicted_depth, reliable_depth):
    # Mean squared error between predicted depth and reliable depth estimates [G]
    return math.mean((predicted_depth - reliable_depth) ** 2)

def check_depth_consistency(depth, rays, k, epsilon_tau):
    # Filters depth based on consistency with the closest training view [S2]
    # Returns a mask of valid depths where consistency check passes
    # Implementation details are in [S2] Sec 4.1.4
    return depth # Returns depth where valid, NaN otherwise

def adjust_learning_rate(optimizer, iteration, initial_lr, final_lr, total_iterations):
    # Linear decay from initial_lr to final_lr over total_iterations [G]
    progress = iteration / total_iterations
    new_lr = initial_lr + (final_lr - initial_lr) * progress
    optimizer.update_lr(new_lr)

def sample_rays(images, poses):
    # Standard ray generation from camera poses and image grid
    return type('RayBatch', (), {'target_color': None, 'target_depth': None, 'has_target_depth': False})()

def train_simple_tensorf(input_images, camera_poses, num_iterations=25000):
    # 1. Initialize Main Model (Full Capacity)
    main_model = TensoRFModel(
        R_sigma=24, R_color=72, N_vox=640**3,
        b=(-1.5, 1.5, -1.67, 1.67, -1.0, 1.0), D=27, l_v=0
    )
    # 2. Initialize Augmented Model (Reduced Capacity)
    aug_model = TensoRFModel(
        R_sigma=12, R_color=72, N_vox=160**3,
        b=(-1.5, 1.5, -1.67, 1.67, -0.5, 1.0), D=27, l_v=0
    )

    # Optimizers (Tensor params LR=2e-2, MLP params LR=1e-3 initially [S2])
    opt_main = Optimizer(main_model_params, lr=2e-2)
    opt_aug = Optimizer(aug_model_params, lr=2e-2)

    # Hyperparameters
    N_mc = 5
    k = 5
    epsilon_tau = 0.1
    lambda_m = 1.0
    lambda_aug = 0.1
    lambda_sd = 0.1
    lambda_mc = 0.01
    lambda_cfc = 0.0

    # Downsample data by factor of 4 [S1, unofficial]
    input_images = downsample_data(input_images, factor=4)
    camera_poses = downsample_data(camera_poses, factor=4)

    for iteration in range(1, num_iterations + 1):
        # Sample rays from input images
        rays = sample_rays(input_images, camera_poses)

        # --- Augmented Model Forward Pass ---
        aug_density, aug_color, aug_depth, weights = aug_model.forward(rays)

        # Photometric Loss for Augmented Model
        L_m_aug = compute_photometric_loss(aug_color, rays.target_color)

        # Mass Concentration Loss (L_mc)
        L_mc = compute_mass_concentration_loss(aug_density, weights, N_mc)

        # Total Loss for Augmented Model
        loss_aug = L_m_aug + lambda_mc * L_mc

        # Update Augmented Model
        opt_aug.zero_grad()
        loss_aug.backward()
        opt_aug.step()

        if iteration > 5000:
            # Filter reliable depths from Augmented Model
            reliable_depth = check_depth_consistency(aug_depth, rays, k, epsilon_tau)

            # --- Main Model Forward Pass ---
            main_density, main_color, main_depth, main_weights = main_model.forward(rays)

            # Photometric Loss for Main Model
            L_m_main = compute_photometric_loss(main_color, rays.target_color)

            # Depth Supervision Loss using Augmented Model's reliable depth
            L_aug = compute_depth_supervision_loss(main_depth, reliable_depth)

            # Sparse Depth Loss (if external depth available)
            L_sd = compute_depth_supervision_loss(main_depth, rays.target_depth) if rays.has_target_depth else 0.0

            # Total Loss for Main Model
            loss_main = (lambda_m * L_m_main +
                         lambda_aug * L_aug +
                         lambda_sd * L_sd +
                         lambda_cfc * 0.0)

            # Update Main Model
            opt_main.zero_grad()
            loss_main.backward()
            opt_main.step()

        # Learning Rate Decay
        adjust_learning_rate(opt_main, iteration, 2e-2, 2e-3, num_iterations)
        adjust_learning_rate(opt_aug, iteration, 1e-3, 1e-4, num_iterations)

def compute_mass_concentration_loss(density, weights, N_mc):
    """
    Computes the mass concentration loss.
    Groups N samples along a ray into N_mc intervals.
    Minimizes entropy of the normalized mass in each interval [S2].
    """
    N = len(weights)
    interval_size = N // N_mc
    total_entropy = 0.0

    for j in range(1, N_mc + 1):
        start_idx = (j - 1) * interval_size
        end_idx = j * interval_size

        # Get weights in this interval
        interval_weights = weights[start_idx:end_idx]

        # Normalize weights by the fraction of total samples in interval
        normalized_weights = [w / (N / N_mc) for w in interval_weights]

        # Compute Entropy H(w) = sum(-w * log(w))
        interval_entropy = 0.0
        for w in normalized_weights:
            if w > 0:
                interval_entropy -= w * math.log(w)

        total_entropy += interval_entropy

    return total_entropy
```

### Parameters and Typical Values
*   **Main Model:** $R_\sigma = 24$, $R_c = 72$, $N_{vox} = 640^3$, $b = (-1.5, 1.5, -1.67, 1.67, -1.0, 1.0)$, $D = 27$, $l_v = 0$ [S2].
*   **Augmented Model:** $R_{\sigma s} = 12$, $N_{vox}^s = 160^3$, $b_{zs1} = -0.5$, $N_{mc} = 5$, $k = 5$, $\epsilon_\tau = 0.1$ [S2].
*   **Optimizer:** Adam. Initial LR: $2 \times 10^{-2}$ (tensor), $1 \times 10^{-3}$ (MLP). Final LR: $2 \times 10^{-3}$ (tensor), $1 \times 10^{-4}$ (MLP) [S2].
*   **Loss Weights:** $\lambda_m = 1$, $\lambda_a = 1$, $\lambda_{sd} = 0.1$, $\lambda_{aug} = 0.1$, $\lambda_{mc} = 0.01$, $\lambda_{cfc} = 0$ [S2].
*   **Training Duration:** 25,000 iterations on NVIDIA RTX 2080 Ti 11GB [S2].
*   **Data:** Downsampled by factor of 4 [S1, unofficial].

### Edge Cases and Pitfalls
*   **Block Artifacts:** Reducing only the grid resolution ($N_{vox}$) allows the model to learn sharp changes in density ($\sigma$) at voxel edges, causing block artifacts. Reducing only the number of components ($R_\sigma$) causes small, completely opaque floaters. Both must be reduced together to achieve smoothing [S2].
*   **Near-Camera Distortions:** Reducing the bounding box size (specifically $b_{z1}$) helps mitigate objects incorrectly placed close to the camera. However, applying this reduction to the *main* model can distort objects that are truly close to the camera. It is applied only to the augmented model [S2].
*   **Transparent Floaters:** Significant transparent floaters may persist in the main model, particularly in regions visible in only one training view. The mass concentration loss ($L_{mc}$) does not completely remove these transparent objects [S2].
*   **Training Time:** Simple-TensoRF takes approximately twice the training time of vanilla TensoRF because it employs a single augmented model with the same number of queries as the main model [S2].

## Operating characteristics
*   **Time Complexity:** Training time is approximately double that of vanilla TensoRF due to the parallel training of the augmented model [S2].
*   **Memory Complexity:** The augmented model uses a smaller grid ($160^3$ vs $640^3$) and fewer components ($12$ vs $24$), but the total memory usage is higher than a single TensoRF model due to the presence of two models [S2].
*   **Measured Performance:**
    *   On NeRF-LLFF (3 views): LPIPS 0.2461, SSIM 0.6749, PSNR 20.22, Depth MAE 0.17, Depth SROCC 0.83 [S2].
    *   On RealEstate-10K (3 views): LPIPS 0.0706, SSIM 0.8920, PSNR 32.70, Depth MAE 0.22, Depth SROCC 0.80 [S2].
*   **Strengths:** Significantly improves depth estimation accuracy and reduces floaters compared to vanilla TensoRF and DS-TensoRF. Effective for sparse input scenarios.
*   **Limitations:** Does not completely eliminate transparent floaters. Training time is increased. Reducing capacity too much may lead to sub-optimal solutions in regions requiring sharp depth discontinuities [S2].
*   **When to Use:** When training TensoRF with very few input views (e.g., 3-10 views) and depth accuracy is critical.
*   **When Not to Use:** When computational resources are extremely limited (due to 2x training time) or when the scene contains many transparent objects that require specialized handling beyond mass concentration.

## Background
Simple-TensoRF is part of the "Simple Radiance Fields" (Simple-RF) family, introduced by Nagabhushan Somraj, Sai Harsha Mupparaju, Adithyan Karanayil, and Rajiv Soundararajan in the paper "Simple-RF: Regularizing Sparse Input Radiance Fields with Simpler Solutions" [S2]. The method addresses the issue of shape-radiance ambiguity and floater artifacts that arise when factorized tensor models like TensoRF are trained on sparse data. It builds on the observation that reducing model capacity (components and resolution) forces the network to learn simpler, more regularized solutions, which can then be used to supervise a higher-capacity model [S2].
