# HexPlane
## Overview
HexPlane is an explicit representation for dynamic 3D scenes that decomposes a 4D spacetime grid into six learned feature planes spanning pairs of coordinate axes (e.g., XY, ZT) [S2]. It solves the memory and data-sparsity challenges of dynamic novel view synthesis by replacing implicit MLPs with a factorized structure that shares information across timesteps, achieving training speeds over 100× faster than implicit baselines like DyNeRF while matching image quality [S2]. Unlike [TensoRF](3026-tensorf.md) which uses vector-matrix decomposition for static 3D volumes, HexPlane extends this to 4D by pairing spatial planes with spatio-temporal planes to capture entangled space-time dynamics [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of posed images with timestamps $\{(I_k, \mathbf{c}_k, t_k)\}$, where $\mathbf{c}_k$ is the camera pose and $t_k$ is the time [S2].
*   **Outputs:** A radiance field model capable of rendering novel views at arbitrary poses and times [S2].

**Data Structures:**
The representation consists of two HexPlanes (one for opacity, one for appearance features) and a small MLP [S2].
1.  **HexPlane:** Defined by six feature planes (matrices) and three fusion matrices [S2].
    *   Six planes: $\mathbf{M}^{XY}, \mathbf{M}^{XZ}, \mathbf{M}^{YZ}$ (spatial) and $\mathbf{M}^{XT}, \mathbf{M}^{YT}, \mathbf{M}^{ZT}$ (spatio-temporal) [S2].
    *   Dimensions: $\mathbf{M}^{XY} \in \mathbb{R}^{N_x \times N_y}$, $\mathbf{M}^{XT} \in \mathbb{R}^{N_x \times N_t}$, etc. $N_x, N_y, N_z$ are spatial resolutions; $N_t$ is temporal resolution [S2].
    *   Fusion Matrices: $\mathbf{V}^{R_1 F}, \mathbf{V}^{R_2 F}, \mathbf{V}^{R_3 F}$ where $R_i$ is the rank and $F$ is the feature dimension [S2].
2.  **MLP:** A tiny multi-layer perceptron taking appearance features, position, and view direction to output RGB color [S2].
3.  **Emptiness Voxel:** A tiny 3D voxel grid indicating empty regions, computed by taking the maximum opacity across all time steps [S2].

**Query Function:**
For a 4D point $(x, y, z, t)$, the feature vector $\mathbf{f} \in \mathbb{R}^F$ is computed by projecting the point onto the six planes, aggregating the six resulting feature vectors, and multiplying by the fusion matrices [S2]. The formula is:

$$
D(x, y, z, t) = (\mathbf{P}_{xy\bullet}^{XYR_1} \odot \mathbf{P}_{xt\bullet}^{ZTR_1}) \mathbf{V}^{R_1F} + (\mathbf{P}_{xz\bullet}^{XZR_2} \odot \mathbf{P}_{yt\bullet}^{YTR_2}) \mathbf{V}^{R_2F} + (\mathbf{P}_{yz\bullet}^{YZR_3} \odot \mathbf{P}_{xt\bullet}^{XTR_3}) \mathbf{V}^{R_3F}
$$

Where:
*   $\mathbf{P}_{xy\bullet}^{XYR_1}$ is a vector of size $R_1$ obtained by bilinearly interpolating the plane $\mathbf{M}^{XY}$ at $(x,y)$ [S2].
*   $\mathbf{P}_{xt\bullet}^{ZTR_1}$ is a vector of size $R_1$ obtained by bilinearly interpolating the plane $\mathbf{M}^{ZT}$ at $(z,t)$ [S2].
*   $\odot$ denotes element-wise multiplication [S2].
*   $\mathbf{V}^{R_1F}$ is a matrix of size $R_1 \times F$ [S2].

**Training Pipeline:**
1.  **Initialization:** Start with low spatial resolution (e.g., $32^3$ or $64^3$) [S2].
2.  **Coarse-to-Fine:** Gradually upsample the grid resolution at specific iterations (e.g., doubling at 70k, 140k, 210k iterations for Plenoptic Video) [S2].
3.  **Emptiness Voxel Update:** Periodically compute the emptiness voxel by evaluating opacities across time and taking the maximum [S2].
4.  **Sampling:** Use importance sampling (e.g., global-median-based or temporal-difference-based) to sample points along rays [S2].
5.  **Rendering:** Perform differentiable volume rendering using the queried opacity and color [S2].
6.  **Loss:** Minimize photometric loss plus regularization:
    $$
    \mathcal{L} = \frac{1}{|\mathcal{R}|} \sum_{\mathbf{r} \in \mathcal{R}} \|C(\mathbf{r}) - \hat{C}(\mathbf{r})\|_2^2 + \lambda_{reg} \mathcal{L}_{reg}
    $$
    Where $\mathcal{L}_{reg}$ includes Total Variation (TV) loss on planes and depth smooth loss [S2].

**Pseudocode:**

```python
import numpy as np

def bilinear_interpolate(grid, u, v):
    """
    Perform bilinear interpolation on a 2D grid.
    grid: shape (H, W)
    u, v: float coordinates in [0, 1]
    Returns: interpolated value
    """
    h, w = grid.shape
    u_idx = u * (w - 1)
    v_idx = v * (h - 1)
    
    u0 = int(np.floor(u_idx))
    v0 = int(np.floor(v_idx))
    u1 = np.clip(u0 + 1, 0, w - 1)
    v1 = np.clip(v0 + 1, 0, h - 1)
    u0 = np.clip(u0, 0, w - 1)
    v0 = np.clip(v0, 0, h - 1)
    
    w_u = u_idx - u0
    w_v = v_idx - v0
    
    val = (1 - w_u) * (1 - w_v) * grid[v0, u0] + \
          (1 - w_u) * w_v * grid[v1, u0] + \
          w_u * (1 - w_v) * grid[v0, u1] + \
          w_u * w_v * grid[v1, u1]
    return val

def query_hexplane(x, y, z, t, planes, fusion_matrices):
    """
    Query the HexPlane representation for a 4D point.
    x, y, z, t: float coordinates in [0, 1]
    planes: dict containing P_XY, P_XZ, P_YZ, P_XT, P_YT, P_ZT
            Each tensor has shape (Dim1, Dim2, R_i)
    fusion_matrices: list of [V1, V2, V3] where Vi is shape (R_i, F)
    Returns: feature vector of shape (F,)
    """
    # Term 1: XY and ZT planes
    vec_xy = np.array([bilinear_interpolate(planes['P_XY'][:,:,r], x, y) for r in range(planes['P_XY'].shape[2])])
    vec_zt = np.array([bilinear_interpolate(planes['P_ZT'][:,:,r], z, t) for r in range(planes['P_ZT'].shape[2])])
    fused_1 = vec_xy * vec_zt
    term_1 = fused_1 @ fusion_matrices[0]
    
    # Term 2: XZ and YT planes
    vec_xz = np.array([bilinear_interpolate(planes['P_XZ'][:,:,r], x, z) for r in range(planes['P_XZ'].shape[2])])
    vec_yt = np.array([bilinear_interpolate(planes['P_YT'][:,:,r], y, t) for r in range(planes['P_YT'].shape[2])])
    fused_2 = vec_xz * vec_yt
    term_2 = fused_2 @ fusion_matrices[1]
    
    # Term 3: YZ and XT planes
    vec_yz = np.array([bilinear_interpolate(planes['P_YZ'][:,:,r], y, z) for r in range(planes['P_YZ'].shape[2])])
    vec_xt = np.array([bilinear_interpolate(planes['P_XT'][:,:,r], x, t) for r in range(planes['P_XT'].shape[2])])
    fused_3 = vec_yz * vec_xt
    term_3 = fused_3 @ fusion_matrices[2]
    
    return term_1 + term_2 + term_3

def sample_points_along_ray(origin, direction, n_samples, t_near=0.0, t_far=1.0):
    """
    Linearly sample points along a ray. Standard implementation [G].
    """
    t_vals = np.linspace(t_near, t_far, n_samples)
    points = origin + t_vals[:, np.newaxis] * direction
    return points

def mlp_decoder(features, point, view_dir):
    """Tiny MLP decoder [G]."""
    x = np.concatenate([features, point, view_dir])
    h = np.maximum(0, x @ np.ones((x.shape[0], 16)))
    return h @ np.ones((16, 3))

def render_ray(ray_origin, ray_direction, t, opacity_planes, opacity_fusion, appearance_planes, appearance_fusion, n_samples):
    """
    Volume render a single ray.
    """
    points = sample_points_along_ray(ray_origin, ray_direction, n_samples)
    
    opacities = []
    appearances = []
    
    for p in points:
        x, y, z = p
        op_feat = query_hexplane(x, y, z, t, opacity_planes, opacity_fusion)
        sigma = op_feat[0]
        opacities.append(sigma)
        
        if sigma > 0.1:
            ap_feat = query_hexplane(x, y, z, t, appearance_planes, appearance_fusion)
            appearances.append(ap_feat)
        else:
            appearances.append(np.zeros(3))
            
    colors = []
    for i, p in enumerate(points):
        if len(appearances) > i and np.linalg.norm(appearances[i]) > 0:
            color = mlp_decoder(appearances[i], p, ray_direction)
            colors.append(color)
        else:
            colors.append(np.zeros(3))
            
    # Standard volume rendering compositing [G]
    alphas = 1.0 - np.exp(np.array(opacities))
    transmittance = np.cumprod(1.0 - alphas)
    weights = alphas * np.concatenate([[1.0], transmittance[:-1]])
    final_color = np.sum(np.array(colors) * weights[:, np.newaxis], axis=0)
    return final_color
```

**Parameters:**
*   **Spatial Resolution ($N$):** Typically $128^3$ to $512^3$ [S2].
*   **Temporal Resolution ($T$):** Typically 32 to 300 [S2].
*   **Rank ($R$):** Number of basis functions. Typical values: 8, 12, 16, 24, 48, 96. Larger $R$ improves quality but increases memory and computation; too large causes overfitting [S2].
    *   Plenoptic Video Appearance: $R_1=48, R_2=24, R_3=24$ [S2].
    *   Plenoptic Video Opacity: $R_1=24, R_2=12, R_3=12$ [S2].
    *   D-NeRF Appearance: $R_1=R_2=R_3=48$ [S2].
    *   D-NeRF Opacity: $R_1=R_2=R_3=24$ [S2].
*   **Learning Rate:** $0.02$ for feature planes, $0.001$ for MLP/VRF [S2].
*   **Optimizer:** Adam ($\beta_1=0.9, \beta_2=0.99$) [S2].

**Edge Cases and Pitfalls:**
*   **Unbounded Scenes:** HexPlane is limited to bounded scenes because grid sampling fails for out-of-boundary points [S2].
*   **Fast Motion:** Degraded results occur when objects move too fast or observations are too sparse [S2].
*   **Color Jittering:** Explicit representations are prone to artifacts; strong regularization (TV loss) is required [S2].
*   **NDC Artifacts:** Using Normalized Device Coordinates (NDC) assumes bounded $x,y$ and can cause artifacts at extreme views [S2].

## Subtopics

### Serial 4D Feature Volumes
A dynamic scene representation consisting of a series of feature volumes, one for each gear level $G$, instead of a unified 4D volume [S4]. Each gear describes regions of a certain scale of motion, while purely spatial features are shared [S4]. The feature vector for gear $G$ at space-time coordinate $(x,t)$ is computed as $f^G(x, t) = B_1(h_1(x, y) \odot k^G_1(z, t)) + B_2(h_2(x, z) \odot k^G_2(y, t)) + B_3(h_3(y, z) \odot k^G_3(x, t))$, where $h_j$ are shared spatial embedding functions, $k^G_j$ are gear-specific spatio-temporal embeddings, and $B_j$ are shared linear transforms [S4]. A continuous gear score is computed via $g(x, t) = 1^\top (h'_1(x, y) \odot k'_1(z, t)) + 1^\top (h'_2(x, z) \odot k'_2(y, t)) + 1^\top (h'_3(y, z) \odot k'_3(x, t))$ [S4]. Typical parameters are $M=32$ for the spatio-temporal embedding dimension and $N_{\text{gear}}=4$ gear levels [S4].

## Operating characteristics
*   **Memory Complexity:** Reduced from $O(N^3 T F)$ to $O(N^2 R + N T R + R F)$ [S2]. For $N=512, T=32, F=3$, a naive 4D volume requires 48GB, while HexPlane requires only ~200MB [S2].
*   **Time Complexity:** Querying requires six bilinear interpolations and vector-matrix products, making it significantly faster than MLP-based methods [S2].
*   **Performance:** On the Plenoptic Video dataset, HexPlane achieves 29.47 PSNR in 12 GPU hours (112× speedup over DyNeRF) [S2]. With fewer iterations (100k), it achieves 29.26 PSNR in 2 GPU hours (672× speedup) [S2]. On D-NeRF, it achieves 31.04 PSNR in 11 minutes [S2].
*   **Strengths:** High efficiency, low memory footprint, no need for deformation fields, robust to various fusion mechanisms and coordinate systems [S2].
*   **Limitations:** Limited to bounded scenes (unless spherical coordinates are used), sensitive to sparse observations and fast motion, requires strong regularization to avoid artifacts [S2].

## Background
HexPlane was introduced by Ang Cao and Justin Johnson from the University of Michigan, Ann Arbor, in January 2023 [S2]. It was developed to address the limitations of implicit representations (like T-NeRF and DyNeRF) which are slow due to numerous MLP evaluations and struggle with memory usage for dynamic scenes [S2]. The method builds on the principles of tensor decomposition used in [TensoRF](3026-tensorf.md) but adapts them for 4D spacetime by using paired spatial and spatio-temporal feature planes [S2].
