# NeRF-XL Joint Training

Also called: Distributed NeRF, Multi-GPU NeRF, NeRF-XL

## Overview
NeRF-XL is a method for distributing Neural Radiance Fields across multiple GPUs by allocating NeRF parameters across a disjoint set of spatial regions and training them jointly, enabling arbitrarily large capacity without the redundancy and blending artifacts of independent training [S1]. Unlike sibling methods such as BlockNeRF and MegaNeRF which rely on overlapping regions and post-hoc blending, NeRF-XL uses 0% overlap and a single unified optimization process, eliminating train-test discrepancies and per-camera embedding inconsistencies [S1].

## How it works
**Inputs:**
*   $N$ training images with known camera poses and intrinsics [G].
*   A scene bounding box partitioned into $K$ disjoint spatial regions, one per GPU [S1].
*   A NeRF architecture (MLP) with parameters $\theta_k$ assigned to region $k$ [S1].

**Outputs:**
*   Optimized NeRF parameters $\{\theta_1, \dots, \theta_K\}$ for each region [S1].
*   A single set of per-camera embeddings (appearance/pose) optimized jointly [S1].

**Data Structures:**
*   **Region Assignment:** A mapping from 3D coordinates to GPU ID based on disjoint bounding boxes [S1]. Each GPU $k$ stores parameters $\theta_k$ for its tile [S1].
*   **Per-Camera Embeddings:** A global list of embeddings, one per training image, shared across all GPUs [S1].
*   **Sample Buffer:** For each ray, a list of samples $(t_i, \mathbf{x}_i, \mathbf{c}_i, \sigma_i, T_i)$ along the ray segment within the scene bounding box [G].

**Numbered Steps:**

1.  **Partitioning:** Divide the 3D scene bounding box into $K$ disjoint, non-overlapping spatial regions. Assign each region to a distinct GPU $k \in \{1, \dots, K\}$ [S1].
2.  **Forward Pass (Local Evaluation):** For a given training image and its corresponding ray: determine the intersection of the ray with the global bounding box and sample points $\mathbf{x}_i$ along the ray [G]. For each sample $\mathbf{x}_i$, identify the GPU $k$ responsible for the region containing $\mathbf{x}_i$ [S1]. On GPU $k$, evaluate the local NeRF $\theta_k$ at $\mathbf{x}_i$ using the global per-camera embedding for the current image to obtain local color $\mathbf{c}_i$ and density $\sigma_i$ [S1].
3.  **Broadcast:** Collect the $(\mathbf{c}_i, \sigma_i)$ pairs from all GPUs. Broadcast these sample values to all GPUs so that every GPU possesses the complete set of samples for the ray [S1].
4.  **Global Volume Rendering:** On each GPU, perform standard front-to-back volume rendering using the global set of samples to compute the final pixel color $\mathbf{C}$ and transmittance [S1]. The rendering equation is:
    $$C(t_n \rightarrow t_f) = \int_{t_n}^{t_f} T(t_n \rightarrow t) \sigma(t) c(t) dt, \quad T(t_n \rightarrow t) = \exp\left(-\int_{t_n}^t \sigma(s) ds\right)$$
    where $T$ is transmittance, $\sigma$ is density, and $c$ is color [S1]. (Discrete approximation is standard [G].)
5.  **Loss Computation:** Compute the photometric loss and the distortion loss $\mathcal{L}_{dist}$ on each GPU. The distortion loss is calculated as:
    $$\mathcal{L}_{dist}(t_n \rightarrow t_f) = \int_{t_n}^{t_f} w(t_i)w(t_j) |t_i - t_j| \, dt_i \, dt_j$$
    where $w(t) = T(t_n \rightarrow t)\sigma(t)$ is the volume rendering weight [S1].
6.  **Backward Pass (Local Gradient):** Compute gradients for the local NeRF parameters $\theta_k$ and the global per-camera embeddings locally on each GPU. No gradient synchronization is required between GPUs during the backward pass [S1].
7.  **Parameter Update:** Update the local parameters $\theta_k$ locally on each GPU. Update the shared per-camera embeddings using standard distributed optimization techniques [G].

**Pseudocode:**

```python
import math

# Global state
num_gpus = K
camera_embeddings = [Embedding() for _ in range(num_images)]
nerf_params = [MLP() for _ in range(num_gpus)]
region_bounds = [Box(min_i, max_i) for i in range(num_gpus)]
lr = 0.001

def sample_ray(origin, direction, num_samples):
    t_vals = [i / num_samples for i in range(num_samples)]
    return [Point(t=t, x=origin + direction * t) for t in t_vals]

def get_gpu_for_point(point, region_bounds):
    for k, box in enumerate(region_bounds):
        if box.contains(point.x):
            return k
    return 0

def volume_render(samples):
    T = 1.0
    color = [0.0, 0.0, 0.0]
    prev_t = samples[0].t
    for sample in samples:
        delta = max(1e-6, sample.t - prev_t)
        alpha = 1.0 - math.exp(-sample.sigma * delta)
        for d in range(3):
            color[d] += T * alpha * sample.color[d]
        T *= (1.0 - alpha)
        sample.T = T
        prev_t = sample.t
    return color

def compute_distortion_loss(samples):
    loss = 0.0
    for i in range(len(samples)):
        for j in range(len(samples)):
            t_i = samples[i].t
            t_j = samples[j].t
            w_i = samples[i].T * samples[i].sigma
            w_j = samples[j].T * samples[j].sigma
            delta_i = max(1e-6, t_i - (samples[i-1].t if i > 0 else 0))
            delta_j = max(1e-6, t_j - (samples[j-1].t if j > 0 else 0))
            loss += w_i * w_j * abs(t_i - t_j) * delta_i * delta_j
    return loss

def forward_pass(ray_origin, ray_direction, image_idx, ground_truth_color):
    samples = sample_ray(ray_origin, ray_direction, num_samples=M)
    local_samples = [[] for _ in range(num_gpus)]

    for point in samples:
        gpu_id = get_gpu_for_point(point, region_bounds)
        color, density = nerf_params[gpu_id].forward(point.x, camera_embeddings[image_idx])
        local_samples[gpu_id].append(Point(t=point.t, x=point.x, color=color, sigma=density))

    all_samples = []
    for gpu_samples in local_samples:
        all_samples.extend(gpu_samples)
    all_samples.sort(key=lambda x: x.t)

    final_color = volume_render(all_samples)
    photometric_loss = sum((final_color[d] - ground_truth_color[d])**2 for d in range(3))
    distortion_loss = compute_distortion_loss(all_samples)
    return final_color, photometric_loss, distortion_loss

def backward_pass(photometric_loss, distortion_loss):
    total_loss = photometric_loss + distortion_loss
    grads_camera = compute_gradients(camera_embeddings, total_loss)
    for gpu_id in range(num_gpus):
        local_grads = compute_gradients(nerf_params[gpu_id], total_loss)
        for param in nerf_params[gpu_id].parameters:
            param -= lr * local_grads[param]
    for emb in camera_embeddings:
        for param in emb.parameters:
            param -= lr * grads_camera[param]
```

**Parameters:**
*   **Overlap:** 0% (Disjoint regions) [S1].
*   **Number of GPUs:** Scales with scene size; demonstrated on Matrix-City with multiple GPUs [S1].

**Edge Cases and Pitfalls:**
*   **Boundary Artifacts:** Independent training of disjoint NeRFs leads to inconsistent per-camera embeddings (appearance and pose) across GPUs, causing color and geometry inconsistencies at boundaries [S1]. Joint training eliminates this by optimizing a single set of embeddings [S1].
*   **Blending Artifacts:** Methods using overlap (e.g., BlockNeRF, MegaNeRF) require 2D or 3D blending, which introduces blur and artifacts due to deviations in the volume rendering equation [S1]. NeRF-XL avoids this entirely [S1].

## Operating characteristics
*   **Time Complexity:** Training time scales with the number of GPUs due to reduced per-GPU workload, but communication overhead exists in the forward pass for broadcasting samples [S1].
*   **Memory Complexity:** Each GPU stores only its local NeRF parameters and a subset of the scene, allowing for arbitrarily large model capacity limited only by the sum of GPU memories [S1].
*   **Performance:** Demonstrates multi-GPU scaling laws, improving reconstruction quality with larger parameter counts and rendering speed with more GPUs [S1].
*   **Strengths:** Eliminates blending artifacts; no train-test discrepancy; handles large-scale scenes (e.g., 25km²) with high detail [S1].
*   **Limitations:** Requires forward-pass synchronization (broadcasting samples), which can be a bottleneck if bandwidth is limited [S1].
*   **When to use:** Large-scale scenes requiring high capacity and detail, where blending artifacts of independent training are unacceptable [S1].

## Background
NeRF-XL was introduced to address the limitations of independent multi-GPU NeRF training methods like BlockNeRF and MegaNeRF, which suffer from blending artifacts and inconsistent embeddings [S1]. It is the first method to reveal multi-GPU scaling laws for NeRFs, showing that joint training of disjoint NeRFs improves quality and speed [S1]. It has been applied to large datasets including Matrix-City (258K images, 25km²), street scans, and drone flyovers [S1].
