# ExBluRF

Also called: Efficient Radiance Fields for Extreme Motion Blurred Images

## Overview
ExBluRF is a novel view synthesis method designed to reconstruct sharp 3D scenes from extreme motion-blurred images by jointly optimizing voxel-based radiance fields and 6-DOF camera trajectories [S1]. It distinguishes itself from sibling methods like [FastNeRF](7183-fastnerf.md) and [C-NeRF](7275-c-nerf.md), which focus on static scene acceleration, by addressing the ill-posed problem of deblurring through a trajectory-based blur model and memory-efficient voxel representations, unlike [DeblurNeRF](7183-fastnerf.md) which relies on spatially varying 2D kernels and MLPs [S1].

## How it works
**Inputs:** A set of $V$ extremely motion-blurred images $\{I_v\}_{v=1}^V$ with known initial camera poses (extrinsics $R_v, K_v$) and shutter times $[\tau_o, \tau_c]$.
**Outputs:** A voxel-based radiance field (density $\sigma$ and color $\mathbf{c}$) and optimized 6-DOF camera trajectories for each view.

**Data Structures:**
1.  **Voxel Grid:** A 3D tensor storing volumetric features. Each cell contains density $\sigma$ and color $\mathbf{c}$. This replaces the MLP $f_{NeRF}$ used in standard NeRF [G].
2.  **Bézier Curve Parameters:** Control points $\{\hat{\mathbf{p}}_j\}_{j=0}^M$ in the Lie algebra $\mathfrak{se}(3)$ defining the camera trajectory for each view. $M$ is the order of the curve.
3.  **Ray Batch:** A batch of $B$ rays, each defined by origin and direction.

**Numbered Steps:**

1.  **Trajectory Reparameterization:** For each view $v$, reparameterize the 6-DOF camera motion trajectory using an $M$-th order Bézier curve in $\mathfrak{se}(3)$ [S1]. The sub-frame camera pose $\mathbf{p}_{\tau_i}$ at normalized time $\tau'_i$ is computed as:
    $$
    \mathbf{p}_{\tau_i} = \sum_{j=0}^{M} \binom{M}{j} (1-\tau'_i)^{M-j} (\tau'_i)^j \cdot \hat{\mathbf{p}}_j
    $$
    where $\tau'_i = \frac{\tau_i - \tau_o}{\tau_c - \tau_o}$ and $\tau_i = \tau_o + \frac{i-1}{N-1}(\tau_c - \tau_o)$ for $i=1 \dots N$ [S1]. The pose $\mathbf{p}_{\tau_i}$ is exponentiated to $SE(3)$ to obtain the transformation matrix $P_{\tau_i}$ [S1].

2.  **Ray Generation:** For each training iteration, for each blurry input image $v$, generate $N$ rays corresponding to intermediate shutter times $\tau_i$ along the estimated trajectory [S1]. For a pixel $\mathbf{x}$, the ray direction $\mathbf{d}_{\tau_i}$ is:
    $$
    \mathbf{d}_{\tau_i} = R_{\tau_i} \cdot K^{-1} [\mathbf{x}]_+
    $$
    where $[\mathbf{x}]_+$ is the homogeneous coordinate of $\mathbf{x}$, and $R_{\tau_i}$ is the rotation component of $P_{\tau_i}$ [S1]. The ray origin is the translation component of $P_{\tau_i}$ [S1].

3.  **Voxel Sampling and Rendering:** For each ray $\mathbf{r}_{\tau_i}$, sample $P$ points $\mathbf{X}_k$ along the ray from origin to far plane [S1]. Retrieve density $\sigma_k$ and color $\mathbf{c}_k$ from the voxel grid using trilinear interpolation [G]. Compute the rendered color $\hat{\mathbf{C}}(\mathbf{r}_{\tau_i})$ using the volume rendering equation:
    $$
    \hat{\mathbf{C}}(\mathbf{r}_{\tau_i}) = \sum_{k=1}^{P} T_k (1 - \exp(-\sigma_k \delta_k)) \mathbf{c}_k
    $$
    where $T_k = \exp(-\sum_{j=1}^{k-1} \sigma_j \delta_j)$ and $\delta_k$ is the distance between sample points [S1].

4.  **Blur Accumulation:** Approximate the motion blur integral by accumulating the rendered colors of the $N$ rays:
    $$
    \hat{\mathbf{C}}_B(\mathbf{x}) \approx \frac{1}{N} \sum_{i=1}^{N} \hat{\mathbf{C}}(\mathbf{r}_{\tau_i}(\mathbf{x}))
    $$
    This $\hat{\mathbf{C}}_B(\mathbf{x})$ is the estimated blurred color for pixel $\mathbf{x}$ [S1].

5.  **Optimization:** Compute the photo-consistency loss (e.g., $L_1$ or $L_2$) between the estimated blurred image $\hat{\mathbf{C}}_B$ and the input blurry image $I_{blur}$ [S1]. Backpropagate to optimize the voxel grid parameters $\phi_{voxel}$ and the Bézier control points $\{\hat{\mathbf{p}}_j\}$ [S1].

**Parameters:**
*   $N$: Number of intermediate sub-frames (sampling points on trajectory). Typical values: 5–31. Higher $N$ improves sharpness but increases compute [S1].
*   $M$: Order of the Bézier curve. Typical values: 3–5. Order 1 (linear) is insufficient for complex motion [S1].
*   $P$: Number of sample points per ray.
*   $B$: Batch size (number of rays processed in parallel) [S1].

**Edge Cases and Pitfalls:**
*   **Precision:** Using a 1st-order Bézier curve (linear motion) fails to fit challenging camera motions, leading to lower performance [S1].
*   **Memory:** Unlike MLP-based methods, ExBluRF's memory usage is constant with respect to $N$, allowing large $N$ without out-of-memory errors [S1].
*   **Initialization:** Pre-trained 2D deblurring networks cannot be directly applied because NeRF requires per-scene optimization without sharp image pairs [S1].

## Operating characteristics
*   **Time Complexity:** Training time is significantly reduced compared to MLP-based methods. On the 'Camellia' dataset, ExBluRF achieves 10x less training time than DeblurNeRF (4.41 hrs vs 27.48 hrs) [S1].
*   **Memory Complexity:** Memory complexity per ray is $O(1)$ because ray marching evaluates points sequentially [S1]. In contrast, DeblurNeRF has $O(P L)$ memory cost due to synchronous feed-forwarding and activation saving [S1]. Total memory is constant relative to $N$ [S1].
*   **Performance:** On the 'Camellia' scene, ExBluRF achieves 28.83 PSNR with 4.31 GB GPU memory, compared to DeblurNeRF's 27.76 PSNR with 13.89 GB memory [S1].
*   **Strengths:** Handles extreme motion blur efficiently; supports large $N$ for sharper results; accurate trajectory estimation (low ATE) [S1].
*   **Limitations:** Requires joint optimization of geometry and motion, which can be ill-posed if not constrained by multi-view consistency [S1].

## Background
ExBluRF was introduced by Dongwoo Lee, Sunghyun Cho, Kyoung Mu Lee, et al. in 2023 [S1]. It addresses the limitations of DeblurNeRF [S1], which struggles with extreme blur due to memory constraints and the inability to handle large kernel sizes. The method builds on [Voxel-based Representation](10852-voxel-based-representation.md) to replace the MLP bottleneck, enabling efficient optimization of 6-DOF trajectories for motion blur modeling [S1].
