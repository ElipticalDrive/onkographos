# Part-based MHE-augmented NeRF

Also called: Instant NVR, Learning Neural Volumetric Representations of Dynamic Humans in Minutes, Part-based voxelized human representation

## Overview
Part-based MHE-augmented NeRF is a method for learning neural volumetric videos of dynamic humans from sparse view videos in minutes with competitive visual quality [S1]. It addresses the slow convergence of per-scene optimization methods by decomposing the canonical human body into multiple anatomical parts, assigning each part its own Multiresolution Hash Encoding (MHE)-augmented NeRF network with varying resolutions to efficiently distribute representational power [S1]. Unlike single-resolution voxelized representations or continuous implicit functions that treat the entire body uniformly, this method leverages a 2D motion parameterization scheme on a parametric mesh (SMPL) to accelerate deformation field learning [S1].

## How it works
**Inputs:**
- A sequence of sparse multi-view videos of a dynamic human.
- SMPL parameters (pose $\rho$, shape $\beta$) for each frame, or a pre-estimated SMPL mesh sequence [S1].
- Camera intrinsics and extrinsics for the input views [S1].

**Outputs:**
- A set of $K$ MHE-augmented NeRF networks, one for each human part $k \in \{1, \dots, K\}$, representing the canonical space [S1].
- A latent embedding $l_t$ for each frame $t$ [S1].
- Rendered novel view images for any camera pose and time $t$ [S1].

**Data Structures:**
1.  **SMPL Mesh Model:** A parametric human model $M=(V, E)$ with vertices $V$ and edges $E$. Each vertex $v_i$ has a blend weight $w_i \in \mathbb{R}^{J}$, where $J$ is the number of bones [S1].
2.  **Part Decomposition:** The body is divided into $K$ parts. For each part $k$, a set of bones $\Omega_k$ is defined. The mesh for part $k$ is $M_k = (V_k, E_k)$, where:
    $$
    V_k = \{v_i \mid \arg\max w_i \in \Omega_k\}
    $$
    $$
    E_k = \{(v_i, v_j) \mid v_i \in V_k, v_j \in V_k\}
    $$
    [S1]
3.  **Multiresolution Hash Encoding (MHE):** Each part $k$ has its own hash table. The hash table size is adapted based on the local geometric and texture complexity of the part [S1]. The encoding function is denoted as $\psi_k$ [S1].
4.  **Networks:**
    -   **Density Network:** $MLP_{\sigma_k}$ takes the encoded point $\psi_k(x)$ and outputs density $\sigma_k$ and feature vector $z$ [S1].
    -   **Color Network:** $MLP_{c_k}$ takes feature vector $z$, viewing direction $d$, and latent embedding $l_t$ to output color $c_k$ [S1].
    -   **Residual Deformation Network:** An MLP that takes hash-encoded $(u, v, t)$ and outputs residual translation $\Delta x$ [S1].

**Numbered Steps:**

1.  **Part Decomposition:** Manually divide the human body into $K$ parts based on the SMPL model's blend weights [S1]. Define $\Omega_k$ for each part $k$ [S1].

2.  **Query Processing (for a query point $x$ at frame $t$):**
    a.  For each part $k$, find the nearest surface point $p_k$ on the posed SMPL mesh part $M_k$ [S1].
    b.  Obtain the blend weight $w_k$ and UV coordinate $(u_k, v_k)$ of the surface point $p_k$ from the SMPL model [S1].

3.  **Motion Parameterization (Transform to Canonical Space):**
    a.  **Inverse LBS:** Transform the query point $x$ to the unposed space using inverse Linear Blend Skinning (LBS). Given pose $\rho$, blend weight $w_k$, and query point $x$, the transformed point $x_0$ is:
        $$
        x_0 = \Phi_{LBS}(x, w_k, \rho) = \left( \sum_{j=1}^{J} w_{k,j} G_j \right)^{-1} x
        $$
        where $\rho$ denotes the human pose and $\{G_j\}_{j=1}^J$ are the transformation matrices for the bones [S1].
    b.  **Residual Deformation:** Apply the residual deformation module. Encode the 2D UV coordinates and time $(u_k, v_k, t)$ using the part-specific MHE $\psi_{res}$ (or a shared encoding for deformation) [S1]. Pass the encoded coordinates through an MLP to regress the residual translation $\Delta x$ [S1].
    c.  **Canonical Point:** Compute the canonical point $x_{can}$ by adding the residual translation to the inverse LBS output:
        $$
        x_{can} = x_0 + \Delta x
        $$
        [S1]

4.  **Density and Color Prediction:**
    a.  Feed the canonical point $x_{can}$ into the $k$-th part's density network. Apply the part-specific MHE $\psi_k$ to $x_{can}$ (or use $x_{can}$ directly if $\psi_k$ is applied internally, but the text says "apply MHE to the transformed point" then feed to MLP) [S1]. Specifically:
        $$
        (\sigma_k, z) = MLP_{\sigma_k}(\psi_k(x_{can}))
        $$
        [S1]
    b.  Feed the feature vector $z$, viewing direction $d$, and latent embedding $l_t$ to the color network:
        $$
        c_k = MLP_{c_k}(z, d, l_t)
        $$
        [S1]
    c.  Repeat steps 4a-4b for all $K$ parts to obtain a set of predictions $\{(\sigma_k, c_k)\}_{k=1}^K$ [S1].

5.  **Selection:** Select the prediction from the part $k^*$ with the maximum density as the final density and color for the query point:
    $$
    (\sigma, c) = (\sigma_{k^*}, c_{k^*}) \quad \text{where} \quad k^* = \arg\max_k \sigma_k
    $$
    [S1]

6.  **Rendering:** Use the standard volume rendering equation to integrate $\sigma$ and $c$ along rays [44-radiance-field-optimization.md].

**Pseudocode:**

```python
import torch
import torch.nn as nn

class PartBasedMHEAugmentedNeRF:
    def __init__(self, K, smpl_model, part_bone_sets, hash_table_sizes, hidden_dim=256):
        """
        K: Number of human parts
        smpl_model: SMPL model instance providing mesh, blend weights, and inverse LBS
        part_bone_sets: List of sets, part_bone_sets[k] contains bone indices for part k
        hash_table_sizes: List of hash table sizes for each part k
        """
        self.K = K
        self.smpl_model = smpl_model
        self.part_bone_sets = part_bone_sets
        
        # Initialize MHE and Networks for each part
        self.mhe_encoders = nn.ModuleList([
            MultiresolutionHashEncoding(size=size) for size in hash_table_sizes
        ])
        self.density_networks = nn.ModuleList([
            MLP_Density(hidden_dim) for _ in range(K)
        ])
        self.color_networks = nn.ModuleList([
            MLP_Color(hidden_dim) for _ in range(K)
        ])
        
        # Residual deformation network (shared or per-part, text implies shared structure for deformation)
        self.residual_deform_net = MLP_ResidualDeformation(hidden_dim)
        
        # Latent embeddings for frames (initialized randomly or learned)
        self.latent_embeddings = None 

    def get_part_mesh(self, k):
        """Get mesh vertices and edges for part k based on SMPL blend weights"""
        # V_k = {v_i | argmax w_i in Omega_k}
        # E_k = {(v_i, v_j) | v_i in V_k, v_j in V_k}
        # This is a preprocessing step, usually done once or cached
        return self.smpl_model.get_submesh(self.part_bone_sets[k])

    def inverse_lbs(self, x, w, pose):
        """
        Compute x_0 = (sum w_j G_j)^-1 x
        x: (N, 3) query points
        w: (N, J) blend weights
        pose: (J, 4, 4) or similar representation of bone transforms G_j
        """
        # Reconstruct transformation matrix from pose and weights
        # G_total = sum_j w_j * G_j(pose)
        G_total = self.smpl_model.compute_weighted_transform(w, pose)
        # Inverse transformation
        G_inv = torch.inverse(G_total)
        # Homogeneous coordinates
        x_homo = torch.cat([x, torch.ones_like(x[:, :1])], dim=1)
        x_0 = torch.matmul(x_homo, G_inv.transpose(-2, -1))[:, :3]
        return x_0

    def find_nearest_surface_point(self, x, part_mesh_k):
        """
        Find nearest point p_k on part k's mesh and return blend weight w_k and UV (u_k, v_k)
        """
        # Use KDTree or similar to find nearest vertex on part_mesh_k
        # Retrieve blend weight w_k and UV coordinate from SMPL model for that vertex
        return w_k, uv_k

    def forward(self, x, t, pose, camera_params):
        """
        x: (N, 3) query points in world space
        t: frame index
        pose: SMPL pose parameters for frame t
        camera_params: camera extrinsics/intrinsics for ray generation (if needed for d)
        """
        # Get latent embedding for frame t
        l_t = self.latent_embeddings[t]
        
        densities = []
        colors = []
        
        for k in range(self.K):
            # 1. Find nearest surface point on part k
            w_k, uv_k = self.find_nearest_surface_point(x, self.get_part_mesh(k))
            
            # 2. Inverse LBS
            x_0 = self.inverse_lbs(x, w_k, pose)
            
            # 3. Residual Deformation
            # Encode (u, v, t)
            uv_t = torch.cat([uv_k, torch.tensor([t]).expand_as(uv_k[:, :1])], dim=1)
            encoded_uv_t = self.residual_deform_net.encoder(uv_t) # Assuming encoder is part of MLP or separate
            delta_x = self.residual_deform_net.mlp(encoded_uv_t)
            
            # 4. Canonical Point
            x_can = x_0 + delta_x
            
            # 5. Density and Color Prediction
            # Apply MHE for part k to x_can
            encoded_x_can = self.mhe_encoders[k](x_can)
            sigma_k, z = self.density_networks[k](encoded_x_can)
            
            # Get viewing direction d from camera_params and x (ray direction)
            # This depends on how rays are generated. Assuming d is passed or computed externally.
            # For the sake of the method description, we assume d is available.
            c_k = self.color_networks[k](z, d, l_t)
            
            densities.append(sigma_k)
            colors.append(c_k)
            
        densities = torch.stack(densities, dim=0) # (K, N)
        colors = torch.stack(colors, dim=0) # (K, N, 3)
        
        # 6. Selection
        k_star = torch.argmax(densities, dim=0) # (N,)
        sigma = densities[k_star, torch.arange(densities.shape[1])] # (N,)
        c = colors[k_star, torch.arange(colors.shape[1]), :] # (N, 3)
        
        return sigma, c

class MultiresolutionHashEncoding(nn.Module):
    def __init__(self, size):
        super().__init__()
        self.size = size
        # Initialize hash table with trainable features
        self.table = nn.Embedding(size, 4) # 4 is typical for MHE, not given explicitly but standard
        
    def forward(self, x):
        # Hash function to map coordinates to table indices
        # This is a simplified representation. Real MHE uses multiple octaves.
        indices = self.hash_function(x)
        return self.table(indices)

class MLP_Density(nn.Module):
    def __init__(self, hidden_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 1 + hidden_dim) # sigma and z
        )
    def forward(self, x):
        out = self.net(x)
        sigma = torch.sigmoid(out[:, :1]) # Density is usually positive
        z = out[:, 1:]
        return sigma, z

class MLP_Color(nn.Module):
    def __init__(self, hidden_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(hidden_dim * 2 + 3 + hidden_dim, hidden_dim), # z, d, l_t
            nn.ReLU(),
            nn.Linear(hidden_dim, 3) # RGB
        )
    def forward(self, z, d, l_t):
        # Concatenate z, d, l_t
        # Note: d and l_t dimensions need to match hidden_dim or be projected
        input_vec = torch.cat([z, d, l_t], dim=-1)
        return torch.sigmoid(self.net(input_vec))

class MLP_ResidualDeformation(nn.Module):
    def __init__(self, hidden_dim):
        super().__init__()
        # Encoder for (u, v, t)
        self.encoder = MultiresolutionHashEncoding(size=2**15) # Example size
        self.mlp = nn.Sequential(
            nn.Linear(4, hidden_dim), # Output of MHE
            nn.ReLU(),
            nn.Linear(hidden_dim, 3) # delta_x
        )
    def forward(self, uv_t):
        encoded = self.encoder(uv_t)
        return self.mlp(encoded)
```

**Parameters:**
-   **Training Time:** Approximately 5 minutes on a single RTX 3090 GPU for a 512x512 video with 100 frames [S1].
-   **Optimizer:** Adam with learning rate $5 \times 10^{-4}$ [S1].
-   **Hash Table Size:** Adapted per part. Using a uniformly large hash table (e.g., $2^{20}$) across all parts increases memory and training time without quality gains [S1].
-   **Number of Parts:** Not explicitly given, but implied to be based on SMPL body parts (e.g., head, torso, arms, legs) [S1].

**Edge Cases and Pitfalls:**
-   **Uniform Hash Table Size:** Using a uniformly large hash table across all parts increases memory consumption and per-iteration training time without guaranteed quality gains [S1].
-   **Equal Complexity Assumption:** Treating all parts as equally complex wastes representational power on simple regions and degrades PSNR (e.g., by 1.98dB) [S1].
-   **Motion Parameterization:** Human motion occurs around a surface. Points near the surface projected to neighboring regions on a parametric model have similar motion behavior. The 2D parameterization exploits this [S1].

## Subtopics

### MHE (Multiresolution Hash Encoding)
A technique to encode coordinates into a high-dimensional space using hash tables of trainable features, allowing for efficient and high-resolution representation [S1]. It sets itself apart by enabling spatially varying resolution and fast lookup. Choose it when memory efficiency and high-frequency detail are needed in implicit fields. [48-multiresolution-hash-encoding.md]

### SMPL (Skinned Multi-Person Linear model)
A parametric human body model used to define the canonical shape and deformation. It provides the mesh, blend weights, and pose parameters. Choose it when working with dynamic human reconstruction. [43-smpl.md]

### Inverse LBS (Linear Blend Skinning)
A method to transform points from posed space to canonical space by inverting the weighted sum of bone transformations. It sets itself apart by providing a differentiable approximation of inverse kinematics. Choose it for pose-dependent deformation. [35-inverse-lbs.md]

## Operating characteristics
-   **Time Complexity:** Training time is approximately 5 minutes for a 512x512 video with 100 frames on a single RTX 3090 GPU [S1]. This is 100 times faster than Neural Body [S1].
-   **Memory Complexity:** Depends on the hash table sizes. The part-based approach allows adapting hash table size per part, reducing memory compared to a single large hash table for the whole body [S1].
-   **Measured Performance:** On the ZJU-MoCap dataset, the part-based approach yields higher PSNR than a single MHE-augmented NeRF for the whole body (286M params vs 302M params) and converges faster [S1].
-   **Scaling:** The method scales with the number of parts and the complexity of each part. Increasing hash table size increases memory and training time [S1].
-   **Strengths:** Fast training time, competitive visual quality, efficient distribution of representational power.
-   **Limitations:** Requires SMPL parameters or pre-estimated SMPL mesh. Performance may degrade if the SMPL fit is poor. [S1]
-   **When to use:** When reconstructing dynamic humans from sparse views with limited training time.
-   **When not to use:** When high generalization to unseen subjects is required without fine-tuning, or when SMPL parameters are not available.
