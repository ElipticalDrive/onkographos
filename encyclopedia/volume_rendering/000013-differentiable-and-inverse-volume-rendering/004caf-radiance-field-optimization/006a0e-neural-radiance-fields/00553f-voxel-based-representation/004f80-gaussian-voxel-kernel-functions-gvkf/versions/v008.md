# Gaussian Voxel Kernel Functions (GVKF)
Also called: GVKF (Gaussian Voxel Kernel Functions)

## Overview
Gaussian Voxel Kernel Functions (GVKF) is a method for efficient and effective 3D surface reconstruction in open scenes that establishes a continuous scene representation based on discrete 3D Gaussian Splatting (3DGS) through kernel regression [S1]. It integrates fast 3DGS rasterization with implicit scene representations to achieve high-fidelity open scene surface reconstruction, real-time rendering speed, and significant savings in storage and training memory consumption [S1]. Unlike standard 3DGS which uses explicit discrete summation leading to high memory consumption and rough surfaces in sparse areas, GVKF replaces discrete opacity values with Gaussian kernel functions, enabling direct mesh extraction and better 3D continuous surface fitting [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** Downsampled Structure-from-Motion (SfM) point clouds for initialization; camera parameters (position, orientation, intrinsics); feature vectors $F$ stored in voxels.
*   **Outputs:** A continuous scene opacity density field; a reconstructed 3D mesh derived from the opacity field.

**Data Structures**
*   **Sparse Voxel Grid:** A spatially sparse grid managing Gaussian primitives. Each voxel stores a feature vector $F \in \mathbb{R}^d$.
*   **Feature Vector $F$:** Stores the relative coordinates of Gaussians to the parent voxel center. It serves as the input to Multi-Layer Perceptrons (MLPs) to decode Gaussian attributes [S1].
*   **Gradient Accumulator:** A value $\nabla$ associated with each voxel, recording and accumulating gradients from 3DGS after each iteration [S1].

**Parameters**
*   $m$: The maximum number of Gaussian primitives allowed per sparse grid voxel [S1].
*   $\nabla_{thresh}$: The threshold metric for voxel subdivision based on accumulated gradient $\nabla$. (Value not given in the sources.)
*   $d_{max}$: The maximum depth of the voxel grid subdivision. (Value not given in the sources.)
*   $T_{prune}$: The specified period after which less frequently used voxels are discarded. (Value not given in the sources.)

**Formulas**
The Gaussian function $G(x)$ is defined as [S1]:
$$
G(x) = \alpha \cdot \exp\left(-\frac{1}{2} (x-p)^T P^{-1} (x-p)\right)
$$
where:
*   $x$ is the query point in 3D space.
*   $p \in \mathbb{R}^3$ is the position.
*   $\alpha \in \mathbb{R}$ is the opacity.
*   $P \in \mathbb{R}^{3 \times 3}$ is the covariance matrix, defined as $P = R S S^T R^T$.
*   $R \in \mathbb{R}^{3 \times 3}$ is the rotation matrix.
*   $S \in \mathbb{R}^{3 \times 3}$ is the scaling matrix (diagonal matrix formed from scaling vector $s \in \mathbb{R}^3$).

The attributes $\alpha, R, s, c$ (color) are decoded from the feature vector $F$ via MLPs [S1]:
$$
\alpha = \text{MLP}_\alpha(F, \text{camera})
$$
$$
R = \text{MLP}_R(F)
$$
$$
s = \text{MLP}_s(F)
$$
$$
c = \text{MLP}_c(F, \text{camera})
$$
where the camera input facilitates view-dependent fitting for alpha and color [S1].

**Numbered Steps**
1.  **Initialization:** Generate a sparse voxel grid from downsampled SfM point clouds [S1].
2.  **Feature Storage:** For each voxel, store a feature vector $F$ containing the relative coordinates of Gaussians to the parent voxel center [S1].
3.  **Attribute Decoding:** Decode Gaussian attributes ($\alpha, R, s, c$) from $F$ using the specified MLPs [S1].
4.  **Rendering:** Perform 3DGS rasterization using the decoded Gaussian primitives. Replace the discrete opacity values of the original 3DGS pipeline with the Gaussian kernel functions $G(x)$ to represent the continuous scene opacity density field [S1].
5.  **Gradient Accumulation:** After each iteration, record and accumulate gradients from the 3DGS rendering into the respective voxels, denoted as $\nabla$ [S1].
6.  **Voxel Subdivision:** Check if the accumulated gradient $\nabla$ in a voxel exceeds the threshold. If so, subdivide the voxel into eight subvoxels to increase grid resolution. Repeat subdivision until the maximum depth $d_{max}$ is reached [S1].
7.  **Dynamic Management:** Dynamically generate Gaussians each iteration and recycle them post-update to reduce memory usage [S1].
8.  **Pruning:** Discard less frequently used voxels after a specified period $T_{prune}$ [S1].
9.  **Mesh Extraction:** Derive the bidirectional mapping relationship between the constructed scene opacity field and the scene surface to enable direct mesh extraction [S1].

**Pseudocode**
```python
# GVKF Implementation Logic

class GVKF:
    def __init__(self, sfm_points, max_depth, max_primitives_per_voxel, gradient_threshold, prune_period):
        self.max_depth = max_depth
        self.max_primitives_per_voxel = max_primitives_per_voxel # m
        self.gradient_threshold = gradient_threshold
        self.prune_period = prune_period
        self.voxel_grid = SparseVoxelGrid()
        
        # Initialize grid from SfM points
        for point in sfm_points:
            voxel = self.voxel_grid.get_or_create_voxel(point)
            voxel.feature_vector = initialize_feature_vector(point)
            voxel.gradient_accumulator = 0.0
            voxel.last_access_time = current_time()

    def decode_attributes(self, feature_vector, camera):
        """
        Decodes Gaussian attributes from feature vector F using MLPs.
        """
        alpha = MLP_alpha(feature_vector, camera)
        R = MLP_R(feature_vector)
        s = MLP_s(feature_vector)
        c = MLP_c(feature_vector, camera)
        return alpha, R, s, c

    def gaussian_kernel(self, x, p, alpha, R, s):
        """
        Computes G(x) = alpha * exp(-0.5 * (x-p)^T P^-1 (x-p))
        """
        S = diag(s)
        P = R @ S @ S.T @ R.T
        P_inv = inverse(P)
        diff = x - p
        exponent = -0.5 * dot(diff, P_inv @ diff)
        return alpha * exp(exponent)

    def render_and_accumulate_gradients(self, camera, scene_views):
        """
        Renders the scene and accumulates gradients into voxels.
        """
        # Reset gradients for this iteration
        self.voxel_grid.reset_gradients()
        
        # Perform 3DGS rasterization
        for ray in camera.rays:
            # Trace ray through voxel grid
            hits = self.voxel_grid.intersect_ray(ray)
            
            # Composite color using Gaussian kernel functions
            color = 0.0
            transmittance = 1.0
            for hit in hits:
                voxel = hit.voxel
                # Decode attributes
                alpha, R, s, c = self.decode_attributes(voxel.feature_vector, camera)
                
                # Compute Gaussian value at ray position
                # Note: In standard 3DGS, opacity is constant per splat. 
                # GVKF uses kernel regression for continuous field.
                # The rendering pipeline integrates these kernels.
                g_val = self.gaussian_kernel(hit.position, hit.gaussian_center, alpha, R, s)
                
                # Accumulate contribution (simplified alpha blending logic adapted for kernels)
                # [G] Standard 3DGS alpha blending: C = sum(c_i * alpha_i * T_i)
                # GVKF replaces discrete alpha with kernel values.
                contribution = c * g_val * transmittance
                color += contribution
                transmittance *= (1.0 - g_val)
                
                # Accumulate gradient for the voxel containing this hit
                # [G] Gradient accumulation typically involves backpropagating loss w.r.t voxel features
                voxel.gradient_accumulator += compute_gradient_contribution(hit, loss)

    def update_voxel_grid(self):
        """
        Subdivides high-gradient voxels and prunes low-activity voxels.
        """
        current_time = get_current_time()
        
        for voxel in self.voxel_grid.iterate_voxels():
            # Subdivision
            if voxel.gradient_accumulator > self.gradient_threshold and voxel.depth < self.max_depth:
                voxel.subdivide_into_8_subvoxels()
                # Initialize subvoxel features based on parent or new SfM data
                for sub_voxel in voxel.subvoxels:
                    sub_voxel.feature_vector = initialize_feature_vector(sub_voxel.center)
                    sub_voxel.gradient_accumulator = 0.0
            
            # Pruning
            if current_time - voxel.last_access_time > self.prune_period:
                self.voxel_grid.remove_voxel(voxel)
                
            # Reset gradient accumulator for next iteration
            voxel.gradient_accumulator = 0.0
            voxel.last_access_time = current_time

    def extract_mesh(self):
        """
        Extracts mesh from the continuous opacity field.
        """
        # [G] Typically uses Marching Cubes or similar on the implicit field
        # derived from the Gaussian kernel regression.
        opacity_field = self.voxel_grid.build_opacity_field()
        mesh = marching_cubes(opacity_field)
        return mesh
```

## Subtopics

### Voxel-based Gaussian Splatting
Uses voxel structures to manage Gaussian primitives but may differ in the specific kernel regression formulation and mesh extraction pipeline. Choose when explicit voxel management is preferred over pure kernel regression. [Link](13071-voxel-based-gaussian-splatting.md)

### 3D Gaussian Particle Approximation of VDB Datasets
Approximates VDB datasets using Gaussian particles. Choose when working with existing VDB data structures rather than building a scene from SfM points. [Link](14723-3d-gaussian-particle-approximation-of-vdb-datasets.md)

## Operating characteristics
*   **Time Complexity:** Rendering speed is comparable to fast 3DGS rasterization, avoiding the low rendering speed of traditional volume rendering due to continuous sampling [S1]. Training involves MLP evaluations and voxel subdivision, which adds overhead compared to standard 3DGS but is mitigated by sparse grid management.
*   **Memory Complexity:** Significant savings in storage and training memory consumption compared to standard 3DGS. By using a sparse voxel grid and decoding attributes from feature vectors via MLPs, it avoids storing explicit tensors for every Gaussian primitive [S1].
*   **Strengths:** High reconstruction quality, real-time rendering speed, significant savings in storage and training memory, and ability to extract continuous surfaces directly [S1].
*   **Limitations:** Overly large and sparse Gaussian points can still affect geometric representations, particularly in background areas [S1]. Requires careful tuning of subdivision thresholds and pruning periods.
*   **When to use:** For high-fidelity open scene surface reconstruction where memory efficiency and continuous surface representation are critical.
*   **When not to use:** For scenes where explicit discrete Gaussian management is sufficient and memory is not a constraint, or for very small scenes where the overhead of voxel management is unnecessary.

## Background
GVKF was proposed to address the issues of excessive memory consumption and rough surface details in sparse Gaussian areas inherent in discrete 3DGS representations [S1]. It was introduced in the paper "GVKF: Gaussian Voxel Kernel Functions for Highly Efficient Surface Reconstruction in Open Scenes" presented at the 38th Conference on Neural Information Processing Systems (NeurIPS 2024) [S1]. The method builds on the fast rendering advantages of Gaussian alpha blending while achieving effective implicit scene representation, without the need for computationally intensive volume rendering [S1]. It draws inspiration from scaffold-Gaussian and OctreeGaussian for voxel registration based on gradient accumulation [S1].
