# Voxel-based Representation
## Overview
Voxel-based representations replace the coordinate-based Multi-Layer Perceptron (MLP) of standard Neural Radiance Fields with discrete 3D grids (voxels) to store scene features [G]. This family addresses the computational bottleneck of MLP evaluation and the lack of explicit spatial inductive biases in pure neural representations [G]. It differs from its siblings, such as [NeRF (Neural Radiance Fields)](1185-nerf-neural-radiance-fields.md) and [Point-NeRF](6569-point-nerf.md), by leveraging dense or sparse tensor structures to capture spatial correlations, often using 3D convolutions for feature extraction [G].

## Shared principles
All methods in this family store scene information in a 3D grid structure rather than a continuous function approximator [G]. The core mechanism involves sampling features from this grid at query points along rays and decoding them into density and color [G].
1. **Grid storage:** The scene is represented by a 3D tensor (voxel grid) where each cell contains a feature vector. The resolution of this grid is a key hyperparameter [G].
2. **Sampling:** For a ray passing through the scene, sample points $\mathbf{x}$ are generated. The feature vector $\mathbf{f}$ at $\mathbf{x}$ is retrieved from the grid, typically using trilinear interpolation to ensure differentiability [G].
3. **Decoding:** The sampled features are combined with positional information (and potentially viewing direction) and passed to a decoder (often a small MLP or convolutional layer) to predict density $\sigma$ and color $\mathbf{c}$ [G].
4. **Rendering:** The predicted $\sigma$ and $\mathbf{c}$ are integrated using the standard volume rendering equation [44-radiance-field-optimization.md]:
$$
\hat{C}(\mathbf{r}) = \sum_{i=1}^N T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i
$$

## Subtopics

### [FastNeRF](7183-fastnerf.md)
FastNeRF is a neural rendering method that accelerates inference by factorizing the view-dependent radiance field into position-dependent and direction-dependent components, enabling efficient caching of intermediate network outputs [FastNeRF](7183-fastnerf.md). It solves the problem of high computational cost in standard NeRF by avoiding MLP evaluations at inference time, instead relying on hardware-accelerated ray tracing and grid lookups to achieve interactive frame rates (200Hz) on consumer hardware [FastNeRF](7183-fastnerf.md). It differs from its siblings, such as [C-NeRF](7275-c-nerf.md) and [V4D](8762-v4d-voxel-for-4d-novel-view-synthesis.md), by using a low-rank inner-product factorization to decouple spatial and directional information, whereas other methods may use spherical harmonics or explicit voxel grids for density only [FastNeRF](7183-fastnerf.md). Choose it when interactive frame rates on consumer hardware are required without sacrificing view-dependent appearance.

### [C-NeRF](7275-c-nerf.md)
C-NeRF is a voxel-based radiance field representation that uses a 3D convolutional neural network (CNN) to generate feature volumes, which are then decoded by a NeRF-like multi-layer perceptron (MLP) to predict density and color [C-NeRF](7275-c-nerf.md). It is distinguished from its parent Voxel-based Representation by explicitly learning spatial features via convolutions rather than relying solely on interpolation of static grid values [C-NeRF](7275-c-nerf.md). It serves as a baseline for dynamic scene representation, often referred to as "Volume Basis" when decomposing 4D volumes into shared 3D components [C-NeRF](7275-c-nerf.md). Choose it when a convolutional prior is needed to regularize spatial features in dynamic or static scenes.

### [V4D (Voxel for 4D Novel View Synthesis)](8762-v4d-voxel-for-4d-novel-view-synthesis.md)
V4D is a voxel-based architecture for 4D novel view synthesis in dynamic scenes that models the 4D neural radiance field directly from single-view video, eliminating the need for a canonical space or explicit deformation fields [V4D](8762-v4d-voxel-for-4d-novel-view-synthesis.md). It distinguishes itself from sibling methods like [D-NeRF](link) and [TiNeuVox](link) by using separate 3D voxel grids for density and texture, combined with a total variation loss and a conditional positional encoding (CPE) module to prevent over-smoothing and over-fitting [V4D](8762-v4d-voxel-for-4d-novel-view-synthesis.md). While it requires longer training times than canonical-space methods due to the lack of temporal alignment, it achieves state-of-the-art performance on synthetic dynamic scenes and faster inference than [TiNeuVox](link) by avoiding per-point position offset prediction [V4D](8762-v4d-voxel-for-4d-novel-view-synthesis.md). Choose it for single-view video input without explicit 3D deformation priors.

### [RenderNet](10878-rendernet.md)
RenderNet is a differentiable rendering convolutional neural network that generates 2D images from 3D voxel grids by jointly learning visibility computation and pixel color calculation (shading) [RenderNet](10878-rendernet.md). Unlike traditional rasterization or ray tracing which rely on discrete, non-differentiable operations like z-buffering, RenderNet uses a CNN to encode spatial occlusion and shading automatically [RenderNet](10878-rendernet.md). It is distinguished from sibling methods like [FastNeRF](7183-fastnerf.md) and [VoxGRAF](12633-voxgraf.md) by its explicit use of a "Projection Unit" that collapses the 3D depth dimension into 2D feature maps while learning visibility, rather than relying on continuous volume rendering equations or sparse voxel structures [RenderNet](10878-rendernet.md). It handles low-resolution or noisy voxel inputs more robustly than mesh-based differentiable renderers [RenderNet](10878-rendernet.md). Choose it when differentiable shape reconstruction from low-resolution voxel inputs is required.

### [Object-NeRF](11987-object-nerf.md)
Object-NeRF is a composition model that separates and edits objects within a scene using a hybrid voxel-based approach with jointly optimized voxel grid features and MLP parameters [Object-NeRF](11987-object-nerf.md). It differs from its siblings by explicitly partitioning the scene into a background "scene branch" and foreground "object branch," allowing for the shifting, addition, or removal of specific objects without retraining the entire radiance field [Object-NeRF](11987-object-nerf.md). Choose it when object-level editing and composition in a shared scene representation are needed.

### [VoxGRAF](12633-voxgraf.md)
VoxGRAF is a 3D-aware Generative Adversarial Network (GAN) that replaces the coordinate-based Multi-Layer Perceptron (MLP) scene representation with a sparse voxel grid generator [VoxGRAF](12633-voxgraf.md). It solves the problem of slow rendering and viewpoint/content entanglement inherent in previous 3D-aware GANs by enabling fast, 3D-consistent image synthesis with a single forward pass [VoxGRAF](12633-voxgraf.md). Unlike its siblings [FastNeRF](7183-fastnerf.md), [C-NeRF](7275-c-nerf.md), [V4D](8762-v4d-voxel-for-4d-novel-view-synthesis.md), [RenderNet](10878-rendernet.md), and [Object-NeRF](11987-object-nerf.md) which often rely on dense coordinate-based queries or hybrid rendering, VoxGRAF generates the entire 3D radiance field on a sparse voxel grid using 3D convolutions, allowing for efficient rendering via alpha composition without reducing sample counts [VoxGRAF](12633-voxgraf.md). Choose it for fast, 3D-consistent generative synthesis where memory efficiency is critical.

### [Voxel-based Gaussian Splatting](13071-voxel-based-gaussian-splatting.md)
Voxel-based Gaussian Splatting (VoxGS) is a volume representation that places isometric 3D Gaussians at the fixed centroids of a regular 3D voxel grid to enable efficient Computed Tomography (CT) volume extraction and differentiable X-ray rendering [Voxel-based Gaussian Splatting](13071-voxel-based-gaussian-splatting.md). Unlike standard 3D Gaussian Splatting (3DGS) which optimizes primitive positions and uses spherical harmonics for view-dependent color, VoxGS fixes positions and removes color coefficients, retaining only opacity, scale, and rotation to support isotropic density modeling [Voxel-based Gaussian Splatting](13071-voxel-based-gaussian-splatting.md). This design solves the instability and inaccurate volume extraction issues associated with applying original 3DGS directly to CT data [Voxel-based Gaussian Splatting](13071-voxel-based-gaussian-splatting.md). Choose it for medical imaging and CT volume extraction where isotropic density modeling is required.

### [Gaussian Voxel Kernel Functions (GVKF)](13979-gaussian-voxel-kernel-functions-gvkf.md)
Gaussian Voxel Kernel Functions (GVKF) is a method for efficient 3D surface reconstruction in open scenes that establishes a continuous scene representation based on discrete 3D Gaussian Splatting (3DGS) through kernel regression [GVKF](13979-gaussian-voxel-kernel-functions-gvkf.md). It differs from explicit 3DGS by using implicit continuous representation via kernel regression instead of explicit discrete summation, reducing memory consumption and improving surface continuity [GVKF](13979-gaussian-voxel-kernel-functions-gvkf.md). Unlike standard volume rendering which relies on continuous sampling, GVKF integrates fast 3DGS rasterization with implicit scene representations to achieve high-fidelity open scene surface reconstruction without computationally intensive volume rendering [GVKF](13979-gaussian-voxel-kernel-functions-gvkf.md). Choose it when high-fidelity surface reconstruction with memory efficiency is prioritized over explicit volume rendering.

### [3D Gaussian Particle Approximation of VDB Datasets](14723-3d-gaussian-particle-approximation-of-vdb-datasets.md)
This method converts OpenVDB volumetric datasets into a set of non-overlapping 3D Gaussian particles to enable memory-efficient, lossy representation with Level of Detail (LOD) support, rendered via forward ray marching using NVIDIA OptiX [3D Gaussian Particle Approximation of VDB Datasets](14723-3d-gaussian-particle-approximation-of-vdb-datasets.md). It differs from standard voxel-based representations by replacing the discrete grid sampling with continuous Gaussian primitives, allowing for hardware-accelerated bounding box intersections and real-time performance with millions of particles, while maintaining compatibility with traditional volume rendering transfer functions [3D Gaussian Particle Approximation of VDB Datasets](14723-3d-gaussian-particle-approximation-of-vdb-datasets.md). Choose it for real-time rendering of large-scale OpenVDB volumetric datasets with LOD support.

### [Global Scene Generator (GSN)](16709-global-scene-generator-gsn.md)
Global Scene Generator (GSN) is a generative model that synthesizes unconstrained 3D scenes by decomposing them into local regions using a global generator and a locally conditioned radiance field [GSN](16709-global-scene-generator-gsn.md). Unlike dictionary-based memory models that limit unseen viewpoints, GSN uses a learned scene prior to allow extrapolation beyond given observations [GSN](16709-global-scene-generator-gsn.md). It sets itself apart from sibling voxel-based methods by explicitly generating a 2D latent "floorplan" grid to condition multiple local radiance fields, rather than storing static features in a 3D voxel grid [GSN](16709-global-scene-generator-gsn.md). Choose it for generating large-scale, unconstrained 3D scenes with spatial extrapolation capabilities.

### Neural Voxel Renderer (NVR)
NVR is a framework that synthesizes realistic images given object voxels as input, providing editing functionalities for illumination, object geometry, and appearance [S1]. The initial voxel resolution is $100^3$, and the scene volume is $V \in 128^3 \times 4$ [S1]. A realism variant uses an environment map of resolution $32 \times 32$, processed by convolutional layers to extract a latent code supplied to NVR+ [S1]. At $25^3$ voxel resolution, performance decreases gracefully but still produces plausible outputs [S1]. NVR captures color and structure but smooths fine texture details, whereas NVR+ accurately renders geometry and texture, realistically synthesizing shadows, specular reflections, and highlights [S1]. It is trained on the ShapeNet chair category and tested on Pix3D and Ikea datasets for sofas, tables, and miscellaneous objects [S1]. Choose it for controllable object-level rendering with illumination and appearance editing.

## Background
Voxel-based representations in neural rendering emerged as a response to the high computational cost and memory usage of coordinate-based MLPs in NeRF [G]. Early works like [C-NeRF](7275-c-nerf.md) and [FastNeRF](7183-fastnerf.md) demonstrated that discretizing the scene into grids could significantly speed up training and inference. [V4D](8762-v4d-voxel-for-4d-novel-view-synthesis.md) extended this to 4D dynamic scenes, while [RenderNet](10878-rendernet.md) adapted voxel grids for differentiable rendering tasks like shape reconstruction. The approach is widely used in applications requiring real-time rendering or efficient large-scale scene representation [G].
