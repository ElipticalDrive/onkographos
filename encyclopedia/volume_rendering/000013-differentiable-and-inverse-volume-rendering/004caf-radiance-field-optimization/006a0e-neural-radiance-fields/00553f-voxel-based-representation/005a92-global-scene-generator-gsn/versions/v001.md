# Global Scene Generator (GSN)

## Overview
Global Scene Generator (GSN) is a generative model that synthesizes unconstrained 3D scenes by decomposing them into local regions using a global generator and a locally conditioned radiance field [S1]. Unlike dictionary-based memory models that limit unseen viewpoints, GSN uses a learned scene prior to allow extrapolation beyond given observations [S1]. It sets itself apart from sibling voxel-based methods by explicitly generating a 2D latent "floorplan" grid to condition multiple local radiance fields, rather than storing static features in a 3D voxel grid [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Global latent code $z \sim p_z$, camera pose $T = [R, t] \in SE(3)$, and camera intrinsics $K \in \mathbb{R}^{3 \times 3}$ [S1].
*   **Outputs:** Rendered image $\hat{X} \in \mathbb{R}^{3 \times w \times h}$ [S1].

**Data Structures:**
1.  **Global Generator Output:** A 2D grid of local latent codes $W \in \mathbb{R}^{c \times s \times s}$, where $c$ is the latent dimension and $s \times s$ is the spatial resolution [S1].
2.  **Radiance Field Input:** Concatenated vector $[p_0, d] \in \mathbb{R}^5$ (positional encoded local point and viewing direction) and local latent code $w_{ij} \in \mathbb{R}^c$ [S1].
3.  **Radiance Field Architecture:** The network $f$ uses modulation of linear layers by $w_{ij}$, similar to CIPS [S1].

**Numbered Steps:**
1.  **Global Generation:** Sample a global latent code $z \sim p_z$ and feed it to the global generator $g$ (implemented as StyleGAN2) to produce the 2D grid of local latent codes $W \in \mathbb{R}^{c \times s \times s}$ [S1].
2.  **Local Code Selection:** For a 3D point $p$ in the global coordinate system, determine its projection on the $zx$-plane (assuming the $y$-axis points up) to find discrete grid indices $(i, j)$ [S1].
3.  **Bilinear Sampling:** Sample the local latent code $w_{ij} \in \mathbb{R}^c$ from grid $W$ at $(i, j)$ using bi-linear sampling [S1].
4.  **Local Coordinate Transformation:** Transform the global point $p$ into a local point $p_0$ relative to the local coordinate system of $w_{ij}$ [S1]. This decomposition prevents the radiance field from relying on absolute coordinates, enabling spatial sharing of latent codes [S1].
5.  **Input Preparation:** Apply positional encoding to $p_0$ and concatenate with the viewing direction $d$ to form the input vector $[p_0, d] \in \mathbb{R}^5$ [S1].
6.  **Radiance Field Evaluation:** Evaluate the locally conditioned radiance field $f$ with inputs $[p_0, d]$ and modulation by $w_{ij}$ to output occupancy $\sigma \in [0, \infty]$ and appearance $a \in \mathbb{R}^3$ [S1].
7.  **Volumetric Rendering:** Render the image by evaluating $f$ along rays $r$. The color $c \in \mathbb{R}^3$ for a ray $r$ is obtained by approximating the integral:
    $$
    c(r, W) = \int_{u_n}^{u_f} T_r(u) \sigma(r(u), w_{ij}) a(r(u), d, w_{ij}) du
    $$
    where the transmittance is:
    $$
    T_r(u) = \exp \left( - \int_{u_n}^{u} \sigma(r(u'), w_{ij}) du' \right)
    $$
    [S1].
8.  **Refinement:** Upsample the rendered feature map using a small convolutional refinement network to achieve the final output resolution $\hat{X}$ [S1].

**Parameters:**
*   **Camera Pose:** $T = [R, t] \in SE(3)$ controls the viewpoint [S1].
*   **Camera Intrinsics:** $K \in \mathbb{R}^{3 \times 3}$ controls the field of view [S1].
*   **Latent Dimension:** $c$ (Not given in the sources).
*   **Grid Resolution:** $s \times s$ (Not given in the sources).

**Edge Cases and Pitfalls:**
*   **Invalid Camera Locations:** Sampling camera poses inside walls or solid objects is handled by stochastic weighted sampling over a set of candidate poses from an empirical distribution $p_T$. The weights are derived from the occupancy $\sigma$ predicted by the generator at those locations, normalized via softmin [S1].
*   **Spatial Sharing:** To prevent $f$ from relying on absolute coordinates, the global coordinate system must be decomposed into local coordinate systems for each $w_{ij}$ [S1].

        # sigma, appearance = f(input_f, w_ij)

def transform_to_local_coordinate_system(p_global, w_ij, i, j):
    """
    Transforms global point p to local coordinates relative to the grid cell (i,j).
    [G] Implementation detail: This likely involves subtracting the center of the grid cell 
    or applying a learned transformation. For this pseudocode, we assume a simple translation 
    based on the grid cell center in the zx-plane.
    """
    # Calculate center of grid cell (i, j) in global coordinates
    # Assuming grid covers bounds [-1, 1] in x and z
    cell_size = 2.0 / self.grid_size
    center_x = -1.0 + (i + 0.5) * cell_size
    center_z = -1.0 + (j + 0.5) * cell_size
    
    # Local coordinates: shift p_global by center
    p_local = p_global.clone()
    p_local[..., 0] -= center_x
    p_local[..., 2] -= center_z
    
    return p_local

## Operating characteristics
*   **Time and Memory Complexity:** The method uses a 2D grid for computational efficiency, though it can be extended to a 3D grid [S1]. The global generator uses StyleGAN2, which is computationally intensive but allows for efficient convolutional generation of the latent grid [S1].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** The 2D grid representation scales better to large, densely populated scenes than 1D global latent codes used in GRAF and $\pi$-GAN [S1].
*   **Strengths:** Allows extrapolation beyond given observations due to the learned scene prior; handles unconstrained scenes by decomposing them into local regions [S1].
*   **Limitations:** Requires stochastic weighted sampling to handle invalid camera locations; the 2D grid assumption may not capture vertical variations as well as a 3D grid [S1].
*   **When to use:** When generating large, unconstrained scenes with diverse viewpoints.
*   **When not to use:** When high-fidelity vertical detail is critical and a 3D grid is necessary, or when computational resources for StyleGAN2 are insufficient.

## Background
*   **Origin:** GSN was introduced in "Unconstrained Scene Generation with Locally Conditioned Radiance Fields" [S1].
*   **History and Development:** It builds on the idea of distributing scenes among several smaller networks to avoid the diminishing returns of increasing a single radiance field network's capacity [S1]. It contrasts with dictionary-based memory models that limit unseen viewpoints [S1].
*   **Usage:** It uses StyleGAN2 architecture for the global generator and discriminator, and CIPS-style modulation for the radiance field network [S1].
