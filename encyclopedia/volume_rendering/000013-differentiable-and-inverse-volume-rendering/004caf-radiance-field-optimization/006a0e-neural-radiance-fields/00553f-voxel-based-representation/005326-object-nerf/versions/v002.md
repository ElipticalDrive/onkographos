# Object-NeRF

Also called: ObjectNeRF

## Overview
Object-NeRF is a composition model that separates and edits objects within a scene using a hybrid voxel-based approach with jointly optimized voxel grid features and MLP parameters [S1]. It differs from its siblings by explicitly partitioning the scene into a background "scene branch" and foreground "object branch," allowing for the shifting, addition, or removal of specific objects without retraining the entire radiance field [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Multi-view RGB images, camera poses, and instance segmentation masks for each object in the scene [S1].
*   **Outputs:** A composited RGB image for a target view, and separate latent representations for the scene and individual objects [S1, S2].

**Data Structures:**
1.  **Voxel Grid:** A 3D tensor storing feature vectors for the scene. The resolution is a hyperparameter. Features are retrieved via trilinear interpolation [S1].
2.  **Object Activation Latent Codes:** A set of learnable latent vectors, one per object instance, used to condition the object-specific decoder [S1].
3.  **MLP Parameters:** Two separate Multi-Layer Perceptrons (MLPs):
    *   $\mathcal{M}_{scene}$: Decodes scene geometry and appearance.
    *   $\mathcal{M}_{obj}$: Decodes object geometry and appearance [S1, S2].

**Numbered Steps:**
1.  **Voxel Feature Sampling:** For a ray $\mathbf{r}$, sample points $\mathbf{x}_i$ along the ray. Retrieve the feature vector $\mathbf{f}_i$ from the voxel grid at $\mathbf{x}_i$ using trilinear interpolation [S1].
2.  **Scene Branch Evaluation:** Pass $\mathbf{f}_i$ and positional encoding of $\mathbf{x}_i$ to $\mathcal{M}_{scene}$ to predict scene density $\sigma_{scene}$ and color $\mathbf{c}_{scene}$ [S1, S2].
3.  **Object Branch Evaluation:** For each object $k$, retrieve its activation latent code $\mathbf{z}_k$. Pass $\mathbf{f}_i$, positional encoding of $\mathbf{x}_i$, and $\mathbf{z}_k$ to $\mathcal{M}_{obj}$ to predict object density $\sigma_{obj}^k$ and color $\mathbf{c}_{obj}^k$ [S1, S2].
4.  **Masking and Selection:** Use the instance segmentation masks to determine which points belong to which object or the background. Points not belonging to any foreground object are treated as background [S1].
5.  **Volume Rendering:** Render the scene and each object separately using the standard volume rendering equation [44-radiance-field-optimization.md]:
    $$
    \hat{C}_{scene}(\mathbf{r}) = \sum_{i=1}^{N} T_i^{scene} (1 - \exp(-\sigma_{scene,i} \delta_i)) \mathbf{c}_{scene,i}
    $$
    $$
    \hat{C}_{obj}^k(\mathbf{r}) = \sum_{i=1}^{N} T_i^{obj} (1 - \exp(-\sigma_{obj,i}^k \delta_i)) \mathbf{c}_{obj,i}^k
    $$
    where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance [44-radiance-field-optimization.md].
6.  **Composition:** Composite the rendered object layers and the background layer. The final pixel color is the sum of the background and all foreground objects [S1, S2].

**Parameters:**
*   **Voxel Grid Resolution:** Not given in the sources.
*   **Number of Latent Codes:** Equal to the number of object instances in the scene [S1].

**Edge Cases and Pitfalls:**
*   **Occlusion:** The method relies on segmentation labels to identify objects. If segmentation is inaccurate, object isolation fails [S1].
*   **Ambient Occlusion:** Standard volume rendering does not account for inter-object shadows unless explicitly modeled in the density/color prediction [G].

**Pseudocode:**
```python
def render_object_nerf(ray_origin, ray_direction, voxel_grid, mlp_scene, mlp_obj, 
                       latent_codes, segmentation_masks, num_samples):
    """
    Renders a view using Object-NeRF.
    
    Args:
        ray_origin: (3,) array, camera origin.
        ray_direction: (3,) array, normalized ray direction.
        voxel_grid: 3D tensor, scene features.
        mlp_scene: MLP, scene decoder.
        mlp_obj: MLP, object decoder.
        latent_codes: List of latent vectors, one per object.
        segmentation_masks: Dict mapping object_id to 2D mask.
        num_samples: int, number of samples per ray.
        
    Returns:
        final_color: (3,) array, composited pixel color.
        object_colors: Dict mapping object_id to rendered color.
        background_color: (3,) array, background color.
    """
    # 1. Sample points along the ray
    t_min, t_max = 0.0, 10.0 # [G] Typical bounds; should be scene-dependent
    t_vals = torch.linspace(t_min, t_max, num_samples)
    points = ray_origin.unsqueeze(0) + t_vals.unsqueeze(1) * ray_direction.unsqueeze(0) # (N, 3)
    
    # 2. Sample voxel features
    # [G] Assuming trilinear interpolation function exists
    features = trilinear_interpolate(voxel_grid, points) # (N, D)
    
    # 3. Positional encoding
    pos_enc = positional_encoding(points) # (N, D_pos)
    
    # 4. Render Background
    scene_input = torch.cat([features, pos_enc], dim=-1)
    sigma_scene, c_scene = mlp_scene(scene_input) # (N,), (N, 3)
    background_color = volume_render(sigma_scene, c_scene, t_vals)
    
    # 5. Render Objects
    object_colors = {}
    for obj_id, latent_code in latent_codes.items():
        obj_input = torch.cat([features, pos_enc, latent_code.expand(num_samples, -1)], dim=-1)
        sigma_obj, c_obj = mlp_obj(obj_input) # (N,), (N, 3)
        
        # [G] Apply segmentation mask to zero out non-object regions
        # Assuming mask is projected to ray space or points are pre-filtered
        # Here we assume sigma_obj is already masked or we mask it here
        # mask = get_mask_for_points(points, segmentation_masks[obj_id])
        # sigma_obj = sigma_obj * mask
        
        obj_color = volume_render(sigma_obj, c_obj, t_vals)
        object_colors[obj_id] = obj_color
        
    # 6. Composite
    # [G] Simple additive composition as per description
    final_color = background_color
    for obj_id, obj_color in object_colors.items():
        final_color = final_color + obj_color
        
    return final_color, object_colors, background_color

def volume_render(sigma, c, t_vals):
    """
    Standard volume rendering equation.
    """
    dt = t_vals[1:] - t_vals[:-1]
    dt = torch.cat([dt, torch.zeros_like(dt[:1])], dim=0)
    
    alpha = 1.0 - torch.exp(-sigma * dt)
    T = torch.cumprod(torch.exp(-sigma * dt), dim=0)
    T = torch.cat([torch.ones_like(T[:1]), T[:-1]], dim=0)
    
    weights = alpha * T
    color = torch.sum(weights.unsqueeze(1) * c, dim=0)
    return color
```

## Subtopics

### [Scene Editing and Decomposition](16868-scene-editing-and-decomposition.md)
This method decomposes a composite radiance field into individual object layers and distinct background layers (near and far) to enable per-object editing and re-rendering. It differs from standard volume rendering by explicitly partitioning the ray integration domain based on 3D bounding boxes, allowing objects to be isolated from the background without requiring explicit objectness priors during training.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$, where $N$ is the number of samples per ray and $M$ is the number of objects. Rendering requires evaluating both the scene MLP and each object MLP for every sample [S1].
*   **Memory Complexity:** $O(V + K \cdot L)$, where $V$ is the voxel grid size, $K$ is the number of objects, and $L$ is the latent code dimension [S1].
*   **Strengths:** Enables explicit object manipulation (shifting, adding, removing) without retraining the entire scene [S2].
*   **Limitations:** Requires instance segmentation labels for training [S1]. Performance degrades with a large number of objects due to the linear scaling of object MLP evaluations [S1].
*   **When to use:** When object-level editing or decomposition is required [S1].
*   **When not to use:** When segmentation labels are unavailable or when real-time performance with many objects is critical [S1].

## Background
Object-NeRF was introduced by Yang et al. in September 2021 [S1]. It builds on the hybrid voxel-based approach [39] and the original NeRF framework [44-radiance-field-optimization.md]. The method was trained and evaluated on the ScanNet dataset and an in-house ToyDesk dataset [S1]. It addresses the limitation of standard NeRFs, which treat the scene as a monolithic entity, by introducing a composition model that separates objects from the background [S1, S2].
