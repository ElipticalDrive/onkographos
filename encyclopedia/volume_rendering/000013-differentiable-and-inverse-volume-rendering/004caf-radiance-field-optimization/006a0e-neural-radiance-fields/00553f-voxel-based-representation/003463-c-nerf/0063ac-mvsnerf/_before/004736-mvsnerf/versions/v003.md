# MVSNeRF

Also called: MVS-NeRF

## Overview
MVSNeRF is a method for fast, generalizable radiance field reconstruction from multi-view stereo that learns a data prior to bypass per-scene optimization [S1][S2, unofficial]. It extracts 2D image features using a pretrained CNN, maps them to a 3D voxelized cost volume through plane sweeping with a variance-based cost, and uses a pretrained 3D CNN to produce a 3D neural encoding volume [S1].

## How it works
**Inputs:** A set of multi-view images $\{I_t\}$ with known camera parameters [G].
**Outputs:** A rendered image $\hat{I}$ [G].

**Data Structures:**
1. **2D Feature Volume:** Extracted from input images using a pretrained CNN [S1].
2. **3D Cost Volume:** A voxelized grid constructed via plane sweeping [S1].
3. **3D Neural Encoding Volume ($V$):** A 3D tensor produced by a pretrained 3D CNN, storing latent codes for spatial points [S1].
4. **NeRF MLP:** A multi-layer perceptron taking latent codes, coordinates, and viewing directions as input [S1].

**Steps:**
1. **2D Feature Extraction:** Extract 2D features from each input image $I_t$ using a pretrained CNN [S1].
2. **Cost Volume Construction:** Map the 2D features to a 3D voxelized cost volume through plane sweeping using a variance-based cost metric [S1].
3. **3D Neural Encoding:** Pass the cost volume through a pretrained 3D CNN to produce the 3D neural encoding volume $V$ [S1].
4. **Latent Code Interpolation:** For any 3D point $p$, retrieve its latent code $z_p$ by interpolating values from $V$ [S1].
5. **Radiance Field Prediction:** Input $z_p$, the 3D point coordinates $p$, and the viewing direction $d$ into the NeRF MLP to predict density $\sigma$ and color $c$ [S1].
6. **Volume Rendering:** Render the image by integrating predicted density and color along camera rays [S1].
7. **Joint Optimization:** During training, jointly optimize the 3D feature volume (via the 3D CNN) and the NeRF MLP parameters [S1].

**Pseudocode:**
```python
import math

def interpolate(volume, point):
    # Standard trilinear interpolation from 3D tensor
    return volume[point]

def mvsnerf_render(ray_origin, ray_direction, V, nerf_mlp, near, far, num_samples):
    rendered_color = [0.0, 0.0, 0.0]
    accumulated_transmittance = 1.0
    
    for i in range(num_samples):
        t = near + (far - near) * (i + 0.5) / num_samples
        p = [ray_origin[j] + ray_direction[j] * t for j in range(3)]
        z_p = interpolate(V, p)
        sigma, color = nerf_mlp(z_p, p, ray_direction)
        
        delta = (far - near) / num_samples
        alpha = 1.0 - math.exp(-sigma * delta)
        weight = accumulated_transmittance * alpha
        rendered_color = [rendered_color[j] + weight * color[j] for j in range(3)]
        accumulated_transmittance *= (1.0 - alpha)
        
    return rendered_color

def train_mvsnerf(images, gt_images, nerf_mlp, optimizer):
    # Joint optimization of 3D feature volume and NeRF MLP
    rendered = mvsnerf_render(ray_origin, ray_direction, V, nerf_mlp, near, far, num_samples)
    loss = sum((r - g)**2 for r, g in zip(rendered, gt_images)) / len(gt_images)
    loss.backward()
    optimizer.step()
```

*   Variance-based cost threshold: Not given in the sources [S1].

**Edge Cases:**
*   Precision: Interpolation from the 3D neural encoding volume requires careful handling of grid boundaries [S1].

## Subtopics

### [Local Sparse Volume Reconstruction](7514-local-sparse-volume-reconstruction.md)
Regresses a local neural volume for each input frame using neighboring images. It solves per-frame radiance field estimation by aggregating multi-view features in a canonical world coordinate frame. Unlike MVSNeRF, which builds perspective frustum volumes for small-baseline rendering, this method constructs volumes directly in canonical space to facilitate global fusion.

## Operating characteristics
*   **Time Complexity:** Training is significantly faster than baseline NeRF; on the DTU dataset, MVSNeRF reached results comparable to hours of baseline NeRF training within 15 minutes [S1].
*   **Memory Complexity:** Requires storing the 3D neural encoding volume and the cost volume [S1].
*   **Strengths:** Fast generalizable reconstruction [S1].
*   **Limitations:** Not given in the sources [S1].
*   **When to use:** Fast reconstruction from multi-view images where per-scene optimization is too slow [S1].
*   **When not to use:** Not given in the sources [S1].

## Background
MVSNeRF was introduced in March 2021 [S1]. It differs from General Radiance Field (GRF) by taking a slightly different approach, whereas GRF operated in canonical space as opposed to view-space for pixelNeRF [S1]. It builds on the idea of using multi-view stereo to initialize or guide the radiance field representation [S1].
