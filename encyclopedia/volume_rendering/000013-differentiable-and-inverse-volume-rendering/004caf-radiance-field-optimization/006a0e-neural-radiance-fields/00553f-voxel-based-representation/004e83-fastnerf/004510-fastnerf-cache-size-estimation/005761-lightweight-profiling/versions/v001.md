# Lightweight Profiling

Also called: Mesh-assisted NeRF Profiling Model, Polynomial-based Size and Quality Prediction

## Overview
Lightweight Profiling is a white-box method that predicts the representation data size and rendering quality of mesh-assisted Neural Radiance Fields (NeRFs) for specific configurations without training the neural network [S1]. It distinguishes itself from black-box approaches by using explicit polynomial models derived from rendering knowledge, allowing for rapid assessment of configuration trade-offs between memory load and visual fidelity [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** Two configuration knobs: geometry density $g$ and texture patch size $p$.
*   **Outputs:** Predicted quality metric $Q$ (SSIM) and predicted size metric $S$ (total data size in bytes or KB).

**Data Structures**
The model consists of two polynomial functions, $f_s$ for size and $f_q$ for quality. Each function is defined by a set of parameters $\theta = \{k, m, a, b, k', m', a', b'\}$ determined via curve fitting [S1].

**Parameters**
*   $g$: Number of voxel grids allocated for each axis in the 3D voxel grid representation [S1].
*   $p$: One-dimensional size of the texture image allocated for each quad face ($p \times p$ pixels) [S1].
*   $Q$: Quality metric, defined as SSIM (Structural Similarity Index Measure), evaluating luminance, contrast, and structure [S1].
*   $S$: Size metric, defined as the total data size quantifying the memory load [S1].
*   Typical values for validation: $g$ and $p$ vary based on the search space; fixed validation points included $p=17$ and $g=80$ [S1].

**Formulas**
The size $S$ and quality $Q$ are modeled as polynomials of $g$ and $p$ [S1]:

$$
S = f_s(g, p) = \frac{k}{(g + a)^3} + m \cdot (p + b)^2
$$

$$
Q = f_q(g, p) = k' \cdot (g + a')^3 \cdot (p + b')^2
$$

Where $k, m, a, b, k', m', a', b'$ are coefficients determined through curve fitting [S1].

**Algorithm Steps**
1.  **Define Search Space:** Identify the valid ranges for $g$ and $p$ based on the target mesh-assisted NeRF implementation (e.g., mobile-NeRF or NeRF2Mesh) [S1].
2.  **Generate Sample Points:** Use a variable step-size searching strategy to select configuration pairs $(g, p)$ for curve fitting [S1]:
    *   Select $g$ values iteratively. For the $i$-th sample, if $g_{i-1}$ is the previous sample point value, the step size is $2 \cdot g_{i-1}$. Thus, $g_i = g_{i-1} + 2 \cdot g_{i-1} = 3 \cdot g_{i-1}$ [S1].
    *   For each selected $g$, select three distinct $p$ values: the minimum, maximum, and midpoint of the valid patch size range [S1].
    *   Pair each $g$ with these three $p$ values to form sample points [S1].
3.  **Compute Ground Truth:** For each sample point $(g, p)$, compute the actual $S$ and $Q$ values.
    *   $S$ is calculated by summing the memory footprint of the voxel grid and the texture images [S1].
    *   $Q$ is calculated by rendering the scene with the configuration and computing the SSIM against a reference image [S1].
4.  **Curve Fitting:** Fit the parameters $\theta$ for both $f_s$ and $f_q$ using the collected sample points $(g, p, S)$ and $(g, p, Q)$ [S1].
5.  **Prediction:** For any new configuration $(g, p)$, compute $S$ and $Q$ using the fitted polynomials [S1].

**Pseudocode**
```python
import numpy as np
from scipy.optimize import curve_fit

def size_model(g, p, k, m, a, b):
    """Polynomial model for data size S."""
    return k / ((g + a)**3) + m * ((p + b)**2)

def quality_model(g, p, k_prime, m_prime, a_prime, b_prime):
    """Polynomial model for quality Q (SSIM)."""
    return k_prime * ((g + a_prime)**3) * ((p + b_prime)**2)

def generate_sample_points(g_min, g_max, p_min, p_max):
    """
    Generate sample points using variable step-size strategy.
    Returns list of (g, p) tuples.
    """
    samples = []
    # Start with an initial g value. The source implies an iterative process.
    # Assuming g starts at a base value, e.g., g_min or a small power of 2.
    # The source says "step size is 2*g' where g' is the previous sample point value".
    # This implies g_next = g_prev + 2*g_prev = 3*g_prev.
    
    # We need an initial g. Let's assume g_min is the start or a small value.
    # To be safe and cover the range, we iterate until g exceeds g_max.
    g_current = g_min
    while g_current <= g_max:
        # Select three p values: min, max, midpoint
        p_mid = (p_min + p_max) / 2.0
        p_values = [p_min, p_mid, p_max]
        
        for p in p_values:
            samples.append((g_current, p))
        
        # Update g using variable step size
        g_current = g_current + 2 * g_current  # Equivalent to 3 * g_current
        
    return samples

def fit_profiling_models(sample_points, ground_truth_S, ground_truth_Q):
    """
    Fit the polynomial models to the ground truth data.
    sample_points: list of (g, p)
    ground_truth_S: list of S values
    ground_truth_Q: list of Q values
    Returns fitted parameters for S and Q models.
    """
    g_vals = np.array([pt[0] for pt in sample_points])
    p_vals = np.array([pt[1] for pt in sample_points])
    
    # Fit Size Model
    # Initial guess for parameters [k, m, a, b]
    p0_s = [1.0, 1.0, 1.0, 1.0]
    try:
        popt_s, _ = curve_fit(size_model, (g_vals, p_vals), ground_truth_S, p0=p0_s)
    except RuntimeError:
        # Fallback if fitting fails, use default or raise error
        popt_s = p0_s
        
    # Fit Quality Model
    # Initial guess for parameters [k_prime, m_prime, a_prime, b_prime]
    p0_q = [1.0, 1.0, 1.0, 1.0]
    try:
        popt_q, _ = curve_fit(quality_model, (g_vals, p_vals), ground_truth_Q, p0=p0_q)
    except RuntimeError:
        popt_q = p0_q
        
    return popt_s, popt_q

def predict(g, p, params_s, params_q):
    """
    Predict size and quality for a given configuration.
    params_s: fitted parameters for size model
    params_q: fitted parameters for quality model
    """
    k, m, a, b = params_s
    k_prime, m_prime, a_prime, b_prime = params_q
    
    S = size_model(g, p, k, m, a, b)
    Q = quality_model(g, p, k_prime, m_prime, a_prime, b_prime)
    
    return S, Q
```

**Edge Cases and Pitfalls**
*   **MLP Exclusion:** The method excludes the MLP configuration knob because its size is small (KBs) and MLP quantization has poor compatibility with commercial rendering engines [S1].
*   **Precision:** The model relies on curve fitting; if the sample points do not adequately cover the configuration space, the polynomial may not generalize well [S1].
*   **Degenerate Input:** $g$ and $p$ must be positive integers. The polynomial forms assume $g+a > 0$ and $p+b > 0$ to avoid division by zero or negative bases for non-integer exponents (though exponents are integers here, the structure implies positive domains) [S1].

## Operating characteristics
*   **Time Complexity:** The profiling model itself is $O(1)$ for prediction once parameters are fitted. The setup cost depends on the number of sample points used for curve fitting. The variable step-size strategy minimizes the number of sampling points required [S1].
*   **Memory Complexity:** The model stores only 8 parameters for size and 8 for quality, making it extremely lightweight compared to storing full neural networks or large lookup tables [S1].
*   **Measured Performance:** Validated on four objects with 45 configuration pairs. Average error in quality prediction (SSIM) is 0.0065 with a standard deviation of 0.0088. Average error in size prediction is 3.3410 (units not specified, likely KB or MB) with a standard deviation of 2.7345 [S1].
*   **Strengths:** Avoids the significant time and resource costs of training the neural network (which can take several hours on multiple GPUs) [S1]. Provides a white-box, interpretable model based on rendering knowledge [S1].
*   **Limitations:** Limited to mesh-assisted NeRF solutions where objects are converted to voxel grid representations. Does not account for MLP configuration changes [S1].

## Background
Lightweight Profiling was introduced in the NeRFlex paper as part of a resource-aware real-time rendering system for mobile devices [S1]. It addresses the high cost of configuration search in mesh-assisted NeRFs, such as mobile-NeRF and NeRF2Mesh, where training time scales with configuration requirements [S1]. The method leverages the structural properties of voxel grids and texture images to create simple polynomial models [S1].
