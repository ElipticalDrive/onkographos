# FastNeRF Cache Size Estimation


## Overview
FastNeRF Cache Size Estimation provides analytical formulas to calculate the memory footprint of the position-dependent and direction-dependent caches in the FastNeRF architecture [S1, unofficial]. It addresses the impracticality of standard NeRF caches, which can exceed 60TB even for highly sparse volumes ($\alpha = 0.01$), by accounting for the factorized representation of the direction-dependent cache [S1, unofficial].

## How it works
The method calculates the total memory size $M$ in bits for the position-dependent and direction-dependent caches [S1, unofficial].

**Inputs:**
*   $\alpha \in [0, 1)$: Inverse volume sparsity, where $\alpha = 1$ indicates a dense volume [S1, unofficial].
*   $k$: Number of bins per dimension in the position-dependent cache [S1, unofficial].
*   $l$: Number of bins per dimension in the direction-dependent cache [S1, unofficial].
*   $D$: Number of components or factors in the direction cache decomposition [S1, unofficial].
*   $s_\sigma$: Size in bits of the stored transparency value [S1, unofficial].
*   $s_{rgb}$: Size in bits of the stored RGB color value [S1, unofficial].
*   $s_{uvw}$: Size in bits of the stored $(u_i, v_i, w_i)$ coordinate values [S1, unofficial].
*   $s_{\beta}$: Size in bits of the stored weights $\beta_i$ [S1, unofficial].

**Outputs:**
*   $M_{NeRF}$: Estimated memory size in bits for a standard NeRF cache [S1, unofficial].
*   $M_{FastNeRF}$: Estimated memory size in bits for the FastNeRF cache [S1, unofficial].

**Formulas:**
1.  **Standard NeRF Cache Size:**
    $$M_{NeRF} = \alpha(s_\sigma + s_{rgb})k^3l^2$$
    This formula assumes a dense lookup table for direction-dependent colors, requiring storage of full RGB vectors for every direction bin [S1, unofficial].
2.  **FastNeRF Cache Size:**
    $$M_{FastNeRF} = \alpha \left( (D \cdot s_{uvw} + s_{\sigma})k^3 \right) + D \cdot s_{\beta}l^2$$
    This formula accounts for the factorized representation, where the position cache stores $D$ coordinate factors and transparency, and the direction cache stores $D$ weight factors [S1, unofficial].

**Parameters and Typical Values:**
*   Standard implementation uses $k = l = 1024$ [S1, unofficial].
*   Number of factors $D = 8$ [S1, unofficial].
*   Color channels $(r, g, b)$ are stored as individual bytes ($s_{rgb} = 24$ bits) [S1, unofficial].
*   Coordinate, weight, and transparency values are stored as half-precision floats ($s_{uvw} = 16$ bits, $s_{\beta} = 16$ bits, $s_{\sigma} = 16$ bits) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **High Memory Usage:** Even for highly sparse volumes with $\alpha = 0.01$, the standard NeRF cache size is nearly 60TB, which exceeds the memory capacity of consumer-grade hardware [S1, unofficial].
*   **Dense Volume:** If $\alpha = 1$, the memory requirements are maximized [S1, unofficial].
*   **Data Type Sensitivity:** The choice of storage size ($s_{uvw}, s_{\beta}, s_{rgb}$) significantly impacts the total memory [S1, unofficial].

**Pseudocode:**
```python
def calculate_neRF_cache_size(alpha, s_sigma, s_rgb, k, l):
    """Calculate memory size in bits for standard NeRF cache."""
    return alpha * (s_sigma + s_rgb) * (k ** 3) * (l ** 2)

def calculate_fastNeRF_cache_size(alpha, D, s_uvw, s_sigma, s_beta, k, l):
    """Calculate memory size in bits for FastNeRF cache."""
    position_cache_size = alpha * ((D * s_uvw) + s_sigma) * (k ** 3)
    direction_cache_size = D * s_beta * (l ** 2)
    return position_cache_size + direction_cache_size
```

## Background
The FastNeRF Cache Size Estimation method originates from the FastNeRF paper by Garbin et al. [S1, unofficial]. It was developed to address the high memory requirements of standard NeRF architectures, which store full RGB vectors for every direction bin [S1, unofficial]. The factorized representation in FastNeRF reduces this footprint, making it feasible for consumer-grade hardware [S1, unofficial]. The formulas are derived from the structure of the position-dependent and direction-dependent caches in the FastNeRF architecture [S1, unofficial].
