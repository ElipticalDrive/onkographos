# VoxGRAF

Also called: VoxGRAF: Fast 3D-Aware Image Synthesis with Sparse Voxel Grids

## Overview
VoxGRAF is a 3D-aware Generative Adversarial Network (GAN) that replaces the coordinate-based Multi-Layer Perceptron (MLP) scene representation with a sparse voxel grid generator [S1]. It solves the problem of slow rendering and viewpoint/content entanglement inherent in coordinate-based 3D-aware GANs by enabling fast, 3D-consistent image synthesis via a single forward pass [S1]. Unlike sibling methods that rely on neural rendering or reduced sample points, VoxGRAF generates high-resolution geometry directly on a sparse grid, leveraging fast trilinear interpolation to maintain visual fidelity without reducing the number of samples [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A latent code $z \in \mathbb{R}^M$ sampled from a standard normal distribution $\mathcal{N}(0,1)$, and a camera pose $\xi$ (extrinsics) and intrinsics $K$ [S1].
*   **Outputs:** A rendered RGB image $\hat{I}$ and an optional alpha mask $a_r$ [S1].

**Data Structures:**
*   **Sparse Voxel Grid:** A 3D structure storing color $c \in \mathbb{R}^3$ and density $\sigma \in \mathbb{R}^+$ values [S1].
    *   **Resolution:** The grid has a base resolution $R_G$ [S1].
    *   **Layout:** The grid is sparse, meaning only occupied voxels are stored to mitigate cubic memory growth [S1]. The exact sparse data structure (e.g., hash table, linked list) is not specified in the sources, but the mechanism relies on efficient querying [S1].
    *   **Fields:** Each active voxel stores a color vector $c$ and a scalar density $\sigma$ [S1].

**Numbered Steps:**

1.  **Foreground Generation:** The foreground generator $G_{f_{\theta_{fg}}}$ takes the latent code $z$ and camera pose $\xi$ as input. It produces color values $c \in \mathbb{R}^{3 \times R_G \times R_G \times R_G}$ and densities $\sigma \in \mathbb{R}^{1 \times R_G \times R_G \times R_G}$ on a sparse voxel grid of resolution $R_G$ [S1].
2.  **Ray Sampling:** For a given camera pose $\xi'$ and intrinsics $K$, rays are cast through the scene. $N$ sampling points are placed along each ray $r$ [S1].
3.  **Voxel Query:** Values at the sampling points are computed by trilinearly interpolating the voxel grid [S1]. This replaces the MLP query used in methods like GRAF [S1].
4.  **Volume Rendering:** The radiance field is rendered by approximating the volumetric projection integral via numerical integration [S1]. For each camera ray $r$, the sampled points yield colors and densities $\{(c_i^r, \sigma_i^r)\}_{i=1}^N$ [S1].
5.  **Alpha Composition:** The points are projected to an RGB color value $c_r$ and an alpha mask $a_r$ using alpha composition [S1]:
    $$
    c_r = \sum_{i=1}^{N} T_i \alpha_i^r c_i^r
    $$
    $$
    a_r = \sum_{i=1}^{N} T_i \alpha_i^r
    $$
    where $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j^r)$ is the transmittance, and $\alpha_i^r = 1 - \exp(-\sigma_i^r \delta_i^r)$ is the opacity, with $\delta_i^r = \|x_{i+1}^r - x_i^r\|_2$ being the distance between neighboring sample points [S1].
6.  **Background Generation:** A separate 2D GAN $G_{bg_{\theta_b}}$ generates the background [S1].
7.  **Final Composition:** The foreground and background are combined using alpha composition to produce the final image $\hat{I}$ [S1].
8.  **Discrimination:** The discriminator $D_{\phi}$ compares the generated image $\hat{I}$ to the real image $I_{real}$ [S1].

**Parameters:**
*   $R_G$: The resolution of the sparse voxel grid for the foreground generator [S1].
*   $N$: The number of sampling points along each camera ray [S1].
*   $z$: An $M$-dimensional latent variable [S1].
*   $\gamma(\cdot)$: Fixed positional encoding used to project inputs (if any coordinate-based components remain, though the core is voxel-based) to higher-dimensional features [S1].

    # N points are sampled along each ray r

    # Step 4: Query the sparse voxel grid
    # Values are retrieved via trilinear interpolation
    colors = trilinear_interpolate(color_grid, sample_points)
    densities = trilinear_interpolate(density_grid, sample_points)
    
    # Step 5: Compute opacity and transmittance
    # Calculate distances between adjacent sample points
    deltas = compute_distances(sample_points)
    
    # Alpha values: alpha = 1 - exp(-sigma * delta)
    alphas = 1.0 - torch.exp(-densities * deltas)
    
    # Transmittance: T_i = product(1 - alpha_j) for j < i
    # T_1 is always 1.0
    transmittances = compute_transmittance(alphas)
    
    # Step 6: Alpha composition for foreground
    # c_r = sum(T_i * alpha_i * c_i)
    weights = transmittances * alphas
    foreground_color = torch.sum(weights.unsqueeze(-1) * colors, dim=1)
    foreground_alpha = torch.sum(weights, dim=1)
    
    # Step 7: Generate background
    # A separate 2D GAN generates the background
    background_image = generate_background_2d(z, camera_pose)
    
    # Step 8: Combine foreground and background
    # Final image = foreground + (1 - foreground_alpha) * background
    rendered_image = foreground_color + (1.0 - foreground_alpha.unsqueeze(-1)) * background_image
    
    return rendered_image

**Edge Cases and Pitfalls:**
*   **Memory Growth:** Dense voxel grids suffer from cubic memory growth, limiting resolution. VoxGRAF uses sparsity to mitigate this [S1].
*   **Entanglement:** Neural rendering often entangles viewpoint and content. VoxGRAF is 3D-consistent by design, avoiding unwanted changes in geometry or appearance when changing camera pose [S1].
*   **Performance:** Rendering an image at 256x256 resolution with 48 sample points per ray requires approximately 3 million MLP queries in coordinate-based methods. VoxGRAF avoids this by generating the scene once and rendering in milliseconds [S1].

## Subtopics

### Sparse Voxel Grids
A 3D representation that stores only occupied voxels, enabling higher resolutions than dense grids. It sets itself apart by allowing fast trilinear interpolation and reduced memory usage. Choose it when high-resolution 3D consistency is required without the cost of per-ray MLP queries [S1]. Link: [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md).

### 3D-Aware GANs
GANs that generate 3D-consistent images. VoxGRAF sets itself apart by using a sparse voxel grid generator instead of a coordinate-based MLP, enabling single-pass rendering. Choose it for fast, high-fidelity 3D-aware synthesis [S1]. Link: [Voxel-based Radiance Fields](11470-voxel-based-radiance-fields.md).

## Operating characteristics
*   **Time Complexity:** Inference requires a single forward pass to generate the 3D scene. Once generated, rendering images takes milliseconds [S1]. This is two orders of magnitude faster than existing approaches that require another forward pass per view [S1].
*   **Memory Complexity:** Sparse voxel grids mitigate the cubic memory growth of dense grids, allowing scaling to higher resolutions [S1].
*   **Measured Performance:** Rendering a 256x256 image with 48 samples per ray in coordinate-based methods requires ~3M MLP queries. VoxGRAF performs these queries via fast trilinear interpolation [S1].
*   **Strengths:** Fast rendering, 3D consistency, high visual fidelity, no viewpoint/content entanglement [S1].
*   **Limitations:** Requires a 2D GAN for background generation, which may limit full 3D consistency of the background [S1].
*   **When to Use:** When fast, high-resolution, 3D-consistent image synthesis is needed, and the scene can be decomposed into foreground (3D) and background (2D) [S1].
*   **When Not to Use:** When full 3D consistency of the entire scene (including complex backgrounds) is required without decomposition [S1].

## Background
VoxGRAF was introduced in the paper "VoxGRAF: Fast 3D-Aware Image Synthesis with Sparse Voxel Grids" [S1]. It was motivated by the limitations of coordinate-based 3D-aware GANs (like GRAF) which require a forward pass for every point along each camera ray, leading to slow rendering and viewpoint/content entanglement [S1]. VoxGRAF builds on recent results in voxel-based novel view synthesis and sparse 3D representations (e.g., Plenoxels, DVGO) to replace monolithic MLPs with 3D convolutions on sparse voxel grids [S1]. It combines sparse voxel grids with progressive growing, free space pruning, and appropriate regularization [S1].
