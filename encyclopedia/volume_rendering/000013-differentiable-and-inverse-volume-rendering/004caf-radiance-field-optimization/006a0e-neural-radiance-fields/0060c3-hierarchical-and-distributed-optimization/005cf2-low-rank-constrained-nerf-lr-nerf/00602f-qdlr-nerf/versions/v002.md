# QDLR-NeRF

Also called: DLR-NeRF, LR-NeRF, Light Field Compression via Compact Neural Scene Representation, Quantized Distilled Low Rank Neural Radiance Field[S2, unofficial]

## Overview
QDLR-NeRF is a light field compression method that learns a Neural Radiance Field (NeRF) from input views, optimizes its MLP weights under a low-rank constraint using the Alternating Direction Method of Multipliers (ADMM), decomposes the weights into Tensor Train (TT) components to create a distilled network (DLR-NeRF), and quantizes the distilled weights to produce a compact representation (QDLR-NeRF) [S1][S2, unofficial]. It differs from standard NeRF by using a single MLP and trainable camera parameters to halve the parameter count, and from its parent LR-NeRF by adding network distillation and global codebook quantization to further reduce model size to 3.3% of the original while maintaining reconstruction quality [S1][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of light field views (images) [S1].
*   **Outputs:** A compact neural scene representation consisting of quantized TT components $\hat{Q}1_i, \hat{Q}2_i$, quantized biases $\hat{b}_i$, camera parameters $f, \Delta$, and a global codebook $C$ [S1].

**Data Structures:**
*   **MLP Architecture:** An 8-layer Multi-Layer Perceptron (MLP) with 256 channels [S1].
*   **Weight Layout:** Weights $W_i$ are decomposed into Tensor Train (TT) components $Q1_i \in \mathbb{R}^{1 \times n_1 \times r}$ and $Q2_i \in \mathbb{R}^{r \times n_2 \times 1}$ [S1].
*   **Transmission Payload:** The final encoded bitstream contains $\hat{Q}1_i, \hat{Q}2_i$ (Huffman encoded), $\hat{b}_i$ (16-bit uniform), $f$ (32-bit), $\Delta$ (32-bit), and the codebook $C$ (32-bit) [S1].

**Parameters:**
*   **Target Rank ($r$):** 40 for both LR-NeRF and DLR-NeRF stages [S2, unofficial].
*   **Codebook Size ($N$):** 256 centroids [S2, unofficial].
*   **Penalty Parameter ($\rho$):** 10 [S1].
*   **Learning Rate:** $5 \times 10^{-4}$ with exponential decay rate 0.1 [S1].
*   **Iterations:** $3 \times 10^5$ for NeRF initialization and rank optimization; $2 \times 10^5$ for DLR-NeRF finetuning; $3 \times 10^4$ for quantization-aware training per layer [S1].
*   **Sampling Rate:** 128 samples along light rays [S1][S2, unofficial].
*   **Initialization:** Focal length $f$ initialized to $0.01W$ (where $W$ is image width); offset $\Delta$ initialized to 10 [S1].

**Algorithm Steps:**

1.  **NeRF Initialization:** Optimize weights $W_i$, biases $b_i$, focal length $f$, and offset $\Delta$ by minimizing the squared L2 error between rendered pixels $c'$ and ground-truth pixels $c_{gt}$ [S1].
    $$ \{W_i, b_i, f, \Delta\} = \arg\min_{W_i,b_i,f,\Delta} \|c' - c_{gt}\|^2_2 $$
    The NeRF takes 5D coordinates $(x, y, z, \theta, \phi)$ of light rays as input to predict color (RGB) and density ($\sigma$) [S1].

2.  **Rank Optimization (ADMM):** Reformulate the low-rank constraint problem using an indicator function $g(W_i)$ (0 if rank $< r$, $+\infty$ otherwise) and auxiliary variable $Z_i$ [S1]. Solve via augmented Lagrangian $L(W_i, Z_i, U_i)$ [S1].
    $$ L(W_i, Z_i, U_i) = l(W_i) + g(Z_i) + \frac{\rho}{2}\|W_i - Z_i + U_i\|^2_F + \frac{\rho}{2}\|U_i\|^2_F $$
    where $l = \|c' - c_{gt}\|^2_2$ is the rendering error, $\rho$ is the penalty parameter, and $U_i$ is the dual multiplier [S1].
    The optimization proceeds via alternating updates [S1]:
    *   **Update $W_i$:** Minimize $L(W_i^t, Z_i^t, U_i^t)$ using gradient descent [S1].
    *   **Update $Z_i$:** Project $(W_i^{t+1} + U_i^t)$ onto the set of matrices with rank $< r$ using TT decomposition truncated to rank $r$ [S1].
        $$ Z_i^{t+1} = \Pi_r(W_i^{t+1} + U_i^t) $$
        where $\Pi_r$ is the operation that decomposes the matrix into the TT format truncated to the desired rank $r$ [S1].
    *   **Update $U_i$:**
        $$ U_i^{t+1} = U_i^t + W_i^{t+1} - Z_i^{t+1} $$
    This step is repeated for $3 \times 10^5$ iterations [S1].

3.  **Network Distillation:** Decompose the optimized low-rank weights $W_i$ into TT components $Q1_i$ and $Q2_i$ [S1]. Initialize a smaller network (DLR-NeRF) by neglecting the first dimension of $Q1_i$ and the last dimension of $Q2_i$ [S1]. Only perform decomposition if the parameter count is reduced [S1].
    $$ W_i = Q1_i \cdot Q2_i $$
    where $Q1_i \in \mathbb{R}^{1 \times n_1 \times r}$ and $Q2_i \in \mathbb{R}^{r \times n_2 \times 1}$ [S1].

4.  **Finetuning:** Gradually quantize the layers of the DLR-NeRF from the first layer to the last one using a global codebook learned by k-means to obtain the final QDLR-NeRF [S2, unofficial]. Finetune the distilled network for $2 \times 10^5$ iterations to stabilize performance [S1].

5.  **Quantization Strategy:**
    *   **Values outside $[-1, 1]$:** Quantize using a uniform 16-bit quantizer [S1].
    *   **Values inside $[-1, 1]$:** Quantize using a non-uniform optimized quantizer with codebook $C$ obtained via k-means clustering into $N$ centroids [S1].
    *   **Biases:** Precisely quantize biases $b_i$ with a 16-bit uniform quantizer to compensate for weight quantization error [S1].
    *   **Global vs Local:** Use a single global codebook for all layers to achieve higher compression ratio, accepting slightly more distortion compared to local layer-wise codebooks [S1][S2, unofficial].

6.  **Quantization-Aware Training:**
    *   Quantize $Q1_i, Q2_i$ for layer $i=n$ [S1].
    *   Continue training to update $Q1_j, Q2_j$ for $j > n$ and biases $b_i$ [S1].
    *   After all layers are quantized, update the codebook and iterate [S1]. One iteration is found sufficient [S1].

7.  **Encoding:** Encode quantized matrices $\hat{Q}1_i, \hat{Q}2_i$ using Huffman coding [S1]. Code the union of parameters inside and outside $[-1, 1]$ directly to avoid extra indication flags [S1].

**Pseudocode:**

```python
def qdlr_nerf(light_field_views, image_width: int, target_rank: int = 40, codebook_size: int = 256):
    # 1. NeRF Initialization
    # Initialize 8-layer MLP with 256 channels
    W = [random_init_matrix() for _ in range(8)]
    b = [random_init_vector() for _ in range(8)]
    f = 0.01 * image_width
    delta = 10
    
    # Minimize ||c' - c_gt||^2_2 for 3e5 iterations
    for _ in range(300000):
        c_prime = render_5d_nerf(W, b, f, delta, light_field_views, samples=128)
        loss = sum((c_prime[k] - c_gt[k])**2 for k in range(len(c_gt)))
        W = [W[i] - 5e-4 * grad(loss, W[i]) for i in range(8)]
        b = [b[i] - 5e-4 * grad(loss, b[i]) for i in range(8)]
        f -= 5e-4 * grad(loss, f)
        delta -= 5e-4 * grad(loss, delta)
        
    # 2. Rank Optimization (ADMM)
    Z = [zeros_like(W[i]) for i in range(8)]
    U = [zeros_like(W[i]) for i in range(8)]
    rho = 10
    
    for _ in range(300000):
        # Update W: Gradient descent on augmented Lagrangian
        W = [W[i] - 5e-4 * grad(L(W, Z, U, rho), W[i]) for i in range(8)]
        
        # Update Z: Project (W + U) onto rank < r using TT decomposition
        for i in range(8):
            Z[i] = tt_truncate(W[i] + U[i], rank=target_rank)
            
        # Update U: U = U + W - Z
        for i in range(8):
            U[i] = U[i] + W[i] - Z[i]
            
    # 3. Network Distillation
    distilled_W = []
    for i in range(8):
        Q1, Q2 = tt_decompose(W[i], rank=target_rank)
        if parameter_count(Q1, Q2) < parameter_count(W[i]):
            # Neglect first dim of Q1 and last dim of Q2
            distilled_W.append(concat(Q1[:, :, :-1], Q2[1:, :, :]))
        else:
            distilled_W.append(W[i])
            
    # 4. Finetuning
    for _ in range(200000):
        c_prime = render_5d_nerf(distilled_W, b, f, delta, light_field_views, samples=128)
        loss = sum((c_prime[k] - c_gt[k])**2 for k in range(len(c_gt)))
        distilled_W = [distilled_W[i] - 5e-4 * grad(loss, distilled_W[i]) for i in range(8)]
        b = [b[i] - 5e-4 * grad(loss, b[i]) for i in range(8)]
        
    # 5. Quantization & 6. Quantization-Aware Training
    codebook = kmeans_cluster(distilled_W, N=codebook_size, iterations=20)
    
    for layer_idx in range(8):
        # Quantize Q1, Q2 for current layer
        for param in [distilled_W[layer_idx], b[layer_idx]]:
            for val in param:
                if abs(val) > 1.0:
                    quantize_uniform_16bit(val)
                else:
                    quantize_nonuniform(val, codebook)
        b[layer_idx] = quantize_uniform_16bit(b[layer_idx])
        
        # Quantization-aware training for subsequent layers and biases
        for _ in range(30000):
            c_prime = render_5d_nerf(distilled_W, b, f, delta, light_field_views, samples=128)
            loss = sum((c_prime[k] - c_gt[k])**2 for k in range(len(c_gt)))
            for j in range(layer_idx + 1, 8):
                distilled_W[j] -= 5e-4 * grad(loss, distilled_W[j])
                b[j] -= 5e-4 * grad(loss, b[j])
                
    # Update codebook once after all layers quantized
    codebook = kmeans_cluster(distilled_W, N=codebook_size, iterations=20)
    
    # 7. Encoding
    bitstream = huffman_encode(distilled_W + b)
    
    return bitstream, codebook, f, delta
```

## Subtopics

### LR-NeRF
An optimization step where the simplified NeRF weights are finetuned under a low-rank constraint using the Alternating Direction Method of Multipliers (ADMM) to prepare for Tensor Train decomposition [S2, unofficial]. It sets the stage for distillation by ensuring weights are low-rank [S1]. [Link: [Low-Rank Constrained NeRF (LR-NeRF)](17322-low-rank-constrained-nerf-lr-nerf.md)]

### DLR-NeRF
The distilled version of LR-NeRF, where low-rank weights are decomposed into Tensor Train components to create a smaller network [S1]. It avoids the instability of training a small network from scratch [S2, unofficial].

## Operating characteristics
*   **Time and Memory Complexity:** The method involves multiple optimization phases (NeRF init, ADMM, finetuning), each requiring significant GPU memory and time [S1]. The ADMM step adds overhead due to the projection operation [S1]. The final model size is reduced to 3.3% of the original NeRF [S2, unofficial].
*   **Measured Performance:** Averaged over four synthetic scenes:
    *   NeRF-org: 41.98 dB PSNR, 100% size [S2, unofficial].
    *   LR-NeRF: 38.83 dB PSNR, 50% size [S2, unofficial].
    *   DLR-NeRF: 38.72 dB PSNR, 16.7% size [S2, unofficial].
    *   QDLR-NeRF: 38.18 dB PSNR, 3.3% size [S2, unofficial].
*   **Scaling:** The method is designed for light field compression, handling both synthetic and real-world (Lytro-captured) datasets [S2, unofficial].
*   **Strengths:** High compression ratio (down to 3.3% size) with acceptable PSNR loss (0.6 dB from DLR-NeRF) [S2, unofficial]. Free-viewpoint reconstruction capability [S1]. Outperforms reference methods with a large margin [S2, unofficial].
*   **Limitations:** The transition from NeRF-org to LR-NeRF incurs a ~3 dB PSNR loss due to estimated camera poses and low-rank constraint [S2, unofficial]. Training from scratch with random initialization for the distilled network can lead to local minima and blurriness [S2, unofficial].
*   **When to use:** Light field compression where storage and transmission bandwidth are critical, and free-viewpoint synthesis is required [S2, unofficial].
*   **When not to use:** When maximum possible PSNR is required without compression, or when computational resources for the multi-stage optimization are insufficient [S1][S2, unofficial].

## Background
QDLR-NeRF was proposed by Jinglei Shi and Christine Guillemot in the paper "Light Field Compression via Compact Neural Scene Representation" [S1]. It builds upon the NeRF framework [S1] and addresses the large data volume and redundancy of light fields [S1]. The method sequentially applies low-rank constraints, network distillation, and quantization to reduce model size while maintaining reconstruction quality [S2, unofficial]. It is applied to light field compression on both synthetic and real-world datasets [S2, unofficial].
