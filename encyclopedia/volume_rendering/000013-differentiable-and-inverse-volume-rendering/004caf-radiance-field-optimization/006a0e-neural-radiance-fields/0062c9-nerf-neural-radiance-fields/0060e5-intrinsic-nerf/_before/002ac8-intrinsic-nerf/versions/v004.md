# Intrinsic NeRF

Also called: Intrinsic Image Decomposition in NeRF, Intrinsic NeRF Decomposition, Intrinsic NeRF Model

## Overview
Intrinsic NeRF is a variant of Neural Radiance Fields that decouples geometry, illumination, and material properties by decomposing the rendered color into reflectance and shading components, solving the ill-posed inverse rendering problem without supervision [S1]. It differs from standard NeRF by explicitly outputting physical scene attributes (density, reflectance, shading) rather than just radiance, enabling downstream tasks like relighting and material analysis [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D location $\mathbf{X} \in \mathbb{R}^3$ and view direction $\mathbf{D} \in \mathbb{R}^3$ (normalized).
*   **Output:** A tuple $(\sigma, \mathbf{R}, S)$ where $\sigma \in \mathbb{R}$ is volume density, $\mathbf{R} \in \mathbb{R}^3$ is reflectance (albedo), and $S \in \mathbb{R}$ is shading (incident illumination intensity) [S1].

**Data Structures:**
Two Multi-Layer Perceptrons (MLPs) are used:
1.  **Reflectance MLP ($f_R$):** Takes $\mathbf{X}$ as input. Outputs $\mathbf{R}$.
2.  **Shading MLP ($f_S$):** Takes $\mathbf{X}$ and $\mathbf{D}$ as inputs. Outputs $S$.
3.  **Density MLP ($f_\sigma$):** (Implicitly part of the standard NeRF architecture or a separate head) Takes $\mathbf{X}$ as input. Outputs $\sigma$. [S1]

**Formulas:**
The rendered color $\hat{\mathbf{C}}(\mathbf{r})$ for a ray $\mathbf{r}$ is computed via volume rendering integration from near plane $t_n$ to far plane $t_f$:
$$
\hat{\mathbf{C}}(\mathbf{r}) = \int_{t_n}^{t_f} T(t) \sigma(t) (\mathbf{S}(t) \cdot \mathbf{R}(t)) dt
$$
where:
*   $T(t) = \exp\left(-\int_{t_n}^{t} \sigma(s) ds\right)$ is the transmittance.
*   $\mathbf{S}(t)$ is the shading scalar at $t$.
*   $\mathbf{R}(t)$ is the reflectance vector at $t$.
*   The dot product $\mathbf{S}(t) \cdot \mathbf{R}(t)$ effectively scales the reflectance by the shading intensity [S1].

**Training:**
The model is trained using only RGB images from the input dataset, with no additional lighting or material labels [S1]. The loss function is the mean squared error between the rendered color and the ground truth RGB:
$$
\mathcal{L} = \frac{1}{|\mathcal{R}|} \sum_{\mathbf{r} \in \mathcal{R}} \|\hat{\mathbf{C}}(\mathbf{r}) - \mathbf{C}(\mathbf{r})\|_2^2
$$
where $\mathbf{C}(\mathbf{r})$ is the ground truth color and $\mathcal{R}$ is the set of camera rays in a batch [S1].

**Pseudocode:**
```python
def intrinsic_nerf_forward(xyz, view_dir, density_mlp, reflectance_mlp, shading_mlp):
    """
    Computes density, reflectance, and shading for a batch of points.
    
    Args:
        xyz: Tensor of shape (N, 3), 3D coordinates.
        view_dir: Tensor of shape (N, 3), normalized view directions.
        density_mlp: MLP taking xyz -> sigma (scalar).
        reflectance_mlp: MLP taking xyz -> R (vector, 3).
        shading_mlp: MLP taking xyz, view_dir -> S (scalar).
        
    Returns:
        sigma: Tensor of shape (N, 1), density.
        R: Tensor of shape (N, 3), reflectance.
        S: Tensor of shape (N, 1), shading.
    """
    # Compute density from location only
    sigma = density_mlp(xyz)
    
    # Compute reflectance from location only
    R = reflectance_mlp(xyz)
    
    # Compute shading from location and view direction
    S = shading_mlp(xyz, view_dir)
    
    return sigma, R, S

def render_intrinsic_ray(rays_o, rays_d, t_n, t_f, num_samples, density_mlp, reflectance_mlp, shading_mlp):
    """
    Renders a single ray using volume rendering with intrinsic decomposition.
    
    Args:
        rays_o: Origin of the ray (3,).
        rays_d: Direction of the ray (3,).
        t_n: Near plane distance.
        t_f: Far plane distance.
        num_samples: Number of samples along the ray.
        
    Returns:
        C_hat: Rendered color (3,).
    """
    # Sample points along the ray
    t_vals = torch.linspace(t_n, t_f, num_samples)
    xyz = rays_o.unsqueeze(0) + t_vals.unsqueeze(1) * rays_d.unsqueeze(0) # Shape: (num_samples, 3)
    
    # Get view direction (constant for the ray)
    view_dir = rays_d.unsqueeze(0).expand_as(xyz)
    
    # Query networks
    sigma, R, S = intrinsic_nerf_forward(xyz, view_dir, density_mlp, reflectance_mlp, shading_mlp)
    
    # Compute transmittance
    # alpha = 1 - exp(-sigma * delta_t)
    # T(t) = product(1 - alpha)
    # Standard volume rendering accumulation
    deltas = t_vals[1:] - t_vals[:-1]
    # Add infinite delta for the last segment to handle transparency correctly
    deltas = torch.cat([deltas, torch.tensor([1e10], device=deltas.device)])
    
    alpha = 1.0 - torch.exp(-sigma * deltas)
    T = torch.cumprod(torch.cat([torch.ones_like(alpha[:, :1]), 1.0 - alpha + 1e-10], dim=1)[:, :-1], dim=1)
    
    # Weighted sum of color
    # Color contribution = T(t) * alpha(t) * S(t) * R(t)
    weights = T * alpha
    color_contribution = weights.unsqueeze(-1) * S * R
    
    C_hat = torch.sum(color_contribution, dim=0)
    
    return C_hat

def train_step(batch, density_mlp, reflectance_mlp, shading_mlp, optimizer):
    """
    Single training step.
    """
    optimizer.zero_grad()
    
    # batch contains rays_o, rays_d, and ground truth colors C
    C_hat = render_intrinsic_ray(...) # Implementation details for batched rays omitted for brevity
    
    # Loss calculation
    loss = torch.mean((C_hat - batch.C_gt) ** 2)
    
    loss.backward()
    optimizer.step()
    
    return loss.item()
```

**Edge Cases and Pitfalls:**
*   **Ill-posedness:** Without supervision on shading or reflectance, the decomposition is ambiguous. The model relies on the inductive bias that reflectance is view-independent and shading is view-dependent [S1].
*   **View Direction Normalization:** View directions must be normalized before input to the shading MLP to ensure consistent lighting estimation [S1].
*   **Density Independence:** The density field $\sigma$ is typically shared or derived from the same location-based network as in standard NeRF, but the color composition explicitly separates it from the material/illumination split [S1].

## Subtopics

### [Geometry Decomposition and Normal Regularization](4854-geometry-decomposition-and-normal-regularization.md)
Enhances geometric consistency by computing differentiable normal maps from the volume density field and applying depth-dependent regularization loss. It solves noisy geometry issues by enforcing surface smoothness weighted by physical area.

## Operating characteristics
*   **Time Complexity:** Similar to standard NeRF training, dominated by MLP evaluations for density, reflectance, and shading per sample. The additional shading MLP adds computational overhead proportional to the number of samples.
*   **Memory Complexity:** Requires storing parameters for three MLPs (density, reflectance, shading) instead of one or two.
*   **Strengths:** Enables inverse rendering tasks such as relighting and material analysis without explicit supervision [S1].
*   **Limitations:** The decomposition is inherently ill-posed; results depend heavily on the network architecture's inductive biases [S1].
*   **When to use:** When the goal is to extract physical scene properties (albedo, lighting) for relighting or editing, rather than just novel view synthesis.

## Background
Intrinsic NeRF was introduced to address the ill-posed problem of inverse rendering 3D scenes without supervision by utilizing a simplified intrinsic image decomposition model [S1]. It builds on the NeRF framework by adding explicit outputs for reflectance and shading [S1].
