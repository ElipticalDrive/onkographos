# NeRDF Learning via Knowledge Distillation

Also called: NeRDF Distillation, Teacher-Student NeRF Distillation

## Overview
NeRDF (Neural Radiance Distribution Field) is a training framework that accelerates view synthesis by distilling knowledge from a pre-trained teacher NeRF into a smaller, faster student model [S1]. Unlike standard NeRF optimization which requires iterative ray marching per pixel, NeRDF learns to predict the full radiance distribution of a ray in a single forward pass, enabling real-time rendering speeds comparable to NeLF but with the quality of NeRF [S1]. It distinguishes itself from sibling methods by explicitly matching the volume density distribution between teacher and student, rather than just pixel colors [S1].

## How it works
The method uses a knowledge distillation framework where a teacher NeRF synthesizes dense and diverse pseudo-training views for a student NeRDF [S1].

**Inputs and Outputs:**
*   **Input:** A set of source images with known camera poses.
*   **Output:** A student NeRDF model capable of rendering novel views at high speed.

**Data Structures:**
*   **Teacher Model:** A standard NeRF MLP (e.g., 8-layer) that outputs density $\sigma$ and color $\mathbf{c}$ [S1].
*   **Student Model:** A smaller NeRDF MLP that outputs the radiance distribution parameters directly [S1].
*   **Ray Encoding:** An input ray encoding method that captures rich ray information (position and direction) [S1].

**Steps:**
1.  **Teacher Rendering:** The pre-trained teacher NeRF renders a dense grid of views. An online view sampling strategy is used to expand the diversity of these pseudo-training data points [S1].
2.  **Student Forward Pass:** For each sampled ray, the student NeRDF processes the ray encoding to predict the radiance distribution. This requires only a single network forward pass per ray, avoiding iterative sampling [S1].
3.  **Density Matching:** An additional loss term matches the volume density distribution of the student NeRDF to that of the teacher NeRF. This promotes the learning of a strong 3D prior [S1].
4.  **Radiance Matching:** The student's predicted radiance is matched to the teacher's rendered radiance (standard distillation loss) [S1].
5.  **Volume Density Constraint:** A volume density constraint loss is applied to further regularize the student's geometry [S1].

**Formulas:**
The total loss $\mathcal{L}$ combines the distillation loss and the density constraint:
$$
\mathcal{L} = \mathcal{L}_{distill} + \lambda \mathcal{L}_{density}
$$
Where $\mathcal{L}_{distill}$ matches the output radiance distributions, and $\mathcal{L}_{density}$ matches the volume density distributions $\sigma$ between teacher and student [S1].

**Parameters:**
*   **Network Depth:** The student uses an 8-layer MLP [S1].
*   **Rendering Speed:** Achieves ~21 FPS on the LLFF dataset without specific inference optimizations [S1].

**Edge Cases and Pitfalls:**
*   **Teacher Quality:** The student's performance is bounded by the teacher's quality. If the teacher is poorly trained, the student inherits these errors [S1].
*   **Training Time:** The distillation process requires the teacher to render many views, increasing total training time compared to training the student from scratch [S2, unofficial].

## Subtopics

### Student-Teacher Training for Neural Light Fields
A training strategy where input data is augmented with synthetic renderings generated by a fully trained teacher model (e.g., NeRF) to improve quantitative metrics [S2, unofficial]. It uses a 10x10 grid of renderings from the teacher [S2, unofficial]. On the Real Forward-Facing dataset, this variant outperforms NeRF in PSNR (e.g., Fern: 26.06 vs 26.92, Flower: 28.90 vs 28.57, Fortress: 32.60 vs 32.94) but requires increased training time [S2, unofficial].

## Operating characteristics
*   **Speed:** ~21 FPS on LLFF dataset, ~5x faster than R2L and ~100x faster than original NeRF [S1].
*   **Memory:** Uses only an 8-layer MLP, comparable to NeLF [S1].
*   **Quality:** Comparable visual quality to existing methods [S1].
*   **Limitations:** Increased training time due to teacher rendering [S2, unofficial].

## Background
Originating from the work on Efficient View Synthesis with Neural Radiance Distribution Field [S1], this method builds on the R2L approach [S2, unofficial] which first exploited KD for view synthesis. It was evaluated on the Real Forward-Facing (LLFF) dataset [S1].
