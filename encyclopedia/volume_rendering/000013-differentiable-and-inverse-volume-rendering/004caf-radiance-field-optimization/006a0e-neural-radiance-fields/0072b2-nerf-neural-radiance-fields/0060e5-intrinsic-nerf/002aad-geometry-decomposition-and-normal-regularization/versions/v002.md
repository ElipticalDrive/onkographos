# Geometry Decomposition and Normal Regularization

Also called: Depth-Dependent Normal Regularization, Normal Map Computation

## Overview
This method enhances the geometric consistency of Intrinsic NeRF by computing differentiable normal maps from the volume density field and applying a depth-dependent regularization loss [S1]. It addresses the problem of noisy, inconsistent geometry in complex scenes [S1]. Unlike standard NeRF variants that optimize only for RGB consistency, this approach explicitly enforces surface smoothness weighted by physical area, ensuring that background pixels (covering larger physical areas) are regularized more strongly than foreground pixels [S1].

## How it works
The method operates on the volume density field $\sigma$ and its gradient $\nabla \sigma$ to derive geometric attributes [S1].

**Inputs and Outputs:**
- **Input:** Camera rays $\mathcal{R}$, near/far bounds $t_n, t_f$, and the trained density field $\sigma(\mathbf{x})$ [S1].
- **Output:** Depth map $\mathbf{D}$, Normal map $\mathbf{N}$, and the regularization loss $\mathcal{L}_d$ [S1].

**Data Structures:**
- **Density Field:** A neural network or voxel grid mapping 3D coordinates $\mathbf{x}$ to scalar density $\sigma$ [S1].
- **Ray Structure:** Each ray $\mathbf{r}$ is defined by origin $\mathbf{o}$ and direction $\mathbf{d}$ [G].
- **Adjacency Map:** A set of neighboring pixel indices for each pixel $\mathbf{r}$ in the image plane [G].

**Formulas:**
1. **Transmittance:** $T(t) = \exp\left(-\int_{t_n}^{t} \sigma(s) ds\right)$ [S1].
2. **Depth Map:** The expected depth along ray $\mathbf{r}$ [S1]:
   $$ \mathbf{D}(\mathbf{r}) = \int_{t_n}^{t_f} T(t) \sigma(t) t dt $$
3. **Normal Map:** The expected surface normal along ray $\mathbf{r}$ [S1]:
   $$ \mathbf{N}(\mathbf{r}) = \int_{t_n}^{t_f} T(t) \sigma(t) (-\nabla \sigma(\mathbf{x}(t))) dt $$
   where $\mathbf{x}(t) = \mathbf{o} + t\mathbf{d}$ [G].
4. **Depth-Dependent Normal Regularization Loss:** Encourages consistency between adjacent pixels, weighted by the inverse square of depth [S1]:
   $$ \mathcal{L}_d = \frac{1}{|\mathcal{R}|} \sum_{\mathbf{r} \in \mathcal{R}} \left( 1 - \frac{\mathbf{N}(\mathbf{r}) \cdot \mathbf{N}(\mathbf{r}_{adj})}{|\mathbf{N}(\mathbf{r})| |\mathbf{N}(\mathbf{r}_{adj})|} \right) \frac{1}{\mathbf{D}(\mathbf{r})^2} $$
   where $\mathbf{r}_{adj}$ denotes the rays corresponding to adjacent pixels to $\mathbf{r}$ [S1].

**Parameters:**
- **Sampling Steps:** Number of samples per ray for integration. Not given in the sources.
- **Adjacency Window:** Typically immediate 4- or 8-neighbors in the image grid. Not given in the sources.

**Pseudocode:**
```python
import math

def compute_geometry_loss(rays, density_net, t_n, t_f, num_samples):
    """
    Computes depth, normal maps, and the depth-dependent normal regularization loss.
    
    Args:
        rays: List of (o, d) tuples, where o and d are 3D vectors.
        density_net: Function returning (sigma, grad_sigma) for point x.
        t_n: Near plane distance.
        t_f: Far plane distance.
        num_samples: Number of integration steps per ray.
        
    Returns:
        L_d: Scalar regularization loss.
    """
    total_loss = 0.0
    count = 0
    normals = []
    depths = []

    # 1. Integrate depth and normal along each ray
    for o, d in rays:
        t_vals = [t_n + i * (t_f - t_n) / (num_samples - 1) for i in range(num_samples)]
        deltas = [t_vals[i+1] - t_vals[i] for i in range(num_samples - 1)]

        sigma_vals = []
        grad_vals = []
        for t in t_vals:
            x = (o[0] + t*d[0], o[1] + t*d[1], o[2] + t*d[2])
            sigma, grad = density_net(x)
            sigma_vals.append(sigma)
            grad_vals.append(grad)

        # Transmittance: T_i = exp(-sum_{j=0}^{i-1} sigma_j * delta_j)
        T = [1.0]
        for i in range(num_samples - 1):
            T.append(T[-1] * math.exp(-sigma_vals[i] * deltas[i]))

        # Discrete integration for Depth and Normal
        depth = 0.0
        normal = [0.0, 0.0, 0.0]
        for i in range(num_samples - 1):
            weight = T[i] * sigma_vals[i] * deltas[i]
            depth += weight * t_vals[i]
            normal[0] += weight * (-grad_vals[i][0])
            normal[1] += weight * (-grad_vals[i][1])
            normal[2] += weight * (-grad_vals[i][2])

        normals.append(normal)
        depths.append(depth)

    # 2. Compute loss over image grid
    # Not given in the sources: grid reshaping logic; assumed raster scan order
    H = int(math.sqrt(len(rays)))
    W = H
    normals_grid = [normals[i*W + j] for i in range(H) for j in range(W)]
    depths_grid = [depths[i*W + j] for i in range(H) for j in range(W)]

    def get_neighbors(i, j):
        neighbors = []
        for di in [-1, 0, 1]:
            for dj in [-1, 0, 1]:
                if di == 0 and dj == 0: continue
                ni, nj = i + di, j + dj
                if 0 <= ni < H and 0 <= nj < W:
                    neighbors.append((ni, nj))
        return neighbors

    for i in range(H):
        for j in range(W):
            idx = i * W + j
            n_r = normals_grid[idx]
            d_r = depths_grid[idx]
            norm_r = math.sqrt(sum(c*c for c in n_r))
            if norm_r < 1e-8: continue

            for ni, nj in get_neighbors(i, j):
                n_adj = normals_grid[ni * W + nj]
                norm_adj = math.sqrt(sum(c*c for c in n_adj))
                if norm_adj < 1e-8: continue

                cos_sim = sum(a*b for a, b in zip(n_r, n_adj)) / (norm_r * norm_adj)
                weight = 1.0 / (d_r**2 + 1e-8)
                total_loss += (1.0 - cos_sim) * weight
                count += 1

    return total_loss / count if count > 0 else 0.0
```

**Edge Cases and Pitfalls:**
- **Noise:** Without this regularization, normal maps exhibit significantly more noise, particularly in complex scenes [S1].
- **Background Weighting:** A pixel in the background corresponds to a larger physical area, so the $1/\mathbf{D}(\mathbf{r})^2$ weight guides the regularization process [S1].
- **Gradient Estimation:** The normal map relies on $\nabla \sigma$ [G]. If the density field is not smooth, the gradient will be noisy, leading to unstable normals [G].

## Subtopics

### DINO Feature Regularization
Regularizes reflectance estimation by distilling DINO features from 2D images to 3D surfaces [S2]. It minimizes the distance between learnable DINO features on the surface and pre-trained ViT features [S2]. Steps: 1. Distill DINO feature to the initial geometry field [S2]. 2. Minimize the loss function by comparing learnable surface features with 2D image features [S2]. 3. Incorporate distilled DINO features into networks for specular albedo and roughness to enhance material decomposition accuracy [S2]. Parameter: Images are upsampled by a scaling factor of two to extract higher resolution DINO features for finer material decoupling [S2].

## Operating characteristics
- **Time Complexity:** Adds overhead for computing gradients of density $\nabla \sigma$ and integrating normal maps. The adjacency comparison is $O(|\mathcal{R}|)$ per batch [G].
- **Memory Complexity:** Requires storing normal maps for the current batch [G].
- **Strengths:** Significantly reduces noise in normal maps, leading to smoother geometry and better material decomposition [S1].
- **Limitations:** Requires differentiable density field to compute $\nabla \sigma$ [G]. Sensitive to the choice of adjacency window and depth weighting [G].
- **When to use:** When high-quality geometry is required for subsequent intrinsic decomposition tasks, especially in complex scenes [S1].

## Background
Originated in the context of Intrinsic NeRF to address the ill-posed nature of inverse rendering [S1]. The depth-dependent normal regularization was introduced to improve geometric consistency by leveraging the pinhole camera model's property that background pixels cover larger physical areas [S1]. DINO feature regularization was later introduced to further constrain reflectance estimation using self-supervised 2D features [S2].
