# NeuMesh++

Also called: Hybrid rendering for unbounded scenes, Learning Disentangled Neural Mesh-Based Implicit Field, Learning Disentangled Neural Mesh-Based Implicit Field for Geometry and Texture Editing, NeuMesh++ Neural Mesh-based Radiance Field, NeuMesh++ background blending, Unbounded Scene Rendering with NeuMesh++

## Overview
NeuMesh++ is a mesh-based neural radiance field representation that encodes a scene using disentangled geometry, texture, and semantic codes attached to a mesh scaffold [S2]. It solves the problem of high-fidelity novel view synthesis while enabling efficient, fine-grained 3D editing (geometry deformation, texture swapping, painting, and semantic-guided editing) without UV mapping or pre-trained teacher models [S1, S2]. Unlike its predecessor NeuMesh, which relied on distillation from an implicit SDF field and suffered from spatial ambiguity on single-layer vertex codes, NeuMesh++ introduces a novel local space parameterization and a decoder-free modification color to stabilize training and improve editing fidelity [S2]. For unbounded scenes, it learns an additional implicit hash grid for the background and blends it with the mesh-based foreground weighted by accumulated transmittance [S2].

## How it works

### Inputs and Outputs
**Inputs:**
- A set of calibrated images with known camera poses [S2].
- Optional foreground masks for scenes with empty backgrounds [S2].
- A foreground mesh scaffold (typically extracted from Neuralangelo and Marching Cubes) [S2].
- For editing: User interactions (vertex selection, painting masks, semantic clicks) [S2].

**Outputs:**
- Volume-rendered color images for novel views [S2].
- Editable latent codes (geometry, texture, modification color, semantic) stored on mesh vertices [S2].

### Data Structures

**Per-Vertex Storage (on mesh scaffold):**
Each vertex $v$ stores a set of learnable parameters [S2]:
1.  **Geometry Code ($l_g$):** Latent vector for geometry [S2].
2.  **Texture Code ($l_t$):** Latent vector for appearance [S2].
3.  **Modification Color ($c_m$):** View-independent, decoder-free color attribute for editing [S2].
4.  **Semantic Code ($l_s$):** Latent vector storing semantic attributes (aggregated from open-vocabulary segmentation) [S2].

**Query Point Interpolated Attributes:**
For a query point $x$, the system retrieves interpolated values from $K$ nearest vertices [S1, S2]:
-   Interpolated Geometry Code ($l_g(x)$): 32 dimensions [S1].
-   Interpolated Texture Code ($l_t(x)$): 32 dimensions [S1].
-   Local Indicator Vector ($h(x)$): Computed from spatial relationships (see Formulas) [S2].

**Decoders:**
Two separate Multi-Layer Perceptrons (MLPs) [S1, S2]:
1.  **Geometry Decoder ($F_G$):** Decodes density $\sigma$ [S2].
2.  **Radiance Decoder ($F_R$):** Decodes base color $c$ [S2].

### Numbered Steps

1.  **Mesh Acquisition:** Extract a foreground mesh from an external reconstruction method (e.g., Neuralangelo) using Marching Cubes [S2]. The mesh serves as the scaffold for latent codes [S2].
2.  **Occupancy Grid Initialization:** Initialize an occupancy grid using the mesh scaffold to guide ray sampling, bypassing unoccupied space [S2]. Update this grid if the mesh is deformed [S2].
3.  **Ray Casting and Sampling:** Cast rays from camera viewpoints. Sample $N$ points along each ray. NeuMesh++ uses 64 coarse points and 64 fine points (progressive up-sampling), totaling 128 samples per ray [S1]. Pre-compute near-far bounds based on ray-mesh intersections to accelerate this step [S1].
4.  **Nearest Neighbor Search:** For each query point $x$ along a ray, find the $K$ nearest vertices $\{v_k\}_{k=1}^K$ from the mesh scaffold within a fixed radius [S2]. Default $K=8$ [S1].
5.  **Local Indicator Calculation:** For each neighbor $v_k$, calculate the local indicator vector $h_k$ to resolve spatial ambiguity (inner/outer distinction) [S2]:
    -   Calculate normalized distance: $w_k = \frac{\|v_k - x\|}{\sum_{i=1}^K \|v_i - x\|}$ [S2].
    -   Calculate projection distance: $p_k = (v_k - x) \cdot n_k$, where $n_k$ is the normal of vertex $v_k$ [S2].
    -   Form local indicator: $h_k = (p_k, w_k)$ [S2].
6.  **Interpolation:** Interpolate the vertex codes ($l_g, l_t$) based on spatial proximity to form inputs for the decoders [S1, S2]. Local indicators ($h_k$) are computed per neighbor and not interpolated [S2].
7.  **Decoding:**
    -   Feed $l_g$ and $h$ into the Geometry Decoder $F_G$ to obtain density $\sigma$ [S2].
    -   Feed $l_t$, $h$, viewing direction $d$, and vertex normal $n$ into the Radiance Decoder $F_R$ to obtain base color $c$, then add the vertex-specific modification color $c_m$: $c_{final} = c + c_m$ [S2].
8.  **Volume Rendering:** Aggregate densities and colors using standard volume rendering equations [S2]:
    -   Opacity: $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, where $\delta_i$ is the distance between adjacent samples.
    -   Transmittance: $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$.
    -   Color: $\hat{C}(r) = \sum_{i=1}^N T_i \alpha_i c_i$.
9.  **Background Blending (Unbounded Scenes):** For unbounded scenes, render a background color $\hat{C}(r)_{bg}$ using an implicit hash grid (following the NeuS approach) [S2]. Blend foreground and background:
    -   $\hat{C}(r)_{comp} = \hat{C}(r) * T + \hat{C}(r)_{bg} * (1 - T)$, where $T$ is the accumulated transmittance of the NeuMesh++ foreground [S2].
10. **Training (Distillation-Free):** NeuMesh++ does not require a pre-trained teacher model. It optimizes latent codes and decoders directly using photometric loss and regularization [S2].

### Formulas

**Rendering Equation:**
$$ \hat{C}(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i, \quad T_i = \prod_{j=1}^{i-1} (1 - \alpha_j), \quad \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
where $\mathbf{r}$ is the ray, $N$ is the number of samples, $\sigma_i$ is density, $\mathbf{c}_i$ is color, and $\delta_i$ is sample spacing [S2].

**Local Indicator:**
$$ w_k = \frac{\|v_k - x\|}{\sum_{i=1}^K \|v_i - x\|}, \quad p_k = (v_k - x) \cdot n_k, \quad h_k = (p_k, w_k) $$
where $v_k$ is the $k$-th nearest vertex, $n_k$ is its normal, and $x$ is the query point [S2].

**Decoder Outputs:**
$$ \sigma_k = F_G(\mathbf{l}_k^g, \mathbf{h}_k) $$
$$ \mathbf{c}_k = F_R(\mathbf{l}_k^t, \mathbf{h}_k, \mathbf{d}, \mathbf{n}_k) + \mathbf{c}_k^m $$
where $\mathbf{d}$ is the viewing direction and $\mathbf{c}_k^m$ is the modification color [S2].

**Loss Functions:**
1.  **Photometric Loss:**
    $$ \mathcal{L}_f = \sum_{\mathbf{r} \in R} \|\hat{C}(\mathbf{r}) - C(\mathbf{r})\|_2^2 + 0.01 \cdot \sum_{\mathbf{r} \in R} \|\hat{C}^m(\mathbf{r}) - C(\mathbf{r})\|_2^2 $$
    where $C(\mathbf{r})$ is the ground truth color, and $\hat{C}^m(\mathbf{r})$ is the accumulated modification color [S2].
2.  **Mask Loss (for empty backgrounds):**
    $$ M_m = \sum_{\mathbf{r} \in R} \text{BCE}(\hat{M}(\mathbf{r}), M(\mathbf{r})) $$
    where $\hat{M}(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i$ and $M(\mathbf{r})$ is the ground truth mask [S2].
3.  **Total Variation Loss:**
    $$ \mathcal{L}_t = \sum_{i=1}^N \sum_{j \in \text{NR}(i)} |l_i - l_j| $$
    where $\text{NR}(i)$ contains the indices of the $K_{tv}$ closest vertices to $v_i$ [S2].

### Parameters

-   **K (Nearest Neighbors):** Number of vertices used for interpolation. Default: 8 [S1].
-   **K_tv:** Number of closest vertices for Total Variation loss. Not given in the sources.
-   **Mesh Resolution:** Marching Cubes voxel resolution 256, spatial range $[-1, 1]$ [S1].
-   **Positional Encoding Frequencies:**
    -   Local indicators: 8 frequencies [S1].
    -   Interpolated codes: 2 frequencies [S1].
    -   Viewing directions: 4 frequencies [S1].
-   **Geometry Decoder:** 3 hidden layers, 256 hidden size, SoftPlus activation [S1].
-   **Radiance Decoder:** 4 hidden layers, 256 hidden size, ReLU activation [S1].
-   **Samples per Ray:** 128 total (64 coarse + 64 fine) [S1].
-   **Loss Weight:** 0.01 for modification color photometric loss term [S2].
-   **Rendering Resolution:** 800 × 800 for performance benchmarks; 1600 × 1200 for DTU dataset training [S2].

### Edge Cases and Pitfalls

-   **Spatial Distinguishability:** Naive trilinear interpolation of single-layer vertex codes fails to distinguish inner/outer queries perpendicular to the surface [S1, S2]. NeuMesh++ resolves this with the local indicator vector $h_k$ (projection distance and normalized distance) [S2].
-   **Training Stability:** Vertex-bounded representations lack the spatial continuity of MLP-based methods, risking unstable training [S1]. NeuMesh++ avoids the need for a teacher model (used in NeuMesh) by using the local space parameterization and Total Variation loss [S2].
-   **View-Dependent Editing:** Standard neural decoders limit the range of modifiable colors due to fixed weights and view conditioning [S2]. NeuMesh++ introduces a decoder-free, view-independent **modification color** ($c_m$) per vertex to allow high-fidelity texture painting and swapping [S2].
-   **Overfitting in Editing:** Fine-tuning texture codes with a single image can cause artifacts in other views [S1]. NeuMesh++ uses a **spatial-aware optimization strategy**: it selects only the modification colors of vertices intersected by probing rays from painted pixels, fine-tuning only those to preserve other regions [S2].
-   **Non-Watertight Meshes:** The representation is agnostic to mesh topology (non-watertight, non-manifold) because it relies on local vertex neighborhoods rather than global surface continuity [S2].

### Pseudocode

```python
import numpy as np

def positional_encoding(x, freqs=8):
    """Standard positional encoding for input x."""
    scales = np.array([2**i for i in range(freqs)])
    x = np.expand_dims(x, axis=-1) * scales
    return np.sin(x).flatten()

def find_k_nearest_vertices(query_point, vertices, K):
    """Finds K nearest vertices to query_point."""
    dists = np.linalg.norm(vertices - query_point, axis=1)
    indices = np.argsort(dists)[:K]
    return indices

def compute_occupancy_grid_from_mesh(mesh):
    """Initializes occupancy grid using mesh bounding box and resolution."""
    # Simplified: returns a boolean grid covering mesh bounds
    bounds = np.array([mesh.vertices.min(axis=0), mesh.vertices.max(axis=0)])
    return np.zeros((32, 32, 32), dtype=bool) # Placeholder for actual grid logic

def compute_ray_mesh_intersections(mesh, camera_poses):
    """Pre-computes near-far bounds for rays based on mesh intersections."""
    # Simplified: returns min/max distances along ray directions
    return np.zeros((len(camera_poses), 2))

def generate_rays(pose, image_shape):
    """Generates ray origins and directions from camera pose and image shape."""
    # Simplified:
    origins = np.zeros((image_shape[0] * image_shape[1], 3))
    directions = np.zeros((image_shape[0] * image_shape[1], 3))
    return origins, directions

def sample_along_ray(origins, directions, near_far_bounds, N_total):
    """Samples points along rays between near and far bounds."""
    # Simplified: evenly spaced samples
    t = np.linspace(near_far_bounds[:, 0], near_far_bounds[:, 1], N_total)
    return origins[:, None, :] + directions[:, None, :] * t[:, :, None]

def neu_mesh_plus_plus_render(mesh, camera_poses, images, masks, 
                              geometry_decoder, radiance_decoder, 
                              K=8, num_coarse=64, num_fine=64):
    """
    NeuMesh++ Rendering and Training Loop.
    
    Args:
        mesh: Object containing vertices V, normals N, and latent codes 
              (l_g, l_t, c_m, l_s).
        camera_poses: List of camera extrinsics/intrinsics.
        images: Ground truth images.
        masks: Ground truth foreground masks (optional).
        geometry_decoder: MLP F_G.
        radiance_decoder: MLP F_R.
        K: Number of nearest neighbors.
        num_coarse: Number of coarse samples.
        num_fine: Number of fine samples.
        
    Returns:
        Rendered images, losses.
    """
    
    # 1. Initialize Occupancy Grid from Mesh
    occupancy_grid = compute_occupancy_grid_from_mesh(mesh)
    
    # 2. Pre-compute Near-Far Bounds for Rays
    near_far_bounds = compute_ray_mesh_intersections(mesh, camera_poses)
    
    rendered_images = []
    total_loss = 0
    
    for pose, gt_image, gt_mask in zip(camera_poses, images, masks):
        ray_origins, ray_directions = generate_rays(pose, gt_image.shape)
        N = len(ray_origins)
        rendered_ray_colors = np.zeros((N, 3))
        
        # Combine coarse and fine samples
        N_total = num_coarse + num_fine
        sample_distances = sample_along_ray(ray_origins, ray_directions, 
                                            near_far_bounds, N_total)
        
        # 3. Volume Rendering Loop
        for i in range(N):
            origin = ray_origins[i]
            direction = ray_directions[i]
            
            # Get sample points along ray
            points = sample_distances[i]
            
            # Initialize accumulation variables
            T_acc = 1.0
            color_acc = np.zeros(3)
            mod_color_acc = np.zeros(3)
            
            for j, x in enumerate(points):
                # 4. Find K nearest vertices
                neighbors = find_k_nearest_vertices(x, mesh.vertices, K)
                
                # 5. Calculate Local Indicators and Interpolate
                densities = []
                colors = []
                mod_colors = []
                weights = []
                
                for v_idx in neighbors:
                    v = mesh.vertices[v_idx]
                    n = mesh.normals[v_idx]
                    
                    # Local Indicator Calculation
                    dist_vec = v - x
                    dist_norm = np.linalg.norm(dist_vec)
                    
                    # Normalized distance
                    sum_dists = sum(np.linalg.norm(mesh.vertices[k] - x) for k in neighbors)
                    w_k = dist_norm / sum_dists if sum_dists > 0 else 0
                    
                    # Projection distance
                    p_k = np.dot(dist_vec, n)
                    
                    h_k = np.array([p_k, w_k])
                    
                    # Interpolate Codes (Weighted by inverse distance)
                    weight = 1.0 / (dist_norm + 1e-8)
                    weights.append(weight)
                    
                    l_g_interp = mesh.l_g[v_idx]
                    l_t_interp = mesh.l_t[v_idx]
                    c_m_interp = mesh.c_m[v_idx]
                    
                    # Positional Encoding
                    h_pe = positional_encoding(h_k, freqs=8)
                    l_g_pe = positional_encoding(l_g_interp, freqs=2)
                    l_t_pe = positional_encoding(l_t_interp, freqs=2)
                    d_pe = positional_encoding(direction, freqs=4)
                    
                    # 6. Decode
                    sigma = geometry_decoder.forward(np.concatenate([l_g_pe, h_pe]))
                    base_color = radiance_decoder.forward(np.concatenate([l_t_pe, h_pe, d_pe, n]))
                    
                    # Add modification color
                    final_color = base_color + c_m_interp
                    
                    densities.append(sigma)
                    colors.append(final_color)
                    mod_colors.append(c_m_interp)
                
                # Fuse densities and colors from neighbors using weights
                total_weight = sum(weights)
                norm_weights = [w / total_weight for w in weights]
                
                sigma_final = sum(d * w for d, w in zip(densities, norm_weights))
                color_final = sum(c * w for c, w in zip(colors, norm_weights))
                mod_color_final = sum(m * w for m, w in zip(mod_colors, norm_weights))
                
                # 7. Volume Rendering Step
                delta = sample_distances[i][j+1] - sample_distances[i][j] if j < N_total-1 else 0
                alpha = 1.0 - np.exp(-sigma_final * delta)
                
                T_acc *= (1.0 - alpha)
                color_acc += T_acc * alpha * color_final
                mod_color_acc += T_acc * alpha * mod_color_final
                
                if T_acc < 1e-4:
                    break
            
            rendered_ray_colors[i] = color_acc
        
        rendered_images.append(rendered_ray_colors)
        
        # 8. Loss Calculation
        # Photometric Loss
        loss_f = np.mean((rendered_ray_colors - gt_image) ** 2)
        # Accumulated modification color loss
        loss_mod = 0.01 * np.mean((mod_color_acc - gt_image) ** 2)
        
        # Mask Loss
        # M_hat = sum(T_i * alpha_i)
        # M_m = BCE(M_hat, M)
        loss_mask = 0 # Placeholder for BCE calculation
        
        # Total Variation Loss (on latent codes)
        loss_tv = compute_total_variation_loss(mesh, K_tv=10)
        
        total_loss += loss_f + loss_mod + loss_mask + loss_tv
        
    return rendered_images, total_loss

def compute_total_variation_loss(mesh, K_tv=10):
    """
    Computes Total Variation loss on latent codes.
    """
    loss = 0
    for i, v_i in enumerate(mesh.vertices):
        neighbors = find_k_nearest_vertices(v_i, mesh.vertices, K_tv)
        for j in neighbors:
            l_i = mesh.l_g[i]
            l_j = mesh.l_g[j]
            loss += np.sum(np.abs(l_i - l_j))
    return loss
```

## Operating characteristics

-   **Time Complexity:** Rendering speed is approximately 15 fps on an Nvidia GTX 4070 GPU for 800×800 images [S2]. This is achieved by using compact latent codes, lightweight decoders, and an occupancy grid to skip unoccupied space [S2].
-   **Memory Complexity:** Memory usage is dominated by the storage of latent codes per vertex. For a mesh with 50K–150K vertices, this is significantly less than storing a dense voxel grid or a large hash grid for the entire scene [S1, S2].
-   **Performance:** Outperforms BakedSDF quantitatively on the Mip-NeRF 360 dataset, particularly in high-frequency details [S2].
-   **Editing Efficiency:**
    -   Geometry editing: ~1 second to update the occupancy grid after mesh deformation [S2].
    -   Texture painting: ~1 second for fine-tuning modification colors [S2].
    -   Semantic-guided editing: ~2 seconds for 3D semantic propagation [S2].
    -   Texture swapping/filling: Immediate rendering without fine-tuning [S2].
-   **Strengths:**
    -   Enables fine-grained, mesh-guided editing (geometry, texture, semantics) [S2].
    -   No need for UV mapping [S1].
    -   Agnostic to mesh topology (non-watertight) [S2].
    -   High-fidelity rendering of complex geometry and textures [S2].
    -   Training stability without a pre-trained teacher model [S2].
-   **Limitations:**
    -   Requires an initial mesh scaffold (e.g., from Neuralangelo) [S2].
    -   Performance depends on mesh quality and vertex density [S1].
    -   May suffer from artifacts if editing is not spatially aware (mitigated by the proposed strategy) [S1].

## Background

-   **Origin:** NeuMesh++ is an extension of NeuMesh [S1], published in TPAMI in 2025 [S2].
-   **Development:** NeuMesh used a distillation approach from a pre-trained implicit SDF field (NeuS) to stabilize training but suffered from spatial ambiguity and limited editing fidelity [S1, S2]. NeuMesh++ rebuilds the representation on the neural radiance field directly, introducing local space parameterization and modification colors to remove the need for distillation and improve editing [S2].
-   **Usage:** Evaluated on the DTU dataset (15 scenes) and NeRF 360 Synthetic dataset [S2]. Used for applications requiring interactive 3D editing, such as texture swapping, filling, painting, and semantic-guided manipulation [S2].
