# Radiance Field Prediction Network

Also called: RFPN

## Overview
The Radiance Field Prediction Network (RFPN) is a neural network component that predicts volumetric density $\sigma(\mathbf{x})$ and RGB color $\mathbf{c}(\mathbf{x})$ for a 3D point $\mathbf{x}$ within a canonicalized space [S1]. It builds on [General Radiance Field Rendering via MLP](8683-general-radiance-field-rendering-via-mlp.md) by explicitly incorporating per-point latent attributes, a learned masking mechanism, and per-image appearance codes to handle view-dependent effects and lighting variations [S1]. It sets itself apart from siblings like [Visibility and Outgoing Radiance MLP](16668-visibility-and-outgoing-mlp.md) by decoupling the prediction of geometric attributes from the final radiance output via a dedicated masking network and explicit appearance conditioning [S1].

## How it works
**Inputs:**
*   Canonicalized 3D point $\mathbf{x} \in \mathbb{R}^3$.
*   Per-point predicted attributes $\alpha(\mathbf{x})$ (e.g., ambient code).
*   Lifted latent code $\beta(\mathbf{x})$.
*   Per-image learnable appearance code $\psi$.
*   View direction $(\theta, \phi)$, positionally encoded.

**Outputs:**
*   Density value $\sigma(\mathbf{x}) \in \mathbb{R}$.
*   RGB color $\mathbf{c}(\mathbf{x}) \in \mathbb{R}^3$.

**Data Structures:**
*   The network consists entirely of fully connected (linear) layers with ReLU activation, except for the final color output [S1].
*   Hidden layer dimension is $d=64$ [S1].
*   Positional encoding for $\mathbf{x}$ uses 8 sine components [S1].
*   Positional encoding for $\alpha(\mathbf{x})$ and $\beta(\mathbf{x})$ uses a single sine component, with its frequency linearly increasing from $1k$ to $11k$ [S1].

**Steps:**
1.  **Positional Encoding:** Encode the canonicalized point $\mathbf{x}$ using 8 sine components:
    $$ \text{PE}(\mathbf{x}) = [\sin(2^0 \pi \mathbf{x}), \dots, \sin(2^7 \pi \mathbf{x})] $$
    [S1]
2.  **Attribute Encoding:** Encode the per-point attributes $\alpha(\mathbf{x})$ and $\beta(\mathbf{x})$ using a single sine component with frequency $f$, where $f$ is determined by the training step $t$:
    $$ f(t) = 1k + \frac{t - t_{start}}{t_{end} - t_{start}} \times (11k - 1k) $$
    $$ \text{PE}_{\alpha}(\mathbf{x}) = \sin(f(t) \cdot \alpha(\mathbf{x})) $$
    $$ \text{PE}_{\beta}(\mathbf{x}) = \sin(f(t) \cdot \beta(\mathbf{x})) $$
    [S1]
3.  **Masking:** Predict a mask $m(\mathbf{x})$ from a separate masking network (not detailed in the RFPN definition itself, but applied here) [S1]. Apply the mask to the encoded attributes:
    $$ \alpha'(\mathbf{x}) = m(\mathbf{x}) \odot \text{PE}_{\alpha}(\mathbf{x}) $$
    $$ \beta'(\mathbf{x}) = m(\mathbf{x}) \odot \text{PE}_{\beta}(\mathbf{x}) $$
    [S1]
4.  **Feature Aggregation:** Concatenate the encoded point $\text{PE}(\mathbf{x})$, masked attributes $\alpha'(\mathbf{x})$, and $\beta'(\mathbf{x})$ [S1].
5.  **Hidden Layers:** Pass the concatenated vector through fully connected layers with ReLU activation [S1].
6.  **Final Prediction:** The final linear layer takes the output of the hidden layers, the per-image appearance code $\psi$, and the positionally encoded view directions $(\theta, \phi)$ [S1].
    *   Encode view direction $(\theta, \phi)$ using standard positional encoding (details not specified in the provided text, assumed standard [G]).
    *   Concatenate the hidden features, $\psi$, and $\text{PE}(\theta, \phi)$ [S1].
    *   Apply a linear transformation to produce the raw density $\hat{\sigma}(\mathbf{x})$ and raw color $\hat{\mathbf{c}}(\mathbf{x})$ [S1].
7.  **Activation:** Apply a sigmoid function to the color output to constrain it to $[0, 1]$:
    $$ \mathbf{c}(\mathbf{x}) = \sigma_{sig}(\hat{\mathbf{c}}(\mathbf{x})) $$
    [S1]
    The density $\sigma(\mathbf{x})$ is typically output directly or via a softplus/exponential activation (not explicitly specified in the provided text, assumed standard for density [G]).

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class RadianceFieldPredictionNetwork(nn.Module):
    def __init__(self, d=64, num_sine_components=8, freq_start=1000, freq_end=11000):
        super().__init__()
        self.d = d
        self.num_sine_components = num_sine_components
        self.freq_start = freq_start
        self.freq_end = freq_end
        
        # Linear layers for hidden blocks
        # Input size: 3 * num_sine_components (for x) + d (for alpha) + d (for beta)
        # Assuming alpha and beta are of size d
        input_size = 3 * num_sine_components + 2 * d
        self.hidden1 = nn.Linear(input_size, d)
        self.hidden2 = nn.Linear(d, d)
        self.hidden3 = nn.Linear(d, d)
        self.hidden4 = nn.Linear(d, d)
        self.hidden5 = nn.Linear(d, d)
        self.hidden6 = nn.Linear(d, d)
        
        # Final layer input: d (hidden) + d (appearance code) + 2 * num_sine_components (view direction)
        # Assuming view direction encoding uses same number of components as x for simplicity, 
        # though not explicitly stated. Standard PE for 2D direction.
        view_dir_enc_size = 2 * num_sine_components 
        final_input_size = d + d + view_dir_enc_size
        
        self.final_linear = nn.Linear(final_input_size, 4) # 1 for sigma, 3 for color

    def positional_encoding(self, x, num_components):
        """Standard positional encoding using sine functions."""
        # x shape: (..., 3)
        # Output shape: (..., 3 * num_components)
        frequencies = torch.pow(2.0, torch.arange(0, num_components, device=x.device).float())
        scaled_x = x.unsqueeze(-1) * frequencies * torch.pi
        encoded = torch.sin(scaled_x)
        return encoded.view(x.shape[0], -1)

    def single_sine_encoding(self, x, freq):
        """Single sine component encoding with frequency freq."""
        # x shape: (..., d)
        # Output shape: (..., d)
        return torch.sin(freq * x)

    def forward(self, x, alpha, beta, appearance_code, view_direction, mask, step):
        """
        x: (N, 3) canonicalized points
        alpha: (N, d) per-point attributes
        beta: (N, d) lifted latent code
        appearance_code: (1, d) or (N, d) per-image appearance code
        view_direction: (N, 2) (theta, phi)
        mask: (N, 1) mask from masking network
        step: current training step for frequency scheduling
        """
        # 1. Positional Encoding for x
        pe_x = self.positional_encoding(x, self.num_sine_components)
        
        # 2. Frequency scheduling for alpha and beta
        # Linearly increase from 1k to 11k
        # Assuming step ranges from 0 to total_steps
        # Note: The source says "linearly increase contribution... from 1k to 11k step"
        # This implies the frequency itself increases.
        freq = self.freq_start + (self.freq_end - self.freq_start) * (step / 11000.0) # Approximation if step is not normalized
        # More accurately, if step is the iteration index, we need total steps. 
        # The source says "from 1k to 11k step", which might mean the frequency goes from 1000 to 11000 over the training.
        # Let's assume step is normalized 0-1 for the formula.
        # If step is not normalized, this part needs adjustment based on total steps.
        # For implementation, we assume step is normalized or we pass total_steps.
        # Given the ambiguity, we use a placeholder for total_steps if not provided.
        # [G] Assuming step is normalized between 0 and 1 for the frequency interpolation.
        freq = self.freq_start + (self.freq_end - self.freq_start) * step
        
        pe_alpha = self.single_sine_encoding(alpha, freq)
        pe_beta = self.single_sine_encoding(beta, freq)
        
        # 3. Masking
        # mask shape: (N, 1) or (N, d)
        # The source says "masked by a mask predicted from the masking network"
        # Assuming mask is broadcastable to (N, d)
        masked_alpha = mask * pe_alpha
        masked_beta = mask * pe_beta
        
        # 4. Concatenate
        # pe_x: (N, 3*8) = (N, 24)
        # masked_alpha: (N, d)
        # masked_beta: (N, d)
        features = torch.cat([pe_x, masked_alpha, masked_beta], dim=1)
        
        # 5. Hidden Layers
        h = F.relu(self.hidden1(features))
        h = F.relu(self.hidden2(h))
        h = F.relu(self.hidden3(h))
        h = F.relu(self.hidden4(h))
        h = F.relu(self.hidden5(h))
        h = F.relu(self.hidden6(h))
        
        # 6. Final Layer
        # Encode view direction
        pe_view = self.positional_encoding(view_direction, self.num_sine_components)
        
        # appearance_code: (1, d) or (N, d)
        # If (1, d), broadcast to (N, d)
        if appearance_code.shape[0] == 1:
            appearance_code = appearance_code.expand(h.shape[0], -1)
            
        final_input = torch.cat([h, appearance_code, pe_view], dim=1)
        output = self.final_linear(final_input)
        
        # 7. Activation
        sigma = output[:, 0] # Raw density
        color = torch.sigmoid(output[:, 1:]) # RGB color
        
        return sigma, color
```

**Parameters:**
*   Hidden dimension $d=64$ [S1].
*   Number of sine components for $\mathbf{x}$: 8 [S1].
*   Frequency range for $\alpha(\mathbf{x})$ and $\beta(\mathbf{x})$: $1k$ to $11k$ [S1].

**Edge Cases and Pitfalls:**
*   The appearance code $\psi$ can be discarded during evaluation [S1].
*   The model may learn spurious interpolations for controlled elements that occupy little space in the image or have insufficient annotations (e.g., fast motion, specularity) [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Explicitly handles view-dependent effects and lighting variations through appearance codes and view direction conditioning [S1]. The masking network allows for selective attribute prediction [S1].
*   **Limitations:** May fail to capture fast-moving or specular elements if annotations are insufficient, leading to spurious interpolations or ignoring of such elements [S1].
*   **When to use:** When controllable neural radiance fields are needed, particularly with explicit control over appearance and lighting [S1].
*   **When not to use:** When computational resources are limited and the overhead of the masking network and multiple encoding steps is prohibitive, or when the scene contains fast-moving specular objects with poor annotation [S1].

## Background
The Radiance Field Prediction Network is part of the CoNeRF (Controllable Neural Radiance Fields) architecture, introduced in the paper "CoNeRF: Controllable Neural Radiance Fields" [S1]. It is designed to enable controllable novel view synthesis by separating geometric and appearance attributes [S1].
