# General Radiance Field Rendering via MLP

Also called: MLP Radiance Field with Aggregated Features, Neural Radiance Field MLP, Radiance Field Prediction MLP

## Overview
This method renders novel views by training a Multi-Layer Perceptron (MLP) to predict volumetric density and RGB color for 3D points, forming a General Radiance Field (GRF) [S1]. It differs from standard Neural Radiance Fields (NeRF) by using aggregated 3D point features as the primary spatial input to the MLP, rather than raw 3D coordinates, while retaining the viewing direction as a secondary input [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of 2D images with known camera poses [S1]. For rendering, the inputs are a 3D point $p$ and a viewing direction $V_p$ [S1].
*   **Outputs:** Volumetric density $\sigma(t)$ and RGB color $c(t)$ for points along a ray, resulting in a rendered 2D image pixel value [S1].

**Data Structures:**
*   **Aggregated Point Features ($\bar{F}_p$):** A feature vector representing the 3D point $p$ [S1]. The exact dimension and generation method are not specified in the source, but it replaces the raw coordinate vector $[x, y, z]$ used in NeRF [S1].
*   **Viewing Direction ($V_p$):** A 3D vector $[x_v, y_v, z_v]$ representing the direction from the camera center to point $p$ [S1].
*   **MLP:** A neural network architecture strictly following the design in NeRF [29] [S1]. It takes the concatenated input $[\bar{F}_p, V_p]$ and outputs density and color [S1].

**Numbered Steps:**
1.  **Positional Encoding:** Apply the positional encoding function $\gamma(\cdot)$ proposed in NeRF [29] to both the aggregated point features $\bar{F}_p$ and the viewing direction $V_p$ [S1].
2.  **MLP Forward Pass:** Feed the encoded input into the MLP to predict the volumetric density $\sigma$ and RGB color $c$ for the query point [S1].
3.  **Ray Casting:** For each pixel in the target image, cast a ray from the camera center through the pixel into the 3D space [S1].
4.  **Hierarchical Sampling:** Estimate the volume rendering integral using numerical quadrature with a hierarchical sampling strategy, strictly following the method in NeRF [29] [S1].
5.  **Volume Rendering:** Compute the final pixel color $rgb$ by integrating the density and color along the ray [S1].
6.  **Optimization:** Minimize the L2 loss between the rendered RGB values and the ground truth RGB values from the input images [S1]. The entire network is trained end-to-end [S1].

**Formulas:**
The rendered pixel color is computed as:
$$ rgb = \int_{t_n}^{t_f} T(t) c(t) \sigma(t) dt $$
where the transmittance $T(t)$ is:
$$ T(t) = \exp\left(-\int_{t_n}^{t} \sigma(s) ds\right) $$
Here, $t_n$ and $t_f$ are the near and far clipping planes, $c(t)$ is the color at point $t$, $\sigma(t)$ is the volume density at point $t$, and $T(t)$ is the accumulated transmittance [S1].

**Parameters:**
*   **Loss Function:** L2 loss between rendered and ground truth RGB [S1].
*   **Positional Encoding:** As defined in NeRF [29] [S1].
*   **Sampling:** Hierarchical sampling strategy as defined in NeRF [29] [S1].
*   **Typical Values:** Not given in the sources [S1].

**Edge Cases and Pitfalls:**
*   **Precision:** Not given in the sources [S1].
*   **Boundaries:** The ray integration is bounded by near and far clipping planes ($t_n, t_f$) [S1].
*   **Degenerate Input:** Not given in the sources [S1].

## Subtopics

### [Visibility and Outgoing Radiance MLP](16668-visibility-and-outgoing-radiance-mlp.md)
This method replaces costly recursive path tracing for indirect illumination by learning continuous functions for visibility and outgoing radiance, enabling efficient view synthesis and inverse rendering. It differs from its parent [General Radiance Field Rendering via MLP](8683-general-radiance-field-rendering-via-mlp.md) by explicitly decoupling the visibility term and the outgoing radiance field into separate learnable MLPs, avoiding the need for expensive sphere tracing during forward rendering.

### Radiance Field Prediction Network
Predicts RGB colors $c(x)$ and density values $\sigma(x)$ from canonicalized points, applying masks and conditioning on view directions and appearance codes [S3]. The network encodes points $x$ with 8 sine components, linearly increases the contribution of a single component in $\alpha(x)$ and $\beta(x)$ from 1k to 11k step, and masks per-point predicted attributes $\alpha(x)$ and lifted latent code $\beta(x)$ using a mask predicted from a masking network [S3]. The data passes through fully connected layers with ReLU activation, and the final linear layer takes an appearance code $\psi$ and positionally encoded view directions, activating the color output with a sigmoid function [S3]. The input consists of canonicalized points $x$, per-point predicted attributes $\alpha(x)$, lifted latent code $\beta(x)$, per-image appearance code $\psi$, and positionally encoded view directions $(\theta, \phi)$, while the output is RGB colors $c(x)$ and density values $\sigma(x)$ [S3]. The appearance code $\psi$ can be discarded during evaluation [S3].

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources [S1].
*   **Measured Performance:** On ShapeNetv2 chair and car classes, the method (GRF) achieved a PSNR of 22.65, compared to 24.48 for SRNs [S1].
*   **Scaling:** Not given in the sources [S1].
*   **Strengths:** Can synthesize novel 2D images directly by querying points along light rays, trainable only with 2D images without requiring 3D data [S1].
*   **Limitations:** The source does not specify limitations compared to NeRF other than the architectural difference in input [S1].
*   **When to use:** When a general radiance field representation is desired that leverages aggregated features rather than raw coordinates [S1].
*   **When not:** When raw coordinate-based spatial encoding is preferred or when higher PSNR is required (SRNs performed better in the cited experiment) [S1].

## Background
The method was introduced in the paper "GRF: Learning a General Radiance Field for 3D Representation and Rendering" [S1]. It adapts the MLP architecture from NeRF [4972-neural-radiance-fields.md] by replacing raw 3D coordinates with aggregated point features as the MLP input [S1]. The key innovation is the substitution of raw 3D coordinates with aggregated point features as the input to the radiance field MLP [S1].
