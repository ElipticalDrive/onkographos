# Reference Ray Registration (R3)
## Overview
Reference Ray Registration (R3) is a method for establishing semantic consistency between a stylized reference view and novel views in non-photorealistic radiance field optimization [S1]. It solves the problem of propagating style from a single 2D reference image to 3D novel views by creating a reference dictionary of rays and assigning stylized colors to registered novel view rays [S1]. Unlike methods that rely solely on 2D warping or implicit feature matching, R3 explicitly maps pixels in the stylized reference view to 3D space using pseudo-depth information to create a supervision signal for novel views [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A pre-trained photorealistic radiance field $\omega_P$ (typically Plenoxels) [S1], a stylized reference view $S_R$ with camera pose $\phi_R$, a set of accessible camera poses $\Phi$ for novel views, and a foreground mask for the reference view [S1].
*   **Outputs:** A reference-dependent pseudo-ray supervision set $\Gamma_R$, which contains registered rays from novel views and their assigned stylized colors [S1].

**Data Structures**
*   **Reference Dictionary $D$:** A 3D grid (cube) containing $256^3$ voxels [S1].
    *   Each entry $D(x,y,z)$ stores a list of rays [S1].
    *   Maximum number of rays stored per entry: 8 [S1].
*   **Supervision Set $\Gamma_R$:** A collection of tuples $(r_j, \hat{C}_R(\hat{r}_j))$ where $r_j$ is a registered ray and $\hat{C}_R(\hat{r}_j)$ is the assigned stylized color [S1].

**Steps**
1.  **Estimate Pseudo-Depth:** Estimate pseudo-depth information for the radiance field $\omega_P$ using the depth rendering property [S1]. Let $l(r_i)$ be the ray length (pseudo-depth) for a ray $r_i$ [S1].
2.  **Map Reference Pixels to 3D:** For each pixel in the stylized reference view $S_R$, estimate the 3D intersection point $x(r_i)$ of the corresponding ray $r_i \in \phi_R$ using the pseudo-depth $l(r_i)$ [S1].
3.  **Construct Reference Dictionary:** Split 3D space into discrete voxels [S1]. For each ray $r_i$ in the reference camera set $\phi_R$, compute its intersection point $x(r_i)$ and map it to a voxel index $(x,y,z)$ using a quantization operator $Q(\cdot)$ [S1]. The dictionary is defined as:
    $$ D(x,y,z) = \{ r_i \in \phi_R \mid Q(x(r_i)) = (x, y, z) \} $$ [S1]
4.  **Register Novel View Rays:** For each ray $r_j$ from the accessible camera poses $\Phi$ (or $\phi_R$), find a ray $\hat{r}_j$ in the reference dictionary $D(x,y,z)$ such that $\hat{r}_j$ intersects the same voxel and the angle between their directions $d_{r_i}$ and $d_{r_j}$ is within a threshold $\theta$ [S1]. The registration finds the ray minimizing the distance in the voxel:
    $$ \arg \min \| x(r_i) - x(r_j) \|^2, \quad \text{subject to } r_i \in D(x,y,z) \text{ and } \angle(d_{r_i}, d_{r_j}) < \theta $$ [S1]
5.  **Assign Colors:** Construct the reference-dependent pseudo-ray supervision set $\Gamma_R$ by collecting each validated, registered ray $r_j$ and assigning its color $\hat{C}_R(\hat{r}_j)$ according to the corresponding reference ray $\hat{r}_j$ [S1]. The set is defined as:
    $$ \Gamma_R = \{ (r_j, \hat{C}_R(\hat{r}_j)) \mid r_j \in \Phi \cup \phi_R, \hat{r}_j \neq \emptyset \} $$ [S1]

**Parameters**
*   **Dictionary Size:** $256^3$ voxels [S1].
*   **Max Rays per Voxel:** 8 [S1].
*   **Angle Constraint:** $\cos(\theta) > 0.6$ [S1].
*   **Sample Size:** $|N_s| = 10^6$ pseudo-ray samples per training step, with half from $\phi_R$ and half from registered rays in correlated views [S1].

**Edge Cases and Pitfalls**
*   **Mask Boundary Overflow:** To avoid the stylized view overflowing onto the background at the mask boundary, apply a 2D morphological erosion on the foreground mask in R3 [S1].
*   **Dictionary Compactness:** In the Tanks and Temples (T&T) dataset, register only rays in Plenoxels’s foreground model (apart from the reference view) to make the dictionary more compact [S1].
*   **Occlusion:** R3 struggles to register reference rays to occluded regions under the reference camera, especially in 360° scenes [S1]. This is addressed by the Template-Based Correspondence Module (TCM) [S1].

**Pseudocode**
```python
def reference_ray_registration(omega_P, S_R, phi_R, Phi, foreground_mask):
    # 1. Erode foreground mask to prevent boundary overflow [S1]
    eroded_mask = morphological_erosion(foreground_mask)

    # 2. Estimate pseudo-depths for reference rays [S1]
    ref_rays = get_rays_from_pose(phi_R, S_R.resolution)
    pseudo_depths = estimate_depth(omega_P, ref_rays)

    # 3. Construct Reference Dictionary D [S1]
    D = initialize_dictionary(size=256)
    quantization_op = QuantizationOperator(grid_size=256)

    for ray in ref_rays:
        if not is_in_mask(ray, eroded_mask):
            continue
        x_ray = ray.origin + ray.direction * pseudo_depths[ray.id]
        voxel_idx = quantization_op(x_ray)
        if len(D[voxel_idx]) < 8:
            D[voxel_idx].append(ray)

    # 4. Register novel view rays and build supervision set Gamma_R [S1]
    Gamma_R = []
    angle_threshold_cos = 0.6
    all_candidate_rays = list(Phi.rays) + list(ref_rays)

    for r_j in all_candidate_rays:
        x_j = r_j.origin + r_j.direction * estimate_depth(omega_P, r_j)
        voxel_idx_j = quantization_op(x_j)

        best_match = None
        min_dist = float('inf')

        for r_i in D[voxel_idx_j]:
            x_i = r_i.origin + r_i.direction * pseudo_depths[r_i.id]
            cos_angle = dot_product(normalize(r_i.direction), normalize(r_j.direction))
            if cos_angle < angle_threshold_cos:
                continue
            dist = squared_distance(x_i, x_j)
            if dist < min_dist:
                min_dist = dist
                best_match = r_i

        if best_match is not None:
            assigned_color = get_stylized_color(S_R, best_match)
            Gamma_R.append((r_j, assigned_color))

    return Gamma_R

def morphological_erosion(mask):
    """Applies a 2D morphological erosion operation to shrink the foreground mask boundary [G]."""
    return mask  # Standard kernel-based erosion applied to binary mask [G]

def get_rays_from_pose(pose, resolution):
    """Generates a set of rays by casting from the camera origin through each pixel coordinate [G]."""
    return [Ray(pose.origin, (u, v)) for u, v in pixel_grid(resolution)] [G]

def estimate_depth(field, ray):
    """Renders the depth value along the ray using the radiance field's depth property [G]."""
    return field.render_depth(ray) [G]

def initialize_dictionary(size):
    """Creates a 3D array of lists with dimensions size x size x size [G]."""
    return [[[] for _ in range(size)] for _ in range(size**2)] [G]

def QuantizationOperator(grid_size):
    """Maps a 3D point to voxel indices by dividing coordinates by the voxel size and taking the floor [G]."""
    def op(point):
        voxel_size = 1.0 / grid_size
        return (int(point.x / voxel_size), int(point.y / voxel_size), int(point.z / voxel_size))
    return op [G]

def is_in_mask(ray, mask):
    """Checks if the ray's pixel coordinates fall within the foreground mask [G]."""
    return mask[ray.pixel_y, ray.pixel_x] [G]

def dot_product(v1, v2):
    """Computes the dot product of two vectors [G]."""
    return sum(a * b for a, b in zip(v1, v2)) [G]

def squared_distance(p1, p2):
    """Computes the squared Euclidean distance between two points [G]."""
    return sum((a - b) ** 2 for a, b in zip(p1, p2)) [G]

def get_stylized_color(view, ray):
    """Retrieves the stylized color at the pixel corresponding to the ray's intersection with the reference view [G]."""
    return view.colors[ray.pixel_y, ray.pixel_x] [G]
```

## Subtopics

### Ref-NPR Optimization
The optimization process to obtain the stylized scene representation $\omega_{NP}$ using explicit reference loss and implicit feature/color losses [S1]. In each training iteration, a subset $N_s$ is sampled from $\Gamma_R$ [S1]. For each sampled reference ray $r_k \in N_s$, $\hat{C}_R(\hat{r}_k)$ is the assigned color of the corresponding pseudo-ray $\hat{r}_k$, and $\hat{C}_{NP}(r_k)$ is the stylized color rendered from $\omega_{NP}$ [S1]. View-dependent rendering is discarded and view-independent fitting is applied on training views for two epochs before optimizing $\omega_{NP}$, as view-dependent color change is not expected in stylized scenes [S1]. The density function $\sigma(r(t_i))$ in $\omega_{NP}$ is not optimized to keep the same geometrical structure of the scene [S1]. Before training the final 3 epochs, $\omega_P$ is replaced with a frozen $\omega_{NP}$ as the content view generator in TCM, and $L_{ref}$ and $L_{feat}$ are minimized only, with $\lambda_f = 0.2$ and $\lambda_0 = 0$, for smoother content update [S1]. The overall objective is $L_{NP} = \lambda_f L_{feat} + \lambda_r L_{ref} + \lambda_c L_{color}$ [S1]. The balancing factor $\lambda_r$ for reference loss is set to 1 [S1]. Ref-NPR is based on the ARF codebase and uses Plenoxels as the radiance field for scene representation [S1]. Each scene is trained on one NVIDIA 3090 GPU for 10 epochs [S1].

### [Template-Based Correspondence Module](15648-template-based-correspondence-module.md)
The Template-Based Correspondence Module (TCM) is a method for non-photorealistic radiance field optimization that broadcasts style from a reference view to novel views by enforcing semantic correspondence consistency. It addresses the limitation of Reference Ray Registration (R3), which fails to register reference rays to occluded regions in 360° scenes, by using a content-style mapping template to guide stylization across the entire scene.

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1].
*   **Memory Complexity:** The reference dictionary $D$ consumes memory proportional to $256^3$ voxels, with up to 8 rays per voxel [S1].
*   **Measured Performance:** Evaluated on Tanks and Temples (T&T), LLFF, and Synthetic datasets [S1]. Trained on one NVIDIA 3090 GPU for 10 epochs [S1].
*   **Strengths:** Establishes explicit semantic consistency between stylized reference and novel views using 3D information [S1].
*   **Limitations:** Struggles with occluded regions in 360° scenes without the TCM module [S1].
*   **When to use:** When stylizing a 3D scene with a single 2D reference view and maintaining semantic consistency across novel views is required [S1].
*   **When not to use:** When the scene has significant occlusions relative to the reference view and TCM is not available or applicable [S1].

## Background
Reference Ray Registration (R3) is part of the Ref-NPR (Reference-Based Non-Photorealistic Radiance Fields) method, introduced in 2023 [S1]. It builds on the idea that precise 3D positions and camera parameters enable pixel-wise correspondence between views, utilizing pseudo-depth from a radiance field to create supervision signals [S1]. Ref-NPR is based on the ARF codebase and uses Plenoxels as the radiance field representation [S1].
