# Reference-Based Non-Photorealistic Radiance Fields
Also called: Ref-NPR

## Overview
Ref-NPR is a controllable scene stylization method that transfers the style of a single 2D reference image to a 3D scene represented by a radiance field, ensuring semantic consistency across novel views [S1]. Unlike standard NeRF optimization which minimizes photometric error against ground-truth photos, Ref-NPR optimizes a non-photorealistic (NP) radiance field using explicit supervision from a stylized reference view and implicit supervision for occluded regions [S1]. It sets itself apart from sibling methods like [Neural Reconstruction in the Wild](6202-neural-reconstruction-in-the-wild.md) by explicitly mapping 2D stylized pixels to 3D space via ray registration to establish semantic correspondence, rather than relying solely on global style loss or 2D warping [S1].

## How it works
Ref-NPR builds on the differentiable volume rendering principles of [Neural Radiance Fields](4972-neural-radiance-fields.md). It optimizes a new NP radiance field $\omega_{NP}$ using a pre-trained photorealistic radiance field $\omega_P$ as a geometric prior [S1].

**Inputs:**
1.  Pre-trained photorealistic radiance field $\omega_P$ [S1].
2.  Set of training camera poses $\Phi$ and their corresponding content images $I_T$ [S1].
3.  A specific reference camera pose $\phi_R$ and its content image $I_R$ [S1].
4.  A stylized version of the reference image $S_R$, obtained via 2D stylization (e.g., Gatys or AdaIN) or manual editing [S1].

**Outputs:**
1.  Optimized non-photorealistic radiance field $\omega_{NP}$ [S1].
2.  Stylized renderings $S_T$ for arbitrary target camera poses $\phi_T$ [S1].

**Data Structures:**
*   **Radiance Field $\omega$**: A neural network mapping 3D position $\mathbf{x}$ and view direction $\mathbf{d}$ to density $\sigma$ and color $\mathbf{c}$ [G].
*   **Reference Dictionary $\mathcal{D}$**: A collection of rays from the reference camera $\phi_R$, each associated with a 3D intersection point and a stylized color [S1].
*   **Pseudo-Ray Supervision $\Gamma_R$**: A set of rays from training views $\Phi$ mapped to the reference dictionary, carrying stylized color targets [S1].

**Algorithm Steps:**

1.  **Render Reference View:** Render the content image $I_R$ from camera $\phi_R$ using $\omega_P$ to obtain the reference view [S1].
2.  **Stylize Reference:** Apply a 2D stylization algorithm to $I_R$ to generate the stylized reference view $S_R$ [S1].
3.  **Estimate Pseudo-Depth:** For each ray $r$ in the reference view, estimate the depth $l(r)$ where the ray intersects the scene geometry. The intersection point is defined as:
    $$
    x(r) = o + l(r)\mathbf{d}
    $$
    where $o$ is the camera origin, $\mathbf{d}$ is the ray direction, and $l(r)$ is the depth at which the accumulated transmittance drops below a threshold $\sigma_z$ [S1]:
    $$
    l(r) = \min \left\{ t_i \mid \sum_{j=1}^{i-1} \sigma_j (t_{j+1} - t_j) \ge \sigma_z \right\}
    $$
    [S1].
4.  **Build Reference Dictionary:** Construct a dictionary $\mathcal{D}$ for $S_R$ by storing the mapping from voxel coordinates $(x,y,z)$ to the stylized color $\hat{C}_R(r)$ and the ray direction [S1].
5.  **Reference Ray Registration (R3):** For each training ray $r_j$ from poses $\Phi \setminus \{\phi_R\}$, find a corresponding ray $\hat{r}_j$ in the reference dictionary $\mathcal{D}$ (associated with $\phi_R$) that minimizes the Euclidean distance between their 3D intersection points. Ray registration finds a ray in the dictionary whose intersection point drops into the same voxel $D(x,y,z)$ as the ray of interest: $Q(x(r_j)) = (x, y, z), r_j \in \Phi$ [S1]. To avoid over-matching from ray direction gaps, the angle between matched ray directions must not exceed a threshold $\theta$ [S1]:
    $$
    \hat{r}_j = \arg \min_{r \in \mathcal{D}} \| x(r_j) - x(r) \|_2 \quad \text{subject to} \quad \angle(\mathbf{d}_{r_i}, \mathbf{d}_{r_j}) < \theta
    $$
    [S1].
6.  **Construct Pseudo-Ray Supervision:** Create the supervision set $\Gamma_R$ by assigning the stylized color $\hat{C}_R(\hat{r}_j)$ from the reference dictionary to the registered training ray $r_j$ [S1].
7.  **Template-based Correspondence Module (TCM):** For regions in the reference view that are occluded in the training views (or vice versa), use TCM to propagate style implicitly. This module uses feature matching to fill occluded regions with perceptually similar styles, ensuring consistency where direct ray registration is impossible [S1].
8.  **Optimize NP Radiance Field:** Train $\omega_{NP}$ by minimizing a composite loss function $\mathcal{L}_{NP}$ that includes explicit supervision, feature loss, and implicit supervision from TCM [S1]:
    $$
    \mathcal{L}_{NP} = \mathcal{L}_{ref} + \mathcal{L}_{feat} + \mathcal{L}_{color}
    $$
    [S1].
9.  **Inference:** Render stylized images $S_T$ from arbitrary target poses $\phi_T$ using the optimized $\omega_{NP}$ [S1].

**Pseudocode:**

```python
import math
import numpy as np

def ref_npr_optimize(omega_P, phi_R, S_R, Phi, sigma_z, theta, N_samples, num_iterations, learning_rate):
    """
    Optimizes a non-photorealistic radiance field using reference-based stylization.
    
    Args:
        omega_P: Pre-trained photorealistic radiance field.
        phi_R: Reference camera pose.
        S_R: Stylized reference image.
        Phi: Set of training camera poses.
        sigma_z: Depth threshold for pseudo-depth estimation.
        theta: Maximum angle threshold for ray registration.
        N_samples: Number of samples per ray.
        num_iterations: Training loop iterations.
        learning_rate: Optimizer step size.
        
    Returns:
        omega_NP: Optimized non-photorealistic radiance field.
    """
    # Step 3 & 4: Build Reference Dictionary
    ref_rays = sample_rays(phi_R, N_samples)
    reference_dict = {}
    
    for ray in ref_rays:
        l_r = estimate_pseudo_depth(ray, omega_P, sigma_z, N_samples)
        x_r = ray.origin + l_r * ray.direction
        voxel_coords = quantize_to_voxel(x_r)
        
        # Store ray, intersection point, and stylized color
        reference_dict[voxel_coords] = {
            'ray': ray,
            'x': x_r,
            'color': get_pixel_color(S_R, ray.pixel_coords)
        }
        
    # Step 5 & 6: Reference Ray Registration (R3)
    pseudo_ray_supervision = []
    
    for phi in Phi:
        if phi == phi_R:
            continue
            
        train_rays = sample_rays(phi, N_samples)
        for ray_j in train_rays:
            l_j = estimate_pseudo_depth(ray_j, omega_P, sigma_z, N_samples)
            x_j = ray_j.origin + l_j * ray_j.direction
            voxel_coords_j = quantize_to_voxel(x_j)
            
            best_match = None
            min_dist = float('inf')
            
            if voxel_coords_j in reference_dict:
                ref_entry = reference_dict[voxel_coords_j]
                ref_ray = ref_entry['ray']
                
                # Check angle constraint to avoid over-matching
                angle = angle_between(ray_j.direction, ref_ray.direction)
                if angle < theta:
                    dist = np.linalg.norm(x_j - ref_entry['x'])
                    if dist < min_dist:
                        min_dist = dist
                        best_match = ref_entry
            
            if best_match is not None:
                pseudo_ray_supervision.append({
                    'ray': ray_j,
                    'target_color': best_match['color']
                })
                
    # Step 7: TCM for occluded regions (Implicit Supervision)
    # Implementation details for TCM are not provided in the sources [G].
    # Placeholder for implicit style loss computation over occluded regions.
    tcm_loss = compute_implicit_style_loss(S_R, omega_P, phi_R, Phi)
    
    # Step 8: Optimize NP Radiance Field
    omega_NP = initialize_radiance_field()
    optimizer = torch.optim.Adam(omega_NP.parameters(), lr=learning_rate)
    
    for iteration in range(num_iterations):
        batch_rays = sample_batch_rays(Phi, N_samples)
        rendered_colors = render_volume(batch_rays, omega_NP)
        
        explicit_loss = 0.0
        for sup in pseudo_ray_supervision:
            rendered_c = get_rendered_color_for_ray(rendered_colors, sup['ray'])
            target_c = sup['target_color']
            explicit_loss += torch.mean((rendered_c - target_c) ** 2)
            
        feature_loss = compute_style_loss(rendered_colors, S_R)
        total_loss = explicit_loss + feature_loss + tcm_loss
        
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
        
    return omega_NP

def estimate_pseudo_depth(ray, omega_P, sigma_z, N_samples):
    """Estimates depth l(r) where accumulated transmittance drops below sigma_z."""
    t_values = np.linspace(0.0, ray.max_dist, N_samples)
    accumulated_sigma = 0.0
    l_r = ray.max_dist
    
    for i in range(N_samples - 1):
        t_curr = t_values[i]
        t_next = t_values[i+1]
        delta_t = t_next - t_curr
        
        sigma = omega_P.query_density(t_curr, ray.direction)
        accumulated_sigma += sigma * delta_t
        
        if accumulated_sigma >= sigma_z:
            l_r = t_curr
            break
            
    return l_r

def sample_rays(camera_pose, N_samples):
    """Generates rays from camera origin through pixel centers."""
    rays = []
    for y in range(camera_pose.height):
        for x in range(camera_pose.width):
            origin = camera_pose.position
            direction = normalize(camera_pose.focal_matrix @ np.array([x, y, 1.0]))
            rays.append({'origin': origin, 'direction': direction, 'pixel_coords': (x, y), 'max_dist': camera_pose.max_dist})
    return rays

def quantize_to_voxel(point):
    """Maps 3D point to integer voxel coordinates."""
    return tuple(np.floor(point).astype(int))

def angle_between(v1, v2):
    """Computes angle in radians between two vectors."""
    cos_theta = np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))
    return np.arccos(np.clip(cos_theta, -1.0, 1.0))

def render_volume(rays, omega):
    """Standard volume rendering equation."""
    colors = []
    for ray in rays:
        t_values = np.linspace(0.0, ray['max_dist'], 64)
        accumulated_transmittance = 1.0
        accumulated_color = np.zeros(3)
        
        for i in range(len(t_values) - 1):
            t_curr = t_values[i]
            t_next = t_values[i+1]
            delta_t = t_next - t_curr
            
            sigma = omega.query_density(t_curr, ray['direction'])
            alpha = 1.0 - np.exp(-sigma * delta_t)
            
            accumulated_color += accumulated_transmittance * alpha * omega.query_color(t_curr, ray['direction'])
            accumulated_transmittance *= (1.0 - alpha)
            
        colors.append(accumulated_color)
    return np.array(colors)

def get_pixel_color(image, pixel_coords):
    """Retrieves stylized color from reference image."""
    return image[pixel_coords[1], pixel_coords[0]]

def get_rendered_color_for_ray(rendered_colors, ray):
    """Maps a ray to its corresponding rendered color in a batch."""
    idx = ray['pixel_coords'][1] * ray['width'] + ray['pixel_coords'][0]
    return rendered_colors[idx]

def compute_style_loss(rendered, reference):
    """Computes style loss (e.g., Gram matrix distance). Not fully specified in sources [G]."""
    return torch.mean((rendered - reference) ** 2)

def compute_implicit_style_loss(S_R, omega_P, phi_R, Phi):
    """Computes TCM loss for occluded regions. Implementation details not provided in sources [G]."""
    return torch.tensor(0.0)

def initialize_radiance_field():
    """Initializes NP radiance field parameters. Standard initialization [G]."""
    return torch.nn.Module()
```

**Parameters:**
*   $\sigma_z$: Depth threshold for pseudo-depth estimation. Not given in the sources.
*   $\theta$: Angle threshold for ray registration. Not given in the sources.
*   $N$: Number of samples per ray. Not given in the sources.

**Edge Cases:**
*   **Occlusions:** Rays from training views may not intersect the same 3D points as reference rays due to occlusion. R3 handles explicit supervision for visible regions, while TCM handles implicit supervision for occluded regions [S1].
*   **Over-matching:** Rays with similar intersection points but vastly different directions may be incorrectly matched. The angle constraint $\theta$ prevents this [S1].
*   **Precision:** Depth estimation relies on the accuracy of $\omega_P$ [G].

## Subtopics

### [Reference Ray Registration (R3)](15646-reference-ray-registration-r3.md)
A sub-method for establishing semantic consistency by mapping stylized reference pixels to 3D space via pseudo-depth and voxel-based matching. It provides explicit supervision for visible regions. Choose it when semantic correspondence is critical and a pre-trained geometric model is available.

## Operating characteristics
*   **Time Complexity:** Depends on the number of training views, samples per ray, and the size of the reference dictionary. Ray registration requires searching the dictionary for each training ray, which can be optimized with spatial hashing (voxels) [S1].
*   **Memory Complexity:** Requires storing the reference dictionary and the optimized NP radiance field. The dictionary size is proportional to the resolution of the reference view [G].
*   **Strengths:** Preserves semantic correspondence better than global style transfer methods; handles occlusions via TCM; controllable via single reference image [S1].
*   **Limitations:** Relies on the accuracy of the pre-trained photorealistic radiance field $\omega_P$ for geometry; may struggle with large viewpoint changes where ray registration fails; requires 2D stylization quality [G].
*   **When to use:** When stylizing a known 3D scene with a specific artistic style from a single reference image while maintaining object identity and structure [S1].
*   **When not to use:** When no pre-trained NeRF is available; when the reference view is significantly different from the training views (large baseline); when real-time performance is required without optimization [G].

## Background
Ref-NPR addresses the limitation of existing 3D scene stylization methods that lack meaningful semantic correspondences between the reference and novel views [S1]. The method builds on the differentiable rendering of NeRF and incorporates techniques from 2D style transfer (Gatys, AdaIN) and 3D geometry estimation [S1].
