# Reference-Based Non-Photorealistic Radiance Fields

Also called: Ref-NPR

## Overview
Ref-NPR is a controllable 3D scene stylization method that transfers the style of a single 2D reference view to a pre-trained photorealistic radiance field, ensuring semantic and geometric consistency in novel views [S1]. Unlike methods that apply style arbitrarily or require multi-view stylized inputs, Ref-NPR propagates style faithfully by establishing explicit semantic correspondence between the reference view and novel views via ray registration, and filling occluded regions using template-based feature matching [S1]. It builds on [Neural Radiance Fields](4972-neural-radiance-fields.md) by optimizing a new non-photorealistic (NP) radiance field using explicit and implicit supervisions derived from the reference [S1].

## How it works
Ref-NPR optimizes a non-photorealistic radiance field $\omega_{NP}$ to render stylized images $S_T$ from arbitrary camera poses $\phi_T$, given a pre-trained photorealistic radiance field $\omega_P$, a set of training camera poses $\Phi$, and a single stylized reference view $S_R$ corresponding to a reference camera pose $\phi_R$ [S1].

### Inputs and Outputs
**Inputs:**
*   Pre-trained photorealistic radiance field $\omega_P$ (parameters $\sigma, \mathbf{c}$) [S1].
*   Reference camera pose $\phi_R$ and its corresponding rendered view $I_R$ from $\omega_P$ [S1].
*   Stylized reference view $S_R$ (obtained by stylizing $I_R$) [S1].
*   Set of training camera poses $\Phi = \{\phi_1, \dots, \phi_K\}$ [S1].
*   Target camera poses $\phi_T$ for inference [S1].

**Outputs:**
*   Optimized non-photorealistic radiance field $\omega_{NP}$ [S1].
*   Stylized novel view images $S_T$ rendered from $\phi_T$ using $\omega_{NP}$ [S1].

### Data Structures
*   **Radiance Field ($\omega$):** A neural network mapping 3D position $\mathbf{x}$ and view direction $\mathbf{d}$ to density $\sigma$ and view-dependent color $\mathbf{c}$ [S1].
*   **Reference Dictionary ($\mathcal{D}$):** A collection of rays from the reference camera $\phi_R$ and their associated intersection points in 3D space, used for ray registration [S1].
*   **Pseudo-Ray Supervision ($\Gamma_R$):** A set of rays from training views $\Phi$ mapped to the reference view, along with their assigned stylized colors [S1].

### Algorithm Steps

1.  **Render Reference View:** Render the view $I_R$ from the reference camera pose $\phi_R$ using the pre-trained photorealistic radiance field $\omega_P$ [S1].
2.  **Stylize Reference:** Apply a structure-preserving 2D-stylization algorithm (e.g., Gatys [11] or AdaIN [20]) or manual editing to $I_R$ to obtain the stylized reference view $S_R$ [S1].
3.  **Construct Reference Dictionary:**
    *   For each pixel in $S_R$, cast a ray $r$ from $\phi_R$.
    *   Estimate the pseudo-depth $l(r)$ along the ray using the density $\sigma$ from $\omega_P$ [S1]:
        $$ l(r) = \min \left\{ t_i \mid \sum_{j=1}^{i-1} \sigma_j (t_{j+1} - t_j) \ge \sigma_z \right\} $$
        where $\sigma_z$ is a threshold [S1].
    *   Compute the intersection point $x(r)$:
        $$ x(r) = o + l(r)d $$
        where $o$ is the camera origin and $d$ is the ray direction [S1].
    *   Store the ray $r$ and its intersection point $x(r)$ in the reference dictionary $\mathcal{D}$ [S1].
4.  **Reference Ray Registration (R3):**
    *   For each training camera pose $\phi_j \in \Phi$, cast a ray $r_j$ for each pixel.
    *   Compute the intersection point $x(r_j)$ using $\omega_P$ [S1].
    *   Find the best-matching ray $\hat{r}_j$ in the reference dictionary $\mathcal{D}$ by minimizing the Euclidean distance between intersection points $x(r_j)$ and $x(\hat{r}_j)$ [S1].
    *   Apply a direction constraint: the angle between the directions of $r_j$ and $\hat{r}_j$ must be less than a threshold $\theta$:
        $$ \angle(d_{r_j}, d_{\hat{r}_j}) < \theta $$
    *   If a match is found, assign the color of the stylized reference view $S_R$ at the corresponding pixel of $\hat{r}_j$ to the ray $r_j$ [S1].
    *   Collect all validated registered rays and their assigned colors to form the pseudo-ray supervision set $\Gamma_R$ [S1].
5.  **Template-based Correspondence Module (TCM):**
    *   Use template-based feature matching to identify semantic correspondences between the reference view $S_R$ and the training views [S1].
    *   Generate implicit style supervision for occluded regions in the reference view that do not have explicit matches in the training views [S1].
6.  **Optimize Non-Photorealistic Radiance Field ($\omega_{NP}$):**
    *   Initialize $\omega_{NP}$ (e.g., copy parameters from $\omega_P$) [S1].
    *   Render images from training views $\Phi$ using $\omega_{NP}$.
    *   Compute loss functions:
        *   **Explicit Supervision Loss ($L_{ref}$):** Based on the pseudo-ray supervision $\Gamma_R$. For each ray $r_j \in \Gamma_R$, compare the rendered color $\hat{C}(r_j)$ from $\omega_{NP}$ with the assigned stylized color $C_{stylized}(r_j)$ from $S_R$ [S1].
        *   **Implicit Supervision Loss ($L_{feat}$):** Based on feature matching from TCM for occluded regions [S1].
        *   **Color/Feature Loss ($L_{color}$):** Standard photometric or feature consistency losses [S1].
    *   Update $\omega_{NP}$ by minimizing the total loss:
        $$ L_{\omega_{NP}} = L_{ref} + L_{feat} + L_{color} $$
    *   Iterate until convergence [S1].
7.  **Inference:**
    *   Render stylized results $S_T$ from target camera poses $\phi_T$ using the optimized $\omega_{NP}$ [S1].

### Pseudocode

```python
def ref_npr(omega_P, phi_R, I_R, stylize_func, Phi, theta, sigma_z):
    """
    Ref-NPR Method Implementation
    
    Args:
        omega_P: Pre-trained photorealistic radiance field
        phi_R: Reference camera pose
        I_R: Rendered reference view from omega_P
        stylize_func: 2D stylization function (e.g., Gatys, AdaIN)
        Phi: Set of training camera poses
        theta: Maximum angle threshold for ray registration
        sigma_z: Depth threshold for intersection calculation
        
    Returns:
        omega_NP: Optimized non-photorealistic radiance field
    """
    
    # Step 1 & 2: Stylize Reference View
    S_R = stylize_func(I_R)
    
    # Step 3: Construct Reference Dictionary
    reference_dictionary = []
    for pixel in S_R:
        ray_r = cast_ray(phi_R, pixel)
        # Estimate pseudo-depth
        l_r = estimate_depth(omega_P, ray_r, sigma_z)
        # Compute intersection point
        x_r = ray_r.origin + l_r * ray_r.direction
        reference_dictionary.append({
            'ray': ray_r,
            'point': x_r,
            'color': pixel.color
        })
    
    # Step 4: Reference Ray Registration (R3)
    pseudo_ray_supervision = []
    for phi_j in Phi:
        for pixel in get_view_from_pose(phi_j):
            ray_rj = cast_ray(phi_j, pixel)
            x_rj = ray_rj.origin + estimate_depth(omega_P, ray_rj, sigma_z) * ray_rj.direction
            
            # Find best match in reference dictionary
            best_match = None
            min_dist = infinity
            for entry in reference_dictionary:
                dist = euclidean_distance(x_rj, entry['point'])
                angle = angle_between(ray_rj.direction, entry['ray'].direction)
                
                if dist < min_dist and angle < theta:
                    min_dist = dist
                    best_match = entry
            
            if best_match is not None:
                # Assign stylized color from reference view
                stylized_color = best_match['color']
                pseudo_ray_supervision.append({
                    'ray': ray_rj,
                    'target_color': stylized_color
                })
    
    # Step 5: Template-based Correspondence Module (TCM)
    # This provides implicit supervision for occluded regions
    # Implementation details depend on specific feature matching algorithm
    implicit_supervision = compute_implicit_supervision(S_R, Phi, omega_P)
    
    # Step 6: Optimize Non-Photorealistic Radiance Field
    omega_NP = copy_parameters(omega_P)
    
    for epoch in range(max_epochs):
        total_loss = 0
        
        # Explicit Supervision Loss
        for sup in pseudo_ray_supervision:
            ray = sup['ray']
            target_color = sup['target_color']
            
            # Render color using omega_NP
            rendered_color = render_ray(omega_NP, ray)
            
            # Compute loss (e.g., L2)
            loss_explicit = l2_loss(rendered_color, target_color)
            total_loss += loss_explicit
            
        # Implicit Supervision Loss (from TCM)
        loss_implicit = compute_implicit_loss(omega_NP, implicit_supervision)
        total_loss += loss_implicit
        
        # Additional losses (e.g., color consistency)
        loss_color = compute_color_loss(omega_NP, Phi)
        total_loss += loss_color
        
        # Backpropagate and update omega_NP
        update_parameters(omega_NP, total_loss)
        
    return omega_NP

def estimate_depth(omega, ray, sigma_z):
    """
    Estimate depth along a ray using density threshold.
    """
    samples = sample_ray(ray, N=100)
    accumulated_density = 0
    for i, sample in enumerate(samples):
        sigma = omega.density(sample.position)
        delta = sample.distance - (samples[i-1].distance if i > 0 else 0)
        accumulated_density += sigma * delta
        if accumulated_density >= sigma_z:
            return sample.distance
    return samples[-1].distance

def render_ray(omega, ray):
    """
    Render a single ray using the volume rendering equation.
    """
    samples = sample_ray(ray, N=100)
    color = [0.0, 0.0, 0.0]
    transmittance = 1.0
    
    for sample in samples:
        sigma = omega.density(sample.position)
        c = omega.color(sample.position, ray.direction)
        delta = sample.distance - (samples[samples.index(sample)-1].distance if samples.index(sample) > 0 else 0)
        
        alpha = 1.0 - exp(-sigma * delta)
        weight = transmittance * alpha
        color += weight * c
        transmittance *= (1.0 - alpha)
        
    return color
```

### Parameters and Typical Values
*   **$\theta$ (Angle Threshold):** Not given in the sources. [G] Typical values for ray matching might be $10^\circ$-$30^\circ$.
*   **$\sigma_z$ (Depth Threshold):** Not given in the sources. [G] Typically a small value like $0.1$ or $1.0$ depending on scene scale.
*   **Stylization Algorithm:** Gatys [11] or AdaIN [20] [S1].

### Edge Cases and Pitfalls
*   **Occluded Regions:** Rays in novel views that correspond to occluded parts of the reference view may not have explicit matches in the reference dictionary. TCM handles this via implicit supervision [S1].
*   **Over-matching:** Rays with similar intersection points but vastly different directions may be incorrectly matched. The angle constraint $\theta$ mitigates this [S1].
*   **Precision:** Depth estimation relies on the density threshold $\sigma_z$. Inaccurate density from $\omega_P$ can lead to incorrect intersection points [S1].

## Subtopics

### [Reference Ray Registration (R3)](15646-reference-ray-registration-r3.md)
A method to establish semantic consistency between a stylized reference view and novel views by creating a reference dictionary of rays and assigning stylized colors to registered novel view rays. It provides explicit supervision for the optimization of the NP radiance field. Choose this when explicit semantic correspondence is required for style transfer.

## Operating characteristics
*   **Time Complexity:** Not given in the sources. [G] Ray registration involves matching each training ray to a reference ray, which is $O(N_{train} \cdot N_{ref})$ without spatial indexing. Optimization is similar to NeRF training.
*   **Memory Complexity:** Not given in the sources. [G] Requires storing the reference dictionary and pseudo-ray supervision.
*   **Strengths:** Preserves geometric and semantic consistency with the reference view; handles occlusions via TCM; works with a single reference view [S1].
*   **Limitations:** Relies on the accuracy of the pre-trained photorealistic radiance field $\omega_P$ for depth estimation and ray registration; may struggle with large viewpoint changes if the angle constraint $\theta$ is too strict or too loose [S1].
*   **When to Use:** When stylizing a 3D scene with a single 2D reference image while maintaining semantic consistency across novel views.
*   **When Not to Use:** When multiple reference views are available (other methods might be more robust) or when the pre-trained NeRF is inaccurate.

## Background
Ref-NPR was introduced in "Ref-NPR: Reference-Based Non-Photorealistic Radiance Fields for Controllable Scene Stylization" [S1]. It addresses the limitation of existing 3D scene stylization methods that lack meaningful semantic correspondences when using arbitrary style references [S1]. The method builds on the differentiability of radiance fields and the volume rendering equation [44-radiance-field-optimization.md].
