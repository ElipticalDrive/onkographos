# NeRF-MAE

Also called: Masked AutoEncoders for Self-Supervised 3D Representation Learning for Neural Radiance Fields, Masked voxel-grid pretraining, NeRF Masked Auto Encoders, NeRF-MAE Masked Radiance and Density Grid Pretraining

## Overview
NeRF-MAE is a self-supervised pretraining framework for Neural Radiance Fields (NeRF) that learns 3D scene representations by masking and reconstructing patches from an explicit radiance and density grid [S1]. Unlike implicit NeRFs or point-cloud-based methods, it operates directly on the regular, high-density volumetric grid extracted from a trained NeRF, allowing the use of standard 3D Vision Transformers without adaptation [S1]. It disentangles representation learning from NeRF training, enabling the use of large-scale unlabeled data from diverse sources to improve downstream tasks such as 3D object detection and semantic labeling [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Posed RGB images used to train an initial implicit NeRF, and the resulting explicit 4D radiance/density grid $G$ [S1].
*   **Output:** A reconstructed 4D volume $R \in \mathbb{R}^{H \times W \times D \times 4}$ containing predicted radiance (RGB) and opacity ($\alpha$) [S1].

**Data Structures:**
The core data structure is the explicit grid $G \in \mathbb{R}^{H \times W \times D \times 4}$, where $H, W, D$ are spatial dimensions and the 4 channels represent $(r, g, b, \alpha)$ [S1].
*   **Patches:** The grid is partitioned into cubic patches of size $P = p \times p \times p$ with $p=4$ [S1].
*   **Tokens:** Patches are converted into 3D tokens of size $\frac{H}{p} \times \frac{W}{p} \times \frac{D}{p} \times E$ via a 3D convolutional embedding layer [S1].
*   **Masking:** A binary mask $M$ indicates which patches are hidden. A masking ratio of $m=0.75$ is used [S1].

**Parameters:**
*   Grid dimensions: $H=W=D=160$ [S1].
*   Patch size: $p=4$ [S1].
*   Masking ratio: $m=0.75$ [S1].
*   Encoder Embedding dimension: $E=96$ [S1].
*   Swin Transformer block depths: $d=[2, 2, 18, 2]$ [S1].
*   Number of attention heads: $[3, 6, 12, 24]$ for the four stages [S1].
*   Window size: $W_{win}=4$ [S1].
*   Preset distance for opacity calculation: $\Delta x = 0.01$ [S1].

**Steps:**

1.  **Grid Extraction:**
    Train an implicit NeRF $f(x, \theta)$ (e.g., Instant-NGP) on posed images [S1]. Extract the explicit grid $G$ by querying the NeRF for all training camera viewing directions $\theta$ at each grid point $(i, j, k)$ and averaging the output [S1]:
    $$
    (r_{i, j, k}, g_{i, j, k}, b_{i, j, k}, \alpha_{i, j, k}) = \frac{1}{N} \sum_{\theta=1}^{N} f(x_{i, j, k}, \theta)
    $$
    where $N$ is the number of training images [S1]. The opacity $\alpha$ is derived from volume density $\sigma$ and a preset distance $\Delta x = 0.01$:
    $$
    \alpha = 1 - \exp(-\sigma \Delta x)
    $$
    [S1].

2.  **Masking:**
    Randomly mask out patches of size $p \times p \times p$ from $G$ with ratio $m=0.75$ to create the masked grid $M$ [S1].

3.  **Patch Partitioning and Embedding:**
    Divide $M$ into patches using a 3D convolutional operation that merges partitioning and linear embedding into one step, creating tokens of size $\frac{H}{p} \times \frac{W}{p} \times \frac{D}{p} \times E$ [S1].

4.  **Positional Encoding:**
    Add 3D positional embeddings to each token. No classification token is added [S1].

5.  **Encoder (3D Swin Transformer):**
    Process tokens through 4 stages. Each stage consists of Swin Transformer 3D blocks and patch merging layers (except the last stage) [S1].
    *   **Block Structure:** Each block contains local multi-head self-attention (W-MSA-3D) or shifted multi-head self-attention (SW-MSA-3D), a 2-layer MLP with GeLU activation, Linear Norm (LN) layers, and residual connections [S1].
    *   **Window Shifting:** Windows are displaced by $[\frac{W_{win}}{2}, \frac{W_{win}}{2}, \frac{W_{win}}{2}]$ every layer [S1].
    *   **Patch Merging:** Merges four volumetric patches, reducing spatial dimensions by 2 and increasing channel dimension by 2, followed by LN and MLP [S1].
    *   **Feature Pyramid:** Concatenate outputs of all 4 stages to form feature pyramid $F = [f_0, f_1, f_2, f_3]$ [S1]. The final encoder output has spatial size $5 \times 5 \times 5$ and channel dimension 768 [S1].

6.  **Decoder:**
    Reconstruct the grid using lightweight transposed 3D convolution decoders $D_i$ attached to the feature pyramid [S1].
    *   **Update Rule:** $d_i = \text{Conv}(d_{i-1} + D(f_i))$ with $d_0 = f_3$, where $D$ is a transposed 3D convolution with kernel size 3 [S1].
    *   **Output Prediction:** The final decoder output passes through a residual block with $3 \times 3 \times 3$ convolutions and a sigmoid activation to predict $R \in \mathbb{R}^{H \times W \times D \times 4}$ [S1].

7.  **Loss Computation:**
    Compute reconstruction loss $\mathcal{L}_{recon} = \mathcal{L}_{rad} + \mathcal{L}_{\alpha}$ [S1].
    *   Radiance Loss:
        $$
        \mathcal{L}_{rad} = \frac{1}{K} \sum_{i=1}^{N} (\hat{y}_{rad_i} - y_{rad_i})^2
        $$
        where $K$ is the number of voxels in the mask corresponding to patches where $\alpha > \Delta x$ ($\Delta x = 0.01$) [S1].
    *   Opacity Loss:
        $$
        \mathcal{L}_{\alpha} = \frac{1}{M} \sum_{j=1}^{M} (\hat{y}_{\alpha_j} - y_{\alpha_j})^2
        $$
        where $M$ is the number of voxels in the mask corresponding to removed 3D patches [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class NeRFMAE:
    def __init__(self, H=160, W=160, D=160, p=4, m=0.75, E=96, window_size=4):
        self.H, self.W, self.D = H, W, D
        self.p = p
        self.m = m
        self.E = E
        self.window_size = window_size
        self.num_patches = (H // p) * (W // p) * (D // p)

        # Patch embedding: 3D conv merging partitioning and linear embedding
        self.patch_embed = nn.Conv3d(4, E, kernel_size=p, stride=p)

        # Encoder: 4 stages of Swin Transformer 3D blocks
        # Depths: [2, 2, 18, 2], Heads: [3, 6, 12, 24]
        self.encoder_stages = nn.ModuleList()
        embed_dims = [E, E*2, E*4, E*8] # Patch merging doubles channels
        for i in range(4):
            stage = []
            for _ in range([2, 2, 18, 2][i]):
                stage.append(SwinTransformer3DBlock(embed_dims[i], window_size, [3, 6, 12, 24][i]))
            self.encoder_stages.append(nn.Sequential(*stage))
            if i < 3: # Patch merging after each block except last
                self.encoder_stages.append(nn.Sequential(
                    PatchMerging3D(embed_dims[i], embed_dims[i+1]),
                    nn.LayerNorm(embed_dims[i+1]),
                    nn.Linear(embed_dims[i+1], embed_dims[i+1])
                ))

        # Decoder: 4 stages with transposed convs
        # d0 = f3. di = Conv(d_{i-1} + D(fi))
        self.decoder_stages = nn.ModuleList()
        for i in range(3, -1, -1):
            self.decoder_stages.append(nn.ConvTranspose3d(embed_dims[i], embed_dims[i], kernel_size=3, padding=1))

        self.final_block = nn.Sequential(
            nn.Conv3d(embed_dims[0], embed_dims[0], kernel_size=3, padding=1),
            nn.ReLU(),
            nn.Conv3d(embed_dims[0], 4, kernel_size=3, padding=1),
            nn.Sigmoid()
        )

    def forward(self, G):
        # G: (B, 4, H, W, D)
        B = G.shape[0]

        # 1. Masking
        num_masked = int(self.num_patches * self.m)
        mask_indices = torch.randperm(self.num_patches)[:num_masked]
        patch_mask = torch.zeros(self.num_patches)
        patch_mask[mask_indices] = 1.0

        # Reshape to patches: (B, num_patches, p*p*p*4)
        patches = G.unfold(2, self.p, self.p).unfold(3, self.p, self.p).unfold(4, self.p, self.p)
        patches = patches.permute(0, 5, 6, 7, 1, 2, 3).reshape(B, -1, self.p**2 * 4)

        # Zero out masked patches
        masked_patches = patches * (1 - patch_mask.unsqueeze(0).unsqueeze(-1))
        masked_grid = masked_patches.reshape(B, 4, self.H, self.W, self.D)

        # 2. Patch Embedding
        x = self.patch_embed(masked_grid) # (B, E, H/p, W/p, D/p)

        # 3. Positional Encoding [G]
        pos_embed = self._get_3d_pos_embed(x.shape[2], x.shape[3], x.shape[4])
        x = x + pos_embed

        # 4. Encoder -> Feature Pyramid F = [f0, f1, f2, f3]
        F = []
        for stage in self.encoder_stages:
            x = stage(x)
            F.append(x)

        # 5. Decoder
        # d0 = f3
        d = F[3]
        # di = Conv(d_{i-1} + D(fi)) for i=2,1,0
        for i in range(2, -1, -1):
            fi = F[i]
            # D(fi) is transposed conv
            fi_up = self.decoder_stages[3-i](fi)
            d = self.decoder_stages[3-i](d + fi_up) # Conv(d_{i-1} + D(fi))

        # 6. Output Prediction
        R = self.final_block(d)
        return R, mask_indices

    def compute_loss(self, R, G, mask_indices):
        # Reshape to patches
        R_patches = R.unfold(2, self.p, self.p).unfold(3, self.p, self.p).unfold(4, self.p, self.p)
        R_patches = R_patches.permute(0, 5, 6, 7, 1, 2, 3).reshape(R.shape[0], -1, self.p**2 * 4)
        G_patches = G.unfold(2, self.p, self.p).unfold(3, self.p, self.p).unfold(4, self.p, self.p)
        G_patches = G_patches.permute(0, 5, 6, 7, 1, 2, 3).reshape(G.shape[0], -1, self.p**2 * 4)

        R_masked = R_patches[:, mask_indices, :]
        G_masked = G_patches[:, mask_indices, :]

        # Split radiance (RGB) and opacity (Alpha)
        R_rad = R_masked[:, :, :3]
        G_rad = G_masked[:, :, :3]
        R_alpha = R_masked[:, :, 3:]
        G_alpha = G_masked[:, :, 3:]

        # Flatten to voxels
        R_rad_flat = R_rad.reshape(R_rad.shape[0], -1, 3)
        G_rad_flat = G_rad.reshape(G_rad.shape[0], -1, 3)
        G_alpha_flat = G_alpha.reshape(G_alpha.shape[0], -1, 1)

        # L_rad: K voxels where target alpha > 0.01
        alpha_thresh = 0.01
        valid_voxels = (G_alpha_flat > alpha_thresh).squeeze(-1) # (B, num_masked_voxels)
        R_rad_valid = R_rad_flat[valid_voxels]
        G_rad_valid = G_rad_flat[valid_voxels]
        K = R_rad_valid.shape[0]
        L_rad = torch.mean((R_rad_valid - G_rad_valid)**2) if K > 0 else torch.tensor(0.0)

        # L_alpha: M all masked voxels
        L_alpha = torch.mean((R_alpha.reshape(R_alpha.shape[0], -1) - G_alpha.reshape(G_alpha.shape[0], -1))**2)

        return L_rad + L_alpha

    def _get_3d_pos_embed(self, H, W, D):
        # Standard 3D sinusoidal positional embedding [G]
        freqs = torch.arange(0, self.E // 4, dtype=torch.float32)
        freqs = (1.0 / (10000 ** (freqs / (self.E / 2))))
        pos = torch.arange(H * W * D, dtype=torch.float32)
        out = torch.sin(torch.outer(pos, freqs))
        out = torch.cat([out, torch.cos(torch.outer(pos, freqs))], dim=-1)
        return out.reshape(1, 1, H, W, D)

class SwinTransformer3DBlock(nn.Module):
    def __init__(self, dim, window_size, num_heads):
        super().__init__()
        self.attn = WindowAttention3D(dim, window_size, num_heads)
        self.mlp = nn.Sequential(
            nn.LayerNorm(dim),
            nn.Linear(dim, dim * 4),
            nn.GELU(),
            nn.Linear(dim * 4, dim)
        )
        self.norm1 = nn.LayerNorm(dim)
        self.norm2 = nn.LayerNorm(dim)

    def forward(self, x):
        # x shape: (B, C, H, W, D)
        # Standard Swin requires shifting windows. Simplified for pseudocode.
        x = x + self.attn(self.norm1(x))
        x = x + self.mlp(self.norm2(x))
        return x

class WindowAttention3D(nn.Module):
    def __init__(self, dim, window_size, num_heads):
        super().__init__()
        self.num_heads = num_heads
        self.scale = (dim // num_heads) ** -0.5
        self.qkv = nn.Linear(dim, dim * 3)
        self.proj = nn.Linear(dim, dim)
        self.window_size = window_size

    def forward(self, x):
        B, C, H, W, D = x.shape
        # Implementation details omitted for brevity, follows standard 3D window attention [G]
        # Returns tensor of shape (B, C, H, W, D)
        return self.proj(self.qkv(x).view(B, -1, 3, C // 3, self.num_heads, -1).permute(2, 0, 3, 4, 1, 5).mean(dim=0))

class PatchMerging3D(nn.Module):
    def __init__(self, in_channels, out_channels):
        super().__init__()
        self.conv = nn.Conv3d(in_channels, out_channels, kernel_size=2, stride=2)
        self.norm = nn.LayerNorm(out_channels)
        self.mlp = nn.Linear(out_channels, out_channels)

    def forward(self, x):
        # x shape: (B, C, H, W, D)
        x = self.conv(x)
        B, C, H, W, D = x.shape
        x = x.permute(0, 2, 3, 4, 1).reshape(B, -1, C)
        x = self.norm(x)
        x = self.mlp(x)
        return x.permute(0, 2, 1).reshape(B, -1, H, W, D)
```

## Operating characteristics
*   **Time Complexity:** The encoder uses shifted window attention, which reduces the quadratic complexity of global self-attention to linear with respect to the number of voxels, making it efficient for large volumes [S1].
*   **Memory Complexity:** The explicit grid storage requires $O(H \times W \times D)$ memory. For $160^3$, this is manageable. The attention mechanism's memory usage is proportional to the number of tokens and window size [S1].
*   **Performance:** NeRF-MAE significantly outperforms self-supervised 3D pretraining and NeRF scene understanding baselines on Front3D and ScanNet datasets, with an absolute performance improvement of over 20% AP50 and 8% AP25 for 3D object detection [S1].
*   **Strengths:** Utilizes standard 3D Transformers without adaptation; disentangles representation learning from NeRF training, allowing use of diverse data sources; handles dense volumetric information better than sparse point clouds [S1].
*   **Limitations:** Requires an initial trained NeRF to extract the grid; relies on posed images; the explicit grid extraction can be computationally expensive for very large scenes [S1].

## Background
NeRF-MAE was introduced by M.Z. Irshad et al. in 2024 [S1]. It builds on the success of Masked Autoencoders (MAE) in 2D vision and extends it to 3D neural radiance fields [S1]. The method addresses the lack of large-scale self-supervised pretraining for NeRFs by leveraging the regular structure of the explicit radiance and density grid [S1]. It is used for downstream tasks such as 3D object detection, voxel-grid super-resolution, and semantic voxel labeling [S1].
