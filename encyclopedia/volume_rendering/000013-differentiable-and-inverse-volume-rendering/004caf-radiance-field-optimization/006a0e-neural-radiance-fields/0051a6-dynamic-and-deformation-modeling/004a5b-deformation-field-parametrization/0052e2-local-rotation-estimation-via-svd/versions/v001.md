# Local Rotation Estimation via SVD

Also called: SVD-based Rotation Estimation

## Overview
Local Rotation Estimation via SVD is a technique used in dynamic neural radiance fields to correct view-dependent rendering artifacts caused by large local rotations during deformation [S1, unofficial]. While deformation MLPs can accurately predict point translations, direct rendering of deformed points without accounting for orientation changes leads to inconsistencies between the deformed space and the canonical space [S1, unofficial]. This method estimates the local rotation for each point using Singular Value Decomposition (SVD), inspired by As-Rigid-As-Possible (ARAP) mesh deformation, and interpolates these rotations to redirect querying rays [S1, unofficial]. It sets itself apart from siblings like [Neural Deformation Field](12724-neural-deformation-field.md) by explicitly modeling the rotational component of deformation to preserve view-dependent appearance, rather than relying solely on positional shifts or implicit feature adjustments.

## How it works
**Inputs:**
- A set of points in the canonical space $P = \{(\mathbf{x}_i, \mathbf{f}_i, \gamma_i)\}$, where $\mathbf{x}_i$ is the position, $\mathbf{f}_i$ is the neural feature, and $\gamma_i$ is the scale confidence [S1, unofficial].
- A deformation field (typically an MLP) that predicts the translation $\Delta \mathbf{x}_i$ for each point to its deformed position $\mathbf{x}'_i = \mathbf{x}_i + \Delta \mathbf{x}_i$ [S1, unofficial].
- A query ray $\mathbf{r}$ defined by origin $\mathbf{o}$ and direction $\mathbf{d}$ in the camera space [S1, unofficial].

**Outputs:**
- A corrected ray direction $\mathbf{d}'$ in the canonical space that accounts for the local rotation at the intersection point [S1, unofficial].
- The rendered color $\hat{C}(\mathbf{r})$ using the standard emission-absorption model [44-radiance-field-optimization.md].

**Data Structures:**
- **Point Cloud:** List of tuples $(\mathbf{x}_i, \mathbf{f}_i, \gamma_i)$.
- **Rotation Field:** A mapping from point indices to $3 \times 3$ rotation matrices $R_i$.
- **Ray:** Origin $\mathbf{o} \in \mathbb{R}^3$, Direction $\mathbf{d} \in \mathbb{R}^3$ (normalized).

**Steps:**

1. **Deform Points:**
   For each point $i$ in the canonical point cloud, compute the deformed position $\mathbf{x}'_i$ using the deformation MLP:
   $$ \mathbf{x}'_i = \mathbf{x}_i + \text{MLP}_{\text{def}}(\mathbf{x}_i) $$
   [S1, unofficial]

2. **Estimate Local Rotation via SVD:**
   For each point $i$, estimate the local rotation matrix $R_i$ that best aligns the local neighborhood in the canonical space to the deformed space. This is done by constructing a covariance matrix from the relative vectors of the point and its neighbors, then applying SVD.
   
   Let $\mathcal{N}(i)$ be the set of neighbors of point $i$. Construct the matrix $H_i$:
   $$ H_i = \sum_{j \in \mathcal{N}(i)} (\mathbf{x}_j - \mathbf{x}_i)(\mathbf{x}'_j - \mathbf{x}'_i)^T $$
   [G: Neighbor selection is typically based on k-nearest neighbors or a fixed radius, as implied by the ARAP analogy in [S1, unofficial] and [S2].]
   
   Perform SVD on $H_i$:
   $$ H_i = U_i \Sigma_i V_i^T $$
   [S1, unofficial]
   
   Compute the rotation matrix $R_i$:
   $$ R_i = V_i U_i^T $$
   [G: If $\det(R_i) = -1$, multiply the last column of $V_i$ by $-1$ to ensure a proper rotation (no reflection). This is a standard SVD rotation extraction step [G].]
   [S1, unofficial]

3. **Interpolate Rotation to Query Ray:**
   When a ray $\mathbf{r}$ intersects the deformed geometry, identify the nearest deformed point $\mathbf{x}'_k$ (or a set of nearby points). Interpolate the local rotation matrices $R_k$ to the query location to obtain the global rotation $R_{\text{query}}$ [S1, unofficial].
   [G: Interpolation is typically done via weighted averaging of rotation matrices (e.g., using quaternion slerp or matrix logarithm/exponential) to maintain the rotation group structure, though the source notes do not specify the exact interpolation formula. We assume a standard weighted average of the resulting matrices or quaternions derived from them.]

4. **Ray Bending (Redirect Ray):**
   Transform the query ray direction $\mathbf{d}$ from the deformed space back to the canonical space using the estimated rotation. The ray origin $\mathbf{o}$ is also transformed if necessary, but the primary correction is on the direction to align with the canonical view dependence.
   $$ \mathbf{d}_{\text{canonical}} = R_{\text{query}}^T \mathbf{d} $$
   [S1, unofficial]
   The ray origin $\mathbf{o}$ is transformed to the canonical space position $\mathbf{o}_{\text{canonical}}$ using the inverse deformation or by tracing back from the deformed intersection point.
   [G: The source states "redirect the querying ray in the right direction", implying the ray is bent to sample the canonical radiance field correctly. The exact transformation of the origin is implied by the need to query the canonical space.]

5. **Render:**
   Use the canonical ray $(\mathbf{o}_{\text{canonical}}, \mathbf{d}_{\text{canonical}})$ to query the pre-trained canonical radiance field for density $\sigma$ and color $\mathbf{c}$, then integrate using the standard volume rendering equation [44-radiance-field-optimization.md].

**Parameters:**
- Neighbor selection radius or $k$ for SVD computation: Not given in the sources.
- Weighting scheme for interpolation: Not given in the sources.

**Edge Cases and Pitfalls:**
- **Degenerate Neighbors:** If a point has no neighbors or collinear neighbors, the covariance matrix $H_i$ may be singular. [G: Add a small regularization term $\epsilon I$ to $H_i$ before SVD.]
- **Reflection:** SVD can produce a reflection ($\det(R) = -1$). Must check determinant and correct if necessary [G].
- **Large Rotations:** The method is specifically designed for large rotations where simple translation-based deformation fails [S1, unofficial].

## Subtopics

### ARAP Mesh Deformation
As-Rigid-As-Possible (ARAP) mesh deformation is the foundational technique from which the SVD-based rotation estimation borrows its core idea [S1, unofficial]. It minimizes the distortion energy of a mesh by optimizing local rotations $R_i$ and deformed positions $v'_i$ alternately. The energy function is:
$$ E(S^0) = \sum_{i=1}^{n} \sum_{j \in N(i)} w_{ij} \| (v'_i - v'_j) - R_i(v_i - v_j) \|^2 $$
where $w_{ij} = \frac{1}{2}(\cot \alpha_{ij} + \cot \beta_{ij})$ is the cotangent weight, and $\alpha_{ij}, \beta_{ij}$ are angles opposite to edge $(i,j)$ [S2]. This method is used when the deformation is guided by a mesh structure rather than a point cloud, providing a rigid-body-like deformation that preserves local geometry [S2]. It is chosen when explicit mesh topology is available and rigidity is desired.

## Operating characteristics
**Time and Memory Complexity:**
- The SVD computation is performed per point, which is $O(1)$ per point if the number of neighbors is fixed, but requires neighbor search which is $O(N \log N)$ or $O(N)$ with spatial hashing.
- Interpolation is $O(1)$ per ray sample.
- Memory usage is dominated by storing the point cloud and the deformation MLP, similar to standard NeRFs. The additional storage for rotation matrices is $9 \times N$ floats.

**Measured Performance:**
- The method significantly outperforms state-of-the-art methods on fine-level complex deformation for digital humans and other 3D characters [S1, unofficial].
- It allows for consistent rendering of deformed scenes without introducing extra complexity into the NeRF model structure itself, unlike methods that add extra information to features [S1, unofficial].

**Strengths and Limitations:**
- **Strengths:** Handles large rotations effectively; simple to integrate into existing point-based NeRF frameworks; preserves view-dependent appearance [S1, unofficial].
- **Limitations:** Relies on the quality of the deformation field; requires neighbor information for SVD, which may be sparse in some point clouds; interpolation of rotations can be non-trivial to implement correctly [S1, unofficial].

**When to Use:**
- Use when rendering deformed 3D characters or objects with significant local rotations where view-dependent effects are important.
- Use when a point-based representation is preferred over mesh-based or voxel-based representations.

**When Not to Use:**
- Use when deformations are small and rigid, as the rotational correction may be negligible.
- Use when computational resources are extremely limited and neighbor search/SVD overhead is prohibitive.

## Background
The method was introduced in "Point-Based Radiance Fields for Controllable Human Motion Synthesis" by Zhang et al. in 2023 [S1, unofficial]. It addresses the limitation of previous point-based NeRF editing methods that only modeled translation, leading to artifacts under large rotations. The approach borrows the SVD-based rotation estimation from ARAP mesh deformation, a technique originally developed for geometry processing [S2]. The work demonstrates that ray-bending using estimated local rotations can significantly improve the visual quality of dynamic NeRFs for human motion synthesis.
