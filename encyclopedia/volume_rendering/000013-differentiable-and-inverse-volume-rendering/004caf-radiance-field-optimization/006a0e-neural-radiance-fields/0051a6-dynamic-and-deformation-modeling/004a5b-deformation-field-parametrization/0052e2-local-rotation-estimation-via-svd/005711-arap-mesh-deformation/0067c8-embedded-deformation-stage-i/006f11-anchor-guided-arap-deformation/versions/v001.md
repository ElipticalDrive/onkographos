# Anchor-Guided ARAP Deformation
Also called: Anchor-based ARAP, Global deformation

## Overview
Anchor-Guided ARAP Deformation is a variational mesh deformation method that computes a globally rigid-consistent deformation of a template mesh by minimizing a combination of As-Rigid-As-Possible (ARAP) energy and a sparse anchor fidelity term [S1, unofficial]. It solves the problem of applying noisy or sparse motion flows (e.g., from voxelized geometry tracking) to a mesh without propagating noise across the entire surface [S1, unofficial]. Unlike standard ARAP [SA07] which relies on fixed boundary conditions, this method uses a dynamically selected subset of high-curvature or high-motion vertices as anchors, making it resilient to input noise while preserving local geometric features [S1, unofficial].

## How it works
**Inputs:**
- Template mesh $M_0$ with vertices $p_i$ and one-ring neighborhoods $N(i)$.
- Target positions $p'_i$ derived from a noisy motion flow (e.g., voxel correspondence).
- Edge weights $w_{ij}$ for the ARAP term.

**Outputs:**
- Deformed mesh positions $p^0_i$ (denoted $p'_i$ in source notation for the optimized state).
- Local rotation matrices $R_i$ for each vertex.

**Data Structures:**
- **Mesh Connectivity:** Adjacency list or matrix defining $N(i)$.
- **Laplacian Matrix $L$:** Sparse matrix of size $n \times n$ (where $n$ is the number of vertices).
- **RHS Vector $b$:** Dense vector of size $3n$ (3 components per vertex).
- **Anchor Weights $w_{ai}$:** Scalar weight per vertex; 0 if not an anchor.

**Anchor Selection:**
1. For each vertex $i$, compute a curvature score using the method in [PGK02].
2. Compute a motion vector score based on correspondence matching [BLNL14].
3. Normalize and sum these scores to get a vertex score.
4. Select the subset of vertices with the highest scores as anchors.
5. Set $w_{ai}$ to the normalized score for anchors, and $0$ otherwise [S1, unofficial].

**Algorithm:**
The method minimizes the total energy:
$$ E(M_0) = E_{ARAP}(M_0) + E_{ANC}(M_0) $$

Where:
$$ E_{ARAP}(M_0) = \frac{1}{2} \sum_{i=1}^{n} \sum_{j \in N(i)} w_{ij} \|(p^0_i - p^0_j) - R_i(p_i - p_j)\|^2 $$
$$ E_{ANC}(M_0) = \frac{1}{2} \sum_{i=1}^{n} w_{ai} \|p^0_i - p_i\|^2 $$
Note: In the source, $p_i$ in the anchor term refers to the target position from the motion flow, while $p^0_i$ is the optimized position. To avoid confusion with the template $p_i$, let $t_i$ be the target position from the flow. The anchor energy is $\frac{1}{2} \sum_{i=1}^{n} w_{ai} \|p^0_i - t_i\|^2$ [S1, unofficial].

**Steps:**
1. **Initialization:** Set initial rotations $R_i$ (e.g., identity matrices) [S1, unofficial].
2. **Iterate until convergence:**
   a. **Solve Linear System:** Construct $L$ and $b$ based on current $R_i$. Solve $L p^0 = b$ for new positions $p^0$.
      - $L$ is the Laplacian of $M_0$ with $w_{ai}$ added to the diagonal entries for anchor nodes [S1, unofficial].
      - $b$ is constructed from the optimality condition:
        $$ \sum_{j \in N(i)} w_{ij}(p^0_i - p^0_j) + w_{ai}p^0_i = \sum_{j \in N(i)} w_{ij} \frac{1}{2} (R_i - R_j)(p_i - p_j) + w_{ai}t_i $$
        Rearranging for the linear system $L p^0 = b$, the RHS term for vertex $i$ is:
        $$ b_i = \sum_{j \in N(i)} w_{ij} \frac{1}{2} (R_i - R_j)(p_i - p_j) + w_{ai}t_i $$
        (Note: The source equation (3) implies the RHS involves the rotation difference. The standard ARAP derivation [SA07] is mirrored here with added anchor terms) [S1, unofficial].
   b. **Update Rotations:** For each vertex $i$, compute the optimal rotation $R_i$ using SVD on the covariance matrix of the vectors $(p_i - p_j)$ and $(p^0_i - p^0_j)$ for $j \in N(i) \cup \{i\}$, as derived in [SA07] [S1, unofficial].

**Pseudocode:**
```python
def anchor_guided_arap(mesh, targets, anchors, weights_anchors, max_iter=10, tol=1e-4):
    """
    mesh: object with vertices p (n, 3), neighbors N(i), edge weights w_ij
    targets: target positions t (n, 3) from motion flow
    anchors: boolean mask or list of anchor indices
    weights_anchors: scalar weights w_ai for each vertex (0 if not anchor)
    """
    n = mesh.num_vertices
    R = [Identity(3) for _ in range(n)] # Initial rotations
    p_curr = mesh.p.copy() # Current deformed positions, initialized to template
    
    for iteration in range(max_iter):
        # 1. Solve Linear System L p_new = b
        L = build_laplacian(mesh, weights_anchors) # Laplacian + diagonal anchor weights
        b = zeros((n, 3))
        
        for i in range(n):
            rhs_term = zeros(3)
            # ARAP RHS contribution
            for j in mesh.N(i):
                diff_p = mesh.p[i] - mesh.p[j]
                diff_R = R[i] - R[j]
                rhs_term += mesh.w_ij[i][j] * 0.5 * diff_R @ diff_p
            
            # Anchor RHS contribution
            if weights_anchors[i] > 0:
                rhs_term += weights_anchors[i] * targets[i]
            
            b[i] = rhs_term
        
        p_new = solve_linear_system(L, b)
        
        # Check convergence
        if norm(p_new - p_curr) < tol:
            break
            
        p_curr = p_new
        
        # 2. Update Rotations
        for i in range(n):
            # Collect vectors from neighbors and self
            # Standard ARAP SVD step [SA07]
            H = zeros((3, 3))
            for j in mesh.N(i):
                v1 = mesh.p[i] - mesh.p[j]
                v2 = p_curr[i] - p_curr[j]
                H += v2 @ v1.T
            # Add self-term if necessary for stability, though standard ARAP uses neighbors
            # SVD to find optimal rotation
            U, S, Vt = svd(H)
            R[i] = Vt.T @ U.T
            # Handle reflection if det(R[i]) < 0
            
    return p_curr, R

def build_laplacian(mesh, weights_anchors):
    n = mesh.num_vertices
    L = sparse_csr_matrix((n, n))
    for i in range(n):
        for j in mesh.N(i):
            w = mesh.w_ij[i][j]
            L[i, j] -= w
            L[i, i] += w
        # Add anchor weight to diagonal
        if weights_anchors[i] > 0:
            L[i, i] += weights_anchors[i]
    return L
```

## Operating characteristics
- **Time Complexity:** Dominated by solving the sparse linear system $L p^0 = b$ and computing SVDs per vertex. Each iteration is $O(n)$ for SVDs (constant size 3x3) and $O(nnz)$ for the linear solve, where $nnz$ is the number of non-zeros in $L$.
- **Memory Complexity:** $O(n)$ for storing vertices, rotations, and weights. $O(nnz)$ for the sparse Laplacian matrix.
- **Strengths:** Resilient to noisy motion flows; preserves local geometric details better than direct application of flow; handles non-rigid deformation via ARAP while anchoring global pose.
- **Limitations:** Requires iterative convergence; sensitive to anchor selection quality; may smooth out fine details if anchors are too sparse or weights too low.
- **When to use:** When deforming a mesh based on sparse or noisy global motion data (e.g., from voxel tracking) and preserving local rigidity is important.
- **When not to use:** When high-frequency non-rigid details (like cloth folds) are the primary focus, as this method is a global deformation step; local optimization is needed subsequently [S1, unofficial].

## Background
Originated in the context of 4D mesh reconstruction from time-varying voxelized geometry [S1, unofficial]. It builds on the As-Rigid-As-Possible (ARAP) deformation method [SA07] by introducing a sparse set of anchors guided by curvature and motion correspondence scores [PGK02, BLNL14]. The method was developed to handle the noise inherent in voxel-based motion tracking, providing a robust global deformation step before local regularization [S1, unofficial].
