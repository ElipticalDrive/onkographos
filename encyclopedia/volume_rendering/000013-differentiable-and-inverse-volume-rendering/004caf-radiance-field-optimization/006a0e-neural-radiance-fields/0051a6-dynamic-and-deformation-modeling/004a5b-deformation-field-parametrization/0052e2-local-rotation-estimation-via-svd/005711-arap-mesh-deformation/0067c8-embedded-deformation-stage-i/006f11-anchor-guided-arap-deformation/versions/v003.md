# Anchor-Guided ARAP Deformation
Also called: Anchor-based ARAP, Global deformation

## Overview
Anchor-Guided ARAP Deformation is a variational mesh deformation method that computes a globally rigid-consistent deformation of a template mesh by minimizing a combination of As-Rigid-As-Possible (ARAP) energy and a sparse anchor fidelity term [S1, unofficial]. It solves the problem of applying noisy or sparse motion flows (e.g., from voxelized geometry tracking) to a mesh without propagating noise across the entire surface [S1, unofficial]. Unlike standard ARAP [SA07] which relies on fixed boundary conditions, this method uses a dynamically selected subset of high-curvature or high-motion vertices as anchors, making it resilient to input noise while preserving local geometric features [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Inputs: Template mesh $M_0$ with vertices $p_i \in \mathbb{R}^3$ and one-ring neighborhoods $N(i)$, target positions $p_i^{\text{target}} \in \mathbb{R}^3$ derived from a noisy motion flow, edge weights $w_{ij}$, and anchor weights $w_{ai}$ [S1, unofficial].
- Outputs: Deformed mesh positions $p'_i \in \mathbb{R}^3$ and local rotation matrices $R_i \in \mathbb{R}^{3 \times 3}$ for each vertex [S1, unofficial].

**Data Structures:**
- Mesh connectivity: Adjacency list storing $N(i)$ for each vertex $i=1 \dots n$ [G].
- Position arrays: `p_template` ($n \times 3$) for original vertices, `p_target` ($n \times 3$) for target positions, `p_curr` ($n \times 3$) for deformed vertices [G].
- Weight arrays: `w_ij` (sparse map or dictionary mapping $(i,j)$ to float), `w_ai` ($n$-vector) [G].
- Rotation array: `R` (list of $3 \times 3$ matrices, size $n$) [G].
- Linear system data: Dense matrix $L$ ($n \times n$), dense vector $b$ ($n \times 3$) [G].

**Numbered Steps:**
1. **Anchor Selection:** For each vertex at time $t_i$, compute a curvature score using [PGK02] and a motion vector score based on correspondence matching [BLNL14]. Normalize and sum these scores. Select the subset with the highest scores as anchors. Set $w_{ai}$ to the normalized score for anchors, and $0$ otherwise [S1, unofficial].
2. **Initialization:** Set initial rotations $R_i$ to identity matrices [S1, unofficial]. Initialize deformed positions $p'_i$ to template positions $p_i$ [G].
3. **Iterate until convergence:**
   a. **Solve Linear System:** Construct $L$ and $b$ based on current $R_i$. Solve $L p' = b$ for new positions $p'$ [S1, unofficial].
   b. **Update Rotations:** For each vertex $i$, compute the optimal rotation $R_i$ using SVD on the positions of $p_i$ and $p'_i$ (and their one-ring neighbors) as derived in [SA07] [S1, unofficial].
4. **Convergence Check:** Stop when $\|p'_{\text{new}} - p'_{\text{old}}\| < \epsilon$ [G].

**Formulas:**
Total energy: $E(M_0) = E_{\text{ARAP}}(M_0) + E_{\text{ANC}}(M_0)$ [S1, unofficial].
ARAP energy: $E_{\text{ARAP}}(M_0) = \frac{1}{2} \sum_{i=1}^{n} \sum_{j \in N(i)} w_{ij} \|(p'_i - p'_j) - R_i(p_i - p_j)\|^2$ [S1, unofficial].
Anchor energy: $E_{\text{ANC}}(M_0) = \frac{1}{2} \sum_{i=1}^{n} w_{ai} \|p'_i - p_i^{\text{target}}\|^2$, where $w_{ai} = 0$ if vertex $i$ is not an anchor [S1, unofficial].
Optimality condition (fixed $R_i$): $\sum_{j \in N(i)} w_{ij}(p'_i - p'_j) + w_{ai}p'_i = \sum_{j \in N(i)} w_{ij} \frac{1}{2} (R_i - R_j)(p_i - p_j) + w_{ai}p_i^{\text{target}}$ [S1, unofficial].
This yields the linear system $L p' = b$, where $L$ is the Laplacian of $M_0$ with $w_{ai}$ added to the diagonal for anchor nodes, and $b$ contains the right-hand side terms [S1, unofficial].

**Parameters:**
- Anchor weights $w_{ai}$: Confidence scores from selection, typically $[0, 1]$ after normalization [S1, unofficial].
- Edge weights $w_{ij}$: Standard cotangent or uniform weights [G].
- Convergence tolerance $\epsilon$: Typically $10^{-4}$ to $10^{-6}$ [G].
- Maximum iterations: Typically 10–20 [G].

**Edge Cases and Pitfalls:**
- Precision: Solving the linear system requires a sparse solver (e.g., conjugate gradient or direct sparse LU) to handle ill-conditioning from low anchor weights [G].
- Boundaries: The method assumes a closed or well-connected mesh; disconnected components require separate anchor sets or global constraints [G].
- Degenerate input: If anchors are too sparse or weights are near zero, the system becomes under-constrained; a minimum anchor count or fallback to standard ARAP is needed [G].
- SVD reflection: The optimal rotation from SVD may yield a reflection ($\det(R_i) = -1$); it must be corrected by flipping the sign of the smallest singular vector [SA07] [G].

**Pseudocode:**
```python
import numpy as np

def anchor_guided_arap(p_template, neighbors, w_ij, p_target, w_ai, max_iter=10, tol=1e-4):
    """
    p_template: (n, 3) array of original vertex positions
    neighbors: list of lists, neighbors[i] contains indices of N(i)
    w_ij: dict mapping (i, j) to float edge weight
    p_target: (n, 3) array of target positions from motion flow
    w_ai: (n,) array of anchor weights (0 if not anchor)
    """
    n = len(p_template)
    p_curr = p_template.copy()
    R = [np.eye(3) for _ in range(n)]  # Initial rotations [G]
    
    for _ in range(max_iter):
        L = np.zeros((n, n))
        b = np.zeros((n, 3))
        
        for i in range(n):
            rhs = np.zeros(3)
            for j in neighbors[i]:
                w = w_ij.get((i, j), 0.0)
                L[i, i] += w
                L[i, j] -= w
                diff_p = p_template[i] - p_template[j]
                diff_R = R[i] - R[j]
                rhs += w * 0.5 * (diff_R @ diff_p)
            L[i, i] += w_ai[i]
            rhs += w_ai[i] * p_target[i]
            b[i] = rhs
            
        p_new = np.linalg.solve(L, b)  # Standard dense solver [G]
        
        if np.linalg.norm(p_new - p_curr) < tol:
            break
        p_curr = p_new
        
        # Update rotations via SVD [SA07]
        for i in range(n):
            H = np.zeros((3, 3))
            for j in neighbors[i]:
                v1 = p_template[i] - p_template[j]
                v2 = p_curr[i] - p_curr[j]
                H += np.outer(v2, v1)
            U, S, Vt = np.linalg.svd(H)
            R[i] = Vt.T @ U.T
            if np.linalg.det(R[i]) < 0:
                Vt[-1, :] *= -1
                R[i] = Vt.T @ U.T
                
    return p_curr, R
```

## Operating characteristics
- **Time Complexity:** Dominated by solving the sparse linear system $L p' = b$ and computing SVDs per vertex. Each iteration is $O(n)$ for SVDs (constant size $3 \times 3$) and $O(nnz)$ for the linear solve, where $nnz$ is the number of non-zeros in $L$ [G].
- **Memory Complexity:** $O(n)$ for storing vertices, rotations, and weights. $O(nnz)$ for the sparse Laplacian matrix [G].
- **Strengths:** Resilient to noisy motion flows; preserves local geometric details better than direct application of flow; handles non-rigid deformation via ARAP while anchoring global pose [S1, unofficial].
- **Limitations:** Requires iterative convergence; sensitive to anchor selection quality; may smooth out fine details if anchors are too sparse or weights too low [G].
- **When to use:** When deforming a mesh based on sparse or noisy global motion data (e.g., from voxel tracking) and preserving local rigidity is important [S1, unofficial].
- **When not to use:** When high-frequency non-rigid details (like cloth folds) are the primary focus, as this method is a global deformation step; local optimization is needed subsequently [S1, unofficial].

## Background
The method was introduced in the context of 4D mesh reconstruction from time-varying voxelized geometry [S1, unofficial]. It builds on the As-Rigid-As-Possible (ARAP) deformation method [SA07] by introducing a sparse set of anchors guided by curvature and motion correspondence scores [PGK02, BLNL14] [S1, unofficial]. The method was developed to handle the noise inherent in voxel-based motion tracking, providing a robust global deformation step before local regularization [S1, unofficial].
