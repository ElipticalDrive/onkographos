# Deformation Field Parametrization

Also called: Dynamic Deformation Modeling, Canonical Space Mapping

## Overview
Deformation Field Parametrization methods enable the representation of non-rigid, time-varying scenes within Neural Radiance Fields (NeRFs) by mapping dynamic coordinates to a static canonical space [13340-dynamic-scene-representation.md][13428-deformable-neural-radiance-fields-nerfies.md]. This family solves the problem of animating static neural representations without relying on rigid body assumptions, allowing for the reconstruction of dynamic geometry from multi-view video or sparse projections [12724-neural-deformation-field.md]. Unlike static NeRFs, these methods explicitly model the temporal evolution of geometry, setting them apart from siblings like [JointRF Representation](13660-jointrf-representation.md) which may use joint factorization rather than explicit deformation fields, and [D-TensoRF](13781-d-tensorf.md) which uses tensor decomposition for temporal compression [13781-d-tensorf.md].

## Shared principles
All methods in this family rely on the differentiability of the forward rendering operator and the propagation of gradients through the integration steps [44-radiance-field-optimization.md]. The core mechanism is the evaluation of the volume rendering equation and the computation of gradients with respect to scene parameters (density, geometry, transfer functions, camera poses) [44-radiance-field-optimization.md].

The standard emission-absorption model computes the color $\hat{C}(\mathbf{r})$ for a ray $\mathbf{r}$ as [44-radiance-field-optimization.md]:

$$
\hat{C}(\mathbf{r}) = \sum_{i=1}^N T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i
$$

where $\sigma_i$ is the density, $\delta_i$ is the step size, $\mathbf{c}_i$ is the color, and $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$ is the transmittance [44-radiance-field-optimization.md].

Differentiation strategies fall into three main categories [44-radiance-field-optimization.md]:
1. **Reverse-Mode Automatic Differentiation (AD):** Standard backpropagation through the computational graph. This requires storing $O(kn)$ intermediate states (where $n$ is pixels and $k$ is samples), leading to high memory usage [44-radiance-field-optimization.md].
2. **Adjoint Method:** Computes gradients by propagating adjoint variables backward through the rendering algorithm, evaluating the chain rule from output to input. This has computational complexity largely constant in the number of parameters, making it preferable for optimizing many parameters like the transfer function [44-radiance-field-optimization.md].
3. **Analytic Inversion / Explicit Gradients:** Uses a-priori knowledge of the DVR operations to invert the order of operations or derive closed-form gradients, reducing memory consumption to $O(n)$ by avoiding the storage of intermediate results [44-radiance-field-optimization.md].

## Subtopics

### [Spline-based Deformation Field](11457-spline-based-deformation-field.md)
This method parametrizes the deformation field using cubic B-splines with time-modulated weights to map spatial coordinates $(x, y, z)$ at time $t$ to canonical coordinates $(x_0, y_0, z_0)$ [11457-spline-based-deformation-field.md]. It enables the reconstruction of dynamic scenes from sparse projection data by combining a pre-trained canonical volume with the learned deformation field [11457-spline-based-deformation-field.md]. Unlike Neural Deformation Fields which rely on MLPs and complex regularization, this approach allows reconstruction from as few as two projections due to the efficient encoding provided by B-splines [11457-spline-based-deformation-field.md]. Choose this method when data is extremely sparse (e.g., few-view CT) and a high-quality static canonical volume is available [11457-spline-based-deformation-field.md].

### [Deformation-Guided Neural Fields](12044-deformation-guided-neural-fields.md)
Deformation-Guided Neural Fields (DGNF) creates fully 3D face portraits with controllable pose and expression by using deformation field MLPs guided by a parametric morphable model (3DMM) [12044-deformation-guided-neural-fields.md]. It addresses the limitation of standard NeRF approaches which struggle with moving bodies and dynamic geometry [12044-deformation-guided-neural-fields.md]. It sets itself apart from siblings like [Neural Deformation Field](12724-neural-deformation-field.md) by explicitly leveraging a parametric morphable model (3DMM) to drive the deformation, rather than learning a generic or skeleton-based deformation field [12044-deformation-guided-neural-fields.md]. Choose this method for face reenactment or animation where strong priors on facial geometry are beneficial [12044-deformation-guided-neural-fields.md].

### [Neural Deformation Field](12724-neural-deformation-field.md)
The Neural Deformation Field (NDF) models non-rigid, time-varying deformations by predicting per-point displacements in a canonical space, mapping points from a target deformed space to canonical space using inverse Linear Blend Skinning (LBS) and a neural displacement field [12724-neural-deformation-field.md]. It solves the problem of animating static neural representations without relying on rigid body assumptions or human-specific priors like SMPL [12724-neural-deformation-field.md]. Unlike cage-based or linear blend skinning methods, NDF generalizes to arbitrary objects and enables fine-level complex deformation through user-defined or algorithmically extracted key points [12724-neural-deformation-field.md]. It sets itself apart from sibling methods like Deformation-Guided Neural Fields by explicitly decoupling the rigid skeletal transformation (LBS) from the residual non-rigid displacement predicted by a neural network [12724-neural-deformation-field.md]. Choose this method for general non-rigid object animation where skeletal structure is known or can be approximated [12724-neural-deformation-field.md].

### [Local Rotation Estimation via SVD](14864-local-rotation-estimation-via-svd.md)
Local Rotation Estimation via SVD is a technique used in dynamic neural radiance fields to correct view-dependent rendering artifacts caused by large rigid-body rotations during deformation [14864-local-rotation-estimation-via-svd.md]. It estimates the local rotation for each point in a deformed point cloud using Singular Value Decomposition (SVD), inspired by As-Rigid-As-Possible (ARAP) mesh deformation [14864-local-rotation-estimation-via-svd.md]. This estimated rotation is then interpolated to query view directions to "bend" rays, ensuring consistency between the deformed space and the canonical space representation [14864-local-rotation-estimation-via-svd.md]. It differs from sibling methods like [Neural Deformation Field](12724-neural-deformation-field.md) by explicitly modeling rotational components of the deformation field rather than relying solely on translation or dense deformation vectors, thereby handling complex fine-level deformations without introducing extra complexity into the radiance field model itself [14864-local-rotation-estimation-via-svd.md]. Choose this method when large rigid rotations cause significant artifacts in standard deformation fields [14864-local-rotation-estimation-via-svd.md].

## Background
The concept of mapping dynamic scenes to a canonical space originated with the need to extend static NeRFs to dynamic content. Early works like [Dynamic Scene Representation](13340-dynamic-scene-representation.md) and [Deformable Neural Radiance Fields (Nerfies)](13428-deformable-neural-radiance-fields-nerfies.md) established the feasibility of learning deformation fields [13340-dynamic-scene-representation.md][13428-deformable-neural-radiance-fields-nerfies.md]. Subsequent developments introduced more specialized parametrizations, such as spline-based fields for sparse data [11457-spline-based-deformation-field.md], 3DMM-guided fields for faces [12044-deformation-guided-neural-fields.md], and LBS-based fields for general objects [12724-neural-deformation-field.md]. The inclusion of local rotation estimation via SVD addresses specific artifacts arising from pure translation-based deformation fields [14864-local-rotation-estimation-via-svd.md]. These methods are primarily used in computer graphics for dynamic scene reconstruction, novel view synthesis, and character animation.
