# Deformation-Guided Neural Fields

Also called: Deformation Field NeRF, Morphable Model Guided NeRF, RigNeRF

## Overview
Deformation-Guided Neural Fields construct a fully 3D face portrait with controllable pose and expression using deformation field MLPs guided by a morphable 3D face model [S1]. It sets itself apart from sibling methods by explicitly guiding the deformation field with a parametric 3D morphable model (3DMM) rather than relying on unconstrained neural predictions [S1].

## How it works
**Inputs:**
*   Training images with known camera poses and 3DMM parameters [S1].
*   A pre-trained 3D Morphable Model (3DMM) [S1].

**Outputs:**
*   A trained neural field capable of rendering novel views of the face with arbitrary pose and expression [S1].

**Data Structures:**
*   Deformation field MLP guided by a morphable 3D face model [S1].
*   Appearance field MLP for density and color prediction [G].
*   [G] Exact layouts, fields, sizes, and bit packing are not given in the sources.

**Steps:**
1.  **Canonical Space Definition:** Define the canonical space as the neutral expression state of the subject, using the 3DMM mean shape [S1].
2.  **Deformation Field Evaluation:** For a query point $\mathbf{x}_{\text{canon}}$ in canonical space, compute the deformation $\Delta \mathbf{x}$ using the deformation field MLP, taking canonical coordinates and expression/pose parameters $\theta$ derived from the 3DMM fit as input [S1].
3.  **Coordinate Transformation:** Map the canonical coordinate to the deformed space $\mathbf{x}_{\text{def}}$ by adding the computed deformation [G].
4.  **Appearance Query:** Query the appearance field with the deformed coordinate $\mathbf{x}_{\text{def}}$ and viewing direction $\mathbf{d}$ to obtain density $\sigma$ and color $\mathbf{c}$ [G].
5.  **Volume Rendering:** Render the image using the standard emission-absorption model (see [44-radiance-field-optimization.md](44-radiance-field-optimization.md)) with the sampled $(\sigma, \mathbf{c})$ values along rays [G].
6.  **Optimization:** Minimize the photometric loss between rendered and ground-truth images [G].

**Formulas:**
*   Deformation: $\Delta \mathbf{x} = \mathcal{M}_{\text{def}}(\mathbf{x}_{\text{canon}}, \theta)$, where $\mathcal{M}_{\text{def}}$ is the deformation MLP, $\mathbf{x}_{\text{canon}}$ are canonical coordinates, and $\theta$ are 3DMM coefficients [S1].
*   Transformed coordinate: $\mathbf{x}_{\text{def}} = \mathbf{x}_{\text{canon}} + \Delta \mathbf{x}$ [G].
*   Appearance query: $(\sigma, \mathbf{c}) = \mathcal{M}_{\text{app}}(\mathbf{x}_{\text{def}}, \mathbf{d})$, where $\mathcal{M}_{\text{app}}$ is the appearance MLP, $\sigma$ is density, $\mathbf{c}$ is color, and $\mathbf{d}$ is the viewing direction [G].

**Parameters:**
*   3DMM coefficients (pose, expression): [G] Not given in the sources.
*   MLP hidden layers: [G] Not given in the sources.
*   Typical values: [G] Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Fitting Errors:** If the 3DMM fit to the input images is inaccurate, the canonical space definition may be misaligned, leading to artifacts [G]. A common mitigation is to include a mask supervision loss to ensure the rendered alpha channel aligns with the subject's silhouette [G].
*   **Degenerate Input:** Extreme expressions outside the 3DMM basis may cause extrapolation errors in the deformation field [G].

## Subtopics

### [Canonical Face Space Transformation](13405-canonical-face-space-transformation.md)
Canonical Face Space Transformation normalizes world coordinates to a canonical face space using a rigid transform to address face shape variations between training data and real-world inputs, making the NeRF robust to geometry and pose variations. It sets itself apart from methods that rely on detailed mesh priors or non-rigid deformation fields by using only a rigid alignment derived from a mean geometry, avoiding the need for mesh details during view synthesis. Choose it when rigid alignment is sufficient to handle pose variations without complex non-rigid warping.

### Mesh-anchored Hash Table Blendshapes
Mesh-anchored Hash Table Blendshapes is a 3D neural avatar system achieving real-time rendering with high fidelity and fine-grained control through mesh-anchored hash table blendshapes [S1]. It sets itself apart from standard global deformation fields by linking each vertex of a 3DMM mesh to a local hash table for expression-dependent embeddings and localized facial deformations [S1]. Choose it when real-time rendering and localized control are prioritized over global deformation fields [S1].

### HiDe-NeRF
HiDe-NeRF is a neural radiation field technique for detailed, unobstructed dynamic head synthesis [S2]. It sets itself apart from other deformation methods by using a multi-scale generalized appearance module (MGA) and a streamlined expression-aware deformation module (LED) to enhance expression precision while preserving identity data [S2]. Choose it when high-fidelity dynamic head synthesis with strong identity preservation is required [S2].

## Background
Deformation-Guided Neural Fields emerged as a solution to the limitations of standard NeRFs in handling moving subjects [S1]. While standard NeRFs struggle with moving bodies, mesh deformation approaches like Neural Body demonstrated the ability to interpolate between frames and poses [S1]. RigNeRF, introduced in June 2022, innovated on this topic by using deformation field MLPs guided by a morphable 3D face model, creating a fully 3D face portrait with controllable pose and expression [S1]. This approach built upon the popular paradigm of animating articulated bodies using a baseline skeleton equipped with an MLP-based deformation field, a paradigm established by works such as A-NeRF (Feb 2021) and Animatable NeRF (May 2021) [S1].
