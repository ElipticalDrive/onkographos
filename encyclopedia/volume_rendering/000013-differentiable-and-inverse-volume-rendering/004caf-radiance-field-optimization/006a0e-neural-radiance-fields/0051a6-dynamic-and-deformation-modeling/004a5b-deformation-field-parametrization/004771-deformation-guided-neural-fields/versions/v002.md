# Deformation-Guided Neural Fields

Also called: Deformation Field NeRF, Morphable Model Guided NeRF, RigNeRF

## Overview
Deformation-Guided Neural Fields use a deformation field MLP guided by a morphable 3D face model to create a fully 3D face portrait with controllable pose and expression [S1]. It sets itself apart from standard NeRF approaches that struggle with moving bodies by leveraging a mesh deformation approach, allowing for interpolation between frames and poses, similar to the paradigm established by Neural Body [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D query point $\mathbf{x}_t$ at time $t$ (or pose/expression parameters), driving signals (pose, expression coefficients) derived from a 3D Morphable Model (3DMM).
*   **Outputs:** Density $\sigma$ and color $\mathbf{c}$ for the query point, used to render pixel color $\hat{C}(\mathbf{r})$.

**Data Structures:**
*   **Deformation MLP:** A neural network that takes $\mathbf{x}_t$ and driving signals $\theta_t$ as input and outputs a displacement vector $\Delta$.
*   **Static Radiance Field $F_{\text{static}}$:** A neural network (MLP) that takes the canonical coordinate $\mathbf{x}_c$ and outputs density $\sigma$ and color $\mathbf{c}$.

**Steps:**
1.  **Deformation Prediction:** Compute the displacement $\Delta$ using the deformation function $f_{\Delta}$ driven by the 3DMM parameters:
    $$
    \Delta = f_{\Delta}(\mathbf{x}_t, \theta_t)
    $$
    where $\theta_t$ represents the driving signals such as pose and expression coefficients [S1].
2.  **Canonical Coordinate Mapping:** Transform the query point $\mathbf{x}_t$ to the canonical space $\mathbf{x}_c$:
    $$
    \mathbf{x}_c = \mathbf{x}_t + \Delta
    $$
    [S1]
3.  **Radiance Field Query:** Query the static radiance field to obtain density and color:
    $$
    (\sigma, \mathbf{c}) = F_{\text{static}}(\mathbf{x}_c)
    $$
    [S1]
4.  **Volume Rendering:** Compute the final pixel color using the standard emission-absorption model:
    $$
    \hat{C}(\mathbf{r}) = \sum_{i=1}^N T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i
    $$
    where $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$ [44-radiance-field-optimization.md].

## Subtopics

### [Canonical Face Space Transformation](13405-canonical-face-space-transformation.md)
Canonical Face Space Transformation normalizes world coordinates to a canonical face space using a rigid transform to address face shape variations between training data and real-world inputs, making the NeRF robust to geometry and pose variations. It sets itself apart from methods that rely on detailed mesh priors or non-rigid deformation fields by using only a rigid alignment derived from a mean geometry, avoiding the need for mesh details during view synthesis. [13405-canonical-face-space-transformation.md]

### Mesh-anchored Hash Table Blendshapes
A 3D neural avatar system achieving real-time rendering with high fidelity and fine-grained control through mesh-anchored hash table blendshapes [S1]. Each vertex of a 3DMM mesh is linked to a local hash table, allowing for expression-dependent embeddings and localized facial deformations [S1]. Local blendshapes are combined using per-vertex weights predicted in UV space from driving signals [S1]. Uses a hash encoding with decoding MLP in a hybrid neural implicit field to predict color and density from 3D queries using volume rendering [S1].

## Background
RigNeRF was introduced in June 2022 [S1]. It innovated on the topic of animating articulated bodies, building on the paradigm established by Neural Body, which used a baseline skeleton equipped with an MLP-based deformation field [S1]. This approach inspired a large number of works such as A-NeRF (Feb 2021) and Animatable NeRF (May 2021) [S1].
