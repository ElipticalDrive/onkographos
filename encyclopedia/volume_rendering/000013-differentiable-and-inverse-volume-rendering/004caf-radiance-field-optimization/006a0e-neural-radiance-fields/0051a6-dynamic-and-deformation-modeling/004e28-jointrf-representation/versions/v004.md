# JointRF Representation
Also called: JointRF

## Overview
JointRF is a compact residual feature grid representation for dynamic Neural Radiance Fields (NeRFs) that handles large motions and long sequences by decomposing the radiance field into a long-reference basis feature grid and a coefficient feature grid [S1]. Unlike canonical space methods that warp features back to a static canonical space—making them fragile to large motions and topological changes—JointRF uses residual grids to capture temporal variations, thereby diminishing temporal redundancy and improving compression efficiency [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A sequence of dynamic radiance fields over time, represented as a set of frames [S1].
*   **Output:** A compressed representation consisting of a keyframe basis grid, a keyframe coefficient grid, and a sequence of residual grids and coefficient grids for subsequent frames [S1].

**Data Structures:**
The representation is organized into Groups of Feature grids (GOF) [S1]. Each GOF $G = \{f_t\}_{t=1}^N$ contains:
1.  **Keyframe ($t=1$):**
    *   $B_1$: Long-reference basis feature grid. Captures signal commonality across the sequence [S1].
    *   $C_1$: Coefficient feature grid. Depicts spatial variations for the keyframe [S1].
2.  **Subsequent Frames ($1 < t \le N$):**
    *   $R_t$: Compact residual feature grid. Represents the compensation for errors and newly observed regions between the keyframe's basis grid and the current frame's basis grid [S1].
    *   $C_t$: Coefficient feature grid for frame $t$ [S1].
*   **Grid Resolution:** Not given in the sources. [S1]
*   **Bit Packing:** Not given in the sources. [S1]

**Numbered Steps:**
1.  Divide the long sequence of dynamic radiance fields into multiple continuous Groups of Feature grids (GOF) [S1].
2.  For the first frame (keyframe) of each GOF, initialize a long-reference basis feature grid $B_1$ and a coefficient feature grid $C_1$ [S1].
3.  For each subsequent frame $t$ ($1 < t \le N$) in the GOF:
    a. Learn a compact residual feature grid $R_t$ [S1].
    b. Learn a coefficient feature grid $C_t$ [S1].
    c. Compute the current frame's basis grid: $B_t = B_1 + R_t$ [S1].
4.  To render a ray $\mathbf{r}$ at frame $t$:
    a. Sample points along the ray [G].
    b. For each sample point $x_i$, retrieve features from $B_t$ and $C_t$ using interpolation: $f_{B} = \text{interp}(x_i, B_t)$ and $f_{C} = \text{interp}(x_i, C_t)$ [S1].
    c. Compute the combined feature vector: $f_i = f_{C} \circ f_{B}$ [S1].
    d. Pass $f_i$ and the viewing direction $d_i$ through the MLP $\Phi$ to obtain density $\sigma_i$ and color $c_i$ [S1].
5.  Compute the final color $\hat{c}(\mathbf{r})$ using the standard volume rendering equation [S1]:
    $$
    \hat{c}(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) c_i
    $$
    where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$, $\delta_i$ is the distance between adjacent samples, $c_i$ is color, and $\sigma_i$ is density [S1].

**Formulas:**
The radiance field for any frame is reconstructed using a tiny Multi-Layer Perceptron (MLP) $\Phi$ [S1]:
$$
(c, \sigma) = \Phi(\text{interp}(x, C) \circ \text{interp}(x, B), d)
$$
where:
*   $x$ is the 3D spatial coordinate [S1].
*   $d$ is the viewing direction [S1].
*   $\text{interp}(\cdot)$ is the interpolation function on the grids (e.g., trilinear interpolation) [S1].
*   $\circ$ denotes the Hadamard (element-wise) product [S1].
*   $c$ is the color and $\sigma$ is the density [S1].

For $t > 1$, the basis grid $B_t$ is calculated as:
$$
B_t = B_1 + R_t
$$
The coefficient grid $C_t$ is learned directly for frame $t$, but the sources note that learning residuals for $C_t$ holds no physical significance; only the basis grid residuals are modeled [S1].

**Parameters:**
*   **GOF Size:** Not given in the sources. [S1]
*   **Grid Resolution:** Not given in the sources. [S1]
*   **MLP Architecture:** Described as a "tiny MLP" [S1]. Specific layer sizes are not given in the sources. [S1]

**Edge Cases and Pitfalls:**
*   **Large Motions:** Canonical space warping methods fail under large motions; JointRF handles them by using residual grids [S1].
*   **Coefficient Residuals:** Learning residuals for the coefficient grid $C_t$ is physically insignificant and should not be done; only basis grid residuals $R_t$ are modeled [S1].
*   **Temporal Redundancy:** The method is designed to minimize redundancy by leveraging the commonality in the basis grid [S1].

**Pseudocode:**
```python
import math

def jointrf_render(ray_origin, ray_direction, time_index, gof_data):
    """
    Renders a single ray for a specific time index using JointRF representation.
    
    Args:
        ray_origin: list of 3 floats, origin of the ray.
        ray_direction: list of 3 floats, direction of the ray.
        time_index: int, index of the frame within the GOF (0-based).
        gof_data: dict containing:
            - 'B1': 3D list, long-reference basis feature grid for the keyframe.
            - 'C1': 3D list, coefficient feature grid for the keyframe.
            - 'R': List of 3D lists, residual grids for frames 1 to N-1.
            - 'C': List of 3D lists, coefficient grids for frames 1 to N-1.
            - 'mlp': Function, the tiny MLP Phi.
            - 'interp': Function, standard trilinear interpolation on grids.
            
    Returns:
        color: list of 3 floats, rendered color.
    """
    t_near, t_far, num_samples = 0.0, 10.0, 128
    dt = (t_far - t_near) / num_samples
    t_vals = [t_near + i * dt for i in range(num_samples)]
    points = [[ray_origin[j] + t * ray_direction[j] for j in range(3)] for t in t_vals]

    B1 = gof_data['B1']
    C1 = gof_data['C1']
    R_list = gof_data['R']
    C_list = gof_data['C']

    if time_index == 0:
        B_t, C_t = B1, C1
    else:
        R_t = R_list[time_index - 1]
        B_t = [[b + r for b, r in zip(b_row, r_row)] for b_row, r_row in zip(B1, R_t)]
        C_t = C_list[time_index - 1]

    f_B = gof_data['interp'](B_t, points)
    f_C = gof_data['interp'](C_t, points)
    f_combined = [c * b for c, b in zip(f_C, f_B)]
    dirs = [ray_direction] * num_samples

    outputs = gof_data['mlp'](f_combined, dirs)
    sigma = [o[0] for o in outputs]
    colors = [o[1:4] for o in outputs]

    alphas = [1.0 - math.exp(-s * dt) for s in sigma]
    T = [1.0] * num_samples
    for i in range(1, num_samples):
        T[i] = math.exp(-sum(sigma[:i]) * dt)

    rendered_color = [0.0, 0.0, 0.0]
    for i in range(num_samples):
        for c in range(3):
            rendered_color[c] += T[i] * alphas[i] * colors[i][c]
    return rendered_color
```

## Operating characteristics
*   **Time Complexity:** Rendering complexity is similar to standard NeRF, $O(N \cdot S)$ where $N$ is the number of rays and $S$ is the number of samples per ray, plus the cost of grid interpolation [G]. The representation allows simultaneous rendering of multiple non-keyframes because it relies on only one keyframe during rendering, facilitating parallel computation [S1].
*   **Memory Complexity:** The representation is compact [S1]. It stores one long-reference basis grid $B_1$ and one coefficient grid $C_1$ for the keyframe, plus residual grids $R_t$ and coefficient grids $C_t$ for subsequent frames [S1]. The residual grids are compact, reducing memory usage compared to storing full feature grids for every frame [S1].
*   **Strengths:** Handles large motions without compromising quality; diminishes temporal redundancy; supports streamable dynamic and long-sequence radiance fields; enables efficient sequential feature modeling [S1].
*   **Limitations:** Learning residuals for the coefficient grid $C_t$ is physically insignificant and should be avoided [S1]. The method requires a sequential feature compression subnetwork for optimal compression, which adds complexity to the training pipeline [S1].
*   **When to use:** When representing dynamic scenes with large motions and long durations where canonical space warping methods fail [S1].

## Background
JointRF was proposed by researchers affiliated with Shanghai Jiao Tong University, supported by the National Natural Science Foundation of China and STCSM [S1]. It addresses the challenges of storing and transmitting volumetric video using NeRF, particularly for sequences involving arbitrary motions and long durations [S1]. The method builds on the idea of residual radiance field techniques, similar to ReRF, but introduces a joint optimization scheme for representation and compression [S1]. It decomposes the static scene radiance field into coefficient and basis feature grids via basis expansion, extending this to dynamic scenes by using residual grids for temporal variations [S1].
