# Deformable Neural Radiance Fields (Nerfies)

Also called: Deformable NeRF, Nerfies

## Overview
Deformable Neural Radiance Fields (Nerfies) reconstructs non-rigidly deforming scenes by decomposing the scene into a static canonical template volume (a standard NeRF) and a per-observation continuous deformation field that maps observation-space coordinates to canonical-space coordinates [S1]. Unlike methods that condition deformation on time or define it on discrete meshes/voxels, Nerfies conditions the deformation on a learned per-frame latent code and models the deformation as a continuous function using an MLP [S1]. It distinguishes itself from siblings by introducing elastic regularization to resolve ambiguities between motion and scaling, and a coarse-to-fine optimization strategy to avoid local minima [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $n$ images $\{I_i\}_{i=1}^n$ of a non-rigidly deforming scene, along with their camera poses.
*   **Outputs:** A canonical NeRF $F$ (representing the template) and a deformation field $T$ (parameterized by an MLP), along with per-frame latent codes $\omega_i$ (deformation) and $\psi_i$ (appearance). The system renders novel views of the deforming subject.

**Data Structures:**
1.  **Canonical NeRF $F$:** An MLP mapping $(x', d, \psi_i) \to (\sigma, c)$, where $x'$ is a canonical 3D coordinate, $d$ is a viewing direction, $\sigma$ is density, and $c$ is color.
2.  **Deformation MLP $W$:** An MLP mapping $(x, \omega_i) \to (r, v) \in \mathbb{R}^6$, where $x$ is an observation-space 3D coordinate and $\omega_i$ is the deformation latent code. The output $(r, v)$ parameterizes an SE(3) transformation.
3.  **Latent Codes:**
    *   $\omega_i \in \mathbb{R}^8$: Per-frame learned latent deformation code encoding the scene state.
    *   $\psi_i \in \mathbb{R}^8$: Per-frame learned latent appearance code modulating color output to handle exposure/white balance variations.
4.  **Positional Encoding:** Input coordinates $x$ are encoded using $\gamma_\alpha(x)$, which applies frequency-dependent weights $w_k(\alpha)$ to sinusoidal basis functions.

**Parameters:**
*   **Network Architecture:** Deformation network depth 6, hidden size 128, skip connection at the 4th layer. [S1]
*   **Samples:** 256 coarse and 256 fine ray samples per ray for full HD (1920x1080). [S1]
*   **Annealing:** 6 frequency bands; $\alpha$ annealed from 0 to 6 over 80K iterations. [S1]
*   **Loss Weights:** $\lambda = \mu = 10^{-3}$ for elastic and background regularization. [S1]
*   **Robust Loss Hyperparameter:** $c = 0.03$ for the Geman-McClure function. [S1]

**Step-by-Step Method:**

1.  **Initialization:**
    *   Initialize the weights of the last layer of the deformation MLP $W$ from a uniform distribution $U(-10^{-5}, 10^{-5})$. This ensures the deformation starts near the identity, as the exponential map $e^S$ is the identity when $S=0$ [S1].
    *   Initialize latent codes $\omega_i$ and $\psi_i$ via embedding layers.

2.  **Ray Casting and Sampling:**
    *   For a target view, cast rays $\mathbf{r}$ through the camera.
    *   Sample $N$ points $x_i$ along each ray in the observation space.

3.  **Deformation (Observation to Canonical):**
    *   For each sample point $x_i$ and frame $i$, retrieve the deformation latent code $\omega_i$.
    *   Encode $x_i$ using the positional encoding $\gamma_\alpha(x_i)$, where $\alpha$ is the current annealing parameter.
    *   Pass $(\gamma_\alpha(x_i), \omega_i)$ through the deformation MLP $W$ to obtain $(r, v) \in \mathbb{R}^6$.
    *   Compute the SE(3) transformation $e^S$ from the screw axis $S = (r; v)$:
        *   Compute rotation angle $\theta = \|r\|$ and axis $\hat{r} = r/\|r\|$.
        *   Compute rotation matrix $e^r$ using Rodrigues' formula:
            $$ e^r = I + \frac{\sin \theta}{\theta}[r]_\times + \frac{1 - \cos \theta}{\theta^2}[r]_\times^2 $$
            where $[r]_\times$ is the cross-product matrix of $r$.
        *   Compute translation $p$ using the matrix $G$:
            $$ G = I + \frac{1 - \cos \theta}{\theta^2}[r]_\times + \frac{\theta - \sin \theta}{\theta^3}[r]_\times^2 $$
            $$ p = Gv $$
        *   Transform the point to canonical space: $x'_i = e^r x_i + p$.

4.  **Radiance Field Evaluation:**
    *   Query the canonical NeRF $F$ with the transformed point $x'_i$, viewing direction $d$, and appearance code $\psi_i$ to obtain density $\sigma_i$ and color $c_i$.

5.  **Volume Rendering:**
    *   Compute the rendered color $\hat{C}(\mathbf{r})$ using the standard emission-absorption model:
        $$ \hat{C}(\mathbf{r}) = \sum_{i=1}^N T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i $$
        where $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$ is the transmittance and $\delta_i$ is the step size.

6.  **Loss Computation and Regularization:**
    *   **Photometric Loss:** Compute MSE between $\hat{C}(\mathbf{r})$ and the ground truth image color.
    *   **Elastic Regularization:** Compute the Jacobian $J_T(x)$ of the deformation field with respect to $x$ using automatic differentiation. Compute the singular values $\Sigma$ of $J_T(x)$. Apply the robust elastic loss:
        $$ L_{\text{elastic-r}}(x) = \rho(\|\log \Sigma\|_F, c) $$
        where $\rho(x, c) = \frac{2(x/c)^2}{(x/c)^2 + 4}$ is the Geman-McClure robust error function with $c=0.03$.
        *   Weight this loss by the sample's contribution to the rendered view $w_i$ to allow free deformation in empty space.
    *   **Background Regularization (Optional):** If static 3D points $\{x_k\}_{k=1}^K$ are known, penalize their movement:
        $$ L_{\text{bg}} = \frac{1}{K} \sum_{k=1}^K \|T(x_k) - x_k\|^2 $$
    *   **Total Loss:** $L_{\text{total}} = L_{\text{rgb}} + \lambda L_{\text{elastic-r}} + \mu L_{\text{bg}}$.

7.  **Optimization:**
    *   Optimize the parameters of $F$, $W$, $\omega_i$, and $\psi_i$ using Adam.
    *   Anneal the positional encoding bandwidth parameter $\alpha(t)$ linearly: $\alpha(t) = m \cdot \frac{t}{N}$, where $t$ is the current iteration, $N$ is the total iterations for $\alpha$ to reach $m$, and $m$ is the max number of frequency bands (e.g., 6). This implements coarse-to-fine optimization.

**Pseudocode:**

```python
import torch
import torch.nn as nn
import numpy as np

def rodrigues(r):
    """
    Computes rotation matrix from rotation vector r using Rodrigues' formula.
    r: (3,) tensor
    Returns: (3, 3) tensor
    """
    theta = torch.norm(r, dim=-1, keepdim=True)
    r_hat = r / (theta + 1e-8)
    sin_theta = torch.sin(theta)
    cos_theta = torch.cos(theta)
    
    # Cross-product matrix [r]_x
    # For a vector r = [x, y, z], [r]_x = [[0, -z, y], [z, 0, -x], [-y, x, 0]]
    r_hat_x = torch.zeros_like(r_hat).repeat(1, 3, 3) # Placeholder for batched implementation details
    # Simplified for single vector r:
    x, y, z = r_hat[:, 0], r_hat[:, 1], r_hat[:, 2]
    R_x = torch.stack([torch.zeros_like(x), -z, y,
                       z, torch.zeros_like(x), -x,
                       -y, x, torch.zeros_like(x)], dim=1).view(-1, 3, 3)
    
    I = torch.eye(3).to(r.device)
    R = I + sin_theta * R_x + (1 - cos_theta) * torch.bmm(R_x, R_x)
    return R

def compute_se3_transform(r, v):
    """
    Computes SE(3) transform from screw axis parameters r (rotation vector) and v (translation vector).
    r: (3,) tensor
    v: (3,) tensor
    Returns: (3, 3) rotation matrix R, (3,) translation vector p
    """
    theta = torch.norm(r)
    r_hat = r / (theta + 1e-8)
    sin_theta = torch.sin(theta)
    cos_theta = torch.cos(theta)
    
    # Rotation matrix
    R = rodrigues(r)
    
    # Translation matrix G
    # G = I + ((1 - cos(theta)) / theta^2) * [r]_x + ((theta - sin(theta)) / theta^3) * [r]_x^2
    # Using r_hat for stability
    r_hat_x = torch.zeros(3, 3)
    x, y, z = r_hat
    r_hat_x[0, 1] = -z; r_hat_x[0, 2] = y
    r_hat_x[1, 0] = z; r_hat_x[1, 2] = -x
    r_hat_x[2, 0] = -y; r_hat_x[2, 1] = x
    
    term1 = ((1 - cos_theta) / (theta**2 + 1e-8)) * r_hat_x
    term2 = ((theta - sin_theta) / (theta**3 + 1e-8)) * torch.mm(r_hat_x, r_hat_x)
    G = torch.eye(3) + term1 + term2
    
    p = torch.mm(G, v.unsqueeze(1)).squeeze(1)
    return R, p

def nerfies_forward(x_obs, omega, psi, canonical_nerf, deformation_mlp, pos_encoder, alpha):
    """
    Forward pass for a single point in observation space.
    """
    # 1. Deformation
    # Encode input
    x_encoded = pos_encoder(x_obs, alpha) # Returns weighted positional encoding
    # Get screw axis parameters
    r_v = deformation_mlp(torch.cat([x_encoded, omega], dim=-1))
    r = r_v[:, :3]
    v = r_v[:, 3:]
    
    # Compute SE(3) transform
    R, p = compute_se3_transform(r, v)
    
    # Transform point to canonical space
    # x_obs is (N, 3), R is (N, 3, 3), p is (N, 3)
    x_canonical = torch.bmm(R, x_obs.unsqueeze(-1)).squeeze(-1) + p
    
    # 2. Radiance Field
    # Query canonical NeRF
    # Assuming canonical_nerf takes (x, d, psi)
    # d is viewing direction, psi is appearance code
    sigma, color = canonical_nerf(x_canonical, d, psi)
    
    return sigma, color

def elastic_regularization(deformation_mlp, x_obs, omega):
    """
    Computes elastic regularization loss.
    """
    x_obs.requires_grad_(True)
    # Get deformation output
    x_encoded = pos_encoder(x_obs, alpha)
    r_v = deformation_mlp(torch.cat([x_encoded, omega], dim=-1))
    r = r_v[:, :3]
    v = r_v[:, 3:]
    
    # Compute transformed point x'
    R, p = compute_se3_transform(r, v)
    x_prime = torch.bmm(R, x_obs.unsqueeze(-1)).squeeze(-1) + p
    
    # Compute Jacobian J_T(x) = dx'/dx
    # Using automatic differentiation
    jacobian = torch.autograd.grad(x_prime.sum(), x_obs, create_graph=True)[0]
    
    # Compute Singular Values
    # SVD of jacobian
    U, S, Vh = torch.linalg.svd(jacobian)
    
    # Log of singular values
    log_S = torch.log(S + 1e-8)
    
    # Elastic loss: Frobenius norm of log(S)
    # L_elastic = ||log Sigma||_F
    elastic_loss = torch.norm(log_S, dim=-1) ** 2 # Sum of squares of log singular values
    
    # Robust loss
    c = 0.03
    robust_loss = 2 * (elastic_loss / c)**2 / ((elastic_loss / c)**2 + 4)
    
    return robust_loss

def coarse_to_fine_alpha(t, N, m):
    """
    Computes annealing parameter alpha.
    """
    return m * (t / N)
```

## Subtopics

### [Coarse-to-Fine Optimization](13448-coarse-to-fine-optimization.md)
Coarse-to-Fine Optimization is a training strategy for deformable neural radiance fields that stabilizes convergence by gradually increasing the model's capacity to represent high-frequency details. It addresses the difficulty of simultaneously optimizing complex geometry, texture, and non-rigid deformation from scratch by annealing the frequency components of the positional encoding used by the deformation network. It starts with low-frequency bands to learn smooth, large-scale motions, then introduces higher frequencies to capture fine details, preventing local minima.

### [Template-Free NeRF (TFS-NeRF)](16781-template-free-nerf-tfs-nerf.md)
TFS-NeRF is a template-free 3D semantic NeRF method for reconstructing dynamic scenes from sparse or single-view RGB videos, specifically handling interactions between two or more entities (rigid, non-rigid, or deformable). It distinguishes itself from Nerfies by explicitly disentangling the motions of interacting entities and from LBS-based approaches like TAVA by using an Invertible Neural Network (INN) to predict Linear Blend Skinning (LBS) weights directly, thereby bypassing computationally expensive root-finding optimizations. This enables time-efficient training and semantically separable geometry reconstruction without relying on pre-defined template models (e.g., SMPL) or latent codes.

## Operating characteristics
*   **Time Complexity:** Training is computationally intensive. Full HD models require training on 8 V100 GPUs for a week, while half-resolution models take 16 hours [S1]. The deformation field evaluation adds overhead to each ray sample compared to static NeRF.
*   **Memory Complexity:** High memory usage due to storing latent codes for each frame and the large MLPs for both the canonical NeRF and deformation field. The use of automatic differentiation for elastic regularization also requires storing intermediate states for the Jacobian computation.
*   **Performance:** Capable of photorealistic rendering of non-rigidly deforming scenes (e.g., human faces, bodies) from casually captured mobile phone videos [S1].
*   **Strengths:** Continuous deformation field allows for smooth, high-quality reconstructions without discretization artifacts. Elastic regularization resolves ambiguities between motion and scaling. Coarse-to-fine optimization improves robustness.
*   **Limitations:** Prone to local minima without coarse-to-fine optimization. Requires careful tuning of regularization weights. Performance degrades if the scene has significant non-rigid deformations that violate the "as-rigid-as-possible" prior (e.g., extreme stretching).
*   **When to use:** When reconstructing non-rigidly deforming scenes (like humans) from casual video, especially when a template is not available or when continuous deformation is preferred over discrete mesh-based methods.
*   **When not to use:** For static scenes (use standard NeRF), or for scenes with severe non-rigid deformations that break the local rigidity assumption (e.g., fluid-like motions).

## Background
Deformable Neural Radiance Fields (Nerfies) was introduced by Mildenhall et al. in 2021 [S1]. It builds on the original NeRF paper [39] by adding a continuous volumetric deformation field conditioned on per-frame latent codes. The method was motivated by the challenge of capturing people with hand-held cameras, where non-rigidity and camera motion make reconstruction difficult. It draws inspiration from geometry processing and physical simulation, specifically elastic energy formulations, to regularize the deformation field. The method was evaluated on data captured using a rig of two synchronized mobile phones [S1].
