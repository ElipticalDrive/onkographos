# Coarse-to-Fine Optimization

Also called: Exponential Loss Weighting Strategy, Exponential Weight Decay for Coarse-to-Fine, Frequency Annealing for Deformation Fields

## Overview
Coarse-to-Fine Optimization is a training strategy for deformable neural radiance fields that stabilizes convergence by gradually increasing the model's capacity to represent high-frequency details [G]. It addresses the difficulty of simultaneously optimizing complex geometry, texture, and non-rigid deformation from scratch by either decaying the weight of a coarse reconstruction loss relative to a fine-grained loss [S1] or by annealing the frequency components of the positional encoding used by the deformation network [S2].

## How it works
### Inputs and Outputs
- **Inputs**: Training images, camera poses, latent codes for deformation conditioning, and hyperparameters ($\lambda_s, \lambda_e, e_c, e_f$ for loss weighting; frequency cutoff schedule for encoding) [G].
- **Outputs**: Updated network weights (deformation field, radiance field) and optimized scene representation [G].

### Data Structures
- **Positional Encoding Vector**: A vector $\phi(\mathbf{x})$ constructed by applying sinusoidal functions at multiple frequencies to input coordinates $\mathbf{x}$ [G].
- **Loss Weights**: A scalar $\lambda$ that varies per training iteration [G].

### Numbered Steps
**Method 1: Exponential Loss Weighting (DP-NeRF)**
1. Define hyperparameters $\lambda_s$, $\lambda_e$, $e_c$, $e_f$, and current epoch $e_i$ [S1].
2. Compute the exponential decay rate $\alpha$ [S1].
3. Calculate the current coarse loss weight $\lambda$ for epoch $e_i$ [S1].
4. Combine the RBK (coarse) and AWP (fine) reconstruction losses using $\lambda$ [S1].
5. Backpropagate through the combined loss to update network weights [G].

**Method 2: Frequency Annealing (Nerfies)**
1. Construct the standard positional encoding $\phi(\mathbf{x})$ for input coordinates $\mathbf{x}$ (typically 3D spatial coordinates plus time or latent code) [G].
2. At the start of optimization, zero out the components of $\phi(\mathbf{x})$ corresponding to high frequencies [S2].
3. As optimization proceeds, gradually introduce higher frequency components into the positional encoding [S2].
4. Backpropagate to update network weights, allowing the effective capacity of the deformation field to increase over time [G].

### Formulas
All symbols are defined in the steps above. The exponential decay rate $\alpha$ is computed as [S1]:
$$ \alpha = -\frac{\log(\lambda_s / \lambda_e)}{e_f - e_c} $$
The current weight $\lambda$ for the coarse loss at epoch $e_i$ is [S1]:
$$ \lambda = \lambda_s \exp(\alpha (e_c - e_i)) $$
The total loss $\mathcal{L}_{total}$ balances the RBK and AWP losses using the decaying weight $\lambda$ [S1]:
$$ \mathcal{L}_{total} = \lambda \mathcal{L}_{RBK} + \mathcal{L}_{AWP} $$

### Parameters
- $\lambda_s$: Initial weight for the coarse loss (typically $> 1$) [S1].
- $\lambda_e$: Final weight for the coarse loss (typically $< 1$) [S1].
- $e_c$: Start epoch for decay [S1].
- $e_f$: End epoch for decay [S1].
- Frequency cutoff schedule: Not specified in the sources; implementers typically use a linear or stepwise ramp [G].

### Edge Cases and Pitfalls
- $\lambda_s$ and $\lambda_e$ must be chosen such that $\lambda_s > \lambda_e$ for decay to occur [S1].
- Frequency cutoff indices must be integers aligned with the positional encoding vector dimensions [G].
- Floating point precision in exponential calculations should be sufficient to avoid underflow for large epoch differences [G].

### Pseudocode (Loss Weighting Variant)
```python
import math

def compute_coarse_to_fine_weight(current_epoch, start_epoch, end_epoch, lambda_start, lambda_end):
    if current_epoch < start_epoch:
        return lambda_start
    if current_epoch > end_epoch:
        return lambda_end
    alpha = -math.log(lambda_start / lambda_end) / (end_epoch - start_epoch)
    lambda_current = lambda_start * math.exp(alpha * (start_epoch - current_epoch))
    return lambda_current

def train_step(loss_rbk, loss_awp, current_epoch, start_epoch, end_epoch, lambda_start, lambda_end):
    lambda_weight = compute_coarse_to_fine_weight(current_epoch, start_epoch, end_epoch, lambda_start, lambda_end)
    total_loss = lambda_weight * loss_rbk + loss_awp
    return total_loss
```

### Pseudocode (Frequency Annealing Variant)
```python
import math

def get_positional_encoding(x, max_freq_index, current_freq_index):
    encoded = []
    for i in range(max_freq_index):
        if i < current_freq_index:
            encoded.append(math.sin(2**i * math.pi * x))
        else:
            encoded.append(0.0)
    return encoded

def anneal_frequency_schedule(current_epoch, total_epochs, min_freq, max_freq):
    # Schedule not specified in sources; linear interpolation shown as example [G]
    progress = current_epoch / total_epochs
    current_freq = min_freq + progress * (max_freq - min_freq)
    return int(current_freq)
```

## Operating characteristics
- Time complexity adds negligible overhead to standard NeRF training [G].
- Memory complexity requires no additional memory beyond standard buffers [G].
- Strengths include preventing oscillation and local minima in high-frequency deformation fields [G].
- Limitations include requiring careful tuning of hyperparameters and potentially slowing convergence if decay is too slow [G].
- Use when training deformable NeRFs (Nerfies) or deblurred NeRFs (DP-NeRF) from scratch [G].

## Background
Coarse-to-Fine Optimization was introduced in two key papers: Nerfies (Park et al., 2021) [S2] proposed frequency annealing of positional encodings to regularize the deformation field, preventing it from overfitting to high-frequency noise early in training. DP-NeRF (Zhang et al., 2022) [S1] proposed exponential decay of the weight between a coarse rigid background loss and a fine adaptive weighting prior loss to stabilize training for deblurred scene reconstruction. Both methods address the instability of optimizing high-capacity neural networks for complex 3D representations from scratch [G].
