# Gaussian Deformation Field (GauFRe)
Also called: Dynamic Gaussian Splatting with static component, Forward-warping deformation field

## Overview
GauFRe is a dynamic scene representation that augments 3D Gaussian Splatting with a time-conditioned forward-warping deformation field [S1]. Unlike NeRF-based methods that use backward warps to query canonical space from spatio-temporal coordinates, GauFRe stores Gaussians in a canonical space and uses a neural network to output deformed attributes for each time step $t$ [S1]. It distinguishes itself from sibling methods by explicitly separating the scene into static and deformable components, preventing capacity waste in static regions and allowing the deformation field to focus solely on non-rigid and rigid motion [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of static Gaussians $\{G_j\}$, a set of deformable Gaussians $\{G_i\}$ in canonical space, camera poses, and a target time $t$.
*   **Outputs:** A rendered image $I$ at time $t$.

**Data Structures:**
1.  **Static Gaussians $\{G_j\}$:**
    *   Stored in world space.
    *   Attributes: Position $\mathbf{x}_j$, Rotation $q_j$, Scale $s_j$, Opacity $\sigma_j$, Color $c_j$.
    *   These attributes are constant over time and are not processed by the deformation field.
2.  **Deformable Gaussians $\{G_i\}$:**
    *   Stored in canonical space.
    *   Attributes: Canonical Position $\mathbf{x}_i$, Canonical Rotation $q_i$, Canonical Scale $s_i$, Opacity $\sigma_i$, Color $c_i$.
    *   These attributes are modified by the deformation field $\Phi$ based on time $t$.
3.  **Deformation Field $\Phi$:**
    *   An MLP with 6 hidden layers and 256 width [S1].
    *   Inputs: Positional encoding of position $\gamma(\mathbf{x}_i)$ and time $\gamma(t)$ [S1].
    *   Outputs: Deltas $\delta \mathbf{x}_{ti}, \delta q_{ti}, \delta s_{ti}$ [S1].

**Positional Encoding:**
Both position $\mathbf{x}$ and time $t$ are encoded using $\gamma(\cdot)$ with base $L_x=10$ and $L_t=10$ respectively [S1]:
$$ \gamma(v) = (\sin(2^0 v), \cos(2^0 v), \dots, \sin(2^{L-1} v), \cos(2^{L-1} v)) $$

**Numbered Steps:**

1.  **Initialization:**
    *   Initialize static Gaussians $\{G_j\}$ using a Structure-from-Motion (SfM) point cloud [S1].
    *   Initialize deformable Gaussians $\{G_i\}$ with uniform random samples within the scene bounding box [S1].
    *   *Rationale:* This prevents the two sets from competing for scene occupancy; SfM captures static regions well, while random initialization allows deformable Gaussians to cover dynamic regions without bias [S1].

2.  **Deformation Field Forward Pass:**
    For each deformable Gaussian $i$ at time $t$:
    *   Compute encoded inputs: $\mathbf{e}_x = \gamma(\mathbf{x}_i)$, $\mathbf{e}_t = \gamma(t)$ [S1].
    *   Pass through MLP $\Phi$: $(\delta \mathbf{x}_{ti}, \delta q_{ti}, \delta s_{ti}) = \Phi(\mathbf{e}_x, \mathbf{e}_t)$ [S1].
    *   *Note:* The field models the delta-change in canonical attributes, not absolute values [S1].

3.  **Attribute Update:**
    Compute the deformed attributes $\mathbf{x}_{ti}, q_{ti}, s_{ti}$ for time $t$:
    *   **Position:**
        $$ \mathbf{x}_{ti} = \mathbf{x}_i + \delta \mathbf{x}_{ti} \quad (4) $$
    *   **Scale:**
        $$ \text{Exp}(s_{ti}) = \text{Exp}(s_i + \delta s_{ti}) \quad (5) $$
        *   *Note:* Pre-exponentiation is used because it is a log-linear estimation problem, simpler than exponential, and allows handling negative changes [S1].
    *   **Rotation:**
        $$ q_{ti} = q_i \cdot \delta q_{ti} \quad (6) $$
        *   *Note:* Quaternion multiplication is used, not addition, to maintain geometric bounds. The resulting quaternion must be normalized after deformation to stabilize training [S1].
    *   **Opacity and Color:**
        *   $\sigma_{ti} = \sigma_i$ and $c_{ti} = c_i$. These are **not** deformed over time [S1].

4.  **Rendering:**
    *   Concatenate the deformed set $\{G_{it}\}$ (with updated $\mathbf{x}_{ti}, q_{ti}, s_{ti}$) and the static set $\{G_j\}$ [S1].
    *   Render the combined set as a static world representation using standard 3D Gaussian Splatting rasterization [S1].

5.  **Optimization:**
    *   **Loss Function:**
        $$ \mathcal{L}(I, I_{gt}) = \begin{cases} (1 - \lambda_{ssim})\mathcal{L}_2(I, I_{gt}) + \lambda_{ssim}(1 - \text{SSIM}(I, I_{gt})) & \text{if } itr \le 20,000 \\ (1 - \lambda_{ssim})\mathcal{L}_1(I, I_{gt}) + \lambda_{ssim}(1 - \text{SSIM}(I, I_{gt})) & \text{if } itr > 20,000 \end{cases} $$
        *   Switch from L2 to L1 loss at 20,000 iterations to increase sharpness late in optimization [S1].
    *   **Optimizer:** Adam with $\beta = (0.9, 0.999)$ and $\epsilon = 10^{-15}$ [S1].
    *   **Learning Rate:** Deformation field LR is 0.001, with exponential scheduling shrinking to $0.001 \times$ original rate until 30,000 iterations [S1].
    *   **Densification/Pruning:** Both static and deformable sets are densified and pruned separately until 20,000 iterations. Optimization continues until 40,000 iterations [S1].

```python
import torch
import torch.nn as nn
import math

class PositionalEncoding(nn.Module):
    def __init__(self, L):
        super().__init__()
        self.L = L

    def forward(self, x):
        # x shape: (..., 1)
        # Output shape: (..., 2*L)
        freq_bands = 2.0 ** torch.arange(self.L, device=x.device).float()
        # sin(2^0 x), cos(2^0 x), ...
        s = torch.sin(freq_bands * x)
        c = torch.cos(freq_bands * x)
        return torch.cat([s, c], dim=-1)

class DeformationField(nn.Module):
    def __init__(self, Lx=10, Lt=10, hidden_dim=256, num_layers=6):
        super().__init__()
        self.pe_x = PositionalEncoding(Lx)
        self.pe_t = PositionalEncoding(Lt)
        
        # Input dim: 2*Lx (pos) + 2*Lt (time)
        input_dim = 2 * Lx + 2 * Lt
        # Output dim: 3 (pos delta) + 4 (quat delta) + 3 (scale delta)
        output_dim = 10 
        
        layers = []
        layers.append(nn.Linear(input_dim, hidden_dim))
        layers.append(nn.ReLU())
        for _ in range(num_layers - 1):
            layers.append(nn.Linear(hidden_dim, hidden_dim))
            layers.append(nn.ReLU())
        layers.append(nn.Linear(hidden_dim, output_dim))
        self.mlp = nn.Sequential(*layers)

    def forward(self, x, t):
        # x: (N, 3), t: (N,) or scalar
        if t.dim() == 0:
            t = t.expand(x.size(0))
        
        pe_x = self.pe_x(x)
        pe_t = self.pe_t(t.unsqueeze(-1))
        
        input_vec = torch.cat([pe_x, pe_t], dim=-1)
        delta = self.mlp(input_vec)
        
        # Split delta into components
        delta_x = delta[:, :3]
        delta_q = delta[:, 3:7]
        delta_s = delta[:, 7:10]
        
        return delta_x, delta_q, delta_s

def update_gaussians(canonical_gaussians, delta_x, delta_q, delta_s):
    """
    canonical_gaussians: dict with keys 'x', 'q', 's', 'sigma', 'c'
    Returns deformed attributes
    """
    x = canonical_gaussians['x']
    q = canonical_gaussians['q']
    s = canonical_gaussians['s']
    
    # Position update
    x_deformed = x + delta_x
    
    # Scale update (pre-exponentiation)
    # Exp(s_deformed) = Exp(s + delta_s)
    # We store log-scale, so we update the log-scale directly
    s_deformed = s + delta_s
    
    # Rotation update (quaternion multiplication)
    # q_deformed = q * delta_q
    # Note: delta_q is a small rotation delta. 
    # Implementation depends on quaternion library, but mathematically:
    # q_deformed = quaternion_multiply(q, delta_q)
    # Then normalize.
    q_deformed = quaternion_multiply(q, delta_q)
    q_deformed = q_deformed / (torch.norm(q_deformed, dim=-1, keepdim=True) + 1e-8)
    
    return {
        'x': x_deformed,
        'q': q_deformed,
        's': s_deformed,
        'sigma': canonical_gaussians['sigma'], # Not deformed
        'c': canonical_gaussians['c']          # Not deformed
    }

def render_scene(static_gaussians, deformed_gaussians, camera_params):
    """
    Concatenate static and deformed Gaussians and rasterize.
    """
    all_gaussians = concatenate(static_gaussians, deformed_gaussians)
    image = rasterize(all_gaussians, camera_params)
    return image
```

**Subtopics:**
*   **Explicit Keyframing:** Stores attributes at discrete timestamps and interpolates. Chosen when motion is sparse or discrete, but suffers from discontinuities and high memory for high-frequency motion [14584-explicit-4d-gaussian-splatting.md].
*   **Light-weight 4D Gaussian Splatting (LGS):** Focuses on compression to fit dynamic data within memory constraints. Chosen when VRAM is limited, but may sacrifice detail compared to full deformation fields [15777-light-weight-4d-gaussian-splatting-lgs.md].

## Operating characteristics
*   **Time Complexity:** Training is significantly faster than MLP-based NeRF representations, taking 10–20 minutes on D-NeRF and NeRF-DS datasets [S1].
*   **Memory Complexity:** Separating static and deformable components reduces capacity waste in static regions, improving efficiency [S1].
*   **Rendering Speed:** Real-time rendering on NVIDIA 3090 GPU: 0.01s (100 FPS) for D-NeRF, 0.06s for HyperNeRF [S1].
*   **Strengths:** High reconstruction quality (top PSNR on D-NeRF and NeRF-DS), real-time rendering, fast training, handles non-rigid deformations (scaling) [S1].
*   **Limitations:** Deforming opacity and color causes overfitting and artifacts, so these are fixed [S1]. Requires careful initialization to prevent static/deformable sets from fighting [S1].
*   **When to use:** Real-time dynamic novel view synthesis with monocular or sparse multi-view input, especially when static regions are present [S1].
*   **When not to use:** Scenes where color/opacity changes significantly over time (e.g., lighting changes, material changes) [S1].

## Background
GauFRe was introduced in "GauFRe: Gaussian Deformation Fields for Real-Time Dynamic Novel View Synthesis" [S1]. It addresses the limitations of backward-warping NeRFs and rigid-only dynamic Gaussian splatting methods by introducing a forward-warping deformation field that models non-rigid transformations (scaling) and separates static/dynamic components [S1].
