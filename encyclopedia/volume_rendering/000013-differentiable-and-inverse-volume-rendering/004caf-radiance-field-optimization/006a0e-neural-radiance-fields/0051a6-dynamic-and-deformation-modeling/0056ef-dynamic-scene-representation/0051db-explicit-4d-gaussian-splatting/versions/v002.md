# Explicit 4D Gaussian Splatting

Also called: Dynamic 3DGS with Keyframe Interpolation, Fully Explicit Dynamic Gaussian Splatting

## Overview
Explicit 4D Gaussian Splatting (Ex4DGS) is a dynamic scene representation method that renders novel views of video sequences by explicitly interpolating Gaussian attributes between sparse keyframes [S1]. It solves the problem of memory inefficiency and rendering artifacts in dynamic scenes by separating Gaussians into static and dynamic categories, storing only temporal metadata for dynamic primitives [S1]. Unlike implicit deformation fields, Ex4DGS avoids neural network inference during rendering, maintaining the high throughput of static 3D Gaussian Splatting while handling complex motions like self-occlusion through a simplified opacity model [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A sequence of images (video) and an initial sparse point cloud (typically from Structure-from-Motion on the first frame) [S1].
*   **Outputs:** A set of 3D Gaussians with time-dependent attributes, allowing differentiable rasterization of any timestamp $t \in [0, l]$ [S1].

**Data Structures**
The scene is represented by two disjoint sets of Gaussians: Static ($G_s$) and Dynamic ($G_d$) [S1].
*   **Static Gaussian ($G_s$):** Stores a pivot position $x$, a translation vector $d$, and standard static attributes (rotation $R$, scale $S$, opacity $\sigma$, color $c$) [S1].
*   **Dynamic Gaussian ($G_d$):** Stores a sequence of keyframe states. For each keyframe $n$, it stores position $p_n$, rotation $r_n$, and opacity $\sigma_n$ [S1]. It also stores parameters for the opacity interpolation model (means $a_{so}, a_{of}$ and variances $b_{so}, b_{fo}$) [S1].

**Mathematical Preliminaries**
The rendering equation follows standard 3D Gaussian Splatting [S1]. A 3D Gaussian is defined as:
$$ G(x) = e^{-\frac{1}{2} (x-\mu)^\top \Sigma^{-1} (x-\mu)} $$
where $\mu$ is the position and $\Sigma$ is the covariance matrix [S1]. The covariance in camera coordinates is $\Sigma' = J W \Sigma W^\top J^\top$, where $J$ is the Jacobian of the perspective projection affine approximation and $W$ is the viewing transformation [S1]. The covariance is decomposed into scale $S$ and rotation $R$ as $\Sigma = R S S^\top R^\top$ [S1]. The rendered color $C$ is computed via alpha blending:
$$ C=\sum_{i=1}^{N} T_i (1 - e^{-\sigma_i \delta_i })c_i, \quad T_i = e^{-\sum_{j=1}^{i-1} \sigma_j \delta_j} $$
where $N$ is the number of visible Gaussians, $i,j$ are depth-ordered indices, $\sigma_i$ is density, $\delta_i$ is the interval along the ray, and $c_i$ is color [S1].

**Algorithm Steps**

1.  **Initialization:** Initialize all Gaussians as static, assuming linear motion. Set the scene duration $l$ and keyframe interval $I$ [S1].
2.  **Static Motion Model:** For a static Gaussian, the position $\mu(t)$ at time $t$ is:
    $$ \mu(t) = x + t' d, \quad t' = t/l \in [0, 1] $$
    where $x$ is the pivot position, $d$ is the translation vector, and $l$ is the scene duration [S1].
3.  **Dynamic Keyframe Definition:** Keyframes are defined as $K = \{t | t = nI, n \in \mathbb{Z}, t \in T\}$, where $I$ is the interval [S1].
4.  **Progressive Training:**
    *   Start with an initial duration (e.g., 10 frames).
    *   Increment the duration by the interval $I$ every 400 iterations [S1].
    *   When the duration increases, estimate new keyframe positions/rotations using linear regression on the last $\rho$ frames to share motion information [S1].
5.  **Static-to-Dynamic Conversion:**
    *   Measure motion in image space by normalizing the translation vector $d$ by the squared distance $\lambda$ between the point and the camera at the last timestamp: $\|d\| / \|\lambda\|^2$ [S1].
    *   Sort points by this metric. Convert the top $\eta$ percent (empirically $\eta=2$) into dynamic Gaussians [S1].
    *   For converted points, estimate position at each keyframe using $x$ and $d$. Initialize rotation to the same value in all keyframes and opacity to visible in all keyframes [S1].
6.  **Temporal Interpolation (Rendering):**
    *   **Position:** Use Cubic Hermite Interpolation (CHip) for position. For time $t$ within interval $[nI, (n+1)I]$, let $t' = (t - nI)/I$. The position is:
        $$ \mu(t) = CHip(p_n, m_n, p_{n+1}, m_{n+1}; t') $$
        where tangents are estimated from neighbors: $m_n = (p_{n+1} - p_{n-1})/(2I)$ and $m_{n+1} = (p_{n+2} - p_n)/(2I)$ [S1].
    *   **Rotation:** Use Spherical Linear Interpolation (Slerp) for quaternions $r_n, r_{n+1}$:
        $$ q(t) = Slerp(r_n, r_{n+1}; t') = \frac{\sin[(t')\Omega]}{\sin \Omega}r_n + \frac{\sin[(1 - t')\Omega]}{\sin \Omega}r_{n+1} $$
        where $\cos \Omega = r_n \cdot r_{n+1}$ [S1].
    *   **Opacity:** Use a simplified Gaussian mixture model. Let $g_{so}$ and $g_{fo}$ be Gaussians with means $a_{so}, a_{of}$ and variances $b_{so}, b_{fo}$. The temporal opacity $\sigma_t(t)$ is:
        $$ \sigma_t(t) = \begin{cases} e^{-\frac{(t-a_{so})^2}{b_{so}}} & t < a_{so} \\ 1 & a_{so} \le t \le a_{of} \\ e^{-\frac{(t-a_{of})^2}{b_{fo}}} & t > a_{of} \end{cases} $$
        This handles appearance and disappearance [S1].
7.  **Pruning (Point Backtracking):**
    *   Calculate per-pixel error $E$ for pixel $k$:
        $$ E = \frac{\sum_{i} \sigma_i \times \prod_{j=1}^{i-1} (1 - \sigma_j) \times q_k}{\sum_{i} \sigma_i \times \prod_{j=1}^{i-1} (1 - \sigma_j)} $$
        where $q_k$ is the measured error (L1/SSIM) at pixel $k$, and $i,j$ are depth-ordered visible Gaussians [S1].
    *   Calculate accumulated error $E_{total} = \sum_{v \in D} \frac{E_v}{|D|}$ over training views $D$ [S1].
    *   Prune Gaussians with error exceeding $E_{total}$ at pre-defined steps [S1].
8.  **Optimization:**
    *   Use RAdam optimizer [S1].
    *   Losses: L1 and SSIM between rendered and ground truth images [S1].
    *   Regularization: Minimize $\|d\|$ for static points and $\|p_{n+1} - p_n\|$ for dynamic points (parameter 0.0001) [S1].

**Pseudocode**

import numpy as np

def cubic_hermite(p0, m0, p1, m1, t):
    """
    Cubic Hermite Interpolation on unit interval t in [0, 1].
    """
    t2 = t * t
    t3 = t2 * t
    h00 = 2 * t3 - 3 * t2 + 1
    h10 = t3 - 2 * t2 + t
    h01 = -2 * t3 + 3 * t2
    h11 = t3 - t2
    return h00 * p0 + h10 * m0 + h01 * p1 + h11 * m1

def slerp(q0, q1, t):
    """
    Spherical Linear Interpolation for quaternions.
    """
    dot = np.dot(q0, q1)
    # Clamp dot product to avoid numerical instability
    dot = np.clip(dot, -1.0, 1.0)
    theta = np.arccos(dot)
    sin_theta = np.sin(theta)
    
    if sin_theta < 1e-6:
        # Linear interpolation if quaternions are parallel
        return q0 + t * (q1 - q0)
        
    s0 = np.sin((1 - t) * theta) / sin_theta
    s1 = np.sin(t * theta) / sin_theta
    return s0 * q0 + s1 * q1

def get_temporal_opacity(t, a_so, b_so, a_of, b_fo):
    """
    Simplified Gaussian mixture model for opacity.
    """
    if t < a_so:
        return np.exp(-((t - a_so)**2) / b_so)
    elif t > a_of:
        return np.exp(-((t - a_of)**2) / b_fo)
    else:
        return 1.0

def render_ex4dgs(gaussians, camera, time_t, duration_l, interval_I):
    """
    Renders a frame for time_t using Ex4DGS attributes.
    """
    # 1. Transform Gaussians to camera space
    # (Standard 3DGS projection logic)
    projected_gaussians = []
    
    for g in gaussians:
        if g.is_static:
            # Static motion: linear interpolation
            t_prime = time_t / duration_l
            mu = g.pivot_position + t_prime * g.translation_vector
            # Rotation, Scale, Opacity are constant or view-dependent (SH)
            rot = g.rotation
            scale = g.scale
            opacity = g.opacity
        else:
            # Dynamic motion: Keyframe interpolation
            n = int(time_t // interval_I)
            t_prime = (time_t - n * interval_I) / interval_I
            
            # Get keyframe data
            p_n = g.keyframes[n].position
            p_n1 = g.keyframes[n+1].position
            p_n_1 = g.keyframes[n-1].position if n > 0 else p_n # Handle boundary
            p_n2 = g.keyframes[n+2].position if n+2 < len(g.keyframes) else p_n1 # Handle boundary
            
            # Position via CHip
            m_n = (p_n1 - p_n_1) / (2 * interval_I)
            m_n1 = (p_n2 - p_n) / (2 * interval_I)
            mu = cubic_hermite(p_n, m_n, p_n1, m_n1, t_prime)
            
            # Rotation via Slerp
            r_n = g.keyframes[n].rotation
            r_n1 = g.keyframes[n+1].rotation
            rot = slerp(r_n, r_n1, t_prime)
            
            # Opacity via Gaussian Mixture
            opacity = get_temporal_opacity(time_t, 
                                           g.opacity_params['a_so'], 
                                           g.opacity_params['b_so'], 
                                           g.opacity_params['a_of'], 
                                           g.opacity_params['b_fo'])
            
            # Scale is typically static or interpolated similarly if needed
            scale = g.scale 

        # Project to 2D

        cov_cam = project_covariance(cov, camera)
        projected_gaussians.append({
            'mu': mu,
            'cov': cov_cam,
            'opacity': opacity,

## Operating characteristics
*   **Time Complexity:** Rendering is $O(N)$ where $N$ is the number of Gaussians, identical to static 3DGS, as interpolation is a simple arithmetic operation per Gaussian [S1]. Training time is comparable to 3DGS but requires additional steps for keyframe estimation and pruning [S1].
*   **Memory Complexity:** Significantly lower than implicit methods or methods storing full keyframes for all Gaussians. Only dynamic Gaussians store temporal data, and static Gaussians store only two vectors ($x, d$) [S1].
*   **Performance:** Achieves 62 fps on a single NVIDIA 2080Ti GPU for 300-frame scenes at 1352×1014 resolution [S1].
*   **Strengths:** High rendering speed; handles self-occlusion (disappearing/reappearing objects) better than trajectory-based methods via opacity modeling; no neural network inference overhead [S1].
*   **Limitations:** Requires uniform keyframe intervals for the standard interpolation logic; performance depends on the quality of the initial sparse point cloud; may struggle with very high-frequency motion if keyframe interval $I$ is too large [S1].

## Background
Ex4DGS was introduced in the paper "Fully Explicit Dynamic Gaussian Splatting" [S1]. It addresses the limitations of prior dynamic 3DGS methods that either relied on implicit deformation fields (slower rendering) or explicit trajectories that failed to handle self-occlusion efficiently (memory burden) [S1]. The method builds on the foundational 3D Gaussian Splatting paper [S1] and incorporates techniques from video interpolation (Cubic Hermite, Slerp) [S1].
