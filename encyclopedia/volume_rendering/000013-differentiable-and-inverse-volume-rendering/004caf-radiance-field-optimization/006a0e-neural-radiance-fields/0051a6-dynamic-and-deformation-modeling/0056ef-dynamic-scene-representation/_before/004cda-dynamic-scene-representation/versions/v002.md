# Dynamic Scene Representation

Also called: Dynamic Neural Radiance Fields

## Overview
Dynamic Scene Representation methods extend static radiance fields to model time-varying scenes, solving the problem of novel view synthesis for non-static environments [S1]. Unlike static methods, these approaches condition the radiance field prediction on temporal or parametric variables to capture motion and deformation [S1]. This family differs from its siblings by focusing on the general representation of dynamic scenes, ranging from monolithic temporal conditioning to structured variable encoding, as detailed in [DyNeRF](7274-dynerf.md) and [Neural Rendering of Variable Scenes](12734-neural-rendering-of-variable-scenes.md).

## Shared principles
All methods in this family rely on the differentiability of the forward rendering operator and the propagation of gradients through the integration steps [44-radiance-field-optimization.md]. The core mechanism is the evaluation of the volume rendering equation and the computation of gradients with respect to scene parameters (density, geometry, transfer functions, camera poses) [44-radiance-field-optimization.md].

The standard emission-absorption model computes the color $\hat{C}(\mathbf{r})$ for a ray $\mathbf{r}$ as [44-radiance-field-optimization.md]:

$$
\hat{C}(\mathbf{r}) = \sum_{i=1}^N T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i
$$

where $\sigma_i$ is the density, $\delta_i$ is the step size, $\mathbf{c}_i$ is the color, and $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$ is the transmittance [44-radiance-field-optimization.md].

Differentiation strategies fall into three main categories [44-radiance-field-optimization.md]:
1. **Reverse-Mode Automatic Differentiation (AD):** Standard backpropagation through the computational graph. This requires storing $O(kn)$ intermediate states (where $n$ is pixels and $k$ is samples), leading to high memory usage [44-radiance-field-optimization.md].
2. **Adjoint Method:** Computes gradients by propagating adjoint variables backward through the rendering algorithm, evaluating the chain rule from output to input. This has computational complexity largely constant in the number of parameters, making it preferable for optimizing many parameters like the transfer function [44-radiance-field-optimization.md].
3. **Analytic Inversion / Explicit Gradients:** Uses a-priori knowledge of the DVR operations to invert the order of operations or derive closed-form gradients, reducing memory consumption to $O(n)$ by avoiding the storage of intermediate results [44-radiance-field-optimization.md].

## Subtopics

### [DyNeRF](7274-dynerf.md)
DyNeRF is a baseline method for dynamic scene representation that models volumetric video using a single NeRF-like Multi-Layer Perceptron (MLP). It solves the problem of novel view synthesis for dynamic scenes by conditioning the radiance field prediction on a temporal variable. Unlike its sibling [Neural Rendering of Variable Scenes](12734-neural-rendering-of-variable-scenes.md) which may use different structural priors, DyNeRF relies on a monolithic shared MLP structure. This simplicity allows it to serve as a direct baseline for more complex decomposition or deformation-based methods, though it tends to lose high-frequency details due to the limitations of a single shared network.

### [Neural Rendering of Variable Scenes](12734-neural-rendering-of-variable-scenes.md)
Neural Rendering of Variable Scenes refers to methods that explicitly incorporate scene variation into the training phase by assuming a predefined range for each variable scene element encoded into a structured representation. Unlike Neural Irradiance Volumes (NIV) which do not explicitly model higher-order interactions between dynamic objects and the scene, these methods learn a surface radiance field for all possible permutations of scene variables. They are chosen when the goal is to capture complex, higher-order lighting interactions (such as path-traced global illumination effects) that static irradiance volumes may approximate less accurately at low capacities, though they suffer from significant performance and flexibility trade-offs.

### Generalizable Dynamic Neural Radiance Field
A neural radiance field that takes transformed 3D location, view direction, and aggregated features as input to predict volume density and color [S1]. The aggregated features $F_p$ are derived from pixel alignment, and the model uses pose-embedded non-rigid human deformation to warp the body from the current time frame to a common canonical pose, allowing the NeRF to receive static sampling queries [S1].

## Background
The concept of representing dynamic scenes using neural radiance fields emerged with the need to extend static NeRF capabilities to video and real-world dynamic content. DyNeRF was introduced as a foundational approach for this extension [S1]. The field has since expanded to include methods that handle specific deformations, such as human motion, and those that model variable scene parameters for complex interactions [S1].
