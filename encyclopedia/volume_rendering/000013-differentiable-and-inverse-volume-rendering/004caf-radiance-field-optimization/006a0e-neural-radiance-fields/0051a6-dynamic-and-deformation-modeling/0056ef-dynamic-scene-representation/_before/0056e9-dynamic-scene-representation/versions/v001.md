# Dynamic Scene Representation

Also called: Dynamic 3D Gaussian Splatting, 4D Gaussian Splatting

## Overview
Dynamic Scene Representation extends static 3D Gaussian Splatting to handle temporal variations, enabling real-time novel view synthesis of non-rigid or moving scenes [14584-explicit-4d-gaussian-splatting.md], [15458-gaussian-deformation-field-gaufre.md], [15777-light-weight-4d-gaussian-splatting-lgs.md]. It solves the problem of modeling time-dependent geometry and appearance without the memory overhead of storing full 3D Gaussian sets for every frame. It differs from static methods by introducing time-conditioned attributes, and from NeRF-based dynamic methods by maintaining explicit Gaussian primitives for rasterization efficiency [14584-explicit-4d-gaussian-splatting.md], [15458-gaussian-deformation-field-gaufre.md].

## Shared principles
All dynamic representations in this family share the core mechanism of augmenting the static 3D Gaussian Splatting pipeline with a temporal dimension $t$. The rendering equation remains the standard differentiable rasterization, but the Gaussian attributes (position, rotation, scale, opacity, color) become functions of time $t$ [14584-explicit-4d-gaussian-splatting.md], [15458-gaussian-deformation-field-gaufre.md].

The fundamental challenge is representing continuous motion and deformation efficiently. This is achieved by either:
1.  **Explicit Keyframing:** Storing attributes at discrete timestamps and interpolating between them [14584-explicit-4d-gaussian-splatting.md].
2.  **Implicit Deformation Fields:** Using a neural network (MLP) to predict deltas to canonical attributes based on position and time [15458-gaussian-deformation-field-gaufre.md].
3.  **Compression:** Reducing the parameter count of Gaussians and feature fields to fit dynamic data within memory constraints [15777-light-weight-4d-gaussian-splatting-lgs.md].

Common optimization strategies include separating static and dynamic components to prevent capacity waste in static regions [14584-explicit-4d-gaussian-splatting.md], [15458-gaussian-deformation-field-gaufre.md], and using progressive training schedules to handle sparse initialization [14584-explicit-4d-gaussian-splatting.md].

## Subtopics

### [Explicit 4D Gaussian Splatting](14584-explicit-4d-gaussian-splatting.md)
Separates Gaussians into static and dynamic categories, storing explicit keyframe data for dynamic points and using Cubic Hermite interpolation for position and Slerp for rotation. Choose when memory efficiency for occluded objects is critical and explicit keyframes are feasible.

### [Gaussian Deformation Field (GauFRe)](15458-gaussian-deformation-field-gaufre.md)
Uses a time-conditioned MLP to output deformed attributes from a canonical space. Choose for real-time novel view synthesis of non-rigid deformations where implicit modeling is preferred over keyframes.

### [Light-weight 4D Gaussian Splatting (LGS)](15777-light-weight-4d-gaussian-splatting-lgs.md)
Integrates Deformation-Aware Pruning, Gaussian-Attribute Pruning, and Feature Field Condensation with knowledge distillation. Choose for resource-constrained environments (e.g., surgical scenes) requiring drastic memory reduction.

## Background
Dynamic 3D Gaussian Splatting emerged as an extension of the static 3DGS method [14584-explicit-4d-gaussian-splatting.md], [15458-gaussian-deformation-field-gaufre.md], [15777-light-weight-4d-gaussian-splatting-lgs.md]. Early approaches adapted NeRF-based dynamic representations (like DynamicNeRF) to Gaussian splatting, but faced challenges with memory and rendering speed. Explicit methods like Ex4DGS addressed occlusion handling by separating static/dynamic sets [14584-explicit-4d-gaussian-splatting.md]. GauFRe introduced forward-warping deformation fields to avoid backward warping artifacts common in NeRFs [15458-gaussian-deformation-field-gaufre.md]. LGS focused on compression techniques for specific applications like surgical robotics [15777-light-weight-4d-gaussian-splatting-lgs.md].
