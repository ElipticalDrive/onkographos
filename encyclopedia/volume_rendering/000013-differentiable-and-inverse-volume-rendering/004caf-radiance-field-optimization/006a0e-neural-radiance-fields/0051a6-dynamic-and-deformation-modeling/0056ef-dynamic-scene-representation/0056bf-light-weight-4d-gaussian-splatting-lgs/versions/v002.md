# Light-weight 4D Gaussian Splatting (LGS)

## Overview
Light-weight 4D Gaussian Splatting (LGS) is a memory-efficient method for real-time rendering of dynamic scenes, specifically designed for surgical endoscopy [S1]. It addresses the high memory footprint and computational cost of standard 4D Gaussian Splatting by combining Deformation-Aware Pruning (DAP), Gaussian-Attribute Pruning (GAP), and Feature Field Condensation (FFC) [S1]. Unlike [Explicit 4D Gaussian Splatting](14584-explicit-4d-gaussian-splatting.md) which stores full attributes per timestamp, or [Gaussian Deformation Field (GauFRe)](15458-gaussian-deformation-field-gaufre.md) which relies on neural deformation fields, LGS achieves compression rates up to 15x compared to prior Gaussian methods while maintaining rendering quality comparable to uncompressed models [S1].

## How it works
LGS operates in two phases: an initial training of an uncompressed "teacher" model, followed by the optimization of a compressed "student" model using knowledge distillation [S1]. The student model is constrained by three pruning and compression techniques to reduce memory usage without significant quality loss [S1].

### Inputs and Outputs
*   **Inputs:** A set of synchronized multi-view images with known camera poses and timestamps $t$ [S1].
*   **Outputs:** A compressed set of 3D Gaussians with time-dependent attributes and a condensed spatial-temporal feature field [S1].

### Data Structures
The scene is represented by a set of $N$ 3D Gaussians. Each Gaussian $i$ has attributes that vary with time $t$:
*   **Position:** $\mathbf{p}_i(t) \in \mathbb{R}^3$
*   **Rotation:** $\mathbf{q}_i(t) \in \mathbb{R}^4$ (quaternion)
*   **Scale:** $\mathbf{s}_i(t) \in \mathbb{R}^3$
*   **Opacity:** $\alpha_i(t) \in [0, 1]$
*   **Color:** Represented by spherical harmonics (SH) coefficients stored in a condensed feature field [S1].

The feature field is a 4D voxel grid with dimensions $[D_x, D_y, D_z, D_t]$ [S1].

### Steps

1.  **Teacher Training:** Train an uncompressed 4D Gaussian Splatting model on the dynamic scene data until convergence [S1]. This model serves as the teacher for distillation.
2.  **Deformation-Aware Pruning (DAP):** Prune Gaussians that contribute minimally to deformation or rendering [S1].
    *   Calculate a pruning score for each Gaussian based on its contribution to the scene's deformation and visual fidelity [S1].
    *   Remove Gaussians with scores below a threshold defined by parameter $h$ [S1].
    *   *Parameter:* $h = 0.5$ [S1].
    *   *Parameter:* $\beta = 0.1$ [S1].
3.  **Gaussian-Attribute Pruning (GAP):** Reduce the dimensionality of Gaussian attributes (specifically SH coefficients) in non-critical areas [S1].
    *   Identify regions where high-frequency texture details are not essential [S1].
    *   Prune SH coefficients based on a threshold $h_{sh}$ [S1].
    *   *Parameter:* $h_{sh} = 2$ [S1].
    *   *Note:* Without GAP, model size increases significantly (e.g., to 26.30MB on ENDONERF) and FPS drops, indicating GAP reduces Gaussian parameters by ~40% [S1].
4.  **Feature Field Condensation (FFC):** Compress the 4D spatial-temporal feature field using 3D adaptive pooling [S1].
    *   The feature field is decomposed into subplanes $\Phi \in \{(x, y), (x, z), (y, z), (x, t), (y, t), (z, t)\}$ [S1].
    *   Apply pooling to each subplane to reduce resolution while preserving 4D features [S1].
    *   The condensed feature $E_{\Phi'}$ at index $(i, j)$ is calculated as:
        $$ E_{\Phi'}(i, j) = \frac{1}{r_{\Phi1} r_{\Phi2}} \sum_{i'=i \cdot r_{\Phi1}}^{(i+1) \cdot r_{\Phi1}} \sum_{j'=j \cdot r_{\Phi2}}^{(j+1) \cdot r_{\Phi2}} E_{\Phi}(i', j') $$
        where $r_{\Phi1}$ and $r_{\Phi2}$ are the compression rates on the respective axes of the subplane $\Phi$ [S1].
    *   *Parameter:* Feature field resolution is set to $[16, 16, 16, 25]$ [S1].
    *   A tiny MLP $F$ is retained to preserve deformation calculation ability [S1].
5.  **Knowledge Distillation Optimization:** Optimize the pruned/compressed student model using a combined loss function [S1].
    *   The student model renders images $\hat{I}_{stu}(t)$ at each timestamp $t$ [S1].
    *   The teacher model renders images $\hat{I}_{tch}(t)$ [S1].
    *   The ground truth images are $I_{gt}(t)$ [S1].
    *   The total loss $L$ is:
        $$ L = L_d + L_r $$
    *   Distillation loss $L_d$ (MSE between teacher and student):
        $$ L_d = \frac{1}{T} \sum_{t=1}^{T} \| \hat{I}_{tch}(t) - \hat{I}_{stu}(t) \|^2 $$
    *   Rendering loss $L_r$ (MSE between student and ground truth):
        $$ L_r = \frac{1}{T} \sum_{t=1}^{T} \| I_{gt}(t) - \hat{I}_{stu}(t) \|^2 $$
    *   where $T$ is the number of training timestamps [S1].

### Pseudocode

```python
def train_lgs(images, poses, timestamps, teacher_model):
    """
    Train the LGS student model using knowledge distillation from a pre-trained teacher.
    
    Args:
        images: List of ground truth images for each timestamp.
        poses: Camera poses for each timestamp.
        timestamps: List of time values t.
        teacher_model: Pre-trained uncompressed 4D Gaussian Splatting model.
        
    Returns:
        student_model: The optimized, compressed LGS model.
    """
    # Initialize student model with same structure as teacher but with lower capacity
    student_model = initialize_student_model(teacher_model)
    
    # Apply initial pruning thresholds
    student_model.apply_dap(h=0.5, beta=0.1)
    student_model.apply_gap(h_sh=2)
    student_model.apply_ffc(resolution=[16, 16, 16, 25])
    
    # Tiny MLP F is initialized to preserve deformation calculation
    student_model.init_tiny_mlp()
    
    optimizer = torch.optim.Adam(student_model.parameters(), lr=1e-3)
    
    for epoch in range(num_epochs):
        for t, img_gt, pose in zip(timestamps, images, poses):
            # Render student image
            img_stu = student_model.render(pose, t)
            
            # Render teacher image (no gradient needed for teacher)
            with torch.no_grad():
                img_tch = teacher_model.render(pose, t)
            
            # Calculate losses
            L_d = torch.mean((img_tch - img_stu) ** 2)
            L_r = torch.mean((img_gt - img_stu) ** 2)
            L = L_d + L_r
            
            # Backpropagate
            optimizer.zero_grad()
            L.backward()
            optimizer.step()
            
    return student_model
```

### Edge Cases and Pitfalls
*   **Over-pruning:** Removing too many Gaussians or compressing the feature field too aggressively leads to visible artifacts and loss of detail [S1]. The ablation study shows that removing FFC increases model size to 329.6MB and reduces quality [S1].
*   **Repetitive Textures:** Without GAP, the model struggles with repetitive textures, leading to increased model size and reduced FPS [S1].
*   **Deformation Accuracy:** The tiny MLP $F$ is critical for maintaining deformation calculation ability; removing it or compressing it too much may degrade temporal consistency [S1].

## Operating characteristics
*   **Memory Efficiency:** LGS achieves significant compression. On the ENDONERF dataset, the model size is 25.00MB, which is 15x smaller than EndoGaussian (334.5MB) [S1]. On the SCARED dataset, it is 20.40MB, 9x smaller than EndoGaussian (184.0MB) [S1].
*   **Rendering Speed:** LGS achieves real-time performance. On ENDONERF, it reaches 188.3 FPS [S1]. On SCARED, it reaches 194.66 FPS [S1]. It is 21.8 FPS faster than EndoGaussian and 87.9 FPS faster than EndoGS on ENDONERF [S1].
*   **Quality:** On ENDONERF, LGS achieves SSIM 0.963, PSNR 37.48, and LPIPS 0.068 [S1]. The quality difference compared to uncompressed GS methods is minimal (0.3 lower PSNR, 0.05 lower SSIM) [S1]. On SCARED, it achieves SSIM 0.826, PSNR 27.05, and LPIPS 0.297 [S1].
*   **Scalability:** The method is designed for dynamic scenes with significant deformation, such as surgical endoscopy [S1]. It may not be optimal for static scenes where simpler representations suffice.
*   **Strengths:** High compression ratio, real-time rendering, maintains high visual quality, suitable for resource-constrained environments [S1].
*   **Limitations:** Requires a pre-trained teacher model for distillation, increasing initial training time [S1]. Performance is highly dependent on the effectiveness of the pruning and condensation parameters [S1].

## Background
LGS was introduced by Liu et al. in the paper "LGS: A Light-Weight 4D Gaussian Splatting for Efficient Surgical Scene Reconstruction" [S1]. It was developed to address the challenges of rendering efficiency and memory efficiency in dynamic surgical scene reconstruction [S1]. The method builds upon the principles of 3D Gaussian Splatting and extends them to 4D by incorporating temporal dimensions, while introducing novel compression techniques to reduce the computational burden [S1].
