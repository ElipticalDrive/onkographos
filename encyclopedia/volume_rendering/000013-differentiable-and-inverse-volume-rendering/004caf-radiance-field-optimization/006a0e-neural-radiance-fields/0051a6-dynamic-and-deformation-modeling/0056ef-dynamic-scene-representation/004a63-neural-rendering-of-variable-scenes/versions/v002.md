# Neural Rendering of Variable Scenes

Also called: Variable Scene Methods

## Overview
Neural Rendering of Variable Scenes refers to methods that explicitly incorporate scene variation into the training phase by assuming a predefined range for each variable scene element encoded into a structured representation [S1]. Unlike Neural Irradiance Volumes (NIV) which do not explicitly model higher-order interactions between dynamic objects and the scene, these methods learn a surface radiance field for all possible permutations of scene variables [S1]. They are chosen when the goal is to capture complex, higher-order lighting interactions (such as path-traced global illumination effects) that static irradiance volumes may approximate less accurately at low capacities, though they suffer from significant performance and flexibility trade-offs [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Spatial coordinates $\mathbf{x}$, view direction $\mathbf{v}$, and a vector of scene variables $\mathbf{p}$ representing the current state of dynamic elements (e.g., object positions, light angles) [S1].
*   **Outputs:** Volume density $\sigma$ and view-dependent color $\mathbf{c}$ [S1].

**Data Structures:**
The method relies on a neural network (typically an MLP) that takes the concatenated input of spatial/view data and the encoded scene variables [S1]. The scene variables $\mathbf{p}$ are encoded into a structured representation, usually a vector [S1]. This vector is either used directly as input or processed through a learned encoding [S1].

**Steps:**
1.  **Encode Scene Variables:** The current state of dynamic scene elements is encoded into a vector $\mathbf{p}$ [S1].
2.  **Construct Input Vector:** The spatial coordinate $\mathbf{x}$ (and potentially view direction $\mathbf{v}$) is combined with the encoded scene variables $\mathbf{p}$ [S1].
3.  **Neural Prediction:** The combined vector is passed through the trained neural network to predict the volume density $\sigma$ and color $\mathbf{c}$ for the specific permutation of scene variables [S1].
4.  **Volume Rendering:** Standard volume rendering integration is performed using the predicted $\sigma$ and $\mathbf{c}$ to compute the final pixel color [S1].

**Parameters:**
*   **Scene Variable Range:** A predefined range for each variable scene element must be established during training [S1].
*   **Model Capacity:** The size of the neural network determines the ability to learn interactions. As capacity grows, error can drop below the theoretical lower bound of static irradiance volumes [S1].

**Pitfalls:**
*   **Retraining Requirement:** The model requires retraining whenever the set of scene parameters changes (e.g., objects added, removed, or modified) [S1].
*   **Performance:** Inference times exceed 100 ms, failing to achieve real-time performance [S1].
*   **Scaling:** Inference time scales with the number of dynamic objects, limiting the use of primitives with many scene variables, such as animated meshes [S1].
*   **Error vs. Capacity:** For a fixed model size, rendering error may be higher than NIV as the number of scene variables increases, because capacity is diverted to learning interactions on top of outgoing radiance [S1].

## Subtopics

### Higher-dimensional Irradiance Fields
This variant extends a pre-computed neural irradiance volume by adding inputs for known runtime-changing scene parameters (e.g., emitter positions) to avoid real-time representation updates and temporal artifacts [S1]. It is trained by randomly sampling the variable scene parameter during the training phase [S1]. It targets 1-2 variable parameters modeling dynamic phenomena, using frequency encoding [MST* 21] to add little inference overhead [S1]. To ensure artifact-free results, the hash table size encoding scene position is doubled to ~10MB [S1]. Implemented use cases include a rotating directional light source simulating a time-of-day cycle and a moving occluding object [S1]. Scaling to more than two scene variables at the same representational capacity causes visible reconstruction error, which could be resolved using learned encodings but introduces disadvantages noted in the main section [S1].

## Operating characteristics
*   **Time Complexity:** Inference times exceed 100 ms, failing to achieve real-time performance [S1]. Inference time scales with the number of dynamic objects present in the scene [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** At a model capacity of 1 MB, NIV captures color bleed from the static scene onto variable scene elements, while variable-scene methods do not [S1]. However, as model capacity grows, variable-scene methods can drop below the theoretical lower bound of irradiance volumes (error level of path-traced static irradiance field), producing shading effects resembling path-traced GI including higher-order interactions [S1].
*   **Strengths:** Can produce shading effects resembling path-traced global illumination, including higher-order interactions between variable parameters and the scene, which NIV may not capture as accurately at low capacities [S1].
*   **Limitations:** Requires retraining for parameter changes; slow inference; scales poorly with the number of dynamic objects; error increases relative to NIV as the number of scene variables increases for a fixed model size [S1].
*   **When to use:** When capturing high-fidelity higher-order lighting interactions is prioritized over real-time performance and flexibility, and the set of scene variables is fixed during deployment [S1].
*   **When not to use:** When real-time performance is required, or when the scene configuration (objects/parameters) changes dynamically after training [S1].

## Background
This approach is discussed in the context of comparing Neural Irradiance Volumes (NIV) with other neural rendering techniques that explicitly handle scene variation [S1]. The method is attributed to works such as [DPD22] and [SDR* 24], which are cited as examples of variable-scene methods [S1]. The comparison highlights that while NIV does not explicitly model higher-order interactions, variable-scene methods devote capacity to learning these interactions [S1].
