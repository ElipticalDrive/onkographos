# D-TensoRF

Also called: Dynamic Tensorial Radiance Fields

## Overview
D-TensoRF is a dynamic radiance field model that maps 3D location $\mathbf{x}$, viewing direction $\mathbf{d}$, and time instant $t$ to emitted color $\mathbf{c}$ and volume density $\sigma$ using factorized 4D/5D tensor grids [S1, unofficial]. It extends TensoRF by incorporating a time dimension and applying Matrix-Matrix (MM) decomposition to reduce memory complexity from $O(n^4)$ to $O(n^2)$ compared to naive 4D grid representations [S1, unofficial]. Unlike Deformable Neural Radiance Fields (Nerfies), which rely on explicit deformation fields to warp static coordinates, D-TensoRF models temporal dynamics directly within the tensor structure, augmented by smoothing regularization to enforce temporal dependency [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D spatial coordinates $\mathbf{x} = (x, y, z)$, viewing direction $\mathbf{d} = (\theta, \phi)$, and time instant $t$ [S1, unofficial].
*   **Outputs:** Volume density $\sigma$ and view-dependent color $\mathbf{c}$ [S1, unofficial].

**Data Structures:**
The model utilizes two primary grids, factorized via MM decomposition:
1.  **Geometry Grid ($G_\sigma$):** A 4D tensor with dimensions $I \times J \times K \times N$, where $I, J, K$ are spatial resolutions (X, Y, Z) and $N$ is the time axis resolution [S1, unofficial].
2.  **Appearance Grid ($G_c$):** A 5D tensor with dimensions $I \times J \times K \times N \times P$, where $P$ is the number of feature channels [S1, unofficial].

**MM Decomposition Layout:**
For a 4D tensor $T \in \mathbb{R}^{I \times J \times K \times N}$, MM decomposition expresses $T$ as a summation of outer products of matrix factors corresponding to pairs of modes [S1, unofficial]:
$$
T = \sum_{r=1}^{R_1} M_{r,1,2} \circ M_{r,3,4} + \sum_{r=1}^{R_2} M_{r,1,3} \circ M_{r,2,4} + \sum_{r=1}^{R_3} M_{r,2,3} \circ M_{r,1,4}
$$
where $M_{r,i,j} \in \mathbb{R}^{d_i \times d_j}$ is a matrix factor for modes $i$ and $j$, and $\circ$ denotes the outer product of the scalar values resulting from the interaction of the two matrices at specific indices [S1, unofficial].

**Parameters:**
*   **Components:** $R_\sigma$ for geometry, $R_c$ for appearance. $R_c$ is set to $3 \times R_\sigma$ [S1, unofficial].
*   **Time Resolution ($N_t$):** Set to $0.25 \times (\text{number of training images})$ [S1, unofficial].
*   **Initial Grid Resolution:** $64^3 \times N_t$ [S1, unofficial].
*   **Converting Function $S$:** A small MLP with two fully-connected layers and 128-channel hidden layers [S1, unofficial].
*   **Smoothing Regularization:** Window size $S=3$, smoothing degree $\sigma=0.5$ [S1, unofficial].

**Algorithm Steps:**

1.  **Initialize Grids:** Initialize geometry grid $G_\sigma$ and appearance grid $G_c$ with random values for their matrix and vector factors. Set initial spatial resolution to $64^3$ and time resolution $N_t = 0.25 \times N_{images}$ [S1, unofficial].
2.  **Compute Density ($\sigma$):** Evaluate $G_\sigma(\mathbf{x}, t)$ using MM decomposition. For each component $r$, compute the scalar value by multiplying the corresponding entries from the matrix factors (e.g., $M_{\sigma,r,X,Y}(x,y) \times M_{\sigma,r,Z,T}(z,t)$). Sum these products across all components [S1, unofficial].
    $$
    \sigma = \sum_{r=1}^{R_\sigma} \left( M_{\sigma,r,X,Y} \circ M_{\sigma,r,Z,T} + M_{\sigma,r,X,Z} \circ M_{\sigma,r,Y,T} + M_{\sigma,r,Y,Z} \circ M_{\sigma,r,X,T} \right)
    $$
    The result is the volume density $\sigma$ at $(\mathbf{x}, t)$ [S1, unofficial].
3.  **Compute Appearance Features ($G_c$):** Evaluate $G_c(\mathbf{x}, t)$ using MM decomposition. This involves matrix factors for appearance ($M_{c}$) and geometry ($M_{\sigma}$). The decomposition for $G_c$ is defined as [S1, unofficial]:
    $$
    G_c = \sum_{r=1}^{R_c} \left( M_{c,r,X,Y} \circ M_{c,r,Z,T} \circ \mathbf{b}_{3r-2} + M_{c,r,X,Z} \circ M_{c,r,Y,T} \circ \mathbf{b}_{3r-1} + M_{\sigma,r,Y,Z} \circ M_{c,r,X,T} \circ \mathbf{b}_{3r} \right)
    $$
    Here, $\mathbf{b}$ represents vector factors. The term $M_{c,r,X,Y} \circ M_{c,r,Z,T}$ produces a scalar value for the spatial-temporal interaction, which is then multiplied by the vector $\mathbf{b}$ [S1, unofficial].
4.  **Compute Color ($\mathbf{c}$):** Pass the appearance features $G_c(\mathbf{x}, t)$ and viewing direction $\mathbf{d}$ through the converting function $S$:
    $$
    \mathbf{c} = S(G_c(\mathbf{x}, t), \mathbf{d})
    $$
    $S$ is implemented as a 2-layer MLP with 128 hidden units [S1, unofficial].
5.  **Render:** Use differentiable volume rendering (standard emission-absorption model) to compute the pixel color $\hat{C}(\mathbf{r})$ from $\sigma$ and $\mathbf{c}$ along ray $\mathbf{r}$ [S1, unofficial].
6.  **Regularization:** Apply smoothing regularization $L_{smooth}$ to enforce temporal dependency on time-related factors (vectors $\mathbf{b}$ and matrices involving the time axis $T$) [S1, unofficial]. For a feature value $ev_{it}$ (or $em_{l,it}$ for matrices) at time index $it$:
    $$
    L_{smooth} = \sum_{r=1}^{R} \sum_{it=0}^{N} \left\| ev_{it} - \sum_{iw \in \text{window}(it,S)} w(it, iw) ev_{iw} \right\|^2
    $$
    The weight $w(it, iw)$ is a Gaussian kernel:
    $$
    w(it, iw) = \frac{K(it, iw)}{\sum_{i'w \in \text{window}(it,S)} K(it, i'w)}, \quad K(it, iw) = \exp\left(-\frac{(it - iw)^2}{2\sigma^2}\right)
    $$
    where $\sigma=0.5$ and window size $S=3$ [S1, unofficial]. Apply L1 regularization on all vector and matrix factors to prevent overfitting [S1, unofficial].
7.  **Optimization:** Minimize L2 rendering loss against 2D image supervision using gradient descent [S1, unofficial].
8.  **Upsampling:** Upsample vector and matrix factors linearly and bilinearly at training steps 2000, 3000, 4000, 5500, and 7000 [S1, unofficial]. Do not upsample the feature grid along the time axis [S1, unofficial].
9.  **Bounding Box Refinement:** At training step 2000, calculate a binary occupancy mask grid to create a more accurate bounding box, preventing unnecessary computation [S1, unofficial].

**Pseudocode:**

```python
import math

class D_TensoRF:
    def __init__(self, I, J, K, N, R_sigma, R_c, P=128):
        self.I, self.J, self.K, self.N = I, J, K, N
        self.R_sigma = R_sigma
        self.R_c = R_c
        self.P = P
        # Initialize factors with random values
        self.M_sigma_XY = [[math.random() for _ in range(J)] for _ in range(I)]
        self.M_sigma_ZT = [[math.random() for _ in range(N)] for _ in range(K)]
        self.M_sigma_XZ = [[math.random() for _ in range(K)] for _ in range(I)]
        self.M_sigma_YT = [[math.random() for _ in range(N)] for _ in range(J)]
        self.M_sigma_YZ = [[math.random() for _ in range(K)] for _ in range(J)]
        self.M_sigma_XT = [[math.random() for _ in range(N)] for _ in range(I)]

        self.M_c_XY = [[math.random() for _ in range(J)] for _ in range(I)]
        self.M_c_ZT = [[math.random() for _ in range(N)] for _ in range(K)]
        self.M_c_XZ = [[math.random() for _ in range(K)] for _ in range(I)]
        self.M_c_YT = [[math.random() for _ in range(N)] for _ in range(J)]
        self.M_c_XT = [[math.random() for _ in range(N)] for _ in range(I)]

        self.b = [[math.random() for _ in range(P)] for _ in range(3 * R_c)]

        # MLP S: 2 FC layers, 128 hidden
        self.W1 = [[math.random() for _ in range(128)] for _ in range(P)]
        self.W2 = [[math.random() for _ in range(3)] for _ in range(128)]

    def _quadrilinear(self, factor, x, y, z, t):
        # Assumes integer indices for discrete evaluation; 
        # continuous coordinates require fractional interpolation.
        return factor[int(x)][int(y)][int(z)][int(t)]

    def compute_sigma(self, x, y, z, t):
        term1 = self._quadrilinear(self.M_sigma_XY, x, y, z, t) * self._quadrilinear(self.M_sigma_ZT, x, y, z, t)
        term2 = self._quadrilinear(self.M_sigma_XZ, x, y, z, t) * self._quadrilinear(self.M_sigma_YT, x, y, z, t)
        term3 = self._quadrilinear(self.M_sigma_YZ, x, y, z, t) * self._quadrilinear(self.M_sigma_XT, x, y, z, t)
        return term1 + term2 + term3

    def compute_color(self, x, y, z, t, d):
        feat1 = self._quadrilinear(self.M_c_XY, x, y, z, t) * self._quadrilinear(self.M_c_ZT, x, y, z, t) * self.b[0::3]
        feat2 = self._quadrilinear(self.M_c_XZ, x, y, z, t) * self._quadrilinear(self.M_c_YT, x, y, z, t) * self.b[1::3]
        feat3 = self._quadrilinear(self.M_sigma_YZ, x, y, z, t) * self._quadrilinear(self.M_c_XT, x, y, z, t) * self.b[2::3]
        features = feat1 + feat2 + feat3
        # MLP S
        h = [max(0, sum(features[j] * self.W1[j][k] for j in range(self.P))) for k in range(128)]
        return [sum(h[k] * self.W2[k][m] for k in range(128)) for m in range(3)]

    def smoothing_loss(self, factors, time_axis_idx):
        S_window = 3
        sigma_smooth = 0.5
        loss = 0.0
        for r in range(len(factors)):
            for it in range(self.N):
                window_indices = [max(0, it - 1), it, min(self.N - 1, it + 1)]
                weights = []
                for iw in window_indices:
                    k_val = math.exp(-((it - iw) ** 2) / (2 * sigma_smooth ** 2))
                    weights.append(k_val)
                w_sum = sum(weights)
                w = [w_val / w_sum for w_val in weights]
                target = factors[r][time_axis_idx][it]
                predicted = sum(w[i] * factors[r][time_axis_idx][window_indices[i]] for i in range(3))
                loss += (target - predicted) ** 2
        return loss

    def forward(self, rays):
        results = []
        for ray in rays:
            x, y, z, theta, phi, t = ray
            d = (theta, phi)
            sigma = self.compute_sigma(x, y, z, t)
            color = self.compute_color(x, y, z, t, d)
            results.append((sigma, color))
        return results
```

## Operating characteristics
*   **Memory Complexity:** MM decomposition reduces memory complexity from $O(n^4)$ to $O(n^2)$ compared to a naive 4D grid representation [S1, unofficial].
*   **Performance:** The MLP converting function $S$ consistently shows better results than Spherical Harmonics (SH) [S1, unofficial].
*   **Hardware:** Evaluated on a single GeForce RTX 3090 GPU [S1, unofficial].
*   **Strengths:** Compact representation for dynamic scenes; effective handling of temporal dependencies via smoothing regularization; efficient memory usage compared to dense 4D grids [S1, unofficial].
*   **Limitations:** Smoothing regularization parameters ($S=3, \sigma=0.5$) are fixed and not learned [S1, unofficial].
*   **When to use:** Suitable for dynamic scenes with continuous motion where memory efficiency is critical [S1, unofficial].
*   **When not to use:** Not given in the sources.

## Background
D-TensoRF was introduced in the paper "D-TensoRF: Tensorial Radiance Fields for Dynamic Scenes" [S1, unofficial]. It extends the TensoRF method, which uses tensor decomposition for static scenes, to handle dynamic content by adding a time dimension [S1, unofficial]. The method was developed to address the limitations of existing dynamic radiance field models in terms of memory efficiency and representation capacity [S1, unofficial]. It builds on the principles of differentiable volume rendering and tensor factorization [S1, unofficial].
