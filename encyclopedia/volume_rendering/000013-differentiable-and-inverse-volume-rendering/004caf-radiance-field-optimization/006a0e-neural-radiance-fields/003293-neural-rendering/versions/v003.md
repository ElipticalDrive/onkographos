# Neural Rendering

Also called: Learned Differentiable Rendering

## Overview
Neural rendering is a method that learns the rendering process directly from data rather than relying on handcrafted analytical differentiation of physical rendering equations [S1, unofficial]. It jointly trains a scene generation network and a rendering network by minimizing image reconstruction error, allowing the system to produce high-quality, photorealistic images that can be indistinguishable from real-world captures [S1, unofficial]. Unlike traditional differentiable rendering which explicitly computes gradients through geometric primitives, neural rendering bypasses explicit differentiation by learning the input-output mapping of the renderer, though it often suffers from limited generalization to unseen scenes or multi-object compositions [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A dataset of images (and optionally camera poses) representing the target scene or domain.
*   **Outputs:** A trained pair of neural networks: a scene representation network (encoding the scene) and a rendering network (mapping the representation to pixel colors).

**Data Structures:**
*   **Scene Representation Network ($N_{scene}$):** A neural network (e.g., MLP or CNN) that outputs a latent feature vector or volumetric field value for a given 3D coordinate and viewing direction.
*   **Rendering Network ($N_{render}$):** A neural network that takes the output of $N_{scene}$ and camera parameters to predict the final pixel color $\hat{C}$.
*   *Note:* The specific architecture (e.g., MLP vs. Voxel Grid) is not fixed by the definition of Neural Rendering itself but is chosen based on the inductive biases applied [S1, unofficial].

**Steps:**
1.  **Scene Encoding:** For a given ray $\mathbf{r}$, sample points $\mathbf{x}_i$. Pass $\mathbf{x}_i$ and viewing direction $\mathbf{d}$ through the Scene Representation Network to obtain features $\mathbf{f}_i$.
2.  **Rendering:** Pass features $\mathbf{f}_i$ and camera parameters through the Rendering Network to predict color contributions $\hat{\mathbf{c}}_i$.
3.  **Integration:** Combine $\hat{\mathbf{c}}_i$ into a final image pixel $\hat{C}(\mathbf{r})$. This integration may use standard volume rendering equations or a learned aggregation function, depending on the specific implementation [S1, unofficial].
4.  **Loss Calculation:** Compute the reconstruction error between the rendered image $\hat{I}$ and the ground truth image $I$ (e.g., using Mean Squared Error or LPIPS).
5.  **Optimization:** Update the parameters of both $N_{scene}$ and $N_{render}$ using gradient descent to minimize the loss. The gradients are computed via backpropagation through the entire joint network [S1, unofficial].

**Pitfalls:**
*   **Generalization:** The method struggles to generalize to scenes significantly different from the training data [S1, unofficial].
*   **Scaling:** Scaling to scenes composed of multiple distinct objects is limited [S1, unofficial].
*   **Editability:** The ability for humans to modify the generated scene is restricted due to the lack of explicit semantic or geometric structure [S1, unofficial].

## Subtopics

### Deferred Neural Rendering
Deferred Neural Rendering is a variant where the rendering process is decoupled into separate stages, often leveraging the learned representation to optimize specific rendering passes or attributes after the initial neural rendering step. This allows for more flexible post-processing and optimization of rendering effects without retraining the core scene representation [S1, unofficial].

### [Rendering-Invariant State Predictor (RISP)](15076-rendering-invariant-state-predictor-risp.md)
RISP is a neural network $N_\theta$ that acts as an inverse renderer, mapping an input image $I$ to a predicted state $\hat{s}$ that is invariant to rendering parameters $\psi$. It solves the problem of optimizing physical system parameters from video by replacing sensitive image-space losses with robust state-space losses, allowing gradient-based optimization to succeed even when source and target rendering domains (e.g., lighting, materials) differ vastly. Unlike direct image-space optimization which traps gradient descent in local minima under domain shift, RISP enables optimization in a rendering-invariant state space.

### [Equivariant Neural Rendering](15993-equivariant-neural-rendering.md)
Equivariant Neural Rendering is a framework for learning neural scene representations directly from 2D images without requiring 3D ground truth or camera pose supervision at inference time. It solves the problem of novel view synthesis by enforcing that the learned implicit scene representation transforms like a real 3D scene, specifically satisfying the equivariance relation $T_X g(z) = g(T_Z z)$. Unlike sibling methods such as Rendering-Invariant State Predictor (RISP) which may rely on different invariance assumptions, this method explicitly models 3D rotation equivariance using deep voxel grids, allowing the model to generalize across camera transformations without absolute pose alignment.

## Operating characteristics
*   **Strengths:** Capable of generating high-quality images indistinguishable from real-world ones by learning from data, bypassing the need for accurate physical modeling [S1, unofficial].
*   **Limitations:** Limited generalization to unseen scenes, poor scalability to multi-object scenes, and low editability by humans [S1, unofficial].
*   **Performance:** Efficiency can be improved with coarse-to-fine sampling and importance sampling near boundaries [S1, unofficial].
*   **Usage:** Novel view synthesis, semantic photo manipulation, facial/body reenactment, relighting, free-viewpoint video, and photo-realistic avatar creation [S1, unofficial].

## Background
The concept was introduced by Eslami et al. [58] as an alternative to handcrafting rendering differentiation, proposing to learn the rendering process from data [S1, unofficial]. It has become a prominent area of research, often combined with inductive biases for 3D scenes to improve performance [S1, unofficial].
