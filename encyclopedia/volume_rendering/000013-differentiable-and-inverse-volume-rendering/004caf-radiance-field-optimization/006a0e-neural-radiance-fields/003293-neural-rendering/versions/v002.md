# Neural Rendering

Also called: Learned Rendering, Data-Driven Rendering

## Overview
Neural rendering is a method that learns the rendering process from data rather than relying on handcrafted differentiable graphics pipelines [S1, unofficial]. It jointly trains a scene generation network and a rendering network to minimize image reconstruction error, enabling the synthesis of photorealistic novel views and effects like relighting or reenactment [S1, unofficial]. Unlike traditional differentiable rendering which uses explicit physical models, neural rendering approximates the complex mapping from scene parameters to pixel values using neural networks, allowing it to capture visual details that are difficult to model analytically [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** Training dataset consisting of images (and potentially associated camera poses or scene parameters) and a neural network architecture.
- **Output:** A trained model capable of generating novel images of the scene or object.

**Data Structures:**
- **Scene Generation Network ($N_{scene}$):** A neural network (e.g., MLP, CNN, or transformer) that outputs a neural scene representation. This representation encodes the geometry, appearance, and potentially dynamic properties of the scene. The specific format of this representation (e.g., implicit fields, feature grids, or latent codes) depends on the implementation but is treated as the output of $N_{scene}$ [S1, unofficial].
- **Rendering Network ($N_{render}$):** A neural network that takes the scene representation and camera/view parameters as input and outputs the final pixel colors. In many implementations, these two networks are combined or tightly coupled [S1, unofficial].

**Steps:**
1. **Scene Representation Learning:** The scene generation network $N_{scene}$ is initialized and trained to produce a compact neural representation of the target scene or object from the input data. This step often involves learning latent codes or implicit functions that describe the 3D structure and material properties [S1, unofficial].
2. **Rendering Network Training:** The rendering network $N_{render}$ is initialized. It takes the scene representation from $N_{scene}$ and the desired viewing parameters (e.g., camera position, orientation, lighting conditions) as input.
3. **Joint Optimization:** The networks are jointly trained by minimizing the image reconstruction error. The loss function typically compares the rendered image $\hat{I}$ with the ground-truth image $I$ from the training set:
   $$
   \mathcal{L} = \| \hat{I} - I \|_2^2
   $$
   Gradients are backpropagated through the rendering network and the scene generation network to update their parameters [S1, unofficial].
4. **Novel View Synthesis:** Once trained, the rendering network can generate images for new camera viewpoints or lighting conditions by feeding the learned scene representation with new view parameters [S1, unofficial].

**Parameters:**
- **Learning Rate:** Standard values for neural network optimization (e.g., $10^{-3}$ to $10^{-5}$) [G].
- **Network Architecture:** Depth, width, and activation functions of $N_{scene}$ and $N_{render}$ are hyperparameters that must be tuned for the specific scene complexity [G].

**Edge Cases and Pitfalls:**
- **Generalization:** The method struggles to generalize to scenes that differ significantly from the training data [S1, unofficial].
- **Scalability:** Scaling to scenes composed of multiple objects or large-scale environments is limited due to the capacity of the neural representation [S1, unofficial].
- **Human Modification:** The ability for humans to directly modify the scene (e.g., changing object positions or materials) is limited because the scene is encoded as a black-box neural representation rather than explicit geometry [S1, unofficial].

## Subtopics

### [Rendering-Invariant State Predictor (RISP)](15076-rendering-invariant-state-predictor-risp.md)
RISP is a neural network $N_\theta$ that acts as an inverse renderer, mapping an input image $I$ to a predicted state $\hat{s}$ that is invariant to rendering parameters $\psi$. It solves the problem of optimizing physical system parameters from video by replacing sensitive image-space losses with robust state-space losses, allowing gradient-based optimization to succeed even when source and target rendering domains (e.g., lighting, materials) differ vastly. Unlike direct image-space optimization which traps gradient descent in local minima under domain shift, RISP enables optimization in a rendering-invariant state space.

## Operating characteristics
- **Time Complexity:** Training time depends on the complexity of the neural networks and the size of the dataset. Inference time is generally fast once trained, as it involves a forward pass through the neural networks [S1, unofficial].
- **Memory Complexity:** Memory usage is determined by the size of the neural networks and the scene representation. Large-scale scenes may require significant memory to store the network weights and intermediate activations [S1, unofficial].
- **Strengths:** Capable of generating high-quality, photorealistic images that are indistinguishable from real-world ones, especially when learning from real-world data [S1, unofficial]. It can capture complex visual phenomena that are difficult to model with handcrafted renderers [S1, unofficial].
- **Limitations:** Limited generalization to unseen scenes, poor scalability to multi-object scenes, and lack of explicit control for human modification [S1, unofficial].
- **When to Use:** Suitable for applications where photorealism is prioritized over explicit scene control, such as novel view synthesis, facial reenactment, and relighting [S1, unofficial].
- **When Not to Use:** Not suitable for applications requiring explicit scene manipulation, generalization to diverse scenes, or scalability to large multi-object environments [S1, unofficial].

## Background
Neural rendering was proposed by Eslami et al. [58] as an alternative to handcrafted rendering differentiation, aiming to learn the rendering process directly from data [S1, unofficial]. The approach has gained traction with advances in neural networks, enabling applications in novel view synthesis, semantic photo manipulation, facial and body reenactment, relighting, free-viewpoint video, and the creation of photo-realistic avatars [S1, unofficial]. A key direction for improvement involves adding inductive biases for 3D scenes and rendering into neural networks to address generalization and scalability issues [S1, unofficial]. Combining differentiable renderers with inductive biases and neural rendering is considered a promising research area [S1, unofficial].
