# Rendering-Invariant State Predictor (RISP)

Also called: RISP (Rendering-Invariant State Predictor), RISP Network Training, RISP network, Rendering-Invariant State Predictor training, rendering-invariant state-prediction network

## Overview
RISP is a neural network $N_\theta$ that acts as an inverse renderer, mapping an input image $I$ to a predicted state $\hat{s}$ that is invariant to rendering parameters $\psi$ [S1, unofficial]. It solves the problem of optimizing physical system parameters from video by replacing sensitive image-space losses with robust state-space losses, allowing gradient-based optimization to succeed even when source and target rendering domains (e.g., lighting, materials) differ vastly [S1, unofficial]. Unlike direct image-space optimization which traps gradient descent in local minima under domain shift, RISP enables optimization in a rendering-invariant state space [S1, unofficial].

## How it works

### Inputs and Outputs
*   **Input:** An image sequence $\{I_i\}$ generated by a differentiable renderer from a physical simulation, or a reference image sequence $\{I_i^{\text{ref}}\}$ from a target domain.
*   **Output:** A predicted state sequence $\{\hat{s}_i\}$ where $\hat{s}_i = N_\theta(I_i)$.

### Data Structures
The RISP network $N_\theta$ is a standard neural network (e.g., CNN or MLP) parameterized by weights $\theta$.
*   **State Vector $s$:** Encodes the physical state of the system (e.g., position, velocity, orientation).
*   **Action Vector $a$:** Encodes control inputs applied at each time step.
*   **System Parameters $\phi$:** Vector encoding intrinsic system properties (e.g., mass, inertia, elasticity) [S1, unofficial].
*   **Rendering Parameters $\psi$:** Vector encoding rendering configurations (e.g., light intensity, material reflectance, background color) [S1, unofficial].
*   **Time Steps $N$:** The number of steps in a simulation rollout [S1, unofficial].

### Simulation and Rendering Workflow
The method relies on a differentiable simulation engine $M_\phi$ and a differentiable rendering engine $R_\psi$ [S1, unofficial].

1.  **Simulation:** Given an initial state $s_0$ and a sequence of actions $\{a_i\}$, the state at step $i+1$ is computed as:
    $$ s_{i+1} = M_\phi(s_i, a_i), \quad \forall i = 0, 1, \dots, N-1 $$
    where $\phi$ encodes system parameters [S1, unofficial].

2.  **Rendering:** The state $s_i$ is rendered to an image $I_i$:
    $$ I_i = R_\psi(s_i), \quad \forall i = 0, 1, \dots, N $$
    where $\psi$ encodes rendering parameters [S1, unofficial].

3.  **Compact Form:** The workflow is expressed as:
    $$ \{I_i\} = R_\psi [ M_\phi (s_0, \{a_i\}) ] $$
    [S1, unofficial].

### Training the RISP Network
The network $N_\theta$ is pre-trained and fixed before the main optimization task. It is trained to minimize a combined loss $L_{\text{train}}$ consisting of a prediction error term $L_{\text{error}}$ and a regularization term $L_{\text{reg}}$ [S1, unofficial].

#### 1. Domain Randomization (Data Generation)
Sample pairs of states $s_j$ and rendering parameters $\psi_j$ from their respective distributions. Render images $I_j = R_{\psi_j}(s_j)$ to create a dataset $\mathcal{D} = \{(s_j, \psi_j, I_j)\}$ [S1, unofficial].

#### 2. Prediction Error Loss ($L_{\text{error}}$)
Minimize the L1 distance between the true state $s_j$ and the network prediction $N_\theta(I_j)$:
$$ L_{\text{error}}(\theta, \mathcal{D}) = \sum_{(s_j, \psi_j, I_j) \in \mathcal{D}} \| s_j - N_\theta(I_j) \|_1 $$
This ensures the network accurately predicts the state for specific instances [S1, unofficial].

#### 3. Rendering Gradient Regularization ($L_{\text{reg}}$)
To enforce invariance to $\psi$, the network's output should not change with respect to $\psi$. The condition is $\frac{\partial N_\theta(R_\psi(s))}{\partial \psi} \equiv 0$ [S1, unofficial]. The regularizer is the Frobenius norm of this Jacobian:
$$ L_{\text{reg}}(\theta, \mathcal{D}) = \sum_{(s_j, \psi_j, I_j) \in \mathcal{D}} \left\| \frac{\partial N_\theta(R_{\psi_j}(s_j))}{\partial \psi_j} \right\|_F $$
Using the chain rule:
$$ \frac{\partial N_\theta(R_{\psi_j}(s_j))}{\partial \psi_j} = \frac{\partial N_\theta(I_j)}{\partial I_j} \frac{\partial I_j}{\partial \psi_j} $$
*   $\frac{\partial N_\theta(I_j)}{\partial I_j}$ is computed via standard reverse-mode autodiff in the network [S1, unofficial].
*   $\frac{\partial I_j}{\partial \psi_j}$ is obtained from the differentiable renderer [S1, unofficial].

#### 4. Total Training Loss
$$ L_{\text{train}}(\theta, \mathcal{D}) = L_{\text{error}} + \gamma L_{\text{reg}} $$
where $\gamma$ is a regularization weight [S1, unofficial].

**Pitfall:** Optimizing $L_{\text{reg}}$ alone leads to a trivial solution where the network predicts constant states. It must be combined with $L_{\text{error}}$ to balance accuracy and invariance [S1, unofficial].

### Optimization for Parameter Estimation
Given a reference image sequence $\{I_i^{\text{ref}}\}$ from a target domain with unknown parameters, optimize the initial state $s_0$, action sequence $\{a_i\}$, system parameters $\phi$, and rendering parameters $\psi$ to minimize the state-space loss:
$$ \min_{s_0, \{a_i\}, \phi, \psi} L(N_\theta(\{I_i^{\text{ref}}\}), N_\theta(\{I_i\})) \quad \text{s.t.} \quad \{I_i\} = R_\psi [ M_\phi (s_0, \{a_i\}) ] $$
[ S1].

```python
import torch
import torch.nn as nn
import torch.optim as optim

# Assume differentiable_renderer is an instance of a differentiable rendering engine
# Assume differentiable_simulator is an instance of a differentiable simulation engine

def train_risp_network(N_theta, differentiable_renderer, dataset_D, gamma, num_epochs):
    """
    Pre-trains the RISP network N_theta.
    
    Args:
        N_theta: Neural network module.
        differentiable_renderer: Differentiable renderer R_psi.
        dataset_D: List of tuples (s_j, psi_j, I_j).
        gamma: Regularization weight.
        num_epochs: Number of training epochs.
    """
    optimizer = optim.Adam(N_theta.parameters(), lr=1e-3)
    
    for epoch in range(num_epochs):
        total_loss = 0.0
        for s_j, psi_j, I_j in dataset_D:
            # Forward pass: Network prediction
            s_hat = N_theta(I_j)
            
            # L_error: L1 loss between true state and prediction
            loss_error = torch.mean(torch.abs(s_j - s_hat))
            
            # L_reg: Gradient of network output w.r.t rendering parameters
            # Requires computing Jacobian-vector products or full Jacobian
            # dN/dI * dI/dpsi
            
            # 1. dN/dI: Gradient of network output w.r.t input image
            # We need the Jacobian of N_theta w.r.t I_j.
            # Since N_theta(I) outputs a vector s_hat, and I_j is an image,
            # we compute the Jacobian matrix J_N = d(s_hat)/d(I_j).
            # In practice, this is often done via Jacobian-vector products 
            # or by computing the full Jacobian if dimensions are small.
            
            # 2. dI/dpsi: Gradient of rendered image w.r.t rendering parameters
            # This is provided by the differentiable renderer.
            # I_j = R_psi(s_j). We need d(I_j)/d(psi_j).
            # Note: psi_j might be a vector.
            
            # Efficient computation of || dN/d(psi) ||_F
            # dN/d(psi) = (dN/dI) @ (dI/dpsi)
            
            # Let's compute the Jacobian of N_theta w.r.t I_j
            # shape: (dim_s, dim_I)
            # Using torch.autograd.functional.jacobian if feasible, 
            # or custom loop for efficiency.
            try:
                J_N = torch.autograd.functional.jacobian(N_theta, I_j)
            except Exception:
                # Fallback or approximation if jacobian is too large
                # [G] In high-dimensional image spaces, full Jacobian is expensive.
                # The paper suggests O(|s||theta|) time using pre-computed data 
                # and specific gradient propagation tricks, avoiding second-order 
                # gradients in the renderer.
                # Here we assume a simplified access to the gradient term.
                J_N = None 

            # Compute dI/dpsi
            # I_j is already computed. We need gradients w.r.t psi_j.
            # differentiable_renderer provides dI/dpsi.
            dI_dpsi = differentiable_renderer.get_gradient_wrt_params(psi_j, s_j)
            
            # Combine: dN/dpsi = J_N @ dI_dpsi
            # If J_N is (dim_s, dim_I) and dI_dpsi is (dim_I, dim_psi),
            # result is (dim_s, dim_psi).
            if J_N is not None:
                dN_dpsi = torch.matmul(J_N, dI_dpsi)
                loss_reg = torch.norm(dN_dpsi, p='fro')
            else:
                # [G] Placeholder for efficient Jacobian computation method 
                # described in Theorem 1 of [S1, unofficial].
                loss_reg = torch.tensor(0.0)

            loss = loss_error + gamma * loss_reg
            
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            total_loss += loss.item()
        
        print(f"Epoch {epoch}, Loss: {total_loss / len(dataset_D)}")

def optimize_parameters(N_theta, differentiable_renderer, differentiable_simulator, I_ref, s0_init, a_init, phi_init, psi_init):
    """
    Optimizes system parameters using the pre-trained RISP network.
    
    Args:
        N_theta: Pre-trained RISP network.
        differentiable_renderer: Differentiable renderer R_psi.
        differentiable_simulator: Differentiable simulator M_phi.
        I_ref: Reference image sequence (tensor of shape [N, H, W, C]).
        s0_init: Initial state guess.
        a_init: Initial action sequence guess.
        phi_init: Initial system parameters guess.
        psi_init: Initial rendering parameters guess.
        
    Returns:
        Optimized s0, a, phi, psi.
    """
    # Make parameters trainable
    s0 = s0_init.clone().detach().requires_grad_(True)
    a = a_init.clone().detach().requires_grad_(True)
    phi = phi_init.clone().detach().requires_grad_(True)
    psi = psi_init.clone().detach().requires_grad_(True)
    
    optimizer = optim.Adam([s0, a, phi, psi], lr=1e-3)
    
    # Assume N is the number of time steps
    N = len(I_ref)
    
    for epoch in range(1000): # Example iteration count
        optimizer.zero_grad()
        
        # 1. Simulate states
        s_current = s0
        states = [s_current]
        actions_list = []
        
        for i in range(N):
            # Get action a_i
            # a might be a sequence tensor [N, dim_a]
            a_i = a[i]
            actions_list.append(a_i)
            
            # Simulate next state
            s_next = differentiable_simulator.step(s_current, a_i, phi)
            states.append(s_next)
            s_current = s_next
            
        states_tensor = torch.stack(states) # Shape [N+1, dim_s]
        
        # 2. Render images
        # differentiable_renderer.render(states_tensor, psi)
        # Returns image sequence {I_i}
        I_gen = differentiable_renderer.render(states_tensor, psi)
        
        # 3. Predict states using RISP
        # N_theta takes images and outputs states
        # I_gen shape: [N+1, H, W, C]
        # N_theta(I) -> s_hat
        s_hat_gen = N_theta(I_gen)
        
        # 4. Predict states for reference images
        s_hat_ref = N_theta(I_ref)
        
        # 5. Compute loss in state space
        # L(N_theta(I_ref), N_theta(I_gen))
        # Using L1 or L2 loss between predicted states
        loss = torch.mean(torch.abs(s_hat_ref - s_hat_gen))
        
        loss.backward()
        optimizer.step()
        
        if epoch % 100 == 0:
            print(f"Optimization Epoch {epoch}, Loss: {loss.item()}")
            
    return s0, a, phi, psi
```

### Subtopics
*   **Direct Image-Space Optimization:** Optimizes pixel-wise loss directly between rendered and reference images. Fails when rendering domains differ significantly due to non-linearity and local minima [S1, unofficial].
*   **Alternative Regularizer (Error Invariance):** Encourages the *prediction error* to be rendering-invariant rather than the output itself. Computed as $\sum \| \frac{\partial L_{\text{error}}}{\partial \psi_j} \|$. Takes $O(|\theta|)$ time vs $O(|s||\theta|)$ for the original regularizer, with comparable performance [S1, unofficial].

## Operating characteristics

### Time and Memory Complexity
*   **Training $L_{\text{reg}}$:** Computing the gradient of $L_{\text{reg}}$ w.r.t. network parameters $\theta$ takes $O(|s||\theta|)$ time per image [S1, unofficial].
*   **Memory:** Requires pre-computed data occupying $O(\sum_j |\psi_j||I_j|)$ space [S1, unofficial].
*   **Alternative Regularizer:** The alternative regularizer (Eqn. 12 in [S1, unofficial]) takes $O(|\theta|)$ time to compute gradients, making it significantly faster for large state spaces [S1, unofficial].
*   **Second-Order Gradients:** The method does **not** require second-order gradients in the renderer $R$, which exceeds the capability of most existing differentiable renderers [S1, unofficial].

### Performance and Scaling
*   **Performance:** Achieves significantly lower reconstruction errors and better generalizability across unknown rendering configurations compared to existing methods [S1, unofficial].
*   **Scaling:** The $O(|s||\theta|)$ cost is affordable for small rigid-body systems ($|s| < 10$) but not scalable for large deformable bodies without the alternative regularizer [S1, unofficial].
*   **Robustness:** State-space optimization is fairly robust to random initialization, whereas image-space optimization traps gradient descent in local minima if initial images are not reasonably similar to references [S1, unofficial].

### Strengths and Limitations
*   **Strengths:** Decouples state estimation from rendering artifacts; enables cross-domain parameter estimation; works with black-box differentiable simulators [S1, unofficial].
*   **Limitations:** Requires a differentiable renderer; pre-training data must span the distribution of rendering parameters; direct image-space optimization is not viable for large domain shifts [S1, unofficial].

## Background

### Origin
The Rendering-Invariant State Predictor (RISP) was introduced in the paper "RISP: Rendering-Invariant State Predictor with Differentiable Simulation and Rendering for Cross-Domain Parameter Estimation" [S1, unofficial].

### History and Development
RISP was developed to address the limitations of $\nabla$Sim, a state-of-the-art method that optimizes physical parameters by minimizing image-space losses. While $\nabla$Sim works for moderately different rendering domains, it fails when domains are vastly different. RISP introduces the concept of an "inverse renderer" to map images to a rendering-invariant state space, enabling robust optimization [S1, unofficial].

### Usage
RISP has been evaluated in rigid-body and deformable-body simulation environments for tasks including state estimation, system identification, imitation learning, and visuomotor control. It has also been applied to real-world quadrotor video inference [S1, unofficial].
