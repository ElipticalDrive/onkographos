# NLR++ Training Loss and Supervision

Also called: NLR++, NLR++ Loss, NLR++ Optimization

## Overview
NLR++ Training Loss and Supervision defines the end-to-end differentiable optimization objective for the Neural Lumigraph Representation (NLR++), which jointly reconstructs shape via a Signed Distance Function (SDF) and appearance via a radiance field from posed 2D images [S1, unofficial]. It distinguishes itself from standard volumetric rendering losses by introducing a soft mask loss on the SDF minimum along rays and a specific training schedule that decouples shape approximation from feature refinement to accelerate convergence [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:** A batch of $k \le N$ input images $\{I_n\}_{n=1}^k$, their corresponding binary object masks $\{M_n\}_{n=1}^k$, and viewpoint parameters $\{C_n\}_{n=1}^k$. The model parameters are $\Phi_\theta$ (SDF), $E_\xi$ (encoder), $D_\psi$ (decoder), and $\Gamma_\zeta$ (aggregator).
*   **Outputs:** A synthesized target image $\hat{I}_t$, a rendered mask $\hat{M}_t$, and the updated model parameters after minimizing the total loss.

**Data Structures**
*   **SDF ($\Phi_\theta$):** An implicit function mapping 3D coordinates to signed distance values. Initialized as a unit sphere of radius 0.5 using a pre-trained SIREN [S1, unofficial].
*   **Radiance Field:** Defined by the encoder $E$, decoder $D$, and aggregator $\Gamma$, which map view-dependent features to color.
*   **Ray Sampling:** For each pixel $p$, a ray is traced from the camera center defined by $C_t$.

**Numbered Steps**
1.  **Batch Sampling:** For each training iteration, sample a set of $k \le N$ images $\{I_n\}_{n=1}^k$ from the available $N$ input images.
2.  **Target Selection:** Designate one image as the primary ground-truth target $I_t$, with its mask $M_t$ and viewpoint $C_t$.
3.  **Multi-Target Gradient Computation:** To improve gradient accuracy and utilize GPU memory, treat $l < k$ images in the batch as target images. Compute gradients for each of these $l$ targets using the other images in the batch as input context [S1, unofficial].
4.  **Synthesis:** Generate the synthesized target image $\hat{I}_t$ and rendered mask $\hat{M}_t$ from viewpoint $C_t$ using the NLR++ image formation model [S1, unofficial].
5.  **Loss Calculation:** Compute the total loss $\mathcal{L}$ as the sum of image reconstruction loss, soft mask loss, and eikonal regularization [S1, unofficial].
6.  **Scheduled Shape Supervision:** Enforce shape-related losses ($\mathcal{L}_M$ and $\mathcal{L}_E$) only for the first $t_1$ iterations, and then every $t_2$ iterations thereafter. This allows initial shape approximation before refining with better feature encoding [S1, unofficial].
7.  **Optimization:** Update parameters $\Theta = [\xi, \psi, \zeta, \theta]$ using the Adam optimizer [S1, unofficial].

**Formulas**
The total loss is defined as [S1, unofficial]:
$$
\mathcal{L}(\{\hat{I}_t, \hat{M}_t\}, \{I_t, M_t\}, \Phi_\theta) = \mathcal{L}_R(\hat{I}_t, \{I_t, M_t\}) + \lambda_1 \mathcal{L}_M(\Phi_\theta, M_t) + \lambda_2 \mathcal{L}_E(\Phi_\theta)
$$

1.  **Image Reconstruction Loss ($\mathcal{L}_R$):** A masked L1 loss on rendered images [S1, unofficial]:
    $$
    \mathcal{L}_R(\hat{I}_t, \{I_t, M_t\}) = \frac{1}{P} \sum_{p | M_t[p]=1} |I_t[p] - \hat{I}_t[p]|
    $$
    where $P$ is the number of pixels where $M_t[p]=1$.

2.  **Soft Mask Loss ($\mathcal{L}_M$):** Applied to bootstrap neural shape learning from object masks [S1, unofficial]:
    $$
    \mathcal{L}_M(\Phi_\theta, M_t) = \frac{1}{\alpha \sum_{p | M_t[p]=0 \lor \Phi_{\min}[p]<\tau} M_t[p]} \sum_{p | M_t[p]=0 \lor \Phi_{\min}[p]<\tau} \text{BCE}(\text{sigmoid}(-\alpha \Phi_{\min}[p]), M_t[p])
    $$
    where:
    *   $\Phi_{\min}[p]$ is the minimum SDF value along the ray traced from pixel $p$.
    *   $\tau$ is a threshold for whether the zero level set $L_0(\Phi_\theta)$ has been intersected.
    *   $\alpha$ is a softness hyperparameter.
    *   $\text{BCE}(y, \hat{y}) = -[y \log(\hat{y}) + (1-y) \log(1-\hat{y})]$ is the Binary Cross Entropy.

3.  **Eikonal Regularization ($\mathcal{L}_E$):** Enforces the eikonal constraint on randomly sampled points $p_i$ in a unit cube containing the scene [S1, unofficial]:
    $$
    \mathcal{L}_E(\Phi_\theta) = \frac{1}{P} \sum_{i=0}^{P} ||(||\nabla_{p_i} \Phi_\theta(p_i)||^2 - 1)||^2_2
    $$

**Parameters**
*   $\alpha$: Softness hyperparameter for mask loss. Starting value: 50 [S1, unofficial].
*   $\tau$: Threshold for zero level set intersection. Starting value: $1 \times 10^{-3}$ [S1, unofficial].
*   $\lambda_1$: Weight for mask loss. Calculated as $1 \times 10^2 / \alpha$ [S1, unofficial].
*   $\lambda_2$: Weight for eikonal regularization. Starting value: 3 [S1, unofficial].
*   $t_1$: Number of initial iterations to enforce shape losses. Starting value: 50 [S1, unofficial].
*   $t_2$: Frequency (in iterations) to enforce shape losses after $t_1$. Starting value: 7 [S1, unofficial].
*   Learning Rates: Adam optimizer with starting LR $1 \times 10^{-4}$ for $\Phi$ and $5 \times 10^{-4}$ for $E, D, \Gamma$ [S1, unofficial].

**Pseudocode**
```python
def train_nlr_plus_plus(batch_images, batch_masks, batch_cameras, 
                        model_params, optimizer, hyperparams):
    """
    Performs one training step for NLR++.
    
    Args:
        batch_images: List of k images {I_n}
        batch_masks: List of k masks {M_n}
        batch_cameras: List of k camera parameters {C_n}
        model_params: Parameters [xi, psi, zeta, theta] for E, D, Gamma, Phi
        optimizer: Adam optimizer instance
        hyperparams: Dict containing alpha, tau, lambda1, lambda2, t1, t2, l, k
        
    Returns:
        loss_value: Scalar loss value
    """
    k = len(batch_images)
    l = hyperparams['l'] # Number of target images in batch, l < k
    t1 = hyperparams['t1']
    t2 = hyperparams['t2']
    current_iter = get_current_iteration() # Global iteration counter
    
    # Select l target images from the batch
    # In practice, this might be random or sequential; here we assume indices 0 to l-1
    target_indices = list(range(l))
    
    total_loss = 0.0
    
    for idx in target_indices:
        I_t = batch_images[idx]
        M_t = batch_masks[idx]
        C_t = batch_cameras[idx]
        
        # 1. Synthesize target image and mask
        # Uses the NLR++ image formation model with current model_params
        # The model takes other images in the batch as context if needed, 
        # but typically I_t is synthesized from C_t and the global representation.
        # Note: The source implies gradients are computed for I_t from other images,
        # meaning the context images are used to build the feature representation.
        context_images = [batch_images[i] for i in range(k) if i != idx]
        
        I_hat_t, M_hat_t = synthesize_image(
            viewpoint=C_t, 
            context_images=context_images, 
            params=model_params
        )
        
        # 2. Compute Image Reconstruction Loss (Masked L1)
        # Only compute over pixels where M_t[p] == 1
        mask_pixels = get_masked_pixels(M_t)
        lr_loss = 0.0
        count = 0
        for p in mask_pixels:
            lr_loss += abs(I_t[p] - I_hat_t[p])
            count += 1
        if count > 0:
            lr_loss /= count
        else:
            lr_loss = 0.0
            
        # 3. Compute Soft Mask Loss (Shape Loss)
        # Only enforced if current_iter <= t1 OR current_iter % t2 == 0
        lm_loss = 0.0
        if current_iter <= t1 or current_iter % t2 == 0:
            # Find minimum SDF along ray for each pixel
            # This requires dense sampling of Phi_theta along rays
            phi_min_values = []
            valid_mask_sum = 0.0
            
            for p in range(M_t.height * M_t.width):
                # Check condition: M_t[p] == 0 OR Phi_min[p] < tau
                # We need Phi_min[p] to check the condition, so we compute it first
                ray = get_ray_from_pixel(p, C_t)
                phi_min = find_min_sdf_along_ray(ray, model_params.phi)
                
                if M_t[p] == 0 or phi_min < hyperparams['tau']:
                    phi_min_values.append(phi_min)
                    valid_mask_sum += M_t[p] # Note: M_t[p] is 0 or 1. 
                                              # If M_t[p]==0, it adds 0 to sum? 
                                              # Formula says: sum_{p|...} M_t[p]. 
                                              # If M_t[p]==0, term is 0. 
                                              # If M_t[p]==1, term is 1.
                                              # But the condition includes M_t[p]==0.
                                              # Let's re-read formula:
                                              # sum_{p | M_t[p]=0 v Phi_min[p]<tau} M_t[p]
                                              # If M_t[p]=0, M_t[p] is 0. So it contributes 0 to denominator.
                                              # If M_t[p]=1 and Phi_min < tau, it contributes 1.
                                              # If M_t[p]=1 and Phi_min >= tau, it is excluded.
                                              # If M_t[p]=0, it is included in sum but adds 0.
                                              # So denominator is effectively count of pixels where M_t[p]=1 AND Phi_min < tau.
                                              # Wait, if M_t[p]=0, the term M_t[p] is 0. 
                                              # So the denominator is sum of M_t[p] for valid p.
                                              # This effectively counts pixels where M_t[p]=1 and Phi_min < tau.
                                              # However, the numerator sums BCE for ALL valid p.
                                              # If M_t[p]=0, BCE(sigmoid(-alpha*phi), 0).
                                              # If M_t[p]=1, BCE(sigmoid(-alpha*phi), 1).
                                              pass 
            
            # Recalculate denominator correctly based on formula
            denominator_sum = 0.0
            numerator_sum = 0.0
            
            for p in range(M_t.height * M_t.width):
                ray = get_ray_from_pixel(p, C_t)
                phi_min = find_min_sdf_along_ray(ray, model_params.phi)
                
                if M_t[p] == 0 or phi_min < hyperparams['tau']:
                    # Add to denominator sum: M_t[p]
                    denominator_sum += M_t[p]
                    
                    # Add to numerator sum: BCE(sigmoid(-alpha * phi_min), M_t[p])
                    sig_val = sigmoid(-hyperparams['alpha'] * phi_min)
                    bce_val = binary_cross_entropy(sig_val, M_t[p])
                    numerator_sum += bce_val
            
            if denominator_sum > 0:
                lm_loss = numerator_sum / (hyperparams['alpha'] * denominator_sum)
            else:
                lm_loss = 0.0
                
        # 4. Compute Eikonal Regularization (Shape Loss)
        # Only enforced if current_iter <= t1 OR current_iter % t2 == 0
        le_loss = 0.0
        if current_iter <= t1 or current_iter % t2 == 0:
            # Sample P random points in unit cube
            points = sample_random_points(hyperparams['P'], bounds=[-1, 1])
            grad_norm_sq_sum = 0.0
            for p_i in points:
                grad = compute_gradient(model_params.phi, p_i)
                norm_sq = dot(grad, grad)
                le_loss += pow(norm_sq - 1, 2)
            le_loss /= len(points)
            
        # 5. Combine Losses
        loss = lr_loss + hyperparams['lambda1'] * lm_loss + hyperparams['lambda2'] * le_loss
        total_loss += loss
        
    # Average loss over l targets
    total_loss /= l
    
    # 6. Backpropagation
    optimizer.zero_grad()
    total_loss.backward()
    optimizer.step()
    
    return total_loss

def find_min_sdf_along_ray(ray, phi):
    """
    Finds the minimum SDF value along a ray.
    Requires dense sampling.
    """
    # Sample points along the ray
    # Typically from near to far plane
    samples = sample_along_ray(ray, num_samples=256) # Example count
    min_val = infinity
    for p in samples:
        val = phi(p)
        if val < min_val:
            min_val = val
    return min_val
```

**Edge Cases and Pitfalls**
*   **Compute Bottleneck:** $\mathcal{L}_M$ requires finding the minimum of $\Phi_\theta$ along a ray, which necessitates dense sampling of the network and accounts for most of the compute time of each forward pass [S1, unofficial].
*   **Precision:** The threshold $\tau$ must be small enough to detect the zero level set but large enough to avoid noise. The softness parameter $\alpha$ controls the sharpness of the mask boundary; if too high, gradients may become unstable [S1, unofficial].
*   **Degenerate Input:** If no pixels satisfy the condition $M_t[p]=0 \lor \Phi_{\min}[p]<\tau$, the denominator in $\mathcal{L}_M$ becomes zero. The implementation must handle this division by zero case (e.g., by setting loss to 0 or adding a small epsilon) [S1, unofficial].

## Subtopics

### MetaNLR++ Meta-Learning Initialization
MetaNLR++ uses meta-learning to learn a prior over feature encoding, decoding, aggregation, and shape representation by optimizing the initial network weights $\Theta_0$ for fast convergence on unseen scenes [S1, unofficial]. It differs from standard NLR++ by using the Reptile algorithm to update $\Theta_0$ based on inner-loop optimization on sampled tasks [S1, unofficial]. The meta-learning objective is to find initial weights $\Theta_0^*$ that minimize the expected loss after $m$ optimization steps on an unseen scene $T$: $\Theta_0^* = \arg \min_{\Theta_0} \mathbb{E}_{T \sim \mathcal{T}} [\mathcal{L}(\Theta_m(\Theta_0, T))]$ [S1, unofficial]. The update rule is $\Theta_0^{j+1} = \Theta_0^j + \beta(\Theta_m(\Theta_0^j, T_j) - \Theta_0^j)$, where $\beta$ is the meta-learning rate (starting value $1 \times 10^{-1}$) and $m$ is the fixed number of inner-loop steps [S1, unofficial]. This approach significantly reduces training time; for example, on the ShapeNet chairs split, MetaNLR++ reaches 30dB PSNR in 1.5 minutes compared to NLR++'s 3.6 minutes [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The training is dominated by the dense sampling required for $\mathcal{L}_M$, which accounts for most of the compute time per forward pass [S1, unofficial]. The multi-target batching strategy adds forward passes to $\Gamma$ and $D$, which are fast to evaluate [S1, unofficial].
*   **Memory Complexity:** The number of target images $l$ treated as targets in the batch is limited by GPU memory [S1, unofficial].
*   **Performance:** On the ShapeNet dataset, NLR++ is slower to converge than MetaNLR++. For instance, on the chairs split, NLR++ takes 3.6 minutes to reach 30dB PSNR, while MetaNLR++ takes 1.5 minutes [S1, unofficial].
*   **Strengths:** The scheduled shape supervision allows for faster initial convergence by decoupling shape approximation from feature refinement [S1, unofficial]. The use of CNN encoder/decoder increases the receptive field of the image loss, allowing for more meaningful gradients [S1, unofficial].
*   **Limitations:** The dense sampling for $\mathcal{L}_M$ is computationally expensive [S1, unofficial]. NLR++ without meta-learning converges slower than MetaNLR++ [S1, unofficial].
*   **When to Use:** Use NLR++ when a standard neural lumigraph representation is needed without the overhead of meta-learning setup. Use MetaNLR++ when rapid convergence on unseen scenes is critical.

## Background
NLR++ was introduced as an end-to-end differentiable neural lumigraph representation optimized to reconstruct target views from a set of input images using a CNN encoder/decoder and a signed distance function (SDF) for shape [S1, unofficial]. It serves as the baseline for MetaNLR++, which improves upon it using meta-learning [S1, unofficial]. The method was developed to enable real-time export of view-dependent textured meshes from posed 2D images [S1, unofficial]. The implementation details, including hyperparameters and training schedules, are described in the supplementary material of the source paper [S1, unofficial]. Experiments were conducted on Nvidia Quadro RTX8000 and RTX6000 GPUs [S1, unofficial].
