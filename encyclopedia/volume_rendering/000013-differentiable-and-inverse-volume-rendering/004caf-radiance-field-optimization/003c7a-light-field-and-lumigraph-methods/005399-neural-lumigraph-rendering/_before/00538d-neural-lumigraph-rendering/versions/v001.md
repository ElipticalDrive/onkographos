# Neural Lumigraph Rendering

Also called: NLR

## Overview
Neural Lumigraph Rendering (NLR) is a neural rendering framework that jointly optimizes an implicit signed distance function (SDF) for shape and a radiance field for appearance, supervised exclusively by posed 2D images [S1]. Unlike standard NeRF which relies on volumetric integration and requires minutes of inference time, NLR achieves real-time rendering rates by exporting a high-resolution surface mesh with view-dependent texture information [S1]. It sets itself apart by using a SIREN-based SDF for geometry and a radiance field conditioned on local normals, enabling the use of traditional graphics pipelines for efficient rendering [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $m$ multi-view 2D images $I \in \mathbb{R}^{m \times w \times h \times 3}$ and corresponding known object masks $M \in \mathbb{R}^{m \times w \times h}$ (where 1 marks foreground) [S1]. Camera poses are assumed known [S1].
*   **Outputs:** A rendered 2D image, or a mesh with projective textures for real-time rendering [S1].

**Data Structures:**
1.  **SDF Network ($S$):** A SIREN (Sinusoidal Representation Network) parameterized by $\theta$ [S1].
    *   Input: Position $\mathbf{x} \in \mathbb{R}^3$.
    *   Output: Scalar SDF value $S(\mathbf{x}; \theta) \in \mathbb{R}$ [S1].
2.  **Radiance Field Network ($E$):** A network parameterized by $\theta$ (shared with SDF for capacity) and $\phi$ (additional parameters) [S1].
    *   Input: Position $\mathbf{x} \in \mathbb{R}^3$, view direction $\mathbf{r}_d \in \mathbb{R}^3$, local normal $\mathbf{n} \in \mathbb{R}^3$.
    *   Output: RGB color $\mathbf{c} \in \mathbb{R}^3$ [S1].
3.  **Camera Matrices:** View matrix $V \in \mathbb{R}^{4 \times 4}$ and projection matrix $P \in \mathbb{R}^{4 \times 4}$ [S1].

**Numbered Steps:**

1.  **Ray Generation:** For a pixel at relative projection plane location $\mathbf{u} \in [-1, 1]^2$, compute the ray origin $\mathbf{r}_o$ and direction $\mathbf{r}_d$:
    $$
    \mathbf{r}_o = (V^{-1} \cdot [0, 0, 1, 0]^T)_{x,y,z}
    $$
    $$
    \mathbf{r}_d = \nu \left( (P \cdot V)^{-1} \cdot [\mathbf{u}_x, \mathbf{u}_y, 0, 1]^T \right)
    $$
    where $\nu(\boldsymbol{\omega}) = \boldsymbol{\omega}_{x,y,z} / \|\boldsymbol{\omega}_{x,y,z}\|$ is vector normalization [S1].

2.  **Sphere Tracing:** Find the zero-level set $S_0$ closest to the camera origin along each ray. Initialize $\mathbf{x}_0 = \mathbf{r}_o$. Perform iterative updates for $n=16$ steps:
    $$
    \mathbf{x}_{i+1} = \mathbf{x}_i + S(\mathbf{x}_i) \mathbf{r}_d
    $$
    Only retain gradients in the last step ($\mathbf{x}_n$) to make sphere tracing memory efficient [S1]. A small residual $|S(\mathbf{x}_n)| < 0.005$ is tolerated in practice [S1]. The surface point is defined as $S_0 = \{\mathbf{x}_n \mid S(\mathbf{x}_n) = 0\}$ [S1].

3.  **Normal Computation:** Compute the local normal $\mathbf{n}$ at the surface point $\mathbf{x}_n$ via automatic differentiation of the SDF:
    $$
    \mathbf{n} = \nabla_{\mathbf{x}} S(\mathbf{x}_n; \theta)
    $$
    Normalize $\mathbf{n}$ if necessary (implied by usage in $E$) [S1].

4.  **Appearance Sampling:** Sample the radiance field at the converged surface point:
    $$
    \mathbf{c} = E(\mathbf{x}_n, \mathbf{r}_d, \mathbf{n}; \theta, \phi)
    $$
    The radiance field is conditioned on position, view direction, and local normal [S1].

5.  **Loss Calculation:** Minimize the following loss terms using mini-batches of image pixels $\mathbf{U}$:
    *   **Reconstruction Loss ($L_R$):** L1 error for true foreground pixels $\mathbf{U}_f = \mathbf{U} \cap S_0 \cap \{\mathbf{U} \mid M_{\mathbf{U}} = 1\}$:
        $$
        L_R = \frac{1}{|\mathbf{U}|} \sum_{\mathbf{c} \in I_{\mathbf{U}_f}} |E(\mathbf{x}, \mathbf{r}_d, \mathbf{n}; \theta, \phi) - \mathbf{c}|
        $$
        where $\mathbf{c}$ is the RGB value of a foreground pixel [S1].
    *   **Eikonal Regularization ($L_E$):** Enforces metric properties of the SDF using random points $\mathbf{x}_r$ uniformly sampled from a cube encapsulating the object's bounding unit radius sphere:
        $$
        L_E = \frac{1}{|\mathbf{U}|} \sum_{\mathbf{x}} (\|\nabla_{\mathbf{x}} S(\mathbf{x}_r; \theta)\|^2 - 1)^2
        $$
        [S1].
    *   **Soft Mask Loss ($L_M$):** Restricts coarse shape by enforcing projected pattern to fall within object mask boundaries for non-foreground pixels $\mathbf{m} \in M_{\mathbf{U} \setminus \mathbf{U}_f}$:
        $$
        L_M = \frac{1}{\alpha |\mathbf{U}|} \sum_{\mathbf{m}} \text{BCE}(\text{sigmoid}(-\alpha S_{\min}), \mathbf{m})
        $$
        where $S_{\min} = \arg \min_t S(\mathbf{r}_o + t\mathbf{r}_d; \theta)$ is the minimum S value along the entire ray, and $\alpha$ is a softness parameter [S1].
    *   **Angular Smoothness ($L_S$):** Regularizes the radiance field to avoid overfitting to training views by linearizing angular behavior:
        $$
        L_S = \frac{1}{|\mathbf{U}|} \sum_{\mathbf{x}} \|\nabla^2_{\mathbf{r}_d} E(\mathbf{x}, \mathbf{r}_d, \mathbf{n}; \theta, \phi)\|_2^2
        $$
        [S1].

6.  **Mesh Extraction (Post-Training):** Extract a high-resolution surface mesh from the SDF $S$ voxelized at a resolution of $512^3$ using the marching cubes algorithm [S1]. Offset the iso-surface of $S$ by 0.5% of the object radius in the outside direction to optimize image quality [S1]. Resample the emissivity function $E$ to synthesize projective textures $T_i$ for $N$ camera poses [S1].

**Parameters:**
*   $\theta$: Learnable parameters for the SIREN-based SDF and radiance field [S1].
*   $\phi$: Additional learnable parameters for the radiance field to increase capacity for fine spatial details and micro-reflections [S1].
*   $n=16$: Step count for sphere tracing [S1].
*   $\alpha$: Softness parameter for the soft mask loss [S1].
*   Resolution: $512^3$ for mesh extraction [S1].

**Pitfalls:**
*   SIREN has extreme overfitting behavior; the custom loss functions (especially $L_S$ and $L_M$) are critical to prevent this [S1].
*   Sphere tracing must only retain gradients in the last step to be memory efficient [S1].
*   L1 loss produces marginally sharper images than L2 [S1].

## Operating characteristics
*   **Rendering Speed:** Achieves 10x higher rendering rates than NeRF, enabling real-time rendering via mesh export [S1].
*   **Training Time:** Faster than standard NeRF due to the surface-based representation, though specific training times are not given in the sources [S1].
*   **Memory:** Sphere tracing is memory efficient by retaining gradients only in the last step [S1].
*   **Strengths:** Real-time rendering capability, high image quality comparable to SOTA neural volume rendering, explicit mesh export [S1].
*   **Limitations:** Requires posed 2D images and object masks; does not model lighting/shading (fixed lighting conditions only) [S1].

## Background
Neural Lumigraph Rendering was introduced by [S1] (CVPR 2021). It builds on sinusoidal representation networks (SIREN) [S1]. The method addresses the slow inference time of state-of-the-art neural volume rendering approaches by optimizing an implicit surface and a radiance field jointly [S1]. It is unique in allowing the export of a mesh with view-dependent texture information, making it compatible with traditional graphics pipelines [S1].
