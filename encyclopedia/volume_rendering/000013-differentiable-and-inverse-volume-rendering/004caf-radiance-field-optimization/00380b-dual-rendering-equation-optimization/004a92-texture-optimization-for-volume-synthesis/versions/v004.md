# Texture Optimization for Volume Synthesis

Also called: Kwatra et al. method adaptation

## Overview
This method synthesizes a 3D volumetric texture (specifically cloud volumes) from a single input photograph by minimizing an energy function that measures the distance between the input image pixel blocks and the rendered voxel blocks [S1]. It adapts the patch-based texture synthesis technique of Kwatra et al. to the 3D volume domain, treating voxel blocks as the fundamental units of synthesis [S1]. Unlike standard volume rendering which uses fixed parameters, this method optimizes the voxel values themselves to match visual evidence [S1]. It is distinguished from its parent [Dual Rendering Equation Optimization](8167-dual-rendering-equation-optimization.md) by explicitly solving for the volume geometry and appearance via an Expectation-Maximization (EM) framework rather than optimizing only lighting parameters [S1].

## How it works
**Inputs:**
*   $I_{ph}$: Input photograph (2D image) [S1].
*   $V_{ex}$: Example cloud volume database [S1].
*   $C_{ex} = \{C_1, \dots, C_K\}$: Set of $K$ voxel blocks extracted from $V_{ex}$, each with dimensions $w \times w \times N_z$ [S1].
*   $L_0^*, L_a^*$: Optimized lighting parameters (ambient and directional light) obtained by solving a nonlinear least square problem [S1].

**Outputs:**
*   $V$: Synthesized cloud volume [S1].

**Data Structures:**
*   **Voxel Block ($z_V$):** A 3D array of size $w \times w \times N_z$ representing density/extinction values [S1].
*   **Rendered Image Block ($z_I$):** A 2D array of size $w \times w$ representing pixel values, computed by the rendering operator $R(z_V, \tau, L_0^*, L_a^*)$ [S1].
*   **Vector $z$:** Concatenation of rendered image block and voxel block: $z = \{z_I, z_V\}$ [S1].
*   **Vector $x_p$:** Concatenation of input image pixel block $x_p^I$ and corresponding voxel block $x_p^V$: $x_p = \{x_p^I, x_p^V\}$ [S1].
*   **Distance Metric $d(x_p, z)$:**
    $$d(x_p, z) = \|x_p^V - z_V\|^2 + \lambda \|x_p^I - z_I\|^2$$
    where $\lambda$ is a relative weighting coefficient (default 100) [S1].

**Algorithm Steps:**

1.  **Preprocessing:**
    *   Extract voxel blocks $C_{ex}$ from the example database $V_{ex}$, resampling the grid resolution in the Z-direction to equal $N_z$ [S1].
    *   Render all example volumes in $V_{ex}$ using $L_0^*$ and $L_a^*$ to populate the set of candidate vectors $z$ [S1].

2.  **Sorting:**
    *   Sort all voxel blocks in the order in which incident sunlight reaches them [S1].
    *   This ensures that transmittance $\tau$ can be calculated for voxels closer to the sun first [S1].

3.  **Optimization Loop (EM Steps):**
    *   Repeat until the energy function converges or iterations reach a specified number [S1].
    *   **E-step (Expectation Step):**
        *   Minimize energy with respect to $x_p$ (specifically $x_p^V$) keeping $z_p$ fixed [S1].
        *   This results in a least squares problem where the derivative of the energy function $E(x; \{z\}) = \sum_{p \in X_{ph}} d(x_p, z_p)$ with respect to $x_p^V$ is set to zero [S1].
        *   The solution simplifies to a weighted average computation of neighbor voxel blocks [S1].
        *   Update $x_p^V$ and accumulate the best $z_p^V$ into the corresponding voxels in $V$ [S1].
    *   **M-step (Maximization Step):**
        *   Minimize energy with respect to $z_p$ keeping $x_p$ fixed [S1].
        *   This involves searching for the closest vector $z_p$ from the set of all vectors $z$ [S1].
        *   **Acceleration Strategy:** Since searching all $K$ vectors is computationally expensive, use a two-pass search [S1].
            1.  For each $x_p^V$, find $k$ nearest neighbor vectors $z_1^V, \dots, z_k^V$ from the database using an approximate nearest neighbor library [S1].
            2.  Render each $z_i^V$ to compute $z_i^I$ [S1].
            3.  Search for the closest vector $z_p$ from the set $\{z_1, \dots, z_k\}$ based on the distance metric $d(x_p, z)$ [S1].

**Pseudocode:**

```python
import numpy as np

def synthesize_volume(input_image, example_volumes, lighting_params, w, Nz, k_neighbors, lambda_weight, max_iterations, tol=1e-4):
    # 1. Preprocessing: Extract voxel blocks and render examples
    voxel_blocks_db = []
    for vol in example_volumes:
        for z in range(0, vol.shape[0] - Nz + 1, Nz):
            for y in range(0, vol.shape[1] - w + 1, w):
                for x in range(0, vol.shape[2] - w + 1, w):
                    voxel_blocks_db.append(vol[z:z+Nz, y:y+w, x:x+w])
                    
    candidate_vectors = []
    for z_V in voxel_blocks_db:
        z_I = render_block(z_V, lighting_params)
        candidate_vectors.append({'z_V': z_V, 'z_I': z_I})
        
    vol_height, vol_width = input_image.shape[:2]
    volume = np.zeros((vol_height, vol_width, Nz))
    
    # 2. Sorting: Sort blocks by sunlight incidence order [S1]
    # [G] Assume sun direction is along +Z axis for sorting logic
    sun_dir = np.array([0, 0, 1])
    block_coords = [(y*w, x*w) for y in range(vol_height//w) for x in range(vol_width//w)]
    sorted_indices = sorted(range(len(block_coords)), key=lambda i: np.dot(block_coords[i], sun_dir))
    
    # 3. Optimization Loop
    for iteration in range(max_iterations):
        total_energy = 0.0
        
        for idx in sorted_indices:
            y, x = block_coords[idx]
            x_p_I = input_image[y:y+w, x:x+w]
            x_p_V = volume[y:y+w, x:x+w, :]
            
            # --- E-step: Minimize energy w.r.t x_p^V keeping z_p fixed [S1] ---
            # Simplifies to weighted average of neighbor voxel blocks [S1]
            x_p_V = weighted_average_neighbors(volume, y, x, w, Nz)
            volume[y:y+w, x:x+w, :] = x_p_V
            
            # --- M-step: Minimize energy w.r.t z_p keeping x_p fixed [S1] ---
            # Acceleration: Find k nearest neighbors in voxel space [S1]
            x_p_V_flat = x_p_V.flatten()
            dists = [np.linalg.norm(np.array(z['z_V'].flatten()) - x_p_V_flat) for z in candidate_vectors]
            k_indices = np.argsort(dists)[:k_neighbors]
            
            best_candidate = None
            min_dist = float('inf')
            
            for i in k_indices:
                cand = candidate_vectors[i]
                dist_V = np.sum((x_p_V - cand['z_V'])**2)
                dist_I = np.sum((x_p_I - cand['z_I'])**2)
                dist = dist_V + lambda_weight * dist_I
                
                if dist < min_dist:
                    min_dist = dist
                    best_candidate = cand
            
            # Accumulate best z_V^p into volume [S1]
            volume[y:y+w, x:x+w, :] = best_candidate['z_V']
            total_energy += min_dist
            
        if total_energy < tol:
            break
            
    return volume

def render_block(z_V, lighting_params):
    # Standard volume rendering operator R(z_V, tau, L0, La) [G]
    L0, La = lighting_params
    transmittance = 1.0
    radiance = np.zeros((z_V.shape[1], z_V.shape[2]))
    for z in range(z_V.shape[0]):
        density = z_V[z, :, :]
        transmittance *= np.exp(-density)
        radiance += density * transmittance * La
    return radiance + L0

def weighted_average_neighbors(volume, y, x, w, Nz):
    # [G] Standard patch-based weighted average over 3x3 neighborhood
    avg = np.zeros((w, w, Nz))
    count = 0
    for dy in range(-1, 2):
        for dx in range(-1, 2):
            ny, nx = y + dy*w, x + dx*w
            if 0 <= ny < volume.shape[0] and 0 <= nx < volume.shape[1]:
                avg += volume[ny:ny+w, nx:nx+w, :]
                count += 1
    return avg / max(count, 1)
```

**Parameters:**
*   $\lambda$: Relative weighting coefficient for the pixel difference term. Default value is 100 [S1].
*   $k$: Number of nearest neighbors searched in the M-step acceleration strategy [S1].

**Edge Cases and Pitfalls:**
*   **Transmittance Calculation:** Requires voxel values of blocks closer to the sun to be computed first [S1]. Incorrect sorting order leads to incorrect lighting and shadowing [S1].
*   **Computational Cost:** Rendering $z_V$ for every candidate is expensive [S1]. The $k$-nearest neighbor acceleration is critical for feasibility [S1].

## Subtopics

### Two-Orthogonal Image Synthesis Extension
An extension of the texture optimization method to synthesize a cloud volume such that rendered images from two orthogonal directions (e.g., xy and xz planes) match two input images [S1]. It augments the vector $x_p$ and $z$ to include pixel values from the second image plane ($I_{xz}$) [S1]. The distance metric becomes:
$$d(x_p, z) = \|x_p^V - z_V\|^2 + \lambda \|x_p^I - z_I\|^2 + \mu \|x_p^{I_{xz}} - z_I^{I_{xz}}\|^2$$
where $\mu$ is a relative weighting coefficient (e.g., 10 in experiments) [S1].

### Patch-based Texture Synthesis
A method to synthesize a new texture patch $P_n$ by pasting an example patch $E_n$ from an input image $I_{in}$ into the output $I_{out}$, ensuring boundary matching to avoid feature mismatches [S2]. It uses an overlap region to initialize optimized kd-trees for accelerating approximate nearest neighbors (ANN) search [S2]. The matching condition is $d(\partial(P_n), \partial(E_n)) < \eta$, where $\partial(\cdot)$ is the boundary zone and $\eta$ is a prescribed constant [S2]. A probability density function (PDF) is computed based on the L2 distance of boundaries, and a patch is randomly chosen according to the PDF, then pasted and blended [S2].

## Operating characteristics
*   **Performance:** On a desktop PC with an Intel Core-i7 4790 3.60 GHz CPU, preprocessing takes about 4 minutes for a database of 137 example volumes [S1]. The synthesized volume resolution in the cited experiments is $64 \times 51 \times 20$ [S1].
*   **Strengths:** Produces visually consistent textures that match input photographs by directly optimizing voxel values [S1].
*   **Limitations:** Computationally expensive due to repeated rendering in the optimization loop [S1]. Requires a database of example volumes [S1]. Synthesis time scales with resolution and iteration count [S1].

## Background
The method is based on the texture optimization technique proposed by Kwatra et al. [11] (referenced in [S1]). It was adapted for 3D cloud volume synthesis by Iwasaki, Dobashi, and Okabe in 2017 [S1]. The approach leverages the similarity between 2D patch-based synthesis and 3D voxel-based synthesis, extending the EM framework to volumetric data [S1].
