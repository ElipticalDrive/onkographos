# Two-Phase Method


## Overview
The Two-Phase Method is a synthesis technique designed to ensure both geometric and appearance continuity in synthesized results, particularly for complex texture and geometry [S1]. It decouples the patch selection process into two stages: first filtering candidates for geometric continuity, then selecting one for appearance continuity [S1].

## How it works
The method operates on a set of candidate patches derived from an exemplar volume [S1]. It requires a density field $V^{(d)}$ and a color feature field $V^{(f)}$ from the exemplar, along with a shading map to guide lighting consistency [S1].

**Inputs:**
- Candidate patch set $\mathcal{P}$ (filtered by shading similarity) [S1].
- Exemplar density field $V^{(d)}$ [S1].
- Exemplar color feature field $V^{(f)}$ [S1].
- Synthesis target patch $P_n$ [S1].

**Outputs:**
- Selected patch $P_{selected}$ from $\mathcal{P}$ [S1].

**Data Structures:**
- Patches are represented as 3D voxel blocks [G].
- Density field $V^{(d)}$ stores scalar density values [G].
- Color feature field $V^{(f)}$ stores color/feature vectors [G].

**Steps:**
1. **Phase 1: Geometry-based Synthesis**
   - For each candidate patch $P_i \in \mathcal{P}$, calculate the geometric continuity error against the target $P_n$ using the density field $V^{(d)}$ [S1].
   - Select a subset of $k_g$ candidate patches that exhibit the highest geometric continuity [S1].

2. **Phase 2: Appearance-based Synthesis**
   - For each of the $k_g$ candidates from Phase 1, calculate the appearance continuity error against the target $P_n$ using the color feature field $V^{(f)}$ [S1].
   - Select the single patch $P_{selected}$ that best matches the target in color features [S1].

**Formulas:**
- Geometric Error $E_g(P_i, P_n)$: Not given in the sources.
- Appearance Error $E_a(P_i, P_n)$: Not given in the sources.

**Parameters:**
- $k_g$: Number of candidates retained after Phase 1. Not given in the sources.

**Edge Cases and Pitfalls:**
- Boundary artifacts may occur if patches are not constrained at scene edges [S1].
- Precision issues in density or color feature comparison may lead to suboptimal selections [G].

**Pseudocode:**
```python
def two_phase_synthesis(target_patch, candidate_patches, density_field, color_field):
    # Phase 1: Geometry-based Synthesis
    geometric_errors = []
    for patch in candidate_patches:
        err = _boundary_l2(patch, target_patch, density_field)
        geometric_errors.append((patch, err))
    
    geometric_errors.sort(key=lambda x: x[1])
    k_g = 10  # Not given in the sources [G]
    top_candidates = [x[0] for x in geometric_errors[:k_g]]
    
    # Phase 2: Appearance-based Synthesis
    appearance_errors = []
    for patch in top_candidates:
        err = _boundary_l2(patch, target_patch, color_field)
        appearance_errors.append((patch, err))
        
    best_patch, _ = min(appearance_errors, key=lambda x: x[1])
    return best_patch

def _boundary_l2(patch1, patch2, field):
    """Computes L2 distance between boundary voxels of two patches using a field [G]."""
    # Not given in the sources [G]
    # Standard implementation: mean squared difference of boundary voxels
    b1 = field[patch1.boundary_indices]
    b2 = field[patch2.boundary_indices]
    return ((b1 - b2) ** 2).mean()
```

## Subtopics

### Edge Error Factor
A variant for textures without sharp boundaries that introduces an edge error factor into the synthesis process to measure and balance average edge discontinuities [S2, unofficial]. It calculates edge errors $E_e$ by measuring average edge discontinuities for composed textures, considering that discontinuities along an edge come from 2 vertical pairs of adjacent cube faces (e.g., A(E)-C(E) and C(N)-D(N) for edge a1-b2-c3-d4) [S2, unofficial]. For each face of a cube, errors of the 4 edges are calculated from all cubes having the same color on the adjacent face, collecting the 2 face errors of the 12 edges from all combinations once and only once [S2, unofficial]. The accumulated synthesis error is $E_s = p_i \times E_i + p_e \times E_e$, where $E_i$ is the inside error, $E_e$ is the edge error, and $p_i, p_e$ are weights set as the inverse of their cutting path size to balance the errors [S2, unofficial].

## Operating characteristics
The method ensures geometric and appearance continuity, which is crucial for complex texture and geometry [S1]. Performance details such as time and memory complexity are not explicitly provided in the sources [S1][S2, unofficial]. The method is suitable for synthesizing large-scale scenes with reasonable lighting [S1].

## Background
The Two-Phase Method was proposed in the context of NeRF Synthesis with Shading Guidance [S1]. It addresses high-dimensional texture synthesis problems inspired by traditional exemplar-based methods [S1].
