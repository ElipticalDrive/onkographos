# Two-Phase Method


## Overview
The Two-Phase Method is a synthesis technique designed to ensure both geometric and appearance continuity in synthesized results, particularly for complex texture and geometry [S1]. It addresses the problem of selecting candidate patches that satisfy multiple constraints by decoupling the selection process into two distinct stages: first filtering for geometric consistency, then refining for appearance consistency [S1].

## How it works
The method operates on a set of candidate patches derived from an exemplar volume [S1]. It requires a density field $V^{(d)}$ and a color feature field $V^{(f)}$ from the exemplar, along with a shading map to guide lighting consistency [S1].

**Inputs:**
- Candidate patch set $\mathcal{P}$ (filtered by shading similarity) [S1].
- Exemplar density field $V^{(d)}$ [S1].
- Exemplar color feature field $V^{(f)}$ [S1].
- Synthesis target patch $P_n$ [S1].

**Outputs:**
- Selected patch $P_{selected}$ from $\mathcal{P}$ [S1].

**Data Structures:**
- Patches are represented as 3D voxel blocks [G].
- Density field $V^{(d)}$ stores scalar density values [S1].
- Color feature field $V^{(f)}$ stores color/feature vectors [S1].

**Steps:**
1. **Phase 1: Geometry-based Synthesis**
   - For each candidate patch $P_i \in \mathcal{P}$, evaluate geometric continuity against the target $P_n$ using the density field $V^{(d)}$ [S1].
   - Select a subset of $k_g$ candidate patches that exhibit the highest geometric continuity [S1].
2. **Phase 2: Appearance-based Synthesis**
   - For each of the $k_g$ candidates from Phase 1, evaluate appearance continuity against the target $P_n$ using the color feature field $V^{(f)}$ [S1].
   - Select the single patch $P_{selected}$ that best matches the color continuity requirements [S1].

**Formulas:**
- Geometric Error $E_g(P_i, P_n)$: Not explicitly defined in the provided notes, but implied to be based on $V^{(d)}$ [S1].
- Appearance Error $E_a(P_i, P_n)$: Not explicitly defined in the provided notes, but implied to be based on $V^{(f)}$ [S1].

**Parameters:**
- $k_g$: Number of candidates retained after Phase 1. Not given in the sources.

## Subtopics

### Edge Error Factor
A variant for textures without sharp boundaries that introduces an edge error factor into the synthesis process to measure and balance average edge discontinuities [S2, unofficial]. It calculates edge errors $E_e$ by measuring average edge discontinuities for composed textures, considering that discontinuities along an edge come from 2 vertical pairs of adjacent cube faces (e.g., A(E)-C(E) and C(N)-D(N) for edge a1-b2-c3-d4) [S2, unofficial]. For each face of a cube, errors of the 4 edges are calculated from all cubes having the same color on the adjacent face, collecting the 2 face errors of the 12 edges from all combinations once and only once [S2, unofficial]. The accumulated synthesis error is $E_s = p_i \times E_i + p_e \times E_e$, where $E_i$ is the inside error, $E_e$ is the edge error, and $p_i, p_e$ are weights set as the inverse of their cutting path size to balance the errors [S2, unofficial].

## Operating characteristics
The method ensures geometric and appearance continuity, which is crucial for complex texture and geometry [S1]. The broader pipeline allows relighting scenes without decoupling the scene by using shading-guided synthesis [S1]. Performance details such as time and memory complexity are not explicitly provided in the sources [S1][S2, unofficial]. The method is suitable for synthesizing large-scale scenes with reasonable lighting [S1].

## Background
The Two-Phase Method was proposed in the context of NeRF Synthesis with Shading Guidance [S1]. It is part of a pipeline that includes shading map extraction and shading-guided synthesis [S1]. The method aims to solve high-dimensional texture synthesis problems inspired by traditional exemplar-based methods [S1].
