# Tetra-NeRF

Also called: Tetrahedra Field

## Overview
Tetra-NeRF is a radiance field representation that replaces uniform voxel grids or sparse point clouds with a dense set of non-overlapping tetrahedra generated by Delaunay triangulation of an input point cloud [S1]. It solves the problem of empty regions in sparse point-based methods and the fixed-resolution limitations of voxel-based methods by providing a continuous, adaptive representation that is naturally denser near surfaces [S1]. Unlike [Point-NeRF](7673-derf-decomposed-radiance-fields.md) which requires growing the point cloud during training to fill gaps, Tetra-NeRF uses a fixed set of points and constant parameter count, ensuring the representation complexity does not grow [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A point cloud (typically from Structure from Motion/SfM like COLMAP) and camera poses [S1].
*   **Output:** Novel view images synthesized via volumetric rendering [S1].

**Data Structures:**
1.  **Point Cloud:** A set of 3D points $P$. Each point has a position and an initial feature vector.
    *   **Feature Vector:** Size 64.
    *   **Initialization:**
        *   Dimensions 0-3: RGBA color values from the point cloud, rescaled to $[0, 1]$. Original points have $\alpha=1$; randomly added points have $\alpha=0$ [S1].
        *   Dimensions 4-63: Uniformly sampled from $[-10^{-4}, 10^{-4}]$ [S1].
2.  **Tetrahedra Field:** A set of non-overlapping tetrahedra $\mathcal{T}$ covering the convex hull of $P$, generated via Delaunay triangulation [S1].
3.  **Acceleration Structure:** An acceleration structure (e.g., OptiX) for fast ray-triangle intersection to identify intersected tetrahedra [S1].
4.  **MLP:**
    *   **Density/Appearance MLP:** 3 layers, hidden size 128, Kaiming uniform initialization [S1].
    *   **Color MLP:** 1 linear layer [S1].

**Numbered Steps:**

1.  **Point Cloud Preprocessing:**
    *   If the number of points $|P| > 10^6$, subsample to $10^6$ points randomly [S1].
    *   If $|P| \le 10^6$ (e.g., Blender dataset), add $|P|/2$ random points to prevent edge artifacts [S1].
    *   To add a random point: Sample $x_0 \in P$, a random normal $n$, and $\alpha \sim \mathcal{N}(\bar{d}, \bar{d}^2/4)$, where $\bar{d}$ is the average spacing of $P$. Add $x = x_0 + \alpha n$ [S1].

2.  **Triangulation:**
    *   Perform Delaunay triangulation on $P$ to generate the set of tetrahedra $\mathcal{T}$ [S1].

3.  **Ray Casting and Intersection:**
    *   For each pixel in a virtual view, project a ray $r$ from the camera plane [S1].
    *   Compute intersections between $r$ and all faces of tetrahedra in $\mathcal{T}$ using an acceleration structure (e.g., OptiX) [S1].
    *   Limit to the first 512 intersected triangles per ray [S1].
    *   Determine the corresponding tetrahedra and order them along the ray to allow marching [S1].

4.  **Barycentric Coordinate Computation:**
    *   For each ray-tetrahedron intersection, compute the 2D barycentric coordinates $\lambda_{2D}$ with respect to the triangle face [S1].
    *   Obtain the 3D barycentric coordinates $\lambda_{3D}$ for the tetrahedron by setting the coordinate for the vertex opposite to the intersected face to 0 [S1].
    *   For a query point $x$ inside a tetrahedron, compute its barycentric coordinates $\lambda$ by linearly interpolating between the barycentric coordinates of the two ray-tetrahedron intersections [S1].
    *   Alternatively, compute $\lambda$ directly via volume ratios:
        $$ \lambda = \left(\frac{V_{x234}}{V_{1234}}, \frac{V_{1x34}}{V_{1234}}, \frac{V_{12x4}}{V_{1234}}, \frac{V_{123x}}{V_{1234}}\right) $$
        where $V_{1234}$ is the volume of the tetrahedron and $V_{x234}$ etc. are volumes formed by replacing one vertex with $x$ [S1].

5.  **Feature Interpolation:**
    *   Interpolate the feature vectors $f_v$ at the four vertices of the containing tetrahedron using $\lambda$:
        $$ f_x = \sum_{i=1}^{4} \lambda_i f_{v_i} $$
    *   This yields the feature vector $f_x$ for the query point $x$ [S1].

6.  **Network Query:**
    *   Pass $f_x$ through the 3-layer MLP (hidden size 128) to compute raw density $\bar{\sigma}$ and appearance features $a$ [S1].
    *   Encode the ray direction $d$ using Fourier features [S1].
    *   Concatenate $a$ and the encoded $d$, then pass through the single linear layer to get raw RGB color $\bar{c}$ [S1].

7.  **Activation:**
    *   Map raw density to volume density: $\sigma = \text{softplus}(\bar{\sigma})$ [S1].
    *   Map raw color to RGB: $c = \text{sigmoid}(\bar{c})$ [S1].

8.  **Sampling:**
    *   **Coarse Stage:** Use stratified uniform sampling along the ray, limited to the space occupied by tetrahedra [S1].
    *   **Fine Stage:** Use density weights from the coarse stage to bias sampling towards potential surfaces. Use the same network as the coarse stage [S1].
    *   Merge coarse and fine samples [S1].

9.  **Rendering:**
    *   Compute accumulated weights $\bar{w}_i$ for each sample $i$:
        $$ \bar{w}_i = (1 - \exp (-\sigma_i \delta_i))\exp \left(-\sum_{j=1}^{i-1}\sigma_j \delta_j\right) $$
        where $\delta_i = t_i - t_{i-1}$ [S1].
    *   Normalize weights to $w_i$ and render final color $C$:
        $$ \mathbf {C} = \sum _{i=1}^{N} T_i (1 - \exp (\sigma _i \delta _i))\mathbf {c}_i, \quad T_i = \exp (-\sum _{i=1}^{N - 1} \sigma _i \delta _i) $$
    *   Backpropagate MSE loss to update features and MLP weights [S1].

**Pseudocode:**

```python
import numpy as np

def softplus(x):
    return np.log1p(np.exp(-np.abs(x))) + np.maximum(x, 0)

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def compute_barycentric_coords_via_volumes(v1, v2, v3, v4, x):
    """
    Compute barycentric coordinates of x in tetrahedron (v1, v2, v3, v4)
    using volume ratios.
    """
    def tetra_volume(a, b, c, d):
        return np.abs(np.dot(a - d, np.cross(b - d, c - d))) / 6.0
    
    V_total = tetra_volume(v1, v2, v3, v4)
    if V_total == 0:
        return np.array([0.25, 0.25, 0.25, 0.25]) # Fallback for degenerate case
    
    l1 = tetra_volume(x, v2, v3, v4) / V_total
    l2 = tetra_volume(v1, x, v3, v4) / V_total
    l3 = tetra_volume(v1, v2, x, v4) / V_total
    l4 = tetra_volume(v1, v2, v3, x) / V_total
    return np.array([l1, l2, l3, l4])

def interpolate_features(vertices, features, barycentric_coords):
    """
    Interpolate feature vectors at vertices using barycentric coordinates.
    vertices: (4, 3) array of vertex positions
    features: (4, 64) array of vertex feature vectors
    barycentric_coords: (4,) array of lambda values
    """
    return np.dot(barycentric_coords, features)

def fourier_encode(direction, freq_bands=10):
    """
    Simple Fourier encoding of direction vector.
    """
    scales = 2 ** np.arange(freq_bands)
    scaled_direction = np.outer(direction, scales)
    encoded = np.concatenate([np.sin(scaled_direction), np.cos(scaled_direction)], axis=-1)
    return encoded

def tetra_nerf_forward(ray_origin, ray_direction, tetrahedra, vertex_features, 
                        mlp_density_appearance, mlp_color, num_coarse_samples=64, 
                        num_fine_samples=48):
    """
    Forward pass for a single ray.
    """
    # 1. Find intersected tetrahedra and sort by distance
    # This requires an acceleration structure (e.g., OptiX) in practice.
    # Here we assume a function `get_intersected_tetra_indices` returns 
    # sorted indices of tetrahedra intersected by the ray.
    intersected_tetra_indices = get_intersected_tetra_indices(ray_origin, ray_direction, tetrahedra)
    
    # Limit to 512 triangles/tetrahedra as per source
    intersected_tetra_indices = intersected_tetra_indices[:512]
    
    # 2. Coarse Sampling
    # Sample points along the ray within the bounding volume of the tetrahedra
    # For simplicity, assume we sample uniformly within the min/max extent 
    # of the intersected tetrahedra along the ray.
    t_min = max(0, (get_min_extent(ray_origin, ray_direction, intersected_tetra_indices)))
    t_max = min(max_extent, (get_max_extent(ray_origin, ray_direction, intersected_tetra_indices)))
    
    coarse_t = np.linspace(t_min, t_max, num_coarse_samples)
    coarse_points = ray_origin + coarse_t[:, None] * ray_direction
    
    coarse_sigma = []
    coarse_c = []
    
    for t, x in zip(coarse_t, coarse_points):
        # Find containing tetrahedron
        tet_idx = find_containing_tetrahedron(x, intersected_tetra_indices)
        if tet_idx is None:
            coarse_sigma.append(0.0)
            coarse_c.append([0.0, 0.0, 0.0])
            continue
            
        tet = tetrahedra[tet_idx]
        verts = np.array([tet.v1, tet.v2, tet.v3, tet.v4])
        feats = vertex_features[tet_idx] # (4, 64)
        
        # Compute barycentric coords
        lambdas = compute_barycentric_coords_via_volumes(*verts, x)
        
        # Interpolate features
        f_x = interpolate_features(verts, feats, lambdas)
        
        # MLP: Density and Appearance
        raw_sigma, appearance = mlp_density_appearance(f_x)
        sigma = softplus(raw_sigma)
        
        # MLP: Color
        encoded_dir = fourier_encode(ray_direction)
        raw_c = mlp_color(np.concatenate([appearance, encoded_dir]))
        c = sigmoid(raw_c)
        
        coarse_sigma.append(sigma)
        coarse_c.append(c)
        
    coarse_sigma = np.array(coarse_sigma)
    coarse_c = np.array(coarse_c)
    
    # 3. Compute coarse weights for fine sampling bias
    deltas = np.diff(np.concatenate([[0], coarse_t]))
    # w_i = (1 - exp(-sigma_i * delta_i)) * exp(-sum_{j<i} sigma_j * delta_j)
    alpha_coarse = 1 - np.exp(-coarse_sigma * deltas)
    transmittance_coarse = np.exp(-np.cumsum(coarse_sigma * deltas))
    weights_coarse = alpha_coarse * transmittance_coarse
    
    # 4. Fine Sampling
    # Sample based on weights_coarse
    fine_t = sample_from_distribution(weights_coarse, t_min, t_max, num_fine_samples)
    fine_points = ray_origin + fine_t[:, None] * ray_direction
    
    fine_sigma = []
    fine_c = []
    
    for t, x in zip(fine_t, fine_points):
        tet_idx = find_containing_tetrahedron(x, intersected_tetra_indices)
        if tet_idx is None:
            fine_sigma.append(0.0)
            fine_c.append([0.0, 0.0, 0.0])
            continue
            
        tet = tetrahedra[tet_idx]
        verts = np.array([tet.v1, tet.v2, tet.v3, tet.v4])
        feats = vertex_features[tet_idx]
        
        lambdas = compute_barycentric_coords_via_volumes(*verts, x)
        f_x = interpolate_features(verts, feats, lambdas)
        
        raw_sigma, appearance = mlp_density_appearance(f_x)
        sigma = softplus(raw_sigma)
        
        encoded_dir = fourier_encode(ray_direction)
        raw_c = mlp_color(np.concatenate([appearance, encoded_dir]))
        c = sigmoid(raw_c)
        
        fine_sigma.append(sigma)
        fine_c.append(c)
        
    fine_sigma = np.array(fine_sigma)
    fine_c = np.array(fine_c)
    
    # 5. Merge and Render
    all_t = np.concatenate([coarse_t, fine_t])
    all_sigma = np.concatenate([coarse_sigma, fine_sigma])
    all_c = np.concatenate([coarse_c, fine_c])
    
    # Sort by t
    sort_idx = np.argsort(all_t)
    all_t = all_t[sort_idx]
    all_sigma = all_sigma[sort_idx]
    all_c = all_c[sort_idx]
    
    deltas = np.diff(np.concatenate([[0], all_t]))
    alpha = 1 - np.exp(-all_sigma * deltas)
    transmittance = np.exp(-np.cumsum(all_sigma * deltas))
    weights = alpha * transmittance
    
    final_color = np.sum(weights[:, None] * all_c, axis=0)
    
    return final_color
```

**Parameters:**
*   **Feature Vector Size:** 64 [S1].
*   **MLP Hidden Sizes:** 128 [S1].
*   **Batch Size:** 4,096 random rays [S1].
*   **Optimizer:** RAdam [S1].
*   **Learning Rate:** Exponential decay from $10^{-3}$ to $10^{-4}$ in 300k steps [S1].
*   **Max Intersections:** 512 triangles per ray [S1].

**Edge Cases and Pitfalls:**
*   **Fixed Triangle Limit:** Limiting to 512 triangles can degrade results in large scenes or those with fine-grained tetrahedralization, as more intersections may be needed [S1]. Mitigation: Consider more triangles at the cost of runtime [S1].
*   **Edge Artifacts:** With low point counts, some pixels on edges may not intersect any tetrahedra, causing artifacts [S1]. Mitigation: Add randomly generated points near the original point cloud [S1].
*   **Empty Regions:** Unlike Point-NeRF, Tetra-NeRF does not suffer from empty regions due to sparse points because the triangulation covers the convex hull continuously [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the number of tetrahedra, vertices, and scene structure. Training speed ranges from 15k to 30k rays per second on a single NVIDIA A100 GPU [S1]. Full training (300k iterations) takes 11–24 hours [S1].
*   **Memory Complexity:** Fixed number of parameters. Feature vectors are stored at vertices. The number of parameters stays constant during training, unlike Point-NeRF or Plenoxels which grow complexity [S1].
*   **Strengths:** Adaptive resolution (denser near surfaces), continuous representation avoiding empty regions, fixed parameter count [S1].
*   **Limitations:** Performance degrades if the fixed triangle intersection limit (512) is insufficient for the scene complexity [S1].
*   **When to Use:** When a high-quality point cloud (e.g., from SfM) is available, and adaptive resolution is desired without the overhead of growing representations or fixed grid resolutions [S1].
*   **When Not to Use:** In very large scenes where the fixed intersection limit causes significant artifacts, or when no initial point cloud is available [S1].

## Background
Tetra-NeRF was introduced in the paper "Tetra-NeRF: Representing Neural Radiance Fields Using Tetrahedra" [S1]. It builds on the idea of using classical surface reconstruction methods (Delaunay triangulation) to create a dense, non-overlapping tetrahedral mesh from a point cloud, extending the triangle-rendering pipeline to neural radiance fields [S1]. It addresses limitations of MLP-based NeRFs (costly queries, hard to modify) and voxel/grid-based methods (fixed resolution, non-local effects) by storing features freely in 3D space on a tetrahedral mesh [S1].
