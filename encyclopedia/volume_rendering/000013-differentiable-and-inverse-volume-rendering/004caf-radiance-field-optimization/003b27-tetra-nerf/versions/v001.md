# Tetra-NeRF

Also called: Tetrahedra Field

## Overview
Tetra-NeRF is a radiance field representation that replaces uniform voxel grids or sparse point clouds with a dense set of non-overlapping tetrahedra obtained via Delaunay triangulation of an input point cloud [S1]. It solves the problem of empty regions in sparse point-based methods and the fixed resolution limits of voxel-based methods by providing a continuous, adaptive representation that is naturally denser near surfaces [S1]. Unlike Point-NeRF, which requires growing the point cloud during training to fill gaps, Tetra-NeRF uses a fixed set of points and constant parameter count, ensuring the representation complexity does not grow [S1].

## How it works
**Inputs:** A point cloud (typically from Structure from Motion/SfM tools like COLMAP) providing 3D positions and RGBA colors, along with camera poses [S1].
**Outputs:** A rendered color image for a given camera view [S1].

**Data Structures:**
1.  **Point Cloud:** A set of $N$ points $P = \{p_1, ..., p_N\}$ with positions $\mathbf{x}_i$ and RGBA attributes.
2.  **Tetrahedral Mesh:** A set of non-overlapping tetrahedra $\mathcal{T}$ generated by Delaunay triangulation of $P$. The union of these tetrahedra forms the convex hull of $P$ [S1].
3.  **Vertex Features:** Each vertex $v$ of the tetrahedra has a trainable feature vector $\mathbf{f}_v \in \mathbb{R}^{64}$ [S1].
4.  **Acceleration Structure:** A ray-triangle intersection structure (e.g., OptiX BVH) built on the faces of the tetrahedra to efficiently find ray intersections [S1].

**Initialization:**
*   If $|P| > 10^6$, subsample $P$ to $10^6$ points randomly [S1].
*   If $|P| < 10^6$ (e.g., Blender dataset), add $|P|/2$ random points. For each added point:
    1.  Pick random $x_0 \in P$.
    2.  Pick random normal $n$.
    3.  Sample $\alpha \sim \mathcal{N}(\bar{d}, \bar{d}^2/4)$, where $\bar{d}$ is the average spacing of $P$ [S1].
    4.  Set $x = x_0 + \alpha n$. Set its alpha value to 0 [S1].
*   Original points have alpha value 1 [S1].
*   Initialize $\mathbf{f}_v$ uniformly in $[-10^{-4}, 10^{-4}]$. Set the first 4 dimensions of $\mathbf{f}_v$ to the RGBA color of the associated point (rescaled to $[0,1]$) [S1].
*   Initialize MLPs with Kaiming uniform initialization [S1].

**Numbered Steps:**

1.  **Ray Casting:** For each pixel in the target view, project a ray $\mathbf{r}$ from the camera plane [S1].
2.  **Tetrahedron Selection:** Compute intersections between $\mathbf{r}$ and all tetrahedron faces. Take the first 512 intersected triangles and determine the corresponding tetrahedra [S1]. Order these tetrahedra along the ray [S1].
    *   *Pitfall:* Limiting to 512 triangles may degrade results in large scenes or fine-grained triangulations [S1].
3.  **Sampling:** Perform two-stage sampling along $\mathbf{r}$, limited to the space occupied by the selected tetrahedra [S1].
    *   **Coarse Stage:** Use stratified uniform sampling. Split the ray into equally long intervals within the tetrahedral volume and sample uniformly in each [S1].
    *   **Fine Stage:** Use density weights from the coarse stage to bias sampling towards potential surfaces. Use the same network as the coarse stage [S1].
    *   Merge coarse and fine samples [S1].
4.  **Point Location:** For each sample point $\mathbf{x}$ along $\mathbf{r}$:
    *   Find the containing tetrahedron $T$ from the ordered list [S1].
    *   Compute the 3D barycentric coordinates $\bm{\lambda}$ of $\mathbf{x}$ with respect to $T$'s vertices $v_1, v_2, v_3, v_4$ [S1].
        *   *Method A (Volume Ratio):* $\bm{\lambda} = \left(\frac{V_{x234}}{V_{1234}}, \frac{V_{1x34}}{V_{1234}}, \frac{V_{12x4}}{V_{1234}}, \frac{V_{123x}}{V_{1234}}\right)$, where $V_{1234}$ is the volume of $T$ and $V_{x234}$ is the volume of the tetrahedron formed by $\mathbf{x}$ and the face opposite $v_1$ [S1].
        *   *Method B (Ray Intersection Interpolation):* Compute 2D barycentric coordinates $\bm{\lambda}_{in}$ and $\bm{\lambda}_{out}$ at the entry and exit points of $\mathbf{r}$ on the tetrahedron faces. Add 0 for the vertex opposite the face. Interpolate linearly between $\bm{\lambda}_{in}$ and $\bm{\lambda}_{out}$ based on the position of $\mathbf{x}$ along the ray segment inside $T$ [S1].
5.  **Feature Interpolation:** Interpolate the vertex features using $\bm{\lambda}$:
    $$ \mathbf{f}_{\mathbf{x}} = \sum_{i=1}^4 \lambda_i \mathbf{f}_{v_i} $$
    [S1]
6.  **Network Evaluation:**
    *   Pass $\mathbf{f}_{\mathbf{x}}$ through a 3-layer MLP (hidden size 128) to compute raw density $\bar{\sigma}$ and appearance features $\mathbf{a}$ [S1].
    *   Encode ray direction $\mathbf{d}$ using Fourier features [S1].
    *   Concatenate $\mathbf{a}$ and encoded $\mathbf{d}$, pass through a single linear layer to get raw RGB color $\bar{\mathbf{c}}$ [S1].
7.  **Activation:**
    *   Map raw density to volume density: $\sigma = \text{softplus}(\bar{\sigma})$ [S1].
    *   Map raw color to RGB: $\mathbf{c} = \text{sigmoid}(\bar{\mathbf{c}})$ [S1]
8.  **Rendering:** Compute the accumulated weight $\bar{w}_i$ for each sample $i$:
    $$ \bar{w}_i = (1 - \exp(-\sigma_i \delta_i)) \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) $$
    where $\delta_i$ is the distance between adjacent samples [S1]. Normalize weights to $w_i$ and render color:
    $$ \mathbf{C} = \sum_{i=1}^N w_i \mathbf{c}_i $$
    [S1]

def fourier_encode(direction, num_bands=10):

## Operating characteristics
*   **Time Complexity:** Depends on the number of tetrahedra and the efficiency of the ray-triangle intersection. The paper reports training speeds of 15k to 30k rays per second on a single NVIDIA A100 GPU [S1].
*   **Memory Complexity:** Fixed number of parameters. Feature vectors are stored at vertices ($64 \times N$). MLP parameters are constant. This contrasts with methods that grow complexity during training [S1].
*   **Strengths:** Adaptive resolution (denser near surfaces), continuous representation (no empty regions), fixed parameter count [S1].
*   **Limitations:** Limited to the convex hull of the point cloud. Limiting intersections to 512 triangles can cause artifacts in large/fine scenes [S1]. Edge artifacts if point cloud is too sparse (mitigated by adding random points) [S1].
*   **When to use:** When a good initial point cloud (SfM/MVS) is available and adaptive resolution is desired without the complexity of growing representations [S1].
*   **When not to use:** For scenes with large empty spaces outside the convex hull of the point cloud, or where the point cloud is extremely sparse and cannot be augmented effectively [S1].

## Background
Tetra-NeRF was introduced in 2023 by [S1]. It builds on the idea of using explicit geometric representations (like voxel grids or point clouds) to accelerate NeRF training and rendering, but addresses the sparsity of point clouds and the rigidity of voxel grids by using Delaunay triangulation [S1]. It is implemented using CUDA and NVIDIA's OptiX library for acceleration [S1].
