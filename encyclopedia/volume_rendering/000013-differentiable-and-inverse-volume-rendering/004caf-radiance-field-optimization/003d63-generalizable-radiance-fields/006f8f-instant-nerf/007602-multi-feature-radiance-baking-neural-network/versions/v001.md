# Multi-feature Radiance Baking Neural Network

Also called: MRPNN, Multi-feature Radiance Baking

## Overview
Multi-feature Radiance Baking Neural Network (MRBNN) is a neural volumetric rendering method that achieves real-time performance by leveraging analytic decomposition of scattering with an efficient learned representation [S1]. It reformulates the in-scattering integral in the Volumetric Radiance Transfer Equation (VRTE) into a diagonal scaling operator in the spherical harmonics spectrum, eliminating explicit spherical integration [S1]. Unlike its parent [Instant-NeRF](21892-instant-nerf.md) and sibling [MRPNN](21892-instant-nerf.md), MRBNN operates without the low-density volume assumption, supports spatially varying albedo and heterogeneous phase functions, and achieves a 4–5× speedup over state-of-the-art methods while maintaining high visual fidelity [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Camera position, viewing direction $\omega$, volume bounding box, scattering coefficients (albedo $\alpha$, phase function parameter $g$), and light direction $\omega_s$.
*   **Outputs:** Radiance $S(p, \omega)$ at point $p$.

**Data Structures:**
1.  **Feature Grids:** Multi-resolution voxel grids storing features.
    *   **Base Grid ($\mathcal{B}$):** Stores base features. Sampled via towards-light sampling.
    *   **Transmittance Map ($\mathcal{T}$):** Stores optical depth normalized by maximum density. Mipmapped.
    *   **Light Grid ($\mathcal{L}$):** Stores spherical harmonic coefficients $L_{i,l}^m(p)$.
    *   **View Grid ($\mathcal{V}$):** Stores view-dependent features.
    *   **Geometry Grid ($\mathcal{G}$):** Stores geometry features.
    *   **Albedo Grid ($\mathcal{A}$):** Stores albedo features.
    *   *Note:* For production volumes, scattering and extinction coefficients are stored as scalar voxels (direction-independent) [S1].
2.  **Latent Features ($O_i$):** Intermediate representations fused across levels. $O_0$ is a zero vector [S1].
3.  **MLPs:** Lightweight networks for feature fusion and decoding. Each MLP consists of two 64-neuron fully-connected layers [S1].

**Parameters:**
*   $M_1$: Number of grid levels and total steps towards light to sample $\mathcal{B}$. Typical value: 4 [S1].
*   $M_2$: Number of steps to sample $\mathcal{T}$. Typical value: 4 [S1].
*   $K$: Order of spherical harmonics expansion [S1].
*   Coordinate Mapping: $\cos \theta \in [-1, 1]$ is mapped to $[0, 1]$ by $(x+1)/2$ [S1].
*   Grid Resolution Mapping: Finer grid resolution is allocated for media with higher albedo using the non-linear mapping $(e^x - 1)/(e - 1)$ [S1].
*   Activation: ReLU6 is used as the final layer activation in MLPs for numeric stability [S1].

**Algorithm Steps:**

1.  **Reformulate Scattering:** The in-scattering integral in the VRTE is reformulated as a diagonal scaling operator in the spherical harmonics spectrum. This allows the scattering operator to be approximated by a low-rank, factorized representation in latent space [S1].
2.  **Sample Base and Transmittance Features:**
    *   Perform towards-light sampling (cone tracing) to sample the Base feature $\mathcal{B}$ and Transmittance feature $\mathcal{T}$ [S1].
    *   Sample $\mathcal{B}$ at $M_1$ points $p_i$ along the towards-light direction.
    *   Sample $\mathcal{T}$ at $M_2$ points $p_j$ along the towards-light direction. The step size increases exponentially [S1].
3.  **Extract Multi-Feature Components:** For each level $i \in \{1, \dots, M_1\}$, extract the following features at the current shading point $p$ and view direction $\omega$:
    *   **Base Feature:** $\mathcal{B}_i(p_i)$ sampled at the $i$-th towards-light point [S1].
    *   **Light Feature:** Approximated by summing spherical harmonics: $\sum_{l=0}^K g(p)^l \sum_{m=-l}^l \mathcal{L}_{i,l}^m(p)Y_l^m(\omega_s)$ [S1].
    *   **View Feature:** $\mathcal{V}_i(\omega)$ [S1].
    *   **Geometry Feature:** $\mathcal{G}_i(g(p), \cos \theta)$ [S1].
    *   **Albedo Feature:** $\mathcal{A}_i(\alpha(p, \omega), \cos \theta)$ [S1].
    *   **Transmittance Vector:** A vector of $M_2$ samples $[\mathcal{T}_i(p_j, \omega_s)]_{j=1}^{M_2}$ [S1].
4.  **Construct Feature Vector:** Concatenate the components to form the feature vector $\mathcal{F}_i(p, \omega)$:
    $$ \mathcal{F}_i(p, \omega) = \left( \mathcal{B}_i(p_i), \sum_{l=0}^K g(p)^l \sum_{m=-l}^l \mathcal{L}_{i,l}^m(p)Y_l^m(\omega_s), \mathcal{V}_i(\omega), \mathcal{G}_i(g(p), \cos \theta), \mathcal{A}_i(\alpha(p, \omega), \cos \theta), [\mathcal{T}_i(p_j, \omega_s)]_{j=1}^{M_2} \right) $$
    [S1]
5.  **Fuse Features Hierarchically:** Use hierarchical residual blocks to fuse features across levels. For level $i$, compute the fused feature $\overline{O_i}$ and update the latent feature $O_i$:
    $$ \overline{O_i}(p, \omega) = \text{Concat}(\mathcal{F}_i(p, \omega), O_{i-1}(p, \omega)) $$
    $$ O_i(p, \omega) = \mathcal{S}_i(\overline{O_i}(p, \omega)) + \overline{O_i}(p, \omega) $$
    where $\mathcal{S}_i$ is an MLP with input and output dimension $D$ [S1]. $O_0$ is initialized to a zero vector [S1].
6.  **Decode Radiance:** After aggregating all $M_1$ levels, use the final MLP $\mathcal{S}_{M_1+1}$ to decode the final latent representation $O_{M_1}$ into radiance [S1].

**Edge Cases and Pitfalls:**
*   **High-frequency Ambient Lighting:** Stochastic light direction drawing causes severe flickering and requires seconds to converge. Baking ambient lighting (treating it as self-emission) stabilizes this [S1].
*   **Low-Density Assumption:** MRBNN does not assume low-density volumes, avoiding over-illumination artifacts in fragmented-volume scenarios where MRPNN fails [S1].
*   **Albedo/Phase Variation:** MRBNN supports spatially varying albedo and heterogeneous phase functions, whereas MRPNN requires consistent parameters throughout the scene [S1].

## Operating characteristics
*   **Time Complexity:** The method achieves real-time performance. MRBNN renders complex multi-scattering effects of dense volumes at 200 FPS for 1024 × 1024 resolution with three-channel albedo [S1].
*   **Memory Complexity:** Uses compact latent-space neural baking with low-rank compression, offering practical space complexity [S1].
*   **Performance:**
    *   Achieves a 4–5× speedup over the state-of-the-art (MRPNN) [S1].
    *   Sampling strategy yields ~1.6× speedup; network inference achieves >20× speedup compared to MRPNN [S1].
    *   MRPNN (single) takes 1.09ms delta tracking, 4.12ms sampling, 13.19ms MLP inference, <0.5ms post-process (51.1 FPS). MRBNN (single) takes 0.653ms MLP inference [S1].
    *   MRPNN (full) takes 19.0ms MLP inference (40.5 FPS). MRBNN (full) takes 0.753ms MLP inference, 203ms post-process (5.01x), resulting in higher FPS [S1].
*   **Strengths:** Real-time rendering, support for spatially varying albedo and heterogeneous phase functions, temporal stability, no low-density assumption.
*   **Limitations:** Requires training (10 epochs per scene, ~4 hours on RTX 4090) [S1]. High-frequency ambient lighting requires baking to avoid flickering [S1].
*   **When to Use:** Real-time volumetric rendering of complex, dense volumes with varying material properties.
*   **When Not to Use:** Scenes with high-frequency ambient lighting if baking is not feasible, or when offline path-tracing quality is required without neural approximation.

## Background
MRBNN was introduced by Jiaming Liang, Hongliang Yuan, Meng Gai, Guoping Wang, and Sheng Li in 2026 at SIGGRAPH Conference Papers '26 [S1]. It builds on the limitations of MRPNN, which assumed fragmented volumes to be continuous low-density volumes (causing over-illumination) and required consistent albedo and phase function parameters [S1]. MRBNN addresses these by using analytic decomposition of scattering and a compact factorized representation [S1].
