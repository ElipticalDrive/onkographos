# HybridNeRF

Also called: Hybrid Surface-Volume NeRF

## Overview
HybridNeRF is a neural rendering method that combines the efficiency of surface-based representations with the flexibility of volumetric rendering to achieve high-fidelity novel-view synthesis at real-time frame rates. It solves the trade-off between the slow sampling required by pure volumetric NeRFs and the inability of pure surface methods to model thin, semi-opaque, or translucent structures. Unlike siblings such as [Surface NeRF](7385-surface-nerf.md) which use a global surfaceness parameter, HybridNeRF learns a spatially-varying surfaceness field $\beta(\mathbf{x})$, allowing it to render most of the scene as thin surfaces (using few samples) while modeling challenging regions volumetrically [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of calibrated images with known camera poses.
*   **Outputs:** A scene representation consisting of a Signed Distance Field (SDF) network, a color network, and a surfaceness grid. The method renders pixel colors $\hat{C}(\mathbf{r})$ for new camera viewpoints.

**Data Structures:**
1.  **SDF Network:** A neural network (MLP) taking 3D coordinates $\mathbf{x}$ as input, outputting a scalar signed distance $f(\mathbf{x})$.
2.  **Color Network:** A neural network taking 3D coordinates $\mathbf{x}$ and a view direction $\mathbf{d}$ as input, outputting a color vector $\mathbf{c}$.
3.  **Surfaceness Grid:** A 3D grid of size $512 \times 512 \times 512$ storing scalar values $\beta(\mathbf{x})$. Values are queried via nearest-neighbor interpolation [S1].
4.  **Feature Grids:** Dense multi-resolution 3D feature grids and multi-resolution triplanes are used to featurize 3D sample locations before passing them to the SDF and Color networks [S1].
5.  **Proposal Network:** A small network used to improve sampling efficiency, similar to Nerfacto [S1].

**Numbered Steps:**

1.  **Phase 1: Global Surfaceness Training.**
    Train a VolSDF-like model [S1] where the surfaceness parameter $\beta$ is a single global scalar. The SDF is regularized using a distance-adjusted Eikonal loss to model the background and general geometry.
    
2.  **Phase 2: Spatially-Varying Surfaceness Fine-tuning.**
    Transition from the global $\beta$ to a position-dependent field $\beta(\mathbf{x})$. Initialize the $512^3$ grid with the global $\beta$ value. Allow the grid values to diverge spatially during fine-tuning. This enables the model to treat most of the scene as thin surfaces (high $\beta$) while maintaining volumetric flexibility (lower $\beta$) near fine structures, semi-opaque areas, or thin wires [S1].

3.  **Rendering (Sphere Tracing).**
    For a given ray $\mathbf{r}$, use sphere tracing to identify sample locations. This leverages the fact that the model behaves as a valid SDF in $>95\%$ of the scene [S1].
    *   Iterate to find intersections with the zero-level set of $f(\mathbf{x})$.
    *   Evaluate the density $\sigma_{\text{SDF}}(\mathbf{x})$ and color $\mathbf{c}$ at the sampled points.
    *   Compute the transmittance and accumulated color using the standard volume rendering equation.

**Formulas:**

The density $\sigma_{\text{SDF}}(\mathbf{x})$ is derived from the SDF output $f(\mathbf{x})$ and the local surfaceness $\beta(\mathbf{x})$:

$$
\sigma_{\text{SDF}}(\mathbf{x}) := \beta(\mathbf{x})\Psi(f(\mathbf{x})\beta(\mathbf{x}))
$$

where $\Psi$ is the Cumulative Distribution Function (CDF) of a standard Laplace distribution:

$$
\Psi(s) = \begin{cases} \frac{1}{2} \exp(-s) & \text{if } s > 0 \\ 1 - \frac{1}{2} \exp(s) & \text{if } s \leq 0. \end{cases}
$$

The Eikonal loss regularization ensures the gradient of the SDF has unit norm:

$$
\mathcal{L}_{\text{Eik}}(\mathbf{r}) := \sum_{i=0}^{N-1} \eta_i (\|\nabla f(\mathbf{x}_i)\| - 1)^2
$$

where $\eta_i$ is a per-sample loss weight, typically set to 1 [S1].

**Parameters:**
*   **Surfaceness Grid Resolution:** $512^3$ [S1].
*   **Interpolation:** Nearest-neighbor [S1].
*   **Eikonal Weight ($\eta_i$):** 1 [S1].
*   **Rendering Resolution:** Tested at 2K×2K (VR resolution) [S1].

    neg_mask = ~pos_mask
    result[pos_mask] = 0.5 * np.exp(-s[pos_mask])
    result[neg_mask] = 1.0 - 0.5 * np.exp(s[neg_mask])

**Subtopics:**
*   **VolSDF:** A foundational method that interprets MLP outputs as SDFs and uses a global $\beta$ to convert SDF to density. HybridNeRF builds on this by making $\beta$ spatially adaptive [S1].
*   **Surface NeRF:** Methods that rely purely on surface representations. HybridNeRF differs by retaining volumetric capabilities in specific regions via $\beta(\mathbf{x})$ [S1].

## Operating characteristics
*   **Time Complexity:** Rendering is significantly faster than standard NeRF because sphere tracing allows the use of far fewer samples per ray for the $>95\%$ of the scene that behaves as a surface [S1].
*   **Memory Complexity:** The surfaceness grid requires memory for a $512^3$ grid of floats. The neural networks (SDF, Color, Feature Grids) also consume memory, but the reduction in sampling count reduces the computational load per pixel [S1].
*   **Measured Performance:** Achieves real-time framerates of at least 36 FPS for virtual-reality resolutions (2K×2K) [S1].
*   **Accuracy:** Improves error rates by 15–30% compared to state-of-the-art baselines, including rasterization-based approaches, on datasets like Eyeful Tower [S1].
*   **Strengths:** High rendering speed, high fidelity for thin structures and semi-opaque areas, real-time capability.
*   **Limitations:** Requires careful tuning of the surfaceness grid initialization and training phases. Sphere tracing assumes the SDF is well-behaved, which may not hold in all volumetric regions if $\beta$ is too low [S1].

## Background
HybridNeRF was introduced by Haithem Turki et al. in 2024 [S1]. It addresses the limitations of pure surface-based neural fields, which struggle with thin structures and view-dependent effects like refraction and translucency, and pure volumetric NeRFs, which are slow to render. The method was developed to enable efficient rendering for immersive applications such as augmented reality and virtual teleconferencing [S1].
