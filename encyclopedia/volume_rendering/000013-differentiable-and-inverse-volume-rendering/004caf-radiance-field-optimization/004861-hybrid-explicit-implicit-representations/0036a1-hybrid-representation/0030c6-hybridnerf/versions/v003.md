# HybridNeRF

Also called: Hybrid Surface-Volume NeRF

## Overview
HybridNeRF is a radiance field optimization method that combines explicit surface representations with implicit volumetric modeling to achieve high-fidelity novel-view synthesis at real-time frame rates [S1]. It addresses the computational expense of pure implicit NeRFs and the reconstruction limitations of pure surface-based methods by rendering most of the scene as thin surfaces while modeling challenging regions (thin structures, semi-opaque areas) volumetrically using spatially-varying surfaceness parameters $\beta(\mathbf{x})$ [S1]. Unlike prior work that treats surfaceness as a global parameter, HybridNeRF learns $\beta$ in a spatially adaptive manner, allowing it to improve error rates by 15–30% compared to state-of-the-art baselines while achieving at least 36 FPS for 2K×2K virtual-reality resolutions [S1].

## How it works
**Inputs:** A set of calibrated images with known camera poses [G].
**Outputs:** A rendered image for a target camera pose, and trained model parameters (SDF MLP, color MLP, surfaceness grid) [G].

**Data Structures:**
1. **SDF and Color Networks:** Two separate multi-layer perceptrons (MLPs) [S1]. The SDF network takes 3D coordinates and features as input and outputs a signed distance value $f(\mathbf{x})$ [S1]. The color network takes 3D coordinates, features, and viewing direction as input and outputs color $\mathbf{c}$ [S1].
2. **Feature Grids:** Dense multi-resolution 3D feature grids in combination with multi-resolution triplanes [S1]. These store features for 3D sample locations [S1].
3. **Surfaceness Grid:** A 3D grid of size $512^3$ storing scalar values for $\beta(\mathbf{x})$ [S1].
4. **Proposal Network:** A small network similar to Nerfacto used to improve sampling efficiency by predicting likely surface locations [S1].

**Parameters:**
* $\beta(\mathbf{x})$: Surfaceness parameter. Initially uniform, then spatially varying [S1].
* $\eta_i$: Per-sample loss weight for Eikonal regularization, typically set to 1 [S1].

**Algorithm Steps:**
1. **Initialization:** Initialize the SDF network, color network, feature grids, and the surfaceness grid. Set all values in the surfaceness grid to a uniform constant $\beta$ [G].
2. **Phase 1: Global Surfaceness Training:** Train the model using a VolSDF-like approach [S1]. Sample points along rays. Compute the Eikonal loss to regularize the SDF gradient magnitude to 1: $\mathcal{L}_{\text{Eik}}(\mathbf{r}) := \sum_{i=0}^{N-1} \eta_i (\|\nabla f(\mathbf{x}_i)\| - 1)^2$, where $\mathbf{x}_i$ are sample points along ray $\mathbf{r}$, and $\eta_i = 1$ [S1]. Convert SDF $f(\mathbf{x})$ to density $\sigma_{\text{SDF}}(\mathbf{x})$ using the global $\beta$: $\sigma_{\text{SDF}}(\mathbf{x}) := \beta \Psi(f(\mathbf{x})\beta)$ [S1]. Render the image using standard volume rendering integration [S1]. Optimize network weights and the uniform $\beta$ value [S1].
3. **Phase 2: Spatially-Varying Surfaceness Transition:** Transition from the global $\beta$ to position-dependent $\beta(\mathbf{x})$ values [S1]. Initialize the $512^3$ surfaceness grid with the converged global $\beta$ value [S1]. Enable gradient updates for the surfaceness grid values [G]. Continue training with the same loss functions, but now $\beta$ is queried from the grid at each sample location $\mathbf{x}_i$: $\beta(\mathbf{x}_i) = \text{GridQuery}(\mathbf{x}_i)$ [S1]. The surfaceness grid is queried via nearest-neighbor interpolation [S1]. This allows the model to maintain high surfaceness (thin surfaces) in most of the scene while lowering $\beta$ (more volumetric) in regions with thin structures or semi-opaque areas to preserve quality [S1].
4. **Rendering:** For a given camera ray, use sphere tracing to identify sample locations, leveraging the fact that the model behaves as a valid SDF in >95% of the scene [S1]. At each sample point $\mathbf{x}_i$: Query features from the multi-resolution grids [S1]. Query $\beta(\mathbf{x}_i)$ from the $512^3$ grid using nearest-neighbor interpolation [S1]. Compute density: $\sigma_{\text{SDF}}(\mathbf{x}_i) = \beta(\mathbf{x}_i) \Psi(f(\mathbf{x}_i)\beta(\mathbf{x}_i))$ [S1]. Compute color $\mathbf{c}(\mathbf{x}_i)$ from the color network [S1]. Perform volume rendering integration using the computed densities and colors [S1].

**Pseudocode:**
```python
import numpy as np

def laplace_cdf(s):
    """Computes the CDF of a standard Laplace distribution."""
    return 0.5 * np.exp(-s) if s > 0 else 1.0 - 0.5 * np.exp(s)

def compute_density(sdf_val, beta):
    """Converts SDF value and surfaceness to density."""
    return beta * laplace_cdf(sdf_val * beta)

def query_surfaceness_grid(x, grid, bounds=1.0):
    """Queries the 512x512x512 surfaceness grid via nearest-neighbor interpolation."""
    # Map world coordinates x in [-bounds, bounds]^3 to grid indices [0, 511]
    idx = np.round((x + bounds) / (2 * bounds) * 511).astype(int)
    idx = np.clip(idx, 0, 511)
    return grid[idx[0], idx[1], idx[2]]

def compute_gradient(network, x):
    """[G] Computes spatial gradient of the SDF network at x."""
    eps = 1e-4
    grad = np.zeros(3)
    for d in range(3):
        x_p = x.copy(); x_p[d] += eps
        x_m = x.copy(); x_m[d] -= eps
        grad[d] = (network(x_p) - network(x_m)) / (2 * eps)
    return grad

def train_phase1(images, poses, sdf_net, color_net, feat_grids, beta_global, epochs):
    """Phase 1: Train with globally uniform surfaceness."""
    for _ in range(epochs):
        for img, pose in zip(images, poses):
            rays = generate_rays(pose)
            pts = proposal_sample(rays, sdf_net, feat_grids)
            sdf_vals = sdf_net(pts, feat_grids)
            colors = color_net(pts, feat_grids, rays.dirs)
            dens = compute_density(sdf_vals, beta_global)
            rendered = volume_render(rays, dens, colors)
            loss_rgb = mse(rendered, img)
            eik = sum((np.linalg.norm(compute_gradient(sdf_net, p)) - 1)**2 for p in pts)
            total = loss_rgb + eik
            update_params(sdf_net, color_net, feat_grids, beta_global, total)

def train_phase2(images, poses, sdf_net, color_net, feat_grids, surf_grid, beta_global, epochs):
    """Phase 2: Transition to spatially-varying surfaceness."""
    surf_grid[:] = beta_global
    for _ in range(epochs):
        for img, pose in zip(images, poses):
            rays = generate_rays(pose)
            pts = proposal_sample(rays, sdf_net, feat_grids)
            sdf_vals = sdf_net(pts, feat_grids)
            colors = color_net(pts, feat_grids, rays.dirs)
            betas = np.array([query_surfaceness_grid(p, surf_grid) for p in pts])
            dens = compute_density(sdf_vals, betas)
            rendered = volume_render(rays, dens, colors)
            loss_rgb = mse(rendered, img)
            eik = sum((np.linalg.norm(compute_gradient(sdf_net, p)) - 1)**2 for p in pts)
            total = loss_rgb + eik
            update_params(sdf_net, color_net, feat_grids, surf_grid, total)

def render(camera_pose, surf_grid, sdf_net, color_net, feat_grids, max_dist=10.0, eps=1e-4):
    """Renders an image using sphere tracing."""
    rays = generate_rays(camera_pose)
    img = np.zeros(rays.origin.shape)
    for i, ray in enumerate(rays):
        t = 0.0
        samples = []
        while t < max_dist:
            p = ray.origin + t * ray.dir
            sdf_val = sdf_net(p, feat_grids)
            if abs(sdf_val) < eps:
                samples.append(p)
                break
            t += max(sdf_val, eps)
            beta = query_surfaceness_grid(p, surf_grid)
            samples.append((p, compute_density(sdf_val, beta)))
        img[i] = volume_render_ray(ray, samples)
    return img
```

**Edge Cases and Pitfalls:**
* **Precision:** Sphere tracing relies on the SDF property $\|\nabla f(\mathbf{x})\| \approx 1$ [S1].
* **Boundaries:** The surfaceness grid is finite ($512^3$). Points outside the grid bounds must be handled, typically by clamping or assuming a default $\beta$ [G].
* **Degenerate Input:** Thin structures and semi-opaque areas require lower $\beta$ values [S1].

## Subtopics

### VolSDF
A method that interprets MLP outputs as a signed distance field (SDF) and regularizes the gradient norm to 1 using Eikonal loss [S1]. It serves as the foundation for the SDF representation in HybridNeRF [S1].

### Nerfacto
A method that uses a proposal network to improve sampling efficiency in neural radiance fields [S1]. HybridNeRF uses a similar proposal network [S1].

### Multi-resolution Triplanes
A technique for featurizing 3D locations using 2D planes [S1]. HybridNeRF uses this for feature storage [S1].

## Operating characteristics
* **Time Complexity:** Rendering is accelerated by sphere tracing, which requires far fewer samples per ray than uniform volumetric sampling, as the model behaves as a valid SDF in >95% of the scene [S1].
* **Memory Complexity:** The model uses dense multi-resolution 3D feature grids, multi-resolution triplanes, and a $512^3$ surfaceness grid [S1].
* **Measured Performance:** HybridNeRF improves error rates by 15–30% compared to state-of-the-art baselines, including rasterization-based approaches, while achieving real-time framerates (at least 36 FPS) for virtual-reality resolutions (2K×2K) [S1].
* **Strengths:** High rendering efficiency due to surface-like behavior in most of the scene; high fidelity in challenging regions (thin structures, semi-opaque areas) due to volumetric modeling; real-time performance [S1].
* **Limitations:** Requires careful tuning of the surfaceness grid and Eikonal loss [S1].
* **When to use:** When real-time rendering is required and the scene contains a mix of solid surfaces and thin/semi-opaque structures [S1].
* **When not to use:** For scenes that are entirely volumetric (e.g., smoke, fire) or entirely solid without thin structures, pure volumetric or pure surface methods may be more appropriate [G].

## Background
HybridNeRF was proposed by Haithem Turki et al. in 2024 [S1]. It builds on previous work in surface-based neural fields, such as VolSDF [S1], which interprets MLP outputs as SDFs. The key innovation is the introduction of spatially-varying surfaceness parameters $\beta(\mathbf{x})$, replacing the global $\beta$ used in prior work [S1]. The method was evaluated on the Eyeful Tower dataset [S1] and other commonly used view synthesis datasets [S1].
