# Plenoxels Optimization Configuration

Also called: Plenoxels optimizer settings, RMSProp vs SGD for Plenoxels

## Overview
Plenoxels Optimization Configuration defines the gradient-based training protocol for optimizing voxel opacity ($\sigma$) and spherical harmonic (SH) coefficients in a static 3D voxel grid. It solves the problem of efficiently fitting multi-view images into a discretized radiance field without neural network MLPs. It differs from its siblings by using a fixed-resolution grid optimized via specific learning rate schedules and optimizer choices, whereas [Coarse-to-Fine Optimization with Pruning](1153-coarse-to-fine-optimization-with-pruning.md) dynamically adjusts grid density, and [PlenOctree Optimization](1291-plenoctree-optimization.md) uses a hierarchical tree structure.

## How it works
**Inputs and Outputs:**
- Input: Multi-view images, camera poses, and a target voxel grid resolution (e.g., $256^3$).
- Output: Optimized voxel opacity values ($\sigma$) and SH coefficients for each voxel.

**Data Structures:**
- **Voxel Grid:** A 3D array of size $N \times N \times N$. Each voxel stores:
  - Opacity ($\sigma$): A scalar value.
  - SH Coefficients: A vector of coefficients representing directional color/intensity. The degree of SH determines the vector size (e.g., degree 9 requires specific coefficient counts).

**Numbered Steps:**
1. **Initialization:** Initialize the voxel grid with opacity and SH coefficients. [G] Typically, opacity is initialized to a small positive value or derived from space carving, and SH coefficients to zero or mean color.
2. **Optimizer Selection:** Select the gradient-based optimizer. RMSProp is preferred over SGD, particularly for optimizing SH coefficients, though the method is robust to variations [S1].
3. **Learning Rate Schedule Configuration:** Configure distinct learning rate schedules for $\sigma$ and SH coefficients. The optimal configuration uses a delayed learning rate schedule for $\sigma$ and a constant schedule for SH [S1].
4. **Training Loop:**
   - Render images from current voxel grid.
   - Compute loss (e.g., MSE) against ground truth images.
   - Compute gradients for $\sigma$ and SH coefficients.
   - Update parameters using the selected optimizer and schedules.
5. **Regularization (Optional):** Apply TV loss or sparsity constraints if specified [S1].

**Formulas:**
- Rendering involves integrating opacity and SH along rays. The specific SH evaluation formula depends on the degree.
- Loss function: Typically Mean Squared Error (MSE) between rendered and target images.

**Parameters:**
- **Optimizer:** RMSProp [S1].
- **Resolution:** $256^3$ for standard benchmarks [S1].
- **SH Degree:** Not explicitly fixed in the primary configuration notes, but degree 9 is used in related implementations [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** Ensure stable gradient updates for SH coefficients, which may have varying magnitudes.
- **Boundaries:** Handle voxel boundaries carefully during interpolation or rendering.

**Pseudocode:**
```python
# Configuration
```

## Subtopics

### Space Carving and Opaque Voxels Optimization with Spherical Harmonics
A technique composed of two steps: space carving and opaque voxels optimization, used to generate neural radiance fields based on plenoxels [S2, unofficial]. Spherical harmonics of degree 9 are used to render the shading of each voxel [S2, unofficial]. Running the implementation `main_carve_sph.py` takes approximately 4 minutes on a single GPU [S2, unofficial].

### Plenoxels Training
Training implementation of plenoxels that saves the final voxel grid [S2, unofficial]. The final voxel grid resolution is 128x128x128 [S2, unofficial]. Running the training implementation `main.py` takes approximately 30 minutes on a single GPU [S2, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
- Memory: Scales with $N^3$ for the voxel grid, where $N$ is the resolution. Each voxel stores opacity and SH coefficients.
- Time: Training time depends on resolution and number of views. For $256^3$ resolution, training time is not explicitly given in [S1], but [S2, unofficial] reports ~30 minutes for $128^3$ on a single GPU.

**Measured Performance:**
- On 8 synthetic NeRF scenes at $256^3$ resolution, RMSProp for both SH and $\sigma$ achieves PSNR 30.57, SSIM 0.950, LPIPS 0.065 [S1].
- SGD for both drops to PSNR 29.35, SSIM 0.932, LPIPS 0.087 [S1].
- Delayed schedule for $\sigma$ and constant for SH yields best results (PSNR 30.57) [S1]. Constant for both yields lower quality (PSNR 30.13) [S1].

**Strengths and Limitations:**
- Strengths: Fast training compared to MLP-based NeRFs; robust to variations in optimizer and schedule [S1].
- Limitations: Fixed resolution may lead to inefficiencies in sparse regions; requires careful tuning of SH degree and resolution.

**When to Use:**
- Use when fast training and inference are required, and the scene can be represented well by a fixed-resolution voxel grid.

## Background
Originated in the paper "Plenoxels: Radiance Fields without Neural Networks" [S1]. It represents an alternative to MLP-based NeRFs by using a voxel grid with SH coefficients. The method is part of the broader field of differentiable and inverse volume rendering.
