# Plenoxel


## Overview
Plenoxel is a neural network-free radiance field representation that models a scene as a sparse 3D grid, calculating color and opacity via trilinear interpolation during ray casting [S2]. It distinguishes itself from its parent [Plenoxels Optimization Configuration](929-plenoxels-optimization-configuration.md) and sibling [Plenoxels Training](5979-plenoxels-training.md) by relaxing the assumption of constant opacity and spherical harmonic (SH) coefficients within each voxel, instead using trilinear interpolation to define a continuous function throughout the volume [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Sparse 3D voxel grid containing learnable features (opacity and SH coefficients).
*   **Output:** Per-pixel color and transmittance for a given camera view.

**Data Structures:**
The scene is represented as a sparse 3D grid [S2]. Unlike standard PlenOctrees which assume piecewise constant values, Plenoxel stores values at voxel corners or centers that are interpolated [S1].
*   **Voxel Content:** Each voxel location holds learnable parameters for opacity ($\sigma$) and spherical harmonic coefficients [S1].
*   **Interpolation:** Trilinear interpolation is used to compute values at arbitrary points within the volume [S1, S2].

**Steps:**
1.  **Ray Casting:** For each pixel, cast a ray through the scene [S2].
2.  **Sampling:** Sample points along the ray [S2].
3.  **Feature Retrieval:** For each sample point, determine its position relative to the voxel grid [S1].
4.  **Interpolation:** Use trilinear interpolation to compute the opacity and SH coefficients at the sample point from the surrounding voxel data [S1, S2].
5.  **Rendering:** Integrate the interpolated opacity and color (derived from SH coefficients) along the ray to produce the final pixel color [S2].
6.  **Optimization:** Directly optimize the voxel opacities and SH coefficients using gradient-based methods without a neural network [S1].

**Formulas:**
Let $v$ be a sample point in 3D space. The value $f(v)$ (opacity or SH coefficient) is computed via trilinear interpolation of the 8 surrounding voxel values.
$$ f(v) = \sum_{i=0}^{7} w_i f_i $$
where $f_i$ are the values at the 8 corners of the containing voxel and $w_i$ are the trilinear weights determined by the relative position of $v$ within the voxel [S1, S2].

**Parameters:**
*   **Grid Sparsity:** Not given in the sources.
*   **SH Degree:** Not given in the sources.
*   **Learning Rate:** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Boundaries:** Trilinear interpolation requires valid voxel neighbors. Handling rays that exit the sparse grid boundary requires specific logic (e.g., assuming zero opacity/color outside) [G].
*   **Precision:** Trilinear interpolation is computationally cheaper than MLP queries but may introduce smoothing artifacts compared to higher-order interpolation or neural representations [S1].

**Pseudocode:**
```python
def render_plenoxel(ray_origin, ray_direction, voxel_grid):
    """
    Renders a single ray using Plenoxel representation.
    voxel_grid: Sparse structure mapping (x,y,z) -> (opacity, sh_coeffs)
    """
    # 1. Sample points along the ray
    # Standard NeRF sampling strategy (e.g., uniform + stratified)
    sample_points = sample_along_ray(ray_origin, ray_direction, num_samples=192) # [S2]
    
    final_color = [0.0, 0.0, 0.0]
    T = 1.0  # Transmittance
    
    for point in sample_points:
        # 2. Check if point is within the sparse grid bounds
        if not voxel_grid.contains(point):
            break
            
        # 3. Retrieve and interpolate features
        # Trilinear interpolation of opacity and SH coefficients
        sigma = voxel_grid.trilinear_interpolate_opacity(point)
        sh_coeffs = voxel_grid.trilinear_interpolate_sh(point)
        
        # 4. Compute color from SH coefficients
        # Direction vector for SH evaluation
        direction = normalize(ray_direction)
        color = evaluate_sh(sh_coeffs, direction)
        
        # 5. Accumulate color
        # Alpha compositing: C = sum(T * (1 - exp(-sigma * delta)) * color)
        # Approximation for small delta or standard NeRF integration
        alpha = 1.0 - exp(-sigma) # Assuming unit step or pre-computed delta
        T_current = T * (1.0 - alpha)
        final_color += T * alpha * color
        T = T_current
        
        if T < 1e-4:
            break
            
    return final_color
```

## Operating characteristics
*   **Time Complexity:** Significantly faster than MLP-based NeRFs. Standard NeRF requires hundreds of MLP queries per pixel (e.g., 192 samples * 256 MLPs = ~49,152 queries per pixel in some contexts, or 235,929,600 total for an image) [S2]. Plenoxel replaces MLP queries with trilinear interpolation, reducing computational cost by orders of magnitude [S2].
*   **Memory Complexity:** Depends on the sparsity of the 3D grid. Sparse grids reduce memory usage compared to dense grids [S2].
*   **Performance:** In standard benchmark tasks, Plenoxels optimized with Instant-NGP algorithms are 2 orders of magnitude faster than JNeRF without loss in visual quality [S2].
*   **Strengths:** No neural network overhead; fast inference and training; efficient memory usage via sparsity.
*   **Limitations:** Trilinear interpolation may lack the representational power of neural networks for complex high-frequency details [S1].

## Background
Plenoxel was proposed by Fridovich-Keil et al. in 2022 [S2]. It was introduced as a NeRF model that does not use neural networks, representing the scene as a sparse 3D grid and calculating color and opacity via trilinear interpolation [S2]. It relaxes the PlenOctrees assumption of constant opacity and SH coefficients within each voxel [S1].
