# Plenoxels

Also called: Plenoxels Alpha, Radiance Fields without Neural Networks, Volumetric rendering using ReLU fields

## Overview
Plenoxels is a method for representing radiance fields using a sparse 3D grid of trilinearly interpolated values instead of neural networks, allowing for fast optimization and rendering [S1, S3, unofficial]. It solves the high computational cost of training and rendering Neural Radiance Fields (NeRF) by replacing the multi-layer perceptron (MLP) with explicit density scalars and Spherical Harmonic (SH) coefficients stored in voxel cells [S3, S4, unofficial]. Unlike NeRF, which uses MLPs for density and color, Plenoxels uses a static 3D grid with SH coefficients for color and a single density value per cell, allowing for faster evaluation without neural network inference [S3, unofficial]. It builds on [Radiance-field optimization](44-radiance-field-optimization.md).

## How it works
**Inputs:** A set of calibrated images with known camera poses (position, orientation, intrinsics).
**Outputs:** A rendered image for a given camera pose, or a trained grid model.

**Data Structures:**
The core data structure is a `Grid` containing a flat array of `Cell` structures.
*   **Grid:**
    *   `cells`: Flat array of `Cell` objects. Size is `constants::total` (e.g., $128^3 = 2,097,152$) [S3, unofficial].
    *   `minPoint`: World position of the grid origin, typically $(-1, -1, -1)$ [S3, unofficial].
    *   `maxPoint`: World position of the grid corner, typically $(1, 1, 1)$ [S3, unofficial].
    *   `grid_size`: Integer dimensions of the grid (e.g., $[128, 128, 128]$) [S3, unofficial].
*   **Cell:**
    *   `density`: Scalar float representing volume density $\sigma$ [S3, unofficial].
    *   `shr`: Array of 9 floats (2nd order SH coefficients for Red) [S3, unofficial].
    *   `shg`: Array of 9 floats (2nd order SH coefficients for Green) [S3, unofficial].
    *   `shb`: Array of 9 floats (2nd order SH coefficients for Blue) [S3, unofficial].
    *   Total size: 28 floats [S3, unofficial].

**Parameters:**
*   `opt.step_size` / `delta_step`: Fixed step size for ray marching [S1, S2, unofficial].
*   `opt.sigma_thresh`: Minimum density threshold for a sample to contribute to color accumulation [S1, unofficial].
*   `opt.stop_thresh`: Transmission threshold below which ray marching terminates early [S1, unofficial].
*   `opt.background_brightness`: Constant background color value added if no background layers are defined [S1, unofficial].
*   `num_samples`: Number of samples taken along each ray [S2, unofficial].
*   `constants::bins`: Number of partitions along the ray segment within grid bounds (e.g., 100) [S3, unofficial].
*   `constants::shsize`: Dimensionality of SH basis (9 for 2nd order, $l=0,1$) [S3, unofficial].

**Algorithm Steps:**

1.  **Camera Ray Generation:**
    For a pixel $(x, y)$ in an image of size $W \times H$:
    1.  Calculate aspect ratio $AR = W/H$.
    2.  Calculate focal length $focal = 2 \cdot \tan(FOV/2)$ [S3, unofficial].
    3.  Calculate normalized screen coordinates $u = (x + 0.5)/W$, $v = (y + 0.5)/H$ [S3, unofficial].
    4.  Compute ray direction in camera space:
        $$x = \text{lerp}(-w/2, w/2, u)$$
        $$y = \text{lerp}(h/2, -h/2, v)$$
        $$z = -1$$
        $$\mathbf{d}_{cam} = \text{normalize}(x, y, z)$$
    5.  Transform ray direction and origin using the camera view matrix to get world-space ray $\mathbf{r}$ and origin $\mathbf{p}_0$ [S3, unofficial].

2.  **Ray-Grid Intersection:**
    Compute entry ($t_{min}$) and exit ($t_{max}$) distances for the ray against the grid's axis-aligned bounding box defined by `minPoint` and `maxPoint` using the slab method [S3, unofficial]:
    $$\mathbf{r}_{inv} = 1.0 / \mathbf{r}$$
    $$t_{min} = \max(\min(\mathbf{r}_{inv} \cdot (\text{minPoint} - \mathbf{p}_0)), \min(\mathbf{r}_{inv} \cdot (\text{maxPoint} - \mathbf{p}_0)))$$
    $$t_{max} = \min(\max(\mathbf{r}_{inv} \cdot (\text{minPoint} - \mathbf{p}_0)), \max(\mathbf{r}_{inv} \cdot (\text{maxPoint} - \mathbf{p}_0)))$$
    If $t_{min} > t_{max}$, the ray misses the grid [S3, unofficial].

3.  **Ray Marching and Accumulation:**
    Iterate from $t = t_{min}$ to $t_{max}$ with step size `delta_step` (or `opt.step_size`) [S1, S2, unofficial]. For each sample point $\mathbf{p}$:
    1.  **Grid Lookup:** Convert world position $\mathbf{p}$ to integer grid coordinate `coord` and fractional offset `sample` [S3, unofficial]:
        $$\text{coord} = \text{floor}\left( \frac{\text{grid\_size} - 1}{2} (\mathbf{p} + 1.0) \right)$$
        $$\mathbf{p}_0 = \text{position}(\text{coord})$$
        $$\mathbf{p}_1 = \text{position}(\text{coord} + (1,1,1))$$
        $$\text{sample} = (\mathbf{p} - \mathbf{p}_0) / (\mathbf{p}_1 - \mathbf{p}_0)$$
    2.  **Trilinear Interpolation:** Fetch the 8 corner cells $c_{ijk}$ using `get(coord + offset, ray)` and interpolate [S3, unofficial]:
        $$c_{00} = c_{000}(1-s_x) + c_{100}s_x, \quad c_{01} = c_{001}(1-s_x) + c_{101}s_x$$
        $$c_{10} = c_{010}(1-s_x) + c_{110}s_x, \quad c_{11} = c_{011}(1-s_x) + c_{111}s_x$$
        $$c_{0} = c_{00}(1-s_y) + c_{10}s_y, \quad c_{1} = c_{01}(1-s_y) + c_{11}s_y$$
        $$c = c_{0}(1-s_z) + c_{1}s_z$$
        Where $c_{ijk}$ contains $(\sigma, \mathbf{c}_{RGB})$ [S3, unofficial].
    3.  **SH Evaluation:** Evaluate Spherical Harmonics for the ray direction $\mathbf{d}$ to get basis values $\mathbf{b}$ [S3, unofficial]:
        $$\mathbf{b} = \text{SH}(\mathbf{d})$$
        Basis functions (2nd order, $l=0,1$):
        $$Y_0 = 0.28209479177387814$$
        $$Y_1(z) = z \cdot 0.488602511902919923$$
        $$Y_2(z^2) = z^2 \cdot 0.94617469575756008 - 0.315391565252520045$$
        $$Y_3(x) = -0.488602511902919978 \cdot x$$
        $$Y_4(y) = -0.488602511902919978 \cdot y$$
        $$Y_5(xz) = -1.09254843059207896 \cdot z \cdot x$$
        $$Y_6(yz) = -1.09254843059207896 \cdot z \cdot y$$
        $$Y_7(x^2-y^2) = 0.546274215296039478 \cdot (x^2 - y^2)$$
        $$Y_8(xy) = 0.546274215296039478 \cdot (2xy)$$
        Color $\mathbf{C} = \sum_{k=0}^{8} \text{SH}_k \cdot b_k$ [S3, unofficial].
    4.  **Accumulation:**
        Compute attenuation $\Delta \tau = \sigma \cdot \Delta t$ [S1, unofficial].
        Update transmittance $T = T \cdot e^{-\Delta \tau}$ [S1, unofficial].
        Compute weight $w = T \cdot (1 - e^{-\Delta \tau})$ [S1, unofficial].
        Accumulate color: $\mathbf{C}_{out} += w \cdot \mathbf{C}$ [S1, unofficial].
        Clamp color to non-negative: $\mathbf{C}_{out} = \max(\mathbf{C}_{out}, 0)$ [S1, unofficial].
    5.  **Early Termination:** If $T < \text{opt.stop\_thresh}$, break loop [S1, unofficial].

4.  **Background Addition:**
    If no background layers are defined, add $T \cdot \text{opt.background\_brightness}$ to the final color [S1, unofficial].

**Pseudocode:**

```python
import math

def evaluate_sh(direction, sh_coeffs):
    """
    Evaluate 2nd order Spherical Harmonics for a given direction.
    direction: (x, y, z)
    sh_coeffs: list of 9 floats for one color channel
    Returns: float value
    """
    x, y, z = direction
    z2 = z * z
    c0 = x
    s0 = y
    c1 = x * c0 - y * s0
    s1 = x * s0 + y * c0
    
    # Basis functions from Mitsuba 3
    b = [0.0] * 9
    b[0] = 0.28209479177387814
    b[1] = -0.488602511902919978 * s0
    b[2] = z * 0.488602511902919923
    b[3] = -0.488602511902919978 * c0
    b[4] = 0.546274215296039478 * s1  # 2xy
    b[5] = -1.09254843059207896 * z * s0
    b[6] = z2 * 0.94617469575756008 - 0.315391565252520045
    b[7] = -1.09254843059207896 * z * c0
    b[8] = 0.546274215296039478 * c1  # x^2-y^2
    
    return sum(c * b_i for c, b_i in zip(sh_coeffs, b))

def trilinear_interpolate(grid, coord, sample, ray_dir):
    """
    Trilinearly interpolate density and color from grid cells.
    grid: Grid object with cells, minPoint, maxPoint, grid_size
    coord: (ix, iy, iz) integer coordinates
    sample: (sx, sy, sz) fractional offsets [0, 1]
    ray_dir: (x, y, z) ray direction for SH evaluation
    Returns: (density, color_rgb)
    """
    # Helper to get cell data
    def get_cell(c):
        # Check bounds
        if not (0 <= c[0] < grid.grid_size[0] and 
                0 <= c[1] < grid.grid_size[1] and 
                0 <= c[2] < grid.grid_size[2]):
            return (0.0, (0.0, 0.0, 0.0))
        
        cell = grid.cells[c[0] * grid.grid_size[1] * grid.grid_size[2] + 
                         c[1] * grid.grid_size[2] + c[2]]
        
        # Evaluate SH for R, G, B
        sh_r = evaluate_sh(ray_dir, cell.shr)
        sh_g = evaluate_sh(ray_dir, cell.shg)
        sh_b = evaluate_sh(ray_dir, cell.shb)
        
        return (cell.density, (sh_r, sh_g, sh_b))

    # Fetch 8 corners
    c000 = get_cell((coord[0], coord[1], coord[2]))
    c100 = get_cell((coord[0]+1, coord[1], coord[2]))
    c010 = get_cell((coord[0], coord[1]+1, coord[2]))
    c110 = get_cell((coord[0]+1, coord[1]+1, coord[2]))
    c001 = get_cell((coord[0], coord[1], coord[2]+1))
    c101 = get_cell((coord[0]+1, coord[1], coord[2]+1))
    c011 = get_cell((coord[0], coord[1]+1, coord[2]+1))
    c111 = get_cell((coord[0]+1, coord[1]+1, coord[2]+1))

    # Interpolate along X
    c00 = (c000[0]*(1-sample[0]) + c100[0]*sample[0], 
           tuple(c000[1][i]*(1-sample[0]) + c100[1][i]*sample[0] for i in range(3)))
    c01 = (c010[0]*(1-sample[0]) + c110[0]*sample[0], 
           tuple(c010[1][i]*(1-sample[0]) + c110[1][i]*sample[0] for i in range(3)))
    c10 = (c001[0]*(1-sample[0]) + c101[0]*sample[0], 
           tuple(c001[1][i]*(1-sample[0]) + c101[1][i]*sample[0] for i in range(3)))
    c11 = (c011[0]*(1-sample[0]) + c111[0]*sample[0], 
           tuple(c011[1][i]*(1-sample[0]) + c111[1][i]*sample[0] for i in range(3)))

    # Interpolate along Y
    c0 = (c00[0]*(1-sample[1]) + c01[0]*sample[1], 
          tuple(c00[1][i]*(1-sample[1]) + c01[1][i]*sample[1] for i in range(3)))
    c1 = (c10[0]*(1-sample[1]) + c11[0]*sample[1], 
          tuple(c10[1][i]*(1-sample[1]) + c11[1][i]*sample[1] for i in range(3)))

    # Interpolate along Z
    density = c0[0]*(1-sample[2]) + c1[0]*sample[2]
    color = tuple(c0[1][i]*(1-sample[2]) + c1[1][i]*sample[2] for i in range(3))
    
    return (density, color)

def render_ray(grid, ray_origin, ray_direction, delta_step, sigma_thresh, stop_thresh, background_brightness):
    """
    Render a single ray using volumetric rendering.
    """
    # Ray-Grid Intersection
    # Assuming grid bounds are minPoint=(-1,-1,-1) and maxPoint=(1,1,1)
    min_point = (-1.0, -1.0, -1.0)
    max_point = (1.0, 1.0, 1.0)
    
    ray_inv = (1.0/ray_direction[0], 1.0/ray_direction[1], 1.0/ray_direction[2])
    
    t_min = max(min(ray_inv[0]*(min_point[0]-ray_origin[0]), ray_inv[0]*(max_point[0]-ray_origin[0])),
                min(ray_inv[1]*(min_point[1]-ray_origin[1]), ray_inv[1]*(max_point[1]-ray_origin[1])),
                min(ray_inv[2]*(min_point[2]-ray_origin[2]), ray_inv[2]*(max_point[2]-ray_origin[2])))
    
    t_max = min(max(ray_inv[0]*(min_point[0]-ray_origin[0]), ray_inv[0]*(max_point[0]-ray_origin[0])),
                max(ray_inv[1]*(min_point[1]-ray_origin[1]), ray_inv[1]*(max_point[1]-ray_origin[1])),
                max(ray_inv[2]*(min_point[2]-ray_origin[2]), ray_inv[2]*(max_point[2]-ray_origin[2])))
    
    if t_min > t_max:
        return (0.0, 0.0, 0.0) # Missed grid

    # Ray Marching
    total_color = (0.0, 0.0, 0.0)
    transmittance = 1.0
    t = t_min
    
    while t < t_max:
        # Position to Coordinate
        # Map world pos to grid coord [0, grid_size-1]
        # Formula: coord = floor( (grid_size - 1) * (pos + 1.0) / 2 )
        pos = (ray_origin[0] + t * ray_direction[0],
               ray_origin[1] + t * ray_direction[1],
               ray_origin[2] + t * ray_direction[2])
        
        coord = (int(math.floor((grid.grid_size[0] - 1) * (pos[0] + 1.0) / 2.0)),
                 int(math.floor((grid.grid_size[1] - 1) * (pos[1] + 1.0) / 2.0)),
                 int(math.floor((grid.grid_size[2] - 1) * (pos[2] + 1.0) / 2.0)))
        
        # Clamp coord to valid range
        coord = (max(0, min(coord[0], grid.grid_size[0]-1)),
                 max(0, min(coord[1], grid.grid_size[1]-1)),
                 max(0, min(coord[2], grid.grid_size[2]-1)))
                 
        # Calculate fractional offset
        # p0 is position of coord, p1 is position of coord + (1,1,1)
        # p0 = minPoint + (maxPoint - minPoint) * (coord / grid_size)
        # Actually, simpler: sample = (pos - p0) / (p1 - p0)
        # Since grid is uniform [-1, 1], p1 - p0 is constant step
        step_x = 2.0 / grid.grid_size[0]
        step_y = 2.0 / grid.grid_size[1]
        step_z = 2.0 / grid.grid_size[2]
        
        p0 = (-1.0 + coord[0] * step_x, -1.0 + coord[1] * step_y, -1.0 + coord[2] * step_z)
        p1 = (-1.0 + (coord[0]+1) * step_x, -1.0 + (coord[1]+1) * step_y, -1.0 + (coord[2]+1) * step_z)
        
        sample = ((pos[0] - p0[0]) / (p1[0] - p0[0]),
                  (pos[1] - p0[1]) / (p1[1] - p0[1]),
                  (pos[2] - p0[2]) / (p1[2] - p0[2]))
        
        # Grid Lookup
        density, color = trilinear_interpolate(grid, coord, sample, ray_direction)
        
        if density > sigma_thresh:
            # Accumulate
            delta_tau = density * delta_step
            weight = transmittance * (1.0 - math.exp(-delta_tau))
            
            # Clamp color to non-negative
            color = tuple(max(c, 0.0) for c in color)
            
            total_color = tuple(total_color[i] + weight * color[i] for i in range(3))
            transmittance *= math.exp(-delta_tau)
            
            if transmittance < stop_thresh:
                break
        
        t += delta_step

    # Background
    total_color = tuple(total_color[i] + transmittance * background_brightness for i in range(3))
    
    return total_color
```

**Subtopics:**
*   **Plenoxels Alpha:** A variant using ReLU fields for approximate colored rendering, implemented on CPU [S3, unofficial].
*   **Sparse Voxel Grids:** The use of sparse 3D voxel grids reduces the number of 3D points compared to dense grids [S4, unofficial].
*   **Total Variation Loss:** A regularization technique required for Plenoxels to ensure smooth density fields [S4, unofficial].

## Operating characteristics
*   **Time Complexity:** Rendering is $O(N)$ where $N$ is the number of samples along the ray, but significantly faster than NeRF due to the absence of MLP inference. CPU rendering on Intel Core i7-7700HQ, GTX 1060, 1024x768 resolution took 7.83s (single-threaded) and 1.40s (4 threads OpenMP) [S3, unofficial].
*   **Memory Complexity:** Memory usage is proportional to the grid size ($128^3$ cells in the reference implementation) [S3, unofficial].
*   **Strengths:** Fast optimization and rendering; no neural network inference overhead; pure PyTorch implementation possible [S1, S2, unofficial].
*   **Limitations:** View-dependent effects are not supported in some implementations (e.g., pure PyTorch versions use Nearest-Neighbors for voxel distances) [S2, unofficial]. Performance can suffer from bank conflicts in shared memory access patterns in GPU implementations [S1, unofficial].
*   **When to use:** When fast training and rendering are prioritized over high-fidelity view-dependent effects. Suitable for consumer devices [S2, unofficial].
*   **When not to use:** When high-quality view-dependent specularities or complex lighting effects are required [S2, unofficial].

## Background
Plenoxels was introduced by Sara Fridovich-Keil, Alex Yu, Matthew Tancik, et al. in 2022 at CVPR [S1, unofficial]. The paper "Plenoxels: Radiance Fields without Neural Networks" proposes replacing the MLP in NeRF with a sparse 3D grid of trilinearly interpolated values [S1, unofficial]. It is not strictly a successor of svox but shares conceptual similarities [S1, unofficial]. The method is used for novel view synthesis and 3D scene representation [S1, unofficial].
