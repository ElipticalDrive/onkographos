# Hierarchical Grid Optimization

Also called: Explicit Radiance Fields Optimization, Plenoxels Training, Coarse-to-Fine Voxel Optimization

## Overview
Hierarchical Grid Optimization (HGO) refers to a family of methods that optimize explicit 3D grid representations (voxels, octrees) for radiance fields, avoiding the computational overhead of neural network inference during training. It solves the memory and speed bottlenecks of implicit neural representations by directly optimizing density and color parameters stored in spatial data structures [S1]. Unlike [Neural Radiance Fields](4972-neural-radiance-fields.md) which use MLPs, HGO methods leverage explicit data access for real-time rendering and faster convergence [S1]. The family encompasses diverse strategies: non-linear least-squares solvers for explicit fields [S1], fixed-grid optimization with spherical harmonics [S1], and dynamic coarse-to-fine refinement with pruning [S1].

## Shared principles
All methods in this family optimize explicit 3D structures (grids or trees) to minimize a photometric loss between rendered and ground-truth images. The core mechanism relies on the differentiability of the volume rendering equation with respect to voxel densities ($\sigma$) and color coefficients [S1, S2].

The standard emission-absorption model computes the color $\hat{C}(\mathbf{r})$ for a ray $\mathbf{r}$ as:

$$
\hat{C}(\mathbf{r}) = \sum_{i=1}^N T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i
$$

where $\sigma_i$ is the density, $\delta_i$ is the step size, $\mathbf{c}_i$ is the color, and $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$ is the transmittance [S1, unofficial][S5].

Differentiation strategies fall into three main categories:
1.  **Reverse-Mode Automatic Differentiation (AD):** Standard backpropagation through the computational graph. This requires storing $O(kn)$ intermediate states (where $n$ is pixels and $k$ is samples), leading to high memory usage [S5].
2.  **Adjoint Method:** Computes gradients by propagating adjoint variables backward through the rendering algorithm, evaluating the chain rule from output to input. This has computational complexity largely constant in the number of parameters, making it preferable for optimizing many parameters like the transfer function [S1, unofficial][S3, unofficial].
3.  **Analytic Inversion / Explicit Gradients:** Uses a-priori knowledge of the DVR operations to invert the order of operations or derive closed-form gradients, reducing memory consumption to $O(n)$ by avoiding the storage of intermediate results [S5].

## Subtopics

### [Explicit Radiance Fields](806-explicit-radiance-fields.md)
Uses a Gauss-Newton solver with Preconditioned Conjugate Gradient on a fixed hierarchical grid and environment maps, achieving fast convergence without neural networks.

### [Plenoxels Optimization Configuration](929-plenoxels-optimization-configuration.md)
Optimizes a fixed-resolution sparse voxel grid with SH coefficients using RMSProp and delayed learning rate schedules, balancing speed and quality.

### [Coarse-to-Fine Optimization with Pruning](1153-coarse-to-fine-optimization-with-pruning.md)
Dynamically refines resolution by pruning unoccupied voxels and subdividing, adapting the grid structure to scene complexity.

### [PlenOctree Optimization](1291-plenoctree-optimization.md)
Fine-tunes a pre-converted hierarchical octree using SGD to refine density and SH coefficients, focusing on post-conversion quality.

### [Sparse Voxel Grid Optimization](2568-sparse-voxel-grid-optimization.md)
Manages a dynamic sparse octree with Morton codes, supporting both novel-view synthesis and mesh reconstruction via SDFs.

### [Plenoxels](7440-plenoxels.md)
The foundational explicit representation using sparse voxel grids for density and SH coefficients, optimized via gradient descent.

## Background
The concept of explicit radiance fields originated with [Explicit Radiance Fields](806-explicit-radiance-fields.md) (PERF), which formulated volumetric reconstruction as a non-linear least-squares problem solved explicitly without neural networks [S1]. This approach achieved 2-3 orders of magnitude faster convergence than neural methods like NeRF [S1]. The field evolved with [Plenoxels](7440-plenoxels.md), which replaced neural networks with sparse voxel grids storing density and spherical harmonic coefficients, enabling training speeds two orders of magnitude faster than NeRF while maintaining comparable image quality [S1][S5, unofficial]. Subsequent works introduced hierarchical strategies like [Coarse-to-Fine Optimization with Pruning](1153-coarse-to-fine-optimization-with-pruning.md) and [PlenOctree Optimization](1291-plenoctree-optimization.md) to manage memory and detail more effectively [S1].
