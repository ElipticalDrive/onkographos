# DirectVoxGO


## Overview
DirectVoxGO is a differentiable volume rendering method that optimizes a single 3D voxel grid for density and color features, supporting both standard dense grids and FourierGrid variants [S1, unofficial]. It uses occupancy caching and near-camera voxel masking to accelerate training and handle unbounded scenes [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:** Source images, camera poses, `xyz_min`, `xyz_max`, `num_voxels`, `alpha_init`, `mask_cache_thres`, `fast_color_thres`, `rgbnet_dim`, `rgbnet_depth`, `rgbnet_width`, `viewbase_pe`, `rgbnet_direct`, `rgbnet_full_implicit`, `use_fourier_grid`, `fourier_freq_num`, `mask_cache_path`, and `near_clip` [S1, unofficial].

**Outputs:** Optimized density grid, color feature grid (k0), MLP weights (if `rgbnet_dim > 0`), and rendered images for a given camera pose [S1, unofficial].

### Data Structures
1. **Density Grid:** A 3D tensor storing density values. Type is specified by `density_type` (e.g., `DenseGrid`) [S1, unofficial].
2. **Color Feature Grid (k0):** A 3D tensor storing color features. Channels are determined by `k0_dim` [S1, unofficial].
3. **Mask Cache:** A boolean tensor stored as `grid.MaskGrid` with `xyz_min` and `xyz_max` [S1, unofficial].
4. **MLP:** A multi-layer perceptron for color prediction, initialized with ReLU activations and zero bias on the final layer [S1, unofficial].

### Initialization Steps
1. **Initialize Density Grid:** If `use_fourier_grid` is false, create grid using `grid.create_grid` with `density_type`, `channels=1`, `world_size`, `xyz_min`, `xyz_max`, and `density_config`. If true, create grid using `FourierGrid_grid.create_grid` with `use_nerf_pos=True` and `fourier_freq_num` [S1, unofficial].
2. **Initialize Color Feature Grid (k0):** If `rgbnet_dim <= 0`, set `k0_dim=3` and create grid with `channels=3` (coarse stage, no MLP). If `rgbnet_dim > 0`, set `k0_dim` based on `rgbnet_dim` and flags, create grid with `channels=k0_dim`, and initialize MLP (`rgbnet`) [S1, unofficial].
3. **Initialize MLP Input Dimension (`dim0`):** Start with `3 + 3 * viewbase_pe * 2`. If `rgbnet_direct` is true, add `k0_dim`. If `rgbnet_direct` is false and not `full_implicit`, add `k0_dim - 3` [S1, unofficial].
4. **Initialize Mask Cache:** If `mask_cache_path` is provided, load `MaskGrid` and compute mask for grid points. Otherwise, create a mask of all `True` values. Store as `grid.MaskGrid` with `xyz_min` and `xyz_max` [S1, unofficial].
5. **Mask Out Near-Camera Voxels:** Compute grid XYZ coordinates. For each camera origin (split into batches of 100 for memory), compute nearest distance from grid points to camera origin. Set density grid values to `-100` where `nearest_dist <= near_clip` [S1, unofficial]. For FourierGrid, compute normalized coordinates, apply NeRF position embedding, and compute nearest distance in the embedded space for each position embedding dimension [S1, unofficial].
6. **Scale Volume Grid:** Update `world_size` and `voxel_size`. Scale density and k0 grids. If `total_voxels <= 256^3`, compute alpha from density, apply 3D max pooling (kernel=3, padding=1, stride=1), and update `mask_cache` by combining with `alpha > fast_color_thres` [S1, unofficial].
7. **Update Occupancy Cache:** Compute grid XYZ for `mask_cache` resolution. Query density and activate to get alpha. Apply 3D max pooling (kernel=3, padding=1, stride=1). Update `mask_cache` mask by ANDing with `alpha > fast_color_thres` [S1, unofficial].

### Formulas
- $\text{act\_shift} = \log\left(\frac{1}{\alpha_{\text{init}}} - 1\right)$
- $\text{voxel\_size}_{\text{base}} = \sqrt[3]{\frac{\text{Volume}}{\text{num\_voxels}_{\text{base}}}}$
- $\text{voxel\_size} = \sqrt[3]{\frac{\text{Volume}}{\text{num\_voxels}}}$
- $\text{world\_size} = \lfloor \frac{\text{xyz}_{\text{max}} - \text{xyz}_{\text{min}}}{\text{voxel\_size}} \rfloor$
- $\text{voxel\_size}_{\text{ratio}} = \frac{\text{voxel\_size}}{\text{voxel\_size}_{\text{base}}}$ [S1, unofficial]

### Parameters
- `xyz_min`: Lower bound of the 3D world coordinate system, stored as a `torch.Tensor` buffer [S1, unofficial].
- `xyz_max`: Upper bound of the 3D world coordinate system, stored as a `torch.Tensor` buffer [S1, unofficial].
- `num_voxels`: Total number of voxels in the primary grid resolution [S1, unofficial].
- `num_voxels_base`: Reference voxel count used to calculate base voxel size for resolution scaling [S1, unofficial].
- `alpha_init`: Initial alpha value used to compute the density bias shift for the activation function [S1, unofficial].
- `mask_cache_thres`: Threshold value for the mask cache to determine occupancy [S1, unofficial].
- `fast_color_thres`: Threshold for determining if a voxel is opaque enough to skip color network evaluation [S1, unofficial].
- `density_type`: String specifying the type of density grid (e.g., 'DenseGrid') [S1, unofficial].
- `k0_type`: String specifying the type of color feature grid [S1, unofficial].
- `rgbnet_dim`: Dimension of the color feature grid. If `<= 0`, uses a coarse stage with 3-channel grid and no MLP; otherwise uses fine stage with feature grid and MLP [S1, unofficial].
- `rgbnet_direct`: Boolean flag for direct color encoding in the MLP input [S1, unofficial].
- `rgbnet_full_implicit`: Boolean flag for full implicit color encoding [S1, unofficial].
- `rgbnet_depth`: Depth of the color MLP (number of layers) [S1, unofficial].
- `rgbnet_width`: Width (hidden dimension) of the color MLP [S1, unofficial].
- `viewbase_pe`: Number of positional encoding frequencies for view direction [S1, unofficial].

### Pseudocode
```python
import torch
import torch.nn.functional as F

def initialize_direct_voxgo(xyz_min, xyz_max, num_voxels, alpha_init,
                            rgbnet_dim, rgbnet_direct, rgbnet_full_implicit,
                            viewbase_pe, use_fourier_grid, fourier_freq_num,
                            near_clip, fast_color_thres, mask_cache_path=None,
                            camera_origins=None, rgbnet_depth=3, rgbnet_width=64):
    volume = torch.prod(xyz_max - xyz_min)
    voxel_size = (volume / num_voxels).pow(1.0 / 3.0)
    world_size = torch.floor((xyz_max - xyz_min) / voxel_size).long()

    # 1. Initialize Density Grid
    if not use_fourier_grid:
        density_grid = torch.zeros(world_size, 1)
    else:
        density_grid = torch.zeros(world_size, 1)

    # 2. Initialize Color Feature Grid (k0)
    if rgbnet_dim <= 0:
        k0_dim = 3
        k0_grid = torch.zeros(world_size, 3)
        mlp = None
    else:
        k0_dim = rgbnet_dim
        k0_grid = torch.zeros(world_size, k0_dim)
        layers = []
        for i in range(rgbnet_depth):
            in_dim = k0_dim if i == 0 else rgbnet_width
            out_dim = 3 if i == rgbnet_depth - 1 else rgbnet_width
            layers.append(torch.nn.Linear(in_dim, out_dim))
            if i < rgbnet_depth - 1:
                layers.append(torch.nn.ReLU())
        mlp = torch.nn.Sequential(*layers)
        mlp[-1].bias.data.zero_()

    # 3. Initialize MLP Input Dimension (dim0)
    dim0 = 3 + 3 * viewbase_pe * 2
    if rgbnet_direct:
        dim0 += k0_dim
    elif not rgbnet_full_implicit:
        dim0 += k0_dim - 3

    # 4. Initialize Mask Cache
    if mask_cache_path is not None:
        mask_cache = torch.load(mask_cache_path)
    else:
        mask_cache = torch.ones(world_size, dtype=torch.bool)

    # 5. Mask Out Near-Camera Voxels
    if camera_origins is None:
        camera_origins = []
    for batch_start in range(0, len(camera_origins), 100):
        batch_origins = camera_origins[batch_start:batch_start+100]
        for origin in batch_origins:
            grid_coords = get_grid_coordinates(world_size, xyz_min, xyz_max)
            if not use_fourier_grid:
                dists = torch.norm(grid_coords - origin, dim=-1)
                mask = dists <= near_clip
                density_grid[mask] = -100.0
            else:
                embedded_coords = apply_nerf_pos(grid_coords, fourier_freq_num)
                embedded_origin = apply_nerf_pos(origin.unsqueeze(0), fourier_freq_num).expand_as(embedded_coords)
                dists = torch.norm(embedded_coords - embedded_origin, dim=-1)
                mask = dists <= near_clip
                density_grid[mask] = -100.0

    # 6. Scale Volume Grid & 7. Update Occupancy Cache
    act_shift = torch.log(1.0 / alpha_init - 1.0)
    density = density_grid + act_shift
    alpha = 1.0 - torch.exp(-density)
    alpha_pooled = F.max_pool3d(alpha.unsqueeze(0).unsqueeze(0), kernel_size=3, stride=1, padding=1).squeeze()
    mask_cache = mask_cache & (alpha_pooled > fast_color_thres)

    return density_grid, k0_grid, mlp, mask_cache, act_shift, dim0

def get_grid_coordinates(world_size, xyz_min, xyz_max):
    coords = torch.linspace(0, 1, world_size)
    grid = torch.stack(torch.meshgrid(coords, coords, coords, indexing='ij'), dim=-1)
    return xyz_min + grid * (xyz_max - xyz_min)

def apply_nerf_pos(coords, freq_num):
    scales = torch.tensor([2**i for i in range(freq_num)])
    scaled_coords = coords.unsqueeze(-1) * scales
    emb = torch.cat([torch.sin(scaled_coords), torch.cos(scaled_coords)], dim=-1)
    return emb.view(emb.size(0), -1)
```

### Pitfalls
- Memory usage during near-camera masking: Camera origins are split into batches of 100 to prevent excessive memory consumption during distance calculations [S1, unofficial].
- FourierGrid near-camera masking: Uses position embedding dimensions for distance calculation instead of raw coordinates, requiring iteration over `pos_embed_output_dim` [S1, unofficial].
- Max pooling for occupancy: 3D max pooling with kernel 3, padding 1, stride 1 is applied to alpha values to smooth occupancy and prevent thin structures from being missed [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Dominated by the single voxel grid. Near-camera masking requires batching camera origins into groups of 100 to prevent excessive memory consumption [S1, unofficial].
- **Performance:** Achieves super-fast convergence for radiance field reconstruction [S1, unofficial].
- **Strengths:** Occupancy caching and near-camera voxel masking accelerate training; supports resolution scaling via `num_voxels_base` and `voxel_size_ratio` [S1, unofficial].
- **Limitations:** Single resolution may require scaling for fine details; memory scales with the cube of `world_size` [S1, unofficial].
- **When to use:** When fast training convergence is prioritized, or for unbounded scenes requiring near-camera masking [S1, unofficial].

## Background
DirectVoxGO was introduced by Cheng Sun, Min Sun, and Hwann-Tzong Chen in 2022 [S1, unofficial]. It is part of the family of direct voxel grid optimization methods, aiming to simplify the training process of neural radiance fields by optimizing a single voxel grid directly [S1, unofficial]. The method builds on earlier work in voxel-based rendering and differentiable volume rendering [S1, unofficial].
