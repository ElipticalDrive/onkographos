# Clonoxels

Also called: Cloning-Plenoxels

## Overview
Clonoxels is a voxel-based radiance field framework that automatically detects repeated objects within a scene using instance and semantic segmentation, aligns them via rigid registration, and shares voxel features between instances to improve reconstruction quality and reduce storage requirements [S1, unofficial]. It sets itself apart from standard Plenoxels by introducing intra-scene information sharing, allowing gradients to propagate to 3D regions unseen within training images and enabling the recovery of hidden structures by drawing information from other instances of the same object [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Training images with known camera parameters (intrinsics and extrinsics), instance segmentation masks, and semantic labels for the training set [S1, unofficial].
*   **Outputs:** A shared voxel feature grid, learnable rigid transformation parameters (poses) for each instance, and scalar color correction values [S1, unofficial]. The final output can be rendered images or extracted 3D meshes via marching cubes [S1, unofficial].

**Data Structures:**
1.  **Baseline Grid:** A regular 3D voxel grid storing opacity values $\sigma$ and view-dependent color $c$ represented as spherical harmonic (SH) coefficients (9 per color channel), following the Plenoxels baseline [S1, unofficial].
2.  **Object Subgrid:** An axis-aligned bounding cube (AABB) of voxels assigned to a specific detected instance [S1, unofficial]. Features are stored at the vertices of this subgrid [S1, unofficial].
3.  **Transformation Parameters:** For each instance, a learnable rigid transformation defined by a rotation matrix $R \in SO(3)$ derived from a learnable quaternion, a center of rotation $o \in \mathbb{R}^3$, and a translation vector $t \in \mathbb{R}^3$ [S1, unofficial].
4.  **Color Correction:** A single scalar voxel feature $\Delta c$ per subgrid voxel, applied equally to all three RGB channels [S1, unofficial].

**Formulas:**
*   **Volume Rendering:** The color $\hat{C}$ of a camera ray $x(t) = x_o + t \hat{d}$ is computed as:
    $$ \hat{C}(x) = \int_{t_n}^{t_f} V(t) \sigma(x(t)) c(x(t), \hat{d}) dt $$
    where $V(t)$ is the transmittance:
    $$ V(t) = e^{-\int_0^t \sigma(x(s)) ds} $$
    [S1, unofficial]

*   **Rigid Transformation:** Each vertex $v$ of an object's feature subgrid $F$ is transformed to $v'$:
    $$ v' = R(v - o) + o + t $$
    [S1, unofficial]

*   **Color Correction:** The final color $c'$ is:
    $$ c' = c + \Delta c \cdot \mathbf{1} $$
    where $\mathbf{1} = (1, 1, 1)^T$. The result is clamped to $[0, 1]$ [S1, unofficial].

*   **Loss Functions:**
    *   Reconstruction Loss: $L_{recon} = ||C - \hat{C}||_2^2$ [S1, unofficial].
    *   Total Variation Loss: $L_{TV}$ (used for regularization) [S1, unofficial].
    *   Feature Similarity Loss: $L_{feat} = \lambda_{feat} ||F' - \hat{F}||_1$, where $F'$ is the transformed subgrid of one instance, $\hat{F}$ is the subgrid of another instance of the same class, and $\lambda_{feat}$ is a weighting coefficient. L1 is used for outlier tolerance [S1, unofficial].

**Algorithm Steps:**

1.  **Instance Detection and Ranking:** Use instance segmentation (e.g., Mask2Former or SAM2 with YOLOv10 boxes) and semantic labels on training images to extract objects [S1, unofficial]. Rank semantic classes by instance count and retain only masks corresponding to the most numerous class to prioritize repetitions [S1, unofficial].
2.  **3D Localization and Subgrid Definition:** Project the 2D masks into 3D space using multi-view consistency [S1, unofficial]. Assign voxels to define axis-aligned bounding cubes (Object Subgrids) for each instance [S1, unofficial].
3.  **Initial Scene Optimization:** Optimize the entire scene's baseline features ($\sigma, c$) using $L_{recon}$ and $L_{TV}$ to build an initial representation [S1, unofficial].
4.  **Pose Estimation (Feature Sharing Setup):** Cull low-density voxels to ensure pose optimization stability [S1, unofficial]. Optimize only the transformation parameters ($R, o, t$) for each instance using $L_{feat}$ until convergence to align the subgrids of repeated objects [S1, unofficial].
5.  **Joint Optimization:** Reintroduce $L_{recon}$ and $L_{TV}$ [S1, unofficial]. Continue updating features and transformations jointly so that instances exchange information while pose refinement is informed by photometric cues [S1, unofficial].
6.  **Rendering:** Query the shared feature grid [S1, unofficial]. For a given instance, apply its learned transformation to map the shared features to its local coordinate system [S1, unofficial]. Apply the scalar color correction $\Delta c$ to handle lighting differences (shadows, specular highlights) [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def quaternion_to_matrix(q):
    # [G] Standard conversion from unit quaternion to 3x3 rotation matrix
    w, x, y, z = q[:, 0], q[:, 1], q[:, 2], q[:, 3]
    R = torch.zeros(q.shape[0], 3, 3)
    R[:, 0, 0] = 1 - 2 * (y**2 + z**2)
    R[:, 0, 1] = 2 * (x * y - w * z)
    R[:, 0, 2] = 2 * (x * z + w * y)
    R[:, 1, 0] = 2 * (x * y + w * z)
    R[:, 1, 1] = 1 - 2 * (x**2 + z**2)
    R[:, 1, 2] = 2 * (y * z - w * x)
    R[:, 2, 0] = 2 * (x * z - w * y)
    R[:, 2, 1] = 2 * (y * z + w * x)
    R[:, 2, 2] = 1 - 2 * (x**2 + y**2)
    return R

def clonoxels_optimization(scene_data, training_images, masks, semantic_labels):
    # 1. Instance Detection and Ranking
    instances = detect_instances(masks, semantic_labels) # [G] Extract objects via instance/semantic segmentation
    top_class_instances = rank_and_select_top_class(instances) # [G] Sort by count, keep most numerous class

    # 2. 3D Localization and Subgrid Definition
    subgrids = {}
    for inst in top_class_instances:
        subgrids[inst.id] = project_to_3d(inst.mask, training_images.cameras) # [G] Multi-view backprojection to AABB

    # 3. Initial Scene Optimization
    optimizer_baseline = torch.optim.Adam(scene_data.parameters())
    for _ in range(1000): # [G] Standard convergence loop
        optimizer_baseline.zero_grad()
        loss_recon = torch.sum((render_ray(scene_data, training_images) - training_images.targets)**2)
        loss_tv = compute_total_variation_loss(scene_data)
        (loss_recon + loss_tv).backward()
        optimizer_baseline.step()

    # 4. Pose Estimation
    scene_data = cull_low_density(scene_data, threshold=0.15) # [G] Remove voxels with sigma < threshold
    optimizer_transforms = torch.optim.Adam([t.parameters() for t in subgrids.values()])
    reference_instance = top_class_instances[0] # [G] Select reference instance for F_hat
    for _ in range(500): # [G] Standard convergence loop
        optimizer_transforms.zero_grad()
        loss_feat = 0
        for inst in top_class_instances:
            q = F.normalize(inst.transform.q)
            R = quaternion_to_matrix(q)
            v_prime = (R @ (inst.vertices - inst.transform.o).T).T + inst.transform.o + inst.transform.t
            F_prime = F.grid_sample(scene_data.features.unsqueeze(0), v_prime.unsqueeze(0),
                                    mode='bilinear', padding_mode='border').squeeze(0)
            F_hat = subgrids[reference_instance.id].features
            loss_feat += lambda_feat * torch.norm(F_prime - F_hat, p=1)
        loss_feat.backward()
        optimizer_transforms.step()

    # 5. Joint Optimization
    optimizer_joint = torch.optim.Adam(list(scene_data.parameters()) + [t.parameters() for t in subgrids.values()])
    for _ in range(1000):
        optimizer_joint.zero_grad()
        loss_recon = torch.sum((render_ray(scene_data, training_images) - training_images.targets)**2)
        loss_feat = 0
        for inst in top_class_instances:
            q = F.normalize(inst.transform.q)
            R = quaternion_to_matrix(q)
            v_prime = (R @ (inst.vertices - inst.transform.o).T).T + inst.transform.o + inst.transform.t
            F_prime = F.grid_sample(scene_data.features.unsqueeze(0), v_prime.unsqueeze(0),
                                    mode='bilinear', padding_mode='border').squeeze(0)
            F_hat = subgrids[reference_instance.id].features
            loss_feat += lambda_feat * torch.norm(F_prime - F_hat, p=1)
        total_loss = loss_recon + loss_feat
        total_loss.backward()
        optimizer_joint.step()

    return scene_data, subgrids
```

**Edge Cases and Pitfalls:**
*   **Lighting Differences:** Direct feature sharing fails under different lighting (shadows, specular highlights) [S1, unofficial]. The scalar correction $\Delta c$ is essential [S1, unofficial]. Per-channel corrections are not used to maintain memory savings [S1, unofficial].
*   **Symmetric Objects:** Rigid pose registration may struggle with highly symmetric objects, which are sensitive to pose initialization [S1, unofficial].
*   **Visual Differences:** Semantically similar objects may have significant visual differences, compromising feature sharing gains [S1, unofficial].
*   **Precision:** Calculations assume 32-bit floating-point precision [S1, unofficial].

## Operating characteristics
*   **Memory:** Significantly reduces memory footprint by storing only one instance's features and propagating them via learned poses and color corrections [S1, unofficial]. Memory savings are reported as absolute values (e.g., 13.3 MB to 23.6 MB saved) and percentages (e.g., 66.0% to 76.4% of voxels with $\sigma > 0.15$) [S1, unofficial].
*   **Quality:** Improves reconstruction quality, particularly for occluded novel views [S1, unofficial]. Clonoxels reduces MSE by 21% in occluded novel view rendering compared to the baseline by drawing information from other objects [S1, unofficial].
*   **Color Correction Impact:** Using the scalar color correction $\Delta c$ improves MSE (0.022 vs 0.039), PSNR (26.9 vs 24.2), and SSIM (0.85 vs 0.83) compared to not using it [S1, unofficial].
*   **Denoising:** The method imposes constraints on geometry and appearance, reducing noisy artifacts and producing cleaner 3D geometry suitable for mesh extraction [S1, unofficial].
*   **Limitations:** Performance degrades if repeated objects have significant visual differences or if objects are highly symmetric [S1, unofficial].

## Background
Clonoxels (Cloning-Plenoxels) was introduced by O. Camilleri, M. Volino, and A. Hilton in 2026 [S1, unofficial]. It builds on the Plenoxels framework, which optimizes voxel opacity and spherical harmonic coefficients [S1, unofficial]. The method addresses the limitations of standard voxel-based radiance fields by leveraging intra-scene repetition to enhance reconstruction and reduce storage, offering a practical path for efficient and accurate reconstruction of complex scenes [S1, unofficial].
