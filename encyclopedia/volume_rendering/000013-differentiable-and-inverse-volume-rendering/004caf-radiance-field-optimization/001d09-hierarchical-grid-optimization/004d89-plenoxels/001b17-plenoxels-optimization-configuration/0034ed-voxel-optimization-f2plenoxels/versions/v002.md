# Voxel optimization (F2Plenoxels)
Also called: Depth-guided voxel pre-pruning with SH regularization

## Overview
F2Plenoxels is a voxel radiance field optimization method for few-shot view synthesis that eliminates neural networks by combining depth-guided voxel pre-pruning with spherical harmonic (SH) regularization [S1]. It improves upon baseline Plenoxels by significantly reducing floaters and cluttered artifacts while maintaining high geometry accuracy and appearance fidelity [S1].

## How it works
**Inputs:** Pruned density voxel grid $V_D$, SH coefficient voxel grid $V_{SH}$, input images $I = \{I_n\}_{n=1}^S$, camera intrinsics $K = \{K_n\}_{n=1}^S$, and extrinsics $P = \{P_n\}_{n=1}^S$ [S1].
**Outputs:** Optimized voxel grids $V_D$ and $V_{SH}$ [S1].

**Data Structures:**
*   $V_D$: 3D density grid. Initialized to zeros.
*   $V_{SH}$: 3D SH coefficient grid. Initialized to zeros.
*   $R$: Array of training rays (origin and direction).
*   $C$: Array of target pixel colors.

**Parameters:**
*   Training duration: $E = 10$ epochs.
*   Iterations per epoch: $N = 2560$.
*   Batch size: 5000 rays.
*   SH degree: 2.
*   SH regularization iterations: $T = 1280$.
*   Density learning rate: Delayed exponential, scaled by 15, initial delay 3000 steps, decays to 0.05 at step 50000 [S1].
*   SH learning rate: Pure exponential decay, initial 0.01, decays to $5 \times 10^{-6}$ at step 50000 [S1].
*   Total Variation (TV) regularization weights ($\lambda_\sigma$ for density, $\lambda_k$ for SH):
    *   Blender dataset: $\lambda_\sigma = 5 \times 10^{-4}$, $\lambda_k = 5 \times 10^{-2}$ [S1].
    *   LLFF dataset: $\lambda_\sigma = 2.5 \times 10^{-3}$, $\lambda_k = 2.5 \times 10^{-2}$ [S1].

**Algorithm:**
1.  Initialize $V_D \leftarrow 0$, $V_{SH} \leftarrow 0$ [S1].
2.  Retrieve all training rays and colors: $R_{\text{all}}, C_{\text{all}} \leftarrow \text{GenerateRays}(K, P, I)$ [S1].
3.  For epoch $e$ from 1 to $E$:
    4.  Shuffle $R_{\text{all}}, C_{\text{all}}$ [S1].
    5.  For iteration $n$ from 1 to $N$:
        6.  Calculate global iteration count: $i \leftarrow (e - 1) \times N + n$ [S1].
        7.  Sample batch: $R, C \leftarrow \text{SampleBatch}(R_{\text{all}}, C_{\text{all}}, \text{batch\_size})$ [S1].
        8.  If $i \le T$: Apply SH regularization to $V_{SH}$ [S1].
        9.  Render ray colors: $\hat{C} \leftarrow \text{VolumeRendering}(R, V_D, V_{SH})$ [S1].
        10. Compute MSE loss: $\mathcal{L}_{\text{MSE}} \leftarrow \text{MSE}(\hat{C}, C)$ [S1].
        11. Compute TV loss: $\mathcal{L}_{\text{TV}} \leftarrow \lambda_\sigma \text{TV}(V_D) + \lambda_k \text{TV}(V_{SH})$ [S1].
        12. Update $V_D$ and $V_{SH}$ via RMSProp with respective learning rate schedules [S1].

**Pseudocode:**
```python
import numpy as np

def voxel_optimization(V_D, V_SH, K, P, I, E=10, N=2560, batch_size=5000, T=1280,
                       lr_D_init=1.0, lr_SH_init=0.01, decay_steps=50000,
                       lambda_sigma=5e-4, lambda_k=5e-2):
    # 1. Initialize voxel grids to zeros
    V_D = np.zeros_like(V_D)
    V_SH = np.zeros_like(V_SH)

    # 2. Generate all training rays and target colors
    R_all, C_all = [], []
    for idx in range(len(I)):
        rays = cast_rays_from_cameras(K[idx], P[idx], I[idx].shape)
        R_all.extend(rays)
        C_all.extend(I[idx].reshape(-1, 3))
    R_all = np.array(R_all)
    C_all = np.array(C_all)

    # RMSProp state
    m_D, m_SH = np.zeros_like(V_D), np.zeros_like(V_SH)
    v_D, v_SH = np.zeros_like(V_D), np.zeros_like(V_SH)
    rho = 0.9  # RMSProp decay rate [G]

    for e in range(1, E + 1):
        # 3-4. Shuffle rays for the epoch
        perm = np.random.permutation(len(R_all))
        R_all, C_all = R_all[perm], C_all[perm]

        for n in range(1, N + 1):
            # 5-6. Global iteration count
            i = (e - 1) * N + n

            # 7. Sample batch
            start = (n - 1) * batch_size
            end = start + batch_size
            R_batch, C_batch = R_all[start:end], C_all[start:end]

            # 8. SH Regularization (only for first T iterations)
            if i <= T:
                # [G] Apply SH regularization (exact formula not provided in sources)
                V_SH = apply_sh_regularization(V_SH)

            # 9. Render ray colors
            C_hat = volume_rendering(R_batch, V_D, V_SH)

            # 10. Compute MSE loss
            loss_mse = np.mean((C_hat - C_batch) ** 2)

            # TV Regularization
            tv_D = total_variation(V_D)
            tv_SH = total_variation(V_SH)
            loss_tv = lambda_sigma * tv_D + lambda_k * tv_SH
            loss = loss_mse + loss_tv

            # Compute gradients (simulated for pseudocode clarity)
            grad_D, grad_SH = compute_gradients(loss, V_D, V_SH, R_batch, C_batch)

            # Learning rate schedules
            if i <= 3000:
                lr_D = lr_D_init
            else:
                lr_D = lr_D_init * np.exp(-15 * (i - 3000) / decay_steps)
            lr_SH = lr_SH_init * np.exp(-np.log(lr_SH_init / 5e-6) * i / decay_steps)

            # RMSProp update
            m_D = rho * m_D + (1 - rho) * grad_D ** 2
            m_SH = rho * m_SH + (1 - rho) * grad_SH ** 2
            V_D -= lr_D * grad_D / (np.sqrt(m_D) + 1e-8)
            V_SH -= lr_SH * grad_SH / (np.sqrt(m_SH) + 1e-8)

    return V_D, V_SH
```

**Edge Cases and Pitfalls:**
*   **Depth estimation quality:** Depth-guided pruning requires accurate depth priors; noisy or misaligned depths reintroduce floaters and degrade geometry fidelity [S1].
*   **Near-camera overfitting:** Depth-prior methods can suffer from near-camera overfitting, causing blurriness; F2Plenoxels mitigates this through its specific depth-guided pre-pruning strategy [S1].
*   **Artifact suppression:** Without proper regularization, grid-based methods may produce cluttered needle-like artifacts; F2Plenoxels avoids these via SH regularization and TV constraints [S1].

## Operating characteristics
*   **Performance:** F2Plenoxels achieves the best SSIM among few-shot NeRF-based methods on the LLFF dataset and outperforms other NeRF-based methods in PSNR and LPIPS, though it remains slightly inferior to some 3DGS-based methods on specific metrics [S1].
*   **Comparison:** It significantly reduces floaters compared to Plenoxels, MixNeRF, and SynergyNeRF [S1]. It produces less blurriness than ReVoRF [S1]. It avoids cluttered needle-like artifacts present in DNGaussian [S1]. It improves geometry accuracy and appearance fidelity over baseline Plenoxels [S1]. Its depth constraints are finer than those of SparseNeRF, VGOS, DiffusioNeRF, and FrugalNeRF, resulting in better texture details [S1].
*   **Efficiency:** The method is built on Plenoxels' codebase and uses RMSProp [S1]. Training time is evaluated on a single NVIDIA Quadro P5000 GPU [S1]. Specific training times for F2Plenoxels are not given in the sources.

## Background
F2Plenoxels was introduced in the paper "F2Plenoxels: fast voxel radiance fields without neural networks for few-shot view synthesis" [S1]. It builds on the Plenoxels framework [S1]. The method is evaluated on the Blender (Mildenhall et al. 2020) and LLFF (Mildenhall et al. 2019) datasets [S1].
