# Camera-Calibrated Differentiable Holographic Model

Also called: Camera-Calibrated Differentiable Model for Holography, Camera-calibrated model, Differentiable holographic model

## Overview
A differentiable computational model that simulates the physical propagation of light from a Spatial Light Modulator (SLM) to a camera sensor, incorporating learnable parameters to account for system-specific imperfections such as polarization, SLM curvature, beam profiles, higher diffraction orders, crosstalk, and Lookup Table (LUT) non-linearity [S1]. It sets itself apart from standard Angular Spectrum Method (ASM) implementations by explicitly modeling the superposition of zero and first-order diffraction patterns through a neural network (U-Net) and calibrating these parameters against experimental data, thereby compensating for unmodeled physical effects in compact optical setups [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** SLM digital input pattern $s$ (scalar per pixel), propagation distance $z$, wavelength $\lambda$.
*   **Outputs:** Predicted image intensity $I_z$ at the sensor plane.

**Data Structures:**
*   **SLM Pattern $s$:** 2D array of integers (e.g., 0-255) representing digital drive values.
*   **Diffraction Orders $G_0, G_1$:** Complex-valued 2D arrays representing the zero-order and first-order diffraction patterns generated by the SLM.
*   **Propagated Fields $f_{ASM}$:** Complex-valued 2D arrays resulting from ASM propagation.
*   **U-Net:** A neural network architecture (separate instance for each color channel) taking stacked complex fields as input and outputting real-valued intensity.
*   **Learnable Parameters:**
    *   $a_1, a_2$: Scalars (per color channel) for the linear LUT model.
    *   $k_{xt}$: 5x5 convolution kernel (per color channel) for crosstalk.
    *   $M_{color}$: 3x3 matrix for camera color balance.

**Formulas:**
1.  **SLM Phase with Crosstalk and LUT:**
    The phase $\phi_\lambda(s)$ off the SLM for wavelength $\lambda$ given input $s$ is modeled as:
    $$ \phi_\lambda(s) = k_{xt} * (a_1 \cdot s + a_2) $$
    where $*$ denotes convolution, $a_1, a_2$ are learnable linear LUT parameters, and $k_{xt}$ is a learned 5x5 convolution kernel representing field fringing (crosstalk) [S1].

2.  **Diffraction Pattern Generation:**
    The SLM phase is converted into complex diffraction patterns $G_0$ (zero-order) and $G_1$ (first-order). The specific mapping from phase to $G_0, G_1$ relies on the physics of the SLM modulation, typically involving Fourier components of the phase profile [S1].

3.  **Angular Spectrum Propagation:**
    Each diffraction order is propagated independently to distance $z$ using the Angular Spectrum Method (ASM), building on [Angular Spectrum Method (ASM)](12941-angular-spectrum-method-asm.md):
    $$ f_{ASM}(G, z) = \mathcal{F}^{-1} \{ G \cdot H_{ASM}(z) \} $$
    where $G$ is the diffraction order pattern ($G_0$ or $G_1$), $H_{ASM}(z)$ is the ASM transfer kernel, and $\mathcal{F}^{-1}$ is the inverse Fourier transform [S1].

4.  **Intensity Prediction via U-Net:**
    The propagated zero-order field $f_{ASM}(G_0, z)$ and first-order field $f_{ASM}(G_1, z)$ are stacked and passed through a U-Net to predict the final image intensity:
    $$ I_z = \text{Unet}(f_{ASM}(G_0, z), f_{ASM}(G_1, z)) $$
    A separate U-Net is learned for each color channel to handle color-specific unmodeled system aspects [S1].

**Numbered Steps:**

1.  **Calibration Phase (Parameter Learning):**
    1.  Pre-calculate 882 SLM patterns from a dataset of images using the standard ASM propagation model [S1].
    2.  Capture these patterns using the experimental camera at 10 mm increments from $z=90$ mm to $z=120$ mm [S1].
    3.  Debayer the camera data and apply an affine transform to align the image coordinates with the SLM grid [S1].
    4.  Initialize learnable parameters: $a_1, a_2$ (LUT), $k_{xt}$ (crosstalk kernel), and $M_{color}$ (3x3 color calibration matrix) [S1].
    5.  Perform gradient descent using PyTorch to minimize the L1 loss between the model output $I_z$ and the captured camera data [S1].
    6.  Train until convergence, typically taking 2-3 days on an Nvidia A6000 GPU [S1].

2.  **Hologram Generation (Optimization):**
    1.  Initialize the SLM pattern $s$ (e.g., random or target-based initialization).
    2.  Compute the phase $\phi_\lambda(s)$ using the calibrated LUT and crosstalk model (Eq. 11) [S1].
    3.  Generate diffraction orders $G_0$ and $G_1$ from the phase [S1].
    4.  Propagate $G_0$ and $G_1$ to the target distance $z$ using ASM (Eq. 12) [S1].
    5.  Stack the propagated fields and pass them through the trained U-Net to predict intensity $I_z$ [S1].
    6.  Compute the loss (e.g., perceptual loss) between $I_z$ and the target image [S1].
    7.  Use PyTorch autodifferentiation to compute gradients with respect to $s$ [S1].
    8.  Update $s$ using gradient descent.
    9.  **Constraint Handling:** After every optimization step, wrap $s$ values to the LUT valid range (e.g., 0-255) to ensure physical validity [S1].

**Edge Cases and Pitfalls:**
*   **Higher Diffraction Orders:** The discrete pixel structure of the SLM creates higher diffraction orders not modeled by standard ASM. This method avoids physical apertures (4f systems) by modeling the 0th and 1st orders explicitly and using a U-Net to compensate for residual unmodeled effects [S1].
*   **SLM Crosstalk:** LCoS SLMs exhibit field fringing due to elastic forces in the LC layer. This is modeled as a convolution ($k_{xt}$) on the phase. Failure to model this leads to blurred phase and reduced hologram quality [S1].
*   **LUT Validity:** The SLM pattern $s$ must be constrained to the range where the LUT is valid (e.g., 0-255). Values outside this range must be wrapped after every optimization step [S1].
*   **Color Deviation:** Simultaneous RGB holography is an overdetermined problem (3x more output pixels than SLM degrees of freedom). This can lead to color deviations and desaturation if not addressed by the perceptual loss and calibrated model [S1].

## Operating characteristics
*   **Time Complexity:** Hologram generation optimization takes approximately 2 minutes per 2D hologram on an Nvidia A6000 GPU [S1]. 3D hologram computation time scales proportionally to the number of depth planes [S1].
*   **Memory Complexity:** Requires memory for the SLM pattern, propagated fields, and the U-Net parameters. The U-Net is separate for each color channel [S1].
*   **Strengths:** Enables simultaneous color computer-generated holography in a compact setup without bulky optics or filters, suitable for VR/AR displays [S1]. Reduces depth replicas and high-frequency out-of-focus light by using extended phase range SLMs and modeling higher orders [S1].
*   **Limitations:** Calibration is time-consuming (2-3 days on A6000) [S1]. The method relies on the accuracy of the U-Net to capture unmodeled system imperfections, which may not generalize perfectly to different hardware without re-calibration [S1].
*   **When to Use:** When generating simultaneous color holograms in a compact optical setup where physical filtering of higher diffraction orders is impractical.
*   **When Not to Use:** When high coherence lasers are required (this method uses SLEDs to reduce speckle) or when a 4f system is already present to filter diffraction orders [S1].

## Background
The method was developed to address the mismatch between simulated holograms and experimental captures in simultaneous color computer-generated holography [S1]. It builds on the Angular Spectrum Method (ASM) and incorporates insights from Gopakumar et al. [2021] regarding higher-order angular spectrum models [S1]. The use of SLEDs (Superluminescent Light Emitting Diodes) to reduce speckle is based on work by Deng and Chu [2017] [S1]. The specific implementation details, including the U-Net architecture and calibration procedure, are described in the source paper [S1].
