# Angular Spectrum Method (ASM)
Also called: Free-space propagation operator
## Overview
The Angular Spectrum Method (ASM) is a free-space propagation operator used to model the parallel propagation of a wave field from a source plane to a target plane at distance $z$ [S2]. It calculates the wavefield by propagating plane waves in different directions, providing an exact reconstruction without the paraxial or Fresnel approximations inherent in other methods [S1]. It sets itself apart from the Fresnel Method by avoiding approximations, though this comes at the cost of higher computational intensity due to the requirement of two Fourier transforms [S1].
## How it works
**Inputs and Outputs:**
- Input: The complex optical field $U_0(x_0, y_0)$ at the source plane ($z=0$).
- Output: The reconstructed complex wavefield $U_r(x, y)$ at the target plane ($z$).
- Parameters: Wavelength $\lambda$, propagation distance $z$.

**Data Structures:**
- The optical field is represented as a 2D complex array.
- The angular spectrum is represented as a 2D complex array in the frequency domain.
- The transfer function is a 2D complex array of phase factors.

**Steps:**
1. Compute the 2D Fourier Transform of the input optical field $U_0(x_0, y_0)$ to obtain the Angular Spectrum $A_0(k_x, k_y)$ [S1].
   $$ A_0(k_x, k_y) = \mathcal{F} \{ U_0(x_0, y_0) \} $$
   Note: The continuous definition involves a normalization factor of $\frac{1}{2\pi}$ in some conventions, but discrete implementations typically use the standard DFT definition [S1].
2. Calculate the propagation phase factor (transfer function) $H(k_x, k_y; z)$ [S1, S2].
   $$ H(k_x, k_y; z) = \exp \left( j k_z z \right) $$
   where $k_z$ is the longitudinal wavenumber:
   $$ k_z = \sqrt{k^2 - k_x^2 - k_y^2} $$
   and $k$ is the total wavenumber:
   $$ k = \frac{2\pi}{\lambda} $$
   This calculation assumes $k^2 \ge k_x^2 + k_y^2$ [S1].
3. Multiply the Angular Spectrum by the propagation phase factor [S1].
   $$ A_z(k_x, k_y) = A_0(k_x, k_y) \cdot \exp \left( j \sqrt{k^2 - k_x^2 - k_y^2} z \right) $$
4. Compute the Inverse Fourier Transform of the result to obtain the reconstructed wavefield $U_r(x, y)$ [S1].
   $$ U_r(x, y) = \mathcal{F}^{-1} \{ A_z(k_x, k_y) \} $$

**Combined Formula:**
The complete reconstruction is expressed as:
$$ U_r(x, y) = \mathcal{F}^{-1} \left\{ \mathcal{F} \{ U_0 \} \exp \left( j \sqrt{k^2 - k_x^2 - k_y^2} z \right) \right\} $$
[S1]

**Pseudocode:**
```python
def angular_spectrum_method(U0, wavelength, distance, dx, dy):
    """
    Propagates a wavefield U0 using the Angular Spectrum Method.
    
    Args:
        U0: 2D complex array representing the input optical field.
        wavelength: Scalar float, the wavelength of light (lambda).
        distance: Scalar float, the propagation distance z.
        dx: Scalar float, pixel size in x direction.
        dy: Scalar float, pixel size in y direction.
        
    Returns:
        Ur: 2D complex array representing the reconstructed wavefield.
    """
    import numpy as np
    
    # 1. Fourier Transform the input field
    # Note: np.fft.fft2 uses unnormalized DFT. The continuous definition 
    # in [S1] includes 1/(2pi), but standard DFT implementations absorb 
    # constants or assume specific normalization. We follow the standard 
    # DFT structure implied by [S1]'s final equation (11).
    A0 = np.fft.fft2(U0)
    
    # 2. Define frequency coordinates
    # The spatial frequencies kx, ky depend on the sampling.
    # For an array of size (M, N), the frequency bins correspond to 
    # kx = 2*pi * fx, where fx are the spatial frequencies in cycles/length.
    # However, the formula in [S1] uses kx, ky directly as spatial frequency 
    # components in the exponent. In discrete FFT, the indices map to 
    # spatial frequencies.
    
    M, N = U0.shape
    # Create frequency grid in cycles per unit length
    fx = np.fft.fftfreq(N, d=dy)
    fy = np.fft.fftfreq(M, d=dx)
    FX, FY = np.meshgrid(fx, fy)
    
    # Convert to angular spatial frequencies (kx, ky)
    # kx = 2 * pi * fx
    kx = 2 * np.pi * FX
    ky = 2 * np.pi * FY
    
    # 3. Calculate wavenumber k
    k = 2 * np.pi / wavelength
    
    # 4. Calculate kz
    # kz = sqrt(k^2 - kx^2 - ky^2)
    # Note: If kx^2 + ky^2 > k^2, kz becomes imaginary (evanescent waves).
    # The source [S1] assumes k^2 >= kx^2 + ky^2. In practice, for 
    # propagating waves, we may need to handle evanescent components 
    # (set to 0 or decay). [S1] does not specify handling, so we compute 
    # the principal square root.
    kz_sq = k**2 - kx**2 - ky**2
    
    # Handle evanescent waves: if kz_sq < 0, kz is imaginary.
    # Standard ASM often sets these to 0 or allows complex kz.
    # [S1] implies real kz for the valid range. We use np.sqrt which 
    # returns complex for negative inputs.
    kz = np.sqrt(kz_sq)
    
    # 5. Calculate transfer function H
    H = np.exp(1j * kz * distance)
    
    # 6. Multiply in frequency domain
    A_z = A0 * H
    
    # 7. Inverse Fourier Transform
    Ur = np.fft.ifft2(A_z)
    
    return Ur
```

**Edge Cases and Pitfalls:**
- **Evanescent Waves:** If $k_x^2 + k_y^2 > k^2$, $k_z$ becomes imaginary. The source [S1] assumes $k^2 \ge k_x^2 + k_y^2$. In numerical implementations, this results in exponentially decaying terms. If not handled, they may cause numerical noise or artifacts.
- **Computational Cost:** ASM requires two 2D Fourier transforms, making it more computationally intensive than the Fresnel Method [S1].
- **Sampling:** The spatial frequencies $k_x, k_y$ are determined by the pixel size and array dimensions. Insufficient sampling can lead to aliasing or loss of high-frequency information.

A differentiable computational model that simulates the physical propagation of light from a Spatial Light Modulator (SLM) to a camera sensor, incorporating learnable parameters to account for system-specific imperfections such as polarization, SLM curvature, beam profiles, higher diffraction orders, crosstalk, and Lookup Table (LUT) non-linearity. It sets itself apart from standard Angular Spectrum Method (ASM) implementations by explicitly modeling the superposition of zero and first-order diffraction patterns through a neural network (U-Net) and calibrating these parameters against experimental data, thereby compensating for unmodeled physical effects in compact optical setups.

## Operating characteristics
- **Time Complexity:** Requires two 2D Fourier Transforms. Complexity is $O(MN \log(MN))$ for an $M \times N$ array, similar to Fresnel propagation, but with a higher constant factor due to the exact phase calculation [S1].
- **Memory Complexity:** Requires storage for the input field, the angular spectrum, the transfer function, and the output field. $O(MN)$ complex numbers.
- **Accuracy:** Exact solution to the free-space wave equation; no paraxial or Fresnel approximations [S1].
- **Strengths:** High accuracy for near-field and wide-angle propagation; handles evanescent waves (if implemented).
- **Limitations:** Computationally more expensive than Fresnel method; sensitive to sampling conditions; requires handling of evanescent waves [S1].
- **When to use:** When high accuracy is required, especially for near-field propagation or when the paraxial approximation is invalid.
- **When not to use:** When computational efficiency is paramount and the Fresnel approximation is valid.

## Background
The Angular Spectrum Method is a fundamental technique in wave optics and digital holography. It is based on the principle that any wavefield can be decomposed into a sum of plane waves (the angular spectrum) [S1]. The method was developed as an exact alternative to approximate propagation methods like the Fresnel and Fraunhofer approximations. It is widely used in computer-generated holography (CGH) and digital holographic reconstruction [S1, S2]. The method is referenced in recent advances in processing and rendering algorithms for CGH [S1] and in mesh-represented hologram synthesis [S2].
