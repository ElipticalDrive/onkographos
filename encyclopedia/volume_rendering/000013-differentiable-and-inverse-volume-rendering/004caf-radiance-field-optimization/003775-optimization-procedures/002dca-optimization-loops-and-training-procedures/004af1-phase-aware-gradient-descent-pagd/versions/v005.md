# Phase-Aware Gradient Descent (PAGD)
Also called: Phase-Only Hologram Synthesis via PAGD

## Overview
Phase-Aware Gradient Descent (PAGD) is an optimization method used to encode complex wave fields into phase-only holograms for 3D holographic displays [S1]. It solves the problem of rendering accurate depth cues and view-dependent effects by supervising the phase of the reconstructed wave field, rather than relying solely on amplitude [S1]. Unlike amplitude-only methods which suffer from unnatural blur spreading and ringing artifacts, PAGD adheres to the physical two-step hologram process (recording and reconstruction) interconnected through phase information [S1]. It is distinguished from its siblings, such as the Gerchberg-Saxton Algorithm, by using gradient-based loss minimization with a learned forward model rather than iterative hard amplitude constraints [S1].

## How it works
**Inputs:**
*   Mesh-represented scene $M$ [S1].
*   Camera settings $C$ [S1].
*   Lighting $L$ [S1].
*   Number of optimization iterations $T$ [S1].
*   Initial phase $\Phi_{init}$ [S1].

**Outputs:**
*   Optimized phase-only hologram $\Phi_{OPT}$ [S1].

**Data Structures:**
*   $\Phi$: Complex-valued phase hologram matrix, size $h \times w$ (SLM resolution) [S1].
*   $u_{WR}$: Target complex wave field generated by POS-WRP [S1].
*   $u_{ti}$: Target complex wave field at the $i$-th plane ($i \in \{1, 2, 3\}$) [S1].
*   $u_{ri}$: Reconstructed complex wave field at the $i$-th plane [S1].
*   $s_i$: Complex-valued scale factor for the $i$-th plane [S1].

**Formulas:**
The complex-valued scale factor $s$ accounts for light source intensity deviations and phase shift invariances [S1]. For a reconstructed field $u_r$ and target field $u_t$, the real and imaginary parts of $s$ are calculated as [S1]:

$$
\text{Re}(s) = \frac{\text{Re}(u_r) \odot \text{Re}(u_t) + \text{Im}(u_r) \odot \text{Im}(u_t)}{\text{Re}(u_r)^2 + \text{Im}(u_r)^2}
$$

$$
\text{Im}(s) = \frac{-\text{Im}(u_r) \odot \text{Re}(u_t) + \text{Re}(u_r) \odot \text{Im}(u_t)}{\text{Re}(u_r)^2 + \text{Im}(u_r)^2}
$$

where $\odot$ denotes element-wise multiplication [S1].

The loss function $L$ compares the scaled reconstructed field with the target field using Mean Squared Error (MSE) on real and imaginary components [S1]:

$$
L(s \odot u_r, u_t) = \text{MSE}(\text{Re}(s u_r), \text{Re}(u_t)) + \text{MSE}(\text{Im}(s u_r), \text{Im}(u_t))
$$

The total loss $E(\Phi)$ is the sum of scaled losses across 3 target planes [S1]:

$$
E(\Phi) = \sum_{i=1}^3 L(s_i \odot u_{ri}, u_{ti})
$$

**Steps:**
1.  Initialize phase $\Phi \leftarrow \Phi_{init}$ [S1].
2.  Generate the target wave field $u_{WR}$ using the Phase-Only Spatial Wave Reconstruction (POS-WRP) model with inputs $M, C, L$ [S1].
3.  Propagate the target wave field $u_{WR}$ to near, medium, and far planes ($z_i$) to obtain target fields $u_{ti}$ for $i=1, 2, 3$ [S1].
4.  For each iteration $n$ from 1 to $T$:
    a. For each of the 3 planes $i$:
        i. Propagate the current phase hologram $e^{j\Phi}$ shifted by $z_{WR} + z_i$ to obtain the reconstructed field $u_{ri}$ [S1].
    b. Calculate the complex-valued scale factors $s_i$ for each plane using the formula above [S1].
    c. Calculate the total loss $E(\Phi)$ by summing the scaled losses for all 3 planes [S1].
    d. Compute gradients $\nabla E(\Phi)$ via backpropagation through the learned forward model [S1].
    e. Update $\Phi$ using gradient descent [S1].
5.  Set the final optimized phase $\Phi_{OPT} = \Phi$ [S1].

**Pseudocode:**
```python
def phase_aware_gradient_descent(M, C, L, T, Phi_init, z_WR, z_planes):
    """
    M: Mesh scene
    C: Camera settings
    L: Lighting
    T: Number of optimization iterations
    Phi_init: Initial phase matrix
    z_WR: Distance from SLM to reference plane
    z_planes: List of 3 distances [z1, z2, z3] for target planes
    """
    Phi = Phi_init
    
    # Generate target wave field using POS-WRP
    u_WR = pos_wrp(M, C, L)
    
    # Propagate target wave field to 3 planes
    u_targets = []
    for z_i in z_planes:
        u_t = propagate(u_WR, z_i)
        u_targets.append(u_t)
        
    for n in range(T):
        u_reconstructions = []
        for z_i in z_planes:
            # Propagate current phase hologram
            # e^(j*Phi) creates complex field from phase
            phase_field = complex_exp(j * Phi)
            u_r = propagate(phase_field, z_WR + z_i)
            u_reconstructions.append(u_r)
            
        total_loss = 0.0
        for i in range(3):
            u_r = u_reconstructions[i]
            u_t = u_targets[i]
            
            # Calculate complex scale factor s
            # Denominator is element-wise square of magnitude of u_r
            denom = (u_r.real ** 2) + (u_r.imag ** 2)
            # Avoid division by zero [G]
            denom = where(denom < 1e-8, 1e-8, denom)
            
            s_real = ((u_r.real * u_t.real) + (u_r.imag * u_t.imag)) / denom
            s_imag = (-(u_r.imag * u_t.real) + (u_r.real * u_t.imag)) / denom
            s = complex(s_real, s_imag)
            
            # Scaled reconstruction
            u_scaled = s * u_r
            
            # Loss: MSE of real and imaginary parts
            loss_real = mse(u_scaled.real, u_t.real)
            loss_imag = mse(u_scaled.imag, u_t.imag)
            plane_loss = loss_real + loss_imag
            total_loss += plane_loss
            
        # Backpropagate to update Phi
        gradients = compute_gradients(total_loss, Phi)
        Phi = update_phase(Phi, gradients)
        
    return Phi
```

**Edge Cases and Pitfalls:**
*   **Phase Non-Uniqueness:** Supervising phase is challenging due to two inherent shift invariances: 1) Global shift in phase does not alter the wave field. 2) Phase value on each pixel can be shifted by $2\pi$ without changing the target field [S1]. The complex-valued scale factor $s$ accounts for these deviations and light source intensity variations [S1].
*   **Tilted Wave Fields:** Amplitude loss fails to reconstruct correct defocus cues on unsupervised planes for tilted wave fields (e.g., 1° tilt). Phase-aware supervision is required for accurate reconstruction in these cases [S1].
*   **Ringing Artifacts:** Abandoning phase supervision introduces ringing artifacts (e.g., edge ringing) [S1].

## Subtopics

### [Camera-Calibrated Wave Propagation Model Training](12905-camera-calibrated-wave-propagation-model-training.md)
This method trains a data-driven surrogate model using experimentally captured phase-to-intensity data to predict light propagation from a Spatial Light Modulator (SLM) to multiple target planes.

### [Gerchberg-Saxton Algorithm](14575-gerchberg-saxton-algorithm.md)
The Gerchberg-Saxton algorithm is an iterative optimization method used to compute phase-only holograms by determining object point phase values that cause interference resulting in constant amplitude across the hologram plane. It solves the problem of phase-only display constraints where the eye does not detect image phase, allowing the algorithm to treat object phases as free variables to satisfy amplitude constraints on the display. It is distinguished from its parent, Phase-Aware Gradient Descent (PAGD), by its specific use of back-and-forth propagation with hard amplitude constraints rather than gradient-based loss minimization, and from its sibling, Camera-Calibrated Wave Propagation Model Training, by being a direct analytical iterative solver rather than a learned model.

## Operating characteristics
*   **Time Complexity:** The training time for the PAGD optimizer component is 30 seconds per hologram [S1]. The total time for generating one phase-only hologram from a mesh scene is on average 54.96 seconds (24.96 s for POS-WRP and 30 s for PAGD) [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** PAGD mitigates ringing artifacts and unnatural blur spreading found in amplitude-only or RGB-D methods [S1]. It offers more accurate reconstruction than amplitude-only supervision for tilted wave fields [S1]. Incorporating phase regularization reduces the demand for multi-plane supervision; enforcing complex target supervision on 1-plane yields an improvement of 7 dB in PSNR over 2-plane amplitude-only supervision while being slightly faster, and is 2.39× faster than 5-plane amplitude-only supervision at the same image quality [S1].
*   **Strengths:** Adheres to the physical two-step hologram process; handles tilted wave fields accurately; reduces the number of required supervised planes; view-dependent holography is a direct outcome; requires training the forward model only once [S1].
*   **Limitations:** Real-time hologram generation remains a goal for future exploration; numerical models like ASM struggle to replicate real-world optical systems due to imperfections (aberrations, SLM non-linearities, stray light, limited diffraction efficiency), necessitating a learned model [S1].
*   **When to use:** When accurate 3D depth cues and view-dependent effects are required for phase-only holographic displays, especially for tilted wave fields or when minimizing the number of supervised planes is critical [S1].
*   **When not to use:** When real-time performance is strictly required without further acceleration (e.g., via CNNs) [S1].

## Background
PAGD was proposed in a 2026 paper published in *Nature Communications* by researchers investigating mesh-represented and learning-empowered hologram synthesis for full 3D holographic displays [S1]. The method addresses limitations of amplitude-based optimization, such as manual setting of target planes, single-viewpoint constraints, and unrealistic defocus blur [S1]. It builds on the concept of Phase-Only Spatial Wave Reconstruction (POS-WRP) and utilizes a camera-calibrated learned wavefront propagation model to enhance precision [S1].
