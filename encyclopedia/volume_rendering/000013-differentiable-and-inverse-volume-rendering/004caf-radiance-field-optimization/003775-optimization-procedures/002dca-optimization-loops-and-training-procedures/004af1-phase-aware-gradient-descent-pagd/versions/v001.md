# Phase-Aware Gradient Descent (PAGD)
Also called: Phase-Only Hologram Synthesis via PAGD

## Overview
Phase-Aware Gradient Descent (PAGD) is an optimization method used to encode complex wave fields into phase-only holograms for 3D holographic displays [S1]. It solves the problem of ringing artifacts and unnatural blur spreading inherent in amplitude-only or RGB-D holographic synthesis methods [S1]. Unlike amplitude-only end-to-end optimization techniques, PAGD adheres to the physical two-step hologram process (recording and reconstruction) interconnected through phase information, rather than using implicit models [S1]. It builds on [Optimization Loops and Training Procedures](5622-optimization-loops-and-training-procedures.md) by incorporating phase-aware supervision, which offers more accurate reconstruction than amplitude-only supervision for tilted wave fields [S1].

## How it works
**Inputs:**
*   Mesh-represented scene $M$
*   Camera settings $C$
*   Lighting $L$
*   Number of optimization iterations $T$
*   Initial phase $\Phi_{init}$

**Outputs:**
*   Optimized phase-only hologram $\Phi_{OPT}$

**Data Structures:**
*   $\Phi$: Complex-valued phase hologram (stored as real-valued phase map).
*   $u_{WR}$: Target wave field generated by POS-WRP.
*   $u_{ti}$: Target wave field at plane $i$ (near, medium, far).
*   $u_{ri}$: Reconstructed wave field at plane $i$.
*   $s$: Complex-valued scale factor.
*   $z_i$: Depth positions of the three target planes.
*   $z_{WR}$: Distance from the SLM to the wave field recording plane.

**Steps:**

1.  **Initialize Phase:** Set $\Phi \leftarrow \Phi_{init}$.
2.  **Generate Target Wave Field:** Generate the target wave field $u_{WR}$ using the Phase-Only Wave Field Recording (POS-WRP) method with inputs $M, C, L$ [S1].
3.  **Propagate Targets:** Propagate the target wave field $u_{WR}$ to near, medium, and far planes ($z_i$) to obtain target fields $u_{ti}$ for $i=1, 2, 3$ [S1].
4.  **Optimization Loop:** For each iteration $n$ from 1 to $T$:
    a.  **Reconstruction:** For each of the 3 planes $i$:
        i.  Propagate the current phase hologram $e^{j\Phi}$ shifted by $z_{WR} + z_i$ to obtain the reconstructed field $u_{ri}$ [S1].
    b.  **Scale Factor Calculation:** Calculate the complex-valued scale factor $s$ to account for light source intensity deviations and phase shift invariances [S1]. The real and imaginary parts of $s$ are computed as:
        $$
        \text{Re}(s) = \frac{\text{Re}(u_r) \odot \text{Re}(u_t) + \text{Im}(u_r) \odot \text{Im}(u_t)}{\text{Re}(u_r)^2 + \text{Im}(u_r)^2}
        $$
        $$
        \text{Im}(s) = \frac{-\text{Im}(u_r) \odot \text{Re}(u_t) + \text{Re}(u_r) \odot \text{Im}(u_t)}{\text{Re}(u_r)^2 + \text{Im}(u_r)^2}
        $$
        where $u_r$ and $u_t$ represent the reconstructed field and target field respectively, and $\odot$ denotes element-wise multiplication [S1].
    c.  **Loss Calculation:** Calculate the total loss $E(\Phi)$ by summing the scaled losses for all 3 planes:
        $$
        E(\Phi) = \sum_{i=1}^3 L(s_i \odot u_{ri}, u_{ti})
        $$
        where the loss function $L$ is defined as:
        $$
        L(s \odot u_r, u_t) = \text{MSE}(\text{Re}(s u_r), \text{Re}(u_t)) + \text{MSE}(\text{Im}(s u_r), \text{Im}(u_t))
        $$
        [S1].
    d.  **Backpropagation:** Compute gradients $\nabla E(\Phi)$ and update $\Phi$ using backpropagation [S1].
5.  **Finalize:** Set $\Phi_{OPT} = \Phi$ [S1].

**Parameters:**
*   $T$: Number of optimization iterations. Typical value not specified, but training time is 30 seconds per hologram [S1].
*   $z_i$: Distances of the three target planes. Specific values for the camera-calibrated variant are 10.00, 10.07, 10.14, 10.21, 10.28, 10.35, 10.42, and 10.49 cm from the SLM [S1].

**Edge Cases and Pitfalls:**
*   **Phase Non-Uniqueness:** Supervising phase faces challenges due to the non-uniqueness of phase distribution. Two inherent shift invariances exist:
    1.  Global shift in phase does not alter the wave field.
    2.  Phase value on each pixel can be shifted by $2\pi$ without changing the target field [S1].
*   **Mitigation:** The complex-valued scale factor $s$ accounts for deviation in light source intensity and these shift-invariance characteristics [S1].
*   **Amplitude-Only Limitations:** Amplitude-based multi-layer representations are constrained to encoding scenes from a single viewpoint, whereas complex fields can capture directional light field information [S1]. Amplitude loss fails to reconstruct correct defocus cues on unsupervised planes for tilted wave fields (e.g., 1° tilt) [S1].

## Subtopics

### Camera-Calibrated Wave Propagation Model Training
A variant where the forward model is trained on real hardware data to capture optical imperfections (aberrations, SLM non-linearities, stray light) that numerical models like ASM struggle to replicate [S1]. It uses a dataset of 5860 phase patterns (including 2D phases from SGD, higher-order gradient descent, double-phase amplitude encoding, and true 3D phases from the Flying Planes dataset) recorded at eight target planes (10.00, 10.07, 10.14, 10.21, 10.28, 10.35, 10.42, 10.49 cm) [S1]. The model is trained on a single NVIDIA RTX 4090 GPU with a batch size of 1 for 20 epochs using the Adam optimizer with a learning rate of 0.0005 [S1]. The Region of Interest (ROI) is 880 × 1600 pixels [S1].

## Operating characteristics
*   **Time Complexity:** The training time for the PAGD optimizer component is 30 seconds per hologram [S1]. The total time for generating one phase-only hologram from a mesh scene is on average 54.96 s (24.96 s for POS-WRP and 30 s for PAGD) [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** Phase-aware supervision offers more accurate reconstruction than amplitude-only supervision for tilted wave fields (e.g., 1° tilt) [S1]. Incorporating phase regularization in the loss function reduces the demand for multi-plane supervision; enforcing complex target supervision on 1-plane yields an improvement of 7 dB in PSNR over 2-plane amplitude-only supervision while being slightly faster, and is 2.39 × faster than 5-plane amplitude-only supervision at the same image quality [S1].
*   **Strengths:** Mitigates ringing artifacts and unnatural blur spreading; adheres to physical two-step hologram process; requires training the forward model only once; does not necessitate specific data per viewpoint during training; facilitates 3D imaging with continuous depth cues across multiple viewpoints [S1].
*   **Limitations:** Real-time hologram generation remains a goal for future exploration [S1].

## Background
PAGD was proposed in a 2026 paper published in *Nature Communications* [S1]. It is part of a mesh-represented and learning-empowered hologram synthesis pipeline for full 3D holographic displays [S1]. The method addresses limitations of amplitude-based optimization, such as manual setting of target planes, single-viewpoint constraints, and unrealistic defocus blur [S1]. It leverages a camera-calibrated learned model to enhance precision, trained on the Flying Planes mesh-wave field-hologram dataset [S1].
