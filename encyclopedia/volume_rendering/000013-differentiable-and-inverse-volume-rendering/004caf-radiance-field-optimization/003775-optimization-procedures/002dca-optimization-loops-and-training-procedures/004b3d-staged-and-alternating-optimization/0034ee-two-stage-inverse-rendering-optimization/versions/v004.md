# Two-Stage Inverse Rendering Optimization

Also called: Hybrid Differentiable Rendering for Inverse Rendering, Two-Stage Optimization Strategy

## Overview
Two-Stage Inverse Rendering Optimization is a pipeline that decouples geometry and reflectance estimation by first optimizing scene geometry using an approximate differentiable renderer and then optimizing material reflectance (albedo) and lighting using a physically-based differentiable renderer [S1]. It differs from NeRF, IDR, and PhySG by utilizing triangle meshes and physically-based rendering (PBR) materials (Cook-Torrance) rather than Signed Distance Fields (SDFs) or Spherical Gaussians, enabling direct deployment on graphics engines and superior specular handling [S1].

## How it works
The method operates in two distinct phases. The first phase initializes and refines geometry, while the second phase optimizes material properties and illumination while keeping geometry fixed.

### Inputs and Outputs
**Inputs:**
*   A set of multi-view images $\{I_{rgb}\}$ of a scene.
*   Camera parameters for each input image.
*   (Optional) Binary foreground masks $M$ for the input images [S2].
*   Initial geometry: A dense mesh obtained via Structure-from-Motion (SfM) and Multi-View Stereo (MVS) reconstruction [S1].

**Outputs:**
*   Optimized vertex positions $\theta_p$ defining the mesh geometry [S1].
*   Diffuse albedo texture $\theta_d$ and specular albedo texture $\theta_s$ [S1].
*   HDR Environment map $L_{env}$ representing the illumination [S1, S2].

### Data Structures
**Scene Parameters $\Theta$:**
*   $\theta_p$: Vertex positions of the mesh [S1].
*   $\theta_d$: Diffuse albedo texture map [S1].
*   $\theta_s$: Specular albedo texture map [S1].
*   $L_{env}$: Environment map radiance [S2].

**Gaussian Splatting Attributes (Stage 2 variant [S2]):**
*   $\mu$: Position [S2].
*   $\Sigma$: Covariance [S2].
*   $c$: Color [S2].
*   $\alpha$: Opacity [S2].
*   $n$: Normal [S2].
*   $\rho$: Albedo (diffuse/specular) [S2].
*   $r$: Roughness [S2].

### Numbered Steps

#### Stage 1: Geometry Optimization
This stage establishes a robust geometric proxy. Two variations exist in the literature: one using explicit mesh optimization [S1] and one using 3D Gaussian Splatting initialization [S2].

1.  **Initialization:**
    *   Generate a sparse point cloud and rough mesh using SfM [S1].
    *   Generate dense pixel-level matching using MVS [S1].
    *   Reconstruct a dense mesh via Poisson surface reconstruction [S1].
    *   Initialize the environment map $L_{env}$ with white light, setting channels to $(0.5, 0.5, 0.5)$ [S1].
    *   [S2] Pretrain a standard 3D Gaussian model with joint normal training.

2.  **Geometry Update:**
    *   [S1] Compute a silhouette image $I_{sil}(\theta_p)$ for each input image using an approximate differentiable renderer (e.g., Soft Rasterizer) and camera parameters.
    *   [S2] Render opacity $\hat{\alpha}$ and color using the Gaussian splatter.

3.  **Loss Calculation:**
    *   [S1] Compute the geometry loss $L_{geo}$:
        $$ L_{geo} = \lambda_{sil} L_{sil} + \lambda_{lap} L_{lap} + \lambda_{normal} L_{normal} + \lambda_{edge} L_{edge} $$
        Where:
        *   Silhouette Loss: $L_{sil} = \frac{1}{|\Omega|} \sum_{\Omega} \left( 1 - \frac{\tilde{I}_{sil} \otimes I_{sil}}{\tilde{I}_{sil} \oplus I_{sil}} \right)$, with $\otimes$ and $\oplus$ being element-wise product and sum, and $\tilde{I}_{sil}$ being the ground truth silhouette.
        *   Laplacian Loss: $L_{lap} = \|LV\|_2$, where $V$ is the $n \times 3$ vertex coordinate matrix and $L$ is the $n \times n$ Laplacian matrix of the mesh.
        *   Normal Consistency Loss: $L_{normal} = \sum_{i,j} [1 - (n_i \cdot n_j)]$, summed over all triangle pairs $(i,j)$ sharing a common edge, where $n_i, n_j$ are face normals.
        *   Edge Length Loss: $L_{edge} = \sum_i e_i$, where $e_i$ is the length of the $i$-th edge.
    *   [S2] Compute the initialization loss $L_{init}$:
        $$ L_{init} = L_c + L_n + \lambda_{mask} L_{mask} $$
        Where:
        *   $L_c$: Color reconstruction loss from standard Gaussian splatting.
        *   $L_n$: Normal loss.
        *   $L_{mask} = \|\hat{\alpha} - M\|_1$, where $M$ is the binary foreground mask. This pulls splats closer to the surface.

4.  **Optimization:**
    *   Optimize vertex positions $\theta_p$ (mesh) or Gaussian attributes $\{\mu, \Sigma, c, \alpha, n\}$ (Gaussian) to minimize the respective loss.
    *   [S1] Iterate for ~200 iterations per view (total ~0.5 hours per example on RTX 3090) [S1].
    *   [S2] Iterate for 30,000 iterations [S2].

#### Stage 2: Reflectance and Lighting Optimization
This stage optimizes material properties and lighting using physically-based rendering.

1.  **Freeze Geometry:**
    *   [S1] Keep vertex positions $\theta_p$ fixed.
    *   [S2] Freeze geometric Gaussian attributes $\{\mu, \Sigma, c, \alpha, n\}$.

2.  **Physically-Based Rendering Setup:**
    *   Define the reflectance model $f_r(\omega_o, \omega_i; x)$:
        $$ f_r(\omega_o, \omega_i; x) = \theta_d(x) + \theta_s(\omega_o, \omega_i; x) $$
        Where:
        *   $\theta_d(x) = \rho_d(x)/\pi$ is the diffuse reflectance.
        *   $\theta_s(\omega_o, \omega_i; x) = \rho_s(x) \frac{D(h, \alpha)G(\omega_o, \omega_i, n(x))}{(n(x) \cdot \omega_i)(n(x) \cdot \omega_o)\pi}$ is the specular reflectance.
        *   $D(h, \alpha)$ is the GGX microfacet distribution [Walter et al., 2007].
        *   The Fresnel effect is ignored [S1].
    *   Render the scene using a physically-based differentiable renderer (e.g., Mitsuba 2 or OptiX-based ray tracer) [S1, S2].
    *   [S1] Set ray tracing bounce depth to 3, image downsampling factor to 4, and samples per pixel (spp) to 4 [S1].
    *   [S2] Use a compact environment map (e.g., $16 \times 32$ or $512 \times 128$) and normal-based hemisphere sampling [S1, S2].

3.  **Loss Calculation:**
    *   [S1] Compute the reflectance loss $L_{ref}$:
        $$ L_{ref} = \lambda_{rgb} L_{rgb} + \lambda_{reg} R(\theta_r) $$
        Where:
        *   $L_{rgb} = \|\tilde{I}_{rgb} - I_{rgb}(\theta_r)\|_1$ is the L1 photometric loss between rendered color $I_{rgb}$ and ground truth $\tilde{I}_{rgb}$.
        *   $R(\theta_r)$ is a regularizer for diffuse $\theta_d$ and specular $\theta_s$ albedos:
            $$ R(\theta_r) = \sum_p \left( \theta_s[p] - \frac{\sum_q \theta_s[q]k_{p,q}}{\sum_q k_{p,q}} \right)^2 + \sum_p \frac{(\theta_d[p] - \theta_d[q])^2}{2\sigma_2^2} $$
            Where $k_{p,q} = \exp\left(-\frac{\|p-q\|_2^2}{2\sigma_1^2}\right)$ is a kernel between specific mesh vertices/pixels $p, q$.
    *   [S2] Compute the L1 photometric loss $L_{1pbr}$ with unit weight.

4.  **Optimization:**
    *   Optimize BRDF parameters ($\rho_d, \rho_s$ or $\theta_d, \theta_s$) and the environment map $L_{env}$ jointly [S1, S2].
    *   [S1] Iterate for 400 iterations per view (total 1.5–2.5 hours per example on RTX 3090) [S1].
    *   [S2] Iterate for 400 iterations [S2].
    *   **Pitfall:** Longer second-stage training degrades relighting quality because the albedo begins to absorb illumination information [S2].

## Operating characteristics
*   **Time Complexity:** Stage 1 (Geometry) takes approximately 0.5 hours per example on an NVIDIA RTX 3090 [S1]. Stage 2 (Reflectance) takes 1.5–2.5 hours per example on the same hardware [S1]. In the Gaussian variant [S2], Stage 1 takes ~15 minutes and Stage 2 ~10 minutes on an RTX A6000 [S2].
*   **Memory Complexity:** The physically-based rendering module requires significant memory. To mitigate this, the method uses a maximum ray tracing bounce depth of 3, an image downsampling factor of 4, and 4 samples per pixel (spp) [S1].
*   **Strengths:**
    *   Decoupling geometry and reflectance allows for more stable optimization than joint optimization [S1].
    *   Using triangle meshes and PBR materials allows direct deployment on graphics engines [S1].
    *   Better handling of specular highlights compared to methods using SDFs or Spherical Gaussians (e.g., PhySG, NeRF) [S1].
*   **Limitations:**
    *   Longer training in Stage 2 degrades relighting quality as the albedo absorbs illumination information [S2].
    *   Relies on initial SfM/MVS reconstruction, which may have defects in boundary regions [S1].
    *   The Fresnel effect is ignored in the reflectance model, which may limit accuracy in certain scenes [S1].

## Background
The method was introduced in "Efficient Multi-View Inverse Rendering Using a Hybrid Differentiable Rendering Method" [S1] at IJCAI-2023. It addresses the challenges of inverse rendering in complex, unstructured scenes without depth information. The approach builds on earlier work in differentiable rendering [Liu et al., 2019] and physically-based rendering [Kajiya, 1986]. It contrasts with NeRF [Mildenhall et al., 2020], IDR [Yariv et al., 2020], and PhySG [Zhang et al., 2021b] by using explicit geometry (meshes) and PBR materials rather than implicit representations (SDFs/occupancy) and simplified lighting models (Spherical Gaussians).
