# Optimization Baselines
Also called: Baselines, CMA-ES, Classical Optimization Baselines, Covariance Matrix Adaptation Evolution Strategy

## Overview
This family provides black-box optimization strategies for inverse rendering problems where the forward rendering operator $f$ is non-differentiable or gradient computation is prohibitively expensive [S1, unofficial]. Unlike gradient-based siblings that rely on automatic differentiation or adjoint methods, these methods treat the renderer as an opaque function, minimizing a photometric loss $\mathcal{L}$ by iteratively sampling and evaluating parameter candidates [S1, unofficial]. The family is distinguished by its reliance on population-based search distributions (typically Gaussian) that adapt to the local loss landscape without explicit gradient information, offering robustness against local minima and Monte Carlo noise [S1, unofficial].

## Shared principles
All methods in this family operate within the standard inverse rendering loop defined by [Optimization Loops and Training Procedures](5622-optimization-loops-and-training-procedures.md), minimizing a photometric loss $\mathcal{L}$ between rendered color $\hat{C}(\mathbf{r})$ and ground-truth $C(\mathbf{r})$ [G]. The core mechanism involves maintaining a search distribution $\mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\Sigma})$ over the parameter space $\mathbb{R}^d$, where $\boldsymbol{\mu}$ is the mean and $\boldsymbol{\Sigma}$ is the anisotropic covariance matrix capturing correlations between parameters [S1, unofficial].

The optimization proceeds in iterations. In each iteration, $k$ candidates $\{\mathbf{x}_i\}_{i=0}^{k}$ are drawn from the current distribution $\mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\Sigma})$ [S1, unofficial]. These candidates are evaluated using the black-box renderer $f$ to compute a cost $c_i = \mathcal{L}(f(\mathbf{x}_i), \mathbf{y}^*)$ [S1, unofficial]. The distribution parameters $\boldsymbol{\mu}$ and $\boldsymbol{\Sigma}$ are then updated by computing a weighted average of the candidates, ranked by their cost [S1, unofficial]. Higher weights are assigned to top-scoring candidates to adapt the search distribution to the local loss landscape [S1, unofficial].

```python
import numpy as np

def cma_es_baseline(renderer, target_image, d, k=500, N=50, sigma_0=1.0/6.0):
    """
    Implements the CMA-ES baseline for black-box inverse rendering.
    Args:
        renderer: Black-box function f: R^d -> Image
        target_image: Target image y*
        d: Dimensionality of parameter space
        k: Population size
        N: Number of iterations
        sigma_0: Initial standard deviation
    Returns:
        mu: Optimized parameters (mean of final distribution)
    """
    mu = np.zeros(d)
    Sigma = sigma_0 * np.eye(d)
    
    for _ in range(N):
        # 1. Sampling: Draw k candidates from N(mu, Sigma)
        candidates = np.random.multivariate_normal(mu, Sigma, size=k)
        
        # 2. Evaluation: Compute photometric loss for each candidate
        costs = np.array([np.mean((renderer(x) - target_image) ** 2) for x in candidates])
        
        # 3. Ranking: Sort candidates by cost (ascending)
        sorted_indices = np.argsort(costs)
        ranked_candidates = candidates[sorted_indices]
        
        # 4. Weighting: Assign higher weights to top-scoring candidates
        weights = np.zeros(k)
        weights[:k//10] = 2.0
        weights[k//10:] = 0.5
        weights /= weights.sum()
        
        # 5. Update mean: Weighted average of ranked candidates
        mu = np.dot(weights, ranked_candidates)
        
        # 6. Update covariance: Rank-one/rank-mu style update using centered candidates
        centered = ranked_candidates - mu
        Sigma = np.sum(weights[:, None, None] * (centered[:, :, None] * centered[:, None, :]), axis=0)
        
    return mu
```

## Subtopics

### [Feature-Guided Diffusion for Inverse Rendering](7375-feature-guided-diffusion-for-inverse-rendering.md)
A fully black-box framework combining a diffusion-based inverse prediction model with CMA-ES. It conditions the proposal distribution on dense visual features extracted from the target image, avoiding the information bottleneck of scalar loss values and mitigating mode averaging in ill-posed inverse problems.
- **CMA-ES:** The classical evolutionary baseline using covariance matrix adaptation. It serves as the primary reference for population-based search, adapting the Gaussian distribution to the loss landscape without auxiliary models.
- **Dual Annealing:** Combines simulated annealing with a local search strategy to improve convergence. It uses a standard implementation (e.g., SciPy) and does not maintain an explicit covariance matrix.
- **ZeroGrads:** Trains a differentiable surrogate of the black-box function’s loss landscape and uses it to derive optimization gradients. It bridges the gap between black-box and gradient-based methods by learning the gradient field.
- **DiBO:** A diffusion-based method that combines a diffusion prior with a learned reward proxy to sample candidates from an approximate posterior over high-performing solutions. It differs from FIDE by using a reward proxy rather than dense image features for conditioning.

## Background
The family originates from the need to solve inverse rendering problems where differentiable rendering is unavailable or unstable [S1, unofficial]. CMA-ES [Hansen 2006] serves as the primary evolutionary baseline, inheriting the ability to adapt to the local loss landscape via covariance updates and providing robustness against local minima without explicit gradient information [S1, unofficial]. Dual annealing [Tsallis and Stariolo 1996] combines simulated annealing with a local search strategy to improve convergence; the standard SciPy implementation [Virtanen et al. 2020] is commonly used [S1, unofficial]. From more recent methods, ZeroGrads [Fischer and Ritschel 2024] trains a differentiable surrogate of the black-box function’s loss landscape and uses it to derive optimization gradients [S1, unofficial]. DiBO [Yun et al. 2025] is a diffusion-based method that combines a diffusion prior with a learned reward proxy to sample candidates from an approximate posterior over high-performing solutions [S1, unofficial]. Classical Bayesian Optimization (BO) is not typically compared directly because its performance overhead is non-linear with iterations and several orders of magnitude higher than that of all other methods [S1, unofficial].
