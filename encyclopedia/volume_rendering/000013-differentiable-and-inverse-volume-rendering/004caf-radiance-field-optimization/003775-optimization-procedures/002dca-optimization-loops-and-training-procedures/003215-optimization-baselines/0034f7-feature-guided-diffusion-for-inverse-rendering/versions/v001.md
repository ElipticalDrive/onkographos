# Feature-Guided Diffusion for Inverse Rendering

Also called: Diffusion-CMA-ES Inverse Rendering, Diffusion-based CMA-ES, FGD, Feature-Guided Diffusion, Feature-Guided Diffusion for Non-Differentiable Inverse Rendering, Feature-Informed Diffusion Evolution

## Overview
Feature-Guided Diffusion for Inverse Rendering (FIDE) is a fully black-box optimization framework that solves non-differentiable inverse rendering problems by combining a diffusion-based inverse predictor with Covariance Matrix Adaptation Evolution Strategy (CMA-ES) [S1, unofficial]. Unlike gradient-based methods or scalar-loss evolutionary baselines like [CMA-ES](6675-optimization-baselines.md), FIDE extracts dense visual features from rendered images to guide candidate proposal, thereby avoiding the information bottleneck of scalar loss values and mitigating mode averaging in ill-posed inverse problems [S1, unofficial]. It is chosen when the renderer is an opaque black box, gradients are unavailable or unstable, and the solution space exhibits multi-modality [S1, unofficial].

## How it works
FIDE operates within the standard inverse rendering loop defined by [Optimization Loops and Training Procedures](5622-optimization-loops-and-training-procedures.md), minimizing a photometric loss $\mathcal{L}$ between rendered color $\hat{C}(\mathbf{r})$ and ground-truth $C(\mathbf{r})$ [G]. The method maintains a search distribution via CMA-ES and a learned diffusion denoiser $\tilde{f}_{\theta}^{-1}$, alternating between inverse prediction and evolutionary refinement [S1, unofficial].

### Inputs and Outputs
*   **Inputs**: Black-box renderer $f: \mathbb{R}^d \to \mathcal{I}$, target image $y^* \in \mathcal{I}$, frozen feature extractor $E: \mathcal{I} \to \mathbb{R}^{h \times w \times c}$ (default: DINOv3-small), population size $k=500$, iteration count $N=50$, initial standard deviation $\sigma_0 = 1/6$.
*   **Outputs**: Optimized parameter vector $\mathbf{x}^*$ minimizing the loss.

### Data Structures
1.  **CMA-ES State**:
    *   Mean $\boldsymbol{\mu} \in \mathbb{R}^d$: Initialized to $\mathbf{0}_d$ (parameters normalized to $[0,1]$ start at $0.5$).
    *   Covariance $\boldsymbol{\Sigma} \in \mathbb{R}^{d \times d}$: Initialized to $\sigma_0 \mathbf{I}_{d \times d}$.
2.  **Diffusion Denoiser $\tilde{f}_{\theta}^{-1}$**:
    *   Architecture: Transformer-based parameter refinement.
    *   Inputs: Noisy parameters $\mathbf{z} \in \mathbb{R}^d$, image features $\mathbf{F} = E(y)$, timestep proxy $\mathbf{s} \in \mathbb{R}^d$.
    *   Internal Layout:
        *   Image features flattened to tokens with learned positional embeddings.
        *   Noisy parameters projected to tokens via linear layer.
        *   Four self-attention blocks on parameter tokens.
        *   Cross-attention blocks attending to image tokens.
        *   Feature-wise Linear Modulation (FiLM) injects $\mathbf{s}$ into each attention block.
        *   Output: Linear projection back to $\mathbb{R}^d$.
3.  **Population**: Set of $k$ candidate parameters $\{\mathbf{x}_i\}_{i=0}^{k-1}$.

### Parameters
*   **Feature Extractor**: Frozen DINOv3-small [S1, unofficial]. Alternatives: VGG-19, learnable 16x16 patch embedding (slower convergence) [S1, unofficial].
*   **Loss Function**: LPIPS (Learned Perceptual Image Patch Similarity) [S1, unofficial].
*   **Optimizer**: Adam for diffusion training, learning rate $0.001$, epochs $20$ [S1, unofficial].
*   **Reverse ODE Solver**: Euler method, 3 steps, schedule $[0.3, 0.2, 0.1]$ [S1, unofficial].

### Algorithm Steps
1.  **Initialization**: Set $\boldsymbol{\mu} = \mathbf{0}_d$, $\boldsymbol{\Sigma} = \sigma_0 \mathbf{I}_{d \times d}$. Initialize denoiser weights $\theta$.
2.  **Iteration Loop** ($i = 1$ to $N$):
    1.  **Sampling**: Draw $k$ candidates $\{\mathbf{x}_i\}_{i=0}^{k-1} \sim \mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\Sigma})$ [S1, unofficial].
    2.  **Inverse Prediction (Partial Denoising)**:
        *   Extract target features $\mathbf{F}^* = E(y^*)$ [S1, unofficial].
        *   Select first half of candidates $\{\mathbf{x}_j\}_{j=0}^{k/2-1}$.
        *   Compute timestep proxy $\mathbf{s} = \sqrt{\text{diag}(\boldsymbol{\Sigma})}$ [S1, unofficial].
        *   Denoise candidates: $\{\mathbf{x}'_j\} = \tilde{f}_{\theta}^{-1}(\{\mathbf{x}_j\}, \mathbf{F}^*, \mathbf{s})$ using reverse ODE solver [S1, unofficial].
        *   Combine: New population is $\{\mathbf{x}'_j\}_{j=0}^{k/2-1} \cup \{\mathbf{x}_j\}_{j=k/2}^{k-1}$ [S1, unofficial].
    3.  **Evaluation**: Render all $k$ candidates to obtain images $\{y_j\} = f(\{\mathbf{x}_j\})$ [S1, unofficial].
    4.  **Feature Extraction**: Compute features $\{\mathbf{F}_j\} = E(\{y_j\})$ [S1, unofficial].
    5.  **Online Training**: Train $\tilde{f}_{\theta}^{-1}$ on the current dataset $\{(\mathbf{x}_j, \mathbf{F}_j)\}$ for 20 epochs using Adam (lr=0.001), starting from previous weights [S1, unofficial].
        *   **Training Objective**: $\| \tilde{f}_{\theta}^{-1}(z, f(x), s) - x \|_2^2$, where $z \sim \mathcal{N}(x, \sigma(s)^2 \mathbf{I})$ [S1, unofficial]. Note: During training, noise is sampled using the current $\boldsymbol{\Sigma}$ to match the inference distribution [S1, unofficial].
    6.  **CMA-ES Update**: Rank candidates by loss $\mathcal{L}(y_j, y^*)$. Update $\boldsymbol{\mu}$ and $\boldsymbol{\Sigma}$ using weighted average of top candidates [S1, unofficial].

### Pseudocode
```python
def fide(renderer, target_image, feature_extractor, k=500, N=50, sigma0=1/6):
    # Initialize CMA-ES
    mu = zeros(d)
    Sigma = sigma0 * identity(d)
    
    # Initialize Diffusion Denoiser
    theta = init_denoiser_weights()
    
    # Extract target features once
    target_features = feature_extractor(target_image)
    
    for i in range(1, N + 1):
        # 1. Sampling
        candidates = sample_normal(k, mu, Sigma)
        
        # 2. Inverse Prediction (Partial Denoising)
        # Compute timestep proxy from covariance diagonal
        s = sqrt(diag(Sigma))
        
        # Denoise first half
        half_k = k // 2
        denoised_candidates = denoise(
            candidates[:half_k], 
            target_features, 
            s, 
            theta
        )
        
        # Combine: denoised first half, raw second half
        candidates = concat(denoised_candidates, candidates[half_k:])
        
        # 3. Evaluation
        rendered_images = [renderer(x) for x in candidates]
        
        # 4. Feature Extraction
        image_features = [feature_extractor(img) for img in rendered_images]
        
        # 5. Online Training
        # Train denoiser to predict clean x from noisy z, conditioned on image features
        # Noise z is sampled from N(x, Sigma) during training to match inference
        train_denoiser(candidates, image_features, s, theta, epochs=20, lr=0.001)
        
        # 6. CMA-ES Update
        losses = [compute_loss(img, target_image) for img in rendered_images]
        mu, Sigma = cma_es_update(candidates, losses, mu, Sigma)
        
    return mu
```

### Edge Cases and Pitfalls
*   **Mode Averaging**: Naïve regression predictors average multiple valid solutions, producing invalid parameters. FIDE uses diffusion to model multi-modality [S1, unofficial].
*   **Mode Collapse**: Relying solely on denoising risks overfitting to current estimates. Partial denoising (50%) preserves diversity [S1, unofficial].
*   **Dimensionality Limit**: CMA-ES has quadratic memory complexity $O(d^2)$, and the diffusion model has quadratic self-attention $O(d^2)$. This limits the method to $d \lesssim 100$ parameters [S1, unofficial].
*   **Initialization**: Parameters must be normalized to $[0, 1]$ and initialized at $0.5$. $\sigma_0=1/6$ ensures the $[0,1]$ space is within $3\sigma$ of initialization [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: Per iteration, dominated by $k$ render calls and diffusion training. Total runtime on Beads task (25k renders, 224x224) is 6–13 minutes on desktop hardware [S1, unofficial].
*   **Memory Complexity**: $O(d^2)$ due to CMA-ES covariance matrix and diffusion self-attention [S1, unofficial].
*   **Scaling**: Convergence is fast up to 60 parameters; at 80 parameters, >50,000 render calls are needed [S1, unofficial].
*   **Strengths**: Handles non-differentiable black-box renderers; escapes local minima better than gradient-based methods; robust to noise and poor initialization; avoids scalar loss information bottleneck [S1, unofficial].
*   **Limitations**: High overhead compared to scalar baselines (e.g., DiBO takes hours, FIDE takes minutes but uses fewer renders); limited to small-to-medium parameter spaces [S1, unofficial].

## Background
FIDE was introduced by Ardelean, Fischer, Weyrich, and Iser in 2026 [S1, unofficial]. It addresses the limitations of evolutionary strategies that rely on scalar fitness values and gradient-based methods that require differentiability. The method builds on CMA-ES [Hansen 2006] and diffusion models [Li and He 2025], adapting the latter to use anisotropic noise from CMA-ES for training [S1, unofficial]. It is validated on camera pose estimation, robot arm estimation, path tracing, vector splines, and Voronoi shaders [S1, unofficial].
