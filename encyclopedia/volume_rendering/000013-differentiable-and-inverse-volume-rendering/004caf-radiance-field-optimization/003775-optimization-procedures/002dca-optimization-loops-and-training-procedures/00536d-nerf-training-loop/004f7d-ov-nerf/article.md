# OV-NeRF

Also called: Open-Vocabulary Neural Radiance Fields With Vision and Language Foundation Models for 3D Semantic Understanding

## Overview
OV-NeRF is a method for accurate NeRF-based open-vocabulary 3D semantic understanding that leverages pre-trained vision and language foundation models (CLIP and SAM) to enhance semantic field learning through single-view and cross-view strategies [S1]. It addresses the limitations of prior methods (e.g., LERF, 3DOVS) that directly use noisy and view-inconsistent CLIP relevancy maps for training [S1]. OV-NeRF introduces Region Semantic Ranking (RSR) regularization to rectify coarse boundaries in single views using SAM mask proposals, and Cross-view Self-enhancement (CSE) to enforce view-consistent supervision using refined 3D semantics from the trained field itself [S1].

## How it works
### Inputs and Outputs
**Inputs:**
*   A set of $N$ posed training images $I = \{I_i \in \mathbb{R}^{H \times W \times 3} \mid i \in \{1, \dots, N\}\}$ [S1].
*   A set of text descriptions for $M$ classes [S1].
*   Pre-trained models: CLIP image encoder $E_i$, CLIP text encoder $E_t$, and Segment Anything Model (SAM) $E_{sam}$ [S1].

**Outputs:**
*   A trained semantic field (NeRF parameters $\theta$ and semantic MLP parameters $\phi$) [S1].
*   Rendered novel views with RGB color, volume density, semantic features, and segmentation logits [S1].

### Data Structures
*   **NeRF Representation:** An implicit neural volumetric representation via MLP $\Gamma_\theta: (x, d) \to (c, \sigma)$ [S1].
    *   $x \in \mathbb{R}^3$: 3D position.
    *   $d$: View direction.
    *   $c \in \mathbb{R}^3$: RGB color.
    *   $\sigma \in \mathbb{R}$: Volume density.
    *   $\theta$: Learnable network parameters [S1].
*   **Semantic Branch:** An additional MLP branch outputs a semantic vector $f_k \in \mathbb{R}^D$ for each sampled point $k$ [S1].
    *   $D$: Feature dimension. Value is 512 [S1].
*   **Textual Features:** $t_c \in \mathbb{R}^{M \times D}$, generated by the CLIP text encoder for $M$ classes [S1].
*   **Relevancy Map:** $S \in \mathbb{R}^{1 \times H \times W}$, representing the segmentation logits or class probabilities for an image [S1].
*   **Region Proposals:** $R_i = \{R^j_i\}_{j=1}^n$, a collection of $n$ binary mask proposals from SAM for image $I_i$ [S1].

### Numbered Steps

1.  **Offline RSR Pre-computation:**
    For each training image $I_i$ and text description $T$:
    1.  Compute CLIP image feature $F_i = E_i(I_i)$ [S1].
    2.  Compute CLIP text embedding $t_c = E_t(T)$ [S1].
    3.  Compute initial noisy relevancy map $S_i = \text{argmax}(\cos\langle t_c, F_i \rangle)$ [S1].
    4.  Generate region proposals $R_i = E_{sam}(I_i)$ using SAM's automatic mask generator (querying uniformly sampled points, filtering low confidence, and deduplicating via non-maximal suppression) [S1].
    5.  Initialize refined map $\tilde{S}_i = \text{zeros}(1, H, W)$ [S1].
    6.  For each region proposal $R^k_i$ in $R_i$:
        a.  Compute masked initial map $S^k_i = R^k_i * S_i$ (element-wise multiplication) [S1].
        b.  Compute masked refined map $\tilde{S}^k_i = R^k_i * \tilde{S}_i$ [S1].
        c.  Rank semantic classes in $S^k_i$ in descending order based on pixel quantity. Select the top class $S^{k}_{i_l}$ [S1].
        d.  Update refined map: $\tilde{S}^k_i = S^{k}_{i_l}$ (assign the top class label to the region) [S1].
    7.  The final refined relevancy map is $\tilde{S}_i = \Psi(S_i)$, where $\Psi$ is the RSR process [S1].
    *   *Note:* This process is performed offline and does not introduce extra training time [S1].

2.  **Ray Sampling and Rendering:**
    1.  Randomly sample rays from all training images in batches [S1].
    2.  For a ray $r(t) = o + td$, sample $K$ points along the ray [S1].
    3.  Query the NeRF $\Gamma_\theta$ to get $(c_k, \sigma_k)$ for each point $k$ [S1].
    4.  Query the semantic MLP to get $f_k$ for each point $k$ [S1].
    5.  Compute opacity $\alpha_k = 1 - \exp(-\delta_k \sigma_k)$, where $\delta_k = t_{k+1} - t_k$ [S1].
    6.  Compute transmittance $T_k = \prod_{j=0}^{k-1} (1 - \alpha_j)$ [S1].
    7.  Render RGB color: $\hat{C}(r) = \sum_{k=1}^K T_k \alpha_k c_k$ [S1].
    8.  Render semantic feature: $\hat{F}(r) = \sum_{k=1}^K T_k \alpha_k f_k$ [S1].
    9.  Compute rendered segmentation logits: $\hat{S}(r) = \cos\langle t_c, \hat{F}(r) \rangle$ [S1].

3.  **Cross-view Self-enhancement (CSE) Setup:**
    1.  After training OV-NeRF for several epochs, leverage rendered pseudo outputs from OV-NeRF [S1].
    2.  These outputs encompass both training views and unseen novel views [S1].
    3.  Use these 3D consistent semantics as supervision targets to replace inconsistent 2D CLIP semantics for subsequent training steps [S1].

4.  **Optimization:**
    1.  Compute supervision losses (detailed below) [S1].
    2.  Update parameters $\theta$ and $\phi$ using gradient descent [S1].

### Formulas

**Volume Rendering:**
$$ \hat{C}(r) = \sum_{k} T_k \alpha_k c_k $$
$$ T_k = \prod_{j=0}^{k-1} (1 - \alpha_j) $$
$$ \alpha_k = 1 - \exp(-\delta_k \sigma_k) $$
$$ \delta_k = t_{k+1} - t_k $$
Where $c_k$ is color, $\sigma_k$ is density, and $t_k$ is depth [S1].

**Semantic Rendering:**
$$ \hat{F}(r) = \sum_{k} T_k \alpha_k f_k $$
$$ \hat{S}(r) = \cos\langle t_c, \hat{F}(r) \rangle $$
Where $f_k$ is the semantic vector and $t_c$ is the text feature [S1].

**Loss Functions:**
1.  **Photometric RGB Loss:**
    $$ L_{color} = \sum_r \|\hat{C}(r) - C(r)\|_2^2 $$
    Where $C(r)$ is ground truth RGB color [S1].

2.  **Relevancy Feature Loss:**
    $$ L_{feat} = \sum_r -\cos\langle \hat{F}(r), S(r)F(r) \rangle $$
    Where $F(r)$ is pre-computed multi-scale CLIP relevancy feature and $S(r)$ is a selection vector for suitable scale selection [S1].

3.  **Relevancy Map Loss (Standard):**
    $$ L_{map} = \sum_r L_{ce}(\hat{S}(r), S(r)) $$
    Where $S(r)$ is the pre-computed relevancy map from CLIP [S1].

4.  **DINO Feature Loss:**
    $$ L_{dino} = \sum_r L_{fda}(\hat{D}(r), D(r)) $$
    Where $D(r)$ is pre-computed DINO feature and $L_{fda}$ is the FDA loss [S1].

5.  **Region Semantic Ranking Regularization (RSR) Loss:**
    $$ L_{RSR} = \sum_r L_{ce}(\hat{S}(r), \tilde{S}(r)) $$
    Where $\tilde{S}(r)$ is the refined relevancy map produced by RSR [S1].

6.  **Total Supervision Loss:**
    $$ L = L_{color} + L_{feat} + L_{map} + L_{dino} $$
    *Note:* During training with RSR, $L_{map}$ is replaced by $L_{RSR}$ [S1]. Thus, the effective loss is:
    $$ L = L_{color} + L_{feat} + L_{RSR} + L_{dino} $$

```python
def compute_rsr_loss(image, text, clip_img_enc, clip_txt_enc, sam_model, nerf_model, semantic_mlp):
    """
    Computes the RSR loss for a single image batch.
    Note: RSR pre-computation (Algorithm 1) is done offline.
    This function assumes pre-computed refined maps S_tilde are available.
    """
    # 1. Render from NeRF
    rays = sample_rays_from_image(image)
    positions, directions = rays_to_params(rays)
    
    # Query NeRF for color and density
    colors, densities = nerf_model(positions, directions)
    
    # Query Semantic MLP for features
    semantic_features = semantic_mlp(positions, directions)
    
    # Volume Rendering
    alphas = 1.0 - torch.exp(-densities * ray_distances)
    transmittances = compute_transmittance(alphas)

def algorithm_1_rsr_precompute(image, text, clip_img_enc, clip_txt_enc, sam_model):
    """
    Offline pre-computation of refined relevancy map using RSR.
    """
    H, W = image.shape[1], image.shape[2]
    
    # 1. Get CLIP features
    F_i = clip_img_enc(image)
    t_c = clip_txt_enc(text)
    
    # 2. Initial noisy relevancy map
    # cos_sim returns shape (M, H, W) for M classes
    cos_sim_map = cosine_similarity(t_c, F_i) 
    S_i = argmax(cos_sim_map, dim=0) # Shape (H, W), class indices
    
    # 3. Get SAM region proposals
    # R_i is a list of binary masks {R^j_i}
    R_i = sam_model.generate_masks(image)
    
    # 4. Initialize refined map
    S_tilde = torch.zeros(1, H, W)
    
    # 5. Rank and regularize each region
    for k in range(len(R_i)):
        R_k = R_i[k] # Binary mask
        
        # Mask the initial map
        S_k = R_k * S_i
        
        # Mask the refined map accumulator
        S_tilde_k = R_k * S_tilde
        
        # Rank classes in S_k by pixel count
        # Count pixels for each class in S_k
        class_counts = count_pixels_in_masked_map(S_k, R_k)
        
        # Get top class index
        top_class_idx = argmax(class_counts)
        
        # Assign top class to this region in refined map
        # Create a mask for this class in the region
        class_mask = (S_k == top_class_idx).float()
        S_tilde_k = class_mask * top_class_idx
        
        # Update accumulator (Note: regions might overlap or be disjoint depending on SAM)
        # The source implies direct assignment: S_tilde_k = S^k_{i_l}
        # We accumulate by adding the masked class label
        S_tilde += S_tilde_k
        
    return S_tilde
```

### Parameters
*   **Feature Dimension $D$:** 512 [S1].
*   **RSR Process $\Psi$:** Performed offline [S1].
*   **CSE Trigger:** After several epochs of training [S1].

### Edge Cases and Pitfalls
*   **Noisy CLIP Semantics:** Direct use of CLIP relevancy maps leads to imprecise results due to coarse boundaries and view inconsistency [S1]. RSR is required to mitigate this.
*   **View Inconsistency:** 2D semantics from CLIP are view-inconsistent. CSE is required to enforce 3D consistency [S1].
*   **SAM Proposals:** SAM generates masks via uniform point sampling and non-maximal suppression. Low confidence masks are filtered [S1].

## Operating characteristics
*   **Performance:** OV-NeRF achieves a 20.31% improvement in mIoU on the Replica dataset and an 18.42% improvement on the ScanNet dataset compared to state-of-the-art methods [S1].
*   **Complexity:** The RSR process is performed offline, so it does not increase training time [S1].
*   **Strengths:** Superior segmentation results compared to methods like LERF and 3DOVS; robust across various CLIP configurations [S1].
*   **Limitations:** Relies on pre-trained foundation models (CLIP, SAM, DINO) which may have inherent biases or limitations in zero-shot generalization [S1].

## Background
OV-NeRF was proposed to address the difficulties methods extracting semantics directly from CLIP encounter due to noisy and view-inconsistent semantics [S1]. It builds on prior work such as LERF [29] and Liu et al. [30] which utilize CLIP for 3D semantic comprehension with NeRF [S1]. The method leverages the potential of pre-trained vision and language foundation models, specifically CLIP and SAM [S1].
