# Sparse Radiance Field (SRF) Representation


## Overview
A Sparse Radiance Field (SRF) is a voxel-based scene representation that stores density and view-dependent radiance directly in a sparse 3D grid, serving as a discrete, efficient alternative to the continuous Multi-Layer Perceptron (MLP) used in standard NeRFs [S1]. It sets itself apart from dense voxel methods by storing features only for occupied regions in COO format, and from MLP-based methods by enabling direct mesh extraction via Marching Cubes and faster optimization through sparse data structures [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of posed images of a scene or object.
*   **Output:** A Sparse Radiance Field $X_{non-empty}$, which is a set of tuples containing voxel coordinates and their associated density and radiance features.

**Data Structures:**
The SRF is defined as a voxel grid of dimension $1+d$, where $d$ is the dimension of the radiance colors and 1 is for density [S1].
*   **Grid Size:** $H \times H \times H$, where $H$ is the resolution in each dimension [S1].
*   **Format:** Compressed Sparse Order (COO) format [S1].
*   **Tuple Structure:** Each element in the sparse set is a tuple $(c_m, f_m)$ [S1]:
    *   $c_m = (i, j, k)$: Positive integer coordinates of the voxel.
    *   $f_m \in \mathbb{R}^{d+1}$: Features consisting of density $\alpha_{i,j,k}$ and radiance colors $\rho_{i,j,k}$ [S1].
*   **Ordering:** The ordering of the $M$ tuples is arbitrary [S1].

**Formulas:**
The SRF is represented as a set of $M$ non-empty tuples [S1]:
$$
X_{non-empty} = \{(c_m, f_m)\}_{m=1}^M
$$
Where:
*   $M$ is the number of non-empty voxels.
*   $c_m \in \mathbb{Z}^+$ are the coordinates.
*   $f_m$ contains the density and radiance.

**Parameters:**
*   **Resolution ($H$):** The grid size in each dimension. Typical values used in SPARF are $H \in \{32, 128, 512\}$ [S1].
*   **Radiance Dimension ($d$):**
    *   For view-dependent SRF using 4 spherical harmonics factors of RGB channels: $d = 3 \times 4 = 12$ [S1].
    *   For fixed RGB colors: $d = 3 \times 1 = 3$ [S1].
    *   Note: Using 4 SH components reduces optimization space by 40% and time by 10% compared to 9 components, while maintaining PSNR [S1]. Using RGB instead of SH reduces PSNR by ~1 dB, space by 80%, and time by 20% [S1].

**Steps for Representation:**
1.  Initialize a dense grid of size $H \times H \times H$ with dimension $1+d$.
2.  Optimize the grid values (density and radiance) using posed images, typically using an adaptation of Plenoxels [S1].
3.  Prune the grid to keep only non-empty voxels, converting the structure to COO format [S1].
4.  Store the resulting set of $M$ tuples $(c_m, f_m)$ [S1].

**Edge Cases and Pitfalls:**
*   **Low-Density Voxels:** Non-empty voxels may have low densities that do not affect volume rendering but contain random colors that can confuse the network [S1].
*   **Vanishing Gradients:** High sparsity (~99%) and misalignment between input and output SRF coordinates (caused by sparse convolutional strides and pruning) can lead to vanishing gradients [S1].
*   **Precision:** Small errors in predicting densities or radiance colors can result in large distortions in rendered images [S1].

## Operating characteristics
*   **Memory:** Memory usage is proportional to the number of non-empty voxels $M$ rather than $H^3$, offering significant savings for sparse scenes [S1].
*   **Speed:** Optimization is faster than dense voxel methods due to sparsity. Using 4 SH components reduces time by 10% compared to 9 components [S1].
*   **Mesh Extraction:** Meshes can be extracted easily with a single pass of Marching Cubes since the data lies on a 3D voxel space [S1].
*   **Limitations:** The irregular volumetric nature may not perfectly reflect the underlying 3D shape, and learning is sensitive to sparsity-induced gradient issues [S1].

## Background
The Sparse Radiance Field was introduced in the context of the SPARF (Large-Scale Learning of 3D Sparse Radiance Fields from Few Input Images) project [S1]. It builds on the concept of Plenoxels, which used spherical harmonics for view-dependent radiance in voxel grids [S1]. The SPARF dataset collected one million SRFs across multiple resolutions (32, 128, 512) from 40,000 shapes to facilitate large-scale learning [S1].
