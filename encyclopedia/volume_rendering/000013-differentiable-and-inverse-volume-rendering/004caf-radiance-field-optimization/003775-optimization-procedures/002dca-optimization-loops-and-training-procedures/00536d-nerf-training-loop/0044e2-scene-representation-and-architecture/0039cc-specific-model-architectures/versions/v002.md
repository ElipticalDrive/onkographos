# Specific Model Architectures

Also called: NeRF Architectures, Radiance Field Network Designs

## Overview
Specific Model Architectures refers to the family of neural network designs used within the NeRF Training Loop to map 3D coordinates and viewing directions to radiance and density. While the standard NeRF uses a simple Multi-Layer Perceptron (MLP), this family encompasses methods that modify the network topology, input encoding, or internal structure to address specific challenges such as real-time rendering, sparse views, geometric ambiguity, or high-resolution synthesis. These architectures set themselves apart from sibling methods like [Training Ray Marching and Integration](2199-training-ray-marching-and-integration.md) by focusing on the *representation* of the scene rather than the *sampling* strategy, and from [Training Configuration](2332-training-configuration.md) by defining the learnable parameters' structure.

## Shared principles
The core mechanism of all architectures in this family is the implicit representation of a 3D scene as a continuous function $f_\Theta: (\mathbf{x}, \mathbf{d}) \rightarrow (\sigma, \mathbf{c})$, where $\mathbf{x} \in \mathbb{R}^3$ is the spatial coordinate, $\mathbf{d} \in \mathbb{S}^2$ is the viewing direction, $\sigma$ is the volume density, and $\mathbf{c}$ is the emitted color. The network $\Theta$ is optimized via gradient descent to minimize the difference between rendered images and ground truth observations.

Key shared components include:
1.  **Positional Encoding:** Most architectures (except R2L) utilize positional encoding $\gamma(\mathbf{x})$ to map low-frequency inputs to high-frequency features, enabling the MLP to learn high-frequency details [S4].
2.  **Volume Rendering:** The output of the network is integrated along rays using the standard volume rendering equation:
    $$ C(r) = \sum_{i=1}^{N} T_i \alpha_i c_i $$
    where $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$ is the accumulated transmittance, $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ is the opacity, and $\delta_i$ is the distance between samples [S1, unofficial].
3.  **Optimization:** Parameters are updated using stochastic gradient descent (typically Adam) to minimize photometric loss [S1, unofficial].

## Subtopics

### [AdaNeRF](6195-adanerf.md)
AdaNeRF is an architecture designed for real-time rendering by decoupling the sampling process from the shading process. It splits the standard NeRF into a lightweight **Sampling Network** and a heavier **Shading Network**. The Sampling Network predicts importance weights for a fixed set of sample points along a ray in a single forward pass, allowing the Shading Network to process only the most significant samples. This reduces computational cost compared to standard NeRF, which evaluates all samples. It is chosen when real-time performance is critical and geometric ambiguity can be mitigated by pre-training. See [AdaNeRF](6195-adanerf.md).

### [SfMNeRF](8664-sfmnerf.md)
SfMNeRF is an architecture that integrates Structure-from-Motion (SfM) constraints directly into the NeRF training loop to improve geometric accuracy under sparse input conditions. Unlike standard NeRF, which relies solely on photometric loss, SfMNeRF explicitly constrains the 3D structure using matched feature positions, epipolar geometry, and multi-view photometric consistency. It uses a pyramidal construction strategy to avoid local minima caused by large pixel motions. It is chosen when input views are sparse and accurate geometry is required. See [SfMNeRF](8664-sfmnerf.md).

### [DASNeRF](8668-dasnerf.md)
DASNeRF is an architecture for sparse-view 3D reconstruction that integrates monocular depth priors and a dynamic sampling mechanism. It distinguishes itself by replacing uniform sampling with a three-layer dynamic mechanism and enforcing depth consistency via a Depth Ordering Fidelity Loss and Depth Structural Consistency Regularization derived from the DepthAnythingV2 model. It uses per-layer input fusion with five-dimensional vectors (spatial coordinates and ray information) to enhance feature representation. It is chosen when high-fidelity detail is needed from sparse inputs and external depth priors are available. See [DASNeRF](8668-dasnerf.md).

### [R2L (Neural Light Field)](8670-r2l-neural-light-field.md)
R2L (Radiance-to-Light-field) is a deep neural light field network trained via knowledge distillation from a pre-trained NeRF teacher model. It differs from standard NeRF by employing an unprecedentedly deep architecture (e.g., width 256, depth 88) with extensive internal residual blocks, trading width for depth to capture fine-grained details. Unlike depth-dependent methods, R2L does not rely on ground-truth depth, allowing it to handle reflective surfaces (e.g., water, mirrors) effectively. It takes 5D coordinates $(x, y, \theta, \phi)$ directly as input without positional encoding. It is chosen for efficient novel view synthesis with reduced computational cost and robustness to reflections. See [R2L (Neural Light Field)](8670-r2l-neural-light-field.md).

### AligNeRF
AligNeRF improves training NeRF on high-resolution images by combining MLP with convolutional layers to encode more neighborhood information and reduce parameters [S1, unofficial]. It proposes alignment-aware strategies to correct inaccuracies in alignment caused by moving objects, which often lead to performance degradation [S1, unofficial]. It is chosen when training on high-resolution images with dynamic elements [S1, unofficial].

### SinNeRF
SinNeRF is a method that uses a depth map to constrain unobserved views via Adversarial loss and Perceptual loss [S1, unofficial]. It constructs a semi-supervised learning process by introducing and propagating a universal 3D model [S2].

### NeRF in the Wild
NeRF in the Wild adds an Appearance embedding to express different lighting conditions and a Transient embedding to model changing geometry [S1, unofficial]. It addresses the lack of robustness in standard NeRF when dealing with unconstrained photo collections where lighting and content vary [S1, unofficial].

### StyleNeRF
StyleNeRF is a 3D-aware generative model that merges 3D scene representation with style-based generative models [S2]. It uses NeRF to generate low-resolution feature maps and samples them to high resolution to avoid super-computation volume rendering, applying regularization terms to improve 3D consistency [S2].

### CLIP-NeRF
CLIP-NeRF adds CLIP (a text-image pre-trained multimodal model) to provide greater freedom in shape operations and global deformation [S2]. It uses a disentangled conditional NeRF architecture where a learned deformation network is applied to shape modulation, and appearance codes are embedded into volume rendering to map color output [S2].

### NeRF-RPN
NeRF-RPN uses a multi-scale Object-NeRF architecture where the scene branch encodes geometry and appearance via a voxel representation of 3D neural volume features, and the object branch encodes each independent object [S2]. It allows for 3D bounding box regression directly in NeRF without rendering [S2].

### JacobiNeRF
JacobiNeRF synthesizes a NeRF model based on second-order information (Jacobian matrix) to maximize mutual information between highly correlated entities under random scene perturbations [S2]. The rendering equation is:
$$ \hat{C}(r, z_s, z_c) = \sum_{i=1}^{N_c-1} c_i \alpha_i \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) $$
where $a_i = 1 - \exp(-\sigma_i \delta_i)$ is consistent with discrete volume rendering [S2].

### DE-NeRF
DE-NeRF decomposes lighting, geometry, and appearance to allow relighting of high-frequency environments and appearance editing [S3]. It trains a signed distance field (SDF) function using 2D images to reconstruct a display grid. The scene is decomposed into geometric and appearance features (diffuse reflection, roughness, specular tint). These features, along with the distance $h$ from the sampling point to the grid, are input into four corresponding MLPs to predict diffuse albedo, roughness, and specular tint. Diffuse reflectance is integrated with the environment map to get diffuse color $c_d$. A specular lighting MLP $F_s$ predicts specular lighting $c_l$, which is multiplied with specular hue to get specular color $c_s$. The final color is $c = c_s + c_d$ [S3]. On NeRF Synthetic and Shiny Blender datasets, PSNR is 2 points higher than latest papers [S3].

### General Radiance Field Rendering via MLP
This method uses an MLP to predict RGB values and volumetric density for a 3D point using its aggregated feature vector $\bar{F}_p$ and viewing direction [S4]. Unlike original NeRF which uses point position $xyz$ as input, this method uses $\bar{F}_p$ [S4]. All 3D locations and RGB values are processed by the positional encoding proposed by NeRF [S4]. Optimization uses L2 loss between rendered RGBs and ground truth [S4].

### RefSR-NeRF
RefSR-NeRF is a reference-guided super-resolution neural radiation field framework combining NeRF and RefSR-CNN [S3]. Stage 1 modifies NeRF sampling to adopt patch ray sampling on high-resolution input images to obtain a low-resolution image. RefSR-CNN yields feature maps from detail-dominant and degradation-dominant modules, which are fused to reconstruct a high-resolution image [S3]. On the NeRF-LLFF dataset, PSNR is nearly one point higher than the best paper [S3].

### RelightingNeRF
RelightingNeRF is proposed for handling unstructured photographs and free-viewpoint reconstruction [S3]. It changes the model architecture to output SDF values and latent features. The first MLP takes sampling point position and outputs SDF values and latent features. Normals, shadow cues, and specular cues are obtained from SDF values. The second MLP takes sampling point positions, lighting positions, viewing directions, and latent features to produce the final color [S3].

### DiffusioNeRF
DiffusioNeRF utilizes a denoising diffusion model to learn priors for scene geometry and color [S3]. During NeRF training, random RGBD patches are rendered. The estimated gradients of the log-likelihood are backpropagated to the color and density fields to normalize the geometry and color [S3]. On the LLFF dataset, PSNR indicators in 3, 6, and 9 input views are 1-2 points higher [S3].

### GeoNeRF
GeoNeRF is a model with two parts: a geometric morphology reasoner and a renderer [S2]. The reasoner builds a cascaded cost volume for source view sequences. The renderer infers geometric and appearance representations using a Transformer-based attention mechanism and cascaded cost volumes, then renders fine images using volume rendering [S2].

## Background
The original NeRF architecture was introduced by Mildenhall et al. in 2020 [S4]. Subsequent research has focused on modifying this architecture to address limitations such as slow rendering, poor performance with sparse views, and lack of semantic understanding. AdaNeRF [S1, unofficial], SfMNeRF [S1, unofficial], and DASNeRF [S1, unofficial] focus on sparse view and efficiency. R2L [S1, unofficial] focuses on distillation and depth. NeRF in the Wild [S1, unofficial] and SinNeRF [S1, unofficial] address unconstrained and single-view scenarios. DE-NeRF [S3] and RelightingNeRF [S3] introduce SDFs for relighting. Generative approaches like StyleNeRF [S2] and CLIP-NeRF [S2] integrate GANs and CLIP. The field continues to evolve with architectures like DiffusioNeRF [S3] leveraging diffusion models.
