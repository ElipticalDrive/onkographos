# MegaNeRF

Also called: Mega-NeRF

## Overview
MegaNeRF is a framework for training large-scale 3D scenes that support interactive human-in-the-loop fly-throughs, addressing challenges of modeling thousands of images with varying lighting, large model capacities, and fast rendering [S1, S5]. It decomposes a scene into a set of spatial cells, learning a separate NeRF submodule for each [S1, S3]. Unlike DeRF and KiloNeRF which use spatial partitioning to speed up inference of a pre-trained single network, MegaNeRF uses spatial partitioning to enable data parallelism for scalable training, as obtaining a pre-trained NeRF for large scales is infeasible [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A large set of training images (e.g., aerial drone footage) with known camera poses.
*   **Outputs:** A collection of independent NeRF submodules (MLPs), one for each spatial cell, and a foreground/background decomposition structure.

**Data Structures:**
1.  **Spatial Cells:** The 3D volume is partitioned into non-overlapping cells (blocks) using spatial Voronoi partitioning [S1].
2.  **Submodules:** Each cell $k$ has an associated NeRF MLP $\mathcal{M}_k$ that predicts density $\sigma$ and color $\mathbf{c}$ [S1, S3].
3.  **Foreground/Background Volumes:** The scene is subdivided into a foreground volume enclosing all camera poses and a background volume for the complement [S1]. The foreground is modeled as an ellipsoid (extending NeRF++'s unit sphere) to tightly enclose camera poses and relevant detail [S1, S2].
4.  **Pixel Assignments:** A mapping from each training pixel to the set of spatial cells its corresponding ray intersects [S1].

**Steps:**

1.  **Foreground/Background Decomposition:**
    *   Define a foreground ellipsoid that tightly encloses all camera poses and relevant foreground detail [S1, S2].
    *   Define the background as the complement of the foreground ellipsoid [S1].
    *   Use an inverse sphere parameterization (extended to an ellipsoid) for the background, similar to NeRF++ [S1, S2].

2.  **Spatial Partitioning:**
    *   Partition the foreground volume into $K$ spatial cells using spatial Voronoi partitioning [S1].
    *   Each cell is represented by a separate NeRF submodule $\mathcal{M}_k$ [S1, S3].

3.  **Data Partitioning (Geometric Clustering):**
    *   For each training image, sample points along the camera ray corresponding to each pixel [S1].
    *   Determine which spatial cells these sampled points intersect [S1].
    *   Assign the pixel to the training set of only those intersecting cells [S1].
    *   This reduces the size of each submodule's trainset by approximately 10x [S1].
    *   Train each submodule $\mathcal{M}_k$ only on images with potentially relevant pixels [S2].

4.  **Training:**
    *   Train each submodule $\mathcal{M}_k$ independently and in parallel using its partitioned pixel data [S1, S3].
    *   Incorporate per-image appearance embedding codes (from NeRF-W) into the model to handle varying lighting [S2].
    *   Use camera altitude measurements to constrain ray sampling bounds, terminating rays near ground level to avoid querying underground regions [S1, S2].

5.  **Rendering (Inference):**
    *   For a query ray $\mathbf{r}$, perform standard raycasting and point sampling [S1].
    *   For each sampled point $\mathbf{x}_i$, query the submodule $\mathcal{M}_k$ corresponding to the cell containing $\mathbf{x}_i$ [S1].
    *   Compute the final color using the standard volumetric rendering integral, ensuring global transmittance $T$ is accumulated across all partitions:
        $$
        C(\mathbf{r}) = \sum_{i} T_i \left( 1 - \exp(-\sigma_i \delta_i) \right) \mathbf{c}_i
        $$
        where $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$ [S1, S3].
    *   To ensure near-interactive view generation, exploit temporal coherence by caching occupancy and color values from nearby previous views [S1].
    *   Alternatively, cache a coarse rendering of densities and colors into an octree for rendering [S2].

**Parameters:**
*   **Number of Cells:** Not given in the sources.
*   **Ellipsoid Dimensions:** Determined by the bounding box of camera poses and relevant foreground detail [S1, S2].
*   **Altitude Threshold:** Determined by camera altitude measurements to terminate rays near ground level [S1, S2].

**Edge Cases and Pitfalls:**
*   **Underground Sampling:** Without altitude constraints, rays may query underground regions unnecessarily [S1, S2].
*   **Training Data Imbalance:** If visibility partitioning is not used, submodules may receive irrelevant data, reducing efficiency and accuracy [S1].
*   **Pre-training Infeasibility:** Unlike other methods, MegaNeRF cannot rely on a pre-trained large network because training on all available data is prohibitive at large scales [S1].

## Operating characteristics
*   **Training Speed:** Improves training speed by 3x compared to baseline approaches [S1].
*   **Rendering Speed:** Achieves a 40x speedup over conventional NeRF rendering [S1, S5].
*   **Quality:** Remains within 0.8 dB in PSNR quality compared to conventional NeRF [S1, S5]. Improves PSNR by 12% compared to baseline approaches on existing datasets [S1].
*   **Scalability:** Decouples rendering time from scene size, allowing rendering to scale to arbitrarily large environments [S5].
*   **Memory:** Not given in the sources.
*   **Strengths:** Enables data parallelism for scalable training; supports interactive fly-throughs; handles large-scale urban scenes from aerial drone images.
*   **Limitations:** Requires geometric clustering for data partitioning; relies on accurate camera poses and altitude measurements.

## Background
MegaNeRF was introduced by Tancik et al. in 2022 [S1, S5]. It was motivated by the need for search-and-rescue applications where drones provide an inexpensive means of quickly surveying large areas [S1]. The method builds on NeRF++'s inverse sphere parameterization for foreground/background separation but extends it to an ellipsoid for better fit with aerial viewpoints [S2]. It also incorporates per-image appearance embedding codes from NeRF-W [S2].
