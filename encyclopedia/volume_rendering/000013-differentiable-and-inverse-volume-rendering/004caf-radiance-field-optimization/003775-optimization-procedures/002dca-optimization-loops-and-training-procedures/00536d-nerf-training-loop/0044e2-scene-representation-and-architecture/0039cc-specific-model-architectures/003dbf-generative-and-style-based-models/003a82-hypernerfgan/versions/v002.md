# HyperNeRFGAN

Also called: HyperNeRFGAN

## Overview
HyperNeRFGAN is a generative adversarial network (GAN) architecture that uses a hypernetwork to produce the weights of a simplified NeRF target network, enabling 3D-aware image generation without requiring camera position information during training [S1, unofficial]. It differs from standard NeRF by omitting viewing directions from the input and from other NeRF-GAN hybrids (like GRAF or π-GAN) by using a hypernetwork to generate weights directly rather than conditioning a SIREN-based field [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Generator Input:** A noise vector $\mathbf{z}$ sampled from a standard Gaussian distribution $P_{noise}$ [S1, unofficial].
*   **Generator Output:** The weights $\theta$ of the target NeRF model $F_\theta$ [S1, unofficial].
*   **Target Model Input:** A 3D spatial coordinate $\mathbf{x} = (x, y, z)$ [S1, unofficial].
*   **Target Model Output:** Color $\mathbf{c}$ and volume density $\sigma$ [S1, unofficial].
*   **Discriminator Input:** A 2D rendered image [S1, unofficial].
*   **Discriminator Output:** A scalar probability indicating whether the image is real or generated [S1, unofficial].

**Data Structures:**
The target NeRF $F_\theta$ is a single Multi-Layer Perceptron (MLP). Unlike standard NeRF, it does not use positional encoding for viewing directions. It consists of hidden layers using Factorized Multiplicative Modulation (FMM) layers [S1, unofficial].

**FMM Layer Definition:**
The FMM layer transforms an input $\mathbf{x}_{in}$ to an output $\mathbf{y}$ as follows [S1, unofficial]:
$$ \mathbf{y} = \mathbf{W} \odot (\mathbf{A} \times \mathbf{B}) \cdot \mathbf{x}_{in} + \mathbf{b} = \tilde{\mathbf{W}} \cdot \mathbf{x}_{in} + \mathbf{b} $$
Where:
*   $\mathbf{W}$ and $\mathbf{b}$ are shared weight matrices and biases across all generated 3D representations [S1, unofficial].
*   $\mathbf{A}$ and $\mathbf{B}$ are modulation matrices created by the generator $G$. $\mathbf{A}$ has dimensions $n_{out} \times k$ and $\mathbf{B}$ has dimensions $k \times n_{in}$ [S1, unofficial].
*   $k$ is the rank parameter controlling the expressiveness and memory usage. The source uses $k=10$ [S1, unofficial].
*   $\tilde{\mathbf{W}} = \mathbf{W} \odot (\mathbf{A} \times \mathbf{B})$ is the effective weight matrix [S1, unofficial].

**Training Procedure:**
The model is trained using the StyleGAN2 objective [S1, unofficial].

1.  Sample a noise vector $\mathbf{z} \sim P_{noise}$ [S1, unofficial].
2.  Pass $\mathbf{z}$ through the generator $G$ to obtain the NeRF weights $\theta = G(\mathbf{z})$ [S1, unofficial].
3.  Instantiate the target NeRF model $F_\theta$ using $\theta$ [S1, unofficial].
4.  Sample a 3D point $\mathbf{x}$ and render a 2D image $\hat{\mathbf{I}}$ using $F_\theta$ [S1, unofficial].
5.  Sample a real image $\mathbf{x}_{real}$ from the data distribution $P_{data}$ [S1, unofficial].
6.  Update the discriminator $D$ and generator $G$ by minimizing the minimax game [S1, unofficial]:
    $$ \min_G \max_D V(D, G) $$
    $$ V(D, G) = \mathbb{E}_{\mathbf{x} \sim P_{data}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z} \sim P_{noise}}[\log(1 - D(G(\mathbf{z})))] $$
    [S1, unofficial]

    color: (N, 3)
    density: (N, 1)

**Parameters:**
*   **Hidden Layer Channels:** 128 (reduced from standard 256) [S1, unofficial].
*   **Network Depth:** 4 layers (reduced from standard 8) in some experiments [S1, unofficial].
*   **Rank $k$:** 10 [S1, unofficial].
*   **Input Noise:** Gaussian distribution [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Viewing Directions:** Standard NeRF requires viewing directions. HyperNeRFGAN omits them, assuming the training data lacks view-dependent characteristics like reflections [S1, unofficial]. If view-dependent effects are present, this simplification may reduce quality.
*   **Fine Network:** Standard NeRF uses a "fine" network for multi-scale rendering. HyperNeRFGAN rejects the fine network and uses only the coarse network to reduce training cost [S1, unofficial].
*   **Camera Poses:** The method is designed for datasets where camera positions are unavailable or hard to estimate. It requires only spatial coordinates $\mathbf{x}$, not ray origins or directions [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Reduced compared to standard NeRF-GANs due to the use of a single coarse network and reduced hidden dimensions (128 channels, 4 layers) [S1, unofficial].
*   **Memory Complexity:** Controlled by the rank parameter $k$ in the FMM layers. Higher $k$ increases expressiveness but also memory usage [S1, unofficial]. The source uses $k=10$ [S1, unofficial].
*   **Performance:**
    *   **ShapeNet Car:** FID 29.6 (vs Point2NeRF 82.1) [S1, unofficial].
    *   **CARLA Dataset:** FID 20.5, KID 0.78, IS 4.20 (outperforming HoloGAN, GRAF, and $\pi$-GAN) [S1, unofficial].
    *   **CelebA Dataset:** FID 15.04, KID 0.66, IS 2.63 (comparable to $\pi$-GAN) [S1, unofficial].
    *   **Medical Data (DRR):** Superior performance compared to MedNeRF and UMedNeRF [S1, unofficial].
*   **Strengths:** Does not require camera pose estimation; suitable for datasets with few views or no pose information (e.g., medical images, single-view objects); simpler architecture than SIREN-based GANs [S1, unofficial].
*   **Limitations:** Cannot model view-dependent effects (e.g., specular reflections) because viewing directions are not used as input [S1, unofficial].

## Background
HyperNeRFGAN was introduced in a paper titled "HyperNeRFGAN: Hypernetwork approach to 3D NeRF GAN" [S1, unofficial]. It builds on the hypernetwork paradigm [S1, unofficial] and the StyleGAN2 architecture [S1, unofficial]. It addresses the limitation of NeRF training requiring camera positions, which is challenging in medical data and other domains [S1, unofficial]. It is used for 3D object generation on ShapeNet (car, plane, chair), CARLA, CelebA, and medical Digitally Reconstructed Radiographs (DRR) [S1, unofficial].
