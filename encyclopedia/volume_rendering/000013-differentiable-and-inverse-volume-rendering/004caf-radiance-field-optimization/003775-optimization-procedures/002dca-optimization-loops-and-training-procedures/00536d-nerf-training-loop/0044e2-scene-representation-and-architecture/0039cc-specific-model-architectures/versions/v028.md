# Specific Model Architectures

Also called: NeRF Architectures, Radiance Field Models

## Overview
This family encompasses specific neural network topologies and structural modifications applied to the canonical Neural Radiance Field (NeRF) representation to address limitations in training speed, memory usage, generalization, dynamic scene modeling, and semantic understanding. While the parent [Scene Representation and Architecture](11368-scene-representation-and-architecture.md) defines the generic mapping of 3D position and viewing direction to density and color via coupled MLPs, this article details distinct architectural paradigms—including sparse grids, transformer-based attention, generative priors, and explicit surface representations—that replace or augment the standard MLP backbone. These methods are chosen when the canonical MLP's high computational cost, lack of global context, or inability to handle dynamic/unconstrained scenes becomes a bottleneck.

## Shared principles
The core mechanism remains the parametric function $F_\Theta$ that maps a 3D position $\mathbf{x} \in \mathbb{R}^3$ and a viewing direction $\mathbf{d} \in \mathbb{R}^3$ to a volume density $\sigma \in \mathbb{R}$ and an RGB color $\mathbf{c} \in \mathbb{R}^3$. This function is implemented as one or more neural networks, typically utilizing positional encoding $\gamma(\mathbf{x})$ to map raw coordinates to a higher-dimensional space using sinusoidal functions at increasing frequencies [Parent].

**Rendering Integration:**
During training, rays are sampled at points $\mathbf{x}_i$ along the ray. The networks predict $\sigma_i$ and $\mathbf{c}_i$. The pixel color $C(\mathbf{r})$ is computed via volumetric rendering:
$$
C(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i, \quad \text{where } \alpha_i = 1 - \exp(-\sigma_i \delta_i), \quad T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)
$$
and $\delta_i$ is the distance between samples [Parent].

**Input Representation:**
Raw coordinates are rarely used directly. They are mapped to a higher-dimensional space using positional encoding $\gamma(\mathbf{x})$. For a coordinate $\mathbf{x}$, the encoding includes the original value and sinusoidal functions at increasing frequencies:
$$
\gamma(\mathbf{x}) = (\sin(2^0 \pi \mathbf{x}), \cos(2^0 \pi \mathbf{x}), \dots, \sin(2^{L-1} \pi \mathbf{x}), \cos(2^{L-1} \pi \mathbf{x}))
$$
where $L$ is the number of frequency bands [Parent].

## Subtopics

### AdaNeRF
AdaNeRF is a method that employs fixed sample positions along each ray and incrementally introduces sparsity during training to achieve real-time rendering [S1, unofficial]. It reduces the number of sample points by training a sampling network to predict all weights for points on a line in one go, thereby lowering the rendering cost [S2]. Unlike standard NeRF which samples uniformly or via stratified sampling, AdaNeRF decouples the sampling distribution prediction from the shading, allowing for adaptive sparsity [S1, unofficial].

### SinNeRF
SinNeRF is a method for training Neural Radiance Fields (NeRF) from a single input image by regularizing the optimization process to prevent overfitting to the reference view [S2]. It addresses the ill-posed nature of single-image 3D reconstruction by introducing a discriminator and a perceptual loss based on a pre-trained vision transformer, which constrain the synthesized views of unobserved angles to be realistic [S1, unofficial][S2]. Unlike standard NeRF which optimizes only for photometric consistency on input views, SinNeRF explicitly penalizes artifacts in novel views generated during training [S2].

### [NeRF-RPN](8663-nerf-rpn.md)
NeRF-RPN is a 3D object detection framework that utilizes a multi-scale Object-NeRF architecture to regress 3D axis-aligned bounding boxes (AABB) and classify objects directly from a neural radiance field. It distinguishes itself from standard NeRF variants by enabling 3D localization without rendering intermediate views, serving as a general framework capable of detecting objects even without class labels.

### AligNeRF
AligNeRF is a training strategy and architectural modification for Neural Radiance Fields (NeRF) designed to improve high-frequency detail recovery and mitigate artifacts caused by misalignment from moving objects or camera calibration errors in high-resolution settings [S1, unofficial][S2]. It distinguishes itself from standard NeRF and its siblings by combining a convolution-augmented architecture with a staged, alignment-aware training procedure that utilizes patch-based sampling and optical flow estimation [S1, unofficial][S2].

### MultiPlaneNeRF
MultiPlaneNeRF is a radiance field representation that replaces the trainable volumetric encoding of vanilla NeRF with a non-trainable 2D image-based projection [S1, unofficial]. It solves the problems of long training times and poor generalization to unseen data by projecting 3D points onto a fixed set of 2D training images to create an aggregate feature vector, which is then processed by a small, shallow implicit decoder [S1, unofficial]. Unlike vanilla NeRF, which encodes object-specific shape and color in network weights requiring separate training per object, MultiPlaneNeRF allows a single decoder to generalize across many objects by simply swapping the input 2D image representation [S1, unofficial].

### [Pool proposer architecture](8953-pool-proposer-architecture.md)
The Pool proposer architecture is a trainable neural network component used in NeRF-ID to generate fine-grained sampling positions for volume rendering. It processes coarse features from a preliminary sampling stage to propose new, higher-quality sample locations along a ray. It is distinguished from its sibling [MLPMix Proposer](#mlpmix-proposer) by its use of average pooling and a bottleneck fully connected layer, though it exhibits higher variance and significantly worse performance on specific complex scenes like Blender: Materials and Blender: Mic.

### [Transformer-based Architectures](8998-transformer-based-architectures.md)
This family replaces or augments the canonical multi-layer perceptron (MLP) radiance field with transformer architectures to model long-range spatial dependencies and global context. Unlike sibling MLP-based methods that rely on local positional encoding and hierarchical skip connections, transformer-based approaches compute pairwise attention over input tokens, enabling the recovery of large-scale structures and global consistency that local convolutions or shallow networks may miss. They are primarily chosen for tasks requiring global scene understanding, such as super-resolution, denoising, or generalizable synthesis from sparse views.

### [NeRDi](9112-nerdi.md)
NeRDi is a single-view synthesis method that leverages a pre-trained 2D image diffusion model to provide general image priors, enabling high-quality novel view synthesis from a single input image. Unlike traditional NeRF variants that rely solely on photometric reconstruction losses, NeRDi minimizes the diffusion loss of rendered views under input view constraints, supplemented by semantic and geometric guidance. It is distinguished by its ability to generalize across scenes using a pre-trained diffusion model and its integration of language-based semantic guidance to ensure multi-view consistency.

### [Neural Light Field Representations](9273-neural-light-field-representations.md)
Neural Light Field (NeLF) representations replace the volumetric ray-marching paradigm of Neural Radiance Fields (NeRF) with a direct mapping from camera ray parameters to pixel color, enabling orders-of-magnitude faster inference by eliminating iterative sampling. Unlike sibling architectures that model density and view-dependent color via 5D fields, NeLF distills a pre-trained NeRF teacher into a deep residual student network that predicts RGB values directly from a 4D ray representation, bypassing the need for volume integration.

### [RING-NeRF](9323-ring-nerf.md)
RING-NeRF is a neural field architecture that represents 3D scenes using a continuous, unbounded multi-scale grid hierarchy and a position/scale-invariant decoder latent space. It solves the problem of aliasing artifacts and resolution adaptation when varying observation distances by computing a distance-aware Level of Detail (LOD) for each sample and using a continuous coarse-to-fine optimization strategy. Unlike sibling methods that require explicit LOD supervision or concatenate positional encodings with grid features, RING-NeRF induces intrinsic LOD through its grid structure and summation-based feature aggregation, allowing for dynamic resolution extension without retraining the decoder.

### [Sparse and Efficient Representations](9326-sparse-and-efficient-representations.md)
Sparse and Efficient Representations address the computational and memory bottlenecks of dense Neural Radiance Fields (NeRFs) in large-scale or high-resolution scenes. While the parent [Specific Model Architectures](8585-specific-model-architectures.md) relies on a monolithic MLP to map 3D coordinates to density and color, sparse methods decompose the scene representation into localized substructures—such as spatial partitions, voxel grids, or distributed parameters—to enable parallel processing and reduced memory footprint. This family sets itself apart from dense alternatives by explicitly managing spatial locality or hardware distribution, allowing for the rendering of scenes that would otherwise exceed GPU memory limits or require prohibitive training times.

### [Geometric Priors and Depth Integration](9395-geometric-priors-and-depth-integration.md)
This family of methods enhances the geometric accuracy and structural consistency of Neural Radiance Fields (NeRF) by integrating external geometric constraints or priors into the optimization process. Standard NeRF relies solely on photometric consistency, which often leads to ambiguous geometry, especially under sparse input conditions or in textureless regions. By incorporating priors such as Structure-from-Motion (SfM) features, monocular depth estimates, or explicit geometric regularizers, these methods guide the implicit surface reconstruction to be more faithful to the real-world 3D structure. They differ from sibling methods like [AdaNeRF](6195-adanerf.md) (which adapts sampling) or [SinNeRF](6199-sinnerf.md) (which uses semantic regularization) by focusing specifically on enforcing geometric fidelity through depth ordering, epipolar constraints, or explicit surface representations.

### [Generative and Style-based Models](9572-generative-and-style-based-models.md)
Generative and Style-based Models integrate Neural Radiance Fields (NeRF) with Generative Adversarial Networks (GANs) to synthesize novel 3D-consistent images from a latent noise distribution rather than optimizing for a single static scene. This family solves the problem of 3D-aware image generation where explicit 3D supervision or dense multi-view inputs are unavailable. Unlike standard NeRF training which optimizes per-object parameters directly in RGB space, these models generate 3D representations (either weights or latent features) that allow for the creation of diverse, high-quality 3D scenes from a single noise vector.

### IRON
IRON is a neural inverse rendering pipeline that reconstructs high-quality 3D triangle meshes and spatially varying material textures from photometric images captured with a collocated flashlight and moving camera [S1, unofficial]. It solves the problem of jointly optimizing geometry and appearance by using a hybrid optimization scheme: it first recovers correct object topology using volumetric radiance field rendering, then refines geometry and disentangles materials from lighting using edge-aware physics-based surface rendering [S1, unofficial]. This approach distinguishes IRON from methods that optimize surface rendering directly, which often diverge or get stuck in local minima with incorrect topology [S1, unofficial].

### [pi-GAN](10298-pi-gan.md)
pi-GAN is a generative adversarial network (GAN) that learns an unsupervised, view-consistent 3D representation of objects from unlabeled 2D images by conditioning a periodic implicit radiance field on a latent noise vector. It differs from standard NeRF-based optimization methods by treating the radiance field as a generative prior rather than a deterministic scene reconstruction, allowing for the synthesis of novel, high-quality 3D-aware images without explicit 3D supervision. Unlike GRAF, which concatenates noise codes, pi-GAN uses a StyleGAN-inspired mapping network with Feature-wise Linear Modulation (FiLM) to condition the network, and it employs a progressive growing strategy to stabilize training.

### [Instance-NeRF](10611-instance-nerf.md)
Instance-NeRF is a learning-based 3D instance segmentation pipeline that extends a pre-trained Neural Radiance Field (NeRF) with an additional instance field component. It takes a pre-trained NeRF model and multi-view RGB images as input to detect all objects within the underlying 3D scene, producing a 3D bounding box, a continuous 3D mask, and a class label for each detected object. Unlike Semantic-NeRF, which relies on 2D semantic priors that are generally consistent across views, Instance-NeRF addresses the challenge of multi-view inconsistent 2D instance masks (where the same object may receive different instance IDs in different views) without relying on 3D bounding volume priors. It achieves this by using a 3D proposal-based mask prediction network (NeRF-RCNN) to generate coarse 3D masks, projecting them to 2D to match and refine multi-view consistent 2D segmentation maps, and then supervising the continuous instance field with these refined masks.

### [MIMO-NeRF](10928-mimo-nerf.md)
MIMO-NeRF is a neural rendering method that accelerates inference by replacing the standard Single-Input Single-Output (SISO) Multi-Layer Perceptron (MLP) with a Multi-Input Multi-Output (MIMO) MLP. It solves the computational bottleneck of evaluating the radiance field for every sample point individually by grouping neighboring samples on a ray and processing them in parallel. Unlike [AdaNeRF](6195-adanerf.md) which adapts to view-dependent appearance, or [Sparse and Efficient Representations](9326-sparse-and-efficient-representations.md) which change the data structure, MIMO-NeRF retains the canonical MLP architecture but modifies its input/output dimensions to reduce the number of forward passes (# Run) per pixel. It distinguishes itself from naive parallelization by employing a self-supervised learning framework with 3D consistency losses to resolve the ambiguity in density and color that arises when multiple points are predicted simultaneously.

### [Appearance and Lighting Decomposition](11061-appearance-and-lighting-decomposition.md)
Appearance and Lighting Decomposition refers to a family of neural radiance field methods that explicitly separate scene geometry, material properties, and illumination to enable relighting, appearance editing, and physically plausible specular reflections. Unlike standard NeRF which predicts view-dependent color directly, these methods decompose the rendering equation into distinct components (e.g., diffuse/specular, geometry/appearance) to improve realism and controllability. They set themselves apart from siblings like [AdaNeRF](6195-adanerf.md) (which adapts features) or [SinNeRF](6199-sinnerf.md) (which uses sine activations) by structuring the output space to reflect physical light transport properties rather than just optimizing for pixel color.

### [Quadri-Plane Radiance Fields](11128-quadri-plane-radiance-fields.md)
Quadri-Plane Radiance Fields represent a 3D scene using four multi-channel 2D feature planes coupled with a decoder MLP, designed to enable computationally efficient volumetric super-resolution by leveraging 2D image super-resolution techniques. Unlike standard NeRF which uses a dense 3D grid or a single MLP for all coordinates, this method decomposes the spatial and angular dependencies into explicit 2D planes, allowing for resolution scaling independent of the 3D volume discretization. It sets itself apart from siblings like [HexPlane](11358-hexplane.md) by using exactly four planes (three spatial, one angular) rather than six spatial planes, and from [MultiPlaneNeRF](8875-multiplanenerf.md) by explicitly separating the view-direction dependency into a dedicated plane rather than relying solely on positional encoding or view-dependent MLPs.

### [Neural RGB-D Surface Reconstruction](11352-neural-rgb-d-surface-reconstruction.md)
Neural RGB-D Surface Reconstruction is a method for high-quality 3D reconstruction of room-scale scenes from an RGB-D input sequence by training a multi-layer perceptron (MLP) to represent a hybrid scene consisting of a truncated signed distance field (TSDF) for geometry and a volumetric radiance field for appearance. Unlike density-based NeRF variants which synthesize novel views but produce noisy, semitransparent geometry, this method reformulates neural rendering using signed distance fields to yield clean, metrical 3D meshes. It jointly optimizes the scene representation, camera poses, and per-frame latent codes to align color and depth data.

### DINER
DINER is a method for novel view synthesis from sparse input views that predicts depth and feature maps to guide the reconstruction of a volumetric scene representation [S1, unofficial]. It solves the problem of high relative distance between source cameras, where standard image-based NeRFs fail due to implicit correspondence search limitations and extrapolation artifacts [S1, unofficial]. Unlike siblings that rely on sparse landmarks or implicit correspondence, DINER leverages dense depth maps for geometry guidance and uses positional encoding with padding to handle feature extrapolation beyond source frustums [S1, unofficial].

### [GNeuVox](11357-gneuvox.md)
GNeuVox is a fast-training framework for rendering free-view moving human bodies from monocular video by integrating neural fields with explicit neural voxel grids. It solves the high computational cost of traditional NeRF-based human rendering by using two types of voxels: "general voxels" pretrained across multiple bodies to provide geometric priors, and "individual voxels" optimized per subject for unique details. Unlike implicit MLP representations, this explicit structure significantly accelerates optimization, allowing fine-tuning for a new body in minutes rather than hours.

### [HexPlane](11358-hexplane.md)
HexPlane is an explicit representation for dynamic 3D scenes that decomposes a 4D spacetime grid into six feature planes spanning each pair of coordinate axes (e.g., XY, ZT). It computes features for points in spacetime by projecting the point onto each feature plane, aggregating the six resulting feature vectors, and passing the fused vector to a tiny MLP to predict color. This method solves the memory and data-sparsity challenges of dynamic novel view synthesis by reducing memory complexity from $O(N^3TF)$ to $O(N^2R + NTR + RF)$ while matching the image quality of implicit methods but with over 100× faster training. Unlike implicit NeRF variants or deformation-based methods, HexPlane uses a basis-sharing mechanism to cope with sparse observations without requiring deformation fields.

### STensoRRF
STensoRRF is a differentiable volume rendering method that represents a 3D scene using a single 4D tensor to enable high-quality novel view synthesis and relighting [S1, unofficial]. Unlike standard NeRF architectures that use coupled MLPs for density and color, STensoRRF decouples appearance features from density within a tensor structure, allowing for the direct estimation of BRDF values and normals to simulate lighting changes [S1, unofficial]. It sets itself apart from sibling architectures by replacing the multi-tensor or multi-voxel mesh representations of previous relighting methods with a single decomposed 4D tensor, accelerating convergence by 50% and rendering speed by 1.5x [S1, unofficial].

### GIRAFFE
GIRAFFE represents scenes as compositions of $N$ entities (typically $N-1$ objects plus 1 background), where each entity possesses a separate neural feature field and an affine transformation [S1, unofficial]. This architecture enables explicit control over the pose, shape, and appearance of individual entities within a generated scene [S1, unofficial]. It distinguishes itself from sibling methods like AdaNeRF or SinNeRF by treating scene composition as a generative problem with disentangled latent codes for shape and appearance, rather than optimizing a single static field per scene [S1, unofficial].

### [Ced-NeRF](11364-ced-nerf.md)
Ced-NeRF is a method for rendering dynamic scenes using a hybrid representation that combines a high-resolution voxel grid with a canonical space deformation model. It solves the problem of overfitting artifacts (floaters, noisy geometry) common in dynamic hybrid representations by using a compact auxiliary network to predict scene deformations, enabling rapid convergence without the training difficulty of separated static/dynamic fields. It sets itself apart from siblings like [AdaNeRF](6195-adanerf.md) and [Sparse and Efficient Representations](9326-sparse-and-efficient-representations.md) by avoiding low-resolution grids or sparse voxel structures in favor of high-resolution grids for fast convergence, while eschewing separated models to maintain rendering speed.

### [Dynamic and Deformable Fields](11366-dynamic-and-deformable-fields.md)
Dynamic and Deformable Fields extend the static radiance field representation to handle time-varying scenes. These architectures introduce a temporal dimension $t$ to the input space, mapping $(\mathbf{x}, \mathbf{d}, t)$ to density and color. To ensure temporal coherence and handle deformation, these methods often employ deformation fields that map observed coordinates to a canonical space, or use explicit temporal encodings. This family is chosen when the scene content changes over time, such as in human performance capture or dynamic urban environments, distinguishing it from static scene representations like [MultiPlaneNeRF](8875-multiplanenerf.md) or [HexPlane](11358-hexplane.md) which handle dynamics through different mechanisms (e.g., spacetime planes).

### NeRF in the Wild
Adds an Appearance embedding to express different lighting conditions. Adds a Transient embedding to model changing geometry [S1, unofficial].

### CLIP-NeRF
A method that adds CLIP (a text-image pre-trained multimodal model) to provide greater freedom in shape operations and global deformation, using a disentangled conditional NeRF architecture [S2].
1. Apply a learned deformation network to shape modulation.
2. Embed appearance codes into volume rendering to map color output.
3. Allow control over both shape and appearance [S2].

### JacobiNeRF
The model synthesizes a NeRF model based on second-order information (Jacobian matrix) to maximize mutual information between highly correlated entities under random scene perturbations [S2]. The rendering equation used is:
$$
\hat{C}(r, z_s, z_c) = \sum_{i=1}^{N_c-1} c_i \alpha_i \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)
$$
where $a_i = 1 - \exp(-\sigma_i \delta_i)$ is consistent with discrete volume rendering [S2].

### RefSR-NeRF
Reference-guided super-resolution neural radiation field framework combining NeRF and RefSR-CNN to achieve high-quality new perspective synthesis while balancing memory and speed [S3].
1. Modify NeRF sampling strategy to adopt patch ray sampling on the high-resolution input image to obtain a low-resolution image.
2. RefSR-CNN yields feature maps from the detail-dominant information module and the degradation-dominant information module.
3. Fuse the two feature maps to reconstruct a high-resolution image [S3].
On the NeRF-LLFF data set, PSNR is nearly one point higher than the best paper [S3].

### RelightingNeRF
Proposed for handling unstructured photographs and free-viewpoint reconstruction, changing model architecture to output SDF values and latent features [S3].
1. Input sampling point position into the first MLP, which outputs SDF values and latent features.
2. Obtain normals, shadow cues, and specular cues from the SDF values.
3. Provide sampling point positions, lighting positions, and viewing directions, along with latent features from the first MLP, to the second MLP.
4. Second MLP produces the final color [S3].

### DiffusioNeRF
A method that utilizes a denoising diffusion model to learn priors for scene geometry and color, normalizing the geometry and color of the scene to achieve better quality in reconstructed geometry under sparse input views [S3].
During NeRF training, render random RGBD patches. Backpropagate the estimated gradients of the log-likelihood to the color and density fields to normalize the geometry and color [S3].
On the LLFF dataset, the PSNR indicators in 3, 6, and 9 input views are 1-2 points higher. Among three input views, the PSNR index is nearly 1 point higher than ViP-NeRF [S3].

### MS-NeRF
Addresses rendering distortion and blurring caused by reflection or refraction (e.g., mirrors) where standard NeRF fails multi-view consistency. Represents the scene by a set of characteristic fields in parallel subspaces [S3].
1. Modify NeRF output and volumetric rendering module to output density and features instead of density and color, generating multiple sets of density and features.
2. Volumetric rendering generates multiple feature maps from the multiple sets of density and features.
3. Apply a Decoder MLP in each subspace to decode RGB images.
4. Use a Gate MLP to obtain pixel-level weights for the feature maps.
5. Integrate features from each subspace by summation to obtain the final result [S3].
On synthetic, real, and RFFR data sets, the PSNR index is 2-4 points higher [S3].

### Edit-NeRF
The first method to execute user-controlled deformation models on NeRF, proposing a modular network's conditional radiance field to guide model editing [S2].
1. Train on multiple instances of the same category.
2. Learn underlying part features in an unsupervised manner.
3. Allow user guidance in 2D image shape/texture to propagate to 3D space [S2].
Limited capability in shape operations; it only supports adding or deleting local parts of an object. The editing process is slow due to its iterative optimization nature [S2].

### DT-NeRF
Both the Diffusion and Transformer models are trained jointly within a unified optimization framework, sharing the same loss function, and are not pretrained but optimized simultaneously during training through backpropagation [S4].

### NeRF-A
A NeRF variant using appearance embeddings (NeRF-A) without transient embeddings for handling varying camera conditions [S5].
1. Train the model with the left half side of the images in the training set and test novel view synthesis on the right half side.
2. Interpolate between appearance embeddings assigned to brighter and darker images for controllable rendering [S5].
Quantitative results on classroom image: PSNR 23.52, SSIM 0.907, LPIPS 0.247 [S5].

### MERF
A volumetric scene representation that achieves real-time rendering of large-scale scenes in a browser by combining a sparse feature grid and high-resolution 2D feature planes, with a lossless baking procedure to convert the optimized parameterization into a fast rendering format [S6].
MERF uses a unified radiance field representation with two different underlying parameterizations: one for optimization (NGP hash grid) and one for rendering (baked binary occupancy grid and triplanes) [S6].
1. During optimization, use the NGP hash grid structure to compress the parameterization, allowing for differentiable sparsification and providing an inductive bias that aids convergence.
2. After optimization, query the recovered NGP to explicitly bake out the MERF and create a binary occupancy grid to accelerate rendering [S6].
MERF achieves better image quality for the same amount of compression as SNeRG++, matching the output of a SNeRG++ model that is over 17x larger [S6].
Compared to TensoRF, MERF speeds up query time by removing the need for matrix multiplication and halves memory bandwidth consumption [S6].

## Background
The canonical NeRF architecture, introduced by Mildenhall et al. in 2020 [S1, unofficial], established the baseline of using coupled MLPs with positional encoding. Subsequent research rapidly diversified into specific architectures to address NeRF's limitations: high training/inference latency, poor generalization to unseen scenes, inability to handle dynamic content, and lack of semantic understanding. Early extensions like NeRF in the Wild [S1, unofficial] and Edit-NeRF [S2] focused on robustness and editability. Later works like MERF [S6] and HexPlane [S1, unofficial] targeted real-time rendering and dynamic scenes through sparse grids and explicit planes. More recent approaches integrate generative models (DiffusioNeRF [S3], NeRDi [S2]) and transformers [S3] to leverage pre-trained priors for single-view or sparse-view synthesis.
