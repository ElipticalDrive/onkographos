# Latent-NeRF

Also called: Latent Diffusion NeRF

## Overview
Latent-NeRF is a method for optimizing Neural Radiance Fields (NeRF) by integrating pre-trained latent diffusion models to improve novel view synthesis quality, particularly in scenarios with limited input data or for text-guided generation [S1]. It distinguishes itself from standard NeRF training by operating in a compact latent space rather than RGB space, using score distillation from a pre-trained autoencoder and diffusion model to guide the optimization [S1]. Unlike HyperNeRFGAN, which uses a GAN framework, Latent-NeRF leverages the denoising capabilities of diffusion models to enforce photorealistic priors [S1].

## How it works
**Inputs:**
- A set of input images (or sparse views) for scene reconstruction.
- A pre-trained autoencoder (e.g., from Stable Diffusion) with an encoder $E$ and decoder $D$.
- A pre-trained latent diffusion model (e.g., Stable Diffusion) with a UNet denoiser $\epsilon_\theta$.
- Optional text prompts and shape guidance for conditional generation.

**Outputs:**
- A NeRF representation (MLP parameters) that maps 3D positions and viewing directions to volume density and latent features.

**Data Structures:**
- **NeRF MLP:** Takes 3D position $\mathbf{x} \in \mathbb{R}^3$ and viewing direction $\mathbf{d} \in \mathbb{R}^3$ as input. Outputs volume density $\sigma \in \mathbb{R}$ and a latent feature vector $\mathbf{z} \in \mathbb{R}^4$. The dimension of $\mathbf{z}$ is fixed to 4, corresponding to the latent features used in the diffusion model [S1].
- **Autoencoder:** Encodes images into latent space and decodes latent features back to image space.
- **Diffusion Model:** Takes a noisy latent image and a timestep $t$ as input, predicting the noise component.

**Algorithm Steps:**
1. **NeRF Forward Pass:** For a given camera ray, sample points along the ray. Query the NeRF MLP at each point to obtain density $\sigma$ and latent feature $\mathbf{z}$.
2. **Volume Rendering in Latent Space:** Render the latent feature map $\mathbf{z}_{rendered}$ from the viewpoint using standard volume rendering integration, weighted by the density $\sigma$ [S1].
   $$ \mathbf{z}_{rendered} = \sum_{i=1}^{N} T_i (1 - e^{-\sigma_i \delta_i}) \mathbf{z}_i $$
   where $T_i = e^{-\sum_{j=1}^{i-1} \sigma_j \delta_j}$ is the accumulated transmittance, $\delta_i$ is the distance between samples, and $\mathbf{z}_i$ is the latent feature at sample $i$.
3. **Noise Injection:** Add noise to the rendered latent feature map $\mathbf{z}_{rendered}$ to create a noisy latent image $\mathbf{z}_t$ at a random diffusion timestep $t$ [S1].
   $$ \mathbf{z}_t = \mathbf{z}_{rendered} + \epsilon \sqrt{1 - \alpha_t} $$
   where $\epsilon \sim \mathcal{N}(0, I)$ and $\alpha_t$ is the noise schedule parameter.
4. **Diffusion Denoising:** Pass the noisy latent image $\mathbf{z}_t$, timestep $t$, and conditioning information (text/shape) into the pre-trained diffusion model to predict the noise $\hat{\epsilon}$ [S1].
5. **Score Distillation Loss:** Compute the loss based on the difference between the predicted noise $\hat{\epsilon}$ and the actual noise $\epsilon$, or equivalently, the difference between the predicted clean latent and the rendered latent. This loss is backpropagated to update the NeRF MLP parameters [S1].
   $$ \mathcal{L} = \mathbb{E}_{t, \epsilon} [ \| \hat{\epsilon}(\mathbf{z}_t, t, \text{cond}) - \epsilon \|^2 ] $$
6. **Optional Reconstruction Loss:** If input images are available, decode the rendered latent features $\mathbf{z}_{rendered}$ using the pre-trained autoencoder decoder $D$ to get $\hat{I}$, and compare with ground truth images $I$ using an $L_1$ or $L_2$ loss [S1].

**Parameters:**
- Diffusion timestep $t$: Sampled uniformly or from a distribution during training [S1].
- Learning rate: Not specified in sources [G].

**Edge Cases and Pitfalls:**
- The latent space dimension is fixed to 4, which may limit the expressiveness of the NeRF for complex scenes [S1].
- Precision issues may arise when backpropagating through the diffusion model and autoencoder, which are frozen [G].
- Degenerate input (e.g., no input images) requires strong text/shape guidance to avoid artifacts [S1].

## Subtopics

### [Points2NeRF](9389-points2nerf.md)
Points2NeRF is a method for generating Neural Radiance Field (NeRF) representations directly from 3D point clouds using a hypernetwork-based auto-encoder architecture. It solves the problem of reconstructing high-quality radiance fields from sparse 3D input data by learning a mapping from point clouds to NeRF network weights, rather than optimizing a NeRF for each object individually. Unlike standard NeRF training which optimizes per-object parameters, Points2NeRF trains a single hypernetwork to produce weights for any input point cloud, enabling the generation of various NeRF functions at test time.

## Operating characteristics
- **Time Complexity:** Training time is significantly higher than standard NeRF due to the involvement of the diffusion model and autoencoder forward/backward passes. Each iteration requires rendering, noise addition, diffusion denoising, and decoding.
- **Memory Complexity:** Higher memory usage due to storing the pre-trained diffusion model and autoencoder parameters, in addition to the NeRF MLP.
- **Performance:** Achieves impressive results in novel view synthesis, especially with sparse inputs or text guidance, by leveraging the strong priors of the diffusion model [S1].
- **Strengths:** Improves rendering quality, enables text-guided generation, works with sparse input data.
- **Limitations:** Computationally expensive, requires pre-trained models, limited by the latent space dimension (4 channels).
- **When to use:** When high-quality novel view synthesis is needed with limited input data or for generative tasks guided by text.
- **When not to use:** When computational resources are limited or when real-time inference is required.

## Background
Latent-NeRF was introduced as an extension of NeRF to improve image rendering quality by using pre-trained models [S1]. It applies score distillation to a latent diffusion model and the compact latent space of a pre-trained autoencoder [S1]. It is the first approach that allows coloring of the grid under the guidance of a pre-trained diffusion model [S1]. The method is part of a broader trend of using generative models to enhance NeRF optimization, as seen in related works like NeRDi [S1].
