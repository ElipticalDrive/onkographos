# Fast Per-subject Fine-tuning

Also called: Compensation fine-tuning, Post-training adaptation

## Overview
Fast Per-subject Fine-tuning is a compensation strategy used in generalizable human radiance field models to address artifacts and imperfections that persist for unseen subjects after initial multi-subject training [S1]. While the base model learns common representations across a dataset, sparse input views for a new individual often result in low-frequency textures and motion artifacts [S1]. This method treats the pre-trained generalizable network as an initialization state and performs rapid optimization of specific parameters on the new subject's data [S1]. It distinguishes itself from full retraining by freezing the feature blending network, focusing adaptation only on the deformation field and the radiance field core [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained generalizable neural radiance field model $\Phi$ trained on a dataset of multiple subjects/performers. The model consists of a deformation field MLP ($MLP_d$), a feature blending network ($MLP_B$), and a generalizable radiance field component. A new unseen subject with sparse multi-view images is provided.
*   **Output:** An adapted radiance field model optimized for the specific geometry and appearance of the unseen subject.

**Data Structures:**
The model parameters are partitioned into:
1.  $\theta_d$: Parameters of the deformation field $MLP_d$.
2.  $\theta_\Phi$: Parameters of the generalizable neural radiance field $\Phi$.
3.  $\theta_B$: Parameters of the feature blending network $MLP_B$.

**Steps:**
1.  **Initialization:** Load the pre-trained weights $\theta_d, \theta_\Phi, \theta_B$ obtained from training on the general dataset [S1].
2.  **Freeze Blending Network:** Set $\theta_B$ as non-trainable (freeze gradients) [S1]. This preserves the learned appearance blending logic and reduces the optimization search space [S1].
3.  **Optimization Loop:** For the unseen subject:
    *   Initialize $\theta_d$ and $\theta_\Phi$ with the pre-trained values [S1].
    *   Render novel views for the subject using the current $\theta_d$ and $\theta_\Phi$.
    *   Compute the rendering loss (e.g., L1 or L2 loss between rendered and ground truth images) [S1].
    *   Perform backpropagation to update only $\theta_d$ and $\theta_\Phi$ [S1].
    *   Repeat until convergence or a fixed number of iterations [S1].

**Pseudocode:**
```python
def fast_per_subject_fine_tuning(pretrained_model, unseen_subject_data):
    # pretrained_model contains MLP_d, Phi, MLP_B
    # unseen_subject_data contains sparse multi-view images
    
    # 1. Extract parameters
    theta_d = pretrained_model.MLP_d.parameters()
    theta_phi = pretrained_model.Phi.parameters()
    theta_b = pretrained_model.MLP_B.parameters()
    
    # 2. Freeze the feature blending network
    for param in theta_b:
        param.requires_grad = False
        
    # 3. Optimize deformation and radiance field parameters
    optimizer = torch.optim.Adam([theta_d, theta_phi], lr=learning_rate)
    
    for iteration in range(max_iterations):
        optimizer.zero_grad()
        
        # Render images for the unseen subject using current theta_d and theta_phi
        rendered_images = render(unseen_subject_data, theta_d, theta_phi, pretrained_model.MLP_B)
        
        # Compute loss against ground truth views
        loss = compute_loss(rendered_images, unseen_subject_data.gt_images)
        
        # Backpropagate and update only theta_d and theta_phi
        loss.backward()
        optimizer.step()
        
    return pretrained_model
```

**Edge Cases:**
*   **Overfitting:** Since the data is sparse, excessive fine-tuning may overfit to noise or specific viewpoints [S1].
*   **Degenerate Input:** If the unseen subject has extreme poses not seen during pre-training, the deformation field may fail to generalize even after fine-tuning [S1].

## Subtopics

## Operating characteristics
*   **Time Complexity:** Significantly faster than training from scratch because the search space is reduced by freezing $MLP_B$ and using pre-trained weights as initialization [S1].
*   **Memory Complexity:** Requires storing gradients for only $\theta_d$ and $\theta_\Phi$, reducing memory footprint during the fine-tuning phase [S1].
*   **Strengths:** Effectively removes artifacts and recovers high-frequency details for unseen persons [S1]. Efficient adaptation to new identities [S1].
*   **Limitations:** Relies on the quality of the initial generalizable training; if the pre-trained model fails to capture the subject's basic structure, fine-tuning may not suffice [S1]. Performance depends on the sparsity of input views [S1].

## Background
This method was introduced in the context of HumanNeRF, a framework for efficiently generating human radiance fields from sparse inputs [S1]. It addresses the limitation that generalizable models, while efficient, may produce artifacts for specific unseen individuals due to data diversity and sparsity [S1]. The approach is inspired by image-based rendering techniques that use adjacent views to refine textures [S1].
