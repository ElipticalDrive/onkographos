# DINER

Also called: DINER (Depth-aware Image-based NEural Radiance fields), Depth-aware Image-based NEural Radiance fields

## Overview
DINER is a method for novel view synthesis that reconstructs a volumetric scene representation (NeRF) from a sparse set of RGB input views by leveraging predicted dense depth maps to guide geometry estimation and sampling efficiency [S1]. Unlike standard image-based NeRFs that rely on implicit correspondence or sparse landmarks, DINER uses depth-aware conditioning and depth-guided sampling to handle high relative distances between source cameras, allowing for complete scene capture with fewer input views [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ source RGB images $\{I^{(i)}\}_{i=1}^N$ with known camera intrinsics $K^{(i)}$ and extrinsics $P^{(i)}$ (where $P^{(i)}$ maps world coordinates to camera coordinates). Typical value for $N$ is 4 [S1].
*   **Outputs:** A radiance field function $f$ that maps a 3D position $x$ and view direction $d$ to color $c$ and opacity $\sigma$, enabling the rendering of novel views [S1].

**Data Structures:**
*   **Feature Maps:** For each source view $i$, a 2D feature map $W^{(i)}$ of size $H \times W \times C$ (where $C=512$) is extracted [S1].
*   **Depth Maps:** Predicted depth maps $D^{(i)}$ for each source view [S1].
*   **Positional Encoding:** A 13-dimensional vector derived from 6 frequency channels with a base frequency of 1 meter, concatenated with the 512-dimensional feature vector [S1].

**Algorithm Steps:**

1.  **Depth Estimation:** Estimate depth maps $D^{(i)}$ for each source view $i$ using a state-of-the-art depth estimation network [S1].
2.  **Source Feature Extrapolation:**
    *   Pad each input image $I^{(i)}$ by 64 pixels by repeating border values [S1].
    *   Compute positional encoding for normalized pixel coordinates $uv \in [-1, +1]$ using 4 exponentially increasing frequencies starting with 0.5, resulting in an 18-channel map. Set this encoding to 0 for unpadded regions [S1].
    *   Concatenate the padded image and the positional encoding map [S1].
    *   Extract per-view feature maps $W^{(i)}$ using a 2D-convolutional encoding network $E$:
        $$ W^{(i)} = E(I^{(i)}) $$
        [S1]
3.  **Ray Sampling:** For a target ray $r(t) = o + t \cdot d$, sample 3D points $t_j$ along the ray. DINER uses depth-guided sampling: generate 1000 candidate samples per ray, shortlist 25 samples, and add 15 samples during Gaussian boosting, summing to 40 total samples contributing to the final ray color [S1].
4.  **Coordinate Transformation:** For each sample point $x$ and view direction $d$, transform them into the coordinate system of each source view $i$:
    $$ x^{(i)} = P^{(i)} \circ x $$
    $$ d^{(i)} = R^{(i)} \circ d $$
    [S1]
5.  **Feature Interpolation:** Project $x^{(i)}$ onto the feature map $W^{(i)}$ to interpolate the feature vector $\omega^{(i)}$:
    $$ \omega^{(i)} = W^{(i)}[K^{(i)} \circ x^{(i)}] $$
    [S1]
6.  **Depth Deviation Calculation:** Compute the deviation $\Delta z$ between the sample location's z-coordinate in camera space and the estimated depth $D^{(i)}$ at the projected pixel location [S1].
7.  **Intermediate Feature Regression:** Process $x^{(i)}$, $d^{(i)}$, $\omega^{(i)}$, and $\Delta z$ through the first MLP part $f_1$ to generate intermediate feature vectors $V^{(i)}$ for each view independently:
    $$ V^{(i)} = f_1(x^{(i)}, d^{(i)}, \omega^{(i)}, \Delta z) $$
    [S1]
    *Note:* The input to $f_1$ includes the positionally encoded depth deviation. The positional encoding uses 6 frequency channels with a base frequency of 1 meter, resulting in a 13-dimensional vector concatenated with the 512-dimensional feature vector $\omega^{(i)}$ [S1].
8.  **Feature Aggregation:** Average pool the intermediate feature vectors across all $N$ views:
    $$ \bar{V} = \text{mean}_i V^{(i)} $$
    [S1]
9.  **Color and Opacity Regression:** Process the averaged features through the second MLP part $f_2$ to regress final color $c$ and opacity $\sigma$:
    $$ (c, \sigma) = f_2(\bar{V}) $$
    [S1]
10. **Volumetric Rendering:** Render the final color $\hat{C}(r)$ using standard volumetric rendering integration:
    $$ \hat{C}(r) = \sum_{j} T_j (1 - \exp(-\sigma_j \delta_j)) c_j $$
    where $T_j = \exp\left(-\sum_{k=1}^{j-1} \sigma_k \delta_k\right)$ and $\delta_j = t_{j+1} - t_j$ [S1].

**Parameters:**
*   $N$: Number of source images. Typical value: 4 [S1].
*   $f_1, f_2$: Parts of the NeRF MLP. $f_1$ takes $(x^{(i)}, d^{(i)}, \omega^{(i)}, \Delta z)$ as input. $f_2$ takes $\text{mean}_i V^{(i)}$ as input [S1].
*   Loss weights: $w_l = 1.0$, $w_{vgg} = 0.1$, $w_{ab} = 5.0$ (or $1.0$ for DTU dataset) [S1].
*   Patch size for loss evaluation: $64 \times 64$ pixels, except for Lab which downsamples patches to $8 \times 8$ pixels through average pooling before evaluating L1 distance [S1].

**Edge Cases and Pitfalls:**
*   **Extrapolation:** Extrapolation beyond source image frustums causes artifacts in standard image-based NeRFs. DINER handles this by padding input images by 64 pixels and applying positional encoding to normalized pixel uv coordinates, setting the encoding to 0 for unpadded regions [S1].
*   **Implicit Correspondence:** Implicit correspondence search fails when the distance between source cameras is large. DINER handles this by using dense depth maps instead of sparse landmarks [S1].
*   **Depth Accuracy:** Synthesis quality improves with depth accuracy up to a standard deviation of 1mm noise; higher accuracy yields no further improvement [S1].
*   **Normal Maps:** Normal maps for point cloud backface culling are obtained by calculating central difference on depth maps via convolutional kernels with size 3, filtering out foreground-background edges [S1].

## Operating characteristics
*   **Time Complexity:** Rendering speed is slow. Synthesis of a $256 \times 256$ pixel image takes two seconds [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** On the DTU dataset, DINER achieves higher synthesis quality with fewer distortions and blurring artifacts compared to state-of-the-art methods [S1].
*   **Scaling:** DINER can process input views with greater disparity, allowing for larger viewpoint changes during novel view synthesis [S1].
*   **Strengths:** Uses dense depth maps which are not restricted to specific object categories and provide denser guidance than sparse landmarks [S1]. Depth-guided sampling focuses samples closer to the ground truth surface, reducing median Chamfer distance by 33% and maximum Chamfer distance by a factor of 4 compared to coarse-to-fine sampling with the same number of points [S1].
*   **Limitations:** Rendering speed is slow, not real-time capable [S1]. Relies on the accuracy of the depth prediction network [S1].

## Background
DINER (Depth-aware Image-based NEural Radiance fields) was presented by Malte Prinzler, Otmar Hilliges, and Justus Thies from the Max Planck Institute for Intelligent Systems and ETH Zürich [S1]. It was published in CVPR 2023 [S1]. The method builds on the pixelNeRF pipeline and addresses the limitations of previous methods that rely on sparse landmarks or implicit correspondence, which fail when the distance between source cameras is large [S1]. It is used for novel view synthesis of human heads and general objects [S1].
