# Anisotropic Neural Representation Learning

Also called: Anisotropic NeRF, SH-guided anisotropic features

## Overview
Anisotropic Neural Representation Learning is a method that models volumetric density and latent features as view-dependent functions using spherical harmonics (SH) to eliminate directional ambiguity in neural rendering, replacing the isotropic point-sampled features of standard NeRF [S1]. It differs from anti-aliasing approaches like Mip-NeRF, which sample cones to approximate pre-filtered representations, by modifying the MLP to predict view-dependent SH coefficients directly, thereby avoiding the need for shape-based sampling parameterization [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Camera ray origin $\mathbf{o}$, viewing direction $\mathbf{d}$, and near/far bounds $t_n, t_f$.
*   **Output:** Rendered pixel color $\hat{C}(\mathbf{r})$.

**Data Structures:**
The core data structure is a Multilayer Perceptron (MLP) that replaces the standard density/feature predictor.
*   **SH Coefficients:** The MLP outputs coefficients for spherical harmonic basis functions. Let $K$ be the number of SH bands. The output vector size depends on the degree $L$ of the SH expansion (e.g., for $L=3$, there are 16 coefficients per feature channel).
*   **Spherical Harmonics Basis:** Pre-computed basis functions $Y_{l,m}(\mathbf{d})$ evaluated at the viewing direction $\mathbf{d}$.

**Numbered Steps:**
1.  **Ray Sampling:** Cast a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ through the scene. Sample $N$ points $t_i$ within the near ($t_n$) and far ($t_f$) bounds, defining intervals $I_i = [t_i, t_{i+1}]$ [S1].
2.  **Direction Query:** For each sample point $t_i$, determine the viewing direction $\mathbf{d}$ from the camera origin to the sample point.
3.  **SH Coefficient Prediction:** Pass the spatial coordinates $\mathbf{x}_i = \mathbf{r}(t_i)$ and the viewing direction $\mathbf{d}$ into the anisotropic MLP. The MLP predicts the SH coefficients $\mathbf{w}_\sigma$ for density and $\mathbf{w}_c$ for color [S1].
4.  **Anisotropic Feature Evaluation:** Evaluate the SH basis functions at $\mathbf{d}$ to obtain view-dependent values. Compute the anisotropic density $\sigma_i$ and color $\mathbf{c}_i$ by projecting the coefficients onto the basis:
    $$ \sigma_i = \sum_{l,m} w_{\sigma, l,m} Y_{l,m}(\mathbf{d}) $$
    $$ \mathbf{c}_i = \sum_{l,m} w_{c, l,m} Y_{l,m}(\mathbf{d}) $$
    [S1]
5.  **Volume Rendering:** Compute the accumulated color using the discrete Riemann sum approximation [S1]:
    $$ \hat{C}(\mathbf{r}) = \sum_{i=0}^{N} \mathbf{c}_i T_i (1 - \exp(-\sigma_i (t_{i+1} - t_i))) $$
    where $T_i = \exp\left(-\sum_{j=0}^{i-1} \sigma_j (t_{j+1} - t_j)\right)$ is the accumulated transmittance [S1].
6.  **Regularization (Training Only):** Decompose the predicted anisotropic elements from the density and latent features. Apply a point-wise operation to penalize the energy of the anisotropic components in the geometry representation to prevent over-fitting and shape-radiance ambiguity [S1].

**Formulas:**
*   **Volume Rendering Integral:**
    $$ \hat{C}(\mathbf{r})=\int _{0}^{\infty } T(t)\sigma (\mathbf {r}(t))\mathbf {c}(t)\, dt $$
    where $T (t) = \exp \left(- \int _{0}^{t} \sigma (\mathbf {r}(s)) \, ds\right)$ [S1].
*   **Discrete Approximation:**
    $$ \hat{C}(\mathbf{r}) =\sum _{i=0}^{N}\mathbf {c}_{i}T_i(1-\exp (-\sigma _{i}(t_{i+1}-t_{i}))) $$
    [S1]

**Parameters:**
*   $N$: The number of samples on the ray within near and far bounds ($t_n$ and $t_f$) [S1].
*   SH Degree: Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Shape-Radiance Ambiguity:** Training with only color reconstruction loss causes strong anisotropy and shape-radiance ambiguity [S1]. This is mitigated by the anisotropy regularization step [S1].
*   **Directional Ambiguity:** Standard isotropic features ignore direction information in point intervals, leading to ambiguous features and limited reconstruction quality [S1].

def render_anisotropic_nerf(ray_origin, ray_direction, near_bound, far_bound, n_samples, sh_degree, mlp):
    """
    Renders a single ray using Anisotropic Neural Representation Learning.
    
    Args:
        ray_origin: (3,) array, camera origin o.
        ray_direction: (3,) array, viewing direction d.
        near_bound: float, t_n.
        far_bound: float, t_f.
        n_samples: int, N.
        sh_degree: int, degree of spherical harmonics.
        mlp: function, takes (position, direction) and returns SH coefficients for density and color.
        
    Returns:
        color: (3,) array, rendered pixel color.
    """
    # 1. Sample points along the ray
    # Linear spacing between near and far bounds
    t_vals = np.linspace(near_bound, far_bound, n_samples)
    
    # 2. Evaluate SH basis for the viewing direction
    # Y is a matrix of shape (n_sh_coeffs, 3) or similar, depending on implementation
    # For a single direction d, we compute the basis values
    sh_basis = evaluate_spherical_harmonics(ray_direction, sh_degree)
    
    accumulated_transmittance = 1.0
    accumulated_color = np.zeros(3)
    
    for i in range(n_samples):
        t_i = t_vals[i]
        # Handle the last interval extending to infinity or far_bound
        if i < n_samples - 1:
            t_next = t_vals[i+1]
        else:
            t_next = far_bound
            
        delta_t = t_next - t_i
        
        # 3. Predict SH coefficients
        # mlp returns coefficients for density and color
        # w_sigma: coefficients for density
        # w_color: coefficients for color (3 channels)
        w_sigma, w_color = mlp(position=ray_origin + t_i * ray_direction, 
                               direction=ray_direction)
        
        # 4. Evaluate anisotropic density and color
        # Project coefficients onto SH basis
        sigma_i = np.dot(w_sigma, sh_basis)
        c_i = np.dot(w_color, sh_basis)
        
        # 5. Compute contribution
        # T_i is accumulated_transmittance from previous steps
        # Opacity of this segment: 1 - exp(-sigma * delta_t)
        opacity = 1.0 - np.exp(-sigma_i * delta_t)
        
        accumulated_color += accumulated_transmittance * c_i * opacity
        accumulated_transmittance *= (1.0 - opacity)
        
        # Early termination if transmittance is negligible
        if accumulated_transmittance < 1e-4:
            break
            
    return accumulated_color

## Subtopics

### Ref-NeRF
Uses reference images to guide the rendering process, leveraging explicit geometry or feature matching. Choose when high-fidelity reflections and complex lighting are present and reference views are available. See [Ref-NeRF](10843-ref-nerf.md).

## Operating characteristics
*   **Time Complexity:** Depends on the number of samples $N$ and the cost of SH evaluation. SH evaluation is $O(L^2)$ where $L$ is the degree. The MLP inference is constant per sample.
*   **Memory Complexity:** Stores SH coefficients for each MLP output. The size of the coefficient vector depends on the SH degree.
*   **Strengths:** Eliminates directional ambiguity without complex sampling strategies (unlike Mip-NeRF). Can be plugged into various NeRF frameworks. Improves rendering quality by capturing anisotropy.
*   **Limitations:** Requires careful regularization to prevent over-fitting to anisotropy (shape-radiance ambiguity).
*   **When to use:** When standard NeRF suffers from directional artifacts or blurring due to isotropic assumptions, and when computational resources for complex sampling (like cone tracing) are limited.
*   **When not to use:** If the scene is strictly isotropic and simple, the overhead of SH evaluation may be unnecessary.

## Background
Anisotropic Neural Representation Learning was proposed to address the limitations of standard NeRF, which ignores direction information in point intervals, resulting in ambiguous features and limited reconstruction quality [S1]. The method utilizes learnable view-dependent features parameterized by multilayer perceptrons to facilitate ambiguity elimination while preserving rendering efficiency [S1]. It was introduced in the paper "Improving Neural Volume Rendering via Learning View-Dependent Integral Approximation" [S1].
