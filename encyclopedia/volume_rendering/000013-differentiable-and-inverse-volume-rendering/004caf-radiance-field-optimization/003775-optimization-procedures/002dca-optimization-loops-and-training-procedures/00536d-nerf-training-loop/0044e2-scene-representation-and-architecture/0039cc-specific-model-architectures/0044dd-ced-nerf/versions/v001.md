# Ced-NeRF

Also called: Compact and Efficient Dynamic Neural Radiance Fields

## Overview
Ced-NeRF is a method for reconstructing dynamic scenes using a hybrid representation that combines a high-resolution hash grid with a canonical space deformation network [S1]. It addresses the overfitting artifacts (floaters, noisy geometry) common in hybrid representations for dynamic scenes by ensuring fast convergence through high-resolution grids while avoiding the training instability of separated static/dynamic fields [S1]. It sets itself apart from siblings like [AdaNeRF](6195-adanerf.md) and [Sparse and Efficient Representations](9326-sparse-and-efficient-representations.md) by prioritizing a single high-resolution grid over sparse voxels or separated models to maximize rendering speed and training efficiency [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of training images with known camera poses $(o, d)$ and timestamps $t$.
*   **Outputs:** Predicted pixel colors $\bar{\mathbf{C}}(\mathbf{r})$ for novel viewpoints and times.

**Data Structures:**
*   **Grid $G$:** A hash table storing feature vectors at voxel vertices. The implementation uses the Instant-NGP hash grid structure [S1].
    *   **Lookup:** For a coordinate $(x, y, z)$, the eight closest grid cells are selected for trilinear interpolation [S1].
*   **Deformation Network $\Phi_d$:** A small MLP mapping encoded spatial coordinates and time to a deformation vector [S1].
*   **Radiance Network $\Phi_r$:** An MLP mapping grid features and direction features to density $\sigma$ and color $\mathbf{c}$ [S1].

**Encoding Functions:**
1.  **Frequency Encoding $\gamma(\cdot)$:** Applied to spatial coordinates $\mathbf{x}$ and viewing direction $\mathbf{d}$ [S1].
    $$
    \gamma(\mathbf{p}) = (\sin(2^0 \pi \mathbf{p}), \cos(2^0 \pi \mathbf{p}), \dots, \sin(2^{L-1} \pi \mathbf{p}), \cos(2^{L-1} \pi \mathbf{p}))
    $$
    where $L$ is the number of frequency bands [S1].
2.  **Grid Encoding $\gamma_{\text{grid}}(\cdot)$:** Applied to spatial coordinates $\mathbf{x}$ to retrieve features from $G$ [S1].
    $$
    \gamma_{\text{grid}}(\mathbf{x}) = \text{interp}(\mathbf{x}, G)
    $$
    where $\text{interp}$ performs trilinear interpolation over the eight nearest grid cells [S1].

**Algorithm Steps:**
1.  **Ray Sampling:** For a camera ray $\mathbf{r} = \mathbf{o} + s\mathbf{d}$, sample $N$ points $\mathbf{r}_i = \mathbf{o} + s_i \mathbf{d}$ along the ray [S1].
2.  **Deformation:** For each sample point $\mathbf{r}_i$ at timestamp $t$:
    *   Encode position $\mathbf{x} = \mathbf{r}_i$ and time $t$ using $\gamma(\cdot)$ [S1].
    *   Compute deformation vector $\Delta \mathbf{x} = \Phi_d(\gamma(\mathbf{x}), \gamma(t))$ [S1].
    *   Compute canonical coordinate $\mathbf{x}' = \mathbf{x} + \Delta \mathbf{x}$ [S1].
3.  **Feature Retrieval:** Encode the canonical coordinate $\mathbf{x}'$ using $\gamma_{\text{grid}}(\cdot)$ to obtain grid features $\mathbf{f}_{\text{grid}}$ [S1].
4.  **Direction Encoding:** Encode the viewing direction $\mathbf{d}$ using $\gamma(\cdot)$ to obtain direction features $\mathbf{f}_{\text{dir}}$ [S1].
5.  **Radiance Prediction:** Pass $\mathbf{f}_{\text{grid}}$ and $\mathbf{f}_{\text{dir}}$ into $\Phi_r$ to predict density $\sigma_i$ and color $\mathbf{c}_i$ [S1].
6.  **Volume Rendering:** Compute the final color $\bar{\mathbf{C}}(\mathbf{r})$ using the standard volume rendering integral [S1]:
    $$
    \bar{\mathbf{C}}(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i
    $$
    where $\delta_i = s_{i+1} - s_i$ and $T_i = \prod_{j=1}^{i-1} \exp(-\sigma_j \delta_j)$ [S1].

**Pseudocode:**
```python
def ced_nerf_forward(ray_o, ray_d, timestamp, grid, deformation_net, radiance_net, num_samples):
    """
    ray_o: (3,) origin of the ray
    ray_d: (3,) normalized direction of the ray
    timestamp: float, time of the frame
    grid: HashGrid object supporting lookup and interpolation
    deformation_net: MLP taking concatenated frequency-encoded pos and time
    radiance_net: MLP taking concatenated grid features and direction features
    num_samples: int, N
    """
    # 1. Sample points along the ray
    # Assuming t_min and t_max are known bounds for the scene
    t_vals = torch.linspace(t_min, t_max, num_samples)
    points = ray_o.unsqueeze(0) + t_vals.unsqueeze(1) * ray_d.unsqueeze(0) # (N, 3)
    
    # 2. Frequency encode position and direction
    # gamma is a standard positional encoding function
    pos_encoded = frequency_encode(points) # (N, 2*L)
    dir_encoded = frequency_encode(ray_d)  # (2*L,)
    
    # 3. Deform points to canonical space
    # Encode timestamp
    time_encoded = frequency_encode(torch.tensor([timestamp])) # (2*L,)
    
    # Concatenate position and time for deformation network
    deformer_input = torch.cat([pos_encoded, time_encoded], dim=-1) # (N, 4*L)
    
    # Get deformation vector
    deformed_vec = deformation_net(deformer_input) # (N, 3)
    
    # Canonical coordinates x' = x + deformation
    canonical_points = points + deformed_vec # (N, 3)
    
    # 4. Retrieve grid features from canonical coordinates
    grid_features = grid.lookup(canonical_points) # (N, D_grid)
    
    # 5. Prepare direction features (broadcast to N)
    dir_features = dir_encoded.unsqueeze(0).expand(num_samples, -1) # (N, 2*L)
    
    # 6. Predict density and color
    radiance_input = torch.cat([grid_features, dir_features], dim=-1) # (N, D_grid + 2*L)
    sigma_raw, color = radiance_net(radiance_input) # sigma_raw: (N,), color: (N, 3)
    
    # Apply activation for density (e.g., ReLU or softplus) if not handled in net
    sigma = torch.relu(sigma_raw) # (N,)
    
    # 7. Volume Rendering
    # Compute delta distances
    deltas = t_vals[1:] - t_vals[:-1] # (N-1,)
    # Pad deltas to match N samples (last delta is 0 or handled by bounds)
    deltas = torch.cat([deltas, torch.tensor([0.0])]) # (N,)
    
    alpha = 1.0 - torch.exp(-sigma * deltas) # (N,)
    transmittance = torch.cumprod(1.0 - alpha + 1e-10, dim=0) # (N,)
    # Adjust transmittance: T_i = product_{j=1}^{i-1} (1 - alpha_j)
    # cumprod gives T_1=1, T_2=1-alpha_1, etc.
    # Standard formula: C = sum T_i * alpha_i * c_i
    # Note: T_i in the formula is the transmittance BEFORE sample i.
    # If we define T_1 = 1, then T_i = prod_{j=1}^{i-1} (1-alpha_j).
    # The cumprod above computes exactly this if we shift or handle indices correctly.
    # Let's use the explicit product form for clarity in implementation:
    T = torch.ones(num_samples)
    for i in range(1, num_samples):
        T[i] = T[i-1] * (1 - alpha[i-1])
        
    weights = T * alpha # (N,)
    final_color = torch.sum(weights.unsqueeze(1) * color, dim=0) # (3,)
    
    return final_color
```

**Parameters:**
*   **Grid Resolution:** High-resolution grid (specific dimensions not given in sources, but cited as superior to low-res or sparse grids for convergence speed) [S1].
*   **Frequency Bands $L$:** Not given in the sources.
*   **Number of Samples $N$:** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Overfitting:** Hybrid representations for dynamic scenes are prone to overfitting due to fast convergence before accurate motion prediction is learned, leading to floaters and noisy geometry on novel views [S1]. Ced-NeRF mitigates this by using a compact auxiliary deformation network and high-resolution grid [S1].
*   **Boundary Conditions:** Ray sampling bounds ($t_{min}, t_{max}$) must be defined to handle empty space [S1].

## Operating characteristics
*   **Time Complexity:** Rendering speed is fast due to the high-resolution hash grid lookup, which converges rapidly [S1]. Training is accelerated compared to separated field models [S1].
*   **Memory Complexity:** Depends on the size of the hash grid $G$ and the small deformation network $\Phi_d$ [S1].
*   **Performance:** On HyperNeRF scenes, Ced-NeRF achieves 4 minutes training time and 34.2 dB PSNR. On DyNeRF scenes, it achieves 21 minutes training time and 30.6 dB PSNR [S1].
*   **Strengths:** Fast rendering, fast convergence, high-quality results, compact parameter count [S1].
*   **Limitations:** Potential for overfitting artifacts if not regularized or if the deformation network is insufficiently expressive [S1].
*   **When to use:** Dynamic scene reconstruction where training speed and rendering efficiency are prioritized, and where sparse voxel grids or separated static/dynamic models are too slow or difficult to train [S1].

## Background
Ced-NeRF was proposed in 2024 by the authors of the paper "Ced-NeRF: A Compact and Efficient Method for Dynamic Neural Radiance Fields" [S1]. It builds upon the Instant-NGP hash grid representation [S1] and the canonical space deformation approach from DNeRF [S1]. It was developed to address the limitations of existing hybrid representations for dynamic scenes, specifically the trade-off between convergence speed and artifact generation [S1].
