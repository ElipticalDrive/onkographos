# AR-NeRF
Also called: Aperture Rendering Neural Radiance Fields, aperture rendering NeRF

## Overview
AR-NeRF is an extension of Neural Radiance Fields (NeRF) that employs an aperture camera model instead of a pinhole camera model to represent defocus effects and viewpoint changes in a unified manner within a common ray-tracing framework [S1]. It enables the fully unsupervised learning of depth and defocus effects from single natural images by jointly leveraging defocus and viewpoint cues without explicit supervision or pretrained models [S1]. Unlike standard NeRF, which assumes a pinhole camera, AR-NeRF represents each pixel using a collection of rays converging at a focus plane, allowing the model to disentangle defocus-aware and defocus-independent representations through aperture randomized training [S1].

## How it works
**Inputs and Outputs:**
The method takes a single natural image (or a dataset of unstructured natural images) as input. The output is a generative model capable of rendering images and corresponding depth maps with adjustable defocus strength and focus distance [S1].

**Data Structures and Layout:**
The scene is represented by a Multilayer Perceptron (MLP) [S1].
*   **MLP Inputs:** The MLP takes the 3D position $\mathbf{x} \in \mathbb{R}^3$, the view direction $\mathbf{d} \in S^2$, and a latent code $\mathbf{z} \in \mathbb{R}^{L_z}$ as inputs [S1].
*   **MLP Outputs:** The MLP predicts the RGB color $\mathbf{c}(\mathbf{x}, \mathbf{d}) \in \mathbb{R}^3$ and the volume density $\sigma(\mathbf{x}) \in \mathbb{R}^+$ [S1].
*   **Latent Code:** $\mathbf{z}$ is sampled from a distribution $p^g(\mathbf{z})$ [S1].
*   **Aperture Size:** A scalar parameter $s$ representing the radius of the aperture camera, sampled from a half-normal distribution with standard deviation $\sigma_s$ [S1].
*   **Focus Distance:** A variable $f$ representing the distance between the ray origin and the plane where all objects are in focus. $f$ is represented using an MLP taking $\mathbf{z}$ as input [S1].
*   **Background Representation:** To handle unbounded backgrounds, the implementation uses NeRF++, composed of a foreground NeRF in a unit sphere and a background NeRF modeled using inverted sphere parameterization [S1].

**Numbered Steps:**

1.  **Aperture Ray Sampling:** For each pixel, generate a finite bundle of rays instead of a single ray. The rays converge at the focus plane. The scale of the collection of rays is determined by the aperture size $s$ [S1].
    *   **Sampling Scheme:** Use stratified sampling with five rays per pixel [S1].
    *   One ray origin is placed at the center of the aperture.
    *   The origins of the other four rays are placed along the circumference of the aperture with equal intervals [S1].
    *   The ray origins are sampled from offsets $|\mathbf{u}| \in [0, s]$ [S1].

2.  **Volume Rendering:** For each sampled ray $\mathbf{r}'$, calculate the color $\mathbf{C}(\mathbf{r}')$ and depth $Z(\mathbf{r}')$ by integrating over the ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ within distance $t \in [t_n, t_f]$ [S1]:
    $$
    \mathbf{C}(\mathbf{r}) = \int_{t_n}^{t_f} T(t) \sigma(\mathbf{r}(t)) \mathbf{c}(\mathbf{r}(t), \mathbf{d}) dt
    $$
    $$
    Z(\mathbf{r}) = \int_{t_n}^{t_f} T(t) \sigma(\mathbf{r}(t)) t dt
    $$
    where the transmittance is:
    $$
    T(t) = \exp \left( - \int_{t_n}^t \sigma(\mathbf{r}(s)) ds \right)
    $$
    [S1]. Note: While depth integration is technically not required for the blur effect, it is included to account for ambiguity derived from defocus blur [S1].

3.  **Aggregation:** Calculate the final output for the pixel by taking the average of the corresponding rendered colors $\mathbf{C}(\mathbf{r}')$ and depths $Z(\mathbf{r}')$ for all rays in the bundle [S1].

4.  **Aperture Randomized Training:** Train the model using a GAN framework. To disentangle defocus-aware and defocus-independent representations, vary the aperture size $s$ and latent code $\mathbf{z}$ randomly and independently during training [S1].
    *   The GAN objective is modified to sample $\mathbf{z}$ and $s$ independently:
        $$
        \mathcal{L}_{\text{AR-NeRF}} = \mathbb{E}_{\mathbf{I}^r \sim p^r(\mathbf{I})} [\log D(\mathbf{I}^r)] + \mathbb{E}_{\mathbf{z} \sim p^g(\mathbf{z}), s \sim p^g(s)} [\log (1 - D(G(\mathbf{z}, s)))]
        $$
        [S1].
    *   The distribution $p^g(s)$ is represented using a half-normal distribution, with its standard deviation $\sigma_s$ parameterized to determine the range of aperture sizes in a data-driven manner [S1].
    *   The focus distance $f$ is predicted by an MLP conditioned on $\mathbf{z}$ [S1].

5.  **Camera Pose Restriction:** To prevent sampled camera parameters from going beyond the real distribution, restrict the range of camera poses using a standard deviation of 0.1 radian [S1].

**Pseudocode:**

```python
import numpy as np

def sample_aperture_rays(aperture_size_s, num_rays=5):
    """
    Generates a bundle of rays for a single pixel using stratified sampling.
    
    Args:
        aperture_size_s (float): The radius of the aperture.
        num_rays (int): Number of rays to sample (default 5).
        
    Returns:
        origins (np.array): Array of shape (num_rays, 3) for ray origins.
        directions (np.array): Array of shape (num_rays, 3) for ray directions.
    """
    # Center ray
    origins = np.zeros((num_rays, 3))
    # Directions are assumed to be passed in or derived from pixel center direction
    # For this implementation, we assume a base direction 'base_dir' is provided
    # and we offset the origin.
    
    # 1. Center ray
    origins[0] = [0, 0, 0] # Relative to aperture center
    
    # 2. Four rays on circumference with equal intervals
    for i in range(1, num_rays):
        angle = 2 * np.pi * (i - 1) / (num_rays - 1)
        origins[i] = [aperture_size_s * np.cos(angle), 
                      aperture_size_s * np.sin(angle), 
                      0]
                      
    # Note: In a full implementation, these origins are added to the pinhole 
    # camera origin, and directions are recalculated to converge at the focus plane.
    # The source specifies origins are placed at center and circumference.
    return origins

def volume_render(ray_origins, ray_directions, focus_distance_f, 
                  nerf_mlp, latent_code_z, t_near, t_far, num_samples):
    """
    Renders color and depth for a bundle of rays.
    
    Args:
        ray_origins (np.array): Shape (num_rays, 3).
        ray_directions (np.array): Shape (num_rays, 3).
        focus_distance_f (float): Distance to the focus plane.
        nerf_mlp (function): The NeRF MLP function.
        latent_code_z (np.array): Latent code vector.
        t_near (float): Near clipping plane.
        t_far (float): Far clipping plane.
        num_samples (int): Number of samples per ray.
        
    Returns:
        avg_color (float): Average color across rays.
        avg_depth (float): Average depth across rays.
    """
    total_color = 0.0
    total_depth = 0.0
    num_rays = len(ray_origins)
    
    for r in range(num_rays):
        origin = ray_origins[r]
        direction = ray_directions[r]
        
        # Sample points along the ray
        t_vals = np.linspace(t_near, t_far, num_samples)
        points = origin + t_vals[:, np.newaxis] * direction
        
        # Query MLP for sigma and color
        # MLP input: x, d, z
        # d is constant for the ray, but might vary slightly if rays diverge/converge
        # Source says MLP takes view direction d. In aperture rendering, 
        # the view direction for the ray is the direction from the aperture point to the sample.
        
        sigma_vals = np.zeros(num_samples)
        color_vals = np.zeros((num_samples, 3))
        
        for i, t in enumerate(t_vals):
            x = points[i]
            d = direction # Simplified; strictly, d should be normalized direction of ray r
            # In AR-NeRF, the ray direction is defined by the aperture offset.
            
            # Predict sigma and color
            sigma, color = nerf_mlp(x, d, latent_code_z)
            sigma_vals[i] = sigma
            color_vals[i] = color
            
        # Compute Transmittance T(t)
        # T(t) = exp(-integral(sigma ds))
        # Discretized: T_i = exp(-sum_{j=0}^{i-1} sigma_j * delta_t)
        delta_t = t_vals[1] - t_vals[0]
        transmittance = np.zeros(num_samples)
        transmittance[0] = 1.0
        for i in range(1, num_samples):
            transmittance[i] = transmittance[i-1] * np.exp(-sigma_vals[i-1] * delta_t)
            
        # Compute Color and Depth
        # C(r) = integral T(t) sigma(t) c(t) dt
        # Z(r) = integral T(t) sigma(t) t dt
        weight = transmittance * sigma_vals * delta_t
        color = np.sum(weight[:, np.newaxis] * color_vals, axis=0)
        depth = np.sum(weight * t_vals, axis=0)
        
        total_color += color
        total_depth += depth
        
    avg_color = total_color / num_rays
    avg_depth = total_depth / num_rays
    
    return avg_color, avg_depth

    # L_AR-NeRF = E[log D(I^r)] + E[log(1 - D(G(z, s)))]
    # D is discriminator, G is generator (MLP + rendering)
    
    real_score = discriminator(image)
    fake_score = discriminator(rendered_image)
    
    loss = -np.mean(np.log(real_score + 1e-8)) - np.mean(np.log(1 - fake_score + 1e-8))
    
    # 4. Backpropagate
    optimizer.step(loss)
    
    return loss
```

**Parameters:**
*   **Aperture Size ($s$):** A scalar parameter representing the radius of the aperture camera. It determines the scale of the collection of rays converging at the focus plane [S1]. It is sampled from a half-normal distribution with standard deviation $\sigma_s$ [S1].
*   **Focus Distance ($f$):** A variable representing the distance between the ray origin and the plane where all objects are in focus. It is represented using an MLP taking the latent code $\mathbf{z}$ as input [S1].
*   **Camera Pose Restriction:** The range of sampled camera parameters is restricted using a standard deviation of 0.1 radian to prevent going beyond the real distribution [S1].
*   **Number of Rays:** 5 rays per pixel are used (1 center, 4 circumference) [S1].

**Edge Cases and Pitfalls:**
*   **Unbounded Background:** Standard generative NeRF renders scenes in a tightly bounded 3D space, which prevents representing strong defocus effects at far distances. This is addressed by using NeRF++ with a foreground NeRF in a unit sphere and a background NeRF modeled using inverted sphere parameterization [S1].
*   **Discretized Formulation:** Unlike AR-GAN, which manipulates depth scale, AR-NeRF manipulates the aperture size directly. This allows AR-NeRF to scale the aperture directly despite the discretized formulation, whereas AR-GAN's learned depth is relative and requires careful tuning when changing focus distance [S1].

## Operating characteristics
*   **Time and Memory Complexity:** The method uses stratified sampling with only five rays per pixel to efficiently represent the aperture, reducing processing time and memory compared to typical ray tracing which might use 100 rays per pixel [S1].
*   **Measured Performance:** The method was applied to various natural image datasets, including flower, bird, and face images [S1].
*   **Strengths:** It can represent both viewpoint changes and defocus effects in a unified manner. It disentangles defocus-aware and defocus-independent representations in an unsupervised manner [S1]. It can explain and utilize other ray-tracing-related phenomena (e.g., viewpoints) in a unified manner, unlike AR-GAN which is specific to learning depth and defocus effects [S1].
*   **Limitations:** It requires a dataset of diversely defocused images (assumption satisfied in typical natural image datasets) [S1]. The depth accuracy calculation is non-trivial as ground truth depth is not available; an alternative metric is used [S1].
*   **When to use:** When unsupervised learning of depth and defocus effects from single natural images is required, and when a unified representation of viewpoint and defocus is needed [S1].

## Background
AR-NeRF was proposed by Takuhiro Kaneko et al. from NTT Communication Science Laboratories [S1]. The project page is available at https://www.kecl.ntt.co.jp/people/kaneko.takuhiro/projects/ar-nerf/ [S1]. It shares the motivation with AR-GAN [37] but differs by using continuous radiance fields instead of discretized CNNs [S1]. The paper was published in 2022 [S1].
