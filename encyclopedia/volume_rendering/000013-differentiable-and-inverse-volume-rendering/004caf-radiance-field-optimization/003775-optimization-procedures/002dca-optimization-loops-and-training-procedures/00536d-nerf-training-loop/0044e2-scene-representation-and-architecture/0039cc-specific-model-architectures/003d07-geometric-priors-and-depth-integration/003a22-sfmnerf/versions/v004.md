# SfMNeRF

Also called: SfM-NeRF

## Overview
SfMNeRF is a neural radiance field optimization method designed to improve novel view synthesis and 3D-scene geometry reconstruction under sparse input conditions [S1]. It addresses the geometric ambiguity and local minima issues inherent in standard NeRF by integrating explicit Structure-from-Motion (SfM) constraints—specifically matched feature positions, epipolar geometry, and multi-view photometric consistency—into the training loop [S1]. Unlike implicit NeRF methods that rely solely on photometric loss, SfMNeRF enforces geometric priors via SIFT feature matching and depth smoothness, utilizing a pyramidal training strategy to handle large pixel motions [S1].

## How it works
**Inputs:**
*   A set of input images with known camera intrinsics $K$ and global poses $[\mathbf{r}_t, \mathbf{t}_t]$ [S1].
*   Matched Scale-Invariant Feature Transform (SIFT) correspondences between image pairs [S1].
*   A Neural Radiance Field (MLP) parameterized by $\theta$, mapping 3D coordinates $\mathbf{x}$ and viewing directions $\mathbf{d}$ to volume density $\sigma$ and color $\mathbf{c}$ [S1].

**Outputs:**
*   Optimized NeRF parameters $\theta$ [S1].
*   Synthesized novel views and depth maps [S1].

**Data Structures:**
*   **Camera Intrinsic Matrix:** $K$ [S1].
*   **Relative Pose:** $T_{r \to t} = [\mathbf{r}, \mathbf{t}]$, derived from global poses [S1].
*   **Mask Map:** $M(p(k))$, a binary map where $M=1$ if point $p(k)$ is within the minimum bounding rectangle of matched SIFT features in the reference image, else $0$ [S1].
*   **Depth Map:** $D$, estimated per pixel via volume rendering integration [S1].
*   **Pyramid Levels:** $L$ levels of image representations $I^0, \dots, I^{L-1}$, where $I^n$ is half the resolution of $I^{n-1}$ [S1].

**Numbered Steps:**

1.  **Pyramid Construction:** Construct an $L$-level image pyramid for the reference image $I_r$ and target image $I_t$. $I^0$ is the original image; $I^n$ is downsampled from $I^{n-1}$ with half the resolution [S1].
2.  **Initialization:** Start optimization at the lowest pyramid level $L-1$ using images $I^{L-1}_r$ and $I^{L-1}_t$ [S1].
3.  **Sub-pixel Sampling:** For a randomly selected patch $\Omega_p$ in the reference image, generate sub-pixel coordinates $p = (x + x_{off}, y + y_{off})$ where $x_{off}, y_{off} \in (0, 1)$ [S1].
4.  **Ground Truth Interpolation:** Compute the ground-truth color $\hat{I}(p)$ for each sub-pixel via bilinear interpolation of the four nearest integer-pixel neighbors in the reference image [S1].
5.  **NeRF Rendering:** Input sub-pixel coordinates and viewing directions into the NeRF to obtain volume density $\sigma$ and color $\mathbf{c}$ along the ray [S1].
6.  **3D Coordinate Estimation:** Calculate the 3D coordinate $\mathbf{x}_s$ of SIFT features and rendered pixels using the weighted sum of samples:
    $$ \mathbf{x}_s = \sum_{j=1}^{N_c} w_j (\mathbf{o} + t_j \mathbf{d}) $$
    where $w_j = T_j (1 - \exp(-\sigma_j \delta_j))$, $\delta_j = t_{j-1} - t_j$, $N_c$ is the number of samples, $\mathbf{o}$ is the camera origin, and $\mathbf{d}$ is the viewing direction [S1].
7.  **Loss Computation:** Compute the following loss components:
    *   **Rendering Loss ($L_{ren}$):** Mean squared error between interpolated ground-truth sub-pixel colors $\hat{I}(p_i)$ and synthesized colors $\tilde{I}(p_i)$ [S1]:
        $$ L_{ren} = \frac{1}{m} \sum_{p_i \in \Omega_p} \left\| \hat{I}(p_i) - \tilde{I}(p_i) \right\|_2^2 $$
    *   **Positions-of-Matched Features Loss ($L_{3D}$):** Minimizes the distance between 3D coordinates of matched SIFT features in reference ($\mathbf{x}_s^k$) and target ($\mathbf{x}_{s'}^k$) images [S1]:
        $$ L_{3D} = \frac{1}{n} \sum_{k=1}^n \|\mathbf{x}_s^k - \mathbf{x}_{s'}^k\|_2^2 $$
    *   **Epipolar Constraint Loss ($L_{epi}$):** Minimizes the distance between the 3D coordinate of a reference point $d_{p_r}$ and points $d_{p_t}$ on the epipolar line in the target image. Implausible points are filtered by color similarity threshold [S1]:
        $$ L_{epi} = \min_t \left\{ \left\| d_{p_r} - d_{p_t} \right\|_2^2 \right\} $$
    *   **Photometric Reconstruction Loss ($L_{pr}$):** Warps pixels from the reference patch to the target view using relative pose $T_{r \to t}$ and compares colors. The relative pose is defined as $\mathbf{r} = \mathbf{r}_t^{-1}$ and $\mathbf{t} = -\mathbf{r}_t^{-1}\mathbf{t}_t$ [S1]:
        $$ L_{pr} = \sum_{p(k) \in \Omega_p} M(p(k)) \left| \hat{I}_r(p(k)) - \hat{I}_t(\hat{p}_t(k)) \right| $$
        where $\hat{p}_t = K T_{r \to t} \mathbf{x}_p$ [S1].
    *   **SSIM Loss ($L_{SSIM}$):** Structural Similarity index between reference and warped target patches, masked by $M$ [S1]:
        $$ L_{SSIM} = M \left( \frac{1 - SSIM_{r \to t}}{2} \right) $$
    *   **Depth Smooth Loss ($L_{ds}$):** Enforces smoothness on the estimated depth map $D$, weighted by image gradient to preserve edges [S1]:
        $$ L_{ds} = \sum_{p(k) \in \Omega_p} \left| \nabla D ( p(k) ) \cdot \left( e^{-|\hat{I}(p(k))|} \right) \right| $$
8.  **Total Loss:** Combine losses with weights $\lambda$ [S1]:
    $$ L_{total} = \lambda_{ren} L_{ren} + \lambda_{3D} L_{3D} + \lambda_{pr} L_{pr} + \lambda_{epi} L_{epi} + \lambda_{SSIM} L_{SSIM} + \lambda_{ds} L_{ds} $$
9.  **Optimization:** Update NeRF parameters using the Adam optimizer [S1].
10. **Pyramidal Progression:** If not at level 0, add a depth loss $L_{depth}$ to guide the next higher resolution level $n-1$ using the depth map $D^{L-1}_r$ from level $n$ [S1]:
    $$ L_{depth} = \sum_{p(k) \in \Omega_p} |D(p(k)) - D_r^{L-1}(p(k)/2)| $$
    where $D_r^{L-1}(p(k)/2)$ is sampled via bilinear interpolation from the lower-resolution depth map [S1]. Recursively repeat steps 1-9 for levels $L-2$ down to $0$ [S1].

**Parameters:**
*   Loss weights: $\lambda_{ren} = 1.0$, $\lambda_{3D} = 1.0$, $\lambda_{pr} = 0.001$, $\lambda_{epi} = 0.0001$, $\lambda_{SSIM} = 0.008$, $\lambda_{ds} = 0.01$ [S1].
*   Patch size: $32 \times 32$ pixels [S1].
*   Sampling: Hierarchical sampling with 64 coarse and 64 importance samples [S1].
*   Optimizer: Adam with $\beta_1 = 0.9, \beta_2 = 0.999$, learning rate $1e-3$ [S1].

**Edge Cases and Pitfalls:**
*   **Epipolar Points:** A large number of epipolar points causes computational inefficiency. Occluded points may not have corresponding points on the epipolar line [S1].
*   **Filtering:** Implausible epipolar points must be filtered using color similarity to maintain efficiency and accuracy [S1].
*   **Local Minima:** Large pixel motions can cause the photometric consistency loss to get stuck in local minima; the pyramidal strategy mitigates this [S1].

## Operating characteristics
*   **Complexity:** The method adds computational overhead to standard NeRF due to SIFT extraction, epipolar line sampling, and multi-view warping. The epipolar constraint requires searching along epipolar lines, which is mitigated by color-based filtering [S1].
*   **Performance:** Evaluated on LLFF-NeRF, ScanNet, and DTU MVS datasets [S1]. It outperforms state-of-the-art approaches under sparse input conditions [S1].
*   **Hardware:** Experiments conducted on NVIDIA RTX 3090 [S1].
*   **Strengths:** Explicitly constrains 3D geometry, reducing shape-radiance ambiguity and improving novel view synthesis quality with sparse inputs [S1].
*   **Limitations:** Relies on the availability of matched SIFT features and accurate camera poses; performance degrades if feature matching fails or poses are inaccurate [S1].

## Background
SfMNeRF was proposed to address the failure of existing NeRF-based methods to obtain moderate 3D structures under sparse input conditions, where novel view synthesis quality drops dramatically due to implicitly reconstructed inaccurate geometry [S1]. It leverages knowledge from self-supervised depth estimation methods to constrain 3D-scene geometry during view synthesis training [S1]. The method integrates epipolar geometry, photometric consistency, depth smoothness, and position-of-matches constraints to explicitly reconstruct the 3D-scene structure [S1]. Code is available at https://github.com/XTU-PR-LAB/SfMNeRF [S1].
