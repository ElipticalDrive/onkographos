# STensoRRF

Also called: StensorR, tensorial able relighting radiance field for single-tensor scene representation

## Overview
STensoRRF is a differentiable volume rendering method that represents a 3D scene using a single 4D tensor to enable high-quality novel view synthesis and relighting [S1, unofficial]. Unlike standard NeRF architectures that use multi-layer perceptrons (MLPs) to map coordinates to density and color, STensoRRF decomposes this 4D tensor into low-rank components to accelerate convergence and explicitly decodes BRDF values for relighting [S1, unofficial]. It sets itself apart from sibling methods like [AdaNeRF](6195-adanerf.md) or [SinNeRF](6199-sinnerf.md) by relying on a single unified tensor representation rather than multiple grids or positional embeddings, and by directly estimating reflected light properties via a dedicated decoder [S1, unofficial].

## How it works
**Inputs:** A set of multi-view images of a scene with unknown illumination, camera poses, and an environment map (or its spherical Gaussian approximation).
**Outputs:** Rendered pixel colors for new viewpoints and relit scenes; a 4D tensor representing the scene.

**Data Structures:**
The core representation is a single 4D tensor $\mathbf{GS}$.
*   **Dimensions:** The first three dimensions correspond to spatial coordinates $(x, y, z)$. The fourth dimension is the feature vector.
*   **Feature Vector Layout:** The first element of the feature vector is the volume density $\sigma$. The remaining elements are appearance features $\mathbf{f}$ used to decode color, normal, and BRDF [S1, unofficial].
*   **Decomposition:** To manage memory and computation, the 4D tensor is decomposed using Vector-Matrix (VM) decomposition into several low-rank tensor components [S1, unofficial].

**Parameters:**
*   Number of Spherical Gaussians (SGs) to fit the environment map: 32 [S1, unofficial].

**Algorithm:**

1.  **Ray Sampling:** For a given camera pose, trace rays from the origin $\mathbf{o}$ along direction $\mathbf{d}$. Sample $N$ points $\mathbf{x}_i$ along each ray.
2.  **Tensor Query:** For each point $\mathbf{x}_i$, retrieve the raw feature vector from the decomposed 4D tensor. Let the retrieved vector be $\mathbf{v}_i$.
    *   $\sigma_i = \mathbf{v}_i[0]$ (Density)
    *   $\mathbf{f}_i = \mathbf{v}_i[1:]$ (Appearance Features) [S1, unofficial].
3.  **Feature Decoding:** Pass $\mathbf{f}_i$ through distinct Multi-Layer Perceptrons (MLPs) to decode:
    *   Color $\mathbf{c}_i$
    *   Normal vector $\mathbf{n}_i$
    *   BRDF value $\mathbf{b}_i$ (representing the amount of light reflected) [S1, unofficial].
4.  **Volume Rendering (Training):** Compute the pixel color $\mathbf{C}(\mathbf{r})$ using the standard volume rendering integral:
    $$
    \mathbf{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i
    $$
    where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ and $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$ [Parent].
5.  **Optimization Loop:** Compare $\mathbf{C}(\mathbf{r})$ with the ground truth pixel color from the input images. Update the 4D tensor parameters (via VM decomposition factors) to minimize the loss [S1, unofficial].
6.  **Surface Estimation (Post-Training/Relighting):** After sufficient iterations, identify surface points on the ray (e.g., using depth estimation or density thresholds). Retrieve $\mathbf{n}_i$ and $\mathbf{b}_i$ for these surface points [S1, unofficial].
7.  **Relighting:**
    *   Approximate the incident light field $\mathbf{L}_i(\omega)$ using 32 Spherical Gaussians [S1, unofficial].
    *   Calculate the reflected light integral by combining the BRDF value $\mathbf{b}_i$, normal $\mathbf{n}_i$, and the simulated light field. The method uses a formula similar to the reflectance equation, where the network directly estimates the reflected light amount [S1, unofficial].
    *   Render the relit color [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def query_tensor(tensor_decomposed, x, y, z):
    """
    Retrieves density and appearance features from the decomposed 4D tensor.
    tensor_decomposed: List of low-rank factors from VM decomposition.
    x, y, z: Float coordinates.
    Returns: sigma (float), features (array)
    """
    # Implementation of VM decomposition lookup depends on specific library,
    # but conceptually it aggregates the low-rank components at (x,y,z).
    # [G] Assuming a standard interpolation or aggregation function for the decomposition.
    raw_vector = vm_decompose_lookup(tensor_decomposed, x, y, z)
    sigma = raw_vector[0]
    features = raw_vector[1:]
    return sigma, features

def decode_features(features):
    """
    Decodes appearance features into color, normal, and BRDF.
    """
    color = color_mlp(features)
    normal = normal_mlp(features)
    brdf_value = brdf_mlp(features)
    return color, normal, brdf_value

def render_ray(ray_origin, ray_direction, tensor_decomposed, num_samples):
    """
    Renders a single ray using volume rendering.
    """
    total_color = np.zeros(3)
    accumulated_transmittance = 1.0
    
    for i in range(num_samples):
        # Sample point along ray
        t = i * step_size # Simplified sampling
        x, y, z = ray_origin + ray_direction * t
        
        sigma, features = query_tensor(tensor_decomposed, x, y, z)
        
        # Compute alpha
        delta = step_size # Distance between samples
        alpha = 1.0 - np.exp(-sigma * delta)
        
        # Compute color contribution
        color, _, _ = decode_features(features)
        contribution = accumulated_transmittance * alpha * color
        
        total_color += contribution
        accumulated_transmittance *= (1.0 - alpha)
        
        if accumulated_transmittance < 1e-5:
            break
            
    return total_color

def relight_surface_point(surface_x, surface_y, surface_z, normal, brdf_value, env_map_sgs):
    """
    Relights a specific surface point using Spherical Gaussians.
    env_map_sgs: List of 32 Spherical Gaussian parameters (amplitude, direction, width).
    """
    # [G] The exact reflectance equation form is not fully detailed in the source,
    # but it combines BRDF, normal, and incident light.
    incident_light = 0.0
    for sg in env_map_sgs:
        # Evaluate SG at the normal direction
        l = sg.direction
        # Simple dot product approximation for incident light from SG
        incident_light += sg.amplitude * np.exp(-sg.width * (1.0 - np.dot(normal, l)))
        
    # Reflected light is approximated by combining BRDF value and incident light
    # The source states the network estimates the "amount of light reflected"
    reflected_color = brdf_value * incident_light
    return reflected_color

def train_step(images, poses, tensor_decomposed, loss_fn):
    """
    One step of optimization.
    """
    rendered_images = []
    for pose in poses:
        # Generate rays from pose
        rays = generate_rays(pose)
        rendered_pixels = []
        for ray in rays:
            color = render_ray(ray.origin, ray.direction, tensor_decomposed, num_samples=128)
            rendered_pixels.append(color)
        rendered_images.append(np.array(rendered_pixels))
        
    loss = loss_fn(rendered_images, images)
    # Update tensor_decomposed parameters using gradient descent
    return loss
```

## Subtopics

### Tensor Decomposition Strategies
STensoRRF uses Vector-Matrix (VM) decomposition. This differs from [Sparse and Efficient Representations](9326-sparse-and-efficient-representations.md) which may use hash grids or octrees, and from [Quadri-Plane Radiance Fields](11128-quadri-plane-radiance-fields.md) which use 2D planes. VM decomposition reduces the memory footprint of the 4D tensor by factorizing it into lower-dimensional components.

### Spherical Gaussian Lighting
The method approximates the environment map using 32 Spherical Gaussians. This is distinct from [Neural Light Field Representations](9273-neural-light-field-representations.md) which might store light fields explicitly, or [Appearance and Lighting Decomposition](11061-appearance-and-lighting-decomposition.md) which might learn lighting parameters implicitly. SGs provide a compact, differentiable representation for relighting.

## Operating characteristics
*   **Convergence:** 50% faster convergence rate compared to existing relighting radiation field models [S1, unofficial].
*   **Speed:** Rendering and relighting speed is approximately 1.5x faster than previous state-of-the-art models [S1, unofficial].
*   **Memory:** Uses a single 4D tensor, which is more memory-efficient than methods using multiple voxel meshes or tensors [S1, unofficial].
*   **Strengths:** High-quality novel view synthesis, efficient relighting, simplified training data requirements (no complex geometric surface properties needed) [S1, unofficial].
*   **Limitations:** Relies on tensor decomposition which may introduce approximation errors; the exact quality of relighting depends on the accuracy of the BRDF value estimation by the network [S1, unofficial].

## Background
STensoRRF (Tensorial Able Relighting Radiance Field for Single-Tensor Scene Representation) was proposed in a preprint published in January 2024 [S1, unofficial]. It addresses the limitations of previous radiance field methods that required multiple voxel meshes or tensors for scene representation and combined reflectance equations in complex ways for relighting. By using a single 4D tensor and a network that directly estimates reflected light (BRDF value), it simplifies the pipeline and accelerates training [S1, unofficial].
