# NeRDi


## Overview
NeRDi is a single-view synthesis method that leverages a pre-trained 2D image diffusion model to provide general image priors, enabling high-quality novel view synthesis from a single input image [S1, S2]. Unlike traditional NeRF variants that rely on multi-view consistency or explicit geometric supervision alone, NeRDi minimizes the diffusion loss of rendered arbitrary views under input view constraints [S2]. It distinguishes itself by introducing semantic guidance via language embeddings and a geometric loss based on estimated depth maps to regularize the underlying 3D structure [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A single input image $I_{in}$ of a scene [S1, S2].
*   **Output:** A trained NeRF model $F_\Theta$ capable of rendering novel views [S1, S2].

**Data Structures:**
The method builds upon the standard NeRF representation defined in [Specific Model Architectures](8585-specific-model-architectures.md).
*   **NeRF Model $F_\Theta$:** A differentiable function mapping 3D coordinates $\mathbf{x}$ and viewing directions $\mathbf{d}$ to density $\sigma$ and color $\mathbf{c}$ [G].
*   **Pre-trained Diffusion Model:** A text-to-image diffusion model used as a fixed prior [S1, S2].
*   **Visual Language Model:** A pre-trained model used to extract text embeddings from the input image [S1].
*   **Depth Estimator:** A monocular depth estimation network used to predict depth maps from rendered views [S1].

**Parameters:**
*   **Learning Rate:** Not given in the sources.
*   **Diffusion Steps:** Not given in the sources.
*   **Frequency Bands ($L$):** As defined in [Specific Model Architectures](8585-specific-model-architectures.md).

**Steps:**
1.  **Semantic Guidance Extraction:** Given the input image $I_{in}$, a pre-trained visual language model extracts two language guides: $s_0$ (an image title containing overall semantics) and $s^*$ (a text embedding capturing visual clues from the input image) [S1].
2.  **NeRF Initialization:** Initialize a standard NeRF model $F_\Theta$ using the architecture described in [Specific Model Architectures](8585-specific-model-architectures.md) [G].
3.  **Ray Sampling and Rendering:** For each training iteration:
    *   Sample rays $\mathbf{r}$ from the camera pose.
    *   Sample points $\mathbf{x}_i$ along the rays.
    *   Compute encoded positions $\gamma(\mathbf{x}_i)$ and directions $\gamma(\mathbf{d})$ using positional encoding [G].
    *   Query the NeRF to obtain density $\sigma_i$ and color $\mathbf{c}_i$ [G].
    *   Render the pixel color $C(\mathbf{r})$ using volumetric rendering:
        $$
        C(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i, \quad \text{where } \alpha_i = 1 - \exp(-\sigma_i \delta_i), \quad T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)
        $$
        [G]
4.  **Diffusion Loss Calculation:** Pass the rendered image $C(\mathbf{r})$ and the semantic guides $s_0, s^*$ into the pre-trained diffusion model. Compute the diffusion loss $\mathcal{L}_{diff}$ by evaluating the diffusion model's prediction on the rendered image conditioned on $s_0$ and $s^*$ [S1, S2]. This step enforces that the rendered view is consistent with the 2D image prior and the semantic content of the input [S1, S2].
5.  **Geometric Loss Calculation:** Estimate the depth map $D_{est}$ from the rendered view $C(\mathbf{r})$ using a monocular depth estimator. Compute the geometric loss $\mathcal{L}_{geo}$ based on the estimated depth mapping to regularize the underlying 3D geometry of the NeRF [S1].
6.  **Optimization:** Update the NeRF parameters $\Theta$ by minimizing the combined diffusion and geometric losses [S1, S2].

**Pseudocode:**
```python
def train_NeRDi(input_image, diffusion_model, language_model, depth_estimator, num_iterations, learning_rate):
    nerf_model = initialize_NeRF()
    s0 = language_model.get_image_title(input_image)
    s_star = language_model.get_text_embedding(input_image)
    
    for iteration in range(num_iterations):
        rays = sample_rays(camera_pose)
        x_i, d_i = sample_points(rays)
        
        gamma_x = positional_encoding(x_i)
        gamma_d = positional_encoding(d_i)
        
        sigma_i, c_i = nerf_model.query(gamma_x, gamma_d)
        rendered_image = volumetric_render(sigma_i, c_i, rays)
        
        # Compute Diffusion Loss
        # Sources do not specify the exact diffusion loss formulation.
        noise_pred = diffusion_model.predict_noise(rendered_image, s0, s_star)
        L_diff = compute_diffusion_loss(noise_pred, rendered_image)
        
        # Compute Geometric Loss
        # Sources do not specify the exact geometric loss formulation.
        depth_map = depth_estimator.predict(rendered_image)
        L_geo = compute_geometric_loss(depth_map, nerf_model)
        
        # Total Loss
        L_total = L_diff + L_geo
        
        nerf_model.update_parameters(L_total, learning_rate)
        
    return nerf_model

def initialize_NeRF():
    return NeRFModel()

def sample_rays(pose):
    return [Ray(pose.origin, pose.direction) for _ in range(num_rays)]

def sample_points(rays, num_samples):
    return [ray.sample(num_samples) for ray in rays]

def positional_encoding(x, L=10):
    enc = [x]
    for i in range(L):
        enc += [sin(2**i * pi * x), cos(2**i * pi * x)]
    return enc

def volumetric_render(sigma, c, rays):
    T = 1.0
    color = zeros(3)
    for i in range(len(sigma)):
        alpha = 1 - exp(-sigma[i] * delta[i])
        color += T * alpha * c[i]
        T *= (1 - alpha)
    return color

def compute_diffusion_loss(noise_pred, rendered_image):
    # Sources do not specify the exact diffusion loss formulation.
    return mean_squared_error(noise_pred, noise_added_to_image)

def compute_geometric_loss(depth_map, nerf_model):
    # Sources do not specify the exact geometric loss formulation.
    return depth_consistency_loss(depth_map, nerf_model)
```

**Edge Cases and Pitfalls:**
*   **Single View Ambiguity:** Without multi-view constraints, the NeRF may converge to incorrect geometries; the diffusion prior and geometric loss are critical to mitigate this [S1, S2].

## Subtopics

### Semantic Guidance
Uses language embeddings to guide the diffusion model, improving multi-view consistency [S1]. It is chosen when semantic understanding of the scene is beneficial. See [NeRDi](11365-nerdi.md).

### Geometric Regularization
Uses estimated depth maps to constrain the NeRF's geometry [S1]. It is chosen when explicit geometric priors are needed to resolve single-view ambiguity. See [Geometric Priors and Depth Integration](9395-geometric-priors-and-depth-integration.md).

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** On the DTU dataset, NeRDi achieves a PSNR that is twice as high as traditional NeRF [S1]. It is suitable for zero-shot NeRF synthesis [S1].
*   **Strengths and Limitations:** Leverages 2D diffusion priors for single-view synthesis; requires pre-trained models [S1, S2].
*   **When to use:** Single-view synthesis tasks where multi-view data is unavailable [S1, S2].
*   **When not to use:** Not given in the sources.

## Background
NeRDi was proposed in 2023 by Deng et al. [S2]. It was developed to address the limitations of NeRF in single-view synthesis, where traditional methods struggle with ambiguity and lack of geometric constraints [S2]. The method builds on the idea of using 2D diffusion models as powerful priors for 3D reconstruction [S2].
