# Truncated Depth-Based Sampling


## Overview
Truncated Depth-Based Sampling (TDBS) is a ray sampling strategy for Neural Radiance Fields (NeRF) that utilizes coarse monocular depth priors to guide the placement of sample points along camera rays [S1]. It solves the problem of slow convergence and inaccurate pose estimation in pose-unknown NeRF by assuming the real surface lies near the estimated depth, thereby concentrating samples where they are most likely to contribute to the final image [S1]. Unlike [NoPe-NeRF](14489-depth-guided-sampling.md), which considers overall depth distortion, TDBS explicitly models the depth prior using a truncated normal distribution to fully exploit the potential of monocular depth maps [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A sequence of input images, initial camera poses (or unknown poses to be optimized), and a pre-trained monocular depth network (DPT) [S1].
*   **Outputs:** Optimized radiance field parameters, camera poses, and rendered RGB/depth images [S1].

**Data Structures:**
*   **Depth Map:** A 2D array of depth values estimated by DPT for each pixel [S1].
*   **Ray:** Defined as $r(t) = o + td$, where $o$ is the camera origin and $d$ is the viewing direction [S1].
*   **Sampling Points:** A set of 128 points sampled along each ray [S1].

**Parameters:**
*   **Number of sampling points:** 128 per ray [S1].
*   **Truncation interval $[a, b]$:** $[0.001, 1.0]$ [S1].
*   **Variance $\bar{\sigma}$:** $0.1$ [S1].
*   **Network:** DPT (Depth Prediction Transformer) [S1].

**Steps:**
1.  **Depth Estimation:** Use the pre-trained DPT network to estimate a coarse depth map $D$ for each input image [S1].
2.  **Ray Casting:** For each pixel, cast a camera ray $r(t) = o + td$ into the scene [S1].
3.  **Sampling:** Sample points along the ray using a truncated normal distribution centered on the depth prior $\bar{\mu}$ (the depth value from the map) with variance $\bar{\sigma}$, truncated within $[a, b]$ [S1].
4.  **Network Query:** Feed the sampled 3D points and viewing directions into an MLP $F_\theta$ to estimate color $c$ and volume density $\sigma$ [S1].
5.  **Volume Rendering:** Integrate $c$ and $\sigma$ along the ray to render RGB and depth images [S1].
6.  **Optimization:** Optimize the radiance field and camera poses by supervising the rendered RGB and depth against target values [S1].

**Formulas:**
The probability density function (PDF) of the truncated normal distribution $\psi(\bar{\mu}, \bar{\sigma}, a, b; x)$ is defined as [S1]:

$$
\psi(\bar{\mu}, \bar{\sigma}, a, b; x) = 
\begin{cases} 
0 & x \le a \\
\frac{\phi(\bar{\mu}, \bar{\sigma}^2; x)}{\Phi(\bar{\mu}, \bar{\sigma}^2; b) - \Phi(\bar{\mu}, \bar{\sigma}^2; a)} & a < x < b \\
0 & b \le x
\end{cases}
$$

where $\phi(\cdot)$ and $\Phi(\cdot)$ denote the probability density and cumulative distribution functions of the normal distribution with mean $\bar{\mu}$ and variance $\bar{\sigma}^2$, respectively [S1].

Sampling points are obtained using inverse distribution sampling from this PDF [S1].

**Pseudocode:**

```python
import numpy as np
from scipy.stats import norm

def truncated_normal_pdf(x, mu, sigma, a, b):
    """
    Calculate the PDF of a truncated normal distribution.
    """
    # Standardize
    z_a = (a - mu) / sigma
    z_b = (b - mu) / sigma
    
    # CDF difference
    cdf_diff = norm.cdf(z_b) - norm.cdf(z_a)
    
    # PDF
    pdf = norm.pdf((x - mu) / sigma) / sigma
    
    # Handle truncation
    if x <= a or x >= b:
        return 0.0
    else:
        return pdf / cdf_diff

def inverse_transform_sampling(mu, sigma, a, b, num_samples):
    """
    Sample points from a truncated normal distribution using inverse transform sampling.
    """
    # CDF at boundaries
    z_a = (a - mu) / sigma
    z_b = (b - mu) / sigma
    
    cdf_a = norm.cdf(z_a)
    cdf_b = norm.cdf(z_b)
    
    # Sample uniform random numbers in the range [CDF(a), CDF(b)]
    u = np.random.uniform(cdf_a, cdf_b, num_samples)
    
    # Inverse CDF (PPF)
    # We need to scale u back to the standard normal range [z_a, z_b]
    # Actually, inverse transform sampling for truncated normal:
    # x = mu + sigma * norm.ppf(u)
    # But u is already in [CDF(a), CDF(b)], so norm.ppf(u) will be in [z_a, z_b]
    
    z_samples = norm.ppf(u)
    x_samples = mu + sigma * z_samples
    
    return x_samples

def sample_points_along_ray(ray_origin, ray_direction, depth_prior, num_samples=128, 
                            a=0.001, b=1.0, sigma=0.1):
    """
    Sample points along a ray using Truncated Depth-Based Sampling.
    
    Args:
        ray_origin: 3D vector (o)
        ray_direction: 3D vector (d)
        depth_prior: float, the depth value from the monocular depth map (mu_bar)
        num_samples: int, number of points to sample
        a: float, lower bound of truncation interval
        b: float, upper bound of truncation interval
        sigma: float, variance parameter (sigma_bar)
        
    Returns:
        points: array of shape (num_samples, 3)
    """
    # The depth prior is the mean of the distribution along the ray
    mu_bar = depth_prior
    
    # Sample distances t along the ray from the truncated normal distribution
    # Note: The depth prior is a distance along the ray.
    # The distribution is defined over the distance t.
    t_samples = inverse_transform_sampling(mu_bar, sigma, a, b, num_samples)
    
    # Convert distances to 3D points
    # r(t) = o + t * d
    points = ray_origin + t_samples[:, np.newaxis] * ray_direction
    
    return points

def render_with_tdb(rays, depth_map, mlp, num_samples=128, a=0.001, b=1.0, sigma=0.1):
    """
    Render an image using TDBS.
    
    Args:
        rays: list of (origin, direction) tuples for each pixel
        depth_map: 2D array of depth values for each pixel
        mlp: function F_theta(x, d) -> (c, sigma)
        num_samples: int
        a, b, sigma: parameters
        
    Returns:
        rendered_rgb: 2D array
        rendered_depth: 2D array
    """
    height, width = depth_map.shape
    rendered_rgb = np.zeros((height, width, 3))
    rendered_depth = np.zeros((height, width))
    
    for y in range(height):
        for x in range(width):
            origin, direction = rays[y, x]
            depth_prior = depth_map[y, x]
            
            # Sample points
            points = sample_points_along_ray(origin, direction, depth_prior, num_samples, a, b, sigma)
            
            # Query MLP
            # Assuming mlp takes (points, directions) and returns (colors, densities)
            # This is a simplification; in practice, batched queries are used
            colors, densities = mlp(points, direction)
            
            # Volume Rendering
            # C(r) = integral T(t) sigma(t) c(t) dt
            # Approximated by discrete sum
            # T(t) = exp(-integral_0^t sigma(s) ds)
            
            # Compute transmittance
            # alpha_i = 1 - exp(-sigma_i * delta_t)
            # T_i = product_{j<i} (1 - alpha_j)
            
            # Assuming uniform spacing or known delta_t
            # For simplicity, assume delta_t is constant or derived from t_samples
            t_sorted_indices = np.argsort(points[:, 0]) # Sort by distance if not already sorted
            # Note: t_samples are already sorted if inverse_transform_sampling is monotonic
            # But points might not be if direction is not normalized or if t is not monotonic with x
            # Let's assume t_samples are sorted distances
            
            deltas = np.diff(np.concatenate(([0], t_samples)))
            # Handle first delta
            deltas = np.insert(deltas, 0, deltas[0]) # Approximation
            
            alphas = 1.0 - np.exp(-densities * deltas)
            transmittance = np.cumprod(1.0 - alphas)
            transmittance = np.insert(transmittance, 0, 1.0)
            
            weights = alphas * transmittance
            color = np.sum(weights[:, np.newaxis] * colors, axis=0)
            depth = np.sum(weights * t_samples, axis=0)
            
            rendered_rgb[y, x] = color
            rendered_depth[y, x] = depth
            
    return rendered_rgb, rendered_depth
```

**Edge Cases and Pitfalls:**
*   **Coarse Depth Inaccuracy:** Pre-trained monocular depth networks (e.g., DPT) produce coarse maps that fail to capture fine details and may be inaccurate or incorrect in many regions [S1]. Using these directly in a full-stage manner can degrade rendering quality [S1].
*   **Local Minima:** Relying solely on TDBS can cause the model to fall into local minima during training [S1]. This is mitigated by using a coarse-to-fine training strategy [S1].

## Subtopics

### [Coarse-to-Fine Training Strategy](10617-coarse-to-fine-training-strategy.md)
A training strategy that progressively improves depth precision to circumvent local minima and refine depth geometry. It sets itself apart by alternating between depth-prior-guided sampling and uniform sampling, whereas its sibling [Truncated Depth-Based Sampling](10613-truncated-depth-based-sampling.md) relies solely on truncated normal distributions throughout training. This alternation accelerates convergence and enhances pose estimation accuracy.

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** TD-NeRF (which uses TDBS) achieves superior performance in joint optimization of camera pose and NeRF, surpassing prior works, and generates more accurate depth geometry [S1].
*   **Strengths:** Improves convergence speed and accuracy of pose estimation by fully exploiting monocular depth priors [S1]. More robust than methods that only consider overall depth distortion [S1].
*   **Limitations:** Dependent on the quality of the coarse depth map; inaccurate depth priors can degrade rendering if not handled via coarse-to-fine training [S1].
*   **When to Use:** When training NeRF from unknown camera poses and monocular depth priors are available [S1].
*   **When Not to Use:** When high-precision depth maps are not available and coarse priors are unreliable, or when computational resources are extremely limited (though TDBS may reduce iterations, the depth estimation step adds overhead) [S1].

## Background
*   **Origin:** Proposed in TD-NeRF by [S1] in 2024.
*   **History:** Developed to address the challenge of simultaneously optimizing neural radiance fields and camera poses without given camera poses in indoor and outdoor scenes [S1]. It builds on previous works like NoPe-NeRF [S1] but improves upon them by explicitly using the truncated normal distribution for sampling [S1].
*   **Usage:** Used in joint camera pose and neural radiance field optimization [S1].
