# Surface-Based Sampling

Also called: Near-Surface Sampling

## Overview
Surface-Based Sampling is a ray sampling strategy that restricts 3D sample points to a narrow region surrounding the estimated surface of an object, rather than sampling uniformly throughout the entire volume or free space [S1]. It solves the problem of quality degradation caused by wasting samples in irrelevant free space or occluded regions, which is common in standard NeRF [S1]. Unlike standard NeRF, it leverages external depth information to concentrate computational resources where the radiance field is most active [S1].

## How it works
**Inputs:**
*   Camera ray parameters (origin and direction).
*   Depth value $d$ for the ray, representing the distance to the object surface.
*   Sampling range parameter $\alpha$ (half-width of the sampling interval).
*   Number of samples $N$.

**Outputs:**
*   A set of $N$ 3D sample points $\{S_{r,1}, ..., S_{r,N}\}$ located near the surface along the ray.

**Data Structures:**
*   The method assumes access to a depth image or a pre-generated point cloud from which depth values $d$ can be retrieved for any given ray direction.
*   No complex data structures are required for the sampling calculation itself, only scalar values.

**Parameters:**
*   $\alpha$: Half of the specified sampling range. Controls sampling density. Typical values: $1/2$, $1/16$ [S1].
*   $N$: Number of sample points per ray. Typical value: 8 [S1].
*   $d$: Depth value (distance from camera to surface).
*   $\gamma$: Random jitter for stratified sampling.

**Steps:**
1.  **Retrieve Depth:** For a given ray, obtain the depth value $d$ to the object surface. This is typically derived from depth images of the training set or a generated point cloud [S1].
2.  **Calculate Start Point:** Compute the location of the sample point nearest to the camera within the sampling range, $S_{r,0}$, using the formula:
    $$S_{r,0} = d - \alpha$$
3.  **Generate Samples:** Compute the location of the $n$-th sample, $S_{r,n}$, for $n = 1, ..., N$, using stratified sampling within the interval $[S_{r,0}, S_{r,0} + 2\alpha]$:
    $$S_{r,n} = S_{r,0} + (n - 1) \frac{2\alpha}{N} + \gamma$$
    where $\gamma$ is a random number uniformly generated between $0$ and $\frac{2\alpha}{N}$ [S1].
4.  **Train/Render:** Use the resulting sample points to train the NeRF model or render novel views [S1].

**Pseudocode:**
```python
def surface_based_sampling(ray_origin, ray_direction, depth_d, alpha, N):
    """
    Generates N sample points near the surface defined by depth_d.
    
    Args:
        ray_origin: 3D vector, camera origin.
        ray_direction: 3D vector, normalized ray direction.
        depth_d: float, distance to the surface along the ray.
        alpha: float, half-width of the sampling range.
        N: int, number of samples.
        
    Returns:
        samples: list of 3D vectors, the N sample points.
    """
    # Step 1 & 2: Calculate the start of the sampling interval
    # S_r,0 is the distance from the camera origin to the nearest sample point
    start_distance = depth_d - alpha
    
    # The total length of the sampling interval is 2 * alpha
    interval_length = 2 * alpha
    
    # Step 3: Generate stratified samples
    samples = []
    for n in range(1, N + 1):
        # Generate random jitter gamma for stratified sampling
        # Gamma is uniform in [0, interval_length / N]
        gamma = random.uniform(0, interval_length / N)
        
        # Calculate distance of the nth sample from the camera origin
        # Formula: S_r,n = S_r,0 + (n - 1) * (2*alpha / N) + gamma
        sample_distance = start_distance + (n - 1) * (interval_length / N) + gamma
        
        # Convert distance to 3D point
        sample_point = ray_origin + ray_direction * sample_distance
        samples.append(sample_point)
        
    return samples
```

**Edge Cases and Pitfalls:**
*   **Depth Accuracy:** If the depth $d$ is poorly estimated, using a small $\alpha$ degrades rendering quality significantly [S1]. The parameter $\alpha$ must be set considering the accuracy of the depth images [S1].
*   **Free Space Sampling:** Standard NeRF samples in free space and occluded regions, which may degrade quality. Surface-based sampling avoids this by restricting samples to the surface vicinity [S1].

## Operating characteristics
*   **Complexity:** The sampling calculation is $O(N)$ per ray, identical to standard uniform or stratified sampling in terms of computational cost for generating coordinates. However, it requires an additional lookup or estimation step for depth $d$.
*   **Performance:** Improves rendering accuracy (PSNR) by avoiding samples in irrelevant free space or occluded regions [S1].
*   **Strengths:** Prevents quality degradation from sampling in empty space; allows for denser sampling near the surface with fewer total samples if $\alpha$ is small [S1].
*   **Limitations:** Heavily dependent on the accuracy of the input depth images. Poor depth estimates lead to poor sampling locations [S1]. Requires depth images for training views and depth estimation/refinement for novel views [S1].
*   **When to use:** When accurate depth information (from sensors or estimation) is available for the training set.
*   **When not to use:** When depth accuracy is low or unavailable, as small $\alpha$ will degrade quality [S1].

## Background
Surface-Based Sampling (also known as Near-Surface Sampling) was introduced in the paper "Improving Neural Radiance Fields Using Near-Surface Sampling with Point Cloud Generation" [S1]. The method addresses the inefficiency of standard NeRF, which samples uniformly along the entire ray length, including free space. By leveraging depth images to generate a point cloud and subsequently refining depth for novel views, the method focuses sampling near the object surface [S1].
