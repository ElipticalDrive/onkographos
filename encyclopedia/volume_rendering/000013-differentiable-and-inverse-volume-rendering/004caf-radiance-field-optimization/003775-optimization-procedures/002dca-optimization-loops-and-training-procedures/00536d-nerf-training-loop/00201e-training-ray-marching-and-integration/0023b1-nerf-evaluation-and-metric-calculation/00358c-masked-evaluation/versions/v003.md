# Masked Evaluation

Also called: Depth reprojection masking, Evaluation Visibility Mask Generation

## Overview
Masked Evaluation is a procedure that restricts NeRF metric calculation (PSNR, SSIM) to pixels visible in at least two training views, preventing metric degradation from predicting unseen geometry or depth of single-view objects [S1, S2]. It differs from unmasked evaluation by excluding regions where radiance fields memorize rather than predict scene content, which artificially inflates error metrics [S2].

## How it works
**Inputs:**
- Set of training views $V_{train} = \{v_1, \dots, v_N\}$ with known camera poses $P_i$ and intrinsics $K_i$ [G].
- Dense-NeRF depth predictions for all training views $D_{train} = \{d_1, \dots, d_N\}$ and test views $D_{test} = \{d'_1, \dots, d'_M\}$ [S1, S2].
- Depth difference threshold parameter $\tau$ [S1, S2].

**Outputs:**
- Binary visibility mask $M_j$ for each test view $v'_j$, where $M_j(u, v) = 1$ if visible in $\ge 2$ training views, else $0$ [S1, S2].

**Data Structures:**
- Depth maps: 2D arrays of float values representing distance from camera center [G].
- Visibility counters: 2D integer arrays initialized to zero, same resolution as test views [G].

**Parameters:**
- Depth difference threshold: $\tau = 0.05 \times \max(D_{train})$ [S1, S2]. Specifically, the maximum depth value of the training view's depth map [S2].

**Steps:**
1. For each training view $v_i \in V_{train}$:
   a. Retrieve its predicted depth map $d_i$ and camera parameters $P_i, K_i$ [S1, S2].
   b. For each test view $v'_j \in V_{test}$:
      i. Warp $d_i$ to the coordinate system of $v'_j$ using depth-based reprojection [S1, S2]. This involves projecting each pixel $(u, v)$ in $d_i$ to 3D using $K_i^{-1}$ and $P_i$, then reprojecting to $v'_j$ using $K_j$ and $P_j$ [G]. Let the warped depth at pixel $(u', v')$ in $v'_j$ be $d_{warped}(u', v')$. Handle occlusions by marking pixels with no valid correspondence as invalid [G].
      ii. Retrieve the Dense-NeRF predicted depth $d'_j(u', v')$ for the corresponding pixel in the test view [S2].
      iii. Compute the absolute depth difference: $\Delta d = |d_{warped}(u', v') - d'_j(u', v')|$ [S1].
      iv. If $\Delta d < \tau$, mark pixel $(u', v')$ in $v'_j$ as visible in training view $v_i$. Increment the visibility counter for $(u', v')$ in $v'_j$ by 1 [S2].
2. For each test view $v'_j$:
   a. Generate the final mask $M_j$ by setting $M_j(u', v') = 1$ if the visibility counter for $(u', v')$ is $\ge 2$, else $0$ [S1, S2].

**Pseudocode:**
```python
import numpy as np

def generate_masked_evaluation_mask(
    train_views, 
    test_views, 
    dense_nerf_depths_train, 
    dense_nerf_depths_test
):
    """
    Generates visibility masks for test views based on depth consistency with training views.
    
    Args:
        train_views: List of training view objects with 'id', 'pose', 'intrinsics'.
        test_views: List of test view objects with 'id', 'pose', 'intrinsics'.
        dense_nerf_depths_train: Dict mapping train view id to depth map (HxW float array).
        dense_nerf_depths_test: Dict mapping test view id to depth map (HxW float array).
        
    Returns:
        masks: Dict mapping test view id to binary visibility mask (HxW uint8 array).
    """
    masks = {}
    
    # Calculate threshold: 0.05 times the maximum depth of the training view [S1, S2]
    all_train_depths = list(dense_nerf_depths_train.values())
    global_max_depth = max(np.max(d) for d in all_train_depths)
    threshold = 0.05 * global_max_depth
    
    for test_view in test_views:
        test_id = test_view.id
        test_depth = dense_nerf_depths_test[test_id]
        H, W = test_depth.shape
        visibility_count = np.zeros((H, W), dtype=np.int32)
        
        for train_view in train_views:
            train_id = train_view.id
            train_depth = dense_nerf_depths_train[train_id]
            
            # [G] Standard depth reprojection: unproject train depth to 3D, transform to test camera space, 
            # project to test image plane, and interpolate. Returns warped_depth_map and valid_mask.
            warped_depth, valid_mask = reproject_depth(
                train_depth, 
                train_view.pose, 
                train_view.intrinsics, 
                test_view.pose, 
                test_view.intrinsics
            )
            
            # Compute absolute depth difference [S1]
            diff = np.abs(warped_depth - test_depth)
            
            # Check against threshold [S2]
            # A pixel is visible in this training view if warping was valid and depth difference < threshold
            is_visible = (valid_mask == True) & (diff < threshold)
            
            # Increment visibility count [S2]
            visibility_count += is_visible.astype(np.int32)
        
        # Final mask: visible if seen in at least 2 training views [S1, S2]
        mask = (visibility_count >= 2).astype(np.uint8)
        masks[test_id] = mask
        
    return masks

def reproject_depth(depth_src, pose_src, intrinsics_src, pose_tgt, intrinsics_tgt):
    # [G] Standard geometric reprojection. Unprojects pixels to 3D using source intrinsics/pose,
    # transforms points to target camera coordinates using target pose, projects to 2D using target intrinsics,
    # and bilinearly samples the source depth onto the target grid.
    H, W = depth_src.shape
    fx, fy, cx, cy = intrinsics_src[0,0], intrinsics_src[1,1], intrinsics_src[0,2], intrinsics_src[1,2]
    u, v = np.meshgrid(np.arange(W), np.arange(H))
    X = (u - cx) / fx * depth_src
    Y = (v - cy) / fy * depth_src
    Z = depth_src
    pts_3d = np.stack([X, Y, Z, np.ones_like(Z)], axis=-1)
    
    pts_world = (np.linalg.inv(pose_src) @ pts_3d.T).T[:, :3]
    pts_tgt_cam = (pose_tgt @ np.concatenate([pts_world, np.ones((pts_world.shape[0], 1))], axis=-1).T).T[:, :3]
    
    u_tgt = pts_tgt_cam[:, 0] / pts_tgt_cam[:, 2]
    v_tgt = pts_tgt_cam[:, 1] / pts_tgt_cam[:, 2]
    
    # Clip to image bounds and interpolate
    valid_mask = (u_tgt >= 0) & (u_tgt < W) & (v_tgt >= 0) & (v_tgt < H)
    u_tgt_clipped = np.clip(u_tgt, 0, W - 1)
    v_tgt_clipped = np.clip(v_tgt, 0, H - 1)
    
    warped_depth = np.zeros_like(depth_src)
    warped_depth[valid_mask] = depth_src[v_tgt_clipped[valid_mask].astype(int), u_tgt_clipped[valid_mask].astype(int)]
    
    return warped_depth, valid_mask
```

**Edge Cases and Pitfalls:**
- Mask accuracy is entirely dependent on the accuracy of the Dense-NeRF depth estimation; incorrect Dense-NeRF depths produce incorrect masks [S1, S2].
- Using depth instead of color makes the mask robust to specular objects [S1, S2]. Color-based reprojection fails on specular surfaces [S2].
- If Dense-NeRF depth estimates are inaccurate, the mask will be incorrect [S1, S2].

## Subtopics

### [Masked Evaluation (Depth-based Visibility Mask Generation)](8648-masked-evaluation-depth-based-visibility-mask-generation.md)
This method identifies pixels in a reference view that are occluded (invisible) when viewed from a new camera pose by comparing the reference depth map with the depth map warped from the new view. It is used to generate masks that restrict evaluation or inpainting to visible regions, preventing metric degradation from predicting unseen geometry.

## Operating characteristics
- **Time Complexity:** $O(N \cdot M \cdot H \cdot W)$, where $N$ is the number of training views, $M$ is the number of test views, and $H \times W$ is the image resolution. Each training view is warped to each test view [G].
- **Memory Complexity:** $O(N \cdot H \cdot W + M \cdot H \cdot W)$ to store depth maps and visibility counters [G].
- **Strengths:** Prevents metric degradation from predicting unseen geometry [S1, S2]. Robust to specular objects compared to color-based methods [S1, S2]. Ensures evaluation is restricted to geometrically consistent regions [S2].
- **Limitations:** Highly dependent on the accuracy of the Dense-NeRF depth estimation [S1, S2]. If depth estimates are poor, masks are incorrect [S1, S2].
- **When to use:** When evaluating NeRFs on sparse input views where unseen regions would otherwise inflate error metrics [S1, S2].
- **When not to use:** When the goal is to evaluate the model's ability to hallucinate or predict unseen regions (though NeRFs are not designed for this by default [S1, S2]).

## Background
Masked Evaluation was introduced in the context of regularizing sparse input Neural Radiance Fields (NeRFs) to prevent them from being evaluated on regions they cannot predict by design [S1, S2]. Radiance fields are designed to memorize a scene and are ill-equipped to predict unseen regions or the depth of objects seen in only one input view [S1, S2]. The method was proposed in "SimpleNeRF" [S1] and "Simple-RF" [S2] to ensure fair comparison of models by restricting evaluation to pixels visible in at least two training views. The depth-based reprojection technique follows prior work by Cho et al. [2017] and Kanchana et al. [2022] [S1, S2].
