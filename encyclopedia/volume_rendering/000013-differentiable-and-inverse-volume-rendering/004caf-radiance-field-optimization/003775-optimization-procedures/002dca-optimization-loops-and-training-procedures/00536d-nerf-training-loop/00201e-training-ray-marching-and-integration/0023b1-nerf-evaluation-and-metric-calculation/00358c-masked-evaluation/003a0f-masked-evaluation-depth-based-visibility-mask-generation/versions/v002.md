# Masked Evaluation (Depth-based Visibility Mask Generation)

Also called: Depth reprojection masking, Invisible Mask Computation, Invisible Region Detection via Depth Warping

## Overview
This method identifies pixels in a reference view that are occluded (invisible) when viewed from a new camera pose by comparing the reference depth map with the depth map warped from the new view [S1]. It generates binary masks that restrict evaluation or inpainting to visible regions, preventing metric degradation from predicting unseen geometry [S1]. While the primary formulation operates directly on rendered depth maps to guide RGBD inpainting [S1], a variant adapts the same depth-reprojection principle to generate consistency masks for feature-level regularization [S2, unofficial].

## How it works
**Inputs:**
*   Reference view depth map $I_d$ and target view depth map $I'_d$ [S1].
*   Camera intrinsics $K$, inverse intrinsics $K^{-1}$, and relative rotation $R_{j \to i}$ between views [S2, unofficial].
*   Threshold $\varepsilon$ for depth difference [S1] or $\tau$ for geometric consistency [S2, unofficial].

**Outputs:**
*   Final invisible mask $m$ (binary, 1 for invisible, 0 for visible) [S1].
*   Masked inputs $\bar{I}_{rgb}$ and $\bar{I}_d$ for subsequent processing (e.g., inpainting) [S1].

**Data Structures:**
*   Depth maps: 2D arrays of floating-point values representing distance from the camera center [S1][S2, unofficial].
*   Masks: 2D binary arrays of identical dimensions to the depth maps [S1][S2, unofficial].

**Steps:**
1.  For each pixel $p_j$ in the target view, compute its 3D position using the target depth $D_j(p_j)$ and inverse intrinsics $K^{-1}$ [S2, unofficial].
2.  Transform the 3D point to the reference camera frame using the relative rotation $R_{j \to i}$ [S2, unofficial].
3.  Project the transformed 3D point back to the reference image plane to obtain continuous coordinates $p_{j \to i}$ [S2, unofficial].
4.  Sample the reference depth $D_i(p_{j \to i})$ at the projected coordinates [S1][S2, unofficial].
5.  Compare the sampled reference depth with the original target depth $D_j(p_j)$ [S1][S2, unofficial].
6.  Apply the indicator function with threshold $\varepsilon$ to generate the per-view mask $m'$ [S1].
7.  Compute the final mask $m$ by performing a logical AND across all per-view masks $m'$ [S1].
8.  Apply $m$ to the RGB and depth inputs to produce masked versions for inpainting or loss computation [S1].

**Formulas:**
*   **Basic Visibility Mask (Single View Pair):**
    $$m'_{ij} = \mathbb{I}(\text{warp}(v'_{ij}) - v_{ij} > \varepsilon)$$
    where $m'_{ij}$ is the mask pixel (1 for invisible, 0 for visible), $\text{warp}(\cdot)$ is the geometric warping function, $v_{ij}$ is the reference depth, $v'_{ij}$ is the warped depth, and $\varepsilon$ is a small error tolerance [S1].
*   **Occlusion-Aware Mask (Feature-Level):**
    $$M(p_j) = [\|D_j(p_j) - D_i(p_{j \to i})\| < \tau]$$
    where $[\cdot]$ is the Iverson bracket, $p_{j \to i}$ is the reprojected pixel coordinate, and $\tau$ is a geometric consistency threshold [S2, unofficial].
*   **Final Invisible Mask:**
    $$m = \bigwedge_{k} m'_k$$
    where the logical AND operation combines masks from all reference views [S1].
*   **Masked Inputs:**
    $$\bar{I}_{rgb} = I_{rgb} \otimes (1 - m)$$
    $$\bar{I}_d = I_d \otimes (1 - m)$$
    where $\otimes$ denotes element-wise multiplication [S1].

**Parameters:**
*   $\varepsilon$: Small threshold for depth difference to tolerate minor warping inaccuracies [S1]. Value not specified in the sources.
*   $\tau$: Threshold determining if two rays render depths of separate surfaces; pixels are masked if the depth distance exceeds $\tau$ [S2, unofficial]. Value not specified in the sources.

**Edge Cases and Pitfalls:**
*   Erroneous geometry causes imperfect warpings that generate false occlusions [S2, unofficial].
*   Self-occlusion and geometric artifacts prevent correct warping, requiring explicit masking [S2, unofficial].
*   Large occlusions in complex panoramic scenes may overwhelm simple inpainting if not handled collaboratively [S1].

**Pseudocode:**
```python
def mat_vec(M, v):
    """Standard matrix-vector multiplication."""
    return [sum(M[r][c] * v[c] for c in range(len(v))) for r in range(len(M))]

def generate_visibility_mask(reference_depth, target_depth, K, K_inv, R, epsilon):
    """
    Generates an invisible mask by warping target depth to the reference view.
    Args:
        reference_depth: 2D list of floats, shape (H, W).
        target_depth: 2D list of floats, shape (H, W).
        K: 3x3 list of lists, camera intrinsic matrix.
        K_inv: 3x3 list of lists, inverse camera intrinsic matrix.
        R: 3x3 list of lists, relative rotation matrix R_{j->i}.
        epsilon: float, depth difference threshold.
    Returns:
        invisible_mask: 2D list of bools, shape (H, W).
    """
    H, W = len(reference_depth), len(reference_depth[0])
    invisible_mask = [[False] * W for _ in range(H)]

    for j in range(H):
        for i in range(W):
            # Homogeneous pixel coordinate in target view
            p_j = [float(i), float(j), 1.0]

            # 1. Back-project to 3D in target frame, scale by depth
            X_tgt = mat_vec(K_inv, p_j)
            X_tgt = [X_tgt[k] * target_depth[j][i] for k in range(3)]

            # 2. Transform to reference camera frame
            X_ref = mat_vec(R, X_tgt)

            # 3. Project to reference image plane
            p_j_to_i = mat_vec(K, X_ref)

            # 4. Normalize homogeneous coordinates
            if p_j_to_i[2] != 0:
                u_proj = p_j_to_i[0] / p_j_to_i[2]
                v_proj = p_j_to_i[1] / p_j_to_i[2]

                # 5. Sample reference depth at projected coordinates
                u_idx = int(round(u_proj))
                v_idx = int(round(v_proj))

                if 0 <= v_idx < H and 0 <= u_idx < W:
                    v_ref = reference_depth[v_idx][u_idx]
                    v_tgt = target_depth[j][i]

                    # 6. Apply visibility condition: warped depth > reference depth + epsilon implies occlusion
                    if v_tgt - v_ref > epsilon:
                        invisible_mask[j][i] = True

    return invisible_mask
```

## Subtopics

### Occlusion-Aware Masking
A technique that generates a consistency mask $M_l$ to ignore regions with geometric inconsistencies (artifacts, self-occlusion) during feature-level regularization [S2, unofficial]. It differs from basic depth reprojection masking by applying the mask to downsampled feature maps rather than raw RGB/depth images [S2, unofficial]. It is chosen when enforcing geometric consistency at the feature level prevents distorted warpings from degrading reconstruction quality [S2, unofficial]. See [GeCoNeRF](https://core.ac.uk/works/309257742).

## Operating characteristics
*   **Time Complexity:** Linear $O(N)$ with respect to the number of pixels $N$, as it requires per-pixel reprojection and depth comparison [S1][S2, unofficial].
*   **Memory Complexity:** Linear $O(N)$, requiring storage for depth maps, masks, and intermediate 3D coordinates [S1][S2, unofficial].
*   **Strengths:** Accurately isolates invisible regions for targeted inpainting [S1]; effectively filters geometric inconsistencies during feature consistency regularization [S2, unofficial].
*   **Limitations:** Highly sensitive to warping errors and geometric artifacts [S2, unofficial]; struggles with large occlusions without auxiliary inpainting strategies [S1].
*   **When to Use:** Multi-view radiance field evaluation or inpainting where occlusion handling is critical [S1][S2, unofficial].
*   **When Not to Use:** Single-view reconstruction or scenarios where occlusion masking is unnecessary [S1].

## Background
Originated in NeRF training pipelines to handle invisible regions in panoramic scenes [S1]. It was developed to overcome the failure of adversarial learning and semantic constraints in filling large occlusions [S1]. The depth-reprojection principle was later adapted for few-shot NeRF methods to enforce geometric consistency at the feature level [S2, unofficial].
