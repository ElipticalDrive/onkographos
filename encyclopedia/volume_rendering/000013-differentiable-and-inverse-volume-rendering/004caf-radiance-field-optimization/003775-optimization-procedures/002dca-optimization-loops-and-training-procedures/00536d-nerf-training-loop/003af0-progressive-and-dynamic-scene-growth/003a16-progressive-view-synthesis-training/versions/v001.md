# Progressive View Synthesis Training

Also called: PERF training loop, collaborative RGBD inpainting and progressive inpainting-and-erasing

## Overview
Progressive View Synthesis Training (PERF) is a training strategy for Panoramic Neural Radiance Fields (NeRF) that reconstructs a 3D scene from a single input panorama by progressively adding synthetic reference views to resolve occlusions and improve semantic coherence [S1]. It distinguishes itself from sibling methods like [DS-NeRF](8679-single-view-nerf-training-with-depth-map.md) and [DietNeRF](8669-nerf-ff.md) by replacing generic depth constraints or semantic regularization with a collaborative RGBD inpainting and progressive inpainting-and-erasing pipeline, which explicitly synthesizes plausible content for occluded regions rather than relying on geometric priors or feature matching alone [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A single input RGB-D panorama (color and depth map) [S1].
*   A pre-trained inpainting model (specifically Stable Diffusion 2) [S1].
*   NeRF representation parameters (Instant-NGP hash grid) [S1].

**Outputs:**
*   Optimized NeRF model parameters capable of synthesizing novel views from arbitrary panoramic poses [S1].

### Data Structures
The method relies on the Instant-NGP representation implemented via the NeRFAcc framework [S1]. The core data structure is the hash grid:
*   **Hash Table Size:** $2^{19}$ entries [S1].
*   **Levels:** 16 levels of feature vectors [S1].
*   **Channel Size:** 2 per feature vector [S1].

### Numbered Steps

1.  **Initial Training:** Train the NeRF model using only the single input panorama for 10,000 iterations [S1].
2.  **View Sampling:** Progressively sample 32 new camera positions. These positions are distributed with gradually increased distance from the original reference panorama view position [S1].
3.  **Iterative View Addition:** For each of the 32 newly sampled positions, perform the following sub-routine:
    a.  **Collaborative RGBD Inpainting:**
        i.  Identify masked regions in the target panorama view that correspond to occluded areas not visible in the current set of reference views.
        ii. Project these masked regions from the panoramic projection to perspective views to avoid distortion artifacts inherent in applying perspective-trained inpainting models to equirectangular projections [S1].
        iii. Apply the pre-trained Stable Diffusion 2 inpainting model to the perspective views to generate plausible color and depth content [S1].
        iv. Project the inpainted regions back to the panoramic projection [S1].
    b.  **Progressive Inpainting-and-Erasing:** This strategy prevents geometry conflicts arising from different views, which cause redundant geometry and degraded RGB quality [S1]. (Specific algorithmic details of the erasing mechanism are not provided in the source, but it is applied after inpainting) [S1].
    c.  **NeRF Optimization:** Continue training the NeRF for 2,000 iterations using the new reference view:
        i.  **First 100 iterations:** Supervise the NeRF using *only* the new reference view (the inpainted panorama) [S1].
        ii. **Remaining 1,900 iterations:** Supervise the NeRF using *all* available reference views (the original input plus all previously added synthetic views) [S1].
4.  **Ray Sampling:** At each iteration, randomly sample 2,048 rays. These rays are supervised using ground-truth or inpainted colors and depth values [S1].
5.  **Optimization:** Use the Adam optimizer to update NeRF parameters [S1].

### Formulas and Parameters

**Loss Function:**
The method employs a distortion loss to regularize the NeRF and prevent "foggy effects" or "floating" densities, encouraging volume densities to converge to valid surfaces [S1].
$$ L_{dist} = \lambda_{dist} \cdot \text{DistortionLoss} $$
*   $\lambda_{dist}$ (distortion loss weight): 1 [S1].

**Learning Rate Schedule:**
For each learning stage corresponding to a newly sampled view, the learning rate follows a cosine annealing strategy [S1]:
*   Initial learning rate ($\eta_{start}$): $10^{-3}$ [S1].
*   Decayed learning rate ($\eta_{end}$): $10^{-4}$ [S1].

**Hyperparameters:**
*   Initial training iterations: 10,000 [S1].
*   Number of progressively sampled new positions: 32 [S1].
*   Training iterations per new view: 2,000 [S1].
*   Supervision iterations using only new view: 100 [S1].
*   Supervision iterations using all views: 1,900 [S1].
*   Rays sampled per iteration: 2,048 [S1].

### Edge Cases and Pitfalls
*   **Panorama Distortion:** Inpainting models trained on perspective FOV cannot be directly applied to panoramas due to distortion. The method must project masked regions to perspective views, inpaint, and project back [S1].
*   **Foggy Effects/Floating Densities:** NeRF may produce invalid surfaces ("foggy effects") instead of converging to valid geometry. This is mitigated by using distortion loss with weight $\lambda_{dist} = 1$ [S1].
*   **Geometry Conflicts:** Without the inpainting-and-erasing strategy, adding multiple views can lead to conflicting geometry, resulting in redundant structures and degraded RGB quality [S1].

## Operating characteristics

**Time and Memory Complexity:**
*   Training a scene typically takes about 2 hours on a single Nvidia V100 GPU with 32GB memory [S1].
*   The Instant-NGP hash grid ($2^{19}$ entries, 16 levels, 2 channels) provides efficient memory usage and fast lookups, contributing to the rapid training time [S1].

**Measured Performance:**
*   On the Replica dataset, PERF achieves the best performance among compared methods in PSNR (23.49), SSIM (0.838), and LPIPS (0.244) [S1].
*   It shows significant improvement in masked PSNR (12.63), demonstrating superior inpainting of invisible regions compared to DS-NeRF (11.73), DietNeRF (11.52), SinNeRF (9.80), 360FusionNeRF (11.87), and Omni-NeRF (10.42) [S1].
*   In user studies, 81% of 29 users preferred PERF results over DS-NeRF, SinNeRF, and DietNeRF [S1].

**Strengths and Limitations:**
*   **Strengths:** Superior semantic coherence in occluded regions compared to methods relying on depth constraints (DS-NeRF) or semantic regularization (DietNeRF, SinNeRF) [S1]. Better visual quality than Omni-NeRF, which suffers from blurring due to lack of geometric regularization [S1].
*   **Limitations:** Relies on the quality of the pre-trained inpainting model (Stable Diffusion 2) [S1]. The progressive addition of views increases computational cost linearly with the number of synthetic views, though the total time remains manageable (~2 hours) [S1].

**When to Use:**
*   Single panorama novel view synthesis.
*   3D virtual tours, VR games/conferences, filmmaking, text-to-3D, and 3D scene stylization [S1].

**When Not to Use:**
*   Scenes where high-fidelity semantic inpainting is not required and geometric priors are sufficient (simpler methods like DS-NeRF may suffice).
*   Real-time applications requiring immediate reconstruction without iterative view synthesis.

## Background

**Origin:**
The method was introduced in the paper "PERF: Panoramic Neural Radiance Field From a Single Panorama" [S1]. It addresses the challenge of reconstructing 3D scenes from a single panoramic image, a task where traditional NeRF methods struggle with occluded regions and lack of geometric constraints.

**History and Development:**
The method builds upon Instant-NGP for efficient NeRF representation [S1] and integrates Stable Diffusion 2 for semantic inpainting [S1]. It was developed to overcome limitations of existing few-shot NeRF techniques (DS-NeRF, DietNeRF, SinNeRF) and single panorama works (Omni-NeRF, 360FusionNeRF) which either fail to synthesize occluded regions well or produce blurred results due to insufficient geometric regularization [S1].

**Usage:**
PERF is used in applications requiring high-quality novel view synthesis from limited input, such as virtual tours and 3D scene stylization [S1].
