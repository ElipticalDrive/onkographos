# 360FusionNeRF

Also called: 360FusionNeRF: Panoramic Neural Radiance Fields with Joint Guidance

## Overview
360FusionNeRF is a semi-supervised learning framework for synthesizing novel views from a single 360° RGB-D panorama image [S1]. It extends OmniNeRF by introducing geometric supervision via auxiliary depth maps and semantic consistency via CLIP features to guide progressive training and reduce artifacts caused by occlusion in unobserved regions [S1]. Unlike standard NeRF methods that rely solely on color reconstruction, 360FusionNeRF explicitly penalizes geometric errors and semantic inconsistencies to improve perceptual quality and generalizability [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A single 360° RGB-D panoramic image.
*   **Output:** A trained neural radiance field (MLP) capable of rendering novel views from arbitrary camera poses.

**Data Structures**
The method uses a standard Multi-Layer Perceptron (MLP) to represent the radiance field, mapping 3D coordinates and viewing directions to volume density ($\sigma$) and color ($c$). The specific architecture details (layer sizes, activation functions) are not provided in the sources [S1]. The training process involves two networks: a coarse network and a refined network, which are identical in structure but differ in sampling strategies [S1].

**Numbered Steps**
1.  **Virtual Camera Reprojection:** The input 360° panorama is re-projected to generate 360° images at virtual camera positions. Auxiliary depth maps are extracted at these virtual positions [S1].
2.  **Hierarchical Sampling:**
    *   **Coarse Stage:** $N_c$ intervals are uniformly sampled along each training ray [S1].
    *   **Refined Stage:** $N_f$ intervals are sampled based on the density estimates from the coarse stage [S1].
3.  **Volumetric Rendering:** For each ray $r$, the rendered color $\hat{C}(r)$ is computed using the standard volume rendering equation for both coarse and refined stages [S1].
4.  **Loss Computation:** The total loss is the sum of three components:
    *   **Color Reconstruction Loss ($L_{Color}$):** Mean squared error between rendered color and ground truth color at input poses [S1].
    *   **Geometric Loss ($L_{Geo}$):** Supervision using the auxiliary depth maps extracted at virtual camera positions [S1].
    *   **Semantic Consistency Loss ($L_{Sem}$):** Encourages realistic renderings by comparing CLIP Vision Transformer activations of the rendered novel views against the input panorama [S1].
5.  **Optimization:** The radiance field is optimized by minimizing the combined loss [S1].

**Formulas**
The rendered color $\hat{C}(r)$ for a ray $r(t) = o + td$ is computed as [S1]:

$$
\hat{C}(r) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) c_i
$$

where:
*   $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance.
*   $\delta_i = t_{i+1} - t_i$ is the interval between adjacent samples.
*   $c_i$ is the color at sample $i$.
*   $\sigma_i$ is the volume density at sample $i$.

The color reconstruction loss is defined as [S1]:

$$
L_{Color} = \sum_{r \in R_i} ||(C(r) - \hat{C}(r))||^2
$$

where $R_i$ is the set of input rays during training and $C(r)$ is the ground truth color [S1].

**Parameters**
*   $N_c$: Number of intervals uniformly sampled along the ray during the coarse stage. Value not given in the sources.
*   $N_f$: Number of intervals decided in accordance with densities from the coarse stage during the refined stage. Value not given in the sources.

**Pseudocode**
```python
def train_360fusionnerf(input_panorama_rgb, input_panorama_depth, virtual_cameras, clip_model):
    """
    Trains the 360FusionNeRF radiance field.
    
    Args:
        input_panorama_rgb: RGB data of the single 360° panorama.
        input_panorama_depth: Depth data of the single 360° panorama.
        virtual_cameras: List of virtual camera poses for reprojection.
        clip_model: Pre-trained CLIP Vision Transformer.
        
    Returns:
        trained_nerf: The optimized neural radiance field.
    """
    # Initialize coarse and refined MLPs
    coarse_nerf = initialize_mlp()
    refined_nerf = initialize_mlp()
    
    # Extract auxiliary depth maps at virtual camera positions
    # This involves re-projecting the input panorama to virtual views
    auxiliary_depths = reproject_panorama_to_virtual_views(
        input_panorama_rgb, 
        input_panorama_depth, 
        virtual_cameras
    )
    
    # Define optimizer
    optimizer = Adam([coarse_nerf.parameters(), refined_nerf.parameters()])
    
    for epoch in range(num_epochs):
        total_loss = 0
        
        # Sample training rays from input panorama poses
        rays = sample_rays_from_panorama(input_panorama_rgb)
        
        for ray in rays:
            # 1. Coarse Sampling
            # Uniformly sample Nc intervals along the ray
            coarse_samples = uniform_sample(ray, Nc)
            
            # Query coarse MLP for density and color
            coarse_sigma, coarse_color = coarse_nerf(coarse_samples)
            
            # Render coarse color
            coarse_rendered_color = volume_render(coarse_samples, coarse_sigma, coarse_color)
            
            # 2. Refined Sampling
            # Sample Nf intervals based on coarse densities
            refined_samples = importance_sample(ray, coarse_sigma, Nf)
            
            # Query refined MLP for density and color
            refined_sigma, refined_color = refined_nerf(refined_samples)
            
            # Render refined color
            refined_rendered_color = volume_render(refined_samples, refined_sigma, refined_color)
            
            # 3. Compute Losses
            # Color Loss (MSE between rendered and ground truth)
            gt_color = get_ground_truth_color(ray)
            loss_color = mse(refined_rendered_color, gt_color)
            
            # Geometric Loss (using auxiliary depth)
            # Note: Exact formulation of geometric loss is not provided in sources [S1]
            # It uses the auxiliary depth maps extracted at virtual positions
            loss_geo = compute_geometric_loss(
                refined_samples, 
                refined_sigma, 
                auxiliary_depths, 
                ray.camera_pose
            )
            
            # Semantic Consistency Loss (using CLIP)
            # Render a novel view from a virtual camera
            novel_view = render_novel_view(refined_nerf, virtual_cameras)
            
            # Extract CLIP features from input panorama and novel view
            input_features = clip_model.encode(input_panorama_rgb)
            novel_features = clip_model.encode(novel_view)
            
            # Compute semantic consistency loss
            # Note: Exact formulation of semantic loss is not provided in sources [S1]
            loss_sem = compute_semantic_loss(input_features, novel_features)
            
            # Total Loss
            loss = loss_color + loss_geo + loss_sem
            
            # Backpropagation
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            total_loss += loss.item()
            
    return refined_nerf
```

**Edge Cases and Pitfalls**
*   **Occlusion Artifacts:** The method specifically addresses artifacts caused by occlusion in unobserved regions, which are common when using only neighborhood interpolation [S1].
*   **Overfitting:** Standard OmniNeRF can overfit to training views; 360FusionNeRF mitigates this through geometric and semantic supervision [S1].
*   **Depth Extraction:** The accuracy of the geometric loss depends on the quality of the auxiliary depth maps extracted from the single input panorama [S1].

## Subtopics

### [OmniNeRF](link-to-omninerf.md)
The base method for 360° NeRFs that 360FusionNeRF extends. It suffers from overfitting and occlusion artifacts.

### [CLIP Vision Transformer](link-to-clip.md)
The pre-trained visual encoder used for semantic consistency supervision.

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** The method produces plausible completions of unobserved regions while preserving scene features, improving perceptual quality compared to prior studies [S1].
*   **Strengths:** Reduces artifacts from occlusion; improves geometry and perceptual quality through joint geometric and semantic supervision; works with a single input image.
*   **Limitations:** Relies on the quality of the single input panorama; requires a pre-trained CLIP model; specific hyperparameters ($N_c, N_f$) are not disclosed.
*   **When to use:** When novel views must be synthesized from a single 360° RGB-D panorama and occlusion artifacts are a concern.
*   **When not to use:** When multiple input views are available (standard NeRF or other multi-view methods may be more appropriate); when computational resources for CLIP inference are limited.

## Background
360FusionNeRF was proposed by Shreyas Kulkarni, Peng Yin, and Sebastian Scherer in 2022 [S1]. It was published in IEEE Robotics and Automation Letters (RA-L) in 2023, with an arXiv preprint available since September 2022 [S1]. The method addresses the limitations of OmniNeRF, which relies on multi-layer perceptron interpolation to complete missing regions, leading to artifacts [S1].
