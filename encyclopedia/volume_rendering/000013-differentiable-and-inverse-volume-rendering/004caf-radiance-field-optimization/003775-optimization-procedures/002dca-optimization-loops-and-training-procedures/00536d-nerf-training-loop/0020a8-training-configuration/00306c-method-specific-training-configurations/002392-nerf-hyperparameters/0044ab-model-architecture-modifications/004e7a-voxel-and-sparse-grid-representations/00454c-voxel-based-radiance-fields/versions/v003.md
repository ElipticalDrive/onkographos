# Voxel-based Radiance Fields

Also called: Voxel NeRF, Voxel Radiance Fields

## Overview
Voxel-based Radiance Fields replace the multi-layer perceptron (MLP) of standard Neural Radiance Fields with explicit 3D voxel grids to store volume density and spherical harmonic (SH) coefficients, enabling real-time differentiable volume rendering [S1]. Unlike MLP-based approaches that require heavy feed-forward computation for every sample point, this method computes color and density directly via trilinear interpolation from the grid, significantly reducing latency while maintaining the memory-efficient framework of sparse voxel representations [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A ray $r$ defined by origin $\mathbf{o}$ and direction $\mathbf{d}$, sampled at $N$ points $\mathbf{X}_k$ along the ray.
*   **Output:** The rendered color $\hat{C}(r)$ and its gradient for backpropagation.

**Data Structures**
Two dense or sparse voxel grids are maintained:
1.  **Density Grid ($G_\sigma$):** Maps 3D coordinates to a scalar.
    *   Layout: $G_\sigma: \mathbb{R}^3 \rightarrow \mathbb{R}$.
    *   Content: Volume density $\sigma$.
2.  **SH Coefficient Grid ($G_{sh}$):** Maps 3D coordinates to a vector of SH coefficients.
    *   Layout: $G_{sh}: \mathbb{R}^3 \rightarrow \mathbb{R}^{9 \times 3}$.
    *   Content: Degree 2 spherical harmonic coefficients for RGB color. The dimension $9$ corresponds to the number of basis functions for degree 2 SH, and $3$ corresponds to the RGB channels.

**Algorithm Steps**
1.  **Sample Points:** Generate $N$ sample points $\mathbf{X}_k$ along the ray $r$ within the bounding volume of the scene.
2.  **Retrieve Density:** For each point $\mathbf{X}_k$, perform trilinear interpolation on the nearest 8 voxels of $G_\sigma$ to obtain the volume density $\sigma_k$ [S1]:
    $$
    \sigma_k = \mathcal{G}_\sigma(\mathbf{X}_k)
    $$
3.  **Retrieve SH Coefficients:** For each point $\mathbf{X}_k$, perform trilinear interpolation on the nearest 8 voxels of $G_{sh}$ to obtain the SH coefficient vector $\mathbf{v}_k$ [S1]:
    $$
    \mathbf{v}_k = \mathcal{G}_{sh}(\mathbf{X}_k)
    $$
4.  **Compute Color:** Map the viewing direction $\mathbf{d}$ to a SH basis vector $\mathbf{S}(\mathbf{d}) \in \mathbb{R}^9$ using the degree 2 spherical harmonic functions. Compute the color $\mathbf{c}_k \in \mathbb{R}^3$ by projecting the SH coefficients onto the basis [S1]:
    $$
    \mathbf{c}_k = \mathbf{S}(\mathbf{d})^\intercal \cdot \mathbf{v}_k
    $$
    *Note: The source defines $\mathbf{c}_k = S(\mathbf{d})^\intercal \cdot \mathcal{G}_{sh}(\mathbf{X}_k)$, implying the dot product between the SH basis vector and the interpolated coefficient vector.*
5.  **Volume Rendering:** Compute opacity $\alpha_k$ and transmittance $T_k$ using the standard differentiable volume rendering equation [S1]:
    $$
    \alpha_k = 1 - e^{-\sigma_k \delta_k}
    $$
    $$
    T_k = \prod_{j=1}^{k-1} (1 - \alpha_j)
    $$
    $$
    w_k = T_k \alpha_k
    $$
    $$
    \hat{C}(r) = \sum_{k=1}^{N} w_k \mathbf{c}_k
    $$
    where $\delta_k$ is the distance between adjacent sample points.

**Pseudocode**
```python
def render_voxel_nerf(ray_origin, ray_direction, grid_sigma, grid_sh, num_samples):
    """
    Renders a single ray using voxel-based radiance fields.
    
    Args:
        ray_origin: (3,) float, origin of the ray.
        ray_direction: (3,) float, normalized direction of the ray.
        grid_sigma: VoxelGrid object storing density, supports trilinear interpolation.
        grid_sh: VoxelGrid object storing SH coefficients (shape 9x3 per voxel), supports trilinear interpolation.
        num_samples: int, number of sample points along the ray.
        
    Returns:
        color: (3,) float, rendered RGB color.
        transmittance: float, final transmittance.
    """
    # 1. Sample points along the ray
    # Assuming a fixed step size or bounding box intersection logic is handled externally.
    # For simplicity, we assume sample_positions is pre-computed as (num_samples, 3).
    sample_positions = sample_along_ray(ray_origin, ray_direction, num_samples)
    
    accumulated_color = np.zeros(3)
    accumulated_transmittance = 1.0
    
    for i in range(num_samples):
        x_k = sample_positions[i]
        
        # 2. Retrieve density via trilinear interpolation
        sigma_k = grid_sigma.interpolate(x_k)
        
        # 3. Retrieve SH coefficients via trilinear interpolation
        # grid_sh returns a vector of size 9*3 = 27 if flattened, or (9, 3)
        sh_coeffs = grid_sh.interpolate(x_k) # Shape: (9, 3)
        
        # 4. Compute color
        # S(d) is the SH basis vector for degree 2, shape (9,)
        sh_basis = spherical_harmonic_basis(ray_direction, degree=2)
        
        # Color is the dot product of SH basis and coefficients for each channel
        # sh_coeffs is (9, 3), sh_basis is (9,)
        # Resulting color is (3,)
        color_k = np.dot(sh_basis, sh_coeffs)
        
        # 5. Volume rendering step
        # delta_k is the distance to the next sample. 
        # If not provided, assume uniform spacing or compute from positions.
        if i < num_samples - 1:
            delta_k = np.linalg.norm(sample_positions[i+1] - x_k)
        else:
            delta_k = 0.0 # Last sample contributes nothing if delta is 0, or handled by epsilon
            
        alpha_k = 1.0 - np.exp(-sigma_k * delta_k)
        
        weight = accumulated_transmittance * alpha_k
        accumulated_color += weight * color_k
        accumulated_transmittance *= (1.0 - alpha_k)
        
        # Early termination optimization can be added here if accumulated_transmittance is very small
        
    return accumulated_color, accumulated_transmittance
```

**Edge Cases and Pitfalls**
*   **Boundary Conditions:** Trilinear interpolation requires valid neighbors. If $\mathbf{X}_k$ falls outside the voxel grid bounds, values must be clamped or padded with zero density/neutral color [G].
*   **SH Basis Normalization:** The SH basis function $S(\mathbf{d})$ must be correctly normalized to ensure energy conservation and correct color representation [S1].
*   **Sparse Grids:** If sparse voxel structures (e.g., hash tables) are used instead of dense grids, the interpolation logic must handle missing voxels by returning zero or a default value, which may introduce artifacts at the boundary of the sparse region [G].

## Operating characteristics
*   **Time Complexity:** $O(N)$ per ray, where $N$ is the number of samples. The constant factor is significantly lower than MLP-based NeRF because it replaces multiple matrix multiplications (fully connected layers) with simple trilinear interpolation and a single dot product [S1].
*   **Memory Complexity:** $O(V \cdot D)$, where $V$ is the number of voxels and $D$ is the feature dimension (1 for density, 27 for SH coefficients). This is generally more memory-efficient than MLPs for high-resolution scenes because parameters are shared across space via the grid structure [S1].
*   **Performance:** Enables real-time volume rendering on standard hardware, whereas MLP-based NeRF typically requires offline training and slow inference [S1].
*   **Strengths:** Real-time rendering capability, memory efficiency through sparse voxel reconstruction, and simplified training pipeline [S1].
*   **Limitations:** Limited by the resolution of the voxel grid; fine details may be lost if the grid is too coarse. Trilinear interpolation may introduce blurring compared to learned MLP representations [G].

## Background
Voxel-based Radiance Fields were introduced as a memory-efficient alternative to MLP-based Neural Radiance Fields (NeRF) [S1]. The approach leverages the differentiable volume rendering framework of NeRF but replaces the neural network with explicit voxel grids for density and spherical harmonic coefficients [S1]. This method was notably applied in the context of extreme motion blur reconstruction (ExBluRF), demonstrating its utility in optimization tasks where real-time feedback is beneficial [S1]. The technique builds on the principles of sparse voxel representations, combining coarse-to-fine reconstruction with pruning strategies to maintain efficiency [S1].
