# Neural Multi-View Image Reconstruction with Hash Encoding

Also called: Ours (multi-view)

## Overview
This method performs neural multi-view image reconstruction and novel view synthesis by combining hash encoding for spatial feature storage with a signed distance function (SDF) based geometry representation [S1]. It solves the problem of reconstructing high-frequency geometric details and synthesizing novel views from multi-view images more efficiently than prior neural implicit methods [S1]. It is distinguished from sibling methods like [Voxel-based Radiance Fields](11470-voxel-based-radiance-fields.md) by using a hash table for feature storage rather than a dense or sparse voxel grid, and from [NeRF](link) by explicitly optimizing an SDF for geometry rather than volume density, which avoids the noise and roughness associated with unconstrained density fields [S1].

## How it works
The method consists of two main networks: a geometry network that predicts the SDF and a light field network that predicts color. The geometry network uses hash encoding to map 3D positions to features, while the light field network conditions on view direction and surface normal.

### Inputs and Outputs
**Inputs:**
*   Multi-view images of a scene.
*   Camera parameters (intrinsics and extrinsics) for each view.
*   Ray origins and directions sampled from the camera frustums.

**Outputs:**
*   Reconstructed 3D geometry (extracted as a mesh).
*   Synthesized novel view images.

### Data Structures
**Hash Encoding Table:**
*   Structure: A hash table with $L=16$ layers [S1].
*   Each layer $l$ contains a hash table mapping 3D coordinates to feature vectors.
*   Feature dimension: 2 per grid feature in each layer [S1].
*   The hash function maps a 3D coordinate to an index in the table. The specific hash function implementation is not detailed in the source, but standard linear probing or chaining is implied by the term "hash table" [G].

**Network Parameters:**
*   Geometry Network: 6 MLP layers [S1].
*   Light Field Network: 4 hidden layers, each with 256 units [S1].

### Numbered Steps

1.  **Hash Encoding:** For a query 3D point $\mathbf{x}$, compute the hash encoding $\text{enc}(\theta_h, \mathbf{x})$. This involves hashing $\mathbf{x}$ into each of the $L=16$ layers and retrieving the corresponding 2-dimensional feature vectors. These features are concatenated to form the geometry feature vector $\mathbf{f}_{geo}$ [S1].
2.  **Geometry Network Forward Pass:** Pass the Fourier positional encoding of $\mathbf{x}$ and the geometry feature vector $\mathbf{f}_{geo}$ through the 6-layer geometry MLP to predict the signed distance value $d$ and the feature vector for the light field network [S1]. The input to the first layer is the Fourier positional encoding of $\mathbf{x}$ with dimension 6 [S1]. The input to the third layer concatenates the hash encoding and the output of the second hidden layer [S1].
3.  **Surface Normal Estimation:** Compute the surface normal $\mathbf{n}$ as the normalized gradient of the SDF: $\mathbf{n} = \nabla d / \|\nabla d\|$ [S1].
4.  **Light Field Network Forward Pass:** Construct the input for the light field MLP by concatenating:
    *   Fourier positional encoding of the view direction $\mathbf{v}$ (dimension 6) [S1].
    *   The estimated surface normal $\mathbf{n}$ [S1].
    *   The geometry feature vector output from the connected layer of the geometry network [S1].
    *   Pass this concatenated vector through the 4-layer MLP (256 units per layer) to predict the color $\mathbf{c}$ [S1].
5.  **Hierarchical Sampling:** Sample points along each ray using a hierarchical sampling strategy [S1]. This involves sampling points near the surface based on the SDF to capture high-frequency details [S1].
6.  **Invalid Point Elimination:** Eliminate invalid sampled points on each ray using the mean of the SDF of the sampled points as a threshold [S1]. Points with SDF values significantly above this threshold are considered invalid and excluded from the volume rendering integral [S1].
7.  **Volume Rendering:** Render the image by integrating the color and density (derived from the SDF) along the ray [S1]. The specific volume rendering formula is not explicitly written out, but it follows the standard differentiable volume rendering pipeline conditioned on the SDF [G].
8.  **Loss Calculation:** Compute the loss using the weights $\alpha=0.1$, $\beta=0.1$, and $\gamma=5 \times 10^{-4}$ in Eq. (8) of the source [S1]. Eq. (8) typically combines reconstruction loss, SDF regularization, and consistency losses [G].
9.  **Geometry Extraction:** Extract the final geometry using the marching cubes algorithm at a resolution of $512^3$ [S1].
10. **Novel View Synthesis:** Synthesize novel view images by performing volume or surface rendering of the reconstructed geometry using the given novel view parameters [S1].

### Edge Cases and Pitfalls
*   **Hash Collisions:** The performance of hash encoding depends on the hash function and table size. Collisions can lead to artifacts [G].
*   **SDF Thresholding:** The choice of threshold for eliminating invalid points affects the quality of the reconstructed geometry [S1].
*   **Textureless Areas:** The method performs better than baselines in textureless areas, but poor initialization or insufficient training can still lead to artifacts [S1].

*   **Rays per Iteration:** 512 rays per iteration [S1].

*   **Limitations:** Requires careful tuning of the SDF threshold and hash encoding parameters [G].
