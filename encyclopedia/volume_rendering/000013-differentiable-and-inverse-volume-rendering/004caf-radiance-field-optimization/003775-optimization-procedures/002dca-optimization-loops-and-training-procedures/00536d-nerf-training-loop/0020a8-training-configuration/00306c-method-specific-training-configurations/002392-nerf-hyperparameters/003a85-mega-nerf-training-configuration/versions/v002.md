# Mega-NeRF Training Configuration

Also called: Mega-NeRF training procedure, Mega-NeRF

## Overview
Mega-NeRF is a training configuration for Neural Radiance Fields (NeRF) designed to accelerate training and reduce model query costs for large-scale scenes [S1]. It differs from standard NeRF by using a single shared Multi-Layer Perceptron (MLP) for both coarse and fine sampling stages, which reduces model size and saves 25% of model queries per ray by reusing coarse outputs during the fine rendering stage [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of calibrated camera poses and corresponding images for a large-scale scene [S1].
*   **Output:** A trained radiance field model capable of synthesizing novel views [S1].

**Data Structures:**
The model consists of 8 parallel submodules [S1]. Each submodule is an MLP with the following architecture:
*   **Hidden Layers:** 8 layers, each with 256 hidden units [S1].
*   **Output Layer:** 1 fully connected layer with 128 channels, followed by a ReLU activation [S1].
*   **Total Parameters:** The shared nature of the MLP across coarse and fine stages reduces the total parameter count compared to using separate networks [S1].

**Numbered Steps:**
1.  **Initialization:** Initialize 8 parallel submodules, each containing an 8-layer MLP with 256 hidden units and a final 128-channel ReLU layer [S1].
2.  **Ray Sampling:** For each batch, sample 1024 rays [S1].
3.  **Hierarchical Sampling:** Determine if the ray intersects foreground or background regions [G]. For foreground regions, sample 256 coarse points and 512 fine points per ray. For background regions, sample 128 coarse points and 256 fine points per ray [S1].
4.  **Coarse Query:** Query the shared MLP for color and density at the coarse sample locations [S1].
5.  **Fine Query:** Query the same shared MLP for color and density at the fine sample locations [S1].
6.  **Rendering:** Perform volume rendering using the hierarchical samples (coarse and fine) to compute the final pixel color [S1].
7.  **Loss Computation:** Compute the loss between the rendered image and the ground truth image [G].
8.  **Optimization:** Update the model parameters using the Adam optimizer [S1].
9.  **Learning Rate Schedule:** Decay the learning rate exponentially from an initial value of $5 \times 10^{-4}$ to $5 \times 10^{-5}$ [S1].
10. **Appearance Embedding Fine-tuning:** Apply the procedure described in NeRF in the Wild to finetune appearance embeddings [S1].
11. **Masking:** Use a pretrained semantic segmentation model to produce masks of common movable objects and ignore masked pixels during training [S1].
12. **Precision:** Use mixed-precision training to accelerate the process [S1].

**Pseudocode:**
```python
import numpy as np

class MegaNeRFSubmodule:
    def __init__(self):
        # 8 layers of 256 hidden units
        self.weights = [np.random.randn(6 if i == 0 else 256, 256) for i in range(8)]
        self.biases = [np.zeros(256) for _ in range(8)]
        # Final fully connected ReLU layer of 128 channels
        self.out_weight = np.random.randn(256, 128)
        self.out_bias = np.zeros(128)

    def forward(self, x):
        for w, b in zip(self.weights, self.biases):
            x = np.maximum(0, x @ w + b)
        return np.maximum(0, x @ self.out_weight + self.out_bias)

def train_mega_nerf(num_epochs, initial_lr=5e-4, final_lr=5e-5, batch_size=1024):
    submodules = [MegaNeRFSubmodule() for _ in range(8)]
    # [G] Standard Adam optimizer initialization
    optimizer = Adam(submodules.parameters(), lr=initial_lr)

    for epoch in range(num_epochs):
        # [G] Standard ray generation from camera poses
        rays = sample_rays(batch_size)
        # [G] Standard depth/region classification
        is_foreground = determine_region(rays)

        num_coarse = 256 if is_foreground else 128
        num_fine = 512 if is_foreground else 256
        # [G] Standard hierarchical sampling
        coarse_samples = sample_points(rays, num_coarse)
        # [G] Standard importance sampling
        fine_samples = sample_points(rays, num_fine)

        # Query shared MLP for coarse samples
        coarse_outputs = query_shared_mlp(submodules, coarse_samples)

        # Query same shared MLP for fine samples
        # Reuse coarse outputs during second rendering stage to save 25% queries [S1]
        fine_outputs = query_shared_mlp(submodules, fine_samples)

        # [G] Standard volume rendering
        rendered_images = render_volume(rays, coarse_outputs, fine_outputs)
        # [G] Standard L2 loss computation
        loss = compute_loss(rendered_images, ground_truth_images)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        # Exponential learning rate decay
        lr = initial_lr * (final_lr / initial_lr) ** (epoch / num_epochs)
        # [G] Standard learning rate update
        update_optimizer_lr(optimizer, lr)

        # [G] Standard appearance embedding update [S1]
        finetune_appearance_embeddings(submodules)
        # [G] Standard mask application for movable objects [S1]
        apply_masks(loss, masks)
```

**Parameters:**
*   **MLP Architecture:** 8 submodules, each with 8 layers of 256 hidden units and a final fully connected ReLU layer of 128 channels [S1].
*   **Sampling:** Hierarchical sampling with 256 coarse and 512 fine samples per ray in foreground regions; 128 coarse and 256 fine samples per ray in background [S1].
*   **Batch Size:** 1024 rays per batch [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** Initial $5 \times 10^{-4}$, decaying exponentially to $5 \times 10^{-5}$ [S1].
*   **Precision:** Mixed-precision training [S1].

**Edge Cases and Pitfalls:**
*   **Masking:** Movable objects must be masked out using a pretrained semantic segmentation model to prevent training artifacts [S1].
*   **Precision:** Mixed-precision training is used to accelerate the process [S1].
*   **Shared MLP:** Reusing the same MLP for coarse and fine stages saves 25% model queries per ray by reusing coarse outputs during the second rendering stage [S1].

## Operating characteristics
*   **Time Complexity:** Training time is significantly reduced compared to standard NeRF. For example, on the "Mill 19 - Building" dataset, Mega-NeRF takes 29:49 hours compared to NeRF's 59:51 hours [S1].
*   **Memory Complexity:** The shared MLP reduces model size compared to using separate MLPs for coarse and fine stages [S1].
*   **Performance:** On the "Mill 19 - Building" dataset, Mega-NeRF achieves a PSNR of 20.93, SSIM of 0.547, and LPIPS of 0.504 [S1].
*   **Scaling:** The method is designed for scalable construction of large-scale NeRFs [S1].
*   **Strengths:** Faster training, reduced model size, and efficient query usage [S1].
*   **Limitations:** Requires a pretrained semantic segmentation model for masking movable objects and mixed-precision training infrastructure [S1].

## Background
Mega-NeRF was introduced in the paper "Mega-NeRF: Scalable Construction of Large-Scale NeRFs for Virtual Fly-Throughs" [S1]. It builds on the original NeRF architecture [24] and NeRF++ [48] [S1]. The method is designed to address the scalability issues of NeRF for large-scale scenes [S1].
