# Spherical Harmonics NeRF

Also called: NeRF with Spherical Harmonics, SH-NeRF

## Overview
Spherical Harmonics NeRF replaces the view-dependent color Multi-Layer Perceptron (MLP) of the standard NeRF architecture with an explicit 2nd-order Spherical Harmonics (SH) illumination model [S1]. This modification allows for explicit relighting by varying learnable SH coefficients, addressing the lack of semantic meaning and direct lighting control in the standard formulation [S1]. It differs from siblings like [NeRF in the Wild (NeRF-W)](11995-nerf-in-the-wild-nerf-w.md) by explicitly modeling illumination rather than relying on appearance embeddings to handle varying lighting conditions, and from [Neural Pre-Integrated Lighting (Neural-PIL)](13783-neural-pre-integrated-lighting-neural-pil.md) by using a global SH basis rather than pre-integrated local lighting [S1].

## How it works
**Inputs:**
*   Ray samples $\{\mathbf{x}_i\}_{i=1}^{N_{\text{depth}}}$ along a ray.
*   Per-image learnable SH coefficients $\mathbf{L} \in \mathbb{R}^{9 \times 3}$.
*   Density values $\sigma(\mathbf{x}_i)$ and their spatial gradients $\frac{\partial}{\partial \mathbf{x}_i}\sigma(\mathbf{x}_i)$ from the neural volume.
*   Transmittance $T(t_i)$ and opacity $\alpha(\sigma(\mathbf{x}_i)\delta_i)$ for each sample.
*   Albedo values $\mathbf{A}$ accumulated from the neural volume.

**Outputs:**
*   Rendered color $\mathbf{C} \in \mathbb{R}^3$.

**Data Structures:**
*   $\mathbf{L}$: A matrix of size $9 \times 3$, storing the learnable SH coefficients for each image. The 9 coefficients correspond to the 2nd-order SH basis functions, and 3 corresponds to the RGB color channels.
*   $\mathbf{b}(\mathbf{n})$: A vector of size $9 \times 1$, containing the values of the 2nd-order SH basis functions evaluated at the normal $\mathbf{n}$.

**Steps:**

1.  **Compute Unnormalized Normal:** Calculate the unnormalized normal vector $\mathbf{\hat{N}}$ by summing the gradient of the density $\frac{\partial}{\partial \mathbf{x}_i}\sigma(\mathbf{x}_i)$ weighted by the transmittance $T(t_i)$, opacity $\alpha(\sigma(\mathbf{x}_i)\delta_i)$, and the distance between samples $\delta_i$ over all $N_{\text{depth}}$ samples [S1]:
    $$
    \mathbf{\hat{N}}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\text{depth}}}\right) = \sum_{i=1}^{N_{\text{depth}}} \left(\frac{\partial}{\partial \mathbf{x}_i}\sigma(\mathbf{x}_i)\right) \odot T(t_i)\alpha(\sigma(\mathbf{x}_i)\delta_i)
    $$
    where $\odot$ denotes elementwise multiplication [S1].

2.  **Normalize Normal:** Normalize the resulting vector $\mathbf{\hat{N}}$ to obtain the unit surface normal $\mathbf{N}$ [S1]:
    $$
    \mathbf{N}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\text{depth}}}\right) = \frac{\mathbf{\hat{N}}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\text{depth}}}\right)}{\left\|\mathbf{\hat{N}}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\text{depth}}}\right)\right\|^2}
    $$
    Note: The source uses squared norm in the denominator for normalization [S1].

3.  **Evaluate SH Basis:** Compute the SH basis vector $\mathbf{b}(\mathbf{N}) \in \mathbb{R}^9$ evaluated at the normal $\mathbf{N}$ [S1].

4.  **Compute Illumination:** Multiply the per-image learnable SH coefficients $\mathbf{L}$ by the SH basis vector $\mathbf{b}(\mathbf{N})$ to get the illumination vector [S1].

5.  **Render Color:** Compute the final color $\mathbf{C}$ by elementwise multiplying the accumulated albedo $\mathbf{A}$ with the illumination vector [S1]:
    $$
    \mathbf{C}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\text{depth}}}, \mathbf{L}\right) = \mathbf{A}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\text{depth}}}\right) \odot \mathbf{L}\mathbf{b}\left(\mathbf{N}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\text{depth}}}\right)\right)
    $$

**Pseudocode:**

```python
import numpy as np

def spherical_harmonics_basis(n):
    """
    Computes the 2nd-order Spherical Harmonics basis vector for a normal n.
    n: numpy array of shape (3,), unit normal vector [nx, ny, nz].
    Returns: numpy array of shape (9,), SH basis coefficients.
    """
    # Standard 2nd-order SH basis functions (unnormalized for simplicity, 
    # normalization constants can be absorbed into L)
    # Order 0
    b0 = 1.0 / np.sqrt(4 * np.pi)
    # Order 1
    b1 = np.sqrt(3 / (4 * np.pi)) * n[0]
    b2 = np.sqrt(3 / (4 * np.pi)) * n[1]
    b3 = np.sqrt(3 / (4 * np.pi)) * n[2]
    # Order 2
    b4 = np.sqrt(15 / (4 * np.pi)) * n[0] * n[1]
    b5 = np.sqrt(15 / (4 * np.pi)) * n[1] * n[2]
    b6 = np.sqrt(15 / (4 * np.pi)) * n[0] * n[2]
    b7 = np.sqrt(5 / (16 * np.pi)) * (3 * n[2]**2 - 1)
    b8 = np.sqrt(15 / (4 * np.pi)) * (n[0]**2 - n[1]**2)
    
    return np.array([b0, b1, b2, b3, b4, b5, b6, b7, b8])

def render_sh_nerf(samples, albedo_accumulated, L, sigma_grads, T, alpha, delta):
    """
    Renders color using Spherical Harmonics NeRF formulation.
    
    samples: list of 3D points {x_i} (not explicitly used in final formula except for indexing)
    albedo_accumulated: numpy array of shape (3,), accumulated albedo A
    L: numpy array of shape (9, 3), learnable SH coefficients
    sigma_grads: numpy array of shape (N, 3), gradients of density w.r.t x_i
    T: numpy array of shape (N,), transmittance T(t_i)
    alpha: numpy array of shape (N,), opacity alpha(sigma(x_i)delta_i)
    delta: numpy array of shape (N,), distance between samples delta_i
    
    Returns: numpy array of shape (3,), rendered color C
    """
    N = len(samples)
    
    # Step 1: Compute unnormalized normal
    # Weighted sum of density gradients
    # Weights: T(t_i) * alpha(sigma(x_i) * delta_i)
    weights = T * alpha * delta
    # Elementwise multiplication of gradients and weights
    weighted_grads = sigma_grads * weights[:, np.newaxis]
    # Sum over all samples
    N_hat = np.sum(weighted_grads, axis=0)
    
    # Step 2: Normalize normal
    # Note: Source uses squared norm in denominator
    norm_sq = np.dot(N_hat, N_hat)
    # Guard against division by zero
    if norm_sq < 1e-8:
        N = np.array([0.0, 0.0, 1.0]) # Default normal if undefined
    else:
        N = N_hat / norm_sq
        
    # Step 3: Evaluate SH basis
    b = spherical_harmonics_basis(N)
    
    # Step 4 & 5: Compute illumination and render color
    # Illumination = L @ b
    illumination = L @ b
    # Color = Albedo * Illumination
    C = albedo_accumulated * illumination
    
    return C
```

**Parameters:**
*   $\mathbf{L} \in \mathbb{R}^{9 \times 3}$: Per-image learnable SH coefficients for illumination [S1].
*   $N_{\text{depth}}$: Number of samples along the ray [S1].

**Edge Cases and Pitfalls:**
*   The model lacks direct shadow generation, which is crucial for outdoor scenes [S1].
*   The normalization step uses the squared norm in the denominator, which is non-standard for unit vector normalization (typically $\|\mathbf{v}\|$ is used). This may lead to incorrect normal directions if not implemented exactly as specified [S1].

## Operating characteristics
*   **Time Complexity:** The rendering step involves a matrix-vector multiplication ($\mathbf{L}\mathbf{b}(\mathbf{N})$) which is $O(1)$ relative to the number of samples, but the normal computation requires summing gradients over $N_{\text{depth}}$ samples, making it $O(N_{\text{depth}})$.
*   **Memory Complexity:** Requires storing $\mathbf{L}$ ($9 \times 3$ per image) and accumulated albedo and normal information.
*   **Strengths:** Allows for explicit relighting by varying $\mathbf{L}$ [S1]. The accumulation of albedo and normals makes estimates less noisy and aids convergence [S1].
*   **Limitations:** Lacks direct shadow generation [S1]. Relies on Lambertian shading model [S1].
*   **When to use:** When explicit relighting is required and the scene is primarily indoor or lacks complex shadowing [S1].
*   **When not to use:** For outdoor scenes where direct shadow generation is crucial [S1].

## Background
Spherical Harmonics NeRF was introduced by V. Rudnev et al. in "NeRF for Outdoor Scene Relighting" [S1]. The work aims to address the limitations of standard NeRF, which lacks semantic meaning of scene intrinsics and direct control over lighting [S1]. It builds on the standard NeRF architecture by replacing the view-dependent color MLP with an explicit 2nd-order SH illumination model [S1].
