# Training Ray Masking and Caching

Also called: Mask-Cached Ray Sampling

## Overview
Training Ray Masking and Caching filters the set of candidate training rays to retain only those that intersect the coarse geometry of the scene, storing the valid rays and their associated RGB values in contiguous buffers for efficient training [S2, unofficial]. It differs from sibling methods like [Pixel Batching](3134-pixel-batching.md) by explicitly discarding rays that miss the geometry (background or empty space) before the training loop begins, thereby reducing the number of rays processed per iteration [S2, unofficial].

## How it works
**Inputs:**
- `rgb_tr_ori`: List of training image tensors (RGB values).
- `cfg.data`: Configuration object containing `H`, `W`, `K` (camera intrinsics), `c2w` (camera-to-world matrices), `ndc` (boolean for NDC coordinate normalization), `inverse_y`, `flip_x`, `flip_y` [S2, unofficial].
- `model`: The neural rendering model instance, specifically its `hit_coarse_geo` method.
- `render_kwargs`: Dictionary of arguments passed to `model.hit_coarse_geo` [S1, unofficial].
- `DEVICE`: Target device (e.g., `torch.device('cuda')`).

**Outputs:**
- `rgb_tr`: Tensor of shape `[N_valid, 3]` containing RGB values for valid rays.
- `rays_o_tr`: Tensor of shape `[N_valid, 3]` containing ray origins.
- `rays_d_tr`: Tensor of shape `[N_valid, 3]` containing ray directions.
- `viewdirs_tr`: Tensor of shape `[N_valid, 3]` containing view directions.
- `imsz`: List of integers, where `imsz[i]` is the number of valid rays from image `i`.
- `batch_index_sampler`: A lambda function that yields indices for sampling batches from the cached valid rays.

**Data Structures:**
- `mask`: Boolean tensor of shape `[H, W]` indicating which pixels in the current image hit the coarse geometry.
- `rgb_tr`, `rays_o_tr`, `rays_d_tr`, `viewdirs_tr`: Pre-allocated float tensors of shape `[N, 3]` (where `N` is the sum of all pixels across all images) to store results before trimming [S1, unofficial].

**Steps:**
1. Calculate the total number of pixels $N$ across all training images:
   $$ N = \sum_{i} (\text{height}_i \times \text{width}_i) $$
   [S1, unofficial]

2. Initialize the output tensors `rgb_tr`, `rays_o_tr`, `rays_d_tr`, and `viewdirs_tr` with shape `[N, 3]` on the `DEVICE`. Initialize a counter `top = 0` and an empty list `imsz` [S1, unofficial].

3. For each training image with pose `c2w`, image `img`, dimensions $(H, W)$, and camera matrix $K$:
   a. Compute ray origins `rays_o`, ray directions `rays_d`, and view directions `viewdirs` using `get_rays_of_a_view(H, W, K, c2w, ndc, inverse_y, flip_x, flip_y)` [S2, unofficial].
   b. Initialize a boolean mask tensor `mask` of shape `[H, W]` on the `DEVICE` [S1, unofficial].
   c. Iterate over the height of the image in chunks of size `CHUNK` (64) [S1, unofficial]. For each chunk starting at row $h$:
      i. Extract `rays_o_chunk = rays_o[h:h+CHUNK]` and `rays_d_chunk = rays_d[h:h+CHUNK]` [S1, unofficial].
      ii. Call `model.hit_coarse_geo(rays_o_chunk, rays_d_chunk, **render_kwargs)` to obtain a boolean tensor of shape `[CHUNK, W]` indicating which rays in the chunk hit the coarse geometry [S1, unofficial].
      iii. Update the mask: `mask[h:h+CHUNK] = model.hit_coarse_geo(...).to(DEVICE)` [S1, unofficial].
   d. Calculate the number of valid pixels $n = \text{mask.sum()}$ [S1, unofficial].
   e. Copy the data for valid rays into the global buffers starting at index `top`:
      - `rgb_tr[top:top+n].copy_(img[mask])`
      - `rays_o_tr[top:top+n].copy_(rays_o[mask].to(DEVICE))`
      - `rays_d_tr[top:top+n].copy_(rays_d[mask].to(DEVICE))`
      - `viewdirs_tr[top:top+n].copy_(viewdirs[mask].to(DEVICE))`
      [S1, unofficial]
   f. Append $n$ to `imsz` and update `top += n` [S1, unofficial].

4. Trim the output tensors to the actual number of valid pixels:
   - `rgb_tr = rgb_tr[:top]`
   - `rays_o_tr = rays_o_tr[:top]`
   - `rays_d_tr = rays_d_tr[:top]`
   - `viewdirs_tr = viewdirs_tr[:top]`
   [S1, unofficial]

5. Create an index generator for the valid rays: `index_generator = batch_indices_generator(len(rgb_tr), cfg_train.N_rand)` [S2, unofficial].

6. Define the batch sampler: `batch_index_sampler = lambda: next(index_generator)` [S2, unofficial].

7. Print the ratio of kept rays to total rays: `top / N` [S2, unofficial].

**Pseudocode:**
```python
import torch

def get_rays_of_a_view(H, W, K, c2w, ndc, inverse_y, flip_x, flip_y):
    # Standard ray generation from camera intrinsics and extrinsics [G]
    i, j = torch.meshgrid(torch.arange(W, device=c2w.device), torch.arange(H, device=c2w.device), indexing='xy')
    dirs = torch.stack([(i - K[0][2]) / K[0][0], -(j - K[1][2]) / K[1][1], torch.ones_like(i)], dim=-1)
    if ndc:
        dirs = (dirs - 0.5) / 0.5
    rays_o = c2w[:3, 3].expand(H, W, 3)
    rays_d = (dirs @ c2w[:3, :3].T).to(dirs.device)
    if inverse_y: rays_d[:, :, 1] *= -1
    if flip_x: rays_d[:, :, 0] *= -1
    if flip_y: rays_d[:, :, 1] *= -1
    viewdirs = rays_d / torch.norm(rays_d, dim=-1, keepdim=True)
    return rays_o, rays_d, viewdirs

def batch_indices_generator(total_rays, batch_size):
    # Standard cyclic index generator for training batches [G]
    idx = 0
    while True:
        yield idx % total_rays
        idx += 1

def get_training_rays_in_maskcache_sampling(rgb_tr_ori, cfg, model, render_kwargs, DEVICE):
    # Step 1: Calculate total pixels N
    N = sum(im.shape[0] * im.shape[1] for im in rgb_tr_ori)
    
    # Step 2: Initialize output tensors
    rgb_tr = torch.zeros((N, 3), device=DEVICE)
    rays_o_tr = torch.zeros((N, 3), device=DEVICE)
    rays_d_tr = torch.zeros((N, 3), device=DEVICE)
    viewdirs_tr = torch.zeros((N, 3), device=DEVICE)
    
    top = 0
    imsz = []
    CHUNK = 64
    
    # Step 3: Process each image
    for i, (c2w, img, H, W, K) in enumerate(zip(cfg.data.c2w, rgb_tr_ori, cfg.data.H, cfg.data.W, cfg.data.K)):
        # 3a: Compute rays
        rays_o, rays_d, viewdirs = get_rays_of_a_view(
            H, W, K, c2w, cfg.data.ndc, cfg.data.inverse_y, 
            cfg.data.flip_x, cfg.data.flip_y
        )
        
        # 3b: Initialize mask
        mask = torch.zeros((H, W), dtype=torch.bool, device=DEVICE)
        
        # 3c: Chunked geometry check
        for h in range(0, H, CHUNK):
            h_end = min(h + CHUNK, H)
            rays_o_chunk = rays_o[h:h_end]
            rays_d_chunk = rays_d[h:h_end]
            
            # Call model to get hit mask for this chunk
            hit_mask_chunk = model.hit_coarse_geo(
                rays_o_chunk, rays_d_chunk, **render_kwargs
            )
            
            # Update global mask
            mask[h:h_end] = hit_mask_chunk.to(DEVICE)
            
        # 3d: Count valid pixels
        n = mask.sum().item()
        
        # 3e: Copy valid data to global buffers
        if n > 0:
            rgb_tr[top:top+n].copy_(img[mask])
            rays_o_tr[top:top+n].copy_(rays_o[mask].to(DEVICE))
            rays_d_tr[top:top+n].copy_(rays_d[mask].to(DEVICE))
            viewdirs_tr[top:top+n].copy_(viewdirs[mask].to(DEVICE))
            
        # 3f: Update indices
        imsz.append(n)
        top += n
        
    # Step 4: Trim tensors
    rgb_tr = rgb_tr[:top]
    rays_o_tr = rays_o_tr[:top]
    rays_d_tr = rays_d_tr[:top]
    viewdirs_tr = viewdirs_tr[:top]
    
    # Step 5 & 6: Create sampler
    index_generator = batch_indices_generator(len(rgb_tr), cfg.train.N_rand)
    batch_index_sampler = lambda: next(index_generator)
    
    # Step 7: Print ratio
    print(f"Ratio of kept rays: {top / N}")
    
    return rgb_tr, rays_o_tr, rays_d_tr, viewdirs_tr, imsz, batch_index_sampler
```

**Parameters:**
- `CHUNK`: Integer, size of the ray chunk processed in each iteration of the geometry check loop. Typical value: 64 [S1, unofficial].
- `render_kwargs`: Dictionary passed to `model.hit_coarse_geo` [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Empty Images:** If an image has no rays hitting the geometry ($n=0$), the copy operations are skipped, and `imsz` records 0 [S1, unofficial].
- **Geometry Definition:** The mask correctness depends entirely on `model.hit_coarse_geo` returning accurate intersection results [S2, unofficial].
- **Device Consistency:** Tensors must be allocated and updated on the same device (`DEVICE`) to prevent runtime errors [G].

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the total number of pixels across all training images, dominated by the `model.hit_coarse_geo` calls performed in chunks [S1, unofficial].
- **Memory Complexity:** $O(N)$ for pre-allocated output tensors before trimming, plus $O(H \times W)$ per image for the mask [S1, unofficial].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales linearly with training images and resolution; chunking manages GPU memory during geometry checks [S1, unofficial].
- **Strengths:** Reduces rays processed per training iteration by filtering background/empty space rays before the loop begins [S2, unofficial].
- **Limitations:** Requires an initial pass over all training rays to build the cache [S2, unofficial].
- **When to use:** When the scene has significant empty space or background, and a coarse geometry model is available [S2, unofficial].
- **When not to use:** When the geometry is unknown or highly dynamic, or when memory is extremely constrained due to $N$-sized tensor pre-allocation [S1, unofficial].

## Background
This method is part of the DirectVoxGO and related NeRF optimization pipelines, specifically designed to optimize training efficiency by focusing on occupied voxels [S2, unofficial]. It was introduced in the context of differentiable volume rendering optimization loops [S2, unofficial]. The approach leverages a coarse geometry representation to pre-filter rays before the main training loop begins [S2, unofficial].
