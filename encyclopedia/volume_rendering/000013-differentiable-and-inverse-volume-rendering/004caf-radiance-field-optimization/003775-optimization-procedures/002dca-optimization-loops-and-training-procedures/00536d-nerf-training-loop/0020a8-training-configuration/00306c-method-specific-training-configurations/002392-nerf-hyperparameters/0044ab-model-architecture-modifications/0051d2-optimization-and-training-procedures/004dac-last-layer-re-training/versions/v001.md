# Last Layer Re-training

Also called: Instant NeRF Editing, Last Layer Fine-tuning

## Overview
Last Layer Re-training is a technique for instantly propagating a color edit from a single view to an entire pre-trained Neural Radiance Field (NeRF) by selectively retraining only the last layer of the color Multi-Layer Perceptron (MLP) [S1]. This approach significantly reduces the number of parameters requiring modification compared to full re-training, thereby enabling near real-time editing while preserving existing view-dependent information encoded in the deeper layers [S1]. It addresses the challenge of maintaining multi-view consistency and preventing color bleeding at object boundaries by leveraging the global feature representations already learned by the network [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained NeRF model (specifically the color MLP weights $\phi_c$ and the density MLP weights $\phi_\sigma$), and a single edited view image $I_{edit} \in \mathbb{R}^{W \times H \times 3}$ containing the desired color changes [S1].
*   **Output:** An updated NeRF model where the color output $c'_{x,\theta}$ reflects the edit while maintaining geometric and view-dependent consistency [S1].

**Data Structures and Layout:**
The color MLP $MLP_c$ takes as input the concatenation of multiresolution hash grid features $f_x$ and the view direction encoding $\gamma(\theta)$ [S1]. The features are constructed by concatenating features from each level $L$:
$$
f_x = \{f_{x,0} \oplus f_{x,1} \oplus ... \oplus f_{x,L}\}
$$
The network structure consists of a density MLP and a color MLP. The color MLP maps the penultimate layer output $h_{x,\theta}$ to the final color $c_{x,\theta}$ [S1].

**Algorithm Steps:**
1.  **Freeze Pre-trained Weights:** Keep the weights of the density MLP ($\phi_\sigma$) and all layers of the color MLP except the last layer fixed. The penultimate layer output $h_{x,\theta}$ is computed using the original pre-trained weights and the input position $x$ and view direction $\theta$ [S1].
2.  **Define Last Layer Function:** Define the new last layer function $MLP_{last}$ which maps the fixed penultimate activations $h_{x,\theta}$ to the new color $c'_{x,\theta}$ using a new set of parameters $\phi'_{last}$ [S1]:
    $$
    c'_{x,\theta} = MLP_{last}(h_{x,\theta}, \phi'_{last})
    $$
3.  **Initialize Parameters:** Initialize $\phi'_{last}$ with the original last layer weights from the pre-trained model [G].
4.  **Optimization Loop:** Minimize the RGB loss between the volume rendered color $C'_{ij}$ and the target edited color $C_{ij}$ from the single input image $I_{edit}$ [S1]:
    $$
    L = \sum_{i,j} \|C_{ij} - C'_{ij}\|^2
    $$
    where $C_{ij}$ is the original RGB value from the training image (the edited view) and $C'_{ij}$ is the volume rendered RGB value [S1].
5.  **Update Weights:** Use the Adam Optimizer to update $\phi'_{last}$ for a fixed number of iterations [S1].

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** 0.01 (constant) [S1].
*   **Iterations:** 200 iterations per scene [S1].
*   **Hardware:** Single NVIDIA RTX 3090 GPU [S1].

**Pseudocode:**
```python
def last_layer_retraining(pretrained_nerf, edited_image, iterations=200, lr=0.01):
    """
    Retrains only the last layer of the color MLP to propagate a color edit.
    
    Args:
        pretrained_nerf: Object containing the pre-trained NeRF model.
        edited_image: Tensor of shape (H, W, 3) representing the single edited view.
        iterations: Number of optimization steps.
        lr: Learning rate for Adam optimizer.
        
    Returns:
        updated_nerf: NeRF model with updated last layer weights.
    """
    # Extract the color MLP from the pre-trained model
    color_mlp = pretrained_nerf.color_mlp
    
    # Freeze all parameters except the last layer
    for param in color_mlp.parameters():
        param.requires_grad = False
        
    # Ensure the last layer parameters are trainable
    for param in color_mlp[-1].parameters():
        param.requires_grad = True
        
    # Initialize optimizer for the last layer only
    optimizer = torch.optim.Adam(color_mlp[-1].parameters(), lr=lr)
    
    # Get camera parameters for the edited view (assumed known or provided)
    # In a full implementation, this would involve ray generation for the edited view
    rays_o, rays_d = generate_rays_from_view(edited_image.shape, pretrained_nerf.cameras)
    
    for step in range(iterations):
        optimizer.zero_grad()
        
        # 1. Compute penultimate layer activations (fixed)
        # Concatenate hash grid features and view direction encoding
        # Note: In Instant-NGP, features are looked up based on position
        features = get_hash_grid_features(rays_o, pretrained_nerf.hash_grid)
        view_enc = positional_encoding(rays_d)
        input_vec = torch.cat([features, view_enc], dim=-1)
        
        # Pass through all layers except the last one
        # Assuming the MLP is a list of layers, e.g., [Linear, ReLU, Linear, ReLU, Linear]
        # We compute up to the second-to-last layer
        penultimate_output = color_mlp[:-1](input_vec)
        
        # 2. Compute new color output using the last layer (trainable)
        new_color = color_mlp[-1](penultimate_output)
        
        # 3. Volume render the new color
        # This step involves sampling along rays and accumulating color with transmittance
        rendered_color = volume_render(rays_o, rays_d, new_color, pretrained_nerf.density_mlp)
        
        # 4. Compute loss against the edited image
        # rendered_color should be of shape (H, W, 3)
        target_color = edited_image.permute(2, 0, 1) # Assuming HWC to CHW if needed, or adjust accordingly
        loss = torch.mean((rendered_color - target_color) ** 2)
        
        # 5. Backpropagate and update
        loss.backward()
        optimizer.step()
        
    return pretrained_nerf
```

**Edge Cases and Pitfalls:**
*   **Color Bleeding:** Since the information encoded in the color MLP is global, modifying the last layer may lead to undesired edits in regions not targeted by the user [S1]. This is addressed in the IReNe method by introducing a 3D segmentation step to restrict edits to target regions [S1].
*   **View-Dependent Effects:** Performing edits on a single view makes reproducing coherent view-dependent effects complex. The method relies on the pre-existing view-dependent information in the deeper layers to maintain consistency [S1].
*   **Precision:** The method assumes the pre-trained model is stable. Retraining only the last layer requires careful initialization to avoid destabilizing the output [G].

## Operating characteristics
*   **Time Complexity:** Significantly faster than full re-training because only the last layer parameters are updated. The number of parameters to optimize is reduced, allowing for convergence in a small number of iterations (e.g., 200) [S1].
*   **Memory Complexity:** Low additional memory overhead compared to full re-training, as the majority of the model weights remain frozen and do not require gradient storage or optimizer states [S1].
*   **Performance:** Achieves near real-time editing capabilities [S1].
*   **Strengths:** Rapid edits, preservation of view-dependent effects, higher quality edits compared to full re-training in some cases [S1].
*   **Limitations:** Potential for color bleeding into non-targeted regions if not combined with segmentation [S1]. Relies on the quality of the pre-trained model's feature representations [S1].
*   **When to use:** When instant editing of a pre-trained NeRF is required, and the edit is primarily color-based [S1].
*   **When not to use:** When significant geometric changes or structural modifications to the scene are required, as this method only affects the color output [S1].

## Background
Last Layer Re-training was introduced in the context of the IReNe (Instant Recoloring of Neural Radiance Fields) method [S1]. The paper was presented at CVPR 2024 [S1]. The method builds upon Instant-NGP [S1] and aims to solve the challenge of interactive NeRF editing by leveraging the structure of the neural network to isolate color information in the last layer [S1].
