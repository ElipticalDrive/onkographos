# SAID-NeRF

Also called: Segmentation-Aided NeRF

## Overview
SAID-NeRF is a method that exploits instance masks generated by Visual Foundation Models (VFMs) to enhance NeRF’s estimation of surfaces of transparent objects that are otherwise ambiguous when relying purely on RGB, via the simultaneous reconstruction of semantic fields and extensions to increase robustness [S1]. It differs from standard NeRF by decomposing appearance into view-independent diffuse and view-dependent specular components and using semantic segmentation to enforce higher surface densities for transparent objects, resulting in sharper depth estimates suitable for robotic grasping [S1]. It builds on [Instant-NGP](13738-voxel-and-sparse-grid-representations.md) for efficient encoding and [Semantic and Feature Branches](12095-semantic-and-feature-branches.md) for the joint optimization of geometry and semantics.

## How it works
**Inputs:**
*   A set of $N$ RGB images and their corresponding camera poses.
*   Optional: RGB-D depth maps from an RGB-D camera (e.g., RealSense D435) [S1].
*   Semantic masks generated by a Visual Foundation Model (specifically Light-HQ SAM) [S1].

**Outputs:**
*   A Semantic Radiance Field model capable of rendering RGB, depth, and semantic labels.
*   Estimated depth maps and semantic segmentation masks for novel views.

**Data Structures:**
The model uses a Multiresolution Hash Encoding for spatial hashing, augmented with a Position Encoding MLP [S1]. The architecture consists of:
1.  **Multiresolution Hash Encoding:** Standard hash grid features [S1].
2.  **Position Encoding MLP:** A single-layer MLP of width 16 that processes the concatenated hash features and positional encoding to avoid floaters and warped geometry [S1].
3.  **Diffuse Color Head:** An MLP taking the processed position features to output view-independent diffuse color $\mathbf{c}_d(\mathbf{x})$ [S1].
4.  **Specular Color Head:** An MLP taking the processed position features and spherical harmonics-encoded view direction $\mathbf{d}$ to output view-dependent specular color $\mathbf{c}_s(\mathbf{x}, \mathbf{d})$ [S1].
5.  **Segmentation Head:** A two-layer MLP of width 32 taking the processed position features to output a vector of length $C$ (number of semantic classes) representing semantic probabilities [S1].

**Numbered Steps:**

1.  **Mask Generation:** Use the Segment Anything Model (SAM), specifically the Light-HQ SAM variant, to generate instance masks for the input images [S1].
2.  **Hierarchical Mask Grouping:** Group the generated masks into a hierarchical set of non-overlapping scene masks consistent across views using Algorithm 1 [S1].
    *   Sort masks in decreasing order of area.
    *   Compute convex hulls for each mask.
    *   Assign masks to sets based on convex hull overlap, creating new sets if conflicts arise.
    *   If the number of sets exceeds the requested number of classes $C$, merge excess sets into the $C$-th set [S1].
3.  **Ray Sampling:** For a pixel, generate a ray $\mathbf{r}$ originating at the camera center. Sample $N$ points $t_i$ along the ray between near and far planes [S1].
4.  **Feature Extraction:** For each sample point $\mathbf{x}_i$:
    *   Retrieve hash features from the Multiresolution Hash Encoding.
    *   Concatenate with positional encoding.
    *   Pass through the Position Encoding MLP (width 16) to get feature vector $\mathbf{h}_i$ [S1].
5.  **Density Estimation:** The density $\sigma_i$ is typically derived from the hash encoding or a shared network branch (standard Instant-NGP practice, implied by the architecture description focusing on the added heads) [S1]. *Note: The source describes the added heads explicitly but assumes the base density estimation follows the Instant-NGP backbone.*
6.  **Color Decomposition:**
    *   Compute diffuse color $\mathbf{c}_d(\mathbf{x}_i)$ using the Diffuse Color Head MLP [S1].
    *   Encode view direction $\mathbf{d}$ using Spherical Harmonics (SH) basis functions [S1].
    *   Compute specular color $\mathbf{c}_s(\mathbf{x}_i, \mathbf{d})$ using the Specular Color Head MLP with input $\mathbf{h}_i$ and SH-encoded $\mathbf{d}$ [S1].
    *   Final color $\mathbf{c}_i = \mathbf{c}_d(\mathbf{x}_i) + \mathbf{c}_s(\mathbf{x}_i, \mathbf{d})$ [S1].
7.  **Semantic Prediction:** Compute semantic probabilities $\mathbf{s}_i \in \mathbb{R}^C$ using the Segmentation Head MLP with input $\mathbf{h}_i$ [S1].
8.  **Volume Rendering:**
    *   Compute transmittance $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ and opacity $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, where $\delta_i = t_{i+1} - t_i$ [S1].
    *   Render expected color:
        $$ \hat{C} = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i $$
    *   Render expected depth:
        $$ \hat{D} = \sum_{i=1}^{N} T_i \alpha_i t_i $$
    *   Render expected semantic labels:
        $$ \hat{S} = \sum_{i=1}^{N} T_i \alpha_i \mathbf{s}_i $$
    [S1]
9.  **Loss Computation:**
    *   **RGB Loss:** L1 loss between $\hat{C}$ and ground truth RGB [S1].
    *   **Semantic Loss:** Binary cross-entropy loss between $\hat{S}$ and the hierarchical semantic masks from Step 2 [S1].
    *   **Depth Loss:** L2 loss between $\hat{D}$ and ground truth depth from RGB-D camera (if available) [S1].
    *   **Specular Penalty:** Small L2 penalty on the specular term $\mathbf{c}_s$ to encourage diffuse color components [S1].
10. **Optimization:** Update network weights to minimize the total loss. Training is capped by a time limit $T$ (e.g., 20 seconds for robotic experiments, 60 seconds for ClearPose dataset) rather than a fixed number of steps [S1].

    def forward(self, positions, directions, ray_samples):
        """
        positions: (N, 3)
        directions: (N, 3)
        ray_samples: object containing t values and deltas
        """
        # 1. Hash Encoding
        hash_features = self.hash_encoding(positions)
        
        # 2. Position Encoding MLP
        pos_features = self.pos_mlp(hash_features) # (N, 16)
        
        # 3. Density (Assumed from hash encoding or shared branch)
        # In Instant-NGP, density is often a direct output of the hash grid or a small network.
        # For SAID-NeRF, we assume standard density estimation from the base architecture.
        densities = self.hash_encoding.get_density(positions) # Implementation detail of hash encoding
        
        # 4. Color Decomposition
        diffuse_colors = self.diffuse_head(pos_features) # (N, 3)
        
        sh_encoded_dirs = self.spherical_harmonics_encode(directions)
        specular_inputs = torch.cat([pos_features, sh_encoded_dirs], dim=-1)
        specular_colors = self.specular_head(specular_inputs) # (N, 3)
        
        colors = diffuse_colors + specular_colors # (N, 3)
        
        # 5. Semantic Prediction
        semantic_probs = self.seg_head(pos_features) # (N, C)
        
        # 6. Volume Rendering
        # T_i = exp(-sum(sigma_j * delta_j))
        # alpha_i = 1 - exp(-sigma_i * delta_i)
        # Standard volumetric rendering loop
        transmittance = torch.ones_like(densities[:, :1])
        rendered_color = torch.zeros_like(colors)
        rendered_depth = torch.zeros_like(densities[:, :1])
        rendered_semantics = torch.zeros_like(semantic_probs)
        
        for i in range(len(ray_samples)):
            delta = ray_samples.deltas[i]
            sigma = densities[i]
            t = ray_samples.t[i]
            
            alpha = 1.0 - torch.exp(-sigma * delta)
            weight = transmittance * alpha
            
            rendered_color += weight * colors[i]
            rendered_depth += weight * t
            rendered_semantics += weight * semantic_probs[i]
            
            transmittance *= (1.0 - alpha)
            
        return rendered_color, rendered_depth, rendered_semantics, specular_colors

    def compute_loss(self, pred_color, pred_depth, pred_semantics, 
                     gt_color, gt_depth, gt_semantics, specular_colors):
        # RGB Loss: L1
        rgb_loss = F.l1_loss(pred_color, gt_color)
        
        # Semantic Loss: Binary Cross Entropy
        # gt_semantics should be one-hot or binary masks
        semantic_loss = F.binary_cross_entropy_with_logits(pred_semantics, gt_semantics)
        
        # Depth Loss: L2 (if depth available)
        depth_loss = F.mse_loss(pred_depth, gt_depth) if gt_depth is not None else torch.tensor(0.0)
        
        # Specular Penalty: L2 on specular term
        specular_loss = torch.mean(specular_colors ** 2)
        
        total_loss = rgb_loss + semantic_loss + depth_loss + 0.1 * specular_loss # Weight for specular penalty is small
        return total_loss

def generate_hierarchical_masks(masks, num_classes=3):
    """
    Algorithm 1: Hierarchical semantic mask generation
    masks: List of binary masks
    num_classes: C, number of semantic classes
    """
    # 1. Sort masks in decreasing order of area
    sorted_masks = sorted(masks, key=lambda m: m.sum(), reverse=True)
    
    # 2. Compute convex hulls (simplified as bounding boxes or actual hulls)
    # In practice, use a convex hull library
    hulls = [compute_convex_hull(m) for m in sorted_masks]
    
    sets = [] # List of lists of mask indices
    
    for i, hull in enumerate(hulls):
        assigned = False
        for s_idx, s_masks in enumerate(sets):
            # Check if hull overlaps with any hull in set s
            conflict = False
            for m_idx in s_masks:
                if hulls[i].overlaps(hulls[m_idx]):
                    conflict = True
                    break
            if not conflict:
                sets[s_idx].append(i)
                assigned = True
                break
        
        if not assigned:
            sets.append([i])
            
    # 3. Merge if too many sets
    if len(sets) > num_classes:
        # Merge excess sets into the last set (index num_classes-1)
        for s_idx in range(num_classes, len(sets)):
            sets[num_classes - 1].extend(sets[s_idx])
        sets = sets[:num_classes]
        
    return sets

**Parameters:**
*   **Number of semantic classes ($C$):** Empirically kept reasonably low ($\le 3$) [S1].
*   **Position Encoding MLP:** Single layer, width 16 [S1].
*   **Segmentation MLP:** Two layers, width 32 [S1].
*   **Training Time Limit ($T$):** 20 seconds for robotic experiments, 60 seconds for ClearPose dataset [S1].
*   **Loss Weights:** Small L2 penalty on specular term [S1].

**Edge Cases and Pitfalls:**
*   **Floaters and Warped Geometry:** Patternless or single-colored backgrounds can lead to inaccurate densities and "floaters." The addition of frequency embedding (Position Encoding MLP) helps mitigate this [S1].
*   **Mask Consistency:** The hierarchical mask generation heuristic is imprecise and may fail in complex settings, but faulty assignments are typically compensated for by other views if $C$ is low [S1].
*   **Transparent Object Depth:** Transparent objects have low density contributions to color, leading to ambiguous depth. The semantic head enforces higher surface densities for these objects [S1].

## Operating characteristics
*   **Time Complexity:** Training is extremely fast, capped at seconds (20-60s) rather than minutes or hours, due to the use of Multiresolution Hash Encoding (Instant-NGP) [S1].
*   **Memory Complexity:** Low memory footprint compared to dense voxel grids, leveraging hash encoding [S1].
*   **Measured Performance:** Outperforms vanilla Instant-NGP using as few as four images or training for under 10 seconds [S1].
*   **Strengths:** Enables robotic grasping of transparent objects in reasonable time using a handful of views; robust to view-dependent appearance via semantic guidance; avoids long training times of implicit surface methods like NeUS [S1].
*   **Limitations:** Relies on the quality of VFM-generated masks; hierarchical mask grouping is imprecise; depth supervision requires RGB-D data which may not capture transparent object surfaces directly [S1].
*   **When to use:** Robotic grasping of transparent objects, depth completion of transparent objects, scenarios with limited views and time constraints [S1].
*   **When not to use:** When high-fidelity specular rendering is the primary goal without semantic constraints; when precise instance separation is impossible for VFMs [S1].

## Background
SAID-NeRF was proposed to address the challenge of acquiring accurate 3D information of transparent objects for Robotics and Computer Vision, where traditional NeRFs fail to recover true shape/depth due to view-dependent specular effects [S1]. It builds on the success of Visual Foundation Models (VFMs) like SAM for zero-shot segmentation and Instant-NGP for fast rendering [S1]. The method was introduced in 2024 [S1].
