# Method-Specific Training Configurations


## Overview
This article defines the family of hyperparameter settings, architectural constraints, and optimization schedules required to train specific Neural Radiance Field (NeRF) variants and related inverse rendering methods. It addresses the problem of converging differentiable volume rendering pipelines by providing precise configurations for datasets (e.g., Blender, LLFF) and model architectures (e.g., MLPs, Hash grids) that standard generic training loops do not cover. It differs from [Training Configuration](2332-training-configuration.md) by focusing on method-specific deviations (such as Mip-NeRF’s activation functions or DONeRF’s two-network pipeline) rather than the general loop structure.

## Shared principles
The training configurations for these methods share the following core mechanisms:
1.  **Differentiable Volume Rendering:** All methods minimize the difference between rendered images and ground truth using the volume rendering equation:
    $$ C(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i c_i $$
    where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ is the opacity and $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ is the transmittance [S3].
2.  **Optimization:** Most methods use the Adam optimizer [S1][S2][S3][S7].
3.  **Sampling:** Methods typically involve sampling rays and querying 3D positions along them. Strategies vary from stratified sampling [S3] to hierarchical importance sampling [S1] or oracle-guided sampling [S3].
4.  **Loss Functions:** The primary loss is often Mean Squared Error (MSE) [S3], though variants like Charbonnier [S1] or GAN losses [S8] are used.

## Subtopics

### [NeRF Hyperparameters](3065-nerf-hyperparameters.md)
Defines the baseline configuration for the original NeRF. It uses an 8-layer Position MLP (256/512 units) and 4-layer Direction MLP (128 units) with axis-aligned IPE. It employs a two-stage training process: coarse sampling (64 points) followed by hierarchical fine sampling (128 points). The optimizer is Adam with an initial learning rate of $5 \times 10^{-4}$ decaying to $5 \times 10^{-6}$. It is chosen for standard synthetic datasets like Blender and LLFF.

### [Mip-NeRF Optimization and Activation Details](3409-mip-nerf-optimization-and-activation-details.md)
Configures Mip-NeRF and JaxNeRF to ensure stable gradient flow. It replaces standard positional encoding with Integrated Positional Encoding (IPE) and removes identity concatenation. Key differentiators are the **shifted softplus** density activation ($\tau = \log(1 + \exp(x - 1))$) to prevent negative density, and the **widened sigmoid** color activation ($c = \frac{1 + 2\epsilon}{1 + \exp(-x)} - \epsilon$ with $\epsilon=0.001$) to handle saturation. It uses a specific learning rate schedule combining warmup and logarithmic annealing over 1,000,000 iterations.

### [DONeRF](4461-donerf.md)
A compact NeRF variant that decouples geometry and shading. It uses a **Depth Oracle Network** (8-layer MLP, no PE) to predict sample locations and a **Shading Network** (8-layer MLP, with PE) to render color. It replaces volumetric raymarching with a two-network pipeline, using only 2–16 samples per ray. It introduces an **Opacity Loss** to prevent dark pixel artifacts when sample counts are low. It is chosen for real-time or resource-constrained applications where standard NeRF is too slow.

### [NeRF Hyperparameters](3065-nerf-hyperparameters.md)
A simplified configuration for the Blender dataset. It uses a single round of sampling (128 samples for proposal MLP, 32 for NeRF MLP), 4-layer proposal MLP (256 units), and 8-layer NeRF MLP (256/512 units). It uses axis-aligned IPE, MSE loss, and disables the distortion regularizer.

### [NeRF Hyperparameters](3065-nerf-hyperparameters.md)
Configures training for the LLFF dataset. It differs from the Blender config by **not disabling** the distortion regularizer and using **Charbonnier loss** instead of MSE. Performance metrics vary by hidden unit count (256 vs 512), with larger models showing significant speedups for comparable or better SSIM/LPIPS.

### [Mip-NeRF Optimization and Activation Details](3409-mip-nerf-optimization-and-activation-details.md)
Configures NeUDF for unsigned distance fields. It uses Adam with a learning rate warming up to $2 \times 10^{-4}$ in 5k iterations and decaying to $1 \times 10^{-5}$. It samples 512 rays from 8 random camera poses per iteration. Training lasts 400k iterations.

### [DONeRF](4461-donerf.md)
Configures NeRF-SDP for generalizable NeRFs. It uses Adam with a learning rate of $1 \times 10^{-3}$ for the Res-UNet and $5 \times 10^{-4}$ for other parts. It trains for 250,000 steps with a batch size of 500. The first 170,000 steps optimize auxiliary and rendering losses; the last 80,000 optimize only rendering loss.

### [Mip-NeRF Optimization and Activation Details](3409-mip-nerf-optimization-and-activation-details.md)
Configures Neuralangelo for high-fidelity surface reconstruction. It assumes a unit sphere ROI. It uses AdamW with weight decay $10^{-2}$ and a learning rate of $1 \times 10^{-3}$ with linear warmup (5k iterations) and decay factors at 300k/400k iterations. It uses a 1-layer SDF MLP and 4-layer color MLP. It samples pixels randomly without tracking statistics.

### [DONeRF](4461-donerf.md)
Configures GO-NeRF for object generation. It optimizes a hash grid representation for 20,000 iterations on a single GPU. It uses a cosine scheduler for $\lambda_S$ and $\lambda_O$ (values 30–300) and sets $\lambda_R = 500$. 30% of iterations use background augmentation.

### [NeRF Hyperparameters](3065-nerf-hyperparameters.md)
Configures Tri-MipRF for anti-aliasing. It uses AdamW with weight decay $10^{-5}$ and learning rate $2 \times 10^{-3}$ (scaled 10x for Tri-Mip encoding). It uses MultiStepLR. The base mipmap shape is $512 \times 512 \times 16$. It implements area loss $L_{area}$ scaling pixel loss by footprint area.

### [NeRF Hyperparameters](3065-nerf-hyperparameters.md)
A variant of nerfacto using a standard MLP density field. For Blender, it uses $t_n=2.0, t_f=6.0$, disables camera optimizer/appearance/distortion/contraction, sets background to white, batch size 2048, and trains for 16.5k epochs. For LLFF, it uses $\ell_\infty$ contraction, batch size 1024 (train)/2048 (eval), and trains for 30k epochs.

### [DONeRF](4461-donerf.md)
Configures AR-NeRF for depth/defocus learning. It uses Adam with learning rate $0.00006$ for 200,000 iterations. R1 regularization weight is 0.2, identity regularizer weight is 15. The synthesis networks use 128 units (foreground) and 64 units (background) with FiLM-SIREN.

### [NeRF Hyperparameters](3065-nerf-hyperparameters.md)
Configures DVGO with Re:NeRF compression. It uses PyTorch 1.12 on an NVIDIA A40 GPU.

## Background
The original NeRF [S3] established the baseline for training neural radiance fields, using an 8-layer MLP and hierarchical sampling. Mip-NeRF [S1] introduced integrated positional encoding and specific activation functions to handle anti-aliasing and gradient stability. DONeRF [S3] proposed a two-network approach for efficiency. Subsequent works like Neuralangelo [S4], Tri-MipRF [S6], and NeRF-SDP [S3] introduced specific hyperparameters for hash grids, multi-scale representations, and generalizable features. These configurations are critical for reproducing results and adapting NeRF to specific datasets (Blender, LLFF, Tanks and Temples) and hardware constraints.
