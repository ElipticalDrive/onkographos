# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF training configuration defines the optimization procedure for text-guided NeRF stylization, specifically addressing the challenge of enforcing semantic style transfer while maintaining geometric consistency. It distinguishes itself from standard NeRF training by freezing density-related parameters and minimizing the negative cosine similarity between rendered images and text prompts in the CLIP embedding space [S1, S2]. Unlike global contrastive losses that may cause uneven stylization, this configuration often employs directional losses to guide the trajectory of stylization [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A pre-trained NeRF model (with frozen density parameters), a target text prompt $\mathbf{t}_{tgt}$, and optionally a source image $\mathbf{I}_{src}$ and source text prompt $\mathbf{t}_{src}$ for relative loss.
*   **Outputs:** Updated NeRF parameters (color/feature MLPs) that produce stylized renderings.

**Data Structures:**
*   **CLIP Model:** ViT-B/32 variant [S1].
*   **Patch Data:** Rendered image patches of size $128 \times 128$ [S1].

**Parameters:**
*   **Iterations:** 500 [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $0.0001$ [S1].
*   **Patch Size:** $128 \times 128$ pixels [S1].
*   **Ray Sampling Stride:** 5 within the patch, resulting in a receptive field of $640 \times 640$ on the original image [S1].
*   **Importance Sampling Points:** 16 per ray during patch rendering [S1].
*   **Fine MLP Samples:** 80 total (64 coarse + 16 fine) [S1].

**Method Steps:**
1.  **Freeze Density:** Freeze all NeRF parameters related to density ($\sigma$) to preserve geometry [S1].
2.  **Sample View:** Randomly sample a camera pose from the training dataset [S1].
3.  **Render Patch:** Render a $128 \times 128$ image patch from the sampled view. Rays are sampled with a stride of 5 to cover a wider context [S1].
4.  **Resize:** Apply bilinear interpolation to resize the rendered patch if necessary for the CLIP encoder [S1].
5.  **Encode:** Pass the resized patch through the CLIP image encoder $\mathcal{E}_i$ and the text prompt through the CLIP text encoder $\mathcal{E}_t$ [S1, S2].
6.  **Compute Loss:** Calculate the directional CLIP loss.
    *   *Absolute Directional Loss:* Used in the original CLIPNeRF implementation [S2]:
        $$ \mathcal{L}_{dir} = 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) \rangle $$
        where $\hat{\mathcal{E}}$ denotes normalized embeddings and $\langle \cdot, \cdot \rangle$ is the cosine similarity [S2].
    *   *Relative Directional Loss:* Used in NeRF-Art to prevent mode collapse and improve diversity [S2]:
        $$ \mathcal{L}_{dir} = 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}) - \hat{\mathcal{E}}_i(\mathbf{I}_{src}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) - \hat{\mathcal{E}}_t(\mathbf{t}_{src}) \rangle $$
        where $\mathbf{I}_{src}$ is the source image and $\mathbf{t}_{src}$ is the source text prompt [S2].
7.  **Optimize:** Minimize $\mathcal{L}_{dir}$ using Adam with the specified learning rate for 500 iterations [S1].

**Pseudocode:**
```python
def clipnerf_train_step(nerf_model, clip_model, text_prompt, optimizer, patch_size=128, stride=5, samples=16):
    # 1. Freeze density parameters in NeRF
    for param in nerf_model.density_params:
        param.requires_grad = False

    # 2. Sample a random camera pose
    camera_pose = sample_random_pose()

    # 3. Render a patch with reduced sampling for memory efficiency
    # Rays are sampled with stride to cover a larger receptive field
    rendered_patch = render_patch(
        nerf_model=nerf_model,
        camera_pose=camera_pose,
        patch_size=patch_size,
        ray_stride=stride,
        num_samples=samples
    )

    # 4. Resize patch for CLIP input
    resized_patch = bilinear_resize(rendered_patch, target_size=224) # Standard CLIP input size

    # 5. Encode image and text
    image_embedding = clip_model.encode_image(resized_patch)
    text_embedding = clip_model.encode_text(text_prompt)

    # 6. Normalize embeddings
    norm_img = normalize(image_embedding)
    norm_txt = normalize(text_embedding)

    # 7. Compute Absolute Directional CLIP Loss
    # L_dir = 1 - cosine_similarity(img_emb, txt_emb)
    cosine_sim = dot_product(norm_img, norm_txt)
    loss = 1.0 - cosine_sim

    # 8. Backpropagate and update only non-frozen parameters
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    return loss
```

**Edge Cases and Pitfalls:**
*   **Memory Constraints:** Naive differentiable rendering of high-resolution images is intractable due to memory limits; patch-based rendering is required [S1].
*   **Mode Collapse:** Absolute directional CLIP loss can cause mode collapse and reduce generation diversity [S2].
*   **Insufficient Magnitude:** Directional loss alone may struggle to reach sufficient stylization magnitude, resulting in weak style transfer [S2].

## Operating characteristics
*   **Time Complexity:** Limited by the 500 iteration count and the cost of CLIP encoding per patch [S1].
*   **Memory Complexity:** Reduced by using $128 \times 128$ patches and only 16 importance sampling points per ray [S1].
*   **Strengths:** Enables text-guided stylization without retraining the entire NeRF from scratch; efficient memory usage via patch rendering [S1, S2].
*   **Limitations:** May produce uneven stylization across the scene; absolute loss can lead to mode collapse; struggles with strong style magnitude [S2].
*   **When to Use:** When text-guided stylization of an existing NeRF is required and computational resources are limited [S1, S2].
*   **When Not to Use:** When high-fidelity, uniform stylization magnitude is critical without additional contrastive losses [S2].

## Background
The CLIPNeRF method was introduced by Wang et al. in 2021, extending the StyleCLIP approach to 3D NeRFs [S2]. It was further refined in NeRF-Art (2023) to address issues with mode collapse and insufficient stylization magnitude by introducing relative directional losses [S2]. The implementation details cited here are primarily from the feature field distillation approach which adapts CLIPNeRF for editing [S1].
