# Last Layer Re-training

Also called: Instant NeRF Editing, Last Layer Fine-tuning

## Overview
Last Layer Re-training is a technique for instantly propagating a color edit from a single user-provided view to an entire pre-trained Neural Radiance Field (NeRF) by selectively retraining only the final layer of the color Multi-Layer Perceptron (MLP) [S1]. It addresses the limitations of full retraining, which is computationally expensive and risks overwriting valuable pre-existing view-dependent information, by preserving the feature representations learned in earlier layers [S1]. Unlike methods that suffer from color bleeding at object boundaries or require hours to converge, this approach achieves high-quality, multi-view consistent edits in seconds [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained NeRF model (specifically the color MLP $MLP_c$) and a single edited view image $I_{edit} \in \mathbb{R}^{W \times H \times 3}$ containing the desired color changes [S1].
*   **Output:** A modified NeRF model where the color MLP has updated weights $\phi'_{last}$ for the last layer, producing new colors $c'_{x,\theta}$ [S1].

**Data Structures and Layout:**
The color MLP $MLP_c$ takes as input the concatenation of multiresolution hash grid features $f_x$ and a view direction encoding $\gamma(\theta)$ [S1].
*   **Feature Encoding:** The input feature vector $f_x$ is a concatenation of features from $L$ resolution levels:
    $$f_x = \{f_{x,0} \oplus f_{x,1} \oplus ... \oplus f_{x,L}\}$$
    where $\oplus$ denotes concatenation [S1].
*   **MLP Structure:** The standard color prediction is defined as:
    $$MLP_c(h_x, \gamma(\theta), \phi_c) = c_{x,\theta}$$
    where $h_x$ is the output hidden vector of the density MLP (or the penultimate layer of the color MLP depending on architecture specifics, but effectively the input to the final linear mapping), $\gamma(\theta)$ is the view direction encoding, $\phi_c$ are the original MLP weights, and $c_{x,\theta}$ is the rendered color [S1].
*   **Last Layer Modification:** The method replaces the full MLP retraining with a last-layer-only update. The new color prediction is:
    $$MLP_{last}(h_{x,\theta}, \phi'_{last}) = c'_{x,\theta}$$
    where $h_{x,\theta}$ is the output of the penultimate layer (which depends on position $x$ and view direction $\theta$) and $\phi'_{last}$ is the new set of parameters for the last layer of the color MLP [S1]. Note that $h_{x,\theta}$ is computed using the *original* pre-trained weights for all layers except the last one [S1].

**Numbered Steps:**
1.  **Freeze Pre-trained Weights:** Keep all weights of the pre-trained NeRF, including the density MLP and all layers of the color MLP except the final one, fixed.
2.  **Compute Penultimate Activations:** For each ray sampled during training, compute the intermediate feature vector $h_{x,\theta}$ using the frozen pre-trained network layers [S1]. This vector encapsulates the spatial and view-dependent information learned during the initial training.
3.  **Define Loss Function:** Minimize the difference between the volume-rendered RGB value $C'_{ij}$ from the edited NeRF and the original RGB value $C_{ij}$ from the user-provided edited image $I_{edit}$ [S1]. The loss is defined as:
    $$L = \sum \|C_{ij} - C'_{ij}\|^2$$
    where the sum is over pixels $(i,j)$ in the edited view [S1].
4.  **Optimize Last Layer Parameters:** Update only $\phi'_{last}$ using gradient descent to minimize $L$. This maps the existing features $h_{x,\theta}$ to the new target colors [S1].
5.  **Apply 3D Segmentation (Optional but Recommended):** To prevent edits from propagating to undesired regions (color bleeding), apply a lightweight 3D segmentation step. This restricts the loss calculation or weight updates to specific regions of interest identified from the 2D edit, ensuring multi-view consistency and preventing artifacts [S1].

**Parameters:**
*   **Optimizer:** Adam Optimizer [S1].
*   **Learning Rate:** 0.01 (constant) [S1].
*   **Iterations:** 200 iterations per scene [S1].
*   **Hardware:** Tested on NVIDIA RTX 3090 GPU [S1].

**Edge Cases and Pitfalls:**
*   **Color Bleeding:** Since the information in the color MLP is global, modifying the last layer can inadvertently affect regions not intended for editing [S1]. This is mitigated by the soft 3D segmentation step [S1].
*   **View-Dependent Effects:** A naive full retraining might lose specularities or other view-dependent effects. By freezing earlier layers, the method preserves these effects while only adjusting the color mapping [S1].
*   **Degenerate Input:** If the edited image contains significant geometric changes, this method (which only adjusts color) may not be sufficient, as it assumes the underlying geometry and appearance features remain valid [S1].

**Pseudocode:**
```python
# Assume pre_trained_nerf is loaded and frozen except for the last layer of the color MLP
# I_edit is the single edited view image
# optimizer = Adam(params=last_layer_weights, lr=0.01)

for iteration in range(200):
    # 1. Sample rays from the edited view I_edit
    rays = sample_rays_from_image(I_edit)
    
    # 2. Forward pass through frozen network to get penultimate activations
    # h_x_theta is the output of the penultimate layer of the color MLP
    # This uses the original pre-trained weights for all layers except the last one
    h_x_theta = []
    for ray in rays:
        # Get position x and view direction theta from ray
        # Get hash grid features f_x for position x
        # Compute intermediate features using frozen layers
        h = compute_penultimate_activation(ray.position, ray.direction, frozen_weights)
        h_x_theta.append(h)
    
    # 3. Apply last layer weights to predict new colors
    # c_prime is the predicted color using the trainable last layer weights
    c_prime = apply_last_layer(h_x_theta, last_layer_weights)
    
    # 4. Volume render the predicted colors to get C'_ij
    # Note: In Instant-NGP based implementations, this might be integrated
    # into the differentiable rendering pipeline
    C_prime = volume_render(c_prime, rays)
    
    # 5. Compute Loss against the edited image
    C_target = get_pixel_colors(I_edit, rays)
    
    # Apply segmentation mask if available to restrict loss to edited regions
    # mask = compute_3d_segmentation(rays, user_edit_mask)
    # loss = sum((C_target - C_prime)^2 * mask)
    loss = sum((C_target - C_prime)^2)
    
    # 6. Backpropagate and update only the last layer weights
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

## Subtopics

### [IReNe](13549-irene.md)
IReNe is a method for instant 360-degree recoloring of pre-trained Neural Radiance Fields (NeRFs) using a single user-edited image. It addresses the limitations of prior methods by preventing color bleeding at object boundaries and ensuring multi-view consistency for view-dependent effects, such as specularities. Unlike ICE-NeRF, which suffers from color bleeding, or Palette-NeRF, which requires hours to train, IReNe achieves high-quality edits in under 5 seconds by selectively fine-tuning only the diffuse neurons in the last layer of the color MLP.

## Operating characteristics
*   **Time Complexity:** Extremely fast, achieving near real-time editing (under 5 seconds) compared to hours required by full retraining methods [S1].
*   **Memory Complexity:** Low, as it only stores and updates the weights of the last layer, significantly reducing the number of parameters requiring modification [S1].
*   **Measured Performance:** Trained on a single NVIDIA RTX 3090 GPU, with 200 iterations per scene [S1].
*   **Strengths:** Preserves pre-existing view-dependent information (e.g., specularities), prevents color bleeding when combined with segmentation, and is computationally efficient [S1].
*   **Limitations:** Limited to color edits; does not handle geometric changes. Relies on the quality of the pre-trained features [S1].
*   **When to Use:** When instant recoloring of a NeRF is required, especially for view-dependent effects, and full retraining is too slow or destructive [S1].
*   **When Not to Use:** When geometric modifications are needed or when the pre-trained features are not suitable for the desired edit [S1].

## Background
The method was introduced in the paper "IReNe: Instant Recoloring of Neural Radiance Fields" by Mazzucchelli et al., published in CVPR 2024 [S1]. It builds upon Instant-NGP [S1] and addresses the challenges of interactive NeRF editing, specifically the trade-off between speed and quality, and the preservation of view-dependent effects [S1].
