# Multi-scale Joint Training Parameters

Also called: Multi-scale joint training loss weights

## Overview
Multi-scale joint training parameters are hyperparameters used to balance loss terms across different network depths or training stages in dynamically growing neural radiance fields. They ensure that uncertainty-aware losses and standard reconstruction losses contribute appropriately to the gradient updates as the network expands. This method is distinct from static regularization priors by adapting weights to the hierarchical structure of the model's growth.

## How it works
The method applies specific weights to loss components calculated at each stage of a dynamically growing network.

**Inputs and Outputs:**
- Input: Loss values from multiple stages $i=1 \dots D$, where $D$ is the current number of stages.
- Output: A scalar total loss $\mathcal{L}$ used for backpropagation.

**Data Structures:**
- $\mathcal{L}_{MSE}^i$: Mean Squared Error loss at stage $i$.
- $L_{unct}^i$: Uncertainty loss at stage $i$.
- $\beta_1, \beta_2$: Scalar weights.

**Formulas:**
The total loss is computed as [S1]:
$$
\mathcal{L} = \sum_{i=1}^D \beta_1 \mathcal{L}_{MSE}^i + \beta_2 L_{unct}^i
$$
where:
- $D$ is the current number of stages (also equal to $D-1$ times the network growth count).
- $\mathcal{L}_{MSE}^i$ is the MSE loss of the output image of layer $i$.
- $L_{unct}^i$ is the uncertainty loss of the output image of layer $i$.
- $\beta_1$ and $\beta_2$ are the multi-scale joint training weights.

**Parameters:**
- $\beta_1 = 1.0$
- $\beta_2 = 0.1$ [S1]

**Pseudocode:**
```python
def compute_multi_scale_loss(stages, beta1=1.0, beta2=0.1):
    """
    Compute total loss for dynamically growing NeRF stages.
    
    Args:
        stages: List of stage objects, each containing 'mse_loss' and 'unct_loss'.
        beta1: Weight for MSE loss.
        beta2: Weight for uncertainty loss.
        
    Returns:
        Total scalar loss.
    """
    total_loss = 0.0
    for stage in stages:
        mse_loss = stage.mse_loss
        unct_loss = stage.unct_loss
        total_loss += beta1 * mse_loss + beta2 * unct_loss
    return total_loss
```

**Edge Cases:**
- If the network has not grown ($D=1$), the sum contains only the initial stage.
- Uncertainty values must be positive; if $L_{unct}^i$ is undefined or zero, it contributes nothing to the weighted sum.

## Subtopics

### Multi-stage Training Protocol
A progressive training scheme used in inverse rendering frameworks that utilizes multi-scale parameters. It involves four steps: (1) Pretrain Direct Prediction Module (albedo, normal, depth) to ensure reasonable initial values; (2) Jointly train Direct and Lighting Joint Prediction Modules using a multi-task loss; (3) Freeze the first two modules and train the Joint Re-prediction Module; (4) End-to-end finetune all modules with multi-task loss on both joint prediction outputs and intermediate outputs [S2]. This protocol ensures stable convergence when learning HDR lighting from LDR images.

## Operating characteristics
- **Complexity:** Linear with respect to the number of stages $D$.
- **Performance:** Improves convergence in dynamically growing networks by preventing early stages from being overwhelmed by later-stage gradients [S1].
- **Limitations:** Requires careful tuning of $\beta_1$ and $\beta_2$ if the scale of MSE and uncertainty losses differs significantly across stages.

## Background
The parameters originate from Recursive-NeRF, which introduces an adaptive dynamic growth strategy. The method clusters uncertain queries to grow deeper networks, requiring balanced loss weighting across these new and existing stages [S1]. The multi-stage protocol is also referenced in inverse rendering contexts to handle coupled prediction tasks [S2].
