# Weighted Adam Optimizer

Also called: Visibility-aware Adam, Weighted Adam, Weighted Adam Optimization, Weighted Adam Updates

## Overview
Weighted Adam is an optimization variant for radiance-field parameters that modulates gradient updates based on the visibility of primitives, preventing divergence caused by obscured or irrelevant parameters in short segments [S1]. It differs from standard Adam by replacing the fixed bias-correction terms with accumulated visibility-weighted counters, ensuring that parameters with low average transmittance do not accumulate momentum from uninformative gradients [S1].

## How it works
**Inputs and Outputs:**
The method takes current parameters $\theta_{i-1}$, raw gradients $\nabla f_i(\theta_{i-1})$, previous first and second moments $m_{i-1}, v_{i-1}$, previous bias-correction accumulators $b_{i-1}^m, b_{i-1}^v$, base learning rate $\gamma$, Gaussian covariance properties, and a keyframe usage flag as inputs [S1]. It outputs the updated parameters $\theta_i$ and the updated state tensors [S1].

**Data Structures:**
The first and second moments $m_i, v_i$ maintain the exact shape of $\theta$ [S1]. The bias accumulators $b_i^m, b_i^v$ also match the shape of $\theta$, storing a scalar value per parameter [S1]. The visibility weight $\bar{u}_i$ is a scalar per Gaussian primitive derived from image-space transmittance [S1].

**Step 1: Compute Visibility Weight**
For each Gaussian primitive $g$ in image $l$, compute the weight $\eta$ (denoted $\bar{u}_i$ in the update formulas) as the average transmittance over the projected pixels $p$:
$$ \eta = \overline{T}_{g,l} = \frac{\sum_{p \in l} T_{g,p}}{N_{g,l}^p} $$
where $N_{g,l}^p$ is the number of pixels covered by the Gaussian in image $l$ [S1]. The weight $\eta \in [0,1]$ represents the average visibility or informativeness of the gradient for iteration $i$ [S1].

**Step 2: Modulate Learning Rate**
Compute the scale-based learning rate modulation factor $\gamma_g$ using the largest singular value of the covariance (largest scale $s_{g,i}$) and a multiplier $\alpha = 0.01$:
$$ \gamma_g = \min \left\{ 1, \alpha \max_i \{ s_{g,i} \} \right\} \gamma $$
where $\gamma$ is the base learning rate [S1].

**Step 3: Handle Keyframed Attributes**
If the parameter belongs to a keyframed attribute, only update it if the Gaussian was used in the current training iteration [S1]. If the Gaussian was not used, skip the update for this parameter [S1].

**Step 4: Compute Weighted Gradients**
The source defines an intermediate gradient $g_i = \nabla f_i(\theta_{i-1}) / \eta_i$ in Equation (44) [S1]. However, the momentum update equations (45–48) explicitly multiply the gradient terms by $\eta_i$, which would cancel the division [S1]. Following the explicit update equations and the method's name, the gradient contribution is treated as the raw gradient scaled by $\eta_i$ in the momentum terms [S1].

**Step 5: Update First and Second Moments**
Update the first moment estimate $m_i$ and second moment estimate $v_i$ using the visibility-weighted gradients and decay rates $\beta_1, \beta_2$:
$$ m_i = (1 - (1 - \beta_1)\bar{u}_i)m_{i-1} + (1 - \beta_1)\bar{u}_i g_i $$
$$ v_i = (1 - (1 - \beta_2)\bar{u}_i)v_{i-1} + (1 - \beta_2)\bar{u}_i g_i^2 $$
where $\beta_1$ is the momentum decay rate for the first moment and $\beta_2$ is the momentum decay rate for the second moment [S1].

**Step 6: Update Bias Correction Accumulators**
Unlike standard Adam, bias correction is not a closed-form function of step count because $\bar{u}_i$ varies per iteration [S1]. Accumulate the correction terms:
$$ b_i^m = (1 - (1 - \beta_1)\bar{u}_i) b_{i-1}^m + (1 - \beta_1)\bar{u}_i $$
$$ b_i^v = (1 - (1 - \beta_2)\bar{u}_i)b_{i-1}^v + (1 - \beta_2)\bar{u}_i $$
Initialize $b_0^m = 0, b_0^v = 0$ [G].

**Step 7: Compute Bias-Corrected Moments**
$$ \hat{m}_i = \frac{m_i}{b_i^m} $$
$$ \hat{v}_i = \frac{v_i}{b_i^v} $$
Guard against division by zero by adding a small constant $\epsilon$ to the denominators if $b_i^m$ or $b_i^v$ is zero [G].

**Step 8: Update Parameters**
$$ \theta_i = \theta_{i-1} - \bar{u}_i \frac{\beta_1 \hat{m}_i}{\beta_2 \hat{v}_i + \bar{u}_i} $$
This update rule is explicitly listed in the source notes [S1]. It deviates from the standard Adam update $\theta_{i-1} - \gamma \frac{\hat{m}_i}{\sqrt{\hat{v}_i} + \epsilon}$ by replacing the square-root variance denominator with a linear combination and scaling the entire step by $\bar{u}_i$ [S1].

**Pseudocode:**
```python
def weighted_adam_update(theta, grad, m, v, b_m, b_v, visibility_weight, base_lr, max_scale, beta1=0.9, beta2=0.999, alpha=0.01, epsilon=1e-8):
    """
    theta: current parameters
    grad: raw gradient
    m: first moment
    v: second moment
    b_m: bias correction accumulator for first moment
    b_v: bias correction accumulator for second moment
    visibility_weight: scalar eta in [0,1]
    base_lr: base learning rate gamma
    max_scale: largest singular value of the covariance
    beta1: momentum decay rate for first moment
    beta2: momentum decay rate for second moment
    alpha: multiplier for scale-based learning rate modulation
    epsilon: small constant for numerical stability
    """
    # Step 2: Modulate learning rate
    gamma_g = min(1.0, alpha * max_scale) * base_lr
    
    # Step 3: Keyframe check is handled by the caller skipping this function if not used
    
    # Step 4: Gradient contribution (raw gradient, weight applied in momentum steps)
    g_i = grad
    
    # Step 5: Update moments
    m = (1.0 - (1.0 - beta1) * visibility_weight) * m + (1.0 - beta1) * visibility_weight * g_i
    v = (1.0 - (1.0 - beta2) * visibility_weight) * v + (1.0 - beta2) * visibility_weight * (g_i ** 2)
    
    # Step 6: Update bias correction accumulators
    b_m = (1.0 - (1.0 - beta1) * visibility_weight) * b_m + (1.0 - beta1) * visibility_weight
    b_v = (1.0 - (1.0 - beta2) * visibility_weight) * b_v + (1.0 - beta2) * visibility_weight
    
    # Step 7: Bias correction with zero-guard
    denom_m = b_m if b_m > 0 else epsilon
    denom_v = b_v if b_v > 0 else epsilon
    m_hat = m / denom_m
    v_hat = v / denom_v
    
    # Step 8: Update parameters
    update = visibility_weight * (beta1 * m_hat) / (beta2 * v_hat + visibility_weight)
    theta = theta - update
    
    return theta, m, v, b_m, b_v
```

**Parameters:**
*   $\alpha = 0.01$: Multiplier for the scale-based learning rate modulation [S1].
*   $\beta_1 = 0.9$: Momentum decay rate for first moment (implied by standard Adam structure) [S1].
*   $\beta_2 = 0.999$: Momentum decay rate for second moment (implied by standard Adam structure) [S1].

**Edge Cases and Pitfalls:**
*   **Divergence:** Standard Adam updates all parameters regardless of visibility, leading to divergence when primitives are obscured or have many keyframes [S1]. Weighted Adam prevents this by weighting updates with $\bar{u}_i \in [0,1]$ [S1].
*   **Keyframed Attributes:** Must only be updated if used in the current iteration [S1].
*   **Bias Correction:** Cannot use closed-form step-count correction; must accumulate $b_i^m, b_i^v$ [S1].

## Operating characteristics
*   **Time Complexity:** Same as Adam per iteration, plus the cost of computing average transmittance $\overline{T}_{g,l}$ for each Gaussian [S1].
*   **Memory Complexity:** Requires storing additional accumulators $b_i^m, b_i^v$ for each parameter, doubling the memory overhead for bias correction compared to standard Adam which uses scalar step counters [S1].
*   **Performance:** Removing Weighted Adam drops PSNR from 25.95 to 20.42, SSIM from 0.848 to 0.551, and VMAF from 71.96 to 28.34 [S1].
*   **Strengths:** Prevents divergence from obscured primitives; allows for increased learning rates due to sparser but more consistent updates [S1].
*   **Limitations:** Requires visibility computation; more complex bias correction [S1].

## Background
Weighted Adam was introduced in the context of Adaptive Spatio-Temporal 3D Gaussian Splatting for Scenes with Oscillatory Motion [S1]. It addresses the issue that adaptive spatio-temporal subdivision makes Gaussians smaller more quickly than original densification, requiring a modified learning rate strategy and visibility-aware updates to prevent divergence [S1].
