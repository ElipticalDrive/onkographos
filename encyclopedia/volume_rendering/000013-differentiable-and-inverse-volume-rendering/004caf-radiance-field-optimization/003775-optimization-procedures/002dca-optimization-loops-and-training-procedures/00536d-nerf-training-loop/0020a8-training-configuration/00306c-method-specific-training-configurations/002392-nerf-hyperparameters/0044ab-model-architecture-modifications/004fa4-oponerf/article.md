# OPONeRF
Also called: One-Point-One NeRF

## Overview
OPONeRF is a neural rendering method that personalizes the parameters of the plenoptic mapping function for each sampled 3D point to handle test-time scene changes and robustness against perturbations such as motion, illumination changes, or contamination [S1, unofficial]. Unlike vanilla NeRFs where network parameters are shared and fixed, or generalizable NeRFs that condition fixed parameters on a latent code, OPONeRF dynamically conditions the network weights $\Theta$ on the point's representation $\mathbf{x}$ and the overall scene representation $\mathbf{F}$ [S1, unofficial]. This approach subdivides the scene and discriminatively responds to local variations, providing more expressiveness and flexibility than methods that model static appearance as stochastic variables [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of posed support images $\{I_k\}_{k=1}^K$, camera poses, and a ray $\mathbf{r}$ defined by origin $\mathbf{o}$ and direction $\mathbf{d}$.
*   **Outputs:** Radiance $\mathbf{c}$ and volume density $\sigma$ for the ray, which are volume-rendered into pixel colors.

**Data Structures:**
1.  **Overall Scene Representation ($\mathbf{F}$):** A 3D feature grid extracted from support images.
2.  **Point-wise Feature ($f_\mathbf{x}$):** A feature vector interpolated from $\mathbf{F}$ at coordinate $\mathbf{x}$.
3.  **Parameter Candidates ($\mathbf{W}^l_a$):** For each target layer $l$, a matrix of shape $\mathbb{R}^{C_i^l \times C_o^l}$ containing candidate weights.
4.  **Layer-variant Codes ($\mathbf{Z}^l$):** Randomly initialized matrices of shape $\mathbb{R}^{C_i^l \times C_o^l}$, updated during training.
5.  **Binary Masks ($M^l$):** Hard binary masks of shape $\mathbb{R}^{C_i^l \times C_o^l}$ generated by a mask decoder.
6.  **Adaptiveness Factor ($A_\mathbf{x}$):** A vector of length $L$ (number of target layers) for point $\mathbf{x}$, determining the selection of parameter candidates.

**Method Steps:**

1.  **Geometry Encoder:**
    *   Extract 2D feature maps $F_k$ from each support image $I_k$ using a shared CNN $T(\cdot)$.
    *   Construct a cost volume by warping features $F_k$ to a reference view ($k=1$) using homographic warping matrix $H_k(z)$ at depth $z$. The warped feature at pixel $(u,v)$ and depth $z$ is $F_{k,z}(u,v)$.
    *   Compute the view-wise variance of these warped features.
    *   Pass the cost volume through a 3D CNN $B(\cdot)$ to obtain the overall scene representation $\mathbf{F}$ [S1, unofficial].
    $$
    \begin{aligned}
    F_k &= T(I_k) \\
    F_{k,z}(u,v) &= W_k\bigl(\mathcal{H}_k(z)[u,v,1]^T\bigr) \\
    \mathbf{F} &= B\Bigl(\text{Var}\bigl(\{F_{k,z}(u,v)\}\bigr)\Bigr)
    \end{aligned}
    $$

2.  **Point Feature Interpolation:**
    *   For a sampled 3D point $\mathbf{x}$, interpolate its point-wise feature $f_\mathbf{x}$ from the gridded representation $\mathbf{F}$ [S1, unofficial].

3.  **Parameter Candidate Generation:**
    *   For each target layer $l$ (where $l=1, \dots, L$), decode $\mathbf{F}$ into a base parameter matrix $\mathbf{W}^l_d$ using a decoder $D^l_w(\cdot)$:
        $$ \mathbf{W}^l_d = D^l_w(\mathbf{F}) $$
    *   Decode $\mathbf{F}$ into a hard binary mask $M^l$ using a mask decoder $D^l_m(\cdot)$:
        $$ M^l = D^l_m(\mathbf{F}) $$
    *   Fuse the base parameters with layer-variant codes $\mathbf{Z}^l$ using the mask $M^l$ and an all-ones matrix $J$ to compute final candidate parameters $\mathbf{W}^l_a$:
        $$ \mathbf{W}^l_a = (J - M^l) * \mathbf{W}^l_d + M^l * \mathbf{Z}^l $$
        where $*$ denotes the Hadamard product [S1, unofficial].

4.  **Discriminative Parameter Personalization:**
    *   Compute the adaptiveness factor $A_\mathbf{x} \in \mathbb{R}^L$ for point $\mathbf{x}$, which discriminatively selects from the parameter pool $\mathbf{W}^l_a$ [S1, unofficial].
    *   The renderer uses the Ray Transformer architecture. The target layers personalized per point are the query (Q), key (K), value (V) projection MLPs and the feedforward layer of the Ray Transformer [S1, unofficial].

5.  **Probabilistic Modeling of Point Representation:**
    *   Model $f_\mathbf{x}$ probabilistically to suppress trivial solutions and encourage diversity.
    *   Use an encoder $Enc(\cdot)$ and decoder $Dec(\cdot)$ mapping to a latent space.
    *   Minimize the reconstruction loss $L_{rec}$ and a divergence loss $L_{div}$ [S1, unofficial].

6.  **Rendering:**
    *   Perform volume rendering using the personalized parameters to output $\mathbf{c}$ and $\sigma$, supervised by photometric loss [S1, unofficial].

import torch
import torch.nn as nn
import torch.nn.functional as F

class OPONeRF:
    def __init__(self, support_images, poses, num_target_layers, layer_dims):
        """
        Initialize OPONeRF.
        support_images: Tensor [K, H, W, 3]
        poses: Tensor [K, 4, 4]
        num_target_layers: int L
        layer_dims: list of tuples [(C_i^1, C_o^1), ..., (C_i^L, C_o^L)]
        """
        self.K = len(support_images)
        self.L = num_target_layers
        self.layer_dims = layer_dims
        
        # Geometry Encoder
        self.shared_cnn = SharedCNN() # Extracts 2D features
        self.cnn_3d = CNN3D() # Produces F from cost volume
        
        # Parameter Candidate Decoders (PCD)
        # Each PCD has Dw and Dm
        self.pcds = nn.ModuleList([
            PCD(dim_i, dim_o) for dim_i, dim_o in layer_dims
        ])
        
        # Layer-variant codes Z^l
        self.layer_variant_codes = nn.ParameterList([
            nn.Parameter(torch.randn(dim_i, dim_o)) 
            for dim_i, dim_o in layer_dims
        ])
        
        # Adaptiveness factor network
        self.adaptiveness_net = nn.Sequential(
            nn.Linear(256, 128), # Assuming f_x dim is 256, adjust as needed
            nn.ReLU(),
            nn.Linear(128, num_target_layers)
        )
        
        # Ray Transformer Renderer (simplified structure)
        self.renderer = RayTransformer(layer_dims)

    def geometry_encoder(self, support_images, poses):
        """
        Extract overall scene representation F.
        """
        # Extract 2D features
        features = [self.shared_cnn(img) for img in support_images] # List of [H, W, C]
        
        # Construct cost volume
        # Warping features to reference view (k=0)
        # Assuming homographic warping function warp_feature exists
        cost_volume = []
        for k in range(self.K):
            # Warp feature F_k to reference view at depth z
            # F_{k,z}(u,v) = W_k(H_k(z)[u,v,1]^T)
            # Compute variance across views
            # This is a simplified representation; actual implementation requires depth sampling
            warped = warp_to_reference(features[k], poses[k], poses[0])
            cost_volume.append(warped)
        
        cost_volume = torch.stack(cost_volume, dim=0) # [K, H, W, C]
        variance = torch.var(cost_volume, dim=0) # [H, W, C]
        
        # Pass through 3D CNN to get F
        F = self.cnn_3d(variance.unsqueeze(0)) # [1, H, W, C_out]
        return F

    def interpolate_point_feature(self, F, points_3d):
        """
        Interpolate f_x from F for given 3D points.
        """
        # Trilinear interpolation from grid F to points_3d
        # points_3d: [N, 3] normalized to [-1, 1]
        f_x = F.grid_sample(points_3d)
        return f_x

    def generate_candidates(self, F):
        """
        Generate parameter candidates W_a^l and masks M^l for all target layers.
        """
        candidates = []
        masks = []
        for l in range(self.L):
            dim_i, dim_o = self.layer_dims[l]
            pcd = self.pcds[l]
            
            # Decode base parameters
            W_d = pcd.decode_weights(F) # [C_i, C_o]
            
            # Decode mask
            M = pcd.decode_mask(F) # [C_i, C_o]
            # Apply binary quantization with gradient estimator
            M_binary = straight_through_estimator(M)
            
            # Layer-variant codes
            Z = self.layer_variant_codes[l] # [C_i, C_o]
            
            # All-ones matrix
            J = torch.ones_like(M_binary)
            
            # Fuse
            W_a = (J - M_binary) * W_d + M_binary * Z
            candidates.append(W_a)
            masks.append(M_binary)
            
        return candidates, masks

    def compute_adaptiveness(self, f_x):
        """
        Compute adaptiveness factor A_x for point x.
        """
        # f_x is the point-wise feature
        A_x = self.adaptiveness_net(f_x) # [L]
        # Normalize or apply softmax if necessary
        return F.softmax(A_x, dim=0)

    def forward(self, rays, support_images, poses):
        """
        Forward pass for a batch of rays.
        rays: [N, 2, 3] (origin, direction)
        """
        # 1. Geometry Encoder
        F = self.geometry_encoder(support_images, poses)
        
        # 2. Sample points along rays
        # Standard NeRF sampling logic
        points_3d = sample_points_along_rays(rays, num_samples=64) # [N, 64, 3]
        
        # 3. Interpolate point features
        f_x = self.interpolate_point_feature(F, points_3d) # [N, 64, D]
        
        # 4. Generate Parameter Candidates
        candidates, masks = self.generate_candidates(F)
        
        # 5. Compute Adaptiveness Factors
        # Reshape f_x to [N*64, D]
        f_x_flat = f_x.view(-1, f_x.shape[-1])
        A_x = self.compute_adaptiveness(f_x_flat) # [N*64, L]
        
        # 6. Personalize Renderer Parameters
        # The renderer uses the candidates based on A_x
        # This step is integrated into the Ray Transformer forward pass
        # where the weights are dynamically selected/fused
        
        # 7. Render
        # Use Ray Transformer with personalized weights
        # Output c and sigma
        c, sigma = self.renderer.forward(
            points_3d, 
            rays[:, 1, :], # directions
            candidates, 
            A_x
        )
        
        # Volume Rendering
        # Standard alpha compositing
        T = torch.cumprod(torch.exp(-sigma * dists), dim=-1)
        weights = sigma * torch.exp(-dists) * T
        color = torch.sum(weights * c, dim=-1)
        
        return color

**Formulas:**
*   **Mapping:** $\mathcal{M}_\Theta^{opo}(\mathbf{x}): (\mathbf{x}, f_\mathbf{x}, \mathbf{d}, \mathbf{F}) \longrightarrow (\mathbf{c}, \sigma)$ [S1, unofficial].
*   **Parameter Fusion:** $\mathbf{W}^l_a = (J - M^l) * \mathbf{W}^l_d + M^l * \mathbf{Z}^l$ [S1, unofficial].
*   **Probabilistic Loss (ELBO):**
    $$ \mathcal{L}_{\mathbf{\mu}_\mathbf{x}, \mathbf{\sigma}_\mathbf{x}}(f_\mathbf{x}) \approx \frac{1}{B}\sum_{i=1}^B \ln p_\theta(f_\mathbf{x}^i|f_\mathbf{x}^{Vi}) + \frac{1}{2B}\sum_{i=1}^B\sum_{j=1}^D \left(1 + \ln((\sigma^{(j)}_{\mathbf{x}_i})^2) - (\mu^{(j)}_{\mathbf{x}_i})^2 - (\sigma^{(j)}_{\mathbf{x}_i})^2\right) $$
    where $B$ is batch size and $D$ is dimension [S1, unofficial].
*   **Reconstruction Loss:** $L_{rec} = \frac{1}{B}\sum_{i=1}^B ||Enc(f_x^i) - Dec(F_x^i)||_2$ [S1, unofficial].
*   **Diversity Loss:** $L_{div} = -\frac{1}{|R|}\sum_{r=1}^{|R|} ||\mu_{r,\cdot} - \tilde{\mu}_{r,\cdot}|| - \frac{1}{N}\sum_{s=1}^N ||\mu_{\cdot,s} - \tilde{\mu}_{\cdot,s}||$ [S1, unofficial].
*   **Gradient Approximation for Binary Quantization:**
    $$ \frac{d}{dx}S(x) \approx H(x) = \begin{cases} 2-4|x|, & -0.4 \le x \le 0.4 \\ 0.4, & 0.4 < |x| \le 1 \\ 0, & \text{otherwise} \end{cases} $$ [S1, unofficial].

**Parameters:**
*   $\mathbf{Z}^l$: Layer-variant codes, shape $\mathbb{R}^{C_i^l \times C_o^l}$, initialized randomly [S1, unofficial].
*   $\mathbf{W}^l_a$: Candidate parameters, shape $\mathbb{R}^{C_i^l \times C_o^l}$ [S1, unofficial].
*   $L$: Number of target layers, typically all linear layers except the last regression heads [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Computational Cost:** Generating full-sized output for PCD is expensive when layer widths $C_i^l, C_o^l > 1000$. Mitigation: Generate a down-sized output, apply linear layers to upscale dimensions, then element-wise multiply with randomly initialized full-sized matrices that are iteratively optimized [S1, unofficial].
*   **Non-differentiable Quantization:** The step function $S(x)$ for binary mask generation is non-differentiable. Mitigation: Use the long-tailed estimator $H(x)$ for gradient computation [S1, unofficial].

## Operating characteristics
*   **Complexity:** The method introduces significant overhead due to the geometry encoder (3D CNN) and the dynamic parameter generation for each point. The computational cost of PCD is high for full-sized outputs, mitigated by the down-sizing technique [S1, unofficial].
*   **Performance:** OPONeRF is designed for robustness against test-time perturbations (motion, illumination, contamination) [S1, unofficial].
*   **Strengths:** Personalizes the renderer per point, offering more expressiveness than fixed-parameter NeRFs or generalizable NeRFs [S1, unofficial].
*   **Limitations:** High computational cost for large layer widths; requires careful implementation of gradient estimators for binary masks [S1, unofficial].

## Background
OPONeRF (One-Point-One NeRF) was introduced to address the limitations of standard NeRFs and generalizable NeRFs in handling dynamic or perturbed scenes. While generalizable NeRFs condition fixed parameters on a latent code, OPONeRF conditions the parameters on the sampled point's representation [S1, unofficial]. It builds on the Ray Transformer architecture [S1, unofficial].
