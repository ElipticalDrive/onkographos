# Progressive Coarse-to-Fine Training Strategy

Also called: Progressive Training, Coarse-to-Fine Strategy

## Overview
A training methodology that decouples the recovery of global scene structure from the refinement of high-frequency details by progressively increasing input complexity or model capacity [S1][S2, S3, unofficial]. It solves the problem of optimization instability and local minima in radiance field reconstruction, particularly in dynamic scenes or when camera poses are imperfect [S1][S3, S4, unofficial]. It sets itself apart from single-resolution training by preventing the model from committing to high-frequency noise before establishing geometric coherence [S2, unofficial], and differs from the NeRF Restarting Approach by using a continuous schedule of complexity rather than discrete restarts [12980-nerf-restarting-approach.md].

## How it works
The strategy generally follows a two-phase progression: a **Coarse Stage** where the model learns global geometry with simplified representations, and a **Fine Stage** where the model refines details with full complexity. The specific implementation varies by domain (dynamic scenes, mapping, or pose estimation).

### Inputs and Outputs
*   **Inputs:** A set of training images (potentially with time steps or camera poses), initial camera parameters (intrinsics/extrinsics), and scene bounds.
*   **Outputs:** A trained radiance field model (NeRF or variant) with optimized geometry and appearance.

### Data Structures
*   **Training Set:** A collection of rays sampled from input images. In incremental mapping, this set grows over time [S2, unofficial].
*   **Model Parameters:**
    *   *Coarse Stage:* Color features may be set to the color itself, ignoring ray direction [S1]. Or, input images are smoothed [S4, unofficial].
    *   *Fine Stage:* Color features are high-dimensional vectors; ray direction dependency is modeled explicitly (e.g., via $F_{\theta4}$) [S1].

### Numbered Steps (General Progressive Coarse-to-Fine)
1.  **Initialize Coarse Model:** Configure the network for low-complexity representation.
    *   *Dynamic Scenes:* Set color feature to be the color itself, without ray direction dependency [S1].
    *   *Pose Estimation:* Apply Gaussian smoothing to input images [S4, unofficial].
2.  **Coarse Training:**
    *   *Progressive Input (Dynamic):* Start training with images close to a canonical time step. Progressively add images with farther time steps until all are included [S1].
    *   *Incremental Mapping:* Sample rays (e.g., 8,192 per step) and train for a fixed number of iterations (e.g., 5,000). Insert new observations into the training set at regular intervals (e.g., every 50 iterations) [S2, unofficial].
    *   *Scale-Space:* Use a linear schedule for the smoothing parameter $\gamma_i$ from 0 to 1 during the first half of training [S4, unofficial].
3.  **Transition:**
    *   *Dynamic Scenes:* Compute a smaller bounding box using proxy geometry from the coarse stage to filter empty space [S1].
    *   *Mapping:* Switch to using all observations [S2, unofficial].
    *   *Scale-Space:* Reduce smoothing as $\gamma_i$ approaches 1 [S4, unofficial].
4.  **Fine Training:**
    *   *Dynamic Scenes:* Set color features to high-dimensional vectors and model ray direction dependency [S1].
    *   *Mapping:* Perform refinement for a larger number of iterations (e.g., 20,000) [S2, unofficial].
    *   *Scale-Space:* Train with full-resolution images as smoothing vanishes [S4, unofficial].

### Formulas
*   **Gaussian Scale-Space Smoothing:**
    The standard deviation $\sigma$ of the Gaussian kernel applied to input images is defined as:
    $$ \sigma = 4 \times (1 - \gamma_i) $$
    where $\gamma_i$ is a schedule parameter [S4, unofficial].
*   **Schedule Parameter:**
    $\gamma_i$ increases linearly from 0 to 1 during the first half of training [S4, unofficial].

### Parameters
*   **Ray Sample Count:** 8,192 rays per optimization step (for coarse mapping) [S2, unofficial].
*   **Iterations:**
    *   Coarse stage: 5,000 iterations [S2, unofficial].
    *   Refinement/Fine stage: 20,000 iterations [S2, unofficial].
*   **Insertion Interval:** New observations inserted every 50 iterations during the coarse stage [S2, unofficial].
*   **Optimizer:** Adam [S2, unofficial].
*   **Learning Rate:** $10^{-1}$ [S2, unofficial].
*   **Gaussian Kernel:** Standard deviation $4 \times (1 - \gamma_i)$ [S4, unofficial].

### Edge Cases and Pitfalls
*   **Homogeneous Scenes:** Gaussian scale-space coarse-to-fine methods may get stuck in local minima for pose estimation in very homogeneous scenes where texture is lacking [S4, unofficial].
*   **Empty Space:** In dynamic scenes, failing to compute a smaller bounding box with proxy geometry in the coarse stage may lead to inefficient fine-stage training due to empty space sampling [S1].
*   **Precision:** Not given in the sources.

    """
    Generic implementation of Progressive Coarse-to-Fine Training.
    Adapted from [S1][S2, S4, unofficial].
    """
    # Initialize model with coarse configuration
    model = initialize_model(coarse=True)
    
    # Setup training set based on strategy type
    if config.strategy == "dynamic_progressive":
        # Start with canonical time images
        current_images = get_images_close_to_canonical(scene_data)
    elif config.strategy == "incremental_mapping":
        current_images = scene_data.initial_images
    elif config.strategy == "scale_space":
        current_images = scene_data.all_images
        gamma = 0.0
    else:
        raise ValueError("Unknown strategy")

    optimizer = Adam(model.parameters(), lr=1e-1)

    # Coarse Stage
    for iteration in range(config.coarse_iterations):
        if config.strategy == "incremental_mapping":
            if iteration % config.insertion_interval == 0:
                current_images = add_new_observations(current_images, scene_data)
        
        if config.strategy == "scale_space":
            # Linear schedule for first half of training
            progress = iteration / config.coarse_iterations
            gamma = 2.0 * progress # 0 to 1 in first half
            sigma = 4.0 * (1.0 - gamma)
            current_images = apply_gaussian_blur(scene_data.all_images, sigma)
            # Use subset of images or all? Source implies smoothing input images
            # We assume we train on the smoothed versions of available images
            rays = sample_rays(current_images, count=8192)
        else:
            rays = sample_rays(current_images, count=8192)

        loss = compute_loss(model, rays)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

    # Transition
    if config.strategy == "dynamic_progressive":
        # Compute proxy geometry and smaller bounding box
        bbox = compute_proxy_bbox(model)
        # Add all remaining images
        current_images = scene_data.all_images
        # Switch to fine model configuration
        model = initialize_model(coarse=False, bbox=bbox)
        optimizer = Adam(model.parameters(), lr=1e-1) # Reset or continue? Source implies new model
    elif config.strategy == "incremental_mapping":
        # Use all observations
        current_images = scene_data.all_images
        model = initialize_model(coarse=False)
        optimizer = Adam(model.parameters(), lr=1e-1)
    elif config.strategy == "scale_space":
        # Gamma reaches 1, sigma becomes 0 (no blur)
        pass

    # Fine Stage
    for iteration in range(config.fine_iterations):
        if config.strategy == "scale_space":
            # Gamma stays 1 or continues? Source says "first half". 
            # Assuming full resolution for second half.
            rays = sample_rays(scene_data.all_images, count=8192)
        else:
            rays = sample_rays(current_images, count=8192)

        loss = compute_loss(model, rays)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

    return model

## Subtopics

### [Two-Stage Training Pipeline](11433-two-stage-training-pipeline.md)
A coarse-to-fine training strategy that first recovers global shape at low resolution, then refines fine details at high resolution. It sets itself apart from single-resolution training by decoupling structural coherence from high-frequency detail recovery, allowing the model to converge to a stable global geometry before committing computational resources to fine-grained optimization.

### Incremental Mapping Optimization
A variant where new observations are inserted into the training set at regular intervals during the coarse stage [S2, unofficial]. It uses 8,192 rays per step, 5,000 coarse iterations, and 20,000 refinement iterations [S2, unofficial].

### Progressive Reconstruction
A technique that restrains the model's ability to reconstruct complex scenes at early stages to enforce consistency across different supervision viewpoints, providing stability with simple training [S3, unofficial]. Introduced in FreeNeRF and Nerfies [S3, unofficial].

### Gaussian Scale-Space Coarse-to-Fine
A coarse-to-fine training procedure that smooths input images with a Gaussian kernel during NeRF training to improve pose estimation robustness [S4, unofficial]. It uses a standard deviation of $4 \times (1 - \gamma_i)$ and a linear schedule for $\gamma_i$ from 0 to 1 in the first half of training [S4, unofficial]. It outperforms baselines in 12/14 and 11/14 cases for rotation and translation estimation but fails in homogeneous scenes [S4, unofficial].

## Operating characteristics
*   **Time Complexity:** Generally higher than single-resolution training due to the two-stage process, but converges more reliably. The incremental mapping variant adds overhead for observation insertion [S2, unofficial].
*   **Memory Complexity:** The coarse stage may use less memory if a smaller bounding box is computed and used to filter empty space [S1].
*   **Measured Performance:** Gaussian scale-space coarse-to-fine outperforms the baseline in 12/14 and 11/14 cases for rotation and translation estimation respectively [S4, unofficial].
*   **Strengths:** Stability in optimization, robustness to imperfect camera poses, ability to handle dynamic scenes [S1][S3, S4, unofficial].
*   **Limitations:** Fails in very homogeneous scenes for pose estimation [S4, unofficial]. Requires careful tuning of schedule parameters [S4, unofficial].
*   **When to Use:** When dealing with dynamic scenes, sparse views, or imperfect camera poses [S1][S3, S4, unofficial].
*   **When Not to Use:** In very homogeneous scenes where direct alignment may struggle less with texture loss [S4, unofficial].
