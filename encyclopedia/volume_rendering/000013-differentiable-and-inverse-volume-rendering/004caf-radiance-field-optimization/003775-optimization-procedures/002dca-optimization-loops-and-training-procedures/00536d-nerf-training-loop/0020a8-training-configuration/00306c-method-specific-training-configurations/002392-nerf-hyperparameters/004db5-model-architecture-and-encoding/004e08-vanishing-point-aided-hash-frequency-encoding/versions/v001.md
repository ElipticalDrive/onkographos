# Vanishing Point Aided Hash-Frequency Encoding

Also called: NeurVPS-ERP

## Overview
Vanishing Point Aided Hash-Frequency Encoding is a hybrid input encoding scheme for Neural Radiance Fields (NeRF) that combines multi-resolution hash encoding with deterministic frequency encoding aligned to scene structure via estimated vanishing points [S1]. It solves the problem of poor reconstruction quality and instability when training NeRFs from sparse 360° inputs or imperfectly centered scenes, where standard hash encoding fails due to lack of learnable explicit structure [S1]. Unlike standard hash encoding which relies solely on learnable features, this method adds deterministic frequency features to improve generalizability and robustness to imperfect scene positioning without requiring additional depth information or pre-training [S1].

## How it works
**Inputs:**
*   3D spatial coordinates $\mathbf{u} \in \mathbb{R}^3$.
*   2D images (typically Equi-Rectangular Projection, ERP) for vanishing point estimation.
*   Hyperparameters: $m$ (number of frequency levels), $k$ (number of hash grid levels), $f$ (feature size per hash cell).

**Outputs:**
*   A concatenated feature vector $\gamma(\mathbf{u}) \in \mathbb{R}^{kf + 2md}$ used as input to the NeRF MLP [S1].

**Data Structures:**
1.  **Multi-resolution Hash Grid:** A set of $k$ levels. Each level consists of a hash table mapping spatial coordinates to feature vectors of dimension $f$. The hash function is a pseudo-random permutation independent for each level [S1].
2.  **Vanishing Points:** A set of $n$ vanishing points $v_i(\lambda_i, \theta_i)$ estimated from input images, where $\lambda_i$ is the plane angle (longitude) and $\theta_i$ is the incline (latitude/elevation) [S1].

**Steps:**

1.  **Vanishing Point Estimation:**
    Estimate vanishing points from the input 2D images. The method uses an adapted NeurVPS network (NeurVPS-ERP) that employs conic convolution on Equi-Rectangular Projection (ERP) images to detect global scene structure [S1]. Let the estimated vanishing points be $v_i$ for $i=1 \dots n$.

2.  **Coordinate Alignment:**
    For each vanishing point $v_i(\lambda_0, \theta)$, transform the input 3D coordinate $\mathbf{u}$ into angular coordinates relative to the vanishing point direction. This involves projecting the 3D point onto the unit sphere to obtain spherical coordinates $(\lambda, \phi)$ and computing the aligned angular coordinate $\alpha_i$ [S1].
    
    The latitude $\phi(\lambda)$ of a spatial line $L$ projected on the sphere is given by:
    $$ \phi(\lambda) = \arctan\left( \frac{\tan(\phi_0) + \tan(\theta)\tan(\lambda - \lambda_0)}{\sqrt{1 + \tan^2(\lambda - \lambda_0)}} \right) $$
    where $\lambda_0$ is the plane angle of the vanishing point, $\theta$ is the incline, and $\phi_0$ is the elevation [S1].
    
    The elevation $\phi_0$ for a point $p(\lambda, \phi)$ relative to vanishing point $v(\lambda_0, \theta)$ is calculated as:
    $$ \phi_0(\lambda, \phi) = \arctan\left( \tan(\phi) \sqrt{1 + \tan^2(\lambda - \lambda_0)} - \tan(\theta)\tan(\lambda - \lambda_0) \right) $$
    [S1]
    
    The aligned coordinate $\alpha_i$ corresponds to the angle along the radial lines originating from the vanishing point. Points on these radial lines share the same $\alpha_i$ value [S1]. The aligned input vector is constructed as $\mathbf{u}_{aligned} = (\alpha_1, \dots, \alpha_n)^\top$ [S1].

3.  **Frequency Encoding:**
    Generate $m$-level frequency-encoded input coordinates $\gamma_{FE}(\mathbf{u}) \in \mathbb{R}^{2md}$ using sinusoidal positional encoding on the aligned coordinates $\mathbf{u}_{aligned}$ [S1].
    
    The frequency encoding is defined as:
    $$ \gamma_{FE}(\mathbf{u}) = \left[ \dots, \cos(2\pi \sigma^{j/m} \mathbf{u}_{aligned}), \sin(2\pi \sigma^{j/m} \mathbf{u}_{aligned}), \dots \right]^\top $$
    for $j = 0, \dots, m-1$, where $\sigma$ is a scaling factor (hyperparameter) [S1]. Note: The source formula uses $\sigma_j/m$ in the exponent context of standard NeRF, but explicitly states "logarithmically-spaced axis-aligned frequencies" and cites the standard NeRF positional encoding form. The dimension is $2md$ because each of the $n$ aligned coordinates (where $n$ is implicitly handled by the dimensionality of $\alpha$) is encoded with $m$ frequencies, producing $2m$ values per coordinate. If $\mathbf{u}_{aligned}$ has dimension $n$, the output is $2m \times n$. The source states $\gamma_{FE}(\mathbf{u}) \in \mathbb{R}^{2md}$, implying $d$ might be the dimension of the aligned space or a specific configuration. Given $\mathbf{u} \in \mathbb{R}^3$ and $n$ vanishing points, if $d=n$, the dimension is $2mn$. The source notation $\mathbb{R}^{2md}$ suggests $d$ is the number of vanishing points or a related dimension. We assume $d$ represents the dimensionality of the aligned angular space (number of vanishing points $n$) [S1].

4.  **Hash Encoding:**
    Hash-encode the original input coordinates $\mathbf{u}$ using the $k$-level multi-resolution feature grid of feature size $f$. This involves:
    *   Mapping $\mathbf{u}$ to grid cells at each of the $k$ resolutions.
    *   Retrieving learnable feature vectors for the corners of the cell.
    *   Performing trilinear (or appropriate dimension) interpolation to obtain the hash-encoded feature vector $\gamma_{H}(\mathbf{u}) \in \mathbb{R}^{kf}$ [S1].

5.  **Concatenation:**
    Concatenate the hash-encoded features and the frequency-encoded features to form the final feature vector:
    $$ \gamma(\mathbf{u}) = [\gamma_{H}(\mathbf{u}), \gamma_{FE}(\mathbf{u})] \in \mathbb{R}^{kf + 2md} $$
    [S1]

**Parameters:**
*   $m$: Number of frequency levels. Typical values not explicitly given, but standard NeRF uses $m=10$ [S1].
*   $k$: Number of levels in the multi-resolution hash grid. Typical values not explicitly given, but Instant-NGP uses $k=16$ [S1].
*   $f$: Feature size (dimensionality) of each cell in the hash grid. Typical values not explicitly given, but Instant-NGP uses $f=2$ [S1].

**Edge Cases and Pitfalls:**
*   **Sparse Input:** Hash encoding fails when input is extremely sparse (e.g., 8 inputs 1 meter apart). The method mitigates this by adding deterministic frequency features which do not rely on learnable explicit structure [S1].
*   **Scene Centering/Scaling:** Proper centering and scaling of the scene are crucial for hash encoding performance. Imperfect positioning in 360° scenes with random camera poses can degrade performance. The auxiliary frequency features provide robustness against these imperfections [S1].
*   **Singularity:** The spherical coordinate conversion has a singularity at the origin ($r=0$). This must be handled explicitly [G].

## Operating characteristics
*   **Time Complexity:** The encoding involves computing vanishing points (offline/pre-processing), spherical coordinate transformations, and hash lookups. Hash lookups are $O(1)$ on average. Frequency encoding is $O(m \cdot n)$. Overall encoding time is dominated by hash grid lookups and interpolation, similar to Instant-NGP [S1].
*   **Memory Complexity:** Memory usage is the sum of the hash grid memory ($k \times \text{table size} \times f$) and the storage for vanishing points. The hash grid size is determined by the implementation of Instant-NGP [S1].
*   **Performance:** The method improves reconstruction quality from sparse 360° inputs compared to standard hash encoding. It does not add overhead to the NeRF network itself or require additional depth information [S1].
*   **Strengths:** Robust to sparse inputs and imperfect scene centering. Combines the efficiency of hash encoding with the generalizability of frequency encoding.
*   **Limitations:** Requires vanishing point estimation, which adds a pre-processing step. Performance depends on the accuracy of vanishing point estimation.

## Background
*   **Origin:** The method was introduced in the paper "Vanishing Point Aided Hash-Frequency Encoding for Neural Radiance Fields (NeRF) from Sparse 360° Input" [S1].
*   **History:** It builds upon Instant-NGP for hash encoding [S1] and NeurVPS for vanishing point estimation [S1]. It addresses the limitations of hash encoding in sparse scenarios, which are common in 360° scene reconstruction [S1].
*   **Usage:** Used in neural radiance field optimization for view synthesis from sparse inputs, particularly 360° images [S1].
