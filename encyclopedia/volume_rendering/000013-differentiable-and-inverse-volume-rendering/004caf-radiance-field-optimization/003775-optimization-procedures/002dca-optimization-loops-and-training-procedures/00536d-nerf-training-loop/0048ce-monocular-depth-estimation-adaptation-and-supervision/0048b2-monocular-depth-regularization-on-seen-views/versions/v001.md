# Monocular Depth Regularization on Seen Views

Also called: Patch-wise depth alignment, Seen-view depth distillation

## Overview
This method applies a depth consistency loss to align pseudo-depth maps generated by a pre-trained Monocular Depth Estimation (MDE) network with NeRF-rendered depth for seen input views [S1, unofficial]. It differs from global scale/shift fitting by computing alignment parameters per image patch, which prevents dominant objects from skewing the depth alignment and alleviates local geometric inconsistencies [S1, unofficial].

## How it works
**Inputs:**
- Set of seen view images $S$.
- Pre-trained MDE network $G_\phi$ with parameters $\phi$ [S1, unofficial].
- Current NeRF model capable of rendering depth [S1, unofficial].

**Outputs:**
- Depth consistency loss $L_{seen}$ [S1, unofficial].

**Data Structures:**
- $I_i$: Input image for view $i$.
- $D_i^*$: Pseudo-depth map from MDE.
- $\bar{D}_i$: Rendered depth map from NeRF.
- $P$: Set of pixel coordinates within a specific patch.
- $w_i, q_i$: Scale and shift parameters for the patch.

**Steps:**
1. For each seen view image $I_i \in S$:
2. Render the NeRF depth map $\bar{D}_i$ for the camera pose of $I_i$ [S1, unofficial].
3. Compute the pseudo-depth map $D_i^* = G_\phi(I_i)$ using the pre-trained MDE network [S1, unofficial].
4. Divide the image into patches. For each patch defined by pixel set $P$:
5. Compute scale $w_i$ and shift $q_i$ via least squares to align $D_i^*$ with $\bar{D}_i$ [S1, unofficial].
6. Calculate the loss contribution for the patch using the formula below [S1, unofficial].
7. Sum the losses over all patches and all seen views [S1, unofficial].

**Formula:**
$$
L_{seen} = \sum_{I_i \in S} \sum_{p \in P} \left\| (w_i \cdot \text{sg}(D_i^*(p)) + q_i) - \bar{D}_i(p) \right\|
$$

**Definitions:**
- $\text{sg}(\cdot)$: Stop-gradient operation applied to $D_i^*$ to prevent gradient flow into the MDE network [S1, unofficial].
- $w_i, q_i$: Scale and shift parameters obtained by least squares between $D_i^*$ and $\bar{D}_i$ [S1, unofficial].
- $P$: Set of pixels within a patch [S1, unofficial].

**Parameters:**
- Patch size: Not given in the sources.
- Least squares solver: Standard linear least squares [S1, unofficial].

**Pitfalls:**
- Global scale/shift fitting favors dominant objects, causing ill-fitted depths in less dominant sections [S1, unofficial].
- The patch-wise approach reduces the computational bottleneck of full image rendering compared to global fitting [S1, unofficial].

**Pseudocode:**
```python
def compute_monocular_depth_regularization_loss(
    seen_views: List[Image],
    nerf_model: NeRF,
    mde_model: MDE,
    patch_size: int
) -> Tensor:
    """
    Computes the monocular depth regularization loss on seen views using patch-wise alignment.
    
    Args:
        seen_views: List of input images I_i.
        nerf_model: The NeRF model to render depth.
        mde_model: Pre-trained MDE network G_phi.
        patch_size: Size of the square patches for local alignment.
        
    Returns:
        Scalar loss L_seen.
    """
    total_loss = 0.0
    
    for image in seen_views:
        # Step 2: Render NeRF depth
        # Assumes nerf_model.render_depth returns a tensor of shape (H, W)
        rendered_depth = nerf_model.render_depth(image.camera_pose)
        
        # Step 3: Extract monocular depth
        # Assumes mde_model.predict returns a tensor of shape (H, W)
        pseudo_depth = mde_model.predict(image)
        
        # Get image dimensions
        H, W = rendered_depth.shape
        
        # Iterate over patches
        for y in range(0, H, patch_size):
            for x in range(0, W, patch_size):
                # Define patch boundaries
                y_end = min(y + patch_size, H)
                x_end = min(x + patch_size, W)
                
                # Extract patch pixels P
                patch_y_indices = range(y, y_end)
                patch_x_indices = range(x, x_end)
                
                # Extract sub-tensors for the patch
                # Note: In practice, this might be done via slicing or gathering indices
                p_rendered = rendered_depth[patch_y_indices, :][:, patch_x_indices]
                p_pseudo = pseudo_depth[patch_y_indices, :][:, patch_x_indices]
                
                # Flatten patches for least squares
                # sg() is applied to pseudo depth to stop gradients
                p_pseudo_sg = p_pseudo.detach() 
                
                # Step 5: Compute scale w_i and shift q_i via least squares
                # Solve for w, q in: p_pseudo_sg * w + q = p_rendered
                # This is a linear regression: [p_pseudo_sg, 1] * [w; q] = p_rendered
                # Using numpy/polyfit or similar for least squares
                # X = [pseudo_depth_values, 1], y = rendered_depth_values
                X = torch.stack([p_pseudo_sg.flatten(), torch.ones_like(p_pseudo_sg.flatten())], dim=1)
                y = p_rendered.flatten()
                
                # Solve least squares: (X^T X)^-1 X^T y
                # Using torch.linalg.lstsq or similar
                # Note: Standard least squares minimizes ||X @ [w,q] - y||^2
                try:
                    # Using torch.linalg.lstsq for robustness
                    # A, b = X, y
                    # solution = torch.linalg.lstsq(A, b).solution
                    # w_i, q_i = solution[0], solution[1]
                    
                    # Manual implementation of least squares for clarity if lstsq is unavailable
                    XtX = X.T @ X
                    Xty = X.T @ y
                    # Add small epsilon for numerical stability if needed
                    w_i, q_i = torch.linalg.solve(XtX, Xty)
                except Exception:
                    # Fallback if singular matrix, skip patch or use identity
                    w_i = 1.0
                    q_i = 0.0
                
                # Step 6: Calculate loss for the patch
                # Loss = || (w_i * sg(p_pseudo) + q_i) - p_rendered ||
                # Using L1 or L2 norm as per source formula ||...|| (usually L1 or L2)
                # Source uses ||...|| which typically denotes L1 or L2. 
                # Given "least squares" context, L2 is common, but source formula uses ||...||.
                # We will use L1 norm as it is common in depth distillation, 
                # but strictly speaking, the source formula is ambiguous between L1/L2.
                # However, "least squares" implies L2 for parameter fitting, 
                # but the loss term itself might be L1. 
                # Let's assume L1 norm for the loss term as is common in such distillation losses,
                # or L2 if the source implies Euclidean distance. 
                # The source formula ||...|| is generic. 
                # We will use L1 norm (sum of absolute differences) as a safe default for depth consistency,
                # but note that L2 is also possible.
                # Re-reading source: "L_seen = sum || ... ||". 
                # In many NeRF papers, this is L1. 
                # Let's use L1.
                patch_loss = torch.abs((w_i * p_pseudo_sg + q_i) - p_rendered).sum()
                
                total_loss += patch_loss
                
    return total_loss
```

## Operating characteristics
- **Time Complexity:** Depends on the number of patches and views. Patch-wise adjustment reduces the computational bottleneck of full image rendering compared to global fitting [S1, unofficial].
- **Memory Complexity:** Requires storing rendered depth and pseudo-depth maps for each patch.
- **Strengths:** Alleviates local geometric inconsistencies caused by dominant objects skewing global depth alignment [S1, unofficial].
- **Limitations:** Requires a pre-trained MDE network [S1, unofficial].

## Background
This method was introduced in the DaRF paper to boost radiance fields from sparse inputs using monocular depth adaptation [S1, unofficial]. It addresses the issue where global scale/shift fitting undermines local statistics, leading to ill-fitted depths in less dominant sections of the scene [S1, unofficial].
