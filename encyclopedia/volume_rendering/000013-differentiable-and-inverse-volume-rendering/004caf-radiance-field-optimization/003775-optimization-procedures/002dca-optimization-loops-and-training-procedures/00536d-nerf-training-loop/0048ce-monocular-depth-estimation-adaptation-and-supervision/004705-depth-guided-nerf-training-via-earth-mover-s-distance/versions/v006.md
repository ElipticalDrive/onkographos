# Depth-Guided NeRF Training via Earth Mover’s Distance

Also called: Depth-guided NeRF via Earth Mover’s Distance, EM D-Guided Sampling, EMD-Guided Depth Supervision for NeRF, EMD-NeRF, EMD-based objective

## Overview
This method improves the geometric understanding of Neural Radiance Fields (NeRFs) trained on sparse views by supervising the distribution of ray termination distances using Earth Mover’s Distance (EMD) against a monocular depth prior, rather than enforcing direct pixel-wise depth consistency [S1]. Unlike sibling methods such as [DäRF](12331-d-rf.md) which minimize the norm between rendered depth and prior, or [SCADE](9518-nerfingmvs.md) which relies on multiple ambiguous hypotheses, this approach uses a single depth prior from a diffusion model and weights the supervision by intrinsic uncertainty maps, allowing the NeRF to selectively incorporate prior information without propagating prior inaccuracies [S1].

## How it works
### Inputs and Outputs
**Inputs:**
*   A set of $N$ input images $\{I_i\}_{i=1}^N$ (typically $N < 20$) and their corresponding SfM camera poses.
*   A pre-trained monocular depth estimation network, specifically DiffDP [11], used to generate depth priors and uncertainty maps.
*   A NeRF network $F_\Theta$ initialized with random weights.

**Outputs:**
*   A trained NeRF network $F_\Theta$ capable of rendering novel views with accurate geometry.
*   Rendered images and depth maps for novel viewpoints.

### Data Structures
1.  **NeRF Network ($F_\Theta$):** A multilayer perceptron (MLP) taking 5D input $(x, y, z, \theta, \phi)$ representing camera position and viewing direction, outputting color $c$ and volume density $\sigma$.
2.  **Depth Prior ($z_0$):** A dense depth map generated by DiffDP for each input image.
3.  **Uncertainty Map ($u$):** A per-pixel uncertainty value derived from the DiffDP denoising process, normalized to $[0, 1]$.
4.  **Ray Samples:** For each ray, a set of termination distances $y = \{y_1, \dots, y_N\}$ sampled from the NeRF's predicted distribution.

### Numbered Steps

1.  **Generate Depth Prior and Uncertainty:**
    *   Pass input image $I$ through the DiffDP network.
    *   DiffDP formulates denoising as $p_\theta(z_{0:T}|I) = p_\theta(z_T) \prod_{t=1}^T p_\theta(z_{t-1}|z_t, I)$, where $z_t \sim \mathcal{N}(0, I)$ and $z_0$ is the final depth estimate [S1].
    *   Compute temporal uncertainty count $c(z_{0:T})$ by comparing current estimate $z_t$ to previous $z_{t-1}$ at each step $t$:
        $$ c(z_{0:T}) = \frac{1}{T} \sum_{t=T,\dots,1} \mathbb{I}(|z_t - z_{t-1}| \ge \tau) $$
        where $\mathbb{I}$ is the indicator function and $\tau$ is a threshold [S1].
    *   Compute spatial consistency uncertainty by mirroring the image $M(I)$ and comparing predictions:
        $$ U(z_{0:T}|I) = \frac{c(z_{0:T}|I) + M(c(z_{0:T}|M(I)))}{2} $$
    *   Augment with final prediction difference:
        $$ u(z_{0:T}|I) = U(z_{0:T}|I) \cdot \| (z_0|I) - M(z_0|M(I)) \|_1 $$
    *   Normalize $u$ to $[0, 1]$ [S1].

2.  **NeRF Forward Pass and Weight Calculation:**
    *   For a ray $r$, sample $N$ termination distances within $[t_{near}, t_{far}]$.
    *   Query $F_\Theta$ for density $\sigma_i$ at each sample $y_i$.
    *   Calculate sample weights $w_i$ as the probability that the ray traverses space without obstruction:
        $$ w_i = T_i (1 - \exp(-\sigma_i \delta_i)) $$
        where $\delta_i$ is the distance between samples, and $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance [S1].

3.  **EMD-Guided Sampling:**
    *   Normalize weights to form a piece-wise constant probability density function (PDF):
        $$ \hat{w}_i = \frac{w_i}{\sum_{j=1}^N w_j} $$
    *   Construct the Cumulative Distribution Function (CDF) from $\hat{w}_i$.
    *   Sample new ray termination distances $y = \{y_1, \dots, y_N\}$ using inverse transform sampling from the CDF [S1].
    *   *Note:* Additional samples (e.g., 128) may be generated specifically for the EMD calculation [S1].

4.  **Loss Computation:**
    *   **Photometric Loss:** Standard L2 loss between observed color $C(r)$ and expected color $\hat{C}(r)$:
        $$ L_{photo} = ||\hat{C}(r) - C(r)||_2^2 $$
    *   **EMD Loss:** Compute Earth Mover’s Distance between the sampled ray termination distances $y$ and the depth prior $z_0$. Since EMD is non-differentiable, approximate it using Sinkhorn Divergence during training:
        $$ L_{EMD} = \text{EMD}(y, z_0) \approx \text{SinkhornDivergence}(y, z_0) $$
    *   **Total Loss:** Combine losses weighted by uncertainty $u$ and balancing weight $\lambda$:
        $$ L = (1 + u)^\gamma L_{photo} + \lambda (1 - u)^\gamma L_{EMD} $$
        where $\gamma$ controls the impact of uncertainty [S1]. Unlike Focal Loss, this applies *less* weight to uncertain pixels for depth supervision [S1].

5.  **Optimization:**
    *   Minimize $L$ with respect to NeRF parameters $\Theta$.
    *   Initialize the scale of depth priors to 1 and learn the scale with a small learning rate [S1].

import torch

def compute_uncertainty(diffdp_model, image):
    """
    Computes uncertainty map u from DiffDP denoising process.
    """
    # 1. Get depth prior z0 and intermediate steps z_t
    # diffdp_model returns list of depth maps [z_T, ..., z_0]
    z_steps = diffdp_model.get_denoising_trajectory(image)
    z_0 = z_steps[0]
    
    # 2. Temporal uncertainty count
    # Compare z_t with z_{t-1}
    temporal_diffs = []
    for t in range(1, len(z_steps)):
        z_t = z_steps[t]
        z_prev = z_steps[t-1]
        # Indicator: 1 if difference >= threshold tau, else 0
        # tau is a hyperparameter, e.g., 0.1
        diff = torch.abs(z_t - z_prev)
        temporal_diffs.append((diff >= 0.1).float())
    
    # Average over time steps
    c_temporal = torch.mean(torch.stack(temporal_diffs), dim=0)
    
    # 3. Spatial consistency uncertainty
    # Mirror image and get its temporal uncertainty
    image_mirrored = torch.flip(image, dims=[-1])
    z_steps_mirrored = diffdp_model.get_denoising_trajectory(image_mirrored)
    c_spatial_mirrored = torch.mean(torch.stack([
        (torch.abs(z_steps_mirrored[t] - z_steps_mirrored[t-1]) >= 0.1).float()
        for t in range(1, len(z_steps_mirrored))
    ]), dim=0)
    
    # Mirror back the spatial uncertainty to align with original image
    c_spatial_mirrored_aligned = torch.flip(c_spatial_mirrored, dims=[-1])
    
    # Combine
    U = (c_temporal + c_spatial_mirrored_aligned) / 2.0
    
    # 4. Augment with final prediction difference
    # L1 norm between z0 and mirrored z0
    z_0_mirrored = torch.flip(z_steps_mirrored[0], dims=[-1])
    spatial_diff = torch.abs(z_0 - z_0_mirrored)
    
    u = U * spatial_diff
    
    # Normalize to [0, 1]
    u = (u - u.min()) / (u.max() - u.min() + 1e-8)
    
    return u, z_0

def nerf_forward(ray_origins, ray_directions, nerf_model, num_samples):
    """
    Standard NeRF forward pass returning weights and samples.
    """
    # Sample points along ray
    t_vals = torch.linspace(0, 1, num_samples).to(ray_origins.device)
    # Linear sampling between near and far (assumed known or fixed)
    # For simplicity, assume uniform sampling in normalized space
    # In practice, use stratified sampling or hierarchical sampling
    samples = ray_origins.unsqueeze(1) + ray_directions.unsqueeze(1) * t_vals.unsqueeze(2)
    
    # Query NeRF
    # samples shape: [batch, num_samples, 3]
    # directions: [batch, 3]
    directions = ray_directions.unsqueeze(1).expand_as(samples)
    
    sigma, color = nerf_model(samples, directions)
    
    # Calculate weights
    # delta is distance between samples
    deltas = t_vals[1:] - t_vals[:-1]
    # Add zero at end for last sample's contribution if needed, 
    # but standard formula uses delta_i between i-1 and i
    # Here we assume uniform spacing for simplicity in pseudocode
    delta = deltas.unsqueeze(0).unsqueeze(0) # [1, 1, num_samples-1]
    
    # Transmittance T_i
    # T_1 = 1, T_i = exp(-sum_{j=1}^{i-1} sigma_j * delta_j)
    alpha = 1 - torch.exp(-sigma * delta)
    T = torch.cumprod(torch.exp(-sigma * delta), dim=1)
    T = torch.cat([torch.ones_like(T[:, :1]), T[:, :-1]], dim=1)
    
    weights = T * alpha
    
    # Normalize weights to get PDF
    weights_sum = weights.sum(dim=1, keepdim=True)
    pdf = weights / (weights_sum + 1e-8)
    
    # Construct CDF
    cdf = torch.cumsum(pdf, dim=1)
    
    # Sample new termination distances via inverse transform
    # Generate random u in [0, 1]
    u_rand = torch.rand_like(cdf)
    # Find indices where cdf >= u_rand
    # This is a simplified inverse transform; in practice, use searchsorted
    indices = torch.searchsorted(cdf, u_rand, side='right')
    indices = torch.clamp(indices, 0, num_samples - 1)
    
    # Interpolate or pick the sample
    # For simplicity, pick the sample index
    y = t_vals[indices]
    
    return y, weights, color

### Parameters
*   **N:** Number of input images, typically $N < 20$ [S1].
*   **Rays per batch:** 1024 [S1].
*   **Ray termination distances (coarse):** 64 [S1].
*   **Ray termination distances (fine):** 128 [S1].
*   **Additional samples for EMD:** 128 [S1].
*   **Dropout probability:** 0.1 [S1].
*   **Weight decay:** $10^{-6}$ [S1].
*   **$\lambda$:** Balancing weight between photometric and EMD loss [S1].
*   **$\gamma$:** Controls the impact of uncertainty $u$ on the loss weights [S1].
*   **Depth prior scale initialization:** 1, learned with a small learning rate [S1].

### Edge Cases and Pitfalls
*   **Photometric Quality vs. Geometry:** High PSNR/SSIM does not guarantee correct geometry; models may render plausible images while misinterpreting structure (e.g., misinterpreting a cabinet as a wall pattern) [S1].
*   **Uncertainty Handling:** Unlike Focal Loss which up-weights uncertain examples, this method down-weights them for depth supervision, relying more on photometric loss when the depth prior is unreliable [S1].
*   **Prior Noise:** Using multiple depth hypotheses (as in SCADE) can introduce noise and training instability dependent on random seeds; this method uses a single prior to avoid this [S1].
*   **Diffusion Uncertainty:** The uncertainty measure is specific to diffusion-based models like DiffDP; it may not be directly applicable to other monocular depth estimators without modification [S1].

## Operating characteristics
*   **Time Complexity:** Training time is comparable to standard NeRF training, with additional overhead from the diffusion model inference (pre-computed) and Sinkhorn divergence approximation. The Sinkhorn divergence is approximated using the `geomloss` library with standard hyper-parameters [S1].
*   **Memory Complexity:** Requires storing the depth prior and uncertainty map for each input image. The NeRF memory footprint is standard.
*   **Measured Performance:** On ScanNet+, the method reduces baseline RMSE by at least 56% while maintaining comparable photometric results (PSNR/SSIM) [S1]. With DiffDP prior, it reduces initial prior RMSE by 31.4%; with DepthAnything prior, by 18.8% [S1].
*   **Scaling:** Effective for sparse view settings ($N < 20$). Performance on uncertain pixels (uncertainty > 0.8) improves RMSE by 5.1% when using uncertainty weighting, compared to 1.9% for certain pixels [S1].
*   **Strengths:** Robust to prior inaccuracies; avoids enforcing incorrect geometry; leverages intrinsic uncertainty from diffusion models.
*   **Limitations:** Relies on the availability of a diffusion-based depth prior for uncertainty estimation; Sinkhorn divergence approximation may introduce numerical instability if not tuned [S1].

## Background
The method was introduced by Rau et al. in a paper titled "Depth-Guided NeRF Training via Earth Mover’s Distance" [S1]. It addresses the limitation of standard NeRFs in sparse view settings where geometry is underconstrained. Previous methods like DäRF supervised rendered depth directly, and SCADE used multiple hypotheses with space-carving loss. This work leverages the uncertainty inherent in diffusion-based depth estimation (DiffDP) and uses EMD to align the ray termination distribution with the prior, providing a more robust supervision signal [S1].
