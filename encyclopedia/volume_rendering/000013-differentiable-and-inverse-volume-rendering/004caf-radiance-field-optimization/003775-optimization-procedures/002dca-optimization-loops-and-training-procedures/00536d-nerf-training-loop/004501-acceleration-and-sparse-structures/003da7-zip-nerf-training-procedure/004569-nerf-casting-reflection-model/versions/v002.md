# NeRF-Casting Reflection Model

Also called: NeRF-Casting Specular Rendering, Reflection Cone Tracing

## Overview
NeRF-Casting is a rendering procedure designed to model accurate, detailed specular reflections in neural radiance fields without the computational cost of evaluating expensive color MLPs along every reflected ray [S1]. It addresses the problem of rendering view-dependent specular highlights by casting a small number of reflected rays through a volume representation, accumulating features, and then using a lightweight decoder to produce final colors [S1]. It differs from its siblings by explicitly approximating the reflection cone via a von Mises-Fisher distribution and pulling the reflection origin closer to the surface for non-perfect mirrors to maintain intersection with the pixel cone, whereas [Conical Reflected Features](11502-conical-reflected-features.md) handles conical integration differently and [Fast Cache (Control Variate Radiance Cache)](9552-fast-cache-control-variate-radiance-cache.md) uses control variates [S1].

## How it works
The method builds on the Zip-NeRF representation, which uses a multi-scale hashgrid to store 3D features, a small MLP (1 layer, width 64) to decode density, and a larger MLP (3 layers, width 256) to decode color [S1]. The rendering process for a single camera ray with origin $\mathbf{o}$ and direction $\mathbf{d}$ proceeds as follows:

### Inputs and Outputs
*   **Input:** Camera ray origin $\mathbf{o}$, camera ray direction $\mathbf{d}$ [S1].
*   **Output:** Final pixel color $\bar{c}$ [S1].

### Data Structures
The underlying representation is based on Zip-NeRF [S1]:
*   **Hashgrid:** Multi-scale grid storing 3D features [S1].
*   **Density MLP:** 1 layer, width 64. Takes grid features, outputs density $\rho(\mathbf{x})$ [S1].
*   **Color MLP:** 3 layers, width 256. Takes grid features, bottleneck features, mixing coefficients, and viewing direction to output RGB color [S1].
*   **Reflection Feature:** A single accumulated vector $\mathbf{f}$ representing the integrated reflection appearance [S1].

### Numbered Steps

1.  **Sample and Encode Camera Ray:** Sample $N$ points $\mathbf{x}_i$ along the camera ray [S1]. Use the Zip-NeRF spatial encoder to encode each point into volume density $\rho(\mathbf{x}_i)$, roughness $\kappa(\mathbf{x}_i)$ (inverse-roughness parameter for the reflection distribution), and surface normal $\mathbf{n}(\mathbf{x}_i)$ [S1].
2.  **Alpha Composite Camera Ray Features:** Alpha composite the sampled densities and features along the camera ray to compute an expected termination point $\bar{\mathbf{x}}$, an aggregated von Mises-Fisher distribution width $\bar{\kappa}$ (inverse-roughness), and an aggregated surface normal $\bar{\mathbf{n}}$ [S1].
3.  **Construct Reflection Distribution:** Reflect the camera direction $\mathbf{d}$ around the aggregated surface normal $\bar{\mathbf{n}}$ to define the center of the reflection distribution [S1]. Approximate the von Mises-Fisher distribution $vMF(\mathbf{d}', \bar{\kappa})$ over reflected rays by sampling a small set of $M$ reflected rays $\{\mathbf{d}'_j\}_{j=1}^M$ (where $M=5$ in the source) [S1].
4.  **Determine Reflection Ray Origins:** For each reflected ray $j$, determine the origin $\mathbf{o}'_j$ [S1]. If the surface is not a perfect mirror (i.e., $\bar{\kappa}$ is finite), the reflection cone widens [S1]. To maintain the same intersection with the pixel cone, the origin of the reflected ray cone must be pulled closer to the surface location $\bar{\mathbf{x}}$ [S1].
5.  **Trace Reflected Rays:** Cast the $M$ reflected rays defined by origins $\mathbf{o}'_j$ and directions $\mathbf{d}'_j$ [S1]. Sample points along these reflected rays and encode each point using the same Zip-NeRF spatial encoder to obtain densities $\rho'(\mathbf{x})$ and features $\mathbf{f}(\mathbf{x})$ [S1].
6.  **Accumulate Reflection Features:** Alpha composite the features along each reflected ray $j$ to get per-ray features $\bar{\mathbf{f}}_j$ [S1]. Average the composited features $\bar{\mathbf{f}}_j$ across all $M$ reflected rays to produce a single reflection feature $\mathbf{f}$ [S1].
7.  **Decode Final Colors:** Broadcast the single reflection feature $\mathbf{f}$ over the original camera ray's samples [S1]. For each sample $i$ along the original ray, pass the reflection feature $\mathbf{f}$, bottleneck features $\mathbf{b}$ (from Zip-NeRF), mixing coefficients $\alpha$, and viewing direction $\mathbf{d}$ to the color decoder to produce an RGB color $c(\mathbf{x}_i)$ for each point [S1].
8.  **Alpha Composite Final Color:** Alpha composite the colors $c(\mathbf{x}_i)$ and densities $\rho(\mathbf{x}_i)$ along the original camera ray to render the final pixel color $\bar{c}$ [S1].

### Pseudocode
```python
import math

def render_nerf_casting_ray(o, d, zip_nerf_model, M=5, N_samples=64, M_samples=32):
    """
    Renders a single ray using the NeRF-Casting reflection model.
    Args:
        o: Camera ray origin (list of 3 floats)
        d: Camera ray direction (list of 3 floats)
        zip_nerf_model: Object with get_grid_features, density_mlp, roughness_head, 
                        normal_head, get_bottleneck, get_mixing_coefficient, color_decoder
        M: Number of reflected rays to sample (default 5)
        N_samples: Number of samples per camera ray
        M_samples: Number of samples per reflected ray
    Returns:
        final_color: Rendered RGB color (list of 3 floats)
    """
    # Step 1: Sample points along camera ray
    t = [i * 0.5 for i in range(1, N_samples + 1)]
    x_samples = [[o[p] + d[p] * t[i] for p in range(3)] for i in range(N_samples)]
    deltas = [t[i] - t[i-1] if i > 0 else t[0] for i in range(N_samples)]
    
    # Step 2: Encode and alpha composite to get aggregated values
    T = 1.0
    acc_pos = [0.0, 0.0, 0.0]
    acc_normal = [0.0, 0.0, 0.0]
    acc_kappa = 0.0
    samples_data = []
    
    for i in range(N_samples):
        x = x_samples[i]
        delta = deltas[i]
        features = zip_nerf_model.get_grid_features(x)
        rho = zip_nerf_model.density_mlp(features)
        kappa = zip_nerf_model.roughness_head(features)
        n = zip_nerf_model.normal_head(features)
        bottleneck = zip_nerf_model.get_bottleneck(features)
        mix_alpha = zip_nerf_model.get_mixing_coefficient(features)
        
        alpha = T * (1.0 - math.exp(-rho * delta))
        T *= math.exp(-rho * delta)
        
        acc_pos = [acc_pos[p] + alpha * x[p] for p in range(3)]
        acc_normal = [acc_normal[p] + alpha * n[p] for p in range(3)]
        acc_kappa += alpha * kappa
        samples_data.append({'x': x, 'rho': rho, 'b': bottleneck, 'mix_alpha': mix_alpha, 'alpha': alpha})
        
    total_alpha = 1.0 - T
    if total_alpha > 1e-6:
        x_bar = [p / total_alpha for p in acc_pos]
        n_bar = normalize(acc_normal)
        kappa_bar = acc_kappa / total_alpha
    else:
        x_bar, n_bar, kappa_bar = o, [0.0, 0.0, 1.0], 0.0
        
    # Step 3 & 4: Construct reflection distribution & adjust origin
    d_ref = reflect(d, n_bar)
    # For non-perfect mirrors, pull origin closer to surface to maintain pixel cone intersection [S1]
    shift = 1.0 / (kappa_bar + 1e-6) if kappa_bar < 100.0 else 0.0
    o_prime = [x_bar[p] - d_ref[p] * shift for p in range(3)]
    
    # Step 5: Trace reflected rays
    reflection_features = []
    for j in range(M):
        d_prime = sample_vmf_ray(d_ref, kappa_bar)
        T_ref = 1.0
        acc_f = [0.0, 0.0, 0.0] # Feature dimension assumed 3 for pseudocode clarity
        for k in range(M_samples):
            t_ref = k * 0.5
            x_ref = [o_prime[p] + d_prime[p] * t_ref for p in range(3)]
            f_ref = zip_nerf_model.get_grid_features(x_ref)
            rho_ref = zip_nerf_model.density_mlp(f_ref)
            alpha_ref = T_ref * (1.0 - math.exp(-rho_ref * 0.5))
            T_ref *= math.exp(-rho_ref * 0.5)
            acc_f = [acc_f[p] + alpha_ref * f_ref[p] for p in range(3)]
        acc_f = [v / (1.0 - T_ref) for v in acc_f] if (1.0 - T_ref) > 1e-6 else [0.0, 0.0, 0.0]
        reflection_features.append(acc_f)
        
    # Step 6: Average reflection features
    f_reflection = [sum(rf[p] for rf in reflection_features) / M for p in range(3)]
    
    # Step 7: Decode colors
    final_colors = []
    for s in samples_data:
        c = zip_nerf_model.color_decoder(f_reflection, s['b'], s['mix_alpha'], d)
        final_colors.append(c)
        
    # Step 8: Alpha composite final color
    final_color = [0.0, 0.0, 0.0]
    T_final = 1.0
    for i in range(N_samples):
        c = final_colors[i]
        alpha = samples_data[i]['alpha']
        final_color = [final_color[p] + T_final * alpha * c[p] for p in range(3)]
        T_final *= (1.0 - alpha)
    return final_color

def reflect(v, n):
    """Reflect vector v around normal n."""
    return [v[p] - 2.0 * sum(v[q]*n[q] for q in range(3)) * n[p] for p in range(3)]

def normalize(v):
    """Normalize vector v."""
    mag = math.sqrt(sum(x*x for x in v))
    return [x/mag for x in v] if mag > 1e-6 else v

def sample_vmf_ray(center_dir, kappa):
    """Sample a direction from a von Mises-Fisher distribution centered on center_dir with concentration kappa [G]."""
    # Standard rejection sampling or spherical perturbation approximation
    phi = math.uniform(0, 2 * math.pi)
    cos_theta = 1.0 / (1.0 + kappa) if kappa > 0 else 0.0
    sin_theta = math.sqrt(1.0 - cos_theta**2)
    # Construct orthonormal basis around center_dir
    up = [0.0, 0.0, 1.0] if abs(center_dir[2]) < 0.9 else [1.0, 0.0, 0.0]
    u = normalize([up[p] - sum(up[q]*center_dir[q] for q in range(3)) * center_dir[p] for p in range(3)])
    v = normalize([sum(center_dir[q]*u[p] - u[q]*center_dir[p] for q in range(3)) for p in range(3)]) # Cross product
    return [center_dir[p]*cos_theta + u[p]*sin_theta*math.cos(phi) + v[p]*sin_theta*math.sin(phi) for p in range(3)]
```

### Parameters
*   **Zip-NeRF Density MLP:** 1 layer, width 64 [S1].
*   **Zip-NeRF Color MLP:** 3 layers, width 256 [S1].
*   **Number of Reflected Rays ($M$):** 5 [S1].
*   **Roughness Parameter ($\kappa$):** Inverse-roughness, used to define the width of the von Mises-Fisher distribution [S1]. For non-perfect mirrors, the reflection cone widens and the origin is pulled closer to the surface [S1].

### Edge Cases and Pitfalls
*   **Non-Perfect Mirrors:** When the surface is not a perfect mirror, the reflection cone widens [S1]. The origin of the reflected ray cone must be pulled closer to the surface location to maintain the same intersection with the pixel cone [S1]. Failure to adjust the origin may result in incorrect reflection sampling [S1].
*   **Precision:** The method relies on accurate estimation of the surface normal and termination point from noisy volume samples [G]. Degenerate inputs (e.g., empty space) should return black or background color [G].
*   **Computational Cost:** While cheaper than full ray tracing, querying the hashgrid and MLPs for $M$ reflected rays per camera ray sample still adds overhead [S1]. The cost is mitigated by using the small density MLP for sampling and only using the larger color MLP for the final composite step [S1].

## Operating characteristics
*   **Time Complexity:** Proportional to $N \times (1 + M)$, where $N$ is the number of samples per camera ray and $M$ is the number of reflected rays (typically 5) [G]. Each reflected ray requires sampling and feature encoding, but avoids the full color MLP evaluation until the final step [S1].
*   **Memory Complexity:** Dominated by the Zip-NeRF hashgrid storage [S1]. The reflection feature is a single vector per ray, requiring minimal additional memory [G].
*   **Strengths:** Models accurate detailed reflections without expensive MLP evaluations along every reflected ray [S1]. Minimizes computation by querying density/features cheaply and only decoding color once per camera sample using accumulated reflection features [S1].
*   **Limitations:** Approximates the reflection cone with a discrete set of rays, which may introduce aliasing or inaccuracies for highly rough surfaces if $M$ is too small [G]. Relies on the quality of the Zip-NeRF representation for normal and roughness estimation [S1].
*   **When to Use:** When view-dependent specular reflections are important and computational resources are limited compared to full path tracing, but more accurate than simple environment map reflections [G].
*   **When Not to Use:** For scenes with complex global illumination beyond first-order reflections, or where perfect mirror reflections are required without approximation [G].

## Background
NeRF-Casting was introduced in the paper "NeRF-Casting: Improved View-Dependent Appearance with Consistent Reflections" [S1]. It builds upon the Zip-NeRF representation, which itself improves upon standard NeRF by using a multi-scale hashgrid for efficient feature storage and decoding [S1]. The method was developed to address the high computational cost of rendering reflections in neural radiance fields by reducing the number of expensive MLP evaluations [S1].
