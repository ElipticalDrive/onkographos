# Deceptive-NeRF/3DGS Pipeline

Also called: Deceptive-3DGS, Deceptive-NeRF

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that enhances NeRF or 3D Gaussian Splatting (3DGS) representations by continuously densifying input observations with synthetic pseudo-observations generated by a diffusion model during training [S1]. Unlike methods that rely on ensemble learning, variational inference, or spatial perturbations to estimate uncertainty, this approach acquires uncertainty through correspondence matching by reprojecting real input observations to novel views, thereby enforcing epipolar constraints with minimal additional computation [S1]. It sets itself apart by conditioning a 2D diffusion model on rendered RGB images, depth maps, and view-consistency uncertainty maps to rectify artifacts and generate photorealistic pseudo-observations that are filtered by perceptual similarity before being used to retrain the 3D representation [S1].

## How it works

### Inputs and Outputs
*   **Inputs:** A set of $W$ input images $I = \{I_1, \dots, I_W\}$ with calibrated camera poses. A pre-trained 2D latent diffusion model (e.g., Stable Diffusion) fine-tuned via ControlNet [S1].
*   **Outputs:** An optimized NeRF or 3DGS representation capable of high-quality novel view synthesis from sparse inputs [S1].

### Data Structures
The method relies on the standard NeRF/3DGS representation $f_\theta: (\mathbf{x}, \mathbf{d}) \to (\sigma, \mathbf{c})$ [Parent]. Additionally, it maintains:
1.  **Coarse and Fine NeRFs:** Two parallel representations trained on the same scene. The "fine" NeRF is trained on all input images, while the "coarse" NeRF is trained on a subset (e.g., one-fifth) of input images to simulate sparse-view conditions [S1].
2.  **Pseudo-Observation Buffer:** A collection of generated pseudo-observations $P_A$ and their associated metadata (depth $D_A$, uncertainty $U_A$) [S1].
3.  **ControlNet Channels:** The diffusion model accepts a 5-channel control map: 3 channels for coarse RGB, 1 for depth, and 1 for uncertainty [S1].

### Numbered Steps

1.  **Initial Training:** Train a "fine" NeRF/3DGS using the full set of input images $I$ and a "coarse" NeRF/3DGS using a subset of $I$ (e.g., 20% of images) [S1].
2.  **Novel View Sampling:** Randomly sample a novel viewpoint $A$ within the bounding box defined by the outermost input views [S1].
3.  **Rendering:** At viewpoint $A$, render the RGB image $\hat{I}_A$, depth map $D_A$, and transmittance using the coarse NeRF/3DGS [S1].
    *   Depth is computed as a weighted sum of distances traveled:
        $$
        \hat{\mathbf{D}} = \sum_{k=1}^K \hat{T}(t_k)\alpha(\sigma(t_k)\delta_k)
        $$
        where $\hat{T}(t_k)$ is transmittance, $\alpha$ is opacity, $\sigma$ is density, and $\delta_k$ is the distance traveled [S1].
4.  **Uncertainty Map Generation:**
    *   Identify the nearest input viewpoint $B$ to the novel view $A$ [S1].
    *   Warp the ground truth image $I_B$ from viewpoint $B$ to viewpoint $A$ using the rendered depth $D_A$ and the relative pose $R_{B \rightarrow A}$:
        $$
        I_{B \rightarrow A} = \psi(I_B; D_A, R_{B \rightarrow A})
        $$
    *   For each pixel $p$ in $\hat{I}_A$, compute the transformed pixel location $q$ in $I_B$:
        $$
        q = K R_{B \rightarrow A} D_A(p) K^{-1} p
        $$
        where $K$ is the camera parameter matrix [S1].
    *   Compute the uncertainty map $U_A$ as the squared difference between the warped image and the rendered image:
        $$
        U_A = (I_{B \rightarrow A} - \hat{I}_A)^2
        $$
        [S1].
5.  **Pseudo-Observation Generation:** Generate a pseudo-observation $P_A$ using the Deceptive Diffusion Model $G$:
    $$
    P_A = G(\hat{I}_A, D_A, U_A)
    $$
    The model $G$ is a latent diffusion model conditioned on the coarse RGB image, depth, uncertainty, and a text embedding $s$ [S1].
6.  **Text Embedding Derivation:**
    *   Generate an initial text prompt $s_0$ using a pre-trained image captioning network [S1].
    *   Optimize a shared latent text embedding $s^*$ using textual inversion, shared across all input observations and coarse images [S1].
    *   Form the composite feature $s = [s_0, s^*]$ by concatenating the embeddings [S1].
7.  **Filtering:** Calculate the perceptual similarity between the generated pseudo-observation $P_A$ and the input images using the LPIPS metric. Discard the 20% of pseudo-observations with the lowest similarity to avoid generating content far from the original inputs [S1].
8.  **Accumulation and Re-training:** Accumulate the valid pseudo-observations into the training set. Continue training the NeRF/3DGS representation using the combination of real input images and the accumulated pseudo-observations [S1].
9.  **Iteration:** Repeat steps 2–8 until a sufficient number of observations are accumulated to achieve the desired reconstruction quality [S1].

def train_deceptive_nerf(input_images, poses, num_epochs, num_pseudo_views):
    """
    Trains a NeRF/3DGS using Deceptive-NeRF pipeline.
    
    Args:
        input_images: List of W input images.
        poses: Camera poses for input_images.
        num_epochs: Number of epochs for initial training.
        num_pseudo_views: Number of pseudo-views to generate per iteration.
        
    Returns:
        Optimized NeRF/3DGS model.
    """
    # 1. Initialize Coarse and Fine Models
    # Fine model uses all input images
    model_fine = init_nerf(input_images, poses)
    # Coarse model uses a subset (e.g., 20%)
    subset_indices = random_sample(len(input_images), 0.2)
    model_coarse = init_nerf(subset_images(input_images, subset_indices), subset_poses(poses, subset_indices))
    
    # 2. Train Coarse Model to generate initial pseudo-observations
    for epoch in range(num_epochs):
        render_coarse(model_coarse, input_images, poses)
        train_step(model_coarse, loss=model_coarse.loss)
        
    # 3. Initialize Deceptive Diffusion Model (G)
    # G is a ControlNet-enhanced Stable Diffusion model
    # Inputs: 3 channels RGB, 1 channel Depth, 1 channel Uncertainty
    diffusion_model = init_controlnet_stable_diffusion()
    train_diffusion_model(diffusion_model, training_data=generate_training_quartets(model_fine, model_coarse))
    
    # 4. Iterative Densification Loop
    pseudo_observations = []
    
    for iteration in range(num_pseudo_views):
        # Sample novel view A
        view_A = sample_novel_view(poses)
        
        # Render from Coarse Model
        rgb_coarse, depth_coarse = render(model_coarse, view_A)
        
        # Find nearest input view B
        view_B = find_nearest_input_view(view_A, poses)
        img_B = get_image(view_B, input_images)
        
        # Generate Uncertainty Map
        # Warp image B to view A using depth from A
        warped_img_B = warp_image(img_B, depth_coarse, view_B, view_A)
        uncertainty_map = (warped_img_B - rgb_coarse) ** 2
        
        # Generate Text Embedding
        text_prompt = caption_image(rgb_coarse)
        latent_embedding = optimize_textual_inversion(input_images, rgb_coarse)
        text_embedding = concatenate(text_prompt, latent_embedding)
        
        # Generate Pseudo-Observation
        pseudo_obs = diffusion_model(rgb_coarse, depth_coarse, uncertainty_map, text_embedding)
        
        # Filter Pseudo-Observation
        similarity = compute_lpips(pseudo_obs, input_images)
        if similarity > threshold: # Keep top 80%
            pseudo_observations.append(pseudo_obs)
        else:
            discard(pseudo_obs)
            
        # Re-train Fine Model with new pseudo-observations
        train_model(model_fine, input_images + pseudo_observations, poses)
        
    return model_fine

def generate_training_quartets(model_fine, model_coarse):
    """
    Generates dataset of quartets (I_fine, I_coarse, D, U) for diffusion training.
    """
    dataset = []
    # Use scenes from Hypersim and CO3D
    scenes = load_scenes(['Hypersim', 'CO3D'])
    
    for scene in scenes:
        # Train coarse NeRF on subset
        coarse_model = train_nerf(scene.images[:len(scene.images)//5], scene.poses)
        # Render coarse
        coarse_rgb, coarse_depth = render(coarse_model, scene.poses)
        
        # Train fine NeRF on all
        fine_model = train_nerf(scene.images, scene.poses)
        # Render fine
        fine_rgb = render(fine_model, scene.poses)
        
        # Compute uncertainty
        for i in range(len(scene.poses)):
            view_A = scene.poses[i]
            view_B = find_nearest_input_view(view_A, scene.poses)
            img_B = scene.images[view_B]
            warped_B = warp_image(img_B, coarse_depth[i], view_B, view_A)
            uncertainty = (warped_B - coarse_rgb[i]) ** 2
            
            dataset.append((fine_rgb[i], coarse_rgb[i], coarse_depth[i], uncertainty))
            
    # Data Augmentation: Add Gaussian noise to RGB images
    noisy_images = add_gaussian_noise(scene.images, std=0.3)
    for i in range(len(scene.images)):
        # Pair noisy image with original depth (no uncertainty for augmented data)
        dataset.append((scene.images[i], noisy_images[i], scene.depths[i], None))
        
    return dataset

### Parameters
*   **Discard Rate:** 20% of pseudo-observations with the lowest LPIPS similarity are discarded [S1].
*   **Coarse NeRF Data:** Trained on one-fifth of input images [S1].
*   **ControlNet Channels:** 5 channels (3 RGB, 1 Depth, 1 Uncertainty) [S1].
*   **Image Resolution:** Randomly cropped to $512 \times 512$ [S1].
*   **Gaussian Noise Std:** 0.3, added to 60,000 images for data augmentation [S1].
*   **Training Dataset Size:** 200 scenes, approx. 20,000 images (Hypersim and CO3D) [S1].

### Edge Cases and Pitfalls
*   **Captioning Efficacy:** Image captioning efficacy diminishes for low-quality images or those with pronounced artifacts. Textual inversion is used to optimize a shared latent text embedding to counteract this [S1].
*   **Augmentation Data:** When training with noisy RGB-depth data augmentation, uncertainty maps are not fed into the diffusion model [S1].
*   **Precision:** The uncertainty map calculation relies on accurate depth rendering and precise camera pose alignment ($K$ matrix) to ensure valid epipolar constraints [S1].

## Operating characteristics
*   **Time Complexity:** The method requires training two NeRFs (coarse and fine) and iteratively generating pseudo-observations. Each iteration involves rendering, warping, and diffusion inference, which is computationally expensive compared to standard NeRF training [S1].
*   **Memory Complexity:** Requires storing both coarse and fine NeRF representations, as well as the large diffusion model and its ControlNet weights [S1].
*   **Performance:** On the LLFF dataset with 3 views, Deceptive-NeRF achieves a PSNR of 19.87 and SSIM of 0.436, outperforming PixelNeRF (17.88 PSNR) and MVSNeRF (17.07 PSNR) [S1]. Deceptive-3DGS achieves 19.95 PSNR [S1].
*   **Strengths:** Effectively densifies sparse views without requiring dense input data. Enforces 3D consistency via uncertainty maps derived from epipolar geometry.
*   **Limitations:** Relies on the quality of the pre-trained diffusion model. Computationally intensive due to iterative training and diffusion inference.

## Background
Deceptive-NeRF/3DGS was introduced by Liu et al. in 2023 [S1]. It addresses the challenge of high-quality novel view synthesis from sparse input views, a common limitation in NeRF and 3DGS applications. The method leverages the power of 2D diffusion models to "rectify" NeRF renderings, hence the term "deceptive," by generating pseudo-observations that are consistent with the input data and 3D geometry. It builds on the principles of differentiable volume rendering and inverse rendering, specifically focusing on optimization loops that incorporate external 2D priors [Parent].
