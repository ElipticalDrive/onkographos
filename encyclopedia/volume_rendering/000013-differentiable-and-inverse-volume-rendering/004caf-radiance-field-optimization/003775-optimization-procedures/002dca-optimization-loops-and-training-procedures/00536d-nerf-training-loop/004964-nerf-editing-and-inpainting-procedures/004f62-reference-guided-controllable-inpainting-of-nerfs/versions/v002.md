# Reference-guided Controllable Inpainting of NeRFs

Also called: Reference-guided Inpainting

## Overview
This method performs 3D inpainting of a Neural Radiance Field (NeRF) using a single inpainted reference view to guide geometry and appearance, ensuring view consistency and generating view-dependent effects (VDEs) in novel views [S1]. It distinguishes itself from multi-view inpainting baselines by avoiding view inconsistencies at distances far from the reference and by explicitly handling disocclusions and VDEs through a unified optimization framework [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** $n$ input images $\{I_i\}_{i=1}^n$, camera transform matrices $\{\Pi_i\}_{i=1}^n$, binary masks $\{M_i\}_{i=1}^n$ delineating unwanted regions, and a single inpainted reference view $I_r$ where $r \in \{1, \dots, n\}$ [S1].
*   **Outputs:** A trained NeRF model $f_\theta$ capable of rendering the scene with the masked regions replaced by content consistent with $I_r$ [S1].

**Data Structures**
The NeRF model $f_\theta$ is parameterized by a multi-layer perceptron (MLP) that maps 3D positions $\mathbf{x}$ and viewing directions $\mathbf{d}$ to density $\sigma$ and color $\mathbf{c}$ [S1]. The standard volume rendering equation is used:
$$
\hat{C}(r) = \sum_{j=1}^J T_j \mathbf{c}_j, \quad T_j = \exp\left(-\sum_{k=1}^{j-1} \sigma_k \delta_k\right), \quad \delta_j = t_{j+1} - t_j
$$
where $t_j$ are sample points along ray $r$ [S1].

**Algorithm Steps**
The optimization proceeds in stages to handle geometry, appearance, and disocclusions separately [S1].

1.  **Unmasked Supervision:** Optimize $f_\theta$ on unmasked pixels for $N_{depth}$ iterations using the standard reconstruction loss. This allows the unmasked geometry to converge while leaving the masked region under-fit for later modification [S1].
    $$
    L_{rec}^{unmasked} = \mathbb{E}_{r \sim R_{unmasked}} \| \hat{C}(r) - C_{GT}(r) \|^2
    $$
    where $R_{unmasked}$ is the set of rays corresponding to pixels in $\{I_i (1 - M_i)\}_{i=1}^n$ [S1].

2.  **Geometry Supervision via Monocular Depth:** Use a monocular depth estimator to back-project the inpainted reference view $I_r$ to 3D positions. Compute a disparity map and align it with the current NeRF scene. Use this to compute the masked depth loss $L_{depth}^{masked}$ [S1].

3.  **View-Dependent Effects (VDEs) via Bilateral Solver:** To generate VDEs for non-reference views, use a view-substitution technique followed by bilaterally guided inpainting. This produces target colors $I_{br,t}$ for non-reference views. These targets are used to compute the masked reconstruction loss $L_{rec}^{masked}$ [S1].

4.  **Disocclusion Handling:** For regions disoccluded in non-reference views that are not supervised by the single reference view, use image inpainters to guide both geometry and appearance via a disocclusion loss $L_{do}$ [S1].

5.  **Combined Optimization:** After the initial $N_{depth}$ iterations, the total loss includes all components. The losses $L_{depth}$, $L_{rec}^{masked}$, and $L_{do}$ are computed every $N_{depth}$, $N_{bilateral}$, and $N_{do}$ iterations respectively [S1].
    $$
    L = L_{rec}^{unmasked} + \gamma_{depth} L_{depth}^{masked} + \gamma_{rec} L_{rec}^{masked} + \gamma_{do} L_{do}
    $$

**Pseudocode**

```python
def reference_guided_inpainting(images, cameras, masks, reference_view, num_iterations):
    """
    Perform 3D inpainting of a NeRF using a single reference view.
    
    Args:
        images: List of n input images {I_i}
        cameras: List of n camera transform matrices {Pi}
        masks: List of n binary masks {Mi}
        reference_view: The inpainted reference image Ir
        num_iterations: Total number of optimization steps
        
    Returns:
        Trained NeRF model f_theta
    """
    # Initialize NeRF model f_theta
    f_theta = initialize_nerf()
    
    # Stage 1: Supervise unmasked pixels for N_depth iterations
    N_depth = 1000  # Typical value, not explicitly given in sources [G]
    N_bilateral = 500  # Typical value, not explicitly given in sources [G]
    N_do = 500  # Typical value, not explicitly given in sources [G]
    
    for i in range(num_iterations):
        # 1. Compute unmasked reconstruction loss
        # R_unmasked: rays corresponding to pixels in {I_i * (1 - M_i)}
        loss_unmasked = compute_reconstruction_loss(f_theta, images, cameras, masks, type="unmasked")
        
        total_loss = loss_unmasked
        
        # 2. Geometry Supervision (after N_depth iterations)
        if i >= N_depth:
            # Back-project reference view to 3D using monocular depth estimator
            depth_map = monocular_depth_estimator(reference_view)
            # Align disparity map with current NeRF scene
            # Compute masked depth loss
            loss_depth = compute_depth_loss(f_theta, reference_view, depth_map, type="masked")
            total_loss += gamma_depth * loss_depth
            
        # 3. View-Dependent Effects (after N_bilateral iterations)
        if i >= N_bilateral:
            # Use view-substitution and bilateral solver to get target colors for non-reference views
            target_colors = bilateral_solver(reference_view, images, cameras, masks)
            # Compute masked reconstruction loss using target colors
            loss_rec_masked = compute_reconstruction_loss(f_theta, target_colors, cameras, masks, type="masked")
            total_loss += gamma_rec * loss_rec_masked
            
        # 4. Disocclusion Handling (after N_do iterations)
        if i >= N_do:
            # Identify disoccluded regions in non-reference views
            disoccluded_regions = identify_disocclusions(images, cameras, masks)
            # Use image inpainters to guide geometry and appearance
            loss_do = compute_disocclusion_loss(f_theta, disoccluded_regions, images, cameras)
            total_loss += gamma_do * loss_do
            
        # Update NeRF parameters
        gradients = compute_gradients(total_loss, f_theta)
        update_parameters(f_theta, gradients)
        
    return f_theta
```

**Parameters**
*   $\gamma_{depth}, \gamma_{rec}, \gamma_{do}$: Weighting coefficients for the respective losses. Values not given in the sources [S1].
*   $N_{depth}, N_{bilateral}, N_{do}$: Iteration counts for when each loss component is introduced. Values not given in the sources [S1].

**Edge Cases and Pitfalls**
*   **Disocclusions:** Regions that become visible in non-reference views but are not covered by the single reference view require specific handling via image inpainters [S1].
*   **View-Dependent Effects:** Without the bilateral solver technique, the inpainted region may lack VDEs, leading to visual inconsistencies [S1].
*   **Under-fitting Masked Region:** The masked region is intentionally left under-fit in the first stage to allow for easier modification in later stages [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** The approach shows superior performance to NeRF inpainting baselines [S1].
*   **Strengths:** Avoids view inconsistencies at views far from the reference; allows user control via a single inpainted image; handles VDEs and disocclusions [S1].
*   **Limitations:** Relies on the quality of the single inpainted reference view and monocular depth estimators [S1].

## Background
This method was introduced in "Reference-guided Controllable Inpainting of Neural Radiance Fields" [S1]. It addresses the limitations of previous NeRF inpainting methods, which often suffer from view inconsistencies, lack of VDEs, and poor handling of disocclusions [S1].
