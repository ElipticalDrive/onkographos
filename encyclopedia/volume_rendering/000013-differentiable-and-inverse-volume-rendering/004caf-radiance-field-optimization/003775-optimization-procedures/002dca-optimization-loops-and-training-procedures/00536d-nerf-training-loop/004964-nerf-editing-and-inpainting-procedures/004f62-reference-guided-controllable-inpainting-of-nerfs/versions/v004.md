# Reference-guided Controllable Inpainting of NeRFs

Also called: Reference-guided Inpainting

## Overview
A 3D inpainting algorithm that uses a single inpainted reference view to guide the geometry and appearance of a NeRF, avoiding view inconsistencies and generating view-dependent effects [S1]. It differs from multi-view inpainting methods by requiring only one user-provided inpainted image rather than a full set of edited views, and from direct optimization methods by explicitly handling disocclusions and view-dependent effects (VDEs) through specialized loss terms rather than relying solely on pixel reconstruction [S1].

## How it works
**Inputs:** $n$ input images $\{I_i\}_{i=1}^n$, camera transform matrices $\{\Pi_i\}_{i=1}^n$, masks $\{M_i\}_{i=1}^n$ delineating unwanted regions, and a single inpainted reference view $I_r$ where $r \in \{1, ..., N\}$ [S1].
**Outputs:** An optimized NeRF representation $f_\theta$ that reconstructs the scene with the masked regions replaced by content consistent with $I_r$ [S1].

**Data Structures:**
*   **NeRF $f_\theta$:** A multi-layer perceptron mapping 3D coordinates $\mathbf{x}$ and viewing directions $\mathbf{d}$ to density $\sigma$ and color $\mathbf{c}$.
*   **Ray Set $R$:** A collection of rays generated from the input camera poses.
*   **Masked Ray Set $R_{masked}$:** Rays passing through pixels where $M_i=1$.
*   **Unmasked Ray Set $R_{unmasked}$:** Rays passing through pixels where $M_i=0$.

**Steps:**

1.  **Initialization:** Initialize $f_\theta$ using standard NeRF training on unmasked pixels for $N_{depth}$ iterations [S1].
2.  **Geometry Supervision:** Use a monocular depth estimator to predict depth for the inpainted reference view $I_r$. Back-project these depth values to 3D positions. Compute a disparity map and align it with the current NeRF scene. Use this for masked depth supervision via $L_{depth}^{masked}$ [S1].
3.  **View-Dependent Effects (VDEs):** Apply a view-substitution technique followed by bilaterally guided inpainting to obtain target colors $I_{br,t}$ for non-reference views. These target colors are used to compute $L_{rec}^{masked}$ [S1].
4.  **Disocclusion Handling:** For non-reference disoccluded regions not supervised by the single reference view, use image inpainters to guide both geometry and appearance via loss $L_{do}$ [S1].
5.  **Optimization Loop:** Minimize the total loss function, updating $f_\theta$ until convergence [S1].

**Formulas:**

The standard NeRF volume rendering equation for a ray $r$ is:
$$ \hat{C}(r) = \sum_{i=1}^{N} w_i \mathbf{c}_i $$
where $w_i = T_i (1 - \exp(-\sigma_i \delta_i))$ and $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ [S1, 12491-nerf-editing-procedure.md].

The unmasked reconstruction loss is:
$$ L_{rec}^{unmasked} = \mathbb{E}_{r \sim R_{unmasked}} \| \hat{C}(r) - C_{GT}(r) \|^2 $$
where $R_{unmasked}$ is the set of rays corresponding to the pixels in $\{I_i (1 - M_i)\}_{i=1}^n$, and $C_{GT}(r)$ is the ground truth color for ray $r$ [S1].

The total loss function is:
$$ L = L_{rec}^{unmasked} + \gamma_{depth} L_{depth}^{masked} + \gamma_{rec} L_{rec}^{masked} + \gamma_{do} L_{do} $$
where $\gamma_{depth}, \gamma_{rec}, \gamma_{do}$ are weighting coefficients [S1].

**Pseudocode:**

```python
def reference_guided_inpainting(input_images, camera_poses, masks, inpainted_ref_view):
    """
    input_images: List of n images {I_i}
    camera_poses: List of n camera matrices {Pi}
    masks: List of n binary masks {Mi}
    inpainted_ref_view: Single inpainted image Ir
    """
    # Initialize NeRF
    nerf = initialize_nerf()
    
    # Stage 1: Supervise unmasked pixels
    for iteration in range(N_depth):
        rays_unmasked = get_rays(input_images, masks, unmasked_only=True)
        colors_gt = get_gt_colors(rays_unmasked, input_images)
        colors_pred = render_nerf(nerf, rays_unmasked)
        loss_unmasked = mean_squared_error(colors_pred, colors_gt)
        optimize(nerf, loss_unmasked)
        
    # Stage 2: Geometry Supervision using Monocular Depth
    # Back-project inpainted reference view to 3D
    depth_map_ref = monocular_depth_estimator(inpainted_ref_view)
    points_3d_ref = back_project(depth_map_ref, camera_poses[r])
    
    # Compute disparity and align with NeRF
    disparity_map = compute_disparity(depth_map_ref)
    aligned_disparity = align_with_nerf(disparity_map, nerf)
    
    # Compute L_depth_masked
    rays_masked = get_rays(input_images, masks, unmasked_only=False)
    # Note: Exact formula for L_depth_masked not provided in sources [G]
    loss_depth = compute_depth_loss(nerf, rays_masked, aligned_disparity)
    
    # Stage 3: View-Dependent Effects (VDEs)
    # Generate target colors for non-reference views
    target_colors_non_ref = bilateral_guided_inpainting(inpainted_ref_view, camera_poses, masks)
    
    # Compute L_rec_masked using target colors
    # Note: Exact formula for L_rec_masked not provided in sources [G]
    loss_rec_masked = compute_reconstruction_loss(nerf, rays_masked, target_colors_non_ref)
    
    # Stage 4: Disocclusion Handling
    # Identify disoccluded regions in non-reference views
    disoccluded_rays = identify_disocclusions(rays_masked, camera_poses)
    
    # Use image inpainters to guide geometry and appearance
    # Note: Exact formula for L_do not provided in sources [G]
    loss_do = compute_disocclusion_loss(nerf, disoccluded_rays)
    
    # Stage 5: Combined Optimization
    while not converged:
        # Sample rays
        rays_unmasked = sample_rays(input_images, masks, unmasked_only=True)
        rays_masked = sample_rays(input_images, masks, unmasked_only=False)
        
        # Render
        colors_unmasked_pred = render_nerf(nerf, rays_unmasked)
        colors_masked_pred = render_nerf(nerf, rays_masked)
        
        # Compute Losses
        loss_unmasked = mean_squared_error(colors_unmasked_pred, get_gt_colors(rays_unmasked, input_images))
        
        # Update geometry supervision periodically
        if iteration % N_depth == 0:
            loss_depth = compute_depth_loss(nerf, rays_masked, aligned_disparity)
            
        # Update VDE supervision periodically
        if iteration % N_bilateral == 0:
            target_colors_non_ref = bilateral_guided_inpainting(inpainted_ref_view, camera_poses, masks)
            loss_rec_masked = compute_reconstruction_loss(nerf, rays_masked, target_colors_non_ref)
            
        # Update disocclusion supervision periodically
        if iteration % N_do == 0:
            disoccluded_rays = identify_disocclusions(rays_masked, camera_poses)
            loss_do = compute_disocclusion_loss(nerf, disoccluded_rays)
            
        # Total Loss
        total_loss = loss_unmasked + gamma_depth * loss_depth + gamma_rec * loss_rec_masked + gamma_do * loss_do
        
        optimize(nerf, total_loss)
        
    return nerf
```

**Parameters:**
*   $N_{depth}$: Number of iterations for initial unmasked supervision. Not given in the sources.
*   $N_{bilateral}$: Iteration interval for updating bilateral guidance. Not given in the sources.
*   $N_{do}$: Iteration interval for disocclusion loss. Not given in the sources.
*   $\gamma_{depth}, \gamma_{rec}, \gamma_{do}$: Loss weighting coefficients. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Masked Region Under-fitting:** The masked region remains under-fit during the initial $N_{depth}$ iterations to allow altering masked values in later stages [S1].
*   **Disocclusions:** Non-reference disoccluded regions cannot be supervised by the single reference view and require specific handling via image inpainters [S1].
*   **View-Dependent Effects:** Without the bilateral solver technique, non-reference views may lack view-dependent effects [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Shows superior performance to NeRF inpainting baselines [S1].
*   **Scaling:** Not given in the sources.
*   **Strengths:** Avoids view inconsistencies, generates view-dependent effects, controllable via a single inpainted image [S1].
*   **Limitations:** Relies on a single reference view, which may limit the complexity of the inpainted content compared to multi-view inputs [S1].
*   **When to use:** When a user wants to inpaint a NeRF with specific content provided in a single reference view [S1].
*   **When not to use:** When multi-view consistency is critical and only a single view is available, or when the scene has complex view-dependent effects that cannot be captured by the bilateral solver [S1].

## Background
Originated in the paper "Reference-guided Controllable Inpainting of Neural Radiance Fields" [S1]. The method addresses the desire for NeRF editing tools that can inpaint regions in a view-consistent and controllable manner [S1]. It builds on the standard NeRF representation and volume rendering equation [S1, 12491-nerf-editing-procedure.md].
