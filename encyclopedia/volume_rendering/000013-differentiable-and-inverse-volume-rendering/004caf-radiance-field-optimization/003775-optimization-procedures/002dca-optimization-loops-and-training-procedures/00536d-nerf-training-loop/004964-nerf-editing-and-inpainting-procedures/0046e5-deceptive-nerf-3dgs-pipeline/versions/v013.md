# Deceptive-NeRF/3DGS Pipeline

Also called: Deceptive-3DGS, Deceptive-NeRF

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that enhances NeRF or 3D Gaussian Splatting (3DGS) representations by continuously densifying input observations with synthetic pseudo-observations generated by a diffusion model during training [S1]. It distinguishes itself from sibling methods by explicitly enforcing 3D view consistency through an uncertainty map derived from epipolar reprojection of nearest input views, rather than relying on ensemble learning or variational inference [S1]. The method alternates between generating high-fidelity pseudo-observations conditioned on coarse renders and depth/uncertainty maps, and optimizing the radiance field using both real and synthetic data [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A set of $W$ input images $I = \{I_1, \dots, I_W\}$ with calibrated camera poses [S1].
*   A pre-trained 2D latent diffusion model (e.g., Stable Diffusion) [S1].
*   A pre-trained image captioning network [S1].

**Outputs:**
*   An optimized NeRF or 3DGS representation $f_\theta$ capable of high-quality novel view synthesis from sparse inputs [S1].
*   A trained "Deceptive Diffusion Model" $G$ [S1].

### Data Structures

**1. Camera Parameters**
*   $K$: Intrinsic camera matrix (3x3) [S1].
*   $R_{B\rightarrow A}$: Rotation matrix representing the viewpoint difference between nearest input view $B$ and novel view $A$ [S1].

**2. Rendered Quantities at Novel View $A$**
*   $\hat{I}_A$: Rendered RGB image at view $A$ [S1].
*   $D_A$: Rendered depth map at view $A$. Computed as:
    $$ D_A(p) = \sum_{k=1}^K \hat{T}(t_k)\alpha (\sigma (t_k)\delta _k) $$
    where $\hat{T}(t_k)$ is transmittance, $\alpha$ is opacity, $\sigma$ is density, and $\delta_k$ is distance traveled [S1].
*   $U_A$: Uncertainty map at view $A$. Defined as the squared difference between the warped nearest input view and the rendered image:
    $$ U_A = (I_{B \rightarrow A} - \hat {I}_A)^2 $$
    where $I_{B \rightarrow A}$ is the warped image from nearest input view $B$ [S1].

**3. Text Embedding**
*   $s_0$: Text prompt generated by a pre-trained image captioning network from the coarse image [S1].
*   $s^*$: Shared latent text embedding optimized via textual inversion for all input observations and coarse images [S1].
*   $s$: Composite feature formed by concatenating embeddings: $s = [s_0, s^*]$ [S1].

**4. Diffusion Model Inputs (ControlNet)**
*   Control map with 5 channels: 3 for coarse RGB ($I_{coarse}$), 1 for depth ($D$), and 1 for uncertainty ($U$) [S1].
*   Text embedding $s$ [S1].

### Numbered Steps

1.  **Initial Training:** Train a NeRF or 3DGS representation using the few input images $I$ with calibrated poses [S1].
2.  **Coarse Reconstruction:** After a set number of epochs, obtain a coarse reconstruction [S1].
3.  **View Sampling:** Randomly sample a novel viewpoint $A$ within a bounding box defined by the outermost input views [S1].
4.  **Rendering:** At viewpoint $A$, render the RGB image $\hat{I}_A$, depth map $D_A$, and uncertainty map $U_A$ [S1].
    *   To compute $U_A$, identify the nearest input viewpoint $B$ to $A$.
    *   Warp the ground truth image $I_B$ to view $A$ using $D_A$ and $R_{B\rightarrow A}$:
        $$ I_{B\rightarrow A} = \psi (I_B; D_A, R_{B\rightarrow A}) $$
    *   Transform pixel locations $p$ in $\hat{I}_A$ to $q$ in $I_B$:
        $$ q = K R_{B\rightarrow A} D_A(p) K^{-1} p $$
    *   Compute $U_A$ as the squared error between $I_{B\rightarrow A}$ and $\hat{I}_A$ [S1].
5.  **Pseudo-Observation Generation:** Generate a pseudo-observation $P_A$ using the deceptive diffusion model $G$:
    $$ P_A = \operatorname {G}(\hat {I}_A, D_A, U_A) $$
    The model $G$ is conditioned on the coarse rendered image, depth, uncertainty, and text embedding $s$ [S1].
6.  **Accumulation:** Add $P_A$ to the set of pseudo-observations [S1].
7.  **Filtering:** Discard 20% of the accumulated pseudo-observations that have the lowest perceptual similarity to the input images, quantified via the LPIPS metric [S1].
8.  **Optimization:** Continue training the NeRF/3DGS representation using the combination of original input images and the accumulated pseudo-observations [S1].
9.  **Iteration:** Repeat steps 3–8 until a sufficient number of observations are accumulated [S1].

### Diffusion Model Fine-Tuning

To train the deceptive diffusion model $G$, a dataset of quartets $(I_{fine}, I_{coarse}, D, U)$ is constructed.

1.  **Dataset Construction:**
    *   **NeRF Duo Method:** Train a "fine" NeRF on all input images and a "coarse" NeRF on only one-fifth of the input images. Render paired images, depth, and uncertainty maps from the same viewpoints [S1].
    *   **Data Augmentation:** For additional training data, add random Gaussian noise (standard deviation 0.3) to RGB images from Hypersim. Use noisy images and accompanying depth maps as inputs, and original RGB images as targets. Note: Uncertainty maps are **not** fed into the diffusion model during this augmentation phase [S1].
2.  **Text Embedding Derivation:**
    *   Generate text prompt $s_0$ using a pre-trained image captioning network [S1].
    *   Optimize a shared latent text embedding $s^*$ using textual inversion [S1].
    *   Form composite feature $s = [s_0, s^*]$ [S1].
3.  **Training Objective:** Fine-tune a pre-trained latent diffusion model (encoder $\mathcal{E}$, denoiser U-Net $\epsilon_\theta$, decoder $\mathcal{D}$) using ControlNet to preserve pre-trained weights. The objective is:
    $$ \min _{\theta}\mathbb {E}_{z\sim \mathcal {E},t,\epsilon \sim \mathcal {N}(0,1)}\|\epsilon -\epsilon _{\theta }(z_t,t,c(I_{\text {coarse}},D,U,s))\|_2^2 $$
    where $z \sim \mathcal{E}$ is the latent code, $t \sim [1, 1000]$ is the diffusion time step, $\epsilon$ is noise, and $c$ is the embedding of coarse image, depth, uncertainty, and text embedding [S1].
4.  **Implementation Details:**
    *   Use ControlNet with 5 control map channels (3 RGB, 1 Depth, 1 Uncertainty) [S1].
    *   Randomly crop all images to 512 × 512 resolution [S1].
    *   Train on a mixture of Hypersim and CO3D (200 scenes, ~20,000 images) [S1].

    Main training loop for Deceptive-NeRF/3DGS.

def warp_image(I_B, view_B, view_A, D_A):
    """
    Warp image I_B from view B to view A using depth map D_A of view A.
    """
    H, W = I_B.shape[:2]
    I_warped = np.zeros_like(I_B)
    
    # Get camera intrinsic K and relative rotation R_{B->A}
    K = get_camera_intrinsic(view_B)
    R_BA = get_relative_rotation(view_B, view_A)
    
    for y in range(H):
        for x in range(W):
            # Pixel p in I_B (source)
            p = np.array([x, y, 1])
            
            # We need to find where this pixel maps to in I_hat_A (target)
            # However, the formula q = K R D_A(p) K^{-1} p maps p in I_hat_A to q in I_B.
            # To warp I_B to I_hat_A, we need the inverse mapping or iterate over target pixels.
            # The paper defines U_A based on I_{B->A} compared to I_hat_A.
            # So we need to generate I_{B->A} which has same dimensions as I_hat_A.
            pass
            
    # Correct approach: Iterate over target pixels in I_hat_A (view A)
    # and find corresponding source pixel in I_B (view B)
    H_A, W_A = D_A.shape
    I_warped = np.zeros((H_A, W_A, 3))
    
    for y in range(H_A):
        for x in range(W_A):
            p = np.array([x, y, 1]) # Pixel in I_hat_A
            
            # Get depth at p
            depth_p = D_A[y, x]
            
            # Transform p to q in I_B
            # q = K * R_{B->A} * depth_p * K^{-1} * p
            p_homogeneous = np.array([x, y, 1])
            p_in_B = K @ R_BA @ (depth_p * (np.linalg.inv(K) @ p_homogeneous))
            
            # Normalize
            if p_in_B[2] != 0:
                q_x = p_in_B[0] / p_in_B[2]
                q_y = p_in_B[1] / p_in_B[2]
                
                # Check bounds
                if 0 <= q_x < W and 0 <= q_y < H:
                    # Interpolate color from I_B
                    I_warped[y, x] = interpolate_color(I_B, q_x, q_y)
                    
    return I_warped

### Parameters
*   **Discard Rate:** 20% of pseudo-observations with the lowest perceptual similarity (LPIPS) are discarded [S1].
*   **Gaussian Noise Std Dev:** 0.3, added to 60,000 images from Hypersim for data augmentation [S1].
*   **Coarse NeRF Data:** Trained on one-fifth of input images [S1].
*   **ControlNet Channels:** 5 channels (3 for coarse RGB, 1 for depth, 1 for uncertainty) [S1].
*   **Image Resolution:** Randomly cropped to 512 × 512 [S1].
*   **Training Dataset Size:** 200 scenes and approximately 20,000 images (Hypersim and CO3D each contributing half) [S1].

### Edge Cases and Pitfalls
*   **Captioning Efficacy:** Image captioning efficacy diminishes for images of lower quality or those with pronounced artifacts. Textual inversion is used to counteract this by optimizing a shared latent text embedding [S1].
*   **Augmentation Uncertainty:** When training with noisy RGB-depth data augmentation, uncertainty maps are **not** fed into the diffusion model [S1].
*   **Uncertainty Measure:** Unlike approaches using ensemble learning, variational inference, or spatial perturbations, this method acquires uncertainty through correspondence matching by reprojecting real input observations to novel views, minimizing additional computation and enforcing epipolar constraints [S1].

## Operating characteristics

*   **Time Complexity:** The method requires iterative training loops. Each iteration involves rendering (NeRF/3DGS), warping (O(N) for N pixels), diffusion sampling (expensive, depends on steps), and backpropagation through the NeRF/3DGS. The total time is proportional to the number of pseudo-views generated and the cost of diffusion inference.
*   **Memory Complexity:** Requires storing the NeRF/3DGS representation, the diffusion model weights, and the pool of pseudo-observations. The dataset for training the diffusion model itself is large (200 scenes, ~20k images) but is pre-generated.
*   **Performance:** On LLFF dataset, Deceptive-NeRF achieves PSNR of 19.87 (3-view), 21.75 (6-view), 23.22 (9-view). Deceptive-3DGS achieves PSNR of 19.95 (3-view), 21.75 (6-view), 23.22 (9-view) [S1].
*   **Strengths:** Enhances sparse-view reconstruction quality significantly. Enforces 3D consistency via uncertainty maps. Leverages powerful 2D diffusion priors without disrupting their natural image priors (via ControlNet).
*   **Limitations:** Computationally expensive due to iterative diffusion sampling and NeRF training. Relies on the quality of the initial coarse reconstruction and the diffusion model.

## Background

*   **Origin:** Proposed by X. Liu et al. in "Deceptive-NeRF/3DGS: Diffusion-Generated Pseudo-Observations for High-Quality Sparse-View Reconstruction" [S1].
*   **History:** The method addresses the limitation of NeRF/3DGS in sparse-view settings by synthesizing additional training data. It builds on latent diffusion models (Stable Diffusion) and ControlNet [S1].
*   **Usage:** Used for few-shot novel view synthesis, super-resolution on novel views, and sparse-view reconstruction on datasets like LLFF, Mip-NeRF 360, ScanNet, and Hypersim [S1].
