# Adaptive View Selection for Inpainting

Also called: 3D Inpainting Component, 3D Inpainting Component with Adaptive View Selection, Adaptive Weight Inpainting, Gradient-Based View Selection

## Overview
This method addresses the inconsistency artifacts inherent in applying 2D inpainting priors directly to NeRFs by introducing a training view selection mechanism based on regional average gradients [S1]. Unlike methods that uniformly blend 2D priors or rely solely on multi-view geometry, it adaptively switches between using 2D inpainted color priors and multi-view geometric consistency based on the texture richness of occluded sub-regions [S1]. It sets itself apart from [NeRF-In Inpainting Optimization](12372-nerf-in-inpainting-optimization.md) by explicitly modeling the fidelity of supplementary information from other views versus 2D priors via gradient thresholds, and from [Reference-guided Controllable Inpainting of NeRFs](13952-reference-guided-controllable-inpainting-of-nerfs.md) by using internal multi-view gradients rather than external reference images for view selection.

## How it works
The method operates on a pre-trained NeRF representation $f_\theta: (\mathbf{x}, \mathbf{d}) \to (\sigma, \mathbf{c})$ and a set of input views with known masks $M$ identifying occluded regions [S1]. It utilizes a 2D inpainter (specifically LaMa [25]) to generate color priors $C_l$ for occluded areas [S1].

### Inputs and Outputs
*   **Inputs:**
    *   Pre-trained NeRF parameters $\theta$.
    *   Set of input views $V = \{v_1, \dots, v_K\}$ with ground truth colors $C(r)$ and depth $D(r)$ [S1].
    *   Binary masks $M$ indicating occluded regions in each view [S1].
    *   2D inpainted images $I^G$ generated by LaMa for the occluded regions [S1].
*   **Outputs:**
    *   Optimized NeRF parameters $\theta$ that render consistent colors for occluded regions [S1].

### Data Structures
*   **Mask $\hat{P}(r)$:** A predicted mask value for ray $r$, derived from an object segmentation network constrained by depth information [S1]. $\hat{P}(r) \approx 1$ if the ray passes through an occluded region, $\approx 0$ otherwise.
*   **Sub-regions:** The occluded area in each view is divided into multiple sub-regions to evaluate local texture richness [S1].
*   **Color Priors:**
    *   $C(r)$: Ground truth color from input views.
    *   $C_l(r)$: Color from the 2D inpainted image corresponding to ray $r$ [S1].
    *   $\hat{C}_c(r), \hat{C}_f(r)$: Predicted coarse and fine colors from the NeRF [S1].

### Formulas
The total reconstruction loss $L$ is a weighted sum of non-occluded loss $L_{NonOcc}$ and occluded loss $L_{Occ}$ [S1]:

$$
L = \lambda L_{NonOcc} + (1 - \lambda) L_{Occ}
$$

The adaptive weight $\lambda$ is determined by comparing the average gradient of the rendered result $\nabla \hat{g}$ against the average gradient of the 2D inpainting result $\nabla g$ in a sub-region [S1]:

$$
\lambda = \begin{cases} 
1 & \text{if } \nabla \hat{g} > \tau \cdot \nabla g \\
0 & \text{if } \nabla \hat{g} \le \tau \cdot \nabla g 
\end{cases}
$$

where $\tau$ is a threshold parameter [S1].

The reconstruction loss for non-occluded areas $L_{NonOcc}$ is defined as [S1]:

$$
L_{NonOcc} = \sum_{r \in R} (1 - \hat{P}(r)) \left[ \|\hat{C}_c(r) - C(r)\|_2^2 + \|\hat{C}_f(r) - C(r)\|_2^2 \right]
$$

The reconstruction loss for occluded areas $L_{Occ}$ is defined as [S1]:

$$
L_{Occ} = \sum_{r \in R} \hat{P}(r) \left[ \|\hat{C}_c(r) - C_l(r)\|_2^2 + \|\hat{C}_f(r) - C_l(r)\|_2^2 \right]
$$

Additionally, a depth loss $L_{depth}$ is used to guide geometric modeling [S1]:

$$
L_{depth} = \sum_{r \in R} \|\hat{D}(r) - D(r)\|_2^2
$$

### Parameters
*   $\tau$: Threshold for gradient comparison. Not given in the sources.
*   $\lambda_1, \lambda_2, \lambda_3$: Weights for the segmentation network loss components ($L_{region-encoding}, L_{rgb}, L_{depth}$). Not given in the sources.

### Steps
1.  **Segmentation:** Use an object segmentation network to infer masks $M$ for occluded areas in all views, constrained by depth information [S1].
2.  **2D Inpainting:** Apply a 2D inpainter (LaMa) to the occluded regions of each input view to generate color priors $C_l$ [S1].
3.  **Sub-region Division:** Divide the occluded area in each view into multiple sub-regions [S1].
4.  **Gradient Evaluation:** Calculate the average gradient $\nabla \hat{g}$ for the rendered NeRF output and $\nabla g$ for the 2D inpainted output in each sub-region [S1].
5.  **Adaptive Weight Calculation:** Compute $\lambda$ for each sub-region based on the condition $\nabla \hat{g} > \tau \cdot \nabla g$ [S1].
6.  **Loss Computation:** Compute $L_{NonOcc}$ using ground truth colors for non-occluded pixels and $L_{Occ}$ using 2D inpainted colors $C_l$ for occluded pixels [S1].
7.  **Optimization:** Minimize the total loss $L$ (and potentially $L_{depth}$) to update NeRF parameters $\theta$, effectively selecting whether to rely on multi-view consistency (via $\lambda=1$) or 2D priors (via $\lambda=0$) for each sub-region [S1].

### Edge Cases and Pitfalls
*   **Uniform Strategy Misjudgment:** Applying a uniform strategy to the entire occluded area can lead to misjudgment. The method avoids this by dividing the occluded area into sub-regions and evaluating gradients individually [S1].
*   **2D Inpainter Inconsistency:** Single 2D image inpainting does not consider 3D scene consistency. The method mitigates this by selecting training views based on texture richness (gradient) to ensure multi-view consistency [S1].
*   **Gradient Threshold Sensitivity:** The choice of $\tau$ is critical. If $\tau$ is too high, the method may rely too heavily on 2D priors even when multi-view information is available. If too low, it may ignore useful 2D priors when multi-view information is sparse. Not given in the sources.

## Operating characteristics
*   **Time Complexity:** Depends on the number of epochs, views, and sub-regions. Each epoch requires rendering and gradient computation for all rays in occluded regions.
*   **Memory Complexity:** Requires storing NeRF parameters, input views, 2D inpainted images, and intermediate gradients.
*   **Strengths:** Improves fidelity of de-occluded results by leveraging multi-view correlation and avoiding disturbing effects of 2D inpainters [S1]. Handles scenes with a wide range of multi-view data effectively [S1].
*   **Limitations:** Relies on the quality of the 2D inpainter (LaMa) and the accuracy of the segmentation network. Performance may degrade if multi-view information is insufficient or inconsistent [S1].
*   **When to Use:** When inpainting occluded areas in NeRFs where multi-view consistency is crucial and 2D inpainting alone leads to artifacts.
*   **When Not to Use:** When computational resources are limited and high-fidelity multi-view consistency is not required, or when the scene has very few input views.

## Background
The method originates from the paper "3D Scene De-occlusion in Neural Radiance Fields: A Framework for Obstacle Removal and Realistic Inpainting" [S1]. It was developed to address the limitations of applying 2D inpainting directly to NeRFs, which often results in 3D inconsistencies. The method was evaluated on datasets such as LLFF and SPIn-NeRF [S1].
