# Blended-NeRF

Also called: Zero-Shot Object Generation and Blending in Existing Neural Radiance Fields

## Overview
Blended-NeRF is a framework for editing a specific region of interest (ROI) in an existing Neural Radiance Field (NeRF) scene based on text prompts and a 3D ROI box [S1]. It solves the problem of locally modifying a 3D scene while preserving the geometry and appearance outside the ROI, without requiring semantic masks or learning a new feature space [S1]. Unlike methods that synthesize objects from scratch or require 2D masks for localization, Blended-NeRF initializes a generator NeRF with the original scene's weights and blends the synthesized content with the original scene using a novel volumetric blending technique [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained NeRF model $F_{\theta_O}$ representing the original scene $x_o$, a 3D bounding box $B$ defining the ROI, and a user-provided text prompt $y$ [S1].
*   **Output:** An edited NeRF model $F_{\theta_E}$ (implicitly defined by the blending of $F_{\theta_O}$ and the trained generator $F_{\theta_G}$) that renders the scene with the edited ROI [S1].

**Data Structures:**
*   **NeRF Model ($F_\theta$):** A Multi-Layer Perceptron (MLP) mapping 3D coordinates $\mathbf{x}$ and viewing directions $\mathbf{d}$ to density $\sigma$ and color $\mathbf{c}$ [S1].
*   **Positional Encoding:** Inputs are embedded using high-frequency sinusoidal positional encoding $\gamma(\mathbf{x}) = [\cos(2^l \mathbf{x}), \sin(2^l \mathbf{x})]_{l=0}^{L-1}$ [S1].
*   **ROI Box ($B$):** Defined by a center point and dimensions, localized via a GUI using depth maps from $F_{\theta_O}$ [S1].

**Parameters:**
*   $\alpha$: Hyperparameter for distance smoothing blending. Controls the weight given to the original scene vs. the edited scene based on distance from the ROI center. Typical values: 0, 0.5, 2, 4, 10 [S1].
*   $\lambda_T, \lambda_D$: Weights for transmittance and depth losses [S1].
*   $\tau$: Max transmittance threshold for $L_T$ [S1].
*   $\rho$: Max variance threshold for $L_D$ [S1].
*   $\epsilon$: Small constant for numerical stability in blending [S1].
*   $\gamma$: Camera Field of View (FOV) [S1].
*   $e_{max}$: Maximum dimension of the ROI box [S1].

**Numbered Steps:**

1.  **Initialization:** Initialize a generator NeRF model $F_{\theta_G}$ with the weights of the original scene model $F_{\theta_O}$ [S1].
2.  **ROI Localization:** Localize a 3D box $B$ inside the scene using a GUI that renders $F_{\theta_O}$ and uses its depth map for 3D understanding [S1].
3.  **Pose Sampling:** For each training iteration, sample a random camera pose around the scene. The initial distance $d$ from the ROI is calculated as $d = \frac{e_{max}}{2 \tan(\gamma/2)}$, where $\gamma$ is the camera FOV. Randomly sample a radius $r$ around $d$ [S1].
4.  **Ray Casting and Sampling:** Cast rays $r$ from the sampled camera pose. Sample points along the ray.
    *   If a sample point $x_i$ is outside $B$, set its density $\sigma_G(x_i) = 0$ for the generator [S1].
    *   If a sample point $x_i$ is inside $B$, query both $F_{\theta_O}$ and $F_{\theta_G}$ [S1].
5.  **Blending Mode Selection:** Choose between "Object Insertion/Replacement" or "Object Blending" [S1].
    *   *Insertion/Replacement:* During training, consider only the radiance field of $F_{\theta_G}$ inside $B$. After training, blend using distance smoothing [S1].
    *   *Blending:* Query both models inside $B$. Compute alpha values: $\alpha_O(x_i) = 1 - \exp(\phi(\sigma_O(x_i)) \cdot \delta_i)$ and $\alpha_G(x_i) = 1 - \exp(\phi(\sigma_G(x_i)) \cdot \delta_i)$, where $\phi$ is a non-negative activation function (e.g., ReLU) [S1].
6.  **Density Blending (Blending Mode Only):**
    *   Option 1 (Sum in activation): $\sigma(x_i) = \phi(\sigma_O(x_i) + \sigma_G(x_i))$. Allows $F_{\theta_G}$ to remove original densities [S1].
    *   Option 2 (Sum out activation): $\sigma(x_i) = \phi(\sigma_O(x_i)) + \phi(\sigma_G(x_i))$. Allows only addition of new densities [S1].
    *   Compute joint transmittance and alpha values using the standard volume rendering equation [S1].
7.  **Color Blending (Blending Mode Only):** Compute the blended color $c(x_i)$:
    $$c(x_i) = S\left(\frac{c_O(x_i) \cdot \alpha_O(x_i) + c_G(x_i) \cdot \alpha_G(x_i)}{\epsilon + \alpha_O(x_i) + \alpha_G(x_i)}\right)$$
    where $S$ is the sigmoid function and $\epsilon$ is a small constant [S1].
8.  **Rendering ROI Content:** Render the generated content inside the ROI $I_{ROI}$ using only points $x_i \in B$. If no points are in $B$, the result is 0 [S1]:
    $$C(r) = \frac{\sum_{x_i \in B} T_i (1 - e^{-\sigma_i \delta_i}) c_i}{\sum_{x_i \in B} T_i (1 - e^{-\sigma_i \delta_i})} \quad \text{if } \exists x_i \in r \text{ s.t. } x_i \in B, \text{ else } 0$$
    where $T_i = \exp(-\sum_{j < i} \sigma_j \delta_j)$ [S1].
9.  **Loss Computation:**
    *   **Similarity Loss:** $L_{sim} = -E_{img}(I_{ROI})^T E_{txt}(y)$, where $E_{img}$ and $E_{txt}$ are CLIP image and text encoders [S1].
    *   **Transmittance Loss:** $L_T = -\min(\tau, \text{mean}(T(P)))$, where $T(P)$ is the average transmittance of the rendered view from pose $P$ [S1].
    *   **Depth Loss:** $L_D = -\min(\rho, \sigma^2(D(P)))$, where $\sigma^2(D(P))$ is the variance of the disparity map of the rendered view [S1].
    *   **Total Loss:** $L_{total} = L_{sim} + \lambda_T L_T + \lambda_D L_D$ [S1].
    *   *Note:* $L_T$ and $L_D$ are gradually introduced during training using an annealing strategy [S1].
10. **Optimization:** Optimize $F_{\theta_G}$ by minimizing $L_{total}$ [S1].
11. **Final Blending (Post-Training):** To render the final edited scene $x_e$, blend the raw densities and RGB values of $F_{\theta_O}$ and $F_{\theta_G}$ inside the ROI using distance smoothing:
    $$f(x) = 1 - \exp\left(-\alpha \frac{d(x)}{diag}\right)$$
    $$\sigma_{blend}(x) = f(x) \cdot \sigma_O(x) + (1 - f(x)) \cdot \sigma_G(x)$$
    $$c_{blend}(x) = f(x) \cdot c_O(x) + (1 - f(x)) \cdot c_G(x)$$
    where $d(x)$ is the Euclidean distance from the ROI center, $diag$ is the box diagonal, and $\alpha$ is the smoothing parameter [S1]. Points outside $B$ remain unchanged ($x_e \odot (1 - B) = x_o \odot (1 - B)$) [S1].

import numpy as np

def positional_encoding(x, L=10):
    """High frequency sinusoidal positional encoding."""
    # x is shape (N, 3)
    scales = np.array([2**l for l in range(L)])
    encoded = []
    for scale in scales:
        encoded.append(np.cos(scale * x))
        encoded.append(np.sin(scale * x))
    return np.concatenate(encoded, axis=-1)

def volume_rendering(samples, densities, colors, delta):
    """
    Standard volume rendering.
    samples: (N, 3) coordinates along ray
    densities: (N,) sigma values
    colors: (N, 3) rgb values
    delta: (N,) distance between adjacent samples
    Returns: color (3,), transmittance (N,)
    """
    # Compute transmittance
    # T_i = exp(-sum_{j=1}^{i-1} sigma_j * delta_j)
    # Using cumulative sum for efficiency
    alpha = 1.0 - np.exp(-densities * delta)
    transmittance = np.ones(len(densities) + 1)
    transmittance[1:] = np.cumprod(1.0 - alpha)
    
    # Contribution
    contribution = transmittance[:-1] * alpha * colors
    
    # Final color
    final_color = np.sum(contribution, axis=0)
    return final_color, transmittance[:-1]

def blend_colors(c_o, c_g, alpha_o, alpha_g, epsilon=1e-8):
    """
    Blend colors from original and generator models.
    c_o, c_g: (N, 3) colors
    alpha_o, alpha_g: (N,) alpha values
    """
    numerator = c_o * alpha_o[:, None] + c_g * alpha_g[:, None]
    denominator = epsilon + alpha_o[:, None] + alpha_g[:, None]
    blended = numerator / denominator
    # Apply sigmoid
    return 1.0 / (1.0 + np.exp(-blended))

def compute_alpha(sigma, delta, activation=np.relu):
    """Compute alpha from density."""
    # sigma is passed through activation to ensure non-negative
    activated_sigma = activation(sigma)
    return 1.0 - np.exp(-activated_sigma * delta)

def distance_smoothing_factor(x, roi_center, diag, alpha_param):
    """
    Compute blending weight f(x) based on distance from ROI center.
    x: (N, 3) points
    roi_center: (3,) center of ROI
    diag: float, diagonal of ROI box
    alpha_param: float, smoothing hyperparameter
    """
    distances = np.linalg.norm(x - roi_center, axis=1)
    f = 1.0 - np.exp(-alpha_param * distances / diag)
    return f

    Render the final edited scene by blending F_theta_O and F_theta_G.

            if B.is_inside(p):

## Operating characteristics
*   **Time Complexity:** Training time depends on the number of iterations and the cost of querying two NeRFs per sample point inside the ROI. The use of CLIP adds inference overhead for the similarity loss.
*   **Memory Complexity:** Requires storing the weights of both the original NeRF $F_{\theta_O}$ and the generator NeRF $F_{\theta_G}$.
*   **Strengths:**
    *   Enables zero-shot editing of any region in an existing NeRF without requiring 2D masks or semantic decomposition [S1].
    *   Preserves the original scene outside the ROI [S1].
    *   Produces view-consistent results through volumetric blending and priors [S1].
    *   Supports multiple editing modes: insertion, replacement, and blending [S1].
*   **Limitations:**
    *   Quality depends on the text prompt and the accuracy of the ROI localization [S1].
    *   May produce amorphous or transparent scenes if transmittance and depth losses are not properly annealed [S1].
    *   Limited to forward-facing or 360-degree scenes with sufficient viewing intervals for depth loss effectiveness [S1].
*   **When to use:** When you need to insert, replace, or blend objects into an existing NeRF scene using text prompts, and you have a way to define a 3D ROI box.
*   **When not to use:** When you need to edit the entire scene, or when semantic masks are available and a different method (like DFF) is preferred for feature-level editing.

## Background
Blended-NeRF was introduced by Ori Gordon, Omri Avrahami, and Dani Lischinski from The Hebrew University in 2023 [S1]. It builds upon the principles of Dream Fields [S1], which used CLIP to guide NeRF generation, and extends them to the context of editing existing scenes. The method addresses the limitations of previous NeRF editing techniques that required semantic decomposition or 2D masks [S1].
