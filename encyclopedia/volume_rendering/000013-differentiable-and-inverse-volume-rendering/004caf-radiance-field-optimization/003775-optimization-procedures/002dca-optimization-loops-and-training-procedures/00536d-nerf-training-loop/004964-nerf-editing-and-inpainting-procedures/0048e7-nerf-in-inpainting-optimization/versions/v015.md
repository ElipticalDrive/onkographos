# NeRF-In Inpainting Optimization

Also called: Free-Form NeRF Inpainting with RGB-D Priors, NeRF object removal, NeRF-In

## Overview
NeRF-In is a framework for removing unwanted objects from a pre-trained Neural Radiance Field (NeRF) by optimizing the model parameters $\Theta$ using color and depth guidance derived from 2D images, without requiring category-specific training data [S1, unofficial]. It sets itself apart from sibling methods like [Blended-NeRF](12273-blended-nerf.md) or [DFF](12068-dff-decomposing-nerf-for-editing-via-feature-field-distillat.md) by relying on external 2D inpainting priors (color and depth) rather than semantic segmentation networks or feature distillation, and it explicitly optimizes for geometric consistency via a depth-guiding loss to prevent the "ghosting" of removed objects [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained NeRF model $F_\Theta$ mapping 3D coordinates $\mathbf{x}$ and viewing directions $\mathbf{d}$ to density $\sigma$ and color $\mathbf{c}$; a user-chosen camera position $o_u$; a user-drawn binary mask $M_u$ on the rendered view $I_u = F_{\Theta_{image}}(o_u)$, where $M_u=1$ for pixels outside the masked region (background) and $M_u=0$ inside (object to remove) [S1, unofficial].
*   **Output:** Updated NeRF parameters $\tilde{\Theta}$ such that the unwanted object is removed in all rendered views [S1, unofficial].

**Data Structures:**
*   **NeRF Model $F_\Theta$:** A multi-layer perceptron (MLP) taking position $\mathbf{x}$ and direction $\mathbf{d}$ as input. The implementation uses a coarse and fine model hierarchy [S1, unofficial].
*   **Camera Trajectory:** A set of $K$ sampled camera positions $O = \{o_s \mid s = 1 \dots K\}$ along a pre-set trajectory (e.g., LLFF test-set trajectory) [S1, unofficial].
*   **Guiding Materials:**
    *   Transferred masks $M = \{M_s \mid s = 1 \dots K\}$, generated by transferring $M_u$ to sampled views using a video object segmentation method (e.g., STCN) [S1, unofficial].
    *   Guiding color images $I^G = \{I_s^G \mid s = 1 \dots K\}$, generated by applying a 2D image inpainting method $\rho$ to the sampled views $I_s$ using masks $M_s$: $I_s^G = \rho(I_s, M_s)$ [S1, unofficial].
    *   Guiding depth images $D^G = \{D_s^G \mid s = 1 \dots K\}$, generated by applying a depth completion method $\tau$ to the sampled depth $D_s$, mask $M_s$, and guiding color $I_s^G$: $D_s^G = \tau(D_s, M_s, I_s^G)$ [S1, unofficial].

**Numbered Steps:**
1.  **Initialization:** Initialize NeRF parameters $\Theta$ (using a pre-trained model for the main method) [S1, unofficial].
2.  **Sampling:** Sample $K$ camera positions $O$ along a pre-set trajectory. Render RGB images $I_s$ and depth images $D_s$ using $F_\Theta$ [S1, unofficial].
3.  **Mask Transfer:** Transfer the user-drawn mask $M_u$ to the sampled views to generate transferred masks $M = \{M_s\}$ using a video object segmentation method (e.g., STCN) [S1, unofficial].
4.  **Guiding Material Generation:**
    *   Generate guiding color images $I_s^G$ for each sampled view $I_s$ using an image inpainting method $\rho$ (e.g., MST inpainting network) [S1, unofficial].
    *   Generate guiding depth images $D_s^G$ for each sampled view using a depth completion method $\tau$ (e.g., Fast Bilateral Solver) [S1, unofficial].
5.  **Optimization:** Optimize the NeRF parameters $\Theta$ to obtain $\tilde{\Theta}$ by minimizing the joint inpainting formulation $\Phi(M_u, I_u^G, M, D_s^G)$, which consists of a color-guiding loss $L_{color}(\Theta)$ and a depth-guiding loss $L_{depth}(\Theta)$ [S1, unofficial].

**Formulas:**
The expected color $\hat{C}(r)$ of a camera ray $r(t) = o + td$ is computed via volume rendering integral [S1, unofficial]:
$$ \hat{C}(r) = \sum_{i=1}^{N} T(t_i)(1 - \exp(-\sigma(t_i)\delta_i))c(t_i) $$
where $T(t_i) = \exp(-\sum_{j=1}^{i-1} \sigma(t_j)\delta_j)$, $N$ is the number of quadrature points, $\delta_i = t_{i+1} - t_i$, and $c(t_i), \sigma(t_i)$ are color and density at point $t_i$ produced by $F_\Theta$ [S1, unofficial].

The total color-guiding loss $L_{color}(\Theta)$ is the sum of the all-view color loss $L_{all\_color}(\Theta)$ and the outside-view color loss $L_{out\_color}(\Theta)$ [S1, unofficial]:
$$ L_{color}(\Theta) = L_{all\_color}(\Theta) + L_{out\_color}(\Theta) $$
where [S1, unofficial]:
$$ L_{all\_color}(\Theta) = \sum_{o \in O_{all}} \| F_{\Theta_{image}}(o) - I_o^G \|_2^2 $$
$$ L_{out\_color}(\Theta) = \sum_{o \in O_{out}} \| (F_{\Theta_{image}}(o) - I_o^G) \odot M_o \|_2^2 $$
In the main framework, $O_{all} = \{o_u\}$ (the user-chosen view) and $O_{out} = O$ (all other sampled views) [S1, unofficial].

The depth-guiding loss $L_{depth}(\Theta)$ measures the L2 distance between rendered fine/coarse depth images and guiding depth [S1, unofficial]:
$$ L_{depth}(\Theta) = \sum_{o_s \in O} \left( \| D_f(o_s) - D_s^G(o_s) \|_2^2 + \| D_c(o_s) - D_s^G(o_s) \|_2^2 \right) $$
where $D_f(o_s)$ is the fine volume predicted depth image and $D_c(o_s)$ is the coarse volume predicted depth image, computed by accumulating density $\sigma$ from ray batches during volume rendering [S1, unofficial].

The final optimization objective is [S1, unofficial]:
$$ \tilde{\Theta} := \arg \min_{\Theta} L_{color}(\Theta) + L_{depth}(\Theta) $$

**Parameters:**
*   $K$: Number of sampled camera positions/views.
*   Batch size: 4,096 [S1, unofficial].
*   Sample points in fine model: 128 [S1, unofficial].
*   Sample points in coarse model: 64 [S1, unofficial].
*   Optimizer: Adam [S1, unofficial].
*   Training steps for inpainting: 50,000 steps [S1, unofficial].

**Pseudocode:**
```python
def nerf_in_inpainting(F_theta, o_u, M_u, trajectory_sampler, mask_transfer_net, 
                       color_inpainter, depth_completer, optimizer, num_steps):
    """
    Optimizes NeRF parameters to remove an object specified by M_u on view o_u.
    """
    # 1. Sample camera positions
    O = trajectory_sampler.sample(K=K) # K is predefined
    
    # 2. Render initial views and depths
    I_s_list = []
    D_s_list = []
    for o_s in O:
        I_s = render_image(F_theta, o_s)
        D_s = render_depth(F_theta, o_s) # Accumulate sigma for depth
        I_s_list.append(I_s)
        D_s_list.append(D_s)
        
    # 3. Transfer mask to sampled views
    M_list = []
    for I_s in I_s_list:
        M_s = mask_transfer_net.transfer(M_u, I_s) # e.g., STCN
        M_list.append(M_s)
        
    # 4. Generate guiding materials
    I_G_list = []
    D_G_list = []
    for I_s, M_s in zip(I_s_list, M_list):
        I_G = color_inpainter.inpaint(I_s, M_s) # e.g., MST network
        D_G = depth_completer.complete(I_s, M_s, I_G) # e.g., Fast Bilateral Solver
        I_G_list.append(I_G)
        D_G_list.append(D_G)
        
    # 5. Define loss sets
    O_all = {o_u}
    O_out = O
    
    # 6. Optimization loop
    for step in range(num_steps):
        # Sample rays for batch
        rays = sample_rays(F_theta, O_all | O_out)
        
        # Forward pass
        # Render coarse and fine colors and depths
        c_c, sigma_c = F_theta.coarse(rays)
        c_f, sigma_f = F_theta.fine(rays)
        
        # Compute rendered colors
        C_c = volume_render_color(c_c, sigma_c)
        C_f = volume_render_color(c_f, sigma_f)
        
        # Compute rendered depths
        D_c = volume_render_depth(sigma_c, rays)
        D_f = volume_render_depth(sigma_f, rays)
        
        # Compute Color Loss
        # L_all_color: on user view o_u
        I_u_rendered = render_image(F_theta, o_u)
        I_u_G = I_G_list[0] # Assuming o_u is first or mapped correctly
        L_all_color = mse(I_u_rendered, I_u_G)
        
        # L_out_color: on other views O_out, masked
        L_out_color = 0
        for o_s, M_s, I_G_s in zip(O_out, M_list[1:], I_G_list[1:]):
            I_s_rendered = render_image(F_theta, o_s)
            # Masked MSE: only compute error outside the object (M_s=1)
            # Note: M_s=1 is background, M_s=0 is object. 
            # Formula uses M_o in L_out_color definition. 
            # Assuming M_s is the mask where 1 is valid/background.
            diff = (I_s_rendered - I_G_s) * M_s
            L_out_color += mse(diff, diff) # Sum of squared errors
            
        L_color = L_all_color + L_out_color
        
        # Compute Depth Loss
        L_depth = 0
        for o_s, D_G_s in zip(O, D_G_list):
            # Find corresponding rendered depths for o_s
            # D_f and D_c are already computed for the batch rays
            # Aggregate to image space or compute per-ray loss
            D_f_s = get_depth_for_view(D_f, rays, o_s)
            D_c_s = get_depth_for_view(D_c, rays, o_s)
            L_depth += mse(D_f_s, D_G_s) + mse(D_c_s, D_G_s)
            
        # Total Loss
        loss = L_color + L_depth
        
        # Backward pass
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
    return F_theta
```

**Edge Cases and Pitfalls:**
*   Optimizing only with masked MSE (mmse) on transferred masks without explicit guidance causes the unwanted object to remain in the result [S1, unofficial].
*   Using only depth-guiding loss ($L_{depth}$) introduces color noise outside the masked region and loses color information in flat regions [S1, unofficial].
*   Using multiple inpainted images as color guidance introduces visual inconsistency between views; the method restricts $L_{all\_color}$ to the user-chosen view only to maintain consistency [S1, unofficial].
*   Artifacts in the initial 2D guidance materials (color or depth) may propagate to the optimized NeRF [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The optimization requires 50,000 steps of Adam optimization [S1, unofficial]. On an Intel i7-7800X CPU and GTX-1080 GPU, this takes approximately five hours per scene [S1, unofficial].
*   **Memory Complexity:** Depends on the batch size (4,096 rays) and the number of sample points (64 coarse, 128 fine) [S1, unofficial].
*   **Strengths:** Does not require category-specific training data or procedures; handles free-form masks; maintains view consistency across novel views [S1, unofficial].
*   **Limitations:** Relies on the quality of external 2D inpainting and depth completion methods; may produce undesired results if initial guidance contains artifacts; not suitable for adding new objects (only removal/retouching) [S1, unofficial].
*   **When to use:** When removing unwanted objects from a pre-trained NeRF without access to category-specific training data or when a simple, free-form mask is available [S1, unofficial].
*   **When not to use:** When the scene requires adding new objects, or when high-quality 2D inpainting priors are difficult to generate for the specific content [S1, unofficial].

## Background
NeRF-In was introduced by Hao-Kang Liu, I-Chao Shen, and Bing-Yu Chen in June 2022 [S1, unofficial]. It addresses the unintuitive nature of editing pre-trained NeRFs, where parameters are not explicitly associated with scene geometry or appearance. Unlike previous methods that required learning additional category-level conditional radiance fields or segmentation networks, NeRF-In was the first framework to enable free-form object removal without category-specific data [S1, unofficial]. It is implemented in PyTorch and Python 3.9 and has been evaluated on the LLFF dataset and custom datasets [S1, unofficial].
