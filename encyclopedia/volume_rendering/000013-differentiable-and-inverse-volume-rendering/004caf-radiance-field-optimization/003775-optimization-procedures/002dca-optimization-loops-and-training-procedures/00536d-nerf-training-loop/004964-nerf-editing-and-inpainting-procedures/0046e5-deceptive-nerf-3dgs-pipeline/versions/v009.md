# Deceptive-NeRF/3DGS Pipeline

Also called: Deceptive-3DGS, Deceptive-NeRF

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that enhances NeRF or 3D Gaussian Splatting (3DGS) representations by continuously densifying input observations with synthetic pseudo-observations generated by a diffusion model during training [S1]. Unlike methods that rely on ensemble learning, variational inference, or spatial perturbations to quantify uncertainty, this approach acquires uncertainty through correspondence matching by reprojecting real input observations to novel views, thereby enforcing epipolar constraints and minimizing additional computation [S1]. It sets itself apart from sibling methods like [NeRF-In Inpainting Optimization](12372-nerf-in-inpainting-optimization.md) by integrating a "deceptive" diffusion model conditioned on rendered RGB, depth, and uncertainty maps to rectify artifacts and fill geometric gaps, rather than solely relying on 2D guidance images or textual prompts for optimization [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A set of $W$ input images $I = \{I_1, \dots, I_W\}$ with calibrated camera poses.
*   A pre-trained 2D diffusion model (e.g., Stable Diffusion) with a ControlNet architecture.
*   A pre-trained image captioning network.
*   A text embedding optimizer (for textual inversion).

**Outputs:**
*   A refined radiance field representation (NeRF or 3DGS) trained on a combination of real input images and accumulated pseudo-observations.
*   A set of pseudo-observations $P_A$ generated for novel viewpoints.

### Data Structures
1.  **Radiance Field Parameters ($\Theta$):** Stores the NeRF MLP weights or 3DGS Gaussian parameters (position, covariance, opacity, SH coefficients).
2.  **Camera Parameters ($K$):** The intrinsic camera matrix $K$ used for projection.
3.  **ControlNet Control Map:** A 5-channel tensor per image: 3 channels for coarse RGB, 1 channel for depth, 1 channel for uncertainty.
4.  **Text Embedding ($s$):** A concatenated vector $s = [s_0, s^*]$ where $s_0$ is the caption embedding and $s^*$ is the optimized latent embedding.
5.  **Pseudo-Observation Buffer:** A collection of generated images $P_A$ and their corresponding poses, filtered by LPIPS similarity.

### Numbered Steps

1.  **Initial Training:** Train the NeRF/3DGS representation using the few-view input images $I$ for a set number of epochs to obtain a coarse reconstruction.
2.  **Novel View Sampling:** Randomly sample a novel viewpoint $A$ within the bounding box defined by the outermost input views.
3.  **Rendering:** At viewpoint $A$, render the coarse RGB image $\hat{I}_A$, the depth map $D_A$, and the uncertainty map $U_A$.
    *   **Depth Rendering:** Compute depth as a weighted sum of distances traveled:
        $$ \hat{\mathbf{D}} = \sum_{k=1}^K \hat{T}(t_k)\alpha(\sigma(t_k)\delta_k) $$
        where $\hat{T}(t_k)$ is transmittance, $\alpha$ is opacity, $\sigma$ is density, and $\delta_k$ is the distance traveled at sample $k$ [S1].
    *   **Uncertainty Map Generation:** Identify the nearest input viewpoint $B$ to the novel view $A$. Warp the ground truth image $I_B$ to viewpoint $A$ using the rendered depth $D_A$ and the viewpoint difference $R_{B \rightarrow A}$:
        $$ I_{B \rightarrow A} = \psi(I_B; D_A, R_{B \rightarrow A}) $$
        The pixel transformation from $\hat{I}_A$ to $I_B$ is:
        $$ q = K R_{B \rightarrow A} D_A(p) K^{-1} p $$
        where $p$ is the pixel location in $\hat{I}_A$ and $q$ is the transformed pixel location in $I_B$. The uncertainty map is the squared difference:
        $$ U_A = (I_{B \rightarrow A} - \hat{I}_A)^2 $$
        [S1].
4.  **Text Embedding Derivation:**
    *   Generate an initial text prompt $s_0$ using a pre-trained image captioning network on the coarse image $\hat{I}_A$.
    *   Optimize a shared latent text embedding $s^*$ using textual inversion, shared across all input observations and coarse images.
    *   Form the composite feature $s = [s_0, s^*]$ by concatenating the embeddings [S1].
5.  **Pseudo-Observation Generation:** Generate the pseudo-observation $P_A$ using the Deceptive Diffusion Model $G$:
    $$ P_A = G(\hat{I}_A, D_A, U_A) $$
    The model $G$ is a latent diffusion model with a denoiser U-Net $\epsilon_\theta$. It is conditioned on the coarse image, depth, uncertainty, and text embedding $s$ via ControlNet [S1].
6.  **Filtering:** Calculate the perceptual similarity between the generated pseudo-observation $P_A$ and the input images using the LPIPS metric. Discard the 20% of pseudo-observations with the lowest similarity to avoid generating content far from the original inputs [S1].
7.  **Accumulation and Optimization:** Accumulate the valid pseudo-observations. Continue training the NeRF/3DGS representation using the combination of real input images and the accumulated pseudo-observations.
8.  **Iteration:** Repeat steps 2–7 until a sufficient number of observations are accumulated for the target reconstruction quality [S1].

### Parameters
*   **Discard Rate:** 20% of pseudo-observations with the lowest perceptual similarity (LPIPS) are discarded [S1].
*   **ControlNet Channels:** 5 channels (3 for coarse RGB, 1 for depth, 1 for uncertainty) [S1].
*   **Image Resolution:** All images are randomly cropped to $512 \times 512$ resolution [S1].
*   **Training Dataset Size:** 200 scenes and approximately 20,000 images for the major section of the training dataset, with Hypersim and CO3D each contributing half [S1].
*   **Coarse NeRF Training Data:** Coarse NeRFs are trained using only one-fifth of the input images [S1].
*   **Gaussian Noise Standard Deviation:** 0.3, added to 60,000 images from Hypersim for data augmentation [S1].
*   **Diffusion Time Step:** $t \sim [1, 1000]$ [S1].

### Edge Cases and Pitfalls
*   **Captioning Efficacy:** Image captioning efficacy diminishes for images of lower quality or those with pronounced artifacts. This is counteracted by optimizing a shared latent text embedding $s^*$ via textual inversion [S1].
*   **Noisy Data Augmentation:** When training with noisy RGB-depth data augmentation (adding Gaussian noise to RGB images), uncertainty maps are not fed into the diffusion model [S1].
*   **Precision:** The depth rendering formula relies on accurate transmittance and density estimates; errors in $\sigma$ can propagate to $D_A$ and subsequently to $U_A$ [S1].

## Operating characteristics

### Time and Memory Complexity
*   **Time:** The method requires iterative training loops where each iteration involves rendering, warping, diffusion sampling, and gradient backpropagation. The diffusion model inference is the most computationally expensive step per novel view. The number of iterations depends on the desired density of pseudo-observations.
*   **Memory:** Requires storing the radiance field parameters, the diffusion model weights, and the buffer of pseudo-observations. The ControlNet architecture adds memory overhead compared to standard Stable Diffusion.

### Measured Performance
*   **Hardware:** Not specified in the sources.
*   **Resolution:** Evaluated at $512 \times 512$ (cropped).
*   **Scene:** Tested on Hypersim, ScanNet, LLFF, and Mip-NeRF 360.
*   **Metrics:** On LLFF with 3 views, Deceptive-NeRF achieves PSNR 19.87, SSIM 0.438, LPIPS 0.270. Deceptive-3DGS achieves PSNR 19.95, SSIM 0.438, LPIPS 0.270. These are compared against SRF, PixelNeRF, MVSNeRF, DietNeRF, RegNeRF, and FreeNeRF [S1].

### Scaling
*   The method scales with the number of input views $W$ and the number of pseudo-observations generated. More pseudo-observations generally lead to better reconstruction but increase training time.

### Strengths and Limitations
*   **Strengths:** Enforces 3D consistency via uncertainty maps derived from epipolar constraints. Improves sparse-view reconstruction quality significantly. Leverages powerful 2D diffusion priors.
*   **Limitations:** Computationally intensive due to diffusion model usage. Relies on the quality of the initial coarse reconstruction. Performance may degrade if the captioning network fails to generate meaningful text embeddings for low-quality inputs.

### When to Use
*   Use when reconstructing scenes from very few input views (sparse-view) where standard NeRF/3DGS fails to capture fine details or suffers from artifacts.
*   Use when high-fidelity novel view synthesis is required and computational resources allow for iterative diffusion-based training.

### When Not to Use
*   Do not use when real-time rendering is required, as the training process is slow.
*   Do not use if the input images are of very low quality, as the captioning and diffusion models may generate inconsistent pseudo-observations.

## Background

### Origin
The method was introduced in the paper "Deceptive-NeRF/3DGS: Diffusion-Generated Pseudo-Observations for High-Quality Sparse-View Reconstruction" by X. Liu et al. [S1].

### History and Development
The method builds on the principles of differentiable rendering and latent diffusion models. It addresses the limitations of sparse-view reconstruction by introducing a "deceptive" diffusion model that rectifies NeRF/3DGS renderings. The uncertainty measure is a novel contribution that avoids ensemble learning or variational inference, instead using correspondence matching [S1].

### Usage
The method is used for high-quality sparse-view reconstruction, novel view synthesis, and super-resolution of 3D scenes. It has been evaluated on synthetic (Hypersim) and real-world (ScanNet, LLFF, Mip-NeRF 360) datasets [S1].
