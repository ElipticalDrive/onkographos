# NeRF-In Inpainting Optimization

Also called: Free-Form NeRF Inpainting with RGB-D Priors, NeRF object removal, NeRF-In

## Overview
NeRF-In is an optimization-based method for removing unwanted objects from a pre-trained Neural Radiance Field (NeRF) without requiring category-specific training data or retraining the model from scratch [S1, unofficial]. It solves the problem of multi-view consistent inpainting by updating the NeRF parameters $\Theta$ to minimize a joint loss function derived from 2D color and depth guidance generated from a single user-drawn mask [S1, unofficial]. Unlike inference-time interception methods that simply zero out density, NeRF-In actively reconstructs the geometry and appearance of the occluded region by leveraging RGB-D priors, ensuring that the edited scene renders consistently across novel views [S1, unofficial].

## How it works

### Inputs and Outputs
*   **Inputs:**
    *   Pre-trained NeRF model $F_\Theta$ with parameters $\Theta$ [S1, unofficial].
    *   User-chosen camera position $o_u$ and its rendered image $I_u = F_{\Theta_{image}}(o_u)$ [S1, unofficial].
    *   User-drawn binary mask $M_u$ on $I_u$, where $M_u = 1$ for pixels outside the masked region (background/valid) and $M_u = 0$ inside the masked region (object to remove) [S1, unofficial].
    *   A pre-set trajectory of camera positions $O = \{o_s \mid s = 1 \dots K\}$ (e.g., LLFF test-set trajectory) [S1, unofficial].
*   **Outputs:**
    *   Updated NeRF parameters $\tilde{\Theta}$ [S1, unofficial].
    *   Rendered images and depth maps from $\tilde{\Theta}$ showing the removed object [S1, unofficial].

### Data Structures
The method relies on standard NeRF data structures but introduces specific guidance buffers:
*   **Ray Batch $R$:** A set of camera rays $r(t) = o + td$ sampled for volume rendering.
*   **Guiding Color Images $I^G$:** A set of inpainted images $\{I_s^G\}$ corresponding to sampled views.
*   **Guiding Depth Images $D^G$:** A set of completed depth maps $\{D_s^G\}$ corresponding to sampled views.
*   **Transferred Masks $M$:** A set of binary masks $\{M_s\}$ transferred from $M_u$ to sampled views.

### Numbered Steps

1.  **Initialize Parameters:**
    Initialize the NeRF parameters $\Theta$ using the pre-trained weights [S1, unofficial].

2.  **Sample Views:**
    Sample $K$ camera positions $O = \{o_s \mid s = 1 \dots K\}$ along a pre-set trajectory [S1, unofficial].

3.  **Render Initial Views:**
    Render RGB images $I_s$ and depth images $D_s$ for each sampled camera position $o_s \in O$ using the current NeRF model $F_\Theta$ [S1, unofficial].

4.  **Transfer Mask:**
    Transfer the user-drawn mask $M_u$ from the user-chosen view $o_u$ to the sampled views $O$ to generate transferred masks $M = \{M_s\}$. This is achieved using a video object segmentation method (e.g., STCN) [S1, unofficial].

5.  **Generate Guiding Materials:**
    *   **Color Guidance:** For each sampled view $I_s$ and its mask $M_s$, generate a guiding color image $I_s^G$ using a single-image inpainting method $\rho$:
        $$ I_s^G = \rho(I_s, M_s) $$
        The method uses the MST inpainting network [S1, unofficial].
    *   **Depth Guidance:** For each sampled view, generate a guiding depth image $D_s^G$ using a depth completion method $\tau$ applied to the rendered depth $D_s$, the mask $M_s$, and the guiding color $I_s^G$:
        $$ D_s^G = \tau(D_s, M_s, I_s^G) $$
        The method uses the Fast Bilateral Solver [S1, unofficial].

6.  **Define View Sets:**
    Define the set of all views $O_{all}$ and outside views $O_{out}$. In the main framework:
    *   $O_{all} = \{o_u\}$ (only the user-chosen view is used for color consistency loss).
    *   $O_{out} = O$ (all sampled views are used for depth consistency loss) [S1, unofficial].

7.  **Optimize NeRF Parameters:**
    Update $\Theta$ to $\tilde{\Theta}$ by minimizing the total loss $L(\Theta) = L_{color}(\Theta) + L_{depth}(\Theta)$ using the Adam optimizer for 50,000 steps [S1, unofficial].

### Formulas

**Volume Rendering:**
The expected color $\hat{C}(r)$ of a camera ray $r(t) = o + td$ is computed via volume rendering integral [S1, unofficial]:
$$ \hat{C}(r) = \sum_{i=1}^{N} T(t_i)(1 - \exp(-\sigma(t_i)\delta_i))c(t_i) $$
where:
*   $N$ is the number of quadrature points.
*   $\delta_i = t_{i+1} - t_i$ is the distance between adjacent points.
*   $c(t_i)$ and $\sigma(t_i)$ are the color and density at point $t_i$ produced by $F_\Theta$.
*   $T(t_i) = \exp\left(-\sum_{j=1}^{i-1} \sigma(t_j)\delta_j\right)$ is the accumulated transmittance.

**Depth Rendering:**
The rendered depth $D_f(o_s)$ (fine) and $D_c(o_s)$ (coarse) are computed by accumulating density $\sigma$ from ray batches during volume rendering [S1, unofficial].

**Color-Guiding Loss:**
The total color loss $L_{color}(\Theta)$ is the sum of the all-view color loss $L_{all\_color}(\Theta)$ and the outside-view color loss $L_{out\_color}(\Theta)$ [S1, unofficial]:
$$ L_{color}(\Theta) = L_{all\_color}(\Theta) + L_{out\_color}(\Theta) $$

Where:
$$ L_{all\_color}(\Theta) = \sum_{o \in O_{all}} \| F_{\Theta_{image}}(o) - I_o^G \|_2^2 $$
$$ L_{out\_color}(\Theta) = \sum_{o \in O_{out}} \| (F_{\Theta_{image}}(o) - I_o^G) \odot M_o \|_2^2 $$
Note: In the main framework, $O_{all} = \{o_u\}$ and $O_{out} = O$. $I_o^G$ is the guiding image for view $o$ [S1, unofficial].

**Depth-Guiding Loss:**
The depth loss $L_{depth}(\Theta)$ measures the L2 distance between rendered fine/coarse depth images and guiding depth $D_G(o_s)$ for sampled camera positions $o_s \in O$ [S1, unofficial]:
$$ L_{depth}(\Theta) = \sum_{o_s \in O} \left( \| D_f(o_s) - D_G(o_s) \|_2^2 + \| D_c(o_s) - D_G(o_s) \|_2^2 \right) $$

**Total Optimization Objective:**
$$ \tilde{\Theta} := \arg \min_{\Theta} \left( L_{color}(\Theta) + L_{depth}(\Theta) \right) $$

### Pseudocode

```python
def nerf_in_inpainting(pretrained_nerf, user_view_o_u, user_mask_M_u, trajectory_O):
    """
    Optimizes a pre-trained NeRF to remove an object specified by a mask.
    
    Args:
        pretrained_nerf: F_Theta, the pre-trained NeRF model.
        user_view_o_u: Camera position for the user-chosen view.
        user_mask_M_u: Binary mask on the rendered image of o_u (1=keep, 0=remove).
        trajectory_O: List of K camera positions {o_s} for sampling.
        
    Returns:
        optimized_nerf: F_Tilde_Theta, the updated NeRF model.
    """
    
    # 1. Initialize parameters
    Theta = pretrained_nerf.parameters
    
    # 2. Sample views and render initial data
    K = len(trajectory_O)
    rendered_images = []
    rendered_depths = []
    transferred_masks = []
    
    for o_s in trajectory_O:
        # Render RGB and Depth from current NeRF
        I_s = render_image(pretrained_nerf, o_s)
        D_s = render_depth(pretrained_nerf, o_s)
        rendered_images.append(I_s)
        rendered_depths.append(D_s)
        
        # Transfer mask using video object segmentation (e.g., STCN)
        # M_s covers the same object as M_u in view o_s
        M_s = transfer_mask(user_mask_M_u, user_view_o_u, o_s, method="STCN")
        transferred_masks.append(M_s)
        
    # 3. Generate Guiding Materials
    guiding_colors = []
    guiding_depths = []
    
    for s in range(K):
        I_s = rendered_images[s]
        M_s = transferred_masks[s]
        
        # Generate guiding color using image inpainting (e.g., MST)
        I_s_G = inpaint_color(I_s, M_s, method="MST")
        guiding_colors.append(I_s_G)
        
        # Generate guiding depth using depth completion (e.g., Fast Bilateral Solver)
        D_s_G = complete_depth(rendered_depths[s], M_s, I_s_G, method="BilateralSolver")
        guiding_depths.append(D_s_G)
        
    # 4. Define View Sets
    O_all = [user_view_o_u]
    O_out = trajectory_O
    
    # 5. Optimization Loop
    optimizer = Adam(Theta, lr=0.001) # Typical Adam settings
    num_steps = 50000
    
    for step in range(num_steps):
        optimizer.zero_grad()
        
        total_loss = 0.0
        
        # Compute Color Loss
        # L_all_color: Only on user-chosen view
        I_u_rendered = render_image_from_params(Theta, user_view_o_u)
        I_u_G = guiding_colors[0] # Assuming user view is part of guidance or handled separately
        # Note: Source defines I_o^G for o in O_all. For o_u, I_u^G is the inpainted user view.
        # If user view is not in trajectory_O, it must be generated separately.
        # Based on source: O_all = {o_u}. So we need I_u^G.
        # Let's assume I_u_G is available from inpainting the user view.
        loss_all_color = sum_squared_error(I_u_rendered, I_u_G)
        
        # L_out_color: On all sampled views O_out
        loss_out_color = 0.0
        for s, o_s in enumerate(O_out):
            I_s_rendered = render_image_from_params(Theta, o_s)
            I_s_G = guiding_colors[s]
            M_s = transferred_masks[s]
            # Masked MSE
            diff = I_s_rendered - I_s_G
            masked_diff = diff * M_s # Element-wise multiplication
            loss_out_color += sum_squared_error(masked_diff, 0)
            
        loss_color = loss_all_color + loss_out_color
        
        # Compute Depth Loss
        loss_depth = 0.0
        for s, o_s in enumerate(O_out):
            D_f_s = render_fine_depth_from_params(Theta, o_s)
            D_c_s = render_coarse_depth_from_params(Theta, o_s)
            D_G_s = guiding_depths[s]
            
            loss_depth += sum_squared_error(D_f_s, D_G_s)
            loss_depth += sum_squared_error(D_c_s, D_G_s)
            
        total_loss = loss_color + loss_depth
        total_loss.backward()
        optimizer.step()
        
    return NeRF(Theta)

def sum_squared_error(pred, target):
    return torch.mean((pred - target) ** 2)
```

### Parameters
*   **K:** Number of sampled camera positions. Not given in the sources.
*   **Batch size:** 4,096 [S1, unofficial].
*   **Sample points (Fine):** 128 [S1, unofficial].
*   **Sample points (Coarse):** 64 [S1, unofficial].
*   **Optimizer:** Adam [S1, unofficial].
*   **Training Steps:** 50,000 steps for inpainting optimization [S1, unofficial].
*   **Hardware:** Intel i7-7800X CPU and GTX-1080 GPU [S1, unofficial].

### Edge Cases and Pitfalls
*   **Masked MSE Only:** Optimizing only with masked Mean Squared Error (MSE) on transferred masks without explicit guidance causes the unwanted object to remain in the result [S1, unofficial].
*   **Depth Loss Only:** Using only the depth-guiding loss ($L_{depth}$) introduces color noise outside the masked region and loses color information in flat regions [S1, unofficial].
*   **Multiple Color Guidance:** Using multiple inpainted images as color guidance introduces visual inconsistency between views. The method restricts color guidance to the user-chosen view only to maintain stability [S1, unofficial].
*   **Guidance Artifacts:** If the initial guidance materials (from inpainting/depth completion) contain artifacts, the optimized NeRF may output undesired results [S1, unofficial].

## Operating characteristics

*   **Time Complexity:** The optimization takes approximately 5 hours per scene on the specified hardware (Intel i7-7800X, GTX-1080) for 50,000 steps [S1, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:**
    *   Does not require category-specific training data or procedures [S1, unofficial].
    *   Ensures multi-view consistency by optimizing the NeRF parameters jointly across views [S1, unofficial].
    *   Produces visually plausible inpainted results that resemble ground truth in different views [S1, unofficial].
*   **Limitations:**
    *   Relies on the quality of external image inpainting and depth completion methods [S1, unofficial].
    *   May fail if the initial guidance contains significant artifacts [S1, unofficial].
    *   Baseline methods (per-view color updating or masked MSE retraining) result in incorrect depth maps, visual inconsistencies, or loss of fine structures [S1, unofficial].
*   **When to use:** When removing unwanted objects from a pre-trained NeRF without access to category-specific training data or the ability to retrain from scratch.
*   **When not to use:** When high-quality, artifact-free 2D inpainting and depth completion are not available, or when real-time editing is required.

## Background

*   **Origin:** The method was introduced by Hao-Kang Liu, I-Chao Shen, and Bing-Yu Chen in the paper "NeRF-In: Free-Form NeRF Inpainting with RGB-D Priors" [S1, unofficial].
*   **Date:** June 10, 2022 (arXiv:2206.04901v1) [S1, unofficial].
*   **History:** It is the first framework to enable free-form object removal from a pre-trained NeRF without category-specific data. Previous methods required learning additional category-level conditional radiance fields or segmentation networks [S1, unofficial].
*   **Usage:** Implemented in PyTorch and Python 3.9. Evaluated on the LLFF dataset and a custom dataset with 24 camera positions per scene [S1, unofficial].
