# NeRF-In Inpainting Optimization

Also called: Free-Form NeRF Inpainting with RGB-D Priors, NeRF object removal, NeRF-In

## Overview
NeRF-In is a method for removing unwanted objects from a 3D scene represented by a pre-trained Neural Radiance Field (NeRF) without requiring category-specific training data or retraining the model from scratch [S1, unofficial]. It solves the problem of visual inconsistency and geometric artifacts that arise when editing NeRFs by jointly optimizing color and depth guidance derived from 2D inpainting priors. Unlike sibling methods that may rely on semantic segmentation or reference images, NeRF-In uses free-form user masks and external 2D inpainting/depth completion tools to guide the optimization of the NeRF parameters $\Theta$ [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
1.  Pre-trained NeRF model $F_\Theta$ mapping $(\mathbf{x}, \mathbf{d}) \to (\sigma, \mathbf{c})$ [S1, unofficial].
2.  User-chosen camera position $\mathbf{o}_u$ and corresponding rendered image $I_u = F_{\Theta_{image}}(\mathbf{o}_u)$ [S1, unofficial].
3.  User-drawn binary mask $M_u$ on $I_u$, where $M_u(\mathbf{p}) = 1$ for pixels outside the masked region (background/valid) and $M_u(\mathbf{p}) = 0$ for pixels inside the masked region (object to remove) [S1, unofficial].
4.  A pre-set trajectory of camera positions $\mathcal{O} = \{\mathbf{o}_s \mid s = 1 \dots K\}$ (e.g., LLFF test-set trajectory) [S1, unofficial].

**Outputs:**
1.  Updated NeRF parameters $\tilde{\Theta}$ [S1, unofficial].
2.  Rendered images and depth maps from $\tilde{\Theta}$ showing the removed object [S1, unofficial].

### Data Structures
*   **NeRF Model $F_\Theta$**: Standard MLP-based NeRF representation. Parameters $\Theta$ include weights and biases.
*   **Ray Batch $\mathcal{R}$**: A set of camera rays $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ sampled for volume rendering.
*   **Masks**:
    *   $M_u$: User mask on view $\mathbf{o}_u$.
    *   $\mathcal{M} = \{M_s \mid s = 1 \dots K\}$: Transferred masks on sampled views $\mathbf{o}_s$.
*   **Guidance Data**:
    *   $I_u^G$: Guiding color image for the user view.
    *   $\mathcal{I}^G = \{I_s^G \mid s = 1 \dots K\}$: Guiding color images for sampled views.
    *   $\mathcal{D}^G = \{D_s^G \mid s = 1 \dots K\}$: Guiding depth images for sampled views.

### Numbered Steps

1.  **Initialize**: Load pre-trained NeRF $F_\Theta$. [S1, unofficial]
2.  **Sample Views**: Sample $K$ camera positions $\mathcal{O} = \{\mathbf{o}_s \mid s = 1 \dots K\}$ along a pre-set trajectory. [S1, unofficial]
3.  **Render Initial Views**: Render RGB images $I_s$ and depth images $D_s$ from $F_\Theta$ for all $\mathbf{o}_s \in \mathcal{O}$. [S1, unofficial]
4.  **Transfer Mask**: Transfer the user-drawn mask $M_u$ from view $\mathbf{o}_u$ to all sampled views $\mathbf{o}_s$ to generate transferred masks $\mathcal{M} = \{M_s\}$. This is done using a video object segmentation method (e.g., STCN) [S1, unofficial].
5.  **Generate Guidance**:
    *   For the user view $\mathbf{o}_u$, generate guiding color $I_u^G$ using an image inpainting method $\rho$ (e.g., MST inpainting network) on $I_u$ and $M_u$: $I_u^G = \rho(I_u, M_u)$ [S1, unofficial].
    *   For each sampled view $\mathbf{o}_s$, generate guiding color $I_s^G$ using $\rho$ on $I_s$ and $M_s$: $I_s^G = \rho(I_s, M_s)$ [S1, unofficial].
    *   For each sampled view $\mathbf{o}_s$, generate guiding depth $D_s^G$ using a depth completion method $\tau$ (e.g., Fast Bilateral Solver) on $D_s$, $M_s$, and $I_s^G$: $D_s^G = \tau(D_s, M_s, I_s^G)$ [S1, unofficial].
6.  **Define View Sets**:
    *   $\mathcal{O}_{all} = \{\mathbf{o}_u\}$ (User-chosen view).
    *   $\mathcal{O}_{out} = \mathcal{O}$ (All sampled views excluding the user view, or all other views). Note: The source defines $\mathcal{O}_{all} = \mathbf{o}_u$ and $\mathcal{O}_{out} = \mathcal{O}$ [S1, unofficial].
7.  **Optimize**: Update $\Theta$ to $\tilde{\Theta}$ by minimizing the total loss $L_{color}(\Theta) + L_{depth}(\Theta)$ using the Adam optimizer for 50,000 steps [S1, unofficial].

### Formulas

**Volume Rendering (Color):**
The expected color $\hat{C}(\mathbf{r})$ of a camera ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ is computed via numerical quadrature [S1, unofficial]:

$$
\hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T(t_i) (1 - \exp(-\sigma(t_i)\delta_i)) c(t_i)
$$

where:
*   $N$ is the number of quadrature points between near plane $t_n$ and far plane $t_f$.
*   $\delta_i = t_{i+1} - t_i$.
*   $c(t_i)$ and $\sigma(t_i)$ are the color and density at point $t_i$ produced by $F_\Theta$.
*   $T(t_i) = \exp\left(-\sum_{j=1}^{i-1} \sigma(t_j)\delta_j\right)$ is the accumulated transmittance.

**Depth Rendering:**
The rendered depth $D(\mathbf{o}_s)$ is computed by accumulating density $\sigma$ from ray batches during volume rendering [S1, unofficial]. Specifically, $D_f(\mathbf{o}_s)$ is the fine volume predicted depth and $D_c(\mathbf{o}_s)$ is the coarse volume predicted depth.

**Color-Guiding Loss:**
The total color loss is the sum of the all-view color loss and the outside-view color loss [S1, unofficial]:

$$
L_{color}(\Theta) = L_{all}^{color}(\Theta) + L_{out}^{color}(\Theta)
$$

Where:
$$
L_{all}^{color}(\Theta) = \sum_{\mathbf{o} \in \mathcal{O}_{all}} \| F_{\Theta_{image}}(\mathbf{o}) - I_u^G \|_2^2
$$

$$
L_{out}^{color}(\Theta) = \sum_{\mathbf{o} \in \mathcal{O}_{out}} \| (F_{\Theta_{image}}(\mathbf{o}) - I_s^G) \odot M_s \|_2^2
$$

Note: The source specifies $L_{all}^{color}$ uses the user view $\mathbf{o}_u$ and guidance $I_u^G$. $L_{out}^{color}$ uses the sampled views $\mathcal{O}$ and their respective guidance $I_s^G$ masked by $M_s$. The source equation (10) shows the mask $M_o$ applied to the difference. Since $M_s=0$ inside the object, this term penalizes the *outside* region to preserve background consistency, while the object region is guided by the depth loss and the implicit structure of the NeRF update. However, the text states $L_{all}^{color}$ measures color difference of the *entire* image on the rendered view. Let's stick to the explicit formulas provided:
$L_{all}^{color}(\Theta) = \sum_{\mathbf{o} \in \mathcal{O}_{all}} \| F_{\Theta_{image}}(\mathbf{o}) - I_u^G \|_2^2$ [S1, unofficial].
$L_{out}^{color}(\Theta) = \sum_{\mathbf{o} \in \mathcal{O}_{out}} \| (F_{\Theta_{image}}(\mathbf{o}) - I_s^G) M_s \|_2^2$ [S1, unofficial].

**Depth-Guiding Loss:**
Measures the L2 distance between rendered fine/coarse depth images and guiding depth $D_s^G$ [S1, unofficial]:

$$
L_{depth}(\Theta) = \sum_{\mathbf{o}_s \in \mathcal{O}} \left( \| D_f(\mathbf{o}_s) - D_s^G \|_2^2 + \| D_c(\mathbf{o}_s) - D_s^G \|_2^2 \right)
$$

**Total Optimization Objective:**
$$
\tilde{\Theta} := \arg \min_{\Theta} \left( L_{color}(\Theta) + L_{depth}(\Theta) \right)
$$ [S1, unofficial].

### Parameters
*   $K$: Number of sampled camera positions. Not given in the sources.
*   Batch size: 4,096 [S1, unofficial].
*   Sample points (fine model): 128 [S1, unofficial].
*   Sample points (coarse model): 64 [S1, unofficial].
*   Optimizer: Adam [S1, unofficial].
*   Optimization steps: 50,000 [S1, unofficial].
*   Hardware: Intel i7-7800X CPU, GTX-1080 GPU [S1, unofficial].

### Pseudocode

```python
import torch
import torch.nn as nn
import torch.optim as optim

def volume_render_color(ray_origins, ray_directions, near, far, nerf_model, num_samples):
    """
    Renders color using volume rendering integral.
    """
    t_vals = torch.linspace(0., 1., steps=num_samples)
    t_vals = near + (far - near) * t_vals
    z_vals = t_vals
    
    # Sample points along ray
    points = ray_origins.unsqueeze(1) + ray_directions.unsqueeze(1) * z_vals.unsqueeze(2)
    
    # Query NeRF for density and color
    # sigma: [batch, num_samples, 1], color: [batch, num_samples, 3]
    sigma, color = nerf_model(points)
    
    # Compute deltas
    deltas = z_vals[:, 1:] - z_vals[:, :-1]
    delta_inf = 1e10 * torch.ones_like(deltas[:, :1])
    deltas = torch.cat([deltas, delta_inf], dim=1)
    
    # Compute transmittance
    alpha = 1.0 - torch.exp(-torch.relu(sigma) * deltas)
    T = torch.cumprod(torch.exp(-sigma * deltas), dim=1)
    T = torch.cat([torch.ones_like(T[:, :1]), T[:, :-1]], dim=1)
    
    # Weighted sum
    weights = alpha * T
    color_rendered = torch.sum(weights.unsqueeze(-1) * color, dim=1)
    
    return color_rendered

def volume_render_depth(ray_origins, ray_directions, near, far, nerf_model, num_samples):
    """
    Renders depth by accumulating density-weighted distances.
    """
    t_vals = torch.linspace(0., 1., steps=num_samples)
    t_vals = near + (far - near) * t_vals
    z_vals = t_vals
    
    points = ray_origins.unsqueeze(1) + ray_directions.unsqueeze(1) * z_vals.unsqueeze(2)
    sigma, _ = nerf_model(points)
    
    deltas = z_vals[:, 1:] - z_vals[:, :-1]
    delta_inf = 1e10 * torch.ones_like(deltas[:, :1])
    deltas = torch.cat([deltas, delta_inf], dim=1)
    
    alpha = 1.0 - torch.exp(-torch.relu(sigma) * deltas)
    T = torch.cumprod(torch.exp(-sigma * deltas), dim=1)
    T = torch.cat([torch.ones_like(T[:, :1]), T[:, :-1]], dim=1)
    
    weights = alpha * T
    # Depth is the weighted average of z_vals
    depth_rendered = torch.sum(weights * z_vals, dim=1)
    
    return depth_rendered

def nerf_in_optimization(nerf_model, user_view_o_u, user_image_I_u, user_mask_M_u, 
                         sampled_views_O, guidance_color_rho, guidance_depth_tau, 
                         num_steps=50000, batch_size=4096):
    """
    Optimizes NeRF parameters to remove object defined by user_mask_M_u.
    """
    optimizer = optim.Adam(nerf_model.parameters(), lr=0.0005) # Typical NeRF lr, not specified in S1, using [G]
    
    # Step 4: Transfer Mask
    # M_s = video_object_segmentation(M_u, I_u, I_s)
    # We assume a function `transfer_mask` exists which uses STCN [S1, unofficial]
    transferred_masks = {}
    for o_s in sampled_views:
        # Render initial view for segmentation input
        I_s = render_image(nerf_model, o_s)
        M_s = transfer_mask(M_u, I_u, I_s)
        transferred_masks[o_s] = M_s

    # Step 5: Generate Guidance
    # I_u^G = rho(I_u, M_u)
    I_u_G = guidance_color_rho(I_u, M_u)
    
    guidance_colors = {}
    guidance_depths = {}
    
    for o_s in sampled_views:
        I_s = render_image(nerf_model, o_s)
        M_s = transferred_masks[o_s]
        
        # I_s^G = rho(I_s, M_s)
        I_s_G = guidance_color_rho(I_s, M_s)
        guidance_colors[o_s] = I_s_G
        
        # D_s^G = tau(D_s, M_s, I_s_G)
        D_s = render_depth(nerf_model, o_s)
        D_s_G = guidance_depth_tau(D_s, M_s, I_s_G)
        guidance_depths[o_s] = D_s_G

    # Step 6: Define Sets
    O_all = [user_view_o_u]
    O_out = sampled_views

    # Step 7: Optimize
    for step in range(num_steps):
        optimizer.zero_grad()
        
        total_loss = 0.0
        
        # L_all_color: User view
        # L_all_color = || F(o_u) - I_u^G ||^2
        I_u_rendered = render_image(nerf_model, user_view_o_u)
        loss_all_color = torch.mean((I_u_rendered - I_u_G) ** 2)
        total_loss += loss_all_color
        
        # L_out_color: Sampled views, masked
        # L_out_color = sum || (F(o_s) - I_s^G) * M_s ||^2
        loss_out_color = 0.0
        for o_s in O_out:
            I_s_rendered = render_image(nerf_model, o_s)
            M_s = transferred_masks[o_s]
            # Masked MSE
            diff = (I_s_rendered - guidance_colors[o_s]) * M_s
            loss_out_color += torch.mean(diff ** 2)
        total_loss += loss_out_color
        
        # L_depth: Sampled views, fine and coarse
        # L_depth = sum (|| D_f - D_G ||^2 + || D_c - D_G ||^2)
        loss_depth = 0.0
        for o_s in O_out:
            # Render fine depth
            D_f = volume_render_depth(...) # Needs ray sampling logic
            # Render coarse depth (if separate coarse model exists, otherwise same)
            # S1 mentions coarse and fine models. Assuming standard NeRF with coarse/fine sampling.
            # For simplicity, we assume D_f and D_c are available from the model's forward pass
            # or separate coarse/fine networks.
            D_c = volume_render_depth_coarse(...) # Placeholder for coarse logic
            
            D_G = guidance_depths[o_s]
            loss_depth += torch.mean((D_f - D_G) ** 2)
            loss_depth += torch.mean((D_c - D_G) ** 2)
        total_loss += loss_depth
        
        total_loss.backward()
        optimizer.step()
        
    return nerf_model
```

### Edge Cases and Pitfalls
*   **Masked MSE Only**: Optimizing only with masked MSE on transferred masks without explicit guidance causes the unwanted object to remain in the result [S1, unofficial].
*   **Depth Loss Only**: Using only depth-guiding loss introduces color noise outside the masked region and loses color information in flat regions [S1, unofficial].
*   **Multiple Guidance Views**: Using multiple inpainted images as color guidance introduces visual inconsistency between views. The method restricts color guidance to the user-chosen view to maintain stability [S1, unofficial].
*   **Guidance Artifacts**: If the initial guidance materials (from $\rho$ and $\tau$) have artifacts, the optimized NeRF may output undesired results [S1, unofficial].

## Operating characteristics

*   **Time Complexity**: The optimization takes approximately 5 hours per scene on an Intel i7-7800X CPU and GTX-1080 GPU for 50,000 steps [S1, unofficial].
*   **Memory Complexity**: Depends on the NeRF model size and batch size (4,096 rays). Not given in the sources.
*   **Strengths**:
    *   No category-specific training data or procedure required [S1, unofficial].
    *   Preserves visual consistency across views by optimizing the NeRF parameters jointly [S1, unofficial].
    *   Correctly removes geometry and color of unwanted objects [S1, unofficial].
*   **Limitations**:
    *   Relies on the quality of external 2D inpainting and depth completion tools [S1, unofficial].
    *   May struggle with complex geometry if guidance is inaccurate [S1, unofficial].
    *   Baseline methods (per-view color updating, masked MSE retraining) show visual inconsistencies or loss of fine structures [S1, unofficial].
*   **When to use**: When removing unwanted objects from a pre-trained NeRF without access to category-specific data or the ability to retrain from scratch.
*   **When not to use**: When high-fidelity semantic editing is required without external guidance, or when the scene has extreme lighting changes that 2D inpainting cannot handle.

## Background

*   **Origin**: NeRF-In was introduced by Hao-Kang Liu, I-Chao Shen, and Bing-Yu Chen in 2022 [S1, unofficial].
*   **Paper**: "NeRF-In: Free-Form NeRF Inpainting with RGB-D Priors" (arXiv:2206.04901) [S1, unofficial].
*   **Development**: It addresses the unintuitive nature of editing pre-trained NeRFs by providing a framework that updates model parameters based on user masks and RGB-D priors. It builds on the concept of differentiable volume rendering and 2D inpainting techniques [S1, unofficial].
*   **Usage**: Evaluated on the LLFF dataset and a custom dataset with 24 camera positions per scene [S1, unofficial].
