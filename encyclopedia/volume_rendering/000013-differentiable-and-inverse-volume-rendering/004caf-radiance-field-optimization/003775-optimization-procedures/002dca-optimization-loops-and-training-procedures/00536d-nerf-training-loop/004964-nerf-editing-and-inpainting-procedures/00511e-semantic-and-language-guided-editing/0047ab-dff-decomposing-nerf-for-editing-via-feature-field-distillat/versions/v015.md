# DFF (Decomposing NeRF for Editing Via Feature Field Distillation)

Also called: Feature Field Distillation

## Overview
DFF enables 3D semantic segmentation and editable novel-view synthesis by distilling high-level semantic features from a pre-trained 2D teacher network (such as LSeg or DINO) into a neural radiance field [S1]. Unlike standard NeRFs, whose internal feature representations are entangled with low-level factors like color and spatial adjacency, DFF learns a dedicated feature field that allows for robust decomposition of scenes into semantic regions [S1]. This decomposition facilitates editing operations such as object deletion, extraction, and appearance modification while maintaining multi-view consistency, overcoming the inconsistencies often produced by 2D image inpainting baselines [S1].

## How it works
DFF extends the standard NeRF architecture by adding a feature output branch. The method involves two phases: initial training of the radiance field and subsequent fine-tuning with feature distillation.

### Inputs and Outputs
*   **Inputs:** A set of posed training images $I$, camera poses, and optionally a 2D teacher network (LSeg or DINO) and query modalities (text for LSeg, image patches for DINO).
*   **Outputs:** A radiance field $f_\theta$ mapping 3D coordinates $\mathbf{x}$ and viewing directions $\mathbf{d}$ to density $\sigma$, color $\mathbf{c}$, and semantic feature vector $\mathbf{f}$.

### Data Structures and Layouts
The neural radiance field consists of two Multi-Layer Perceptrons (MLPs) for hierarchical sampling (coarse and fine). The feature field is integrated as a branch of the fine MLP or as an independent network.

**Fine Radiance Field MLP Layout (Branch-based):**
*   **Input:** Concatenated positional encoding of $\mathbf{x}$ (length 10) and $\mathbf{d}$ (length 4).
*   **Hidden Layers:** 8 ReLU layers, each with 256 dimensions.
*   **Skip Connections:** Standard NeRF skip connections from input to layers 4 and 8.
*   **Output Heads (Linear layers following the 8th hidden layer):**
    1.  Density $\sigma$: 1 dimension.
    2.  Color $\mathbf{c}$: 3 dimensions (RGB).
    3.  Feature $\mathbf{f}$: $D$ dimensions (dimensionality depends on the teacher network, e.g., 256 for DINO, 512 for LSeg).

**Independent Feature Field MLP Layout (Alternative):**
*   **Structure:** 4 layers.
*   **Skip Connections:** A skip connection at the third layer if positional encoding is used.
*   **Positional Encoding:** Optional. Removing PE acts as a smoothness regularizer.

**Positional Encoding:**
*   Input coordinate $\mathbf{x}$ and skip connections: Length 10.
*   Viewing direction $\mathbf{d}$: Length 4.

### Training Procedure

**Phase 1: Radiance Field Training**
1.  Train the standard NeRF (density and color only) for 200,000 iterations.
2.  Use Adam optimizer with a linearly decaying learning rate from $5 \times 10^{-4}$ to $8 \times 10^{-5}$ [S1].
3.  Apply Gaussian noise to the density output during training [S1].
4.  Sample rays using stratified sampling for the coarse MLP (64 points) and importance sampling for the fine MLP (128 points) [S1].

**Phase 2: Feature Distillation (Fine-tuning)**
1.  **Teacher Encoding:** Encode each training image $I$ using the 2D teacher network to generate target feature maps $f_{img}(I, r)$ [S1].
2.  **Resizing:** Resize the target feature maps to match the original image resolution, as teacher networks typically output reduced-size features [S1].
3.  **Architecture Update:** Add the feature branch to the fine MLP (or initialize the independent feature MLP) [S1].
4.  **Optimization:** Fine-tune the network for 5,000 iterations using the combined loss $\mathcal{L}_p + \lambda \mathcal{L}_f$ [S1].
5.  **Hyperparameters:**
    *   Remove Gaussian noise from density [S1].
    *   Set learning rate to $1 \times 10^{-4}$ [S1].
    *   Use coarse sampling (64 points) for training the feature branch to ensure smoothness [S1].
    *   Use fine sampling (128 points) for final edited rendering [S1].

### Loss Functions
The total loss is a weighted sum of photometric loss $\mathcal{L}_p$ and feature loss $\mathcal{L}_f$:
$$ \mathcal{L} = \mathcal{L}_p + \lambda \mathcal{L}_f $$

**Photometric Loss ($\mathcal{L}_p$):**
Standard L1 or L2 loss between rendered color $\hat{C}$ and ground truth image color $C$ [S1].

**Feature Loss ($\mathcal{L}_f$):**
The feature loss minimizes the distance between the rendered feature field and the teacher's feature map. For a ray $r$, the rendered feature $\hat{\mathbf{f}}$ is computed via volume rendering:
$$ \hat{\mathbf{f}}(r) = \sum_{i=1}^{N} w_i \mathbf{f}_i $$
where $w_i$ are the volume rendering weights defined in the parent article, and $\mathbf{f}_i$ is the feature output of the fine MLP at sample point $i$ [S1]. The target feature $f_{img}(I, r)$ is the resized teacher feature at the corresponding pixel [S1].
$$ \mathcal{L}_f = \| \hat{\mathbf{f}}(r) - f_{img}(I, r) \|^2 $$
Note: Training uses only photometric and feature losses; no semantic label supervision is used [S1].

### Query and Decomposition
DFF supports two query modalities for decomposition:

**1. Text Query (LSeg-DFF):**
*   Encode the text label using the LSeg text encoder.
*   Compute the probability $p$ of a point belonging to the class using cosine similarity between the rendered feature $\hat{\mathbf{f}}$ and the encoded text feature [S1].
*   Equation 22 in the source defines this probability calculation [S1].

**2. Image Patch Query (DINO-DFF):**
*   Select a query patch in a reference image.
*   Calculate the patch feature $\mathbf{f}_{patch}$ by averaging the DINO features of all pixels in the patch [S1].
*   Compute the probability $p$ using thresholded cosine similarity between $\hat{\mathbf{f}}$ and $\mathbf{f}_{patch}$ [S1]:
    $$ p = \begin{cases} 1 & \text{if } \cos(\hat{\mathbf{f}}, \mathbf{f}_{patch}) > \tau \\ 0 & \text{otherwise} \end{cases} $$
    where $\tau$ is a threshold [S1]. This enables hard decomposition [S1].

### Smoothness Regularization
To achieve smooth volume decomposition and reduce high-frequency artifacts:
1.  **Coarse Sampling:** Training with coarse sampling (64 points) inherently introduces smoothness regularization [S1].
2.  **No-PE Feature Field:** Train an independent feature field MLP without positional encoding. This eliminates high-frequency spatial variations, promoting smooth volume decomposition [S1].

### Pseudocode

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class DFFNeRF(nn.Module):
    def __init__(self, use_independent_feature=False, use_pe_for_feature=True):
        super().__init__()
        # Standard NeRF Fine MLP
        self.fine_mlp = FineMLP() # 8 layers, 256 dims, ReLU
        self.use_independent_feature = use_independent_feature
        
        if use_independent_feature:
            # Independent Feature MLP: 4 layers, skip at 3rd if PE used
            self.feature_mlp = IndependentFeatureMLP(use_pe=use_pe_for_feature)
        else:
            # Branch from Fine MLP
            self.feature_head = nn.Linear(256, 256) # Assuming 256 dim features

    def forward(self, xyz, dirs):
        # 1. Encode inputs
        xyz_enc = positional_encoding(xyz, length=10)
        dirs_enc = positional_encoding(dirs, length=4)
        
        # 2. Fine MLP forward pass (standard NeRF)
        sigma, color, shared_features = self.fine_mlp(xyz_enc, dirs_enc)
        
        # 3. Feature Output
        if self.use_independent_feature:
            # Independent MLP takes raw xyz or encoded xyz depending on design
            # Source implies it's a separate network for feature field
            feature = self.feature_mlp(xyz_enc) 
        else:
            feature = self.feature_head(shared_features)
            
        return sigma, color, feature

class FineMLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.layers = nn.ModuleList([nn.Linear(256, 256) for _ in range(8)])
        self.relu = nn.ReLU()
        self.sigma_head = nn.Linear(256, 1)
        self.color_head = nn.Linear(256, 3)
        # Skip connections handled in forward

    def forward(self, xyz_enc, dirs_enc):
        # Concatenate xyz and dirs for first layer
        x = torch.cat([xyz_enc, dirs_enc], dim=-1)
        x = self.layers[0](x)
        
        # Layers 1-3
        for i in range(1, 4):
            x = self.layers[i](x)
            x = self.relu(x)
            
        # Skip connection 1
        x = torch.cat([x, xyz_enc], dim=-1)
        
        # Layers 4-7
        for i in range(4, 8):
            x = self.layers[i](x)
            x = self.relu(x)
            
        # Skip connection 2
        x = torch.cat([x, xyz_enc], dim=-1)
        
        sigma = self.sigma_head(x)
        color = self.color_head(x)
        # shared_features is the output of the 8th layer before heads
        # In standard NeRF, this is often the input to the heads.
        # Here we return the pre-head activation for the branch
        shared_features = x 
        
        return sigma, color, shared_features

class IndependentFeatureMLP(nn.Module):
    def __init__(self, use_pe=True):
        super().__init__()
        self.use_pe = use_pe
        self.layers = nn.ModuleList([nn.Linear(256, 256) for _ in range(4)])
        self.relu = nn.ReLU()
        
    def forward(self, xyz_enc):
        x = xyz_enc
        for i in range(4):
            x = self.layers[i](x)
            if i < 3: # ReLU after first 3 layers
                x = self.relu(x)
            if i == 2 and self.use_pe:
                # Skip connection at 3rd layer (index 2) to input
                x = torch.cat([x, xyz_enc], dim=-1)
        return x

def render_dff(rays, nerf_model, teacher_network, teacher_features_resized, lambda_f=1.0):
    """
    Renders a batch of rays and computes losses.
    """
    # 1. Sample points along rays (Coarse sampling for feature training)
    # Assume sample_points returns xyz, dirs, weights
    xyz, dirs, weights = sample_rays_coarse(rays) # 64 points
    
    # 2. Forward NeRF
    sigma, color, feature = nerf_model(xyz, dirs)
    
    # 3. Volume Rendering for Color
    # w_i = T_i * (1 - exp(-sigma_i * delta_i))
    # T_i = exp(-sum(sigma_j * delta_j))
    # C = sum(w_i * color_i)
    rendered_color = volume_render_color(sigma, color, weights)
    
    # 4. Volume Rendering for Feature
    rendered_feature = volume_render_feature(feature, weights)
    
    # 5. Get Target Feature
    # Map ray origin/direction to pixel coordinates to index into teacher_features_resized
    pixel_coords = ray_to_pixel(rays)
    target_feature = teacher_features_resized[pixel_coords]
    
    # 6. Compute Losses
    loss_p = F.l1_loss(rendered_color, rays.gt_color)
    loss_f = F.mse_loss(rendered_feature, target_feature)
    
    total_loss = loss_p + lambda_f * loss_f
    
    return total_loss, rendered_color, rendered_feature

def volume_render_color(sigma, color, weights):
    # weights are pre-computed based on sigma and delta
    return torch.sum(weights * color, dim=-2)

def volume_render_feature(feature, weights):
    return torch.sum(weights.unsqueeze(-1) * feature, dim=-2)
```

## Operating characteristics
*   **Time Complexity:** The fine-tuning phase is short (5,000 iterations) because the feature loss converges significantly faster than the photometric loss [S1].
*   **Memory Complexity:** Branch-based DFF adds minimal overhead compared to standard NeRF [S1]. Independent feature MLPs are lightweight (4 layers) [S1].
*   **Performance:** DFF achieves 3D semantic segmentation performance competitive with or better than supervised models like MinkowskiNet42 [S1].
*   **Strengths:**
    *   Enables multi-view consistent editing (deletion/extraction) unlike 2D inpainting methods like LaMa [S1].
    *   Robust decomposition; naive NeRF features leak to regions with similar color/geometry, but DFF features are semantically distinct [S1].
    *   Coarse sampling produces smooth segmentations, avoiding high-frequency artifacts [S1].
*   **Limitations:**
    *   Deleting foreground objects can leave floating artifacts and blurred volumes in the far distance behind the deleted object [S1].
    *   Excessively increasing the feature loss weight ($\lambda \times 10$) degrades view synthesis quality without improving segmentation [S1].
    *   Fine sampling introduces high-frequency artifacts in segmentation; coarse sampling is preferred for decomposition tasks [S1].

## Background
DFF was introduced in the paper "Decomposing NeRF for Editing Via Feature Field Distillation" [S1]. It addresses the challenges of editable NeRFs, specifically surface decomposition, volume decomposition, lighting decomposition, and estimation of unobserved parts [S1]. The method leverages pre-trained 2D teacher networks, LSeg [44] and DINO [12], to distill semantic knowledge into the 3D representation. It builds on the standard NeRF optimization procedures [S1].
