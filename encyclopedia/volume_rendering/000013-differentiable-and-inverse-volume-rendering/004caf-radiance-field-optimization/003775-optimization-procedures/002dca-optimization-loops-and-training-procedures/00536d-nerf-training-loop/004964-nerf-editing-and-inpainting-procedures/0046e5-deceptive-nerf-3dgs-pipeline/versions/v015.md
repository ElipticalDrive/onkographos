# Deceptive-NeRF/3DGS Pipeline

Also called: Deceptive-3DGS, Deceptive-NeRF

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that enhances NeRF or 3D Gaussian Splatting (3DGS) representations by continuously densifying input observations with synthetic pseudo-observations generated by a diffusion model during training [S1]. It distinguishes itself from sibling methods by explicitly enforcing 3D view consistency through an uncertainty map derived from epipolar reprojection of nearest input views, rather than relying on ensemble learning or variational inference [S1]. This approach allows the diffusion model to rectify artifacts and fill geometric gaps while maintaining photorealism and cross-view coherence [S1].

## How it works

### Inputs and Outputs
*   **Inputs:** A set of $W$ input images $I = \{I_1, \dots, I_W\}$ with calibrated camera poses. A pre-trained or partially trained NeRF/3DGS representation $f_\theta$. A pre-trained 2D latent diffusion model (e.g., Stable Diffusion) and a ControlNet architecture [S1].
*   **Outputs:** An optimized NeRF/3DGS representation $f_\theta$ and a set of accumulated pseudo-observations $P$ used for training.

### Data Structures and Layouts

**1. Camera Parameters**
*   $K$: $3 \times 3$ intrinsic camera matrix.
*   $R_{B \rightarrow A}$: $3 \times 3$ rotation matrix representing the viewpoint difference between the nearest input view $B$ and the novel view $A$.
*   $T_{B \rightarrow A}$: Translation vector (implied in the warping function $\psi$).

**2. Rendered Data at Novel View $A$**
*   $\hat{I}_A$: Rendered RGB image at view $A$.
*   $D_A$: Rendered depth map at view $A$.
*   $U_A$: Uncertainty map at view $A$.

**3. Diffusion Model Inputs (ControlNet)**
*   Control map: 5-channel tensor.
    *   Channels 0-2: Coarse RGB image ($I_{coarse}$).
    *   Channel 3: Depth map ($D$).
    *   Channel 4: Uncertainty map ($U$).
*   Text Embedding $s$: Concatenation of caption embedding $s_0$ and optimized latent embedding $s^*$.

**4. Training Dataset for Diffusion**
*   Quartets $(I_{fine}, I_{coarse}, D, U)$ or augmented pairs $(I_{noisy}, D)$ [S1].
*   Resolution: Randomly cropped to $512 \times 512$ pixels [S1].

### Numbered Steps

1.  **Initial Training:** Train the NeRF/3DGS representation $f_\theta$ using the few input images $I$ with calibrated poses for a set number of epochs to obtain a coarse reconstruction [S1].
2.  **View Sampling:** Randomly sample a novel viewpoint $A$ within the bounding box defined by the outermost input views [S1].
3.  **Rendering:** At view $A$, render the RGB image $\hat{I}_A$ and the depth map $D_A$ using $f_\theta$.
    *   Depth is computed as a weighted sum of distances traveled:
        $$ \hat{\mathbf{D}} = \sum_{k=1}^K \hat{T}(t_k)\alpha (\sigma (t_k)\delta_k) $$
        where $\hat{T}(t_k)$ is transmittance, $\alpha$ is opacity, $\sigma$ is density, and $\delta_k$ is the distance traveled at sample $k$ [S1].
4.  **Uncertainty Map Generation:**
    *   Identify the nearest input viewpoint $B$ to the novel view $A$.
    *   Warp the ground truth image $I_B$ to view $A$ using the rendered depth $D_A$ and the relative pose $R_{B \rightarrow A}$:
        $$ I_{B\rightarrow A} = \psi (I_B; D_A, R_{B\rightarrow A}) $$
    *   For each pixel $p$ in $\hat{I}_A$, compute the corresponding pixel location $q$ in $I_B$:
        $$ q = K R_{B\rightarrow A} D_A(p) K^{-1} p $$
    *   Compute the uncertainty map $U_A$ as the squared difference between the warped image and the rendered image:
        $$ U_A = (I_{B \rightarrow A} - \hat{I}_A)^2 $$
        [S1].
5.  **Text Embedding Derivation:**
    *   Generate an initial text prompt $s_0$ using a pre-trained image captioning network on the coarse image [S1].
    *   Optimize a shared latent text embedding $s^*$ using textual inversion, shared across all input observations and coarse images [S1].
    *   Form the composite text embedding $s = [s_0, s^*]$ by concatenating $s_0$ and $s^*$ [S1].
6.  **Pseudo-Observation Generation:**
    *   Feed $\hat{I}_A$, $D_A$, and $U_A$ into the Deceptive Diffusion Model $G$ (implemented via ControlNet) to generate the pseudo-observation $P_A$:
        $$ P_A = \operatorname {G}(\hat {I}_A, D_A, U_A) $$
        [S1].
7.  **Filtering:**
    *   Calculate the perceptual similarity between $P_A$ and the input images using the LPIPS metric [S1].
    *   Discard 20% of the accumulated pseudo-observations with the lowest perceptual similarity to input images [S1].
8.  **Optimization:**
    *   Update the NeRF/3DGS parameters $\theta$ using gradient descent (e.g., Adam) to minimize the reconstruction loss against the combination of real input images and the accumulated pseudo-observations [S1].
9.  **Iteration:**
    *   Repeat steps 2–8 until a sufficient number of pseudo-observations are accumulated or the training budget is exhausted [S1].

### Diffusion Model Fine-Tuning
To train the Deceptive Diffusion Model $G$, the following objective is minimized:
$$ \min _{\theta}\mathbb {E}_{z\sim \mathcal {E},t,\epsilon \sim \mathcal {N}(0,1)}\|\epsilon -\epsilon _{\theta }(z_t,t,c(I_{\text {coarse}},D,U,s))\|_2^2 $$
where:
*   $z \sim \mathcal{E}$ is the latent code from the VAE encoder.
*   $t \sim [1, 1000]$ is the diffusion time step.
*   $\epsilon$ is the noise sampled from $\mathcal{N}(0,1)$.
*   $\epsilon_\theta$ is the denoiser U-Net.
*   $c(I_{\text{coarse}}, D, U, s)$ is the embedding of the coarse RGB image, depth, uncertainty, and text embedding [S1].

### Parameters
*   **Discard Rate:** 20% of pseudo-observations are discarded based on LPIPS [S1].
*   **Gaussian Noise Std Dev:** 0.3, used for data augmentation on 60,000 Hypersim images [S1].
*   **ControlNet Channels:** 5 channels (3 RGB, 1 Depth, 1 Uncertainty) [S1].
*   **Image Resolution:** $512 \times 512$ [S1].
*   **Coarse NeRF Training Data:** Trained on one-fifth of the input images [S1].
*   **Training Dataset Size:** 200 scenes, ~20,000 images (Hypersim and CO3D each contribute half) [S1].

### Edge Cases and Pitfalls
*   **Captioning Efficacy:** Image captioning efficacy diminishes for low-quality images or those with pronounced artifacts. This is mitigated by optimizing the shared latent text embedding $s^*$ via textual inversion [S1].
*   **Augmentation Data:** When training the diffusion model with noisy RGB-depth data augmentation (where uncertainty maps are not available), uncertainty maps are not fed into the diffusion model [S1].
*   **Uncertainty Calculation:** The uncertainty map relies on the accuracy of the rendered depth $D_A$. If depth estimation is poor, the warping $I_{B \rightarrow A}$ may be inaccurate, leading to misleading uncertainty values [S1].

    # We implement this per pixel or vectorized

    p_hom = p @ K_inv.T # (H, W, 3)
    
    # Scale by depth

    # Apply rotation
    p_rot = p_scaled @ R_BA.T # (H, W, 3)
    
    # Project to pixel coords
    q_hom = p_rot @ K.T # (H, W, 3)
    q = q_hom[:, :, :2] / q_hom[:, :, 2:3] # (H, W, 2)

## Subtopics

### Deceptive Diffusion Model
A 2D latent diffusion model conditioned on coarse RGB, depth, and uncertainty maps, implemented via ControlNet to preserve pre-trained weights [S1]. It is chosen when high-fidelity pseudo-observations are needed to fill sparse-view gaps while maintaining 3D consistency [S1].

### Uncertainty Map via Reprojection
A method to generate view-consistency guidance by warping the nearest input view to the novel view using rendered depth and comparing it to the rendered RGB image [S1]. It is chosen over ensemble or variational methods to minimize additional computation and enforce epipolar constraints [S1].

## Operating characteristics

*   **Time Complexity:** The method adds significant overhead due to the iterative generation of pseudo-observations and the fine-tuning of the diffusion model. Each iteration involves rendering, warping, diffusion sampling, and NeRF optimization [S1].
*   **Memory Complexity:** Requires storing the NeRF/3DGS representation, the diffusion model weights, and the pool of pseudo-observations. The ControlNet architecture adds memory overhead for the additional conditioning branches [S1].
*   **Measured Performance:** On the LLFF dataset, Deceptive-NeRF achieves a PSNR of 19.87 (3-view), 21.75 (6-view), and 23.22 (9-view), outperforming PixelNeRF, MVSNeRF, and DietNeRF [S1]. Deceptive-3DGS achieves 19.95 (3-view), 23.73 (6-view), and 24.15 (9-view) [S1].
*   **Strengths:** Effectively densifies sparse views, reduces artifacts, and enforces 3D consistency through uncertainty-guided diffusion [S1].
*   **Limitations:** Computationally expensive due to the need for training coarse/fine NeRF duos or data augmentation. Performance may degrade if the initial coarse reconstruction is poor, affecting depth and uncertainty accuracy [S1].
*   **When to Use:** Sparse-view reconstruction tasks where high-quality novel view synthesis is required and computational resources allow for iterative diffusion-based densification [S1].
*   **When Not to Use:** Real-time applications or scenarios with very limited computational budgets [S1].

## Background

Deceptive-NeRF/3DGS was introduced by X. Liu et al. in the paper "Deceptive-NeRF/3DGS: Diffusion-Generated Pseudo-Observations for High-Quality Sparse-View Reconstruction" [S1]. The method leverages the power of 2D diffusion models to rectify 3D renderings, addressing the common issue of artifacts and missing details in sparse-view NeRF/3DGS reconstructions [S1]. It builds on the principles of differentiable volume rendering and inverse graphics, specifically focusing on optimization loops that incorporate external generative priors [S1].
