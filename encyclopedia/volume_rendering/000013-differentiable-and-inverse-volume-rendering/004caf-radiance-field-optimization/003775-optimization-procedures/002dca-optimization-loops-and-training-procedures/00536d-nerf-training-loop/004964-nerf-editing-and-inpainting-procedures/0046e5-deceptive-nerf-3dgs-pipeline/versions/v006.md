# Deceptive-NeRF/3DGS Pipeline

Also called: Deceptive-3DGS, Deceptive-NeRF

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that enhances NeRF or 3D Gaussian Splatting (3DGS) representations by continuously densifying input observations with synthetic pseudo-observations generated by a diffusion model during training [S1]. Unlike inference-time interception methods that apply static transforms, this approach optimizes the 3D representation parameters using guidance derived from 2D diffusion priors, specifically addressing the lack of geometric and photometric detail in few-shot scenarios [S1]. It distinguishes itself from other optimization-based editing procedures by introducing an uncertainty map derived from cross-view correspondence matching to enforce 3D consistency in the generated pseudo-observations, rather than relying on ensemble learning or variational inference [S1].

## How it works
The method operates in an iterative loop that alternates between generating pseudo-observations via a "deceptive" diffusion model and optimizing the 3D representation (NeRF or 3DGS) using both real input images and these synthetic views.

### Inputs and Outputs
*   **Inputs:** A set of $W$ input images $I = \{I_1, \dots, I_W\}$ with calibrated camera poses.
*   **Outputs:** An optimized 3D representation (NeRF or 3DGS) capable of high-quality novel view synthesis.

### Data Structures and Parameters
*   **Camera Parameters:** Intrinsic matrix $K$ and extrinsic poses.
*   **Diffusion Model State:** A fine-tuned Stable Diffusion model with ControlNet [S1].
    *   **Control Map Channels:** 5 channels total (3 for coarse RGB, 1 for depth, 1 for uncertainty) [S1].
    *   **Text Embedding:** A composite feature $s = [s_0, s^*]$ where $s_0$ is from a pre-trained image captioning network and $s^*$ is a shared latent text embedding optimized via textual inversion [S1].
*   **Training Dataset:** Constructed from 200 scenes (~20,000 images) from Hypersim and CO3D, plus data augmentation from 60,000 Hypersim images with added Gaussian noise ($\sigma=0.3$) [S1].
*   **Image Resolution:** All images are randomly cropped to $512 \times 512$ during diffusion training [S1].
*   **Discard Rate:** 20% of pseudo-observations with the lowest perceptual similarity (LPIPS) are discarded [S1].

### Numbered Steps

1.  **Initial Coarse Training:** Train a coarse NeRF/3DGS using only one-fifth of the input images $I$ [S1].
2.  **Novel View Sampling:** Randomly sample a novel viewpoint $A$ within the bounding box defined by the outermost input views [S1].
3.  **Rendering:** At viewpoint $A$, render:
    *   RGB image $\hat{I}_A$.
    *   Depth map $D_A$.
    *   Uncertainty map $U_A$ (see *Uncertainty Measure* below).
4.  **Pseudo-Observation Generation:** Generate a pseudo-observation $P_A$ using the deceptive diffusion model $G$:
    $$ P_A = G(\hat{I}_A, D_A, U_A) $$
    The model $G$ is conditioned on the coarse RGB, depth, uncertainty, and the composite text embedding $s$ [S1].
5.  **Filtering:** Calculate the perceptual similarity between $P_A$ and the input images using the LPIPS metric. Discard the bottom 20% of pseudo-observations with the lowest similarity to avoid generating content far from the original inputs [S1].
6.  **Optimization:** Update the NeRF/3DGS parameters $\Theta$ by minimizing the photometric loss between the rendered views and the combined set of real input images and accepted pseudo-observations [S1].
7.  **Iteration:** Repeat steps 2–6 until a sufficient number of pseudo-observations are accumulated [S1].

### Uncertainty Measure
To enforce view consistency, the method computes an uncertainty map $U_A$ for a novel view $A$ by warping the nearest input view $B$ to $A$ and comparing it to the rendered image $\hat{I}_A$.

1.  **Depth Rendering:** Compute the depth map $D_A$ at novel view $A$:
    $$ \hat{\mathbf{D}} = \sum_{k=1}^K \hat{T}(t_k)\alpha(\sigma(t_k)\delta_k) $$
    where $\hat{T}(t_k)$ is transmittance, $\alpha$ is opacity, $\sigma$ is density, and $\delta_k$ is the distance traveled [S1].
2.  **Warping:** Warp the ground truth image $I_B$ from the nearest input viewpoint $B$ to $A$ using the depth map $D_A$ and the viewpoint difference $R_{B \rightarrow A}$:
    $$ I_{B \rightarrow A} = \psi(I_B; D_A, R_{B \rightarrow A}) $$
    Each pixel $p$ in $\hat{I}_A$ is transformed to $q$ in $I_B$ as:
    $$ q = K R_{B \rightarrow A} D_A(p) K^{-1} p $$
    where $K$ is the camera parameter matrix [S1].
3.  **Uncertainty Calculation:** Define the uncertainty map $U_A$ as the squared difference between the warped image and the rendered image:
    $$ U_A = (I_{B \rightarrow A} - \hat{I}_A)^2 $$
    This measure enforces epipolar constraints and minimizes additional computation compared to ensemble or variational methods [S1].

### Deceptive Diffusion Model Training
The diffusion model $G$ is fine-tuned using a latent diffusion architecture with a denoiser U-Net $\epsilon_\theta$ and ControlNet [S1].

1.  **Text Embedding Derivation:**
    *   Generate a text prompt $s_0$ using a pre-trained image captioning network.
    *   Optimize a shared latent text embedding $s^*$ using textual inversion to counteract captioning errors on low-quality or artifact-heavy images [S1].
    *   Form composite feature $s = [s_0, s^*]$ [S1].
2.  **Dataset Construction:**
    *   **Primary Data:** Train "fine" and "coarse" NeRF duos for 200 scenes. Coarse NeRFs use 1/5 of images; fine NeRFs use all. Render quartets $(I_{fine}, I_{coarse}, D, U)$ [S1].
    *   **Augmentation Data:** Add Gaussian noise ($\sigma=0.3$) to 60,000 Hypersim RGB images. Pair noisy RGB and depth maps as inputs, and original RGB as targets. **Note:** Uncertainty maps are **not** fed into the diffusion model when training with this noisy augmentation data [S1].
3.  **Fine-Tuning Objective:** Minimize the denoising loss:
    $$ \min_{\theta}\mathbb{E}_{z\sim \mathcal{E},t,\epsilon \sim \mathcal{N}(0,1)}\|\epsilon -\epsilon_{\theta}(z_t,t,c(I_{\text{coarse}},D,U,s))\|_2^2 $$
    where $z \sim \mathcal{E}$ is the latent code, $t \sim [1, 1000]$ is the diffusion time step, $\epsilon$ is noise, and $c$ is the embedding of the coarse image, depth, uncertainty, and text embedding [S1].

## Subtopics

### Uncertainty Measure via Correspondence
A method to quantify view consistency by warping the nearest input view to a novel view using rendered depth, avoiding ensemble or variational inference overhead [S1].

### Deceptive Diffusion Model
A 2D diffusion model conditioned on coarse RGB, depth, and uncertainty maps to generate photorealistic pseudo-observations, fine-tuned with ControlNet [S1].

### Textual Inversion for Robust Conditioning
A technique to optimize a shared latent text embedding to complement pre-trained image captions, improving conditioning on low-quality or artifact-prone coarse renders [S1].

## Operating characteristics
*   **Time Complexity:** The method is computationally intensive due to the iterative generation of pseudo-observations and the fine-tuning of a large diffusion model. Each iteration requires rendering from the 3D model and running a diffusion sampling step [S1].
*   **Memory Complexity:** Requires storing the 3D representation, the diffusion model weights, and the accumulated pseudo-observations. The dataset construction phase requires significant storage for the 200 scenes and 20,000 images used for fine-tuning [S1].
*   **Performance:** On the LLFF dataset, Deceptive-NeRF achieves a PSNR of 19.87 (3-view) and 25.30 (9-view), while Deceptive-3DGS achieves 19.95 (3-view) and 25.34 (9-view), outperforming methods like PixelNeRF and DietNeRF [S1].
*   **Strengths:** Effectively densifies sparse inputs without requiring dense ground-truth data. The uncertainty map ensures 3D consistency in generated views. ControlNet allows fine-tuning without disrupting pre-trained diffusion priors [S1].
*   **Limitations:** Relies on the quality of the initial coarse reconstruction. Image captioning efficacy diminishes for low-quality images, requiring textual inversion. The method is specific to few-shot reconstruction and may not benefit dense-view scenarios as significantly [S1].
*   **When to Use:** Sparse-view novel view synthesis where input views are limited (e.g., 3-9 views) and high fidelity is required.
*   **When Not to Use:** Dense-view reconstruction where input data is already sufficient, or real-time inference is required without pre-training [S1].

## Background
Deceptive-NeRF/3DGS was introduced by Liu et al. in 2023 [S1]. The method addresses the challenge of sparse-view reconstruction by leveraging the power of 2D diffusion models to generate synthetic training data. It builds on the concept of using diffusion models for image editing and super-resolution, adapting it to the 3D domain by conditioning on rendered depth and uncertainty. The use of ControlNet allows for efficient fine-tuning of pre-trained diffusion models like Stable Diffusion [S1]. The method has been evaluated on synthetic (Hypersim) and real-world (ScanNet, LLFF, Mip-NeRF 360) datasets, demonstrating state-of-the-art performance in few-shot settings [S1].
