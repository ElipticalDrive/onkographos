# DFF (Decomposing NeRF for Editing Via Feature Field Distillation)
Also called: LSeg-DFF, DINO-DFF

## Overview
DFF enables 3D semantic segmentation and editable novel-view synthesis by distilling features from a pre-trained 2D teacher network (LSeg or DINO) into a neural radiance field [S1]. It solves the problem that standard NeRF feature spaces are entangled with low-level factors like color or spatial adjacency rather than semantic similarity, making naive decomposition unreliable [S1]. Unlike sibling methods that rely on diffusion priors or geometric consistency for inpainting, DFF specifically targets semantic decomposition via feature distillation, allowing for multi-view consistent editing such as object deletion or extraction [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of posed training images $I$, camera poses, and a pre-trained 2D teacher network (LSeg [S1] or DINO [S1]). For LSeg, text labels are provided; for DINO, image patch queries are used [S1].
*   **Outputs:** A radiance field $F_\Theta$ mapping 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$ to density $\sigma$, color $c$, and semantic feature vector $\mathbf{f}$ [S1].

**Data Structures:**
1.  **Radiance Field MLP:** An MLP with eight ReLU layers of 256 dimensions, followed by:
    *   A linear layer for density $\sigma$ [S1].
    *   Three linear layers for color $c$ [S1].
    *   Three linear layers for feature $\mathbf{f}$ [S1].
    *   *Note:* The feature branch shares layers with the radiance field in the "branch-based" configuration [S1].
2.  **Independent Feature Field MLP (Optional):** An alternative architecture where the feature field is a separate, lightweight MLP to avoid re-training the radiance field. It consists of four layers, with a skip connection at the third layer if positional encoding is used [S1].
3.  **Positional Encoding:**
    *   Input coordinate $\mathbf{x}$ and skip connection: Length 10 [S1].
    *   Viewing direction $\mathbf{d}$: Length 4 [S1].
4.  **Teacher Feature Maps:** 2D feature maps $f_{img}(I, r)$ generated by the teacher network, resized to the original image size to compensate for reduced resolution [S1].

**Training Phases:**
The method operates in two distinct phases [S1]:
1.  **Radiance Field Training:** Train the NeRF without a feature branch for 200,000 iterations using photometric loss $L_p$ [S1].
2.  **Feature Distillation (Finetuning):** Add the feature branch (or train the independent MLP) and finetune for 5,000 iterations using the composite loss $L_p + \lambda L_f$ [S1].

**Numbered Steps:**
1.  **Teacher Encoding:** Encode each training image $I$ using the teacher network's image encoder to generate target feature maps $f_{img}(I, r)$ [S1].
2.  **Resizing:** Resize the target feature maps to match the original image resolution [S1].
3.  **Ray Sampling:**
    *   Use hierarchical sampling with two MLPs [S1].
    *   **Coarse MLP:** Performs volume rendering with 64 points using stratified sampling [S1].
    *   **Fine MLP:** Works with importance sampling, totaling 192 points (64 coarse + 128 fine) [S1].
    *   *Note:* For training the feature field, use **coarse sampling** only [S1]. For edited rendering, use **fine sampling** [S1].
4.  **Feature Querying:**
    *   **LSeg-DFF:** Encode text labels using the LSeg text encoder. Calculate the probability $p$ of each point belonging to a label using Equation 22 from [S1] (softmax over negative queries).
    *   **DINO-DFF:** Use image patch queries. Calculate the patch feature by averaging features of all pixels in the patch. Compute probability $p$ using thresholded cosine similarity: set $p=1$ if similarity exceeds a threshold, else $p=0$ (hard decomposition) [S1].
5.  **Loss Calculation:** Compute the composite loss (see Formulas).
6.  **Optimization:** Update parameters $\Theta$ using Adam optimizer [S1].

**Formulas:**
*   **Composite Loss:**
    $$ L = L_p + \lambda L_f $$
    Where $L_p$ is the photometric loss and $L_f$ is the feature loss [S1].
*   **Feature Loss ($L_f$):**
    $$ L_f = \| \mathbf{f}_{rendered} - f_{img}(I, r) \|^2 $$
    Where $\mathbf{f}_{rendered}$ is the feature vector rendered from the NeRF and $f_{img}(I, r)$ is the resized teacher feature map [S1].
*   **LSeg Probability (Eq. 22 in [S1]):**
    $$ p = \text{softmax}(\dots) $$
    (Specific implementation details of Eq. 22 are not fully expanded in the provided notes, but it involves text encoder outputs and negative queries [S1]).

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:**
    *   Radiance Field Training: Linearly decaying from $5 \times 10^{-4}$ to $8 \times 10^{-5}$ [S1].
    *   Feature Distillation: Fixed at $1 \times 10^{-4}$ [S1].
*   **Iterations:** 200,000 for radiance field; 5,000 for feature distillation [S1].
*   **Feature Loss Weight ($\lambda$):** Default value not explicitly given, but increasing it by $\times 10$ is noted as harmful [S1].
*   **Gaussian Noise:** Applied to density during radiance field training; removed during feature distillation [S1].
*   **Batch Size:** 1,024 rays for Replica dataset; 2,048 rays for other datasets [S1].
*   **Image Resolution:** 320 × 240 for Replica; 1,008 × 756 for other datasets [S1].

**Pseudocode:**
```python
def train_dff(training_images, poses, teacher_network, teacher_type="LSeg"):
    # 1. Initialize Radiance Field MLP
    # 8 ReLU layers (256 dims), linear for density, 3 linear for color, 3 linear for feature
    radiance_mlp = init_mlp()
    
    # 2. Phase 1: Train Radiance Field (200k iterations)
    optimizer = Adam(lr=5e-4, decay_to=8e-5)
    for i in range(200000):
        rays = sample_rays(training_images, poses, batch_size=1024 if replica else 2048)
        # Coarse sampling: 64 points
        sigma_coarse, color_coarse = radiance_mlp.forward(rays, coarse=True)
        # Fine sampling: 128 additional points (192 total)
        sigma_fine, color_fine = radiance_mlp.forward(rays, coarse=False)
        
        # Render color
        rendered_color = volume_render(sigma_coarse, color_coarse, sigma_fine, color_fine)
        target_color = rays.target_color
        
        # Photometric Loss
        loss_p = mse(rendered_color, target_color)
        
        # Add Gaussian noise to density during this phase
        sigma_coarse_noisy = sigma_coarse + gaussian_noise()
        
        loss_p.backward()
        optimizer.step()
        optimizer.zero_grad()

    # 3. Phase 2: Feature Distillation (5k iterations)
    # Remove Gaussian noise, set LR to 1e-4
    optimizer.lr = 1e-4
    teacher_features = []
    for img in training_images:
        # Encode image with teacher (LSeg or DINO)
        raw_feat = teacher_network.encode(img)
        # Resize to original image size
        feat_resized = resize(raw_feat, img.size)
        teacher_features.append(feat_resized)

    for i in range(5000):
        rays = sample_rays(training_images, poses, batch_size=1024 if replica else 2048)
        
        # Use COARSE sampling for training feature branches
        sigma_coarse, color_coarse, feature_coarse = radiance_mlp.forward(rays, coarse=True)
        
        # Render feature (using coarse sampling)
        rendered_feature = volume_render_feature(sigma_coarse, feature_coarse)
        
        # Get target feature from teacher
        target_feature = teacher_features[rays.image_index]
        # Sample target feature at ray pixel coordinates
        target_feature_sampled = sample_at_pixel(target_feature, rays.uv)
        
        # Losses
        loss_p = mse(rendered_color, rays.target_color) # Color still needed
        loss_f = mse(rendered_feature, target_feature_sampled)
        
        # Composite Loss
        loss = loss_p + lambda_weight * loss_f
        
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()

    return radiance_mlp
```

**Subtopics:**
*   **Branch-based DFF:** The feature branch shares layers with the radiance field. It does not degrade view synthesis performance compared to NeRF without feature fields [S1].
*   **Independent Feature Field DFF:** Uses a separate, lightweight MLP for features. Useful for introducing DFF into arbitrary 3D scene representations (e.g., dynamic NeRFs, meshes) without re-training the radiance field [S1].
*   **LSeg-DFF:** Uses LSeg as the teacher. Enables zero-shot semantic segmentation using text queries [S1].
*   **DINO-DFF:** Uses DINO as the teacher. Enables query-based decomposition using image patch queries via thresholded cosine similarity [S1].

## Operating characteristics
*   **Time Complexity:** Training requires 200,000 iterations for the radiance field and 5,000 for feature distillation [S1]. Feature loss converges significantly faster than photometric loss [S1].
*   **Memory Complexity:** Adds a feature branch (3 linear layers) or an independent MLP (4 layers) to the standard NeRF architecture [S1].
*   **Measured Performance:** On the Replica dataset, DFF (taught by LSeg) achieves better 3D semantic segmentation performance (mIoU) than the supervised sparse 3D convolution-based model MinkowskiNet42 [S1].
*   **Strengths:**
    *   Enables multi-view consistent editing (deletion/extraction), unlike image inpainting baselines like LaMa which generate inconsistent views [S1].
    *   Coarse training produces smooth segmentations, avoiding high-frequency artifacts introduced by fine sampling [S1].
    *   Independent feature field allows editing pre-trained NeRFs without re-training [S1].
*   **Limitations:**
    *   Excessively increasing feature loss weight ($\lambda \times 10$) hurts view synthesis without improving segmentation [S1].
    *   Deleting foreground objects can leave floating artifacts and blurred volumes in the far distance behind the deleted object [S1].
    *   Naive use of NeRF's internal hidden layers (e.g., 8th layer) is not robust for decomposition; regions leak to similar colors/geometry [S1].
*   **When to use:** When semantic decomposition and multi-view consistent editing are required, and a 2D teacher network is available.
*   **When not to use:** When high-frequency geometric detail in the feature field is required (use fine sampling for radiance, but coarse for feature) or when computational resources for 200k iterations are unavailable.

## Background
DFF was introduced in the paper "Decomposing NeRF for Editing Via Feature Field Distillation" [S1]. It addresses the challenges of editable NeRFs, specifically surface decomposition, volume decomposition, lighting decomposition, and estimation of unobserved parts [S1]. The method leverages pre-trained 2D teacher networks (LSeg [S1] and DINO [S1]) to distill semantic information into the 3D radiance field, overcoming the limitation that standard NeRF features are entangled with low-level visual factors [S1].
