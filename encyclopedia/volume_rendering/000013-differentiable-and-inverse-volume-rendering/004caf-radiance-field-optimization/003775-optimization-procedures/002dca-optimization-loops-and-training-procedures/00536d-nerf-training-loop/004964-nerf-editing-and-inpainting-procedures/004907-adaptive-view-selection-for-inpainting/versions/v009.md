# Adaptive View Selection for Inpainting

Also called: 3D Inpainting Component, 3D Inpainting Component with Adaptive View Selection, Adaptive Weight Inpainting, Gradient-Based View Selection

## Overview
This method addresses the inconsistency of single-view 2D inpainting in 3D scenes by integrating a 2D appearance prior with multi-view geometric consistency [S1]. It distinguishes itself from pure optimization-based inpainting [12372-nerf-in-inpainting-optimization.md] by explicitly selecting training views based on texture richness (regional average gradients) to decide whether to rely on the 2D inpainter or supplementary information from other views [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A pre-trained NeRF model $F_\Theta(\mathbf{x}, \mathbf{v})$ producing coarse ($\hat{C}_c$) and fine ($\hat{C}_f$) color outputs; a set of input views with known masks $M$ identifying occluded regions; a 2D image inpainter (specifically LaMa [S1]) to generate appearance priors $C_l$ for occluded pixels; and ground truth colors $C(r)$ and depths $D(r)$ for non-occluded areas.
*   **Outputs:** An updated NeRF model $\Theta$ that renders consistent images where occluded areas are filled using a hybrid of 2D priors and multi-view data.

**Data Structures:**
*   **Ray Set $R$:** The set of rays cast from the camera through each pixel.
*   **Predicted Mask $\hat{P}(r)$:** A scalar value (0 or 1, or soft probability) indicating if ray $r$ passes through an occluded region. This is derived from an object segmentation network [S1].
*   **Sub-regions:** The occluded area in a view is divided into multiple sub-regions to evaluate local texture richness [S1].

**Numbered Steps:**
1.  **Initial Recovery:** Use the pretrained 2D inpainter (LaMa) to generate an initial color prior $C_l(r)$ for pixels corresponding to occluded rays $r$ in the input views [S1].
2.  **Sub-region Division:** Divide the occluded area in the current view into multiple sub-regions [S1].
3.  **Gradient Evaluation:** Calculate the average gradient for each sub-region in both the rendered NeRF output ($\nabla \hat{g}$) and the 2D inpainted prior ($\nabla g$) [S1].
4.  **Adaptive Weight Calculation:** Determine the adaptive weight $\lambda$ for the reconstruction loss based on the gradient comparison [S1]:
    $$
    \lambda = \begin{cases} 
    1 & \text{if } \nabla \hat{g} > \tau \cdot \nabla g \\
    0 & \text{if } \nabla \hat{g} \le \tau \cdot \nabla g 
    \end{cases}
    $$
    Here, $\tau$ is a threshold parameter [S1]. If the rendered gradient is sufficiently rich compared to the prior, the method trusts the NeRF's multi-view consistency ($\lambda=1$); otherwise, it relies more on the 2D prior ($\lambda=0$) [S1].
5.  **Loss Computation:** Compute the total reconstruction loss $L$ as a weighted sum of non-occluded loss $L_{NonOcc}$ and occluded loss $L_{Occ}$ [S1]:
    $$
    L = \lambda L_{NonOcc} + (1 - \lambda) L_{Occ}
    $$
    *   **Non-occluded Loss ($L_{NonOcc}$):** Constrains the NeRF to match ground truth colors in visible areas [S1]:
        $$
        L_{NonOcc} = \sum_{r \in R} (1 - \hat{P}(r)) \left[ \|\hat{C}_c(r) - C(r)\|_2^2 + \|\hat{C}_f(r) - C(r)\|_2^2 \right]
        $$
    *   **Occluded Loss ($L_{Occ}$):** Constrains the NeRF to match the 2D inpainted prior in occluded areas [S1]:
        $$
        L_{Occ} = \sum_{r \in R} \hat{P}(r) \left[ \|\hat{C}_c(r) - C_l(r)\|_2^2 + \|\hat{C}_f(r) - C_l(r)\|_2^2 \right]
        $$
6.  **Optimization:** Update NeRF parameters $\Theta$ using gradient descent on $L$. The method also jointly optimizes the segmentation network using region encoding, RGB, and depth losses to ensure multi-view consistency of the masks [S1].

**Parameters:**
*   $\tau$: Threshold for gradient comparison. Not given in the sources.
*   $\lambda_1, \lambda_2, \lambda_3$: Weights for the segmentation network losses (region encoding, RGB, depth). Not given in the sources.

**Pitfalls:**
*   **Uniform Strategy Misjudgment:** Applying a single strategy to the entire occluded area can fail if texture richness varies locally. The method mitigates this by evaluating sub-regions individually [S1].
*   **2D Inpainter Artifacts:** Single 2D inpainting ignores 3D consistency. Relying solely on $C_l(r)$ without the adaptive view selection mechanism leads to inconsistent 3D reconstructions [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the NeRF training iterations and the cost of the 2D inpainter (LaMa) per view. The sub-region gradient calculation adds minimal overhead.
*   **Memory Complexity:** Requires storing the NeRF model, segmentation network, and intermediate renderings for coarse and fine networks.
*   **Strengths:** Effectively reduces disturbing artifacts from 2D inpainters by leveraging multi-view consistency where texture is rich [S1].
*   **Limitations:** Relies on the quality of the 2D inpainter (LaMa) for areas with no multi-view support [S1]. Performance depends on the accuracy of the segmentation masks [S1].

## Background
Originated in the paper "3D Scene De-occlusion in Neural Radiance Fields: A Framework for Obstacle Removal and Realistic Inpainting" [S1]. It builds on NeRF [21] and LaMa [25] to solve the problem of object removal and inpainting in 3D scenes, addressing the lack of multi-view consistency in previous 2D-based approaches [S1].
