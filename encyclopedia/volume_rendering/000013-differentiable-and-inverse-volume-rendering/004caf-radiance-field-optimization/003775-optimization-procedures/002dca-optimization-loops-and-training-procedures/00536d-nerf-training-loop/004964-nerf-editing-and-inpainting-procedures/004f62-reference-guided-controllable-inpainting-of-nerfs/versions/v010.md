# Reference-guided Controllable Inpainting of NeRFs

Also called: Reference-guided Inpainting

## Overview
This method performs 3D inpainting on a pre-trained Neural Radiance Field (NeRF) using a single inpainted reference view to guide geometry and appearance, ensuring view consistency and generating view-dependent effects (VDEs) in novel views [S1]. It distinguishes itself from multi-view inpainting methods by requiring only one user-provided inpainted image, avoiding the view inconsistencies that arise when propagating information from multiple potentially conflicting sources, while still handling disocclusions in non-reference views [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** $n$ input images $\{I_i\}_{i=1}^n$, camera transform matrices $\{\Pi_i\}_{i=1}^n$, masks $\{M_i\}_{i=1}^n$ delineating unwanted regions, and a single inpainted reference view $I_r$ where $r \in \{1, \dots, n\}$ [S1].
*   **Outputs:** An optimized NeRF representation $f_\theta: (\mathbf{x}, \mathbf{d}) \to (\sigma, \mathbf{c})$ that renders the scene with the masked regions replaced by content consistent with $I_r$ [S1].

**Data Structures**
The NeRF is represented by a multi-layer perceptron (MLP) with parameters $\theta$. The rendering process uses standard volume rendering [Parent]. No additional explicit 3D data structures (like voxels) are required; geometry is implicitly defined by the MLP density $\sigma$ [S1].

**Algorithm Steps**
The optimization is divided into stages, with specific losses activated at different iteration counts $N_{depth}$, $N_{bilateral}$, and $N_{do}$ [S1].

1.  **Unmasked Supervision (Stage 1):**
    Optimize $f_\theta$ for $N_{depth}$ iterations using only the unmasked pixels. This allows the unmasked geometry and appearance to converge while keeping the masked region under-fit, facilitating later alteration [S1].
    The loss is:
    $$
    L_{rec}^{unmasked} = \mathbb{E}_{r \sim R_{unmasked}} \| \hat{C}(r) - C_{GT}(r) \|^2
    $$
    where $R_{unmasked}$ is the set of rays corresponding to pixels in $\{I_i (1 - M_i)\}_{i=1}^n$ and $C_{GT}(r)$ is the ground truth color [S1].

2.  **Geometry Supervision via Depth Estimation:**
    To provide geometric guidance for the masked region, a monocular depth estimator is used to predict the depth of the inpainted reference view $I_r$. This depth is back-projected to 3D positions. A disparity map is computed and aligned with the current NeRF scene. The masked region is supervised using a depth loss $L_{depth}^{masked}$ derived from this alignment [S1].
    *Note: The exact formula for $L_{depth}^{masked}$ is not provided in the sources, but it aligns the NeRF's estimated depth/disparity with the monocular estimate from $I_r$.*

3.  **View-Dependent Effects (VDEs) via Bilateral Solver:**
    To generate view-dependent effects in non-reference views, a view-substitution technique is applied. The method uses a bilateral solver to construct target colors $I_{br,t}$ for non-reference views based on the reference view. These target colors are used to compute the reconstruction loss for the masked region, $L_{rec}^{masked}$ [S1].
    *Note: The specific implementation of the bilateral solver and view-substitution is not detailed in the provided text, but it serves to propagate appearance with VDEs from the reference to other views.*

4.  **Disocclusion Handling:**
    For regions that are disoccluded in non-reference views (and thus not covered by the single reference view), image inpainters are used to guide both geometry and appearance. This is enforced via a loss term $L_{do}$ [S1].

**Total Loss Function**
The total loss $L$ combines the active terms:
$$
L = L_{rec}^{unmasked} + \gamma_{depth} L_{depth}^{masked} + \gamma_{rec} L_{rec}^{masked} + \gamma_{do} L_{do}
$$
where $\gamma_{depth}$, $\gamma_{rec}$, and $\gamma_{do}$ are weighting coefficients [S1]. The losses $L_{depth}^{masked}$, $L_{rec}^{masked}$, and $L_{do}$ are computed every $N_{depth}$, $N_{bilateral}$, and $N_{do}$ iterations respectively, and are not utilized until those iteration counts are reached [S1].

**Pseudocode**
```python
def reference_guided_inpainting(
    images: List[Image], 
    cameras: List[Camera], 
    masks: List[Mask], 
    reference_view_idx: int,
    inpainted_reference_image: Image,
    depth_estimator: Model,
    bilateral_solver: Model,
    image_inpainter: Model,
    nerf_model: NeRF,
    n_depth: int,
    n_bilateral: int,
    n_do: int,
    gamma_depth: float,
    gamma_rec: float,
    gamma_do: float,
    optimizer: Optimizer
):
    """
    Optimizes a NeRF to inpaint masked regions using a single reference view.
    """
    n = len(images)
    
    # Pre-compute unmasked rays
    unmasked_rays = []
    for i in range(n):
        # Rays corresponding to pixels where mask is 0
        for pixel in get_unmasked_pixels(images[i], masks[i]):
            unmasked_rays.append(ray_from_pixel(cameras[i], pixel))
            
    # Pre-compute depth from reference view
    ref_depth_map = depth_estimator.predict(inpainted_reference_image)
    ref_3d_points = back_project(ref_depth_map, cameras[reference_view_idx])
    
    for iteration in range(max_iterations):
        optimizer.zero_grad()
        
        total_loss = 0.0
        
        # 1. Unmasked Supervision (Always active)
        rendered_colors_unmasked = []
        gt_colors_unmasked = []
        for ray in unmasked_rays:
            # Render color for this ray using current NeRF
            c_hat = volume_render(ray, nerf_model)
            # Get ground truth color from input image
            c_gt = get_gt_color(images[ray.camera_idx], ray.pixel)
            rendered_colors_unmasked.append(c_hat)
            gt_colors_unmasked.append(c_gt)
            
        l_rec_unmasked = mse(rendered_colors_unmasked, gt_colors_unmasked)
        total_loss += l_rec_unmasked
        
        # 2. Geometry Supervision (Active after n_depth iterations)
        if iteration >= n_depth:
            # Estimate depth from current NeRF for rays passing through masked regions
            # in the reference view or other views? 
            # Source says "align it with the current inpainted NeRF scene".
            # Assuming we supervise the masked area in the reference view first,
            # or generally in the scene based on the reference depth.
            # For simplicity, we compute depth loss for rays in the reference view
            # that fall within the mask.
            masked_rays_ref = get_masked_rays(cameras[reference_view_idx], masks[reference_view_idx])
            
            nerf_depths = []
            ref_depths = []
            for ray in masked_rays_ref:
                # Render depth (inverse of transmittance integral)
                d_hat = render_depth(ray, nerf_model)
                # Get corresponding depth from pre-computed ref depth map
                d_ref = get_depth_at_pixel(ref_depth_map, ray.pixel)
                nerf_depths.append(d_hat)
                ref_depths.append(d_ref)
                
            l_depth_masked = mse(nerf_depths, ref_depths)
            total_loss += gamma_depth * l_depth_masked
            
        # 3. View-Dependent Effects / Appearance Supervision (Active after n_bilateral iterations)
        if iteration >= n_bilateral:
            # Generate target colors for non-reference views using bilateral solver
            # This simulates VDEs from the reference view
            target_colors = {}
            for i in range(n):
                if i == reference_view_idx:
                    continue
                # Use bilateral solver to get inpainted color for masked region in view i
                # based on reference view and current NeRF state?
                # Source: "bilateral solver can construct view-dependent effects... 
                # enables a guided inpainting approach, propagating non-reference colours"
                # We assume the solver takes the reference view and current NeRF 
                # to produce a target image for the masked region in view i.
                target_colors[i] = bilateral_solver.compute_target(
                    inpainted_reference_image, 
                    images[i], 
                    masks[i],
                    nerf_model
                )
                
            l_rec_masked = 0.0
            count_masked = 0
            for i in range(n):
                masked_rays = get_masked_rays(cameras[i], masks[i])
                for ray in masked_rays:
                    c_hat = volume_render(ray, nerf_model)
                    c_target = get_color_from_image(target_colors[i], ray.pixel)
                    l_rec_masked += mse(c_hat, c_target)
                    count_masked += 1
            if count_masked > 0:
                l_rec_masked /= count_masked
                total_loss += gamma_rec * l_rec_masked
                
        # 4. Disocclusion Handling (Active after n_do iterations)
        if iteration >= n_do:
            # Identify disoccluded regions in non-reference views
            # Source: "non-reference disoccluded regions not supervised by the single reference view"
            # Use image inpainter to guide geometry and appearance
            l_do = 0.0
            count_do = 0
            for i in range(n):
                if i == reference_view_idx:
                    continue
                # Detect disocclusions (e.g., via depth consistency checks)
                disoccluded_pixels = detect_disocclusions(images[i], cameras[i], nerf_model)
                for pixel in disoccluded_pixels:
                    ray = ray_from_pixel(cameras[i], pixel)
                    c_hat = volume_render(ray, nerf_model)
                    # Get guidance from image inpainter
                    c_guide = image_inpainter.predict(images[i], masks[i], pixel)
                    l_do += mse(c_hat, c_guide)
                    count_do += 1
            if count_do > 0:
                l_do /= count_do
                total_loss += gamma_do * l_do
                
        total_loss.backward()
        optimizer.step()
```

**Parameters**
*   $N_{depth}$: Number of iterations for unmasked supervision before activating depth loss. Not given in the sources.
*   $N_{bilateral}$: Number of iterations before activating bilateral VDE loss. Not given in the sources.
*   $N_{do}$: Number of iterations before activating disocclusion loss. Not given in the sources.
*   $\gamma_{depth}, \gamma_{rec}, \gamma_{do}$: Loss weights. Not given in the sources.

**Edge Cases and Pitfalls**
*   **Disocclusions:** Regions visible in non-reference views but occluded in the reference view are not supervised by the reference depth or color. The method relies on image inpainters for these areas, which may lack 3D consistency if not handled carefully [S1].
*   **Under-fitting Masked Region:** The initial stage intentionally leaves the masked region under-fit. If $N_{depth}$ is too low, the unmasked geometry may not be stable enough to support the inpainting. If too high, the NeRF may overfit to the unmasked data, making it harder to alter the masked region later [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the number of optimization iterations and the cost of the external models (monocular depth estimator, bilateral solver, image inpainter). The bilateral solver and image inpainter are called periodically, not every iteration, reducing overhead [S1].
*   **Memory Complexity:** Standard NeRF memory usage plus temporary storage for depth maps and target images from the bilateral solver. No additional large 3D structures [S1].
*   **Strengths:** Avoids view inconsistencies by using a single reference view; generates view-dependent effects; handles disocclusions [S1].
*   **Limitations:** Relies on the quality of the single inpainted reference view; performance depends on the accuracy of the monocular depth estimator and image inpainter [S1].
*   **When to use:** When a user wants to inpaint a NeRF with a specific, user-controlled appearance provided by a single image, and view consistency is critical [S1].
*   **When not to use:** When multiple reference views are available and more robust multi-view consistency is needed; when high-fidelity VDEs are required but the reference view lacks sufficient detail [S1].

## Background
The method was introduced in "Reference-guided Controllable Inpainting of Neural Radiance Fields" (ICCV 2023) [S1]. It addresses the limitations of previous NeRF inpainting methods, which often suffered from view inconsistencies, lack of view-dependent effects, and poor handling of disocclusions [S1]. The approach builds on the standard NeRF rendering equation and integrates external guidance from a single inpainted view using monocular depth estimation and bilateral solvers [S1].
