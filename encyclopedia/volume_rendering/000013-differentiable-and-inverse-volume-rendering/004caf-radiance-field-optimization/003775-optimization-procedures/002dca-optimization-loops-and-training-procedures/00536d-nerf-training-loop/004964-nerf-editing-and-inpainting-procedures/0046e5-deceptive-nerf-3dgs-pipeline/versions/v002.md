# Deceptive-NeRF/3DGS Pipeline

Also called: Deceptive-3DGS, Deceptive-NeRF

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that enhances NeRF or 3D Gaussian Splatting (3DGS) representations by continuously densifying input observations with synthetic pseudo-observations generated by a diffusion model during training [S1]. It differs from sibling methods by explicitly enforcing 3D view consistency through an uncertainty map derived from epipolar reprojection of nearest input views, rather than relying on ensemble learning or variational inference [S1]. This approach allows the diffusion model to condition on geometric and consistency cues to rectify artifacts inherent in sparse-view renderings [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A set of $W$ input images $I = \{I_1, \dots, I_W\}$ with calibrated camera poses [S1].
*   A pre-trained 2D latent diffusion model (e.g., Stable Diffusion) [S1].
*   A pre-trained image captioning network [S1].

**Outputs:**
*   A refined NeRF or 3DGS representation optimized using both real input images and accumulated pseudo-observations [S1].

### Data Structures

**1. Camera Parameters**
*   $K$: $3 \times 3$ intrinsic camera matrix [S1].
*   $R_{B \rightarrow A}$: Rotation matrix representing the viewpoint difference between nearest input view $B$ and novel view $A$ [S1].

**2. Rendering Outputs at Novel View $A$**
*   $\hat{I}_A$: Rendered RGB image [S1].
*   $D_A$: Rendered depth map [S1].
*   $U_A$: Uncertainty map [S1].

**3. Pseudo-Observation**
*   $P_A$: Generated pseudo-observation image [S1].

**4. Diffusion Model Inputs (ControlNet Channels)**
*   Five-channel control map: 3 channels for coarse RGB image $I_{coarse}$, 1 channel for depth $D$, 1 channel for uncertainty $U$ [S1].

**5. Text Embedding**
*   $s_0$: Text prompt generated by captioning network [S1].
*   $s^*$: Shared latent text embedding optimized via textual inversion [S1].
*   $s$: Composite feature $[s_0, s^*]$ [S1].

### Numbered Steps

1.  **Initial Training:** Train a base NeRF or 3DGS model using the few input images $I$ with calibrated poses [S1].
2.  **Coarse Reconstruction:** After a set number of epochs, obtain a coarse reconstruction [S1].
3.  **Novel View Sampling:** Randomly sample novel views within a bounding box defined by the outermost input views [S1].
4.  **Rendering:** At a novel viewpoint $A$, render the RGB image $\hat{I}_A$, depth map $D_A$, and uncertainty map $U_A$ [S1].
5.  **Uncertainty Map Generation:**
    *   Identify $B$, the nearest input viewpoint to novel view $A$ [S1].
    *   Compute the warped image $I_{B \rightarrow A}$ by projecting $I_B$ to view $A$ using $D_A$ and $R_{B \rightarrow A}$ [S1].
    *   Calculate pixel transformation: $q = K R_{B \rightarrow A} D_A(p) K^{-1} p$, where $p$ is the pixel location in $\hat{I}_A$ and $q$ is the transformed location in $I_B$ [S1].
    *   Compute uncertainty: $U_A = (I_{B \rightarrow A} - \hat{I}_A)^2$ [S1].
6.  **Pseudo-Observation Generation:** Generate pseudo-observation $P_A$ using the deceptive diffusion model $G$ conditioned on $\hat{I}_A$, $D_A$, and $U_A$: $P_A = G(\hat{I}_A, D_A, U_A)$ [S1].
7.  **Filtering:** Discard 20% of the generated pseudo-observations that have the lowest perceptual similarity to input images, quantified via the LPIPS metric [S1].
8.  **Accumulation:** Add the valid pseudo-observations to the training dataset [S1].
9.  **Optimization:** Continue training the NeRF/3DGS representation using the combination of real input images and accumulated pseudo-observations [S1].
10. **Iteration:** Repeat steps 3–9 until a sufficient number of observations are accumulated [S1].

### Formulas

**Depth Rendering:**
The depth value for each ray is computed as a weighted composition of distances traveled:
$$
\hat{\mathbf{D}} = \sum_{k=1}^K \hat{T}(t_k)\alpha (\sigma (t_k)\delta _k)
$$
where $\hat{T}(t_k)$ is transmittance, $\alpha$ is opacity, $\sigma$ is density, and $\delta_k$ is the distance traveled [S1].

**Warped Image:**
The ground truth image $I_B$ from the nearest input view $B$ is warped to novel view $A$:
$$
I_{B\rightarrow A} = \psi (I_B; D_A, R_{B\rightarrow A})
$$
where $R_{B\rightarrow A}$ is the viewpoint difference [S1].

**Uncertainty Map:**
Defined as the squared distance between the warped image and the rendered image:
$$
U_A = (I_{B \rightarrow A} - \hat {I}_A)^2
$$
[ S1 ]

**Pseudo-Observation Generation:**
$$
P_A = \operatorname {G}(\hat {I}_A, D_A, U_A)
$$
where $G$ is the deceptive diffusion model [S1].

**Diffusion Fine-Tuning Objective:**
The diffusion model is fine-tuned by solving:
$$
\min _{\theta}\mathbb {E}_{z\sim \mathcal {E},t,\epsilon \sim \mathcal {N}(0,1)}\|\epsilon -\epsilon _{\theta }(z_t,t,c(I_{\text {coarse}},D,U,s))\|_2^2
$$
where $z \sim \mathcal{E}$ is the latent code, $t \sim [1, 1000]$ is the diffusion time step, $\epsilon$ is noise, $\epsilon_\theta$ is the denoiser U-Net, and $c$ is the embedding of the coarse RGB image, depth, uncertainty, and text embedding $s$ [S1].

**Text Embedding Derivation:**
1.  Generate text prompt $s_0$ using a pre-trained image captioning network [S1].
2.  Optimize a shared latent text embedding $s^*$ shared by all input observations and coarse images using textual inversion [S1].
3.  Form composite feature $s = [s_0, s^*]$ by concatenating embeddings [S1].

### Parameters

*   **Discard Rate:** 20% of pseudo-observations with the lowest perceptual similarity are discarded [S1].
*   **LPIPS Metric:** Used to quantify perceptual similarity for filtering [S1].
*   **ControlNet:** Used to implement the training paradigm while preserving pre-trained 2D diffusion model weights [S1].
*   **Gaussian Noise Standard Deviation:** 0.3, added to 60,000 images from Hypersim for data augmentation [S1].
*   **Control Map Channels:** Five channels (3 for coarse RGB, 1 for depth, 1 for uncertainty) [S1].
*   **Image Resolution:** All images are randomly cropped to $512 \times 512$ resolution [S1].
*   **Training Dataset Size:** 200 scenes and approximately 20,000 images (Hypersim and CO3D each contributing half) for the major training stage [S1].
*   **Coarse NeRF Training Data:** Coarse NeRFs are trained using only one-fifth of the input images [S1].

### Edge Cases and Pitfalls

*   **Captioning Efficacy:** Image captioning efficacy diminishes for images of lower quality or those with pronounced artifacts. Textual inversion is used to optimize a shared latent text embedding $s^*$ to counteract this [S1].
*   **Noisy Data Augmentation:** When training with noisy RGB-depth data augmentation (adding Gaussian noise to RGB images), uncertainty maps are not fed into the diffusion model [S1].
*   **Uncertainty Measure:** Unlike approaches using ensemble learning, variational inference, or spatial perturbations, this method acquires uncertainty through correspondence matching, minimizing additional computation while enforcing epipolar constraints [S1].

## Operating characteristics

*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** On the LLFF dataset, Deceptive-NeRF achieved a PSNR of 19.87 (3-view), 21.75 (6-view), and 23.22 (9-view). Deceptive-3DGS achieved a PSNR of 19.95 (3-view), 23.92 (6-view), and 24.15 (9-view) [S1].
*   **Strengths:** Enforces 3D consistency via epipolar constraints; utilizes natural image priors from diffusion models to ameliorate unnaturalness caused by sparse inputs; efficient uncertainty acquisition without modifying the underlying representation [S1].
*   **Limitations:** Requires iterative training loops; dependent on the quality of the initial coarse reconstruction and the pre-trained diffusion model [S1].
*   **When to Use:** Sparse-view novel view synthesis where input views are limited (e.g., 3–9 views) [S1].
*   **When Not to Use:** Not specified in the sources.

## Background

Deceptive-NeRF/3DGS was introduced by X. Liu et al. in the paper "Deceptive-NeRF/3DGS: Diffusion-Generated Pseudo-Observations for High-Quality Sparse-View Reconstruction" [S1]. The method leverages latent diffusion models (specifically Stable Diffusion with ControlNet) to generate pseudo-observations that densify sparse input data. It addresses the issue of artifacts in NeRF/3DGS reconstructions from few views by conditioning the diffusion model on rendered RGB, depth, and a novel uncertainty map derived from view consistency checks [S1]. The training dataset for the diffusion model combines synthetic data from NeRF duos (fine and coarse) on 200 scenes from Hypersim and CO3D, along with augmented noisy data from Hypersim [S1].
