# Progressive Inpainting-and-Erasing

Also called: Conflicted Geometry Detection and Erasing, Inpainting-and-Erasing Strategy, PERF, PERF Algorithm

## Overview
Progressive Inpainting-and-Erasing (PERF) is a training procedure for reconstructing a panoramic Neural Radiance Field (NeRF) from a single input panorama. It solves the problem of geometry conflict between visible regions (observed in the input) and invisible regions (occluded or unseen) by iteratively generating novel views, inpainting missing content, and erasing geometrically inconsistent pixels from the training supervision [S1]. It differs from standard NeRF training by actively synthesizing and refining missing geometry via 2D priors (Stable Diffusion) and explicitly masking out regions where the learned 3D geometry contradicts the multi-view consistency constraints [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A single RGB panorama image $I_{rgb}$ [S1].
*   **Output:** A trained panoramic NeRF function $f_{nerf}$ [S1].

**Data Structures:**
*   **NeRF Representation:** Instant-NGP [S1]. Uses a hash table of size $2^{19}$ with 16 levels of feature vectors, each of channel size 2 [S1].
*   **Reference Views Set:** $I_{ref}$, initialized with the input RGBD panorama [S1].
*   **Trajectory Set:** $\{p_k\}$, a set of novel view camera poses generated based on the initial depth map [S1].

**Parameters:**
*   $\epsilon$: A small threshold value for depth difference comparison [S1].
*   $iters$: Total number of progressive sampling iterations [S1].
*   Initial training iterations: 10,000 iterations for the single input panorama [S1].
*   New view sampling: 32 new positions with approximately gradually increased distance from the original position [S1].
*   Fine-tuning iterations per new view: 2,000 iterations total [S1].
    *   First 100 iterations: Supervision from only the new reference view [S1].
    *   Remaining 1,900 iterations: Supervision from all reference views [S1].
*   Optimizer: Adam [S1].
*   Learning rate: Initially $10^{-3}$, decayed to $10^{-4}$ using cosine annealing for each learning stage of a newly sampled view [S1].
*   Ray sampling: 2,048 rays sampled per iteration [S1].

**Steps:**

1.  **Initial Depth Estimation:** Estimate the initial depth map $I_d$ of the input single panorama $I_{rgb}$ using an external depth estimator (Eq. 2 in [S1]) to obtain the initial RGBD panorama $I_{rgbd}$ [S1].
2.  **Initial NeRF Training:** Train a single-view NeRF $f_{nerf}$ using $I_d$ and $I_{rgb}$ based on the standard volume rendering loss (Eq. 3 in [S1]) for 10,000 iterations [S1].
3.  **Trajectory Generation:** Generate a set of novel view trajectories $\{p_k\}$ based on the estimated depth map $I_d$ [S1].
4.  **Initialization:** Initialize the set of reference views $I_{ref} = \{I_{rgbd}\}$ [S1].
5.  **Progressive Loop:** Iterate $n$ from 1 to $iters$:
    a.  **Sample View:** Randomly sample a new camera view pose $p$ from $\{p_k\}$ [S1].
    b.  **Invisible Region Detection:** Compute the invisible regions mask $m'$ for the new view relative to the current NeRF geometry. This is done by warping depth from the new view to the reference view and identifying pixels where the warped depth is significantly larger than the reference depth, indicating occlusion or unseen space [S1].
        *   Formula: $m'_{ij} = \mathbb{I}(warp(v'_{ij}) - v_{ij} > \epsilon)$, where $v_{ij}$ is the reference depth, $v'_{ij}$ is the warped depth from the new view, and $\mathbb{I}(\cdot)$ is the indicator function [S1].
    c.  **Collaborative RGBD Inpainting:** Perform inpainting on the invisible regions of the new view. Use Stable Diffusion for RGB inpainting and a depth estimator for depth stitching (Eq. 5 in [S1]) to generate a completed panorama for the new view [S1].
    d.  **Conflict Detection and Erasing:** For every view $I_{ref}$ in the reference set $I_{ref}$:
        i.  Compute the conflicted region mask $m''$ by warping the depth from the reference view to the new view and checking for inconsistencies.
        ii. Formula: $m''_{ij} = \mathbb{I}(v_{ij} - warp(v'_{ij}) > \epsilon)$, where $v_{ij}$ is the reference depth and $v'_{ij}$ is the warped depth from the new view [S1].
        iii. The final conflict mask is computed by performing a logic AND operation across the individual masks $m''$ from all reference views [S1].
        iv. Erase these conflicted regions from the supervision of the NeRF training for the new view [S1].
    e.  **Update Reference Set:** Add the inpainted and erased new view to the reference views set $I_{ref}$ [S1].
    f.  **Fine-tuning:** Fine-tune $f_{nerf}$ with the updated $I_{ref}$ for 2,000 iterations [S1].

**Pseudocode:**

```python
def progressive_inpainting_and_erasing(I_rgb):
    # 1. Estimate initial depth
    I_d = estimate_depth(I_rgb) # Eq. 2 in [S1]
    I_rgbd = combine_rgb_depth(I_rgb, I_d)
    
    # 2. Train initial single-view NeRF
    f_nerf = train_single_view_nerf(I_rgbd, iterations=10000) # Eq. 3 in [S1]
    
    # 3. Generate trajectories
    trajectories = generate_trajectories(I_d)
    
    # 4. Initialize reference views
    I_ref = {I_rgbd}
    
    # 5. Progressive loop
    for n in range(1, iters + 1):
        # Sample new view
        p = random_sample(trajectories)
        
        # Render current NeRF to get depth for new view
        v_new = render_depth(f_nerf, p)
        
        # Get reference depth (from one of the views in I_ref, typically the most recent or aggregated)
        # Note: The source implies warping between new view and reference views
        # We assume a reference view I_ref_view is selected or averaged from I_ref
        I_ref_view = get_reference_view(I_ref)
        v_ref = get_depth(I_ref_view)
        
        # Compute invisible regions in new view
        # Warp new view depth to reference view coordinates
        v_new_warped_to_ref = warp_depth(v_new, p, I_ref_view.pose)
        m_invisible = indicator_function(v_new_warped_to_ref - v_ref > epsilon)
        
        # Perform collaborative RGBD inpainting on invisible regions
        I_new_rgb_inpainted = inpaint_rgb_stable_diffusion(I_new_rgb, m_invisible)
        I_new_depth_stitched = inpaint_depth_estimator(I_new_depth, m_invisible)
        I_new_rgbd = combine_rgb_depth(I_new_rgb_inpainted, I_new_depth_stitched)
        
        # Compute conflicted regions
        # Warp reference view depth to new view coordinates
        v_ref_warped_to_new = warp_depth(v_ref, I_ref_view.pose, p)
        m_conflict_individual = indicator_function(v_ref - v_ref_warped_to_new > epsilon) # Eq. 6 in [S1]
        
        # Logic AND across all reference views (simplified for single ref view in loop step, 
        # but source says "all reference views")
        # In implementation, this mask should be accumulated or intersected across all I_ref
        m_conflict_final = m_conflict_individual 
        for other_ref in I_ref:
            v_other = get_depth(other_ref)
            v_other_warped = warp_depth(v_other, other_ref.pose, p)
            m_other_conflict = indicator_function(v_other - v_other_warped > epsilon)
            m_conflict_final = logical_and(m_conflict_final, m_other_conflict)
        
        # Erase conflicted regions from supervision
        # Create a mask for valid supervision pixels
        supervision_mask = logical_not(m_conflict_final)
        
        # Add new view to reference set
        I_ref.add(I_new_rgbd)
        
        # Fine-tune NeRF
        # First 100 iterations: only new view
        fine_tune_nerf(f_nerf, {I_new_rgbd}, iterations=100, supervision_mask=supervision_mask)
        # Next 1900 iterations: all reference views
        fine_tune_nerf(f_nerf, I_ref, iterations=1900, supervision_mask=supervision_mask)
        
    return f_nerf
```

**Edge Cases and Pitfalls:**
*   **Depth Estimation Error:** The initial depth estimation from a single panorama is critical. Errors here propagate to trajectory generation and conflict detection [S1].
*   **Geometry Conflict:** The method explicitly handles conflicts where inpainted regions violate the geometry learned from reference views. Failure to correctly identify these conflicts leads to artifacts [S1].
*   **Precision:** The threshold $\epsilon$ must be carefully chosen to allow for small errors while detecting significant geometric inconsistencies [S1].
*   **Boundary Conditions:** The warping function must handle occlusions and depth discontinuities correctly to avoid false positives in invisible/conflict detection [S1].

## Operating characteristics
*   **Time Complexity:** The method is iterative, with $iters$ steps (e.g., 32 views). Each step involves depth estimation, inpainting (Stable Diffusion), warping, and NeRF fine-tuning (2,000 iterations). Total training time is approximately 2 hours on a single Nvidia V100 GPU for a scene [S1].
*   **Memory Complexity:** Uses Instant-NGP representation with a hash table of size $2^{19}$ and 16 levels of feature vectors of channel size 2 [S1]. Requires memory for storing reference views and intermediate depth maps [S1].
*   **Scaling:** The method scales with the number of sampled views and the complexity of the scene. The use of Instant-NGP helps with rendering speed [S1].
*   **Strengths:** Effectively handles the reconstruction of panoramic NeRFs from a single view by synthesizing missing geometry and resolving conflicts [S1].
*   **Limitations:** Relies on the quality of the initial depth estimation and the inpainting model. May struggle with highly dynamic scenes or regions with no texture [S1].
*   **When to use:** When reconstructing a NeRF from a single panoramic image is required, and standard methods fail due to lack of multi-view constraints [S1].
*   **When not to use:** When multiple views are available, standard NeRF training is more robust and efficient [S1].

## Background
*   **Origin:** Proposed in "PERF: Panoramic Neural Radiance Field From a Single Panorama" [S1].
*   **History:** The method addresses the challenge of single-view panorama reconstruction, a specific case of inverse volume rendering where multi-view consistency is initially absent. It builds on prior work in NeRF [1] and Instant-NGP [40], and incorporates 2D priors from Stable Diffusion [61] for inpainting [S1].
*   **Usage:** Evaluated on the Replica dataset and in-the-wild indoor scenes [S1].
