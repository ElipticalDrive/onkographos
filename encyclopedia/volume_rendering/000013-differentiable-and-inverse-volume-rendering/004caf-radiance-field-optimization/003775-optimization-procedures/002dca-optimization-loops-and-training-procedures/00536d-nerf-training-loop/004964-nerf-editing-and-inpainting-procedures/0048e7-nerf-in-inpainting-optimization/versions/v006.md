# NeRF-In Inpainting Optimization

Also called: Free-Form NeRF Inpainting with RGB-D Priors, NeRF object removal, NeRF-In

## Overview
NeRF-In is a framework for removing unwanted objects from a pre-trained Neural Radiance Field (NeRF) without requiring category-specific training data or additional 3D reconstruction [S1, unofficial]. It solves the problem of editing 3D scenes by optimizing the NeRF parameters $\Theta$ to align with user-provided masks and RGB-D priors derived from 2D image inpainting and depth completion methods [S1, unofficial]. Unlike sibling methods that may rely on semantic feature distillation or diffusion priors, NeRF-In explicitly enforces geometric consistency via a depth-guiding loss alongside photometric color guidance, ensuring multi-view consistency and correct geometry in the inpainted regions [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained NeRF model $F_\Theta$ mapping 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$ to density $\sigma$ and color $c$; a user-chosen camera position $\mathbf{o}_u$; a user-drawn free-form mask $M_u$ on the rendered view $I_u = F_{\Theta_{image}}(\mathbf{o}_u)$, where $M_u=1$ for pixels outside the masked region (background) and $M_u=0$ inside (object to remove) [S1, unofficial].
*   **Output:** Updated NeRF parameters $\tilde{\Theta}$ [S1, unofficial].

**Data Structures:**
*   **NeRF Model $F_\Theta$:** Standard MLP-based representation.
*   **Camera Positions:** A set $O = \{\mathbf{o}_s \mid s = 1 \dots K\}$ sampled along a pre-set trajectory (e.g., LLFF test-set trajectory) [S1, unofficial].
*   **Masks:** Transferred masks $M = \{M_s \mid s = 1 \dots K\}$ generated for each sampled view [S1, unofficial].
*   **Guidance Data:**
    *   Guiding Color Images $I^G = \{I_s^G \mid s = 1 \dots K\}$, where $I_u^G$ is the inpainted user view and $I_s^G$ for $s \neq u$ are inpainted sampled views [S1, unofficial].
    *   Guiding Depth Images $D^G = \{D_s^G \mid s = 1 \dots K\}$ [S1, unofficial].

**Numbered Steps:**

1.  **Initialization:** Initialize NeRF parameters $\Theta$ (using a pre-trained model) [S1, unofficial].
2.  **View Sampling:** Sample $K$ camera positions $O$ along a trajectory. Render initial RGB images $I_s$ and depth images $D_s$ using $F_\Theta$ [S1, unofficial].
3.  **Mask Transfer:** Transfer the user-drawn mask $M_u$ to the sampled views to generate $M = \{M_s\}$ using a video object segmentation method (e.g., STCN) [S1, unofficial].
4.  **Guidance Generation:**
    *   Generate guiding color images $I_s^G$ using an image inpainting method $\rho$: $I_s^G = \rho(I_s, M_s)$ [S1, unofficial].
    *   Generate guiding depth images $D_s^G$ using a depth completion method $\tau$: $D_s^G = \tau(D_s, M_s, I_s^G)$ [S1, unofficial].
5.  **View Set Definition:** Define the set of all views $O_{all}$ and outside views $O_{out}$. In the main framework, set $O_{all} = \{\mathbf{o}_u\}$ (user-chosen view) and $O_{out} = O$ (all other sampled views) [S1, unofficial].
6.  **Optimization:** Optimize $\Theta$ to obtain $\tilde{\Theta}$ by minimizing the joint loss $\Phi(M_u, I_u^G, M, D_s^G)$, defined as the sum of color-guiding loss $L_{color}(\Theta)$ and depth-guiding loss $L_{depth}(\Theta)$ [S1, unofficial].

**Formulas:**

The expected color $\hat{C}(\mathbf{r})$ of a camera ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ is computed via volume rendering integral [S1, unofficial]:

$$
\hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T(t_i) (1 - \exp(-\sigma(t_i)\delta_i)) c(t_i)
$$

where $T(t_i) = \exp(-\sum_{j=1}^{i-1} \sigma(t_j)\delta_j)$, $N$ is the number of quadrature points, $\delta_i = t_{i+1} - t_i$, and $c(t_i), \sigma(t_i)$ are color and density at point $t_i$ produced by $F_\Theta$ [S1, unofficial].

The total color-guiding loss $L_{color}(\Theta)$ is the sum of the all-view color loss $L_{all\_color}(\Theta)$ and the outside-view color loss $L_{out\_color}(\Theta)$ [S1, unofficial]:

$$
L_{color}(\Theta) = L_{all\_color}(\Theta) + L_{out\_color}(\Theta)
$$

where [S1, unofficial]:

$$
L_{all\_color}(\Theta) = \sum_{\mathbf{o} \in O_{all}} \| F_{\Theta_{image}}(\mathbf{o}) - I_u^G \|_2^2
$$

$$
L_{out\_color}(\Theta) = \sum_{\mathbf{o} \in O_{out}} \| (F_{\Theta_{image}}(\mathbf{o}) - I_s^G) \odot M_s \|_2^2
$$

Note: The source defines $L_{all\_color}$ using $I_u^G$ for $O_{all}=\{\mathbf{o}_u\}$ and $L_{out\_color}$ using $I_s^G$ and mask $M_s$ for $O_{out}=O$. The term $I_u^G$ in $L_{all\_color}$ represents the full inpainted image for the user view [S1, unofficial].

The depth-guiding loss $L_{depth}(\Theta)$ measures the L2 distance between rendered fine/coarse depth images and guiding depth [S1, unofficial]:

$$
L_{depth}(\Theta) = \sum_{\mathbf{o}_s \in O} \left( \| D_f(\mathbf{o}_s) - D_s^G(\mathbf{o}_s) \|_2^2 + \| D_c(\mathbf{o}_s) - D_s^G(\mathbf{o}_s) \|_2^2 \right)
$$

where $D_f(\mathbf{o}_s)$ is the fine volume predicted depth image and $D_c(\mathbf{o}_s)$ is the coarse volume predicted depth image, computed by accumulating density $\sigma$ from ray batches during volume rendering [S1, unofficial].

**Parameters:**
*   $K$: Number of sampled camera positions/views [S1, unofficial].
*   Batch size: 4,096 [S1, unofficial].
*   Sample points in fine model: 128 [S1, unofficial].
*   Sample points in coarse model: 64 [S1, unofficial].
*   Optimizer: Adam [S1, unofficial].
*   Training steps for inpainting: 50,000 [S1, unofficial].

**Pitfalls:**
*   Optimizing only with masked MSE on transferred masks without explicit guidance causes the unwanted object to remain [S1, unofficial].
*   Using only depth-guiding loss introduces color noise outside the masked region and loses color information in flat regions [S1, unofficial].
*   Using multiple inpainted images as color guidance introduces visual inconsistency between views; thus, only the user-chosen view is used for $L_{all\_color}$ [S1, unofficial].

**Pseudocode:**

```python
def nerf_in_inpainting(pretrained_nerf, user_view_idx, user_mask, trajectory_indices):
    """
    Optimizes a pre-trained NeRF to remove an object specified by a mask.
    
    Args:
        pretrained_nerf: Pre-trained NeRF model F_Theta.
        user_view_idx: Index of the user-chosen view o_u.
        user_mask: Binary mask M_u for the user view (1=background, 0=object).
        trajectory_indices: List of K camera indices to sample.
        
    Returns:
        updated_nerf: NeRF model with optimized parameters Theta_tilde.
    """
    # 1. Initialize parameters (already pretrained)
    theta = pretrained_nerf.parameters
    
    # 2. Sample K camera positions and render initial views
    # trajectory_indices contains K indices
    sampled_views = []
    for idx in trajectory_indices:
        # Render RGB and Depth using current NeRF
        rgb, depth = render_view(pretrained_nerf, idx)
        sampled_views.append({'rgb': rgb, 'depth': depth, 'idx': idx})
        
    # 3. Transfer mask to sampled views using Video Object Segmentation (e.g., STCN)
    # M_u is mask for user_view_idx. We need masks for all sampled_views.
    transferred_masks = []
    for view_data in sampled_views:
        # STCN takes the user view image, user mask, and the target view image
        # to propagate the mask.
        mask = video_object_segmentation(
            source_image=pretrained_nerf.render_image(user_view_idx),
            source_mask=user_mask,
            target_image=view_data['rgb']
        )
        transferred_masks.append(mask)
        
    # 4. Generate Guidance Materials
    guiding_colors = []
    guiding_depths = []
    
    for i, view_data in enumerate(sampled_views):
        # Generate guiding color using Image Inpainting (e.g., MST)
        # rho(I, M) inpaints I using mask M
        guided_color = image_inpainting(view_data['rgb'], transferred_masks[i])
        guiding_colors.append(guided_color)
        
        # Generate guiding depth using Depth Completion (e.g., Fast Bilateral Solver)
        # tau(D, M, I_G) completes depth D using mask M and guided color I_G
        guided_depth = depth_completion(
            view_data['depth'], 
            transferred_masks[i], 
            guided_color
        )
        guiding_depths.append(guided_depth)
        
    # 5. Define View Sets
    # O_all = {o_u}, O_out = {o_s | s != u}
    # In implementation, we iterate over all K views for loss computation
    # but apply specific loss terms based on whether the view is the user view or not.
    
    # 6. Optimization Loop
    optimizer = Adam(theta, lr=0.001) # Typical Adam settings, lr not specified in source but implied
    
    for step in range(50000):
        optimizer.zero_grad()
        
        total_loss = 0.0
        
        for i, view_data in enumerate(sampled_views):
            o_s = view_data['idx']
            M_s = transferred_masks[i]
            I_s_G = guiding_colors[i]
            D_s_G = guiding_depths[i]
            
            # Render current NeRF
            # Render RGB (fine and coarse)
            C_f, C_c = render_volume(pretrained_nerf, o_s, num_samples_fine=128, num_samples_coarse=64)
            # Render Depth (fine and coarse)
            D_f, D_c = render_depth(pretrained_nerf, o_s, num_samples_fine=128, num_samples_coarse=64)
            
            # Color Loss
            if o_s == user_view_idx:
                # L_all_color: Compare full rendered image with guided image
                # Note: Source uses I_u^G for O_all. I_u^G is the inpainted user view.
                # The mask M_u is 1 for background. The source formula for L_all_color 
                # does not explicitly show masking in the sum, but implies comparison 
                # over the whole image or masked region. Based on Eq 9: ||F(o) - I_G||^2.
                # We assume this applies to the whole image or the background region.
                # Given the pitfall about "outside view", L_all is likely for the user view.
                loss_color_all = mse(C_f, I_s_G) # Using fine color for simplicity, or average
                total_loss += loss_color_all
            else:
                # L_out_color: Compare rendered image with guided image, masked by M_s
                # Eq 10: || (F(o) - I_G) * M_s ||^2
                masked_diff = (C_f - I_s_G) * M_s
                loss_color_out = mse(masked_diff, torch.zeros_like(masked_diff))
                total_loss += loss_color_out
                
            # Depth Loss
            # Eq 11: Sum of L2 between fine/coarse depth and guided depth
            loss_depth_f = mse(D_f, D_s_G)
            loss_depth_c = mse(D_c, D_s_G)
            total_loss += loss_depth_f + loss_depth_c
            
        total_loss.backward()
        optimizer.step()
        
    return pretrained_nerf # With updated theta
```

## Operating characteristics
*   **Time Complexity:** Optimization takes approximately 5 hours per scene on an Intel i7-7800X CPU and GTX-1080 GPU for 50,000 steps [S1, unofficial].
*   **Memory Complexity:** Depends on the batch size (4,096 rays) and the number of sample points (128 fine, 64 coarse) [S1, unofficial].
*   **Strengths:** Requires no category-specific training data; ensures multi-view consistency and correct geometry via depth guidance; works with any existing 2D inpainting and depth completion methods [S1, unofficial].
*   **Limitations:** Performance depends on the quality of the initial 2D guidance materials; artifacts in guidance propagate to the NeRF; may struggle with large holes or high variance regions if guidance is poor [S1, unofficial].
*   **When to use:** When removing unwanted objects from a pre-trained NeRF without access to category-specific data or retraining from scratch.
*   **When not to use:** When high-quality 2D inpainting/depth completion is not available or when the scene requires semantic understanding beyond geometric removal.

## Background
NeRF-In was introduced by Hao-Kang Liu, I-Chao Shen, and Bing-Yu Chen in 2022 [S1, unofficial]. It addresses the unintuitive nature of editing pre-trained NeRFs by providing a framework that updates model parameters based on user masks and RGB-D priors. It builds on the standard NeRF volume rendering formulation [S1, unofficial].
