# Deceptive-NeRF/3DGS Pipeline
Also called: Deceptive-3DGS, Deceptive-NeRF

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that enhances NeRF or 3D Gaussian Splatting (3DGS) representations by continuously densifying input observations with synthetic pseudo-observations generated by a diffusion model during training [S1]. Unlike sibling methods that rely on ensemble learning, variational inference, or spatial perturbations for uncertainty, this method acquires uncertainty through correspondence matching by reprojecting real input observations to novel views, minimizing additional computation while enforcing epipolar constraints [S1]. It builds on [NeRF Editing and Inpainting Procedures](12494-nerf-editing-and-inpainting-procedures.md) by using 2D diffusion priors to rectify artifacts and fill geometric gaps in sparse inputs.

## How it works
**Inputs:** A set of $W$ input images $I = \{I_1, \dots, I_W\}$ with calibrated camera poses.
**Outputs:** A refined radiance field representation (NeRF or 3DGS) and a set of accumulated pseudo-observations.

**Data Structures:**
*   **Radiance Field:** Standard NeRF MLP or 3DGS primitive set.
*   **ControlNet:** A copy of a pre-trained 2D diffusion model (e.g., Stable Diffusion) with frozen weights, augmented with trainable convolutional layers to accept multi-channel control maps [S1].
*   **Text Embedding:** A composite vector $s = [s_0, s^*]$ where $s_0$ is a caption embedding and $s^*$ is an optimized latent embedding [S1].

**Numbered Steps:**

1.  **Initial Training:** Train the NeRF/3DGS representation using the few-view input images $I$ with calibrated poses for a set number of epochs to obtain a coarse reconstruction [S1].
2.  **Novel View Sampling:** Randomly sample a novel viewpoint $A$ within a bounding box defined by the outermost input views [S1].
3.  **Rendering:** At viewpoint $A$, render the coarse RGB image $\hat{I}_A$, the depth map $D_A$, and the uncertainty map $U_A$.
    *   **Depth Rendering:** Compute depth $\hat{\mathbf{D}}$ as a weighted sum of distances traveled:
        $$ \hat {\mathbf {D}} = \sum _{k=1}^K \hat {T}(t_k)\alpha (\sigma (t_k)\delta _k) $$
        where $\hat {T}(t_k)$ is transmittance, $\alpha$ is opacity, $\sigma$ is density, and $\delta _k$ is the distance traveled at sample point $k$ [S1].
    *   **Uncertainty Map:** Identify the nearest input viewpoint $B$ to novel view $A$. Warp the ground truth image $I_B$ to view $A$ using the rendered depth $D_A$ and the viewpoint difference $R_{B\rightarrow A}$:
        $$ I_{B\rightarrow A} = \psi (I_B; D_A, R_{B\rightarrow A}) $$
        Each pixel location $p$ in $\hat{I}_A$ is transformed to $q$ in $I_B$ via:
        $$ q = K R_{B\rightarrow A} D_A(p) K^{-1} p $$
        where $K$ is the camera parameter matrix. The uncertainty map $U_A$ is defined as the squared difference between the warped image and the rendered image:
        $$ U_A = (I_{B \rightarrow A} - \hat {I}_A)^2 $$
        [S1].
4.  **Text Embedding Derivation:**
    *   Generate an initial text prompt $s_0$ using a pre-trained image captioning network on the coarse image [S1].
    *   Optimize a shared latent text embedding $s^*$ using textual inversion, shared by all input observations and coarse images, to counteract captioning errors on low-quality images [S1].
    *   Form the composite feature $s = [s_0, s^*]$ by concatenating the embeddings [S1].
5.  **Pseudo-Observation Generation:** Generate the pseudo-observation $P_A$ using the Deceptive Diffusion Model $G$:
    $$ P_A = \operatorname {G}(\hat {I}_A, D_A, U_A) $$
    The model $G$ is a latent diffusion model fine-tuned with ControlNet. The ControlNet accepts five control map channels: 3 for coarse RGB, 1 for depth, and 1 for uncertainty [S1]. The diffusion fine-tuning objective is:
    $$ \min _{\theta}\mathbb {E}_{z\sim \mathcal {E},t,\epsilon \sim \mathcal {N}(0,1)}\|\epsilon -\epsilon _{\theta }(z_t,t,c(I_{\text {coarse}},D,U,s))\|_2^2 $$
    where $z \sim \mathcal{E}$ is the latent code, $t \sim [1, 1000]$ is the diffusion time step, $\epsilon$ is noise, $\epsilon_\theta$ is the denoiser U-Net, and $c$ is the embedding of the coarse image, depth, uncertainty, and text embedding $s$ [S1].
6.  **Accumulation:** Add $P_A$ to the set of pseudo-observations [S1].
7.  **Filtering:** Discard 20% of the accumulated pseudo-observations with the lowest perceptual similarity to input images, quantified via the LPIPS metric [S1].
8.  **Optimization:** Continue training the NeRF/3DGS representation using the combination of real input images and the accumulated pseudo-observations [S1].
9.  **Iteration:** Repeat steps 2–8 until a sufficient number of observations are accumulated [S1].

**Pseudocode:**

```python
def deceptive_nerf_pipeline(input_images, poses, num_epochs_initial, num_iterations):
    """
    input_images: List of W input images.
    poses: List of W camera poses.
    num_epochs_initial: Epochs for initial coarse training.
    num_iterations: Number of densification iterations.
    """
    # 1. Initial Training
    radiance_field = train_nerf(input_images, poses, epochs=num_epochs_initial)
    
    # 4. Text Embedding Derivation (Pre-computed or updated periodically)
    # s0 from captioning network
    s0 = caption_network(radiance_field.render_coarse()) 
    # s* from textual inversion optimization
    s_star = textual_inversion_optimize(input_images, radiance_field)
    text_embedding = concatenate(s0, s_star)
    
    pseudo_observations = []
    
    for i in range(num_iterations):
        # 2. Novel View Sampling
        view_A = sample_novel_view(poses)
        
        # 3. Rendering
        # Render RGB and Depth
        I_hat_A, D_A = radiance_field.render(view_A)
        
        # Compute Uncertainty Map
        # Find nearest input view B
        view_B = find_nearest_input_view(view_A, poses)
        I_B = get_image(view_B, input_images)
        
        # Warp I_B to view A
        # q = K * R_BA * D_A(p) * K^-1 * p
        K = get_camera_matrix(view_A)
        R_BA = get_rotation_matrix(view_B, view_A)
        I_B_warped = warp_image(I_B, D_A, K, R_BA)
        
        # Uncertainty is squared difference
        U_A = (I_B_warped - I_hat_A) ** 2
        
        # 5. Pseudo-Observation Generation
        # ControlNet inputs: [I_hat_A, D_A, U_A] -> 5 channels
        # P_A = G(I_hat_A, D_A, U_A)
        P_A = deceptive_diffusion_model(I_hat_A, D_A, U_A, text_embedding)
        
        # 6. Accumulation
        pseudo_observations.append(P_A)
        
        # 7. Filtering (Discard bottom 20% by LPIPS)
        # Calculate LPIPS between P_A and all input images
        similarities = [lpips(P_A, I_in) for I_in in input_images]
        min_similarity = min(similarities)
        
        if min_similarity < threshold_20th_percentile(pseudo_observations):
            pseudo_observations.remove(P_A)
            
        # 8. Optimization
        all_images = input_images + pseudo_observations
        radiance_field = train_nerf(all_images, poses, epochs=1) # Incremental update
        
    return radiance_field

def warp_image(I_B, D_A, K, R_BA):
    """
    Warp image I_B to view A using depth D_A and rotation R_BA.
    """
    H, W = I_B.shape[:2]
    I_warped = np.zeros_like(I_B)
    
    # Iterate over pixels in target image A (conceptually, though D_A is on A's grid)
    # In practice, project pixels from A to B
    for y in range(D_A.shape[0]):
        for x in range(D_A.shape[1]):
            # Pixel p in A
            p = np.array([x, y, 1])
            
            # Depth at p in A
            depth_p = D_A[y, x]
            
            # Transform to B
            # q = K * R_BA * depth_p * K^-1 * p
            # Note: The formula in source is q = K R_{B->A} D_A(p) K^{-1} p
            # This implies D_A(p) is treated as a scale factor or depth value in homogeneous coords?
            # Standard warping: p_hom = [x, y, 1]. 
            # The source formula suggests: q = K * R * (D_A(p) * K^-1 * p) ? 
            # Or is D_A(p) the depth value used to reconstruct 3D point?
            # Let's follow the source formula literally:
            
            # 1. Project p to camera space of A? No, K^-1 p is ray direction in camera space.
            # Let's assume standard pinhole: X_cam = K^-1 * [x, y, 1] * depth
            # But the formula is explicit: q = K R_{B->A} D_A(p) K^{-1} p
            
            term1 = np.linalg.inv(K) @ p
            term2 = term1 * depth_p # Scale by depth
            term3 = R_BA @ term2    # Rotate to B's coordinate system
            term4 = K @ term3       # Project to B's image plane
            
            q = term4[:2] / term4[2] # Normalize
            
            qx, qy = int(q[0]), int(q[1])
            if 0 <= qx < W and 0 <= qy < H:
                I_warped[y, x] = I_B[qy, qx]
                
    return I_warped
```

**Parameters:**
*   **Discard Rate:** 20% of pseudo-observations with the lowest perceptual similarity are discarded [S1].
*   **LPIPS Metric:** Used to quantify perceptual similarity [S1].
*   **ControlNet:** Used to implement the training paradigm while preserving pre-trained weights [S1].
*   **Gaussian Noise:** Standard deviation 0.3, added to 60,000 images from Hypersim for data augmentation [S1].
*   **Control Map Channels:** Five channels (3 for coarse RGB, 1 for depth, 1 for uncertainty) [S1].
*   **Image Resolution:** All images are randomly cropped to 512 × 512 [S1].
*   **Training Dataset Size:** 200 scenes and approximately 20,000 images for the major section of the training dataset, with Hypersim and CO3D each contributing half [S1].
*   **Coarse NeRF Training Data:** Coarse NeRFs are trained only with one-fifth of input images [S1].

**Edge Cases and Pitfalls:**
*   **Captioning Efficacy:** Image captioning efficacy diminishes for images of lower quality or those with pronounced artifacts. Textual inversion is used to counteract this by optimizing a shared latent text embedding [S1].
*   **Noisy Augmentation:** When training with noisy RGB-depth data augmentation (adding Gaussian noise to RGB images), uncertainty maps are not fed into the diffusion model [S1].

## Operating characteristics
*   **Time Complexity:** The method requires iterative training loops where each iteration involves rendering, warping, diffusion inference, and NeRF optimization. The diffusion model inference is the most expensive step per novel view.
*   **Memory Complexity:** Requires storing the radiance field, the ControlNet model, and the accumulated pseudo-observations.
*   **Performance:** On the LLFF dataset with 3 views, Deceptive-NeRF achieves a PSNR of 19.87 and SSIM of 0.436, outperforming SRF, PixelNeRF, MVSNeRF, DietNeRF, RegNeRF, and FreeNeRF [S1]. Deceptive-3DGS achieves a PSNR of 19.95 and SSIM of 0.438 [S1].
*   **Strengths:** Enforces view consistency via epipolar constraints without modifying the underlying representation. Generates high-quality photorealistic pseudo-observations that rectify NeRF artifacts.
*   **Limitations:** Computationally intensive due to the diffusion model and iterative densification. Relies on the quality of the pre-trained diffusion model and the accuracy of the initial coarse reconstruction.

## Background
Deceptive-NeRF/3DGS was introduced by X. Liu et al. in 2023 [S1]. It addresses the challenge of sparse-view reconstruction by leveraging the power of 2D diffusion models to generate pseudo-observations that guide the 3D reconstruction process. The method distinguishes itself by using an uncertainty map derived from view consistency (warping nearest views) rather than ensemble methods or variational inference [S1]. It is used for few-shot novel view synthesis and super-resolution on datasets like LLFF, Mip-NeRF 360, ScanNet, and Hypersim [S1].
