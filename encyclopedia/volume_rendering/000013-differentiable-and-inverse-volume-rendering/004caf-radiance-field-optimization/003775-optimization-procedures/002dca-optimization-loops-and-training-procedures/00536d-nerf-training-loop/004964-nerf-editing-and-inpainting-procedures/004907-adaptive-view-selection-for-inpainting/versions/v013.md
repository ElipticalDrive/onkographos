# Adaptive View Selection for Inpainting

Also called: 3D Inpainting Component, 3D Inpainting Component with Adaptive View Selection, Adaptive Weight Inpainting, Gradient-Based View Selection

## Overview
Adaptive View Selection for Inpainting is a method for removing obstacles from Neural Radiance Fields (NeRFs) by combining 2D image inpainting priors with multi-view consistency constraints [S1]. It solves the problem of inconsistent geometry and texture in de-occluded regions by dynamically selecting whether to rely on a 2D inpainter or supplementary information from other training views based on local texture richness [S1]. Unlike methods that apply uniform inpainting priors or rely solely on multi-view geometry, this approach uses regional average gradients to adaptively weight the reconstruction loss, ensuring that high-texture areas leverage multi-view correlations while low-texture areas rely on 2D priors [S1].

## How it works
The method operates on a NeRF representation $f_\theta$ mapping 3D coordinates $\mathbf{x}$ and viewing directions $\mathbf{d}$ to density $\sigma$ and color $\mathbf{c}$, using the standard volume rendering equation [S1, 12491-nerf-editing-procedure.md]. It assumes access to a set of input views with known camera poses, a single mask $M$ identifying the obstacle in one reference view, and a pretrained 2D inpainter (specifically LaMa) [S1].

### Data Structures
*   **NeRF Model:** Two MLPs (coarse and fine) taking $\mathbf{x}, \mathbf{d}$ as input, outputting $\sigma, \mathbf{c}$ [S1].
*   **Region Coding Network:** An MLP or segmentation network that outputs a predicted mask $\hat{P}(r) \in [0, 1]$ for each ray $r$, indicating the probability that the ray passes through the occluded region [S1].
*   **2D Inpainting Cache:** For each input view, a pre-computed image where the occluded region (defined by the projected mask) is filled using the 2D inpainter. Let $C_l(r)$ denote the color of the pixel corresponding to ray $r$ in this inpainted image [S1].
*   **Sub-regions:** The occluded area in each view is divided into a grid of sub-regions (patches) to compute local gradients [S1].

### Inputs and Outputs
*   **Inputs:**
    *   Set of input views $V = \{I_1, ..., I_K\}$ with poses.
    *   Reference mask $M$ for the obstacle in one view.
    *   Pretrained 2D inpainter (LaMa) [S1].
    *   Hyperparameters: $\tau$ (gradient threshold ratio), $\lambda_1, \lambda_2, \lambda_3$ (loss weights for segmentation) [S1].
*   **Outputs:**
    *   Optimized NeRF parameters $\theta$.
    *   De-occluded novel view renderings.

### Numbered Steps

1.  **Mask Propagation:** Use the reference mask $M$ and depth information to infer masks $M_s$ for all other views $s=1...K$ using an object segmentation network [S1]. This ensures multi-view consistency of the occlusion boundary.
2.  **2D Inpainting Prior Generation:** For each view $I_s$, apply the 2D inpainter (LaMa) to the region defined by $M_s$ to generate the inpainted image. Store the pixel colors $C_l(r)$ for rays $r$ passing through the occluded region [S1].
3.  **Sub-region Division:** Divide the occluded region in each view into multiple sub-regions (patches) [S1].
4.  **Gradient Computation:** For each sub-region, compute the average gradient of the rendered image $\nabla \hat{g}$ and the average gradient of the 2D inpainted image $\nabla g$ [S1].
5.  **Adaptive Weight Calculation:** Determine the adaptive weight $\lambda$ for the reconstruction loss based on the gradient comparison [S1]:
    $$
    \lambda = \begin{cases} 
    1 & \text{if } \nabla \hat{g} > \tau \cdot \nabla g \\
    0 & \text{if } \nabla \hat{g} \le \tau \cdot \nabla g 
    \end{cases}
    $$
    Here, $\nabla \hat{g}$ represents the texture richness of the current NeRF render, and $\nabla g$ represents the texture richness of the 2D inpainting prior. If the NeRF render has sufficient texture (gradient) compared to the prior, $\lambda=1$, prioritizing the NeRF's multi-view consistency. If the NeRF render is smooth/low-texture, $\lambda=0$, prioritizing the 2D inpainting prior [S1].
6.  **Loss Formulation:** Compute the total reconstruction loss $L$ as a weighted sum of non-occluded and occluded losses [S1]:
    $$
    L = \lambda L_{NonOcc} + (1 - \lambda) L_{Occ}
    $$
    Where:
    *   $L_{NonOcc}$ is the reconstruction loss for non-occluded areas (rays where $\hat{P}(r) \approx 0$):
        $$
        L_{NonOcc} = \sum_{r \in R} (1 - \hat{P}(r)) \left[ ||\hat{C}_c(r) - C(r)||_2^2 + ||\hat{C}_f(r) - C(r)||_2^2 \right]
        $$
        Here, $\hat{C}_c(r)$ and $\hat{C}_f(r)$ are the coarse and fine predicted colors, and $C(r)$ is the ground truth color [S1].
    *   $L_{Occ}$ is the reconstruction loss for occluded areas (rays where $\hat{P}(r) \approx 1$):
        $$
        L_{Occ} = \sum_{r \in R} \hat{P}(r) \left[ ||\hat{C}_c(r) - C_l(r)||_2^2 + ||\hat{C}_f(r) - C_l(r)||_2^2 \right]
        $$
        Here, $C_l(r)$ is the color from the 2D inpainted image [S1].
7.  **Segmentation Loss:** Simultaneously optimize the region coding network (mask predictor) using a joint loss [S1]:
    $$
    L_{seg} = \lambda_1 L_{region-encoding} + \lambda_2 L_{rgb} + \lambda_3 L_{depth}
    $$
    Where $L_{depth}$ constrains the rendered depth $\hat{D}(r)$ to match ground truth depth $D(r)$:
    $$
    L_{depth} = \sum_{r \in R} ||\hat{D}(r) - D(r)||_2^2
    $$
8.  **Optimization:** Update NeRF parameters and the region coding network parameters to minimize $L + L_{seg}$ [S1].

### Pseudocode

```python
def adaptive_view_selection_inpainting(views, reference_mask, la_ma_inpainter, tau, lambda1, lambda2, lambda3):
    """
    views: List of dicts with keys 'image', 'pose', 'depth'
    reference_mask: 2D array (H, W) binary mask for obstacle in first view
    la_ma_inpainter: Function that inpaints masked regions of an image
    tau: Gradient threshold ratio
    lambda1, lambda2, lambda3: Weights for segmentation loss
    """
    # Initialize NeRF and Region Coding Network
    nerf_coarse = init_nerf()
    nerf_fine = init_nerf()
    region_net = init_region_coding_network()
    
    # Step 1 & 2: Propagate masks and generate 2D inpainting priors
    inpainted_views = []
    for i, view in enumerate(views):
        if i == 0:
            current_mask = reference_mask
        else:
            # Use segmentation network to infer masks for other views
            # This step assumes a separate training loop or pre-computed masks
            current_mask = propagate_mask(view, reference_mask, region_net)
        
        # Apply 2D inpainter to occluded region
        inpainted_img = la_ma_inpainter(view['image'], current_mask)
        inpainted_views.append({
            'image': inpainted_img,
            'mask': current_mask,
            'pose': view['pose'],
            'depth': view['depth']
        })

    # Step 3-8: Training Loop
    for epoch in range(num_epochs):
        total_loss = 0
        for view_data in inpainted_views:
            rays = sample_rays(view_data['image'], view_data['pose'])
            
            # Render NeRF
            rays_coarse, rays_fine = nerf_coarse(rays), nerf_fine(rays)
            predicted_colors_c = rays_coarse['color']
            predicted_colors_f = rays_fine['color']
            predicted_masks = region_net(rays['xyz']) # Predict occlusion probability
            
            # Get 2D inpainting prior colors
            prior_colors = get_prior_colors(rays, view_data['image'])
            
            # Compute gradients for adaptive weight
            # Divide occluded region into sub-regions
            sub_regions = divide_into_patches(view_data['mask'])
            avg_grad_render = compute_average_gradient(predicted_colors_c, sub_regions)
            avg_grad_prior = compute_average_gradient(prior_colors, sub_regions)
            
            # Adaptive lambda
            lambda_val = 1.0 if avg_grad_render > tau * avg_grad_prior else 0.0
            
            # Compute Reconstruction Losses
            # Non-occluded loss
            non_occ_mask = 1.0 - predicted_masks
            loss_non_occ = sum(
                non_occ_mask * (
                    (predicted_colors_c - view_data['image'])**2 + 
                    (predicted_colors_f - view_data['image'])**2
                )
            )
            
            # Occluded loss
            occ_mask = predicted_masks
            loss_occ = sum(
                occ_mask * (
                    (predicted_colors_c - prior_colors)**2 + 
                    (predicted_colors_f - prior_colors)**2
                )
            )
            
            # Total Reconstruction Loss
            loss_recon = lambda_val * loss_non_occ + (1.0 - lambda_val) * loss_occ
            
            # Compute Segmentation Loss
            # L_region_encoding: e.g., BCE between predicted mask and propagated mask
            loss_region = bce_loss(predicted_masks, view_data['mask'])
            
            # L_rgb: Color consistency for non-occluded
            loss_rgb = sum(non_occ_mask * (predicted_colors_c - view_data['image'])**2)
            
            # L_depth: Depth consistency
            predicted_depths = nerf_coarse(rays)['depth']
            loss_depth = sum((predicted_depths - view_data['depth'])**2)
            
            loss_seg = lambda1 * loss_region + lambda2 * loss_rgb + lambda3 * loss_depth
            
            total_loss += loss_recon + loss_seg
        
        # Backpropagate and update
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
```

### Parameters
*   $\tau$: Threshold ratio for gradient comparison. Not given in the sources.
*   $\lambda_1, \lambda_2, \lambda_3$: Weights for segmentation loss components. Not given in the sources.
*   $C_l(r)$: Color of the corresponding pixel in the 2D inpainting image. Used as an estimated color prior for occluded areas [S1].

### Edge Cases and Pitfalls
*   **Single 2D Inpainting Inconsistency:** A single 2D inpainter does not consider consistency in the real 3D scene. The method addresses this by selecting training views based on texture richness (gradient) to ensure multi-view consistency [S1].
*   **Uniform Strategy Misjudgment:** Applying a uniform strategy to the entire occluded area can lead to misjudgment. The method avoids this by dividing the occluded area into sub-regions and evaluating gradients individually [S1].
*   **Lack of Supplementary Information:** When no other view can provide supplementary information for an occluded area, the method relies primarily on the 2D inpainting results [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the number of views, rays sampled, and the cost of the 2D inpainter (LaMa). The adaptive weight calculation adds a gradient computation step per sub-region per view.
*   **Memory Complexity:** Requires storing the NeRF models, the region coding network, and the pre-computed 2D inpainted images for all views.
*   **Strengths:** Effectively reduces the disturbing effect of 2D inpainters by leveraging multi-view consistency where available. Improves fidelity of de-occluded results by adapting to local texture richness.
*   **Limitations:** Relies on the quality of the 2D inpainter (LaMa). Requires accurate mask propagation across views. Performance depends on the availability of multi-view information for occluded regions.
*   **When to use:** When inpainting occluded regions in NeRFs and multi-view consistency is important. Suitable for scenes with wide-range multi-view support.
*   **When not to use:** When only a single view is available or when multi-view information is insufficient to resolve occlusions.

## Background
The method was proposed in the paper "3D Scene De-occlusion in Neural Radiance Fields: A Framework for Obstacle Removal and Realistic Inpainting" [S1]. It addresses the limitations of previous NeRF editing methods that either relied solely on 2D inpainting (ignoring 3D consistency) or solely on multi-view geometry (struggling with large occlusions). The framework integrates a region coding network for obstacle localization and a 3D inpainting component with adaptive view selection. It has been evaluated on datasets like LLFF and SPIn-NeRF [S1].
