# Blended-NeRF

Also called: Zero-Shot Object Generation and Blending in Existing Neural Radiance Fields

## Overview
Blended-NeRF is a framework for editing a specific region of interest (ROI) in an existing Neural Radiance Field (NeRF) scene based on text prompts and a user-defined 3D ROI box [S1]. It solves the problem of local 3D editing by initializing a generator NeRF with the weights of the original scene and blending the synthesized content with the original scene using volumetric blending [S1]. Unlike methods that synthesize new objects from scratch (e.g., Dream Fields) or require semantic decomposition/2D masks for localization (e.g., Kobayashi, Benaim), Blended-NeRF operates on any region using a 3D box without learning a new feature space or requiring 2D masks [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** An existing NeRF model $F_{\theta_O}$ representing scene $x_o$, a 3D ROI box $B$ localized inside the scene, and a text prompt $y$.
*   **Output:** An edited NeRF model $F_{\theta_E}$ (implicitly defined by the blend of $F_{\theta_O}$ and $F_{\theta_G}$) that renders scene $x_e$ where $x_e \odot B$ matches the prompt and $x_e \odot (1 - B) = x_o \odot (1 - B)$ [S1].

**Data Structures:**
*   **NeRF Model ($F_\theta$):** A Multi-Layer Perceptron (MLP) mapping 3D coordinates $\mathbf{x}$ and viewing direction $\mathbf{v}$ to density $\sigma$ and color $\mathbf{c}$.
*   **Positional Encoding:** Inputs are embedded using high-frequency sinusoidal positional encoding $\gamma(\mathbf{x}) = [\cos(2^l \mathbf{x}), \sin(2^l \mathbf{x})]_{l=0}^{L-1}$ [S1].
*   **ROI Box ($B$):** Defined by its center, dimensions, and diagonal length `diag`.

**Numbered Steps:**

1.  **Initialization:** Initialize a generator NeRF model $F_{\theta_G}$ with the weights of the original scene model $F_{\theta_O}$ [S1].
2.  **ROI Localization:** Localize a 3D box $B$ inside the scene using a GUI that renders the original NeRF and uses the output depth map for 3D understanding [S1].
3.  **Training Setup:**
    *   Sample random camera poses around the scene. The initial distance $d$ from the ROI is calculated as $d = \frac{e_{max}}{2 \tan(\gamma/2)}$, where $e_{max}$ is the maximum dimension of the box and $\gamma$ is the camera FOV. Randomly sample radius $r$ around $d$ [S1].
    *   Apply background augmentation (Gaussian noise, checkerboard, or random Fourier textures) during optimization to prevent scene diffusion [S1].
    *   Use directional dependent prompts by concatenating view-dependent text to the original caption [S1].
4.  **Generator Optimization:** Optimize $F_{\theta_G}$ by minimizing the total loss $L_{total}$ [S1].
    *   Cast rays $r$ that pass through the box $B$.
    *   For sample points $\mathbf{x}_i$ outside $B$, set density to zero.
    *   Render the generated content inside the ROI box $I_{ROI}$ using only points $\mathbf{x}_i \in B$ [S1]:
        $$
        C(r) = \begin{cases} 
        \frac{\sum_{\mathbf{x}_i \in B} T_i (1 - e^{-\sigma_i \delta_i}) c_i}{\sum_{\mathbf{x}_i \in B} T_i (1 - e^{-\sigma_i \delta_i})} & \text{if } \exists \mathbf{x}_i \in r \text{ s.t. } \mathbf{x}_i \in B \\
        0 & \text{otherwise}
        \end{cases}
        $$
        where $T_i = \exp(-\sum_{j < i} \sigma_j \delta_j)$, $\delta_i = t_{i+1} - t_i$ is the distance between adjacent samples, $\sigma_i$ is density, and $c_i$ is color [S1].
    *   Compute Similarity Loss $L_{sim}$ using a language-image model (e.g., CLIP) encoders $E_{img}$ and $E_{txt}$:
        $$
        L_{sim} = -E_{img}(I_{ROI})^T E_{txt}(y)
        $$
    *   Compute Transmittance Loss $L_T$ to encourage sparsity:
        $$
        L_T = -\min(\tau, \text{mean}(T(P)))
        $$
        where $T(P)$ is the transmittance of the rendered view from pose $P$ and $\tau$ is the max transmittance [S1].
    *   Compute Depth Loss $L_D$ to encourage volumetric geometry (especially for forward-facing scenes):
        $$
        L_D = -\min(\rho, \sigma^2(D(P)))
        $$
        where $\sigma^2(D(P))$ is the variance of the disparity map of the rendered view from pose $P$ and $\rho$ is the max variance allowed [S1].
    *   Total Objective:
        $$
        L_{total} = L_{sim} + \lambda_T L_T + \lambda_D L_D
        $$
        where $\lambda_T, \lambda_D$ are weights. $L_T$ and $L_D$ are gradually introduced during training using an annealing strategy [S1].
5.  **Blending (Inference):** After training, render the edited scene by blending the sample points generated by $F_{\theta_O}$ and $F_{\theta_G}$ along each view ray [S1].
    *   **Object Insertion/Replacement Mode:** During training, consider only the radiance field of $F_{\theta_G}$ inside the ROI. After training, blend using distance smoothing [S1].
    *   **Object Blending Mode:** Query both $F_{\theta_O}$ and $F_{\theta_G}$ inside the box.
        *   Compute alpha values for each point $\mathbf{x}_i$ on the ray separately from each model:
            $$
            \alpha_O(\mathbf{x}_i) = 1 - \exp(\phi(\sigma_O(\mathbf{x}_i)) \cdot \delta_i)
            $$
            $$
            \alpha_G(\mathbf{x}_i) = 1 - \exp(\phi(\sigma_G(\mathbf{x}_i)) \cdot \delta_i)
            $$
            where $\phi$ is a non-negative activation function [S1].
        *   **Density Blending Options:**
            *   Option 1 (Sum in activation): $\sigma(\mathbf{x}_i) = \phi(\sigma_O(\mathbf{x}_i) + \sigma_G(\mathbf{x}_i))$. Allows $F_{\theta_G}$ to remove original densities [S1].
            *   Option 2 (Sum out activation): $\sigma(\mathbf{x}_i) = \phi(\sigma_O(\mathbf{x}_i)) + \phi(\sigma_G(\mathbf{x}_i))$. Allows only addition of new densities [S1].
        *   **Color Blending:**
            $$
            c(\mathbf{x}_i) = S\left(\frac{c_O(\mathbf{x}_i) \cdot \alpha_O(\mathbf{x}_i) + c_G(\mathbf{x}_i) \cdot \alpha_G(\mathbf{x}_i)}{\epsilon + \alpha_O(\mathbf{x}_i) + \alpha_G(\mathbf{x}_i)}\right)
            $$
            where $S$ is the sigmoid function and $\epsilon$ is a small constant for numerical stability [S1].
    *   **Distance Smoothing:** To blend the scenes smoothly inside the ROI, apply a distance smoothing operator based on the Euclidean distance $d(\mathbf{x})$ from the ROI center and the box diagonal `diag`:
        $$
        f(\mathbf{x}) = 1 - \exp\left(-\alpha \frac{d(\mathbf{x})}{\text{diag}}\right)
        $$
        $$
        \sigma_{blend}(\mathbf{x}) = f(\mathbf{x}) \cdot \sigma_O(\mathbf{x}) + (1 - f(\mathbf{x})) \cdot \sigma_G(\mathbf{x})
        $$
        $$
        c_{blend}(\mathbf{x}) = f(\mathbf{x}) \cdot c_O(\mathbf{x}) + (1 - f(\mathbf{x})) \cdot c_G(\mathbf{x})
        $$
        where $\alpha$ is a hyperparameter controlling blending strength [S1].
    *   **Final Render:** The final rendered view $x_e$ is obtained by blending the raw densities and RGB values inside and outside the ROI along each ray using standard volume rendering (Eq. 1) [S1].

**Parameters:**
*   $\alpha$: Hyperparameter controlling blending strength. $\alpha=0$ gives all weight to the edited scene; higher $\alpha$ gives more attention to original scene points closer to the ROI center. Demonstrated values include 0, 0.5, 2, 4, 10 [S1].
*   $\tau, \rho$: Max transmittance and max variance allowed, respectively [S1].
*   $\lambda_T, \lambda_D$: Weights for transmittance and depth losses [S1].

**Edge Cases and Pitfalls:**
*   **Scene Diffusion:** Without background augmentation, the scene may populate the background with white/black backgrounds [S1].
*   **Flat Geometry:** In forward-facing scenes, limited viewing intervals may result in flat billboard geometry. Depth loss $L_D$ mitigates this [S1].
*   **Transparency/Amorphous Scenes:** Without transmittance and depth losses, the scene may become completely transparent or amorphous. Annealing these losses prevents this [S1].
*   **Precision:** $\epsilon$ is used in color blending for numerical stability [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Not given in the sources.
*   **Strengths:** Can operate on any region of a real-world scene; modifies only the ROI while preserving the rest without learning a new feature space or requiring 2D masks; generates natural-looking and view-consistent results; not restricted to a specific class or domain; enables complex text-guided manipulations such as object insertion/replacement, blending, and texture conversion [S1].
*   **Limitations:** Requires a pretrained language-image model (e.g., CLIP); relies on user-defined 3D ROI box; naive use without augmentations/priors yields low-quality, incoherent results [S1].
*   **When to use:** When editing a specific local region or object in an existing NeRF scene based on text prompts, especially when avoiding the need for semantic decomposition or 2D masks.
*   **When not to use:** When synthesizing new NeRF objects from scratch (use Dream Fields) or when semantic decomposition is already available and preferred (use Kobayashi/Benaim).

## Background
Blended-NeRF was introduced by Ori Gordon, Omri Avrahami, and Dani Lischinski from The Hebrew University in 2023 [S1]. It builds on the principles of Dream Fields [27] and CLIP-NeRF [67], adapting their priors and augmentations for the specific task of editing existing NeRF scenes. It addresses the limitations of prior editing methods that required semantic decomposition or 2D masks [S1].
