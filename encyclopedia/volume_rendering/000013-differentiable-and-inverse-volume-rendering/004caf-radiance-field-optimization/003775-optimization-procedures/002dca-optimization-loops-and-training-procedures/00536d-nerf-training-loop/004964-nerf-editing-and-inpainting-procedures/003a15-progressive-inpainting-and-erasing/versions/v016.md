# Progressive Inpainting-and-Erasing

Also called: Conflicted Geometry Detection and Erasing, Inpainting-and-Erasing Strategy, PERF, PERF Algorithm

## Overview
Progressive Inpainting-and-Erasing (PERF) is a method for reconstructing a panoramic Neural Radiance Field (NeRF) from a single input panorama by iteratively synthesizing novel views and refining the 3D geometry. It solves the problem of geometry conflicts that arise when inpainting invisible regions of a scene, ensuring that the generated content remains consistent with the already-learned visible geometry. Unlike methods that optimize a static NeRF from multiple views, PERF progressively expands the viewpoint range by alternating between collaborative RGBD inpainting of new views and erasing geometrically inconsistent regions from the training supervision [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A single RGB panorama image $I_{rgb}$.
*   **Output:** A panoramic NeRF representation $f_{nerf}$, implemented using Instant-NGP [S1].

**Data Structures:**
*   **NeRF Representation:** Instant-NGP hash grid. The hash table size is $2^{19}$ with 16 levels of feature vectors, each of channel size 2 [S1].
*   **Reference Views Set ($I_{ref}$):** A set containing RGB-D images used for supervision. Initially contains the estimated depth map of the input panorama.
*   **Trajectory ($\{p_k\}$):** A set of novel camera poses generated based on the initial depth map, with positions gradually increasing in distance from the original viewpoint [S1].

**Parameters:**
*   $\epsilon$: A small threshold value for depth difference comparison [S1].
*   `iters`: Total number of progressive sampling iterations [S1].
*   `num_new_views`: Number of new positions sampled (32) [S1].
*   `init_iters`: Initial training iterations for the single panorama (10,000) [S1].
*   `fine_tune_iters`: Fine-tuning iterations per new view (2,000) [S1].
*   `lr_init`: Initial learning rate ($10^{-3}$) [S1].
*   `lr_final`: Final learning rate ($10^{-4}$) [S1].
*   `ray_count`: Number of rays sampled per iteration (2,048) [S1].

**Formulas:**
1.  **Initial Depth Estimation:**
    $$ I_{rgbd} = \text{DepthEstimator}(I_{rgb}) $$
    where $I_{rgbd}$ is the RGB-D image combining $I_{rgb}$ and the estimated depth map $I_d$ [S1].

2.  **Single-View NeRF Training:**
    The NeRF $f_{nerf}$ is trained using $I_{rgb}$ and $I_d$ via standard volume rendering losses [S1].

3.  **Invisible Region Mask ($m'$):**
    To identify regions in a reference view that are occluded in a new view:
    $$ m'_{ij} = \mathbb{I}(\text{warp}(v'_{ij}) - v_{ij} > \epsilon) $$
    where:
    *   $v_{ij}$ is the depth value at pixel $(i,j)$ in the reference view's depth map $I_d$.
    *   $v'_{ij}$ is the depth value at pixel $(i,j)$ in the new view's depth map $I'_d$.
    *   $\text{warp}(\cdot)$ projects the new view's depth to the reference view's coordinate system.
    *   $\mathbb{I}(\cdot)$ is the indicator function (1 if true, 0 if false).
    *   $m'_{ij}=1$ indicates an invisible region in the reference view relative to the new view [S1].

4.  **Collaborative RGBD Inpainting:**
    The invisible regions identified by $m'$ are inpainted using Stable Diffusion for RGB and a depth estimator for depth, stitching the result into the panorama [S1].

5.  **Conflicted Region Mask ($m''$):**
    To identify regions in the reference view that conflict with the geometry of the newly inpainted view:
    $$ m''_{ij} = \mathbb{I}(v_{ij} - \text{warp}(v'_{ij}) > \epsilon) $$
    where:
    *   $v_{ij}$ is the depth value in the reference view.
    *   $v'_{ij}$ is the depth value warped from the new view.
    *   $m''_{ij}=1$ indicates inconsistent geometry (conflict) [S1].

6.  **Final Conflict Mask:**
    The final mask for erasing is computed by performing a logic AND operation across the individual conflict masks $m''$ from all reference views in $I_{ref}$ [S1].

**Algorithm Steps:**
1.  Estimate the initial depth map $I_d$ of the input panorama $I_{rgb}$ to obtain $I_{rgbd}$ [S1].
2.  Train a single-view NeRF $f_{nerf}$ using $I_d$ and $I_{rgb}$ for `init_iters` (10,000) iterations [S1].
3.  Generate a trajectory $\{p_k\}$ of novel views based on $I_d$, with 32 positions at gradually increasing distances [S1].
4.  Initialize the reference view set $I_{ref} = \{I_{rgbd}\}$ [S1].
5.  For $n$ from 1 to `iters`:
    a.  Randomly sample a new camera pose $p$ from $\{p_k\}$ [S1].
    b.  Compute the invisible regions in the current reference views relative to $p$ using Eq. (4) [S1].
    c.  Perform collaborative RGBD inpainting on the invisible regions using Stable Diffusion and a depth estimator to generate a completed panorama for view $p$ [S1].
    d.  For each reference view $I_{ref} \in I_{ref}$:
        i.  Compute the conflicted regions between $I_{ref}$ and the new view using Eq. (6) [S1].
        ii. Erase these conflicted regions from the supervision of the NeRF training [S1].
    e.  Add the inpainted new view to $I_{ref}$ [S1].
    f.  Fine-tune $f_{nerf}$ using all views in $I_{ref}$ for `fine_tune_iters` (2,000) iterations. The first 100 iterations use only the new view for supervision; the remaining 1,900 iterations use all reference views [S1].

**Pseudocode:**
```python
def progressive_inpainting_and_erasing(I_rgb):
    # 1. Initial Depth Estimation
    I_d = depth_estimator(I_rgb)
    I_rgbd = combine(I_rgb, I_d)
    
    # 2. Initial NeRF Training
    f_nerf = InstantNGP()
    f_nerf.train(I_rgbd, iterations=10000, optimizer=Adam, lr=1e-3)
    
    # 3. Generate Trajectory
    p_k = generate_trajectory(I_d, num_positions=32)
    
    # 4. Initialize Reference Views
    I_ref = {I_rgbd}
    
    # 5. Progressive Loop
    for n in range(iters):
        # Sample new view
        p = random_sample(p_k)
        
        # Render current NeRF to get depth for new view
        I_d_new = f_nerf.render_depth(p)
        
        # Compute invisible regions in reference views
        # Note: In practice, this involves warping new view depth to reference view coordinates
        invisible_masks = []
        for I_ref_view in I_ref:
            v_ref = I_ref_view.depth
            v_new_warped = warp(I_d_new, p, I_ref_view.pose)
            m_prime = indicator(v_new_warped - v_ref > epsilon)
            invisible_masks.append(m_prime)
            
        # Collaborative RGBD Inpainting
        # Inpaint RGB using Stable Diffusion and Depth using Depth Estimator
        I_new_pano = inpaint_rgb(I_rgb, invisible_masks, model=StableDiffusion)
        I_d_new_pano = inpaint_depth(I_d_new, invisible_masks, model=DepthEstimator)
        I_new_rgbd = combine(I_new_pano, I_d_new_pano)
        
        # Compute conflicted regions and prepare erasing mask
        # Final conflict mask is AND of all individual conflict masks
        final_conflict_mask = None
        for I_ref_view in I_ref:
            v_ref = I_ref_view.depth
            v_new_warped = warp(I_d_new_pano, p, I_ref_view.pose)
            m_double_prime = indicator(v_ref - v_new_warped > epsilon)
            
            if final_conflict_mask is None:
                final_conflict_mask = m_double_prime
            else:
                final_conflict_mask = logical_and(final_conflict_mask, m_double_prime)
        
        # Add new view to reference set
        I_ref.add(I_new_rgbd)
        
        # Fine-tune NeRF
        # First 100 iterations: only new view
        f_nerf.train([I_new_rgbd], iterations=100, optimizer=Adam, lr=1e-3)
        # Remaining 1900 iterations: all reference views, excluding conflicted regions
        f_nerf.train(I_ref, iterations=1900, optimizer=Adam, lr=1e-3, exclude_mask=final_conflict_mask)
        
    return f_nerf
```

**Edge Cases and Pitfalls:**
*   **Depth Estimation Error:** The accuracy of the initial depth map $I_d$ is critical for generating the trajectory $\{p_k\}$ and warping operations. Errors here propagate through the invisible/conflict detection [S1].
*   **Geometry Conflict:** If the inpainted geometry violates the existing NeRF's geometry, the conflict mask $m''$ will identify these regions. Erasing them prevents the NeRF from learning inconsistent structures, but excessive erasing may lead to incomplete geometry [S1].
*   **Convergence:** The method relies on iterative fine-tuning. Insufficient iterations per view may result in poor convergence, while too many may lead to overfitting to the current reference set [S1].

## Operating characteristics
*   **Time Complexity:** The method is iterative, with complexity proportional to the number of iterations `iters` and the number of reference views. Each iteration involves depth estimation, warping, inpainting (Stable Diffusion), and NeRF fine-tuning. Training a scene takes approximately 2 hours on a single Nvidia V100 GPU [S1].
*   **Memory Complexity:** Depends on the Instant-NGP hash grid size ($2^{19}$) and the storage of reference views. The GPU memory usage is reported as 32G for the experiments [S1].
*   **Strengths:** Effectively handles single-view panorama reconstruction by progressively expanding the viewpoint range. The erasing mechanism prevents geometry conflicts between visible and invisible regions, leading to more consistent 3D geometry [S1].
*   **Limitations:** Relies on external models (Stable Diffusion, depth estimator) which may introduce artifacts. The quality of the initial depth estimation is crucial. The method is computationally expensive due to the iterative nature and the use of large generative models [S1].
*   **When to use:** When reconstructing a NeRF from a single panoramic image is required, and consistency with the initial view's geometry is important.
*   **When not to use:** When multiple views are available, or when real-time performance is required.

## Background
PERF was introduced in the paper "PERF: Panoramic Neural Radiance Field From a Single Panorama" [S1]. It addresses the challenge of reconstructing high-quality panoramic NeRFs from a single input, a task that is ill-posed due to the lack of depth information and viewpoint diversity. The method builds on the Instant-NGP representation [S1] and integrates collaborative RGBD inpainting to fill in missing regions. The progressive inpainting-and-erasing strategy is a key contribution, designed to mitigate the geometry conflicts that arise when inpainting invisible regions. The method was evaluated on the Replica dataset and in-the-wild data [S1].
