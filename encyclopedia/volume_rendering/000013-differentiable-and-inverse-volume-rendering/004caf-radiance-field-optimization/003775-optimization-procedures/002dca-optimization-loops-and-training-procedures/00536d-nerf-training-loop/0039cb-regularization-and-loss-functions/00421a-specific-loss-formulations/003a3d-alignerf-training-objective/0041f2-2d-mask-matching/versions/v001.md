# 2D Mask Matching

Also called: Mask IoU Assignment, Multi-view Mask Consistency

## Overview
2D Mask Matching aligns 2D instance segmentation masks predicted independently from different camera views to a consistent set of 3D instances detected by a NeRF-based detector (specifically NeRF-RCNN). It solves the problem of multi-view inconsistency where the same physical object receives different instance IDs or segmentation boundaries across images, which degrades the quality of the instance field in instance-aware NeRF training [S1]. It differs from direct 2D supervision by enforcing 3D consistency through projection, and from refinement methods by establishing the initial consistent ground truth before iterative correction [S1].

## How it works
**Inputs:**
*   A set of $N$ training images with corresponding camera poses.
*   A 3D instance field or coarse mask volume generated by NeRF-RCNN, representing detected 3D instances.
*   A pre-trained panoptic segmentation model (Mask2Former [S1]).
*   A class mapping from COCO categories to the target dataset categories.

**Outputs:**
*   A set of consistently annotated 2D instance masks for each training image, where each mask is assigned to a unique 3D instance ID.
*   A binary mask indicating valid pixels for training (excluding unlabeled areas).

**Data Structures:**
*   **3D Instance Masks:** A set of binary volumes or point clouds $\{M_3^i\}_{i=1}^K$ representing the $K$ detected 3D instances.
*   **2D Predicted Masks:** A list of binary masks $\{m_{2D}^{j}\}_{j=1}^L$ for each image, where $L$ is the number of detected objects in that view.
*   **Assignment Map:** A dictionary or array mapping each 2D mask index to a 3D instance ID.

**Steps:**
1.  **Initial Segmentation:** Run Mask2Former on each input image to obtain initial 2D panoptic segmentation masks [S1].
2.  **Background Filtering:** Filter out masks belonging to background classes using the COCO-to-dataset class mapping [S1].
3.  **3D-to-2D Projection:** For each detected 3D instance $i$, project its 3D mask $M_3^i$ onto the 2D image plane of each training view $v$ using the camera intrinsics and extrinsics. This yields a set of projected 2D masks $\{P_{2D}^{i,v}\}$ [S1].
4.  **IoU Computation:** For each image $v$, compute the Intersection over Union (IoU) between every predicted 2D mask $m_{2D}^{j}$ and every projected 2D mask $P_{2D}^{i,v}$ for all instances $i$ [S1]. The IoU is defined as:
    $$ \text{IoU}(A, B) = \frac{|A \cap B|}{|A \cup B|} $$
    where $A$ and $B$ are binary masks [S1].
5.  **Assignment:** Assign each predicted 2D mask $m_{2D}^{j}$ to the 3D instance $i$ that maximizes the IoU with the projected mask $P_{2D}^{i,v}$ [S1].
6.  **Thresholding:** If the maximum IoU for a predicted mask $m_{2D}^{j}$ is less than or equal to 0.05, the mask is treated as an unlabeled area and excluded from instance field training [S1].
7.  **Consistency Check:** Repeat for all views to ensure that the same 3D instance is assigned the same ID across all views where it is visible [S1].

**Pseudocode:**
```python
def compute_2d_mask_matching(
    images: List[Image],
    camera_poses: List[CameraPose],
    nerf_rcnn_3d_instances: List[Instance3D],
    mask2former_model: Model,
    coco_to_dataset_map: Dict[int, int],
    iou_threshold: float = 0.05
) -> Dict[int, List[AssignedMask]]:
    """
    Aligns 2D masks to 3D instances for multi-view consistency.
    
    Args:
        images: List of input images.
        camera_pososes: List of camera poses corresponding to images.
        nerf_rcnn_3d_instances: List of 3D instances detected by NeRF-RCNN.
        mask2former_model: Pre-trained Mask2Former model.
        coco_to_dataset_map: Mapping from COCO class IDs to dataset class IDs.
        iou_threshold: Minimum IoU for a mask to be considered valid.
        
    Returns:
        A dictionary mapping 3D instance ID to a list of assigned 2D masks 
        and their corresponding image indices.
    """
    consistent_assignments = {}
    
    # Step 1 & 2: Initial Segmentation and Filtering
    for img_idx, (image, pose) in enumerate(zip(images, camera_poses)):
        # Get raw masks from Mask2Former
        raw_masks = mask2former_model.predict(image)
        
        # Filter background masks
        valid_masks = []
        for mask in raw_masks:
            class_id = mask.class_id
            if class_id in coco_to_dataset_map:
                valid_masks.append(mask)
        
        # Step 3: Project 3D instances to 2D
        projected_masks = {}
        for instance in nerf_rcnn_3d_instances:
            # Project 3D mask volume to 2D plane using camera pose
            proj_mask = project_3d_to_2d(instance.mask_3d, pose)
            projected_masks[instance.id] = proj_mask
            
        # Step 4 & 5: Compute IoU and Assign
        for mask in valid_masks:
            max_iou = -1.0
            best_instance_id = None
            
            for inst_id, proj_mask in projected_masks.items():
                # Compute IoU between predicted 2D mask and projected 2D mask
                iou = compute_iou(mask.binary_mask, proj_mask)
                if iou > max_iou:
                    max_iou = iou
                    best_instance_id = inst_id
            
            # Step 6: Thresholding
            if max_iou > iou_threshold:
                if best_instance_id not in consistent_assignments:
                    consistent_assignments[best_instance_id] = []
                consistent_assignments[best_instance_id].append({
                    'image_idx': img_idx,
                    'mask': mask,
                    'iou': max_iou
                })
            else:
                # Treat as unlabeled area, do not participate in training
                pass
                
    return consistent_assignments

def compute_iou(mask_a: BinaryMask, mask_b: BinaryMask) -> float:
    intersection = np.logical_and(mask_a, mask_b).sum()
    union = np.logical_or(mask_a, mask_b).sum()
    if union == 0:
        return 0.0
    return intersection / union
```

**Parameters:**
*   `iou_threshold`: Default 0.05 [S1]. Masks with IoU below this are ignored.
*   `mask2former_model`: Pre-trained on COCO [S1].

**Edge Cases and Pitfalls:**
*   **Low IoU:** Predicted masks with IoU $\le 0.05$ are treated as unlabeled areas and do not participate in training [S1].
*   **Occlusion:** Partially occluded objects may lead to missing or erroneous mask predictions in different views, which can mislead the model if not handled by refinement [S1].
*   **Background:** Masks belonging to background must be filtered out using the class mapping [S1].

## Subtopics

## Operating characteristics
*   **Time Complexity:** Dominated by the Mask2Former inference ($O(N \cdot T_{seg})$) and the projection/IoU computation ($O(K \cdot N \cdot P)$, where $K$ is the number of 3D instances, $N$ is the number of views, and $P$ is the number of pixels).
*   **Memory Complexity:** Requires storing 3D instance masks and 2D projected masks for all views.
*   **Strengths:** Ensures multi-view consistency for instance fields, which is crucial for quality [S1]. Decouples segmentation from NeRF training initially.
*   **Limitations:** Relies on the accuracy of the initial 3D instance detection and the pre-trained segmentation model. May fail on objects with poor visibility or severe occlusion without refinement [S1].
*   **When to use:** When training instance-aware NeRF models (e.g., Instance-NeRF) and multi-view consistency of 2D masks is required.
*   **When not to use:** When only single-view supervision is available or when 3D instance detection is not feasible.

## Background
The method was introduced in the context of Instance Neural Radiance Field (Instance-NeRF) to address the inconsistency of 2D instance masks across different views [S1]. It builds on NeRF-RCNN for 3D instance detection and Mask2Former for 2D segmentation [S1]. The approach is part of a pipeline that includes 2D mask refinement to handle occlusions and partial visibility [S1].
