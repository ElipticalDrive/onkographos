# Guided Optimization of NeRF

Also called: Confidence-Based Depth Filtering

## Overview
Guided Optimization of NeRF mitigates the shape-radiance ambiguity inherent in Neural Radiance Fields (NeRF) for indoor scenes by restricting the spatial domain where samples are drawn along camera rays [S1]. Unlike standard NeRF, which samples uniformly between fixed near/far bounds, this method uses adapted monocular depth priors and multi-view consistency errors to define adaptive sampling ranges $[t_n, t_f]$ centered on the estimated depth [S1]. It further refines the resulting depth map using confidence scores derived from RGB reconstruction errors and plane bilateral filtering [S1].

## How it works
**Inputs:** $N$ input views with RGB images and camera intrinsics $K$; adapted monocular depth priors $\{D^i\}_{i=1}^N$ for each view; NeRF network parameters $\theta$.
**Outputs:** Optimized NeRF network $\theta$; refined depth maps $\{D^i\}_{i=1}^N$; rendered RGB images.

**Data Structures:**
*   **Adapted Depth Priors:** A set of $N$ depth maps, one per input view.
*   **Error Maps:** A set of $N$ 2D maps $\{e_i\}$, where $e_i$ is the scalar error value for each pixel in view $i$.
*   **Confidence Scores:** A set of $N$ 2D maps $\{S^i\}$, where $S^i_j$ is the confidence for pixel $j$ in view $i$.
*   **NeRF Model:** A multi-layer perceptron (MLP) $F_\theta: (\mathbf{x}, \mathbf{d}) \rightarrow (c, \sigma)$, where $\mathbf{x}$ is position, $\mathbf{d}$ is direction, $c$ is color, and $\sigma$ is density [S1].

**Parameters:**
*   $K=4$: Number of minimum cross-view depth projection errors used to calculate the error map value [S1].
*   $\alpha_l = 0.05$: Lower bound for the relative sampling range [S1].
*   $\alpha_h = 0.15$: Higher bound for the relative sampling range [S1].
*   $M$: Number of sample bins per ray (standard NeRF parameter) [S1].

**Steps:**

1.  **Acquire Adapted Depth Priors:** Obtain initial depth estimates $\{D^i\}_{i=1}^N$ for the $N$ input views using a monocular depth network (e.g., Mannequin Challenge architecture) fine-tuned on the target scene [S1].
2.  **Compute Error Maps:**
    *   For each pair of views $(i, j)$, project the depth map $D^i$ from view $i$ to view $j$ using camera intrinsics $K$ and relative pose $T^{i \rightarrow j}$ to obtain projected coordinates $p^{i \rightarrow j}$ and depths $D^{i \rightarrow j}$ [S1].
    *   Sample the depth map of view $j$ at these coordinates to get $D^{j'} = D^j(p^{i \rightarrow j})$ [S1].
    *   Calculate the reprojection error for each pixel.
    *   For each view $i$, compute the error map $e_i$ as the average of the top $K$ minimum cross-view depth projection errors for each pixel [S1].
3.  **Calculate Adaptive Sample Ranges:** For each ray $\mathbf{r}$ corresponding to a pixel in view $i$, determine the near bound $t_n$ and far bound $t_f$ using the adapted depth prior $D$ and error map value $e$ for that pixel:
    $$t_n = D(1 - \text{clamp}(e, \alpha_l, \alpha_h))$$
    $$t_f = D(1 + \text{clamp}(e, \alpha_l, \alpha_h))$$
    where $\text{clamp}(x, a, b)$ restricts $x$ to the interval $[a, b]$ [S1].
4.  **Stratified Sampling:** Partition the interval $[t_n, t_f]$ into $M$ bins. For each bin $i \in [1, M]$, sample a point $t_i$ uniformly:
    $$t_i \sim \mathcal{U} \left[ t_n + \frac{i-1}{M}(t_f - t_n), \,\, t_n + \frac{i}{M}(t_f - t_n) \right]$$
    [S1].
5.  **Volume Rendering:** Query the NeRF network $F_\theta$ at each sample point $t_i$ to get density $\sigma_i$ and color $c_i$. Compute accumulated transmittance $T_i = \exp \left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$ where $\delta_i = t_{i+1} - t_i$ [S1]. Render the color $C(\mathbf{r})$ and depth $D(\mathbf{r})$:
    $$C(\mathbf{r}) = \sum_{i=1}^{M} T_i (1 - e^{-\sigma_i \delta_i}) c_i$$
    $$D(\mathbf{r}) = \sum_{i=1}^{M} T_i (1 - e^{-\sigma_i \delta_i}) t_i$$
    [S1].
6.  **Compute Confidence Scores:** For each pixel $j$ in view $i$, calculate the confidence score $S^i_j$ based on the $L_1$ difference between the ground truth RGB image $C_{gt}^i(j)$ and the rendered RGB image $C_{render}^i(j)$, normalized by 255:
    $$S^i_j = 1 - \frac{1}{3} \| C_{gt}^i(j) - C_{render}^i(j) \|_1$$
    [S1].
7.  **Refine Depth Map:** Apply plane bilateral filtering to the rendered depth map $D(\mathbf{r})$, weighted by the confidence scores $S^i_j$, to produce the final output depth map [S1].

## Subtopics

### ENeRF with Guided Sampling Training
A variant that integrates pixel and depth-guided ray sampling into the Efficient NeRF (ENeRF) framework [S2]. It samples fewer rays per iteration than standard ENeRF, achieving improved performance with lower GPU memory usage [S2]. It uses a total loss $\mathcal{L} = \mathcal{L}_{mse} + \lambda' \mathcal{L}_{perc}$, where $\mathcal{L}_{mse} = \frac{1}{N_r} \sum_{i=1}^{N_r} \| \hat{C}_i - C_i \|^2$ and $\mathcal{L}_{perc} = \frac{1}{N_i} \sum_{i=1}^{N_i} \| \Phi(\hat{I}_i) - \Phi(I_i) \|$ [S2]. The perceptual loss weight $\lambda'$ is set to 0.01 [S2]. It is used for generalization on DTU, Real Forward-facing, NeRF Synthetic, ZJU-MoCap, and digital human datasets [S2].

## Operating characteristics
*   **Time Complexity:** Depends on the number of views $N$, samples $M$, and training iterations. The multi-view consistency check adds overhead proportional to $N^2$ projections per iteration or pre-computation step [S1].
*   **Memory Complexity:** Standard NeRF memory usage plus storage for $N$ depth priors and error maps [S1]. The ENeRF variant reduces GPU memory usage by sampling fewer rays [S2].
*   **Strengths:** Mitigates shape-radiance ambiguity in poorly textured indoor scenes (e.g., walls) where standard NeRF fails [S1]. Produces accurate depth maps and improves view synthesis quality compared to original NeRF [S1].
*   **Limitations:** Relies on the quality of adapted monocular depth priors. Applying existing correspondence-based neural optimization (like CVD) to these priors can degrade quality due to unreliable flow correspondences in poorly textured regions [S1].
*   **When to use:** Indoor scenes with texture-less regions where accurate depth estimation is required.
*   **When not to use:** Scenes with rich textures where standard NeRF performs well, or when high-quality monocular depth priors are unavailable.

## Background
Neural Radiance Fields (NeRF) were initially proposed in [33] [S1]. The shape-radiance ambiguity, where incorrect geometry can still produce high-quality rendered images, is a known issue, particularly in poorly textured areas common in indoor environments [S1]. This method was introduced to address this by guiding NeRF sampling with adapted depth priors [S1]. The monocular depth network used is based on the Mannequin Challenge architecture [S1].
