# Single-view NeRF Training with Depth Map

Also called: Depth-guided Single-view NeRF, Single-view NeRF with Depth Initialization

## Overview
This method addresses the under-constrained optimization problem of single-view 3D reconstruction by initializing the geometry of visible regions using a 360-degree depth estimation [S1]. It sets itself apart from sibling methods like [Depth-Supervised NeRF](8687-depth-supervised-nerf.md) by explicitly handling the scale ambiguity and misalignment inherent in projecting a single panorama into multiple perspective views for depth estimation, using a deformable alignment step to create a canonical depth map before NeRF training [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A single input RGB panorama $I_{\text{rgb}}$.
*   **Output:** A trained NeRF model $f_{\text{nerf}}$ that represents the 3D geometry and appearance of the visible regions of the scene [S1].

**Data Structures**
*   **Perspective Projections:** A set of $K$ perspective images $\{\bar{I}_{\text{rgb}}^k\}_{k=1}^K$ and their corresponding estimated depth maps $\{\bar{I}_d^k\}_{k=1}^K$.
*   **Canonical Depth Map:** A learnable panorama depth map $I_d$ with pixel values $v$.
*   **Alignment Parameters:** For each perspective view $k$, a global scale factor $w_k$ and local bias fields $\{b_{k,i,j}\}$ [S1].
*   **Coordinate Mapping:** A projective operation $M$ that maps perspective image coordinates $(i,j)$ to panorama image coordinates [S1].

**Numbered Steps**

1.  **Perspective Projection:** Project the single input panorama $I_{\text{rgb}}$ into $K$ perspective images $\{\bar{I}_{\text{rgb}}^k\}$ using different viewing directions. The standard value for $K$ is 20 [S1]. This is necessary because existing monocular depth estimators are trained on limited field-of-view images and do not work directly on 360-degree panoramas warped into rectangular matrices [S1].

2.  **Depth Estimation:** Use a monocular depth estimation model (e.g., [52] in the source) to estimate depth values for each perspective image $\bar{I}_{\text{rgb}}^k$, obtaining the set of perspective depth maps $\{\bar{I}_d^k\}$ [S1]. Note that due to scale ambiguity in single-view depth estimation, estimated depth values in overlapped regions between different perspectives may differ significantly [S1].

3.  **Deformable Alignment:** Perform a deformable alignment to jointly align the perspective depth maps $\{\bar{I}_d^k\}$ to a canonical learnable panorama depth map $I_d$. This step resolves scale and bias inconsistencies by optimizing the following objective function [S1]:

    $$
    \sum_{k,i,j} \left\| \bar{v}_{i,j}^k w_k + b_{k,i,j} - v_{M(i,j)} \right\| + L_s(b_{i,j+1}, b_{i,j}) + L_s(b_{i+1,j}, b_{i,j})
    $$

    Where:
    *   $\bar{v}_{i,j}^k$ is the pixel value of the perspective depth map $\bar{I}_d^k$ at coordinates $(i,j)$.
    *   $w_k$ is the scale value for view $k$.
    *   $b_{k,i,j}$ is the local bias value for view $k$ at coordinates $(i,j)$.
    *   $v_{M(i,j)}$ is the pixel value of the canonical panorama depth map $I_d$ at the mapped coordinates.
    *   $L_s$ is the smooth L1 loss, serving as a total variation term to enforce spatial smoothness on the bias fields [S1].

4.  **NeRF Training:** Train the single-view NeRF using the RGB panorama $I_{\text{rgb}}$ and the aligned canonical depth map $I_d$. The NeRF is optimized by minimizing the combined color and depth reconstruction loss $L'_{\text{nerf}}$ [S1]:

    $$
    L'_{\text{nerf}} = \sum_{r \in R} \left( \|\hat{C}(r) - C(r)\|^2 + \|\hat{D}(r) - \bar{D}(r)\|^2 \right)
    $$

    Where:
    *   $R$ is the set of sampled rays.
    *   $\hat{C}(r)$ is the expected pixel color rendered by the NeRF for ray $r$.
    *   $C(r)$ is the ground-truth pixel color from the input panorama.
    *   $\hat{D}(r)$ is the expected depth value rendered by the NeRF for ray $r$.
    *   $\bar{D}(r)$ is the corresponding depth pixel computed by the depth estimator (derived from the aligned depth map $I_d$) [S1].

**Pseudocode**

```python
def single_view_nerf_with_depth_map(I_rgb, K=20):
    """
    Trains a NeRF from a single panorama using depth-guided initialization.
    
    Args:
        I_rgb: Input RGB panorama image.
        K: Number of perspective projections (default 20).
        
    Returns:
        f_nerf: Trained NeRF model.
    """
    
    # Step 1: Project panorama to K perspective views
    perspective_images = []
    for k in range(K):
        # Project I_rgb into perspective view k
        # Implementation depends on specific projection geometry (e.g., equirectangular to perspective)
        img_k = project_perspective(I_rgb, direction=k)
        perspective_images.append(img_k)
        
    # Step 2: Estimate depth for each perspective view
    perspective_depth_maps = []
    for img_k in perspective_images:
        # Use a monocular depth estimator (e.g., model [52])
        # Note: Estimator must handle limited FOV
        depth_k = monocular_depth_estimator(img_k)
        perspective_depth_maps.append(depth_k)
        
    # Step 3: Deformable Alignment to canonical depth map I_d
    # Initialize learnable canonical depth map I_d and alignment parameters
    I_d = initialize_canonical_depth_map()
    scales = [1.0] * K  # Initial scale factors w_k
    biases = [zeros_like(I_d) for _ in range(K)]  # Initial local bias fields b_k,i,j
    
    # Optimize alignment parameters to minimize Eq. (2)
    # Loss = sum_k sum_i,j || v_bar_k * w_k + b_k - v_M || + TV(bias)
    optimizer = Optimizer(params=I_d + scales + biases)
    
    for iteration in range(num_alignment_iterations):
        alignment_loss = 0.0
        for k in range(K):
            w_k = scales[k]
            b_k = biases[k]
            v_bar_k = perspective_depth_maps[k]
            
            # Map perspective coordinates to panorama coordinates
            # M maps (i,j) from perspective view k to panorama coordinates
            mapped_coords = map_to_perspective(v_bar_k, view_index=k)
            
            # Get corresponding pixel values from canonical map I_d
            v_M = sample_at_coords(I_d, mapped_coords)
            
            # Data alignment term: || v_bar * w + b - v_M ||
            # Using L2 or L1 norm as per source Eq (2) which uses ||...||
            # Source implies L2 for the first term based on standard notation, 
            # but L1/L2 mix is common. Source Eq 2 uses ||...|| without subscript, 
            # typically L2 in this context unless specified. 
            # However, L_s is explicitly smooth L1. 
            # We assume L2 for the data term as is standard for ||...||^2 in optimization,
            # though source Eq 2 does not show squared. 
            # Re-reading source: "||v_bar...||" usually implies L2 norm magnitude.
            # Let's stick to the source's explicit notation.
            data_term = norm(v_bar_k * w_k + b_k - v_M)
            alignment_loss += data_term
            
            # Total Variation (Smooth L1) on biases
            # L_s(b_i+1,j, b_i,j) + L_s(b_i,j+1, b_i,j)
            tv_loss = smooth_l1_loss(b_k[:, 1:, :], b_k[:, :-1, :]) + \
                      smooth_l1_loss(b_k[1:, :, :], b_k[:-1, :, :])
            alignment_loss += tv_loss
            
        optimizer.step(alignment_loss)
        
    # Step 4: Train NeRF with RGB and Aligned Depth
    # Initialize NeRF model f_nerf
    f_nerf = initialize_nerf()
    
    # Define combined loss L'_nerf
    def nerf_loss(rays):
        # Render color and depth from NeRF
        C_hat = render_color(f_nerf, rays)
        D_hat = render_depth(f_nerf, rays)
        
        # Get ground truth color from panorama
        C_gt = sample_color_from_perspective(I_rgb, rays)
        
        # Get depth from aligned canonical map I_d
        # D_bar is computed by the depth estimator, which corresponds to I_d here
        D_gt = sample_depth_from_perspective(I_d, rays)
        
        color_loss = squared_error(C_hat, C_gt)
        depth_loss = squared_error(D_hat, D_gt)
        
        return color_loss + depth_loss
        
    # Optimize NeRF parameters
    nerf_optimizer = Optimizer(params=f_nerf.parameters())
    for iteration in range(num_nerf_iterations):
        rays = sample_rays_from_perspective(I_rgb)
        loss = nerf_loss(rays)
        nerf_optimizer.step(loss)
        
    return f_nerf
```

**Edge Cases and Pitfalls**
*   **Scale Ambiguity:** Monocular depth estimation suffers from scale ambiguity. The deformable alignment step is critical to resolve this by learning scale factors $w_k$ and biases $b_k$ [S1].
*   **FOV Limitations:** Standard depth estimators are trained on limited FOV images. Direct application to panoramas fails, necessitating the projection into $K$ perspective views [S1].
*   **Visible Regions Only:** Since only a single panorama is available, the trained NeRF $f_{\text{nerf}}$ only accurately represents visible regions. Invisible regions require additional completion steps (e.g., inpainting) not covered in this specific training loop [S1].

## Operating characteristics
*   **Complexity:** The method adds an initial alignment phase involving $K$ depth estimations and an optimization loop for deformable alignment before the main NeRF training. The complexity is dominated by the depth estimation model inference and the iterative alignment optimization.
*   **Strengths:** Provides accurate geometry reconstruction for visible regions in single-view scenarios by leveraging depth supervision, addressing the under-constrained nature of the problem [S1].
*   **Limitations:** The resulting NeRF is limited to visible regions; invisible areas are not reconstructed by this specific method and require separate inpainting techniques [S1]. Performance depends heavily on the accuracy of the underlying monocular depth estimator [S1].

## Background
This method originates from the work on PERF (Panoramic Neural Radiance Field From a Single Panorama) [S1]. It was developed to enable photo-realistic panoramic NeRF reconstruction from a single view, allowing users to roam in complex scenes. The approach builds on 360MonoDepth [51] for depth estimation and integrates it with NeRF training [S1].
