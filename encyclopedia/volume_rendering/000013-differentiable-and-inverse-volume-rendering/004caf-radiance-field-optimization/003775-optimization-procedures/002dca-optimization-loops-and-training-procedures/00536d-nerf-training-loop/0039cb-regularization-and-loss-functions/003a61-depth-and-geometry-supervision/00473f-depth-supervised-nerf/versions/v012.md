# Depth-Supervised NeRF

Also called: DS-NeRF

## Overview
Depth-Supervised NeRF (DS-NeRF) is a training procedure for Neural Radiance Fields that incorporates sparse 3D depth priors from Structure-from-Motion (SfM) to accelerate convergence and improve reconstruction quality with fewer input views [S1, S2][S3, unofficial]. It solves the problem of NeRF overfitting to incorrect geometries when data is sparse by enforcing that the rendered ray termination distribution aligns with the surface locations estimated by SfM [S1]. Unlike methods relying on category-specific priors or dense multi-view stereo (MVS) initialization, DS-NeRF requires no additional training data distribution assumptions and leverages "free" depth signals already generated during standard camera pose estimation [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ input images $\{I_j\}$, camera poses $\{P_j\}$ (intrinsic and extrinsic), and a sparse 3D point cloud $\{X\}$ with visibility flags generated by an SfM solver (e.g., COLMAP) [S1][S3, unofficial].
*   **Outputs:** A trained NeRF model $\theta$ (MLP parameters for density $\sigma$ and color $c$) [S1].

**Data Structures:**
*   **Keypoints:** A set of 3D points $X = \{x_1, \dots, x_M\} \subset \mathbb{R}^3$ [S1].
*   **Visibility:** For each image $j$, a subset $X_j \subset X$ of keypoints visible from camera $P_j$ [S1].
*   **Depth Uncertainty:** For each keypoint $x_i$, a scalar $\hat{\sigma}_i$ representing the average reprojection error across all views where $x_i$ was detected [S1].

**Numbered Steps:**

1.  **SfM Preprocessing:** Run an SfM pipeline (e.g., COLMAP) on the input images to estimate camera parameters and generate the sparse 3D point cloud $X$ [S1][S3, unofficial].
2.  **Depth Estimation:** For each training image $I_j$ with camera $P_j$, identify visible keypoints $X_j$. For each $x_i \in X_j$, compute the projected depth $D_{ij}$ by projecting $x_i$ with $P_j$ and taking the re-projected z-value in camera coordinates [S1].
3.  **Uncertainty Calculation:** Compute the depth uncertainty $\hat{\sigma}_i$ for each keypoint $x_i$ as the average reprojection error across all views where the keypoint was detected [S1].
4.  **Ray Allocation:** For each training iteration, allocate a portion of the total training rays to "keypoint rays" [S1].
5.  **Keypoint Ray Generation:** For each allocated keypoint ray corresponding to image $I_j$ and keypoint $x_i$:
    *   Calculate the ray origin in local camera coordinates from the image coordinates of $x_i$ [S1].
    *   Set the camera axis coordinate to -1 to define the ray direction pointing into the scene [S1].
    *   Interpolate the RGB color value $\mathbf{C}(x_i)$ from the input image $I_j$ at the keypoint's pixel location [S1].
6.  **Volume Rendering:** Shoot the keypoint rays into the scene using the standard NeRF sampling procedure (uniform or importance sampling between near $t_n$ and far $t_f$ bounds) [S1]. Compute the rendered color $\widehat{\mathcal{C}}(\mathbf{r})$ and the ray termination distribution $h(t)$ [S1].
    *   The ray termination distribution is defined as $h(t) = T(t)\sigma(t)$, where $T(t) = \exp(-\int_0^t \sigma(s)ds)$ is the accumulated transmittance [S1].
    *   Note: $h(t)$ is a valid probability distribution over $t \in [0, \infty)$ assuming $\sigma(t) \ge 0$ and $\int_0^\infty \sigma(s)ds = \infty$ (often enforced by treating $t_f$ as an opaque wall) [S1].
7.  **Loss Computation:** Compute the total loss $\mathcal{L}$ [S1]:
    $$ \mathcal{L} = \mathcal{L}_{\text{Color}} + \lambda_D \mathcal{L}_{\text{Depth}} $$
    *   **Color Loss:** Standard photometric loss for the keypoint rays:
        $$ \mathcal{L}_{\text{Color}} = \|\widehat{\mathcal{C}}(\mathbf{r}) - \mathbf{C}(x_i)\|_2^2 $$
        [S1]
    *   **Depth Loss:** Minimize the KL divergence between the rendered distribution $h(t)$ and a Gaussian distribution $\mathcal{N}(D_{ij}, \hat{\sigma}_i)$ modeling the noisy keypoint depth [S1]. This is approximated as:
        $$ \mathcal{L}_{\text{Depth}} = \sum_{k} -\log h_k \exp \left( -\frac{(t_k - D_{ij})^2}{2\hat{\sigma}_i^2} \right) \Delta t_k $$
        where $t_k$ are the sample points along the ray, $h_k = h(t_k)$, and $\Delta t_k$ is the step size [S1].
        *   *Alternative:* Some implementations use Mean Squared Error (MSE) between rendered depth and $D_{ij}$, but KL divergence yields fewer artifacts [S1][S3, unofficial].
8.  **Optimization:** Backpropagate gradients through the volume rendering process to update NeRF parameters $\theta$ [S1].

**Pseudocode:**

```python
def train_ds_nerf(images, poses, keypoints, uncertainties, num_iterations, lambda_d):
    """
    images: List of input images.
    poses: Camera poses for each image.
    keypoints: 3D points from SfM.
    uncertainties: Reprojection errors for each keypoint.
    lambda_d: Weight for depth loss.
    """
    nerf_model = initialize_nerf()
    
    for iteration in range(num_iterations):
        # 1. Allocate rays
        rays, gt_colors = sample_training_rays(images, poses)
        
        # 2. Identify keypoint rays
        keypoint_rays, keypoint_gt_colors = [], []
        keypoint_depths, keypoint_sigmas = [], []
        
        for img_idx, img in enumerate(images):
            visible_kps = get_visible_keypoints(keypoints, poses[img_idx])
            for kp in visible_kps:
                # Generate ray from keypoint image coordinates
                ray = generate_ray_from_keypoint(img, kp, poses[img_idx])
                keypoint_rays.append(ray)
                keypoint_gt_colors.append(interpolate_color(img, kp))
                keypoint_depths.append(project_depth(kp, poses[img_idx]))
                keypoint_sigmas.append(uncertainties[kp])
                
        # Combine regular rays and keypoint rays for batch processing
        all_rays = rays + keypoint_rays
        all_gt_colors = gt_colors + keypoint_gt_colors
        
        # 3. Forward pass (Volume Rendering)
        # Render colors and depth distributions for all rays
        rendered_colors, h_t, t_samples, dt_samples = volume_render(nerf_model, all_rays)
        
        # 4. Compute Losses
        # Color loss for all rays
        color_loss = mean_squared_error(rendered_colors, all_gt_colors)
        
        # Depth loss only for keypoint rays
        depth_loss = 0.0
        num_regular = len(rays)
        for i in range(len(keypoint_rays)):
            idx = num_regular + i
            h_k = h_t[idx]
            t_k = t_samples[idx]
            dt_k = dt_samples[idx]
            d_ij = keypoint_depths[i]
            sigma_i = keypoint_sigmas[i]
            
            # KL Divergence approximation: sum over samples
            # L_depth = sum( -log(h(t)) * exp(-(t - D)^2 / 2*sigma^2) * dt )
            term = -log(h_k + 1e-8) * exp(-((t_k - d_ij)**2) / (2 * sigma_i**2))
            depth_loss += sum(term * dt_k)
            
        depth_loss /= len(keypoint_rays)
        
        total_loss = color_loss + lambda_d * depth_loss
        
        # 5. Backpropagate
        gradients = compute_gradients(total_loss, nerf_model)
        update_parameters(nerf_model, gradients)
        
    return nerf_model
```

**Parameters:**
*   $\lambda_D$: Hyper-parameter balancing color and depth supervision. Typically set to 1 [S1, S4].
*   $t_n, t_f$: Near and far clipping planes. $t_f$ is often treated as an opaque wall to ensure $\int h(t)dt = 1$ [S1].
*   Training Iterations: $O(10k - 100k)$ [S3, unofficial].
*   Image Resolution: Often down-sampled to $400 \times 300$ for training [S1].

**Edge Cases and Pitfalls:**
*   **SfM Failure:** Optimization fails if SfM produces poor depth estimates or inaccurate depth measurements [S1].
*   **Gaussian Assumption:** The method assumes a Gaussian distribution models keypoint uncertainty, which may not hold for depth from non-SfM sources [S1].
*   **Domain Gap:** Methods pre-trained on specific domains (e.g., DTU) may struggle on others (e.g., NeRF Real) if combined with DS-NeRF, though DS-NeRF itself generalizes better than data-driven priors [S1].
*   **MVSNeRF Compatibility:** Adding depth supervision did not improve MVSNeRF because it already has a geometry prior from PSV initialization [S1].

## Operating characteristics
*   **Time Complexity:** Training iterations are reduced by 2-3x compared to standard NeRF to reach the same PSNR [S1]. Wall-clock time per iteration is comparable ($\sim 362.4$ ms vs $\sim 359.8$ ms on RTX A5000) [S1].
*   **Memory Complexity:** No significant additional memory overhead beyond storing the sparse point cloud and visibility flags, which are small relative to the NeRF model [S1].
*   **Performance:** On the NeRF Real dataset with 5 input views, DS-NeRF achieves a test PSNR of 22.6 (100% keypoints) compared to NeRF's 18.2 [S1]. It accelerates training by 2-3x, achieving peak PSNR ~13 hours faster in 5-view setups [S1].
*   **Strengths:** Works with few views (2-10 views); compatible with other NeRF methods (e.g., pixelNeRF, IBRNet); requires no additional training data or category priors [S1].
*   **Limitations:** Dependent on the quality of SfM; does not improve methods that already have strong geometric priors (e.g., MVSNeRF) [S1].

## Background
*   **Origin:** Introduced by Deng et al. in 2022 [S1].
*   **History:** Developed to address the failure mode of NeRF fitting incorrect geometries with insufficient input views [S1]. It leverages the fact that SfM pipelines (like COLMAP) are already standard in NeRF preprocessing, providing "free" depth supervision [S1].
*   **Usage:** Applied to LLFF, NeRF Real, Redwood-3dscan, and DTU datasets [S1].
