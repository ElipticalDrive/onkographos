# Patch-Based Depth Regularization

Also called: Bilateral Depth Regularization, Bilateral filter regularization, Joint Bilateral Depth Regularization, Joint bilateral filter regularization

## Overview
Patch-Based Depth Regularization is a technique applied during Neural Radiance Field (NeRF) training to enforce geometric consistency by smoothing rendered depth maps while preserving sharp structural edges [S1]. It distinguishes itself from sibling methods like RegNeRF’s patch similarity constraints by utilizing bilateral or joint bilateral filters, which explicitly account for spatial proximity and intensity/depth similarity to reduce noise without blurring boundaries [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A set of rendered depth patches $P$ extracted from the NeRF’s depth output $\hat{D}$ [S1].
*   **Output:** A scalar regularization loss $L_{reg}$ added to the total training loss [S1].

**Data Structures**
*   **Depth Patch $\hat{D}(p)$:** A 2D tensor of shape $(H_p, W_p)$ containing depth values for a specific patch $p$ [S1].
*   **Set $P$:** The collection of all patches sampled from the rendered depth map during a training step [S1].
*   **Filter Kernel:** Defined by spatial sigma $\sigma_{space}$ and range sigma $\sigma_{color}$ [S1].

**Parameters**
*   **Patch Size:** $16 \times 16$ pixels [S1]. Larger sizes (32, 64) cause undertraining and excessive compute time [S1].
*   **Kernel Size:** $9 \times 9$ [S1].
*   **Spatial Sigma ($\sigma_{space}$):** $75 \times 75$ (defines spatial extent) [S1].
*   **Range Sigma ($\sigma_{color}$):** $10$ (controls intensity/depth similarity) [S1].
*   **Weight ($\lambda_{reg}$):** $10^{-7}$ [S1].
*   **Color Weight ($\lambda_{color}$):** $1$ (used in joint bilateral filter) [S1].

**Algorithm Steps**
1.  **Pre-training:** Train the NeRF model to convergence using only photometric (RGB) loss [S1].
2.  **Patch Sampling:** Extract patches $p \in P$ from the rendered depth map $\hat{D}$ [S1].
3.  **Filtering:** Apply a bilateral or joint bilateral filter $F$ to each patch $\hat{D}(p)$ to produce a filtered patch $F(\hat{D}(p))$ [S1].
    *   *Bilateral Filter:* Weights pixels based on spatial distance and depth difference [S1].
    *   *Joint Bilateral Filter:* Weights pixels based on spatial distance, depth difference, and RGB intensity similarity in the corresponding view [S1].
4.  **Loss Calculation:** Compute the Mean Squared Error (MSE) between the original depth patch and the filtered patch for all pixels in the patch, then average over all patches [S1].

**Formula**
The regularization loss is defined as:

$$
L_{reg} = \frac{1}{|P|} \sum_{p \in P} \frac{1}{|p|} \sum_{i,j} \| \hat{D}(p_{ij}) - F(\hat{D}(p))_{ij} \|^2
$$

Where:
*   $|P|$ is the number of patches [S1].
*   $|p|$ is the number of pixels in patch $p$ [S1].
*   $\hat{D}(p_{ij})$ is the original depth value at pixel $(i,j)$ in patch $p$ [S1].
*   $F(\hat{D}(p))_{ij}$ is the filtered depth value at pixel $(i,j)$ in patch $p$ [S1].

**Pseudocode**
```python
import math

def patch_based_depth_regularization(depth_map, patches, lambda_reg, sigma_space=75.0, sigma_color=10.0, use_joint=False, rgb_map=None):
    """
    Computes the patch-based depth regularization loss.
    """
    total_loss = 0.0
    num_patches = len(patches)
    
    for p in patches:
        if use_joint and rgb_map is not None:
            rgb_p = extract_rgb_patch(rgb_map, p.coords)
            filtered_p = joint_bilateral_filter(p.values, rgb_p, sigma_space, sigma_color)
        else:
            filtered_p = bilateral_filter(p.values, sigma_space, sigma_color)
            
        mse = 0.0
        h, w = len(p.values), len(p.values[0])
        for i in range(h):
            for j in range(w):
                diff = p.values[i][j] - filtered_p[i][j]
                mse += diff * diff
        mse /= (h * w)
        total_loss += mse
        
    return (total_loss / num_patches) * lambda_reg

def extract_rgb_patch(rgb_map, coords):
    # Returns the RGB tensor corresponding to the patch coordinates
    return rgb_map[coords.y1:coords.y2, coords.x1:coords.x2]

def bilateral_filter(depth_patch, sigma_space, sigma_color):
    h, w = len(depth_patch), len(depth_patch[0])
    filtered = [[0.0] * w for _ in range(h)]
    kernel_radius = 4  # 9x9 kernel
    
    for y in range(h):
        for x in range(w):
            numerator = 0.0
            denominator = 0.0
            for dy in range(-kernel_radius, kernel_radius + 1):
                for dx in range(-kernel_radius, kernel_radius + 1):
                    ny, nx = y + dy, x + dx
                    if 0 <= ny < h and 0 <= nx < w:
                        spatial_dist = dy**2 + dx**2
                        depth_diff = (depth_patch[y][x] - depth_patch[ny][nx])**2
                        # Standard bilateral weight calculation [G]
                        weight = math.exp(-(spatial_dist / (2 * sigma_space**2)) - (depth_diff / (2 * sigma_color**2)))
                        numerator += weight * depth_patch[ny][nx]
                        denominator += weight
            filtered[y][x] = numerator / denominator if denominator > 0 else depth_patch[y][x]
    return filtered

def joint_bilateral_filter(depth_patch, rgb_patch, sigma_space, sigma_color):
    h, w = len(depth_patch), len(depth_patch[0])
    filtered = [[0.0] * w for _ in range(h)]
    kernel_radius = 4
    
    for y in range(h):
        for x in range(w):
            numerator = 0.0
            denominator = 0.0
            for dy in range(-kernel_radius, kernel_radius + 1):
                for dx in range(-kernel_radius, kernel_radius + 1):
                    ny, nx = y + dy, x + dx
                    if 0 <= ny < h and 0 <= nx < w:
                        spatial_dist = dy**2 + dx**2
                        depth_diff = (depth_patch[y][x] - depth_patch[ny][nx])**2
                        # RGB intensity difference for joint range weighting [G]
                        rgb_diff = sum((rgb_patch[y][x][c] - rgb_patch[ny][nx][c])**2 for c in range(3))
                        weight = math.exp(-(spatial_dist / (2 * sigma_space**2)) - (depth_diff / (2 * sigma_color**2)) - (rgb_diff / (2 * sigma_color**2)))
                        numerator += weight * depth_patch[ny][nx]
                        denominator += weight
            filtered[y][x] = numerator / denominator if denominator > 0 else depth_patch[y][x]
    return filtered
```

**Edge Cases and Pitfalls**
*   **Training Time:** Adding patch-based regularization significantly increases training time. Models using this method converged in 280,000 iterations, compared to 200,000 for photometric-only training [S1].
*   **Patch Size Sensitivity:** Larger patches (32x32, 64x64) remain undertrained even after 400,000 iterations and drastically increase compute cost [S1].
*   **Occlusion:** Performance may degrade in scenes with significant occlusions (e.g., large furniture) where ray coverage is limited [S1].
*   **Implementation:** The method relies on open-source libraries like Kornia for filter implementation [S1].

## Operating characteristics
*   **Time Complexity:** Significantly higher than standard NeRF training due to the additional filtering step per patch and the need for longer training durations (280,000 iterations vs 200,000) [S1].
*   **Memory Complexity:** Increases with the number of patches and patch size. Larger patches require more memory for intermediate filter computations [S1].
*   **Performance:** Outperforms RegNeRF’s depth patch regularization in indoor scenes by reducing noise while preserving sharp edges [S1]. Joint bilateral filtering provides additional gains over standard bilateral filtering [S1].
*   **Strengths:** Effective at mitigating rendering irregularities beyond planar architectural surfaces while preserving structural details [S1].
*   **Limitations:** Computationally expensive; sensitive to patch size; less effective in highly occluded areas [S1].
*   **When to Use:** Indoor scenes with planar architectural surfaces where geometric consistency is critical and computational resources allow for extended training [S1].

## Background
The method was proposed in "Improving Geometric Consistency for 360-Degree Neural Radiance Fields in Indoor Scenarios" (2025) [S1]. It builds on the concept of depth regularization introduced in RegNeRF (Niemeyer et al., 2022) but replaces simple patch similarity constraints with bilateral and joint bilateral filters [S1]. The bilateral filter was originally introduced by Tomasi and Manduchi (1998), and the joint bilateral filter by He et al. (2012) [S1]. The implementation was tested using Instant-NGP within the Nerfstudio framework [S1].
