# Geometric Baseline Regularization

Also called: Geometric Baseline, Geometric Loss

## Overview
Geometric Baseline Regularization is a composite loss function designed to prevent degenerate solutions in Neural Radiance Field (NeRF) optimization, particularly in few-view settings where models may collapse to copying training images [S1]. It combines photometric reconstruction with three geometric priors: foreground completeness, frustum consistency, and depth distribution compactness [S1]. It serves as a strong baseline for differentiable volume rendering optimization, distinct from sibling methods that rely on external depth supervision or point clouds [8687-depth-supervised-nerf.md, 12693-3d-point-supervision-loss.md].

## How it works
The method optimizes density $\sigma$ and color $\mathbf{c}$ fields by minimizing a total loss $\mathcal{L}_{\text{geom}}$ [S1].

**Inputs and Outputs:**
- **Inputs:** Training images $\mathcal{I}$, camera poses, ray sampling positions $t_i$, transmittance $T(t)$, and density $\sigma(t)$ along rays.
- **Outputs:** Gradients for $\sigma$ and $\mathbf{c}$; rendered colors $\mathbf{C}_i$.

**Data Structures:**
- Ray $r(t)$: Parametrized by origin $\mathbf{o}$ and direction $\mathbf{d}$.
- Sample points $t_i$: Discretized positions along the ray, $i=1 \dots N$.
- Weights $w_i$: Contribution of each sample, $w_i = T(t_i)(1 - e^{-\sigma_i \delta_i})$, where $\delta_i = t_{i+1} - t_i$ [S1].
- Expected depth $D(\mathbf{r})$: Weighted average of sample positions [S1].

**Formulas:**
The total loss is defined as [S1]:
$$ \mathcal{L}_{\text{geom}} = \mathcal{L}_{\text{photo}} + \lambda_{\text{fg}} \mathcal{L}_{\text{fg}} + \lambda_{\text{fr}} \mathcal{L}_{\text{fr}} + \lambda_{\text{dist}} \mathcal{L}_{\text{dist}} $$

1. **Photometric Loss** $\mathcal{L}_{\text{photo}}$: L2 difference between rendered and input images [S1]:
   $$ \mathcal{L}_{\text{photo}}(\sigma, \mathbf{c}) = \sum_{i=1}^{\mathcal{I}} ||I_i - \mathbf{C}_i||_2 $$
   where $I_i$ is the input image and $\mathbf{C}_i$ is the rendered color.

2. **Foreground Loss** $\mathcal{L}_{\text{fg}}$: Encourages weights to sum to unity, assuming full absorption [S1]:
   $$ \mathcal{L}_{\text{fg}} = \left( 1 - \sum_{i=1}^N w_i \right)^2 $$

3. **Frustum Loss** $\mathcal{L}_{\text{fr}}$: Penalizes density placed in only one view frustum to prevent image copying [S1]:
   $$ \mathcal{L}_{\text{fr}} = \sum_i w_i \mathbf{1}(n_i \le 1) $$
   where $n_i$ is the number of training view frustums containing the point $r(t_i)$, and $\mathbf{1}(\cdot)$ is the indicator function.

4. **Distribution Loss** $\mathcal{L}_{\text{dist}}$: Encourages compact weight distribution, scaled by expected depth [S1]:
   $$ \mathcal{L}_{\text{dist}} = \frac{1}{D(\mathbf{r})} \left( \sum_{i,j} w_i w_k \left| \frac{t_i + t_{i+1}}{2} - \frac{t_j + t_{j+1}}{2} \right| + \frac{1}{3} \sum_{i=1}^N w_i^2 (t_{i+1} - t_i) \right) $$
   Note: The source uses indices $i,j$ for the first term and $i,k$ in the text description; the formula explicitly uses $w_i w_k$ with indices $i,j$ in the summation bounds. We follow the explicit formula structure. The term $\frac{t_i + t_{i+1}}{2}$ represents the midpoint of the $i$-th interval.

5. **Expected Depth** $D(\mathbf{r})$:
   $$ D(\mathbf{r}) = \frac{\sum_{i=1}^N w_i t_i}{\sum_{i=1}^N w_i} $$

**Parameters:**
- $\lambda_{\text{fg}}, \lambda_{\text{fr}}$: Not given in the sources. [G] Typical values in related literature are often 1.0 or 0.1, but must be tuned.
- $\lambda_{\text{dist}}$: Scheduled weight. Starts at 0 for the first 2500 steps. Linearly increases to $1 \times 10^{-4}$ (DTU dataset) or $1.5 \times 10^{-5}$ (LLFF dataset) at 8000 steps [S1].

**Pseudocode:**
```python
def geometric_baseline_loss(rendered_colors, input_images, weights, t_positions, frustum_counts, lambda_fg, lambda_fr, lambda_dist, step, max_steps=8000, start_steps=2500, dataset='DTU'):
    """
    Computes the Geometric Baseline Loss.
    
    Args:
        rendered_colors: List of rendered color tensors for each training view.
        input_images: List of input image tensors for each training view.
        weights: Tensor of shape (num_rays, N) containing sample weights w_i.
        t_positions: Tensor of shape (num_rays, N+1) containing sample boundaries t_i.
        frustum_counts: Tensor of shape (num_rays, N) containing n_i (number of frustums covering each sample).
        lambda_fg: Float, weight for foreground loss.
        lambda_fr: Float, weight for frustum loss.
        lambda_dist: Float, weight for distribution loss.
        step: Current training step.
        max_steps: Step at which lambda_dist reaches max value.
        start_steps: Step at which lambda_dist starts increasing.
        dataset: String, 'DTU' or 'LLFF'.
        
    Returns:
        Total loss scalar.
    """
    # 1. Photometric Loss
    photo_loss = 0.0
    for rendered, input_img in zip(rendered_colors, input_images):
        photo_loss += torch.mean((rendered - input_img) ** 2)
        
    # 2. Foreground Loss: (1 - sum(w))^2
    # Sum weights along the ray dimension (dim=1)
    sum_weights = torch.sum(weights, dim=1)
    fg_loss = torch.mean((1.0 - sum_weights) ** 2)
    
    # 3. Frustum Loss: sum(w * 1(n_i <= 1))
    # Indicator: 1 if n_i <= 1, else 0
    frustum_mask = (frustum_counts <= 1).float()
    fr_loss = torch.mean(torch.sum(weights * frustum_mask, dim=1))
    
    # 4. Distribution Loss
    # Compute expected depth D(r) for each ray
    # D(r) = sum(w_i * t_i) / sum(w_i)
    # Note: t_positions has shape (N+1). We need midpoints or use t_i as sample points.
    # The formula uses (t_i + t_{i+1})/2 as the center of the interval.
    # Let's assume t_positions[i] is the start of interval i, t_positions[i+1] is the end.
    # The weight w_i corresponds to the interval [t_i, t_{i+1}].
    
    # Midpoints of intervals
    midpoints = (t_positions[:, :-1] + t_positions[:, 1:]) / 2.0
    
    # Expected depth
    numerator = torch.sum(weights * midpoints, dim=1)
    denominator = torch.sum(weights, dim=1)
    # Avoid division by zero
    denominator = torch.clamp(denominator, min=1e-8)
    expected_depth = numerator / denominator
    
    # Term 1: sum_{i,j} w_i w_j |mid_i - mid_j|
    # This is a pairwise distance weighted by product of weights.
    # Efficient computation: sum_i w_i * sum_j w_j |mid_i - mid_j|
    # Or using broadcasting:
    # diff = |mid_i - mid_j| for all pairs
    # weighted_diff = w_i * w_j * diff
    # sum over i, j
    
    # Reshape for broadcasting: (num_rays, N, 1) and (num_rays, 1, N)
    w_i = weights.unsqueeze(2)  # (num_rays, N, 1)
    w_j = weights.unsqueeze(1)  # (num_rays, 1, N)
    mid_i = midpoints.unsqueeze(2) # (num_rays, N, 1)
    mid_j = midpoints.unsqueeze(1) # (num_rays, 1, N)
    
    abs_diff = torch.abs(mid_i - mid_j)
    term1 = torch.sum(w_i * w_j * abs_diff, dim=(1, 2))
    
    # Term 2: (1/3) * sum_i w_i^2 * (t_{i+1} - t_i)
    # delta_t = t_{i+1} - t_i
    delta_t = t_positions[:, 1:] - t_positions[:, :-1]
    term2 = (1.0 / 3.0) * torch.sum(weights ** 2 * delta_t, dim=1)
    
    # Combine terms and divide by expected depth
    dist_loss_per_ray = (term1 + term2) / expected_depth
    dist_loss = torch.mean(dist_loss_per_ray)
    
    # Schedule lambda_dist
    if step < start_steps:
        current_lambda_dist = 0.0
    else:
        # Linear increase from 0 to max_val
        progress = (step - start_steps) / (max_steps - start_steps)
        progress = torch.clamp(torch.tensor(progress), 0.0, 1.0)
        
        if dataset == 'DTU':
            max_lambda_dist = 1e-4
        elif dataset == 'LLFF':
            max_lambda_dist = 1.5e-5
        else:
            max_lambda_dist = 1e-4 # Default fallback
            
        current_lambda_dist = progress * max_lambda_dist
        
    total_loss = photo_loss + lambda_fg * fg_loss + lambda_fr * fr_loss + current_lambda_dist * dist_loss
    
    return total_loss
```

**Edge Cases and Pitfalls:**
- **Division by Zero:** In $\mathcal{L}_{\text{dist}}$, $D(\mathbf{r})$ can be zero if no density is present. Clamp denominator to a small epsilon [G].
- **Frustum Counting:** Computing $n_i$ requires checking if point $r(t_i)$ lies within the camera frustum of each training view. This is computationally expensive and must be precomputed or cached [S1].
- **Few-View Collapse:** Without $\mathcal{L}_{\text{fr}}$, NeRFs may collapse to copying training images. This loss specifically targets density in only one frustum [S1].

## Operating characteristics
- **Time Complexity:** The distribution loss involves pairwise weight interactions ($O(N^2)$ per ray), which can be expensive for large $N$. The frustum loss requires frustum containment checks for all samples across all views.
- **Memory Complexity:** Requires storing weights, positions, and frustum counts for all samples.
- **Strengths:** Prevents degenerate solutions in few-view settings without requiring external depth maps or point clouds [S1].
- **Limitations:** Does not provide explicit geometric supervision like depth maps; relies on implicit priors. The distribution loss is sensitive to the expected depth scaling.
- **When to Use:** Few-view NeRF optimization where external geometric priors are unavailable.
- **When Not to Use:** When high-precision geometric reconstruction is required and external depth/point supervision is available (use [Depth-Supervised NeRF](8687-depth-supervised-nerf.md) or [3D Point Supervision Loss](12693-3d-point-supervision-loss.md)).

## Background
Geometric Baseline Regularization was introduced in "DiffusioNeRF: Regularizing Neural Radiance Fields with Denoising Diffusion Models" (2023) [S1]. It serves as a foundational regularization strategy for NeRF optimization, addressing the issue of degenerate solutions in sparse view settings. It is used as a baseline in diffusion-based NeRF methods and other regularized optimization frameworks.
