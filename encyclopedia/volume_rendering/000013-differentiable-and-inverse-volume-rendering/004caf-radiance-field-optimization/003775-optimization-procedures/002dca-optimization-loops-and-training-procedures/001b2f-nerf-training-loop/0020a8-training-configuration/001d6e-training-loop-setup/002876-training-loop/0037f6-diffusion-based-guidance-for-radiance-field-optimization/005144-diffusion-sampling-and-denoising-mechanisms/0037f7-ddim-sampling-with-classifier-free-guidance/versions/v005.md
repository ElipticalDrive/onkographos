# DDIM Sampling with Classifier-Free Guidance

Also called: DDIMSampler, refine

## Overview
Iteratively denoises latent variables using the Denoising Diffusion Implicit Models (DDIM) scheduler and classifier-free guidance (CFG) to generate images or refine existing ones [S1, unofficial]. It sets itself apart from sibling methods like [Inpainting SDS Loss](11185-inpainting-sds-loss.md) by operating as a general-purpose sampling and refinement engine rather than a specific loss function for masked regions, and builds on [Diffusion-Based Guidance for Radiance Field Optimization](8117-diffusion-based-guidance-for-radiance-field-optimization.md) by providing the concrete sampling loop that generates the gradient signal source [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:**
  - `embeddings`: A dictionary containing `pos` (positive/unconditional) and `neg` (negative/unconditional) text embeddings. Shape: `[batch_size, seq_len, dim]`.
  - `num_inference_steps`: Integer, number of DDIM steps.
  - `guidance_scale`: Float, CFG multiplier.
  - `height`, `width`: Integers, target image dimensions.
  - `strength`: Float (0.0 to 1.0), used in refinement mode to determine how much noise to add relative to the input [S1, unofficial].
  - `init_latents`: Optional tensor of shape `[1, channels, height//8, width//8]`. If not provided, random noise is used [S1, unofficial].
- **Outputs:**
  - `latents`: The final denoised latent tensor.

**Data Structures:**
- **Latents:** Tensor of shape `[batch_size, channels, H/8, W/8]`. Channels is determined by the UNet input (typically 4 for latent diffusion).
- **Scheduler State:** Maintains the current timestep $t$ and previous sample $x_{t-1}$ (or $x_0$ prediction) internally.

**Parameters:**
- `num_inference_steps`: Default 50 [S1, unofficial].
- `guidance_scale`: Default 7.5 for sampling, 100 for refinement/training [S1, unofficial].

**Algorithm:**
1. **Initialization:** If `init_latents` is not provided, initialize `latents` with standard normal noise:
   $$ \text{latents} \sim \mathcal{N}(0, I) $$
   Specifically, shape is `[1, self.unet.in_channels, height // 8, width // 8]` on the target device [S1, unofficial].
2. **Scheduler Setup:** Configure the DDIM scheduler with the specified `num_inference_steps`. This generates a sequence of timesteps $T, T-1, \dots, 0$ [S1, unofficial].
3. **Embedding Preparation:** Concatenate the positive and negative embeddings along the batch dimension to allow joint processing:
   $$ \text{embeddings}_{\text{cat}} = \text{concat}([\text{embeddings}_{\text{pos}} \otimes \text{batch\_size}, \text{embeddings}_{\text{neg}} \otimes \text{batch\_size}]) $$
   Where $\otimes$ denotes expansion to match batch size [S1, unofficial].
4. **Iteration Loop:** For each timestep $t$ in the scheduler's sequence:
   a. **Duplicate Latents:** Create a batch of size 2 by concatenating the current latents with itself:
      $$ \text{latent\_model\_input} = \text{concat}([\text{latents}, \text{latents}]) $$
   b. **Noise Prediction:** Pass `latent_model_input` and timestep $t$ through the frozen UNet to predict noise $\epsilon_\theta$:
      $$ [\epsilon_{\text{cond}}, \epsilon_{\text{uncond}}] = \text{UNet}(\text{latent\_model\_input}, t, \text{embeddings}_{\text{cat}}) $$
   c. **Classifier-Free Guidance:** Combine predictions using the guidance scale $s$:
      $$ \epsilon_{\text{pred}} = \epsilon_{\text{uncond}} + s \cdot (\epsilon_{\text{cond}} - \epsilon_{\text{uncond}}) $$
   d. **Scheduler Step:** Update latents using the DDIM step function:
      $$ \text{latents} = \text{scheduler.step}(\epsilon_{\text{pred}}, t, \text{latents}).\text{prev\_sample} $$
5. **Refinement Mode (Optional):** If refining an existing image/latent, add noise at a specific step determined by `strength`. Calculate `init_step = int(steps * strength)` and skip early timesteps (from $T$ down to `init_step`) to preserve structure, then resume denoising from `init_step` [S1, unofficial].

**Pseudocode:**
```python
def ddim_sample_with_cfg(
    unet, 
    scheduler, 
    embeddings_pos, 
    embeddings_neg, 
    num_inference_steps=50, 
    guidance_scale=7.5, 
    height=512, 
    width=512, 
    strength=1.0, 
    init_latents=None
):
    device = unet.device
    in_channels = unet.in_channels
    
    # 1. Initialize latents
    if init_latents is None:
        latents = torch.randn(
            (1, in_channels, height // 8, width // 8), 
            device=device
        )
    else:
        latents = init_latents

    # 2. Set scheduler timesteps
    scheduler.set_timesteps(num_inference_steps)
    timesteps = scheduler.timesteps # List of timesteps
    
    # 3. Prepare embeddings for CFG
    # Expand embeddings to batch size 2 (cond + uncond)
    # Note: embeddings_pos/neg are assumed to be [1, seq, dim] or similar
    batch_pos = embeddings_pos.expand(1, -1, -1) # Assuming batch size 1 for simplicity
    batch_neg = embeddings_neg.expand(1, -1, -1)
    embeddings_cat = torch.cat([batch_pos, batch_neg], dim=0)

    # 4. Loop over timesteps
    # If refining, we might start from a later timestep
    start_step = int(num_inference_steps * (1.0 - strength))
    timesteps_to_run = timesteps[start_step:]

    for t in timesteps_to_run:
        # a. Duplicate latents for CFG
        latent_model_input = torch.cat([latents, latents])
        
        # b. Predict noise
        # UNet returns noise prediction for both cond and uncond
        noise_pred = unet(latent_model_input, t, encoder_hidden_states=embeddings_cat).sample
        
        # Split predictions
        noise_pred_cond, noise_pred_uncond = noise_pred.chunk(2)
        
        # c. Apply CFG
        noise_pred = noise_pred_uncond + guidance_scale * (noise_pred_cond - noise_pred_uncond)
        
        # d. Step scheduler
        latents = scheduler.step(noise_pred, t, latents).prev_sample

    return latents
```

## Subtopics

### [Conditional Generator for NeRF Refinement](13028-conditional-generator-for-nerf-refinement.md)
The Conditional Generator is a 2D post-processing module that refines NeRF renderings by acting as a stochastic denoiser. It takes a raw NeRF rendering and an auxiliary random vector as input to produce a cleaned image, addressing artifacts that remain after 3D optimization. Unlike 3D discriminator-based methods that guide the radiance field directly, this method operates in image space, leveraging a StyleGAN2-inspired architecture to enhance perceptual quality without altering the underlying 3D representation.

### NeRF Interpolation via DDIM and SLERP
A procedure to generate smooth transitions between 3D samples by interpolating in the diffusion latent space before deterministic decoding [S2]. It samples two initial diffusion latent values $x^{(T)} \sim \mathcal{N}(0, I)$, interpolates them using spherical linear interpolation (SLERP), and passes the interpolated latents through a deterministic solver to obtain the final samples [S2]. Standard Gaussian diffusion models typically produce non-smooth interpolation results, and models trained with long schedules for unconditional generation yield distinct but discontinuous interpolated samples [S2]. However, early stopping for sparse-view reconstruction preserves a smoother prior, yielding better generalization and smoother transitions than long unconditional training schedules [S2]. Used in SSDNeRF to interpolate between generated 3D samples [S2].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of inference steps $T$ and the cost of the UNet forward pass. Each step requires one UNet evaluation (or two if not batching cond/uncond, but here they are batched).
- **Memory Complexity:** Proportional to the latent size and the UNet's activation memory. The batching of conditional/unconditional inputs doubles the batch dimension temporarily during the forward pass.
- **Performance:** Default settings use 50 steps for sampling [S1, unofficial]. Refinement/training uses a higher guidance scale (100) compared to sampling (7.5) [S1, unofficial].
- **Strengths:** Deterministic sampling (unlike DDPM) allows for reproducible results and smoother interpolation [S2]. CFG allows for strong control over the output distribution [S1, unofficial].
- **Limitations:** Standard Gaussian diffusion models can produce non-smooth interpolations if not trained with early stopping [S2]. Refinement requires careful selection of the `strength` parameter to avoid destroying existing structure [S1, unofficial].
- **When to use:** When high-fidelity image generation or refinement of NeRF renderings is needed, or when interpolating between 3D shapes in latent space [S1, unofficial][S2].
- **When not to use:** When real-time performance is critical (DDIM is still iterative) or when smooth interpolation is required without the specific training regimen (early stopping) described in [S2].

## Background
The method originates from the DDIM paper [S2, ref 50] and the concept of Classifier-Free Guidance [S1, ref implied by CFG usage, unofficial]. It is widely used in diffusion-based 3D generation pipelines such as DreamGaussian [S1, unofficial] and SSDNeRF [S2]. DreamGaussian uses it for image generation and refinement [S1, unofficial], while SSDNeRF uses it for 3D sample interpolation [S2].
