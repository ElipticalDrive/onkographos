# Anti-Aliased Interlevel Loss

Also called: Blurred NeRF Loss, Prefiltered Loss

## Overview
The Anti-Aliased Interlevel Loss is a proposal supervision loss function that measures the distance between a NeRF histogram and a proposal histogram by blurring the NeRF histogram into a piecewise-linear spline and resampling it into the proposal's interval endpoints [S1]. Unlike the piecewise constant loss used in mip-NeRF 360, which suffers from aliasing when NeRF histogram bins are narrow or translate relative to the proposal, this method produces a smooth loss surface that prevents aliasing artifacts during training [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** NeRF histogram endpoints $\mathbf{s} = \{s_0, \dots, s_N\}$ and weights $\mathbf{w} = \{w_0, \dots, w_{N-1}\}$, where $s_i$ are normalized distances in $[0, 1]$ and $w_i$ are accumulated weights for interval $[s_i, s_{i+1}]$ [S1]. Proposal histogram endpoints $\hat{\mathbf{s}} = \{\hat{s}_0, \dots, \hat{s}_M\}$ and weights $\hat{\mathbf{w}} = \{\hat{w}_0, \dots, \hat{w}_{M-1}\}$ [S1]. Convolution radius $r$ [S1].
*   **Outputs:** Scalar loss $\mathcal{L}_{\text{prop}}$ [S1]. Resampled NeRF weights $\hat{\mathbf{w}}^{\mathbf{s}}$ [S1].

**Parameters**
*   $r$: The radius of the rectangular pulse used for convolution [S1]. Not given in the sources for other parameters.

**Algorithm Steps**
1.  **Normalize:** Divide NeRF weights $\mathbf{w}$ by the size of each interval in $\mathbf{s}$ to yield a piecewise constant PDF that integrates to $\le 1$ [S1].
2.  **Convolve:** Convolve the piecewise constant PDF with a rectangular pulse of radius $r$ (integrating to 1) to obtain a piecewise linear PDF [S1]. This is implemented by turning each endpoint $s_i$ into two signed delta functions at $s_i - r$ and $s_i + r$ with values proportional to the change between adjacent PDF heights, sorting them, and integrating twice [S1].
3.  **Integrate to CDF:** Integrate the piecewise linear PDF to produce a piecewise-quadratic CDF [S1].
4.  **Resample:** Query the piecewise-quadratic CDF via piecewise quadratic interpolation at each location in $\hat{\mathbf{s}}$ [S1].
5.  **Compute Loss:** Calculate resampled NeRF weights $\hat{w}_i^{\mathbf{s}}$ by taking the difference between adjacent interpolated CDF values at the proposal endpoints [S1]. Evaluate the loss as an element-wise function of $\hat{\mathbf{w}}^{\mathbf{s}}$ and $\hat{\mathbf{w}}$ [S1].

**Pseudocode**
```python
import numpy as np

def anti_aliased_interlevel_loss(s, w, s_hat, w_hat, r):
    """
    Computes the anti-aliased interlevel loss.
    
    Args:
        s: NeRF histogram endpoints, shape (N+1,)
        w: NeRF histogram weights, shape (N,)
        s_hat: Proposal histogram endpoints, shape (M+1,)
        w_hat: Proposal histogram weights, shape (M,)
        r: Convolution radius
        
    Returns:
        loss: Scalar loss value
    """
    N = len(w)
    M = len(w_hat)
    
    # Step 1: Normalize to piecewise constant PDF
    # h[i] is the height of the step function in interval i
    intervals = s[1:] - s[:-1]
    # Guard against zero-width intervals [G]
    intervals = np.maximum(intervals, 1e-8)
    h = w / intervals
    
    # Step 2: Convolve with rectangular pulse using delta functions
    # Create delta functions at s[i] - r and s[i] + r
    # The value is proportional to the change in h, scaled by 1/(2r) [S1]
    deltas = []
    
    # At s[0], change is h[0] - 0
    deltas.append((s[0] - r, h[0] / (2 * r)))
    deltas.append((s[0] + r, -h[0] / (2 * r)))
    
    # Internal boundaries
    for i in range(1, N):
        delta_val = (h[i] - h[i-1]) / (2 * r)
        deltas.append((s[i] - r, delta_val))
        deltas.append((s[i] + r, -delta_val))
        
    # At s[N], change is 0 - h[N-1]
    deltas.append((s[N] - r, -h[N-1] / (2 * r)))
    deltas.append((s[N] + r, h[N-1] / (2 * r)))
    
    # Sort deltas by position [S1]
    deltas.sort(key=lambda x: x[0])
    
    # Step 3 & 4: Integrate twice to get CDF values at s_hat
    # Double integration of a delta at pos with value v yields v * max(0, x - pos)
    cdf_values = np.zeros(M + 1)
    
    for j in range(M + 1):
        x = s_hat[j]
        cdf_val = 0.0
        for pos, val in deltas:
            if pos <= x:
                cdf_val += val * (x - pos)
        cdf_values[j] = cdf_val
        
    # Step 5: Compute resampled weights
    # w_hat_s[i] = CDF(s_hat[i+1]) - CDF(s_hat[i])
    w_hat_s = cdf_values[1:] - cdf_values[:-1]
    
    # Step 6: Evaluate loss
    # L_prop = sum_i (1 / w_hat_i) * max(0, stopgrad(w_hat_s_i) - w_hat_i)^2 [S1]
    # stopgrad is applied conceptually; gradients flow through w_hat_s to the NeRF,
    # but not to the proposal network [S1]
    diff = np.maximum(0, w_hat_s - w_hat)
    
    # Guard against division by zero in w_hat [G]
    w_hat_safe = np.maximum(w_hat, 1e-8)
    
    loss = np.sum(diff**2 / w_hat_safe)
    
    return loss
```

**Edge Cases and Pitfalls**
*   **Narrow Bins:** Rasterizing the step function and performing convolution fails in the common case of extremely narrow histogram bins, necessitating the delta-function integration algorithm [S1].
*   **Zero-Width Intervals:** If $s_{i+1} - s_i = 0$, the normalization step involves division by zero. A small epsilon is added to the interval size [G].
*   **Zero Proposal Weights:** If $\hat{w}_i = 0$, the loss term involves division by zero. A small epsilon is added to the proposal weights in the denominator [G].

## Operating characteristics
*   **Strengths:** Produces a smooth loss surface that is robust to aliasing when NeRF histogram bins are narrow or translate relative to the proposal [S1].
*   **Limitations:** More computationally expensive than the piecewise constant loss used in mip-NeRF 360 due to the convolution and resampling steps [S1].

## Background
The Anti-Aliased Interlevel Loss was introduced in the Zip-NeRF paper [S1]. It builds on the proposal supervision approach from mip-NeRF 360 [S1]. The key innovation is the use of a blurred, piecewise-linear representation of the NeRF histogram to enable smooth gradient flow during training, addressing the aliasing issues inherent in the piecewise constant comparison used in mip-NeRF 360 [S1].
