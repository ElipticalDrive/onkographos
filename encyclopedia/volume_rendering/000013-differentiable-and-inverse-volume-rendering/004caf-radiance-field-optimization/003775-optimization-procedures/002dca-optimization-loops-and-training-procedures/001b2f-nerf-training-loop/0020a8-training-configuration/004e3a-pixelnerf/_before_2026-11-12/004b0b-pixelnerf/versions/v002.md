# PixelNeRF

Also called: pixelNeRF, spatial CNN feature

## Overview
PixelNeRF is a neural radiance field method that synthesizes novel views from one or a few input images by conditioning a standard NeRF renderer on image features extracted via a pretrained CNN [S2, unofficial][S3]. Unlike vanilla NeRF, which requires many views for training and relies solely on positional encoding, PixelNeRF projects camera rays onto the source image plane to extract spatial features for each query point, enabling sparse-view reconstruction [S1][S2, unofficial]. It differs from sibling methods like MVSNeRF by operating in view-space with direct ray-to-pixel feature extraction rather than canonical-space voxelization [S1].

## How it works
### Inputs and Outputs
**Inputs:**
- Reference images: A set of $N$ input images (typically 1–3) with known camera poses [S3].
- Query rays: For each pixel in the target view, a ray defined by origin $\mathbf{o}$ and direction $\mathbf{d}$ [S1].
- Sampling depths: Near ($near$) and far ($far$) bounds for the ray segment [S2, unofficial].

**Outputs:**
- RGB color and opacity (density) for each sample point along the ray [S1].
- Final rendered image (RGB) and depth map [S2, unofficial].

### Data Structures
- **Ray Tensor:** Shape $(B, 8)$, where $B$ is the batch size. The last two elements are $near$ and $far$ distances [S2, unofficial].
- **Feature Maps:** Extracted from reference images using a CNN backbone. Feature map size is adjusted from 64 to 128 channels [S3].
- **MLP:** A 3-layer network with skip connections to the second layer [S3].

### Numbered Steps
1. **Feature Extraction:** For each query point $\mathbf{x}$ on a ray, project the point onto the image planes of the reference images. Extract 2D features using a pretrained CNN (ResNet-34) and bilinear interpolation [S1, S3].
2. **Feature Aggregation:** If multiple reference views are used, aggregate the features from all views via average pooling [S4].
3. **Sampling:** Generate sample positions along the ray using stratified sampling [S2, unofficial].
   - Calculate step size: $step = 1.0 / n_{coarse}$ [S2, unofficial].
   - Generate normalized depths: $z_{steps} = \text{linspace}(0, 1 - step, n_{coarse})$ [S2, unofficial].
   - Add uniform noise: $z_{steps} += \text{rand\_like}(z_{steps}) \times step$ [S2, unofficial].
   - Compute physical positions $z$ based on $near$ and $far$:
     - If $lindisp$ is False: $z = near \cdot (1 - z_{steps}) + far \cdot z_{steps}$ [S2, unofficial].
     - If $lindisp$ is True: $z = \frac{1}{\frac{1}{near} \cdot (1 - z_{steps}) + \frac{1}{far} \cdot z_{steps}}$ [S2, unofficial].
4. **NeRF Query:** Pass the query point $\mathbf{x}$, view direction $\mathbf{d}$, and the aggregated CNN features into the NeRF MLP [S1].
5. **Output Prediction:** The MLP outputs density $\sigma$ and color $\mathbf{c}$ for each sample [S1].
6. **Volume Rendering:** Composite the samples into final RGB and depth using standard volume rendering equations [S2, unofficial].

### Pseudocode
```python
import torch
import torch.nn.functional as F

def extract_features(ray_origins, ray_directions, reference_images, camera_poses, cnn_backbone):
    """
    Extracts CNN features for query points by projecting rays onto reference images.
    """
    # Project 3D query points to 2D image coordinates for each reference view
    # This involves inverse projection using camera_poses and bilinear interpolation
    # Returns features of shape (B, C, H, W) or flattened (B, C, N_samples)
    # Note: Exact projection math depends on camera model; assume helper exists
    features = []
    for img, pose in zip(reference_images, camera_poses):
        # Project ray origins/directions to 2D
        # Interpolate features from pretrained CNN backbone
        feat = interpolate_cnn_features(img, pose, ray_origins, ray_directions)
        features.append(feat)
    
    # Aggregate features via average pooling if multiple views
    if len(features) > 1:
        aggregated_features = torch.mean(torch.stack(features, dim=0), dim=0)
    else:
        aggregated_features = features[0]
        
    return aggregated_features

def sample_coarse(rays, n_coarse=128, lindisp=False):
    """
    Generates stratified samples along rays.
    rays shape: (B, 8), where rays[:, -2:-1] is near, rays[:, -1:] is far.
    """
    near = rays[:, -2:-1]  # Shape (B, 1)
    far = rays[:, -1:]     # Shape (B, 1)
    
    step = 1.0 / n_coarse
    z_steps = torch.linspace(0, 1 - step, n_coarse, device=rays.device)
    z_steps = z_steps.repeat(rays.shape[0], 1)  # Shape (B, Kc)
    
    # Stratified sampling
    z_steps += torch.rand_like(z_steps) * step
    
    if not lindisp:
        z = near * (1 - z_steps) + far * z_steps
    else:
        z = 1.0 / (1.0 / near * (1 - z_steps) + 1.0 / far * z_steps)
        
    return z

def render(rays, n_coarse=128, n_fine=0, cnn_backbone=None, reference_images=None, camera_poses=None):
    """
    Main rendering function for PixelNeRF.
    """
    if rays.shape[0] == 0:
        return torch.zeros((0, 3), device=rays.device), torch.zeros((0,), device=rays.device)
    
    # Extract features for all query points
    # Note: ray_origins and ray_directions must be derived from rays tensor
    ray_origins = rays[:, :3]
    ray_directions = rays[:, 3:6]
    
    cnn_features = extract_features(ray_origins, ray_directions, reference_images, camera_poses, cnn_backbone)
    
    # Sample coarse points
    z_coarse = sample_coarse(rays, n_coarse)
    
    # Query NeRF MLP with position, direction, and CNN features
    # MLP input: [position, direction, cnn_features]
    # Output: sigma (density), color
    sigma_coarse, color_coarse = query_nerf_mlp(z_coarse, ray_directions, cnn_features)
    
    # Volume rendering for coarse pass
    rgb_coarse, depth_coarse = volume_render(sigma_coarse, color_coarse, z_coarse)
    
    # If fine sampling is enabled, use importance sampling based on coarse weights
    if n_fine > 0:
        weights = compute_weights(sigma_coarse, z_coarse)
        z_fine = importance_sample(z_coarse, weights, n_fine)
        sigma_fine, color_fine = query_nerf_mlp(z_fine, ray_directions, cnn_features)
        rgb_fine, depth_fine = volume_render(sigma_fine, color_fine, z_fine)
        return rgb_fine, depth_fine
    else:
        return rgb_coarse, depth_coarse
```

### Parameters
- `n_coarse`: Number of coarse samples. Default: 128 [S2, unofficial].
- `n_fine`: Number of fine samples. Default: 0 [S2, unofficial].
- `eval_batch_size`: Ray batch size for evaluation. Default: 100,000 [S2, unofficial].
- `R`: Batch size of rendered rays per object. Default: 50,000 (eval), 128 (train) [S2, unofficial].
- `white_bkgd`: If true, background is white; else black. Default: False [S2, unofficial].
- `lindisp`: If true, sample in disparity space. Default: False [S2, unofficial].
- `noise_std`: Noise added to sigma. Not used in this implementation [S2, unofficial].
- `depth_std`: Noise for depth samples. Default: 0.01 [S2, unofficial].
- `P`: Source-view specification string (e.g., '64' for 1-view) [S2, unofficial].
- `L`: Path to viewlist file [S2, unofficial].

### Edge Cases and Pitfalls
- **DTU Overfitting:** The model overfits significantly to the training set on the DTU dataset. Use only train/val sets, with val used for testing [S2, unofficial].
- **SRN View Sampling:** Training with random 1/2 views per batch degrades performance, especially for 1-view. Use a fixed number of views [S2, unofficial].
- **Memory:** Reduce `R` if running out of memory; can increase to 100,000 on large-memory GPUs [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Rendering time is higher than vanilla NeRF due to CNN feature extraction. For example, 2.189 s for Feet dataset and 5.493 s for Chest dataset [S3].
- **Memory Complexity:** Depends on batch size `R` and feature map size. Feature map size adjusted from 64 to 128 [S3].
- **Performance:** Outperforms vanilla NeRF but has smaller margins than Instant-NGP (e.g., 0.031 vs 0.058 in 3D SSIM in Chest dataset) [S3].
- **Strengths:** Enhances reconstruction of internal small structures (e.g., teeth in Jaw dataset) [S3].
- **Limitations:** Relies on frequency-based encoding, which may not capture high-frequency details as well as hash encoding [S3].

## Background
PixelNeRF was introduced by Alex Yu, Vickie Ye, Matthew Tancik, and Angjoo Kanazawa from UC Berkeley in December 2020 [S2, unofficial]. It extends vanilla NeRF by leveraging pretrained CNN features to enable sparse-view reconstruction [S1, S3]. It is used for ShapeNet (NMR, SRN), DTU, and real car images [S2, unofficial].
