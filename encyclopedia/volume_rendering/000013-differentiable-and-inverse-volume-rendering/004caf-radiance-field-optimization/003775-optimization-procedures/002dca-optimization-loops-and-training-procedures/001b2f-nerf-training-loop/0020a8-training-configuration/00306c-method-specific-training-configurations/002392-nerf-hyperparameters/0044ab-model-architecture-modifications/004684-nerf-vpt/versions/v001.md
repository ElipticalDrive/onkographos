# NeRF-VPT
Also called: NeRF with View Prompt Tuning, NeRF-VPT with Cascading Learning, Neural Radiance Fields via View Prompt Tuning

## Overview
NeRF-VPT is a cascading view prompt tuning paradigm for novel view synthesis that progressively enhances image quality by using RGB information from preceding rendering iterations as visual prompts for subsequent stages [S1]. It solves the problem of limited learning capacity in standard NeRF, particularly under sparse view conditions, by iteratively incorporating prior knowledge into the network [S1]. Unlike methods that rely on external networks or specific data preprocessing for priors, NeRF-VPT uses only the network's internal output (previous stage RGB) as prior knowledge, making it plug-and-play and transferable to other NeRF variants like Mip-NeRF and TensoRF [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D position $\mathbf{x}$, view direction $\mathbf{d}$, and the rendered RGB image $\hat{c}(r)_{i-1}$ from the previous stage $i-1$.
*   **Outputs:** Volume density $\sigma$ and color $\mathbf{c}$ for the current stage $i$.

**Data Structures:**
The framework consists of $N+1$ stages, indexed from Stage 0 to Stage $N$.
*   **Stage 0:** A standard NeRF network $F_0$. It takes only encoded position $\text{PE}(\mathbf{x})$ and encoded direction $\text{DE}(\mathbf{d})$ as input. It does not rely on additional input beyond position and direction [S1].
*   **Stage $i$ ($i > 0$):** A new network $F_i$. It takes the encoded position $\text{PE}(\mathbf{x})$, the encoded direction $\text{DE}(\mathbf{d})$, and the RGB prompt from the previous stage $\hat{c}(r)_{i-1}$ as input [S1].
*   **Encoding:** Positional encoding $\text{PE}$ and Directional encoding $\text{DE}$ are applied to $\mathbf{x}$ and $\mathbf{d}$ respectively. The RGB prompt is concatenated after the direction encoding because color is high-frequency data and encoding is viewed as signal decomposition [S1].

**Numbered Steps:**
1.  **Initialize Stage 0:** Train a standard NeRF network $F_0$ without any prior knowledge. This stage gains knowledge of 3D space and generates prior RGB values as a view prompt for the next stage [S1].
2.  **Iterate Stages $i = 1$ to $N$:**
    a.  **Ray Sampling:** Sample points $\mathbf{x}$ and directions $\mathbf{d}$ along rays [S1].
    b.  **Encode Direction:** Encode the viewing direction $(\theta, \phi)$ using $\text{DE}$ [S1].
    c.  **Retrieve Prompt:** Retrieve the RGB image $\hat{c}(r)_{i-1}$ rendered in the previous stage $i-1$ [S1].
    d.  **Combine Inputs:** Combine the encoded direction $\text{DE}(\mathbf{d})$ and the previous stage's RGB output $\hat{c}(r)_{i-1}$ as input to the current stage's network. The input to $F_i$ is $(\text{PE}(\mathbf{x}), (\text{DE}(\mathbf{d}), \hat{c}(r)_{i-1}))$ [S1].
    e.  **Predict:** The network $F_i$ outputs density $\sigma_i$ and color $\mathbf{c}_i$ for the current stage [S1].
    f.  **Render:** Compute the rendered color $\hat{c}(r)$ using volumetric rendering [S1].
    g.  **Optimize:** Update network weights using the loss function [S1].
3.  **Termination:** Training concludes once the limit of stages (typically 5-6) is reached [S1].

**Formulas:**
The mapping function for iteration $i$ is defined as [S1]:
$$
(\mathbf{c}_i, \sigma_i) = F_i(\text{PE}(\mathbf{x}), (\text{DE}(\mathbf{d}), \hat{c}(r)_{i-1}))
$$
where $F_0$ and $F_i$ denote the mapping functions in iterations, $\text{PE}$ is position encoding, $\text{DE}$ is direction encoding, and $\hat{c}(r)_{i-1}$ is the RGB prompt from the previous stage [S1].

The volumetric rendering equation for color $\hat{c}(r)$ is [S1]:
$$
\hat{c}(r) = \sum_{i=n}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i
$$
where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ handles occlusion, $t_n, t_f$ are near/far boundaries, and $\delta_i$ is the distance between sampling points [S1].

The training loss is [S1]:
$$
L = \sum_{r \in R} ||\hat{c}(r) - c(r)||
$$
where $R$ presents all image pixels in training data, and $c(r)$ is ground-truth color [S1].

**Parameters:**
*   **Number of stages:** Five to six stages on a standard baseline achieve maximum performance [S1].
*   **Prompt Integration Point:** The RGB prompt is concatenated after the direction encoding [S1].
*   **Number of prior images:** 20 uniformly sampled training images are used to represent the entire scene for feature extraction in ablation studies, but the final method uses the rendered output from the previous stage as the prompt [S1].

**Pitfalls and Edge Cases:**
*   **Ground Truth Unavailability:** Directly providing ground truth images as priors fails during testing for unknown viewpoints because ground truth is unavailable. NeRF-VPT solves this by using rendered images from a pre-trained model as the prompt, which are available for all viewpoints [S1].
*   **Feature Fusion Limitations:** Extracting features from multiple images via Swin-Transformer or CNN and fusing them into an MLP showed limited improvement because it is challenging to encapsulate multi-view information within a single feature [S1].
*   **Training Time:** Training time per iteration decreases significantly as the cascade progresses, because increasingly accurate visual prompts reduce the learning difficulty for the network [S1].

            # Retrieve previous stage's rendered output as prompt
            # If this is the first iteration of Stage 1, use Stage 0's output
            # In a continuous training loop, previous_rendered_output is updated after each stage
            if previous_rendered_output is None:
                # Render using current_model (which is F0 for stage 1)
                sigma_prev, color_prev = current_model(rays.position, rays.direction)

            # Concatenate after direction encoding

            # Input to current stage network: PE(x), (DE(d), prompt)

            # Render current stage
            rendered_color_stage = volumetric_render(rays, sigma_stage, color_stage, near, far)
            
            # Compute loss against ground truth
            loss_stage = compute_loss(rendered_color_stage, training_data.targets)
            
            # Update weights for current stage
            update_weights(F_stage, loss_stage)
        
        # Update current model for the next stage's prompt generation
        current_model = F_stage
        
        # Generate prompt for the next stage
        # Render using the fully trained current_model to get the prompt for stage+1

## Operating characteristics
*   **Time and Memory Complexity:** Parameter overhead is negligible, with only 0.0008 M additional parameters compared to baseline NeRF [S1]. Rendering speed is 0.108 FPS on the Replica dataset, compared to 0.103 FPS for NeRF [S1]. Training time per iteration decreases significantly as the cascade progresses, because increasingly accurate visual prompts reduce the learning difficulty for the network [S1].
*   **Measured Performance:**
    *   On Realistic Synthetic 360 Dataset, NeRF-VPT (Stage 6) achieves PSNR 34.95, SSIM 0.977, LPIPS 0.042, outperforming NeRF (31.01, 0.947, 0.081) and Mip-NeRF (33.09, 0.961, 0.043) [S1].
    *   On Real Forward-Facing Dataset, NeRF-VPT (Stage 6) achieves PSNR 28.95, SSIM 0.872, LPIPS 0.158, outperforming NeRF (26.50, 0.811, 0.250) and Mip-NeRF (27.13, 0.839, 0.164) [S1].
    *   On Replica Dataset, training with 45 sparse views using NeRF-VPT achieves comparable image quality to training standard NeRF with 180 views [S1].
*   **Scaling:** The method scales with the number of stages, with performance peaking at 5-6 stages [S1].
*   **Strengths and Limitations:**
    *   **Strengths:** Plug-and-play integration with other NeRF variants (Mip-NeRF, TensoRF); effective under sparse view conditions; maintains depth prediction quality (MSE distance 0.02, identical to baseline NeRF) [S1].
    *   **Limitations:** Requires multiple training stages, increasing total training time compared to a single-stage NeRF, although time per stage decreases [S1].
*   **When to use it:** When high-quality novel view synthesis is required from sparse views or when integrating with existing NeRF variants to boost performance without significant architectural changes [S1].

## Background
NeRF-VPT was introduced in 2024 in the paper "NeRF-VPT: Learning Novel View Representations with Neural Radiance Fields via View Prompt Tuning" [S1]. It builds on the success of NeRF and aims to fully harness its inherent potential by incorporating effective guidance through a cascading view prompt tuning paradigm [S1]. The method addresses limitations of prior approaches that relied on external networks or specific data preprocessing, offering a more general and transferable solution [S1].
