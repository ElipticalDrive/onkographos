# Warm-start Encoding

Also called: Temporal Coherency Encoding, Temporal warm-start, Temporally-Coherent Warm-Start Encoder, Warm-start Encoder

## Overview
Warm-start encoding accelerates the training of neural volume representations for animated sparse volumes by initializing the network weights for each frame with the converged weights from the previous frame [S1][S2, unofficial]. It solves the problem of flickering artifacts caused by weight discontinuities in high-frequency details (e.g., thin smoke layers) when using naive cold-start training, while simultaneously reducing encoding time by a factor of 1.5–2.5 compared to independent frame training [S1][S2, unofficial]. Unlike standard cold-start methods, it leverages temporal coherency to preserve smooth transitions across frames [S1][S2, unofficial].

## How it works
**Inputs:** A sequence of animated sparse volumes $V_1, V_2, \dots, V_N$; a target learning rate $\eta_{\text{target}}$; a neural network architecture [S1].
**Outputs:** A sequence of trained neural networks $W_1, W_2, \dots, W_N$, where $W_i$ encodes volume $V_i$ [S1].

**Data Structures:**
*   $W_{\text{prev}}$: The converged network weights from the previous frame. For the first frame, $W_{\text{prev}}$ is initialized randomly [G].
*   $\eta_{\text{current}}$: The active learning rate for the current training phase.
*   $L_1$: The final loss of the first frame, used as a stopping threshold for subsequent frames [S1].

**Numbered Steps:**

1.  **Initialize:** Set $W_{\text{prev}} \leftarrow \text{RandomInit}()$. Set $\eta_{\text{current}} \leftarrow \eta_{\text{target}}$.
2.  **Iterate Frames:** For each frame $i$ from 1 to $N$:
    a.  **Warm-Start Initialization:** Initialize the current network weights $W_{\text{curr}}$ with $W_{\text{prev}}$.
    b.  **First Frame Special Handling:** If $i == 1$:
        i.   Train $W_{\text{curr}}$ on $V_1$ using learning rate $\eta_{\text{target}}$ until convergence (loss $L_1$ stabilizes).
        ii.  Save $W_1 \leftarrow W_{\text{curr}}$.
        iii. Re-process frame 1: Set $\eta_{\text{fine}} \leftarrow \eta_{\text{target}} / 100$ (or smaller) [S1]. Train $W_1$ on $V_1$ using $\eta_{\text{fine}}$ until convergence.
        iv.  Update $\eta_{\text{current}} \leftarrow \eta_{\text{fine}}$.
    c.  **Subsequent Frames:** If $i > 1$:
        i.   Train $W_{\text{curr}}$ on $V_i$ using $\eta_{\text{current}}$ for a single pass or until loss $L_i < L_1$ [S1].
        ii.  Save $W_i \leftarrow W_{\text{curr}}$.
    d.  **Update Previous:** Set $W_{\text{prev}} \leftarrow W_i$.
3.  **Domain Decomposition Exception:** If a new domain is added mid-sequence (e.g., via domain decomposition), repeat the "First Frame Special Handling" process for that new domain using $\eta_{\text{target}}$ followed by $\eta_{\text{fine}}$ [S1].

**Pseudocode:**
```python
def warm_start_encode(volumes, target_lr, network_class):
    prev_weights = None
    current_lr = target_lr
    first_frame_final_loss = None
    saved_networks = []

    for i, volume in enumerate(volumes):
        # 1. Initialize network with previous frame's weights
        if prev_weights is None:
            net = network_class()
            net.random_init()
        else:
            net = network_class()
            net.set_weights(prev_weights)

        if i == 0:
            # 2. First frame: Train with target LR until convergence
            net.train(volume, lr=target_lr)  # [G] Convergence criterion not specified in sources
            first_frame_final_loss = net.get_loss()

            # 3. First frame: Re-process with smaller LR to fix flickering
            fine_lr = target_lr / 100.0
            net.train(volume, lr=fine_lr)  # [G] Convergence criterion not specified in sources
            current_lr = fine_lr
            saved_networks.append(net)
        else:
            # 4. Subsequent frames: Train once with reduced LR
            # Stop when loss is lower than first frame's final loss
            net.train(volume, lr=current_lr, stop_loss=first_frame_final_loss)
            saved_networks.append(net)

        prev_weights = net.get_weights()

    return saved_networks
```

**Parameters:**
*   $\eta_{\text{target}}$: Target learning rate for initial convergence. Typical value: Not given in the sources.
*   $\eta_{\text{fine}}$: Reduced learning rate for re-processing. Value: Up to 100 times smaller than $\eta_{\text{target}}$ [S1][S2, unofficial].
*   Stop Condition: Training iterations stop when loss becomes lower than the first frame's final loss [S1].

**Edge Cases and Pitfalls:**
*   **Flickering:** Naive cold-start encoding with a fixed learning rate causes discontinuities in network weights across frames, leading to flickering, especially in high-frequency details like thin smoke layers [S1].
*   **Domain Decomposition:** If new domains are added mid-sequence, the warm-start logic must be reset for that domain, re-running the target LR then fine LR process [S1].

## Operating characteristics
*   **Time Complexity:** Accelerates encoding by a factor of 1.5–2.5 compared to cold-start training [S1][S2, unofficial].
*   **Memory Complexity:** Requires storing the network weights for each frame during sequential processing [S1].
*   **Measured Performance:** Tested on NVIDIA RTX A40 GPUs and AMD EPYC 7502 CPU [S1].
*   **Strengths:** Ensures temporal coherence; reduces flickering in high-frequency details; speeds up training [S1][S2, unofficial].
*   **Limitations:** Sequential dependency (frame $i$ depends on $i-1$); requires careful LR tuning for the fine step [S1].
*   **When to Use:** Animated sparse volumes with high-frequency details (e.g., smoke, fire) where temporal coherence is critical [S1].
*   **When Not to Use:** Static volumes or sequences with no temporal coherence [G].

## Background
Introduced in NeuralVDB for encoding time-sequences of animated sparse volumes [S1][S2, unofficial]. It is similar to fine-tuning in transfer learning [Zhou et al. 2017], adapting to a new target without drifting too much from the old one [S1][S2, unofficial]. The method leverages the temporal coherency of input volumes to preserve coherency in output volumes [S1][S2, unofficial].
