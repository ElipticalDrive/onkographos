# Mip-NeRF Optimization and Activation Details

Also called: JaxNeRF Training Procedure, Mip-NeRF Misc. Changes

## Overview
This article defines the specific implementation details, activation functions, and optimization schedules used to train Mip-NeRF and JaxNeRF models. It addresses the problem of training instability and catastrophic failure modes (such as zero gradients from negative density predictions) that can occur with standard NeRF configurations. It sets itself apart from standard NeRF training by replacing ReLU with shifted softplus for density, using a widened sigmoid for color, removing identity encoding concatenation, and employing a specific warmup learning rate schedule [S1].

## How it works
The method consists of specific architectural choices for the MLP inputs and outputs, distinct activation functions for density and color, and a structured optimization loop.

### Inputs and Outputs
*   **Input:** Integrated Positional Encoding (IPE) features derived from the mean and covariance of the conical frustum. The original position and view direction are **not** concatenated with the IPE [S1].
*   **Output:** Density $\tau$ and color $c$.

### Data Structures and Layouts
The MLP processes the IPE features. The view direction is handled separately and injected at the final stage.

### Numbered Steps
1.  **Density Prediction:** The MLP takes the IPE features as input and outputs a scalar value $x_\tau$.
2.  **Density Activation:** Apply the shifted softplus activation to $x_\tau$ to obtain density $\tau$.
3.  **View Direction Handling:**
    *   Normalize the ray direction $\mathbf{d}$.
    *   Apply positional encoding with $L=4$ levels to $\mathbf{d}$ [S1].
    *   Inject the encoded view direction into the last layer of the MLP. This injection occurs after $\tau$ is predicted but before $c$ is predicted [S1].
4.  **Color Prediction:** The MLP (with view direction injected) outputs a scalar value $x_c$.
5.  **Color Activation:** Apply the widened sigmoid activation to $x_c$ to obtain color $c$ [S1].

### Formulas
**Density Activation:**
$$ \tau = \log(1 + \exp(x_\tau - 1)) $$
This is a shifted softplus function. The shift by $-1$ is equivalent to initializing the biases producing $\tau$ to $-1$, resulting in small initial density values [S1].

**Color Activation:**
$$ c = \frac{1 + 2\epsilon}{1 + \exp(-x_c)} - \epsilon $$
where $\epsilon = 0.001$. This "widened" sigmoid saturates slightly outside the $[0, 1]$ range to prevent optimization failure when explaining black or white pixels [S1].

**Learning Rate Schedule:**
The learning rate $\eta_i$ at iteration $i$ is defined as:
$$ \eta_i = \left( \lambda_w + (1 - \lambda_w) \sin\left(\frac{\pi}{2} \operatorname{clip}\left(\frac{i}{n_w}, 0, 1\right)\right) \right) \times \left( \exp\left( (1 - \frac{i}{n}) \log(\eta_0) + \frac{i}{n} \log(\eta_n) \right) \right) $$
where:
*   $n$ is the total number of iterations.
*   $n_w$ is the number of warmup iterations.
*   $\eta_0$ is the initial learning rate.
*   $\eta_n$ is the final learning rate.
*   $\lambda_w$ is a scale factor annealed from $0.01$ to $1$ during the warmup period [S1].

### Parameters
*   **Optimizer:** Adam [S1].
*   **Total Iterations ($n$):** 1,000,000 [S1].
*   **Batch Size:** 4096 [S1].
*   **Initial Learning Rate ($\eta_0$):** $5 \cdot 10^{-4}$ [S1].
*   **Final Learning Rate ($\eta_n$):** $5 \cdot 10^{-6}$ [S1].
*   **Warmup Iterations ($n_w$):** 2500 [S1].
*   **Warmup Start Factor ($\lambda_{w,start}$):** 0.01 [S1].
*   **Warmup End Factor ($\lambda_{w,end}$):** 1 [S1].
*   **View Direction PE Levels ($L$):** 4 [S1].
*   **Color Sigmoid Epsilon ($\epsilon$):** 0.001 [S1].

### Edge Cases and Pitfalls
*   **Negative Density:** Using ReLU for density can lead to catastrophic failure if the MLP emits negative values everywhere, causing zero gradients. The shifted softplus prevents this [S1].
*   **Black/White Pixel Saturation:** Standard sigmoid saturation can cause optimization failure when trying to explain extreme pixel values. The widened sigmoid mitigates this [S1].
*   **Identity Concatenation:** Concatenating identity (original position/view) with PE is removed because it makes the formalization of IPE features challenging and does not meaningfully improve performance or speed [S1].

import math

def shifted_softplus(x):
    """
    Density activation: log(1 + exp(x - 1))
    """
    return math.log(1 + math.exp(x - 1))

def widened_sigmoid(x, epsilon=0.001):
    """
    Color activation: (1 + 2*eps) / (1 + exp(-x)) - eps
    """
    return (1 + 2 * epsilon) / (1 + math.exp(-x)) - epsilon

def compute_learning_rate(i, n, n_w, eta_0, eta_n, lambda_w_current):
    """
    Compute the learning rate at iteration i.
    lambda_w_current is the current value of lambda_w (annealed from 0.01 to 1 during warmup).
    """
    # Warmup factor
    clip_val = min(max(i / n_w, 0), 1)
    warmup_factor = lambda_w_current + (1 - lambda_w_current) * math.sin(math.pi / 2 * clip_val)
    
    # Logarithmic annealing factor
    annealing_factor = math.exp((1 - i / n) * math.log(eta_0) + (i / n) * math.log(eta_n))
    
    return warmup_factor * annealing_factor

def train_mipnerf():

    eta_0 = 5e-4

        # Normalize ray direction
        d_normalized = normalize(ray_direction)

## Subtopics

### [Mip-NeRF 360 Optimization Setup](3426-mip-nerf-360-optimization-setup.md)
Defines the specific optimization configuration, network architectures, and loss functions used to train the Mip-NeRF 360 model. It solves the problem of stabilizing the training of unbounded, anti-aliased radiance fields by combining a multi-stage proposal sampling strategy with a robust reconstruction loss. It sets itself apart from standard NeRF training by using a two-stage proposal network to guide sampling and by employing a Charbonnier loss for reconstruction stability.

### [Scale-Dependent Downweighting for Grid Interpolation](8571-scale-dependent-downweighting-for-grid-interpolation.md)
Scale-Dependent Downweighting is a technique to anti-alias trilinear interpolation in neural radiance fields by downweighting features interpolated from grid cells that are small relative to the sampling Gaussian's spread, preventing aliasing artifacts from high-frequency content. Unlike naive trilinear interpolation which causes aliasing at high frequencies, this method uses the Gaussian CDF to weight samples, similar to Mip-NeRF's IPE features but applied to grid-based representations.

### Alternative Gaussian Positional Encoding
An alternative to Integrated Positional Encoding (IPE) involves concatenating the positional encodings of the mean and the (signed) square root of the covariance matrix elements as input to the MLP. Specifically, positional encoding with $L=12$ is applied to the mean $\mu$, and positional encoding with $L=2$ is applied to $\operatorname{vec}(\operatorname{triu}(\operatorname{sign}(\Sigma) \circ \sqrt{|\Sigma|}))$. This approach performs comparably to IPE but is sensitive to hyperparameters $L$ and covariance parameterization, whereas IPE is hyperparameter-free and compact. IPE features are insensitive to off-diagonal elements of $\Sigma$ (correlation), but experiments show that modeling this correlation does not improve accuracy [S1].

### Reflected Cone Derivation
A geometric derivation used in methods like NeRF-Casting to shift the origin of a reflected ray so that its cone radius matches the incident ray's cone radius at the intersection point, ensuring consistent view-dependent appearance for reflections. The condition for equating radii is $\dot{r}\|\bar{\mathbf{x}} - \mathbf{o}\| = \dot{r}'\|\bar{\mathbf{x}} - \mathbf{o}'\|$, where $\dot{r}$ is the incident ray radius parameter, $\bar{\mathbf{x}}$ is the intersection point, $\mathbf{o}$ is the incident ray origin, $\dot{r}'$ is the reflected ray radius parameter, and $\mathbf{o}'$ is the reflected ray origin. This is solved along with the constraint that $\mathbf{o}'$ lies on the reflected ray [S2].

### RawNeRF
A method for High Dynamic Range (HDR) image view synthesis and denoising that adapts Mip-NeRF to use raw linear images as training data, allowing post-processing after rendering. It renders in a linear color space and supervises with variable exposure images, scaling the NeRF models’ “exposure” by the training image’s shutter speed, as well as a per-channel learned scaling factor. Unlike HDR-NeRF which uses LDR images, RawNeRF uses raw linear images, allowing varying exposure and tone-mapping curves to be applied after NeRF rendering [S3].

## Operating characteristics
*   **Training Speed:** Mip-NeRF is 13x faster to train than a brute-force supersampling baseline (16 rays/pixel) [S1].
*   **Evaluation Speed:** Mip-NeRF is 16x faster to evaluate than the supersampling baseline [S1].
*   **Quality:** Mip-NeRF outperforms the 16x supersampling baseline in quality metrics (PSNR, SSIM, LPIPS) on the multiscale Blender dataset [S1].
*   **Stability:** The specific activation functions and learning rate schedule improve training stability, particularly when using larger learning rates or training ablations [S1].
*   **Memory:** The removal of identity concatenation and the use of IPE make the feature representation more compact compared to concatenating PE of mean and covariance square roots [S1].

## Background
The details described in this article originate from the Mip-NeRF paper (2021) by Barron et al. [S1]. These "miscellaneous" changes were included to improve robustness during optimization without significantly changing accuracy or speed. The training procedure is based on the JaxNeRF codebase [S1]. RawNeRF (2021) adapted these optimization principles for HDR image processing [S3]. The reflected cone derivation is detailed in NeRF-Casting (2024) [S2].
