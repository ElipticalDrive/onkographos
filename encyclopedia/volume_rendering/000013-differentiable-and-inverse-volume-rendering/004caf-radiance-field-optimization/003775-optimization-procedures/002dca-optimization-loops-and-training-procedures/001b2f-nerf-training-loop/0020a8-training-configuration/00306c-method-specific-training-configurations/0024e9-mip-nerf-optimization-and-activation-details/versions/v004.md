# Mip-NeRF Optimization and Activation Details

Also called: JaxNeRF Training Procedure, Mip-NeRF Misc. Changes

## Overview
This article specifies the implementation details for training mip-NeRF and JaxNeRF, focusing on activation functions, input encoding structures, and learning rate scheduling. These modifications are designed to improve training stability and robustness without significantly altering the method's accuracy or speed [S1]. Unlike the original NeRF implementation, mip-NeRF removes the identity concatenation from the MLP input and employs shifted/widened activation functions to prevent catastrophic failure modes during optimization [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ray origins, ray directions, integrated positional encoding (IPE) features for position and view direction, and iteration index $i$.
*   **Outputs:** Density $\tau$ and color $c$ for the ray segment.

**Data Structures:**
*   **MLP Input:** A vector containing only the integrated positional encoding (IPE) features. The original position and view direction vectors are **not** concatenated with the encoding [S1].
*   **View Direction Injection:** The view direction is processed separately and injected into the final layer of the MLP [S1].

**Numbered Steps:**
1.  **Input Preparation:** Compute the IPE for the position and view direction. Do not concatenate the raw position or view direction vectors to these features [S1].
2.  **Density Prediction:** Pass the IPE features through the MLP layers up to the density head. Apply the shifted softplus activation to produce $\tau$ [S1].
3.  **View Direction Handling:**
    *   Normalize the ray direction $d$ [S1].
    *   Apply positional encoding to $d$ with $L=4$ [S1].
    *   Inject the encoded view direction into the last layer of the MLP [S1].
4.  **Color Prediction:** After the view direction injection, apply the widened sigmoid activation to produce $c$ [S1].

**Formulas:**
*   **Density Activation (Shifted Softplus):**
    $$ \tau = \log(1 + \exp(x - 1)) $$
    Where $x$ is the pre-activation value. The shift by $-1$ is equivalent to initializing the bias of the density output to $-1$, resulting in small initial $\tau$ values [S1].

*   **Color Activation (Widened Sigmoid):**
    $$ c = \frac{1 + 2\epsilon}{1 + \exp(-x)} - \epsilon $$
    Where $\epsilon = 0.001$ and $x$ is the pre-activation value. This function saturates slightly outside the $[0, 1]$ range to avoid optimization failure when explaining black or white pixels [S1].

*   **Learning Rate Schedule:**
    $$ \eta_i = (\lambda_w + (1 - \lambda_w) \sin((\pi/2) \operatorname{clip}(i/n_w, 0, 1))) \times (\exp((1 - i/n) \log(\eta_0) + (i/n) \log(\eta_n))) $$
    Where:
    *   $i$ is the current iteration.
    *   $n$ is the total number of iterations.
    *   $n_w$ is the number of warmup iterations.
    *   $\eta_0$ is the initial learning rate.
    *   $\eta_n$ is the final learning rate.
    *   $\lambda_w$ is a scale factor annealed from $0.01$ to $1$ during the warmup period [S1].

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Total Iterations ($n$):** 1,000,000 [S1].
*   **Batch Size:** 4096 [S1].
*   **Initial Learning Rate ($\eta_0$):** $5 \cdot 10^{-4}$ [S1].
*   **Final Learning Rate ($\eta_n$):** $5 \cdot 10^{-6}$ [S1].
*   **Warmup Iterations ($n_w$):** 2500 [S1].
*   **Warmup Scale Factor ($\lambda_w$):** Annealed from $0.01$ to $1$ during the first $n_w$ iterations [S1].
*   **View Direction PE Levels ($L$):** 4 [S1].

**Edge Cases and Pitfalls:**
*   **Negative Density:** Using standard ReLU for density can cause catastrophic failure if the MLP emits negative values everywhere, resulting in zero gradients. The shifted softplus prevents this [S1].
*   **Color Saturation:** Standard sigmoid saturation can cause optimization failure when explaining extreme pixel values (black/white). The widened sigmoid mitigates this [S1].
*   **Identity Concatenation:** Concatenating raw position/view direction with IPE is unnecessary and complicates the formalization of IPE features. It should be removed [S1].

**Pseudocode:**
```python
import math
import numpy as np

def shifted_softplus(x):
    """
    Density activation function.
    Equivalent to log(1 + exp(x - 1)).
    """
    return np.log(1 + np.exp(x - 1))

def widened_sigmoid(x, epsilon=0.001):
    """
    Color activation function.
    Saturates slightly outside [0, 1].
    """
    return (1 + 2 * epsilon) / (1 + np.exp(-x)) - epsilon

def positional_encoding(x, L=4):
    """
    Standard sinusoidal positional encoding.
    Assumes x is a vector of coordinates.
    Returns concatenated sin/cos frequencies.
    """
    # Implementation detail: Standard PE maps x to [sin(2^0 pi x), cos(2^0 pi x), ..., sin(2^(L-1) pi x), cos(2^(L-1) pi x)]
    # This is a placeholder for the specific PE implementation used in mip-NeRF.
    # In practice, this involves scaling x by powers of 2 and applying sin/cos.
    # For the purpose of this article, we assume this function exists and returns the encoded vector.
    pass

def compute_learning_rate(i, n, n_w, eta_0, eta_n):
    """
    Compute the learning rate at iteration i.
    """
    # Anneal lambda_w from 0.01 to 1 during warmup
    # clip(i/n_w, 0, 1) ensures we stay within [0, 1]
    progress = min(i / n_w, 1.0)
    lambda_w = 0.01 + (1 - 0.01) * math.sin((math.pi / 2) * progress)
    
    # Logarithmic annealing for the base learning rate
    base_lr = math.exp((1 - i / n) * math.log(eta_0) + (i / n) * math.log(eta_n))
    
    return lambda_w * base_lr

def mip_nerf_forward(mlp, position, view_direction, ipe_position, ipe_view_direction, i, n, n_w, eta_0, eta_n):
    """
    Forward pass for mip-NeRF with specific optimization details.
    
    Args:
        mlp: The neural network model.
        position: Raw 3D position vector.
        view_direction: Raw ray direction vector.
        ipe_position: Integrated positional encoding for position.
        ipe_view_direction: Integrated positional encoding for view direction.
        i: Current iteration index.
        n: Total iterations.
        n_w: Warmup iterations.
        eta_0: Initial learning rate.
        eta_n: Final learning rate.
        
    Returns:
        tau: Density.
        c: Color.
        grad: Gradients (computed by autograd framework).
    """
    # Step 1: Input Preparation
    # Do NOT concatenate raw position or view direction.
    # Input to MLP is only IPE features.
    mlp_input = ipe_position
    
    # Step 2: Density Prediction
    # Pass through MLP layers up to density head
    # Apply shifted softplus
    tau_pre_activation = mlp.layers_before_density(mlp_input)
    tau = shifted_softplus(tau_pre_activation)
    
    # Step 3: View Direction Handling
    # Normalize ray direction
    d_normalized = view_direction / np.linalg.norm(view_direction)
    
    # Apply positional encoding with L=4
    view_pe = positional_encoding(d_normalized, L=4)
    
    # Inject into the last layer of the MLP
    # This is done after tau is predicted but before c is predicted
    # In practice, this means the view PE is added to the features 
    # entering the final color prediction layer.
    features_for_color = mlp.layers_before_color(mlp_input) + view_pe
    
    # Step 4: Color Prediction
    c_pre_activation = mlp.color_head(features_for_color)
    c = widened_sigmoid(c_pre_activation)
    
    return tau, c
```

## Operating characteristics
*   **Training Speed:** Mip-NeRF is 13x faster to train than a brute-force supersampling baseline (16 rays/pixel) [S1].
*   **Evaluation Speed:** Mip-NeRF is 16x faster to evaluate than the supersampling baseline [S1].
*   **Quality:** Mip-NeRF outperforms the supersampling baseline in quality metrics (PSNR, SSIM, LPIPS) [S1].
*   **Stability:** The modified activation functions and learning rate schedule improve training stability, particularly with large learning rates or during ablation studies [S1].
*   **Memory:** The removal of identity concatenation reduces input dimensionality slightly, but the primary memory savings come from the unified multiscale model compared to NeRF's separate per-scale models [S1].

## Background
*   **Origin:** The details described in this article are from the "Miscellaneous Changes" section of the Mip-NeRF paper [S1].
*   **Purpose:** These changes were identified as not significantly affecting accuracy or speed but were included to simplify the method and increase robustness during optimization [S1].
*   **Comparison:** The IPE features used in mip-NeRF are preferred over concatenating positional encodings of mean and covariance square roots because IPE is more compact, easier to justify, and has no hyperparameters [S1].
