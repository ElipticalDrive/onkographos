# Activation-Informed Coarse-to-Fine Rendering

Also called: Activation-based early exit, Masked fine pass

## Overview
This method accelerates NeRF rendering by skipping the expensive fine-pass MLP evaluation for rays identified as empty or background using intermediate activation values from the coarse pass [S1]. It differs from standard coarse-to-fine rendering by introducing a conditional skip mechanism based on activation statistics rather than fixed ray traversal or density thresholds alone [S1].

## How it works
**Inputs:**
- Coarse MLP $\Theta_{\text{coarse}}$ and Fine MLP $\Theta_{\text{fine}}$.
- Ray $r$ for each pixel $(x, y)$.
- Positional encoding function $\gamma(\cdot)$.
- Number of coarse samples $N_c$ and fine samples $N_f$.
- Layer index $\ell$ for activation analysis.

**Outputs:**
- Final radiance $\hat{C}$ for each pixel.

**Data Structures:**
- Activation tensor $A^{(\ell)} \in \mathbb{R}^{N_s \times N_h}$, where $N_s$ is the number of samples along the ray and $N_h$ is the number of hidden units in layer $\ell$ [S1].
- Scalar activation $v_\ell$ per ray [S1].
- Threshold $\tau$ [S1].
- Set of rays $P$ requiring fine pass [S1].

**Steps:**
1. For each pixel $(x, y)$, generate ray $r$ and apply positional encoding $\gamma(\cdot)$ to sample points [S1].
2. Pass samples along $r$ through $\Theta_{\text{coarse}}$ to obtain predicted densities $\sigma$ and intermediate activations $A^{(\ell)}$ [S1].
3. Compute the scalar activation $v_\ell$ for the ray by summing all elements of $A^{(\ell)}$ and dividing by the total number of elements ($N_s \times N_h$) [S1]:
   $$ v_\ell = \frac{1}{N_s} \sum_{i=1}^{N_s} \sum_{j=1}^{N_h} A^{(\ell)}_{i,j} $$
   Note: $A^{(\ell)}$ is recorded after the ReLU activation function has been applied [S1].
4. Calculate the threshold $\tau$ as the mean activation $\mu(V_\ell)$ of the activation image $V_\ell$ across all rays/pixels [S1].
5. Identify the set of rays $P$ where $v_\ell < \tau$. These rays are treated as having no significant scene content [S1].
6. For rays $r \in P$, evaluate $\Theta_{\text{fine}}$ to compute final radiance. For rays $r \notin P$, use the coarse radiance $\hat{C}_c$ as the final output [S1].

**Parameters:**
- $\tau$: Threshold for skipping fine pass. Value: $\mu(V_\ell)$, the mean of the activation image $V_\ell$ [S1].
- $\ell$: Layer index for activation analysis. Typical value: 1, 2, or 3. Applying to earlier layers accelerates inference more substantially [S1].

**Edge Cases and Pitfalls:**
- The method relies on transparent backgrounds found in synthetic scenes (e.g., Blender dataset) [S1].
- It fails on real-world scenes with detailed backgrounds, necessitating a density approximation method instead [S1].

**Pseudocode:**
```python
def activation_informed_rendering(ray, theta_coarse, theta_fine, layer_index, all_activations):
    # 1. Generate ray and apply positional encoding
    # (Assume ray generation and encoding are handled by the caller or standard NeRF setup)
    
    # 2. Pass through coarse MLP
    # theta_coarse returns densities and intermediate activations
    densities, activations = theta_coarse(ray, layer_index)
    
    # 3. Compute scalar activation v_l
    # activations shape: (N_s, N_h)
    # N_s = number of samples, N_h = number of hidden units
    N_s, N_h = activations.shape
    v_l = torch.sum(activations) / (N_s * N_h)
    
    # 4. Calculate threshold tau
    # all_activations is a list/array of v_l for all rays processed in the current batch/frame
    tau = torch.mean(torch.tensor(all_activations))
    
    # 5. Determine if fine pass is needed
    if v_l < tau:
        # 6a. Evaluate fine MLP
        radiance = theta_fine(ray)
    else:
        # 6b. Use coarse radiance
        # (Assume theta_coarse also returns coarse radiance or it is computed from densities)
        radiance = compute_coarse_radiance(densities)
        
    return radiance, v_l
```

## Subtopics

### Density Approximation
Uses activation features to estimate density directly, bypassing the coarse MLP for real-world scenes with detailed backgrounds [S1].

### Proposal Network Integration
Applied to proposal network samplers (e.g., in Nerfacto) to accelerate sampling [S1].

## Operating characteristics
- **Time Complexity:** Reduces the number of fine MLP evaluations. On the Blender 'lego' scene (800x800), using layer 1 achieved a 34.69% speedup with 40% of rays processed by the fine pass [S1]. Using layer 3 achieved a 55% speedup with 47% of rays processed by the fine pass [S1].
- **Memory Complexity:** Requires storing intermediate activations for all rays to compute the mean threshold $\tau$ [S1].
- **Measured Performance:**
  - Layer 1: PSNR 29.66, SSIM 0.93, LPIPS 0.04 [S1].
  - Layer 3: PSNR 31.21, SSIM 0.95, LPIPS 0.02 [S1].
  - Full NeRF: PSNR 32.20, SSIM 0.96, LPIPS 0.02 [S1].
- **Strengths:** Significant performance improvement with negligible image quality loss on synthetic scenes with transparent backgrounds [S1].
- **Limitations:** Fails on real-world scenes with detailed backgrounds [S1].

## Background
Originated in the analysis of neural radiance field internals, specifically leveraging the observation that intermediate activations contain notable structural information and correlate with density [S1]. The method was applied to NeRF and Mip-NeRF models [S1].
