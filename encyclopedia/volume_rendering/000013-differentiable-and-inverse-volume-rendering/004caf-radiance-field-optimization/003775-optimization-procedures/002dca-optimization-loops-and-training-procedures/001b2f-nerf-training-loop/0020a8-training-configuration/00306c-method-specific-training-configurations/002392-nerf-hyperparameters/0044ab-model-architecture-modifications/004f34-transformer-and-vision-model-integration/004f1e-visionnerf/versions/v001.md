# VisionNeRF

Also called: Vision Transformer for NeRF

## Overview
VisionNeRF is a novel view synthesis method that infers a 3D representation from a single unposed input image by combining global features learned from a Vision Transformer (ViT) and local appearance features extracted from a 2D CNN, rendered via a NeRF-based MLP [S1]. It distinguishes itself from sibling methods like [ViT-NeRF](13878-vit-nerf.md) and [TransNeRF](13907-transnerf.md) by explicitly addressing self-occlusion in single-image settings through long-range dependency modeling via self-attention, allowing it to retrieve relevant features from distant parts of the source view for occluded regions, whereas standard image-conditioned models query features along the ray corresponding to the visible surface in the input view [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A single unposed image $I_s$ at camera $s$. No camera pose information is required [S1].
*   **Output:** A rendered novel view image for a target camera pose (which must be provided at inference time for ray casting, though the model itself does not learn pose from the input image) [S1].

**Data Structures:**
1.  **Feature Tokens:** A sequence of vectors resulting from the ViT encoder.
2.  **Multi-level Feature Maps:** A set of 2D feature maps at different resolutions (coarse-to-fine) derived from unflattened and resampled ViT tokens [S1].
3.  **Local Feature Maps:** 2D feature maps extracted by the CNN [S1].
4.  **NeRF MLP:** A multi-layer perceptron that takes 3D coordinates and concatenated features as input and outputs color and density [S1].

**Numbered Steps:**
1.  **Global Feature Extraction:** Lift the input 2D image $I_s$ into feature tokens and apply a Vision Transformer (ViT) to learn global information [S1].
2.  **Feature Map Construction:** Unflatten the feature tokens and resample them into multi-level feature maps to capture global information in a coarse-to-fine manner [S1].
3.  **Local Feature Extraction:** Extract local features from the input image using a 2D convolutional neural network (CNN) to capture details and appearance [S1].
4.  **Volume Rendering:** Train a multi-layer perceptron (MLP) network conditioned on the learned 3D representation (global ViT features and local CNN features) to perform volume rendering for novel viewpoints [S1].

**Formulas and Definitions:**
*   Let $I_s$ be the input image.
*   Let $F_{global}$ be the global feature representation derived from the ViT.
*   Let $F_{local}$ be the local feature representation derived from the CNN.
*   The NeRF MLP $\mathcal{M}$ takes a 3D point $\mathbf{x}$ and the concatenated features $\mathbf{c} = \text{Interpolate}(F_{global}, \mathbf{x}) \oplus \text{Interpolate}(F_{local}, \mathbf{x})$ as input, where $\text{Interpolate}$ denotes sampling the feature maps at the projected 2D location of $\mathbf{x}$, and $\oplus$ denotes concatenation.
*   The MLP outputs density $\sigma$ and color $\mathbf{c}_{out}$:
    $$ (\sigma, \mathbf{c}_{out}) = \mathcal{M}(\mathbf{x}, \mathbf{c}) $$
*   The final pixel color $C(r)$ for a ray $r$ is computed via standard volumetric rendering:
    $$ C(r) = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i, \quad \text{where } \alpha_i = 1 - \exp(-\sigma_i \delta_i), \quad T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) $$
    where $\delta_i$ is the distance between samples [S1].

**Parameters:**
*   **Coordinate System:** Viewer-centered coordinate system. The method does not enforce constraints like symmetry or canonical coordinate systems [S1].
*   **Training Data:** ShapeNet dataset (13 object categories) and real-world images [S1].

**Pitfalls and Edge Cases:**
*   **Self-occlusion:** Standard image-conditioned models suffer from incorrect feature conditioning when a target view pixel is invisible from the input view. For example, rendering an occluded wheel might incorrectly use features from a visible window [S1]. VisionNeRF mitigates this by using self-attention to find long-range dependencies, retrieving relevant features from distant parts of the source view [S1].
*   **Unposed Input:** The method requires no camera pose for the input image, but novel view synthesis still requires specifying the target camera pose for ray generation [S1].

**Pseudocode:**
```python
def vision_nerf_forward(input_image, target_camera_poses):
    """
    Renders novel views from a single unposed image.
    
    Args:
        input_image: Tensor of shape (H, W, 3) or (B, H, W, 3).
        target_camera_poses: Tensor of shape (B, N, 4, 4) or similar, defining 
                             the extrinsics for N rays per image.
                             
    Returns:
        rendered_images: Tensor of shape (B, N, H, W, 3).
    """
    # Step 1: Global Feature Extraction via ViT
    # Lift image to tokens and apply ViT
    # Note: Exact ViT architecture (patch size, layers, heads) is not specified in sources [S1]
    global_tokens = vit_encoder(input_image)
    
    # Step 2: Construct Multi-level Feature Maps
    # Unflatten tokens and resample into coarse-to-fine feature maps
    # Note: Specific resampling strategy (e.g., bilinear, nearest) and number of levels 
    # are not specified in sources [S1]
    global_feature_maps = unflatten_and_resample(global_tokens)
    
    # Step 3: Local Feature Extraction via CNN
    # Extract local features capturing details and appearance
    # Note: Specific CNN architecture (e.g., ResNet, U-Net) is not specified in sources [S1]
    local_feature_maps = cnn_encoder(input_image)
    
    # Step 4: Volume Rendering
    rendered_images = []
    for camera_pose in target_camera_poses:
        # Generate rays from camera pose
        rays = generate_rays(camera_pose)
        
        # Sample points along rays
        points = sample_points_along_rays(rays)
        
        # Interpolate features at 3D points
        # Interpolate global and local features at the 2D projection of each 3D point
        global_feats = interpolate_features(global_feature_maps, points)
        local_feats = interpolate_features(local_feature_maps, points)
        
        # Concatenate features
        combined_feats = concatenate(global_feats, local_feats)
        
        # Query NeRF MLP for density and color
        # Note: MLP architecture (layers, dimensions) is not specified in sources [S1]
        densities, colors = nerf_mlp(points, combined_feats)
        
        # Perform volumetric rendering
        image = volumetric_render(rays, points, densities, colors)
        rendered_images.append(image)
        
    return concatenate(rendered_images, axis=0)
```

## Operating characteristics
*   **Performance:** On the ShapeNet dataset, VisionNeRF achieves LPIPS: 0.09 and PSNR: 21.03 for novel views [S1]. This compares to PixelNeRF's LPIPS: 0.20 and PSNR: 21.85 [S1]. VisionNeRF shows superior perceptual quality (lower LPIPS) in occluded regions, while PixelNeRF has a slightly higher PSNR [S1].
*   **Comparison with SRT:** Unlike SRT, which learns 3D scene information as a set of latent code decoded by a transformer, VisionNeRF adopts a radiance field representation using per-pixel information from feature maps, providing an explicit mapping between the input image and 3D point queries [S1]. VisionNeRF achieves favorable results over SRT in PSNR and SSIM metrics [S1].
*   **Strengths:** Handles self-occlusion better than standard image-conditioned models by leveraging long-range dependencies via self-attention [S1]. Generalizes across multiple object categories using a single model [S1]. Renders richer details in occluded regions [S1].
*   **Limitations:** Performance in PSNR is slightly lower than PixelNeRF [S1]. Requires training a ViT and CNN, which may be computationally expensive during training [S1].

## Background
VisionNeRF was proposed to address the limitation of existing approaches that use local image features to reconstruct a 3D object, which often render blurry predictions at viewpoints distant from the source view due to self-occlusion [S1]. The method was introduced by Wei-Sheng Lai, Ravi Ramamoorthi, and Tsung-Yi Lin, with work done while interning at Google and at Google, respectively [S1]. It was published in the IEEE Winter Conference on Applications of Computer Vision (WACV) in 2023 [S1]. The method is trained and evaluated on the ShapeNet dataset including 13 object categories, as well as real-world images [S1].
