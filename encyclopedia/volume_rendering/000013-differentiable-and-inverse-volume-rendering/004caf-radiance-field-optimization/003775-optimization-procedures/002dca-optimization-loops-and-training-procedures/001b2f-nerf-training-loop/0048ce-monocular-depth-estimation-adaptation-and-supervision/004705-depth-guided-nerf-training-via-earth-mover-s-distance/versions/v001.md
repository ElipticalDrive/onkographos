# Depth-Guided NeRF Training via Earth Mover’s Distance

Also called: Depth-guided NeRF via Earth Mover’s Distance, EM D-Guided Sampling, EMD-Guided Depth Supervision for NeRF, EMD-NeRF, EMD-based objective

## Overview
This method improves the geometric understanding of Neural Radiance Fields (NeRFs) in sparse-view settings by supervising the distribution of ray termination distances using Earth Mover’s Distance (EMD) rather than enforcing direct depth matching via L2 loss [S1]. It utilizes off-the-shelf monocular depth priors from diffusion models (specifically DiffDP) to provide depth estimates and intrinsic uncertainty maps, weighting the photometric and depth losses to selectively incorporate prior information without propagating prior inaccuracies [S1]. Unlike [DäRF](10371-darf.md) which directly supervises rendered depth, or [SCADE](10371-scade.md) which uses multiple ambiguous hypotheses, this approach guides the ray termination distribution to avoid wrong geometry understanding while maintaining photometric quality [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A set of $N$ input images $\{I_i\}_{i=1}^N$ (typically $N < 20$) and their corresponding Structure-from-Motion (SfM) camera poses [S1].
*   A pre-trained monocular depth estimation network, specifically DiffDP [11], used to generate depth priors and uncertainty maps [S1].
*   NeRF hyperparameters: number of coarse samples ($N_c=64$), fine samples ($N_f=128$), and additional EMD samples ($N_{EMD}=128$) [S1].

**Outputs:**
*   A trained NeRF network $F_\Theta$ that maps 3D coordinates and viewing directions to color $c$ and volume density $\sigma$ [S1].
*   Rendered novel views with improved geometric consistency [S1].

### Data Structures
*   **NeRF Network ($F_\Theta$):** A multilayer perceptron taking camera position $(x_i, y_i, z_i)$ and viewing direction $(\theta_i, \phi_i)$ as input, outputting color $c_i$ and volume density $\sigma_i$ [S1].
*   **Depth Prior ($z_0$):** A dense depth map generated by DiffDP for each input image [S1].
*   **Uncertainty Map ($u$):** A pixel-wise map in $[0, 1]$ derived from the DiffDP denoising process, indicating the reliability of the depth prior [S1].
*   **Ray Samples:** A set of termination distances $y$ sampled from the NeRF's predicted distribution [S1].

### Steps

1.  **Generate Depth Prior and Uncertainty:**
    Use the DiffDP network to predict depth $z_0$ and uncertainty for each input image. DiffDP formulates denoising as $p_\theta(z_{0:T}|I)$. The uncertainty is derived by comparing estimates at each time step $t$ [S1].
    
    Calculate the temporal uncertainty count $c(z_{0:T})$ by comparing the current estimate $z_t$ to the previous one $z_{t-1}$:
    $$ c(z_{0:T}) = \frac{1}{T} \sum_{t=T,...,1} \mathbb{I}(|z_t - z_{t-1}| \ge \tau) $$
    where $\tau$ is a threshold [S1].
    
    Compute the final uncertainty $U(z_{0:T}|I)$ by combining temporal uncertainty with spatial consistency using a mirrored image $M(I)$:
    $$ U(z_{0:T}|I) = \frac{c(z_{0:T}|I) + M(c(z_{0:T}|M(I)))}{2} $$
    $$ u(z_{0:T}|I) = U(z_{0:T}|I) \cdot \| (z_0|I) - M(z_0|M(I)) \|_1 $$
    The uncertainty map $u$ is normalized to $[0, 1]$ [S1].

2.  **NeRF Forward Pass and Weight Calculation:**
    For a ray $r$, sample $N_c$ points for the coarse network and $N_f$ points for the fine network within the interval $(near, far)$. For each sample $i$, the network outputs density $\sigma_i$ [S1].
    
    Calculate the weight $w_i$ as the probability that the ray traverses space without obstruction until sample $i$:
    $$ w_i = T_i (1 - \exp(-\sigma_i \delta_i)) $$
    where $\delta_i$ is the distance between samples, and $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance [S1].

3.  **EMD-Guided Sampling:**
    Normalize the weights to form a piece-wise constant probability density function (PDF):
    $$ \hat{w}_i = \frac{w_i}{\sum_{j=1}^{N} w_j} $$
    Construct the Cumulative Distribution Function (CDF) from $\hat{w}_i$. Sample new ray termination distances $y = \{y_1, y_2, ..., y_{N_{EMD}}\}$ using inverse transform sampling [S1]. These samples represent the NeRF's learned distribution of ray terminations [S1].

4.  **Compute Losses:**
    *   **Photometric Loss ($L_{photo}$):** Standard L2 loss between observed color $C(r)$ and expected color $\hat{C}(r)$:
        $$ L_{photo} = ||\hat{C}(r) - C(r)||_2^2 $$
        where $\hat{C}(r) = \sum w_l c_l$ [S1].
    *   **EMD Loss ($L_{EMD}$):** Compute the Earth Mover’s Distance between the sampled ray termination distances $y$ and the depth prior $z_0$. Since EMD is non-differentiable, approximate it using Sinkhorn Divergence [S1]:
        $$ L_{EMD} = EMD(y, z_0) $$
        [S1].

5.  **Loss Weighting and Optimization:**
    Combine the losses using the uncertainty map $u$ and balancing weight $\lambda$:
    $$ L = (1 + u)^\gamma L_{photo} + \lambda (1 - u)^\gamma L_{EMD} $$
    where $\gamma$ controls the impact of uncertainty [S1]. Unlike Focal Loss which increases weight for uncertain examples, this method applies *less* weight to uncertain pixels for depth supervision, relying more on photometric loss when depth is unreliable [S1].
    
    Optimize the NeRF parameters $\Theta$ using gradient descent. Typical parameters include a learning rate of 1 for depth prior scale initialization, 1024 rays per batch, dropout probability 0.1, and weight decay $1e-6$ [S1].

### Pseudocode

```python
import torch
import torch.nn as nn
import torch.optim as optim
from geomloss import SamplesLoss # Sinkhorn Divergence implementation

class DepthGuidedNeRF:
    def __init__(self, nerf_model, diffdp_model, num_coarse=64, num_fine=128, num_emd_samples=128):
        self.nerf = nerf_model
        self.diffdp = diffdp_model
        self.num_coarse = num_coarse
        self.num_fine = num_fine
        self.num_emd_samples = num_emd_samples
        self.sinkhorn_loss = SamplesLoss(loss="sinkhorn", p=1, blur=0.1)
        
    def get_depth_prior_and_uncertainty(self, image):
        """
        Generates depth prior z0 and uncertainty map u using DiffDP.
        """
        # DiffDP denoising process p_theta(z_0:T | I)
        # z_t ~ N(0, I)
        # Decoder denoises z_t conditioned on image features
        
        # Calculate temporal uncertainty count
        # c(z_0:T) = (1/T) * sum(I(|z_t - z_{t-1}| >= tau))
        # Note: Exact tau and T are implementation details of DiffDP [S1]
        temporal_uncertainty = self.diffdp.get_temporal_uncertainty(image)
        
        # Mirror image M(I)
        mirrored_image = self.diffdp.mirror(image)
        mirrored_uncertainty = self.diffdp.get_temporal_uncertainty(mirrored_image)
        
        # Final uncertainty U
        U = (temporal_uncertainty + self.diffdp.mirror(mirrored_uncertainty)) / 2.0
        
        # Augmented uncertainty u
        z0 = self.diffdp.predict_depth(image)
        z0_mirrored = self.diffdp.predict_depth(mirrored_image)
        spatial_diff = torch.abs(z0 - self.diffdp.mirror(z0_mirrored))
        u = U * spatial_diff.mean(dim=1, keepdim=True) # Simplified L1 norm aggregation
        
        # Normalize u to [0, 1]
        u = torch.clamp(u, 0, 1)
        return z0, u

    def sample_ray_distances(self, ray_origins, ray_directions, near, far):
        """
        Samples ray termination distances from the NeRF's predicted distribution.
        """
        # 1. Sample N_coarse + N_fine points along the ray
        t_vals = torch.linspace(near, far, self.num_coarse + self.num_fine)
        points = ray_origins.unsqueeze(1) + t_vals.unsqueeze(0).unsqueeze(0) * ray_directions.unsqueeze(1).unsqueeze(0)
        
        # 2. Forward pass through NeRF to get density sigma
        # F_theta(x, y, z, theta, phi) -> (c, sigma)
        # Note: Direction (theta, phi) derived from ray_directions
        sigma = self.nerf.get_density(points)
        
        # 3. Calculate weights w_i = T_i * (1 - exp(-sigma_i * delta_i))
        delta = t_vals[1:] - t_vals[:-1]
        delta = torch.cat([delta, torch.tensor([1e-10])]) # Handle last sample
        
        # Accumulated transmittance T_i
        alpha = 1.0 - torch.exp(-sigma * delta.unsqueeze(-1)) # Assuming delta is broadcastable
        T = torch.cumprod(1.0 - alpha, dim=0)
        T = torch.cat([torch.ones_like(T[:1]), T[:-1]])
        
        weights = T * alpha
        
        # 4. Normalize weights to PDF
        weights = weights / weights.sum()
        
        # 5. Construct CDF and sample N_emd_samples via inverse transform
        cdf = torch.cumsum(weights, dim=0)
        u_samples = torch.rand(self.num_emd_samples)
        # Inverse transform sampling (approximated via search or interpolation)
        y = torch.searchsorted(cdf, u_samples)
        y = t_vals[y]
        
        return y

    def compute_loss(self, ray_origins, ray_directions, image_pixels, depth_prior, uncertainty_map):
        """
        Computes the total loss for a batch of rays.
        """
        # 1. Photometric Loss
        # Render color C_hat(r) = sum(w_l * c_l)
        # L_photo = ||C_hat(r) - C(r)||^2
        # Note: Standard NeRF rendering logic required here [S1]
        rendered_color = self.nerf.render_ray(ray_origins, ray_directions)
        l_photo = torch.mean((rendered_color - image_pixels) ** 2)
        
        # 2. EMD Loss
        # Sample ray termination distances y
        y = self.sample_ray_distances(ray_origins, ray_directions, near=0.0, far=1.0)
        
        # Depth prior z0 corresponding to the ray's pixel
        # z0 is the depth value from the prior map at the pixel location
        z0 = depth_prior[ray_indices] 
        
        # L_EMD = EMD(y, z0) approximated by Sinkhorn Divergence
        # y and z0 are 1D tensors of samples
        l_emd = self.sinkhorn_loss(y, z0)
        
        # 3. Weighted Loss
        # L = (1 + u)^gamma * L_photo + lambda * (1 - u)^gamma * L_EMD
        gamma = 1.0 # Typical value not explicitly given, assume 1
        lambda_bal = 1.0 # Balancing weight
        u = uncertainty_map[ray_indices]
        
        l_photo_weighted = (1 + u) ** gamma * l_photo
        l_emd_weighted = lambda_bal * (1 - u) ** gamma * l_emd
        
        total_loss = l_photo_weighted + l_emd_weighted
        return total_loss

    def train_step(self, batch):
        optimizer = self.optimizer
        optimizer.zero_grad()
        
        rays = batch['rays']
        images = batch['images']
        depth_priors = batch['depth_priors']
        uncertainties = batch['uncertainties']
        
        loss = self.compute_loss(
            rays['origins'], 
            rays['directions'], 
            images, 
            depth_priors, 
            uncertainties
        )
        
        loss.backward()
        optimizer.step()
        return loss.item()
```

### Parameters
*   **N:** Number of input images, typically $N < 20$ [S1].
*   **Learning Rate:** 1 for depth prior scale initialization [S1].
*   **Rays per batch:** 1024 [S1].
*   **Ray termination distances (Coarse):** 64 [S1].
*   **Ray termination distances (Fine):** 128 [S1].
*   **Additional EMD samples:** 128 [S1].
*   **Dropout probability:** 0.1 [S1].
*   **Weight decay:** $1e-6$ [S1].
*   **$\lambda$:** Balancing weight between photometric and EMD losses [S1].
*   **$\gamma$:** Exponent controlling the impact of uncertainty $u$ [S1].

### Edge Cases and Pitfalls
*   **Photometric vs. Geometric Quality:** High PSNR/SSIM does not guarantee correct geometry. Models may render plausible images while misinterpreting structure (e.g., misinterpreting a cabinet as a carpet pattern) [S1].
*   **Uncertainty Handling:** Unlike Focal Loss which up-weights uncertain examples, this method down-weights uncertain pixels for depth supervision to avoid propagating errors [S1].
*   **Prior Noise:** Using multiple depth hypotheses (as in SCADE) can introduce noise and training instability dependent on random seeds. This method uses a single prior to avoid this [S1].
*   **Diffusion Uncertainty:** The uncertainty measure is specific to diffusion-based models like DiffDP. It may not be directly applicable to other depth estimation networks without modification [S1].

## Operating characteristics

### Time and Memory Complexity
*   **Time:** The method adds the cost of running the DiffDP prior (once per image for prior construction) and the Sinkhorn Divergence calculation during each training step. The Sinkhorn approximation is efficient but adds overhead compared to simple L2 depth loss [S1].
*   **Memory:** Requires storing the depth prior and uncertainty map for each input image. The NeRF model size is standard. Additional samples for EMD ($N_{EMD}=128$) increase the memory footprint for ray sampling slightly [S1].

### Measured Performance
*   **ScanNet+:** Reduces baseline RMSE by at least 56% while maintaining comparable photometric results (PSNR/SSIM) [S1].
*   **Prior Improvement:** With DiffDP prior, EMD objective reduces initial prior RMSE by 31.4%; with DepthAnything prior, reduces it by 18.8% [S1].
*   **Uncertainty Impact:** For pixels with uncertainty $> 0.8$, incorporating $u$ improves RMSE by 5.1%. For pixels with uncertainty $< 0.1$, it helps by only 1.9% [S1].

### Scaling
*   The method is designed for sparse-view settings ($N < 20$). It scales with the number of images but relies heavily on the quality of the monocular prior [S1].

### Strengths and Limitations
*   **Strengths:** Robust to inaccurate depth priors by using EMD instead of L2. Leverages intrinsic uncertainty from diffusion models. Improves geometric accuracy without sacrificing photometric quality. Simple drop-in replacement for existing depth-supervised NeRFs [S1].
*   **Limitations:** Uncertainty measure is specific to diffusion-based priors. Sensitive to hyperparameters in uncertainty map construction. Does not handle dynamic scenes or multi-modal depth distributions as explicitly as methods using multiple hypotheses (though it avoids the noise associated with them) [S1].

### When to Use
*   Use for sparse-view NeRF reconstruction in challenging indoor scenes (e.g., ScanNet) where geometric accuracy is critical and monocular depth priors are available [S1].
*   Use when standard L2 depth supervision leads to geometric inaccuracies due to noisy priors [S1].

### When Not to Use
*   Do not use if only non-diffusion-based depth priors are available, as the specific uncertainty measure relies on the diffusion denoising process [S1].
*   Do not use if real-time training speed is the primary constraint and the overhead of Sinkhorn Divergence is prohibitive [S1].

## Background

### Origin
The method was introduced by A. Rau et al. in the paper "Depth-Guided NeRF Training via Earth Mover’s Distance" [S1]. It addresses the limitation of NeRFs in sparse-view settings where they often fail to learn accurate geometry despite good photometric results [S1].

### History and Development
Previous methods like DäRF directly supervised NeRF-rendered depth using L2 loss, which forced the NeRF to approximate potentially inaccurate priors [S1]. SCADE used multiple depth hypotheses and a space-carving loss, but this introduced noise and instability [S1]. This method replaces L2 loss with EMD to guide the ray termination distance distribution, leveraging uncertainty from DiffDP to weight the losses [S1].

### Usage
It is used as a drop-in replacement for existing depth-supervised NeRFs, particularly on datasets like ScanNet and ScanNet+ [S1].
