# Fast Cache (Control Variate Radiance Cache)
Also called: Fast Cache architecture, Flash Cache fast cache

## Overview
Fast Cache is a computationally efficient approximation of the incoming radiance used in radiance caching for inverse rendering, designed to replace or augment the expensive NeRF-based cache [S1]. It solves the bottleneck of evaluating high-fidelity neural radiance fields for every importance sampling direction by using a lightweight, low-resolution hash grid and a small MLP to predict incident radiance [S1]. It sets itself apart from the standard NeRF-based cache by using a fixed, small number of samples (8) and direct distance prediction, while maintaining accuracy by serving as a control variate to correct the bias of the NeRF cache [S1].

## How it works
**Inputs and Outputs:**
- **Input:** Ray origin $\mathbf{x}$, outgoing direction $\omega_o$, incoming direction $\omega_i$, surface normal $\mathbf{n}$, importance sampling PDF $p(\omega)$, BRDF $f(\mathbf{x}, \omega_i, \omega_o)$, and scene geometry [S1].
- **Output:** Estimated outgoing radiance $\hat{L}_o$ [S1].

**Data Structures:**
1. **Low-resolution NGP Grid:** A multi-resolution hash grid (Neural Graphics Primitive) storing features $\mathbf{f}_k$ for sample points [S1].
2. **Sampling MLP ($g_{\text{sample}}$):** A small MLP that takes ray origin and direction, outputting sample distances $t'_k$ and unnormalized weights $w'_k$ [S1].
3. **Color MLP ($\text{MLP}_{\text{color}}$):** A small MLP that takes the aggregated ray feature vector and outputs incident radiance $\hat{L}_i^{\text{fast}}$ [S1].
4. **Environment MLP ($\text{MLP}_{\text{env}}$):** A small MLP taking direction $\omega_i$ to output far-field illumination [S1].

**Parameters:**
- $S$: Number of samples for the fast cache ray integration. Value: $S=8$ [S1].
- $M'$: Number of directions sampled for the fast cache estimate [S1].
- $M$: Number of additional independent directions sampled for the error correction term ($M \ll M'$) [S1].
- $p(\omega)$: Importance sampling distribution for incoming directions [S1].

**Steps:**
1. **Fast Cache Ray Integration:**
   For a given ray origin $\mathbf{x}$ and direction $\omega_i$:
   a. Compute sample distances and weights using the sampling function:
      $$ \{t'_k, w'_k\}_{k=1}^{S} = g_{\text{sample}}(\mathbf{x}, \omega_i) $$
   b. Compute sample positions:
      $$ \mathbf{x}'_k = \mathbf{x} + t'_k \omega_i $$
   c. Query features from the low-resolution NGP grid at each $\mathbf{x}'_k$ to get $\mathbf{f}_k$ [S1].
   d. Normalize weights using softmax:
      $$ \tilde{w}'_k = \frac{\exp(w'_k)}{\sum_{j=1}^{S} \exp(w'_j)} $$
   e. Compute the ray feature vector:
      $$ \mathbf{F}_{\text{ray}} = \sum_{k=1}^{S} \tilde{w}'_k \mathbf{f}_k $$
   f. Decode incident radiance:
      $$ \hat{L}_i^{\text{fast}}(\mathbf{x}, \omega_i) = \text{MLP}_{\text{color}}(\mathbf{F}_{\text{ray}}) $$

2. **Control Variate Estimation:**
   To estimate outgoing radiance $\hat{L}_o$, sample $M'$ directions $\{\omega'_i\}_{j=1}^{M'}$ and $M$ additional independent directions $\{\omega_i\}_{j=1}^{M}$ from the importance sampling distribution $p(\omega)$ [S1].
   a. Evaluate the fast cache $\hat{L}_i^{\text{fast}}$ for all $M' + M$ directions [S1].
   b. Evaluate the accurate NeRF-based cache $\hat{L}_i^{\text{NeRF}}$ for the $M$ additional directions only [S1].
   c. Compute the fast outgoing radiance estimate:
      $$ \hat{L}_o^{\text{fast}} = \frac{1}{M'} \sum_{j=1}^{M'} f(\mathbf{x}, \omega'_i, \omega_o) \hat{L}_i^{\text{fast}}(\mathbf{x}, \omega'_i) \frac{(\mathbf{n} \cdot \omega'_i)}{p(\omega'_i)} $$
   d. Compute the delta (error) outgoing radiance:
      $$ \Delta \hat{L}_o = \frac{1}{M} \sum_{j=1}^{M} f(\mathbf{x}, \omega_i, \omega_o) \left( \hat{L}_i^{\text{NeRF}}(\mathbf{x}, \omega_i) - \hat{L}_i^{\text{fast}}(\mathbf{x}, \omega_i) \right) \frac{(\mathbf{n} \cdot \omega_i)}{p(\omega_i)} $$
   e. Combine estimates:
      $$ \hat{L}_o = \hat{L}_o^{\text{fast}} + \Delta \hat{L}_o $$

3. **Far-Field Illumination:**
   Add environment lighting to the cache radiance. Compute transparency $T = 1 - \sum_{k=1}^{N} w_k$ using the weights from the NeRF-based cache integration [S1]. Compute environment radiance $L_{\text{env}_i}(\omega_i) = \text{MLP}_{\text{env}}(\omega_i)$ and multiply by $T$ [S1]. Add the result to the cache radiance contribution [S1].

**Pseudocode:**
```python
def fast_cache_radiance(x, omega_o, n, p_func, m_prime, m,
                        g_sample, ngp_fast, mlp_color, mlp_env,
                        mlp_nerf, brdf_eval):
    """
    Computes outgoing radiance using Fast Cache as a control variate.
    """
    # Sample M' + M directions and their PDFs from importance distribution p
    # Note: Exact sampling algorithm is not specified in the source [G]
    dirs_fast, pdfs_fast = sample_directions(p_func, m_prime + m)
    dirs_nerf, pdfs_nerf = sample_directions(p_func, m)

    # Evaluate fast cache for all M' + M directions
    L_i_fast_all = []
    for omega in dirs_fast:
        t_prime, w_prime = g_sample(x, omega)
        x_prime = x + t_prime * omega
        features = [ngp_fast.query(x_pos) for x_pos in x_prime]
        w_norm = softmax(w_prime)
        F_ray = sum(w_norm[k] * features[k] for k in range(len(t_prime)))
        L_i_fast = mlp_color(F_ray)
        L_i_fast_all.append(L_i_fast)

    # Evaluate NeRF cache for M directions
    L_i_nerf_all = []
    for omega in dirs_nerf:
        L_i_nerf = mlp_nerf(x, omega) # Full Zip-NeRF evaluation [G]
        L_i_nerf_all.append(L_i_nerf)

    # Compute fast outgoing radiance estimate
    L_o_fast = 0.0
    for j in range(m_prime):
        omega = dirs_fast[j]
        pdf = pdfs_fast[j]
        L_i_fast = L_i_fast_all[j]
        f_val = brdf_eval(x, omega, omega_o)
        L_o_fast += f_val * L_i_fast * dot(n, omega) / pdf
    L_o_fast /= m_prime

    # Compute delta outgoing radiance
    Delta_L_o = 0.0
    for j in range(m):
        omega = dirs_nerf[j]
        pdf = pdfs_nerf[j]
        L_i_fast = L_i_fast_all[m_prime + j]
        L_i_nerf = L_i_nerf_all[j]
        f_val = brdf_eval(x, omega, omega_o)
        diff = L_i_nerf - L_i_fast
        Delta_L_o += f_val * diff * dot(n, omega) / pdf
    Delta_L_o /= m

    # Combine estimates
    L_o = L_o_fast + Delta_L_o

    # Add far-field illumination
    # Transparency T is computed from the NeRF-based cache integration weights [S1]
    # Note: Exact transparency calculation method is not specified in the source [G]
    T = compute_transparency(mlp_nerf, x)
    L_env = mlp_env(omega) * T
    L_o += L_env

    return L_o
```

## Operating characteristics
- **Time Complexity:** Requires $M$ evaluations of the expensive NeRF-based cache and $M + M'$ evaluations of the cheap fast cache [S1].
- **Memory Complexity:** Uses a low-resolution NGP grid and small MLPs, significantly less memory than the full Zip-NeRF grid [S1].
- **Strengths:** High efficiency due to low sample count ($S=8$) and lightweight network [S1]. Unbiased estimator when combined with the NeRF cache [S1].
- **Limitations:** Relies on the accuracy of the fast cache; if the fast cache is inaccurate, the control variate correction may not fully compensate.
- **When to use:** When real-time or near-real-time inverse rendering is required, and the full NeRF-based cache is too slow [S1].

## Background
Fast Cache is part of the Flash Cache method, introduced in "Flash Cache: Reducing Bias in Radiance Cache Based Inverse Rendering" [S1]. It builds on the Zip-NeRF architecture [S1] and Ref-NeRF [S1]. The method addresses the bias and computational cost of radiance caching in inverse rendering by using a control variate approach [S1].
