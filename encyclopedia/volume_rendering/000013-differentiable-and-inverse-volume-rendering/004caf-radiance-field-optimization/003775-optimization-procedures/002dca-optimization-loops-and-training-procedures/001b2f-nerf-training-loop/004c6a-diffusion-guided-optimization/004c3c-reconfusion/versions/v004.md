# ReconFusion

Also called: ReconFusion: 3D Reconstruction with Diffusion Priors

## Overview
ReconFusion is a 3D reconstruction method that recovers high-quality Neural Radiance Fields (NeRFs) from a small number of input images by regularizing the optimization process with a diffusion prior trained for novel view synthesis [S1]. Unlike methods that rely solely on reconstruction losses or text-guided score distillation, ReconFusion uses a multiview-conditioned latent diffusion model to generate plausible geometry and texture for unobserved regions, effectively preventing catastrophic failures in underconstrained few-view scenarios and reducing volumetric artifacts like "fog" and "floaters" in denser captures [S1]. It differs from SparseFusion by sampling a new image at each iteration rather than using a multistep sampling approach where an image is sampled given a noisy encoding of the current rendering as a target, and empirically outperforms Score Distillation Sampling (SDS) [S1].

## How it works
ReconFusion optimizes a NeRF backbone (specifically Zip-NeRF) by minimizing two loss terms: a reconstruction loss on observed views and a diffusion-based sampling loss on novel views [S1]. The method involves training a diffusion model conditioned on input images and poses, followed by an iterative optimization loop where the NeRF is updated using gradients derived from the diffusion model's predictions [S1].

### Inputs and Outputs
**Inputs:**
*   A set of $N$ input images $x_{obs} = \{x_i\}_{i=1}^N$ with corresponding camera parameters $\pi_{obs} = \{\pi_i\}_{i=1}^N$ [S1].
*   A pretrained Latent Diffusion Model (LDM) encoder $E$, denoising U-Net $\epsilon_\theta$, and decoder $D$ [S1].
*   A pretrained CLIP image encoder [S1].
*   A PixelNeRF-style encoder $R_\phi$ [S1].

**Outputs:**
*   Optimized NeRF parameters $\psi$ representing the 3D scene [S1].

### Data Structures
1.  **NeRF ($\psi$):** Standard Zip-NeRF representation [S1].
2.  **Diffusion Model:**
    *   **VAE Encoder $E$:** Encodes images to latents. Input resolution $512 \times 512 \times 3$, latent dimensions $64 \times 64 \times 8$ [S1].
    *   **Denoising U-Net $\epsilon_\theta$:** Predicts noise in latent space. Conditioned on noisy latents, feature maps, and CLIP embeddings [S1].
    *   **VAE Decoder $D$:** Decodes latents back to image space [S1].
3.  **PixelNeRF Encoder $R_\phi$:**
    *   Input: Image resolution $512 \times 512$.
    *   Output: Feature map $f$ of resolution $64 \times 64$ with 128 channels [S1].
4.  **CLIP Embeddings:** Text/image embeddings used for cross-attention in the U-Net [S1].

### Parameters
*   **Classifier-free guidance scale:** 3.0 [S1].
*   **DDIM sampling steps ($k$):** 10 [S1].
*   **Noise schedule bounds:** $t_{max}$ fixed at 1.0; $t_{min}$ linearly annealed from 1.0 to 0.0 during training [S1].
*   **Sampling loss weight ($L_{sample}$):** Linearly decayed from 1 to 0.1 over training [S1].
*   **Input dropout:** Input images set to all zeros with probability 10% to enable classifier-free guidance [S1].
*   **Nearest neighbors:** 3 nearest camera positions from observed inputs are selected for conditioning a target novel view [S1].
*   **Training iterations:** NeRF trained for 1000 iterations [S1]. Diffusion model finetuned for 250k iterations [S1].
*   **Learning rate:** $10^{-4}$ for joint training of PixelNeRF and finetuning of the denoising U-Net [S1].
*   **Batch size:** 256 [S1].

### Formulas
1.  **Feature Map Generation:**
    The PixelNeRF encoder $R_\phi$ fuses input image data to render a feature map $f$ for a target viewpoint $\pi$:
    $$ f = R_\phi(x_{obs}, \pi_{obs}, \pi) $$
    where $x_{obs}$ are the input images, $\pi_{obs}$ are their poses, and $\pi$ is the target novel view pose [S1].

2.  **Reconstruction Loss:**
    $$ L_{Recon}(\psi) = \mathbb{E}_{x_{obs}, \pi_{obs}} \ell(x(\psi, \pi_{obs}), x_{obs}) $$
    where $\ell$ is the Charbonnier loss [S1].

3.  **Sampling Loss:**
    $$ L_{sample}(\psi) = \mathbb{E}_{\pi, t} w(t) \left( \| x - \hat{x}_\pi \|_1 + L_p(x, \hat{x}_\pi) \right) $$
    where:
    *   $\pi$ is a randomly sampled novel pose [S1].
    *   $t$ is the noise level [S1].
    *   $w(t)$ is a noise-level dependent weighting function [S1].
    *   $x$ is the noisy latent derived from the current NeRF rendering [S1].
    *   $\hat{x}_\pi$ is the decoded output sample from the diffusion model [S1].
    *   $L_p$ is the perceptual distance (LPIPS) [S1].

### Pseudocode
```python
# Initialization
# Load pretrained LDM components: VAE Encoder E, Denoising U-Net epsilon_theta, VAE Decoder D
# Load pretrained CLIP image encoder
# Load PixelNeRF encoder R_phi
# Initialize Zip-NeRF parameters psi
# Load input images x_obs and camera poses pi_obs

# Diffusion Model Finetuning (Pre-requisite)
# Train R_phi and epsilon_theta jointly for 250k iterations
# Batch size 256, Learning rate 1e-4
# For each batch:
#   1. Sample input images x_obs and poses pi_obs
#   2. Sample target pose pi
#   3. Compute feature map f = R_phi(x_obs, pi_obs, pi)
#   4. Encode input images to latents: z_obs = E(x_obs)
#   5. Encode target image (from dataset) to latent: z_target = E(x_target)
#   6. Add noise to z_target at step t: z_t = add_noise(z_target, t)
#   7. Compute CLIP embeddings for x_obs
#   8. Predict noise: epsilon_pred = epsilon_theta(z_t, f, clip_embeddings, t)
#   9. Minimize MSE(epsilon_pred, true_noise)

# NeRF Optimization Loop
# For iteration in range(1000):
#   1. Sample a batch of observed poses pi_obs_batch from pi_obs
#   2. Render images from NeRF for pi_obs_batch: x_render_obs = NeRF_render(psi, pi_obs_batch)
#   3. Compute Reconstruction Loss:
#      L_recon = Charbonnier_loss(x_render_obs, x_obs_batch)
#
#   4. Sample a novel pose pi_novel from the distribution defined by pi_obs
#   5. Render image from NeRF for pi_novel: x_render_novel = NeRF_render(psi, pi_novel)
#   6. Encode rendered image to latent: z_render = E(x_render_novel)
#   7. Select 3 nearest camera positions from pi_obs for conditioning
#   8. Compute feature map for pi_novel: f_novel = R_phi(x_obs, pi_obs, pi_novel)
#   9. Compute CLIP embeddings for the selected 3 input images
#   10. Sample noise level t from [t_min, t_max]
#       Note: t_max is fixed at 1.0, t_min is annealed from 1.0 to 0.0
#   11. Add noise to z_render: z_noisy = add_noise(z_render, t)
#   12. Predict denoised latent using U-Net:
#       z_denoised = denoise_step(z_noisy, f_novel, clip_embeddings, t, epsilon_theta)
#       Note: denoise_step performs k=10 DDIM steps with CFG scale 3.0
#   13. Decode denoised latent to image: x_sample = D(z_denoised)
#   14. Compute Sampling Loss:
#       L_sample = L1_loss(x_render_novel, x_sample) + LPIPS_loss(x_render_novel, x_sample)
#       Note: Weight w(t) is applied
#   15. Compute Total Loss:
#       L_total = L_recon + current_L_sample_weight * L_sample
#       Note: current_L_sample_weight is linearly decayed from 1 to 0.1
#   16. Backpropagate L_total through NeRF parameters psi
#   17. Update psi using optimizer (Learning rate not explicitly stated for NeRF, assume standard Adam/SGD)
```

### Edge Cases and Pitfalls
*   **Few-View Scenarios:** With 3 or 9 views, the reconstruction problem is severely underconstrained. Without the diffusion prior, catastrophic failures occur. The prior prevents this by providing plausible geometry and appearance [S1].
*   **Dense Capture Settings:** With 54 views, the method helps reduce "fog" and "floater" artifacts common in volumetric reconstruction while preserving the appearance of well-sampled regions [S1].
*   **Novel View Selection:** Views should not be placed inside objects or behind walls. The method defines a distribution based on known input poses to encompass reasonable novel camera poses, similar to RegNeRF [S1].
*   **Classifier-Free Guidance:** Input images are set to all zeros randomly with probability 10% during diffusion model training to enable classifier-free guidance [S1].

## Operating characteristics
*   **Time Complexity:** The NeRF is trained for 1000 iterations [S1]. Each iteration requires rendering from the NeRF, encoding to latent space, and a 10-step DDIM sampling process through the U-Net [S1]. The diffusion model itself requires 250k iterations for finetuning [S1].
*   **Memory Complexity:** Depends on the NeRF size and the U-Net memory footprint. The latent space is $64 \times 64 \times 8$ [S1].
*   **Performance:** Outperforms existing baselines on forward-facing and unbounded 360-degree scenes [S1]. Empirically found to work better than SDS and SparseFusion's multistep sampling approach [S1].
*   **Strengths:** Robustness in few-view scenarios; reduction of volumetric artifacts in denser captures; ability to handle arbitrary numbers of input images via PixelNeRF conditioning [S1].
*   **Limitations:** Requires a pretrained and finetuned diffusion model; relies on the quality of the diffusion prior; computationally expensive due to the iterative sampling process [S1].
*   **When to use:** When only a few photos are available for 3D reconstruction, or when standard NeRF training results in artifacts like floaters [S1].
*   **When not to use:** When dense input views are available and computational resources are limited, as the diffusion prior adds significant overhead [S1].

## Background
ReconFusion was introduced in 2023/2024 by researchers aiming to democratize 3D capture by reducing the need for dense image acquisition [S1]. It builds upon the challenges of few-view NeRF reconstruction, where methods like DS-NeRF and DDP-NeRF use sparse depth or other regularizers [S1]. ReconFusion specifically addresses the limitations of text-guided methods (like DreamFusion) and single-image methods (like ZeroNVS) by using a multiview-conditioned diffusion model [S1]. The diffusion model is finetuned from a pretrained LDM on a mixture of real-world (RealEstate10K, CO3D) and synthetic (MVImgNet, Objaverse) multiview datasets [S1]. The method is evaluated on datasets including CO3D, RealEstate10K, LLFF, DTU, and mip-NeRF 360 [S1].
