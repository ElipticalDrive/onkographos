# AligNeRF

Also called: AligNeRF: High-Fidelity Neural Radiance Fields via Alignment-Aware Training

## Overview
AligNeRF is an alignment-aware training strategy for Neural Radiance Fields (NeRF) that addresses misalignment caused by moving objects or camera calibration errors, while improving high-frequency detail recovery in high-resolution settings [S1, S2]. It sets itself apart from standard NeRF variants by combining a convolution-augmented architecture with a staged training procedure that switches from random ray sampling to patch-based sampling, explicitly optimizing for spatial alignment between rendered and ground truth patches [S1, S2].

## How it works
**Inputs and Outputs**
*   **Inputs:** Camera poses, intrinsics, training images, and a baseline NeRF model (typically mip-NeRF 360) [S1].
*   **Outputs:** A refined NeRF model capable of rendering high-fidelity, aligned images [S1].

**Data Structures**
*   **MLP Network ($F_\Theta$):** Takes 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$ as input. The final layer outputs $N$ feature channels instead of 3 RGB channels [S1].
*   **Convolutional Network:** A 3-layer CNN with ReLU activations and $3 \times 3$ kernels [S1].
*   **Feed-forward Perceptron:** Converts the $N$-channel feature space back to RGB space [S1].
*   **Patch Data:**
    *   Rendered Patch $R$: Size $32 \times 32$ pixels [S1].
    *   Ground Truth Patch $G$: Size $48 \times 48$ pixels [S1].
    *   Subpatches $G_i$: $32 \times 32$ subregions extracted from $G$ [S1].

**Algorithm Steps**
The method employs a two-stage training process:

1.  **Pre-training (Normal Stage):**
    *   Train the baseline NeRF model using standard random ray sampling and RGB output [S1].
    *   This establishes a coarse scene representation [S1].

2.  **Alignment-Aware Fine-tuning Stage:**
    *   **Architecture Modification:**
        *   Switch from random ray sampling to **patch-based sampling**. Gather a $32 \times 32$ local image region for each iteration [S1].
        *   Modify the MLP's last layer to output $N$ feature channels (where $N > 3$) [S1].
        *   Perform numerical integration along the ray in this $N$-dimensional feature space rather than RGB space [S1].
        *   Apply a 3-layer CNN ($3 \times 3$ kernels, ReLU) to the rendered feature map. Use "reflectance" padding for inputs and remove padding values in outputs to prevent checkerboard artifacts [S1].
        *   Use a feed-forward perceptron to map the CNN output from feature space to RGB space [S1].
    *   **Alignment-Aware Loss Optimization:**
        *   During each iteration, sample a larger ground truth patch $G$ ($48 \times 48$) [S1].
        *   Render a smaller patch $R$ ($32 \times 32$) [S1].
        *   Search over all possible subpatches $G_i$ within $G$ to find the best match with $R$ [S1].
        *   Compute the loss $L_{PM}$ using the minimum distance plus a regularization term:
            $$ L_{PM}(G, R) = \min_{i=1,...,N} (D(G_i, R) + \lambda \cdot D_{coord}(G_i, R)) $$
            where:
            *   $D(G_i, R) = \|G_i - R\|_2$ is the Euclidean distance between the subpatch and rendered patch [S1].
            *   $D_{coord}(G_i, R) = \sqrt{\Delta x^2 + \Delta y^2}$ is the coordinate offset penalty, where $\Delta x$ and $\Delta y$ are the horizontal and vertical offsets between $G_i$ and $R$ [S1].
            *   $\lambda$ is a regularization weight, empirically set to $0.01$ [S1].
            *   $N$ is the number of possible subpatches in $G$ [S1].

**Pseudocode**

```python
def alignerf_training(baseline_nerf, training_data, num_iterations):
    """
    AligNeRF training procedure.
    baseline_nerf: Initial NeRF model (e.g., mip-NeRF 360).
    training_data: Dataset containing images and camera poses.
    num_iterations: Total training steps.
    """
    
    # Stage 1: Pre-training
    # Train baseline_nerf using standard random ray sampling and RGB loss.
    # This is assumed to be completed before entering the fine-tuning stage.
    model = baseline_nerf
    
    # Stage 2: Alignment-Aware Fine-tuning
    # Modify model architecture for feature-space rendering and CNN post-processing
    model.modify_last_layer_output_channels(N=128) # N is larger than 3, exact value not specified in sources [S1]
    model.add_convolutional_post_processor(layers=3, kernel_size=3, activation='ReLU')
    model.add_perceptron_to_rgb()
    
    # Patch sizes
    PATCH_SIZE_R = 32
    PATCH_SIZE_G = 48
    LAMBDA = 0.01
    
    for iteration in range(num_iterations):
        # 1. Patch-based Sampling
        # Sample a batch of rays corresponding to a 32x32 patch in the image plane
        rays, gt_patch_R_pixels = sample_patch_rays(training_data, size=PATCH_SIZE_R)
        
        # 2. Feature Space Rendering
        # Sample points along rays
        points, t_vals = sample_points_along_rays(rays, near_plane, far_plane, num_samples)
        
        # Encode points and directions
        # Note: Positional encoding gamma is applied as in standard NeRF/mip-NeRF [S1]
        encoded_points = positional_encoding(points)
        encoded_dirs = positional_encoding(rays.directions)
        
        # Forward pass through MLP to get feature density and features
        # sigma: volume density, features: N-channel feature vector
        sigma, features = model.mlp(encoded_points, encoded_dirs)
        
        # Numerical integration in feature space
        # Compute weights based on sigma and distances
        weights = compute_transmittance_weights(sigma, t_vals)
        
        # Render feature map (N channels)
        rendered_features = integrate_features(features, weights)
        
        # 3. CNN Post-processing
        # Reshape rendered features to image-like tensor for CNN
        feature_tensor = reshape_to_image(rendered_features, height=PATCH_SIZE_R, width=PATCH_SIZE_R)
        
        # Apply CNN with reflectance padding
        # Reflectance padding: pad with edge values
        padded_tensor = reflectance_pad(feature_tensor, kernel_size=3)
        cnn_output = model.cnn(padded_tensor)
        
        # Remove padding values from output
        cnn_output = remove_padding(cnn_output, kernel_size=3)
        
        # Convert feature space to RGB space using perceptron
        # Flatten spatial dimensions if necessary, apply perceptron, reshape back
        rgb_tensor = model.perceptron(cnn_output)
        
        # Rendered patch R (RGB)
        rendered_patch_R = rgb_tensor
        
        # 4. Alignment-Aware Loss Calculation
        # Sample a larger ground truth patch G (48x48) centered on the current patch
        gt_patch_G = sample_larger_ground_truth_patch(training_data, center=rays.center, size=PATCH_SIZE_G)
        
        # Search for best matching subpatch Gi in G
        min_loss = infinity
        best_offset = (0, 0)
        
        # Iterate over all possible 32x32 subpatches in the 48x48 ground truth patch
        # Number of subpatches N_sub = (48-32+1)^2 = 17^2 = 289
        for i in range(PATCH_SIZE_G - PATCH_SIZE_R + 1):
            for j in range(PATCH_SIZE_G - PATCH_SIZE_R + 1):
                # Extract subpatch Gi
                gi = gt_patch_G[i:i+PATCH_SIZE_R, j:j+PATCH_SIZE_R]
                
                # Compute Euclidean distance
                d_dist = l2_norm(gi, rendered_patch_R)
                
                # Compute coordinate offset penalty
                # Delta x and y are the offsets of this subpatch relative to the rendered patch center
                delta_x = j
                delta_y = i
                d_coord = sqrt(delta_x**2 + delta_y**2)
                
                # Total loss for this subpatch
                loss = d_dist + LAMBDA * d_coord
                
                if loss < min_loss:
                    min_loss = loss
                    best_offset = (delta_x, delta_y)
        
        # Backpropagate min_loss to update model parameters
        min_loss.backward()
        optimizer.step()
```

**Parameters**
*   **Patch Size (Rendered):** $32 \times 32$ pixels [S1].
*   **Patch Size (Ground Truth):** $48 \times 48$ pixels [S1].
*   **Regularization Weight ($\lambda$):** $0.01$ [S1].
*   **CNN Kernels:** $3 \times 3$ [S1].
*   **MLP Output Channels ($N$):** Larger than 3 (exact value not specified in sources) [S1].

**Edge Cases and Pitfalls**
*   **Checkerboard Artifacts:** Mitigated by using "reflectance" padding for CNN inputs and removing padding values in outputs [S1].
*   **Blurry Renderings:** If the rendered patch $R$ is too blurry, it may match multiple subpatches $G_i$ equally well. The coordinate regularization term $D_{coord}$ penalizes large offsets to resolve this ambiguity [S1].
*   **Multiview Inconsistency:** The authors note that because the CNN is shallow and does not perform upsampling, multiview inconsistency is not observed [S1].

## Operating characteristics
*   **Time Complexity:** Training time is not significantly increased compared to standard NeRF, despite the additional CNN and patch search operations [S2].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** On outdoor datasets, AligNeRF achieves a PSNR higher than the best mip-NeRF result and more than 3 points higher than standard NeRF [S2].
*   **Strengths:** Improves high-frequency detail recovery; addresses misalignment from moving objects; easy to plug into existing NeRF-like models (point-sampling or frustum-based) [S1, S2].
*   **Limitations:** Relies on a staged training approach; requires patch-based sampling which may complicate integration with some existing pipelines [S1].

## Background
AligNeRF was introduced by Yifan Jiang, Peter Hedman, Ben Mildenhall, Dejia Xu, Jonathan T. Barron, Zhangyang Wang, and Tianfan Xue from the University of Texas at Austin, Google Research, and The Chinese University of Hong Kong [S1]. The method was published in November 2022 (arXiv:2211.09682v1) and later presented at CVPR 2023 [S1]. It builds on the mip-NeRF 360 baseline to address limitations in high-resolution training and alignment accuracy [S1, S2].
