# KiloNeRF

Also called: KiloNeRF: Speeding up Neural Radiance Fields with Thousands of Tiny MLPs

## Overview
KiloNeRF is a sparse representation method that decomposes a large, deep Neural Radiance Field (NeRF) into a set of small, shallow MLPs arranged in a 3D grid [S1][S2, unofficial]. It solves the inefficiency of querying a single global network for small spatial portions by using a teacher-student training paradigm where knowledge is distilled from a standard NeRF into these lightweight local models [S1]. It is distinguished from siblings like Mega-NeRF by its specific use of a cached sparse 3D grid for surface localization and its reliance on dynamic parameter loading for thousands of tiny networks [S2, S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained standard NeRF (teacher) serving as the source of truth for density $\sigma$ and color $\mathbf{c}$.
*   **Output:** A set of lightweight MLPs (students) arranged in a 3D grid, and a sparse data structure mapping spatial regions to specific MLP instances.

**Data Structures:**
1.  **Sparse 3D Grid:** A cached structure storing active voxels or cells. It maps a spatial coordinate $\mathbf{x}$ to a specific MLP index or pointer [S3, unofficial]. The grid is sparse to reduce memory overhead, storing only non-empty or relevant regions [S2, S3, unofficial].
2.  **Tiny MLPs:** A collection of small neural networks. Each MLP is significantly shallower and has fewer parameters than the original NeRF [S1][S2, unofficial].

**Numbered Steps:**
1.  **Teacher Training:** Train a standard, deep NeRF on the scene data to obtain high-quality density and color predictions [S1].
2.  **Grid Initialization:** Define a 3D grid covering the scene bounds. Initialize the grid with a sparse structure to hold references to student MLPs [S3, unofficial].
3.  **Student Initialization:** Create a set of lightweight MLPs. These networks are designed to be small enough to fit in cache or be loaded dynamically [S1][S2, unofficial].
4.  **Distillation:** Distill the teacher NeRF's knowledge into the student MLPs. Each student MLP is responsible for a specific spatial region (cell/voxel) of the grid [S1][S2, unofficial]. The loss function typically minimizes the difference between the teacher's output and the student's output for samples within that region [S1].
5.  **Surface Localization (Rendering):** During inference, use the cached sparse 3D grid to quickly locate the surface and identify which MLPs are relevant for the current ray [S3, unofficial]. This allows skipping empty space [S2, S3, unofficial].
6.  **Dynamic Parameter Loading:** As a ray traverses the scene, it passes through different cells, each associated with a different MLP. The system must dynamically load the parameters of the specific MLP for the current sample point [S2, unofficial]. This requires special CUDA kernels to manage the non-contiguous memory access and loading of thousands of tiny models [S2, unofficial].
7.  **Volumetric Rendering:** For each sample point $\mathbf{x}_i$ along the ray, query the active MLP for that region to get $\sigma_i$ and $\mathbf{c}_i$. Composite the final color using the standard volume rendering equation:
    $$
    C(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i, \quad \alpha_i = 1 - \exp(-\sigma_i \delta_i), \quad T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)
    $$

**Pseudocode:**
```python
# Conceptual implementation of KiloNeRF rendering
# Note: Actual implementation requires custom CUDA kernels for dynamic loading

class TinyMLP:
    def __init__(self, num_layers, hidden_dim):
        # Initialize a small MLP with specific layers and hidden dimensions
        self.weights = initialize_weights(num_layers, hidden_dim)

    def forward(self, x, d):
        # Forward pass through the tiny MLP
        # x: position, d: direction
        h = x
        for i in range(num_layers - 1):
            h = relu(linear(h, self.weights[i]))
        sigma = exp(linear(h, self.weights[-2])) # Density
        c = sigmoid(linear(h, self.weights[-1])) # Color
        return sigma, c

class KiloNeRFRenderer:
    def __init__(self, grid_size, num_tiny_mlps):
        # Initialize sparse 3D grid
        self.grid = Sparse3DGrid(grid_size)
        # Initialize a pool of tiny MLPs
        self.tiny_mlps = [TinyMLP(num_layers=2, hidden_dim=32) for _ in range(num_tiny_mlps)]

    def train_distillation(self, teacher_nerf, dataset):
        # Step 1-4: Distill teacher knowledge into students
        for ray in dataset:
            samples = sample_ray(ray)
            for sample in samples:
                # Find the cell in the grid containing the sample
                cell_id = self.grid.find_cell(sample.position)
                # Get the associated tiny MLP
                mlp = self.tiny_mlps[cell_id]
                # Get teacher prediction
                sigma_t, c_t = teacher_nerf.forward(sample.position, sample.direction)
                # Get student prediction
                sigma_s, c_s = mlp.forward(sample.position, sample.direction)
                # Compute distillation loss
                loss = MSE(sigma_s, sigma_t) + MSE(c_s, c_t)
                # Backpropagate to update the tiny MLP
                mlp.update(loss)

    def render_ray(self, ray):
        # Step 5-7: Render using sparse grid and dynamic loading
        samples = sample_ray(ray)
        # Use sparse grid to filter samples or locate surface
        relevant_samples = self.grid.locate_surface(samples)
        
        color = 0.0
        transmittance = 1.0
        
        for sample in relevant_samples:
            # Find the tiny MLP for this sample's location
            cell_id = self.grid.find_cell(sample.position)
            mlp = self.tiny_mlps[cell_id]
            
            # Dynamic loading of MLP parameters would happen here in CUDA
            # sigma, c = mlp.forward(sample.position, sample.direction)
            
            # For pseudocode clarity, assume direct call
            sigma, c = mlp.forward(sample.position, sample.direction)
            
            alpha = 1.0 - exp(-sigma * sample.delta)
            weight = transmittance * alpha
            color += weight * c
            transmittance *= (1.0 - alpha)
            
        return color
```

## Subtopics

### Teacher-Student Distillation
A training paradigm where a large model's knowledge is transferred to smaller models. It sets apart KiloNeRF by enabling the use of tiny MLPs that would otherwise lack accuracy. Choose when model size and inference speed are critical constraints. [S1]

### Sparse 3D Grid for Surface Localization
A data structure used to quickly identify relevant spatial regions. It sets apart KiloNeRF by enabling efficient skipping of empty space. Choose when scene sparsity is high. [S3, unofficial]

## Operating characteristics
*   **Time Complexity:** Acceleration of up to three orders of magnitude compared to the original NeRF [S1].
*   **Memory Complexity:** Substantial memory overhead due to the deployment of a large number of MLPs [S1].
*   **Measured Performance:** Up to 1000x faster than original NeRF [S1].
*   **Scaling:** Scales with the number of tiny MLPs and grid resolution.
*   **Strengths:** Significant speedup, efficient spatial decomposition [S1][S2, unofficial].
*   **Limitations:** High memory overhead, complex dynamic parameter loading [S1][S2, unofficial].
*   **When to use:** When real-time or near-real-time rendering of large scenes is required and memory is not the primary bottleneck.
*   **When not to use:** When memory is extremely constrained or when the scene is dense and sparse grid benefits are minimal.

## Background
KiloNeRF was introduced by Reiser et al. in 2021 [S1]. It was developed to address the inefficiency of standard NeRFs, which sample the entire ray even though only a small fraction of samples contribute to the final image [S2, unofficial]. The method builds on the principle of spatial decomposition, specifically using a grid of tiny MLPs [S1][S2, unofficial].
