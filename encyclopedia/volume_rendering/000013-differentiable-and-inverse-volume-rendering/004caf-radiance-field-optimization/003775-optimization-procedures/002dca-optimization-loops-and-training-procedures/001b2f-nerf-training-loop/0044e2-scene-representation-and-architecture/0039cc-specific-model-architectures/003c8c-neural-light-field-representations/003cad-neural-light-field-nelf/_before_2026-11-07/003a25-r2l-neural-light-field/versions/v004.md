# R2L (Neural Light Field)

Also called: Neural Light Field, R2L network

## Overview
R2L (R2L) is a deep neural light field network designed for efficient novel view synthesis (NVS) by distilling a pre-trained NeRF teacher model into a significantly deeper, residual-heavy student architecture [S1]. It solves the trade-off between rendering quality and computational cost by reducing FLOPs by 26–35× and achieving 28–31× wall-time speedup compared to standard NeRF, while simultaneously improving PSNR on synthetic datasets [S1]. Unlike baseline NeRF or depth-dependent efficient methods like DONeRF, R2L relies on extensive internal residual blocks and hard-example training to capture fine-grained details without requiring ground-truth depth, making it robust on reflective surfaces [S1].

## How it works
R2L replaces the standard shallow NeRF MLP with a deep neural light field network. The core innovation is the architectural shift from width to depth under a fixed FLOPs budget, combined with a distillation training pipeline that uses pseudo-data generated by a teacher NeRF to prevent overfitting in the deep student network [S1].

### Inputs and Outputs
*   **Inputs:** 3D spatial coordinates $\mathbf{x}$ and viewing directions $\mathbf{d}$.
*   **Outputs:** Volumetric density $\sigma$ and color $\mathbf{c}$.
*   **Rendering:** The outputs are integrated using the standard volume rendering equation [S1]:
    $$ C(r) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i, \quad T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right), \quad \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$

### Data Structures
The R2L network is a Multi-Layer Perceptron (MLP) with specific depth and width configurations.
*   **Architecture:** Two variants are cited: W256D88 (width 256, depth 88) and W181D88 (width 181, depth 88) [S1].
*   **Internal Structure:** The network consists of 88 layers. Unlike standard NeRF which uses skip connections for direction input, R2L employs extensive residual blocks in the internal layers [S1].
*   **Positional Encoding:** Retains standard sinusoidal positional encoding for $\mathbf{x}$ and $\mathbf{d}$, consistent with the parent architecture principles [S1].

### Training Procedure
The training involves a distillation phase from a pre-trained NeRF teacher and a specific hard-example sampling strategy.

1.  **Teacher Initialization:** A standard NeRF model is pre-trained on the original captured images. The teacher uses a batch size of 1,024, initial learning rate $5 \times 10^{-4}$, and trains for 200k iterations [S1].
2.  **Pseudo-Data Generation:** The pre-trained teacher model synthesizes pseudo-training images to inflate the dataset. The default pseudo sample size $S$ is 10,000 images [S1].
3.  **Student Initialization:** The R2L network (W256D88 or W181D88) is initialized. It does not use ground-truth depth [S1].
4.  **Hard-Example Sampling:** During training, a fraction $r$ of rays in each batch are selected based on having small PSNR (high error) relative to the teacher's prediction or ground truth. The default ratio $r$ is 0.2 [S1].
5.  **Optimization Loop:**
    *   **Batch Construction:** A batch of 98,304 rays is randomly sampled from different images (different origins) to ensure diversity [S1].
    *   **Loss Calculation:** The student network renders the rays, and the loss is computed against the teacher's predictions or ground truth (depending on the variant: Ours-1 uses only pseudo data; Ours-2 uses pseudo + real images) [S1].
    *   **Update:** Parameters are updated using the Adam optimizer with the same learning rate schedule as the teacher NeRF [S1].
    *   **Iteration:** The network trains for 1,000k iterations [S1].

import torch
import torch.nn as nn
import torch.optim as optim

class R2LNetwork(nn.Module):
    """
    Deep Neural Light Field Network with extensive residual blocks.
    Architecture: W256D88 or W181D88.
    """
    def __init__(self, width=256, depth=88):
        super(R2LNetwork, self).__init__()
        self.depth = depth
        self.width = width
        
        # Input layers
        self.input_layer = nn.Linear(6, width) # 3 for pos, 3 for dir encoding
        
        # Internal layers with residual blocks
        # Note: Exact residual block structure is not fully detailed in [S1],
        # but it is described as "extensive residual blocks in the internal layers".
        # We implement a simplified residual MLP structure consistent with the description.
        self.layers = nn.ModuleList()
        for i in range(depth - 2): # -2 for input and output
            self.layers.append(nn.Linear(width, width))
            self.layers.append(nn.ReLU())
            # Residual connection logic is implicit in the block design
            # Standard residual block: x + F(x)
            
        self.output_density = nn.Linear(width, 1)
        self.output_color = nn.Linear(width, 3)

    def forward(self, x_encoded, d_encoded):
        # Concatenate position and direction encodings
        inputs = torch.cat([x_encoded, d_encoded], dim=-1)
        
        x = self.input_layer(inputs)
        
        # Process through deep layers with residuals
        for i in range(0, len(self.layers), 2):
            layer_linear = self.layers[i]
            layer_act = self.layers[i+1]
            
            # Standard forward pass
            residual = x
            x = layer_linear(x)
            x = layer_act(x)
            
            # Apply residual connection
            # Note: [S1] states "without residuals, the network is barely trainable"
            # and "promote employing extensive residual blocks in the internal layers".
            # We assume the residual connects the input of the block to the output.
            x = x + residual 
            
        # Output heads
        sigma = self.output_density(x)
        color = self.output_color(x)
        
        return sigma, color

### Parameters and Edge Cases
*   **Batch Size:** 98,304 rays per batch [S1].
*   **Hard Example Ratio ($r$):** Default 0.2. Tested values $\{0, 0.1, 0.2, 0.3\}$ show no significant difference beyond 0.1, but $r=0$ performs worse [S1].
*   **Pseudo Sample Size ($S$):** Default 10,000 images. Performance saturates around 5,000 images. Using only 100 images causes severe overfitting (PSNR ~19.81 vs 26.67 with 10k) [S1].
*   **Hardware:** 8 NVIDIA V100 GPUs [S1].
*   **Framework:** PyTorch 1.9 [S1].
*   **Edge Case - Reflections:** R2L outperforms DONeRF on reflective surfaces (water, mirrors) because it does not rely on ground-truth depth, which fails on reflective geometry [S1].
*   **Edge Case - Overfitting:** The deep network is prone to overfitting if data is insufficient. Real images alone (0.1k) are insufficient; pseudo data is critical [S1].

## Operating characteristics
*   **Speed:** 28–31× faster than NeRF and 2× faster than DONeRF-16-noGT on GeForce 2080Ti, Tesla V100, and CPU benchmarks [S1].
*   **FLOPs:** Reduces FLOPs by 26–35× compared to NeRF (e.g., 6.00 M FLOPs for R2L vs 211.42 M for NeRF) [S1].
*   **Quality:** On NeRF synthetic dataset, Ours-2 achieves 31.87 PSNR (+1.40 over teacher), 0.9950 SSIM, 0.0340 LPIPS [S1]. On DONeRF synthetic dataset, Ours-2 achieves 35.45 PSNR (+2.78 over teacher) [S1].
*   **Storage:** 23.7 MB for R2L vs 2.4 MB for Teacher NeRF (due to larger parameter count in deep network) [S1].
*   **Strengths:** High speed, high quality, robust to reflections, no depth requirement.
*   **Limitations:** Requires pre-trained teacher for distillation, large storage footprint compared to shallow NeRF, sensitive to insufficient training data (requires pseudo data).

## Background
R2L was introduced by H. Wang et al. in the paper "R2L: Distilling Neural Radiance Field to Neural Light Field for Efficient Novel View Synthesis" [S1]. It addresses the limitations of standard NeRF's computational cost and the depth-dependency of other efficient methods like DONeRF. The work builds on the concept of Neural Light Fields (NeLF) but introduces a deep residual architecture to improve representational capacity [S1].
