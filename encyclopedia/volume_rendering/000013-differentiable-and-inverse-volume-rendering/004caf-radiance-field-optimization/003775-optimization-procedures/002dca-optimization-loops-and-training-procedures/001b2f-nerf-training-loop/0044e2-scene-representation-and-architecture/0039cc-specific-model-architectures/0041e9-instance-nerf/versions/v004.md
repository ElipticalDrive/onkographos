# Instance-NeRF

Also called: Instance Neural Radiance Field

## Overview
Instance-NeRF is a learning-based 3D instance segmentation pipeline that extends a pre-trained NeRF with an additional instance field to detect all objects within a scene, producing bounding boxes, continuous 3D masks, and class labels [S1]. Unlike Semantic-NeRF, which relies on view-consistent 2D semantic priors, Instance-NeRF addresses the challenge of multi-view inconsistent 2D instance masks (where the same object may have different IDs across views) without relying on 3D bounding volume priors, which can be ambiguous for overlapping objects of the same class [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained NeRF model $F_{\Theta_\sigma, \Theta_c}$ trained on posed RGB images, and a set of multi-view 2D panoptic segmentation maps generated by external models (e.g., Mask2Former, CascadePSP) [S1].
*   **Output:** A continuous 3D instance segmentation field, discrete 3D instance masks, 3D bounding boxes, and class labels for each detected object [S1].

**Data Structures and Layout:**
The model is parameterized by three components [S1]:
1.  **Density Net ($\Theta_\sigma$):** Part of the pre-trained NeRF, outputs volume density $\sigma$.
2.  **Color Branch ($\Theta_c$):** Part of the pre-trained NeRF, outputs RGB radiance $\mathbf{c}$.
3.  **Instance Branch ($\Theta_i$):** The new component, outputs an instance label vector $\mathbf{i}$.

The Instance Field is formulated as $G_{\Theta_\sigma, \Theta_i}(\mathbf{x}) = \mathbf{i}$, where $\mathbf{i}$ is an $L$-dimensional vector representing the instance label distribution over $L$ labels (including background) [S1]. Note that $\mathbf{i}$ depends only on position $\mathbf{x}$, not viewing direction $\mathbf{d}$, making it view-independent [S1].

**Numbered Steps:**

1.  **Ray Formulation:** For each pixel, formulate a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ emitted from the camera center $\mathbf{o}$ to the pixel, where $\mathbf{d}$ is the viewing direction [S1].
2.  **Sampling:** Select $K$ quadrature points $\{t_k\}_{k=1}^K$ along the ray within the traceable volume using hierarchical stratified sampling [S1].
3.  **NeRF-RCNN Proposal (3D Mask Generation):**
    *   Extract radiance and density features from the pre-trained NeRF at the sampled points [S1].
    *   Pass these features through a NeRF-RCNN network (extended from NeRF-RPN) to predict 3D bounding boxes, class labels, and discrete 3D masks for each detected object [S1].
4.  **2D Panoptic Segmentation:** Generate 2D panoptic segmentation maps for the rendered images from the NeRF using external models like Mask2Former [S1]. These maps are inherently multi-view inconsistent regarding instance IDs [S1].
5.  **Mask Matching and Refining:**
    *   Project the discrete 3D masks obtained in Step 3 back to the 2D image space from the same camera poses [S1].
    *   Use Mask2Former and CascadePSP to match the projected 3D masks with the 2D segmentation masks from different views, linking each 2D instance mask to its corresponding 3D instance to resolve ID inconsistency [S1].
    *   Refine the resultant masks to produce multi-view consistent 2D segmentation maps [S1].
6.  **Instance Field Training:**
    *   Use the multi-view consistent 2D segmentation maps as supervision to train the instance field component ($\Theta_i$) [S1].
    *   During training, render expected instance logits $\hat{\mathbf{I}}(\mathbf{r})$ for each pixel using volumetric rendering (see Formulas).
    *   Optimize $\Theta_i$ to minimize the difference between the rendered instance logits and the ground truth instance labels derived from the consistent 2D masks [S1].

**Formulas:**
The numerical quadrature to accumulate expected values for a ray $\mathbf{r}$ is defined as [S1]:

$$
\hat{C}(\mathbf{r}) = \sum_{k=1}^{K} \hat{T}(t_k) \alpha(\sigma(t_k)\delta_k) \mathbf{c}(t_k)
$$

$$
\hat{D}(\mathbf{r}) = \sum_{k=1}^{K} \hat{T}(t_k) \alpha(\sigma(t_k)\delta_k) t_k
$$

$$
\hat{\mathbf{I}}(\mathbf{r}) = \sum_{k=1}^{K} \hat{T}(t_k) \alpha(\sigma(t_k)\delta_k) \mathbf{i}(t_k)
$$

Where:
*   $\hat{T}(t_k)$ is the transmittance up to point $t_k$.
*   $\alpha(\sigma(t_k)\delta_k) = 1 - \exp(-\sigma(t_k)\delta_k)$ is the opacity at sample $k$.
*   $\sigma(t_k)$ is the volume density predicted by $\Theta_\sigma$.
*   $\mathbf{c}(t_k)$ is the RGB radiance predicted by $\Theta_c$.
*   $\mathbf{i}(t_k)$ is the instance label vector predicted by $\Theta_i$.
*   $\delta_k$ is the distance between samples.
*   $K$ is the number of quadrature points.

**Parameters:**
*   $K$: Number of quadrature points per ray. Not given in the sources.
*   $L$: Number of instance labels (including background). Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Multi-view Inconsistency:** 2D instance masks from external models often assign different IDs to the same object across different views. Instance-NeRF explicitly handles this via the matching/refining stage rather than ignoring it or relying on 3D priors [S1].
*   **Overlapping Objects:** Unlike Panoptic NeRF, which uses 3D bounding volumes as priors, Instance-NeRF does not rely on such priors. This avoids ambiguity when objects of the same class have overlapping bounding volumes, a limitation of Panoptic NeRF [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** One of the first learning-based approaches for 3D instance segmentation in NeRF without requiring ground-truth 3D segmentation input. It produces satisfactory 3D object masks on complex scenes and resolves multi-view instance ID inconsistency without 3D bounding volume priors [S1].
*   **Limitations:** Performance may vary on simple scenes with limited objects, with room for quality improvement and generalization [S1]. Relies on external panoptic segmentation models (Mask2Former, CascadePSP) for supervision, which may propagate errors if those models fail [S1].
*   **When to use:** When 3D instance segmentation is required for a scene represented by a NeRF, and multi-view consistency of instance IDs is critical, especially in scenes with overlapping objects of the same class.
*   **When not to use:** When ground-truth 3D segmentation is available and a simpler supervised approach might suffice, or when computational resources for running external panoptic segmentation models and the NeRF-RCNN are limited.

## Background
Instance-NeRF was proposed by Yichen Liu, Benran Hu, Junkai Huang, Yu-Wing Tai, and Chi-Keung Tang from The Hong Kong University of Science and Technology, Carnegie Mellon University, and Dartmouth College [S1]. It was presented at ICCV 2023 [S1]. The work addresses the gap in 3D instance segmentation within NeRF frameworks, building upon prior work like Semantic-NeRF and Panoptic NeRF, while introducing a novel approach to handle instance ID inconsistency without 3D priors [S1].
