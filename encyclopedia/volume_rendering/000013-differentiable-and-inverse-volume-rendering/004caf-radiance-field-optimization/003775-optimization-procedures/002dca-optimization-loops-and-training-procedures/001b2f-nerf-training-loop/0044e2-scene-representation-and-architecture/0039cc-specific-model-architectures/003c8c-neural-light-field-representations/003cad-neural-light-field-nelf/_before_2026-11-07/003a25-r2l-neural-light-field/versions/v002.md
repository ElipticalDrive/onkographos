# R2L (Neural Light Field)

Also called: Neural Light Field, R2L network

## Overview
R2L (R2L: Distilling NeRF to NeLF for Efficient Novel View Synthesis) is a deep neural light field network designed for efficient novel view synthesis by distilling a pre-trained NeRF teacher model [S1]. It differs from standard NeRF architectures by employing an unprecedented depth (88 layers) with extensive internal residual blocks, trading width for depth under a fixed FLOPs budget to achieve significantly higher rendering quality and faster inference [S1]. Unlike depth-dependent efficient methods like DONeRF, R2L does not rely on ground-truth depth, allowing it to handle reflective surfaces (e.g., water, mirrors) more effectively [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D spatial coordinate $\mathbf{x} \in \mathbb{R}^3$ and a viewing direction $\mathbf{d} \in \mathbb{R}^3$ (normalized).
*   **Output:** Volume density $\sigma \in \mathbb{R}$ and emitted color $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures:**
The R2L network is a Multi-Layer Perceptron (MLP) with specific architectural constraints:
*   **Width ($W$):** 256 (W256D88) or 181 (W181D88).
*   **Depth ($D$):** 88 layers.
*   **Internal Structure:** Extensive residual blocks are inserted in the internal layers. Standard skip connections (as used in NeRF for direction input) are present, but internal residual connections are critical for trainability [S1].
*   **Positional Encoding:** Unlike most sibling architectures, R2L does **not** use positional encoding for inputs [S1].

**Training Procedure:**
The method involves a two-stage process: data generation from a teacher and distillation training.

1.  **Teacher Initialization:** A standard NeRF teacher model is pre-trained on the original captured images. The teacher uses a batch size of 1,024, initial learning rate $5 \times 10^{-4}$ (decayed during training), and 200k iterations [S1].
2.  **Pseudo Data Generation:** Rays are sampled from the pre-trained NeRF teacher to generate pseudo training images.
    *   **Pseudo Sample Size ($S$):** Default is 10,000 images. Performance saturates around 5,000 images; fewer than 1,000 images cause overfitting [S1].
3.  **Student Network Initialization:** Initialize the R2L network with width $W \in \{256, 181\}$ and depth 88 [S1].
4.  **Hard-Example Training Setup:** Define a hard-example ratio $r$ (default 0.2). This ratio determines the fraction of rays in each batch selected based on their current PSNR error [S1].
5.  **Optimization Loop:**
    *   **Batch Sampling:** Sample a batch of 98,304 rays. Rays are randomly sampled from different images to ensure they do not share the same origin [S1].
    *   **Hard Example Selection:** Within the batch, identify rays with small PSNR (high error) to focus optimization on fine-grained details. The fraction of these hard examples is controlled by $r$ [S1].
    *   **Forward Pass:** Compute $\sigma$ and $\mathbf{c}$ for all sampled rays.
    *   **Rendering:** Integrate outputs along rays using the standard volume rendering equation:
        $$ C(r) = \sum_{i=1}^{N} T_i \alpha_i c_i $$
        where $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$, $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, and $\delta_i$ is the distance between samples [S1].
    *   **Loss Calculation:** Compute photometric loss between rendered images and ground truth (for real data) or teacher predictions (for pseudo data). The method supports training on both pseudo data (Ours-1) and combined pseudo + real data (Ours-2) [S1].
    *   **Parameter Update:** Update weights using the Adam optimizer with the same learning rate schedule as the teacher NeRF [S1].
    *   **Iteration:** Repeat for 1,000k iterations [S1].

        # Output layer
        self.sigma_layer = nn.Linear(width, 1)
        self.color_layer = nn.Linear(width, 3)

    def forward(self, x, d):
        # x: [B, 3], d: [B, 3]
        # Concatenate x and d
        input_vec = torch.cat([x, d], dim=-1)
        
        h = self.input_layer(input_vec)
        
        for layer in self.layers:
            h = layer(h)
            
        sigma = self.sigma_layer(h)
        color = self.color_layer(h)
        
        return sigma, color

class ResidualBlock(nn.Module):
    """
    Standard residual block for internal layers.
    """
    def __init__(self, width):
        super(ResidualBlock, self).__init__()
        self.fc1 = nn.Linear(width, width)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(width, width)
        
    def forward(self, x):
        residual = x
        out = self.fc1(x)
        out = self.relu(out)
        out = self.fc2(out)
        out = out + residual # Residual connection
        out = self.relu(out)
        return out

def volume_rendering(sigma, alpha, color, ray_directions, near, far, num_samples):
    """
    Standard volume rendering integration.
    """
    # Calculate delta distances
    t_vals = torch.linspace(0., 1., num_samples)
    z_vals = near * (1. - t_vals) + far * t_vals
    deltas = z_vals[:, 1:] - z_vals[:, :-1]
    deltas = torch.cat([deltas, torch.tensor([1e10], device=sigma.device)], dim=-1)
    
    # Opacity
    alpha = 1. - torch.exp(-sigma * deltas)
    
    # Transmittance
    transmittance = torch.cumprod(torch.cat([torch.ones_like(alpha[:, :1]), 1. - alpha + 1e-10], dim=-1), dim=-1)[:, :-1]
    
    # Weighted color
    weights = alpha * transmittance
    color_out = torch.sum(weights * color, dim=-2)
    
    return color_out

**Parameters:**
*   **Batch Size:** 98,304 rays per batch [S1].
*   **Hard Example Ratio ($r$):** Default 0.2. Tested values $\{0, 0.1, 0.2, 0.3\}$. No significant difference between 0.1, 0.2, and 0.3 [S1].
*   **Pseudo Sample Size ($S$):** Default 10,000 images. Performance saturates around 5,000 images [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** Same schedule as the teacher NeRF (initial $5 \times 10^{-4}$, decaying) [S1].
*   **Iterations:** 1,000k [S1].

**Edge Cases and Pitfalls:**
*   **Overfitting:** Without sufficient pseudo data (e.g., $S < 1,000$), the deep network overfits to the training data, resulting in low test PSNR (e.g., 19.81 on Lego scene) [S1].
*   **Trainability:** Without residual blocks in internal layers, the network is barely trainable [S1].
*   **Reflective Surfaces:** Unlike DONeRF, R2L does not fail on reflective surfaces (water, mirrors) because it does not rely on ground-truth depth [S1].

## Operating characteristics
*   **FLOPs:** R2L (W256D88) requires 11.79 M FLOPs, compared to 303.82 M FLOPs for the Teacher NeRF [S1]. This represents a reduction to approximately 1/26 of the FLOPs [S1].
*   **Storage:** 23.7 MB [S1].
*   **Speed:** 28–31× faster than NeRF and 2× faster than DONeRF-16-noGT on GeForce 2080Ti, Tesla V100, and CPU benchmarks [S1].
*   **Performance (NeRF Synthetic Dataset):**
    *   Ours-2 (Pseudo+Real): 31.87 PSNR (+1.40 over teacher), 0.9950 SSIM, 0.0340 LPIPS [S1].
    *   Ours-1 (Pseudo only): 30.48 PSNR (+0.01 over teacher), 0.9939 SSIM, 0.0391 LPIPS [S1].
*   **Performance (DONeRF Synthetic Dataset):**
    *   Ours-2: 35.45 PSNR (+2.78 over teacher), 0.047 FLIP [S1].
*   **Strengths:** High rendering quality with significantly reduced FLOPs; handles reflective surfaces better than depth-dependent methods; deep network captures fine-grained details better than shallow networks under the same FLOPs budget [S1].
*   **Limitations:** Requires a pre-trained NeRF teacher for pseudo data generation; training requires a large amount of pseudo data to prevent overfitting; blurry artifacts from the teacher may persist in the student [S1].

## Background
R2L was introduced by H. Wang et al. in the paper "R2L: Distilling NeRF to NeLF for Efficient Novel View Synthesis" [S1]. It is the first deep neural light field network capable of representing complex synthetic and real-world scenes with high efficiency [S1]. The method addresses the high computational cost of NeRF by distilling knowledge into a deeper, more efficient architecture [S1].
