# Mega-NeRF Spatial Partitioning

Also called: Cell-based NeRF, Spatial Data Parallelism

## Overview
Mega-NeRF Spatial Partitioning decomposes a large-scale 3D scene into a set of spatial cells, each managed by a separate, smaller neural network submodule, to enable parallel training and reduce memory consumption [S1]. Unlike monolithic NeRF implementations, this method assigns query points to the nearest cell centroid, allowing the system to scale to city-scale environments by limiting each submodule's training data to only the pixels relevant to its spatial region [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of calibrated training images with known camera poses; a scene bounding volume.
*   **Outputs:** A set of neural network submodules $\{f^n\}$, one for each spatial cell $n$, and a set of cell centroids $\mathcal{N}$.

**Data Structures**
1.  **Centroids ($\mathcal{N}$):** A set of 3D points $\mathbf{n} = (n_x, n_y, n_z)$ representing the center of each spatial cell.
2.  **Submodules ($f^n$):** For each centroid $n$, a fully connected neural network (MLP) similar to the standard NeRF architecture. The network takes position $\mathbf{x}$ and outputs density $\sigma$. A second branch takes $\mathbf{x}$, viewing direction $\mathbf{d}$, and an appearance embedding $\mathbf{l}^{(a)}$ to output color $\mathbf{c} = (r, g, b)$.
3.  **Appearance Embeddings ($\mathbf{l}^{(a)}$):** A unique vector associated with each input image $a$ to account for lighting variations [S1].
4.  **Trainset Partitioning:** A mapping from each cell $n$ to a subset of training pixels.

**Algorithm Steps**

1.  **Centroid Initialization:**
    Tessellate the scene into a top-down 2D grid to determine centroid positions. Fix the height ($z$-coordinate) of all centroids to a single value, as altitude variance is small relative to latitude/longitude differences in the target scenes [S1].

2.  **Submodule Initialization:**
    Initialize a separate MLP submodule $f^n$ for each centroid $n \in \mathcal{N}$. Initialize appearance embeddings $\mathbf{l}^{(a)}$ for each training image $a$ [S1].

3.  **Visibility Partitioning (Data Assignment):**
    For each training image $a$:
    a. Sample points along the camera rays corresponding to each pixel.
    b. Identify which spatial cells these rays intersect.
    c. Assign the pixel to the trainset of only those intersecting cells.
    d. Apply an overlap factor (typically 15%) between adjacent cells to minimize visual artifacts at boundaries [S1].

4.  **Spatial Data Pruning (Optional Post-Processing):**
    After a coarse training phase, refine the trainsets:
    a. Use the coarse geometry inferred by the submodules to identify occluders.
    b. For each cell, prune pixels/rays that are occluded by geometry inferred by *other* cells (e.g., if a wall in cell $F$ occludes a view from image 2, remove those pixels from cells $A$ and $B$) [S1].

5.  **Parallel Training:**
    Train all submodules $f^n$ in parallel. For a query point $\mathbf{x}$, direction $\mathbf{d}$, and image $a$:
    a. Find the closest centroid: $\mathbf{n} = \arg\min_{n \in \mathcal{N}} \|\mathbf{n} - \mathbf{x}\|^2$.
    b. Query the corresponding submodule:
       $$ \sigma = f^n(\mathbf{x}) $$
       $$ \mathbf{c} = f^n(\mathbf{x}, \mathbf{d}, \mathbf{l}^{(a)}) $$
    c. Use $\sigma$ and $\mathbf{c}$ in the standard volume rendering integral [S1].

**Pseudocode**

```python
import numpy as np

def initialize_mega_nerf(images, camera_poses, scene_bounds):
    """
    Initialize the spatial partitioning structure.
    images: List of training images.
    camera_poses: List of camera transformation matrices.
    scene_bounds: Bounding box of the scene.
    """
    # Step 1: Tessellate scene into a top-down 2D grid
    # Fix height to a single value (e.g., ground level or average camera height)
    centroids = create_2d_grid(scene_bounds, height=scene_bounds.min_z)
    
    # Step 2: Initialize submodules and appearance embeddings
    submodules = {n: init_mlp() for n in centroids}
    appearance_embeddings = {a: init_embedding() for a in images}
    
    return centroids, submodules, appearance_embeddings

def assign_pixels_to_cells(images, camera_poses, centroids, overlap_factor=0.15):
    """
    Step 3: Visibility Partitioning.
    Assigns pixels to cells based on ray intersection.
    """
    cell_trainsets = {n: [] for n in centroids}
    
    for a, img in enumerate(images):
        for pixel in img.pixels:
            ray = cast_ray(camera_poses[a], pixel)
            # Find all cells intersected by the ray
            intersecting_cells = find_intersecting_cells(ray, centroids, overlap_factor)
            
            for cell in intersecting_cells:
                cell_trainsets[cell].append((a, pixel))
                
    return cell_trainsets

def prune_occluded_pixels(centroids, submodules, cell_trainsets, iterations=10):
    """
    Step 4: Spatial Data Pruning.
    Removes pixels occluded by geometry inferred by other cells.
    """
    for _ in range(iterations):
        # Render a coarse depth map for each cell using current submodules
        depth_maps = {n: render_coarse(submodules[n]) for n in centroids}
        
        for n, trainset in cell_trainsets.items():
            pruned_trainset = []
            for a, pixel in trainset:
                # Check if this pixel is occluded by another cell's geometry
                if not is_occluded_by_other_cells(pixel, depth_maps, n):
                    pruned_trainset.append((a, pixel))
            cell_trainsets[n] = pruned_trainset
            
    return cell_trainsets

def query_mega_nerf(x, d, image_index, centroids, submodules, appearance_embeddings):
    """
    Step 5: Query the nearest submodule.
    """
    # Find closest centroid
    distances = [np.linalg.norm(n - x) for n in centroids]
    closest_idx = np.argmin(distances)
    n = centroids[closest_idx]
    
    # Query the submodule
    sigma = submodules[n].forward_position(x)
    c = submodules[n].forward_color(x, d, appearance_embeddings[image_index])
    
    return sigma, c
```

**Parameters**
*   **Overlap Factor:** 15% (used to minimize visual artifacts near cell boundaries) [S1].
*   **Centroid Height:** Fixed to a single value for all cells [S1].

**Edge Cases and Pitfalls**
*   **Boundary Artifacts:** Without the overlap factor, discontinuities may appear at cell boundaries.
*   **Initial Geometry Ignorance:** The initial pixel assignment is based on camera positions, not scene geometry. This leads to redundant data (e.g., pixels of distant regions assigned to local cells) until pruning is applied [S1].
*   **Altitude Variance:** The method assumes small altitude variance relative to horizontal differences. Scenes with significant vertical variation (e.g., multi-story buildings with large height differences) may require adjustments to the centroid height strategy [S1].

## Subtopics

### Mega-NeRF (Full System)
*   **What it is:** The complete system that uses spatial partitioning as its core scalability mechanism, often combined with foreground/background decomposition [S1].
*   **Difference:** Includes additional components like NeRF++-style foreground/background splitting and hierarchical sampling [S1].
*   **When to choose:** When building large-scale, city-scale NeRFs for virtual fly-throughs.
*   **Link:** [Mega-NeRF](8941-mega-nerf.md)

### KiloNeRF
*   **What it is:** A similar approach that partitions the scene into a grid of cells, each with its own MLP.
*   **Difference:** KiloNeRF typically uses a fixed grid and may employ different pruning or quantization strategies. Mega-NeRF emphasizes the 2D tessellation and appearance embeddings for large-scale consistency.
*   **When to choose:** For large scenes where memory is a constraint, but potentially simpler implementation than Mega-NeRF's appearance embedding system.
*   **Link:** [KiloNeRF](8942-kilonerf.md)

## Operating characteristics
*   **Time Complexity:** Training time is reduced due to parallelization of submodules and smaller per-submodule datasets. Visibility partitioning reduces the trainset size by 10x compared to the aggregate trainset [S1]. Additional pruning reduces it by a further 2x [S1].
*   **Memory Complexity:** Memory usage is distributed across submodules. Each submodule only stores weights for its local region, significantly reducing peak memory compared to a single large NeRF [S1].
*   **Scaling:** Scales well to large-scale scenes (e.g., North Pittsburgh) because irrelevant pixels are pruned from local submodules [S1].
*   **Strengths:** Enables training on scenes that are too large for a single GPU; reduces training time via parallelism; handles lighting variations via appearance embeddings [S1].
*   **Limitations:** Requires careful tuning of the overlap factor; initial data assignment is inefficient until pruning is applied; assumes relatively flat terrain for the fixed-height centroid strategy [S1].

## Background
Mega-NeRF was introduced in 2022 by [S1] to address the scalability limitations of NeRF for large-scale environments. It builds on the idea of spatial decomposition, drawing inspiration from previous work on hierarchical sampling and NeRF++ [S1]. The method was designed specifically for virtual fly-throughs of city-scale scenes, where traditional NeRFs fail due to memory and training time constraints [S1].
