# HyperNeRFGAN

Also called: Hypernetwork approach to 3D NeRF GAN

## Overview
HyperNeRFGAN is a generative adversarial network (GAN) architecture that synthesizes 3D-aware radiance fields from 2D images without requiring camera pose information during training [S1, unofficial]. It solves the limitation of standard NeRFs, which require known camera positions, by using a hypernetwork to generate the weights of a simplified NeRF target network directly from a Gaussian noise vector [S1, unofficial]. Unlike sibling methods like [Latent-NeRF](9110-latent-nerf.md) which optimize latent codes for a fixed network, HyperNeRFGAN generates the network parameters themselves, allowing for the creation of distinct 3D objects from noise while maintaining 3D consistency through a standard 2D discriminator [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A noise vector $\mathbf{z}$ sampled from a standard Gaussian distribution $P_{noise}$.
*   **Output:** A rendered 2D image from a specified viewing angle, generated by the instantiated NeRF. The training objective also produces a discriminator score distinguishing real from generated images.

**Data Structures:**
1.  **Generator ($G$):** A StyleGAN2-based hypernetwork. It takes $\mathbf{z}$ and outputs the weights $\theta$ for the target NeRF.
2.  **Target NeRF ($F_\theta$):** A single Multi-Layer Perceptron (MLP).
    *   **Input:** 3D spatial coordinate $\mathbf{x} = (x, y, z)$. Note: Viewing direction $\mathbf{d}$ is **not** an input.
    *   **Output:** Color $\mathbf{c}$ and volume density $\sigma$.
    *   **Architecture:** Uses Factorized Multiplicative Modulation (FMM) layers instead of standard linear layers.
    *   **Dimensions:**
        *   Hidden layer channels: 128 (reduced from standard 256).
        *   Layers: 4 to 8 (typically 4 in experiments to reduce cost).
3.  **Discriminator ($D$):** A standard 2D CNN discriminator that evaluates the rendered 2D images.

**Factorized Multiplicative Modulation (FMM) Layer:**
The core building block of the target NeRF $F_\theta$. It allows the generator $G$ to modulate the shared weights $W$ and bias $b$ using matrices $A$ and $B$ generated from $\mathbf{z}$.
$$ \mathbf{y} = W \odot (A \times B) \cdot \mathbf{x}_{in} + \mathbf{b} = \tilde{W} \cdot \mathbf{x}_{in} + \mathbf{b} $$
Where:
*   $W \in \mathbb{R}^{n_{out} \times n_{in}}$ and $\mathbf{b} \in \mathbb{R}^{n_{out}}$ are shared parameters across all generated NeRFs.
*   $A \in \mathbb{R}^{n_{out} \times k}$ and $B \in \mathbb{R}^{k \times n_{in}}$ are modulation matrices produced by $G$.
*   $k$ is the rank parameter controlling expressiveness vs. memory. $k=10$ is used.
*   $\tilde{W} = W \odot (A \times B)$ is the effective weight matrix for the specific instance.

**Training Steps:**
1.  Sample a noise vector $\mathbf{z} \sim P_{noise}$.
2.  Pass $\mathbf{z}$ through the Generator $G$ to obtain the NeRF weights $\theta$.
3.  Instantiate the target NeRF $F_\theta$ using $\theta$.
4.  Render a 2D image $\mathbf{I}_{gen}$ from $F_\theta$ using a chosen camera pose (viewing direction $\mathbf{d}$ is used for *rendering*, but not as input to $F_\theta$).
5.  Sample a real image $\mathbf{I}_{real}$ from the dataset $P_{data}$.
6.  Update Discriminator $D$ to maximize the likelihood of distinguishing $\mathbf{I}_{real}$ from $\mathbf{I}_{gen}$.
7.  Update Generator $G$ to minimize the likelihood of $D$ detecting $\mathbf{I}_{gen}$ as fake.

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class FMMLayer(nn.Module):
    """
    Factorized Multiplicative Modulation Layer.
    W_shared and b_shared are persistent buffers (shared across instances).
    A and B are generated per instance by the hypernetwork.
    """
    def __init__(self, n_in, n_out, k, W_shared, b_shared):
        super().__init__()
        self.n_in = n_in
        self.n_out = n_out
        self.k = k
        # These are shared weights, not learned by the hypernetwork directly
        # but used in the modulation formula.
        self.register_buffer('W_shared', W_shared) 
        self.register_buffer('b_shared', b_shared)

    def forward(self, A, B, x_in):
        # A: (n_out, k), B: (k, n_in)
        # Compute effective weights: W_eff = W_shared * (A @ B)
        # Note: The paper uses element-wise multiplication (Hadamard) 
        # between W_shared and the product (A @ B).
        modulation = torch.matmul(A, B) # (n_out, n_in)
        W_eff = self.W_shared * modulation
        
        # Linear transformation with effective weights
        x_out = torch.matmul(x_in, W_eff.t()) + self.b_shared
        return x_out

class HyperNeRF(nn.Module):
    """
    The target NeRF network.
    Input: x (3D position). Output: c (color), sigma (density).
    No viewing direction input.
    """
    def __init__(self, n_layers, n_channels, k):
        super().__init__()
        self.n_layers = n_layers
        self.n_channels = n_channels
        self.k = k
        
        # Shared weights initialization (simplified for pseudocode)
        # In practice, these are initialized once and shared.
        self.shared_weights = []
        self.shared_biases = []
        
        for i in range(n_layers):
            n_in = n_channels if i > 0 else 3
            n_out = n_channels
            # Initialize shared W and b for this layer
            W = torch.randn(n_out, n_in)
            b = torch.zeros(n_out)
            self.shared_weights.append(W)
            self.shared_biases.append(b)
            
        # Final layer for color and density
        # Output: 4 channels (R, G, B, sigma)
        n_in_final = n_channels
        n_out_final = 4
        W_final = torch.randn(n_out_final, n_in_final)
        b_final = torch.zeros(n_out_final)
        self.shared_weights.append(W_final)
        self.shared_biases.append(b_final)

    def forward(self, A_list, B_list, x):
        """
        x: (batch, 3)
        A_list, B_list: lists of tensors from Generator G
        """
        h = x
        for i in range(self.n_layers):
            layer = FMMLayer(self.n_channels, self.n_channels, self.k, 
                             self.shared_weights[i], self.shared_biases[i])
            h = layer(A_list[i], B_list[i], h)
            h = F.relu(h)
            
        # Final layer (no ReLU, or specific activation for sigma)
        final_layer = FMMLayer(4, self.n_channels, self.k,
                               self.shared_weights[-1], self.shared_biases[-1])
        out = final_layer(A_list[-1], B_list[-1], h)
        
        # Split color and density
        c = out[:, :3]
        sigma = out[:, 3:]
        return c, sigma

class HyperNeRFGAN:

        self.D = discriminator

        self.k = k
        # The NeRF is instantiated dynamically during training
        self.neRF = None 

    def render_image(self, z, camera_params):
        """
        Render a 2D image from noise z and camera parameters.
        """
        # 1. Generate modulation matrices from noise
        # G outputs lists of A and B matrices for each layer
        A_list, B_list = self.G(z)
        
        # 2. Instantiate NeRF (conceptually, weights are fixed for this forward pass)
        # In implementation, the NeRF module holds shared weights, 
        # and A/B are passed as inputs.
        
        # 3. Sample 3D points along rays defined by camera_params
        # This step depends on the specific ray marching implementation.
        # For brevity, assume we have a list of 3D points 'points' and 'depths'
        points, depths = sample_rays(camera_params)
        
        # 4. Query NeRF
        c, sigma = self.neRF(A_list, B_list, points)
        
        # 5. Volume Rendering (Standard NeRF alpha compositing)
        # T_i = exp(-sum_{j<i} sigma_j * delta_j)
        # C(r) = sum_{i} T_i * (1 - exp(-sigma_i * delta_i)) * c_i
        image = volume_render(points, sigma, c, depths)
        
        return image

    def train_step(self, real_images, z_batch, camera_params_batch):
        """
        One step of the minimax game.
        """
        # --- Update Discriminator ---
        self.D.zero_grad()
        
        # Real images
        real_pred = self.D(real_images)
        loss_real = F.softplus(-real_pred) # log(D(x)) approximation in WGAN-GP or similar
        
        # Generated images
        gen_images = self.render_image(z_batch, camera_params_batch)
        fake_pred = self.D(gen_images.detach())

        self.G.zero_grad()
        
        # Re-render to allow gradient flow through NeRF weights (generated by G)
        gen_images = self.render_image(z_batch, camera_params_batch)
        fake_pred = self.D(gen_images)
        
        # Minimize log(1 - D(G(z))) -> Maximize log(D(G(z)))
        # Using GAN loss: -log(D(G(z)))
        loss_G = F.softplus(-fake_pred)
        loss_G.backward()
        optimizer_G.step()
        
        return loss_D.item(), loss_G.item()
```

**Parameters:**
*   **Rank $k$:** 10. Controls the rank of the modulation matrices $A \times B$. Higher $k$ increases expressiveness and memory usage [S1, unofficial].
*   **Hidden Channels:** 128. Reduced from the standard 256 to lower computational cost [S1, unofficial].
*   **Network Depth:** 4 layers. Reduced from the standard 8 layers in some experiments to lower cost [S1, unofficial].
*   **Noise Distribution:** Standard Gaussian $P_{noise}$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Viewing Direction:** The target NeRF $F_\theta$ does **not** accept viewing direction $\mathbf{d}$ as input. This is intentional because the training datasets (e.g., medical DRRs, CelebA) often lack view-dependent characteristics like reflections or precise camera poses [S1, unofficial]. However, viewing directions are still required for the *ray marching* process to render the 2D image from the 3D field.
*   **Fine Network:** Standard NeRFs use a coarse and a fine network. HyperNeRFGAN discards the fine network entirely to reduce training cost, relying only on the coarse network [S1, unofficial].
*   **Single View Training:** The method is designed to work even with a single unlabeled view per object, though multiple views improve quality [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training is computationally expensive due to the hypernetwork generating weights for every batch and the subsequent ray marching. However, it is lighter than full NeRF-GANs that optimize latent codes for large networks because the target NeRF is simplified (4 layers, 128 channels, no fine network) [S1, unofficial].
*   **Memory Complexity:** Memory usage is dominated by the StyleGAN2 generator and the storage of shared weights. The rank $k=10$ is a trade-off; higher $k$ increases memory for the modulation matrices [S1, unofficial].
*   **Performance:**
    *   **ShapeNet Car:** FID 29.6 (vs. Point2NeRF 82.1) [S1, unofficial].
    *   **CARLA Dataset:** FID 20.5, KID 0.78, IS 4.20. Outperforms HoloGAN (FID 67.5), GRAF (FID 41.7), and $\pi$-GAN (FID 29.2) [S1, unofficial].
    *   **CelebA Dataset:** FID 15.04, KID 0.66, IS 2.63. Comparable to $\pi$-GAN (FID 14.7, KID 0.39, IS 2.62) [S1, unofficial].
*   **Strengths:** Does not require camera pose estimation; works on datasets with unknown or no poses (e.g., medical images); produces high-quality 3D-aware generations.
*   **Limitations:** Cannot model view-dependent effects (specularities, reflections) because viewing direction is omitted from the NeRF input [S1, unofficial].

## Background
HyperNeRFGAN was introduced in 2023 by authors associated with the paper "HyperNeRFGAN: Hypernetwork approach to 3D NeRF GAN" [S1, unofficial]. It builds upon the INR-GAN architecture, which uses hypernetworks for image generation, and adapts it to 3D radiance fields. It addresses the limitations of previous 3D-aware GANs like GRAF and $\pi$-GAN, which rely on SIREN networks and complex conditioning mechanisms, by using a simplified NeRF with FMM layers [S1, unofficial]. It is particularly noted for its application in medical imaging (Digitally Reconstructed Radiographs) where camera poses are difficult to obtain [S1, unofficial].
