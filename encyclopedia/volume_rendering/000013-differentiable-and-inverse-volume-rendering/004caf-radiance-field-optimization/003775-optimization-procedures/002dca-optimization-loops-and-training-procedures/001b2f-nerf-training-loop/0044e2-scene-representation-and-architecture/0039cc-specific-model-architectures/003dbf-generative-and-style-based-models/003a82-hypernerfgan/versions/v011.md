# HyperNeRFGAN

Also called: HyperNeRF GAN, Hypernetwork NeRF GAN

## Overview
HyperNeRFGAN is a generative model that uses a hypernetwork to produce the weights of a simplified NeRF target network, trained using the StyleGAN2 objective to generate 3D representations from a Gaussian noise distribution [S1, unofficial]. It solves the problem of 3D-aware image generation when camera positions are unavailable or unreliable by removing viewing directions from the NeRF input and using a hypernetwork to implicitly encode scene geometry [S1, unofficial]. Unlike sibling methods like [Latent-NeRF](9110-latent-nerf.md) which optimize latent codes for a fixed NeRF, HyperNeRFGAN generates the NeRF weights themselves, allowing for a single 3D representation per generated sample without requiring explicit conditioning mechanisms [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A noise vector $\mathbf{z}$ sampled from a standard Gaussian distribution $P_{noise}$ [S1, unofficial].
*   **Output:** A rendered 2D image $\mathbf{C}(\mathbf{r})$ generated by the instantiated NeRF, evaluated by a discriminator [S1, unofficial].

**Data Structures:**
1.  **Generator ($G$):** A StyleGAN2-based architecture that maps $\mathbf{z}$ to modulation matrices $A$ and $B$ [S1, unofficial].
2.  **Target NeRF ($F_\theta$):** A single MLP that maps 3D spatial coordinates $\mathbf{x}$ to color $\mathbf{c}$ and density $\sigma$. It does not take viewing direction $\mathbf{d}$ as input [S1, unofficial].
    *   **Architecture:** Uses Factorized Multiplicative Modulation (FMM) layers [S1, unofficial].
    *   **Layer Parameters:**
        *   Shared weights $W$ and bias $b$ are constant across all generated instances (shared across the batch or global) [S1, unofficial].
        *   Modulation matrices $A$ (size $n_{out} \times k$) and $B$ (size $k \times n_{in}$) are generated by $G$ for each instance [S1, unofficial].
        *   Rank parameter $k = 10$ [S1, unofficial].
    *   **Network Size:**
        *   Hidden layer channels: 128 (reduced from standard 256) [S1, unofficial].
        *   Network depth: 4 to 8 layers (reduced from standard 8+ layers) [S1, unofficial].
        *   Only the "coarse" network is used; the "fine" network is rejected to reduce cost [S1, unofficial].
3.  **Discriminator ($D$):** A standard 2D CNN discriminator that evaluates the rendered images [S1, unofficial].

**Formulas:**
The FMM layer computes the output $\mathbf{y}$ from input $\mathbf{x}_{in}$ as [S1, unofficial]:
$$ \mathbf{y} = W \odot (A \times B) \cdot \mathbf{x}_{in} + \mathbf{b} = \tilde{W} \cdot \mathbf{x}_{in} + \mathbf{b} $$
where $\tilde{W} = W \odot (A \times B)$ is the effective weight matrix for the current instance [S1, unofficial].

The NeRF function is defined as [S1, unofficial]:
$$ F_\theta: \mathbf{x} \rightarrow (\mathbf{c}, \sigma) $$
where $\mathbf{x} = (x, y, z)$ [S1, unofficial].

The GAN minimax objective is [S1, unofficial]:
$$ \min_G \max_D V(D, G) $$
$$ V(D, G) = \mathbb{E}_{\mathbf{x} \sim P_{data}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z} \sim P_{noise}}[\log(1 - D(G(\mathbf{z})))] $$

**Numbered Steps:**
1.  Sample a noise vector $\mathbf{z} \sim P_{noise}$ (Gaussian distribution) [S1, unofficial].
2.  Pass $\mathbf{z}$ through the Generator $G$ to obtain modulation matrices $A$ and $B$ [S1, unofficial].
3.  Compute the effective weights $\tilde{W}$ for the target NeRF layers using $\tilde{W} = W \odot (A \times B)$ [S1, unofficial].
4.  Instantiate the target NeRF $F_\theta$ using the shared weights $W, \mathbf{b}$ and the instance-specific $\tilde{W}$ [S1, unofficial].
5.  For a set of camera poses (required for rendering, but not for the NeRF input), sample 3D points $\mathbf{x}$ along rays [S1, unofficial].
6.  Query $F_\theta(\mathbf{x})$ to get $\mathbf{c}$ and $\sigma$ [S1, unofficial].
7.  Render the 2D image using the standard volume rendering integral (as defined in [Generative and Style-based Models](9572-generative-and-style-based-models.md)) [S1, unofficial].
8.  Pass the rendered image and real images to the Discriminator $D$ [S1, unofficial].
9.  Update $G$ and $D$ using the StyleGAN2 adversarial loss [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class HyperNeRFGAN:
    def __init__(self, n_in, n_out, k=10, hidden_channels=128, num_layers=4):
        """
        Initialize HyperNeRFGAN components.
        :param n_in: Input dimension for NeRF layer (3 for xyz)
        :param n_out: Output dimension for NeRF layer (4 for c_r, c_g, c_b, sigma)
        :param k: Rank of modulation matrices
        :param hidden_channels: Number of channels in hidden layers
        :param num_layers: Number of layers in the NeRF
        """
        self.k = k
        self.num_layers = num_layers
        self.hidden_channels = hidden_channels
        
        # Generator G: StyleGAN2 backbone (simplified representation)
        # Maps z -> modulation parameters for each layer
        self.G = StyleGAN2Generator(z_dim=512, k=k, n_layers=num_layers)
        
        # Shared weights W and biases b for the NeRF
        # These are NOT optimized directly; they are modulated by G
        self.shared_W = nn.ParameterList([
            nn.Parameter(torch.randn(hidden_channels, n_in if i == 0 else hidden_channels))
            for i in range(num_layers)
        ])
        self.shared_b = nn.ParameterList([
            nn.Parameter(torch.zeros(hidden_channels))
            for i in range(num_layers)
        ])
        
        # Final output layer weights (also shared, but typically not modulated in the same way or handled separately)
        # Note: The paper describes FMM for the layers. The final output layer might be standard or modulated.
        # Assuming standard output layer for simplicity based on "single MLP" description.
        self.final_W = nn.Parameter(torch.randn(n_out, hidden_channels))
        self.final_b = nn.Parameter(torch.zeros(n_out))
        
        # Discriminator D
        self.D = Discriminator(image_size=256)

    def get_nerf_weights(self, z):
        """
        Generate modulation matrices A and B for the current instance.
        :param z: Noise vector
        :return: List of (A, B) tuples for each layer
        """
        # G outputs modulation parameters. 
        # In StyleGAN2, these are often affine transformations. 
        # Here we assume G outputs A and B directly or parameters to derive them.
        # Based on [S1, unofficial]: A is n_out x k, B is k x n_in.
        # G typically outputs style vectors. We assume a projection to A and B.
        # For implementation completeness, we assume G returns A and B tensors.
        A_list, B_list = self.G(z) 
        return list(zip(A_list, B_list))

    def forward_nerf(self, x, modulation_params):
        """
        Forward pass of the target NeRF with modulation.
        :param x: Spatial coordinates (B, 3)
        :param modulation_params: List of (A, B) tuples
        :return: Color (B, 3) and Density (B, 1)
        """
        h = x
        for i in range(self.num_layers):
            W_shared = self.shared_W[i]
            b_shared = self.shared_b[i]
            A, B = modulation_params[i]
            
            # Compute effective weight: W_tilde = W_shared o (A x B)
            # A: (n_out, k), B: (k, n_in) -> A @ B: (n_out, n_in)
            # W_shared: (n_out, n_in)
            # Element-wise multiplication
            W_tilde = W_shared * (A @ B)
            
            # Linear layer: y = W_tilde @ x + b
            h = F.linear(h, W_tilde, b_shared)
            
            # Activation (SIREN or ReLU? Paper mentions SIREN-based NeRFs are common, 
            # but HyperNeRFGAN uses FMM. Standard NeRF uses ReLU. 
            # Paper says "simplified NeRF... does not utilize viewing direction". 
            # Standard NeRF uses ReLU. We assume ReLU for stability in GAN training unless specified otherwise.
            # However, INR-GAN (which uses FMM) often uses SIREN. 
            # Given "HyperNeRFGAN... adheres to design patterns of INR-GAN", we use SIREN (sin activation).
            h = torch.sin(h) 
            
        # Final output layer
        # No modulation mentioned for final layer in snippet, assuming standard
        c_sigma = F.linear(h, self.final_W, self.final_b)
        
        # Split color and density
        # Assuming last channel is density, first 3 are color
        c = c_sigma[:, :3]
        sigma = c_sigma[:, 3:]
        
        return c, sigma

    def render(self, x, modulation_params):
        """
        Render 2D image from 3D points using volume rendering.
        :param x: Points along rays (N, 3)
        :param modulation_params: Weights for NeRF
        :return: Rendered image (H, W, 3)
        """
        c, sigma = self.forward_nerf(x, modulation_params)
        
        # Volume Rendering
        # T_i = exp(-sum_{j=1}^{i-1} sigma_j * delta_j)
        # alpha_i = 1 - exp(-sigma_i * delta_i)
        # C = sum T_i * alpha_i * c_i
        
        # This requires ray marching logic. 
        # For the purpose of the article, we assume a standard volume rendering function.
        image = volume_render(x, sigma, c)
        return image

    def train_step(self, real_images, z):
        """
        Single training iteration.
        """
        # 1. Generate NeRF weights
        mod_params = self.get_nerf_weights(z)
        
        # 2. Render fake images
        # Assume we have a set of rays/points for the camera pose
        fake_images = self.render(rays, mod_params)
        
        # 3. Discriminator loss
        d_real = self.D(real_images)
        d_fake = self.D(fake_images.detach())
        
        loss_d = -torch.mean(d_real) + torch.mean(d_fake)
        
        # 4. Generator loss
        d_fake_gen = self.D(fake_images)
        loss_g = -torch.mean(d_fake_gen)
        
        # 5. Update
        loss_d.backward()
        self.D.optimizer.step()
        self.D.optimizer.zero_grad()
        
        loss_g.backward()
        self.G.optimizer.step()
        self.G.optimizer.zero_grad()
        
        return loss_d, loss_g
```

**Edge Cases and Pitfalls:**
*   **Viewing Direction:** The model does not accept viewing directions. If the dataset contains view-dependent effects (e.g., reflections), performance will degrade [S1, unofficial].
*   **Fine Network:** The "fine" network is omitted. This may reduce quality for complex scenes compared to full NeRF, but reduces training cost [S1, unofficial].
*   **Rank $k$:** Higher $k$ increases expressiveness but also memory usage. $k=10$ is used [S1, unofficial].
*   **Camera Poses:** While the NeRF does not use camera poses as input, camera poses are still required for rendering (to define rays). The model assumes these are available or estimated, but does not learn them [S1, unofficial].

## Subtopics

### Latent-NeRF
Optimizes a latent code for a fixed NeRF. HyperNeRFGAN generates the NeRF weights directly, offering a different trade-off between generation flexibility and training stability [S1, unofficial].

### GRAF
Uses SIREN with a conditioning mechanism. HyperNeRFGAN uses a hypernetwork to generate weights, avoiding the complexity of conditioning SIREN [S1, unofficial].

### $\pi$-GAN
Uses SIREN with a conditioning mechanism. HyperNeRFGAN achieves comparable performance on CelebA but with a different architectural approach [S1, unofficial].

## Operating characteristics
*   **Time and Memory Complexity:** Reduced compared to standard NeRF due to the omission of the fine network and reduced hidden channels (128 vs 256) and layers (4-8 vs 8+) [S1, unofficial].
*   **Measured Performance:**
    *   **ShapeNet Car:** FID 29.6 (vs Point2NeRF 82.1) [S1, unofficial].
    *   **CARLA:** FID 20.5, KID 0.78, IS 4.20 (vs HoloGAN FID 67.5, GRAF FID 41.7, $\pi$-GAN FID 29.2) [S1, unofficial].
    *   **CelebA:** FID 15.04, KID 0.66, IS 2.63 (comparable to $\pi$-GAN FID 14.7, KID 0.39, IS 2.62) [S1, unofficial].
    *   **Medical (DRR):** Outperforms MedNeRF and UMedNeRF in FID and KID [S1, unofficial].
*   **Strengths:** Works well on datasets where camera positions are unknown or hard to estimate (e.g., medical data, single-view datasets) [S1, unofficial].
*   **Limitations:** Cannot model view-dependent effects (reflections) as viewing directions are not used [S1, unofficial].

## Background
HyperNeRFGAN was introduced in 2023 by authors associated with the paper "HyperNeRFGAN: Hypernetwork approach to 3D NeRF GAN" [S1, unofficial]. It builds on the hypernetwork paradigm (Ha et al., 2016) and StyleGAN2 (Karras et al., 2020) to generate NeRF weights. It addresses the limitations of previous GAN-based 3D generation methods that required camera poses or used SIREN with conditioning [S1, unofficial].
