# HyperNeRFGAN

Also called: Hypernetwork approach to 3D NeRF GAN

## Overview
HyperNeRFGAN is a generative adversarial network (GAN) architecture that employs a hypernetwork to transform a Gaussian noise vector into the weights of a simplified NeRF target network, enabling 3D-aware image generation without requiring camera position information during training [S1, unofficial]. Unlike standard NeRF which uses a 5D input (position and viewing direction), HyperNeRFGAN uses a 3D input (position only) because the training datasets lack view-dependent characteristics like reflections [S1, unofficial]. It differs from siblings like [Latent-NeRF](9110-latent-nerf.md) by using a hypernetwork to generate NeRF weights directly, avoiding the complexity of NeRF conditioning mechanisms while maintaining 3D awareness [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Generator Input:** A noise vector $\mathbf{z}$ sampled from a Gaussian distribution $P_{noise}$ [S1, unofficial].
*   **Generator Output:** The weights $\theta$ of the target NeRF model $F_\theta$ [S1, unofficial].
*   **Target Model Input:** 3D spatial location $\mathbf{x} = (x, y, z)$ [S1, unofficial].
*   **Target Model Output:** Color $\mathbf{c}$ and volume density $\sigma$ [S1, unofficial].
*   **Discriminator Input:** 2D rendered images [S1, unofficial].

**Data Structures:**
The target NeRF model $F_\theta$ is a single Multi-Layer Perceptron (MLP) [S1, unofficial].
*   **Architecture:** It consists of hidden layers with Factorized Multiplicative Modulation (FMM) layers [S1, unofficial].
*   **FMM Layer Layout:** An FMM layer takes an input $\mathbf{x}_{in}$ of size $n_{in}$ and produces an output $\mathbf{y}$ of size $n_{out}$ [S1, unofficial].
    *   Shared parameters: Weight matrix $W$ and bias vector $b$ [S1, unofficial].
    *   Modulation parameters: Two matrices $A$ and $B$ generated by the generator $G$ [S1, unofficial].
    *   Dimensions: $A$ is $n_{out} \times k$, $B$ is $k \times n_{in}$ [S1, unofficial].
    *   Rank parameter: $k$ controls the rank of the modulation $A \times B$ [S1, unofficial].
*   **Target Network Dimensions:**
    *   Hidden layer channels: 128 (reduced from standard 256) [S1, unofficial].
    *   Network depth: 4 layers (reduced from standard 8) in some experiments [S1, unofficial].
    *   Rank $k$: 10 [S1, unofficial].

**Formulas:**
The FMM layer operation is defined as [S1, unofficial]:
$$
\mathbf{y} = W \odot (A \times B) \cdot \mathbf{x}_{in} + \mathbf{b} = \tilde{W} \cdot \mathbf{x}_{in} + \mathbf{b}
$$
where $\tilde{W} = W \odot (A \times B)$ [S1, unofficial].

The target NeRF maps spatial location to color and density [S1, unofficial]:
$$
F_\theta: \mathbf{x} \rightarrow (\mathbf{c}, \sigma)
$$

The GAN training objective is a minimax game [S1, unofficial]:
$$
\min_G \max_D V(D, G)
$$
where
$$
V = \mathbb{E}_{\mathbf{x} \sim P_{data}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z} \sim P_{noise}}[\log(1 - D(G(\mathbf{z})))]
$$

**Numbered Steps:**
1.  Sample a noise vector $\mathbf{z}$ from the base Gaussian distribution $P_{noise}$ [S1, unofficial].
2.  Transform $\mathbf{z}$ using the generator $G$ to obtain the weights $\theta$ of the target NeRF model $F_\theta$ [S1, unofficial].
3.  Instantiate the target NeRF model $F_\theta$ using the generated weights [S1, unofficial].
4.  Render 2D images from the target NeRF model $F_\theta$ from a variety of perspectives (camera poses) [S1, unofficial].
5.  Evaluate the rendered 2D images using a standard 2D discriminator $D$ [S1, unofficial].
6.  Update the generator $G$ and discriminator $D$ using the GAN minimax objective [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class FMMLayer(nn.Module):
    """
    Factorized Multiplicative Modulation layer.
    W, b are shared parameters. A, B are modulation matrices from Generator.
    """
    def __init__(self, n_in, n_out, k):
        super().__init__()
        self.n_in = n_in
        self.n_out = n_out
        self.k = k
        # Shared parameters
        self.W = nn.Parameter(torch.randn(n_out, n_in))
        self.b = nn.Parameter(torch.zeros(n_out))
        # Modulation matrices dimensions
        # A: n_out x k, B: k x n_in
        
    def forward(self, x_in, A, B):
        # x_in: (batch, n_in)
        # A: (batch, n_out, k)
        # B: (batch, k, n_in)
        
        # Compute modulation weight matrix: W_tilde = W o (A x B)
        # A x B results in (batch, n_out, n_in)
        modulation = torch.bmm(A, B) 
        W_tilde = self.W * modulation # Element-wise multiplication
        
        # Linear transformation with modulation
        # y = W_tilde @ x_in + b
        # Note: Broadcasting handles batch dimensions if x_in is (batch, n_in)
        # and W_tilde is (batch, n_out, n_in)
        y = torch.bmm(W_tilde, x_in.unsqueeze(-1)).squeeze(-1) + self.b
        return y

class TargetNeRF(nn.Module):
    """
    Simplified NeRF target network.
    Input: 3D position x.
    Output: Color c, Density sigma.
    Uses FMM layers.
    """
    def __init__(self, n_in=3, n_out_color=3, n_out_sigma=1, hidden_dim=128, num_layers=4, k=10):
        super().__init__()
        self.num_layers = num_layers
        self.hidden_dim = hidden_dim
        self.k = k
        
        # Layers
        self.layers = nn.ModuleList()
        for i in range(num_layers):
            in_dim = n_in if i == 0 else hidden_dim
            out_dim = hidden_dim
            self.layers.append(FMMLayer(in_dim, out_dim, k))
            
        # Heads
        self.color_head = nn.Linear(hidden_dim, n_out_color)
        self.sigma_head = nn.Linear(hidden_dim, n_out_sigma)

    def forward(self, x, A_list, B_list):
        """
        x: (batch, 3)
        A_list: list of A matrices, each (batch, hidden_dim, k)
        B_list: list of B matrices, each (batch, k, hidden_dim)
        """
        h = x
        for i, layer in enumerate(self.layers):
            # Apply FMM layer
            h = layer(h, A_list[i], B_list[i])
            # Activation (ReLU is standard for NeRF hidden layers, though not explicitly 
            # specified for FMM, standard NeRF uses ReLU. [G] Assuming ReLU activation 
            # after each FMM layer as per standard MLP structure in NeRF)
            h = F.relu(h)
            
        c = self.color_head(h)
        sigma = self.sigma_head(h)
        return c, sigma

class Generator(nn.Module):
    """
    Hypernetwork Generator.
    Input: Noise z.
    Output: Weights (A, B matrices) for TargetNeRF.
    Based on StyleGAN2 backbone [S1, unofficial].
    """
    def __init__(self, z_dim, n_layers, hidden_dim, k):
        super().__init__()
        self.n_layers = n_layers
        self.hidden_dim = hidden_dim
        self.k = k
        
        # StyleGAN2-like mapping network to map z to intermediate latent w
        # [G] Simplified mapping network structure. 
        # In practice, this involves multiple linear layers with AdaIN or similar.
        # For the purpose of this article, we assume it outputs the modulation matrices.
        
        # We need to generate A and B for each layer.
        # A: (batch, hidden_dim, k)
        # B: (batch, k, hidden_dim)
        
        # [G] Placeholder for StyleGAN2 generator logic. 
        # The generator produces A and B matrices from z.
        self.mapping_net = nn.Sequential(
            nn.Linear(z_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
        )
        
        # Projection to generate A and B parameters
        # Total parameters needed: n_layers * (hidden_dim * k + k * hidden_dim)
        self.proj = nn.Linear(hidden_dim, n_layers * 2 * hidden_dim * k)

    def forward(self, z):
        w = self.mapping_net(z)
        params = self.proj(w)
        
        # Reshape params into A and B lists
        # params shape: (batch, n_layers * 2 * hidden_dim * k)
        # Split into A and B parts
        # A part: n_layers * hidden_dim * k
        # B part: n_layers * k * hidden_dim
        
        # Reshape to (batch, n_layers, 2, hidden_dim, k)
        params = params.view(z.shape[0], self.n_layers, 2, self.hidden_dim, self.k)
        
        A = params[:, :, 0, :, :] # (batch, n_layers, hidden_dim, k) -> need (batch, hidden_dim, k) per layer?
        # Wait, A is n_out x k. n_out is hidden_dim. So A is (hidden_dim, k).
        # B is k x n_in. n_in is hidden_dim. So B is (k, hidden_dim).
        
        # Reshape A to (batch, n_layers, hidden_dim, k)
        # Reshape B to (batch, n_layers, k, hidden_dim)
        
        A = A.view(z.shape[0], self.n_layers, self.hidden_dim, self.k)
        B = params[:, :, 1, :, :].view(z.shape[0], self.n_layers, self.k, self.hidden_dim)
        
        return A, B

class Discriminator(nn.Module):
    """
    Standard 2D Discriminator.
    Input: 2D Image.
    Output: Real/Fake score.
    """
    def __init__(self, channels=3):
        super().__init__()

        self.net = nn.Sequential(
            nn.Conv2d(channels, 64, 4, stride=2, padding=1),

            nn.Conv2d(128, 256, 4, stride=2, padding=1),

            nn.LeakyReLU(0.2),
            nn.Conv2d(256, 1, 4, stride=1, padding=0),
            nn.Sigmoid()
        )

    def forward(self, x):
        return self.net(x)
```

**Edge Cases and Pitfalls:**
*   **Viewing Directions:** Standard NeRF requires viewing directions, which are often unavailable. HyperNeRFGAN solves this by removing viewing directions from the NeRF input [S1, unofficial].
*   **Fine Network:** Standard NeRF uses a 'fine' network for multi-scale rendering. HyperNeRFGAN rejects the larger 'fine' network and employs only the smaller 'coarse' network to reduce training cost [S1, unofficial].
*   **Rank $k$:** Higher values of $k$ increase expressiveness but also increase memory usage [S1, unofficial].

## Operating characteristics
*   **Time and Memory Complexity:** The use of a hypernetwork adds complexity to the generator, but the target NeRF is simplified (single network, no fine network, reduced channels/layers) to reduce computational expense [S1, unofficial].
*   **Measured Performance:**
    *   **ShapeNet Car:** FID 29.6 (vs Point2NeRF 82.1) [S1, unofficial].
    *   **CARLA Dataset:** FID 20.5, KID 0.78, IS 4.20 (outperforming HoloGAN FID 67.5, GRAF FID 41.7, π-GAN FID 29.2) [S1, unofficial].
    *   **CelebA Dataset:** FID 15.04, KID 0.66, IS 2.63 (comparable to π-GAN FID 14.7, KID 0.39, IS 2.62) [S1, unofficial].
    *   **Medical (DRR):** Superior performance compared to MedNeRF and UMedNeRF in FID and KID metrics [S1, unofficial].
*   **Strengths:** Does not require camera position information; suitable for datasets where camera estimation is challenging (e.g., medical data, single-view objects); superior performance on datasets with limited views [S1, unofficial].
*   **Limitations:** Cannot model view-dependent effects (e.g., reflections) as viewing directions are omitted [S1, unofficial].
*   **When to use:** When training data lacks camera poses or view-dependent characteristics, or when computational resources are limited [S1, unofficial].
*   **When not to use:** When view-dependent effects are important [S1, unofficial].

## Background
HyperNeRFGAN was introduced in a paper titled "HyperNeRFGAN: Hypernetwork approach to 3D NeRF GAN" [S1, unofficial]. It builds on the hypernetwork paradigm (Ha et al., 2016) and the StyleGAN2 architecture [S1, unofficial]. It is used for 3D object generation on ShapeNet (car, plane, chair) and CARLA datasets, and for medical applications on Digitally Reconstructed Radiographs (DRR) of chests and knees [S1, unofficial].
