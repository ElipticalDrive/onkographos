# R2L (Neural Light Field)

Also called: Neural Light Field, R2L network

## Overview
R2L is a deep neural light field (NeLF) network trained via distillation from a pre-trained NeRF teacher to achieve efficient novel view synthesis with significantly reduced FLOPs [S1]. It differs from standard NeRF by using a much deeper network with extensive internal residual blocks, trading width for depth under the same FLOPs budget to consistently gain performance [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A query point $\mathbf{x} \in \mathbb{R}^3$ and a viewing direction $\mathbf{d} \in \mathbb{R}^3$.
*   **Output:** Volume density $\sigma$ and color $\mathbf{c}$.

**Data Structures:**
The model is a multi-layer perceptron (MLP) with specific architectural constraints:
*   **Width ($W$):** 256 (W256D88) or 181 (W181D88) [S1].
*   **Depth ($D$):** 88 layers [S1].
*   **Internal Structure:** Extensive residual blocks are used in internal layers. The network does not use standard skip connections for ray directions in the internal layers as in original NeRF, but relies on residual connectivity for trainability [S1].

**Training Procedure:**
1.  **Teacher Initialization:** Train a standard NeRF teacher model using a batch size of 1,024, initial learning rate $5 \times 10^{-4}$ (decayed during training), for 200k iterations [S1].
2.  **Pseudo Data Generation:** Synthesize pseudo training data by sampling rays from the pre-trained NeRF teacher. The default pseudo sample size $S$ is 10,000 images, though performance saturates around 5,000 images [S1].
3.  **Architecture Initialization:** Initialize the R2L network with width $W$ and depth $D=88$ [S1].
4.  **Hard-Example Selection:** For each training batch, select a fraction $r$ of rays with small PSNR (hard examples) to focus optimization on fine-grained details. The default ratio is $r=0.2$ [S1].
5.  **Optimization:** Train the R2L network for 1,000k iterations using the Adam optimizer with the same learning rate schedule as the teacher NeRF [S1]. The batch size is 98,304 rays per batch, sampled randomly from different images so they do not share the same origin [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.optim as optim

class ResidualBlock(nn.Module):
    """
    A residual block for the R2L network.
    Consists of two linear layers with ReLU activation.
    """
    def __init__(self, width):
        super(ResidualBlock, self).__init__()
        self.fc1 = nn.Linear(width, width)
        self.fc2 = nn.Linear(width, width)
        self.relu = nn.ReLU()

    def forward(self, x):
        identity = x
        out = self.fc1(x)
        out = self.relu(out)
        out = self.fc2(out)
        out += identity
        out = self.relu(out)
        return out

class R2LNetwork(nn.Module):
    """
    The R2L Neural Light Field network.
    Depth D=88, Width W=256 or 181.
    """
    def __init__(self, width=256, depth=88):
        super(R2LNetwork, self).__init__()
        self.width = width
        self.depth = depth
        
        # Input layer: position (3) + direction (3) = 6
        self.input_layer = nn.Linear(6, width)
        self.relu = nn.ReLU()
        
        # Internal layers: extensive residual blocks
        # The first internal layer takes the output of the input layer
        self.residual_blocks = nn.ModuleList([
            ResidualBlock(width) for _ in range(depth - 2)
        ])
        
        # Output layers
        self.sigma_layer = nn.Linear(width, 1)
        self.color_layer = nn.Linear(width, 3)

    def forward(self, xyz, dirs):
        # Concatenate position and direction
        x = torch.cat([xyz, dirs], dim=-1)
        
        # Input projection
        x = self.input_layer(x)
        x = self.relu(x)
        
        # Deep residual processing
        for block in self.residual_blocks:
            x = block(x)
            
        # Predict density
        sigma = torch.exp(self.sigma_layer(x)) # Ensure positive density
        
        # Predict color
        color = torch.sigmoid(self.color_layer(x))
        
        return sigma, color

    # Combine real and pseudo data if using Ours-2 configuration

    for i in range(num_iterations):
```

**Parameters:**
*   **Batch Size:** 98,304 rays per batch [S1].
*   **Hard Example Ratio ($r$):** Fraction of hard examples per batch. Default 0.2. Tested values $\{0, 0.1, 0.2, 0.3\}$ [S1].
*   **Pseudo Sample Size ($S$):** Number of pseudo images used for training. Default 10k. Performance saturates around 5k images [S1].
*   **Hardware:** 8 NVIDIA V100 GPUs [S1].
*   **Framework:** PyTorch 1.9 [S1].

**Edge Cases and Pitfalls:**
*   **Overfitting:** The deep network is over-parameterized. Using only original captured images (e.g., 0.1k images) leads to severe overfitting (e.g., 19.81 PSNR on Lego) [S1]. Pseudo data is critical to prevent this [S1].
*   **Trainability:** Without residual blocks, the network is barely trainable [S1].
*   **Reflections:** Unlike methods relying on ground-truth depth (e.g., DONeRF-8), R2L handles reflection surfaces (water, mirrors) well because it does not rely on depth inputs which fail on reflective geometry [S1].

## Operating characteristics
*   **FLOPs:** R2L (W256D88) uses 11.79 M FLOPs compared to Teacher NeRF's 303.82 M FLOPs [S1].
*   **Speed:** 28–31× faster than NeRF and 2× faster than DONeRF-16-noGT on GeForce 2080Ti, Tesla V100, and CPU benchmarks [S1].
*   **Quality (NeRF Synthetic):** Ours-2 (Pseudo+real) achieves 31.87 PSNR (+1.40 over teacher), 0.9950 SSIM, 0.0340 LPIPS [S1].
*   **Quality (DONeRF Synthetic):** Ours-2 achieves 35.45 PSNR (+2.78 over teacher), 0.047 FLIP [S1].
*   **Strengths:** High efficiency, better handling of reflections than depth-based methods, improved quality over teacher via deeper capacity and hard-example training [S1].
*   **Limitations:** Blurry parts from the teacher NeRF may appear in R2L results [S1]. Requires significant pseudo data generation [S1].

## Background
R2L (R2L: Distilling Neural Radiance Field to Neural Light Field for Efficient Novel View Synthesis) was proposed by H. Wang et al. [S1]. It is the first deep neural light field network capable of representing complex synthetic and real-world scenes. The method addresses the high computational cost of NeRF by distilling knowledge into a deeper, residual-based NeLF architecture [S1].
