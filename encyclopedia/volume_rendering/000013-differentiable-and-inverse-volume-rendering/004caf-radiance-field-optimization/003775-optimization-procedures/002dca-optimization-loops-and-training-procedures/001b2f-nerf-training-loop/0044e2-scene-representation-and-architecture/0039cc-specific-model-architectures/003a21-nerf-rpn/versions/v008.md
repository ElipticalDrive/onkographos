# NeRF-RPN

Also called: NeRF Region Proposal Network

## Overview
NeRF-RPN is a general framework for 3D object detection within neural radiance fields that regresses bounding boxes directly from the scene representation without rendering intermediate views [S1]. It solves the problem of identifying and localizing discrete objects in a continuous, view-dependent radiance field by treating detection as a dense prediction task on a voxelized feature volume [S1]. It sets itself apart from instance-level segmentation methods like [NeRF-RCNN](10610-nerf-rcnn.md) by providing a proposal generation stage that can be used for unlabelled object detection, whereas NeRF-RCNN refines these proposals into final discrete masks and class labels [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained NeRF model representing the scene, defined by its density $\sigma$ and color $\mathbf{c}$ fields [S1].
*   **Output:** A set of 3D Axis-Aligned Bounding Boxes (AABB) or oriented bounding boxes with associated objectness scores [S1, S2].

**Data Structures:**
The method employs a multi-scale **Object-NeRF** architecture [S1]. This consists of two coupled branches:
1.  **Scene Branch:** Encodes the global geometry and appearance of the scene using a voxel representation of 3D neural volume features [S1].
2.  **Object Branch:** Encodes features for each independent object candidate [S1].

**Network Topology:**
The core detection head is built upon a feature extraction backbone (e.g., VGG19, ResNet-50, Swin-S) applied to the voxelized features [S2]. The head architecture varies between two main variants:
1.  **Anchor-based:** Predicts offsets relative to predefined 3D anchor boxes [S2].
2.  **Anchor-free:** Predicts bounding box dimensions and center offsets directly, augmented by a **centerness** prediction to suppress low-quality off-center proposals [S2].

**Rendering Integration:**
Unlike traditional 2D detectors, NeRF-RPN does not require rendering images from multiple viewpoints to detect objects. It operates directly on the implicit 3D representation [S1].

**Training Steps:**
1.  **Feature Extraction:** The voxelized 3D neural volume features from the Scene Branch are passed through the backbone network to generate multi-scale feature volumes [S1, S2].
2.  **Proposal Generation:** The RPN head processes these feature volumes to predict objectness scores and bounding box coordinates [S2].
    *   For anchor-free models, all output proposals are used to compute the loss [S2].
    *   For anchor-based models, a ratio of positive to negative anchors of 1:1 is maintained during loss computation [S2].
3.  **Loss Computation:** The model is optimized using a combination of classification/objectness loss and bounding box regression loss [S2]. Common regression losses include IoU loss [S2].

**Pseudocode:**
```python
def nerf_rpn_forward(scene_nerf, voxel_features, backbone, rpn_head):
    """
    Forward pass for NeRF-RPN.
    scene_nerf: Pre-trained NeRF model (provides density/color fields).
    voxel_features: 3D voxel grid of neural volume features from Scene Branch.
    backbone: Feature extractor (e.g., VGG19, ResNet-50, Swin-S).
    rpn_head: Region Proposal Network head (Anchor-based or Anchor-free).
    """
    # 1. Extract multi-scale features from the voxelized scene representation
    feature_volumes = backbone(voxel_features)
    
    # 2. Generate proposals using the RPN head
    # Returns: list of bounding boxes, list of objectness scores
    proposals, scores = rpn_head(feature_volumes)
    
    return proposals, scores

def nerf_rpn_test(proposals, scores, scene_boundary, nms_iou_threshold=0.1, top_k=2500):
    """
    Testing and proposal filtering pipeline for NeRF-RPN.
    """
    # Step 1: Discard ROIs whose geometry centers are beyond the scene boundary
    valid_proposals = []
    valid_scores = []
    for box, score in zip(proposals, scores):
        if is_inside_scene_boundary(box.center, scene_boundary):
            valid_proposals.append(box)
            valid_scores.append(score)
            
    # Step 2: Select top proposals on each level of feature volumes independently
    # Note: In practice, this implies filtering per scale level before aggregation
    # For simplicity, we aggregate and then filter, assuming level-aware scoring
    # is handled by the head's output structure.
    
    # Step 3: Apply Non-Maximum Suppression (NMS) based on rotated-IoU
    # Aggregated boxes are suppressed based on rotated-IoU threshold
    final_boxes, final_scores = nms(
        valid_proposals, 
        valid_scores, 
        iou_threshold=nms_iou_threshold, 
        use_rotated_iou=True
    )
    
    # Step 4: Select the top 2,500 boxes with the highest objectness scores
    sorted_indices = argsort_desc(final_scores)
    selected_boxes = final_boxes[sorted_indices[:top_k]]
    selected_scores = final_scores[sorted_indices[:top_k]]
    
    return selected_boxes, selected_scores
```

**Parameters:**
*   **NMS Threshold:** Rotated-IoU threshold of 0.1 [S2].
*   **Top-K Proposals:** 2,500 proposals selected per feature level and after NMS [S2].

**Edge Cases and Pitfalls:**
*   **Noisy NeRF Input:** Anchor-free models with centerness prediction are more robust to noisy NeRF inputs and misalignment between bounding box centers and mass centers [S2].
*   **Tiny Objects:** The method may fail to generate proposals for tiny or second-level objects [S2].
*   **Rotation Errors:** Incorrect rotation predictions can occur in complex scenes [S2].
*   **Merging/Missing:** Proposals may merge distinct objects or miss objects entirely in cluttered scenes [S2].

## Subtopics

### NeRF-RPN Backbone and Head Selection
The performance of NeRF-RPN is sensitive to the choice of backbone and head type [S2].
*   **Head Type:** Anchor-free models generally achieve higher Average Precision (AP) than anchor-based models across datasets (3D-FRONT, ScanNet, Hypersim) when backbones are fixed [S2]. This is attributed to centerness prediction suppressing off-center proposals and the flexibility to handle varying 3D object sizes without limited anchor aspect ratios [S2].
*   **Backbone Choice:** VGG19 generally achieves better recall and AP compared to ResNet-50 and Swin-S [S2]. However, on the Hypersim dataset, which contains noisier NeRF results and complex scenes, Swin-S demonstrates superior recall and AP for anchor-based models due to its larger receptive fields, shifted windows, and attention mechanisms [S2].

### [NeRF-RCNN](10610-nerf-rcnn.md)
NeRF-RCNN is a proposal-based 3D instance segmentation model that takes a pre-trained NeRF as input. It extends NeRF-RPN by appending a box prediction head and a mask prediction head to refine proposals into final instances. Unlike NeRF-RPN, which outputs bounding boxes, NeRF-RCNN outputs discrete 3D masks and class labels. It is chosen when instance-level segmentation is required rather than just detection.

### [NeRF-MAE Pretraining Architecture](11771-nerf-mae-pretraining-architecture.md)
NeRF-MAE is a self-supervised pretraining architecture for 3D radiance fields that utilizes Masked Autoencoders (MAE) to learn robust scene representations from unlabeled data. It sets itself apart from supervised baselines like NeRF-RPN by enabling efficient transfer learning for downstream tasks such as 3D object detection and voxel super-resolution, achieving significant performance gains with fewer labeled annotations.

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:**
    *   On **Hypersim**, VGG19 (Anchor-free) achieves Recall@25 of 66.7 and AP@25 of 27.7 [S2]. Swin-S (Anchor-based) achieves Recall@25 of 69.8 and AP@25 of 13.0 [S2].
    *   On **3D-FRONT**, VGG19 (Anchor-free) achieves Recall@25 of 96.3 and AP@25 of 69.9 [S2].
    *   On **ScanNet**, VGG19 (Anchor-free) achieves Recall@25 of 89.2 and AP@25 of 42.9 [S2].
*   **Strengths:** General framework for unlabelled object detection; does not require rendering views; anchor-free variant handles varying object sizes well [S1, S2].
*   **Limitations:** May miss tiny objects; sensitive to noisy NeRF inputs (mitigated by anchor-free heads); rotation errors possible [S2].
*   **When to use:** When detecting objects in a NeRF scene without instance masks or when using a general detection framework.
*   **When not to use:** When instance-level segmentation masks are required (use [NeRF-RCNN](10610-nerf-rcnn.md)) or when self-supervised pretraining is needed for downstream tasks (use [NeRF-MAE](11771-nerf-mae-pretraining-architecture.md)).

## Background
NeRF-RPN was proposed by Hu et al. in 2023 [S1]. It was introduced to enable the detection of all objects' bounding boxes in a scene using a multi-scale Object-NeRF architecture [S1]. The method leverages the voxel representation of 3D neural volume features to regress 3D bounding boxes directly, avoiding the need for rendering from any viewpoint [S1]. It serves as a general framework applicable to unlabelled objects [S1].
