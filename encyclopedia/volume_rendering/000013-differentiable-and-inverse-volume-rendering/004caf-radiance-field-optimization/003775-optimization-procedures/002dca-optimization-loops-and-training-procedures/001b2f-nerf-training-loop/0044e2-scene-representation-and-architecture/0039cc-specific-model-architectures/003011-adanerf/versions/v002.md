# AdaNeRF

Also called: Adaptive Sampling for Real-time Rendering of Neural Radiance Fields

## Overview
AdaNeRF is a method that employs fixed sample positions along each ray and incrementally introduces sparsity during training to achieve real-time rendering [S1]. It splits the NeRF network into a lightweight Sampling Network and a heavier Shading Network, where the former predicts sample importance weights and the latter processes only the most significant samples [S1]. This approach allows for fine-tuning to a desired number of samples, resulting in a compact neural representation suitable for real-time applications [S1].

## How it works
**Inputs and Outputs:**
*   Input: Camera ray parameters (origin $\mathbf{o}$, direction $\mathbf{d}$), training images, and ground truth colors.
*   Output: Rendered image pixels.

**Data Structures:**
1.  **Sampling Network ($N_{sample}$):** A lightweight MLP.
2.  **Shading Network ($N_{shade}$):** A heavier MLP, typically initialized from a pre-trained NeRF [S1].
3.  **Fixed Sample Positions:** A set of $K$ equidistant points along the ray, defined by distances $\delta_i$ from the ray origin.

**Steps:**
1.  **Initialization:** Initialize $N_{shade}$ using a pre-trained NeRF model to ensure good color initialization [S1]. Initialize $N_{sample}$ with random weights.
2.  **Sampling Weight Prediction:** For a given ray, evaluate $N_{sample}$ once to predict importance weights $w_i$ for all $K$ fixed sample positions [S1].
    *   The network takes ray parameters as input and outputs a vector of weights.
3.  **Sparsity Introduction:** During training, incrementally introduce sparsity. This involves selecting a subset of samples based on the predicted weights $w_i$ [S1].
4.  **Shading:** Evaluate the heavier $N_{shade}$ only for the selected significant samples to compute density $\sigma$ and color $\mathbf{c}$ [S1].
5.  **Rendering:** Compute the final color using the standard volume rendering equation with the selected samples [S1].
6.  **Fine-tuning:** Fine-tune the model to the desired number of samples to create a compact representation [S1].

**Pseudocode:**
```python
def render_ray(ray_origin, ray_direction, K, N_sample, N_shade, num_samples_to_select):
    # Step 1: Define fixed sample positions
    # Assuming equidistant sampling along the ray
    t_values = linspace(t_near, t_far, K)
    sample_points = ray_origin + t_values[:, None] * ray_direction
    
    # Step 2: Predict importance weights using Sampling Network
    # N_sample takes ray parameters (or derived features) and outputs K weights
    weights = N_sample(ray_origin, ray_direction)
    
    # Step 3: Select significant samples based on weights
    # Sort weights and select top indices
    top_indices = argsort(weights, descending=True)[:num_samples_to_select]
    selected_t_values = t_values[top_indices]
    selected_points = ray_origin + selected_t_values[:, None] * ray_direction
    
    # Step 4: Shade selected samples using Shading Network
    # N_shade takes 3D coordinates and viewing direction
    densities, colors = N_shade(selected_points, ray_direction)
    
    # Step 5: Render using volume rendering equation
    # Calculate deltas between selected points
    deltas = diff(selected_t_values, prepend=t_near)
    
    # Calculate opacity and transmittance
    alphas = 1 - exp(-densities * deltas)
    transmittances = exp(-cumsum(densities * deltas[:-1]))
    transmittances = concatenate([ones(1), transmittances])
    
    # Composite color
    contribution = transmittances * alphas * colors
    final_color = sum(contribution)
    
    return final_color
```

**Parameters:**
*   $K$: Total number of fixed sample positions. Not given in the sources.
*   $N_{sample}$: Architecture of the sampling network. Not given in the sources.
*   $N_{shade}$: Architecture of the shading network. Not given in the sources.
*   $t_{near}, t_{far}$: Near and far clipping planes. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Initialization:** Requires a pre-trained NeRF to initialize the color network for best results [S1].
*   **Sparsity Schedule:** The rate of introducing sparsity must be managed to avoid premature convergence to poor sample locations [S1].

## Operating characteristics
*   **Time Complexity:** Reduced compared to standard NeRF due to fewer shading network evaluations. The sampling network is lightweight and evaluated once per ray [S1].
*   **Memory Complexity:** Compact neural representation after fine-tuning [S1].
*   **Performance:** Enables real-time rendering [S1]. Adaptable to meet performance targets [S1].
*   **Strengths:** Real-time capability, compact representation, no depth map required [S1].
*   **Limitations:** Requires pre-training [S1]. Fixed sample positions may not adapt to complex geometry as well as learned positions [S1].

## Background
AdaNeRF was introduced by Kurz et al. in 2022 [S1]. It is part of the broader effort to accelerate neural radiance fields for real-time applications [S1]. The method builds on the idea of splitting the NeRF network into sampling and shading components [S1].
