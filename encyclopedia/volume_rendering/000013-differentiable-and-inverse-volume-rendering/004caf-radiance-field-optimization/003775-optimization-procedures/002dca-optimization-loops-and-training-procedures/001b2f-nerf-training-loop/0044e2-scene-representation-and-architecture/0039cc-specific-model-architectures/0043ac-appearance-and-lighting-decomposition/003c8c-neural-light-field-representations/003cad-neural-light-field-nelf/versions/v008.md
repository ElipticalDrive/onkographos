# Neural Light Field (NeLF)

Also called: Neural Light Field (NeLF) via R2L Distillation, Neural Light Field with Distillation, R2L (Neural Light Field with Distillation), R2L network

## Overview
Neural Light Field (NeLF) via R2L Distillation is a method for efficient novel view synthesis that represents a 3D scene as a Neural Light Field rather than a Neural Radiance Field [S1]. It maps camera ray origin and direction directly to RGB values, avoiding ray-marching and iterative sampling [S1]. Unlike the parent architecture which predicts density $\sigma$ to compute transmittance $T_i$ and alpha $\alpha_i$ for volume integration, NeLF outputs the final accumulated color $\mathbf{c}$ directly [S1]. The method distills a pre-trained NeRF teacher model into a deep residual MLP student model, enabling a single forward pass per ray for rendering [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 6D vector representing an oriented ray, composed of the ray origin coordinates $(x_o, y_o, z_o)$ and the normalized viewing direction $(x_d, y_d, z_d)$ [S1].
*   **Output:** A 3D vector representing the final accumulated RGB color $(r, g, b)$ [S1].

**Data Structures:**
The input representation concatenates the spatial coordinates of $K$ sampled points along the ray, forming a $3K$-dimensional vector [S1].
*   $K$: Number of sampled points. Default value is 16 [S1].
*   Input Vector: $[x_1, y_1, z_1, x_2, y_2, z_2, \dots, x_K, y_K, z_K]$ [S1].
*   Network Architecture: A deep residual Multi-Layer Perceptron (MLP) [S1].
    *   Depth: 88 layers [S1].
    *   Width: Configurable. Common configurations are W256D88 (12M FLOPs) and W181D88 (6M FLOPs) [S1].
    *   Internal Structure: Extensive residual blocks are used in internal layers [S1].
    *   Positional Encoding: Sinusoidal positional encoding $\gamma(\cdot)$ is applied to the input coordinates to mitigate spectral bias, following the NeRF method [S1, Parent].

**Training Data Generation (Distillation):**
Since deep networks require extensive data and original captured images are insufficient, pseudo data is generated by rendering images from random views using a pre-trained NeRF teacher model $F_{\Theta^*}$ [S1].
1.  Define a viewing bounding box inferred from training data camera poses [S1].
2.  Sample ray origins $(x_o, y_o, z_o)$ and normalized directions $(x_d, y_d, z_d)$ from a uniform distribution $U$ within the bounding box [S1]:
    $$
    \begin{aligned}
    x_o &\sim U(x_{o,\min}, x_{o,\max}), & y_o &\sim U(y_{o,\min}, y_{o,\max}), & z_o &\sim U(z_{o,\min}, z_{o,\max}) \\
    x_d &\sim U(x_{d,\min}, x_{d,\max}), & y_d &\sim U(y_{d,\min}, y_{d,\max}), & z_d &\sim U(z_{d,\min}, z_{d,\max})
    \end{aligned}
    $$
    [S1]
3.  Query the pre-trained NeRF teacher model $F_{\Theta^*}$ with the sampled 6D input to obtain the target RGB value $(\hat{r}, \hat{g}, \hat{b})$ [S1]:
    $$
    (\hat{r}, \hat{g}, \hat{b}) = F_{\Theta^*}(x_o, y_o, z_o, x_d, y_d, z_d)
    $$
    [S1]
4.  The training slice is the vector $(x_o, y_o, z_o, x_d, y_d, z_d, \hat{r}, \hat{g}, \hat{b})$ [S1].
5.  Default pseudo sample size $S$ is 10,000 images [S1]. Performance saturates around 5,000 images [S1].

**Point Sampling Strategy:**
*   **Training:** $K$ points are randomly sampled along the ray using stratified sampling to prevent overfitting to specific point locations and ensure generalization [S1].
*   **Testing:** $K$ points are evenly spaced along the ray [S1].

**Training Objective and Optimization:**
The network is trained using Mean Squared Error (MSE) loss between the NeLF output and the NeRF teacher's output [S1]:
$$
L = \text{MSE}(G_\phi(x_o, y_o, z_o, x_d, y_d, z_d), (\hat{r}, \hat{g}, \hat{b}))
$$
[S1]

*   **Optimizer:** Adam [S1].
*   **Learning Rate:** Initial learning rate $5 \times 10^{-4}$, decayed during training, using the same schedule as the teacher NeRF [S1].
*   **Iterations:** 1,000,000 (1,000k) iterations [S1].
*   **Batch Size:** 98,304 rays per batch [S1].
*   **Hardware:** 8 NVIDIA V100 GPUs [S1].
*   **Framework:** PyTorch 1.9 [S1].

**Hard Example Mining:**
To focus optimization on fine-grained details and accelerate convergence, hard example mining is applied [S1].
1.  Maintain a pool of hard examples defined by larger loss values [S1].
2.  In each iteration, sort batch losses in ascending order [S1].
3.  Add the top $r$ (a pre-defined percentage constant) of samples to the hard example pool [S1].
4.  Randomly pick $r$ samples from the pool to augment the training batch [S1].
5.  Default hard example ratio $r$ is 0.2 [S1]. Tested values include $\{0, 0.1, 0.2, 0.3\}$ [S1].

import torch
import torch.nn as nn
import torch.optim as optim

# torch.nn.functional.relu, torch.cat, etc.

class ResidualBlock(nn.Module):
    """
    A single residual block for the NeLF network.
    Uses ReLU activation.
    """
    def __init__(self, width):
        super(ResidualBlock, self).__init__()
        self.fc1 = nn.Linear(width, width)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(width, width)

    def forward(self, x):
        out = self.fc1(x)
        out = self.relu(out)
        out = self.fc2(out)
        return x + out  # Residual connection

class NeLF(nn.Module):
    """
    Deep Residual MLP for Neural Light Field.
    Architecture: W256D88 or W181D88.
    Input: 3K dimensional vector (K=16).
    Output: 3 dimensional vector (RGB).
    """
    def __init__(self, width=256, depth=88, k=16):
        super(NeLF, self).__init__()
        self.k = k
        input_dim = 3 * k
        
        # Initial linear layer
        self.input_layer = nn.Linear(input_dim, width)
        self.relu = nn.ReLU()
        
        # Deep residual blocks
        self.residual_blocks = nn.ModuleList([
            ResidualBlock(width) for _ in range(depth)
        ])
        
        # Final output layer
        self.output_layer = nn.Linear(width, 3)

    def forward(self, x):
        # x shape: (batch_size, 3*K)
        out = self.input_layer(x)
        out = self.relu(out)
        
        for block in self.residual_blocks:
            out = block(out)
            
        rgb = self.output_layer(out)
        return rgb

def positional_encoding(x, min_deg=0, max_deg=10):
    """
    Sinusoidal positional encoding as used in NeRF.
    """
    scales = torch.tensor([2**i for i in range(min_deg, max_deg)])
    xb = torch.reshape(x, (x.shape[0], -1, 1)) * scales
    four_feat = torch.sin(torch.cat([xb, xb + np.pi/2], dim=-1))
    return torch.reshape(four_feat, (x.shape[0], -1))

def generate_pseudo_data(teacher_nerf, num_samples, bounding_box):

    Generates pseudo training data by querying the NeRF teacher model.
    """
    # bounding_box: dict with keys xmin_o, xmax_o, etc.
    # Sample origins
    xo = torch.rand(num_samples) * (bounding_box['xo_max'] - bounding_box['xo_min']) + bounding_box['xo_min']
    yo = torch.rand(num_samples) * (bounding_box['yo_max'] - bounding_box['yo_min']) + bounding_box['yo_min']
    zo = torch.rand(num_samples) * (bounding_box['zo_max'] - bounding_box['zo_min']) + bounding_box['zo_min']
    
    # Sample directions (normalized)
    xd_raw = torch.rand(num_samples) * (bounding_box['xd_max'] - bounding_box['xd_min']) + bounding_box['xd_min']
    yd_raw = torch.rand(num_samples) * (bounding_box['yd_max'] - bounding_box['yd_min']) + bounding_box['yd_min']
    zd_raw = torch.rand(num_samples) * (bounding_box['zd_max'] - bounding_box['zd_min']) + bounding_box['zd_min']
    
    directions = torch.stack([xd_raw, yd_raw, zd_raw], dim=1)
    directions = directions / torch.norm(directions, dim=1, keepdim=True)
    
    origins = torch.stack([xo, yo, zo], dim=1)
    
    # Query teacher
    # Note: Teacher NeRF F_Theta* typically takes (x,y,z, theta, phi) or (x,y,z, dx,dy,dz)
    # Assuming the teacher accepts the 6D input format described in [S1]
    targets = teacher_nerf(origins, directions)
    
    return origins, directions, targets

def train_step(nelf, teacher_nerf, optimizer, batch_size, hard_example_ratio, bounding_box):
    """
    One training iteration.
    """
    nelf.train()
    
    # 1. Generate a batch of rays
    origins, directions, targets = generate_pseudo_data(teacher_nerf, batch_size, bounding_box)
    
    # 2. Sample points along rays for input representation
    # During training, use stratified sampling
    points = []
    for i in range(batch_size):
        # Extract single ray
        ro = origins[i]
        rd = directions[i]
        # Sample K points
        pts = stratified_sampling(ro, rd, k=16)
        points.append(pts)
    
    points_tensor = torch.stack(points, dim=0) # Shape: (batch_size, K, 3)
    
    # 3. Flatten to 3K dimension
    input_vector = points_tensor.view(batch_size, -1) # Shape: (batch_size, 48)
    
    # 4. Forward pass through NeLF
    predictions = nelf(input_vector) # Shape: (batch_size, 3)
    
    # 5. Compute Loss
    loss = torch.nn.functional.mse_loss(predictions, targets)
    
    # 6. Backward pass
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    
    return loss.item(), predictions, targets

**Edge Cases and Pitfalls:**
*   **Trainability of Deep Networks:** Without residual connections, the deep network (88 layers) is barely trainable [S1].
*   **Overfitting:** Deep networks require abundant data. Using only original captured images (typically <100) leads to severe overfitting (e.g., 19.81 PSNR on Lego) [S1]. Pseudo data is critical [S1].
*   **Input Representation:** Concatenated coordinates perform better than Plücker coordinates (PSNR 29.50 vs 29.08 on Lego) [S1].
*   **Reflection Surfaces:** Unlike methods relying on ground-truth depth (e.g., DONeRF), NeLF handles reflective surfaces (water, mirrors) well because it does not depend on depth maps which fail on reflections [S1].

## Subtopics

### Neural Light Field Representations
The parent category. NeLF replaces the 5D radiance field with a 6D light field mapping ray origin and direction to color [Parent].

### NeRF Training Loop
The distillation process relies on a pre-trained NeRF teacher, which is trained using the standard NeRF training loop [S1, Parent].

## Operating characteristics
**Time and Memory Complexity:**
*   **FLOPs:** R2L achieves 26–35× FLOPs reduction per camera ray compared to NeRF [S1].
    *   W256D88: 12M FLOPs [S1].
    *   W181D88: 6M FLOPs [S1].
*   **Wall-Time Speedup:** 28–31× faster than NeRF on synthetic scenes [S1].
    *   Compared to DONeRF-16-noGT: 2× faster [S1].
    *   Compared to method [4]: ~30× speedup vs ~5× [S1].
*   **Memory:** Storage size is comparable to NeRF (2.4 MB for Teacher NeRF, 23.7 MB for R2L) [S1].

**Measured Performance:**
*   **Synthetic Scenes (NeRF Dataset):**
    *   Ours-1 (Pseudo only): 30.48 PSNR (+0.01 over teacher), 0.9939 SSIM, 0.0391 LPIPS [S1].
    *   Ours-2 (Pseudo + Real): 31.87 PSNR (+1.40 over teacher), 0.9950 SSIM, 0.0340 LPIPS [S1].
*   **Real-World Scenes (Forward-Facing):**
    *   Ours-2: 27.79 PSNR (+0.11 over teacher), 0.9729 SSIM, 0.0340 LPIPS [S1].
*   **DONeRF Synthetic Dataset:**
    *   Ours-2: 35.45 PSNR (+2.78 over teacher), 0.047 FLIP [S1].

**Strengths and Limitations:**
*   **Strengths:** Single forward pass per ray; no customized parallelism required (vanilla PyTorch); handles reflections better than depth-based methods; significantly faster than NeRF and other efficient methods like KiloNeRF and RSEN [S1].
*   **Limitations:** Requires a pre-trained NeRF teacher for distillation; deep network training is sensitive to data volume and requires hard example mining for convergence [S1].

**When to Use:**
*   When high-speed novel view synthesis is required without sacrificing quality.
*   When ground-truth depth is unavailable (unlike DONeRF).
*   When reflective surfaces are present in the scene.

**When Not to Use:**
*   When computational resources for training the deep network are extremely limited (requires 1,000k iterations on 8 GPUs).
*   When the scene is simple and the speedup is not critical, as NeRF may be sufficient.

## Background
**Origin:**
The method was introduced in the paper "R2L: Distilling Neural Radiance Field to Neural Light Field for Efficient Novel View Synthesis" [S1]. It was developed to address the high computational cost of NeRF rendering while maintaining or improving rendering quality.

**History and Development:**
*   NeRF [34] established the radiance field representation but required iterative sampling.
*   Previous NeLF attempts [46, 4] used shallow MLPs (6-8 layers) and achieved limited speedups (~5×) [S1].
*   R2L introduced a deep (88-layer) residual MLP and knowledge distillation from NeRF, achieving >30× speedup and better quality [S1].
*   The method bridges the gap between radiance fields and light fields by using a teacher-student distillation framework [S1].

**Usage:**
Used for efficient novel view synthesis in computer graphics and vision, particularly for synthetic and real-world scenes with complex geometry and materials [S1].
