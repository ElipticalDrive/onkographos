# Mega-NeRF Spatial Partitioning

Also called: Cell-based NeRF, Spatial Data Parallelism

## Overview
Mega-NeRF Spatial Partitioning decomposes a large-scale scene into spatial cells, each managed by a separate MLP submodule, to enable parallel training and reduce memory consumption [S1]. It distinguishes itself from monolithic NeRFs by using a fixed 2D grid of centroids to assign pixels to local subnetworks, and from other sparse methods by explicitly pruning rays based on inferred geometry to minimize redundant computation [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of calibrated training images with poses; a scene bounding volume.
*   **Outputs:** A set of MLP submodules $\{f^n\}$, one per spatial cell $n \in \mathcal{N}$, and their associated appearance embeddings $\{l^{(a)}\}$ for each image $a$.

**Data Structures:**
*   **Centroids ($\mathcal{N}$):** A set of 3D points $n = (n_x, n_y, n_z)$ representing cell centers.
*   **Submodules ($f^n$):** MLPs identical in architecture to the base NeRF, taking position $\mathbf{x}$ and direction $\mathbf{d}$ as input.
*   **Appearance Embeddings ($l^{(a)}$):** A vector per training image $a$ to model lighting variations.
*   **Trainsets ($T^n$):** For each cell $n$, a subset of training pixels/rays assigned to that cell.

**Algorithm Steps:**

1.  **Centroid Initialization:**
    Tessellate the scene into a top-down 2D grid to determine centroid positions. Fix the height ($z$-coordinate) of all centroids to a single value, as altitude variance is small relative to latitude/longitude differences in the target scenes [S1].

2.  **Submodule Initialization:**
    Initialize a separate MLP $f^n$ for each centroid $n \in \mathcal{N}$. Initialize appearance embeddings $l^{(a)}$ for each training image $a$ [S1].

3.  **Visibility Partitioning (Initial Assignment):**
    For each training image $a$:
    a. Sample points along the camera ray for each pixel.
    b. Identify which spatial cells $n$ these points intersect.
    c. Add the pixel to the trainset $T^n$ for every intersecting cell $n$.
    d. Apply an overlap factor (e.g., 15%) to cell boundaries to minimize visual artifacts [S1].

4.  **Spatial Data Pruning (Geometric Pruning):**
    After coarse training, refine the trainsets $T^n$ by removing rays occluded by geometry inferred by other cells. For example, if cell $F$ infers a wall, remove rays from cells $A$ and $B$ that pass through that wall [S1].

5.  **Rendering Query:**
    For a query point $\mathbf{x}$, direction $\mathbf{d}$, and image $a$:
    a. Find the closest centroid $n^*$:
       $$ n^* = \arg\min_{n \in \mathcal{N}} \| n - \mathbf{x} \|^2 $$
    b. Compute opacity $\sigma$ and color $\mathbf{c}$ using the corresponding submodule:
       $$ \sigma = f^{n^*}(\mathbf{x}) $$
       $$ \mathbf{c} = f^{n^*}(\mathbf{x}, \mathbf{d}, l^{(a)}) $$
    [S1]

6.  **Foreground/Background Decomposition:**
    Subdivide the scene into a foreground volume (enclosing all camera poses) and a background volume. Model each with a separate Mega-NeRF instance [S1].

**Pseudocode:**

```python
import numpy as np

def initialize_mega_nerf(images, poses, scene_bounds):
    """
    Initialize Mega-NeRF spatial partitioning.
    images: list of training images
    poses: camera poses corresponding to images
    scene_bounds: bounding box of the scene
    """
    # Step 1: Centroid Initialization
    # Tessellate scene into a top-down 2D grid.
    # Fix height to a single value (e.g., mean camera height).
    centroids = create_2d_grid(scene_bounds) 
    # centroids is a list of 3D points (x, y, fixed_z)
    
    # Step 2: Submodule Initialization
    # Initialize MLPs for each centroid
    submodules = {n: init_mlp() for n in centroids}
    
    # Initialize appearance embeddings for each image
    appearance_embeddings = {i: init_embedding() for i in range(len(images))}
    
    # Step 3: Visibility Partitioning
    trainsets = {n: [] for n in centroids}
    
    for img_idx, (image, pose) in enumerate(zip(images, poses)):
        # Sample rays for this image
        rays = sample_rays(image, pose)
        
        for ray in rays:
            # Determine which cells this ray intersects
            intersecting_cells = find_intersecting_cells(ray, centroids)
            
            # Add ray to trainsets of intersecting cells
            for cell in intersecting_cells:
                trainsets[cell].append((ray, img_idx))
                
    # Apply overlap factor to boundaries (implementation detail omitted)
    # trainsets = apply_overlap(trainsets, overlap_factor=0.15)
    
    return submodules, appearance_embeddings, trainsets

def render_mega_nerf(query_point, direction, image_idx, submodules, centroids, appearance_embeddings):
    """
    Render a single point using the closest submodule.
    """
    # Step 5: Rendering Query
    # Find closest centroid
    distances = [np.linalg.norm(n - query_point) for n in centroids]
    closest_idx = np.argmin(distances)
    closest_centroid = centroids[closest_idx]
    
    # Get submodule and appearance embedding
    submodule = submodules[closest_centroid]
    appearance_emb = appearance_embeddings[image_idx]
    
    # Compute opacity and color
    sigma = submodule.forward(query_point)
    color = submodule.forward(query_point, direction, appearance_emb)
    
    return sigma, color

def prune_trainsets(submodules, trainsets, images, poses, threshold=0.5):
    """
    Step 4: Spatial Data Pruning based on inferred geometry.
    """
    # Coarse training to infer geometry
    # (Implementation assumes a coarse pass has been done)
    
    for cell, rays in trainsets.items():
        pruned_rays = []
        for ray, img_idx in rays:
            # Check if ray is occluded by geometry inferred by OTHER cells
            # This requires querying the scene representation from other submodules
            if not is_occluded_by_other_cells(ray, cell, submodules, centroids):
                pruned_rays.append((ray, img_idx))
        trainsets[cell] = pruned_rays
        
    return trainsets

def is_occluded_by_other_cells(ray, current_cell, submodules, centroids):
    """
    Check if a ray is occluded by geometry from cells other than current_cell.
    """
    # Sample points along the ray
    points = sample_points_along_ray(ray)
    
    for point in points:
        # Find the closest centroid for this point
        distances = [np.linalg.norm(n - point) for n in centroids]
        closest_idx = np.argmin(distances)
        closest_centroid = centroids[closest_idx]
        
        # If the closest centroid is NOT the current cell, check opacity
        if closest_centroid != current_cell:
            submodule = submodules[closest_centroid]
            # Query opacity from the other submodule
            # Note: direction and appearance embedding needed for color, 
            # but opacity depends only on position in standard NeRF
            sigma = submodule.forward(point)
            
            # If opaque, the ray is occluded
            if sigma > 0.5: # Threshold [G]
                return True
                
    return False
```

**Parameters:**
*   **Overlap Factor:** 15% (used to minimize visual artifacts near cell boundaries) [S1].
*   **Centroid Height:** Fixed to a single value for all centroids [S1].

**Edge Cases and Pitfalls:**
*   **Boundary Artifacts:** Without an overlap factor, visual discontinuities may appear at cell boundaries [S1].
*   **Occlusion Ambiguity:** Initial pixel assignment is based on camera positions, not geometry. Pruning must be done after coarse training to avoid removing valid rays prematurely [S1].
*   **Altitude Variance:** The method assumes small altitude variance relative to horizontal differences. Scenes with large vertical extent may require 3D tessellation [S1].

## Subtopics

### Sparse Radiance Field (SRF) Representation
Uses a sparse voxel grid to store features, allowing for efficient storage and querying of large scenes. Choose when memory efficiency is critical and the scene has significant empty space. [8876-sparse-radiance-field-srf-representation.md]

### KiloNeRF
Uses a hash-based encoding to map spatial coordinates to a large feature grid, enabling fast lookup and parallel training. Choose when fast inference and training on moderate-sized scenes are needed. [8942-kilonerf.md]

### ProNeRF
Uses a progressive neural radiance field that refines the scene representation at different levels of detail. Choose when high-frequency details are important and computational resources allow for multi-scale optimization. [9673-pronerf.md]

## Operating characteristics
*   **Time Complexity:** Training is parallelized across submodules, reducing wall-clock time. Visibility partitioning reduces the trainset size per submodule by 10x compared to the aggregate trainset [S1]. Additional spatial data pruning reduces trainset sizes by a further factor of 2x [S1].
*   **Memory Complexity:** Memory usage is distributed across submodules. Each submodule only stores weights for its local region, reducing peak memory requirements compared to a single large NeRF [S1].
*   **Strengths:** Scalable to large-scale scenes (e.g., city blocks); reduces training time and memory footprint; handles lighting variations via appearance embeddings [S1].
*   **Limitations:** Requires careful tuning of the overlap factor; geometric pruning adds complexity; fixed-height centroids may not suit scenes with large vertical variations [S1].
*   **When to Use:** Large-scale outdoor scenes with significant horizontal extent and small vertical variance; when training time and memory are bottlenecks.
*   **When Not to Use:** Scenes with large vertical extent; scenes where high-frequency details require dense sampling that sparse partitioning might miss.

## Background
Mega-NeRF was introduced in 2022 by [S1] to address the scalability issues of NeRF for large-scale virtual fly-throughs. It builds on the principles of spatial partitioning and parallel training, extending them to handle scenes at the scale of city blocks. The method was developed to overcome the memory and time limitations of monolithic NeRFs, enabling the reconstruction of large-scale environments with high fidelity.
