# ProNeRF

Also called: ProNeRF-12, ProNeRF-32, ProNeRF-8, Projection-Aware Ray Sampling for Fine-Grained Implicit Neural Radiance Fields

## Overview
ProNeRF is a sparse sampling method for neural radiance fields that uses a Projection-Aware Sampling (PAS) network to predict a small number of high-density 3D points along a ray, enabling high-quality rendering with significantly fewer samples than standard NeRF [S1]. It distinguishes itself from generalizable radiance fields (e.g., IBRNet, NeuRay) by using a fixed, small subset of reference views for color-to-ray projection rather than storing all training images, and from other sparse methods (e.g., HyperReel) by achieving higher PSNR through an alternating exploration-exploitation training strategy [S1].

## How it works
ProNeRF computes a radiance field function $f_\theta(\mathbf{x}, \mathbf{d})$ via a shading network $F_{\theta_s}$, but determines the sampling points $\mathbf{x}_i$ using a PAS network composed of two MLP heads, $F_{\theta_c}$ (coarse) and $F_{\theta_f}$ (fine), guided by color-to-ray projections from reference views [S1].

### Inputs and Outputs
*   **Input:** Ray $\mathbf{r} = (\mathbf{r}_o, \mathbf{r}_d)$ defined by origin $\mathbf{r}_o$ and direction $\mathbf{r}_d$, near/far bounds $t_n, t_f$, and a fixed set of $N_n$ neighboring reference view colors.
*   **Output:** Rendered color $\hat{\mathbf{c}}(\mathbf{r})$ using $N_s$ samples (typically 8, 12, or 32).

### Data Structures and Layout
The method uses three neural network components, all implemented as Multi-Layer Perceptrons (MLPs) with ELU activations [S1]:
1.  **Coarse MLP ($F_{\theta_c}$):** 6 fully connected layers, 256 neurons each. Inputs: Plücker ray-point encoding. Outputs: Coarse distances $T'$, opacity shifts/scales $A_t, B_t$, coarse color $\hat{\mathbf{c}}_c$, and auxiliary weights.
2.  **Fine MLP ($F_{\theta_f}$):** 6 fully connected layers, 256 neurons each. Inputs: Refined ray features and aggregated projection colors. Outputs: Refinement weights $\Delta_T$, aggregation weights $W$ (softmax), and mixture weights $M$ (sigmoid).
3.  **Shading Network ($F_{\theta_s}$):** 8 fully connected layers, 256 neurons each (based on DoNeRF [S1]). Inputs: 3D point coordinates. Outputs: Density $\sigma$ and color $\mathbf{c}$.
4.  **Pruning MLP ($F_{\theta_m}$):** (Optional, for ProNeRF-8 prune) Same complexity as $F_{\theta_c}$. Outputs: Error prediction between fast and full rendering.

**Plücker Ray-Point Encoding:**
To encode the ray, $N_{pr}$ points are sampled evenly between $t_n$ and $t_f$ to form a vector $\mathbf{t}_{nf}$. The Plücker representation $\mathbf{r}_{pr}$ is calculated as [S1]:
$$
\mathbf{r}_{pr} = [\mathbf{r}_d, \mathbf{r}_o + \mathbf{r}_d \odot \mathbf{t}_{nf}, (\mathbf{r}_o + \mathbf{r}_d \odot \mathbf{t}_{nf}) \odot \mathbf{r}_d]
$$
where $\odot$ is the Hadamard product. $N_{pr}=48$ is used in the reference implementation [S1].

### Numbered Steps

1.  **Coarse Sampling:**
    Compute $\mathbf{r}_{pr}$ for the target ray. Pass $\mathbf{r}_{pr}$ to $F_{\theta_c}$ to obtain coarse distances $T' = \{t'_1, \dots, t'_{N_s}\}$, opacity adjustments $A_t, B_t$, and coarse color $\hat{\mathbf{c}}_c$ [S1].

2.  **Color-to-Ray Projection:**
    For each coarse point $p_i = \mathbf{r}(t'_i)$, trace lines from $p_i$ to the camera centers of $N_n$ neighboring reference views. Collect the colors at the intersection of these lines with the reference image planes. This yields a set of projected colors $\mathbf{f}_{p_i} = [c^1_{p_i}, \dots, c^{N_n}_{p_i}]$ for each $i$ [S1].

3.  **Refinement:**
    Construct an expanded set $\dot{T} = \{t_n, t'_1, \dots, t'_{N_s}, t_f\}$. Pass the refined ray features and the aggregated projection colors $\{\mathbf{f}_{p_1}, \dots, \mathbf{f}_{p_{N_s}}\}$ to $F_{\theta_f}$ to obtain refinement weights $\Delta_T$, softmax weights $W$, and sigmoid weights $M$ [S1].
    Compute the final refined distances $T = \{t_1, \dots, t_{N_s}\}$ using linear interpolation between consecutive elements of $\dot{T}$ adjusted by $\Delta_T$:
    $$
    t_i = \frac{1}{2} \left( (\dot{T}_i + \dot{T}_{i+1}) + \Delta_{T_i}(\dot{T}_{i+2} - \dot{T}_i) \right), \quad i=1,\dots,N_s
    $$
    where indices are handled appropriately for boundaries [S1].

4.  **Fast Rendering (AVR) / Auxiliary Output:**
    Compute the Approximated Volumetric Rendering (AVR) color $\hat{\mathbf{c}}_f$ using the projected colors and weights $W, M$:
    $$
    \hat{\mathbf{c}}_f = \sum_{k=1}^{N_n} M_k \left( \sum_{i=1}^{N_s} W_i c^k_{p_i} \right)
    $$
    This provides a fast, projection-aware color estimate without querying the shading network [S1].

5.  **Shading and Final Rendering:**
    Query the shading network $F_{\theta_s}$ at the refined points $\mathbf{x}_i = \mathbf{r}(t_i)$ to get $(\sigma_i, \mathbf{c}_i)$ [S1].
    Compute opacities $\alpha_i$ using the adjusted formula:
    $$
    \alpha_i = 1 - \exp\left( -(\sigma_i + A_{t_i}) (t_{i+1} - t_i) \cdot B_{t_i} \right)
    $$
    where $t_{N_s+1}$ is typically $t_f$ or handled via the last interval [S1].
    Render the final color $\hat{\mathbf{c}}(\mathbf{r})$ via alpha compositing:
    $$
    \hat{\mathbf{c}}(\mathbf{r}) = \sum_{i=1}^{N_s} \left( \prod_{j=1}^{i-1} (1 - \alpha_j) \right) \alpha_i \mathbf{c}_i
    $$
    [S1].

6.  **Pruning (Optional, ProNeRF-8 prune):**
    During inference, query $F_{\theta_m}$ to predict the error between $\hat{\mathbf{c}}_f$ and the full $\hat{\mathbf{c}}(\mathbf{r})$. If the predicted error is below a threshold, return $\hat{\mathbf{c}}_f$ (AVR). Otherwise, return $\hat{\mathbf{c}}(\mathbf{r})$ [S1].

### Parameters
*   **$N_s$ (Samples):** 8, 12, or 32. ProNeRF-8 is >20x faster than NeRF; ProNeRF-12 is ~15x faster [S1].
*   **$N_n$ (Reference Views):** A small fixed subset (e.g., 4) of the total training views $N_t$ [S1].
*   **$N_{pr}$ (Plücker Points):** 48 [S1].
*   **$N$ (Max Exploration Samples):** 64 [S1].
*   **Learning Rate:** $5 \times 10^{-4}$, exponentially decayed over $7 \times 10^5$ iterations [S1].
*   **Batch Size:** 4,096 rays [S1].
*   **Auxiliary Loss Weight ($\lambda$):** 1 for the first 60% of iterations ($4 \times 10^5$), then 0 [S1].
*   **Memory Overhead (Pruning):** 3.3 MB [S1].

### Edge Cases and Pitfalls
*   **Precision:** The method uses FP16 for testing on RTX 3090, but training stability relies on the alternating pass strategy [S1].
*   **Boundary Conditions:** The refinement formula uses $t_n$ and $t_f$ explicitly in $\dot{T}$. Care must be taken with the last interval for opacity calculation if $t_{N_s+1}$ is not $t_f$ [S1].
*   **Degenerate Input:** If reference views are not calibrated or aligned, color-to-ray projections will fail. The method assumes calibrated multi-view inputs [S1].

## Operating characteristics
*   **Speed:** ProNeRF is 15-23× faster than vanilla NeRF [S1]. ProNeRF-8 prune is 23% faster than standard ProNeRF-8 [S1].
*   **Quality:** ProNeRF-12 achieves 0.65 dB higher PSNR than NeRF on LLFF. ProNeRF-8 achieves 0.28 dB higher PSNR than NeRF [S1]. It outperforms HyperReel by 0.95 dB PSNR [S1].
*   **Memory:** Similar to NeRF (~3.8 MB for NeRF, ProNeRF-32 is 6.3 MB) [S1]. Pruning adds 3.3 MB [S1].
*   **Strengths:** High quality with very few samples; consistent memory footprint regardless of scene size (fixed reference views); fast inference.
*   **Limitations:** Requires calibrated multi-view input; training is complex due to alternating passes and auxiliary losses; performance depends on the quality of the fixed reference view subset [S1].
*   **When to use:** When rendering speed is critical and high-quality results are needed with limited samples, and calibrated multi-view data is available.
*   **When not to use:** For uncalibrated or sparse view scenarios where generalizable methods (like IBRNet) might be more robust, or if memory is extremely constrained and pruning overhead is unacceptable.

## Background
ProNeRF was proposed in 2024 by the authors of the paper "ProNeRF: Learning Efficient Projection-Aware Ray Sampling for Fine-Grained Implicit Neural Radiance Fields" [S1]. It addresses the trade-off between memory, speed, and quality in neural rendering, aiming to outperform sampler-based methods like HyperReel and grid-based methods like K-Planes [S1]. It builds on the principles of sparse and efficient representations [Parent].
