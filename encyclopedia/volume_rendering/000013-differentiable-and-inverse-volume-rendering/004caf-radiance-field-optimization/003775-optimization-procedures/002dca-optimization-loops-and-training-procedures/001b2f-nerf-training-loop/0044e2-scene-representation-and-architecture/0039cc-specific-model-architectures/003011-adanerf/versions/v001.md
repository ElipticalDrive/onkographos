# AdaNeRF

Also called: AdaNeRF: Adaptive Sampling for Real-time Rendering of Neural Radiance Fields

## Overview
AdaNeRF is a method for accelerating Neural Radiance Fields (NeRF) to achieve real-time rendering by reducing the number of sample points per ray [S2, unofficial]. It employs fixed sample positions along each ray and incrementally introduces sparsity during training to create a compact neural representation [S1]. It sets itself apart from standard NeRF by splitting the network into a lightweight Sampling Network and a heavier Shading Network, where the former predicts sample importance weights in a single evaluation [S1].

## How it works
**Inputs:** Pre-trained NeRF weights (optional initialization), camera parameters, training images.
**Outputs:** Trained Sampling Network and Shading Network weights.

**Data Structures:**
1.  **Sampling Network:** A lightweight Multi-Layer Perceptron (MLP).
2.  **Shading Network:** A heavier MLP (standard NeRF architecture) processing color and density.
3.  **Fixed Sample Positions:** A set of $N$ fixed 3D coordinates along each ray.

**Steps:**
1.  **Initialization:** Start with a pre-trained standard NeRF model to initialize the color network, which improves quality in geometrically ambiguous regions [S1].
2.  **Network Split:** Decompose the model into two parts:
    *   The **Sampling Network** predicts importance weights for all fixed sample points on a line in one go [S1][S2, unofficial].
    *   The **Shading Network** processes only the most significant samples identified by the Sampling Network [S1].
3.  **Joint Training:** Train both networks jointly. The Sampling Network learns to localize surfaces and predict weights without requiring depth maps [S1].
4.  **Sparsity Introduction:** Incrementally introduce sparsity during training [S1].
5.  **Fine-tuning:** Fine-tune the model to the desired number of samples to create a compact neural representation [S1].
6.  **Rendering:** Use the compact representation for real-time rendering [S1].

**Pseudocode:**
```python
# AdaNeRF Training Step
def adanerf_step(camera_params, image, sampling_net, shading_net, fixed_positions):
    # 1. Generate ray for each pixel
    rays = generate_rays(camera_params)
    
    # 2. Evaluate Sampling Network once per ray to get weights for all fixed positions
    # fixed_positions: [N, 3] coordinates along the ray
    # sampling_net: lightweight MLP
    weights = sampling_net(fixed_positions) # Predicts importance weights for all points
    
    # 3. Select significant samples based on weights
    # Threshold or top-k selection to identify significant samples
    significant_indices = select_significant_samples(weights, threshold=0.1)
    significant_positions = fixed_positions[significant_indices]
    
    # 4. Evaluate Shading Network only on significant samples
    # shading_net: heavier MLP
    densities, colors = shading_net(significant_positions)
    
    # 5. Compute loss
    # Rendered color is computed using the significant samples and their weights
    rendered_color = render_ray(significant_positions, densities, colors, weights[significant_indices])
    loss = compute_loss(rendered_color, image)
    
    # 6. Backpropagate to both networks
    update_parameters(sampling_net, shading_net, loss)
```

**Edge Cases:**
*   **Geometric Ambiguity:** Without a pre-trained NeRF initialization, quality may suffer in ambiguous regions [S1].
*   **Sparsity Tuning:** The method is adaptable and can be fine-tuned to meet specific performance targets [S1].

## Operating characteristics
*   **Performance:** Enables real-time rendering [S1].
*   **Complexity:** Reduces rendering cost by lowering the number of sample points [S2, unofficial].
*   **Limitations:** Requires a pre-trained NeRF for best results in some configurations [S1].

## Background
AdaNeRF was introduced by Kurz et al. in 2022 [S1][S2, unofficial]. It is part of the broader effort to accelerate neural fields by baking or simplifying the sampling process [S1].
