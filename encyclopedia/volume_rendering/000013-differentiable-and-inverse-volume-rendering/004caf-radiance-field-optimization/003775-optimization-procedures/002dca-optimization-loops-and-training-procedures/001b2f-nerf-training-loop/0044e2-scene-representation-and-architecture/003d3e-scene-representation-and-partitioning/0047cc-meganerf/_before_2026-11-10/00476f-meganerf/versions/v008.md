# MegaNeRF

Also called: Mega-NeRF

## Overview
MegaNeRF is a framework for training large-scale 3D scenes that support interactive human-in-the-loop fly-throughs, addressing challenges of modeling thousands of images with varying lighting, large model capacities, and fast rendering [S1, S2]. It solves the infeasibility of training a single global NeRF on urban-scale datasets by decomposing the scene into spatial cells, each represented by a separate NeRF submodule [S1, S3]. Unlike DeRF and KiloNeRF, which use spatial partitioning to speed up inference of a pre-trained single network, MegaNeRF uses spatial partitioning to enable data parallelism for scalable training, as obtaining a pre-trained NeRF for large scales is infeasible [S1]. It achieves a 40x speedup over conventional NeRF rendering while remaining within 0.8 dB in PSNR quality [S1, S5].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A large set of training images (e.g., drone footage) with camera poses, intrinsics, and optionally altitude measurements.
*   **Outputs:** A collection of NeRF submodules (MLPs), one for each spatial cell, and an octree cache for rendering acceleration.

**Data Structures:**
1.  **Spatial Cells:** The scene is partitioned using spatial Voronoi partitioning into a set of cells [S1]. Each cell has a centroid $(x, y, z)$ and a radius. The height of the centroids is fixed to the same value if the altitude variation between camera poses is small relative to latitude/longitude differences [S1].
2.  **NeRF Submodules:** Each cell is associated with a small Multi-Layer Perceptron (MLP) network [S1, S3]. These MLPs take 3D coordinates and viewing directions as input and output density $\sigma$ and color $\mathbf{c}$.
3.  **Pixel Partition Map:** A mapping from each training pixel to the set of spatial cells whose volume intersects the ray corresponding to that pixel [S1].
4.  **Octree Cache:** A coarse rendering of densities and colors cached into an octree structure to accelerate rendering [S2].

**Method Steps:**

1.  **Foreground/Background Decomposition:**
    The scene is subdivided into a foreground volume enclosing all camera poses and a background volume for the complement [S1, S2].
    *   **Foreground:** Modeled using an ellipsoid that tightly encloses camera poses and relevant detail, replacing NeRF++'s unit sphere [S1, S2]. The ellipsoid parameterization extends NeRF++'s inverse sphere parameterization to better fit the aerial point of view [S2].
    *   **Background:** Uses the same 4D outer volume parameterization and raycasting formulation as NeRF++ [S1].
    *   **Altitude Constraint:** Camera altitude measurements are used to constrain ray sampling bounds, terminating rays near ground level to avoid querying underground regions [S1, S2].

2.  **Data Partitioning (Training):**
    *   For each training image, sample points along the camera ray corresponding to each pixel [S1].
    *   Identify which spatial cells these sampled points intersect [S1].
    *   Assign the pixel to the training set of only those intersecting cells [S1]. This geometric clustering algorithm reduces the size of each submodule’s trainset by approximately 10x [S1].
    *   Incorporate per-image appearance embedding codes from NeRF-W to handle varying lighting conditions [S2].

3.  **Parallel Training:**
    *   Train each NeRF submodule independently and in parallel using its partitioned pixel data [S1, S2].
    *   Each module is trained only on images with potentially relevant pixels [S2].

4.  **Rendering (Inference):**
    *   **Standard Raycasting:** For a new view, cast rays and sample points. For each sampled point, query the encompassing submodule (the cell containing the point) to get $\sigma$ and $\mathbf{c}$ [S1].
    *   **Temporal Coherence:** To ensure near-interactive view generation, cache occupancy and color values from nearby previous views [S1].
    *   **Octree Acceleration:** Cache a coarse rendering of densities and colors into an octree for faster rendering [S2].

import numpy as np

def train_mega_nerf(training_images, cell_centroids, cell_radii):
    """
    Training phase for MegaNeRF.
    
    Args:
        training_images: List of dicts with keys 'image', 'camera_pose', 'camera_intrinsics', 'altitude'.
        cell_centroids: Array of shape (N, 3) containing the (x, y, z) of N cell centers.
        cell_radii: Array of shape (N,) containing the radius of each cell.
        
    Returns:
        submodules: List of trained NeRF MLPs, one per cell.
    """
    N = len(cell_centroids)
    submodules = [init_nerf_mlp() for _ in range(N)]
    
    # Step 1: Partition pixels to cells
    # Initialize training sets for each cell
    cell_train_sets = [[] for _ in range(N)]
    
    for img in training_images:
        rays = generate_rays(img['camera_pose'], img['camera_intrinsics'], img['image'].shape)
        for pixel_idx, ray in enumerate(rays):
            # Sample points along the ray within the scene bounds
            # Bounds are constrained by altitude to avoid underground sampling
            t_min, t_max = get_ray_bounds(ray, img['altitude'])
            samples = sample_along_ray(ray, t_min, t_max, num_samples=128)
            
            # Find intersecting cells for these samples
            intersecting_cells = set()
            for sample in samples:
                for i, (centroid, radius) in enumerate(zip(cell_centroids, cell_radii)):
                    if np.linalg.norm(sample - centroid) < radius:
                        intersecting_cells.add(i)
            
            # Add pixel to the trainset of intersecting cells
            for cell_idx in intersecting_cells:
                cell_train_sets[cell_idx].append((img, pixel_idx))
                
    # Step 2: Train each submodule in parallel
    # In practice, this would be distributed across GPUs
    for i in range(N):
        train_set = cell_train_sets[i]
        # Incorporate per-image appearance embedding from NeRF-W
        # This requires extracting appearance codes for each image in the train set
        appearance_codes = get_appearance_codes([ts[0] for ts in train_set])
        
        # Train the MLP for this cell
        # Loss is computed against the ground truth colors of the assigned pixels
        submodules[i] = train_nerf_module(
            module=submodules[i],
            data=train_set,
            appearance_codes=appearance_codes,
            cell_centroid=cell_centroids[i],
            cell_radius=cell_radii[i]
        )
        
    return submodules

def render_mega_nerf(camera_pose, camera_intrinsics, submodules, cell_centroids, cell_radii, octree_cache=None):
    """
    Rendering phase for MegaNeRF.
    
    Args:
        camera_pose: Camera extrinsic matrix.
        camera_intrinsics: Camera intrinsic matrix.
        submodules: List of trained NeRF MLPs.
        cell_centroids: Array of cell centers.
        cell_radii: Array of cell radii.
        octree_cache: Optional octree for caching coarse densities/colors.
        
    Returns:
        image: Rendered image.
    """
    rays = generate_rays(camera_pose, camera_intrinsics)
    image = np.zeros(rays.shape[:2])
    
    for y in range(image.shape[0]):
        for x in range(image.shape[1]):
            ray = rays[y, x]
            t_min, t_max = get_ray_bounds(ray, altitude=0) # Altitude constraint applied
            
            # Sample points along the ray
            samples = sample_along_ray(ray, t_min, t_max, num_samples=128)
            
            # Query submodules and accumulate transmittance and color
            # Using the standard volume rendering integral
            T = 1.0
            color = np.zeros(3)
            
            for sample in samples:
                # Find the cell containing this sample
                cell_idx = find_containing_cell(sample, cell_centroids, cell_radii)
                
                if cell_idx is not None:
                    # Query the specific submodule for this cell
                    # Input: sample position, viewing direction, and appearance code if needed
                    sigma, c = submodules[cell_idx].forward(sample, ray.direction)
                    
                    # Volume rendering step
                    alpha = 1.0 - np.exp(-sigma * ray.step_size)
                    transmittance = T
                    T = T * (1.0 - alpha)
                    color += transmittance * alpha * c
                else:
                    # If not in any cell (e.g., background or underground), handle appropriately
                    # For background, use the background module or 0 if outside bounds
                    pass
                    
            image[y, x] = color
            
    return image

**Parameters:**
*   **Cell Partitioning:** Spatial Voronoi partitioning [S1].
*   **Foreground Shape:** Ellipsoid [S1, S2].
*   **Background Parameterization:** NeRF++ 4D outer volume [S1].
*   **Appearance Embedding:** NeRF-W per-image codes [S2].
*   **Rendering Cache:** Octree [S2].

**Edge Cases and Pitfalls:**
*   **Underground Sampling:** Rays may query underground regions if not constrained by altitude. Mitigated by using camera altitude measurements to terminate rays near ground level [S1, S2].
*   **Cell Boundary Discontinuities:** Since each cell has its own MLP, discontinuities may occur at cell boundaries. The sources do not explicitly detail a blending mechanism, but mention "seamless integration" in the context of Block-NeRF [S5], which is a sibling method. MegaNeRF relies on the spatial separation and visibility partitioning to minimize visible seams [S1].
*   **Visibility Partitioning:** If a pixel's ray does not intersect any cell, it is not assigned to any submodule's training set [S1]. This reduces training data size but requires careful handling during inference if a ray falls outside all cell bounds.

## Operating characteristics
*   **Time Complexity:** Training is data parallel, allowing submodules to be trained simultaneously [S1]. This improves training speed by 3x compared to baseline approaches [S1].
*   **Memory Complexity:** Each submodule is smaller than a global NeRF, reducing memory requirements per GPU [S1].
*   **Rendering Speed:** Achieves a 40x speedup over conventional NeRF rendering [S1, S5].
*   **Quality:** Remains within 0.8 dB in PSNR quality compared to conventional NeRF [S1, S5]. Improves PSNR by 12% compared to baseline approaches on existing datasets [S1].
*   **Scalability:** Decouples rendering time from scene size, allowing rendering to scale to arbitrarily large environments [S5].
*   **Strengths:** Enables training on massive urban scenes (150,000 to over 1,300,000 m²) [S1]. Supports interactive fly-throughs [S1].
*   **Limitations:** Requires geometric clustering and visibility partitioning preprocessing [S1]. Discontinuities at cell boundaries may be visible if not handled [S5, implied].

## Background
MegaNeRF was introduced in 2022 by Tancik et al. in the paper "Mega-NeRF: Scalable Construction of Large-Scale NeRFs for Virtual Fly-Throughs" [S1]. It was motivated by the need for search-and-rescue applications where drones provide inexpensive means of quickly surveying large areas [S1]. The method builds on NeRF++ for foreground/background decomposition and NeRF-W for appearance embedding [S1, S2]. It is a sibling to Block-NeRF, which uses a similar divide-and-conquer strategy but was introduced slightly later [S3, S5].
