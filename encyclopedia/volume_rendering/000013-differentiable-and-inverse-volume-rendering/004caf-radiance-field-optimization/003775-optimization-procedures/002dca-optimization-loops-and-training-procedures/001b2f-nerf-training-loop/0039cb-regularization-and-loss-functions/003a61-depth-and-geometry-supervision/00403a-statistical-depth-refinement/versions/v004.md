# Statistical Depth Refinement

Also called: Corrupt Depth Patching, Underfitting Depth Smoothing

## Overview
Statistical Depth Refinement is a post-processing step applied during the training of radiance fields to mitigate the impact of corrupt stereo depth data caused by fuzzy pixels and specular highlights [S1]. It prevents the model from overfitting to these erroneous depth values, which would otherwise lead to abrupt geometric artifacts in the reconstruction [S1]. Unlike direct depth supervision, this method leverages the smoothing properties of an underfitting model to identify and replace corrupt depth pixels with statistically smoother alternatives [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   $D_i$: The initial stereo depth map for the $i$-th frame [S1].
    *   $D_b^K_i$: The depth map rendered from the radiance field after $K$ iterations of training (the "underfitting" output) [S1].
    *   $\alpha$: A threshold parameter representing the quantile for identifying corrupt pixels [S1].
*   **Outputs:**
    *   $\tilde{D}_i$: The patched depth map used for subsequent optimization [S1].

**Data Structures:**
*   Depth maps are represented as 2D arrays of floating-point values, where each element corresponds to the depth $t$ along the ray for a specific pixel $(u, v)$ [S1].
*   Residual maps are 2D arrays of the same dimensions, storing the absolute difference between the stereo depth and the model's current depth estimate [S1].

**Parameters:**
*   $K$: The number of training iterations after which the underfitting depth map is sampled. The typical value is 4000 [S1].
*   $\alpha$: The quantile threshold for identifying corrupt pixels. The typical value is 0.1 [S1].
*   $\lambda$: The weight for the depth loss term in the total loss function. The typical value is 1 [S1].

**Steps:**
1.  **Train to Underfitting State:** Train the radiance field for $K$ iterations. At this stage, the model has not fully converged and tends to average learned colors and occupancy, resulting in smoother depth estimates [S1].
2.  **Compute Residuals:** Calculate the residual map $R_i$ between the underfitting depth $D_b^K_i$ and the stereo depth $D_i$:
    $$ R_i[u, v] = |D_b^K_i[u, v] - D_i[u, v]| $$
    where $(u, v)$ is the pixel location [S1].
3.  **Identify Corrupt Pixels:** Compute the probabilistic distribution of the residual values in $R_i$. Identify pixels with residuals in the top $\alpha$-quantile (i.e., the largest $\alpha \times 100\%$ of residuals) [S1]. These pixels are statistically identified as corrupt depth [S1].
4.  **Patch Depth:** Replace the depth values of the identified corrupt pixels in the stereo depth map $D_i$ with the corresponding smoother values from the underfitting depth map $D_b^K_i$. Let the resulting patched depth map be $\tilde{D}_i$ [S1].
5.  **Resume Optimization:** Use the patched depth map $\tilde{D}_i$ for depth supervision in subsequent training iterations [S1].

**Pseudocode:**
```python
def statistical_depth_refinement(stereo_depth: Tensor, model: RadianceField, K: int, alpha: float) -> Tensor:
    """
    Refines stereo depth by patching corrupt pixels with underfitting model output.
    
    Args:
        stereo_depth: The initial stereo depth map D_i [H, W].
        model: The radiance field model.
        K: Number of iterations to train before sampling underfitting depth.
        alpha: Quantile threshold for identifying corrupt pixels.
        
    Returns:
        patched_depth: The refined depth map.
    """
    # Step 1: Train to underfitting state
    # Note: This assumes the model is trained for K iterations.
    # In practice, this might involve a separate training loop or checkpoint.
    model.train_for_iterations(K)
    
    # Step 2: Obtain underfitting depth map
    # Render depth map from the model for the same camera pose as stereo_depth
    underfitting_depth = model.render_depth(stereo_depth.camera_pose)
    
    # Step 3: Compute residual map
    residual_map = torch.abs(underfitting_depth - stereo_depth)
    
    # Step 4: Identify corrupt pixels based on alpha quantile
    # Find the threshold value corresponding to the top alpha quantile
    threshold = torch.quantile(residual_map, 1 - alpha)
    
    # Create a mask for pixels with residual >= threshold
    corrupt_mask = residual_map >= threshold
    
    # Step 5: Patch depth
    # Replace corrupt pixels in stereo_depth with values from underfitting_depth
    patched_depth = torch.where(corrupt_mask, underfitting_depth, stereo_depth)
    
    return patched_depth
```

**Edge Cases and Pitfalls:**
*   **Precision:** The method relies on the statistical significance of residuals. If the stereo depth is uniformly corrupt, the method may fail to identify specific outliers [S1].
*   **Boundaries:** The method assumes that the underfitting model provides a "smoother" but still geometrically plausible estimate. If the model is too far from convergence, the underfitting depth may be inaccurate [S1].
*   **Degenerate Input:** If the stereo depth is missing or invalid for a large portion of the image, the residual computation may be unreliable [S1].

## Subtopics

### Perceptual Distillation
Perceptual Distillation is a technique that transfers deblurred texture information from pre-deblurred images to the NeRF using perceptual loss on rendered patches [S2]. It overcomes the geometric inconsistency of pre-deblurred images by not using them as direct pixel-wise color supervision [S2]. Instead, it uses an off-the-shelf deep learning-based image deblurring network to generate pre-deblurred images from blurred inputs [S2]. It then renders color patches $\hat{C}_{ptc}$ from the NeRF using patch-wise sampled rays $r_{ptc}^{pd}$ at the same pixel locations as the pre-deblurred color patches $\bar{C}_{ptc}$ [S2]. Perceptual loss is applied by extracting features from both the pre-deblurred color patch and the rendered color patch using a shared pre-trained image feature extractor [S2]. A key pitfall is that pre-deblurred images cannot be used as direct pixel-wise color supervision due to the lack of 3D consistency caused by the ill-posed property of image deblurring and independent processing across multi-view images [S2].

## Operating characteristics
*   **Time Complexity:** The method adds a one-time cost of training the model for $K$ iterations and rendering a depth map. The patching operation is $O(H \times W)$, where $H$ and $W$ are the image dimensions [S1].
*   **Memory Complexity:** Requires storing the stereo depth map, the underfitting depth map, and the residual map, all of size $O(H \times W)$ [S1].
*   **Measured Performance:** Evaluated on robotic surgery stereo videos with 807 frames across 6 cases [S1]. The method improves PSNR, SSIM, and LPIPS metrics compared to direct depth supervision [S1].
*   **Strengths:** Effectively handles corrupt depth caused by fuzzy pixels and specular highlights [S1]. Prevents overfitting to corrupt depth [S1].
*   **Limitations:** Requires a separate training phase to obtain the underfitting depth map [S1]. The quality of the refinement depends on the choice of $K$ and $\alpha$ [S1].
*   **When to Use:** When stereo depth data is noisy or contains artifacts due to specular highlights or motion blur [S1].
*   **When Not to Use:** When the stereo depth is accurate and reliable [S1].

## Background
Statistical Depth Refinement was proposed in the context of neural rendering for stereo 3D reconstruction of deformable tissues in robotic surgery [S1]. The method addresses the challenge of reconstructing scenes with non-rigid deformation and tool occlusion, where standard stereo depth estimation can produce errors [S1]. The authors observed that underfitting models tend to produce smoother depth estimates, which can be used to identify and correct corrupt depth pixels [S1]. The method was evaluated on in-house DaVinci robotic prostatectomy data [S1].
