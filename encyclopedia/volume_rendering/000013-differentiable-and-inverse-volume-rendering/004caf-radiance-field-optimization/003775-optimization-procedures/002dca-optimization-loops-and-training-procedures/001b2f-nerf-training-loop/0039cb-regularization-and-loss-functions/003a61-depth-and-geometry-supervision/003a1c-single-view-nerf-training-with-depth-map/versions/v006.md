# Single-view NeRF Training with Depth Map

Also called: Depth-guided Single-view NeRF, Single-view NeRF with Depth Initialization

## Overview
This method addresses the under-constrained optimization problem of reconstructing a 360-degree scene from a single input panorama by initializing the geometry of visible regions using monocular depth estimation [S1]. It differs from [Depth-Supervised NeRF](8687-depth-supervised-nerf.md) by specifically handling the scale ambiguity and field-of-view limitations of monocular estimators through a deformable alignment step to a canonical panorama depth map before NeRF training, and from [Guided Optimization of NeRF](7496-guided-optimization-of-nerf.md) by focusing on single-view panoramic reconstruction rather than multi-view consistency or object removal [S1].

## How it works
**Inputs:** A single input RGB panorama $I_{\text{rgb}}$.
**Outputs:** A trained NeRF model $f_{\text{nerf}}$ representing the visible regions of the scene.

**Data Structures:**
1.  **Perspective Projections:** A set of $K$ perspective images $\{\bar{I}_{\text{rgb}}^k\}_{k=1}^K$ and their corresponding estimated depth maps $\{\bar{I}_d^k\}_{k=1}^K$.
2.  **Canonical Panorama Depth Map:** A learnable depth map $I_d$ aligned with $I_{\text{rgb}}$.
3.  **Alignment Parameters:** For each perspective view $k$, a global scale factor $w_k$ and a local bias field $\{b_{k,i,j}\}$, where $i,j$ are pixel coordinates.

**Parameters:**
*   $K$: Number of perspective projections. Default value is 20 [S1].

**Steps:**

1.  **Perspective Projection:** Project the single input panorama $I_{\text{rgb}}$ into $K$ perspective images $\{\bar{I}_{\text{rgb}}^k\}_{k=1}^K$ using different viewing directions [S1].
2.  **Monocular Depth Estimation:** Apply a monocular depth estimation model [52] to each perspective image $\bar{I}_{\text{rgb}}^k$ to obtain depth maps $\{\bar{I}_d^k\}_{k=1}^K$. Note that due to scale ambiguity, depth values in overlapping regions may differ significantly [S1].
3.  **Deformable Alignment:** Align the perspective depth maps $\{\bar{I}_d^k\}$ to a canonical learnable panorama depth map $I_d$ by optimizing the following objective:
    $$ \sum_{k,i,j} ||\bar{v}_{i,j}^k w_k + b_{k,i,j} - v_{M(i,j)}|| + L_s(b_{i,j+1}, b_{i,j}) + L_s(b_{i+1,j}, b_{i,j}) $$
    where:
    *   $\bar{v}_{i,j}^k$ is the pixel value at $(i,j)$ in perspective depth map $\bar{I}_d^k$.
    *   $v_{M(i,j)}$ is the pixel value at the corresponding coordinate in the canonical panorama depth map $I_d$, where $M$ maps perspective image coordinates to panorama image coordinates.
    *   $L_s$ is the smooth L1 loss (Total Variation regularization) [S1].
    *   The optimization jointly learns the scale $w_k$ and local biases $b_{k,i,j}$ for each view [S1].
4.  **NeRF Training:** Train the NeRF using the RGB panorama $I_{\text{rgb}}$ and the aligned depth map $I_d$ by minimizing the combined loss $\mathcal{L}_{\text{nerf}}'$:
    $$ \mathcal{L}_{\text{nerf}}' = \sum_{r \in R} \left( ||\hat{C}(r) - C(r)||^2 + ||\hat{D}(r) - \bar{D}(r)||^2 \right) $$
    where:
    *   $R$ is the set of rays sampled from the panorama.
    *   $\hat{C}(r)$ is the expected pixel color rendered by the NeRF.
    *   $C(r)$ is the ground-truth pixel color from $I_{\text{rgb}}$.
    *   $\hat{D}(r)$ is the expected depth value rendered by the NeRF.
    *   $\bar{D}(r)$ is the corresponding depth pixel value computed from the aligned depth map $I_d$ [S1].
