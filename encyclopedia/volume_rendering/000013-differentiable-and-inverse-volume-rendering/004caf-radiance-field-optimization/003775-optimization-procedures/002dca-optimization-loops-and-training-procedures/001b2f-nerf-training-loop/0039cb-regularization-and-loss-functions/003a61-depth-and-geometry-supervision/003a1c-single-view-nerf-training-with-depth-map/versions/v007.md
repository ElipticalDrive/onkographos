# Single-view NeRF Training with Depth Map

Also called: Depth-guided Single-view NeRF, Single-view NeRF with Depth Initialization

## Overview
This method addresses the under-constrained optimization problem of reconstructing a 3D scene from a single panoramic input by initializing the NeRF geometry using estimated depth maps. It sets itself apart from sibling methods like [Depth-Supervised NeRF](8687-depth-supervised-nerf.md) by explicitly performing a deformable alignment of multiple perspective depth estimates into a canonical panorama before training, rather than applying depth loss directly to raw estimates or using multi-view consistency. It builds on [Depth and Geometry Supervision](8727-depth-and-geometry-supervision.md) by providing a robust initialization strategy for visible regions.

## How it works
**Inputs:** A single input RGB panorama $I_{\text{rgb}}$.
**Outputs:** A trained NeRF model $f_{\text{nerf}}$ representing the geometry and appearance of visible regions.

**Data Structures:**
1.  **Perspective Projections:** A set of $K$ perspective images $\{\bar{I}_{\text{rgb}}^k\}_{k=1}^K$ and their corresponding estimated depth maps $\{\bar{I}_d^k\}_{k=1}^K$.
2.  **Canonical Panorama Depth Map:** A learnable depth map $I_d$ of the same resolution as $I_{\text{rgb}}$.
3.  **Alignment Parameters:** For each perspective view $k$, a global scale factor $w_k$ and a local bias field $\{b_{k,i,j}\}$ corresponding to pixel coordinates $(i,j)$.

**Numbered Steps:**

1.  **Perspective Projection:** Project the single input panorama $I_{\text{rgb}}$ into $K$ perspective images $\{\bar{I}_{\text{rgb}}^k\}$ using different viewing directions. The standard value for $K$ is 20 [S1]. This is necessary because monocular depth estimators are typically trained on limited field-of-view images and fail on warped 360-degree panoramas [S1].

2.  **Monocular Depth Estimation:** Use a pre-trained depth estimation model (e.g., [52] in source) to estimate depth values for each perspective image $\bar{I}_{\text{rgb}}^k$, obtaining the set of depth maps $\{\bar{I}_d^k\}$ [S1]. Note that due to scale ambiguity in single-view depth estimation, depth values in overlapping regions between different perspective views may differ significantly [S1].

3.  **Deformable Alignment:** Align the perspective depth maps $\{\bar{I}_d^k\}$ to a canonical learnable panorama depth map $I_d$ by optimizing an alignment objective. This step resolves scale and bias inconsistencies across views [S1].
    *   **Alignment Objective:** Minimize the following loss with respect to $I_d$, $\{w_k\}$, and $\{b_{k,i,j}\}$:
        $$ \sum_{k,i,j} \left\| \bar{v}_{i,j}^k w_k + b_{k,i,j} - v_{M(i,j)} \right\| + \mathcal{L}_s(b_{i,j+1}, b_{i,j}) + \mathcal{L}_s(b_{i+1,j}, b_{i,j}) $$
        Where:
        *   $\bar{v}_{i,j}^k$ is the pixel value of depth map $\bar{I}_d^k$ at $(i,j)$.
        *   $v_{M(i,j)}$ is the pixel value of the canonical panorama depth map $I_d$ at the coordinate mapped from perspective view $k$ via projective operation $M$.
        *   $w_k$ is the scale factor for view $k$.
        *   $b_{k,i,j}$ is the local bias for pixel $(i,j)$ in view $k$.
        *   $\mathcal{L}_s$ is the smooth L1 loss, acting as a total variation regularizer on the bias field to ensure spatial smoothness [S1].

4.  **NeRF Training:** Train the single-view NeRF using the RGB panorama $I_{\text{rgb}}$ and the aligned canonical depth map $I_d$. The NeRF is optimized to minimize the combined color and depth reconstruction loss:
    $$ \mathcal{L}_{\text{nerf}}' = \sum_{r \in R} \left( \left\| \hat{\mathbf{C}}(r) - \mathbf{C}(r) \right\|^2 + \left\| \hat{D}(r) - \bar{D}(r) \right\|^2 \right) $$
    Where:
    *   $R$ is the set of rays sampled from the panorama.
    *   $\hat{\mathbf{C}}(r)$ is the expected pixel color rendered by the NeRF for ray $r$.
    *   $\mathbf{C}(r)$ is the ground-truth pixel color from $I_{\text{rgb}}$.
    *   $\hat{D}(r)$ is the expected depth value rendered by the NeRF for ray $r$.
    *   $\bar{D}(r)$ is the corresponding depth pixel value computed from the aligned depth map $I_d$ for ray $r$ [S1].

**Pseudocode:**

```python
def single_view_nerf_with_depth(panorama_rgb, depth_estimator, num_views=20):
    """
    Trains a single-view NeRF initialized with aligned depth maps.
    
    Args:
        panorama_rgb: Input RGB panorama image.
        depth_estimator: Pre-trained monocular depth estimation model.
        num_views: Number of perspective projections K (default 20).
        
    Returns:
        trained_nerf: The trained NeRF model.
    """
    
    # Step 1: Project panorama to K perspective images
    perspective_images = []
    for k in range(num_views):
        # Project panorama to perspective view k using specific direction
        img_k = project_panorama_to_perspective(panorama_rgb, direction=k)
        perspective_images.append(img_k)
        
    # Step 2: Estimate depth for each perspective image
    perspective_depth_maps = []
    for img_k in perspective_images:
        # Use depth estimator to get depth map
        d_k = depth_estimator.predict(img_k)
        perspective_depth_maps.append(d_k)
        
    # Step 3: Deformable Alignment
    # Initialize canonical panorama depth map I_d
    # Initialize scale factors w_k and bias fields b_k
    I_d = initialize_canonical_depth(panorama_rgb.shape)
    w = [1.0 for _ in range(num_views)]
    b = [[[0.0 for _ in range(panorama_rgb.shape[1])] 
          for _ in range(panorama_rgb.shape[0])] for _ in range(num_views)]
    
    # Optimize alignment objective
    # Loss = sum_k || v_bar_k * w_k + b_k - v_M || + TV(bias)
    for iteration in range(align_iterations):
        loss = 0.0
        for k in range(num_views):
            d_k = perspective_depth_maps[k]
            # Map coordinates from perspective k to panorama coordinates
            # M maps (i,j) in perspective k to (i',j') in panorama
            for i, j in coordinates_of_perspective_k(k):
                i_p, j_p = map_perspective_to_panorama(i, j, k)
                
                v_bar = d_k[i, j]
                v_pano = I_d[i_p, j_p]
                bias = b[k][i][j]
                scale = w[k]
                
                # Data alignment term (L1 or Smooth L1)
                diff = v_bar * scale + bias - v_pano
                loss += smooth_l1_loss(diff)
                
        # Total variation regularization on bias field
        for k in range(num_views):
            for i in range(height - 1):
                for j in range(width):
                    loss += smooth_l1_loss(b[k][i+1][j] - b[k][i][j])
            for i in range(height):
                for j in range(width - 1):
                    loss += smooth_l1_loss(b[k][i][j+1] - b[k][i][j])
                    
        # Update I_d, w, b using gradient descent
        update_parameters(I_d, w, b, loss)
        
    # Step 4: Train NeRF with aligned depth map
    # Initialize NeRF model
    nerf = initialize_nerf()
    
    for iteration in range(nerf_training_iterations):
        # Sample rays from panorama
        rays = sample_rays_from_panorama(panorama_rgb)
        
        total_loss = 0.0
        for r in rays:
            # Render color and depth from NeRF
            c_hat, d_hat = nerf.render(r)
            
            # Get ground truth color from panorama
            c_gt = get_pixel_color(panorama_rgb, r)
            
            # Get corresponding depth from aligned map I_d
            d_gt = get_depth_from_map(I_d, r)
            
            # Compute loss
            color_loss = mse(c_hat, c_gt)
            depth_loss = mse(d_hat, d_gt)
            loss = color_loss + depth_loss
            
            total_loss += loss
            
        # Update NeRF parameters
        update_nerf(nerf, total_loss)
        
    return nerf
```

**Parameters:**
*   $K$: Number of perspective projections. Typical value: 20 [S1].
*   $\lambda_k$: Not explicitly defined as separate weights in the NeRF loss equation in the source, but the depth loss is added directly to the color loss [S1].

**Edge Cases and Pitfalls:**
*   **Scale Ambiguity:** Monocular depth estimation suffers from scale ambiguity, leading to inconsistent depth values in overlapping regions of perspective views. The deformable alignment step is critical to resolve this [S1].
*   **Panorama Warping:** Standard monocular depth estimators fail on 360-degree panoramas warped into rectangular matrices. Projecting to perspective views is necessary to leverage existing models [S1].
*   **Visible Regions Only:** The trained NeRF $f_{\text{nerf}}$ only works for visible regions of the single panorama. Invisible regions require separate inpainting procedures (e.g., using Stable Diffusion) [S1].

## Operating characteristics
*   **Time Complexity:** The method involves an initial alignment optimization step over $K$ views and the full NeRF training loop. The alignment step adds overhead proportional to $K \times \text{pixels} \times \text{iterations}$.
*   **Memory Complexity:** Requires storing $K$ perspective depth maps and the canonical panorama depth map. The NeRF model size is standard.
*   **Strengths:** Provides accurate geometry reconstruction for visible regions by leveraging the strength of monocular depth estimators on perspective views while resolving their inconsistencies.
*   **Limitations:** Only reconstructs visible regions; invisible regions are not handled by this specific step. Relies on the quality of the external depth estimator [S1].
*   **When to use:** When reconstructing a scene from a single panoramic image and accurate geometry of visible parts is required.
*   **When not to use:** When the scene has significant occlusions or invisible regions that need to be filled without additional inpainting methods.

## Background
This method originates from the work on PERF (Panoramic Neural Radiance Field From a Single Panorama) [S1]. It addresses the limitation of previous single-view NeRF methods that did not fully address geometry consistency. By initializing the NeRF with a canonical depth map derived from aligned perspective estimates, it enables photo-realistic panoramic NeRF training from a single view [S1].
