# Guided Optimization of NeRF

Also called: Confidence-Based Depth Filtering

## Overview
Guided Optimization of NeRF mitigates the shape-radiance ambiguity inherent in Neural Radiance Fields, particularly in poorly textured indoor environments where standard sampling fails to recover correct geometry despite accurate RGB synthesis [S1]. It sets itself apart from sibling methods by explicitly adapting the sampling intervals $[t_n, t_f]$ along camera rays using adapted monocular depth priors and multi-view consistency error maps, rather than relying solely on explicit depth loss terms or fixed sparse reconstruction bounds [S1]. This approach constrains the search space for geometry to regions near the depth priors, weighted by a confidence score derived from RGB reconstruction error [S1].

## How it works
The method optimizes a Neural Radiance Field $F_\theta: (\mathbf{x}, \mathbf{d}) \rightarrow (c, \sigma)$ by integrating adapted depth priors into the sampling process and refining the output using confidence-based filtering [S1].

**Inputs:**
*   $N$ input views with RGB images and camera parameters (intrinsics $K$, relative poses $T^{i \rightarrow j}$).
*   Adapted monocular depth priors $\{D^i\}_{i=1}^N$ for each view, obtained from a scene-specific fine-tuned depth network [S1].
*   Hyperparameters: $K=4$ (number of cross-view errors for consistency), $\alpha_l = 0.05$ (lower bound), $\alpha_h = 0.15$ (upper bound) [S1].

**Outputs:**
*   Optimized NeRF network parameters $\theta$.
*   Refined depth maps for each view.

**Data Structures:**
*   **Error Map $e_i$:** A 2D array for view $i$, where each pixel value is the average of the top $K$ minimum cross-view depth projection errors.
*   **Confidence Map $S^i$:** A 2D array for view $i$, where each pixel value $S^i_j \in [0, 1]$ represents the confidence of the depth prediction at pixel $j$.

**Numbered Steps:**

1.  **Acquire Adapted Depth Priors:** Obtain initial depth maps $\{D^i\}_{i=1}^N$ using a pre-trained monocular depth network fine-tuned on the target scene [S1].
2.  **Compute Error Maps:** For each view $i$, project its depth map $D^i$ to all other views $j \neq i$ to compute reprojection errors.
    *   Project depth $D^i$ to view $j$: $p^{i \rightarrow j}, D^{i \rightarrow j} = \text{proj}(K, T^{i \rightarrow j}, D^i)$, where $p$ are 2D coordinates and $D^{i \rightarrow j}$ are projected depths [S1].
    *   Sample the depth from view $j$'s prior at these coordinates: $D^{j'} = D^j(p^{i \rightarrow j})$ [S1].
    *   Calculate the relative error between $D^j$ and $D^{i \rightarrow j}$ for overlapping pixels.
    *   For each pixel in view $i$, collect the errors from projections to all other views. Select the $K$ minimum errors and compute their average to form the error map value $e_i$ for that pixel [S1].
3.  **Calculate Adaptive Sample Ranges:** For each camera ray $\mathbf{r}$ corresponding to a pixel in view $i$ with adapted depth $D$ and error map value $e$:
    *   Compute near bound: $t_n = D(1 - \text{clamp}(e, \alpha_l, \alpha_h))$ [S1].
    *   Compute far bound: $t_f = D(1 + \text{clamp}(e, \alpha_l, \alpha_h))$ [S1].
    *   Here, $\text{clamp}(x, a, b)$ restricts $x$ to the interval $[a, b]$ [S1].
4.  **Stratified Sampling:** Partition the interval $[t_n, t_f]$ into $M$ bins. For each bin $i \in [1, M]$, sample a point $t_i$ uniformly:
    $$t_i \sim \mathcal{U} \left[ t_n + \frac{i-1}{M}(t_f - t_n), \,\, t_n + \frac{i}{M}(t_f - t_n) \right]$$
    [S1]
5.  **Volume Rendering:** Query the NeRF network $F_\theta$ at each sample point $(t_i, \mathbf{d})$ to get color $c_i$ and density $\sigma_i$. Compute rendered color $C(\mathbf{r})$ and depth $D(\mathbf{r})$:
    $$C(\mathbf{r}) = \sum_{i=1}^{M} T_i (1 - e^{-\sigma_i \delta_i}) c_i$$
    $$D(\mathbf{r}) = \sum_{i=1}^{M} T_i (1 - e^{-\sigma_i \delta_i}) t_i$$
    where $\delta_i = t_{i+1} - t_i$, $T_i = \exp \left(-\sum_{j=1}^{i-1} \sigma_j \delta_j \right)$ is the accumulated transmittance, and $T_1 = 1$ [S1].
6.  **Compute Confidence Scores:** For each pixel $j$ in view $i$, calculate the confidence score $S^i_j$ based on the $L_1$ difference between the ground truth RGB image $C_{gt}^i(j)$ and the rendered RGB image $C_{render}^i(j)$ (values normalized by 255):
    $$S^i_j = 1 - \frac{1}{3} \| C_{gt}^i(j) - C_{render}^i(j) \|_1$$
    [S1]
7.  **Refine Depth Map:** Apply plane bilateral filtering to the rendered depth map $D(\mathbf{r})$, using the confidence scores $S^i$ as weights to preserve edges and reduce noise in regions with low RGB reconstruction accuracy [S1].
8.  **Optimization:** Update network parameters $\theta$ to minimize the reconstruction loss (typically $L_1$ or $L_2$ on RGB) using the sampled points within the guided ranges [S1].

## Subtopics

### ENeRF with Guided Sampling Training
Integrates pixel and depth-guided ray sampling into the Efficient NeRF (ENeRF) framework [S2]. It samples fewer rays per iteration than standard ENeRF, achieving improved performance with lower GPU memory usage [S2]. The training objective combines Mean Squared Error (MSE) and Perceptual Loss: $\mathcal{L} = \mathcal{L}_{mse} + \lambda' \mathcal{L}_{perc}$, where $\lambda' = 0.01$ [S2]. It is used for rapid generalization on the DTU dataset and fine-tuning on novel scenes, including digital humans [S2].

## Operating characteristics
*   **Time Complexity:** The method adds overhead for multi-view depth reprojection and error map calculation ($O(N^2 \cdot H \cdot W)$ for error map construction) and confidence-based filtering. The sampling step itself is similar to standard NeRF but with adaptive bounds.
*   **Memory Complexity:** Requires storing adapted depth priors for all views and error maps. ENeRF variant uses less GPU memory due to fewer rays sampled per iteration [S2].
*   **Performance:** Outperforms original NeRF in depth estimation accuracy on indoor scenes (e.g., ScanNet) by mitigating shape-radiance ambiguity [S1].
*   **Strengths:** Effective in poorly textured indoor environments where standard NeRF fails; leverages monocular depth priors effectively.
*   **Limitations:** Relies on the quality of adapted monocular depth priors; correspondence-based optimization (like CVD) on these priors can degrade quality due to unreliable flow in texture-less regions [S1].
*   **When to use:** Indoor multi-view stereo and depth estimation where texture is sparse.
*   **When not to use:** Outdoor scenes with rich texture where standard NeRF sampling is sufficient, or when high-quality sparse reconstruction is unavailable to guide initial priors.

## Background
The method was proposed to address the shape-radiance ambiguity in Neural Radiance Fields, particularly in indoor scenes with poorly textured areas like walls [S1]. It builds on the original NeRF formulation [33] and integrates adapted monocular depth priors [S1]. The concept of using confidence scores derived from RGB reconstruction error to refine depth maps is also central to the method [S1].
