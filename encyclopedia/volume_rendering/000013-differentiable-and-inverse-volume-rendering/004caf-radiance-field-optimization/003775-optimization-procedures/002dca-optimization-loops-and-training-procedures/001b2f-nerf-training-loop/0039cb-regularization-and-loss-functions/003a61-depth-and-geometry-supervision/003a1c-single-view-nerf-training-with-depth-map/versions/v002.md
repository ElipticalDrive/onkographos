# Single-view NeRF Training with Depth Map

Also called: Depth-guided Single-view NeRF, Single-view NeRF with Depth Initialization

## Overview
This method addresses the under-constrained optimization problem of reconstructing a 360-degree scene from a single panoramic input by initializing the geometry of visible regions using estimated depth maps [S1]. It differs from [Depth-Supervised NeRF](8687-depth-supervised-nerf.md) by explicitly constructing a canonical panorama depth map through deformable alignment of multiple perspective projections before training, rather than applying depth loss directly to rendered depths during standard NeRF optimization [S1]. It builds on [Depth and Geometry Supervision](8727-depth-and-geometry-supervision.md) by integrating external geometric priors to regularize the density field $\sigma$ [7496-guided-optimization-of-nerf.md][8679-single-view-nerf-training-with-depth-map.md][8687-depth-supervised-nerf.md].

## How it works
**Inputs:**
- A single input RGB panorama $I_{rgb}$.
- A monocular depth estimation model (e.g., [52] in [S1]).
- A NeRF representation $f_{nerf}$ mapping 3D coordinates and viewing directions to color and density.

**Outputs:**
- A trained NeRF $f_{nerf}$ representing the visible regions of the scene.
- A canonical panorama depth map $I_d$.

**Data Structures:**
- **Perspective Projections:** $K$ perspective images $\{\bar{I}_{rgb}^k\}_{k=1}^K$ and their corresponding estimated depth maps $\{\bar{I}_d^k\}_{k=1}^K$.
- **Canonical Depth Map:** $I_d$, a learnable panorama depth map.
- **Alignment Parameters:** For each perspective map $k$, a global scale factor $w_k$ and a local bias field $\{b_{k,i,j}\}$, where $i,j$ are pixel coordinates.
- **Coordinate Mapping:** A function $M$ that maps perspective image coordinates $(i,j)$ to panorama image coordinates.

**Steps:**

1.  **Perspective Projection:** Project the single input panorama $I_{rgb}$ into $K$ perspective images $\{\bar{I}_{rgb}^k\}_{k=1}^K$ using different viewing directions. The number of projections is set to $K=20$ [S1]. This is necessary because existing monocular depth estimators are trained on limited field-of-view images and do not handle 360-degree panoramas directly [S1].

2.  **Depth Estimation:** Apply the monocular depth estimation model to each perspective image $\bar{I}_{rgb}^k$ to obtain the corresponding depth maps $\{\bar{I}_d^k\}_{k=1}^K$ [S1]. Note that due to scale ambiguity in single-view depth estimation, estimated depth values in overlapped regions between different perspectives may differ significantly [S1].

3.  **Deformable Alignment:** Align the perspective depth maps $\{\bar{I}_d^k\}$ to a canonical learnable panorama depth map $I_d$ by optimizing the following objective [S1]:
    $$
    \sum_{k,i,j} \left\| \bar{v}_{i,j}^k w_k + b_{k,i,j} - v_{M(i,j)} \right\| + L_s(b_{i,j+1}, b_{i,j}) + L_s(b_{i+1,j}, b_{i,j})
    $$
    Here, $\bar{v}_{i,j}^k$ is the pixel value of the perspective depth map $\bar{I}_d^k$, $v$ is the pixel value of the panorama depth map $I_d$, $L_s$ is the smooth L1 loss, and $M$ maps perspective coordinates to panorama coordinates. The first term is a data alignment term, while the subsequent terms constitute a total variation regularization term [S1].

4.  **NeRF Training:** Train the single-view NeRF using the RGB panorama $I_{rgb}$ and the aligned depth map $I_d$ by minimizing the combined color and depth reconstruction loss [S1]:
    $$
    L_{nerf}' = \sum_{\mathbf{r} \in \mathcal{R}} \left( \|\hat{C}(\mathbf{r}) - C(\mathbf{r})\|^2 + \|\hat{D}(\mathbf{r}) - \bar{D}(\mathbf{r})\|^2 \right)
    $$
    where $\hat{C}(\mathbf{r})$ is the expected pixel color, $C(\mathbf{r})$ is the ground-truth pixel color, $\hat{D}(\mathbf{r})$ is the expected depth values rendered by the NeRF, and $\bar{D}(\mathbf{r})$ is the corresponding depth pixel computed by the depth estimator $f_d$ for the panorama [S1]. The trained NeRF $f_{nerf}$ is valid only for visible regions [S1].

**Pseudocode:**

```python
def single_view_nerf_with_depth(panorama_rgb, depth_estimator, nerf_model):
    """
    Trains a single-view NeRF using depth-guided initialization.
    
    Args:
        panorama_rgb: Input RGB panorama image.
        depth_estimator: Monocular depth estimation model.
        nerf_model: NeRF representation to be trained.
        
    Returns:
        Trained nerf_model.
    """
    K = 20
    # Step 1: Project panorama to K perspective views
    perspective_images = []
    for k in range(K):
        # Project panorama to perspective view k
        # Implementation depends on specific projection geometry
        img = project_panorama_to_perspective(panorama_rgb, direction=k)
        perspective_images.append(img)
        
    # Step 2: Estimate depth for each perspective view
    perspective_depth_maps = []
    for img in perspective_images:
        depth_map = depth_estimator.predict(img)
        perspective_depth_maps.append(depth_map)
        
    # Step 3: Deformable alignment to canonical panorama depth map
    # Initialize learnable panorama depth map I_d
    canonical_depth_map = initialize_panorama_depth(panorama_rgb.shape)
    
    # Initialize alignment parameters
    scales = [1.0 for _ in range(K)]
    biases = [[0.0 for _ in range(height)] for _ in range(width)] # Local bias field
    
    # Optimize alignment parameters to minimize Eq. (2)
    # This involves gradient descent on I_d, scales, and biases
    for iteration in range(num_alignment_iterations):
        loss = 0.0
        for k in range(K):
            depth_map_k = perspective_depth_maps[k]
            scale_k = scales[k]
            bias_k = biases[k]
            
            # Compute aligned depth values
            # v_bar_k * w_k + b_kij
            aligned_depth = depth_map_k * scale_k + bias_k
            
            # Map to panorama coordinates
            # M maps (i,j) from perspective to panorama
            for i, j in coordinates_of_perspective_view(k):
                pano_i, pano_j = M(i, j, k)
                v_bar = aligned_depth[i, j]
                v = canonical_depth_map[pano_i, pano_j]
                
                # Data alignment term
                loss += smooth_l1_loss(v_bar, v)
                
                # Total variation terms (regularization)
                # L_s(b_{i,j+1}, b_{i,j})
                if j + 1 < width:
                    loss += smooth_l1_loss(bias_k[i, j+1], bias_k[i, j])
                # L_s(b_{i+1,j}, b_{i,j})
                if i + 1 < height:
                    loss += smooth_l1_loss(bias_k[i+1, j], bias_k[i, j])
                    
        # Update canonical_depth_map, scales, and biases using gradient descent
        update_parameters(canonical_depth_map, scales, biases, loss)
        
    # Step 4: Train NeRF with combined loss
    # L_nef' = sum(||C_hat - C||^2 + ||D_hat - D_bar||^2)
    for iteration in range(num_nerf_iterations):
        # Sample rays from the panorama
        rays = sample_rays_from_panorama(panorama_rgb)
        
        # Render color and depth from NeRF
        colors, depths = nerf_model.render(rays)
        
        # Get ground truth color and depth
        gt_colors = get_pixel_colors(rays, panorama_rgb)
        gt_depths = get_depth_from_canonical_map(rays, canonical_depth_map)
        
        # Compute loss
        color_loss = mean_squared_error(colors, gt_colors)
        depth_loss = mean_squared_error(depths, gt_depths)
        total_loss = color_loss + depth_loss
        
        # Update NeRF parameters
        update_nerf_parameters(nerf_model, total_loss)
        
    return nerf_model

def smooth_l1_loss(a, b):
    diff = a - b
    abs_diff = abs(diff)
    return sum(0.5 * diff**2 / 1.0 if abs_diff < 1.0 else abs_diff - 0.5 for diff in [diff])
```

**Parameters:**
- $K$: Number of perspective projections, set to 20 [S1].

**Edge Cases and Pitfalls:**
- **Scale Ambiguity:** Single-view depth estimation suffers from scale ambiguity, leading to inconsistent depth values in overlapped regions between different perspective projections [S1]. The deformable alignment step is crucial to resolve this [S1].
- **Limited Field of View:** Existing monocular depth estimators are trained on limited field-of-view images and do not work directly on 360-degree panoramas [S1]. Projection to perspective views is required [S1].
- **Visible Regions Only:** The trained NeRF is only valid for visible regions of the single panorama; invisible regions require additional completion methods (e.g., inpainting) [S1].

## Operating characteristics
- **Time Complexity:** The method involves $K$ depth estimations and an alignment optimization step before NeRF training. The alignment step requires iterating over $K$ perspective maps and their pixels, adding overhead to the training pipeline [S1].
- **Memory Complexity:** Requires storing $K$ perspective depth maps and the canonical panorama depth map, along with alignment parameters [S1].
- **Strengths:** Addresses the under-constrained nature of single-view reconstruction by providing geometric initialization [S1]. Enables photo-realistic panoramic NeRF from a single view [S1].
- **Limitations:** The NeRF is only valid for visible regions; invisible regions require additional processing [S1]. Relies on the accuracy of the monocular depth estimator [S1].
- **When to Use:** When reconstructing a 360-degree scene from a single panoramic input and geometric consistency is a concern [S1].
- **When Not to Use:** When multiple views are available, or when the scene contains significant invisible regions that cannot be handled by subsequent inpainting steps [S1].

## Background
The method was introduced in "PERF: Panoramic Neural Radiance Field From a Single Panorama" [S1]. It addresses limitations of previous single-view NeRF methods that did not fully address geometry consistency, such as SPInNeRF which inpaints depth maps and uses perceptual loss [S1]. The approach is inspired by 360MonoDepth [51] for predicting panorama depth by fusing perspective depth maps [S1].
