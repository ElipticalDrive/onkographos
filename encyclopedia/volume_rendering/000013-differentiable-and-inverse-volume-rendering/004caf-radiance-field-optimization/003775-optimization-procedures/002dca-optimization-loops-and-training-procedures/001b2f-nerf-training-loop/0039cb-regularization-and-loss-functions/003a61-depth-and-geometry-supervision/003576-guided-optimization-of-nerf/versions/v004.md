# Guided Optimization of NeRF

Also called: Confidence-Based Depth Filtering

## Overview
Guided Optimization of NeRF mitigates the shape-radiance ambiguity inherent in Neural Radiance Fields (NeRF) [S1], particularly in poorly textured indoor environments where standard sampling fails to recover correct geometry despite accurate RGB reconstruction [S1]. It sets itself apart from sibling methods by explicitly adapting the sampling bounds $[t_n, t_f]$ along camera rays using multi-view consistent depth priors, rather than relying solely on post-hoc depth supervision or fixed bounds [S1]. This approach constrains the optimization to regions likely containing geometry, preventing the network from converging to degenerate shapes that explain the input images but deviate from the ground truth [S1].

## How it works
The method integrates adapted monocular depth priors into the NeRF training loop to guide point sampling. It operates by first establishing reliable depth estimates through multi-view consistency checks, then using these estimates to define adaptive sampling intervals for each ray. Finally, it refines the output depth using confidence scores derived from the rendering quality.

### Inputs and Outputs
*   **Inputs:** $N$ input RGB images $\{I^i\}_{i=1}^N$, their camera intrinsics $K$, relative poses $T^{i \to j}$, and an initial monocular depth estimate for each view.
*   **Outputs:** A trained NeRF model $\mathcal{F}_\theta$ parameterizing radiance fields, and a refined depth map for each view.

### Data Structures
*   **Adapted Depth Priors:** $\{D^i\}_{i=1}^N$, where $D^i$ is a 2D depth map for view $i$.
*   **Error Maps:** $\{e_i\}_{i=1}^N$, where $e_i$ is a scalar value (or map) representing the reprojection error for view $i$.
*   **Confidence Scores:** $S^i_j$, a scalar confidence value for pixel $j$ in view $i$.

### Numbered Steps

1.  **Acquire Adapted Depth Priors:**
    Obtain initial depth estimates $\{D^i\}_{i=1}^N$ for the $N$ input views using a monocular depth network [S1]. These priors are adapted to the specific scene [S1].

2.  **Compute Error Maps via Multi-View Consistency:**
    For each view $i$, project its depth map $D^i$ to all other views $j$ to compute reprojection errors [S1].
    *   Project depth from view $i$ to view $j$:
        $$ p^{i \rightarrow j}, D^{i \rightarrow j} = \text{proj}(K, T^{i\rightarrow j}, D^i) $$
        where $p^{i \rightarrow j}$ are the 2D coordinates in view $j$ and $D^{i \rightarrow j}$ are the projected depth values [S1].
    *   Sample the depth from the target view $j$'s prior at these coordinates:
        $$ D^{j'} = D^j(p^{i \rightarrow j}) $$
    *   Calculate the relative error between the projected depth $D^{i \rightarrow j}$ and the target view's depth $D^{j'}$ [S1].
    *   Compute the error map value $e_i$ for view $i$ as the average of the top $K$ minimum cross-view depth projection errors [S1]. The parameter $K=4$ is used [S1].

3.  **Calculate Adaptive Sample Ranges:**
    For each ray $\mathbf{r}$ corresponding to a pixel in view $i$, determine the near ($t_n$) and far ($t_f$) bounds for sampling based on the adapted depth prior $D$ (the depth value for that pixel) and the error map value $e_i$ [S1]:
    $$ t_n = D(1 - \text{clamp}(e_i, \alpha_l, \alpha_h)) $$
    $$ t_f = D(1 + \text{clamp}(e_i, \alpha_h, \alpha_l)) $$
    Here, $\alpha_l = 0.05$ and $\alpha_h = 0.15$ are the lower and higher bounds for the range expansion [S1]. The function $\text{clamp}(x, a, b)$ restricts $x$ to the interval $[a, b]$ [S1]. This ensures sampling is concentrated around the prior for low-error pixels and expands for high-error pixels [S1].

4.  **Stratified Sampling:**
    Partition the interval $[t_n, t_f]$ into $M$ bins [S1]. For each bin $i \in [1, M]$, sample a point $t_i$ uniformly from the bin interval:
    $$ t_i \sim \mathcal{U} \left[ t_n + \frac{i-1}{M}(t_f - t_n), \,\, t_n + \frac{i}{M}(t_f - t_n) \right] $$
    [S1].

5.  **Volume Rendering:**
    Query the NeRF $\mathcal{F}_\theta$ at each sample point $t_i$ to obtain color $c_i$ and density $\sigma_i$ [S1]. Compute the accumulated transmittance $T_i = \exp \left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$, where $\delta_i = t_{i+1} - t_i$ [S1]. Render the RGB color $C(\mathbf{r})$ and depth $D(\mathbf{r})$ for the ray:
    $$ C(\mathbf{r}) = \sum_{i=1}^{M} T_i (1 - e^{-\sigma_i \delta_i}) c_i $$
    $$ D(\mathbf{r}) = \sum_{i=1}^{M} T_i (1 - e^{-\sigma_i \delta_i}) t_i $$
    [S1].

6.  **Compute Confidence Scores:**
    Calculate the confidence score $S^i_j$ for pixel $j$ in view $i$ based on the $L_1$ difference between the ground truth RGB $C_{gt}^i(j)$ and the rendered RGB $C_{render}^i(j)$, normalized by 255 [S1]:
    $$ S^i_j = 1 - \frac{1}{3} \| C_{gt}^i(j) - C_{render}^i(j) \|_1 $$
    [S1]. The norm is taken over the 3 color channels [S1].

7.  **Refine Depth with Plane Bilateral Filtering:**
    Apply plane bilateral filtering to the final depth map, weighted by the confidence scores $S^i_j$ [S1]. This step improves depth quality in regions where the rendered RGB images are not accurate [S1].

def project_depth(depth_map, K, pose_i, pose_j):
    """
    Projects depth map from view i to view j.
    Returns 2D coordinates and projected depth values.
    """
    # Get 3D points from depth map and camera i
    # H, W
    H, W = depth_map.shape
    # Create grid of 2D coordinates
    y, x = torch.meshgrid(torch.arange(H), torch.arange(W), indexing='ij')
    # Convert to homogeneous 2D
    uv = torch.stack([x, y], dim=-1).float() # (H, W, 2)
    
    # Unproject to 3D using K and depth
    # x_cam = K^{-1} [u, v, 1]^T * depth
    K_inv = torch.inverse(K)
    ones = torch.ones(H, W, 1)
    uv_homo = torch.cat([uv, ones], dim=-1) # (H, W, 3)
    
    # Reshape for matrix mult
    uv_homo_flat = uv_homo.reshape(-1, 3) # (HW, 3)
    depth_flat = depth_map.reshape(-1, 1) # (HW, 1)
    
    # 3D points in camera i frame
    pts_cam_i = (K_inv @ uv_homo_flat.T).T * depth_flat # (HW, 3)
    
    # Transform to world frame (assuming pose_i is world-to-camera? Or camera-to-world?)
    # Standard: P_world = T_cw * P_cam
    # Let's assume pose_i is T_cw (camera to world)
    # P_world = pose_i @ [P_cam; 1]
    pts_cam_i_homo = torch.cat([pts_cam_i, torch.ones(HW, 1)], dim=-1) # (HW, 4)
    pts_world = (pose_i @ pts_cam_i_homo.T).T[:, :3] # (HW, 3)
    
    # Transform to camera j frame
    # P_cam_j = T_wc_j @ P_world
    # T_wc_j = pose_j^{-1}
    T_wc_j = torch.inverse(pose_j)
    pts_world_homo = torch.cat([pts_world, torch.ones(HW, 1)], dim=-1)
    pts_cam_j = (T_wc_j @ pts_world_homo.T).T[:, :3] # (HW, 3)
    
    # Project to 2D in camera j
    uv_j = (K @ pts_cam_j.T).T # (HW, 3)
    uv_j_xy = uv_j[:, :2] / (uv_j[:, 2:] + 1e-6) # (HW, 2)
    depth_j = pts_cam_j[:, 2] # (HW)
    
    return uv_j_xy, depth_j

def sample_depth(depth_map, coords_2d):
    """
    Samples depth from depth_map at 2D coordinates.
    """
    # coords_2d shape (N, 2)
    # Normalize to [-1, 1] for grid_sample
    H, W = depth_map.shape
    # coords_2d is in [0, W], [0, H]
    # grid_sample expects [-1, 1]
    x_norm = 2 * coords_2d[:, 0] / (W - 1) - 1
    y_norm = 2 * coords_2d[:, 1] / (H - 1) - 1
    grid = torch.stack([x_norm, y_norm], dim=-1).unsqueeze(0).unsqueeze(0) # (1, 1, N, 2)
    
    # depth_map needs to be (1, 1, H, W)
    depth_tensor = depth_map.unsqueeze(0).unsqueeze(0)
    
    # Sample
    sampled = torch.nn.functional.grid_sample(depth_tensor, grid, align_corners=True)
    return sampled.squeeze()

### Parameters
*   $K=4$: Number of minimum cross-view depth projection errors used to calculate the error map value [S1].
*   $\alpha_l = 0.05$: Lower bound for the sample range expansion [S1].
*   $\alpha_h = 0.15$: Higher bound for the sample range expansion [S1].
*   $M$: Number of bins for stratified sampling. Not given in the sources.

### Edge Cases and Pitfalls
*   **Shape-Radiance Ambiguity:** In poorly textured indoor areas (e.g., walls), NeRF can synthesize high-quality RGB images with incorrect geometry. Standard NeRF sampling fails here because sampled points predict similar RGB values with confidence concentrated in a limited range, leading to depth deviation from ground truth [S1].
*   **Correspondence-Based Optimization Degradation:** Applying existing correspondence-based neural optimization (like CVD) to adapted depth priors degrades quality due to unreliable flow correspondences in poorly textured regions [S1].
*   **Occlusions:** The projection step assumes visibility. Pixels that do not overlap across views or are occluded must be handled, though the source notes "pixels that do not overlap across some..." without detailing the specific masking strategy [S1].

## Subtopics

### ENeRF with Guided Sampling Training
A variant that integrates pixel and depth-guided ray sampling into the ENeRF framework [S2]. It uses fewer rays per iteration but achieves improved performance with lower GPU memory usage [S2]. It employs an MSE loss $\mathcal{L}_{mse} = \frac{1}{N_r} \sum_{i=1}^{N_r} \| \hat{C}_i - C_i \|^2$ and a perceptual loss $\mathcal{L}_{perc} = \frac{1}{N_i} \sum_{i=1}^{N_i} \| \Phi(\hat{I}_i) - \Phi(I_i) \|$, with a total loss $\mathcal{L} = \mathcal{L}_{mse} + \lambda' \mathcal{L}_{perc}$ where $\lambda' = 0.01$ [S2]. It is used on DTU, Real Forward-facing, NeRF Synthetic, ZJU-MoCap, and digital human datasets [S2].

## Operating characteristics
*   **Time and Memory Complexity:** The method requires multi-view consistency checks, which involve projecting depth maps between all pairs of views, increasing computational overhead compared to standard NeRF [S1]. However, the variant ENeRF with guided sampling reduces GPU memory usage by sampling fewer rays per iteration [S2].
*   **Measured Performance:** The method outperforms state-of-the-art depth estimation methods on the ScanNet dataset in all metrics [S1]. It significantly outperforms original NeRF in terms of view synthesis quality [S1].
*   **Strengths:** Mitigates shape-radiance ambiguity in indoor scenes; improves depth estimation accuracy; allows novel view synthesis using adapted depth priors from the nearest seen view [S1].
*   **Limitations:** Relies on the quality of monocular depth priors; degrades if correspondence-based optimization is applied to the priors [S1].
*   **When to Use:** Indoor scenes with poorly textured regions where standard NeRF fails to recover geometry [S1].
*   **When Not to Use:** Scenes with rich textures where standard NeRF performs well, or when high-quality multi-view correspondences are unavailable [S1].

## Background
The method was proposed in "Depth-Guided Optimization of Neural Radiance Fields for Indoor Multi-View Stereo" [S1]. It addresses the limitations of NeRF [33] in indoor environments, where shape-radiance ambiguity is prevalent [S1]. The approach builds on the observation that NeRF favors smoother surfaces but can still converge to incorrect geometries in texture-less areas [S1]. It integrates adapted monocular depth priors to guide the sampling process, a strategy distinct from direct depth supervision or fixed bounds [S1].
