# NeRF with Unknown Camera Parameters

Also called: Joint Optimization of NeRF and Poses, Joint optimisation of NeRF and camera parameters, NeRF with unknown cameras, NeRF without known camera parameters, NeRF-- (NeRF without known camera parameters)

## Overview
This method simultaneously optimizes the parameters of a Neural Radiance Field ($\Theta$) and the camera poses ($P$) for a set of input images, eliminating the need for pre-estimated camera parameters such as those provided by Structure-from-Motion (SfM) pipelines [S1][S2, unofficial]. It differs from standard NeRF by treating camera extrinsics and intrinsics as learnable variables within the differentiable rendering loop [S2, unofficial]. Unlike [NoPe-NeRF](8705-nope-nerf.md) which incorporates explicit depth priors, the baseline NeRF-- formulation relies solely on photometric consistency [S2, unofficial].

## How it works
**Inputs:** A set of $N$ RGB images $\{I_i\}_{i=1}^N$ without associated camera poses.
**Outputs:** Optimized NeRF model parameters $\Theta$, camera poses $\{P_i\}_{i=1}^N$, and potentially intrinsic parameters (e.g., focal length $f$).

### Data Structures
*   **NeRF Model ($F_\Theta$):** A multi-layer perceptron (MLP) mapping 3D coordinates and viewing directions to color and density.
    *   *Layout:* Standard NeRF architecture. Hidden layer dimension is reduced to 128 for computational efficiency [S2, unofficial].
*   **Camera Parameters ($\pi_i$):**
    *   Extrinsic: Rotation $\phi_i$ (axis-angle representation) and translation $t_i$ (3D vector) [S2, unofficial].
    *   Intrinsic: Focal length $f$ (scalar, assumed shared across all cameras in the baseline formulation) [S2, unofficial].
*   **Depth Priors (Optional/Advanced):** In variants like TD-NeRF, a pre-trained monocular depth network provides prior depth maps $\hat{D}_{idpt}$ [S1].

### Numbered Steps
1.  **Initialization:**
    *   Initialize NeRF weights $\Theta$ using Kaiming initialization [S2, unofficial].
    *   Initialize all camera poses at the origin, looking in the $-z$ direction [S2, unofficial].
    *   Initialize focal length $f$ to the image width [S2, unofficial].
2.  **Ray Generation:** For each pixel $p=(u,v)$ in image $I_i$, compute the ray origin $\hat{o}_i$ and direction $\hat{d}_{i,p}$ using current estimates $\hat{\pi}_i = (\hat{f}, \hat{\phi}_i, \hat{t}_i)$:
    $$ \hat{o}_i = \hat{t}_i $$
    $$ \hat{d}_{i,p} = \hat{R}_i \begin{pmatrix} (u - W/2)/\hat{f} \\ -(v - H/2)/\hat{f} \\ -1 \end{pmatrix} $$
    where $\hat{R}_i$ is the rotation matrix computed from $\hat{\phi}_i$ using Rodrigues' formula, and $W, H$ are image dimensions [S2, unofficial].
3.  **Sampling:** Sample $K$ points $\{x_j\}_{j=1}^K$ along the ray. In the baseline NeRF--, $K=128$ points are sampled uniformly [S2, unofficial].
4.  **Evaluation:** Query the NeRF model $F_\Theta$ for each point $x_j$ to obtain density $\sigma_j$ and color $c_j$ [S2, unofficial].
5.  **Volume Rendering:** Compute the rendered pixel color $\hat{C}$ using the standard volume rendering integral:
    $$ \hat{C} = \sum_{j=1}^K T_j \alpha_j c_j $$
    where $\alpha_j = 1 - \exp(-\sigma_j \delta_j)$ and $T_j = \exp(-\sum_{m=1}^{j-1} \sigma_m \delta_m)$ [S2, unofficial].
6.  **Loss Computation:**
    *   **Photometric Loss:** Minimize the difference between rendered color $\hat{C}$ and ground truth $I$ [S2, unofficial].
    *   **Depth Loss (TD-NeRF variant only):** If using depth priors, apply a linear transformation $s_i \hat{D}_{idpt} + k_i$ to undistort the prior depth $\hat{D}_{idpt}$ using learnable parameters $s_i, k_i$, and minimize the difference with rendered depth $D_{infer}$ [S1].
7.  **Optimization:** Update $\Theta$, $\{P_i\}$, and $f$ using gradient descent [S2, unofficial].

### Pseudocode
```python
def train_nerf_with_unknown_cameras(images, epochs=10000):
    # 1. Initialization
    nerf_model = initialize_nerf(hidden_dim=128, init='kaiming')
    # Initialize all cameras at origin, looking at -z
    poses = [CameraPose(t=np.array([0,0,0]), phi=np.array([0,0,0])) for _ in images]
    focal_length = images[0].width
    
    # 2. Optimizers
    opt_nerf = Adam(nerf_model.parameters(), lr=0.001)
    opt_poses = Adam([p.phi for p in poses] + [p.t for p in poses], lr=0.001)
    opt_focal = Adam([focal_length], lr=0.001)
    
    for epoch in range(epochs):
        # Learning rate decay
        if epoch % 10 == 0:
            nerf_model.lr *= 0.9954
        if epoch % 100 == 0:
            opt_poses.lr *= 0.9
            opt_focal.lr *= 0.9
            
        total_loss = 0
        
        for image in images:
            # 3. Randomly sample M pixels (M=1024)
            pixels = sample_random_pixels(image, M=1024)
            
            for p in pixels:
                # 4. Ray Generation
                # Compute rotation matrix R from phi using Rodrigues' formula
                R = rodrigues(poses[image.id].phi)
                u, v = p.u, p.v
                W, H = image.width, image.height
                
                # Ray direction in camera space, then rotated to world space
                cam_dir = np.array([(u - W/2)/focal_length, -(v - H/2)/focal_length, -1])
                ray_dir = R @ cam_dir
                ray_origin = poses[image.id].t
                
                # 5. Sampling and Rendering
                # Sample 128 points along ray
                points = sample_along_ray(ray_origin, ray_dir, num_samples=128)
                
                # Evaluate NeRF
                densities, colors = nerf_model(points, ray_dir)
                
                # Volume rendering
                rendered_color = volume_render(points, densities, colors)
                
                # 6. Loss
                gt_color = image.get_pixel_color(p)
                loss = (rendered_color - gt_color)**2
                
                # 7. Backpropagation
                # Gradients flow to nerf_model, poses, and focal_length
                loss.backward()
                total_loss += loss.item()
                
        opt_nerf.step()
        opt_poses.step()
        opt_focal.step()
        opt_nerf.zero_grad()
        opt_poses.zero_grad()
        opt_focal.zero_grad()
```

### Parameters
*   **Hidden Layer Dimension:** 128 (reduced from 256 for efficiency) [S2, unofficial].
*   **Pixels per Image:** 1024 [S2, unofficial].
*   **Points per Ray:** 128 [S2, unofficial].
*   **Learning Rate:** 0.001 for all optimizers [S2, unofficial].
*   **Decay:** NeRF LR decays by 0.9954 every 10 epochs; Pose/Focal LR decays by 0.9 every 100 epochs [S2, unofficial].
*   **Epochs:** 10,000 [S2, unofficial].

### Pitfalls
*   **Local Minima:** Joint optimization can trap the solution in local minima, particularly for scenes with limited texture or specific geometries (e.g., "Orchids", "Room"), leading to inaccurate intrinsics and worse Novel View Synthesis (NVS) quality [S2, unofficial].
*   **Intrinsic Ambiguity:** Without strong priors, optimizing focal length simultaneously with poses can be unstable [S2, unofficial].

## Operating characteristics
*   **Complexity:** Time complexity is dominated by the MLP queries per pixel. Sampling 1024 pixels and 128 points per ray increases memory bandwidth usage compared to fixed-pose NeRF due to the need to store gradients for camera parameters.
*   **Performance:** Achieves comparable NVS quality to baseline NeRF (using COLMAP poses) with $\Delta$SSIM and $\Delta$LPIPS $\approx 0.05$ [S2, unofficial].
*   **Strengths:** Eliminates dependency on SfM pipelines; robust to moderate camera motion instability [S2, unofficial].
*   **Limitations:** Susceptible to local minima; requires careful initialization and learning rate scheduling [S2, unofficial]. Not recommended for scenes with significant parallax or non-forward-facing views without modification [S2, unofficial].

## Background
The method was introduced in "NeRF--: Neural Radiance Fields Without Known Camera Parameters" [S2, unofficial]. It addresses the limitation of standard NeRF which requires accurate camera poses from external tools like COLMAP. The approach demonstrates that differentiable rendering allows for the end-to-end optimization of scene and camera parameters. Variants like TD-NeRF [S1] later introduced depth priors to improve robustness.
