# Vision-Only Pose Filtering in a NeRF

Also called: Optimization-based Pose Filter for NeRF, Recursive SE(3) Optimization

## Overview
This method is an optimization-based state estimation filter that estimates the 6-DoF pose and velocities of a robot within a Neural Radiance Field (NeRF) using only onboard monocular RGB images [S1]. It addresses the limitation of single-shot pose estimators by treating the problem as recursive Bayesian estimation, balancing a NeRF-based photometric loss with a dynamics prediction loss to provide robustness in low-gradient regions and output state covariance [S1].

## How it works
The method operates as a recursive filter at each timestep $t$, updating the robot's state belief based on a new image $I_t$, the previous action $u_t$, and the prior state estimate [S1].

**Inputs and Outputs:**
*   **Inputs:** Current image $I_t$, previous action $u_t$, prior state mean $\mu_{t-1}$, prior state covariance $\Sigma_{t-1}$, pre-trained NeRF model, and a subset of selected pixels $I$ (identified via feature detection) [S1].
*   **Outputs:** Updated state mean $\mu_t$, updated state covariance $\Sigma_t$, and the robot pose $T_t$ derived from $\mu_t$ [S1].

**Data Structures:**
*   **State Vector $\mu_t$:** Contains the robot's position, orientation (represented in SE(3)), and velocities [S1].
*   **Covariance Matrix $\Sigma_t$:** A symmetric positive-definite matrix representing the uncertainty of the state estimate [S1].
*   **Pixel Subset $I$:** A set of 2D image coordinates $(u, v)$ selected using an image feature detector (e.g., ORB) to bias sampling toward areas of high gradient information [S1].

**Numbered Steps:**

1.  **State Propagation (Prediction):**
    Propagate the state mean and covariance forward using the system dynamics model $f$ and the applied action $u_t$ [S1].
    $$ \mu_{t|t-1} = f(\mu_{t-1}, u_t) $$
    $$ A_{t-1} = \left. \frac{\partial f(x, u_t)}{\partial x} \right|_{x=\mu_{t-1}} $$
    $$ \Sigma_{t|t-1} = A_{t-1} \Sigma_{t-1} A_{t-1}^T + Q_{t-1} $$
    where $Q_{t-1}$ is the process noise covariance [S1].

2.  **Pixel Selection:**
    Select a subset of pixels $I$ from the current image $I_t$ using an image feature detector (e.g., ORB) to identify points of interest [S1].

3.  **Optimization (Update):**
    Minimize the cost function $J(\mu_t)$ with respect to the state $\mu_t$ to find the posterior mean $\mu_t$ [S1]. The cost function combines a photometric loss and a process loss [S1]:
    $$ J(\mu_t) = \| C_I(T_t) - I_t(I) \|_{S_t^{-1}}^2 + \| \mu_{t|t-1} - \mu_t \|_{\Sigma_{t|t-1}^{-1}}^2 $$
    where:
    *   $C_I(T_t)$ represents the predicted pixel values for the selected subset $I$ given the pose $T_t$ (derived from $\mu_t$) and the NeRF [S1].
    *   $I_t(I)$ are the observed pixel values from the image $I_t$ at locations $I$ [S1].
    *   $S_t$ is the measurement noise covariance [S1].
    *   The notation $\| x \|_M^2 = x^T M x$ denotes the weighted $L_2$ norm [S1].

4.  **Outlier Rejection:**
    Perform outlier rejection on the per-pixel loss to reduce variance before or during the optimization step [S1].

5.  **Covariance Update:**
    Compute the posterior covariance $\Sigma_t$ using the Hessian of the loss function at the optimized mean [S1]:
    $$ \Sigma_t = \left( \left. \frac{\partial^2 J(x)}{\partial x^2} \right|_{x=\mu_t} \right)^{-1} $$

6.  **Manifold Projection:**
    During the optimization of $\mu_t$, project the pose back onto the SE(3) manifold after every gradient step [S1]. This "recursive SE(3)" approach is preferred over optimizing with respect to a reference pose and projecting once, as the multiplication of skew-symmetric matrices in the exponential map does not commute, and recursive projection converges quicker and more smoothly on the noisy photometric loss landscape [S1].

**Pseudocode:**

```python
import torch
import torch.autograd.functional as AF

def vision_only_pose_filter(
    prev_mu: torch.Tensor,
    prev_Sigma: torch.Tensor,
    action_u: torch.Tensor,
    current_image: torch.Tensor,
    nerf_model: callable,
    pixel_subset_I: list,
    Q: torch.Tensor,
    S: torch.Tensor,
    max_iterations: int,
    learning_rate: float
) -> tuple:
    # Step 1: State Propagation
    # Dynamics model f(mu, u) is problem-specific and not detailed in the sources.
    mu_pred = dynamics_model(prev_mu, action_u)
    A = compute_jacobian_dynamics(prev_mu, action_u)
    Sigma_pred = A @ prev_Sigma @ A.T + Q

    # Step 2: Pixel Selection
    # pixel_subset_I is provided as input, selected via ORB or similar feature detector [S1].

    # Step 3 & 6: Optimization with Recursive SE(3) Projection
    mu_opt = mu_pred.clone().detach().requires_grad_(True)
    optimizer = torch.optim.Adam([mu_opt], lr=learning_rate)

    for step in range(max_iterations):
        optimizer.zero_grad()
        loss = cost_function(mu_opt, mu_pred, Sigma_pred, S, current_image, pixel_subset_I, nerf_model)

        # Outlier rejection on per-pixel loss reduces variance [S1].
        loss = apply_outlier_rejection(loss, current_image, pixel_subset_I, mu_opt, nerf_model)

        loss.backward()
        optimizer.step()

        # Recursive SE(3) projection after every gradient step [S1].
        mu_opt = project_se3_manifold(mu_opt)

    # Step 5: Covariance Update
    # Hessian of the loss function at the optimized mean [S1].
    H = AF.hessian(cost_function, mu_opt, args=(mu_pred, Sigma_pred, S, current_image, pixel_subset_I, nerf_model))
    Sigma_t = torch.inverse(H)

    return mu_opt.detach(), Sigma_t

def dynamics_model(mu: torch.Tensor, u: torch.Tensor) -> torch.Tensor:
    # Problem-specific dynamics f(mu, u). Not given in the sources.
    # Example: constant velocity model
    return mu + u

def compute_jacobian_dynamics(mu: torch.Tensor, u: torch.Tensor) -> torch.Tensor:
    # Jacobian A = df/dx at x=mu [S1].
    return torch.autograd.functional.jacobian(lambda x: dynamics_model(x, u), mu)

def cost_function(mu: torch.Tensor, mu_pred: torch.Tensor, Sigma_pred: torch.Tensor,
                  S: torch.Tensor, current_image: torch.Tensor, pixel_subset_I: list,
                  nerf_model: callable) -> torch.Tensor:
    T_t = extract_pose_from_state(mu)
    predicted_pixels = nerf_model.render(T_t, pixel_subset_I)
    observed_pixels = current_image[pixel_subset_I]

    diff_photo = predicted_pixels - observed_pixels
    diff_photo_flat = diff_photo.view(-1, 1)
    S_inv = torch.inverse(S)
    photometric_loss = diff_photo_flat.T @ S_inv @ diff_photo_flat

    diff_proc = mu_pred - mu
    diff_proc_flat = diff_proc.view(-1, 1)
    Sigma_pred_inv = torch.inverse(Sigma_pred)
    process_loss = diff_proc_flat.T @ Sigma_pred_inv @ diff_proc_flat

    return (photometric_loss + process_loss).squeeze()

def extract_pose_from_state(mu: torch.Tensor) -> torch.Tensor:
    # Extracts SE(3) pose from the state vector.
    # Layout depends on the specific state representation [G].
    return mu[:6]

def project_se3_manifold(state: torch.Tensor) -> torch.Tensor:
    # Projects pose component back onto SE(3) manifold after every gradient step [S1].
    # Uses standard SVD to enforce valid rotation matrices [G].
    pose = state[:6]
    R = pose[:3, :3]
    U, _, Vt = torch.linalg.svd(R)
    R_proj = U @ Vt
    t = pose[:3, 3]
    new_state = state.clone()
    new_state[:3, :3] = R_proj
    return new_state

def apply_outlier_rejection(loss: torch.Tensor, current_image: torch.Tensor,
                            pixel_subset_I: list, mu: torch.Tensor,
                            nerf_model: callable) -> torch.Tensor:
    # Masks pixels with high photometric residuals before backpropagation [S1].
    T_t = extract_pose_from_state(mu)
    predicted = nerf_model.render(T_t, pixel_subset_I)
    observed = current_image[pixel_subset_I]
    residuals = torch.abs(predicted - observed)
    mask = residuals < torch.median(residuals) + 3 * torch.std(residuals)
    if not torch.any(mask):
        return loss
    return loss * torch.mean(mask.float())
```

**Parameters:**
*   **Feature Detector:** ORB is used to select pixels for photometric evaluation [S1].
*   **Process Noise Covariance $Q_{t-1}$:** Covariance of the process noise in the state propagation step [S1].
*   **Measurement Noise Covariance $S_t$:** Covariance weighting the photometric loss term [S1].
*   **Learning Rate:** Hyperparameter for the optimizer; value not specified in the sources.

**Edge Cases and Pitfalls:**
*   **SE(3) Manifold Optimization:** Multiplication of skew-symmetric matrices in the exponential map does not commute. Optimizing with respect to a reference pose and projecting once is mathematically distinct from recursive projection [S1]. The recursive SE(3) approach is required for quicker and smoother convergence due to the noisy photometric loss landscape [S1].
*   **Low Gradient Regions:** The method is designed to be robust in regions with low photometric gradient information by relying more on the dynamics model (process loss) [S1].
*   **Implementation:** Optimization on the manifold is implemented using the LieTorch library [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Demonstrated in simulation with a quadrotor navigating through a jungle gym, the inside of a church, and Stonehenge, and with an omnidirectional ground robot navigating through a church [S1].
*   **Strengths:** Provides robust pose estimation in low-gradient regions; outputs state covariance useful for parallel algorithms like collision avoidance; integrates seamlessly with trajectory planning in an online replanning loop [S1].
*   **Limitations:** Requires a pre-trained NeRF model; computationally intensive due to NeRF rendering and optimization at each timestep; sensitive to the accuracy of the dynamics model $f$ and noise covariances $Q, S$ [S1].
*   **When to Use:** Online robot navigation in environments represented by NeRFs where only monocular vision is available and dynamics are known [S1].
*   **When Not to Use:** When high-frequency updates are not required and offline batch optimization is acceptable; when the environment is not well-represented by a NeRF; when dynamics are unknown or highly uncertain [S1].

## Background
The method was introduced by Mikhalkiewicz et al. in 2022 in the paper "Vision-Only Robot Navigation in a Neural Radiance World" [S1]. It builds upon previous work on single-image camera pose estimation using NeRFs [19] (cited in [S1]) but extends it to recursive Bayesian estimation [S1]. The method is part of a larger navigation framework that combines trajectory planning (based on differential flatness) and pose filtering for online replanning [S1]. It was demonstrated in high-fidelity simulation environments including a playground, a church, and Stonehenge [S1].
