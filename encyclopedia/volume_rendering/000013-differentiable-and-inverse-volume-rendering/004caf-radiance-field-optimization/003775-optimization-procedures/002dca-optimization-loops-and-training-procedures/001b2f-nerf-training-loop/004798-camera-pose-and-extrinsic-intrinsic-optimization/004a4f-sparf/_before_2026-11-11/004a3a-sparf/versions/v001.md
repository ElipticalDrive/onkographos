# SPARF
Also called: Neural Radiance Fields from Sparse and Noisy Poses

## Overview
SPARF is a joint pose-NeRF training strategy designed for novel view synthesis using a sparse set of input images (as few as 3) with noisy camera pose estimates [S1]. It solves the overfitting and geometric inconsistency inherent in sparse-view regimes by replacing the standard photometric loss with multi-view geometry constraints, specifically a multi-view correspondence loss and a depth consistency loss [S1]. Unlike sibling methods like BARF or SCNeRF that rely on independent photometric supervision, SPARF explicitly enforces global geometric consistency across all training views through pixel correspondences [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** $n$ RGB images (typically $n=3$) with large viewpoint variations and noisy camera pose estimates $\hat{P}$. No prior on scene shape is assumed [S1].
*   **Outputs:** Optimized camera poses $\hat{P}$ and a trained NeRF model parameters $\theta$ [S1].

**Data Structures:**
*   **NeRF Model:** A multi-layer perceptron (MLP) $F_\theta$ mapping 3D coordinates and viewing directions to color $c$ and volume density $\sigma$ [S1].
*   **Camera Poses:** Represented as a continuous 6-vector for rotation and a direct vector for translation [S1].
*   **Matches:** Dense pixel correspondences $q$ for each pixel $p$ in a source view, along with confidence scores $w_p$, obtained from a pre-trained matching network [S1].

**Volume Rendering Formulas:**
Given a camera pose $P_i$, a pixel $p$ defines a ray. Samples are taken at depths $t_m$ within $[t_n, t_f]$. The rendered color $\hat{I}_{i,p}$ is:
$$ \hat{I}_{i,p} = \sum_{m=1}^{M} \alpha_m c_m $$
where $\alpha_m = T_m (1 - \exp(-\sigma_m \delta_m))$ and $T_m = \exp \left( -\sum_{m'=1}^{m} \sigma_{m'} \delta_{m'} \right)$. Here, $\delta_m = t_{m+1} - t_m$ is the distance between adjacent samples [S1].

**Algorithm Steps:**

1.  **Extract Dense Matches:** Use a pre-trained dense correspondence regression network (e.g., PDC-Net) to find matches $q$ for each pixel $p$ in training views, obtaining confidence weights $w_p$ [S1].
2.  **Joint Pose-NeRF Training (Multi-View Correspondence Loss):**
    *   Randomly sample a pair of training images $(I_i, I_j)$.
    *   For each pixel $p$ in $I_i$ with match $q$ in $I_j$:
        *   Backproject $p$ to 3D using the rendered depth $\hat{z}(p; \theta, \hat{P}_i)$ and current pose $\hat{P}_i$: $r_{i,p} = \hat{P}_i^{-1} \pi^{-1}(p, \hat{z}(p; \theta, \hat{P}_i))$.
        *   Project this 3D point into view $I_j$ using current pose $\hat{P}_j$: $y = \pi(r_{i,p}; \hat{P}_j)$.
        *   Compute the re-projection error between the predicted projection $y$ and the matched pixel $q$.
        *   Minimize the Huber loss $\rho$ weighted by confidence $w_p$:
            $$ L_{MVCorr} = \sum_{p} w_p \rho(y - q) $$
    *   This loss drives the poses and geometry to converge to a globally consistent solution [S1].
3.  **NeRF Refinement (Depth Consistency Loss):**
    *   Sample a virtual pose $P_{un}$, typically interpolated between two close-by training views [S1].
    *   For each pixel $p$ in a training view $I_i$:
        *   Backproject to 3D: $r_{i,p} = \hat{P}_i^{-1} \pi^{-1}(p, \hat{z}(p; \theta, \hat{P}_i))$.
        *   Project to virtual view $P_{un}$: $y = \pi(r_{i,p}; P_{un})$.
        *   Get the depth $z_y$ of this point in the virtual view coordinate system ($z_y = [r_{i,p}]_3$).
        *   Render the depth $\hat{z}(y; \theta, P_{un})$ at pixel $y$ in the virtual view.
        *   Calculate the visibility mask $\gamma_y$ to handle occlusions and out-of-view pixels:
            $$ \gamma_y = T_{un, z_y} = \exp \left( -\sum_{m'=1}^{m} \sigma_{m'} \delta_{m'} \right) $$
            evaluated along the ray in the virtual view up to depth $z_y$. $\gamma_y \approx 1$ if unoccluded, $\approx 0$ if occluded or out-of-view [S1].
        *   Compute the loss:
            $$ L_{DCons} = \sum_{p} \gamma_y \rho(z_y - \hat{z}(y; \theta, P_{un})) $$
    *   Backpropagate through the pseudo-supervision $z_y$ and $\hat{z}$, but **not** through the pose estimate $\hat{P}_i$ [S1].

**Pseudocode:**

```python
def sparf_training(images, initial_poses, matching_model, nerf_model, num_iterations=100000):
    """
    images: List of n RGB images.
    initial_poses: List of n noisy camera poses (rotation 6-vector + translation vector).
    matching_model: Pre-trained dense correspondence network (e.g., PDC-Net).
    nerf_model: NeRF MLP parameters theta.
    """
    poses = initial_poses
    matches = {} # Dictionary storing matches and confidences for each image pair
    
    # Step 1: Extract matches
    for i in range(len(images)):
        for j in range(i + 1, len(images)):
            matches[(i, j)] = matching_model.get_matches(images[i], images[j])
            
    for iteration in range(num_iterations):
        # Sample a pair of training views
        i, j = random_pair(len(images))
        pair_matches = matches[(i, j)]
        
        # Step 2: Multi-View Correspondence Loss
        mv_corr_loss = 0.0
        for p, q, w_p in pair_matches:
            # Backproject pixel p in view i to 3D
            depth_i = nerf_model.render_depth(images[i], poses[i], p)
            point_3d_i = backproject(p, depth_i, poses[i])
            
            # Project 3D point to view j
            projected_q = project(point_3d_i, poses[j])
            
            # Huber loss between projected_q and actual match q
            mv_corr_loss += w_p * huber_loss(projected_q, q)
            
        mv_corr_loss.backward() # Gradients for theta and poses
        
        # Step 3: Depth Consistency Loss
        # Create virtual pose by interpolating two close training poses
        k, l = find_close_views(poses)
        virtual_pose = interpolate_poses(poses[k], poses[l])
        
        d_cons_loss = 0.0
        for p in range(width * height): # Iterate over pixels in view i
            # Backproject to 3D
            depth_i = nerf_model.render_depth(images[i], poses[i], p)
            point_3d_i = backproject(p, depth_i, poses[i])
            
            # Project to virtual view
            virtual_pixel = project(point_3d_i, virtual_pose)
            
            # Check if virtual_pixel is within bounds of virtual view
            if not is_in_bounds(virtual_pixel):
                continue
                
            # Get depth of point in virtual view coordinate system
            z_y = point_3d_i.z # Assuming standard camera coordinate system
            
            # Render depth at virtual_pixel in virtual view
            rendered_depth_virtual = nerf_model.render_depth(images[i], virtual_pose, virtual_pixel)
            
            # Calculate visibility mask gamma_y
            # This requires querying the NeRF along the ray in the virtual view
            # up to depth z_y to compute accumulated transmittance
            gamma_y = compute_visibility_mask(virtual_pose, virtual_pixel, z_y, nerf_model)
            
            # Huber loss between true depth z_y and rendered depth
            d_cons_loss += gamma_y * huber_loss(z_y, rendered_depth_virtual)
            
        d_cons_loss.backward() # Gradients for theta only (poses not updated here)
        
        # Optimization step for theta and poses
        optimizer.step()
        optimizer.zero_grad()
```

**Parameters:**
*   **Training Duration:** 100K iterations [S1].
*   **Hardware:** ~10 hours on a single A100 GPU [S1].
*   **Loss Weights:** $\lambda_c$ and $\lambda_d$ for $L_{MVCorr}$ and $L_{DCons}$ respectively (values not specified in sources, but noted as predefined) [S1].
*   **Positional Encoding:** Coarse-to-fine positional encoding strategy is used to prevent overfitting [S1].

**Edge Cases and Pitfalls:**
*   **Overfitting:** Direct photometric loss causes the NeRF to collapse to training views, especially with noisy poses. SPARF avoids this by using multi-view geometry as the primary signal [S1].
*   **Occlusion/Out-of-View:** The depth consistency loss is invalid for occluded pixels or those projected outside the virtual view. This is handled by the visibility mask $\gamma_y$ [S1].
*   **Degenerate Geometry:** Standard high-frequency positional encodings can lead to degenerate geometry in sparse settings. A coarse-to-fine PE strategy is required [S1].

## Operating characteristics
*   **Time Complexity:** 100K iterations, approximately 10 hours on an A100 GPU for 3 views [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:**
    *   **DTU (3 views, noisy poses):** PSNR 17.74 (18.92 masked), SSIM 0.71 (0.83), LPIPS 0.26 (0.13), Rotation Error 1.81°, Translation Error 5.0 (x100). Outperforms BARF (PSNR 10.71) and SCNeRF (PSNR 12.04) [S1].
    *   **LLFF (3 views, identity poses):** PSNR 19.58, SSIM 0.61, LPIPS 0.31, Rotation Error 0.53°, Translation Error 2.8 (x100). Outperforms BARF (PSNR 17.47) and SCNeRF (PSNR 17.10) [S1].
    *   **Replica (3 views, COLMAP poses):** PSNR 26.98, SSIM 0.88, LPIPS 0.13, Rotation Error 0.15°, Translation Error 0.36 (x100). Outperforms DS-NeRF (PSNR 24.75) and SCNeRF (PSNR 22.54) [S1].
*   **Strengths:** Handles sparse views (as low as 3) and noisy poses effectively; enforces global geometric consistency; superior to photometric-only methods in sparse regimes.
*   **Limitations:** Requires a pre-trained matching model (e.g., PDC-Net); computationally intensive (10 hours on A100); sensitive to positional encoding strategies [S1].
*   **When to use:** Few-shot novel view synthesis with noisy or unknown camera poses.
*   **When not to use:** Dense view settings where photometric loss is sufficient; real-time applications requiring faster training [S1].

## Background
SPARF was introduced in the paper "SPARF: Neural Radiance Fields from Sparse and Noisy Poses" [S1]. It addresses the limitations of prior joint pose-NeRF methods like BARF and NeRF--, which rely on photometric loss and assume dense coverage of 3D space. SPARF adapts multi-view geometry principles to the NeRF framework to handle the under-constrained sparse-view regime [S1]. It is evaluated on DTU, LLFF, and Replica datasets [S1].
