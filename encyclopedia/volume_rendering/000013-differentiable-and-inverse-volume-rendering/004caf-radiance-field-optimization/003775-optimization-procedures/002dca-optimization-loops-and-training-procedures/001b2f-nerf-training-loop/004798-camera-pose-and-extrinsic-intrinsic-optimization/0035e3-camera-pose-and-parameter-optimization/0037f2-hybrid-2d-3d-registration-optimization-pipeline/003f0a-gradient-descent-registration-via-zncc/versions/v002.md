# Gradient Descent Registration via ZNCC

Also called: Slice-to-Volume Registration via Gradient Descent, ZNCC-based 6 DoF Registration

## Overview
This method performs 6 Degrees of Freedom (DoF) slice-to-volume registration by minimizing the negative Zero-Normalized Cross-Correlation (ZNCC) between a fixed Digitally Reconstructed Radiograph (DRR) and a moving DRR using gradient descent [S1]. It serves as the local refinement stage of the Hybrid 2D/3D Registration Optimization Pipeline, leveraging the locally convex loss landscape of ZNCC to converge quickly from random initializations [S1]. Unlike the global network-based loss ($L_N$) in its parent pipeline, this method relies on traditional gradient descent with momentum, requiring differentiable DRR generation to compute gradients with respect to pose parameters [S1].

## How it works

### Inputs and Outputs
*   **Inputs:**
    *   Fixed DRR image $I_{fixed}$ generated from ground truth parameters $\eta^*$ [S1].
    *   Moving DRR image $I_{moving}$ generated from initial parameters $\eta_0$ [S1].
    *   CT Volume data (implicit in DRR generation) [S1].
    *   Hyperparameters: Learning rates $\beta_{\theta\phi\gamma}$, $\beta_{xyz}$, momentum $\lambda$, maximum iterations $N_{max}$, and convergence threshold [S1].
*   **Outputs:**
    *   Optimized 6 DoF pose parameters $\eta_{opt} = (\theta, \phi, \gamma, b_x, b_y, b_z)$ [S1].

### Data Structures
The pose is represented as a vector of 6 parameters:
$$ \eta = [\theta, \phi, \gamma, b_x, b_y, b_z] $$
*   $\theta, \phi, \gamma$: Rotations [S1].
*   $b_x, b_y, b_z$: Translations in millimeters [S1].
*   Source-to-detector distance and pixel dimensions are fixed and not optimized [S1].

Gradients are accumulated in a velocity vector $v$ of the same shape as $\eta$ for momentum updates [S1].

### Formulas
1.  **ZNCC:**
    $$ \text{ZNCC}(I_{fixed}, I_{moving}) = \frac{\sum (I_{fixed} - \bar{I}_{fixed})(I_{moving} - \bar{I}_{moving})}{\sqrt{\sum (I_{fixed} - \bar{I}_{fixed})^2 \sum (I_{moving} - \bar{I}_{moving})^2}} $$
    where $\bar{I}$ denotes the mean intensity of the image [S1].
2.  **Loss Function:**
    $$ L = -\text{ZNCC}(I_{fixed}, I_{moving}) $$
    The goal is to minimize $L$ [S1].
3.  **Gradient Descent Update:**
    $$ v_t = \lambda v_{t-1} + \nabla_\eta L $$
    $$ \eta_{t+1} = \eta_t - \beta \odot v_t $$
    where $\beta = [\beta_{\theta\phi\gamma}, \beta_{\theta\phi\gamma}, \beta_{\theta\phi\gamma}, \beta_{xyz}, \beta_{xyz}, \beta_{xyz}]$ is the learning rate vector applied element-wise to $v_t$ [S1].

### Parameters
*   **Learning Rate (Rotations) $\beta_{\theta\phi\gamma}$:** $5.3 \times 10^{-2}$ [S1].
*   **Learning Rate (Translations) $\beta_{xyz}$:** $7.5 \times 10^{1}$ (75) [S1].
*   **Momentum $\lambda$:** $0.9$ [S1].
*   **Convergence Threshold:** Negative ZNCC $< -0.999$ [S1].
*   **Maximum Iterations $N_{max}$:** 250 [S1].

### Steps
1.  Initialize $\eta$ with random values sampled from a broad distribution (e.g., $\pm 120^\circ$ for rotations, $\pm 60$ mm for translations) [S1].
2.  Initialize velocity $v = 0$ [S1].
3.  Loop $t$ from 0 to $N_{max}-1$:
    a. Generate $I_{moving}$ from $\eta$ using the auto-differentiable DRR generator [S1].
    b. Compute Loss $L = -\text{ZNCC}(I_{fixed}, I_{moving})$ [S1].
    c. Compute gradients $\nabla_\eta L$ via backpropagation through the DRR generator [S1].
    d. Update velocity: $v = \lambda v + \nabla_\eta L$ [S1].
    e. Update parameters: $\eta = \eta - \beta \odot v$ [S1].
    f. If $L < -0.999$, break and return $\eta$ [S1].
4.  If the loop completes without convergence, return current $\eta$ (treated as failure) [S1].

### Pseudocode
```python
class Tensor:
    """Minimal self-contained tensor for autodiff-compatible operations."""
    def __init__(self, data): self.data = list(data); self.grad = [0.0]*len(self.data)
    def mean(self): return sum(self.data)/len(self.data)
    def sum(self): return sum(self.data)
    def __sub__(self, o): return Tensor([a-b for a,b in zip(self.data, o.data)])
    def __mul__(self, o): return Tensor([a*b for a,b in zip(self.data, o.data)])
    def __pow__(self, n): return Tensor([a**n for a in self.data])
    def backward(self): pass # Hook for automatic differentiation

def gradient_descent_zncc_registration(I_fixed, generate_drr, eta_init,
                                     beta_rot=0.053, beta_trans=75.0,
                                     momentum=0.9, max_iter=250,
                                     threshold=-0.999):
    eta = Tensor(list(eta_init))
    v = [0.0] * 6
    beta = [beta_rot, beta_rot, beta_rot, beta_trans, beta_trans, beta_trans]

    for t in range(max_iter):
        I_moving = generate_drr(eta)
        mean_f = I_fixed.mean()
        mean_m = I_moving.mean()
        diff_f = I_fixed - mean_f
        diff_m = I_moving - mean_m
        numerator = (diff_f * diff_m).sum()
        denominator = ((diff_f**2).sum() * (diff_m**2).sum())**0.5
        zncc = numerator / denominator
        loss = -zncc

        if loss < threshold:
            return eta.data, True

        loss.backward()
        grad = eta.grad
        for i in range(6):
            v[i] = momentum * v[i] + grad[i]
            eta.data[i] -= beta[i] * v[i]
        eta.grad = [0.0] * 6

    return eta.data, False
```

### Edge Cases and Pitfalls
*   **Local Minima:** The algorithm can get stuck in local minima if the initialization is too far from the global optimum, resulting in a low negative ZNCC that does not improve [S1]. Example: An estimated DRR orthogonal to the sagittal plane, resembling a coronal view [S1].
*   **Precision:** The loss landscape is locally convex around the optimal parameters, but global convexity is not guaranteed [S1].
*   **Fixed Parameters:** Source-to-detector distance and pixel dimensions are assumed fixed; optimizing them is not supported in this specific configuration [S1].

### Measured Performance
*   **Hardware/Scene:** CT Volume Size: $360 \text{ mm} \times 360 \text{ mm} \times 332.5 \text{ mm}$ [S1].
*   **Convergence Rate:** 745 out of 1,000 randomly initialized DRRs converged [S1].
*   **Average Iterations:** $65.48 \pm 14.27$ [S1].
*   **Average Time:** $1.92 \pm 0.43$ seconds [S1].

### Strengths and Limitations
*   **Strengths:** Fast convergence (average ~65 iterations); leverages locally convex loss landscape of ZNCC; simple implementation using standard gradient descent with momentum [S1].
*   **Limitations:** Susceptible to local minima; requires good initialization or a global stage (like the parent pipeline's $L_N$) to avoid failure; limited to 6 DoF with fixed geometry parameters [S1].

### When to Use
*   Use for local refinement when a reasonable initial pose is available or after a global optimization stage [S1].
*   Suitable when differentiable DRR generation is available and computational resources allow for iterative gradient computation [S1].

## Background

### Origin
The method was introduced in the paper "Fast Auto-Differentiable Digitally Reconstructed Radiographs for Solving Inverse Problems in Intraoperative Imaging" [S1]. It utilizes auto-differentiable DRR generation to enable gradient-based optimization for slice-to-volume registration [S1].

### History and Development
The approach builds on the observation that image similarity metrics like Negative ZNCC and L2 norm produce locally convex loss landscapes around the optimal parameters, making them suitable for gradient descent optimization [S1]. The study demonstrated that basic gradient descent with momentum could effectively solve the 6 DoF registration problem from random initializations within a convex neighborhood [S1].

### Usage
Used in intraoperative imaging contexts for slice-to-volume registration, particularly where fast, differentiable DRR generation is available [S1].
