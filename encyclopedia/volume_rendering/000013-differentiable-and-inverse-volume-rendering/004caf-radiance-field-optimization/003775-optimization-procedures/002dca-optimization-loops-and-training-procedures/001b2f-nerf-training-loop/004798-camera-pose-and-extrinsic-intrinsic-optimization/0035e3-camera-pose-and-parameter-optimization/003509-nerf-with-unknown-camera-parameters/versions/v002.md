# NeRF with Unknown Camera Parameters

Also called: Joint optimisation of NeRF and camera parameters, NeRF with unknown cameras, NeRF-- (NeRF without known camera parameters)

## Overview
NeRF with Unknown Camera Parameters (NeRF--) is a method that jointly optimizes camera parameters along with a Neural Radiance Field (NeRF) model on a sparse set of forward-facing views, eliminating the need for pre-estimated camera poses [S1, unofficial]. Unlike baseline NeRF which requires ground-truth camera intrinsics and extrinsics, NeRF-- treats camera parameters as trainable variables within a fully differentiable pipeline, enabling joint optimization by minimizing the reconstruction loss [S1, unofficial]. It sets itself apart from siblings like BARF by optimizing all camera parameters simultaneously from initialization, rather than using a coarse-to-fine frequency scheduling strategy [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ input images $\{I_i\}_{i=1}^N$ with unknown camera parameters.
*   **Outputs:** A trained NeRF model $F_\Theta$ and optimized camera parameters $\{\pi_i\}_{i=1}^N$ for each image, where $\pi_i = (\hat{f}, \hat{\phi}_i, \hat{t}_i)$.

**Data Structures:**
*   **NeRF Model ($F_\Theta$):** A multi-layer perceptron (MLP) mapping 3D coordinates and viewing directions to color and density.
    *   Hidden layer dimension: 128 [S1, unofficial].
    *   Input: 3D position $\mathbf{x}$, viewing direction $\mathbf{d}$.
    *   Output: Color $\mathbf{c}$, density $\sigma$.
*   **Camera Parameters ($\pi_i$):**
    *   Focal length $\hat{f}$: Scalar trainable parameter.
    *   Rotation $\hat{\phi}_i$: Axis-angle vector $\in \mathbb{R}^3$.
    *   Translation $\hat{t}_i$: Vector $\in \mathbb{R}^3$.

**Numbered Steps:**
1.  **Initialization:**
    *   Initialize NeRF model weights using Kaiming initialization [S1, unofficial].
    *   Initialize all camera poses at the origin $(0,0,0)$ looking down the $-z$ axis.
    *   Initialize focal length $\hat{f}$ to the image width $W$ [S1, unofficial].
2.  **Ray Generation:** For each pixel $p$ with coordinates $(u, v)$ in image $I_i$:
    *   Compute ray direction $\hat{d}_{i,p}$ using current camera estimates $\hat{\pi}_i = (\hat{f}, \hat{\phi}_i, \hat{t}_i)$:
        $$ \hat{d}_{i,p} = \hat{R}_i \begin{pmatrix} (u - W/2)/\hat{f} \\ -(v - H/2)/\hat{f} \\ -1 \end{pmatrix} $$
        where $\hat{R}_i$ is the rotation matrix computed from axis-angle vector $\hat{\phi}_i$ using Rodrigues' formula [S1, unofficial].
    *   Set ray origin $\hat{o}_i = \hat{t}_i$ [S1, unofficial].
    *   Define ray $\hat{r}_{i,p}(h) = \hat{o}_i + h\hat{d}_{i,p}$.
3.  **Volume Rendering:**
    *   Sample $K=128$ 3D points $\{x_j\}$ along the ray [S1, unofficial].
    *   Evaluate radiance colors $\{c_j\}$ and density values $\{\sigma_j\}$ from $F_\Theta$ [S1, unofficial].
    *   Aggregate predicted radiance and densities to compute pixel color $\hat{C}_i(p)$ using the standard volume rendering equation [S1, unofficial].
4.  **Loss Computation:**
    *   Randomly select $M=1024$ pixels per image [S1, unofficial].
    *   Compute reconstruction loss (e.g., Mean Squared Error) between rendered colors $\hat{C}_i(p)$ and ground-truth colors $C_i(p)$ for the selected pixels [S1, unofficial].
5.  **Gradient Update:**
    *   Backpropagate gradients through the rendering equation to update NeRF parameters $\Theta$ and camera parameters $\{\pi_i\}$ [S1, unofficial].
    *   Use separate Adam optimizers for NeRF, camera poses, and focal lengths [S1, unofficial].

```python
def train_neRF_with_unknown_cameras(images, num_epochs=10000, M=1024, K=128):
    """
    Jointly optimize NeRF and camera parameters.
    images: list of ground truth images
    """
    # Initialize NeRF model with Kaiming initialization
    nerf_model = NeRFModel(hidden_dim=128)
    nerf_model.apply(kaiming_init)
    
    N = len(images)
    H, W = images[0].shape[1], images[0].shape[2]
    
    # Initialize camera parameters
    # All cameras at origin, looking at -z, focal length = image width
    focal_lengths = torch.ones(N) * W
    axis_angles = torch.zeros(N, 3)
    translations = torch.zeros(N, 3)
    
    # Separate optimizers
    optimizer_nerf = optim.Adam(nerf_model.parameters(), lr=0.001)
    optimizer_poses = optim.Adam([axis_angles, translations], lr=0.001)
    optimizer_focal = optim.Adam([focal_lengths], lr=0.001)
    
    for epoch in range(num_epochs):
        total_loss = 0
        
        for i in range(N):
            # Randomly select M pixels
            u_coords = torch.randint(0, W, (M,))
            v_coords = torch.randint(0, H, (M,))
            
            # Compute ray directions
            # R_i from axis_angles[i] using Rodrigues' formula
            R_i = rodrigues(axis_angles[i])
            
            # Ray direction calculation
            # d_hat = R_i * [(u - W/2)/f, -(v - H/2)/f, -1]^T
            u_norm = (u_coords.float() - W/2) / focal_lengths[i]
            v_norm = (-(v_coords.float() - H/2) / focal_lengths[i])
            dirs_local = torch.stack([u_norm, v_norm, torch.ones(M)], dim=1) # (M, 3)
            ray_dirs = torch.matmul(R_i, dirs_local.t()).t() # (M, 3)
            
            ray_origins = translations[i].unsqueeze(0).expand(M, -1) # (M, 3)
            
            # Render rays
            rendered_colors = []
            for j in range(M):
                color = render_ray(ray_origins[j], ray_dirs[j], nerf_model, K)
                rendered_colors.append(color)
            rendered_colors = torch.stack(rendered_colors, dim=0) # (M, 3)
            
            # Compute loss
            gt_colors = images[i][v_coords, u_coords] # (M, 3)
            loss = torch.mean((rendered_colors - gt_colors) ** 2)
            
            total_loss += loss
            
            # Backpropagation
            optimizer_nerf.zero_grad()
            optimizer_poses.zero_grad()
            optimizer_focal.zero_grad()
            
            loss.backward()
            
            optimizer_nerf.step()
            optimizer_poses.step()
            optimizer_focal.step()
        
        # Learning rate decay
        if (epoch + 1) % 10 == 0:
            for param_group in optimizer_nerf.param_groups:
                param_group['lr'] *= 0.9954
        
        if (epoch + 1) % 100 == 0:
            for param_group in optimizer_poses.param_groups:
                param_group['lr'] *= 0.9
            for param_group in optimizer_focal.param_groups:
                param_group['lr'] *= 0.9

    return nerf_model, axis_angles, translations, focal_lengths
```

**Parameters:**
*   Hidden layer dimension: 128 [S1, unofficial].
*   Pixels sampled per image ($M$): 1024 [S1, unofficial].
*   Points sampled along each ray ($K$): 128 [S1, unofficial].
*   Initial learning rate: 0.001 for all optimizers [S1, unofficial].
*   NeRF learning rate decay: Every 10 epochs, multiply by 0.9954 [S1, unofficial].
*   Pose and focal length learning rate decay: Every 100 epochs, multiply by 0.9 [S1, unofficial].
*   Training duration: 10,000 epochs [S1, unofficial].

**Edge Cases and Pitfalls:**
*   Joint optimization may trap into local minima for certain scenes (e.g., Orchids, Room), resulting in inaccurate intrinsics and worse Novel View Synthesis (NVS) quality compared to baseline [S1, unofficial].
*   Initialization is critical; random initialization often leads to divergence [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training requires 10,000 epochs with separate optimizers for NeRF, poses, and focal lengths, increasing computational cost compared to fixed-camera NeRF [S1, unofficial].
*   **Memory Complexity:** Reduced hidden layer dimension (128 vs 256) and no hierarchical sampling reduce memory usage [S1, unofficial].
*   **Performance:** Achieves comparable NVS quality to baseline NeRF (using COLMAP poses) with $\Delta$SSIM and $\Delta$LPIPS $\approx 0.05$ [S1, unofficial].
*   **Strengths:** Eliminates the need for pre-estimated camera poses (e.g., from COLMAP) [S1, unofficial].
*   **Limitations:** Sensitive to initialization; prone to local minima in complex scenes [S1, unofficial].
*   **When to use:** When camera parameters are unknown or unreliable, and the scene is forward-facing [S1, unofficial].
*   **When not to use:** When high-precision camera poses are available or when real-time performance is critical [S1, unofficial].

## Background
NeRF-- was introduced in the paper "NeRF--: Neural Radiance Fields Without Known Camera Parameters" [S1, unofficial]. It addresses the limitation of original NeRF, which requires accurate camera poses and intrinsics, typically obtained via Structure-from-Motion (SfM) tools like COLMAP. The method was evaluated on the Blender Forward Facing (BLEFF) dataset, a synthetic dataset containing 14 path-traced scenes with rotation and translation perturbations [S1, unofficial].
