# NeRV Training
Also called: NeRV loss minimization, NeRV optimization

## Overview
NeRV training optimizes a continuous volumetric representation that decouples scene geometry (shape) from material appearance (reflectance) and lighting interactions (visibility) to enable efficient relighting and view synthesis [S1]. It differs from standard NeRF training by introducing a separate visibility MLP that predicts ray visibility and termination depth, supervised by consistency terms with the primary shape MLP rather than ground-truth labels, allowing the simulation of direct and one-bounce indirect illumination within the training loop [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of posed RGB images of a scene and corresponding lighting environment maps [S1].
*   **Outputs:** Weights for three MLPs: Shape/Reflectance MLP ($\theta$) and Visibility MLP ($\phi$) [S1].

**Data Structures:**
1.  **Positional Encoding:** Inputs are mapped using NeRF's positional encoding [S1].
    *   3D coordinates $\mathbf{x}$: Maximum frequency $L_{\text{coord}} = 7$ (frequencies $2^0$ to $2^7$) [S1].
    *   3D direction vectors $\boldsymbol{\omega}$: Maximum frequency $L_{\text{dir}} = 4$ (frequencies $2^0$ to $2^4$) [S1].
2.  **Shape and Reflectance MLP ($\theta$):**
    *   Architecture: 8 fully-connected ReLU layers with 256 channels each [S1].
    *   Input: Encoded $\mathbf{x}$ and $\boldsymbol{\omega}$ [S1].
    *   Output: Volume density $\sigma$ and reflectance properties [S1].
3.  **Visibility MLP ($\phi$):**
    *   Stage 1: 8 fully-connected ReLU layers with 256 channels each map encoded $\mathbf{x}$ to an 8-dimensional feature vector [S1].
    *   Stage 2: Concatenation with encoded $\boldsymbol{\omega}$ [S1].
    *   Stage 3: 4 fully-connected ReLU layers with 128 channels each [S1].
    *   Output: Predicted visibility $\tilde{V}_\phi$ and expected termination depth $\tilde{D}_\phi$ [S1].

**Training Procedure:**
1.  **Initialization:** Initialize $\theta$ and $\phi$ from scratch [S1].
2.  **Ray Sampling:** At each iteration, randomly sample a batch of 512 pixel rays $\mathcal{R}$ from input images and 256 random rays $\mathcal{R}'$ intersecting the volume [S1].
3.  **Forward Pass (Pixel Rays $\mathcal{R}$):** Render pixels using the current NeRV model (Shape/Reflectance MLPs) to obtain rendered radiance $\tilde{L}(\mathbf{r})$ [S1].
4.  **Forward Pass (Random Rays $\mathcal{R}'$):** For each ray $\mathbf{r}' \in \mathcal{R}'$, compute visibility $V_\theta(\mathbf{r}'(t))$ and expected termination depth $D_\theta(\mathbf{r}'(t))$ implied by the Shape MLP's density $\sigma$ at each location and in either direction along the ray [S1]. Query the Visibility MLP to get predictions $\tilde{V}_\phi(\mathbf{r}'(t))$ and $\tilde{D}_\phi(\mathbf{r}'(t))$ [S1].
5.  **Loss Computation:** Define tone-mapping operator $\tau(x) = x/(1+x)$ [S1]. Compute total loss $\mathcal{L}$:
    $$ \mathcal{L} = \sum_{\mathbf{r} \in \mathcal{R}} \left\| \tau(\tilde{L}(\mathbf{r})) - \tau(L(\mathbf{r})) \right\|_2^2 + \lambda \sum_{\mathbf{r}' \in \mathcal{R} \setminus \mathcal{R}_{\text{ret}}} \left( \left\| \tilde{V}_\phi(\mathbf{r}'(t)) - V_\theta(\mathbf{r}'(t)) \right\|_2^2 + \left\| \tilde{D}_\phi(\mathbf{r}'(t)) - D_\theta(\mathbf{r}'(t)) \right\|_2^2 \right) $$
    where $\lambda = 20$ [S1]. Apply a stop gradient to $V_\theta$ and $D_\theta$ in the consistency terms so the shape MLP is not encouraged to degrade its own performance to better match the visibility MLP output [S1].
6.  **Optimization:** Update $\theta$ and $\phi$ using the Adam optimizer for 1,000,000 total iterations [S1].

**Pseudocode:**
```python
import jax.numpy as jnp
from jax import value_and_grad

# Hyperparameters
BATCH_SIZE_PIXEL = 512
BATCH_SIZE_RANDOM = 256
LAMBDA = 20
LR_INIT = 1e-5
LR_DECAY_TARGET = 1e-6
BETA_1 = 0.9
BETA_2 = 0.999
EPSILON = 1e-8
TOTAL_ITERATIONS = 1_000_000
NUM_SAMPLES = 256

def positional_encoding(x, max_freq_log2):
    """Standard NeRF positional encoding [G]."""
    scales = jnp.array([2**i for i in range(max_freq_log2 + 1)])
    x = jnp.expand_dims(x, axis=-1) * scales
    return jnp.concatenate([jnp.sin(x), jnp.cos(x)], axis=-1)

def mlp_forward(params, x):
    """Standard fully-connected ReLU MLP forward pass [G]."""
    for W, b in params:
        x = jnp.dot(x, W) + b
        x = jnp.maximum(0, x)
    return x

def shape_reflectance_mlp(params, x_enc, omega_enc):
    """8 FC ReLU layers, 256 channels. Returns sigma and reflectance [S1]."""
    return mlp_forward(params, jnp.concatenate([x_enc, omega_enc], axis=-1))

def visibility_mlp(params, x_enc, omega_enc):
    """
    Stage 1: 8 FC ReLU (256 ch) -> 8-dim vector.
    Concat with omega_enc.
    Stage 2: 4 FC ReLU (128 ch) -> returns V, D [S1].
    """
    feat = mlp_forward(params['stage1'], x_enc)
    combined = jnp.concatenate([feat, omega_enc], axis=-1)
    return mlp_forward(params['stage2'], combined)

def compute_visibility_and_depth(sigma, t_samples, delta):
    """
    Compute visibility V and expected termination depth D from density sigma [S1].
    V(x, c) = exp(-sum_{s < t} sigma(x(s)) * delta)
    D is expected termination depth.
    """
    transmittance = jnp.exp(-jnp.cumsum(sigma * delta, axis=-1))
    visibility = transmittance
    alpha = 1 - jnp.exp(-sigma * delta)
    weights = alpha * transmittance
    depth = jnp.sum(t_samples * weights, axis=-1) / (jnp.sum(weights, axis=-1) + 1e-8)
    return visibility, depth

def tone_mapping(x):
    return x / (1 + x)

def adam_step(params, grad, state, lr):
    """Standard Adam optimizer step [G]."""
    m = BETA_1 * state['m'] + (1 - BETA_1) * grad
    v = BETA_2 * state['v'] + (1 - BETA_2) * grad**2
    m_hat = m / (1 - BETA_1**state['t'])
    v_hat = v / (1 - BETA_2**state['t'])
    new_params = params - lr * m_hat / (jnp.sqrt(v_hat) + EPSILON)
    return new_params, {'m': m, 'v': v, 't': state['t'] + 1}

def loss_fn(params_shape, params_vis, batch_rays, batch_random_rays, gt_images):
    # 1. Pixel Ray Loss
    # Render pixels using shape/reflectance MLP with 256 stratified samples [S1]
    t = jnp.linspace(0, 1, NUM_SAMPLES)
    delta = t[1] - t[0]
    points = batch_rays[:, None, :] + t[None, :, None] * batch_rays[:, None, :]
    x_enc = positional_encoding(points, 7)
    omega_enc = positional_encoding(batch_rays, 4)
    sigma = shape_reflectance_mlp(params_shape, x_enc, omega_enc)
    rendered_radiance = jnp.sum(sigma * delta, axis=-1) # Simplified volume rendering [G]
    pixel_loss = jnp.sum(jnp.square(tone_mapping(rendered_radiance) - tone_mapping(gt_images)))

    # 2. Random Ray Consistency Loss
    points = batch_random_rays[:, None, :] + t[None, :, None] * batch_random_rays[:, None, :]
    x_enc = positional_encoding(points, 7)
    omega_enc = positional_encoding(batch_random_rays, 4)
    sigma = shape_reflectance_mlp(params_shape, x_enc, omega_enc)
    v_theta, d_theta = compute_visibility_and_depth(sigma, t, delta)

    x_enc_vis = positional_encoding(points, 7)
    omega_enc_vis = positional_encoding(batch_random_rays, 4)
    v_phi, d_phi = visibility_mlp(params_vis, x_enc_vis, omega_enc_vis)

    # Stop gradient on V_theta and D_theta [S1]
    consistency_loss = jnp.sum(jnp.square(v_phi - v_theta)) + jnp.sum(jnp.square(d_phi - d_theta))
    return pixel_loss + LAMBDA * consistency_loss

def train():
    # Initialize params_shape, params_vis from scratch [S1]
    # Initialize Adam state with lr=1e-5, beta1=0.9, beta2=0.999, eps=1e-8 [S1]
    # Sample 512 pixel rays and 256 random rays intersecting volume [S1]
    # Get ground truth pixels for sampled rays [S1]
    lr = LR_INIT
    for i in range(TOTAL_ITERATIONS):
        lr = max(LR_DECAY_TARGET, lr * 0.999) # Exponential decay to 1e-6 [S1]
        loss, grads = value_and_grad(loss_fn)(params_shape, params_vis, batch_rays, batch_random_rays, gt_images)
        params_shape, state = adam_step(params_shape, grads['shape'], state, lr)
        params_vis, state = adam_step(params_vis, grads['vis'], state, lr)
```

**Parameters:**
*   **Batch Size (Pixel Rays):** 512 [S1].
*   **Batch Size (Random Rays):** 256 [S1].
*   **Loss Weight ($\lambda$):** 20 [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** Starts at $10^{-5}$, decays exponentially to $10^{-6}$ [S1].
*   **Adam Hyperparameters:** $\beta_1 = 0.9$, $\beta_2 = 0.999$, $\epsilon = 10^{-8}$ [S1].
*   **Total Iterations:** 1,000,000 [S1].

**Edge Cases and Pitfalls:**
*   **Stop Gradient:** The shape MLP must not be updated via the consistency loss terms to prevent it from degrading its rendering quality to match the visibility MLP [S1].
*   **$\mathcal{R}_{\text{ret}}$:** The set $\mathcal{R}_{\text{ret}}$ is subtracted from the random rays in the consistency loss. The exact criteria for exclusion are not provided in the sources [S1].
*   **Visibility Supervision:** The visibility MLP is not supervised by ground-truth visibility or depth. It is only optimized for consistency with the shape MLP's current geometry estimate [S1].

## Operating characteristics
*   **Time Complexity:** Rendering involves 256 stratified samples per ray [S1]. The visibility MLP adds computational overhead but reduces the complexity of computing direct and indirect illumination from quadratic and cubic to linear, enabling the simulation of direct illumination from environment lighting and one-bounce indirect illumination within the training loop [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Hardware:** Implemented in JAX and trained on 128 TPU cores [S1].
*   **Strengths:** Enables simulation of direct illumination from environment lighting and one-bounce indirect illumination within the training loop [S1]. Decouples geometry and appearance for relighting [S1].
*   **Limitations:** Requires posed RGB images and corresponding lighting environments for each scene [S1]. The visibility MLP is not supervised by ground truth, relying solely on consistency with the shape MLP [S1].

## Background
NeRV (Neural Reflectance and Visibility Fields) was introduced in the paper "NeRV: Neural Reflectance and Visibility Fields for Relighting and View Synthesis" [S1]. The method was developed to address the limitations of standard NeRF in handling relighting and complex lighting interactions by explicitly modeling visibility and reflectance fields [S1]. It builds on the NeRF training loop but adds the visibility MLP and consistency losses [S1].
