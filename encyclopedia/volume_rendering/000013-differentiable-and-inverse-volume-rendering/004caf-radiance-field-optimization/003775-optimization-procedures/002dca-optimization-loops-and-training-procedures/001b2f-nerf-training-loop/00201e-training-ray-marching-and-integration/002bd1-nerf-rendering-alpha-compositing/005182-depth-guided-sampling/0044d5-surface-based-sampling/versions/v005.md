# Surface-Based Sampling

Also called: Near-Surface Sampling

## Overview
Surface-Based Sampling is a sampling strategy that restricts 3D point sampling to the region close to the surface of an object, rather than sampling throughout the entire volume or free space [S1]. It solves the problem of quality degradation caused by sampling in irrelevant regions (free space or occluded areas) by leveraging depth priors to focus computational resources on the object's geometry [S1]. It sets itself apart from standard NeRF by eliminating the need to sample empty space, and from its siblings in the Depth-Guided Sampling family by specifically defining a fixed-width bin around the estimated depth $d$ for stratified sampling [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Depth value $d$ for a specific ray (from a depth image or point cloud), half-sampling range $\alpha$, number of samples $N$.
*   **Outputs:** A set of $N$ sample locations $\{S_{r,1}, ..., S_{r,N}\}$ along the ray.

**Data Structures:**
*   **Depth Map:** A 2D array where each pixel $(u,v)$ stores the depth $d$ to the nearest surface.
*   **Point Cloud:** Generated from training depth images to provide depth estimates for novel views during inference [S1].

**Parameters:**
*   $\alpha$: Half of the specified sampling range. Determines sampling density. Typical values: $1/2$, $1/16$ [S1].
*   $N$: Number of sample points per ray. Typical value: $8$ [S1].
*   $\gamma$: Random offset for stratified sampling, drawn uniformly from $[0, 2\alpha/N]$ [S1].

**Algorithm Steps:**
1.  **Depth Acquisition:** Obtain the depth value $d$ for the current ray. During training, this comes from input depth images. During inference, it is generated from a point cloud derived from training views, potentially refined via hole filling [S1].
2.  **Calculate Start Point:** Compute the location of the point nearest to the camera within the sampling range:
    $$S_{r,0} = d - \alpha$$
3.  **Generate Samples:** For each sample index $n$ from $1$ to $N$:
    *   Generate a random number $\gamma \in [0, 2\alpha/N]$.
    *   Calculate the sample location:
        $$S_{r,n} = S_{r,0} + (n - 1) \frac{2\alpha}{N} + \gamma$$
4.  **Render:** Use the calculated sample points to query the NeRF network and integrate color/opacity [S1].

**Pseudocode:**
```python
def surface_based_sampling(depth_d, alpha, num_samples):
    """
    Generates sample locations along a ray centered around a depth value.
    
    Args:
        depth_d (float): Depth value to the surface.
        alpha (float): Half of the specified sampling range.
        num_samples (int): Number of sample points N.
        
    Returns:
        list: List of sample locations S_r,n.
    """
    # Calculate the start of the sampling range (nearest to camera)
    s_r_0 = depth_d - alpha
    
    samples = []
    bin_length = (2 * alpha) / num_samples
    
    for n in range(1, num_samples + 1):
        # Generate random offset gamma for stratified sampling
        # gamma is uniform in [0, bin_length]
        gamma = random.uniform(0, bin_length)
        
        # Calculate sample location
        # Formula: S_r,n = S_r,0 + (n - 1) * (2*alpha / N) + gamma
        sample_location = s_r_0 + (n - 1) * bin_length + gamma
        samples.append(sample_location)
        
    return samples
```

**Edge Cases and Pitfalls:**
*   **Depth Accuracy:** If the depth $d$ is poorly estimated, using a small $\alpha$ degrades rendering quality [S1]. The parameter $\alpha$ must be set considering the accuracy of the depth images [S1].
*   **Free Space Sampling:** Unlike standard NeRF, this method does not sample free space. If the depth estimate is significantly wrong, the sampling range may miss the object entirely [S1].

## Operating characteristics
*   **Time Complexity:** $O(N)$ per ray, where $N$ is the number of samples. The calculation of sample positions is constant time per sample.
*   **Memory Complexity:** $O(1)$ per ray for sample generation. Requires storage for depth maps or point clouds for novel view synthesis [S1].
*   **Performance:** Improves rendering accuracy (PSNR) by avoiding sampling in irrelevant free space and occluded regions [S1].
*   **Strengths:** Reduces noise and artifacts associated with sampling empty space; allows for denser sampling near the surface with fewer total samples if $\alpha$ is small [S1].
*   **Limitations:** Heavily dependent on the accuracy of the depth estimation. Poor depth leads to poor sampling [S1].
*   **When to use:** When accurate depth information is available (e.g., from stereo matching or LiDAR) and the scene contains significant empty space.
*   **When not to use:** When depth estimates are unreliable or noisy, as small $\alpha$ will degrade quality [S1].

## Background
Surface-Based Sampling was introduced in the paper "Improving Neural Radiance Fields Using Near-Surface Sampling with Point Cloud Generation" [S1]. The method addresses the inefficiency of standard NeRF, which samples uniformly or hierarchically across the entire volume, including free space [S1]. It builds on the idea that sampling density around the object surface is critical for quality [S1]. The approach involves an offline stage to generate a point cloud from training depth images and an online stage to refine depth for novel views using hole filling [S1].
