# Surface-Based Sampling

Also called: Near-Surface Sampling

## Overview
Surface-Based Sampling is a ray sampling strategy that restricts 3D point evaluation to a narrow volume surrounding the estimated surface of an object, rather than sampling uniformly across the entire ray segment or free space [S1]. It solves the problem of quality degradation caused by evaluating the neural radiance field in irrelevant regions (free space or occluded areas) by leveraging depth information to focus computational resources on the geometry [S1]. It differs from standard NeRF by eliminating sampling in empty space, and from hierarchical methods like [Coarse-to-Fine NeRF](3406-coarse-to-fine-nerf.md) by using explicit depth priors rather than a secondary network to determine sampling density [S1].

## How it works
**Inputs:**
- A depth value $d$ for each pixel/ray, representing the distance to the object surface [S1].
- A total number of sample points per ray $N$ [S1].
- A sampling range parameter $\alpha$, which defines the half-width of the sampling interval around the surface [S1].
- A random number $\gamma$ for stratified sampling [S1].

**Outputs:**
- A set of 3D sample locations $\{S_{r,1}, \dots, S_{r,N}\}$ along the ray, concentrated near the surface [S1].

**Data Structures:**
- The method does not define complex persistent data structures for the sampling step itself. However, the source notes an offline stage where a point cloud is generated from training depth images and saved for inference [S1]. At test time, this point cloud is used to generate depth images for novel views, which are then refined via hole filling [S1].

**Parameters:**
- $\alpha$: Half of the specified sampling range. Controls sampling density. As $\alpha$ decreases, sampling density near the surface increases [S1]. Typical values: $1/2$, $1/16$ [S1].
- $N$: Number of sample points for each ray. Typical value: $8$ [S1].
- $\gamma$: Random number generated uniformly between $0$ and $2\alpha/N$ [S1].

**Steps:**
1.  **Depth Acquisition:** Obtain or estimate the depth $d$ to the object surface for the current ray. During training, this is assumed to be available from the training set. During inference, it is generated from a saved point cloud and refined [S1].
2.  **Calculate Start Point:** Compute the location of the sample point nearest to the camera ($S_{r,0}$) using the formula:
    $$S_{r,0} = d - \alpha$$
    where $d$ is the depth value and $\alpha$ is half the sampling range [S1].
3.  **Calculate Sample Locations:** For each sample index $n$ from $1$ to $N$, compute the location $S_{r,n}$ using stratified sampling within the interval $[S_{r,0}, S_{r,0} + 2\alpha]$:
    $$S_{r,n} = S_{r,0} + (n - 1) \frac{2\alpha}{N} + \gamma$$
    where $\gamma$ is a random number in $[0, 2\alpha/N]$ [S1].
4.  **NeRF Evaluation:** Train or render the NeRF model using the calculated sample points $\{S_{r,1}, \dots, S_{r,N}\}$ [S1].

**Pseudocode:**
```python
def surface_based_sampling(depth_d, num_samples_N, alpha):
    """
    Generates sample locations along a ray concentrated near the surface.
    
    Args:
        depth_d (float): Depth value to the object surface.
        num_samples_N (int): Number of sample points per ray.
        alpha (float): Half of the specified sampling range.
        
    Returns:
        list: List of sample distances from the camera origin.
    """
    # Step 2: Calculate the start of the sampling range
    # S_r,0 = d - alpha
    start_point = depth_d - alpha
    
    # The total length of the sampling interval is 2 * alpha
    interval_length = 2.0 * alpha
    
    # Step 3: Generate N samples using stratified sampling
    samples = []
    for n in range(1, num_samples_N + 1):
        # Calculate the deterministic part of the position
        # (n - 1) * (2 * alpha / N)
        deterministic_offset = (n - 1) * (interval_length / num_samples_N)
        
        # Generate random jitter gamma in [0, 2*alpha/N]
        # Note: In a real implementation, this would be drawn from a uniform distribution
        # For the purpose of the formula definition, we assume gamma is provided or drawn.
        # Here we simulate the draw for completeness, though the source defines gamma as a variable.
        gamma = random.uniform(0, interval_length / num_samples_N)
        
        # S_r,n = S_r,0 + (n - 1) * (2*alpha / N) + gamma
        sample_location = start_point + deterministic_offset + gamma
        samples.append(sample_location)
        
    return samples
```

**Edge Cases and Pitfalls:**
- **Depth Accuracy:** If the depth $d$ is poorly estimated, using a small $\alpha$ will degrade rendering quality because the sampling range will miss the actual surface [S1]. The parameter $\alpha$ must be set considering the accuracy of the depth images [S1].
- **Free Space Sampling:** Standard NeRF samples in free space and occluded regions, which may degrade quality. This method avoids that by restricting sampling to the near-surface area [S1].

## Operating characteristics
- **Time Complexity:** Reduces the number of unnecessary MLP evaluations in free space compared to uniform sampling, potentially improving rendering quality for a fixed computational budget or allowing faster convergence [S1].
- **Memory Complexity:** Requires storage for depth images or a point cloud generated from training data [S1].
- **Strengths:** Prevents quality degradation caused by sampling in irrelevant regions (free space/occluded areas) [S1]. Can improve rendering performance without requiring a fine sampling process if the depth is accurate [S1].
- **Limitations:** Heavily dependent on the accuracy of the depth estimates. Poor depth estimation with small $\alpha$ leads to poor results [S1].
- **When to use:** When accurate depth information (from sensors or estimation) is available and the scene contains significant empty space or occlusions that standard NeRF samples inefficiently [S1].

## Background
Surface-Based Sampling was introduced in the paper "Improving Neural Radiance Fields Using Near-Surface Sampling with Point Cloud Generation" [S1]. The method addresses the inefficiency of standard NeRF, which samples uniformly along rays regardless of whether the ray passes through empty space or the object [S1]. By leveraging depth images to generate a point cloud and subsequently refining depth for novel views, the method focuses the neural network's capacity on the object's surface [S1].
