# VoxNeRF


## Overview
VoxNeRF is a neural rendering method that integrates explicit scene geometry priors (mesh, point cloud, or depth map) with implicit radiance field representation to improve sampling efficiency and reconstruction accuracy [S1]. It addresses the ill-posed nature of recovering 3D geometry from 2D images by using a Sparse Voxel Octree (SVO) to model geometric uncertainty, which guides a hybrid sampling strategy [S1]. Unlike standard NeRF methods that sample uniformly or via stratified noise, VoxNeRF concentrates samples near the estimated surface while maintaining coverage of free space, reducing computational waste in empty regions [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   Input images with known camera poses.
*   A scene geometry prior, which can be a mesh, point cloud, or depth map [S1].
*   Pseudo-depth labels $D$ derived from the geometry prior for regularization [S1].

**Outputs:**
*   Rendered RGB images for novel viewpoints.
*   Volume accumulated depth $\hat{D}$ [S1].

### Data Structures

**Sparse Voxel Octree (SVO)**
*   Represents the scene geometry prior [S1].
*   Each voxel is an axis-aligned bounding box with side length $v$ [S1].
*   Voxel vertex coordinates are encoded using 8-bit Morton codes to map 3D coordinates to 1D representations, preserving spatial locality and reducing memory consumption [S1].
*   Used to determine ray-surface intersections [S1].

**Multi-resolution Hash Grids (MHG)**
*   Represents the radiance field [S1].
*   Consists of several compact spatial hash tables indexed at different resolutions [S1].
*   Stores trainable feature vectors [S1].
*   Used to encode spatial features for the neural network [S1].

**Neural Network**
*   **Feature MLP:** Takes concatenated tri-linear interpolated outputs from MHG tables and view direction encoding $d_i$ as input, outputting density $\sigma_i$ and a hidden code [S1].
*   **Color MLP:** A 3-layer MLP that takes the hidden code concatenated with view direction encoding $d_i$ as input, outputting radiance $c_i$ [S1].

### Sampling Strategy
The sampling strategy divides points into an "important region" near the surface and a "remaining region" for the rest of the ray [S1].

1.  **Ray-Surface Intersection:** Find the first non-empty leaf voxel hit by the ray in the SVO. Let $z(p_i)$ be the hitting point distance of the ray and the voxel [S1].
2.  **Important Region:** Model the sampling region as a Gaussian distribution $\mathcal{N}(z(p_i), (\sqrt{3}v_i)^2)$, where $v_i$ is the voxel size [S1].
    *   The region length is $6\sqrt{3}v_i$, centered at $z(p_i)$ [S1].
    *   This captures 99.7% of the distribution, assuming the true surface lies within the cube defined by the voxel uncertainty [S1].
    *   Sample points uniformly within this region [S1].
3.  **Remaining Region:** Generate additional sampling points using uniform distributions for the rest of the ray:
    *   $U(0, z(p_i) - 3\sqrt{3}v_i)$
    *   $U(z(p_i) + 3\sqrt{3}v_i, \infty)$ [S1].

### Rendering and Loss

**Volume Rendering**
For each sample point $i$ with density $\sigma_i$, emitted radiance $c_i$, and distance to the next adjacent sample $\delta_i$:
*   Termination probability $\alpha_i$ and accumulated transmittance $T_i$ are computed as:
    $$ \alpha_i = 1 - \exp(-\delta_i \sigma_i) $$
    $$ T_i = \prod_{j<i} (1 - \alpha_j) $$
    *(Note: Source Eq. 2 contains a typo `1 - exp(1 - δi σi)`; standard volume rendering uses the negative exponent [S1]).*
*   Rendered color $C$ and accumulated depth $\hat{D}$ are:
    $$ C = \sum_i \alpha_i T_i c_i, \quad \hat{D} = \sum_i \alpha_i T_i z_i $$

**Loss Function**
The total loss $L$ is defined as:
$$ L = L_c + \lambda_d (L_d + L_{reg}) $$
where $L_c$ is the color reconstruction loss [S1].

**Robust Depth Loss ($L_d$)**
Let $\hat{D}$ be the volume accumulated depth and $D$ be the pseudo depth. Let $\beta = 0.1$ [S1].
$$
L_d =
\begin{cases}
\frac{1}{2} |\hat{D} - D|^2 & \text{if } |\hat{D} - D| < \beta \\
\frac{1}{2} |\hat{D} - D| + \ln\left(\frac{|\hat{D} - D|}{\beta}\right) & \text{if } |\hat{D} - D| \ge \beta
\end{cases}
$$
This loss uses a squared error for small differences and a logarithmic function for large differences to reduce sensitivity to outliers [S1].

**Regularization Loss ($L_{reg}$)**
Penalizes gradients across different scales to enforce smoothness:
$$ L_{reg} = \sum_{s=1}^{S} \sum_{i,j} M_{i,j} (|G_x^{(s)}| + |G_y^{(s)}|) $$
where $G_x^{(s)}$ and $G_y^{(s)}$ are gradient components at scale $s$, and $M_{i,j}$ is a mask [S1].

### Parameters
*   **Voxel Size ($v$):** Set to the maximal standard deviation $\sigma$ across all scene points in the geometry prior: $v = \max(\sigma_1, \sigma_2, \dots, \sigma_n)$ [S1].
*   **Batch Size:** 4,096 rays per batch [S1].
*   **Points per Ray:** 128 points in the important sampling region and 128 points in the remaining region [S1].
*   **Optimizer:** ADAM with learning rate 0.01 and exponential schedule [S1].
*   **Beta ($\beta$):** 0.1 [S1].

    """
    Renders a batch of rays using VoxNeRF sampling and volume integration.

        ray_origins: (B, 3) Array of ray origins.
        ray_directions: (B, 3) Array of ray directions.
        svos: Sparse Voxel Octree structures.

        feature_mlp: Function returning (hidden_codes, sigmas) from MHG features and view dirs.
        color_mlp: Function returning radiance from hidden codes and view dirs.
        params: Dictionary containing hyperparameters.

        colors: (B, 3) Rendered colors.
        depths: (B,) Accumulated depths.
    """
    B = ray_origins.shape[0]
    colors = np.zeros((B, 3))
    depths = np.zeros(B)
    max_dist = params.get('max_dist', 100.0)
    N_imp = 128
    N_rem = 128

    for i in range(B):
        # 1. Ray-Surface Intersection [S1]
        # Traverses SVO to find first non-empty leaf voxel intersection
        # Returns distance to intersection and voxel side length [G]

        # 2. Sampling [S1]
        half_width = 3.0 * np.sqrt(3.0) * v_i
        imp_min = z_pi - half_width
        imp_max = z_pi + half_width
        pts_imp = np.linspace(imp_min, imp_max, N_imp)

        rem_min = 0.0
        rem_max = max_dist
        # Split remaining points evenly between near and far intervals
        pts_near = np.linspace(rem_min, imp_min, N_rem // 2) if imp_min > rem_min else np.array([])
        pts_far = np.linspace(imp_max, rem_max, N_rem // 2) if rem_max > imp_max else np.array([])
        pts_rem = np.concatenate([pts_near, pts_far])

        all_pts = np.concatenate([pts_imp, pts_rem])
        pts_3d = ray_origins[i] + all_pts[:, None] * ray_directions[i]

        # 3. Network Query [S1]
        # Tri-linear interpolation across multi-resolution hash tables [S1]
        mhg_feats = _query_mhgs(mhgs, pts_3d)
        view_dirs = ray_directions[i][None, :]
        hidden_codes, sigmas = feature_mlp(mhg_feats, view_dirs)
        radiance = color_mlp(hidden_codes, view_dirs)

        # 4. Volume Rendering [S1, G]
        deltas = np.diff(all_pts, append=all_pts[-1] + 1e-6)
        alphas = 1.0 - np.exp(-sigmas * deltas)
        transmittances = np.cumprod(1.0 - alphas)
        transmittances = np.concatenate([[1.0], transmittances[:-1]])

        weights = alphas * transmittances
        colors[i] = np.sum(weights[:, None] * radiance, axis=0)
        depths[i] = np.sum(weights * all_pts)

    return colors, depths

## Operating characteristics
*   **Time Complexity:** Depends on the number of sampling points (256 per ray in the reported setup) and the cost of querying the Multi-resolution Hash Grids and MLPs [S1].
*   **Memory Complexity:** Dominated by the MHG tables and the SVO structure [S1].
*   **Performance:** Evaluated on ScanNet and ScanNet++ datasets. Trained for 30,000 iterations on a single 24GB NVIDIA RTX 4090 GPU [S1].
*   **Strengths:** Reduces unnecessary sampling in free space by focusing on the geometry prior. Handles noise in geometry priors via the Gaussian sampling model [S1].
*   **Limitations:** Relies on the quality of the geometry prior. If the prior is inaccurate, the sampling region may miss the true surface or include too much empty space [S1].
*   **When to use:** When a coarse geometry prior (point cloud, depth map) is available and efficient rendering is desired. Particularly useful in sparse-view settings [S1].

## Background
VoxNeRF was introduced to bridge the gap between voxel-based representations and neural radiance fields [S1]. It addresses the limitations of standard NeRF methods which often suffer from slow convergence and poor performance in textureless or ambiguous regions [S1]. By incorporating explicit geometry priors, it aims to provide a more robust and efficient rendering pipeline. The method was evaluated on real-world indoor datasets like ScanNet and ScanNet++ [S1].
