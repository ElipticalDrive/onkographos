# Surface-Based Sampling

Also called: Near-Surface Sampling

## Overview
Surface-based sampling is a strategy that restricts 3D point sampling to the area close to the surface of an object, rather than sampling throughout the entire volume or free space [S1]. It solves the problem of quality degradation caused by standard NeRF methods sampling in irrelevant regions such as free space or occluded areas [S1]. It sets itself apart from siblings like [Pixel Region and Depth Guided Ray Sampling](8866-pixel-region-and-depth-guided-ray-sampling.md) and [Truncated Depth-Based Sampling](10613-truncated-depth-based-sampling.md) by explicitly defining a fixed-width band around an estimated depth value $d$ for stratified sampling, rather than using pixel-region heuristics or hard truncation limits [S1].

## How it works
**Inputs:**
- Depth value $d$ for a specific ray (from a depth image or point cloud).
- Sampling range parameter $\alpha$ (half-width of the sampling band).
- Number of sample points $N$.

**Outputs:**
- A set of $N$ sample locations $\{S_{r,1}, ..., S_{r,N}\}$ along the ray.

**Data Structures:**
- The method does not define complex persistent data structures in the sampling step itself, but relies on a pre-generated point cloud (from depth images) to estimate $d$ for novel views [S1].

**Parameters:**
- $\alpha$: Half of the specified sampling range. Determines sampling density. Typical values: $1/2$, $1/16$ [S1].
- $N$: Number of sample points for each ray. Typical value: 8 [S1].
- $\gamma$: Random number for stratified sampling, generated uniformly between $0$ and $2\alpha/N$ [S1].

**Steps:**
1. Retrieve the depth value $d$ for the current ray. This $d$ represents the distance to the surface of the object [S1].
2. Calculate the starting location of the sampling range, $S_{r,0}$, which is the point nearest to the camera within the sampling band:
   $$S_{r,0} = d - \alpha$$
3. For each sample index $n$ from $1$ to $N$:
   a. Generate a random offset $\gamma$ uniformly distributed in $[0, 2\alpha/N]$ [S1].
   b. Calculate the sample location $S_{r,n}$:
      $$S_{r,n} = S_{r,0} + (n - 1) \frac{2\alpha}{N} + \gamma$$
4. Use the resulting points $\{S_{r,1}, ..., S_{r,N}\}$ to train or query the NeRF model [S1].

**Pseudocode:**
```python
def surface_based_sampling(d, alpha, N):
    """
    Generate N sample points near the surface defined by depth d.
    
    Args:
        d (float): Depth value (distance to surface) for the current ray.
        alpha (float): Half of the specified sampling range.
        N (int): Number of sample points.
        
    Returns:
        list[float]: List of N sample locations along the ray.
    """
    samples = []
    # Calculate the start of the sampling range
    s_r_0 = d - alpha
    
    # Bin width for stratified sampling
    bin_width = (2 * alpha) / N
    
    for n in range(1, N + 1):
        # Generate random offset gamma for stratified sampling
        # gamma is uniform in [0, bin_width]
        gamma = random.uniform(0, bin_width)
        
        # Calculate sample location
        # Formula: S_r,n = S_r,0 + (n - 1) * (2*alpha / N) + gamma
        s_r_n = s_r_0 + (n - 1) * bin_width + gamma
        samples.append(s_r_n)
        
    return samples
```

**Edge Cases and Pitfalls:**
- If the depth $d$ is poorly estimated, using a small $\alpha$ degrades rendering quality [S1].
- Recommendation: Set $\alpha$ considering the accuracy of the depth images. If depth accuracy is low, a larger $\alpha$ should be used to ensure the sampling band covers the actual surface [S1].

## Subtopics

### Depth Image Generation for Novel Views
At the test stage, depth images are unavailable. A point cloud is generated from training depth images and saved. For novel views, this point cloud is used to generate an initial depth image, which is then refined through computationally efficient hole filling to enable surface-based sampling [S1].

## Operating characteristics
- **Time Complexity**: Not given in the sources.
- **Memory Complexity**: Not given in the sources.
- **Measured Performance**: Experiments show that restricting sampling to the near-surface area improves rendering accuracy (PSNR) compared to standard NeRF which samples in free space and occluded regions [S1].
- **Scaling**: As $\alpha$ decreases, sampling density near the surface increases, potentially improving quality if depth is accurate [S1].
- **Strengths**: Prevents quality degradation caused by sampling in irrelevant regions (free space/occluded areas) [S1].
- **Limitations**: Highly dependent on the accuracy of the depth estimation. Poor depth estimates with small $\alpha$ lead to degraded quality [S1].

## Background
- **Origin**: The method was introduced in the paper "Improving Neural Radiance Fields Using Near-Surface Sampling with Point Cloud Generation" [S1].
- **History**: The authors observed that standard NeRF sampling in free space and occluded regions degrades rendering quality. They proposed sampling only around the object surface to improve performance without requiring a fine sampling process [S1].
- **Usage**: Used in NeRF training and novel view synthesis pipelines where depth information (either ground truth or estimated) is available or can be generated [S1].
