# Deceptive-NeRF/3DGS Pipeline

Also called: Deceptive-3DGS, Deceptive-NeRF

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that enhances NeRF or 3D Gaussian Splatting (3DGS) representations by continuously densifying input observations with synthetic pseudo-observations generated by a diffusion model during training [S1]. Unlike methods that rely on ensemble learning, variational inference, or spatial perturbations for uncertainty estimation, this approach acquires uncertainty through correspondence matching by reprojecting real input observations to novel views, thereby enforcing epipolar constraints with minimal additional computation [S1]. It sets itself apart by conditioning a 2D diffusion model on coarse rendered RGB images, depth maps, and view-consistency uncertainty maps to rectify artifacts and fill unobserved regions [S1].

## How it works

### Inputs and Outputs
*   **Inputs:** A set of $W$ input images $I = \{I_1, \dots, I_W\}$ with calibrated camera poses.
*   **Outputs:** An optimized radiance field representation (NeRF or 3DGS) and a set of generated pseudo-observations used for training.

### Data Structures
*   **Camera Parameters:** Intrinsic matrix $K$ and extrinsic parameters defining the pose of each input view.
*   **Rendered Data:** For any viewpoint, the renderer produces:
    *   RGB image $\hat{I}$.
    *   Depth map $D$.
    *   Uncertainty map $U$.
*   **Diffusion Model Inputs:** A 5-channel control map consisting of:
    *   3 channels for coarse RGB image $I_{coarse}$.
    *   1 channel for depth map $D$.
    *   1 channel for uncertainty map $U$.
*   **Text Embedding:** A composite feature $s = [s_0, s^*]$ where $s_0$ is a text prompt and $s^*$ is an optimized latent embedding.

### Method Steps

1.  **Initial Training:** Train a NeRF or 3DGS representation using the few-view input images $I$ with their calibrated poses for a set number of epochs to obtain a coarse reconstruction [S1].
2.  **Novel View Sampling:** Randomly sample a novel viewpoint $A$ within a bounding box defined by the outermost input views [S1].
3.  **Rendering:** At viewpoint $A$, render the coarse RGB image $\hat{I}_A$, depth map $D_A$, and uncertainty map $U_A$ [S1].
    *   **Depth Rendering:** Compute depth as a weighted composition of distances traveled:
        $$ \hat{\mathbf{D}} = \sum_{k=1}^K \hat{T}(t_k)\alpha (\sigma (t_k)\delta _k) $$
        where $\hat{T}(t_k)$ is transmittance, $\alpha$ is opacity, $\sigma$ is density, and $\delta_k$ is the distance traveled [S1].
4.  **Uncertainty Map Generation:** Enforce view consistency by warping the nearest input view $B$ to the novel view $A$ and comparing it to the rendered image [S1].
    *   Identify $B$ as the nearest input viewpoint to $A$.
    *   Compute the warped image $I_{B\rightarrow A}$ using the viewpoint difference $R_{B\rightarrow A}$ and depth $D_A$:
        $$ I_{B\rightarrow A} = \psi (I_B; D_A, R_{B\rightarrow A}) $$
    *   Transform pixel locations $p$ in $\hat{I}_A$ to $q$ in $I_B$ using the camera matrix $K$:
        $$ q = K R_{B\rightarrow A} D_A(p) K^{-1} p $$
    *   Define the uncertainty map $U_A$ as the squared distance between the warped image and the rendered image:
        $$ U_A = (I_{B \rightarrow A} - \hat {I}_A)^2 $$
5.  **Text Embedding Derivation:**
    *   Generate an initial text prompt $s_0$ using a pre-trained image captioning network [S1].
    *   Optimize a shared latent text embedding $s^*$ shared by all input observations and coarse images using textual inversion to counteract captioning errors on low-quality images [S1].
    *   Form the composite feature $s = [s_0, s^*]$ by concatenating the embeddings [S1].
6.  **Pseudo-Observation Generation:** Generate a refined natural image pseudo-observation $P_A$ using the Deceptive Diffusion Model $G$:
    $$ P_A = \operatorname {G}(\hat {I}_A, D_A, U_A) $$
    The model $G$ is a latent diffusion model (e.g., Stable Diffusion) fine-tuned with ControlNet [S1]. The conditioning embedding $c$ includes the coarse image, depth, uncertainty, and text embedding $s$ [S1].
7.  **Filtering:** Discard 20% of the generated pseudo-observations that have the lowest perceptual similarity to the input images, quantified via the LPIPS metric [S1]. This prevents generating content far from the original inputs [S1].
8.  **Accumulation and Optimization:** Accumulate the valid pseudo-observations. Continue training the NeRF/3DGS representation using a combination of the original real input images and the accumulated pseudo-observations [S1].
9.  **Iteration:** Repeat steps 2–8 until a sufficient number of observations are accumulated [S1].

def is_acceptable_quality(pseudo_obs, history, threshold_percentile=20):
    """
    Checks if pseudo_obs is in the top 80% of perceptual similarity to inputs.
    """
    # Calculate similarity to inputs
    similarities = [calculate_lpips(pseudo_obs, inp_img) for inp_img in input_images]
    current_min_sim = min(similarities)
    
    # If history is empty, accept
    if not history:
        return True
        
    # Calculate similarities for all history items
    history_sims = []
    for hist_obs in history:
        hist_sims = [calculate_lpips(hist_obs, inp_img) for inp_img in input_images]
        history_sims.append(min(hist_sims))
        
    # Determine threshold
    threshold = np.percentile(history_sims, threshold_percentile)
    
    # Accept if current similarity is above threshold

### Parameters
*   **Discard Rate:** 20% of pseudo-observations with the lowest perceptual similarity (LPIPS) are discarded [S1].
*   **ControlNet Channels:** 5 channels (3 for coarse RGB, 1 for depth, 1 for uncertainty) [S1].
*   **Image Resolution:** All images are randomly cropped to $512 \times 512$ resolution [S1].
*   **Training Dataset Size:** 200 scenes and approximately 20,000 images for the major section of the training dataset, with Hypersim and CO3D each contributing half [S1].
*   **Coarse NeRF Training Data:** Coarse NeRFs are trained only with one-fifth of input images [S1].
*   **Gaussian Noise Standard Deviation:** 0.3, added to 60,000 images from Hypersim for training data augmentation [S1].

### Edge Cases and Pitfalls
*   **Image Captioning Efficacy:** Image captioning efficacy diminishes for images of lower quality or those with pronounced artifacts. Textual inversion is used to optimize a shared latent text embedding to counteract this [S1].
*   **Noisy Data Augmentation:** When training with noisy RGB-depth data augmentation (adding Gaussian noise to RGB images), uncertainty maps are not fed into the diffusion model [S1].
*   **Precision:** The depth rendering formula relies on accurate transmittance and density estimation; errors here propagate to the uncertainty map [S1].

## Subtopics

### Deceptive Diffusion Model
*   **What it is:** A 2D latent diffusion model (e.g., Stable Diffusion) fine-tuned with ControlNet to generate pseudo-observations conditioned on coarse RGB, depth, and uncertainty maps.
*   **What sets it apart:** It explicitly uses an uncertainty map derived from view-consistency warping to guide generation, unlike standard inpainting models that only use masks or RGB context.
*   **When to choose it:** When high-fidelity texture synthesis is required for sparse-view inputs and computational resources allow for diffusion model inference.

## Operating characteristics

*   **Time Complexity:** The method requires iterative training loops where each iteration involves rendering, warping, diffusion inference, and gradient updates. The diffusion model inference is the most computationally expensive step per iteration.
*   **Memory Complexity:** Requires storing the NeRF/3DGS representation, the diffusion model weights, and the accumulated pseudo-observations. The dataset for fine-tuning the diffusion model (200 scenes, 20k images) is large but static.
*   **Measured Performance:** On the LLFF dataset, Deceptive-NeRF achieves a PSNR of 19.87 (3-view), 21.75 (6-view), and 23.22 (9-view). Deceptive-3DGS achieves 19.95 (3-view), 23.92 (6-view), and 24.15 (9-view). These results are competitive with or better than PixelNeRF, MVSNeRF, DietNeRF, RegNeRF, and FreeNeRF [S1].
*   **Strengths:**
    *   Enforces 3D consistency via uncertainty maps derived from epipolar constraints.
    *   Mitigates artifacts common in sparse-view NeRFs (e.g., floating artifacts) by leveraging diffusion priors.
    *   Does not modify the underlying NeRF/3DGS representation for uncertainty estimation, minimizing additional computation.
*   **Limitations:**
    *   Computationally intensive due to the need for diffusion model inference and fine-tuning.
    *   Relies on the quality of the pre-trained diffusion model and the accuracy of the depth estimation.
    *   Performance may degrade if the initial coarse reconstruction is too poor to provide meaningful conditioning signals.
*   **When to use it:** For high-quality novel view synthesis from very few input views (e.g., 3-9 views) where traditional multi-view stereo or NeRF methods struggle with missing data.
*   **When not to use it:** When real-time rendering is required, or when computational resources are limited, as the training process is significantly slower than standard NeRF training.

## Background

*   **Origin:** The method was introduced in the paper "Deceptive-NeRF/3DGS: Diffusion-Generated Pseudo-Observations for High-Quality Sparse-View Reconstruction" by X. Liu et al. [S1].
*   **History and Development:** The work builds on the success of NeRF and 3DGS for novel view synthesis and the recent application of diffusion models for image editing and inpainting. It addresses the limitation of sparse-view reconstruction by synthesizing additional training data (pseudo-observations) that are consistent with the input views.
*   **Usage:** It is used for few-shot novel view synthesis, super-resolution of novel views, and general sparse-view reconstruction tasks. It has been evaluated on datasets including Hypersim, ScanNet, LLFF, and Mip-NeRF 360 [S1].
