# DFF (Decomposing NeRF for Editing Via Feature Field Distillation)
Also called: Feature Field Distillation, LSeg-DFF, DINO-DFF

## Overview
DFF enables 3D semantic segmentation and editable novel-view synthesis by distilling features from a pre-trained 2D teacher network (such as LSeg or DINO) into a neural radiance field [S1]. It solves the problem of decomposing scenes into semantic regions for editing, addressing challenges in surface decomposition, volume decomposition, and handling unobserved parts [S1]. Unlike naive NeRF feature extraction, which is entangled with low-level factors like color and spatial adjacency, DFF provides robust semantic decomposition that supports multi-view consistent editing [S1]. It differs from optimization-based editing methods by providing a static, queryable feature field that allows for inference-time interception and selection without re-optimizing the radiance field for every edit [S1, Parent].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Training images $I$, camera poses, and optionally a 2D teacher network (LSeg or DINO). For editing, inputs include a query (text string for LSeg, image patch for DINO) and a threshold $\tau$.
*   **Outputs:** A radiance field $\mathcal{R}$ (density $\sigma$ and color $\mathbf{c}$) and a feature field $\mathcal{F}$ (semantic features $\mathbf{f}$). The feature field allows computing the probability $p$ that a 3D point belongs to a semantic class defined by the query.

**Data Structures and Layout:**
The method uses two primary neural network architectures, often sharing weights or trained jointly:

1.  **Radiance Field MLP ($\mathcal{R}$):**
    *   **Architecture:** 8 ReLU layers with 256 dimensions.
    *   **Outputs:**
        *   Density $\sigma$: Linear layer (1 output).
        *   Color $\mathbf{c}$: 3 ReLU layers (256 dim) $\to$ Linear layer (3 outputs, RGB).
        *   Feature $\mathbf{f}$: 3 ReLU layers (256 dim) $\to$ Linear layer (output dim depends on teacher, e.g., 256 for DINO, 512 for LSeg).
    *   **Positional Encoding (PE):** Length 10 for input coordinates $\mathbf{x}$ and skip connections; Length 4 for viewing direction $\mathbf{v}$ [S1].

2.  **Independent Feature Field MLP ($\mathcal{F}_{ind}$) (Optional):**
    *   Used to introduce DFF into existing NeRFs without retraining the radiance field.
    *   **Architecture:** 4 ReLU layers.
    *   **Skip Connection:** Included at the third layer if PE is used.
    *   **Smoothness Variant:** To achieve smooth volume decomposition, an independent MLP is trained *without* positional encoding [S1].

**Training Procedure:**
The training consists of two phases: initial radiance field training and feature field distillation.

1.  **Teacher Feature Extraction:**
    *   Encode each training image $I$ using the teacher network's image encoder to generate target feature maps $f_{img}(I, r)$ [S1].
    *   Resize target feature maps to the original image resolution (e.g., $320 \times 240$ for Replica, $1008 \times 756$ for others) because teacher networks output reduced-size features [S1].

2.  **Phase 1: Radiance Field Training (200K iterations):**
    *   Train the radiance field MLP to minimize photometric loss $L_p$ (e.g., $L_1$ loss between rendered and ground truth colors) [S1].
    *   **Sampling:** Hierarchical sampling with 64 coarse points and 128 fine points (total 192) [S1].
    *   **Optimizer:** Adam, linearly decaying learning rate from $5 \times 10^{-4}$ to $8 \times 10^{-5}$ [S1].
    *   **Noise:** Add Gaussian noise to the density $\sigma$ during training [S1].
    *   **Batch Size:** 1024 rays for Replica; 2048 rays for other datasets [S1].

3.  **Phase 2: Feature Field Distillation (5K iterations):**
    *   Add the feature branch to the radiance field (or train the independent feature field MLP).
    *   **Loss Function:** Minimize $L = L_p + \lambda L_f$, where $L_f$ is the feature loss [S1].
    *   **Feature Loss ($L_f$):** Mean squared error between the rendered feature field output and the resized teacher feature map $f_{img}(I, r)$ at the sampled points [S1].
    *   **Parameters:** Remove Gaussian noise from density. Set learning rate to $1 \times 10^{-4}$ [S1].
    *   **Sampling for Feature Training:** Use **coarse sampling** (64 points) for training the feature branch. This produces smoother segmentations and avoids high-frequency artifacts associated with fine sampling [S1]. Use coarse sampling for edited rendering as well, even if fine sampling is used for final high-quality view synthesis [S1].
    *   **Feature Loss Weight ($\lambda$):** Typical value not explicitly fixed, but increasing $\lambda$ by 10x hurts view synthesis without improving segmentation [S1].

**Inference and Editing:**
To edit a scene, a query is used to compute a selection probability $p_i$ for each sampled point $\mathbf{x}_i$ on a ray $\mathbf{r}$.

*   **LSeg-DFF (Text Query):**
    1.  Encode the text label using the LSeg text encoder to get a text feature vector $\mathbf{t}$ [S1].
    2.  Retrieve the feature vector $\mathbf{f}_i$ from the feature field at point $\mathbf{x}_i$.
    3.  Compute probability $p_i$ using cosine similarity (Equation 22 in source, typically softmax over similarities or normalized similarity) [S1].
    4.  If $p_i > \tau$, apply the editing transform $g$ to the density $\sigma_i$ or color $\mathbf{c}_i$ before volume rendering [S1, Parent].

*   **DINO-DFF (Image Patch Query):**
    1.  Select a query patch from a reference image.
    2.  Calculate the patch feature $\mathbf{q}$ by averaging the DINO features of all pixels in the patch [S1].
    3.  Retrieve feature $\mathbf{f}_i$ from the feature field at $\mathbf{x}_i$.
    4.  Compute cosine similarity $s = \text{cosine}(\mathbf{f}_i, \mathbf{q})$ [S1].
    5.  Apply hard thresholding:
        $$
        p_i = \begin{cases} 
        1 & \text{if } s > \tau \\
        0 & \text{otherwise}
        \end{cases}
        $$
    6.  Use $p_i$ to select points for editing [S1].

    """
    Computes probability for LSeg-DFF using cosine similarity.
    """
    # Normalize features
    f_norm = F.normalize(feature, p=2, dim=-1)
    t_norm = F.normalize(text_feature, p=2, dim=-1)
    sim = torch.sum(f_norm * t_norm, dim=-1)
    # Softmax or sigmoid thresholding as per Eq 22
    prob = torch.sigmoid(sim) # Simplified, actual Eq 22 may vary
    return prob

def compute_dino_probability(feature, query_feature, threshold=0.5):
    """
    Computes hard probability for DINO-DFF.

    prob = (sim > threshold).float()

## Operating characteristics
*   **Time Complexity:** Training requires 200K iterations for the radiance field and 5K for distillation. The distillation phase is short because the feature loss converges significantly faster than the photometric loss [S1].
*   **Memory Complexity:** The branch-based approach adds minimal overhead to the standard NeRF MLP (3 extra layers for features). The independent feature field approach adds a separate lightweight MLP (4 layers), which is useful for integrating DFF into existing models without retraining the radiance field [S1].
*   **Performance:** DFF achieves 3D semantic segmentation performance comparable to or better than supervised sparse 3D convolution models like MinkowskiNet42 [S1]. It produces multi-view consistent results for deletion/extraction, unlike image inpainting baselines like LaMa [S1].
*   **Strengths:**
    *   Enables zero-shot semantic segmentation via text (LSeg) or patch (DINO) queries [S1].
    *   Coarse sampling for feature training ensures smooth volume decomposition, reducing high-frequency artifacts [S1].
    *   Independent feature field allows editing of pre-trained NeRFs without retraining [S1].
*   **Limitations:**
    *   Deleting foreground objects can leave floating artifacts and blurred volumes in the far distance behind the deleted object [S1].
    *   Excessively high feature loss weight ($\lambda \times 10$) degrades view synthesis quality without improving segmentation [S1].
    *   Naive use of NeRF hidden layer features fails to decompose scenes robustly, leaking selections to regions with similar colors or geometry [S1].
    *   Fine sampling introduces high-frequency artifacts in segmentation; coarse sampling is preferred for decomposition [S1].

## Background
DFF was introduced in the paper "Decomposing NeRF for Editing Via Feature Field Distillation" [S1]. It addresses the limitations of editable NeRFs, which struggle with surface decomposition, volume decomposition, and estimating unobserved parts [S1]. The method leverages pre-trained 2D teacher networks, specifically LSeg [44] and DINO [12], to distill semantic knowledge into the 3D radiance field. This allows for 3D semantic segmentation without explicit 3D semantic labels, relying only on photometric and feature losses during training [S1].
