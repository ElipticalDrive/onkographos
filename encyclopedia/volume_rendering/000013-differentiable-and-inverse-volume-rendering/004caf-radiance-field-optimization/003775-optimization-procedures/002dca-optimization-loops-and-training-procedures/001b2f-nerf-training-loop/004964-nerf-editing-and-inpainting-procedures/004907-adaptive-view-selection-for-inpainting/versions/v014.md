# Adaptive View Selection for Inpainting

Also called: 3D Inpainting Component, 3D Inpainting Component with Adaptive View Selection, Adaptive Weight Inpainting, Gradient-Based View Selection

## Overview
This method addresses the inconsistency artifacts inherent in applying 2D inpainting directly to NeRFs by introducing a training view selection mechanism that leverages multi-view correlation [S1]. It distinguishes itself from pure 2D-inpainting approaches by dynamically deciding, per sub-region of the occluded area, whether to rely on the appearance prior from a pretrained 2D inpainter or to reconstruct the geometry and color from other visible views based on texture richness [S1].

## How it works
The method operates within a NeRF framework where an MLP $f_\theta$ maps 3D coordinates $\mathbf{x}$ and viewing directions $\mathbf{d}$ to density $\sigma$ and color $\mathbf{c}$ [S1]. It utilizes a coarse network ($\hat{C}_c$) and a fine network ($\hat{C}_f$) to predict colors [S1].

### Inputs and Outputs
**Inputs:**
*   A set of input views with known camera poses.
*   A binary mask $M$ identifying the occluded region in at least one view (typically generated by an object segmentation network [S1]).
*   A pretrained 2D image inpainter (specifically LaMa [S1]) to generate appearance priors for occluded pixels.
*   Ground truth depth maps $D(r)$ for the input views [S1].

**Outputs:**
*   Optimized NeRF parameters $\theta$.
*   A rendered image with the occluded region realistically inpainted, maintaining multi-view consistency.

### Data Structures
*   **NeRF Model:** Two MLPs (coarse and fine) taking $(\mathbf{x}, \mathbf{d})$ and outputting $(\sigma, \mathbf{c})$.
*   **Occlusion Mask:** A predicted mask $\hat{P}(r)$ for each ray $r$, where $\hat{P}(r) \in [0, 1]$ indicates the probability of the ray passing through the occluded area [S1].
*   **2D Inpainting Prior:** An image $I_l$ generated by the 2D inpainter, where occluded pixels are filled with synthesized content. For a ray $r$ hitting pixel $(u,v)$, $C_l(r)$ is the color at $(u,v)$ in $I_l$ [S1].
*   **Sub-regions:** The occluded area in each view is divided into multiple sub-regions (patches) to allow local gradient evaluation [S1].

### Steps

1.  **Initial 2D Inpainting:**
    Apply the pretrained 2D inpainter (LaMa) to the input views containing occlusions to generate $I_l$. This provides an initial appearance prior $C_l(r)$ for occluded pixels [S1].

2.  **Occlusion Masking:**
    Use an object segmentation network (constrained by depth information) to predict the occlusion mask $\hat{P}(r)$ for rays in the input views [S1].

3.  **Sub-region Division:**
    Divide the occluded area in each view into multiple sub-regions (patches) [S1].

4.  **Gradient Evaluation:**
    For each sub-region, calculate the average gradient of the rendered result $\nabla \hat{g}$ and the average gradient of the 2D inpainting result $\nabla g$ [S1]. The gradient serves as an indicator of texture richness [S1].

5.  **Adaptive Weight Calculation:**
    Compute the adaptive weight $\lambda$ for each sub-region based on the threshold $\tau$:
    $$
    \lambda = \begin{cases} 
    1 & \text{if } \nabla \hat{g} > \tau \cdot \nabla g \\
    0 & \text{if } \nabla \hat{g} \le \tau \cdot \nabla g 
    \end{cases}
    $$
    Here, $\nabla \hat{g}$ is the average gradient of the NeRF-rendered image in the sub-region, and $\nabla g$ is the average gradient of the 2D inpainted image in the same sub-region [S1].
    *   If $\lambda = 1$, the NeRF rendering has sufficient texture detail (richer than the 2D prior), so the method trusts the multi-view NeRF reconstruction.
    *   If $\lambda = 0$, the NeRF rendering lacks detail (poorer than the 2D prior), so the method relies on the 2D inpainting prior [S1].

6.  **Loss Computation:**
    Compute the total reconstruction loss $L$ as a weighted sum of non-occluded loss $L_{NonOcc}$ and occluded loss $L_{Occ}$ [S1]:
    $$
    L = \lambda L_{NonOcc} + (1 - \lambda) L_{Occ}
    $$
    
    *   **Non-Occluded Loss ($L_{NonOcc}$):** Applied to rays $r \in R$ where the mask $\hat{P}(r) \approx 0$. It minimizes the L2 distance between the predicted colors and the ground truth input colors $C(r)$ [S1]:
        $$
        L_{NonOcc} = \sum_{r \in R} (1 - \hat{P}(r)) \left[ \|\hat{C}_c(r) - C(r)\|_2^2 + \|\hat{C}_f(r) - C(r)\|_2^2 \right]
        $$
    
    *   **Occluded Loss ($L_{Occ}$):** Applied to rays $r \in R$ where the mask $\hat{P}(r) \approx 1$. It minimizes the L2 distance between the predicted colors and the 2D inpainting prior $C_l(r)$ [S1]:
        $$
        L_{Occ} = \sum_{r \in R} \hat{P}(r) \left[ \|\hat{C}_c(r) - C_l(r)\|_2^2 + \|\hat{C}_f(r) - C_l(r)\|_2^2 \right]
        $$

7.  **Additional Regularization:**
    The segmentation network is jointly optimized using region encoding loss, RGB loss, and depth loss $L_{depth}$ to ensure multi-view consistency and smoothness [S1]:
    $$
    L_{seg} = \lambda_1 L_{region-encoding} + \lambda_2 L_{rgb} + \lambda_3 L_{depth}
    $$
    Where $L_{depth}$ is the L2 distance between rendered depth $\hat{D}(r)$ and ground truth depth $D(r)$ [S1].

8.  **Optimization:**
    Update NeRF parameters $\theta$ and segmentation network parameters to minimize the total loss. The adaptive weight $\lambda$ is recalculated during training as the NeRF renders improve [S1].

def compute_adaptive_weights(pred_colors, prior_colors, mask, tau):
    """
    Computes adaptive weights lambda per sub-region.
    """
    # Divide mask into sub-regions
    regions = divide_into_patches(mask)
    weights = {}
    
    for region in regions:
        # Extract sub-region data
        pred_sub = pred_colors[region]
        prior_sub = prior_colors[region]
        
        # Calculate average gradients
        grad_pred = average_gradient(pred_sub)
        grad_prior = average_gradient(prior_sub)
        
        # Determine lambda
        if grad_pred > tau * grad_prior:
            weights[region] = 1
        else:
            weights[region] = 0
            
    return weights

### Parameters
*   $\tau$: Threshold for adaptive weight calculation. Not given in the sources.
*   $\lambda_1, \lambda_2, \lambda_3$: Weights for segmentation loss components. Not given in the sources.
*   $C_l(r)$: Color of the corresponding pixel in the 2D inpainting image for ray $r$. Used as an estimated color prior for occluded areas [S1].

### Edge Cases and Pitfalls
*   **Single 2D Inpainting Inconsistency:** A single 2D image inpainter does not consider consistency in the real 3D scene [S1]. The method addresses this by selecting training views based on texture richness (gradient) to ensure multi-view consistency [S1].
*   **Uniform Strategy Misjudgment:** Applying a uniform treatment strategy to the entire occluded area can lead to misjudgment. The method avoids this by dividing the occluded area into multiple sub-regions and evaluating the average gradient of each sub-region individually [S1].
*   **Precision:** The gradient calculation must be robust to noise. The sources do not specify the gradient operator used (e.g., Sobel, Scharr) [S1].

*   **Limitations:** Relies on the quality of the pretrained 2D inpainter (LaMa) and the accuracy of the object segmentation network [S1].

## Background
The method was proposed in the paper "3D Scene De-occlusion in Neural Radiance Fields: A Framework for Obstacle Removal and Realistic Inpainting" [S1]. It builds upon the NeRF representation [S1] and addresses the limitations of previous 3D inpainting methods that either ignored multi-view consistency or relied solely on 2D priors [S1].
