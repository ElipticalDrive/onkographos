# Blended-NeRF

Also called: Zero-Shot Object Generation and Blending in Existing Neural Radiance Fields

## Overview
Blended-NeRF is a framework for editing a specific region of interest (ROI) in an existing Neural Radiance Field (NeRF) scene based on text prompts and a user-defined 3D ROI box [S1]. It solves the problem of local 3D editing by initializing a generator NeRF with the original scene's weights and blending the synthesized content with the original scene using volumetric blending, preserving the scene outside the box [S1]. Unlike methods that synthesize objects from scratch (e.g., Dream Fields) or require semantic masks (e.g., Volumetric Disentanglement), Blended-NeRF operates on any region using a 3D box without learning a new feature space or requiring 2D masks [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** An existing NeRF model $F_{\theta_O}$ representing scene $x_o$, a 3D ROI box $B$ localized in the scene, and a text prompt $y$ [S1].
*   **Output:** An edited NeRF model $F_{\theta_E}$ (implicitly defined by blending $F_{\theta_O}$ and $F_{\theta_G}$) that renders scene $x_e$ where $x_e \odot B$ matches the prompt and $x_e \odot (1 - B) = x_o \odot (1 - B)$ [S1].

**Data Structures:**
*   **NeRF Model ($F_\theta$):** A Multi-Layer Perceptron (MLP) mapping 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$ to density $\sigma$ and color $\mathbf{c}$ [S1].
*   **Positional Encoding:** Inputs are embedded using high-frequency sinusoidal positional encoding $\gamma(\mathbf{x}) = [\cos(2^l \mathbf{x}), \sin(2^l \mathbf{x})]_{l=0}^{L-1}$ [S1].
*   **ROI Box ($B$):** A 3D axis-aligned or oriented box defined by its center and dimensions, used to mask sampling during training and blending during inference [S1].
*   **Language-Image Model:** Pretrained encoders $E_{img}$ and $E_{txt}$ (e.g., CLIP) used for similarity loss [S1].

**Numbered Steps:**

1.  **Initialization:** Initialize a generator NeRF model $F_{\theta_G}$ with the weights of the original scene model $F_{\theta_O}$ [S1].
2.  **ROI Localization:** Localize the 3D box $B$ inside the scene using a GUI that renders the original NeRF and uses its depth map for 3D understanding [S1].
3.  **Training Setup:**
    *   Sample random camera poses around the scene. The initial distance $d$ from the ROI is calculated as $d = \frac{e_{max}}{2 \tan(\gamma/2)}$, where $e_{max}$ is the maximum dimension of the box and $\gamma$ is the camera FOV. Randomly sample radius $r$ around $d$ [S1].
    *   Apply background augmentation using random backgrounds (Gaussian noise, checkerboard, random Fourier textures) to prevent scene diffusion [S1].
    *   Construct directional dependent prompts by concatenating view-dependent text to the original caption [S1].
4.  **Ray Sampling and Rendering (Training):**
    *   Cast rays $r$ that pass through the box $B$.
    *   Sample points along the ray. For sample points $x_i$ outside $B$, set density to zero.
    *   Render the generated content inside the ROI $I_{ROI}$ using only points $x_i \in B$ [S1]:
        $$
        C(r) = \begin{cases} 
        \frac{\sum_{x_i \in B} T_i (1 - e^{-\sigma_i \delta_i}) c_i}{\sum_{x_i \in B} T_i (1 - e^{-\sigma_i \delta_i})} & \text{if } \exists x_i \in r \text{ s.t. } x_i \in B \\
        0 & \text{otherwise}
        \end{cases}
        $$
        where $T_i = \exp(-\sum_{j < i} \sigma_j \delta_j)$, $\delta_i = t_{i+1} - t_i$ is the distance between adjacent samples, $\sigma_i$ is density, and $c_i$ is color [S1].
5.  **Loss Calculation:**
    *   Compute similarity loss $L_{sim}$ using CLIP encoders: $L_{sim} = -E_{img}(I_{ROI})^T E_{txt}(y)$ [S1].
    *   Compute Transmittance Loss $L_T = -\min(\tau, \text{mean}(T(P)))$, where $T(P)$ is the average transmittance of the rendered view from pose $P$ and $\tau$ is the max transmittance [S1].
    *   Compute Depth Loss $L_D = -\min(\rho, \sigma^2(D(P)))$, where $\sigma^2(D(P))$ is the variance of the disparity map of the rendered view and $\rho$ is the max variance allowed [S1].
    *   Total objective: $L_{total} = L_{sim} + \lambda_T L_T + \lambda_D L_D$, where $\lambda_T, \lambda_D$ are weights [S1].
    *   Anneal $L_T$ and $L_D$ during training to prevent transparent or amorphous scenes [S1].
6.  **Optimization:** Optimize $F_{\theta_G}$ by minimizing $L_{total}$ using gradient descent (e.g., Adam) [S1].
7.  **Blending (Inference):**
    *   Render the edited scene by querying both $F_{\theta_O}$ and $F_{\theta_G}$ for the same set of rays [S1].
    *   Points inside the box are processed by $F_{\theta_G}$ and points outside by $F_{\theta_O}$ [S1].
    *   Apply distance smoothing blending for density $\sigma_{blend}(x)$ and color $c_{blend}(x)$ inside the ROI:
        $$
        f(x) = 1 - \exp\left(-\alpha \frac{d(x)}{diag}\right)
        $$
        $$
        \sigma_{blend}(x) = f(x) \cdot \sigma_O(x) + (1 - f(x)) \cdot \sigma_G(x)
        $$
        $$
        c_{blend}(x) = f(x) \cdot c_O(x) + (1 - f(x)) \cdot c_G(x)
        $$
        where $d(x)$ is the Euclidean distance from the ROI center, $diag$ is the box diagonal, and $\alpha$ is a hyperparameter controlling blending strength [S1].
    *   Final rendered view $x_e$ is obtained by blending the raw densities and RGB values inside and outside the ROI along each ray using standard volume rendering [S1].

**Object Blending Mode Details:**
If blending with existing content inside the ROI (Object Blending mode), compute alpha values for each point $x_i$:
$$
\alpha_O(x_i) = 1 - \exp(\phi(\sigma_O(x_i)) \cdot \delta_i)
$$
$$
\alpha_G(x_i) = 1 - \exp(\phi(\sigma_G(x_i)) \cdot \delta_i)
$$
where $\phi$ is a non-negative activation function [S1].
Blend colors:
$$
c(x_i) = S\left(\frac{c_O(x_i) \cdot \alpha_O(x_i) + c_G(x_i) \cdot \alpha_G(x_i)}{\epsilon + \alpha_O(x_i) + \alpha_G(x_i)}\right)
$$
where $S$ is sigmoid and $\epsilon$ is a small constant [S1].
Blend densities using one of two options:
1.  Sum in activation: $\sigma(x_i) = \phi(\sigma_O(x_i) + \sigma_G(x_i))$ (allows $F_{\theta_G}$ to remove original densities) [S1].
2.  Sum out activation: $\sigma(x_i) = \phi(\sigma_O(x_i)) + \phi(\sigma_G(x_i))$ (allows only addition of new densities) [S1].

**Pseudocode:**

```python
import numpy as np

def positional_encoding(x, L=10):
    """High frequency sinusoidal positional encoding."""
    # x is shape (N, 3)
    scales = np.array([2**l for l in range(L)])
    encoded = []
    for scale in scales:
        encoded.append(np.cos(scale * x))
        encoded.append(np.sin(scale * x))
    return np.concatenate(encoded, axis=-1)

def volume_rendering(rays, model, roi_box=None, mode='training'):
    """
    Render a batch of rays.
    rays: (N, 2, 3) [origin, direction]
    model: function mapping (points, dirs) -> (sigma, color)
    roi_box: bounding box [min_x, max_x, min_y, max_y, min_z, max_z]
    mode: 'training' (only render inside ROI) or 'inference' (standard)
    """
    # Sample points along rays
    t_vals = np.linspace(0.0, 1.0, 128) # N samples
    t = t_vals[:, None] * rays[:, 1, None, :] # (N, 128, 3)
    origins = rays[:, 0, None, :] # (N, 1, 3)
    points = origins + t # (N, 128, 3)
    
    # Compute deltas
    deltas = t_vals[1:] - t_vals[:-1] # (127,)
    deltas = np.concatenate([deltas, np.array([1e10])]) # (128,)
    deltas = deltas[None, :, None] # (1, 128, 1)
    
    # Query model
    # Note: In practice, direction is computed from ray origin and point
    dirs = rays[:, 1, None, :] # (N, 1, 3)
    # Flatten for model query
    pts_flat = points.reshape(-1, 3)
    dirs_flat = dirs.reshape(-1, 3)
    
    sigma, color = model(pts_flat, dirs_flat)
    sigma = sigma.reshape(points.shape[:-1]) # (N, 128)
    color = color.reshape(points.shape[:-1] + (3,)) # (N, 128, 3)
    
    # Apply ROI Masking for Training
    if mode == 'training' and roi_box is not None:
        inside_roi = (
            (points[:, :, 0] >= roi_box[0]) & (points[:, :, 0] <= roi_box[1]) &
            (points[:, :, 1] >= roi_box[2]) & (points[:, :, 1] <= roi_box[3]) &
            (points[:, :, 2] >= roi_box[4]) & (points[:, :, 2] <= roi_box[5])
        )
        # Set density to zero outside ROI
        sigma = np.where(inside_roi, sigma, 0.0)
        
        # Check if any point in ray is inside ROI
        has_roi_point = np.any(inside_roi, axis=1) # (N,)
        
        # Compute transmittance
        alpha = 1.0 - np.exp(-sigma * deltas.squeeze()) # (N, 128)
        T = np.cumprod(np.concatenate([np.ones((points.shape[0], 1)), 1.0 - alpha[:, :-1]], axis=1), axis=1) # (N, 128)
        
        weights = alpha * T # (N, 128)
        
        # Render color
        color_out = np.sum(weights[:, :, None] * color, axis=1) # (N, 3)
        
        # Normalize if ROI was hit, else 0
        weight_sum = np.sum(weights, axis=1) # (N,)
        color_out = np.where(weight_sum[:, None] > 0, color_out / (weight_sum[:, None] + 1e-10), 0.0)
        color_out = np.where(has_roi_point[:, None], color_out, 0.0)
        
        return color_out, sigma, T, alpha
    else:
        # Standard Volume Rendering
        alpha = 1.0 - np.exp(-sigma * deltas.squeeze())
        T = np.cumprod(np.concatenate([np.ones((points.shape[0], 1)), 1.0 - alpha[:, :-1]], axis=1), axis=1)
        weights = alpha * T
        color_out = np.sum(weights[:, :, None] * color, axis=1)
        return color_out, sigma, T, alpha

def compute_clip_loss(rendered_img, text_prompt, clip_model):
    """Compute similarity loss using CLIP."""
    img_emb = clip_model.encode_image(rendered_img)
    txt_emb = clip_model.encode_text(text_prompt)
    # Normalize embeddings
    img_emb = img_emb / np.linalg.norm(img_emb, axis=1, keepdims=True)
    txt_emb = txt_emb / np.linalg.norm(txt_emb, axis=1, keepdims=True)
    # Cosine similarity
    sim = np.sum(img_emb * txt_emb, axis=1)
    return -np.mean(sim)

def blend_fields(model_O, model_G, rays, roi_box, alpha_smooth=2.0):
    """
    Blend original and generator fields during inference.
    """
    # Sample points
    t_vals = np.linspace(0.0, 1.0, 128)
    t = t_vals[:, None] * rays[:, 1, None, :]
    origins = rays[:, 0, None, :]
    points = origins + t
    dirs = rays[:, 1, None, :]
    
    # Query both models
    sigma_O, color_O = model_O(points.reshape(-1, 3), dirs.reshape(-1, 3))
    sigma_G, color_G = model_G(points.reshape(-1, 3), dirs.reshape(-1, 3))
    
    sigma_O = sigma_O.reshape(points.shape[:-1])
    color_O = color_O.reshape(points.shape[:-1] + (3,))
    sigma_G = sigma_G.reshape(points.shape[:-1])
    color_G = color_G.reshape(points.shape[:-1] + (3,))
    
    # Distance smoothing inside ROI
    roi_center = np.mean(roi_box.reshape(2, 3), axis=0)
    roi_diag = np.linalg.norm(roi_box[1:4] - roi_box[0:3])
    dists = np.linalg.norm(points - roi_center, axis=-1)
    f = 1.0 - np.exp(-alpha_smooth * dists / roi_diag)
    
    # Blend densities and colors inside ROI
    # Outside ROI, use model_O
    inside_roi = (
        (points[:, :, 0] >= roi_box[0]) & (points[:, :, 0] <= roi_box[1]) &
        (points[:, :, 1] >= roi_box[2]) & (points[:, :, 1] <= roi_box[3]) &
        (points[:, :, 2] >= roi_box[4]) & (points[:, :, 2] <= roi_box[5])
    )
    
    sigma_blend = np.where(inside_roi, f * sigma_O + (1 - f) * sigma_G, sigma_O)
    color_blend = np.where(inside_roi, f * color_O + (1 - f) * color_G, color_O)
    
    # Standard volume rendering on blended field
    deltas = t_vals[1:] - t_vals[:-1]
    deltas = np.concatenate([deltas, np.array([1e10])])
    deltas = deltas[None, :, None]
    
    alpha = 1.0 - np.exp(-sigma_blend * deltas.squeeze())
    T = np.cumprod(np.concatenate([np.ones((points.shape[0], 1)), 1.0 - alpha[:, :-1]], axis=1), axis=1)
    weights = alpha * T
    color_out = np.sum(weights[:, :, None] * color_blend, axis=1)
    
    return color_out

def train_blended_nerf(model_O, roi_box, text_prompt, clip_model, num_iterations=1000):
    """
    Main training loop for Blended-NeRF.
    """
    # Initialize Generator with Original weights
    model_G = copy_weights(model_O)
    optimizer = Adam(model_G.parameters())
    
    for i in range(num_iterations):
        # 1. Sample Pose
        pose = sample_random_pose(roi_box)
        
        # 2. Cast Rays and Render ROI
        rays = generate_rays_from_pose(pose, roi_box)
        color_roi, sigma, T, alpha = volume_rendering(rays, model_G, roi_box, mode='training')
        
        # 3. Compute Losses
        L_sim = compute_clip_loss(color_roi, text_prompt, clip_model)
        
        # Transmittance Loss
        mean_T = np.mean(T)
        L_T = -np.min([tau, mean_T]) # tau is max transmittance
        
        # Depth Loss (requires disparity estimation from sigma)
        disparity = compute_disparity_from_sigma(sigma, rays)
        var_D = np.var(disparity)
        L_D = -np.min([rho, var_D]) # rho is max variance
        
        # Anneal L_T and L_D
        anneal_factor = min(1.0, i / num_iterations)
        L_total = L_sim + lambda_T * anneal_factor * L_T + lambda_D * anneal_factor * L_D
        
        # 4. Optimize
        optimizer.zero_grad()
        L_total.backward()
        optimizer.step()
        
    return model_G
```

## Operating characteristics
*   **Time Complexity:** Training time depends on the number of iterations and the cost of querying the MLP and CLIP encoders. It is comparable to other text-guided NeRF optimization methods like Dream Fields [S1].
*   **Memory Complexity:** Requires storing two NeRF models (original and generator) and their gradients during training. The original model can be frozen or kept in memory for blending [S1].
*   **Strengths:**
    *   Enables local editing without requiring semantic masks or 2D segmentation [S1].
    *   Preserves the original scene outside the ROI [S1].
    *   Supports object insertion, replacement, and blending [S1].
    *   Uses text prompts for flexible, zero-shot editing [S1].
*   **Limitations:**
    *   Quality depends on the accuracy of the ROI box localization [S1].
    *   May produce artifacts if the text prompt is ambiguous or conflicts strongly with the original scene geometry [S1].
    *   Requires careful tuning of blending parameters ($\alpha$) and loss weights ($\lambda_T, \lambda_D$) [S1].
*   **When to use:** When you need to edit a specific object or region in an existing NeRF scene using a text prompt, without access to semantic masks or the ability to retrain the entire scene from scratch.
*   **When not to use:** When global scene editing is required, or when high-fidelity semantic consistency across the entire scene is needed without local artifacts.

## Background
Blended-NeRF was introduced by Ori Gordon, Omri Avrahami, and Dani Lischinski from The Hebrew University in 2023 [S1]. It builds on the principles of Dream Fields [S1], which used CLIP to guide NeRF generation, and extends them to the context of editing existing scenes. The method addresses the limitations of prior editing techniques that required semantic decomposition or 2D masks [S1].
