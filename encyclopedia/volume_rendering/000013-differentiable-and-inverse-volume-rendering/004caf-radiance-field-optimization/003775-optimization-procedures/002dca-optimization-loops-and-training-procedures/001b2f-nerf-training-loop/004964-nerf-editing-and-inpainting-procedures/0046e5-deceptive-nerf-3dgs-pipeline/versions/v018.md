# Deceptive-NeRF/3DGS Pipeline

Also called: Deceptive-3DGS, Deceptive-NeRF

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that enhances NeRF or 3D Gaussian Splatting (3DGS) representations by continuously densifying input observations with synthetic pseudo-observations generated by a diffusion model during training [S1]. Unlike methods that rely on ensemble learning, variational inference, or spatial perturbations to estimate uncertainty, this approach acquires uncertainty through correspondence matching by reprojecting real input observations to novel views, thereby minimizing additional computation while enforcing epipolar constraints [S1]. It sets itself apart by conditioning a 2D diffusion model on rendered RGB images, depth maps, and view-consistency uncertainty maps to rectify artifacts and generate photorealistic pseudo-observations that are then used to supervise the radiance field [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A set of $W$ input images $I = \{I_1, \dots, I_W\}$ with calibrated camera poses [S1].
*   A pre-trained 2D diffusion model (e.g., Stable Diffusion) [S1].
*   A pre-trained image captioning network [S1].
*   A ControlNet architecture [S1].

**Outputs:**
*   A refined NeRF or 3DGS representation optimized using both real input images and generated pseudo-observations [S1].

### Data Structures
The method utilizes standard radiance field data structures (NeRF MLP weights or 3DGS Gaussian parameters) [S1]. For the diffusion model, the following data structures are constructed during training:
*   **Quartet Dataset:** A dataset of quartets $(I_{fine}, I_{coarse}, D, U)$ where:
    *   $I_{fine}$: Fine RGB image (target).
    *   $I_{coarse}$: Coarse RGB image (condition).
    *   $D$: Depth map (condition).
    *   $U$: Uncertainty map (condition) [S1].
*   **Control Map:** A 5-channel tensor combining inputs for ControlNet: 3 channels for coarse RGB, 1 for depth, and 1 for uncertainty [S1].
*   **Text Embedding:** A composite feature $s = [s_0, s^*]$ where $s_0$ is the text prompt from the captioning network and $s^*$ is an optimized shared latent text embedding [S1].

### Numbered Steps

1.  **Initial Training:** Train a NeRF or 3DGS representation using the few-view input images $I$ with calibrated poses [S1].
2.  **Coarse Reconstruction:** After a set number of epochs, obtain a coarse reconstruction [S1].
3.  **View Sampling:** Randomly sample novel views within a bounding box defined by the outermost input views [S1].
4.  **Rendering:** At a novel viewpoint $A$, render:
    *   RGB image $\hat{I}_A$ [S1].
    *   Depth map $D_A$ using the weighted composition of distances traveled:
        $$
        \hat{\mathbf{D}} = \sum_{k=1}^{K} \hat{T}(t_k)\alpha (\sigma (t_k)\delta _k)
        $$
        where $\hat{T}(t_k)$ is transmittance, $\alpha$ is opacity, $\sigma$ is density, and $\delta_k$ is the distance traveled [S1].
    *   Uncertainty map $U_A$ (see Step 5) [S1].
5.  **Uncertainty Map Generation:**
    *   Identify the nearest input viewpoint $B$ to the novel view $A$ [S1].
    *   Warp the ground truth image $I_B$ towards $A$ using the rendered depth map $D_A$ and the viewpoint difference $R_{B\rightarrow A}$:
        $$
        I_{B\rightarrow A} = \psi (I_B; D_A, R_{B\rightarrow A})
        $$
    *   Transform each pixel location $p$ in $\hat{I}_A$ to $q$ in $I_B$ using the camera parameter matrix $K$:
        $$
        q = K R_{B\rightarrow A} D_A(p) K^{-1} p
        $$
    *   Define the uncertainty map $U_A$ as the squared distance between the warped image and the rendered image:
        $$
        U_A = (I_{B \rightarrow A} - \hat {I}_A)^2
        $$
        [S1].
6.  **Pseudo-Observation Generation:** Generate a pseudo-observation $P_A$ using the deceptive diffusion model $G$ conditioned on the rendered RGB image, depth map, and uncertainty map:
    $$
    P_A = \operatorname {G}(\hat {I}_A, D_A, U_A)
    $$
    [S1].
7.  **Filtering:** Discard 20% of the pseudo-observations with the lowest perceptual similarity to input images, quantified via the LPIPS metric [S1].
8.  **Optimization:** Continue training the NeRF/3DGS representation using a combination of the original input images (real) and the accumulated pseudo-observations (synthesized) [S1].
9.  **Iteration:** Repeat steps 3–8 until a sufficient number of observations are accumulated [S1].

### Diffusion Model Fine-Tuning
To train the deceptive diffusion model $G$, the following procedure is used:

1.  **Text Embedding Derivation:**
    *   Generate a text prompt $s_0$ using a pre-trained image captioning network [S1].
    *   Optimize a shared latent text embedding $s^*$ shared by all input observations and coarse images using textual inversion [S1].
    *   Form the composite feature $s = [s_0, s^*]$ [S1].
2.  **Data Augmentation (Optional/Initial Phase):**
    *   Add random Gaussian noise (standard deviation 0.3) to 60,000 images from Hypersim [S1].
    *   Use these noisy images and accompanying depth maps as training inputs, retaining original RGB images as targets [S1].
    *   *Note:* When training with this noisy RGB-depth data augmentation, uncertainty maps are **not** fed into the diffusion model [S1].
3.  **NeRF Duo Training (Major Phase):**
    *   Train coarse NeRFs using only one-fifth of input images [S1].
    *   Train fine NeRFs using all input images [S1].
    *   Render quartets $(I_{fine}, I_{coarse}, D, U)$ from the same viewpoints [S1].
    *   Dataset size: 200 scenes and approximately 20,000 images, with Hypersim and CO3D each contributing half [S1].
4.  **Fine-Tuning Objective:**
    *   Fine-tune a pre-trained diffusion model (encoder $\mathcal{E}$, denoiser U-Net $\epsilon_\theta$, decoder $\mathcal{D}$) using ControlNet to preserve pre-trained weights [S1].
    *   Minimize the objective:
        $$
        \min _{\theta}\mathbb {E}_{z\sim \mathcal {E},t,\epsilon \sim \mathcal {N}(0,1)}\|\epsilon -\epsilon _{\theta }(z_t,t,c(I_{\text {coarse}},D,U,s))\|_2^2
        $$
        where $z \sim \mathcal{E}$ is the latent code, $t \sim [1, 1000]$ is the diffusion time step, $\epsilon$ is noise, and $c$ is the embedding of the coarse image, depth, uncertainty, and text embedding $s$ [S1].
5.  **Implementation Details:**
    *   Set five control map channels (3 for coarse RGB, 1 for depth, 1 for uncertainty) [S1].
    *   Randomly crop all images to a resolution of $512 \times 512$ [S1].

        novel_view_id = get_view_id(novel_view_pose)

        )

        # Step 6: Generate Pseudo-Observation
        # Condition on RGB, Depth, Uncertainty
        # Text embedding is derived from the coarse rendered image
        text_emb = get_text_embedding(rendered_rgb)
        
        pseudo_obs = deceptive_diffusion.generate(
            rgb_condition=rendered_rgb,
            depth_condition=rendered_depth,
            uncertainty_condition=uncertainty_map,
            text_embedding=text_emb
        )
        
        # Step 7: Filter Pseudo-Observations
        # Discard 20% with lowest LPIPS similarity to input images
        # Note: LPIPS is computed against the set of real input images
        similarity_scores = compute_lpips_batch(pseudo_obs, input_images)
        threshold = percentile(similarity_scores, 20) # Lowest 20%
        
        if similarity_scores < threshold:
            continue # Discard this pseudo-observation
            
        pseudo_observations.append(pseudo_obs)
        
        # Step 8: Optimize Radiance Field
        # Combine real inputs and pseudo-observations
        all_images = input_images + pseudo_observations
        # Note: Pseudo-observations need poses. 
        # The novel view pose is used for the pseudo-observation.
        all_poses = camera_poses + [novel_view_pose]
        
        radiance_field = optimize_radiance_field(
            radiance_field, 
            all_images, 
            all_poses
        )
        
    return radiance_field

### Parameters
*   **Discard Rate:** 20% of pseudo-observations with the lowest perceptual similarity are discarded [S1].
*   **LPIPS Metric:** Used to quantify perceptual similarity for filtering [S1].
*   **ControlNet:** Used to implement the training paradigm while preserving pre-trained weights [S1].
*   **Gaussian Noise Standard Deviation:** 0.3, added to 60,000 images from Hypersim for data augmentation [S1].
*   **Control Map Channels:** 5 channels (3 for coarse RGB, 1 for depth, 1 for uncertainty) [S1].
*   **Image Resolution:** All images are randomly cropped to $512 \times 512$ [S1].
*   **Training Dataset Size:** 200 scenes and approximately 20,000 images for the major section, with Hypersim and CO3D each contributing half [S1].
*   **Coarse NeRF Training Data:** Coarse NeRFs are trained only with one-fifth of input images [S1].

### Edge Cases and Pitfalls
*   **Image Captioning Efficacy:** Image captioning efficacy diminishes for images of lower quality or those with pronounced artifacts. Textual inversion is used to counteract this by optimizing a shared latent text embedding [S1].
*   **Noisy Data Augmentation:** When training with noisy RGB-depth data augmentation (Hypersim), uncertainty maps are **not** fed into the diffusion model [S1].
*   **Precision:** The uncertainty map calculation involves pixel-wise warping and subtraction. Precision in depth rendering and camera matrix inversion is critical for accurate warping [S1].

## Operating characteristics

### Time and Memory Complexity
*   **Time:** The method requires iterative training loops where the radiance field is updated after generating pseudo-observations. Each iteration involves rendering (depth, RGB), warping images, and running a diffusion model inference. The diffusion model fine-tuning also adds significant computational overhead during the initial training phase [S1].
*   **Memory:** Requires storing the radiance field, the diffusion model weights, and the dataset of quartets (or generating them on the fly). The use of ControlNet allows preserving pre-trained weights, but the fine-tuning process requires memory for gradients and activations [S1].

### Measured Performance
*   **Hardware:** Not given in the sources.
*   **Resolution:** $512 \times 512$ [S1].
*   **Scene:** Evaluated on LLFF, Mip-NeRF 360, ScanNet, Hypersim, and CO3D [S1].
*   **Scaling:** The method is designed for sparse-view reconstruction (e.g., 3, 6, 9 views) [S1].

### Strengths and Limitations
*   **Strengths:**
    *   Enforces 3D consistency through uncertainty maps derived from correspondence matching, minimizing additional computation compared to ensemble or variational methods [S1].
    *   Generates high-quality photorealistic pseudo-observations that rectify NeRF/3DGS artifacts [S1].
    *   Effective for few-shot novel view synthesis and super-resolution [S1].
*   **Limitations:**
    *   Relies on the quality of the initial coarse reconstruction.
    *   Image captioning may fail on low-quality images, requiring textual inversion [S1].
    *   Computational cost of iterative diffusion model inference and radiance field optimization [S1].

### When to Use
*   Use when reconstructing scenes from a very small number of input views (sparse-view) [S1].
*   Use when high-fidelity novel view synthesis is required and standard NeRF/3DGS fails due to lack of data [S1].

### When Not to Use
*   Use when computational resources are extremely limited, as the method involves multiple training stages and diffusion model inference [S1].
*   Use when input images are of very low quality and captioning/textual inversion cannot recover semantic information [S1].

## Background

### Origin
The method was introduced in the paper "Deceptive-NeRF/3DGS: Diffusion-Generated Pseudo-Observations for High-Quality Sparse-View Reconstruction" by X. Liu et al. [S1].

### History and Development
The method builds on the concept of using diffusion models for 3D reconstruction. It specifically addresses the issue of sparse-view reconstruction by generating pseudo-observations to densify the input data. The use of uncertainty maps for view consistency is a novel contribution, distinguishing it from previous methods that used ensemble learning or variational inference [S1].

### Where it is Used
The method is used for few-shot novel view synthesis, super-resolution on novel views, and sparse-view reconstruction across various datasets including synthetic (Hypersim) and real-world (ScanNet, LLFF, Mip-NeRF 360) scenes [S1].
