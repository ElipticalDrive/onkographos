# Progressive Inpainting-and-Erasing

Also called: Conflicted Geometry Detection and Erasing, Inpainting-and-Erasing Strategy, PERF, PERF Algorithm

## Overview
Progressive Inpainting-and-Erasing (PERF) is a training procedure for expanding a single-view Neural Radiance Field (NeRF) into a full panoramic representation by iteratively synthesizing and integrating novel views [S1]. It solves the problem of geometry conflicts that arise when inpainting invisible regions with generative models, which often produce structures inconsistent with the existing learned geometry [S1]. Unlike methods that rely on multi-view consistency from the start, PERF progressively enlarges the viewpoint range by detecting and erasing conflicted regions from supervision, ensuring geometric coherence between visible and newly generated invisible areas [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A single input panorama image $I_{rgb}$ [S1].
*   **Output:** A panoramic NeRF representation $f_{nerf}$ [S1].

**Data Structures:**
*   **NeRF Representation ($f_{nerf}$):** Uses Instant-NGP [S1]. The hash table size is $2^{19}$ with 16 levels of feature vectors, each of channel size 2 [S1].
*   **Reference Views Set ($I_{ref}$):** A set containing the initial RGBD panorama and subsequently added inpainted RGBD panoramas [S1].
*   **Trajectories ($\{p_k\}$):** A set of novel view camera poses generated based on the initial depth map [S1].
*   **Ray Sampling:** 2048 rays are sampled per iteration for supervision [S1].

**Formulas:**
1.  **Initial Depth Estimation:** The initial depth map $I_d$ is estimated from $I_{rgb}$ using an external depth estimator [S1]. The combined input is $I_{rgbd} = (I_{rgb}, I_d)$ [S1].
2.  **Invisible Region Mask ($m'$):** For a new view, invisible regions are detected by warping depth from the new view to a reference view. If the warped depth is significantly larger than the reference depth, the region is invisible [S1]:
    $$ m'_{ij} = \mathbb{I}(warp(v'_{ij}) - v_{ij} > \varepsilon) $$
    where $v_{ij}$ is the reference depth, $v'_{ij}$ is the warped depth from the new view, $\varepsilon$ is a small threshold, and $\mathbb{I}(\cdot)$ is the indicator function [S1].
3.  **Conflicted Region Mask ($m''$):** Conflicts are detected by warping depth from the reference view to the new view. If the reference depth is significantly larger than the warped new depth, the region is conflicted (i.e., the inpainted geometry violates the reference geometry) [S1]:
    $$ m''_{ij} = \mathbb{I}(v_{ij} - warp(v'_{ij}) > \varepsilon) $$
    where $v_{ij}$ is the reference depth and $v'_{ij}$ is the warped depth from the reference view to the new view [S1].
4.  **Final Conflict Mask:** The final mask for a specific reference view is computed as above. The global conflict mask is the logic AND of individual masks across all reference views [S1].

**Parameters:**
*   **$\varepsilon$:** A small value threshold for depth difference [S1].
*   **Initial Training Iterations:** 10,000 iterations for the single input panorama [S1].
*   **New View Sampling:** 32 new positions are sampled with approximately gradually increased distance from the original position [S1].
*   **Fine-tuning Iterations:** 2,000 iterations per new view [S1].
    *   First 100 iterations: Supervision only from the new reference view [S1].
    *   Remaining 1,900 iterations: Supervision from all reference views [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** Initially $10^{-3}$, decayed to $10^{-4}$ using cosine annealing for each learning stage of a newly sampled view [S1].

**Edge Cases and Pitfalls:**
*   **Depth Estimation Error:** The initial depth estimation from a single panorama is critical. Errors here propagate to trajectory generation and warping [S1].
*   **Geometry Conflict:** Inpainting with Stable Diffusion may generate plausible but geometrically inconsistent structures. The erasing mechanism is essential to prevent these from corrupting the NeRF [S1].
*   **Warping Accuracy:** The warping function relies on accurate camera poses and depth. Misalignment leads to false positives in conflict detection [S1].
*   **Convergence:** The method relies on iterative fine-tuning until convergence for each new view. Insufficient iterations may leave artifacts [S1].

## Operating characteristics
*   **Time Complexity:** Training a scene takes about 2 hours on a single Nvidia V100 GPU [S1]. The process is iterative, involving 32 new views, each requiring 2,000 iterations of fine-tuning plus initial 10,000 iterations [S1].
*   **Memory Complexity:** Uses Instant-NGP with a hash table size of $2^{19}$ and 16 levels of feature vectors of channel size 2 [S1]. Requires 32G memory on the GPU [S1].
*   **Scaling:** The method scales by adding more novel views (up to 32 in the reported experiments) to expand the panorama [S1].
*   **Strengths:** Effectively avoids geometry conflicts between visible and invisible regions, allowing for coherent panoramic reconstruction from a single view [S1].
*   **Limitations:** Relies on the quality of the initial depth estimator and the generative inpainting model. Performance may degrade on in-the-wild data if the depth estimation is poor [S1].
*   **When to Use:** When only a single panorama is available and a full 360-degree NeRF is required [S1].
*   **When Not to Use:** When multi-view inputs are available, as other methods may be more efficient and accurate [S1].

## Background
*   **Origin:** Proposed in the paper "PERF: Panoramic Neural Radiance Field From a Single Panorama" [S1].
*   **History:** The method builds upon Instant-NGP [S1] and Stable Diffusion [S1]. It addresses the limitations of single-view NeRF reconstruction by introducing a progressive strategy to handle the ambiguity of unseen regions [S1].
*   **Usage:** Evaluated on the Replica dataset and in-the-wild indoor scenes [S1].
