# Blended-NeRF

Also called: Zero-Shot Object Generation and Blending in Existing Neural Radiance Fields

## Overview
Blended-NeRF is a framework for editing a specific region of interest (ROI) in an existing Neural Radiance Field (NeRF) scene based on text prompts and a user-defined 3D ROI box [S1]. It solves the problem of local 3D editing by initializing a generator NeRF with the weights of the original scene and blending the synthesized content with the original scene using volumetric blending [S1]. Unlike methods that synthesize new objects from scratch or require semantic masks, Blended-NeRF operates on any region using a 3D box without learning a new feature space [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** An existing NeRF scene $F_{\theta_O}$ mapping $(\mathbf{x}, \mathbf{d}) \to (\sigma, \mathbf{c})$, a 3D region of interest box $B$ localized within the scene, and a text prompt $y$ [S1].
*   **Output:** An edited scene $x_e$ where the content inside $B$ is modified according to $y$, and the content outside $B$ is preserved ($x_e \odot (1 - B) = x_o \odot (1 - B)$) [S1].

**Data Structures:**
*   **NeRF Model ($F_\theta$):** A Multi-Layer Perceptron (MLP) taking positional encoding $\gamma(\mathbf{x})$ and view direction $\mathbf{d}$ as input, outputting density $\sigma$ and color $\mathbf{c}$ [S1].
*   **Positional Encoding:** High frequency sinusoidal encoding $\gamma(\mathbf{x}) = [\cos(2^l \mathbf{x}), \sin(2^l \mathbf{x})]_{l=0}^{L-1}$ [S1].
*   **ROI Box ($B$):** Defined by a center point and dimensions, localized via a GUI using depth maps from $F_{\theta_O}$ [S1].

**Parameters:**
*   $\alpha$: Hyperparameter for distance smoothing blending strength. $\alpha=0$ weights all to edited scene; higher values weight closer points to original scene [S1]. Typical values: 0, 0.5, 2, 4, 10 [S1].
*   $\lambda_T, \lambda_D$: Weights for transmittance and depth losses [S1].
*   $\tau$: Max transmittance for transmittance loss [S1].
*   $\rho$: Max variance for depth loss [S1]
*   $\epsilon$: Small constant for numerical stability in blending [S1].
*   $\gamma$: Camera Field of View (FOV) [S1].
*   $e_{max}$: Maximum dimension of the ROI box [S1].

**Steps:**

1.  **Initialization:** Initialize a generator NeRF model $F_{\theta_G}$ with the weights of the original scene model $F_{\theta_O}$ [S1].
2.  **ROI Localization:** Localize the 3D box $B$ inside the scene using a GUI that renders $F_{\theta_O}$ and uses its depth map for 3D understanding [S1].
3.  **Training Loop:** Optimize $F_{\theta_G}$ by minimizing the total loss $L_{total}$:
    *   **Ray Sampling:** Sample rays $r$ passing through box $B$. For sample points $\mathbf{x}_i$ outside $B$, set density to zero [S1].
    *   **Rendering Inside ROI:** Render the generated content $I_{ROI}$ using only points $\mathbf{x}_i \in B$. The rendered color $C(r)$ for a ray $r$ is:
        $$ C(r) = \begin{cases} \frac{\sum_{\mathbf{x}_i \in B} T_i (1 - e^{-\sigma_i \delta_i}) c_i}{\sum_{\mathbf{x}_i \in B} T_i (1 - e^{-\sigma_i \delta_i})} & \text{if } \exists \mathbf{x}_i \in r \text{ s.t. } \mathbf{x}_i \in B \\ 0 & \text{otherwise} \end{cases} $$
        where $T_i = \exp(-\sum_{j < i} \sigma_j \delta_i)$ is the transmittance, $\delta_i$ is the distance between adjacent samples, $\sigma_i$ is density, and $c_i$ is color [S1].
    *   **Similarity Loss ($L_{sim}$):** Minimize the negative cosine similarity between the image encoder output of the rendered ROI and the text prompt encoder output:
        $$ L_{sim} = -E_{img}(I_{ROI})^T E_{txt}(y) $$
        where $E_{img}$ and $E_{txt}$ are the image and text encoders of a language-image model (e.g., CLIP) [S1].
    *   **Pose Sampling:** Sample random camera poses around the scene with azimuth/elevation angles $(\theta, \phi)$. Initial distance $d = \frac{e_{max}}{2 \tan(\gamma/2)}$. Randomly sample radius $r$ around $d$ [S1].
    *   **Background Augmentation:** Use random backgrounds (Gaussian noise, checkerboard, random Fourier textures) during optimization to prevent scene diffusion [S1].
    *   **Directional Dependent Prompts:** Concatenate view-dependent text prompt to the original caption to constrain object description across views [S1].
    *   **Transmittance Loss ($L_T$):** Encourage sparse transmittance:
        $$ L_T = -\min(\tau, \text{mean}(T(P))) $$
        where $T(P)$ is the transmittance of the rendered view from pose $P$ [S1].
    *   **Depth Loss ($L_D$):** Encourage volumetric geometry (variance of disparity map):
        $$ L_D = -\min(\rho, \sigma^2(D(P))) $$
        where $\sigma^2(D(P))$ is the variance of the disparity map of the rendered view from pose $P$ [S1].
    *   **Annealing:** Gradually introduce $L_T$ and $L_D$ during training to prevent completely transparent or amorphous scenes [S1].
    *   **Total Objective:**
        $$ L_{total} = L_{sim} + \lambda_T L_T + \lambda_D L_D $$
        [S1].
4.  **Blending:** After training, render the edited scene by blending sample points from $F_{\theta_O}$ and $F_{\theta_G}$ along each view ray [S1].
    *   **Object Insertion/Replacement Mode:** During training, consider only $F_{\theta_G}$ inside ROI. After training, blend using distance smoothing [S1].
    *   **Object Blending Mode:** Query both $F_{\theta_O}$ and $F_{\theta_G}$ inside the box [S1].
        *   Compute alpha values for each point $\mathbf{x}_i$:
            $$ \alpha_O(\mathbf{x}_i) = 1 - \exp(\phi(\sigma_O(\mathbf{x}_i)) \cdot \delta_i) $$
            $$ \alpha_G(\mathbf{x}_i) = 1 - \exp(\phi(\sigma_G(\mathbf{x}_i)) \cdot \delta_i) $$
            where $\phi$ is a non-negative activation function [S1].
        *   **Density Blending Options:**
            *   Option 1 (Sum in activation): $\sigma(\mathbf{x}_i) = \phi(\sigma_O(\mathbf{x}_i) + \sigma_G(\mathbf{x}_i))$ [S1].
            *   Option 2 (Sum out activation): $\sigma(\mathbf{x}_i) = \phi(\sigma_O(\mathbf{x}_i)) + \phi(\sigma_G(\mathbf{x}_i))$ [S1].
        *   **Color Blending:**
            $$ c(\mathbf{x}_i) = S\left(\frac{c_O(\mathbf{x}_i) \cdot \alpha_O(\mathbf{x}_i) + c_G(\mathbf{x}_i) \cdot \alpha_G(\mathbf{x}_i)}{\epsilon + \alpha_O(\mathbf{x}_i) + \alpha_G(\mathbf{x}_i)}\right) $$
            where $S$ is the sigmoid function [S1].
    *   **Distance Smoothing:** For the final blend inside the ROI, use the distance smoothing operator based on distance $d(\mathbf{x})$ from the ROI center and box diagonal $diag$:
        $$ f(\mathbf{x}) = 1 - \exp\left(-\alpha \frac{d(\mathbf{x})}{diag}\right) $$
        $$ \sigma_{blend}(\mathbf{x}) = f(\mathbf{x}) \cdot \sigma_O(\mathbf{x}) + (1 - f(\mathbf{x})) \cdot \sigma_G(\mathbf{x}) $$
        $$ c_{blend}(\mathbf{x}) = f(\mathbf{x}) \cdot c_O(\mathbf{x}) + (1 - f(\mathbf{x})) \cdot c_G(\mathbf{x}) $$
        [S1].
    *   **Final Render:** The final rendered view $x_e$ is obtained by blending the raw densities and RGB values inside and outside the ROI along each ray using standard volume rendering [S1].

        return color_final

## Operating characteristics
*   **Time Complexity:** Training time depends on the number of iterations and the cost of querying two NeRFs per ray during blending evaluation, plus CLIP inference for the similarity loss. The use of a pre-trained CLIP model adds significant overhead per iteration compared to pure pixel-loss methods.
*   **Memory Complexity:** Requires storing two NeRF models ($F_{\theta_O}$ and $F_{\theta_G}$) and the CLIP model in memory.
*   **Strengths:** Does not require semantic masks or 2D masks for localization; works on any region defined by a 3D box; preserves the original scene outside the ROI; generates view-consistent results using priors.
*   **Limitations:** Quality depends on the text prompt and CLIP alignment; may produce amorphous or transparent scenes without proper priors ($L_T, L_D$); blending artifacts may occur at ROI boundaries if $\alpha$ is not tuned correctly; limited to text-guided editing.
*   **When to use:** When editing a specific object or region in an existing NeRF using text prompts without needing precise 2D masks or semantic segmentation.
*   **When not to use:** When high-fidelity geometric consistency is required without volumetric artifacts, or when editing requires complex semantic understanding beyond text prompts.

## Background
Blended-NeRF was introduced by Ori Gordon, Omri Avrahami, and Dani Lischinski from The Hebrew University in 2023 [S1]. It builds on the principles of Dream Fields [S1], which used CLIP to guide NeRF generation, and Volumetric Disentanglement [S1], which used 2D masks. Blended-NeRF differs from Dream Fields by editing existing scenes rather than generating new ones from scratch, and from Volumetric Disentanglement by using a 3D box instead of 2D masks [S1].
