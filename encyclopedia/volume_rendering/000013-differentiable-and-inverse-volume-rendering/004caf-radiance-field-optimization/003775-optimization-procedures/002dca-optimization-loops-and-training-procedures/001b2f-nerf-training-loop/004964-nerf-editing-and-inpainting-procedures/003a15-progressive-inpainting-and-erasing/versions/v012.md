# Progressive Inpainting-and-Erasing

Also called: Conflicted Geometry Detection and Erasing, Inpainting-and-Erasing Strategy, PERF, PERF Algorithm

## Overview
Progressive Inpainting-and-Erasing (PERF) is a training procedure for generating a panoramic Neural Radiance Field (NeRF) from a single input panorama. It solves the problem of geometry conflict and incomplete geometry that arises when expanding a NeRF from one view to multiple novel views by progressively inpainting invisible regions and erasing conflicted regions from the training supervision [S1]. It sets itself apart from other NeRF editing methods by explicitly detecting and removing geometric inconsistencies between the learned model and the inpainted guidance data, rather than relying solely on generative priors or multi-view consistency losses [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A single input panorama image $I_{rgb}$ [S1].
*   **Output:** A panoramic NeRF function $f_{nerf}$ mapping 3D coordinates and viewing directions to density $\sigma$ and color $\mathbf{c}$ [S1].

**Data Structures:**
*   **NeRF Representation:** Instant-NGP [S1]. Uses a hash table of size $2^{19}$ with 16 levels of feature vectors, each having a channel size of 2 [S1].
*   **Reference Views Set ($I_{ref}$):** A set containing the initial RGBD panorama and subsequently added inpainted RGBD panoramas [S1].
*   **Trajectories ($\{p_k\}$):** A set of novel camera poses generated based on the initial depth map [S1].

**Parameters:**
*   $\epsilon$: A small threshold value for depth difference comparison [S1].
*   Hash table size: $2^{19}$ [S1].
*   Levels: 16 [S1].
*   Feature vector channel size: 2 [S1].
*   Initial training iterations: 10,000 [S1].
*   New view sampling count: 32 positions with gradually increased distance from the original position [S1].
*   Fine-tuning iterations per new view: 2,000 total [S1].
    *   First 100 iterations: Supervision from the new reference view only [S1].
    *   Remaining 1,900 iterations: Supervision from all reference views [S1].
*   Optimizer: Adam [S1].
*   Learning rate: Initially $10^{-3}$, decaying to $10^{-4}$ using cosine annealing for each learning stage of a newly sampled view [S1].
*   Ray sampling: 2,048 rays per iteration [S1].

**Algorithm Steps:**

1.  **Initial Depth Estimation:** Estimate the initial depth map $I_d$ of the input panorama $I_{rgb}$ using a depth estimator [S1]. Combine $I_d$ and $I_{rgb}$ to form the initial RGBD panorama $I_{rgbd}$ [S1].
2.  **Single-View NeRF Training:** Train the single-view NeRF $f_{nerf}$ using $I_{rgbd}$ and $I_{rgb}$ for 10,000 iterations [S1].
3.  **Trajectory Generation:** Generate a set of novel view trajectories $\{p_k\}$ based on the estimated depth map $I_d$ [S1].
4.  **Initialization:** Initialize the set of reference views $I_{ref} = \{I_{rgbd}\}$ [S1].
5.  **Progressive Loop:** Iterate $n$ from 1 to `iters` (where `iters` corresponds to the number of new views, e.g., 32):
    a.  **Sample View:** Randomly sample a new camera pose $p$ from $\{p_k\}$ [S1].
    b.  **Invisible Region Detection:** Compute the mask of invisible regions $m'$ according to Equation (4) [S1]:
        $$ m'_{ij} = \mathbb{I}(\text{warp}(v'_{ij}) - v_{ij} > \epsilon) $$
        where $v_{ij}$ is the depth value from the reference view, $v'_{ij}$ is the depth value warped from the new view to the reference view, $\text{warp}(\cdot)$ is the warping function, $\mathbb{I}(\cdot)$ is the indicator function, and $\epsilon$ is the small threshold [S1]. A value of 1 indicates an invisible region (where the warped depth is significantly larger than the reference depth), and 0 indicates a visible region [S1].
    c.  **Collaborative RGBD Inpainting:** Perform inpainting on the invisible regions using Stable Diffusion for RGB and a depth estimator for depth stitching, guided by the mask $m'$ [S1]. This generates a completed panorama for the new view [S1].
    d.  **Conflict Detection and Erasing:** For every reference view $I_{ref} \in I_{ref}$:
        i.  Compute the conflicted region mask $m''$ according to Equation (6) [S1]:
            $$ m''_{ij} = \mathbb{I}(v_{ij} - \text{warp}(v'_{ij}) > \epsilon) $$
            where $v_{ij}$ is the depth from the new view and $v'_{ij}$ is the depth warped from the reference view to the new view [S1]. A value of 1 indicates inconsistent geometry (conflict), and 0 indicates consistent geometry [S1].
        ii. Erase these conflicted regions from the supervision of the NeRF training [S1].
    e.  **Update Reference Set:** Add the inpainted new view to the reference views set $I_{ref}$ [S1].
    f.  **Fine-Tuning:** Fine-tune $f_{nerf}$ with the updated $I_{ref}$ for 2,000 iterations [S1]. The first 100 iterations use only the new reference view for supervision, and the remaining 1,900 iterations use all reference views [S1].

**Pseudocode:**

```python
def progressive_inpainting_and_erasing(I_rgb, iters=32):
    # 1. Initial Depth Estimation
    I_d = estimate_depth(I_rgb) # Eq. (2)
    I_rgbd = combine(I_rgb, I_d)
    
    # 2. Single-View NeRF Training
    f_nerf = train_single_view_neRF(I_rgbd, I_rgb, iterations=10000)
    
    # 3. Trajectory Generation
    trajectories = generate_trajectories(I_d)
    
    # 4. Initialize Reference Views
    I_ref = {I_rgbd}
    
    # 5. Progressive Loop
    for n in range(1, iters + 1):
        # Sample new view
        p = random_sample(trajectories)
        
        # Render current NeRF at new view p to get depth v'
        v_prime = render_depth(f_nerf, p)
        
        # Get depth from existing reference views (v)
        # Note: In practice, this requires warping v' to reference views
        # and comparing with reference depths.
        
        # Compute invisible regions mask m'
        # m' indicates regions in the new view that are invisible in reference views
        m_prime = compute_invisible_mask(v_prime, I_ref, epsilon=epsilon)
        
        # Collaborative RGBD Inpainting
        # Inpaint RGB and Depth for regions in m'
        I_new_rgb = inpaint_rgb(I_rgb_at_p, m_prime, StableDiffusion)
        I_new_d = inpaint_depth(I_d_at_p, m_prime, DepthEstimator)
        I_new_rgbd = combine(I_new_rgb, I_new_d)
        
        # Conflict Detection and Erasing
        conflict_mask = compute_conflict_mask(v_prime, I_ref, epsilon=epsilon)
        
        # Add new view to reference set
        I_ref.add(I_new_rgbd)
        
        # Fine-tune NeRF
        # First 100 iters: only new view
        # Next 1900 iters: all views
        fine_tune(f_nerf, I_ref, conflict_mask, iterations=2000)
        
    return f_nerf

def compute_invisible_mask(v_prime, I_ref, epsilon):
    """
    Computes mask m' where 1 indicates invisible region.
    m'_ij = I(warp(v'_ij) - v_ij > epsilon)
    """
    m_prime = zeros_like(v_prime)
    for ref_view in I_ref:
        v_ref = ref_view.depth
        # Warp v_prime to reference view coordinate system
        v_prime_warped = warp(v_prime, ref_view.camera_params)
        # Compare depths
        diff = v_prime_warped - v_ref
        # Indicator function: 1 if diff > epsilon
        m_prime = logical_or(m_prime, (diff > epsilon))
    return m_prime

def compute_conflict_mask(v_prime, I_ref, epsilon):
    """
    Computes mask m'' where 1 indicates conflicted/inconsistent region.
    m''_ij = I(v_ij - warp(v'_ij) > epsilon)
    Final mask is AND of all individual masks from reference views.
    """
    final_conflict_mask = ones_like(v_prime) # Start with all true (conflicted)
    for ref_view in I_ref:
        v_ref = ref_view.depth
        # Warp v_ref to new view coordinate system
        v_ref_warped = warp(v_ref, inverse_camera_params(ref_view.camera_params))
        # Compare depths
        diff = v_ref_warped - v_prime
        # Indicator function: 1 if diff > epsilon
        individual_mask = (diff > epsilon)
        # Logic AND across all reference views
        final_conflict_mask = logical_and(final_conflict_mask, individual_mask)
    return final_conflict_mask

def fine_tune(f_nerf, I_ref, conflict_mask, iterations=2000):
    optimizer = Adam(f_nerf.parameters(), lr=1e-3)
    scheduler = CosineAnnealingLR(optimizer, T_max=iterations, eta_min=1e-4)
    
    for i in range(iterations):
        if i < 100:
            # Only supervise with new view (last added to I_ref)
            target_rgbd = I_ref[-1]
            # Apply conflict mask to exclude conflicted regions from loss
            loss = compute_loss(f_nerf, target_rgbd, conflict_mask)
        else:
            # Supervise with all reference views
            loss = 0
            for ref_rgbd in I_ref:
                # Note: Conflict mask needs to be computed for each view pair
                # For simplicity, assuming a global mask or per-view mask is applied
                loss += compute_loss(f_nerf, ref_rgbd, conflict_mask)
        
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        scheduler.step()
```

## Subtopics

### Collaborative RGBD Inpainting
A method to fill invisible regions in novel views using Stable Diffusion for RGB and a depth estimator for depth, guided by visibility masks [S1].

### Single-View NeRF Training
The initial training of a NeRF from a single panorama and its estimated depth map [S1].

## Operating characteristics
*   **Time Complexity:** Training a scene takes approximately 2 hours on a single Nvidia V100 GPU with 32G memory [S1]. The process involves iterative fine-tuning for each of the 32 new views [S1].
*   **Memory Complexity:** Uses Instant-NGP representation with a hash table size of $2^{19}$ [S1].
*   **Strengths:** Effectively avoids geometry conflict between visible and invisible regions, enabling the generation of consistent panoramic NeRFs from a single input [S1].
*   **Limitations:** Relies on the accuracy of the initial depth estimation and the inpainting model [S1]. The progressive nature requires multiple training stages [S1].
*   **When to use:** When only a single panorama is available and a full 3D representation is needed [S1].
*   **When not to use:** When multiple views are available, as other methods may be more efficient or accurate [S1].

## Background
PERF was introduced in the paper "PERF: Panoramic Neural Radiance Field From a Single Panorama" [S1]. It addresses the challenge of reconstructing a 3D scene from a single panoramic image, a task that is ill-posed due to the lack of multi-view information. The method builds on the Instant-NGP representation [S1] and integrates generative inpainting techniques [S1].
