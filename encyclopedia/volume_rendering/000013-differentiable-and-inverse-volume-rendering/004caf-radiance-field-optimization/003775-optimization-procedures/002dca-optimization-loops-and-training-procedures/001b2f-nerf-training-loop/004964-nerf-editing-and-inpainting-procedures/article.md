# NeRF Editing and Inpainting Procedures

Also called: NeRF Editing, NeRF Inpainting, 3D Content Editing

## Overview
NeRF Editing and Inpainting Procedures modify a pre-trained Neural Radiance Field (NeRF) to achieve visual changes such as object deletion, colorization, geometric translation, or the removal of unwanted objects without retraining the entire model from scratch. These methods solve the problem of efficient, localized 3D editing by either intercepting the volume rendering query at inference time to apply transforms or by optimizing the underlying radiance field parameters $\Theta$ using external 2D priors (such as diffusion models or inpainting networks) to guide the reconstruction of missing or modified geometry [S1, Parent]. They differ from standard NeRF training by actively synthesizing novel views or refining missing geometry via 2D priors and explicitly masking out regions where the learned 3D geometry contradicts multi-view consistency constraints [S1].

## Shared principles
The family shares the fundamental goal of altering the appearance or geometry of a scene represented by a NeRF $F_\Theta$ while preserving the integrity of unedited regions. The core mechanism involves either:
1.  **Inference-Time Interception:** Keeping $\Theta$ fixed and modifying the density $\sigma$ or color $\mathbf{c}$ of sampled points $\mathbf{x}_i$ along a ray $\mathbf{r}$ based on selection probabilities $p_i$ derived from auxiliary models (e.g., Distilled Feature Fields) or user masks [Parent, 12491-nerf-editing-procedure.md].
2.  **Optimization-Based Editing:** Updating $\Theta$ by minimizing a joint loss function that combines photometric reconstruction loss with guidance derived from 2D priors (e.g., inpainted images, depth maps, or diffusion features) [S1, 12372-nerf-in-inpainting-optimization.md].

Common data structures include the NeRF MLP mapping $(\mathbf{x}, \mathbf{v}) \to (\sigma, \mathbf{c})$, ray sampling strategies (stratified or hierarchical), and volume rendering integrators. Common parameters include learning rates (typically $10^{-4}$ to $10^{-3}$), optimizer settings (Adam), and thresholds for selection or conflict detection ($\epsilon, \tau$).

## Subtopics

### [Progressive Inpainting-and-Erasing](8658-progressive-inpainting-and-erasing.md)
A training procedure for reconstructing a panoramic NeRF from a single input panorama. It solves the problem of geometry conflict between visible and invisible regions by iteratively generating novel views, inpainting missing content, and erasing geometrically inconsistent pixels. It differs from standard training by actively synthesizing missing geometry via 2D priors (Stable Diffusion) and explicitly masking out regions where 3D geometry contradicts multi-view constraints.

### [Deceptive-NeRF/3DGS Pipeline](11860-deceptive-nerf-3dgs-pipeline.md)
A sparse-view reconstruction method that enhances NeRF or 3D Gaussian Splatting by continuously densifying input observations with synthetic pseudo-observations generated by a diffusion model during training. It distinguishes itself by introducing an uncertainty map derived from cross-view correspondence matching to enforce 3D consistency, rather than relying on ensemble learning or variational inference.

### [DFF (Decomposing NeRF for Editing Via Feature Field Distillation)](12068-dff-decomposing-nerf-for-editing-via-feature-field-distillat.md)
Enables 3D semantic segmentation and editable novel-view synthesis by distilling features from a pre-trained 2D teacher network (LSeg or DINO) into a neural radiance field. It provides robust semantic decomposition for multi-view consistent editing without re-optimizing the radiance field for every edit, unlike optimization-based methods.

### [Blended-NeRF](12273-blended-nerf.md)
A framework for editing a specific region of interest (ROI) in an existing NeRF based on text prompts and a user-defined 3D ROI box. It solves local 3D editing by initializing a generator NeRF with original weights and blending synthesized content with the original scene using volumetric blending, operating on any region without learning a new feature space or requiring 2D masks.

### [NeRF-In Inpainting Optimization](12372-nerf-in-inpainting-optimization.md)
An optimization-based framework for removing unwanted objects from a pre-trained NeRF without category-specific training data. It solves "free-form" editing by updating NeRF parameters to minimize a joint loss combining color and depth guidance derived from 2D inpainting and depth completion priors, explicitly optimizing the underlying radiance field rather than modifying rendering queries.

### [Adaptive View Selection for Inpainting](12405-adaptive-view-selection-for-inpainting.md)
A method for 3D scene de-occlusion and inpainting that integrates a 2D image inpainter with a NeRF optimization loop. It addresses the limitation of single 2D inpainters by dynamically selecting whether to rely on 2D appearance priors or supplementary information from other training views based on local texture richness (gradient magnitude).

### [NeRF Editing Procedure](12491-nerf-editing-procedure.md)
Modifies a pre-trained NeRF to achieve visual changes (deletion, colorization, translation) by intercepting the volume rendering query at inference time. It keeps $\Theta$ fixed and applies transforms to $\sigma$ or $\mathbf{c}$ based on selection probabilities from auxiliary models, distinguished from optimization-based methods by its non-optimization-based, inference-time nature.

### Semantic Inpainting for Neural Fields
- **Definition:** A 3D content editing capability allowing editing of neural fields through simple interfaces like free-form sketching or language instructions [S1].
- **Step:** Given a user-supplied edit in a single reference view, the encoding of a neural field automatically propagates this edit to all views. This propagation promotes consistency between all views thanks to the implicit geometrical and photometric priors embodied by the neural network, preserving the structure of the whole scene [S1].
- **History:** Described in reference [19] [S1].

### Post-Refinement Strategy
- **Definition:** A strategy employed after the NeRF has been trained on updated data to enhance consistency by generating a more accurate target for each view using the modified Instruct-Pix2Pix with averaging architecture [S2].
- **Step:** Use the rendered image as input while continuing to use the mixup image as a condition [S2].

## Background
The concept of 3D content editing in neural fields emerged as NeRF technology matured, moving from static reconstruction to interactive manipulation. Early developments allowed editing through simple interfaces like free-form sketching or language instructions, leveraging the implicit geometrical and photometric priors of the neural network to propagate edits across views [S1]. Recent advancements integrate generative models (e.g., Stable Diffusion, DreamFusion) and 2D priors (inpainting, depth completion) to handle sparse views, occlusions, and object removal. Methods like Deceptive-NeRF and Blended-NeRF represent the shift towards diffusion-guided optimization and local volumetric blending, while DFF and inference-time editing procedures focus on semantic decomposition and efficient, non-iterative manipulation [S1, Parent].
