# NeRF Editing Procedure

Also called: Inference-Time Interception, DFF-Based Editing, Local Editing via SAM

## Overview
The NeRF Editing Procedure modifies a pre-trained Neural Radiance Field (NeRF) to achieve visual changes such as object deletion, colorization, or geometric translation without retraining the entire model from scratch. It solves the problem of efficient, localized 3D editing by intercepting the volume rendering query at inference time. Unlike optimization-based methods that update NeRF parameters $\Theta$ via iterative loss minimization [S1, S2], this method keeps $\Theta$ fixed and applies transforms to the density $\sigma$ or color $\mathbf{c}$ based on semantic or geometric selection probabilities derived from auxiliary models like a Distilled Feature Field (DFF) [S1]. It is distinguished from [Progressive Inpainting-and-Erasing](8658-progressive-inpainting-and-erasing.md) by its reliance on explicit feature-field queries for selection rather than erasing masks, and from [NeRF-In Inpainting Optimization](12372-nerf-in-inpainting-optimization.md) by its non-optimization-based, inference-time nature.

## How it works
The method operates by modifying the standard NeRF rendering pipeline. It requires a pre-trained NeRF $\Theta$ and an auxiliary selection model (e.g., DFF) that outputs a probability $p$ indicating whether a 3D coordinate $\mathbf{x}$ belongs to a target semantic region or object.

### Inputs and Outputs
*   **Inputs:**
    *   NeRF parameters $\Theta$ (density and color networks).
    *   Auxiliary selection model (e.g., DFF) capable of outputting a selection probability $p \in [0, 1]$ for a given 3D coordinate $\mathbf{x}$ and query.
    *   Camera pose and ray origin/direction for rendering.
    *   Editing transform parameters (e.g., deletion flag, colorization function $b$, translation vector $\mathbf{t}$).
    *   Selection threshold $\tau$ (user-defined).
*   **Outputs:**
    *   Rendered image with applied edits.

### Data Structures
*   **Ray Sample Points:** A list of 3D coordinates $\mathbf{x}_i$ sampled along the ray, typically using stratified sampling or importance sampling as defined in the base NeRF [S1].
*   **Selection Probability:** A scalar $p_i \in [0, 1]$ for each point $\mathbf{x}_i$, output by the DFF.
*   **Density/Color Tuples:** Modified $(\sigma'_i, \mathbf{c}'_i)$ pairs passed to the volume rendering integrator.

### Steps
1.  **Ray Sampling:** Sample points $\mathbf{x}_i$ along the viewing ray $\mathbf{r}$ as in standard NeRF [S1].
2.  **Feature Query:** For each point $\mathbf{x}_i$, query the DFF to calculate the probability $p_i$ that the coordinate matches the target query [S1].
3.  **Selection Decision:** Define the coordinate as "selected" if $p_i > \tau$, otherwise "not selected" [S1]. Alternatively, use the probability $p_i$ directly as a mixing weight without a hard threshold [S1].
4.  **Transform Application:**
    *   **If not selected:** Compute standard density $\sigma(\mathbf{x}_i)$ and color $\mathbf{c}(\mathbf{x}_i)$ using the vanilla NeRF [S1].
    *   **If selected:** Apply the specific editing transform:
        *   **Deletion:** Set density $\sigma'(\mathbf{x}_i) = 0$. Color $\mathbf{c}'(\mathbf{x}_i)$ is irrelevant as it will be occluded by subsequent transparent layers [S1].
        *   **Color Editing:** Query NeRF for $\sigma(\mathbf{x}_i)$ and $\mathbf{c}(\mathbf{x}_i)$. Transform the color using a colorization function $b$: $\mathbf{c}'(\mathbf{x}_i) = b(\mathbf{c}(\mathbf{x}_i))$. Density remains $\sigma'(\mathbf{x}_i) = \sigma(\mathbf{x}_i)$ [S1].
        *   **Translation/Rescaling:** Compute the inverse transformation $\mathbf{x}_0 = g^{-1}(\mathbf{x}_i)$, where $g$ is the editing transformation (e.g., $\mathbf{x}_0 = \mathbf{x}_i - \mathbf{t}$ for translation) [S1].
            *   If $\mathbf{x}_0$ is also "selected" by the query, use $\mathbf{x}_0$ to query the NeRF for density $\sigma(\mathbf{x}_0)$ and color $\mathbf{c}(\mathbf{x}_0)$ [S1].
            *   If both $\mathbf{x}_i$ and $\mathbf{x}_0$ are selected and have non-zero density (e.g., at boundaries), mix the colors $\mathbf{c}(\mathbf{x}_i)$ and $\mathbf{c}(\mathbf{x}_0)$ in the ratio of their alphas $\alpha_i$ and $\alpha_0$ for simplicity [S1].
5.  **Volume Rendering:** Perform standard volume rendering using the series of modified $(\sigma'_i, \mathbf{c}'_i)$ tuples [S1].

### Pseudocode
```python
def render_edited_ray(ray_origin, ray_direction, nerf_model, dff_model, 
                      edit_type, threshold, color_func=None, transform_inv=None):
    """
    Renders a single ray with editing applied via inference-time interception.
    
    Args:
        ray_origin: 3D vector, origin of the ray.
        ray_direction: 3D vector, direction of the ray.
        nerf_model: Function returning (sigma, color) for a 3D point.
        dff_model: Function returning probability p for a 3D point.
        edit_type: String, one of 'deletion', 'color', 'translation'.
        threshold: Float, selection threshold tau.
        color_func: Function b(c), used if edit_type is 'color'.
        transform_inv: Function g^-1(x), used if edit_type is 'translation'.
        
    Returns:
        color: 3D vector, the final pixel color.
    """
    # 1. Sample points along the ray (Standard NeRF sampling)
    # Assuming T samples, t_n is the distance along the ray
    t_vals = sample_t_vals(ray_origin, ray_direction, num_samples=128)
    points = ray_origin + ray_direction * t_vals
    
    # Storage for modified density and color
    sigmas = []
    colors = []
    
    for i, x in enumerate(points):
        # 2. Query DFF for selection probability
        p = dff_model.query(x)
        
        # 3. Determine if selected
        is_selected = p > threshold
        
        if not is_selected:
            # Not selected: Use vanilla NeRF
            sigma, c = nerf_model(x)
            sigmas.append(sigma)
            colors.append(c)
        else:
            # Selected: Apply transform
            if edit_type == 'deletion':
                # 4-A: Deletion sets density to zero
                sigmas.append(0.0)
                colors.append([0.0, 0.0, 0.0]) # Color irrelevant
            elif edit_type == 'color':
                # 4-B: Color editing
                sigma, c = nerf_model(x)
                sigmas.append(sigma)
                colors.append(color_func(c))
            elif edit_type == 'translation':
                # 4'-C: Translation/Rescaling
                x0 = transform_inv(x)
                
                # Query NeRF for original point
                sigma_x, c_x = nerf_model(x)
                
                # Check if transformed point is also selected
                p0 = dff_model.query(x0)
                is_selected_x0 = p0 > threshold
                
                if is_selected_x0:
                    sigma_x0, c_x0 = nerf_model(x0)
                    
                    # If both selected and non-zero density, mix colors by alpha
                    # Alpha is derived from sigma and distance delta (simplified here)
                    # Note: Standard NeRF alpha calculation requires delta_t
                    # For simplicity in this pseudocode, we assume sigma represents 
                    # the contribution magnitude or use a standard alpha approximation.
                    alpha_x = 1.0 - torch.exp(-sigma_x)
                    alpha_x0 = 1.0 - torch.exp(-sigma_x0)
                    
                    # Mix ratio based on alphas
                    total_alpha = alpha_x + alpha_x0
                    if total_alpha > 0:
                        w_x = alpha_x / total_alpha
                        w_x0 = alpha_x0 / total_alpha
                        c_mixed = w_x * c_x + w_x0 * c_x0
                    else:
                        c_mixed = c_x
                        
                    sigmas.append(sigma_x) # Keep original sigma for occlusion logic
                    colors.append(c_mixed)
                else:
                    # Only x is selected, x0 is not (or not queried)
                    # Use x's properties but potentially modified? 
                    # Source says: "If x0 is selected... x0 is used instead of x"
                    # If x0 is NOT selected, we fall back to standard behavior for x?
                    # Or do we use x's color? The source implies using x0's color IF selected.
                    # If not selected, we likely just use x's color as normal NeRF would,
                    # but since x IS selected, we might need to decide.
                    # The source says: "If x0 is selected by the query, x0 is used instead of x 
                    # for calculating color and density."
                    # Implies if x0 is NOT selected, we use x.
                    sigmas.append(sigma_x)
                    colors.append(c_x)
            else:
                # Default: Vanilla
                sigma, c = nerf_model(x)
                sigmas.append(sigma)
                colors.append(c)
                
    # 5. Volume Rendering
    # Standard alpha compositing
    accumulated_color = [0.0, 0.0, 0.0]
    accumulated_alpha = 0.0
    
    for i in range(len(sigmas)):
        sigma = sigmas[i]
        c = colors[i]
        # Delta t calculation would be needed for precise alpha
        # Assuming uniform sampling for simplicity in pseudocode structure
        delta = t_vals[i+1] - t_vals[i] if i < len(t_vals)-1 else 0.01
        alpha = 1.0 - torch.exp(-sigma * delta)
        
        weight = alpha * (1.0 - accumulated_alpha)
        accumulated_color += weight * c
        accumulated_alpha += weight
        
        if accumulated_alpha > 0.99: # Early termination
            break
            
    return accumulated_color
```

### Parameters and Edge Cases
*   **Threshold $\tau$:** Controls the strictness of selection. A higher $\tau$ results in less aggressive editing. [S1]
*   **Probability Mixing:** Instead of a hard threshold, the probability $p$ can be used as a mixing weight between selected and not-selected results [S1].
*   **Boundary Mixing:** In translation, if both the original point $\mathbf{x}$ and the transformed point $\mathbf{x}_0$ are selected and have non-zero density, their colors are mixed in the ratio of their alphas to handle overlaps at boundaries [S1].
*   **Pitfall:** Incorrect depth estimation or glossy surfaces can lead to misalignment in projection-based methods, though the DFF method is less sensitive to depth errors as it operates on 3D coordinates directly [S2].

## Subtopics

### Local Editing via SAM and Depth Propagation
A technique to edit specific objects within a NeRF without altering the background, using 2D segmentation masks propagated across views via depth information [S2]. It employs the Segment Anything Model (SAM) to derive masks for all components in each image, allowing users to isolate a target instance with a single point [S2]. The identified mask is projected across different views progressively using depth information, continuing as long as the projected mask sufficiently overlaps with the corresponding mask in the current view [S2]. The wrapped segmentation mask is then integrated with the segmented masks in the current view [S2]. This method addresses the pitfall where existing methods induce simultaneous changes in both background and foreground, contradicting user intentions to alter distinct objects [S2].

### ViCA-NeRF Warm-Up
A strategy to efficiently warm up the editing process by blending edits directly before the entire editing process, accelerating editing while preserving consistency [S2]. It randomly selects a view to edit and projects the edited view onto all other views [S2]. The update for a given view $i$ and an edited view $j$ is calculated as:
$$ I_i' = \lambda I_i \odot m_w + (1 - \lambda) I_{i,j} \odot m_w + I_i \odot (1 - m_w) $$
where $m_w$ is the binary mask for the projected area and $\lambda$ is a hyperparameter controlling the ratio preserved from the original pixel value [S2].

### NeRF-RPN Application
A method to edit the scene by setting the density inside a proposal bounding box to zero when rendering, based on proposals produced by a NeRF Region Proposal Network (NeRF-RPN) [S3]. This allows for object deletion or occlusion based on 3D object detection proposals [S3].

## Operating characteristics
*   **Time Complexity:** $O(N)$ per ray, where $N$ is the number of samples. The additional cost is the query to the DFF for each sample point. Since the NeRF is not retrained, the total time is dominated by the rendering pass, making it significantly faster than optimization-based methods [S1, S2].
*   **Memory Complexity:** Requires storing the NeRF parameters $\Theta$ and the DFF model parameters. No additional memory for gradient storage or optimization states is needed [S1].
*   **Strengths:** Real-time or near-real-time editing capability; no iterative training required; precise control via semantic queries [S1].
*   **Limitations:** Relies on the quality of the auxiliary model (DFF); may produce artifacts if the selection probability is noisy; limited to edits that can be expressed as local transforms (deletion, color, translation) [S1].
*   **When to use:** When real-time editing is required, or when the editing goal is simple (deletion, recoloring) and semantic segmentation is available [S1].
*   **When not to use:** When complex structural changes or global style transfers that require coherent 3D optimization are needed [S2].

## Background
The NeRF Editing Procedure via inference-time interception was introduced in "Decomposing NeRF for Editing Via Feature Field Distillation" (DFF) [S1]. The method leverages a Distilled Feature Field (DFF) trained to predict semantic probabilities for 3D coordinates, allowing for the decomposition of the NeRF into editable components. This approach contrasts with optimization-based editing methods like Instruct-NeRF2NeRF, which require iterative updates [S2]. The DFF method was developed to provide a more efficient and flexible way to edit NeRFs by separating the semantic understanding (DFF) from the geometric appearance (NeRF) [S1].
