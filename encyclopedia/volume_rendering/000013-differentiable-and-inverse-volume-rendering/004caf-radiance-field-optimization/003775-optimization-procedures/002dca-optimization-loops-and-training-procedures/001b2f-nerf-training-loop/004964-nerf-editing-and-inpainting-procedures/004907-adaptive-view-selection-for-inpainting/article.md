# Adaptive View Selection for Inpainting

Also called: 3D Inpainting Component, 3D Inpainting Component with Adaptive View Selection, Adaptive Weight Inpainting, Gradient-Based View Selection

## Overview
Adaptive View Selection for Inpainting is a method for 3D scene de-occlusion that combines a pretrained 2D image inpainter with multi-view NeRF optimization to recover occluded regions [S1]. It solves the problem of inconsistent 3D geometry and texture when inpainting occluded areas by selectively using 2D inpainting priors only when multi-view geometric consistency cannot be established [S1]. It differs from sibling methods like [Blended-NeRF](12273-blended-nerf.md) or [NeRF-In Inpainting Optimization](12372-nerf-in-inpainting-optimization.md) by explicitly evaluating the texture richness (via regional average gradients) of occluded sub-regions to adaptively switch between relying on 2D appearance priors and relying on multi-view NeRF reconstruction [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A pre-trained NeRF representation $F_\Theta$ mapping $(\mathbf{x}, \mathbf{v}) \to (\sigma, \mathbf{c})$; a set of input views with known camera poses; a binary mask $M$ defining the occluded region in at least one reference view; a pretrained 2D image inpainter (specifically LaMa [S1]).
*   **Outputs:** An optimized NeRF model $F_{\Theta'}$ where the occluded regions are filled with geometrically consistent texture; rendered novel views with the occlusion removed.

**Data Structures:**
*   **NeRF Model:** Standard MLP-based NeRF with coarse and fine networks, outputting color $\mathbf{c}$ and density $\sigma$.
*   **Mask:** A predicted mask $\hat{P}(r)$ for each ray $r$, indicating the probability of the ray passing through an occluded region.
*   **2D Inpainting Prior:** An image $I_l$ generated by the 2D inpainter, where occluded pixels are filled. The color of a pixel in this image is denoted $C_l(r)$.
*   **Sub-regions:** The occluded area in each view is divided into multiple sub-regions (patches) to evaluate local texture gradients [S1].

**Numbered Steps:**

1.  **Initial 2D Inpainting:** Apply the pretrained 2D inpainter (LaMa) to the input views containing occlusions to generate initial appearance priors $I_l$ [S1].
2.  **Region Coding and Mask Prediction:** Use a region coding network (object segmentation network) constrained by depth information to automatically infer masks $M = \{M_s | s = 1...K\}$ for all views, identifying occluded pixels [S1]. Let $\hat{P}(r)$ be the mask value for ray $r$.
3.  **Sub-region Division:** Divide the occluded area in each view into multiple sub-regions (patches) [S1].
4.  **Gradient Evaluation:** For each sub-region, calculate the average gradient of the rendered NeRF result ($\nabla \hat{g}$) and the average gradient of the 2D inpainting result ($\nabla g$) [S1].
5.  **Adaptive Weight Calculation:** Determine the adaptive weight $\lambda$ for the reconstruction loss based on the gradient comparison [S1]:
    $$
    \lambda = \begin{cases} 
    1 & \text{if } \nabla \hat{g} > \tau \cdot \nabla g \\
    0 & \text{if } \nabla \hat{g} \le \tau \cdot \nabla g 
    \end{cases}
    $$
    Here, $\tau$ is a threshold parameter [S1]. If the NeRF rendered gradient is sufficiently rich compared to the 2D inpainting gradient, the method trusts the multi-view NeRF reconstruction ($\lambda=1$). Otherwise, it relies more on the 2D prior ($\lambda=0$) [S1].
6.  **Loss Computation:** Compute the total reconstruction loss $L$ as a weighted sum of non-occluded loss $L_{NonOcc}$ and occluded loss $L_{Occ}$ [S1]:
    $$
    L = \lambda L_{NonOcc} + (1 - \lambda) L_{Occ}
    $$
    *   **Non-occluded Loss ($L_{NonOcc}$):** Constrains the NeRF to match ground truth colors in non-occluded areas [S1]:
        $$
        L_{NonOcc} = \sum_{r \in R} (1 - \hat{P}(r)) \left[ ||\hat{C}_c(r) - C(r)||_2^2 + ||\hat{C}_f(r) - C(r)||_2^2 \right]
        $$
        where $\hat{C}_c(r)$ and $\hat{C}_f(r)$ are the coarse and fine predicted colors, $C(r)$ is the ground truth color, and $R$ is the set of rays [S1].
    *   **Occluded Loss ($L_{Occ}$):** Guides the NeRF to match the 2D inpainting prior in occluded areas [S1]:
        $$
        L_{Occ} = \sum_{r \in R} \hat{P}(r) \left[ ||\hat{C}_c(r) - C_l(r)||_2^2 + ||\hat{C}_f(r) - C_l(r)||_2^2 \right]
        $$
        where $C_l(r)$ is the color of the corresponding pixel in the 2D inpainting image $I_l$ [S1].
7.  **Optimization:** Update NeRF parameters $\Theta$ by minimizing $L$. The method also jointly optimizes the region coding network using a combination of region encoding loss, RGB loss, and depth loss to ensure multi-view consistency of the masks [S1].

def adaptive_view_selection_inpainting(nerf_model, input_views, masks_2d, lama_inpainter, tau):
    """
    Performs 3D inpainting using adaptive view selection.
    
    Args:
        nerf_model: Pre-trained NeRF with coarse and fine networks.
        input_views: List of input images and camera poses.
        masks_2d: Binary masks for occluded regions in input views.
        lama_inpainter: Pretrained 2D inpainter (LaMa).
        tau: Threshold for gradient comparison.
        
    Returns:
        Optimized NeRF model.
    """
    # Step 1: Generate 2D inpainting priors
    inpainted_views = []
    for view in input_views:
        if has_occlusion(view.mask):
            # Apply LaMa to inpaint occluded areas
            prior_image = lama_inpainter.inpaint(view.image, view.mask)
        else:
            prior_image = view.image
        inpainted_views.append(prior_image)

    # Step 2: Initialize Region Coding Network (Segmentation)
    # This network predicts masks M for all views based on depth constraints
    region_coder = initialize_region_coding_network()
    
    # Step 3: Optimization Loop
    for epoch in range(num_epochs):
        total_loss = 0.0
        
        for view_idx, view in enumerate(input_views):
            rays = render_rays(view.camera_pose)
            
            # Predict mask for each ray using region coder
            # P_hat(r) is the probability that ray r is in an occluded region
            P_hat = region_coder.predict_mask(rays, view.depth)
            
            # Render coarse and fine colors from NeRF
            C_c, C_f = nerf_model.render_coarse_fine(rays)
            
            # Get ground truth colors
            C_gt = view.colors
            
            # Get 2D inpainting prior colors
            C_l = get_prior_colors(inpainted_views[view_idx], rays)
            
            # Divide occluded area into sub-regions (patches)
            sub_regions = divide_into_patches(view.mask)
            
            # Calculate adaptive weight lambda based on regional gradients
            lambda_weight = 0.0
            for sub_region in sub_regions:
                # Calculate average gradient of rendered NeRF result in this sub-region
                grad_rendered = calculate_average_gradient(C_c[sub_region], C_f[sub_region])
                # Calculate average gradient of 2D inpainting result in this sub-region
                grad_prior = calculate_average_gradient(C_l[sub_region])
                
                # Adaptive weight logic
                if grad_rendered > tau * grad_prior:
                    lambda_weight += 1.0
                else:
                    lambda_weight += 0.0
            
            # Average lambda over sub-regions (or use per-pixel logic if implemented differently)
            # Note: The source formula implies a single lambda for the loss term, 
            # but the text describes evaluating sub-regions individually. 
            # We assume lambda is computed per sub-region or averaged. 
            # For simplicity in this pseudocode, we assume a global lambda for the view 
            # based on the average of sub-region evaluations, or apply per-pixel if P_hat is dense.
            # The source formula (6) defines lambda as a scalar for the loss L.
            # We will compute a global lambda for the view based on the average gradient comparison.
            
            avg_grad_rendered = calculate_average_gradient(C_c, C_f)
            avg_grad_prior = calculate_average_gradient(C_l)
            
            if avg_grad_rendered > tau * avg_grad_prior:
                lambda_weight = 1.0
            else:
                lambda_weight = 0.0

            # Calculate Non-Occluded Loss
            # L_NonOcc = sum((1 - P_hat) * (||C_c - C_gt||^2 + ||C_f - C_gt||^2))
            non_occluded_mask = 1.0 - P_hat
            loss_non_occ = sum(non_occluded_mask * (squared_error(C_c, C_gt) + squared_error(C_f, C_gt)))
            
            # Calculate Occluded Loss
            # L_Occ = sum(P_hat * (||C_c - C_l||^2 + ||C_f - C_l||^2))
            occluded_mask = P_hat
            loss_occ = sum(occluded_mask * (squared_error(C_c, C_l) + squared_error(C_f, C_l)))
            
            # Total Loss for this view
            loss = lambda_weight * loss_non_occ + (1.0 - lambda_weight) * loss_occ
            
            # Add depth loss and region coding loss if optimizing region coder
            # L = lambda1 * L_region + lambda2 * L_rgb + lambda3 * L_depth
            # For simplicity, we focus on the NeRF optimization loss defined in the prompt
            
            total_loss += loss
            
        # Backpropagate and update NeRF and Region Coder
        optimize(nerf_model, region_coder, total_loss)
        
    return nerf_model

def calculate_average_gradient(color_image):
    """Calculates the average magnitude of gradients in an image."""
    # Compute gradients in x and y directions
    grad_x = compute_gradient_x(color_image)
    grad_y = compute_gradient_y(color_image)
    # Magnitude
    magnitude = sqrt(grad_x**2 + grad_y**2)
    return mean(magnitude)

def squared_error(pred, target):
    return (pred - target)**2

*   $\lambda_1, \lambda_2, \lambda_3$: Weights for the region coding network optimization (region encoding, RGB, depth losses). Not given in the sources. [G: Standard weights like 1.0 are often used, but not specified.]

**Edge Cases and Pitfalls:**
*   **Uniform Strategy Misjudgment:** Applying a uniform strategy to the entire occluded area can lead to misjudgment. The method avoids this by dividing the occluded area into sub-regions and evaluating gradients individually [S1].
*   **2D Inpainter Inconsistency:** Single 2D image inpainting does not consider 3D consistency. Relying solely on it can result in geometrically inconsistent textures. The adaptive selection mitigates this by switching to multi-view NeRF reconstruction when gradients are rich [S1].
*   **Mask Accuracy:** The accuracy of the inpainting depends on the accuracy of the predicted masks $\hat{P}(r)$. Errors in mask prediction can lead to incorrect application of the 2D prior or NeRF reconstruction [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the number of epochs, number of views, and the cost of the 2D inpainter (LaMa) and NeRF rendering. LaMa is a large CNN, so initial inpainting is costly. NeRF optimization is iterative.
*   **Memory Complexity:** Requires storing the NeRF model, the 2D inpainter model, and intermediate gradients.
*   **Strengths:** Improves fidelity of de-occluded results by leveraging multi-view correlation. Avoids the disturbing effect of 2D inpainters when multi-view information is sufficient.
*   **Limitations:** Relies on the quality of the 2D inpainter (LaMa). Requires a region coding network for mask prediction. Performance depends on the availability of multi-view data.
*   **When to use:** When inpainting occluded areas in NeRF scenes where multi-view consistency is important and 2D inpainting alone is insufficient.
*   **When not to use:** When computational resources are limited and a single-view approximation is acceptable. When multi-view data is sparse or inconsistent.

## Background
The method was proposed in "3D Scene De-occlusion in Neural Radiance Fields: A Framework for Obstacle Removal and Realistic Inpainting" [S1]. It addresses the limitations of 2D inpainting in 3D scenes by introducing a training view selection mechanism based on regional average gradients. The method uses LaMa [S1] as the 2D inpainter. It has been evaluated on the LLFF and SPIn-NeRF datasets [S1].
