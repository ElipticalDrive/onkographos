# DFF (Decomposing NeRF for Editing Via Feature Field Distillation)
Also called: LSeg-DFF, DINO-DFF

## Overview
DFF enables 3D semantic segmentation and editable novel-view synthesis by distilling features from a 2D teacher network (such as LSeg or DINO) into a neural radiance field, allowing the decomposition of scenes into semantic regions [S1]. Unlike methods that rely on explicit semantic labels or on-the-fly geometric masking, DFF learns a dedicated feature field that disentangles semantic information from appearance, enabling editing via semantic queries without retraining the underlying geometry [S1, 12491-nerf-editing-procedure.md]. It sets itself apart by achieving segmentation performance competitive with supervised 3D models while maintaining multi-view consistency for editing tasks, overcoming the entanglement of low-level factors (color, spatial adjacency) found in standard NeRF hidden layers [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of posed training images $I$, camera poses, and optionally a 2D teacher network (LSeg or DINO). For DINO-DFF, an image patch query is also required.
*   **Outputs:** A radiance field $f_\theta$ mapping $(\mathbf{x}, \mathbf{d}) \to (\sigma, \mathbf{c})$ and a feature field $f_\phi$ mapping $\mathbf{x} \to \mathbf{f}$, where $\mathbf{f}$ represents semantic features. The system outputs edited novel views by modulating $\mathbf{c}$ based on semantic probabilities derived from $\mathbf{f}$ [S1].

**Data Structures and Layout:**
The radiance field uses a single MLP with the following architecture [S1]:
1.  **Input Encoding:** Positional Encoding (PE) of length 10 for input coordinate $\mathbf{x}$ and its skip connection; PE of length 4 for viewing direction $\mathbf{d}$.
2.  **Shared Layers:** Eight ReLU layers with 256 dimensions.
3.  **Branches:**
    *   **Density Branch:** One linear layer outputting $\sigma$.
    *   **Color Branch:** Three linear layers outputting $\mathbf{c}$.
    *   **Feature Branch:** Three linear layers outputting $\mathbf{f}$ (used in branch-based DFF).

Alternatively, an **Independent Feature Field** can be used [S1]:
*   An independent MLP with four layers.
*   If PE is used, a skip connection is added at the third layer.
*   For smooth decomposition, this MLP may omit PE entirely [S1].

**Training Phases:**
1.  **Radiance Field Pre-training:** Train the radiance field (without feature branch) for 200K iterations using photometric loss $L_p$ [S1].
2.  **Feature Distillation (Finetuning):** Finetune the network (adding the feature branch or training the independent MLP) for 5K iterations using combined loss $L_p + \lambda L_f$ [S1].

**Formulas:**
The volume rendering equation remains [S1, 12491-nerf-editing-procedure.md]:
$$ \hat{C}(r) = \sum_{i=1}^{N} w_i c_i $$
where $w_i = T_i (1 - \exp(-\sigma_i \delta_i))$, $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$, and $\delta_i = t_i - t_{i-1}$.

The total loss is [S1]:
$$ L = L_p + \lambda L_f $$
where $L_p$ is the photometric reconstruction loss (e.g., $L_1$ or SSIM between rendered and input images) and $L_f$ is the feature distillation loss [S1].

**Teacher Network Feature Extraction (LSeg):**
1.  Encode each training image $I$ using the LSeg image encoder to generate target feature maps $f_{img}(I, r)$ [S1].
2.  Resize target feature maps to the original image size to compensate for reduced resolution [S1].
3.  Encode text labels using the LSeg text encoder.
4.  Calculate the probability $p$ of a point belonging to a label using cosine similarity [S1]:
    $$ p = \frac{\mathbf{f} \cdot \mathbf{t}}{\|\mathbf{f}\| \|\mathbf{t}\|} $$
    where $\mathbf{f}$ is the rendered feature and $\mathbf{t}$ is the text-encoded label vector. Softmax is applied over labels [S1].

**Teacher Network Feature Extraction (DINO):**
1.  Use an image patch query. Calculate the patch feature by averaging features of all pixels in the patch [S1].
2.  Compute probability $p$ using thresholded cosine similarity [S1]:
    $$ p = \begin{cases} 1 & \text{if } \text{sim}(\mathbf{f}, \mathbf{q}) > \tau \\ 0 & \text{otherwise} \end{cases} $$
    where $\mathbf{q}$ is the query feature and $\tau$ is a threshold. This is a hard decomposition [S1].

**Sampling Strategy:**
*   **Coarse Sampling:** 64 points using stratified sampling. Used for training feature fields to ensure smoothness [S1].
*   **Fine Sampling:** 128 points (total 192 with coarse) using importance sampling. Used for final rendering [S1].
*   **Note:** Coarse sampling is used for training feature branches and can be used for edited rendering to maintain smoothness, while fine sampling is used for high-quality view synthesis [S1].

**Parameters:**
*   **Teacher Networks:** LSeg [44] or DINO [12] [S1].
*   **Training Iterations:** 200K for radiance field, 5K for finetuning [S1].
*   **Optimizer:** Adam, linearly decaying learning rate from $5 \times 10^{-4}$ to $8 \times 10^{-5}$ [S1].
*   **Finetuning Learning Rate:** $1 \times 10^{-4}$ [S1].
*   **Gaussian Noise:** Applied to density during initial training; removed during finetuning [S1].
*   **Sampling:** Coarse: 64 points; Fine: 128 points (192 total) [S1].
*   **PE Length:** 10 for coordinates, 4 for directions [S1].
*   **Image Size:** $320 \times 240$ (Replica), $1008 \times 756$ (others) [S1].
*   **Batch Size:** 1024 (Replica), 2048 (others) [S1].
*   **Feature Loss Weight ($\lambda$):** Default 1. Excessively increasing ($\lambda \times 10$) hurts view synthesis [S1].

**Edge Cases and Pitfalls:**
*   **Feature Loss Convergence:** Feature loss converges significantly faster than photometric loss, justifying the short 5K finetuning period [S1].
*   **High Feature Loss Weight:** Increasing $\lambda$ by 10x degrades view synthesis quality without improving segmentation [S1].
*   **Naive NeRF Features:** Using hidden layers of the original NeRF (e.g., 8th layer) for decomposition is not robust; selections leak to regions with similar color/geometry/position [S1].
*   **Deletion Artifacts:** Deleting foreground objects may leave floating artifacts and blurred volumes in the far distance behind the object [S1].
*   **Sampling Impact:** Fine sampling introduces high-frequency artifacts in segmentation; coarse sampling provides smoother decompositions [S1].

## Operating characteristics
*   **Time Complexity:** Training requires 200K iterations for the radiance field plus 5K for finetuning. The feature loss converges quickly, allowing short finetuning [S1].
*   **Memory Complexity:** Branch-based DFF adds minimal overhead (3 layers of 256 units) to the existing NeRF MLP. Independent DFF adds a separate lightweight MLP (4 layers) [S1].
*   **Performance:** Achieves 3D semantic segmentation performance (mIoU) competitive with or better than supervised models like MinkowskiNet42 on Replica [S1]. View synthesis quality is not degraded compared to standard NeRF [S1].
*   **Strengths:** Multi-view consistent editing; enables zero-shot text-based (LSeg) or patch-based (DINO) editing; smooth decomposition with coarse sampling or no-PE [S1].
*   **Limitations:** Floating artifacts behind deleted objects; feature loss weight sensitivity; requires pre-trained 2D teacher networks [S1].
*   **When to Use:** When semantic editing (deletion, extraction, color change) of NeRFs is required without retraining geometry, especially for multi-view consistency.
*   **When Not to Use:** When high-frequency geometric detail in the feature field is critical (use fine sampling with caution) or when computational resources for 200K pre-training are unavailable.

## Background
DFF was introduced in the paper "Decomposing NeRF for Editing Via Feature Field Distillation" [S1]. It addresses the challenge of editable NeRFs, specifically surface decomposition, volume decomposition, and estimation of unobserved parts [S1]. The method leverages pre-trained 2D teacher networks (LSeg for text queries, DINO for patch queries) to distill semantic features into the 3D radiance field, enabling 3D semantic segmentation and editing without explicit 3D semantic labels [S1]. It builds on the standard NeRF training procedure [S1].
