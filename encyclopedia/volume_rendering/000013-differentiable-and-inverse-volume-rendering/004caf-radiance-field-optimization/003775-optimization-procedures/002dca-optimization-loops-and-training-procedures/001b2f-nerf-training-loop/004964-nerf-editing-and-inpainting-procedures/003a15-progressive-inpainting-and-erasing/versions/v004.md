# Progressive Inpainting-and-Erasing

Also called: Conflicted Geometry Detection and Erasing, Inpainting-and-Erasing Strategy, PERF, PERF Algorithm

## Overview
Progressive Inpainting-and-Erasing (PERF) is a method for reconstructing a panoramic Neural Radiance Field (NeRF) from a single input panorama by iteratively synthesizing novel views and refining the geometry [S1]. It solves the problem of geometry conflict between visible regions of the original view and the inpainted invisible regions by computing a mask of conflicted areas and eliminating them from the training supervision [S1]. Unlike methods that rely on multiple input views or explicit geometric priors, PERF progressively enlarges the viewpoint range by randomly sampling camera poses, using collaborative RGBD inpainting to fill missing data and an erasing strategy to maintain geometric consistency [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A single input panorama image $I_{rgb}$ [S1].
*   **Output:** A panoramic NeRF model $f_{nerf}$ [S1].

**Data Structures**
*   **NeRF Representation:** Instant-NGP [S1].
    *   Hash table size: $2^{19}$ [S1].
    *   Levels: 16 [S1].
    *   Feature vector channel size: 2 [S1].
*   **Reference Views Set:** $I_{ref}$, initialized with the input RGBD panorama [S1].
*   **Trajectory Set:** $\{p_k\}$, generated novel view positions [S1].

**Parameters**
*   $\epsilon$: Small threshold value for depth difference comparison [S1].
*   Initial training iterations: 10,000 [S1].
*   Number of new positions sampled: 32 [S1].
*   Fine-tuning iterations per new view: 2,000 [S1].
    *   First 100 iterations: Supervision from the new reference view only [S1].
    *   Remaining 1,900 iterations: Supervision from all reference views [S1].
*   Optimizer: Adam [S1].
*   Learning rate: Initially $10^{-3}$, decayed to $10^{-4}$ using cosine annealing for each learning stage of a newly sampled view [S1].
*   Ray sampling: 2,048 rays per iteration [S1].

**Steps**
1.  **Initial Depth Estimation:** Estimate the initial depth map $I_d$ of the input panorama $I_{rgb}$ using an external depth estimator (Eq. 2 in [S1]) to obtain the initial RGBD panorama $I_{rgbd}$ [S1].
2.  **Single-View NeRF Training:** Train a single-view NeRF $f_{nerf}$ using $I_d$ and $I_{rgb}$ based on Eq. (3) in [S1] for 10,000 iterations [S1].
3.  **Trajectory Generation:** Generate a set of trajectories $\{p_k\}$ for novel views based on the estimated depth map $I_d$ [S1].
4.  **Initialization:** Initialize the set of reference views $I_{ref} = \{I_{rgbd}\}$ [S1].
5.  **Iterative Expansion:** For $n$ from 1 to `iters` (where `iters` corresponds to the 32 new positions):
    a.  **Sample View:** Randomly sample a new camera view $p$ from $\{p_k\}$ [S1].
    b.  **Invisible Region Detection:** Compute the invisible regions mask $m'$ according to Eq. (4) in [S1]:
        $$ m'_{ij} = \mathbb{I}(\text{warp}(v'_{ij}) - v_{ij} > \epsilon) $$
        where $v_{ij}$ is the reference depth, $v'_{ij}$ is the warped depth from the new view, and $\mathbb{I}(\cdot)$ is the indicator function [S1].
    c.  **Collaborative RGBD Inpainting:** Perform collaborative RGBD inpainting using Stable Diffusion for RGB inpainting and a depth estimator for stitching, guided by the invisible regions mask (Eq. 5 in [S1]) [S1].
    d.  **Conflict Detection and Erasing:** For all $I_{ref} \in I_{ref}$:
        i.  Compute conflicted regions mask $m''$ according to Eq. (6) in [S1]:
            $$ m''_{ij} = \mathbb{I}(v_{ij} - \text{warp}(v'_{ij}) > \epsilon) $$
            where $v_{ij}$ and $v'_{ij}$ are pixel values of $I_d$ and $I'_d$ respectively [S1].
        ii. Eliminate the identified conflicted regions from the supervision of the NeRF training [S1].
    e.  **Update Reference Set:** Add the inpainted and erased new view to the reference views $I_{ref}$ [S1].
    f.  **Fine-Tuning:** Fine-tune $f_{nerf}$ with the updated $I_{ref}$ for 2,000 iterations [S1].

**Pseudocode**
```python
def progressive_inpainting_and_erasing(I_rgb):
    # 1. Estimate depth and initialize RGBD
    I_d = estimate_depth(I_rgb) # Eq. (2) in [S1]
    I_rgbd = combine(I_rgb, I_d)
    
    # 2. Train initial single-view NeRF
    f_nerf = train_single_view_neRF(I_d, I_rgb, iterations=10000) # Eq. (3) in [S1]
    
    # 3. Generate trajectories
    trajectories = generate_trajectories(I_d)
    
    # 4. Initialize reference views
    I_ref = {I_rgbd}
    
    # 5. Iterative expansion
    for n in range(32): # 32 new positions [S1]
        # Sample new view
        p = random_sample(trajectories)
        
        # Compute invisible regions (Eq. 4 in [S1])
        # v_ij: reference depth, v'_ij: warped depth from new view
        # warp() projects new view depth to reference view coordinates
        v_ref = get_depth_from_nerf(f_nerf, p) # Or from I_rgbd if using initial depth
        v_warped = warp(v_ref, p)
        mask_invisible = (v_warped - v_ref > epsilon)
        
        # Collaborative RGBD Inpainting (Eq. 5 in [S1])
        # Uses Stable Diffusion for RGB and depth estimator for depth
        I_new_rgb = inpaint_rgb(I_rgb, mask_invisible, model="StableDiffusion")
        I_new_depth = inpaint_depth(I_d, mask_invisible, model="DepthEstimator")
        I_new_rgbd = combine(I_new_rgb, I_new_depth)
        
        # Conflict Detection and Erasing (Eq. 6 in [S1])
        # Compute conflicted regions for all reference views
        for I_ref_view in I_ref:
            v_ref_current = get_depth(I_ref_view)
            v_warped_current = warp(v_ref_current, p)
            mask_conflict = (v_ref_current - v_warped_current > epsilon)
            # Erase conflicted regions from supervision
            I_ref_view = erase_regions(I_ref_view, mask_conflict)
            
        # Add new view to reference set
        I_ref.add(I_new_rgbd)
        
        # Fine-tune NeRF
        # First 100 iterations: only new view
        fine_tune(f_nerf, {I_new_rgbd}, iterations=100, lr=1e-3)
        # Remaining 1900 iterations: all reference views
        fine_tune(f_nerf, I_ref, iterations=1900, lr=1e-4)
        
    return f_nerf
```

**Edge Cases and Pitfalls**
*   **Depth Estimation Error:** The initial depth estimation from a single panorama is critical. Errors here propagate to trajectory generation and warping accuracy [S1].
*   **Warping Accuracy:** The warping function must accurately project depth maps between views. Inaccurate warping leads to incorrect invisible or conflicted region masks [S1].
*   **Threshold $\epsilon$:** The choice of $\epsilon$ affects the sensitivity of conflict detection. Too small a value may miss conflicts; too large a value may erase valid geometry [S1].
*   **Inpainting Quality:** The quality of the inpainted regions directly impacts the NeRF's ability to learn consistent geometry. Poor inpainting may lead to artifacts or inconsistent geometry [S1].
*   **Convergence:** The method relies on iterative fine-tuning. Insufficient iterations may result in incomplete geometry or artifacts [S1].

## Operating characteristics
*   **Time Complexity:** Training a scene takes approximately 2 hours on a single Nvidia V100 GPU [S1].
*   **Memory Complexity:** Uses 32G memory on the GPU [S1].
*   **Scalability:** The method is designed for single panorama input and progressively expands the viewpoint range. The number of iterations and views is fixed (32 new positions) [S1].
*   **Strengths:** Can reconstruct a panoramic NeRF from a single input. Handles invisible regions through inpainting. Maintains geometric consistency through erasing [S1].
*   **Limitations:** Relies on external models for depth estimation and inpainting. Performance depends on the quality of these external models. May struggle with highly dynamic scenes or scenes with significant parallax not captured by the initial depth estimate [S1].
*   **When to use:** When only a single panorama is available and a full 360-degree NeRF is desired.
*   **When not to use:** When multiple input views are available, or when high accuracy in dynamic scenes is required [S1].

## Background
*   **Origin:** Proposed in "PERF: Panoramic Neural Radiance Field From a Single Panorama" [S1].
*   **History:** The method builds upon NeRF [1] and Instant-NGP [40] for efficient representation and training. It incorporates Stable Diffusion [61] for inpainting and NeRFAcc [60] for implementation [S1].
*   **Usage:** Evaluated on the Replica dataset and in-the-wild data [S1].
