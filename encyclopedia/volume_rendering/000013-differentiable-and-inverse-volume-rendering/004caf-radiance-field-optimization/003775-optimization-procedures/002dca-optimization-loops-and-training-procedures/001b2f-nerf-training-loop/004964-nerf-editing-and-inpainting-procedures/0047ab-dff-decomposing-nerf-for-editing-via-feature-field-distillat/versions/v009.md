# DFF (Decomposing NeRF for Editing Via Feature Field Distillation)
Also called: Feature Field Distillation, LSeg-DFF, DINO-DFF

## Overview
DFF enables 3D semantic segmentation and editable novel-view synthesis by distilling high-level semantic features from a pre-trained 2D teacher network (such as LSeg or DINO) into a neural radiance field [S1]. Unlike standard NeRFs, whose latent features are entangled with low-level factors like color and spatial adjacency, DFF decomposes scenes into coherent semantic regions, allowing for multi-view consistent editing (e.g., deletion, extraction, or color transformation) based on text or image patch queries [S1]. It sets itself apart from sibling methods like [NeRF Editing Procedure](12491-nerf-editing-and-inpainting-procedure.md) by providing a robust, learned semantic decomposition that avoids the "leakage" of selections to geometrically or color-similar but semantically distinct regions [S1].

## How it works
### Inputs and Outputs
**Inputs:**
*   A set of posed training images $I$.
*   A 2D teacher network (LSeg or DINO) [S1].
*   For LSeg: Text labels encoded via the LSeg text encoder [S1].
*   For DINO: Image patch queries [S1].

**Outputs:**
*   A radiance field $F_\Theta$ mapping $(\mathbf{x}, \mathbf{v}) \to (\sigma, \mathbf{c})$ [S1].
*   A feature field $F_\Phi$ mapping $\mathbf{x} \to \mathbf{f}$, where $\mathbf{f}$ represents semantic features [S1].
*   A decomposition probability $p_i$ for each sampled point, derived from the feature field and the query [S1].

### Data Structures
**NeRF MLP Architecture:**
*   **Radiance Field:** Eight ReLU layers with 256 dimensions, followed by a linear layer for density $\sigma$, three layers for color $\mathbf{c}$, and three layers for the feature branch $\mathbf{f}$ [S1].
*   **Independent Feature Field (Optional):** Four layers. If positional encoding (PE) is used, a skip connection is added at the third layer [S1]. For smooth decomposition, an independent MLP is trained *without* positional encoding [S1].

**Positional Encoding:**
*   Input coordinate $\mathbf{x}$ and skip connection: Length 10 [S1].
*   Viewing direction $\mathbf{v}$: Length 4 [S1].

**Sampling:**
*   **Coarse MLP:** Stratified sampling with 64 points [S1].
*   **Fine MLP:** Importance sampling with 192 points total (128 fine + 64 coarse) [S1]. Note: Sources specify 128 for fine sampling in parameters but 192 total in text; the text clarifies "coarse MLP... 64... fine MLP... 192 in total" [S1].

### Steps

1.  **Teacher Feature Extraction:**
    Encode each training image $I$ using the teacher network's image encoder to generate target feature maps $f_{img}(I, \mathbf{r})$ [S1].
    *   *Note:* Teacher networks (LSeg, DINO) output reduced-size feature maps. Resize these maps to the original image resolution [S1].

2.  **Initial Radiance Field Training:**
    Train the NeRF radiance field (without feature branches) for 200,000 iterations using only photometric loss $L_p$ [S1].
    *   *Parameters:* Adam optimizer, linearly decaying learning rate from $5 \times 10^{-4}$ to $8 \times 10^{-5}$ [S1].
    *   *Gaussian Noise:* Apply Gaussian noise to density during this phase [S1].

3.  **Feature Field Distillation (Finetuning):**
    Add the feature branch (or independent feature MLP) and finetune for 5,000 iterations using the combined loss $L_p + \lambda L_f$ [S1].
    *   *Parameters:* Remove Gaussian noise. Set learning rate to $1 \times 10^{-4}$ [S1].
    *   *Sampling:* Use coarse sampling (64 points) for training the feature field to ensure smoothness [S1].

4.  **Decomposition Probability Calculation:**
    For a given query (text or patch), compute the probability $p$ that a point belongs to the target region.
    *   **LSeg (Text Query):** Encode the text label. Calculate probability using Equation 22 (cosine similarity between point feature and label feature, normalized) [S1].
    *   **DINO (Patch Query):** Calculate the patch feature by averaging features of all pixels in the query patch. Compute cosine similarity between the point feature and the patch feature. Apply a threshold $\tau$:
        $$
        p = \begin{cases} 
        1 & \text{if } \text{similarity} > \tau \\
        0 & \text{otherwise}
        \end{cases}
        $$
        This creates a hard decomposition [S1].

5.  **Editing:**
    Use the probability $p$ to modulate the radiance field output or mask regions for editing (e.g., deletion, color swap) while preserving unedited regions [S1].

### Pseudocode

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class DFF:
    def __init__(self, teacher_model, teacher_type='LSeg', query=None):
        """
        Initialize DFF.
        :param teacher_model: Pre-trained LSeg or DINO encoder.
        :param teacher_type: 'LSeg' or 'DINO'.
        :param query: Text string for LSeg, or image patch tensor for DINO.
        """
        self.teacher = teacher_model
        self.teacher_type = teacher_type
        self.query = query
        self.radiance_mlp = self._build_radiance_mlp()
        self.feature_mlp = self._build_feature_mlp()
        
        # Pre-compute query embedding
        if teacher_type == 'LSeg':
            self.query_embedding = self.teacher.encode_text(query)
        elif teacher_type == 'DINO':
            # Average features of the patch
            patch_features = self.teacher.encode_image(query)
            self.query_embedding = torch.mean(patch_features, dim=0)
            
    def _build_radiance_mlp(self):
        # 8 ReLU layers (256 dim), linear for density, 3 for color, 3 for feature
        layers = []
        for _ in range(8):
            layers.append(nn.Linear(256, 256))
            layers.append(nn.ReLU())
        # Density head
        density_head = nn.Linear(256, 1)
        # Color head
        color_head = nn.Sequential(nn.Linear(256, 256), nn.ReLU(), 
                                   nn.Linear(256, 256), nn.ReLU(), 
                                   nn.Linear(256, 3))
        # Feature head
        feature_head = nn.Sequential(nn.Linear(256, 256), nn.ReLU(), 
                                     nn.Linear(256, 256), nn.ReLU(), 
                                     nn.Linear(256, 256)) # Assuming 256-dim feature space
        return nn.ModuleList([density_head, color_head, feature_head])

    def _build_feature_mlp(self):
        # Independent MLP: 4 layers. Skip connection at 3rd if PE used.
        # For smooth decomposition, PE is omitted.
        layers = [nn.Linear(10, 256), nn.ReLU(), # Input dim 10 (PE length)
                  nn.Linear(256, 256), nn.ReLU(),
                  nn.Linear(256, 256), nn.ReLU(),
                  nn.Linear(256, 256)]
        return nn.Sequential(*layers)

    def positional_encoding(self, x, v, pe_len_x=10, pe_len_v=4):
        # Standard NeRF positional encoding
        def pe(x, L):
            scales = torch.tensor([2**i for i in range(L//2)])
            xb = torch.reshape((x * scales).unsqueeze(-1), (*x.shape, -1))
            pe = torch.cat((torch.sin(xb), torch.cos(xb)), dim=-1)
            return pe
        
        x_pe = pe(x, pe_len_x)
        v_pe = pe(v, pe_len_v)
        return torch.cat([x_pe, v_pe], dim=-1)

    def forward(self, x, v):
        """
        Forward pass for a single point.
        :param x: (N, 3) coordinates
        :param v: (N, 3) viewing directions
        :return: sigma, color, feature
        """
        # Use coarse sampling for feature field training/rendering as per notes
        # Note: In practice, x and v are already sampled points
        pe_input = self.positional_encoding(x, v)
        
        # Radiance Field Forward
        h = pe_input
        for i in range(8):
            h = F.relu(self.radiance_mlp[0](h) if i==0 else h) # Simplified structure assumption
            # Actual structure: 8 shared layers
            # Density, Color, Feature heads take the output of the 8th layer
        
        # Assuming standard NeRF structure where 8 layers are shared
        # Let's implement the specific structure described:
        # "eight ReLU layers with 256 dimensions, followed by a linear layer for density, 
        #  three layers for color, and three layers for feature"
        
        # Shared backbone
        h = pe_input
        for _ in range(8):
            h = F.relu(nn.Linear(256, 256)(h) if _==0 else h) # Placeholder for shared weights
            # In implementation, these weights are shared. 
            # For pseudocode clarity, we assume a single shared block.
            pass 
            
        # To be precise with the "eight ReLU layers" description:
        # Let's assume a single MLP `shared_mlp` with 8 layers.
        # Since we can't define dynamic weights in simple pseudocode, we outline the logic.
        
        # Density
        sigma = self.radiance_mlp[0](h)
        
        # Color
        color = self.radiance_mlp[1](h)
        
        # Feature
        feature = self.radiance_mlp[2](h)
        
        return sigma, color, feature

    def compute_decomposition_probability(self, feature):
        """
        Compute probability p based on teacher type.
        :param feature: (N, D) feature vectors from the radiance field
        :return: p (N,) probabilities
        """
        if self.teacher_type == 'LSeg':
            # Cosine similarity with text embedding
            sim = F.cosine_similarity(feature, self.query_embedding.unsqueeze(0), dim=1)
            # Equation 22 implies softmax over labels, but for single query:
            # p = exp(sim) / sum(exp(sim)) ? Or just normalized similarity?
            # Source says "probability of each point is calculated by Equation 22"
            # Assuming standard softmax over classes if multi-class, or sigmoid if binary.
            # For single query, we treat it as binary relevance.
            p = torch.sigmoid(sim) # Approximation of probability
        elif self.teacher_type == 'DINO':
            # Thresholded cosine similarity
            sim = F.cosine_similarity(feature, self.query_embedding.unsqueeze(0), dim=1)
            threshold = 0.5 # Example threshold, source says "exceeds threshold"
            p = (sim > threshold).float()
        return p

    def train_step(self, rays, optimizer):
        """
        Training step for distillation.
        :param rays: Batch of rays (x, v, target_color, target_feature_map)
        :param optimizer: Adam optimizer
        """
        optimizer.zero_grad()
        
        # Sample points along rays (Coarse sampling: 64 points)
        x, v = sample_rays(rays, num_samples=64)
        
        # Forward pass
        sigma, color, feature = self.forward(x, v)
        
        # Volume Rendering for Color
        rendered_color = volume_render(sigma, color, x, v)
        
        # Losses
        # Photometric Loss
        L_p = F.mse_loss(rendered_color, rays.target_color)
        
        # Feature Loss
        # Resize target feature map to match rendered feature positions
        target_feature = resize_features(rays.target_feature_map, x, v)
        L_f = F.mse_loss(feature, target_feature)
        
        # Combined Loss
        lambda_f = 1.0 # Source warns against lambda * 10
        loss = L_p + lambda_f * L_f
        
        loss.backward()
        optimizer.step()
        
        return loss.item()
```

### Parameters
*   **Teacher Networks:** LSeg [44] or DINO [12] [S1].
*   **Iterations:** 200K for initial radiance training; 5K for feature distillation [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:**
    *   Initial: Linearly decaying from $5 \times 10^{-4}$ to $8 \times 10^{-5}$ [S1].
    *   Finetuning: $1 \times 10^{-4}$ [S1].
*   **Sampling:** Coarse: 64 points; Fine: 128 points (192 total) [S1].
*   **PE Length:** 10 for coordinates, 4 for viewing direction [S1].
*   **Image Size:** 320×240 (Replica); 1008×756 (others) [S1].
*   **Batch Size:** 1024 (Replica); 2048 (others) [S1].
*   **Feature Loss Weight ($\lambda$):** Standard is 1. Excessively increasing ($\lambda \times 10$) hurts view synthesis [S1].

### Edge Cases and Pitfalls
*   **Feature Loss Convergence:** Feature loss converges significantly faster than photometric loss, justifying the short 5K finetuning period [S1].
*   **Naive NeRF Features:** Using hidden layers of the original NeRF (e.g., the 8th layer) for decomposition is not robust; selections leak to regions with similar color, geometry, or position [S1].
*   **High Feature Loss Weight:** Setting $\lambda$ too high (e.g., $\times 10$) degrades view synthesis quality without improving segmentation [S1].
*   **Deletion Artifacts:** Deleting foreground objects may result in floating artifacts and blurred volumes in the far distance behind the deleted object [S1].
*   **Smoothness vs. Detail:** Fine sampling introduces high-frequency artifacts in segmentation. Coarse sampling or removing positional encoding (PE) in the feature MLP provides smoother volume decomposition [S1].

## Operating characteristics
*   **Time Complexity:** Training requires 200K iterations for the base NeRF plus 5K for distillation. The distillation phase is short due to fast feature loss convergence [S1].
*   **Memory Complexity:** Adds a feature branch (3 layers) or an independent MLP (4 layers) to the NeRF architecture. The independent MLP approach is lightweight and allows adding DFF to existing NeRFs without retraining the radiance field [S1].
*   **Performance:** Achieves 3D semantic segmentation performance comparable to or better than supervised sparse 3D convolution models (e.g., MinkowskiNet) [S1].
*   **Strengths:** Multi-view consistent editing; robust semantic decomposition; zero-shot capability with LSeg; patch-based selection with DINO [S1].
*   **Limitations:** Floating artifacts in unobserved regions behind deleted objects; coarse sampling may lack high-frequency detail [S1].
*   **When to Use:** When semantic decomposition and multi-view consistent editing are required. Prefer coarse sampling or no-PE feature MLPs for smooth volume decomposition [S1].
*   **When Not to Use:** When high-frequency geometric detail in the feature field is critical (fine sampling introduces artifacts) [S1].

## Background
DFF was introduced to address the challenges of editable NeRFs, specifically surface decomposition, volume decomposition, and the estimation of unobserved parts [S1]. It builds on the observation that standard NeRF feature spaces are entangled with low-level visual factors rather than semantic similarity [S1]. By distilling features from 2D teacher networks (LSeg, DINO), it enables 3D semantic segmentation and editing without explicit 3D semantic labels [S1].
