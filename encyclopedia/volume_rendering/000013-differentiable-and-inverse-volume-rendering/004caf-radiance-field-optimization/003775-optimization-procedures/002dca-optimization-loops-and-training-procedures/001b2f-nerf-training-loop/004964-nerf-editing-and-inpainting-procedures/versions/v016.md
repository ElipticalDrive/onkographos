# NeRF Editing and Inpainting Procedures

Also called: NeRF Editing, NeRF Inpainting, 3D Scene Editing

## Overview
This family covers methods for modifying pre-trained Neural Radiance Fields (NeRFs) to remove objects, insert new content, or alter appearance without retraining the entire scene from scratch. It solves the problem of maintaining multi-view consistency and geometric plausibility when applying 2D priors (such as inpainting or diffusion models) to 3D representations. Unlike standard training loops that optimize for reconstruction of input views, these procedures optimize for a target state defined by user intent (e.g., masks, text prompts, or reference images), often leveraging external 2D generative models or semantic fields as guidance.

## Shared principles
All methods in this family operate on a pre-trained or partially trained NeRF representation $f_\theta$ mapping $(\mathbf{x}, \mathbf{d}) \to (\sigma, \mathbf{c})$. The core mechanism involves defining a loss function that guides the optimization of $\theta$ (or a subset of parameters) towards a desired edit. Common principles include:
1.  **Guidance Generation:** Using external tools (2D inpainters, depth estimators, diffusion models, or semantic segmenters) to generate target signals (RGB, depth, or semantic masks) for the regions to be edited.
2.  **Loss Formulation:** Defining losses such as $L_{color}$ (reconstruction against guidance), $L_{depth}$ (geometric consistency), and $L_{seg}$ (semantic adherence).
3.  **Masking:** Utilizing binary or soft masks to restrict optimization to specific regions (e.g., occluded areas, objects to remove) while preserving unmasked regions.
4.  **Optimization:** Iteratively updating $\theta$ using gradient descent (typically Adam) to minimize the total loss.

## Subtopics

### [Progressive Inpainting-and-Erasing](8658-progressive-inpainting-and-erasing.md)
Iteratively expands view coverage for single-view panorama reconstruction by inpainting invisible regions and erasing geometry conflicts.

### [Deceptive-NeRF/3DGS Pipeline](11860-deceptive-nerf-3dgs-pipeline.md)
Enhances sparse-view reconstruction by generating pseudo-observations via a diffusion model conditioned on rendered RGB, depth, and uncertainty.

### [Blended-NeRF](12273-blended-nerf.md)
Edits a specific 3D Region of Interest (ROI) using text prompts and volumetric blending of a generator NeRF with the original scene.

### [NeRF-In Inpainting Optimization](12372-nerf-in-inpainting-optimization.md)
Removes unwanted objects by optimizing NeRF parameters to match RGB-D guidance from 2D inpainting/completion tools.

### [Adaptive View Selection for Inpainting](12405-adaptive-view-selection-for-inpainting.md)
Reduces inconsistency artifacts by dynamically selecting between 2D inpainting priors and multi-view NeRF reconstruction based on texture richness.

### [NeRF Editing Procedure](12491-nerf-editing-procedure.md)
Enables direct, differentiable editing (deletion, colorization, transformation) at inference time using a distilled Feature Field (DFF) without iterative weight optimization.

### [Reference-guided Controllable Inpainting of NeRFs](13952-reference-guided-controllable-inpainting-of-nerfs.md)
Uses a single inpainted reference view and monocular depth estimation to guide geometry and appearance, handling view-dependent effects.

#### Post-Refinement Strategy
- **Definition:** A strategy employed after the NeRF has been trained on updated data to enhance consistency by generating a more accurate target for each view using the modified Instruct-Pix2Pix with averaging architecture [S1].
- **Step:** Use the rendered image as input while continuing to use the mixup image as a condition [S1].

## Background
The field of NeRF editing emerged as NeRFs gained popularity for novel view synthesis, with early works focusing on object removal and insertion. Key developments include methods using 2D inpainting priors [S1], text-guided editing via diffusion models, and semantic-aware editing. The challenge of maintaining multi-view consistency while applying 2D edits remains a central research topic.
