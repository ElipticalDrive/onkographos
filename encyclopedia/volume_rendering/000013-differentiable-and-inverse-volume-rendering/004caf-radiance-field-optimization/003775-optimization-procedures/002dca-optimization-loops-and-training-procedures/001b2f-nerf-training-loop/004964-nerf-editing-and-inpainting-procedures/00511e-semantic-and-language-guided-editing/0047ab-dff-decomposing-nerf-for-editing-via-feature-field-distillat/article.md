# DFF (Decomposing NeRF for Editing Via Feature Field Distillation)
Also called: Feature Field Distillation, LSeg-DFF, DINO-DFF

## Overview
DFF enables 3D semantic segmentation and editable novel-view synthesis by distilling features from a pre-trained 2D teacher network (such as LSeg or DINO) into a neural radiance field [S1]. It solves the problem of decomposing scenes into semantic regions for editing, addressing challenges in surface decomposition, volume decomposition, and handling unobserved parts [S1]. Unlike naive usage of NeRF features which are entangled with low-level factors like color or spatial adjacency, DFF explicitly learns semantic similarity, allowing for multi-view consistent editing such as object deletion or appearance transformation [S1].

## How it works
**Inputs and Outputs:**
- **Inputs:** A set of posed training images $I$, camera poses, and a teacher network (LSeg or DINO) [S1].
- **Outputs:** A radiance field (MLP) producing color and density, and a feature field (MLP) producing semantic features [S1].

**Data Structures:**
1.  **Radiance Field MLP:**
    -   Architecture: 8 ReLU layers with 256 dimensions, followed by a linear layer for density, 3 layers for color, and 3 layers for feature [S1].
    -   Positional Encoding (PE): Length 10 for input coordinate and skip connection; Length 4 for viewing direction [S1].
2.  **Independent Feature Field MLP (Optional/Alternative):**
    -   Architecture: 4 layers [S1].
    -   Skip Connection: At the third layer if PE is used [S1].
    -   Smoothness Variant: An independent MLP without positional encoding can be trained as a smoothness regularizer [S1].
3.  **Teacher Network Targets:**
    -   Feature maps $f_{img}(I, r)$ are generated by encoding training images with the teacher network [S1].
    -   These maps are resized to the original image size to compensate for reduced resolution from the teacher network [S1].

**Numbered Steps:**

1.  **Teacher Feature Extraction:**
    Encode each training image $I$ using the image encoder of the teacher network (LSeg or DINO) to generate target feature maps $f_{img}(I, r)$ [S1]. Resize these maps to the original image resolution [S1].

2.  **NeRF Initialization (Pre-training):**
    Train a standard NeRF without a feature branch for 200,000 iterations using only the photometric loss $L_p$ [S1]. This establishes the geometry and color baseline [S1].

3.  **Feature Field Distillation (Finetuning):**
    Add a feature branch to the NeRF (or train an independent feature MLP) and finetune for 5,000 iterations using the combined loss $L_p + \lambda L_f$ [S1].
    -   Remove Gaussian noise applied to density during this phase [S1].
    -   Set learning rate to $1 \times 10^{-4}$ [S1].
    -   Use coarse sampling (64 points) for training the feature field to ensure smooth segmentations [S1].

4.  **Rendering and Loss Calculation:**
    For a ray $r$, sample points using hierarchical sampling.
    -   **Coarse MLP:** Stratified sampling with 64 points [S1].
    -   **Fine MLP:** Importance sampling with 128 points (192 total including coarse) [S1].
    -   Compute the rendered feature vector $F(r)$ by volume rendering the feature field outputs [S1].
    -   Compute the photometric loss $L_p$ between rendered color and ground truth [S1].
    -   Compute the feature loss $L_f$ between rendered feature $F(r)$ and the resized teacher feature map $f_{img}(I, r)$ at the corresponding pixel [S1].

5.  **Semantic Probability Calculation (Inference):**
    -   **LSeg-DFF:** Encode text labels using the LSeg text encoder. Calculate the probability $p$ of each point belonging to a label using cosine similarity (Equation 22 in [S1]).
    -   **DINO-DFF:** Use image patch queries. Calculate the patch feature by averaging features of all pixels in the patch. Compute probability $p$ using thresholded cosine similarity: set $p=1$ if similarity exceeds a threshold, else $p=0$ for hard decomposition [S1].

**Formulas:**
-   **Total Loss:** $L = L_p + \lambda L_f$ [S1].
-   **Feature Loss ($L_f$):** Not explicitly defined as a single equation in the text, but described as the difference between the volume-rendered feature field output and the resized 2D teacher feature map $f_{img}(I, r)$ [S1].
-   **LSeg Probability:** Calculated via Equation 22 in [S1] (text encoder similarity).
-   **DINO Probability:** $p = \mathbb{I}(\text{similarity} > \text{threshold})$ [S1].

**Parameters:**
-   **Teacher Networks:** LSeg [44] or DINO [12] [S1].
-   **Training Iterations:** 200K for pre-training, 5K for finetuning [S1].
-   **Optimizer:** Adam [S1].
-   **Learning Rate:** Linearly decaying from $5 \times 10^{-4}$ to $8 \times 10^{-5}$ during pre-training; fixed at $1 \times 10^{-4}$ during finetuning [S1].
-   **Sampling:** Coarse: 64 points; Fine: 128 points (192 total) [S1].
-   **PE Length:** 10 (coordinate), 4 (view direction) [S1].
-   **Image Size:** 320×240 (Replica); 1008×756 (others) [S1].
-   **Batch Size:** 1024 rays (Replica); 2048 rays (others) [S1].
-   **Feature Loss Weight ($\lambda$):** Default value not explicitly stated, but increasing it by $\times 10$ is noted as harmful [S1].

def train_dff(training_images, poses, teacher_network, dataset_config):
    """
    Trains a DFF model.
    teacher_network: 'LSeg' or 'DINO'
    """
    # 1. Pre-train Radiance Field (NeRF)
    nerf = NeRFMLP(
        coord_pe_len=10,
        view_pe_len=4,
        hidden_layers=8,
        hidden_dim=256,
        density_layer=1,
        color_layers=3,
        feature_layers=3 # Initially unused or dummy
    )
    
    optimizer = Adam(nerf.parameters(), lr=5e-4)
    lr_scheduler = LinearDecayLR(optimizer, start=5e-4, end=8e-5, total_steps=200000)
    
    for step in range(200000):
        rays = sample_rays(training_images, poses, batch_size=dataset_config.batch_size)
        
        # Standard NeRF forward pass
        colors, densities = nerf.forward(rays)
        
        # Photometric Loss
        gt_colors = rays.gt_colors
        loss_p = mse_loss(colors, gt_colors)
        
        # Gaussian noise for density (as per [S1])
        densities = densities + gaussian_noise()
        
        optimizer.zero_grad()
        loss_p.backward()
        optimizer.step()
        lr_scheduler.step()

    # 2. Finetune with Feature Field
    # Add feature branch to nerf or initialize independent feature MLP
    # Here we assume adding a branch to the existing MLP structure
    nerf.add_feature_branch(num_layers=3, dim=256)
    
    optimizer = Adam(nerf.parameters(), lr=1e-4)
    
    # Pre-compute teacher features for all training images
    teacher_features = []
    for img in training_images:
        # Encode with teacher (LSeg or DINO)
        raw_feat = teacher_network.encode(img)
        # Resize to original image size
        feat = resize_to_original_size(raw_feat, img.shape)
        teacher_features.append(feat)

    for step in range(5000):
        rays = sample_rays(training_images, poses, batch_size=dataset_config.batch_size)
        
        # Forward pass with feature output
        colors, densities, features = nerf.forward_with_features(rays)
        
        # Photometric Loss
        loss_p = mse_loss(colors, rays.gt_colors)
        
        # Feature Loss
        # Map ray pixel coordinates to teacher feature map
        teacher_feat_at_ray = get_teacher_feature(teacher_features, rays.pixel_coords)
        loss_f = mse_loss(features, teacher_feat_at_ray)
        
        # Combined Loss
        lambda_f = 1.0 # Default, avoid excessive weight
        loss = loss_p + lambda_f * loss_f
        
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

    return nerf

def render_editable_view(nerf, query_type, query_data, camera_pose):
    """
    Renders a view and allows editing based on semantic query.
    query_type: 'text' (LSeg) or 'patch' (DINO)
    """
    rays = generate_rays(camera_pose)
    
    # Use coarse sampling for feature consistency during editing
    # Or fine sampling if high-freq detail is needed, but coarse is preferred for smoothness
    colors, densities, features = nerf.forward_with_features(rays, sampling='coarse')
    
    # Calculate semantic probabilities
    if query_type == 'text':
        # LSeg: Encode text, compute similarity
        text_emb = nerf.teacher.text_encoder(query_data)
        probs = cosine_similarity(features, text_emb)
    elif query_type == 'patch':
        # DINO: Average patch features
        patch_feat = average_patch_features(query_data)
        sim = cosine_similarity(features, patch_feat)
        probs = (sim > threshold).float() # Hard decomposition
        
    # Apply edit mask based on probs
    # e.g., mask = 1 - probs for deletion
    edited_colors = apply_mask(colors, probs)
    
    return edited_colors

**Edge Cases and Pitfalls:**
-   **Feature Loss Convergence:** Feature loss converges significantly faster than photometric loss; thus, short finetuning (5K iterations) is sufficient [S1].
-   **Excessive Feature Weight:** Increasing the feature loss weight by $\times 10$ hurts view synthesis without improving segmentation [S1].
-   **Naive NeRF Features:** Using hidden layers of the original NeRF (e.g., 8th layer) for decomposition is not robust; regions leak to parts with similar color/geometry/position [S1].
-   **Deletion Artifacts:** Deleting foreground objects may result in floating artifacts and blurred volumes in the far distance behind the deleted object [S1].
-   **Sampling Impact:** Fine sampling introduces high-frequency artifacts in segmentation; coarse sampling produces smoother, more natural decompositions [S1].

## Operating characteristics
-   **Time Complexity:** Pre-training requires 200K iterations; finetuning requires 5K iterations [S1].
-   **Memory Complexity:** Adds a feature branch (3 layers) or independent MLP (4 layers) to the NeRF architecture [S1].
-   **Performance:** Achieves 3D semantic segmentation performance comparable to or better than supervised sparse 3D convolution models like MinkowskiNet42 [S1].
-   **View Synthesis:** Does not degrade view synthesis performance compared to standard NeRF when feature loss weight is moderate [S1].
-   **Strengths:** Multi-view consistent editing; enables zero-shot semantic segmentation via text (LSeg) or patch (DINO) queries; smooth volume decomposition with coarse sampling or no-PE MLP [S1].
-   **Limitations:** Floating artifacts behind deleted objects; feature loss convergence speed requires careful iteration management; naive NeRF features are insufficient for semantic tasks [S1].
-   **When to Use:** When 3D semantic segmentation or multi-view consistent editing (deletion, appearance change) is required from unstructured image collections.
-   **When Not to Use:** When high-frequency geometric detail in the feature field is critical (coarse sampling smooths it); when computational resources for 200K pre-training are unavailable.

## Background
DFF was introduced in the paper "Decomposing NeRF for Editing Via Feature Field Distillation" [S1]. It builds on the NeRF framework [112] and leverages pre-trained 2D vision models (LSeg [44] and DINO [12]) to inject semantic understanding into 3D radiance fields. The method addresses the limitation that original NeRF feature spaces are entangled with low-level factors rather than semantic similarity [S1]. It is used for 3D semantic segmentation benchmarks (e.g., Replica dataset) and editable novel-view synthesis tasks [S1].
