# Deceptive-NeRF/3DGS Pipeline
Also called: Deceptive-3DGS, Deceptive-NeRF

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that enhances NeRF or 3D Gaussian Splatting (3DGS) representations by continuously densifying input observations with synthetic pseudo-observations generated by a diffusion model during training [S1]. It distinguishes itself from sibling methods by explicitly enforcing 3D view consistency through an uncertainty map derived from epipolar reprojection, rather than relying on ensemble learning or variational inference [S1]. This approach allows the diffusion model to rectify artifacts while maintaining geometric plausibility across novel views [S1].

## How it works
The method operates in an iterative loop that alternates between generating pseudo-observations via a "deceptive" diffusion model and optimizing the radiance field representation using both real and synthetic data.

### Inputs and Outputs
*   **Inputs:** A set of $W$ input images $I = \{I_1, \dots, I_W\}$ with calibrated camera poses.
*   **Outputs:** An optimized NeRF or 3DGS representation capable of high-quality novel view synthesis from sparse inputs.

### Data Structures
1.  **Radiance Field Representation:** Standard NeRF MLP parameters or 3DGS Gaussian primitives.
2.  **Deceptive Diffusion Model $G$:** A latent diffusion model (e.g., Stable Diffusion) fine-tuned with ControlNet [S1].
    *   **ControlNet Channels:** 5 channels total (3 for coarse RGB, 1 for depth, 1 for uncertainty) [S1].
    *   **Text Embedding:** Composite feature $s = [s_0, s^*]$, where $s_0$ is from a captioning network and $s^*$ is an optimized latent embedding [S1].
3.  **Training Dataset for $G$:** Quartets $(I_{fine}, I_{coarse}, D, U)$ generated from NeRF duos or augmented data [S1].

### Numbered Steps

1.  **Initial Training:** Train the NeRF/3DGS representation using the few-view input images $I$ with calibrated poses [S1].
2.  **Coarse Reconstruction:** After a set number of epochs, obtain a coarse reconstruction [S1].
3.  **Novel View Sampling:** Randomly sample novel views within a bounding box defined by the outermost input views [S1].
4.  **Rendering:** At a novel viewpoint $A$, render:
    *   RGB image $\hat{I}_A$
    *   Depth map $D_A$
    *   Uncertainty map $U_A$
5.  **Uncertainty Map Generation:**
    *   Identify the nearest input viewpoint $B$ to novel view $A$ [S1].
    *   Compute the warped image $I_{B\rightarrow A}$ by projecting $I_B$ to view $A$ using $D_A$ and the relative rotation $R_{B\rightarrow A}$ [S1].
    *   Calculate the uncertainty map as the squared difference:
        $$ U_A = (I_{B \rightarrow A} - \hat {I}_A)^2 $$
        where $I_{B\rightarrow A}$ is the warped image and $\hat{I}_A$ is the rendered image [S1].
6.  **Pseudo-Observation Generation:** Generate the pseudo-observation $P_A$ using the deceptive diffusion model:
    $$ P_A = \operatorname {G}(\hat {I}_A, D_A, U_A) $$
    The model $G$ conditions on the coarse rendered image, depth, uncertainty, and text embedding $s$ [S1].
7.  **Filtering:** Discard 20% of the generated pseudo-observations that have the lowest perceptual similarity to input images, quantified via the LPIPS metric [S1].
8.  **Optimization:** Continue training the NeRF/3DGS representation using the combination of real input images and the accumulated pseudo-observations [S1].
9.  **Iteration:** Repeat steps 3–8 until a sufficient number of observations are accumulated [S1].

### Formulas and Definitions

**Depth Rendering:**
The depth value for each ray is computed as a weighted composition of distances traveled:
$$ \hat {\mathbf {D}} = \sum _{k=1}^K \hat {T}(t_k)\alpha (\sigma (t_k)\delta _k) $$
where $\hat {T}(t_k)$ is transmittance, $\alpha$ is opacity, $\sigma$ is density, and $\delta _k$ is the distance traveled [S1].

**Warped Image:**
The image from the nearest input view $B$ is warped to novel view $A$:
$$ I_{B\rightarrow A} = \psi (I_B; D_A, R_{B\rightarrow A}) $$
where $R_{B\rightarrow A}$ is the viewpoint difference [S1].

**Pixel Transformation:**
Each pixel location $p$ in $\hat{I}_A$ is transformed to $q$ in $I_B$:
$$ q = K R_{B\rightarrow A} D_A(p) K^{-1} p $$
where $K$ is the camera parameter matrix [S1].

**Diffusion Fine-Tuning Objective:**
The deceptive diffusion model is fine-tuned by solving:
$$ \min _{\theta}\mathbb {E}_{z\sim \mathcal {E},t,\epsilon \sim \mathcal {N}(0,1)}\|\epsilon -\epsilon _{\theta }(z_t,t,c(I_{\text {coarse}},D,U,s))\|_2^2 $$
where $z \sim \mathcal{E}$ is the latent code, $t \sim [1, 1000]$ is the diffusion time step, $\epsilon$ is noise, $\epsilon_\theta$ is the denoiser U-Net, and $c$ is the embedding of the coarse image, depth, uncertainty, and text embedding $s$ [S1].

**Text Embedding Derivation:**
1.  Generate text prompt $s_0$ using a pre-trained image captioning network [S1].
2.  Optimize a shared latent text embedding $s^*$ shared by all input observations and coarse images using textual inversion [S1].
3.  Form composite feature $s = [s_0, s^*]$ by concatenating embeddings [S1].

### Parameters
*   **Discard Rate:** 20% of pseudo-observations with the lowest LPIPS similarity are discarded [S1].
*   **Gaussian Noise Std Dev:** 0.3, added to 60,000 images from Hypersim for data augmentation [S1].
*   **Image Resolution:** All images are randomly cropped to 512 × 512 resolution [S1].
*   **Coarse NeRF Training Data:** Coarse NeRFs are trained using only one-fifth of the input images [S1].
*   **Training Dataset Size:** 200 scenes and approximately 20,000 images (Hypersim and CO3D each contributing half) [S1].

### Edge Cases and Pitfalls
*   **Captioning Efficacy:** Image captioning efficacy diminishes for low-quality images or those with pronounced artifacts. Textual inversion is used to optimize a shared latent text embedding $s^*$ to counteract this [S1].
*   **Noisy Augmentation:** When training with noisy RGB-depth data augmentation (where uncertainty maps are not fed into the diffusion model), the model learns to utilize depth maps to understand imperfect RGB images [S1].
*   **Uncertainty Calculation:** The uncertainty map relies on the nearest input view. If no input views are available or the depth is highly erroneous, the warping may fail [G].

## Operating characteristics
*   **Time Complexity:** The method requires iterative training loops, alternating between NeRF/3DGS optimization and diffusion model inference. The diffusion model inference is computationally expensive, but the use of ControlNet allows for efficient fine-tuning without disrupting pre-trained weights [S1].
*   **Memory Complexity:** Requires storing the radiance field representation, the diffusion model weights, and the accumulated pseudo-observations. The dataset for training the diffusion model (20,000 images) requires significant storage [S1].
*   **Performance:** On the LLFF dataset, Deceptive-NeRF achieves a PSNR of 19.87 (3-view), 21.75 (6-view), and 23.22 (9-view). Deceptive-3DGS achieves 19.95 (3-view), 23.73 (6-view), and 24.15 (9-view) [S1].
*   **Strengths:** Enforces 3D consistency through epipolar constraints without modifying the underlying representation. Mitigates artifacts common in sparse-view reconstruction [S1].
*   **Limitations:** Relies on the quality of the pre-trained diffusion model and the accuracy of the initial coarse reconstruction. Performance may degrade if the initial NeRF/3DGS is too poor to provide meaningful depth/uncertainty maps [G].

## Background
Deceptive-NeRF/3DGS was introduced by Liu et al. in 2023 [S1]. It addresses the challenge of high-quality novel view synthesis from sparse input views by leveraging the generative priors of 2D diffusion models. The method builds on the concept of using diffusion models for data augmentation but introduces a novel uncertainty measure to ensure geometric consistency [S1].
