# Deceptive-NeRF/3DGS Pipeline

Also called: Deceptive-3DGS, Deceptive-NeRF

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that enhances NeRF or 3D Gaussian Splatting (3DGS) representations by continuously densifying input observations with synthetic pseudo-observations generated by a diffusion model during training [S1]. Unlike methods that rely on ensemble learning, variational inference, or spatial perturbations to estimate uncertainty, this approach acquires uncertainty through correspondence matching by reprojecting real input observations to novel views, thereby enforcing epipolar constraints with minimal additional computation [S1]. It sets itself apart from sibling methods like [Progressive Inpainting-and-Erasing](8658-progressive-inpainting-and-erasing.md) by integrating a "deceptive" diffusion model conditioned on rendered depth and view-consistency uncertainty maps to rectify artifacts and fill unobserved regions, rather than relying solely on generative priors for inpainting or feature distillation [S1, 12068-dff-decomposing-nerf-for-editing-via-feature-field-distillat.md].

## How it works
The method operates in an iterative loop that alternates between generating pseudo-observations via a conditioned diffusion model and optimizing the radiance field representation using both real and synthetic data.

### Inputs and Outputs
**Inputs:**
*   A set of $W$ input images $I = \{I_1, \dots, I_W\}$ with calibrated camera poses.
*   A pre-trained 2D latent diffusion model (e.g., Stable Diffusion) with a denoiser U-Net $\epsilon_\theta$ [S1].
*   A pre-trained image captioning network [S1].
*   Camera intrinsic matrix $K$ [S1].

**Outputs:**
*   An optimized radiance field representation $f_\theta$ (NeRF or 3DGS) capable of high-quality novel view synthesis from sparse inputs [S1].
*   A trained "Deceptive Diffusion Model" $G$ [S1].

### Data Structures
1.  **Radiance Field Representation ($f_\theta$):**
    *   For NeRF: A multi-layer perceptron mapping 3D coordinates $\mathbf{x}$ and viewing directions $\mathbf{d}$ to density $\sigma$ and color $\mathbf{c}$ [S1, 12491-nerf-editing-procedure.md].
    *   For 3DGS: A set of 3D Gaussians with mean $\mu$, covariance $\Sigma$, opacity $\alpha$, and spherical harmonic coefficients for color [S1].
2.  **ControlNet Conditioner:**
    *   A copy of the diffusion model's encoder weights, frozen during training, used to process multi-channel control maps [S1].
    *   Input channels: 5 (3 for coarse RGB, 1 for depth, 1 for uncertainty) [S1].
3.  **Text Embedding ($s$):**
    *   A composite vector formed by concatenating a text prompt embedding $s_0$ and a shared latent text embedding $s^*$ [S1].
    *   $s = [s_0, s^*]$ [S1].
4.  **Pseudo-Observation Buffer:**
    *   A collection of generated images $P_A$ and their associated metadata (viewpoint, depth, uncertainty) [S1].

### Numbered Steps

1.  **Initial Coarse Training:**
    Train a coarse version of the radiance field representation using only a subset of the input images (e.g., one-fifth of $I$) [S1]. This provides the initial $\hat{I}_A$, $D_A$, and $\sigma$ estimates required for the first iteration.

2.  **Text Embedding Derivation:**
    1.  Generate a text prompt $s_0$ for the coarse rendered image using a pre-trained image captioning network [S1].
    2.  Optimize a shared latent text embedding $s^*$ using textual inversion, shared across all input observations and coarse images [S1].
    3.  Concatenate to form $s = [s_0, s^*]$ [S1].

3.  **Novel View Sampling:**
    Randomly sample a novel viewpoint $A$ within the bounding box defined by the outermost input views [S1].

4.  **Rendering:**
    Render the current radiance field at viewpoint $A$ to obtain:
    *   RGB image $\hat{I}_A$ [S1].
    *   Depth map $D_A$ [S1].
    *   Transmittance $\hat{T}(t_k)$ and opacity $\alpha(\sigma(t_k))$ for ray marching [S1].

5.  **Uncertainty Map Generation:**
    1.  Identify the nearest input viewpoint $B$ to the novel view $A$ [S1].
    2.  Compute the warped image $I_{B\rightarrow A}$ by projecting $I_B$ to view $A$ using $D_A$ and the relative rotation $R_{B\rightarrow A}$ [S1]:
        $$ I_{B\rightarrow A} = \psi (I_B; D_A, R_{B\rightarrow A}) $$
    3.  For each pixel $p$ in $\hat{I}_A$, compute the transformed pixel location $q$ in $I_B$:
        $$ q = K R_{B\rightarrow A} D_A(p) K^{-1} p $$
        where $K$ is the camera parameter matrix [S1].
    4.  Compute the uncertainty map $U_A$ as the squared difference between the warped image and the rendered image:
        $$ U_A = (I_{B \rightarrow A} - \hat {I}_A)^2 $$
        [S1].

6.  **Pseudo-Observation Generation:**
    Generate a pseudo-observation $P_A$ using the Deceptive Diffusion Model $G$:
    $$ P_A = \operatorname {G}(\hat {I}_A, D_A, U_A) $$
    The model $G$ is conditioned on the coarse RGB image $\hat{I}_A$, depth $D_A$, uncertainty $U_A$, and text embedding $s$ [S1].

7.  **Filtering:**
    Calculate the perceptual similarity between $P_A$ and the input images using the LPIPS metric. Discard 20% of the pseudo-observations with the lowest similarity scores to avoid generating content far from the original inputs [S1].

8.  **Radiance Field Optimization:**
    Update the radiance field parameters $\Theta$ by minimizing the photometric loss between the rendered images and the combined set of real input images $I$ and accumulated pseudo-observations $\{P_A\}$ [S1].

9.  **Iteration:**
    Repeat steps 3–8 until a sufficient number of pseudo-observations are accumulated to cover the scene adequately [S1].

### Deceptive Diffusion Model Training
To train the model $G$, a dataset of quartets $(I_{fine}, I_{coarse}, D, U)$ is constructed. The model is fine-tuned using the following objective:
$$ \min _{\theta}\mathbb {E}_{z\sim \mathcal {E},t,\epsilon \sim \mathcal {N}(0,1)}\|\epsilon -\epsilon _{\theta }(z_t,t,c(I_{\text {coarse}},D,U,s))\|_2^2 $$
where $z \sim \mathcal{E}$ is the latent code, $t \sim [1, 1000]$ is the diffusion time step, $\epsilon$ is noise, $\epsilon_\theta$ is the denoiser U-Net, and $c$ is the embedding of the coarse image, depth, uncertainty, and text embedding [S1]. ControlNet is used to implement this conditioning while preserving pre-trained weights [S1].

### Data Augmentation for Diffusion Training
If computational resources limit the training of "fine/coarse" NeRF duos for a large dataset:
1.  Use raw RGB images and their depth maps.
2.  Add random Gaussian noise (standard deviation $\sigma=0.3$) to RGB images to create $I_{coarse}$ [S1].
3.  Use the noisy image and depth as inputs, and the original clean image as the target [S1].
4.  **Pitfall:** When using this augmented data, uncertainty maps are **not** fed into the diffusion model [S1].

### Parameters
*   **Discard Rate:** 20% of pseudo-observations [S1].
*   **Similarity Metric:** LPIPS [S1].
*   **Gaussian Noise Std Dev:** 0.3 (for augmentation) [S1].
*   **Image Resolution:** 512 × 512 (randomly cropped) [S1].
*   **ControlNet Channels:** 5 (3 RGB, 1 Depth, 1 Uncertainty) [S1].
*   **Training Dataset Size:** ~20,000 images from 200 scenes (Hypersim and CO3D) [S1].
*   **Coarse NeRF Data:** 1/5 of input images [S1].

### Edge Cases and Pitfalls
*   **Captioning Efficacy:** Image captioning may fail on low-quality or artifact-heavy coarse images. Textual inversion is used to optimize a shared latent embedding $s^*$ to counteract this [S1].
*   **Augmentation Mismatch:** When training with noisy RGB-depth augmentation, uncertainty maps must be excluded from the diffusion input to avoid mismatched conditioning [S1].
*   **Depth Rendering:** Depth is rendered as a weighted composition of distances: $\hat {\mathbf {D}} = \sum _{k=1}^K \hat {T}(t_k)\alpha (\sigma (t_k)\delta _k)$ [S1]. Incorrect depth estimation leads to erroneous warping and uncertainty maps.

## Operating characteristics
*   **Time Complexity:** The method adds significant overhead due to the iterative generation of pseudo-observations and the fine-tuning of a large diffusion model. Each iteration requires rendering, warping, diffusion sampling, and radiance field optimization [S1].
*   **Memory Complexity:** Requires storing the radiance field, the diffusion model weights (ControlNet), and the buffer of pseudo-observations [S1].
*   **Performance:** On the LLFF dataset, Deceptive-NeRF achieves a PSNR of 19.87 (3-view) and 25.30 (9-view), while Deceptive-3DGS achieves 19.95 (3-view) and 25.34 (9-view), outperforming baselines like PixelNeRF and MVSNeRF [S1].
*   **Strengths:** Enforces 3D consistency via epipolar constraints without modifying the underlying representation; leverages strong 2D priors to fill unobserved regions; robust to sparse inputs.
*   **Limitations:** Computationally expensive due to diffusion model usage; quality depends on the accuracy of the initial coarse reconstruction and depth estimation.

## Background
Deceptive-NeRF/3DGS was introduced by Liu et al. in 2023 [S1]. It addresses the challenge of high-quality novel view synthesis from very few input views, a common limitation in real-world capture scenarios. The method builds on the principles of differentiable volume rendering [12491-nerf-editing-procedure.md] and recent advances in diffusion models for image editing and inpainting. It specifically targets the artifacts and inconsistencies that arise in sparse-view reconstructions by using a "deceptive" diffusion model to rectify renderings based on view-consistency uncertainty.
