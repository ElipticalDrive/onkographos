# Deceptive-NeRF/3DGS Pipeline

Also called: Deceptive-3DGS, Deceptive-NeRF

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that enhances NeRF or 3D Gaussian Splatting (3DGS) representations by continuously densifying input observations with synthetic pseudo-observations generated by a diffusion model during training [S1]. Unlike methods that rely on ensemble learning, variational inference, or spatial perturbations to estimate uncertainty, this approach acquires uncertainty through correspondence matching by reprojecting real input observations to novel views, enforcing epipolar constraints while minimizing additional computation [S1]. It sets itself apart from sibling methods like [NeRF-In](12372-nerf-in-inpainting-optimization.md) by explicitly integrating a "deceptive" diffusion model conditioned on rendered RGB, depth, and a novel uncertainty map to rectify artifacts and fill unobserved regions [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A set of $W$ input images $I = \{I_1, \dots, I_W\}$ with calibrated camera poses [S1].
*   A pre-trained 2D diffusion model (e.g., Stable Diffusion) [S1].
*   A pre-trained image captioning network [S1].

**Outputs:**
*   A refined NeRF or 3DGS representation $f_\theta$ capable of high-quality novel view synthesis from sparse inputs [S1].
*   A trained "Deceptive Diffusion Model" $G$ [S1].

### Data Structures

**1. Camera Parameters**
*   $K$: Camera intrinsic matrix [S1].
*   $R_{B \rightarrow A}$: Rotation matrix representing the viewpoint difference between nearest input view $B$ and novel view $A$ [S1].

**2. Rendering Outputs (at novel view $A$)**
*   $\hat{I}_A$: Rendered RGB image [S1].
*   $D_A$: Rendered depth map [S1].
*   $U_A$: Uncertainty map [S1].

**3. Diffusion Model Inputs (ControlNet Channels)**
*   Five-channel control map:
    *   Channels 1-3: Coarse RGB image $\hat{I}_A$ (or $I_{coarse}$) [S1].
    *   Channel 4: Depth map $D_A$ [S1].
    *   Channel 5: Uncertainty map $U_A$ [S1].
*   Text embedding $s$: Composite feature $s = [s_0, s^*]$ [S1].

**4. Training Data for Diffusion Model**
*   Quartets $(I_{fine}, I_{coarse}, D, U)$ [S1].
    *   $I_{fine}$: Target fine RGB image.
    *   $I_{coarse}$: Input coarse RGB image.
    *   $D$: Depth map.
    *   $U$: Uncertainty map [S1].

### Numbered Steps

1.  **Initial Training:** Train an initial NeRF or 3DGS representation using the few input images $I$ with calibrated poses [S1].
2.  **Coarse Reconstruction:** After a set number of epochs, obtain a coarse reconstruction [S1].
3.  **View Sampling:** Randomly sample novel views within a bounding box defined by the outermost input views [S1].
4.  **Rendering:** At a novel viewpoint $A$, render the RGB image $\hat{I}_A$, depth map $D_A$, and uncertainty map $U_A$ [S1].
5.  **Pseudo-Observation Generation:** Generate a pseudo-observation $P_A$ using the deceptive diffusion model $G$ conditioned on $\hat{I}_A$, $D_A$, and $U_A$ [S1].
6.  **Accumulation:** Accumulate the generated pseudo-observations $P_A$ into the training dataset [S1].
7.  **Filtering:** Discard 20% of the pseudo-observations with the lowest perceptual similarity to input images, quantified via the LPIPS metric [S1].
8.  **Representation Update:** Continue training the NeRF/3DGS representation using the combination of real input images and the accumulated pseudo-observations [S1].
9.  **Iteration:** Iterate steps 3–8 until a sufficient number of observations are accumulated [S1].

### Formulas

**Depth Rendering**
The depth value for each ray is computed as a weighted composition of distances traveled from the origin [S1]:
$$ \hat{\mathbf{D}} = \sum_{k=1}^K \hat{T}(t_k)\alpha(\sigma(t_k)\delta_k) $$
where $\hat{T}(t_k)$ is transmittance, $\alpha$ is opacity, $\sigma$ is density, and $\delta_k$ is the distance traveled [S1].

**Uncertainty Map Generation**
To enforce view consistency, the method warps the nearest input view $B$ to the novel view $A$ [S1]:
$$ I_{B \rightarrow A} = \psi(I_B; D_A, R_{B \rightarrow A}) $$
where $R_{B \rightarrow A}$ is the viewpoint difference [S1]. Each pixel location $p$ in $\hat{I}_A$ is transformed to $q$ in $I_B$ as [S1]:
$$ q = K R_{B \rightarrow A} D_A(p) K^{-1} p $$
The uncertainty map $U_A$ is defined as the squared distance between the warped image and the rendered image [S1]:
$$ U_A = (I_{B \rightarrow A} - \hat{I}_A)^2 $$

**Pseudo-Observation Generation**
The deceptive diffusion model $G$ generates the pseudo-observation $P_A$ [S1]:
$$ P_A = \operatorname{G}(\hat{I}_A, D_A, U_A) $$

**Diffusion Fine-Tuning Objective**
The diffusion model is fine-tuned using a latent diffusion architecture with encoder $\mathcal{E}$, denoiser U-Net $\epsilon_\theta$, and decoder $\mathcal{D}$ [S1]:
$$ \min_{\theta}\mathbb{E}_{z\sim \mathcal{E},t,\epsilon \sim \mathcal{N}(0,1)}\|\epsilon -\epsilon_{\theta }(z_t,t,c(I_{\text {coarse}},D,U,s))\|_2^2 $$
where $z \sim \mathcal{E}$ is the latent code, $t \sim [1, 1000]$ is the diffusion time step, $\epsilon$ is noise, and $c$ is the embedding of the coarse image, depth, uncertainty, and text embedding $s$ [S1].

**Text Embedding Derivation**
1.  Generate a text prompt $s_0$ using a pre-trained image captioning network [S1].
2.  Optimize a shared latent text embedding $s^*$ shared by all input observations and coarse images using textual inversion [S1].
3.  Form the composite feature $s = [s_0, s^*]$ by concatenating the embeddings [S1].

### Parameters

*   **Discard Rate:** 20% of pseudo-observations are discarded based on LPIPS similarity [S1].
*   **ControlNet Channels:** 5 channels (3 for RGB, 1 for depth, 1 for uncertainty) [S1].
*   **Gaussian Noise Std Dev:** 0.3, added to 60,000 images from Hypersim for data augmentation [S1].
*   **Image Resolution:** All images are randomly cropped to $512 \times 512$ [S1].
*   **Training Dataset Size:** 200 scenes and approximately 20,000 images (Hypersim and CO3D each contributing half) [S1].
*   **Coarse NeRF Training Data:** Coarse NeRFs are trained using only one-fifth of the input images [S1].

### Edge Cases and Pitfalls

*   **Captioning Efficacy:** Image captioning efficacy diminishes for images of lower quality or those with pronounced artifacts. Textual inversion is used to optimize a shared latent text embedding $s^*$ to counteract this [S1].
*   **Noisy Data Augmentation:** When training the diffusion model with noisy RGB-depth data augmentation (where uncertainty maps are not available), uncertainty maps are not fed into the diffusion model [S1].
*   **Precision:** The pixel transformation $q = K R_{B \rightarrow A} D_A(p) K^{-1} p$ requires accurate camera intrinsics $K$ and relative poses $R_{B \rightarrow A}$ to enforce epipolar constraints correctly [S1].

## Operating characteristics

*   **Time Complexity:** The method requires iterative training loops where the NeRF/3DGS is updated after each batch of pseudo-observations. The diffusion model inference adds significant computational overhead per novel view sampled [S1].
*   **Memory Complexity:** Requires storing the NeRF/3DGS representation, the diffusion model weights, and the accumulated dataset of pseudo-observations [S1].
*   **Measured Performance:** On the LLFF dataset, Deceptive-NeRF achieves a PSNR of 19.87 (3-view), 21.75 (6-view), and 23.22 (9-view). Deceptive-3DGS achieves 19.95 (3-view), 23.73 (6-view), and 23.92 (9-view) [S1].
*   **Strengths:**
    *   Enforces 3D consistency via uncertainty maps derived from epipolar constraints [S1].
    *   Mitigates artifacts from sparse views by leveraging diffusion priors [S1].
    *   ControlNet allows fine-tuning without disrupting pre-trained diffusion weights [S1].
*   **Limitations:**
    *   Relies on the quality of the initial coarse reconstruction [S1].
    *   Computationally expensive due to repeated diffusion model inference and NeRF updates [S1].
    *   Image captioning may fail on low-quality or artifact-heavy images, requiring textual inversion [S1].
*   **When to Use:** Sparse-view reconstruction where input views are insufficient for standard NeRF/3DGS training [S1].
*   **When Not to Use:** When computational resources are limited or when high-quality dense input views are available [S1].

## Background

Deceptive-NeRF/3DGS was introduced by X. Liu et al. in the paper "Deceptive-NeRF/3DGS: Diffusion-Generated Pseudo-Observations for High-Quality Sparse-View Reconstruction" [S1]. The method addresses the challenge of reconstructing high-quality 3D scenes from very few input images by using a diffusion model to generate "deceptive" pseudo-observations that fill in missing details while maintaining view consistency [S1]. It builds on the principles of differentiable volume rendering and inverse rendering, specifically leveraging the rendering equation for depth and color [S1, 12491-nerf-editing-procedure.md]. The use of ControlNet for conditioning the diffusion model on depth and uncertainty maps is a key innovation that distinguishes it from earlier sparse-view methods [S1].
