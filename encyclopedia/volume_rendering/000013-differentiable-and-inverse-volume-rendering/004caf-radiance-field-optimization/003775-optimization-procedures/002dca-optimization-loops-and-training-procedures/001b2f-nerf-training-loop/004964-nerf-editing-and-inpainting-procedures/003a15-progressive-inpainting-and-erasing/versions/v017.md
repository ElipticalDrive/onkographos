# Progressive Inpainting-and-Erasing

Also called: Conflicted Geometry Detection and Erasing, Inpainting-and-Erasing Strategy, PERF, PERF Algorithm

## Overview
Progressive Inpainting-and-Erasing (PERF) is a method for reconstructing a panoramic Neural Radiance Field (NeRF) from a single input panorama by iteratively expanding the view coverage through novel view synthesis and geometry-aware training [S1]. It solves the problem of geometry conflicts that arise when inpainting invisible regions with generative models, which may produce structures inconsistent with the already-learned visible geometry [S1]. Unlike methods that optimize a fixed set of views, PERF progressively enlarges the range of viewpoints, using a conflict mask to erase inconsistent regions from supervision before fine-tuning the NeRF [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A single input panorama image $I_{rgb}$ [S1].
*   **Output:** A panoramic NeRF representation $f_{nerf}$ [S1].

**Data Structures:**
*   **NeRF Representation:** The method uses Instant-NGP [S1]. The data structure consists of a hash table of size $2^{19}$ with 16 levels of feature vectors, each having a channel size of 2 [S1].
*   **Reference Views Set ($I_{ref}$):** A set containing the initial RGBD panorama and subsequently added inpainted RGBD panoramas [S1].
*   **Trajectory Set ($\{p_k\}$):** A set of novel camera poses generated based on the initial depth map [S1].

**Parameters:**
*   $\epsilon$: A small threshold value for depth difference comparison [S1].
*   $iters$: Total number of progressive sampling iterations [S1].
*   $N_{views}$: Number of new positions sampled, typically 32, with approximately gradually increased distance from the original position [S1].
*   $N_{rays}$: Number of rays sampled per iteration for supervision, typically 2048 [S1].
*   $L_{init}$: Initial learning rate, $10^{-3}$ [S1].
*   $L_{final}$: Final learning rate, $10^{-4}$ [S1].
*   $N_{fine\_tune}$: Total fine-tuning iterations per new view, 2000 [S1].
*   $N_{new\_view\_only}$: Iterations using only the new reference view for supervision, 100 [S1].
*   $N_{initial}$: Initial training iterations for the single input panorama, 10,000 [S1].

**Formulas:**
1.  **Invisible Region Mask ($m'$):**
    $$ m'_{ij} = \mathbb{I}(warp(v'_{ij}) - v_{ij} > \epsilon) $$
    Where $v_{ij}$ is the reference depth, $v'_{ij}$ is the warped depth from the new view, $warp(\cdot)$ is the warping function, and $\mathbb{I}(\cdot)$ is the indicator function. $m'_{ij}=1$ indicates an invisible region [S1].

2.  **Conflicted Region Mask ($m''$):**
    $$ m''_{ij} = \mathbb{I}(v_{ij} - warp(v'_{ij}) > \epsilon) $$
    Where $v_{ij}$ is the reference depth and $v'_{ij}$ is the warped depth from the new view. $m''_{ij}=1$ indicates inconsistent/conflicted geometry [S1].

3.  **Final Conflict Mask:**
    The final conflict mask is computed by performing a logic AND operation across the individual masks $m''$ from all reference views in $I_{ref}$ [S1].

**Steps:**
1.  **Initial Depth Estimation:** Estimate the initial depth map $I_d$ of the input single panorama $I_{rgb}$ using a depth estimator (Eq. 2 in source) to obtain an initial RGBD panorama $I_{rgbd}$ [S1].
2.  **Initial NeRF Training:** Train a single-view NeRF $f_{nerf}$ using $I_d$ and $I_{rgb}$ based on the standard NeRF rendering equation (Eq. 3 in source) for 10,000 iterations [S1].
3.  **Trajectory Generation:** Generate a set of novel view trajectories $\{p_k\}$ based on the estimated depth map $I_d$ [S1].
4.  **Initialization:** Initialize the set of reference views $I_{ref} = \{I_{rgbd}\}$ [S1].
5.  **Progressive Loop:** Iterate $n$ from 1 to $iters$:
    a.  **Sample View:** Randomly sample a new camera pose $p$ from $\{p_k\}$ [S1].
    b.  **Detect Invisible Regions:** Compute the invisible regions mask $m'$ according to Eq. (4) [S1].
    c.  **Collaborative Inpainting:** Perform collaborative RGBD inpainting using Stable Diffusion for RGB inpainting and a depth estimator for depth stitching (Eq. 5 in source) to generate the completed panorama for the new view [S1].
    d.  **Detect Conflicts:** For all $I_{ref} \in I_{ref}$, compute the conflicted regions mask $m''$ according to Eq. (6) [S1].
    e.  **Erase Conflicts:** Eliminate the identified conflicted regions from the supervision of the NeRF training by masking them out [S1].
    f.  **Update Reference:** Add the new inpainted and erased view to the reference views set $I_{ref}$ [S1].
    g.  **Fine-tune:** Fine-tune $f_{nerf}$ with the updated $I_{ref}$ for 2,000 iterations. The first 100 iterations use only the new reference view for supervision, and the remaining 1,900 iterations use all reference views [S1]. The learning rate starts at $10^{-3}$ and decays to $10^{-4}$ using cosine annealing [S1].

**Pseudocode:**

```python
def progressive_inpainting_and_erasing(I_rgb):
    # 1. Estimate initial depth
    I_d = estimate_depth(I_rgb)
    I_rgbd = combine_rgb_depth(I_rgb, I_d)
    
    # 2. Train initial single-view NeRF
    f_nerf = train_single_view_nerf(I_rgb, I_d, iterations=10000)
    
    # 3. Generate trajectories
    trajectories = generate_trajectories(I_d, num_views=32)
    
    # 4. Initialize reference views
    I_ref = {I_rgbd}
    
    # 5. Progressive loop
    for n in range(1, iters + 1):
        # Sample new view
        p = random_sample(trajectories)
        
        # Compute invisible regions
        # Note: Requires rendering depth from current f_nerf for reference views
        # and warping depths from the new view to reference views
        m_invisible = compute_invisible_mask(f_nerf, I_ref, p, epsilon=epsilon)
        
        # Collaborative RGBD Inpainting
        # Uses Stable Diffusion for RGB and depth estimator for depth
        I_new_rgbd = collaborative_rgb_inpainting(I_rgb, p, m_invisible)
        
        # Compute conflicted regions
        m_conflict_individual = []
        for I_ref_view in I_ref:
            # Eq. 6: m''_ij = I(v_ij - warp(v'_ij) > epsilon)
            # v_ij is depth from I_ref_view, v'_ij is warped depth from I_new_rgbd
            m_conflict = compute_conflict_mask(I_ref_view, I_new_rgbd, epsilon=epsilon)
            m_conflict_individual.append(m_conflict)
        
        # Final conflict mask is AND of all individual masks
        m_conflict_final = logical_and_all(m_conflict_individual)
        
        # Add new view to reference set
        I_ref.add(I_new_rgbd)
        
        # Fine-tune NeRF
        # First 100 iterations: only new view
        # Next 1900 iterations: all reference views
        # Learning rate: 10^-3 to 10^-4 cosine annealing
        fine_tune_nerf(f_nerf, I_ref, m_conflict_final, 
                       iterations=2000, 
                       new_view_only_iters=100,
                       lr_start=1e-3, lr_end=1e-4)
        
    return f_nerf
```

**Edge Cases and Pitfalls:**
*   **Geometry Conflict:** If the inpainted geometry violates the visible geometry from reference views, it causes artifacts. The erasing step mitigates this by removing conflicting regions from supervision [S1].
*   **Depth Estimation Error:** The initial depth estimation must be reasonably accurate to generate valid trajectories and detect invisible regions correctly [S1].
*   **Stable Diffusion FOV:** The pre-trained Stable Diffusion model is trained on perspective images, which may affect inpainting quality for panoramic inputs [S1].

## Subtopics

### Collaborative RGBD Inpainting
A sub-method that uses Stable Diffusion for RGB inpainting and a depth estimator for depth stitching to fill invisible regions [S1]. It is chosen when generative completion of missing views is required.

### Single-View NeRF Training
The initial step of training a NeRF from a single panorama and its estimated depth [S1]. It is the foundation for the progressive expansion.

## Operating characteristics
*   **Time Complexity:** Training a scene takes about 2 hours on a single Nvidia V100 GPU [S1]. The complexity scales with the number of iterations and the number of reference views, as each iteration involves rendering, warping, inpainting, and fine-tuning [S1].
*   **Memory Complexity:** Uses Instant-NGP with a hash table size of $2^{19}$ and 16 levels of feature vectors of channel size 2 [S1]. Training requires 32G memory on the GPU [S1].
*   **Strengths:** Effectively avoids geometry conflicts between visible and invisible regions, allowing for the reconstruction of panoramic NeRFs from a single input [S1].
*   **Limitations:** Relies on the quality of the initial depth estimation and the generative inpainting model. The progressive nature may accumulate errors if conflicts are not properly erased [S1].
*   **When to use:** When only a single panorama is available and a full 360-degree NeRF is needed.
*   **When not to use:** When multiple views are available, as other methods may be more efficient and accurate.

## Background
The method was introduced in the paper "PERF: Panoramic Neural Radiance Field From a Single Panorama" [S1]. It addresses the challenge of reconstructing panoramic NeRFs from a single input, a problem that is ill-posed without additional constraints or generative priors. The method builds on the Instant-NGP representation [S1] and uses Stable Diffusion [S1] for inpainting.
