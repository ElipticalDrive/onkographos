# Blended-NeRF

Also called: Zero-Shot Object Generation and Blending in Existing Neural Radiance Fields

## Overview
Blended-NeRF is a framework for editing a specific region of interest (ROI) in an existing Neural Radiance Field (NeRF) scene based on text prompts and a 3D ROI box [S1]. It solves the problem of local 3D editing by training a generator NeRF initialized with the original scene's weights and blending the synthesized content with the original scene using volumetric blending [S1]. Unlike methods that synthesize new objects from scratch (e.g., Dream Fields) or require semantic decomposition/2D masks for localization (e.g., Volumetric Disentanglement), Blended-NeRF operates on any region using a 3D box without learning a new feature space [S1].

## How it works
**Inputs:**
*   Existing NeRF model $F_{\theta_O}$ mapping $(\mathbf{x}, \mathbf{d}) \to (\sigma, \mathbf{c})$ [S1].
*   3D Region of Interest (ROI) box $B$ localized inside the scene [S1].
*   User-provided text prompt $y$ [S1].
*   Pretrained language-image model encoders $E_{img}$ and $E_{txt}$ (e.g., CLIP) [S1].

**Outputs:**
*   Edited scene representation $F_{\theta_G}$ (generator) and the final rendered view $x_e$ [S1].

**Data Structures:**
*   **NeRF Model ($F_\theta$):** A Multi-Layer Perceptron (MLP) taking positional encoded coordinates and viewing directions, outputting density $\sigma$ and color $\mathbf{c}$ [S1].
*   **Positional Encoding:** High frequency sinusoidal encoding $\gamma(\mathbf{x}) = [\cos(2^l \mathbf{x}), \sin(2^l \mathbf{x})]_{l=0}^{L-1}$ applied to inputs [S1].
*   **ROI Box $B$:** Defined by center, dimensions, and diagonal length $diag$ [S1].

**Parameters:**
*   $\alpha$: Hyperparameter for distance smoothing blending strength. $\alpha=0$ gives all weight to the edited scene; higher $\alpha$ gives more attention to original scene points closer to the ROI center [S1]. Typical values: 0, 0.5, 2, 4, 10 [S1].
*   $\lambda_T, \lambda_D$: Weights for transmittance and depth losses [S1].
*   $\tau$: Max transmittance threshold [S1].
*   $\rho$: Max variance allowed for depth loss [S1].
*   $\epsilon$: Small constant for numerical stability [S1].
*   $\gamma$: Camera Field of View (FOV) [S1].
*   $e_{max}$: Maximum dimension of the ROI box [S1].

**Numbered Steps:**

1.  **Initialization:** Initialize the generator NeRF model $F_{\theta_G}$ with the weights of the original scene model $F_{\theta_O}$ [S1].
2.  **ROI Localization:** Localize the 3D box $B$ inside the scene using a GUI that renders the original NeRF and uses the output depth map for 3D understanding [S1]. Compute the center of the box (center of mass) and diagonal $diag$ [S1].
3.  **Pose Sampling:** For each training iteration, sample a random camera pose around the scene with azimuth/elevation angles $(\theta, \phi)$. Calculate initial distance $d = \frac{e_{max}}{2 \tan(\gamma/2)}$ and randomly sample radius $r$ around $d$ [S1].
4.  **Ray Casting and Sampling:** Cast rays $r$ from the sampled camera pose. Sample points along the ray. For points outside $B$, set density to zero during training [S1].
5.  **Background Augmentation:** Render with random backgrounds (Gaussian noise, checkerboard, random Fourier textures) to prevent scene diffusion [S1].
6.  **Directional Prompting:** Concatenate a view-dependent text prompt to the original caption $y$ to constrain object description across views [S1].
7.  **Rendering Generated Content:** Render the generated content inside the ROI box $I_{ROI}$ using only points $\mathbf{x}_i \in B$. The rendered color $C(r)$ for a ray $r$ is:
    $$ C(r) = \frac{\sum_{\mathbf{x}_i \in B} T_i (1 - e^{-\sigma_i \delta_i}) \mathbf{c}_i}{\sum_{\mathbf{x}_i \in B} T_i (1 - e^{-\sigma_i \delta_i})} \quad \text{if } \exists \mathbf{x}_i \in r \text{ s.t. } \mathbf{x}_i \in B, \text{ else } 0 $$
    where $T_i = \exp(-\sum_{j < i} \sigma_j \delta_j)$ [S1].
8.  **Loss Computation:**
    *   **Similarity Loss:** $L_{sim} = -E_{img}(I_{ROI})^T E_{txt}(y)$ [S1].
    *   **Transmittance Loss:** $L_T = -\min(\tau, \text{mean}(T(P)))$, where $T(P)$ is transmittance of rendered view from pose $P$ [S1].
    *   **Depth Loss:** $L_D = -\min(\rho, \sigma^2(D(P)))$, where $\sigma^2(D(P))$ is variance of disparity map of rendered view from pose $P$ [S1].
    *   **Total Objective:** $L_{total} = L_{sim} + \lambda_T L_T + \lambda_D L_D$ [S1].
    *   *Note:* $L_T$ and $L_D$ are gradually introduced during training using an annealing strategy [S1].
9.  **Optimization:** Optimize $F_{\theta_G}$ by minimizing $L_{total}$ [S1].
10. **Blending (Inference):** After training, render the edited scene by blending sample points from $F_{\theta_O}$ and $F_{\theta_G}$ along each view ray [S1].
    *   **Object Insertion/Replacement Mode:** During training, consider only $F_{\theta_G}$ inside ROI. After training, blend using distance smoothing (Eq. 5) [S1].
    *   **Object Blending Mode:** Query both $F_{\theta_O}$ and $F_{\theta_G}$ inside the box. Compute alpha values: $\alpha_O(\mathbf{x}_i) = 1 - \exp(\phi(\sigma_O(\mathbf{x}_i)) \cdot \delta_i)$, $\alpha_G(\mathbf{x}_i) = 1 - \exp(\phi(\sigma_G(\mathbf{x}_i)) \cdot \delta_i)$, where $\phi$ is a non-negative activation function [S1].
    *   **Density Blending Options:**
        *   Option 1 (Sum in activation): $\sigma(\mathbf{x}_i) = \phi(\sigma_O(\mathbf{x}_i) + \sigma_G(\mathbf{x}_i))$ [S1].
        *   Option 2 (Sum out activation): $\sigma(\mathbf{x}_i) = \phi(\sigma_O(\mathbf{x}_i)) + \phi(\sigma_G(\mathbf{x}_i))$ [S1].
    *   **Color Blending (Object Blending Mode):**
        $$ \mathbf{c}(\mathbf{x}_i) = S\left(\frac{\mathbf{c}_O(\mathbf{x}_i) \cdot \alpha_O(\mathbf{x}_i) + \mathbf{c}_G(\mathbf{x}_i) \cdot \alpha_G(\mathbf{x}_i)}{\epsilon + \alpha_O(\mathbf{x}_i) + \alpha_G(\mathbf{x}_i)}\right) $$
        where $S$ is sigmoid [S1].
    *   **Distance Smoothing Blending (General):**
        $$ f(\mathbf{x}) = 1 - \exp\left(-\alpha \frac{d(\mathbf{x})}{diag}\right) $$
        $$ \sigma_{blend}(\mathbf{x}) = f(\mathbf{x}) \cdot \sigma_O(\mathbf{x}) + (1 - f(\mathbf{x})) \cdot \sigma_G(\mathbf{x}) $$
        $$ \mathbf{c}_{blend}(\mathbf{x}) = f(\mathbf{x}) \cdot \mathbf{c}_O(\mathbf{x}) + (1 - f(\mathbf{x})) \cdot \mathbf{c}_G(\mathbf{x}) $$
        where $d(\mathbf{x})$ is Euclidean distance from ROI center [S1].
    *   **Final Render:** The final rendered view $x_e$ is obtained by blending the raw densities and RGB values inside and outside the ROI along each ray using standard volume rendering [S1].

import numpy as np

def positional_encoding(x, L=10):
    """High frequency sinusoidal positional encoding."""
    freq_bands = 2.0 ** np.arange(L)
    return np.concatenate([np.cos(freq_bands * x), np.sin(freq_bands * x)], axis=-1)

def blend_scenes(raw_values, roi_box, alpha=2.0):
    """
    Blends original (O) and generator (G) scenes.
    """
    blended_samples = []
    center = roi_box.center
    diag = roi_box.diagonal
    
    for x, sigma_o, c_o, sigma_g, c_g in raw_values:
        d = np.linalg.norm(x - center)
        f = 1 - np.exp(-alpha * d / diag)
        
        # Distance smoothing blending
        sigma_b = f * sigma_o + (1 - f) * sigma_g
        c_b = f * c_o + (1 - f) * c_g
        
        blended_samples.append((x, sigma_b, c_b))
        
    return blended_samples

## Operating characteristics
*   **Time Complexity:** Training time depends on the number of iterations and the cost of CLIP inference per iteration. The method requires rendering rays only inside the ROI during training, which is faster than full-scene optimization, but still requires multiple forward passes through the MLP and CLIP encoders [S1].
*   **Memory Complexity:** Requires storing the weights of both the original NeRF $F_{\theta_O}$ and the generator NeRF $F_{\theta_G}$ [S1].
*   **Strengths:**
    *   Enables zero-shot object generation and blending in existing NeRFs using text prompts [S1].
    *   Operates on any region using a 3D box without requiring semantic decomposition or 2D masks [S1].
    *   Preserves the scene outside the ROI [S1].
    *   Produces natural-looking and view-consistent results using augmentations and priors [S1].
*   **Limitations:**
    *   Relies on the quality of the pretrained language-image model (CLIP) [S1].
    *   May require careful tuning of hyperparameters like $\alpha$ for blending and $\lambda_T, \lambda_D$ for priors [S1].
    *   The "Object Blending" mode with density summing inside activation allows removing original densities, which might lead to unintended artifacts if not controlled [S1].
*   **When to use:** When you need to edit or insert objects into an existing NeRF scene based on text prompts and have a defined 3D ROI box [S1].
*   **When not to use:** When you need to synthesize a new NeRF object from scratch without an existing scene (use Dream Fields) or when you have precise 2D masks and semantic decomposition is preferred (use Volumetric Disentanglement) [S1].

## Background
Blended-NeRF was introduced by Ori Gordon, Omri Avrahami, and Dani Lischinski from The Hebrew University in 2023 [S1]. It builds on the principles of NeRF [42] and Dream Fields [27], leveraging CLIP [51] for text-guided generation. It addresses the limitations of previous editing methods that required semantic decomposition or 2D masks [S1].
