# Deceptive-NeRF/3DGS Pipeline
Also called: Deceptive-3DGS, Deceptive-NeRF

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that enhances NeRF or 3D Gaussian Splatting (3DGS) representations by continuously densifying input observations with synthetic pseudo-observations generated by a diffusion model during training [S1]. Unlike inference-time interception methods that modify existing parameters, this approach optimizes the radiance field representation itself using a joint dataset of real input images and generated pseudo-observations [S1, Parent]. It distinguishes itself from sibling methods like DFF or Blended-NeRF by explicitly enforcing 3D view consistency through an uncertainty map derived from epipolar reprojection, rather than relying on ensemble learning, variational inference, or spatial perturbations [S1].

## How it works
### Inputs and Outputs
**Inputs:**
*   A set of $W$ input images $I = \{I_1, \dots, I_W\}$ with calibrated camera poses.
*   A pre-trained 2D latent diffusion model (e.g., Stable Diffusion) with a ControlNet adapter [S1].
*   A pre-trained image captioning network [S1].

**Outputs:**
*   An optimized NeRF or 3DGS representation $F_\Theta$ capable of high-quality novel view synthesis from sparse inputs [S1].

### Data Structures
1.  **NeRF/3DGS Representation ($F_\Theta$):** Maps 3D coordinates and view directions to density $\sigma$ and color $\mathbf{c}$ (NeRF) or Gaussian attributes (3DGS) [S1].
2.  **ControlNet Adapter:** A copy of the diffusion model's encoder/decoder weights, frozen or lightly tuned, with trainable convolutional layers inserted to process control maps [S1].
3.  **Control Map:** A 5-channel tensor containing:
    *   3 channels: Coarse RGB image $\hat{I}_{coarse}$.
    *   1 channel: Depth map $D$.
    *   1 channel: Uncertainty map $U$ [S1].
4.  **Text Embedding ($s$):** A composite latent vector formed by concatenating a caption embedding $s_0$ and an optimized shared latent embedding $s^*$ [S1].

### Numbered Steps

1.  **Initial Training:** Train the NeRF/3DGS representation using the sparse input images $I$ for a set number of epochs to obtain a coarse reconstruction [S1].
2.  **View Sampling:** Randomly sample novel viewpoints within a bounding box defined by the outermost input views [S1].
3.  **Rendering:** At a novel viewpoint $A$, render:
    *   RGB image $\hat{I}_A$.
    *   Depth map $\hat{D}_A$ using the weighted composition of distances:
        $$ \hat{\mathbf{D}} = \sum_{k=1}^K \hat{T}(t_k)\alpha(\sigma(t_k)\delta_k) $$
        where $\hat{T}(t_k)$ is transmittance, $\alpha$ is opacity, $\sigma$ is density, and $\delta_k$ is distance traveled [S1].
4.  **Uncertainty Map Generation:**
    *   Identify the nearest input viewpoint $B$ to the novel view $A$ [S1].
    *   Compute the warped image $I_{B \rightarrow A}$ by projecting pixels from the novel view to the input view:
        $$ q = K R_{B \rightarrow A} D_A(p) K^{-1} p $$
        where $p$ is the pixel location in $\hat{I}_A$, $q$ is the transformed pixel location in $I_B$, $K$ is the camera parameter matrix, and $R_{B \rightarrow A}$ is the viewpoint difference [S1].
    *   The warped image is defined as $I_{B \rightarrow A} = \psi(I_B; D_A, R_{B \rightarrow A})$ [S1].
    *   Calculate the uncertainty map $U_A$ as the squared difference between the warped image and the rendered image:
        $$ U_A = (I_{B \rightarrow A} - \hat{I}_A)^2 $$
        This enforces epipolar constraints and view consistency [S1].
5.  **Text Embedding Derivation:**
    *   Generate a text prompt $s_0$ using a pre-trained image captioning network on the coarse image [S1].
    *   Optimize a shared latent text embedding $s^*$ using textual inversion, shared across all input observations and coarse images [S1].
    *   Form the composite feature $s = [s_0, s^*]$ [S1].
6.  **Pseudo-Observation Generation:**
    *   Construct the control map from $\hat{I}_A$, $\hat{D}_A$, and $U_A$ [S1].
    *   Generate the pseudo-observation $P_A$ using the deceptive diffusion model $G$:
        $$ P_A = G(\hat{I}_A, \hat{D}_A, U_A) $$
    *   The model $G$ is fine-tuned to minimize the diffusion objective:
        $$ \min_{\theta}\mathbb{E}_{z\sim \mathcal{E},t,\epsilon \sim \mathcal{N}(0,1)}\|\epsilon -\epsilon_{\theta }(z_t,t,c(I_{\text {coarse}},D,U,s))\|_2^2 $$
        where $z \sim \mathcal{E}$ is the latent code, $t \sim [1, 1000]$ is the diffusion time step, $\epsilon$ is noise, $\epsilon_\theta$ is the denoiser U-Net, and $c$ is the embedding of the coarse image, depth, uncertainty, and text embedding [S1].
7.  **Filtering:** Discard 20% of the generated pseudo-observations with the lowest perceptual similarity to input images, quantified via the LPIPS metric [S1].
8.  **Optimization:** Continue training the NeRF/3DGS representation using the combination of real input images and the accumulated pseudo-observations [S1].
9.  **Iteration:** Repeat steps 2–8 until a sufficient number of observations are accumulated [S1].

```python
def train_deceptive_nerf(input_images, poses, diffusion_model, caption_model):
    """
    Trains a NeRF/3DGS using Deceptive-NeRF pipeline.
    """
    # 1. Initial coarse training
    nerf_model = initialize_nerf(input_images, poses)
    nerf_model.train(input_images, epochs=coarse_epochs)

    # 2. Prepare Diffusion Model with ControlNet
    # ControlNet expects 5 channels: 3 RGB, 1 Depth, 1 Uncertainty
    control_net = ControlNet(diffusion_model)
    control_net.load_pretrained_weights()
    
    # Optimize shared text embedding s*
    s_star = optimize_textual_inversion(input_images, caption_model)

    pseudo_observations = []

    while not sufficient_observations(pseudo_observations):
        # 3. Sample novel view
        view_A = sample_novel_view(poses)
        
        # 4. Render from NeRF
        I_hat_A = nerf_model.render_rgb(view_A)
        D_A = nerf_model.render_depth(view_A)
        
        # 5. Compute Uncertainty Map
        view_B = find_nearest_input_view(view_A, poses)
        I_B = get_image(view_B, input_images)
        
        # Warp I_B to view A's coordinate system
        # q = K * R_BA * D_A(p) * K^-1 * p
        I_warped = warp_image(I_B, D_A, view_A, view_B)
        
        # Uncertainty is squared difference
        U_A = (I_warped - I_hat_A) ** 2
        
        # 6. Generate Pseudo-Observation
        # Construct control map
        control_map = stack_channels(I_hat_A, D_A, U_A)
        
        # Get text embedding
        s_0 = caption_model.generate_prompt(I_hat_A)
        s = concatenate_embeddings(s_0, s_star)
        
        # Diffusion step
        # G(I_coarse, D, U, s) -> P_A
        P_A = control_net.generate(control_map, s)
        
        pseudo_observations.append(P_A)

    # 7. Filter pseudo-observations
    # Discard bottom 20% by LPIPS similarity to input images
    filtered_pseudo = filter_by_lpips(pseudo_observations, input_images, discard_rate=0.2)

    # 8. Final Optimization
    all_images = input_images + filtered_pseudo
    all_poses = poses + [view_A for view_A in sampled_views]
    nerf_model.train(all_images, all_poses, epochs=final_epochs)

    return nerf_model
```

### Parameters
*   **Discard Rate:** 20% of pseudo-observations are discarded based on LPIPS [S1].
*   **Image Resolution:** All images are randomly cropped to $512 \times 512$ [S1].
*   **ControlNet Channels:** 5 channels (3 RGB, 1 Depth, 1 Uncertainty) [S1].
*   **Gaussian Noise (Augmentation):** Standard deviation of 0.3, added to 60,000 Hypersim images for data augmentation [S1].
*   **Coarse NeRF Data:** Trained on one-fifth of input images [S1].
*   **Training Dataset Size:** 200 scenes, ~20,000 images (Hypersim and CO3D) [S1].

### Edge Cases and Pitfalls
*   **Captioning Efficacy:** Image captioning efficacy diminishes for low-quality images or those with pronounced artifacts. Textual inversion is used to optimize a shared latent embedding $s^*$ to counteract this [S1].
*   **Augmentation Data:** When training with noisy RGB-depth data augmentation (Hypersim), uncertainty maps are **not** fed into the diffusion model [S1].
*   **Computational Cost:** Training coarse and fine NeRF duos for all scenes is computationally expensive; data augmentation is used to mitigate this [S1].

## Operating characteristics
*   **Time Complexity:** The method requires iterative training loops where each iteration involves rendering, warping, and diffusion generation. The diffusion model inference is the most expensive step per novel view [S1].
*   **Memory Complexity:** Requires storing the NeRF/3DGS representation, the diffusion model weights, and the accumulated pseudo-observations. The ControlNet adapter adds minimal memory overhead [S1].
*   **Performance:** On the LLFF dataset, Deceptive-NeRF achieves a PSNR of 19.87 (3-view) and 25.30 (9-view), while Deceptive-3DGS achieves 19.95 (3-view) and 25.34 (9-view), outperforming SRF, PixelNeRF, MVSNeRF, DietNeRF, RegNeRF, and FreeNeRF [S1].
*   **Strengths:** Enforces 3D consistency via epipolar constraints without modifying the underlying representation. Generates high-quality photorealistic pseudo-observations.
*   **Limitations:** Relies on the quality of the pre-trained diffusion model and the accuracy of the initial coarse NeRF/3DGS reconstruction. Computationally intensive due to iterative diffusion generation [S1].

## Background
Deceptive-NeRF/3DGS was introduced by Liu et al. in 2023 [S1]. It addresses the challenge of sparse-view reconstruction by leveraging the priors of large-scale 2D diffusion models to fill in missing information in 3D radiance fields. The method builds on the concept of using diffusion models for image editing and inpainting, adapting it to the 3D reconstruction pipeline by generating "deceptive" pseudo-observations that guide the optimization of the 3D representation [S1].
