# Deceptive-NeRF/3DGS Pipeline

Also called: Deceptive-3DGS, Deceptive-NeRF

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that enhances NeRF or 3D Gaussian Splatting (3DGS) representations by continuously densifying input observations with synthetic pseudo-observations generated by a diffusion model during training [S1]. It distinguishes itself from sibling methods by explicitly enforcing 3D view consistency through an uncertainty map derived from epipolar reprojection of real input views, rather than relying on ensemble learning or variational inference [S1]. This approach allows the diffusion model to rectify rendering artifacts while maintaining geometric plausibility [S1].

## How it works

### Inputs and Outputs
*   **Inputs:** A set of $W$ input images $I = \{I_1, \dots, I_W\}$ with calibrated camera poses.
*   **Outputs:** A refined NeRF or 3DGS representation and a set of accumulated pseudo-observations $P$.

### Data Structures
*   **NeRF/3DGS Representation:** Standard representation mapping 3D coordinates $\mathbf{x}$ and viewing direction $\mathbf{d}$ to density $\sigma$ and color $\mathbf{c}$ (or Gaussian attributes).
*   **Rendered Data:** For a novel view $A$, the system renders:
    *   RGB image $\hat{I}_A$.
    *   Depth map $D_A$.
    *   Uncertainty map $U_A$.
*   **Diffusion Model Inputs (ControlNet):** A 5-channel control map consisting of:
    *   3 channels for coarse RGB image $I_{coarse}$.
    *   1 channel for depth map $D$.
    *   1 channel for uncertainty map $U$.
*   **Text Embedding:** A composite feature $s = [s_0, s^*]$ where $s_0$ is a text prompt and $s^*$ is an optimized latent embedding.

### Numbered Steps

1.  **Initial Training:** Train a NeRF or 3DGS representation using the few-view input images $I$ with calibrated poses [S1].
2.  **Coarse Reconstruction:** After a set number of epochs, obtain a coarse reconstruction [S1].
3.  **Novel View Sampling:** Randomly sample novel views within a bounding box defined by the outermost input views [S1].
4.  **Rendering:** At a novel viewpoint $A$, render the RGB image $\hat{I}_A$, depth map $D_A$, and uncertainty map $U_A$ [S1].
    *   **Depth Rendering:** Compute depth as a weighted composition of distances traveled:
        $$
        \hat{\mathbf{D}} = \sum_{k=1}^K \hat{T}(t_k)\alpha (\sigma (t_k)\delta _k)
        $$
        where $\hat{T}(t_k)$ is transmittance, $\alpha$ is opacity, $\sigma$ is density, and $\delta_k$ is the distance traveled [S1].
    *   **Uncertainty Map Generation:**
        1.  Identify $B$, the nearest input viewpoint to the novel view $A$ [S1].
        2.  Warp the ground truth image $I_B$ to the novel view $A$ using the rendered depth $D_A$ and the viewpoint difference $R_{B\rightarrow A}$:
            $$
            I_{B\rightarrow A} = \psi (I_B; D_A, R_{B\rightarrow A})
            $$
        3.  Transform pixel locations $p$ in $\hat{I}_A$ to $q$ in $I_B$ using the camera parameter matrix $K$:
            $$
            q = K R_{B\rightarrow A} D_A(p) K^{-1} p
            $$
        4.  Compute the uncertainty map $U_A$ as the squared difference between the warped image and the rendered image:
            $$
            U_A = (I_{B \rightarrow A} - \hat {I}_A)^2
            $$
            This measure enforces epipolar constraints and minimizes additional computation compared to ensemble methods [S1].
5.  **Pseudo-Observation Generation:** Generate a pseudo-observation $P_A$ using the Deceptive Diffusion Model $G$, conditioned on the rendered RGB, depth, and uncertainty:
    $$
    P_A = \operatorname {G}(\hat {I}_A, D_A, U_A)
    $$
    The model $G$ is a latent diffusion model (e.g., Stable Diffusion) fine-tuned with ControlNet [S1].
6.  **Text Embedding Derivation:**
    1.  Generate a text prompt $s_0$ using a pre-trained image captioning network [S1].
    2.  Optimize a shared latent text embedding $s^*$ shared by all input observations and coarse images using textual inversion [S1]. This counteracts the diminished efficacy of captioning on low-quality or artifact-ridden images [S1].
    3.  Form the composite feature $s = [s_0, s^*]$ [S1].
7.  **Diffusion Fine-Tuning (Training Phase):** The diffusion model is trained to minimize the objective:
    $$
    \min _{\theta}\mathbb {E}_{z\sim \mathcal {E},t,\epsilon \sim \mathcal {N}(0,1)}\|\epsilon -\epsilon _{\theta }(z_t,t,c(I_{\text {coarse}},D,U,s))\|_2^2
    $$
    where $z \sim \mathcal{E}$ is the latent code, $t \sim [1, 1000]$ is the diffusion time step, $\epsilon$ is noise, $\epsilon_\theta$ is the denoiser U-Net, and $c$ is the embedding of the coarse image, depth, uncertainty, and text embedding $s$ [S1].
8.  **Accumulation and Filtering:** Accumulate the generated pseudo-observations. Discard 20% of the pseudo-observations with the lowest perceptual similarity to input images, quantified via the LPIPS metric [S1]. This prevents generating content far from the original inputs [S1].
9.  **Optimization:** Continue training the NeRF/3DGS representation using the combination of real input images and the filtered pseudo-observations [S1].
10. **Iteration:** Iterate steps 3–9 until a sufficient number of observations are accumulated [S1].

def bilinear_sample(image, x, y):
    """Simple bilinear sampling."""
    x0, y0 = int(np.floor(x)), int(np.floor(y))
    x1, y1 = x0 + 1, y0 + 1
    dx, dy = x - x0, y - y0
    
    # Handle boundaries
    x0 = max(0, min(x0, image.shape[1]-1))
    y0 = max(0, min(y0, image.shape[0]-1))
    x1 = max(0, min(x1, image.shape[1]-1))
    y1 = max(0, min(y1, image.shape[0]-1))
    
    top = (1-dy) * image[y0, x0] + dy * image[y0, x1]
    bottom = (1-dy) * image[y1, x0] + dy * image[y1, x1]
    return (1-dx) * top + dx * bottom

### Parameters
*   **Discard Rate:** 20% of pseudo-observations with the lowest perceptual similarity (LPIPS) are discarded [S1].
*   **Image Resolution:** All images are randomly cropped to $512 \times 512$ resolution [S1].
*   **ControlNet Channels:** Five channels (3 for coarse RGB, 1 for depth, 1 for uncertainty) [S1].
*   **Gaussian Noise Standard Deviation:** 0.3, added to 60,000 images from Hypersim for training data augmentation [S1].
*   **Coarse NeRF Training Data:** Coarse NeRFs are trained using only one-fifth of the input images [S1].
*   **Training Dataset Size:** 200 scenes and approximately 20,000 images for the major section of the training dataset, with Hypersim and CO3D each contributing half [S1].

### Edge Cases and Pitfalls
*   **Image Captioning Efficacy:** Image captioning efficacy diminishes for images of lower quality or those with pronounced artifacts. This is counteracted by optimizing a shared latent text embedding $s^*$ via textual inversion [S1].
*   **Noisy Data Augmentation:** When training with noisy RGB-depth data augmentation (adding Gaussian noise to RGB images), uncertainty maps are **not** fed into the diffusion model [S1].
*   **Precision:** The uncertainty map calculation relies on precise depth rendering and camera calibration ($K$). Errors in $K$ or depth discontinuities can lead to incorrect warping and misleading uncertainty values [S1].

## Operating characteristics
*   **Time Complexity:** The method requires iterative training loops where each iteration involves rendering, warping, diffusion inference, and NeRF/3DGS optimization. The diffusion model inference is the most computationally expensive step per novel view [S1].
*   **Memory Complexity:** Requires storing the NeRF/3DGS representation, the diffusion model weights, and the accumulated pseudo-observations. The ControlNet architecture adds memory overhead compared to standard Stable Diffusion [S1].
*   **Measured Performance:** On the LLFF dataset, Deceptive-NeRF achieves a PSNR of 19.87 (3-view), 21.75 (6-view), and 23.22 (9-view). Deceptive-3DGS achieves 19.95 (3-view), 21.75 (6-view), and 23.22 (9-view). These results are competitive with or superior to SRF, PixelNeRF, MVSNeRF, DietNeRF, RegNeRF, and FreeNeRF [S1].
*   **Strengths:** Explicitly enforces 3D consistency via epipolar constraints without modifying the underlying representation. Effectively handles sparse views and low-resolution inputs.
*   **Limitations:** Computationally intensive due to the iterative diffusion generation and training. Relies on the quality of the pre-trained diffusion model and the accuracy of the initial coarse reconstruction [S1].

## Background
Deceptive-NeRF/3DGS was introduced by X. Liu et al. in the paper "Deceptive-NeRF/3DGS: Diffusion-Generated Pseudo-Observations for High-Quality Sparse-View Reconstruction" [S1]. The method leverages latent diffusion models (specifically Stable Diffusion with ControlNet) to generate pseudo-observations that rectify artifacts in NeRF/3DGS renderings. It addresses the challenge of sparse-view reconstruction by "densifying" the input data with synthetic views that are guided by an uncertainty map derived from view consistency checks [S1].
