# Deceptive-NeRF/3DGS Pipeline

Also called: Deceptive-3DGS, Deceptive-NeRF

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that enhances NeRF or 3D Gaussian Splatting (3DGS) representations by continuously densifying input observations with synthetic pseudo-observations generated by a diffusion model during training [S1]. It differs from sibling methods by explicitly enforcing 3D view consistency through an uncertainty map derived from epipolar reprojection of real input views, rather than relying on ensemble learning or spatial perturbations [S1]. This allows the diffusion model to generate high-fidelity pseudo-observations that rectify artifacts while maintaining geometric coherence with the sparse input data [S1].

## How it works
The method operates in an iterative loop alternating between rendering novel views, generating pseudo-observations via a conditioned diffusion model, and optimizing the radiance field using both real and synthetic data.

### Inputs and Outputs
**Inputs:**
*   A set of $W$ input images $I = \{I_1, \dots, I_W\}$ with calibrated camera poses.
*   A pre-trained radiance field representation $F_\Theta$ (NeRF or 3DGS).
*   A pre-trained 2D latent diffusion model (e.g., Stable Diffusion) with a ControlNet adapter [S1].

**Outputs:**
*   An optimized radiance field $F_\Theta$ capable of high-quality novel view synthesis from sparse inputs.

### Data Structures
1.  **Radiance Field Parameters $\Theta$**: Stores the neural network weights (NeRF) or Gaussian attributes (3DGS).
2.  **ControlNet Conditioner**: A trainable copy of the diffusion model's encoder/decoder structure, initialized with frozen pre-trained weights, accepting multi-channel control maps [S1].
3.  **Pseudo-Observation Buffer**: A collection of generated images $P_A$ and their corresponding camera poses.
4.  **Text Embedding $s$**: A composite latent vector $s = [s_0, s^*]$ where $s_0$ is from an image captioning network and $s^*$ is a learned shared latent embedding [S1].

### Numbered Steps

1.  **Initial Training**: Train the initial NeRF/3DGS representation $F_\Theta$ using the sparse input images $I$ for a set number of epochs to obtain a coarse reconstruction [S1].
2.  **View Sampling**: Randomly sample a novel viewpoint $A$ within the bounding box defined by the outermost input views [S1].
3.  **Rendering**: At viewpoint $A$, render the RGB image $\hat{I}_A$, depth map $\hat{D}_A$, and uncertainty map $U_A$ using $F_\Theta$ [S1].
    *   **Depth Rendering**: Compute depth as a weighted sum of distances:
        $$ \hat{D}_A = \sum_{k=1}^K \hat{T}(t_k) \alpha (\sigma(t_k)\delta_k) $$
        where $\hat{T}(t_k)$ is transmittance, $\alpha$ is opacity, $\sigma$ is density, and $\delta_k$ is the distance traveled between samples [S1].
    *   **Uncertainty Map Generation**:
        1.  Identify the nearest input viewpoint $B$ to novel view $A$ [S1].
        2.  Warp the ground truth image $I_B$ to viewpoint $A$ using the rendered depth $\hat{D}_A$ and the relative rotation $R_{B\rightarrow A}$:
            $$ I_{B\rightarrow A} = \psi(I_B; \hat{D}_A, R_{B\rightarrow A}) $$
        3.  For each pixel $p$ in $\hat{I}_A$, compute the transformed pixel location $q$ in $I_B$:
            $$ q = K R_{B\rightarrow A} \hat{D}_A(p) K^{-1} p $$
            where $K$ is the camera intrinsic matrix [S1].
        4.  Compute the uncertainty map $U_A$ as the squared difference between the warped image and the rendered image:
            $$ U_A = (I_{B\rightarrow A} - \hat{I}_A)^2 $$
            This enforces epipolar constraints and view consistency [S1].
4.  **Text Embedding Derivation**:
    1.  Generate a text prompt $s_0$ using a pre-trained image captioning network on $\hat{I}_A$ [S1].
    2.  Optimize a shared latent text embedding $s^*$ using textual inversion, shared across all input and coarse images [S1].
    3.  Concatenate to form $s = [s_0, s^*]$ [S1].
5.  **Pseudo-Observation Generation**: Generate the pseudo-observation $P_A$ using the Deceptive Diffusion Model $G$:
    $$ P_A = G(\hat{I}_A, \hat{D}_A, U_A, s) $$
    The model $G$ is a latent diffusion model fine-tuned with ControlNet. The ControlNet accepts a 5-channel control map: 3 channels for the coarse RGB image $\hat{I}_A$, 1 channel for depth $\hat{D}_A$, and 1 channel for uncertainty $U_A$ [S1].
6.  **Filtering**: Accumulate $P_A$ into the training set. Discard 20% of the accumulated pseudo-observations with the lowest perceptual similarity to the input images, quantified using the LPIPS metric [S1].
7.  **Optimization**: Update the radiance field parameters $\Theta$ by minimizing the photometric loss between rendered images and the combined set of real input images $I$ and filtered pseudo-observations [S1].
8.  **Iteration**: Repeat steps 2–7 until a sufficient number of pseudo-observations are accumulated or convergence is reached [S1].

```python
def train_deceptive_nerf(input_images, poses, initial_epochs, max_iterations):
    """
    Trains a NeRF/3DGS representation using Deceptive-NeRF/3DGS pipeline.
    
    Args:
        input_images: List of W input images.
        poses: List of W camera poses.
        initial_epochs: Number of epochs for initial coarse training.
        max_iterations: Total number of densification iterations.
        
    Returns:
        Optimized radiance field parameters Theta.
    """
    # 1. Initial Training
    theta = initialize_radiance_field()
    theta = optimize_radiance_field(theta, input_images, poses, epochs=initial_epochs)
    
    # 2. Prepare Diffusion Model
    # Load pre-trained Stable Diffusion with ControlNet
    diffusion_model = load_controlnet_diffusion()
    # Load captioning network
    captioner = load_image_captioning_network()
    # Initialize shared latent embedding s* via textual inversion
    s_star = optimize_shared_text_embedding(input_images, diffusion_model)
    
    # 3. Iterative Densification
    pseudo_observations = []
    
    for iteration in range(max_iterations):
        # Sample novel view
        view_A = sample_novel_view(poses)
        
        # Render coarse estimates
        I_hat_A, D_hat_A = render_radiance_field(theta, view_A)
        
        # Compute Uncertainty Map
        view_B = find_nearest_input_view(view_A, poses)
        I_B = get_image_for_pose(view_B, input_images)
        
        # Warp I_B to view A using D_hat_A
        # q = K * R_BA * D_hat_A(p) * K_inv * p
        I_warped_B_to_A = warp_image(I_B, D_hat_A, view_B, view_A)
        
        # Uncertainty is squared difference
        U_A = (I_warped_B_to_A - I_hat_A) ** 2
        
        # Generate Text Embedding
        s_0 = captioner.generate_caption(I_hat_A)
        s = concatenate_embeddings(s_0, s_star)
        
        # Generate Pseudo-Observation
        # ControlNet inputs: 3 channels RGB, 1 channel Depth, 1 channel Uncertainty
        control_map = stack_channels(I_hat_A, D_hat_A, U_A)
        P_A = diffusion_model.generate(control_map, s)
        
        pseudo_observations.append(P_A)
        
        # Filter pseudo-observations
        # Discard bottom 20% based on LPIPS against input images
        pseudo_observations = filter_pseudo_observations(pseudo_observations, input_images, discard_rate=0.2)
        
        # Optimize Radiance Field with Real + Pseudo data
        all_images = input_images + pseudo_observations
        theta = optimize_radiance_field(theta, all_images, poses + get_pseudo_poses(pseudo_observations))
        
    return theta
```

### Parameters
*   **Discard Rate**: 20% of pseudo-observations with the lowest LPIPS similarity are discarded [S1].
*   **ControlNet Channels**: 5 channels (3 for RGB, 1 for Depth, 1 for Uncertainty) [S1].
*   **Image Resolution**: All images are randomly cropped to $512 \times 512$ during diffusion training [S1].
*   **Training Dataset Size**: 200 scenes and approximately 20,000 images for the major training dataset (Hypersim and CO3D each contribute half) [S1].
*   **Coarse NeRF Data**: Coarse NeRFs for dataset generation are trained using only one-fifth of the input images [S1].
*   **Data Augmentation Noise**: Gaussian noise with standard deviation 0.3 is added to 60,000 Hypersim images for auxiliary training [S1].

### Edge Cases and Pitfalls
*   **Captioning Quality**: Image captioning efficacy diminishes for low-quality images or those with pronounced artifacts. This is mitigated by optimizing the shared latent text embedding $s^*$ via textual inversion [S1].
*   **Noisy Augmentation Inputs**: When training the diffusion model using noisy RGB-depth data augmentation (where uncertainty maps are not available), uncertainty maps must not be fed into the diffusion model [S1].
*   **Precision**: The uncertainty map calculation relies on accurate depth rendering and precise camera intrinsics $K$ for reprojection [S1].

## Operating characteristics
*   **Time Complexity**: The method adds significant computational overhead due to the iterative generation of pseudo-observations via a large diffusion model and the repeated optimization of the radiance field. Each iteration requires rendering, warping, diffusion sampling, and gradient backpropagation through the radiance field [S1].
*   **Memory Complexity**: Requires storing the radiance field parameters, the diffusion model weights (including ControlNet), and the buffer of pseudo-observations. The ControlNet architecture duplicates the diffusion model's encoder/decoder, increasing memory usage [S1].
*   **Performance**: On the LLFF dataset, Deceptive-NeRF achieves a PSNR of 19.87 (3-view), 21.75 (6-view), and 23.22 (9-view), outperforming SRF, PixelNeRF, MVSNeRF, DietNeRF, RegNeRF, and FreeNeRF [S1]. Deceptive-3DGS achieves similar or slightly better results (e.g., 19.95 PSNR for 3-view) [S1].
*   **Strengths**: Effectively densifies sparse inputs without requiring additional real camera captures. The uncertainty map ensures 3D consistency and reduces artifacts common in sparse-view NeRFs.
*   **Limitations**: Computationally expensive due to the diffusion model integration. Performance depends on the quality of the initial coarse reconstruction and the captioning network [S1].

## Background
Deceptive-NeRF/3DGS was introduced by Liu et al. in 2023 [S1]. It addresses the challenge of high-quality novel view synthesis from very few input images (sparse-view reconstruction). The method builds on the principles of differentiable volume rendering and leverages the strong priors of pre-trained 2D diffusion models to "deceptively" enhance the sparse data with synthetic but consistent observations. It distinguishes itself from uncertainty estimation methods based on ensembles or variational inference by using epipolar reprojection for uncertainty calculation [S1].
