# Deceptive-NeRF/3DGS Pipeline

Also called: Deceptive-3DGS, Deceptive-NeRF

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that enhances NeRF or 3D Gaussian Splatting (3DGS) representations by continuously densifying input observations with synthetic pseudo-observations generated by a diffusion model during training [S1]. Unlike methods that rely on ensemble learning, variational inference, or spatial perturbations for uncertainty estimation, this approach acquires uncertainty through correspondence matching by reprojecting real input observations to novel views, thereby minimizing additional computation while enforcing epipolar constraints [S1]. It addresses the problem of artifacts and missing geometry in sparse-view settings by using a "deceptive" diffusion model conditioned on rendered RGB, depth, and uncertainty maps to generate photorealistic pseudo-observations that guide the 3D optimization [S1].

## How it works

### Inputs and Outputs
*   **Inputs**: A set of $W$ input images $I = \{I_1, \dots, I_W\}$ with calibrated camera poses. A pre-trained 2D diffusion model (e.g., Stable Diffusion) initialized with ControlNet.
*   **Outputs**: An optimized NeRF or 3DGS representation $F_\Theta$ capable of rendering high-quality novel views.

### Data Structures
*   **NeRF/3DGS Representation $F_\Theta$**: Maps 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$ to density $\sigma$ and color $c$. For NeRF, this involves volumetric rendering; for 3DGS, it involves splatting Gaussian primitives.
*   **Rendered Images $\hat{I}_A$**: RGB image rendered at a novel viewpoint $A$.
*   **Rendered Depth Map $\hat{D}_A$**: Depth map rendered at viewpoint $A$.
*   **Uncertainty Map $U_A$**: A map indicating view inconsistency at viewpoint $A$.
*   **Pseudo-Observation $P_A$**: Synthetic image generated by the diffusion model.
*   **Text Embedding $s$**: Composite feature vector combining semantic and visual attributes.

### Numbered Steps

1.  **Initial Training**: Train the NeRF/3DGS representation using the few-view input images $I$ with their calibrated poses for a set number of epochs to obtain a coarse reconstruction [S1].
2.  **View Sampling**: Randomly sample a novel viewpoint $A$ within a bounding box defined by the outermost input views [S1].
3.  **Rendering**: At viewpoint $A$, render the RGB image $\hat{I}_A$ and the depth map $\hat{D}_A$.
    *   The depth value for each ray is computed as a weighted composition of distances traveled from the origin:
        $$ \hat{\mathbf{D}} = \sum_{k=1}^K \hat{T}(t_k)\alpha (\sigma (t_k)\delta_k) $$
        where $\hat{T}(t_k)$ is the transmittance, $\alpha$ is opacity, $\sigma$ is density, and $\delta_k$ is the distance traveled [S1].
4.  **Uncertainty Map Generation**:
    *   Identify the nearest input viewpoint $B$ to the novel view $A$.
    *   Warp the ground truth image $I_B$ from viewpoint $B$ to viewpoint $A$ using the rendered depth map $\hat{D}_A$ and the viewpoint difference $R_{B\rightarrow A}$:
        $$ I_{B\rightarrow A} = \psi (I_B; \hat{D}_A, R_{B\rightarrow A}) $$
    *   For each pixel location $p$ in $\hat{I}_A$, transform it to location $q$ in $I_B$:
        $$ q = K R_{B\rightarrow A} \hat{D}_A(p) K^{-1} p $$
        where $K$ is the camera parameter matrix [S1].
    *   Compute the uncertainty map $U_A$ as the squared distance between the warped image and the rendered image:
        $$ U_A = (I_{B\rightarrow A} - \hat{I}_A)^2 $$
        This measure enforces view consistency by leveraging epipolar constraints without modifying the underlying representation [S1].
5.  **Text Embedding Derivation**:
    *   Generate an initial text prompt $s_0$ using a pre-trained image captioning network [S1].
    *   Optimize a shared latent text embedding $s^*$ shared by all input observations and coarse images using textual inversion to counteract captioning errors on low-quality or artifact-ridden images [S1].
    *   Form the composite feature $s$ by concatenating the embeddings:
        $$ s = [s_0, s^*] $$
        This encapsulates both semantic and visual attributes [S1].
6.  **Pseudo-Observation Generation**:
    *   Generate the pseudo-observation $P_A$ using the deceptive diffusion model $G$, conditioned on the coarse rendered image $\hat{I}_A$, depth map $\hat{D}_A$, uncertainty map $U_A$, and text embedding $s$:
        $$ P_A = \operatorname{G}(\hat{I}_A, \hat{D}_A, U_A, s) $$
    *   The model $G$ is a latent diffusion model fine-tuned with ControlNet to preserve pre-trained weights while learning specific input conditions [S1].
7.  **Filtering**: Discard 20% of the generated pseudo-observations that have the lowest perceptual similarity to the input images, quantified via the LPIPS metric. This prevents the accumulation of content far from the original inputs [S1].
8.  **Optimization**: Continue training the NeRF/3DGS representation using a combination of the original real input images and the accumulated pseudo-observations [S1].
9.  **Iteration**: Repeat steps 2–8 until a sufficient number of observations are accumulated for the final reconstruction [S1].

def compute_depth_rendering(transmittance: np.ndarray, opacity: np.ndarray, 
                            density: np.ndarray, delta: np.ndarray) -> np.ndarray:
    """
    Computes depth map from volumetric rendering parameters.
    D = sum(T(t_k) * alpha * sigma(t_k) * delta_k)
    """
    # alpha is derived from opacity logit o as 2D Gaussian * opacity logit [S1]

    # but source specifies alpha is given by evaluating a 2D Gaussian multiplied by opacity logit.

    depth = np.sum(transmittance * opacity * density * delta, axis=-1)
    return depth

    H, W = source_image.shape[:2]

    p_homogeneous = np.stack([x, y, np.ones_like(x)], axis=-1) # p in homogeneous coords

def deceptive_nerf_pipeline(input_images: List[np.ndarray], poses: List[np.ndarray],

    Main pipeline for Deceptive-NeRF/3DGS.

### Parameters
*   **Discard Rate**: 20% of pseudo-observations with the lowest perceptual similarity (LPIPS) are discarded [S1].
*   **ControlNet Channels**: Five channels are used for the control map: 3 for coarse RGB, 1 for depth, and 1 for uncertainty [S1].
*   **Image Resolution**: All images are randomly cropped to $512 \times 512$ resolution [S1].
*   **Gaussian Noise**: Standard deviation of 0.3 is added to 60,000 images from Hypersim for data augmentation [S1].
*   **Coarse NeRF Training Data**: Coarse NeRFs are trained using only one-fifth of the input images [S1].
*   **Training Dataset Size**: Approximately 20,000 images from 200 scenes (Hypersim and CO3D, half each) are used for the major section of the training dataset [S1].

### Edge Cases and Pitfalls
*   **Captioning Efficacy**: Image captioning efficacy diminishes for images of lower quality or those with pronounced artifacts. Textual inversion is used to optimize a shared latent text embedding $s^*$ to counteract this [S1].
*   **Augmentation Data**: When training with noisy RGB-depth data augmentation (from Hypersim), uncertainty maps are not fed into the diffusion model [S1].
*   **Precision**: The uncertainty map calculation relies on accurate depth rendering and camera calibration; errors in $K$ or pose estimation will propagate into $U_A$ [S1].

## Subtopics

### Deceptive Diffusion Model
A 2D latent diffusion model fine-tuned with ControlNet to generate pseudo-observations conditioned on coarse RGB, depth, and uncertainty maps. It differs from standard inpainting by explicitly using uncertainty to enforce cross-view consistency. Choose this when sparse-view artifacts need rectification using 2D priors. [Link](12068-dff-decomposing-nerf-for-editing-via-feature-field-distillat.md) (See DFF for feature field distillation alternative).

### Uncertainty via Correspondence Matching
A method to estimate view consistency by warping nearest input views to novel views using rendered depth. It differs from ensemble or variational methods by being computationally lightweight and enforcing epipolar constraints. Choose this when computational efficiency in uncertainty estimation is critical. [Link](12405-adaptive-view-selection-for-inpainting.md) (See Adaptive View Selection for view-dependent weighting).

## Operating characteristics

*   **Time Complexity**: The method requires iterative training loops. Each iteration involves rendering, warping, diffusion inference, and NeRF/3DGS optimization. The diffusion model fine-tuning adds significant preprocessing time.
*   **Memory Complexity**: Requires storing the NeRF/3DGS representation, the diffusion model (ControlNet), and the accumulated pseudo-observations. The dataset for diffusion training (20,000 images) requires significant storage.
*   **Measured Performance**: On LLFF dataset with 3 views, Deceptive-NeRF achieves PSNR 19.87 and SSIM 0.436. Deceptive-3DGS achieves PSNR 19.95 and SSIM 0.438. These results are competitive with or better than PixelNeRF, MVSNeRF, and DietNeRF in sparse-view settings [S1].
*   **Strengths**: Effectively densifies sparse inputs, reduces artifacts, and enforces 3D consistency without modifying the 3D representation's core architecture.
*   **Limitations**: Relies on the quality of the pre-trained diffusion model and the accuracy of the initial coarse reconstruction. Performance may degrade if the initial NeRF/3DGS is very poor.
*   **When to Use**: Sparse-view reconstruction (3-9 views) where standard NeRF/3DGS fails to capture geometry and texture.
*   **When Not to Use**: Dense-view settings where pseudo-observations add little value, or when computational resources for diffusion inference are limited.

## Background

Deceptive-NeRF/3DGS was introduced by Liu et al. in 2023 [S1]. It builds on the principles of differentiable volume rendering and recent advances in diffusion models for image synthesis. The method addresses the limitations of sparse-view reconstruction by leveraging the strong priors of 2D diffusion models to generate plausible pseudo-observations, guided by uncertainty maps derived from epipolar geometry. It is used in computer vision for novel view synthesis, particularly in scenarios with limited input data.
