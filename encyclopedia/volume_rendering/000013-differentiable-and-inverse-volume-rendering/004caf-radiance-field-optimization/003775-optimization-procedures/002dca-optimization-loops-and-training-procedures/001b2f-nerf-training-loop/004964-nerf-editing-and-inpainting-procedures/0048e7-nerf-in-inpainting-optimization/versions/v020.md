# NeRF-In Inpainting Optimization

Also called: Free-Form NeRF Inpainting with RGB-D Priors, NeRF object removal, NeRF-In

## Overview
NeRF-In is a method for removing unwanted objects from a pre-trained Neural Radiance Field (NeRF) without category-specific training data or retraining from scratch [S1, unofficial]. It solves the problem of 3D object removal by optimizing the NeRF parameters $\Theta$ to match 2D color and depth guidance derived from a single user-drawn mask and external inpainting priors [S1, unofficial]. Unlike methods that require retraining from random initialization or category-specific data, NeRF-In updates an existing model using a joint color and depth loss, ensuring geometric consistency and view coherence [S1, unofficial].

## How it works
**Inputs:**
*   Pre-trained NeRF model $F_\Theta$ mapping $(\mathbf{x}, \mathbf{d}) \to (\sigma, \mathbf{c})$.
*   User-chosen camera position $\mathbf{o}_u$.
*   User-drawn mask $M_u$ on the rendered view $I_u = F_{\Theta_{image}}(\mathbf{o}_u)$, where $M_u(\mathbf{p})=1$ for pixels outside the masked region (background) and $0$ inside (object to remove).
*   Trajectory for sampling $K$ additional camera positions $\mathbf{O} = \{\mathbf{o}_s \mid s=1\dots K\}$.

**Outputs:**
*   Updated NeRF parameters $\tilde{\Theta}$.

**Data Structures:**
*   **NeRF Model $F_\Theta$**: Standard MLP parameters.
*   **Masks $M$**: Set of transferred masks $\{M_s\}_{s=1}^K$ for sampled views.
*   **Guidance Images $I^G$**: Set of inpainted color images $\{I_s^G\}_{s=1}^K$.
*   **Guidance Depth $D^G$**: Set of completed depth images $\{D_s^G\}_{s=1}^K$.

**Steps:**

1.  **Sample Views:** Sample $K$ camera positions $\mathbf{O}$ along a pre-set trajectory (e.g., LLFF test-set trajectory). Render initial RGB images $I_s$ and depth images $D_s$ using $F_\Theta$.
2.  **Transfer Mask:** Transfer the user-drawn mask $M_u$ to the sampled views to generate transferred masks $M = \{M_s\}$ using a video object segmentation method (e.g., STCN) [S1, unofficial].
3.  **Generate Guidance:**
    *   Generate guiding color images $I_s^G = \rho(I_s, M_s)$ using an image inpainting method $\rho$ (e.g., MST inpainting network) [S1, unofficial].
    *   Generate guiding depth images $D_s^G = \tau(D_s, M_s, I_s^G)$ using a depth completion method $\tau$ (e.g., Fast Bilateral Solver) [S1, unofficial].
4.  **Define View Sets:**
    *   Set $\mathcal{O}_{all} = \{\mathbf{o}_u\}$ (only the user-chosen view for color consistency).
    *   Set $\mathcal{O}_{out} = \mathbf{O}$ (all sampled views for depth consistency) [S1, unofficial].
5.  **Optimize:** Minimize the total loss $L(\Theta) = L_{color}(\Theta) + L_{depth}(\Theta)$ using the Adam optimizer for 50,000 steps to obtain $\tilde{\Theta}$ [S1, unofficial].

**Formulas:**

The rendered color $\hat{C}(\mathbf{r})$ for a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ is computed via volume rendering [S1, unofficial]:
$$
\hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) c_i
$$
where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$, $\delta_i = t_{i+1} - t_i$, and $c_i, \sigma_i$ are the color and density at sample point $t_i$.

The **Color-Guiding Loss** $L_{color}(\Theta)$ is the sum of an all-view loss and an outside-view loss [S1, unofficial]:
$$
L_{color}(\Theta) = L_{all}^{color}(\Theta) + L_{out}^{color}(\Theta)
$$
where:
$$
L_{all}^{color}(\Theta) = \sum_{\mathbf{o} \in \mathcal{O}_{all}} \| F_{\Theta_{image}}(\mathbf{o}) - I_{\mathbf{o}}^G \|_2^2
$$
$$
L_{out}^{color}(\Theta) = \sum_{\mathbf{o} \in \mathcal{O}_{out}} \| (F_{\Theta_{image}}(\mathbf{o}) - I_{\mathbf{o}}^G) \odot M_{\mathbf{o}} \|_2^2
$$
Here, $F_{\Theta_{image}}(\mathbf{o})$ is the rendered image from camera $\mathbf{o}$, and $M_{\mathbf{o}}$ is the transferred mask at that view. Note that $\mathcal{O}_{all}$ contains only $\mathbf{o}_u$, while $\mathcal{O}_{out}$ contains the sampled views $\mathbf{O}$ [S1, unofficial].

The **Depth-Guiding Loss** $L_{depth}(\Theta)$ measures the L2 distance between rendered fine/coarse depth images and guiding depth [S1, unofficial]:
$$
L_{depth}(\Theta) = \sum_{\mathbf{o}_s \in \mathbf{O}} \left( \| D_f(\mathbf{o}_s) - D_s^G \|_2^2 + \| D_c(\mathbf{o}_s) - D_s^G \|_2^2 \right)
$$
where $D_f(\mathbf{o}_s)$ and $D_c(\mathbf{o}_s)$ are the fine and coarse depth images rendered from $\mathbf{o}_s$ using $F_\Theta$. Depth is computed by accumulating density $\sigma$ along rays [S1, unofficial].

**Parameters:**
*   $K$: Number of sampled camera positions.
*   Batch size: 4,096 [S1, unofficial].
*   Sample points (fine): 128 [S1, unofficial].
*   Sample points (coarse): 64 [S1, unofficial].
*   Optimizer: Adam [S1, unofficial].
*   Training steps for inpainting: 50,000 [S1, unofficial].

**Pseudocode:**

```python
def nerf_in_inpainting(F_theta, o_u, M_u, trajectory, K, rho, tau, optimizer, steps):
    """
    F_theta: Pre-trained NeRF model
    o_u: User-chosen camera position
    M_u: User-drawn mask on view o_u (1=outside, 0=inside)
    trajectory: Function to sample K camera positions
    K: Number of sampled views
    rho: Image inpainting function
    tau: Depth completion function
    optimizer: Adam optimizer for theta
    steps: Number of optimization steps (50,000)
    """
    
    # 1. Sample K camera positions
    O = trajectory(K)
    
    # 2. Render initial views and transfer masks
    # Note: STCN is used for mask transfer in the source, implemented here as a placeholder function
    masks_M = []
    for o_s in O:
        # Render initial RGB and Depth for mask transfer context
        I_s = render_image(F_theta, o_s)
        D_s = render_depth(F_theta, o_s)
        
        # Transfer mask from o_u to o_s using video object segmentation (e.g., STCN)
        # This requires temporal consistency logic not detailed in the single-passage source
        M_s = transfer_mask(M_u, o_u, o_s, I_u=render_image(F_theta, o_u)) 
        masks_M.append(M_s)
        
    # 3. Generate Guidance Materials
    guidance_colors = []
    guidance_depths = []
    
    for s in range(K):
        o_s = O[s]
        M_s = masks_M[s]
        
        # Generate guiding color image using inpainting method rho
        I_s_G = rho(render_image(F_theta, o_s), M_s)
        guidance_colors.append(I_s_G)
        
        # Generate guiding depth image using depth completion method tau
        D_s_G = tau(render_depth(F_theta, o_s), M_s, I_s_G)
        guidance_depths.append(D_s_G)
        
    # 4. Define View Sets
    O_all = [o_u]
    O_out = O
    
    # 5. Optimization Loop
    for step in range(steps):
        optimizer.zero_grad()
        
        total_loss = 0.0
        
        # Color Loss: All-view (only user view)
        # L_all_color = || F(o_u) - I_u^G ||^2
        # Note: I_u^G is generated from I_u and M_u using rho
        I_u_G = rho(render_image(F_theta, o_u), M_u)
        loss_all_color = mse_loss(render_image(F_theta, o_u), I_u_G)
        total_loss += loss_all_color
        
        # Color Loss: Outside-view (sampled views)
        # L_out_color = sum( || (F(o_s) - I_s^G) * M_s ||^2 )
        loss_out_color = 0.0
        for s in range(K):
            o_s = O[s]
            M_s = masks_M[s]
            I_s_G = guidance_colors[s]
            rendered_I = render_image(F_theta, o_s)
            
            # Apply mask: only compute loss on pixels where M_s == 1 (outside object)
            # Element-wise multiplication with mask
            diff = (rendered_I - I_s_G) * M_s
            loss_out_color += mse_loss(diff, torch.zeros_like(diff))
            
        total_loss += loss_out_color
        
        # Depth Loss: Sampled views
        # L_depth = sum( || D_f(o_s) - D_s^G ||^2 + || D_c(o_s) - D_s^G ||^2 )
        loss_depth = 0.0
        for s in range(K):
            o_s = O[s]
            D_s_G = guidance_depths[s]
            
            # Render fine and coarse depth
            D_f = render_depth_fine(F_theta, o_s)
            D_c = render_depth_coarse(F_theta, o_s)
            
            loss_depth += mse_loss(D_f, D_s_G)
            loss_depth += mse_loss(D_c, D_s_G)
            
        total_loss += loss_depth
        
        total_loss.backward()
        optimizer.step()
        
    return F_theta
```

**Edge Cases and Pitfalls:**
*   **Masked MSE Only:** Optimizing only with masked Mean Squared Error (MSE) on transferred masks without explicit guidance causes the unwanted object to remain in the result [S1, unofficial].
*   **Depth-Only Loss:** Using only $L_{depth}$ introduces color noise outside the masked region and loses color information in flat regions [S1, unofficial].
*   **Multiple Color Guidance:** Using multiple inpainted images as color guidance introduces visual inconsistency between views. The method restricts color guidance to the user-chosen view only to maintain stability [S1, unofficial].
*   **Guidance Artifacts:** If the initial guidance materials (from $\rho$ and $\tau$) contain artifacts, the optimized NeRF may output undesired results [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Optimization takes approximately 5 hours per scene on an Intel i7-7800X CPU and GTX-1080 GPU for 50,000 steps [S1, unofficial].
*   **Memory Complexity:** Uses a batch size of 4,096 rays. Requires storing guidance images and masks for $K$ views.
*   **Strengths:** No category-specific training data or procedure required; preserves view consistency; corrects geometry via depth loss.
*   **Limitations:** Relies on the quality of external inpainting/depth completion models; may propagate artifacts from guidance; not given in the sources for large-scale scene scalability.
*   **When to use:** Removing specific unwanted objects from a static NeRF scene where a single view mask is available.
*   **When not to use:** When high-fidelity color restoration in flat regions is critical without depth guidance, or when the scene geometry is highly dynamic (NeRF assumes static scenes).

## Background
NeRF-In was introduced by Hao-Kang Liu, I-Chao Shen, and Bing-Yu Chen in June 2022 [S1, unofficial]. It addresses the unintuitive nature of editing pre-trained NeRFs by providing a free-form inpainting framework. It builds on standard NeRF volume rendering [S1, unofficial] and utilizes existing 2D inpainting (MST) and depth completion (Fast Bilateral Solver) techniques as priors. It was evaluated on the LLFF dataset and a custom dataset with 24 camera positions per scene [S1, unofficial].
