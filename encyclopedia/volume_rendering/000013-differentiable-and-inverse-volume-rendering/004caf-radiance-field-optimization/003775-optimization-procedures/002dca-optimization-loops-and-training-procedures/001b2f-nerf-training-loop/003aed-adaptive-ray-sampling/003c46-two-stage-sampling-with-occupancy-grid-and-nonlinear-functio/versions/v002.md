# Two-Stage Sampling with Occupancy Grid and Nonlinear Function

Also called: Hybrid Sampling Strategy, Two-Phase Sampling

## Overview
This method accelerates neural implicit surface reconstruction by combining spatial pruning with importance biasing. It solves the inefficiency of uniform sampling in empty space and the randomness of inverse transform sampling near surfaces. Unlike [Coarse-to-Fine NeRF](3406-coarse-to-fine-nerf.md) which relies on a proposal network, and [Probability-based Ray Sampling with Quadtree Subdivision](7481-probability-based-ray-sampling-with-quadtree-subdivision.md) which uses image-space error, this method uses a binary Occupancy Grid to skip empty regions and a nonlinear piecewise exponential function to bias samples toward the surface within occupied regions [S1].

## How it works

### Inputs and Outputs
*   **Inputs**: Camera parameters (position, direction), ground truth RGB images, optional binary masks.
*   **Outputs**: Rendered RGB images, reconstructed 3D mesh (via Marching Cubes).

### Data Structures

**Occupancy Grid**
*   **Layout**: A binary array (or hash map) mapping spatial coordinates to a boolean value.
*   **Meaning**: `True` if an object surface intersects the spatial region (cell); `False` otherwise.
*   **Implementation**: Uses Multi-resolution Hash Encoding with 16 levels, ranging from $2^5$ to $2^{16}$, with a feature size of 2 per level [S1].

**Network Inputs**
For each sample point $x$, the appearance network $F_\beta$ takes:
1.  Position $x$.
2.  Normal vector $n$ (computed via finite differences).
3.  Geometry feature $enc$ (output from the SDF network).
4.  Direction $d$ (encoded via Spherical Harmonics) [S1].

### Algorithm Steps

1.  **Coarse Stage (Spatial Pruning)**:
    *   Cast a ray through the Occupancy Grid.
    *   Identify the interval $[t_{near}, t_{far}]$ where the ray intersects occupied cells.
    *   Skip sampling in empty cells to avoid invalid computations [S1].

2.  **Coarse Sampling**:
    *   Perform uniform sampling within the occupied interval $[t_{near}, t_{far}]$ to generate coarse points $\{t_i\}$.
    *   Query the SDF network $F_\theta$ at these points to get SDF values $f_{sdf}(t_i)$.
    *   Compute opacity weights $w_i$ for each point using the standard NeRF/NeuS formulation: $w_i = T_i \alpha_i$, where $T_i$ is the accumulated transmittance and $\alpha_i$ is the opacity derived from the SDF [S1].

3.  **Fine Stage (Nonlinear Biasing)**:
    *   For each coarse interval $[t_i, t_{i+1}]$, define the weights at the endpoints: $a = w(t_i)$ and $b = w(t_{i+1})$.
    *   Define the nonlinear piecewise exponential function $\hat{w}(s)$ for $s \in [0, 1]$ (normalized interval):
        $$ \hat{w}(s) = a \left( \frac{b}{a} \right)^s $$
        where $a \ge 0$ and $b \le 1$ [S1].
    *   Compute the cumulative distribution function (CDF) integral for this interval:
        $$ \int_{t_i}^{t_{i+1}} w(t) dt = \int_{0}^{1} \hat{w}(s) ds = \frac{b - a}{\ln b - \ln a} \quad (\text{if } a \neq b) $$
        *Note: If $a=b$, the integral is simply $a$.*
    *   Use Inverse Transform Sampling with the CDF derived from $\hat{w}(s)$ to draw fine sample points. This biases samples toward the endpoint with the higher weight (typically the surface intersection) [S1].

4.  **Network Forward Pass**:
    *   Query the SDF network $F_\theta$ at fine sample points to get $f_{sdf}(x)$.
    *   Compute normals $n$ using finite differences:
        $$ \nabla f_{sdf}(x) \approx \frac{f_{sdf}(x + \epsilon) - f_{sdf}(x - \epsilon)}{2\epsilon} $$
        where $\epsilon$ is the hash grid size [S1].
    *   Query the Appearance network $F_\beta$ with $(x, n, enc, d)$ to get color $c$.

5.  **Rendering and Loss**:
    *   Render color $\hat{C}(x)$ and accumulated opacity $\hat{O}_k$.
    *   Compute Loss $\mathcal{L} = \mathcal{L}_{color} + \lambda_1 \mathcal{L}_{eik} + \lambda_2 \mathcal{L}_{mask}$ [S1].

import numpy as np

def compute_nonlinear_cdf(a, b, num_samples):
    """
    Computes sample positions using Inverse Transform Sampling
    for the nonlinear function w_hat(s) = a * (b/a)^s.
    
    Args:
        a: Weight at start of interval w(t_i)
        b: Weight at end of interval w(t_{i+1})
        num_samples: Number of fine samples to draw in this interval
        
    Returns:
        normalized_positions: Array of s in [0, 1]
    """
    if a == 0 and b == 0:
        # No weight, uniform distribution
        return np.linspace(0, 1, num_samples)
    
    if a == 0:
        # Limit case: a -> 0. Integral is b. CDF is s.
        # However, mathematically if a=0, w_hat(s) = 0 for all s unless b>0?
        # Actually if a=0, w_hat(s) = 0 * (b/0)^s is undefined.
        # In practice, if a is very small, we treat it as uniform or handle carefully.
        # Based on formula: integral = (b-0)/(ln b - ln 0) -> 0.
        # If a=0, the weight is 0 at start. If b>0, it rises.
        # Let's assume a > 0 for stability, or use uniform if a is negligible.
        return np.linspace(0, 1, num_samples)

    if a == b:
        # Constant weight, uniform distribution
        return np.linspace(0, 1, num_samples)

    # CDF(s) = integral_0^s a * (b/a)^t dt
    # Let k = ln(b/a). Integral = a * [ (b/a)^t / k ]_0^s
    # CDF(s) = (a/k) * ( (b/a)^s - 1 )
    # Total Integral I = (a/k) * ( (b/a)^1 - 1 ) = (a/k) * (b/a - 1) = (b-a)/k
    
    k = np.log(b / a)
    total_integral = (b - a) / k
    
    # Generate random u in [0, 1]
    u = np.random.uniform(0, 1, num_samples)
    
    # Inverse CDF: u = CDF(s) => u * k / a = (b/a)^s - 1
    # (b/a)^s = 1 + u * k / a
    # s = ln(1 + u * k / a) / ln(b/a)
    
    # Guard against numerical issues
    val = 1 + u * k / a
    val = np.clip(val, 1e-8, None)
    
    s = np.log(val) / k
    
    return s

### Parameters
*   **Hash Encoding Levels**: 16 levels, ranging from $2^5$ to $2^{16}$ [S1].
*   **Hash Feature Size**: 2 per level [S1].
*   **Geometry MLP**: 1 layer, hidden size 64 [S1].
*   **Appearance MLP**: 2 layers, hidden size 64 [S1].
*   **Learning Rate**: 0.001 for both Geometry Network $F_\theta$ and Appearance Network $F_\beta$ [S1].
*   **Optimizer**: AdamW, betas $(0.9, 0.99)$ [S1].
*   **Regularization Weights**: $\lambda_1$ (Eikonal) = 0.1, $\lambda_2$ (Mask) = 0.1 [S1].
*   **Progressive Training Update Step**: 1000 iterations (hash levels updated every 1000 steps) [S1].

### Edge Cases and Pitfalls
*   **Normal Noise**: Using analytic gradients for normals in SDF networks can be noisy. This method uses finite differences for smoother normals [S1].
*   **Empty Regions**: The Occupancy Grid must be accurately updated. If the grid is too coarse, it may mark empty space as occupied or vice versa, leading to wasted samples or missing geometry.
*   **Weight Extremes**: If $a=0$ and $b=0$, the nonlinear function is undefined. The implementation should fall back to uniform sampling in this case. If $a=b$, it also falls back to uniform sampling [S1].

## Subtopics

### Coarse-to-Fine NeRF
Uses a proposal network to learn the sampling distribution. Choose when you have sufficient memory for a proposal network and want to learn complex distributions without explicit spatial structures. Link: [Coarse-to-Fine NeRF](3406-coarse-to-fine-nerf.md).

### Probability-based Ray Sampling with Quadtree Subdivision
Uses image-space error to subdivide regions. Choose when error is spatially varying and not just depth-dependent. Link: [Probability-based Ray Sampling with Quadtree Subdivision](7481-probability-based-ray-sampling-with-quadtree-subdivision.md).

### TermiNeRF
Focuses on termination criteria for ray marching. Choose when dealing with transparent scenes or specific termination logic. Link: [TermiNeRF](8828-terminerf.md).

### Pixel Region and Depth Guided Ray Sampling
Uses depth estimation to guide sampling. Choose when depth priors are available or reliable. Link: [Pixel Region and Depth Guided Ray Sampling](8866-pixel-region-and-depth-guided-ray-sampling.md).

### NeuSample
Uses a separate network to predict sampling positions. Choose when you want a learned, data-driven sampling distribution rather than a heuristic one. Link: [NeuSample](9472-neusample.md).

## Operating characteristics

*   **Time Complexity**: Reduced compared to uniform sampling due to skipping empty regions (Occupancy Grid) and concentrating samples near surfaces (Nonlinear Function). The hash encoding lookup is $O(1)$ on average.
*   **Memory Complexity**: Dominated by the Occupancy Grid (hash map) and the MLP weights. The hash grid size is determined by the number of levels and feature size (16 levels, 2 features) [S1].
*   **Measured Performance**: Tested on DTU and NeRF Synthetic datasets. Achieves better Chamfer Distance (CD) and PSNR than NeuS and Neus-acc with fewer iterations (20,000) [S1].
*   **Strengths**:
    *   Avoids sampling in empty space.
    *   Biases samples toward the surface, improving reconstruction quality.
    *   Faster than NeuS due to fewer useless samples.
*   **Limitations**:
    *   Requires an Occupancy Grid, which needs to be maintained/updated.
    *   Finite difference normal computation is slower than analytic gradients (though smoother).
    *   Performance depends on the resolution of the Occupancy Grid.
*   **When to Use**: Efficient neural implicit surface reconstruction from RGB images where training time and sample efficiency are critical.
*   **When Not to Use**: If analytic gradients are sufficient and speed of normal computation is more critical than smoothness, or if the scene has no clear empty/occupied distinction.

## Background

*   **Origin**: Proposed by Siyuan He and Xinglin Liu from Wuyi University, published in March 2024 [S1].
*   **History**: Builds on NeRF [1] and NeuS [2]. Addresses limitations of NeuS (random scatter near surface) and Instant-NGP (uniform sampling in occupied cells) [S1]. Inspired by DoNeRF [15] and NeuS2 [12]/Neuralangelo [14] regarding occupancy grids.
*   **Usage**: Used for neural implicit surface reconstruction, specifically for surface recovery and novel view synthesis on real and synthetic datasets (DTU, NeRF Synthetic) [S1].
