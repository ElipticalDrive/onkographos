# NeRF-HuGS

Also called: Heuristics-Guided Segmentation

## Overview
NeRF-HuGS is a training procedure for Neural Radiance Fields (NeRF) that mitigates artifacts caused by transient distractors (e.g., moving objects, shadows) in non-static scenes. It solves the problem of distinguishing static geometry from transient elements by combining hand-crafted heuristics with the Segment Anything Model (SAM). Unlike prior segmentation-based methods that require semantic class priors or heuristic-only methods that miss low-frequency static details, HuGS fuses Structure-from-Motion (SfM) features (high-frequency textures) and color residuals from a partially trained NeRF (low-frequency textures) to guide SAM in generating precise static masks [S1].

## How it works
**Inputs:** A set of unordered multi-view images $I = \{I_i \mid i = 1, 2, \dots, N_I\}$ containing transient distractors.
**Outputs:** A set of static maps $M = \{M_i \mid i = 1, 2, \dots, N_I\}$, where $M_i$ is a binary mask for image $I_i$ labeling pixels of static objects as 1 and transient objects as 0. These maps are used as weights in the NeRF loss function.

**Data Structures:**
*   **Image Set $I$:** List of 2D images.
*   **Feature Points $F_i$:** For each image $I_i$, a set of 2D local feature points $F_i = \{ (x_{ij}, f_{ij}) \mid j = 1, \dots, N_{F_i} \}$, where $x_{ij} \in \mathbb{R}^2$ is the coordinate and $f_{ij}$ is the appearance descriptor [S1].
*   **Sparse Point Cloud $C$:** A 3D point cloud reconstructed from $F_i$ across all images, representing the static scene structure [S1].
*   **Static Map $M_i$:** A 2D mask of the same resolution as $I_i$.

**Parameters:**
*   **SfM Heuristics:** Effective for static objects with high-frequency texture patterns [S1].
*   **Residual Heuristics:** Derived from a partially trained NeRF (e.g., Nerfacto [46]) after several thousand iterations; effective for static elements with low-frequency textures [S1].
*   **Segmentation Model:** Segment Anything Model (SAM) [S1].

**Steps:**

1.  **Extract SfM Features:** For each image $I_i$, extract 2D local feature points $F_i$ using Structure-from-Motion (SfM) [S1].
2.  **Reconstruct Sparse Cloud:** Use $F_i$ from all images to reconstruct a sparse point cloud $C$ [S1].
3.  **Identify Static Features via SfM:** Identify static features as those reliably matched and triangulated across multiple views in the SfM pipeline. For each 2D feature point $(x_{ij}, f_{ij})$ in $I_i$, let $n_{ij}$ be the number of its matching points in the other images $I$ [S1]. Points with sufficient matches are considered static [S1].
4.  **Train Partial NeRF:** Train a NeRF model (specifically Nerfacto [46]) for several thousand iterations to obtain a partially trained model [S1].
5.  **Compute Color Residuals:** Use the partially trained NeRF to render images and compute color residuals against the input images $I$. High residuals indicate transient or poorly modeled regions [S1].
6.  **Generate Initial SAM Masks (SfM-guided):** Use the static feature points identified in Step 3 as point prompts for SAM to generate dense masks for each image [S1].
7.  **Fuse Heuristics:** Combine the SfM-based heuristics (from Step 3) and the Residual-based heuristics (from Step 5) to create a combined guidance signal [S1].
8.  **Generate Final Static Maps:** Use the combined heuristics to guide SAM again, generating the final static map $M_i$ for each input image $I_i$ [S1].
9.  **Train NeRF with Static Masks:** Train the final NeRF using the static maps $M_i$ as weights in the loss function to ignore transient pixels [S1].

**Formulas:**

The NeRF outputs color $c \in \mathbb{R}^3$ and density $\sigma \in \mathbb{R}$ for a 3D position $p \in \mathbb{R}^3$ and viewing direction $d \in S^2$:
$$ (c, \sigma) = \text{MLP}(p, d; \theta) \quad [S1] $$

The standard NeRF loss is:
$$ L(r) = L_{\text{recon}}(\hat{C}(r), C(r)) \quad [S1] $$
where $L_{\text{recon}}$ is a reconstruction loss (e.g., MSE or Charbonnier [5]), $\hat{C}(r)$ is the rendered color, and $C(r)$ is the ground truth color [S1].

The modified loss using the static map $M(r)$ (omitting image index $i$ for simplicity) is:
$$ L(r) = M(r) L_{\text{recon}}(\hat{C}(r), C(r)) \quad [S1] $$

**Pseudocode:**

```python
def nerf_hugs(images, num_iterations=10000):
    """
    images: List of 2D images I_i.
    num_iterations: Number of iterations for partial NeRF training.
    Returns: List of static masks M_i.
    """
    # Step 1 & 2: SfM Feature Extraction and Sparse Cloud Reconstruction
    # Extract 2D local feature points F_i for each image I_i
    feature_points = []
    for I_i in images:
        F_i = extract_sfm_features(I_i) # Returns list of (x_ij, f_ij)
        feature_points.append(F_i)
    
    # Reconstruct sparse point cloud C from all F_i
    sparse_cloud = reconstruct_sparse_cloud(feature_points)
    
    # Step 3: Identify Static Features
    # For each feature point, count matches across views
    static_feature_points = []
    for i, F_i in enumerate(feature_points):
        for x_ij, f_ij in F_i:
            # Count number of matching points in other images I
            n_ij = count_matches(x_ij, f_ij, feature_points, exclude_index=i)
            # If reliably matched (threshold not specified in source, assume high count implies static)
            if is_static_by_sfm(n_ij):
                static_feature_points.append((i, x_ij))
                
    # Step 4 & 5: Partial NeRF Training and Residuals
    # Train a partially trained Nerfacto model
    partial_nerf = train_nerfacto(images, iterations=num_iterations)
    
    # Compute color residuals
    residuals = []
    for I_i in images:
        # Render image using partial_nerf
        rendered_I_i = render_image(partial_nerf, camera_poses_for(I_i))
        # Compute residual (e.g., MSE or L1)
        residual_map = compute_residual(I_i, rendered_I_i)
        residuals.append(residual_map)
        
    # Step 6: Generate Initial SAM Masks using SfM points
    # Use static features from SfM as point prompts for SAM
    initial_masks = []
    for i, I_i in enumerate(images):
        # Get points for this image
        points_for_i = [p for idx, p in static_feature_points if idx == i]
        # Generate mask using SAM
        mask = sam_generate_mask(I_i, point_prompts=points_for_i)
        initial_masks.append(mask)
        
    # Step 7 & 8: Fuse Heuristics and Generate Final Static Maps
    final_masks = []
    for i, I_i in enumerate(images):
        # Combine SfM heuristics (initial_masks[i]) and Residual heuristics (residuals[i])
        # The source states "combine ... to guide SAM again"
        # Note: Exact fusion logic of heuristics is not detailed, but implies using both cues
        combined_guidance = fuse_heuristics(initial_masks[i], residuals[i])
        
        # Guide SAM again to generate final static map
        final_mask = sam_generate_mask(I_i, guidance=combined_guidance)
        final_masks.append(final_mask)
        
    return final_masks

def train_nerf_with_masks(images, masks, model):
    """
    Train NeRF using static masks as loss weights.
    """
    for epoch in range(total_epochs):

            # Sample rays

            # Render
            rendered_colors = render_rays(model, rays)
            
            # Compute loss with mask weighting
            # L(r) = M(r) * L_recon(C_hat(r), C(r))
            loss = 0
            for r, rendered_c, ground_c, mask_val in zip(rays, rendered_colors, ground_truth_colors, M_i):

                loss += mask_val * recon_loss

            model.backward(loss)
```

## Operating characteristics
*   **Time Complexity:** Requires two phases of NeRF optimization: a partial training phase (several thousand iterations) and the final training phase. SfM feature extraction and matching add preprocessing time. SAM inference adds per-image segmentation time.
*   **Memory Complexity:** Stores the sparse point cloud $C$, the partially trained NeRF weights, and the generated static masks $M_i$.
*   **Strengths:** Robustly captures the full spectrum of static scene elements by combining high-frequency (SfM) and low-frequency (residual) cues. Avoids the need for semantic class priors required by other segmentation methods.
*   **Limitations:** Relies on the quality of SfM reconstruction (may fail in textureless regions) and the accuracy of the partially trained NeRF residuals. Computationally more expensive than standard NeRF training due to the heuristic generation and SAM steps.
*   **When to use:** Non-static scenes with transient distractors where static geometry needs to be preserved.
*   **When not to use:** Static scenes (overhead of heuristic generation is unnecessary) or scenes with no transient distractors.

## Background
NeRF-HuGS was proposed to address the limitation of standard NeRF methods, which assume static scenes and suffer from artifacts when trained on data with transient distractors [S1]. The method was introduced in the paper "NeRF-HuGS: Improved Neural Radiance Fields in Non-static Scenes Using Heuristics-Guided Segmentation" [S1]. It builds on the use of SfM for camera pose estimation and scene initialization [S1] and leverages the Segment Anything Model (SAM) [16] for precise boundary delineation. It contrasts with RobustNeRF, which uses heuristics alone and may ignore high-frequency static details [S1].
