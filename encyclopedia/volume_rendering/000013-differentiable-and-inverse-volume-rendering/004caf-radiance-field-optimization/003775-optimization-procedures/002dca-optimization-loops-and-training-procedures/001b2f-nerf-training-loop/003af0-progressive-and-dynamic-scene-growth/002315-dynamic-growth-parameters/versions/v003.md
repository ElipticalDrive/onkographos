# Dynamic Growth Parameters

Also called: NeRF Growth Steps, Recursive NeRF Growth

## Overview
Dynamic Growth Parameters is an adaptive training strategy for Neural Radiance Fields that expands network capacity based on local scene complexity and prediction uncertainty [S1]. Unlike static architectures, it clusters high-uncertainty query points and grows parallel network branches to refine predictions in those regions, enabling coarse-to-fine representation without pre-defining the entire hierarchy [S1].

## How it works
**Inputs and Outputs:**
- Input: A set of 3D query points $X$, viewing directions $d$, and ground-truth colors [G].
- Output: A recursively structured neural field where each branch $F_{\Phi_i}$ takes a parent latent vector $y_{p_i}$ and viewing direction $d$, and predicts color $c_i$, density $\sigma_i$, uncertainty $\delta_i$, and a latent vector $y_i$ [S1].

**Data Structures:**
- **Network Branch:** A multi-layer perceptron (MLP) with input $(y_{p_i}, d)$ and output $(c_i, \sigma_i, \delta_i, y_i)$ [S1].
- **Cluster Centers:** $k$ centroids derived from k-means clustering of high-uncertainty points [S1].
- **Growth State:** Tracks the current recursion depth and the set of active branches [G].

**Algorithm Steps:**
1. **Initial Training:** Train the base branch for $I_1$ iterations [S1].
2. **Uncertainty Estimation:** Compute $\delta_i$ for all sampled points using the current network [G].
3. **Clustering:** Identify points where $\delta_i > \tau$ [S1]. Apply k-means with $k \in [2, 4]$ to these points, yielding $k$ cluster centers [S1].
4. **Network Growth:** Instantiate $k$ new child branches according to the cluster centers [S1].
5. **Recursive Training:** Jointly train the parent and new child branches [S1]. Points are routed to the child branch corresponding to their cluster center [S1].
6. **Early Termination:** During rendering, if $\delta_i$ is below a threshold, terminate recursion and use the current branch's output; otherwise, pass $y_i$ to the appropriate child branch [S1]. During training, sample points can exit at multiple stages, while during inference, points exit only once at a specific stage [S1].
7. **Iteration:** Repeat steps 2–6. The total number of growth steps is limited to 3 by default [S1].

**Parameters:**
- $k$: Number of branches per growth step. Default: $k=2$ [S1].
- Total Growth Steps: Maximum 3 [S1].
- Threshold $\tau$: Uncertainty threshold for clustering [S1]. Not given in the sources.

**Pseudocode:**

def dynamic_growth_training(points, directions, gt_colors, max_steps=3, k=2, threshold=0.5):
    # Each branch is an MLP: input (parent_latent, direction) -> (color, density, uncertainty, latent)
    branches = [Branch()]
    assignments = [0] * len(points)  # Index of branch assigned to each point

    for step in range(max_steps):
        # 1. Train all active branches on their assigned points
        for i, branch in enumerate(branches):
            branch.train(points, directions, gt_colors, assignments, i)

        # 2. Predict uncertainty for all points
        uncertainties = []
        for idx, p in enumerate(points):
            branch_idx = assignments[idx]
            _, _, delta, _ = branches[branch_idx].forward(p, directions[idx])
            uncertainties.append(delta)

        # 3. Identify high-uncertainty points
        high_unc_indices = [idx for idx, u in enumerate(uncertainties) if u > threshold]
        if not high_unc_indices:
            break

        high_unc_points = [points[idx] for idx in high_unc_indices]

        # 4. Cluster high-uncertainty points using k-means
        centers = kmeans(high_unc_points, k=k)

        # 5. Grow k new child branches
        new_branches = [Branch() for _ in range(k)]

        # 6. Assign high-uncertainty points to nearest cluster center
        for idx in high_unc_indices:
            best_j = min(range(k), key=lambda j: distance(points[idx], centers[j]))
            assignments[idx] = len(branches) + best_j

        # 7. Add new branches to the network
        branches.extend(new_branches)

    return branches

## Subtopics

### Dynamic Growth
An adaptive strategy that clusters uncertain queries at the current stage and grows deeper networks according to the clustering result [S1]. After $I_1$ iterations, points with uncertainty higher than a threshold are clustered using k-means with $k \in [2, 4]$ [S1]. The network grows $k$ branches according to the cluster centers [S1].

## Operating characteristics
- **Time Complexity:** Increases with each growth step due to additional network branches and clustering overhead [S1].
- **Memory Complexity:** Scales with the number of branches [S1].
- **Strengths:** Early termination speeds up rendering by avoiding unnecessary calculations when uncertainty is low enough [S1].
- **Limitations:** Requires tuning of uncertainty thresholds and clustering parameters [S1].
- **When to Use:** Scenes with varying levels of detail where uniform resolution is inefficient [G].
- **When Not to Use:** Simple scenes with uniform detail [G].

## Background
Originated in Recursive-NeRF, published in IEEE Transactions on Visualization and Computer Graphics in 2022 [S1]. The method addresses the inefficiency of static NeRF architectures by dynamically expanding network depth based on learned uncertainty, allowing for coarse-to-fine scene representation without manual hierarchy design [S1].
