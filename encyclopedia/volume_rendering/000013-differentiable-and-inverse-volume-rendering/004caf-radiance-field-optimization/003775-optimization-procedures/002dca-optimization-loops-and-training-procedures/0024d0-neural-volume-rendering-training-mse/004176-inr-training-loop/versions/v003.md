# INR Training Loop
## Overview
The INR Training Loop optimizes an Implicit Neural Representation (INR) to approximate a discrete volumetric dataset [S1, unofficial]. It learns a continuous function $f_\theta$ that maps 3D coordinates to scalar values by minimizing the mean squared error (MSE) between network predictions and ground-truth samples drawn uniformly from the volume domain [S1, unofficial].

## How it works
**Inputs:** Volume $V$ of size $N \times N \times N$; neural network $f_\theta$ with parameters $\theta$; encoding function $\gamma$; learning rate $\eta$; batch size $B$ [S1, unofficial].
**Outputs:** Trained network $f_\theta$ representing $V$ as a continuous function [S1, unofficial].
**Data Structures:** Coordinates: Set of $B$ tuples $\{(x_j, y_j, z_j)\}_{j=1}^B$; Encodings: Vector $e_j = \gamma(x_j, y_j, z_j)$; Predictions: Scalar $\hat{v}_j = f_\theta(e_j)$; Ground Truth: Scalar $v_j$ obtained via trilinear interpolation [S1, unofficial].
**Steps:**
1. Sample $B$ coordinates $\{(x_j, y_j, z_j)\}_{j=1}^B$ uniformly from the volume domain [S1, unofficial].
2. For each coordinate, compute encoding $e_j \leftarrow \gamma(x_j, y_j, z_j)$ [S1, unofficial].
3. Compute network output $\hat{v}_j \leftarrow f_\theta(e_j)$ [S1, unofficial].
4. Retrieve ground truth $v_j \leftarrow \text{trilinear}(V, x_j, y_j, z_j)$ [S1, unofficial].
5. Compute MSE loss $L \leftarrow \frac{1}{B} \sum_{j=1}^B (\hat{v}_j - v_j)^2$ [S1, unofficial].
6. Perform gradient update $\theta \leftarrow \theta - \eta \nabla_\theta L$ [S1, unofficial].

**Pseudocode:**
```python
import random

def train_inr(V, f_theta, gamma, eta, B, num_iterations):
    """
    V: 3D array of shape (N, N, N)
    f_theta: neural network function taking encoded coordinates
    gamma: encoding function
    eta: learning rate
    B: batch size
    num_iterations: number of training steps
    """
    N = V.shape[0]
    for _ in range(num_iterations):
        # 1. Sample B coordinates uniformly from the volume domain [0, N-1]
        coords = [(random.uniform(0, N - 1), random.uniform(0, N - 1), random.uniform(0, N - 1)) for _ in range(B)]
        losses = []
        for (x, y, z) in coords:
            # 2. Encode
            e = gamma(x, y, z)
            # 3. Predict
            v_hat = f_theta(e)
            # 4. Ground Truth via trilinear interpolation
            v = trilinear(V, x, y, z)
            # 5. Accumulate squared error
            losses.append((v_hat - v) ** 2)
        # 6. Compute MSE loss
        L = sum(losses) / B
        # 7. Gradient update
        # Automatic differentiation computes ∇_θ L [G]
        grad = compute_gradients(f_theta, L)
        for param in f_theta.parameters:
            param -= eta * grad[param]
    return f_theta

def trilinear(V, x, y, z):
    # Standard trilinear interpolation for continuous coordinates in [0, N-1]
    # Clamps coordinates to volume bounds to prevent out-of-bounds access [G]
    x = max(0, min(V.shape[0] - 1, x))
    y = max(0, min(V.shape[1] - 1, y))
    z = max(0, min(V.shape[2] - 1, z))
    # Extract grid points and interpolation weights
    x0, y0, z0 = int(x), int(y), int(z)
    x1, y1, z1 = x0 + 1, y0 + 1, z0 + 1
    dx, dy, dz = x - x0, y - y0, z - z0
    # Fetch values with boundary checks
    def val(ix, iy, iz):
        ix = max(0, min(V.shape[0] - 1, ix))
        iy = max(0, min(V.shape[1] - 1, iy))
        iz = max(0, min(V.shape[2] - 1, iz))
        return V[ix, iy, iz]
    # Trilinear interpolation formula
    c00 = val(x0, y0, z0) * (1 - dx) + val(x1, y0, z0) * dx
    c01 = val(x0, y0, z1) * (1 - dx) + val(x1, y0, z1) * dx
    c10 = val(x0, y1, z0) * (1 - dx) + val(x1, y1, z0) * dx
    c11 = val(x0, y1, z1) * (1 - dx) + val(x1, y1, z1) * dx
    c0 = c00 * (1 - dy) + c10 * dy
    c1 = c01 * (1 - dy) + c11 * dy
    return c0 * (1 - dz) + c1 * dz
```

**Edge Cases:**
*   **Boundary Conditions:** Trilinear interpolation requires coordinates to be within the volume bounds; coordinates sampled uniformly over a continuous domain may fall outside discrete indices and require clamping [G].
*   **Precision:** Trilinear interpolation introduces smoothing artifacts compared to nearest-neighbor sampling, which may affect high-frequency reconstruction [G].

## Subtopics

### [Meta-INR](10630-meta-inr.md)
A pretraining strategy using meta-learning to optimize initial network parameters from a sparse, spatiotemporally subsampled volumetric dataset, enabling rapid adaptation to unseen similar volumes via few gradient steps. It differs from standard INR training by optimizing a shared initialization that serves as a strong prior for generalizability, rather than training each volume independently from scratch. This approach significantly reduces the computational overhead of encoding new volumes in time-varying or ensemble datasets, achieving encoding speeds approximately 5.87× faster than training from scratch while maintaining higher reconstruction quality.
