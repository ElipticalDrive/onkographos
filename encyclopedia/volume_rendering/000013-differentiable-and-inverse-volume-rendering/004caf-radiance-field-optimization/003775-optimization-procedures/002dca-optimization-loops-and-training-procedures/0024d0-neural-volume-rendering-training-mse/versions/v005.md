# Neural Volume Rendering Training (MSE)

Also called: Standard Neural Volume Rendering Training, Photometric MSE Training

## Overview
Neural Volume Rendering Training (MSE) is the foundational optimization procedure for training implicit neural radiance fields (NeRFs) by minimizing the Mean Squared Error (MSE) between rendered and ground-truth images. It solves the inverse problem of recovering a continuous volumetric scene representation from discrete 2D observations. It sets itself apart from sibling methods by relying exclusively on a simple pixel-wise L2 loss without additional geometric priors (like Eikonal regularization) or complex scheduling strategies, serving as the baseline for more advanced techniques [S1, S2].

## How it works
**Inputs and Outputs:**
- **Inputs:** A set of $N$ training images $\{I_i\}_{i=1}^N$, each with known camera poses $P_i$ and intrinsics. A neural network $\mathcal{N}_\theta$ parameterized by weights $\theta$ that maps 3D coordinates $\mathbf{x}$ and viewing directions $\mathbf{d}$ to color $\mathbf{c}$ and volume density $\sigma$.
- **Outputs:** Optimized network parameters $\theta^*$.

**Data Structures:**
- **Ray Batch:** A tensor of shape $(B, 3)$ for origins $\mathbf{o}$ and $(B, 3)$ for directions $\mathbf{d}$, where $B$ is the batch size.
- **Sample Points:** For each ray, $K$ points are sampled along the ray segment $[t_n, t_f]$. These points are stored as a tensor of shape $(B, K, 3)$.
- **Network Output:** For each sample point, the network outputs a 4D vector: density $\sigma \in \mathbb{R}$ and color $\mathbf{c} \in \mathbb{R}^3$.

**Numbered Steps:**
1. **Ray Sampling:** For each training image, generate a ray for each pixel (or a random subset for efficiency). Sample $K$ points along each ray using uniform or stratified sampling within the near/far planes.
2. **Forward Pass:** Query the neural network $\mathcal{N}_\theta$ at each sample point $\mathbf{x}_k$ with direction $\mathbf{d}$ to obtain $\sigma_k$ and $\mathbf{c}_k$.
3. **Volume Rendering:** Compute the expected color $\hat{C}(\mathbf{r})$ for each ray $\mathbf{r}$ using the differentiable volume rendering integral:
   $$ \hat{C}(\mathbf{r}) = \sum_{k=1}^{K} T_k \left( 1 - \exp(-\sigma_k \delta_k) \right) \mathbf{c}_k $$
   where $\delta_k$ is the distance between adjacent samples, and $T_k = \exp\left(-\sum_{j=1}^{k-1} \sigma_j \delta_j\right)$ is the accumulated transmittance.
4. **Loss Computation:** Calculate the MSE loss between the rendered color $\hat{C}(\mathbf{r})$ and the ground-truth pixel color $C(\mathbf{r})$:
   $$ \mathcal{L} = \frac{1}{N} \sum_{i=1}^{N} \| \hat{C}(\mathbf{r}_i) - C(\mathbf{r}_i) \|^2 $$
5. **Backpropagation:** Compute gradients $\nabla_\theta \mathcal{L}$ using reverse-mode automatic differentiation.
6. **Update:** Update parameters $\theta$ using an optimizer (typically Adam).

**Parameters:**
- **Number of Samples ($K$):** Typically 128–256 per ray [S1].
- **Learning Rate:** Typically $10^{-4}$ to $5 \times 10^{-4}$ [S2].
- **Batch Size:** Often 1–4 rays per iteration to manage memory [S1].

**Edge Cases and Pitfalls:**
- **Precision:** Use float32 for stability; float64 may be needed for very large scenes but increases memory [G].
- **Boundaries:** Ensure near/far planes tightly bound the scene to avoid sampling empty space, which wastes computation and can cause gradient vanishing [G].
- **Degenerate Input:** If training images have inconsistent exposure or white balance, MSE loss may converge to a blurry average; preprocessing is required [G].

**Pseudocode:**
```python
import torch
import torch.nn as nn

class NeuralVolumeRenderer(nn.Module):
    def __init__(self, net):
        super().__init__()
        self.net = net  # Neural network taking (x, d) -> (sigma, color)

    def forward(self, origins, directions, near, far, num_samples):
        """
        Renders images for a batch of rays.
        origins: (B, 3)
        directions: (B, 3)
        near: (B,)
        far: (B,)
        num_samples: int
        """
        # 1. Sample points along rays
        t_vals = torch.linspace(0., 1., num_samples, device=origins.device)
        t_vals = t_vals.unsqueeze(0).expand(origins.shape[0], -1)
        # Stratified sampling can be added here by jittering t_vals
        t_samples = near.unsqueeze(1) + t_vals * (far.unsqueeze(1) - near.unsqueeze(1))
        
        # Interpolate 3D points
        points = origins.unsqueeze(1) + directions.unsqueeze(1) * t_samples.unsqueeze(2)
        points = points.reshape(-1, 3)
        
        # 2. Query network
        # Repeat directions for each sample
        dirs = directions.unsqueeze(1).expand(-1, num_samples, -1).reshape(-1, 3)
        sigma, color = self.net(points, dirs)
        
        # 3. Volume Rendering
        deltas = t_samples[:, 1:] - t_samples[:, :-1]
        delta_inf = 1e10 * torch.ones_like(deltas[:, :1])
        deltas = torch.cat([deltas, delta_inf], dim=1)
        
        # Alpha values
        alpha = 1.0 - torch.exp(-sigma * deltas)
        transmittance = torch.cumprod(torch.exp(-sigma * deltas), dim=1)
        transmittance = torch.cat([torch.ones_like(transmittance[:, :1]), transmittance[:, :-1]], dim=1)
        
        # Weighted sum
        weights = alpha * transmittance
        rendered_color = torch.sum(weights.unsqueeze(2) * color.reshape(-1, num_samples, 3), dim=1)
        
        return rendered_color

def train_step(model, optimizer, batch):
    """
    Single training step.
    batch: dict with 'origins', 'directions', 'near', 'far', 'gt_colors'
    """
    optimizer.zero_grad()
    
    # Forward pass
    pred_colors = model(batch['origins'], batch['directions'], 
                        batch['near'], batch['far'], 
                        model.num_samples)
    
    # Loss computation
    gt_colors = batch['gt_colors']
    loss = torch.mean((pred_colors - gt_colors) ** 2)
    
    # Backpropagation
    loss.backward()
    
    # Update
    optimizer.step()
    
    return loss.item()
```

## Operating characteristics
- **Time Complexity:** $O(N \cdot K \cdot D)$ per iteration, where $N$ is batch size, $K$ is samples per ray, and $D$ is network depth [S1].
- **Memory Complexity:** $O(N \cdot K)$ to store intermediate gradients and activations [S1].
- **Performance:** Converges slowly compared to methods with adaptive sampling or hierarchical structures. Requires many iterations (100k+) for high quality [S2].
- **Strengths:** Simple to implement; robust to noise in ground truth due to L2 norm properties [G].
- **Limitations:** Prone to overfitting to training views; struggles with high-frequency details without sufficient sampling [S1].
- **When to Use:** Baseline training; scenes with smooth geometry and lighting.
- **When Not to Use:** Scenes with high-frequency details or sparse views; use hierarchical or sparse variants instead.

## Background
Originated with the seminal NeRF paper by Mildenhall et al. (2020) [S1]. It established the standard pipeline for differentiable volume rendering. The MSE loss was chosen for its differentiability and simplicity, though it is known to produce blurry results compared to perceptual losses [S2].
