# Neural Volume Rendering Training (MSE)

Also called: Hierarchical Geometric Guidance (HGG)

## Overview
This method defines the core optimization loop for training Neural Radiance Fields (NeRF) and similar implicit neural representations by minimizing the Mean Squared Error (MSE) between rendered images and ground truth observations [S1, unofficial]. It addresses the problem of converging to geometrically accurate and photometrically correct scene representations from sparse or noisy input data. It is distinguished from its siblings by its foundational reliance on the standard differentiable volume rendering equation and explicit strategies to mitigate depth-supervision bias, such as Hierarchical Geometric Guidance (HGG) and Hierarchical Photometric Guidance (HPG) [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $M$ calibrated images $\{I_m\}_{m=1}^M$ with known camera poses; optionally, sparse depth priors $\{D_m\}_{m=1}^M$ from Structure-from-Motion (SfM) [S1, unofficial].
*   **Outputs:** Optimized neural network parameters $\Theta$ (defining density $\sigma$ and color $\mathbf{c}$) [S1, unofficial].

**Data Structures:**
*   **Neural Network $f_\Theta$:** A multi-layer perceptron (MLP) taking a 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$ as input, outputting density $\sigma$ and color $\mathbf{c}$ [S1, unofficial].
*   **Sampling Points:** A set of 3D points $\mathbf{x}_i$ sampled along rays $\mathbf{r}$ within near $t_n$ and far $t_f$ planes [S1, unofficial].
*   **Ray Set $R$:** The collection of all rays cast from camera centers through pixel centers across all training images [S1, unofficial].

**Numbered Steps:**

1.  **Ray Casting and Sampling:** For each training image, cast a ray $\mathbf{r}$ through each pixel. Sample $N$ points $\{t_i\}_{i=1}^N$ along the ray within the interval $[t_n, t_f]$ [S1, unofficial].
    *   *Note:* In Hierarchical Photometric Guidance (HPG), two sets of samples are used: coarse stratified samples $t_c$ and fine samples $t_f$ generated via inverse transform sampling based on coarse densities [S1, unofficial].

2.  **Neural Query:** Query the network $f_\Theta$ at each sample point $t_i$ to obtain density $\sigma_i$ and color $\mathbf{c}_i$ [S1, unofficial].

3.  **Volume Rendering (Forward Pass):** Compute the predicted color $\hat{C}(\mathbf{r})$ using the standard emission-absorption model [44-radiance-field-optimization.md]:
    $$
    \hat{C}(\mathbf{r}) = \sum_{i=1}^N T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i
    $$
    where $\delta_i = t_{i+1} - t_i$ is the step size, and $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$ is the accumulated transmittance [S1, 44-radiance-field-optimization.md, unofficial].
    *   *For HPG:* Compute $\hat{C}_{crecon}$ using $t_c$ and $\hat{C}_{frecon}$ using $t_c \cup t_f$ [S1, unofficial].

4.  **Loss Computation:**
    *   **Standard MSE:** Compute the pixel-wise MSE loss between the predicted color $\hat{C}(\mathbf{r})$ and the ground truth color $C_{gt}(\mathbf{r})$ [S1, unofficial].
    *   **Hierarchical Photometric Guidance (HPG):** Compute the combined loss for coarse and fine models [S1, unofficial]:
        $$
        L_{hpg} = \frac{1}{2} \sum_{r \in R} \left( C_{gt}(r) - \hat{C}_{crecon}(r; t_c) \right)^2 + \left( C_{gt}(r) - \hat{C}_{frecon}(r; t_c \cup t_f) \right)^2
        $$
        where $R$ is the set of all rays [S1, unofficial].

5.  **Backpropagation and Update:** Compute gradients $\nabla_\Theta L$ with respect to the network parameters $\Theta$ and update them using an optimizer (typically Adam) [S1, unofficial].

**Parameters:**
*   **$N_{hgg}$:** Number of iterations for Hierarchical Geometric Guidance to extend sampling bounds. Typical value: 10% of total training iterations [S1, unofficial].
*   **$\epsilon_{hgg}$:** Minimum adjusting rate for the region expansion. Typical value: 0.2 [S1, unofficial].
*   **Learning Rate:** Initial learning rate $1 \times 10^{-3}$, exponentially decaying to $1 \times 10^{-5}$ [S1, unofficial].
*   **Samples per Ray:** 64 for coarse model, 128 for fine model (in HPG variants) [S1, unofficial].

**Pseudocode:**

```python
def train_neural_volume_rendering_mse(
    images, cameras, depth_priors=None, 
    network, optimizer, total_iterations, 
    use_hpg=False, use_hgg=False
):
    """
    Trains a neural volume rendering model using MSE loss.
    
    Args:
        images: List of ground truth RGB images.
        cameras: List of camera poses and intrinsics.
        depth_priors: Optional sparse depth maps from SfM.
        network: Neural network f_theta (MLP).
        optimizer: Optimizer (e.g., Adam).
        total_iterations: Total number of training steps.
        use_hpg: Boolean flag to use Hierarchical Photometric Guidance.
        use_hgg: Boolean flag to use Hierarchical Geometric Guidance.
    """
    
    # Initialize network parameters
    params = network.parameters()
    
    for i in range(total_iterations):
        # 1. Sample a batch of rays
        # Select random pixels from random images in the batch
        batch_rays = sample_rays(images, cameras)
        
        # 2. Determine sampling bounds [t_n, t_f]
        if use_hgg and depth_priors is not None:
            # Hierarchical Geometric Guidance: Expand bounds from depth prior
            # Calculate region adjustment rate gamma(i)
            # epsilon_hgg = 0.2 (typical value)
            # N_hgg = 0.1 * total_iterations (typical value)
            ratio = min(max(i / (0.1 * total_iterations), 0.2), 1.0)
            gamma = (1 - cos(ratio * pi)) / 2
            
            # Get initial depth prior t_depth for the ray
            t_depth = get_depth_prior(depth_priors, batch_rays)
            
            # Initial bounds t_n_init, t_f_init are set close to t_depth
            # Extend to full bounds using gamma
            t_n = t_depth + (t_n_init - t_depth) * gamma
            t_f = t_depth + (t_f_init - t_depth) * gamma
        else:
            # Standard bounds (e.g., fixed scene bounds or default near/far)
            t_n, t_f = get_default_bounds(batch_rays)
            
        # 3. Sample points along rays
        if use_hpg:
            # Hierarchical Photometric Guidance: Coarse and Fine sampling
            # Coarse: Stratified sampling
            t_c = stratified_sample(t_n, t_f, num_samples=64)
            # Fine: Inverse transform sampling based on coarse densities
            # Query coarse network for sigma_c
            sigma_c = network.query(batch_rays, t_c)
            # Generate fine samples t_f using inverse transform sampling
            t_f_samples = inverse_transform_sampling(t_c, sigma_c, num_samples=128)
            # Union of samples
            all_samples = union(t_c, t_f_samples)
        else:
            # Standard sampling (e.g., uniform or stratified)
            all_samples = stratified_sample(t_n, t_f, num_samples=128)
            
        # 4. Query network for density and color
        # Positions x are derived from ray origins and t values
        positions = batch_rays.origins + batch_rays.directions * all_samples
        directions = batch_rays.directions
        
        if use_hpg:
            # Query coarse model for coarse prediction
            sigma_c, color_c = network_coarse(positions, directions)
            # Query fine model for fine prediction
            sigma_f, color_f = network_fine(positions, directions)
        else:
            sigma, color = network(positions, directions)
            
        # 5. Render images
        if use_hpg:
            # Render coarse image
            C_c = volume_render(batch_rays, all_samples, sigma_c, color_c)
            # Render fine image
            C_f = volume_render(batch_rays, all_samples, sigma_f, color_f)
            
            # 6. Compute Loss (HPG)
            # L_hpg = 0.5 * MSE(C_gt, C_c) + 0.5 * MSE(C_gt, C_f)
            loss = 0.5 * mse_loss(images, C_c) + 0.5 * mse_loss(images, C_f)
        else:
            # Render standard image
            C_pred = volume_render(batch_rays, all_samples, sigma, color)
            
            # 6. Compute Loss (Standard MSE)
            loss = mse_loss(images, C_pred)
            
        # 7. Backpropagate and update
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
```

**Edge Cases and Pitfalls:**
*   **Depth Supervision Bias:** Directly supervising the reconstructed depth $\hat{D}_{recon}$ with sparse SfM depth priors introduces bias $\Delta P$ due to keypoint mismatching ($\Delta d$) and small translations between frames, causing geometric misalignment [S1, unofficial]. HGG avoids this by using depth only for sampling region initialization, not direct supervision [S1, unofficial].
*   **Precision:** The transmittance calculation $T_i$ involves exponentials of accumulated densities. Underflow or overflow can occur if densities are not properly bounded or if step sizes $\delta_i$ are extremely small/large [44-radiance-field-optimization.md].
*   **Degenerate Input:** If depth priors are missing or highly inaccurate, HGG initialization may fail to converge to the correct scene bounds, leading to poor reconstruction [S1, unofficial].

## Subtopics

### [Neural Surface Rendering Training (Eikonal & Boundary Regularization)](3430-neural-surface-rendering-training-eikonal-boundary-regulariz.md)
This method trains a neural Signed Distance Function (SDF) to render images that match ground truth RGB while enforcing geometric priors via Eikonal and boundary regularization losses. It differs from standard neural volume rendering training (MSE) by explicitly optimizing the gradient magnitude of the SDF to be unity (Eikonal equation) and penalizing non-zero SDF values in the volume (boundary loss), which stabilizes surface extraction and improves geometric accuracy.

### [Global Optimization](5436-global-optimization.md)
Global Optimization reconstructs a complete image or volume from sparse measurements by solving for all pixels/voxels simultaneously across the entire domain. It differs from local or block-based solvers by optimizing the full domain at once, improving reconstruction quality at the cost of higher memory and per-iteration computational cost. It is applied in compressive rendering and tomographic reconstruction.

### [Neural Volume Rendering Training Setup](6559-neural-volume-rendering-training-setup.md)
This article details the specific hyperparameters, data preprocessing, and hardware configurations required to train neural volume rendering models, focusing on the implicit neural representation (INR) approach for medical volume data. It establishes the baseline training loop for reconstructing high-resolution volumes from downsampled inputs using an L1 loss and Adam optimizer. A minor variant, Mobile-GS, adapts this setup for 3D Gaussian Splatting with distillation and quantization.

### [Handpainted Reference Image Inversion](6686-handpainted-reference-image-inversion.md)
Handpainted Reference Image Inversion is a training task where a volume rendering model learns to reproduce a user-edited 2D reference image from a 3D volume, demonstrating the ability to learn complex classification features that are difficult to define with traditional multidimensional transfer functions. It solves the problem of tedious trial-and-error transfer function adjustments by allowing the model to automatically learn the parameters required to replicate a user-provided visual effect. Unlike base 3D Gaussian Splatting which bakes the scene appearance, this method enables editing of lighting and appearance via optimization, achieving perceptual fidelity even from poor viewpoint reference images. It sets itself apart from sibling methods like Global Optimization by focusing on semantic colorization tasks derived from hand-painted edits rather than pure photometric reconstruction or geometric regularization.

### [Coarse-to-fine Sparse Volume Training](6838-coarse-to-fine-sparse-volume-training.md)
This method defines the training and optimization pipeline for sparse neural radiance fields, specifically focusing on the fine-tuning stage that refines a pre-constructed sparse volume $V^g$ per scene. It solves the problem of achieving high-fidelity novel view synthesis with significantly reduced training time compared to dense per-scene optimization methods like NeRF. It is distinguished from its siblings by its reliance on a coarse-to-fine iterative pruning and subdivision strategy during optimization, rather than static initialization or global optimization over the entire dataset. It builds on [Neural Volume Rendering Training (MSE)](3429-neural-volume-rendering-training-mse.md).

### [INR Training Loop](10522-inr-training-loop.md)
The INR Training Loop is the fundamental optimization procedure for fitting an Implicit Neural Representation (INR) to a discrete volumetric dataset. It solves the problem of learning a continuous function $f_\theta$ that approximates a 3D volume $V$ by minimizing the mean squared error (MSE) between network predictions and ground-truth samples. It differs from [Neural Surface Rendering Training (Eikonal & Boundary Regularization)](3430-neural-surface-rendering-training-eikonal-boundary-regulariz.md) by focusing on volumetric density/attenuation rather than surface geometry, and from [Global Optimization](5436-global-optimization.md) by using stochastic gradient descent on random batches rather than full-volume or global constraints.

### Inverse Rendering for Texture/Attribute Refinement
This variant uses inverse rendering to optimize texture field (TexF) attributes by propagating image-space supervision through a differentiable rendering process [S2, unofficial]. It computes a photometric loss between UV reference images and TexF renderings to guide voxel attribute refinement [S2, unofficial]. The optimization target is to reduce transfer and discretization errors during representation construction and refine the compressed neural field [S2, unofficial].

### Hierarchical Photometric Guidance
This variant trains a coarse model and a fine model to improve novel view synthesis performance by combining their predicted colors in the loss function [S1, unofficial]. It queries the coarse model with stratified volume samples $t_c$ to get $\hat{C}_{crecon}$, and the fine model with the union of coarse and fine samples $t_c \cup t_f$ to get $\hat{C}_{frecon}$ [S1, unofficial]. The loss is the sum of MSE errors for both predictions against ground truth [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M \cdot K)$ per iteration, where $N$ is the number of pixels, $M$ is the number of rays per pixel (if multi-sample), and $K$ is the number of samples per ray [44-radiance-field-optimization.md]. With HPG, this doubles due to coarse and fine models [S1, unofficial].
*   **Memory Complexity:** $O(N \cdot K)$ to store intermediate transmittance and density values for backpropagation if using reverse-mode AD [44-radiance-field-optimization.md]. Adjoint methods or analytic inversion can reduce this to $O(N)$ [44-radiance-field-optimization.md].
*   **Measured Performance:** On the DTU dataset, HG3-NeRF (using HGG and HPG) synthesizes images with more fine details and distinct depth edges compared to baselines [S1, unofficial].
*   **Strengths:** Simple to implement; effective for dense input data; HPG improves detail reconstruction; HGG mitigates depth bias from sparse priors [S1, unofficial].
*   **Limitations:** High memory usage with standard AD; sensitive to sampling strategies; HGG requires accurate initial depth priors [S1, unofficial].
*   **When to Use:** Standard training for NeRF-like models; when sparse depth priors are available but direct supervision is risky [S1, unofficial].
*   **When Not to Use:** When geometric accuracy is paramount and surface-based representations are preferred (use Eikonal regularization instead) [3430-neural-surface-rendering-training-eikonal-boundary-regulariz.md]; when global consistency is required over local optimization [5436-global-optimization.md].

## Background
The method originates from the foundational NeRF paper [44-radiance-field-optimization.md] and subsequent works like HG3-NeRF [S1, unofficial]. It is widely used in novel view synthesis, 3D reconstruction, and inverse rendering tasks [S1, S2, unofficial]. The HGG and HPG variants were introduced to address specific challenges in sparse-view inputs and hierarchical optimization [S1, unofficial].
