# ADMM Solver

Also called: Alternating Direction Method of Multipliers, Standard ADMM

## Overview
The ADMM Solver is an optimization method for solving separable minimization problems of the form $\min_x f(x) + g(x)$ by splitting the objective into a data term $f(x)$ and a prior term $g(x)$ [S1, unofficial]. It differs from direct solvers by decoupling these terms into alternating subproblems, allowing specialized solvers for each component, and differs from primal-dual methods by explicitly maintaining a dual variable $u$ to enforce consensus between the split variables [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Objective functions $f(x)$ and $g(x)$; linear operator $D$ (identity $I$ for standard form); penalty parameter $\rho > 0$; initial guesses $x^0, z^0, u^0$ [S1, unofficial].
- Output: Optimal variable $x$ [S1, unofficial].

**Data Structures:**
- Vectors $x, z, u \in \mathbb{R}^n$ [S1, unofficial].
- Scalar $\rho$ [S1, unofficial].
- Integer iteration counter $k$ [S1, unofficial].

**Steps:**
1. **Initialize:** Set $k=0$. Initialize $x^0, z^0, u^0$ [S1, unofficial].
2. **Check Convergence:** If convergence criteria met, return $x^k$ [G].
3. **Update $x$:** Solve for $x^{k+1}$ by minimizing the augmented Lagrangian with respect to $x$:
   $$x^{k+1} = \operatorname{argmin}_x f(x) + \frac{\rho}{2} \|Dx - z^k + u^k\|^2$$
   [S1, unofficial] For $D=I$, this simplifies to the proximal operator: $x^{k+1} = \text{prox}_{\rho f}(x^k - u^k)$ [S1, unofficial].
4. **Update $z$:** Solve for $z^{k+1}$ by minimizing the augmented Lagrangian with respect to $z$:
   $$z^{k+1} = \operatorname{argmin}_z g(z) + \frac{\rho}{2} \|Dx^{k+1} - z + u^k\|^2$$
   [S1, unofficial] For $D=I$, this simplifies to the proximal operator: $z^{k+1} = \text{prox}_{\rho g}(x^{k+1} + u^k)$ [S1, unofficial].
5. **Update Dual:** Update the scaled dual variable $u$:
   $$u^{k+1} = u^k + Dx^{k+1} - z^{k+1}$$
   [S1, unofficial] When $D=I$, this becomes $u^{k+1} = x^k + x^{k+1} - z^{k+1}$ [S1, unofficial].
6. **Increment:** Set $k \leftarrow k+1$ and return to Step 2 [G].

**Formulas:**
- **Augmented Lagrangian:** $L(x, z, u) = f(x) + g(z) + \frac{\rho}{2} \|Dx - z + u\|^2$ [S1, unofficial].
- **Proximal Operator:** $\text{prox}_{\lambda h}(y) = \operatorname{argmin}_x h(x) + \frac{1}{2\lambda} \|x - y\|^2$ [S1, unofficial].
- **Standard ADMM (when $D=I$):**
  $$x^{k+1} = \text{prox}_{\rho f}(x^k - u^k)$$
  $$z^{k+1} = \text{prox}_{\rho g}(x^{k+1} + u^k)$$
  $$u^{k+1} = x^k + x^{k+1} - z^{k+1}$$
  [S1, unofficial]

**Parameters:**
- $\rho$: Penalty parameter. Typical values are not given in the sources [S1, unofficial].
- $\lambda$: Used in the standard form definition, effectively equivalent to $\rho$ in the scaled form [S1, unofficial].

**Edge Cases and Pitfalls:**
- Precision issues may arise if $\rho$ is too large or too small, affecting convergence speed [G].
- The $x$-update may require iterative solvers like Conjugate Gradient (CG) when $D$ is not easily invertible, as implemented in the Reconstruction ToolKit (RTK) [S1, unofficial].

**Pseudocode:**
```python
def admm_solver(f, g, D, rho, x0, z0, u0, max_iter=1000, tol=1e-6):
    """
    Solves min_x f(x) + g(Dx) using ADMM.
    """
    x = x0.copy()
    z = z0.copy()
    u = u0.copy()
    
    for k in range(max_iter):
        # Update x: argmin_x f(x) + (rho/2) * ||Dx - z + u||^2
        if D_is_identity(D):
            x_new = prox_f_scaled(x - u, rho)
        else:
            # Solve quadratic subproblem; typically via Conjugate Gradient [S1, unofficial]
            x_new = solve_x_subproblem(f, D, rho, z, u)
                
        # Update z: argmin_z g(z) + (rho/2) * ||Dx_new - z + u||^2
        z_new = prox_g_scaled(D(x_new) + u, rho)
                
        # Update dual: u^{k+1} = u^k + Dx^{k+1} - z^{k+1}
        u_new = u + D(x_new) - z_new
            
        # Check convergence
        if vector_norm(x_new - x) < tol and vector_norm(z_new - z) < tol and vector_norm(u_new - u) < tol:
            return x_new
                
        x = x_new
        z = z_new
        u = u_new
            
    return x

def prox_f_scaled(y, rho):
    """Computes prox_{rho f}(y) = argmin_x f(x) + (rho/2)||x - y||^2."""
    return prox_f(y, rho)

def prox_g_scaled(y, rho):
    """Computes prox_{rho g}(y) = argmin_z g(z) + (rho/2)||z - y||^2."""
    return prox_g(y, rho)

def prox_f(y, lambda_val):
    """Standard proximal operator for f: argmin_x f(x) + 1/(2*lambda)||x - y||^2 [S1, unofficial]."""

def prox_g(y, lambda_val):
    """Standard proximal operator for g: argmin_z g(z) + 1/(2*lambda)||z - y||^2 [S1, unofficial]."""
    # Example for L1 norm g(x)=||x||_1: soft thresholding [G]
    return soft_threshold(y, lambda_val)

def soft_threshold(y, threshold):
    return sign(y) * max(abs(y) - threshold, 0)

def D_is_identity(D):
    return D is None or D == 'I'
```

## Subtopics

### [L1 Shearlet Regularized CT Reconstruction (ADMM)](10811-l1-shearlet-regularized-ct-reconstruction-admm.md)
This method solves the L1 shearlet regularized Computed Tomography (CT) reconstruction problem using the Alternating Direction Method of Multipliers (ADMM). It is designed to produce high-quality reconstructions from limited-angle or sparse sinogram data by enforcing sparsity in the shearlet domain while maintaining data consistency. It differs from standard Filtered Backprojection (FBP) by incorporating a non-linear prior that preserves edges and reduces artifacts, and it differs from other ADMM solvers by specifically structuring the proximal operators for shearlet sparsity and non-negativity constraints.

## Operating characteristics
- **Time Complexity:** Depends on the cost of evaluating $f$, $g$, and their proximal operators, and the number of iterations to convergence [G]. Each iteration involves one evaluation of $D$ and its transpose (if needed for the $x$-update) [G].
- **Memory Complexity:** $O(n)$ for storing $x, z, u$ and intermediate vectors [G].
- **Measured Performance:** Implemented in the Reconstruction ToolKit (RTK) as an ADMM total variation-regularized solver with conjugate gradient (CG) method [S1, unofficial].
- **Scaling:** Scales well with problem size if subproblems can be solved efficiently [G].
- **Strengths:** Handles non-smooth priors (like L1) effectively; decouples complex objectives [G].
- **Limitations:** Convergence can be slow for ill-conditioned problems; requires careful tuning of $\rho$ [G].
- **When to use:** When the objective function is separable into a data term and a prior term, and proximal operators are available or easy to compute [G].
- **When not to use:** When the problem is not separable or proximal operators are expensive to compute [G].

## Background
The ADMM method is a proximal algorithm used for volume reconstruction, particularly in Computed Tomography (CT) [S1, unofficial]. It is implemented in the Reconstruction ToolKit (RTK), a high-performance toolkit for 3D cone beam reconstruction based on ITK [S1, unofficial]. The method is part of a broader class of proximal algorithms for solving inverse problems [S1, unofficial].
