# ADMM Solver

Also called: Alternating Direction Method of Multipliers, Standard ADMM

## Overview
The ADMM Solver is an optimization method for solving separable minimization problems of the form $\min_x f(x) + g(x)$, where $f(x)$ is a data fidelity term and $g(x)$ is a regularization prior [S1, unofficial]. It sets itself apart from direct solvers by decomposing complex objectives into simpler subproblems that can be solved via proximal operators, making it particularly suitable for volume reconstruction with total variation or $L_1$ regularization [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Objective functions $f(x)$ and $g(x)$, operator $D$ (identity $I$ for standard form), penalty parameter $\rho$, initial variables $x^0, z^0, u^0$.
- Output: Reconstructed volume $x$.

**Data Structures:**
- Vectors $x, z, u \in \mathbb{R}^n$ representing the primal and dual variables.
- Matrix $A$ (for data term) and $D$ (for prior term).
- Scalar $\rho > 0$ (penalty parameter).

**Numbered Steps:**
1. Initialize $x^0, z^0, u^0$.
2. For iteration $k = 0, 1, \dots$:
   a. **x-update**: Solve $x^{k+1} = \operatorname{argmin}_x f(x) + \frac{\rho}{2} \|Dx - z^k + u^k\|^2$.
   b. **z-update**: Solve $z^{k+1} = \operatorname{argmin}_z g(z) + \frac{\rho}{2} \|Dx^{k+1} - z + u^k\|^2$.
   c. **u-update**: Update dual variable $u^{k+1} = u^k + Dx^{k+1} - z^{k+1}$.
3. Return $x^{k+1}$.

**Formulas:**
The scaled augmented Lagrangian is:
$$L(x, z, u) = f(x) + g(z) + \frac{\rho}{2} \|Dx - z + u\|^2$$

The updates are derived by minimizing this Lagrangian with respect to $x$ and $z$ sequentially, followed by a dual ascent step on $u$.

When $D = I$, the problem reduces to the standard form:
$$x^{k+1} = \text{prox}_{\rho f}(x^k - u^k)$$
$$z^{k+1} = \text{prox}_{\rho g}(x^{k+1} + u^k)$$
$$u^{k+1} = u^k + x^{k+1} - z^{k+1}$$

**Parameters:**
- $\rho$: Penalty parameter. Typical values are not specified in the sources [S1, unofficial].
- $\lambda$: Used in the simplified proximal notation, equivalent to $\rho$ in the constrained form [S1, unofficial].

**Edge Cases and Pitfalls:**
- The $x$-update often requires solving a linear system. In implementations like RTK, this is done using a Conjugate Gradient (CG) method [S1, unofficial].
- If $D$ is not identity, the $x$-update involves solving a system with $D^T D$, which can be computationally expensive.

## Subtopics

### Linearized ADMM
A variation that approximates the x-update to avoid solving linear systems, also known as Split Uzawa or Proximal ADMM [S1, unofficial].

### ADMM with Total Variation
A specific application where $g(x)$ is the total variation norm, used for edge-preserving reconstruction [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Depends on the cost of the proximal operators and the linear solver for the x-update. In RTK, the x-update uses Conjugate Gradient, which is iterative [S1, unofficial].
- **Memory Complexity**: Requires storage for $x, z, u$ and the operator $D$.
- **Strengths**: Handles non-smooth regularizers (like $L_1$) efficiently. Decomposes complex problems into simpler steps [S1, unofficial].
- **Limitations**: Convergence rate can be slow. Requires careful tuning of $\rho$ [S1, unofficial].
- **When to use**: Volume reconstruction with sparsity or total variation priors [S1, unofficial].

## Background
The ADMM solver is implemented in the Reconstruction ToolKit (RTK), a high-performance toolkit for 3D cone beam reconstruction based on ITK [S1, unofficial]. It is used for industrial computed tomography to estimate material composition from attenuated X-ray radiation [S1, unofficial].
