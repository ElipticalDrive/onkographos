# ADMM Solver

Also called: Alternating Direction Method of Multipliers, Standard ADMM

## Overview
The ADMM Solver is an optimization method for solving separable minimization problems of the form $\min_x f(x) + g(x)$ by splitting the objective into a data term $f(x)$ and a prior term $g(x)$ [S1, unofficial]. It differs from direct solvers by decoupling these terms into alternating subproblems, allowing specialized solvers for each component, and differs from primal-dual methods by explicitly maintaining a dual variable $u$ to enforce consensus between the split variables [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Objective functions $f(x)$ and $g(x)$; linear operator $D$ (identity $I$ for standard form); penalty parameter $\rho > 0$; initial guesses $x^0, z^0, u^0$.
- Output: Optimal variable $x$.

**Data Structures:**
- Vectors $x, z, u \in \mathbb{R}^n$.
- Scalar $\rho$.
- Integer iteration counter $k$.

**Steps:**
1. **Initialize:** Set $k=0$. Initialize $x^0, z^0, u^0$.
2. **Check Convergence:** If convergence criteria met, return $x^k$.
3. **Update $x$:** Solve for $x^{k+1}$ by minimizing the augmented Lagrangian with respect to $x$:
   $$x^{k+1} = \operatorname{argmin}_x f(x) + \frac{\rho}{2} \|Dx - z^k + u^k\|^2$$
   [G] For $D=I$, this simplifies to the proximal operator: $x^{k+1} = \text{prox}_{\rho f}(x^k - u^k)$.
4. **Update $z$:** Solve for $z^{k+1}$ by minimizing the augmented Lagrangian with respect to $z$:
   $$z^{k+1} = \operatorname{argmin}_z g(z) + \frac{\rho}{2} \|Dx^{k+1} - z + u^k\|^2$$
   [G] For $D=I$, this simplifies to the proximal operator: $z^{k+1} = \text{prox}_{\rho g}(x^{k+1} + u^k)$.
5. **Update Dual:** Update the scaled dual variable $u$:
   $$u^{k+1} = u^k + Dx^{k+1} - z^{k+1}$$
6. **Increment:** Set $k \leftarrow k+1$ and return to Step 2.

**Formulas:**
- **Augmented Lagrangian:** $L(x, z, u) = f(x) + g(z) + \frac{\rho}{2} \|Dx - z + u\|^2$.
- **Proximal Operator:** $\text{prox}_{\lambda h}(y) = \operatorname{argmin}_x h(x) + \frac{1}{2\lambda} \|x - y\|^2$.
- **Standard ADMM (when $D=I$):**
  $$x^{k+1} = \text{prox}_{\rho f}(x^k - u^k)$$
  $$z^{k+1} = \text{prox}_{\rho g}(x^{k+1} + u^k)$$
  $$u^{k+1} = x^k + x^{k+1} - z^{k+1}$$

**Parameters:**
- $\rho$: Penalty parameter. Typical values are not given in the sources.
- $\lambda$: Used in the standard form definition, effectively equivalent to $\rho$ in the scaled form.

**Edge Cases and Pitfalls:**
- If $D$ is not invertible or ill-conditioned, the $x$-update may require iterative solvers like Conjugate Gradient (CG) [S1, unofficial].
- Precision issues may arise if $\rho$ is too large or too small, affecting convergence speed.

## Subtopics

### [L1 Shearlet Regularized CT Reconstruction (ADMM)](10811-l1-shearlet-regularized-ct-reconstruction-admm.md)
This method solves the L1 shearlet regularized Computed Tomography (CT) reconstruction problem using the Alternating Direction Method of Multipliers (ADMM). It is designed to produce high-quality reconstructions from limited-angle or sparse sinogram data by enforcing sparsity in the shearlet domain while maintaining data consistency. It differs from standard Filtered Backprojection (FBP) by incorporating a non-linear prior that preserves edges and reduces artifacts, and it differs from other ADMM solvers by specifically structuring the proximal operators for shearlet sparsity and non-negativity constraints.

## Operating characteristics
- **Time Complexity:** Depends on the cost of evaluating $f$, $g$, and their proximal operators, and the number of iterations to convergence. Each iteration involves one evaluation of $D$ and its transpose (if needed for the $x$-update).
- **Memory Complexity:** $O(n)$ for storing $x, z, u$ and intermediate vectors.
- **Measured Performance:** Implemented in the Reconstruction ToolKit (RTK) as an ADMM total variation-regularized solver with conjugate gradient (CG) method [S1, unofficial].
- **Scaling:** Scales well with problem size if subproblems can be solved efficiently.
- **Strengths:** Handles non-smooth priors (like L1) effectively; decouples complex objectives.
- **Limitations:** Convergence can be slow for ill-conditioned problems; requires careful tuning of $\rho$.
- **When to use:** When the objective function is separable into a data term and a prior term, and proximal operators are available or easy to compute.
- **When not to use:** When the problem is not separable or proximal operators are expensive to compute.

## Background
The ADMM method is a proximal algorithm used for volume reconstruction, particularly in Computed Tomography (CT) [S1, unofficial]. It is implemented in the Reconstruction ToolKit (RTK), a high-performance toolkit for 3D cone beam reconstruction based on ITK [S1, unofficial]. The method is part of a broader class of proximal algorithms for solving inverse problems [S1, unofficial].
