# General Least Squares Solver
## Overview
The General Least Squares Solver addresses the overdetermined linear system $Ax = b$ for a non-symmetric matrix $A$ by transforming it into a symmetric positive semi-definite system via the normal equations $A^T A x = A^T b$ [S1, unofficial]. It is distinguished from its parent, the Symmetric Least Squares Solver, by its preprocessing step of explicitly forming $A^T A$ and $A^T b$, which squares the condition number of the original system, thereby gaining computational speed at the cost of numerical stability for ill-conditioned inputs [S1, unofficial].
## How it works
**Inputs:**
- $A$: A non-symmetric matrix of size $M \times N$ (typically $3 \times 3$ in the cited implementation context).
- $b$: A vector of size $M$.
- $svd\_tol$: Tolerance for Singular Value Decomposition convergence.
- $svd\_sweeps$: Number of Jacobi sweeps for SVD.
- $pinv\_tol$: Tolerance for pseudoinverse calculation (singular value cutoff).

**Outputs:**
- $x$: The solution vector of size $N$.
- Residual error (scalar).

**Data Structures:**
- `Mat3`: A $3 \times 3$ matrix structure.
- `SMat3`: A symmetric $3 \times 3$ matrix structure (stores only upper/lower triangle).
- `Vector3`: A 3-element vector.

**Steps:**
1. **Transpose**: Compute $A^T$ from $A$ using `MatUtils.transpose` [S1, unofficial].
2. **Form Normal Matrix**: Compute $ATA = A^T A$ using `MatUtils.mmul_ata` [S1, unofficial].
3. **Form Right-Hand Side**: Compute $ATb = A^T b$ using `MatUtils.vmul` [S1, unofficial].
4. **Solve Symmetric System**: Call `solveSymmetric(ata, atb, x, svd_tol, svd_sweeps, pinv_tol)` to find $x$ [S1, unofficial].
5. **Return**: Return $x$ and the residual error $\|Ax - b\|$ [S1, unofficial].

**Pseudocode:**
```python
def solve_general_least_squares(A, b, svd_tol, svd_sweeps, pinv_tol):
    # Step 1: Transpose A into AT
    AT = transpose(A)
    # Step 2: Compute ATA = A^T * A
    ATA = matmul_symmetric(AT, A)
    # Step 3: Compute ATb = A^T * b
    ATb = vmul(AT, b)
    # Step 4: Solve symmetric system ATA * x = ATb
    x, residual = solve_symmetric(ATA, ATb, svd_tol, svd_sweeps, pinv_tol)
    return x, residual

def solve_symmetric(A, b, svd_tol, svd_sweeps, pinv_tol):
    # Compute SVD of symmetric A: A = V D V^T
    V, D = get_symmetric_svd(A, svd_tol, svd_sweeps)
    # Compute pseudoinverse A^+ = V D^+ V^T
    pinv = pseudoinverse_symmetric(V, D, pinv_tol)
    # Solve x = A^+ b
    x = vmul(pinv, b)
    # Compute residual ||Ax - b||
    residual = calc_error(A, x, b)
    return x, residual

def transpose(M):
    return [[M[j][i] for j in range(len(M))] for i in range(len(M[0]))]

def matmul_symmetric(AT, A):
    n = len(A)
    ATA = [[0.0] * n for _ in range(n)]
    for i in range(n):
        for j in range(i, n):
            val = sum(AT[i][k] * A[k][j] for k in range(n))
            ATA[i][j] = val
            ATA[j][i] = val
    return ATA

def vmul(M, v):
    return [sum(M[i][j] * v[j] for j in range(len(v))) for i in range(len(M))]

def get_symmetric_svd(A, tol, sweeps):
    # Standard Jacobi SVD for symmetric matrices [G]
    # Iteratively applies Givens rotations to diagonalize M
    n = len(A)
    V = [[1.0 if i == j else 0.0 for j in range(n)] for i in range(n)]
    D = [A[i][i] for i in range(n)]
    for _ in range(sweeps):
        for i in range(n):
            for j in range(i + 1, n):
                if abs(A[i][j]) < tol: continue
                tau = (D[j] - D[i]) / (2.0 * A[i][j])
                stt = (1.0 + tau * tau) ** 0.5
                tan_val = 1.0 / ((tau >= 0) * (tau + stt) + (tau < 0) * (tau - stt))
                c = 1.0 / (1.0 + tan_val * tan_val) ** 0.5
                s = tan_val * c
                # Apply rotation to A and accumulate in V
                for k in range(n):
                    A[i][k], A[j][k] = c * A[i][k] + s * A[j][k], -s * A[i][k] + c * A[j][k]
                    V[k][i], V[k][j] = c * V[k][i] + s * V[k][j], -s * V[k][i] + c * V[k][j]
                D[i], D[j] = A[i][i], A[j][j]
    return V, D

def pseudoinverse_symmetric(V, D, pinv_tol):
    # D is diagonal of singular values
    n = len(V)
    D_inv = [1.0 / d if d > pinv_tol else 0.0 for d in D]
    # ATA^+ = V * diag(D_inv) * V^T
    pinv = [[0.0] * n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            pinv[i][j] = sum(V[i][k] * D_inv[k] * V[j][k] for k in range(n))
    return pinv

def calc_error(A, x, b):
    Ax = vmul(A, x)
    return sum((Ax[i] - b[i]) ** 2 for i in range(len(b))) ** 0.5
```

**Parameters:**
- $svd\_tol$: Not given in the sources.
- $svd\_sweeps$: Not given in the sources.
- $pinv\_tol$: Not given in the sources.

**Edge Cases:**
- Ill-conditioned $A$: Squaring the condition number ($\kappa(A^T A) = \kappa(A)^2$) can lead to significant numerical instability and loss of precision [S1, unofficial].
- Singular $A^T A$: The pseudoinverse handles this by zeroing out components corresponding to singular values below $pinv\_tol$ [S1, unofficial].

## Subtopics

### [Normal Equations Solver](4954-normal-equations-solver.md)
The Normal Equations Solver addresses the overdetermined linear system $Ax = b$ arising in radiance-field optimization by forming and solving the symmetric positive semi-definite system $A^T A x = A^T b$. It is distinguished from sibling methods like the General Least Squares Solver by explicitly squaring the condition number to gain computational speed, making it the fastest alternative for well-conditioned systems but prone to numerical instability when the matrix is ill-conditioned.
