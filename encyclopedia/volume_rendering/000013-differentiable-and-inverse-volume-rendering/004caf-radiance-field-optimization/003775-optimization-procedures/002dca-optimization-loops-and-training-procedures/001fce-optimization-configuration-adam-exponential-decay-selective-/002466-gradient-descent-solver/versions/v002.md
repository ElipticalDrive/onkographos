# Gradient Descent Solver

Also called: Adam Optimizer Solver, L1/L2 Norm Solver

## Overview
The Gradient Descent Solver is a matrix-free iterative method for optimizing transfer functions in volume rendering, designed to handle ill-conditioned or rank-deficient systems more stably than direct normal equation approaches [S1, unofficial]. It distinguishes itself from sibling solvers like CGLS by using iterative gradient updates rather than conjugate gradients, and from Partially Learned Gradient Descent by relying on fixed physics-based gradients without learnable neural network unrolling [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A differentiable rendering objective function $L(\mathbf{t})$ dependent on the transfer function parameters $\mathbf{t}$, and a choice of optimization mode (constant rate $\alpha$ or Adam).
- Output: The optimized transfer function parameters $\mathbf{t}$.

**Data Structures:**
- $\mathbf{t}$: Vector of transfer function coefficients.
- $\mathbf{g}$: Accumulated gradient vector, same size and layout as $\mathbf{t}$.
- For Adam: $\mathbf{m}$ (first moment estimate) and $\mathbf{v}$ (second moment estimate), same size as $\mathbf{t}$.

**Steps:**
1. Initialize $\mathbf{t}$ to a starting value (e.g., identity or zero). Initialize $\mathbf{g}, \mathbf{m}, \mathbf{v}$ to zero vectors [G].
2. For each iteration $k$:
   a. Compute the gradient $\nabla L(\mathbf{t}_k)$ via automatic differentiation or manual derivation of the rendering pipeline [S1, unofficial].
   b. Accumulate gradients into $\mathbf{g}$ using atomic additions to support parallel evaluation [S1, unofficial].
   c. Update $\mathbf{t}$ based on the selected optimizer:
      - **Constant Rate:** $\mathbf{t}_{k+1} = \mathbf{t}_k - \alpha \mathbf{g}$, where $\alpha$ is the learning rate.
      - **Adam:** Update $\mathbf{m}$ and $\mathbf{v}$ using standard Adam formulas with bias correction, then update $\mathbf{t}$ [KB15].
   d. Reset $\mathbf{g}$ to zero for the next iteration [G].

**Formulas:**
- **L2-Norm (Least Squares):** Minimizes $\sum_i (y_i - \hat{y}_i)^2$. Penalizes larger residuals more strongly due to the quadratic term [S1, unofficial].
- **L1-Norm (Least Absolute Deviations):** Minimizes $\sum_i |y_i - \hat{y}_i|$. Tolerates larger outliers in favor of minimizing many lower deviations [S1, unofficial].

**Parameters:**
- $\alpha$: Constant update rate. Value not given in the sources.
- Adam hyperparameters: $\beta_1, \beta_2, \epsilon$. Standard values not given in the sources, but referenced as [KB15].

**Edge Cases and Pitfalls:**
- Ill-conditioned systems: The solver is noted to show stable behavior for ill-conditioned systems, unlike direct methods [S1, unofficial].
- Atomic additions: Required for parallel gradient accumulation to avoid race conditions [S1, unofficial].

**Pseudocode:**
```python
def gradient_descent_solver(render_pipeline, objective, optimizer_type='adam', alpha=0.01, beta1=0.9, beta2=0.999, epsilon=1e-8, max_iterations=1000):
    # Initialize transfer function parameters
    t = initialize_transfer_function()
    
    # Initialize optimizer states
    m = zeros_like(t)
    v = zeros_like(t)
    g = zeros_like(t)
    
    for k in range(max_iterations):
        # Compute gradient of the objective with respect to t
        # This involves differentiating the rendering pipeline
        g = compute_gradient(render_pipeline, objective, t)
        
        if optimizer_type == 'constant':
            # Constant learning rate update
            t = t - alpha * g
        elif optimizer_type == 'adam':
            # Adam optimizer update
            m = beta1 * m + (1 - beta1) * g
            v = beta2 * v + (1 - beta2) * g**2
            
            m_hat = m / (1 - beta1**k)
            v_hat = v / (1 - beta2**k)
            
            t = t - alpha * m_hat / (sqrt(v_hat) + epsilon)
            
        # Reset gradient accumulator for next iteration
        g = zeros_like(t)
        
    return t
```

## Subtopics

### [CGLS Solver (Conjugate Gradient Least Squares)](3285-cgls-solver-conjugate-gradient-least-squares.md)
The CGLS solver is a sparse linear least squares solver used to avoid the ill-conditioning of normal equations ($A^T A$), providing numerically stable results for large or rank-deficient problems. It differs from its parent [Gradient Descent Solver](3280-gradient-descent-solver.md) by solving the linear system directly via conjugate gradients rather than iterative gradient updates, and from its siblings [Partially Learned Gradient Descent](3771-partially-learned-gradient-descent.md) by relying on the specific CGLS algorithm for least-squares minimization.

### [Partially Learned Gradient Descent](3771-partially-learned-gradient-descent.md)
Partially Learned Gradient Descent is an iterative reconstruction method that unrolls a fixed number of optimization steps into a neural network, combining a fixed physics-based gradient step with a learnable neural network update. It initializes the reconstruction with a filtered backprojection (FBP) estimate and, in its base form, does not use a regularization term in the network input. Unlike standard Gradient Descent which uses a fixed step size, this method learns the update rule via a convolutional network while retaining the physical forward model and gradient structure, making it more interpretable and robust to distribution shifts than fully learned end-to-end CNNs. It builds on [Gradient Descent Solver](3280-gradient-descent-solver.md).

### [Newton's Method](6442-newton-s-method.md)
Newton's method is a second-order optimization algorithm that approximates the objective function $f$ using a second-order Taylor expansion to determine an update step that targets the stationary point where the gradient is zero. It sets itself apart from first-order solvers like Gradient Descent by incorporating local curvature information via the Hessian matrix, allowing for faster convergence near optima, though at the cost of significant computational overhead for high-dimensional problems.

#### SGD with Positive t-Distribution
An ablation study variant that uses Stochastic Gradient Descent (SGD) with a positive Student's t distribution [S2]. It replaces Gaussian distributions with Student's t distributions, removes negative components and SGHMC (Stochastic Gradient Hamiltonian Monte Carlo), and adds a low-pass filter (0.3 diagonal offset) to ensure fair comparison with similar component counts [S2]. Used in the Ablation Study to provide a fair comparison with similar component numbers against methods using the low-pass filter [S2].

## Operating characteristics
- **Stability:** Shows stable behavior for ill-conditioned systems, similar to CGLS [S1, unofficial].
- **Speed:** Generally slower than computing the matrix $A^T A$ and vector $A^T b$ directly for large problems, but avoids the numerical instability of normal equations [S1, unofficial].
- **Loss Function Choice:** The choice between L2 and L1 norms makes a minor difference in final results, with L2 penalizing large residuals more and L1 tolerating outliers [S1, unofficial].
- **Matrix-Free:** Implemented in a matrix-free manner, which is beneficial for memory efficiency in large-scale volume rendering [S1, unofficial].

## Background
The Gradient Descent Solver was implemented as part of a study on transfer function optimization for comparative volume rendering, specifically within the DiffDVR framework [S1, unofficial]. It was introduced to provide a stable alternative to direct solvers for ill-conditioned systems in the context of optimizing transfer functions for voxel- and image-based optimization [S1, unofficial].
