# Large Steps reparameterization

Also called: Nicolet et al. 2021 method, Nicolet et al. Large Steps, Shape Reconstruction with Large Steps

## Overview
Large Steps reparameterization is a gradient preconditioning technique for inverse rendering of geometry that handles sparse silhouette gradients and prevents mesh topology errors such as flipped triangles [S1]. It achieves fast convergence by preconditioning the bias of gradient steps toward smooth solutions without enforcing smoothness in the final result [S2, unofficial]. It sets itself apart from standard optimizers by treating the optimization as a spatiotemporal process using Laplacian smoothing and infinity-norm filtering [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Current vertex positions $x \in \mathbb{R}^{3N}$ (where $N$ is the number of vertices), Laplacian matrix $L \in \mathbb{R}^{3N \times 3N}$, hyperparameter $\lambda > 0$, and the gradient of the loss function with respect to $x$, denoted $\nabla_x f$.
*   **Output:** Updated vertex positions $x$.

**Data Structures:**
*   **Laplacian Matrix ($L$):** A sparse matrix representing the mesh connectivity. For a standard cotangent Laplacian, $L_{ij}$ depends on the angles opposite the edge connecting vertices $i$ and $j$. The matrix is symmetric and positive semi-definite.
*   **Reparameterized Variable ($u$):** $u \in \mathbb{R}^{3N}$, defined as $u = (I + \lambda L)x$.
*   **Optimizer State ($m_u, v_u$):** First and second moment estimates for $u$, initialized to zero vectors of size $3N$.

**Parameters:**
*   $\lambda$: Controls the strength of regularization introduced by the Laplacian matrix [S2, unofficial]. Typical values are not specified in the sources; implementation notes suggest it may require adjustment depending on the rendering engine (e.g., Mitsuba 3 vs. nvdiffrast) [S2, unofficial].
*   $\alpha$: Learning rate for the UniformAdam optimizer.
*   $\beta_1, \beta_2$: Exponential decay rates for moment estimates (standard Adam defaults: 0.9, 0.999).
*   $\epsilon$: Numerical stability constant (standard Adam default: $10^{-8}$).

**Steps:**
1.  **Reparameterization:** Compute the transformed variable $u$ from the current geometry $x$:
    $$ u = (I + \lambda L)x $$
2.  **Gradient Transformation:** Compute the gradient with respect to $u$ using the chain rule. Since $u = (I + \lambda L)x$, the Jacobian is $\frac{\partial x}{\partial u} = (I + \lambda L)^{-1}$. The gradient for $u$ is:
    $$ \nabla_u f = (I + \lambda L)^{-1} \nabla_x f $$
    *Note: In practice, this involves solving a linear system $(I + \lambda L) \nabla_u f = \nabla_x f$.*
3.  **UniformAdam Update:** Perform an update on $u$ using the UniformAdam variant of Adam. Let $g = \nabla_u f$.
    *   Update biased first moment estimate: $m_u \leftarrow \beta_1 m_u + (1 - \beta_1) g$
    *   Update biased second raw moment estimate: $v_u \leftarrow \beta_2 v_u + (1 - \beta_2) g^2$ (element-wise square)
    *   Compute bias-corrected estimates:
        $$ \hat{m}_u = \frac{m_u}{1 - \beta_1^t}, \quad \hat{v}_u = \frac{v_u}{1 - \beta_2^t} $$
        where $t$ is the time step.
    *   **Key Difference:** Instead of dividing by $\sqrt{\hat{v}_u} + \epsilon$, UniformAdam uses the infinity norm of the second moment vector. Let $V_{\infty} = \max(\hat{v}_u)$ (the maximum element-wise value). The update step $\Delta u$ is:
        $$ \Delta u = -\alpha \frac{\hat{m}_u}{\sqrt{V_{\infty}} + \epsilon} $$
        *Note: The source describes replacing component-wise division by $v_t$ with component-wise max $\|v_t\|_\infty$. This implies the denominator is a scalar derived from the max norm, applied to the entire vector update, or potentially element-wise if interpreted as scaling. The text "component-wise max ||vt||∞" is slightly ambiguous. Standard interpretation of "infinity norm" is a scalar. However, "component-wise division... replaced with component-wise max" suggests the denominator might be treated as a scalar broadcast or the operation is vector-wise. Given "UniformAdam... same as Adam except...", and Adam is element-wise, replacing the element-wise denominator with a scalar max-norm makes it a "uniform" step size direction. We assume the denominator is the scalar $\sqrt{\max(\hat{v}_u)} + \epsilon$.*
    *   Update $u$:
        $$ u \leftarrow u + \Delta u $$
4.  **Inverse Reparameterization:** Convert the updated $u$ back to the physical space $x$:
    $$ x = (I + \lambda L)^{-1} u $$
    *Note: This involves solving the linear system $(I + \lambda L) x = u$.*

**Pseudocode:**
```python
import numpy as np
from scipy.sparse.linalg import spsolve

def large_steps_update(x, L, lambda_reg, grad_x, m_u, v_u, alpha, beta1, beta2, epsilon, t):
    """
    Performs one step of Large Steps reparameterization.
    
    Args:
        x: Current vertex positions, shape (N, 3) or (3N,)
        L: Laplacian matrix, sparse matrix of shape (3N, 3N)
        lambda_reg: Hyperparameter lambda
        grad_x: Gradient of loss w.r.t x, shape (3N,)
        m_u: First moment estimate for u, shape (3N,)
        v_u: Second moment estimate for u, shape (3N,)
        alpha: Learning rate
        beta1, beta2: Adam decay rates
        epsilon: Numerical stability constant
        t: Current time step
        
    Returns:
        x_new: Updated vertex positions
        m_u_new: Updated first moment
        v_u_new: Updated second moment
    """
    N = x.shape[0]
    I = scipy.sparse.eye(L.shape[0])
    
    # 1. Reparameterization: u = (I + lambda * L) * x
    # Solve for u directly if x is known, or compute matrix-vector product
    # u = (I + lambda * L) @ x
    # However, the method defines u as the variable. 
    # In the update step, we start with x, compute grad_x.
    # We need to maintain u. If u is not stored, we compute it from x.
    # But the optimizer state is on u. So we assume u is tracked.
    # If we only have x, we compute u = (I + lambda L) x.
    
    # Let's assume we have current u. If not, compute it.
    # For clarity, let's assume u is passed or computed.
    # The input is x. We must compute u from x.
    A = I + lambda_reg * L
    u = A.dot(x)
    
    # 2. Gradient Transformation: grad_u = (I + lambda L)^-1 * grad_x
    # Solve A * grad_u = grad_x
    grad_u = spsolve(A, grad_x)
    
    # 3. UniformAdam Update on u
    # Update moments
    m_u_new = beta1 * m_u + (1 - beta1) * grad_u
    v_u_new = beta2 * v_u + (1 - beta2) * (grad_u ** 2)
    
    # Bias correction
    bias_correction_1 = 1 - beta1 ** t
    bias_correction_2 = 1 - beta2 ** t
    
    m_hat = m_u_new / bias_correction_1
    v_hat = v_u_new / bias_correction_2
    
    # UniformAdam: Use infinity norm of v_hat
    # ||v_hat||_inf = max(v_hat)
    v_inf = np.max(np.abs(v_hat)) # Or just max(v_hat) since v_hat is squared
    
    # Update step
    # Delta u = - alpha * m_hat / (sqrt(v_inf) + epsilon)
    # Note: The source says "component-wise division by vt is replaced with component-wise max ||vt||inf"
    # This phrasing is tricky. "Component-wise max" usually doesn't make sense for a scalar.
    # It likely means the denominator is the scalar max norm.
    # If it meant element-wise, it would say "element-wise max".
    # "Infinity norm" is a scalar.
    
    denominator = np.sqrt(v_inf) + epsilon
    delta_u = -alpha * m_hat / denominator
    
    u_new = u + delta_u
    
    # 4. Inverse Reparameterization: x = (I + lambda L)^-1 * u_new
    # Solve A * x_new = u_new
    x_new = spsolve(A, u_new)
    
    return x_new, m_u_new, v_u_new
```

**Edge Cases and Pitfalls:**
*   **Singular Matrix:** The matrix $(I + \lambda L)$ is positive definite if $\lambda > 0$ and $L$ is positive semi-definite, so it is invertible. However, for very large meshes, solving the linear system can be computationally expensive. Iterative solvers (e.g., Conjugate Gradient) are recommended.
*   **Precision:** The inversion of $(I + \lambda L)$ can be sensitive to numerical precision if $\lambda$ is very small or very large.
*   **Boundary Conditions:** The Laplacian matrix $L$ depends on the mesh connectivity. Degenerate triangles or flipped triangles in the input mesh can lead to incorrect Laplacian values. The method aims to *prevent* flipped triangles, but the initial mesh must be valid.
*   **Hyperparameter Tuning:** The value of $\lambda$ and the learning rate $\alpha$ are critical and may need adjustment based on the specific rendering engine and scene complexity [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** The dominant cost is solving the linear system $(I + \lambda L) y = b$ twice per step (once for gradient transformation, once for inverse reparameterization). Using direct solvers, this is $O(N^3)$ in the worst case, but for sparse meshes, iterative solvers can achieve $O(N)$ to $O(N \log N)$ depending on the condition number.
*   **Memory Complexity:** $O(N)$ to store the sparse Laplacian matrix and the optimizer states.
*   **Strengths:** Prevents flipped triangles and tangled meshes by smoothing gradients [S1]. Allows for higher learning rates due to the preconditioning [S2, unofficial].
*   **Limitations:** Requires the computation and storage of the Laplacian matrix. The choice of $\lambda$ is non-trivial and may require tuning [S2, unofficial].
*   **When to use:** Shape reconstruction in inverse rendering where mesh topology preservation is critical and gradients are sparse (e.g., silhouette-based optimization).
*   **When not to use:** When the mesh topology is fixed and known to be robust, or when computational resources are extremely limited and iterative linear solves are too slow.

## Background
The Large Steps reparameterization was introduced by Nicolet et al. in 2021 [S1]. It was designed to address the instability of gradient-based optimization for mesh reconstruction, where gradients are concentrated on sparse silhouettes, leading to local vertex perturbations that cause flipped triangles [S1]. The method is described as a spatiotemporal optimizer that uses Laplacian smoothing and an infinity norm as filters [S1]. It has been adopted in subsequent work, such as MRD, which uses Mitsuba 3 for implementation [S2, unofficial].
