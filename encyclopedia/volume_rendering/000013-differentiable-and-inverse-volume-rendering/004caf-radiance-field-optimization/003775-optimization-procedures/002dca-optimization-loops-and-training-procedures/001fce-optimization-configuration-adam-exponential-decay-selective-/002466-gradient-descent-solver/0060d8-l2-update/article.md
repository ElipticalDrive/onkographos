# L2 Update
Also called: L2-norm minimization update step, PWLS Update

## Overview
The L2 Update is a single optimization step for differentiable volume rendering that minimizes the L2-norm of the residual between projected and measured data, incorporating Poisson-statistics-based weighting [S1, unofficial]. It distinguishes itself from standard gradient descent by applying adaptive weights to both the residual and the volume update, supporting subset-based processing to handle large datasets [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** `projections` (measured data), `volume` (current volume estimate), `geometry` (projection geometry), `settings` (configuration flags `update_residual`, `studentst`), `subsets` (number of subsets).
- **Outputs:** Updated `volume`, normalized residual norm `rnorm`.

**Data Structures:**
- `projections`: Array of measured projection values.
- `volume`: 3D array of voxel values.
- `geometry`: Object defining projection parameters (angles, distances, detector dimensions).
- `residual`: Temporary array same shape as `projections`.
- `vol_tmp`, `bwp_w`: Temporary arrays same shape as `volume`.
- `fwp_w`: Temporary array same shape as `projections`.

**Steps:**
1. Retrieve `settings.update_residual` and `settings.studentst`.
2. Determine the number of subsets.
3. Compute the backprojection weight normalization factor by calling `_bp_norm_(projections, volume, geometry)`.
4. Loop over subsets generated by `_subset_generator_(projections, volume, geometry, copy=True)`:
    a. Initialize `residual` as a contiguous zero array with the same shape as the current subset of projections.
    b. Forward project the current `volume` into `residual`.
    c. Apply filters to `residual`.
    d. If `update_residual` is true, compute the root mean square of `residual` and add it to `rnorm`.
    e. If `studentst` is true, apply Student's T norm with degree 6 to `residual`.
    f. Scale `residual` by `bp_weight * subsets * 2`.
    g. Backproject `residual` into `volume` (filtered=False).
    h. Return `rnorm / subsets`.
5. Retrieve `settings.update_residual`.
6. Determine the number of subsets.
7. Compute the backprojection weight normalization factor by calling `_bp_norm_(projections, volume, geometry)`.
8. Loop over subsets generated by `_subset_generator_(projections, volume, geometry, copy=True)`:
    a. Initialize `vol_tmp` and `bwp_w` as zero arrays with the same shape as `volume`.
    b. Compute weights `fwp_w` as `exp(-subset)`.
    c. Backproject `fwp_w` into `bwp_w` (filtered=False).
    d. Initialize `residual` as a contiguous zero array with the same shape as the current subset of projections.
    e. Forward project the current `volume` into `residual`.
    f. Apply filters to `residual`.
    g. If `update_residual` is true, compute the root mean square of `residual` and add it to `rnorm`.
    h. Scale `residual` by `bp_weight * subsets * 2 * fwp_w`.
    i. Backproject `residual` into `vol_tmp` (filtered=False).
    j. Normalize `bwp_w` by dividing by its maximum value.
    k. Clamp `bwp_w` values below `1e-2` to `1e-2`.
    l. Update `volume` by adding `vol_tmp` divided by `bwp_w`.
    m. Return `rnorm / subsets`.

    """
    Performs a single L2-norm minimization update step with Poisson weighting.
    
    Args:
        projections: Array of measured projection data.
        volume: Current 3D volume estimate.
        geometry: Projection geometry object.
        settings: Object containing 'update_residual' (bool) and 'studentst' (bool).
        num_subsets: Number of subsets to process.
        
    Returns:
        rnorm: Normalized residual norm.
    """

    bp_weight = _bp_norm(projections, volume, geometry)
    
    # Generate subsets
    subsets = _subset_generator(projections, volume, geometry, copy=True)

        # Initialize residual
        residual = np.zeros_like(subset)
        
        # Forward project volume into residual
        residual = _forward_project(volume, geometry)
        
        # Apply filters to residual
        residual = _apply_filters(residual)
        
        # Update residual norm if required
        if settings.update_residual:
            rnorm += np.sqrt(np.mean(residual**2))
            
        # Apply Student's T norm if required
        if settings.studentst:
            residual = _apply_student_t_norm(residual, degree=6)

        volume = _backproject(residual, geometry, filtered=False)

    rnorm = rnorm / num_subsets
    return rnorm

**Edge Cases and Pitfalls:**
- Precision issues may arise when computing `exp(-subset)` for large negative values.
- Clamping `bwp_w` to `1e-2` prevents division by zero but may introduce bias in low-weight regions.
- The method assumes that the `geometry` object provides accurate projection parameters.

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of voxels and projections, scaled by the number of subsets.
- **Memory Complexity:** Linear with respect to the number of voxels and projections, due to temporary arrays.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales well with the number of subsets, as each subset can be processed independently.
- **Strengths:** Handles large datasets efficiently through subset processing; incorporates Poisson statistics for improved accuracy.
- **Limitations:** Requires careful tuning of parameters such as `num_subsets` and `degree`; may be sensitive to noise in the projections.
- **When to Use:** Suitable for differentiable volume rendering tasks where Poisson statistics are relevant and large datasets need to be processed efficiently.
- **When Not to Use:** Not suitable for real-time applications due to the computational cost of forward and backprojection operations.
