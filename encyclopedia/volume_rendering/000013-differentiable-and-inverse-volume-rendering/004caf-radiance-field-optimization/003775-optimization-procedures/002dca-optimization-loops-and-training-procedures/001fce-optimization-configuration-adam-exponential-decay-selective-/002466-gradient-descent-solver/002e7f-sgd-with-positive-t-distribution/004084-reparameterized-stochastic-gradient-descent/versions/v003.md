# Reparameterized Stochastic Gradient Descent

Also called: Reparameterized SGD, Reparameterized Stochastic Gradient Descent for Parameter Optimization

## Overview
Reparameterized Stochastic Gradient Descent (Reparam-SGD) is an optimization technique designed to find altered scattering parameters $(g, \sigma_s)$ that minimize the error between a rendered image and a target image [S1]. It addresses the problem of SGD getting trapped in local minima with small gradients caused by low-frequency lighting, which leads to solutions that generalize poorly to high-frequency lighting [S1]. It sets itself apart from standard SGD by reparameterizing the search space to regularize the error surface and using sequential 1D searches to escape ill-conditioned regions [S1].

## How it works
**Inputs:**
*   Target image $I_0$ [S1].
*   Initial guess for scattering parameters $(g, \sigma_s)$ [S1].
*   Error function $d(g, \sigma_s)$ defined in [S1] (Eq. 21 in source), where $I_0$ is the input image [S1].

**Outputs:**
*   Optimized scattering parameters $(g^*, \sigma_s^*)$ [S1].

**Data Structures:**
*   Parameters: $g$ (anisotropy factor), $\sigma_s$ (scattering coefficient) [S1].
*   Reparameterized variable: $\tilde{\sigma}_s$ (reduced scattering coefficient) [S1].

**Formulas:**
The reparameterization replaces the horizontal axis with the reduced scattering coefficient:
$$ \tilde{\sigma}_s := (1 - g)\sigma_s $$
This ensures both axes ($g$ and $\tilde{\sigma}_s$) have the same units and regularizes the error surface [S1].

**Steps:**
1.  **Reparameterize:** Transform the search space from $(g, \sigma_s)$ to $(g, \tilde{\sigma}_s)$ using the formula above [S1].
2.  **First 1D Search:** Fix $\sigma_s$ and perform a one-dimensional SGD search to find $\tilde{\sigma}_s$ that minimizes the error $d$ [S1]. This step selects an equivalence class based on the order-1 similarity relation [S1].
3.  **Second 1D Search:** Keep the found $\tilde{\sigma}_s$ fixed and perform another one-dimensional SGD search to find the best $\sigma_s$ within the selected equivalence class [S1].
4.  **Result:** The pair $(g, \sigma_s)$ from the second step is the solution [S1].

**Edge Cases and Pitfalls:**
*   **Low-frequency lighting:** Creates large regions where the error function is close to zero with very small gradients, dominated by Monte Carlo or measurement noise. Standard SGD gets trapped here [S1].
*   **Local Minima:** Solutions found in low-error regions under low-frequency lighting may generalize poorly to high-frequency lighting [S1].
*   **Physical Validity:** Parameters $g$ and $\sigma_s$ must remain within physical bounds (e.g., $\sigma_s > 0$, $g \in [-1, 1]$) [G].

## Subtopics

### [Similarity-Based Inverse Rendering](10272-similarity-based-inverse-rendering.md)
A reparameterization technique for optimizing translucent material properties that resolves ambiguities caused by similarity equivalence classes. It sets itself apart from standard gradient descent by warping the non-linear parameter space to separate indistinguishable parameter sets, thereby preventing the optimization from stalling in ill-conditioned regions.

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** The method finds solutions that generalize better to high-frequency lighting compared to standard SGD, which gets trapped in local minima under low-frequency lighting [S1].
*   **Strengths:** Regularizes the error surface; avoids local minima caused by low-frequency lighting; improves generalization to high-frequency lighting [S1].
*   **Limitations:** Relies on Monte Carlo simulations for gradients, which can be noisy [S1].
*   **When to use:** When optimizing scattering parameters $(g, \sigma_s)$ for translucent materials, especially under low-frequency lighting conditions where standard SGD fails to generalize [S1].
*   **When not to use:** When high-frequency lighting is not a concern and standard SGD converges sufficiently [S1].
