# SGD with Positive t-Distribution

Also called: SGD + positive t-distribution

## Overview
An ablation study variant of differentiable volume rendering optimization that replaces Gaussian noise assumptions with a positive Student's t-distribution to model gradient uncertainty [S1]. It serves as a controlled baseline to isolate the impact of heavy-tailed noise modeling from other components like MCMC sampling, ensuring fair comparison with methods using low-pass filtering [S1]. It builds on the Gradient Descent Solver [3280-gradient-descent-solver.md] by modifying the noise model [G].

## How it works
**Inputs and Outputs:** Not given in the sources [S1].

**Data Structures:** Not given in the sources [S1].

**Steps:**
1. Replace Gaussian noise sampling with sampling from a Student's t-distribution [S1].
2. Remove negative components from the sampled noise or update [S1].
3. Remove SGHMC (Stochastic Gradient Hamiltonian Monte Carlo) dynamics [S1].
4. Apply a low-pass filter with a 0.3 diagonal offset to the update or parameters [S1].

**Formulas:**
The probability density function for a Student's t-distribution is:
$$ f(t | \nu, \mu, \gamma) = \frac{\Gamma(\frac{\nu+1}{2})}{\sqrt{\nu\pi}\gamma\Gamma(\frac{\nu}{2})} \left( 1 + \frac{1}{\nu} \left( \frac{t-\mu}{\gamma} \right)^2 \right)^{-\frac{\nu+1}{2}} $$
Where $\mu$ is location, $\gamma$ is scale, and $\nu$ is degrees of freedom [G]. The "positive" constraint implies restricting the support or sampling mechanism to non-negative values for the noise component [G].

**Parameters:**
- $\nu$ (degrees of freedom): Controls tail heaviness. Not given in the sources [S1].
- $\alpha$ (learning rate): Standard SGD learning rate. Not given in the sources [S1].
- Low-pass filter offset: 0.3 diagonal offset [S1].

**Pseudocode:**
```python
def sgd_positive_t_update(theta, gradient, alpha, nu, scale):
    # Sample from Student's t-distribution with nu degrees of freedom and scale [G]
    z = standard_normal()
    v = chi_squared(nu)
    noise = z * scale / sqrt(v / nu)
    
    # Remove negative components as per method definition [S1]
    noise = max(noise, 0.0)
    
    # Combine gradient and noise
    update = gradient + noise
    
    # Apply low-pass filter with 0.3 diagonal offset [S1]
    # Exact application of the diagonal offset is not specified in sources [G]
    
    # Apply learning rate and update parameters
    theta_new = theta - alpha * update
    return theta_new
```

## Subtopics

### [Reparameterized Stochastic Gradient Descent](10267-reparameterized-stochastic-gradient-descent.md)
An optimization technique to find altered scattering parameters (g, σₛ) that minimize an error function d(g, σₛ) between a rendered image and a target image, using a reparameterized search space to avoid local minima.

## Operating characteristics
- Performance: Used in ablation studies to compare against methods with similar component counts, showing competitive LPIPS scores on Mip-NeRF 360 and Tanks&Temples datasets [S1].
- Strengths: Provides a robust baseline for heavy-tailed noise modeling; fair comparison with filtered methods [S1].
