# Multi-view Style-Transfer

Also called: Lmvst, MVST

## Overview
Multi-view Style-Transfer (MVST) is a method to jointly optimize input image colors to match a given style while maintaining photo-consistency across multiple views [S1]. It leverages the differentiability of point-based reprojection to enforce multi-view consistency through a photo-consistency loss, distinguishing it from single-view style transfer methods [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of input images $\{I_n\}$, a target style image $S$, the original versions of the input images $\{I_n^*\}$, and a 3D representation $R$ [S1].
*   **Outputs:** Optimized input images $\{I_n\}$ that exhibit the target style while preserving multi-view photo-consistency [S1].

**Data Structures:**
*   **Input Images ($I_n$):** Stored as learnable tensor parameters during optimization [S1].
*   **Reprojected Images ($R(I_{m \neq n})$):** Generated by projecting the 3D representation onto the camera views of other images $m \neq n$ [S1].
*   **Mask ($M$):** A binary mask indicating pixels containing valid content in the reprojected images $R(I_m)$ [S1].

**Loss Function:**
The total optimization objective is defined as [S1]:

$$L_{mvst}(I_n, R(I_{m \neq n})) = L_{photo} + C_{X_{style}}(I_n, S) + C_{X_{cont}}(I_n, I_n^*)$$

where $L_{photo}$ enforces photo-consistency, $C_{X_{style}}$ measures style similarity, and $C_{X_{cont}}$ measures content similarity [S1].

**Detailed Loss Terms:**
1.  **Photo-consistency Loss ($L_{photo}$):** Ensures consistency between the optimized image $I_n$ and reprojected images from other views [S1]. It is calculated as [S1]:
    $$L_{photo} = \sum_{m \neq n} (M \odot (I_n - R(I_m)))^2$$
    where $\odot$ denotes element-wise multiplication and the sum aggregates over all other views $m$ [S1].
2.  **Contextual Style Loss ($C_{X_{style}}$) and Contextual Content Loss ($C_{X_{cont}}$):** Both terms use the contextual loss metric described in Mechrez et al. [MTZM18] [S1]. The exact mathematical formulation of the contextual loss is not provided in the sources [G].

**Algorithm Steps:**
1.  Initialize the pixel values of each input image $I_n$ as trainable optimization parameters [S1].
2.  For each optimization iteration:
    a. Compute reprojected images $R(I_{m \neq n})$ for all $m \neq n$ using the current 3D representation [S1].
    b. Compute $L_{photo}$ using the mask $M$ [S1].
    c. Compute $C_{X_{style}}(I_n, S)$ and $C_{X_{cont}}(I_n, I_n^*)$ [S1].
    d. Sum the terms to obtain $L_{mvst}$ [S1].
    e. Backpropagate through the reprojection and loss functions to compute gradients with respect to $I_n$ [S1].
    f. Update $I_n$ using gradient descent [S1].

**Parameters:**
*   $S$: Target style image [S1].
*   $I_n^*$: Content reference for $I_n$ (the original input image) [S1].
*   $M$: Mask for valid pixels in reprojected images [S1].

**Edge Cases and Pitfalls:**
*   The mask $M$ must accurately exclude background regions to prevent the photo-consistency loss from penalizing empty pixels [S1].
*   The method requires the reprojection pipeline to be fully differentiable with respect to the input image colors [S1].

## Subtopics

### View-consistent color transfer
A technique to correct color mismatches between rendered images and the style image by applying a linear color transformation estimated from statistics [S2]. The procedure consists of four steps: first, recolor the training views via color transfer from the style image [S2]. Second, use the recolored images to pre-optimize the artistic radiance field to obtain an initialization for the stylization optimization [S2]. Third, use the color-transferred images as the reference for the content preservation loss [S2]. Fourth, after the 3D stylization process, perform color transfer on images rendered to the training viewpoints and apply the exact same transformation directly to the radiance field's color values [S2]. The transformation is a linear mapping in RGB space [S2]. Its parameters are estimated by matching the mean and covariance of the pixel colors in the image set $c_i$ to those of the style image $s_i$, i.e., solving analytically for a linear transformation $A$ such that $E[Ac] = E[s]$ and $\text{Cov}[Ac] = \text{Cov}[s]$ [S2].

## Background
The method is based on the contextual loss approach of Mechrez et al. [MTZM18] [S1]. It was introduced within the context of point-based neural rendering with per-view optimization [S1].
