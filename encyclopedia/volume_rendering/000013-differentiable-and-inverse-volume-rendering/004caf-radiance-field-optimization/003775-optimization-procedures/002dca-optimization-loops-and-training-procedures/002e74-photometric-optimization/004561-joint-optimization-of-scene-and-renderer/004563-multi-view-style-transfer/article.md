# Multi-view Style-Transfer

Also called: Lmvst, MVST

## Overview
Multi-view Style-Transfer (MVST) is a method to jointly optimize input image colors to match a given style while maintaining photo-consistency across multiple views [S1]. It leverages the differentiability of point-based reprojection to allow style transfer between input images and a target style image, distinguishing itself from standard style transfer by enforcing multi-view consistency through a photo-consistency loss term [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of input images $\{I_n\}$, a target style image $S$, a radiance field or point cloud representation $R$, and the original versions of the input images $\{I_n^*\}$ [S1].
*   **Outputs:** Optimized input images $\{I_n\}$ that exhibit the style of $S$ while remaining consistent with the 3D scene geometry and other views [S1].

**Data Structures:**
*   **Input Images ($I_n$):** Treated as learnable parameters in the optimization process [S1].
*   **Reprojected Images ($R(I_{m \neq n})$):** Generated by projecting the 3D representation onto the camera views of other images $m$ [S1].
*   **Mask ($M$):** A binary mask indicating pixels containing content in the reprojected images $R(I_m)$ [S1].

**Loss Function:**
The total loss for multi-view style transfer is defined as [S1]:

$$
L_{mvst} (I_n , R(I_{m\neq n})) = L_{photo} + C_{X_{style}} (I_n , S) + C_{X_{cont}} (I_n , I_n^*)
$$

Where:
*   $L_{photo}$ is the photo-consistency loss [S1].
*   $C_{X_{style}}$ is the contextual style loss between the input image $I_n$ and the style image $S$ [S1].
*   $C_{X_{cont}}$ is the contextual content loss between the input image $I_n$ and its original version $I_n^*$ [S1].

**Detailed Loss Terms:**

1.  **Photo-consistency Loss ($L_{photo}$):**
    Ensures consistency between the optimized image $I_n$ and the reprojected images from other views $R(I_m)$ [S1]. It is calculated as [S1]:
    $$
    L_{photo} = \sum_{m \neq n} (M \odot (I_n - R(I_m)))^2
    $$
    Where $M$ is the mask of pixels containing content in $R(I_m)$, and $\odot$ denotes element-wise multiplication [S1].

2.  **Contextual Style Loss ($C_{X_{style}}$):**
    Measures the style similarity between $I_n$ and $S$ using the contextual loss metric [S1]. This is based on the approach of Mechrez et al. [MTZM18].

3.  **Contextual Content Loss ($C_{X_{cont}}$):**
    Measures the content similarity between the optimized image $I_n$ and its original version $I_n^*$ using the contextual loss metric [S1]. This ensures that the semantic content of the original image is preserved while the style is transferred [S1].

**Algorithm Steps:**
1.  Initialize the input image colors $I_n$ as parameters for optimization [S1].
2.  For each optimization step:
    a. Compute the reprojected images $R(I_{m \neq n})$ from the current 3D representation [S1].
    b. Calculate the photo-consistency loss $L_{photo}$ between $I_n$ and $R(I_{m \neq n})$ using the mask $M$ [S1].
    c. Calculate the contextual style loss $C_{X_{style}}(I_n, S)$ [S1].
    d. Calculate the contextual content loss $C_{X_{cont}}(I_n, I_n^*)$ [S1].
    e. Compute the total loss $L_{mvst}$ [S1].
    f. Update the parameters $I_n$ using gradient descent [S1].

**Parameters:**
*   $S$: Target style image [S1].
*   $I_n^*$: Content reference for $I_n$ (the original input image) [S1].
*   $M$: Mask for valid pixels in reprojected images [S1].

**Edge Cases and Pitfalls:**
*   The mask $M$ must correctly identify pixels containing content in the reprojected images to avoid comparing against empty or background regions [S1].
*   The method relies on the differentiability of the point-based reprojection process [S1].

## Background
The method is based on the approach of Mechrez et al. [MTZM18] for contextual loss [S1]. It was introduced in the context of point-based neural rendering with per-view optimization [S1].
