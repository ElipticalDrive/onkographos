# Geometric Baseline Regularization

Also called: Geometric Baseline, Geometric Loss

## Overview
Geometric Baseline Regularization is a composite loss function designed to prevent degenerate solutions in Neural Radiance Field (NeRF) optimization, particularly in few-view settings where the network might collapse to copying training images [S1]. It serves as a strong baseline by combining photometric reconstruction with geometric priors that enforce compact depth distributions, full absorption, and multi-view consistency [S1]. Unlike sibling methods that may rely on external depth supervision or complex structural constraints, this method derives regularization directly from the probabilistic interpretation of the volume rendering weights [S1].

## How it works
The method optimizes the density $\sigma$ and color $\mathbf{c}$ fields by minimizing a total loss $\mathcal{L}_{\text{geom}}$ that combines a photometric term with three geometric regularizers [S1].

**Inputs and Outputs**
- **Inputs**: Training images $\mathcal{I}$, camera poses, ray origins $\mathbf{o}$ and directions $\mathbf{d}$, sample depths $t_i$ along rays, and hyperparameters $\lambda_{\text{fg}}, \lambda_{\text{fr}}, \lambda_{\text{dist}}$.
- **Outputs**: Updated network parameters $\theta = (\sigma, \mathbf{c})$.

**Data Structures**
- **Rendering Weights**: $w_i = T_i (1 - \exp(-\sigma_i \delta_i))$, where $T_i = \prod_{j=1}^{i-1} (1 - \rho_j)$ is the accumulated transmittance, $\rho_i = 1 - \exp(-\sigma_i \delta_i)$ is the opacity, and $\delta_i = t_{i+1} - t_i$ [S1].
- **Expected Depth**: $\mathbf{D}(\mathbf{r}) = \frac{\sum_{i=1}^N w_i t_i}{\sum_{i=1}^N w_i}$ [S1].

**Formulas**
The total loss is defined as [S1]:
$$ \mathcal{L}_{\text{geom}} = \mathcal{L}_{\text{photo}} + \lambda_{\text{fg}} \mathcal{L}_{\text{fg}} + \lambda_{\text{fr}} \mathcal{L}_{\text{fr}} + \lambda_{\text{dist}} \mathcal{L}_{\text{dist}} $$

1.  **Photometric Loss**: L2 difference between input image $I_i$ and rendered color $\mathbf{C}_i$ [S1]:
    $$ \mathcal{L}_{\text{photo}}(\sigma, \mathbf{c}) = \sum_{i=1}^{\mathcal{I}} ||I_i - \mathbf{C}_i||_2 $$

2.  **Foreground Loss ($\mathcal{L}_{\text{fg}}$)**: Encourages weights to sum to unity, ensuring rays are fully absorbed by scene geometry [S1]:
    $$ \mathcal{L}_{\text{fg}} = \left( 1 - \sum_{i=1}^N w_i \right)^2 $$

3.  **Frustum Loss ($\mathcal{L}_{\text{fr}}$)**: Penalizes density placed in only one view frustum to prevent "image plane" collapse [S1]:
    $$ \mathcal{L}_{\text{fr}} = \sum_i w_i \mathbf{1}(n_i \le 1) $$
    where $n_i$ is the number of training view frustums containing the point $\mathbf{r}(t_i)$, and $\mathbf{1}(\cdot)$ is the indicator function [S1].

4.  **Distribution Loss ($\mathcal{L}_{\text{dist}}$)**: Regularizes weights to have a compact distribution, deviating from the original formulation by dividing by expected depth to increase strength for geometry close to the camera [S1]:
    $$ \mathcal{L}_{\text{dist}} = \frac{1}{\mathbf{D}(\mathbf{r})} \left( \sum_{i,j} w_i w_k \left| \frac{t_i + t_{i+1}}{2} - \frac{t_j + t_{j+1}}{2} \right| + \frac{1}{3} \sum_{i=1}^N w_i^2 (t_{i+1} - t_i) \right) $$
    *Note: The source uses indices $i,j$ and $k$ in the summation term $\sum_{i,j} w_i w_k$. Context implies $k$ corresponds to the second index of the pair, effectively summing over pairs of samples.* [S1].

**Parameters**
- $\lambda_{\text{fg}}, \lambda_{\text{fr}}$: Coefficients for foreground and frustum losses. Values not explicitly given in the sources, assumed to be 1 or standard weights unless specified [S1].
- $\lambda_{\text{dist}}$: Weight for the distribution regularizer. It is 0 for the first 2500 steps, then linearly increases to $1 \times 10^{-4}$ for the DTU dataset and $1.5 \times 10^{-5}$ for the LLFF dataset at 8000 steps [S1].

**Pseudocode**
```python
def geometric_baseline_loss(rendered_colors, target_images, weights, depths, 
                            frustum_counts, lambda_fg, lambda_fr, lambda_dist, 
                            step, max_steps=8000, dataset='DTU'):
    """
    Computes the Geometric Baseline Loss.
    
    Args:
        rendered_colors: Rendered color for each ray.
        target_images: Ground truth images.
        weights: Rendering weights w_i for each sample on each ray.
        depths: Sample depths t_i.
        frustum_counts: Number of training view frustums n_i for each sample.
        lambda_fg: Weight for foreground loss.
        lambda_fr: Weight for frustum loss.
        lambda_dist: Weight for distribution loss.
        step: Current training step.
        max_steps: Steps at which lambda_dist reaches max value.
        dataset: 'DTU' or 'LLF'.
        
    Returns:
        Total loss scalar.
    """
    # 1. Photometric Loss
    photo_loss = sum(l2_norm(img - pred) for img, pred in zip(target_images, rendered_colors))
    
    # 2. Foreground Loss: Encourage sum of weights to be 1
    # Sum weights over all samples for each ray, then square (1 - sum)
    # Assuming weights is a list of arrays, one per ray
    ray_weight_sums = [sum(w) for w in weights]
    fg_loss = sum((1 - s)**2 for s in ray_weight_sums)
    
    # 3. Frustum Loss: Penalize weights in only one frustum
    fr_loss = 0
    for w, n in zip(weights, frustum_counts):
        # w is array of weights, n is array of counts (or scalar if per-sample)
        # Indicator function: 1 if n <= 1, else 0
        mask = [1 if count <= 1 else 0 for count in n]
        fr_loss += sum(w_i * m for w_i, m in zip(w, mask))
        
    # 4. Distribution Loss
    # Calculate expected depth D(r) for each ray
    expected_depths = []
    for w, d in zip(weights, depths):
        numerator = sum(w_i * d_i for w_i, d_i in zip(w, d))
        denominator = sum(w)
        # Avoid division by zero
        if denominator > 1e-8:
            expected_depths.append(numerator / denominator)
        else:
            expected_depths.append(1.0) # Fallback
            
    dist_loss = 0
    for w, d, D in zip(weights, depths, expected_depths):
        if D < 1e-8:
            continue
            
        # Term 1: Sum over pairs i, j of |mid_i - mid_j| * w_i * w_k
        # Note: Source uses w_k, assumed to be w_j for the second element of the pair
        pair_sum = 0
        N = len(w)
        for i in range(N):
            mid_i = (d[i] + d[i+1]) / 2
            for j in range(N):
                mid_j = (d[j] + d[j+1]) / 2
                pair_sum += w[i] * w[j] * abs(mid_i - mid_j)
                
        # Term 2: 1/3 * sum(w_i^2 * delta_i)
        delta_sum = 0
        for i in range(N):
            delta = d[i+1] - d[i]
            delta_sum += (w[i]**2) * delta
            
        ray_dist = (pair_sum + (1/3) * delta_sum) / D
        dist_loss += ray_dist
        
    # Schedule lambda_dist
    if step < 2500:
        current_lambda_dist = 0
    else:
        # Linear increase from 0 to max_val
        progress = (step - 2500) / (max_steps - 2500)
        max_val = 1e-4 if dataset == 'DTU' else 1.5e-5
        current_lambda_dist = progress * max_val
        
    total_loss = photo_loss + lambda_fg * fg_loss + lambda_fr * fr_loss + current_lambda_dist * dist_loss
    return total_loss
```

**Edge Cases and Pitfalls**
- **Division by Zero**: The distribution loss divides by expected depth $\mathbf{D}(\mathbf{r})$. If a ray has no absorption (sum of weights $\approx 0$), depth is undefined. A guard or fallback is required [S1, G].
- **Few-View Collapse**: Without $\mathcal{L}_{\text{fr}}$, NeRFs may collapse to copying training images. This loss specifically targets density located in only one view frustum [S1].
- **Depth Scaling**: The division by $\mathbf{D}(\mathbf{r})$ in $\mathcal{L}_{\text{dist}}$ increases the regularizer's strength for geometry close to the camera, which is a deviation from the original formulation [S1].

## Operating characteristics
- **Time Complexity**: The distribution loss involves a pairwise summation over samples $O(N^2)$ per ray, which can be computationally expensive for large $N$. The other losses are $O(N)$.
- **Memory Complexity**: Requires storing weights, depths, and frustum counts for all samples.
- **Strengths**: Provides a robust baseline for few-view reconstruction without requiring external depth maps or point clouds. It effectively prevents degenerate solutions [S1].
- **Limitations**: The $O(N^2)$ term in $\mathcal{L}_{\text{dist}}$ may be prohibitive for high-resolution rendering or large numbers of samples. The effectiveness depends on careful tuning of $\lambda_{\text{dist}}$ schedule [S1].

## Background
The Geometric Baseline Regularization was introduced in the context of regularizing NeRFs using Denoising Diffusion Models, specifically in the work "DiffusioNeRF" [S1]. It builds upon the probabilistic interpretation of volume rendering, where rendering weights are viewed as a probability distribution [S1]. The method was proposed to address the issue of degenerate solutions in few-view settings, such as the "image plane" collapse, by enforcing geometric priors directly on the rendered weights [S1].
