# Confidence-Based Loss Calibration

Also called: ICON, Incremental Confidence

## Overview
Confidence-Based Loss Calibration (ICON) solves the problem of joint optimization instability in NeRF and camera pose estimation by dynamically weighting gradients based on the reliability of the current solution state [S1]. It sets itself apart from sibling methods like [RegNeRF](8582-regnerf.md) or [Depth and Geometry Supervision](8727-depth-and-geometry-supervision.md) by explicitly decoupling the confidence of the radiance field from the confidence of the camera poses, using these metrics to modulate the respective gradient updates rather than applying static regularization terms [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Current NeRF parameters $\Theta$, current pose estimates $\hat{P} = \{P_i\}$, ground truth images $I$, and hyperparameters $\beta$ (momentum), $\lambda$ (re-init threshold), $K$ (window size).
*   **Outputs:** Updated $\Theta$, updated $\hat{P}$, and confidence scores $\zeta^P$ (pose confidence) and $\zeta^r$ (ray confidence).

**Data Structures:**
*   $\zeta^P_i$: Scalar pose confidence for image $i$.
*   $\zeta^r_{ji}$: Scalar ray confidence for ray $j$ from pose $i$.
*   History buffer: Stores the last $K$ pose confidences for re-initialization checks.

**Numbered Steps:**
1.  **Ray Sampling:** For each pose $P_i$, sample a set of rays $\{r_{ji}\}_{j=1}^B$.
2.  **Ray Confidence Update:** Compute ray confidence $\zeta^r_{ji}$ based on the consistency of the rendered ray against the ground truth or other metrics (e.g., photometric error). The specific formula for $\zeta^r$ is not detailed in the source beyond its usage in weighting [S1].
3.  **Pose Confidence Update:** Update the running average pose confidence $\zeta^P_i$ using exponential moving average with momentum $\beta$:
    $$ \zeta^P_i = \beta \zeta^P_{i-1} + (1 - \beta) \frac{1}{B} \sum_{j=1}^B \zeta^r_{ji} $$
    Typical value for $\beta$ is 0.9 [S1].
4.  **Loss Calibration:** Compute the calibrated losses:
    *   **NeRF Loss:** Weight the total NeRF loss by the pose confidence $\zeta^P_i$. This down-weights gradients for $\Theta$ when the pose is uncertain:
        $$ \mathcal{L}_{\text{NeRF}}(\Theta|\hat{P}, I) = \frac{\sum_{i} \sum_{j} \mathcal{L}(r_{ji}) \zeta^P_i}{\sum_{i} \zeta^P_i} $$
    *   **Pose Loss:** Weight the per-ray loss by the ray confidence $\zeta^r_{ji}$. This down-weights gradients for $P_i$ when specific rays are unreliable:
        $$ \mathcal{L}_{\text{Pose}}(\hat{P}|\Theta, I) = \frac{\sum_{i} \sum_{j} \mathcal{L}(r_{ji}) \zeta^r_{ji}}{\sum_{i} \sum_{j} \zeta^r_{ji}} $$
    *   **Total Loss:**
        $$ \mathcal{L}_{\text{all}}(\Theta, \hat{P}|I) = \mathcal{L}_{\text{NeRF}} + \mathcal{L}_{\text{Pose}} + \mathcal{L}_{\text{conf}} $$
        Note: $\mathcal{L}_{\text{conf}}$ is mentioned in the total loss equation but its specific formulation is not provided in the source [S1].
5.  **Pose Re-initialization (Guard):** If a new pose $P_i$ fails to register, restart it from the previous pose. Failure is declared if the new pose confidence drops abruptly:
    $$ \zeta^P_i \leq \text{mean}(\{\zeta^P_j\}_{j=i-K}^{i-1}) - \lambda \cdot \text{std}(\{\zeta^P_j\}_{j=i-K}^{i-1}) $$
    Typical values: $\lambda = 2$, $K = 10$ [S1].

**Pseudocode:**
```python
def confidence_calibration_step(nerf_params, poses, images, history_buffer, beta=0.9, lambda_thresh=2, K=10):
    """
    Performs one step of confidence-based loss calibration.
    Returns updated nerf_params, poses, and history_buffer.
    """
    total_neurf_grad = 0
    total_neurf_weight = 0
    total_pose_grad = 0
    total_pose_weight = 0
    
    # 1. Compute Ray and Pose Confidences
    pose_confidences = []
    for i, pose in enumerate(poses):
        rays = sample_rays(pose, images[i])
        ray_confidences = []
        for j, ray in enumerate(rays):
            # Compute ray confidence based on photometric error or similar metric
            # Specific formula for zeta_r is not given, assumed to be a scalar in [0,1]
            ray_conf = compute_ray_confidence(ray, images[i]) 
            ray_confidences.append(ray_conf)
        
        # Update pose confidence using EMA
        if i == 0:
            pose_conf = mean(ray_confidences)
        else:
            prev_pose_conf = pose_confidences[-1] if pose_confidences else 0
            pose_conf = beta * prev_pose_conf + (1 - beta) * mean(ray_confidences)
        
        pose_confidences.append(pose_conf)
        
        # 2. Calibrate Gradients
        # NeRF Loss: Weighted by Pose Confidence
        # L_NeRF = sum(L(r) * zeta_P) / sum(zeta_P)
        # We accumulate weighted gradients for backprop
        for j, ray in enumerate(rays):
            loss_val = compute_loss(ray, images[i])
            grad_neurf = compute_gradient(loss_val, nerf_params)
            grad_pose = compute_gradient(loss_val, pose)
            
            # Accumulate for NeRF update
            total_neurf_grad += grad_neurf * pose_conf
            total_neurf_weight += pose_conf
            
            # Accumulate for Pose update
            total_pose_grad += grad_pose * ray_confidences[j]
            total_pose_weight += ray_confidences[j]
            
    # 3. Apply Updates
    if total_neurf_weight > 0:
        nerf_grads = total_neurf_grad / total_neurf_weight
        update(nerf_params, nerf_grads)
        
    if total_pose_weight > 0:
        pose_grads = total_pose_grad / total_pose_weight
        update(poses, pose_grads)
        
    # 4. Pose Re-initialization Check
    if len(pose_confidences) > K:
        recent_confs = pose_confidences[-K:]
        mean_conf = mean(recent_confs)
        std_conf = std(recent_confs)
        current_conf = pose_confidences[-1]
        
        if current_conf < mean_conf - lambda_thresh * std_conf:
            # Restart pose from previous
            poses[-1] = poses[-2]
            # Re-compute confidence for the restarted pose?

            # likely resetting the pose and re-evaluating.
            pass
            
    history_buffer.append(pose_confidences[-1])
    if len(history_buffer) > K:
        history_buffer.pop(0)
        
    return nerf_params, poses, history_buffer
```

## Subtopics

### Learnable Confidence Combination
A method to compute a robust confidence map by defining learnable weights for individual confidence metrics and jointly optimizing them during training [S2, unofficial]. The final confidence map is learned as $\hat{C} = \sum_i \omega_i C_i$, where $\sum_i \omega_i = 1$. The set of metrics $i \in \{\text{rgb, ssim, vgg, depth, flow}\}$ represents optional confidence metrics. The learnable weights $\omega$ adapt the model to automatically focus on correct confidence [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Adds overhead for computing ray/pose confidences and maintaining the EMA history buffer. The re-initialization check is $O(K)$ per pose update.
*   **Memory Complexity:** Requires storing the last $K$ pose confidences.
*   **Strengths:** Stabilizes joint optimization of NeRF and poses, particularly in incremental SfM scenarios where initial poses are poor [S1].
*   **Limitations:** Requires careful tuning of $\beta$, $\lambda$, and $K$. The specific formulation of $\mathcal{L}_{\text{conf}}$ is not provided, which may limit reproducibility [S1].
*   **When to use:** Joint optimization of radiance fields and camera poses, especially in incremental or challenging registration scenarios.
*   **When not to use:** Static pose scenarios where pose optimization is not required.

## Background
ICON (Incremental Confidence) was introduced by Schonberger and Frahm (2016) in the context of incremental SfM, though the specific application to NeRF confidence-based loss calibration is detailed in the 2024 paper "ICON: Incremental CONfidence for Joint Pose and Radiance Field Optimization" [S1]. It builds on trial-and-error registration mechanisms [S1].
