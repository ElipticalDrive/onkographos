# CLIP Similarity Loss

Also called: CLIP Loss, Image-Text CLIP Loss

## Overview
A loss function that quantifies the semantic alignment between a rendered image and a text prompt by measuring their distance in the CLIP embedding space. It differs from photometric losses by enforcing high-level semantic consistency rather than pixel-wise color accuracy, and from directional losses by measuring absolute alignment rather than relative change [S1].

## How it works
**Inputs and outputs:**
- Input: A rendered image $I$ and a text prompt $T$.
- Output: A scalar loss value $L_{CLIP}$.

**Data structures:**
- Pre-trained CLIP Image Encoder $E_{img}$: A neural network (typically ViT) mapping an image to a normalized feature vector.
- Pre-trained CLIP Text Encoder $E_{txt}$: A neural network (typically Transformer) mapping a text prompt to a normalized feature vector.
- Feature vectors: $v_{img} = E_{img}(I)$ and $v_{txt} = E_{txt}(T)$, both in $\mathbb{R}^d$ with unit L2 norm.

**Steps:**
1. Encode the rendered image $I$ using the frozen CLIP image encoder to obtain the image embedding $v_{img} = E_{img}(I)$.
2. Encode the text prompt $T$ using the frozen CLIP text encoder to obtain the text embedding $v_{txt} = E_{txt}(T)$.
3. Compute the cosine similarity between the two embeddings:
   $$sim(v_{img}, v_{txt}) = \frac{v_{img} \cdot v_{txt}}{\|v_{img}\|_2 \|v_{txt}\|_2}$$
   Since CLIP embeddings are typically normalized, this simplifies to the dot product $v_{img} \cdot v_{txt}$.
4. Calculate the loss as one minus the similarity:
   $$L_{CLIP}(I, T) = 1 - sim(v_{img}, v_{txt})$$

**Parameters:**
- None. The encoders are pre-trained and frozen.

**Edge cases and pitfalls:**
- The loss is bounded between $0$ and $2$. A value of $0$ indicates perfect alignment.
- Gradient flow depends on the differentiability of the rendering process feeding into $E_{img}$.
- Text prompts must be tokenized consistently with the CLIP model's expected input format.

```python
def clip_similarity_loss(rendered_image, text_prompt, clip_image_encoder, clip_text_encoder):
    """
    Computes the CLIP similarity loss between a rendered image and a text prompt.
    
    Args:
        rendered_image: Tensor of shape (H, W, 3) or (3, H, W), pixel values in [0, 1].
        text_prompt: String representing the text description.
        clip_image_encoder: Pre-trained, frozen CLIP image encoder.
        clip_text_encoder: Pre-trained, frozen CLIP text encoder.
        
    Returns:
        Scalar loss value.
    """
    # 1. Encode image
    # Ensure image is in the correct format for the encoder (e.g., normalized to [-1, 1] or [0, 1])
    # and batched if necessary.
    image_embedding = clip_image_encoder(rendered_image)
    
    # 2. Encode text
    # Tokenize text prompt appropriately for the CLIP model
    text_embedding = clip_text_encoder(text_prompt)
    
    # 3. Normalize embeddings (if not already normalized by the encoder)
    image_embedding = image_embedding / torch.norm(image_embedding)
    text_embedding = text_embedding / torch.norm(text_embedding)
    
    # 4. Compute cosine similarity
    similarity = torch.dot(image_embedding, text_embedding)
    
    # 5. Compute loss
    loss = 1.0 - similarity
    
    return loss
```

## Subtopics

## Operating characteristics
- **Time complexity:** Dominated by the forward pass of the CLIP encoders, which are relatively lightweight compared to the NeRF itself but add significant overhead per iteration.
- **Memory complexity:** Requires storing the CLIP model weights in memory.
- **Strengths:** Enables semantic editing and text-guided generation without 3D ground truth labels.
- **Limitations:** Lacks fine-grained geometric or photometric detail; can lead to blurry or semantically correct but visually inconsistent results if used alone.
- **When to use:** When semantic consistency is more important than photometric accuracy, or for text-guided editing.
- **When not to use:** When high-fidelity photometric reconstruction is the primary goal.

## Background
Originated from the CLIP model (Contrastive Language-Image Pre-training) by OpenAI, which trained image and text encoders using contrastive learning [S1]. In the context of NeRF, CLIP-NeRF was the pioneering method to introduce this loss for disentangled conditional NeRF editing [S1].
