# Direct Depth Supervision

Also called: Direct supervision, L1 depth loss, MSE depth loss

## Overview
Direct Depth Supervision is a regularization technique in differentiable volume rendering that minimizes the pixel-wise discrepancy between the depth map rendered by the neural radiance field and a provided ground truth depth prior [S1]. It explicitly constrains the geometric structure of the scene, distinguishing it from photometric losses that enforce color consistency . Unlike indirect methods that enforce geometric consistency through other signals, this approach directly penalizes errors in the expected depth value [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A batch of $N_r$ camera rays $\{r_i\}_{i=1}^{N_r}$, where each ray $r_i$ is defined by origin $o_i$ and direction $d_i$. Ground truth depth values $\{D(r_i)\}_{i=1}^{N_r}$ corresponding to these rays.
*   **Outputs:** A scalar loss value $\mathcal{L}_d$ used for backpropagation to update network parameters $\theta$ (density $\sigma$ and color $\mathbf{c}$).

**Data Structures:**
*   **Rendered Depth:** For each ray $r_i$, the rendered depth $\hat{D}(r_i)$ is computed as the expected distance along the ray using the standard volume rendering equation [S1]:
    $$ \hat{D}(r_i) = \sum_{k=1}^N w_{i,k} t_{i,k} $$
    where $t_{i,k}$ is the sample depth along ray $i$ at index $k$, and $w_{i,k}$ is the rendering weight:
    $$ w_{i,k} = T_{i,k} (1 - \exp(-\sigma_{i,k} \delta_{i,k})) $$
    with accumulated transmittance $T_{i,k} = \prod_{j=1}^{k-1} (1 - \rho_{i,j})$ and opacity $\rho_{i,k} = 1 - \exp(-\sigma_{i,k} \delta_{i,k})$ [S1].

**Algorithm Steps:**
1.  Sample a batch of $N_r$ rays from the training camera poses [S1].
2.  For each ray $r_i$, query the neural network for density $\sigma$ and color $\mathbf{c}$ at sample points $t_{i,k}$ [S1].
3.  Compute rendering weights $w_{i,k}$ and accumulated transmittance $T_{i,k}$ [S1].
4.  Calculate the rendered depth $\hat{D}(r_i)$ for each ray [S1].
5.  Retrieve the ground truth depth $D(r_i)$ for each ray from the depth prior [S1].
6.  Compute the loss using either Mean Squared Error (MSE) or L1 norm [S1].

**Formulas:**
The loss function $\mathcal{L}_d$ is defined as:

For MSE Loss:
$$ \mathcal{L}_d^{\text{MSE}} = \frac{1}{N_r} \sum_{i=1}^{N_r} \| D(r_i) - \hat{D}(r_i) \|^2 \quad (3) $$

For L1 Loss:
$$ \mathcal{L}_d^{\text{L1}} = \frac{1}{N_r} \sum_{i=1}^{N_r} | D(r_i) - \hat{D}(r_i) | \quad (4) $$

where $D(r_i)$ is the ground truth depth and $\hat{D}(r_i)$ is the rendered depth for ray $r_i$ [S1].

**Parameters:**
*   $N_r$: Batch size of rays. Typical values are not specified in the sources.
*   Loss Type: Either MSE or L1. Both are included in experimental setups [S1].

**Edge Cases and Pitfalls:**
*   **Depth Prior Quality:** The method relies on the accuracy of the ground truth depth prior. If the prior is noisy or sparse (e.g., raw LiDAR), the supervision may introduce artifacts [S1].
*   **Ambiguity:** In regions with low texture or transparency, the rendered depth may be ambiguous, leading to high loss values even if the color is correct [S1].
*   **Precision:** Standard floating-point precision is assumed for the summation in the depth calculation [S1].

**Pseudocode:**
```python
def direct_depth_supervision(rays, gt_depths, nerf_model, num_samples):
    """
    Computes direct depth supervision loss.
    
    Args:
        rays: List of ray origins and directions.
        gt_depths: Ground truth depth values for each ray.
        nerf_model: Neural Radiance Field model.
        num_samples: Number of samples per ray.
        
    Returns:
        loss: Scalar loss value.
    """
    rendered_depths = []
    
    for ray in rays:
        # Sample points along the ray
        t_vals = sample_points(ray.origin, ray.direction, num_samples)
        
        # Query network for density
        sigma_vals = []
        for t in t_vals:
            sigma = nerf_model.query_density(ray.origin, ray.direction, t)
            sigma_vals.append(sigma)
            
        # Compute rendering weights
        weights = []
        transmittance = 1.0
        for i, sigma in enumerate(sigma_vals):
            delta = t_vals[i+1] - t_vals[i] if i < len(t_vals) - 1 else 0.0
            opacity = 1.0 - exp(-sigma * delta)
            weight = transmittance * opacity
            weights.append(weight)
            transmittance *= (1.0 - opacity)
            
        # Compute rendered depth
        rendered_depth = sum(w * t for w, t in zip(weights, t_vals))
        rendered_depths.append(rendered_depth)
        
    # Compute loss
    # Using L1 loss as an example; MSE can be used similarly
    loss = sum(abs(gt - pred) for gt, pred in zip(gt_depths, rendered_depths)) / len(rays)
    
    return loss
```

## Subtopics

### [Direct Depth Supervision (L1)](16850-direct-depth-supervision-l1.md)
Uses the mean absolute error metric, which is less sensitive to outliers in depth prediction compared to L2. Choose this when depth priors contain significant noise or outliers.
- [Direct Depth Supervision (MSE)]: Uses the mean squared error metric. Choose this when depth priors are dense and accurate, as it penalizes large errors more heavily than L1.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of rays $N_r$ and samples per ray $N$. The dominant cost is the forward pass through the neural network to compute densities [S1].
*   **Memory Complexity:** Linear with respect to $N_r \times N$ to store intermediate values (weights, transmittances) for backpropagation [S1].
*   **Strengths:** Directly enforces geometric accuracy; simple to implement; differentiable [S1].
*   **Limitations:** Sensitive to the quality of the depth prior; may struggle with sparse or noisy depth data if not regularized [S1].
*   **When to use:** When high-quality depth priors (e.g., from LiDAR or stereo matching) are available and geometric accuracy is prioritized over photometric consistency [S1].
*   **When not to use:** When depth priors are unreliable or absent [S1].

## Background
Direct Depth Supervision was introduced as part of the broader effort to integrate depth priors into Neural Radiance Fields (NeRF) for outdoor scenes [S1]. The method leverages the differentiability of volume rendering to backpropagate gradients from depth errors to the network parameters, enabling joint optimization of color and geometry [S1, 8582-regnerf.md]. It is a foundational technique in depth-supervised NeRF frameworks [S1].
