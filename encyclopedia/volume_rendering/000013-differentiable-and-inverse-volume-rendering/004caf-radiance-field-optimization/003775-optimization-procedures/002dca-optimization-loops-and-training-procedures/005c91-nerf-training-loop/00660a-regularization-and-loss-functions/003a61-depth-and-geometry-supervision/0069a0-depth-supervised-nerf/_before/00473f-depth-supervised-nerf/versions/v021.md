# Depth-Supervised NeRF

Also called: DS-NeRF

## Overview
Depth-Supervised NeRF (DS-NeRF) is a training procedure for Neural Radiance Fields that incorporates sparse 3D depth supervision from Structure-from-Motion (SfM) point clouds to accelerate convergence and improve reconstruction quality with fewer input views [S1, S2][S3, unofficial]. Unlike methods relying on category-specific priors or dense multi-view stereo (MVS) initialization, DS-NeRF treats the sparse keypoints generated during standard SfM preprocessing as "free" geometric constraints, enforcing that the rendered ray termination distribution aligns with these surface priors [S1]. This approach reduces overfitting in sparse-view settings and typically achieves target quality in 2–3× fewer training iterations than standard NeRF [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ training images $\{I_j\}$ with known camera poses $\{P_j\}$ (estimated via SfM, e.g., COLMAP); sparse 3D keypoints $\{X\}$ and their visibility flags from the SfM pipeline; near and far clipping bounds $t_n, t_f$ for ray marching.
*   **Outputs:** A trained NeRF model (MLP parameters $\theta$ for density $\sigma$ and color $\mathbf{c}$) capable of rendering novel views.

**Data Structures:**
*   **Keypoints:** A set $X = \{x_i\}$ where each $x_i \in \mathbb{R}^3$.
*   **Visibility:** For each image $j$, a subset $X_j \subset X$ of keypoints visible from camera $P_j$.
*   **Depth Estimates:** For each visible keypoint $x_i \in X_j$, a scalar depth $D_{ij}$ and uncertainty $\hat{\sigma}_i$.
*   **Ray Termination Distribution:** Discretized values $h_k = h(t_k)$ computed during volume rendering.

**Step-by-Step Method:**

1.  **SfM Preprocessing:** Run an SfM solver (e.g., COLMAP) on the input images to estimate camera poses $P_j$ and reconstruct a sparse 3D point cloud $X$ [S1][S3, unofficial].
2.  **Depth and Uncertainty Estimation:**
    *   For each image $I_j$ and camera $P_j$, identify visible keypoints $X_j$ [S1].
    *   Compute the projected depth $D_{ij}$ for each $x_i \in X_j$ by projecting $x_i$ with $P_j$ and taking the re-projected z-value (depth along the camera axis) [S1].
    *   Compute the depth uncertainty $\hat{\sigma}_i$ for each keypoint $x_i$ as the average reprojection error across all views where $x_i$ was detected [S1].
    *   Model the true depth of the first surface as a random variable $D_{ij} \sim \mathcal{N}(D_{ij}, \hat{\sigma}_i)$ [S1].
3.  **Ray Generation for Supervision:**
    *   For each detected keypoint $x_i \in X_j$, define a ray $\mathbf{r}$ originating from the camera center $o_j$ with direction $\mathbf{d}$ pointing towards the projection of $x_i$ on the image plane [S1].
    *   In local camera coordinates, the ray direction is derived from the keypoint's image coordinates $(u, v)$ and $-1$ in the camera axis [S1].
    *   *Note:* To combine color and depth supervision efficiently, the method exploits the continuity of image coordinates. Rays corresponding to keypoints are sampled within the same ray marching procedure used for standard pixel rays, interpolating RGB supervision values for these specific rays [S1].
4.  **Volume Rendering:**
    *   Shoot rays $\mathbf{r}$ into the scene using standard NeRF sampling between $t_n$ and $t_f$ [S1].
    *   Compute the ray termination distribution $h(t) = T(t)\sigma(t)$, where $T(t) = \exp(-\int_0^t \sigma(s)ds)$ is the transmittance [S1].
    *   Discretize this distribution at sample points $t_k$ with step size $\Delta t_k$: $h_k = h(t_k)$ [S1].
    *   Compute the rendered color $\hat{\mathbf{C}}(\mathbf{r})$ and rendered depth $\hat{D}(\mathbf{r})$ [S1, S4].
5.  **Loss Computation:**
    *   **Color Loss:** Standard photometric loss $L_{Color} = \|\hat{\mathbf{C}}(\mathbf{r}) - \mathbf{I}[u, v]\|_2^2$ [S1, S4].
    *   **Depth Loss:** Minimize the KL divergence between the rendered ray termination distribution $h(t)$ and the noisy depth distribution $\mathcal{N}(D_{ij}, \hat{\sigma}_i)$ [S1]. The loss is approximated as:
        $$ L_{Depth} = \mathbb{E}_{x_i \in X_j} \left[ \sum_k -\log h_k \exp \left( -\frac{(t_k - D_{ij})^2}{2\hat{\sigma}_i^2} \right) \Delta t_k \right] $$
        where $t_k$ are the sample depths along the ray [S1].
        *Alternative:* An MSE loss between rendered depth and $D_{ij}$ can be used, but KL divergence yields fewer artifacts [S1][S3, unofficial].
    *   **Total Loss:**
        $$ L = L_{Color} + \lambda_D L_{Depth} $$
        where $\lambda_D$ is a hyperparameter balancing the terms [S1].
6.  **Optimization:** Update network parameters $\theta$ using gradients backpropagated through the differentiable volume rendering process [S1, S2].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def compute_ray_termination_distribution(sigma, t_starts, t_ends):
    """
    Computes the ray termination distribution h(t) = T(t) * sigma(t).
    Args:
        sigma: Tensor of shape (..., num_samples), differential density.
        t_starts: Tensor of shape (..., num_samples), start depths.
        t_ends: Tensor of shape (..., num_samples), end depths.
    Returns:
        h: Tensor of shape (..., num_samples), termination distribution values.
        T: Tensor of shape (..., num_samples), accumulated transmittance.
    """
    # Delta distances
    deltas = t_ends - t_starts
    
    # Density-weighted opacity
    # rho = 1 - exp(-sigma * delta)
    # However, for h(t), we need T(t) * sigma(t)
    # T(t_i) = product_{j<i} (1 - rho_j)
    
    # Compute transmittance T
    # log_T = sum_{j<i} log(1 - rho_j)
    # Using the approximation from NeRF: T_i = exp(-sum_{j<i} sigma_j * delta_j)
    
    # Accumulated sigma * delta
    # We need the sum up to i-1. 
    # Let's compute cumulative sum of sigma * delta
    sigma_delta = sigma * deltas
    cum_sigma_delta = torch.cumsum(sigma_delta, dim=-1)
    
    # T_i = exp(-cumulative_sum_before_i)
    # Shift cum_sigma_delta to get sum before i
    # T_0 = 1 (exp(0))
    # T_i = exp(-sum_{j=0}^{i-1} sigma_j * delta_j)
    
    # Create shifted version
    # T = exp(-cumsum[:-1] padded with 0)
    # But we need T for each sample i.
    # T_i = exp(- (cum_sigma_delta[..., i-1] if i>0 else 0))
    
    # Efficiently:
    # log_T = -torch.cat([torch.zeros_like(cum_sigma_delta[..., :1]), cum_sigma_delta[..., :-1]], dim=-1)
    # T = torch.exp(log_T)
    
    # Alternative standard NeRF implementation:
    # T = torch.exp(-torch.cumsum(sigma_delta[..., :-1], dim=-1)) # This is T for the *next* sample?
    # Let's stick to the definition: h(t_i) = T(t_i) * sigma(t_i)
    # T(t_i) = exp(- integral_0^{t_i} sigma(s) ds)
    
    # Approximation: integral_0^{t_i} sigma(s) ds approx sum_{j=0}^{i-1} sigma_j * delta_j
    # So T_i = exp(- sum_{j=0}^{i-1} sigma_j * delta_j)
    
    # Compute cumulative sum of sigma * delta
    # We need the sum *before* the current sample
    cum_sum = torch.cumsum(sigma_delta, dim=-1)
    # Shift right by 1, fill with 0
    T = torch.exp(-torch.cat([torch.zeros_like(cum_sum[..., :1]), cum_sum[..., :-1]], dim=-1))
    
    # h(t) = T(t) * sigma(t)
    h = T * sigma
    
    return h, T

def depth_supervised_nerf_loss(sigma, t_starts, t_ends, keypoints_depths, keypoint_uncertainties, 
                               rendered_colors, gt_colors, ray_indices_for_keypoints):
    """
    Computes the combined loss for DS-NeRF.
    Args:
        sigma: (num_rays, num_samples)
        t_starts: (num_rays, num_samples)
        t_ends: (num_rays, num_samples)
        keypoints_depths: (num_keypoint_rays,) Depth D_ij from SfM
        keypoint_uncertainties: (num_keypoint_rays,) Uncertainty sigma_hat_i
        rendered_colors: (num_rays, 3)
        gt_colors: (num_rays, 3)
        ray_indices_for_keypoints: List of indices in the batch corresponding to keypoint rays
    Returns:
        total_loss: scalar
    """
    # 1. Color Loss for all rays
    color_loss = F.mse_loss(rendered_colors, gt_colors)
    
    # 2. Depth Loss for keypoint rays
    if len(ray_indices_for_keypoints) == 0:
        return color_loss
        
    # Extract sigma and t for keypoint rays
    sigma_k = sigma[ray_indices_for_keypoints]
    t_starts_k = t_starts[ray_indices_for_keypoints]
    t_ends_k = t_ends[ray_indices_for_keypoints]
    
    # Compute h(t) for keypoint rays
    h, _ = compute_ray_termination_distribution(sigma_k, t_starts_k, t_ends_k)
    
    # Discretization step size
    deltas = t_ends_k - t_starts_k
    
    # KL Divergence approximation:
    # L_depth = sum_k -log(h_k) * exp(-(t_k - D_ij)^2 / (2 * sigma_hat_i^2)) * delta_t_k
    # Note: The source formula uses -log(h) * Gaussian. This is effectively minimizing KL(h || Gaussian) 
    # up to a constant, or maximizing the likelihood of h under the Gaussian model?
    # Source [S1]: L_Depth = E [ -log h(t) exp( -(t-D)^2 / 2sigma^2 ) ] dt
    # This is equivalent to minimizing KL( Gaussian || h )? 
    # KL(P||Q) = sum P log(P/Q). If P is Gaussian and Q is h.
    # sum Gaussian * log(Gaussian / h) = sum Gaussian * log(Gaussian) - sum Gaussian * log(h)
    # The source formula is sum -log(h) * Gaussian. This matches the second term.
    
    depths = keypoints_depths[ray_indices_for_keypoints]
    uncertainties = keypoint_uncertainties[ray_indices_for_keypoints]
    
    # Gaussian term
    # exp( -(t - D)^2 / (2 * sigma^2) )
    gaussian_term = torch.exp(-((t_starts_k + deltas/2) - depths.unsqueeze(1))**2 / (2 * uncertainties.unsqueeze(1)**2))
    
    # Log h
    # Clamp h to avoid log(0)
    h_clamped = torch.clamp(h, min=1e-6)
    log_h = torch.log(h_clamped)
    
    # Loss term
    depth_loss_per_ray = -log_h * gaussian_term * deltas
    depth_loss = torch.mean(torch.sum(depth_loss_per_ray, dim=-1))
    
    # Total Loss
    lambda_d = 1.0 # Empirically set to 1 [S4]
    total_loss = color_loss + lambda_d * depth_loss
    
    return total_loss
```

**Parameters:**
*   $\lambda_D$: Depth loss weight. Empirically set to 1 [S4].
*   $t_n, t_f$: Near and far clipping planes. $t_f$ is often treated as an opaque wall to ensure $\int h(t)dt = 1$ [S1].
*   Training Iterations: Typically $10,000 - 100,000$ [S3, unofficial].
*   Image Resolution: $400 \times 300$ in standard experiments [S1].

**Edge Cases and Pitfalls:**
*   **SfM Failure:** Optimization fails if SfM produces poor depth estimates or inaccurate depth measurements [S1].
*   **Gaussian Assumption:** The method assumes a Gaussian distribution models keypoint uncertainty, which may not hold for depth from non-SfM sources (e.g., noisy sensors) [S1].
*   **Domain Gap:** While DS-NeRF itself generalizes, combining it with other methods (like pixelNeRF) may suffer if there is a domain gap between pre-training data and test data [S1].
*   **MVSNeRF Compatibility:** Adding depth supervision did not improve MVSNeRF because it already possesses a strong geometry prior via PSV initialization [S1].

## Operating characteristics
*   **Time Complexity:** Training iterations are reduced by 2–3× compared to standard NeRF [S1]. Wall-clock time per iteration is comparable ($\sim 362.4$ ms vs $\sim 359.8$ ms on RTX A5000) [S1].
*   **Memory Complexity:** No significant additional memory overhead compared to standard NeRF, as it reuses the ray marching buffer and only adds supervision for a subset of rays [S1].
*   **Performance:** On the NeRF Real dataset with 5 input views, DS-NeRF achieves a test PSNR of 22.6 (vs 18.2 for NeRF) [S1]. It reaches target PSNR significantly faster, e.g., 13 hours faster in the 5-view case [S1].
*   **Strengths:** Accelerates training, improves quality with few views, compatible with other NeRF variants, and uses "free" SfM data [S1].
*   **Limitations:** Dependent on the quality of SfM keypoints; does not improve methods that already have strong geometric priors (like MVSNeRF) [S1].

## Background
DS-NeRF was introduced by Deng et al. in 2022 [S1]. It addresses the failure mode of NeRF when trained on insufficient input views, where the model fits incorrect geometries due to the lack of constraints enforcing empty space and opaque surfaces [S1]. The method leverages the fact that SfM pipelines (like COLMAP), which are standard prerequisites for NeRF training, already produce sparse 3D keypoints [S1].
