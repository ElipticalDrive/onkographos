# Depth-Supervised NeRF

Also called: DS-NeRF

## Overview
Depth-Supervised NeRF (DS-NeRF) is a training procedure for Neural Radiance Fields that incorporates sparse 3D depth supervision from Structure-from-Motion (SfM) keypoints to accelerate convergence and improve reconstruction quality with fewer input views [S1][S3, unofficial]. Unlike methods that rely on data-driven priors from other scenes or semantic consistency, DS-NeRF leverages the "free" depth estimates inherent in standard SfM preprocessing (e.g., COLMAP) to enforce that the rendered ray termination distribution matches surface priors, thereby reducing overfitting to empty space [S1]. It sets itself apart by requiring no additional training or category-specific priors, making it a generalizable regularization technique compatible with other NeRF variants [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ input images $\{I_j\}$ with known camera poses $\{P_j\}$ (estimated via SfM), and the corresponding sparse 3D keypoints $\{X\}$ and visibility flags generated by the SfM solver [S1].
*   **Outputs:** A trained NeRF model (MLPs for density $\sigma$ and color $c$) and rendered novel views [S1].

**Data Structures:**
*   **Keypoints:** A set of 3D points $X = \{x_1, x_2, \dots\} \in \mathbb{R}^3$ [S1].
*   **Visibility:** For each camera $j$, a subset $X_j \subset X$ of keypoints visible from that camera [S1].
*   **Depth Estimates:** For each visible keypoint $x_i \in X_j$, a scalar depth $D_{ij}$ and uncertainty $\hat{\sigma}_i$ [S1].
*   **Ray Termination Distribution:** The discrete approximation $h_k$ of the continuous distribution $h(t)$ along sampled points $t_k$ [S1].

**Parameters:**
*   **Near/Far Bounds:** $t_n, t_f$ defining the sampling interval [S1].
*   **Depth Loss Weight:** $\lambda_D$ balancing color and depth losses [S1].
*   **Ray Allocation:** A fraction of training rays dedicated to keypoint rays [S1].
*   **Typical Values:** $\lambda_D$ is often set to 1 [S4]. Training typically requires $10^4$ to $10^5$ iterations [S3, unofficial].

**Method Steps:**

1.  **SfM Preprocessing:** Run an SfM solver (e.g., COLMAP) on the input images to estimate camera poses $P_j$ and generate sparse 3D keypoints $X$ with visibility information [S1][S3, unofficial].
2.  **Depth and Uncertainty Estimation:** For each image $I_j$ and camera $P_j$, identify visible keypoints $X_j$. For each $x_i \in X_j$:
    *   Compute the projected depth $D_{ij}$ by projecting $x_i$ with $P_j$ and taking the re-projected z-value [S1].
    *   Compute the depth uncertainty $\hat{\sigma}_i$ as the average reprojection error of keypoint $x_i$ across all views where it was detected [S1].
    *   Model the true depth as a random variable $D_{ij} \sim \mathcal{N}(D_{ij}, \hat{\sigma}_i)$ [S1].
3.  **Ray Generation:** For each training iteration:
    *   Allocate a portion of the total training rays to "keypoint rays" [S1].
    *   For each keypoint ray, compute the ray origin in local camera coordinates from the image coordinates of the detected keypoint, setting the camera axis coordinate to -1 [S1].
    *   Interpolate the RGB supervision value $\mathbf{I}[u, v]$ for these rays from the input image $I_j$, exploiting the continuity of image coordinates [S1].
4.  **Volume Rendering:** Shoot the rays into the scene using the standard NeRF sampling procedure between $t_n$ and $t_f$ [S1]. Compute the rendered color $\widehat{\mathcal{C}}(\mathbf{r})$ and the ray termination distribution $h(t)$ [S1].
    *   The differential density $\sigma(t)$ must be non-negative (e.g., ReLU or softplus) [S1].
    *   The ray termination distribution is defined as $h(t) = T(t)\sigma(t) = \exp\left[-\int_0^t \sigma(s)ds\right]\sigma(t)$ [S1].
    *   $h(t)$ is a valid probability distribution because $\int_0^\infty h(t)dt = 1$ [S1].
    *   In practice, $t_f$ is treated as an opaque wall to ensure the distribution sums to one within the bounded interval [S1].
5.  **Loss Computation:**
    *   **Color Loss:** Standard photometric loss $L_{Color} = \mathbb{E}_{\mathbf{r}} \|\widehat{\mathcal{C}}(\mathbf{r}) - \mathbf{C}(\mathbf{r})\|_2^2$ [S1].
    *   **Depth Loss:** Minimize the KL divergence between the rendered distribution $h_{ij}(t)$ and the noisy depth distribution $\mathcal{N}(D_{ij}, \hat{\sigma}_i)$ [S1]. This is approximated as:
        $$ L_{Depth} = \mathbb{E}_{x_i \in X_j} \sum_k -\log h_k \exp \left( -\frac{(t_k - D_{ij})^2}{2\hat{\sigma}_i^2} \right) \Delta t_k $$
        where $t_k$ are the sample points along the ray and $\Delta t_k$ is the step size [S1].
    *   **Total Loss:** $\mathcal{L} = L_{Color} + \lambda_D L_{Depth}$ [S1].
6.  **Optimization:** Backpropagate gradients through the differentiable volume rendering process to update the NeRF parameters [S1].

**Pseudocode:**

```python
def train_ds_nerf(images, camera_poses, keypoints, visibility):
    """
    images: List of input images I_j
    camera_poses: List of camera matrices P_j
    keypoints: Set of 3D points X
    visibility: Map from camera index j to subset X_j of visible keypoints
    
    Returns: Trained NeRF model
    """
    # Step 1: Estimate depth and uncertainty for each keypoint in each view
    depth_estimates = {} # (j, i) -> D_ij
    depth_uncertainties = {} # i -> sigma_hat_i
    
    # Calculate average reprojection error for uncertainty
    reprojection_errors = {i: [] for i in keypoints}
    for j, (img, pose) in enumerate(zip(images, camera_poses)):
        for i in visibility[j]:
            # Project 3D keypoint x_i to 2D and back to depth
            D_ij = project_depth(pose, keypoints[i])
            depth_estimates[(j, i)] = D_ij
            # Store reprojection error for uncertainty calculation [G]
            # In practice, this is derived from the SfM bundle adjustment output
            reprojection_errors[i].append(compute_reprojection_error(pose, keypoints[i], img))

    for i in keypoints:
        depth_uncertainties[i] = mean(reprojection_errors[i])

    # Step 2: Training Loop
    for iteration in range(num_iterations):
        # Allocate rays: some for standard supervision, some for keypoint supervision
        standard_rays = generate_rays(images, camera_poses, num_standard)
        keypoint_rays = []
        keypoint_targets = [] # (color, depth, uncertainty)
        
        for j, (img, pose) in enumerate(zip(images, camera_poses)):
            for i in visibility[j]:
                # Generate ray for keypoint x_i
                ray = generate_keypoint_ray(pose, keypoints[i])
                keypoint_rays.append(ray)
                
                # Interpolate RGB from image
                u, v = project_2d(pose, keypoints[i])
                color_target = interpolate_color(img, u, v)
                
                # Get depth supervision
                D_ij = depth_estimates[(j, i)]
                sigma_hat = depth_uncertainties[i]
                
                keypoint_targets.append((color_target, D_ij, sigma_hat))

        # Combine rays for batch processing
        all_rays = standard_rays + keypoint_rays
        
        # Render
        rendered_colors, rendered_distributions = volume_render(all_rays, nerf_model)
        
        # Compute Losses
        loss_color = 0
        loss_depth = 0
        
        # Standard rays only contribute to color loss
        for k, ray in enumerate(standard_rays):
            gt_color = get_gt_color(ray, images, camera_poses)
            loss_color += mse(rendered_colors[k], gt_color)
            
        # Keypoint rays contribute to both
        for k, (ray, target) in enumerate(zip(keypoint_rays, keypoint_targets)):
            gt_color, D_ij, sigma_hat = target
            loss_color += mse(rendered_colors[len(standard_rays) + k], gt_color)
            
            # Compute Depth Loss (KL divergence approximation)
            # h_k is the rendered distribution weight at sample t_k
            # t_k are the sample depths along the ray
            h_k = rendered_distributions[len(standard_rays) + k]
            t_k = get_sample_depths(ray)
            delta_t = get_sample_step_sizes(ray)
            
            for h_val, t_val in zip(h_k, t_k):
                # KL term: -log(h(t)) * exp(-(t - D)^2 / 2*sigma^2)
                # Note: The formula in [S1] is E[-log h(t) exp(...)]
                # We approximate the expectation by summing over samples
                term = -log(h_val + epsilon) * exp(-((t_val - D_ij)**2) / (2 * sigma_hat**2))
                loss_depth += term * delta_t
                
        total_loss = loss_color + lambda_D * loss_depth
        
        # Backpropagate and update
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()

    return nerf_model
```

## Subtopics

### Robust Depth Loss
Uses robust loss functions (e.g., Huber, Geman-McClure) instead of L2 or KL divergence to handle outliers in depth supervision [9368-robust-depth-loss.md].

### Depth Structural Consistency Regularization
Enforces smoothness and continuity in depth maps using KNN-based constraints, complementing point-wise depth matching [9371-depth-structural-consistency-regularization.md].

### Geometric Baseline Regularization
Prevents degenerate solutions like floaters by enforcing foreground completeness and opacity sparsity, often used alongside depth supervision [7475-geometric-baseline-regularization.md].

### 3D Point Supervision Loss
Directly supervises the NeRF density field using 3D point clouds, potentially using different distance metrics than the ray-termination distribution approach [12693-3d-point-supervision-loss.md].

## Operating characteristics
*   **Time Complexity:** Training iterations are reduced by 2-3x compared to standard NeRF [S1]. Wall-clock time per iteration is comparable (~362.4 ms vs ~359.8 ms on RTX A5000) [S1].
*   **Memory Complexity:** Requires storing sparse keypoints and visibility flags, which is negligible compared to the NeRF model size [S1].
*   **Performance:** Significantly improves PSNR in sparse-view settings (e.g., 2-5 views) [S1]. On NeRF Real with 5 views, DS-NeRF achieves peak PSNR ~13 hours faster than NeRF [S1].
*   **Strengths:** Accelerates training, improves quality with few views, generalizes to any scene where SfM succeeds, and is compatible with other NeRF methods [S1].
*   **Limitations:** Relies on the quality of SfM depth estimates; poor SfM can cause optimization failure [S1]. Assumes Gaussian uncertainty, which may not hold for non-SfM depth sources [S1]. Does not improve methods like MVSNeRF that already have strong geometry priors [S1].
*   **When to Use:** Sparse-view reconstruction, accelerating NeRF training, scenes where SfM provides reliable keypoints.
*   **When Not to Use:** Scenes with poor SfM reconstruction, or when using methods that already incorporate strong geometric priors (e.g., MVSNeRF) [S1].

## Background
DS-NeRF was introduced by Deng et al. in 2022 [S1]. It addresses the failure mode of NeRF fitting incorrect geometries with insufficient input views by formalizing the assumption that scenes consist of empty space and opaque surfaces [S1]. The method leverages the sparse 3D points produced by standard SfM pipelines (like COLMAP) as "free" depth supervision [S1]. It has been applied to datasets such as LLFF, NeRF Real, Redwood-3dscan, and DTU [S1].
