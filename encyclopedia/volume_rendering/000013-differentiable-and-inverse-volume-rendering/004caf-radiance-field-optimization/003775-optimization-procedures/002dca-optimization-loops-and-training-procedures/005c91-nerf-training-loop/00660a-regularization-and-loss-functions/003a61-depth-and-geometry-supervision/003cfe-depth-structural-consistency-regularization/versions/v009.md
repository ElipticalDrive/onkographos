# Depth Structural Consistency Regularization
Also called: RDSC
## Overview
Depth Structural Consistency Regularization (RDSC) is a geometric regularization technique used in Neural Radiance Field (NeRF) training to enforce continuity in rendered depth maps based on priors from external depth estimation models. It solves the problem of noisy or inconsistent depth structures in sparse-view reconstruction by aligning the relative depth relationships of neighboring pixels in the rendered output with those in a reference depth map. It distinguishes itself from sibling methods like [Depth-Supervised NeRF](8687-depth-supervised-nerf.md) by focusing on structural consistency (relative ordering and smoothness) rather than absolute depth matching, and from [Geometric Baseline Regularization](7475-geometric-baseline-regularization.md) by utilizing KNN-based constraints derived from external depth priors.
## How it works
**Inputs and Outputs:**
- Input: Rendered expected depth map $D^r$ for a specific view; Reference depth map $D^{V2}$ (e.g., from DepthAnythingV2) for the same view; Hyperparameter $m_{ar'}$ (boundary value for minor variations); Hyperparameter $k$ (number of neighbors).
- Output: Scalar regularization loss $\mathcal{L}_{DSC}$ (denoted $R_{DSC}$ in source [S1]).

**Data Structures:**
- $D^r$: 2D array of floats, shape $(H, W)$, containing the expected depth value for each pixel.
- $D^{V2}$: 2D array of floats, shape $(H, W)$, containing the reference depth value for each pixel.
- $KNN(\cdot)$: A function that, given a pixel location and its reference depth, returns the indices of the $k$ nearest neighboring pixels based on depth value similarity within a local spatial region.

**Algorithm:**
1. For each pixel $p_1$ in the rendered depth map $D^r$:
    a. Let $d^r_{p_1}$ be the depth value at $p_1$ in $D^r$.
    b. Let $d^{V2}_{p_1}$ be the reference depth value at $p_1$ in $D^{V2}$.
    c. Identify the set of $k$ nearest neighbor pixels $P_{knn}$ based on $d^{V2}_{p_1}$. The source [S1] defines this as "k-nearest neighbors based on depth values within a small region." This implies a spatial neighborhood is considered, and neighbors are ranked or selected by their reference depth proximity to $d^{V2}_{p_1}$.
    d. For each neighbor pixel $p_2 \in P_{knn}$:
        i. Let $d^r_{p_2}$ be the depth value at $p_2$ in $D^r$.
        ii. Compute the absolute difference $\Delta = |d^r_{p_1} - d^r_{p_2}|$.
        iii. Compute the hinge loss term: $\max(\Delta - m_{ar'}, 0)$.
    e. Sum the hinge loss terms for all $p_2 \in P_{knn}$.
2. Sum the results from step 1 over all pixels $p_1$ in the image.
3. The total loss is $\mathcal{L}_{DSC} = \sum_{p_1} \sum_{p_2 \in KNN(p_1)} \max(|d^r_{p_1} - d^r_{p_2}| - m_{ar'}, 0)$.

**Formula:**
$$ \mathcal{L}_{DSC} = \sum_{p_1} \sum_{p_2 \in KNN(p_1)} \max(|d^r_{p_1} - d^r_{p_2}| - m_{ar'}, 0) $$

Where:
- $p_1, p_2$ are pixel indices.
- $d^r_{p}$ is the rendered expected depth at pixel $p$.
- $KNN(p_1)$ returns the set of $k$ neighbor pixels for $p_1$, selected based on depth values in the reference map $D^{V2}$.
- $m_{ar'}$ is a small boundary value (threshold) that allows for minor depth variations without penalizing the loss.

**Parameters:**
- $m_{ar'}$: Not given in the sources.
- $k$: Not given in the sources.

**Edge Cases and Pitfalls:**
- If $D^{V2}$ contains invalid values (e.g., infinity, NaN), the KNN selection may fail or produce incorrect neighbors. [G] Implementation should mask out invalid pixels in $D^{V2}$ before computing KNN.
- The definition of "small region" for KNN is not specified. [G] A common implementation is to restrict the search to a local window (e.g., $3 \times 3$ or $5 \times 5$) around $p_1$.
- The term "based on depth values" in KNN selection is ambiguous. It likely means sorting neighbors by $|d^{V2}_{neighbor} - d^{V2}_{p_1}|$. [G] This interpretation is used in the pseudocode.

**Pseudocode:**
```python
import numpy as np

def depth_structural_consistency_regularization(rendered_depth, reference_depth, k=4, margin=0.01):
    """
    Compute Depth Structural Consistency Regularization loss.
    
    Args:
        rendered_depth (np.ndarray): 2D array of shape (H, W) with rendered expected depths.
        reference_depth (np.ndarray): 2D array of shape (H, W) with reference depths (e.g., from DepthAnythingV2).
        k (int): Number of nearest neighbors to consider.
        margin (float): Boundary value m_ar' for minor depth variations.
        
    Returns:
        float: The RDSC loss value.
    """
    H, W = rendered_depth.shape
    loss = 0.0
    
    # Define a local window for neighbor search
    # Using a 3x3 window centered at each pixel, excluding the pixel itself
    window_size = 3
    half_window = window_size // 2
    
    for i in range(H):
        for j in range(W):
            # Get reference depth at current pixel
            d_ref_current = reference_depth[i, j]
            
            # If reference depth is invalid, skip
            if not np.isfinite(d_ref_current):
                continue
                
            # Collect neighbors within the local window
            neighbors = []
            for di in range(-half_window, half_window + 1):
                for dj in range(-half_window, half_window + 1):
                    if di == 0 and dj == 0:
                        continue
                    ni, nj = i + di, j + dj
                    if 0 <= ni < H and 0 <= nj < W:
                        d_ref_neighbor = reference_depth[ni, nj]
                        if np.isfinite(d_ref_neighbor):
                            # Distance in reference depth space
                            depth_diff = abs(d_ref_neighbor - d_ref_current)
                            neighbors.append((depth_diff, ni, nj))
            
            # Sort neighbors by reference depth difference and take top k
            neighbors.sort(key=lambda x: x[0])
            selected_neighbors = neighbors[:k]
            
            # Get rendered depth at current pixel
            d_render_current = rendered_depth[i, j]
            
            # Compute hinge loss for each selected neighbor
            for _, ni, nj in selected_neighbors:
                d_render_neighbor = rendered_depth[ni, nj]
                diff = abs(d_render_current - d_render_neighbor)
                hinge_loss = max(diff - margin, 0.0)
                loss += hinge_loss
                
    return loss
```
## Subtopics

### [Patch-Based Depth Regularization](10369-patch-based-depth-regularization.md)
Patch-Based Depth Regularization is a technique applied during Neural Radiance Field (NeRF) training to enforce geometric consistency by smoothing rendered depth maps while preserving sharp structural edges. It distinguishes itself from sibling methods like RegNeRF’s patch similarity constraints by utilizing bilateral or joint bilateral filters, which explicitly account for spatial proximity and intensity/depth similarity to reduce noise without blurring boundaries.

## Operating characteristics
- Time Complexity: $O(H \cdot W \cdot k \cdot w^2)$, where $H, W$ are image dimensions, $k$ is the number of neighbors, and $w$ is the window size for neighbor search.
- Memory Complexity: $O(H \cdot W)$ for storing depth maps and intermediate neighbor lists.
- Strengths: Enforces structural consistency in depth, which is particularly useful in sparse-view scenarios where depth ambiguity is high. It leverages external depth priors to guide the NeRF optimization.
- Limitations: Depends on the quality of the external depth map ($D^{V2}$). If the external depth is inaccurate, the regularization may enforce incorrect structures. The choice of $k$ and $m_{ar'}$ is critical and not well-specified in the source.
- When to use: Sparse-view 3D reconstruction where depth continuity is important and external depth estimates are available.
- When not to use: When high-quality multi-view depth is available, or when the external depth prior is unreliable.
## Background
Originated in the context of sparse-view NeRF reconstruction, specifically in the DASNeRF method [S1]. The method aims to improve scene reconstruction quality by combining depth consistency optimization, adaptive sampling, and hierarchical structural fusion. It uses modern depth estimation models (like DepthAnythingV2) to provide reference depth maps for regularization.
