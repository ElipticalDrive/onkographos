# CLIP Similarity Loss

Also called: CLIP Loss, Image-Text CLIP Loss

## Overview
A regularization term that enforces semantic alignment between rendered images and text prompts by minimizing the distance between their embeddings in the CLIP latent space. It differs from photometric losses by optimizing for high-level semantic consistency rather than pixel-wise intensity matching, enabling text-guided editing and semantic constraints in radiance fields.

## How it works
**Inputs and outputs:**
- Input: Rendered image $I$ (typically from a NeRF or 3DGS scene) and a text prompt $T$.
- Output: Scalar loss value $L_{CLIP}$.

**Data structures:**
- $E_{img}$: Pre-trained CLIP image encoder (e.g., ViT-L/14). Takes normalized image tensor.
- $E_{txt}$: Pre-trained CLIP text encoder. Takes tokenized text prompt.
- Embeddings: Unit-normalized vectors in $\mathbb{R}^d$ (typically $d=768$ or $1024$).

**Steps:**
1. Encode the rendered image $I$ into an embedding vector $v_{img} = E_{img}(I)$.
2. Encode the text prompt $T$ into an embedding vector $v_{txt} = E_{txt}(T)$.
3. Compute the cosine similarity between $v_{img}$ and $v_{txt}$.
4. Compute the loss as one minus the similarity.

**Formula:**
$$L_{CLIP}(I, T) = 1 - \text{sim}(E_{img}(I), E_{txt}(T))$$

Where:
- $E_{img}$ and $E_{txt}$ are the pre-trained CLIP image and text encoders, respectively [S1].
- $\text{sim}(A, B)$ is the cosine similarity between two feature vectors $A$ and $B$, defined as:
  $$\text{sim}(A, B) = \frac{A \cdot B}{\|A\| \|B\|}$$
- $I$ is the rendered image [S1].
- $T$ is the text prompt [S1].

**Parameters:**
- CLIP model variant: Not specified in sources, but typically ViT-L/14 or RN50 [S1].
- Image preprocessing: Standard CLIP normalization (resize to 224x224, normalize to [-1, 1] or [0, 1] depending on implementation) [G].

**Edge cases and pitfalls:**
- Gradient flow: CLIP encoders are frozen; gradients only flow through the rendering process (NeRF/3DGS) to the image $I$ [S1].
- Semantic ambiguity: Text prompts may be ambiguous, leading to suboptimal or unintended semantic alignments [G].
- Resolution sensitivity: CLIP encoders expect fixed input sizes; resizing rendered images may introduce artifacts [G].

**Pseudocode:**
```python
def clip_similarity_loss(rendered_image: Tensor, text_prompt: str, 
                         clip_img_encoder: Module, clip_txt_encoder: Module) -> Tensor:
    """
    Compute CLIP similarity loss between a rendered image and a text prompt.
    
    Args:
        rendered_image: Tensor of shape (C, H, W) or (B, C, H, W), normalized to [-1, 1].
        text_prompt: String text prompt.
        clip_img_encoder: Frozen CLIP image encoder.
        clip_txt_encoder: Frozen CLIP text encoder.
        
    Returns:
        Scalar loss tensor.
    """
    # Encode image
    img_embedding = clip_img_encoder(rendered_image)
    
    # Encode text
    txt_embedding = clip_txt_encoder(text_prompt)
    
    # Normalize embeddings (CLIP outputs are typically already normalized, but ensure unit length)
    img_embedding = img_embedding / img_embedding.norm(dim=-1, keepdim=True)
    txt_embedding = txt_embedding / txt_embedding.norm(dim=-1, keepdim=True)
    
    # Compute cosine similarity
    similarity = (img_embedding * txt_embedding).sum(dim=-1)
    
    # Compute loss
    loss = 1.0 - similarity
    
    return loss.mean()
```

## Operating characteristics
- **Time complexity:** Dominated by the forward pass of the CLIP encoders, which is constant with respect to scene size but depends on image resolution and text length. Typically negligible compared to NeRF/3DGS rendering [S1].
- **Memory complexity:** Minimal, as CLIP encoders are frozen and do not store gradients for the encoders themselves [S1].
- **Strengths:** Enables semantic guidance, text-driven editing, and high-level scene understanding [S1].
- **Limitations:** May not enforce fine-grained geometric or photometric accuracy; can lead to semantic drift if not balanced with photometric losses [G].
- **When to use:** When semantic consistency is more important than pixel-perfect reconstruction, or for text-guided editing tasks [S1].
- **When not to use:** When precise geometric or photometric fidelity is required without semantic constraints [G].

## Background
Originated from the CLIP model (Contrastive Language-Image Pre-training) by OpenAI, which trains image and text encoders using contrastive learning [S1]. CLIP similarity loss was adapted for 3D editing in methods like CLIP-NeRF, which introduced disentangled conditional NeRFs for text-guided editing [S1]. It is a foundational technique in semantic NeRF editing and inverse rendering.
