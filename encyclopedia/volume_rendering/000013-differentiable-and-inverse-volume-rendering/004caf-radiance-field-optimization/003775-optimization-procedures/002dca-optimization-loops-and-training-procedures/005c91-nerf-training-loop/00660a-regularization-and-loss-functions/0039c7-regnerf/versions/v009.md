# RegNeRF

Also called: Regularized NeRF

## Overview
RegNeRF is a method for synthesizing novel views from sparse input images by applying depth smoothness and color priors to constrain the unobserved regions of the scene [S1]. It differs from sibling methods like [DiffNeRF](8572-diffnerf.md), which relies on automatic differentiation of the ray-based representation for gradient estimation, by using finite-difference approximations on patch-based dataloaders to compute depth gradients [S1][S2, unofficial]. Unlike [Depth and Geometry Supervision](8727-depth-and-geometry-supervision.md) which often requires explicit depth labels, RegNeRF employs generative priors (Normalizing Flows) and geometric smoothness constraints without requiring pretraining on the target dataset [S1].

## How it works
RegNeRF operates within the differentiable volume rendering framework [S1, 8582-regnerf.md]. It uses Mip-NeRF [48] as the backbone neural radiance field, which renders anti-aliased cones instead of rays to handle frequency aliasing [S1]. The method introduces three key components: sampled space annealing, depth smoothness regularization, and color regularization via Normalizing Flows.

### Inputs and Outputs
*   **Inputs:** A sparse set of $N$ input images with known camera poses.
*   **Outputs:** A trained NeRF model (density $\sigma$ and color $\mathbf{c}$ fields) capable of rendering novel views.

### Data Structures
*   **Patches:** The method operates on image patches of size $S_{patch} \times S_{patch}$ rather than single pixels or full images. A patch $P_r$ is centered at pixel $r$.
*   **Normalizing Flow Model:** A pre-trained bijection $\phi$ mapping patches to $\mathbb{R}^d$ where $d = S_{patch} \cdot S_{patch} \cdot 3$, trained on a large unposed dataset (e.g., JFT-300M) [S1].

### Algorithm Steps

1.  **Sampled Space Annealing:**
    At the start of training, to prevent divergent NeRF modes with high density at the ray origin, the range of sample points along each ray is limited to a small volume defined by the bounding box of all input images. This volume is gradually extended to cover the full scene as training progresses [S1].

2.  **Random View Sampling:**
    For each training step, randomly sample unobserved viewpoints (camera poses) that are not in the input set. Render patches from these viewpoints using the current NeRF model [S1].

3.  **Depth Smoothness Loss ($\mathcal{L}_{ds}$):**
    Compute the expected depth $\hat{D}(\mathbf{r})$ for rays passing through the rendered patches. The smoothness loss encourages the world geometry to be piecewise smooth by penalizing depth differences between adjacent pixels in the patch [S1]:
    $$ \mathcal{L}_{ds} = \sum_{i,j} \sum_{\mathbf{r}} \left( (d(\mathbf{r}_{i,j}) - d(\mathbf{r}_{i+1,j}))^2 + (d(\mathbf{r}_{i,j}) - d(\mathbf{r}_{i,j+1}))^2 \right) $$
    where $d(\mathbf{r}_{i,j})$ is the expected depth of the ray through pixel $(i,j)$ of a patch of size $S_{patch}$ from a randomly sampled unobserved viewpoint [S1].

4.  **Color Regularization Loss ($\mathcal{L}_{NLL}$):**
    Estimate the likelihood of the rendered color patches using a Normalizing Flow model. The flow model $\phi$ maps the predicted RGB patch $P_{\mathbf{r}}$ (centered at $\mathbf{r}$) to a latent space where the distribution is assumed to be Gaussian $p_z$ [S1]. The loss is the negative log-likelihood:
    $$ \mathcal{L}_{NLL} = - \sum_{\mathbf{r}} \log p_z(\phi(P_{\mathbf{r}})) $$
    where $p_z$ is a Gaussian distribution [S1].

5.  **Optimization:**
    Minimize the total loss (typically combining $\mathcal{L}_{ds}$, $\mathcal{L}_{NLL}$, and the standard photometric reconstruction loss on input views) with respect to the NeRF parameters using gradient descent [S1].

### Pseudocode

```python
def train_regnerf(input_images, input_poses, flow_model, num_epochs):
    """
    Trains a Mip-NeRF model with RegNeRF regularization.
    """
    nerf = MipNeRF()  # Backbone model
    optimizer = Adam(nerf.parameters())
    
    # Annealing parameters
    min_volume = get_bounding_box(input_images)
    max_volume = get_scene_bounds()
    
    for epoch in range(num_epochs):
        # 1. Sampled Space Annealing
        # Gradually expand sample range from min_volume to max_volume
        current_sample_range = lerp(min_volume, max_volume, epoch / num_epochs)
        
        for batch in dataloader(input_images, input_poses):
            optimizer.zero_grad()
            
            # 2. Render input views (standard photometric loss)
            rendered_colors_input = render_nerf(nerf, batch.poses, current_sample_range)
            loss_recon = mse_loss(rendered_colors_input, batch.images)
            
            # 3. Sample random unobserved viewpoints
            random_poses = sample_random_poses(num_views=1)
            
            # 4. Render patches from unobserved views
            # Render at patch resolution to extract patches
            rendered_colors_random = render_nerf(nerf, random_poses, current_sample_range)
            patches = extract_patches(rendered_colors_random, size=S_patch)
            depths_random = render_depth(nerf, random_poses, current_sample_range)
            depth_patches = extract_patches(depths_random, size=S_patch)
            
            # 5. Compute Depth Smoothness Loss
            loss_ds = 0
            for patch_depth in depth_patches:
                # Compute differences between adjacent pixels in the patch
                diff_x = patch_depth[:, 1:, :] - patch_depth[:, :-1, :]
                diff_y = patch_depth[:, :, 1:] - patch_depth[:, :, :-1]
                loss_ds += mse_loss(diff_x, 0) + mse_loss(diff_y, 0)
            
            # 6. Compute Color Regularization Loss
            loss_nll = 0
            for patch_color in patches:
                # Map patch to latent space using Normalizing Flow
                latent = flow_model.encode(patch_color)
                # Compute negative log-likelihood under Gaussian prior
                loss_nll += -log_likelihood_gaussian(latent)
            
            # 7. Total Loss and Update
            total_loss = loss_recon + lambda_ds * loss_ds + lambda_nll * loss_nll
            total_loss.backward()
            optimizer.step()
```

### Parameters
*   $S_{patch}$: Patch size. Not given in the sources.
*   $\lambda_{ds}$: Weight for depth smoothness loss. Not given in the sources.
*   $\lambda_{NLL}$: Weight for color regularization loss. Not given in the sources.
*   Backbone: Mip-NeRF [S1].

### Edge Cases and Pitfalls
*   **Divergent Modes:** Without sampled space annealing, the NeRF may converge to modes with high density at the ray origin, failing to reconstruct the scene geometry [S1].
*   **Sparse Views:** The method is specifically designed for sparse input views; performance on dense views may be suboptimal compared to standard NeRF due to the overhead of regularization [S1].
*   **Flow Model Dependency:** The color regularization relies on a pre-trained Normalizing Flow model. If the flow model is not well-calibrated for the domain, the regularization may introduce artifacts [S1].

## Subtopics

### DiffNeRF
DiffNeRF is a regularization framework that uses differential geometry to improve robustness in few-shot scenarios by modifying the NeRF to represent continuous, infinitely differentiable functions [S1]. Unlike RegNeRF, which approximates gradients via finite differences on patch-based dataloaders, DiffNeRF uses automatic differentiation to compute depth gradients directly from the ray-based NeRF representation, allowing regularization of unseen views without specialized dataloader modifications [S1].

### SS-NeRF
SS-NeRF employs an encoding function and two position decoding functions (one direction-dependent, one direction-independent) represented by MLPs to produce various scene properties [S1]. It trains the network to produce color, semantic labels, surface normal, shading, keypoints, and edges [S1]. It uses a combination of losses: MSE for color and surface normals; MAE for shading, keypoints and edges; and cross-entropy for semantic labels [S1].

## Operating characteristics
*   **Time Complexity:** Training time is increased due to the additional loss computations (depth smoothness and flow likelihood) and the need to render from random unobserved viewpoints at each step [S1].
*   **Memory Complexity:** Requires storing the pre-trained Normalizing Flow model and its parameters, in addition to the NeRF model [S1].
*   **Performance:** RegNeRF outperforms models such as PixelNeRF, SRF, and MVSNeRF under sparse view conditions on DTU and LLFF datasets [S1]. It achieves comparable performance to models that require pretraining on DTU and fine-tuning per scene, without needing such pretraining [S1].
*   **Strengths:** Does not require pretraining on the target dataset; effective for sparse view synthesis; improves geometric smoothness and color consistency in unobserved regions [S1].
*   **Limitations:** Relies on the quality of the pre-trained Normalizing Flow model; may not generalize well to domains significantly different from the flow model's training data [S1].

## Background
RegNeRF was proposed in December 2021 [S1]. It aimed to solve the problem of NeRF training with sparse input views by employing additional depth and color regularization, without requiring pretraining [S1]. It was tested on DTU and LLFF datasets [S1]. The method builds on the Mip-NeRF backbone [48] [S1].
