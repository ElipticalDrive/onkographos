# Direct Depth Supervision

Also called: Direct supervision, L1 depth loss, MSE depth loss

## Overview
Direct Depth Supervision is a training objective that minimizes the pixel-wise difference between the depth rendered by a Neural Radiance Field (NeRF) and a ground truth depth prior [S1]. It differs from indirect methods by applying the loss directly to the expected depth value $\hat{\mathbf{D}}(\mathbf{r})$ rather than using geometric constraints on density or surface normals [S1]. It builds on [Depth and Geometry Supervision](8727-depth-and-geometry-supervision.md).

## How it works
**Inputs and Outputs:**
*   **Inputs:** A batch of $N_r$ camera rays $\{\mathbf{r}_i\}_{i=1}^{N_r}$, the corresponding ground truth depth values $\{\mathbf{D}(\mathbf{r}_i)\}_{i=1}^{N_r}$ from a depth prior, and the NeRF parameters $\theta$ (density $\sigma$ and color $\mathbf{c}$).
*   **Outputs:** A scalar loss value $\mathcal{L}_{depth}$ used for backpropagation.

**Data Structures:**
*   **Rendered Depth:** For each ray $\mathbf{r}_i$, the rendered depth $\hat{\mathbf{D}}(\mathbf{r}_i)$ is computed as the expected distance along the ray:
    $$ \hat{\mathbf{D}}(\mathbf{r}_i) = \sum_{j=1}^{N} w_{i,j} t_{i,j} $$
    where $t_{i,j}$ are the sample depths, and $w_{i,j} = T_{i,j} (1 - \exp(-\sigma_{i,j} \delta_{i,j}))$ are the rendering weights derived from accumulated transmittance $T_{i,j}$ and density $\sigma_{i,j}$ [S1][S2, unofficial].
*   **Ground Truth Depth:** $\mathbf{D}(\mathbf{r}_i)$ is the scalar depth value from the prior (e.g., LiDAR, monocular estimation) corresponding to ray $\mathbf{r}_i$ [S1].

**Steps:**
1.  Sample a batch of $N_r$ rays from the training views [S1].
2.  Render the depth map for these rays using the current NeRF parameters $\theta$ to obtain $\hat{\mathbf{D}}(\mathbf{r}_i)$ for each ray [S1].
3.  Retrieve the corresponding ground truth depth values $\mathbf{D}(\mathbf{r}_i)$ from the depth prior [S1].
4.  Compute the loss using either Mean Squared Error (MSE) or L1 norm [S1].

**Formulas:**
The two common loss functions are [S1]:

1.  **MSE Loss:**
    $$ \mathcal{L}_{MSE} = \frac{1}{N_r} \sum_{i=1}^{N_r} \| \mathbf{D}(\mathbf{r}_i) - \hat{\mathbf{D}}(\mathbf{r}_i) \|^2 $$

2.  **L1 Loss:**
    $$ \mathcal{L}_{L1} = \frac{1}{N_r} \sum_{i=1}^{N_r} | \mathbf{D}(\mathbf{r}_i) - \hat{\mathbf{D}}(\mathbf{r}_i) | $$

**Parameters:**
*   $N_r$: Number of rays in the batch.
*   $N$: Number of samples per ray.

**Edge Cases and Pitfalls:**
*   **Invalid Depth:** If the ground truth depth prior contains invalid values (e.g., infinity, NaN) for a specific ray, those pixels should be masked out or excluded from the sum to prevent gradient corruption [G].
*   **Scale Mismatch:** If the depth prior and the NeRF's coordinate system have different scales or origins, the loss will not converge to the correct geometry [G].

**Pseudocode:**
```python
def direct_depth_loss(rendered_depth, ground_truth_depth, mask=None):
    """
    Computes direct depth supervision loss.
    
    Args:
        rendered_depth: Tensor of shape (N_r,) containing D_hat(r_i).
        ground_truth_depth: Tensor of shape (N_r,) containing D(r_i).
        mask: Optional boolean tensor of shape (N_r,) indicating valid pixels.
              If None, all pixels are used.
    
    Returns:
        Scalar loss value.
    """
    # Select valid pixels if mask is provided
    if mask is not None:
        rendered_depth = rendered_depth[mask]
        ground_truth_depth = ground_truth_depth[mask]
    
    # Compute L1 loss
    l1_loss = torch.mean(torch.abs(rendered_depth - ground_truth_depth))
    
    # Compute MSE loss
    mse_loss = torch.mean((rendered_depth - ground_truth_depth) ** 2)
    
    # Return both or a weighted combination as needed by the training loop
    return l1_loss, mse_loss
```

## Subtopics

### Direct Depth Supervision (L1)
Uses the L1 norm ($\mathcal{L}_{L1}$) as the primary loss function. It is often preferred over MSE for depth because it is less sensitive to outliers and large errors in the depth prior [S2, unofficial]. It is chosen when robustness to noisy depth priors is required.

## Operating characteristics
*   **Time Complexity:** $O(N_r \cdot N)$ for rendering, plus $O(N_r)$ for the loss computation. The gradient computation is linear in the number of samples due to the differentiable nature of the volume rendering integral [S1].
*   **Memory Complexity:** $O(N_r \cdot N)$ to store intermediate rendering weights and transmittances for backpropagation [S1].
*   **Strengths:** Simple to implement; directly penalizes geometric error; works with various depth priors (LiDAR, monocular) [S1].
*   **Limitations:** Sensitive to scale mismatches between the NeRF and the depth prior; can struggle with sparse or noisy depth priors if not masked correctly [S1].
*   **When to use:** When high-quality depth priors are available and the scale is known or calibrated.
*   **When not to use:** When the depth prior is extremely sparse or has significant scale ambiguity without additional regularization.

## Background
Direct depth supervision was introduced as a standard technique for incorporating geometric priors into NeRF training [S1]. It is widely used in outdoor NeRF methods where LiDAR or dense depth completion data is available [S1]. The method leverages the differentiability of the volume rendering process to backpropagate gradients from the depth loss to the density field parameters [S1].
