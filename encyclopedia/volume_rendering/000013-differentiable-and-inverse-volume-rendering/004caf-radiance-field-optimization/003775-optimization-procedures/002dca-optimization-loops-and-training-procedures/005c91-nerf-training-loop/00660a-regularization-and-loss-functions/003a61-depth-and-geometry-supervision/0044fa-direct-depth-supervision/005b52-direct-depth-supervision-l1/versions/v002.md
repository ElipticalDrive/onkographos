# Direct Depth Supervision (L1)
Also called: L1 Depth Loss

## Overview
Direct Depth Supervision (L1) is a training objective that penalizes the absolute difference between the depth rendered by a neural radiance field (NeRF) and a ground truth depth prior [S2]. It serves as a geometric regularizer to enforce metric consistency during optimization [S2]. Unlike gradient-aware variants, this method operates solely on raw depth values without incorporating spatial derivative constraints [S3].

## How it works
**Inputs and Outputs**
- Input: Predicted depth map $D_{pred}$ (or $\lambda$) and ground truth depth map $D_{gt}$ (or $\lambda_{GT}$) [S1, unofficial][S2].
- Output: Scalar loss value $\mathcal{L}_D$ [S2].

**Data Structures**
- Depth maps are represented as 2D arrays of floating-point values corresponding to pixel coordinates [S1, unofficial][S2].
- Valid depth pixels are identified by a mask or by excluding invalid/undefined values [S1, unofficial].

**Steps**
1. Identify the set of valid pixels $S_1$ where both predicted and ground truth depths are defined [S1, unofficial].
2. Compute the absolute difference between predicted and ground truth depth for each valid pixel [S2].
3. Sum the absolute differences over all valid pixels [S1, unofficial].
4. Normalize the sum by the number of valid pixels $|S_1|$ to obtain the mean L1 error [S1, unofficial].

**Formula**
The loss is defined as:
$$
\mathcal{L}_D = \frac{1}{|S_1|} \sum_{s \in S_1} |D_{pred}(s) - D_{gt}(s)|
$$
Where:
- $S_1$ is the set of pixels with valid depth [S1, unofficial].
- $D_{pred}(s)$ is the predicted depth at pixel $s$ [S1, unofficial][S2].
- $D_{gt}(s)$ is the ground truth depth at pixel $s$ [S1, unofficial][S2].
- $| \cdot |$ denotes the absolute value [S2].

**Parameters**
- No weighting parameters are used in the basic L1 formulation [S2].

**Edge Cases and Pitfalls**
- Invalid depth values (e.g., background pixels) must be excluded from the summation to prevent bias [S1, unofficial].
- Precision issues may arise if depth values span a large dynamic range; normalization is critical [S1, unofficial].

**Pseudocode**
```python
def l1_depth_loss(D_pred, D_gt, valid_mask):
    """
    Computes the L1 depth loss.
    
    Args:
        D_pred: 2D array of predicted depths.
        D_gt: 2D array of ground truth depths.
        valid_mask: 2D boolean array, True where depth is valid.
        
    Returns:
        Scalar loss value.
    """
    # Select valid pixels
    D_pred_valid = D_pred[valid_mask]
    D_gt_valid = D_gt[valid_mask]
    
    # Compute number of valid pixels
    num_valid = valid_mask.sum()
    
    # Handle edge case: no valid pixels
    if num_valid == 0:
        return 0.0
        
    # Compute absolute differences
    abs_diffs = abs(D_pred_valid - D_gt_valid)
    
    # Compute mean L1 loss
    loss = abs_diffs.sum() / num_valid
    
    return loss
```

## Subtopics

### Gradient-Aware Depth Supervision Loss
This variant extends the L1 loss by adding gradient terms to enforce local geometric smoothness [S3]. The loss is defined as $\mathcal{L}_{depth} = \alpha \cdot |D_{pred} - D_{gt}| + \beta \cdot |\partial_x D_{pred} - \partial_x D_{gt}| + \beta \cdot |\partial_y D_{pred} - \partial_y D_{gt}|$, where $D$ represents inverse depth and $\partial_x, \partial_y$ are spatial gradients [S3]. Parameters are $\alpha = 20$ and $\beta = 20$ [S3]. It is chosen when preserving sharp edges and local structure is more critical than global metric accuracy [S3].

## Operating characteristics
- **Time Complexity**: $O(N)$, where $N$ is the number of valid pixels [S1, unofficial].
- **Memory Complexity**: $O(N)$ to store intermediate difference arrays [S1, unofficial].
- **Strengths**: Simple to implement; robust to outliers compared to L2 loss [S2].
- **Limitations**: Does not enforce geometric smoothness or continuity [S3].
- **When to use**: When ground truth depth is available and metric accuracy is the primary goal [S2].
- **When not to use**: When depth maps are noisy or lack fine geometric detail, as L1 may not regularize local structures effectively [S3].

## Background
The L1 depth loss originates from inverse rendering frameworks that use signed distance functions (SDFs) and depth distance functions (DDFs) [S2]. It was employed in the FIRe framework to enforce consistency between latent codes and predicted depths [S2]. The formulation aligns with standard L1 regression practices in computer vision [S2].
