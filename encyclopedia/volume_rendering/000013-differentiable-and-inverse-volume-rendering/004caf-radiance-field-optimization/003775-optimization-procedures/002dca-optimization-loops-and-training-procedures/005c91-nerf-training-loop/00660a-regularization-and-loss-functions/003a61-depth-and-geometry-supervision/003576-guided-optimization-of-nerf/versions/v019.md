# Guided Optimization of NeRF

Also called: Confidence-Based Depth Filtering

## Overview
Guided Optimization of NeRF mitigates shape-radiance ambiguity in poorly textured indoor scenes by constraining the sampling range of Neural Radiance Fields (NeRF) using adapted monocular depth priors [S1]. It sets itself apart from standard NeRF and other geometric supervision methods by explicitly limiting the search space along camera rays based on multi-view consistency errors, rather than relying solely on photometric gradients or explicit depth loss terms [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** $N$ input views with RGB images, camera intrinsics $K$, relative poses $T^{i \to j}$, and adapted monocular depth priors $\{D^i\}_{i=1}^N$ for each view [S1].
*   **Outputs:** A trained NeRF model $F_\theta: (\mathbf{x}, \mathbf{d}) \to (c, \sigma)$ and a refined depth map for each view [S1].

**Data Structures:**
*   **Depth Priors:** A set of $N$ depth maps $\{D^i\}$, one per input view.
*   **Error Maps:** A set of $N$ error maps $\{e_i\}$, where $e_i$ is a scalar value per pixel representing the reprojection error of the depth priors.
*   **NeRF Model:** A multi-layer perceptron (MLP) parameterized by $\theta$, taking 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$ as input, outputting color $c$ and volume density $\sigma$ [S1].

**Parameters:**
*   $K=4$: Number of minimum cross-view depth projection errors used to calculate the error map value [S1].
*   $\alpha_l = 0.05$: Lower bound for the relative sampling range [S1].
*   $\alpha_h = 0.15$: Higher bound for the relative sampling range [S1].
*   $M$: Number of sample points per ray (standard NeRF parameter, not explicitly fixed in the source text but required for stratified sampling) [S1].

**Algorithm Steps:**

1.  **Acquire Adapted Depth Priors:** Obtain initial depth estimates $\{D^i\}_{i=1}^N$ for the $N$ input views using a monocular depth network (e.g., Mannequin Challenge architecture) fine-tuned on the target scene [S1].

2.  **Compute Error Maps:**
    For each view $i$ and every other view $j$:
    a. Project the depth map $D^i$ from view $i$ to view $j$ using camera intrinsics $K$ and relative pose $T^{i \to j}$ to obtain projected 2D coordinates $p^{i \to j}$ and projected depth $D^{i \to j}$ [S1]:
    $$ p^{i \to j}, D^{i \to j} = \text{proj}(K, T^{i \to j}, D^i) $$
    b. Sample the depth value from the target view's prior $D^j$ at the projected coordinates to get $D^{j'}$:
    $$ D^{j'} = D^j(p^{i \to j}) $$
    c. Calculate the relative reprojection error between $D^{j'}$ and $D^{i \to j}$ [S1].
    d. For each pixel in view $i$, compute the error map value $e_i$ as the average of the top $K$ minimum cross-view reprojection errors [S1].

3.  **Calculate Adaptive Sample Ranges:**
    For each ray $\mathbf{r}$ corresponding to a pixel in view $i$, with adapted depth prior $D$ and error map value $e$, compute the near ($t_n$) and far ($t_f$) bounds for sampling [S1]:
    $$ t_n = D(1 - \text{clamp}(e, \alpha_l, \alpha_h)) $$
    $$ t_f = D(1 + \text{clamp}(e, \alpha_l, \alpha_h)) $$
    Here, $\text{clamp}(x, a, b)$ restricts $x$ to the interval $[a, b]$. This ensures that pixels with low error have sampling concentrated near the prior, while pixels with high error have a wider range [S1].

4.  **Stratified Sampling:**
    Partition the interval $[t_n, t_f]$ into $M$ bins. For each bin $i \in [1, M]$, sample a point $t_i$ uniformly from the bin interval [S1]:
    $$ t_i \sim \mathcal{U} \left[ t_n + \frac{i-1}{M}(t_f - t_n), \,\, t_n + \frac{i}{M}(t_f - t_n) \right] $$
    The 3D position $\mathbf{x}_i$ is computed from $t_i$ and the ray origin/direction.

5.  **NeRF Evaluation and Volume Rendering:**
    Query the NeRF for density $\sigma_i$ and color $c_i$ at each sample point $\mathbf{x}_i$ [S1]. Compute the rendered color $C(\mathbf{r})$ and expected depth $D(\mathbf{r})$ using volume rendering [S1]:
    $$ C(\mathbf{r}) = \sum_{i=1}^{M} T_i (1 - e^{-\sigma_i \delta_i}) c_i $$
    $$ D(\mathbf{r}) = \sum_{i=1}^{M} T_i (1 - e^{-\sigma_i \delta_i}) t_i $$
    where $\delta_i = t_{i+1} - t_i$ is the distance between adjacent samples, and $T_i = \exp \left(-\sum_{j=1}^{i-1} \sigma_j \delta_j \right)$ is the accumulated transmittance [S1].

6.  **Compute Confidence Scores:**
    Calculate the confidence score $S^i_j$ for pixel $j$ in view $i$ based on the $L_1$ difference between the ground truth RGB $C_{gt}^i(j)$ and the rendered RGB $C_{render}^i(j)$, normalized by 255 [S1]:
    $$ S^i_j = 1 - \frac{1}{3} || C_{gt}^i(j) - C_{render}^i(j) ||_1 $$
    The $L_1$ norm is taken over the 3 color channels [S1].

7.  **Depth Refinement (Post-Processing):**
    Apply plane bilateral filtering to the rendered depth map, weighted by the confidence scores $S^i_j$, to produce the final depth output [S1].

def project_depth(depth_map, K, T):
    """
    Projects depth map from one view to another.
    Returns projected coordinates (u, v) in target view and projected depth values.
    """
    # Inverse intrinsics
    K_inv = np.linalg.inv(K)
    
    # Get pixel coordinates
    h, w = depth_map.shape
    u, v = np.meshgrid(np.arange(w), np.arange(h))
    uv1 = np.stack([u, v, np.ones_like(u)], axis=-1) # (H, W, 3)
    
    # Back-project to 3D in source camera frame
    # X_cam = K_inv * [u, v, 1] * D
    X_cam = (K_inv @ uv1.reshape(-1, 3).T).T * depth_map.reshape(-1, 1)
    X_cam = X_cam.reshape(h, w, 3)
    
    # Transform to target camera frame
    # T is T_i_to_j, i.e., from i to j
    # X_j = T @ [X_i; 1]
    ones = np.ones((h, w, 1))
    X_hom = np.concatenate([X_cam, ones], axis=-1) # (H, W, 4)
    X_hom_flat = X_hom.reshape(-1, 4)
    
    # Apply transformation
    X_j_hom = (T @ X_hom_flat.T).T
    X_j = X_j_hom[:, :3]
    
    # Project to target image plane
    # [u', v', w'] = K @ X_j
    uv1_j = (K @ X_j.T).T
    u_j = uv1_j[:, :, 0] / (uv1_j[:, :, 2] + 1e-6)
    v_j = uv1_j[:, :, 1] / (uv1_j[:, :, 2] + 1e-6)
    D_j = uv1_j[:, :, 2]
    
    return (u_j, v_j), D_j

## Subtopics

### [ENeRF with Guided Sampling Training](7580-enerf-with-guided-sampling-training.md)
ENeRF with Guided Sampling Training is a training procedure that integrates pixel-region and depth-boundary-guided ray sampling into the Efficient Neural Radiance Field (ENeRF) framework. It solves the problem of high GPU memory consumption and inefficient sampling in generalizable NeRF models by using fewer rays per iteration while maintaining or improving rendering performance. It sets itself apart from standard ENeRF by actively guiding sampling locations using adapted monocular depth priors, thereby mitigating shape-radiance ambiguity more effectively than uniform or random sampling strategies.

## Operating characteristics
**Time and Memory Complexity:**
The method requires multi-view consistency checks, which involve projecting depth maps between all pairs of views. For $N$ views, this is $O(N^2)$ projections per iteration or preprocessing step. The NeRF training itself follows the complexity of standard NeRF, $O(M \cdot R)$ per iteration, where $M$ is samples per ray and $R$ is the number of rays [S1].

**Measured Performance:**
The method outperforms state-of-the-art depth estimation methods on the ScanNet dataset [S1]. It significantly improves depth estimation quality over original NeRF and mitigates shape-radiance ambiguity in indoor scenes [S1]. Applying existing correspondence-based neural optimization (like CVD) to adapted depth priors degrades quality, highlighting the necessity of this specific guided optimization [S1].

**Strengths and Limitations:**
*   **Strengths:** Effectively handles shape-radiance ambiguity in poorly textured indoor areas (e.g., walls) where standard NeRF fails [S1]. Produces accurate depth maps and improves novel view synthesis quality [S1].
*   **Limitations:** Relies on the quality of adapted monocular depth priors. Performance may degrade if the priors are inaccurate. Correspondence-based optimization on these priors can be unreliable in poorly textured regions [S1].

**When to Use:**
Use this method when optimizing NeRF for indoor scenes with poorly textured regions where standard NeRF suffers from shape-radiance ambiguity and depth estimation is a primary goal [S1].

**When Not to Use:**
Avoid if high-quality monocular depth priors are not available or if the scene is rich in texture where standard NeRF geometry is already sufficient [S1].

## Background
The method was proposed in "Depth-Guided Optimization of Neural Radiance Fields for Indoor Multi-View Stereo" [S1]. It builds on the original NeRF formulation [33] and addresses the shape-radiance ambiguity discussed in [61]. The authors observed that NeRF struggles in poorly textured indoor areas, leading to depth deviations from ground truth despite high-quality RGB synthesis [S1]. The method uses adapted monocular depth priors (fine-tuned from the Mannequin Challenge network [23]) and multi-view consistency checks to guide sampling [S1].
