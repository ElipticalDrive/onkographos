# MoCo-NeRF

Also called: Motion-Oriented Compositional Neural Radiance Fields

## Overview
MoCo-NeRF is a framework for free-viewpoint rendering of monocular human videos that models non-rigid body motions as radiance residual fields rather than spatial offsets, using rigid skeletal transformations as a prior [S1]. It decomposes the representation into a rigid branch learning a canonical T-pose radiance field and a non-rigid branch optimizing pose-driven radiance residuals, allowing for direct color supervision and reduced learning complexity compared to offset-based methods [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Monocular video frames of a human subject (or multiple subjects), corresponding camera poses, and skeletal joint positions $J$ for each frame.
*   **Outputs:** Rendered RGB images for novel viewpoints and poses.

**Data Structures:**
*   **Skeletal Weights Volume Decoder:** Optimizes canonical skinning weights $w^c_k$ for $K$ joints [S1].
*   **Multi-Hash Encoding (MHE):** A hash grid structure. For single-subject, one MHE $\psi_{hash}$ with 16 levels, feature dimension $H=2$ per level [S1]. For multi-subject, one global MHE $\psi_{hash}^G$ (4 levels, $H=2$) and $N_s$ local MHEs $\{\psi_{hash}^i\}$ (16 levels, $H=2$) [S1].
*   **Learnable Base Code:** $S \in \mathbb{R}^{64}$, randomly initialized [S1].
*   **Projection Matrices:** $W_p, W_Q, W_K, W_V$ for pose embedding generation [S1].
*   **MLP Decoders:** $M_{rigid}$ for rigid branch, $M_{nr}$ for non-rigid branch [S1].

**Numbered Steps:**

1.  **Canonical Transformation:** Transform an observation point $\mathbf{x}$ to a canonical point $\mathbf{x}_c$ using inverse linear blend skinning [S1]:
    $$ \mathbf{x}_c = \sum_{k=1}^K w^o_k (R_k \mathbf{x} + \mathbf{t}_k) $$
    where $w^o_k = \frac{w^c_k(R_k \mathbf{x} + \mathbf{t}_k)}{\sum_{j=1}^K w^c_j(R_j \mathbf{x} + \mathbf{t}_j)}$, $R_k, \mathbf{t}_k$ are rotation and translation of bone $k$, and $w^c_k$ are optimized canonical skinning weights [S1].

2.  **Rigid Branch Feature Query:** Query multiresolution volumetric features $\mathbf{f}_{\mathbf{x}_c}$ from the MHE $\psi_{hash}$:
    $$ \mathbf{f}_{\mathbf{x}_c} = \psi_{hash}(\mathbf{x}_c) $$
    [S1].

3.  **Rigid Branch Prediction:** Slice the first half ($H$ dimensions) of $\mathbf{f}_{\mathbf{x}_c}$ at each resolution level to compute $\mathbf{f}^{:H}_{\mathbf{x}_c}$. Predict rigid color $\mathbf{c}$ and density $\sigma$ using MLP $M_{rigid}$ [S1]:
    $$ \mathbf{c}, \sigma = M_{rigid}(\mathbf{f}^{:H}_{\mathbf{x}_c}) $$
    [S1].

4.  **Non-Rigid Branch Feature Preparation:** Use the full feature $\mathbf{f}_{\mathbf{x}_c}$ but freeze the first half representing canonical radiance. Denote the remaining optimized half as $\mathbf{f}^*_{\mathbf{x}_c}$ [S1].

5.  **Pose-Embedded Implicit Feature Generation:**
    a. Apply sinusoidal positional encoding $\gamma$ to 23 joint positions $J$:
    $$ \gamma(\mathbf{j}_i) = [\mathbf{j}_i, \sin(2^0 \pi \mathbf{j}_i), \cos(2^0 \pi \mathbf{j}_i), \dots, \sin(2^{L-1} \pi \mathbf{j}_i), \cos(2^{L-1} \pi \mathbf{j}_i)] $$
    where $L=10$ frequency bands [S1].
    b. Project encoded joints $\gamma(J) \in \mathbb{R}^{23 \times 63}$ to raw pose-embedded code $\mathbf{P}_{raw}$:
    $$ \mathbf{P}_{raw} = W_p \cdot \gamma(J) $$
    [S1].
    c. Generate query $\mathbf{P}_q$ from base code $S$, and key $\mathbf{P}_k$, value $\mathbf{P}_v$ from $\mathbf{P}_{raw}$:
    $$ \mathbf{P}_q = W_Q \cdot S, \quad \mathbf{P}_k = W_K \cdot \mathbf{P}_{raw}, \quad \mathbf{P}_v = W_V \cdot \mathbf{P}_{raw} $$
    [S1].
    d. Compute final implicit feature $\mathbf{P}_{nr}$ using cross-attention:
    $$ \mathbf{P}_{nr} = \text{softmax}(\mathbf{P}_q \cdot \mathbf{P}_k^\top) \cdot \mathbf{P}_v $$
    [S1].

6.  **Non-Rigid Branch Prediction:** Predict color and density residuals $\Delta \mathbf{c}, \Delta \sigma$ using MLP $M_{nr}$ conditioned on $\mathbf{f}^*_{\mathbf{x}_c}$ and $\mathbf{P}_{nr}$:
    $$ \Delta \mathbf{c}, \Delta \sigma = M_{nr}(\mathbf{f}^*_{\mathbf{x}_c}; \mathbf{P}_{nr}) $$
    [S1].

7.  **Compositional Rendering:** For each ray $\mathbf{r}$, query $M$ samples. Compute final RGB $\mathbf{C}_{final}$ using stratified sampling and volume rendering with compositional density $(\sigma + \Delta \sigma)$ and color $(\mathbf{c} + \Delta \mathbf{c})$ [S1]:
    $$ \mathbf{C}_{final}(\mathbf{r}) = \sum_{m=1}^M T_m (1 - \exp(-(\sigma_m + \Delta \sigma_m)\delta_m)) (\mathbf{c}_m + \Delta \mathbf{c}_m) $$
    where transmittance $T_m = \exp(-\sum_{n=1}^{m-1} \sigma_n \delta_n)$ and $\delta_m$ is the adjacent distance from the $m$-th to the $m+1$-th sample [S1].

8.  **Multi-Subject Extension (Optional):** For subject $i$, query global features from global MHE $\psi_{hash}^G$ and slice local features from local MHE $\psi_{hash}^i$. Concatenate global features, sliced local features, and subject ID code $S_i$ to predict $\mathbf{c}, \sigma$:
    $$ \mathbf{c}, \sigma = M_{rigid}(\psi_{hash}^G(\mathbf{x}_c) \oplus (\psi_{hash}^i(\mathbf{x}_c))^{:H} \oplus S_i) $$
    [S1].

**Parameters:**
*   $K$: Total number of joints in the skeletal model (23) [S1].
*   $L$: Number of frequency bands in sinusoidal positional encoding (10) [S1].
*   $\lambda$: Hyperparameter for balancing rigid and final loss terms (0.2) [S1].
*   $H$: Feature dimension per MHE level (2) [S1].
*   $M$: Samples per ray (256) [S1].
*   $N_p$: Patches per iteration (6) [S1].
*   Patch size: $32 \times 32$ [S1].

**Pitfalls:**
*   Spatial offset strategies suffer from high computational complexity because a single spatial offset spans an unbounded range and is unique for every 3D point across all input frames and body poses [S1].
*   Spatial offset strategies suffer from misaligned learning objectives because the learning objective of spatial offsets is not directly aligned with conventional RGB-based supervision [S1].

## Operating characteristics
*   **Time Complexity:** Training time is significantly reduced compared to offset-based methods. Single-subject training takes 1–2 hours on an RTX 3090, while multi-subject training (6 subjects) takes ~2 hours [S1].
*   **Memory Complexity:** Uses a single MHE for single-subject, or global + local MHEs for multi-subject. MHE size depends on the number of levels and hash table size (not specified in sources) [S1].
*   **Performance:** Achieves state-of-the-art PSNR/SSIM/LPIPS* on ZJU-MoCap and MonoCap datasets, comparable or better than HumanNeRF, Instant-NVR, GauHuman, NHP, and GHuNeRF [S1].
*   **Strengths:** Direct color supervision for non-rigid motions, reduced learning complexity, efficient training, multi-subject support [S1].
*   **Limitations:** Requires accurate skeletal joint positions [S1].

## Background
MoCo-NeRF was proposed by J. Kim et al. in 2024 [S1]. It addresses the limitations of spatial offset strategies in dynamic human modeling, which suffer from high computational complexity and misaligned learning objectives [S1]. The method builds on the principles of Neural Radiance Fields (NeRF) and linear blend skinning [S1].
