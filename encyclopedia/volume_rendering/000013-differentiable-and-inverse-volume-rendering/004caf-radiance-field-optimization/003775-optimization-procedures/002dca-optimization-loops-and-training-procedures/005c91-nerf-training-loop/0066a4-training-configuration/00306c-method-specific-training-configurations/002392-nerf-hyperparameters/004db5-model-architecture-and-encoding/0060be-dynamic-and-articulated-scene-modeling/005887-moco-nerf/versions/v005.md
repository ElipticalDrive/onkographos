# MoCo-NeRF

Also called: Motion-Oriented Compositional Neural Radiance Fields

## Overview
MoCo-NeRF is a framework for free-viewpoint rendering of monocular human videos that models non-rigid body motions as radiance residual fields rather than spatial offsets, using rigid skeletal transformations as a prior [S1]. It decomposes the representation into a rigid branch learning a canonical T-pose radiance field and a non-rigid branch optimizing pose-driven radiance residuals, allowing direct supervision from ground-truth pixel colors [S1]. Unlike offset-based strategies that suffer from high computational complexity and misaligned learning objectives, MoCo-NeRF reduces prediction range to the radiance space and establishes direct RGB-based supervision for both rigid and non-rigid components [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Monocular video frames $I_j$, camera poses, and skeletal joint positions $J = \{j_i\}_{i=1}^{23}$ for each frame.
*   **Outputs:** Rendered RGB images $\hat{C}(r)$ for arbitrary viewpoints.

**Data Structures:**
1.  **Skeletal Weights Volume Decoder:** Optimizes canonical skinning weights $w^c_k$ for $K$ joints [S1].
2.  **Multi-Hash Encoding (MHE):**
    *   **Global MHE ($\psi^G_{hash}$):** 4 levels, feature dimension $H=2$. Shared across subjects [S1].
    *   **Local MHEs ($\psi^i_{hash}$):** 16 levels, feature dimension $H=2$. One per subject $i$ [S1].
    *   **Feature Layout:** Features are vectors of size $H$. Slicing operation $(\cdot)^{:H}$ takes the first $H$ dimensions [S1].
3.  **Learnable Base Code ($S$):** Vector in $\mathbb{R}^{64}$, randomly initialized [S1].
4.  **Pose-Embedded Implicit Feature ($P_{nr}$):** Output of cross-attention, size determined by projection [S1].
5.  **MLP Decoders:**
    *   $M_{rigid}$: Predicts rigid color $\mathbf{c}$ and density $\sigma$ [S1].
    *   $M_{nr}$: Predicts residuals $\Delta \mathbf{c}$ and $\Delta \sigma$, conditioned on $P_{nr}$ [S1].

**Numbered Steps:**

1.  **Canonical Point Transformation:**
    For a query point $\mathbf{x}$ in observation space, compute the canonical point $\mathbf{x}_c$ using inverse linear blend skinning [S1]:
    $$ \mathbf{x}_c = \sum_{k=1}^K w^o_k (R_k \mathbf{x} + \mathbf{t}_k) $$
    where $R_k, \mathbf{t}_k$ are rotation and translation of bone $k$, and observation weights $w^o_k$ are computed from canonical weights $w^c_k$ [S1]:
    $$ w^o_k = \frac{w^c_k(R_k \mathbf{x} + \mathbf{t}_k)}{\sum_{j=1}^K w^c_j(R_j \mathbf{x} + \mathbf{t}_j)} $$
    The canonical weights $w^c_k$ are optimized via an explicit volume decoder [S1].

2.  **Rigid Branch Feature Query:**
    Query multiresolution volumetric features $\mathbf{f}_{\mathbf{x}_c}$ from the MHE $\psi_{hash}$ (global for multi-subject, local for single-subject) [S1]:
    $$ \mathbf{f}_{\mathbf{x}_c} = \psi_{hash}(\mathbf{x}_c) $$
    Slice the first half ($H$ dimensions) of $\mathbf{f}_{\mathbf{x}_c}$ at each resolution level to compute $\mathbf{f}^{:H}_{\mathbf{x}_c}$ [S1].

3.  **Rigid Radiance Prediction:**
    For multi-subject, concatenate global features, sliced local features, and subject ID code $\mathbf{S}_i$ [S1]:
    $$ \mathbf{f}_{concat} = \psi^G_{hash}(\mathbf{x}_c) \oplus (\psi^i_{hash}(\mathbf{x}_c))^{:H} \oplus \mathbf{S}_i $$
    For single-subject, $\mathbf{f}_{concat} = \mathbf{f}^{:H}_{\mathbf{x}_c}$ [S1].
    Predict rigid color $\mathbf{c}$ and density $\sigma$ using $M_{rigid}$ [S1]:
    $$ \mathbf{c}, \sigma = M_{rigid}(\mathbf{f}_{concat}) $$

4.  **Non-Rigid Feature Preparation:**
    Use the full feature $\mathbf{f}_{\mathbf{x}_c}$ (not sliced). Freeze the first half representing canonical radiance. Denote the remaining optimized half as $\mathbf{f}^*_{\mathbf{x}_c}$ [S1].

5.  **Pose-Embedded Implicit Feature Generation:**
    *   Initialize learnable base code $\mathbf{S} \in \mathbb{R}^{64}$ [S1].
    *   Apply sinusoidal positional encoding $\gamma$ to 23 joint positions $J$:
        $$ \gamma(\mathbf{j}_i) = [\mathbf{j}_i, \sin(2^0 \pi \mathbf{j}_i), \cos(2^0 \pi \mathbf{j}_i), \dots, \sin(2^{L-1} \pi \mathbf{j}_i), \cos(2^{L-1} \pi \mathbf{j}_i)] $$
        where $L=10$ frequency bands [S1]. Result $\gamma(J) \in \mathbb{R}^{23 \times 63}$.
    *   Project to raw pose-embedded code $\mathbf{P}_{raw}$ using projection matrix $\mathbf{W}_p$:
        $$ \mathbf{P}_{raw} = \mathbf{W}_p \cdot \gamma(J) $$
    *   Generate query $\mathbf{P}_q$ from $\mathbf{S}$, and key $\mathbf{P}_k$, value $\mathbf{P}_v$ from $\mathbf{P}_{raw}$ via linear projections $\mathbf{W}_Q, \mathbf{W}_K, \mathbf{W}_V$ [S1]:
        $$ \mathbf{P}_q = \mathbf{W}_Q \cdot \mathbf{S}, \quad \mathbf{P}_k = \mathbf{W}_K \cdot \mathbf{P}_{raw}, \quad \mathbf{P}_v = \mathbf{W}_V \cdot \mathbf{P}_{raw} $$
    *   Compute final implicit feature $\mathbf{P}_{nr}$ using cross-attention [S1]:
        $$ \mathbf{P}_{nr} = \text{softmax}(\mathbf{P}_q \cdot \mathbf{P}_k^\top) \cdot \mathbf{P}_v $$

6.  **Non-Rigid Residual Prediction:**
    Predict color and density residuals $\Delta \mathbf{c}, \Delta \sigma$ using $M_{nr}$ conditioned on $\mathbf{f}^*_{\mathbf{x}_c}$ and $\mathbf{P}_{nr}$ [S1]:
    $$ \Delta \mathbf{c}, \Delta \sigma = M_{nr}(\mathbf{f}^*_{\mathbf{x}_c}; \mathbf{P}_{nr}) $$
    The source notes that $\mathbf{P}_{nr}$ is concatenated to the first intermediate output of $M_{nr}$ [S1].

7.  **Compositional Rendering:**
    For each ray $r$, query $M$ samples. Compute final RGB $\hat{C}_{final}$ using stratified sampling and volume rendering with compositional density $(\sigma + \Delta \sigma)$ and color $(\mathbf{c} + \Delta \mathbf{c})$ [S1]:
    $$ \hat{C}_{final}(r) = \sum_{m=1}^M T_m (1 - \exp(-(\sigma_m + \Delta \sigma_m)\delta_m)) (\mathbf{c}_m + \Delta \mathbf{c}_m) $$
    where transmittance $T_m = \exp(-\sum_{n=1}^{m-1} \sigma_n \delta_n)$ and $\delta_m$ is the distance between adjacent samples [S1].
    Also compute $\hat{C}_{rigid}$ from $(\mathbf{c}, \sigma)$ for loss calculation [S1].

**Parameters:**
*   $\lambda$: Hyperparameter for balancing rigid and final loss terms, typically $\lambda=0.2$ [S1].
*   $L$: Number of frequency bands in sinusoidal positional encoding, typically $L=10$ [S1].
*   $H$: Feature dimension for MHE, typically $H=2$ [S1].
*   Optimizer: Adam with betas $(0.9, 0.99)$ [S1].
*   Learning Rate: $5 \times 10^{-5}$ for skeletal weights volume decoder, $5 \times 10^{-3}$ for all other components [S1].
*   Sampling: 6 patches of size $32 \times 32$ per iteration, 256 samples per ray [S1].

**Edge Cases and Pitfalls:**
*   **Spatial Offset Misalignment:** Traditional spatial offset strategies suffer from misaligned learning objectives because the learning objective of spatial offsets is not directly aligned with conventional RGB-based supervision [S1]. MoCo-NeRF avoids this by modeling residuals in radiance space [S1].
*   **Unbounded Range:** Spatial offsets span an unbounded range and are unique for every 3D point, escalating computational complexity [S1]. MoCo-NeRF reduces the prediction range to the radiance space [S1].
*   **Precision:** Not given in the sources.

## Operating characteristics
*   **Time Complexity:** Training time is significantly reduced compared to offset-based methods. Single-subject training takes 1–2 hours on an RTX 3090, compared to 38.9 hours for HumanNeRF [S1]. Multi-subject training (6 subjects) takes ~2 hours, compared to ~123 hours for NHP [S1].
*   **Memory Complexity:** Uses a single MHE for single-subject, and global + local MHEs for multi-subject. The exact memory footprint is not given, but the use of hash encoding implies lower memory than dense voxel grids [S1].
*   **Performance:** On ZJU-MoCap single-subject evaluation (subjects 377, 386, 387, 392, 393, 394), MoCo-NeRF achieves PSNR 31.06, SSIM 0.9734, LPIPS* 28.83 [S1]. On multi-subject evaluation (subjects 377, 386, 392), it achieves PSNR 31.97, SSIM 0.9781, LPIPS* 24.54 [S1].
*   **Strengths:** Direct RGB supervision for non-rigid motions; efficient training; scalable to multi-subject; handles complex cloth dynamics [S1].
*   **Limitations:** Requires accurate skeletal joint positions as input [S1]. Performance depends on the quality of the skeletal transformation [S1].
*   **When to use:** Free-viewpoint rendering of dynamic humans from monocular videos where training efficiency and high fidelity are required [S1].
*   **When not to use:** Static scenes (use standard NeRF); multi-view setups with dense cameras (other methods may be more efficient); scenes without clear skeletal structure [S1].

## Background
MoCo-NeRF was proposed by J. Kim et al. in 2024 [S1]. It addresses the challenges of novel view synthesis of monocular human videos, specifically the modeling of non-rigid motions (e.g., cloth dynamics) which are distinct from skeletal articulations [S1]. Previous methods modeled these motions as spatial 3D offsets, leading to high computational complexity and misaligned learning objectives [S1]. MoCo-NeRF introduces a motion-oriented compositional approach, decomposing the radiance field into rigid and non-rigid branches, and utilizes a cross-attention module for pose-embedded implicit features [S1]. It has been evaluated on the ZJU-MoCap and MonoCap datasets [S1].
