# CCNeRF

Also called: Compressible-Composable NeRF, Rank-residual Decomposition NeRF

## Overview
CCNeRF is a neural field representation that enables efficient compression and composition of 3D scenes by learning a hybrid tensor rank decomposition of the scene without using neural networks for rendering [S1]. Unlike NeRF variants that rely on a shared MLP renderer (e.g., NSVF) or hybrid tensor-MLP approaches (e.g., TensoRF), CCNeRF models the radiance field *only* with tensor rank decomposition, preserving low-rank approximation properties to allow dynamic model size adjustment via rank truncation and arbitrary composition via rank concatenation [S1].

## How it works
CCNeRF represents a 3D scene as a 4D feature volume described by rank components and a weight matrix. The method replaces the implicit MLP-based query with an explicit tensor decomposition, allowing the scene to be queried, compressed, and composed using linear algebra operations [S1].

### Inputs and Outputs
*   **Input:** A set of 2D images with known camera poses $(o, d)$ and a target rank configuration (vector-based vs. matrix-based components).
*   **Output:** A compressed radiance field representation consisting of factor matrices/vectors, a core tensor (or weight matrix), and transformation matrices for composed objects.

### Data Structures
The model structure consists of two main parts [S1]:
1.  **Rank Weights Matrix ($W$):** A matrix storing weights for different feature channels.
2.  **Decomposed Rank Components:** A set of components that are either vector-based (CP decomposition) or matrix-based (triple plane variant). The ratio of vector- to matrix-based components is controllable.

For a 3D tensor $T \in \mathbb{R}^{H \times W \times D}$, the Tucker decomposition is defined as [S1]:
$$ T_{i,j,k} = \sum_{p=1}^P \sum_{q=1}^Q \sum_{r=1}^R S_{p,q,r} U^x_{i,p} U^y_{j,q} U^z_{k,r} $$
where $S$ is the core tensor and $U^x, U^y, U^z$ are factor matrices. In CCNeRF, this is extended to a hybrid decomposition where some dimensions use vector factors (CP) and others use matrix factors (triple plane) [S1].

### Numbered Steps

1.  **Initialization:** Initialize the rank components (factor matrices/vectors) and the weight matrix. The initial decomposition can be obtained via standard tensor decomposition algorithms (e.g., HOSVD) or learned directly [S1].
2.  **Rank-Residual Learning:** During training, a rank-residual learning strategy is employed. This strategy encourages lower ranks to preserve more important information of the whole scene. This is achieved by optimizing the model such that the residual error is minimized while maintaining the low-rank structure [S1].
3.  **Querying a 3D Coordinate:** To render a pixel, rays are sampled along the viewing direction. For each sample point $\mathbf{x}$ along the ray:
    *   Project the coordinate $\mathbf{x}$ to the decomposed vectors or matrices.
    *   Perform weighted interpolation using the stored rank weights $W$ and the projected features to obtain the density $\sigma$ and color $\mathbf{c}$ [S1].
    *   The specific interpolation depends on the hybrid decomposition type (CP or triple plane). For CP, the feature is the sum of outer products of vectors. For triple plane, it involves interactions between plane factors [S1].
4.  **Volume Rendering:** Compute the pixel color using the standard volume rendering equation [S1]:
    $$ \hat{C}(r) = \sum_i T_i \alpha_i c_i $$
    where $T_i = \prod_{j<i} (1 - \alpha_i)$, $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, and $\delta_i = t_{i+1} - t_i$. Here $\sigma_i$ is density, $c_i$ is color, and $t_i$ is the sample position along ray $r$ from origin $o$ with direction $d$ [S1].
5.  **Compression (Rank Truncation):** To compress the model, an empirical sort-and-truncate strategy is used. The rank components are sorted by importance (derived from the weight matrix or singular values), and the least important components are truncated. This achieves near-optimal low-rank approximation at any targeted rank without retraining [S1].
6.  **Composition:** To compose multiple models into a single scene:
    *   Concatenate the rank components of different objects along the rank dimension.
    *   Record a transformation matrix for each object to control its position and orientation.
    *   The composed scene is queried by selecting the appropriate rank components based on the spatial location and applying the transformation [S1].

    """
    Compress the model by truncating ranks.
    
    Args:
        rank_components: Current rank components
        weights: Current weight matrix
        target_rank: Desired number of ranks to keep
    
    Returns:
        compressed_components: Truncated rank components
        compressed_weights: Truncated weights
    """
    # Empirical sort-and-truncate strategy
    # Sort ranks by importance
    importance = compute_importance(weights)
    sorted_indices = np.argsort(importance)[::-1]
    
    # Keep top target_rank ranks
    selected_indices = sorted_indices[:target_rank]
    
    # Truncate components and weights
    compressed_components = [comp[selected_indices] for comp in rank_components]
    compressed_weights = weights[selected_indices]
    
    return compressed_components, compressed_weights

def compose_models(models):
    """
    Compose multiple CCNeRF models into one scene.
    
    Args:
        models: List of tuples (rank_components, weights, transform_matrix)
    
    Returns:
        composed_components: Concatenated rank components
        composed_weights: Concatenated weights
        transforms: List of transformation matrices
    """
    # Concatenate rank components along the rank dimension
    # [G] Assuming all models have the same feature dimension
    composed_components = []
    for i in range(len(models[0][0])):
        comp_list = [m[0][i] for m in models]
        composed_components.append(np.concatenate(comp_list, axis=0))
    
    # Concatenate weights
    composed_weights = np.concatenate([m[1] for m in models], axis=0)
    
    # Record transformation matrices
    transforms = [m[2] for m in models]
    
    return composed_components, composed_weights, transforms

### Parameters
*   **Rank Truncation:** The number of components kept in the decomposition determines the model size and detail level. Lower ranks preserve primary information due to rank-residual learning [S1].
*   **Vector-to-Matrix Ratio:** The ratio of vector-based (CP) to matrix-based (triple plane) components is controllable to trade off between model size and performance [S1].

### Edge Cases and Pitfalls
*   **Truncated HOSVD:** Standard truncated Higher-Order SVD (HOSVD) does not hold the optimal property of truncated SVD, but yields a quasi-optimal solution sufficient for practical use [S1].
*   **MLP Dependency:** Unlike TensoRF, CCNeRF avoids using MLPs in the decomposition to preserve low-rank approximation properties. Using MLPs would disturb the tensor rank decomposition property and prevent compression or composition [S1].

## Operating characteristics
*   **Time Complexity:** Querying is faster than MLP-based NeRF as it involves linear algebra operations (projection and interpolation) rather than forward passes through a neural network.
*   **Memory Complexity:** Memory usage is determined by the size of the rank components and weight matrix. Compression can significantly reduce memory usage by truncating ranks.
*   **Performance:** Achieves comparable rendering quality to state-of-the-art methods while enabling extra capabilities of compression and composition [S1].
*   **Strengths:** No neural networks for rendering, allowing arbitrary composition without retraining or compatibility constraints. Dynamic model size adjustment via rank truncation without retraining.
*   **Limitations:** The quasi-optimal nature of truncated HOSVD may lead to suboptimal compression compared to true optimal low-rank approximation. The hybrid decomposition requires careful tuning of the vector-to-matrix ratio.

## Background
CCNeRF was introduced by Jiaxiang Tang, Xiaokang Chen, Jingbo Wang, and Gang Zeng from Peking University and Chinese University of Hong Kong in 2022 [S1]. The paper addresses the difficulty of manipulating implicit NeRF representations, which are often restricted by shared renderer networks or suffer from large model sizes. The method is motivated by the low-rank approximation property of the SVD algorithm and proposes a rank-residual learning strategy to encourage the preservation of primary information in lower ranks [S1].
