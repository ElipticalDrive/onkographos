# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF training configuration defines the optimization procedure for text-guided stylization of Neural Radiance Fields (NeRFs) by minimizing the negative cosine similarity between rendered images and text prompts in the CLIP embedding space [S1, S2]. It distinguishes itself from standard NeRF optimization by freezing density-related parameters and utilizing patch-based rendering to manage memory constraints while enforcing semantic alignment via directional CLIP losses [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A pre-trained NeRF model (encoding position $\mathbf{x}$ and direction $\mathbf{d}$), a target text prompt $\mathbf{t}_{tgt}$, an optional source text prompt $\mathbf{t}_{src}$, and a source image $\mathbf{I}_{src}$ (for relative loss).
*   **Outputs:** Stylized NeRF parameters (specifically color and semantic features, with density frozen).

**Data Structures:**
*   **CLIP Encoder:** Uses CLIP ViT-B/32 [S1].
*   **Patch Renderer:** Renders a $128 \times 128$ pixel patch [S1].
*   **Ray Sampling:** Rays within the patch are sampled with a stride of 5, creating a receptive field of $640 \times 640$ on the original image scale [S1].
*   **Sampling Points:** Importance sampling uses 16 points per ray during patch rendering [S1]. The fine MLP uses a total of 80 samples (64 coarse + 16 fine) [S1].

**Formulas:**
The core loss is based on the cosine similarity between normalized CLIP embeddings [S2].

1.  **Absolute Directional CLIP Loss:**
    Measures the trajectory from the origin to the target text in CLIP space [S2]:
    $$ \mathcal{L}_{dir} = 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) \rangle $$
    where $\hat{\mathcal{E}}_i$ and $\hat{\mathcal{E}}_t$ are normalized image and text embeddings, respectively [S2].

2.  **Relative Directional CLIP Loss:**
    Measures the trajectory from the source to the target, mitigating mode collapse [S2]:
    $$ \mathcal{L}_{dir} = 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}) - \hat{\mathcal{E}}_i(\mathbf{I}_{src}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) - \hat{\mathcal{E}}_t(\mathbf{t}_{src}) \rangle $$
    where $\mathbf{I}_{tgt}$ is the rendered view and $\mathbf{I}_{src}$ is the source image [S2].

**Parameters:**
*   **Iterations:** 500 [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** 0.0001 [S1].
*   **Freezing:** Sub-parameters related to density are frozen; only color/semantic parameters are optimized [S1].

**Pseudocode:**
```python
# Configuration
iterations = 500
learning_rate = 0.0001
patch_size = 128
ray_stride = 5
num_importance_samples = 16
num_fine_samples = 64
total_samples = num_fine_samples + num_importance_samples

# Initialization
nerf_model = load_nerf()
clip_encoder = load_clip_vit_b_32()
optimizer = Adam(nerf_model.parameters(), lr=learning_rate)

# Freeze density parameters
for param in nerf_model.density_parameters:
    param.requires_grad = False

for step in range(iterations):
    # 1. Sample a random pose from the training dataset
    pose = sample_random_pose()
    
    # 2. Generate ray coordinates for a 128x128 patch
    # Rays are sampled with stride 5 to cover a 640x640 receptive field
    ray_origins, ray_directions = generate_patch_rays(pose, patch_size, ray_stride)
    
    # 3. Render the patch using NeRF
    # Use reduced importance sampling for memory efficiency
    colors, depths = render_nerf_patch(
        nerf_model, 
        ray_origins, 
        ray_directions, 
        num_samples=num_importance_samples,
        num_fine_samples=num_fine_samples
    )
    
    # 4. Resize rendered patch to match CLIP input requirements if necessary
    # (Bilinear interpolation is mentioned as part of the efficient method)
    rendered_image = resize_bilinear(colors, target_size=clip_encoder.input_size)
    
    # 5. Compute CLIP embeddings
    image_embedding = clip_encoder.encode_image(rendered_image)
    text_embedding = clip_encoder.encode_text(target_prompt)
    
    # 6. Normalize embeddings
    image_embedding = normalize(image_embedding)
    text_embedding = normalize(text_embedding)
    
    # 7. Compute Loss (Absolute Directional)
    # L_dir = 1 - <I_tgt, T_tgt>
    loss = 1.0 - cosine_similarity(image_embedding, text_embedding)
    
    # 8. Backpropagate and optimize
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

**Edge Cases and Pitfalls:**
*   **Memory Constraints:** Naive differentiable rendering of high-resolution images is intractable due to memory limits [S1]. The patch-based approach with stride sampling is required [S1].
*   **Mode Collapse:** The absolute directional CLIP loss can cause mode collapse of the generator and hurt generation diversity [S2].
*   **Insufficient Magnitude:** Directional loss alone struggles to reach sufficient stylization magnitude, resulting in weak style transfer [S2]. Global contrastive losses may be needed to ensure proper magnitude [S2].

## Operating characteristics
*   **Time Complexity:** Determined by 500 iterations of patch rendering and CLIP encoding [S1].
*   **Memory Complexity:** Reduced by using $128 \times 128$ patches and 16 importance samples per ray instead of full-resolution rendering [S1].
*   **Strengths:** Enables text-guided stylization of NeRFs; efficient memory usage via patch rendering [S1, S2].
*   **Limitations:** Absolute directional loss risks mode collapse and insufficient stylization magnitude [S2].
*   **When to use:** Text-driven NeRF stylization where memory is constrained [S1, S2].
*   **When not to use:** When high diversity or strong magnitude stylization is required without additional contrastive losses [S2].

## Background
CLIPNeRF was introduced by Wang et al. in 2021, extending the StyleCLIP and StyleGAN-NADA frameworks to 3D radiance fields [S2]. It was designed to enable text-driven editing of NeRFs by aligning rendered views with text prompts in the CLIP embedding space [S2]. The method addresses the intractability of full-resolution differentiable rendering by using efficient patch-based sampling [S1].
