# Dynamic Appearance Particle Neural Radiance Field

Also called: Dynamic Appearance Particle NeRF, Lagrangian dynamic model in NeRF

## Overview
Dynamic Appearance Particle Neural Radiance Field is a method for modeling dynamic scenes from monocular video data by integrating a particle-based motion network with a static grid-based radiance field [S1]. It solves the problem of reconstructing temporally varying scenes without requiring multi-view stereo data at each time step, which is a constraint of related particle-based methods like ParticleNeRF [S1]. Unlike ParticleNeRF, which encodes the entire scene with particles and relies on radius nearest neighbor searching, this method applies appearance particles only to dynamic elements and uses a grid-based field with linear interpolation for efficient querying [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** Monocular video data (one camera view per time frame $t$).
*   **Outputs:** Rendered pixel color $C(\mathbf{r}, t)$ for a given ray $\mathbf{r}$ and time $t$.

**Data Structures**
The method maintains two primary feature fields:
1.  **Static Field ($V_s$):** A time-independent grid-based model (e.g., canonical feature field). It stores static scene information.
2.  **Dynamic Field ($V_{td}$):** A particle-based representation. It consists of an ensemble of particles that move over time. The field is defined as a convolution with a kernel to integrate over finite volumes.

**Notation**
*   $\mathbf{r}(s) = \mathbf{o} + s\mathbf{d}$: Ray equation, where $\mathbf{o}$ is the camera center, $\mathbf{d}$ is the direction, and $s$ is the distance.
*   $t$: Time index.
*   $V_s(\mathbf{x})$: Static feature field at location $\mathbf{x}$.
*   $V_{td}(\mathbf{x})$: Dynamic feature field at location $\mathbf{x}$.
*   $w_t(\mathbf{x})$: Weight function indicating if the dynamic field is effective at $(\mathbf{x}, t)$.
*   $W(\mathbf{x})$: Finite support kernel replacing the Dirac delta function.

**Formulas**
The total feature field $V(\mathbf{x}, t)$ is a superposition of static and dynamic components [S1]:
$$
V(\mathbf{x}, t) = (1 - w_t(\mathbf{x}))V_s(\mathbf{x}) + w_t(\mathbf{x})V_{td}(\mathbf{x})
$$
where $w_t(\mathbf{x}) = 1$ if the dynamic field is effective at $(\mathbf{x}, t)$ and $0$ otherwise [S1]. The support of the dynamic field is implied by the particle representation [S1].

The dynamic field $V_{td}$ is formulated as a convolution with a kernel $W$ with finite support [S1]:
$$
V_{td}(\mathbf{x}) = (V_{td} * W)(\mathbf{x}) = \int V_{td}(\mathbf{x}') W(\mathbf{x} - \mathbf{x}') d\nu(\mathbf{x}')
$$
where $W(\mathbf{x}) = 0$ when $\|\mathbf{x}\|$ exceeds a small radius, and $\int W(\mathbf{x}) d\nu(\mathbf{x}) = 1$ [S1].

The rendering equation for pixel color $C(\mathbf{r}, t)$ is [S1]:
$$
C(\mathbf{r}, t) = \int_{s_n}^{s_f} T(s, t) \sigma(\mathbf{r}(s), t) \mathbf{c}(\mathbf{r}(s), \mathbf{d}, t) ds
$$
where $T(s, t) = \exp\left(-\int_{s_n}^{s} \sigma(\mathbf{r}(s'), t) ds'\right)$ is the accumulated transmittance, $\sigma$ is volume density, and $\mathbf{c}$ is emitted radiance [S1].

**Parameters**
*   $w_t(\mathbf{x})$: Binary weight (0 or 1) determining the contribution of the dynamic field [S1].
*   Kernel support radius: A small radius defining the local support of $W(\mathbf{x})$ [S1].

**Steps**
1.  **Ray Casting:** For a target time $t$, cast a ray $\mathbf{r}(s) = \mathbf{o} + s\mathbf{d}$ from the camera center $\mathbf{o}$ through the pixel, with $s \in [s_n, s_f]$ [S1].
2.  **Sample Points:** Sample points $\mathbf{x}$ along the ray [S1].
3.  **Query Static Field:** Retrieve the static feature value $V_s(\mathbf{x})$ from the grid-based model using linear interpolation [S1].
4.  **Query Dynamic Field:**
    a. Identify particles contributing to location $\mathbf{x}$ at time $t$.
    b. Compute $V_{td}(\mathbf{x})$ by convolving the particle features with the kernel $W(\mathbf{x} - \mathbf{x}')$ [S1].
5.  **Superpose Fields:** Compute the combined field $V(\mathbf{x}, t)$ using the weight $w_t(\mathbf{x})$ [S1].
6.  **Decode:** Decode $V(\mathbf{x}, t)$ to obtain density $\sigma(\mathbf{x}, t)$ and color $\mathbf{c}(\mathbf{x}, \mathbf{d}, t)$ using MLPs [S1].
7.  **Volume Rendering:** Integrate $\sigma$ and $\mathbf{c}$ along the ray to compute $C(\mathbf{r}, t)$ [S1].

**Pseudocode**
```python
def render_dynamic_nerf(ray_o, ray_d, time_t, static_grid, particle_system, kernel_W):
    """
    Renders a single pixel for a given ray and time using Dynamic Appearance Particle NeRF.
    
    Args:
        ray_o: Camera origin (3D vector).
        ray_d: Ray direction (3D vector).
        time_t: Current time index.
        static_grid: Grid-based static feature field.
        particle_system: List of particles with positions, velocities, and features.
        kernel_W: Finite support kernel function.
        
    Returns:
        color: Rendered pixel color.
    """
    # 1. Sample points along the ray
    # In practice, this involves sampling N points between near and far bounds
    samples = sample_points_along_ray(ray_o, ray_d, num_samples=128)
    
    accumulated_transmittance = 1.0
    accumulated_color = [0.0, 0.0, 0.0]
    
    for x in samples:
        # 2. Query Static Field
        # Linear interpolation on the static grid
        v_s = static_grid.query(x)
        
        # 3. Query Dynamic Field
        # Identify particles within the kernel support radius of x
        contributing_particles = get_particles_in_radius(particle_system, x, kernel_W.support_radius)
        
        v_td = 0.0
        for particle in contributing_particles:
            # Compute kernel weight based on distance
            dist = norm(x - particle.position)
            w_kernel = kernel_W.evaluate(dist)
            
            # Interpolate particle feature (simplified)
            v_particle = particle.feature
            
            # Convolve: sum of particle features weighted by kernel
            v_td += v_particle * w_kernel
            
        # 4. Superpose Fields
        # Determine if dynamic field is effective at this location and time
        # This is implied by the particle representation; if no particles contribute, w_t is 0
        w_t = 1.0 if len(contributing_particles) > 0 else 0.0
        
        v_combined = (1.0 - w_t) * v_s + w_t * v_td
        
        # 5. Decode to Density and Color
        # Using MLPs defined in the source architecture
        sigma, color = decode_features(v_combined)
        
        # 6. Volume Rendering Accumulation
        alpha = 1.0 - exp(-sigma * dist_between_samples)
        transmittance = accumulated_transmittance
        accumulated_transmittance *= (1.0 - alpha)
        
        accumulated_color += transmittance * alpha * color
        
        if accumulated_transmittance < 1e-4:
            break
            
    return accumulated_color
```

**Edge Cases and Pitfalls**
*   **Precision:** The kernel approximation replaces the Dirac delta function. The choice of kernel support radius affects the smoothness and quantization of the dynamic field [S1].
*   **Boundaries:** The method assumes the dynamic field is localized. If dynamic elements move outside the particle system's coverage, they may not be rendered correctly [S1].
*   **Monocular Limitation:** The method is designed for monocular video. It does not leverage multi-view consistency at each time step, which may limit reconstruction quality compared to multi-view methods [S1].

## Subtopics

### ParticleNeRF
Encodes the entire scene with particles and uses radius nearest neighbor searching. Requires 20 camera views per time frame. [S1]

### InstantNGP
An alternative framework that can integrate the Lagrangian representation proposed in this method. [S1]

*   **Limitations:** Relies on particle representation for dynamics, which may have limited support; does not use multi-view stereo at each time step. [S1]

## Background
The method was proposed in a paper titled "Dynamic Appearance Particle Neural Radiance Field" [S1]. It builds on the Lagrangian dynamic model and integrates it into a NeRF framework. The work contrasts with ParticleNeRF, which encodes the entire scene with particles and requires multi-view data [S1]. The method is designed to capture and model scene dynamics across all time frames using a particle motion network and appearance particles [S1].
