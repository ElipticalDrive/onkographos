# NeRF Training Setup

Also called: Control-NeRF Training Setup, Nerfstudio Training

## Overview
This configuration establishes a reproducible training pipeline for Neural Radiance Fields (NeRFs) using the Nerfstudio library, specifically leveraging NerfAcc and Instant-NGP for fast convergence on static scenes [S2]. It distinguishes itself from standard NeRF baselines by replacing the positionally encoded 3D position input with a pre-sampled 64-dimensional feature vector from a volume, thereby omitting positional encoding for the spatial coordinates while retaining it for the viewing direction [S1]. This setup is designed for static environments with minimal dynamic elements, such as surgical scenes [S2].

## How it works
**Inputs and Outputs**
*   **Inputs:** Multi-view RGB images (e.g., LLFF datasets scaled to $504 \times 378$ resolution) [S1]; camera poses estimated via SfM methods (e.g., COLMAP, LocalRF) [S2]; a pre-computed volume $V_s$ containing 64-dimensional feature vectors [S1].
*   **Outputs:** Optimized network parameters for coarse ($\hat{C}_c$) and fine ($\hat{C}_f$) networks; rendered images and opacity maps [S1, S2].

**Data Structures**
*   **Feature Volume ($V_s$):** A 3D grid or implicit representation storing a 64-dimensional feature vector $\mathbf{v}_s$ at each spatial location [S1].
*   **Ray Bundle:** A batch of rays defined by origin $\mathbf{o}$ and direction $\mathbf{d}$, sampled from the input images [S2].
*   **Network Input:** The radiance function $F_\Theta$ accepts a tuple $(\mathbf{v}_s, \gamma(\mathbf{d}))$ [S1].

**Numbered Steps**
1.  **Data Preparation:** Extract equidistant frames from video or static images. Estimate camera poses using tools like COLMAP or LocalRF [S2]. Scale input images to $504 \times 378$ resolution [S1].
2.  **Ray Sampling:** For each training batch, sample 1024 rays from the input images based on the estimated camera poses [S1, S2]. Exclude specific regions (e.g., surgical tools or artifacts) if necessary [S2].
3.  **Feature Sampling:** For each point $\mathbf{p}$ along a ray, retrieve the 64-dimensional feature vector $\mathbf{v}_s$ from the volume $V_s$ using trilinear sampling $S(V_s, \mathbf{p})$ [S1]. No positional encoding is applied to $\mathbf{v}_s$ [S1].
4.  **Direction Encoding:** Apply positional encoding $\gamma(\mathbf{d})$ to the direction vector $\mathbf{d} \in \mathbb{R}^3$ [S1].
5.  **Coarse Network Optimization:** Optimize the coarse network $\hat{C}_c(\mathbf{r})$ which samples 64 points from evenly spaced bins along the ray length [S1].
6.  **Fine Network Sampling:** Use the opacity results from the coarse network to sample 64 additional points for the fine network $\hat{C}_f(\mathbf{r})$, focusing on relevant portions of the scene volume [S1].
7.  **Rendering:** Compute the final color $C(\mathbf{r})$ using the discretized volume rendering integral [S1]:
    $$ C(\mathbf{r}) = \int_{t_n}^{t_f} T(t)\sigma(\mathbf{v}_s)c(\mathbf{v}_s, \mathbf{d})dt $$
    where $T(t) = \exp\left(-\int_{t_n}^{t} \sigma(\mathbf{v}_s)ds\right)$ [S1].
8.  **Loss Computation and Update:** Compute the loss (e.g., mean squared error between predicted and ground truth colors) and update the network parameters using the scheduler [S3, unofficial].

**Formulas**
*   **Direction Positional Encoding:**
    $$ \gamma(\mathbf{p}) = [\sin(2^0\pi\mathbf{p}), \cos(2^0\pi\mathbf{p}), \dots, \sin(2^{L-1}\pi\mathbf{p}), \cos(2^{L-1}\pi\mathbf{p})] $$
    where $\mathbf{p}$ is each dimension of $\mathbf{d}$ and $L=4$ [S1].
*   **Volume Rendering Integral:**
    $$ C(\mathbf{r}) = \int_{t_n}^{t_f} T(t)\sigma(\mathbf{v}_s)c(\mathbf{v}_s, \mathbf{d})dt $$
    $$ T(t) = \exp\left(-\int_{t_n}^{t} \sigma(\mathbf{v}_s)ds\right) $$
    where $\mathbf{v}_s = S(V_s, \mathbf{p})$ is the sampled feature vector [S1].

**Parameters**
*   **Positional Encoding Depth ($L$):** 4 for direction vector [S1].
*   **Batch Size:** 1024 rays per batch [S1].
*   **Image Resolution:** $504 \times 378$ [S1].
*   **Coarse Points:** 64 evenly spaced bins [S1].
*   **Fine Points:** 64 additional points sampled based on coarse opacity [S1].
*   **Library:** Nerfstudio, including NerfAcc and Instant-NGP [S2].
*   **Hardware:** Single RTX A6000 GPU, 128 GB RAM [S2].

**Edge Cases and Pitfalls**
*   **Dynamic Content:** The setup is designed for static scenes. Presence of moving organs or surgical tools may require masking or dynamic handling [S2].
*   **Feature Volume Quality:** The quality of $\mathbf{v}_s$ directly impacts rendering. Trilinear sampling assumes a continuous volume representation [S1].
*   **Precision:** Standard floating-point precision is assumed for the rendering integral discretization [S1].

def positional_encoding(p, L=4):
    """
    Applies positional encoding to each dimension of p.

    # p is expected to be (..., 3)
    # We need to apply the encoding to each dimension
    # The formula is: [sin(2^0 pi p), cos(2^0 pi p), ..., sin(2^{L-1} pi p), cos(2^{L-1} pi p)]

    frequencies = 2.0 ** torch.arange(L, device=p.device).float() # (L,)
    
    # Expand p to (..., 3, 1) and frequencies to (1, 1, L)
    # p: (..., 3, 1)
    # frequencies: (1, 1, L)
    # result: (..., 3, L)
    
    scaled_p = p.unsqueeze(-1) * frequencies.unsqueeze(0).unsqueeze(0) # (..., 3, L)
    
    # Compute sin and cos

## Subtopics

### Image-Based NeRF Training
Training a NeRF using RGB images as ground truth, optimizing both geometry (via Eikonal loss) and appearance (via color loss) [S3, unofficial]. It involves loading datasets with `get_nerf_datasets`, sampling random pixels to construct ray bundles, and computing mean squared error for color loss [S3, unofficial]. Geometry regularization is added via Eikonal loss, similar to SDF training [S3, unofficial]. The learning rate is updated using a scheduler after each epoch [S3, unofficial]. This variant typically runs for 250 epochs on $128 \times 128$ images for datasets like Lego [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** Fast convergence is achieved using NerfAcc and Instant-NGP [S2].
*   **Memory Complexity:** Requires 128 GB RAM and a single RTX A6000 GPU [S2].
*   **Performance:** Evaluated on LLFF datasets at $504 \times 378$ resolution [S1].
*   **Strengths:** Fast training, suitable for static scenes with minimal dynamic content [S2].
*   **Limitations:** Not designed for highly dynamic scenes without modification [S2].
*   **When to Use:** Static scene reconstruction, especially in controlled environments like surgery [S2].
*   **When Not to Use:** Highly dynamic scenes or scenes with significant occlusions not handled by masking [S2].

## Background
The method originates from the Control-NeRF paper, which introduces editable feature volumes for scene rendering and manipulation [S1]. It was further adapted for laparoscopic surgical video rendering using the Nerfstudio library, NerfAcc, and Instant-NGP to handle static abdominal environments [S2]. The approach modifies the standard NeRF architecture by replacing positionally encoded 3D positions with sampled feature vectors [S1].
