# Model Architecture Modifications

Also called: NeRF Architecture Variants, Implicit Representation Modifications

## Overview
Model Architecture Modifications encompass the structural changes applied to the standard Neural Radiance Field (NeRF) backbone to address specific limitations such as geometric accuracy, rendering speed, dynamic scene handling, lighting conditions, and sparse input constraints. While the standard NeRF [Parent](3065-nerf-hyperparameters.md) uses two Multi-Layer Perceptrons (MLPs) to map 3D coordinates and view directions to density and color, this family introduces alternative representations (e.g., SDFs, Voxels, Point Clouds), auxiliary networks (e.g., for lighting, semantics, or uncertainty), and conditioning mechanisms (e.g., for time, pose, or external priors). These modifications set the method apart from the baseline by altering the input domain, output heads, or the underlying geometric prior, enabling capabilities like real-time rendering, explicit surface extraction, or robustness to sparse views.

## Shared principles
The standard NeRF architecture [Parent](3065-nerf-hyperparameters.md) serves as the baseline for all modifications. It consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ [14428-sparse-view-and-few-shot-optimization.md].

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories [14428-sparse-view-and-few-shot-optimization.md]:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation [14428-sparse-view-and-few-shot-optimization.md].
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
    [14428-sparse-view-and-few-shot-optimization.md].
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs) [14428-sparse-view-and-few-shot-optimization.md].

## Subtopics

### [DoF-NeRF](9432-dof-nerf.md)
DoF-NeRF extends the standard NeRF to simulate depth-of-field effects by modeling the Circle of Confusion (CoC). It differs from siblings by explicitly optimizing aperture and focus distance parameters per view, enabling the synthesis of all-in-focus views from shallow DoF inputs. Choose this method when dealing with images captured with a physical lens where focus blur is present.

### [NeRF-VPT](11770-nerf-vpt.md)
NeRF-VPT is a cascading view prompt tuning paradigm that uses RGB information from preceding rendering iterations as visual prompts. It differs from siblings by iteratively refining the network's output using internal priors without external networks. Choose this method for sparse-view settings to enhance image quality progressively.

### [Activation Feature Density Approximation](12492-activation-feature-density-approximation.md)
This method estimates volumetric density directly from intermediate activation features of the coarse MLP, replacing expensive fine network evaluations. It differs from siblings like SDF-based fields by retaining the standard density-based formulation. Choose this method to accelerate coarse-to-fine sampling.

### [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md)
SDF representations replace the density field $\sigma(\mathbf{x})$ with a continuous scalar field $s(\mathbf{x})$ representing distance to the nearest surface. This addresses geometric inaccuracy and surface holes typical of density-based NeRFs. Choose this method when explicit, smooth surface reconstruction is required.

### [Volume-Augmented NeRF](12973-volume-augmented-nerf.md)
Volume-Augmented NeRF binds an explicit fluid volume value $v_i$ to each sample point to handle dynamic fluid scenes. It differs from static NeRF by integrating differentiable fluid simulator outputs. Choose this method for dynamic scene reconstruction involving fluid dynamics.

### [Neural-PIL Decomposition Architecture](12975-neural-pil-decomposition-architecture.md)
This architecture separates scene geometry, material properties, and illumination into distinct networks. It differs from standard NeRF by predicting BRDF and illumination embeddings rather than direct color. Choose this method when input images have varying lighting conditions and explicit reflectance decomposition is needed.

### [SAID-NeRF](13619-said-nerf.md)
SAID-NeRF exploits instance masks from Visual Foundation Models to enhance surface estimation of transparent objects. It differs from standard NeRF by decomposing appearance into diffuse/specular components and using semantic segmentation. Choose this method for transparent object reconstruction requiring sharp depth estimates.

### [MINE](13661-mine.md)
MINE models the frustum of the source camera using a continuous depth Multiplane Image (MPI) representation. It differs from ray-based methods by reconstructing the frustum per plane, allowing efficient rendering of multiple target views via homography warping. Choose this method for efficient multi-view synthesis from a single source.

### [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md)
This family replaces the continuous MLP with discrete spatial structures (voxels, hash tables, triplanes) to store features. It enables memory-efficient training and real-time rendering by avoiding heavy feed-forward computation. Choose this method for scalability to large scenes and real-time performance.

### [Aleth-NeRF](13764-aleth-nerf.md)
Aleth-NeRF trains on under- and over-exposed images to render normal-light views using 'Concealing Fields'. It differs from RAW-NeRF by operating on standard 8-bit LDR images without paired training data. Choose this method for low-light or over-exposed input synthesis.

### [Transformer and Vision Model Integration](13911-transformer-and-vision-model-integration.md)
This family integrates Vision Transformers (ViT) into NeRF to leverage global semantic understanding. It solves the limitations of MLP-based NeRFs regarding global scene modeling and single-image inputs. Choose this method when generalization across scenes or global context is required.

### [Human and Specific Subject Modeling](13997-human-and-specific-subject-modeling.md)
These methods adapt NeRF for dynamic human subjects using parametric priors (e.g., SMPL) and canonical space transformations. They differ from static modeling by handling non-rigid deformation and occlusion. Choose this method for novel view synthesis of humans from monocular or sparse inputs.

### [OPONeRF](14014-oponerf.md)
OPONeRF personalizes plenoptic mapping parameters for each sampled 3D point to handle test-time scene changes. It differs from vanilla NeRF by dynamically conditioning network weights on point and scene representations. Choose this method for robustness against perturbations like motion or illumination changes.

### [Mixer-NeRF](14073-mixer-nerf.md)
Mixer-NeRF introduces a hybrid spatial feature learning module (MLCA) and SE network to address blurry details. It sets itself apart by mixing spatial and channel features before MLP inference. Choose this method to recover high-frequency details lost in standard NeRF.

### [Sparse View and Few-Shot Optimization](14428-sparse-view-and-few-shot-optimization.md)
This family addresses overfitting and geometry breakdown in sparse-view settings ($|S| < 20$). It mitigates ambiguity through in-situ regularization or deformable sampling. Choose this method when training data is severely limited.

### [Mixture-of-Experts and Modular Architectures](14429-mixture-of-experts-and-modular-architectures.md)
This family replaces the single continuous function with multiple specialized networks (experts). It solves the limitations of INRs struggling with complex features. Choose this method to improve compression, training speed, or representation capacity.

### [Uncertainty and Reliability](14487-uncertainty-and-reliability.md)
These methods extend NeRF to quantify prediction confidence, modeling the scene as a probabilistic entity. They differ from deterministic variants by providing pixel-level reliability metrics. Choose this method for robust filtering and conformal prediction in sparse data.

### [Object Decomposition and Composition](14518-object-decomposition-and-composition.md)
These methods explicitly separate a scene into distinct semantic or geometric object instances. They differ from monolithic radiance fields by introducing auxiliary outputs for instance-level editing. Choose this method for amodal segmentation and object manipulation.

### [Lighting and Appearance Models](14522-lighting-and-appearance-models.md)
These models explicitly represent illumination and material properties, enabling relighting. They differ from standard NeRF by separating albedo from illumination using global bases. Choose this method for handling varying lighting conditions and relighting.

### [Optimization and Training Procedures](14565-optimization-and-training-procedures.md)
This family covers algorithmic procedures for optimizing NeRF, including structural modifications to the optimization scope. It addresses efficient minimization of photometric loss under computational constraints. Choose this method for acceleration or specialized editing techniques.

### [Image Enhancement and Restoration Methods](14566-image-enhancement-and-restoration-methods.md)
These methods integrate restoration mechanisms (e.g., blur kernels, transient occlusion removal) into the NeRF loop. They differ from standard NeRF by assuming sharp, clean inputs. Choose this method for degraded input imagery.

### [Modular, Hierarchical, and Latent Architectures](14567-modular-hierarchical-and-latent-architectures.md)
This family extends NeRF to handle non-rigid deformation with topological changes (HyperNeRF) or hierarchical scenes (Strata-NeRF). Choose this method for dynamic scenes with topology changes or stratified environments.

### [MuRF (Multi-Baseline Radiance Fields)](15007-murf-multi-baseline-radiance-fields.md)
MuRF is a feed-forward method for sparse view synthesis under varying camera baselines. It differs from prior methods by constructing a target view frustum volume and using a 3D context-aware decoder. Choose this method for large baseline novel view synthesis.

### [Gaussian and Primitive-Based Representations](15011-gaussian-and-primitive-based-representations.md)
This family replaces the MLP with discrete geometric primitives or Gaussian distributions. It differs from voxel grids by using analytic primitives and from SDFs by using alpha-blended primitives. Choose this method for improved rendering efficiency and geometric fidelity.

### [Decentralized Federated NeRF](15032-decentralized-federated-nerf.md)
DecentNeRF learns global 3D representations from crowd-sourced images while preserving privacy. It differs from centralized approaches by distributing computation and using secure aggregation. Choose this method for privacy-preserving global scene reconstruction.

### [Neural Proxy](15220-neural-proxy.md)
Neural Proxy represents targets as animatable proxies, combining neural volume rendering with neural texture. It differs from NeRF by allowing particles to move with animated proxy geometry. Choose this method for synthesizing unseen animations.

### [ViSNeRF](15255-visnerf.md)
ViSNeRF efficiently synthesizes visualizations from dynamic volumetric scenes with adjustable parameters. It differs from standard NeRF by factorizing the static 3D volume and parameter space. Choose this method for high-dimensional $(3+K)$-D radiance fields.

### [EBAD-NeRF](15441-ebad-nerf.md)
EBAD-NeRF reconstructs sharp 3D fields from motion-blurred images using event-RGB data. It differs from prior works by modeling complex camera motion trajectories with multiple learnable poses. Choose this method for motion-blurred input reconstruction.

### [Point-NeRF Representation](15538-point-nerf-representation.md)
Point-NeRF replaces the MLP with a discrete neural point cloud. It differs from Gaussian primitives by using point-based aggregation and from voxels by maintaining explicit geometric anchors. Choose this method for faster optimization and higher-quality rendering than standard NeRF.

### [NeurMiPs](15543-neurmips.md)
NeurMiPs represents a scene as a mixture of learnable rectangular planar surfaces. It alleviates the frontal-parallel limitation of traditional MPI. Choose this method for high efficiency and superior extrapolation capabilities.

### [CodeNeRF](15544-codenerf.md)
CodeNeRF learns variation of object shapes and textures across a semantic category. It differs from standard NeRF by disentangling shape and texture via latent embeddings. Choose this method for one-shot reconstruction of unseen objects from a single unposed image.

### [Dynamic Scene and Temporal Modeling](15546-dynamic-scene-and-temporal-modeling.md)
This family extends static NeRF to reconstruct scenes changing over time. It explicitly models the 4D space-time volume. Choose this method for temporal consistency and motion representation.

### [NeRF-Casting](15547-nerf-casting.md)
NeRF-Casting integrates ray tracing into the NeRF pipeline to synthesize specular appearance. It differs from Ref-NeRF by casting reflection rays into the geometry rather than reparameterizing outgoing radiance. Choose this method for photorealistic specular reflections.

### [RoseNeRF](15548-rosenerf.md)
RoseNeRF simplifies complex ray interactions in transparent media to a single refraction event. It differs from deformation field methods by predicting the refracted ray directly. Choose this method for high-fidelity synthesis of real refractive objects.

### [NeRF-Det](15549-nerf-det.md)
NeRF-Det explicitly models scene geometry as an opacity field for indoor 3D object detection. It improves upon "NeRF-then-Det" by integrating multi-view geometry constraints. Choose this method for end-to-end 3D object detection.

### [Semantic and Feature Field Extensions](15556-semantic-and-feature-field-extensions.md)
These extensions predict arbitrary per-point feature signals $\mathbf{f}$ in addition to color and density. They lift 2D supervision into a consistent 3D representation. Choose this method for 3D-aware semantic understanding and zero-shot editing.

### [Neural Density-Distance Fields](15665-neural-density-distance-fields.md)
NeDDF reciprocally constrains distance and density fields, deriving density from depth values. It allows for boundaryless scenes and complex shapes. Choose this method for stable mesh extraction and camera pose localization.

### [LAENeRF](15738-laenerf.md)
LAENeRF is a unified framework for local appearance editing of pre-trained NeRFs. It differs from mask-based methods by learning a palette-based color decomposition. Choose this method for interactive recoloring or stylization of 3D regions.

### [ExtremeNeRF](15739-extremenerf.md)
ExtremeNeRF is a few-shot view synthesis framework for unconstrained, varying illumination. It enforces multi-view albedo consistency via intrinsic decomposition. Choose this method for robustness to varying lighting in sparse views.

### [Frequency-Modulated Point Cloud Rendering](15903-frequency-modulated-point-cloud-rendering.md)
This method replaces the MLP with a point cloud modulated by an Adaptive Frequency Net (AFNet). It solves high-frequency detail reconstruction issues. Choose this method for real-time rendering with high-fidelity textured regions.

### NeRF-VAE
- **Definition:** A generative NeRF model that generalizes to out-of-distribution scenes and removes the need to train on each scene from scratch [S1].
- **Steps:** The NeRF renderer is conditioned on a latent code trained using Iterative Amortized Inference and a ResNet encoder. An attention-based scene function is introduced instead of the typical MLP [S1].
- **Comparison:** Outperforms baseline NeRF with a low number of scene views (5-20), but is outperformed by baseline NeRF when a large number of views are available (100+) due to lower scene expressivity [S1].

### PIE-NeRF
- **Definition:** A pipeline integrating physics-based elastodynamic simulation with a neural radiance field representation, using a meshless discretisation based on quadratic generalized moving least squares on top of the density field of a NeRF [S1].
- **Steps:** Enables large deformations and nonlinear hyperelastic material simulation directly on the implicit representation and supports interactive manipulation of real-world captured scenes with complex geometries [S1].

### DäRF Implementation Details
- **Parameters:** NeRF Backbone: K-planes [36]. MDE Model: DPT-hybrid [38]. Optimizer: Adam [21]. NeRF Learning Rate: 1e-2. MDE Learning Rate: 1e-5. LR Schedule: Cosine warmup [S2, unofficial].

### NeRF Model Architecture
- **Definition:** The neural network architecture for NeRF, consisting of dense layers with ReLU activations, potentially using view directions as input [S3, unofficial].
- **Parameters:** `D`: The depth of the network (number of hidden layers). Default is 8. `input_ch_views`: The number of input channels for view directions. Default is 3. `output_ch`: The number of output channels. Default is 4 (RGB + density). `use_viewdirs`: Boolean flag to determine if view directions are used as input to the network [S3, unofficial].

### S3-NeRF
- **Definition:** A method using shadow and shading cues to infer scene geometry and enable single-image NeRF training [S1].
- **Steps:** Employ a UNISURF-based occupancy field 3D representation instead of density. Use a modified physics-based rendering equation. Use occupancy-based shadow calculation [S1].

### NeuralEditor
- **Definition:** A method employing a point cloud-guided NeRF model for shape manipulation, leveraging K-D trees and deterministic integration strategy for accurate point cloud-based rendering, with Phong reflection modeling to enhance color fidelity and geometric detail [S4].
- **Steps:** 1. Employ point cloud-guided NeRF model. 2. Leverage K-D trees. 3. Use deterministic integration strategy. 4. Achieve accurate point cloud-based rendering. 5. Apply Phong reflection modeling [S4].

### Network Architectures
- **Parameters:** MLPs A and F use the MLP designed in NeRF, with hidden layer sizes increased from 256 to 384. MLPs A and F are not used during inference, allowing more time on training. Small MLP H is the same as the small MLP used in SNeRG, with two hidden layers, each consisting 16 neurons [S5].

### NeRF-Swin
- **Definition:** A baseline method that performs super-resolution on an LR NeRF using released SwinIR models under the 'Real-World Image Super-Resolution' setting, trained on more than 10k LR-HR pairs [S6].
- **Parameters:** Training set size: More than 10k LR-HR pairs [S6].
- **Pitfalls:** On synthetic Blender dataset, SwinIR may produce false predictions due to domain mismatch. On real-world LLFF dataset, SwinIR tends to be oversmooth and may predict false color or geometry [S6].
- **Metrics:** Blender ×2 (100x100): PSNR 26.34, SSIM 0.913, LPIPS 0.075. Blender ×4 (100x100): PSNR 24.85, SSIM 0.881, LPIPS 0.108. Blender ×2 (200x200): PSNR 28.03, SSIM 0.926, LPIPS 0.058. Blender ×4 (200x200): PSNR 26.78, SSIM 0.906, LPIPS 0.086. LLFF ×2: PSNR 25.18, SSIM 0.793, LPIPS 0.147. LLFF ×4: PSNR 23.26, SSIM 0.685, LPIPS 0.247 [S6].

## Background
The standard NeRF architecture was introduced by Mildenhall et al. [1] in 2020, utilizing hierarchical rendering with coarse and fine networks to improve computational efficiency. Subsequent works have focused on improving geometry, training speed, and inference capabilities. SNeS (June 2022) improved geometry by learning probable symmetries [110]. S3-NeRF (October 2022) used shadow and shading cues for single-image training [111]. NeRF-VAE (January 2021) introduced a generative approach with latent codes [136]. PIE-NeRF (November 2023) integrated physics-based simulation [227]. NeRF-SR (2022) explored super-resolution using SwinIR [6]. These developments highlight the evolution from basic implicit representations to complex, multi-modal, and physically grounded architectures.
