# NeRF-GT Baseline Training Setup
Also called: NeRF-GT, HDR NeRF Baseline
## Overview
The NeRF-GT baseline establishes an upper-bound reference for neural radiance field quality by training directly on High Dynamic Range (HDR) ground truth views [S1]. It differs from standard NeRF implementations by utilizing HDR inputs and applying tone-mapping to both predictions and ground truth for loss computation, addressing the limitations of training on Low Dynamic Range (LDR) data [S1]. This setup serves as a performance ceiling against which methods like HDR-NeRF are evaluated [S1].
## How it works
### Inputs and Outputs
- **Inputs:** HDR views of the scene (rendered via path-tracing or captured with consistent exposure) [S1].
- **Outputs:** A trained NeRF model capable of synthesizing novel views [S1].

### Data Structures
The implementation follows the standard NeRF architecture [S2, unofficial]:
- **Coarse Network:** Samples 64 points along each ray [S2, unofficial].
- **Fine Network:** Samples 128 points along each ray [S2, unofficial].
- **Batch Processing:** Processes 2,048 rays per batch [S2, unofficial].
- **Resolution:** 800 × 600 pixels [S2, unofficial].

### Steps
1. **Training Input:** Train the NeRF model using HDR views as input [S1].
2. **Prediction:** The network predicts HDR pixel values for each sampled point along the ray [S1].
3. **Tone-Mapping:** Apply tone-mapping to the predicted HDR pixel values to convert them into LDR pixel values [S1].
4. **Ground Truth Preparation:** Apply the same tone-mapping parameters to the ground truth LDR views [S1].
5. **Loss Computation:** Compute the loss by comparing the tone-mapped predictions to the tone-mapped ground truth LDR views [S1].

### Parameters
- **Samples per Ray:** 64 (coarse), 128 (fine) [S2, unofficial].
- **Batch Size:** 2,048 rays [S2, unofficial].
- **Training Steps:** 200,000 solver steps [S2, unofficial].
- **Resolution:** 800 × 600 pixels [S2, unofficial].

### Pitfalls
Training directly on HDR views can fail to encode all scene areas well due to the high dynamic range, even when using tone-mapped colors for loss calculation [S1]. This makes it difficult to ensure uniform quality across all regions of the scene [S1].

## Subtopics

### NeRF Baseline
The standard NeRF baseline uses LDR views and standard MSE loss without the specific HDR tone-mapping pipeline described in the NeRF-GT setup [S2, unofficial]. It serves as a comparative lower-bound or standard reference point [S2, unofficial].

## Operating characteristics
- **Training Time:** 0.40 seconds per iteration [S2, unofficial].
- **Rendering Time:** 32 seconds per frame [S2, unofficial].
- **Scaling:** The method requires significant computational resources due to the large number of samples and iterations (200,000 steps) [S2, unofficial].
- **Strengths:** Provides a high-quality upper bound for novel view synthesis [S1].
- **Limitations:** Struggles with encoding high dynamic range scenes uniformly [S1].

## Background
The NeRF-GT baseline originates from the evaluation of HDR-NeRF, where it was used to demonstrate the limitations of directly training NeRF on HDR data [S1]. The training configuration (64/128 samples, 2048 rays, 200k steps) is adapted from the original NeRF paper's recommended settings for the DTU dataset [S2, unofficial].
