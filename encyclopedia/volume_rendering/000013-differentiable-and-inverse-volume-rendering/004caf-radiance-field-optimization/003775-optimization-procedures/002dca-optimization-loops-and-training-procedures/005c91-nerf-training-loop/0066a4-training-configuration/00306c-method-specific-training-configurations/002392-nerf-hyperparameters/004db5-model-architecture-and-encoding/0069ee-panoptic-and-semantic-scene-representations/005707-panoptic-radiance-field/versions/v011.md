# Panoptic Radiance Field

Also called: Panoptic Lifting

## Overview
Panoptic Lifting learns a panoptic 3D volumetric representation from posed RGB images and machine-generated 2D panoptic segmentation masks, lifting noisy 2D labels into a consistent 3D representation comprising color, density, semantics, and instances [S1]. It differs from sibling methods like [Panoptic NeRF](11916-panoptic-nerf.md) and [DM-NeRF](12073-dm-nerf.md) by requiring only machine-generated 2D labels rather than manual ground truth or coarse meshes, and by explicitly modeling instance consistency via surrogate identifiers and linear assignment [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Posed RGB images $\{I\}$ and corresponding machine-generated 2D panoptic segmentation masks. Each training ray $r$ has an associated RGB color $\hat{c}_r \in \mathbb{R}^3$, semantic class $\hat{k}_r \in K$, and 2D instance ID $\hat{h}_r \in H_I$ (defined only for thing classes $\hat{k}_r \in K_T$) [S1].
*   **Outputs:** A panoptic radiance field $\Phi(\mathbf{x}, \mathbf{d})$ that renders RGB color $c$, density $\sigma$, semantic class distribution $\kappa$, and instance distribution $\pi$ along rays [S1].

**Data Structures:**
The field $\Phi(\mathbf{x}, \mathbf{d})$ assigns to each 3D point $\mathbf{x} \in \mathbb{R}^3$ and viewing direction $\mathbf{d} \in S^2$:
1.  Density $\sigma \in \mathbb{R}_{\ge 0}$.
2.  Semantic class distribution $\kappa$ over classes $K$.
3.  Distribution $\pi$ over surrogate identifiers $J$.
4.  RGB color $c \in \mathbb{R}^3$ [S1].

The architecture leverages **TensoRF** [4] for color and density, and two separate small **MLPs** for the semantic field ($\kappa$) and the instance field ($\pi$) [S1].
*   $K$: Set of semantic classes, partitioned into thing classes $K_T$ and stuff classes $K_S$.
*   $J$: Fixed set of class-agnostic, 3D-consistent surrogate object identifiers held by the instance MLP.
*   $H_{3D}$: Set of all possible 3D instances, defined as $H_{3D} := K_T \times J$ [S1].

**Rendering Equation:**
Given density $\sigma$, any vector field $f$ is rendered along ray $r$ as [S1]:
$$ R[f | r, \sigma] := \int_0^\infty \alpha_t(r) \sigma(r_t) f(r_t, d_{r_t}) dt $$
where $\alpha_t(r) := \exp \left(-\int_0^t \sigma(r_s) ds\right)$ is the transmittance [S1].

**Training Procedure:**
1.  **Test-Time Augmentation (TTA) & Confidence Estimation:** Apply augmentations (horizontal flip, scale, brightness, contrast) to input images, fuse resulting segmentations via segment clustering, and compute a semantic class distribution $\hat{\kappa}_r$ and confidence $w_r$ for each pixel/ray [S1].
2.  **Linear Assignment for Instances:** Solve a linear assignment problem to map noisy 2D instance IDs $\hat{h}_r$ to 3D surrogate identifiers $j \in J$. The cost is based on the model's current predictions and the 2D masks, ensuring consistent lifting of 2D instances to 3D [S1]. Let $\Pi^*_R$ be the injective mapping from 2D instance $h$ to the most compatible 3D surrogate identifier [S1].
3.  **Loss Computation:** Compute the total loss $\mathcal{L}_{tot}$ over a batch of rays $R = R_S \cup R_I$ (where $R_S$ are rays sampled across the scene and $R_I$ are rays from a single image) [S1]:
    $$ \mathcal{L}_{tot}(R) := \lambda_{ins} \mathcal{L}_{ins}(R_I) + \lambda_{con} \mathcal{L}_{con}(R_I) + \lambda_{RGB} \mathcal{L}_{RGB}(R_S) + \lambda_{sem} \mathcal{L}_{sem}(R_S) $$
    *   **Semantic Loss ($\mathcal{L}_{sem}$):** Cross-entropy between rendered distribution $\kappa_r$ and augmented label $\hat{\kappa}_r$, weighted by confidence $w_r$ [S1]:
        $$ \mathcal{L}_{sem}(R) := -\frac{1}{|R|} \sum_{r \in R} w_r \sum_{k \in K} \hat{\kappa}_r(k) \log \kappa_r(k) $$
    *   **Instance Loss ($\mathcal{L}_{ins}$):** Minimizes the log-loss of the co-occurrence of the mapped 2D instance and the rendered surrogate ID distribution [S1].
    *   **Segment Consistency Loss ($\mathcal{L}_{con}$):** Guides semantic supervision to avoid fragmenting objects in the presence of label inconsistencies [S1].
    *   **Photometric Loss ($\mathcal{L}_{RGB}$):** Standard L2 loss on rendered color [S1].
4.  **Gradient Blocking:** Stop gradients from the semantic and instance branches back to the density field to prevent noisy labels from corrupting geometry [S1].
5.  **Optimization:** Update parameters using Adam [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class PanopticRadianceField:
    def __init__(self, num_surrogates, num_classes, tensorf_config):
        """
        Initialize the Panoptic Lifting model.
        
        Args:
            num_surrogates (int): Size of the fixed set J of surrogate identifiers.
            num_classes (int): Size of the semantic class set K.
            tensorf_config (dict): Configuration for the TensoRF density/color backbone.
        """
        super().__init__()
        # TensoRF backbone for density and color
        self.tensorf = TensoRFBackbone(tensorf_config)
        
        # Semantic MLP: outputs class distribution
        self.semantic_mlp = nn.Sequential(
            nn.Linear(tensorf_config.feature_dim, 128),
            nn.ReLU(),
            nn.Linear(128, num_classes)
        )
        
        # Instance MLP: outputs surrogate ID distribution
        self.instance_mlp = nn.Sequential(
            nn.Linear(tensorf_config.feature_dim, 128),
            nn.ReLU(),
            nn.Linear(128, num_surrogates)
        )
        
        # Loss weights
        self.lambda_ins = 1.0
        self.lambda_con = 1.35
        self.lambda_rgb = 1.0
        self.lambda_sem = 1.0

    def forward(self, x, d):
        """
        Query the field at point x and direction d.
        
        Args:
            x (Tensor): 3D points, shape (..., 3).
            d (Tensor): Viewing directions, shape (..., 3).
            
        Returns:
            sigma (Tensor): Density, shape (..., 1).
            c (Tensor): RGB color, shape (..., 3).
            kappa (Tensor): Semantic class distribution (probabilities), shape (..., K).
            pi (Tensor): Surrogate ID distribution (probabilities), shape (..., J).
        """
        # Get features from TensoRF backbone
        features = self.tensorf.get_features(x, d)
        
        # Predict density and color
        sigma, c = self.tensorf.predict_density_color(features)
        
        # Predict semantic distribution
        logits_sem = self.semantic_mlp(features)
        # Bounded probability distribution: use Softmax to ensure bounded outputs
        kappa = F.softmax(logits_sem, dim=-1)
        
        # Predict instance distribution
        logits_inst = self.instance_mlp(features)
        # Bounded probability distribution
        pi = F.softmax(logits_inst, dim=-1)
        
        return sigma, c, kappa, pi

    def compute_loss(self, rays, labels, confidences, assignment_map):
        """
        Compute the total training loss.
        
        Args:
            rays (dict): Dictionary containing ray origins and directions for sampling.
            labels (dict): Ground truth labels for rays.
                - 'rgb': RGB colors, shape (B, 3).
                - 'sem': Semantic class distribution from TTA, shape (B, K).
                - 'inst_2d': 2D instance IDs, shape (B,).
            confidences (Tensor): Confidence weights w_r, shape (B,).
            assignment_map (Tensor): Mapping from 2D instance IDs to 3D surrogate IDs, shape (B,).
            
        Returns:
            loss (Tensor): Scalar total loss.
        """
        # 1. Render fields along rays
        # Sample points along rays using density sigma
        # Note: Standard volume rendering integration is assumed here
        sigma_samples, c_samples, kappa_samples, pi_samples = self.render_rays(rays)
        
        # 2. Photometric Loss (RGB)
        # Rendered color c_r compared to ground truth rgb
        c_rendered = volume_render_color(sigma_samples, c_samples, rays)
        loss_rgb = F.mse_loss(c_rendered, labels['rgb'])
        
        # 3. Semantic Loss
        # Rendered semantic distribution kappa_r compared to TTA labels kappa_hat
        kappa_rendered = volume_render_distribution(sigma_samples, kappa_samples, rays)
        # Cross-entropy weighted by confidence
        # labels['sem'] is kappa_hat
        loss_sem = -torch.sum(labels['sem'] * torch.log(kappa_rendered + 1e-8), dim=-1)
        loss_sem = torch.mean(confidences * loss_sem)
        
        # 4. Instance Loss
        # Map 2D instance IDs to surrogate IDs using assignment_map
        target_surrogates = assignment_map[labels['inst_2d']]
        # Loss on rendered surrogate distribution pi_r
        # Minimizing log-loss (cross-entropy) for the assigned surrogate
        loss_inst = F.cross_entropy(pi_rendered, target_surrogates, reduction='none')
        loss_inst = torch.mean(confidences * loss_inst)
        
        # 5. Segment Consistency Loss
        # Implementation detail: Encourages spatial consistency of semantic predictions
        # This is a placeholder for the specific consistency term described in [S1]
        loss_con = compute_segment_consistency(kappa_rendered, rays)
        
        # 6. Total Loss
        loss = (self.lambda_ins * loss_inst + 
                self.lambda_con * loss_con + 
                self.lambda_rgb * loss_rgb + 
                self.lambda_sem * loss_sem)
        
        return loss

    def render_panoptic(self, ray):
        """
        Render panoptic segmentation for a novel view ray.
        
        Args:
            ray (dict): Ray origin and direction.
            
        Returns:
            semantic_class (int): Predicted semantic class.
            instance_id (tuple): (semantic_class, surrogate_id) for 3D instance.
        """
        # Render distributions
        sigma, c, kappa, pi = self.forward(ray.origin, ray.direction)
        
        # Aggregate along ray (simplified)
        kappa_r = aggregate_along_ray(sigma, kappa)
        pi_r = aggregate_along_ray(sigma, pi)
        
        # Get most probable semantic class
        k_star = torch.argmax(kappa_r, dim=-1)
        
        # If thing class, get most probable surrogate
        if k_star in thing_classes:
            j_star = torch.argmax(pi_r, dim=-1)
            instance_id = (k_star, j_star)
        else:
            instance_id = None
            
        return k_star, instance_id
```

**Edge Cases and Pitfalls:**
*   **Unbounded Logits:** Rendering class logits instead of probabilities can introduce semantic inconsistencies across viewpoints because unbounded logits can generate significant signals in low-density areas, violating geometric constraints. This is resolved by rendering bounded probability distributions (using Softmax) [S1].
*   **Geometry Corruption:** Supervision from noisy 2D labels can influence geometry, causing "cloudy" geometry to satisfy conflicting labels. This is avoided by stopping gradients from segmentation branches back to densities [S1].
*   **Label Noise:** Machine-generated labels are noisy and inconsistent across views. The method uses TTA and linear assignment to mitigate this [S1].

## Operating characteristics
*   **Time Complexity:** Training is lengthy, requiring ~450k iterations (~10 hours) on a single NVIDIA A6000 [S1].
*   **Memory Complexity:** Depends on the TensoRF grid size and MLP dimensions. Not given in the sources.
*   **Performance:** Improves scene-level Panoptic Quality (PQ) by 8.4% on Hypersim, 13.8% on Replica, and 10.6% on ScanNet over state-of-the-art methods [S1]. Maintains comparable PSNR for novel view synthesis [S1].
*   **Strengths:** Robust to inherent noise in machine-generated labels; enables in-the-wild scene processing without manual ground truth; supports scene editing (deletion, duplication, manipulation) [S1].
*   **Limitations:** Limited to classes supported by the pre-trained 2D segmentation model (e.g., Mask2Former); runs offline due to pre-processing (pose estimation, 2D segmentation, optimization) [S1].

## Background
Panoptic Lifting was introduced in "Panoptic Lifting for 3D Scene Understanding with Neural Fields" (CVPR 2023) [S1]. It addresses the limitations of prior panoptic NeRF methods (like Panoptic NeRF and DM-NeRF) which required manual ground truth or coarse meshes, by lifting machine-generated 2D panoptic labels into a 3D neural field [S1]. It builds on the TensoRF architecture for efficient radiance field representation [S1].
