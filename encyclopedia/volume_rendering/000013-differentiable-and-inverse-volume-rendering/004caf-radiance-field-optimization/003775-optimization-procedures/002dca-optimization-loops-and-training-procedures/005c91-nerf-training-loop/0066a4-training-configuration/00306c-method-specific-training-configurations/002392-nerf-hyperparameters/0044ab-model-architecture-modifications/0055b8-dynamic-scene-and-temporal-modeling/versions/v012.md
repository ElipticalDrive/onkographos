# Dynamic Scene and Temporal Modeling

Also called: Dynamic NeRF, 4D Radiance Fields

## Overview
Dynamic Scene and Temporal Modeling extends static neural radiance fields to represent and render scenes that change over time, solving the problem of novel view synthesis for non-rigid or moving subjects . Unlike static NeRF variants that assume a fixed geometry, these methods introduce a temporal dimension to the radiance field $f(\mathbf{x}, t)$, allowing density and color to vary with time [14705-nerf-with-time-parameter.md]. They differ from sibling methods like [Gear-NeRF](13848-gear-nerf.md) and [Forward Warping for Novel View Synthesis](15541-forward-warping-for-novel-view-synthesis.md) by their specific approach to handling temporal coherence: Gear-NeRF uses semantic stratification, Forward Warping uses canonical space deformation, and this family broadly encompasses time-conditioned MLPs, particle-based dynamics, and Kalman-filtered deformation fields.

## Shared principles
The core mechanism involves expanding the input domain of the radiance field from 5D $(\mathbf{x}, \mathbf{d})$ to 6D $(\mathbf{x}, \mathbf{d}, t)$, where $\mathbf{x} \in \mathbb{R}^3$ is spatial position, $\mathbf{d} \in \mathbb{R}^3$ is viewing direction, and $t \in \mathbb{R}$ is time [14705-nerf-with-time-parameter.md]. The rendered color $C(r, t)$ for a ray $r$ at time $t$ is computed via the volume rendering integral:

$$
C(r, t) = \int_{s_n}^{s_f} T(s, t)\sigma(\mathbf{r}(s), t)c(\mathbf{r}(s), \mathbf{d}, t)ds
$$

where the accumulated transmittance $T(s, t)$ is:

$$
T(s, t) = \exp\left(-\int_{s_n}^{s} \sigma(\mathbf{r}(s'), t)ds'\right)
$$

[15550-dynamic-appearance-particle-neural-radiance-field.md].

Methods generally fall into three architectural strategies:
1.  **Direct Time Conditioning:** The network explicitly takes $t$ as an input, often via positional encoding $\gamma_t(t)$, concatenated with spatial encoding $\gamma_x(\mathbf{x})$ [14705-nerf-with-time-parameter.md].
2.  **Canonical Space Warping:** A static "canonical" field is learned, and a deformation field $\mathbf{d}(\mathbf{x}, t)$ maps dynamic points to this canonical space [15541-forward-warping-for-novel-view-synthesis.md].
3.  **Hybrid/Particle Representations:** The scene is decomposed into static and dynamic components, where the dynamic part is modeled using particles or specific temporal feature structures [15550-dynamic-appearance-particle-neural-radiance-field.md].

## Subtopics

### [Gear-NeRF](13848-gear-nerf.md)
Gear-NeRF stratifies the scene into motion-based "gears" using semantic segmentation. It employs parallel 4D feature volumes for each gear level, allowing higher-motion regions to be sampled at higher resolutions. Choose this when semantic priors are available and motion scales vary significantly across the scene.

### [NeRF with Time Parameter](14705-nerf-with-time-parameter.md)
This method treats time as an explicit input dimension to the standard NeRF MLP, creating a 4D radiance field $f(\mathbf{x}, t)$. It serves as a baseline that lacks sophisticated dynamic reasoning and may suffer from blurriness. Choose this for simple, low-motion dynamic scenes or as a baseline comparison.

### [Forward Warping for Novel View Synthesis](15541-forward-warping-for-novel-view-synthesis.md)
This method models a static canonical radiance field and forward-warps it to target time steps using a learned deformation flow. It addresses many-to-one mapping ambiguities using average splatting and inpainting. Choose this for scenes with complex occlusions and non-rigid motion where backward flow is unstable.

### [Dynamic Appearance Particle Neural Radiance Field](15550-dynamic-appearance-particle-neural-radiance-field.md)
DAP-NeRF models scene dynamics using a particle-based representation superimposed on a static grid field. It solves the problem of reconstructing dynamic scenes from monocular video without prior geometric knowledge. Choose this when only monocular input is available and multi-view stereo data is not accessible.

### [KFD-NeRF](15551-kfd-nerf.md)
KFD-NeRF models the 4D radiance field as a dynamic system estimated using a Kalman filter. It integrates control-theoretic motion priors with a tri-plane spatial representation. Choose this for scenes with smooth, predictable motion where temporal consistency is critical and direct interpolation is insufficient.

## Background
The concept of dynamic neural radiance fields emerged as an extension of the original NeRF [3065-nerf-hyperparameters.md] to handle temporal variations. Early approaches treated time as an additional input channel to the MLP [14705-nerf-with-time-parameter.md]. Subsequent research introduced canonical space representations to decouple geometry from appearance changes [15541-forward-warping-for-novel-view-synthesis.md], and more recent methods have incorporated semantic information [13848-gear-nerf.md] and control theory [15551-kfd-nerf.md] to improve stability and efficiency. These methods are primarily used in free-viewpoint video synthesis, augmented reality, and dynamic scene reconstruction.
