# Panoptic Radiance Field

Also called: Panoptic Lifting

## Overview
Panoptic Lifting learns a panoptic 3D volumetric representation from posed RGB images and machine-generated 2D panoptic segmentation masks, lifting noisy 2D labels into a consistent 3D representation of color, density, semantics, and instances [S1]. It differs from sibling methods like [Panoptic NeRF](11916-panoptic-nerf.md) and [DM-NeRF](11916-panoptic-nerf.md) by requiring only machine-generated 2D labels rather than manual ground truth or coarse meshes, using linear assignment to resolve instance inconsistencies across views [S1].

## How it works
**Inputs:**
*   Posed RGB images $\{I\}$ of a scene.
*   Machine-generated 2D panoptic segmentation masks for each image, providing semantic class $\hat{k}_r \in K$ and 2D instance ID $\hat{h}_r \in H_I$ for each ray $r$.
*   Rays $r$ parameterized as $r = p_0 + t d_r$, where $p_0$ is the ray origin, $d_r$ is the unit direction, and $t$ is a scalar.

**Outputs:**
*   Novel view RGB images.
*   Novel view depth images.
*   Novel view 3D-consistent panoptic segmentation masks (semantic class and 3D instance ID).

**Data Structures:**
The panoptic radiance field $\Phi(x, d)$ assigns to each 3D point $x \in \mathbb{R}^3$ and viewing direction $d \in S^2$:
1.  **Density:** $\sigma \in \mathbb{R}_{\ge 0}$.
2.  **Semantic Distribution:** $\kappa$ over the set of semantic classes $K$.
3.  **Instance Distribution:** $\pi$ over a fixed set of surrogate identifiers $J$.
4.  **Color:** $c \in \mathbb{R}^3$.

The architecture leverages **TensoRF** [S1] for color and density. Two separate small Multi-Layer Perceptrons (MLPs) are used for the semantic field ($\kappa$) and the instance field ($\pi$).

**Parameters:**
*   $K$: Set of semantic classes, partitioned into thing classes $K_T$ and stuff classes $K_S$.
*   $J$: Set of surrogate identifiers. A fixed number held by the instance field MLP.
*   $H_{3D}$: Set of all possible 3D instances, defined as $H_{3D} := K_T \times J$.
*   Loss weights: $\lambda_{con} = 1.35$, $\lambda_{ins} = 1$, $\lambda_{sem} = 1$, $\lambda_{RGB} = 1$.
*   Optimizer: Adam. Learning rates: $5 \times 10^{-4}$ for MLPs, $1 \times 10^{-2}$ for TensoRF lines and planes [S1].

**Steps:**

1.  **Preprocessing (Test-Time Augmentation):**
    Apply test-time augmentations (e.g., horizontal flip, scale, brightness, contrast) to input images. Fuse the resulting segmentations using segment clustering to obtain a refined semantic class distribution $\hat{\kappa}_r$ and a confidence estimate $w_r$ for each pixel (ray $r$) [S1].

2.  **Instance Mapping (Linear Assignment):**
    For each training image, solve a linear assignment problem to map noisy 2D instance IDs $\hat{h}_r$ to the 3D surrogate identifiers $J$. The cost is based on the model's current predictions and the machine-generated masks. This creates an injective mapping $\Pi^*_R$ that assigns each ray $r$ a compatible 3D surrogate identifier [S1].

3.  **Training Loop:**
    Sample a batch of rays $R = R_S \cup R_I$, where $R_S$ are rays randomly sampled across the scene and $R_I$ are rays sampled from a single image. Compute the total loss:
    $$ L_{tot}(R) := \lambda_{ins} L_{ins}(R_I) + \lambda_{con} L_{con}(R_I) + \lambda_{RGB} L_{RGB}(R_S) + \lambda_{sem} L_{sem}(R_S) $$
    
    *   **Semantic Loss ($L_{sem}$):** Supervise the semantic field directly with 2D labels. Render the semantic distribution $\kappa_r$ along ray $r$. Compute the cross-entropy between $\kappa_r$ and the augmented label distribution $\hat{\kappa}_r$, weighted by confidence $w_r$:
        $$ L_{sem}(R) := -\frac{1}{|R|} \sum_{r \in R} w_r \sum_{k \in K} \hat{\kappa}_r(k) \log \kappa_r(k) $$
        [S1]
        
    *   **Instance Loss ($L_{ins}$):** Supervise the instance field using the mapped 2D instances. Let $R_h$ be the subset of rays belonging to 2D instance $h$. Minimize the log-loss of the co-occurrence of the rendered instance distribution $\pi_r$ and the mapped surrogate identifier [S1].
        
    *   **Segment Consistency Loss ($L_{con}$):** An additional loss to avoid optima that fragment objects in the presence of label inconsistencies [S1].
        
    *   **Photometric Loss ($L_{RGB}$):** Standard L2 loss between rendered color $c_r$ and ground truth RGB $\hat{c}_r$ [S1].

4.  **Gradient Blocking:**
    Stop gradients from the semantic and instance branches back to the density network (geometry). This prevents noisy labels from influencing geometry, which would otherwise cause "cloudy" geometry to satisfy conflicting labels [S1].

5.  **Bounded Segmentation Fields:**
    Render bounded probability distributions for semantics and instances, rather than unbounded logits. This prevents significant signals in low-density areas that violate geometric constraints [S1].

**Rendering Novel Views:**
For a ray $r$ from a novel view:
1.  Compute rendered semantic distribution $\kappa_r$ and instance distribution $\pi_r$ using the rendering equation.
2.  Determine semantic class: $k^*_r := \arg \max_{k \in K} \kappa_r(k)$.
3.  If $k^*_r \in K_T$ (thing class), determine surrogate ID: $j^*_r := \arg \max_{j \in J} \pi_r(j)$.
4.  Form 3D instance ID: $(k^*_r, j^*_r) \in H_{3D}$ [S1].

**Scene Editing:**
*   **Deletion:** Set density $\sigma$ to zero for points where the predicted instance equals the target instance.
*   **Duplication:** Manipulate rays passing through a new position/rotation region to query the original instance region.
*   **Manipulation:** Combine deletion and duplication [S1].

## Operating characteristics
*   **Time Complexity:** Training is lengthy, requiring ~450k iterations (~10 hours) on a single NVIDIA A6000 GPU [S1].
*   **Memory Complexity:** Uses TensoRF for compact density/color storage, plus two small MLPs for semantics and instances.
*   **Performance:** Improves scene-level Panoptic Quality (PQ) by 8.4% on Hypersim, 13.8% on Replica, and 10.6% on ScanNet over state-of-the-art methods [S1]. Maintains comparable PSNR for novel view synthesis [S1].
*   **Strengths:** Robust to noise in machine-generated labels; does not require manual ground truth or 3D meshes; enables scene editing (deletion, duplication, manipulation) [S1].
*   **Limitations:** Limited to classes supported by the pre-trained 2D segmentation model (e.g., Mask2Former); runs offline due to pose estimation and segmentation inference preprocessing; performance depends on the quality of the 2D segmenter [S1].

## Background
Panoptic Lifting was introduced in 2023 by the authors of "Panoptic Lifting for 3D Scene Understanding with Neural Fields" [S1]. It addresses the limitations of previous panoptic NeRF methods (like Panoptic NeRF and DM-NeRF) which required manual ground truth or coarse meshes. It builds on the TensoRF architecture for efficient radiance field representation [S1].
