# Model Architecture Modifications

Also called: NeRF Architecture Variants, Implicit Representation Modifications

## Overview
Model Architecture Modifications refer to structural changes applied to the standard Neural Radiance Field (NeRF) pipeline—typically consisting of positional encoding, coarse/fine Multi-Layer Perceptrons (MLPs), and volume rendering—to address specific limitations such as geometric accuracy, computational efficiency, dynamic scene modeling, or input constraints [S1, S6]. Unlike standard NeRF, which maps 3D coordinates and view directions to density and color via a continuous implicit function, these modifications introduce auxiliary heads, substitute the MLP with discrete structures (voxels, SDFs, points), or augment the input/output domains with semantic, temporal, or physical priors [14428-sparse-view-and-few-shot-optimization.md, 14429-mixture-of-experts-and-modular-architectures.md]. They are chosen when the baseline architecture fails to capture high-frequency details, requires explicit geometry, needs to handle dynamic content, or must operate under sparse-view or adverse lighting conditions [S1].

## Shared principles
The standard NeRF architecture [Parent](3065-nerf-hyperparameters.md) serves as the baseline for all modifications. It consists of two MLPs: a coarse network and a fine network [14428-sparse-view-and-few-shot-optimization.md].
1.  **Coarse Network:** Takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$.
2.  **Fine Network:** Takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$.

The positional encoding $\gamma(\mathbf{x}, d_1, d_2)$ is defined as:
$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$
[14428-sparse-view-and-few-shot-optimization.md].

Modifications generally fall into three categories [14428-sparse-view-and-few-shot-optimization.md]:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation [14428-sparse-view-and-few-shot-optimization.md].
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
    [14428-sparse-view-and-few-shot-optimization.md].
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs) [14428-sparse-view-and-few-shot-optimization.md].

## Subtopics

### [DoF-NeRF](9432-dof-nerf.md)
DoF-NeRF extends the standard NeRF to simulate depth-of-field effects by modeling the Circle of Confusion (CoC). It introduces learnable aperture $K$ and focus distance $F$ parameters per view, optimizing them jointly with the network to render all-in-focus views from shallow DoF inputs.

### [NeRF-VPT](11770-nerf-vpt.md)
NeRF-VPT uses a cascading view prompt tuning paradigm. It iteratively refines rendering by concatenating the RGB output of the previous stage as a visual prompt to the next stage's input, enhancing image quality in sparse-view settings without external networks.

### [Activation Feature Density Approximation](12492-activation-feature-density-approximation.md)
This method estimates volumetric density $\hat{d}$ directly from intermediate activation features $\mathbf{f}_\ell$ of the coarse MLP, replacing expensive fine network evaluations with lightweight statistical computations (mean, std, ReLU) to accelerate training.

### [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md)
SDF representations replace the density field $\sigma(\mathbf{x})$ with a continuous scalar field $s(\mathbf{x})$ representing distance to the nearest surface. This provides explicit geometry via the zero-level set and enables sharp surface normals via $\mathbf{n} = \nabla s(\mathbf{x}) / \|\nabla s(\mathbf{x})\|$.

### [Volume-Augmented NeRF](12973-volume-augmented-nerf.md)
Designed for dynamic fluid scenes, this variant binds an explicit fluid volume value $v_i$ to each sample point. The density MLP takes $\gamma(\mathbf{x}_i)$ and $v_i$ as input, allowing the renderer to learn density based on differentiable fluid simulator outputs.

### [Neural-PIL Decomposition Architecture](12975-neural-pil-decomposition-architecture.md)
This architecture separates geometry, material, and illumination. It predicts density, a BRDF embedding, and an illumination embedding, using a learned pre-integrated lighting network to render shaded colors, handling varying lighting conditions better than standard NeRF.

### [SAID-NeRF](13619-said-nerf.md)
SAID-NeRF uses instance masks from Visual Foundation Models (e.g., SAM) to enhance transparent object reconstruction. It decomposes appearance into diffuse and specular components and uses semantic segmentation to enforce higher surface densities, improving depth estimates for robotic grasping.

### [MINE](13661-mine.md)
MINE models the source camera's frustum using a continuous depth Multiplane Image (MPI) representation. It uses a fully-convolutional decoder to reconstruct the frustum, allowing novel view synthesis via homography warping after a single encoder pass, making it efficient for multiple target views.

### [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md)
This family replaces the continuous MLP with discrete structures (dense voxels, sparse grids, hash tables, or triplanes). Values are retrieved via interpolation or hashing, enabling memory-efficient training and real-time rendering by avoiding heavy feed-forward computation for every sample.

### [Aleth-NeRF](13764-aleth-nerf.md)
Aleth-NeRF trains on under- and over-exposed images to render normal-light views. It introduces a 'Concealing Field' assumption where air particles attenuate emission, using local and global concealing fields to suppress light transport without requiring HDR RAW inputs.

### [Transformer and Vision Model Integration](13911-transformer-and-vision-model-integration.md)
This family integrates Vision Transformers (ViT) to extract global semantic features. These features are fused with local CNN features and conditioned into the NeRF MLP, enabling generalization across scenes and handling occlusions via attention mechanisms.

### [Human and Specific Subject Modeling](13997-human-and-specific-subject-modeling.md)
These methods adapt NeRF for dynamic humans by introducing a canonical space transformation and parametric priors (e.g., SMPL). The deformation field combines rigid LBS with non-rigid residuals, and appearance is pose-conditioned to handle articulation.

### [OPONeRF](14014-oponerf.md)
OPONeRF personalizes plenoptic mapping parameters for each 3D point. It dynamically conditions network weights $\Theta$ on the point's representation $\mathbf{x}$ and scene representation $\mathbf{F}$, allowing robust handling of test-time scene changes and perturbations.

### [Mixer-NeRF](14073-mixer-nerf.md)
Mixer-NeRF addresses blurry details by introducing a Hybrid Spatial Feature Learning Module (MLCA) and a Squeeze-and-Excitation (SE) module. It mixes spatial and channel features via fully connected layers before the main MLP inference to capture high-frequency details.

### [Sparse View and Few-Shot Optimization](14428-sparse-view-and-few-shot-optimization.md)
This family addresses overfitting in sparse-view settings ($|S| < 20$). Modifications include input expansion (appearance embeddings), output expansion (auxiliary heads), and representation substitution to mitigate geometry breakdown and floaters.

### [Mixture-of-Experts and Modular Architectures](14429-mixture-of-experts-and-modular-architectures.md)
These architectures replace the single continuous function with multiple specialized networks (experts) or parallel streams. They partition the input domain or ray batch among distinct modules to improve compression, speed, or capacity, addressing boundary discontinuities in grid-based INRs(13765-mixture-of-experts-implicit-neural-representation.md).

### [Uncertainty and Reliability](14487-uncertainty-and-reliability.md)
These methods extend NeRF to quantify prediction confidence. They output auxiliary uncertainty metrics alongside density and color, modeled as probabilistic distributions (e.g., Gaussian) to enable robust filtering and conformal prediction.

### [Object Decomposition and Composition](14518-object-decomposition-and-composition.md)
These methods explicitly separate a scene into distinct semantic or geometric object instances. They introduce auxiliary outputs (object codes, separate heads) to decompose the volume, enabling instance-level editing and amodal segmentation.

### [Lighting and Appearance Models](14522-lighting-and-appearance-models.md)
These models decouple geometry, albedo, and illumination. They use explicit mathematical bases or neural modules for light, enabling semantic lighting control and relighting, distinguishing themselves from appearance embeddings or 2D style transfer.

### [Optimization and Training Procedures](14565-optimization-and-training-procedures.md)
This family covers algorithmic procedures for optimizing NeRF, including structural modifications to the optimization scope such as skipping expensive fine-pass evaluations for empty rays or restricting updates to specific layers.

### [Image Enhancement and Restoration Methods](14566-image-enhancement-and-restoration-methods.md)
These methods integrate restoration mechanisms (e.g., blur kernels, inpainting) into the NeRF loop to handle degraded inputs. They separate static geometry from transient artifacts or model degradation processes to render clean views.

### [Modular, Hierarchical, and Latent Architectures](14567-modular-hierarchical-and-latent-architectures.md)
This family handles non-rigid deformation (e.g., HyperNeRF lifting space to higher dimensions) and hierarchical scenes (e.g., Strata-NeRF using discrete latent codes) to prevent cloudy artifacts and topological discontinuities.

### [MuRF (Multi-Baseline Radiance Fields)](15007-murf-multi-baseline-radiance-fields.md)
MuRF is a feed-forward method for sparse view synthesis under varying baselines. It constructs a target view frustum volume and uses a 3D context-aware convolutional decoder to aggregate multi-view information, handling small overlap scenarios.

### [Gaussian and Primitive-Based Representations](15011-gaussian-and-primitive-based-representations.md)
This family replaces the MLP with discrete geometric primitives or explicit Gaussian distributions. It uses analytic primitives (quadrics/Gaussians) and alpha-blending for efficiency and geometric fidelity, differing from voxel grids and SDFs.

### [Decentralized Federated NeRF](15032-decentralized-federated-nerf.md)
DecentNeRF learns global 3D representations from crowd-sourced images by distributing training to users. It decomposes the scene into global and personal radiance fields per user and uses Secure Multi-Party Computation (SMPC) for aggregation.

### [Neural Proxy](15220-neural-proxy.md)
Neural Proxy represents targets as animatable proxies by injecting an animatable mesh proxy into the scene. It combines neural volume rendering with neural texture, allowing particles to move with the animated proxy geometry.

### [ViSNeRF](15255-visnerf.md)
ViSNeRF synthesizes visualizations from dynamic volumetric scenes with adjustable parameters. It combines explicit feature grids with implicit MLP decoders and applies generalized tensor factorization to reduce memory complexity from $O(N^3 M^K)$ to $O(N^2 M)$.

### [EBAD-NeRF](15441-ebad-nerf.md)
EBAD-NeRF reconstructs sharp NeRFs from motion-blurred images using hybrid event-RGB data. It jointly optimizes learnable camera poses and NeRF parameters, supervising motion blur via an intensity-change-metric event loss.

### [Point-NeRF Representation](15538-point-nerf-representation.md)
Point-NeRF replaces the MLP with a discrete neural point cloud. It uses neighborhood queries and inverse distance weighting of processed feature vectors to model the radiance field, avoiding ray sampling in empty space.

### [NeurMiPs](15543-neurmips.md)
NeurMiPs represents a scene as a mixture of $K$ learnable rectangular planar surfaces. Each surface acts as an expert predicting color and transparency via a local neural radiance field, alleviating the frontal-parallel limitation of traditional MPI.

### [CodeNeRF](15544-codenerf.md)
CodeNeRF learns variation of object shapes and textures across a semantic category. It disentangles shape and texture via separate latent embeddings, enabling one-shot reconstruction and explicit editing from a single unposed image.

### [Dynamic Scene and Temporal Modeling](15546-dynamic-scene-and-temporal-modeling.md)
These methods extend NeRF to 4D space-time by adding a temporal coordinate $t$ to the input domain. They model non-rigid deformation and temporal consistency, often using total variation loss on time-varying features.

### [NeRF-Casting](15547-nerf-casting.md)
NeRF-Casting synthesizes specular appearance by integrating ray tracing. It casts reflection rays from sample points into the NeRF geometry to render feature vectors, which are decoded into color, avoiding the need for a large MLP to encode the environment.

### [RoseNeRF](15548-rosenerf.md)
RoseNeRF synthesizes refractive objects by predicting a single refracted ray using a 4D light field representation and a refraction network. It avoids Index of Refraction (IoR) fields and point-by-point deformation.

### [NeRF-Det](15549-nerf-det.md)
NeRF-Det performs indoor 3D object detection by jointly training a NeRF branch with a 3D detection pipeline. It uses a shared geometry MLP to integrate multi-view geometry constraints, enabling end-to-end training.

### [Semantic and Feature Field Extensions](15556-semantic-and-feature-field-extensions.md)
These extensions predict arbitrary per-point feature signals $\mathbf{f}$ in addition to color and density. This lifts 2D supervision into a consistent 3D representation for semantic understanding and zero-shot editing.

### [Neural Density-Distance Fields](15665-neural-density-distance-fields.md)
NeDDF reciprocally constrains distance and density fields. It predicts a distance field $D$ and computes density $\sigma$ via its gradient, enabling boundaryless scenes and stable mesh extraction.

### NeRF-VAE
- [S1] A generative NeRF model that generalizes to out-of-distribution scenes and removes the need to train on each scene from scratch.
- [S1] The NeRF renderer is conditioned on a latent code. This latent code is trained using Iterative Amorphized Inference and a ResNet encoder.
- [S1] An attention-based scene function is introduced instead of the typical MLP.
- [S1] Outperforms baseline NeRF with a low number of scene views (5-20), but is outperformed by baseline NeRF when a large number of views are available (100+) due to lower scene expressivity.

### PIE-NeRF
- [S1] A pipeline integrating physics-based elastodynamic simulation with a neural radiance field representation, using a meshless discretisation based on quadratic generalized moving least squares on top of the density field of a NeRF.
- [S1] Enables large deformations and nonlinear hyperelastic material simulation directly on the implicit representation and supports interactive manipulation of real-world captured scenes with complex geometries.

## Background
The standard NeRF architecture was introduced by Mildenhall et al. in 2020 [S1][S3, unofficial]. It established the paradigm of using MLPs to map 3D coordinates and view directions to density and color. Subsequent research has focused on modifying this architecture to improve geometry (SDFs, Point-NeRF), efficiency (Voxels, MINE), dynamics (Dynamic NeRF, Volume-Augmented NeRF), and robustness (Sparse View, Uncertainty) [S1]. The family continues to evolve with the integration of foundation models (SAID-NeRF) and specialized hardware constraints (MobileNeRF) [S1, S5].
