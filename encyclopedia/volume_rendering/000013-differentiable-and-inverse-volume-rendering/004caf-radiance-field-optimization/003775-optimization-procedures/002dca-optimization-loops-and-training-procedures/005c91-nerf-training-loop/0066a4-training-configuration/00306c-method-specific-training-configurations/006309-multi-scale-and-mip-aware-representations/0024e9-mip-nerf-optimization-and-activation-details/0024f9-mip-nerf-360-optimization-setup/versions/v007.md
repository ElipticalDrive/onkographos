# Mip-NeRF 360 Optimization Setup

Also called: Gaussian Position Encoding, Mip-NeRF 360 Training Procedure, Position Warping for Unbounded Scenes

## Overview
Mip-NeRF 360 optimization setup defines the training configuration for unbounded neural radiance fields, specifically addressing the challenges of large-scale, "in-the-wild" scenes with limited video memory. It combines a scene contraction function to warp unbounded space into a finite sphere with a multi-stage proposal network training loop. This method sets itself apart from standard NeRF implementations by explicitly handling unbounded depth distributions and using a stop-gradient-based proposal supervision to stabilize training without requiring additional scaling hyperparameters for the proposal loss.

## How it works
The method consists of two main components: a coordinate warping scheme for unbounded scenes and a specific training loop involving proposal networks.

### Inputs and Outputs
- **Inputs**: Camera poses $\mathbf{P}$, intrinsics, and a set of input images $\mathbf{I}^*$ with corresponding pixel colors $\mathbf{C}^*$.
- **Outputs**: A trained NeRF MLP $\Theta_{\text{NeRF}}$ and a trained Proposal MLP $\Theta_{\text{prop}}$ that can render novel views.

### Data Structures
1.  **Proposal MLP ($\Theta_{\text{prop}}$)**:
    -   Architecture: 4 layers, 256 hidden units.
    -   Activations: ReLU for hidden layers, softplus for density output $\tau$.
2.  **NeRF MLP ($\Theta_{\text{NeRF}}$)**:
    -   Architecture: 8 layers, 1024 hidden units.
    -   Activations: ReLU for hidden layers, softplus for density output $\tau$.
3.  **Scene Warping Function**:
    -   Maps 3D coordinates $\mathbf{x}$ to a unit sphere.

### Step-by-Step Procedure

1.  **Scene Warping (Position Encoding)**:
    To handle unbounded scenes, input 3D coordinates $\mathbf{x}$ are warped into a finite sphere using the following contract function [S1, S2]:
    $$
    \mathbf{x}_{\text{encoding}} = \begin{cases} 
    \mathbf{x} & \text{if } \|\mathbf{x}\|_2 \leq 1 \\
    \left(2 - \frac{1}{\|\mathbf{x}\|_2}\right) \frac{\mathbf{x}}{\|\mathbf{x}\|_2} & \text{if } \|\mathbf{x}\|_2 > 1
    \end{cases}
    $$
    Points within the unit sphere ($\|\mathbf{x}\|_2 \leq 1$) remain unchanged. Points outside are contracted towards the sphere boundary [S2].

2.  **Proposal Network Evaluation and Resampling**:
    The proposal network is evaluated in two stages to generate sample distributions [S1]:
    -   **Stage 0**: Evaluate $\Theta_{\text{prop}}$ with 64 samples along the ray to produce interval midpoints $\hat{s}_0$ and weights $\hat{w}_0$.
    -   **Stage 1**: Resample based on $\hat{w}_0$, evaluate $\Theta_{\text{prop}}$ again with 64 samples to produce $\hat{s}_1$ and $\hat{w}_1$.
    These distributions $(\hat{s}_0, \hat{w}_0)$ and $(\hat{s}_1, \hat{w}_1)$ are used to supervise the proposal network.

3.  **NeRF Network Evaluation**:
    -   **Stage 2**: Resample based on the final proposal distribution (typically $\hat{w}_1$), evaluate $\Theta_{\text{NeRF}}$ with 32 samples to produce final interval midpoints $s$ and weights $w$ [S1].
    -   Render the final color $\mathbf{C}(\mathbf{t})$ using the standard volume rendering integral with $(s, w)$.

4.  **Loss Computation**:
    The total loss is the sum of reconstruction loss, a distribution regularizer, and proposal supervision losses [S1]:
    $$
    \mathcal{L} = \mathcal{L}_{\text{recon}}(\mathbf{C}(\mathbf{t}), \mathbf{C}^*) + \lambda \mathcal{L}_{\text{dist}}(\mathbf{s}, \mathbf{w}) + \sum_{k=0}^1 \mathcal{L}_{\text{prop}}(\mathbf{s}, \mathbf{w}, \hat{\mathbf{s}}^k, \hat{\mathbf{w}}^k)
    $$
    -   $\mathcal{L}_{\text{recon}}$: Charbonnier loss $\sqrt{(x - x^*)^2 + \epsilon^2}$ with $\epsilon = 0.001$ [S1].
    -   $\mathcal{L}_{\text{dist}}$: Regularizer balancing data and regularization terms.
    -   $\mathcal{L}_{\text{prop}}$: Interlevel loss supervising the proposal network.
    -   $\lambda$: Hyperparameter balancing $\mathcal{L}_{\text{recon}}$ and $\mathcal{L}_{\text{dist}}$, set to $0.01$ [S1].
    -   The stop-gradient operator is applied to $\mathcal{L}_{\text{prop}}$ with respect to $\Theta_{\text{NeRF}}$, making the optimization of $\Theta_{\text{prop}}$ independent of $\Theta_{\text{NeRF}}$ [S1].

5.  **Optimization**:
    -   Optimizer: Adam with $\beta_1 = 0.9$, $\beta_2 = 0.999$, $\epsilon = 10^{-6}$ [S1].
    -   Learning Rate: Annealed log-linearly from $2 \times 10^{-3}$ to $2 \times 10^{-5}$ over 250k iterations, with a warm-up phase of 512 iterations [S1].
    -   Gradient Clipping: Norm clipped to $10^{-3}$ [S1].
    -   Batch Size: $2^{14}$ rays [S1].

```python
import numpy as np

def warp_position(x):
    """
    Warps 3D coordinates into a unit sphere.
    x: numpy array of shape (..., 3)
    """
    norm = np.linalg.norm(x, axis=-1, keepdims=True)
    # Points inside unit sphere are unchanged
    # Points outside are contracted
    # Note: The formula uses 2 - 1/||x||. 
    # If ||x|| <= 1, return x.
    # If ||x|| > 1, return (2 - 1/||x||) * (x / ||x||)
    
    mask = norm <= 1.0
    x_outside = x[~mask]
    norm_outside = norm[~mask]
    
    x_warped = np.zeros_like(x)
    x_warped[mask] = x[mask]
    
    # For outside points: (2 - 1/norm) * (x / norm)
    scale = 2.0 - 1.0 / norm_outside.squeeze()
    x_warped[~mask] = x_outside * (scale / norm_outside.squeeze())[:, np.newaxis]
    
    return x_warped

def softplus(x):
    return np.log1p(np.exp(-np.abs(x))) + np.maximum(x, 0)

def evaluate_mlp(mlp_params, x_encoded, t):

    Returns densities and colors (if NeRF).
    This is a placeholder for the actual MLP forward pass.

def volume_render(s, w, colors):
    """
    Standard volume rendering.
    s: interval midpoints
    w: interval weights
    colors: RGB colors at intervals
    """
    # C = sum(w * c)
    return np.sum(w * colors, axis=-1)

def train_mipnerf360(images, poses, num_iterations=250000):
    # Initialize Proposal MLP: 4 layers, 256 hidden, ReLU, softplus density
    theta_prop = init_mlp(layers=4, hidden=256, activation='relu', density_activation='softplus')
    
    # Initialize NeRF MLP: 8 layers, 1024 hidden, ReLU, softplus density
    theta_nerf = init_mlp(layers=8, hidden=1024, activation='relu', density_activation='softplus')
    
    # Optimizer setup
    optimizer = Adam(lr=2e-3, beta1=0.9, beta2=0.999, eps=1e-6)
    
    # Learning rate schedule parameters
    lr_start = 2e-3
    lr_end = 2e-5
    warmup_iters = 512
    total_iters = num_iterations
    
    for i in range(total_iters):
        # 1. Sample rays and get poses
        rays, gt_colors = sample_batch(poses, images)
        
        # 2. Compute learning rate
        if i < warmup_iters:
            lr = lr_start * (i / warmup_iters)
        else:
            # Log-linear annealing
            # log_lr = log_start + (log_end - log_start) * ((i - warmup_iters) / (total_iters - warmup_iters))
            log_lr_start = np.log(lr_start)
            log_lr_end = np.log(lr_end)
            progress = (i - warmup_iters) / (total_iters - warmup_iters)
            lr = np.exp(log_lr_start + (log_lr_end - log_lr_start) * progress)
        
        optimizer.set_lr(lr)
        
        # 3. Warp positions
        # x is the 3D position along the ray
        x_warped = warp_position(rays.x)
        
        # 4. Proposal Network Evaluation (Stage 0)
        # Sample 64 points
        s0, w0 = sample_and_evaluate_proposal(theta_prop, x_warped, rays.t, num_samples=64)
        
        # 5. Proposal Network Evaluation (Stage 1)
        # Resample based on w0, evaluate again
        s1, w1 = sample_and_evaluate_proposal(theta_prop, x_warped, rays.t, num_samples=64, weights=w0)
        
        # 6. NeRF Network Evaluation
        # Resample based on w1 (final proposal), evaluate NeRF
        s, w, colors = sample_and_evaluate_nerf(theta_nerf, x_warped, rays.t, num_samples=32, weights=w1)
        
        # 7. Render Color
        c_rendered = volume_render(s, w, colors)
        
        # 8. Compute Losses
        # Reconstruction Loss (Charbonnier)
        epsilon = 0.001
        l_recon = np.sqrt((c_rendered - gt_colors)**2 + epsilon**2)
        
        # Distribution Regularizer
        l_dist = compute_distribution_regularizer(s, w)
        
        # Proposal Loss (with stop-gradient on NeRF outputs)
        # L_prop compares (s, w) from NeRF with (s_hat, w_hat) from Proposal
        # Note: In the paper, L_prop uses the NeRF's (s, w) and Proposal's (s_hat, w_hat)
        # The stop-gradient is applied to the NeRF part of the loss calculation for proposal update
        l_prop_0 = compute_interlevel_loss(s, w, s0, w0)
        l_prop_1 = compute_interlevel_loss(s, w, s1, w1)
        
        # Total Loss
        lambda_dist = 0.01
        loss = np.mean(l_recon) + lambda_dist * np.mean(l_dist) + np.mean(l_prop_0) + np.mean(l_prop_1)
        
        # 9. Backpropagation
        # Gradient clipping
        grads = compute_gradients(loss, theta_nerf, theta_prop)
        grads = clip_gradients(grads, max_norm=1e-3)
        
        optimizer.step(theta_nerf, grads['nerf'])
        optimizer.step(theta_prop, grads['prop'])
```

### Parameters
-   **Proposal MLP**: 4 layers, 256 hidden units, ReLU, softplus density [S1].
-   **NeRF MLP**: 8 layers, 1024 hidden units, ReLU, softplus density [S1].
-   **Samples per Stage**: Proposal stages use 64 samples; NeRF stage uses 32 samples [S1].
-   **Lambda ($\lambda$)**: 0.01 [S1].
-   **Charbonnier Epsilon ($\epsilon$)**: 0.001 [S1].
-   **Adam Hyperparameters**: $\beta_1 = 0.9$, $\beta_2 = 0.999$, $\epsilon = 10^{-6}$ [S1].
-   **Learning Rate**: $2 \times 10^{-3}$ to $2 \times 10^{-5}$, warm-up 512 iterations [S1].
-   **Gradient Clip Norm**: $10^{-3}$ [S1].
-   **Total Iterations**: 250k [S1].

### Edge Cases and Pitfalls
-   **Z-aliasing**: The standard interlevel loss can cause the proposal network to learn non-smooth mappings, leading to "skipped" scene content, especially with high-capacity backends like iNGP [S3]. This is mitigated by using smooth proposal supervision (see Subtopics).
-   **Unbounded Depth**: Without warping, large scenes require excessive memory. The contraction function ensures all points are mapped to a unit sphere, but care must be taken with points exactly on the boundary $\|\mathbf{x}\|_2 = 1$ [S2].
-   **Proposal Independence**: The stop-gradient on $\mathcal{L}_{\text{prop}}$ is critical. Without it, the NeRF gradients would interfere with the proposal network's ability to learn accurate sampling distributions [S1].

## Subtopics

### [Anti-Aliased Interlevel Loss](3457-anti-aliased-interlevel-loss.md)
The Anti-Aliased Interlevel Loss is a proposal supervision loss function that measures the distance between a NeRF histogram and a proposal histogram by blurring the NeRF histogram into a piecewise-linear spline and resampling it into the proposal's interval endpoints. Unlike the piecewise constant loss used in mip-NeRF 360, which suffers from aliasing when NeRF histogram bins are narrow or translate relative to the proposal, this method produces a smooth loss surface that prevents aliasing artifacts during training.

### [Isotropic Gaussian Scale Contraction](5407-isotropic-gaussian-scale-contraction.md)
Isotropic Gaussian Scale Contraction is a technique for efficiently adapting the scale of isotropic Gaussians when a scene contraction function $C(\mathbf{x})$ is applied. It solves the problem of maintaining correct anti-aliasing properties in contracted coordinate spaces without the computational overhead of general multivariate Gaussian transformations. It sets itself apart from the standard mip-NeRF 360 approach by linearizing the contraction around each Gaussian center to derive an isotropic scale from the Jacobian determinant, rather than contracting a full covariance matrix.

### [Google Immersive View NeRF](13526-google-immersive-view-nerf.md)
A method for 3D reconstruction and novel view synthesis that distills a dense collection of indoor photos into a neural field to render photorealistic views from viewpoints not present in the original collection, specifically optimized for the scale, lighting variability, and privacy constraints of Google Maps Immersive View. It distinguishes itself from standard NeRF implementations by integrating low-dimensional generative latent optimization (GLO) vectors and metadata-derived exposure conditioning into the radiance network, thereby resolving cloudy geometry artifacts caused by lighting changes without sacrificing interpretability. Unlike [Anti-Aliased Interlevel Loss](3457-anti-aliased-interlevel-loss.md) which focuses on sampling strategies, this method focuses on appearance modeling and capture constraints; it builds on [Mip-NeRF 360 Optimization Setup](3426-mip-nerf-360-optimization-setup.md) as its architectural base.

### [Progressively Optimized Local Radiance Fields](15521-progressively-optimized-local-radiance-fields.md)
A method for robust view synthesis of long video sequences by dynamically allocating new local radiance fields as the camera trajectory extends, preventing global failure from pose outliers and maintaining high resolution around the camera path.

### Smooth Proposal Supervision
A method to resolve 'z-aliasing' artifacts in proposal networks by replacing the discrete interlevel loss with a continuous, smooth loss function that penalizes partial overlaps between proposal and NeRF histograms [S3]. The original Mip-NeRF 360 interlevel loss assigns equivalent loss to NeRF and proposal histogram bins regardless of overlap extent, penalizing only complete failures to overlap, leading to non-smooth density maps [S3]. The new loss prevents the proposal network from learning non-smooth mappings that occur with the previous loss, particularly when the proposal network has high capacity (e.g., iNGP backend) [S3].

### MipNeRF-360 Depth Rendering
An unbounded extension of MipNeRF that uses a contract function to parameterize 3D Euclidean space within a ball of radius 2, allowing direct rendering of images and depth maps in the contracted space [S4]. Images and depth maps are rendered in the contracted space using standard NeRF equations [S4].

### Simple Multi-Space Radiance Field (Ablation Variant)
A simplified module that outputs K scalars and K RGB-G vectors (4 dimensions: 3 RGB + 1 gating scaler) without efficient multi-space composition strategy, leading to over-smoothing [S5]. Rendering uses the same integral equation as NeRF to accumulate the K RGB-G vectors and get the RGB-G maps of each sub-space. The RGB-G maps are split into RGB maps and sub-space composition maps (gating maps). Softmax is applied over the gating maps along the sub-space channels and used as the weight to compose sub-space RGB maps to form the final rendering results [S5]. K is set to 8 [S5]. The lack of an efficient multi-space composition strategy introduces an over-smoothing problem [S5].

### Mip-NeRF360 Evaluation Configuration
Uses the scene warping scheme identical to DVGO and Mip-NeRF360 [S6]. Keeps other components (positional encoding, point sampling, etc.) identical to TensoRF [S6]. Uses 2 scales [S6]. Mip-NeRF360 results on the dataset: garden PSNR 24.13, room PSNR 28.11, Model Size avg 12.6MB [S6].

### MipNeRF-360 Distillation Mode
Implementing the MipNeRF-360 distillation mode replaces the default settings with a light proposal MLP, reducing training and inference time [S7, unofficial]. The distillation mode runs 30% faster in training and 40% faster in inference than default settings, with a PSNR drop of 0.33 [S7, unofficial].

## Operating characteristics
-   **Time Complexity**: The multi-stage proposal network adds overhead compared to single-stage NeRF, but the efficient sampling reduces the number of NeRF evaluations. The distillation mode variant reduces training time by 30% and inference time by 40% [S7, unofficial].
-   **Memory Complexity**: The scene warping allows handling of unbounded scenes within limited video memory by contracting the space into a unit sphere [S2]. Model size for standard Mip-NeRF 360 scenes is approximately 12.6MB [S6].
-   **Performance**: On the Mip-NeRF 360 dataset, the method achieves PSNR of 24.13 on the garden scene and 28.11 on the room scene [S6].
-   **Strengths**: Robust to large-scale, unbounded scenes; stable training with proposal networks; anti-aliased rendering.
-   **Limitations**: Requires careful tuning of the contraction function; proposal network training can be sensitive to the interlevel loss formulation (z-aliasing) [S3].

## Background
Mip-NeRF 360 was introduced by Mildenhall et al. in 2022 [S1]. It extends the original mip-NeRF by handling unbounded scenes and "in-the-wild" photo collections. The optimization setup described here is based on the implementation details provided in the original paper [S1]. The scene warping technique has been adopted by other methods such as Gaussian Position Encoding [S2] and Strivec [S6].
