# KFD-NeRF

Also called: Kalman Filter Guided Deformation Field NeRF, Kalman Filter Guided Dynamic NeRF

## Overview
KFD-NeRF is a dynamic neural radiance field method that models the 4D radiance field as a dynamic system with temporally varying states, estimated using a Kalman filter to combine observations from input data and predictions based on local linear motion equations [S1]. It differs from sibling methods like [Gear-NeRF](13848-gear-nerf.md) or [NeRF with Time Parameter](14705-nerf-with-time-parameter.md) by explicitly separating motion estimation into an observer branch (shallow MLP) and a predictor branch (linear motion model), fusing them via a learnable Kalman gain, and utilizing a tri-plane spatial representation for the canonical space [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D point coordinates $\mathbf{x}$, timestamps $t_i$, and camera parameters.
*   **Outputs:** Deformation field $\Delta \mathbf{x}$ (warping points to canonical space), volume density $\sigma$, and color $\mathbf{c}$.

**Data Structures:**
1.  **Tri-Plane Representation:** Three mutually orthogonal 2D planes encode the canonical space. Features are concatenated with raw coordinate inputs to handle coordinate shift errors [S1].
2.  **Observer MLP:** A two-layer shallow MLP takes $\mathbf{x}$ and $t_i$ as input [S1].
3.  **Kalman Gain Network:** A linear layer $f$ takes noise terms $\varepsilon_{t_i}, \varepsilon_{t_{i-1}}$ and timestamps $t_i, t_{i-1}$ to output the Kalman gain $K_{t_i}$ [S1].

**Numbered Steps:**

1.  **Observer Query (Current Frame):** Query the observer MLP with $\mathbf{x}$ and $t_i$ to obtain the mean observation $y_{t_i}$ and noise-related terms $\varepsilon_{t_i}$ [S1].
    $$ y_{t_i}, \varepsilon_{t_i} = \text{Observer}(\mathbf{x}, t_i) $$
2.  **Velocity Calculation:** Approximate the velocity $v_{t_i}$ using the deformation from the previous two frames ($t_{i-1}$ and $t_{i-2}$) [S1].
    $$ v_{t_i} = (d\mathbf{x}_{t_{i-1}} - d\mathbf{x}_{t_{i-2}}) / \Delta t_i $$
    where $d\mathbf{x}_{t}$ is the deformation at time $t$, and $\Delta t_i$ is the time interval [S1].
3.  **Prediction:** Calculate the predicted deformation $\hat{d\mathbf{x}}_{t_i}^{-}$ using the locally linear motion model. The prediction uses the previous frame's deformation and the calculated velocity [S1].
    $$ \hat{d\mathbf{x}}_{t_i}^{-} = d\mathbf{x}_{t_{i-1}} + \Delta t_i \cdot v_{t_i} $$
    *Note: The source text contains a typo in the formula derivation description but clarifies the logic: prediction is based on previous state plus velocity step.*
4.  **Kalman Gain Calculation:** Compute the Kalman gain $K_{t_i}$ using the linear layer $f$ [S1].
    $$ K_{t_i} = f(\varepsilon_{t_i}, \varepsilon_{t_{i-1}}, t_i, t_{i-1}) $$
5.  **Deformation Estimation (Update):** Combine the observation $y_{t_i}$ and the prediction $\hat{d\mathbf{x}}_{t_i}^{-}$ using the Kalman gain to produce the final deformation estimation $\hat{d\mathbf{x}}_{t_i}$ [S1].
    $$ \hat{d\mathbf{x}}_{t_i} = \hat{d\mathbf{x}}_{t_i}^{-} + K_{t_i} (y_{t_i} - \hat{d\mathbf{x}}_{t_i}^{-}) $$
6.  **Warping:** Warp all points in real space to a time-independent canonical space according to the estimated deformation $\hat{d\mathbf{x}}_{t_i}$ [S1].
7.  **Rendering:** Render the radiance field from the canonical space using the tri-plane representation and standard volume rendering [S1].

**Pseudocode:**

```python
def kfd_nerf_deformation(x, t_i, t_prev, t_prev_prev, observer_mlp, kalman_gain_net, prev_deformations):
    """
    Computes the deformation for point x at time t_i using Kalman Filter guidance.
    
    Args:
        x: 3D point coordinates (vector)
        t_i: Current timestamp (float)
        t_prev: Previous timestamp (float)
        t_prev_prev: Timestamp before previous (float)
        observer_mlp: Two-layer MLP for observation
        kalman_gain_net: Linear layer for Kalman gain
        prev_deformations: Dictionary mapping timestamp to deformation d_x
        
    Returns:
        d_x: Estimated deformation vector
    """
    # Step 1: Observer Query for current frame
    y_t, epsilon_t = observer_mlp(x, t_i)
    
    # Step 2: Retrieve previous deformations and compute velocity
    d_x_prev = prev_deformations[t_prev]
    d_x_prev_prev = prev_deformations[t_prev_prev]
    
    delta_t = t_i - t_prev_prev # Time interval between t_prev_prev and t_i? 
                                # Source says (dx_{t-1} - dx_{t-2}) / delta_t. 
                                # Assuming delta_t is the interval between the two previous frames 
                                # or the interval used for velocity estimation.
                                # Standard finite difference: v = (dx(t-1) - dx(t-2)) / (t_{t-1} - t_{t-2})
                                # Let's assume dt_vel is the interval between t_prev and t_prev_prev
    dt_vel = t_prev - t_prev_prev
    v_t = (d_x_prev - d_x_prev_prev) / dt_vel
    
    # Step 3: Prediction
    # Prediction uses the most recent known deformation (t_prev) and velocity
    # dx_pred = dx_{t-1} + dt * v
    # The source formula: dx_hat^- = dx_{t-1} + delta_t_i * v_{t_i}
    # Here delta_t_i likely refers to the step from t_{i-1} to t_i
    dt_step = t_i - t_prev
    d_x_pred = d_x_prev + dt_step * v_t
    
    # Step 4: Kalman Gain
    epsilon_prev = observer_mlp(x, t_prev)[1] # Retrieve epsilon from previous step if not stored, 
                                              # or assume it's passed. 
                                              # In practice, epsilon_t_prev is needed.
    # Note: The source implies epsilon_{t-1} is available. 
    # If not explicitly stored, it must be retrieved from the previous observer call.
    # For this self-contained pseudocode, we assume epsilon_prev is passed or retrieved.
    # However, the function signature above doesn't include it. 
    # Let's adjust to assume we have access to epsilon_prev from the previous frame's observer call.
    
    K_t = kalman_gain_net(epsilon_t, epsilon_prev, t_i, t_prev)
    
    # Step 5: Update
    d_x = d_x_pred + K_t * (y_t - d_x_pred)
    
    return d_x
```

**Formulas:**
*   **Velocity:** $v_{t_i} = (d\mathbf{x}_{t_{i-1}} - d\mathbf{x}_{t_{i-2}}) / \Delta t_i$ [S1].
*   **Kalman Loss:** $\mathcal{L}_{kf} = \frac{1}{\mathcal{N}} \sum_{\mathbf{x} \in \mathcal{N}} \| y_{t_i} - \hat{d\mathbf{x}}_{t_i} \|_2^2$ [S1].
*   **Canonical Observation Loss:** $\mathcal{L}_{co} = \frac{1}{\mathcal{N}} \sum_{\mathbf{x} \in \mathcal{N}} \mathbb{1}(t) d\mathbf{x}$, where $\mathbb{1}(t) = 1$ if $t=0$ and $0$ otherwise [S1].
*   **Total Variation Loss:** $\mathcal{L}_{tv}(\mathbf{x}) = \frac{1}{|C|} \sum_{c, i, j} (\| \mathbf{x}_c^{i,j} - \mathbf{x}_c^{i-1,j} \|_2^2 + \| \mathbf{x}_c^{i,j} - \mathbf{x}_c^{i,j-1} \|_2^2)$, where $c$ is a plane from collection $C$ [S1].
*   **Total Loss:** $\mathcal{L} = \mathcal{L}_{image} + \mathcal{L}_{kf} + \mathcal{L}_{co} + \mathcal{L}_{prop} + \lambda_{tv} \mathcal{L}_{tv}$ [S1].

**Parameters:**
*   **Total Variation Weight ($\lambda_{tv}$):** $1 \times 10^{-4}$ [S1].
*   **Observer MLP Depth:** 2 layers [S1].
*   **Spatial Representation:** Tri-plane [S1].

**Edge Cases and Pitfalls:**
*   **Initial Training:** During initial stages, predictions primarily influence the process to facilitate convergence for frames with substantial motion [S1].
*   **Late Training:** In later stages, observations take precedence to recover precise and fine-grained motion details [S1].
*   **Coordinate Shift:** Errors due to coordinate shifts when $\mathbf{x}'$ are encoded by finite resolution tri-planes are mitigated by concatenating encoded tri-plane features with raw coordinate inputs [S1].
*   **Canonical Space Regularization:** A hard mask for $t=0$ (as in D-NeRF) is avoided; instead, a soft regularization term $\mathcal{L}_{co}$ is used to normalize the difference between the canonical space and the real world at $t=0$ [S1].

## Operating characteristics
*   **Performance (Synthetic):** PSNR 35.73 dB, SSIM 0.984, LPIPS 0.045, Average 0.0131 [S1].
*   **Performance (Real):** PSNR 28.75 dB, SSIM 0.891, LPIPS 0.115, Average 0.0389 [S1].
*   **Training Time:** 30 minutes (KFD-NeRF-S) to 3 hours (KFD-NeRF-L) [S1].
*   **Parameters:** 175 MB [S1].
*   **Strengths:** Faster convergence and higher quality than MLP-based backbones (e.g., D-NeRF) due to tri-plane representation; accurate deformation estimation via Kalman filter; smooth deformation fields easier to fit with MLPs than high-frequency feature interpolation [S1].
*   **Limitations:** Relies on local linear motion assumption, which may struggle with highly non-linear or abrupt motions not captured by the velocity approximation [S1].

## Background
KFD-NeRF was introduced by Li, Niu, Zhong, Nobuhara, Nishino, and Zheng in 2024 [S1]. It draws inspiration from control theory, modeling the 4D radiance field as a dynamic system. It improves upon previous dynamic NeRF methods like D-NeRF [36] and TiNeuVox [10] by integrating a Kalman filter guided deformation field [S1].
