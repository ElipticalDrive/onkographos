# Panoptic Radiance Field

Also called: Panoptic Lifting

## Overview
Panoptic Lifting learns a panoptic 3D volumetric representation from posed RGB images and machine-generated 2D panoptic segmentation masks, lifting noisy 2D labels into a consistent 3D representation of color, density, semantics, and instances [S1]. It differs from sibling methods like [Panoptic NeRF](11916-panoptic-nerf.md) and [DM-NeRF](11916-dm-nerf.md) by requiring no manual ground truth (such as coarse meshes or per-image panoptic segmentations), relying instead on pre-trained 2D segmentation networks to handle inherent label noise and view inconsistencies [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** Posed RGB images $\{I\}$ of a scene. For each training image, machine-generated 2D panoptic segmentation masks are provided. These masks yield, for each pixel (ray $r$), an RGB color $\hat{\mathbf{c}}_r \in \mathbb{R}^3$, a semantic class $\hat{k}_r \in \mathcal{K}$, and a 2D instance ID $\hat{h}_r \in \mathcal{H}_I$ (defined only for thing classes $\hat{k}_r \in \mathcal{K}_T$) [S1].
*   **Outputs:** A panoptic radiance field $\Phi(\mathbf{x}, \mathbf{d})$ that, for any 3D point $\mathbf{x} \in \mathbb{R}^3$ and viewing direction $\mathbf{d} \in S^2$, outputs:
    *   Density $\sigma \in \mathbb{R}_{\ge 0}$
    *   Semantic class distribution $\boldsymbol{\kappa}$ over $\mathcal{K}$
    *   Distribution $\boldsymbol{\pi}$ over surrogate identifiers $\mathcal{J}$
    *   RGB color $\mathbf{c} \in \mathbb{R}^3$
*   **Rendering:** From $\Phi$, novel views of color, depth, and 3D-consistent panoptic segmentations are generated [S1].

**Data Structures**
The representation $\Phi$ comprises four components:
1.  **Color and Density:** Leveraged from TensoRF [S1]. This involves learnable 3D grid structures (lines and planes) [S1].
2.  **Semantic Field:** A small Multi-Layer Perceptron (MLP) $\Phi_{sem}$ [S1].
3.  **Instance Field:** A separate small MLP $\Phi_{ins}$ [S1].
4.  **Surrogate Identifiers:** A fixed set $\mathcal{J}$ of class-agnostic, 3D-consistent surrogate object identifiers held by the instance field [S1].

The set of all possible 3D instances is $\mathcal{H}_{3D} := \mathcal{K}_T \times \mathcal{J}$ [S1].

**Numbered Steps**

1.  **Preprocessing (Test-Time Augmentation):**
    For each training image, apply test-time augmentations (e.g., horizontal flip, scale, brightness, contrast) to the input images. Run the pre-trained 2D panoptic segmentation model on these augmented images. Fuse the resulting segmentations using segment clustering to obtain a robust semantic class distribution $\hat{\boldsymbol{\kappa}}_r$ and a prediction confidence $w_r$ for each pixel (ray $r$) [S1].

2.  **Linear Assignment for Instance Mapping:**
    To handle inconsistent 2D instance identifiers across views, solve a linear assignment problem for each training image. The cost function is based on the model’s current 3D instance predictions and the machine-generated 2D segmentation masks. This yields an injective mapping $\Pi^*_R$ that assigns each 2D instance $h \in \mathcal{H}_I$ to a 3D surrogate identifier $j \in \mathcal{J}$ [S1].

3.  **Training Loop Optimization:**
    Optimize the parameters of $\Phi$ using the total loss $\mathcal{L}_{tot}$. For a batch of rays $\mathcal{R} = \mathcal{R}_S \cup \mathcal{R}_I$, where $\mathcal{R}_S$ are rays randomly sampled across the scene and $\mathcal{R}_I$ are rays sampled from a single image:
    $$ \mathcal{L}_{tot}(\mathcal{R}) := \lambda_{ins} \mathcal{L}_{ins}(\mathcal{R}_I) + \lambda_{con} \mathcal{L}_{con}(\mathcal{R}_I) + \lambda_{RGB} \mathcal{L}_{RGB}(\mathcal{R}_S) + \lambda_{sem} \mathcal{L}_{sem}(\mathcal{R}_S) $$
    *   **Semantic Loss ($\mathcal{L}_{sem}$):** Supervise the semantic field directly with the machine-generated 2D labels. Compute the rendered semantic distribution $\boldsymbol{\kappa}_r$ along ray $r$. The loss is the weighted cross-entropy between $\boldsymbol{\kappa}_r$ and $\hat{\boldsymbol{\kappa}}_r$:
        $$ \mathcal{L}_{sem}(\mathcal{R}) := -\frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} w_r \sum_{k \in \mathcal{K}} \hat{\boldsymbol{\kappa}}_r(k) \log \boldsymbol{\kappa}_r(k) $$
        [S1]
    *   **Segment Consistency Loss ($\mathcal{L}_{con}$):** An additional loss guiding semantic supervision to avoid optima that fragment objects in the presence of label inconsistencies [S1].
    *   **Instance Loss ($\mathcal{L}_{ins}$):** Supervise the instance field using the mapped 2D instances. For a batch of rays $\mathcal{R}$, let $\mathcal{R}_h$ be the subset of rays belonging to 2D instance $h$, and $\mathcal{H}_R$ the subset of 2D instances in the batch. Each ray $r$ is assigned a surrogate identifier via $\Pi^*_R$. The loss minimizes the log-loss of the co-occurrence of the rendered instance distribution and the mapped 2D instance [S1].
    *   **Photometric Loss ($\mathcal{L}_{RGB}$):** Standard L2 loss between rendered color $\mathbf{c}_r$ and ground truth $\hat{\mathbf{c}}_r$ [S1].

4.  **Rendering Novel Views:**
    For a pixel from a novel view corresponding to ray $r$:
    *   Compute the rendered semantic class distribution $\boldsymbol{\kappa}_r$ using the volumetric rendering equation.
    *   Obtain the semantic class $k^*_r := \arg \max_{k \in \mathcal{K}} \boldsymbol{\kappa}_r(k)$.
    *   If $k^*_r$ is a thing class, compute the most probable surrogate identifier $j^*_r := \arg \max_{j \in \mathcal{J}} \boldsymbol{\pi}_r(j)$.
    *   Form the unique 3D instance identifier as the pair $(k^*_r, j^*_r) \in \mathcal{H}_{3D}$ [S1].

**Volumetric Rendering Equation**
To render any vector field $\mathbf{f}$ along ray $r$ given density field $\sigma$:
$$ R[\mathbf{f} | r, \sigma] := \int_0^\infty \alpha_t(r) \sigma(r_t) \mathbf{f}(r_t, \mathbf{d}_r) dt $$
where $\alpha_t(r) := \exp \left(-\int_0^t \sigma(r_s) ds\right)$ is the transmittance probability at $t$ [S1].

**Parameters**
*   $\mathcal{K}$: Set of semantic classes, partitioned into thing classes $\mathcal{K}_T$ and stuff classes $\mathcal{K}_S$ [S1].
*   $\mathcal{J}$: Fixed number of surrogate identifiers held by the instance field MLP [S1].
*   Loss weights: $\lambda_{con} = 1.35$, $\lambda_{ins} = 1$, $\lambda_{sem} = 1$, $\lambda_{RGB} = 1$ [S1].
*   Optimizer: Adam [S1].
*   Learning rates: $5 \times 10^{-4}$ for MLPs, $1 \times 10^{-2}$ for TensoRF lines and planes [S1].
*   Training hardware: 1 NVIDIA A6000. Duration: 450k iterations (~10 hours) [S1].
*   Pre-trained model: Mask2Former with Swin-L backbone is used for 2D label predictions [S1].

**Pitfalls and Edge Cases**
*   **Logits vs. Probabilities:** Rendering class logits instead of probabilities can introduce semantic inconsistencies across viewpoints because unbounded logits can generate significant signals in low-density areas, violating geometric constraints. This is resolved by rendering bounded probability distributions [S1].
*   **Geometry Degradation:** Supervision from noisy 2D labels can influence geometry, causing "cloudy" geometry to satisfy conflicting labels. This is avoided by stopping gradients from the semantic and instance branches back to the density field [S1].
*   **Class Limitations:** The method is limited to classes supported by the pre-trained 2D segmentation model [S1].
*   **Offline Nature:** The method runs offline due to lengthy pre-processing for pose estimation, 2D segmentation inference, and neural field optimization [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Training requires significant time (e.g., ~10 hours on a single A6000 for 450k iterations) due to the optimization of the neural field and the pre-processing steps [S1]. Memory usage is driven by the TensoRF representation and the MLPs [S1].
*   **Measured Performance:** On Hypersim, Replica, and ScanNet datasets, Panoptic Lifting improves scene-level Panoptic Quality ($PQ_{scene}$) by 8.4%, 13.8%, and 10.6% respectively over state-of-the-art methods, while maintaining comparable PSNR for novel view synthesis [S1].
*   **Strengths:** Robust to inherent noise in machine-generated labels; enables in-the-wild scene processing without manual ground truth; supports scene editing (deletion, duplication, manipulation) [S1].
*   **Limitations:** Limited to classes in the pre-trained 2D model; offline processing; requires posed images [S1].
*   **When to use:** When 3D panoptic segmentation is required for in-the-wild scenes and manual 3D annotations are unavailable.
*   **When not to use:** When real-time processing is required or when the scene contains classes outside the pre-trained 2D model's vocabulary [S1].

## Background
Panoptic Lifting was introduced in the paper "Panoptic Lifting for 3D Scene Understanding with Neural Fields" [S1]. It addresses the challenge of learning panoptic 3D representations from in-the-wild scenes where only machine-generated 2D labels are available, which are often noisy and inconsistent across views [S1]. The method builds on [TensoRF](13550-model-architecture-and-encoding.md) for efficient radiance field representation and incorporates techniques from [Panoptic NeRF](11916-panoptic-nerf.md) and [DM-NeRF](11916-dm-nerf.md) but removes the dependency on manual ground truth [S1].
