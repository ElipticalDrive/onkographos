# SCALAR-NeRF

Also called: SCAlable LARge-scale Neural Radiance Fields for Scene Reconstruction

## Overview
SCALAR-NeRF is a coarse-to-fine framework for scalable large-scale neural scene reconstruction that structures the neural representation as an encoder-decoder architecture to avoid the 'foggy' issue in Block-NeRF and enable training on a single GPU [S1, unofficial]. It decomposes expansive scenes into manageable blocks, trains a shared decoder from a coarse global model, and fuses local results using the global model to avoid foggy reconstructions [S1, unofficial]. Unlike Block-NeRF, which blends images using an inverse distance weighting function causing foggy appearance when block centroids are close, SCALAR-NeRF fuses local block outputs with a reference image from the coarse global model [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A dataset of images $\{I_i\}$ with corresponding camera poses $\{P_i\}$ covering a large-scale scene.
*   **Outputs:** A set of local neural radiance field models and a fused final reconstruction.

**Data Structures:**
1.  **Multi-resolution Hash Table Encoder:** Maps 3D coordinates to feature vectors.
    *   Structure: A collection of hash tables, one for each resolution level $l \in \{1, \dots, L\}$.
    *   Size: Total number of entries is $2^{19}$ [S1, unofficial].
    *   Feature Vector: For a point $\mathbf{x}$, the feature embedding $F$ is the concatenation of features from all levels: $F = [f_1, \dots, f_L] \in \mathbb{R}^{L \cdot F}$, where $L$ is the number of levels and $F$ is the feature dimension per level [S1, unofficial].
2.  **Shared Decoder:** A shallow Multi-Layer Perceptron (MLP) [S1, unofficial].
    *   Input: Feature vector $F$.
    *   Output: Volume density $\sigma$ and color $\mathbf{c}$.
    *   Formula: $\sigma, \mathbf{c} = \text{Decoder}(F)$ [S1, unofficial].
3.  **Spatial Blocks:** Defined by Axis-Aligned Bounding Boxes (AABBs).
    *   Each block $k$ has a base AABB $\mathcal{B}_k$.
    *   Enhanced AABB $\mathcal{B}'_k$ is scaled by a factor $s_{\text{AABB}}$ to create overlap regions [S1, unofficial].

**Parameters:**
*   Hash table size: $2^{19}$ [S1, unofficial].
*   AABB scale factor ($s_{\text{AABB}}$): Controls overlap. Optimal value found is 1.2 [S1, unofficial].
*   Number of levels ($L$) and feature dimension ($F$): Not given in the sources.

**Steps:**

1.  **Space Contraction (Optional but recommended for unbounded scenes):**
    Contract 3D points $\mathbf{x}$ to a unit sphere using the Mip-NeRF360 method [S1, unofficial]:
    $$
    \text{contract}(\mathbf{x}) = \begin{cases} 
    \mathbf{x}, & \|\mathbf{x}\| \le 1, \\
    \frac{\mathbf{x}}{2 - \frac{1}{\|\mathbf{x}\|}}, & \|\mathbf{x}\| > 1.
    \end{cases}
    $$
    [S1, unofficial]

2.  **Train Coarse Global Model:**
    *   Initialize a hash table encoder and a decoder.
    *   Train this global model on the entire image dataset $\{I_i\}$ using the standard differentiable volume rendering equation [S1, unofficial].
    *   This model serves as the initialization for the local models and the fusion reference.

3.  **Partition Images into Blocks:**
    *   Cluster the camera positions (or image centroids) of the training images into $K$ clusters using KMeans [S1, unofficial].
    *   Assign each image to a block based on its cluster.

4.  **Define Local Block Boundaries:**
    *   For each block $k$, determine its base AABB $\mathcal{B}_k$ enclosing the assigned images' frustums or points.
    *   Scale the AABB by $s_{\text{AABB}}$ to create the enhanced bounding box $\mathcal{B}'_k$:
        $$ \mathcal{B}'_k = \text{Scale}(\mathcal{B}_k, s_{\text{AABB}}) $$
    *   This scaling ensures overlapping regions between adjacent blocks [S1, unofficial].

5.  **Initialize Local Models:**
    *   For each block $k$, initialize a local hash table encoder.
    *   **Share the Decoder:** Copy the weights of the decoder from the trained coarse global model to all local models [S1, unofficial].
    *   **Fix Decoder (Optional but recommended):** Freeze the decoder weights in the local models to eliminate saving the computational graph for these parameters, allowing larger hash table sizes or faster training [S1, unofficial]. Fine-tuning the decoder is optional and not strictly required for satisfactory results [S1, unofficial].

6.  **Train Local Models:**
    *   For each block $k$, train its local hash table encoder using only the images assigned to that block.
    *   The decoder remains fixed (or fine-tuned if chosen).
    *   Rendering is performed only for rays passing through the enhanced bounding box $\mathcal{B}'_k$ [S1, unofficial].

7.  **Fuse Local Results:**
    *   Synthesize an image $I_k$ for each block $k$ using its local model.
    *   Synthesize a reference image $I_{\text{global}}$ using the coarse global model.
    *   Fuse the images. The method proposes using the coarse global model's output for fusion rather than Inverse Distance Weighting (IDW) [S1, unofficial].
    *   *Note on Fusion Strategy:* The source states "fuse them with a reference image rendered from the coarse model" and "leveraging the coarse global model to discard poorly rendered results". It does not provide a specific mathematical formula for the fusion blend (e.g., weighted average, max, etc.), only that the global model's output is used as the reference/fusion mechanism [S1, unofficial].

## Operating characteristics
*   **Time and Memory Complexity:** The method allows training on a single GPU by splitting the scene into blocks, avoiding the need for a large hash table ($2^{21}$) that would exceed GPU memory [S1, unofficial]. The hash table size is $2^{19}$ [S1, unofficial]. Training time is reduced compared to training a single large model because local models are trained on smaller subsets of data [S1, unofficial].
*   **Measured Performance:** On the Tanks and Temples dataset, SCALAR-NeRF with hash table size $2^{19}$ outperforms Block-NeRF and Instant-NGP with hash table size $2^{21}$ in PSNR, SSIM, and LPIPS [S1, unofficial].
*   **Strengths:** Scalable to large-scale scenes; avoids "foggy" artifacts common in Block-NeRF; fits on a single GPU; shared decoder promotes feature space alignment.
*   **Limitations:** Requires KMeans clustering of camera positions; performance degrades if AABB scale factor is too large (increases hash collisions); IDW fusion is inferior to global model fusion.
*   **When to use:** Large-scale outdoor scenes where single-GPU training is required and Block-NeRF produces foggy artifacts.
*   **When not to use:** Small-scale scenes where a single global model suffices; scenes where blocks are very close and IDW is used (SCALAR-NeRF's global fusion is better).

## Background
SCALAR-NeRF was introduced by Yu Chen and Gim Hee Lee from the National University of Singapore in November 2023 [S1, unofficial]. It addresses the limitations of Block-NeRF, which suffers from foggy appearances when block centroids are close due to its inverse distance weighting fusion [S1, unofficial]. It also improves upon Instant-NGP's scalability by enabling large-scale reconstruction on a single GPU without increasing hash table size [S1, unofficial].
