# Neural Multi-View Image Reconstruction with Hash Encoding

Also called: Ours (multi-view)

## Overview
This method performs neural multi-view image reconstruction and novel view synthesis by combining a hash-encoded spatial representation with a signed distance function (SDF) geometry network [S1]. It solves the problem of reconstructing high-frequency geometric details and textureless areas where traditional volume density-based methods like NeRF fail, and where other SDF-based methods like NeuS or IDR are computationally expensive [S1]. It is distinguished from its siblings by using a multi-resolution hash table for feature storage and a specific thresholding strategy based on the mean SDF to filter invalid samples, resulting in significantly faster training and lower memory usage compared to IDR and NeuS [S1].

## How it works
The method consists of a geometry network that predicts SDF values and a light field network that predicts color. The geometry is represented by a hash encoding of 3D coordinates, while the appearance is modeled by an MLP conditioned on view direction, surface normal, and geometry features.

### Inputs and Outputs
*   **Inputs:** A set of multi-view images with known camera parameters (intrinsics and extrinsics).
*   **Outputs:** A reconstructed 3D geometry (extracted as a mesh) and synthesized novel view images.

### Data Structures
**Hash Encoding Table:**
*   Structure: A set of 16 layers (grids).
*   Layout: Each layer is a hash table mapping hashed 3D coordinates to feature vectors.
*   Feature Dimension: 2 per grid feature in each layer [S1].
*   Hashing: Coordinates are hashed to indices in the lookup table. The specific hash function is not detailed in the source, but it maps continuous 3D positions to discrete table indices [S1].

**Network Parameters:**
*   Geometry Network: 6 MLP layers.
*   Light Field Network: 4 hidden layers, each with 256 units [S1].

### Numbered Steps

1.  **Initialization:**
    *   Initialize the geometry network using a modified strategy from [12] (as cited in [S1]).
    *   Initialize the hash table with learnable features [S1].

2.  **Ray Sampling:**
    *   For each ray $r$ passing through a pixel in a training view, sample $N$ points along the ray segment within the bounding volume $\Omega$.
    *   Use a hierarchical sampling strategy to concentrate samples near the expected surface [S1].

3.  **SDF Evaluation and Filtering:**
    *   Query the geometry network to obtain the SDF value $s_k$ for each sampled point $\mathbf{x}_k$.
    *   Calculate the mean SDF of the sampled points on the ray: $\bar{s} = \frac{1}{N} \sum_{k=1}^{N} s_k$.
    *   Eliminate invalid sampled points where the SDF value is significantly positive (outside the surface) relative to the mean. 4.  **Feature Retrieval:**
    *   For the remaining valid points $\mathbf{x}_k$, retrieve the geometry feature vector $\mathbf{f}_k$ from the hash encoding table.
    *   Compute the Fourier positional encoding of the spatial location $\mathbf{x}_k$ with dimension 6: $\text{enc}_{ff}(\mathbf{x}_k)$ [S1].

5.  **Geometry Network Forward Pass:**
    *   Input to the first layer of the geometry network: $\text{enc}_{ff}(\mathbf{x}_k)$.
    *   Input to the third layer: Concatenation of the hash encoding feature $\mathbf{f}_k$ and the output of the second hidden layer.
    *   Output: The SDF value $s_k$ and the gradient (surface normal) $\mathbf{n}_k = \nabla s_k$ [S1].

6.  **Light Field Network Forward Pass:**
    *   Compute Fourier positional encoding of the view direction $\mathbf{v}$ with dimension 6.
    *   Compute Fourier positional encoding of the normal $\mathbf{n}_k$ with dimension 6.
    *   Input to the light field MLP: Concatenation of $\text{enc}_{ff}(\mathbf{v})$, $\text{enc}_{ff}(\mathbf{n}_k)$, and the geometry feature vector $\mathbf{f}_k$ (output from the connected layer of the geometry network) [S1].
    *   Output: The color $\mathbf{c}_k$ [S1].

        $$
        \hat{C}(r) = \sum_{k=1}^{N} w_k \mathbf{c}_k, \quad w_k = T_k \alpha_k, \quad T_k = \prod_{j=1}^{k-1} (1 - \alpha_j)

    *   Compute the photometric loss between $\hat{C}(r)$ and the ground truth pixel color.

    *   Extract the final geometry using the marching cubes algorithm on the SDF field at a resolution of $512^3$ [S1].

        super().__init__()
        self.hash_enc = hash_enc
        # 6 MLP layers
        self.fc1 = nn.Linear(6, hidden_dim) # Input: Fourier pos encoding (dim 6)
        self.fc2 = nn.Linear(hidden_dim, hidden_dim)
        self.fc3 = nn.Linear(hidden_dim + 32, hidden_dim) # Input: prev_out + hash_feat (16 layers * 2 dim)
        self.fc4 = nn.Linear(hidden_dim, hidden_dim)
        self.fc5 = nn.Linear(hidden_dim, hidden_dim)
        self.fc6 = nn.Linear(hidden_dim, 1) # Output: SDF

        # 1. Fourier positional encoding of x (dim 6)
        x_enc = fourier_encoding(x, num_freqs=6)
        
        # 2. Hash encoding features
        hash_feat = self.hash_enc(x)
        
        # 3. MLP Forward
        h1 = torch.relu(self.fc1(x_enc))
        h2 = torch.relu(self.fc2(h1))
        
        # Concatenate hash features at layer 3
        h3_in = torch.cat([h2, hash_feat], dim=-1)
        h3 = torch.relu(self.fc3(h3_in))
        h4 = torch.relu(self.fc4(h3))
        h5 = torch.relu(self.fc5(h4))
        
        sdf = self.fc6(h5)
        return sdf

class LightFieldNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        # 4 hidden layers, 256 units each
        self.fc1 = nn.Linear(6 + 6 + 32, 256) # View enc(6) + Normal enc(6) + Hash feat(32)
        self.fc2 = nn.Linear(256, 256)
        self.fc3 = nn.Linear(256, 256)
        self.fc4 = nn.Linear(256, 256)
        self.fc5 = nn.Linear(256, 3) # Output: Color (RGB)

    def forward(self, v, n, hash_feat):
        v_enc = fourier_encoding(v, num_freqs=6)
        n_enc = fourier_encoding(n, num_freqs=6)
        x = torch.cat([v_enc, n_enc, hash_feat], dim=-1)
        h = torch.relu(self.fc1(x))
        h = torch.relu(self.fc2(h))
        h = torch.relu(self.fc3(h))
        h = torch.relu(self.fc4(h))
        color = torch.sigmoid(self.fc5(h))
        return color

def fourier_encoding(x, num_freqs=6):
    # Standard Fourier positional encoding
    # x: (N, D)
    # Returns: (N, 2*D*num_freqs)
    scales = torch.tensor([2**i for i in range(num_freqs)], dtype=x.dtype, device=x.device)
    scaled_x = x.unsqueeze(-1) * scales.unsqueeze(0)
    scaled_x = scaled_x.view(*x.shape, -1)
    return torch.cat([torch.sin(scaled_x), torch.cos(scaled_x)], dim=-1)

def render_ray(ray_origin, ray_direction, geometry_net, light_field_net, hash_enc, num_samples=512):
    # Sample points along ray
    t_vals = torch.linspace(0.0, 1.0, num_samples)
    points = ray_origin.unsqueeze(0) + ray_direction.unsqueeze(0) * t_vals.unsqueeze(-1)
    
    # Get SDF
    sdf = geometry_net(points)
    
    # Filter invalid points using mean SDF threshold
    mean_sdf = sdf.mean()
    # [G] Exact thresholding logic from Eq. (8) is not provided. 
    # Assuming points with SDF > mean_sdf + epsilon are invalid.
    valid_mask = sdf < (mean_sdf + 0.1) # Placeholder epsilon
    
    if not valid_mask.any():
        return torch.zeros(3), torch.zeros(1)
        
    valid_points = points[valid_mask]
    valid_sdf = sdf[valid_mask]
    
    # Compute density from SDF [G] Standard conversion assumed
    # sigma = max(0, -sdf / delta) * smoothstep
    delta = 0.01 # Small displacement
    sigma = torch.relu(-valid_sdf / delta)
    alpha = 1.0 - torch.exp(-sigma * delta)
    
    # Get features for valid points
    hash_feat = hash_enc(valid_points)
    
    # Compute normals (gradient of SDF) [G] Numerical gradient approximation
    eps = 1e-4
    grad = torch.zeros_like(valid_points)
    for i in range(3):
        offset = valid_points.clone()
        offset[:, i] += eps
        sdf_plus = geometry_net(offset)
        grad[:, i] = (sdf_plus - valid_sdf) / eps
        
    # Render color
    # View direction is constant for the ray
    v = ray_direction
    color = light_field_net(v, grad, hash_feat)
    
    # Volume rendering
    T = torch.cumprod(torch.cat([torch.ones(1, device=points.device), 1.0 - alpha[:-1]], dim=0), dim=0)
    weights = T * alpha
    rendered_color = torch.sum(weights.unsqueeze(-1) * color, dim=0)
    
    return rendered_color, alpha

## Operating characteristics
*   **Time Complexity:** Training is significantly faster than baselines. On the DTU dataset, it takes 1.8 hours compared to 5.2 hours for IDR and 7.2 hours for NeuS [S1].
*   **Memory Complexity:** Uses 5 GB of GPU memory, compared to 6.5 GB for IDR and 7 GB for NeuS [S1].
*   **Performance:** Achieves a mean PSNR of 30.85 dB and a mean Chamfer-L2 distance of $0.72 \times 10^{-6}$ on multi-view reconstruction tasks [S1].
*   **Strengths:** Reconstructs more geometric detail than baselines like NeuS, IDR, VolSDF, and UNISURF, particularly in textureless areas. Provides better high-frequency detail than NeRF, which suffers from rough geometry and noise due to lack of direct constraints on volume density [S1].
*   **Limitations:** The method relies on a predefined bounding volume and marching cubes for mesh extraction, which may limit resolution to the grid size ($512^3$) [S1].

## Background
The method was proposed by Z. Deng, H. Xiao, Y. Lang, et al. in the paper "Multi-scale hash encoding based neural geometry representation" [S1]. It builds upon the principles of neural implicit representations, specifically leveraging hash encoding to accelerate feature lookup and SDF-based geometry for explicit surface extraction. It is compared against state-of-the-art methods including IDR, NeuS, UNISURF, VolSDF, and NeRF [S1].
