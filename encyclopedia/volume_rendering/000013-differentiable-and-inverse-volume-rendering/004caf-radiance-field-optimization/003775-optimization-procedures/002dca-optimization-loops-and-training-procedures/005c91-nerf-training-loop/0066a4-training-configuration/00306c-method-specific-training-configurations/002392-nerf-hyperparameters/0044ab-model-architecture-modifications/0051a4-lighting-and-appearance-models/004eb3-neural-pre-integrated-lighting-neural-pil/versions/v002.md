# Neural Pre-Integrated Lighting (Neural-PIL)
Also called: Neural-PIL

## Overview
Neural-PIL replaces the costly numerical integration of incoming light with a simple neural network query, predicting pre-integrated light $\tilde{L}_i$ directly from illumination embedding, direction, and roughness [S1, unofficial]. Unlike Spherical Harmonics (SH) or Spherical Gaussian (SG) light representations which suffer from lack of fine details or high memory costs, Neural-PIL is an MLP that directly produces pre-integrated light, representing finer details in illumination [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:** Illumination embedding $\mathbf{z}_l \in \mathbb{R}^{128}$, incoming light direction $\omega_r \in \mathbb{R}^3$, and roughness $b_r$ (scalar) [S1, unofficial].
*   **Output:** Pre-integrated light $\tilde{L}_i(\omega_r, b_r)$ [S1, unofficial].

**Data Structures**
The method uses a coordinate-based Multi-Layer Perceptron (MLP) architecture based on pi-GAN with FiLM-SIREN layers [S1, unofficial].
*   **FiLM-SIREN Layer:** Takes modulating parameters (scalar $\lambda_0$ and vectors $\beta, \gamma$) to modulate the output $y$ of an earlier linear layer followed by sine computation [S1, unofficial].
*   **Mapping Networks:** Two separate networks predict the modulating parameters $(\gamma, \beta)$ for the FiLM-SIREN layers [S1, unofficial].

**Numbered Steps**
1.  **Illumination Decoding:** The network takes the direction $\omega_r$ as input. The first few layers decode illumination information for the given direction. The first mapping network generates modulating parameters $(\gamma, \beta)$ for these first layers from the illumination embedding $\mathbf{z}_l$ [S1, unofficial].
2.  **Light Integration:** A later layer (specifically the penultimate layer) performs light integration conditioned on the material roughness $b_r$. The second mapping network generates modulating parameters for this penultimate layer from the roughness $b_r$ [S1, unofficial].
3.  **Query:** The network outputs $\tilde{L}_i(\omega_r, b_r)$, which is used in the rendering equation [S1, unofficial].

**Formulas**
The rendering equation approximates the outgoing radiance $L_o(x, \omega_o)$ using the pre-integrated light $\tilde{L}_i$ [S1, unofficial]:

$$
L_o(x, \omega_o) \approx \frac{b_d}{\pi}\tilde{L}_i(n, 1) + b_s \left( F_0(\omega_o, n)B_0(\omega_o \cdot n, b_r) + B_1(\omega_o \cdot n, b_r) \right) \tilde{L}_i(\omega_r, b_r)
$$

Where:
*   The first term is the diffuse component, parameterized by surface normal $n \in \mathbb{R}^3$ and a diffuse roughness of 1 [S1, unofficial].
*   The second term is the specular component [S1, unofficial].
*   $F_0(\omega_o, n) = (1 - \omega_o \cdot h)^5$ with $h = (\omega_i + \omega_o)/\|\omega_i + \omega_o\|$ [S1, unofficial].
*   $B_0$ and $B_1$ are 2D lookup textures indexed by $(\omega_o \cdot n)$ and roughness $b_r$ [S1, unofficial].
*   The pre-integrated light is defined as:
    $$
    \tilde{L}_i(\omega_r, b_r) = \int_{\Omega} D(b_r, \omega_i, \omega_r) L_i(x, \omega_i) d\omega_i
    $$
    where $D$ describes the microfacet distribution [S1, unofficial].

The activation function for the FiLM-SIREN layers is:
$$
\phi(y) = \sin(\lambda_0 \gamma \odot y + \beta)
$$
where $\odot$ denotes a Hadamard product [S1, unofficial].

**Pseudocode**
```python
def neural_pil_query(z_l, omega_r, b_r):
    """
    Predicts pre-integrated light using Neural-PIL.
    
    Args:
        z_l: Illumination embedding, shape (128,)
        omega_r: Incoming light direction, shape (3,)
        b_r: Roughness scalar
        
    Returns:
        L_tilde: Pre-integrated light value
    """
    # Mapping Network 1: Generates parameters for first layers from illumination embedding
    # Note: Specific architecture of mapping networks is not detailed in sources [G]
    params_first_layers = mapping_network_1(z_l) 
    
    # Mapping Network 2: Generates parameters for penultimate layer from roughness
    # Note: Specific architecture of mapping networks is not detailed in sources [G]
    params_penultimate = mapping_network_2(b_r)
    
    # Neural-PIL Forward Pass
    # Input to network is omega_r
    x = omega_r
    
    # First few layers: Conditioned by params_first_layers
    # These layers decode illumination information for the given direction
    for layer in first_layers:
        # Apply FiLM-SIREN modulation
        # layer.linear computes y = Wx + b
        y = layer.linear(x)
        # Apply sine activation with modulation
        # params_first_layers contains lambda_0, gamma, beta for this layer
        lambda_0, gamma, beta = params_first_layers[layer.id]
        x = sin(lambda_0 * (gamma * y) + beta)
        
    # Intermediate layers (standard SIREN or similar)
    # Note: Exact intermediate layer definitions are not detailed in sources [G]
    for layer in intermediate_layers:
        x = sin(layer.linear(x))
        
    # Penultimate layer: Conditioned by params_penultimate
    # This layer performs light integration conditioned on roughness
    y = penultimate_layer.linear(x)
    lambda_0, gamma, beta = params_penultimate
    x = sin(lambda_0 * (gamma * y) + beta)
    
    # Final layer outputs the pre-integrated light
    L_tilde = final_layer(x)
    
    return L_tilde
```

**Parameters**
*   Illumination embedding dimension: 128 [S1, unofficial].
*   Direction dimension: 3 [S1, unofficial].
*   Roughness: Scalar [S1, unofficial].

**Edge Cases and Pitfalls**
*   The pre-integrated light $\tilde{L}_i$ is queried twice: once for the diffuse part (with normal $n$ and roughness 1) and once for the specular part (with mirrored view direction $\omega_r$ and roughness $b_r$) [S1, unofficial].
*   The method relies on a frozen Light-SMAE encoder to provide the illumination embedding $\mathbf{z}_l$, ensuring a smooth embedding space [S1, unofficial].

## Subtopics

### Lighting and Appearance Models
The parent category. Neural-PIL is a modification within this category that replaces standard lighting representations with a learned neural approximation. See [Lighting and Appearance Models](14522-lighting-and-appearance-models.md).

### Spherical Harmonics NeRF
A sibling method that uses spherical harmonics to represent lighting. Neural-PIL is preferred when fine illumination details are required, as SH suffers from lack of fine details or high memory costs. See [Spherical Harmonics NeRF](14480-spherical-harmonics-nerf.md).

## Operating characteristics
*   **Time Complexity:** The method replaces costly numerical integration or convolution on environment maps with a simple neural network query, significantly reducing rendering time per pixel compared to direct integration [S1, unofficial].
*   **Memory Complexity:** Avoids the high memory costs associated with high-band SH or SG representations needed for fine details [S1, unofficial].
*   **Strengths:** Represents finer details in illumination compared to SG or SH representations [S1, unofficial].
*   **Limitations:** Requires training a separate Light-SMAE and BRDF-SMAE beforehand, and the Neural-PIL network itself, which adds complexity to the training pipeline [S1, unofficial].
*   **When to use:** When differentiable rendering requires high-fidelity illumination details that SH/SG cannot provide efficiently, and computational resources allow for the pre-training of the embedding networks [S1, unofficial].
*   **When not to use:** When fine illumination details are not critical, or when memory constraints prevent storing the additional neural networks and embeddings [S1, unofficial].

## Background
Neural-PIL was introduced in the paper "Neural-PIL: Neural Pre-Integrated Lighting for Reflectance Decomposition" [S1, unofficial]. The method addresses the impracticality of costly numerical accumulation or convolution on complete environment maps within differential rendering engines [S1, unofficial]. It leverages a pi-GAN-like architecture with FiLM-SIREN layers [S1, unofficial]. The illumination embedding $\mathbf{z}_l$ is derived from a Light-SMAE (Smooth Manifold Auto-encoder) trained on a dataset of 320 environment maps [S1, unofficial]. The Neural-PIL network is trained with the manifold created by the frozen Light-SMAE encoder, separated from the BRDF-SMAE to ease memory requirements [S1, unofficial].
