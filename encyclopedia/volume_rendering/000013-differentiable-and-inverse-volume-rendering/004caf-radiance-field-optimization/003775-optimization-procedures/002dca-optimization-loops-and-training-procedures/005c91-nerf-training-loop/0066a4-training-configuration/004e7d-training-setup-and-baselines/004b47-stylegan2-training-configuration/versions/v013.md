# StyleGAN2 Training Configuration

Also called: StyleGAN2 Training Setup

## Overview
This configuration adapts the StyleGAN2 architecture for training 3D-aware image synthesis models (such as StyleNeRF or VoxGRAF) by leveraging its discriminator and generator training dynamics. It solves the problem of stable adversarial training for high-resolution neural radiance fields by incorporating equalized learning rates, minibatch standard deviation, and mixed precision. It is distinguished from standard NeRF baselines by its reliance on GAN-specific regularization (R1) and weight averaging (EMA) rather than purely photometric supervision, and from original StyleGAN2 by the explicit exclusion of path regularization and style-mixing to suit the differentiable rendering pipeline.

## How it works
**Inputs and Outputs:**
*   **Inputs:** Real image batches, latent vectors $z$, camera parameters (intrinsics/poses), and scene geometry (voxel grid or implicit field).
*   **Outputs:** Discriminator scores (real/fake logits), Generator weights (EMA updated), and rendered images.

**Data Structures:**
*   **Generator/Discriminator Weights:** Standard PyTorch tensors.
*   **EMA State:** Separate copy of generator weights, updated via exponential moving average.
*   **Minibatch Statistics:** A tensor of shape $(B, C, H, W)$ representing the standard deviation across the batch dimension $B$ for each channel $C$ and spatial location $(H, W)$.

**Parameters:**
*   **R1 Regularization Strength ($\gamma$):** 1.0 [S1].
*   **R1 Frequency:** Once every 4 minibatches [S1].
*   **Learning Rate Scaling:** Equalized learning rates applied to trainable parameters [S1].
*   **Mixed Precision:** Enabled for both Generator and Discriminator [S1].
*   **Path Regularization / Style-Mixing:** Disabled [S1].

**Numbered Steps:**
1.  **Initialize Weights:** Load generator weights. If the dataset is small (e.g., AFHQ), initialize with a generator pretrained on FFHQ [S1].
2.  **Forward Pass (Generator):** Sample latent vectors $z$. Pass through the generator to produce a 3D representation (e.g., sparse voxel grid). Render images using differentiable volume rendering (equidistant sampling, early exit if transmittance $T_i < 10^{-7}$) [S1].
3.  **Forward Pass (Discriminator):** Pass real images and generated images through the discriminator. The discriminator uses a skip architecture for progressive growing, adding a downsampled version of the input image to the input of each layer [S1].
4.  **Minibatch Standard Deviation:** Compute the standard deviation of the discriminator's feature maps across the minibatch dimension. Concatenate this statistic to the feature maps before the final classification layer [S1].
5.  **Compute Losses:**
    *   Calculate adversarial loss for real and fake images.
    *   **R1 Regularization:** If the current minibatch index is divisible by 4, compute the R1 gradient penalty on the real images. The penalty is $\gamma \cdot \frac{1}{2} \|\nabla_{x_r} D(x_r)\|^2$ [S1].
6.  **Backward Pass:** Compute gradients for both Generator and Discriminator.
7.  **Update Weights:** Update generator and discriminator weights using an optimizer (typically Adam).
8.  **EMA Update:** Update the generator's EMA weights: $W_{ema} \leftarrow \alpha W_{ema} + (1-\alpha) W_{gen}$, where $\alpha$ is the decay rate (typically 0.999 or similar, though exact $\alpha$ is not specified in sources, the mechanism is [S1]).
9.  **Repeat:** Continue until convergence.

**Pseudocode:**
```python
# Pseudocode for one training step
def train_step(real_images, latent_z, generator, discriminator, ema_generator, optimizer_g, optimizer_d, step_count):
    # 1. Generator Forward
    # Rendered images are produced via differentiable volume rendering
    fake_images = generator(latent_z)
    
    # 2. Discriminator Forward (Real)
    # Apply minibatch standard deviation
    real_features = discriminator(real_images)
    real_std = torch.std(real_features, dim=0, unbiased=False)
    real_features = torch.cat([real_features, real_std], dim=1)
    real_logits = discriminator.classifier(real_features)
    
    # 3. Discriminator Forward (Fake)
    fake_features = discriminator(fake_images)
    fake_std = torch.std(fake_features, dim=0, unbiased=False)
    fake_features = torch.cat([fake_features, fake_std], dim=1)
    fake_logits = discriminator.classifier(fake_features)
    
    # 4. Loss Calculation
    # Adversarial Loss (e.g., WGAN-GP or standard GAN loss)
    d_loss_real = -torch.mean(real_logits)
    d_loss_fake = torch.mean(fake_logits)
    d_loss = d_loss_real + d_loss_fake
    
    # R1 Regularization (applied every 4 steps)
    r1_penalty = 0.0
    if step_count % 4 == 0:
        # Compute gradient of real logits w.r.t real images
        grad_real, = torch.autograd.grad(
            outputs=real_logits.sum(), 
            inputs=real_images, 
            create_graph=True
        )
        # R1 penalty: gamma * 0.5 * ||grad||^2
        r1_penalty = 1.0 * 0.5 * (grad_real ** 2).sum()
        
    d_loss += r1_penalty
    
    # Generator Loss
    g_loss = -torch.mean(fake_logits)
    
    # 5. Backward Pass
    optimizer_d.zero_grad()
    d_loss.backward()
    optimizer_d.step()
    
    optimizer_g.zero_grad()
    g_loss.backward()
    optimizer_g.step()
    
    # 6. EMA Update
    update_ema(ema_generator, generator, decay=0.999) # Decay value inferred from standard practice, mechanism from [S1]
    
    return d_loss.item(), g_loss.item()
```

**Edge Cases and Pitfalls:**
*   **Small Datasets:** For datasets like AFHQ, training from scratch may fail. The pitfall is to finetune a generator pretrained on FFHQ [S1].
*   **Regularization Frequency:** Applying R1 every step is computationally expensive. The source specifies applying it every 4 minibatches to reduce cost [S1].
*   **Missing Features:** Unlike original StyleGAN2, path regularization and style-mixing are not used. Implementing them would be incorrect for this specific configuration [S1].

## Subtopics

### Conditional Discriminator with Skip Connections for Progressive Growing
A variant of the discriminator architecture used in this configuration. It incorporates conditional input (e.g., camera poses or class labels) and uses a skip connection architecture for progressive growing, where a downsampled version of the input image is added to the input of each layer [S1]. This allows the model to train at increasing resolutions smoothly.

## Operating characteristics
*   **Time Complexity:** Training is accelerated by mixed-precision arithmetic [S1]. R1 regularization is applied every 4 minibatches, reducing the computational overhead compared to per-step R1 [S1].
*   **Memory Complexity:** Mixed precision reduces memory usage for both generator and discriminator [S1].
*   **Performance:** The configuration is designed for fast 3D-aware synthesis (e.g., VoxGRAF) [S1].
*   **Strengths:** Stable training for high-resolution images; efficient via mixed precision and infrequent R1; robust to small datasets via finetuning.
*   **Limitations:** Requires careful tuning of learning rates (equalized) and regularization strength; not suitable for datasets where style-mixing is beneficial (though excluded here by design).
*   **When to use:** When training 3D-aware generative models (NeRF-based) that benefit from GAN stability and high-resolution synthesis.
*   **When not to use:** When computational resources are extremely limited and R1 cannot be skipped; when style-mixing is required for the specific data distribution.

## Background
This configuration is derived from the StyleGAN2 training methodology [S1]. It was adapted for 3D-aware image synthesis in works such as StyleNeRF and VoxGRAF [S1]. The use of equalized learning rates, minibatch standard deviation, and R1 regularization are hallmarks of the StyleGAN2 paper . The specific adaptation for volume rendering (excluding path regularization/style-mixing) is detailed in the VoxGRAF paper [S1].
