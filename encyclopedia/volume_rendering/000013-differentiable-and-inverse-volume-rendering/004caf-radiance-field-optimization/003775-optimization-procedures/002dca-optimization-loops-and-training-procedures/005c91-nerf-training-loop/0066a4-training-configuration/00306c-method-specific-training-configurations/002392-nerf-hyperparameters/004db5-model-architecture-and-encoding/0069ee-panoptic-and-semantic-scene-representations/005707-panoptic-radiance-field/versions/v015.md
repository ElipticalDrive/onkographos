# Panoptic Radiance Field

Also called: Panoptic Lifting

## Overview
Panoptic Lifting learns a panoptic 3D volumetric representation from posed RGB images and machine-generated 2D panoptic segmentation masks, lifting noisy 2D labels into a consistent 3D representation comprising color, density, semantics, and instances [S1]. It differs from sibling methods like [Panoptic NeRF](11916-panoptic-nerf.md) and [DM-NeRF](11916-dm-nerf.md) by requiring only machine-generated 2D labels rather than manual ground truth or coarse meshes, and employs specific robustness mechanisms (bounded fields, gradient blocking) to handle label noise [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Posed RGB images $\{I\}$ and corresponding machine-generated 2D panoptic segmentation masks. Each training ray $r$ has an associated RGB color $\hat{c}_r \in \mathbb{R}^3$, semantic class $\hat{k}_r \in K$, and 2D instance ID $\hat{h}_r \in H_I$ (defined only for thing classes $\hat{k}_r \in K_T$) [S1].
*   **Outputs:** A panoptic radiance field $\Phi(\mathbf{x}, \mathbf{d})$ that renders RGB color, density, semantic class distribution, and instance identifiers for novel views [S1].

**Data Structures:**
The field $\Phi(\mathbf{x}, \mathbf{d})$ assigns to each 3D point $\mathbf{x} \in \mathbb{R}^3$ and viewing direction $\mathbf{d} \in S^2$:
1.  Density $\sigma \in \mathbb{R}_{\ge 0}$ and RGB color $\mathbf{c} \in \mathbb{R}^3$, modeled using TensoRF [S1].
2.  Semantic class distribution $\kappa$ over classes $K$, modeled by a small MLP [S1].
3.  Distribution $\pi$ over surrogate identifiers $J$, modeled by a separate small MLP [S1].
    *   $K$ is partitioned into thing classes $K_T$ and stuff classes $K_S$.
    *   $J$ is a fixed set of class-agnostic surrogate identifiers [S1].
    *   The set of all possible 3D instances is $H_{3D} := K_T \times J$ [S1].

**Rendering Equation:**
Given density $\sigma$, any vector field $f$ along ray $r$ is rendered as [S1]:
$$ R[f | r, \sigma] := \int_0^\infty \alpha_t(r) \sigma(r_t) f(r_t, d_{r_t}) dt $$
where $\alpha_t(r) := \exp \left(-\int_0^t \sigma(r_s) ds\right)$ is the transmittance [S1].

**Training Procedure:**
1.  **Preprocessing (Test-Time Augmentation):** For each training image, apply augmentations (horizontal flip, scale, brightness, contrast) and fuse segmentations via segment clustering to obtain a refined semantic class distribution $\hat{\kappa}_r$ and a confidence estimate $w_r$ for each pixel/ray [S1].
2.  **Linear Assignment:** To handle inconsistent 2D instance IDs across views, solve a linear assignment problem. The cost is based on the model's current 3D instance predictions and the machine-generated 2D masks. This maps each 2D instance $\hat{h}_r$ to a 3D surrogate identifier via an injective mapping $\Pi^*_R$ [S1].
3.  **Loss Computation:** Compute the total loss $L_{tot}$ over a batch of rays $R = R_S \cup R_I$ (where $R_S$ are rays sampled across the scene and $R_I$ are rays from a single image) [S1]:
    $$ L_{tot}(R) := \lambda_{ins} L_{ins}(R_I) + \lambda_{con} L_{con}(R_I) + \lambda_{RGB} L_{RGB}(R_S) + \lambda_{sem} L_{sem}(R_S) $$
    *   $L_{RGB}$: L2 photometric loss on rendered color [S1].
    *   $L_{sem}$: Cross-entropy between rendered distribution $\kappa_r$ and 2D label distribution $\hat{\kappa}_r$, weighted by confidence $w_r$:
        $$ L_{sem}(R) := -\frac{1}{|R|} \sum_{r \in R} w_r \sum_{k \in K} \hat{\kappa}_r(k) \log \kappa_r(k) $$
        Note: The semantic field renders bounded probability distributions, not logits, to prevent semantic inconsistencies in low-density areas [S1].
    *   $L_{ins}$: Log-loss of the rendered instance distribution against the mapped 2D instances [S1].
    *   $L_{con}$: Segment consistency loss to avoid fragmenting objects due to label inconsistencies [S1].
4.  **Gradient Blocking:** Stop gradients from the semantic and instance branches back to the density field to prevent noisy labels from corrupting geometry [S1].
5.  **Optimization:** Update parameters using Adam [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.optim as optim

class PanopticRadianceField:
    def __init__(self, num_surrogates, num_classes, tensorf_config):
        # TensoRF for density and color
        self.tensorf = TensoRF(tensorf_config)
        
        # Small MLP for semantic distribution (outputs probabilities)
        self.semantic_mlp = nn.Sequential(
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Linear(64, num_classes),
            nn.Softmax(dim=-1) # Bounded probability distribution
        )
        
        # Small MLP for instance surrogate distribution
        self.instance_mlp = nn.Sequential(
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Linear(64, num_surrogates),
            nn.Softmax(dim=-1)
        )
        
        # Loss weights
        self.lambda_ins = 1.0
        self.lambda_con = 1.35
        self.lambda_rgb = 1.0
        self.lambda_sem = 1.0

    def forward(self, x, d):
        # Query TensoRF for density and color
        sigma, color = self.tensorf(x, d)
        
        # Encode x and d (simplified feature extraction for heads)
        # In TensoRF, features are extracted from grid structures
        features = self.tensorf.get_features(x, d)
        
        # Semantic and Instance heads
        # Note: Gradients from these heads are detached before backprop to density
        with torch.no_grad():
            semantic_dist = self.semantic_mlp(features)
            instance_dist = self.instance_mlp(features)
            
        return sigma, color, semantic_dist, instance_dist

    def compute_loss(self, rays, gt_rgb, gt_sem_dist, gt_confidence, gt_instance_ids, surrogate_mapping):
        sigma, color, semantic_dist, instance_dist = self.forward(rays.x, rays.d)
        
        # Rendered values
        rendered_color = color # Assuming direct color output or simple integration
        rendered_sem = semantic_dist
        rendered_inst = instance_dist
        
        # 1. RGB Loss (L2)
        l_rgb = torch.mean((rendered_color - gt_rgb) ** 2)
        
        # 2. Semantic Loss (Cross-Entropy, weighted by confidence)
        # gt_sem_dist is the distribution from TTA fusion
        l_sem = 0
        for r_idx in range(len(rays)):
            w = gt_confidence[r_idx]
            # Cross entropy: - sum(p * log(q))
            ce = -torch.sum(gt_sem_dist[r_idx] * torch.log(rendered_sem[r_idx] + 1e-8))
            l_sem += w * ce
        l_sem = l_sem / len(rays)
        
        # 3. Instance Loss (Log-loss against mapped surrogates)
        # surrogate_mapping maps 2D instance ID to 3D surrogate index
        l_ins = 0
        for r_idx in range(len(rays)):
            if rays.is_thing_class[r_idx]:
                target_surrogate = surrogate_mapping[rays.instance_id[r_idx]]
                # Log loss for the specific surrogate
                l_ins += -torch.log(rendered_inst[r_idx, target_surrogate] + 1e-8)
        l_ins = l_ins / len(rays)
        
        # 4. Segment Consistency Loss (Implementation detail not fully specified in source)
        # [G] Placeholder for consistency regularization term
        l_con = 0.0 
        
        total_loss = (self.lambda_ins * l_ins + 
                      self.lambda_con * l_con + 
                      self.lambda_rgb * l_rgb + 
                      self.lambda_sem * l_sem)
        
        return total_loss

    def render_panoptic(self, rays):
        sigma, color, semantic_dist, instance_dist = self.forward(rays.x, rays.d)
        
        # Rendered semantic class
        k_star = torch.argmax(semantic_dist, dim=-1)
        
        # Rendered instance ID
        # If thing class, combine class and most probable surrogate
        j_star = torch.argmax(instance_dist, dim=-1)
        instance_ids = torch.stack([k_star, j_star], dim=-1)
        
        return color, instance_ids
```

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Learning Rates:** $5 \times 10^{-4}$ for MLPs; $1 \times 10^{-2}$ for TensoRF lines and planes [S1].
*   **Loss Weights:** $\lambda_{con} = 1.35$, $\lambda_{ins} = 1$, $\lambda_{sem} = 1$, $\lambda_{RGB} = 1$ [S1].
*   **Hardware:** 1 NVIDIA A6000 [S1].
*   **Duration:** 450k iterations (~10 hours) [S1].

**Edge Cases and Pitfalls:**
*   **Logits vs. Probabilities:** Rendering class logits instead of probabilities can cause semantic inconsistencies in low-density areas because unbounded logits can generate significant signals violating geometric constraints. The method uses bounded probability distributions [S1].
*   **Geometry Corruption:** Noisy 2D labels can influence geometry, causing "cloudy" geometry to satisfy conflicting labels. This is mitigated by stopping gradients from segmentation branches back to densities [S1].
*   **Label Noise:** Machine-generated labels are noisy and inconsistent across views. Test-time augmentations and confidence weighting are required to handle this [S1].
*   **Class Limitations:** The method is limited to classes supported by the pre-trained 2D panoptic segmentation model (e.g., Mask2Former) [S1].

## Operating characteristics
*   **Time and Memory:** Training takes ~10 hours on a single NVIDIA A6000 for 450k iterations [S1]. The method is offline due to lengthy pre-processing (pose estimation, 2D segmentation, optimization) [S1].
*   **Performance:** Improves scene-level Panoptic Quality (PQ) by 8.4% on Hypersim, 13.8% on Replica, and 10.6% on ScanNet over state-of-the-art methods [S1]. Maintains comparable PSNR for novel view synthesis while significantly improving mIoU and PQ_scene [S1].
*   **Strengths:** Robust to inherent noise in machine-generated labels; requires no manual ground truth; enables scene editing (deletion, duplication, manipulation) [S1].
*   **Limitations:** Limited to classes in the pre-trained 2D model; offline processing; dependent on accurate pose estimation [S1].

## Background
Panoptic Lifting was introduced in 2023 by the authors of "Panoptic Lifting for 3D Scene Understanding with Neural Fields" [S1]. It addresses the limitations of prior panoptic NeRF methods (Panoptic NeRF, DM-NeRF) which required manual ground truth or coarse meshes, and PNF which required 3D bounding boxes. It builds on TensoRF for efficient density/color representation and uses Mask2Former with a Swin-L backbone for 2D label generation [S1].
