# NeRF Training Setup

Also called: Control-NeRF Training Setup, Nerfstudio Training

## Overview
This method defines the training configuration for NeRF-based models using the Nerfstudio library, specifically leveraging NerfAcc and Instant-NGP for fast convergence on static scenes [S2]. It differs from standard NeRF implementations by replacing the positionally encoded 3D position input with a pre-sampled 64-dimensional feature vector, thereby omitting positional encoding for the spatial coordinates while retaining it for view directions [S1]. This setup is designed for static scenes with minimal dynamic elements, such as surgical environments [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A dataset of multi-view images (e.g., LLFF or laparoscopic video frames), estimated camera poses, and a pre-computed feature volume $V_s$ [S1, S2].
*   **Outputs:** Optimized network parameters for the coarse and fine radiance fields, resulting in a renderable implicit representation [S1, S2].

**Data Structures:**
*   **Feature Volume ($V_s$):** A 3D grid storing 64-dimensional feature vectors. Each vector $\mathbf{v}_s$ at position $\mathbf{p}$ is obtained via trilinear sampling $S(V_s, \mathbf{p})$ [S1].
*   **Ray Bundle:** A batch of rays, each defined by origin and direction, sampled from the input images [S2].
*   **Network Input:** The radiance function $F_\Theta$ receives the concatenated feature vector $\mathbf{v}_s$ and the directionally encoded vector $\gamma(\mathbf{d})$ [S1].

**Numbered Steps:**
1.  **Ray Sampling:** Sample 1024 rays per batch from the input images, scaled to a resolution of $504 \times 378$ [S1]. For surgical video applications, rays are sampled from extracted video frames, excluding specific regions to prevent artifacts [S2].
2.  **Coarse Network Query ($\hat{C}_c$):**
    *   Sample 64 points from evenly spaced bins along the ray length [S1].
    *   For each point $\mathbf{p}$, retrieve the feature vector $\mathbf{v}_s = S(V_s, \mathbf{p})$ [S1].
    *   Encode the ray direction $\mathbf{d}$ using positional encoding $\gamma(\mathbf{d})$ [S1].
    *   Query the coarse network $F_\Theta(\mathbf{v}_s, \gamma(\mathbf{d}))$ to predict density $\sigma$ and color $\mathbf{c}$ [S1].
3.  **Fine Network Sampling:**
    *   Use the opacity results from the coarse network to sample 64 additional points, concentrating samples in relevant portions of the scene volume (e.g., near surfaces) [S1].
4.  **Fine Network Query ($\hat{C}_f$):**
    *   Query the fine network with the newly sampled points and their corresponding feature vectors and direction encodings to predict final density and color [S1].
5.  **Differentiable Volume Rendering:**
    *   Compute the pixel color $\mathbf{C}(\mathbf{r})$ using the discretized volume rendering integral [S1]:
        $$ \mathbf{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i $$
        where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance, $\sigma_i$ is the density, $\delta_i$ is the segment length, and $\mathbf{c}_i$ is the color at sample $i$ [S1].
6.  **Loss Computation and Optimization:**
    *   Compute the Mean Squared Error (MSE) between the rendered pixel colors and the ground truth images [S1, S2].
    *   Update network parameters using stochastic gradient descent [S2].

**Formulas:**
*   **Directional Positional Encoding:**
    $$ \gamma(\mathbf{p}) = [\sin(2^0\pi\mathbf{p}), \cos(2^0\pi\mathbf{p}), \dots, \sin(2^{L-1}\pi\mathbf{p}), \cos(2^{L-1}\pi\mathbf{p})] $$
    where $\mathbf{p}$ is each dimension of the direction vector $\mathbf{d} \in \mathbb{R}^3$ and $L=4$ [S1].
*   **Transmittance:**
    $$ T(t) = \exp \left( -\int_{t_n}^{t} \sigma(\mathbf{v}_s) ds \right) $$
    approximated discretely in the rendering step [S1].

**Parameters:**
*   **Positional Encoding Depth ($L$):** 4 for direction vectors [S1].
*   **Batch Size:** 1024 rays [S1].
*   **Image Resolution:** $504 \times 378$ for LLFF datasets [S1].
*   **Coarse Samples:** 64 points [S1].
*   **Fine Samples:** 64 points [S1].
*   **Feature Vector Dimension:** 64 [S1].

**Edge Cases and Pitfalls:**
*   **Dynamic Content:** The method assumes static scenes. Significant movement (e.g., moving organs) may degrade quality unless handled by specific dynamic variants [S2].
*   **Ray Exclusion:** In surgical video contexts, rays passing through specific artifacts (e.g., red lines from tools) must be excluded to prevent training artifacts [S2].
*   **Feature Sampling:** The method relies on accurate trilinear sampling from the feature volume; errors in pose estimation or volume alignment will propagate directly to the network input [S1].

## Subtopics

### Image-Based NeRF Training
Trains a NeRF using RGB images as ground truth, optimizing both geometry and appearance [S3, unofficial]. It differs from the main setup by explicitly adding an Eikonal loss for geometry regularization alongside the color loss [S3, unofficial]. It uses the `get_nerf_datasets` utility for data loading and ray bundle construction [S3, unofficial]. Typical configuration involves 250 epochs on $128 \times 128$ images [S3, unofficial].

## Operating characteristics
*   **Hardware:** Tested on a single NVIDIA RTX A6000 GPU with 128 GB RAM [S2].
*   **Performance:** Utilizes NerfAcc and Instant-NGP for fast convergence [S2].
*   **Scalability:** Designed for static scenes; performance may degrade with high dynamic content [S2].
*   **Strengths:** Fast convergence, efficient use of pre-computed feature volumes, compatibility with Nerfstudio ecosystem [S1, S2].
*   **Limitations:** Requires pre-computed feature volumes and accurate camera poses; not inherently suited for highly dynamic scenes without modification [S1, S2].

## Background
Originated from the Control-NeRF paper, which introduced editable feature volumes for scene rendering [S1]. The training setup was adapted for laparoscopic surgical video rendering using the Nerfstudio library and Instant-NGP to handle static abdominal environments [S2]. The approach modifies the standard NeRF architecture by replacing positional encoding of 3D positions with sampled feature vectors [S1].
