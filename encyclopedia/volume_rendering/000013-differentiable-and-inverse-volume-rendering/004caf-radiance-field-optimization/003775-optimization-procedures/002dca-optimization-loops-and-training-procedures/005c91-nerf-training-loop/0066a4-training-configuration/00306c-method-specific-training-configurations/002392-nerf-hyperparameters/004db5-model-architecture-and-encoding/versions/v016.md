# Model Architecture and Encoding


## Overview
This family defines the neural network structures and coordinate encoding schemes used to map 3D spatial coordinates and viewing directions to radiance field properties (density, color, semantics). It addresses the problem of representing high-frequency geometric details and view-dependent appearance efficiently, balancing reconstruction quality, training speed, and memory footprint. It is distinguished from sibling methods by its specific architectural choices (e.g., MLP depth, grid resolution, tensor decomposition) and encoding strategies (e.g., integrated positional encoding, frequency modulation, binary constraints) rather than optimization hyperparameters or sampling pipelines.

## Shared principles
All methods in this family map a 3D point $\mathbf{x} \in \mathbb{R}^3$ and a viewing direction $\mathbf{d} \in S^2$ to output values such as volume density $\sigma \in \mathbb{R}_{\ge 0}$ and RGB color $\mathbf{c} \in [0, 1]^3$. The core mechanism involves two stages:
1.  **Encoding:** Transforming the raw input coordinates into a higher-dimensional feature space using positional encoding, hash grids, or tensor projections.
2.  **Decoding:** Passing the encoded features through a neural network (typically an MLP or tensor decomposition layer) to predict the radiance field values.

The specific choice of encoding determines the inductive bias (e.g., frequency sensitivity, locality) and the network architecture determines the capacity and computational cost.

## Subtopics

### [Depth-Guided NeRF Training Configuration](11916-depth-guided-nerf-training-configuration.md)
This configuration modifies the standard NeRF architecture by inserting dropout layers with probability $p=0.1$ after each of the first eight fully connected (FC) ReLU-activated layers that encode the positional encoding. It is distinguished from siblings by its specific use of Earth Mover’s Distance (EMD) for depth alignment and fixed dropout regularization on the encoder, rather than relying on semantic guidance or binary occupancy.

### [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md)
This configuration freezes the density parameters of the NeRF and utilizes a directional loss that enforces semantic alignment in the CLIP space rather than photometric fidelity. It distinguishes itself by optimizing only the color/feature fields to match text embeddings, using a patch-based rendering approach ($128 \times 128$) to manage memory.

### [Binary Radiance Fields](13622-binary-radiance-fields.md)
Binary Radiance Fields (BiRF) constrains feature encoding parameters in multi-resolution hash grids to binary values $\{-1, +1\}$, reducing storage to ~0.5 MB. It employs a 2D-3D hybrid architecture (one 3D voxel grid and three 2D plane grids) and uses a Straight-Through Estimator (STE) for binarization during training, unlike post-processing compression methods.

### [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md)
This architecture replaces standard positional encoding with **Integrated Positional Encoding (IPE)** to handle aliasing by integrating over conical frustums. It structures the model into a density network (8 layers, 256 width) and a color network (1 layer, 128 width) with specific skip connections and bias configurations, distinguishing it from grid-based methods by its reliance on dense MLPs.

### [SUDS](14964-suds.md)
SUDS factorizes the scene into three separate multi-resolution hash table structures: static, dynamic, and far-field. It enables scalability to large urban scenes by combining spatial partitioning with video-specific hash indexing, allowing it to handle ego-motion and multi-video captures without linear memory growth, unlike sibling methods relying on supervised bounding boxes.

### [CCNeRF](15008-ccnerf.md)
CCNeRF models the radiance field as a hybrid tensor rank decomposition (CP and Triple Plane), eliminating the need for neural networks during rendering. Unlike NeRF variants with shared MLP renderers, CCNeRF uses only tensor rank decomposition, allowing dynamic model size adjustment via rank truncation and composition via rank concatenation without retraining.

### [Rip-NeRF](15532-rip-nerf.md)
Rip-NeRF renders high-fidelity images by combining cone casting with an anisotropic 3D Gaussian representation encoded via Platonic Solid Projection and Ripmap Encoding. It differs from siblings like Zip-NeRF by replacing multi-sampling with compact, learnable Ripmap features on Platonic solid faces, enabling efficient anisotropic area-sampling.

### [UE4-NeRF](15539-ue4-nerf.md)
UE4-NeRF partitions the environment into sub-NeRFs represented as textured polygonal meshes (initialized as regular octahedra) and integrates them into the Unreal Engine 4 rasterization pipeline. It uses an Encoder-Decoder MLP (4-layer encoder, 3-layer decoder) implemented as an HLSL shader, achieving real-time performance via multi-resolution hash encoding and LOD hierarchy, unlike Block-NeRF's grid structure.

### [Generative Occupancy Fields (GOF)](15773-generative-occupancy-fields-gof.md)
GOF predicts alpha values interpreted as occupancy instead of volume densities, enabling surface-aware image synthesis via root-finding. It solves the problem of diffused surfaces in generative radiance fields by transitioning from cumulative volume rendering to surface-point rendering, unlike siblings that rely on density-based volume rendering.

### [Panoptic Radiance Field](15849-panoptic-radiance-field.md)
Panoptic Lifting learns a panoptic 3D volumetric representation using TensoRF for density/color and small MLPs for semantic/instance distributions. It differs from siblings by requiring only machine-generated 2D labels and explicitly modeling 3D-consistent instance identifiers via surrogate IDs, rather than manual ground truth or coarse meshes.

### [Frequency-Modulated Position Encoding](15897-frequency-modulated-position-encoding.md)
This encoding scheme maps 3D coordinates to feature vectors using sine and cosine basis functions with exponentially spaced frequencies, specifically tailored for point cloud rasterization. It distinguishes itself from standard NeRF encoding by narrowing the encoding interval and using specific frequency bands ($L=10$ for space, $L=2$ for direction) to compensate for sparsity.

### Triplane NeRF with Diffusion Prior
- **Definition:** The framework uses a triplane NeRF representation where scene codes are optimized jointly with a diffusion prior to handle sparse-view data and ensure end-to-end coherence [S1].
- **Parameters:** Prediction format uses v-parameterization $\hat{x} = \alpha(t)x(t) - \sigma(t)\hat{v}$ [S1]. Weighting function uses SNR-based weighting $w(t) = (\alpha(t)/\sigma(t))^{2\omega}$ [S1].
- **Layout:** Scene code $\xi_i \in \mathbb{R}^{3 \times 6 \times 128 \times 128}$ [S1]. Denoising network is a U-Net with 122M parameters [S1].

### EG3D Triplane Representation
- **Steps:** Render feature image $I_f \in \mathbb{R}^{32 \times 128 \times 128}$ and raw RGB image $I_{128} \in \mathbb{R}^{3 \times 128 \times 128}$ by accumulating points along rays [S2]. Extract dense depth map $I_D \in \mathbb{R}^{128 \times 128}$ [S2]. Feed $I_f$ and $I_{128}$ into a 2D super-resolution network to yield $I_{512} \in \mathbb{R}^{3 \times 512 \times 512}$ [S2].
- **Formula:** $\text{SuperRes}(I_f, I_{128}) = I_{512}$ [S2].
- **Parameters:** Image resolution 512x512 [S2].
- **Layout:** Triplane representation $T \in \mathbb{R}^{256 \times 256 \times 96}$, corresponding to 3 axis-aligned planes (xy, xz, yz), each with 32 channels and resolution 256x256 [S2].
- **Number:** Rendering speed 42 fps on RTX 3090 [S2].

### NeRF-W Hyperparameter Configuration
- **Parameters:** Base MLP: 8 layers of 512 hidden units. Static and Transient/Uncertainty MLPs: 4 layers of 128 hidden units each [S3]. Positional encoding frequencies: 15 for position, 4 for viewing direction [S3]. Sampling points: 512 per ray per model (coarse and fine) during training (1024 total), doubled to 2048 during evaluation [S3]. Appearance embedding dimension $n(a) = 48$. Transient object embedding dimension $n(\tau) = 16$ [S3]. L1 regularizer multiplier $\lambda_u = 0.01$. Minimum importance threshold $\beta_{min} = 0.03$ [S3]. Optimizer: Adam, batch size 2048, initial learning rate 0.001, decaying ten-fold every 150,000 iterations, over 300,000 iterations total [S3].
- **Number:** Hyperparameters were optimized for the Brandenburg Gate scene of the Phototourism dataset and reused for remaining scenes [S3].

### Explicit Mesh Reconstruction from Neural Fields
- **Definition:** An algorithm to extract an explicit 3D mesh representation from the implicit neural radiance field learned by CodeNeRF, allowing for 3D reconstruction from a single input image [S4].
- **Steps:** Feed the center coordinates of a $256^3$ voxel grid to the CodeNeRF MLP to obtain volume density values $\sigma$ [S4]. Apply the Marching Cubes algorithm to the volume density values $\sigma$ to find mesh vertices [S4]. Cast rays along the vertex normals of the generated mesh to associate colors to the vertices [S4].

### Efficient EndoNeRF scene representation
- **Definition:** A voxel-grids-based scene representation that replaces coordinate-based MLPs with explicit density and feature volume grids to accelerate optimization, combined with a canonical field and time-dependent deformation field for dynamic surgical scenes [S5].
- **Steps:** The dynamic scene at time $t$ is modeled by warping a canonical radiance field (represented by $\mathbf{V}_\sigma$ and $\mathbf{V}_a$) with a time-dependent deformation field [S5]. The deformation field is modeled using decomposed 4D motion fields and a 3-layer MLP that maps a spatial-temporal coordinate to a deformation offset [S5].

### NeRF-Liif
- **Definition:** A baseline method that super-resolves LR images using a pretrained LIIF (Local Implicit Image Function) model, which requires LR-HR pairs for training and introduces external data priors [S6].
- **Parameters:** Training data requirement: LR-HR pairs [S6].
- **Pitfalls:** On synthetic Blender dataset, LIIF may produce false predictions due to domain mismatch with its external training set [S6]. On real-world LLFF dataset, LIIF tends to be oversmooth and may predict false color or geometry [S6].
- **Numbers:** Blender ×2 (100x100): PSNR 27.07, SSIM 0.919, LPIPS 0.067. Blender ×4 (100x100): PSNR 25.36, SSIM 0.885, LPIPS 0.125. Blender ×2 (200x200): PSNR 28.81, SSIM 0.934, LPIPS 0.058. Blender ×4 (200x200): PSNR 27.34, SSIM 0.912, LPIPS 0.096. LLFF ×2: PSNR 26.81, SSIM 0.823, LPIPS 0.145. LLFF ×4: PSNR 24.76, SSIM 0.723, LPIPS 0.292 [S6].

### UniSurf
- **Definition:** A method unifying volume rendering (radiance fields) and surface rendering (implicit surfaces) to achieve high-quality geometry and sharp textures without mask supervision [S7, unofficial].
- **Steps:** Uses an occupancy field where the occupancy at the $i^{th}$ sample corresponds to an indicator of surface presence [S7, unofficial]. Uses volume rendering in the early stage for optimization without mask supervision [S7, unofficial]. Uses surface rendering in the later stage to extract level-set surfaces [S7, unofficial].
- **Comparison:** Unlike pure surface rendering which requires mask supervision and has blurry texture mapping, this method provides high-quality novel views and sharp textures/colors without mask supervision [S7, unofficial].

## Background
The foundational NeRF architecture [15] introduced the use of a dense MLP with positional encoding to map coordinates to density and color. Subsequent works have diversified this approach to address specific challenges:
*   **Efficiency:** Instant-NGP [19] and BiRF [S1] introduced hash grids and binary constraints to reduce memory and increase training speed.
*   **Quality/Aliasing:** Mip-NeRF [14098] introduced integrated positional encoding to handle spatial extent.
*   **Generative/Text:** CLIPNeRF [12073] and Diffusion NeRF [S1] integrated external priors (CLIP, Diffusion) into the architecture or training loop.
*   **Dynamic/Large Scale:** SUDS [14964] and UE4-NeRF [15539] adapted architectures for large-scale dynamic scenes and real-time rendering.
*   **Surface/Geometry:** GOF [15773] and UniSurf [S7, unofficial] shifted focus from density to occupancy/surface representations.
*   **Semantic/Panoptic:** Panoptic Radiance Field [15849] added semantic and instance heads to the radiance field structure.
