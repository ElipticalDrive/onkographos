# Generative Occupancy Fields (GOF)

## Overview
Generative Occupancy Fields (GOF) is a 3D-aware image synthesis method that learns compact object surfaces by transitioning from cumulative volumetric rendering to surface-point rendering [S1, unofficial]. Unlike standard radiance fields that produce diffused surfaces due to shape-color ambiguity, GOF reinterprets alpha values as occupancy probabilities to locate surfaces via root-finding, enabling the gradual shrinking of the sampling region to ensure surface compactness without impeding training convergence [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A latent code $z \sim p_z$ (typically truncated for inference), a camera pose $\xi \sim p_\xi$, and a viewing direction $\mathbf{d}$.
*   **Outputs:** A synthesized 2D image $\tilde{C}(r, z)$ for ray $r$ defined by origin $o$ and direction $\mathbf{d}$.

**Data Structures:**
*   **Generator Network ($G_\theta$):** A FiLMed-SIREN backbone [S1, unofficial] that takes spatial coordinate $\mathbf{x}$, direction $\mathbf{d}$, and latent code $z$ as input. It outputs a scalar alpha value $\alpha_\theta(\mathbf{x}, z) \in [0, 1]$ and a color vector $\mathbf{c}_\theta(\mathbf{x}, \mathbf{d}, z) \in \mathbb{R}^3$.
*   **Discriminator Network ($D_\phi$):** Standard GAN discriminator taking 2D images as input.
*   **Parameters:**
    *   $N$: Number of rendering samples. Typical value: 12 [S1, unofficial].
    *   $M$: Number of root-finding bins. Typical value: 12 [S1, unofficial].
    *   $m_s$: Number of secant iterations. Typical value: 3 [S1, unofficial].
    *   $\tau$: Threshold for root-finding. Typical value: 0.5 [S1, unofficial].
    *   $\Delta_{init}$: Initial sampling interval, set to $(t_f - t_n)/2$ [S1, unofficial].
    *   $\Delta_{min}$: Minimal sampling interval (pre-defined) [S1, unofficial].
    *   $\gamma$: Decay rate for shrinking interval [S1, unofficial].

**Formulas:**
1.  **Alpha Value:** The network predicts $\alpha_\theta(\mathbf{x}_i, z)$ directly, which corresponds to the occupancy probability for a segment of length $\delta_i$:
    $$ \alpha_\theta(\mathbf{x}_i, z) = 1 - \exp(-\sigma_\theta(\mathbf{x}_i, z)\delta_i) $$
    where $\sigma_\theta$ is the implicit volume density [S1, unofficial].

2.  **Rendering (Cumulative):** The color $\tilde{C}(r, z)$ is computed via alpha composition:
    $$ \tilde{C}(r, z) = \sum_{i=1}^{N} \alpha_\theta(\mathbf{x}_i, z) \left( \prod_{j<i} (1 - \alpha_\theta(\mathbf{x}_j, z)) \right) \mathbf{c}_\theta(\mathbf{x}_i, \mathbf{d}, z) $$
    where $\mathbf{x}_i$ are points sampled along the ray [S1, unofficial].

3.  **Surface Location (Root-Finding):**
    *   Sample $M$ evenly-spaced points $\mathbf{x}_k$ partitioning the volume $[t_n, t_f]$.
    *   Find the bin $k_S$ where alpha crosses threshold $\tau$:
        $$ k_S = \arg\min_k (\alpha_\theta(\mathbf{x}_k, z) < \tau \le \alpha_\theta(\mathbf{x}_{k+1}, z)) $$
    *   Apply the secant method iteratively $m_s$ times to find the precise surface point $\mathbf{x}_s$ [S1, unofficial].

4.  **Shrinking Sampling Region:**
    *   At training step $n$, compute the interval width:
        $$ \Delta_n = \max(\Delta_{init} \exp(-\gamma n), \Delta_{min}) $$
    *   Sample $N$ points uniformly in $[\mathbf{x}_s - \Delta_n, \mathbf{x}_s + \Delta_n]$ [S1, unofficial].

5.  **Loss Functions:**
    *   **GAN Loss:**
        $$ L_{origin}(\theta_D, \theta_G) = \mathbb{E}_{z \sim p_z, \xi \sim p_\xi} f(D_{\theta_D}(G_{\theta_G}(z, \xi))) + \mathbb{E}_{I \sim p_D} f(-D_{\theta_D}(I)) + \lambda ||\nabla_{D_{\theta_D}}(I)||_2^2 $$
        where $f(u) = -\log(1 + \exp(-u))$ [S1, unofficial].
    *   **Opacity Regularization:** Reduces entropy of alpha values:
        $$ L_{opacity} = \frac{1}{N} \sum_{i=1}^{N} \log(\alpha_\theta(\mathbf{x}_i, z)) + \log(1 - \alpha_\theta(\mathbf{x}_i, z)) $$
    *   **Normal Regularization:** Encourages surface smoothness (applied to surface points $\mathbf{x}_s \in S$):
        $$ L_{normal} = \sum_{\mathbf{x}_s \in S} ||\mathbf{n}_\theta(\mathbf{x}_s, z) - \mathbf{n}_\theta(\mathbf{x}_s + \epsilon, z)||_2 $$
    *   **Total Loss:**
        $$ L(\theta, \phi) = L_{origin}(\theta, \phi) + \lambda_{normal} L_{normal} + \lambda_{opacity} L_{opacity} $$

**Pseudocode:**

def train_gof(generator, discriminator, dataset, config):
    """
    Trains the GOF model.
    config contains: N, M, ms, tau, gamma, delta_min, lambda_normal, lambda_opacity.
    """
    delta_init = (config.t_far - config.t_near) / 2.0
    step = 0
    
    for epoch in epochs:
        for batch in dataset:
            # 1. Sample latent codes and camera poses
            z = sample_latent(config.p_z)
            xi = sample_pose(config.p_xi)
            
            # 2. Root-finding to locate surface
            # Sample M points along the ray r defined by xi
            x_bins = sample_evenly_spaced_points(config.t_near, config.t_far, M)
            alphas = generator.query_alpha(x_bins, z)
            
            # Find bin where alpha crosses threshold tau
            k_S = find_crossing_bin(alphas, config.tau)
            
            # Refine surface point using secant method
            x_s = secant_refinement(x_bins[k_S], x_bins[k_S+1], generator, z, config.tau, config.ms)
            
            # 3. Shrinking sampling region
            # Compute current delta
            delta_n = max(delta_init * exp(-config.gamma * step), config.delta_min)
            
            # Sample N points in the shrinking region around x_s
            # Note: x_s is a point on the ray. We need to map this to ray coordinates.
            # Assuming x_s is the distance t_s along the ray:
            t_s = distance_from_origin(x_s, xi.origin, xi.direction)
            
            t_start = t_s - delta_n
            t_end = t_s + delta_n
            
            # Clamp to near/far bounds
            t_start = max(t_start, config.t_near)
            t_end = min(t_end, config.t_far)
            
            x_render = sample_uniform_points(t_start, t_end, N)
            
            # 4. Render image
            # Query alpha and color for rendering points
            alphas_r = generator.query_alpha(x_render, z)
            colors = generator.query_color(x_render, xi.direction, z)
            
            # Alpha composition
            T = 1.0
            C_rendered = zeros(3)
            for i in range(N):
                alpha = alphas_r[i]
                color = colors[i]
                # T_i = product(1 - alpha_j) for j < i
                C_rendered += T * alpha * color
                T *= (1 - alpha)
            
            # 5. Compute Losses
            # GAN Loss
            L_origin = compute_gan_loss(discriminator, C_rendered, batch.real_image, config.lambda_grad)
            
            # Opacity Loss
            L_opacity = mean(log(alphas_r) + log(1 - alphas_r))
            
            # Normal Loss (requires gradient of alpha or color w.r.t x to estimate normal)
            # Implemented via finite differences or automatic differentiation on surface points
            L_normal = compute_normal_smoothness(generator, x_s, z)
            
            L_total = L_origin + config.lambda_normal * L_normal + config.lambda_opacity * L_opacity
            
            # 6. Update networks
            update_generator(generator, L_total)
            update_discriminator(discriminator, L_origin)
            
            step += 1

def infer_gof(generator, z, xi, config):

    Can use cumulative rendering or single surface point rendering.

**Edge Cases and Pitfalls:**
*   **Shape-Color Ambiguity:** Direct training of generative radiance fields fails to maintain surface compactness because small perturbations on surfaces still lead to realistic RGB images, fooling the discriminator [S1, unofficial]. GOF mitigates this by shrinking the sampling region.
*   **Gradient Sparsity:** Directly applying occupancy representations causes severe convergence problems due to sparse gradients located only on surfaces. GOF avoids this by starting with cumulative rendering (dense gradients) and transitioning [S1, unofficial].
*   **Density Thresholding:** Predicted densities in generative radiance fields range from 0 to 50, making thresholding difficult. GOF uses alpha values (range [0,1]) for root-finding, which is more stable [S1, unofficial].
*   **Inference Speed:** Standard rendering requires $M + m_s + N$ queries. Single-point rendering requires $M + m_s + 1$ queries [S1, unofficial].

## Operating characteristics
*   **Complexity:** GOF requires $M + m_s + N$ network queries for standard rendering, or $M + m_s + 1$ for single-point surface rendering. Baselines (e.g., pi-GAN) typically require $2N$ queries due to hierarchical sampling [S1, unofficial].
*   **Performance:** GOF outperforms baselines on MAD (Mean Angle Deviation, measuring compactness) and is comparable on SIDE (Scale-Invariant Depth Error, measuring depth accuracy) [S1, unofficial].
*   **Strengths:** Produces compact and smooth surfaces; alleviates the burden of sampling many points during inference; combines the training stability of radiance fields with the surface precision of occupancy networks.
*   **Limitations:** Single-point rendering may make textured objects (e.g., furry cats) appear over-smooth; best suited for solid objects with a single surface [S1, unofficial].
*   **Hardware/Resolution:** Tested on CelebA, BFM, and Cats datasets [S1, unofficial]. Specific hardware metrics are not provided in the source.

## Background
*   **Origin:** Proposed by Xudong Xu, Xingang Pan, Dahua Lin, and Bo Dai in 2021 [S1, unofficial].
*   **History:** GOF addresses the limitations of prior generative radiance fields like pi-GAN, which suffer from diffused surfaces, and occupancy networks, which suffer from convergence issues in generative settings. It bridges the gap by reinterpreting alpha values as occupancy [S1, unofficial].
*   **Usage:** Used for 3D-aware image synthesis on datasets such as CelebA, BFM, and Cats [S1, unofficial].
