# Training Setup and Baselines


## Overview
This family defines the configuration, hyperparameters, and baseline methodologies for optimizing radiance fields and related neural volume representations. It establishes reference points for performance comparison, including ground-truth HDR baselines, generative 3D-aware models, and meta-learning approaches. It differs from sibling articles by focusing on the specific architectural adaptations, data handling strategies, and hyperparameter schedules required to train these distinct model families, rather than the general loop mechanics or optimization algorithms themselves.

## Shared principles
The training setups across these baselines share a common reliance on differentiable volume rendering to compute photometric losses between rendered views and ground-truth images. They all utilize gradient-based optimization (typically Adam) to update network parameters. A key shared principle is the adaptation of standard 2D or generic 3D training pipelines to handle the specific constraints of volumetric data, such as ray sampling, density prediction, and handling of sparse or hierarchical data structures.

## Subtopics

### [NeRF-GT Baseline Training Setup](11349-nerf-gt-baseline-training-setup.md)
A reference upper bound for novel view synthesis that trains a standard NeRF on high-dynamic-range (HDR) ground truth data [11349-nerf-gt-baseline-training-setup]. It differs from standard NeRF by using HDR inputs to mitigate information loss from low-dynamic-range (LDR) captures, serving as a performance ceiling for methods recovering HDR from LDR [11349-nerf-gt-baseline-training-setup]. It uses 64 coarse and 128 fine samples per ray, a batch size of 2,048 rays, and 200,000 iterations at 800×600 resolution [11349-nerf-gt-baseline-training-setup]. A key pitfall is that training directly on HDR views may fail to encode all scene areas well, even with tone-mapped loss calculation [11349-nerf-gt-baseline-training-setup].

### [StyleGAN2 Training Configuration](12972-stylegan2-training-configuration.md)
A reproducible baseline for 3D-aware generative models using StyleGAN2, adapted for volume rendering contexts like sparse voxel grids [12972-stylegan2-training-configuration]. It differs from standard StyleGAN2 by omitting path regularization and style-mixing to reduce overhead, while introducing R1 regularization (every 4 minibatches, $\gamma=1$) and mixed precision (FP16) for stability and efficiency [12972-stylegan2-training-configuration]. It uses equalized learning rates, a minibatch standard deviation layer in the discriminator, and EMA weight updates [12972-stylegan2-training-configuration]. For small datasets (e.g., AFHQ), it requires fine-tuning from an FFHQ-pretrained generator with specific resolution parameters [12972-stylegan2-training-configuration].

### [NeRF Training Setup](13271-nerf-training-setup.md)
A configuration for NeRF-based models using Nerfstudio, NerfAcc, and Instant-NGP for fast convergence on static scenes [13271-nerf-training-setup]. It differs from standard NeRF by replacing positional encoding of 3D positions with a pre-sampled 64-dimensional feature vector from a volumetric feature field $V_s$, omitting positional encoding on this vector itself [13271-nerf-training-setup]. It uses 1024 rays per batch at 504×378 resolution, with 64 coarse and 64 fine samples [13271-nerf-training-setup]. Direction vectors are encoded with positional encoding depth $L=4$ [13271-nerf-training-setup]. It is designed for static scenes with minimal moving elements [13271-nerf-training-setup].

### [NLR Baseline](15254-nlr-baseline.md)
A differentiable volume rendering method using a neural lumigraph with per-view feature embeddings and a shared MLP to predict radiance and density [15254-nlr-baseline]. It differs from standard NeRF by relying on view-dependent embeddings and having significantly higher per-iteration cost, offset by faster convergence in meta-learning settings [15254-nlr-baseline]. It uses a meta-learning rate of $5 \times 10^{-2}$, 800×600 resolution, and Reptile for meta-updates [15254-nlr-baseline]. It assumes accurate camera poses and masks, as inaccuracies can limit performance [15254-nlr-baseline].

### NeuralVDB Hyperparameter Configuration
A training setup for hierarchical neural networks on sparse VDB volumes [S1, unofficial]. It differs by using subdomain sizes (multiples of 512) to balance empty space waste and dispatch overhead [S1, unofficial]. It uses Adam with LR 0.001, decaying by 0.975 every 100 epochs (no resampling) or 0.75 every 1,000 epochs (with resampling) [S1, unofficial]. Level-1 networks have half the width of level-0 (default 128, depth 3) [S1, unofficial]. Sampling is either $2^{16}$ random samples per epoch or resampling a subset ($100/500 \times$ batch size) with $2^{12}$ batches per epoch for fine details [S1, unofficial]. Sparse VDB with active masks yields the best visual quality, reducing noise compared to dense or block grids [S1, unofficial].

### Neural Codebook Training Configuration
A training setup for Neural Codebooks (NCB) for compact radiance fields [S2]. It uses Adam ($\beta_1=0.9, \beta_2=0.999$) with weight decay $1e-5$, initial LR $5e-3$ decaying by 0.3 every 5,000 iterations, for 20,000 iterations with a batch size of 100,000 voxels [S2]. The trained NCB is cast to float16 for testing and storage [S2].

## Background
The NeRF-GT baseline originates from efforts to establish performance ceilings for HDR novel view synthesis [11349-nerf-gt-baseline-training-setup]. The StyleGAN2 configuration adapts the 2019 StyleGAN2 architecture [12972-stylegan2-training-configuration] for 3D-aware synthesis. The NeRF Training Setup leverages modern libraries like Nerfstudio and NerfAcc for efficient static scene reconstruction [13271-nerf-training-setup]. The NLR baseline is used in meta-learning comparisons for novel view synthesis [15254-nlr-baseline]. NeuralVDB and Neural Codebook configurations are derived from specific research on sparse volume representations and compact radiance fields [S1, unofficial][S2].
