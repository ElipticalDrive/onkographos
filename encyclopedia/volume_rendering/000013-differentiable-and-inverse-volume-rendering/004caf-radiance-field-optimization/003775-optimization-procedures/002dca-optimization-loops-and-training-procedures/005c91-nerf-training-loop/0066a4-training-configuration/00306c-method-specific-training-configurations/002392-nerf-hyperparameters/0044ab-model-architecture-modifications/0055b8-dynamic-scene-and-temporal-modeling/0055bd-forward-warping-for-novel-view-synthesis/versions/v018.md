# Forward Warping for Novel View Synthesis

Also called: Canonical Field Forward Warping, Forward Flow

## Overview
Forward Warping for Novel View Synthesis is a method for rendering dynamic scenes by modeling a static scene at a canonical time step and forward warping the entire canonical radiance field to other time steps [S1]. It addresses the many-to-one and one-to-many mapping difficulties inherent in dynamic scene reconstruction by employing differentiable forward warping with average splatting and an inpaint network [S1]. Unlike backward flow methods such as NDVG, this approach leverages a smooth trajectory field to achieve superior performance, particularly for canonical frames [S1].

## How it works
The method uses a coarse-to-fine training strategy to learn a canonical radiance field and a deformation field, then warps the canonical field to target times for rendering [S1].

### Inputs and Outputs
*   **Inputs:** A set of images $\{I_t\}$ with known camera poses and timestamps $t$. The canonical time $t_{can}$ is selected (first frame for D-NeRF, middle frame for HyperNeRF) [S1].
*   **Outputs:** Rendered images $C(\mathbf{r}, t)$ for novel views and intermediate times [S1].

### Data Structures
The method maintains several voxel grids and neural networks [S1]:

1.  **Canonical Radiance Feature Grid ($VRf$):** Voxel grid containing radiance features. Feature dimension is 12 [S1].
2.  **Canonical Coordinate Grid ($VrCan$):** Voxel grid containing the coordinate of each voxel [S1].
3.  **Canonical Density Grid ($V\sigma^{Can}$):** Voxel grid containing canonical density [S1].
4.  **Canonical Color Feature Grid ($Vcf^{Can}$):** Voxel grid containing canonical color features. Dimension is 3 or 12 depending on the training stage [S1].
5.  **Canonical Deformation Feature Grid ($VDf^{Can}$):** Voxel grid containing canonical deformation features. Dimension is 0 for D-NeRF, 12 for HyperNeRF [S1].
6.  **Trajectory Grid ($VT^t$):** Voxel grid containing DCT parameters of each voxel's trajectory [S1].
7.  **Deformation Flow Grid ($Vflow$):** Voxel grid containing deformation flow of each voxel from canonical to time $t$ [S1].
8.  **Warped Radiance Field ($VR^t$):** Radiance field at time $t$ warped from $VR^{Can}$ [S1].
9.  **Inpainted Radiance Field ($VR^{t}_{Inp}$):** Radiance field at time $t$ after inpainting by $F_{\theta3}$ [S1].
10. **Upsampled Radiance Field ($VR^{t}_{Up}$):** Upsampled radiance field at time $t$ [S1].

### Networks
1.  **Canonical Radiance Network ($F_{\theta1}$):**
    *   **Structure:** 3-layer MLP, width 128, ReLU activation [S1].
    *   **Input:** Radiance feature from $VRf$ (dim 12) and embedded position (dim 33) [S1].
    *   **Output:** Density (dim 1) and color feature (dim 3 or 12) [S1].
2.  **Canonical Deformation Network ($F_{\theta2}$):**
    *   **Structure:** 4-layer MLP, width 64 [S1].
    *   **Input:** Deformation feature (dim 0 or 12) and embedded position (dim 33) [S1].
    *   **Output:** Trajectory parameters (DCT coefficients) [S1].
3.  **View Dependent Color Network ($F_{\theta4}$):**
    *   **Structure:** 2-layer MLP, width 64 [S1].
    *   **Input:** Embedded view direction (dim 27) and color feature (dim 12) [S1].
    *   **Output:** RGB color (dim 3) [S1].
4.  **Inpaint Network ($F_{\theta3}$):**
    *   **Structure:** UNet with 4 encode layers and 3 decode layers, plus an upsample layer [S1]. Each encode layer has one max pooling layer and two convolution layers (Instance Norm + Conv + ReLU). Each decode layer has one up-sample interpolation layer and two convolution layers (Instance Norm + Conv + ReLU) [S1].
    *   **Input:** Warped radiance field features [S1].
    *   **Output:** Inpainted radiance field features [S1].

### Number of DCT Bases
*   D-NeRF: 15 [S1].
*   HyperNeRF: 25 [S1].

### Loss Functions

1.  **Point-wise Color Loss ($\mathcal{L}_{ptc}$):**
    Supervises the color of sampled points weighted by their accumulation [S1].
    $$
    \mathcal{L}_{ptc} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Up}}(\mathbf{r}))
    $$
    where
    $$
    \mathcal{L}(\mathbf{C}(\mathbf{r})) = \frac{1}{K} \sum_{k=1}^{K} A_{\text{accum}}(k) \|\mathbf{c}(w_k) - \mathbf{C}_{\text{gt}}(\mathbf{r})\|_2^2
    $$
    and
    $$
    A_{\text{accum}}(k) = T(w_k) \, \sigma(w_k) \delta_k
    $$
    $\mathbf{C}_{\text{Inp}}$ and $\mathbf{C}_{\text{Up}}$ are colors from inpainted and upsampled fields [S1].

2.  **Background Entropy Loss ($\mathcal{L}_{bg}$):**
    Encourages densities to concentrate on foreground or background [S1].
    $$
    \mathcal{L}_{bg} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Up}}(\mathbf{r}))
    $$
    where
    $$
    \mathcal{L}(\mathbf{A}(\mathbf{r})) = -\frac{1}{K-1} \sum_{k=1}^{K-1} [ A_{\text{accum}}(k)\log(A_{\text{accum}}(k)) + (1-A_{\text{accum}}(k))\log(1-A_{\text{accum}}(k)) ]
    $$
    [S1].

3.  **Total Loss:**
    $$
    \mathcal{L} = \mathcal{L}_{photo} + w_1\mathcal{L}_{ptc} + w_2\mathcal{L}_{bg} + w_3\mathcal{L}_{flow} + w_4\mathcal{L}_{vdiff} + w_5\mathcal{L}_{tv}(\mathbf{V}_{\sigma}^{\text{Can}}) + w_6\mathcal{L}_{tv}(\mathbf{V}_{\text{flow}}^t) + w_7\mathcal{L}_{tv}(\mathbf{D})
    $$
    where $w_1..w_7$ are balancing weights [S1].

### Edge Cases and Pitfalls
*   **Memory Consumption:** High, especially for real scenes [S1].
*   **Training Speed:** Slow, approximately one day per scene on GeForce RTX 3090 [S1].
*   **Coarse Stage Importance:** Removing the coarse stage causes significant performance drop because the voxel grid covers bigger space without proxy geometry filtering [S1].
*   **Inpaint Network Importance:** Removing the inpaint network significantly reduces performance (e.g., Hell Warrior PSNR drops from 27.71 to 27.15) [S1].
*   **Splatting Choice:** Average splatting is used instead of softmax splatting. Softmax splatting with predicted weights showed no obvious improvement and introduced too much complexity [S1].

## Operating characteristics
*   **Time Complexity:** Training is slow, taking approximately one day per scene on a GeForce RTX 3090 GPU [S1].
*   **Memory Complexity:** High memory consumption, particularly for real scenes [S1].
*   **Model Size:** 260M parameters for D-NeRF, 440M for HyperNeRF [S1].
*   **Rendering Speed:** 7s per image for D-NeRF, 15s per image for HyperNeRF [S1].
*   **Strengths:** Achieves SOTA performance on public datasets, especially for canonical frames. Clear advantage over backward flow based methods like NDVG [S1].
*   **Limitations:** High memory usage and slow training speed [S1].

## Background
Forward Warping for Novel View Synthesis was proposed in the paper "Forward Flow for Novel View Synthesis of Dynamic Scenes" [S1]. The method builds on the idea of canonical representations but introduces forward warping with average splatting and an inpaint network to handle dynamic scenes. It was evaluated on the D-NeRF and HyperNeRF datasets, as well as a newly built Lego Complete Dataset [S1].
