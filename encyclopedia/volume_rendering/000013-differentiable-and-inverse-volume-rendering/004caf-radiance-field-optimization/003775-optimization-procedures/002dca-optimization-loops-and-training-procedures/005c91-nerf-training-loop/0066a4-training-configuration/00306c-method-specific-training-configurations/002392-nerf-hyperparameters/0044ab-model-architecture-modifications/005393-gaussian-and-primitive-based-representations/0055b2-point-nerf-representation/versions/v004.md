# Point-NeRF Representation

Also called: Neural point cloud, Point-based radiance field

## Overview
Point-NeRF replaces the global implicit function of NeRF with a discrete neural point cloud to model a continuous volumetric radiance field, avoiding ray sampling in empty space by leveraging classical point clouds that approximate scene geometry [S1]. It differs from Gaussian Splatting by using inverse-distance weighted aggregation of local feature vectors rather than projecting 2D Gaussians, and from Differentiable Primitive Assembly by regressing radiance from point neighborhoods rather than evaluating implicit signed distance functions [S1, 13657-differentiable-primitive-assembly.md, 14273-viewing-direction-gaussian-splatting.md].

## How it works
**Inputs:** A set of $N$ neural points $\mathcal{P}$, a camera ray defined by origin $\mathbf{o}$ and direction $\mathbf{d}$, and rendering parameters including the number of shading samples $M$ and search radius $R$.
**Outputs:** Pixel radiance $c$.

**Data Structures:**
The neural point cloud is defined as $\mathcal{P} = \{(\mathbf{p}_i, \mathbf{f}_i, \gamma_i) \mid i = 1, \dots, N\}$, where:
*   $\mathbf{p}_i \in \mathbb{R}^3$: 3D location of point $i$.
*   $\mathbf{f}_i \in \mathbb{R}^D$: Neural feature vector encoding local scene content.
*   $\gamma_i \in [0, 1]$: Scale confidence value representing the likelihood of the point being near an actual scene surface [S1].

**Algorithm:**
1.  **Ray Marching:** Sample $M$ shading points $\{\mathbf{x}_j \mid j = 1, \dots, M\}$ along the ray. Calculate distance $\Delta_j$ between adjacent samples [S1].
2.  **Neighborhood Query:** For each shading point $\mathbf{x}_j$, query $K$ neighboring neural points within radius $R$ [S1].
3.  **Per-Point Processing:** For each neighbor $i$, compute relative position $\mathbf{x}_j - \mathbf{p}_i$ and process via MLP $F$ to predict a local feature vector $\mathbf{f}_{i,j}$:
    $$ \mathbf{f}_{i,j} = F(\mathbf{f}_i, \mathbf{x}_j - \mathbf{p}_i) $$
    This makes the network invariant to point translation [S1].
4.  **Feature Aggregation:** Aggregate the $K$ processed features using inverse distance weighting, weighted by confidence $\gamma_i$:
    $$ w_i = \frac{1}{\|\mathbf{p}_i - \mathbf{x}_j\|} $$
    $$ \mathbf{f}_j = \sum_{i=1}^{K} \gamma_i \frac{w_i}{\sum_{k=1}^{K} w_k} \mathbf{f}_{i,j} $$
    [S1].
5.  **Radiance Regression:** Regress view-dependent radiance $\mathbf{r}_j$ from the aggregated feature $\mathbf{f}_j$ and viewing direction $\mathbf{d}$ using MLP $R$:
    $$ \mathbf{r}_j = R(\mathbf{f}_j, \mathbf{d}) $$
    [S1].
6.  **Density Regression:** Regress volume density $\sigma_j$ at $\mathbf{x}_j$. (Note: Source [S1] defines the regression function as returning $(\sigma, r)$ but only provides the formula for $r$. The density $\sigma$ is typically derived from the same or a parallel network output [S1]).
7.  **Volume Rendering:** Accumulate radiance using the standard volume rendering equation:
    $$ c = \sum_{j=1}^{M} \tau_j (1 - \exp(-\sigma_j \Delta_j)) \mathbf{r}_j $$
    $$ \tau_j = \exp\left(-\sum_{t=1}^{j-1} \sigma_t \Delta_t\right) $$
    [S1].

**Pseudocode:**
```python
def point_nerf_render(ray_origin, ray_direction, neural_points, mlp_F, mlp_R, mlp_Sigma, M, R_search):
    """
    ray_origin: (3,)
    ray_direction: (3,)
    neural_points: List of tuples (p, f, gamma)
    mlp_F: MLP processing local features
    mlp_R: MLP regressing radiance
    mlp_Sigma: MLP regressing density
    M: Number of shading samples
    R_search: Query radius
    """
    # 1. Sample points along ray
    # Assuming uniform sampling or similar strategy not detailed in source [S1]
    # Placeholder for specific sampling strategy [G]
    shading_points = sample_along_ray(ray_origin, ray_direction, M)
    
    pixel_radiance = 0.0
    transmittance = 1.0
    
    for j, x_j in enumerate(shading_points):
        # 2. Query neighbors
        neighbors = query_neighbors(x_j, neural_points, R_search)
        
        if not neighbors:
            sigma_j = 0.0
            r_j = [0.0, 0.0, 0.0]
        else:
            # 3. Per-point processing
            local_features = []
            weights = []
            for p_i, f_i, gamma_i in neighbors:
                # Relative position
                rel_pos = x_j - p_i
                # Process with MLP F
                f_i_x = mlp_F(f_i, rel_pos)
                local_features.append(f_i_x)
                # Inverse distance weight
                w_i = 1.0 / norm(p_i - x_j)
                weights.append(w_i)
            
            # 4. Aggregate features
            sum_weights = sum(weights)
            f_j = [0.0] * len(local_features[0])
            for i, (f_i_x, w_i, gamma_i) in enumerate(zip(local_features, weights, [n[2] for n in neighbors])):
                weight_factor = gamma_i * (w_i / sum_weights)
                for k in range(len(f_j)):
                    f_j[k] += weight_factor * f_i_x[k]
            
            # 5. Regress radiance
            r_j = mlp_R(f_j, ray_direction)
            
            # 6. Regress density (Formula not explicitly given in source, assumed from same context [S1])
            sigma_j = mlp_Sigma(f_j) # [G] Assumption based on regression function definition
        
        # 7. Volume rendering accumulation
        delta_j = distance(shading_points[j], shading_points[j-1]) if j > 0 else 0.0 # [G] Edge case for first point
        
        alpha = 1.0 - exp(-sigma_j * delta_j)
        contribution = transmittance * alpha * r_j
        pixel_radiance += contribution
        transmittance *= (1.0 - alpha)
        
    return pixel_radiance
```

**Parameters:**
*   $K$: Number of neighbors. Not given in the sources.
*   $R$: Search radius. Not given in the sources.
*   $M$: Number of shading samples. Not given in the sources.
*   $D$: Dimension of feature vector $\mathbf{f}_i$. Not given in the sources.

## Operating characteristics
*   **Time Complexity:** Depends on $K$ (neighborhood size) and MLP depth. Faster than NeRF as it avoids sampling empty space [S1].
*   **Memory Complexity:** Proportional to $N$ (number of points) and feature dimension $D$.
*   **Strengths:** Efficient representation leveraging classical point clouds; faster optimization per scene (tens of minutes) compared to NeRF [S1].
*   **Limitations:** Quality depends on the initial point cloud quality; holes and outliers in the initial reconstruction require pruning and growing [S1].
*   **When to use:** When fast per-scene optimization is required and a good initial point cloud (e.g., from COLMAP) is available [S1].

## Background
Point-NeRF was introduced by Qiangeng Xu, Zexiang Xu, Julien Philip, Sai Bi, Zhixin Shu, Kalyan Sunkavalli, and Ulrich Neumann in 2022 [S1]. It builds on the idea of using neural point clouds to represent radiance fields, aiming to improve upon the slow optimization of NeRF by utilizing discrete geometric priors [S1].
