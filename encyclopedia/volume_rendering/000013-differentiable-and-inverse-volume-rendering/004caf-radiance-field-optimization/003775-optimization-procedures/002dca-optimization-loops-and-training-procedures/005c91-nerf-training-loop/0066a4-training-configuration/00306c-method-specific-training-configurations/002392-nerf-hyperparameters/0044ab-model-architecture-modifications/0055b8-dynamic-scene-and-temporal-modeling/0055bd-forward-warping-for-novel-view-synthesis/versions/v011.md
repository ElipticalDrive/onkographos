# Forward Warping for Novel View Synthesis

Also called: Canonical Field Forward Warping, Forward Flow

## Overview
Forward Warping for Novel View Synthesis is a method for rendering dynamic scenes by modeling a static "canonical" radiance field and differentially warping this field to target time steps [S1]. It solves the many-to-one and one-to-many mapping ambiguities inherent in dynamic scene reconstruction by using average splatting for forward warping and an inpaint network to fill occluded regions [S1]. Unlike backward-flow methods such as NDVG, it maintains a clear advantage in rendering quality, particularly for canonical frames, by explicitly predicting deformation flows from a static reference [S1].

## How it works
The method employs a coarse-to-fine training strategy. The canonical field is defined at a specific time step (first frame for D-NeRF, middle frame for HyperNeRF) [S1]. The pipeline consists of voxel grids for features, MLPs for local predictions, and a UNet-based inpaint network [S1].

### Inputs and Outputs
*   **Inputs:** Training images with known camera poses and time steps $t$; canonical time $t_{can}$.
*   **Outputs:** Rendered RGB images for arbitrary views and time steps; deformation flow fields.

### Data Structures
The method relies on several voxel grids and MLPs. All voxel grids are 3D structures indexed by spatial coordinates.

1.  **Canonical Radiance Feature Grid ($VR_f$):** Stores radiance features. Dimension: 12.
2.  **Canonical Coordinate Grid ($VR_{Can}$):** Stores the 3D coordinate of each voxel center.
3.  **Canonical Density Grid ($V_{\sigma}^{Can}$):** Stores volume density $\sigma$.
4.  **Canonical Color Feature Grid ($V_{cf}^{Can}$):** Stores color features. Dimension: 3 (coarse stage) or 12 (fine stage).
5.  **Canonical Deformation Feature Grid ($VD_f^{Can}$):** Stores deformation features. Dimension: 0 for D-NeRF, 12 for HyperNeRF.
6.  **Trajectory Grid ($VT_t$):** Stores DCT parameters for trajectory modeling.
7.  **Deformation Flow Grid ($V_{flow}$):** Stores the deformation flow vector from canonical position to position at time $t$.
8.  **Warped Radiance Field ($VR_t$):** The radiance field at time $t$, obtained by warping $VR_f$ using $V_{flow}$.
9.  **Inpainted Radiance Field ($VR_t^{Inp}$):** The field after inpainting holes in $VR_t$.
10. **Upsampled Radiance Field ($VR_t^{Up}$):** The field after upsampling $VR_t^{Inp}$.

**Networks:**
*   **Canonical Radiance Network ($F_{\theta_1}$):** 3-layer MLP, width 128, ReLU activation.
    *   Input: Radiance feature from $VR_f$ (dim 12) concatenated with embedded position $\gamma(\mathbf{x})$ (dim 33).
    *   Output: Density (dim 1) and color feature (dim 3 or 12).
*   **Canonical Deformation Network ($F_{\theta_2}$):** 4-layer MLP, width 64.
    *   Input: Deformation feature from $VD_f^{Can}$ concatenated with embedded position $\gamma(\mathbf{x})$ (dim 33).
    *   Output: Trajectory parameters or flow components.
*   **View Dependent Color Network ($F_{\theta_4}$):** 2-layer MLP, width 64.
    *   Input: Embedded view direction $\gamma(\mathbf{d})$ (dim 27) concatenated with color feature from $V_{cf}^{Can}$ (dim 12).
    *   Output: RGB color (dim 3).
*   **Inpaint Network ($F_{\theta_3}$):** UNet structure with 4 encode layers and 3 decode layers, plus an upsample layer.
    *   Encode layers: Max pooling + two convolution layers (Instance Norm + Conv + ReLU).
    *   Decode layers: Up-sample interpolation + two convolution layers (Instance Norm + Conv + ReLU).
    *   Input: Warped radiance field features.
    *   Output: Inpainted radiance field features.

### Numbered Steps

**1. Canonical Field Initialization (Coarse Stage)**
1.  Initialize voxel grids $VR_f$, $VR_{Can}$, $V_{\sigma}^{Can}$, $V_{cf}^{Can}$, $VD_f^{Can}$, $VT_t$, $V_{flow}$ with zeros or small random values.
2.  For each training ray $r$ at time $t$:
    a. Sample $K$ points $w_k$ along the ray.
    b. Query $VR_f$ and $VR_{Can}$ to get radiance features and coordinates.
    c. Compute embedded position $\gamma(\mathbf{x})$ for each point.
    d. Pass features and $\gamma(\mathbf{x})$ to $F_{\theta_1}$ to get density $\sigma(w_k)$ and color feature $\mathbf{c}_{feat}(w_k)$.
    e. Store $\sigma(w_k)$ in $V_{\sigma}^{Can}$ (if optimizing grid directly) or use for rendering.
    f. Render color $\mathbf{C}_{coarse}(r)$ using standard volume rendering with $\sigma$ and $\mathbf{c}_{feat}$ (passed through $F_{\theta_4}$ if needed, though coarse stage often uses grid features directly or simplified heads). *Note: The source specifies $F_{\theta_1}$ outputs color feature, and $F_{\theta_4}$ is used for final color. In coarse stage, the inpaint network is NOT used.*
    g. Compute loss $\mathcal{L}_{photo}$ and auxiliary losses.
    h. Update voxel grids and $F_{\theta_1}$ parameters.

**2. Forward Warping to Time $t$**
1.  For a target time $t$:
    a. For each voxel in the canonical grid, query $VD_f^{Can}$ and $VT_t$.
    b. Use $F_{\theta_2}$ to predict deformation flow $\mathbf{v}_{flow}$ from canonical position $\mathbf{x}_{can}$ to $\mathbf{x}_t$.
    c. Store $\mathbf{v}_{flow}$ in $V_{flow}$.
    d. **Average Splatting:** Warp the canonical radiance features from $VR_f$ to the new positions defined by $\mathbf{x}_{can} + \mathbf{v}_{flow}$.
        *   For each target voxel in the warped grid $VR_t$, gather contributions from canonical voxels that map to it.
        *   Average the features from all contributing canonical voxels. This handles the one-to-many mapping (multiple canonical points mapping to one target) and many-to-one mapping (multiple target points mapping to one canonical point) by averaging.
        *   *Note:* Softmax splatting was tested but average splatting was chosen for simplicity and comparable performance [S1].

**3. Inpainting**
1.  The warped field $VR_t$ contains holes where no canonical voxels mapped (occlusions) or sparse regions.
2.  Pass $VR_t$ through the Inpaint Network $F_{\theta_3}$.
3.  Output the inpainted field $VR_t^{Inp}$.
4.  Upsample $VR_t^{Inp}$ to get $VR_t^{Up}$ (resolution enhancement).

**4. Rendering and Loss Computation**
1.  For each training ray $r$ at time $t$:
    a. Sample points $w_k$ along the ray in the warped/inpainted space.
    b. Query $VR_t^{Up}$ (or $VR_t^{Inp}$) to get density $\sigma(w_k)$ and color feature $\mathbf{c}_{feat}(w_k)$.
    c. Pass $\mathbf{c}_{feat}(w_k)$ and embedded view direction $\gamma(\mathbf{d})$ to $F_{\theta_4}$ to get RGB color $\mathbf{c}(w_k)$.
    d. Render color $\mathbf{C}_{Inp}(r)$ from $VR_t^{Inp}$ and $\mathbf{C}_{Up}(r)$ from $VR_t^{Up}$.
    e. Compute Point-wise Color Loss $\mathcal{L}_{ptc}$:
       $$
       \mathcal{L}_{ptc} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Up}}(\mathbf{r}))
       $$
       where
       $$
       \mathcal{L}(\mathbf{C}(\mathbf{r})) = \frac{1}{K} \sum_{k=1}^{K} A_{\text{accum}}(k) \|\mathbf{c}(w_k) - \mathbf{C}_{\text{gt}}(\mathbf{r})\|_2^2
       $$
       and
       $$
       A_{\text{accum}}(k) = T(w_k) \, \sigma(w_k) \delta_k
       $$
       Here, $T(w_k)$ is the transmittance up to point $w_k$, $\sigma(w_k)$ is the density, and $\delta_k$ is the distance between samples. This loss weights the pixel error by the contribution of each sample to the final color [S1].
    f. Compute Background Entropy Loss $\mathcal{L}_{bg}$:
       $$
       \mathcal{L}_{bg} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Up}}(\mathbf{r}))
       $$
       where
       $$
       \mathcal{L}(\mathbf{A}(\mathbf{r})) = -\frac{1}{K-1} \sum_{k=1}^{K-1} \left[ A_{\text{accum}}(k)\log(A_{\text{accum}}(k)) + (1-A_{\text{accum}}(k))\log(1-A_{\text{accum}}(k)) \right]
       $$
       This encourages densities to be either 0 or 1 (foreground/background) [S1].
    g. Compute Total Loss:
       $$
       \mathcal{L} = \mathcal{L}_{photo} + w_1\mathcal{L}_{ptc} + w_2\mathcal{L}_{bg} + w_3\mathcal{L}_{flow} + w_4\mathcal{L}_{vdiff} + w_5\mathcal{L}_{tv}(\mathbf{V}_{\sigma}^{\text{Can}}) + w_6\mathcal{L}_{tv}(\mathbf{V}_{\text{flow}}^t) + w_7\mathcal{L}_{tv}(\mathbf{D})
       $$
       where $\mathcal{L}_{photo}$ is the standard pixel-wise MSE, $\mathcal{L}_{flow}$ and $\mathcal{L}_{vdiff}$ are flow consistency and video diffusion losses (if applicable), and $\mathcal{L}_{tv}$ is Total Variation loss on density, flow, and deformation features $\mathbf{D}$ [S1].

**5. Fine Stage Training**
1.  Start with the coarse stage model.
2.  Progressive Training: Begin with 10 images closest to the canonical time step. Add one image with the closest remaining time step every 60 iterations [S1].
3.  Increase voxel resolution (e.g., from $6^3$ to $8^3$ or $7^3$).
4.  Enable the inpaint network (scale factor 2.0).
5.  Continue optimization with updated weights.

### Parameters
*   **Coarse Stage:**
    *   Voxel Number: $6^3$.
    *   Inpaint Scale: 1.5 (Inpaint network not used).
    *   Iterations: 20,000.
    *   Weights: $w_1=10^{-1}, w_2=10^{-2}, w_3=10^{-5}, w_4=0, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$.
*   **Fine Stage:**
    *   Voxel Number: $8^3$ (D-NeRF), $7^3$ (HyperNeRF).
    *   Inpaint Scale: 2.0.
    *   Iterations: 100,000.
    *   Weights: $w_1=10^{-2}, w_2=10^{-3}, w_3=10^{-5}, w_4=10^{-5}, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$.
*   **Learning Rate:** $10^{-1}$ for voxel grids, $10^{-3}$ for MLPs.
*   **Canonical Time:** First frame (D-NeRF), Middle frame (HyperNeRF) [S1].

### Edge Cases and Pitfalls
*   **Memory Consumption:** High, especially for real-world scenes [S1].
*   **Training Speed:** Slow, approximately one day per scene on an RTX 3090 [S1].
*   **Coarse Stage Necessity:** Removing the coarse stage causes significant performance drops because the voxel grid covers a larger space without proxy geometry filtering [S1].
*   **Inpainting Importance:** Removing the inpaint network significantly reduces performance (e.g., Hell Warrior PSNR drops from 27.71 to 27.15) [S1].
*   **Softmax Splatting:** Using softmax splatting instead of average splatting did not show obvious improvement and added complexity [S1].

## Operating characteristics
*   **Time Complexity:** Training is slow (~1 day per scene) [S1]. Rendering is slow (7s/image for D-NeRF, 15s/image for HyperNeRF) [S1].
*   **Memory Complexity:** High, due to multiple voxel grids and large model sizes (260M params for D-NeRF, 440M for HyperNeRF) [S1].
*   **Strengths:** SOTA performance on public datasets, especially for canonical frames. Clear advantage over backward-flow methods like NDVG [S1].
*   **Limitations:** High memory usage, slow training and rendering speeds [S1].
*   **When to use:** When high-quality novel view synthesis for dynamic scenes is required, and computational resources are sufficient.
*   **When not to use:** When real-time rendering or low-memory constraints are critical.

## Background
The method was proposed in "Forward Flow for Novel View Synthesis of Dynamic Scenes" [S1]. It builds on the concept of canonical representations for dynamic scenes, addressing the limitations of previous methods that struggled with occlusions and complex motions. The forward warping approach contrasts with backward flow methods (e.g., NDVG) by explicitly predicting the deformation from a static canonical frame [S1].
