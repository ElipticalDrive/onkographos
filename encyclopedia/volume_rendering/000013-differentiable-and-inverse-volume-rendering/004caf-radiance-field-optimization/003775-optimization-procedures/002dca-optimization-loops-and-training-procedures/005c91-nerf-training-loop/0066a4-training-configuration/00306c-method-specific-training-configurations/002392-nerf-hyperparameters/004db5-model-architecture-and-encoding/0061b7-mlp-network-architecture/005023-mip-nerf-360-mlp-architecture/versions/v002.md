# Mip-NeRF 360 MLP Architecture

Also called: Integrated Positional Encoding MLP, PosEnc MLP

## Overview
The Mip-NeRF 360 MLP architecture is a multi-layer perceptron (MLP) that maps 3D spatial coordinates and view directions to volume density and color, utilizing integrated positional encoding to handle aliasing in continuous radiance fields [S1, unofficial]. It distinguishes itself from standard NeRF by lifting Gaussian covariance matrices into the positional encoding space, allowing the network to explicitly model the frequency content of the signal along a ray [S1, unofficial]. The architecture supports advanced features such as specular tinting, roughness prediction, and integrated directional encoding (IDE) for view-dependent effects [S1, unofficial].

## How it works
The method consists of two primary sub-networks: a density network that processes spatial information and a color network that combines spatial features with view-dependent information.

### Inputs and Outputs
**Inputs:**
*   $\mathbf{x} \in \mathbb{R}^3$: 3D spatial coordinates (means of Gaussian distributions).
*   $\Sigma \in \mathbb{R}^{3 \times 3}$: Covariance matrix of the Gaussian distribution at $\mathbf{x}$ [S1, unofficial].
*   $\mathbf{v} \in \mathbb{R}^3$: View direction (or reflection direction $\mathbf{r}$ if reflections are enabled) [S1, unofficial].
*   $\mathbf{n} \in \mathbb{R}^3$: Surface normal (optional, required if reflections are enabled) [S1, unofficial].

**Outputs:**
*   $\sigma \in \mathbb{R}$: Volume density.
*   $\mathbf{c} \in \mathbb{R}^3$: RGB color.
*   (Optional) $\rho \in \mathbb{R}$: Roughness.
*   (Optional) $\mathbf{n} \in \mathbb{R}^3$: Surface normal.

### Data Structures and Parameters
The architecture is defined by the following hyperparameters [S1, unofficial]:

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `net_depth` | int | 8 | Depth of the density MLP. |
| `net_width` | int | 256 | Width of the density MLP. |
| `bottleneck_width` | int | 256 | Width of the feature vector connecting density and color networks. |
| `net_depth_viewdirs` | int | 1 | Depth of the color MLP. |
| `net_width_viewdirs` | int | 128 | Width of the color MLP. |
| `min_deg_point` | int | 0 | Minimum degree of positional encoding for points. |
| `max_deg_point` | int | 12 | Maximum degree of positional encoding for points. |
| `skip_layer` | int | 4 | Frequency of skip connections in the density MLP. |
| `skip_layer_dir` | int | 4 | Frequency of skip connections in the color MLP. |
| `deg_view` | int | 4 | Degree of encoding for view/reflection directions. |
| `density_bias` | float | -1.0 | Bias added to raw density before activation. |
| `density_noise` | float | 0.0 | Standard deviation of noise added to raw density. |
| `rgb_bias` | float | 0.0 | Bias added to raw color before activation. |
| `rgb_padding` | float | 0.001 | Padding applied to RGB output range. |
| `use_reflections` | bool | False | Enable reflection directions instead of view directions. |
| `use_directional_enc` | bool | False | Use Integrated Directional Encoding (IDE). |
| `enable_pred_roughness` | bool | False | Predict roughness parameter. |
| `roughness_bias` | float | -1.0 | Bias for roughness prediction. |
| `use_diffuse_color` | bool | False | Split color into diffuse and specular components. |
| `use_specular_tint` | bool | False | Predict a tint vector for specular color. |
| `use_n_dot_v` | bool | False | Append $\mathbf{n} \cdot \mathbf{v}$ to color network input. |
| `bottleneck_noise` | float | 0.0 | Noise added to the bottleneck feature vector. |
| `basis_shape` | str | 'icosahedron' | Basis shape for integrated encoding ('octahedron' or 'icosahedron'). |
| `basis_subdivisions` | int | 2 | Tessellation count for the basis shape. |

### Pseudocode

```python
import jax.numpy as jnp
import jax
from jax import random

def mlp_mipnerf_360(
    means,           # (..., 3) Spatial coordinates
    covs,            # (..., 3, 3) Covariance matrices
    viewdirs,        # (..., 3) View directions
    normals=None,    # (..., 3) Surface normals (optional)
    glo_vec=None,    # (..., D) Global vectors (optional)
    
    # Architecture parameters
    net_depth=8, net_width=256, bottleneck_width=256,
    net_depth_viewdirs=1, net_width_viewdirs=128,
    min_deg_point=0, max_deg_point=12,
    skip_layer=4, skip_layer_dir=4,
    deg_view=4,
    density_bias=-1.0, density_noise=0.0,
    rgb_bias=0.0, rgb_padding=0.001,
    use_reflections=False, use_directional_enc=False,
    enable_pred_roughness=False, roughness_bias=-1.0,
    use_diffuse_color=False, use_specular_tint=False,
    use_n_dot_v=False, bottleneck_noise=0.0,
    basis_shape='icosahedron', basis_subdivisions=2,
    
    # Helper functions (assumed defined elsewhere)
    pos_enc=None, # Function for standard positional encoding
    generate_basis=None, # Function to generate basis matrix
    generate_ide_fn=None, # Function to generate IDE function
    l2_normalize=None, # L2 normalization function
    linear_to_srgb=None, # Linear to sRGB conversion
    reflect=None # Reflection vector calculation
):
    """
    Forward pass of the Mip-NeRF 360 MLP architecture.
    """
    
    # 1. Setup Basis and Directional Encoding
    # Precompute transpose of basis matrix for integrated positional encoding
    basis_shape_tuple = (3, 3) # Simplified for pseudocode; actual shape depends on basis
    pos_basis_t = generate_basis(basis_shape_tuple, basis_subdivisions).T
    
    if use_directional_enc:
        dir_enc_fn = generate_ide_fn(deg_view)
    else:
        # Standard positional encoding for directions
        dir_enc_fn = lambda v: pos_enc(v, min_deg=0, max_deg=deg_view, append_identity=True)

    # 2. Density Network
    # Linearize means and covs if a warp function is provided
    # [G] Assuming track_linearize handles the transformation of Gaussian parameters
    if warp_fn is not None:
        means, covs = track_linearize(warp_fn, means, covs)
        
    # Lift and diagonalize covariances to get lifted means and variances
    lifted_means, lifted_vars = lift_and_diagonalize(means, covs, pos_basis_t)
    
    # Compute integrated positional encoding for spatial points
    # This accounts for the frequency content of the Gaussian along the ray
    x = integrated_pos_enc(lifted_means, lifted_vars, min_deg_point, max_deg_point)
    
    # Density MLP layers
    for i in range(net_depth):
        x = dense_layer(x, width=net_width, activation=net_activation)
        if i > 0 and i % skip_layer == 0:
            x = jnp.concatenate([x, x_orig], axis=-1) # Skip connection
            
    # Raw density output
    raw_density = dense_layer(x, width=1)[..., 0]
    
    # Add noise to density if specified
    if density_noise > 0:
        noise = random.normal(random.PRNGKey(0), raw_density.shape)
        raw_density += density_noise * noise
        
    # Compute normals from raw density gradient (numerically stable)
    # [G] jax.vmap is used to vectorize over batch dimensions
    if disable_density_normals is False:
        # Flatten batch dimensions for vmap
        flat_means = means.reshape(-1, 3)
        flat_covs = covs.reshape(-1, 3, 3)
        
        # Compute density and its gradient simultaneously
        raw_density_flat, raw_grad_density_flat = jax.vmap(
            lambda m, c: jax.value_and_grad(
                lambda m: predict_density(m, c, ...), has_aux=False
            )(m), axis_name='batch'
        )(flat_means, flat_covs)
        
        # Reshape gradients back to batch shape
        raw_grad_density = raw_grad_density_flat.reshape(means.shape)
        
        # Normals are negative normalized gradient
        normals = -l2_normalize(raw_grad_density)
        
    # Final density activation
    density = density_activation(raw_density + density_bias)
    
    # 3. Directional Encoding
    # Compute reflection direction if enabled
    if use_reflections:
        # Viewdirs point from camera to point; reflect assumes toward camera
        # Flip viewdirs before reflection
        reflected_viewdirs = reflect(-viewdirs, normals)
        dir_input = reflected_viewdirs
    else:
        dir_input = viewdirs
        
    dir_enc = dir_enc_fn(dir_input)
    
    # 4. Color Network
    # Broadcast dir_enc to match bottleneck shape
    # [G] Assuming bottleneck features are available from previous step or passed in
    # Here we assume 'bottleneck' is the output of the density network's last layer before raw_density
    # In the source, 'bottleneck' is implied to be the feature vector x before the final density layer
    # However, the source code snippet shows 'bottleneck' being used in color network input.
    # We assume 'bottleneck' is the feature vector x after the density MLP layers (before raw_density)
    
    # Broadcast dir_enc
    dir_enc_broad = jnp.broadcast_to(
        dir_enc[..., None, :], 
        bottleneck.shape[:-1] + (dir_enc.shape[-1],)
    )
    
    x_color = [bottleneck]
    
    # Append directional encoding
    x_color.append(dir_enc_broad)
    
    # Append n dot v if enabled
    if use_n_dot_v:
        normals_to_use = normals if normals is not None else ... # [G] Handle case where normals not computed
        dotprod = jnp.sum(normals_to_use * viewdirs[..., None, :], axis=-1, keepdims=True)
        x_color.append(dotprod)
        
    # Append global vectors if provided
    if glo_vec is not None:
        glo_vec_broad = jnp.broadcast_to(
            glo_vec[..., None, :], 
            bottleneck.shape[:-1] + (glo_vec.shape[-1],)
        )
        x_color.append(glo_vec_broad)
        
    # Concatenate all inputs
    x_color = jnp.concatenate(x_color, axis=-1)
    
    # Color MLP layers
    for i in range(net_depth_viewdirs):
        x_color = dense_layer(x_color, width=net_width_viewdirs, activation=net_activation)
        if i > 0 and i % skip_layer_dir == 0:
            x_color = jnp.concatenate([x_color, x_color_orig], axis=-1) # Skip connection
            
    # Raw RGB output
    raw_rgb = dense_layer(x_color, width=num_rgb_channels)
    
    # Apply roughness prediction if enabled
    if enable_pred_roughness:
        raw_roughness = dense_layer(x_color, width=1)[..., 0]
        roughness = roughness_activation(raw_roughness + roughness_bias)
        
    # Apply RGB activation and bias
    rgb = rgb_activation(rgb_premultiplier * raw_rgb + rgb_bias)
    
    # Specular/Diffuse Split
    if use_diffuse_color:
        # Diffuse color from raw_rgb_diffuse (assumed to be part of raw_rgb or separate)
        # [G] Assuming raw_rgb contains diffuse component if use_diffuse_color is True
        # The source uses raw_rgb_diffuse. We assume raw_rgb is split or raw_rgb_diffuse is extracted.
        # For pseudocode, we assume raw_rgb has shape (..., 3) and represents diffuse if split is used?
        # Actually, source says: diffuse_linear = nn.sigmoid(raw_rgb_diffuse - log(3.0))
        # This implies raw_rgb_diffuse is a scalar or specific channel. 
        # Let's assume raw_rgb is the diffuse component if use_diffuse_color is True.
        diffuse_linear = jnp.sigmoid(raw_rgb - jnp.log(3.0))
        
        if use_specular_tint:
            # [G] tint is assumed to be a learned parameter or input
            specular_linear = tint * rgb
        else:
            specular_linear = 0.5 * rgb
            
        rgb = jnp.clip(linear_to_srgb(specular_linear + diffuse_linear), 0.0, 1.0)
    else:
        # Standard RGB padding
        rgb = rgb * (1 + 2 * rgb_padding) - rgb_padding
        
    return density, rgb
```

### Step-by-Step Description

1.  **Setup**:
    *   If `use_reflections` is True, normals must be available (either predicted or computed from density). If not, raise `ValueError` [S1, unofficial].
    *   Precompute the transpose of the basis matrix (`pos_basis_t`) using `geopoly.generate_basis` with the specified `basis_shape` and `basis_subdivisions` [S1, unofficial].
    *   If `use_directional_enc` is True, generate the Integrated Directional Encoding (IDE) function using `ref_utils.generate_ide_fn(deg_view)`. Otherwise, use standard positional encoding for directions with `min_deg=0` and `max_deg=deg_view` [S1, unofficial].

2.  **Density Prediction**:
    *   If a `warp_fn` is provided, linearize the means and covariances using `coord.track_linearize` [S1, unofficial].
    *   Lift and diagonalize the means and covariances using `coord.lift_and_diagonalize` with `pos_basis_t` to obtain `lifted_means` and `lifted_vars` [S1, unofficial].
    *   Compute the integrated positional encoding of the lifted means and variances using `coord.integrated_pos_enc` with `min_deg_point` and `max_deg_point` to get the input feature vector $x$ [S1, unofficial].
    *   Iterate through `net_depth` layers of the density MLP. Each layer applies a dense transformation with `net_width` and `net_activation`. If `i > 0` and `i % skip_layer == 0`, concatenate the current input $x$ with the original input to the layer (skip connection) [S1, unofficial].
    *   Output the raw density using a dense layer with width 1: `raw_density = dense_layer(1)(x)[..., 0]` [S1, unofficial].
    *   If `density_noise > 0`, add Gaussian noise to `raw_density` [S1, unofficial].
    *   If normals are not disabled (`disable_density_normals is False`), compute the gradient of the raw density with respect to the spatial coordinates using `jax.vmap(jax.value_and_grad)`. Compute normals as the negative L2-normalized gradient: `normals = -ref_utils.l2_normalize(raw_grad_density)` [S1, unofficial].
    *   Apply the density activation function to `raw_density + density_bias` to get the final density [S1, unofficial].

3.  **Directional Encoding**:
    *   If `use_reflections` is True, flip the view directions (`-viewdirs`) because they point from camera to point, whereas the reflection function assumes they point toward the camera. Compute reflection directions using `ref_utils.reflect` [S1, unofficial].
    *   Encode the view/reflection directions using the `dir_enc_fn` [S1, unofficial].

4.  **Color Network Input**:
    *   Broadcast the directional encoding `dir_enc` to match the shape of the bottleneck features [S1, unofficial].
    *   Append `dir_enc` to the list of inputs $x$ for the color network.
    *   If `use_n_dot_v` is True, compute the dot product of normals and view directions and append it to $x$ [S1, unofficial].
    *   If `glo_vec` is provided, broadcast it to match the bottleneck shape and append it to $x$ [S1, unofficial].
    *   Concatenate all elements in $x$ along the last axis [S1, unofficial].

5.  **Color Network**:
    *   Iterate through `net_depth_viewdirs` layers of the color MLP. Each layer applies a dense transformation with `net_width_viewdirs` and `net_activation`. If `i > 0` and `i % skip_layer_dir == 0`, concatenate the current input with the original input (skip connection) [S1, unofficial].
    *   Compute the raw RGB output using a dense layer with `num_rgb_channels` [S1, unofficial].

6.  **Output Processing**:
    *   If `use_diffuse_color` is True, compute diffuse color as `sigmoid(raw_rgb_diffuse - log(3.0))`. If `use_specular_tint` is True, compute specular color as `tint * rgb`; otherwise, use `0.5 * rgb`. Combine and tone map using `linear_to_srgb` [S1, unofficial].
    *   If `use_diffuse_color` is False, apply RGB padding: `rgb = rgb * (1 + 2 * rgb_padding) - rgb_padding` [S1, unofficial].

### Edge Cases and Pitfalls
*   **Reflections require normals**: If `use_reflections` is True, normals must be computed. If `enable_pred_normals` is False and `disable_density_normals` is True, a `ValueError` is raised [S1, unofficial].
*   **Reflection direction flip**: View directions point from the camera to the point, but `ref_utils.reflect` assumes directions point toward the camera. Therefore, view directions must be flipped (`-viewdirs`) before reflection [S1, unofficial].
*   **Normal stability**: Normals are computed from the gradient of the raw (pre-activation) density, not the post-activation density, because it is numerically more stable, especially when the activation function has a steep or flat gradient [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: The density network has $L_1$ layers of width $W_1$, and the color network has $L_2$ layers of width $W_2$. The complexity is $O(L_1 W_1^2 + L_2 W_2^2)$ per sample, dominated by the matrix multiplications in the dense layers.
*   **Memory Complexity**: The memory usage is proportional to the number of parameters in the MLP, which is $O(L_1 W_1^2 + L_2 W_2^2 + W_1 W_2)$. The integrated positional encoding requires storing the lifted means and variances, adding $O(N)$ memory for $N$ samples.
*   **Strengths**: The integrated positional encoding reduces aliasing artifacts by explicitly modeling the frequency content of the signal. The architecture supports advanced rendering effects like specular tinting and roughness.
*   **Limitations**: The architecture is computationally more expensive than standard NeRF due to the additional steps for lifting, diagonalizing, and computing integrated positional encoding. The use of skip connections and multiple layers increases memory usage.
*   **When to use**: Use this architecture when high-quality rendering with reduced aliasing is required, especially for scenes with high-frequency details. It is suitable for applications requiring view-dependent effects like specular highlights.
*   **When not to use**: Avoid this architecture if computational resources are limited or if real-time performance is critical, as it is slower than standard NeRF.

## Background
The Mip-NeRF 360 MLP architecture was introduced in the "Mip-NeRF 360" paper by Google Research [S1, unofficial]. It builds upon the original NeRF architecture by incorporating integrated positional encoding to address aliasing issues in continuous radiance fields. The architecture has been widely adopted in subsequent research for its ability to produce high-quality renderings with reduced artifacts.
