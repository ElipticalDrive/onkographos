# Rip-NeRF

Also called: Rip-NeRF25k

## Overview
Rip-NeRF is a hybrid radiance field method that renders high-fidelity, anti-aliased images by combining cone casting with anisotropic 3D Gaussian characterization [S1]. It distinguishes itself from sibling methods like Zip-NeRF by using Ripmap-Encoded Platonic Solids to enable efficient anisotropic area-sampling, avoiding the discrete point-based sampling that causes aliasing [S1]. While Zip-NeRF relies on a multi-sampling mechanism that is effective but computationally inefficient, Rip-NeRF achieves comparable or superior quality with significantly faster training, smaller model size, and higher rendering speeds [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of calibrated multi-view 2D images.
*   **Outputs:** Rendered pixel colors $\hat{C}(r)$ for new viewpoints.
*   **Learnable Parameters:** Ripmap Encodings (feature grids), 3D Gaussian parameters (mean $\boldsymbol{\mu}$, covariance $\boldsymbol{\Sigma}$), and MLP weights $\theta$.

**Data Structures:**
1.  **Ripmap Encoding:** A hierarchical feature grid.
    *   **Base Level ($R_{0,0}$):** Learnable tensor of shape $H \times W \times C$. Default: $512 \times 512 \times 16$ [S1].
    *   **Derived Levels:** Generated from $R_{0,0}$ using averaging operations to ensure consistency and compactness [S1].
2.  **Platonic Solid:** A geometric proxy for the scene. Default: Icosahedron with 10 unparalleled faces [S1].
3.  **3D Gaussian:** Characterizes each conical frustum. Defined by mean $\boldsymbol{\mu} \in \mathbb{R}^3$ and covariance $\boldsymbol{\Sigma} \in \mathbb{R}^{3 \times 3}$ [S1].
4.  **MLP ($F_\theta$):** A "tiny" Multi-Layer Perceptron mapping aggregated features to density $\sigma$ and color $\mathbf{c}$ [S1].

**Numbered Steps:**

1.  **Cone Casting and Frustum Division:**
    For each pixel, cast a cone into the scene. Divide the cone into multiple conical frustums along the ray depth [S1]. This avoids discrete point-based sampling [S1].

2.  **Anisotropic 3D Gaussian Characterization:**
    Characterize each conical frustum as an anisotropic 3D Gaussian parameterized by mean $\boldsymbol{\mu}$ and covariance $\boldsymbol{\Sigma}$ [S1].

3.  **Platonic Solid Projection:**
    Project the 3D Gaussian onto the $n$ faces $\{P_i | i = 1, \dots, n\}$ of the Platonic solid (default $n=10$ for icosahedron) [S1].
    For each face $P_i$, compute the projected 2D Gaussian parameters $(\boldsymbol{\mu}_{proj}, \boldsymbol{\Sigma}_{proj})$ using the projection matrix $M_i \in \mathbb{R}^{3 \times 2}$:
    $$ \boldsymbol{\mu}_{proj} = M_i^T \boldsymbol{\mu} $$
    $$ \boldsymbol{\Sigma}_{proj} = M_i^T \boldsymbol{\Sigma} M_i $$
    [S1]

4.  **Ripmap Encoding Query:**
    For each projected 2D Gaussian on face $P_i$, query a feature vector $\mathbf{f}_i$ from the Ripmap Encoding of that face [S1].
    The query uses tetra-linear interpolation on the Ripmap grid. The position $(p_x, p_y)$ and level $(l_x, l_y)$ for interpolation are determined by $\boldsymbol{\mu}_{proj}$ and $\boldsymbol{\Sigma}_{proj}$ respectively [S1].
    The hyper-parameter $w$ in the level calculation is set to 2.0 to adjust the probability mass coverage of the Gaussian footprint [S1].
    *Note: The specific interpolation formula for Ripmap levels is referenced as Eq. 2 and Eq. 3 in the source, but the exact algebraic form is not provided in the text. The levels are derived from the base level $R_{0,0}$ via averaging (Eq. 1) [S1].*

5.  **Feature Aggregation:**
    Concatenate all feature vectors $\{\mathbf{f}_i | i = 1, \dots, n\}$ from the Platonic solid faces and the encoded view direction $\mathbf{d}$ to form the final feature vector $\mathbf{f}$ [S1].

6.  **MLP Decoding:**
    Pass the aggregated feature vector $\mathbf{f}$ through the tiny MLP $F_\theta$ to estimate the volume density $\sigma$ and color $\mathbf{c}$ for the frustum [S1].

7.  **Volume Rendering:**
    Render the pixel color $\hat{C}(r)$ by integrating the estimated $\sigma$ and $\mathbf{c}$ along the ray using standard volume rendering equations [S1]:
    $$ \hat{C}(r) = \sum_i T_i \alpha_i c_i, \quad T_i = \prod_{j<i} (1 - \alpha_i), \quad \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
    where $\delta_i$ is the distance between samples [S1].

8.  **Optimization:**
    Optimize the system end-to-end using a photometric loss between rendered and observed images [S1].
    The loss is scaled by the area of the pixel footprint on the image plane (Area Loss $L_{area}$) to make it area-aware [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class RipNeRF:
    def __init__(self, num_faces=10, base_h=512, base_w=512, base_c=16, w=2.0):
        """
        Initialize Rip-NeRF.
        :param num_faces: Number of faces on the Platonic solid (default 10 for icosahedron).
        :param base_h, base_w, base_c: Dimensions of the base Ripmap level R_0,0.
        :param w: Hyper-parameter for level calculation (default 2.0).
        """
        self.num_faces = num_faces
        self.w = w
        # Base level is learnable; derived levels are computed on the fly or cached
        self.base_level = nn.Parameter(torch.randn(base_h, base_w, base_c))
        
        # Tiny MLP for density and color
        # Input dim: num_faces * base_c + view_dir_dim
        # Output dim: 4 (sigma, r, g, b)
        self.mlp = nn.Sequential(
            nn.Linear(num_faces * base_c + 3, 64),
            nn.ReLU(),
            nn.Linear(64, 4)
        )
        
        # 3D Gaussian parameters (mean and covariance) are optimized
        # In practice, these might be per-frustum or learned per-scene
        # For this pseudocode, we assume a simplified query interface
        self.gaussian_params = None 

    def get_derived_level(self, level_x, level_y):
        """
        Compute derived Ripmap level from base level using averaging.
        Eq. 1 from source:
        R_i,j = Avg2x1(R_i, j-1) if j != 0
        R_i,j = Avg1x2(R_i-1, j) if i != 0 & j == 0
        R_i,j = 0 otherwise (or base if i=j=0)
        """
        if level_x == 0 and level_y == 0:
            return self.base_level
        
        # Note: Exact implementation of Avg2x1/Avg1x2 depends on grid alignment.
        # This is a placeholder for the averaging logic described in [S1].
        # In a real implementation, this would involve strided slicing and pooling.
        raise NotImplementedError("Exact averaging kernel for Ripmap derivation not fully specified in source text.")

    def project_gaussian_to_face(self, mu, sigma, face_index):
        """
        Project 3D Gaussian (mu, sigma) to 2D Gaussian on face P_i.
        :param mu: (3,) mean vector
        :param sigma: (3,3) covariance matrix
        :param face_index: Index of the Platonic solid face
        :return: mu_proj (2,), sigma_proj (2,2)
        """
        # M_i is the projection matrix for face i
        # This matrix is pre-defined based on the icosahedron geometry
        M_i = self.get_projection_matrix(face_index) # Shape: (3, 2)
        
        mu_proj = M_i.T @ mu
        sigma_proj = M_i.T @ sigma @ M_i
        return mu_proj, sigma_proj

    def query_riipmap(self, mu_proj, sigma_proj, face_index):
        """
        Query feature vector from Ripmap Encoding of face P_i.
        Uses tetra-linear interpolation.
        Position (px, py) and level (lx, ly) determined by mu_proj and sigma_proj.
        """
        # Determine position and level from 2D Gaussian parameters
        # px, py from mu_proj
        # lx, ly from sigma_proj (scaled by w)
        px, py = mu_proj[0], mu_proj[1]
        lx = self.w * sigma_proj[0, 0] # Example mapping
        ly = self.w * sigma_proj[1, 1] # Example mapping
        
        # Get the appropriate level
        level = self.get_derived_level(lx, ly)
        
        # Tetra-linear interpolation (bilinear in 2D)
        # This requires coordinate normalization and boundary handling
        feature = self.interpolate_2d(level, px, py)
        return feature

    def forward(self, rays, gaussian_params):
        """
        Render a batch of rays.
        :param rays: Ray origins and directions
        :param gaussian_params: (mu, sigma) for the frustums along the rays
        :return: Rendered colors
        """
        mu, sigma = gaussian_params
        rendered_colors = []
        
        for ray_idx, ray in enumerate(rays):
            # 1. Cast cone and divide into frustums
            frustums = self.cast_cone_and_divide(ray)
            
            frustum_features = []
            for frustum in frustums:
                # 2. Characterize frustum as 3D Gaussian (mu_f, sigma_f)
                mu_f, sigma_f = frustum.get_gaussian_params()
                
                # 3 & 4. Project to Platonic faces and query Ripmap
                face_features = []
                for i in range(self.num_faces):
                    mu_proj, sigma_proj = self.project_gaussian_to_face(mu_f, sigma_f, i)
                    f_i = self.query_riipmap(mu_proj, sigma_proj, i)
                    face_features.append(f_i)
                
                # 5. Aggregate features
                # Concatenate face features and view direction
                view_dir_encoded = self.encode_view_direction(ray.direction)
                f_agg = torch.cat(face_features + [view_dir_encoded], dim=-1)
                
                # 6. MLP Decoding
                out = self.mlp(f_agg)
                sigma_f = torch.exp(out[0]) # Ensure positive density
                color = torch.sigmoid(out[1:])
                
                frustum_features.append((sigma_f, color))
            
            # 7. Volume Rendering
            color = self.volume_render(frustum_features)
            rendered_colors.append(color)
            
        return torch.stack(rendered_colors)

    def compute_loss(self, rendered, target):
        """
        Compute area-aware photometric loss.
        """
        # Scale loss by pixel footprint area
        # L_area = Mean( Area * ||Rendered - Target||^2 )
        return torch.mean(self.pixel_areas * (rendered - target) ** 2)
```

**Parameters:**
*   **Base Ripmap Shape ($R_{0,0}$):** $H=512, W=512, C=16$ [S1].
*   **Platonic Solid:** Icosahedron (10 faces) [S1].
*   **Hyper-parameter $w$:** 2.0 (adjusts probability mass coverage) [S1].
*   **Optimizer:** AdamW [S1].
*   **Iterations:** 120k (standard), 25k (Rip-NeRF25k variant) [S1].
*   **Weight Decay:** $1 \times 10^{-5}$ [S1].
*   **Initial Learning Rate:** $2 \times 10^{-3}$, modulated by MultiStepLR [S1].
*   **Ripmap LR Scale:** 10.0 times the base learning rate [S1].

**Edge Cases and Pitfalls:**
*   **Empty Space:** Use a binary occupancy grid (via NerfAcc) to skip samples in empty areas [S1].
*   **Precision:** The Ripmap levels are derived from the base level via averaging, ensuring consistency [S1].
*   **Hardware:** Uses `tiny-cuda-nn` for MLP and custom CUDA kernels for Platonic Solid Projection and Ripmap Encoding [S1].

## Operating characteristics
*   **Training Time:** 2.6 hours on NVIDIA A100-SXM4-80GB GPU for 120k iterations [S1]. The Rip-NeRF25k variant trains in 32 minutes (11.76% of Zip-NeRF's 4.5h) [S1].
*   **Model Size:** 160 MB [S1]. (Zip-NeRF: 592 MB) [S1].
*   **GPU Memory:** 20 GB during training [S1]. (Zip-NeRF: ~80 GB) [S1].
*   **Rendering Speed:** 3 FPS [S1]. (Zip-NeRF: 0.25 FPS) [S1].
*   **Quality:** Outperforms Zip-NeRF in PSNR and LPIPS. Zip-NeRF has slightly better SSIM [S1].
*   **Strengths:** High efficiency, compact model size, fast rendering, anti-aliased output.
*   **Limitations:** Requires calibrated multi-view images. The specific derivation of Ripmap levels (Eq. 1) requires careful implementation to maintain consistency [S1].

## Background
Rip-NeRF was introduced in the paper "Rip-NeRF: Anti-aliasing Radiance Fields with Ripmap-Encoded Platonic Solids" [S1]. It builds upon the hybrid representation approach of NeRF [Mildenhall et al. 2020] and area-sampling techniques from Mip-NeRF [Barron et al. 2021] and Tri-MipRF [Hu et al. 2023]. It specifically addresses the inefficiency of multi-sampling methods like Zip-NeRF [Barron et al. 2023] by introducing Ripmap-Encoded Platonic Solids for anisotropic area-sampling [S1].
