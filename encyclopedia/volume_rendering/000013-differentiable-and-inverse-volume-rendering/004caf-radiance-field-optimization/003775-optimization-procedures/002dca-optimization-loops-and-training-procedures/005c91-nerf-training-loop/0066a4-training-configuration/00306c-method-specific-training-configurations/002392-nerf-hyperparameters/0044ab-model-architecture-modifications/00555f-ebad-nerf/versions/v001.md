# EBAD-NeRF

Also called: Event-driven Bundle Adjustment for Deblurring Neural Radiance Fields

## Overview
EBAD-NeRF is a method for reconstructing sharp 3D radiance fields from motion-blurred images by jointly optimizing learnable camera poses and NeRF parameters using hybrid event-RGB data [S1]. It distinguishes itself from prior works like BAD-NeRF and E2 NeRF by modeling complex camera motion trajectories with multiple learnable poses rather than linear interpolation or fixed pre-estimated poses, and by explicitly supervising the motion blur via an intensity-change-metric event loss [S1].

## How it works
**Inputs:**
- Blurry RGB images $B$ captured during exposure time $[t_{start}, t_{end}]$.
- Synchronized event data $E$ recording intensity changes during the same exposure period [S1].
- Camera intrinsics (assumed known) [S1].

**Outputs:**
- A sharp NeRF model $F_\theta$ representing the static 3D scene [S1].
- Accurate camera motion trajectories (poses) during the exposure time [S1].

**Data Structures:**
- **NeRF Model:** Two MLPs (coarse and fine) as per the standard architecture . The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs latent feature $\mathbf{h}$ and density $\sigma$. The fine network takes $\mathbf{h}$, $\gamma(\mathbf{x})$, and view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ .
- **Positional Encoding:** $\gamma_K(\mathbf{x})$ maps input $\mathbf{x}$ to $K+1$ dimensions using sine and cosine frequencies:
  $$
  \gamma_K(\mathbf{x}) = \{\sin(2^k \pi \mathbf{x}), \cos(2^k \pi \mathbf{x})\}_{k=0}^K
  $$
  [S1].
- **Learnable Poses:** For each view, $p$ learnable camera poses $\{P_i\}_{i=1}^p$ are defined, representing the camera trajectory during exposure. These are stored as SE(3) transformations [S1].

**Numbered Steps:**

1.  **Trajectory Modeling:** For each training view with exposure time $[t_{start}, t_{end}]$, define $p$ virtual camera poses $\{P_i\}_{i=1}^p$ sampled evenly over the exposure interval. These poses are learnable parameters initialized from a coarse estimate (e.g., COLMAP) but updated during training [S1].
2.  **Ray Sampling:** For each pixel $\mathbf{x}$ in the blurry image, cast a ray $\mathbf{r}$ through the camera center for each of the $p$ poses $P_i$. Divide the ray segment $[l_{near}, l_{far}]$ into $N$ equal parts and sample $N$ points along the ray for each pose [S1].
3.  **NeRF Evaluation:** For each sampled point $\mathbf{o}$ and view direction $\mathbf{d}$, query the NeRF MLP $F_\theta$ to obtain color $\mathbf{c}$ and density $\sigma$:
    $$
    (\mathbf{c}, \sigma) = F_\theta(\gamma_o(\mathbf{o}), \gamma_d(\mathbf{d}))
    $$
    [S1].
4.  **Volume Rendering:** Compute the rendered color $C(P_i, \mathbf{x})$ for each pose $P_i$ using volume rendering:
    $$
    C(\mathbf{r}, \mathbf{x}) = \sum_{i=1}^N T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i
    $$
    where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$, $\delta_i = l_{i+1} - l_i$, and $T_i$ is the transparency up to point $i$ [S1].
5.  **Blur Simulation:** Approximate the blurry image $\hat{B}(\mathbf{x})$ by averaging the rendered sharp images from the $p$ poses:
    $$
    \hat{B}(\mathbf{x}) = \frac{1}{p} \sum_{i=1}^p C(P_i, \mathbf{x})
    $$
    [S1].
6.  **Event Loss Calculation:** Compute the intensity-change-metric event loss. This involves comparing the predicted intensity changes from the NeRF rendering (integrated over time/poses) with the actual event data $E$. The event data provides high-temporal-resolution supervision for the camera motion trajectory [S1].
7.  **Photo-metric Loss:** Compute the pixel-wise difference between the simulated blurry image $\hat{B}(\mathbf{x})$ and the observed blurry image $B(\mathbf{x})$:
    $$
    L_{photo} = \| \hat{B}(\mathbf{x}) - B(\mathbf{x}) \|
    $$
    [S1].
8.  **Joint Optimization:** Minimize the total loss, which combines the photo-metric blur loss and the intensity-change-metric event loss, with respect to both the NeRF parameters $\theta$ and the learnable poses $\{P_i\}$ [S1].

**Parameters:**
- $N$: Number of stratified samples per ray (Not given in the sources).
- $p$: Number of learnable poses per view to model the trajectory (Not given in the sources).
- $K$: Number of frequency bands in positional encoding (Not given in the sources).

**Edge Cases and Pitfalls:**
- **Degenerate Motion:** If the camera is static, the learnable poses may collapse to a single pose; the event loss helps prevent this by enforcing consistency with event data [S1].
- **Event Data Sparsity:** In low-light or low-contrast scenes, event data may be sparse, reducing the effectiveness of the event loss [S1].
- **Pose Initialization:** Poor initialization of learnable poses may lead to local minima; using COLMAP estimates as a starting point is recommended [S1].

## Operating characteristics
- **Time Complexity:** Training is more expensive than standard NeRF due to the joint optimization of $p$ poses per view and the additional event loss computation [S1].
- **Memory Complexity:** Increased memory usage to store $p$ poses per view and their gradients [S1].
- **Strengths:** Handles complex motion blur better than linear interpolation methods (BAD-NeRF) and does not rely on pre-deblurred images or fixed poses (E2 NeRF) [S1].
- **Limitations:** Requires synchronized event-RGB data, which is not always available [S1].

## Background
EBAD-NeRF was proposed by Yunshan Qi, Lin Zhu, Yifan Zhao, Nan Bao, and Jia Li [S1]. It addresses the limitations of previous deblurring NeRF methods like Deblur-NeRF, BAD-NeRF, and E2 NeRF, which either use deformable kernels, linear pose interpolation, or fixed poses from pre-deblurred images [S1]. The method leverages bio-inspired event cameras to provide high-temporal-resolution data for modeling motion blur [S1].
