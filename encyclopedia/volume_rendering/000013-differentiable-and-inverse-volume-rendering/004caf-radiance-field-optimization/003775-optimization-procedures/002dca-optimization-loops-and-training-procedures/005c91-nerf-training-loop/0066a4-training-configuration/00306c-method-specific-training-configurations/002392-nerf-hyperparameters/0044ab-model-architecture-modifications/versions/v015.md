# Model Architecture Modifications

Also called: NeRF Architecture Variants, Implicit Representation Modifications

## Overview
Model Architecture Modifications encompass structural changes to the standard Neural Radiance Field (NeRF) pipeline, including input expansion, output expansion, and representation substitution, to enable new capabilities such as semantic understanding, dynamic scene modeling, or improved rendering efficiency [S6, unofficial]. Unlike standard NeRF, which maps coordinates to color and density via a single MLP, these modifications introduce auxiliary heads, discrete data structures, or external conditioning features to address specific limitations in geometry, appearance, or computational cost [14428-sparse-view-and-few-shot-optimization.md].

## Shared principles
The standard NeRF architecture consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network [S6, unofficial]. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ [S6, unofficial].

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories [14428-sparse-view-and-few-shot-optimization.md]:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation [14428-sparse-view-and-few-shot-optimization.md].
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color [14428-sparse-view-and-few-shot-optimization.md]:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs) [14428-sparse-view-and-few-shot-optimization.md].

### NeRF-VAE
- [S1] A generative NeRF model that generalizes to out-of-distribution scenes and removes the need to train on each scene from scratch.
- [S1] The NeRF renderer is conditioned on a latent code. This latent code is trained using Iterative Amortized Inference and a ResNet encoder.
- [S1] An attention-based scene function is introduced instead of the typical MLP.
- [S1] Outperforms baseline NeRF with a low number of scene views (5-20), but is outperformed by baseline NeRF when a large number of views are available (100+) due to lower scene expressivity.

### PIE-NeRF
- [S1] A pipeline integrating physics-based elastodynamic simulation with a neural radiance field representation, using a meshless discretisation based on quadratic generalized moving least squares on top of the density field of a NeRF.
- [S1] Enables large deformations and nonlinear hyperelastic material simulation directly on the implicit representation and supports interactive manipulation of real-world captured scenes with complex geometries.

### NeRF Model Architecture
- [S3, unofficial] The neural network architecture for NeRF, consisting of dense layers with ReLU activations, potentially using view directions as input.
- [S3, unofficial] `D`: The depth of the network (number of hidden layers). Default is 8.
- [S3, unofficial] `input_ch_views`: The number of input channels for view directions. Default is 3.
- [S3, unofficial] `output_ch`: The number of output channels. Default is 4 (RGB + density).
- [S3, unofficial] `use_viewdirs`: Boolean flag to determine if view directions are used as input to the network.

### S3-NeRF
- [S1] A method using shadow and shading cues to infer scene geometry and enable single-image NeRF training.
- [S1] Employ a UNISURF-based occupancy field 3D representation instead of density.
- [S1] Use a modified physics-based rendering equation.
- [S1] Use occupancy-based shadow calculation.

### NeuralEditor
- [S4] A method employing a point cloud-guided NeRF model for shape manipulation, leveraging K-D trees and deterministic integration strategy for accurate point cloud-based rendering, with Phong reflection modeling to enhance color fidelity and geometric detail.
- [S4] 1. Employ point cloud-guided NeRF model. 2. Leverage K-D trees. 3. Use deterministic integration strategy. 4. Achieve accurate point cloud-based rendering. 5. Apply Phong reflection modeling.

### Shared G-MLP
- [S5] A shared geometry MLP that enables the constraint of multi-view consistency to be propagated from the NeRF branch to the detection branch.
- [S5] Without the shared G-MLP, performance drops from 50.1 to 48.1 mAP@.25, as the influence of multi-view consistency is only propagated into the image backbone.

### NeRF with Frozen DINO Features
- [S6, unofficial] A NeRF variant that integrates pre-trained DINOv2 features by projecting them to match NeRF input dimensions and concatenating them with positional encodings before feeding into the NeRF MLP.
- [S6, unofficial] $f'(x) = W_f \cdot f(x) + b_f$ where $f(x)$ is the aggregated feature vector from all views, and $W_f, b_f$ are learned linear transformation parameters.
- [S6, unofficial] Input to NeRF MLP: $F_\theta([\gamma(x), \gamma(d), f'(x)]) \rightarrow (c, \sigma)$ where $f'(x)$ is projected to 256 dimensions.
- [S6, unofficial] Feature projection dimension: 256 (matching NeRF hidden units).
- [S6, unofficial] DINO Model: DINOv2-base, pre-trained on ImageNet, frozen during training.
- [S6, unofficial] Feature Extraction: DINOv2-base model outputs dense feature maps $F_i \in \mathbb{R}^{H \times W \times D}$ where $D=768$. Features are bilinearly sampled at projected 2D coordinates $(u_i, v_i) = \Pi(P_i, x)$ for each 3D point $x$.

### PlenOctree
- [S1] An approach achieving inference times approximately 3000 times faster than the original NeRF by training a spherical harmonic NeRF (NeRF-SH).
- [S1] Predict spherical harmonic coefficients of the color function instead of directly predicting color values.
- [S1] Construct an octree of precomputed spherical harmonic (SH) coefficients derived from the MLP’s colors.
- [S1] Voxelize the scene during octree construction.
- [S1] Eliminate voxels with low transmissivity.
- [S1] Apply this procedure to standard NeRF models by performing Monte Carlo estimations of the spherical harmonic components.
- [S1] Optimize PlenOctrees using initial training images via a fast fine-tuning procedure relative to NeRF training.
- [S1] Inference times approximately 3000 times faster than the original NeRF implementation.

## Background
The standard NeRF architecture, introduced by Mildenhall et al. [1], established the baseline of using two MLPs (coarse and fine) with positional encoding to map 3D coordinates and view directions to color and density [S1][S6, unofficial]. Subsequent research has focused on modifying this architecture to address limitations in training speed, geometric accuracy, semantic understanding, and dynamic scene representation [S1]. Early improvements included PlenOctree, which accelerated inference by 3000 times using spherical harmonics and octrees [S1], and FastNeRF, which factorized the color function for caching [S1]. Later works introduced generative models like NeRF-VAE [S1], physics-based simulations like PIE-NeRF [S1], and integration with vision transformers like DINO-enhanced NeRF [S6, unofficial]. The field has evolved to include hybrid explicit-implicit representations [15545-hybrid-explicit-implicit-representations.md], sparse view optimization [14428-sparse-view-and-few-shot-optimization.md], and federated learning approaches [15032-decentralized-federated-nerf.md].
