# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF is a text-driven stylization method for Neural Radiance Fields (NeRF) that optimizes the radiance field to match a target text description by minimizing the cosine distance between rendered image embeddings and text embeddings in the CLIP space [S2]. It distinguishes itself from standard NeRF training by replacing photometric reconstruction loss with a directional CLIP loss, allowing for semantic style transfer without requiring 3D ground-truth labels [S2]. The method addresses the trade-off between global semantic alignment and local detail preservation, often employing relative directional losses to prevent mode collapse [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A source NeRF model (initialized from source images), a target text prompt $\mathbf{t}_{tgt}$, and optionally a source text prompt $\mathbf{t}_{src}$ for relative loss.
*   **Outputs:** A stylized NeRF model where rendered views exhibit the semantic style of $\mathbf{t}_{tgt}$.

**Data Structures:**
*   **CLIP Encoder:** Uses the ViT-B/32 architecture [S1]. It takes an image or text input and outputs a normalized embedding vector $\hat{\mathbf{e}} \in \mathbb{R}^D$ (where $D=512$ for ViT-B/32) [S2].
*   **NeRF Model:** Follows the standard MLP structure defined in [Model Architecture and Encoding](13550-model-architecture-and-encoding.md), mapping $(\mathbf{x}, \mathbf{d})$ to density $\sigma$ and color $\mathbf{c}$ [S2].
*   **Patch Renderer:** Renders a $128 \times 128$ pixel patch from a randomly sampled camera pose [S1].

**Parameters:**
*   **Iterations:** 500 [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $1 \times 10^{-4}$ [S1].
*   **Patch Size:** $128 \times 128$ pixels [S1].
*   **Ray Sampling Stride:** 5 within the patch, resulting in a receptive field of $640 \times 640$ on the original image scale [S1].
*   **Importance Sampling Points:** 16 per ray during patch rendering [S1].
*   **Fine MLP Samples:** 64 coarse + 16 fine = 80 total samples per ray [S1].
*   **Freezing:** Sub-parameters related to density $\sigma$ are frozen; only color/feature parameters are optimized [S1].

**Loss Functions:**
Two variants of the directional CLIP loss are used [S2]:

1.  **Absolute Directional CLIP Loss:** Measures the cosine similarity between the normalized embedding of the rendered image $\mathbf{I}_{tgt}$ and the normalized embedding of the target text prompt $\mathbf{t}_{tgt}$ [S2].
    $$ \mathcal{L}_{dir}^{abs} = \sum_{r} \left( 1 - \langle \hat{\mathbf{e}}_i(\mathbf{I}_{tgt}), \hat{\mathbf{e}}_t(\mathbf{t}_{tgt}) \rangle \right) $$
    where $\langle \cdot, \cdot \rangle$ denotes the dot product of normalized vectors [S2].

2.  **Relative Directional CLIP Loss:** Measures the similarity between the *direction* of the stylization trajectory in CLIP space. It uses the difference between the rendered image embedding and the source image embedding, compared to the difference between the target text and source text embeddings [S2].
    $$ \mathcal{L}_{dir}^{rel} = \sum_{r} \left( 1 - \langle \hat{\mathbf{e}}_i(\mathbf{I}_{tgt}) - \hat{\mathbf{e}}_i(\mathbf{I}_{src}), \hat{\mathbf{e}}_t(\mathbf{t}_{tgt}) - \hat{\mathbf{e}}_t(\mathbf{t}_{src}) \rangle \right) $$
    where $\mathbf{I}_{src}$ is a rendered view from the source NeRF [S2].

**Algorithm:**
1.  Initialize NeRF from source data. Freeze density-related MLP weights [S1].
2.  For iteration $k = 1$ to 500:
    a. Sample a random camera pose from the training dataset [S1].
    b. Render a $128 \times 128$ patch $\mathbf{I}_{patch}$ using the current NeRF.
       i. Sample rays with stride 5 to cover the patch [S1].
       ii. For each ray, perform volume rendering with 16 importance sampling points (80 total samples including coarse) [S1].
    c. Resize $\mathbf{I}_{patch}$ via bilinear interpolation to match CLIP input resolution (typically $224 \times 224$) [S1].
    d. Compute embeddings:
       i. $\hat{\mathbf{e}}_i = \text{CLIP}_{img}(\mathbf{I}_{patch})$ [S1].
       ii. $\hat{\mathbf{e}}_t = \text{CLIP}_{txt}(\mathbf{t}_{tgt})$ [S1].
    e. Compute loss $\mathcal{L}_{dir}$ using either absolute or relative formula [S2].
    f. Backpropagate $\mathcal{L}_{dir}$ through the NeRF color/feature parameters only [S1].
    g. Update NeRF parameters using Adam with LR $10^{-4}$ [S1].

**Edge Cases and Pitfalls:**
*   **Memory Constraints:** Naive differentiable rendering of high-resolution images is intractable due to memory limits [S1]. The patch-based approach mitigates this [S1].
*   **Mode Collapse:** Absolute directional loss can cause mode collapse, reducing generation diversity [S2]. Relative loss is preferred for diversity [S2].
*   **Insufficient Magnitude:** Directional loss alone may fail to achieve sufficient stylization magnitude, resulting in weak style transfer [S2]. Global contrastive losses may be needed to enforce magnitude [S2].
*   **Local Inconsistency:** CLIP may focus on distinguishable regions, leading to excess stylization in some parts and insufficiency in others (e.g., eyes vs. faces) [S2].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of iterations (500) and the number of rays sampled per patch. Patch rendering is significantly faster than full-image rendering [S1].
*   **Memory Complexity:** Low, due to patch-based rendering ($128 \times 128$) and reduced sampling points (16) [S1].
*   **Strengths:** Enables text-driven 3D stylization without 3D annotations; computationally efficient via patch rendering [S1, S2].
*   **Limitations:** Prone to mode collapse (absolute loss) and insufficient stylization magnitude (directional loss alone) [S2]. Quality depends heavily on CLIP's ability to align 3D geometry with 2D text embeddings [S2].
*   **When to use:** When text-guided semantic stylization of a NeRF is required, and photometric fidelity to source images is secondary to semantic alignment [S2].

## Background
CLIPNeRF was introduced by Wang et al. in 2021, extending the StyleCLIP and StyleGAN-NADA frameworks to 3D radiance fields [S2]. It was designed to enable text-driven editing of NeRFs by leveraging the semantic alignment capabilities of the CLIP model [S2]. The method builds on the observation that CLIP embeddings can guide generative models toward specific semantic directions [S2].
