# Depth-Guided Robust and Fast Point Cloud Fusion NeRF

Also called: Ours, Point Cloud Fusion NeRF

## Overview
A NeRF framework for sparse input views that perceives radiance fields as an explicit voxel grid of features, constructs a point cloud for each input view, accumulates them into a fused point cloud, and refines depth inaccuracies by referencing the fused point cloud [S1]. Unlike DSNeRF which uses depth supervision but fails to account for inaccurate depth values, this method refines or substitutes inaccurate depth values using the fused point cloud from other views [S1]. Unlike DDP-NeRF which uses a depth completion network that may introduce more inaccurate depth values, this method directly uses sparse depth and refines it via fusion [S1]. Unlike SparseNeRF which renders from rough point clouds leading to low quality, this method uses point cloud fusion and voxel grid fine-tuning for robustness [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Sparse set of RGB-D images and their corresponding camera parameters [S1].
*   **Outputs:** A trained radiance field model capable of rendering novel views (RGB and depth) [S1].

**Data Structures:**
The radiance field is represented as an explicit 3D feature grid $G \in \mathbb{R}^{I \times J \times K}$, where $I, J, K$ are the resolutions along the X, Y, and Z axes respectively [S1]. This grid is segregated into two distinct components:
1.  **Geometry Grid ($G_\sigma$):** A single-channel grid $G_\sigma \in \mathbb{R}^{I \times J \times K}$ where values directly represent volume density $\sigma$ [S1].
2.  **Appearance Grid ($G_c$):** A multi-channel grid $G_c \in \mathbb{R}^{I \times J \times K \times P}$, where $P$ is the number of appearance feature channels [S1]. This grid stores neural features and spherical harmonics (SH) coefficients [S1].

**Numbered Steps:**

1.  **Point Cloud Construction:** Map the 2D pixels of each input view to 3D space using the sparse input RGB-D images and camera parameters to generate a point cloud for each individual view [S1].
2.  **Point Cloud Fusion:** Aggregate the point cloud from each input view to assemble a fused point cloud representing the entire scene [S1].
3.  **Density and Feature Encoding:** Convert the depth values from the input views into densities. Encode both depth and color information into the voxel grid utilizing two distinct sets of matrices and vectors [S1].
4.  **Voxel Value Computation:** For each shading location $x_w = (x, y, z)$, use sampled values from the vectors and matrices to compute the corresponding values of the tensor component within the feature grid [S1].
5.  **Color Regression:** Send the appearance values extracted from the grid to a decoding MLP $S$ for color regression [S1].
6.  **Loss Computation:** Compute the loss function composed of an RGB loss and a depth loss [S1].
7.  **Optimization:** Iteratively refine the planes and vectors during the training process, allowing the point cloud of the entire scene to guide the refinement of density and appearance [S1].

**Formulas and Definitions:**
*   **Radiance Field Model:** Establishes a relationship between a 3D location $x$ and a viewing direction $d$, yielding volume density $\sigma$ and view-dependent color $c$ [S1].
*   **Color Decoding Function $S$:** A small MLP that transforms an appearance feature vector in combination with a viewing direction $d$ into a color $c$ [S1]. The appearance grid $G_c$ comprises neural features and spherical harmonics (SH) coefficients which serve as inputs to $S$ [S1].
*   **Density Representation:** The values in the single-channel grid $G_\sigma$ directly represent the volume density $\sigma$ [S1].

**Parameters:**
*   $P$: Number of appearance feature channels in the appearance grid $G_c$ [S1].
*   $I, J, K$: Resolutions of the feature grid along the X, Y, and Z axes respectively [S1].

# Training Loop

    for image, depth_map, camera_params in input_views:
        # Step 3 & 4: Encode and sample
        # Convert depth to densities and encode into grid

        # For a ray r passing through the scene:
        samples = sample_along_ray(r)
        
        densities = []
        features = []
        
        for sample_point in samples:
            # Sample values from vectors and matrices to compute tensor component
            # This references the fused point cloud to refine inaccuracies
            sigma = sample_grid(G_sigma, sample_point)
            feature_vec = sample_grid(G_c, sample_point)
            
            densities.append(sigma)
            features.append(feature_vec)
            
        # Step 5: Color Regression

**Edge Cases and Pitfalls:**
*   **Depth Inaccuracies:** The method specifically addresses holes, artifacts, and inaccurate values in depth maps which are common in sparse inputs [S1]. Failure to fuse point clouds may lead to the propagation of these inaccuracies, similar to issues seen in DSNeRF [S1].
*   **Sparse Input Overfitting:** NeRFs generally demand numerous images; with sparse inputs, there is a risk of overfitting leading to inconsistencies or failure [S1]. The explicit voxel grid and point cloud fusion help mitigate this [S1].

## Operating characteristics
*   **Model Size:** The method is significantly smaller than PlenOctrees (1750 MB), SNeRG (1500 MB), Plenovels (1250 MB), DVGO (1000 MB), RegNeRF (750 MB), ViP-NeRF (300 MB), and DSNeRF (250 MB) on the LLFF dataset [S1].
*   **Training Time:** The method achieves significantly faster reconstruction times compared to PlenOctrees, SNeRG, Plenovels, DVGO, RegNeRF, ViP-NeRF, and DSNeRF on the LLFF dataset [S1].
*   **Strengths:** Superior rendering quality, faster reconstruction, and greater compactness due to effective vector-matrix decomposition and point cloud presentation [S1]. It is the first NeRF framework integrated with point cloud fusion [S1].
*   **Limitations:** Relies on the quality of the initial sparse RGB-D inputs and camera parameters. While it refines depth, it does not use a depth completion network, which might be a limitation if the initial depth is extremely sparse or noisy beyond the fusion capability.

## Background
This method was proposed to address issues in NeRFs for sparse input synthesis, specifically leveraging depth prior for geometric and spatial understanding while overcoming the low time efficiency and depth inaccuracies of existing works [S1]. It builds on the concept of explicit representations like TensoRF, employing a standard 3D grid $G \in \mathbb{R}^{I \times J \times K}$ [S1]. The work is cited as [S1] Depth-Guided Robust and Fast Point Cloud Fusion NeRF for Sparse Input Views.
