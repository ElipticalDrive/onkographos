# Voxel and Sparse Grid Representations

Also called: Grid-based Radiance Fields, Sparse Voxel Representations, Hash Encoding

## Overview
Voxel and Sparse Grid Representations replace the continuous multi-layer perceptron (MLP) of standard Neural Radiance Fields with discrete spatial structures (dense grids, sparse voxel trees, or hash tables) to store volume density and appearance features [S1, 11470-voxel-based-radiance-fields]. This substitution enables real-time differentiable volume rendering by eliminating the heavy computation of fully-connected layers for every sample point, instead computing color directly from interpolated grid values [S1, 11470-voxel-based-radiance-fields]. Unlike MLP-based NeRF, which requires evaluating a neural network for every ray sample, these methods leverage spatial locality and hardware-accelerated interpolation or hashing [11470-voxel-based-radiance-fields, 13013-neural-multi-view-image-reconstruction-with-hash-encoding].

## Shared principles
The core mechanism involves discretizing the 3D scene space into a structured or sparse grid. For any 3D point $\mathbf{x}$ queried during ray marching, the representation retrieves a feature vector $\mathbf{v}$ from the grid. This retrieval is typically performed via:
1.  **Trilinear Interpolation:** On dense or sparse voxel grids, the value is interpolated from the 8 nearest neighbors [11470-voxel-based-radiance-fields].
2.  **Hash Lookup:** On hash-encoded grids, spatial coordinates are hashed to indices in a table, and features are retrieved directly [13013-neural-multi-view-image-reconstruction-with-hash-encoding].

The retrieved features are then used to predict physical properties:
*   **Density ($\sigma$):** Often stored directly in a dedicated grid or derived from a Signed Distance Function (SDF) [11470-voxel-based-radiance-fields, 13013-neural-multi-view-image-reconstruction-with-hash-encoding].
*   **Color ($\mathbf{c}$):** Stored as Spherical Harmonic (SH) coefficients or raw RGB values, or predicted by a small MLP conditioned on the grid features and view direction [11470-voxel-based-radiance-fields, 14134-lightning-nerf].

Rendering follows the standard differentiable volume rendering equation:
$$
\hat{C}(r) = \sum_{k=1}^{N} w_k \mathbf{c}_k, \quad w_k = T_k \alpha_k, \quad T_k = \prod_{j=1}^{k-1} (1 - \alpha_j)
$$
where opacity $\alpha_k = 1 - e^{-\sigma_k \delta_k}$ [11470-voxel-based-radiance-fields].

## Subtopics

### [Voxel-based Radiance Fields](11470-voxel-based-radiance-fields.md)
Replaces the MLP with two dense 3D voxel grids (density and SH coefficients). It enables real-time rendering by directly interpolating grid values, eliminating feed-forward neural operations.

### [Neural Multi-View Image Reconstruction with Hash Encoding](13013-neural-multi-view-image-reconstruction-with-hash-encoding.md)
Uses a multi-resolution hash grid for geometry (SDF) and a separate light field network for color. It distinguishes itself by using a sparse hash grid instead of dense voxels and employing a specific SDF thresholding strategy for invalid point elimination.

### [G-NeLF](13480-g-nelf.md)
A grid-based Neural Light Field method that predicts ray color directly without point-wise volume density modeling. It uses a hash-based multi-resolution tri-plane and an LSTM decoder to capture view-dependent appearance with significantly fewer parameters than standard NeRF.

### [Lightning NeRF](14134-lightning-nerf.md)
An efficient hybrid representation for autonomous driving using explicit voxel grids for density (initialized with LiDAR) and implicit MLPs for color. It splits the scene into foreground and background, using inverse cubic modeling for the unbounded background.

### [TriDF](14761-tridf.md)
A hybrid explicit–implicit representation for few-shot novel view synthesis. It decouples color (stored in explicit triplanes) and volume density (predicted by an implicit MLP) to reduce computational burden and accelerate reconstruction from sparse views.

### SNeRG Rendering Pipeline
*   **Definition:** A real-time rendering pipeline that stores a NeRF model in a sparse 3D voxel grid, using an indirection grid to skip empty regions and a deferred MLP to compute view-dependent color from accumulated diffuse and specular features [S1].
*   **Step:** Raymarch along $r(t) = o + td$. For occupied voxels, set step size $\delta_i$ equal to the voxel width [S1]. Concatenate accumulated diffuse color $C_d$, accumulated specular feature $F_s$, and positional encoding $PE(\mathbf{d})$ of the ray's view direction $\mathbf{d}$. Pass through a lightweight deferred MLP $\Phi$ to produce a view-dependent residual color [S1].
*   **Formula:** $w_i = \prod_{j=1}^{i-1} (1 - \alpha_j) \alpha_i$, where $w_i$ is the accumulated weight for sample $i$ [S1].

### KiloNeRF-style Grid Distillation
*   **Definition:** Distills a large teacher NeRF into a spatially partitioned grid of tiny MLPs to enable fast, adaptive evaluation by mapping 3D positions to local student networks [S2, unofficial].
*   **Step:** Initialize a dictionary mapping 3D grid cell indices $(i,j,k)$ to TinyMLP instances. For each training iteration, sample a random ray and generate `num_samples` stratified samples along it. Compute the grid cell index for each sample by normalizing its position within the bounding box and scaling by grid resolution. Accumulate L2 loss between student and teacher outputs across all samples. Update all grid MLPs using the accumulated loss and the configured learning rate [S2, unofficial].
*   **Parameter:** `grid_resolution`: 3D tuple defining the number of cells per axis, e.g., $(16,16,16)$. `num_distill_iterations`: Number of distillation optimization steps, e.g., 1000. `num_samples`: Number of stratified samples per ray, e.g., 384. `learning_rate`: Optimization step size for grid MLP updates, e.g., $1e-3$. `bmin`, `bmax`: Axis-aligned bounding box defining the scene bounds, e.g., $[0,0,0]$ and $[1,1,1]$ [S2, unofficial].

## Background
The shift from continuous MLPs to discrete grid representations was driven by the need for real-time rendering and reduced memory footprint. Early works like SNeRG and MERF demonstrated that storing radiance field attributes in sparse voxel grids or hybrid structures could achieve real-time performance on standard hardware [S1]. SNeRG precomputed attributes in a sparse 3D voxel grid, using an indirection grid to enhance rendering by skipping empty regions [S1]. MERF optimized the balance between performance and memory efficiency by leveraging hybrid low-resolution sparse voxels and high-resolution 2D triplanes [S1]. Hash encoding, popularized by Instant-NGP and adapted in methods like Neural Multi-View Image Reconstruction, introduced multi-resolution hash tables to efficiently store high-frequency details without the memory overhead of dense grids [13013-neural-multi-view-image-reconstruction-with-hash-encoding]. G-NeLF further explored grid-based representations by using tri-planes and recurrent networks to model light fields directly [13480-g-nelf.md]. Lightning NeRF applied these concepts to large-scale autonomous driving scenes, integrating LiDAR data for initialization [14134-lightning-nerf.md]. TriDF focused on few-shot scenarios, decoupling geometry and color to handle sparse input views effectively [14761-tridf.md].
