# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF training configuration defines the optimization procedure for text-guided stylization of Neural Radiance Fields (NeRFs) by minimizing the negative cosine similarity between rendered image embeddings and text prompt embeddings in the CLIP latent space [S1, S2]. It distinguishes itself from standard NeRF reconstruction by freezing density parameters and optimizing only color/feature networks to enforce a specific stylistic trajectory, utilizing patch-based rendering to manage memory constraints [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A pre-trained NeRF model (initialized from a source scene), a target text prompt $\mathbf{t}_{tgt}$, and optionally a source text prompt $\mathbf{t}_{src}$ for relative loss.
*   **Outputs:** Updated NeRF parameters (specifically color/feature networks) that produce stylized renderings.

**Data Structures:**
*   **CLIP Encoder:** Uses CLIP ViT-B/32 [S1]. The image encoder $\mathcal{E}_i$ and text encoder $\mathcal{E}_t$ output normalized embedding vectors.
*   **NeRF Model:** Follows the standard MLP structure defined in [Parent], but density parameters are frozen during this phase.

**Loss Functions:**
Two variants of directional CLIP loss are defined [S2]:

1.  **Absolute Directional CLIP Loss:** Measures the cosine similarity between the rendered image embedding and the target text embedding.
    $$ \mathcal{L}_{dir} = \sum_{r} \left( 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) \rangle \right) $$
    where $\mathbf{I}_{tgt}$ is the rendered image, $\hat{\mathcal{E}}$ denotes normalized embeddings, and $\langle \cdot, \cdot \rangle$ is the dot product [S2].

2.  **Relative Directional CLIP Loss:** Transfers style from a source domain to a target domain by measuring the trajectory between embeddings.
    $$ \mathcal{L}_{dir} = \sum_{r} \left( 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}) - \hat{\mathcal{E}}_i(\mathbf{I}_{src}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) - \hat{\mathcal{E}}_t(\mathbf{t}_{src}) \rangle \right) $$
    where $\mathbf{I}_{src}$ is a rendering of the source NeRF and $\mathbf{t}_{src}$ is the source text prompt [S2].

**Parameters:**
*   **Iterations:** 500 [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $0.0001$ [S1].
*   **Text Encoder:** CLIP ViT-B/32 [S1].
*   **Patch Size:** $128 \times 128$ pixels [S1].
*   **Ray Sampling Stride:** 5 within the patch, resulting in a receptive field of $640 \times 640$ on the original image resolution [S1].
*   **Importance Sampling Points:** 16 per ray during patch rendering [S1].
*   **Fine MLP Samples:** 80 total (64 coarse + 16 fine) [S1].

**Algorithm:**
1.  Initialize NeRF parameters. Freeze all parameters related to density $\sigma$ [S1].
2.  For iteration $k$ from 1 to 500:
    a. Randomly sample a camera pose from the training dataset [S1].
    b. Render a $128 \times 128$ patch of the image $\mathbf{I}_{patch}$ using the current NeRF.
       i. Sample rays with stride 5 to cover the patch.
       ii. Perform volume rendering with 16 importance sampling points per ray [S1].
    c. Resize $\mathbf{I}_{patch}$ via bilinear interpolation to match CLIP input resolution [S1].
    d. Compute embeddings: $\mathbf{e}_i = \mathcal{E}_i(\mathbf{I}_{patch})$ and $\mathbf{e}_t = \mathcal{E}_t(\mathbf{t}_{tgt})$ [S1].
    e. Compute loss $\mathcal{L}_{dir}$ using Equation 3 or 4 [S2].
    f. Backpropagate $\mathcal{L}_{dir}$ to update only the non-density parameters of the NeRF [S1].

**Edge Cases and Pitfalls:**
*   **Memory Constraints:** Naive differentiable rendering of high-resolution images is intractable due to memory limits [S1]. The patch-based approach is required.
*   **Mode Collapse:** Absolute directional CLIP loss can cause mode collapse of the generator and reduce generation diversity [S2].
*   **Insufficient Magnitude:** Directional loss alone may struggle to reach sufficient stylization magnitude, resulting in weak style transfer, as it ignores the distance between vectors [S2].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of iterations (500) and the number of rays sampled per patch. The patch-based approach reduces per-step memory but requires multiple steps to cover the full image if global consistency is needed.
*   **Memory Complexity:** Significantly reduced compared to full-image rendering. By rendering only $128 \times 128$ patches with 16 samples, VRAM usage is kept low enough for standard GPUs [S1].
*   **Strengths:** Enables text-guided stylization of 3D scenes; computationally feasible for high-resolution scenes via patching [S1].
*   **Limitations:** May produce uneven stylization (excess in some parts, insufficient in others) because CLIP focuses on distinguishable regions [S2]. Absolute loss risks mode collapse [S2].
*   **When to use:** When text-guided artistic stylization of an existing NeRF is required.
*   **When not to use:** When high-fidelity photorealistic reconstruction is the primary goal (standard NeRF loss is better) or when global style magnitude consistency is critical without additional contrastive losses [S2].

## Background
The method originates from CLIP-NeRF [Wang et al. 2021a], which extended StyleCLIP [Patashnik et al. 2021] to 3D. It was further refined in NeRF-Art [S2] to address issues with style magnitude and diversity using relative directional loss and global-local contrastive learning. The implementation details cited in [S1] are derived from the repository https://github.com/kwea123/ngp_pl.
