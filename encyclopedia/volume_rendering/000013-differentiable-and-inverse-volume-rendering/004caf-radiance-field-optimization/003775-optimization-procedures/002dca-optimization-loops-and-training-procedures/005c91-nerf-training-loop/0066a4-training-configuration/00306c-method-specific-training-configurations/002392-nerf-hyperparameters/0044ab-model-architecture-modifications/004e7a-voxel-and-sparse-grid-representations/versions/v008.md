# Voxel and Sparse Grid Representations

Also called: Grid-based NeRF, Hash-Encoded NeRF, Triplane NeRF, Sparse Voxel Octree NeRF

## Overview
Voxel and Sparse Grid Representations replace the implicit multi-layer perceptron (MLP) coordinate-to-color mapping of standard NeRF with explicit spatial data structures, such as 3D voxel grids, hash tables, or triplanes, to store features directly in space [S1]. This approach solves the computational bottleneck of evaluating deep networks for every sample point, enabling real-time rendering and significantly reducing memory usage through sparse reconstruction strategies [S1]. Unlike MLP-based approaches that require heavy feed-forward computation for every sample, these methods compute color and density directly from interpolated grid values or lookups [S1].

## Shared principles
The core mechanism involves discretizing the 3D scene space into a structured or hash-mapped grid where each cell (or hash entry) stores a feature vector. These features typically encode volume density $\sigma$ and appearance information (e.g., spherical harmonic coefficients for view-dependent color).

For any query point $\mathbf{x}$, the system retrieves features from the grid. In dense voxel grids, this is done via trilinear interpolation from the 8 nearest neighbors. In hash-based grids, continuous coordinates are hashed to discrete indices, and features are retrieved from the corresponding table entries, often with bilinear interpolation in 2D projections (triplanes) or direct lookup.

The rendering pipeline remains differentiable volume rendering:
$$
\hat{C}(r) = \sum_{k=1}^{N} w_k \mathbf{c}_k, \quad w_k = T_k \alpha_k, \quad T_k = \prod_{j=1}^{k-1} (1 - \alpha_j)
$$
where $\alpha_k = 1 - e^{-\sigma_k \delta_k}$ [S1]. The gradients flow back through the interpolation/lookup operations to update the grid features.

## Subtopics

### [Voxel-based Radiance Fields](11470-voxel-based-radiance-fields.md)
Replaces the MLP with explicit 3D voxel grids for density and spherical harmonic (SH) coefficients. It computes color directly from interpolated grid values, reducing latency while maintaining memory efficiency via sparse reconstruction.

### [Neural Multi-View Image Reconstruction with Hash Encoding](13013-neural-multi-view-image-reconstruction-with-hash-encoding.md)
Combines hash-encoded spatial representation with an SDF geometry network. It solves the problem of reconstructing high-frequency geometric details and textureless areas where traditional volume density-based methods fail. It uses a multi-resolution hash table and mean SDF thresholding for faster training and lower memory usage compared to NeuS/IDR.

### [G-NeLF](13480-g-nelf.md)
A grid-based Neural Light Field method that predicts ray color directly without explicit point-wise volume density modeling. It uses a hash-based multi-resolution tri-plane decoded by an LSTM. It trains end-to-end from original views only, achieving comparable performance to grid-based NeRFs with ~1/10th the parameters.

### [SCALAR-NeRF](14267-scalar-nerf.md)
A coarse-to-fine framework for scalable large-scale neural scene reconstruction. It structures the representation as an encoder-decoder architecture to avoid the 'foggy' issue in Block-NeRF. It decomposes scenes into blocks, trains a shared decoder from a coarse global model, and fuses local results using the global model.

### [TriDF](14761-tridf.md)
A hybrid explicit–implicit 3D representation for few-shot novel view synthesis. It decouples color and volume density: high-frequency color is mapped to explicit triplanes, while low-frequency geometry is modeled by implicit density fields. It accelerates reconstruction by 30× compared to NeRF-based methods.

### [Tile and Slide Framework](15219-tile-and-slide-framework.md)
An out-of-core method (Snake-NeRF) that scales NeRFs to large-scale Earth observation scenes by partitioning the region into non-overlapping 3D tiles, each trained with its own independent NeRF. It uses a 2×2 sliding window progression and segmented ray sampler to prevent boundary errors.

### SNeRG Rendering Pipeline
- **Definition:** A real-time rendering pipeline that stores a NeRF model in a sparse 3D voxel grid, using an indirection grid to skip empty regions and a deferred MLP to compute view-dependent color from accumulated diffuse and specular features [S1].
- **Step:** Raymarch along $r(t) = o + td$. For occupied voxels, set step size $\delta_i$ equal to the voxel width [S1]. Concatenate accumulated diffuse color $C_d$, accumulated specular feature $F_s$, and positional encoding $PE(\mathbf{d})$ of the ray's view direction $\mathbf{d}$. Pass through a lightweight deferred MLP $\Phi$ to produce a view-dependent residual color [S1].
- **Formula:** $w_i = \prod_{j=1}^{i-1} (1 - \alpha_j) \alpha_i$, where $w_i$ is the accumulated weight for sample $i$ [S1]. The final color is computed as $\boldsymbol{C}(\boldsymbol{r})=\boldsymbol{C}_d + \Phi (\boldsymbol{C}_d , \boldsymbol{F}_s, PE(\boldsymbol{d}))$ [S1].

### KiloNeRF-style Grid Distillation
- **Definition:** Distills a large teacher NeRF into a spatially partitioned grid of tiny MLPs to enable fast, adaptive evaluation by mapping 3D positions to local student networks [S2, unofficial].
- **Step:** Initialize a dictionary mapping 3D grid cell indices $(i,j,k)$ to TinyMLP instances [S2, unofficial]. For each training iteration, sample a random ray and generate `num_samples` stratified samples along it [S2, unofficial]. Compute the grid cell index for each sample by normalizing its position within the bounding box and scaling by grid resolution [S2, unofficial]. Accumulate L2 loss between student and teacher outputs across all samples [S2, unofficial]. Update all grid MLPs using the accumulated loss and the configured learning rate [S2, unofficial].
- **Parameter:** `grid_resolution`: 3D tuple defining the number of cells per axis, e.g., $(16,16,16)$ [S2, unofficial]. `num_distill_iterations`: Number of distillation optimization steps, e.g., 1000 [S2, unofficial]. `num_samples`: Number of stratified samples per ray, e.g., 384 [S2, unofficial]. `learning_rate`: Optimization step size for grid MLP updates, e.g., $10^{-3}$ [S2, unofficial]. `bmin`, `bmax`: Axis-aligned bounding box defining the scene bounds, e.g., $[0,0,0]$ and $[1,1,1]$ [S2, unofficial].

## Background
The shift from MLP-based NeRF to voxel/grid representations was driven by the need for real-time rendering and scalability to large scenes. SNeRG [13] and MERF [30] set benchmarks for real-time rendering by precomputing models in sparse 3D voxel grids [S1]. SNeRG uses an indirection grid to skip empty regions, while MERF combines low-resolution sparse voxels with high-resolution triplanes [S1]. Hash encoding, popularized by Instant-NGP, introduced multi-resolution hash tables to efficiently store features, a technique adopted by methods like Neural Multi-View Image Reconstruction [S1] and SCALAR-NeRF [S1]. Triplane representations, originally used for efficient 3D generation, were adapted for NeRFs (e.g., TriDF [S1]) to decouple geometry and appearance. Large-scale applications like City-on-Web [S1] and Snake-NeRF [S1] extended these concepts to urban-scale scenes using tiling and out-of-core processing.
