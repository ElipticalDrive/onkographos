# Model Architecture Modifications

Also called: NeRF Architecture Variants, Implicit Representation Modifications

## Overview
Model Architecture Modifications extend the standard Neural Radiance Field (NeRF) framework by altering the underlying neural network structure, input/output channels, or geometric representation to address specific limitations such as dynamic scenes, sparse inputs, lighting variations, or computational efficiency. Unlike standard NeRF, which uses a static MLP to map 3D coordinates and view directions to density and color, these modifications introduce auxiliary heads, discrete representations, or conditional encoders to enable tasks like depth-of-field simulation, semantic segmentation, or real-time rendering.

## Shared principles
The standard NeRF architecture  consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ .

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation .
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
    .
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs) .

## Subtopics

### [DoF-NeRF](9432-dof-nerf.md)
DoF-NeRF extends the standard NeRF architecture to simulate depth-of-field effects by introducing two learnable scalar parameters per training view: the aperture parameter $K$ and the focus distance $F$. These parameters are jointly optimized with the NeRF network parameters to enable the synthesis of all-in-focus novel views from shallow depth-of-field inputs. It is chosen when the input data contains optical blur due to finite aperture size and the goal is to recover a sharp 3D representation.

### [NeRF-VPT](11770-nerf-vpt.md)
NeRF-VPT modifies the NeRF architecture into a cascading view prompt tuning paradigm. It uses the RGB output from a preceding stage as a visual prompt concatenated with the direction encoding for subsequent stages. This plug-and-play modification enhances image quality in sparse-view settings by leveraging internal network outputs as prior knowledge, without requiring external networks or specific data preprocessing.

### [Activation Feature Density Approximation](12492-activation-feature-density-approximation.md)
This method estimates volumetric density $\hat{d}$ directly from intermediate activation features $\mathbf{f}_\ell$ of the coarse MLP, replacing expensive coarse network evaluations with lightweight statistical computations (mean and standard deviation of activations). It differs from SDF-based methods by retaining the standard density-based rendering formulation while optimizing the density prediction step itself.

### [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md)
SDF representations replace the standard NeRF density field $\sigma(\mathbf{x})$ with a continuous scalar field $s(\mathbf{x})$ representing the distance to the nearest surface, defining geometry via the zero-level set $\{\mathbf{x} \mid s(\mathbf{x}) = 0\}$. This substitution addresses geometric inaccuracy and surface holes typical of density-based NeRFs by providing a more explicit and smooth formulation of surfaces.

### [Volume-Augmented NeRF](12973-volume-augmented-nerf.md)
Volume-Augmented NeRF binds an explicit fluid volume value $v_i$ to each sample point, allowing the renderer to learn density and color based on the spatial distribution provided by a differentiable fluid simulator. It serves as the rendering component in a joint differentiable framework for dynamic fluid scenes, bridging a neural Euler simulator and the radiance field.

### [Neural-PIL Decomposition Architecture](12975-neural-pil-decomposition-architecture.md)
This architecture separates scene estimation into distinct networks: a coarse network for density and color, and a decomposition network for density and a BRDF embedding $\mathbf{z}_b$. It uses frozen auto-encoders for illumination and BRDF encoding, enabling explicit reflectance decomposition and relighting in scenes with varying illumination.

### [SAID-NeRF](13619-said-nerf.md)
SAID-NeRF decomposes appearance into view-independent diffuse and view-dependent specular components and adds a segmentation head to output semantic probabilities. It uses instance masks from Visual Foundation Models to enforce higher surface densities for transparent objects, resulting in sharper depth estimates. It builds on Instant-NGP for encoding and Semantic and Feature Branches for joint optimization.

### [MINE](13661-mine.md)
MINE models the frustum of the source camera using a continuous depth Multiplane Image (MPI) representation, conditioned on input images via a fully-convolutional decoder. Unlike pixelNeRF and GRF, which model the entire 3D space per ray, MINE reconstructs the frustum per plane, allowing rendering of any target view via homography warping after a single encoder pass and a fixed number of decoder passes.

### [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md)
This family replaces the continuous MLP function with discrete, spatially structured data structures (dense voxels, sparse grids, hash tables, or triplanes) to store volume density and appearance features. This substitution enables memory-efficient training and real-time differentiable volume rendering by retrieving values via interpolation or hashing instead of neural inference.

### [Aleth-NeRF](13764-aleth-nerf.md)
Aleth-NeRF introduces a 'Concealing Field' assumption where air particles attenuate emission, modeling illumination adaptive volume rendering through local and global concealing fields. It enables the synthesis of normal-light views from low-light or over-exposed inputs without paired training data, operating on standard 8-bit LDR images.

### [Unified Volumetric Avatar (UVA)](13784-unified-volumetric-avatar-uva.md)
UVA anchors structured latent codes to a deformable mesh in canonical space, enabling local and independent editing of geometry and texture for dynamic human avatars. Unlike pre-defined UV mapping methods, UVA is end-to-end trainable and jointly optimized with the skinning field from scratch.

### [Gear-NeRF](13848-gear-nerf.md)
Gear-NeRF uses a series of 4D feature volumes, one per motion-based 'gear' level, to stratify the scene into regions with specific spatio-temporal sampling resolutions. It leverages semantic information to assign higher resolution to regions with larger motion scales, solving the inefficiency of uniform 4D sampling in dynamic scenes.

### [Transformer and Vision Model Integration](13911-transformer-and-vision-model-integration.md)
This family integrates Vision Transformers (ViT) and general Transformer architectures into NeRF to leverage global semantic understanding and long-range dependencies. It solves the limitations of standard MLP-based NeRFs by either generalizing across scenes without per-scene tuning or explicitly modeling self-occlusion via attention mechanisms.

### [Human and Specific Subject Modeling](13997-human-and-specific-subject-modeling.md)
This family extends standard NeRF architectures to handle non-rigid deformation with topological changes and hierarchical scene structures, respectively. [HyperNeRF](13906-hypernerf.md) models non-rigidly deforming scenes by lifting the canonical 3D space into a higher-dimensional ambient space. [Strata-NeRF](14015-strata-nerf.md) models stratified scenes by replacing continuous positional encoding inputs with discrete latent codes.

### [OPONeRF](14014-oponerf.md)
OPONeRF dynamically conditions the network weights $\Theta$ on the point's representation $\mathbf{x}$ and the overall scene representation $\mathbf{F}$, subdividing the scene to discriminatively respond to local variations. This approach provides more expressiveness and flexibility than methods that model static appearance as stochastic variables.

### [Mixer-NeRF](14073-mixer-nerf.md)
Mixer-NeRF introduces a hybrid spatial feature learning module (MLCA) and a squeeze-and-excitation (SE) network module to explicitly mix spatial and channel features before the main MLP inference. It addresses the loss of local information and blurry details in standard NeRF by capturing high-frequency details more effectively.

### [Sparse View and Few-Shot Optimization](14428-sparse-view-and-few-shot-optimization.md)
This family addresses severe overfitting and geometry breakdown in NeRF trained with drastically reduced input viewpoints ($|S| < 20$). Techniques include in-situ regularization, deformable sampling strategies, or pseudo-observation densification, setting them apart from generalized sparse NeRFs that require large-scale pre-training.

### [Mixture-of-Experts and Modular Architectures](14429-mixture-of-experts-and-modular-architectures.md)
This family replaces or augments the single continuous function of standard NeRF with multiple specialized networks (experts) or parallel processing streams. It solves the limitations of conventional Implicit Neural Representations (INRs) by explicitly partitioning the input domain or ray batch among distinct neural modules to improve compression, training speed, or representation capacity(13765-mixture-of-experts-implicit-neural-representation.md).

### [Uncertainty and Reliability](14487-uncertainty-and-reliability.md)
Uncertainty and Reliability methods extend standard NeRF architectures to quantify prediction confidence, modeling the scene as a probabilistic entity to provide pixel-level reliability metrics for color and depth. This enables robust filtering and conformal prediction, distinguishing it from deterministic NeRF variants.

### [Object Decomposition and Composition](14518-object-decomposition-and-composition.md)
Object Decomposition and Composition methods extend standard NeRF architectures to explicitly separate a scene into distinct semantic or geometric object instances, enabling instance-level editing and amodal segmentation. This family is distinguished by its primary focus on structural decomposition for editing rather than just appearance or semantic labeling.

### [Lighting and Appearance Models](14522-lighting-and-appearance-models.md)
Lighting and Appearance Models modify the standard NeRF architecture to explicitly represent or control illumination and material properties, decoupling geometry, albedo, and illumination [Parent]. They set themselves apart from sibling methods like [NeRF in the Wild (NeRF-W)](11995-nerf-in-the-wild-nerf-w.md) by using explicit mathematical bases or neural modules for light [Parent].

### [Optimization and Training Procedures](14565-optimization-and-training-procedures.md)
This family covers algorithmic procedures for optimizing NeRF, ranging from standard training loops to specialized acceleration and editing techniques. Unlike standard gradient descent, methods often employ structural modifications to the optimization scope, such as skipping expensive fine-pass evaluations for empty rays or restricting updates to specific network layers.

### [Image Enhancement and Restoration Methods](14566-image-enhancement-and-restoration-methods.md)
Image Enhancement and Restoration Methods integrate restoration mechanisms directly into the NeRF optimization loop to address degradation such as blur, transient occlusions, or low resolution. They differ from sibling methods by focusing on specific degradation types, often using 2D priors to guide 3D consistency.

### [Modular, Hierarchical, and Latent Architectures](14567-modular-hierarchical-and-latent-architectures.md)
This family extends standard NeRF architectures to handle non-rigid deformation with topological changes and hierarchical scene structures. [HyperNeRF](13906-hypernerf.md) models non-rigidly deforming scenes by lifting the canonical 3D space into a higher-dimensional ambient space. [Strata-NeRF](14015-strata-nerf.md) models stratified scenes by replacing continuous positional encoding inputs with discrete latent codes.

### [MuRF (Multi-Baseline Radiance Fields)](15007-murf-multi-baseline-radiance-fields.md)
MuRF is a feed-forward method that constructs a **target view frustum volume** aligned with the target camera rather than a reference input view, using a **3D context-aware convolutional decoder**. This approach effectively aggregates multi-view information even when overlap between input and target views is small.

### [Gaussian and Primitive-Based Representations](15011-gaussian-and-primitive-based-representations.md)
This family replaces the continuous MLP radiance field with discrete geometric primitives or explicit Gaussian distributions to improve rendering efficiency and geometric fidelity. It differs from sibling methods like [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md) by using analytic primitives rather than voxel grids, and from [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md) by relying on alpha-blended primitives.

### [Decentralized Federated NeRF](15032-decentralized-federated-nerf.md)
Decentralized Federated NeRF (DecentNeRF) distributes training computation to users and aggregates only global radiance field models to minimize server compute and personal data leakage. It explicitly decomposes the scene into global and personal radiance fields per user and employs a learned weighted aggregation protocol with Secure Multi-Party Computation (SMPC).

### [Neural Proxy](15220-neural-proxy.md)
Neural Proxy represents photo-realistic targets as animatable proxies, combining neural volume rendering with neural texture by injecting an animatable mesh proxy into the scene. Unlike NeRF, which ties content to continuous Cartesian coordinates, Neural Proxy allows particles to move with the animated proxy geometry.

### [ViSNeRF](15255-visnerf.md)
ViSNeRF solves the scalability problem of representing high-dimensional $(3+K)$-D radiance fields by combining explicit feature grids with implicit MLP decoders and applying generalized tensor factorization. It factorizes the static 3D spatial volume into vector-matrix components and the $K$-D parameter space into CP components, reducing memory complexity.

### [EBAD-NeRF](15441-ebad-nerf.md)
EBAD-NeRF reconstructs sharp 3D radiance fields from motion-blurred images by jointly optimizing learnable camera poses and NeRF parameters using hybrid event-RGB data. It models complex camera motion trajectories with multiple learnable poses rather than linear interpolation or fixed pre-estimated poses.

### [Network Architectures](15530-network-architectures.md)
This article details specific modifications to the standard NeRF network architecture, focusing on parameter scaling, auxiliary heads, and input/output expansions. It serves as a catalog of structural variations used to improve training efficiency, enable auxiliary tasks, or reduce memory footprint.

### [Point-NeRF Representation](15538-point-nerf-representation.md)
Point-NeRF replaces the continuous MLP function with a discrete neural point cloud to model a continuous volumetric radiance field. This approach avoids ray sampling in empty space by leveraging classical point clouds that approximate scene geometry, allowing for faster optimization and higher-quality rendering.

### [NeurMiPs](15543-neurmips.md)
NeurMiPs represents a 3D scene as a mixture of $K$ learnable rectangular planar surfaces, where each surface acts as an independent "expert" predicting view-dependent color and transparency. It alleviates the frontal-parallel limitation of traditional MPI while maintaining high efficiency through analytical ray-plane intersection.

### [CodeNeRF](15544-codenerf.md)
CodeNeRF is an implicit 3D neural representation that learns the variation of object shapes and textures across a semantic category, enabling the synthesis of novel views of unseen objects from a single unposed input image. It disentangles shape and texture by learning separate latent embeddings, allowing for one-shot reconstruction and explicit editing.

### [Hybrid Explicit-Implicit Representations](15545-hybrid-explicit-implicit-representations.md)
Hybrid explicit-implicit representations combine discrete geometric structures (such as triangle meshes or voxel grids) with continuous neural fields (such as MLPs or hash tables) to optimize the trade-off between rendering speed, storage efficiency, and geometric fidelity. This approach addresses the limitations of pure implicit models, which suffer from slow ray-marching inference, and pure explicit models, which struggle with complex, non-manifold geometry.

### [Dynamic Scene and Temporal Modeling](15546-dynamic-scene-and-temporal-modeling.md)
Dynamic Scene and Temporal Modeling extends static NeRF to reconstruct and render 4D scenes that change over time by conditioning the radiance field on time or temporal dynamics. Unlike static methods, these approaches must model the deformation of geometry or the evolution of appearance across frames.

### [NeRF-Casting](15547-nerf-casting.md)
NeRF-Casting synthesizes photorealistic specular appearance and reflections by integrating ray tracing into the NeRF rendering pipeline. It casts reflection rays from points along camera rays into the NeRF geometry to render feature vectors, which are then decoded into color, avoiding the need for the MLP to represent the full environment at every point.

### [RoseNeRF](15548-rosenerf.md)
RoseNeRF simplifies complex ray interactions inside transparent media to a single refraction event by predicting a refracted ray using a 4D light field representation and a refraction network. It avoids the need for Index of Refraction (IoR) fields or detailed surface reconstructions by predicting the refracted ray and using hierarchical sampling.

### [NeRF-Det](15549-nerf-det.md)
NeRF-Det explicitly models scene geometry as an opacity field by jointly training a NeRF branch with a 3D detection pipeline. It improves upon the "NeRF-then-Det" paradigm by integrating multi-view geometry constraints from the NeRF branch into 3D detection through a shared geometry MLP, enabling end-to-end training without per-scene optimization.

### [Dynamic Appearance Particle Neural Radiance Field](15550-dynamic-appearance-particle-neural-radiance-field.md)
DAP-NeRF models dynamic scenes from monocular video data by combining a static grid-based radiance field with a particle-based dynamic component. It applies appearance particles only to dynamic elements and uses a grid-based field for efficient querying via linear interpolation, avoiding the need for multi-view stereo data.

### [Semantic and Feature Field Extensions](15556-semantic-and-feature-field-extensions.md)
This family extends standard NeRF architectures to include semantic labels and feature fields alongside color and density. These auxiliary outputs are rendered using the same transmittance weights and opacity as color, enabling tasks such as semantic segmentation and feature-based editing.

#### NeRF-VAE
- **Definition:** A generative NeRF model that generalizes to out-of-distribution scenes and removes the need to train on each scene from scratch [S1].
- **Steps:** The NeRF renderer is conditioned on a latent code trained using Iterative Amortized Inference and a ResNet encoder. An attention-based scene function is introduced instead of the typical MLP [S1].
- **Comparison:** Outperforms baseline NeRF with a low number of scene views (5-20), but is outperformed by baseline NeRF when a large number of views are available (100+) due to lower scene expressivity [S1].

#### PIE-NeRF
- **Definition:** A pipeline integrating physics-based elastodynamic simulation with a neural radiance field representation, using a meshless discretisation based on quadratic generalized moving least squares on top of the density field of a NeRF [S1].
- **Steps:** Enables large deformations and nonlinear hyperelastic material simulation directly on the implicit representation and supports interactive manipulation of real-world captured scenes with complex geometries [S1].

#### DäRF Implementation Details
- **Parameters:** NeRF Backbone: K-planes [36]. MDE Model: DPT-hybrid [38]. Optimizer: Adam [21]. NeRF Learning Rate: 1e-2. MDE Learning Rate: 1e-5. LR Schedule: Cosine warmup [S2, unofficial].

#### NeRF Model Architecture
- **Definition:** The neural network architecture for NeRF, consisting of dense layers with ReLU activations, potentially using view directions as input [S3, unofficial].
- **Parameters:** `D`: The depth of the network (number of hidden layers). Default is 8. `input_ch_views`: The number of input channels for view directions. Default is 3. `output_ch`: The number of output channels. Default is 4 (RGB + density). `use_viewdirs`: Boolean flag to determine if view directions are used as input to the network [S3, unofficial].

#### S3-NeRF
- **Definition:** A method using shadow and shading cues to infer scene geometry and enable single-image NeRF training [S1].
- **Steps:** Employ a UNISURF-based occupancy field 3D representation instead of density. Use a modified physics-based rendering equation. Use occupancy-based shadow calculation [S1].

#### NeuralEditor
- **Definition:** A method employing a point cloud-guided NeRF model for shape manipulation, leveraging K-D trees and deterministic integration strategy for accurate point cloud-based rendering, with Phong reflection modeling to enhance color fidelity and geometric detail [S4].
- **Steps:** 1. Employ point cloud-guided NeRF model. 2. Leverage K-D trees. 3. Use deterministic integration strategy. 4. Achieve accurate point cloud-based rendering. 5. Apply Phong reflection modeling [S4].

#### PlenOctree
- **Definition:** An approach achieving inference times approximately 3000 times faster than the original NeRF by training a spherical harmonic NeRF (NeRF-SH) [S1].
- **Steps:** Predict spherical harmonic coefficients of the color function instead of directly predicting color values. Construct an octree of precomputed spherical harmonic (SH) coefficients derived from the MLP’s colors. Voxelize the scene during octree construction. Eliminate voxels with low transmissivity. Apply this procedure to standard NeRF models by performing Monte Carlo estimations of the spherical harmonic components. Optimize PlenOctrees using initial training images via a fast fine-tuning procedure relative to NeRF training [S1].
- **Number:** Inference times approximately 3000 times faster than the original NeRF implementation [S1].

## Background
The standard NeRF architecture, introduced by Mildenhall et al. in 2020, established the baseline for neural radiance fields using two MLPs for coarse and fine rendering [S1]. Subsequent research has focused on modifying this architecture to address limitations in training speed, geometric accuracy, dynamic scene representation, and generalization. Early improvements included PlenOctree, which accelerated inference by 3000 times using spherical harmonics and octrees [S1]. Generative approaches like NeRF-VAE introduced latent codes and attention mechanisms to generalize across scenes [S1]. More recent modifications have integrated vision transformers, discrete representations like voxels and SDFs, and specialized heads for semantic and lighting decomposition to enable a wider range of 3D vision tasks [S1].
