# NeRF with Time Parameter

Also called: NeRF + time, NeRF with Time Parameter Baseline, Time-NeRF

## Overview
This method adapts the static Neural Radiance Field (NeRF) architecture to handle dynamic scenes by augmenting the input domain with a temporal coordinate $t$ [S1]. It solves the problem of rendering novel views of non-static environments by allowing the density and color fields to vary over time [S1]. Unlike advanced dynamic NeRF variants that employ canonical space warping or explicit deformation fields, this approach treats time as a direct input feature, serving as a baseline for temporal modeling [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A 4D query tuple $(\mathbf{x}, \mathbf{d}, t)$, where $\mathbf{x} \in \mathbb{R}^3$ is the spatial position, $\mathbf{d} \in \mathbb{R}^3$ is the viewing direction, and $t \in \mathbb{R}$ is the time coordinate [S1].
*   **Outputs:** Volume density $\sigma$ and view-dependent color $\mathbf{c}$ [S1].

**Data Structures:**
The model uses a Multi-Layer Perceptron (MLP) identical to the standard NeRF architecture, but with an expanded input dimension. The positional encoding function $\gamma$ is applied to both spatial coordinates and the time parameter [S1].

**Steps:**
1.  **Positional Encoding of Time:** Apply the positional encoding function $\gamma_t$ to the time parameter $t$. The specific frequency bands are typically consistent with the spatial encoding used in the base NeRF [S1].
2.  **Concatenation:** Concatenate the encoded time $\gamma_t(t)$ with the encoded spatial coordinates $\gamma_x(\mathbf{x})$ to form the combined spatial-temporal input vector [S1].
    $$ \mathbf{z}_{input} = [\gamma_x(\mathbf{x}); \gamma_t(t)] $$
3.  **Network Forward Pass:** Feed $\mathbf{z}_{input}$ and the viewing direction $\mathbf{d}$ into the MLP. The MLP outputs the density $\sigma$ and the color $\mathbf{c}$ conditioned on the specific time $t$ [S1].
4.  **Volume Rendering:** Render the image using the standard volume rendering equation, where density and color are functions of time:
    $$ C(\mathbf{r}, t) = \int_{s_n}^{s_f} T(s, t) \sigma(\mathbf{r}(s), t) c(\mathbf{r}(s), \mathbf{d}, t) ds $$
    where $T(s, t) = \exp \left( -\int_{s_n}^{s} \sigma(\mathbf{r}(s'), t) ds' \right)$ [S1].

**Parameters:**
*   **Training Configuration:** The method is trained using the same hyperparameters and configuration reported for NeRF's real forward-facing experiments [S1]. Specific values (learning rate, layer sizes, number of samples per ray) are not explicitly detailed in the source beyond referencing the standard NeRF forward-facing setup [S1].

**Edge Cases and Pitfalls:**
*   **Blurriness:** The method suffers from blurry predictions and lacks fine detail compared to methods using deformation fields [S1].
*   **Dynamic Reasoning:** It fails to reason about scene dynamics explicitly, leading to artifacts when camera pose changes interact with object motion [S1].
*   **Ghosting:** While improved over vanilla NeRF, it may still exhibit ghosting artifacts if the temporal interpolation is insufficient for rapid motion [S1].

## Subtopics

### Temporal Compression of NeRF Models
A compression strategy for sequences of NeRF models that exploits temporal redundancy by treating the first model as a key-frame and compressing only the deltas between successive models [S2]. It is chosen when storage or transmission bandwidth for a sequence of dynamic NeRFs is constrained [S2].
*   **Initialization:** The NeRF for the first frame is trained from scratch [S2].
*   **Subsequent Frames:** For frame $i > 1$, the new NeRF is initialized using the weights of the previously trained NeRF (frame $i-1$) to encourage temporal redundancy and reduce training time [S2].
*   **Delta Calculation:** Compute the delta $\Delta W_i = W_i - W_{i-1}$ between the current frame's weights $W_i$ and the previous frame's weights $W_{i-1}$ [S2].
*   **Compression:** Apply exponent-based quantization and Huffman coding to the delta weights $\Delta W_i$ [S2].
*   **Decoding/Restoration:** To restore a model, accumulate the decoded deltas to the reference model (the previous frame's model) [S2].

## Operating characteristics
*   **Complexity:** Time and memory complexity are identical to standard NeRF, as the network architecture size does not change, only the input dimension increases by the size of the time encoding [S1].
*   **Performance:** On KITTI dynamic scenes, "NeRF + time" achieves a PSNR of 24.18, SSIM of 0.677, and LPIPS of 0.425, which is an improvement over vanilla NeRF (PSNR 23.34, SSIM 0.662, LPIPS 0.415) but significantly worse than the proposed Neural Scene Graph method (PSNR 26.66, SSIM 0.806, LPIPS 0.186) [S1].
*   **Strengths:** Simple to implement; requires no modification to the core volume rendering pipeline or canonical space mapping [S1].
*   **Limitations:** Lacks detail; produces blurry predictions; cannot explicitly model or reason about complex scene dynamics [S1].
*   **When to use:** As a baseline for evaluating dynamic scene reconstruction methods; when computational resources for complex deformation fields are unavailable [S1].
*   **When not to use:** When high-fidelity detail or explicit motion modeling is required [S1].

## Background
The method was introduced in the context of evaluating implicit representations for dynamic scenes, specifically as a comparison point for "Neural Scene Graphs for Dynamic Scenes" [S1]. It was proposed by the authors of the Neural Scene Graphs paper to demonstrate that simply adding a time parameter to static NeRF is insufficient for high-quality dynamic scene reconstruction [S1]. The approach builds on the standard NeRF architecture [S1].
