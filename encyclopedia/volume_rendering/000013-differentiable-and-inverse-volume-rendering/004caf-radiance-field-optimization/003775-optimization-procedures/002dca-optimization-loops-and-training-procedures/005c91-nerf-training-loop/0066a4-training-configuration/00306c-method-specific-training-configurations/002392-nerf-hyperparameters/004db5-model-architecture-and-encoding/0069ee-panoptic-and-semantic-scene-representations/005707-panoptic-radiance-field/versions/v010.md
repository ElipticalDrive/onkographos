# Panoptic Radiance Field

Also called: Panoptic Lifting

## Overview
Panoptic Lifting is a method for learning panoptic 3D volumetric representations from images of in-the-wild scenes by lifting noisy 2D machine-generated segmentation masks into a consistent 3D representation [S1]. It represents a static 3D scene as a panoptic radiance field that generates a unified and multi-view consistent, 3D panoptic representation of the scene, lifting noisy 2D segmentation masks into a consistent 3D representation [S1]. Unlike Panoptic NeRF and DM-NeRF, which require manual ground truth (coarse meshes or per-image 2D panoptic segmentations), Panoptic Lifting requires only machine-generated 2D panoptic segmentation masks inferred from a pre-trained network [S1]. It outperforms Mask2Former, SemanticNeRF, DM-NeRF, and PNF on mIoU and PQ_scene across HyperSim, Replica, and ScanNet datasets, while maintaining comparable PSNR for novel view synthesis [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Posed RGB images $\{I\}$ of a scene and corresponding machine-generated 2D panoptic segmentation masks. Rays $r$ are parameterized as $r = p_0 + t d_r$, with $p_0$ ray origin, $d_r$ unit direction, and $t$ scalar. Training rays have associated RGB color $\hat{c}_r \in \mathbb{R}^3$, semantic class $\hat{k}_r \in K$, and 2D instance ID $\hat{h}_r \in H_I$ (defined only for thing classes $\hat{k}_r \in K_T$) [S1].
*   **Outputs:** A panoptic radiance field $\Phi(x, d)$ that assigns to each 3D point $x \in \mathbb{R}^3$ and viewing direction $d \in S^2$: density $\sigma \in \mathbb{R}_{\ge 0}$, semantic class distribution $\kappa$ over $K$, distribution $\pi$ over surrogate identifiers $J$, and RGB color $c \in \mathbb{R}^3$ [S1]. From this, one can render color images, depth, and 3D-consistent panoptic segmentation masks for novel views [S1].

**Data Structures:**
The neural field representation comprises four components:
1.  **Color and Density:** Leverage TensoRF [4] (lines and planes).
2.  **Semantic Field:** A small MLP.
3.  **Instance Field:** A separate small MLP holding a fixed number of class-agnostic, 3D-consistent surrogate object identifiers [S1].
4.  **Surrogate Identifiers:** A fixed set $J$ of identifiers. The set of all possible 3D instances is $H_{3D} := K_T \times J$ [S1].

**Rendering Equation:**
Given the density field $\sigma$, any vector field $f$ over 3D points along a ray $r$ is rendered as [S1]:
$$ R[f |r, \sigma] := \int_0^\infty \alpha_t (r)\sigma(r_t)f (r_t, d_{r_t})dt $$
where $\alpha_t (r) := \exp \left(-\int_0^t \sigma(r_s)ds\right)$ is the transmittance probability at $t$ [S1].

**Training Procedure:**
1.  **Preprocessing (Test-Time Augmentation):** Run test-time augmentations on input images (e.g., horizontal flip, scale, brightness, contrast) and fuse the resulting segmentations by segment clustering to obtain a semantic class distribution $\hat{\kappa}_r$ and a confidence estimate $w_r$ for each pixel (ray $r$) [S1].
2.  **Linear Assignment:** Solve a linear assignment with a cost based on the model’s current predictions and the machine-generated segmentation masks to account for inconsistencies of 2D instance identifiers across views, enabling lifting of 2D instances to 3D in a consistent way [S1]. Each ray $r$ is assigned the most compatible 3D surrogate identifier via an injective mapping $\Pi^*_R$, given its 2D machine-generated instance $\hat{h}_r$ [S1].
3.  **Loss Calculation:** Compute the total training loss [S1]:
    $$ L_{tot}(R) := \lambda_{ins} L_{ins}(R_I) + \lambda_{con} L_{con}(R_I) + \lambda_{RGB} L_{RGB}(R_S) + \lambda_{sem} L_{sem}(R_S) $$
    where $R_S$ are rays randomly sampled across the scene and $R_I$ are rays sampled from a single image [S1].
    *   **Semantic Loss:** Supervise the semantic field directly with machine-generated 2D labels using cross-entropy, weighted by confidence $w_r$ [S1]:
        $$ L_{sem}(R) := -\frac{1}{|R|} \sum_{r \in R} w_r \sum_{k \in K} \hat{\kappa}_r (k) \log \kappa_r (k) $$
    *   **Instance Loss:** Supervise the instance field using an NCE loss on the mapped 2D instance field [S1].
    *   **Segment Consistency Loss:** Guide semantic supervision with an additional segment consistency loss to avoid optima that fragment objects in the presence of label inconsistencies [S1].
    *   **Photometric Loss:** Standard L2 loss on rendered color [S1].
4.  **Optimization:** Optimize the panoptic radiance field $\Phi(x, d)$ using the Adam optimizer [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.optim as optim

class PanopticRadianceField:
    def __init__(self, num_surrogates, num_classes, tensorf_config):
        # TensoRF for density and color
        self.tensorf = TensoRF(tensorf_config)
        
        # Small MLP for semantic distribution
        self.semantic_mlp = nn.Sequential(
            nn.Linear(tensorf_config.feature_dim, 256),
            nn.ReLU(),
            nn.Linear(256, num_classes)
        )
        
        # Small MLP for surrogate identifier distribution
        self.instance_mlp = nn.Sequential(
            nn.Linear(tensorf_config.feature_dim, 256),
            nn.ReLU(),
            nn.Linear(256, num_surrogates)
        )
        
        self.optimizer = optim.Adam(
            list(self.tensorf.parameters()) + 
            list(self.semantic_mlp.parameters()) + 
            list(self.instance_mlp.parameters()),
            lr=5e-4
        )
        
        # Loss weights
        self.lambda_ins = 1.0
        self.lambda_con = 1.35
        self.lambda_rgb = 1.0
        self.lambda_sem = 1.0

    def query(self, x, d):
        """
        Query the field at point x and direction d.
        Returns: sigma, c, kappa_logits, pi_logits
        """
        # Get TensoRF features and density
        sigma, c = self.tensorf.query(x, d)
        
        # Get features for semantic and instance heads
        # Note: TensoRF typically provides a feature vector at x
        features = self.tensorf.get_features(x)
        
        # Semantic distribution (bounded probabilities)
        kappa_logits = self.semantic_mlp(features)
        kappa = torch.softmax(kappa_logits, dim=-1)
        
        # Instance distribution
        pi_logits = self.instance_mlp(features)
        pi = torch.softmax(pi_logits, dim=-1)
        
        return sigma, c, kappa, pi

    def render_ray(self, ray_origin, ray_direction, t_near, t_far, num_samples):
        """
        Render a ray using volumetric rendering.
        Returns: color, semantic_dist, instance_dist, depth
        """
        t_vals = torch.linspace(t_near, t_far, num_samples)
        deltas = t_vals[1:] - t_vals[:-1]
        
        # Sample points along ray
        x_vals = ray_origin.unsqueeze(0) + t_vals.unsqueeze(1) * ray_direction.unsqueeze(0)
        
        sigma, c, kappa, pi = self.query(x_vals, ray_direction)
        
        # Alpha calculation
        alpha = 1.0 - torch.exp(-sigma * deltas)
        
        # Transmittance
        T = torch.cumprod(torch.cat([torch.ones_like(alpha[:, :1]), 1.0 - alpha], dim=1), dim=1)[:, :-1]
        
        # Weights
        weights = T * alpha
        
        # Rendered outputs
        color = torch.sum(weights.unsqueeze(-1) * c, dim=1)
        semantic_dist = torch.sum(weights.unsqueeze(-1) * kappa, dim=1)
        instance_dist = torch.sum(weights.unsqueeze(-1) * pi, dim=1)
        depth = torch.sum(weights * t_vals, dim=1)
        
        return color, semantic_dist, instance_dist, depth

    def compute_loss(self, rendered_color, rendered_semantic, rendered_instance, 
                     gt_color, gt_semantic_dist, gt_confidence, gt_instance_id, 
                     current_instance_predictions, num_classes, num_surrogates):
        """
        Compute total loss.
        """
        # RGB Loss
        rgb_loss = torch.nn.functional.mse_loss(rendered_color, gt_color)
        
        # Semantic Loss (Cross Entropy weighted by confidence)
        # gt_semantic_dist is the distribution from TTA
        # rendered_semantic is the predicted distribution
        semantic_loss = -torch.mean(gt_confidence * torch.sum(gt_semantic_dist * torch.log(rendered_semantic + 1e-8), dim=-1))
        
        # Instance Loss (NCE based on linear assignment)
        # Solve linear assignment to map 2D instance to 3D surrogate
        # cost_matrix based on current predictions and 2D labels
        assignment = solve_linear_assignment(current_instance_predictions, gt_instance_id)
        mapped_gt_surrogates = map_to_surrogates(gt_instance_id, assignment)
        
        # NCE Loss between rendered instance distribution and mapped GT
        instance_loss = compute_nce_loss(rendered_instance, mapped_gt_surrogates)
        
        # Segment Consistency Loss (to avoid fragmentation)
        consistency_loss = compute_segment_consistency(rendered_semantic, gt_semantic_dist)
        
        total_loss = (self.lambda_ins * instance_loss + 
                      self.lambda_con * consistency_loss + 
                      self.lambda_rgb * rgb_loss + 
                      self.lambda_sem * semantic_loss)
        
        return total_loss

    def train_step(self, rays, gt_data):
        self.optimizer.zero_grad()
        
        # Render
        rendered_color, rendered_semantic, rendered_instance, depth = self.render_ray(
            rays.origin, rays.direction, rays.t_near, rays.t_far, rays.num_samples
        )
        
        # Compute Loss
        loss = self.compute_loss(
            rendered_color, rendered_semantic, rendered_instance,
            gt_data.color, gt_data.semantic_dist, gt_data.confidence,
            gt_data.instance_id, self.query_instance_field(rays.points),
            gt_data.num_classes, gt_data.num_surrogates
        )
        
        # Gradient blocking: Stop gradients from semantic/instance branches to geometry (TensoRF)
        # This is implemented by detaching TensoRF parameters from semantic/instance loss gradients
        # or by zeroing gradients of TensoRF params for those specific loss components.
        # For simplicity in pseudocode, we assume the loss computation handles this via detached tensors
        # or specific gradient masking.
        
        loss.backward()
        self.optimizer.step()
        
        return loss.item()

    def render_panoptic(self, ray_origin, ray_direction, t_near, t_far, num_samples):
        """
        Render panoptic segmentation for a novel view.
        """
        _, semantic_dist, instance_dist, _ = self.render_ray(
            ray_origin, ray_direction, t_near, t_far, num_samples
        )
        
        # Get most probable semantic class
        semantic_class = torch.argmax(semantic_dist, dim=-1)
        
        # If thing class, get most probable surrogate ID
        is_thing = semantic_class in thing_classes
        if is_thing:
            surrogate_id = torch.argmax(instance_dist, dim=-1)
            instance_id = (semantic_class, surrogate_id)
        else:
            instance_id = None
            
        return semantic_class, instance_id
```

**Parameters:**
*   $K$: Set of semantic classes, partitioned into thing classes $K_T$ and stuff classes $K_S$ [S1].
*   $J$: Set of surrogate identifiers. Fixed number held by the instance field MLP [S1].
*   $H_{3D}$: Set of all possible 3D instances, defined as $H_{3D} := K_T \times J$ [S1].
*   Loss weights: $\lambda_{con} = 1.35$, $\lambda_{ins} = 1$, $\lambda_{sem} = 1$, $\lambda_{RGB} = 1$ [S1].
*   Optimizer: Adam. Learning rates: $5 \times 10^{-4}$ for MLPs, $1 \times 10^{-2}$ for TensoRF lines and planes [S1].
*   Training hardware: 1 NVIDIA A6000. Duration: 450k iterations (~10 hours) [S1].
*   Pre-trained panoptic segmentation model: Mask2Former with Swin-L backbone [S1].

**Edge Cases and Pitfalls:**
*   **Logits vs. Probabilities:** Rendering class logits instead of probabilities can introduce semantic inconsistencies across viewpoints because unbounded logits can generate significant signals in low-density areas, violating geometric constraints. This is resolved by rendering bounded probability distributions [S1].
*   **Geometry Influence:** Supervision from noisy 2D labels can influence geometry, causing cloudy geometry to satisfy conflicting labels. This is avoided by stopping gradients from segmentation branches back to densities [S1].
*   **Offline Processing:** The method runs offline due to lengthy pre-processing for pose estimation, 2D segmentation inference, and neural field optimization [S1].
*   **Class Limitations:** The method is limited to classes supported by the pre-trained 2D panoptic segmentation model [S1].

*   **Limitations:** Limited to classes supported by the pre-trained 2D panoptic segmentation model [S1]. Runs offline due to lengthy pre-processing [S1].

## Background
Panoptic Lifting was introduced in "Panoptic Lifting for 3D Scene Understanding with Neural Fields" (CVPR 2023) [S1]. It addresses the challenge of learning panoptic 3D volumetric representations from in-the-wild scenes without manual 3D ground truth, relying instead on machine-generated 2D panoptic segmentation masks [S1]. It builds on [Model Architecture and Encoding](13550-model-architecture-and-encoding.md) and [TensoRF](4) for the base radiance field representation [S1].
