# Neural Scene Graphs

Also called: NSG

## Overview
Neural Scene Graphs (NSG) is a method for decomposing dynamic, multi-object scenes into a hierarchical learned scene graph with decoupled object transformations and scene representations [S1]. It solves the problem of novel view synthesis and rendering of unseen arrangements in dynamic scenes, where existing methods rely on static scenes or encode the entire scene into a single static network [S1]. Unlike its siblings, NSG uses object-level implicit representations shared across instances of the same class, allowing for the modeling of dynamic components (appearance, shape, class) separately from the static background [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of video frames and corresponding tracking data (labeled or generated) [S1]. Camera intrinsic and extrinsic parameters [S1].
*   **Outputs:** A rendered image $\hat{C}(\mathbf{r})$ for a given ray $\mathbf{r}$, and a scene graph $S$ containing learned object representations and transformations [S1].

**Data Structures:**
The scene is defined by a directed acyclic graph $S$:
$$ S = \langle W, C, F, L, E \rangle \quad (1) $$
*   $W$: Root node representing the global world space [S1].
*   $C$: Camera node [S1].
*   $F$: Set of representation nodes (neural radiance fields) [S1].
*   $L$: Latent descriptors for objects [S1].
*   $E$: Set of edges representing affine transformations or property assignments [S1].

**Edges:**
Edges $E$ represent affine transformations from node $u$ to $v$ or property assignments:
$$ E = \{ e_{u,v} \in \{ [\mathbf{I}], \mathbf{M}_{u,v} \} \} \quad (2) $$
where $\mathbf{M}_{u,v}$ is a $4 \times 4$ affine transformation matrix:
$$ \mathbf{M}_{u,v} = \begin{bmatrix} \mathbf{R} & \mathbf{t} \\ \mathbf{0} & 1 \end{bmatrix}, \quad \mathbf{R} \in \mathbb{R}^{3 \times 3}, \mathbf{t} \in \mathbb{R}^3 $$
*   $[\mathbf{I}]$ denotes the identity transformation [S1].
*   Transformations between the global world space $W$ and local object/camera space are assigned to edges originating from $W$ [S1].
*   Non-uniform scaling $\mathbf{S}_o$ is assigned at edge $e_{o,f}$ between an object node and its shared representation model $F$ to handle different scales of the same object type [S1].

**Representation Models:**
*   **Background Node ($F_{\theta_{bckg}}$):** Approximates static parts of the scene. It is a neural radiance field living on **sparse planes** instead of a volume [S1]. It maps $(\mathbf{x}, \mathbf{d}) \to (\mathbf{c}, \sigma)$ [S1]. It uses Fourier encodings [37] to aid learning high-frequency functions in the MLP model [S1].
*   **Object Nodes ($F_{\theta_o}$):** Represented as augmented implicit neural radiance fields following Mildenhall et al. [22] [S1]. Representation models are shared and defined in a shared, unit-scaled frame [S1]. Similar objects are modeled using the same network by adding a latent vector $\mathbf{z}$ to the input 3D query point [S1].

**Algorithm:**
1.  **Graph Construction:** Define the scene graph $S$ with root $W$, camera $C$, background node $F_{\theta_{bckg}}$, and dynamic object nodes $F_{\theta_o}$ [S1].
2.  **Transformation Assignment:** Assign transformations $\mathbf{T}^W_v$ for edges from root $W$ to local object/camera spaces [S1]. Assign scaling $\mathbf{S}_o$ for edges between object nodes and shared models [S1].
3.  **Object Pose Retrieval:** To retrieve an object’s local transformation and position $\mathbf{p}_o = [x, z, y]_o$, traverse from root node $W$, applying transformations until the desired object node $F_{\theta_o}$ is reached [S1]. This ends in the frame of reference defined in Eq. 8 of the source [S1].
4.  **Rendering:**
    *   For a ray $\mathbf{r}$, sample points along the ray.
    *   For each sample point $\mathbf{x}$, determine if it belongs to the background or an object.
    *   If background, query $F_{\theta_{bckg}}(\mathbf{x}, \mathbf{d})$ to get $\sigma, \mathbf{c}$ [S1].
    *   If object, transform $\mathbf{x}$ to the object's local unit-scaled frame using the accumulated transformation from $W$ [S1]. Add the object's latent vector $\mathbf{z}$ to the transformed point [S1]. Query the shared object model $F_{\theta_o}(\mathbf{x}_{local} + \mathbf{z}, \mathbf{d})$ to get $\sigma, \mathbf{c}$ [S1].
    *   Composite colors and densities using the standard volume rendering equation [S1].

**Parameters:**
*   Fourier encoding frequencies: Not given in the sources.
*   MLP architecture for $F_{\theta_{bckg}}$ and $F_{\theta_o}$: Not given in the sources (follows Mildenhall et al. [22] structure) [S1].

**Edge Cases and Pitfalls:**
*   **Scale Handling:** Different scales of the same object type must be handled via non-uniform scaling $\mathbf{S}_o$ assigned at the edge $e_{o,f}$ [S1].
*   **Frame of Reference:** Transformations must be applied correctly from the global world space $W$ to the local object frame [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Allows for novel view synthesis and rendering of unseen arrangements of dynamic objects; facilitates 3D object detection using inverse rendering; decouples object transformations from scene representations [S1].
*   **Limitations:** Relies on tracking data (labeled or generated) for training [S1].
*   **When to use:** Dynamic, multi-object scenes where objects can be tracked and grouped by class [S1].
*   **When not to use:** Static scenes or scenes without distinct, trackable dynamic objects [S1].

## Background
Neural Scene Graphs was introduced by Niemeyer et al. in 2021 [S1]. It builds on the concept of implicit neural radiance fields [22] and differentiable rendering [20, 24, 26] [S1]. The method addresses the limitation of existing neural rendering methods that encode the entire scene into a single, static network, which is unsuitable for dynamic scenes with varying object arrangements [S1].
