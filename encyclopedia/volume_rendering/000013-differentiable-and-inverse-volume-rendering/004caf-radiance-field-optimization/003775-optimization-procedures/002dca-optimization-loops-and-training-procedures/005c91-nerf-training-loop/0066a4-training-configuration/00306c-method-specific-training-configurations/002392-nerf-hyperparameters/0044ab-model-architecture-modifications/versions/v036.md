# Model Architecture Modifications

Also called: NeRF Architecture Variants, Network Structure Changes, Implicit Representation Modifications

## Overview
Model Architecture Modifications refer to structural changes applied to the baseline Neural Radiance Field (NeRF) multi-layer perceptron (MLP) to address specific limitations such as computational bottlenecks, sparse input data, dynamic scenes, or geometric inaccuracies. Unlike standard NeRF, which maps 3D coordinates and viewing directions to density and color via a single global MLP, these modifications introduce alternative representations (e.g., voxels, SDFs), conditional latent codes, or specialized encoding schemes. They set themselves apart from sibling methods like [NeRF Hyperparameters](3065-nerf-hyperparameters.md) by altering the network's topology or input/output interfaces rather than just training hyperparameters.

## How it works
The baseline NeRF architecture [Parent](3065-nerf-hyperparameters.md) consists of two MLPs: a Position MLP (typically 8 layers, 256 hidden units) mapping spatial coordinates to density and intermediate features, and a Color MLP (typically 4 layers, 256 hidden units) mapping features and viewing directions to RGB color [S1][S5, unofficial]. Model architecture modifications alter this structure in the following ways:

### 1. Spatial Compression and Encoding Modifications (PL-NeRF)
For unbounded scenes with thin structures (e.g., power transmission lines), the standard NeRF uses Normalized Device Coordinates (NDC) for space contraction, which is ill-defined for unbounded scenes [S1].
*   **Spatial Compression:** The scene space is compressed into a fixed cube using the $L_\infty$ norm, rather than the sphere used in Mip-NeRF 360 [S1]. This aligns better with hash encoding [S1].
    *   Formula: $\mathbf{x}' = \text{sign}(\mathbf{x}) \cdot \min(|\mathbf{x}|, 1)$ [S1, inferred from $L_\infty$ norm description].
*   **Position Encoding:**
    *   **Hash Encoding (HE):** Used for positional information. The compressed scene space is quantized, and a Hash Table is initialized. A Hash Function maps vertex coordinates to indices for cubic interpolation [S1].
    *   **Integrated Positional Encoding (IPE):** Used for directional information. It approximates the integration of positional encoding over a truncated frustum using a multivariate Gaussian approach to generate anti-aliasing features [S1].
*   **Network Structure:** The Position MLP has 8 layers with 256 hidden units; the Color MLP has 4 layers with 256 hidden units [S1].

### 2. Low-Rank and Tensor Train Distillation (DLR-NeRF)
To reduce model size while preserving low-rank properties, weights from a Low-Rank NeRF (LR-NeRF) are decomposed into Tensor Train (TT) components [S2, unofficial].
*   **Decomposition:** For each layer $L_i$ with weight matrix $W^r_i$, decompose $W^r_i$ into TT components $Q1_i$ and $Q2_i$ such that $W^r_i = Q1_i \cdot Q2_i$ [S2, unofficial].
*   **Initialization:**
    *   If $(n_1 + n_2) \times r < (n_1 \times n_2)$, initialize two cascaded fully-connected layers $L'_{i1}$ and $L'_{i2}$ in DLR-NeRF with $Q1_i$ and $Q2_i$ respectively [S2, unofficial].
    *   Otherwise, initialize one layer $L'_i$ with the original weight matrix $W^r_i$ and bias $b_i$ [S2, unofficial].
*   **Fine-tuning:** DLR-NeRF is fine-tuned using the same loss function as the original NeRF to update parameters [S2, unofficial]. Training from scratch with random weights yields poor quality; distillation bridges low-rank approximation and quantization [S2, unofficial].

### 3. Generative and Latent Conditioning (NeRF-VAE)
To generalize to out-of-distribution scenes without per-scene training:
*   **Latent Code:** The NeRF renderer is conditioned on a latent code $z$ [S3].
*   **Encoder:** A ResNet encoder extracts $z$ from input images using Iterative Amortized Inference [S3].
*   **Scene Function:** An attention-based scene function replaces the typical MLP to improve generalization [S3].

### 4. Super-Resolution Integration (NeRF-Swin)
To enhance resolution of low-resolution NeRFs:
*   **Architecture:** Integrates SwinIR models for super-resolution [S7].
*   **Training:** Trained on >10k LR-HR pairs [S7].
*   **Pitfall:** On synthetic datasets (Blender), domain mismatch may cause false predictions; on real-world datasets (LLFF), it may oversmooth or predict false color/geometry [S7].

### 5. Standard Baseline Parameters
For reference, the standard NeRF architecture [S5, unofficial] uses:
*   `netdepth`: 8 (hidden layers)
*   `netwidth`: 256 (channels per layer)
*   `output_ch`: 4 (RGB + density)
*   `use_viewdirs`: True (view directions injected into intermediate layers)

## Subtopics

### [DoF-NeRF](9432-dof-nerf.md)
DoF-NeRF extends NeRF to simulate depth-of-field effects by modeling aperture and focus distance, computing colors based on Circle of Confusion (CoC) diameter. Choose when synthesizing views with arbitrary focus configurations from shallow DoF inputs.

### [NeRF-VPT](11770-nerf-vpt.md)
NeRF-VPT uses a cascading view prompt tuning paradigm, using RGB from previous iterations as visual prompts for subsequent stages. Choose for sparse-view settings to enhance image quality iteratively without external networks.

### [Activation Feature Density Approximation](12492-activation-feature-density-approximation.md)
Estimates volumetric density $\hat{d}$ from intermediate activation features $\mathbf{f}_\ell$ of an MLP, replacing expensive coarse network evaluations. Choose when optimizing density prediction speed while retaining standard density-based rendering.

### [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md)
Replaces density field $\sigma(\mathbf{x})$ with a continuous scalar field $s(\mathbf{x})$ representing distance to the nearest surface. Choose for explicit, smooth surface formulations and geometric accuracy, addressing holes in density-based NeRFs.

### [Volume-Augmented NeRF](12973-volume-augmented-nerf.md)
Binds an explicit fluid volume value $v_i$ to each sample point for dynamic scenes. Choose for fluid dynamics where density and color change over time due to flow.

### [Neural-PIL Decomposition Architecture](12975-neural-pil-decomposition-architecture.md)
Separates geometry, material, and illumination into distinct networks, predicting density, BRDF, and illumination embeddings. Choose when inputs have varying illumination and explicit reflectance decomposition is required.

### [MINE](13661-mine.md)
Models the frustum using a continuous depth Multiplane Image (MPI) representation. Choose for efficient rendering of multiple novel views via homography warping, independent of target view count.

### [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md)
Replaces the continuous MLP with discrete spatial structures (voxels, hash tables) for feature storage. Choose for real-time differentiable volume rendering and memory efficiency on large scenes.

### [Aleth-NeRF](13764-aleth-nerf.md)
Trains on under/over-exposed images using a 'Concealing Field' assumption to suppress light transport. Choose for synthesizing normal-light views from low-light or over-exposed LDR inputs without paired data.

### [Transformer and Vision Model Integration](13911-transformer-and-vision-model-integration.md)
Transfers visual attributes using dense semantic correspondences from Vision Transformer (ViT) features. Choose for rigid appearance transfer between objects with different geometries.

### [Human and Specific Subject Modeling](13997-human-and-specific-subject-modeling.md)
Adapts NeRF for dynamic human subjects using parametric priors (e.g., SMPL) or structured latent codes. Choose for non-rigid deformation and occlusion handling in human modeling.

### [OPONeRF](14014-oponerf.md)
Personalizes plenoptic mapping parameters for each 3D point by conditioning weights $\Theta$ on point representation $\mathbf{x}$ and scene representation $\mathbf{F}$. Choose for handling test-time scene changes and local variations.

### [Mixer-NeRF](14073-mixer-nerf.md)
Introduces a hybrid spatial feature learning module (MLCA) and squeeze-and-excitation (SE) network to mix spatial and channel features. Choose to address loss of local information and blurry details in standard NeRF.

### [Sparse View and Few-Shot Optimization](14428-sparse-view-and-few-shot-optimization.md)
Mitigates ambiguity in sparse-view regimes ($|S| < 20$) through in-situ regularization or adaptive sampling. Choose when input views are drastically reduced to prevent geometry breakdown.

### [Mixture-of-Experts and Modular Architectures](14429-mixture-of-experts-and-modular-architectures.md)
Partitions the scene among specialized sub-networks (experts) with a gating mechanism. Choose for large-scale or complex scenes to reduce active MLP evaluations per ray.

### [Uncertainty and Reliability](14487-uncertainty-and-reliability.md)
Extends NeRF to output probabilistic distributions or calibrated uncertainty bounds. Choose for filtering artifacts and weighting training samples in sparse or dynamic scenes.

### [Object Decomposition and Composition](14518-object-decomposition-and-composition.md)
Separates a scene into distinct object instances and background using one-hot activation or frequency-based partitioning. Choose for individual object manipulation and amodal segmentation.

### [Lighting and Appearance Models](14522-lighting-and-appearance-models.md)
Explicitly handles view-dependent effects and varying illumination. Choose to address the semantic gap in lighting control and high-frequency appearance variations.

### [Optimization and Training Procedures](14565-optimization-and-training-procedures.md)
Covers algorithmic procedures like skipping fine-pass evaluations for empty rays. Choose for efficient minimization of photometric loss under computational constraints.

### [Image Enhancement and Restoration Methods](14566-image-enhancement-and-restoration-methods.md)
Modifies the training pipeline to handle input defects (blur, occlusions) via supervision signal changes. Choose when input images have defects rather than scene representation issues.

### [Modular, Hierarchical, and Latent Architectures](14567-modular-hierarchical-and-latent-architectures.md)
Introduces discrete latent codes or higher-dimensional ambient spaces. Choose for complex scene properties like topological discontinuities or non-rigid deformations.

### [MuRF (Multi-Baseline Radiance Fields)](15007-murf-multi-baseline-radiance-fields.md)
Constructs a target view frustum volume with a 3D context-aware convolutional decoder. Choose for sparse view synthesis under varying camera baselines, including large baselines.

### [Gaussian and Primitive-Based Representations](15011-gaussian-and-primitive-based-representations.md)
Replaces the global MLP with discrete, local representations (Gaussians, quadrics). Choose for real-time rendering speeds and handling high-frequency details via differentiable rasterization.

### [Decentralized Federated NeRF](15032-decentralized-federated-nerf.md)
Distributes training to users, aggregating only global models using Secure Multi-Party Computation (SMPC). Choose for crowdsourced 3D reconstruction while preventing personal data leakage.

### [Neural Proxy](15220-neural-proxy.md)
Represents targets as animatable proxies, injecting a 3D mesh for geometry and texture for appearance. Choose for synthesizing unseen animations without temporal learning.

### [ViSNeRF](15255-visnerf.md)
Combines explicit feature grids with implicit MLP decoders and generalized tensor factorization for dynamic volumetric scenes. Choose for scalability of high-dimensional $(3+K)$-D radiance fields.

### [EBAD-NeRF](15441-ebad-nerf.md)
Reconstructs sharp 3D radiance fields from motion-blurred images using hybrid event-RGB data and multiple learnable poses. Choose for joint optimization of camera poses and NeRF parameters from blurred inputs.

### [Network Architectures](15530-network-architectures.md)
Modifies the baseline MLP to address continual learning, compression, or dynamic modeling. Choose for expanding inputs with trainable embeddings or substituting continuous functions.

### [NeurMiPs](15543-neurmips.md)
Represents a scene as a mixture of $K$ learnable rectangular planar surfaces acting as independent experts. Choose for high efficiency through analytical ray-plane intersection and superior extrapolation.

### [CodeNeRF](15544-codenerf.md)
Learns variation of object shapes and textures across a semantic category using separate latent embeddings. Choose for one-shot reconstruction and explicit editing of unseen objects from single unposed images.

### [Dynamic Scene and Temporal Modeling](15546-dynamic-scene-and-temporal-modeling.md)
Introduces a temporal dimension to the input space or representation. Choose as the foundational approach for all dynamic NeRF variants.

### [NeRF-Casting](15547-nerf-casting.md)
Integrates ray tracing into the NeRF pipeline to cast reflection rays for specular appearance. Choose for synthesizing photorealistic reflections without requiring the MLP to encode the full environment.

### [RoseNeRF](15548-rosenerf.md)
Models refraction by predicting a single refracted ray using a 4D light field representation. Choose for high-fidelity synthesis of real refractive objects without IoR fields.

### [Semantic and Feature Field Extensions](15556-semantic-and-feature-field-extensions.md)
Generalizes NeRF to predict arbitrary per-point feature signals $\mathbf{f}$ (semantic labels, embeddings). Choose for lifting 2D observations into a consistent 3D representation.

### [Neural Density-Distance Fields](15665-neural-density-distance-fields.md)
Reciprocally constrains distance and density fields, deriving density from depth values. Choose for boundaryless scenes, complex shapes, and stable mesh extraction.

### [LAENeRF](15738-laenerf.md)
Learns a palette-based color decomposition within a user-selected region for local appearance editing. Choose for photorealistic and non-photorealistic editing with minimal background artifacts.

### [ExtremeNeRF](15739-extremenerf.md)
Enforces multi-view albedo consistency through a two-stage intrinsic decomposition pipeline. Choose for few-shot view synthesis under unconstrained, varying illumination.

### [Conditional and Latent Representations](15989-conditional-and-latent-representations.md)
Models an entire object class using instance-specific latent vectors for shape and appearance. Choose for editing and generalization across a class of objects.

### [ActiveNeRF Model Architecture](16203-activenerf-model-architecture.md)
Outputs prediction variance alongside density and color for uncertainty-aware view synthesis. Choose to guide active sampling strategies.

### [SCARF](16591-scarf.md)
Factorizes NeRF MLP weights into scene-specific and cross-scene shared components via a hypernetwork. Choose for memory-efficient continual learning of multiple 3D scenes.

### [Multi-input MLP (mi-MLP)](16599-multi-input-mlp-mi-mlp.md)
Incorporates 3D location and viewing direction inputs into every layer of the MLP. Choose to alleviate overfitting in few-shot view synthesis by creating shorter paths between inputs and outputs.

## Operating characteristics
*   **PL-NeRF:** Prioritizes reconstruction quality over rendering smoothness and real-time capabilities [S1]. Achieves PSNR = 29, SSIM = 0.871, LPIPS = 0.087 on PTL datasets [S1].
*   **DLR-NeRF:** Reduces model size via quantization while preserving low-rank properties [S2, unofficial]. Parameter count depends on layer depth $L$ rather than scene size [S1][S2, unofficial].
*   **NeRF-VAE:** Outperforms baseline NeRF with 5-20 views but is outperformed with 100+ views due to lower scene expressivity [S3].
*   **NeRF-Swin:** On Blender ×2 (100x100), PSNR 26.34, SSIM 0.913, LPIPS 0.075; on LLFF ×2, PSNR 25.18, SSIM 0.793, LPIPS 0.147 [S7]. Prone to domain mismatch artifacts [S7].
*   **Neural Architecture Search:** Network depth provides hierarchical representation ability; width provides memorization capacity. Reducing width monotonically decreases quality; reducing depth below 2 drops quality [S8].

## Background
The baseline NeRF architecture was introduced by Mildenhall et al. [S5, unofficial]. Subsequent modifications have been inspired by various works: PL-NeRF is inspired by Mip-NeRF 360 [44] for space compression and Ref-NeRF [51] for normal prediction [S1]. NeRF-VAE was proposed by Kosiorek et al. [S3]. S3-NeRF uses shadow and shading cues [S3]. NeuralEditor employs point cloud guidance [S6]. NeRF-Swin uses SwinIR for super-resolution [S7]. Neural Architecture Search analyzes depth and width impacts [S8].
