# SLS4D

Also called: Sparse Latent Space for 4D Novel View Synthesis

## Overview
SLS4D is a method for 4D novel view synthesis that represents dynamic scenes using a sparse, compact, and informative latent feature space, significantly reducing the number of network parameters compared to previous state-of-the-art methods [S1]. It replaces dense voxel grids with learnable latent codes to capture global dynamics while maintaining high rendering quality [S1]. Unlike sibling methods that rely on dense coordinate relationships or hierarchical voxel grids, SLS4D abandons direct coordinate-to-feature mapping in favor of relative relationships in a latent space, using an attention mechanism to adaptively weight latent codes based on spatial position [S1].

## How it works
SLS4D reconstructs a 4D radiance field $R(\mathbf{x}, \mathbf{d}, t)$ by decoupling temporal and spatial information. It uses a deformation field to warp dynamic 3D coordinates to a canonical space and a sparse latent space to store spatial features, which are aggregated via attention [S1].

### Inputs and Outputs
*   **Inputs:** A set of images $\{I_i\}$ with corresponding camera poses $\{P_i\}$ and timestamps $\{t_i\}$.
*   **Outputs:** For a query ray $\mathbf{r}(s)$ at time $t$, the method outputs color $\mathbf{c}$ and density $\sigma$ to be integrated via volume rendering [S1].

### Data Structures
1.  **Time Slots ($T$):** A dense set of learnable vectors representing temporal states.
    *   Size: $T$ vectors.
    *   Layout: Each vector has dimension $d_t$ (Not given in the sources).
    *   Typical Value: $T = 512$ [S1].
2.  **Spatial Latent Codes ($B$):** A sparse set of globally learnable latent codes representing spatial features.
    *   Size: $B$ vectors.
    *   Layout: Each vector has dimension $d_b$ (Not given in the sources).
    *   Typical Value: $B = 512$ [S1].
3.  **Deformation MLP:** A 7-layer Multi-Layer Perceptron.
    *   Input: Concatenation of 3D position $\mathbf{x} = (x, y, z)$ and time slot feature $\mathbf{t}_{slot}$ corresponding to time $t$.
    *   Output: Displacement vector $\Delta \mathbf{x} = (\Delta x, \Delta y, \Delta z)$ [S1].
4.  **Interpolator Decoder:** A network that combines aggregated spatial features with view direction $\mathbf{d}$ to predict $\sigma$ and $\mathbf{c}$.
    *   Activation: GeGLU (Gated Linear Unit with GeLU gating) [S1].

### Numbered Steps

1.  **Time Slot Encoding:**
    For a query time $t$, retrieve the corresponding dense time slot feature $\mathbf{t}_{slot}$ from the learnable time slots. The time slots are indexed discretely or interpolated to match the continuous time $t$ [S1].

2.  **Deformation Field Prediction:**
    Compute the displacement $\Delta \mathbf{x}$ for a 3D position $\mathbf{x}$ at time $t$ using the deformation MLP:
    $$ \Delta \mathbf{x} = \text{MLP}_{def}([\mathbf{x}; \mathbf{t}_{slot}]) $$
    The canonical position $\mathbf{x}'$ is calculated as:
    $$ \mathbf{x}' = \mathbf{x} + \Delta \mathbf{x} $$
    The deformation field is supervised by Total Variance (TV) Loss to ensure temporal smoothness [S1].

3.  **Spatial Feature Aggregation via Attention:**
    Query the sparse latent space using the canonical position $\mathbf{x}'$.
    *   Compute Query $\mathbf{q}$ from $\mathbf{x}'$ (Not given in the sources, typically a linear projection).
    *   Compute Keys $\mathbf{K}_i$ for each latent code $i \in \{1, \dots, B\}$ (Not given in the sources, typically a linear projection of the latent code).
    *   Calculate attention weights $\alpha_i$ using the inner product of $\mathbf{q}$ and $\mathbf{K}_i$:
        $$ \alpha_i = \text{softmax}_i \left( \frac{\mathbf{q} \cdot \mathbf{K}_i}{\sqrt{d}} \right) $$
    *   Aggregate features $\mathbf{f}_{spatial}$ by weighting the latent codes $\mathbf{L}_i$:
        $$ \mathbf{f}_{spatial} = \sum_{i=1}^{B} \alpha_i \mathbf{L}_i $$
    This mechanism allows the model to rely on relative relationships in the latent feature space rather than direct coordinate mappings [S1].

4.  **Radiance Field Prediction:**
    Pass the aggregated spatial feature $\mathbf{f}_{spatial}$ and view direction $\mathbf{d}$ through the Interpolator Decoder (using GeGLU activation) to predict density $\sigma$ and color $\mathbf{c}$ [S1].

5.  **Volume Rendering:**
    Render the image using the standard volume rendering equation [S1]:
    $$ C(\mathbf{r}, t) = \int_{s_n}^{s_f} T(s, t) \sigma(\mathbf{r}(s), t) c(\mathbf{r}(s), \mathbf{d}, t) ds $$
    where $T(s, t) = \exp \left( -\int_{s_n}^{s} \sigma(\mathbf{r}(s'), t) ds' \right)$ [S1].

### Pseudocode

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SLS4D:
    def __init__(self, B=512, T=512, d_latent=256, d_time=256):
        """
        Initialize SLS4D model.
        B: Number of spatial latent codes.
        T: Number of time slots.
        d_latent: Dimension of spatial latent codes.
        d_time: Dimension of time slot features.
        """
        self.B = B
        self.T = T
        
        # Learnable parameters
        self.latent_codes = nn.Parameter(torch.randn(B, d_latent))
        self.time_slots = nn.Parameter(torch.randn(T, d_time))
        
        # Deformation MLP: 7 layers
        # Input: [x, y, z, t_feat] -> Output: [dx, dy, dz]
        self.deformation_mlp = nn.Sequential(
            nn.Linear(3 + d_time, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 3) # Output displacement
        )
        
        # Interpolator Decoder with GeGLU
        # Input: [spatial_feat, view_dir] -> Output: [sigma, color]
        self.decoder = nn.Sequential(
            nn.Linear(d_latent + 3, 256),
            GeGLU(), # Custom layer defined below
            nn.Linear(256, 256),
            GeGLU(),
            nn.Linear(256, 4) # sigma (1) + color (3)
        )

    def get_time_slot(self, t):
        """
        Retrieve time slot feature for time t.
        Assumes t is normalized to [0, T-1] or mapped to indices.
        For simplicity, we assume t is an index into the time slots.
        In practice, interpolation might be used.
        """
        # Clamp t to valid range
        t_idx = torch.clamp(t.long(), 0, self.T - 1)
        return self.time_slots[t_idx]

    def deform(self, x, t):
        """
        Deform 3D position x at time t to canonical space.
        x: (N, 3)
        t: (N,) time values
        """
        t_feat = self.get_time_slot(t)
        input_feat = torch.cat([x, t_feat], dim=-1)
        displacement = self.deformation_mlp(input_feat)
        x_canonical = x + displacement
        return x_canonical

    def aggregate_spatial_features(self, x_canonical):
        """
        Aggregate spatial features using attention.
        x_canonical: (N, 3)
        """
        # Query generation (simplified: linear projection of position)
        # Note: Source says "inner product of the query feature of the 3D position 
        # and the key value of the latent code". 
        # We assume a linear projection for Query and Key.
        q = F.linear(x_canonical, nn.Linear(3, self.latent_codes.shape[1]).weight)
        k = self.latent_codes # (B, d_latent)
        
        # Attention weights
        # q: (N, d_latent), k: (B, d_latent)
        # scores: (N, B)
        scores = torch.matmul(q, k.t())
        alpha = F.softmax(scores, dim=-1)
        
        # Aggregate
        # latent_codes: (B, d_latent)
        spatial_feat = torch.matmul(alpha, self.latent_codes)
        return spatial_feat

    def forward(self, x, d, t):
        """
        Forward pass.
        x: (N, 3) 3D positions
        d: (N, 3) view directions
        t: (N,) timestamps
        """
        # 1. Deform to canonical space
        x_canonical = self.deform(x, t)
        
        # 2. Aggregate spatial features
        spatial_feat = self.aggregate_spatial_features(x_canonical)
        
        # 3. Predict density and color
        input_decoder = torch.cat([spatial_feat, d], dim=-1)
        output = self.decoder(input_decoder)
        
        sigma = output[:, 0:1]
        color = output[:, 1:4]
        
        return sigma, color

class GeGLU(nn.Module):
    def forward(self, x):
        # GeGLU: x * GELU(Wx + b) where x is split into two halves
        # Or more commonly: x * GELU(x) if input dim is even and split?
        # Standard GLU: x * sigmoid(Wx + b)
        # GeGLU: x * GELU(x) is not standard. 
        # Source says "bilinear GLU". 
        # Common implementation: split input into two, apply GELU to one, multiply.
        # Assuming input dim is even.
        dim = x.shape[-1]
        x1, x2 = x.chunk(2, dim=-1)
        return x1 * F.gelu(x2)
```

### Parameters
*   **B (Number of latent features):** 512 [S1].
*   **T (Number of time slots):** 512 [S1].
*   **Learning Rate Decay:** Cosine*exp decay function. Cosine decay alone is unstable; exponential decay alone may get stuck in local optima [S1].

### Edge Cases and Pitfalls
*   **Long-duration inputs:** Excessively long-duration inputs may struggle to fit data adequately with a small number of parameters [S1].
*   **Absence of deformation fields:** Without deformation fields (SLS4Dnd), the absence of decoupling between time and space poses challenges in extracting information for reconstruction [S1].
*   **Removing time slots:** Removing time slots (SLS4Dnf) results in degradation of rendering quality [S1].
*   **Decoder choice:** Using only GeLU (SLS4Dge) or MLP (SLS4Dml) as interpolator decoder results in inferior performance compared to GeGLU [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Proportional to $B \times d_{latent} + T \times d_{time} + \text{MLP parameters}$. The method uses approximately 6% of the parameters of V4D [S1].
*   **Measured Performance:** On the D-NeRF dataset, SLS4D achieves PSNR 34.84, SSIM 0.981, LPIPS 0.025, with ~0.25M parameters [S1].
*   **Training Time:** 3 hours to achieve results similar to V4D (7 hours) on Nvidia 4090; total 6 hours to reach final results [S1].
*   **Strengths:** Significantly reduced parameter count (~6% of V4D), high rendering quality, effective capture of global dynamics via sparse latent space [S1].
*   **Limitations:** Struggles with excessively long-duration inputs due to limited parameters [S1].

## Background
SLS4D was introduced as a novel approach for 4D novel-view synthesis, representing the first method to use a sparse latent space representation for dynamic neural radiance fields [S1]. It builds on the principles of D-NeRF by introducing deformation fields but replaces dense voxel grids with learnable latent codes [S1]. The method was developed to address the high parameter count of previous state-of-the-art methods like V4D and TiNeuVox [S1].
