# SLS4D

Also called: Sparse Latent Space for 4D Novel View Synthesis

## Overview
SLS4D is a method for 4D novel view synthesis that represents dynamic scenes using a sparse, compact, and informative latent feature space, replacing dense voxel grids to significantly reduce network parameters while maintaining high rendering quality [S1]. It distinguishes itself from sibling methods like [TiNeuVox](15551-kfd-nerf.md) and [V4D](13848-gear-nerf.md) by abandoning direct coordinate-based feature determination in favor of relative relationships within a learned latent space, utilizing an attention mechanism to adaptively weight global latent codes [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of input images with known camera poses and timestamps $t$. The method operates on 4D coordinates $(x, y, z, t)$.
*   **Outputs:** Volume density $\sigma$ and view-dependent color $\mathbf{c}$ for any 3D position $\mathbf{x}$ and time $t$, enabling novel view synthesis.

**Data Structures:**
1.  **Time Slots ($T$):** A dense set of learnable 1D vectors representing temporal slots. Size: $T \times D_t$, where $D_t$ is the time slot dimension.
2.  **Spatial Latent Codes ($B$):** A sparse set of globally learnable 3D feature vectors. Size: $B \times D_b$, where $D_b$ is the latent code dimension.
3.  **Deformation Field Network:** A Multi-Layer Perceptron (MLP) mapping 4D coordinates to 3D displacements.
4.  **Interpolator Decoder:** A network using GeGLU activations to map latent features to radiance field properties.

**Parameters:**
*   $B = 512$: Number of spatial latent codes.
*   $T = 512$: Number of time slots.
*   These values are chosen because the total duration of scenes in datasets like HyperNeRF is significantly longer than in D-NeRF [S1].
*   **Learning Rate Decay:** Cosine * exponential decay function. Cosine decay alone is unstable; exponential decay alone may get stuck in local optima [S1].

**Steps:**

1.  **Temporal Encoding:**
    For a query time $t$, retrieve the corresponding dense time slot feature $\mathbf{z}_t$ from the learnable time slots. This ensures smooth transition and separation of deformation fields for each timestamp [S1].

2.  **Deformation Field Prediction:**
    Compute the displacement $\Delta \mathbf{x}$ for a 3D position $\mathbf{x}$ at time $t$ using a 7-layer MLP. The input is the 4D coordinate $(x, y, z, t)$ concatenated with the time slot feature $\mathbf{z}_t$. The output is a 3D vector $(\Delta x, \Delta y, \Delta z)$ [S1].
    $$ \mathbf{x}' = \mathbf{x} + \text{DeformationMLP}([\mathbf{x}, \mathbf{z}_t]) $$
    where $\mathbf{x}'$ is the canonical coordinate. This step decouples time and space, addressing the challenge of extracting information for reconstruction in dynamic scenes [S1].

3.  **Spatial Feature Extraction via Attention:**
    Instead of using coordinate relationships directly, SLS4D relies on relative relationships in the latent feature space [S1].
    *   Query: The canonical position $\mathbf{x}'$ is mapped to a query vector $\mathbf{q}$ (via a linear projection or small MLP).
    *   Keys: The spatial latent codes $\{\mathbf{c}_1, \dots, \mathbf{c}_B\}$ serve as keys.
    *   Weights: The attention weights $\alpha_i$ for each latent code are determined by the inner product of the query $\mathbf{q}$ and the key $\mathbf{c}_i$:
        $$ \alpha_i = \text{softmax}\left(\frac{\mathbf{q} \cdot \mathbf{c}_i}{\sqrt{d}}\right) $$
    *   Aggregation: The spatial feature $\mathbf{f}_{spatial}$ is the weighted sum of the latent codes:
        $$ \mathbf{f}_{spatial} = \sum_{i=1}^{B} \alpha_i \mathbf{c}_i $$
    This mechanism allows the model to integrate global priors and adapt to 4D scenes without explicit positional encoding of the spatial coordinates [S1].

4.  **Radiance Field Decoding:**
    The spatial feature $\mathbf{f}_{spatial}$ and the time slot feature $\mathbf{z}_t$ are concatenated and passed through the Interpolator Decoder. The decoder uses GeGLU (bilinear GLU) activations, which offer higher fitting capacity than standard GeLU or MLPs for modeling complex nonlinear relationships [S1].
    $$ [\sigma, \mathbf{c}] = \text{Decoder}([\mathbf{f}_{spatial}, \mathbf{z}_t]) $$

5.  **Rendering:**
    Standard volume rendering is performed along rays, using the time-dependent density $\sigma(\mathbf{r}(s), t)$ and color $\mathbf{c}(\mathbf{r}(s), \mathbf{d}, t)$ [S1].

6.  **Loss Functions:**
    *   **Photometric Loss:** Standard MSE between rendered and ground truth images.
    *   **Total Variance (TV) Loss:** Applied to the deformation fields to supervise temporal smoothness, ensuring smooth transitions between timestamps [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SLS4D:
    def __init__(self, num_latent_codes=512, num_time_slots=512, 
                 latent_dim=64, time_dim=64, hidden_dim=256):
        """
        Initialize SLS4D model.
        """
        self.num_latent_codes = num_latent_codes
        self.num_time_slots = num_time_slots
        
        # Learnable parameters
        # Spatial latent codes: B x D_b
        self.latent_codes = nn.Parameter(torch.randn(num_latent_codes, latent_dim))
        
        # Time slots: T x D_t
        self.time_slots = nn.Parameter(torch.randn(num_time_slots, time_dim))
        
        # Deformation Field: 7-layer MLP
        # Input: 3 (x,y,z) + D_t (time slot)
        # Output: 3 (dx, dy, dz)
        self.deformation_mlp = nn.Sequential(
            nn.Linear(latent_dim + time_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 3)
        )
        
        # Interpolator Decoder
        # Input: D_b + D_t
        # Output: 4 (sigma, r, g, b)
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim + time_dim, hidden_dim),
            nn.GELU(), # Note: Source mentions GeGLU, implemented as standard GELU for simplicity or custom GLU
            nn.Linear(hidden_dim, hidden_dim),
            nn.GELU(),
            nn.Linear(hidden_dim, 4)
        )

    def get_time_slot(self, t_normalized):
        """
        Retrieve time slot feature for normalized time t in [0, 1].
        Assumes time slots are indexed 0 to T-1.
        """
        # Map normalized time to index
        idx = t_normalized * (self.num_time_slots - 1)
        idx_floor = int(idx)
        idx_ceil = min(idx_floor + 1, self.num_time_slots - 1)
        weight = idx - idx_floor
        
        slot_floor = self.time_slots[idx_floor]
        slot_ceil = self.time_slots[idx_ceil]
        
        # Linear interpolation
        return slot_floor * (1 - weight) + slot_ceil * weight

    def get_spatial_feature(self, canonical_pos):
        """
        Compute spatial feature using attention over latent codes.
        canonical_pos: (N, 3)
        """
        # Project canonical position to query
        # Assuming a simple linear projection for query generation
        query = F.linear(canonical_pos, self.query_weight) # query_weight needs initialization
        
        # Keys are the latent codes
        keys = self.latent_codes # (B, D_b)
        
        # Attention weights
        # (N, D_b) dot (D_b, B) -> (N, B)
        attn_weights = F.softmax(torch.matmul(query, keys.T), dim=1)
        
        # Weighted sum
        spatial_feature = torch.matmul(attn_weights, keys) # (N, D_b)
        return spatial_feature

    def forward(self, xyz, time_normalized, view_dirs=None):
        """
        Forward pass.
        xyz: (N, 3) 3D coordinates
        time_normalized: (N,) normalized time in [0, 1]
        """
        # 1. Get time slot
        time_slots = torch.stack([self.get_time_slot(t) for t in time_normalized]) # (N, D_t)
        
        # 2. Deformation Field
        # Concatenate xyz and time slot
        deform_input = torch.cat([xyz, time_slots], dim=1)
        displacement = self.deformation_mlp(deform_input) # (N, 3)
        
        # Canonical coordinate
        canonical_xyz = xyz + displacement
        
        # 3. Spatial Feature Extraction
        spatial_feature = self.get_spatial_feature(canonical_xyz) # (N, D_b)
        
        # 4. Decoder
        decoder_input = torch.cat([spatial_feature, time_slots], dim=1)
        output = self.decoder(decoder_input) # (N, 4)
        
        sigma = output[:, 0]
        color = torch.sigmoid(output[:, 1:])
        
        return sigma, color

    def compute_tv_loss(self, deformation_field_output):
        """
        Total Variance loss for temporal smoothness.
        deformation_field_output: tensor of displacements over time steps
        """
        # Compute difference between consecutive time steps
        # Assuming shape (T, N, 3) or similar
        diffs = deformation_field_output[1:] - deformation_field_output[:-1]
        return torch.mean(torch.abs(diffs))
```

**Edge Cases and Pitfalls:**
*   **Long-Duration Scenes:** Excessively long-duration inputs may struggle to fit data adequately with a small number of parameters ($B=512, T=512$) [S1].
*   **No Deformation Field (SLS4Dnd):** Removing the deformation field leads to a decline in reconstruction quality due to the lack of decoupling between time and space [S1].
*   **No Time Slots (SLS4Dnf):** Removing time slots results in degradation of rendering quality, as they ensure smoothness of dense temporal information [S1].
*   **Decoder Choice:** Using only GeLU (SLS4Dge) or a standard MLP (SLS4Dml) as the interpolator decoder results in inferior performance compared to GeGLU [S1].
*   **Learning Rate:** Using only cosine decay (SLS4Dco) is unstable; using only exponential decay (SLS4Deo) may get stuck in local optima [S1].

## Background
SLS4D was introduced as a novel approach for 4D novel-view synthesis, representing the first use of a sparse latent space for dynamic neural radiance fields [S1]. It builds upon the principles of D-NeRF by introducing deformation fields to separate time and space, but replaces the dense feature space with a sparse set of globally learnable latent codes [S1]. The method was developed to address the high parameter count and computational cost of previous SOTA methods like V4D and TiNeuVox [S1].
