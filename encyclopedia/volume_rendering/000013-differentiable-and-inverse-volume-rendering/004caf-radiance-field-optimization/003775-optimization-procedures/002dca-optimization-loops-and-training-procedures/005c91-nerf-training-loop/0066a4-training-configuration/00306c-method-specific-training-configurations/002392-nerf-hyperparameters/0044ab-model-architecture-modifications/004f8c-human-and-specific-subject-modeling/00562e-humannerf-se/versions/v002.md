# HumanNeRF-SE

Also called: HumanNeRF with Sparse Encoding

## Overview
HumanNeRF-SE is a method for synthesizing novel pose images of humans from monocular video inputs by combining explicit SMPL shape priors with an implicit NeRF representation [S1]. It solves the problem of overfitting and high computational complexity inherent in previous deformable NeRF methods, which often require large numbers of optimizable parameters and multi-camera data [S1]. Unlike siblings such as [HumanNeRF](13842-humannerf.md) and [Unified Volumetric Avatar (UVA)](13784-unified-volumetric-avatar-uva.md) that learn blending weights from scratch or fine-tune SMPL weights, HumanNeRF-SE uses frozen SMPL blending weights for rigid deformation and filters irrelevant sampling points using a sparse convolutional voxel volume, ensuring pose generalization without pose leakage [S1].

## How it works
**Inputs:** Monocular video frames of a human performer; SMPL model parameters (vertices $v$, joints $J$) for each frame.
**Outputs:** Rendered image $C(r)$ for arbitrary viewpoints and poses.

**Data Structures:**
*   **Voxel Volume $V$:** A sparse 3D grid. Each voxel containing SMPL vertices stores a tuple $(n_v, w_1, \dots, w_{24})$, where $n_v$ is the vertex count (occupancy) and $w_j$ are the SMPL Linear Blending Skinning (LBS) weights for the 24 joints [S1]. Empty voxels store $(0, 0, \dots, 0)$ [S1].
*   **Spatial-Aware Features $F_s$:** Output of channel-by-channel convolution on $V$, providing local geometric context for sampling points [S1].

**Numbered Steps:**

1.  **Voxelization:** Calculate the bounding box of the SMPL vertices $v$. Scale the bounding box to a set voxel size $v_s$. Find the least common multiple of the axes dimensions and 32. Scale vertices down by $v_s$ after subtracting the minimum coordinate. Construct the voxel volume $V$ using Sparse Convolution $Sp$:
    $$ V = Sp(v, v_s, W) $$
    [S1]

2.  **Conv-Filter (Feature Extraction & Point Filtering):** Initialize a convolution kernel to one. Perform channel-by-channel convolution on $V$ to obtain spatially-aware features $F_s$. For the $i$-th channel:
    $$ F_{s,i} = \sum_{m=h}^{h'} \sum_{n=w}^{w'} \sum_{t=d}^{d'} \nu_{m,n,t,i} \cdot \vartheta_{m,n,t,i} $$
    where $\nu$ is the voxel value and $\vartheta$ is the kernel weight [S1].
    Query the occupancy of $F_s(x)$ for each sampling point $x$:
    *   If $F_s(x) = 0$, the point is irrelevant ($x_o$). Force its density $\sigma(x_o) = 0$ and exclude it from further deformation [S1].
    *   If $F_s(x) > 0$, the point is human-related ($x_r$). Keep it for canonicalization [S1].

3.  **Point Canonicalization (Rigid Deformation):** Query the nearest neighbor SMPL weights $W_{smpl} = K(x_r, v)$ for the remaining points $x_r$. Compute the rigid deformation $x^{rcnl}$ using the frozen SMPL blending weights and current pose joints $J$:
    $$ x^{rcnl} = \sum_{j \in J} w_j ((x_r \cdot R_j) + T_j) $$
    where $R_j$ and $T_j$ are the rotation and translation of the $j$-th joint relative to the T-pose, and $w_j$ is the deformation weight of the $j$-th channel of $W_{smpl}$ on the sampled point [S1].

4.  **Point Canonicalization (Non-Rigid Refinement):** Refine the coarse coordinates using a network $P$ conditioned on the spatial-aware features $F_s$ and the filtered points $x_r$:
    $$ x^{cnl} = x^{rcnl} + P(F_s, x_r) $$
    This step accounts for non-rigid clothing deformation that rigid LBS cannot capture [S1].

5.  **Appearance Net:** Encode the canonical coordinates $x^{cnl}$ using positional encoding (as in standard NeRF). Pass through an MLP $M_\sigma$ to output color $\mathbf{c}$ and density $\sigma$:
    $$ \mathbf{c}, \sigma = M_\sigma(x^{cnl}) $$
    [S1]

6.  **Volume Rendering:** Render the image using differentiable volume rendering along ray $r$ with $N_s$ samples:
    $$ \tilde{C}_t(r) = \sum_{k=1}^{N_s} \alpha_k \mathbf{c}(x_k) \prod_{j=1}^{k-1} (1 - \alpha_j) $$
    where $\alpha_i = 1 - \exp(-\sigma(x_i) \Delta t_i)$ [S1].

**Pseudocode:**

```python
def human_nerf_se_forward(smpl_vertices, pose_joints, ray_samples, voxel_size):
    # 1. Voxelization
    # Calculate bounding box of smpl_vertices
    min_coord, max_coord = compute_bounding_box(smpl_vertices)
    # Scale vertices to voxel grid
    scaled_vertices = scale_vertices(smpl_vertices, min_coord, voxel_size)
    # Construct sparse voxel volume V with occupancy and SMPL weights
    V = sparse_convolution(scaled_vertices, voxel_size)
    
    # 2. Conv-Filter
    # Initialize kernel to ones
    kernel = initialize_kernel_ones()
    # Channel-by-channel convolution to get spatial features Fs
    Fs = channel_by_channel_conv(V, kernel)
    
    # Filter points
    human_points = []
    filtered_points = []
    for point in ray_samples:
        # Query spatial feature at point location
        feature_val = query_voxel(Fs, point)
        if feature_val > 0:
            human_points.append(point)
        else:
            filtered_points.append(point)
            
    # 3. Rigid Deformation
    # Query nearest SMPL weights for human points
    W_smpl = query_nearest_smpl_weights(human_points, smpl_vertices)
    
    # Compute rigid transform using frozen SMPL weights and current pose
    x_rcnl = zeros_like(human_points)
    for j in pose_joints:
        w_j = W_smpl[:, j]
        R_j, T_j = get_pose_transform(j, pose_joints)
        x_rcnl += w_j * (human_points * R_j + T_j)
        
    # 4. Non-Rigid Refinement
    # Get spatial features for human points
    Fs_human = query_voxel(Fs, human_points)
    # Refine coordinates using point-level network P
    x_cnl = x_rcnl + P(Fs_human, human_points)
    
    # 5. Appearance Net
    # Encode canonical points
    encoded_cnl = positional_encoding(x_cnl)
    # Predict color and density
    color, density = MLP(encoded_cnl)
    
    # Set density to 0 for filtered points
    density_filtered = zeros_like(density)
    
    # 6. Rendering
    # Combine densities and colors for all samples
    all_density = concatenate(density, density_filtered)
    all_color = concatenate(color, zeros_like(color))
    
    # Volume render
    alpha = 1 - exp(-all_density * delta_t)
    T = product(1 - alpha[:-1])
    rendered_color = sum(alpha * all_color * T)
    
    return rendered_color
```

**Parameters:**
*   $v_s$: Voxel size used to scale the bounding box of the SMPL model [S1].
*   $\lambda$: Weight for the MSE loss term in the total loss function [S1].
*   SMPL Blending Weights: Frozen, not fine-tuned [S1].

**Edge Cases and Pitfalls:**
*   **Overfitting:** Using learnable or fine-tuned SMPL weights leads to artifacts in novel poses because the weights overfit the limited training data [S1].
*   **Pose Leakage:** Using frame-level features (e.g., frame index) in the refinement network causes the model to memorize specific poses rather than generalizing. HumanNeRF-SE avoids this by using only point-level features $F_s$ [S1].
*   **Irrelevant Points:** Simply using nearest SMPL weights fills the volume with incorrect colors because training deforms irrelevant points onto the body. The Conv-Filter is essential to remove these points [S1].
*   **Alpha Map Errors:** If points are not filtered, the network may learn incorrect alpha maps due to color diffusion into surrounding space, increasing computational complexity and training time [S1].

## Operating characteristics
*   **Complexity:** Reduces required sampling points from ~300K to less than 100K [S1]. Uses less than 1% of learnable parameters compared to previous methods [S1].
*   **Performance:** Reduces training time by 95% (to 1/20 of previous methods) [S1]. Increases rendering speed by 15 times without using existing acceleration modules [S1].
*   **Quality:** On ZJU-MOCAP few-shot evaluation: PSNR=31.09, SSIM=0.974, LPIPS=24.085 (where LPIPS is scaled by 1,000). This outperforms HumanNeRF (PSNR=30.10, SSIM=0.9677, LPIPS=33.056) and MonoHuman (PSNR=30.11, SSIM=0.9684, LPIPS=32.084) [S1].
*   **Strengths:** Generalizes to diverse poses with few-shot input; avoids overfitting; computationally efficient; works with monocular input.
*   **Limitations:** Relies on the accuracy of the SMPL model; performance may degrade if the subject's body shape deviates significantly from the SMPL average [S1].

## Background
HumanNeRF-SE was introduced in 2024 by Miles et al. in the paper "HumanNeRF-SE: A Simple yet Effective Approach to Animate HumanNeRF with Diverse Poses" [S1]. It addresses the limitations of earlier methods like HumanNeRF [56] and MonoHuman [62], which struggled with overfitting and required extensive training data or multi-camera setups [S1]. The method builds on the insight that explicit shape priors (SMPL) can reduce the burden on the implicit NeRF representation [S1].
