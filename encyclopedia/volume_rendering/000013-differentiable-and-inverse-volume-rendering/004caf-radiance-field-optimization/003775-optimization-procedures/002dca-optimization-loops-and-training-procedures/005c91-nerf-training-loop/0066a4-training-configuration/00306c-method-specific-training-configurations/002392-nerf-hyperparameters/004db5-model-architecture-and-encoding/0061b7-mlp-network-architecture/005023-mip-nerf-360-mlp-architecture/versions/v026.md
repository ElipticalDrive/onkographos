# Mip-NeRF 360 MLP Architecture

Also called: Integrated Positional Encoding MLP, PosEnc MLP

## Overview
The Mip-NeRF 360 MLP architecture is a two-branch Multi-Layer Perceptron (MLP) that predicts volume density and view-dependent radiance for differentiable volume rendering. It distinguishes itself from standard NeRF by using **integrated positional encoding** to analytically integrate the positional encoding function over Gaussian intervals, thereby reducing aliasing artifacts from high-frequency scene details [S1, unofficial]. The architecture supports optional extensions for specular shading, roughness prediction, and normal estimation.

## How it works
The method consists of a density network and a color network, connected by a bottleneck vector. The density network processes 3D spatial coordinates, while the color network processes the bottleneck features along with view or reflection directions.

### Inputs and Outputs
**Inputs:**
*   `means`: Array of shape `(batch, num_samples, 3)` representing the centers of the Gaussian intervals for each ray sample.
*   `covs`: Array of shape `(batch, num_samples, 3, 3)` representing the covariance matrices of the Gaussian intervals.
*   `viewdirs`: Array of shape `(batch, num_samples, 3)` representing the normalized view directions (from camera to point).
*   `refdirs` (optional): Array of shape `(batch, num_samples, 3)` representing reflection directions.
*   `normals` (optional): Array of shape `(batch, num_samples, 3)` representing surface normals.
*   `glo_vec` (optional): Global vector for scene-level features.

**Outputs:**
*   `raw_density`: Scalar density values.
*   `rgb`: Final rendered RGB colors.
*   `normals`: Estimated surface normals (if enabled).
*   `roughness` (optional): Predicted roughness values.

### Data Structures and Parameters
The architecture is defined by the following hyperparameters [S1, unofficial]:

*   `net_depth`: Depth of the density MLP (default: 8).
*   `net_width`: Width of the density MLP layers (default: 256).
*   `bottleneck_width`: Width of the bottleneck vector (default: 256).
*   `net_depth_viewdirs`: Depth of the color MLP (default: 1).
*   `net_width_viewdirs`: Width of the color MLP layers (default: 128).
*   `min_deg_point`: Minimum degree of positional encoding for points (default: 0).
*   `max_deg_point`: Maximum degree of positional encoding for points (default: 12).
*   `deg_view`: Degree of positional encoding for directions (default: 4).
*   `skip_layer`: Frequency of skip connections in the density MLP (default: 4).
*   `skip_layer_dir`: Frequency of skip connections in the color MLP (default: 4).
*   `density_bias`: Bias added to raw density before activation (default: -1.0).
*   `density_noise`: Standard deviation of noise added to raw density (default: 0.0).
*   `rgb_bias`: Bias added to raw color before activation (default: 0.0).
*   `rgb_padding`: Padding for RGB output range (default: 0.001).
*   `basis_shape`: Basis shape for integrated encoding ('icosahedron' or 'octahedron', default: 'icosahedron').
*   `basis_subdivisions`: Tessellation count for the basis (default: 2).
*   `use_reflections`: Use reflection directions instead of view directions (default: False).
*   `use_directional_enc`: Use Integrated Directional Encoding (IDE) (default: False).
*   `enable_pred_normals`: Enable predicted normals via a separate network (default: False).
*   `disable_density_normals`: Disable gradient-based normals from density (default: False).
*   `use_diffuse_color`: Predict diffuse and specular colors separately (default: False).
*   `use_specular_tint`: Predict a tint vector for specular color (default: False).
*   `use_n_dot_v`: Include dot product of normal and view direction (default: False).
*   `enable_pred_roughness`: Predict roughness (default: False).
*   `roughness_bias`: Bias for roughness pre-activation (default: -1.0).
*   `bottleneck_noise`: Noise added to bottleneck vector (default: 0.0).
*   `warp_fn`: Optional warping function for linearization.

### Pseudocode

```python
import jax.numpy as jnp
import jax
from jax import random

def mlp_mipnerf_360(
    means, covs, viewdirs, refdirs=None, normals=None, glo_vec=None,
    config, params, key=None
):
    """
    Mip-NeRF 360 MLP Architecture.
    
    Args:
        means: (B, N, 3) Gaussian means.
        covs: (B, N, 3, 3) Gaussian covariances.
        viewdirs: (B, N, 3) View directions.
        refdirs: (B, N, 3) Optional reflection directions.
        normals: (B, N, 3) Optional normals.
        glo_vec: (B, N, G) Optional global vector.
        config: Configuration object with hyperparameters.
        params: Dictionary of MLP weights.
        key: JAX PRNG key.
        
    Returns:
        dict with 'raw_density', 'rgb', 'normals', etc.
    """
    
    # --- Setup ---
    # Validate reflection requirements
    if config.use_reflections:
        if not config.enable_pred_normals and config.disable_density_normals:
            raise ValueError("Reflections require normals to be computed.")
            
    # Precompute basis transpose for integrated positional encoding
    # geopoly.generate_basis returns basis matrix; we store transpose
    basis_matrix = geopoly_generate_basis(config.basis_shape, config.basis_subdivisions)
    pos_basis_t = basis_matrix.T
    
    # Setup directional encoding function
    if config.use_directional_enc:
        dir_enc_fn = ref_utils_generate_ide_fn(config.deg_view)
    else:
        def dir_enc_fn(v):
            return coord_pos_enc(v, min_deg=0, max_deg=config.deg_view, append_identity=True)

    # --- Density Prediction ---
    
    # Linearize means and covs if warping is used
    if config.warp_fn is not None:
        means, covs = coord_track_linearize(config.warp_fn, means, covs)
        
    # Lift and diagonalize covariances using the basis
    lifted_means, lifted_vars = coord_lift_and_diagonalize(
        means, covs, pos_basis_t
    )
    
    # Compute integrated positional encoding
    # This integrates the positional encoding over the Gaussian intervals
    x = coord_integrated_pos_enc(
        lifted_means, lifted_vars, 
        config.min_deg_point, config.max_deg_point
    )
    
    # Density MLP (First Branch)
    # Input x shape: (B, N, D_point)
    for i in range(config.net_depth):
        # Dense layer with net_width
        x = dense_layer(x, params['density_dense_' + str(i)], config.net_width)
        x = activation(x, config.net_activation)
        
        # Skip connections
        if i > 0 and i % config.skip_layer == 0:
            x = jnp.concatenate([x, x_orig], axis=-1)
            
    # Output raw density
    raw_density = dense_layer(x, params['density_output'], width=1)[..., 0]
    
    # Add density noise
    if config.density_noise > 0 and key is not None:
        noise = random.normal(key, raw_density.shape)
        raw_density = raw_density + config.density_noise * noise
        
    # Compute normals from raw density gradient if enabled
    if not config.disable_density_normals:
        # Flatten for vmap
        flat_means = means.reshape(-1, 3)
        flat_covs = covs.reshape(-1, 3, 3)
        
        # Compute value and gradient of density w.r.t means
        # predict_density takes (means, covs) and returns raw_density
        raw_density_flat, raw_grad_density_flat = jax.vmap(
            jax.value_and_grad(predict_density_single, has_aux=False)
        )(flat_means, flat_covs)
        
        # Reshape gradients
        raw_grad_density = raw_grad_density_flat.reshape(means.shape)
        
        # Normals are negative normalized gradient
        normals_density = -ref_utils_l2_normalize(raw_grad_density)
    else:
        normals_density = None

    # Density Activation
    final_density = density_activation(raw_density + config.density_bias)
    
    # --- Directional Encoding ---
    
    # Determine direction vector
    if config.use_reflections:
        # Flip viewdirs because they point camera->point, but reflect assumes point->camera
        if refdirs is not None:
            dir_vec = refdirs
        else:
            dir_vec = -viewdirs
    else:
        dir_vec = viewdirs
        
    # Encode direction
    dir_enc = dir_enc_fn(dir_vec)
    
    # --- Color Network Input Construction ---
    
    # Broadcast dir_enc to match bottleneck dimensions if necessary
    # Assuming bottleneck is derived from density output
    bottleneck = x # From last layer of density MLP before output? 
                   # Note: In standard NeRF, bottleneck is the output of the 
                   # hidden layers before the density head. 
                   # Here, we assume 'x' after the loop is the bottleneck representation.
                   # However, the source says "Append dir_enc to bottleneck list x".
                   # Let's assume x here is the feature vector before density head.
                   # Re-reading source: "Iterate i from 0 to net_depth-1... Output raw density".
                   # Usually, the bottleneck is the output of the last hidden layer.
                   # Let's assume the variable 'x' after the loop is the bottleneck.
    
    # Prepare list for concatenation
    x_list = [bottleneck]
    
    # Broadcast dir_enc
    # dir_enc shape: (B, N, D_dir)
    # bottleneck shape: (B, N, D_bottleneck)
    dir_enc_broadcast = jnp.broadcast_to(
        dir_enc[..., None, :], 
        bottleneck.shape[:-1] + (dir_enc.shape[-1],)
    )
    x_list.append(dir_enc_broadcast)
    
    # Optional: n dot v
    if config.use_n_dot_v:
        # Use normals_density if available, else normals input
        normals_to_use = normals_density if normals_density is not None else normals
        if normals_to_use is not None:
            dotprod = jnp.sum(
                normals_to_use * viewdirs[..., None, :], 
                axis=-1, 
                keepdims=True
            )
            x_list.append(dotprod)
            
    # Optional: glo_vec
    if config.glo_vec is not None:
        glo_vec_broadcast = jnp.broadcast_to(
            config.glo_vec[..., None, :], 
            bottleneck.shape[:-1] + (config.glo_vec.shape[-1],)
        )
        x_list.append(glo_vec_broadcast)
        
    # Concatenate all
    x_color = jnp.concatenate(x_list, axis=-1)
    
    # Color MLP (Second Branch)
    for i in range(config.net_depth_viewdirs):
        x_color = dense_layer(x_color, params['color_dense_' + str(i)], config.net_width_viewdirs)
        x_color = activation(x_color, config.net_activation)
        
        if i > 0 and i % config.skip_layer_dir == 0:
            x_color = jnp.concatenate([x_color, x_color_orig], axis=-1)
            
    # RGB Output
    raw_rgb = dense_layer(x_color, params['color_output'], width=config.num_rgb_channels)
    
    # Apply premultiplier and bias
    rgb_premultiplied = config.rgb_premultiplier * raw_rgb + config.rgb_bias
    
    # --- Specular/Diffuse Split and Tone Mapping ---
    
    if config.use_diffuse_color:
        # Predict diffuse and specular separately
        # raw_rgb is assumed to contain diffuse + specular components or separate heads?
        # Source says: diffuse_linear = sigmoid(raw_rgb_diffuse - log(3.0))
        # This implies raw_rgb might be split or we need separate outputs.
        # Assuming raw_rgb contains diffuse in first channel or similar?
        # Standard MipNeRF 360 uses separate outputs for diffuse/specular if enabled.
        # For simplicity, assuming raw_rgb has diffuse component.
        # Note: Source logic is specific. 
        diffuse_linear = nn_sigmoid(raw_rgb[..., 0] - jnp.log(3.0)) # Example assumption
        
        if config.use_specular_tint:
            # Tint is predicted, let's assume it's in params or glo_vec
            # Source: specular_linear = tint * rgb
            # This is ambiguous without full context on 'tint'. 
            # Assuming tint is a scalar or vector multiplier.
            specular_linear = config.tint * raw_rgb
        else:
            specular_linear = 0.5 * raw_rgb
            
        rgb_combined = specular_linear + diffuse_linear
        rgb = jnp.clip(image_linear_to_srgb(rgb_combined), 0.0, 1.0)
    else:
        rgb = rgb_activation(rgb_premultiplied)
        
    # RGB Padding
    rgb = rgb * (1 + 2 * config.rgb_padding) - config.padding
    
    # --- Roughness Prediction (Optional) ---
    if config.enable_pred_roughness:
        roughness = roughness_activation(raw_roughness + config.roughness_bias)
    else:
        roughness = None
        
    return {
        'raw_density': raw_density,
        'density': final_density,
        'rgb': rgb,
        'normals': normals_density,
        'roughness': roughness
    }

def predict_density_single(means, covs):
    """Helper to compute density for gradient computation."""
    # Re-run integrated pos enc and density head for this single sample
    # This is computationally expensive but necessary for vmap+grad
    lifted_means, lifted_vars = coord_lift_and_diagonalize(
        means[None, ...], covs[None, ...], pos_basis_t
    )
    x = coord_integrated_pos_enc(
        lifted_means, lifted_vars, 
        config.min_deg_point, config.max_deg_point
    )
    # Run density MLP
    for i in range(config.net_depth):
        x = dense_layer(x, params['density_dense_' + str(i)], config.net_width)
        x = activation(x, config.net_activation)
        if i > 0 and i % config.skip_layer == 0:
            # Skip connection logic requires storing original x
            pass 
    raw_density = dense_layer(x, params['density_output'], width=1)[..., 0]
    return raw_density[0]
```

### Edge Cases and Pitfalls
1.  **Reflections and Normals**: If `use_reflections` is True, normals must be available. This requires either `enable_pred_normals` to be True or `disable_density_normals` to be False. If neither is met, a `ValueError` is raised [S1, unofficial].
2.  **Reflection Direction Flip**: View directions typically point from the camera to the point. The reflection function `ref_utils.reflect` assumes directions point toward the camera. Therefore, view directions must be flipped (`-viewdirs`) before computing reflections [S1, unofficial].
3.  **Normal Stability**: Normals are computed from the gradient of the **raw** (pre-activation) density, not the final activated density. This is because the activation function (e.g., softplus) may have steep or flat gradients that distort the normal estimation [S1, unofficial].
4.  **Integrated Encoding**: The use of `integrated_pos_enc` requires the covariance matrices to be diagonalized in the lifted basis. Failure to correctly lift and diagonalize leads to incorrect frequency integration [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: The dominant cost is the integrated positional encoding, which involves matrix multiplications with the basis matrix for each sample. The MLP forward pass is $O(N \cdot D^2)$ where $N$ is the number of samples and $D$ is the width.
*   **Memory Complexity**: Requires storing the covariance matrices and the basis matrix. The integrated encoding increases the feature dimension compared to standard positional encoding.
*   **Strengths**: Significantly reduces aliasing artifacts in scenes with high-frequency details or when rays pass through large intervals (mip-splatting effect). Supports view-dependent shading and normal estimation.
*   **Limitations**: More complex to implement than standard NeRF due to the integrated encoding and basis generation. Slightly higher computational overhead per sample.
*   **When to use**: Ideal for unbounded scenes (360-degree) or scenes with significant depth variation where standard NeRF suffers from aliasing.

## Background
The Mip-NeRF 360 MLP architecture was introduced by Mildenhall et al. in the context of Mip-NeRF 360, extending the original Mip-NeRF approach to unbounded scenes. It integrates the concept of integrated positional encoding to handle the integration of radiance along rays more accurately. The architecture is part of the Google Research Multinerf project [S1, unofficial].
