# Method-Specific Training Configurations


## Overview
This family encompasses the hyperparameter settings, architectural deviations, and optimization schedules required to train specific Neural Radiance Field (NeRF) variants and related inverse rendering methods. While standard NeRF optimization relies on a generic hierarchical sampling loop with Adam optimization [Parent], these configurations address specific challenges such as anti-aliasing (Mip-NeRF), computational efficiency via sparse sampling (DONeRF), unsupervised depth/defocus learning (AR-NeRF), super-resolution (NeRF-SR), and mobile deployment constraints (DP-based Configuration Selector). Each entry defines the precise numerical values, loss weights, and network structures that distinguish the method from the baseline NeRF [3065-nerf-hyperparameters.md] and its siblings.

## Shared principles
The training configurations in this family share the following foundational mechanisms:
1.  **Differentiable Volume Rendering:** All methods compute rendered pixel colors $\hat{C}(\mathbf{r})$ via the differentiable volume rendering integral:
    $$ \hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i $$
    where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ is the opacity, $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the transmittance, $\sigma_i$ is the volume density, $\mathbf{c}_i$ is the view-dependent color, and $\delta_i$ is the distance between samples [Parent].
2.  **Photometric Loss:** The primary objective is minimizing the difference between rendered colors and ground truth images, typically using Mean Squared Error (MSE) or Charbonnier loss [Parent][S1].
3.  **Adam Optimizer:** Most variants utilize the Adam optimizer [S1][S3][S9, unofficial].
4.  **Hierarchical or Importance Sampling:** Many methods (NeRF, Mip-NeRF, NeRF-SR) employ a coarse-to-fine sampling strategy where a proposal network guides the sampling of fine points in high-density regions [Parent][S1].

## Subtopics

### [NeRF Hyperparameters](3065-nerf-hyperparameters.md)
Standard NeRF training configuration. Uses 8-layer MLPs (256/512 units), 10/4 frequency positional encoding, 64 coarse/128 fine samples, Adam optimizer ($lr=5\times10^{-4}$), and 200k–300k iterations. Sensitive to the balance between coarse/fine sampling and learning rate decay.

### [Mip-NeRF Optimization and Activation Details](3409-mip-nerf-optimization-and-activation-details.md)
Optimizes Mip-NeRF and JaxNeRF for stability. Removes identity encoding from MLP input. Uses **Shifted Softplus** for density ($\tau = \log(1 + \exp(x_\tau - 1))$) to prevent negative density failure, and **Widened Sigmoid** for color ($c = \frac{1 + 2\epsilon}{1 + \exp(-x_c)} - \epsilon, \epsilon=0.001$) to handle black/white pixels. Uses a warmup phase followed by logarithmic annealing for learning rate.

### [DONeRF](4461-donerf.md)
Replaces dense raymarching with a dual-network design: a **Depth Oracle** (classification of depth bins) and a **Shading Network** (color/density). Oracle predicts sample locations, allowing shading network to use only 2–16 samples per ray. Trained sequentially: Oracle for 300k iters, then Shading for 300k iters. Includes an **Opacity Loss** to prevent dark pixel artifacts from low sample counts.

### [AR-NeRF Training Configuration](12407-ar-nerf-training-configuration.md)
Unsupervised learning of depth/defocus from natural images using aperture rendering. Builds on pi-GAN. Uses **FiLM-SIREN** networks (Foreground: 8 layers/128 units; Background: 8 layers/64 units). Includes **Identity Regularization** ($\lambda_{id}=15$) to maintain semantic consistency across views. Discriminator uses CoordConv for aligned faces (FFHQ) but not for flowers/birds.

### [NeRF-SR Training Configuration](15560-nerf-sr-training-configuration.md)
Super-resolution from low-resolution inputs. Uses hierarchical sampling (64 coarse/64 fine) and Adam optimizer. Trained for 20 epochs (Blender) or 30 epochs (LLFF). Employs a **Refinement Network** for real-world data (LLFF) using $K=8$ reference patches to boost high-frequency details.

### [DP-based Configuration Selector](15955-dp-based-configuration-selector.md)
Selects optimal NeRF configurations (grid resolution/plane parameters) for multiple objects under a strict memory budget $H$. Formulated as a **Multiple-Choice Knapsack (MCK)** problem. Uses Dynamic Programming to guarantee an optimal solution within memory limits (e.g., 240MB for iPhone 13, 150MB for Pixel 4), avoiding greedy failures.

### Blender Dataset Simplified Configuration
For the Blender dataset, a simplified configuration is used for speed: one round of sampling, 128 samples for the proposal MLP, 32 samples for the NeRF MLP. Proposal MLP has 4 layers/256 hidden units; NeRF MLP has 8 layers/256 (or 512) hidden units. Uses axis-aligned Integrated Positional Encoding (IPE), MSE loss, and no distortion regularizer [S1].

### LLFF Training Configuration
For the LLFF dataset, the distortion regularizer is **not** disabled. Charbonnier loss is used instead of MSE. Performance metrics for 256 hidden units: mip-NeRF (PSNR 26.93, SSIM 0.830, LPIPS 0.177, Time 2.48 hrs, Params 0.61M); Our Model (PSNR 26.68, SSIM 0.847, LPIPS 0.150, Time 2.39 hrs, Params 0.84M). For 512 hidden units: mip-NeRF (PSNR 27.01, SSIM 0.845, LPIPS 0.148, Time 6.15 hrs, Params 2.27M); Our Model (PSNR 26.86, SSIM 0.858, LPIPS 0.128, Time 3.84 hrs, Params 3.23M). The model does not outperform mip-NeRF in PSNR but yields improved SSIM/LPIPS and significant speedup with large MLPs [S1].

### NeUDF Training Configuration
Trains Neural Unsigned Distance Fields. Optimizer: ADAM. Learning rate warms up to $2 \times 10^{-4}$ in the first 5k iterations, decreasing to $1 \times 10^{-5}$ by the end. Batch size: 512 random rays from 8 randomly selected camera poses. Total training: 400k iterations (9 hours with mask, 11 hours without mask on Nvidia 3090) [S2].

### NeRF-SDP Training Configuration
Efficient generalizable NeRF with Scene Depth Perception. Optimizer: Adam. Learning rate: $1\times10^{-3}$ for Res-UNet, $5\times10^{-4}$ for other parts. Batch size: 500. Hardware: Nvidia RTX 3090. Total steps: 250,000. First 170,000 steps optimize auxiliary and rendering losses; last 80,000 steps optimize only rendering loss. Feature dimensions: 2D features 24, 3D features 8. Datasets: LLFF, IBRNet, Google Scanned [S3].

### Neuralangelo Training Configuration
High-fidelity neural surface reconstruction. Samples pixels randomly without tracking statistics/errors; uses long training iterations (500k total) to reduce stochastics. ROI assumed inside a unit sphere. Inactive hash resolution feature vectors set to zero. Learning rate: $1\times10^{-3}$ with 5k linear warmup, decaying by factor of 10 at 300k and 400k iterations. Optimizer: AdamW (weight decay $10^{-2}$, $w_{iek}=0.1$). SDF MLP: 1 layer; Color MLP: 4 layers. Batch size: 1 (DTU), 16 (Tanks and Temples) [S4].

### GO-NeRF Training Configuration
Generates objects in NeRF for VR. Optimizes generation model on Nvidia 3090 for 20,000 iterations. 30% of iterations trained with background augmentation. Scheduler values for $\lambda_S$ and $\lambda_O$ range from 30 to 300. $\lambda_R$ set to 500 [S5].

### Tri-MipRF Training Configuration
Tri-Mip Representation for Efficient Anti-Aliasing. Base mipmap shape $M_{l0}$: H=512, W=512, C=16. Optimizer: AdamW (weight decay $10^{-5}$, LR $2\times10^{-3}$, MultiStepLR schedule). Tri-Mip encoding LR scaled up 10x relative to MLP. Loss: Area loss $L_{area}$ (scaling pixel loss by footprint area). Framework: PyTorch, tiny-cuda-nn, nvdiffrast [S6].

### NeRF† Implementation Configuration
Variant of nerfacto using standard MLP density field instead of HashMLPDensityField.
*   **Blender:** $t_n=2.0, t_f=6.0$. Camera optimizer, appearance embedding, distortion loss, scene contraction disabled. Background white. Batch size 2048 rays. Initial sampler uniform. 16.5k epochs.
*   **LLFF:** Camera optimizer, appearance embedding, distortion loss disabled. Scene contraction uses $\ell_\infty$ norm. Batch size 1024 rays (train), 2048 (eval). 30k epochs. Leaves scene uses uniform initial proposal sampler.
*   **Mip-NeRF 360:** PSNR 24.20, SSIM 0.726, LPIPS 0.247. Comparable to nerfacto but significantly slower [S7].

### DVGO Reference Architecture
Reference architecture for DVGO. Compression method: Re:NeRF. Hardware: NVIDIA A40 GPU. Software: PyTorch 1.12 [S8].

### Nerfacto Training Configuration
Production NeRF baseline. Uses Adam optimizer with learning rate schedule $10^{-2} \to 10^{-4}$. Trained for 30k iterations by default [S9, unofficial].

## Background
The standard NeRF training loop [Parent] established the baseline for differentiable volume rendering optimization. Subsequent research introduced method-specific configurations to address limitations in rendering quality (anti-aliasing with Mip-NeRF [S1]), computational cost (DONeRF [S3], Tri-MipRF [S6]), unsupervised learning (AR-NeRF [S1]), super-resolution (NeRF-SR [S1]), and deployment constraints (DP-based Selector [S1], Nerfacto [S9, unofficial]). These configurations define the precise hyperparameters, loss functions, and architectural tweaks necessary to reproduce the results reported in their respective primary sources.
