# Feature Fields

Also called: Generalized NeRF, Semantic Fields

## Overview
Feature Fields generalize the Neural Radiance Field (NeRF) formulation to predict arbitrary per-point feature signals $\mathbf{f}$ in addition to color $\mathbf{c}$ and density $\sigma$ [S1, 12095-semantic-and-feature-branches.md, unofficial]. This allows the representation of semantic labels, physical properties, or latent embeddings within the 3D volume [S1, 12095-semantic-and-feature-branches.md, unofficial]. Unlike standard NeRF which only models appearance, this family lifts 2D observations into a consistent 3D representation, enabling tasks such as zero-shot segmentation, object manipulation, and view-dependent reflection modeling [S1, 12095-semantic-and-feature-branches.md, 12404-nerf-for-object-segmentation.md, unofficial].

## Shared principles
The core mechanism modifies the radiance field function $F_\Theta$ to map input coordinates $(\mathbf{x}, \mathbf{d})$ to a tuple $(\mathbf{f}, \mathbf{c}, \sigma)$, where $\mathbf{f} \in \mathbb{R}^d$ is a feature vector [12995-feature-fields.md]. The rendering of these features follows the same volume integration principle as color. For a ray $r$, the rendered feature $\hat{\mathbf{F}}(r)$ is computed as:

$$
\hat{\mathbf{F}}(r) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{f}(x_i)
$$

where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance and $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ is the opacity weight [12995-feature-fields.md]. Supervision is performed by comparing the rendered feature $\hat{\mathbf{F}}(r)$ against ground-truth 2D feature maps or teacher network outputs projected onto the image plane [12995-feature-fields.md]. This process lifts 2D observations into a consistent 3D representation [12995-feature-fields.md].

## Subtopics

### [Multi-Space Neural Radiance Field (MS-NeRF)](11707-multi-space-neural-radiance-field-ms-nerf.md)
MS-NeRF addresses the failure of standard NeRF methods to render reflective and refractive objects, which violate multi-view consistency in Euclidean space and result in blurry or distorted images. It differs from single-space NeRF by representing the scene using a group of feature fields in parallel sub-spaces rather than a single radiance field, allowing virtual images to be placed in sub-spaces visible only from specific viewpoints. This approach automatically handles mirror-like objects without manual labeling, unlike vanilla NeRF which treats virtual images as textures on reflective surfaces.

### [NRFF](12072-nrff.md)
NRFF is a method for encoding view-dependent effects in radiance fields by replacing the standard positional encoding and roughness/IDE inputs of Ref-NeRF with a structured latent representation of specular reflections. It differs from its siblings by explicitly modeling anisotropic reflections using Anisotropic Spherical Gaussians (ASG) and a custom Rendering Equation Encoding (REE) in the latent space, rather than relying on isotropic roughness or precomputed environment maps.

### [Semantic and Feature Branches](12095-semantic-and-feature-branches.md)
This method extends the standard NeRF formulation by adding a feature branch to the radiance field function, which outputs an arbitrary high-dimensional feature vector $\mathbf{f}$ in addition to density $\sigma$ and color $\mathbf{c}$. It solves the limitation of standard NeRF, which only models appearance, by enabling the representation of semantic, geometric, or perceptual attributes within the 3D volume. Unlike sibling methods that may use fixed semantic labels or specific geometric constraints, this family generalizes the output space to support diverse downstream tasks such as zero-shot segmentation, pose estimation, and scene editing. It builds on [Feature Fields](12995-feature-fields.md) by providing the architectural mechanism to predict these auxiliary signals.

### [NeRF for Object Segmentation](12404-nerf-for-object-segmentation.md)
This method extends the standard NeRF formulation to perform object segmentation by simultaneously estimating scene geometry and predicting semantic occlusion masks. It introduces "area encoding" to represent the probability that a sampling point belongs to an occluded area, leveraging the strong correlation between geometry estimation and semantic label prediction. Unlike sibling methods that predict arbitrary feature vectors, this approach specifically targets binary or probabilistic occlusion masks to enable view-consistent segmentation and subsequent inpainting of occluded regions.

### [Semantic-NeRF](14889-semantic-nerf.md)
Semantic-NeRF is a method for synthesizing semantic labels for novel views by extending the standard NeRF formulation with an additional direction-independent MLP branch. It solves the problem of 3D semantic understanding by integrating RGB images and corresponding 2D semantic labels to train the network, allowing for the recovery of semantic information from sparse or noisy annotations. It is distinguished from its siblings by being the first work to integrate semantic information directly into the NeRF framework using a dedicated semantic output branch.

### [Augmented Features (Avg, Var, Color)](15000-augmented-features-avg-var-color.md)
Augmented Features (Avg, Var, Color) is a method for enhancing the geometric priors in neural radiance fields (NeRF) for 3D object detection by augmenting the feature volume with mean, variance, and color information. It solves the problem of insufficient geometric detail in standard NeRF opacity fields by leveraging statistical moments and low-level color cues as explicit geometry priors. It sets itself apart from sibling methods like [Semantic and Feature Branches](12095-semantic-and-feature-branches.md) by focusing on statistical variance and raw color intensity rather than semantic labels or high-level feature embeddings, and from [Multi-Space Neural Radiance Field (MS-NeRF)](11707-multi-space-neural-radiance-field-ms-nerf.md) by operating within a single-view or multi-view cost-volume-like aggregation framework rather than multi-space representations.

### Object Field Representation
**Definition:** A function $f(\mathbf{p})$ that maps a 3D point $\mathbf{p}$ to an object code vector $\mathbf{o}$, representing object ownership independent of viewing angles [S2, unofficial].
**Parameters:** $H$: Predefined maximum number of solid objects the network predicts. A relatively large value is chosen in practice [S2, unofficial]. The function $f$ is parameterized by a series of MLPs [S2, unofficial].
**Pitfall:** Variable number of objects and large non-occupied volumes. Solved by fixing dimension to $H+1$, reserving the last dimension for empty space to handle occlusion/collision [S2, unofficial].

### NeRF Branch Feature Sampling and Augmentation
**Definition:** Variance of color features describes occupancy: low variance implies occupied 3D location (Lambertian assumption), high variance implies free space (different appearances from different views) [S4].
**Steps:**
1. Sample points along the ray originated from the camera: $r(t) = \mathbf{o} + t \times \mathbf{d}$, where $\mathbf{o}$ is the ray origin and $\mathbf{d}$ is the view direction [S4].
2. Augment sampled features with variance from multiple views to describe occupancy. Compute variance: $V_{var}(\mathbf{p}) = \sum_{i=1}^{M_p} (V_i(\mathbf{p}) - \bar{V}(\mathbf{p}))^2 / M_p$ [S4].
3. Compute mean and variance for pixel RGB values in the same way as for deep features [S4].
4. Pass sampled augmented features into NeRF MLPs to generate density and color [S4].
**Formula:** Density and latent features are computed as: $\sigma(\mathbf{p}), \hat{\mathbf{h}}(\mathbf{p}) = \text{G-MLP}(\bar{V}(\mathbf{p}), \gamma(\mathbf{p}))$, where $\bar{V}(\mathbf{p})$ is ray features aggregated and augmented from multi-view features, and $\gamma(\mathbf{p})$ is position encoding. Color is computed as: $\mathbf{c}(\mathbf{p}, \mathbf{d}) = \text{C-MLP}(\hat{\mathbf{h}}(\mathbf{p}), \mathbf{d})$ [S4].
**Parameters:** Grid resolution for 3D detection: $40 \times 40 \times 16$ [S4]. Source image feature map resolution: typically $160 \times 120$ [S4].
**Layout:** Augmented feature $\bar{V}$ is a concatenation of $\{V_{avg}, V_{var}, \text{RGB}_{avg}, \text{RGB}_{var}\}$ [S4].

### Feature Sampling from Multi-View 2D Features
**Definition:** Sampling point features along the ray from multi-view image features instead of low-resolution volume features to address the need for high-resolution images in NeRF [S4].
**Number:** Sampling from image features achieves 20.51 PSNR for novel-view synthesis compared to 18.93 with volume sampling [S4].

## Background
The concept of feature fields generalizes the original NeRF formulation, which maps $(\mathbf{x}, \mathbf{d}) \rightarrow (\mathbf{c}, \sigma)$, to $(\mathbf{x}, \mathbf{d}) \rightarrow (\mathbf{f}, \mathbf{c}, \sigma)$ [S1, unofficial]. This allows the network to predict arbitrary per-point feature signals, including semantics, physical properties, or latent descriptors [S1, unofficial]. Semantic-NeRF was the first work to introduce semantic fields within the NeRF framework, using ground-truth semantic segmentation maps to augment the radiance field with per-point semantic logits [S1, unofficial]. Subsequent works have expanded this to include self-supervised segmentation using teacher networks like DINO [S3], object manipulation via object fields [S2, unofficial], and geometric priors for 3D detection [S4].
