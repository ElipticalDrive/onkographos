# Frequency-Modulated Point Cloud Rendering

Also called: AFNet, Adaptive Frequency Net, Adaptive Frequency Net (AFNet) based rendering, FreqPCR, Frequency-Modulated Radiance Mapping

## Overview
Frequency-Modulated Point Cloud Rendering is a pipeline that renders scenes from a discrete point cloud representation using an Adaptive Frequency Net (AFNet) to modulate implicit radiance signals with local texture frequency encoding [S1]. It solves the problem of high-frequency detail reconstruction in point-based rendering, where standard MLPs suffer from spectral bias towards low-frequency signals [S1]. Unlike its siblings, it decouples frequency adaptation from the global network by using a hypernetwork to predict per-point frequency and phase parameters, enabling real-time rendering (39.27 FPS on NeRF-Synthetic) and direct point cloud editing [S1]. It is 1700× faster than NeRF and 37× faster than CCNeRF [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D points $\mathcal{P} = \{\mathbf{p}_i\}_{i=1}^M$ with initial attributes (position, color, opacity). Camera parameters (view and projection matrices).
*   **Output:** Rendered image pixels $C$.

**Data Structures:**
*   **Point Cloud:** A list of $M$ points. Each point $i$ has:
    *   Position $\mathbf{p}_i \in \mathbb{R}^3$.
    *   Color $\mathbf{c}_i \in \mathbb{R}^3$ (or feature vector).
    *   Opacity $\alpha_i \in [0, 1]$.
*   **AFNet Parameters:**
    *   Hypernetwork weights $W_{hyp}$ (Two-layer MLP).
    *   Radiance mapping network weights $W_{net}$ (MLP layers with AF layers).
    *   Adaptive frequency $\omega^{(i)} \in \mathbb{R}$ and phase $\phi^{(i)} \in \mathbb{R}$ per point $i$ and per layer.

**Numbered Steps:**

1.  **Point Cloud Geometry Optimization (Preprocessing):**
    *   Initialize point cloud with coarse geometry (e.g., from SfM).
    *   Use volume rendering to optimize point positions and opacities. Keep multiple points per ray in the pixel buffer during optimization to allow geometry refinement [S1].
    *   Learn opacity $\alpha_i$ for each point based on volume rendering loss against ground truth images [S1].
    *   *Note:* This step improves PSNR by 2-4dB for poorly reconstructed scenes and avoids artifacts [S1].

2.  **Frequency Estimation via Hypernetwork:**
    *   For each point $i$ and each layer $l$ in the radiance mapping network, pass the point's spatial coordinates (or intermediate features) through a two-layer MLP hypernetwork [S1].
    *   The hypernetwork outputs adaptive frequency $\omega^{(i, l)}$ and phase $\phi^{(i, l)}$ [S1].
    *   These parameters are scalars per point per layer, broadcast to the feature dimension during modulation [S1].

3.  **Radiance Mapping with Adaptive Frequency Activation:**
    *   For each point $i$, query the radiance mapping network.
    *   Let $\mathbf{X}^{(i, l)} \in \mathbb{R}^{1 \times C}$ be the input feature to layer $l$ for point $i$ (where $C$ is feature dimension) [S1].
    *   Compute the output $\mathbf{Y}^{(i, l)}$ using the Adaptive Frequency (AF) layer:
        $$
        \mathbf{Y}^{(i, l)} = \mathbf{X}^{(i, l)} \circ \sin(\omega^{(i, l)} \circ \mathbf{X}^{(i, l)} + \phi^{(i, l)})
        $$
        where $\circ$ denotes the Hadamard (element-wise) product [S1].
    *   The frequency $\omega^{(i, l)}$ modulates the derivative of the signal, and the sine function constrains the numerical range [S1].
    *   The final output of the network is the raw RGB color $\mathbf{c}_i$ and opacity $\alpha_i$ for point $i$.

4.  **Volume Rendering:**
    *   Sort points along each camera ray by depth.
    *   Compute pixel color $C$ using the standard volume rendering equation:
        $$
        C = \sum_{i \in \text{sorted}} T_i \alpha_i \mathbf{c}_i, \quad T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)
        $$
    *   This is performed per-pixel for all rays [S1].

5.  **Object Editing (Optional):**
    *   To edit an object, modify the positions/colors of points belonging to that object in the point cloud [S1].
    *   The deformation field between the original and deformed 3D space is obtained by querying the transformations performed on the point cloud [S1].
    *   Re-render using the modified point cloud [S1].

6.  **Scene Composition (Optional):**
    *   To combine multiple scenes, use a masking strategy based on the depth buffer to avoid cross-scene training [S1].
    *   Render each scene separately and combine pixels based on depth masks [S1].

**Pseudocode:**

import numpy as np

def hypernetwork_forward(x, weights):
    """
    Two-layer MLP hypernetwork to predict frequency and phase.
    x: (M, D_in) - input features/coordinates for M points
    weights: list of [W1, b1, W2, b2]
    Returns: omega (M, 1), phi (M, 1)
    """
    # Layer 1
    h1 = np.maximum(0, x @ weights[0] + weights[1]) # ReLU activation assumed for hidden layer
    # Layer 2
    out = h1 @ weights[2] + weights[3]
    # Split output into omega and phi
    omega = out[:, :1]
    phi = out[:, 1:]
    return omega, phi

def af_layer(x, omega, phi):
    """
    Adaptive Frequency Activation Layer.
    x: (M, C) - input feature
    omega: (M, 1) - adaptive frequency
    phi: (M, 1) - adaptive phase
    Returns: y (M, C) - activated output
    """
    # Broadcast omega and phi to (M, C)
    omega_broadcast = np.broadcast_to(omega, x.shape)
    phi_broadcast = np.broadcast_to(phi, x.shape)
    
    # Formula: Y = X * sin(omega * X + phi)
    y = x * np.sin(omega_broadcast * x + phi_broadcast)
    return y

**Parameters:**
*   **Hypernetwork:** Two-layer MLP [S1].
*   **AF Layer:** Sinusoidal activation $\sin(\omega X + \phi)$ followed by element-wise multiplication with input $X$ [S1].
*   **Rendering Speed:** 39.27 FPS on NeRF-Synthetic dataset [S1].
*   **Typical Values:** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Spectral Bias:** Standard MLPs with ReLU have strong spectral bias towards low-frequency signals, limiting high-frequency reconstruction [S1]. AFNet mitigates this by adapting frequency locally [S1].
*   **Geometry Optimization:** Previous surface point-based works could not optimize point cloud geometry because they kept only the closest point as surface estimation for each ray [S1]. AFNet uses volume rendering to keep more points and learn opacity, avoiding artifacts [S1].
*   **Cross-Scene Training:** When composing scenes, cross-scene training can occur if not handled. AFNet uses a depth-buffer-based masking strategy to avoid this [S1].
