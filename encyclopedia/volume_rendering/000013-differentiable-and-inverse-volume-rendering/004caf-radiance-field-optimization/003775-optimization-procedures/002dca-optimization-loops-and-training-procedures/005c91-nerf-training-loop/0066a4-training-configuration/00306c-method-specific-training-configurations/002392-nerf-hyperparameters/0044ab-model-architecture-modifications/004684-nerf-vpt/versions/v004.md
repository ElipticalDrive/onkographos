# NeRF-VPT

Also called: NeRF with View Prompt Tuning, NeRF-VPT with Cascading Learning, Neural Radiance Fields via View Prompt Tuning

## Overview
NeRF-VPT is a cascading view prompt tuning paradigm for novel view synthesis that progressively enhances image quality by using RGB information from preceding rendering iterations as visual prompts for subsequent stages [S1]. It solves the problem of limited scene understanding in sparse-view or standard NeRF training by iteratively incorporating prior knowledge into the network, distinguishing itself from methods that rely on external networks or ground-truth priors by using only the model's own internal output as guidance [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Training images (RGB), camera poses, and the output (RGB image) from the previous stage $i-1$.
*   **Outputs:** Predicted density ($\sigma$) and color ($c$) for the current stage, resulting in a refined rendered image.

**Data Structures and Layout:**
The framework consists of $N+1$ stages, indexed from Stage 0 to Stage $N$ [S1].
*   **Stage 0:** A standard NeRF network. It takes position $x$ and direction $d$ as inputs and does not rely on additional prior inputs [S1].
*   **Stage $i$ ($i > 0$):** A new network instance. Its input combines the encoded viewing direction and the RGB output from Stage $i-1$ [S1].
*   **Prompt Integration:** The RGB prompt from the previous stage is concatenated after the direction encoding [S1]. This placement is chosen because color is high-frequency data and encoding is viewed as signal decomposition [S1].

**Numbered Steps:**
1.  **Initialize Stage 0:** Train a standard NeRF network using position $x$ and direction $d$ to gain initial knowledge of the 3D space. This stage generates the first prior RGB values [S1].
2.  **Iterate for Stages 1 to $N$:**
    a.  **Ray Sampling:** Sample points $x$ and directions $d$ along rays [S1].
    b.  **Encoding:** Encode the viewing direction $(\theta, \phi)$ using Direction Encoding (DE) [S1]. Encode position $x$ using Position Encoding (PE) [S1].
    c.  **Retrieve Prompt:** Retrieve the RGB image rendered in the previous stage ($i-1$), denoted as $c(r)_{i-1}$ [S1].
    d.  **Combine Inputs:** Concatenate the encoded direction $DE(d)$ and the previous stage's RGB output $c(r)_{i-1}$ [S1].
    e.  **Network Forward Pass:** Input $PE(x)$ and the combined vector $(DE(d), c(r)_{i-1})$ into the current stage's mapping function $F_i$ [S1].
    f.  **Output:** The network outputs density $\sigma_i$ and color $c_i$ for the current stage [S1].
3.  **Rendering:** Compute the final pixel color $\hat{c}(r)$ using volumetric rendering [S1].
4.  **Loss Calculation:** Compute the loss $L$ between the rendered color $\hat{c}(r)$ and the ground-truth color $c(r)$ [S1].
5.  **Optimization:** Update the weights of the current stage's network using the computed loss [S1].

**Formulas:**
The volumetric rendering equation for color $\hat{c}(r)$ is [S1]:
$$ \hat{c}(r) = \sum_{i=n}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) c_i $$
where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ handles occlusion, $t_n, t_f$ are near/far boundaries, and $\delta_i$ is the distance between samples [S1].

The training loss is [S1]:
$$ L = \sum_{r \in R} ||\hat{c}(r) - c(r)|| $$
where $R$ represents all image pixels in the training data [S1].

The mapping function for iteration $i$ is defined as [S1]:
$$ (c_i, \sigma_i) = F_i(PE(x), (DE(d), c(r)_{i-1})) $$
where $F_0$ and $F_i$ are the mapping functions for iterations 0 and $i$, respectively [S1].

**Parameters:**
*   **Number of Stages:** Five to six stages are typically used to achieve maximum performance [S1]. The source specifies a cascade structure of six stages (Stage 0 to Stage 6) [S1].
*   **Prior Images for Feature Extraction (Alternative Method):** 20 uniformly sampled training images are used to represent the entire scene for feature extraction via Swin-Transformer and soft-view pooling [S1]. *Note: This method yielded limited improvement and is not the primary NeRF-VPT mechanism described in the main algorithm.* [S1].

**Edge Cases and Pitfalls:**
*   **Ground Truth Unavailability:** Directly providing ground truth images as priors fails during testing for unknown viewpoints because ground truth is unavailable [S1]. NeRF-VPT solves this by using rendered images from the previous stage as the prompt, which are available for all viewpoints [S1].
*   **Feature Fusion Limitations:** Extracting features from multiple images via Swin-Transformer or CNN and fusing them into an MLP showed limited improvement because it is challenging to encapsulate multi-view information within a single feature [S1].
*   **Encoding Placement:** Incorporating priors into direction encoding yields higher PSNR (33.96) than position encoding (32.88), because direction information induces diverse color variations for the same position after volume density is predicted [S1].

def nerf_vpt_training(training_images, poses, num_stages=6):
    """
    Trains NeRF-VPT using cascading view prompt tuning.
    
    Args:
        training_images: List of ground truth RGB images.
        poses: Camera poses for training images.
        num_stages: Number of refinement stages (default 6).
        
    Returns:
        List of trained networks [F_0, F_1, ..., F_N].
    """
    networks = []
    
    # Stage 0: Standard NeRF
    # F_0 takes PE(x) and DE(d)
    F_0 = initialize_neRF_network()
    networks.append(F_0)
    
    # Train Stage 0
    train_stage(F_0, training_images, poses, prior_rgb=None)
    
    # Stages 1 to N
    for i in range(1, num_stages + 1):
        # Initialize new network for stage i
        F_i = initialize_neRF_network()
        networks.append(F_i)
        
        # Get prior RGB from previous stage
        # Render images using F_{i-1} on training viewpoints
        prior_rgb_images = render_images(networks[i-1], training_images, poses)
        
        # Train stage i with prior
        train_stage(F_i, training_images, poses, prior_rgb=prior_rgb_images)
        
    return networks

    """

            # Encode inputs
            pe_x = position_encoding(x)
            de_d = direction_encoding(d)
            
            # Get prior RGB for this ray's pixel location
            # prior_rgb is the rendered image from previous stage
            if prior_rgb is not None:
                # Retrieve RGB value at the pixel corresponding to this ray
                c_prev = get_pixel_value(prior_rgb, ray.pixel_coords)
                # Concatenate after direction encoding
                input_vector = concatenate(de_d, c_prev)
                network_input = (pe_x, input_vector)

            loss = mean_squared_error(rendered_color, gt_color)
            
            # Backpropagate and update weights
            network.backward(loss)

## Subtopics

### Sparse View Synthesis
NeRF-VPT is particularly effective in sparse-view scenarios, achieving comparable image quality to standard NeRF trained with dense views (e.g., 45 views vs. 180 views) [S1]. See [Sparse View and Few-Shot Optimization](14428-sparse-view-and-few-shot-optimization.md).

### Plug-and-Play Integration
The method can be integrated into other NeRF variants like Mip-NeRF and TensoRF to improve their performance [S1]. See [Mip-NeRF](15543-neurmips.md) and [TensoRF](15543-neurmips.md) (Note: TensoRF link not provided in sibling list, but mentioned in text; Mip-NeRF is [Mip-NeRF](15543-neurmips.md)).

## Operating characteristics
*   **Time Complexity:** Training time per iteration decreases significantly as the cascade progresses because increasingly accurate visual prompts reduce the learning difficulty for the network [S1].
*   **Memory Complexity:** Parameter overhead is negligible, adding only 0.0008 M additional parameters compared to baseline NeRF [S1].
*   **Measured Performance:**
    *   **Rendering Speed:** 0.108 FPS on the Replica dataset, compared to 0.103 FPS for standard NeRF [S1].
    *   **Realistic Synthetic 360 Dataset (Stage 6):** PSNR 34.95, SSIM 0.977, LPIPS 0.042, outperforming NeRF (31.01, 0.947, 0.081) and Mip-NeRF (33.09, 0.961, 0.043) [S1].
    *   **Real Forward-Facing Dataset (Stage 6):** PSNR 28.95, SSIM 0.872, LPIPS 0.158, outperforming NeRF (26.50, 0.811, 0.250) and Mip-NeRF (27.13, 0.839, 0.164) [S1].
    *   **Replica Dataset (Sparse Views):** Training with 45 sparse views achieves comparable image quality to training standard NeRF with 180 views [S1].
*   **Depth Prediction:** Depth prediction quality is maintained with a Mean-Squared Error distance of 0.02, identical to baseline NeRF, despite significant image quality improvements [S1].
*   **Strengths:** Improves novel view synthesis quality, especially in sparse-view settings; plug-and-play with existing NeRF variants; negligible parameter overhead; reduces learning difficulty through guided optimization [S1].
*   **Limitations:** Requires multiple training stages (increasing total training time compared to a single-stage NeRF, though per-stage time decreases); performance gains plateau after 5-6 stages [S1].

## Background
NeRF-VPT was introduced in 2024 by authors publishing in the Thirty-Eighth AAAI Conference on Artificial Intelligence [S1]. It builds on the success of NeRF and aims to harness its inherent potential through cascading view prompt tuning [S1]. The method addresses limitations of prior approaches that relied on external networks or specific data preprocessing, offering a more transferable solution by using only internal network outputs [S1].
