# Mip-NeRF 360 MLP Architecture

Also called: Integrated Positional Encoding MLP, PosEnc MLP

## Overview
The Mip-NeRF 360 MLP architecture is a specific neural network configuration for radiance field optimization that replaces standard positional encoding with **integrated positional encoding** to handle aliasing and frequency mismatch during volume rendering [S1, unofficial]. It structures the radiance field function $F_\theta(\mathbf{x}, \mathbf{d})$ into a density network and a color network separated by a bottleneck layer, supporting advanced features like specular tinting, roughness prediction, and normal-based reflection directions [S1, unofficial]. It sets itself apart from standard NeRF by explicitly modeling the integration of the encoding function over the conical frustum defined by the ray segment, rather than sampling at discrete points [S1, unofficial].

## How it works
The method implements the query function $F_\theta(\mathbf{x}, \mathbf{d})$ using two distinct MLP stages: a density network and a color network. The density network processes the 3D position $\mathbf{x}$ (represented as a mean $\mu$ and covariance $\Sigma$ to capture the integrated extent) and outputs the volume density $\sigma$. The color network processes the bottleneck features from the density network, combined with the viewing direction $\mathbf{d}$ (or reflection direction $\mathbf{r}$), to output the color $\mathbf{c}$.

### Inputs and Outputs
*   **Inputs**:
    *   $\mu \in \mathbb{R}^3$: Mean 3D position.
    *   $\Sigma \in \mathbb{R}^{3 \times 3}$: Covariance matrix of the position (diagonal in standard usage, representing the integrated extent along the ray).
    *   $\mathbf{d} \in S^2$: Viewing direction vector.
    *   $\mathbf{r} \in S^2$: Reflection direction vector (optional, used if `use_reflections` is True).
    *   $\mathbf{n} \in S^2$: Surface normal vector (optional, required for reflections if not predicted).
*   **Outputs**:
    *   $\sigma \in \mathbb{R}$: Raw volume density.
    *   $\mathbf{c} \in \mathbb{R}^3$: Output color (RGB).
    *   $\mathbf{n}_{pred} \in \mathbb{R}^3$: Predicted surface normal (optional).
    *   $\rho \in \mathbb{R}$: Predicted roughness (optional).

### Data Structures and Parameters
The architecture is defined by the following hyperparameters [S1, unofficial]:

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `net_depth` | int | 8 | Depth of the density MLP. |
| `net_width` | int | 256 | Width of the density MLP layers. |
| `bottleneck_width` | int | 256 | Width of the bottleneck vector connecting density and color networks. |
| `net_depth_viewdirs` | int | 1 | Depth of the color MLP. |
| `net_width_viewdirs` | int | 128 | Width of the color MLP layers. |
| `min_deg_point` | int | 0 | Minimum degree of integrated positional encoding for points. |
| `max_deg_point` | int | 12 | Maximum degree of integrated positional encoding for points. |
| `skip_layer` | int | 4 | Skip connection frequency for the density MLP. |
| `skip_layer_dir` | int | 4 | Skip connection frequency for the color MLP. |
| `deg_view` | int | 4 | Degree of encoding for directions (standard or IDE). |
| `density_bias` | float | -1.0 | Bias added to raw density before activation. |
| `density_noise` | float | 0.0 | Standard deviation of noise added to raw density. |
| `rgb_bias` | float | 0.0 | Bias added to raw color before activation. |
| `rgb_padding` | float | 0.001 | Padding applied to RGB output range. |
| `use_reflections` | bool | False | Use reflection directions instead of view directions. |
| `use_directional_enc` | bool | False | Use Integrated Directional Encoding (IDE). |
| `enable_pred_normals` | bool | False | Predict normals via the network. |
| `disable_density_normals` | bool | True | Disable gradient-based normal computation. |
| `basis_shape` | str | 'icosahedron' | Basis shape for integrated positional encoding. |
| `basis_subdivisions` | int | 2 | Tessellation count for the basis shape. |

### Algorithm Steps

1.  **Setup and Basis Generation**:
    *   If `use_reflections` is True, ensure normals are available (either predicted via `enable_pred_normals` or computed via gradients). If not, raise `ValueError` [S1, unofficial].
    *   Generate the transpose of the basis matrix $B^T$ using `geopoly.generate_basis(basis_shape, basis_subdivisions)` and store as `self.pos_basis_t` [S1, unofficial].

2.  **Directional Encoding Preparation**:
    *   If `use_directional_enc` is True, generate the Integrated Directional Encoding (IDE) function using `ref_utils.generate_ide_fn(deg_view)` [S1, unofficial].
    *   Otherwise, define `dir_enc_fn` as standard positional encoding with `min_deg=0`, `max_deg=deg_view`, and `append_identity=True` [S1, unofficial].

3.  **Density Network Input (Integrated Positional Encoding)**:
    *   **Linearization**: If a warping function `warp_fn` is provided, linearize the means and covariances: $(\mu_{lin}, \Sigma_{lin}) = \text{coord.track\_linearize}(\text{warp\_fn}, \mu, \Sigma)$ [S1, unofficial].
    *   **Lifting**: Lift and diagonalize the means and covariances using the precomputed basis transpose $B^T$:
        $$ (\mu_{lifted}, \Sigma_{lifted}) = \text{coord.lift\_and\_diagonalize}(\mu_{lin}, \Sigma_{lin}, B^T) $$
        This step projects the spatial extent into the frequency domain [S1, unofficial].
    *   **Encoding**: Compute the integrated positional encoding input $x$ using the lifted parameters:
        $$ x = \text{coord.integrated\_pos\_enc}(\mu_{lifted}, \Sigma_{lifted}, \text{min\_deg\_point}, \text{max\_deg\_point}) $$
        This replaces the standard $\sin(\gamma(\mu))$ with an integral over the Gaussian distribution defined by $\mu$ and $\Sigma$ [S1, unofficial].

4.  **Density Network Forward Pass**:
    *   Initialize $x_{curr} = x$.
    *   Iterate $i$ from 0 to `net_depth` - 1:
        *   Apply dense layer: $x_{curr} = \text{activation}(W_i x_{curr} + b_i)$, where $W_i \in \mathbb{R}^{\text{net\_width} \times \text{input\_dim}}$ and input_dim is `net_width` for $i>0$, or the encoding dimension for $i=0$.
        *   If $i > 0$ and $i \pmod{\text{skip\_layer}} == 0$, concatenate the original input $x$ to $x_{curr}$ along the last axis: $x_{curr} = \text{concat}(x_{curr}, x)$ [S1, unofficial].
    *   Compute raw density: $\sigma_{raw} = \text{dense\_layer}_{\text{out}}(x_{curr})[..., 0]$ [S1, unofficial].
    *   **Density Noise**: If `density_noise` > 0, add Gaussian noise: $\sigma_{raw} \leftarrow \sigma_{raw} + \mathcal{N}(0, \text{density\_noise})$ [S1, unofficial].
    *   **Normal Computation (Optional)**:
        *   If `disable_density_normals` is False, compute the gradient of the density with respect to the input position. This is typically done using `jax.vmap(jax.value_and_grad(predict_density, has_aux=True))` on flattened inputs to get $\nabla_\mu \sigma_{raw}$ [S1, unofficial].
        *   Compute normals: $\mathbf{n} = -\text{normalize}(\nabla_\mu \sigma_{raw})$. Note: Normals are computed from raw density for numerical stability [S1, unofficial].
    *   **Density Activation**: $\sigma = \text{density\_activation}(\sigma_{raw} + \text{density\_bias})$ [S1, unofficial].

5.  **Color Network Input Preparation**:
    *   Extract the bottleneck features $h$ from the last layer of the density network (before the final output layer).
    *   **Directional Encoding**:
        *   If `use_reflections` is True, compute reflection direction $\mathbf{r} = 2(\mathbf{n} \cdot \mathbf{d})\mathbf{n} - \mathbf{d}$. Note: View directions $\mathbf{d}$ point from camera to point, so they must be flipped ($-\mathbf{d}$) before reflection if the reflection utility assumes eye-to-surface vectors [S1, unofficial].
        *   Compute directional encoding $e_d = \text{dir\_enc\_fn}(\mathbf{d} \text{ or } \mathbf{r})$.
        *   Broadcast $e_d$ to match the bottleneck shape dimensions [S1, unofficial].
    *   **Feature Concatenation**:
        *   Initialize list $x_{color} = [h]$.
        *   Append $e_d$ to $x_{color}$.
        *   If `use_n_dot_v` is True, compute $n \cdot v = \sum_j n_j v_j$ and append to $x_{color}$ [S1, unofficial].
        *   If `glo_vec` (global vector) is provided, broadcast and append to $x_{color}$ [S1, unofficial].
        *   Concatenate all elements in $x_{color}$ along the last axis to form $x_{color\_in}$ [S1, unofficial].

6.  **Color Network Forward Pass**:
    *   Initialize $x_{curr} = x_{color\_in}$.
    *   Iterate $i$ from 0 to `net_depth_viewdirs` - 1:
        *   Apply dense layer: $x_{curr} = \text{activation}(W_i x_{curr} + b_i)$, where width is `net_width_viewdirs`.
        *   If $i > 0$ and $i \pmod{\text{skip\_layer\_dir}} == 0$, concatenate the original input $x_{color\_in}$ to $x_{curr}$ [S1, unofficial].
    *   Compute raw RGB: $\mathbf{c}_{raw} = \text{dense\_layer}_{\text{rgb}}(x_{curr})$ [S1, unofficial].

7.  **Output Processing**:
    *   **Specular/Diffuse Split (Optional)**:
        *   If `use_diffuse_color` is True, compute diffuse color: $\mathbf{c}_{diffuse} = \sigma(\mathbf{c}_{raw} - \ln(3.0))$ [S1, unofficial].
        *   If `use_specular_tint` is True, compute specular color: $\mathbf{c}_{specular} = \text{tint} \times \mathbf{c}_{raw}$. Else, $\mathbf{c}_{specular} = 0.5 \times \mathbf{c}_{raw}$ [S1, unofficial].
        *   Combine and tone map: $\mathbf{c} = \text{clip}(\text{linear\_to\_srgb}(\mathbf{c}_{specular} + \mathbf{c}_{diffuse}), 0.0, 1.0)$ [S1, unofficial].
        *   If not using split, $\mathbf{c} = \text{rgb\_activation}(\mathbf{c}_{raw} + \text{rgb\_bias})$ [S1, unofficial].
    *   **RGB Padding**: Apply padding to expand the output range: $\mathbf{c} = \mathbf{c} \times (1 + 2 \times \text{rgb\_padding}) - \text{rgb\_padding}$ [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: The integrated positional encoding step is more computationally expensive than standard positional encoding due to the calculation of the integral over the covariance matrix, though it remains $O(D \log D)$ or $O(D)$ depending on implementation, where $D$ is the encoding dimension. The MLP complexity is $O(L \cdot W^2)$ per layer, where $L$ is depth and $W$ is width.
*   **Memory Complexity**: Requires storing the basis matrix $B^T$ and the covariance matrices $\Sigma$ for each sample. The bottleneck architecture separates density and color networks, allowing for independent tuning but requiring storage of the bottleneck vector.
*   **Strengths**: Significantly reduces aliasing artifacts in novel views, especially for scenes with high-frequency details or large depth variations (e.g., outdoor scenes). The integrated encoding provides a more robust representation of the signal along the ray.
*   **Limitations**: Increased computational overhead per sample compared to standard NeRF. Requires careful tuning of the covariance estimation (often derived from the ray marching strategy). The use of IDE (Integrated Directional Encoding) adds further complexity.
*   **When to use**: Ideal for "Mip-NeRF 360" style scenes (unbounded, outdoor, or large-scale indoor) where standard NeRF suffers from aliasing. Not necessary for small, bounded, low-frequency scenes where standard NeRF performs well.

## Background
The Mip-NeRF 360 MLP architecture was introduced by Ben Mildenhall et al. in the paper "Mip-NeRF 360: Unbounded Anti-Aliased Neural Radiance Fields" (2022) [S1, unofficial]. It builds upon the original Mip-NeRF (2021) by extending the integrated positional encoding concept to unbounded scenes and incorporating additional features like specular tinting and roughness prediction to handle complex materials. The architecture is implemented in the `google-research/multinerf` repository [S1, unofficial].
