# StylizedNeRF

Also called: Stylized NeRF

## Overview
StylizedNeRF is a method for generating stylized novel views of 3D scenes by jointly optimizing a 3D radiance field representation and a 2D image stylization network. It solves the problem of maintaining geometric consistency while applying 2D artistic styles, which often introduce ambiguities that conflict with the underlying 3D structure. It differs from its siblings, such as [Spherical Harmonics NeRF](14480-spherical-harmonics-nerf.md) which focuses on lighting decomposition, by explicitly decoupling style application from geometry through a mutual learning strategy and learnable latent codes.

## How it works
**Inputs and Outputs:**
- **Inputs:** A set of input images $\{I_i\}$ of the scene, a target style image $S$, and the initial NeRF parameters.
- **Outputs:** A stylized NeRF model capable of rendering novel views in the target style, and a 2D stylization network.

**Data Structures:**
- **Stylized NeRF:** Standard MLP-based radiance field encoding position $\mathbf{x}$ and viewing direction $\mathbf{d}$ to output density $\sigma$ and color $\mathbf{c}$.
- **2D Stylization Network:** A neural network (e.g., based on WCT or similar style transfer architectures) that maps content features to style features.
- **Learnable Latent Codes:** A set of latent vectors $\mathbf{z}$ used to resolve ambiguities in the 2D stylization process, ensuring geometric consistency.

**Method Steps:**
1. **Initialization:** Initialize the NeRF MLP and the 2D stylization network. Initialize learnable latent codes $\mathbf{z}$.
2. **Forward Pass (NeRF):** For a given ray $r$, sample points $\mathbf{x}_i$ along the ray. Compute density $\sigma_i$ and color $\mathbf{c}_i$ using the NeRF MLP.
3. **Volume Rendering:** Render the unstyled color $\hat{C}(r)$ using standard volume rendering:
   $$
   \hat{C}(r) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i
   $$
   where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ and $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$.
4. **2D Stylization:** Pass the rendered unstyled image $\hat{C}$ through the 2D stylization network. The network uses the learnable latent codes $\mathbf{z}$ to guide the style transfer, mitigating geometric inconsistencies:
   $$
   \hat{C}_{stylized} = \text{Stylize}(\hat{C}, S, \mathbf{z})
   $$
5. **Mutual Learning:**
   - **NeRF Update:** Compute the loss between the stylized NeRF output (after 2D stylization) and the ground truth stylized images (if available) or use a consistency loss. Update NeRF parameters.
   - **Stylization Network Update:** Compute the stylization loss (e.g., style loss, content loss) and update the 2D stylization network parameters and latent codes $\mathbf{z}$.
6. **Regularization:** Apply a geometry consistency loss to ensure that the stylized outputs maintain the structural integrity of the original scene. This is achieved by comparing the gradients or features of the stylized images with the original content.
7. **Iteration:** Repeat steps 2-6 for a fixed number of iterations or until convergence.

**Parameters:**
- Learning rates for NeRF and Stylization Network: Not given in the sources.
- Number of samples per ray $N$: Not given in the sources.
- Latent code dimension: Not given in the sources.

**Edge Cases and Pitfalls:**
- **Geometric Inconsistency:** 2D stylization can distort geometry. The learnable latent codes and consistency loss are critical to mitigate this [S1].
- **Training Stability:** Mutual learning can be unstable. Careful balancing of losses is required [S1].

## Subtopics

## Operating characteristics
- **Time Complexity:** Depends on the number of rays, samples per ray, and the complexity of the 2D stylization network. Generally higher than standard NeRF due to the additional 2D network and mutual learning overhead.
- **Memory Complexity:** Higher than standard NeRF due to the storage of the 2D stylization network parameters and latent codes.
- **Strengths:** Produces high-quality stylized novel views with good geometric consistency.
- **Limitations:** Requires careful tuning of mutual learning parameters. May be computationally expensive.
- **When to use:** When stylized novel view synthesis is required with a focus on maintaining 3D geometric consistency.
- **When not to use:** When real-time performance is critical or when geometric consistency is less important than style fidelity.

## Background
StylizedNeRF was introduced in [102] (cited in [S1]). It addresses the limitations of previous methods that either applied style post-hoc (leading to geometric inconsistencies) or integrated style into the 3D representation without sufficient mechanisms to handle 2D ambiguities. The method builds on the standard NeRF framework [Parent](3065-nerf-hyperparameters.md) and incorporates insights from 2D style transfer techniques.
