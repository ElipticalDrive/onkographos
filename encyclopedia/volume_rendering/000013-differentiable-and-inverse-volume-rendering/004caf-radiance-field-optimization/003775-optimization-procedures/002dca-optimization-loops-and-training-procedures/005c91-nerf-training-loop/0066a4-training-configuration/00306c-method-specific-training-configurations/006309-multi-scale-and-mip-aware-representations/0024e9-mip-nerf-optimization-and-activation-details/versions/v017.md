# Mip-NeRF Optimization and Activation Details

Also called: JaxNeRF Training Procedure, Mip-NeRF Misc. Changes

## Overview
This article defines the specific implementation details, activation functions, and optimization schedules used to train Mip-NeRF and JaxNeRF models [S1]. These modifications are designed to improve training stability and robustness, particularly against catastrophic failure modes, without significantly altering the model's accuracy or computational speed [S1]. Unlike standard NeRF implementations, this configuration removes identity encoding, employs shifted softplus and widened sigmoid activations, and utilizes a specific warmup learning rate schedule [S1].

## How it works
The training process minimizes the difference between rendered pixel colors and ground truth images using the Adam optimizer [S1]. The method modifies the standard NeRF pipeline in three key areas: input encoding, activation functions, and learning rate scheduling [S1].

**Inputs and Outputs**
*   **Inputs:** Training images, camera intrinsics, camera extrinsics, and dataset metadata (near/far clipping planes) [S1].
*   **Outputs:** Optimized MLP weights for density $\tau$ and color $\mathbf{c}$ [S1].

**Data Structures**
*   **Ray Bundle:** Tensor of shape $[B, 3]$ for origins and $[B, 3]$ for directions, where $B$ is the batch size [S1].
*   **Query Points:** Tensor of shape $[B, N, 3]$ containing 3D coordinates along rays, where $N$ is the number of samples per ray [S1].
*   **Integrated Positional Encoding (IPE):** The input to the MLP is the IPE only. The concatenation of IPE with the original position and view direction (identity encoding) is removed [S1].

**Numbered Steps**
1.  **Ray Sampling:** Generate rays from camera origins and directions [S1].
2.  **Point Sampling:** Sample points along rays using the proposal network or uniform sampling [S1].
3.  **Feature Encoding:** Compute the Integrated Positional Encoding (IPE) for the query points. Do not concatenate the original position or view direction [S1].
4.  **Density Prediction:** Pass IPE features through the MLP to predict density $\tau$. Apply the shifted softplus activation [S1].
5.  **View Direction Injection:** Normalize the ray direction $\mathbf{d}$. Apply positional encoding with $L=4$. Inject this encoded view direction into the last layer of the MLP [S1].
6.  **Color Prediction:** Predict color $\mathbf{c}$. Apply the widened sigmoid activation [S1].
7.  **Volume Rendering:** Compute the rendered color $\hat{C}(\mathbf{r})$ using the standard differentiable volume rendering integral [S1].
8.  **Loss Computation:** Compute the loss between $\hat{C}(\mathbf{r})$ and ground truth [S1].
9.  **Optimization:** Update weights using Adam optimizer with the specific learning rate schedule [S1].

**Formulas**
*   **Density Activation:** The density $\tau$ is predicted using a shifted softplus function [S1]:
    $$ \tau = \log(1 + \exp(x - 1)) $$
    where $x$ is the raw output of the MLP layer. The shift by $-1$ is equivalent to initializing the biases for $\tau$ to $-1$, resulting in small initial density values [S1].

*   **Color Activation:** The color $\mathbf{c}$ is predicted using a "widened" sigmoid function [S1]:
    $$ \mathbf{c} = \frac{1 + 2\epsilon}{1 + \exp(-x)} - \epsilon $$
    where $x$ is the raw output of the MLP layer and $\epsilon = 0.001$. This allows the activation to saturate slightly outside the $[0, 1]$ range [S1].

*   **Learning Rate Schedule:** The learning rate $\eta_i$ at iteration $i$ is calculated as [S1]:
    $$ \eta_i = \left( \lambda_w + (1 - \lambda_w) \sin\left(\frac{\pi}{2} \operatorname{clip}\left(\frac{i}{n_w}, 0, 1\right)\right) \right) \times \left( \exp\left( (1 - \frac{i}{n}) \log(\eta_0) + \frac{i}{n} \log(\eta_n) \right) \right) $$
    where:
    *   $n$ is the total number of iterations.
    *   $n_w$ is the number of warmup iterations.
    *   $\eta_0$ is the initial learning rate.
    *   $\eta_n$ is the final learning rate.
    *   $\lambda_w$ is a scale factor annealed from $0.01$ to $1$ during the warmup period [S1].

**Parameters**
*   **Optimizer:** Adam [S1].
*   **Batch Size:** 4096 rays [S1].
*   **Total Iterations:** 1,000,000 [S1].
*   **Warmup Iterations ($n_w$):** 2500 [S1].
*   **Initial Learning Rate ($\eta_0$):** $5 \cdot 10^{-4}$ [S1].
*   **Final Learning Rate ($\eta_n$):** $5 \cdot 10^{-6}$ [S1].
*   **Positional Encoding Layers ($L$):** 4 for view direction [S1].

**Edge Cases and Pitfalls**
*   **Catastrophic Failure:** Using standard ReLU for density can cause the MLP to emit negative values everywhere, resulting in zero gradients and optimization failure. The shifted softplus prevents this [S1].
*   **Saturation Failure:** Standard sigmoid saturation at $[0, 1]$ can cause optimization failure when explaining black or white pixels. The widened sigmoid avoids this [S1].
*   **Identity Encoding:** Concatenating identity features with positional encodings does not meaningfully improve performance or speed and complicates the formalization of IPE features. It is removed in this configuration [S1].

## Subtopics

### Alternative Gaussian Positional Encoding
An alternative to Integrated Positional Encoding (IPE) involves concatenating the positional encodings of the mean and the (signed) square root of the covariance matrix elements [S1]. Specifically, positional encoding with $L=12$ is applied to the mean $\mu$, and positional encoding with $L=2$ is applied to $\text{vec}(\text{triu}(\text{sign}(\Sigma) \circ \sqrt{|\Sigma|}))$ [S1]. This approach performs comparably to IPE in terms of accuracy but is sensitive to hyperparameters $L$ and the covariance parameterization design [S1]. IPE is preferred because it is hyperparameter-free, more compact, and easier to justify [S1]. Note that IPE features are insensitive to off-diagonal elements of $\Sigma$ (correlation), but experiments show that modeling this correlation does not improve accuracy [S1].

### Reflected Cone Derivation
In the context of reflections, the origin of a reflected ray is shifted so that its cone radius matches the incident ray's cone radius at the intersection point [S2]. This ensures consistent view-dependent appearance for reflections [S2]. The condition for equating radii is $\dot{r}\|\bar{\mathbf{x}} - \mathbf{o}\| = \dot{r}'\|\bar{\mathbf{x}} - \mathbf{o}'\|$, where $\dot{r}$ is the incident ray radius parameter, $\bar{\mathbf{x}}$ is the intersection point, $\mathbf{o}$ is the incident ray origin, $\dot{r}'$ is the reflected ray radius parameter, and $\mathbf{o}'$ is the reflected ray origin [S2]. This equation is solved along with the constraint that $\mathbf{o}'$ lies on the reflected ray $r'(s) = \mathbf{o}' + s\mathbf{d}'$ [S2].

### RawNeRF
RawNeRF adapts Mip-NeRF for High Dynamic Range (HDR) image view synthesis and denoising by using raw linear images as training data [S3]. Unlike HDR-NeRF which uses LDR images, RawNeRF renders in a linear color space, allowing varying exposure and tone-mapping curves to be applied after rendering [S3]. The model is supervised with variable exposure images, scaling the NeRF models’ “exposure” by the training image’s shutter speed, as well as a per-channel learned scaling factor [S3].

## Operating characteristics
*   **Training Speed:** Mip-NeRF is 13x faster to train than a brute-force supersampling baseline (16 rays/pixel) [S1].
*   **Evaluation Speed:** Mip-NeRF is 16x faster to evaluate than the supersampling baseline [S1].
*   **Quality:** Mip-NeRF outperforms the supersampling baseline in quality metrics (PSNR, SSIM, LPIPS) [S1].
*   **Stability:** The specific activation functions and learning rate schedule improve training stability, particularly with large learning rates, preventing catastrophic failure modes [S1].
*   **Memory:** The removal of identity encoding reduces input dimensionality slightly, but the primary memory cost remains the MLP weights and feature storage [S1].

## Background
Mip-NeRF was introduced by Barron et al. in 2021 [S1]. The optimization and activation details described here are part of the "miscellaneous" changes implemented in the JaxNeRF codebase to improve reproducibility and training robustness [S1]. These changes were found to not significantly affect performance but to increase stability during optimization [S1]. RawNeRF, a variant using raw linear images, was created by Mildenhall et al. in November 2021 [S3].
