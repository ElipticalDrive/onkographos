# NeRF-Det

Also called: NeRF-then-Det

## Overview
NeRF-Det is a method for indoor 3D object detection using posed RGB images that explicitly models scene geometry as an opacity field by jointly training a NeRF branch with a 3D detection pipeline [S1]. It improves upon the "NeRF-then-Det" paradigm (e.g., NeRF-RPN) by integrating multi-view geometry constraints from the NeRF branch into 3D detection through a shared geometry MLP, enabling end-to-end training without per-scene optimization [S1]. Unlike prior methods that struggle to model geometry or rely on external depth estimation, NeRF-Det learns a generalizable geometry-aware volumetric representation that enhances detection accuracy while maintaining low inference latency [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $T$ posed RGB frames $I_i \in \mathbb{R}^{H_i \times W_i \times 3}$ with corresponding intrinsic matrix $K \in \mathbb{R}^{3 \times 3}$ and extrinsic matrix $R_i \in \mathbb{R}^{3 \times 4}$ for $i = 1, \dots, T$ [S1].
*   **Outputs:** 3D bounding boxes for objects in the scene [S1].

**Data Structures:**
1.  **2D Feature Map ($F_i$):** High-resolution features extracted from each image $I_i$ using a Feature Pyramid Network (FPN) [S1].
    *   Layout: $F_i \in \mathbb{R}^{C \times H/4 \times W/4}$, where $C$ is the channel dimension, and $H, W$ are the original image dimensions [S1].
2.  **3D Voxel Grid:** A 3D coordinate system with $z$-axis as height, $x$ and $y$ as horizontal dimensions.
    *   Layout: A grid of $N_x \times N_y \times N_z$ voxels [S1].
3.  **3D Volume Features ($V_i(p)$):** For each voxel center $p = (x, y, z)^T$, a feature vector assigned from the 2D projections [S1].
4.  **Aggregated Volume Features ($V_{avg}(p)$):** The mean of effective multi-view features for each voxel [S1].
5.  **Density Field ($\sigma(p)$):** Predicted by the shared Geometry MLP (G-MLP) [S1].
6.  **Opacity Field ($\alpha$):** Derived from $\sigma(p)$ [S1].

**Numbered Steps:**

1.  **2D Feature Extraction:** Pass each input image $I_i$ through a 2D image backbone (FPN) to extract high-resolution features $F_i \in \mathbb{R}^{C \times H/4 \times W/4}$ [S1].

2.  **3D Grid Construction:** Define a 3D grid with dimensions $N_x \times N_y \times N_z$. For each voxel center $p = (x, y, z)^T$:
    *   Project $p$ into view $i$ to obtain 2D coordinates. The projection is calculated as:
        $$
        \begin{pmatrix} u'_i, v'_i, d_i \end{pmatrix}^T = K' \times R_i \times \begin{pmatrix} \mathbf{p}, 1 \end{pmatrix}^T
        $$
        where $K'$ is the scaled intrinsic matrix accounting for feature map downsampling, and $(u_i, v_i) = (u'_i/d_i, v'_i/d_i)$ is the pixel coordinate of $p$ in view $i$ [S1].

3.  **Feature Assignment:** Assign 3D features $V_i(p)$ by nearest neighbor interpolation of $F_i$ at location $(u_i, v_i)$:
    $$
    V_i(p) = \text{interpolate}((u_i, v_i), F_i)
    $$
    *   **Edge Case:** If $p$ is projected outside the image boundary or behind the image plane ($d_i \le 0$), discard the feature and set $V_i(p) = 0$ [S1].

4.  **Multi-View Aggregation:** Aggregate features from all effective views. Let $M_p$ be the number of effective 2D projections (views where $V_i(p) \neq 0$). Compute the average volume feature:
    $$
    V_{avg}(p) = \frac{1}{M_p} \sum_{i=1}^{M_p} V_i(p)
    $$
    *   **Note:** The sources indicate that sampling from multi-view 2D image features yields better performance (+0.7 mAP@0.25) than sampling from 3D volume features [S1]. Variance features are also introduced to improve performance by over 0.7 mAP@.25 and 0.6 mAP@.50 compared to using only average features [S1].

5.  **Geometry Prediction (Shared G-MLP):** Feed the voxel coordinates $p$ into a shared Geometry MLP (G-MLP) to predict the volume density $\sigma(p)$ [S1].
    *   **Activation:** ReLU is used for the density $\sigma(p)$ [S1].

6.  **Opacity and Weighting:** Transform the density field $\sigma(p)$ into an opacity field $\alpha$ (typically $\alpha = 1 - e^{-\sigma \Delta}$, though the specific transmittance formula is not explicitly detailed, the text states "transform the density field into an opacity field") [S1]. Multiply the opacity with the volume features to reduce weights of empty space:
    $$
    V_{geometry-aware}(p) = \alpha(p) \cdot V_{avg}(p)
    $$
    *   This step incorporates multi-view consistency constraints from the NeRF branch into the detection branch [S1].

7.  **3D Detection:** Feed the geometry-aware volume features $V_{geometry-aware}(p)$ into the detection head for 3D bounding box regression [S1].

8.  **Inference:** During inference, the NeRF branch (G-MLP and associated rendering logic) is removed to minimize additional overhead, leaving only the detection head operating on the pre-computed or efficiently computed geometry-aware features [S1].

**Pseudocode:**

```python
def nerf_det_forward(images, intrinsics, extrinsics, voxel_grid):
    """
    images: List of T RGB images [H, W, 3]
    intrinsics: Scaled intrinsic matrix K' [3, 3]
    extrinsics: List of T extrinsic matrices R_i [3, 4]
    voxel_grid: 3D grid of voxel centers p [N_x, N_y, N_z, 3]
    
    Returns: 3D bounding boxes
    """
    # Step 1: Extract 2D features
    # F_i shape: [C, H/4, W/4]
    features = [extract_fpn_features(img) for img in images]
    
    # Step 2 & 3: Project voxels and assign features
    # V_i(p) shape: [N_x, N_y, N_z, C]
    volume_features_per_view = []
    
    for i in range(len(images)):
        R_i = extrinsics[i]
        # Project all voxel centers to view i
        # p_homogeneous shape: [N_x, N_y, N_z, 4] (with 1s appended)
        p_homogeneous = np.concatenate([voxel_grid, np.ones_like(voxel_grid[..., :1])], axis=-1)
        
        # u'_i, v'_i, d_i shape: [N_x, N_y, N_z, 3]
        projected = np.matmul(intrinsics, np.matmul(R_i, p_homogeneous.transpose(0,1,2,3))) # Simplified matmul logic for 3D grid
        
        # Normalize to get pixel coordinates
        d_i = projected[..., 2]
        u_i = projected[..., 0] / d_i
        v_i = projected[..., 1] / d_i
        
        # Interpolate features from F_i
        # Nearest neighbor interpolation
        V_i = interpolate_nearest_neighbor(features[i], u_i, v_i)
        
        # Discard invalid projections (outside boundary or behind plane)
        valid_mask = (d_i > 0) & (u_i >= 0) & (u_i < W/4) & (v_i >= 0) & (v_i < H/4)
        V_i[~valid_mask] = 0
        
        volume_features_per_view.append(V_i)
        
    # Step 4: Aggregate multi-view features
    # V_avg shape: [N_x, N_y, N_z, C]
    # Calculate mean over effective views
    # Note: Source mentions using variance features as well. 
    # Here we compute mean as per primary description.
    V_avg = np.mean(volume_features_per_view, axis=0)
    
    # Step 5: Predict density using Shared G-MLP
    # G-MLP takes voxel coordinates p
    # sigma shape: [N_x, N_y, N_z]
    sigma = shared_g_mlp(voxel_grid)
    sigma = relu(sigma) # Activation for density
    
    # Step 6: Transform density to opacity and weight features
    # Alpha calculation (standard NeRF opacity)
    # Assuming uniform step size or similar, but source just says "transform density to opacity"
    # We use standard alpha = 1 - exp(-sigma) for simplicity if delta is not specified, 
    # or alpha = sigma if normalized. Source implies multiplication.
    alpha = 1 - np.exp(-sigma) 
    
    # Geometry-aware volume features
    V_geometry_aware = alpha[..., np.newaxis] * V_avg
    
    # Step 7: Detection Head
    # Returns 3D bounding boxes
    boxes = detection_head(V_geometry_aware)
    
    return boxes
```

**Parameters:**
*   **Density Activation:** ReLU [S1].
*   **Color Activation:** Sigmoid (used in the NeRF branch for novel view synthesis, though the detection branch primarily uses the geometry-aware features) [S1].
*   **Interpolation:** Nearest neighbor [S1].

**Pitfalls:**
*   **Depth Estimation Errors:** Using predicted depth maps from external geometry reconstruction (e.g., NeuralRecon) significantly degrades detection performance by 2.3 mAP@.50 compared to plain ImVoxelNet, demonstrating that depth estimation errors propagate inaccuracy through the detection pipeline [S1].
*   **Detection Branch Impact on NeRF:** The detection branch negatively impacts the NeRF branch's novel view synthesis quality because it is prone to erasing low-level details required for NeRF rendering. Disabling the detection branch brings a 0.43dB improvement in PSNR for novel view synthesis [S1].
*   **Boundary Conditions:** Voxels projected outside the image boundary or behind the image plane must be handled by setting their features to 0 to avoid invalid sampling [S1].

## Subtopics

### Shared G-MLP
A shared geometry MLP that enables the constraint of multi-view consistency to be propagated from the NeRF branch to the detection branch [S1]. Without the shared G-MLP, performance drops from 50.1 to 48.1 mAP@.25, as the influence of multi-view consistency is only propagated into the image backbone [S1].

## Operating characteristics
*   **Time Complexity:** The method avoids per-scene optimization, allowing for generalizable inference. Latency is significantly lower than NeRF-then-Det methods.
*   **Memory Complexity:** Requires storing 3D feature volumes and the shared G-MLP parameters.
*   **Measured Performance:**
    *   On ScanNet, NeRF-Det-R50 achieves 35.13 AP50 with a latency of 0.554s on one V100, compared to NeRF-RPN's 33.13 AP25 and ~846.8s latency [S1].
    *   Improves state-of-the-art by 3.9 mAP on ScanNet and 3.1 mAP on ARKITScenes benchmarks [S1].
    *   Achieves an average PSNR of 20+ for novel view synthesis and an RMSE of 0.756 for depth estimation on 312 scenes in the validation set, without per-scene training [S1].
*   **Strengths:** Joint training allows geometry-aware volumetric representations to improve 3D detection. It generalizes to unseen scenes without per-scene optimization.
*   **Limitations:** The detection branch can degrade the NeRF branch's novel view synthesis quality by erasing low-level details [S1].
*   **When to use:** Indoor 3D object detection with posed RGB images where explicit geometry modeling is beneficial and per-scene optimization is computationally prohibitive.
*   **When not to use:** When high-fidelity novel view synthesis is the primary goal, as the detection branch may degrade rendering quality [S1].

## Background
NeRF-Det was introduced by Chenfeng et al. at Meta in 2023 [S1]. It addresses the limitations of existing indoor 3D detection methods that struggle to model scene geometry and the high latency associated with per-scene NeRF optimization. The method builds on the ImVoxelNet architecture and integrates concepts from NeRF to explicitly estimate 3D geometry, improving detection performance while enabling generalizable novel view synthesis [S1].
