# Dynamic Scene and Temporal Modeling

Also called: Dynamic NeRF, 4D Radiance Fields, Temporal NeRF

## Overview
Dynamic Scene and Temporal Modeling extends static Neural Radiance Fields (NeRF) to handle time-varying scenes, solving the "ghosting" and blurring artifacts that occur when a static implicit representation attempts to model multi-frame video data [14705-nerf-with-time-parameter.md]. Unlike static methods, these approaches introduce a temporal dimension to the input space or explicitly model motion fields, allowing the network to learn scene appearance variations and geometry changes directly through the radiance field [14705-nerf-with-time-parameter.md]. This family differs from sibling methods that focus on static optimization or sparse views by specifically addressing the non-rigid or rigid dynamics of the scene over time.

## Shared principles
The standard NeRF architecture [Parent](15546-dynamic-scene-and-temporal-modeling.md) serves as the baseline for most modifications. It consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ [14428-sparse-view-and-few-shot-optimization.md].

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories [14428-sparse-view-and-few-shot-optimization.md]:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation [14428-sparse-view-and-few-shot-optimization.md].
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs).

## Subtopics

### [Gear-NeRF](13848-gear-nerf.md)
Gear-NeRF is a framework for free-viewpoint rendering and tracking of dynamic scenes that leverages semantic information from image segmentation models to stratify the scene into motion-based 'gears', allowing for region-specific spatio-temporal sampling resolution. It differs from unified 4D volume approaches by using a series of feature volumes, one per gear level, where regions with larger motion scales are assigned higher gears and thus higher-resolution sampling. This motion-aware stratification improves photo-realistic dynamic novel view synthesis while enabling free-viewpoint object tracking as a by-product.

### [NeRF with Time Parameter](14705-nerf-with-time-parameter.md)
This method adapts the static Neural Radiance Field (NeRF) architecture for dynamic scenes by introducing a temporal dimension to the input space. It solves the problem of "ghosting" and blurry predictions that occur when a static implicit representation attempts to model multi-frame video data. Unlike sibling methods that explicitly model geometry or motion fields, this approach treats time as an additional coordinate, allowing the network to learn scene appearance variations directly through the radiance field.

### [Forward Warping for Novel View Synthesis](15541-forward-warping-for-novel-view-synthesis.md)
Forward Warping for Novel View Synthesis is a method for rendering dynamic scenes by modeling a static scene at a canonical time step and forward warping the entire canonical field to other time steps. It addresses the many-to-one and one-to-many mapping difficulties inherent in dynamic scene reconstruction by using differentiable forward warping with average splatting and an inpaint network. It sets itself apart from backward flow-based methods like NDVG by achieving superior performance, particularly for canonical frames, despite using similar regularization terms.

### [Dynamic Appearance Particle Neural Radiance Field](15550-dynamic-appearance-particle-neural-radiance-field.md)
Dynamic Appearance Particle Neural Radiance Field is a method for novel view synthesis in dynamic scenes using monocular video input. It solves the problem of modeling temporal dynamics without requiring multi-view data or prior geometric knowledge of moving objects. It differs from ParticleNeRF by applying particle-based representation only to dynamic elements while keeping a static grid for the background, and by supporting single-camera input rather than requiring multiple views per time frame.

### [KFD-NeRF](15551-kfd-nerf.md)
KFD-NeRF is a dynamic neural radiance field method that models the 4D radiance field as a dynamic system with temporally varying states, estimated using a Kalman filter to combine observations from input data and predictions based on local linear motion equations. It differs from sibling methods like [Gear-NeRF](13848-gear-nerf.md) and [NeRF with Time Parameter](14705-nerf-with-time-parameter.md) by explicitly separating motion estimation into an observer branch (shallow MLP) and a predictor branch (linear motion model), fusing them via a learnable Kalman gain, whereas alternatives often rely on direct time-conditioned feature interpolation or rigid body assumptions.

### [SLS4D](16576-sls4d.md)
SLS4D is a method for 4D novel view synthesis that represents dynamic scenes using a sparse, compact, and informative latent feature space, significantly reducing the number of network parameters compared to dense voxel-based or fully implicit alternatives. It distinguishes itself by abandoning direct coordinate-to-feature mapping in favor of relative relationships within a latent space, utilizing dense learnable time slots for temporal continuity and an attention-based interpolator decoder for spatial feature aggregation.
