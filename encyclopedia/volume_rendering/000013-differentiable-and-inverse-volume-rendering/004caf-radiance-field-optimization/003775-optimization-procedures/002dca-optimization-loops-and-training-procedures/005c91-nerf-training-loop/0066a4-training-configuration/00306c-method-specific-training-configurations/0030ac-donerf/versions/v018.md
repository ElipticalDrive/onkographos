# DONeRF

Also called: Depth Oracle Neural Radiance Fields, DONeRF Training Configuration, DONeRF training setup, Depth Oracle Network, DoNeRF

## Overview
DONeRF is a training configuration and architectural variant that replaces the standard NeRF raymarching scheme with a compact dual-network design: a depth oracle network and a shading network [S3]. It solves the prohibitive computational cost of dense sampling in NeRF by using the oracle to predict a small set of optimal sample locations, allowing the shading network to render high-quality images with only 2–16 samples per ray [S3]. Unlike standard NeRF, which evaluates density and color at hundreds of points, DONeRF reduces inference costs by up to 48× while achieving equal or better quality, without requiring explicit acceleration structures or large memory caches [S3].

## How it works
DONeRF consists of two distinct neural networks trained sequentially. The pipeline operates in five stages: (1) ray unification within a view cell, (2) non-linear depth transformation, (3) oracle estimation of sample importance, (4) warping of sample positions, and (5) radiance generation by the shading network [S3].

### Inputs and Outputs
*   **Inputs:** Camera ray origin $\mathbf{o}$, direction $\mathbf{d}$, and optionally ground truth depth maps $D_{gt}$ for the view cell [S3].
*   **Outputs:** Rendered RGB color $\hat{C}(\mathbf{r})$ and accumulated opacity [S3].

### Data Structures and Network Architectures
Both networks are Multi-Layer Perceptrons (MLPs) with 8 hidden layers and 256 hidden units each [S3].

1.  **Depth Oracle Network:**
    *   **Input:** Concatenated position $\mathbf{x} \in \mathbb{R}^3$ and view direction $\mathbf{d} \in S^2$. No positional encoding is applied [S1].
    *   **Architecture:** 8-layer MLP with ReLU activations. The last layer outputs a single value representing depth classification logits [S1].
    *   **Output:** Classification logits for discretized depth bins [S3].

2.  **Shading Network:**
    *   **Input:** Position $\mathbf{x}$ and direction $\mathbf{d}$.
    *   **Encoding:** Positional encoding is applied to obtain $\gamma(\mathbf{x})$ (63-dimensional) and $\gamma(\mathbf{d})$ (27-dimensional) [S1].
    *   **Architecture:** 8-layer MLP with ReLU activations. $\gamma(\mathbf{x})$ is injected at the first layer. $\gamma(\mathbf{d})$ is concatenated to the feature vector before the last layer [S1].
    *   **Output:** RGB color $\mathbf{c} \in \mathbb{R}^3$ and volume density $\sigma \in \mathbb{R}^+$ [S1].

### Training Procedure
The training is not end-to-end; it occurs in two sequential phases [S3].

**Phase 1: Depth Oracle Training**
The oracle is trained to predict depth using ground truth depth maps. It solves a classification task rather than regressing continuous depth values [S3].
*   **Loss:** Binary Cross-Entropy (BCE) loss on the discretized depth classification [S3].
*   **Optimizer:** Adam with learning rate $0.0005$ [S3].
*   **Batch Size:** 4096 samples per iteration [S3].
*   **Iterations:** 300,000 [S3].

**Phase 2: Shading Network Training**
The shading network is trained using sample locations predicted by the frozen oracle [S3].
*   **Sampling:** The oracle outputs $N_s$ sample indices (e.g., $N_s=16$ for DONeRF-16). These indices are used to select $N_s$ 3D positions along the ray. These positions are transformed logarithmically and warped towards the view cell center to handle large depth ranges and focus on foreground frequencies [S3].
*   **Loss:** A weighted sum of Mean Squared Error (MSE) for RGB and an Opacity Loss ($\text{loss}_O$) [S3].
    $$ \text{loss} = \alpha \cdot \text{loss}_{\text{MSE}} + \beta \cdot \text{loss}_O $$
    Where $\alpha = 1.0$ and $\beta = 10.0$ [S3].
*   **Opacity Loss:** Prevents dark pixel artifacts by forcing accumulated opacity to be at least 1 for opaque surfaces [S3].
    $$ \text{loss}_O = \begin{cases} 0, & \text{if } \sum_{i=1}^O \delta_i \geq 1 \\ \left( \left( \sum_{i=1}^X \delta_i \right) - 1 \right)^2, & \text{otherwise} \end{cases} $$
    Where $X$ is the number of samples per ray, $\delta_i$ is the transmittance contribution (or opacity weight) of sample $i$, and $O$ is the number of samples contributing to the sum [S3].
*   **Optimizer:** Adam with learning rate $0.0005$ [S3].
*   **Batch Size:** 4096 samples per iteration [S3].
*   **Iterations:** 300,000 [S3].

### Training without Ground Truth Depth (DONeRF-X-noGT)
If ground truth depth is unavailable, a dense NeRF is trained first to extract depth maps [S3].
1.  Train a dense NeRF with 12 layers, 512 hidden units, and 128 samples per ray [S3].
2.  Extract depth maps for all training poses [S3].
3.  Use these extracted depth maps as the ground truth for Phase 1 of DONeRF training [S3].

    Depth Oracle Network: 8 layers, 256 hidden units, ReLU.
    Input: x (3), d (3). No positional encoding.
    Output: Depth classification logits.
    """
    def __init__(self):
        super().__init__()
        self.layers = nn.ModuleList()
        # Input dim: 3 (x) + 3 (d) = 6
        self.layers.append(nn.Linear(6, 256))
        for _ in range(6):
            self.layers.append(nn.Linear(256, 256))
        self.layers.append(nn.Linear(256, 1)) # Output logits

    def forward(self, x, d):
        # Concatenate x and d
        input_vec = torch.cat([x, d], dim=-1)
        h = input_vec
        for i, layer in enumerate(self.layers):
            h = layer(h)
            if i < len(self.layers) - 1: # ReLU for hidden layers
                h = torch.relu(h)
        return h

class ShadingNetwork(nn.Module):
    """
    Shading Network: 8 layers, 256 hidden units, ReLU.
    Input: x (3), d (3). Positional encoding applied.
    Output: RGB (3), Density (1).
    """
    def __init__(self, num_freqs_x=10, num_freqs_d=4):
        super().__init__()
        # PE dimensions: 2*num_freqs*dim + dim
        # x: 2*10*3 + 3 = 63
        # d: 2*4*3 + 3 = 27
        self.num_freqs_x = num_freqs_x
        self.num_freqs_d = num_freqs_d
        
        self.layers = nn.ModuleList()
        # First layer takes PE(x)
        self.layers.append(nn.Linear(63, 256))
        for _ in range(6):
            self.layers.append(nn.Linear(256, 256))
        # Last layer takes PE(d) concatenated
        self.layers.append(nn.Linear(256 + 27, 4)) # RGB(3) + Sigma(1)

    def forward(self, x, d):
        # Positional Encoding for x
        pe_x = positional_encoding(x, self.num_freqs_x) # Returns 63-dim vector
        h = pe_x
        h = torch.relu(self.layers[0](h))
        
        for i in range(1, 7):
            h = torch.relu(self.layers[i](h))
            
        # Positional Encoding for d
        pe_d = positional_encoding(d, self.num_freqs_d) # Returns 27-dim vector
        h = torch.cat([h, pe_d], dim=-1)
        
        return self.layers[7](h)

def positional_encoding(x, num_freqs):
    """Standard NeRF positional encoding."""
    # x shape: (..., 3)
    # Returns shape: (..., 2 * num_freqs * 3 + 3)
    freq_bands = 2.0 ** torch.linspace(0, num_freqs - 1, num_freqs)
    x_expanded = x.unsqueeze(-1) * freq_bands.unsqueeze(0)
    s = torch.sin(x_expanded)
    c = torch.cos(x_expanded)
    pe = torch.cat([x, s, c], dim=-1)
    return pe

        loss = criterion(logits, target_bins)
        
        optimizer.zero_grad()
        loss.backward()

        # Compute opacity and transmittance

        # Since points are warped, delta calculation might be in warped space or original.
        # Standard NeRF rendering:
        # alpha_i = 1 - exp(-sigma_i * delta_i)
        # T_i = exp(-sum(sigma_j * delta_j))
        
        # Calculate deltas in the warped space? Or original?

        transmittances = torch.cumprod(1.0 - alphas, dim=-1)
        transmittances = torch.cat([torch.ones_like(transmittances[..., :1]), transmittances[..., :-1]], dim=-1)
        
        # Accumulate color
        weights = alphas * transmittances
        rendered_colors = torch.sum(weights.unsqueeze(-1) * rgbs, dim=-2)
        
        # Accumulate opacity for loss
        accumulated_opacity = torch.sum(weights, dim=-1)
        
        # 4. Loss Computation
        loss_mse = torch.mean((rendered_colors - gt_colors) ** 2)
        
        # Opacity Loss
        # If accumulated opacity < 1, penalize
        opacity_loss = torch.where(
            accumulated_opacity >= 1.0,
            torch.zeros_like(accumulated_opacity),
            (accumulated_opacity - 1.0) ** 2
        )
        opacity_loss = torch.mean(opacity_loss)
        
        total_loss = alpha * loss_mse + beta * opacity_loss
        
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()

### Edge Cases and Pitfalls
*   **Dark Pixel Artifacts:** At low sample counts, rays may not accumulate to opacity 1 for opaque surfaces, causing darkening. This is remedied by the opacity loss term [S3].
*   **Cheating:** Shading networks with low sample counts may "cheat" by relying on opacity outputs to mix background color into the accumulation. The opacity loss mitigates this [S3].
*   **Reflective/Transparent Surfaces:** Low sample counts and single depth estimates are insufficient for perfect replication of view-dependent phenomena like mirrors or refractive water [S3].
*   **No-GT Training Noise:** When training without ground truth depth, NeRF may output high-frequency depth values in the background, creating zero-contribution samples. Adding background detection during oracle training would likely resolve this [S3].
*   **Non-End-to-End:** The architecture is not end-to-end trainable and struggles without high-quality depth supervision [S2].

## Operating characteristics
*   **Time Complexity:** DONeRF requires approximately 4.35 MFLOP per pixel [S3]. Inference costs are reduced by up to 48× compared to NeRF when conditioning on available ground truth depth [S3].
*   **Memory Complexity:** DONeRF stays in the realm of compact MLPs without additional data structures or increased storage requirements, unlike baking methods which may require hundreds of MBs to GBs [S3]. It does not require additional memory for explicit caching or acceleration structures, unlike NSVF [S3].
*   **Performance:** On an NVIDIA RTX 3090 at 800x800 resolution with 2 samples/ray, DONeRF renders in 51.3 ms (~20 fps) [S3]. At 400x400, it renders at 22 ms per frame [S3].
*   **Scaling:** Shading network cost scales nearly linearly with the number of samples: 34.9 ms (2 samples), 65.4 ms (4 samples), 136.4 ms (8 samples), 270.4 ms (16 samples) [S3].
*   **Quality:** DONeRF achieves an average PSNR of 31.14 dB compared to NeRF's 30.52 dB [S3]. At 16 samples, DONeRF is up to 7 dB higher PSNR than NeRF [S3].
*   **Strengths:** Real-time rendering capability, compact memory footprint, high quality on large scenes.
*   **Limitations:** Struggles with reflective/transparent surfaces, requires high-quality depth supervision (or a pre-trained NeRF for initialization), not end-to-end trainable.

## Background
DONeRF was introduced by [S3] to address the prohibitive computational cost of NeRF in real-time applications like games and VR. It builds on the concept of using depth information to guide sampling, replacing the coarse network in NeRF with a depth oracle network [S2]. The method was designed to render large-scale synthetic content in real-time on consumer GPUs without explicit acceleration structures.
