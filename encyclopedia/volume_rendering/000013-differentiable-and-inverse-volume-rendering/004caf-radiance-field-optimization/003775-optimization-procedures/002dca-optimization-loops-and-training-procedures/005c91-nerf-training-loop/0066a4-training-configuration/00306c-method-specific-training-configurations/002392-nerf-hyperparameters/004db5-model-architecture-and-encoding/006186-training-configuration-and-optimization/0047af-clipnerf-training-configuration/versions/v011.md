# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF is a method for text-driven stylization of Neural Radiance Fields (NeRFs) by optimizing the radiance field parameters to align rendered views with text prompts in the CLIP embedding space [S2]. It distinguishes itself from standard NeRF training by replacing or augmenting photometric reconstruction losses with directional CLIP losses that enforce semantic consistency with text, enabling style transfer without requiring 3D ground-truth labels [S2].

## How it works
**Inputs:**
*   A pre-trained NeRF model (density and color MLPs) initialized from a source scene.
*   A source image $\mathbf{I}_{src}$ (optional, for relative loss).
*   A target text prompt $\mathbf{t}_{tgt}$ and optionally a source text prompt $\mathbf{t}_{src}$.
*   Training views sampled from the dataset.

**Outputs:**
*   Optimized NeRF parameters (specifically the color network and bottleneck features, while density parameters are often frozen [S1]).
*   Stylized 3D scene representation.

**Data Structures:**
*   **CLIP Encoder:** Uses CLIP ViT-B/32 [S1]. The image encoder $\mathcal{E}_i$ and text encoder $\mathcal{E}_t$ produce normalized embedding vectors $\hat{\mathbf{e}}_i$ and $\hat{\mathbf{e}}_t$ [S2].
*   **Rendered Patch:** A $128 \times 128$ pixel patch $\mathbf{I}_{tgt}$ rendered from a random pose [S1].

**Loss Functions:**
Two variants of directional CLIP loss are defined, measuring cosine similarity between normalized embeddings [S2]:

1.  **Absolute Directional CLIP Loss:** Measures similarity between the rendered image and the target text prompt directly [S2]:
    $$ \mathcal{L}_{dir}^{abs} = 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) \rangle $$
    This guides the NeRF with a global direction of the target text [S2].

2.  **Relative Directional CLIP Loss:** Measures the similarity of the *difference* vectors in embedding space, transferring style from a source to a target domain [S2]:
    $$ \mathcal{L}_{dir}^{rel} = 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}) - \hat{\mathcal{E}}_i(\mathbf{I}_{src}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) - \hat{\mathcal{E}}_t(\mathbf{t}_{src}) \rangle $$
    This enforces the correct stylization trajectory while ignoring magnitude [S2].

**Training Procedure:**
1.  **Initialization:** Load a pre-trained NeRF. Freeze sub-parameters related to density to preserve geometry [S1].
2.  **Sampling:** For each iteration, sample a random training pose [S1].
3.  **Patch Rendering:** Render a $128 \times 128$ patch $\mathbf{I}_{tgt}$ from the sampled pose [S1].
    *   To cover a wide receptive field, rays within the patch are sampled with a stride interval of 5, corresponding to a $640 \times 640$ region in the original image resolution [S1].
    *   To manage memory, reduce the number of importance sampling points to 16 per ray [S1].
    *   The fine MLP uses 64 coarse samples + 16 fine samples = 80 total samples [S1].
4.  **Embedding:** Pass $\mathbf{I}_{tgt}$ through the CLIP image encoder $\mathcal{E}_i$ [S1]. Encode $\mathbf{t}_{tgt}$ (and $\mathbf{t}_{src}$ if using relative loss) through the CLIP text encoder $\mathcal{E}_t$ [S2].
5.  **Loss Calculation:** Compute $\mathcal{L}_{dir}$ based on the chosen variant (absolute or relative) [S2].
6.  **Optimization:** Minimize the loss using the Adam optimizer with a learning rate of $0.0001$ [S1].
7.  **Iteration:** Repeat for 500 iterations [S1].

**Pseudocode:**
```python
def train_clipnerf(nerf_model, text_prompt_tgt, text_prompt_src=None, 
                   num_iterations=500, lr=0.0001, patch_size=128, 
                   ray_stride=5, fine_samples=16, coarse_samples=64):
    # Initialize optimizer for color/bottleneck parameters only
    optimizer = Adam(nerf_model.color_mlp.parameters(), lr=lr)
    
    # Pre-encode text prompts
    emb_tgt = clip_text_encoder(text_prompt_tgt)
    emb_src = clip_text_encoder(text_prompt_src) if text_prompt_src else None
    
    for i in range(num_iterations):
        # 1. Sample random pose
        pose = sample_random_pose()
        
        # 2. Render patch with reduced sampling for memory efficiency
        # Ray stride 5 means we sample every 5th pixel in a 640x640 area
        # to fill the 128x128 patch
        rendered_patch = nerf_model.render_patch(
            pose=pose, 
            width=patch_size, 
            height=patch_size, 
            ray_stride=ray_stride,
            num_coarse_samples=coarse_samples,
            num_fine_samples=fine_samples
        )
        
        # 3. Encode rendered image
        emb_img = clip_image_encoder(rendered_patch)
        
        # 4. Compute Loss
        if text_prompt_src is not None:
            # Relative Directional CLIP Loss
            # Normalize embeddings if not already normalized by encoder
            emb_img_norm = normalize(emb_img)
            emb_src_norm = normalize(clip_image_encoder(sample_source_image()))
            emb_tgt_norm = normalize(emb_tgt)
            emb_src_text_norm = normalize(emb_src)
            
            img_diff = emb_img_norm - emb_src_norm
            text_diff = emb_tgt_norm - emb_src_text_norm
            loss = 1.0 - cosine_similarity(img_diff, text_diff)
        else:
            # Absolute Directional CLIP Loss
            emb_img_norm = normalize(emb_img)
            emb_tgt_norm = normalize(emb_tgt)
            loss = 1.0 - cosine_similarity(emb_img_norm, emb_tgt_norm)
            
        # 5. Backpropagate
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
```

**Edge Cases and Pitfalls:**
*   **Memory Constraints:** Naive differentiable rendering of high-resolution images is intractable due to memory constraints [S1]. Using patches with reduced sampling is necessary [S1].
*   **Mode Collapse:** The absolute directional CLIP loss can cause mode-collapse of the generator and hurt generation diversity [S2].
*   **Insufficient Magnitude:** Directional loss alone struggles to reach sufficient stylization magnitude, resulting in weak style transfer, as it only measures directional similarity and ignores actual distances in embedding space [S2].

## Operating characteristics
*   **Time Complexity:** Dependent on the number of iterations (typically 500 [S1]) and the cost of CLIP encoding and NeRF rendering per patch.
*   **Memory Complexity:** Reduced by rendering patches ($128 \times 128$) instead of full images and reducing importance sampling points to 16 [S1].
*   **Strengths:** Enables text-driven 3D stylization without 3D ground truth; preserves geometry by freezing density [S1].
*   **Limitations:** Absolute loss causes mode collapse; directional loss lacks magnitude control [S2].

## Background
CLIPNeRF was introduced by Wang et al. [S2], extending the StyleGAN-NADA approach [Gal et al. 2021] to 3D NeRFs. It was designed to address the lack of significant descriptions for reproducing NeRF editing results [S1]. The method leverages the pre-trained CLIP ViT-B/32 model [S1].
