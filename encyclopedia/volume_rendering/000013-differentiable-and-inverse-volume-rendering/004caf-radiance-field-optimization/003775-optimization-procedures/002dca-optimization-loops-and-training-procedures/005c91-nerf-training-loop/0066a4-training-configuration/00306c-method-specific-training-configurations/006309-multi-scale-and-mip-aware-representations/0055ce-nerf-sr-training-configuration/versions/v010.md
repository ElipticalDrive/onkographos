# NeRF-SR Training Configuration

Also called: NeRF-SR, NeRF Super-Resolution

## Overview
NeRF-SR is a training configuration designed to synthesize high-resolution (HR) novel views from low-resolution (LR) inputs by optimizing the neural radiance field directly at the target resolution, rather than upsampling the output image [S1]. It distinguishes itself from standard NeRF by employing a supersampling strategy that leverages 3D consistency to recover high-frequency details, and from post-processing methods like NeRF-Bi by avoiding the blurring artifacts inherent to 2D upsampling [S1]. It builds on [Method-Specific Training Configurations](6267-method-specific-training-configurations.md) by utilizing hierarchical sampling and photometric loss but adapts the training loop to handle independent resolution scales [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ LR images (typically 100 for training) with known camera poses and intrinsics.
*   **Outputs:** A trained MLP representing the radiance field $\mathbf{F}$ parameterized by weights $\theta$, capable of rendering HR images.

**Data Structures:**
The method uses the standard NeRF MLP structure [S1].
*   **Coarse MLP:** Takes position $\mathbf{x}$ and viewing direction $\mathbf{d}$, outputs density $\sigma$ and color $\mathbf{c}$.
*   **Fine MLP:** Takes position $\mathbf{x}$, viewing direction $\mathbf{d}$, and intermediate features from the coarse network, outputs color $\mathbf{c}$.
*   **Sampling Points:** For each ray, $N_c = 64$ coarse samples and $N_f = 64$ fine samples are generated [S1].

**Training Steps:**
1.  **Initialization:** Initialize the coarse and fine MLPs. Set optimizer to Adam with $\beta_1 = 0.9, \beta_2 = 0.999$ [S1].
2.  **Sampling:** For each batch of rays:
    *   Generate $N_c$ samples uniformly along the ray for the coarse network.
    *   Use the coarse network's density estimates to guide importance sampling for $N_f$ fine samples [S1].
3.  **Rendering:** Compute the rendered color $\hat{C}(\mathbf{r})$ using the differentiable volume rendering integral defined in the parent article [Parent].
4.  **Loss Calculation:** Compute the photometric loss between the rendered HR image and the ground truth HR image. The primary metric is Mean Squared Error (MSE), though PSNR, SSIM, and LPIPS are reported for evaluation [S1].
5.  **Optimization:** Update weights $\theta$ using the Adam optimizer.
6.  **Learning Rate Schedule:** Decay the learning rate exponentially from $5 \cdot 10^{-4}$ to $5 \cdot 10^{-6}$ over the course of training [S1].
7.  **Iteration:** Repeat for the specified number of epochs.

**Parameters:**
*   **Batch Size:** 2048 rays per batch [S1].
*   **Coarse Samples ($N_c$):** 64 [S1].
*   **Fine Samples ($N_f$):** 64 [S1].
*   **Initial Learning Rate:** $5 \cdot 10^{-4}$ [S1].
*   **Final Learning Rate:** $5 \cdot 10^{-6}$ [S1].
*   **Optimizer Hyperparameters:** $\beta_1 = 0.9, \beta_2 = 0.999$ [S1].

**Edge Cases and Pitfalls:**
*   **Resolution Independence:** The method trains independently for different image resolutions. It does not support arbitrary-scale super-resolution natively; specific models are trained for specific scale factors (e.g., $\times 2, \times 4$) [S1].
*   **Real-world Detail Loss:** For real-world datasets like LLFF, supersampling alone may not recover sufficient texture details at high magnification factors (e.g., $\times 4$), necessitating a refinement step [S1].

## Subtopics

### Refinement Network (Ours-Refine)
A post-processing module applied to NeRF-SR outputs to boost texture details and edge sharpness, specifically for real-world scenes (LLFF) where supersampling is insufficient [S1]. It uses a fixed number of reference patches ($K=8$) of size $64 \times 64$ [S1]. During inference, input images are divided into non-overlapping patches, refined using reference information, and stitched together [S1]. It improves LPIPS and PSNR, particularly at scale $\times 4$, where supersampling derives fewer details [S1].

## Operating characteristics
**Time and Memory Complexity:**
*   **Training Time:** The method requires training separate models for each resolution scale. For the Blender dataset, training takes 20 epochs; for LLFF, 30 epochs [S1].
*   **Inference Time:** The refinement stage adds negligible overhead. For a $1008 \times 756$ image on a single 1080Ti GPU, NeRF rendering takes ~48 seconds, while refinement takes ~1.3 seconds [S1].

**Measured Performance:**
*   **Blender Dataset:** Trained on 100 views, tested on 200 held-out images [S1].
*   **LLFF Dataset ($\times 2$):** PSNR 27.34, SSIM 0.842, LPIPS 0.103 (with refinement) [S1].
*   **LLFF Dataset ($\times 4$):** PSNR 25.59, SSIM 0.759, LPIPS 0.165 (with refinement) [S1].
*   **Comparison:** Outperforms NeRF-Bi (bicubic upsampling) and NeRF-Liif in PSNR and SSIM on LLFF [S1].

**Strengths and Limitations:**
*   **Strengths:** Achieves photorealistic renderings without external data or HR ground truth. Leverages 3D consistency for better detail recovery than 2D upsampling [S1].
*   **Limitations:** Does not support arbitrary-scale super-resolution. Introduces extra computational cost compared to standard NeRF, though it consumes no more time than training a full HR NeRF [S1].

## Background
NeRF-SR was introduced by Wang et al. in the paper "NeRF-SR: High-Quality Neural Radiance Fields using Supersampling" [S1]. It is the first pipeline to achieve high-resolution novel view synthesis using mostly low-resolution inputs without external data. The method exploits 3D consistency through a supersampling strategy and, for real-world data, a patch-based refinement network [S1].
