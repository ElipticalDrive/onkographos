# Forward Warping for Novel View Synthesis

Also called: Canonical Field Forward Warping, Forward Flow

## Overview
Forward Warping for Novel View Synthesis is a method for rendering dynamic scenes by modeling a static scene at a canonical time step and forward warping the entire canonical radiance field to other time steps [S1]. It addresses the many-to-one and one-to-many mapping difficulties inherent in dynamic scene reconstruction by employing differentiable forward warping with average splatting and an inpaint network [S1]. Unlike backward flow methods such as NDVG, this approach leverages a canonical representation to simplify the deformation field learning, achieving state-of-the-art performance on public datasets [S1].

## How it works
The method operates in two stages: a coarse stage to learn proxy geometry and a fine stage for high-fidelity rendering. It utilizes a canonical radiance field and a deformation field to map points from the canonical space to the target time $t$.

### Inputs and Outputs
*   **Inputs:** A set of images $\{\mathbf{I}_i\}$ with corresponding camera poses and time steps $t_i$. The canonical time $t_{can}$ is selected (first frame for D-NeRF, middle frame for HyperNeRF) [S1].
*   **Outputs:** Rendered images $\mathbf{C}(\mathbf{r}, t)$ for arbitrary views and time steps $t$ [S1].

### Data Structures
The method maintains several voxel grids and neural networks [S1]:

1.  **Canonical Radiance Feature Grid ($VR_f$):** Voxel grid containing radiance features. Feature dimension is 12 [S1].
2.  **Canonical Coordinate Grid ($VR_{Can}$):** Voxel grid containing the coordinate of each voxel [S1].
3.  **Canonical Density Grid ($V_{\sigma}^{Can}$):** Voxel grid containing canonical density [S1].
4.  **Canonical Color Feature Grid ($V_{cf}^{Can}$):** Voxel grid containing canonical color features. Dimension is 3 or 12 depending on the training stage [S1].
5.  **Canonical Deformation Feature Grid ($VD_f^{Can}$):** Voxel grid containing canonical deformation features. Dimension is 0 for D-NeRF, 12 for HyperNeRF [S1].
6.  **Trajectory Grid ($VT_t$):** Voxel grid containing DCT parameters of each voxel's trajectory [S1].
7.  **Deformation Flow Grid ($V_{flow}$):** Voxel grid containing deformation flow of each voxel from canonical to time $t$ [S1].
8.  **Warped Radiance Field ($VR_t$):** Radiance field at time $t$ warped from $VR_{Can}$ [S1].
9.  **Inpainted Radiance Field ($VR_t^{Inp}$):** Radiance field at time $t$ after inpainting by $F_{\theta3}$ [S1].
10. **Upsampled Radiance Field ($VR_t^{Up}$):** Upsampled radiance field at time $t$ [S1].

### Neural Networks
1.  **Canonical Radiance Network ($F_{\theta1}$):**
    *   **Structure:** 3-layer MLP, width 128, ReLU activation [S1].
    *   **Input:** Radiance feature sampled from $VR_f$ (dim 12) and embedded position (dim 33) [S1].
    *   **Output:** Density (dim 1) and color feature (dim 3 or 12) [S1].
2.  **Canonical Deformation Network ($F_{\theta2}$):**
    *   **Structure:** 4-layer MLP, width 64 [S1].
    *   **Input:** Deformation feature (dim 0 for D-NeRF, 12 for HyperNeRF) and embedded position (dim 33) [S1].
    *   **Output:** Trajectory parameters (DCT coefficients) [S1].
    *   **DCT Bases:** 15 for D-NeRF, 25 for HyperNeRF [S1].
3.  **View Dependent Color Network ($F_{\theta4}$):**
    *   **Structure:** 2-layer MLP, width 64 [S1].
    *   **Input:** Embedded view direction (dim 27) and color feature (dim 12) [S1].
    *   **Output:** RGB color (dim 3) [S1].
4.  **Inpaint Network ($F_{\theta3}$):**
    *   **Structure:** UNet with 4 encode layers and 3 decode layers, plus an upsample layer [S1].
    *   **Encode Layer:** One max pooling layer and two convolution layers (Instance Norm + Conv + ReLU) [S1].
    *   **Decode Layer:** One up-sample interpolation layer and two convolution layers (Instance Norm + Conv + ReLU) [S1].
    *   **Upsample Layer:** Same structure as decode layer [S1].

### Algorithm Steps

#### 1. Canonical Field Initialization
Initialize voxel grids $VR_f$, $VR_{Can}$, $V_{\sigma}^{Can}$, $V_{cf}^{Can}$, $VD_f^{Can}$, and $VT_t$ [S1].

#### 2. Coarse Stage Training
*   **Goal:** Learn proxy geometry to calculate bounding box for fine stage [S1].
*   **Voxel Number:** $6^3$ [S1].
*   **Inpaint Scale:** 1.5 [S1].
*   **Iterations:** 20,000 [S1].
*   **Note:** The inpaint network is **not** used during the coarse stage [S1].
*   **Loss Weights:** $w_1=10^{-1}, w_2=10^{-2}, w_3=10^{-5}, w_4=0, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$ [S1].

#### 3. Fine Stage Training
*   **Goal:** High-fidelity rendering [S1].
*   **Voxel Number:** $8^3$ for D-NeRF, $7^3$ for HyperNeRF [S1].
*   **Inpaint Scale:** 2.0 [S1].
*   **Iterations:** 100,000 [S1].
*   **Progressive Training:** Start with 10 images closest to canonical step. Add one image with the closest time step every 60 iterations [S1].
*   **Loss Weights:** $w_1=10^{-2}, w_2=10^{-3}, w_3=10^{-5}, w_4=10^{-5}, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$ [S1].

#### 4. Forward Warping Pipeline
For a target time $t$ and ray $\mathbf{r}$:

1.  **Sample Canonical Points:** Sample points $w_k$ along the ray in canonical space.
2.  **Compute Deformation:**
    *   Query $VD_f^{Can}$ and $VT_t$ at $w_k$ to get deformation features and DCT parameters.
    *   Pass through $F_{\theta2}$ to get trajectory parameters.
    *   Compute deformation flow $\mathbf{V}_{flow}$ from canonical to time $t$ using DCT basis functions [S1].
    *   Warp point: $w_k^t = w_k + \mathbf{V}_{flow}(w_k, t)$ [S1].
3.  **Average Splatting:**
    *   Use average splatting to warp the canonical radiance field $VR_{Can}$ to time $t$, producing $VR_t$ [S1].
    *   *Note:* Softmax splatting was tested but average splatting was chosen for simplicity and comparable performance [S1].
4.  **Inpainting:**
    *   Pass $VR_t$ through $F_{\theta3}$ to produce $VR_t^{Inp}$ [S1].
5.  **Upsampling:**
    *   Upsample $VR_t^{Inp}$ to produce $VR_t^{Up}$ [S1].
6.  **Rendering:**
    *   Render colors from $VR_t^{Inp}$ and $VR_t^{Up}$ using standard volume rendering [S1].

### Formulas

**Point-wise Color Loss ($\mathcal{L}_{ptc}$):**
Supervises the color of sampled points weighted by their accumulation [S1].
$$
\mathcal{L}_{ptc} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Up}}(\mathbf{r}))
$$
where
$$
\mathcal{L}(\mathbf{C}(\mathbf{r})) = \frac{1}{K} \sum_{k=1}^{K} A_{\text{accum}}(k) \|\mathbf{c}(w_k) - \mathbf{C}_{\text{gt}}(\mathbf{r})\|_2^2
$$
and
$$
A_{\text{accum}}(k) = T(w_k) \, \sigma(w_k) \delta_k
$$
$\mathbf{C}_{\text{Inp}}$ and $\mathbf{C}_{\text{Up}}$ are colors from inpainted and upsampled fields [S1].

**Background Entropy Loss ($\mathcal{L}_{bg}$):**
Encourages densities to concentrate on foreground or background [S1].
$$
\mathcal{L}_{bg} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Up}}(\mathbf{r}))
$$
where
$$
\mathcal{L}(\mathbf{A}(\mathbf{r})) = -\frac{1}{K-1} \sum_{k=1}^{K-1} [ A_{\text{accum}}(k)\log(A_{\text{accum}}(k)) + (1-A_{\text{accum}}(k))\log(1-A_{\text{accum}}(k)) ]
$$
[ S1 ]

**Total Loss:**
$$
\mathcal{L} = \mathcal{L}_{photo} + w_1\mathcal{L}_{ptc} + w_2\mathcal{L}_{bg} + w_3\mathcal{L}_{flow} + w_4\mathcal{L}_{vdiff} + w_5\mathcal{L}_{tv}(\mathbf{V}_{\sigma}^{\text{Can}}) + w_6\mathcal{L}_{tv}(\mathbf{V}_{\text{flow}}^t) + w_7\mathcal{L}_{tv}(\mathbf{D})
$$
where $w_1..w_7$ are balancing weights [S1].

### Parameters
*   **Learning Rate:** $10^{-1}$ for voxel grids, $10^{-3}$ for networks [S1].
*   **Optimizer:** Adam [S1].
*   **Coarse Stage:**
    *   Voxel Number: $6^3$ [S1].
    *   Inpaint Scale: 1.5 [S1].
    *   Iterations: 20,000 [S1].
*   **Fine Stage:**
    *   Voxel Number: $8^3$ (D-NeRF), $7^3$ (HyperNeRF) [S1].
    *   Inpaint Scale: 2.0 [S1].
    *   Iterations: 100,000 [S1].
*   **Canonical Time:** First frame for D-NeRF, middle frame for HyperNeRF [S1].

### Edge Cases and Pitfalls
*   **Memory Consumption:** High, especially for real scenes [S1].
*   **Training Speed:** Slow, approximately one day per scene on GeForce RTX 3090 [S1].
*   **Coarse Stage Importance:** Removing the coarse stage causes significant performance drop because the voxel grid covers a bigger space without proxy geometry filtering [S1].
*   **Inpaint Network Importance:** Removing the inpaint network significantly reduces performance (e.g., Hell Warrior PSNR drops from 27.71 to 27.15) [S1].
*   **Softmax Splatting:** Predicting weights for softmax splatting introduced too much complexity with no obvious improvement over average splatting [S1].

## Operating characteristics
*   **Time Complexity:** Training is slow, taking ~1 day per scene on a GeForce RTX 3090 [S1].
*   **Memory Complexity:** High memory consumption, particularly for real scenes [S1].
*   **Model Size:** 260M parameters for D-NeRF, 440M for HyperNeRF [S1].
*   **Rendering Speed:** 7s per image for D-NeRF, 15s per image for HyperNeRF [S1].
*   **Strengths:** Achieves SOTA performance on public datasets, especially for canonical frames. Forward warping design provides clear advantage over backward flow methods like NDVG [S1].
*   **Limitations:** High memory usage and slow training speed [S1].
*   **When to Use:** When high-quality novel view synthesis of dynamic scenes is required, and computational resources are sufficient for long training times.
*   **When Not to Use:** When real-time rendering or low-memory constraints are critical.

## Background
Forward Warping for Novel View Synthesis was proposed in the paper "Forward Flow for Novel View Synthesis of Dynamic Scenes" [S1]. It builds on the canonical representation approach, addressing the limitations of backward flow methods by explicitly warping the canonical field forward in time. The method was developed to handle complex dynamic scenes with many-to-one and one-to-many mappings, which are challenging for standard NeRF architectures. It was evaluated on the D-NeRF and HyperNeRF datasets, as well as a newly built Lego Complete Dataset [S1].
