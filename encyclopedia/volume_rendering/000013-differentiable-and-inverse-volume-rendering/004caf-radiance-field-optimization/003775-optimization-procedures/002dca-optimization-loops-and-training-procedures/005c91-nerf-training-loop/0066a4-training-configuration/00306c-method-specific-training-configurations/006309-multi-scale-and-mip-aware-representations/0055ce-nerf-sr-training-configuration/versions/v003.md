# NeRF-SR Training Configuration
Also called: NeRF-SR, High-Quality Neural Radiance Fields using Supersampling

## Overview
NeRF-SR is a training configuration designed to synthesize high-resolution novel views from low-resolution input images by optimizing the neural radiance field at multiple scales [S1]. It distinguishes itself from standard NeRF by employing a supersampling strategy that leverages 3D consistency to recover high-frequency details, rather than simply upsampling the final rendered image [S1]. It builds on [NeRF Training Loop](3065-nerf-training-loop.md) but modifies the sampling and optimization schedule to handle resolution scaling explicitly.

## How it works
**Inputs:** Low-resolution training images, camera intrinsics, camera extrinsics, and dataset metadata.
**Outputs:** Optimized MLP weights for density $\sigma$ and color $\mathbf{c}$, capable of rendering high-resolution images.

**Data Structures:**
*   **MLP:** Standard NeRF MLP architecture with positional encoding.
*   **Batch:** Tensor of ray origins and directions.
*   **Samples:** Coarse and fine sample points along rays.

**Parameters:**
*   **Optimizer:** Adam with $\beta_1 = 0.9$, $\beta_2 = 0.999$ [S1].
*   **Batch Size:** 2048 rays per batch [S1].
*   **Learning Rate:** Exponential decay from $5 \cdot 10^{-4}$ to $5 \cdot 10^{-6}$ [S1].
*   **Sampling:** Hierarchical sampling with 64 coarse samples and 64 fine samples [S1].
*   **Epochs:** 20 epochs for Blender dataset; 30 epochs for LLFF dataset [S1].
*   **Dataset Split:** 100 views for training, 200 images held out for testing (Blender); all images for training, average metrics reported (LLFF) [S1].

**Steps:**
1.  **Initialize:** Load low-resolution training images and camera parameters. Initialize NeRF MLP weights.
2.  **Ray Sampling:** For each batch, generate 2048 rays from the training camera poses [S1].
3.  **Hierarchical Sampling:**
    *   Sample 64 points along each ray using the coarse MLP to estimate density [S1].
    *   Use the density estimates to sample 64 additional points for the fine MLP, focusing on high-density regions [S1].
4.  **Volume Rendering:** Compute the rendered color $\hat{C}(\mathbf{r})$ using the standard differentiable volume rendering integral [S1]:
    $$ \hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i $$
    where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$, and $\delta_i$ is the distance between samples [S1].
5.  **Loss Computation:** Compare the rendered high-resolution image against the ground truth high-resolution image (obtained by upsampling or using high-res inputs if available for evaluation) using PSNR, SSIM, and LPIPS metrics [S1].
6.  **Optimization:** Update MLP weights using the Adam optimizer with the specified learning rate decay [S1].
7.  **Iteration:** Repeat steps 2-6 for the specified number of epochs (20 for Blender, 30 for LLFF) [S1].

**Refinement Network (Ours-Refine):**
For real-world datasets like LLFF, a refinement network is applied post-training to boost texture details and edge sharpness [S1].
*   **Definition:** A network that takes the supersampled output and reference patches to enhance high-frequency details [S1].
*   **Inference:** Input images are divided into non-overlapping patches. For each patch, $K=8$ reference patches are extracted from a reference image (typically the first image in the dataset) based on estimated depth and camera parameters [S1]. The refined patch is constructed using these references [S1].
*   **Parameters:** Reference patches count $K=8$; Patch dimensions $64 \times 64$ [S1].
*   **Performance:** Inference time is negligible (~1.3 seconds on a single 1080Ti for a 1008x756 image) compared to rendering (~48 seconds) [S1].
*   **Results:** LLFF $\times$2 Refined: PSNR 27.34, SSIM 0.842, LPIPS 0.103. LLFF $\times$4 Refined: PSNR 25.59, SSIM 0.759, LPIPS 0.165 [S1].

## Subtopics

### Refinement Network (Ours-Refine)
A post-processing step that boosts NeRF-SR outputs with texture details and edge sharpness, particularly for real-world LLFF dataset where supersampling alone is insufficient [S1]. It uses a fixed number of reference patches ($K=8$) of size $64 \times 64$ [S1]. For scale 2, PSNR increases only slightly as supersampling already learns decent HR fields, but LPIPS improves [S1]. For scale 4, refinement is necessary as supersampling derives fewer details [S1].

## Operating characteristics
*   **Time Complexity:** Training time is comparable to training a high-resolution NeRF [S1]. Inference time for rendering a 1008x756 image is ~48 seconds on a single 1080Ti, plus ~1.3 seconds for refinement [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** On LLFF dataset at $\times$2 scale, Ours-Refine achieves PSNR 27.34, SSIM 0.842, LPIPS 0.103 [S1]. At $\times$4 scale, it achieves PSNR 25.59, SSIM 0.759, LPIPS 0.165 [S1].
*   **Strengths:** Achieves photorealistic renderings without external data by exploiting 3D consistency [S1].
*   **Limitations:** Does not support arbitrary-scale super-resolution [S1]. Introduces extra computation efficiency overhead, though it consumes no more time than training a HR NeRF [S1].

## Background
NeRF-SR was introduced by Wang et al. in 2021 [S1]. It is the first pipeline for high-resolution novel view synthesis using mostly low-resolution inputs [S1]. The method exploits 3D consistency from two perspectives: a supersampling strategy and a refinement network [S1].
