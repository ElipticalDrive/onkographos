# Frequency-Modulated Position Encoding

Also called: FM-NeRF Encoding, Frequency-Modulated Point Cloud Rendering with Easy Editing

## Overview
Frequency-Modulated Position Encoding is a coordinate encoding scheme used in point-based radiance field optimization to map raw 3D spatial coordinates and viewing directions into a higher-dimensional feature space suitable for neural network decoding [S1]. It distinguishes itself from standard NeRF positional encoding by narrowing the encoding interval (using powers of 2 with fractional exponents) to provide finer-grained basis function support for frequency modulation, which is critical for high-fidelity point cloud rendering [S1]. It serves as the input transformation stage for the AFNet MLP decoder in the FM-NeRF pipeline [S1].

## How it works
The method transforms input vectors $\mathbf{p}$ (representing either a 3D position $\mathbf{x}$ or a viewing direction $\mathbf{d}$) into a concatenated vector of sine and cosine functions. This encoded vector is then passed to the AFNet MLP.

**Inputs and Outputs:**
*   **Input:** A coordinate vector $\mathbf{p} \in \mathbb{R}^D$ (where $D=3$ for position, $D=3$ for direction).
*   **Output:** An encoded feature vector $\gamma(\mathbf{p}) \in \mathbb{R}^{2 \times L \times D}$, where $L$ is the number of frequency bands.

**Data Structures:**
The encoding is a static mathematical transformation. No persistent data structures are required beyond the input vector and the integer parameter $L$.

**Parameters:**
*   $L$: Number of frequency bands. Set to $L=10$ for spatial coordinates and $L=2$ for view directions [S1].
*   Base: The base of the exponent is 2 [S1].

**Formula:**
The encoding function $\gamma(\mathbf{p})$ is defined as:
$$
\gamma (\mathbf {p}) = \left( \sin (2^0 \pi \mathbf {p}), \cos (2^0 \pi \mathbf {p}), \sin (2^{0.5} \pi \mathbf {p}), \cos (2^{0.5} \pi \mathbf {p}), \dots, \sin (2^{L-1} \pi \mathbf {p}), \cos (2^{L-1} \pi \mathbf {p}) \right)
$$
where $\mathbf{p}$ is the input coordinate/direction and $L$ is the number of frequency bands [S1]. Note that the exponent increases by 0.5 at each step ($0, 0.5, 1.0, \dots, L-1$), rather than the integer steps ($0, 1, 2, \dots$) used in standard NeRF [S1].

**Pseudocode:**
```python
import numpy as np

def frequency_modulated_encoding(p: np.ndarray, L: int) -> np.ndarray:
    """
    Applies frequency-modulated positional encoding to input coordinates.
    
    Args:
        p: Input coordinate vector of shape (D,) or (N, D).
        L: Number of frequency bands.
        
    Returns:
        Encoded vector of shape (2 * L * D,) or (N, 2 * L * D).
    """
    # Ensure p is a numpy array
    p = np.asarray(p)
    
    # Calculate frequencies: 2^0, 2^0.5, ..., 2^(L-1)
    # The exponent ranges from 0 to L-1 with a step of 0.5
    exponents = np.arange(L) * 0.5
    frequencies = np.power(2, exponents)
    
    # Multiply by pi
    scaled_frequencies = frequencies * np.pi
    
    # Prepare output array
    # If p is 1D (single point), shape is (D,)
    # If p is 2D (batch), shape is (N, D)
    is_batch = p.ndim > 1
    
    if is_batch:
        N, D = p.shape
        encoded_list = []
        for freq in scaled_frequencies:
            # Compute sin and cos for all dimensions
            sin_vals = np.sin(p * freq)
            cos_vals = np.cos(p * freq)
            # Concatenate along the last axis
            encoded_list.append(sin_vals)
            encoded_list.append(cos_vals)
        return np.concatenate(encoded_list, axis=-1)
    else:
        # Single point case
        encoded_list = []
        for freq in scaled_frequencies:
            sin_vals = np.sin(p * freq)
            cos_vals = np.cos(p * freq)
            encoded_list.append(sin_vals)
            encoded_list.append(cos_vals)
        return np.concatenate(encoded_list)

```

**Edge Cases and Pitfalls:**
*   **Precision:** The use of fractional exponents in the frequency scaling ($2^{0.5}, 2^{1.0}, \dots$) requires careful implementation to ensure the frequency progression matches the source exactly. Standard NeRF implementations using integer powers ($2^0, 2^1, \dots$) will produce incorrect features [S1].
*   **Dimensionality:** The output dimension is $2 \times L \times D$. For spatial coordinates ($D=3, L=10$), the output is 60-dimensional. For view directions ($D=3, L=2$), the output is 12-dimensional [S1].

### Rasterization
Points are expanded to disks to compensate for sparsity. Radius selection is critical to avoid "bleeding" (seeing occluded surfaces) and "edge expansion" (inaccurate depth) [S1].

## Operating characteristics
*   **Time Complexity:** The encoding itself is $O(L \cdot D)$ per point. The overall training time for realistic rendering is approximately 10 minutes, with convergence taking about 10 hours on the NeRF-Synthetic dataset (one epoch consumes ~12.8s) [S1].
*   **Memory Complexity:** Depends on the MLP size and point cloud size. The MLP has 5 layers with hidden dimensions 256, 256, 256, 128 [S1].
*   **Performance:** Achieves higher PSNR/SSIM on NeRF-Synthetic and Tanks and Temples datasets compared to NeRF, CCNeRF, NPBG, NPBG++, and Huang et al. Comparable or better results on ScanNet and DTU [S1].
*   **Strengths:** Provides fine-grained basis function support for frequency modulation, leading to high-fidelity rendering. Fast convergence for realistic rendering [S1].
*   **Limitations:** Sensitive to rasterization radius; too small causes bleeding, too large causes edge expansion [S1]. Requires initial point clouds from MVSNet or similar [S1].

## Background
The method was introduced in the paper "Frequency-Modulated Point Cloud Rendering with Easy Editing" [S1]. It builds upon the positional encoding form of NeRF [S1] but modifies the frequency progression to narrow the encoding interval. It is used in the context of point-based radiance field optimization, specifically for the AFNet architecture. It is designed to work with point clouds generated by MVSNet [S1].
