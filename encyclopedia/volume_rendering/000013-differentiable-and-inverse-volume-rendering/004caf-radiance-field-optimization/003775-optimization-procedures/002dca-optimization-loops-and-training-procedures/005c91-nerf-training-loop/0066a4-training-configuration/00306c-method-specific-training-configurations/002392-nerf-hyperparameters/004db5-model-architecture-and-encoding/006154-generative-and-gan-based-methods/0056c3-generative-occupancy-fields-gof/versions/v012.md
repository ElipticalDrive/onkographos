# Generative Occupancy Fields (GOF)

## Overview
Generative Occupancy Fields (GOF) is a generative radiance field method for 3D-aware image synthesis that resolves the shape-color ambiguity and diffused surface artifacts inherent in standard cumulative rendering [S1, unofficial]. It achieves this by reinterpreting alpha values as occupancy probabilities and transitioning from volume-based rendering to surface-point rendering via a shrinking sampling region and root-finding [S1, unofficial]. Unlike siblings like [Binary Radiance Fields](13622-binary-radiance-fields.md) which discretize space, GOF maintains continuous differentiability while ensuring compact, smooth surfaces comparable to occupancy networks but with the training stability of radiance fields [S1, unofficial].

## How it works
### Inputs and Outputs
*   **Inputs:** Latent code $z \sim p_z$, camera pose $\xi \sim p_\xi$ (defining ray origin $o$ and direction $d$).
*   **Outputs:** Rendered image color $\tilde{C}(r, z)$ for ray $r$.

### Data Structures
The generator $g_\theta$ is a neural network (typically a FiLMed-SIREN backbone) that takes encoded coordinates and latent code $z$ as input.
*   **Input:** $\text{encode}(x_i, d, z)$
*   **Output:** Alpha value $\alpha_\theta(x_i, z) \in [0, 1]$ and color $\mathbf{c}_\theta(x_i, d, z) \in \mathbb{R}^3$.
*   **Note:** The network predicts $\alpha$ directly, not volume density $\sigma$.

### Parameters
*   $N$: Number of points sampled for rendering. Default: 12 [S1, unofficial].
*   $M$: Number of evenly-spaced points for root-finding. Default: 12 [S1, unofficial].
*   $m_s$: Number of secant method iterations for surface refinement. Default: 3 [S1, unofficial].
*   $\tau$: Threshold for root-finding. Default: 0.5 [S1, unofficial].
*   $\Delta_{init}$: Initial sampling half-width. Defined as $(t_f - t_n)/2$ [S1, unofficial].
*   $\Delta_{min}$: Minimal sampling half-width (pre-defined constant) [S1, unofficial].
*   $\gamma$: Decay rate for shrinking region [S1, unofficial].
*   $\lambda_{normal}, \lambda_{opacity}$: Loss balancing coefficients [S1, unofficial].

### Algorithm Steps

1.  **Surface Location via Root-Finding:**
    To locate the surface $S$ along ray $r(t) = o + td$ within bounds $[t_n, t_f]$:
    1.  Sample $M$ evenly-spaced points $x_k = o + t_k d$ for $k=0 \dots M$, where $t_k = t_n + \frac{k}{M}(t_f - t_n)$.
    2.  Query the generator for alpha values $\alpha_\theta(x_k, z)$. *Note: Gradients are not computed for these queries.*
    3.  Find the bin index $k_S$ where the alpha crosses the threshold $\tau$:
        $$ k_S = \arg\min_k (\alpha_\theta(x_k, z) < \tau \le \alpha_\theta(x_{k+1}, z)) $$
    4.  Apply the secant method iteratively $m_s$ times within the interval $[x_{k_S}, x_{k_S+1}]$ to find the precise surface point $x_s = o + t_s d$ [S1, unofficial].

2.  **Shrinking Sampling Region (Training Only):**
    During training step $n$, restrict the sampling interval to a neighborhood around the located surface $t_s$:
    1.  Compute current half-width: $\Delta_n = \max(\Delta_{init} \exp(-\gamma n), \Delta_{min})$.
    2.  Sample $N$ points $x_i$ uniformly in $[t_s - \Delta_n, t_s + \Delta_n]$.
        $$ t_i \sim U\left[t_s - \Delta_n + \frac{2i-2}{N}\Delta_n, \quad t_s - \Delta_n + \frac{2i}{N}\Delta_n\right] $$
        for $i=1 \dots N$.
    3.  If any $t_i$ exceeds $[t_n, t_f]$, shift the interval back to fit within bounds [S1, unofficial].

3.  **Rendering:**
    Compute the integrated color $\tilde{C}(r, z)$ using alpha composition:
    $$ \tilde{C}(r, z) = \sum_{i=1}^{N} \alpha_\theta(x_i, z) \left( \prod_{j=1}^{i-1} (1 - \alpha_\theta(x_j, z)) \right) \mathbf{c}_\theta(x_i, d, z) $$
    *   For inference, one may use $N=1$ (rendering only the surface point $x_s$) for speed, as the surface is compact [S1, unofficial].

### Pseudocode

```python
import math
import torch

def generate_image(generator, latent_z, ray_origin, ray_direction, 
                   t_near, t_far, N=12, M=12, ms=3, tau=0.5, 
                   delta_init=None, delta_min=0.01, gamma=0.0, step=0):
    """
    Renders an image for a single ray using Generative Occupancy Fields.
    
    Args:
        generator: Neural network returning (alpha, color) for (x, z).
        latent_z: Latent code vector.
        ray_origin: 3D vector (o).
        ray_direction: 3D vector (d).
        t_near: Near plane bound.
        t_far: Far plane bound.
        N: Number of rendering samples.
        M: Number of root-finding bins.
        ms: Secant iterations.
        tau: Threshold for surface detection.
        delta_init: Initial half-width. If None, computed from bounds.
        delta_min: Minimal half-width.
        gamma: Decay rate.
        step: Current training step (for shrinking).
        
    Returns:
        Rendered color scalar/vector.
    """
    
    # 1. Surface Location via Root-Finding
    # Sample M points evenly across [t_near, t_far]
    t_bins = torch.linspace(t_near, t_far, M + 1)
    x_bins = ray_origin.unsqueeze(0) + t_bins.unsqueeze(1) * ray_direction.unsqueeze(0)
    
    # Query alpha values (no gradients needed for root finding)
    with torch.no_grad():
        # Assuming generator returns alpha and color
        # alpha shape: (M+1,)
        alphas = generator(x_bins, latent_z)[0]
        
    # Find bin where alpha crosses tau
    # Condition: alpha[k] < tau <= alpha[k+1]
    # We look for the first k satisfying this
    inside = alphas < tau
    # Shift to compare k and k+1
    # We want smallest k such that inside[k] is True and inside[k+1] is False
    # Actually, alpha approaches 1 in occupied space. 
    # Free space: alpha < tau. Occupied: alpha >= tau.
    # Transition from Free to Occupied.
    
    # Create boolean mask for transition
    # prev < tau AND curr >= tau
    prev_free = alphas[:-1] < tau
    curr_occ = alphas[1:] >= tau
    transition_mask = prev_free & curr_occ
    
    # Find index of first transition
    k_s = torch.argmax(transition_mask.float())
    
    # Define interval for secant method
    t_left = t_bins[k_s]
    t_right = t_bins[k_s + 1]
    alpha_left = alphas[k_s]
    alpha_right = alphas[k_s + 1]
    
    # Secant method iterations
    for _ in range(ms):
        # Linear interpolation (secant approximation)
        # t_new = t_left - alpha_left * (t_right - t_left) / (alpha_right - alpha_left)
        denom = alpha_right - alpha_left
        if abs(denom) < 1e-8:
            break
        t_new = t_left - alpha_left * (t_right - t_left) / denom
        
        # Clamp to interval
        t_new = torch.clamp(t_new, t_left, t_right)
        
        # Query alpha at new point
        x_new = ray_origin + t_new * ray_direction
        with torch.no_grad():
            alpha_new = generator(x_new.unsqueeze(0), latent_z)[0].item()
            
        # Update interval
        if alpha_new < tau:
            t_left = t_new
            alpha_left = alpha_new
        else:
            t_right = t_new
            alpha_right = alpha_new
            
    t_surface = (t_left + t_right) / 2.0
    
    # 2. Determine Sampling Region
    if delta_init is None:
        delta_init = (t_far - t_near) / 2.0
        
    # Shrinking logic (only affects training, but implemented here for completeness)
    # In inference, we might just use delta_min or a fixed small value
    delta_n = max(delta_init * math.exp(-gamma * step), delta_min)
    
    # Sample N points in [t_surface - delta_n, t_surface + delta_n]
    t_start = t_surface - delta_n
    t_end = t_surface + delta_n
    
    # Clamp to [t_near, t_far]
    t_start = max(t_start, t_near)
    t_end = min(t_end, t_far)
    
    # Uniform sampling
    t_samples = torch.linspace(t_start, t_end, N)
    x_samples = ray_origin.unsqueeze(0) + t_samples.unsqueeze(1) * ray_direction.unsqueeze(0)
    
    # 3. Rendering
    # Query alpha and color for all samples
    alphas, colors = generator(x_samples, latent_z)
    
    # Alpha composition
    # T_i = product(1 - alpha_j) for j < i
    # Weight w_i = T_i * alpha_i
    # Color = sum(w_i * color_i)
    
    # Compute transmittance
    # 1 - alpha
    one_minus_alpha = 1.0 - alphas
    # Cumulative product of (1 - alpha)
    # T[0] = 1.0
    # T[i] = T[i-1] * (1 - alpha[i-1])
    
    # Using torch.cumprod
    # We need T_i for each i. T_1 = 1. T_2 = (1-a_1). T_3 = (1-a_1)(1-a_2)
    # Let's compute cumulative product of (1-alpha)
    cum_prod = torch.cumprod(one_minus_alpha, dim=0)
    
    # T_i is cum_prod[i-1] for i>0, and 1.0 for i=0
    # Shift cum_prod to align with T_i
    # T = [1, (1-a0), (1-a0)(1-a1), ...]
    # cum_prod = [(1-a0), (1-a0)(1-a1), ...]
    
    T = torch.cat([torch.tensor([1.0]).to(alphas.device), cum_prod[:-1]])
    
    # Weights
    weights = T * alphas
    
    # Final color
    color = torch.sum(weights.unsqueeze(1) * colors, dim=0)
    
    return color
```

### Edge Cases and Pitfalls
*   **Convergence:** Directly applying occupancy representations to generative models causes severe convergence problems due to sparse gradients on surfaces [S1, unofficial]. GOF mitigates this by starting with cumulative rendering (dense gradients) and shrinking the region [S1, unofficial].
*   **Shape-Color Ambiguity:** Small perturbations on surfaces can still produce realistic RGB images, fooling the discriminator. The opacity regularization and shrinking process help resolve this [S1, unofficial].
*   **Density Thresholding:** Predicted densities in standard radiance fields range widely (0-50), making thresholding difficult. GOF predicts alpha directly, which is bounded in $[0, 1]$, allowing a fixed threshold $\tau=0.5$ [S1, unofficial].
*   **Inference Speed:** Standard rendering requires $M + m_s + N$ queries. Surface-only rendering requires $M + m_s + 1$ queries, offering significant speedup for offline applications [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Rendering requires $O(M + m_s + N)$ network queries per ray. With $N=12, M=12, m_s=3$, this is 27 queries, compared to $2N=24$ in hierarchical sampling baselines, but the surface-only mode reduces this to 16 queries [S1, unofficial].
*   **Memory Complexity:** Depends on the generator architecture (e.g., SIREN). No explicit voxel grid is stored, unlike grid-based methods.
*   **Performance:** Outperforms baselines on MAD (Mean Angle Deviation, measuring compactness) and is comparable on SIDE (Scale-Invariant Depth Error) [S1, unofficial].
*   **Strengths:** Compact, smooth surfaces; stable training; efficient surface-only rendering.
*   **Limitations:** Less suitable for translucent or multi-surface objects (e.g., furry cats) where surface-only rendering leads to over-smoothing [S1, unofficial].

## Background
*   **Origin:** Proposed by Xu et al. in "Generative Occupancy Fields for 3D Surface-Aware Image Synthesis" (2021) [S1, unofficial].
*   **Context:** Builds on generative radiance fields (GRAFs) and occupancy networks. It addresses the trade-off between the training stability of radiance fields and the surface precision of occupancy networks [S1, unofficial].
*   **Usage:** Evaluated on CelebA, BFM, and Cats datasets for 3D-aware image synthesis [S1, unofficial].
