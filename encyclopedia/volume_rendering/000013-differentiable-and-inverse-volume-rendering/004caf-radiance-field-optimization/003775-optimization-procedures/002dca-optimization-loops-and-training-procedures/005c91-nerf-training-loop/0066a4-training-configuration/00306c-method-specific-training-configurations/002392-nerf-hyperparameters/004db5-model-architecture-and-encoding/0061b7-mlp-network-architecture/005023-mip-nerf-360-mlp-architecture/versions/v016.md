# Mip-NeRF 360 MLP Architecture

Also called: Integrated Positional Encoding MLP, PosEnc MLP

## Overview
The Mip-NeRF 360 MLP architecture is a specific neural network configuration for radiance field optimization that integrates positional encoding with a multi-layer perceptron (MLP) to predict volume density and RGB color. It distinguishes itself from standard NeRF by utilizing **integrated positional encoding** to handle the integration of radiance along rays, thereby reducing aliasing artifacts and improving performance on out-of-focus or distant scenes [S1, unofficial]. It builds on [Model Architecture and Encoding](13550-model-architecture-and-encoding.md) by replacing standard positional encoding with a Gaussian-smoothed variant.

## How it works
The architecture consists of two main components: a density network and a color network, separated by a bottleneck vector. The density network processes 3D coordinates using integrated positional encoding, while the color network combines the bottleneck features with directional encoding to predict RGB values.

### Inputs and Outputs
*   **Inputs:**
    *   3D point coordinates $\mathbf{x} \in \mathbb{R}^3$ (represented as mean $\mu$ and covariance $\Sigma$ for integrated encoding).
    *   Viewing direction $\mathbf{d} \in S^2$ (or reflection direction $\mathbf{r}$ if reflections are enabled).
    *   Optional auxiliary inputs: normals, roughness, GLO vectors.
*   **Outputs:**
    *   Volume density $\sigma \in \mathbb{R}_{\ge 0}$.
    *   RGB color $\mathbf{c} \in [0, 1]^3$.
    *   Optional: Normals, roughness, specular/diffuse components.

### Data Structures and Parameters
The architecture is defined by the following hyperparameters [S1, unofficial]:

| Parameter | Type | Default Value | Description |
| :--- | :--- | :--- | :--- |
| `net_depth` | int | 8 | Depth of the density MLP. |
| `net_width` | int | 256 | Width of the density MLP. |
| `bottleneck_width` | int | 256 | Width of the vector connecting density and color networks. |
| `net_depth_viewdirs` | int | 1 | Depth of the color MLP. |
| `net_width_viewdirs` | int | 128 | Width of the color MLP. |
| `min_deg_point` | int | 0 | Minimum degree of positional encoding for points. |
| `max_deg_point` | int | 12 | Maximum degree of positional encoding for points. |
| `skip_layer` | int | 4 | Skip connection interval for the density MLP. |
| `skip_layer_dir` | int | 4 | Skip connection interval for the color MLP. |
| `deg_view` | int | 4 | Degree of encoding for view/reflection directions. |
| `density_bias` | float | -1.0 | Bias added to raw density before activation. |
| `density_noise` | float | 0.0 | Standard deviation of noise added to raw density. |
| `rgb_bias` | float | 0.0 | Bias added to raw color before activation. |
| `rgb_padding` | float | 0.001 | Padding for RGB output range $[-p, 1+p]$. |
| `use_reflections` | bool | False | Use reflection directions instead of view directions. |
| `use_directional_enc` | bool | False | Use Integrated Directional Encoding (IDE). |
| `basis_shape` | str | 'icosahedron' | Basis shape for IDE ('octahedron' or 'icosahedron'). |
| `basis_subdivisions` | int | 2 | Tessellation count for the basis shape. |
| `enable_pred_normals` | bool | False | Enable prediction of normals via the network. |
| `disable_density_normals` | bool | True | Disable automatic gradient-based normal computation. |
| `use_diffuse_color` | bool | False | Predict diffuse and specular colors separately. |
| `use_specular_tint` | bool | False | Predict a tint vector for specular color. |
| `use_n_dot_v` | bool | False | Feed $\mathbf{n} \cdot \mathbf{v}$ to the color network. |
| `bottleneck_noise` | float | 0.0 | Standard deviation of noise added to the bottleneck vector. |
| `warp_fn` | callable | None | Function to linearize means and covs. |

### Algorithm Steps

1.  **Setup and Basis Generation:**
    *   If `use_reflections` is True, ensure normals are available (either via `enable_pred_normals` or by not disabling density normals). If not, raise `ValueError` [S1, unofficial].
    *   Precompute the transpose of the basis matrix for integrated positional encoding:
        $$ \mathbf{B}^T = \text{generate\_basis}(\text{basis\_shape}, \text{basis\_subdivisions})^T $$
        Store as `self.pos_basis_t` [S1, unofficial].

2.  **Directional Encoding Function:**
    *   If `use_directional_enc` is True, generate the Integrated Directional Encoding (IDE) function using `ref_utils.generate_ide_fn(deg_view)` [S1, unofficial].
    *   Otherwise, define `dir_enc_fn` as standard positional encoding with `min_deg=0`, `max_deg=deg_view`, and `append_identity=True` [S1, unofficial].

3.  **Density Prediction:**
    *   **Linearization:** If `warp_fn` is not None, linearize the input means and covs:
        $$ (\mu', \Sigma') = \text{track\_linearize}(\text{warp\_fn}, \mu, \Sigma) $$
    *   **Lift and Diagonalize:** Lift the means and covs into the positional encoding basis and diagonalize them to obtain lifted means $\tilde{\mu}$ and lifted variances $\tilde{\sigma}^2$:
        $$ (\tilde{\mu}, \tilde{\sigma}^2) = \text{lift\_and\_diagonalize}(\mu, \Sigma, \mathbf{B}^T) $$
    *   **Integrated Positional Encoding:** Compute the input feature vector $\mathbf{x}$ using integrated positional encoding:
        $$ \mathbf{x} = \text{integrated\_pos\_enc}(\tilde{\mu}, \tilde{\sigma}^2, \text{min\_deg\_point}, \text{max\_deg\_point}) $$
        This involves integrating the sinusoidal positional encoding functions over the Gaussian distribution defined by $\tilde{\mu}$ and $\tilde{\sigma}^2$ [S1, unofficial].
    *   **Density MLP:** Iterate $i$ from 0 to `net_depth` - 1:
        *   Apply dense layer: $\mathbf{x} = \text{activation}(\mathbf{W}_i \mathbf{x} + \mathbf{b}_i)$.
        *   If $i > 0$ and $i \pmod{\text{skip\_layer}} == 0$, concatenate the original input $\mathbf{x}_{\text{orig}}$ to $\mathbf{x}$ along the last axis.
    *   **Raw Density:** Output raw density $\sigma_{\text{raw}}$ using a final dense layer with width 1:
        $$ \sigma_{\text{raw}} = \mathbf{W}_{\text{out}} \mathbf{x} + b_{\text{out}} $$
        Extract the scalar value: $\sigma_{\text{raw}} = \sigma_{\text{raw}}[..., 0]$.
    *   **Density Noise:** If `density_noise` > 0, add Gaussian noise:
        $$ \sigma_{\text{raw}} \leftarrow \sigma_{\text{raw}} + \mathcal{N}(0, \text{density\_noise}) $$
    *   **Normal Computation (Optional):** If `disable_density_normals` is False:
        *   Flatten $\mu$ and $\Sigma$.
        *   Compute the gradient of the raw density with respect to the input coordinates using automatic differentiation (e.g., `jax.value_and_grad`).
        *   Compute normals $\mathbf{n}$ as the negative normalized gradient:
            $$ \mathbf{n} = -\frac{\nabla_{\mathbf{x}} \sigma_{\text{raw}}}{\|\nabla_{\mathbf{x}} \sigma_{\text{raw}}\|_2} $$
        *   Note: Normals are computed from raw density for numerical stability [S1, unofficial].
    *   **Density Activation:** Compute final density:
        $$ \sigma = \text{density\_activation}(\sigma_{\text{raw}} + \text{density\_bias}) $$
        Typically, `density_activation` is `softplus` or `relu` [S1, unofficial].

4.  **Color Network Input Preparation:**
    *   **Bottleneck:** The output of the density network (before the final density layer) is the bottleneck vector $\mathbf{b}$.
    *   **Directional Encoding:** Compute directional encoding $\mathbf{d}_{\text{enc}}$:
        *   If `use_reflections` is True, compute reflection direction $\mathbf{r} = 2(\mathbf{n} \cdot \mathbf{v})\mathbf{n} - \mathbf{v}$ (note: viewdirs are flipped before reflection if they point from camera to point) [S1, unofficial].
        *   Apply `dir_enc_fn` to $\mathbf{d}$ or $\mathbf{r}$ to get $\mathbf{d}_{\text{enc}}$.
    *   **Broadcasting:** Broadcast $\mathbf{d}_{\text{enc}}$ to match the bottleneck shape dimensions.
    *   **Concatenation:** Create input list $\mathbf{x}_{\text{color}} = [\mathbf{b}, \mathbf{d}_{\text{enc}}]$.
    *   **Optional Additions:**
        *   If `use_n_dot_v` is True, compute $\mathbf{n} \cdot \mathbf{v}$ and append to $\mathbf{x}_{\text{color}}$.
        *   If `glo_vec` is not None, broadcast and append to $\mathbf{x}_{\text{color}}$.
    *   Concatenate all elements in $\mathbf{x}_{\text{color}}$ along the last axis.

5.  **Color Prediction:**
    *   **Color MLP:** Iterate $i$ from 0 to `net_depth_viewdirs` - 1:
        *   Apply dense layer: $\mathbf{x}_{\text{color}} = \text{activation}(\mathbf{W}_i \mathbf{x}_{\text{color}} + \mathbf{b}_i)$.
        *   If $i > 0$ and $i \pmod{\text{skip\_layer\_dir}} == 0$, concatenate the original input $\mathbf{x}_{\text{color, orig}}$ to $\mathbf{x}_{\text{color}}$.
    *   **Raw Color:** Compute raw RGB values:
        $$ \mathbf{c}_{\text{raw}} = \mathbf{W}_{\text{out}} \mathbf{x}_{\text{color}} + \mathbf{b}_{\text{out}} $$
    *   **Specular/Diffuse Split (Optional):**
        *   If `use_diffuse_color` is True:
            $$ \mathbf{c}_{\text{diffuse}} = \sigma(\mathbf{c}_{\text{raw}} - \ln(3.0)) $$
        *   If `use_specular_tint` is True:
            $$ \mathbf{c}_{\text{specular}} = \text{tint} \odot \mathbf{c}_{\text{raw}} $$
        *   Else:
            $$ \mathbf{c}_{\text{specular}} = 0.5 \odot \mathbf{c}_{\text{raw}} $$
        *   Combine and tone map:
            $$ \mathbf{c} = \text{clip}(\text{linear\_to\_srgb}(\mathbf{c}_{\text{specular}} + \mathbf{c}_{\text{diffuse}}), 0.0, 1.0) $$
    *   **Standard RGB Output:** If no split:
        $$ \mathbf{c} = \text{rgb\_activation}(\mathbf{c}_{\text{raw}} + \text{rgb\_bias}) $$
    *   **RGB Padding:** Apply padding to ensure output range $[-\text{rgb\_padding}, 1+\text{rgb\_padding}]$:
        $$ \mathbf{c} = \mathbf{c} \cdot (1 + 2 \cdot \text{rgb\_padding}) - \text{rgb\_padding} $$

### Pseudocode

```python
import jax.numpy as jnp
import jax
from jax import random

def mipnerf360_mlp_forward(params, x, cov, viewdirs, config):
    """
    Forward pass for Mip-NeRF 360 MLP.
    
    Args:
        params: Dictionary of network weights.
        x: 3D coordinates, shape (..., 3).
        cov: Covariance matrices, shape (..., 3, 3).
        viewdirs: Viewing directions, shape (..., 3).
        config: Configuration object with hyperparameters.
        
    Returns:
        density: Volume density, shape (...,).
        rgb: RGB color, shape (..., 3).
        normals: Surface normals, shape (..., 3) or None.
    """
    
    # 1. Setup
    if config.use_reflections:
        if not config.enable_pred_normals and config.disable_density_normals:
            raise ValueError("Reflections require normals to be computed.")
    
    # Precomputed basis transpose (stored in params or config)
    pos_basis_t = config.pos_basis_t
    
    # 2. Directional Encoding Function
    if config.use_directional_enc:
        dir_enc_fn = generate_ide_fn(config.deg_view, config.basis_shape, config.basis_subdivisions)
    else:
        dir_enc_fn = lambda d: pos_enc(d, min_deg=0, max_deg=config.deg_view, append_identity=True)
    
    # 3. Density Prediction
    # Linearize if warp_fn is provided
    if config.warp_fn is not None:
        x_lin, cov_lin = track_linearize(config.warp_fn, x, cov)
    else:
        x_lin, cov_lin = x, cov
        
    # Lift and diagonalize
    lifted_means, lifted_vars = lift_and_diagonalize(x_lin, cov_lin, pos_basis_t)
    
    # Integrated positional encoding
    x_enc = integrated_pos_enc(lifted_means, lifted_vars, 
                               config.min_deg_point, config.max_deg_point)
    
    # Density MLP
    x_dens = x_enc
    for i in range(config.net_depth):
        x_dens = apply_dense_layer(x_dens, params[f'dens_w{i}'], params[f'dens_b{i}'], 
                                   config.net_activation)
        if i > 0 and i % config.skip_layer == 0:
            x_dens = jnp.concatenate([x_dens, x_enc], axis=-1)
            
    # Raw density
    raw_density = jnp.squeeze(apply_dense_layer(x_dens, params['dens_w_out'], params['dens_b_out'], 
                                                lambda x: x), axis=-1)
    
    # Density noise
    if config.density_noise > 0:
        raw_density += config.density_noise * random.normal(random.PRNGKey(0), raw_density.shape)
        
    # Normal computation (if enabled)
    normals = None
    if not config.disable_density_normals:
        # Compute gradient of raw_density w.r.t x
        def predict_density(x_in):
            # Re-run density network up to raw_density for gradient
            # ... (simplified for brevity, assumes x_in is used to recompute)
            pass
        
        # Using jax.vmap for batched gradient computation
        raw_density_grad = jax.vmap(jax.grad(predict_density))(x)
        normals = -l2_normalize(raw_density_grad)
        
    # Density activation
    density = density_activation(raw_density + config.density_bias)
    
    # 4. Color Network Input
    # Bottleneck is the output of the density network before the final layer
    # In practice, this is often the output of the last hidden layer of the density MLP
    bottleneck = x_dens # Assuming x_dens is the bottleneck before final layer
    
    # Directional encoding
    if config.use_reflections:
        # Flip viewdirs if they point from camera to point
        viewdirs_toward = -viewdirs
        if normals is not None:
            refdirs = reflect(viewdirs_toward, normals)
        else:
            refdirs = viewdirs_toward # Fallback or error
    else:
        refdirs = viewdirs
        
    dir_enc = dir_enc_fn(refdirs)
    
    # Broadcast dir_enc to match bottleneck shape
    dir_enc = jnp.broadcast_to(dir_enc[..., None, :], bottleneck.shape[:-1] + (dir_enc.shape[-1],))
    
    x_color = [bottleneck, dir_enc]
    
    if config.use_n_dot_v:
        if normals is not None:
            n_dot_v = jnp.sum(normals * viewdirs[..., None, :], axis=-1, keepdims=True)
            x_color.append(n_dot_v)
            
    if config.glo_vec is not None:
        glo_vec = jnp.broadcast_to(config.glo_vec, bottleneck.shape)
        x_color.append(glo_vec)
        
    x_color = jnp.concatenate(x_color, axis=-1)
    
    # 5. Color Prediction
    for i in range(config.net_depth_viewdirs):
        x_color = apply_dense_layer(x_color, params[f'color_w{i}'], params[f'color_b{i}'], 
                                    config.net_activation)
        if i > 0 and i % config.skip_layer_dir == 0:
            x_color = jnp.concatenate([x_color, x_color_orig], axis=-1)
            
    raw_rgb = apply_dense_layer(x_color, params['color_w_out'], params['color_b_out'], 
                                lambda x: x)
    
    # Specular/Diffuse Split
    if config.use_diffuse_color:
        diffuse_linear = sigmoid(raw_rgb - jnp.log(3.0))
        if config.use_specular_tint:
            specular_linear = config.tint * raw_rgb
        else:
            specular_linear = 0.5 * raw_rgb
        rgb = clip(linear_to_srgb(specular_linear + diffuse_linear), 0.0, 1.0)
    else:
        rgb = rgb_activation(raw_rgb + config.rgb_bias)
        
    # RGB Padding
    rgb = rgb * (1 + 2 * config.rgb_padding) - config.rgb_padding
    
    return density, rgb, normals
```

### Edge Cases and Pitfalls
*   **Reflections Require Normals:** If `use_reflections` is True, normals must be computed. This can be done by enabling `enable_pred_normals` or by not disabling density normals (`disable_density_normals = False`). If neither is true, a `ValueError` is raised [S1, unofficial].
*   **Reflection Direction Flip:** View directions typically point from the camera to the point. The `reflect` function assumes directions point toward the camera. Therefore, view directions must be flipped (`-viewdirs`) before computing reflections [S1, unofficial].
*   **Normal Stability:** Normals are computed from the gradient of the *raw* (pre-activation) density, not the final activated density. This is because the activation function (e.g., softplus) may have a steep or flat gradient, leading to numerical instability [S1, unofficial].
*   **Integrated Encoding:** The use of integrated positional encoding requires passing both mean and covariance of the point distribution, not just the mean. This is a key difference from standard NeRF [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The density network has `net_depth` layers and width `net_width`. The color network has `net_depth_viewdirs` layers and width `net_width_viewdirs`. The complexity is $O(\text{net\_depth} \cdot \text{net\_width}^2 + \text{net\_depth\_viewdirs} \cdot \text{net\_width\_viewdirs}^2)$ per point.
*   **Memory Complexity:** The model stores weights for both MLPs. The bottleneck width is `bottleneck_width`.
*   **Performance:** Integrated positional encoding improves rendering quality for out-of-focus and distant scenes by reducing aliasing. It is computationally more expensive than standard positional encoding due to the integration step.
*   **Strengths:** Handles aliasing well, supports specular reflections, roughness prediction, and diffuse/specular splitting.
*   **Limitations:** Requires covariance information for integrated encoding. Reflections require normals.

## Background
The Mip-NeRF 360 MLP architecture is part of the Mip-NeRF 360 project by Google Research, which extends the original NeRF architecture to handle unbounded scenes and improve rendering quality. It uses integrated positional encoding to address the aliasing issues inherent in standard NeRF when rendering at different resolutions or focal lengths [S1, unofficial].
