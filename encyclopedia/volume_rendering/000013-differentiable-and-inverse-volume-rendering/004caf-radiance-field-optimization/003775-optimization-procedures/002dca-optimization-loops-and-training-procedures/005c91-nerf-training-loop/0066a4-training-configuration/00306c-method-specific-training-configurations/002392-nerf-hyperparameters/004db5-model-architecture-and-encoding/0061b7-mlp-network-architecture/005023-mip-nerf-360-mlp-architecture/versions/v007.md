# Mip-NeRF 360 MLP Architecture

Also called: Integrated Positional Encoding MLP, PosEnc MLP

## Overview
This method defines the specific Multi-Layer Perceptron (MLP) architecture used in the Mip-NeRF 360 implementation to map 3D spatial coordinates and viewing directions to volume density and color. It distinguishes itself from standard NeRF architectures by integrating positional encoding over the Gaussian uncertainty of the input points (integrated positional encoding) rather than encoding a single point, and by supporting advanced features such as specular tinting, roughness prediction, and reflection-based shading [S1, unofficial].

## How it works
**Inputs:**
*   3D spatial coordinates $\mathbf{x} \in \mathbb{R}^3$ (represented as a mean $\mu$ and covariance $\Sigma$ to account for integration).
*   Viewing direction $\mathbf{d} \in \mathbb{R}^3$ (or reflection direction $\mathbf{r}$).
*   Optional normal vectors $\mathbf{n} \in \mathbb{R}^3$.
*   Optional global orientation vectors (GLO) $\mathbf{g} \in \mathbb{R}^k$.

**Outputs:**
*   Volume density $\sigma \in \mathbb{R}$.
*   Color $\mathbf{c} \in \mathbb{R}^3$.
*   Optional roughness $\rho \in \mathbb{R}$ and normals $\mathbf{n}$.

**Data Structures:**
The architecture is defined by a configuration object containing the following fields:
*   `net_depth`: int (default 8). Depth of the density MLP.
*   `net_width`: int (default 256). Width of the density MLP.
*   `bottleneck_width`: int (default 256). Width of the feature vector $\mathbf{e}$ connecting density and color networks.
*   `net_depth_viewdirs`: int (default 1). Depth of the color MLP.
*   `net_width_viewdirs`: int (default 128). Width of the color MLP.
*   `min_deg_point`: int (default 0). Minimum frequency for positional encoding of points.
*   `max_deg_point`: int (default 12). Maximum frequency for positional encoding of points.
*   `skip_layer`: int (default 4). Frequency of skip connections in the density MLP.
*   `skip_layer_dir`: int (default 4). Frequency of skip connections in the color MLP.
*   `deg_view`: int (default 4). Degree of positional encoding for directions.
*   `density_bias`: float (default -1.0). Bias added to raw density before activation.
*   `density_noise`: float (default 0.0). Standard deviation of noise added to raw density.
*   `rgb_bias`: float (default 0.0). Bias added to raw color before activation.
*   `rgb_padding`: float (default 0.001). Padding applied to RGB output range.
*   `use_reflections`: bool (default False). Use reflection directions instead of view directions.
*   `use_directional_enc`: bool (default False). Use Integrated Directional Encoding (IDE).
*   `enable_pred_roughness`: bool (default False). Predict roughness.
*   `roughness_bias`: float (default -1.0). Bias for roughness.
*   `use_diffuse_color`: bool (default False). Predict diffuse/specular split.
*   `use_specular_tint`: bool (default False). Predict specular tint.
*   `use_n_dot_v`: bool (default False). Include $\mathbf{n} \cdot \mathbf{d}$ in color input.
*   `bottleneck_noise`: float (default 0.0). Noise added to bottleneck features.
*   `basis_shape`: str (default 'icosahedron'). Basis for integrated PE ('icosahedron' or 'octahedron').
*   `basis_subdivisions`: int (default 2). Tessellation count for the basis.
*   `net_activation`: Callable. Activation function for hidden layers.
*   `density_activation`: Callable. Activation function for density.
*   `rgb_activation`: Callable. Activation function for RGB.
*   `roughness_activation`: Callable. Activation function for roughness.
*   `rgb_premultiplier`: float. Multiplier for RGB output.
*   `num_rgb_channels`: int. Number of color channels.
*   `enable_pred_normals`: bool. Enable normal prediction.
*   `disable_density_normals`: bool. Disable density gradient normals.
*   `disable_rgb`: bool. Disable RGB output.
*   `warp_fn`: Callable. Function to linearize means/covs.

**Steps:**

1.  **Setup and Basis Precomputation:**
    If `use_reflections` is True, normals must be available. If `enable_pred_normals` is False and `disable_density_normals` is True, raise `ValueError` [S1, unofficial].
    Precompute the transpose of the basis matrix for integrated positional encoding:
    $$ \mathbf{B}^T = \text{geopoly.generate\_basis}(\text{basis\_shape}, \text{basis\_subdivisions})^T $$
    Store as `self.pos_basis_t` [S1, unofficial].

2.  **Directional Encoding Function:**
    If `use_directional_enc` is True, generate the Integrated Directional Encoding (IDE) function using `ref_utils.generate_ide_fn(deg_view)` [S1, unofficial].
    Otherwise, define `dir_enc_fn` to use standard positional encoding with `min_deg=0`, `max_deg=deg_view`, and `append_identity=True` [S1, unofficial].

3.  **Density Prediction:**
    a. **Linearization:** If `warp_fn` is not None, linearize the means $\mu$ and covariances $\Sigma$ using `coord.track_linearize(warp_fn, mu, Sigma)` [S1, unofficial].
    b. **Lift and Diagonalize:** Lift the means and covariances into the basis space and diagonalize them to obtain lifted means $\tilde{\mu}$ and lifted variances $\tilde{\sigma}^2$:
       $$ \tilde{\mu}, \tilde{\sigma}^2 = \text{coord.lift\_and\_diagonalize}(\mu, \Sigma, \mathbf{B}^T) $$
    c. **Integrated Positional Encoding:** Compute the integrated positional encoding input $\mathbf{x}$:
       $$ \mathbf{x} = \text{coord.integrated\_pos\_enc}(\tilde{\mu}, \tilde{\sigma}^2, \text{min\_deg\_point}, \text{max\_deg\_point}) $$
    d. **Density MLP Forward Pass:**
       Initialize $x_0 = \mathbf{x}$.
       For $i$ from 0 to `net_depth` - 1:
       $$ h_i = \text{net\_activation}(\mathbf{W}_i x_i + \mathbf{b}_i) $$
       If $i > 0$ and $i \pmod{\text{skip\_layer}} == 0$:
       $$ x_{i+1} = \text{concat}(h_i, x_0) $$
       Else:
       $$ x_{i+1} = h_i $$
    e. **Raw Density:**
       $$ \sigma_{\text{raw}} = \text{dense\_layer}_{\text{width}=1}(x_{\text{net\_depth}})[..., 0] $$
    f. **Density Noise:** If `density_key` is not None and `density_noise` > 0:
       $$ \sigma_{\text{raw}} \leftarrow \sigma_{\text{raw}} + \text{density\_noise} \cdot \mathcal{N}(0, 1) $$
    g. **Normal Computation:** If `disable_density_normals` is False:
       Compute the gradient of the raw density with respect to the input coordinates using automatic differentiation (e.g., `jax.value_and_grad`).
       $$ \nabla \sigma_{\text{raw}} = \nabla_{\mathbf{x}} \sigma_{\text{raw}} $$
       Compute normals:
       $$ \mathbf{n} = -\frac{\nabla \sigma_{\text{raw}}}{\|\nabla \sigma_{\text{raw}}\|_2} $$
       *Note: Normals are computed from raw density for numerical stability [S1, unofficial].*
    h. **Final Density:**
       $$ \sigma = \text{density\_activation}(\sigma_{\text{raw}} + \text{density\_bias}) $$

4.  **Color Network Input Preparation:**
    a. **Directional Encoding:** Compute directional encoding $\mathbf{d}_{\text{enc}}$.
       If `use_reflections` is True, flip view directions $\mathbf{d}$ to $-\mathbf{d}$ before computing reflection $\mathbf{r}$, as view directions point from camera to point, while reflection utilities assume they point toward the camera [S1, unofficial].
       $$ \mathbf{d}_{\text{enc}} = \text{dir\_enc\_fn}(\mathbf{d} \text{ or } \mathbf{r}) $$
       Broadcast $\mathbf{d}_{\text{enc}}$ to match the bottleneck feature dimensions:
       $$ \mathbf{d}_{\text{enc}} \leftarrow \text{broadcast}(\mathbf{d}_{\text{enc}}, \text{shape}=\text{bottleneck.shape}[:-1] + (\text{dir\_enc.shape}[-1],)) $$
    b. **Feature Aggregation:**
       Let $\mathbf{e}$ be the bottleneck feature vector from the density network.
       Initialize input list $x_{\text{color}} = [\mathbf{e}]$.
       Append $\mathbf{d}_{\text{enc}}$ to $x_{\text{color}}$.
       If `use_n_dot_v` is True:
       $$ \text{ndv} = \sum (\mathbf{n} \cdot \mathbf{d}) $$
       Append $\text{ndv}$ to $x_{\text{color}}$.
       If `glo_vec` is not None:
       Broadcast `glo_vec` to match bottleneck shape and append to $x_{\text{color}}$.
       Concatenate all elements in $x_{\text{color}}$ along the last axis to form $\mathbf{x}_{\text{color}}$.

5.  **Color Network Forward Pass:**
    Initialize $y_0 = \mathbf{x}_{\text{color}}$.
    For $i$ from 0 to `net_depth_viewdirs` - 1:
    $$ h_i = \text{net\_activation}(\mathbf{W}'_i y_i + \mathbf{b}'_i) $$
    If $i > 0$ and $i \pmod{\text{skip\_layer\_dir}} == 0$:
    $$ y_{i+1} = \text{concat}(h_i, y_0) $$
    Else:
    $$ y_{i+1} = h_i $$

6.  **RGB Output and Post-Processing:**
    a. **Raw RGB:**
       $$ \mathbf{c}_{\text{raw}} = \text{dense\_layer}_{\text{num\_rgb\_channels}}(y_{\text{net\_depth\_viewdirs}}) $$
    b. **Activation:**
       $$ \mathbf{c} = \text{rgb\_activation}(\mathbf{c}_{\text{raw}} \cdot \text{rgb\_premultiplier} + \text{rgb\_bias}) $$
    c. **Specular/Diffuse Split (Optional):**
       If `use_diffuse_color` is True:
       $$ \mathbf{c}_{\text{diffuse}} = \sigma(\mathbf{c}_{\text{raw\_diffuse}} - \ln(3.0)) $$
       If `use_specular_tint` is True:
       $$ \mathbf{c}_{\text{specular}} = \text{tint} \cdot \mathbf{c} $$
       Else:
       $$ \mathbf{c}_{\text{specular}} = 0.5 \cdot \mathbf{c} $$
       $$ \mathbf{c} = \text{clip}(\text{linear\_to\_srgb}(\mathbf{c}_{\text{specular}} + \mathbf{c}_{\text{diffuse}}), 0.0, 1.0) $$
    d. **RGB Padding:**
       $$ \mathbf{c} = \mathbf{c} \cdot (1 + 2 \cdot \text{rgb\_padding}) - \text{rgb\_padding} $$

**Pseudocode:**

```python
import jax.numpy as jnp
import jax
from jax import random

class MipNeRF360MLP:
    def __init__(self, config):
        self.config = config
        self.net_depth = config.net_depth
        self.net_width = config.net_width
        self.bottleneck_width = config.bottleneck_width
        self.net_depth_viewdirs = config.net_depth_viewdirs
        self.net_width_viewdirs = config.net_width_viewdirs
        self.min_deg_point = config.min_deg_point
        self.max_deg_point = config.max_deg_point
        self.skip_layer = config.skip_layer
        self.skip_layer_dir = config.skip_layer_dir
        self.deg_view = config.deg_view
        self.density_bias = config.density_bias
        self.density_noise = config.density_noise
        self.rgb_bias = config.rgb_bias
        self.rgb_padding = config.rgb_padding
        self.use_reflections = config.use_reflections
        self.use_directional_enc = config.use_directional_enc
        self.enable_pred_roughness = config.enable_pred_roughness
        self.roughness_bias = config.roughness_bias
        self.use_diffuse_color = config.use_diffuse_color
        self.use_specular_tint = config.use_specular_tint
        self.use_n_dot_v = config.use_n_dot_v
        self.bottleneck_noise = config.bottleneck_noise
        self.basis_shape = config.basis_shape
        self.basis_subdivisions = config.basis_subdivisions
        self.net_activation = config.net_activation
        self.density_activation = config.density_activation
        self.rgb_activation = config.rgb_activation
        self.roughness_activation = config.roughness_activation
        self.rgb_premultiplier = config.rgb_premultiplier
        self.num_rgb_channels = config.num_rgb_channels
        self.enable_pred_normals = config.enable_pred_normals
        self.disable_density_normals = config.disable_density_normals
        self.disable_rgb = config.disable_rgb
        self.warp_fn = config.warp_fn
        
        # Precompute basis transpose
        # Note: geopoly.generate_basis is assumed to be available in the environment
        self.pos_basis_t = geopoly.generate_basis(self.basis_shape, self.basis_subdivisions).T
        
        # Setup directional encoding
        if self.use_directional_enc:
            self.dir_enc_fn = ref_utils.generate_ide_fn(self.deg_view)
        else:
            self.dir_enc_fn = lambda x: coord.pos_enc(x, min_deg=0, max_deg=self.deg_view, append_identity=True)

    def predict_density(self, coords, means, covs, rng_key):
        """
        Predicts density and optionally normals.
        coords: (..., 3)
        means: (..., 3)
        covs: (..., 3, 3)
        """
        # Linearize if warp_fn is present
        if self.warp_fn is not None:
            means, covs = coord.track_linearize(self.warp_fn, means, covs)
            
        # Lift and diagonalize
        lifted_means, lifted_vars = coord.lift_and_diagonalize(means, covs, self.pos_basis_t)
        
        # Integrated positional encoding
        x = coord.integrated_pos_enc(lifted_means, lifted_vars, self.min_deg_point, self.max_deg_point)
        
        # Density MLP
        h = x
        for i in range(self.net_depth):
            h = self.net_activation(jnp.dot(h, self.weights_density[i]) + self.biases_density[i])
            if i > 0 and i % self.skip_layer == 0:
                h = jnp.concatenate([h, x], axis=-1)
                
        raw_density = h[..., 0]
        
        # Density noise
        if self.density_noise > 0:
            noise = random.normal(rng_key, raw_density.shape)
            raw_density = raw_density + self.density_noise * noise
            
        # Normal computation
        normals = None
        if not self.disable_density_normals:
            # Compute gradient of raw density w.r.t coords
            # Using jax.value_and_grad for efficiency
            raw_density_val, raw_grad_density = jax.value_and_grad(
                lambda c: self.predict_density_raw(c, means, covs), has_aux=False
            )(coords)
            normals = -ref_utils.l2_normalize(raw_grad_density)
            
        density = self.density_activation(raw_density + self.density_bias)
        return density, normals, raw_density

    def predict_density_raw(self, coords, means, covs):
        """Helper to compute raw density for gradient calculation."""
        if self.warp_fn is not None:
            means, covs = coord.track_linearize(self.warp_fn, means, covs)
        lifted_means, lifted_vars = coord.lift_and_diagonalize(means, covs, self.pos_basis_t)
        x = coord.integrated_pos_enc(lifted_means, lifted_vars, self.min_deg_point, self.max_deg_point)
        h = x
        for i in range(self.net_depth):
            h = self.net_activation(jnp.dot(h, self.weights_density[i]) + self.biases_density[i])
            if i > 0 and i % self.skip_layer == 0:
                h = jnp.concatenate([h, x], axis=-1)
        return h[..., 0]

    def predict_color(self, bottleneck_features, viewdirs, normals, glo_vec, rng_key):
        """
        Predicts color from bottleneck features, view directions, and normals.
        bottleneck_features: (..., bottleneck_width)
        viewdirs: (..., 3)
        normals: (..., 3) or None
        glo_vec: (..., k) or None
        """
        # Directional encoding
        if self.use_reflections:
            # Flip viewdirs because they point from camera to point
            refdirs = ref_utils.reflect(-viewdirs, normals)
            dir_enc = self.dir_enc_fn(refdirs)
        else:
            dir_enc = self.dir_enc_fn(viewdirs)
            
        # Broadcast dir_enc to match bottleneck shape
        dir_enc = jnp.broadcast_to(
            dir_enc[..., None, :], 
            bottleneck_features.shape[:-1] + (dir_enc.shape[-1],)
        )
        
        # Prepare color network input
        x_color = [bottleneck_features, dir_enc]
        
        if self.use_n_dot_v and normals is not None:
            ndv = jnp.sum(normals * viewdirs[..., None, :], axis=-1, keepdims=True)
            x_color.append(ndv)
            
        if glo_vec is not None:
            glo_vec_broadcast = jnp.broadcast_to(
                glo_vec[..., None, :], 
                bottleneck_features.shape[:-1] + (glo_vec.shape[-1],)
            )
            x_color.append(glo_vec_broadcast)
            
        x_color = jnp.concatenate(x_color, axis=-1)
        
        # Color MLP
        h = x_color
        for i in range(self.net_depth_viewdirs):
            h = self.net_activation(jnp.dot(h, self.weights_color[i]) + self.biases_color[i])
            if i > 0 and i % self.skip_layer_dir == 0:
                h = jnp.concatenate([h, x_color], axis=-1)
                
        raw_rgb = jnp.dot(h, self.weights_rgb) + self.biases_rgb
        
        # RGB Activation
        rgb = self.rgb_activation(raw_rgb * self.rgb_premultiplier + self.rgb_bias)
        
        # Specular/Diffuse Split
        if self.use_diffuse_color:
            raw_rgb_diffuse = raw_rgb[..., :3] # Assuming first 3 channels are diffuse
            diffuse_linear = jnp.sigmoid(raw_rgb_diffuse - jnp.log(3.0))
            if self.use_specular_tint:
                specular_linear = self.tint * rgb
            else:
                specular_linear = 0.5 * rgb
            rgb = jnp.clip(specular_linear + diffuse_linear, 0.0, 1.0)
            
        # RGB Padding
        rgb = rgb * (1 + 2 * self.rgb_padding) - self.rgb_padding
        
        return rgb
```

## Operating characteristics
*   **Time Complexity:** The density network has depth 8 and width 256, while the color network has depth 1 and width 128. The dominant cost is the matrix multiplications in the density network. The integrated positional encoding adds overhead proportional to the number of frequency bands (up to degree 12) and the basis size.
*   **Memory Complexity:** The model parameters are relatively small compared to the stored features or the scene representation. The bottleneck width is 256.
*   **Strengths:** Integrated positional encoding handles aliasing and multi-scale details better than standard positional encoding, which is crucial for the 360-degree scenes in Mip-NeRF 360. The architecture supports advanced shading models (specular, roughness).
*   **Limitations:** The fixed depth and width may not be optimal for all scenes. The reliance on automatic differentiation for normals can be computationally expensive if normals are required for every ray.
*   **When to use:** When implementing Mip-NeRF 360 or similar methods that require integrated positional encoding and advanced shading features.
*   **When not to use:** For simple scenes where standard NeRF is sufficient, or when computational resources are extremely limited and the overhead of integrated PE and complex shading is unjustified.

## Background
The Mip-NeRF 360 MLP architecture was introduced in the "Mip-NeRF 360: Unbounded Anti-Aliased Neural Radiance Fields" paper by T. Müller et al. (2022) [S1, unofficial]. It builds upon the original NeRF architecture [S1, unofficial] by incorporating integrated positional encoding to handle aliasing and by supporting a wider range of shading models. The implementation is part of the `google-research/multinerf` repository [S1, unofficial].
