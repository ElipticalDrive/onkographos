# Conditional Radiance Field with Shared Branch

Also called: CRF with Shared Branch, Modular Conditional Radiance Field

## Overview
The Conditional Radiance Field with Shared Branch is a neural radiance field architecture designed for shape and color disentanglement, enabling efficient editing by allowing specific submodules to be finetuned [S1]. It maps a 3D location $\mathbf{x}$, viewing direction $\mathbf{d}$, and instance-specific shape code $\mathbf{z}^{(s)}$ and color code $\mathbf{z}^{(c)}$ to radiance $\mathbf{c}$ and scalar density $\sigma$ [S1]. Unlike standard NeRF or sibling methods that treat all geometry monolithically, this method separates the learning of category-specific geometry (via a shared branch) from instance-specific deviations (via an instance-specific branch), which improves view synthesis quality and allows the model to scale to more instances [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D position $\mathbf{x} \in \mathbb{R}^3$, viewing direction $\mathbf{d} \in \mathbb{R}^3$, shape latent code $\mathbf{z}^{(s)} \in \mathbb{R}^{32}$, color latent code $\mathbf{z}^{(c)} \in \mathbb{R}^{32}$.
*   **Outputs:** Scalar density $\sigma \in \mathbb{R}$, radiance vector $\mathbf{c} \in \mathbb{R}^3$ (RGB).

**Data Structures:**
The network consists of five Multi-Layer Perceptrons (MLPs), all defined as 4-layer deep, 256-channel wide networks with ReLU activations, outputting 256-dimensional features [S1].
1.  $F_{\text{share}}$: Shared shape network.
2.  $F_{\text{inst}}$: Instance-specific shape network.
3.  $F_{\text{fuse}}$: Fusion shape network.
4.  $F_{\text{dens}}$: Output density network (linear layer).
5.  $F_{\text{rad}}$: Output radiance network (two-layer MLP).

**Positional Encoding:**
Inputs $\mathbf{x}$ and $\mathbf{d}$ are transformed using the positional encoding function $\gamma(\cdot)$ as defined in Mildenhall et al. [S1].

**Algorithm Steps:**
1.  **Compute Shared Shape Representation:** Pass the positional encoding of the position, $\gamma(\mathbf{x})$, through the shared shape network $F_{\text{share}}$.
    $$ \mathbf{h}_{\text{share}} = F_{\text{share}}(\gamma(\mathbf{x})) $$
2.  **Compute Instance-Specific Shape Representation:** Concatenate the shape code $\mathbf{z}^{(s)}$ and the positional encoding $\gamma(\mathbf{x})$. Pass this concatenation through the instance-specific shape network $F_{\text{inst}}$.
    $$ \mathbf{h}_{\text{inst}} = F_{\text{inst}}(\text{concat}(\mathbf{z}^{(s)}, \gamma(\mathbf{x}))) $$
3.  **Fuse Representations:** Add the outputs of the shared and instance-specific networks, then pass the sum through the fusion shape network $F_{\text{fuse}}$.
    $$ \mathbf{h}_{\text{fuse}} = F_{\text{fuse}}(\mathbf{h}_{\text{share}} + \mathbf{h}_{\text{inst}}) $$
4.  **Predict Density:** Pass the fused feature $\mathbf{h}_{\text{fuse}}$ through the linear density network $F_{\text{dens}}$ to obtain the scalar density $\sigma$.
    $$ \sigma = F_{\text{dens}}(\mathbf{h}_{\text{fuse}}) $$
5.  **Predict Radiance:** Concatenate the fused feature $\mathbf{h}_{\text{fuse}}$, the color code $\mathbf{z}^{(c)}$, and the encoded viewing direction $\gamma(\mathbf{d})$. Pass this concatenation through the two-layer radiance network $F_{\text{rad}}$ to obtain the radiance $\mathbf{c}$.
    $$ \mathbf{c} = F_{\text{rad}}(\text{concat}(\mathbf{h}_{\text{fuse}}, \mathbf{z}^{(c)}, \gamma(\mathbf{d}))) $$

            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256)
        )
        
        # F_fuse: Input 256 -> 256 -> 256 -> 256 -> 256
        self.F_fuse = nn.Sequential(
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256)

        self.F_rad = nn.Sequential(

            nn.Linear(256, 3)

        h_share = self.F_share(gamma_x)
        
        # 2. Instance-specific shape representation
        # Concatenate shape code z_s and positional encoding gamma(x)
        h_inst_input = torch.cat([z_s, gamma_x], dim=-1)
        h_inst = self.F_inst(h_inst_input)

*   Shape code dimension: 32 [S1].
*   Color code dimension: 32 [S1].

**Edge Cases and Pitfalls:**
*   The method relies on the joint optimization of latent codes via backpropagation [S1]. If the set of training rays is small, caching computations is feasible, but this must be managed to avoid unnecessary computation during optimization [S1].
*   The disentanglement relies on the modular structure; modifying the shared branch affects all instances, while the instance branch affects only the specific instance [S1].

## Operating characteristics
*   **Performance:** On the PhotoShapes dataset, the shared shape branch improves PSNR from 33.91 (model without shared branch) to 35.79 [S1].
*   **Efficiency:** The modular design allows for efficient editing. Acceleration of 3.2× for color edits and 1.9× for shape edits is achieved by only updating relevant network components during the editing phase [S1].
*   **Scalability:** The shared shape branch helps the model scale to more instances compared to models without it [S1].
*   **Limitations:** The method requires learning category-specific geometric representations, which may limit its applicability to highly heterogeneous datasets without a shared category [S1].

## Background
The method was introduced in "Editing Conditional Radiance Fields" (2021) [S1]. It builds on the inductive biases provided by positional encodings and stage-wise network design found in NeRF [45, 70] [S1]. The architecture is designed to facilitate shape and color editing by separating the network into modular parts, allowing specific submodules to be finetuned during the editing process [S1].
