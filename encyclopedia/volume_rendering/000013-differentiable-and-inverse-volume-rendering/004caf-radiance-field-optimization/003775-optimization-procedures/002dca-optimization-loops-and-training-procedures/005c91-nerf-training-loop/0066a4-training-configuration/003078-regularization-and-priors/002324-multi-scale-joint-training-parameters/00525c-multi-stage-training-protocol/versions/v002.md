# Multi-stage Training Protocol

Also called: Pretrain and Joint Train Strategy, Training Scheme

## Overview
This protocol structures the optimization of inverse rendering models into sequential phases to ensure stable convergence of coupled components. It addresses the dependency of lighting estimation on accurate geometry and appearance by decoupling the training of Direct Prediction (geometry/appearance) and Lighting Joint Prediction modules. Unlike end-to-end training which may suffer from gradient conflicts or poor initialization, this method progressively introduces complexity, starting with isolated component training before joint optimization and final refinement.

## How it works
The method optimizes a model comprising three submodules: a Direct Prediction Module ($h_{DP}$) producing albedo ($A$), normal ($N$), and depth ($D$); a Lighting Joint Prediction Module; and a Joint Re-prediction Module. The goal is to recover HDR lighting from LDR images while predicting physically plausible surface properties.

**Inputs:**
- LDR input images.
- Camera poses and intrinsics.
- Initial visible surface volume and VSG lighting grid (resolution $128^3$) [S1].

**Outputs:**
- Predicted albedo ($\hat{A}$), normal ($\hat{N}$), depth ($\hat{D}$), and lighting ($\hat{L}$).
- Intermediate re-predicted albedo ($\tilde{A}$), normal ($\tilde{N}$), and depth ($\tilde{D}$).

**Data Structures:**
- **Direct Prediction Module ($h_{DP}$):** Neural network branches for $A, N, D$.
- **Lighting Joint Prediction Module:** Neural network dependent on outputs of $h_{DP}$.
- **Joint Re-prediction Module:** Neural network for refining $A, N, D$.
- **Lighting Grid:** 3D voxel grid of resolution $128^3$ for VSG lighting [S1].

**Loss Function:**
The multi-task loss $L$ used in joint stages is defined as [S1]:
$$
L = \lambda_A L_{albedo} + \lambda_N L_{normal} + \lambda_D L_{depth} + \lambda_L L_{light} + \lambda_{visible} L_{visible} + \lambda_{reg} L_{reg} + \lambda_{rerender} L_{rerender}
$$
where $\lambda$ terms are weighting hyperparameters.

**Steps:**

1.  **Pretrain Direct Prediction Module:**
    Train only the albedo, normal, and depth branches of $h_{DP}$ using available supervision. This ensures reasonable initial values for the subsequent lighting module, which depends on these properties [S1].

2.  **Joint Train Direct and Lighting Modules:**
    Unfreeze the Lighting Joint Prediction Module. Jointly train $h_{DP}$ and the Lighting Joint Prediction Module using the full multi-task loss $L$ [S1].

3.  **Train Joint Re-prediction Module:**
    Freeze the weights of the Direct Prediction Module and the Lighting Joint Prediction Module. Train only the Joint Re-prediction Module to predict albedo, normals, and depth [S1].

4.  **End-to-End Finetune:**
    Unfreeze all modules. Jointly finetune all three modules end-to-end. The loss is computed on both the joint prediction outputs $(\hat{A}, \hat{N}, \hat{D}, \hat{L})$ and the intermediate re-prediction outputs $(\tilde{A}, \tilde{N}, \tilde{D})$ [S1].

**Pseudocode:**

```python
def multi_stage_training(model, data_loader, hyperparams):
    # model contains: direct_pred_module, lighting_joint_module, joint_repred_module
    
    # Step 1: Pretrain Direct Prediction Module
    # Freeze lighting_joint_module and joint_repred_module
    for epoch in range(pretrain_epochs):
        for batch in data_loader:
            # Forward pass through direct_pred_module only
            A_pred, N_pred, D_pred = model.direct_pred_module(batch)
            
            # Compute loss using only albedo, normal, depth terms from L
            # Note: Specific terms L_albedo, L_normal, L_depth are used
            loss = compute_partial_loss(A_pred, N_pred, D_pred, batch)
            
            # Backpropagate and update direct_pred_module weights
            optimizer_direct.step()
            
    # Step 2: Joint Train Direct and Lighting Modules
    # Unfreeze lighting_joint_module
    # Keep joint_repred_module frozen
    for epoch in range(joint_train_epochs):
        for batch in data_loader:
            # Forward pass
            A_pred, N_pred, D_pred = model.direct_pred_module(batch)
            L_pred = model.lighting_joint_module(A_pred, N_pred, D_pred)
            
            # Compute full multi-task loss L
            loss = hyperparams.lambda_A * L_albedo(A_pred, batch) + \
                   hyperparams.lambda_N * L_normal(N_pred, batch) + \
                   hyperparams.lambda_D * L_depth(D_pred, batch) + \
                   hyperparams.lambda_L * L_light(L_pred, batch) + \
                   hyperparams.lambda_visible * L_visible(batch) + \
                   hyperparams.lambda_reg * L_reg(L_pred) + \
                   hyperparams.lambda_rerender * L_rerender(L_pred, batch)
            
            # Backpropagate and update direct_pred_module and lighting_joint_module weights
            optimizer_joint.step()
            
    # Step 3: Train Joint Re-prediction Module
    # Freeze direct_pred_module and lighting_joint_module
    # Unfreeze joint_repred_module
    for epoch in range(repred_epochs):
        for batch in data_loader:
            # Forward pass through direct_pred_module (frozen)
            A_pred, N_pred, D_pred = model.direct_pred_module(batch)
            
            # Forward pass through joint_repred_module
            A_repred, N_repred, D_repred = model.joint_repred_module(A_pred, N_pred, D_pred)
            
            # Compute loss for re-prediction outputs
            # Specific loss terms for A, N, D re-prediction
            loss = compute_repred_loss(A_repred, N_repred, D_repred, batch)
            
            # Backpropagate and update joint_repred_module weights
            optimizer_repred.step()
            
    # Step 4: End-to-End Finetune
    # Unfreeze all modules
    for epoch in range(finetune_epochs):
        for batch in data_loader:
            # Forward pass
            A_pred, N_pred, D_pred = model.direct_pred_module(batch)
            L_pred = model.lighting_joint_module(A_pred, N_pred, D_pred)
            A_repred, N_repred, D_repred = model.joint_repred_module(A_pred, N_pred, D_pred)
            
            # Compute loss on both joint predictions and intermediate re-predictions
            loss = hyperparams.lambda_A * (L_albedo(A_pred, batch) + L_albedo(A_repred, batch)) + \
                   hyperparams.lambda_N * (L_normal(N_pred, batch) + L_normal(N_repred, batch)) + \
                   hyperparams.lambda_D * (L_depth(D_pred, batch) + L_depth(D_repred, batch)) + \
                   hyperparams.lambda_L * L_light(L_pred, batch) + \
                   hyperparams.lambda_visible * L_visible(batch) + \
                   hyperparams.lambda_reg * L_reg(L_pred) + \
                   hyperparams.lambda_rerender * L_rerender(L_pred, batch)
            
            # Backpropagate and update all weights
            optimizer_all.step()
```

## Subtopics

## Operating characteristics
- **Stability:** Decoupling prevents gradient instability caused by the strong dependency of lighting estimation on geometry/appearance initialization [S1].
- **Convergence:** Progressive training ensures the lighting module receives reasonable inputs, avoiding local minima associated with random initialization [S1].
- **Complexity:** The method requires multiple optimization phases, increasing total training time compared to single-stage training.
- **Hardware:** The lighting grid resolution is fixed at $128^3$ [S1].

## Background
Originated in the context of indoor inverse rendering with 3D spatially-varying lighting. The protocol was introduced to handle the complexity of jointly optimizing geometry, appearance, and lighting from LDR images, enabling the recovery of HDR lighting [S1].
