# Voxel-based Radiance Fields

Also called: Voxel NeRF, Voxel Radiance Fields

## Overview
Voxel-based Radiance Fields replace the multi-layer perceptron (MLP) of standard Neural Radiance Fields with structured voxel grids to store volume density and spherical harmonic (SH) coefficients, enabling memory-efficient training and real-time differentiable volume rendering [S1]. Unlike MLP-based approaches that require heavy feed-forward computation for every sample point, this method computes color and density directly via trilinear interpolation from grid values [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D scene defined by a set of training images with known camera poses.
*   **Output:** Two voxel grids, $G_\sigma$ and $G_{sh}$, and the rendered image $\hat{C}(r)$ for a given ray $r$.

**Data Structures:**
The representation consists of two dense voxel grids defined over the scene domain $\mathbb{R}^3$:
1.  **Density Grid ($G_\sigma$):** A 3D grid mapping spatial coordinates to a scalar value.
    *   Layout: $G_\sigma: \mathbb{R}^3 \rightarrow \mathbb{R}$.
    *   Content: Stores the volume density $\sigma$.
2.  **Spherical Harmonic Grid ($G_{sh}$):** A 3D grid mapping spatial coordinates to a vector of coefficients.
    *   Layout: $G_{sh}: \mathbb{R}^3 \rightarrow \mathbb{R}^{9 \times 3}$.
    *   Content: Stores degree-2 Spherical Harmonic coefficients for RGB color. The dimension $9 \times 3$ corresponds to 9 SH basis functions for each of the 3 color channels (R, G, B) [S1].

**Numbered Steps:**
1.  **Ray Sampling:** For a camera ray $r$, sample $N$ points $\mathbf{X}_k$ along the ray within the scene bounds, with spacing $\delta_k$.
2.  **Density Retrieval:** For each sample point $\mathbf{X}_k$, retrieve the volume density $\sigma_k$ by performing trilinear interpolation on the density grid $G_\sigma$ using the 8 nearest neighboring voxels [S1].
    $$ \sigma_k = \mathcal{G}_\sigma(\mathbf{X}_k) $$
3.  **SH Coefficient Retrieval:** For each sample point $\mathbf{X}_k$, retrieve the degree-2 SH coefficients $\mathbf{v}_k$ by performing trilinear interpolation on the SH grid $G_{sh}$ using the 8 nearest neighboring voxels [S1].
    $$ \mathbf{v}_k = \mathcal{G}_{sh}(\mathbf{X}_k) $$
4.  **Color Computation:** Compute the view-dependent color $\mathbf{c}_k$ by projecting the viewing direction $\mathbf{d}$ into the SH basis and dotting it with the retrieved coefficients [S1].
    $$ \mathbf{c}_k = S(\mathbf{d})^\intercal \cdot \mathbf{v}_k $$
    Where $S(\mathbf{d}): \mathbb{R}^3 \rightarrow \mathbb{R}^9$ is the function mapping the viewing direction $\mathbf{d}$ to the 9 degree-2 Spherical Harmonic basis values [S1].
5.  **Volume Rendering:** Compute the final pixel color $\hat{C}(r)$ using the standard differentiable volume rendering equation [S1]:
    $$ \hat{C}(r) = \sum_{k=1}^{N} w_k \mathbf{c}_k, \quad w_k = T_k \alpha_k, \quad T_k = \prod_{j=1}^{k-1} (1 - \alpha_j) $$
    Where opacity $\alpha_k = 1 - e^{-\sigma_k \delta_k}$ [S1].

**Parameters:**
*   **SH Degree:** Degree 2 is used, resulting in 9 coefficients per channel [S1].
*   **Interpolation:** Trilinear interpolation is used for both grids [S1].

**Edge Cases and Pitfalls:**
*   **Grid Boundaries:** Points outside the voxel grid bounds require clamping or extrapolation strategies not specified in the source [G].
*   **Memory Usage:** Dense voxel grids scale cubically with resolution. The source mentions "coarse-to-fine sparse voxel reconstruction combined with a pruning strategy" for memory-efficient training, but does not detail the specific sparse data structure or pruning algorithm [S1].

## Operating characteristics
*   **Time Complexity:** Rendering is significantly faster than MLP-based NeRF because it eliminates the feed-forward neural network computation. Color is computed via direct interpolation and dot product [S1].
*   **Memory Complexity:** Memory usage is determined by the voxel grid resolution. While more memory-efficient than storing large MLP weights for high-resolution scenes, dense grids still consume significant memory compared to sparse representations [S1].
*   **Strengths:** Real-time volume rendering capability; memory-efficient framework limiting learnable parameters to grid values [S1].
*   **Limitations:** Resolution is limited by voxel grid size; aliasing artifacts may occur at high frequencies if grid resolution is insufficient [G].
*   **When to use:** When real-time rendering is required or when training memory is constrained by MLP size, particularly for tasks like motion blur reconstruction where efficiency is critical [S1].

## Background
Voxel-based Radiance Fields were introduced as a memory-efficient alternative to MLP-based NeRF [S1]. The approach leverages differentiable volume rendering while replacing the neural network with explicit grid structures [S1]. It has been applied to problems such as extreme motion blur reconstruction (ExBluRF) [S1].
