# Mask+SDS with Background Prompt

Also called: Mask+SDS+BGT

## Overview
Mask+SDS with Background Prompt is a score distillation loss modification for NeRF editing that explicitly provides a background description to the diffusion model to guide surrounding content generation [S1]. It addresses the "black hole" artifact—where previously occluded or covered regions develop into undefined voids due to a lack of explicit supervision—by ensuring the diffusion prior understands the context of the environment [S1]. It sets itself apart from standard Mask+SDS by adding semantic context for the surroundings, and from Mask+SDS+CLIP by relying on the diffusion model's text encoder rather than a separate CLIP loss for background filling [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A NeRF radiance field $\Theta$, a text prompt $P_{obj}$ describing the target object, a text prompt $P_{bg}$ describing the background, and a binary mask $M$ indicating the region to be edited (where $M=1$ is the target region, $M=0$ is the background).
*   **Outputs:** Updated NeRF parameters $\Theta$ optimized to render the edited scene.

**Data Structures:**
*   **Prompt:** A single concatenated string $P_{total} = P_{obj} + \text{" in "} + P_{bg}$ (e.g., "a lego man head in leaves") [S1].
*   **Mask:** A binary image $M$ of the same resolution as the rendered view, used to weight the loss [S1].

**Method Steps:**
1.  **Render:** Render an image $I$ from the NeRF $\Theta$ at a random camera pose.
2.  **Construct Prompt:** Combine the object and background prompts into a single text string $P_{total}$ [S1].
3.  **Diffusion Forward:** Add noise $\epsilon \sim \mathcal{N}(0,1)$ at timestep $t$ to the rendered image $I$ to form $x_t = \sqrt{\bar{\alpha}_t} I + \sqrt{1-\bar{\alpha}_t} \epsilon$ [S1].
4.  **Noise Prediction:** Pass $x_t$ and $P_{total}$ to the frozen Stable Diffusion UNet to predict the noise $\hat{\epsilon}$ [S1].
5.  **Compute SDS Loss:** Calculate the standard Score Distillation Sampling (SDS) gradient based on $\hat{\epsilon}$ and $\epsilon$ [S1].
6.  **Apply Masking:** The loss is applied to the unmasked regions to strongly control the background and avoid unwanted content changes, while the masked region is guided by the combined prompt [S1]. The specific weighting function $\omega(t)$ and the diffusion forward process remain foundational as per the parent article [S1].

**Parameters:**
*   **$\lambda_{unmask}$:** Weight for the unmasked region loss (Eq. 14 in [S1]). The sources compare different effects of this value but do not provide a specific default value [S1].

**Edge Cases and Pitfalls:**
*   **Black Holes:** Previously occluded or covered regions develop into black holes (undefined voids) due to a lack of explicit supervision for those areas when using Mask+SDS+BGT alone [S1].
*   **Shape Artifacts:** If only CLIP is used for background filling (Mask+SDS+CLIP), the generated shapes retain artifacts from the original occluded geometry (e.g., petal shapes persisting as hair) [S1].

## Subtopics

### Mask+SDS+CLIP
A variant that removes the background prompt from the diffusion model's text prompt and instead uses CLIP with a background prompt to fill occluded regions [S1]. It provides a view of the unmasked region to CLIP along with a background prompt to supervise and fill the black hole [S1]. While CLIP fills the black hole with reasonable texture, the generated shapes retain artifacts from the original occluded geometry (e.g., petal shapes) [S1].

### Mask+SDS+BGT+CLIP
The final combined editing configuration that uses SDS with a full prompt (object + background) and CLIP with a background prompt on unmasked views [S1]. It sets the diffusion model text prompt to include both object and background (e.g., "object in background") and simultaneously feeds unmasked views to CLIP with the background prompt to supervise the surroundings [S1]. This produces normal shapes and fills black holes with appropriate background material (e.g., green leaves around a blue rose) [S1].

## Operating characteristics
*   **Time Complexity:** Standard SDS complexity, requiring one forward pass through the diffusion model per step [S1].
*   **Memory Complexity:** Standard NeRF and diffusion model memory requirements [S1].
*   **Strengths:** Explicitly guides the diffusion model to generate coherent background content, reducing the likelihood of incoherent artifacts in the surroundings compared to standard Mask+SDS [S1].
*   **Limitations:** The "black hole" artifact in previously covered regions persists if CLIP is not used in conjunction [S1]. The method relies on the diffusion model receiving full-resolution images without mask overlays, which may limit fine-grained pixel-level control over the background compared to mask-based losses [S1].
*   **When to use:** When editing an object in a scene and it is critical that the surrounding background remains semantically consistent and coherent with the new object [S1].
*   **When not to use:** When the background is complex and the diffusion model's text prompt is insufficient to capture the necessary details, or when the black hole artifact is unacceptable without additional CLIP supervision [S1].

## Background
Mask+SDS with Background Prompt was introduced in the paper "RePaint-NeRF: NeRF Editing via Semantic Masks and Diffusion Models" [S1]. The method was developed to address the limitations of standard NeRF editing techniques where occluded regions become undefined. It builds on the RePaint inpainting framework adapted for NeRFs [S1]. The authors observed that simply masking the region and prompting the object led to artifacts in the background or the object itself, leading to the development of the background prompt variant and its combination with CLIP [S1].
