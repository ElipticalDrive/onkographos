# Lifting 2D GAN to 3D Radiance Field

Also called: GAN-to-NeRF Lifting, Lift3D

## Overview
This method distills 3D structural knowledge from a pretrained 2D Generative Adversarial Network (specifically StyleGAN2) into a shared conditional Neural Radiance Field (NeRF) [S1]. It solves the problem of generating photorealistic 3D objects with arbitrary poses for data augmentation in downstream tasks (e.g., autonomous driving perception) by jointly optimizing the NeRF parameters and latent codes [S1]. Unlike naive isolated NeRF reconstruction which fails to capture category priors and is hindered by noisy GAN sampling, this approach uses Generative Latent Optimization (GLO) to learn shared shape and appearance priors across all objects simultaneously [S1].

## How it works

### Inputs and Outputs
**Inputs:**
1.  **Pretrained 2D GAN:** StyleGAN2 trained on a specific category (e.g., LSUN Car) [S1].
2.  **Template Data:** A set of 3D models (e.g., from ShapeNet) rendered under 200 viewpoints to establish pose-latent mappings [S1].
3.  **Ground Truth Masks:** Binary masks for objects, extracted using a segmentation network like PointRend [S1].
4.  **Environment Layout:** 2D images with drivable area annotations, processed via HRNet and Inverse Perspective Mapping (IPM) [S1].

**Outputs:**
1.  **Shared Conditional NeRF ($\Phi_\theta$):** A 3D radiance field representation conditioned on latent codes [S1].
2.  **Optimized Latent Codes ($\hat{Z}$):** A set of latent vectors for each object in the asset bank [S1].
3.  **Synthetic 3D Assets:** Novel views of generated objects with consistent geometry and appearance [S1].

### Data Structures

**1. Disentangled Latent Space ($w^*$):**
The StyleGAN2 latent space $z$ is mapped to an intermediate space $w^* = (w_1^*, ..., w_{16}^*)$ via 16 affine transformations [S1].
*   **Pose Latents ($w_p$):** The first 8 layers ($w_1^* ... w_8^*$) control camera viewpoint/pose [S1].
*   **Shape/Appearance Latents ($w_s$):** The remaining 8 layers ($w_9^* ... w_{16}^*$) control shape, texture, and background [S1].

**2. Tri-Plane NeRF Representation ($\Phi_\theta$):**
The NeRF is represented using three axis-aligned orthogonal feature planes (XY, YZ, XZ) [S1].
*   **Feature Planes:** Generated by a 2D CNN mapping a constant input conditioned on latent code $z$ [S1].
*   **Point Query:** For a 3D point $x \in \mathbb{R}^3$, features are retrieved by projecting $x$ onto the three planes and performing bilinear interpolation [S1].
*   **MLP Head:** The summed feature vector is fed into a single-layer SIREN-based MLP conditioned on $z$ to output density $\sigma$ and color $c$ [S1].

**3. Pose Label ($P$):**
Defined by azimuth $\alpha \in [0, 360^\circ)$ and elevation $\beta \in [0, 20^\circ)$, representing a unit sphere looking at the origin [S1].

### Numbered Steps

1.  **Disentangle StyleGAN2:** Map the input latent code $z$ to $w^*$ using the StyleGAN2 generator's affine layers. Separate $w^*$ into pose latents $w_p$ (first 8 layers) and shape/appearance latents $w_s$ (remaining 8 layers) [S1].
2.  **Obtain Latent-Label Pairs:**
    *   Select a 3D model (e.g., from ShapeNet) [S1].
    *   Render the model under 200 different viewpoints $P$ [S1].
    *   Use optimization-based GAN inversion to find the template latent code corresponding to the rendered image [S1].
    *   Associate the first 8 layers of this template latent with the pose label $P$ [S1].
3.  **Generate 2D Training Data:**
    *   Sample pose latents $w_p$ from the obtained pose-latent pairs [S1].
    *   Sample shape/appearance latents $w_s$ randomly from a Gaussian distribution $\mathcal{N}(0, I)$ [S1].
    *   Combine $w_p$ and $w_s$ to generate 2D images $I$ with associated pose labels $P$ [S1].
    *   Filter out generated objects that fall outside drivable areas by projecting 2D drivable area masks (from HRNet) to Bird's-Eye-View (BEV) via IPM [S1].
4.  **Joint Optimization (GLO):**
    *   Initialize a shared NeRF $\Phi_\theta$ and a set of latent codes $Z$ for all objects in the asset bank [S1].
    *   Minimize the total loss $\mathcal{L}$ with respect to $\theta$ and $Z$ simultaneously [S1].
5.  **Volumetric Rendering:**
    *   For a camera ray $r(t) = o + td$, compute the expected color $C(r)$ [S1]:
        $$ C(r) = \int_{t_n}^{t_f} T(t) \sigma(r(t)) c(r(t), d) dt $$
    *   Compute transmittance $T(t)$:
        $$ T(t) = \exp\left(-\int_{t_n}^{t} \sigma(r(s)) ds\right) $$
    *   $t_n$ and $t_f$ are the nearest and furthest sampling bounds [S1].
6.  **Shadow Generation:** Cast a pre-computed shadow map at the bottom of each object to simulate lighting interactions [S1].
7.  **Binary Mask Prediction:** Extract the foreground mask $\hat{M}$ based on accumulated transmittance at the furthest bound $t_f$ [S1]:
    $$ \hat{M} = \begin{cases} 1 & \text{if } T(t_f) \geq 0.5 \\ 0 & \text{if } T(t_f) < 0.5 \end{cases} $$
8.  **Composition:** Alpha blend the foreground image $I_2$ and background image $I_1$ using the smoothed mask $M$ (smoothed via Gaussian filter) [S1]:
    $$ I_{out} = I_1 \cdot M + I_2 \cdot (1 - M) $$

### Formulas

**Optimization Objective:**
$$ \hat{Z}, \hat{\theta} = \arg \min_{z, \theta} \mathcal{L}(I, \Phi_{\theta}(z, P)) $$
where $\hat{Z}$ is the concatenation of all latent codes, $P$ is the pose label, and $\mathcal{L}$ is the total loss [S1].

**Total Loss:**
$$ \mathcal{L} = \sum_{i=1}^{N} (\mathcal{L}_{RGB} + \lambda_{IoU}\mathcal{L}_{IoU} + \lambda_{perc}\mathcal{L}_{perc}) $$
where $N$ is the number of image pairs, and $\lambda_{IoU}, \lambda_{perc}$ are loss weights [S1].

**Photometric Loss (L1):**
$$ \mathcal{L}_{RGB} = \frac{1}{CHW} |I_i - \Phi_{\theta}(z_i, P_i)| $$
where $C, H, W$ are channel, height, and width dimensions [S1].

**Perceptual Loss:**
$$ \mathcal{L}_{perc} = \frac{1}{CHW} |VGG(I_i) - VGG(\hat{I}_i)| $$
where VGG is a 16-layer network pretrained on ImageNet [S1].

**IoU Loss:**
$$ \mathcal{L}_{IoU} = 1 - \frac{\hat{M} \cap M^*}{\hat{M} \cup M^*} $$
where $\hat{M}$ is the predicted mask and $M^*$ is the ground truth mask from PointRend [S1].

### Parameters and Typical Values
*   **Pose Latent Layers:** First 8 layers of $w^*$ [S1].
*   **Shape/Appearance Latent Layers:** Remaining 8 layers of $w^*$ [S1].
*   **Mask Threshold:** 0.5 (for binary mask prediction) [S1].
*   **Confidence Filter Threshold:** 0.5 (during inference, images with confidence < 0.5 are filtered as noisy) [S1].
*   **Pose Sampling Range:** Azimuth $0-360^\circ$, Elevation $0-20^\circ$ [S1].
*   **Viewpoints per Model:** 200 [S1].
*   **Asset Bank Size:** 1000 different vehicles (each with 200 multi-view images) [S1].
*   **Loss Weights:** $\lambda_{IoU}, \lambda_{perc}$ are hyperparameters; exact values not specified in sources [S1].

### Edge Cases and Pitfalls
*   **Noisy GAN Sampling:** Generated images and pose labels can be noisy or corrupted. This is mitigated by filtering low-confidence images (confidence < 0.5) and using GLO to learn shared priors rather than isolated reconstruction [S1].
*   **Drivable Area Constraints:** Objects must be filtered if they fall outside drivable areas to maintain environmental consistency (e.g., vehicles not appearing inside buildings) [S1].
*   **Boundary Artifacts:** Alpha blending with a Gaussian-filtered mask is required to smooth edges when composing foreground and background [S1].

class TriPlaneNeRF(nn.Module):
    """
    NeRF representation using Tri-Plane feature encoding.
    """
    def __init__(self, latent_dim, feature_dim, hidden_dim):
        super().__init__()
        # 2D CNN to map constant input to three orthogonal feature planes
        # conditioned on latent code z.
        self.feature_extractor = FeatureExtractor(latent_dim, feature_dim)
        # Single-layer SIREN-based MLP conditioned on z
        self.mlp = SIRENMLP(feature_dim * 3, hidden_dim)

    def forward(self, x, z):
        """
        x: (N, 3) 3D points
        z: (N, latent_dim) latent codes
        """
        # Project x onto three planes and retrieve features via bilinear interpolation
        features_xy = self.feature_extractor.get_plane_feature(x, 'xy', z)
        features_yz = self.feature_extractor.get_plane_feature(x, 'yz', z)
        features_xz = self.feature_extractor.get_plane_feature(x, 'xz', z)
        
        # Sum the three feature vectors
        combined_features = features_xy + features_yz + features_xz
        
        # Output density and RGB
        density, color = self.mlp(combined_features, z)
        return density, color

class StyleGAN2Disentangler:
    """
    Disentangles StyleGAN2 latent space into pose and shape components.
    """
    def __init__(self, stylegan2_model):
        self.model = stylegan2_model

    def get_latents(self, z):
        # Map z to w* via 16 affine transformations
        w_star = self.model.mapping(z)
        # First 8 layers are pose latents
        w_p = w_star[:, :8]
        # Remaining 8 layers are shape/appearance latents
        w_s = w_star[:, 8:]
        return w_p, w_s

def generate_training_data(stylegan2_disentangler, num_samples=1000):

    Generates 2D training data by sampling pose and shape latents.

    images = []
    poses = []

        img = stylegan2_disentangler.model.synthesis(w_full)

        images.append(img)
        poses.append(pose)
        
    return images, poses

def compute_volumetric_rendering(ray_o, ray_d, nerf_model, z, t_n, t_f, num_samples=256):
    """
    Renders a single ray using volumetric rendering.
    """
    # Sample points along the ray
    t_vals = torch.linspace(t_n, t_f, num_samples)
    xyz = ray_o.unsqueeze(1) + ray_d.unsqueeze(1) * t_vals.unsqueeze(0)
    
    # Query NeRF for density and color
    density, color = nerf_model(xyz, z)
    
    # Compute transmittance
    # T(t) = exp(-int_{t_n}^{t} sigma(r(s)) ds)
    # Approximated using discrete sum
    deltas = t_vals[1:] - t_vals[:-1]
    alpha = 1 - torch.exp(-density * deltas)
    transmittance = torch.cumprod(torch.exp(-density * deltas), dim=0)
    transmittance = torch.cat([torch.ones_like(transmittance[:, :1]), transmittance], dim=1)
    
    # Compute expected color
    weights = alpha * transmittance
    color_rendered = torch.sum(weights.unsqueeze(-1) * color, dim=0)
    
    # Compute accumulated transmittance at furthest bound for mask
    T_tf = transmittance[-1]
    
    return color_rendered, T_tf

def compute_loss(rendered_img, gt_img, rendered_mask, gt_mask, vgg_model):
    """
    Computes the total loss: Photometric + IoU + Perceptual.
    """
    # Photometric Loss (L1)
    l_rgb = torch.mean(torch.abs(rendered_img - gt_img))
    
    # IoU Loss
    intersection = torch.sum(rendered_mask * gt_mask)
    union = torch.sum(rendered_mask + gt_mask)
    l_iou = 1 - (intersection / (union + 1e-6))
    
    # Perceptual Loss
    vgg_rendered = vgg_model(rendered_img)
    vgg_gt = vgg_model(gt_img)
    l_perc = torch.mean(torch.abs(vgg_rendered - vgg_gt))
    
    # Total Loss
    lambda_iou = 1.0 # Placeholder, should be tuned
    lambda_perc = 1.0 # Placeholder, should be tuned
    total_loss = l_rgb + lambda_iou * l_iou + lambda_perc * l_perc
    
    return total_loss

def train_lifting_3d(stylegan2_model, gt_masks, drivable_areas, asset_bank_size=1000):

    Main training loop for Lifting 2D GAN to 3D Radiance Field.
    """
    # 1. Disentangle StyleGAN2
    disentangler = StyleGAN2Disentangler(stylegan2_model)
    
    # 2. Obtain Latent-Label Pairs (using ShapeNet templates)

    # 4. Initialize Shared NeRF and Latent Codes
    nerf = TriPlaneNeRF(latent_dim=512, feature_dim=64, hidden_dim=256)
    latent_codes = [torch.randn(512) for _ in range(len(images))]
    
    # 5. Joint Optimization (GLO)
    optimizer = torch.optim.Adam(list(nerf.parameters()) + [nn.Parameter(code) for code in latent_codes], lr=1e-4)
    vgg_model = VGG16(pretrained=True)

## Operating characteristics

**Time and Memory Complexity:**
*   **Memory:** The method uses a Tri-Plane representation, which is more memory-efficient than voxel grids or dense point clouds for high-resolution scenes [S1]. The memory usage scales with the number of feature planes and the resolution of the 2D CNN output [S1].
*   **Time:** The joint optimization (GLO) requires simultaneous updates of the NeRF parameters and all latent codes, which can be computationally intensive compared to isolated NeRF reconstruction [S1]. However, the Tri-Plane representation allows for efficient feature querying [S1].

**Measured Performance:**
*   The method was evaluated on KITTI and nuScenes datasets for 3D object detection tasks [S1].
*   It generates high-quality synthetic data that improves the performance of downstream 3D detection models [S1].
*   Qualitative comparisons show superior visual quality compared to GIRAFFE and GIRAFFE HD, especially when increasing depth magnitude [S1].

**Strengths:**
*   **Data Augmentation:** Enables the generation of novel 3D objects with arbitrary poses for training data augmentation [S1].
*   **Shared Priors:** Learns shared shape and appearance priors within a category, mitigating the noise from GAN sampling [S1].
*   **Efficiency:** Uses Tri-Plane representation for efficient 3D feature encoding [S1].
*   **High Quality:** Produces photorealistic images with consistent geometry and appearance [S1].

**Limitations:**
*   **Dependency on 2D GAN:** Relies on the quality of the pretrained 2D GAN (StyleGAN2) [S1].
*   **Noisy Inputs:** Generated images and pose labels can be noisy, requiring filtering and robust optimization [S1].
*   **Environment Constraints:** Requires accurate drivable area annotations to filter out invalid objects [S1].

**When to Use:**
*   When generating large-scale synthetic 3D datasets for training perception models in autonomous driving or robotics [S1].
*   When high-quality, diverse 3D objects with consistent appearance are needed [S1].

**When Not to Use:**
*   When precise geometric accuracy is more important than photorealism [S1].
*   When computational resources are limited for joint optimization [S1].
