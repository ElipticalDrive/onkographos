# CCNeRF
Also called: Compressible-Composable NeRF, Rank-residual Decomposition NeRF

## Overview
CCNeRF is a neural field representation that enables efficient compression and composition of 3D scenes by learning a hybrid tensor rank decomposition of the scene without using neural networks for rendering [S1]. Unlike NeRF variants that rely on a shared MLP renderer (e.g., NSVF) or hybrid tensor-MLP approaches (e.g., TensoRF), CCNeRF models the radiance field *only* with tensor rank decomposition, preserving low-rank approximation properties to allow dynamic model size adjustment via rank truncation and arbitrary composition via rank concatenation [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 2D images with known camera poses $(o, d)$ and corresponding pixel colors.
*   **Output:** A compressed radiance field representation consisting of rank components (vectors or matrices) and a weight matrix, allowing the rendering of novel views via volume rendering [S1].

**Data Structures:**
The model structure consists of two main parts [S1]:
1.  **Rank Components:** A set of decomposed components representing the spatial features. These are either vector-based (CANDECOMP/PARAFAC or CP decomposition) or matrix-based (a triple plane variant). The ratio of vector- to matrix-based components is controllable [S1].
2.  **Weight Matrix:** A matrix storing rank weights for different feature channels [S1].

**Querying a 3D Coordinate:**
To query a 3D coordinate $\mathbf{x}$ for density $\sigma$ and color $\mathbf{c}$ [S1]:
1.  Project the coordinate $\mathbf{x}$ to the decomposed vectors or matrices.
2.  Perform weighted interpolation using the stored rank weights [S1].

**Rank-Residual Learning:**
To encourage the preservation of primary information in lower ranks, a rank-residual learning strategy is employed [S1]. This allows the model to achieve near-optimal low-rank approximation at any targeted rank through an empirical sort-and-truncate strategy, enabling dynamic trade-offs between model size and rendering quality without retraining [S1].

**Composition:**
Different models are composed by concatenating their rank components along the rank dimension [S1]. A transformation matrix is recorded for each object to control its position and orientation in the scene [S1].

**Compression:**
Model size is dynamically adjusted by rank truncation. An empirical sort-and-truncate strategy is used to achieve near-optimal low-rank approximation at any targeted rank [S1].

**Formulas:**
*   **Volume Rendering Equation:**
    $$ \hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i $$
    where $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ is the transmittance, $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ is the opacity, and $\delta_i = t_{i+1} - t_i$ is the distance between samples along ray $\mathbf{r}$ [S1]. Here $\sigma_i$ is density, $\mathbf{c}_i$ is color, and $t_i$ is sample position along ray $\mathbf{r}$ from origin $\mathbf{o}$ with direction $\mathbf{d}$ [S1].

*   **Tucker Decomposition:**
    $$ T_{i,j,k} = \sum_{p=1}^P \sum_{q=1}^Q \sum_{r=1}^R S_{p,q,r} U^x_{i,p} U^y_{j,q} U^z_{k,r} $$
    where $S$ is the core tensor and $U^x, U^y, U^z$ are factor matrices [S1].

**Parameters:**
*   **Rank Truncation:** The number of components kept in the decomposition determines the model size and detail level. Lower ranks preserve primary information due to rank-residual learning [S1].

**Edge Cases and Pitfalls:**
*   Standard truncated HOSVD does not hold the optimal property of truncated SVD, but yields a quasi-optimal solution sufficient for practical use [S1].

## Operating characteristics
*   **Time and Memory Complexity:** The model size can be dynamically adjusted by rank truncation, allowing for compression [S1]. The exact complexity depends on the rank and the number of components [S1].
*   **Measured Performance:** The method achieves comparable rendering quality to state-of-the-art methods while enabling extra capability of compression and composition [S1].
*   **Scaling:** Model size growth in composed scenes can be mitigated by compressing unimportant objects [S1].
*   **Strengths:** No neural networks for rendering, allowing arbitrary composition without retraining or compatibility constraints [S1]. Dynamic adjustment of model size via rank truncation [S1].
*   **Limitations:** Standard truncated HOSVD is quasi-optimal, not optimal [S1].
*   **When to use:** When efficient manipulation (compression and composition) of 3D scenes is required without the overhead of neural network rendering [S1].
*   **When not to use:** When optimal low-rank approximation is strictly required, as truncated HOSVD is only quasi-optimal [S1].

## Background
CCNeRF was introduced by Jiaxiang Tang, Xiaokang Chen, Jingbo Wang, and Gang Zeng from Peking University and Chinese University of Hong Kong [S1]. It was presented in the paper "Compressible-Composable NeRF via Rank-residual Decomposition" in October 2022 [S1]. The method addresses the difficulty in manipulating NeRF models, which are typically restricted by shared renderer networks or suffer from large model sizes [S1]. It builds on the low-rank approximation property of the SVD algorithm and tensor decomposition techniques [S1].
