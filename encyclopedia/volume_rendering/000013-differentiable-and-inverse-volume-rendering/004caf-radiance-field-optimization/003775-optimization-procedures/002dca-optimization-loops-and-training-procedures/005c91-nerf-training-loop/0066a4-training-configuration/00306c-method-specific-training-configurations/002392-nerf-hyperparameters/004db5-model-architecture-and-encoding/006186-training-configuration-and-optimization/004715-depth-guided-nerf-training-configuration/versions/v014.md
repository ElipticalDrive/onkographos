# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the hyperparameters, architectural modifications, and optimization settings for training a Neural Radiance Field (NeRF) model using depth priors to improve reconstruction quality [S1]. It builds on [Model Architecture and Encoding](13550-model-architecture-and-encoding.md) by integrating a depth supervision loss and specific regularization techniques. It is distinguished from sibling methods like [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md) by its explicit use of Earth Mover’s Distance (EMD) or standard depth losses rather than semantic or generative constraints, and from [Binary Radiance Fields](13622-binary-radiance-fields.md) by its continuous density representation [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Multi-view RGB images, camera poses, and ground truth depth maps (where available).
*   **Outputs:** A trained NeRF model (MLPs for density and color) capable of rendering novel views and predicting depth.

**Data Structures:**
The model architecture follows the standard NeRF MLP structure [Parent], with the following specific modifications:
*   **Density Network:** A series of fully connected layers. After each of the first eight fully connected ReLU-activated layers that encode the positional encoding, a dropout layer is added [S1].
*   **Depth Scale:** A learnable parameter or network output used to scale depth predictions, optimized with a specific learning rate [S1].

**Numbered Steps:**
1.  **Initialization:** Initialize the NeRF MLPs. Set the depth scale learning rate to $1 \times 10^{-7}$ [S1].
2.  **Sampling:** Sample rays through the scene. For each ray, sample points along the ray and query the density and color networks [Parent].
3.  **Rendering:** Compute the rendered color $\mathbf{c}$ and expected depth $\hat{d}$ using volume rendering equations [Parent].
4.  **Uncertainty Thresholding:** Calculate a threshold $\tau$ to evaluate the uncertainty of the depth map. The threshold is defined as:
    $$ \tau = (\text{max\_depth} - \text{min\_depth}) \cdot 0.0001 $$
    For ScanNet, $\text{max\_depth} = 10$ and $\text{min\_depth} = 0.001$ [S1].
5.  **Loss Calculation:** Compute the total loss, which includes the color loss and the depth loss. The depth loss is weighted by $\lambda$. The uncertainty weight $\gamma$ is set to 1 [S1].
6.  **Optimization:** Update the network weights using the Adam optimizer [S1].

**Formulas:**
*   **Depth Evaluation Metrics:**
    *   RMSE: $\text{RMSE}(d, \hat{d}) = \sqrt{\frac{1}{K} \sum_{k=1,...,K} (d_k - \hat{d}_k)^2}$ [S1]
    *   Log RMSE: $\text{RMSE}_{\log}(d, \hat{d}) = \sqrt{\frac{1}{K} \sum_{k=1,...,K} (\log d_k - \log \hat{d}_k)^2}$ [S1]
    *   AbsRel: $\text{AbsRel}(d, \hat{d}) = \frac{1}{K} \sum_{k=1,...,K} \frac{|d_k - \hat{d}_k|}{d_k}$ [S1]
    *   SqRel: $\text{SqRel}(d, \hat{d}) = \frac{1}{K} \sum_{k=1,...,K} \frac{(d_k - \hat{d}_k)^2}{d_k}$ [S1]
    Where $K$ is the number of pixels with valid ground truth depth [S1].

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Initial Learning Rate:** $5 \times 10^{-4}$ [S1].
*   **Learning Rate Schedule:** Reduce to $5 \times 10^{-5}$ after 80% of total steps [S1].
*   **Weight Decay:** $1 \times 10^{-6}$ [S1].
*   **Depth Loss Weight ($\lambda$):** $0.007$ for all scenes except scene 710, where it is $0.02$ [S1].
*   **Uncertainty Weight ($\gamma$):** $1$ [S1].
*   **Depth Scale Learning Rate:** $1 \times 10^{-7}$ [S1].
*   **Total Training Steps:** 500,000 [S1].
*   **Dropout Probability:** 0.1 [S1].

**Pseudocode:**
```python
def train_depth_guided_nerf(model, optimizer, data_loader, config):
    # config contains: lr, lr_schedule_step, lr_schedule_factor, weight_decay, 
    # depth_loss_weight, total_steps, dropout_prob, depth_scale_lr
    
    model.train()
    optimizer = Adam(model.parameters(), lr=config['lr'], weight_decay=config['weight_decay'])
    
    # Separate optimizer for depth scale if it is a distinct parameter
    if 'depth_scale' in model.parameters():
        optimizer_depth = Adam([model.depth_scale], lr=config['depth_scale_lr'])
    else:
        optimizer_depth = None

    for step in range(config['total_steps']):
        # Learning rate schedule
        if step > config['total_steps'] * 0.8:
            for param_group in optimizer.param_groups:
                param_group['lr'] = config['lr_schedule_factor']
            if optimizer_depth:
                # Depth scale LR is constant or scaled separately if specified
                pass 

        batch = next(data_loader)
        images, poses, depths = batch
        
        # Forward pass
        rendered_colors, rendered_depths = model(poses)
        
        # Compute Color Loss (e.g., L1 or L2)
        color_loss = compute_color_loss(rendered_colors, images)
        
        # Compute Depth Loss
        # Apply thresholding for uncertainty if required by specific variant
        # For standard implementation in [S1]:
        depth_loss = compute_depth_loss(rendered_depths, depths)
        
        # Total Loss
        lambda_d = config['depth_loss_weight']
        # Handle scene-specific lambda if needed
        if scene_id == 710:
            lambda_d = 0.02
            
        total_loss = color_loss + lambda_d * depth_loss
        
        # Backward pass
        optimizer.zero_grad()
        if optimizer_depth:
            optimizer_depth.zero_grad()
            
        total_loss.backward()
        optimizer.step()
        if optimizer_depth:
            optimizer_depth.step()

def compute_depth_loss(rendered_depth, gt_depth):
    # Standard L1 or L2 loss on valid pixels
    # Valid pixels are those where gt_depth > 0 and within bounds
    mask = (gt_depth > 0) & (gt_depth < 100) # Example bounds
    valid_rendered = rendered_depth[mask]
    valid_gt = gt_depth[mask]
    return torch.mean((valid_rendered - valid_gt) ** 2)
```

**Edge Cases and Pitfalls:**
*   **Scene 710:** Requires a higher depth loss weight ($\lambda = 0.02$) compared to other scenes ($\lambda = 0.007$) [S1].
*   **Threshold Calculation:** The uncertainty threshold $\tau$ depends on the scene's depth range. For ScanNet, specific min/max values are used [S1].
*   **Overfitting:** In some variants (e.g., DS-NeRF on DTU), the original publication results could not be reproduced with the official code base, suggesting potential architectural tricks like reduced positional encoding frequency were used to prevent overfitting [S2].

## Subtopics

### DS-NeRF Depth Loss Integration
Integrates the depth loss from the DS-NeRF official code base into the training pipeline [S2]. When evaluating on LLFF, results must be re-trained on specific train/test splits because the original publication used a different split [S2]. For DTU, results from the publication are reported directly because the official code base lacks configuration files and cannot reproduce the results [S2].

## Operating characteristics
*   **Time Complexity:** Training requires 500,000 steps [S1]. The exact time per step depends on the scene complexity and hardware, but the use of dropout and depth loss adds minimal overhead compared to standard NeRF.
*   **Memory Complexity:** Standard NeRF memory usage plus storage for depth maps [S1].
*   **Strengths:** Improves depth accuracy and potentially geometry reconstruction by leveraging ground truth depth priors [S1].
*   **Limitations:** Requires ground truth depth maps for training. Performance may vary across scenes (e.g., scene 710 requires different hyperparameters) [S1]. Reproduction of results can be difficult if configuration files are missing (e.g., DTU in DS-NeRF) [S2].
*   **When to use:** When depth accuracy is critical and ground truth depth is available.
*   **When not to use:** When depth priors are unavailable or unreliable.

## Background
This configuration is based on the "Depth-Guided NeRF" method, which incorporates depth supervision into the NeRF training process [S1]. The specific hyperparameters and architectural modifications (dropout, Adam settings) are detailed in the associated publication [S1]. The integration of DS-NeRF's depth loss highlights the community's effort to improve depth estimation in NeRFs [S2].
