# NeRF with Time Parameter

Also called: NeRF + time, NeRF with Time Parameter Baseline, Time-NeRF

## Overview
This method adapts the standard NeRF architecture [Parent](3065-nerf-hyperparameters.md) for dynamic scenes by introducing a temporal dimension to the input space. It solves the problem of static scene representation by allowing the neural radiance field to vary over time. Unlike sibling methods such as [Gear-NeRF](13848-gear-nerf.md) or [KFD-NeRF](15551-kfd-nerf.md) which employ complex structural changes or explicit motion fields, this approach relies solely on input expansion. While it improves upon vanilla NeRF, it lacks detailed dynamic reasoning and produces blurry predictions [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Spatial position $\mathbf{x} \in \mathbb{R}^3$, view direction $\mathbf{d} \in \mathbb{R}^3$, and time parameter $t \in \mathbb{R}$.
*   **Outputs:** Volume density $\sigma$ and color $\mathbf{c}$, conditioned on $t$.

**Data Structures:**
The model consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network, following the standard NeRF structure [Parent](3065-nerf-hyperparameters.md). The weight matrices and biases are modified to accept the concatenated positional encoding of space and time.

**Positional Encoding:**
The time parameter $t$ is positionally encoded using the same scheme as spatial coordinates. The combined positional encoding $\gamma(\mathbf{x}, t)$ is defined as:
$$
\gamma(\mathbf{x}, t) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x}), t, \sin(2^{d_1}\pi t), \cos(2^{d_1}\pi t), \dots, \sin(2^{d_2-1}\pi t), \cos(2^{d_2-1}\pi t)]
$$
where $d_1$ and $d_2$ define the frequency bands [Parent](3065-nerf-hyperparameters.md).

**Algorithm Steps:**
1.  **Sampling:** For a given ray $r$ and time $t$, sample points $\mathbf{x}_i$ along the ray.
2.  **Encoding:** Compute $\gamma(\mathbf{x}_i, t)$ for each point.
3.  **Coarse Network:** Pass $\gamma(\mathbf{x}_i, t)$ to the coarse MLP to obtain latent feature $\mathbf{h}_i$ and density $\sigma_i$.
4.  **Fine Network:** Pass $\mathbf{h}_i$, $\gamma(\mathbf{x}_i, t)$, and $\gamma(\mathbf{d})$ to the fine MLP to obtain color $\mathbf{c}_i$.
5.  **Rendering:** Compute the rendered color $\hat{C}(r)$ using standard volume rendering integration with transmittance $T_i$ and opacity $\alpha_i$ [Parent](3065-nerf-hyperparameters.md).

**Parameters:**
*   Training configuration: Uses the same hyperparameters reported for NeRF's real forward-facing experiments [S1].

**Edge Cases and Pitfalls:**
*   **Blurriness:** The method suffers from blurry predictions and lacks detail in complex dynamic scenes [S1].
*   **Dynamic Reasoning:** It fails to explicitly reason about scene dynamics, leading to artifacts when camera poses change significantly across frames [S1].

## Subtopics

### Temporal Compression of NeRF Models
A compression strategy for sequences of NeRF models that exploits temporal redundancy by treating the first model as a key-frame and compressing only the deltas between successive models [S2].
*   **Definition:** Neighboring NeRF models share considerable similarities. This method treats the first model as a "key-frame" or "I-frame" and compresses only the deltas between successive models [S2].
*   **Training Strategy:** Each NeRF is initialized based on the previous frame’s NeRF, except for the first frame’s NeRF, which is trained from scratch. This encourages temporal redundancy and saves training time [S2].
*   **Compression Steps:**
    1.  Initialize the NeRF for the first frame from scratch [S2].
    2.  For subsequent frames, initialize the new NeRF based on the previous frame's trained NeRF [S2].
    3.  Calculate the delta between the current frame's NeRF weights and the previous frame's NeRF weights [S2].
    4.  Apply exponent-based quantization and Huffman coding to the deltas [S2].
*   **Decoding:** To restore a model, accumulate the decoded deltas to the reference model (the previous frame's model) [S2].

## Operating characteristics
*   **Performance:** Improves quality over vanilla NeRF but still lacks detail and suffers from blurry predictions [S1].
*   **Limitations:** Fails to reason about scene dynamics effectively [S1].
*   **Complexity:** Time and memory complexity are similar to standard NeRF, scaled by the number of time steps if multiple models are stored, or constant if a single time-conditioned model is used.
*   **When to use:** When a simple baseline for dynamic scenes is required and computational resources for complex dynamic NeRF variants are limited.
*   **When not to use:** For scenes with complex, non-rigid dynamics where high fidelity and sharp details are required.

## Background
This method was introduced as a baseline modification to adapt Static Scene Representations (SRNs) and NeRF for dynamic scenes [S1]. It was proposed in the context of comparing against Neural Scene Graphs for Dynamic Scenes [S1]. The approach highlights the limitations of simple input expansion for dynamic scene representation, motivating more complex methods like scene graphs [S1].
