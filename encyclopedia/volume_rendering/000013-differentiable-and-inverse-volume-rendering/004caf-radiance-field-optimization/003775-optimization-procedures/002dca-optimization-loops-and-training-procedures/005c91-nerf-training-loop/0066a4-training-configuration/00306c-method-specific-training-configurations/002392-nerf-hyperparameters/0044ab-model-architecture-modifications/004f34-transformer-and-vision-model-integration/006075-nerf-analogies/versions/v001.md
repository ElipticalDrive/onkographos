# NeRF Analogies

Also called: Example-Based Visual Attribute Transfer, NeRF Analogies: Example-Based Visual Attribute Transfer

## Overview
NeRF Analogies is a method for transferring visual appearance attributes from a source NeRF to a target NeRF by establishing dense semantic correspondences using Vision Transformer (ViT) features [S1]. It solves the problem of style or texture transfer in 3D scenes by creating a "NeRF analogy" where the target object adopts the visual characteristics of the source while maintaining its own geometry [S1]. It differs from sibling methods like [ViT-NeRF](13878-vit-nerf.md) and [VisionNeRF](13885-visionnerf.md) by focusing on cross-scene attribute transfer via semantic matching rather than single-scene feature encoding or reconstruction [S1].

## How it works
**Inputs:**
1.  Source NeRF: A trained neural radiance field representing the source object/scene.
2.  Target NeRF: A trained neural radiance field representing the target object/scene (geometry only, or with initial appearance).
3.  Source Images: A set of images of the source object.
4.  Target Images: A set of images of the target object.

**Outputs:**
1.  Transformed Target NeRF: A NeRF where the appearance (color/texture) has been transferred from the source, guided by semantic correspondences.

**Data Structures:**
*   **Feature Map:** A 2D tensor of shape $H \times W \times D$, where $H, W$ are spatial dimensions and $D$ is the feature dimension (384 for DiNO-ViT-8B).
*   **NeRF MLP:** A fully connected network.
    *   Layers 1-8: 256 neurons each.
    *   Layer 9: 128 neurons.
    *   Output Layer: 3 or 4 channels (RGB or RGB+A), activated by Sigmoid.

**Algorithm Steps:**

1.  **Feature Extraction:**
    *   For each source and target image, extract dense semantic features using DiNO-ViT with a ViT-8B backbone [S1].
    *   Use a patch size of 8 and a stride of 4 pixels [S1].
    *   To increase spatial resolution and handle overlapping patches, query the ViT on four translated versions of the image: translations by $(-1, 0)$, $(0, -1)$, $(-1, -1)$, and $(0, 0)$ relative to the original [S1].
    *   Aggregate these features to produce a high-resolution feature map. For 400p images, the resulting feature map resolution is $392 \times 392$ with 384 features per pixel [S1].
    *   Use the output of the deepest (11th) attention layer, specifically the **key-component** of the attention maps, as the feature representation [S1].

2.  **Correspondence Mapping:**
    *   For a given pixel $p_t$ in a target image, find the corresponding pixel $p_s$ in a source image by computing the cosine similarity between their feature vectors $F_t(p_t)$ and $F_s(p_s)$ [S1].
    *   The correspondence is established by maximizing this semantic similarity [S1].

3.  **NeRF Training with Analogy Loss:**
    *   Initialize the Target NeRF using a standard architecture: an MLP with 8 layers of 256 neurons, followed by a layer of 128 neurons, and an output layer with Sigmoid activation [S1].
    *   Sample rays through the Target NeRF.
    *   Compute the rendering color $C_{rendered}$ for each ray.
    *   Compute the **Color Loss** ($\mathcal{L}_c$) between $C_{rendered}$ and the ground truth target image color [S1].
    *   Compute the **DoG Loss** ($\mathcal{L}_G$) to enforce structural consistency based on the semantic correspondences. The DoG (Difference of Gaussians) loss encourages the gradient of the rendered image to match the gradient of the source image at corresponding semantic locations [S1].
    *   Compute the total loss:
        $$ \mathcal{L} = \mathcal{L}_c + \lambda \mathcal{L}_G $$
        where $\lambda$ is a weighting factor [S1].
    *   Optimize the Target NeRF parameters using the Adam optimizer [S1].

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $1 \times 10^{-4}$ [S1].
*   **Batch Size:** 512 [S1].
*   **Loss Weight $\lambda$:** Set to 0 for the first 20,000 iterations. Then, gradually fade in, increasing up to a maximum of 50 [S1].
*   **Total Training Iterations:** 60,000 [S1].
*   **ViT Backbone:** DiNO-ViT-8B [S1].
*   **Feature Dimension:** 384 [S1].

    """
    Computes the DoG loss between the gradient of the rendered image

**Edge Cases and Pitfalls:**
*   **Noisy Correspondences:** DiNO features can produce noisy correspondences where two points on the target mesh map to different points in the source NeRF. The L1 loss in the DoG term helps alleviate this by encouraging sparsity [S1].
*   **Feature Granularity:** Using DiNO-v2 is not recommended as it uses a larger patch size, resulting in coarser feature granularity unsuitable for pixel-level dense correspondences [S1].
*   **Semantic vs. Geometric:** The method relies on semantic similarity, not geometric similarity. It can transfer appearance to semantically unrelated but similarly shaped objects (e.g., avocado to armchair), though results may be less plausible [S1].

## Operating characteristics
*   **Time Complexity:** Training is fast, taking less than two hours on a single GPU, including feature extraction [S1].
*   **Memory Complexity:** Depends on the resolution of the feature maps. For 400p images, feature maps are $392 \times 392 \times 384$ [S1].
*   **Performance:** Evaluated using NeRFStudio Instant-NGP for real-world scenes [S1].
*   **Strengths:** Fast training, effective semantic transfer, works with standard NeRF architectures.
*   **Limitations:** Relies on the quality of ViT features; may struggle with large semantic discrepancies; DoG loss requires careful tuning of $\lambda$ [S1].
*   **When to use:** When you want to transfer texture/style from one 3D object to another while preserving the target's geometry.
*   **When not to use:** When geometric editing is required, or when semantic correspondence is ambiguous.

## Background
NeRF Analogies was introduced by Michael Fischer, Zhengqin Li, Thu Nguyen-Phuoc, Aljaž Božič, Zhao Dong, Carl Marshall, and Tobias Ritschel from University College London and Meta Reality Labs [S1]. The method was published in 2022 (CVPR 2024 proceedings) [S1]. It builds on the idea of using Vision Transformers for dense semantic correspondence, extending it to the 3D radiance field domain [S1].
