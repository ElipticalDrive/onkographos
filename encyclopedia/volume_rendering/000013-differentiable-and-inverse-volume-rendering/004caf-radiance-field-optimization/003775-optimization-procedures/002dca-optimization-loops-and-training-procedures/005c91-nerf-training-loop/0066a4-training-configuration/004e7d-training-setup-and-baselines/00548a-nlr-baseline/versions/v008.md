# NLR Baseline

Also called: Neural Lumigraph Representation, NLR

## Overview
The NLR Baseline is a method for novel view synthesis that represents a scene as a collection of neural radiance fields associated with specific camera viewpoints, rather than a single global field. It solves the problem of efficient rendering and training by leveraging the spatial coherence of light fields. Unlike global NeRF approaches, NLR learns a separate color and shape network for each input view, allowing for rapid convergence on specific scenes. It is distinguished from [NeRF-GT Baseline Training Setup](11349-nerf-gt-baseline-training-setup.md) by its per-view representation and from [NeRF Training Setup](13271-nerf-training-setup.md) by its specific architecture designed for light-field-like data.

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ calibrated images with known camera poses. Each image has resolution $W \times H$.
*   **Outputs:** A set of learned parameters for shape and color networks, one pair per input view, enabling rendering of novel views via interpolation.

**Data Structures:**
For each view $i \in \{1, \dots, N\}$:
*   **Shape Network ($\Phi_i$):** A small MLP that maps 3D coordinates to a scalar depth value or occupancy.
*   **Color Network ($\Psi_i$):** A small MLP that maps 3D coordinates and viewing direction to an RGB color value.
*   **Parameters:** Weights and biases for $\Phi_i$ and $\Psi_i$.

**Steps:**
1.  **Initialization:** Initialize $\Phi_i$ and $\Psi_i$ for each view $i$.
2.  **Ray Sampling:** For each training image, generate rays from the camera center through each pixel.
3.  **Sampling:** Sample points along each ray. The depth of points is determined by the shape network $\Phi_i$ of the source view $i$.
4.  **Color Prediction:** For each sampled point, compute the color using the color network $\Psi_i$ of the source view $i$, conditioned on the point's 3D position and the viewing direction.
5.  **Volume Rendering:** Composite the colors and densities along the ray to produce the final pixel color for the training image.
6.  **Loss Computation:** Compute the Mean Squared Error (MSE) between the rendered image and the ground truth training image.
7.  **Optimization:** Update the parameters of $\Phi_i$ and $\Psi_i$ using gradient descent (typically Adam) to minimize the loss.

**Parameters:**
*   **Learning Rate:** Not explicitly given in the baseline description, but standard Adam parameters are assumed.
*   **Iterations:** Training proceeds until convergence.

**Edge Cases:**
*   **Occlusion:** NLR handles occlusion implicitly through the per-view shape networks. If a point is occluded in view $i$, the shape network $\Phi_i$ will not sample it, or the density will be low.
*   **Precision:** Standard floating-point precision is used.

**Pseudocode:**
```python
# Pseudocode for NLR Baseline training step
# Inputs: images, poses, shape_networks, color_networks
# Outputs: updated shape_networks, color_networks

for each view i in views:
    for each ray in rays_from_view(i):
        # Sample points along the ray based on shape network of view i
        points = sample_points(ray, shape_networks[i])
        
        # Get viewing direction
        direction = ray.direction
        
        # Compute colors using color network of view i
        colors = []
        for point in points:
            color = color_networks[i](point, direction)
            colors.append(color)
            
        # Composite colors to get rendered pixel value
        rendered_color = volume_render(points, colors, ray)
        
        # Compute loss against ground truth
        gt_color = ground_truth_pixel(i, ray.pixel)
        loss = mse(rendered_color, gt_color)
        
        # Update networks
        update(shape_networks[i], loss)
        update(color_networks[i], loss)
```

## Subtopics

### MetaNLR Baseline
MetaNLR extends NLR by using the Reptile meta-learning algorithm to learn a better initialization for the shape and color networks [S1, unofficial]. This allows for faster specialization to new test scenes with fewer gradient steps. The meta-learning rate is set to $5 \times 10^{-2}$ [S1, unofficial]. It is chosen when rapid adaptation to novel scenes is required.

## Operating characteristics
*   **Time Complexity:** Training time is approximately 2.21 seconds per iteration [S1, unofficial]. Rendering time is 0.025 seconds per frame [S1, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Fast rendering; efficient training for specific scenes.
*   **Limitations:** Requires calibrated input images; less flexible for unstructured data compared to global NeRF.
*   **When to use:** When high-quality novel view synthesis is needed for a set of calibrated images and fast rendering is critical.

## Background
NLR was introduced in the paper "Neural Lumigraph Representations" [S1, unofficial]. It builds on the concept of lumigraph representations by using neural networks to model the radiance field.
