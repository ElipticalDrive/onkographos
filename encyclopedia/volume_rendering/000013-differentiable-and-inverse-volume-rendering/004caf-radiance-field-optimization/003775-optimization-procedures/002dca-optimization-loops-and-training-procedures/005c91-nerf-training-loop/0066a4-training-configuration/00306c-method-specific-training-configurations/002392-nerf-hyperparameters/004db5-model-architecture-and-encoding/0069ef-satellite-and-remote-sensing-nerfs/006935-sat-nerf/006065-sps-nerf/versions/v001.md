# SpS-NeRF

Also called: SparseSat-NeRF

## Overview
SpS-NeRF is a variant of NeRF adapted for sparse single-date satellite imagery that employs dense depth supervision guided by a cross-correlation similarity metric from traditional semi-global MVS (SGM) matching [S1]. It extends Sat-NeRF to enable novel view generation and 3D geometry reconstruction from sparse satellite views by jointly optimizing RGB and depth losses, using uncertainty metrics from SGM correlation maps to robustify the supervision [S1]. Unlike methods relying on learning-based depth prediction networks for indoor scenes, SpS-NeRF leverages traditional SGM, which is sufficient for satellite scenarios and avoids the need for ground truth depth maps for training [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ synchronous satellite images with known camera poses. Dense depth maps and cross-correlation maps are pre-computed for each input image using Semi-Global Matching (SGM) on images downsampled by a factor of 4 [S1].
*   **Outputs:** A radiance field model $F_\Theta$ capable of rendering novel views and a refined digital surface model (DSM) [S1].

**Data Structures:**
*   **Radiance Field $F_\Theta$:** A fully-connected neural network (MLP) mapping 3D coordinates and viewing directions to color and density, following the standard NeRF architecture [S1].
*   **SGM Maps:** For each view, a depth map $D$ and a correlation map $C_{corr}$ are stored. The depth map is incomplete due to occlusions and has lower precision (4x Ground Sample Distance) [S1].

**Parameters:**
*   **Ray Sampling:** Guided ray sampling is used, borrowed from Roessle et al. (2022) [S1].
*   **Uncertainty Margin ($m$):** A threshold defining the acceptable deviation from the input depth [S1].
*   **Correlation Weight ($corr(r)$):** A value derived from the SGM cross-correlation map for ray $r$, used to weight the loss [S1].

**Numbered Steps:**

1.  **Initialization:** Initialize the radiance field network $F_\Theta$. Pre-compute dense depth maps and SGM cross-correlation maps for all input images using SGM on downsampled (1/4 resolution) images [S1].
2.  **Ray Sampling:** For each pixel in a training image, cast a ray $r$. Use guided ray sampling to select query points along the ray, prioritizing regions near the input depth estimate [S1].
3.  **Forward Pass:** Query $F_\Theta$ at the sampled points $x_i$ to obtain density $\sigma_i$ and color $c_i$. Compute the accumulated opacity $\alpha_i$ and transmittance $T_i$ [S1]:
    $$ \alpha_i = 1 - e^{-\sigma_i \delta_i} $$
    $$ T_i = \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    where $\delta_i = t_{i+1} - t_i$ is the distance between adjacent query points [S1].
4.  **Color Rendering:** Compute the rendered color $C(r)$ for the ray [S1]:
    $$ C(r) = \sum_{i=1}^{N} T_i \alpha_i c_i $$
5.  **Depth Estimation:** Estimate the rendered depth $D_{pred}(r)$ from the sampled points and their densities [S1].
6.  **Uncertainty Calculation:** Calculate the uncertainty metric $corr(r)$ for the ray based on the SGM cross-correlation map corresponding to the pixel [S1].
7.  **Loss Computation:** Compute the total loss as a combination of color loss and depth loss [S1]:
    *   **Color Loss:** Standard $L_1$ or $L_2$ loss between rendered color $C(r)$ and ground truth color [S1].
    *   **Depth Loss:** The depth loss is weighted and gated by the uncertainty metric [S1]:
        $$ L_{depth} = corr(r) \cdot \max(0, |D_{pred}(r) - D_{input}(r)| - m) $$
        Where $D_{input}(r)$ is the input depth from SGM, and $m$ is the margin [S1].
    *   **Total Loss:**
        $$ L = L_{color} + \lambda \cdot L_{depth} $$
        Where $\lambda$ is a weighting factor [S1].
8.  **Optimization:** Update $F_\Theta$ using gradient descent to minimize the total loss [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import numpy as np

class SpSNeRF:
    def __init__(self, network, sgm_depths, sgm_correlations, margin=0.5, lambda_depth=1.0):
        """
        Initialize SpS-NeRF.
        
        Args:
            network: The radiance field MLP F_Theta.
            sgm_depths: Dictionary mapping image_id to dense depth map (downsampled 4x).
            sgm_correlations: Dictionary mapping image_id to SGM cross-correlation map.
            margin: The uncertainty margin m for depth loss gating.
            lambda_depth: Weight for the depth loss term.
        """
        self.network = network
        self.sgm_depths = sgm_depths
        self.sgm_correlations = sgm_correlations
        self.margin = margin
        self.lambda_depth = lambda_depth
        self.optimizer = torch.optim.Adam(network.parameters(), lr=5e-4)

    def render_ray(self, ray_o, ray_d, num_samples):
        """
        Render a single ray using the radiance field.
        
        Args:
            ray_o: Origin of the ray (3,).
            ray_d: Direction of the ray (3,).
            num_samples: Number of query points along the ray.
            
        Returns:
            rendered_color: Rendered color (3,).
            rendered_depth: Estimated depth (scalar).
            sampled_points: Query points (num_samples, 3).
            sampled_alphas: Opacity of each point (num_samples,).
        """
        # Generate query points along the ray
        # Note: In practice, this involves stratified sampling or guided sampling
        # Borrowed from Roessle et al. (2022) as per [S1]
        t_vals = torch.linspace(0.0, 1.0, num_samples)
        points = ray_o.unsqueeze(0) + ray_d.unsqueeze(0) * t_vals.unsqueeze(1).unsqueeze(2)
        
        # Query network for sigma and color
        # F_Theta expects (x, y, z, dx, dy, dz)
        directions = ray_d.unsqueeze(0).expand_as(points)
        sigma, color = self.network(points, directions)
        
        # Compute alphas
        # delta is distance between points. Assuming uniform spacing for simplicity
        # In guided sampling, delta might vary
        delta = 1.0 / num_samples 
        alphas = 1.0 - torch.exp(-sigma * delta)
        
        # Compute transmittance
        # T_i = product(1 - alpha_j) for j < i
        transmittance = torch.cumprod(1.0 - alphas + 1e-10, dim=0)
        transmittance = torch.roll(transmittance, 1)
        transmittance[0] = 1.0
        
        # Render color
        weights = alphas * transmittance
        rendered_color = torch.sum(weights.unsqueeze(2) * color, dim=0)
        
        # Render depth (expected depth)
        rendered_depth = torch.sum(weights * t_vals, dim=0)
        
        return rendered_color, rendered_depth, points, alphas

    def compute_loss(self, rendered_color, rendered_depth, gt_color, gt_depth, correlation_map, pixel_coords):
        """
        Compute the SpS-NeRF loss.
        
        Args:
            rendered_color: Rendered color (3,).
            rendered_depth: Estimated depth (scalar).
            gt_color: Ground truth color (3,).
            gt_depth: Ground truth depth from SGM (scalar).
            correlation_map: SGM correlation map for the image (H, W).
            pixel_coords: (u, v) coordinates of the pixel.
            
        Returns:
            total_loss: Scalar loss value.
        """
        # Color Loss
        color_loss = torch.nn.functional.l1_loss(rendered_color, gt_color)
        
        # Uncertainty Metric corr(r)
        # Extract correlation value for the specific pixel
        u, v = pixel_coords
        corr_r = correlation_map[u, v]
        
        # Depth Loss with uncertainty gating
        # L_depth = corr(r) * max(0, |D_pred - D_input| - m)
        depth_diff = torch.abs(rendered_depth - gt_depth)
        depth_loss_raw = torch.clamp(depth_diff - self.margin, min=0.0)
        depth_loss = corr_r * depth_loss_raw
        
        total_loss = color_loss + self.lambda_depth * depth_loss
        return total_loss

    def train_step(self, image_id, ray_o, ray_d, gt_color, gt_depth, pixel_coords):
        """
        Perform one training step.
        
        Args:
            image_id: Identifier for the input image.
            ray_o: Ray origin.
            ray_d: Ray direction.
            gt_color: Ground truth color.
            gt_depth: Ground truth depth from SGM.
            pixel_coords: Pixel coordinates (u, v).
        """
        # Get SGM maps for this image
        sgm_depth = self.sgm_depths[image_id]
        sgm_corr = self.sgm_correlations[image_id]
        
        # Render
        rendered_color, rendered_depth, _, _ = self.render_ray(ray_o, ray_d, num_samples=64)
        
        # Compute Loss
        loss = self.compute_loss(
            rendered_color, rendered_depth, 
            gt_color, gt_depth, 
            sgm_corr, pixel_coords
        )
        
        # Optimize
        self.optimizer.zero_grad()
        loss.backward()
        self.optimizer.step()
        
        return loss.item()
```

**Edge Cases and Pitfalls:**
*   **Flat Surface Regularization:** SpS-NeRF lacks regularization on flat surfaces, leading to local irregularities, a common problem in NeRF [S1]. Adding semantic information might be a solution [S1].
*   **SGM Outliers:** SGM is susceptible to outliers. The Ground Truth DSM in the Djibouti dataset was generated with the same SGM, potentially biasing comparisons and corrupting GT with erroneous depth estimations [S1].
*   **Incomplete Depth:** Input depth maps from SGM are incomplete due to occlusions [S1].
*   **Low Precision:** Input depth maps have lower precision (4x GSD) [S1].

## Subtopics

### [Sat-NeRF](13550-model-architecture-and-encoding.md)
The base architecture for satellite NeRF, which SpS-NeRF extends. SpS-NeRF omits transient objects and solar correction modeling from Sat-NeRF because it targets synchronous acquisitions.

### [DDPNeRF](11916-depth-guided-nerf-training-configuration.md)
Provides the dense depth supervision framework and depth loss formulation that SpS-NeRF adapts. SpS-NeRF replaces DDPNeRF's depth loss distance metric with one based on SGM correlation maps.

### [Roessle et al. (2022) Ray Sampling](13550-model-architecture-and-encoding.md)
Provides the guided ray sampling strategy used by SpS-NeRF to improve depth estimation near the input depth surface.

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:**
    *   **DFC2019 (2 views):** PSNR 20.2, SSIM 0.87, MAEin 3.02, MAEout 7.77 [S1].
    *   **DFC2019 (3 views):** PSNR 19.06, SSIM 0.86, MAEin 4.63, MAEout 2.05 [S1].
    *   **Djibouti (2 views):** PSNR 32.85, SSIM 0.92, MAEin 1.57, MAEout 1.15 [S1].
    *   **Djibouti (3 views):** PSNR 36.26, SSIM 0.95, MAEin 1.35, MAEout 0.81 [S1].
*   **Scaling:** Not given in the sources.
*   **Strengths:**
    *   Outperforms NeRF and Sat-NeRF in sparse view scenarios [S1].
    *   Better than full-resolution SGM (SGMscl1) in occluded and poorly textured areas (MAEout) [S1].
    *   Better behavior close to building outlines and free of outliers compared to SGMscl1 [S1].
    *   Capable of recovering tree canopy surfaces with 3 views, which is challenging for traditional patch-based methods [S1].
*   **Limitations:**
    *   Less good than SGMscl1 in altitude extraction on valid pixels (MAEin) due to lack of regularization [S1].
    *   Lacks regularization on flat surfaces, leading to local irregularities [S1].
    *   Relies on SGM, which can be slow and susceptible to outliers [S1].
*   **When to use:** Sparse satellite imagery scenarios where traditional MVS fails in occluded/poorly textured areas and learning-based depth prediction is not desired or feasible [S1].
*   **When not to use:** Scenarios requiring high precision on flat surfaces or where real-time performance is critical given the SGM preprocessing step [S1].

## Background
SpS-NeRF was presented in 2023 by Zhang et al. in the ISPRS Annals of the Photogrammetry, Remote Sensing and Spatial Information Sciences [S1]. It is an extension of Sat-NeRF (Marí et al., 2022) and builds on the dense depth supervision approach of DDPNeRF (Roessle et al., 2022) [S1]. The method was developed to address the challenge of generating convincing 3D geometries from sparse satellite imagery, where many views are rare [S1]. It was tested on the DFC2019 dataset and the Djibouti dataset (obtained via CNES ISIS framework) [S1]. Numerical computations were performed on the SCAPAD cluster at the Institute de Physique du Globe de Paris [S1].
