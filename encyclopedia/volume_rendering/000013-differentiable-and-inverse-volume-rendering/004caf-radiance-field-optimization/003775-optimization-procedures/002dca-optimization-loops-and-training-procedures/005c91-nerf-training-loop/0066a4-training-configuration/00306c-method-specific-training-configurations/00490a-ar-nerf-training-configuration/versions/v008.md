# AR-NeRF Training Configuration

Also called: AR-NeRF Implementation Details, AR-NeRF architecture and training configuration

## Overview
AR-NeRF (Aperture Rendering Neural Radiance Fields) is a method for unsupervised learning of depth and defocus effects from natural images by integrating aperture rendering into a generative NeRF framework [S1]. It differs from standard NeRF variants by explicitly modeling the camera aperture to synthesize images with controllable defocus blur and depth, rather than just reconstructing a static 3D scene [S1]. Unlike [NeRF Hyperparameters](3065-nerf-hyperparameters.md) which focuses on general optimization stability, AR-NeRF requires specific architectural changes (foreground/background synthesis networks) and regularization terms (identity loss) to maintain view consistency while learning depth [S1].

## How it works
AR-NeRF builds on [Method-Specific Training Configurations](6267-method-specific-training-configurations.md) by extending the generative NeRF pipeline with aperture-based rendering and specific network architectures [S1].

### Inputs and Outputs
*   **Inputs:** Unposed natural images (e.g., Oxford Flowers, CUB-200-2011, FFHQ). No camera poses or depth labels are provided [S1].
*   **Outputs:** Synthesized images from novel viewpoints with controllable defocus strength and focus distance [S1].

### Data Structures and Layout
The model consists of three main components: a Mapping Network, a Synthesis Network (split into Foreground and Background), and a Discriminator [S1].

1.  **Mapping Network:**
    *   Structure: Multi-Layer Perceptron (MLP).
    *   Layers: 3 hidden layers.
    *   Units: 256 units per layer.
    *   Activation: Leaky ReLU (LReLU) with negative slope 0.2 [S1].
    *   Latent Code Dimension: 256 [S1].

2.  **Synthesis Network:**
    *   **Foreground Synthesis Network:**
        *   Structure: MLP with FiLM-SIREN layers.
        *   Layers: 8 hidden layers.
        *   Units: 128 units per layer [S1].
        *   Note: Reduced from 256 units (used in pi-GAN) to allow more points per ray, improving performance without significant quality loss [S1].
    *   **Background Synthesis Network:**
        *   Structure: MLP with FiLM-SIREN layers.
        *   Layers: 8 hidden layers.
        *   Units: 64 units per layer [S1].
        *   Rationale: Fewer parameters assumed sufficient as background is simpler than foreground [S1].

3.  **Discriminator:**
    *   **For FFHQ:** Uses CoordConv layers followed by residual blocks [S1].
    *   **For Oxford Flowers / CUB-200-2011:** Same as FFHQ but **without** CoordConv layers [S1].
    *   Rationale: CoordConv layers negatively affected performance on datasets with unaligned subjects (flowers/birds) compared to aligned faces [S1].

### Training Steps and Parameters
The training minimizes a GAN loss with specific regularizers [S1].

1.  **Optimization:** Adam optimizer [S1].
2.  **Learning Rate:** $6 \times 10^{-5}$ (0.00006) [S1].
3.  **Iterations:** 200,000 [S1].
4.  **Loss Functions:**
    *   **GAN Loss:** Non-saturating GAN loss [S1].
    *   **R1 Regularization:** Weight $\lambda_{R1} = 0.2$ [S1].
    *   **Identity Regularizer:** Weight $\lambda_{id} = 15$ [S1]. This term ensures identity consistency across different viewpoints [S1].

### Edge Cases and Pitfalls
*   **Ray Density:** The number of rays and points per ray must be tuned. Preliminary experiments showed that stratified sampling outperforms fixed ray counts. Increasing the number of points along the ray is critical for performance, enabled by the reduced layer units (128 vs 256) [S1].
*   **Resolution Scaling:** For higher-resolution applications, the input point density must be increased to allow AR-NeRF-R (the defocus renderer variant) to process higher-resolution images (e.g., 128x128) [S1].
*   **Discriminator Architecture:** Using CoordConv layers on unaligned datasets (Oxford Flowers, CUB-200-2011) degrades performance; they must be removed [S1].

## Subtopics

### AR-NeRF-R
A defocus renderer trained on images generated by AR-NeRF, allowing continuous and intuitive manipulation of defocus strength and focus distance given an input image [S1].

*   **Definition:** A conditional U-Net that takes an AR-NeRF generated image and auxiliary parameters (aperture size $s$, focus distance $f$) to output a defocused image [S1].
*   **Training Steps:**
    1.  Generate training images at 128×128 resolution using AR-NeRF by increasing input point density [S1].
    2.  Train a conditional U-Net on these images [S1].
    3.  Feed aperture size $s$ and focus distance $f$ as auxiliary information to the U-Net [S1].
    4.  Output defocused images by varying $s$ and $f$ continuously [S1].
*   **Parameters:**
    *   Aperture size $s$: Auxiliary continuous control parameter for defocus strength [S1].
    *   Focus distance $f$: Auxiliary continuous control parameter for focus plane depth [S1].
*   **Architecture:** U-Net with two auxiliary scalar inputs ($s, f$) concatenated or injected as conditioning signals [S1].
*   **Comparison:** Unlike AR-GAN-DR, where defocus parameters are uniquely determined by the input image, AR-NeRF-R allows continuous interactive adjustment of $s$ and $f$ [S1].
*   **Usage:** Trained on Oxford Flowers dataset (128×128 images generated by AR-NeRF); evaluated on iPhone2DSLR Flower dataset [S1].

## Operating characteristics
*   **Performance:** AR-NeRF achieves lower FID and KID scores compared to baseline GANs (AR-GAN, AR-GAN++, RGBD-GAN) on Oxford Flowers, CUB-200-2011, and FFHQ datasets [S1].
*   **Complexity:** Processing time and memory increase with the number of rays. The reduction of synthesis network units from 256 to 128 allows for a larger number of points per ray, which is critical for performance but increases computational load per ray [S1].
*   **Scalability:** The method requires increasing input point density to support higher resolution outputs (e.g., 128×128 for AR-NeRF-R) [S1].
*   **Strengths:** Unsupervised learning of depth and defocus; continuous control of defocus parameters; improved FID/KID metrics over GAN baselines [S1].
*   **Limitations:** Requires careful tuning of ray counts and point densities; CoordConv layers are not universally beneficial (dataset-dependent) [S1].

## Background
AR-NeRF was introduced in the paper "AR-NeRF: Unsupervised Learning of Depth and Defocus Effects from Natural Images with Aperture Rendering Neural Radiance Fields" [S1]. It is based on pi-GAN, a state-of-the-art generative variant of NeRF [S1]. The authors adapted pi-GAN configurations for specific datasets (Oxford Flowers, CUB-200-2011, FFHQ) and extended it with aperture rendering to enable depth and defocus learning without supervision [S1]. The method was evaluated on three datasets: Oxford Flowers (8,189 images, 102 categories), CUB-200-2011 (11,788 images, 200 bird species), and FFHQ (70,000 face images) [S1].
