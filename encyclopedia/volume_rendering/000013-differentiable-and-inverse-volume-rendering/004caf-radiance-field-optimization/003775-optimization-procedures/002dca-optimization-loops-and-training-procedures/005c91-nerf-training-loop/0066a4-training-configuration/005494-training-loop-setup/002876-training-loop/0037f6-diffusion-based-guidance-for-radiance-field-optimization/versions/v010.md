# Diffusion-Based Guidance for Radiance Field Optimization

Also called: Score Distillation Sampling, Stable Diffusion Training Guidance

## Overview
Diffusion-Based Guidance for Radiance Field Optimization, commonly known as Score Distillation Sampling (SDS), computes a gradient signal from a frozen 2D diffusion model to optimize a 3D radiance field representation [S1, unofficial]. It solves the problem of generating 3D geometry and texture from 2D priors by backpropagating the difference between the diffusion model's predicted noise and the actual noise added to a rendered image's latent representation [S1, unofficial]. Unlike sibling methods that may use explicit 3D supervision or multi-view consistency losses directly, SDS relies entirely on the generative prior of a pre-trained text-to-image diffusion model to guide the optimization loop [S1, unofficial].

## How it works
The method optimizes a radiance field (or Gaussian Splatting representation) by rendering images from random viewpoints, converting them to latent space, and using a frozen Stable Diffusion model to provide gradients that steer the 3D representation toward the distribution of the text prompt.

### Inputs and Outputs
*   **Inputs:**
    *   Radiance field parameters (e.g., NeRF weights or 3D Gaussian attributes).
    *   Text prompt $P$ for conditioning.
    *   Camera pose $(\theta, \phi)$ for rendering.
    *   Diffusion model components: UNet, VAE encoder/decoder, Scheduler, Text Encoder.
*   **Outputs:**
    *   Gradient signal applied to radiance field parameters.

### Data Structures
*   **Latents:** Tensor of shape $[B, 4, 64, 64]$ representing the encoded image in the latent space of the VAE [S1, unofficial].
*   **Text Embeddings:** Tensor containing positive (conditioned) and negative (unconditional) embeddings derived from the text prompt [S1, unofficial].
*   **Timestep:** Integer $t$ sampled from the diffusion schedule [S1, unofficial].

### Parameters
*   `guidance_scale`: Classifier-Free Guidance (CFG) scale multiplier. Default value is 100 [S1, unofficial].
*   `t_range`: List `[0.02, 0.98]` used to compute `min_step` and `max_step` as fractions of `num_train_timesteps` [S1, unofficial].
*   `step_ratio`: Float controlling timestep selection. `1.0` maps to `min_step` (early diffusion), `0.0` maps to `max_step` (late diffusion) [S1, unofficial].
*   `as_latent`: Boolean flag. If `false`, input RGB is interpolated to 512x512 and encoded via VAE. If `true`, input is assumed to be latent, interpolated to 64x64, and scaled by $2x - 1$ [S1, unofficial].

### Numbered Steps
1.  **Rendering:** Render an image $I$ from the current radiance field using a random camera pose.
2.  **Latent Encoding:**
    *   If `as_latent` is `false`:
        *   Convert $I$ to `self.dtype`.
        *   Interpolate $I$ to 512x512.
        *   Encode via VAE to get `latents` of shape $[B, 4, 64, 64]$ [S1, unofficial].
    *   If `as_latent` is `true`:
        *   Interpolate input to 64x64.
        *   Scale by $2x - 1$ [S1, unofficial].
3.  **Timestep Selection:** Sample a timestep $t$ based on `step_ratio` and `t_range` [S1, unofficial].
4.  **Noise Addition:**
    *   Compute weighting factor $w = (1 - \alpha_t)$, where $\alpha_t$ is the noise schedule value at $t$. Shape: $[batch\_size, 1, 1, 1]$ [S1, unofficial].
    *   Sample noise $\epsilon = \text{torch.randn\_like}(latents)$ [S1, unofficial].
    *   Add noise: $latents_{noisy} = \text{scheduler.add\_noise}(latents, \epsilon, t)$ [S1, unofficial].
5.  **Classifier-Free Guidance (CFG) Preparation:**
    *   Duplicate noisy latents and timesteps: $latent\_model\_input = \text{cat}([latents_{noisy}] * 2)$, $t_{cat} = \text{cat}([t] * 2)$ [S1, unofficial].
    *   Prepare text embeddings: Concatenate positive and negative embeddings. If directional embeddings (e.g., `front`, `side`, `back` based on azimuth angle $h$) are provided, concatenate them with the negative embeddings [S1, unofficial].
6.  **Noise Prediction:**
    *   Pass inputs to UNet: $noise\_pred = \text{unet}(latent\_model\_input, t_{cat}, \text{encoder\_hidden\_states}=embeddings).sample$ [S1, unofficial].
7.  **Guidance Application:**
    *   Split $noise\_pred$ into $noise\_pred_{cond}$ and $noise\_pred_{uncond}$ [S1, unofficial].
    *   Compute guided prediction: $noise\_pred = noise\_pred_{uncond} + \text{guidance\_scale} \times (noise\_pred_{cond} - noise\_pred_{uncond})$ [S1, unofficial].
8.  **Gradient Computation:**
    *   Compute gradient: $grad = w \times (noise\_pred - \epsilon)$ [S1, unofficial].
    *   Handle numerical instability: $grad = \text{torch.nan\_to\_num}(grad)$ [S1, unofficial].
9.  **Target and Loss:**
    *   Compute target: $target = (latents - grad).detach()$ [S1, unofficial].
    *   Compute loss: $loss = 0.5 \times \text{F.mse\_loss}(latents.float(), target, \text{reduction='sum'}) / latents.shape[0]$ [S1, unofficial].
10. **Backpropagation:** Backpropagate the loss to update the radiance field parameters [S1, unofficial].

### Pseudocode
```python
def compute_sds_gradient(latents, t, embeddings, unet, scheduler, guidance_scale, w):
    """
    Computes the SDS gradient given noisy latents and diffusion model components.
    
    Args:
        latents: Tensor [B, 4, 64, 64], clean latents from VAE encoding.
        t: Integer, current diffusion timestep.
        embeddings: Tensor, concatenated positive and negative text embeddings.
        unet: Diffusion UNet model.
        scheduler: Diffusion scheduler object.
        guidance_scale: Float, CFG scale.
        w: Tensor [B, 1, 1, 1], weighting factor (1 - alpha_t).
        
    Returns:
        grad: Tensor, gradient to backpropagate to radiance field.
    """
    # Sample noise
    noise = torch.randn_like(latents)
    
    # Add noise to latents
    latents_noisy = scheduler.add_noise(latents, noise, t)
    
    # Duplicate for CFG
    latent_model_input = torch.cat([latents_noisy] * 2)
    t_cat = torch.cat([t] * 2)
    
    # Predict noise with UNet
    # Note: embeddings must be structured as [positive, negative] for the unet
    noise_pred = unet(latent_model_input, t_cat, encoder_hidden_states=embeddings).sample
    
    # Split predictions
    noise_pred_cond, noise_pred_uncond = noise_pred.chunk(2)
    
    # Apply Classifier-Free Guidance
    noise_pred = noise_pred_uncond + guidance_scale * (noise_pred_cond - noise_pred_uncond)
    
    # Compute gradient
    grad = w * (noise_pred - noise)
    
    # Handle NaNs
    grad = torch.nan_to_num(grad)
    
    return grad

def train_step_radiance_field(radiance_field, text_prompt, camera_pose, diffusion_model, guidance_scale=100):
    """
    Single training step for radiance field optimization using SDS.
    """
    # 1. Render image from radiance field
    rendered_image = radiance_field.render(camera_pose)
    
    # 2. Encode to latent space
    # Assuming VAE encoder is part of diffusion_model
    latents = diffusion_model.vae.encode(rendered_image)
    
    # 3. Get text embeddings
    embeddings = diffusion_model.text_encoder(text_prompt)
    # Ensure negative embedding is available for CFG
    negative_embeddings = diffusion_model.text_encoder("") # Empty string or null prompt
    
    # Concatenate for CFG input
    full_embeddings = torch.cat([embeddings, negative_embeddings], dim=0)
    
    # 4. Sample timestep
    t = sample_timestep() # Based on step_ratio and t_range
    
    # 5. Compute weighting factor w
    alpha_t = diffusion_model.scheduler.alphas[t]
    w = (1 - alpha_t).view(1, 1, 1, 1)
    
    # 6. Compute SDS gradient
    grad = compute_sds_gradient(
        latents=latents,
        t=t,
        embeddings=full_embeddings,
        unet=diffusion_model.unet,
        scheduler=diffusion_model.scheduler,
        guidance_scale=guidance_scale,
        w=w
    )
    
    # 7. Backpropagate gradient to radiance field
    # Note: The gradient is technically with respect to latents.
    # We need to backprop through the VAE decoding and rendering process.
    # In practice, this is done by computing the loss:
    # target = (latents - grad).detach()
    # loss = 0.5 * MSE(latents, target)
    # loss.backward()
    
    target = (latents - grad).detach()
    loss = 0.5 * F.mse_loss(latents.float(), target, reduction='sum') / latents.shape[0]
    loss.backward()
    
    return loss
```

### Edge Cases and Pitfalls
*   **NaN Values:** Gradient computation can produce NaN values due to numerical instability in the diffusion process or guidance scaling. The code explicitly clamps NaNs to 0 using `torch.nan_to_num(grad)` [S1, unofficial].
*   **Timestep Selection:** The choice of timestep affects the balance between global structure and fine details. Early timesteps (high noise) capture global structure, while late timesteps (low noise) capture details [S6].
*   **Latent Space Mismatch:** If `as_latent` is false, the input image must be correctly interpolated and encoded. Incorrect handling leads to misaligned gradients [S1, unofficial].

## Subtopics

### [Inpainting SDS Loss](11185-inpainting-sds-loss.md)
Inpainting SDS Loss is a training objective for Neural Radiance Fields (NeRFs) that uses a pre-trained 2D diffusion inpainting model to generate 3D content that harmonizes with an existing scene. It solves the problem of incomplete or misaligned object generation common in vanilla SDS, where generated parts (e.g., a cat's head) fail to composite properly with the background. Unlike vanilla SDS, which optimizes based on global noise prediction, this method conditions the diffusion model on a masked image and mask derived from a 3D bounding box, ensuring complete geometry and proper pose relative to the scene context.

### SKED
SKED is a method for editing a Neural Radiance Field (NeRF) scene using guidance from 2D sketches provided from multiple views, in addition to an input text prompt [S1, unofficial][S2]. It addresses the problem of localized 3D editing, specifically object insertion and replacement, by ensuring that edits are confined to sketched regions while preserving the unedited parts of the original scene [S1, unofficial][S2]. It is distinguished from sibling methods like [Inpainting SDS Loss](11185-inpainting-sds-loss.md) by its explicit use of multi-view 2D sketches as spatial priors to define the edit region, rather than relying solely on text prompts or single-view masks [S1, unofficial][S2].

### [Synthetic Training with EG3D Supervision](13312-synthetic-training-with-eg3d-supervision.md)
This method trains an image-to-triplane encoder to reconstruct a 3D radiance field representation from a single input image by leveraging synthetic data generated by a frozen, pretrained EG3D generator. It solves the problem of generalizing single-image portrait synthesis by ensuring the encoder produces triplanes that are consistent not only with the input reference view but also with novel multiview renderings, thereby enforcing geometric and photometric coherence. It differs from standard supervised training by using a frozen generative model as a ground-truth oracle and alternating between reference-view and multiview supervision to prevent overfitting to the specific distribution of the input image.

### [Mask+SDS with Background Prompt](14382-mask-sds-with-background-prompt.md)
Mask+SDS with Background Prompt is a differentiable volume rendering optimization method that uses a frozen Stable Diffusion model to edit specific regions of a scene while explicitly guiding the generation of surrounding content. It solves the problem of "black holes" (unsupervised, often black or undefined regions) that occur when masking out parts of a NeRF for editing, by appending a background description to the diffusion model's text prompt. It sets itself apart from standard Mask+SDS by providing explicit semantic guidance for the occluded areas, and from Mask+SDS+CLIP by relying on the diffusion model's generative prior for the background rather than a separate CLIP-based texture fill.

### [Diffusion-Based 3D Inpainting](14834-diffusion-based-3d-inpainting.md)
Diffusion-Based 3D Inpainting is a method that utilizes a self-trained 2D inpainting diffusion model to reconstruct missing or masked regions in a 3D scene represented by a radiance field. It solves the problem of 3D scene completion or object removal by combining explicit reconstruction constraints for visible areas with implicit diffusion priors for occluded areas. It is distinguished from sibling methods like [Inpainting SDS Loss](11185-inpainting-sds-loss.md) by its specific reliance on a *self-trained* 2D inpainting model rather than a generic pre-trained one, and from [SKED](12268-sked.md) by its focus on distilling 2D inpainting results into a single 3D scene via iterative refinement.

### [Reference-guided Controllable Inpainting of Neural Radiance Fields](15289-reference-guided-controllable-inpainting-of-neural-radiance-.md)
This method performs 3D inpainting of Neural Radiance Fields (NeRFs) by substituting a single reference view with a diffusion-generated target view, then optimizing the NeRF to match the new view while maintaining consistency with the remaining input views. It solves the problem of inserting or modifying objects in a 3D scene without requiring multi-view supervision for the target content. It differs from [Inpainting SDS Loss](11185-inpainting-sds-loss.md) by using a deterministic 2D inpainting prior (Stable Diffusion) followed by a bilateral solver for residual smoothing, rather than relying solely on gradient-based SDS guidance during optimization.

### Iterative Optimization with Learnable Parameters for Diffusion-Guided Radiance Fields
A method addressing quality impairment caused by differences between the diffusion prior and the training process of the diffusion model [S2]. It performs iterative optimization of the 3D model and the diffusion prior [S2]. It introduces a learnable unconditional embedding in the classifier-free guidance formula and additional parameters, such as LoRA parameters, added to the network [S2].

### Interval Score Matching
A modification to SDS loss that replaces DDPM with DDIM inversion and introduces supervisions from interval steps to avoid high error in one-step reconstruction [S2].

### Context-Translation Training with Segmentation Masking
Passes a segmentation mask to the training process where pixels excluded in the stylization process are masked out [S3]. Calculates the loss only on the pixels outside the mask to avoid changing the appearance of masked pixels [S3]. Employs a background loss $L_{BG}$ as an additional regularization loss within the stylization process [S3]. $L_{BG}$ is defined as the L1 distance between the ground truth pixels of the background in the rendered image and the pixels in the background of the GT image [S3].

### Style Adaptation via Diffusion Guidance
Uses a reference image as a condition alongside the text prompt to guide generation [S4].

### Blending Refinement Model
A model employing two Instruct-Pix2Pix processes as learned regularization to improve quality by purifying noisy mixup images and aligning them with detailed characteristics, using averaged latent codes for stability [S5]. First pass: Use the mixup image as input and the original image as a condition to purify the noisy mixup image by preserving structural integrity [S5]. Second pass: Use the resulting image from the first pass as input and the mixup image as the condition to align with the mixup image’s detailed characteristics [S5]. Introduce $n_r$ noised latent codes and update them independently. Compute the average of the latent codes and decode it back into the image [S5]. Parameters: $n_r=5$, $t=0.6$, 3 diffusion steps [S5].

### Masked-NeRF + DreamFusion
A baseline method that uses per-scene text prompts to guide the generation of masked regions using score distillation sampling (SDS) loss [S6]. Gradually and uniformly decreases the maximum noise steps $t_{max}$ during fitting, until it equals the minimum noise steps $t_{min}$ at the last iteration [S6].

## Operating characteristics
*   **Time Complexity:** Each training step requires a forward pass through the diffusion model (UNet, Text Encoder) and a backward pass through the radiance field renderer. The diffusion model is frozen, so its parameters are not updated, but its forward pass is computationally expensive.
*   **Memory Complexity:** Requires storing the radiance field parameters, the diffusion model weights (frozen), and intermediate activations for backpropagation.
*   **Measured Performance:** Performance depends heavily on the diffusion model used (e.g., Stable Diffusion) and the number of diffusion steps. Higher `guidance_scale` can improve fidelity but may reduce diversity or cause artifacts.
*   **Scaling:** Scales with the number of training iterations and the complexity of the radiance field representation.
*   **Strengths:** Leverages powerful 2D diffusion priors for high-quality 3D generation. Simple to implement if a diffusion model is available.
*   **Limitations:** Computationally expensive due to repeated diffusion model forward passes. Can suffer from "over-saturation" or "Janus" problems if not carefully tuned. Gradient noise can lead to unstable optimization.
*   **When to use:** When generating 3D content from text prompts or single images with high aesthetic quality is the primary goal.
*   **When not to use:** When real-time performance is critical, or when explicit 3D supervision (e.g., multi-view images) is available and more reliable.

## Background
Score Distillation Sampling (SDS) was introduced in the DreamFusion paper [S1, unofficial][S6]. It enables the optimization of 3D generative models using pre-trained 2D diffusion models. The method has become a standard technique for text-to-3D generation and has been extended to various other 3D representations and editing tasks [S2].
