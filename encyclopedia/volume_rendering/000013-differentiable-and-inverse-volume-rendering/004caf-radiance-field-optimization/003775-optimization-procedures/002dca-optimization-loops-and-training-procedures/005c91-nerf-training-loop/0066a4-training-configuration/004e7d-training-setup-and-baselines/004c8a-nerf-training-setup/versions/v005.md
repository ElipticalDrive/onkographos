# NeRF Training Setup

Also called: Control-NeRF Training Setup, Nerfstudio Training

## Overview
This article defines the training configuration for NeRF-based models using the Nerfstudio library, specifically leveraging NerfAcc and Instant-NGP for fast convergence on static scenes [S2]. It is distinguished from standard NeRF implementations by replacing the positionally encoded 3D position input with a pre-sampled 64-dimensional feature vector, thereby omitting positional encoding on the feature vector itself [S1]. This setup serves as a baseline for evaluating variants such as Image-Based NeRF Training [S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A dataset of multi-view images (e.g., LLFF datasets) and corresponding camera poses. The scene is represented by a volume $V_s$ containing sampled feature vectors.
*   **Output:** Optimized network parameters for the coarse network $\hat{C}_c$ and fine network $\hat{C}_f$, producing rendered images and opacity maps.

**Data Structures:**
*   **Feature Vector ($\mathbf{v}_s$):** A 64-dimensional vector sampled from volume $V_s$ at point $\mathbf{p} \in \mathbb{R}^3$ using trilinear sampling $S(V_s, \mathbf{p})$ [S1].
*   **Direction Encoding ($\gamma(\mathbf{d})$):** A positional encoding applied to the direction vector $\mathbf{d} \in \mathbb{R}^3$. The encoding depth is $L=4$ [S1]. The encoding for each dimension $p$ of $\mathbf{d}$ is defined as:
    $$
    \gamma(p) = [\sin(2^0\pi p), \cos(2^0\pi p), \dots, \sin(2^{L-1}\pi p), \cos(2^{L-1}\pi p)]
    $$
    This results in a 24-dimensional encoded direction vector ($2 \times L \times 3$) [S1].

**Algorithm Steps:**
1.  **Ray Sampling:** Sample 1024 rays per batch from the input images, which are scaled to a resolution of $504 \times 378$ [S1].
2.  **Coarse Network Optimization:** Optimize the coarse network $\hat{C}_c(\mathbf{r})$. This network samples 64 points from evenly spaced bins along the ray length [S1].
3.  **Fine Network Sampling:** Sample 64 additional points for the fine network $\hat{C}_f(\mathbf{r})$. These points are sampled based on the opacity results from the coarse network to focus on relevant portions of the scene volume [S1].
4.  **Feature Sampling:** For each sampled point $\mathbf{p}$, obtain the feature vector $\mathbf{v}_s = S(V_s, \mathbf{p})$. No positional encoding is applied to $\mathbf{v}_s$ [S1].
5.  **Direction Encoding:** Apply the positional encoding $\gamma(\mathbf{d})$ to the ray direction $\mathbf{d}$ [S1].
6.  **Radiance Function Input:** Pass the concatenated input $(\mathbf{v}_s, \gamma(\mathbf{d}))$ to the radiance function $F_\Theta$ to predict color $\mathbf{c}$ and density $\sigma$ [S1].
7.  **Volume Rendering:** Compute the rendered color $\mathbf{C}(\mathbf{r})$ using the discretized approximation of the volume rendering integral:
    $$
    \mathbf{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i
    $$
    where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance, $\sigma_i$ is the density, $\delta_i$ is the segment length, and $\mathbf{c}_i$ is the color at sample $i$ [S1][S3, unofficial].

**Parameters:**
*   **Encoding Depth ($L$):** 4 [S1].
*   **Batch Size:** 1024 rays [S1].
*   **Image Resolution:** $504 \times 378$ [S1].
*   **Library:** Nerfstudio [S2].
*   **Models:** NerfAcc and Instant-NGP [S2].
*   **Scene Type:** Static scenes with minimal surgical tools, actions, and moving organs [S2].

**Edge Cases and Pitfalls:**
*   **Precision:** The discretized approximation assumes small segment lengths $\delta_i$ to accurately model the exponential transmittance [S1].
*   **Boundaries:** Trilinear sampling $S(V_s, \mathbf{p})$ requires careful handling of points outside the volume bounds [S1].

## Subtopics

### Image-Based NeRF Training
Training a NeRF using RGB images as ground truth, optimizing both geometry (via Eikonal loss) and appearance (via color loss) [S3, unofficial]. It differs from the baseline by explicitly adding an Eikonal loss for geometry regularization, similar to SDF training [S3, unofficial]. It is chosen when explicit geometric regularization is required alongside appearance optimization [S3, unofficial].

## Operating characteristics
*   **Hardware:** Single RTX A6000 GPU and 128 GB RAM [S2].
*   **Performance:** The use of NerfAcc and Instant-NGP enables fast convergence on static scenes [S2].
*   **Scaling:** The method scales with the number of frames and camera poses estimated via SfM methods (e.g., COLMAP, HLOC) [S2].
*   **Strengths:** Fast convergence; leverages pre-computed feature volumes to simplify network input [S1, S2].
*   **Limitations:** Restricted to static scenes; requires accurate camera pose estimation [S2].

## Background
This training setup originates from the Control-NeRF method, which introduces editable feature volumes for scene rendering and manipulation [S1]. It was adapted for laparoscopic surgical video rendering using the Nerfstudio library to handle static abdominal environments [S2]. The approach modifies the standard NeRF architecture by replacing the positionally encoded 3D position input with a 64-dimensional feature vector, omitting positional encoding on the feature vector itself [S1].
