# Generative Occupancy Fields (GOF)


## Overview
Generative Occupancy Fields (GOF) is a 3D-aware image synthesis method that combines radiance fields with occupancy representations to learn compact object surfaces without impeding training convergence [S1, unofficial]. It solves the problem of diffused surfaces in prior generative radiance fields (like GRAFs) and the sparse gradient convergence issues in direct occupancy networks by transitioning from cumulative volume rendering to surface-point rendering [S1, unofficial]. GOF is distinguished from its siblings by reinterpreting alpha values as occupancy values to enable root-finding for surface location, allowing a gradual shift from volume-based to surface-based sampling during training [S1, unofficial].

## How it works
GOF maps a 3D position $\mathbf{x} \in \mathbb{R}^3$, viewing direction $\mathbf{d} \in S^2$, and latent code $\mathbf{z} \sim p_z$ to an alpha value $\alpha_\theta(\mathbf{x}, \mathbf{z}) \in [0, 1]$ and color $\mathbf{c}_\theta(\mathbf{x}, \mathbf{d}, \mathbf{z}) \in \mathbb{R}^3$ [S1, unofficial]. The core mechanism replaces volume density prediction with direct alpha prediction, treating alpha as occupancy to locate surfaces via root-finding [S1, unofficial].

### Data Structures
*   **Generator $G_\theta$**: A neural network (e.g., FiLMed-SIREN) taking $(\mathbf{x}, \mathbf{d}, \mathbf{z})$ and outputting $(\alpha_\theta, \mathbf{c}_\theta)$ [S1, unofficial].
*   **Discriminator $D_\phi$**: Standard GAN discriminator taking images [S1, unofficial].
*   **Parameters**:
    *   $\tau$: Threshold for root-finding. Default: $0.5$ [S1, unofficial].
    *   $N$: Number of rendering samples. Default: $12$ [S1, unofficial].
    *   $M$: Number of root-finding bins. Default: $12$ [S1, unofficial].
    *   $m_s$: Secant iterations. Default: $3$ [S1, unofficial].
    *   $\Delta_{init}$: Initial sampling interval half-width. Default: $(t_f - t_n)/2$ [S1, unofficial].
    *   $\Delta_{min}$: Minimal sampling interval half-width. Not given in the sources.
    *   $\gamma$: Shrinking rate. Not given in the sources.
    *   $\lambda_{normal}, \lambda_{opacity}$: Loss weights. Not given in the sources.

### Rendering Equation
GOF uses alpha composition where $\alpha_\theta$ is predicted directly:
$$ \tilde{C}(\mathbf{r}, \mathbf{z}) = \sum_{i=1}^{N} \alpha_\theta(\mathbf{x}_i, \mathbf{z}) \left( \prod_{j<i} (1 - \alpha_\theta(\mathbf{x}_j, \mathbf{z})) \right) \mathbf{c}_\theta(\mathbf{x}_i, \mathbf{d}, \mathbf{z}) $$
where $\mathbf{x}_i$ are sample points along ray $\mathbf{r}$ [S1, unofficial].

### Algorithm Steps

#### 1. Surface Location via Root-Finding
To locate the surface $\mathbf{x}_s$ for shrinking:
1.  Sample $M$ evenly-spaced points $\mathbf{x}_k$ partitioning the volume $[t_n, t_f]$ along the ray [S1, unofficial].
2.  Query generator for alpha values $\alpha_\theta(\mathbf{x}_k, \mathbf{z})$ [S1, unofficial].
3.  Find bin $k_S$ where alpha crosses threshold $\tau$:
    $$ k_S = \arg\min_k (\alpha_\theta(\mathbf{x}_k, \mathbf{z}) < \tau \le \alpha_\theta(\mathbf{x}_{k+1}, \mathbf{z})) $$
    [S1, unofficial].
4.  Apply secant method iteratively $m_s$ times within the bin $[\mathbf{x}_{k_S}, \mathbf{x}_{k_S+1}]$ to find precise surface point $\mathbf{x}_s$ [S1, unofficial].
    *   *Note*: Gradients are not computed for these $M$ points [S1, unofficial].

#### 2. Shrinking Sampling Region
During training, the sampling region shrinks from the full volume to a minimal neighborhood around $\mathbf{x}_s$:
1.  Initialize $\Delta_{init} = (t_f - t_n)/2$ [S1, unofficial].
2.  At training step $n$, compute current interval half-width:
    $$ \Delta_n = \max(\Delta_{init} \exp(-\gamma n), \Delta_{min}) $$
    [S1, unofficial].
3.  Sample $N$ points uniformly in $[\mathbf{x}_s - \Delta_n, \mathbf{x}_s + \Delta_n]$:
    $$ t_i \sim U\left[\mathbf{x}_s - \Delta_n + \frac{2i-2}{N}\Delta_n, \mathbf{x}_s - \Delta_n + \frac{2i}{N}\Delta_n\right] $$
    [S1, unofficial].
4.  If the region exceeds $[t_n, t_f]$, shift it back to fit within bounds [S1, unofficial].

#### 3. Inference Rendering
1.  Fetch truncated latent code $\hat{\mathbf{z}}$ [S1, unofficial].
2.  Locate surface $\mathbf{x}_s$ using Root-Finding [S1, unofficial].
3.  Option A (Standard): Sample $N$ points in $[\mathbf{x}_s - \Delta_{min}, \mathbf{x}_s + \Delta_{min}]$ and render using the alpha composition equation [S1, unofficial].
4.  Option B (Surface-Only): Use $N=1$ at $\mathbf{x}_s$ for speed. The rendered image is theoretically indistinguishable from Option A as $\Delta_{min} \to 0$ [S1, unofficial].

### Pseudocode

```python
def gof_render(ray_origin, ray_direction, latent_code, generator, params):
    """
    Renders an image using GOF.
    params: {M, ms, N, tau, delta_min, delta_init, gamma, step_n}
    """
    t_n, t_f = params['near'], params['far']
    
    # 1. Surface Location
    # Sample M points for root-finding
    x_bins = linspace(t_n, t_f, params['M'] + 1)
    alpha_bins = [generator.query(x, ray_direction, latent_code).alpha for x in x_bins]
    
    # Find crossing bin
    k_S = None
    for k in range(params['M']):
        if alpha_bins[k] < params['tau'] <= alpha_bins[k+1]:
            k_S = k
            break
            
    if k_S is None:
        # Fallback or error handling if no surface found
        return None

    # Secant method refinement
    x_s = secant_refine(x_bins[k_S], x_bins[k_S+1], alpha_bins[k_S], alpha_bins[k_S+1], 
                        generator, ray_direction, latent_code, params['tau'], params['ms'])
    
    # 2. Determine Sampling Interval
    # Calculate shrinking delta
    delta_n = max(params['delta_init'] * exp(-params['gamma'] * params['step_n']), params['delta_min'])
    
    # 3. Sample Points
    # For inference, we can use delta_min or the calculated delta_n depending on training/inference mode
    # The paper suggests using delta_min for inference or surface-only rendering
    delta = params['delta_min'] 
    
    # Clamp to bounds
    t_start = max(t_n, x_s - delta)
    t_end = min(t_f, x_s + delta)
    
    # Sample N points
    t_samples = linspace(t_start, t_end, params['N'] + 1)
    # Midpoints or uniform samples within bins? Paper says uniform in [ts - delta, ts + delta]
    # Re-reading: "sample N points uniformly in [ts - delta, ts + delta]"
    # Using the formula from paper:
    t_samples = [x_s - delta + (2*i - 1)/params['N'] * delta for i in range(1, params['N'] + 1)]
    
    # Clamp again to ensure within [t_n, t_f]
    t_samples = [max(t_n, min(t_f, t)) for t in t_samples]
    
    # 4. Render
    color = 0.0
    transmittance = 1.0
    for t in t_samples:
        x = ray_origin + t * ray_direction
        alpha_val, color_val = generator.query(x, ray_direction, latent_code)
        
        # Alpha composition
        contribution = transmittance * alpha_val * color_val
        color += contribution
        transmittance *= (1 - alpha_val)
        
    return color

def secant_refine(x_low, x_high, alpha_low, alpha_high, generator, d, z, tau, ms):
    """
    Iteratively refines surface location using secant method.
    """
    x_curr = x_low
    x_prev = x_high # Initial guess
    
    for _ in range(ms):
        # Query alpha at current point (approximation for secant)
        # Note: The paper implies using the bin endpoints and refining.
        # Standard secant: x_new = x_curr - f(x_curr) * (x_curr - x_prev) / (f(x_curr) - f(x_prev))
        # Here f(x) = alpha(x) - tau
        
        alpha_curr = generator.query(x_curr, d, z).alpha
        alpha_prev = generator.query(x_prev, d, z).alpha
        
        if abs(alpha_curr - alpha_prev) < 1e-6:
            break
            
        x_new = x_curr - (alpha_curr - tau) * (x_curr - x_prev) / (alpha_curr - alpha_prev)
        
        x_prev = x_curr
        x_curr = x_new
        
    return x_curr
```

### Edge Cases and Pitfalls
*   **Shape-Color Ambiguity**: Direct training fails to maintain surface compactness because small perturbations on surfaces still lead to realistic RGB images, fooling the discriminator [S1, unofficial]. GOF mitigates this by shrinking the sampling region [S1, unofficial].
*   **Gradient Sparsity**: Direct occupancy networks suffer from sparse gradients on surfaces, causing convergence issues. GOF avoids this by starting with volume rendering (full volume sampling) and gradually shrinking [S1, unofficial].
*   **Density Thresholding**: Predicted densities in generative radiance fields range from 0 to 50, making thresholding difficult. GOF uses alpha values (range [0,1]) instead, allowing a fixed threshold $\tau=0.5$ [S1, unofficial].
*   **Surface Rendering Artifacts**: Rendering with only the surface point ($N=1$) may make furry or complex textures over-smooth and less realistic [S1, unofficial].

## Operating characteristics
*   **Complexity**: GOF requires $M + m_s + N$ queries for standard rendering, or $M + m_s + 1$ for single-point surface rendering [S1, unofficial]. Baselines typically require $2N$ queries due to hierarchical sampling [S1, unofficial].
*   **Performance**: GOF outperforms baselines on MAD (Mean Angle Deviation, measuring compactness) and is comparable on SIDE (Scale-Invariant Depth Error, measuring depth accuracy) [S1, unofficial].
*   **Strengths**: Compact and smooth surfaces; efficient inference with surface-only rendering; stable training convergence [S1, unofficial].
*   **Limitations**: Less effective for non-solid objects (e.g., furry cats) where surface-only rendering leads to artifacts [S1, unofficial].

## Background
GOF was proposed by Xudong Xu, Xingang Pan, Dahua Lin, and Bo Dai in 2021 [S1, unofficial]. It builds on the concept of generative radiance fields (GRAFs) and occupancy networks, addressing the trade-off between surface compactness and training stability [S1, unofficial]. It is used for 3D-aware image synthesis on datasets like CelebA, BFM, and Cats [S1, unofficial].
