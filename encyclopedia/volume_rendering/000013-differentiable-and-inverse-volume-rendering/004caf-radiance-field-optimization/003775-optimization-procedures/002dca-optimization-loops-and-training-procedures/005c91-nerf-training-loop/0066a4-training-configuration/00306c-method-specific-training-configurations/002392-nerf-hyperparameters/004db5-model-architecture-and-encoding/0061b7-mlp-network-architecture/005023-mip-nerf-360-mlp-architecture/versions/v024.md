# Mip-NeRF 360 MLP Architecture

Also called: Integrated Positional Encoding MLP, PosEnc MLP

## Overview
The Mip-NeRF 360 MLP architecture is a neural network model that maps 3D positions and viewing directions to volume density and color, specifically designed to handle aliasing in large-scale scenes by using integrated positional encoding [S1, unofficial]. It differs from standard NeRF by lifting the mean and covariance of the cone of integration into the positional encoding space, allowing the network to implicitly account for the frequency content of the signal at different scales [S1, unofficial].

## How it works
The method consists of two main components: a density network that processes spatial information and a color network that incorporates viewing direction. The core innovation is the use of Integrated Positional Encoding (IPE) for the density network, which takes the mean and covariance of the ray segment as input rather than just the mean.

### Inputs and Outputs
**Inputs:**
- 3D position $\mathbf{x} \in \mathbb{R}^3$ and its associated covariance matrix $\Sigma \in \mathbb{R}^{3 \times 3}$ (derived from the ray cone).
- Viewing direction $\mathbf{d} \in S^2$ (or reflection direction $\mathbf{r}$ if reflections are enabled).
- Optional normal vectors $\mathbf{n}$ (if predicted or provided).

**Outputs:**
- Raw volume density $\sigma$.
- Volume density $\sigma_{final}$ after activation.
- Surface normals $\mathbf{n}_{pred}$ (optional, derived from density gradient).
- RGB color $\mathbf{c} \in [0, 1]^3$.

### Steps

1.  **Setup and Basis Generation**:
    If `use_reflections` is True, ensure normals are available (either via `enable_pred_normals` or by not disabling density normals). If not, raise an error [S1, unofficial].
    Precompute the transpose of the basis matrix for integrated positional encoding using `geopoly.generate_basis(basis_shape, basis_subdivisions)` and store as `pos_basis_t` [S1, unofficial].

2.  **Directional Encoding Function**:
    If `use_directional_enc` is True, generate an Integrated Directional Encoding (IDE) function using `ref_utils.generate_ide_fn(deg_view)`. Otherwise, define `dir_enc_fn` to use standard positional encoding with `min_deg=0`, `max_deg=deg_view`, and `append_identity=True` [S1, unofficial].

3.  **Density Network Input Preparation (Integrated Positional Encoding)**:
    a.  **Warping**: If `warp_fn` is not None, linearize the means and covs using `coord.track_linearize(warp_fn, means, covs)` [S1, unofficial].
    b.  **Lifting and Diagonalization**: Lift and diagonalize the means and covs using the precomputed basis transpose:
        $$ \text{lifted\_means}, \text{lifted\_vars} = \text{coord.lift\_and\_diagonalize}(\text{means}, \text{covs}, \text{pos\_basis\_t}) $$
        This transforms the 3D position and its uncertainty into a higher-dimensional space suitable for positional encoding [S1, unofficial].
    c.  **Integrated Positional Encoding**: Compute the input features $x$ by applying integrated positional encoding to the lifted means and variances:
        $$ x = \text{coord.integrated\_pos\_enc}(\text{lifted\_means}, \text{lifted\_vars}, \text{min\_deg\_point}, \text{max\_deg\_point}) $$
        This step integrates the positional encoding over the cone of integration, effectively anti-aliasing the signal [S1, unofficial].

4.  **Density Network Forward Pass**:
    Iterate $i$ from 0 to `net_depth` - 1:
    a.  Apply a dense layer with width `net_width` and activation `net_activation` to $x$.
    b.  If $i > 0$ and $i \% \text{skip\_layer} == 0$, concatenate $x$ with the original input to this layer along the last axis (skip connection) [S1, unofficial].
    c.  Output raw density:
        $$ \text{raw\_density} = \text{dense\_layer}(1)(x)[..., 0] $$
    d.  If `density_noise` > 0, add Gaussian noise:
        $$ \text{raw\_density} \leftarrow \text{raw\_density} + \text{density\_noise} \times \mathcal{N}(0, 1) $$
        where the noise is sampled using `density_key` [S1, unofficial].

5.  **Normal Computation (Optional)**:
    If `disable_density_normals` is False:
    a.  Flatten means and covs.
    b.  Compute the gradient of the raw density with respect to the input position using automatic differentiation (e.g., `jax.value_and_grad`). This yields `raw_grad_density` [S1, unofficial].
    c.  Compute normals as the negative normalized gradient:
        $$ \mathbf{n}_{pred} = -\frac{\text{raw\_grad\_density}}{\|\text{raw\_grad\_density}\|_2} $$
        Using raw density ensures numerical stability compared to post-activation density [S1, unofficial].

6.  **Density Activation**:
    Apply the final density activation:
    $$ \sigma_{final} = \text{density\_activation}(\text{raw\_density} + \text{density\_bias}) $$
    Typically, this is a softplus function [S1, unofficial].

7.  **Color Network Input Preparation**:
    a.  **Directional Encoding**: Compute directional encoding `dir_enc` using `dir_enc_fn` on the viewing direction (or reflection direction if `use_reflections` is True). Note: If using reflections, flip the view direction (`-viewdirs`) before reflection because the convention differs [S1, unofficial].
    b.  **Broadcasting**: Broadcast `dir_enc` to match the bottleneck shape dimensions.
    c.  **Concatenation**:
        -   Initialize input list $x_{color}$ with the bottleneck vector from the density network.
        -   Append `dir_enc` to $x_{color}$.
        -   If `use_n_dot_v` is True, compute $\mathbf{n} \cdot \mathbf{v}$ and append it.
        -   If `glo_vec` is not None, broadcast and append it.
        -   Concatenate all elements in $x_{color}$ along the last axis [S1, unofficial].

8.  **Color Network Forward Pass**:
    Iterate $i$ from 0 to `net_depth_viewdirs` - 1:
    a.  Apply a dense layer with width `net_width_viewdirs` and activation `net_activation` to $x_{color}$.
    b.  If $i > 0$ and $i \% \text{skip\_layer\_dir} == 0$, concatenate $x_{color}$ with the original input to this layer along the last axis (skip connection) [S1, unofficial].

9.  **RGB Output**:
    a.  Compute raw RGB:
        $$ \text{raw\_rgb} = \text{dense\_layer}(\text{num\_rgb\_channels})(x_{color}) $$
    b.  Apply activation and bias:
        $$ \mathbf{c} = \text{rgb\_activation}(\text{rgb\_premultiplier} \times \text{raw\_rgb} + \text{rgb\_bias}) $$
    c.  **Specular/Diffuse Split (Optional)**:
        -   If `use_diffuse_color` is True, compute diffuse color:
            $$ \mathbf{c}_{diffuse} = \sigma(\text{raw\_rgb}_{diffuse} - \ln(3.0)) $$
        -   If `use_specular_tint` is True, compute specular tint:
            $$ \mathbf{c}_{specular} = \text{tint} \times \mathbf{c} $$
            Else:
            $$ \mathbf{c}_{specular} = 0.5 \times \mathbf{c} $$
        -   Combine and tone map:
            $$ \mathbf{c}_{final} = \text{clip}(\text{linear\_to\_srgb}(\mathbf{c}_{specular} + \mathbf{c}_{diffuse}), 0.0, 1.0) $$
    d.  **RGB Padding**:
        $$ \mathbf{c}_{final} = \mathbf{c}_{final} \times (1 + 2 \times \text{rgb\_padding}) - \text{rgb\_padding} $$
        This maps the color to $[-\text{rgb\_padding}, 1+\text{rgb\_padding}]$ [S1, unofficial].

### Pseudocode

```python
import jax.numpy as jnp
import jax
from jax import random

def mipnerf360_mlp_forward(params, x, cov, viewdirs, config, rng=None):
    """
    Forward pass for Mip-NeRF 360 MLP.
    
    Args:
        params: Dictionary of network weights.
        x: 3D position, shape (..., 3).
        cov: Covariance matrix, shape (..., 3, 3).
        viewdirs: Viewing direction, shape (..., 3).
        config: Configuration object with hyperparameters.
        rng: JAX PRNGKey for noise.
        
    Returns:
        density: Final volume density.
        rgb: Final RGB color.
        normals: Predicted normals (if enabled).
    """
    # 1. Setup
    if config.use_reflections:
        if not config.enable_pred_normals and config.disable_density_normals:
            raise ValueError("Reflections require normals to be computed.")
    
    # Precompute basis transpose (done once during init)
    pos_basis_t = config.pos_basis_t
    
    # 2. Directional Encoding
    if config.use_directional_enc:
        dir_enc_fn = ref_utils.generate_ide_fn(config.deg_view)
    else:
        dir_enc_fn = lambda d: coord.pos_enc(d, min_deg=0, max_deg=config.deg_view, append_identity=True)
        
    # Handle reflection direction
    if config.use_reflections:
        # Flip viewdirs because they point from camera to point, 
        # but reflect function assumes they point toward camera
        refdirs = ref_utils.reflect(-viewdirs, normals)
        dir_enc = dir_enc_fn(refdirs)
    else:
        dir_enc = dir_enc_fn(viewdirs)
        
    # 3. Density Network
    # Warp if necessary
    if config.warp_fn is not None:
        means, covs = coord.track_linearize(config.warp_fn, x, cov)
    else:
        means, covs = x, cov
        
    # Lift and diagonalize
    lifted_means, lifted_vars = coord.lift_and_diagonalize(means, covs, pos_basis_t)
    
    # Integrated Positional Encoding
    x_enc = coord.integrated_pos_enc(lifted_means, lifted_vars, 
                                     config.min_deg_point, config.max_deg_point)
    
    # Density MLP
    x = x_enc
    for i in range(config.net_depth):
        x = nn.Dense(config.net_width, name=f'density_mlp_{i}')(x)
        x = config.net_activation(x)
        if i > 0 and i % config.skip_layer == 0:
            x = jnp.concatenate([x, x_enc], axis=-1)
            
    raw_density = nn.Dense(1, name='density_out')(x)[..., 0]
    
    # Density Noise
    if config.density_noise > 0 and rng is not None:
        noise = random.normal(rng, raw_density.shape)
        raw_density += config.density_noise * noise
        
    # Density Activation
    density = config.density_activation(raw_density + config.density_bias)
    
    # 4. Normals (Optional)
    normals = None
    if not config.disable_density_normals:
        # Compute gradient of raw_density w.r.t x
        def predict_density(x_in):
            # Re-run density network for x_in to get raw_density
            # This is simplified; in practice, use jax.value_and_grad on the whole block
            pass 
        # Using jax.vmap for batched gradient computation
        raw_grad_density = jax.vmap(jax.value_and_grad(lambda x_in: predict_density(x_in), has_aux=True))(x)
        normals = -ref_utils.l2_normalize(raw_grad_density)
        
    # 5. Color Network
    # Broadcast dir_enc
    dir_enc = jnp.broadcast_to(dir_enc[..., None, :], 
                               jnp.array(density.shape[:-1] + (dir_enc.shape[-1],)))
                               
    x_color = [density, dir_enc]
    
    if config.use_n_dot_v and normals is not None:
        n_dot_v = jnp.sum(normals * viewdirs[..., None, :], axis=-1, keepdims=True)
        x_color.append(n_dot_v)
        
    if config.glo_vec is not None:
        glo_vec = jnp.broadcast_to(config.glo_vec, density.shape[:-1] + (config.glo_vec.shape[-1],))
        x_color.append(glo_vec)
        
    x_color = jnp.concatenate(x_color, axis=-1)
    
    # Color MLP
    for i in range(config.net_depth_viewdirs):
        x_color = nn.Dense(config.net_width_viewdirs, name=f'color_mlp_{i}')(x_color)
        x_color = config.net_activation(x_color)
        if i > 0 and i % config.skip_layer_dir == 0:
            x_color = jnp.concatenate([x_color, x_color], axis=-1) # Skip connection
            
    raw_rgb = nn.Dense(config.num_rgb_channels, name='color_out')(x_color)
    rgb = config.rgb_activation(config.rgb_premultiplier * raw_rgb + config.rgb_bias)
    
    # Specular/Diffuse Split
    if config.use_diffuse_color:
        raw_rgb_diffuse = raw_rgb # Assuming raw_rgb contains diffuse component or separate output
        diffuse_linear = jnp.sigmoid(raw_rgb_diffuse - jnp.log(3.0))
        if config.use_specular_tint:
            specular_linear = config.tint * rgb
        else:
            specular_linear = 0.5 * rgb
        rgb = jnp.clip(image.linear_to_srgb(specular_linear + diffuse_linear), 0.0, 1.0)
        
    # RGB Padding
    rgb = rgb * (1 + 2 * config.rgb_padding) - config.rgb_padding
    
    return density, rgb, normals
```

### Edge Cases and Pitfalls
-   **Reflections and Normals**: If `use_reflections` is True, normals must be computed. If `enable_pred_normals` is False and `disable_density_normals` is True, a `ValueError` is raised [S1, unofficial].
-   **Reflection Direction Flip**: View directions point from camera to point, but reflection functions often assume they point toward the camera. Flip viewdirs (`-viewdirs`) before reflection [S1, unofficial].
-   **Normal Stability**: Compute normals from the gradient of raw (pre-activation) density, not post-activation density, for numerical stability [S1, unofficial].
-   **Precision**: Use float64 for color correction and metric computation to ensure high precision [S1, unofficial].

## Operating characteristics
-   **Time Complexity**: The density network has $O(\text{net\_depth} \times \text{net\_width}^2)$ complexity per sample. The color network has $O(\text{net\_depth\_viewdirs} \times \text{net\_width\_viewdirs}^2)$. The integrated positional encoding adds overhead proportional to the number of frequency bands ($\text{max\_deg\_point}$).
-   **Memory Complexity**: The model stores weights for the MLPs. The basis matrix for IPE is precomputed and stored.
-   **Performance**: Mip-NeRF 360 is designed for large-scale, unbounded scenes. The integrated positional encoding reduces aliasing artifacts, leading to higher quality renders at varying distances without requiring explicit multi-resolution hierarchies in the encoding itself.
-   **Strengths**: Handles aliasing naturally, supports reflections and specular highlights, robust to varying scene scales.
-   **Limitations**: Slightly higher computational cost per sample due to IPE and potential normal computation. Requires careful tuning of `density_bias` and `rgb_padding`.

## Background
The Mip-NeRF 360 MLP architecture was introduced in the "Mip-NeRF 360" paper by Barron et al. (2022) [S1, unofficial]. It extends the original Mip-NeRF concept to 360-degree scenes, addressing the challenge of rendering large, unbounded environments with consistent quality across different scales. The key contribution is the integration of positional encoding over the cone of integration, which acts as a low-pass filter, reducing high-frequency aliasing.
