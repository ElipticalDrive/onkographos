# Lighting and Appearance Models

Also called: Appearance Conditioning, Illumination Modeling in NeRF

## Overview
Lighting and Appearance Models modify the standard NeRF architecture to explicitly handle view-dependent effects, varying illumination, or artistic stylization, which the baseline MLP struggles to represent efficiently [14428-sparse-view-and-few-shot-optimization.md]. Unlike siblings that focus on geometric representations or sparse views, this family addresses the semantic gap in lighting control and the computational cost of high-frequency appearance variations [13783-neural-pre-integrated-lighting-neural-pil.md; 14480-spherical-harmonics-nerf.md; 14882-stylizednerf.md].

## Shared principles
The standard NeRF architecture [Parent](3065-nerf-hyperparameters.md) serves as the baseline for most modifications. It consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ [14428-sparse-view-and-few-shot-optimization.md].

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories [14428-sparse-view-and-few-shot-optimization.md]:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation [14428-sparse-view-and-few-shot-optimization.md].
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs).

## Subtopics

### [Neural Pre-Integrated Lighting (Neural-PIL)](13783-neural-pre-integrated-lighting-neural-pil.md)
Neural-PIL replaces costly numerical integration of incoming light with a neural network query, predicting pre-integrated light $\tilde{L}_i$ directly from illumination embedding, direction, and roughness [13783-neural-pre-integrated-lighting-neural-pil.md]. It differs from Spherical Harmonics by capturing finer illumination details without high memory costs [13783-neural-pre-integrated-lighting-neural-pil.md]. Choose this when explicit, high-fidelity relighting with material roughness is required.

### [Spherical Harmonics NeRF](14480-spherical-harmonics-nerf.md)
Spherical Harmonics NeRF replaces the view-dependent color MLP with an explicit 2nd-order Spherical Harmonics (SH) illumination model [14480-spherical-harmonics-nerf.md]. It allows explicit relighting by varying learnable SH coefficients, addressing the lack of semantic meaning in standard NeRF [14480-spherical-harmonics-nerf.md]. It differs from Neural-PIL by using a global SH basis rather than pre-integrated local lighting [14480-spherical-harmonics-nerf.md]. Choose this for efficient, explicit lighting control in static scenes.

### [StylizedNeRF](14882-stylizednerf.md)
StylizedNeRF integrates a style-based generator into the NeRF framework for high-resolution 3D-aware image synthesis [14882-stylizednerf.md]. It solves the problem of generating consistent, stylized 3D objects by combining a NeRF++ backbone with StyleGAN2-style synthesis networks [14882-stylizednerf.md]. It differs from lighting-focused siblings by natively synthesizing artistic style during reconstruction [14882-stylizednerf.md]. Choose this for artistic 3D generation rather than photorealistic lighting.

## Background
The standard NeRF formulation [Parent](3065-nerf-hyperparameters.md) assumes fixed lighting and view-dependent appearance is captured implicitly by the view-direction input to the color MLP [14428-sparse-view-and-few-shot-optimization.md]. This approach lacks explicit lighting control and struggles with high-frequency variations or varying illumination conditions [14480-spherical-harmonics-nerf.md]. Subsequent works introduced explicit lighting models (SH, Neural-PIL) and generative style priors (StylizedNeRF) to address these limitations [13783-neural-pre-integrated-lighting-neural-pil.md; 14480-spherical-harmonics-nerf.md; 14882-stylizednerf.md].
