# CCNeRF

Also called: CCNeRF, Rank-residual Decomposition NeRF

## Overview
CCNeRF is a neural field representation that enables efficient compression and composition of 3D scenes by learning a hybrid tensor rank decomposition of the scene without using neural networks for rendering [S1]. Unlike NeRF variants that rely on shared MLP renderers (e.g., NSVF) or hybrid tensor-MLP approaches (e.g., TensoRF), CCNeRF models the radiance field *only* with tensor rank decomposition, preserving low-rank approximation properties to allow dynamic model size adjustment via rank truncation and arbitrary composition via rank concatenation [S1].

## How it works
CCNeRF represents a 3D scene as a 4D feature volume described by rank components and a weight matrix. The method replaces the implicit MLP decoding of standard NeRF with explicit tensor operations, allowing the scene to be queried, compressed, and composed using linear algebra operations [S1].

### Inputs and Outputs
*   **Input:** 3D spatial coordinate $\mathbf{x} = (x, y, z)$ and viewing direction $\mathbf{d} = (\theta, \phi)$.
*   **Output:** Volume density $\sigma \in \mathbb{R}$ and color $\mathbf{c} \in \mathbb{R}^3$.

### Data Structures
The model structure consists of two main parts [S1]:
1.  **Rank Weights Matrix ($W$):** A matrix storing weights for different feature channels. The dimensions are $R_{vec} + R_{mat} \times G$, where $G$ is the number of feature channels (typically 4 for $\sigma, r, g, b$).
2.  **Decomposed Rank Components:** A set of components that are either vector-based (CP decomposition) or matrix-based (triple plane variant).
    *   **Vector-based (CP):** Factor matrices $U^x, U^y, U^z \in \mathbb{R}^{H \times R_{vec}}$, $U^y, U^z, U^x \in \mathbb{R}^{W \times R_{vec}}$, etc. (Note: The source describes a hybrid approach where some ranks use vectors and others use planes).
    *   **Matrix-based (Triple Plane):** Factor matrices $U^{xy}, U^{yz}, U^{zx} \in \mathbb{R}^{D \times R_{mat}}$ (where $D$ is the resolution of the planes).
    *   The ratio of vector- to matrix-based components is controllable.

### Formulas
**Volume Rendering Equation:**
The final pixel color $\hat{C}(r)$ for a ray $r$ is computed using standard volume rendering [S1]:
$$ \hat{C}(r) = \sum_i T_i \alpha_i c_i $$
where:
*   $T_i = \prod_{j<i} (1 - \alpha_j)$ is the accumulated transmittance.
*   $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ is the opacity of the $i$-th sample.
*   $\delta_i = t_{i+1} - t_i$ is the distance between samples.
*   $\sigma_i$ and $c_i$ are the density and color queried at sample position $t_i$ along ray $r$ from origin $o$ with direction $d$.

**Tucker Decomposition (Preliminaries):**
The source cites the general Tucker decomposition for a 3D tensor $T \in \mathbb{R}^{H \times W \times D}$ as [S1]:
$$ T_{i,j,k} = \sum_{p=1}^P \sum_{q=1}^Q \sum_{r=1}^R S_{p,q,r} U^x_{i,p} U^y_{j,q} U^z_{k,r} $$
where $S$ is the core tensor and $U^x, U^y, U^z$ are factor matrices. CCNeRF adapts this concept to the radiance field features.

**Querying a 3D Coordinate:**
To query a coordinate $\mathbf{x}$, the method performs weighted interpolation using the stored rank weights [S1]:
1.  Project the coordinate $\mathbf{x}$ to the decomposed vectors or matrices.
2.  Perform weighted interpolation using the rank weights matrix $W$.

Specifically, for a hybrid CP/Plane decomposition, the feature vector $f(\mathbf{x})$ is constructed by concatenating contributions from vector-based and matrix-based ranks. For a vector-based rank $k$, the contribution is $\sum_{d \in \{x,y,z\}} U^d_{x_d, k}$. For a matrix-based rank $k$, the contribution involves the triple planes (e.g., $U^{xy}_{x,y,k}$). The final features are obtained by multiplying these aggregated spatial features by the weight matrix $W$ [S1].

### Parameters
*   **Rank ($R$):** The number of components kept in the decomposition. This determines the model size and detail level. Lower ranks preserve primary information due to rank-residual learning [S1].
*   **Resolution ($H, W, D$):** The resolution of the factor matrices/planes.
*   **Feature Channels ($G$):** The number of output channels (typically 4: density + RGB).

### Steps
1.  **Training (Rank-Residual Learning):**
    *   Initialize the rank components and weight matrix.
    *   Use a rank-residual learning strategy to encourage lower ranks to preserve more important information of the whole scene [S1]. This ensures that when ranks are truncated, the most significant features are retained.
2.  **Compression (Rank Truncation):**
    *   To compress the model, apply an empirical sort-and-truncate strategy to the rank components [S1].
    *   Sort the ranks based on their importance (derived from the rank-residual learning) and truncate the least important ones.
    *   This achieves near-optimal low-rank approximation at any targeted rank without retraining [S1].
3.  **Composition:**
    *   To compose different models (objects) into one scene, concatenate their rank components along the rank dimension [S1].
    *   Record a transformation matrix for each object to control its position and orientation in the scene.
    *   Since there are no MLP renderers, different models can be arbitrarily transformed and composed without compatibility constraints or retraining [S1].

### Edge Cases and Pitfalls
*   **Truncation Optimality:** Standard truncated HOSVD does not hold the optimal property of truncated SVD, but yields a quasi-optimal solution sufficient for practical use [S1].
*   **Composition Growth:** Composing many objects can lead to large model sizes. This can be mitigated by compressing unimportant objects in the composed scene [S1].

## Operating characteristics
*   **Time Complexity:** Querying is faster than MLP-based NeRF as it involves only tensor lookups and linear operations [S1].
*   **Memory Complexity:** Model size is determined by the rank $R$ and resolution of factor matrices. Compression is achieved by reducing $R$ [S1].
*   **Strengths:**
    *   No neural networks for rendering, enabling arbitrary composition without retraining [S1].
    *   Dynamic trade-off between model size and rendering quality via rank truncation without retraining [S1].
    *   Near-optimal compression [S1].
*   **Limitations:**
    *   Quasi-optimal truncation (not strictly optimal like SVD) [S1].
    *   Requires careful tuning of the ratio of vector- to matrix-based components [S1].

## Background
CCNeRF was introduced by Jiaxiang Tang, Xiaokang Chen, Jingbo Wang, and Gang Zeng in 2022 [S1]. It addresses the difficulty of manipulating NeRF models (like compression and composition) caused by their implicit representation and shared renderer networks [S1]. The method is motivated by the low-rank approximation property of the SVD algorithm and builds on tensor decomposition techniques used in other vision tasks [S1]. It contrasts with TensoRF, which uses MLPs that prevent compression/composition [S1].
