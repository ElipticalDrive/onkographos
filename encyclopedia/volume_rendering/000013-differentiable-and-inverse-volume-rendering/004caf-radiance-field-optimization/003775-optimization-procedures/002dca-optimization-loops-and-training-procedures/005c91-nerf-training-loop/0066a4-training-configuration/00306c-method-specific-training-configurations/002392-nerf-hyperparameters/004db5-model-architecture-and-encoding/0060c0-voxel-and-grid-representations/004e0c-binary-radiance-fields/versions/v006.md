# Binary Radiance Fields

Also called: BRF

## Overview
Binary Radiance Fields (BiRF) is a storage-efficient radiance field representation that constrains feature encoding parameters in multi-resolution grids to binary values $\{-1, +1\}$, reducing storage overhead to approximately 0.5 MB for standard scenes [S1]. Unlike post-processing compression methods such as PlenOctrees or Re:NeRF, which require additional optimization steps and are bounded by pre-trained model performance, BiRF performs binarization during training, achieving superior reconstruction quality with significantly smaller storage footprints than state-of-the-art efficient models like Instant-NGP or TensoRF [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D spatial coordinate $\mathbf{x} \in \mathbb{R}^3$, viewing direction $\mathbf{d} \in \mathbb{R}^3$.
*   **Output:** Volume density $\sigma \in \mathbb{R}$, color vector $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures:**
The representation consists of a multi-resolution 2D-3D hybrid feature grid implemented using hash encoding [S1].
1.  **3D Voxel Grid ($\Phi_{\theta_{xyz}}$):** Contains $L$ resolution levels. Resolutions range from 16 to 1024. Each level stores up to $T_{3D}$ feature vectors.
2.  **2D Plane Grids ($\Phi_{\theta_{xy}}, \Phi_{\theta_{xz}}, \Phi_{\theta_{yz}}$):** Three orthogonal planes. Each contains $M$ resolution levels. Resolutions range from 64 to 512. Each level stores up to $T_{2D}$ feature vectors.
3.  **Parameter Storage:** All grid parameters are binary, stored as 1-bit values $\{-1, +1\}$ [S1].
4.  **MLPs:**
    *   Density MLP: 1 hidden layer, 128 channels, ReLU activation.
    *   Color MLP: 2 hidden layers, 128 channels, ReLU activation.
    *   Total MLP storage: 0.06–0.11 MB depending on feature dimension [S1].

**Parameters:**
*   $L$: Number of 3D grid levels.
*   $M$: Number of 2D grid levels.
*   $T_{3D}$: Max feature vectors per 3D level.
*   $T_{2D}$: Max feature vectors per 2D level.
*   $F$: Feature dimension per level.
*   Model Variants:
    *   Small (Ours-S): $\log_2(T_{3D}) = 17$, $\log_2(T_{2D}) = 15$.
    *   Base (Ours-B): $\log_2(T_{3D}) = 19$, $\log_2(T_{2D}) = 17$.
    *   Suffix indicates $F \in \{2, 4, 8\}$ (e.g., Ours-B2 has $F=2$) [S1].
*   $\lambda_{\text{sparsity}}$: Sparsity loss weight, typically $2.0 \times 10^{-5}$ [S1].
*   Optimizer: Adam, initial learning rate 0.01, decayed by factor 0.33 at iterations 15,000 and 18,000. Warm-up for first 1,000 iterations [S1].

**Steps:**

1.  **Binarization:**
    Real-valued grid parameters $\theta$ are constrained to binary values $\theta'$ using the sign function:
    $$
    \theta' = \text{sign}(\theta) = \begin{cases} +1 & \text{if } \theta \ge 0 \\ -1 & \text{otherwise} \end{cases}
    $$
    Gradients are propagated using the Straight-Through Estimator (STE). The gradient is passed if $|\theta| \le 1$, otherwise it is stopped to prevent scale divergence [S1].

2.  **Feature Encoding (3D):**
    For input coordinate $\mathbf{x}$, compute features from the 3D grid by linearly interpolating binary parameters across $L$ resolution levels and concatenating them:
    $$
    \mathbf{f}_{xyz} = \left\{ \text{interp}(\mathbf{x}, \text{sign}(\Phi^l_{\theta_{xyz}})) \right\}_{l=1}^L
    $$
    where $\text{interp}$ denotes tri-linear interpolation [S1].

3.  **Feature Encoding (2D):**
    Project $\mathbf{x}=(x,y,z)$ to 2D coordinates: $\mathbf{x}_{xy}=(x,y)$, $\mathbf{x}_{xz}=(x,z)$, $\mathbf{x}_{yz}=(y,z)$. For each axis, interpolate binary parameters across $M$ resolution levels and concatenate:
    $$
    \mathbf{f}_{xy} = \left\{ \text{interp}(\mathbf{x}_{xy}, \text{sign}(\Phi^m_{\theta_{xy}})) \right\}_{m=1}^M
    $$
    Repeat for $\mathbf{f}_{xz}$ and $\mathbf{f}_{yz}$ using bi-linear interpolation. The 2D grids alleviate hash collisions present in the 3D grid at higher resolutions [S1].

4.  **Feature Concatenation:**
    Combine all encoded features:
    $$
    \mathbf{f} = \{ \mathbf{f}_{xyz}, \mathbf{f}_{xy}, \mathbf{f}_{xz}, \mathbf{f}_{yz} \}
    $$

5.  **Positional Encoding:**
    Apply sinusoidal positional encoding $\gamma(\mathbf{x})$ to the input 3D coordinate [S1].

6.  **Density Prediction:**
    Feed positional encoded coordinates $\gamma(\mathbf{x})$ and features $\mathbf{f}$ into the density MLP:
    $$
    (\sigma, \mathbf{e}) = \text{MLP}_{\text{density}}(\gamma(\mathbf{x}), \mathbf{f})
    $$
    where $\sigma$ is density and $\mathbf{e}$ is the embedded feature [S1].

7.  **Color Prediction:**
    Encode direction $\mathbf{d}$ using spherical harmonics basis functions. Feed embedded feature $\mathbf{e}$ and directional encoding into the color MLP:
    $$
    \mathbf{c} = \text{MLP}_{\text{color}}(\mathbf{e}, \mathbf{d})
    $$

**Pseudocode:**

```python
import math

def sign(x):
    """Binary binarization: +1 if x >= 0, else -1."""
    return 1.0 if x >= 0.0 else -1.0

def ste_sign(x):
    """Straight-Through Estimator for sign function.
    Gradient is 1 if |x| <= 1, else 0.
    """
    binary = sign(x)
    # Gradient logic is handled by the autograd engine in practice,
    # but conceptually:
    # if abs(x) <= 1: grad = 1.0
    # else: grad = 0.0
    return binary

def tri_linear_interp(grid, x, y, z):
    """Interpolate binary parameters from 3D grid.
    grid: list of 3D arrays for each resolution level.
    x, y, z: normalized coordinates in [0, 1].
    Returns concatenated features from all levels.
    """
    features = []
    for level in grid:
        # Perform tri-linear interpolation on binary values
        val = interpolate_3d(level, x, y, z)
        features.append(val)
    return concat(features)

def bi_linear_interp(grid, u, v):
    """Interpolate binary parameters from 2D grid.
    grid: list of 2D arrays for each resolution level.
    u, v: normalized coordinates in [0, 1].
    Returns concatenated features from all levels.
    """
    features = []
    for level in grid:
        val = interpolate_2d(level, u, v)
        features.append(val)
    return concat(features)

def positional_encoding(x, num_frequencies=10):
    """Sinusoidal positional encoding."""
    # Standard NeRF PE implementation
    pe = []
    for i in range(num_frequencies):
        freq = 2.0 ** i * math.pi
        pe.append(math.sin(freq * x))
        pe.append(math.cos(freq * x))
    return pe

def train_step(rays, grids, mlp_density, mlp_color, optimizer):
    """Single training step."""
    # 1. Sample rays and get coordinates x and directions d
    x, d = sample_rays(rays)
    
    # 2. Feature Encoding
    # 3D Grid
    f_xyz = tri_linear_interp(grids['3d'], x.x, x.y, x.z)
    
    # 2D Grids
    f_xy = bi_linear_interp(grids['2d_xy'], x.x, x.y)
    f_xz = bi_linear_interp(grids['2d_xz'], x.x, x.z)
    f_yz = bi_linear_interp(grids['2d_yz'], x.y, x.z)
    
    # Concatenate
    f = concat([f_xyz, f_xy, f_xz, f_yz])
    
    # 3. Positional Encoding
    pe_x = positional_encoding(x)
    
    # 4. Density Prediction
    sigma, e = mlp_density(pe_x, f)
    
    # 5. Color Prediction
    # Directional encoding using spherical harmonics
    d_sh = spherical_harmonics(d)
    c = mlp_color(e, d_sh)
    
    # 6. Loss Calculation
    # Reconstruction Loss
    L_recon = mean_squared_error(c, target_color)
    
    # Sparsity Loss
    # L_sparsity = sum(log(1 + 2 * sigma^2))
    L_sparsity = sum(math.log(1 + 2 * sigma**2))
    
    lambda_sparsity = 2.0e-5
    L_total = L_recon + lambda_sparsity * L_sparsity
    
    # 7. Optimization
    optimizer.zero_grad()
    L_total.backward()
    optimizer.step()
    
    return L_total
```

**Edge Cases and Pitfalls:**
*   **Hash Collisions:** 3D grids suffer from hash collisions at higher resolutions. The 2D grids supplement the 3D grid, alleviating collision impact and reinforcing features with fewer parameters [S1].
*   **Gradient Vanishing:** The derivative of the sign function is zero almost everywhere. The STE solves this by passing gradients through the threshold function during training [S1].
*   **Scale Divergence:** Large values of $\theta$ can cause divergence. STE stops propagating gradients when $|\theta| > 1$, constraining the value to $\{-1, 1\}$ [S1].

## Operating characteristics
*   **Storage:** Extremely compact. Ours-S2 requires < 0.5 MB, outperforming baselines like TensoRF-CP (3.7 MB) and Instant-NGP (24.5 MB) on the mic scene while maintaining comparable or better PSNR [S1]. Total MLP storage is 0.06–0.11 MB [S1].
*   **Performance:** PSNR of 32.03 dB for Synthetic-NeRF, 34.48 dB for Synthetic-NSVF, and 28.20 dB for Tanks and Temples [S1].
*   **Training Time:** Approximately 6, 9, and 14 minutes for Synthetic-NeRF scenes for Ours-B2 to Ours-B8 models respectively, on a single NVIDIA RTX A6000 [S1].
*   **Strengths:** Storage efficiency without post-optimization; superior reconstruction quality compared to other efficient methods.
*   **Limitations:** Performance is bounded by the binary representation capacity; may struggle with extremely high-frequency details compared to full-precision models if grid resolution is insufficient.

## Background
Binary Radiance Fields were proposed by Seungjoo Shin and Jaesik Park from POSTECH and Seoul National University, published in December 2023 [S1]. The work builds upon Instant-NGP and NerfAcc, aiming to make radiance fields more accessible by removing storage bottlenecks [S1].
