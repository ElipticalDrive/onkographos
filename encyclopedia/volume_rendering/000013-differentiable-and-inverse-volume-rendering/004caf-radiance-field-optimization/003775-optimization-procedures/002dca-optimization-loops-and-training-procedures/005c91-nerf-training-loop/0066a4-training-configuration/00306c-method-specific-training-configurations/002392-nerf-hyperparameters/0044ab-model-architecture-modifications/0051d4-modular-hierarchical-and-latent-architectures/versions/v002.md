# Modular, Hierarchical, and Latent Architectures


## Overview
Modular, Hierarchical, and Latent Architectures extend the standard NeRF baseline [Parent](11313-model-architecture-modifications.md) by introducing discrete latent codes, higher-dimensional ambient spaces, or modular routing mechanisms to handle complex scene properties that continuous MLPs struggle with, such as topological discontinuities, hierarchical structures, or non-rigid deformations. Unlike standard NeRFs which map coordinates directly to radiance, these methods condition the radiance field on auxiliary latent representations (e.g., deformation codes, VQ indices, or expert tokens) to decouple scene geometry, appearance, and structure. This family sets itself apart from siblings like [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md) by retaining continuous coordinate-based querying while using discrete or latent conditioning to manage complexity, and from [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md) by focusing on radiance field conditioning rather than implicit surface extraction.

## Shared principles
The standard NeRF architecture [Parent](3065-nerf-hyperparameters.md) serves as the baseline for most modifications. It consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ [14428-sparse-view-and-few-shot-optimization.md].

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories [14428-sparse-view-and-few-shot-optimization.md]:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation [14428-sparse-view-and-few-shot-optimization.md].
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs).

## Subtopics

### [HyperNeRF](13906-hypernerf.md)
HyperNeRF models non-rigidly deforming scenes with topological variations by embedding the scene in $\mathbb{R}^{3+W}$ and representing each observation as a non-planar slice through this hyperdimensional volume. It sets itself apart from siblings like Strata-NeRF by explicitly addressing topological discontinuities via ambient dimensions rather than stratified sampling or hierarchical structures.

### [Strata-NeRF](14015-strata-nerf.md)
Strata-NeRF models "stratified scenes" with distinct hierarchical levels (e.g., building exterior/interior) using discrete Vector Quantized (VQ) latent codes to explicitly represent scene hierarchy, allowing for sharp transitions between levels within a single unified network. It sets itself apart from siblings like HyperNeRF by using discrete VQ latents rather than continuous ambient coordinates to handle structural discontinuities.

### Strata-NeRF Architecture
Design choices for the Strata-NeRF Latent Router (LR) and Latent Generator (LG) indicate that using two parallel dense layers in the LR outperforms individual dense layers [S3]. The full Latent Router architecture is superior to direct concatenation of the generated embedding with positional encoding (D3) or substituting the VQ-VAE with a standard VAE (D4) [S3]. Disabling either the first (D2) or second (D1) router in the LR degrades performance compared to the full two-router configuration [S3].

## Background
The concept of modular and latent architectures in NeRFs emerged to address limitations in modeling complex, dynamic, or structurally diverse scenes using a single continuous MLP. HyperNeRF was introduced to handle topological changes (e.g., opening mouths) that standard deformation fields cannot model due to the band-limited nature of coordinate-based MLPs [S2, unofficial]. Strata-NeRF was developed to handle stratified scenes where standard NeRFs produce artifacts like haziness when trained jointly on distinct structural levels [S1]. These methods build on the foundational NeRF architecture [Parent](3065-nerf-hyperparameters.md) and related optimization techniques [14428-sparse-view-and-few-shot-optimization.md].
