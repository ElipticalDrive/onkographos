# StyleGAN2 Training Configuration

Also called: GAN Training Configuration, GSN Training Configuration, Generative Network Training Setup, StyleGAN2 Training Setup

## Overview
This configuration adapts the StyleGAN2 architecture for training 3D-aware generative models, specifically integrating it with differentiable volume rendering pipelines. It solves the problem of stable GAN training for high-resolution 3D synthesis by combining specific regularization, mixed-precision optimization, and architectural modifications. It is distinguished from standard NeRF training setups by its reliance on adversarial losses, equalized learning rates, and specific discriminator structures (such as minibatch standard deviation) rather than purely photometric reconstruction losses [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Real image batches (for discriminator), latent vectors (for generator), camera poses (for rendering).
*   **Outputs:** Generated 3D-aware images, discriminator scores, updated network weights.

**Data Structures:**
*   **Generator ($G$):** Maps latent space to 3D representation (e.g., voxel grid or radiance field) and then to 2D images via volume rendering.
*   **Discriminator ($D$):** Maps 2D images to scalar realism scores.
*   **Optimizer State:** Maintained per parameter group (typically RMSprop moments).

**Parameters:**
*   **Learning Rate ($\eta$):** 0.002 for main network layers [S2].
*   **Mapping Network Learning Rate:** $0.002 / 100 = 0.00002$ [S2].
*   **RMSprop Hyperparameters:** $\alpha = 0.99$, $\epsilon = 10^{-8}$ [S2].
*   **EMA Decay:** $\beta_{ema} = 0.999$ [S1, S2].
*   **R1 Regularization Strength ($\gamma$ or $\lambda_{R1}$):** 1.0 [S1] or 0.01 [S2].
*   **R1 Frequency:** Every 4 minibatches [S1] or every 16 iterations [S2].
*   **Batch Size:** 32 [S2].
*   **Resolution:** 64×64 [S2].
*   **Iterations:** 500,000 [S2].

**Steps:**

1.  **Initialize Networks:** Initialize Generator and Discriminator weights. Apply **Equalized Learning Rates** to all trainable parameters in the generator and discriminator to stabilize training dynamics [S1, S2].
2.  **Configure Optimizer:** Use RMSprop for both Generator and Discriminator with $\eta=0.002$, $\alpha=0.99$, $\epsilon=10^{-8}$ [S2]. Set the mapping network's learning rate to $1/100$ of the main network's rate [S2].
3.  **Prepare Discriminator:** Append a **Minibatch Standard Deviation** layer to the end of the discriminator architecture [S1, S2]. This layer computes the standard deviation of features across the batch dimension and concatenates it as an additional channel, helping the discriminator detect mode collapse [S1].
4.  **Apply Data Augmentation:** Apply differentiable data augmentations to all discriminator inputs. This includes random translation, color jitter, and Cutout [S2].
5.  **Forward Pass (Generator):**
    *   Sample latent vectors $\mathbf{z}$.
    *   Pass through mapping network (using reduced learning rate).
    *   Generate 3D representation.
    *   Render images using volume rendering (equidistant sampling, skipping low-density voxels) [S1].
6.  **Forward Pass (Discriminator):**
    *   Pass real images and generated images through the discriminator.
    *   Compute discriminator loss using adversarial loss (e.g., WGAN-GP or standard GAN loss, though specific loss function form is not detailed, R1 penalty is applied) [S1, S2].
7.  **Regularization (R1):**
    *   Calculate R1 gradient penalty on the discriminator.
    *   Apply this penalty every $K$ iterations (where $K=4$ per [S1] or $K=16$ per [S2]).
    *   Formula for R1 penalty: $\lambda_{R1} \sum (\nabla_{\mathbf{x}} D(\mathbf{x}))^2$ [S2].
    *   Strength $\lambda_{R1}$ is 1.0 [S1] or 0.01 [S2].
8.  **Backpropagation:** Compute gradients for both networks and update weights using RMSprop.
9.  **Exponential Moving Average (EMA):** Update the generator's weights with an EMA of the training weights using decay $\beta_{ema} = 0.999$ [S1, S2]. This stabilizes test-time performance.
10. **Mixed Precision:** Use mixed-precision training (FP16) for the generator [S1, S2]. Note: [S2] explicitly states mixed precision is **not** applied to the discriminator to maintain training stability, while [S1] states it is used for both.

**Pseudocode:**

```python
# Initialization
generator = StyleGAN2Generator()
discriminator = StyleGAN2Discriminator()
# Add minibatch std dev layer to discriminator
discriminator.add_minibatch_std_layer()

# Optimizers
opt_g = RMSprop(generator.parameters(), lr=0.002, alpha=0.99, eps=1e-8)
opt_d = RMSprop(discriminator.parameters(), lr=0.002, alpha=0.99, eps=1e-8)
# Mapping network lr is handled internally or by separate param group with lr=0.00002

# EMA state
ema_g = ExponentialMovingAverage(generator.parameters(), decay=0.999)

# Hyperparameters
r1_lambda = 1.0  # or 0.01 depending on source [S1, S2]
r1_freq = 4      # or 16 depending on source [S1, S2]
batch_size = 32
mixed_precision_g = True
mixed_precision_d = False # [S2] specifies False for D

for iteration in range(500000):
    # 1. Sample data
    real_images = sample_real_images(batch_size)
    latent_z = sample_latent(batch_size)
    
    # 2. Augment discriminator inputs
    real_images_aug = augment(real_images, methods=['translation', 'color_jitter', 'cutout'])
    
    # 3. Generator Forward
    if mixed_precision_g:
        with torch.cuda.amp.autocast():
            generated_images = generator(latent_z)
    else:
        generated_images = generator(latent_z)
        
    # 4. Discriminator Forward
    if mixed_precision_d:
        with torch.cuda.amp.autocast():
            d_real = discriminator(real_images_aug)
            d_fake = discriminator(generated_images.detach())
    else:
        d_real = discriminator(real_images_aug)
        d_fake = discriminator(generated_images.detach())
        
    # 5. Discriminator Loss
    # Assuming standard GAN loss or WGAN-GP variant
    loss_d = compute_adversarial_loss(d_real, d_fake)
    
    # 6. R1 Regularization (Lazy)
    if iteration % r1_freq == 0:
        # Compute R1 penalty on real images
        real_images_aug.requires_grad = True
        d_real_r1 = discriminator(real_images_aug)
        grad_real = torch.autograd.grad(
            outputs=d_real_r1.sum(), 
            inputs=real_images_aug, 
            create_graph=True
        )[0]
        r1_penalty = torch.sum(grad_real ** 2)
        loss_d += r1_lambda * r1_penalty
        
    # 7. Update Discriminator
    opt_d.zero_grad()
    loss_d.backward()
    opt_d.step()
    
    # 8. Generator Forward (for GAN loss)
    if mixed_precision_g:
        with torch.cuda.amp.autocast():
            generated_images_g = generator(latent_z)
            d_fake_g = discriminator(generated_images_g)
    else:
        generated_images_g = generator(latent_z)
        d_fake_g = discriminator(generated_images_g)
        
    # 9. Generator Loss
    loss_g = compute_adversarial_loss(d_fake_g) # Typically -mean(d_fake) for WGAN or similar
    
    # 10. Update Generator
    opt_g.zero_grad()
    loss_g.backward()
    opt_g.step()
    
    # 11. Update EMA
    ema_g.update(generator.parameters())
```

## Subtopics

### Conditional Discriminator with Skip Connections for Progressive Growing
A variant of the discriminator used in StyleGAN2-based 3D synthesis to facilitate progressive growing. It uses a conditional input and implements a skip architecture where a downsampled version of the input image is added to the input of each layer [S1]. This allows the model to train at increasing resolutions smoothly.

## Operating characteristics
*   **Time Complexity:** Training 64×64 models takes approximately 4 days on two NVIDIA A100 GPUs (40GB each) for 500k iterations with a batch size of 32 [S2].
*   **Memory Complexity:** Mixed precision is used to reduce memory cost. [S2] notes that mixed precision is applied only to the generator to preserve stability, while [S1] applies it to both.
*   **Scaling:** The configuration supports progressive growing via skip connections in the discriminator [S1].
*   **Strengths:** Stable training for high-resolution 3D generation; R1 regularization prevents mode collapse; EMA improves sample quality.
*   **Limitations:** High computational cost; mixed precision on the discriminator may cause instability [S2]; requires careful tuning of R1 frequency and strength due to source disagreement.
*   **When to use:** When training 3D-aware generative models (like StyleNeRF or GSN) that require the stability and quality of StyleGAN2 training dynamics.
*   **When not to use:** When computational resources are extremely limited (due to 4-day training times) or when using small datasets without pretraining (requires finetuning from FFHQ [S1]).

## Background
Originating from the StyleGAN2 architecture [22] and adapted for 3D-aware synthesis in works like VoxGRAF [S1] and GSN [S2]. The configuration combines techniques from StyleGAN2 [22], such as equalized learning rates [23] and minibatch standard deviation [19], with specific adaptations for volume rendering, such as lazy R1 regularization [29, 25] and mixed precision [20]. It addresses the challenges of training GANs in the context of differentiable rendering, where stability is paramount.
