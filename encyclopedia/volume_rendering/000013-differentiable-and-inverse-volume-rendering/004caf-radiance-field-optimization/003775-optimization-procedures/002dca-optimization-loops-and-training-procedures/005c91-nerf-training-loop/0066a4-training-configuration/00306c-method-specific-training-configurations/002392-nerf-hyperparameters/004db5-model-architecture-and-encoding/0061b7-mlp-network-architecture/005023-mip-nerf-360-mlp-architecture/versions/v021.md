# Mip-NeRF 360 MLP Architecture

Also called: Integrated Positional Encoding MLP, PosEnc MLP

## Overview
The Mip-NeRF 360 MLP architecture is a coordinate-based neural network that maps 3D spatial coordinates and viewing directions to volume density and color. It is distinguished from standard NeRF by its use of **Integrated Positional Encoding (IPE)** to handle anti-aliasing via integrated positional encoding, and its support for optional **Integrated Directional Encoding (IDE)** for view-dependent effects [S1, unofficial]. It builds on [Model Architecture and Encoding](13550-model-architecture-and-encoding.md) by replacing standard sinusoidal positional encoding with a basis-function-based integrated encoding that accounts for the spatial extent (covariance) of the query points.

## How it works
**Inputs:**
*   3D point coordinates $\mathbf{x} \in \mathbb{R}^3$ and their associated $3 \times 3$ covariance matrices $\Sigma \in \mathbb{R}^{3 \times 3}$ (representing the spatial extent of the query).
*   Viewing direction $\mathbf{d} \in S^2$ (or reflection direction $\mathbf{r} \in S^2$).
*   Optional normal vectors $\mathbf{n} \in S^2$.

**Outputs:**
*   Volume density $\sigma \in \mathbb{R}$.
*   Color $\mathbf{c} \in \mathbb{R}^3$.
*   Optional: Normals, roughness, diffuse/specular components.

**Data Structures:**
The architecture is defined by a configuration object containing the following fields:
*   `net_depth`: int (default 8). Depth of the density MLP.
*   `net_width`: int (default 256). Width of the density MLP.
*   `bottleneck_width`: int (default 256). Width of the feature vector connecting density and color networks.
*   `net_depth_viewdirs`: int (default 1). Depth of the color MLP.
*   `net_width_viewdirs`: int (default 128). Width of the color MLP.
*   `min_deg_point`, `max_deg_point`: int (default 0, 12). Degree range for point encoding.
*   `deg_view`: int (default 4). Degree for directional encoding.
*   `skip_layer`, `skip_layer_dir`: int (default 4). Skip connection frequency.
*   `density_bias`: float (default -1.0). Bias added to raw density.
*   `density_noise`: float (default 0.0). Standard deviation of density noise.
*   `rgb_bias`: float (default 0.0). Bias added to raw color.
*   `rgb_padding`: float (default 0.001). Padding for RGB output range.
*   `basis_shape`: str (default 'icosahedron'). Basis shape for IPE.
*   `basis_subdivisions`: int (default 2). Tessellation count for basis.
*   `use_reflections`: bool (default False). Use reflection directions.
*   `use_directional_enc`: bool (default False). Use IDE.
*   `use_diffuse_color`, `use_specular_tint`, `use_n_dot_v`: bools. Flags for advanced rendering features.
*   `enable_pred_normals`, `disable_density_normals`: bools. Controls normal computation.
*   `warp_fn`: Callable. Optional warping function for coordinates.

**Numbered Steps:**

1.  **Setup:**
    *   If `use_reflections` is True, ensure normals are enabled (`enable_pred_normals` is True or `disable_density_normals` is False). Raise `ValueError` otherwise [S1, unofficial].
    *   Precompute the transpose of the basis matrix $B^T$ using `geopoly.generate_basis(basis_shape, basis_subdivisions)` and store as `pos_basis_t` [S1, unofficial].
    *   If `use_directional_enc` is True, generate the Integrated Directional Encoding (IDE) function using `ref_utils.generate_ide_fn(deg_view)`. Otherwise, define `dir_enc_fn` using standard positional encoding with `min_deg=0`, `max_deg=deg_view`, and `append_identity=True` [S1, unofficial].

2.  **Coordinate Warping (Optional):**
    *   If `warp_fn` is not None, linearize the means and covariances: $(\tilde{\mu}, \tilde{\Sigma}) = \text{coord.track_linearize}(warp\_fn, \mu, \Sigma)$ [S1, unofficial].
    *   Otherwise, use $\mu$ and $\Sigma$ directly.

3.  **Lift and Diagonalize:**
    *   Lift the means and covariances into the basis space using the precomputed basis transpose:
        $$ \tilde{\mu} = B^T \mu, \quad \tilde{\Sigma} = B^T \Sigma B $$
        (Implemented via `coord.lift_and_diagonalize(means, covs, pos_basis_t)`) [S1, unofficial].
    *   Extract the diagonal elements of the lifted covariance to get lifted variances $\tilde{\sigma}^2$ [S1, unofficial].

4.  **Integrated Positional Encoding (IPE):**
    *   Compute the integrated positional encoding input $x$ using the lifted means $\tilde{\mu}$ and lifted variances $\tilde{\sigma}^2$:
        $$ x = \text{coord.integrated_pos_enc}(\tilde{\mu}, \tilde{\sigma}^2, min\_deg\_point, max\_deg\_point) $$
        This function integrates the sinusoidal basis functions over the Gaussian distribution defined by the mean and variance, providing anti-aliasing [S1, unofficial].

5.  **Density Network:**
    *   Initialize the feature vector $h = x$.
    *   Iterate $i$ from 0 to `net_depth` - 1:
        *   Apply a dense layer with width `net_width` and activation `net_activation` (e.g., ReLU): $h = \text{Activation}(W_i h + b_i)$.
        *   If $i > 0$ and $i \% \text{skip\_layer} == 0$, concatenate the original input $x$ to $h$: $h = \text{concat}(h, x)$ [S1, unofficial].
    *   Compute raw density: $\sigma_{raw} = \text{dense\_layer}_{1}(h)[..., 0]$ [S1, unofficial].
    *   If `density_noise` > 0, add Gaussian noise: $\sigma_{raw} \leftarrow \sigma_{raw} + \text{density\_noise} \cdot \mathcal{N}(0, 1)$ [S1, unofficial].
    *   Compute final density: $\sigma = \text{density\_activation}(\sigma_{raw} + \text{density\_bias})$ [S1, unofficial].

6.  **Normal Computation (Optional):**
    *   If `disable_density_normals` is False:
        *   Flatten $\mu$ and $\Sigma$ for batched gradient computation.
        *   Compute the gradient of the raw density with respect to the input coordinates using `jax.vmap(jax.value_and_grad(predict_density, has_aux=True))` [S1, unofficial].
        *   Compute normals: $\mathbf{n} = -\text{ref_utils.l2_normalize}(\nabla_\mu \sigma_{raw})$. Note: Normals are computed from the *raw* (pre-activation) density for numerical stability [S1, unofficial].

7.  **Directional Encoding:**
    *   Determine the direction vector $\mathbf{d}_{enc}$:
        *   If `use_reflections` is True, compute reflection direction $\mathbf{r} = 2(\mathbf{n} \cdot (-\mathbf{d}))\mathbf{n} + \mathbf{d}$ (note: viewdirs are flipped before reflection as they point from camera to point) [S1, unofficial].
        *   Apply `dir_enc_fn` to $\mathbf{d}_{enc}$ (or $\mathbf{r}$) to get encoded direction features $e_{dir}$ [S1, unofficial].
    *   Broadcast $e_{dir}$ to match the bottleneck shape dimensions [S1, unofficial].

8.  **Color Network Input Construction:**
    *   Initialize the input list $x_{color} = [\text{bottleneck\_features}]$.
    *   Append $e_{dir}$ to $x_{color}$ [S1, unofficial].
    *   If `use_n_dot_v` is True, compute $dot = \sum \mathbf{n} \cdot \mathbf{d}$ and append to $x_{color}$ [S1, unofficial].
    *   If `glo_vec` is not None, broadcast and append it to $x_{color}$ [S1, unofficial].
    *   Concatenate all elements in $x_{color}$ along the last axis to form the final input $x_{final}$ [S1, unofficial].

9.  **Color Network:**
    *   Initialize $h_{color} = x_{final}$.
    *   Iterate $i$ from 0 to `net_depth_viewdirs` - 1:
        *   Apply a dense layer with width `net_width_viewdirs` and activation `net_activation`: $h_{color} = \text{Activation}(W_i h_{color} + b_i)$.
        *   If $i > 0$ and $i \% \text{skip\_layer\_dir} == 0$, concatenate $x_{final}$ to $h_{color}$: $h_{color} = \text{concat}(h_{color}, x_{final})$ [S1, unofficial].

10. **RGB Output:**
    *   Compute raw RGB: $\mathbf{c}_{raw} = \text{dense\_layer}_{num\_rgb\_channels}(h_{color})$ [S1, unofficial].
    *   Apply premultiplier and bias: $\mathbf{c}_{pre} = \mathbf{c}_{raw} \cdot \text{rgb\_premultiplier} + \text{rgb\_bias}$ [S1, unofficial].
    *   Apply activation: $\mathbf{c}_{act} = \text{rgb\_activation}(\mathbf{c}_{pre})$ [S1, unofficial].
    *   Apply padding: $\mathbf{c} = \mathbf{c}_{act} \cdot (1 + 2 \cdot \text{rgb\_padding}) - \text{rgb\_padding}$ [S1, unofficial].

11. **Specular/Diffuse Split (Optional):**
    *   If `use_diffuse_color` is True:
        *   Compute diffuse component: $\mathbf{c}_{diff} = \text{sigmoid}(\mathbf{c}_{raw\_diffuse} - \log(3.0))$ [S1, unofficial].
        *   Compute specular component: If `use_specular_tint` is True, $\mathbf{c}_{spec} = \text{tint} \cdot \mathbf{c}_{act}$; else $\mathbf{c}_{spec} = 0.5 \cdot \mathbf{c}_{act}$ [S1, unofficial].
        *   Combine and tone map: $\mathbf{c}_{final} = \text{clip}(\text{linear\_to\_srgb}(\mathbf{c}_{spec} + \mathbf{c}_{diff}), 0.0, 1.0)$ [S1, unofficial].
    *   Otherwise, $\mathbf{c}_{final} = \mathbf{c}$ [S1, unofficial].

    )

        if i > 0 and i % config.skip_layer_dir == 0:

    # 10. RGB Output
    raw_rgb = dense_layer(h_color, params['color_output'], config.num_rgb_channels)
    rgb_premultiplied = raw_rgb * config.rgb_premultiplier + config.rgb_bias
    rgb = config.rgb_activation(rgb_premultiplied)

        if config.use_specular_tint:

        else:
            specular_linear = 0.5 * rgb
        rgb = jnp.clip(image.linear_to_srgb(specular_linear + diffuse_linear), 0.0, 1.0)
        
    return density, rgb, normals

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of query points and the depth of the MLPs. The IPE computation adds a constant factor overhead compared to standard positional encoding due to the basis matrix multiplication and variance integration.
*   **Memory Complexity:** Proportional to the number of parameters in the MLPs. The basis matrix is precomputed and stored once.
*   **Performance:** Provides better anti-aliasing than standard NeRF, especially for scenes with high-frequency details or when rendered at varying resolutions. The integrated encoding reduces aliasing artifacts without requiring explicit supersampling [S1, unofficial].
*   **Strengths:** Anti-aliasing via IPE, support for view-dependent effects via IDE, flexible configuration for various rendering features (normals, roughness, etc.).
*   **Limitations:** Slightly higher computational cost than standard NeRF due to IPE. Requires careful tuning of basis shape and subdivisions. Reflections require normals, which adds complexity if not predicted by the network.
*   **When to use:** When rendering scenes with high-frequency details or when anti-aliasing is a concern. When view-dependent effects like specular highlights are desired.
*   **When not to use:** When computational resources are extremely limited and standard NeRF performance is sufficient. When normals are not needed and reflections are not used, the overhead of IPE might be unnecessary.

## Background
The Mip-NeRF 360 MLP architecture was introduced in the context of the Mip-NeRF 360 project, which aimed to improve the robustness and quality of NeRF reconstructions for unbounded scenes. It builds upon the original NeRF architecture by incorporating integrated positional encoding to address aliasing issues [S1, unofficial]. The architecture is implemented in the `google-research/multinerf` repository [S1, unofficial].
