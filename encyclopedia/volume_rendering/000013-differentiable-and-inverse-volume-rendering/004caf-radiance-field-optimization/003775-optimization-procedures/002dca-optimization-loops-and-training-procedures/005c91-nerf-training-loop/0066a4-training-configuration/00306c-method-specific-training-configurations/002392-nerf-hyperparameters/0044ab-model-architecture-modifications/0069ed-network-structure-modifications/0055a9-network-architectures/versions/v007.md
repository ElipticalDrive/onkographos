# Network Architectures

Also called: NeRF Network Architectures

## Overview
Network architectures in NeRF-based methods define the functional mapping from spatial coordinates (and often auxiliary inputs like view direction or time) to radiance and density fields. While the canonical NeRF uses a single dense Multi-Layer Perceptron (MLP), subsequent architectures modify this structure to address specific bottlenecks such as inference latency, memory footprint, or the need for explicit geometric manipulation. These variants set themselves apart by altering the network topology (e.g., splitting into depth/oracle and shading networks), replacing dense MLPs with sparse or modular structures, or integrating external priors like point clouds or 2D image features.

## How it works
The core input to any NeRF network architecture is a 3D spatial coordinate $\mathbf{x} \in \mathbb{R}^3$ and, typically, a view direction $\mathbf{d} \in \mathbb{R}^3$. The output is usually a volume density $\sigma \in \mathbb{R}$ and a view-dependent color $\mathbf{c} \in \mathbb{R}^3$. However, specific architectures modify these inputs and outputs to achieve distinct goals.

### Canonical NeRF Baseline
The baseline architecture [S1] consists of two MLPs:
1.  **Positional Encoding:** The input coordinates $\mathbf{x}$ and view directions $\mathbf{d}$ are passed through a positional encoding function $\gamma(\cdot)$, which maps them to a higher-dimensional space using sinusoidal functions.
2.  **Feature Network (A):** An MLP that takes the encoded position $\gamma(\mathbf{x})$ and outputs a feature vector $\mathbf{h}$.
3.  **Shading Network (F):** An MLP that takes the feature vector $\mathbf{h}$ and the encoded view direction $\gamma(\mathbf{d})$ to predict density $\sigma$ and color $\mathbf{c}$.

### MIMO-DONeRF Architecture
MIMO-DONeRF modifies the standard two-network structure (Depth Oracle and Shading) to support Multi-Input Multi-Output (MIMO) processing [S1].
*   **Inputs:** Instead of processing a single sample $(\mathbf{x}, \mathbf{d})$, the network accepts a batch of $N_p$ samples simultaneously.
*   **Structure:**
    *   **Network A (Depth Oracle):** Uses the NeRF MLP design with hidden layer sizes increased from 256 to 384 [S1]. It is not used during inference.
    *   **Network F (Shading):** Uses the NeRF MLP design with hidden layer sizes increased from 256 to 384 [S1]. It is not used during inference.
    *   **Network H (Small MLP):** A lightweight network with two hidden layers, each consisting 16 neurons, identical to the one used in SNeRG [S1]. This network is used during inference to process the grouped samples.
*   **Operation:** By processing $N_p$ samples in parallel, the architecture accumulates neighbor information, improving image quality metrics (PSNR, SSIM, LPIPS) while reducing inference duration compared to sequential sampling in standard DONeRF [S1].

### Point-NeRF Adaptation for Object Manipulation
This variant replaces the continuous volumetric representation with a discrete neural point cloud [S2, S2, unofficial].
*   **Data Structure:** A set of neural points, each associated with a latent object code.
*   **Training Step:** To ensure high-quality geometry, the method uses a ground truth dense point cloud (400 million points per scene) instead of MVSNet-generated points to initialize the neural point cloud [S2, S2, unofficial].
*   **Inference Step:**
    1.  Feed spatial locations of all neural points into the DM-NeRF network to infer corresponding object codes.
    2.  Apply manipulation transformations to specific neural points based on predefined manipulation information.
    3.  Render the image using point-based volume rendering with the modified neural point cloud [S2, S2, unofficial].

### Pyramid NeRF
Pyramid NeRF replaces the single large MLP with thousands of smaller MLPs to accelerate training and inference [S3].
*   **Strategy:** Employs a "low-frequency-first, high-frequency-second" optimization approach [S3].
*   **Structure:** Uses progressive segmentation to substitute large MLPs with smaller ones [S3].
*   **Sampling:** Introduces depth-aware sampling to enhance rendering quality and hasten convergence [S3].
*   **Performance:** Achieves a 15x increase in training speed and an 805x increase in inference speed relative to the original NeRF [S3].

## Subtopics

### [MIMO-DONeRF](16217-mimo-donerf.md)
MIMO-DONeRF is a method that applies the Multi-Input Multi-Output (MIMO) neural rendering concept to the DONeRF architecture. It modifies the shading network to accept multiple spatial inputs and view directions simultaneously, producing multiple color and density outputs per forward pass. This approach improves inference speed compared to increasing the number of samples in standard DONeRF, while maintaining or improving image quality by allowing the network to accumulate neighbor information through grouped samples. It differs from standard DONeRF by processing $N_p$ samples in parallel rather than sequentially, and from MIMO-NeRF by being specifically adapted to the two-network structure (depth oracle and shading) of DONeRF.

### [Sparse Latent Space for 4D Novel View Synthesis (SLS4D)](18112-sparse-latent-space-for-4d-novel-view-synthesis-sls4d.md)
A method for 4D novel-view synthesis that uses a learnable sparse latent space to represent radiance fields, reducing network parameters compared to dense grid discretizations while maintaining high-frequency detail via attention-based interpolation.

### [Neural Feature Fusion Fields (N3F)](18114-neural-feature-fusion-fields-n3f.md)
A method that distills dense 2D image features (from a self-supervised or supervised teacher network) into a 3D representation (student network) defined in world space, using differentiable neural rendering to fuse features across multiple views.

### Point-NeRF Adaptation for Object Manipulation
A specific configuration of Point-NeRF designed for scene-level geometry decomposition and manipulation [S2, S2, unofficial]. It utilizes a ground truth dense point cloud (400 million points per scene) during training to generate the neural point cloud, ensuring high geometric fidelity. During inference, it infers object codes for neural points, applies spatial transformations based on manipulation inputs, and renders the result using point-based volume rendering [S2, S2, unofficial].

### Pyramid NeRF
A method that accomplishes rapid NeRF training and inference through the application of an image pyramid and a strategy based on frequency optimization [S3]. It utilizes a 'low-frequency-first, high-frequency-second' approach, substitutes large MLPs with thousands of smaller ones via progressive segmentation, and introduces a sampling approach that is aware of depth to enhance rendering quality and hasten training convergence [S3]. It enhances training speed by 15x and inference speed by 805x relative to the original NeRF [S3].

## Operating characteristics
*   **MIMO-DONeRF:** Improves inference speed and image quality (PSNR, SSIM, LPIPS) over standard NeRF and DONeRF [S1]. The increased hidden layer sizes (384) in networks A and F increase training time but are not used during inference, optimizing the inference-to-training ratio [S1].
*   **Point-NeRF (DM-NeRF):** Requires significant memory for storing large point clouds (e.g., 400 million points) but allows for explicit geometric manipulation which is difficult with continuous volumetric representations [S2, S2, unofficial].
*   **Pyramid NeRF:** Offers massive speedups (15x training, 805x inference) and better structural/perceptual resemblance than original NeRF [S3]. The complexity lies in managing the thousands of smaller MLPs and the depth-aware sampling strategy [S3].

## Background
The canonical NeRF architecture [S1] established the use of dense MLPs for implicit scene representation. Subsequent research has focused on modifying this architecture to address scalability, speed, and functionality. MIMO-DONeRF extends the DONeRF framework [S1]. Point-NeRF and its manipulation variant [S2, S2, unofficial] integrate explicit point-based representations. Pyramid NeRF [S3] introduces frequency-based optimization and network segmentation.
