# Conditional Radiance Field with Shared Branch

Also called: CRF with Shared Branch, Modular Conditional Radiance Field

## Overview
The Conditional Radiance Field with Shared Branch is a neural radiance field architecture designed for shape and color disentanglement, enabling efficient instance-specific editing by allowing specific submodules to be fine-tuned independently [S1]. It maps a 3D location $\mathbf{x}$, viewing direction $\mathbf{d}$, and instance-specific latent codes to radiance and density, distinguishing itself from sibling methods by explicitly separating the geometric representation into shared and instance-specific branches to improve view synthesis quality and editing efficiency [S1].

## How it works
**Inputs and Outputs**
*   **Inputs**: 3D position $\mathbf{x} \in \mathbb{R}^3$, viewing direction $\mathbf{d} \in \mathbb{R}^3$, instance-specific shape code $\mathbf{z}^{(s)} \in \mathbb{R}^{32}$, and instance-specific color code $\mathbf{z}^{(c)} \in \mathbb{R}^{32}$.
*   **Outputs**: Scalar density $\sigma \in \mathbb{R}$ and radiance color $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures**
The network consists of five Multi-Layer Perceptrons (MLPs), all configured with 4 layers, 256 hidden channels, and ReLU activations [S1]:
1.  $F_{\text{share}}$: Shared shape network.
2.  $F_{\text{inst}}$: Instance-specific shape network.
3.  $F_{\text{fuse}}$: Fusion shape network.
4.  $F_{\text{dens}}$: Output density network (linear layer).
5.  $F_{\text{rad}}$: Output radiance network (2-layer MLP).

All intermediate feature vectors output by $F_{\text{share}}$, $F_{\text{inst}}$, and $F_{\text{fuse}}$ are 256-dimensional [S1]. The latent codes $\mathbf{z}^{(s)}$ and $\mathbf{z}^{(c)}$ are 32-dimensional vectors [S1].

**Positional Encoding**
Inputs $\mathbf{x}$ and $\mathbf{d}$ are transformed using the standard NeRF positional encoding function $\gamma(\cdot)$ [S1].

**Algorithm Steps**
1.  **Compute Shared Shape Representation**: Pass the positional encoding of the position, $\gamma(\mathbf{x})$, through the shared shape network $F_{\text{share}}$ to obtain the shared feature vector $\mathbf{f}_{\text{share}}$.
    $$ \mathbf{f}_{\text{share}} = F_{\text{share}}(\gamma(\mathbf{x})) $$
2.  **Compute Instance-Specific Shape Representation**: Concatenate the shape code $\mathbf{z}^{(s)}$ with the positional encoding $\gamma(\mathbf{x})$. Pass this concatenation through the instance-specific shape network $F_{\text{inst}}$ to obtain the instance feature vector $\mathbf{f}_{\text{inst}}$.
    $$ \mathbf{f}_{\text{inst}} = F_{\text{inst}}([\mathbf{z}^{(s)}; \gamma(\mathbf{x})]) $$
3.  **Fuse Representations**: Add the shared and instance-specific feature vectors, then pass the sum through the fusion shape network $F_{\text{fuse}}$ to obtain the fused feature vector $\mathbf{f}_{\text{fuse}}$.
    $$ \mathbf{f}_{\text{fuse}} = F_{\text{fuse}}(\mathbf{f}_{\text{share}} + \mathbf{f}_{\text{inst}}) $$
4.  **Predict Density**: Pass the fused feature vector $\mathbf{f}_{\text{fuse}}$ through the linear density network $F_{\text{dens}}$ to obtain the scalar density $\sigma$.
    $$ \sigma = F_{\text{dens}}(\mathbf{f}_{\text{fuse}}) $$
5.  **Predict Radiance**: Concatenate the fused feature vector $\mathbf{f}_{\text{fuse}}$, the color code $\mathbf{z}^{(c)}$, and the encoded viewing direction $\gamma(\mathbf{d})$. Pass this concatenation through the two-layer radiance network $F_{\text{rad}}$ to obtain the radiance color $\mathbf{c}$.
    $$ \mathbf{c} = F_{\text{rad}}([\mathbf{f}_{\text{fuse}}; \mathbf{z}^{(c)}; \gamma(\mathbf{d})]) $$

**Pseudocode**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

# Standard NeRF positional encoding implementation
def positional_encoding(x, min_deg, max_deg):
    scales = torch.tensor([2**i for i in range(min_deg, max_deg)])
    scaled_x = x.unsqueeze(-1) * scales.unsqueeze(0)
    scaled_x = scaled_x.view(*x.shape[:-1], -1)
    return torch.cat([x, torch.sin(scaled_x), torch.cos(scaled_x)], dim=-1)

class ConditionalRadianceFieldSharedBranch(nn.Module):
    def __init__(self, min_deg_pos=0, max_deg_pos=10, min_deg_dir=0, max_deg_dir=4):
        super().__init__()
        self.min_deg_pos = min_deg_pos
        self.max_deg_pos = max_deg_pos
        self.min_deg_dir = min_deg_dir
        self.max_deg_dir = max_deg_dir
        
        # Calculate input dimensions based on NeRF encoding
        # x is 3D, d is 3D
        dim_pos = 3 * (1 + 2 * (max_deg_pos - min_deg_pos))
        dim_dir = 3 * (1 + 2 * (max_deg_dir - min_deg_dir))
        
        self.dim_pos = dim_pos
        self.dim_dir = dim_dir
        
        # Network components: 4 layers, 256 channels, ReLU
        # F_share: input dim_pos -> 256
        self.F_share = nn.Sequential(
            nn.Linear(dim_pos, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256)
        )
        
        # F_inst: input dim_pos + 32 -> 256
        self.F_inst = nn.Sequential(
            nn.Linear(dim_pos + 32, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256)
        )
        
        # F_fuse: input 256 -> 256
        self.F_fuse = nn.Sequential(
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256)
        )
        
        # F_dens: input 256 -> 1 (linear layer)
        self.F_dens = nn.Linear(256, 1)
        
        # F_rad: input 256 + 32 + dim_dir -> 256 -> 3 (2-layer MLP)
        self.F_rad = nn.Sequential(
            nn.Linear(256 + 32 + dim_dir, 256), nn.ReLU(),
            nn.Linear(256, 3)
        )

    def forward(self, x, d, z_s, z_c):
        """
        x: (N, 3) position
        d: (N, 3) viewing direction
        z_s: (N, 32) shape code
        z_c: (N, 32) color code
        """
        # 1. Positional Encoding
        gamma_x = positional_encoding(x, self.min_deg_pos, self.max_deg_pos)
        gamma_d = positional_encoding(d, self.min_deg_dir, self.max_deg_dir)
        
        # 2. Shared Shape Representation
        f_share = self.F_share(gamma_x)
        
        # 3. Instance-Specific Shape Representation
        # Concatenate shape code z_s and positional encoding gamma_x
        inst_input = torch.cat([z_s, gamma_x], dim=-1)
        f_inst = self.F_inst(inst_input)
        
        # 4. Fuse Representations
        # Add outputs of F_share and F_inst
        fused_input = f_share + f_inst
        f_fuse = self.F_fuse(fused_input)
        
        # 5. Predict Density
        sigma = self.F_dens(f_fuse)
        
        # 6. Predict Radiance
        # Concatenate f_fuse, color code z_c, and encoded viewing direction gamma_d
        rad_input = torch.cat([f_fuse, z_c, gamma_d], dim=-1)
        c = self.F_rad(rad_input)
        
        return sigma, c
```

**Parameters and Training**
*   **Latent Codes**: Shape code $\mathbf{z}^{(s)}$ and color code $\mathbf{z}^{(c)}$ are 32-dimensional vectors [S1].
*   **Optimization**: The latent codes are jointly optimized with the network parameters using the Adam optimizer [S1].
*   **Learning Rates**: The training learning rate is $10^{-4}$ [S1]. For specific editing tasks, the learning rate is increased to $10^{-2}$ [S1].
*   **Edge Cases**: The method assumes a fixed dimensionality for latent codes (32) and MLP widths (256). Deviations require retraining or architectural adjustment [S1].

## Operating characteristics
*   **Performance**: On the PhotoShapes dataset, the shared shape branch improves PSNR from 33.91 (without shared branch) to 35.79 [S1].
*   **Efficiency**: The modular design allows for efficient editing. Color edits are accelerated by $3.2\times$ and shape edits by $1.9\times$ compared to non-modular approaches, as only a subset of network components and latent codes need updating during editing [S1].
*   **Scalability**: The shared branch helps the model scale to more instances by learning a category-specific geometric representation [S1].
*   **Limitations**: The method requires joint optimization of latent codes for all instances, which may increase memory usage during training compared to single-instance NeRFs, although it outperforms single-instance models in quality [S1].

## Background
The Conditional Radiance Field with Shared Branch was introduced in "Editing Conditional Radiance Fields" (ICCV 2021) [S1]. It builds on the inductive biases of positional encodings and stage-wise network design found in NeRF . The architecture was developed to address the need for efficient shape and color editing in neural radiance fields by disentangling these attributes into modular network components [S1].
