# IE-NeRF

Also called: IE-NeRF Pipeline, Image-dependent NeRF with transient mask inpainting, Inpainting Enhanced NeRF

## Overview
IE-NeRF enhances novel view synthesis in uncontrolled, "in-the-wild" environments by separating static scene geometry and appearance from transient occlusions (e.g., pedestrians, vehicles) using a learned 2D transient mask and an image inpainting module, rather than modeling a 3D transient field or relying on external semantic priors [S1]. It differs from siblings like [DeblurNeRF](11964-deblurnerf.md) and [Sharp-NeRF](14270-sharp-nerf.md) by explicitly modeling transient occlusions as a learnable 2D visibility map that guides a pre-trained inpainting network to generate supervision targets for the static NeRF, whereas those methods focus on correcting optical degradations like blur or defocus [S1].

## How it works
**Inputs:** A set of uncalibrated or SfM-calibrated images $\{I_i\}$ with corresponding camera poses.
**Outputs:** A static radiance field $F_\theta$ capable of rendering occlusion-free static views, and a transient mask generator.

**Data Structures:**
1.  **NeRF MLPs:** Two Multi-Layer Perceptrons, $MLP_{\theta_1}$ and $MLP_{\theta_2}$.
    *   $MLP_{\theta_1}$: 8 fully connected layers, 256 hidden units. Input: Positional encoded ray point. Output: Density $\sigma$ and intermediate feature $z_i(t)$.
    *   $MLP_{\theta_2}$: 8 fully connected layers, 256 hidden units, followed by a 128-unit layer. Input: Directional encoding, $z_i(t)$, and image latent $\ell_i$. Output: Transient mask embedding $\ell_t$ and static color $c_i(t)$.
2.  **CNN Encoder $E$:** Encodes input image $I_i$ into a latent vector $\ell_i \in \mathbb{R}^d$.
3.  **Mask Generator $E_\phi$:** Linear layers mapping $\ell_t$ and 2D pixel coordinates $l_{ij}$ to mask probability $M_{ij}$.
4.  **Inpainting Module $G_\Delta$:** Pre-trained LaMa network. Input: 4-channel tensor $x' = \text{stack}(x \odot m, m)$, where $x$ is the image and $m$ is the mask. Output: Inpainted image $\hat{x}$.

**Numbered Steps:**

1.  **Image Encoding:** For each input image $I_i$, encode it into a feature latent vector $\ell_i$ using the CNN encoder $E$:
    $$ \ell_i = E(I_i) $$
    [S1]

2.  **Ray Sampling:** For a camera ray $r(t) = o + td$ passing through pixel $(u,v)$, sample $K$ points $t_k$ along the ray. Use mip-NeRF cone casting with Integrated Positional Encoding (IPE) to handle multiscale representations [S1].

3.  **Static Feature Extraction:** Process the 3D location $r(t)$ through $MLP_{\theta_1}$ with positional encoding $\gamma_x$ to obtain volume density $\sigma(t)$ and intermediate feature $z_i(t)$:
    $$ [\sigma(t), z_i(t)] = MLP_{\theta_1}[\gamma_x(r(t))] $$
    [S1]

4.  **Image-Dependent Radiance and Mask Embedding:** Feed the viewing direction $d$ (encoded via $\gamma_d$), the intermediate feature $z_i(t)$, and the image latent $\ell_i$ into $MLP_{\theta_2}$ to predict the image-dependent static radiance $c_i(t)$ and the transient mask embedding $\ell_t$:
    $$ c_i(t) = MLP_{\theta_2}[\gamma_d(d), z_i(t), \ell_i] $$
    $$ \ell_t = MLP_{\theta_2}^{\text{mask}}[\gamma_d(d), z_i(t), \ell_i] $$
    [S1]

5.  **Transient Mask Generation:** Generate a 2D pixel-wise transient mask probability $M_{ij}$ for pixel $l_{ij} = (u,v)$ in image $I_i$ by mapping the 2D location and the transient embedding $\ell_t$ through linear layers $E_\phi$:
    $$ M_{ij} = E_\phi(l_{ij}, \ell_t) $$
    The mask $M_{ij}$ represents the probability of a pixel being transient. A threshold is applied to create a binary mask for the inpainting module [S1].

6.  **Static Volume Rendering:** Compute the approximated static pixel color $\hat{C}_i(r)$ using the static density $\sigma(t)$ and image-dependent radiance $c_i(t)$:
    $$ \hat{C}_i(r) = \sum_{k=1}^{K} T(t_k) \cdot \alpha(\sigma(t_k)\delta_k) \cdot c_i(t_k) $$
    where $T(t_k) = \exp\left(-\sum_{k'=1}^{k-1} \sigma(t_{k'})\delta_{k'}\right)$ and $\alpha(\sigma) = 1 - \exp(-\sigma\delta)$ [S1].

7.  **Inpainting Supervision Generation:**
    *   **Image:** Feed the original image $I_i$ and the thresholded transient mask $M_{ij}$ into the LaMa inpainting module $G_\Delta$ to produce the restored static image $I_{ri}$:
        $$ I_{ri} = G_\Delta(I_i \odot (1-M_{ij}), M_{ij}) $$
        The input to LaMa is a 4-channel tensor formed by stacking the masked image and the mask [S1].
    *   **Depth:** Render static depth maps $D_{si}$ from the NeRF. Inpaint these depth maps using LaMa guided by $M_{ij}$ to produce restored depth maps $D_{ri}$ [S1].

8.  **Optimization:** Minimize the total loss $L$, which combines static photometric loss, transient loss, perceptual loss (LPIPS), and depth loss:
    $$ L = \alpha \sum_{ij} L_s + \beta \sum_{ij} L_t + \gamma \sum_i L_{\text{LPIPS}} + \rho \sum_i L_{\text{depth}} $$
    [S1]

**Formulas:**

*   **Static Photometric Loss ($L_s$):**
    $$ L_s = \sum_{ij} (1 - M_{ij}) \| C(r_{ij}) - \hat{C}_s(r_{ij}) \|^2 $$
    where $C(r_{ij})$ is the observed color and $\hat{C}_s(r_{ij})$ is the rendered static color. This term only supervises pixels identified as static [S1].

*   **Transient Loss ($L_t$):**
    $$ L_t = \sum_{ij} (1 - M_{ij}) \| C(r_{ij}) - \hat{C}_s(r_{ij}) \|^2 + \lambda \sum_{ij} M_{ij} \| C_s(r_{ij}) - \hat{C}_s(r_{ij}) \|^2 $$
    *Note: The source text for Eq. 14 contains a slight ambiguity in notation. The first term handles occlusion error (comparing rendered static to ground truth outside mask). The second term addresses reconstruction error inside the mask, assuming $M_{ij}$ indicates static phenomena, comparing rendered static to "repaired" ground truth $C_s$. In practice, this balances the separation: ensuring transient pixels are not rendered as static, and static pixels are rendered correctly.*
    [S1]

*   **Depth Loss ($L_{\text{depth}}$):**
    $$ L_{\text{depth}} = \frac{1}{|R|} \sum_{r \in R} \| \hat{D}_{si}(r) - D_{ri}(r) \|^2 $$
    where $\hat{D}_{si}$ is the rendered static depth and $D_{ri}$ is the inpainted depth [S1].

*   **Frequency Regularization (RegFre-IPE):**
    To stabilize training, a linearly increasing frequency mask $\omega$ is applied to the positional encoding $\gamma_L$:
    $$ \gamma_L'(t, T; x) = \gamma_L(x) \odot \omega(t, T, L) $$
    where $\omega^i(t, T, L)$ is defined as:
    $$ \omega^i(t, T, L) = \begin{cases} 
    1 & \text{if } i \le \lfloor \frac{t \cdot L}{T} \rfloor \\
    \frac{t \cdot L}{T} - \lfloor \frac{t \cdot L}{T} \rfloor & \text{if } \lfloor \frac{t \cdot L}{T} \rfloor < i \le \lfloor \frac{t \cdot L}{T} \rfloor + 1 \\
    0 & \text{if } i > \lfloor \frac{t \cdot L}{T} \rfloor + 1
    \end{cases} $$
    (Simplified interpretation of the piecewise function in Eq. 17 based on standard linear warmup logic described in text: low frequencies are active early, high frequencies are introduced gradually).
    [S1]

**Parameters:**
*   $\lambda$: Balances static/transient components in $L_t$. [S1]
*   $\alpha, \beta, \gamma, \rho$: Weights for static loss, transient loss, perceptual loss, and depth loss. [S1]
*   $L$: Maximum encoded frequency in positional encoding. [S1]
*   $r$: Transient mask factor (ratio of transient pixels to total image area), used in frequency regularization scheduling. [S1]
*   Typical Values: Not given in the sources.

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class IENeRF:
    def __init__(self, num_layers=8, hidden_dim=256, color_dim=128, 
                 num_freqs=10, num_img_features=256):
        # MLP for density and intermediate features
        self.mlp_density = nn.Sequential(
            *[nn.Linear(2 * num_freqs * 3 + 3, hidden_dim) for _ in range(num_layers)],
            nn.ReLU()
        )
        # MLP for color and mask embedding
        self.mlp_radiance = nn.Sequential(
            *[nn.Linear(2 * num_freqs * 2 + hidden_dim + num_img_features, hidden_dim) for _ in range(num_layers)],
            nn.ReLU(),
            nn.Linear(hidden_dim, color_dim),
            nn.Sigmoid() # Static color
        )
        self.mlp_mask_embed = nn.Sequential(
            *[nn.Linear(2 * num_freqs * 2 + hidden_dim + num_img_features, hidden_dim) for _ in range(num_layers)],
            nn.ReLU(),
            nn.Linear(hidden_dim, color_dim) # Mask embedding
        )
        
        # Linear layers for mask probability from embedding and 2D coords
        self.mask_gen = nn.Linear(color_dim + 2, 1) # l_t + (u,v) -> M_ij
        
        # CNN Encoder for image latent
        self.encoder = nn.Sequential(
            nn.Conv2d(3, 64, 3, padding=1), nn.ReLU(),
            nn.Conv2d(64, 128, 3, padding=1), nn.ReLU(),
            nn.AdaptiveAvgPool2d(1),
            nn.Flatten(),
            nn.Linear(128, num_img_features)
        )
        
        # Placeholder for LaMa Inpainting Module
        self.inpainting_module = LaMaModule()

    def positional_encoding(self, x, num_freqs):
        # Standard NeRF positional encoding
        x_proj = x.view(-1, 1) * torch.exp(torch.linspace(0, num_freqs - 1, num_freqs).float() * torch.log(torch.tensor(2.0)))
        return torch.sin(torch.cat([x_proj, x_proj + torch.pi/2], dim=-1)).view(-1, 2 * num_freqs * x.shape[-1])

    def forward(self, rays_o, rays_d, images, img_indices, t_vals, num_freqs):
        """
        rays_o: (N_rays, 3) origin
        rays_d: (N_rays, 3) direction
        images: (N_imgs, 3, H, W) input images
        img_indices: (N_rays,) index of image for each ray
        t_vals: (N_rays, K) sample depths
        """
        # 1. Encode images
        img_latents = self.encoder(images) # (N_imgs, num_img_features)
        
        # 2. Sample points
        pts = rays_o.unsqueeze(1) + rays_d.unsqueeze(1) * t_vals.unsqueeze(2) # (N_rays, K, 3)
        pts_flat = pts.view(-1, 3)
        
        # 3. Positional Encoding with Frequency Regularization
        # Note: Simplified IPE logic. In practice, mip-NeRF integrates PE over cones.
        # Here we assume standard PE with a mask omega applied during training.
        pe_pts = self.positional_encoding(pts_flat, num_freqs)
        
        # 4. Density and Intermediate Feature
        # [sigma, z_i] = MLP_theta1[gamma_x(r(t))]
        # We assume the last layer of mlp_density outputs sigma and z_i concatenated or split
        # For simplicity, let's say mlp_density outputs z_i, and sigma is derived or separate head
        # Source says: [sigma(t), z_i(t)] = MLP_theta1...
        # Let's adjust architecture to match source: 8 layers, 256 units.
        # Output of MLP_theta1 is [sigma, z_i].
        
        # Re-defining internal heads for clarity matching source Eq 6
        # z_i is intermediate feature. sigma is density.
        z_i = self.mlp_density(pe_pts) # (N_rays*K, hidden_dim)
        sigma = torch.sigmoid(z_i[:, :1]) # Simplified: assuming sigma is first channel or separate head
        z_i = z_i[:, 1:] # Remaining channels as z_i
        
        # 5. Radiance and Mask Embedding
        # Directions
        dirs_flat = rays_d.unsqueeze(1).expand_as(t_vals).view(-1, 3)
        pe_dirs = self.positional_encoding(dirs_flat, num_freqs)
        
        # Gather image latents
        img_latents_gathered = img_latents[img_indices] # (N_rays, num_img_features)
        img_latents_flat = img_latents_gathered.unsqueeze(1).expand_as(t_vals).view(-1, num_img_features)
        
        # Concat: pe_dirs, z_i, img_latents
        input_radiance = torch.cat([pe_dirs, z_i, img_latents_flat], dim=-1)
        
        c_i = self.mlp_radiance(input_radiance) # (N_rays*K, 3) Static Color
        l_t = self.mlp_mask_embed(input_radiance) # (N_rays*K, color_dim) Mask Embedding
        
        # 6. Volume Rendering
        # Alpha and Transmittance
        delta = t_vals[:, :, 1] - t_vals[:, :, 0]
        alpha = 1.0 - torch.exp(-sigma * delta)
        T = torch.cumprod(torch.cat([torch.ones_like(alpha[:, :1]), 1.0 - alpha + 1e-10], dim=1), dim=1)[:, :-1]
        
        weights = T * alpha
        C_i = torch.sum(weights.unsqueeze(-1) * c_i, dim=1) # (N_rays, 3)
        
        # 7. Transient Mask Generation
        # M_ij = E_phi(l_ij, l_t)
        # l_ij is 2D pixel coord. We need to map ray index to pixel coord.
        # Assuming rays are ordered by image and pixel.
        # For implementation, we assume we have pixel coordinates (u,v) for each ray.
        # l_t is per-sample. We need to aggregate or use the sample with highest weight?
        # Source says: "maps a 2D-pixel location l_ij and the transient image embedding l_t to a 2D pixel-wise probability"
        # This implies l_t might be aggregated per image or per pixel. 
        # Given l_t is output of MLP per sample, we likely average l_t per pixel or use the sample closest to surface.
        # Let's assume we aggregate l_t per pixel (u,v) in the image.
        
        # Simplified: Assume we have aggregated l_t per pixel (u,v) for the current image batch.
        # In a real loop, we would bin l_t by (u,v).
        # Here, we return l_t and C_i, and let the loss function handle the mask aggregation if needed,
        # or assume a separate pass for mask generation per image.
        
        return C_i, sigma, l_t, weights

    def compute_loss(self, rendered_color, gt_images, masks, inpainted_images, rendered_depth, inpainted_depth):
        # Static Loss
        static_loss = torch.mean((1 - masks) * (rendered_color - gt_images)**2)
        
        # Transient Loss (Eq 14)
        # Term 1: Occlusion error (outside mask)
        term1 = torch.mean((1 - masks) * (rendered_color - gt_images)**2)
        # Term 2: Reconstruction error (inside mask, comparing to inpainted/repaired)
        # Note: Source uses C_s for repaired ground truth.
        term2 = torch.mean(masks * (inpainted_images - rendered_color)**2)
        transient_loss = term1 + 0.5 * term2 # lambda = 0.5 example
        
        # Depth Loss
        depth_loss = torch.mean((rendered_depth - inpainted_depth)**2)
        
        # LPIPS Loss (Placeholder)
        lpips_loss = 0.0 
        
        return static_loss + transient_loss + depth_loss + lpips_loss

class LaMaModule(nn.Module):
    def __init__(self):
        super().__init__()
        # Pre-trained LaMa weights would be loaded here
        pass
    def forward(self, masked_img, mask):
        # Input: 4-channel tensor stack(masked_img, mask)
        x = torch.cat([masked_img, mask], dim=1)
        # Return inpainted image
        return self.network(x)
```

## Subtopics

### IE-NeRF(IM)
Uses an independent mask generation network without the MLP-based transient embedding, relying on spatial constraints. Less sensitive to occluders similar to scene color but prone to artifacts due to lack of prior supervision. [S1]

### IE-NeRF(SM)
Uses a pre-trained semantic model (MaskDINO) to generate transient masks. Limited effectiveness for small occluders or shadows not covered by predefined classes. [S1]

### RegFre-IPE
The proposed training strategy using Integrated Positional Encoding with frequency regularization. Mitigates high-frequency instability during transient separation. [S1]

### WT-IPE
Integrated Positional Encoding with wavelet transform. Found to have negative impacts on performance compared to RegFre-IPE. [S1]

## Operating characteristics
*   **Time and Memory Complexity:** The method uses a standard NeRF architecture (8 layers, 256 units) plus a CNN encoder and a LaMa inpainting module. LaMa is a large ResNet-like architecture with Fast Fourier Convolutions, increasing memory usage and inference time compared to vanilla NeRF. [S1]
*   **Measured Performance:** On the Phototourism dataset (Brandenburg Gate), IE-NeRF achieved PSNR 25.33, SSIM 0.898, and LPIPS 0.158, outperforming NeRF (18.90/0.816/0.232), NeRF-W (24.17/0.891/0.167), and Ha-NeRF (24.04/0.877/0.139). [S1]
*   **Scaling:** Performance degrades with small datasets and sparse inputs because the transient mask lacks sufficient information for the inpainting module to guarantee restoration. [S1]
*   **Strengths:** Effectively separates static and transient components in uncontrolled environments without 3D transient fields or semantic priors. Handles varying lighting and transient objects (people, cars). [S1]
*   **Limitations:** Inpainting modules may produce blurry results or view inconsistencies, mitigated by LPIPS and depth loss. Struggles with sparse inputs. [S1]

## Background
IE-NeRF was proposed by Wang et al. from Sun Yat-sen University and Pengcheng Laboratory, published in *Neurocomputing* in 2024 (arXiv:2407.10695v2). It addresses the limitations of NeRF in "in-the-wild" scenarios where transient objects and varying illumination degrade reconstruction quality. It builds on [NeRF-W](11964-deblurnerf.md) and [Ha-NeRF](11964-deblurnerf.md) but diverges by using image inpainting for supervision rather than dual NeRFs or semantic segmentation. [S1]
