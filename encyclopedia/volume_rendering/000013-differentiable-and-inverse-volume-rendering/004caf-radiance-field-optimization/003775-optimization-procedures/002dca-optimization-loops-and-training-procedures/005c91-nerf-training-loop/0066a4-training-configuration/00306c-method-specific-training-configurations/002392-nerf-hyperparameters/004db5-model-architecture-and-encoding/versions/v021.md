# Model Architecture and Encoding


## Overview
Model Architecture and Encoding defines the neural network structures and input transformation functions that map 3D spatial coordinates and viewing directions to radiance field attributes (density, color, semantics). It solves the problem of representing complex, high-frequency 3D scenes with limited computational resources and ensuring the network can learn the underlying geometry and appearance. It sets itself apart from sibling articles like [NeRF Initialization Strategies](8674-nerf-initialization-strategies.md) by focusing on the topological design (layers, encodings, grid structures) rather than parameter initialization, and from [Model Architecture Modifications](11313-model-architecture-modifications.md) by covering the foundational architectural choices (MLPs, Hash Grids, Triplanes) that define the base representation before specific optimization tweaks are applied.

## Shared principles
The core mechanism involves querying a function $F_\theta$ with input coordinates $\mathbf{x} \in \mathbb{R}^3$ and viewing directions $\mathbf{d} \in S^2$ to produce outputs such as volume density $\sigma \in \mathbb{R}$ and color $\mathbf{c} \in \mathbb{R}^3$. The architecture typically consists of two main components: an **encoding function** that maps raw low-dimensional inputs to a higher-dimensional feature space, and a **decoder network** (usually an MLP) that maps these features to the target attributes.

Common architectural patterns include:
1.  **Multi-Layer Perceptrons (MLPs):** Used as the primary decoder. Standard configurations involve multiple fully connected layers with non-linear activations (e.g., ReLU, SIREN). Skip connections are often employed to preserve low-frequency information from the input to deeper layers [S1].
2.  **Coordinate Encoding:** Raw coordinates are transformed using basis functions. The most common is Sinusoidal Positional Encoding (SPE), but variants include Integrated Positional Encoding (IPE) for anti-aliasing [S1], Frequency-Modulated Position Encoding for finer frequency support [S1], and Hash Encoding for efficient multi-resolution storage [S1].
3.  **Feature Grids:** Instead of relying solely on MLP capacity, many modern architectures use learnable feature grids (e.g., 3D voxel grids, 2D planes, or hash tables) to store features at query points. These grids are interpolated (trilinear, bilinear, or tetra-linear) to retrieve features for the decoder [S1].
4.  **View-Dependent Modeling:** Viewing directions are encoded separately (often with fewer frequencies than position) and concatenated with spatial features before being processed by the color network [S1].

## Subtopics

### [Depth-Guided NeRF Training Configuration](11916-depth-guided-nerf-training-configuration.md)
This configuration modifies the standard NeRF MLP architecture by inserting dropout layers after the first eight fully connected ReLU-activated layers that encode the positional encoding. It differs from standard NeRF training by explicitly incorporating depth supervision via an Earth Mover’s Distance (EMD) or similar depth loss, requiring specific weight decay and learning rate schedules to handle the multi-task optimization. It is chosen when depth priors are available to regularize the learning process and improve geometric accuracy. See [Depth-Guided NeRF Training Configuration](11916-depth-guided-nerf-training-configuration.md).

### [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md)
CLIPNeRF training configuration defines the optimization procedure for text-guided stylization of Neural Radiance Fields (NeRFs) by minimizing the negative cosine similarity between rendered image embeddings and text prompt embeddings in the CLIP latent space. It distinguishes itself from standard NeRF training by freezing density-related parameters and utilizing patch-based rendering to manage memory constraints while applying directional losses to enforce stylistic trajectories. It is chosen for text-guided 3D stylization tasks. See [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md).

### [Binary Radiance Fields](13622-binary-radiance-fields.md)
Binary Radiance Fields (BiRF) is a storage-efficient radiance field representation that constrains feature grid parameters to binary values (+1 or -1) to achieve compact storage. It solves the storage bottleneck of neural radiance fields by replacing real-valued floating-point features with 1-bit binary features, while maintaining reconstruction quality through a 2D-3D hybrid multi-resolution architecture. Unlike post-processing compression methods (e.g., PlenOctrees, Re:NeRF) that require additional optimization steps and are bounded by pre-trained model performance, BiRF performs binarization during training without post-optimization. It is chosen for memory-constrained environments. See [Binary Radiance Fields](13622-binary-radiance-fields.md).

### [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md)
The Mip-NeRF 360 MLP architecture is a specific neural network configuration for radiance field optimization that replaces standard positional encoding with **Integrated Positional Encoding (IPE)** to handle aliasing and frequency mismatch during volume rendering. It structures the network into two distinct Multi-Layer Perceptrons (MLPs): a density network that processes 3D spatial coordinates and a color network that processes view-dependent features, connected by a bottleneck vector. This architecture is designed to be compatible with the Mip-NeRF ray integration strategy, ensuring that the network's output is consistent with the integrated volume rendering equation. It is chosen for anti-aliased rendering of unconstrained photo collections. See [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md).

### [SUDS](14964-suds.md)
SUDS is a 4D radiance field representation designed for large-scale, dynamic urban environments that factorizes the scene into three separate multi-resolution hash table branches: static, dynamic, and far-field. Unlike prior methods that require supervised 3D bounding boxes or panoptic labels, SUDS learns scene flow, semantic decomposition, and free-viewpoint rendering using only unlabeled inputs (RGB, sparse LiDAR, 2D optical flow, and DINO descriptors). It distinguishes itself from siblings like [NSG](11916-depth-guided-nerf-training-configuration.md) by handling ego-motion and multi-video representations without linear memory growth per object, scaling to hundreds of square kilometers. It is chosen for large-scale dynamic urban scene reconstruction. See [SUDS](14964-suds.md).

### [CCNeRF](15008-ccnerf.md)
CCNeRF is a neural field representation that enables efficient compression and composition of 3D scenes by learning a hybrid tensor rank decomposition of the scene without using neural networks for rendering. Unlike NeRF variants that rely on a shared MLP renderer (e.g., NSVF) or hybrid tensor-MLP approaches (e.g., TensoRF), CCNeRF models the radiance field *only* with tensor rank decomposition, preserving low-rank approximation properties to allow dynamic model size adjustment via rank truncation and arbitrary composition via rank concatenation. It is chosen for compressible and composable 3D scene representations. See [CCNeRF](15008-ccnerf.md).

### [Rip-NeRF](15532-rip-nerf.md)
Rip-NeRF is a hybrid radiance field method that renders high-fidelity, anti-aliased images by combining cone casting with anisotropic 3D Gaussian characterization. It distinguishes itself from sibling methods like Zip-NeRF by using Ripmap-Encoded Platonic Solids to enable efficient anisotropic area-sampling, whereas Zip-NeRF relies on a multi-sampling mechanism that is effective but computationally inefficient. It is chosen for high-fidelity rendering with anti-aliasing. See [Rip-NeRF](15532-rip-nerf.md).

### [UE4-NeRF](15539-ue4-nerf.md)
UE4-NeRF is a neural rendering system designed for the real-time interactive rendering of large-scale scenes by partitioning environments into sub-NeRFs represented as textured polygonal meshes and integrating them into the Unreal Engine 4 (UE4) rasterization pipeline. Unlike standard differentiable volume rendering which relies on ray marching, UE4-NeRF converts the learned radiance field into explicit geometry (octahedral meshes) and neural shaders, enabling frame rates up to 43 FPS at 4K resolution. It distinguishes itself from sibling methods like Mobile-NeRF by using regular octahedra to handle tilted surfaces and from Block-NeRF by supporting non-grid terrains, while achieving significantly faster training times through multi-resolution hash encoding. It is chosen for real-time interactive rendering in game engines. See [UE4-NeRF](15539-ue4-nerf.md).

### [Generative Occupancy Fields (GOF)](15773-generative-occupancy-fields-gof.md)
Generative Occupancy Fields (GOF) is a 3D-aware image synthesis method that combines radiance fields with occupancy representations to learn compact object surfaces without impeding training convergence. It solves the problem of diffused surfaces in standard generative radiance fields (like GRAFs) and the sparse gradient convergence issues in direct occupancy networks by transitioning from cumulative volume rendering to surface-point rendering. Unlike siblings that predict volume density $\sigma$ and rely on cumulative alpha composition, GOF predicts alpha values $\alpha$ directly, reinterpreting them as occupancy to enable root-finding for precise surface location. It is chosen for high-quality 3D-aware image generation with sharp surfaces. See [Generative Occupancy Fields (GOF)](15773-generative-occupancy-fields-gof.md).

### [Panoptic Radiance Field](15849-panoptic-radiance-field.md)
Panoptic Lifting learns a panoptic 3D volumetric representation from posed RGB images and machine-generated 2D panoptic segmentation masks, lifting noisy 2D labels into a consistent 3D representation comprising color, density, semantics, and instances. It differs from sibling methods like [Panoptic NeRF](11916-panoptic-nerf.md) and [DM-NeRF](12073-dm-nerf.md) by requiring only machine-generated 2D labels rather than manual ground truth or coarse meshes, and by explicitly modeling instance consistency via surrogate identifiers and linear assignment. It is chosen for panoptic 3D scene understanding. See [Panoptic Radiance Field](15849-panoptic-radiance-field.md).

### [Frequency-Modulated Position Encoding](15897-frequency-modulated-position-encoding.md)
Frequency-Modulated Position Encoding is a coordinate encoding scheme used in point-based radiance field optimization to map raw 3D spatial coordinates and viewing directions into a higher-dimensional feature space suitable for neural network decoding. It distinguishes itself from standard NeRF positional encoding by narrowing the encoding interval (using powers of 2 with fractional exponents) to provide finer-grained basis function support for frequency modulation, which is critical for high-fidelity point cloud rendering. It serves as the input transformation stage for the AFNet MLP decoder in the FM-NeRF pipeline. It is chosen for point-based rendering requiring high-frequency detail. See [Frequency-Modulated Position Encoding](15897-frequency-modulated-position-encoding.md).

### [MoCo-NeRF](16197-moco-nerf.md)
MoCo-NeRF is a framework for free-viewpoint rendering of monocular human videos that models non-rigid body motions as radiance residual fields rather than spatial offsets. It separates the representation into a rigid canonical radiance field and a pose-dependent non-rigid residual field, allowing direct supervision from ground-truth pixel colors. Unlike offset-based strategies that suffer from high computational complexity and misaligned learning objectives, MoCo-NeRF reduces prediction range to the radiance space using rigid fields as a prior. It is chosen for dynamic human avatar rendering from monocular video. See [MoCo-NeRF](16197-moco-nerf.md).

### [UrbanIR](16200-urbanir.md)
UrbanIR is a method for inverse rendering of large-scale urban scenes from a single monocular video under single illumination, inferring shape, albedo, visibility, and sun/sky illumination to enable relighting and night simulation. It differs from standard NeRFs by learning intrinsic attributes (albedo, normal) independent of lighting, and from other relightable methods like NeRF-OSR or FEGR by requiring only single-illumination RGB video without LiDAR or multiple cameras. It is chosen for relightable urban scene reconstruction. See [UrbanIR](16200-urbanir.md).

#### Triplane NeRF with Diffusion Prior
- **Definition:** The framework uses a triplane NeRF representation where scene codes are optimized jointly with a diffusion prior to handle sparse-view data and ensure end-to-end coherence [S1].
- **Parameters:** Prediction Format uses v-parameterization $\hat{v}_\phi(x(t), t)$ from [43], such that $\hat{x} = \alpha(t)x(t) - \sigma(t)\hat{v}$. Weighting Function $w(t)$ uses SNR-based weighting $w(t) = (\alpha(t)/\sigma(t))^2\omega$ from Eq. (5), instead of LSGM mechanisms [S1].
- **Layout:** Scene code $x_i$ has shape $\mathbb{R}^{3 \times 6 \times 128 \times 128}$, representing a triplane NeRF representation. Denoising Network Input/Output involves noisy and denoised triplane features, with channels of all three planes stacked together. Denoising Network Architecture is a U-Net with 122M parameters [S1].

#### EG3D Triplane Representation
- **Steps:** Render feature image $I_f \in \mathbb{R}^{32 \times 128 \times 128}$ and raw RGB image $I_{128} \in \mathbb{R}^{3 \times 128 \times 128}$ by accumulating points along rays and performing volume rendering. Extract dense depth map $I_D \in \mathbb{R}^{128 \times 128}$ from the volume rendering. Feed $I_f$ and $I_{128}$ into a 2D super-resolution network to yield final output $I_{512} \in \mathbb{R}^{3 \times 512 \times 512}$ [S2].
- **Formula:** $\text{SuperRes}(I_f, I_{128}) = I_{512}$ [S2].
- **Parameters:** Image resolution is 512x512 for input images and final output [S2].
- **Layout:** Triplane representation $T$ is a tensor in $\mathbb{R}^{256 \times 256 \times 96}$, corresponding to 3 axis-aligned planes (xy, xz, yz), each with 32 channels and resolution 256x256 [S2].
- **Number:** Rendering speed is 42 fps on RTX 3090 [S2].

#### NeRF-W Hyperparameter Configuration
- **Parameters:** Base MLP: 8 layers of 512 hidden units. Static and Transient/Uncertainty MLPs: 4 layers of 128 hidden units each. Positional encoding frequencies: 15 for position, 4 for viewing direction. Sampling points: 512 per ray per model (coarse and fine) during training (1024 total), doubled to 2048 during evaluation. Appearance embedding dimension $n(a) = 48$. Transient object embedding dimension $n(\tau) = 16$. L1 regularizer multiplier $\lambda_u = 0.01$. Minimum importance threshold $\beta_{min} = 0.03$. Optimizer: Adam, batch size 2048, initial learning rate 0.001, decaying ten-fold every 150,000 iterations, over 300,000 iterations total [S3].
- **Number:** Hyperparameters were optimized for the Brandenburg Gate scene of the Phototourism dataset and reused for remaining scenes [S3].

#### Explicit Mesh Reconstruction from Neural Fields
- **Definition:** An algorithm to extract an explicit 3D mesh representation from the implicit neural radiance field learned by CodeNeRF, allowing for 3D reconstruction from a single input image [S4].
- **Steps:** Feed the center coordinates of a $256^3$ voxel grid to the CodeNeRF MLP to obtain volume density values $\sigma$. Apply the Marching Cubes algorithm to the volume density values $\sigma$ to find mesh vertices. Cast rays along the vertex normals of the generated mesh to associate colors to the vertices [S4].

#### Efficient EndoNeRF scene representation
- **Definition:** A voxel-grids-based scene representation that replaces coordinate-based MLPs with explicit density and feature volume grids to accelerate optimization, combined with a canonical field and time-dependent deformation field for dynamic surgical scenes [S5].
- **Steps:** The dynamic scene at time $t$ is modeled by warping a canonical radiance field (represented by $\mathbf{V}_\sigma$ and $\mathbf{V}_a$) with a time-dependent deformation field. The deformation field is modeled using decomposed 4D motion fields and a 3-layer MLP that maps a spatial-temporal coordinate to a deformation offset [S5].

#### NeRF-Liif
- **Definition:** A baseline method that super-resolves LR images using a pretrained LIIF (Local Implicit Image Function) model, which requires LR-HR pairs for training and introduces external data priors [S6].
- **Parameters:** Training data requirement: LR-HR pairs [S6].
- **Pitfalls:** On synthetic Blender dataset, LIIF may produce false predictions due to domain mismatch with its external training set. On real-world LLFF dataset, LIIF tends to be oversmooth and may predict false color or geometry [S6].
- **Number:** Blender ×2 (100x100): PSNR 27.07, SSIM 0.919, LPIPS 0.067. Blender ×4 (100x100): PSNR 25.36, SSIM 0.885, LPIPS 0.125. Blender ×2 (200x200): PSNR 28.81, SSIM 0.934, LPIPS 0.058. Blender ×4 (200x200): PSNR 27.34, SSIM 0.912, LPIPS 0.096. LLFF ×2: PSNR 26.81, SSIM 0.823, LPIPS 0.145. LLFF ×4: PSNR 24.76, SSIM 0.723, LPIPS 0.292 [S6].

#### UniSurf
- **Definition:** A method unifying volume rendering (radiance fields) and surface rendering (implicit surfaces) to achieve high-quality geometry and sharp textures without mask supervision [S7, unofficial].
- **Steps:** Uses an occupancy field where the occupancy at the $i^{th}$ sample corresponds to an indicator of surface presence. Uses volume rendering in the early stage for optimization without mask supervision. Uses surface rendering in the later stage to extract level-set surfaces [S7, unofficial].
- **Comparison:** Unlike pure surface rendering which requires mask supervision and has blurry texture mapping, this method provides high-quality novel views and sharp textures/colors without mask supervision [S7, unofficial].

## Background
The foundational NeRF architecture introduced in 2020 by Mildenhall et al. established the use of MLPs with sinusoidal positional encoding to represent continuous 3D scenes [S1]. Subsequent developments focused on improving efficiency (Instant-NGP with hash encoding [S1]), anti-aliasing (Mip-NeRF with integrated encoding [S1]), and generative capabilities (Diffusion NeRF with triplane codes [S1]). The field has evolved to include hybrid representations (Triplanes [S2], Binary Grids [S1]), dynamic scenes (SUDS [S1], MoCo-NeRF [S1]), and explicit geometry extraction (UE4-NeRF [S1], UniSurf [S7, unofficial]).
