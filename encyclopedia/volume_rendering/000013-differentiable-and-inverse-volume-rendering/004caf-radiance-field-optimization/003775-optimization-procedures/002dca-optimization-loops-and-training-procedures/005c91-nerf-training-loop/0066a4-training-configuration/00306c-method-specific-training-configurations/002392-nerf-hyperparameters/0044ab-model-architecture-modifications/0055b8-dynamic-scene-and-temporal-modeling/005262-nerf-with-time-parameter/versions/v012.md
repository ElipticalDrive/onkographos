# NeRF with Time Parameter

Also called: NeRF + time, NeRF with Time Parameter Baseline, Time-NeRF

## Overview
This method adapts the static Neural Radiance Field (NeRF) architecture for dynamic scenes by introducing a temporal dimension to the input space [S1]. It solves the problem of reconstructing time-varying geometry and appearance, which standard NeRF cannot handle due to its static assumption [S1]. Unlike sibling methods that model explicit motion fields or use complex graph structures, this approach simply augments the input vector with time, serving as a baseline for temporal NeRFs [S1]. It sets itself apart by its minimal architectural change, though it is noted to lack detail and suffer from blurry predictions compared to more advanced dynamic scene methods [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Spatial coordinates $\mathbf{x} = (x, y, z)$, viewing direction $\mathbf{d} = (d_x, d_y, d_z)$, and a scalar time parameter $t$.
*   **Outputs:** Volume density $\sigma$ and view-dependent color $\mathbf{c}$.

**Data Structures:**
The model is a Multi-Layer Perceptron (MLP) identical to the standard NeRF architecture [S1]. The input layer size is increased by one dimension to accommodate the time parameter.

**Steps:**
1.  **Positional Encoding of Time:** Apply the same positional encoding function $\gamma_t$ used for spatial coordinates to the time parameter $t$.
    $$ \gamma_t(t) = (\sin(2^0 \pi t), \cos(2^0 \pi t), \dots, \sin(2^{L-1} \pi t), \cos(2^{L-1} \pi t)) $$
    where $L$ is the number of frequency bands [S1].
2.  **Concatenation:** Concatenate the encoded time $\gamma_t(t)$ with the positional encoding of the spatial coordinates $\gamma_x(\mathbf{x})$.
    $$ \mathbf{z}_{input} = [\gamma_x(\mathbf{x}), \gamma_t(t)] $$
    Note: The viewing direction $\mathbf{d}$ is typically encoded separately and concatenated later in the standard NeRF pipeline, but the time parameter is specifically concatenated with the spatial encoding in this variant [S1].
3.  **Network Forward Pass:** Feed $\mathbf{z}_{input}$ into the first MLP (the density network) to produce intermediate features and density $\sigma$.
4.  **Color Prediction:** Concatenate the intermediate features with the encoded viewing direction $\gamma_d(\mathbf{d})$ and pass through the second MLP (the color network) to produce color $\mathbf{c}$ [S1].

**Parameters:**
*   **Training Configuration:** The method is trained using the same configuration reported for NeRF's real forward-facing experiments [S1]. Specific hyperparameters (learning rate, number of samples per ray, etc.) are not detailed in the sources but are assumed to match the standard NeRF baseline [S1].

**Edge Cases and Pitfalls:**
*   **Blurriness:** The method suffers from blurry predictions and lacks detail because it does not explicitly model scene dynamics or motion [S1].
*   **Ghosting:** While improved over vanilla NeRF, it may still exhibit artifacts if the temporal interpolation is insufficient for rapid scene changes [S1].
*   **Lack of Dynamics Reasoning:** The model cannot reason about scene dynamics beyond interpolation, leading to poor performance on complex temporal metrics [S1].

## Subtopics

### Temporal Compression of NeRF Models
A compression strategy for sequences of NeRF models that exploits temporal redundancy by treating the first model as a key-frame and compressing only the deltas between successive models [S2]. It is chosen when storage or transmission bandwidth for dynamic NeRF sequences is constrained [S2]. It sets itself apart by operating on the model weights rather than the input space, enabling efficient storage of time-varying scenes [S2].
*   **Definition:** Exploits the observation that neighboring NeRF models share considerable similarities [S2].
*   **Steps:**
    1.  Initialize the NeRF for the first frame from scratch (trained from the beginning) [S2].
    2.  For subsequent frames, initialize the new NeRF based on the previous frame's trained NeRF to encourage temporal redundancy and save training time [S2].
    3.  Calculate the delta between the current frame's NeRF weights and the previous frame's NeRF weights [S2].
    4.  Apply exponent-based quantization and Huffman coding to the deltas [S2].
    5.  To restore a model, accumulate the decoded deltas to the reference model (the previous frame's model) [S2].

## Operating characteristics
*   **Time Complexity:** Training time is comparable to standard NeRF, as the architectural change is minimal (one additional input dimension) [S1]. However, the compression variant reduces storage and potentially training time for subsequent frames by leveraging redundancy [S2].
*   **Memory Complexity:** Slightly higher than static NeRF due to the additional input dimension, but negligible in practice [S1]. The compression variant significantly reduces storage requirements by encoding deltas [S2].
*   **Measured Performance:** On KITTI scenes, "NeRF + time" achieves a PSNR of 24.18, SSIM of 0.677, and LPIPS of 0.425, which is an improvement over vanilla NeRF (PSNR 23.34, SSIM 0.662, LPIPS 0.415) but inferior to the proposed Neural Scene Graph method (PSNR 26.66, SSIM 0.806, LPIPS 0.186) [S1].
*   **Strengths:** Simple to implement; minimal change to existing NeRF codebases; improves quality over static NeRF for dynamic scenes [S1].
*   **Limitations:** Lacks detail; suffers from blurry predictions; fails to reason about scene dynamics; not suitable for complex dynamic scenes [S1].
*   **When to use:** As a baseline for dynamic scene reconstruction; when computational resources are limited and high fidelity is not required [S1].
*   **When not to use:** For scenes with complex motion or rapid changes where high temporal fidelity is required [S1].

## Background
The method was introduced in "Neural Scene Graphs for Dynamic Scenes" by Yuang Shi et al. (CVPR 2021) [S1]. It was proposed as a simple modification to address the limitations of static NeRF in dynamic environments [S1]. The temporal compression variant was later described in "Volumetric Video Compression Through Neural-based Representation" (ACM MM 2023) [S2].
