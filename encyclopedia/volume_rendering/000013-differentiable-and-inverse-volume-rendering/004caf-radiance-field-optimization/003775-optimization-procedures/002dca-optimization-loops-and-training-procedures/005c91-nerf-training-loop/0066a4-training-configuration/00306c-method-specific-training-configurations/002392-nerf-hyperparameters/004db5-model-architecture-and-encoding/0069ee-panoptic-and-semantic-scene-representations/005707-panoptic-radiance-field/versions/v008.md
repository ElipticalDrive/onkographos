# Panoptic Radiance Field

Also called: Panoptic Lifting

## Overview
Panoptic Lifting learns a panoptic 3D volumetric representation from posed RGB images and machine-generated 2D panoptic segmentation masks, lifting noisy 2D labels into a consistent 3D representation comprising color, density, semantics, and instances [S1]. It differs from sibling methods like [Panoptic NeRF](11916-panoptic-nerf.md) and [DM-NeRF](11916-dm-nerf.md) by requiring only machine-generated 2D labels rather than manual ground truth or coarse meshes, and by explicitly modeling instance consistency via surrogate identifiers and linear assignment [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** Posed RGB images $\{I\}$ and corresponding machine-generated 2D panoptic segmentation masks. Each training ray $r$ has an associated RGB color $\hat{c}_r \in \mathbb{R}^3$, a semantic class $\hat{k}_r \in K$, and a 2D instance ID $\hat{h}_r \in H_I$ (defined only for thing classes $\hat{k}_r \in K_T$) [S1].
*   **Outputs:** A panoptic radiance field $\Phi(\mathbf{x}, \mathbf{d})$ that renders RGB color $c$, density $\sigma$, semantic class distribution $\kappa$, and instance distribution $\pi$ for novel views [S1].

**Data Structures**
The field $\Phi(\mathbf{x}, \mathbf{d})$ assigns to each 3D point $\mathbf{x} \in \mathbb{R}^3$ and viewing direction $\mathbf{d} \in S^2$:
1.  Density $\sigma \in \mathbb{R}_{\ge 0}$.
2.  Semantic class distribution $\kappa$ over $K$ classes.
3.  Distribution $\pi$ over $J$ surrogate identifiers.
4.  RGB color $c \in \mathbb{R}^3$ [S1].

The architecture leverages **TensoRF** [4] for color and density, and two separate small **MLPs** for the semantic field ($\kappa$) and the instance field ($\pi$) [S1].
*   $K$: Set of semantic classes, partitioned into thing classes $K_T$ and stuff classes $K_S$.
*   $J$: Fixed number of class-agnostic, 3D-consistent surrogate object identifiers held by the instance MLP.
*   $H_{3D}$: Set of all possible 3D instances, defined as $H_{3D} := K_T \times J$ [S1].

**Rendering Equation**
Given density field $\sigma$, any vector field $f$ along ray $r$ is rendered as [S1]:
$$ R[f |r, \sigma] := \int_0^\infty \alpha_t (r)\sigma(r_t)f (r_t, \mathbf{d}_{r_t})dt $$
where $\alpha_t (r) := \exp \left(-\int_0^t \sigma(r_s)ds\right)$ is the transmittance probability at $t$ [S1].

**Training Steps**
1.  **Test-Time Augmentation (TTA) for Confidence:** Run test-time augmentations (horizontal flip, scale, brightness, contrast) on input images and fuse resulting segmentations by segment clustering to obtain a semantic class distribution $\hat{\kappa}_r$ and a confidence estimate $w_r$ for each pixel (ray $r$) [S1].
2.  **Linear Assignment for Instance Mapping:** Solve a linear assignment problem with a cost based on the model’s current predictions and the machine-generated segmentation masks. This maps each 2D instance $\hat{h}_r$ to a 3D surrogate identifier via an injective mapping $\Pi^*_R$, accounting for inconsistencies of 2D instance identifiers across views [S1].
3.  **Compute Losses:**
    *   **Semantic Loss ($L_{sem}$):** Supervise the semantic field directly with 2D labels using cross-entropy, weighted by confidence $w_r$. The field must render bounded probability distributions, not logits, to prevent semantic inconsistencies in low-density areas [S1].
        $$ L_{sem} (R) := -\frac{1}{|R|} \sum_{r \in R} w_r \sum_{k \in K} \hat{\kappa}_r (k) \log \kappa_r (k) $$
    *   **Instance Loss ($L_{ins}$):** Supervise the instance field using the mapped 2D instances. The loss minimizes the log-loss of the co-occurrence of the rendered instance distribution and the mapped surrogate identifiers [S1].
    *   **Segment Consistency Loss ($L_{con}$):** An additional loss to avoid optima that fragment objects in the presence of label inconsistencies [S1].
    *   **Photometric Loss ($L_{RGB}$):** Standard L2 loss on rendered color [S1].
4.  **Gradient Blocking:** Stop gradients from the semantic and instance branches back to the density/geometry parameters. This prevents noisy labels from influencing geometry and causing "cloudy" geometry that satisfies conflicting labels [S1].
5.  **Optimization:** Minimize the total loss using Adam [S1].

**Pseudocode**
```python
# Initialization
# tensorf_model: TensoRF model for density sigma and color c
# semantic_mlp: Small MLP for semantic distribution kappa
# instance_mlp: Small MLP for instance distribution pi
# optimizer: Adam optimizer with lr=5e-4 for MLPs, lr=1e-2 for TensoRF params
# K: Set of semantic classes
# J: Set of surrogate identifiers (fixed size)
# lambda_con = 1.35, lambda_ins = 1, lambda_sem = 1, lambda_rgb = 1

def render_ray(ray_r, tensorf_model, semantic_mlp, instance_mlp):
    # Sample points along ray_r
    points = sample_points_along_ray(ray_r)
    
    # Query TensoRF for density and color
    sigma = tensorf_model.get_density(points)
    color = tensorf_model.get_color(points, ray_r.direction)
    
    # Query Semantic MLP for class distribution
    # Note: Must output bounded probabilities, not logits
    kappa = semantic_mlp.get_probability_distribution(points)
    
    # Query Instance MLP for surrogate ID distribution
    pi = instance_mlp.get_probability_distribution(points)
    
    # Volumetric Rendering
    # Alpha transmittance
    alpha = exp(-sigma * delta_t) # delta_t is step size
    
    # Rendered Color
    c_rendered = sum(alpha * color * transmittance_accumulated)
    
    # Rendered Semantic Distribution
    kappa_rendered = sum(alpha * kappa * transmittance_accumulated)
    
    # Rendered Instance Distribution
    pi_rendered = sum(alpha * pi * transmittance_accumulated)
    
    return c_rendered, sigma, kappa_rendered, pi_rendered

def train_step(batch_rays, ground_truth_colors, ground_truth_semantics, ground_truth_instances):
    # 1. Get Confidence Estimates via TTA (Pre-computed or cached)
    # w_r, kappa_hat_r are obtained from TTA fusion
    
    total_loss = 0
    
    for ray_r in batch_rays:
        # 2. Render
        c_r, sigma_r, kappa_r, pi_r = render_ray(ray_r, tensorf_model, semantic_mlp, instance_mlp)
        
        # 3. Compute Photometric Loss
        loss_rgb = L2(c_r, ground_truth_colors[ray_r])
        
        # 4. Compute Semantic Loss (Cross-Entropy weighted by confidence)
        # Only for rays with valid semantic labels
        if ray_r.has_semantic_label:
            # Ensure kappa_r is probability distribution
            kappa_r_prob = softmax(kappa_r) # Or bounded output from MLP
            loss_sem = -ground_truth_semantics[ray_r].log(kappa_r_prob) * ray_r.confidence
            total_loss += lambda_sem * loss_sem
        
        # 5. Compute Instance Loss
        if ray_r.has_instance_label:
            # Map 2D instance to 3D surrogate ID via Linear Assignment
            surrogate_id = linear_assignment_map(ray_r.instance_id, current_model_predictions)
            
            # Loss minimizes log-loss of co-occurrence
            # Assuming pi_r is distribution over J
            target_pi = one_hot(surrogate_id, size=len(J))
            loss_ins = CrossEntropy(pi_r, target_pi)
            total_loss += lambda_ins * loss_ins
            
            # 6. Segment Consistency Loss (Simplified)
            # Encourages consistent instance IDs for spatially nearby points with same label
            loss_con = compute_segment_consistency_loss(pi_r, ray_r)
            total_loss += lambda_con * loss_con
            
        # 7. Gradient Blocking
        # Detach sigma from semantic and instance branches
        sigma_detached = sigma_r.detach()
        
        # Note: In practice, this is done by not passing gradients from 
        # semantic/instance heads to the shared geometry encoder (TensoRF)
        
    # Add RGB loss (usually sampled across scene)
    total_loss += lambda_rgb * loss_rgb
    
    # Backpropagate and update
    optimizer.zero_grad()
    total_loss.backward()
    optimizer.step()
```

**Parameters**
*   **Optimizer:** Adam [S1].
*   **Learning Rates:** $5 \times 10^{-4}$ for MLPs, $1 \times 10^{-2}$ for TensoRF lines and planes [S1].
*   **Loss Weights:** $\lambda_{con} = 1.35$, $\lambda_{ins} = 1$, $\lambda_{sem} = 1$, $\lambda_{RGB} = 1$ [S1].
*   **Training Duration:** 450k iterations (~10 hours) on 1 NVIDIA A6000 [S1].
*   **2D Segmenter:** Mask2Former with Swin-L backbone [S1].

**Edge Cases and Pitfalls**
*   **Logits vs. Probabilities:** Rendering class logits instead of probabilities can introduce semantic inconsistencies across viewpoints because unbounded logits can generate significant signals in low-density areas, violating geometric constraints. This is resolved by rendering bounded probability distributions [S1].
*   **Geometry Corruption:** Supervision from noisy 2D labels can influence geometry, causing "cloudy" geometry to satisfy conflicting labels. This is avoided by stopping gradients from segmentation branches back to densities [S1].
*   **Class Limitations:** The method is limited to classes supported by the pre-trained 2D panoptic segmentation model (e.g., COCO classes if using Mask2Former) [S1].
*   **Offline Nature:** The method runs offline due to lengthy pre-processing for pose estimation, 2D segmentation inference, and neural field optimization [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Training requires 450k iterations (~10 hours) on a single NVIDIA A6000 [S1]. Memory usage is driven by the TensoRF representation and the two MLPs.
*   **Measured Performance:** Improves scene-level Panoptic Quality (PQ) by 8.4% on Hypersim, 13.8% on Replica, and 10.6% on ScanNet over state-of-the-art methods [S1]. Maintains comparable PSNR for novel view synthesis while outperforming competitors in mIoU and PQ_scene [S1].
*   **Strengths:** Robust to inherent noise in machine-generated labels; requires no manual ground truth; enables 3D-consistent panoptic segmentation and scene editing (deletion, duplication, manipulation) [S1].
*   **Limitations:** Limited to classes in the pre-trained 2D segmenter; offline processing; relies on accurate pose estimation [S1].
*   **When to use:** When only machine-generated 2D labels are available and 3D-consistent panoptic understanding is required.
*   **When not to use:** When real-time processing is needed or when classes outside the pre-trained 2D model's vocabulary are required [S1].

## Background
Panoptic Lifting was introduced in "Panoptic Lifting for 3D Scene Understanding with Neural Fields" (CVPR 2023) [S1]. It addresses the limitation of previous panoptic NeRF methods (like Panoptic NeRF and DM-NeRF) which required manual ground truth (coarse meshes or per-image 2D panoptic segmentations) [S1]. It builds on the TensoRF architecture [4] and leverages advances in 2D panoptic segmentation (e.g., Mask2Former) [S1].
