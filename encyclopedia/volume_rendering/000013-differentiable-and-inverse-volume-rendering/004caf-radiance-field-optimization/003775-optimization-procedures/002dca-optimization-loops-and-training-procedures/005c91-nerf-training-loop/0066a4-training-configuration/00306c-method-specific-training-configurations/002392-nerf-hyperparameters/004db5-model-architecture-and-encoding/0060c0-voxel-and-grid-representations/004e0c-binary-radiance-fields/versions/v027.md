# Binary Radiance Fields

Also called: BRF, BiRF, Binarized Radiance Fields

## Overview
Binary Radiance Fields (BiRF) is a storage-efficient radiance field representation that constrains feature grid parameters to binary values $\{-1, +1\}$ to drastically reduce memory footprint while maintaining reconstruction quality [S2]. It differs from post-processing compression methods (e.g., PlenOctrees, Re:NeRF) by performing binarization during training without requiring additional optimization steps, and it improves upon standard hash encoding by using a 2D-3D hybrid grid to mitigate hash collisions at high resolutions [S2].

## How it works
**Inputs and Outputs**
*   **Inputs:** 3D position $\mathbf{x} \in \mathbb{R}^3$, viewing direction $\mathbf{d} \in \mathbb{R}^3$, and camera parameters for ray sampling.
*   **Outputs:** Volume density $\sigma \in \mathbb{R}$ and RGB color $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures**
The core data structure is a multi-resolution hybrid feature grid consisting of one 3D voxel grid and three orthogonal 2D plane grids, all implemented using hash encoding [S2].
1.  **3D Voxel Grid ($\Phi_{\theta_{xyz}}$):** Contains $L$ resolution levels. Resolutions range from 16 to 1024. Each level stores up to $T_{3D}$ feature vectors.
2.  **2D Plane Grids ($\Phi_{\theta_{xy}}, \Phi_{\theta_{xz}}, \Phi_{\theta_{yz}}$):** Three grids corresponding to projections along the z, y, and x axes. Each contains $M$ resolution levels. Resolutions range from 64 to 512. Each level stores up to $T_{2D}$ feature vectors.
3.  **Feature Values:** All grid parameters are binary, constrained to $\{-1, +1\}$. Each feature vector has dimension $F$.
4.  **MLPs:**
    *   Density MLP: 1 hidden layer, 128 channels, ReLU activation.
    *   Color MLP: 2 hidden layers, 128 channels, ReLU activation.
    *   Directional Encoding: Spherical harmonics basis functions [S2].

**Parameters**
*   $L$: Number of 3D grid levels.
*   $M$: Number of 2D grid levels.
*   $T_{3D}$: Max feature vectors per 3D level.
*   $T_{2D}$: Max feature vectors per 2D level.
*   $F$: Feature dimension per level.
*   $\lambda_{\text{sparsity}}$: Sparsity loss weight. Default: $2.0 \times 10^{-5}$ [S2].
*   Model Variants:
    *   Small (Ours-S): $\log_2(T_{3D}) = 17, \log_2(T_{2D}) = 15$.
    *   Base (Ours-B): $\log_2(T_{3D}) = 19, \log_2(T_{2D}) = 17$.
    *   Suffix (e.g., Ours-B2): $F \in \{2, 4, 8\}$ [S2].

**Numbered Steps**
1.  **Binarization:** Maintain real-valued parameters $\theta$ in memory. During the forward pass, compute binary parameters $\theta'$ using the sign function:
    $$ \theta' = \text{sign}(\theta) = \begin{cases} +1 & \text{if } \theta \ge 0 \\ -1 & \text{otherwise} \end{cases} $$
    [S2]
2.  **Gradient Propagation (STE):** Backpropagate gradients through the sign function using the Straight-Through Estimator (STE). The gradient is passed unchanged if $|\theta| \le 1$, and zero otherwise. This prevents scale divergence and constrains values to $\{-1, 1\}$ [S2].
3.  **3D Feature Encoding:** For input coordinate $\mathbf{x}$, compute features from the 3D grid by tri-linearly interpolating the binary parameters across $L$ levels and concatenating them:
    $$ \mathbf{f}_{xyz} = \left\{ \text{interp}(\mathbf{x}, \text{sign}(\Phi^l_{\theta_{xyz}})) \right\}_{l=1}^L $$
    where $\text{interp}$ denotes tri-linear interpolation [S2].
4.  **2D Feature Encoding:** Project $\mathbf{x}=(x,y,z)$ to 2D coordinates: $\mathbf{x}_{xy}=(x,y)$, $\mathbf{x}_{xz}=(x,z)$, $\mathbf{x}_{yz}=(y,z)$. For each axis, bi-linearly interpolate binary parameters across $M$ levels and concatenate:
    $$ \mathbf{f}_{xy} = \left\{ \text{interp}(\mathbf{x}_{xy}, \text{sign}(\Phi^m_{\theta_{xy}})) \right\}_{m=1}^M $$
    Repeat for $\mathbf{f}_{xz}$ and $\mathbf{f}_{yz}$ [S2].
5.  **Feature Concatenation:** Combine all encoded features:
    $$ \mathbf{f} = \{ \mathbf{f}_{xyz}, \mathbf{f}_{xy}, \mathbf{f}_{xz}, \mathbf{f}_{yz} \} $$
    [S2]
6.  **Positional Encoding:** Apply hierarchical sinusoidal positional encoding $\gamma(\cdot)$ to the input 3D coordinate $\mathbf{x}$ [S1].
7.  **Density Prediction:** Feed $\gamma(\mathbf{x})$ and $\mathbf{f}$ into the density MLP:
    $$ (\sigma, \mathbf{e}) = \text{MLP}_{\text{density}}(\gamma(\mathbf{x}), \mathbf{f}) $$
    where $\sigma$ is density and $\mathbf{e}$ is the embedded feature [S2].
8.  **Color Prediction:** Feed $\mathbf{e}$ and directional encoding $\mathbf{d}$ (using spherical harmonics) into the color MLP:
    $$ \mathbf{c} = \text{MLP}_{\text{color}}(\mathbf{e}, \mathbf{d}) $$
    [S2]
9.  **Loss Calculation:** Compute reconstruction loss $L_{\text{recon}}$ and sparsity loss $L_{\text{sparsity}}$:
    $$ L_{\text{recon}} = \sum_{\mathbf{r} \in \mathcal{R}} ||\hat{C}(\mathbf{r}) - C(\mathbf{r})||_2^2 $$
    $$ L_{\text{sparsity}} = \sum_{i,k} \log(1 + 2\sigma(\mathbf{r}_i(t_k))^2) $$
    Total loss: $L = L_{\text{recon}} + \lambda_{\text{sparsity}} L_{\text{sparsity}}$ [S2].

**Edge Cases and Pitfalls**
*   **Hash Collisions:** 3D grids suffer from hash collisions at higher resolutions. The hybrid 2D-3D design mitigates this by supplementing the 3D grid with 2D grids, which reinforce features with fewer parameters [S2].
*   **Gradient Vanishing:** The derivative of the sign function is zero almost everywhere. The Straight-Through Estimator (STE) solves this by passing gradients through the threshold function during training [S2].
*   **Scale Divergence:** Large values of $\theta$ can cause divergence. STE stops propagating gradients when $|\theta| > 1$, constraining the value to $\{-1, 1\}$ [S2].

## Operating characteristics
*   **Storage:** Extremely compact. Ours-S2 requires < 0.5 MB, outperforming TensoRF-CP (3.7 MB) and Instant-NGP (24.5 MB) on the mic scene [S2].
*   **Performance:** PSNR of 32.03 dB on Synthetic-NeRF, 34.48 dB on Synthetic-NSVF, and 28.20 dB on Tanks and Temples [S2].
*   **Training Time:** Approximately 6, 9, and 14 minutes for Synthetic-NeRF scenes using Ours-B2 to Ours-B8 models on a single NVIDIA RTX A6000 [S2].
*   **Strengths:** Significant reduction in storage overhead compared to real-valued floating-point grids; no post-optimization required; superior reconstruction quality compared to prior efficient methods with smaller storage [S2].
*   **Limitations:** Binary quantization may limit representational capacity compared to full-precision models, though the hybrid grid mitigates this [S2].

## Background
Binary Radiance Fields (BiRF) was proposed by Seungjoo Shin and Jaesik Park in 2023 [S2]. It addresses the storage burden of implicit feature embeddings in methods like Instant-NGP by binarizing parameters to $\{-1, +1\}$ [S1]. The method builds on the multi-resolution hash encoding architecture and incorporates insights from NVP regarding 2D plane grids [S2]. It is implemented based on Instant-NGP using the occupancy grid from NerfAcc [S2].
