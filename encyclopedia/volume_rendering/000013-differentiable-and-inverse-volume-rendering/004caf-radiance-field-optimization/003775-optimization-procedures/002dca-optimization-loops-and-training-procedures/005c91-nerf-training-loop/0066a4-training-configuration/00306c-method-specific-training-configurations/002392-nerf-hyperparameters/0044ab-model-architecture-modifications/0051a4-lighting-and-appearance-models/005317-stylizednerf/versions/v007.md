# StylizedNeRF

Also called: StyleNeRF

## Overview
StylizedNeRF (also referred to as StyleNeRF in its primary architectural formulation) is a method for high-resolution, 3D-consistent image synthesis that integrates style-based generation into a Neural Radiance Field (NeRF) backbone [S2, unofficial]. It solves the problem of generating high-fidelity, view-consistent images with arbitrary styles by decoupling the 3D geometry representation from the 2D appearance style [S2, unofficial]. Unlike standard NeRF which maps 3D coordinates directly to color, StylizedNeRF uses a style-based generator (inspired by StyleGAN2) to modulate the NeRF's feature representations, allowing for the synthesis of diverse styles while maintaining 3D structural consistency [S2, unofficial]. It differs from siblings like [Spherical Harmonics NeRF](14480-spherical-harmonics-nerf.md) by focusing on generative style transfer rather than lighting decomposition, and from [Neural Pre-Integrated Lighting](13783-neural-pre-integrated-lighting-neural-pil.md) by prioritizing appearance synthesis over physical light transport accuracy.

## How it works
**Inputs and Outputs:**
*   **Inputs:** Latent codes $\mathbf{w}$ sampled from a standard Gaussian distribution; 3D position $\mathbf{x}$; view direction $\mathbf{d}$.
*   **Outputs:** Volume density $\sigma$ and color $\mathbf{c}$ for a given ray, or rendered 2D images for a given camera pose.

**Data Structures:**
1.  **Mapping Network:** A multi-layer perceptron (MLP) that maps the latent code $\mathbf{w} \sim \mathcal{N}(0, I)$ to a style vector $\mathbf{s}$. The output vectors are broadcast to the synthesis networks [S2, unofficial].
2.  **Synthesis Network (NeRF++ Backbone):**
    *   **Foreground NeRF:** An MLP predicting density $\sigma_f$ and features for a unit sphere.
    *   **Background NeRF:** An MLP with fewer parameters predicting density $\sigma_b$ using inverted sphere parameterization for unbounded backgrounds [S2, unofficial].
    *   **Shared Color MLP:** Predicts color $\mathbf{c}$ conditioned on features and style [S2, unofficial].
3.  **Style-Conditioned Block:** Consists of an affine transformation layer and a $1 \times 1$ Convolution layer (Conv) [S2, unofficial].
    *   **Affine Transformation:** Modulates the style vector $\mathbf{s}$ into scale $\gamma$ and shift $\beta$.
    *   **Conv Layer:** Weights are modulated by $\gamma$ and $\beta$, then demodulated for computation.
    *   **Activation:** Leaky ReLU [S2, unofficial].

**Algorithm Steps:**
1.  **Latent Sampling:** Sample a latent code $\mathbf{w}$ from a standard Gaussian distribution [S2, unofficial].
2.  **Style Generation:** Pass $\mathbf{w}$ through the Mapping Network to obtain the style vector $\mathbf{s}$ [S2, unofficial].
3.  **Ray Casting:** For each pixel, cast a ray defined by origin $\mathbf{o}$ and direction $\mathbf{d}$. Sample points $\mathbf{x}_i$ along the ray.
4.  **Feature Extraction:**
    *   For each point $\mathbf{x}_i$, determine if it lies within the foreground unit sphere or the background.
    *   If foreground, pass $\mathbf{x}_i$ through the Foreground NeRF to get density $\sigma_f$ and features $\mathbf{h}_f$.
    *   If background, pass $\mathbf{x}_i$ through the Background NeRF to get density $\sigma_b$ and features $\mathbf{h}_b$.
5.  **Style Modulation:**
    *   Apply the Style-Conditioned Block to the features $\mathbf{h}$ using the style vector $\mathbf{s}$.
    *   Compute affine transformation parameters $(\gamma, \beta)$ from $\mathbf{s}$.
    *   Modulate features: $\mathbf{h}' = \gamma \odot \mathbf{h} + \beta$.
    *   Pass $\mathbf{h}'$ through the $1 \times 1$ Conv layer.
    *   Demodulate the convolution output to ensure stable training [S2, unofficial].
6.  **Color Prediction:** Pass the modulated features through the Shared Color MLP to predict color $\mathbf{c}_i$ [S2, unofficial].
7.  **Volume Rendering:** Compute transmittance $T_i$ and opacity $\alpha_i$ as in standard NeRF. Render the final color $\hat{C}(r)$ using the standard volume rendering integral [Parent](3065-nerf-hyperparameters.md).
8.  **Training Optimization:**
    *   Use a non-saturating GAN objective with R1 regularization [S2, unofficial].
    *   Employ a NeRF path regularization loss to enforce 3D consistency [S2, unofficial].
    *   Use a mutual learning strategy if optimizing a stylized NeRF alongside a 2D stylization network, handling ambiguities via learnable latent codes [S1].

**Parameters:**
*   **Input Resolution:** Fixed at $32^2$ for all experiments [S2, unofficial].
*   **Batch Size:** 64 images per batch [S2, unofficial].
*   **Training Steps:** $T_1 = 500k$, $T_2 = 5000k$, $T_3 = 25000k$ images [S2, unofficial].
*   **Activation:** Leaky ReLU [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Small Datasets:** The method may fail to train stably on small datasets (e.g., CelebFaces) and requires fine-tuning from a pretrained model (e.g., FFHQ) [S2, unofficial].
*   **3D Consistency:** Without proper regularization, the style modulation may introduce 3D inconsistencies, such as shape or appearance changes when the camera moves [S2, unofficial].

## Subtopics

### StyleNeRF Architecture
This variant refers to the specific architectural implementation described in [S2, unofficial], which uses NeRF++ as the backbone and integrates StyleGAN2-style mapping and synthesis networks. It differs from other stylization methods by explicitly using affine transformations and $1 \times 1$ convolutions to modulate NeRF features, ensuring that the style is applied consistently across different viewpoints. It is chosen when high-resolution, 3D-consistent style transfer is required for unbounded scenes.

## Operating characteristics
*   **Time Complexity:** Training is computationally intensive due to the GAN objective and the dual-MLP structure (foreground/background). The use of NeRF++ adds complexity compared to standard NeRF.
*   **Memory Complexity:** Higher memory usage than standard NeRF due to the additional Mapping Network, Style-Conditioned Blocks, and Discriminator. The input resolution is fixed at $32^2$ for training, but target images are resized to $256^2$ for evaluation [S2, unofficial].
*   **Performance:** Achieves high-quality and 3D-consistent results, outperforming baselines like HoloGAN, GARF, and $\pi$-GAN which suffer from severe artifacts or 3D inconsistency [S2, unofficial].
*   **Strengths:** High resolution, 3D consistency, ability to handle unbounded backgrounds.
*   **Limitations:** Requires large datasets for stable training; computationally expensive; sensitive to hyperparameters.
*   **When to use:** When generating high-fidelity, stylized 3D-aware images is the primary goal.
*   **When not to use:** When working with small datasets or when computational resources are limited.

## Background
StylizedNeRF (StyleNeRF) was introduced in the paper "StyleNeRF: A Style-based 3D-Aware Generator for High-resolution Image Synthesis" [S2, unofficial]. It builds on the NeRF++ architecture [S2, unofficial] and the StyleGAN2 framework [S2, unofficial]. The method was developed to address the limitations of previous 3D-aware generative models that failed to learn correct geometry or produced 3D inconsistent artifacts. It is used in applications requiring high-resolution, style-controlled 3D image synthesis.
