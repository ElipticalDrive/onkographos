# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF training configuration defines the optimization procedure for text-guided stylization of Neural Radiance Fields (NeRFs) by minimizing the negative cosine similarity between rendered images and text prompts in the CLIP embedding space [S1, S2]. It distinguishes itself from standard NeRF training by freezing density-related parameters and utilizing patch-based rendering to manage memory constraints while enforcing stylistic trajectories via directional CLIP losses [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A pre-trained NeRF model (encoding $\mathbf{x} \in \mathbb{R}^3$ and direction $\mathbf{d} \in S^2$ to density $\sigma$ and color $\mathbf{c}$), a target text prompt $\mathbf{t}_{tgt}$, and optionally a source image $\mathbf{I}_{src}$ and source text prompt $\mathbf{t}_{src}$ for relative loss.
*   **Outputs:** A stylized NeRF model with updated appearance parameters.

**Data Structures:**
*   **CLIP Encoder:** Uses CLIP ViT-B/32 [S1]. The image encoder $\mathcal{E}_i$ and text encoder $\mathcal{E}_t$ map inputs to normalized embedding vectors $\hat{\mathbf{e}} \in \mathbb{R}^D$ [S2].
*   **Patch Rendering Buffer:** Stores rendered color values for a $128 \times 128$ patch [S1].

**Parameters:**
*   **Iterations:** 500 [S1].
*   **Optimizer:** Adam with learning rate $\eta = 0.0001$ [S1].
*   **Patch Size:** $128 \times 128$ pixels [S1].
*   **Ray Sampling Stride:** 5 within the patch, resulting in a receptive field of $640 \times 640$ on the original image [S1].
*   **Importance Sampling Points:** 16 per ray during patch rendering [S1].
*   **Fine MLP Samples:** 80 total (64 coarse + 16 fine) [S1].
*   **Freezing:** Sub-parameters related to density $\sigma$ are frozen; only appearance/stylization parameters are optimized [S1].

**Loss Functions:**
Two variants of directional CLIP loss are used [S2]:

1.  **Absolute Directional CLIP Loss:** Measures cosine similarity between the rendered image $\mathbf{I}_{tgt}$ and the target text prompt $\mathbf{t}_{tgt}$ [S2].
    $$ \mathcal{L}_{dir} = \sum \left( 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) \rangle \right) $$
    where $\langle \cdot, \cdot \rangle$ denotes the dot product of normalized vectors [S2].

2.  **Relative Directional CLIP Loss:** Transfers style from a source domain to a target domain using a pair of text prompts $(\mathbf{t}_{src}, \mathbf{t}_{tgt})$ [S2].
    $$ \mathcal{L}_{dir} = \sum \left( 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}) - \hat{\mathcal{E}}_i(\mathbf{I}_{src}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) - \hat{\mathcal{E}}_t(\mathbf{t}_{src}) \rangle \right) $$
    where $\mathbf{I}_{tgt}$ is an arbitrarily sampled view rendered from the NeRF [S2].

**Algorithm:**
1.  Initialize NeRF model with pre-trained weights [S1].
2.  Freeze density-related MLP weights [S1].
3.  For iteration $k = 1$ to 500:
    a. Randomly sample a training view pose [S1].
    b. Define a $128 \times 128$ patch on the image plane [S1].
    c. Sample rays for the patch with stride 5 [S1].
    d. Render the patch using volume rendering with 16 importance samples per ray and 80 total fine samples [S1].
    e. Resize the rendered patch via bilinear interpolation to match CLIP input dimensions [S1].
    f. Compute embeddings $\hat{\mathcal{E}}_i(\mathbf{I}_{patch})$ and $\hat{\mathcal{E}}_t(\mathbf{t}_{tgt})$ [S1, S2].
    g. Compute $\mathcal{L}_{dir}$ (absolute or relative) [S2].
    h. Backpropagate $\mathcal{L}_{dir}$ through the appearance parameters using Adam ($\eta=0.0001$) [S1].
4.  Return optimized NeRF [S1].

**Edge Cases and Pitfalls:**
*   **Memory Constraints:** Naive differentiable rendering of high-resolution images is intractable due to memory limits [S1]. Patch-based rendering with reduced sampling is required [S1].
*   **Mode Collapse:** Absolute directional CLIP loss can cause mode collapse of the generator and hurt generation diversity [S2].
*   **Insufficient Magnitude:** Directional loss only measures trajectory similarity and ignores magnitude, potentially resulting in weak style transfer [S2].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Reduced by using $128 \times 128$ patches and 16 importance samples per ray, avoiding full-image rendering [S1].
*   **Strengths:** Enables text-guided stylization of NeRFs; efficient memory usage via patch rendering [S1, S2].
*   **Limitations:** Absolute loss risks mode collapse; directional loss may lack sufficient stylization magnitude [S2].
*   **When to use:** Text-driven NeRF stylization where memory is constrained [S1, S2].
*   **When not to use:** When high-fidelity magnitude preservation is critical without additional contrastive losses [S2].

## Background
CLIPNeRF was introduced by Wang et al. in 2021, extending StyleCLIP [Patashnik et al. 2021] and StyleGAN-NADA [Gal et al. 2021] to 3D scene representation [S2]. It uses the absolute directional CLIP loss to guide NeRF rendering with a global direction of the target text [S2]. Subsequent work, NeRF-Art (2023), proposed relative directional loss and global-local contrastive learning to address mode collapse and insufficient magnitude issues [S2]. The implementation often follows the configuration described in "Decomposing NeRF for Editing Via Feature Field Distillation" [S1].
