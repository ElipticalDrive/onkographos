# MZEN (Multi-zoom Enhanced NeRF)
Also called: Multi-zoom Enhanced NeRF

## Overview
MZEN is a framework for 3-D reconstruction from images with unknown camera poses and varying optical magnifications, explicitly modeling optical zoom as a learnable intrinsic parameter [S1]. It solves the problem of geometric inconsistency in pose-free NeRF when magnification changes significantly, which typically couples translation, scale, and focal length in an unidentifiable way [S1]. Unlike Mip-NeRF, Zip-NeRF, and CamP, which require high-resolution image pyramids or external pose initialization, MZEN keeps every frame at native resolution and uses a three-phase training schedule with cross-zoom pose registration to align non-overlapping zoomed-in and zoomed-out views [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ images $\mathcal{I} = \{I_k\}_{k=1}^N$. The set is partitioned into $N_{out}$ zoomed-out images (indices $i=1 \dots N_{out}$) and $N_{in}$ zoomed-in images (indices $j=N_{out}+1 \dots N$). Each image has a rough initial estimate of its zoom parameter $\xi_k$ (e.g., from a dial reading or apparent size comparison) [S1].
*   **Outputs:** NeRF network parameters $\Theta$, camera poses $\Pi = \{R_k, t_k\}_{k=1}^N$, base intrinsics $f=(f_x, f_y)$, principal point $c=(c_x, c_y)$, and per-view zoom parameters $\{\xi_k\}_{k=1}^N$ [S1].

**Data Structures:**
*   **Camera Pose $\Pi_k$:** Tuple $(R_k, t_k, f, c, \xi_k)$ where $R_k \in SO(3)$, $t_k \in \mathbb{R}^3$, $f \in \mathbb{R}^2$, $c \in \mathbb{R}^2$, $\xi_k \in \mathbb{R}$ [S1].
*   **Effective Intrinsic Matrix:** $K_{eff}^k = \text{diag}(\xi_k f_x, \xi_k f_y, 1)$ [S1].
*   **Renderer:** $F_\Theta(\Theta, \Pi_k)$ returns the rendered RGB image for pose $\Pi_k$ using differentiable volume rendering [S1].

**Parameters:**
*   $\xi_k$: Zoom parameter. Initialized to 1 for zoomed-out views ($i \le N_{out}$) and $>1$ for zoomed-in views ($j > N_{out}$) [S1].
*   $\eta$: Step size for gradient descent, satisfying $\eta \in (0, 1/L]$ where $L$ is the Lipschitz constant of the gradients [S1].
*   $\mu$: Polyak-Łojasiewicz (PL) constant, $\mu > 0$ [S1].

**Algorithm Steps:**

1.  **Phase A: Global Pose Bootstrap**
    *   Initialize zoom parameters for the $N_{out}$ most zoomed-out images: $\xi_i = 1$ for $i=1 \dots N_{out}$ [S1].
    *   Randomly initialize NeRF parameters $\Theta^{(A)}$, rotations $R_i$, translations $t_i$, and base focal length $f^{(A)}$ [S1].
    *   Withhold all zoomed-in images ($j > N_{out}$) from the loss calculation [S1].
    *   Optimize $\Theta^{(A)}$, $\{R_i, t_i\}_{i=1}^{N_{out}}$, and $f^{(A)}$ by minimizing the coarse loss:
        $$ L_{coarse} = \sum_{i=1}^{N_{out}} \| F_{\Theta^{(A)}}(\Theta^{(A)}, \Pi^{(A)}) - I_i \|_2^2 $$
        where $\Pi_i = (R_i, t_i, f^{(A)}, c, \xi_i)$ [S1].
    *   Result: Coarse NeRF parameters $\Theta^{(A)}$ and globally consistent poses for zoomed-out views $\Pi^{(A)}$ [S1].

2.  **Cross-Zoom Pose Registration (Initialization for Phase B)**
    *   For each zoomed-in image $I_j$ ($j > N_{out}$):
        *   Find the best matching zoomed-out image index $g^*(j)$ from $\{1, \dots, N_{out}\}$ by minimizing the RGB mean-squared error between $I_j$ and a surrogate view $\tilde{I}_{g \to j}$ [S1].
        *   The surrogate view $\tilde{I}_{g \to j}$ is created by extracting the central $1/\xi_j$ crop from the rendered zoomed-out image $I_{g}$ (using current estimates) and bilinearly resizing it to the native resolution of $I_j$ [S1].
        *   Initialize the pose for $I_j$ by copying $R_j, t_j, f, c$ from the surrogate's source view $g^*(j)$ and setting $\xi_j$ to its initial estimate [S1]. This is "pose priming" [S1].

3.  **Phase B: Zoom-in Pose Registration**
    *   Freeze NeRF parameters at $\Theta^{(A)}$ [S1].
    *   For each zoomed-in image $j$, optimize only its pose parameters $\Pi_j = (R_j, t_j, f, c, \xi_j)$ by minimizing the pose loss:
        $$ L_{pose} = \sum_{j=N_{out}+1}^{N} \| F_{\Theta^{(A)}}(\Theta^{(A)}, \Pi_j) - I_j \|_2^2 $$
    *   Intrinsics $f, c$ are copied from the surrogate and remain fixed during this phase [S1].
    *   Result: Provisional full pose set $\Pi^{(B)} = \{\Pi_i^{(A)}\}_{i=1}^{N_{out}} \cup \{\Pi_j^{(B)}\}_{j=N_{out}+1}^{N}$ [S1].

4.  **Phase C: Joint Refinement**
    *   Initialize NeRF parameters $\Theta^{(C)} = \Theta^{(A)}$ [S1].
    *   Unfreeze all parameters: NeRF weights $\Theta$, all camera poses $\Pi$, and all zoom parameters $\{\xi_k\}$ [S1].
    *   Optimize jointly by minimizing the fine loss over all $N$ images:
        $$ L_{fine} = \sum_{k=1}^{N} \| F_{\Theta^{(C)}}(\Theta^{(C)}, \Pi_k) - I_k \|_2^2 $$
    *   Result: Final pixel-accurate poses and refined NeRF parameters [S1].

**Pseudocode:**

```python
def mzen_train(images, initial_zoom_estimates, N_out):
    """
    images: List of N images [I_1, ..., I_N]
    initial_zoom_estimates: List of N zoom values [xi_1, ..., xi_N]
    N_out: Number of zoomed-out images
    """
    
    # --- Phase A: Global Pose Bootstrap ---
    # Initialize parameters
    theta = random_init_nerf()
    poses_out = []
    for i in range(N_out):
        # Zoom parameter fixed at 1 for zoomed-out views
        xi = 1.0 
        # Random init for pose, shared base focal length
        R = random_rotation()
        t = random_translation()
        f = random_focal_length()
        c = [0, 0] # Principal point assumed center or initialized
        poses_out.append({'R': R, 't': t, 'f': f, 'c': c, 'xi': xi})
    
    # Optimize Phase A
    # Loss: sum over i=1 to N_out of || F_theta(theta, Pi_i) - I_i ||^2
    # Optimizers update theta, poses_out, and f
    theta, poses_out, f = optimize_phase_a(theta, poses_out, images[:N_out], f)
    
    # --- Cross-Zoom Pose Registration ---
    poses_in = []
    for j in range(N_out, len(images)):
        # Find best matching zoomed-out image
        best_g = -1
        min_mse = infinity
        best_surrogate = None
        
        for g in range(N_out):
            # Render zoomed-out view g using current theta and poses_out[g]
            rendered_g = render_image(theta, poses_out[g])
            
            # Extract central 1/xi_j crop from rendered_g
            # Note: xi_j is the initial estimate from input
            xi_j = initial_zoom_estimates[j]
            crop = extract_center_crop(rendered_g, scale=1.0/xi_j)
            
            # Resize to native resolution of I_j
            surrogate = bilinear_resize(crop, target_size=images[j].size)
            
            # Compute MSE between surrogate and I_j
            mse = mean_squared_error(surrogate, images[j])
            if mse < min_mse:
                min_mse = mse
                best_g = g
                best_surrogate = surrogate # Store for potential reuse if needed, but mainly for matching
        
        # Pose priming: Copy pose from best_g
        source_pose = poses_out[best_g]
        new_pose = {
            'R': source_pose['R'],
            't': source_pose['t'],
            'f': source_pose['f'], # Shared f
            'c': source_pose['c'],
            'xi': initial_zoom_estimates[j] # Initial estimate
        }
        poses_in.append(new_pose)
        
    # --- Phase B: Zoom-in Pose Registration ---
    # Freeze theta
    theta_frozen = theta
    
    # Optimize only poses_in
    # Loss: sum over j=N_out+1 to N of || F_theta_frozen(theta_frozen, Pi_j) - I_j ||^2
    # Optimizers update poses_in
    poses_in = optimize_phase_b(theta_frozen, poses_in, images[N_out:])
    
    # Combine poses
    all_poses = poses_out + poses_in
    
    # --- Phase C: Joint Refinement ---
    # Initialize theta for phase C
    theta = theta_frozen
    
    # Optimize theta, all_poses, and all xi
    # Loss: sum over k=1 to N of || F_theta(theta, Pi_k) - I_k ||^2
    # Optimizers update theta, all_poses, and xi values in all_poses
    theta, all_poses, final_xi = optimize_phase_c(theta, all_poses, images)
    
    return theta, all_poses, final_xi

def optimize_phase_a(theta, poses_out, images, f):
    # Standard gradient descent loop
    for iteration in range(max_iterations):
        loss = 0
        grads = compute_gradients(theta, poses_out, images, f)
        theta -= eta * grads.theta
        for i, pose in enumerate(poses_out):
            pose['R'] -= eta * grads.poses[i]['R']
            pose['t'] -= eta * grads.poses[i]['t']
        f -= eta * grads.f
        # Update poses_out with new R, t
        for i, pose in enumerate(poses_out):
            pose['R'] = pose['R'] # Updated
            pose['t'] = pose['t'] # Updated
    return theta, poses_out, f

def optimize_phase_b(theta_frozen, poses_in, images):
    for iteration in range(max_iterations):
        loss = 0
        grads = compute_gradients_pose_only(theta_frozen, poses_in, images)
        for i, pose in enumerate(poses_in):
            pose['R'] -= eta * grads.poses[i]['R']
            pose['t'] -= eta * grads.poses[i]['t']
            # xi is also optimized in Phase B according to S1 "Optimize only the rotation R_j, translation t_j, and zoom parameter xi_j"
            pose['xi'] -= eta * grads.poses[i]['xi']
    return poses_in

def optimize_phase_c(theta, all_poses, images):
    for iteration in range(max_iterations):
        loss = 0
        grads = compute_gradients_joint(theta, all_poses, images)
        theta -= eta * grads.theta
        for i, pose in enumerate(all_poses):
            pose['R'] -= eta * grads.poses[i]['R']
            pose['t'] -= eta * grads.poses[i]['t']
            pose['xi'] -= eta * grads.poses[i]['xi']
    return theta, all_poses, [p['xi'] for p in all_poses]
```

**Edge Cases and Pitfalls:**
*   **Instability:** Simultaneous optimization of NeRF parameters and camera poses across all zoom levels is unstable. The three-phase schedule is required [S1].
*   **Unidentifiability:** Standard NeRF formulations assume fixed or small zoom-level perturbations. When magnification changes significantly, translation, scale, and focal length become coupled and unidentifiable, causing pose-free NeRFs to fail [S1].
*   **Pose Priming Convergence:** Pose priming converges faster than random initialization because the initial error is $O(\delta^2)$ (crop misregistration) compared to $O(\sigma_{rand}^2)$ (random noise), where $\delta \ll \sigma_{rand}$ [S1].
*   **PL Condition:** Phase B convergence relies on the Polyak-Łojasiewicz (PL) condition $\|\nabla L_j(\Pi)\|_2^2 \geq 2\mu (L_j(\Pi) - L^*_j)$ and L-Lipschitz gradients in a neighborhood of the optimum [S1].

## Operating characteristics
*   **Time Complexity:** The method involves three sequential optimization phases. Phase A optimizes $N_{out}$ views. Phase B optimizes $N_{in}$ views with frozen NeRF. Phase C optimizes all $N$ views jointly. The total time is proportional to the sum of iterations required for each phase. Theoretical analysis shows Phase B converges linearly with rate $(1-\eta\mu)$ [S1].
*   **Memory Complexity:** Requires storing the NeRF model parameters, camera poses for all $N$ images, and the images themselves. No additional large data structures like grids or pyramids are required, as it operates at native resolution [S1].
*   **Strengths:** Does not require high-resolution images or external pose initialization (SfM). Handles significant changes in optical magnification. Stable convergence due to the three-phase schedule and pose priming [S1].
*   **Limitations:** Requires a rough initial estimate of the zoom parameter $\xi_k$ for each view (from dial or apparent size). Assumes a single base focal length $f$ for all views [S1].
*   **When to use:** Industrial imaging systems (microscopes, SEMs, inspection cameras) where exact calibration is unavailable and specimens move microns, making SfM fail [S1].
*   **When not to use:** Scenes with known, stable camera calibration where standard NeRF or SfM-based methods are sufficient. Scenes where zoom varies continuously and cannot be discretized into zoomed-out/zoomed-in groups with rough estimates [S1].

## Background
MZEN was introduced to address the limitations of standard NeRF formulations in industrial imaging contexts where camera poses are unknown and optical magnification varies significantly [S1]. Classical Structure-from-Motion (SfM) fails in these settings because the specimen stage moves only microns and exact calibration is unavailable [S1]. The method explicitly models optical zoom as a learnable intrinsic parameter, differing from CamP which treats focal length as a perturbed parameter for every view [S1]. It also differs from Mip-NeRF, Zip-NeRF, and CamP by not requiring high-resolution image pyramids or external pose initialization [S1]. The theoretical analysis of Phase B's convergence relies on the Polyak-Łojasiewicz condition and L-Lipschitz gradients [S1].
