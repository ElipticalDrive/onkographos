# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the training protocol for Neural Radiance Fields (NeRF) that incorporate depth supervision to improve geometry reconstruction. It extends the standard NeRF optimization loop by integrating a depth loss term and specific architectural regularizations. It is distinguished from sibling methods like [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md) (which uses semantic/visual guidance) and [Binary Radiance Fields](13622-binary-radiance-fields.md) (which discretizes space) by its explicit use of continuous depth priors and uncertainty-aware weighting.

## How it works
The method modifies the standard NeRF training loop [Parent](13550-model-architecture-and-encoding.md) by adding dropout regularization, adjusting the loss function to include depth constraints, and tuning optimizer hyperparameters.

**Inputs:**
*   Camera poses and intrinsics.
*   RGB images.
*   Ground truth depth maps (optional, scene-dependent).
*   Scene-specific depth bounds ($min\_depth$, $max\_depth$).

**Outputs:**
*   Optimized NeRF parameters $\theta$.
*   Rendered RGB images and depth maps.

**Data Structures:**
*   **Network:** Multi-Layer Perceptron (MLP) as defined in [Parent](13550-model-architecture-and-encoding.md).
*   **Dropout Mask:** Binary mask applied to the first 8 fully connected layers.

**Parameters:**
*   Depth loss weight $\lambda$: $0.007$ for most scenes; $0.02$ for scene 710.
*   Uncertainty weight $\gamma$: $1$.
*   Optimizer: Adam.
*   Initial learning rate: $5 \times 10^{-4}$.
*   Learning rate schedule: Reduce to $5 \times 10^{-5}$ after 80% of total steps.
*   Weight decay: $1 \times 10^{-6}$.
*   Total training steps: $500,000$.
*   Depth scale learning rate: $1 \times 10^{-7}$.
*   Threshold $\tau$: Calculated per scene as $\tau = (max\_depth - min\_depth) \cdot 0.0001$. For ScanNet, $max\_depth = 10$ and $min\_depth = 0.001$.

**Steps:**
1.  **Initialize** the NeRF network $\theta$ and optimizer.
2.  **Modify Architecture:** Insert dropout layers with probability $p=0.1$ after each of the first eight fully connected ReLU-activated layers that process the positional encoding.
3.  **Sample Rays:** For each training iteration, sample rays through the scene.
4.  **Render:** Query the network to obtain volume density $\sigma$ and color $\mathbf{c}$ along each ray. Compute the rendered RGB image $\hat{I}$ and depth map $\hat{D}$ using standard volume rendering integrals.
5.  **Compute RGB Loss:** Calculate the photometric loss between the rendered image $\hat{I}$ and the ground truth image $I$.
6.  **Compute Depth Loss:**
    *   Identify pixels $k \in \{1, \dots, K\}$ with valid ground truth depth.
    *   Calculate the threshold $\tau$ for the current scene.
    *   Compute the depth error. The specific metric is not explicitly defined as a single formula in the primary source, but evaluation metrics include RMSE, Log-RMSE, AbsRel, and SqRel [S1]. The training loss typically uses a combination of these or a specific Earth Mover's Distance variant as implied by the title [S1].
    *   Apply the weight $\lambda$ to the depth loss term.
7.  **Compute Total Loss:** Combine RGB and depth losses. The uncertainty weight $\gamma$ is applied to modulate the depth loss based on the confidence of the depth prediction, where confidence is evaluated against threshold $\tau$ [S1].
8.  **Update:** Perform a backward pass and update $\theta$ using Adam with the specified learning rate and weight decay.
9.  **Schedule:** Reduce the learning rate to $5 \times 10^{-5}$ after 80% of the 500,000 steps.
10. **Repeat** until 500,000 steps are completed.

**Pseudocode:**
```python
# Configuration
dropout_prob = 0.1
lambda_depth = 0.007 # 0.02 for scene 710
gamma_uncertainty = 1
lr_initial = 5e-4
lr_final = 5e-5
lr_decay_step = 0.8 * 500000
weight_decay = 1e-6
lr_depth_scale = 1e-7
total_steps = 500000

# Architecture Modification

    model = StandardNeRF() # As per [Parent]
    # Add dropout to first 8 FC layers after ReLU
    for i, layer in enumerate(model.first_8_fc_layers):
        layer.add_dropout(dropout_prob)
    return model

# Training Loop
optimizer = Adam(model.parameters(), lr=lr_initial, weight_decay=weight_decay)
scheduler = StepLR(optimizer, step_size=lr_decay_step, gamma=lr_final/lr_initial)

for step in range(total_steps):
    # 1. Sample rays and get ground truth RGB and Depth
    rays, rgb_gt, depth_gt = sample_batch()
    
    # 2. Forward pass
    rgb_pred, depth_pred, uncertainty = model(rays)
    
    # 3. Compute RGB Loss (e.g., L1 or L2)
    loss_rgb = compute_rgb_loss(rgb_pred, rgb_gt)
    
    # 4. Compute Depth Loss
    # Calculate threshold for valid depth pixels
    max_d = get_max_depth(scene)
    min_d = get_min_depth(scene)
    tau = (max_d - min_d) * 0.0001
    
    # Filter valid pixels based on uncertainty/depth confidence
    valid_mask = compute_valid_depth_mask(depth_gt, tau)
    
    # Compute depth error (e.g., L1 or L2 on valid pixels)

    # Apply weights

    # 5. Backward pass
    optimizer.zero_grad()
    total_loss.backward()
    optimizer.step()
    
    # 6. Learning rate schedule
```

## Subtopics

### DS-NeRF Depth Loss Integration
This variant involves integrating the depth loss implementation from the official DS-NeRF codebase into the training pipeline. It requires re-training on specific datasets (LLFF, DTU) using released configuration files, as original publication results may use different splits or unreleased architectural tricks (e.g., reduced positional encoding frequency) to prevent overfitting [S2].

## Operating characteristics
*   **Time Complexity:** Determined by the 500,000 training steps and the cost of querying the MLP with dropout. Dropout adds negligible overhead.
*   **Memory Complexity:** Standard NeRF memory footprint plus storage for depth maps and uncertainty maps during training.
*   **Strengths:** Improves geometric accuracy by leveraging depth priors; dropout prevents overfitting in the early layers.
*   **Limitations:** Requires ground truth depth maps; sensitive to the choice of $\lambda$ and $\tau$; scene 710 requires a distinct hyperparameter setting.
*   **When to use:** When depth supervision is available and geometric fidelity is prioritized over appearance alone.

## Background
This configuration originates from the Depth-Guided NeRF method, which utilizes Earth Mover’s Distance for depth guidance [S1]. It builds upon the original NeRF architecture [S1]. The specific hyperparameters (dropout, learning rate schedule) were tuned for datasets like ScanNet and LLFF. The DS-NeRF variant references work on sparse pose and depth refinement [S2].
