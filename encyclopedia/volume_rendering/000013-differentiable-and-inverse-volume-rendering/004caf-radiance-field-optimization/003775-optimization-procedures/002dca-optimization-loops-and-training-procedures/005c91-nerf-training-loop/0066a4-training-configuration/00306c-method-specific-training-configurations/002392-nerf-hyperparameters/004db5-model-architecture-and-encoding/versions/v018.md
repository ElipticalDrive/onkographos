# Model Architecture and Encoding


## Overview
Model Architecture and Encoding defines the neural network structures and coordinate transformation functions used to map 3D spatial coordinates and viewing directions to radiance field properties (density, color, semantics). It solves the problem of representing high-frequency geometric and appearance details in a continuous function, which standard multi-layer perceptrons (MLPs) struggle to learn due to spectral bias [S1, S3]. It distinguishes itself from sibling methods by focusing on the *input representation* (encoding) and the *internal topology* (architecture) of the radiance field predictor, rather than the optimization loop or loss functions. Key variants include hybrid grid-MLP structures [S1], tensor decompositions [S1], and specialized encodings for dynamic or sparse data [S1, S3].

## Shared principles
All methods in this family map a 3D point $\mathbf{x} \in \mathbb{R}^3$ and a viewing direction $\mathbf{d} \in S^2$ to a feature vector or directly to density $\sigma$ and color $\mathbf{c}$. The core components are:
1.  **Encoding Function $\gamma$:** Transforms raw coordinates into a higher-dimensional space. Standard NeRF uses positional encoding:
    $$ \gamma(\mathbf{p}) = (\sin(2^0 \pi \mathbf{p}), \cos(2^0 \pi \mathbf{p}), \dots, \sin(2^{L-1} \pi \mathbf{p}), \cos(2^{L-1} \pi \mathbf{p})) $$
    where $L$ is the number of frequency bands [S1, S3].
2.  **Network Backbone:** Typically an MLP that takes the encoded coordinates and outputs properties. The architecture varies from simple dense layers [S3] to hybrid structures combining feature grids with shallow MLPs [S1].
3.  **Output Heads:** Separate networks or layers for density $\sigma$ (often with ReLU or softplus activation) and color $\mathbf{c}$ (often with sigmoid or tanh activation, sometimes incorporating spherical harmonics for view dependence) [S1, S3].

## Subtopics

### [Depth-Guided NeRF Training Configuration](11916-depth-guided-nerf-training-configuration.md)
This configuration modifies the standard NeRF architecture by inserting dropout layers to regularize the network when training with depth priors. It addresses geometry regularization and convergence stability. Unlike other methods that use adaptive weighting, it relies on a fixed dropout probability and a fixed depth loss weight [11916-depth-guided-nerf-training-configuration.md].

### [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md)
CLIPNeRF replaces the photometric reconstruction loss with a directional CLIP loss to enable text-driven stylization. The architecture retains the standard NeRF MLP structure but freezes density-related weights, optimizing only color/feature parameters to match CLIP embeddings. It distinguishes itself by using a patch-based rendering approach to manage memory constraints during optimization [12073-clipnerf-training-configuration.md].

### [Binary Radiance Fields](13622-binary-radiance-fields.md)
Binary Radiance Fields (BiRF) constrains feature grid parameters to binary values (+1 or -1) to achieve compact storage. It uses a 2D-3D hybrid grid structure (3D voxel grid + 2D plane grids) with hash encoding. All parameters are binary, stored as 1-bit values, and gradients are propagated using the Straight-Through Estimator (STE). It distinguishes itself from Instant-NGP by replacing real-valued hash grid features with binary features [13622-binary-radiance-fields.md].

### [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md)
The Mip-NeRF 360 MLP architecture integrates **integrated positional encoding** to handle the integration of radiance along rays, reducing aliasing artifacts. It uses a density network and a color network separated by a bottleneck vector. The density network processes 3D coordinates (mean $\mu$ and covariance $\Sigma$) using Gaussian-smoothed positional encoding. It distinguishes itself from standard NeRF by utilizing integrated encoding to model the cone cast by pixels [14098-mip-nerf-360-mlp-architecture.md].

### SUDS
SUDS is a 4D radiance field representation for large-scale dynamic urban scenes. It factorizes the scene into three separate multi-resolution hash table structures: Static, Dynamic, and Far-field. Each branch uses hash indexing with specific functions for spatial, spatio-temporal, and directional coordinates. It distinguishes itself by using unlabeled target signals (RGB, sparse LiDAR, 2D descriptors, optical flow) for supervision, enabling free-viewpoint rendering and scene flow estimation without ground truth 3D labels [14964-suds.md].

### CCNeRF
CCNeRF is a neural field representation that enables efficient compression and composition of 3D scenes without using neural networks for rendering. It models the radiance field entirely through tensor rank decomposition (CP or Triple Plane), allowing arbitrary composition via rank concatenation and dynamic compression via rank truncation. It distinguishes itself from NeRF variants that rely on a shared MLP renderer by using linear algebra operations on decomposed tensors [15008-ccnerf.md].

### [Rip-NeRF](15532-rip-nerf.md)
Rip-NeRF renders high-fidelity, anti-aliased images by combining cone casting with an anisotropic 3D Gaussian characterization. It uses Ripmap-Encoded Platonic Solids (e.g., Icosahedron) to enable efficient anisotropic area-sampling. It distinguishes itself from Zip-NeRF by using a hierarchical feature grid (Ripmap) projected onto Platonic solid faces, avoiding the computationally inefficient multi-sampling mechanism of Zip-NeRF [15532-rip-nerf.md].

### [UE4-NeRF](15539-ue4-nerf.md)
UE4-NeRF is a neural rendering system for real-time interactive rendering of large-scale 3D scenes. It partitions the environment into sub-NeRFs represented as textured polygonal meshes (regular octahedra) and integrates them into the Unreal Engine 4 rasterization pipeline. It uses an Encoder-Decoder MLP structure where the encoder outputs opacity and feature vectors, and the decoder outputs color. It distinguishes itself by converting the learned radiance field into a mesh-based representation optimized for GPU rasterization, enabling real-time 4K frame rates [15539-ue4-nerf.md].

### [Generative Occupancy Fields (GOF)](15773-generative-occupancy-fields-gof.md)
Generative Occupancy Fields (GOF) learns compact object surfaces by transitioning from cumulative volume rendering to surface-point rendering. It predicts alpha values $\alpha$ (interpreted as occupancy probabilities) rather than volume density $\sigma$, allowing the use of root-finding to locate the surface. It distinguishes itself from siblings that predict $\sigma$ directly by resolving shape-color ambiguity and enabling deterministic surface representation [15773-generative-occupancy-fields-gof.md].

### [Panoptic Radiance Field](15849-panoptic-radiance-field.md)
Panoptic Radiance Field learns a panoptic 3D volumetric representation from posed RGB images and machine-generated 2D panoptic segmentation masks. It uses a TensoRF-like structure for color/density, and separate small MLPs for semantic and instance fields. It distinguishes itself by requiring no manual ground truth (such as coarse meshes), relying instead on pre-trained 2D segmentation networks to handle label noise and view inconsistencies [15849-panoptic-radiance-field.md].

### [Frequency-Modulated Position Encoding](15897-frequency-modulated-position-encoding.md)
Frequency-Modulated Position Encoding is a coordinate encoding scheme for point-based radiance field optimization. It solves the problem of representing high-frequency details in sparse point clouds by applying sine and cosine basis functions with exponentially increasing frequencies. It differs from standard NeRF positional encoding by narrowing the encoding interval and using specific frequency bands (powers of 2 and $2^{0.5}$) to provide finer basis function support, critical for stability in point-based rendering [15897-frequency-modulated-position-encoding.md].

### Triplane NeRF with Diffusion Prior
This framework uses a triplane NeRF representation where scene codes are optimized jointly with a diffusion prior to handle sparse-view data and ensure end-to-end coherence. It uses a U-Net with 122M parameters for denoising. The prediction format uses v-parameterization, and the weighting function uses SNR-based weighting $w(t) = (\alpha(t)/\sigma(t))^2\omega$. The scene code shape is $\mathbb{R}^{3 \times 6 \times 128 \times 128}$ [S1].

### EG3D Triplane Representation
EG3D uses a hybrid triplane representation $T \in \mathbb{R}^{256 \times 256 \times 96}$, corresponding to 3 axis-aligned planes (xy, xz, yz), each with 32 channels and resolution $256 \times 256$. It renders a feature image $I_f \in \mathbb{R}^{32 \times 128 \times 128}$ and raw RGB image $I_{128} \in \mathbb{R}^{3 \times 128 \times 128}$, then feeds them into a 2D super-resolution network to yield $I_{512} \in \mathbb{R}^{3 \times 512 \times 512}$. Rendering speed is 42 fps on RTX 3090 [S2].

### NeRF-W Hyperparameter Configuration
NeRF-W uses an MLP architecture with 8 layers of 512 hidden units for the 'Base' component, and 4 layers of 128 hidden units for 'Static' and 'Transient/Uncertainty' components. Positional encoding uses 15 frequencies for position and 4 for viewing direction. It samples 512 points per ray per model (1024 total) during training, doubled to 2048 during evaluation. Appearance embedding dimension is 48, transient object embedding is 16. L1 regularizer multiplier is 0.01, minimum importance threshold is 0.03. Optimizer is Adam, batch size 2048, initial LR 0.001, decaying ten-fold every 150,000 iterations, over 300,000 iterations total. These hyperparameters were optimized for the Brandenburg Gate scene and reused for remaining scenes [S3].

### Explicit Mesh Reconstruction from Neural Fields
This algorithm extracts an explicit 3D mesh representation from the implicit neural radiance field learned by CodeNeRF. It feeds the center coordinates of a $256^3$ voxel grid to the CodeNeRF MLP to obtain volume density values $\sigma$. Marching Cubes is applied to find mesh vertices. Rays are cast along vertex normals to associate colors to the vertices [S4].

### Efficient EndoNeRF scene representation
This voxel-grids-based scene representation replaces coordinate-based MLPs with explicit density and feature volume grids ($\mathbf{V}_\sigma$ and $\mathbf{V}_a$) to accelerate optimization. It models dynamic surgical scenes by warping a canonical radiance field with a time-dependent deformation field. The deformation field is modeled using decomposed 4D motion fields and a 3-layer MLP mapping spatial-temporal coordinates to deformation offsets [S5].

### NeRF-Liif
NeRF-Liif is a baseline method that super-resolves LR images using a pretrained LIIF (Local Implicit Image Function) model. It requires LR-HR pairs for training, introducing external data priors. On the Blender dataset, it may produce false predictions due to domain mismatch. On the LLFF dataset, it tends to be oversmooth and may predict false color or geometry. Metrics: Blender ×2 (100x100): PSNR 27.07, SSIM 0.919, LPIPS 0.067; Blender ×4 (100x100): PSNR 25.36, SSIM 0.885, LPIPS 0.125; Blender ×2 (200x200): PSNR 28.81, SSIM 0.934, LPIPS 0.058; Blender ×4 (200x200): PSNR 27.34, SSIM 0.912, LPIPS 0.096; LLFF ×2: PSNR 26.81, SSIM 0.823, LPIPS 0.145; LLFF ×4: PSNR 24.76, SSIM 0.723, LPIPS 0.292 [S6].

### UniSurf
UniSurf unifies volume rendering (radiance fields) and surface rendering (implicit surfaces) to achieve high-quality geometry and sharp textures without mask supervision. It uses an occupancy field where occupancy at the $i^{th}$ sample corresponds to an indicator of surface presence. It uses volume rendering in the early stage for optimization without mask supervision, and surface rendering in the later stage to extract level-set surfaces. Unlike pure surface rendering, it provides high-quality novel views and sharp textures/colors without mask supervision [S7, unofficial].

## Background
The foundational NeRF architecture [Mildenhall et al. 2020] introduced the use of positional encoding and a simple MLP to map coordinates to density and color. Subsequent works have diversified the architecture to address specific challenges:
*   **Efficiency:** Instant-NGP [Müller et al. 2022] introduced multi-resolution hash encoding, which has been adapted into binary grids (BiRF) [S1] and hybrid structures (SUDS) [S1].
*   **Anti-aliasing:** Mip-NeRF [Barron et al. 2021, 2022] introduced integrated positional encoding to handle cone casting, reducing aliasing in out-of-focus scenes [14098-mip-nerf-360-mlp-architecture.md].
*   **Generative Models:** EG3D [Chan et al. 2022] and Diffusion NeRF [S1] use triplane representations and diffusion priors for 3D-aware generation.
*   **Dynamic Scenes:** SUDS [S1] and EndoNeRF [S5] extend the architecture to include time and deformation fields.
*   **Surface Extraction:** UniSurf [Oechsle et al. 2021] [S7, unofficial] and CodeNeRF [S4] focus on extracting explicit meshes from neural fields.
*   **Panoptic Understanding:** Panoptic NeRF [S1] extends the output to include semantic and instance fields.
