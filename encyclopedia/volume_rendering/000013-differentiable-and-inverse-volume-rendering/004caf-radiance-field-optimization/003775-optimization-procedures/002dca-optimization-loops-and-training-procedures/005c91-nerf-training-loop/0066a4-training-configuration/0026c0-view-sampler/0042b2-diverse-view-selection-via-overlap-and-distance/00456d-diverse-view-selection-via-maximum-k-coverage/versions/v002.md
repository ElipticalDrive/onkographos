# Diverse View Selection via Maximum K-Coverage

Also called: Camera Selection Algorithm, Camera Selection via Maximum K-Coverage, Greedy K-Coverage View Selection, K-Maximum Coverage Camera Selection, Maximum K-Coverage camera selection

## Overview
This method selects a subset of input cameras to maximize pixel coverage in a novel view, addressing GPU memory limitations in large-scale IBR and neural rendering pipelines [S1]. It builds on the K-Maximum coverage algorithm from set theory to provide fast and accurate camera selection [S1]. Unlike simple ULR-style weights, superpixel-based IBR, or voxel grid approximations, this approach explicitly maximizes the union of visible pixels from the chosen subset [S1].

## How it works
**Inputs:**
*   $M$: Number of input cameras.
*   $N$: Number of pixels in the novel view space $P$.
*   $k$: Target number of views to select ($|V_{sel}| = k$).
*   $Mesh$: A proxy mesh estimated from Multi-View Stereo (MVS) [S1].
*   $T_i$: Projection matrices for each input camera $i \in \{1, \dots, M\}$.
*   $T_{novel}$: Projection matrix for the novel view.

**Outputs:**
*   $V_{sel}$: A subset of $k$ input camera indices.

**Data Structures:**
*   $S_i$: A downscaled score map (array) for input camera $i$, with dimensions matching the resolution of the novel view space [S1].
*   $C_{covered}$: A boolean mask of size $N$, tracking the coverage status of each pixel in the novel view [G].

**Algorithm Steps:**

1.  **Initialize Coverage:** Create $C_{covered}$ initialized to false for all $p \in P$ [G]. Initialize $V_{sel} = \emptyset$. Initialize total score $V_0 = 0$ [G].

2.  **Precompute Score Maps:** For each input camera $i \in \{1, \dots, M\}$:
    a.  Project the $Mesh$ onto the novel view space using $T_{novel}$ and $T_i$ to determine visibility [S1].
    b.  Perform a depth test using the $Mesh$ to handle occlusions [S1].
    c.  Compute the visibility score $S_i(p)$ for each pixel $p \in P$.
        *   *Binary Mode:* $S_i(p) = 1$ if $p$ is visible in view $i$, else $0$ [S1].
        *   *Density Mode (Optional):* Replace binary visibility with a per-pixel score approximating point density: $S_i(p) = \frac{d_{novel}(p)}{d_{input}(p)}$, where $d_{novel}(p)$ is the distance from the novel camera to the visible point, and $d_{input}(p)$ is the distance from the input camera to the visible point [S1].
    d.  Store $S_i$ in memory [S1].

3.  **Greedy Selection Loop:** Iterate $j$ from $1$ to $k$:
    a.  **Evaluate Candidates:** For each remaining candidate camera $c \notin V_{sel}$:
        i.  Calculate the marginal gain $G_c = \sum_{p \in P} S_c(p) \cdot \mathbb{I}(\neg C_{covered}[p])$, where $\mathbb{I}(\cdot)$ is the indicator function [G].
    b.  **Select Best:** Choose $c^* = \arg\max_{c \notin V_{sel}} G_c$ [G].
    c.  **Update State:**
        i.  Add $c^*$ to $V_{sel}$ [G].
        ii. Update $C_{covered}$: For all $p \in P$, if $S_{c^*}(p) > 0$, mark $p$ as covered [G].
        iii. Calculate current total score $V_j = \sum_{p \in P} \mathbb{I}(C_{covered}[p])$ (or sum of max scores if using non-binary scores) [G].

4.  **Degeneracy Check:** After each selection step $j$, check for the degenerate case where the novel view is identical to an already selected input view [S1].
    a.  Compute ratio $R = V_j / V_{j-1}$ [S1].
    b.  If $R < \epsilon$, the algorithm has stalled because the first view covered all pixels, leaving zero marginal gain for others [S1].
    c.  **Fallback:** If stalled, discard the greedy selection for this step and instead select the remaining candidate with the absolute maximum total score: $\arg\max_{c \notin V_{sel}} \sum_{p \in P} S_c(p)$ [S1].

5.  **Return:** Output $V_{sel}$ [G].

    N = len(S[0])

    V_prev = 0.0
    
    for step in range(1, k + 1):
        best_gain = -1.0
        best_idx = -1
        best_total = -1.0
        
        # 2. Evaluate candidates
        for i in range(len(cameras)):
            if i in V_sel:
                continue
            
            # Calculate marginal gain: sum scores of uncovered pixels
            gain = sum(S[i][p] for p in range(N) if not covered[p])
            total = sum(S[i])
            
            if gain > best_gain:
                best_gain = gain
                best_idx = i
                best_total = total
        
        # 3. Degeneracy Check
        # Calculate current total coverage score V_step
        current_total = sum(1.0 for c in covered if c)
        
        # Source condition: V_{k+1}/V_k < epsilon
        if V_prev > 0 and current_total / V_prev < epsilon:
            # Degenerate case: switch to absolute max score
            best_idx = -1
            max_total = -1.0
            for i in range(len(cameras)):
                if i in V_sel:
                    continue
                if sum(S[i]) > max_total:
                    max_total = sum(S[i])
                    best_idx = i
        
        # 4. Update
        if best_idx == -1:
            break # No more candidates
            
        V_sel.append(best_idx)

        for p in range(N):
            if S[best_idx][p] > 0:
                covered[p] = True
                
        V_prev = sum(1.0 for c in covered if c)
        
    return V_sel

**Edge Cases and Pitfalls:**
*   **Degeneracy:** If the novel view is identical to an input view, the first selected view covers all pixels, resulting in zero marginal gain for subsequent views [S1]. This is detected when $V_{k+1}/V_k < \epsilon$ [S1]. The algorithm switches to selecting the view with the absolute maximum sum of scores [S1].
*   **Precision:** The algorithm relies on accurate depth testing and occlusion handling using the proxy mesh [S1].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$, where $N$ is the number of pixels in the novel view and $M$ is the number of input cameras [S1].
*   **Memory Complexity:** $O(N \cdot M)$ to store the score maps for all input cameras in the novel view space [S1].
*   **Performance:** Provides faster and more accurate selection than ULR-style weights, superpixel-based IBR, or voxel grid approximations [S1].
*   **Strengths:** Guarantees a lower bound of $1 - 1/e$ on the ratio of the score compared to the optimal solution (greedy approximation guarantee for Maximum K-Coverage) [S1].
*   **Limitations:** Requires a proxy mesh from MVS, which may not be available or accurate for all scenes [S1].

## Background
This method was introduced by G. Kopanas, J. Philip, T. Leimkühler & G. Drettakis in "Point-Based Neural Rendering with Per-View Optimization" [S1]. It builds upon the K-Maximum coverage algorithm [HP98] to address the limitations of previous camera selection methods like those by Riegler and Koltun [RK20], which ranked views based on overlap but did not necessarily maximize the union of coverage [S1]. The approach is part of a broader trend in neural rendering that leverages MVS proxy geometry for efficient per-view optimization [S1].
