# Dynamic Scene and Temporal Modeling

Also called: Dynamic NeRF, 4D NeRF, Time-conditioned NeRF

## Overview
Dynamic Scene and Temporal Modeling adapts the static Neural Radiance Field (NeRF) architecture to reconstruct time-varying geometry and appearance, solving the problem that standard NeRF assumes a static scene [S1]. It sets itself apart from its siblings by introducing a temporal dimension to the input space or representation, serving as the foundational approach for all dynamic NeRF variants [S1]. Unlike methods that model explicit motion fields or use complex graph structures, this category ranges from simple time-augmented inputs to complex semantic stratifications, with the baseline approach noted for lacking detail and suffering from blurry predictions compared to more advanced dynamic scene methods [S1].

## How it works
The core mechanism involves extending the static 5D function $(\mathbf{x}, \mathbf{d}) \mapsto (\sigma, \mathbf{c})$ to a 6D function $(\mathbf{x}, \mathbf{d}, t) \mapsto (\sigma, \mathbf{c})$, where $t$ represents time [S1].

**Inputs and Outputs:**
*   **Input:** 3D position $\mathbf{x} \in \mathbb{R}^3$, view direction $\mathbf{d} \in \mathbb{R}^3$, and time $t \in \mathbb{R}$ (normalized to $[0, 1]$ or similar range).
*   **Output:** Volume density $\sigma \in \mathbb{R}$ and color $\mathbf{c} \in \mathbb{R}^3$ for the specific time $t$.

**Data Structures:**
The primary data structure is the MLP (or hash grid/voxel grid in variants) which accepts the concatenated vector $[\mathbf{x}, \mathbf{d}, t]$ or a positional encoding thereof. In advanced variants like Gear-NeRF, multiple 4D feature volumes are used, one per motion region [S1].

**Steps:**
1.  **Temporal Encoding:** The time coordinate $t$ is encoded, often using positional encoding similar to spatial coordinates, or via adaptive pose encoding to enhance separation of static and dynamic parts [S1].
2.  **Feature Query:** The encoded time $t$, position $\mathbf{x}$, and direction $\mathbf{d}$ are passed through the network. In baseline methods, this is a direct concatenation. In variants like ER-NeRF, a Tri-Plane Hash Representation and Region Attention Module (RAM) are used to delineate links between attributes and spatial areas [S1].
3.  **Density and Color Prediction:** The network outputs density $\sigma$ and color $\mathbf{c}$.
4.  **Rendering:** Standard volume rendering is applied along rays, integrating $\sigma$ and $\mathbf{c}$ over the sampled points for the specific time $t$ [S1].

**Formulas:**
The standard NeRF positional encoding $\gamma$ is extended to include time:
$$
\gamma(\mathbf{x}, \mathbf{d}, t) = [\mathbf{x}, \mathbf{d}, t, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{t_1}\pi t), \cos(2^{t_1}\pi t)]
$$
Where $d_1$ and $t_1$ are the number of frequency bands for space and time respectively [S1].

**Parameters:**
*   **Time Range:** Typically normalized to $[0, 1]$ corresponding to the video duration [S1].
*   **Sampling:** Points are sampled along rays at the specific time $t$ of the target frame [S1].

**Edge Cases and Pitfalls:**
*   **Blurriness:** The baseline "NeRF with Time Parameter" approach is noted to lack detail and suffer from blurry predictions compared to more advanced methods [S1].
*   **Pose Extrapolation:** Additional fine-tuning might be necessary to sustain superior rendering outcomes for poses that exceed the scope of the training dataset [S1].
*   **Many-to-One Ambiguity:** Dynamic scenes suffer from many-to-one and one-to-many mapping ambiguities (e.g., occlusion changes), which simple time-conditioned models may not resolve without additional warping or inpainting mechanisms [S1].

## Subtopics

### [Gear-NeRF](13848-gear-nerf.md)
Uses semantic segmentation to stratify the scene into motion-based 'gears', assigning higher sampling resolution to regions with larger motion scales. Chosen when efficiency in free-viewpoint rendering of dynamic scenes is required.

### [NeRF with Time Parameter](14705-nerf-with-time-parameter.md)
The baseline method that simply augments the input vector with time. Chosen for minimal architectural change, though it produces blurrier results than advanced variants.

### [Forward Warping for Novel View Synthesis](15541-forward-warping-for-novel-view-synthesis.md)
Models a static "canonical" radiance field and differentially warps it to target time steps using average splatting and inpainting. Chosen for superior performance on canonical frames by explicitly learning deformation flow.

### [Dynamic Appearance Particle Neural Radiance Field](15550-dynamic-appearance-particle-neural-radiance-field.md)
Applies particle-based representation only to dynamic elements while keeping a static grid for the background. Chosen for single-camera input scenarios without multi-view data.

### [KFD-NeRF](15551-kfd-nerf.md)
Models the 4D radiance field as a dynamic system with temporally varying states, estimated using a Kalman filter. Chosen when treating motion estimation as a state estimation problem is preferred over simple interpolation.

### [SLS4D](16576-sls4d.md)
Represents dynamic scenes using a sparse, compact latent feature space with globally learnable latent codes interpolated via attention. Chosen for significantly reducing network parameters compared to dense voxel-based approaches.

## Operating characteristics
*   **Time Complexity:** Depends on the specific variant. Baseline time-conditioned NeRF has similar complexity to static NeRF per frame but requires training on temporal data. Gear-NeRF improves efficiency by varying sampling resolution [S1]. SLS4D reduces parameter count significantly [S1].
*   **Memory Complexity:** Baseline methods require storing features for all time steps or a large 4D volume. Gear-NeRF uses multiple 4D feature volumes [S1]. SLS4D uses sparse latent codes, reducing memory usage [S1].
*   **Performance:** ER-NeRF attains instantaneous rendering and rapid convergence using a compact model size [S1]. Forward warping achieves superior performance for canonical frames [S1].
*   **Strengths:** Enables novel view synthesis of dynamic scenes. Variations like Gear-NeRF allow for free-viewpoint object tracking [S1].
*   **Limitations:** Baseline methods suffer from blurriness [S1]. Pose extrapolation beyond training data requires fine-tuning [S1].

## Background
The concept originates from the need to extend NeRF, which assumes static scenes, to dynamic environments. The "NeRF with Time Parameter" serves as the baseline for temporal NeRFs [S1]. Recent developments include ER-NeRF (2023), a Conditional NeRF framework for dynamic portrait creation synchronized with audio, which uses Tri-Plane Hash Representation and Adaptive Pose Encoding [S1]. Other approaches include AvatarMAV (2023), which separates dynamic expression movement from standard appearance using Motion-Aware Neural Voxels [S1].
