# Ray-Space Embedding Network with Local Affine Transformation

Also called: Local affine transformation-based embedding, Ours (no subdivision)

## Overview
This method is a neural light field representation that uses a ray-space embedding network to predict local affine transformations for color computation, enabling view-dependent effects and multi-view consistency without explicit geometry [S1, unofficial]. It differs from standard NeRF by parameterizing the radiance field locally within a voxel grid (for sparse inputs) or globally (for dense inputs), using an embedding network to derive affine parameters that linearize color level sets, thereby improving interpolation quality and rendering speed [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A ray $r$ defined by origin and direction; for subdivided models, a 3D voxel grid covering NDC space.
*   **Output:** Final color $c$ for the ray.

**Data Structures:**
1.  **Voxel Grid:** A regular 3D grid covering NDC space.
    *   **Sparse Light Fields (e.g., Real Forward-Facing, Shiny):** $32^3$ resolution. Exception: Shiny CD/Lab sequences use a $4^3$ grid [S1, unofficial].
    *   **Dense Light Fields (e.g., Stanford):** No subdivision (single global evaluation) [S1, unofficial].
2.  **Networks:** Two shared 8-layer MLPs with 256 hidden units and one skip connection:
    *   **Embedding Network $E_\phi$:** Predicts local affine parameters.
    *   **Color Network $F_\theta$:** Predicts color and alpha.
    *   Both networks are shared across all voxels [S1, unofficial].

**Numbered Steps:**

1.  **Ray-Voxel Intersection:** For each ray $r$, intersect it with the front and back planes of each voxel in the grid. This yields a set of local ray coordinates $\{r_i\}_{i \in V(r)}$ sorted by distance from the ray origin [S1, unofficial].
    *   If no subdivision is used (dense case), $V(r)$ contains a single set of samples along the ray.

2.  **Embedding Network Forward Pass:** For each sample point $i$ in voxel $V(r)$, compute the local affine transformation parameters $(A_i, b_i)$ using the embedding network $E_\phi$.
    *   Input to $E_\phi$: The local ray coordinate $r_i$ and positional encoding $\gamma(i)$ of the voxel center $p_i$ (where $i \equiv p_i$) [S1, unofficial].
    *   Formula:
        $$ (A_i, b_i) = E_\phi(r_i, \gamma(i)) $$
    *   Output dimensions: $A_i$ is a $32 \times 4$ matrix, $b_i$ is a 32-dimensional vector [S1, unofficial].

3.  **Normalization of Parameters:**
    *   **Matrices $A_i$:** Normalize $A_i$ by its Frobenius norm $\|A_i\|_F$ and multiply by $\sqrt{32} \cdot 4$:
        $$ A_i \leftarrow A_i \cdot \frac{\sqrt{32} \cdot 4}{\|A_i\|_F} $$
    *   **Bias Vectors $b_i$:** Apply $\tanh$ activation to the predicted bias vectors [S1, unofficial].

4.  **Feature Embedding and Normalization:**
    *   Compute the embedded feature $f$ (internal to $E_\phi$ or intermediate step).
    *   Perform L2 normalization on $f$.
    *   Multiply by $\sqrt{32}$ so the average square value of the output features is close to one [S1, unofficial].

5.  **Color and Alpha Prediction:**
    *   Compute the transformed input for the color network: $z_i = A_i r_i + b_i$.
    *   Apply positional encoding $\gamma(\cdot)$ to $z_i$ and the voxel index $i$.
    *   Compute color $c_i$ and alpha $\alpha_i$ using the color network $F_\theta$:
        $$ (c_i, \alpha_i) = F_\theta(\gamma(A_i r_i + b_i), \gamma(i)) $$
    *   Note: The positional encoding uses $L=8$ frequency bands for the subdivided model and $L=10$ for the one-evaluation model [S1, unofficial].

6.  **Volume Rendering (Over-Compositing):**
    *   Sort samples $i \in V(r)$ by distance from the ray origin in ascending order.
    *   Compute final color $c$ using standard volume rendering accumulation:
        $$ c = \sum_{i \in V(r)} \alpha_i c_i \prod_{j \in V(r), j < i} (1 - \alpha_j) $$
    *   This assumes $\alpha_i$ is the alpha of sample $i$ and the product term represents the transmittance from previous samples [S1, unofficial].

**Pseudocode:**

```python
import math
import torch
import torch.nn as nn

class RaySpaceEmbeddingNetwork:
    def __init__(self, use_subdivision=True, grid_resolution=32, 
                 embedding_dim=32, freq_bands=8):
        """
        Initialize the Ray-Space Embedding Network.
        
        Args:
            use_subdivision: Boolean, True for sparse light fields (subdivision),
                             False for dense light fields (no subdivision).
            grid_resolution: Integer, resolution of the voxel grid (e.g., 32 or 4).
            embedding_dim: Integer, dimension of the embedding space (N=32).
            freq_bands: Integer, number of frequency bands for positional encoding.
        """
        self.use_subdivision = use_subdivision
        self.grid_resolution = grid_resolution
        self.N = embedding_dim  # 32
        self.L = freq_bands     # 8 for subdivision, 10 for no subdivision
        
        # Shared MLPs for Embedding and Color
        # 8 layers, 256 hidden units, 1 skip connection
        self.embedding_net = self._build_mlp(input_dim=4 + self._pos_enc_dim(), 
                                             output_dim=self.N * 4 + self.N)
        self.color_net = self._build_mlp(input_dim=self.N + self._pos_enc_dim(), 
                                         output_dim=4) # 3 for color, 1 for alpha

    def _build_mlp(self, input_dim, output_dim):
        """Builds an 8-layer MLP with 256 hidden units and one skip connection."""
        layers = []
        hidden_dim = 256
        # Layer 1
        layers.append(nn.Linear(input_dim, hidden_dim))
        layers.append(nn.ReLU())
        # Layers 2-7
        for _ in range(6):
            layers.append(nn.Linear(hidden_dim, hidden_dim))
            layers.append(nn.ReLU())
        # Layer 8 (Output)
        layers.append(nn.Linear(hidden_dim, output_dim))
        return nn.Sequential(*layers)

    def _pos_enc_dim(self):
        """Returns the dimension of the positional encoding."""
        # Standard positional encoding: 2 * L * dim + dim
        # Assuming 3D position/direction, dim=3 or 4 depending on input
        # The paper specifies L bands. For a 3D vector, PE dim is 2*L*3 + 3 = 6L + 3
        # However, the input to E_phi is r_i (ray coord) and gamma(i) (voxel center).
        # The exact PE implementation details are not fully specified, 
        # but L=8 or L=10 bands are used.
        return 6 * self.L + 3 

    def normalize_A(self, A):
        """
        Normalize matrix A by Frobenius norm and scale by sqrt(32)*4.
        A shape: (batch, 32, 4)
        """
        frob_norm = torch.norm(A, dim=(1, 2), keepdim=True)
        # Avoid division by zero
        frob_norm = torch.clamp(frob_norm, min=1e-8)
        scale = math.sqrt(32) * 4
        A_normalized = A * (scale / frob_norm)
        return A_normalized

    def normalize_f(self, f):
        """
        L2 normalize feature f and multiply by sqrt(32).
        f shape: (batch, 32)
        """
        l2_norm = torch.norm(f, dim=1, keepdim=True)
        l2_norm = torch.clamp(l2_norm, min=1e-8)
        f_normalized = f / l2_norm
        return f_normalized * math.sqrt(32)

    def forward(self, rays, voxel_centers=None):
        """
        Forward pass for a batch of rays.
        
        Args:
            rays: Tensor of shape (batch, 4) representing ray parameters 
                  (e.g., direction components or Plucker coordinates).
            voxel_centers: Tensor of shape (batch, 3) representing voxel centers 
                           for the positional encoding gamma(i). Only needed if 
                           use_subdivision is True.
        
        Returns:
            c: Final color tensor of shape (batch, 3).
        """
        if self.use_subdivision:
            return self._forward_subdivided(rays, voxel_centers)
        else:
            return self._forward_global(rays)

    def _forward_subdivided(self, rays, voxel_centers):
        """
        Forward pass for subdivided model.
        rays: (batch, num_samples, 4) - local ray coordinates for each sample in each voxel
        voxel_centers: (batch, num_samples, 3) - voxel centers for each sample
        """
        batch_size, num_samples, _ = rays.shape
        
        # Flatten for network processing
        rays_flat = rays.view(-1, 4)
        centers_flat = voxel_centers.view(-1, 3)
        
        # Compute positional encoding for voxel centers
        # Note: Exact PE function is not specified, assuming standard sinusoidal PE
        pe_centers = self._positional_encoding(centers_flat, self.L)
        
        # Input to Embedding Network: ray coords + voxel center PE
        # The paper says E_phi(r_i, gamma(i)). 
        # Assuming concatenation of r_i and gamma(i)
        # r_i is 4D (e.g. Plucker or direction+origin offset), gamma(i) is PE of center
        # The dimension of r_i in the affine transform A_i * r_i + b_i suggests r_i is 4D
        # to match the 4 columns of A_i (32x4).
        
        # Embedding Network Input Dim: 4 (ray) + PE_dim(3)
        emb_input = torch.cat([rays_flat, pe_centers], dim=1)
        
        # Forward through Embedding Network
        # Output: (A, b) where A is (batch, 32, 4) and b is (batch, 32)
        emb_output = self.embedding_net(emb_input)
        
        # Reshape to separate A and b
        # A: (batch, 32, 4), b: (batch, 32)
        A = emb_output[:, :self.N * 4].view(-1, self.N, 4)
        b = emb_output[:, self.N * 4 : self.N * 5]
        
        # Normalize A
        A = self.normalize_A(A)
        
        # Apply tanh to b
        b = torch.tanh(b)
        
        # Compute transformed input for Color Network: z = A * r + b
        # r is (batch, 4), A is (batch, 32, 4)
        # Result z is (batch, 32)
        # Matrix multiplication: (batch, 32, 4) @ (batch, 4, 1) -> (batch, 32, 1)
        # But r is (batch, 4). We need to broadcast.
        # z = sum(A * r.unsqueeze(1), dim=2) + b
        # A: (B, N, 4), r: (B, 4) -> r.unsqueeze(1): (B, 1, 4)
        # A * r.unsqueeze(1): (B, N, 4)
        # Sum over dim 2: (B, N)
        z = torch.sum(A * rays_flat.unsqueeze(1), dim=2) + b
        
        # Compute positional encoding for z (and potentially i, but i is already in z via A,b?)
        # The formula is F_theta(gamma(A_i r_i + b_i), gamma(i))
        # gamma(z) is PE of the transformed feature
        pe_z = self._positional_encoding(z, self.L)
        
        # Concatenate PE of z and PE of voxel center i
        color_input = torch.cat([pe_z, pe_centers], dim=1)
        
        # Forward through Color Network
        # Output: (color, alpha) -> (batch, 4)
        color_alpha = self.color_net(color_input)
        
        c = color_alpha[:, :3]
        alpha = color_alpha[:, 3:]
        
        # Volume Rendering
        # Sort samples by distance (assumed already sorted or handled by ray traversal)
        # For simplicity, assume samples are sorted by depth in the input rays
        # Accumulate color
        # c = sum(alpha_i * c_i * prod(1 - alpha_j) for j < i)
        
        # Transmittance T_i = prod_{j < i} (1 - alpha_j)
        # T_0 = 1
        # T_i = T_{i-1} * (1 - alpha_{i-1})
        
        alpha_cumprod = torch.cumprod(1 - alpha, dim=1)
        # Shift alpha_cumprod to align with T_i
        # T_i corresponds to product up to i-1
        # alpha_cumprod[i] = prod_{j=0}^{i} (1-alpha_j)
        # So T_i = alpha_cumprod[i-1] if i>0 else 1
        
        # Construct T tensor
        # T = [1, (1-alpha_0), (1-alpha_0)*(1-alpha_1), ...]
        T = torch.cat([torch.ones_like(alpha[:, :1]), alpha_cumprod[:, :-1]], dim=1)
        
        # Final color
        c_final = torch.sum(T * alpha * c, dim=1)
        
        return c_final

    def _forward_global(self, rays):
        """
        Forward pass for non-subdivided model (dense light fields).
        rays: (batch, num_samples, 4)
        """
        # Similar to subdivided but without voxel center PE or with global PE
        # The paper says "single-evaluation per ray model with ray-space embedding"
        # and L=10 frequency bands.
        # Assuming no voxel center index i, or i is global.
        # For simplicity, we treat it as a standard NeRF-like forward pass 
        # but with the affine embedding on the ray itself.
        
        batch_size, num_samples, _ = rays.shape
        rays_flat = rays.view(-1, 4)
        
        # Embedding Network Input: just ray coords? 
        # The paper says E_phi(r_i, gamma(i)). If no subdivision, i might be global or omitted.
        # Let's assume gamma(i) is omitted or constant for global model.
        emb_input = rays_flat
        
        emb_output = self.embedding_net(emb_input)
        A = emb_output[:, :self.N * 4].view(-1, self.N, 4)
        b = emb_output[:, self.N * 4 : self.N * 5]
        
        A = self.normalize_A(A)
        b = torch.tanh(b)
        
        z = torch.sum(A * rays_flat.unsqueeze(1), dim=2) + b
        
        # PE for z with L=10
        pe_z = self._positional_encoding(z, 10)
        
        # Color network input
        color_input = pe_z # Assuming no gamma(i) for global
        
        color_alpha = self.color_net(color_input)
        c = color_alpha[:, :3]
        alpha = color_alpha[:, 3:]
        
        # Volume Rendering
        alpha_cumprod = torch.cumprod(1 - alpha, dim=1)
        T = torch.cat([torch.ones_like(alpha[:, :1]), alpha_cumprod[:, :-1]], dim=1)
        c_final = torch.sum(T * alpha * c, dim=1)
        
        return c_final

    def _positional_encoding(self, x, L):
        """
        Standard sinusoidal positional encoding.
        x: (batch, dim)
        Returns: (batch, 2*L*dim + dim)
        """
        # This is a placeholder for the exact PE implementation.
        # The paper references Park et al. [36] for windowed PE.
        # Standard PE:
        # freq_bands = torch.linspace(0, L-1, L, device=x.device)
        # angles = x.unsqueeze(-1) * (2**freq_bands).unsqueeze(0)
        # pe = torch.cat([torch.sin(angles), torch.cos(angles)], dim=-1)
        # pe = torch.cat([x, pe], dim=-1)
        # For brevity, returning a dummy tensor of correct size.
        dim = x.shape[1]
        pe_dim = 2 * L * dim + dim
        return torch.zeros(x.shape[0], pe_dim, device=x.device)
```

**Parameters:**
*   **Embedding Dimension ($N$):** 32 [S1, unofficial].
*   **Affine Parameters:** $32 \times 4$ matrices $A$ and 32D bias vectors $b$ [S1, unofficial].
*   **Positional Encoding Bands ($L$):** 8 for subdivided model, 10 for one-evaluation model [S1, unofficial].
*   **Batch Size:** 4,096 for subdivided model, 8,192 for one-evaluation model [S1, unofficial].
*   **Training Iterations:** 50,000 for subdivided model, 80,000 for one-evaluation model [S1, unofficial].
*   **Hardware:** Single Tesla V100 GPU with 16 GB memory [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Plücker Coordinates:** Color level sets for Plücker coordinates are no longer affine, which limits the method's effectiveness for 360-degree scenes parameterized this way [S1, unofficial].
*   **Subdivision Cost:** Subdivision increases render time and training time linearly with grid resolution $N$ [S1, unofficial].
*   **Small-Baseline Light Fields:** Do not use subdivision; use a single-evaluation per ray model [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time is approximately 20 hours for sparse light fields (Real Forward-Facing, Shiny) at $32^3$ resolution, and 10 hours for dense light fields (Stanford) [S1, unofficial]. Rendering speed on Stanford dataset is 0.11 seconds per frame (9.14 FPS at 512x512) [S1, unofficial].
*   **Memory Complexity:** Memory footprint is 5.4 MB for the model parameters, compared to 4.6 MB for NeRF and 38.4 MB for NeX [S1, unofficial].
*   **Performance:** Outperforms AutoInt in quality (~2 dB PSNR) and speed (~30% faster) on Real Forward-Facing dataset, and is competitive with NeRF on PSNR/SSIM while being >4.5x faster [S1, unofficial]. Outperforms NeX on Shiny dataset in PSNR [S1, unofficial].
*   **Strengths:** Better reconstruction of view-dependent effects; handles complex view dependence; good trade-off between quality, speed, and memory [S1, unofficial].
*   **Limitations:** Requires subdivision for sparse light fields, increasing training and render time; less effective for 360-degree scenes with Plücker coordinates [S1, unofficial].

## Background
The method was introduced in "Learning Neural Light Fields with Ray-Space Embedding Networks" [S1, unofficial]. It is designed to handle both sparse (wide-baseline) and dense (narrow-baseline) light fields by leveraging spatial subdivision for sparse inputs and a global ray-space embedding for dense inputs. It builds on the concept of neural light fields and aims to improve upon methods like AutoInt and NeRF by explicitly modeling local affine transformations to encourage view consistency [S1, unofficial].
