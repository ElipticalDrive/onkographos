# SUDS
Also called: Scalable Urban Dynamic Scenes

## Overview
SUDS is a 4D radiance field representation designed for large-scale dynamic urban scenes that factorizes the scene into three separate multi-resolution hash table structures: static, dynamic, and far-field [S1]. It enables free-viewpoint rendering, semantic decomposition, and 3D scene flow estimation at arbitrary poses and time steps using only unlabeled inputs (RGB, sparse LiDAR, 2D descriptors, and 2D optical flow) [S1]. Unlike methods requiring 3D bounding boxes or panoptic labels, SUDS disentangles static background, dynamic objects, and shadows through a multi-branch architecture and self-supervised losses [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** $N$ ordered RGB images from different videos (varying days/weather), associated camera poses, aligned sparse LiDAR depth, 2D self-supervised DINO descriptors, and 2D optical flow predictions [S1].
*   **Outputs:** For a query $(\mathbf{x}, \mathbf{d}, t, \text{vid})$, the method outputs view-dependent color $\mathbf{c}$, volume density $\sigma$, semantic features $\Phi$, and 3D scene flow vectors $\mathbf{s}$ [S1].

**Data Structures**
The scene is partitioned into $K$ spatial cells. Each cell maintains three hash table branches [S1]:
1.  **Static Branch:** 3D spatial voxels $\mathbf{v}_{l,s}$ indexed by position [S1].
2.  **Dynamic Branch:** 4D spacetime voxels $\mathbf{v}_{l,d}$ indexed by position, time $t$, and video ID $\text{vid}$ [S1].
3.  **Far-field Branch:** 3D direction voxels $\mathbf{v}_{l,e}$ indexed by viewing direction $\mathbf{d}$ and $\text{vid}$ [S1].

Each hash table stores $F$-dimensional feature vectors. The hierarchy has $L$ resolution levels, doubling in resolution between levels [S1]. Hash indices are computed as:
$$ i_{l,s} = \text{static\_hash}(\text{space}(\mathbf{v}_{l,s})) $$
$$ i_{l,d} = \text{dynamic\_hash}(\text{space}(\mathbf{v}_{l,d}), \text{time}(\mathbf{v}_{l,d}), \text{vid}) $$
$$ i_{l,e} = \text{env\_hash}(\text{dir}(\mathbf{v}_{l,e}), \text{vid}) $$
Hash collisions are handled via gradient averaging [S1].

**Algorithm**
1.  **Voxel Lookup:** For input $(\mathbf{x}, \mathbf{d}, t, \text{vid})$, find surrounding voxels at all $L$ levels for static and dynamic branches [S1].
2.  **Feature Interpolation:**
    *   Static: Linear interpolation of features from voxel corners [S1].
    *   Dynamic: Quadlinear interpolation of features from 4D voxel corners [S1].
    *   Concatenate features from all $L$ levels into vector $\mathbf{f} \in \mathbb{R}^{LF}$ [S1].
3.  **MLP Evaluation:** Pass $\mathbf{f}$ and auxiliary inputs into separate MLPs for each branch [S1].
    *   **Static Output:** $\sigma_s(\mathbf{x}) \in \mathbb{R}$ and $\mathbf{c}_s(\mathbf{x}, \mathbf{d}, \mathbf{A}_{\text{vid}}\mathbf{F}(t)) \in \mathbb{R}^3$. Lighting is conditioned via $\mathbf{A}_{\text{vid}}\mathbf{F}(t)$, where $\mathbf{A}_{\text{vid}}$ is a video-specific matrix and $\mathbf{F}(t)$ is a Fourier-encoded time index [S1].
    *   **Dynamic Output:** $\sigma_d(\mathbf{x}, t, \text{vid}) \in \mathbb{R}$, $\mathbf{c}_d(\mathbf{x}, t, \text{vid}, \mathbf{d}) \in \mathbb{R}^3$, shadow ratio $\rho_d(\mathbf{x}, t, \text{vid}) \in [0, 1]$, and scene flow $\mathbf{s}_{t0}(\mathbf{x}, t, \text{vid}) \in [-1, 1]^3$ [S1].
    *   **Far-field Output:** $\mathbf{c}_e(\mathbf{d}, \text{vid}) \in \mathbb{R}^3$ [S1].
    *   **Semantic Output:** Each branch outputs $C$-dimensional features $\Phi_s, \Phi_d, \Phi_e$ [S1].
4.  **Density Combination:**
    $$ \sigma(\mathbf{x}, t, \text{vid}) = \sigma_s(\mathbf{x}) + \sigma_d(\mathbf{x}, t, \text{vid}) $$
5.  **Radiance Combination:**
    $$ \mathbf{c}(\mathbf{x}, t, \text{vid}, \mathbf{d}) = \frac{(1 - \rho_d)\sigma_s \mathbf{c}_s + \sigma_d \mathbf{c}_d}{\sigma} $$
6.  **Rendering:** Render color $\hat{C}(\mathbf{r})$ and features $\hat{F}(\mathbf{r})$ using standard volume rendering integration along ray $\mathbf{r}$, including far-field contribution if the ray escapes [S1].

**Pseudocode**

```python
def query_suds(x, d, t, vid, hash_tables, mlps, A_vid, F_t):
    """
    Query the SUDS representation for a single point.
    x: (3,) position
    d: (3,) viewing direction
    t: float time index
    vid: int video ID
    hash_tables: dict with keys 'static', 'dynamic', 'far_field'
                 Each contains lists of hash functions and feature grids
    mlps: dict with keys 'static', 'dynamic', 'far_field'
    A_vid: (F, F_light) video-specific matrix
    F_t: (F_light,) Fourier-encoded time vector
    """
    features_static = []
    features_dynamic = []
    
    # 1. Lookup and Interpolate Static Branch
    for level in hash_tables['static'].levels:
        voxels = get_surrounding_voxels(level, x)
        indices = [static_hash(v) for v in voxels]
        # Linear interpolation of features at indices
        feat = interpolate_linear(voxels, x, indices, hash_tables['static'].features)
        features_static.append(feat)
        
    # 2. Lookup and Interpolate Dynamic Branch
    for level in hash_tables['dynamic'].levels:
        voxels = get_surrounding_voxels_4d(level, x, t)
        # Hash includes time and vid
        indices = [dynamic_hash(v, t, vid) for v in voxels]
        # Quadlinear interpolation
        feat = interpolate_quadlinear(voxels, (x, t), indices, hash_tables['dynamic'].features)
        features_dynamic.append(feat)
        
    # 3. Concatenate and MLP
    f_static = concat(features_static)
    f_dynamic = concat(features_dynamic)
    
    # Static MLP
    lighting_cond = matmul(A_vid, F_t)
    sigma_s, c_s, phi_s = mlps['static'](f_static, d, lighting_cond)
    
    # Dynamic MLP
    sigma_d, c_d, rho_d, s_flow, phi_d = mlps['dynamic'](f_dynamic, d)
    
    # Far-field (simplified lookup)
    c_e = lookup_env_map(hash_tables['far_field'], d, vid)
    phi_e = lookup_env_features(hash_tables['far_field'], d, vid)
    
    # 4. Combine
    sigma_total = sigma_s + sigma_d
    if sigma_total == 0:
        c_total = c_e
        phi_total = phi_e
    else:
        c_total = ((1 - rho_d) * sigma_s * c_s + sigma_d * c_d) / sigma_total
        phi_total = (sigma_s * phi_s + sigma_d * phi_d) / sigma_total
        
    return sigma_total, c_total, phi_total, s_flow, rho_d

def render_ray(r, t, vid, hash_tables, mlps, A_vid, F_t, num_samples):
    """
    Render a single ray using volume rendering.
    r: Ray origin and direction
    """
    samples = sample_along_ray(r, num_samples)
    total_transmittance = 1.0
    accumulated_color = zeros(3)
    accumulated_features = zeros(C)
    
    for x in samples:
        sigma, c, phi, s_flow, rho = query_suds(x, r.d, t, vid, hash_tables, mlps, A_vid, F_t)
        
        alpha = 1.0 - exp(-sigma * r.delta)
        weight = total_transmittance * alpha
        
        accumulated_color += weight * c
        accumulated_features += weight * phi
        
        total_transmittance *= (1.0 - alpha)
        
    # Add far-field if ray escapes
    accumulated_color += total_transmittance * lookup_env_map(hash_tables['far_field'], r.d, vid)
    accumulated_features += total_transmittance * lookup_env_features(hash_tables['far_field'], r.d, vid)
    
    return accumulated_color, accumulated_features, s_flow
```

**Loss Functions**
*   **Reconstruction:** L2 photometric loss $L_c(\mathbf{r}) = \|\mathbf{C}(\mathbf{r}) - \hat{\mathbf{C}}(\mathbf{r})\|^2$ and L1 feature loss $L_f(\mathbf{r}) = \|\mathbf{F}(\mathbf{r}) - \hat{\mathbf{F}}(\mathbf{r})\|_1$ [S1].
*   **Depth:** L2 loss between rendered depth $\hat{D}(\mathbf{r})$ and LiDAR $D(\mathbf{r})$ [S1].
*   **Flow:** L1 loss between rendered 2D flow from 3D scene flow and observed optical flow [S1].
*   **Warping:** Advect samples using predicted flow to adjacent frames, render warped color/features, and minimize L2/L1 loss against ground truth, downweighted by ambiguity weight $W_{t0}$ [S1].
*   **Flow Regularization:** Cycle consistency $L_{cyc}$, spatial/temporal smoothness $L_{sm}$, and static scene prior $L_{slo}$ (L1 norm of flow) [S1].
*   **Static-Dynamic Factorization:** Skewed binary entropy loss $L_e(\mathbf{r}) = \int H\left(\frac{\sigma_d}{\sigma_s + \sigma_d}\right) dt$ with $k=1.75$, and max dynamic ratio penalty $L_d(\mathbf{r}) = \max(\frac{\sigma_d}{\sigma_s + \sigma_d})$ [S1].
*   **Shadow:** L2 penalty on shadow ratio $\rho_d$ [S1].

**Parameters**
*   $F$: Feature vector dimensionality [S1].
*   $L$: Number of resolution levels [S1].
*   $N$: Number of input videos [S1].
*   $C$: Dimensionality of DINO features [S1].
*   $k$: Constant $1.75$ for entropy loss [S1].
*   Training: 250,000 iterations, 4098 rays/batch, Adam optimizer, LR $5 \times 10^{-3}$ decaying to $5 \times 10^{-4}$ [S1].

## Operating characteristics
*   **Scale:** Handles tens of thousands of objects across 1.2 million frames from 1700 videos spanning hundreds of kilometers [S1].
*   **Speed:** 10x quicker to train than methods requiring ground truth 3D bounding box annotations [S1].
*   **Memory:** Uses multi-resolution hash tables, avoiding the linear memory growth of per-object NeRFs (e.g., NSG requires >1TB for 30s video) [S1].
*   **Strengths:** Handles ego-motion, multi-video representations, and shadows; uses unlabeled supervision [S1].
*   **Limitations:** Requires sparse LiDAR and optical flow for optimal performance; complex loss balancing [S1].

## Background
SUDS was introduced in 2023 by the authors of "SUDS: Scalable Urban Dynamic Scenes" [S1]. It addresses the limitations of prior dynamic NeRF methods that relied on supervised 3D bounding boxes or panoptic labels, which are difficult to acquire for large-scale in-the-wild captures [S1]. It builds on Instant-NGP's multi-resolution hash tables and extends them to 4D spacetime and multi-video indexing [S1].
