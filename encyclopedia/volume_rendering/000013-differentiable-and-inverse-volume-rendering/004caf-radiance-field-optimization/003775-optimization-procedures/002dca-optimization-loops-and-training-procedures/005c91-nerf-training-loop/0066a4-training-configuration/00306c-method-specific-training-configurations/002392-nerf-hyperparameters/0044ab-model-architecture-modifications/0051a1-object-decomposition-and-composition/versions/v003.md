# Object Decomposition and Composition


## Overview
Object Decomposition and Composition refers to a family of NeRF architectures that explicitly separate a scene into distinct object instances and background components, enabling instance-level editing, segmentation, and manipulation [S1]. Unlike standard NeRFs that treat the scene as a monolithic volume, these methods introduce mechanisms to identify, isolate, and recombine individual objects, allowing for operations such as translation, rotation, and deformation without affecting other scene elements [S1]. This family is distinguished from sibling methods like [DoF-NeRF](9432-dof-nerf.md) (which focuses on depth-of-field) or [Semantic and Feature Field Extensions](15556-semantic-and-feature-field-extensions.md) (which adds semantic labels) by its primary goal of structural disentanglement for geometric manipulation and scene editing [S1].

## Shared principles
The core mechanism across this family involves partitioning the radiance field representation into multiple branches or fields, each responsible for a specific object or the background. Common elements include:
1.  **Instance Identification:** A mechanism to assign 3D points or rays to specific object instances. This is achieved via learnable object codes [S1], one-hot activation based on density [S1], or frequency-based segmentation [S1].
2.  **Separate Representation:** Distinct neural networks or heads predict density and color for each instance, often conditioned on a shared feature backbone [S1].
3.  **Composition:** A differentiable process to combine the outputs of individual instance fields into a final rendered image. This often involves weighted summation based on activation probabilities or masks [S1].
4.  **Editing Capability:** The separation allows for the transformation of specific object coordinates (e.g., via an inverse query or direct coordinate manipulation) while keeping the radiance field parameters fixed, followed by re-rendering [S1].

## Subtopics

### [DM-NeRF](13525-dm-nerf.md)
DM-NeRF simultaneously reconstructs geometry and decomposes objects using an **object field** that predicts a one-hot object code for every 3D point. It distinguishes itself by integrating decomposition and manipulation into a single differentiable pipeline, handling occlusions via an inverse query algorithm. Choose this method when flexible object shape manipulation (translation, rotation, scaling) is required without 3D ground truth labels.

### [Unified Decompositional and Compositional NeRF](14413-unified-decompositional-and-compositional-nerf.md)
UDC-NeRF is a two-stage framework that jointly learns object-level and scene-level implicit representations. It uses a coarse global field to guide sampling for a fine-grained stage that decomposes the scene into distinct object and background radiance fields. It distinguishes itself by explicitly modeling the interaction between decomposition and composition through a one-hot activation mechanism and residual composition, ensuring global consistency while allowing disentangled manipulation.

### [Detail-based Segmentation](15935-detail-based-segmentation.md)
This is a divide-and-conquer strategy that partitions a scene into multiple specialized networks based on the spatial frequency of detected objects. It solves the problem of single-NeRF networks struggling with high-frequency details by assigning high-frequency objects to dedicated NeRFs and grouping low-frequency objects into a shared NeRF. Choose this when the scene contains objects with varying levels of geometric complexity that a single network fails to render accurately.

#### Fig-NeRF
Fig-NeRF is a scene composition model for object interpolation and amodal segmentation using two separate NeRF models for foreground and background [S1]. It uses an appearance NeRF conditioned on latent codes for the background model and a deformable NeRF for the foreground [S1]. It employs two photometric losses, one for the foreground and one for the background [S1].

## Background
The concept of decomposing scenes into objects for NeRF representation emerged as a solution to the limitations of monolithic radiance fields, which lack explicit object boundaries and make editing difficult. Early works like Fig-NeRF (April 2021) introduced separate models for foreground and background to enable amodal segmentation and object interpolation [S1]. Subsequent research, such as Object-NeRF (September 2021), utilized hybrid voxel-based approaches with conditioned NeRFs to separate and edit objects [S1]. More recent methods like DM-NeRF and UDC-NeRF have refined these approaches by introducing differentiable one-hot activations, inverse query algorithms, and residual composition techniques to achieve more robust decomposition and manipulation from 2D images alone [S1]. These methods are primarily used in applications requiring scene editing, object manipulation, and detailed semantic understanding of 3D scenes [S1].
