# SUDS
Also called: Scalable Urban Dynamic Scenes

## Overview
SUDS is a 4D radiance field representation designed for large-scale dynamic urban scenes that factorizes the scene into three separate multi-resolution hash table data structures to efficiently encode static, dynamic, and far-field radiance fields [S1]. It solves the problem of scaling neural reconstruction to city-level environments with significant dynamism and ego-motion by using unlabeled target signals (RGB, sparse LiDAR, 2D descriptors, 2D optical flow) for supervision, avoiding the need for expensive 3D bounding box or panoptic segmentation annotations [S1]. Unlike sibling methods that rely on per-object NeRFs or supervised labels, SUDS handles multi-video representations and ego-motion while maintaining memory efficiency through spatial partitioning and hash-based feature storage [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ordered RGB images from $N$ videos taken at different days with diverse weather/lighting, associated camera poses, aligned sparse LiDAR depth measurements, 2D self-supervised DINO descriptors, and 2D optical flow predictions [S1].
*   **Outputs:** View-dependent color $\mathbf{c}$, volume density $\sigma$, semantic features $\Phi$, and 3D scene flow vectors $\mathbf{s}$ for any position $\mathbf{x}$, viewing direction $\mathbf{d}$, time $t$, and video ID $vid$ [S1].

**Data Structures:**
The scene is decomposed into $K$ spatial cells with centroids $\mathbf{k} \in \mathbb{R}^3$. Each cell contains three branches, each modeled by a multi-resolution hash table hierarchy with $L$ levels, where resolution doubles between levels [S1].
1.  **Static Branch:** Stores 3D spatial voxels $\mathbf{v}_{l,s}$. Features are indexed by spatial position only.
2.  **Dynamic Branch:** Stores 4D spacetime voxels $\mathbf{v}_{l,d}$. Features are indexed by spatial position, time, and video ID.
3.  **Far-field Branch:** Stores 3D voxels $\mathbf{v}_{l,e}$ indexed by normalized 3D direction vectors $\mathbf{d}$ and video ID, modeling the environment map [S1].

Each voxel corner in the hash tables stores a feature vector $\mathbf{f} \in \mathbb{R}^F$, where $F$ is the feature dimensionality [S1]. Hash collisions are handled via gradient averaging [S1].

**Parameters:**
*   $L$: Number of resolution levels in the hash table hierarchy [S1].
*   $F$: Dimensionality of feature vectors in the hash tables [S1].
*   $N$: Number of input videos [S1].
*   $C$: Dimensionality of the DINO feature grid output ($\mathbb{R}^{H \times W \times C}$) [S1].
*   $k$: Constant set to 1.75 in the skewed binary entropy loss [S1].
*   Training: 250,000 iterations, 4098 rays per batch, Adam optimizer with learning rate decaying from $5 \times 10^{-3}$ to $5 \times 10^{-4}$ [S1].

**Algorithm Steps:**

1.  **Spatial Partitioning and Data Preparation:**
    Split the scene into $K$ spatial cells. For each cell, generate a training dataset including only datapoints whose camera rays intersect the cell. Prune irrelevant rays using LiDAR depth measurements to ensure visibility [S1].

2.  **Hash Indexing:**
    For an input coordinate $(\mathbf{x}, \mathbf{d}, t, vid)$, find surrounding voxels at $L$ resolution levels for the static ($\mathbf{v}_{l,s}$), dynamic ($\mathbf{v}_{l,d}$), and far-field ($\mathbf{v}_{l,e}$) branches. Compute hash indices for the corners of these voxels:
    $$ i_{l,s} = \text{static\_hash}(\text{space}(\mathbf{v}_{l,s})) $$
    $$ i_{l,d} = \text{dynamic\_hash}(\text{space}(\mathbf{v}_{l,d}), \text{time}(\mathbf{v}_{l,d}), vid) $$
    $$ i_{l,e} = \text{env\_hash}(\text{dir}(\mathbf{v}_{l,e}), vid) $$
    [S1]

3.  **Feature Interpolation:**
    Look up feature vectors corresponding to the hashed corners. Linearly interpolate features for the static branch. Use quadlinear interpolation for the dynamic 4D branch. Concatenate the interpolated features from all $L$ levels into a feature vector $\mathbf{f} \in \mathbb{R}^{LF}$ [S1].

4.  **Branch Evaluation (MLP):**
    Pass $\mathbf{f}$ and auxiliary inputs into separate MLPs for each branch:
    *   **Static Branch:** Compute view-dependent color $\mathbf{c}_s(\mathbf{x}, \mathbf{d}, \mathbf{A}_{vid}\mathbf{F}(t)) \in \mathbb{R}^3$ and view-independent density $\sigma_s(\mathbf{x}) \in \mathbb{R}$. Lighting variations are conditioned using a video-specific matrix $\mathbf{A}_{vid}$ and Fourier-encoded time index $\mathbf{F}(t)$ [S1].
    *   **Dynamic Branch:** Compute time/video-dependent density $\sigma_d(\mathbf{x}, t, vid) \in \mathbb{R}$, color $\mathbf{c}_d(\mathbf{x}, t, vid, \mathbf{d}) \in \mathbb{R}^3$, and scalar shadow ratio $\rho_d(\mathbf{x}, t, vid) \in [0, 1]$. Also predict forward/backward 3D scene flow $\mathbf{s}_{t0}(\mathbf{x}, t, vid) \in \mathbb{R}^3$ with values in $[-1, 1]$ [S1].
    *   **Far-field Branch:** Model far-field radiance with environment map $\mathbf{c}_e(\mathbf{d}, vid) \in \mathbb{R}^3$ [S1].
    *   **Semantic Heads:** Each branch outputs $C$-dimensional semantic features $\Phi_s, \Phi_d, \Phi_e$ to distill DINO features [S1].

5.  **Density and Radiance Combination:**
    Compute total density:
    $$ \sigma(\mathbf{x}, t, vid) = \sigma_s(\mathbf{x}) + \sigma_d(\mathbf{x}, t, vid) $$
    Compute total radiance, scaling static color by the shadow ratio:
    $$ \mathbf{c}(\mathbf{x}, t, vid, \mathbf{d}) = \frac{(1 - \rho_d)\sigma_s \mathbf{c}_s + \sigma_d \mathbf{c}_d}{\sigma} $$
    [S1]

6.  **Rendering:**
    Render color $\hat{\mathbf{C}}$ for a camera ray $\mathbf{r}$ by accumulating transmittance along sampled points $\mathbf{r}(t)$:
    $$ \hat{\mathbf{C}}(\mathbf{r}, t, vid) = \int_0^{+\infty} T(t)\sigma(\mathbf{r}(t), t, vid)\mathbf{c}(\mathbf{r}(t), t, vid, \mathbf{d}) dt + T(+\infty)\mathbf{c}_e(\mathbf{d}, vid) $$
    where $T(t) = \exp\left(-\int_0^t \sigma(\mathbf{r}(s), t, vid) ds\right)$ [S1].

7.  **Loss Calculation:**
    Minimize the following losses:
    *   **Reconstruction:** L2 photometric loss $\mathcal{L}_c(\mathbf{r}) = \|\mathbf{C}(\mathbf{r}) - \hat{\mathbf{C}}(\mathbf{r})\|^2$ and L1 feature loss $\mathcal{L}_f(\mathbf{r}) = \|\mathbf{F}(\mathbf{r}) - \hat{\mathbf{F}}(\mathbf{r})\|_1$ [S1].
    *   **Depth:** L2 loss between rendered depth $\hat{D}(\mathbf{r})$ and LiDAR depth $D(\mathbf{r})$ [S1].
    *   **Flow:** Render 2D optical flow from predicted 3D scene flow $\hat{\mathbf{X}}_{t0}$ and minimize L1 distance to observed optical flow $\mathbf{O}$ [S1].
    *   **Warping:** Advect samples using predicted flow to warp density, color, and features. Render warped color $\hat{\mathbf{C}}^w$ and feature $\hat{\mathbf{F}}^w$. Minimize L2/L1 losses downweighted by a weight $W_{t0}(\mathbf{r})$ derived from dynamic geometry difference [S1].
    *   **Flow Regularization:** Cycle consistency $\mathcal{L}_{cyc}$, spatial/temporal smoothness $\mathcal{L}_{sm}$, and static scene prior $\mathcal{L}_{slo}$ (penalizing flow in static regions) [S1].
    *   **Static-Dynamic Factorization:** Skewed binary entropy loss $\mathcal{L}_e(\mathbf{r}) = \int_0^{+\infty} H\left(\frac{\sigma_d}{\sigma_s + \sigma_d}\right)^k dt$ with $k=1.75$, and penalty on max dynamic ratio $\mathcal{L}_d$ [S1].
    *   **Shadow Loss:** Penalize squared magnitude of shadow ratio $\mathcal{L}_\rho$ [S1].

def static_hash(space_voxel):
    # Hash function for static branch based on spatial position
    return hash(space_voxel)

def dynamic_hash(space_voxel, time_val, vid):
    # Hash function for dynamic branch based on space, time, and video ID
    return hash((space_voxel, time_val, vid))

def env_hash(dir_voxel, vid):
    # Hash function for far-field branch based on direction and video ID
    return hash((dir_voxel, vid))

        # Retrieve feature vector from hash table
        feat = get_feature_from_hash_table(idx)
        features.append(feat)
    
    if is_dynamic:
        # Quadlinear interpolation for 4D
        interpolated = quadlinear_interpolation(features, voxel_corners)
    else:
        # Linear interpolation for 3D
        interpolated = np.mean(features, axis=0)
    return interpolated

def fourier_encode_time(t, num_freq_bands=10):
    # Fourier encoding of time index
    t = t.reshape(-1, 1)
    scales = np.array([2**i for i in range(num_freq_bands)])
    emb = np.sin(np.concatenate([t * s for s in scales], axis=1))
    return emb

def compute_lighting_embedding(vid, t, A_vid):
    # Compute latent embedding for lighting variations
    F_t = fourier_encode_time(t)
    return A_vid @ F_t

def evaluate_static_branch(f_static, d, vid, t, A_vid):
    # Static branch MLP
    lighting_emb = compute_lighting_embedding(vid, t, A_vid)

    input_vec = np.concatenate([f_dynamic, d])
    # Pass through MLP

    c_d = mlp_dynamic_color(input_vec)
    rho_d = mlp_dynamic_shadow(input_vec)
    s_flow = mlp_dynamic_flow(input_vec)
    phi_d = mlp_dynamic_semantic(input_vec)
    return sigma_d, c_d, rho_d, s_flow, phi_d

def evaluate_far_field_branch(f_far, d, vid):

    # Concatenate f_far, d
    input_vec = np.concatenate([f_far, d])
    c_e = mlp_far_field_color(input_vec)
    phi_e = mlp_far_field_semantic(input_vec)
    return c_e, phi_e

    # r: ray origin and direction
    # t: time index
    # vid: video ID
    # K_cells: list of spatial cell objects

    c_total = np.zeros(3)
    phi_total = np.zeros(C)

        dynamic_voxels = get_voxel_corners(x, level=L, type='dynamic')

        # Hash indices
        static_indices = [static_hash(v.space) for v in static_voxels]

        far_indices = [env_hash(v.dir, vid) for v in far_voxels]
        
        # Interpolate features
        f_static = interpolate_features(static_indices, static_voxels, is_dynamic=False)
        f_dynamic = interpolate_features(dynamic_indices, dynamic_voxels, is_dynamic=True)
        f_far = interpolate_features(far_indices, far_voxels, is_dynamic=False)

        c_total += weight * c_branch
        phi_total += weight * phi_branch
        T *= (1.0 - sigma)
        
        if T < 1e-4:

    c_total += T * c_e
    phi_total += T * phi_e
    
    return c_total, phi_total, sigma, s_flow

    L_o = np.mean(np.abs(predicted_2d_flow - gt_flow))
    
    # Warping Loss
    # Advect samples using s_flow
    warped_sigma, warped_color, warped_feature = advect_samples(sigma_s, sigma_d, rendered_color, rendered_feature, s_flow)
    # Downweight in ambiguous regions
    W = compute_warping_weight(sigma_s, sigma_d)
    L_w_c = np.mean((1 - W) * (warped_color - gt_color)**2)
    L_w_f = np.mean((1 - W) * np.abs(warped_feature - gt_feature))
    
    # Flow Regularization
    L_cyc = compute_cycle_consistency(s_flow)
    L_sm = compute_smoothness(s_flow)
    L_slo = np.mean(np.abs(s_flow)) # Static scene prior
    
    # Static-Dynamic Factorization
    # Skewed binary entropy
    ratio = sigma_d / (sigma_s + sigma_d + 1e-5)
    H = -(ratio * np.log(ratio + 1e-5) + (1 - ratio) * np.log(1 - ratio + 1e-5))
    L_e = np.mean(H**1.75) # k=1.75
    L_d_ratio = np.mean(np.max(ratio))
    
    # Shadow Loss
    L_rho = np.mean(rho_d**2)
    
    total_loss = L_c + L_f + L_d + L_o + L_w_c + L_w_f + L_cyc + L_sm + L_slo + L_e + L_d_ratio + L_rho
    return total_loss

## Subtopics

### Spatial Partitioning
Splits the scene into $K$ cells to enable parallel training and memory efficiency. It uses visibility reasoning with LiDAR depth to prune irrelevant rays for each cell, ensuring that occluded regions are not processed [S1].

### Multi-Video Hashing
Uses video ID ($vid$) as an auxiliary input to the hash function to index separate interpolating functions for each video. This allows the model to handle distinct moving objects and illumination conditions across videos without linear memory growth [S1].

### Shadow Modeling
Explicitly models a shadow field $\rho_d$ in the dynamic branch to scale down static color. This improves depth reconstruction and static/dynamic factorization by accounting for shadows cast by dynamic objects [S1].

## Operating characteristics
*   **Time Complexity:** Training is 10x quicker than state-of-the-art methods that rely on ground truth 3D bounding box annotations [S1].
*   **Memory Complexity:** Scales to tens of thousands of objects across 1.2 million frames from 1700 videos spanning hundreds of kilometers. Memory usage is controlled by multi-resolution hash tables and spatial partitioning, avoiding the >1TB memory requirement of per-object NeRFs like NSG for similar durations [S1].
*   **Performance:** Surpasses state-of-the-art methods on KITTI and Virtual KITTI 2 datasets [S1].
*   **Strengths:** Handles ego-motion, multi-video representations, and large-scale dynamic scenes without supervised 3D labels. Enables free-viewpoint rendering, semantic decomposition, and 3D scene flow [S1].
*   **Limitations:** Relies on self-supervised 2D descriptors (DINO) and optical flow, which may be less robust than explicit 3D labels in highly ambiguous regions. Requires careful tuning of loss weights for flow and factorization [S1].

## Background
SUDS (Scalable Urban Dynamic Scenes) was introduced in 2023 by the authors of the paper "SUDS: Scalable Urban Dynamic Scenes" [S1]. It addresses the limitations of prior dynamic scene representations that required supervised inputs like panoptic segmentation labels or bounding boxes, which are difficult to acquire for in-the-wild captures. SUDS builds on the multi-resolution hash table concept from Instant-NGP [S1] and extends it to 4D with a three-branch decomposition (static, dynamic, far-field) to handle city-scale environments. It is used for novel-view synthesis of dynamic urban scenes, unsupervised 3D instance segmentation, and 3D cuboid detection [S1].
