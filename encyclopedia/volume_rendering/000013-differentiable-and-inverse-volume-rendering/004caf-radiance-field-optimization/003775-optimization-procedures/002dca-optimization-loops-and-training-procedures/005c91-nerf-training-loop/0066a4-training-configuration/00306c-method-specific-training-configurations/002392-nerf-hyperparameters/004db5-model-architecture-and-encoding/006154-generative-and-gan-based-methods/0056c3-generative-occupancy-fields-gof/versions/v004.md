# Generative Occupancy Fields (GOF)

## Overview
Generative Occupancy Fields (GOF) is a 3D-aware image synthesis method that combines the training stability of generative radiance fields with the surface compactness of occupancy networks [S1, unofficial]. It solves the "shape-color ambiguity" and diffused surface artifacts common in standard generative radiance fields (like pi-GAN) by reinterpreting cumulative rendering alpha values as occupancy probabilities [S1, unofficial]. Unlike its siblings which either maintain diffused volumes or suffer from sparse gradient convergence, GOF transitions from volume rendering to surface-only rendering during training by gradually shrinking the sampling region around a root-found surface [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A latent code $z \sim p_z$ (typically truncated for inference) and a camera pose $\xi \sim p_\xi$.
*   **Output:** A synthesized RGB image $\tilde{C}(r, z)$ for each pixel ray $r$.

**Data Structures:**
The generator $G_\theta$ (typically a FiLMed-SIREN network) takes encoded spatial coordinates and the latent code $z$ as input. It outputs a scalar alpha value $\alpha_\theta(x, z) \in [0, 1]$ and a color vector $c_\theta(x, d, z) \in \mathbb{R}^3$. The discriminator $D_\phi$ takes an image and outputs a scalar score.

**Parameters:**
*   $N$: Number of points sampled for rendering. Typical value: 12 [S1, unofficial].
*   $M$: Number of evenly-spaced points for root-finding. Typical value: 12 [S1, unofficial].
*   $m_s$: Number of secant method iterations for surface refinement. Typical value: 3 [S1, unofficial].
*   $\tau$: Threshold for root-finding to distinguish free space from occupied space. Typical value: 0.5 [S1, unofficial].
*   $\Delta_{init}$: Initial sampling interval, set to $(t_f - t_n)/2$ where $[t_n, t_f]$ is the near/far bound [S1, unofficial].
*   $\Delta_{min}$: Minimal sampling interval for inference and late training [S1, unofficial].
*   $\gamma$: Decay rate for the shrinking interval [S1, unofficial].

**Algorithm Steps:**

1.  **Surface Location via Root-Finding:**
    To locate the object surface $S$ along a ray $r(t) = o + td$:
    1.  Sample $M$ evenly-spaced points $x_k$ partitioning the volume $[t_n, t_f]$.
    2.  Query the generator for alpha values $\alpha_\theta(x_k, z)$. Note: These queries do not require gradient computation.
    3.  Find the bin index $k_S$ where the alpha value crosses the threshold $\tau$:
        $$ k_S = \arg\min_k (\alpha_\theta(x_k, z) < \tau \le \alpha_\theta(x_{k+1}, z)) $$
    4.  Apply the secant method iteratively $m_s$ times within the bin $[x_{k_S}, x_{k_S+1}]$ to find the precise surface point $x_s$ and its depth $t_s$ [S1, unofficial].

2.  **Shrinking Sampling Region (Training Only):**
    To transition from volume rendering to surface rendering, the sampling region is shrunk over training steps $n$:
    1.  Compute the current interval $\Delta_n$:
        $$ \Delta_n = \max(\Delta_{init} \exp(-\gamma n), \Delta_{min}) $$
    2.  Sample $N$ points uniformly in the interval $[t_s - \Delta_n, t_s + \Delta_n]$. The $i$-th point depth $t_i$ is sampled from:
        $$ t_i \sim U\left[t_s - \Delta_n + \frac{2i-2}{N}\Delta_n, t_s - \Delta_n + \frac{2i}{N}\Delta_n\right] $$
    3.  If the interval $[t_s - \Delta_n, t_s + \Delta_n]$ exceeds the global bounds $[t_n, t_f]$, shift it back to fit within bounds [S1, unofficial].

3.  **Rendering:**
    Render the image using alpha composition. Since GOF predicts alpha directly, the color $\tilde{C}(r, z)$ is computed as:
    $$ \tilde{C}(r, z) = \sum_{i=1}^{N} \alpha_\theta(x_i, z) \left( \prod_{j<i} (1 - \alpha_\theta(x_j, z)) \right) c_\theta(x_i, d, z) $$
    where $x_i$ are the sampled points from Step 2 [S1, unofficial].

4.  **Inference Optimization:**
    During inference, the sampling region is fixed at the minimal size $[t_s - \Delta_{min}, t_s + \Delta_{min}]$. For maximum speed, GOF can render using only the single surface point $x_s$ (i.e., $N=1$), as the compact surface ensures negligible error when $\Delta_{min} \to 0$ [S1, unofficial].

**Loss Functions:**
The total loss $L(\theta, \phi)$ combines the GAN loss with two regularizations:
$$ L(\theta, \phi) = L_{origin}(\theta, \phi) + \lambda_{normal} L_{normal} + \lambda_{opacity} L_{opacity} $$

*   **GAN Loss ($L_{origin}$):**
    $$ L_{origin}(\theta_D, \theta_G) = \mathbb{E}_{z \sim p_z, \xi \sim p_\xi} f(D_{\theta_D}(G_{\theta_G}(z, \xi))) + \mathbb{E}_{I \sim p_D} f(-D_{\theta_D}(I)) + \lambda ||\nabla_{D_{\theta_D}}(I)||_2^2 $$
    where $f(u) = -\log(1 + \exp(-u))$ [S1, unofficial].

*   **Normal Regularization ($L_{normal}$):**
    Encourages surface normal smoothness at the located surface points $x_s \in S$:
    $$ L_{normal} = \sum_{x_s \in S} ||n_\theta(x_s, z) - n_\theta(x_s + \epsilon, z)||_2 $$
    where $n_\theta$ is the surface normal estimated via finite differences [S1, unofficial].

*   **Opacity Regularization ($L_{opacity}$):**
    Reduces the entropy of alpha values, pushing them towards 0 or 1:
    $$ L_{opacity} = \frac{1}{N} \sum_{i=1}^{N} \log(\alpha_\theta(x_i, z)) + \log(1 - \alpha_\theta(x_i, z)) $$
    [S1, unofficial].

**Pitfalls and Edge Cases:**
*   **Shape-Color Ambiguity:** Direct training of generative radiance fields fails to maintain surface compactness because small perturbations on surfaces still produce realistic RGB images, fooling the discriminator [S1, unofficial]. GOF mitigates this by forcing the model to rely on precise surface location.
*   **Gradient Sparsity:** Directly applying occupancy networks to generative models causes convergence issues due to sparse gradients located only on surfaces. GOF avoids this by starting with volume rendering (dense gradients) and gradually shrinking the region [S1, unofficial].
*   **Density Thresholding:** Predicted densities in standard radiance fields can range widely (e.g., 0 to 50), making thresholding unreliable. GOF predicts alpha values bounded in $[0, 1]$, enabling a stable threshold $\tau=0.5$ [S1, unofficial].
*   **Furry/Translucent Objects:** Surface rendering mode ($N=1$) may over-smooth or fail for objects with complex internal structures or fur, as it assumes a single solid surface [S1, unofficial].

## Operating characteristics
*   **Query Complexity:** Standard rendering requires $M + m_s + N$ network queries per pixel (for root-finding and rendering). Single-point surface rendering requires $M + m_s + 1$ queries. Baselines using hierarchical sampling typically require $2N$ queries [S1, unofficial].
*   **Performance:** GOF significantly outperforms baselines on the Mean Angle Deviation (MAD) metric, indicating superior surface compactness. It is comparable to strong baselines on the Scale-Invariant Depth Error (SIDE) metric [S1, unofficial].
*   **Strengths:** Produces compact, smooth surfaces; avoids shape-color ambiguity; allows efficient single-point rendering at inference.
*   **Limitations:** Struggles with non-solid or translucent objects (e.g., fur) when using surface-only rendering; requires careful tuning of the shrinking schedule parameters ($\gamma, \Delta_{min}$) [S1, unofficial].

## Background
Generative Occupancy Fields (GOF) was proposed by Xudong Xu, Xingang Pan, Dahua Lin, and Bo Dai in November 2021 [S1, unofficial]. It addresses limitations in prior generative radiance field methods like pi-GAN, which suffer from diffused surfaces due to the cumulative nature of volume rendering. GOF builds on the architecture of GRAFs (Generative Radiance Fields) but introduces the concept of reinterpreting alpha values as occupancy to enable root-finding and surface-aware synthesis [S1, unofficial]. It is used for 3D-aware image synthesis on datasets such as CelebA, BFM, and Cats [S1, unofficial].
