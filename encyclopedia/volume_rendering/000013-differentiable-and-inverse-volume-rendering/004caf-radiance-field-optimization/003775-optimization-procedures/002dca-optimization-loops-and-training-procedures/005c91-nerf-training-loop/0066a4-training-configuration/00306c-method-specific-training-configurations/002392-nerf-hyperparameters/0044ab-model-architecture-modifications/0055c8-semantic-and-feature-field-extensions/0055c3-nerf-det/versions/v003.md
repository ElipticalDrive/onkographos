# NeRF-Det

Also called: NeRF-then-Det

## Overview
NeRF-Det is a method for indoor 3D object detection using posed RGB images that explicitly models scene geometry as an opacity field by jointly training a NeRF branch with a 3D detection pipeline [S1]. It improves upon "NeRF-then-Det" paradigms (like NeRF-RPN) by integrating multi-view geometry constraints from the NeRF branch into 3D detection through a shared geometry MLP, enabling end-to-end training without per-scene optimization [S1]. Unlike sibling methods that primarily focus on semantic segmentation or feature enhancement for rendering, NeRF-Det specifically targets 3D bounding box regression by using NeRF to resolve geometric ambiguity in volumetric representations [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $T$ posed RGB images $I_i \in \mathbb{R}^{H_i \times W_i \times 3}$ with corresponding intrinsic matrix $K \in \mathbb{R}^{3 \times 3}$ and extrinsic matrix $R_i \in \mathbb{R}^{3 \times 4}$ for $i=1, \dots, T$ [S1].
*   **Outputs:** 3D bounding boxes for detected objects, and optionally novel view synthesis images and depth maps [S1].

**Data Structures:**
1.  **2D Feature Map ($F_i$):** High-resolution features extracted from each image $I_i$ using a Feature Pyramid Network (FPN). Dimensions: $\mathbb{R}^{C \times H/4 \times W/4}$ [S1].
2.  **3D Voxel Grid:** A grid of $N_x \times N_y \times N_z$ voxels. The coordinate system has the z-axis as height, and x/y as horizontal dimensions [S1].
3.  **Volume Features ($V_i(p)$):** For each voxel center $p=(x,y,z)^T$, a feature vector assigned from the 2D image features [S1].
4.  **Aggregated Volume Features ($V_{avg}(p)$):** The mean of effective multi-view features for each voxel [S1].
5.  **Geometry-Aware Volume Features:** The product of the opacity field $\alpha(p)$ and $V_{avg}(p)$ [S1].

**Numbered Steps:**

1.  **2D Feature Extraction:** Pass each input image $I_i$ through a 2D image backbone (FPN) to extract high-resolution features $F_i \in \mathbb{R}^{C \times H/4 \times W/4}$ [S1].

2.  **3D Grid Projection:** For each voxel center $p = (x, y, z)^T$ in the 3D grid:
    *   Project $p$ into view $i$ to obtain 2D coordinates.
    *   Compute the projected coordinates using the scaled intrinsic matrix $K'$ (which accounts for feature map downsampling) and the extrinsic matrix $R_i$:
        $$
        \begin{pmatrix} u'_i, v'_i, d_i \end{pmatrix}^T = K' \times R_i \times \begin{pmatrix} \mathbf{p}, 1 \end{pmatrix}^T
        $$
    *   Calculate pixel coordinates: $(u_i, v_i) = (u'_i/d_i, v'_i/d_i)$ [S1].

3.  **Feature Assignment:**
    *   Assign 3D features $V_i(p)$ by nearest neighbor interpolation of $F_i$ at location $(u_i, v_i)$:
        $$
        V_i(p) = \text{interpolate}((u_i, v_i), F_i)
        $$
    *   **Edge Case:** If $p$ is projected outside the image boundary or behind the image plane ($d_i \le 0$), discard the feature and set $V_i(p) = 0$ [S1].

4.  **Multi-View Aggregation:**
    *   Let $M_p$ be the number of effective 2D projections (views where $V_i(p) \neq 0$).
    *   Aggregate features by averaging:
        $$
        V_{avg}(p) = \sum_{i=1}^{M_p} \frac{V_i(p)}{M_p}
        $$
    *   *Note:* The method also computes variance features from the multi-view projections, which are shown to improve performance [S1].

5.  **Geometry Modeling (NeRF Branch):**
    *   Connect the detection and NeRF branches through a shared geometry MLP (G-MLP), denoted as $G(p)$ [S1].
    *   The G-MLP takes the voxel position $p$ as input and predicts a density field $\sigma(p)$ [S1].
    *   **Activation:** Use ReLU for the density $\sigma(p)$ [S1].

6.  **Opacity Field Generation:**
    *   Transform the density field $\sigma(p)$ into an opacity field $\alpha(p)$. The source notes state the density is transformed into an opacity field to reduce weights of empty space, but does not provide the explicit $\alpha = 1 - e^{-\sigma \delta}$ formula used in standard NeRF. It implies a direct mapping or normalization [S1].
    *   Multiply the opacity field with the volume features to create geometry-aware volume features:
        $$
        V_{geo}(p) = \alpha(p) \times V_{avg}(p)
        $$
    *   This step reduces the weights of empty space in the volume feature [S1].

7.  **3D Detection:**
    *   Feed the geometry-aware volume features $V_{geo}(p)$ to the detection head for 3D bounding box regression [S1].

8.  **Inference:**
    *   Remove the NeRF branch (G-MLP) to minimize additional overhead. The detection head operates on the pre-computed or on-the-fly geometry-aware features derived from the trained weights [S1].

**Pseudocode:**

```python
import numpy as np

def nerf_det_forward(images, intrinsics_K, extrinsics_R, voxel_grid_centers):
    """
    Forward pass for NeRF-Det.
    
    Args:
        images: List of T RGB images.
        intrinsics_K: 3x3 intrinsic matrix.
        extrinsics_R: List of T 3x4 extrinsic matrices.
        voxel_grid_centers: Array of shape (N_voxels, 3) containing (x, y, z) for each voxel.
        
    Returns:
        detection_boxes: Predicted 3D bounding boxes.
    """
    T = len(images)
    C, H_feat, W_feat = 256, 64, 64 # Example dimensions for F_i
    
    # Step 1: Extract 2D features
    F = []
    for i in range(T):
        # FPN backbone
        F_i = extract_fpn_features(images[i]) 
        F.append(F_i)
        
    # Step 2 & 3: Project voxels and assign features
    # V_avg will store the aggregated features for each voxel
    N_voxels = voxel_grid_centers.shape[0]
    V_avg = np.zeros((N_voxels, C))
    V_var = np.zeros((N_voxels, C)) # Variance features
    counts = np.zeros(N_voxels)
    
    # Scaled intrinsic matrix considering downsampling (factor of 4)
    K_prime = intrinsics_K / 4.0
    
    for i in range(T):
        R_i = extrinsics_R[i]
        F_i = F[i]
        
        # Project all voxel centers to view i
        # p_homogeneous: (N_voxels, 4)
        p_homogeneous = np.hstack([voxel_grid_centers, np.ones((N_voxels, 1))])
        
        # (u'_i, v'_i, d_i)^T = K' * R_i * (p, 1)^T
        projected = K_prime @ (R_i @ p_homogeneous.T)
        u_prime = projected[0, :]
        v_prime = projected[1, :]
        d = projected[2, :]
        
        # Pixel coordinates
        # Handle division by zero or negative depth
        valid_mask = d > 0
        u = np.zeros(N_voxels)
        v = np.zeros(N_voxels)
        u[valid_mask] = u_prime[valid_mask] / d[valid_mask]
        v[valid_mask] = v_prime[valid_mask] / d[valid_mask]
        
        # Nearest neighbor interpolation
        # Clip coordinates to image bounds [0, H_feat-1], [0, W_feat-1]
        u_int = np.clip(u.astype(int), 0, H_feat - 1)
        v_int = np.clip(v.astype(int), 0, W_feat - 1)
        
        # Gather features
        # F_i shape: (C, H_feat, W_feat)
        # We need to index F_i[:, u_int, v_int]
        # Note: In numpy, this requires advanced indexing or loop
        V_i = np.zeros((N_voxels, C))
        for idx in range(N_voxels):
            if valid_mask[idx]:
                V_i[idx] = F_i[:, u_int[idx], v_int[idx]]
            else:
                V_i[idx] = 0 # Discard if out of bounds or behind plane
                
        # Step 4: Aggregate
        # Update counts for effective projections
        counts += (V_i != 0).any(axis=1).astype(float)
        
        # Accumulate for mean
        V_avg += V_i
        
        # Accumulate for variance (simplified: sum of squares)
        V_var += V_i ** 2
        
    # Compute Mean and Variance
    # Avoid division by zero
    safe_counts = np.maximum(counts, 1)
    V_mean = V_avg / safe_counts[:, np.newaxis]
    
    # Variance = E[X^2] - (E[X])^2
    V_mean_sq = V_var / safe_counts[:, np.newaxis]
    V_variance = np.maximum(V_mean_sq - V_mean ** 2, 0)
    
    # Combine Mean and Variance features (concatenate along channel dim)
    # Assuming C channels for mean and C for variance -> 2C total
    V_combined = np.concatenate([V_mean, V_variance], axis=1)
    
    # Step 5 & 6: Geometry Modeling (Shared G-MLP)
    # G-MLP takes voxel position p and outputs density sigma
    # Note: In implementation, this is usually a network forward pass
    # Here we simulate the density prediction
    sigma = predict_density(voxel_grid_centers) # ReLU activation
    
    # Transform density to opacity alpha
    # Standard NeRF: alpha = 1 - exp(-sigma * delta)
    # Source does not specify delta or exact formula, assumes direct mapping or standard conversion
    # [G] Using standard volume rendering opacity formula as the source implies "transforming density into opacity"
    delta = 0.1 # Typical voxel size, not given in source
    alpha = 1.0 - np.exp(-sigma * delta)
    
    # Multiply opacity with volume features
    # V_geo = alpha * V_combined
    # Broadcasting alpha (N_voxels,) to (N_voxels, 2C)
    alpha_expanded = alpha[:, np.newaxis]
    V_geo = alpha_expanded * V_combined
    
    # Step 7: Detection Head
    detection_boxes = detection_head(V_geo)
    
    return detection_boxes
```

**Parameters:**
*   **Density Activation:** ReLU [S1].
*   **Color Activation:** Sigmoid (used in the NeRF branch for color rendering, though not used in detection inference) [S1].
*   **Voxel Grid Size:** $N_x \times N_y \times N_z$ (Not given in the sources).

**Pitfalls:**
*   **Depth Estimation Errors:** Using predicted depth maps from external geometry reconstruction (e.g., NeuralRecon) significantly degrades detection performance by 2.3 mAP@.50 compared to plain ImVoxelNet, as depth estimation errors propagate inaccuracy through the detection pipeline [S1].
*   **NeRF Quality Degradation:** The detection branch negatively impacts the NeRF branch's novel view synthesis quality because it is prone to erasing low-level details required for NeRF rendering. Disabling the detection branch brings a 0.43dB improvement in PSNR [S1].
*   **Boundary Conditions:** Voxels projected outside the image boundary or behind the image plane must be handled by setting their features to 0 to avoid invalid interpolation [S1].

## Subtopics

### Shared G-MLP
A shared geometry MLP that enables the constraint of multi-view consistency to be propagated from the NeRF branch to the detection branch [S1]. Without the shared G-MLP, performance drops from 50.1 to 48.1 mAP@.25, as the influence of multi-view consistency is only propagated into the image backbone [S1].

## Operating characteristics
*   **Time Complexity:** The method is significantly faster than "NeRF-then-Det" methods. NeRF-Det has a latency of 0.554s on one V100, compared to NeRF-RPN's ~846.8s latency [S1]. This is because NeRF-Det avoids per-scene optimization by using generalizable priors [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:**
    *   Improves state-of-the-art by 3.9 mAP on ScanNet and 3.1 mAP on ARKITScenes benchmarks [S1].
    *   On ScanNet, NeRF-Det-R50 achieves 35.13 AP50 with a latency of 0.554s on one V100 [S1].
    *   Achieves an average PSNR of 20+ for novel view synthesis and an RMSE of 0.756 for depth estimation on 312 scenes in the validation set, without per-scene training [S1].
*   **Strengths:** Joint training allows geometry-aware volumetric representations; generalizable to unseen scenes without per-scene optimization; significantly faster than iterative NeRF optimization methods [S1].
*   **Limitations:** The detection branch can degrade the NeRF branch's rendering quality (PSNR) by erasing low-level details [S1].
*   **When to use:** Indoor 3D object detection with posed RGB images where generalization to new scenes is required without per-scene tuning [S1].
*   **When not to use:** When high-fidelity novel view synthesis is the primary goal, as the detection branch may reduce rendering quality [S1].

## Background
NeRF-Det was introduced by Chenfeng et al. from Meta (Facebook Research) in 2023 [S1]. It addresses the limitations of existing indoor 3D detection methods that struggle to model scene geometry and the high latency of per-scene NeRF optimization [S1]. The method builds on the ImVoxelNet architecture and integrates principles from NeRF [S1].
