# Voxel-based Radiance Fields

Also called: Voxel NeRF, Voxel Radiance Fields

## Overview
Voxel-based Radiance Fields replace the multi-layer perceptron (MLP) of standard Neural Radiance Fields with discrete 3D voxel grids to store volume density and spherical harmonic (SH) coefficients, enabling real-time differentiable volume rendering [S1]. Unlike MLP-based approaches that require heavy feed-forward computation for every sample point, this method retrieves features via trilinear interpolation, significantly reducing latency while maintaining the memory-efficient framework of sparse voxel representations [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of input images with known camera poses; a 3D spatial domain defined by the voxel grid resolution.
*   **Outputs:** A rendered image $\hat{C}(r)$ for a given ray $r$, computed via differentiable volume rendering.

**Data Structures:**
The representation consists of two distinct voxel grids, both mapping 3D coordinates to feature vectors:
1.  **Density Grid ($G_\sigma$):** A 3D tensor $G_\sigma: \mathbb{R}^3 \rightarrow \mathbb{R}$ storing the volume density $\sigma$.
2.  **SH Coefficient Grid ($G_{sh}$):** A 3D tensor $G_{sh}: \mathbb{R}^3 \rightarrow \mathbb{R}^{9 \times 3}$ storing the coefficients for degree 2 spherical harmonics for RGB color. The dimension $9 \times 3$ corresponds to 9 SH basis functions for each of the 3 color channels (R, G, B) [S1].

**Rendering Pipeline:**
For a ray $r$, sample points $\mathbf{X}_k$ and viewing directions $\mathbf{d}$ are generated. The volume density $\sigma_k$ and color $\mathbf{c}_k$ at each sample point are retrieved as follows:

1.  **Density Retrieval:** The volume density $\sigma_k$ is obtained by trilinear interpolation from the nearest 8 voxels of the density grid $G_\sigma$ at location $\mathbf{X}_k$ [S1]:
    $$
    \sigma_k = \mathcal{G}_\sigma(\mathbf{X}_k)
    $$
    where $\mathcal{G}_\sigma$ denotes the trilinear interpolation operator [S1].

2.  **Color Retrieval:** The view-dependent color $\mathbf{c}_k$ is computed by combining the interpolated SH coefficients with the viewing direction $\mathbf{d}$ [S1]:
    $$
    \mathbf{c}_k = S(\mathbf{d})^\intercal \cdot \mathcal{G}_{sh}(\mathbf{X}_k)
    $$
    where:
    *   $S(\mathbf{d}): \mathbb{R}^3 \rightarrow \mathbb{R}^9$ is the spherical harmonic function mapping the viewing direction to a 9-dimensional vector [S1].
    *   $\mathcal{G}_{sh}(\mathbf{X}_k)$ is the trilinear interpolation from the nearest 8 voxels of the SH grid $G_{sh}$ at location $\mathbf{X}_k$, yielding a vector of size $9 \times 3$ [S1].
    *   The dot product $S(\mathbf{d})^\intercal \cdot \mathcal{G}_{sh}(\mathbf{X}_k)$ effectively projects the SH coefficients onto the direction basis to produce the RGB color vector [S1].

3.  **Volume Rendering:** The final pixel color is computed using the standard differentiable volume rendering equation (as defined in the parent article [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md)):
    $$
    \hat{C}(r) = \sum_{k=1}^{N} w_k \mathbf{c}_k, \quad w_k = T_k \alpha_k, \quad T_k = \prod_{j=1}^{k-1} (1 - \alpha_j)
    $$
    where opacity $\alpha_k = 1 - e^{-\sigma_k \delta_k}$ [S1].

**Pseudocode:**
```python
def render_voxel_nerf(ray_origin, ray_direction, voxel_grid_sigma, voxel_grid_sh, num_samples):
    """
    Renders a single ray using voxel-based radiance fields.
    
    Args:
        ray_origin: 3D vector (x, y, z)
        ray_direction: 3D vector (x, y, z), normalized
        voxel_grid_sigma: 3D tensor storing density values
        voxel_grid_sh: 3D tensor storing SH coefficients (9 * 3 channels)
        num_samples: Number of sample points along the ray
        
    Returns:
        color: 3D vector (R, G, B)
    """
    # Generate sample points along the ray
    # Assume t values are generated based on near/far bounds and num_samples
    # X_k = ray_origin + t_k * ray_direction
    # d = ray_direction (constant for the ray)
    
    # Precompute SH basis for the viewing direction
    # S(d) maps direction to 9-dimensional SH basis vector
    sh_basis = compute_sh_basis(ray_direction) # Returns vector of size 9
    
    accumulated_transmittance = 1.0
    accumulated_color = [0.0, 0.0, 0.0]
    
    for k in range(num_samples):
        # 1. Retrieve density via trilinear interpolation
        # G_sigma is the density grid
        sigma = trilinear_interpolate(voxel_grid_sigma, X_k)
        
        # 2. Retrieve SH coefficients via trilinear interpolation
        # G_sh is the SH coefficient grid
        sh_coeffs = trilinear_interpolate(voxel_grid_sh, X_k) # Returns vector of size 9 * 3
        
        # 3. Compute color
        # Reshape sh_coeffs to (9, 3) to match SH basis dimensions
        # color = sh_basis^T @ sh_coeffs
        color = dot_product(sh_basis, sh_coeffs) # Result is 3D vector (R, G, B)
        
        # 4. Compute opacity and weight
        # delta_k is the distance between sample k and k+1
        alpha = 1.0 - exp(-sigma * delta_k)
        weight = accumulated_transmittance * alpha
        
        # 5. Accumulate color
        accumulated_color += weight * color
        
        # 6. Update transmittance
        accumulated_transmittance *= (1.0 - alpha)
        
        # Early termination if transmittance is negligible (optional optimization)
        if accumulated_transmittance < 1e-5:
            break
            
    return accumulated_color
```

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** Trilinear interpolation requires valid coordinates within the voxel grid bounds. Points outside the grid must be handled, typically by clamping or returning zero density/opacity [S1].
*   **Precision:** The SH grid stores coefficients for 9 basis functions across 3 channels. Ensuring the dot product is performed correctly with the 9-dimensional SH basis vector is critical for accurate view-dependent coloring [S1].

## Operating characteristics
*   **Time Complexity:** Rendering is significantly faster than MLP-based NeRF because it eliminates the heavy computation of fully-connected layers for every sample point, replacing it with direct memory access and interpolation [S1]. This enables real-time volume rendering.
*   **Memory Complexity:** The memory footprint is determined by the resolution of the voxel grids $G_\sigma$ and $G_{sh}$. The method is described as a "memory-efficient framework" that limits learnable parameters to the values on the voxel grid [S1].
*   **Strengths:** Real-time rendering capability; memory efficiency compared to dense MLPs; compatibility with coarse-to-fine sparse voxel reconstruction and pruning strategies for efficient training [S1].
*   **Limitations:** Resolution is limited by the voxel grid size; high-frequency details may be lost if the grid resolution is insufficient; view-dependent effects are limited to the degree of spherical harmonics used (degree 2 in the cited source) [S1].
*   **When to use:** When real-time rendering is required and the scene can be adequately represented with discrete voxel grids and low-order spherical harmonics [S1].
*   **When not to use:** When high-frequency view-dependent effects beyond degree 2 SH are required, or when the scene geometry is too complex for the chosen voxel resolution [S1].

## Background
Voxel-based Radiance Fields were introduced as a memory-efficient alternative to the original Neural Radiance Fields (NeRF) [S1]. The approach leverages the differentiable volume rendering framework of NeRF but substitutes the implicit function $f_\theta(\mathbf{x}, \mathbf{d})$ with explicit voxel grids for density and spherical harmonic coefficients [S1]. This modification allows for real-time rendering by eliminating the feed-forward neural network operations [S1]. The method has been applied to tasks such as extreme motion blur reconstruction, demonstrating its efficiency in optimization scenarios [S1].
