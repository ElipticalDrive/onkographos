# NeRF-SR Training Configuration

Also called: NeRF-SR Training, NeRF-SR Hyperparameters

## Overview
NeRF-SR is a training configuration designed to synthesize high-resolution novel views from low-resolution input images by optimizing the neural radiance field at multiple scales [S1]. It distinguishes itself from standard NeRF training by employing a hierarchical supersampling strategy that leverages 3D consistency to recover high-frequency details, rather than relying on post-processing upsampling [S1]. It builds on [Method-Specific Training Configurations](6267-method-specific-training-configurations.md) by adding specific multi-scale rendering loops and, for real-world data, a patch-based refinement stage [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Low-resolution training images (e.g., 504×378), camera intrinsics and extrinsics, and estimated depth maps for the training poses [S1].
*   **Outputs:** A trained neural radiance field (MLP) capable of rendering high-resolution images (e.g., 1008×756 or higher) and, optionally, a refined high-resolution image using reference patches [S1].

**Data Structures:**
*   **NeRF MLP:** Follows the standard NeRF architecture with identical "coarse" and "fine" MLP sizes [S1].
*   **Training Data:** 100 views for training, 200 held out for testing (Blender dataset) or all images for LLFF dataset [S1].

**Numbered Steps:**
1.  **Multi-Scale Training Setup:** The model is trained independently for different image resolutions (e.g., scale factors ×2 and ×4) [S1].
2.  **Hierarchical Sampling:** For each batch, generate rays from training images. Sample points along rays using hierarchical sampling:
    *   **Coarse Stage:** Sample 64 points uniformly or stratified along the ray [S1].
    *   **Fine Stage:** Sample 64 points using importance sampling based on the density predicted by the coarse network [S1].
3.  **Volume Rendering:** Compute the rendered color $\hat{C}(\mathbf{r})$ for each ray using the differentiable volume rendering integral:
    $$ \hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i $$
    where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$, and $\delta_i$ is the distance between samples [S1].
4.  **Loss Computation:** Calculate the photometric loss (MSE) between the rendered high-resolution pixel colors and the ground truth high-resolution images [S1].
5.  **Optimization:** Update network parameters using the Adam optimizer [S1].
6.  **Refinement (Optional/Real-World Only):** For real-world datasets (LLFF), apply a refinement network to boost texture details and edge sharpness [S1].
    *   Divide the input image into non-overlapping patches of size $64 \times 64$ [S1].
    *   For each patch, extract $K=8$ reference patches from a reference image using estimated depth and camera parameters to compute 3D world coordinates and backproject to the reference view [S1].
    *   Input the target patch and reference patches into the refinement network [S1].
    *   Stitch the refined patches together to form the final image [S1].

**Parameters:**
*   **Optimizer:** Adam with $\beta_1 = 0.9$, $\beta_2 = 0.999$ [S1].
*   **Batch Size:** 2048 rays per batch [S1].
*   **Learning Rate:** Exponentially decayed from $5 \cdot 10^{-4}$ to $5 \cdot 10^{-6}$ [S1].
*   **Coarse Samples:** 64 [S1].
*   **Fine Samples:** 64 [S1].
*   **Epochs:** 20 epochs for Blender dataset; 30 epochs for LLFF dataset [S1].
*   **Refinement Reference Patches ($K$):** 8 [S1].
*   **Patch Dimensions:** $64 \times 64$ [S1].

**Edge Cases and Pitfalls:**
*   **Arbitrary Scale Limitation:** NeRF-SR does not support arbitrary-scale super-resolution; it must be trained independently for specific scale factors (e.g., ×2, ×4) [S1].
*   **Real-World Complexity:** Supersampling alone is insufficient for complex real-world scenes (LLFF); refinement is necessary for scale ×4, while scale ×2 shows only minor PSNR improvement but better LPIPS [S1].
*   **Inference Time:** Refinement adds negligible time (~1.3s) compared to volumetric rendering (~48s for 1008×756 on 1080Ti) [S1].

## Subtopics

### Refinement Network (Ours-Refine)
A post-processing network that boosts NeRF-SR outputs with texture details and edge sharpness, specifically for real-world LLFF dataset where supersampling alone is insufficient [S1]. It uses $K=8$ reference patches of size $64 \times 64$ [S1]. During inference, input images are divided into non-overlapping patches and stitched together after refinement [S1]. It is necessary for scale ×4 (PSNR 25.59, SSIM 0.759, LPIPS 0.165) but provides only subtle LPIPS improvement for scale ×2 (PSNR 27.34, SSIM 0.842, LPIPS 0.103) [S1].

## Operating characteristics
*   **Time Complexity:** Training time scales with the number of epochs and resolution. Inference time for volumetric rendering is dominant (~48s for 1008×756 on 1080Ti); refinement adds ~1.3s [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:**
    *   **Blender Dataset (×2):** PSNR 26.81, SSIM 0.823, LPIPS 0.145 (Ours-SS) [S1].
    *   **Blender Dataset (×4):** PSNR 25.13, SSIM 0.730, LPIPS 0.244 (Ours-SS) [S1].
    *   **LLFF Dataset (×2):** PSNR 27.34, SSIM 0.842, LPIPS 0.103 (Ours-Refine) [S1].
    *   **LLFF Dataset (×4):** PSNR 25.59, SSIM 0.759, LPIPS 0.165 (Ours-Refine) [S1].
*   **Strengths:** Achieves photorealistic renderings from low-resolution inputs without external data; leverages 3D consistency [S1].
*   **Limitations:** Does not support arbitrary-scale super-resolution; introduces extra computation efficiency compared to vanilla NeRF, though less than training a full HR NeRF [S1].
*   **When to Use:** When high-quality novel view synthesis is required from low-resolution inputs and specific scale factors (×2, ×4) are acceptable [S1].
*   **When Not to Use:** When arbitrary-scale super-resolution is needed or when computational resources are extremely limited for training [S1].

## Background
NeRF-SR was introduced by Wang et al. in the paper "NeRF-SR: High-Quality Neural Radiance Fields using Supersampling" [S1]. It is the first pipeline to achieve high-resolution novel view synthesis from mostly low-resolution inputs without external data [S1]. The method exploits 3D consistency through a supersampling strategy and, for real-world data, a refinement network [S1].
