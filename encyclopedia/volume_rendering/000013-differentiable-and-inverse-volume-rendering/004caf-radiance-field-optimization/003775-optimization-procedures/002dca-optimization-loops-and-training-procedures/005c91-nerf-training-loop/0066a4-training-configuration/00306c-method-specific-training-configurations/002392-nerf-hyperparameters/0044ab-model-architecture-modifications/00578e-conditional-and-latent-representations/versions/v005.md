# Conditional and Latent Representations

Also called: Conditional Radiance Fields, Latent NeRFs

## Overview
Conditional and Latent Representations extend the standard NeRF architecture to model an entire object class (e.g., chairs) rather than a single scene, using instance-specific latent vectors for shape and appearance to enable editing and generalization [S1]. It differs from sibling methods by explicitly disentangling shape and appearance into separate latent vectors and optimizing them jointly with network parameters to allow independent manipulation of geometry and texture [S1, 2].

## Shared principles
The standard NeRF architecture [Parent](3065-nerf-hyperparameters.md) serves as the baseline for most modifications. It consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ [14428-sparse-view-and-few-shot-optimization.md].

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories [14428-sparse-view-and-few-shot-optimization.md]:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation [14428-sparse-view-and-few-shot-optimization.md].
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs).

## Subtopics

### [Conditional Radiance Field Training](15963-conditional-radiance-field-training.md)
Conditional Radiance Field Training extends the standard NeRF architecture to model a dataset of multiple 3D instances by learning instance-specific latent codes for shape and appearance. It solves the problem of generalizing across variations in geometry and texture without requiring separate models per instance, achieving reconstruction quality comparable to independent single-instance NeRFs while sharing network weights. It differs from sibling methods by explicitly disentangling shape and appearance into separate latent vectors and optimizing them jointly with the network parameters. See [Conditional Radiance Field Training](15963-conditional-radiance-field-training.md).

### [Conditional Radiance Field with Shared Branch](15964-conditional-radiance-field-with-shared-branch.md)
The Conditional Radiance Field with Shared Branch is a neural radiance field architecture designed for shape and color disentanglement, enabling efficient editing by allowing specific submodules to be finetuned. It maps a 3D location $\mathbf{x}$, viewing direction $\mathbf{d}$, and instance-specific shape code $\mathbf{z}^{(s)}$ and color code $\mathbf{z}^{(c)}$ to radiance $\mathbf{c}$ and scalar density $\sigma$. Unlike standard NeRF or basic conditional variants, this method introduces a shared shape network that learns a category-specific geometric representation, improving view synthesis quality and scalability to multiple instances. See [Conditional Radiance Field with Shared Branch](15964-conditional-radiance-field-with-shared-branch.md).

### [Conditional NeRF Implementation Details](16755-conditional-nerf-implementation-details.md)
Conditional NeRF is a generative model for a specific object category that maps spatial position $\mathbf{x}$, viewing direction $\mathbf{v}$, and instance-specific latent codes to volumetric density $\sigma$ and radiance $\mathbf{c}$. It differs from standard NeRF by optimizing learnable shape and appearance latent codes per instance, and from its siblings by explicitly disentangling these controls to prevent mutual interference during manipulation. See [Conditional NeRF Implementation Details](16755-conditional-nerf-implementation-details.md).

### Conditional Radiance Field
#### definition
- [S1] A neural network representation that extends NeRF to model an entire object class (e.g., chairs) rather than a single scene, using latent vectors for shape and appearance to allow editing.
- [S1] The network $F$ takes a 3D location $\mathbf{x}$, viewing direction $\mathbf{d}$, and instance-specific latent vectors $\mathbf{z}^{(s)}$ and $\mathbf{z}^{(c)}$ to output radiance $\mathbf{c}$ and density $\sigma$.
- [S1] The density output $\sigma$ is independent of the viewing direction.
- [S1] The radiance output $\mathbf{c}$ depends on both position and viewing direction.
#### step
- [S1] Sample $N_c$ 3D points $\{t_i\}_{i=1}^{N_c}$ along a cast ray $r$ from pixel location, ordered near to far.
- [S1] Compute radiance $c_i$ and density $\sigma_i$ at each sampled point $t_i$ using network $F$.
#### formula
- [S1] Alpha compositing value: $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, where $\delta_i = t_{i+1} - t_i$ is the distance between adjacent samples.
#### parameter
- [S1] $\mathbf{x}$: 3D location vector $(x, y, z)$.
- [S1] $\mathbf{d}$: viewing direction vector $(\phi, \theta)$.
- [S1] $\mathbf{z}^{(c)}$: latent color (appearance) vector.
#### layout
- [S1] Network $F$ is parametrized as a multi-layer perceptron (MLP).

### Continuous Manipulation via Latent Space Scaling
#### definition
- [S2] A technique to achieve gradual editing of shape and appearance by scaling the editing direction vectors in the latent space using a scalar factor.
#### formula
- [S2] $\mathbf{z}_s = s \times \Delta \mathbf{z}_s + \mathbf{z}_{s0}$, $\mathbf{z}_a = s \times \Delta \mathbf{z}_a + \mathbf{z}_{a0}$, where $s$ is a scalar, $\mathbf{z}_s$ and $\mathbf{z}_a$ are the updated shape and appearance codes, $\mathbf{z}_{s0}$ and $\mathbf{z}_{a0}$ are the original codes, and $\Delta \mathbf{z}_s$ and $\Delta \mathbf{z}_a$ are the manipulation directions provided by the code mappers.
#### parameter
- [S2] Scalar $s$: Controls the intensity of the edit. Typical range: 0 to 1.6 with step 0.2. Effect: Manipulation strength increases as $s$ increases.
#### usage
- [S2] Used for continuous editing of both shape and appearance given a single text prompt or exemplar, allowing users to adjust the degree of change.

### CLIP-Driven Manipulation
#### step
- [S2] 1. Extract CLIP feature embedding from input text prompt or exemplar image. 2. Feed embedding into two separate feed-forward code mappers (shape mapper and appearance mapper). 3. Mappers output local displacements in the latent space to update $\mathbf{z}_s$ and $\mathbf{z}_a$. 4. Render image with updated codes. 5. Train mappers using a CLIP-based matching loss to enforce CLIP space consistency between input constraint and output renderings.
#### comparison
- [S2] Differs from optimization-based editing (e.g., EditNeRF) by using learned feed-forward networks mapping user edits to latent codes, enabling fast inference for interactive editing instead of slow iterative optimization per sample.

## Background
Conditional Radiance Fields were introduced by Chan et al. in "Editing Conditional Radiance Fields" (ICCV 2021) [S1]. The work aimed to enable editing over an entire shape class (e.g., "chairs") by learning a conditional radiance field model that extends the NeRF representation with latent vectors over shape and appearance. The representation is trained over a set of shapes belonging to a class, and each shape instance is represented by latent shape and appearance vectors. The disentanglement of shape and appearance allows certain parts of the network to be modified during editing [S1].

CLIP-NeRF, introduced by Wang et al. in "CLIP-NeRF: Text-and-Image Driven Manipulation of Neural Radiance Fields" (CVPR 2022) [S2], built upon this foundation by integrating the CLIP model to learn code mappers. These mappers map CLIP features to the latent space to manipulate shape or appearance codes based on text prompts or exemplar images. This approach supports high-resolution NeRF manipulation and fast inference for interactive editing, differing from optimization-based methods like EditNeRF by using feed-forward networks [S2].
