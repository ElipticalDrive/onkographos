# Neural Proxy

Also called: Neural Proxy Model

## Overview
Neural Proxy is a neural rendering method that represents photo-realistic targets as animatable proxies, enabling the synthesis of unseen animations without temporal learning [S1, unofficial]. It combines neural volume rendering with neural texture by injecting an animatable mesh proxy into the scene, mimicking the traditional CG pipeline of using a 3D mesh for geometry and a texture for appearance [S1, unofficial]. Unlike NeRF, which ties content to continuous Cartesian coordinates making animation difficult, Neural Proxy allows particles to move with the animated proxy geometry [S1, unofficial]. Unlike Neural Texture, which requires animated training samples to render unseen animations, Neural Proxy renders unseen animations by animating the proxy geometry itself [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Reference geometry (mesh $\bar{M}$), UV coordinates for the mesh, offset parameters for shell extrusion ($\epsilon_{\rightarrow}, \epsilon_{\leftarrow}$), and a neural texture $\Omega_{Tex}$.
*   **Outputs:** Rendered image $I$ for a given camera view.

**Data Structures:**
1.  **Coarse Geometry $\bar{M}$:** A mesh defined by vertices $\mathbf{v}_i$ and smoothed normals $\mathbf{n}_i$ for $i=1 \dots N_v$.
2.  **Proxy Shell:** A volume enclosing the target, constructed by extruding $\bar{M}$ along normals. It consists of an outward surface $\overrightarrow{M}$ and an inward surface $\overleftarrow{M}$.
    *   Outward vertices: $\overrightarrow{\mathbf{v}}_i = \mathbf{v}_i + \mathbf{n}_i \cdot \epsilon_{\rightarrow}$
    *   Inward vertices: $\overleftarrow{\mathbf{v}}_i = \mathbf{v}_i - \mathbf{n}_i \cdot \epsilon_{\leftarrow}$
    *   Conditions: $\epsilon_{\rightarrow}, \epsilon_{\leftarrow} \ge 0$ and $\epsilon_{\rightarrow} + \epsilon_{\leftarrow} > 0$.
3.  **Lifted UV Coordinates:** 3D UV coordinates $\mathbf{u}_i$ for each vertex in the shell.
    *   $\mathbf{u}_i = (u_{2D}, w)$, where $u_{2D}$ is the 2D UV coordinate of the original vertex.
    *   $w$ is the proxy depth component. For the outward shell, $w=1$; for the inward shell, $w=0$ (or similar label) [S1, unofficial].
4.  **Neural Texture $\Omega_{Tex}$:** A learnable feature map (tensor) indexed by the lifted UV coordinates.
5.  **Tetrahedral Decomposition:** Prisms formed by extruding triangles are broken into three tetrahedra to enable Barycentric coordinate sampling [S1, unofficial].

**Steps:**
1.  **Proxy Construction:** Retrieve reference geometry $\bar{M}$ (e.g., via COLMAP or manual low-res mesh) [S1, unofficial].
2.  **Shell Extrusion:** Compute outward and inward surfaces $\overrightarrow{M}$ and $\overleftarrow{M}$ using the offset parameters [S1, unofficial].
3.  **UV Lifting:** Assign lifted UV coordinates $\mathbf{u}_i$ to all vertices in $\overrightarrow{M}$ and $\overleftarrow{M}$ [S1, unofficial].
4.  **Tetrahedralization:** Decompose the prisms of the shell into tetrahedra using the method from [PBFJ05] to support Barycentric interpolation [S1, unofficial].
5.  **Neural Texture Wrapping:** Wrap the proxy with the neural texture $\Omega_{Tex}$. The texture is indexed by the lifted UV coordinates [S1, unofficial].
6.  **Rendering (Particle Sampling):**
    *   For a ray $r$, determine intersection with the proxy shell.
    *   Convert the 3D Cartesian intersection point $\mathbf{x}$ to Barycentric coordinates within the specific tetrahedron of the shell [S1, unofficial].
    *   Use the Barycentric coordinates to interpolate the lifted UV coordinates $\mathbf{u}$ of the tetrahedron's vertices.
    *   Sample the neural texture $\Omega_{Tex}$ at the interpolated $\mathbf{u}$ using a bilinear sampler $f_{Bi}$ to get local features [S1, unofficial].
    *   Feed the sampled features into a neural renderer $f_{NR}$ (parameters $\theta_{NR}$) to produce color $\mathbf{c}$ and density $\sigma$ [S1, unofficial].
    *   The rendering equation approximates the color $\hat{C}(r)$:
        $$ \hat{C}(r) \approx \sum_{i=1}^{N_s} T_i \alpha_i \mathbf{c}_i $$
        where $(\mathbf{c}_i, \sigma_i) = S_p(\mathbf{x}_i)$, $\Delta t_i = t_{i+1} - t_i$, and $N_s$ is the number of sampled particles [S1, unofficial].
    *   For scenes with static surroundings, mix the neural proxy sampler with a static Cartesian sampler [S1, unofficial].

**Pseudocode:**
```python
def render_neural_proxy(ray, proxy_shell, neural_texture, renderer):
    # 1. Intersect ray with proxy shell to get 3D point x
    x = intersect_ray_shell(ray, proxy_shell)
    if x is None:
        return static_background(ray)

    # 2. Find the tetrahedron containing x in the shell
    tet = find_tetrahedron(x, proxy_shell.tetrahedra)

    # 3. Compute Barycentric coordinates of x within the tetrahedron
    bary = compute_barycentric(x, tet.vertices)

    # 4. Interpolate lifted UV coordinates using Barycentric weights
    # tet.uv_coords is a list of 4 lifted UV vectors (u2D, w)
    u_lifted = interpolate_uv(bary, tet.uv_coords)

    # 5. Sample neural texture at the interpolated UV
    # u_lifted[0:2] is the 2D UV, u_lifted[2] is the depth label w
    features = bilinear_sample(neural_texture, u_lifted[0:2], u_lifted[2])

    # 6. Render color and density from features
    c, sigma = renderer(features)

    # 7. Composite with transmittance (standard volume rendering step)
    # T_i and alpha_i are computed based on sigma and step size
    return composite(c, sigma, ray, proxy_shell)
```

## Operating characteristics
*   **Animation Capability:** Enables rendering of unseen animations without temporal learning by animating the proxy geometry [S1, unofficial].
*   **Comparison to NeRF:** Avoids the difficulty of manipulating content tied to continuous Cartesian coordinates [S1, unofficial].
*   **Comparison to Neural Texture:** Does not require animated training samples; generalizes to unseen animations by leveraging the animatable mesh structure [S1, unofficial].
*   **Complexity:** Relies on classical CG techniques (shell maps, Barycentric sampling) combined with neural texture lookup, potentially offering more efficient animation support than full volumetric re-optimization [S1, unofficial].

## Background
Neural Proxy was proposed to address the lack of discussion on enabling neural rendering for synthesizing frames for unseen animations [S1, unofficial]. It builds upon Neural Volume Rendering [LSS* 19] and Neural Radiance Fields (NeRF) [MST* 20], while incorporating concepts from Neural Texture [TZN 19]. The method utilizes shell maps [PBFJ05] for volume construction and Barycentric coordinate systems for sampling [S1, unofficial].
