# Dynamic Appearance Particle Neural Radiance Field

Also called: DAP-NeRF, Dynamic Appearance Particle NeRF, Lagrangian dynamic model in NeRF

## Overview
Dynamic Appearance Particle Neural Radiance Field (DAP-NeRF) is a method for modeling dynamic scenes from monocular video data by combining a static grid-based radiance field with a particle-based dynamic component [S1]. It solves the problem of reconstructing time-varying scenes without requiring multi-view stereo data or prior geometric knowledge of dynamic objects [S1]. Unlike ParticleNeRF, which encodes the entire scene with particles and requires multiple camera views per frame, DAP-NeRF applies appearance particles only to dynamic elements and uses a grid-based field for efficient querying via linear interpolation [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Monocular video data (a sequence of images from a single camera at different time steps $t$). Camera parameters (intrinsics and extrinsics) for each frame.
*   **Outputs:** Rendered pixel colors $C(\mathbf{r}, t)$ for any ray $\mathbf{r}$ and time $t$.

**Data Structures:**
1.  **Static Field ($V_s$):** A time-independent grid-based model (e.g., feature grid) storing static scene information [S1].
2.  **Dynamic Field ($V_{td}$):** An ensemble of particles representing dynamic elements. Each particle has a position and appearance features. The field is defined as a convolution with a kernel [S1].
3.  **Weight Field ($w_t$):** A binary or soft mask indicating where the dynamic field is effective at location $\mathbf{x}$ and time $t$ [S1].

**Formulas:**
The total radiance field $V(\mathbf{x}, t)$ is a superposition of static and dynamic components [S1]:
$$
V(\mathbf{x}, t) = (1 - w_t(\mathbf{x}))V_s(\mathbf{x}) + w_t(\mathbf{x})V_{td}(\mathbf{x})
$$
where:
*   $V_s(\mathbf{x})$ is the static field component.
*   $V_{td}(\mathbf{x})$ is the dynamic field component.
*   $w_t(\mathbf{x})$ is a weight taking value 1 if the dynamic field is effective at $(\mathbf{x}, t)$ and 0 otherwise [S1].

The dynamic field $V_{td}$ is formulated as a convolution with a Dirac function to integrate over finite volumes [S1]:
$$
V_{td}(\mathbf{x}) = (V_{td} * \delta)(\mathbf{x}) = \int V_{td}(\mathbf{x}')\delta(\mathbf{x} - \mathbf{x}')d\nu(\mathbf{x}')
$$
where $\delta(\cdot)$ is the Dirac function [S1].

To quantize the field for implementation, the Dirac function $\delta$ is replaced with a kernel $W$ with finite support [S1]:
$$
W(\mathbf{x}) = 0 \text{ when } \|\mathbf{x}\| \text{ exceeds a small radius, and } \int W(\mathbf{x})d\nu(\mathbf{x}) = 1
$$

**Rendering:**
The pixel color $C(\mathbf{r}, t)$ at time $t$ is computed by casting a ray $\mathbf{r}(s) = \mathbf{o} + s\mathbf{d}$ from camera center $\mathbf{o}$ to the pixel, integrating along the ray from near bound $s_n$ to far bound $s_f$ [S1]:
$$
C(\mathbf{r}, t) = \int_{s_n}^{s_f} T(s)\sigma(\mathbf{r}(s), t)c(\mathbf{r}(s), \mathbf{d}, t)ds
$$
where:
*   $T(s) = \exp\left(-\int_{s_n}^{s} \sigma(\mathbf{r}(s'), t)ds'\right)$ is the accumulated transmittance.
*   $\sigma(\cdot)$ is the volume density.
*   $c(\cdot)$ is the emitted radiance.

**Algorithm Steps:**
1.  **Initialize:** Set up a static grid-based field $V_s(\mathbf{x})$ and a set of particles for the dynamic field $V_{td}$. Initialize particle positions and features.
2.  **For each time step $t$ in the video:**
    a. **Update Particle Motion:** Use a particle motion network to update particle positions and features based on previous states and input image features [S1].
    b. **Construct Dynamic Field:** For each particle, compute its contribution to the field using the kernel $W$. Combine contributions to form $V_{td}(\mathbf{x})$ [S1].
    c. **Determine Weight Mask:** Compute $w_t(\mathbf{x})$ to identify regions where dynamic particles are present and effective [S1].
    d. **Combine Fields:** Compute the total field $V(\mathbf{x}, t)$ using the superposition formula [S1].
    e. **Render:** For each pixel in the current frame:
        i. Cast ray $\mathbf{r}$.
        ii. Sample points along the ray.
        iii. Query density $\sigma$ and color $c$ from $V(\mathbf{x}, t)$ at each sample point.
        iv. Perform volume rendering to compute pixel color $C(\mathbf{r}, t)$ [S1].
    f. **Optimize:** Compare rendered images with ground truth images. Update network parameters (static grid, particle motion network, particle features) using gradient descent [S1].

**Parameters:**
*   **Kernel Radius:** The small radius for the kernel $W$ [S1]. Not given in the sources.
*   **Grid Resolution:** Resolution of the static grid $V_s$ [S1]. Not given in the sources.
*   **Number of Particles:** Number of particles in $V_{td}$ [S1]. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Particle Occlusion:** If particles are occluded, their contribution should not affect the rendered color. The weight mask $w_t(\mathbf{x})$ helps manage this [S1].
*   **Precision:** The kernel approximation requires careful handling of the finite support to avoid artifacts [S1].
*   **Boundary Conditions:** The static field $V_s$ must handle regions where no dynamic particles are present correctly [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the number of particles, grid resolution, and ray sampling. Linear interpolation in the grid is efficient [S1].
*   **Memory Complexity:** Proportional to the size of the static grid and the number of particles [S1].
*   **Performance:** Designed for monocular video, reducing data collection costs compared to multi-view methods [S1].
*   **Strengths:** Handles dynamic scenes without prior geometry; efficient querying via grid interpolation; works with monocular data [S1].
*   **Limitations:** Performance may degrade with highly complex dynamics or large numbers of particles [S1].
*   **When to Use:** Monocular video reconstruction of dynamic scenes [S1].
*   **When Not to Use:** Multi-view static scenes (standard NeRF is better) or scenes requiring high-fidelity multi-view consistency without temporal dynamics [S1].

## Background
DAP-NeRF was introduced in a paper published in IEEE Transactions on Circuits and Systems for Video Technology in 2025 [S1]. It builds on the concept of particle-based representations in NeRF, such as ParticleNeRF, but adapts them for dynamic scene modeling from monocular video [S1]. The method integrates a Lagrangian dynamic model into the radiance field framework [S1]. It is not tightly coupled to a specific architecture and can be integrated into frameworks like InstantNGP [S1].
