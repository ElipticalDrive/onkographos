# Mip-NeRF 360 MLP Architecture

Also called: Integrated Positional Encoding MLP, PosEnc MLP

## Overview
The Mip-NeRF 360 MLP architecture is a neural radiance field model that replaces standard positional encoding with **integrated positional encoding** to analytically integrate the radiance field over cone-shaped volumes, reducing aliasing artifacts in novel view synthesis [S1, unofficial]. It distinguishes itself from standard NeRF by explicitly modeling the spatial extent of rays as cones rather than lines, allowing the MLP to output density and color expectations for integrated volumes [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   $\mathbf{x} \in \mathbb{R}^3$: 3D point coordinates.
*   $\mathbf{d} \in \mathbb{R}^3$: View direction vector (or reflection direction $\mathbf{r}$ if reflections are enabled).
*   $\boldsymbol{\mu} \in \mathbb{R}^3$: Mean of the Gaussian distribution approximating the cone at $\mathbf{x}$.
*   $\boldsymbol{\Sigma} \in \mathbb{R}^{3 \times 3}$: Covariance matrix of the Gaussian distribution approximating the cone at $\mathbf{x}$.

**Outputs:**
*   $\sigma$: Volume density (scalar).
*   $\mathbf{c} \in \mathbb{R}^3$: RGB color.
*   $\mathbf{n} \in \mathbb{R}^3$: Surface normal (optional, derived from density gradient).
*   $\rho$: Roughness (optional, if enabled).

### Data Structures and Configuration
The architecture is defined by a configuration object containing the following hyperparameters [S1, unofficial]:

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `net_depth` | int | 8 | Depth of the density MLP. |
| `net_width` | int | 256 | Width of the density MLP layers. |
| `bottleneck_width` | int | 256 | Width of the feature vector passed to the color MLP. |
| `net_depth_viewdirs` | int | 1 | Depth of the color MLP. |
| `net_width_viewdirs` | int | 128 | Width of the color MLP layers. |
| `min_deg_point` | int | 0 | Minimum degree of positional encoding for points. |
| `max_deg_point` | int | 12 | Maximum degree of positional encoding for points. |
| `skip_layer` | int | 4 | Frequency of skip connections in the density MLP. |
| `skip_layer_dir` | int | 4 | Frequency of skip connections in the color MLP. |
| `deg_view` | int | 4 | Degree of encoding for view/reflection directions. |
| `density_bias` | float | -1.0 | Bias added to raw density before activation. |
| `density_noise` | float | 0.0 | Standard deviation of noise added to raw density. |
| `rgb_bias` | float | 0.0 | Bias added to raw color before activation. |
| `rgb_padding` | float | 0.001 | Padding applied to RGB output range. |
| `use_reflections` | bool | False | Use reflection directions instead of view directions. |
| `use_directional_enc` | bool | False | Use Integrated Directional Encoding (IDE). |
| `basis_shape` | str | 'icosahedron' | Basis shape for IDE ('octahedron' or 'icosahedron'). |
| `basis_subdivisions` | int | 2 | Tessellation count for the basis shape. |
| `enable_pred_normals` | bool | False | Enable explicit normal prediction. |
| `disable_density_normals` | bool | True | Disable normal computation from density gradient. |
| `use_diffuse_color` | bool | False | Predict diffuse and specular colors separately. |
| `use_specular_tint` | bool | False | Predict a tint vector for specular color. |
| `use_n_dot_v` | bool | False | Feed $\mathbf{n} \cdot \mathbf{v}$ to the color MLP. |
| `bottleneck_noise` | float | 0.0 | Standard deviation of noise added to the bottleneck vector. |
| `warp_fn` | callable | None | Function to linearize means and covs. |

### Edge Cases and Pitfalls
*   **Reflections Require Normals:** If `use_reflections` is True, normals must be computed either via `enable_pred_normals` or by not disabling density normals (`disable_density_normals` must be False). Otherwise, a `ValueError` is raised [S1, unofficial].
*   **Reflection Direction Flip:** When computing reflection directions, view directions are flipped (`-viewdirs`) before reflection because they point from the camera to the point, whereas the reflection utility function assumes they point toward the camera [S1, unofficial].
*   **Normal Stability:** Normals are computed from the gradient of the raw (pre-activation) density because it is numerically more stable than the post-activation density when the activation function has a steep or flat gradient [S1, unofficial].
*   **Precision:** High precision (float64) is recommended for color correction and metric computation to avoid quantization errors [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The integrated positional encoding is more computationally expensive than standard positional encoding due to the covariance matrix operations, but it reduces the need for high-frequency sampling, potentially allowing for coarser sampling strategies [S1, unofficial].
*   **Memory Complexity:** The architecture stores the same number of parameters as standard NeRF but requires additional memory for storing the covariance matrices during rendering [S1, unofficial].
*   **Strengths:** Significantly reduces aliasing artifacts in novel view synthesis, especially for scenes with high-frequency details or large depth variations [S1, unofficial].
*   **Limitations:** Increased computational cost per ray due to integrated encoding calculations. Requires careful tuning of the basis shape and subdivisions for IDE [S1, unofficial].

## Background
The Mip-NeRF 360 MLP architecture was introduced in the "Mip-NeRF 360: Unbounded Anti-Aliased Neural Radiance Fields" paper by T. Müller et al. (2022) [S1, unofficial]. It extends the original Mip-NeRF approach to unbounded scenes and 360-degree views, addressing the aliasing issues inherent in standard NeRF when rendering views with significant perspective changes or large depth ranges. The method is implemented in the `google-research/multinerf` repository [S1, unofficial].
