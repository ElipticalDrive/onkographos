# Confidence Updating with Detached Color Network

Also called: Cn-based confidence scoring, PSNR-based confidence update

## Overview
This method addresses the problem of pose outlier contamination in neural surface reconstruction, where shape-radiance ambiguity causes outlier poses to exhibit higher rendering quality (PSNR) than inlier poses, leading to incorrect ray sampling [S1]. It distinguishes itself by employing a detached color network ($C_n$) that excludes viewing direction inputs to mitigate this ambiguity, using its output to dynamically update confidence scores for pose weighting during training [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of training images $V$, initial confidence scores $CS(v_i)$ derived from keypoint matches, a detached color network $C_n$, and the primary color network $C_o$.
*   **Outputs:** Updated confidence scores $CS(v_i)$ used to guide ray sampling probabilities, and filtered outlier poses identified by the discrepancy between $C_o$ and $C_n$ outputs.

**Data Structures:**
*   **Confidence Score ($CS(v_i)$):** A scalar value for each view $v_i \in V$. Initialized based on keypoint matching quality [S1].
*   **PSNR ($PSNR(v_i)$):** A scalar value representing the Peak Signal-to-Noise Ratio for image $v_i$, estimated from the rendering loss [S1].
*   **Threshold ($\tau_1$):** A scalar constant for detecting outliers based on PSNR discrepancy. Default value: 9 [S1].
*   **Learning Rate ($\lambda_c$):** A scalar constant for updating confidence scores. Value not given in the sources.

**Algorithm Steps:**

1.  **Initialize Confidence:** Compute initial confidence scores $CS(v_i)$ for all views based on the number of keypoint matches. Normalize these scores to form a probability distribution:
    $$ CS(v_i) = \frac{CS(v_i)}{\sum_{v \in V} CS(v)} $$
    This distribution guides the initial ray sampling [S1].

2.  **Train Detached Color Network ($C_n$):**
    *   Construct $C_n$ using the same sampling points and geometry features as the original color network $C_o$.
    *   Crucially, $C_n$ does **not** take viewing direction as input. This design mitigates shape-radiance ambiguity and prevents overfitting to specific viewpoints [S1].
    *   Detach all computations related to $C_n$ from the main computational graph. The loss computed using $C_n$ is backpropagated only to $C_n$ and does not impact the gradients of the primary network $C_o$ or the SDF network [S1].

3.  **Estimate PSNR:**
    *   Calculate the photometric loss $L_{color}$ for both networks:
        $$ L_{color} = \frac{1}{k} \sum_{i=1}^k (\hat{C}_i - C_i)^2 $$
        where $\hat{C}_i$ is the rendered color from volume rendering and $C_i$ is the ground truth color [S1].
    *   Estimate $PSNR(v_i)$ for each image based on the current rendering loss for efficiency [S1].
    *   Record $PSNR_o(v_i)$ derived from the original network $C_o$ [S1].
    *   Record $PSNR_n(v_i)$ derived from the detached network $C_n$ [S1].

4.  **Update Confidence Scores:**
    *   Update the confidence score for each view using the PSNR estimated from the detached network $C_n$:
        $$ CS(v_i) = CS(v_i) + \lambda_c \cdot PSNR_n(v_i) $$
    *   Re-normalize the confidence scores to form a new probability distribution:
        $$ CS(v_i) = \frac{CS(v_i)}{\sum_{v \in V} CS(v)} $$
    *   Use this updated distribution to sample rays, prioritizing poses with higher confidence [S1].

5.  **Outlier Filtering:**
    *   Monitor the discrepancy between $PSNR_o$ and $PSNR_n$.
    *   Identify poses as outliers if:
        $$ |PSNR_o - PSNR_n| > \tau_1 $$
    *   The threshold $\tau_1$ is set to 9 [S1]. Significant discrepancy indicates anomalous data due to shape-radiance ambiguity [S1].

**Pseudocode:**

```python
def update_confidence_and_detect_outliers(views, initial_cs, lambda_c, tau_1, C_o, C_n, geometry_features, sampling_points, ground_truth_images):
    """
    Updates confidence scores using a detached color network and detects outliers.
    
    Args:
        views: List of view indices v_i.
        initial_cs: Initial confidence scores based on keypoint matches.
        lambda_c: Learning rate for confidence update.
        tau_1: Threshold for outlier detection (default 9).
        C_o: Original color network (takes viewing direction).
        C_n: Detached color network (does NOT take viewing direction).
        geometry_features: Geometry features for sampling points.
        sampling_points: 3D sampling points along rays.
        ground_truth_images: Ground truth RGB images for views.
        
    Returns:
        normalized_cs: Updated normalized confidence scores.
        outliers: Set of view indices identified as outliers.
    """
    # Step 1: Initialize Confidence
    # Normalize initial scores to form probability distribution
    sum_cs = sum(initial_cs.values())
    cs = {v: initial_cs[v] / sum_cs for v in views}
    
    outliers = set()
    
    for v in views:
        # Step 2: Forward pass through networks
        # C_o uses viewing direction; C_n does not
        # Both use same sampling_points and geometry_features
        
        # Render color using original network C_o
        rendered_color_o = volume_render(C_o, sampling_points, geometry_features, viewing_direction=v)
        
        # Render color using detached network C_n
        # Note: C_n input does not include viewing direction
        rendered_color_n = volume_render(C_n, sampling_points, geometry_features, viewing_direction=None)
        
        # Get ground truth color for view v
        gt_color = ground_truth_images[v]
        
        # Step 3: Calculate Photometric Loss and PSNR
        # L_color = mean((rendered - ground_truth)^2)
        loss_o = mean_squared_error(rendered_color_o, gt_color)
        loss_n = mean_squared_error(rendered_color_n, gt_color)
        
        # Estimate PSNR from loss (standard conversion or direct metric)
        # The source states PSNR is estimated from current image rendering loss
        psnr_o = calculate_psnr_from_loss(loss_o)
        psnr_n = calculate_psnr_from_loss(loss_n)
        
        # Step 4: Update Confidence using PSNR from Detached Network (C_n)
        # CS(v_i) = CS(v_i) + lambda_c * PSNR(v_i)
        cs[v] = cs[v] + lambda_c * psnr_n
        
        # Step 5: Outlier Detection
        # If |PSNR_o - PSNR_n| > tau_1, mark as outlier
        if abs(psnr_o - psnr_n) > tau_1:
            outliers.add(v)
            
    # Re-normalize confidence scores
    sum_cs = sum(cs.values())
    normalized_cs = {v: cs[v] / sum_cs for v in views}
    
    return normalized_cs, outliers

def volume_render(network, points, features, viewing_direction):
    """
    Simulates volume rendering.
    If viewing_direction is None, the network ignores it (for C_n).
    """
    # Implementation detail: The network predicts color based on points, features, and optionally direction.
    # For C_n, the direction argument is ignored or not passed to the MLP.
    colors = []
    for i, point in enumerate(points):
        # Get feature for point
        feat = features[i]
        
        # Predict color
        if viewing_direction is not None:
            color = network(point, feat, viewing_direction)
        else:
            color = network(point, feat)
        colors.append(color)
    
    # Aggregate colors using volume rendering equation (e.g., alpha compositing)

    rendered_color = aggregate_colors(colors)
    return rendered_color

def calculate_psnr_from_loss(mse_loss):
    """
    Converts Mean Squared Error loss to PSNR.
    PSNR = 10 * log10(1 / MSE) for normalized pixel values in [0,1].
    """
    import math
    if mse_loss == 0:
        return float('inf')
    return 10 * math.log10(1.0 / mse_loss)

def mean_squared_error(rendered, ground_truth):
    return mean((rendered - ground_truth) ** 2)
```

**Parameters:**
*   $\tau_1$: Inlier-outlier threshold for PSNR discrepancy. Set to 9 [S1].
*   $\lambda_c$: Weight for PSNR contribution to confidence update. Value not given in the sources.
*   $\lambda$: Weight for regularization loss. Set to 0.1 [S1].
*   $\alpha, \beta$: Other loss weights. Set to 0.2 and 0.001 respectively [S1].
*   $N_p$: Particle number. Set to 24 for efficiency [S1].

**Edge Cases and Pitfalls:**
*   **Shape-Radiance Ambiguity:** Outliers may have higher PSNR than inliers if only the original network $C_o$ is used, leading to incorrect sampling [S1]. The detached network $C_n$ mitigates this by removing viewing direction dependence [S1].
*   **Precision:** The threshold $\tau_1 = 9$ is described as an "extremely large performance gap" [S1].

## Operating characteristics
*   **Time Complexity:** The method adds computational overhead by maintaining a second color network $C_n$. However, since $C_n$ is a shallow MLP (similar to existing works [38, 59]), it does not introduce significant computational overhead [S1].
*   **Memory Complexity:** Requires storing parameters for the additional detached color network $C_n$ [S1].
*   **Performance:** On the SG-NeRF dataset, the method runs for 150k iterations in an average of 13 hours on NVIDIA RTX 3090 GPUs. On the DTU dataset, it runs for 300k iterations in 22 hours [S1].
*   **Strengths:** Effectively identifies and filters outliers caused by shape-radiance ambiguity, improving robustness in object-level 3D surface reconstruction from unorganized inward-facing images [S1].
*   **Limitations:** Relies on the assumption that the discrepancy between $C_o$ and $C_n$ is a reliable indicator of outliers. The threshold $\tau_1$ is fixed at 9, which may not be optimal for all scenes.

## Background
*   **Origin:** Proposed in "Robust SG-NeRF: Robust Scene Graph Aided Neural Surface Reconstruction" (2024) [S1].
*   **Development:** The method builds upon NeuS [59] and addresses limitations in pose estimation and outlier handling in neural surface reconstruction. It leverages insights from NeRF++ [73] regarding the use of shallow MLPs for color networks as implicit regularization [S1].
*   **Usage:** Used for object-level 3D surface reconstruction from unorganized inward-facing images, specifically on datasets like SG-NeRF and DTU [S1].
