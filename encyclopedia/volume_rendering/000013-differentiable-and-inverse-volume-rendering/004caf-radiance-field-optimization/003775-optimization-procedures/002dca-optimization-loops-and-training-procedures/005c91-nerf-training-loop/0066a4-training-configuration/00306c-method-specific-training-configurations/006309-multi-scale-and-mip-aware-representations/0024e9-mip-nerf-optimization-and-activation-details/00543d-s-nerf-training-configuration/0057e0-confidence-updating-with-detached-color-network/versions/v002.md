# Confidence Updating with Detached Color Network

Also called: Cn-based confidence scoring, Color Network w/o View Direction, Detached Color Network for Confidence, Isolated Color Network, PSNR-based confidence update

## Overview
This method distinguishes inlier and outlier camera poses by using a detached color network that omits the viewing direction as input, minimizing the impact of shape-radiance ambiguities that cause high PSNR for wrong poses [S1]. It solves the issue where outliers might have higher PSNR than inliers due to shape-radiance ambiguity, which traditional rendering metrics fail to detect [S1]. Unlike previous works using rendering metrics directly, this approach uses a detached network to provide reliable confidence scores for pose filtering [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of training images $V$, initial camera poses, a scene graph, and a primary NeRF model (including geometry SDF $f$ and traditional color network $C_o$).
*   **Outputs:** Updated confidence scores $CS(v_i)$ for each view $v_i \in V$, used to guide ray sampling.

**Data Structures:**
*   **Confidence Score ($CS(v_i)$):** A scalar value representing the reliability of pose $v_i$. Initialized based on keypoint matches and updated iteratively.
*   **Detached Color Network ($C_n$):** A shallow Multi-Layer Perceptron (MLP) identical in architecture to the primary color network $C_o$ but without viewing direction input.
*   **PSNR Estimates:**
    *   $PSNR_o$: PSNR estimated using the primary color network $C_o$.
    *   $PSNR_n$: PSNR estimated using the detached color network $C_n$.

**Parameters:**
*   $\lambda_c$: Weight for PSNR contribution to confidence update. [G] Typical value not explicitly given in sources; assumed to be a small positive constant (e.g., 1.0 or normalized weight) based on standard additive update rules.
*   $\tau_1$: Inlier-outlier threshold for PSNR discrepancy between $C_o$ and $C_n$. Set to 9 [S1].
*   $\lambda$: Weight for regularization term in loss. Set to 0.1 [S1].

**Numbered Steps:**

1.  **Initialize Confidence Scores:**
    Calculate initial confidence scores $CS(v_i)$ based on keypoint matches from the scene graph. Let $|M_i|$ be the total number of edges (matches) for view $v_i$. Normalize these scores to form a probability distribution:
    $$ CS(v_i) = \frac{|M_i|}{\sum_{v \in V} |M_v|} $$
    (Note: The source describes normalizing based on match counts initially, then updating additively [S1]).

2.  **Construct Detached Color Network ($C_n$):**
    Create a color network $C_n$ that takes only geometry features (from the SDF network) as input, explicitly excluding the viewing direction vector. Use the same sampling points and geometry features as the original color network $C_o$ [S1].

3.  **Detach Optimization Graph:**
    Detach all computations involving $C_n$ from the main pose-NeRF optimization graph. This ensures that the loss calculated from $C_n$ does not backpropagate to the SDF network or the primary color network $C_o$, maintaining the performance of the NSR backbone [S1].

4.  **Compute Rendering Losses:**
    For each training image $i$:
    *   Render the image using $C_o$ to get $\hat{C}_o$. Compute photometric loss $L_{color}(C_o) = \|\hat{C}_o - C\|_1$ [S1].
    *   Render the image using $C_n$ to get $\hat{C}_n$. Compute photometric loss $L_{color}(C_n) = \|\hat{C}_n - C\|_1$ [S1].
    *   Estimate $PSNR_o$ from $L_{color}(C_o)$ and $PSNR_n$ from $L_{color}(C_n)$ [S1].

5.  **Update Confidence Scores:**
    Update the confidence score for each view $v_i$ using the PSNR estimated by the detached network $C_n$:
    $$ CS(v_i) = CS(v_i) + \lambda_c \cdot PSNR_n(v_i) $$
    where $PSNR_n(v_i)$ is the PSNR value for view $v_i$ estimated by $C_n$ [S1].

6.  **Normalize Confidence Scores:**
    After updating, normalize the confidence scores to form a probability distribution for ray sampling:
    $$ CS(v_i) = \frac{CS(v_i)}{\sum_{v \in V} CS(v)} $$
    This distribution guides the training to sample more rays from poses with higher confidence [S1].

7.  **Identify Outliers (Optional Filtering):**
    Monitor the discrepancy between $PSNR_o$ and $PSNR_n$. If $|PSNR_o - PSNR_n| > \tau_1$ (where $\tau_1 = 9$), the pose is identified as an outlier [S1]. This discrepancy indicates shape-radiance ambiguity where the view-dependent network $C_o$ overfits to the wrong pose while the view-independent network $C_n$ fails to render accurately [S1].

**Pseudocode:**

```python
def initialize_confidence(views, scene_graph):
    """
    Initialize confidence scores based on keypoint matches.
    views: List of view indices.
    scene_graph: Graph structure containing match counts.
    """
    confidence_scores = {}
    total_matches = 0
    for v in views:
        # |M_v| is the number of matching pairs/edges for view v
        match_count = scene_graph.get_edge_count(v)
        confidence_scores[v] = match_count
        total_matches += match_count
    
    # Normalize to form initial probability distribution
    for v in views:
        confidence_scores[v] /= total_matches
        
    return confidence_scores

def train_detached_color_network(C_n, geometry_features, ground_truth_images, lr=0.001):
    """
    Train the detached color network C_n independently.
    C_n: MLP taking only geometry features.
    geometry_features: Features from SDF network at sampled points.
    ground_truth_images: GT RGB images.
    """
    optimizer = torch.optim.Adam(C_n.parameters(), lr=lr)
    
    for epoch in range(num_epochs):
        optimizer.zero_grad()
        rendered_colors = C_n(geometry_features)
        loss = torch.mean(torch.abs(rendered_colors - ground_truth_images))
        loss.backward()
        optimizer.step()
        
    return loss

def update_confidence(views, confidence_scores, psnr_n_values, lambda_c=1.0):
    """
    Update confidence scores using PSNR from detached network.
    psnr_n_values: Dict mapping view index to PSNR_n.
    """
    for v in views:
        psnr_n = psnr_n_values[v]
        confidence_scores[v] += lambda_c * psnr_n
        
    # Normalize
    total_confidence = sum(confidence_scores.values())
    for v in views:
        confidence_scores[v] /= total_conf
        
    return confidence_scores

def identify_outliers(psnr_o_values, psnr_n_values, threshold=9.0):
    """
    Identify outliers based on discrepancy between C_o and C_n PSNR.
    """
    outliers = []
    for v in psnr_o_values:
        discrepancy = abs(psnr_o_values[v] - psnr_n_values[v])
        if discrepancy > threshold:
            outliers.append(v)
    return outliers
```

**Edge Cases and Pitfalls:**
*   **Shape-Radiance Ambiguity:** Traditional color networks $C_o$ (with view direction) can render high-PSNR images even for wrong poses, leading to incorrect sampling if used for confidence [S1].
*   **Overfitting:** The detached network $C_n$ must not be coupled with the main optimization to prevent it from learning pose-specific artifacts that defeat its purpose [S1].
*   **Computational Cost:** While $C_n$ adds overhead, using a shallow MLP minimizes the impact on training time [S1].

## Operating characteristics
*   **Time Complexity:** Adds minimal computational overhead because $C_n$ is a shallow MLP, similar to the existing color network [S1]. Training time increases slightly but remains comparable to baseline NeuS/SG-NeRF (e.g., 13 hours for 150k iterations on SG-NeRF, 22 hours for 300k iterations on DTU on RTX 3090) [S1].
*   **Memory Complexity:** Requires storing parameters for an additional shallow MLP $C_n$. [G] Exact memory footprint not given, but described as not substantially increasing costs.
*   **Performance:** Effectively differentiates inliers and outliers, leading to higher quality 3D reconstructions and accurate pose rectification [S1].
*   **Strengths:** Robust against shape-radiance ambiguity; simple rule-based thresholding ($\tau_1=9$) for outlier detection; does not complicate the joint pose-NeRF optimization [S1].
*   **Limitations:** Relies on the assumption that view-independent rendering quality correlates better with pose correctness than view-dependent rendering; requires careful tuning of $\lambda_c$ and $\tau_1$ [S1].

## Background
*   **Origin:** Introduced in "Robust SG-NeRF: Robust Scene Graph Aided Neural Surface Reconstruction" [S1].
*   **History:** Addresses limitations in SG-NeRF where heuristic confidence updating based solely on PSNR failed to distinguish inliers from outliers due to shape-radiance ambiguity [S1].
*   **Usage:** Used in object-level 3D surface reconstruction from unorganized inward-facing images, specifically on datasets like SG-NeRF and DTU [S1].
