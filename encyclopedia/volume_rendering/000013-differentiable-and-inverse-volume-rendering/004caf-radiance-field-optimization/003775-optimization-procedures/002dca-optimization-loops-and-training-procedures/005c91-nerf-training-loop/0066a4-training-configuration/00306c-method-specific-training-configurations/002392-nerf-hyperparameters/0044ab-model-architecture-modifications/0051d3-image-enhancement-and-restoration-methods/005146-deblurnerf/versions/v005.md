# DeblurNeRF

Also called: DeRF, Deblur-NeRF, Deblur-NeRF: Neural Radiance Fields from Blurry Images

## Overview
DeblurNeRF is a method that reconstructs a sharp Neural Radiance Field (NeRF) from blurry input images by explicitly modeling the blurring process via an analysis-by-synthesis approach [S1, S3]. Unlike standard NeRF training which assumes sharp inputs, DeblurNeRF jointly optimizes the radiance field and a Deformable Sparse Kernel (DSK) module to simulate spatially varying blur (such as camera motion or defocus) during training, allowing the network to learn a sharp underlying scene representation [S1]. It differs from sibling methods like DP-NeRF by using pixel-wise independent ray transformations rather than scene-wise shared rigid transformations, which allows it to model spatially varying blur more flexibly but may incur 3D inconsistency [S3].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of blurry multi-view images $B$. Camera parameters (origin $o$, direction $d$) for each view.
*   **Outputs:** A sharp NeRF function $F_\Theta$ and a DSK module $G_\Phi$. At inference, the output is sharp novel views rendered directly from $F_\Theta$.

**Data Structures:**
1.  **NeRF ($F_\Theta$):** Standard MLP mapping $(\mathbf{x}, \mathbf{d}) \to (\mathbf{c}, \sigma)$.
    *   Input: Positional encoded position $\gamma_L(\mathbf{x})$ and view direction $\gamma_L(\mathbf{d})$.
    *   Output: Color $\mathbf{c}$ and volume density $\sigma$.
2.  **Deformable Sparse Kernel (DSK) ($G_\Phi$):** MLP parameterized by $\Phi$.
    *   Input: Pixel coordinate $\mathbf{p}$, canonical kernel location $\mathbf{q}^0$, and view embedding $\mathbf{l}$.
    *   Output: Tuples $(\Delta \mathbf{o}_q, \Delta \mathbf{q}, w_q)$ for each sparse location $q$.
    *   Structure: 4 fully-connected hidden layers, 64 channels each, ReLU activations. Shortcut connection from first to last layer [S1].
3.  **Canonical Kernel Locations ($N^0(\mathbf{p})$):** A set of $N$ fixed 2D coordinates $\{\mathbf{q}^0_i\}_{i=0}^{N-1}$ distributed around pixel $\mathbf{p}$. Initialized within a small range [S3].
4.  **View Embedding ($\mathbf{l}$):** A learned vector of length 32 per view [S1].

**Numbered Steps:**

1.  **Ray Generation:** For each pixel $\mathbf{p}$ in a batch, generate a primary ray $\mathbf{r}_p(t) = \mathbf{o} + t\mathbf{d}_p$ from camera parameters [S1].
2.  **Canonical Sampling:** Define $N$ canonical kernel locations $N^0(\mathbf{p}) = \{\mathbf{q}^0_i\}$ around $\mathbf{p}$ [S1].
3.  **Kernel Deformation (DSK):** For each canonical location $\mathbf{q}^0 \in N^0(\mathbf{p})$, query the DSK MLP $G_\Phi$ with inputs $\mathbf{p}$, $\mathbf{q}^0$, and view embedding $\mathbf{l}$ to predict deformation and weight:
    $$
    (\Delta \mathbf{o}_q, \Delta \mathbf{q}, w_q) = G_\Phi(\mathbf{p}, \mathbf{q}^0, \mathbf{l})
    $$
    *   $\Delta \mathbf{o}_q$: 3D vector, translation of ray origin [S3].
    *   $\Delta \mathbf{q}$: 2D vector, deformation of kernel location [S1].
    *   $w_q$: Scalar weight for the sparse kernel point [S1].
    *   *Initialization:* Multiply outputs by a small gain $\epsilon = 0.1$ to keep optimized rays close to the input ray initially [S1].
4.  **Optimized Ray Generation:** Compute deformed locations $\mathbf{q} = \mathbf{q}^0 + \Delta \mathbf{q}$ and generate $N$ optimized rays $\mathbf{r}_q$:
    $$
    \mathbf{r}_q(t) = (\mathbf{o} + \Delta \mathbf{o}_q) + t\mathbf{d}_q
    $$
    where $\mathbf{d}_q$ is the direction derived from the deformed location $\mathbf{q}$ [S1, S3].
5.  **NeRF Rendering (Coarse & Fine):**
    *   For each optimized ray $\mathbf{r}_q$, perform stratified sampling along near-to-far bounds $[t_n, t_f]$ to generate $N_s$ coarse samples $\mathbf{r}_i = \mathbf{o}_q + t_i \mathbf{d}_q$ [S3].
    *   Query $F_\Theta$ to get $(\mathbf{c}_i, \sigma_i)$ for each sample [S1].
    *   Render coarse color $\hat{\mathbf{C}}_c(\mathbf{r}_q)$ using volume rendering:
        $$
        \hat{\mathbf{C}}_c(\mathbf{r}_q) = \sum_{i=1}^{N_s} T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i
        $$
        where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ and $\delta_i = t_{i+1} - t_i$ [S3].
    *   Compute normalized weights $\hat{w}_i = w_i / \sum_j w_j$ as a PDF.
    *   Perform hierarchical volume sampling using $\hat{w}_i$ to produce fine samples [S3].
    *   Render fine color $\hat{\mathbf{C}}_f(\mathbf{r}_q)$ similarly [S3].
6.  **Blurred Color Composition:** Blend the rendered colors from the $N$ optimized rays to approximate the blurry pixel $\hat{\mathbf{b}}_p$:
    $$
    \hat{\mathbf{b}}_p = \sum_{q \in N(\mathbf{p})} w_q \hat{\mathbf{C}}_f(\mathbf{r}_q)
    $$
    Apply gamma correction to compensate for non-linear Camera Response Function (CRF):
    $$
    \hat{\mathbf{b}}_p = g\left(\sum_{q \in N(\mathbf{p})} w_q \mathbf{c}^0_q\right), \quad g(\mathbf{c}^0) = (\mathbf{c}^0)^{1/2.2}
    $$
    where $\mathbf{c}^0_q$ is the rendered color [S1].
7.  **Loss Computation:**
    *   **Reconstruction Loss:** L2 loss between predicted blurry color and ground truth blurry image $\mathbf{b}^{gt}$:
        $$
        L_{reconstruct} = \sum_{\mathbf{p} \in R} \|\hat{\mathbf{b}}_p - \mathbf{b}^{gt}_p\|_2^2
        $$
        where $R$ is the set of pixels in the batch [S1].
    *   **Alignment Loss:** Constrain the NeRF to avoid non-rigid distortion by forcing one canonical location $\mathbf{q}^0$ to align with the pixel center $\mathbf{p}$ and its origin translation to be small:
        $$
        L_{align} = \|\mathbf{q}^0 - \mathbf{p}\|_2^2 + \lambda_o \|\Delta \mathbf{o}_{q^0}\|_2^2
        $$
        where $\mathbf{q}^0$ is a fixed element in $N(\mathbf{p})$ [S1].
    *   **Total Loss:**
        $$
        L = L_{reconstruct} + \lambda_a L_{align}
        $$
8.  **Optimization:** Jointly optimize parameters $\Theta$ (NeRF) and $\Phi$ (DSK) using Adam optimizer [S1].
9.  **Inference:** Render novel views directly from the trained NeRF $F_\Theta$ without the DSK module to produce sharp images [S1].

**Parameters:**
*   $N$: Number of sparse kernel points. Default 5 [S1]. Quality improves with $N$ but saturates after 5 [S1].
*   $L$: Highest frequency in positional encoding. Controls smoothness [S1].
*   View embedding length: 32 [S1].
*   $\lambda_a$ (Alignment loss weight): 0.1 [S1].
*   $\lambda_o$ (Origin alignment weight): 10 [S1].
*   $\epsilon$ (Initialization gain): 0.1 [S1].
*   Batch size: 1024 rays [S1].
*   Sampling: 64 coarse samples, 64 fine samples [S1].
*   Optimizer: Adam, default parameters [S1].
*   Learning rate: Starts at $5 \times 10^{-4}$, decays exponentially to $8 \times 10^{-5}$ [S1].
*   Training duration: 200k iterations on NVIDIA V100 [S1].

**Edge Cases and Pitfalls:**
*   **Non-rigid Distortion:** If all components are freely optimized, the NeRF may undergo non-rigid distortion to match the blur. This is mitigated by the alignment loss $L_{align}$ [S1].
*   **3D Inconsistency:** Pixel-wise independent optimization of the blur kernel can incur inconsistency in 3D geometry and appearance compared to scene-wise shared transformations [S3].
*   **Positional Encoding on Input:** Using positional encoding on the input $\mathbf{p}$ of $G_\Phi$ was tested but found not to help, likely because the spatially-varying kernel changes gradually without high-frequency variation [S1].
*   **Gamma Correction:** Simple gamma correction ($1/2.2$) is used to compensate for non-linear CRF. More complex CRFs could be used but were found unnecessary [S1].

## Operating characteristics
*   **Time Complexity:** Training requires rendering $N$ rays per pixel. With $N=5$ and standard sampling (128 samples total), the cost is roughly $5 \times$ the cost of a single ray render per pixel, plus the MLP inference for the DSK.
*   **Memory Complexity:** Requires storing parameters for the NeRF and the DSK MLP. The DSK MLP is small (4 layers, 64 channels).
*   **Performance:** On synthetic scenes, the full model achieves the highest average PSNR/SSIM and lowest LPIPS compared to ablations (w/o gamma, w/o align, w/o origin opt) [S1].
*   **Strengths:** Handles both camera motion blur and defocus blur. Recovers sharp novel views at inference. Compact and efficient approximation suited for moderate blur [S2].
*   **Limitations:** May suffer from 3D inconsistency due to pixel-wise independent blur modeling [S3]. Less effective for severe motion blur compared to physically grounded methods like BAD-NeRF, which incurs higher computational complexity [S2].
*   **When to use:** When input images are blurry (motion or defocus) and sharp novel views are desired. Suitable for moderate blur.
*   **When not to use:** For severe motion blur where physical trajectory modeling is critical, or when 3D geometric consistency across views is paramount over flexibility in blur modeling [S2, S3].

## Background
DeblurNeRF (also known as DeRF) was proposed by Xiaoyu Li et al. and published in CVPR 2022 [S1]. It is the first method to recover a sharp NeRF from blurry input images using an analysis-by-synthesis approach [S1]. It was implemented on a PyTorch re-implementation of NeRF and tested on synthetic scenes generated with Blender and real-world scenes captured with a Canon EOS RP [S1]. It differs from DP-NeRF by using pixel-wise independent transformations (DSK) instead of scene-wise shared rigid transformations (RBK) [S3].
