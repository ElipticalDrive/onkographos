# Interval Score Matching

Also called: LucidDreamer (ISM)

## Overview
Interval Score Matching (ISM) is a modification to Score Distillation Sampling (SDS) that replaces the standard Denoising Diffusion Probabilistic Model (DDPM) forward process with Denoising Diffusion Implicit Model (DDIM) inversion [S1][S2, unofficial]. It introduces supervision from multiple interval steps of the diffusion process to mitigate the high reconstruction error inherent in single-step noise prediction [S1][S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A radiance field parameterized by $\Theta$, a text prompt, and a frozen diffusion model (Stable Diffusion).
- Output: Gradients $\nabla_\Theta L$ for optimizing $\Theta$.

**Data Structures:**
- Not given in the sources.

**Steps:**
1. Render an image $I$ from the current radiance field parameters $\Theta$.
2. Instead of adding noise at a single timestep $t$ as in standard SDS, apply DDIM inversion to determine the noise levels corresponding to the interval steps.
3. For each interval step $t_i$ in the chosen set of steps:
   a. Add noise $\epsilon$ to the rendered image $I$ according to the DDIM forward process to obtain $x_{t_i}$.
   b. Pass $x_{t_i}$ through the frozen diffusion model to predict the noise $\hat{\epsilon}_{t_i}$.
   c. Compute the residual $\hat{\epsilon}_{t_i} - \epsilon$.
4. Aggregate the gradients from all interval steps to update $\Theta$.

**Formulas:**
The core modification lies in the use of DDIM inversion. The standard SDS loss relies on a single timestep $t$. ISM uses a set of timesteps $\{t_1, t_2, ..., t_k\}$.
The noise prediction at step $t$ is $\hat{\epsilon}_\theta(x_t, t)$.
The gradient is computed based on the residuals from these interval steps.
Exact weighting functions and aggregation formulas are not given in the sources.

**Parameters:**
- The set of interval steps is not specified in the sources.
- The number of interval steps is not given in the sources.

**Edge Cases and Pitfalls:**
- Precision issues in DDIM inversion are not detailed in the sources.
- Boundary conditions for the interval steps are not given in the sources.

**Pseudocode:**
```python
def interval_score_matching(radiance_field, prompt, diffusion_model, interval_steps):
    # Render image from current radiance field
    image = radiance_field.render()
    
    gradients = 0
    
    # Iterate over interval steps
    for t in interval_steps:
        # Add noise to image at timestep t
        # Note: DDIM inversion logic is implied but not explicitly detailed in sources
        noise = sample_noise()
        x_t = add_noise_ddim(image, noise, t)
        
        # Predict noise using diffusion model
        predicted_noise = diffusion_model.predict(x_t, t, prompt)
        
        # Compute residual
        residual = predicted_noise - noise
        
        # Compute gradient contribution
        # Exact weighting and aggregation formula not given in sources
        grad_t = compute_gradient(residual, t)
        
        gradients += grad_t
        
    return gradients
```
