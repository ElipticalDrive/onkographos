# SDF-based Volume Rendering with Laplacian CDF

Also called: Laplacian opacity transformation, VolSDF variant

## Overview
This method renders geometry by outputting a Signed Distance Function (SDF) value $s$ and a variance parameter $\beta$ from a neural network, then transforming $s$ into opacity $\sigma$ using a Laplacian Cumulative Distribution Function (CDF) [S1]. It builds on [Model Architecture and Encoding](13550-model-architecture-and-encoding.md) by integrating triplane features and SDF-based sampling. Unlike standard NeRF which outputs density directly, this approach enables tight surface extraction and inverse CDF sampling for more accurate depth estimation [S1].

## How it works
**Inputs:**
- Camera ray origin $o$ and direction $d$, defining ray $r(t) = o + td$.
- A set of $N$ sample distances $t_i$ along the ray.
- Triplane feature grid $T$ (spatial resolution $512 \times 512$, feature size 32) [S1].

**Outputs:**
- Rendered color $C(r)$ for the ray.
- Surface variance $B$ (optional, for supervision) [S1].

**Data Structures:**
- **Triplane $T$**: Three axis-aligned 2D feature grids. For a point $x \in \mathbb{R}^3$, features $T_x$ are gathered by projecting $x$ to each plane and taking the Hadamard product of the three resultant vectors [S1].
- **MLP Outputs**: The network `MLPSDF` outputs a tuple $(s, \beta, f_{geo})$ where $s$ is the SDF, $\beta$ is the variance, and $f_{geo}$ are geometry features [S1].

**Parameters:**
- $\beta$: Variance of the Laplacian distribution governing the "tightness" of the representation. It varies spatially in the volume (output by `MLPSDF`) [S1].
- $N$: Number of samples per ray.

**Steps:**
1. **Positional Encoding**: Compute $PosEnc(x)$ for the query point $x$ using standard NeRF positional encoding [S1].
2. **Feature Gathering**: Gather triplane features $T_x$ by projecting $x$ to the three axis-aligned planes and computing the Hadamard product of the resulting vectors [S1].
3. **SDF Prediction**: Pass $(PosEnc(x), T_x)$ to `MLPSDF` to obtain $(s, \beta, f_{geo})$ [S1].
   - *Initialization*: Initialize `MLPSDF` ReLU weights as in SAL [4] to ensure an approximately spherical SDF in early training [S1].
4. **Opacity Transformation**: Transform $s$ and $\beta$ into opacity $\sigma$ using the Laplacian CDF:
   $$
   \sigma = \begin{cases} 
   \frac{1}{2} \exp\left(\frac{s}{\beta}\right) & \text{if } s \le 0 \\
   1 - \frac{1}{2} \exp\left(-\frac{s}{\beta}\right) & \text{if } s > 0 
   \end{cases}
   $$
   where $\Phi(t)$ is the CDF with range $[0, 1]$ [S1].
5. **Inverse CDF Sampling**: To define sample points $t_i$, generate sorted random numbers $u_i \in [0, 1]$ and compute:
   $$
   t_i = \Phi^{-1}(u_i)
   $$
   where $\Phi$ is the CDF derived from the Laplacian distribution defined by $s$ and $\beta$ [S1].
6. **Stratification**: During training, stratify $u_i$ by dividing the unit interval into bins and taking one sample from each bin to lower rendering variance at low sample counts [S1].
7. **Radiance Prediction**: Compute radiance $c$ using a separate MLP `MLPc` conditioned on viewing direction $v$ and geometry features $f_{geo}$:
   $$
   c = MLP_c(PosEnc(v), f_{geo})
   $$
   [S1].
8. **Volume Rendering**: Approximate the volumetric rendering integral $C(r)$ by summing over samples:
   $$
   \hat{C}(r) = \sum_{i=1}^{N} T_i \alpha_i c_i
   $$
   where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, $\delta_i$ is the distance between samples, and $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ is the transmittance [S1].

**Pseudocode:**
```python
def render_ray(ray_origin, ray_direction, triplane_T, MLPSDF, MLPc, N_samples):
    # 1. Generate stratified samples
    # Divide [0, 1] into N_samples bins, take one sample per bin
    u = [random.uniform(i/N_samples, (i+1)/N_samples) for i in range(N_samples)]
    u.sort() # Sort to be increasing
    
    # 2. Initial coarse sampling to estimate distribution for inverse CDF
    # Note: The source mentions using coarse samples to define the distribution pj
    # For implementation, we assume a preliminary pass or uniform sampling 
    # to get initial s, beta to define Phi.
    # Here we assume we have a way to get initial s, beta for all t.
    
    samples_t = []
    for u_i in u:
        # Inverse CDF sampling requires solving Phi(t) = u_i
        # Since Phi depends on s and beta which depend on t, this is iterative.
        # The source states: "ti = Phi^-1(ui)" where Phi is derived from s and beta.
        # In practice, this often involves a root-finding step or pre-computed lookup.
        # For this pseudocode, we assume a helper function inverse_cdf_sample(u_i, ray)
        # which internally queries s, beta at candidate t and solves for t.
        t_i = inverse_cdf_sample(u_i, ray_origin, ray_direction, MLPSDF, triplane_T)
        samples_t.append(t_i)
        
    # 3. Evaluate SDF and Opacity at samples
    alphas = []
    colors = []
    transmittance = 1.0
    
    for t_i in samples_t:
        x = ray_origin + t_i * ray_direction
        
        # Positional Encoding
        pos_enc_x = positional_encoding(x)
        
        # Gather Triplane Features
        # Project x to XY, YZ, XZ planes
        feat_xy = triplane_T[0].sample(x.x, x.y)
        feat_yz = triplane_T[1].sample(x.y, x.z)
        feat_xz = triplane_T[2].sample(x.x, x.z)
        feat_x = hadamard_product(feat_xy, feat_yz, feat_xz)
        
        # Predict SDF, Beta, Geo Features
        s, beta, f_geo = MLPSDF(pos_enc_x, feat_x)
        
        # Transform to Opacity
        if s <= 0:
            sigma = 0.5 * exp(s / beta)
        else:
            sigma = 1.0 - 0.5 * exp(-s / beta)
            
        # Distance to next sample (handle last sample)
        if t_i == samples_t[-1]:
            delta = 0.0 # Or a small epsilon
        else:
            delta = samples_t[index_of(t_i) + 1] - t_i
            
        alpha = 1.0 - exp(-sigma * delta)
        
        # Predict Radiance
        pos_enc_v = positional_encoding(ray_direction)
        c = MLPc(pos_enc_v, f_geo)
        
        # Accumulate
        color = transmittance * alpha * c
        colors.append(color)
        alphas.append(alpha)
        transmittance *= (1.0 - alpha)
        
    # Sum colors
    final_color = sum(colors)
    return final_color
```

**Edge Cases and Pitfalls:**
- **Precision**: The exponential terms in the Laplacian CDF can underflow or overflow if $s/\beta$ is large. Clamping or careful initialization is required [S1].
- **Initialization**: Initializing `MLPSDF` as in SAL [4] is critical to avoid degenerate SDFs in early training [S1].
- **Spatially Varying Beta**: Unlike [45, 72], $\beta$ varies spatially. This requires regularization to prevent unstable variance values [S1].

## Operating characteristics
- **Time Complexity**: Depends on the number of samples $N$ and the cost of triplane feature gathering and MLP inference. Inverse CDF sampling adds overhead compared to uniform sampling [S1].
- **Memory Complexity**: Dominated by the triplane storage ($512 \times 512 \times 32 \times 3$ floats) and MLP weights [S1].
- **Strengths**: Tight surface extraction, lower rendering variance with stratification, high-fidelity geometry [S1].
- **Limitations**: Requires careful initialization and regularization of $\beta$. Inverse CDF sampling is computationally more expensive than uniform sampling [S1].
- **When to Use**: When high-fidelity geometry and accurate surface extraction are required, such as in 3D GANs or detailed scene reconstruction [S1].

## Background
This method builds on VolSDF [72] and StyleSDF [45], improving upon NeRF [38] and EG3D [7] by using a Laplacian CDF for opacity transformation and stratified sampling [S1]. It was introduced in "What You See is What You GAN" (CVPR 2024) [S1].
