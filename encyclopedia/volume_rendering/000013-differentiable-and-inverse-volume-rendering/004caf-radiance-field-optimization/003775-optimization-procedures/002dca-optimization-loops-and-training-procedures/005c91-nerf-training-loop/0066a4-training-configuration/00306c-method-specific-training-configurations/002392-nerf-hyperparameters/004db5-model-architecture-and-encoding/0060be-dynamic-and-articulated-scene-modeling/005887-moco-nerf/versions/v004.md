# MoCo-NeRF

Also called: Motion-Oriented Compositional Neural Radiance Fields

## Overview
MoCo-NeRF is a framework for free-viewpoint rendering of monocular human videos that models non-rigid body motions as radiance residual fields rather than spatial offsets [S1]. It separates the representation into a rigid canonical radiance field and a pose-dependent non-rigid residual field, allowing direct supervision from ground-truth pixel colors [S1]. Unlike offset-based strategies that suffer from high computational complexity and misaligned learning objectives, MoCo-NeRF reduces prediction range to the radiance space using rigid fields as a prior [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Monocular video frames, camera poses, and skeletal joint positions $J$ for each frame.
*   **Outputs:** Rendered RGB images for novel viewpoints.

**Data Structures:**
1.  **Skeletal Weights Volume Decoder:** Optimizes canonical skinning weights $w^c_k$ for $K$ joints [S1].
2.  **Multi-Hash Encoding (MHE):**
    *   **Single-Subject:** One global MHE $\psi_{hash}$ with 16 levels, feature dimension $H=2$ per level [S1].
    *   **Multi-Subject:** One global MHE $\psi_{hash}^G$ (4 levels, $H=2$) shared across subjects, and $N_s$ local MHEs $\{\psi_{hash}^i\}$ for subject-specific details [S1].
3.  **Learnable Base Code:** $S \in \mathbb{R}^{64}$, randomly initialized [S1].
4.  **Identity Codes:** $\{S_i\}_{i=1}^{N_s}$, learnable codes for multi-subject identification [S1].
5.  **MLP Decoders:**
    *   $M_{rigid}$: Predicts rigid color $\mathbf{c}$ and density $\sigma$ [S1].
    *   $M_{nr}$: Predicts residuals $\Delta \mathbf{c}, \Delta \sigma$ [S1].
6.  **Projection Matrices:** $W_p, W_Q, W_K, W_V$ for pose-embedded feature generation [S1].

**Numbered Steps:**

1.  **Canonical Transformation:** Transform observation point $\mathbf{x}$ to canonical point $\mathbf{x}_c$ using inverse linear blend skinning [S1]:
    $$ \mathbf{x}_c = \sum_{k=1}^K w^o_k (R_k \mathbf{x} + \mathbf{t}_k) $$
    where $w^o_k = \frac{w^c_k(R_k \mathbf{x} + \mathbf{t}_k)}{\sum_{j=1}^K w^c_j(R_j \mathbf{x} + \mathbf{t}_j)}$, $R_k, \mathbf{t}_k$ are rotation and translation of bone $k$, and $w^c_k$ are optimized canonical skinning weights [S1].

2.  **Rigid Branch Feature Query:** Query multiresolution volumetric features $\mathbf{f}_{\mathbf{x}_c}$ from MHE $\psi_{hash}$ [S1]:
    $$ \mathbf{f}_{\mathbf{x}_c} = \psi_{hash}(\mathbf{x}_c) $$
    For multi-subject, concatenate global features, sliced local features, and subject ID code $\mathbf{S}_i$ [S1]:
    $$ \mathbf{f}_{comb} = \psi_{hash}^G(\mathbf{x}_c) \oplus (\psi_{hash}^i(\mathbf{x}_c))^{:H} \oplus \mathbf{S}_i $$

3.  **Rigid Radiance Prediction:** Slice the first half ($H$ dimensions) of $\mathbf{f}_{\mathbf{x}_c}$ at each resolution level to compute $\mathbf{f}_{\mathbf{x}_c}^{:H}$. Predict rigid color $\mathbf{c}$ and density $\sigma$ using $M_{rigid}$ [S1]:
    $$ \mathbf{c}, \sigma = M_{rigid}(\mathbf{f}_{\mathbf{x}_c}^{:H}) $$
    (In multi-subject, use $\mathbf{f}_{comb}$ as input to $M_{rigid}$) [S1].

4.  **Non-Rigid Feature Preparation:** Use the full feature $\mathbf{f}_{\mathbf{x}_c}$ but freeze the first half representing canonical radiance. Denote the remaining optimized half as $\mathbf{f}_{\mathbf{x}_c}^*$ [S1].

5.  **Pose-Embedded Implicit Feature Generation:**
    a. Apply sinusoidal positional encoding $\gamma$ to 23 joint positions $J$:
    $$ \gamma(\mathbf{j}_i) = [\mathbf{j}_i, \sin(2^0 \pi \mathbf{j}_i), \cos(2^0 \pi \mathbf{j}_i), \dots, \sin(2^{L-1} \pi \mathbf{j}_i), \cos(2^{L-1} \pi \mathbf{j}_i)] $$
    where $L=10$ frequency bands [S1].
    b. Project encoded joints $\gamma(J) \in \mathbb{R}^{23 \times 63}$ to raw pose-embedded code $\mathbf{P}_{raw}$:
    $$ \mathbf{P}_{raw} = W_p \cdot \gamma(J) $$
    c. Generate query $\mathbf{P}_q$ from base code $S$, and key $\mathbf{P}_k$, value $\mathbf{P}_v$ from $\mathbf{P}_{raw}$:
    $$ \mathbf{P}_q = W_Q \cdot S, \quad \mathbf{P}_k = W_K \cdot \mathbf{P}_{raw}, \quad \mathbf{P}_v = W_V \cdot \mathbf{P}_{raw} $$
    d. Compute final implicit feature $\mathbf{P}_{nr}$ using cross-attention:
    $$ \mathbf{P}_{nr} = \text{softmax}(\mathbf{P}_q \cdot \mathbf{P}_k^\top) \cdot \mathbf{P}_v $$
    [S1].

6.  **Non-Rigid Residual Prediction:** Predict color and density residuals $\Delta \mathbf{c}, \Delta \sigma$ using $M_{nr}$ conditioned on $\mathbf{f}_{\mathbf{x}_c}^*$ and $\mathbf{P}_{nr}$ [S1]:
    $$ \Delta \mathbf{c}, \Delta \sigma = M_{nr}(\mathbf{f}_{\mathbf{x}_c}^*; \mathbf{P}_{nr}) $$
    [S1].

7.  **Compositional Rendering:** For each ray $\mathbf{r}$, query $M$ samples. Compute final RGB $\hat{C}_{final}$ using stratified sampling and volume rendering with compositional density $(\sigma + \Delta \sigma)$ and color $(\mathbf{c} + \Delta \mathbf{c})$ [S1]:
    $$ \hat{C}_{final}(\mathbf{r}) = \sum_{m=1}^M T_m (1 - \exp(-(\sigma_m + \Delta \sigma_m)\delta_m)) (\mathbf{c}_m + \Delta \mathbf{c}_m) $$
    where transmittance $T_m = \exp(-\sum_{n=1}^{m-1} \sigma_n \delta_n)$ and $\delta_m$ is the distance between adjacent samples [S1].
    Also compute $\hat{C}_{rigid}$ from $(\mathbf{c}, \sigma)$ for loss calculation [S1].

8.  **Optimization:**
    a. Sample $N_p$ patches per iteration. Render patches from $\hat{C}_{rigid}$ ($\hat{P}_k^r$) and $\hat{C}_{final}$ ($\hat{P}_k^f$) [S1].
    b. Compute LPIPS loss against ground truth patch $P_k^{GT}$ using pre-trained VGGNet:
    $$ \mathcal{L}_{LPIPS} = \text{LPIPS}(VGG(\hat{P}_k), VGG(P_k^{GT})) $$
    [S1].
    c. Compute MSE losses $\mathcal{L}_{MSE}^r, \mathcal{L}_{MSE}^f$ for rigid and final patches [S1].
    d. Compute SSIM loss $\mathcal{L}_{SSIM}^f$ only for final patches [S1].
    e. Total loss:
    $$ \mathcal{L}^o = \lambda \mathcal{L}^r + (1-\lambda) \mathcal{L}^f $$
    where $\mathcal{L}^r = \mathcal{L}_{LPIPS}^r + \mathcal{L}_{MSE}^r$ and $\mathcal{L}^f = \mathcal{L}_{LPIPS}^f + \mathcal{L}_{MSE}^f + \mathcal{L}_{SSIM}^f$ [S1].

**Parameters:**
*   $K$: Total number of joints (23) [S1].
*   $L$: Number of frequency bands in positional encoding ($L=10$) [S1].
*   $\lambda$: Hyperparameter balancing rigid and final loss ($\lambda=0.2$) [S1].
*   Optimizer: Adam with betas $(0.9, 0.99)$ [S1].
*   Learning Rate: $5 \times 10^{-5}$ for skeletal weights volume decoder, $5 \times 10^{-3}$ for all other components [S1].
*   MHE Levels: 16 levels with $H=2$ (local), 4 levels with $H=2$ (global) [S1].
*   Sampling: 6 patches of size $32 \times 32$ per iteration, 256 samples per ray [S1].

## Operating characteristics
*   **Time Complexity:** Training time is significantly reduced compared to offset-based methods. Single-subject training takes 1–2 hours on an RTX 3090 [S1]. Multi-subject training (6 subjects) takes ~2 hours on one RTX 3090 [S1].
*   **Memory Complexity:** Uses a single MHE for single-subject, or global + local MHEs for multi-subject. Memory usage is comparable to other NeRF variants but avoids storing large spatial offset fields [S1].
*   **Performance:** Achieves state-of-the-art PSNR/SSIM/LPIPS* on ZJU-MoCap and MonoCap datasets [S1]. Outperforms HumanNeRF, Instant-NVR, GauHuman, NHP, and GHuNeRF in quality and efficiency [S1].
*   **Strengths:** Direct color supervision for non-rigid motions; efficient training; supports multi-subject unified training [S1].
*   **Limitations:** Relies on accurate skeletal transformations; performance depends on the quality of the canonical T-pose representation [S1].

## Background
MoCo-NeRF was proposed by J. Kim et al. in 2024 [S1]. It addresses the limitations of spatial offset strategies in dynamic human modeling, which suffer from high computational complexity and misaligned learning objectives [S1]. The method builds on the principles of Neural Radiance Fields (NeRF) and linear blend skinning [S1]. It is used for free-viewpoint rendering of monocular human videos, evaluated on ZJU-MoCap and MonoCap datasets [S1].
