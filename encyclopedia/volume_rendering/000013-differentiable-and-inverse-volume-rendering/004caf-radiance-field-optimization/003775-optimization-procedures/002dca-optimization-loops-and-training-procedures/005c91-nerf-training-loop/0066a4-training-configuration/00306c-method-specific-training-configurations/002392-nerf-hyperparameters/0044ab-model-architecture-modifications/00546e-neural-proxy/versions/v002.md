# Neural Proxy

Also called: Neural Proxy Model

## Overview
Neural Proxy is a neural rendering method that represents photo-realistic targets as animatable proxies to enable the rendering of unseen animations without temporal learning [S1, unofficial]. It combines neural volume rendering with neural texture techniques, injecting a 3D mesh proxy into the scene to localize particles, thereby decoupling geometry animation from appearance learning [S1, unofficial]. Unlike NeRF, which ties content to continuous Cartesian coordinates making animation difficult, Neural Proxy uses an animatable mesh proxy allowing particles to move with the animation [S1, unofficial]. Unlike Neural Texture, which requires animated training samples to render unseen animations, Neural Proxy renders unseen animations without temporal learning by animating the proxy geometry [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Reference geometry (coarse mesh $\bar{M}$), UV coordinates for $\bar{M}$, offset parameters $\epsilon_{\rightarrow}, \epsilon_{\leftarrow}$, neural texture $\Omega_{Tex}$, neural renderer parameters $\theta_{NR}$.
*   **Outputs:** Rendered image $I$.

**Data Structures:**
*   **Coarse Geometry $\bar{M}$:** Defined by vertices $v_i$ and smoothed normals $n_i$ for $i=1 \dots N_v$.
*   **Proxy Shell:** Composed of an outward surface $M_{\rightarrow}$ and an inward surface $M_{\leftarrow}$.
    *   Vertices: $v_{i}^{\rightarrow} = v_i + n_i \cdot \epsilon_{\rightarrow}$ and $v_{i}^{\leftarrow} = v_i - n_i \cdot \epsilon_{\leftarrow}$.
    *   Constraints: $\epsilon_{\rightarrow}, \epsilon_{\leftarrow} \ge 0$ and $\epsilon_{\rightarrow} + \epsilon_{\leftarrow} > 0$.
*   **UV Coordinates:** Lifted to 3D shell space.
    *   $u_i^{\rightarrow} = (u_{2D}, w_{\rightarrow})$ where $w_{\rightarrow} = 1$ (outward shell label).
    *   $u_i^{\leftarrow} = (u_{2D}, w_{\leftarrow})$ where $w_{\leftarrow} = 0$ (inward shell label).
*   **Neural Texture $\Omega_{Tex}$:** A learnable feature map.
*   **Bilinear Sampler $f_{Bi}$:** Samples features from $\Omega_{Tex}$ based on UV coordinates.

**Steps:**
1.  **Proxy Construction:** Retrieve reference geometry $\bar{M}$ (e.g., via COLMAP or manual low-res mesh). Define vertices $v_i$ and normals $n_i$.
2.  **Shell Extrusion:** Construct the proxy volume by extruding $\bar{M}$ along normals to create outward surface $M_{\rightarrow}$ and inward surface $M_{\leftarrow}$ using offsets $\epsilon_{\rightarrow}$ and $\epsilon_{\leftarrow}$.
3.  **UV Lifting:** Assign 3D UV coordinates to the shell vertices. For each vertex $v_i$, lift its 2D UV coordinate $u_{2D}$ by appending a depth component $w$ indicating the shell layer ($1$ for outward, $0$ for inward).
4.  **Tetrahedralization:** Break prisms formed by the extrusion of triangles into three tetrahedra using the method from [PBFJ05] to enable Barycentric coordinate sampling within the shell volume.
5.  **Neural Texture Wrapping:** Wrap the proxy with the neural texture $\Omega_{Tex}$.
6.  **Particle Sampling:** For a ray $r$, sample particles.
    *   If the particle is within the proxy shell, use the **Neural Proxy Sampler** $S_p$.
    *   If outside, use a static sampler (e.g., standard NeRF).
    *   $S_p$ translates the Cartesian coordinate $x$ to Barycentric coordinates within the tetrahedra, maps to UV space, and samples features from $\Omega_{Tex}$ via $f_{Bi}$.
7.  **Rendering:** Compute color $c$ and density $\sigma$ using $S_p(x)$. The rendered image is computed as:
    $$ I = f_{NR}(f_{Bi}(U; \Omega_{Tex}); \theta_{NR}) $$
    Where $f_{NR}$ is the neural renderer and $\theta_{NR}$ are its parameters.

**Pseudocode:**

```python
def neural_proxy_render(ray, mesh, texture, offsets, renderer_params):
    """
    ray: Ray origin and direction
    mesh: Coarse mesh M_bar with vertices v_i and normals n_i
    texture: Neural texture Omega_Tex
    offsets: Tuple (epsilon_out, epsilon_in)
    renderer_params: Theta_NR
    """
    epsilon_out, epsilon_in = offsets
    
    # 1. Construct Proxy Shell
    # Calculate outward and inward vertices
    v_out = mesh.vertices + mesh.normals * epsilon_out
    v_in = mesh.vertices - mesh.normals * epsilon_in
    
    # 2. Define UV Coordinates for Shell
    # Lift 2D UV to 3D with depth labels
    # u_out = (u_2D, 1), u_in = (u_2D, 0)
    uv_out = stack(mesh.uv, ones_like(mesh.uv[:, :1]), axis=1)
    uv_in = stack(mesh.uv, zeros_like(mesh.uv[:, :1]), axis=1)
    
    # 3. Tetrahedralize Prisms (Simplified assumption for implementation)
    # In practice, decompose extruded triangles into tetrahedra [PBFJ05]
    tetrahedra = decompose_prisms(mesh.triangles, v_out, v_in)
    
    # 4. Sample along Ray
    # Determine intersection with proxy shell
    t_hit, tet_idx = ray_intersect_shell(ray, tetrahedra)
    
    if t_hit is not None:
        # 5. Map Cartesian to Barycentric to UV
        # Get point x on ray at t_hit
        x = ray.origin + ray.direction * t_hit
        
        # Find containing tetrahedron and compute Barycentric coords
        bary = compute_barycentric(x, tetrahedra[tet_idx])
        
        # Interpolate UV coordinates from tetrahedron vertices
        # Vertices of tet have associated UVs (either u_out or u_in)
        uv_sample = interpolate_uv(bary, tetrahedra[tet_idx].uvs)
        
        # 6. Sample Neural Texture
        # f_Bi samples from texture using UV
        features = bilinear_sample(texture, uv_sample)
        
        # 7. Render
        # S_p produces (c, sigma) from features
        color, density = neural_renderer(features, renderer_params)
    else:
        # Static background sampling (e.g., standard NeRF)
        color, density = static_sampler(ray)
        
    return color, density
```

**Parameters:**
*   $\epsilon_{\rightarrow}, \epsilon_{\leftarrow}$: Offset parameters for shell thickness. Must be set such that the shell encloses the target object. [S1, unofficial]
*   $w_{\rightarrow}, w_{\leftarrow}$: Depth labels for UV lifting (1 and 0 respectively). [S1, unofficial]

**Edge Cases and Pitfalls:**
*   **Shell Enclosure:** Offsets must be tuned such that the shell fully encloses the photo-realistic target to ensure relevant particles are contained. [S1, unofficial]
*   **Tetrahedralization:** Correct decomposition of prisms is required for valid Barycentric sampling. [S1, unofficial]
*   **Animation Generalization:** The method avoids training the renderer on animated frames, relying instead on the proxy's geometric animation. [S1, unofficial]

## Background
**Origin:** Proposed in "Neural Proxy: Empowering Neural Volume Rendering for Animation" [S1, unofficial].
**History:** The method addresses the lack of animation support in neural rendering. It combines concepts from Neural Volume Rendering (e.g., NeRF [MST* 20]) and Neural Texture [TZN19]. NeRF uses Cartesian coordinates, making animation difficult. Neural Texture uses learned feature maps but struggles with unseen animations without temporal learning. Neural Proxy bridges this by using an animatable mesh proxy.
**Usage:** Used for rendering photo-realistic targets in unseen animations without temporal learning.
