# NLR Baseline

Also called: Neural Lumigraph Representation Baseline

## Overview
The NLR Baseline serves as a reference implementation for Neural Lumigraph Representations, optimizing a neural network to predict density and color for novel view synthesis. It differs from its siblings by utilizing a specific neural architecture designed for lumigraph-like representations, distinct from the MLP-based NeRF [13271-nerf-training-setup.md] or the generative StyleGAN2 [12972-stylegan2-training-configuration.md] approaches. It operates within the standard differentiable volume rendering loop [52-volume-rendering.md], minimizing photometric loss between rendered and ground truth images.

## How it works
The NLR Baseline follows the shared principles of the parent family [13740-training-setup-and-baselines.md], relying on stochastic gradient descent to minimize Mean Squared Error (MSE) between rendered pixels and ground truth.

**Inputs and Outputs:**
*   **Input:** A set of training images with known camera poses.
*   **Output:** A trained neural network capable of rendering novel views.

**Data Structures:**
The specific internal data structures (e.g., voxel grids, hash tables) are not explicitly detailed in the provided sources [S1, unofficial]. The method relies on the NLR implementation provided by the original authors [3], which is wrapped for meta-learning in the MetaNLR variant.

**Steps:**
1.  **Ray Sampling:** Generate rays from camera poses through image pixels [13740-training-setup-and-baselines.md].
2.  **Point Sampling:** Sample 3D coordinates along these rays [13740-training-setup-and-baselines.md].
3.  **Network Query:** Evaluate the NLR neural network at sampled points to predict density ($\sigma$) and color ($\mathbf{c}$). The architecture is specific to NLR but not detailed in the sources [S1, unofficial].
4.  **Volume Rendering:** Compute final pixel color using the differentiable volume rendering integral [52-volume-rendering.md].
5.  **Backpropagation:** Update network weights based on the gradient of the MSE loss [13740-training-setup-and-baselines.md].

**Parameters:**
*   **Resolution:** Training and testing views are processed at 800x600 resolution [S1, unofficial].
*   **Iteration Time:** Approximately 2.21 seconds per iteration [S1, unofficial].
*   **Rendering Time:** Approximately 0.025 seconds per frame [S1, unofficial].

**Edge Cases and Pitfalls:**
*   The sources note that while NLR iterations are slower than NeRF (0.40 sec/iteration) or IDR (0.2 sec/iteration), NLR requires significantly fewer iterations to converge [S1, unofficial].
*   The implementation details of the NLR architecture itself are not provided in the source text [S1, unofficial].

## Subtopics

### MetaNLR Baseline
MetaNLR is a variant that wraps the NLR implementation with an outer meta-learning loop using Reptile [S1, unofficial]. It learns the initialization of the shape and color networks to enable fast specialization to new scenes [S1, unofficial]. It is chosen when few-shot adaptation to new scenes is required. It uses the same meta-training and meta-test scenes as the baseline method. The meta-learning rate is set to $5 \times 10^{-2}$ [S1, unofficial]. It performs specialization using the same training and testing views at 800x600 resolution [S1, unofficial]. The iteration time for MetaNLR++ (with shape optimization) is 7.69 seconds, while without shape optimization it is 2.19 seconds [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** NLR takes 2.21 seconds per iteration, which is slower than NeRF (0.40 sec/iteration) and IDR (0.2 sec/iteration) [S1, unofficial]. However, it converges in significantly fewer iterations because it optimizes the representation for multiple entire images instead of randomly selected rays [S1, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Rendering time is 0.025 seconds per frame [S1, unofficial].
*   **Strengths:** Fast convergence in terms of iteration count; high quality novel view synthesis results after a short amount of time [S1, unofficial].
*   **Limitations:** Higher per-iteration computational cost compared to some other methods [S1, unofficial].
*   **When to use:** When fast adaptation to new scenes (via MetaNLR) or high-quality synthesis with fewer iterations is prioritized over per-iteration speed.
*   **When not to use:** When per-iteration training speed is the primary constraint and convergence speed is less critical.

## Background
The NLR Baseline is based on the Neural Lumigraph Representation method [3]. The specific implementation details and timing results are documented in the paper "Fast Training of Neural Lumigraph Representations using Meta Learning" [S1, unofficial]. The method was compared against NeRF, IBRNet, SVS*, IDR, and NLR++/MetaNLR++ on the DTU dataset [S1, unofficial].
