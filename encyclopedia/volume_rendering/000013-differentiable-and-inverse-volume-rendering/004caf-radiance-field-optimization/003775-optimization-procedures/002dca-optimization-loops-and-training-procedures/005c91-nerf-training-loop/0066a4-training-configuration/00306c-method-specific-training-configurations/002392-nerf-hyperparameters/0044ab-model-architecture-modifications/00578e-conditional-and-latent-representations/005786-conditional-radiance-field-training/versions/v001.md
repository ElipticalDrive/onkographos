# Conditional Radiance Field Training

Also called: Conditional NeRF, Instance-conditioned NeRF

## Overview
Conditional Radiance Field Training is a method for modeling shape and appearance variations across multiple instances of an object category by training a single neural radiance field conditioned on instance-specific latent codes [S1]. It solves the problem of efficiently representing a dataset of varying objects (e.g., chairs) without training separate independent NeRFs for each instance, while maintaining rendering accuracy comparable to independent models [S1]. It differs from sibling methods like [DoF-NeRF](9432-dof-nerf.md) which focus on depth-of-field, or [NeRF-VPT](11770-nerf-vpt.md) which uses vision-language prompts, by explicitly injecting learned instance embeddings into the network inputs to disentangle geometry and appearance [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A dataset of $K$ object instances. For each instance $k$, a set of training rays $\mathcal{R}_k$ with corresponding ground truth colors $C(\mathbf{r})$. Two latent codes per instance: a shape code $\mathbf{z}_k^{(s)}$ and a color code $\mathbf{z}_k^{(c)}$.
*   **Outputs:** Rendered color $\hat{C}(\mathbf{r})$ for any ray $\mathbf{r}$ given the instance codes.

**Data Structures:**
*   **Shape Code $\mathbf{z}_k^{(s)}$:** A 32-dimensional vector.
*   **Color Code $\mathbf{z}_k^{(c)}$:** A 32-dimensional vector.
*   **Coarse Network $F_{coarse}$:** An MLP with 4 layers, 256 channels width, ReLU activations. Takes positional encoding $\gamma(\mathbf{x})$, shape code $\mathbf{z}_k^{(s)}$, and color code $\mathbf{z}_k^{(c)}$ as input. Outputs density $\sigma$ and a latent feature vector $\mathbf{h}$ [S1].
*   **Fine Network $F_{fine}$:** An MLP with 4 layers, 256 channels width, ReLU activations. Takes $\mathbf{h}$, $\gamma(\mathbf{x})$, view direction $\gamma(\mathbf{d})$, shape code $\mathbf{z}_k^{(s)}$, and color code $\mathbf{z}_k^{(c)}$ as input. Outputs color $\mathbf{c}$ [S1].
*   **Skip Connections:** The shape code and positional inputs are embedded and added via skip connections to intermediate layers, similar to the original NeRF architecture [S1].

**Numbered Steps:**
1.  **Initialization:** Initialize $F_{coarse}$, $F_{fine}$, and the set of codes $\{\mathbf{z}_k^{(s)}, \mathbf{z}_k^{(c)}\}_{k=1}^K$ for $K$ instances.
2.  **Instance Sampling:** For each training iteration, sample an object instance index $k$ uniformly from $\{1, \dots, K\}$ [S1].
3.  **Code Retrieval:** Retrieve the shape code $\mathbf{z}_k^{(s)}$ and color code $\mathbf{z}_k^{(c)}$ for the sampled instance [S1].
4.  **Ray Sampling:** Sample a batch of training rays $\mathcal{R}_k$ from the set of all rays belonging to instance $k$ [S1].
5.  **Coarse Network Forward Pass:**
    *   For each ray $\mathbf{r}$ in $\mathcal{R}_k$, sample points $\mathbf{x}_i$ using stratified sampling along the ray [S1].
    *   Compute positional encoding $\gamma(\mathbf{x}_i)$ and view direction encoding $\gamma(\mathbf{d})$ [S1].
    *   Input $\gamma(\mathbf{x}_i)$, $\mathbf{z}_k^{(s)}$, and $\mathbf{z}_k^{(c)}$ into $F_{coarse}$ to obtain density $\sigma_i$ and feature $\mathbf{h}_i$ [S1].
    *   Render coarse color $\hat{C}_{coarse}(\mathbf{r})$ using standard volume rendering with $\sigma_i$ and $\mathbf{h}_i$ [S1].
6.  **Hierarchical Sampling:** Use the density outputs $\sigma_i$ from the coarse network to sample a hierarchical volume of points for the fine network [S1].
7.  **Fine Network Forward Pass:**
    *   For each ray $\mathbf{r}$, input $\mathbf{h}_i$, $\gamma(\mathbf{x}_i)$, $\gamma(\mathbf{d})$, $\mathbf{z}_k^{(s)}$, and $\mathbf{z}_k^{(c)}$ into $F_{fine}$ to obtain color $\mathbf{c}_i$ [S1].
    *   Render fine color $\hat{C}_{fine}(\mathbf{r})$ using standard volume rendering [S1].
8.  **Loss Calculation:** Compute the photometric loss $L_{train}$ as the sum of squared Euclidean distances between predicted and ground truth colors for both coarse and fine networks [S1]:
    $$
    L_{train} = \sum_{k=1}^{K} \sum_{\mathbf{r} \in \mathcal{R}_k} \left( \|\hat{C}_{coarse}(\mathbf{r}, \mathbf{z}_k^{(s)}, \mathbf{z}_k^{(c)}) - C(\mathbf{r})\|_2^2 + \|\hat{C}_{fine}(\mathbf{r}, \mathbf{z}_k^{(s)}, \mathbf{z}_k^{(c)}) - C(\mathbf{r})\|_2^2 \right)
    $$
9.  **Optimization:** Update $F_{coarse}$, $F_{fine}$, and all codes $\{\mathbf{z}_k^{(s)}, \mathbf{z}_k^{(c)}\}$ using the Adam optimizer [S1].

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $10^{-4}$ for training [S1].
*   **Beta1:** 0.9 [S1].
*   **Beta2:** 0.999 [S1].
*   **Epsilon:** $10^{-8}$ [S1].
*   **Training Duration:** Until convergence, averaging 1 million iterations [S1].
*   **Code Dimension:** 32 dimensions for both shape and color codes [S1].
*   **Network Width:** 256 channels [S1].
*   **Network Depth:** 4 layers [S1].

**Edge Cases and Pitfalls:**
*   **Parameter Count:** Ablation studies increase layer width to keep the number of parameters approximately equal across experiments, ensuring fair comparison with independent NeRF baselines [S1].
*   **Editing vs. Training:** During editing, the coarse network is kept fixed, and only the fine network $F_{fine}$ and codes are optimized with a higher learning rate of $10^{-2}$ for 100 iterations [S1].

## Operating characteristics
*   **Time Complexity:** Training time is proportional to the number of instances $K$ and the number of iterations (avg 1M) [S1]. Each iteration processes a batch of rays for one instance [S1].
*   **Memory Complexity:** Memory usage scales with the number of instances $K$ due to the storage of $2 \times 32$-dimensional codes per instance, plus the fixed memory for the two MLPs [S1].
*   **Performance:** On the PhotoShapes dataset, the method matches the performance of training independent NeRF models for each instance in terms of PSNR and LPIPS [S1]. It scales well to large datasets, e.g., 626 instances [S1].
*   **Strengths:** Jointly models shape and appearance variations; efficient representation of multiple instances; supports editing by optimizing codes [S1].
*   **Limitations:** Requires a dataset of multiple instances of the same object category; joint optimization of codes and network weights can be sensitive to hyperparameters [S1].
*   **When to use:** When you have a dataset of multiple instances of an object category and want to model their variations efficiently.
*   **When not to use:** For single-instance scenes or scenes with no shared category structure.

## Background
The method was introduced in "Editing Conditional Radiance Fields" [S1]. It builds on the standard NeRF architecture  and the concept of conditional radiance fields. The authors evaluated the method on the PhotoShapes and Aubry chairs datasets [S1]. The approach was compared against single-instance NeRF baselines and GAN-based editing methods [S1].
