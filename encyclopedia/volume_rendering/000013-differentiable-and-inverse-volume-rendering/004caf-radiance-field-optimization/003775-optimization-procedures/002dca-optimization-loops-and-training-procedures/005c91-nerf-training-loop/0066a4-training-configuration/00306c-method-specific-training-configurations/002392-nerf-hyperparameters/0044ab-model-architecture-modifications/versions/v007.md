# Model Architecture Modifications

Also called: NeRF Architecture Variants, Neural Radiance Field Structural Changes

## Overview
Model Architecture Modifications extend the standard Neural Radiance Field (NeRF) framework by altering the input conditioning, output heads, or underlying implicit representation to handle specific constraints such as dynamic scenes, sparse inputs, or complex physical phenomena. Unlike standard NeRF, which maps 3D coordinates and viewing directions to density and color via a static Multi-Layer Perceptron (MLP), these methods introduce auxiliary networks, discrete spatial structures, or probabilistic outputs to decouple geometry from appearance, enable real-time inference, or incorporate external priors.

## Shared principles
The standard NeRF architecture [S6] consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$.

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation.
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs).

## Subtopics

### [DoF-NeRF](9432-dof-nerf.md)
DoF-NeRF extends the standard NeRF to simulate depth-of-field effects by optimizing aperture $K$ and focus distance $F$ parameters per view, enabling all-in-focus reconstruction from shallow DoF inputs. Choose this when inputs are blurred by lens optics and a sharp 3D representation is required.

### [NeRF-VPT](11770-nerf-vpt.md)
NeRF-VPT uses a cascading view prompt tuning paradigm where RGB images from previous rendering stages serve as visual prompts for subsequent networks, iteratively refining image quality without external priors. Choose this for sparse-view settings where standard NeRF lacks scene understanding.

### [MixRT](12401-mixrt.md)
MixRT is a hybrid representation combining a low-quality mesh, a view-dependent displacement map, and a compressed Instant-NGP hash table to enable real-time rendering on edge devices by offloading computation to standard graphics hardware. Choose this when real-time performance on constrained hardware is critical.

### [Activation Feature Density Approximation](12492-activation-feature-density-approximation.md)
This method estimates volumetric density directly from intermediate activation features of the coarse MLP, replacing expensive fine network evaluations with lightweight statistical computations. Choose this to accelerate training or inference by reducing the dependency on the fine network.

### [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md)
SDF Representations replace volumetric density with a continuous scalar field representing distance to the nearest surface, defining geometry via a zero-level set for sharper surface reconstruction. Choose this when explicit, watertight geometry is required over soft volumetric boundaries.

### [Volume-Augmented NeRF](12973-volume-augmented-nerf.md)
Volume-Augmented NeRF binds an explicit fluid volume value $v_i$ to each sample point, allowing density and color to be learned based on the spatial distribution from a differentiable fluid simulator. Choose this for rendering dynamic fluid scenes where density changes over time.

### [Neural-PIL Decomposition Architecture](12975-neural-pil-decomposition-architecture.md)
This architecture separates scene geometry, material properties (BRDF), and illumination into distinct networks, using a learned pre-integrated lighting network to render shaded colors. Choose this when input images have varying illumination and explicit reflectance decomposition is needed.

### [Feature Fields](12995-feature-fields.md)
Feature Fields generalize NeRF to predict arbitrary per-point feature signals $\mathbf{f}$ (e.g., semantic labels, object codes) in addition to color and density, lifting 2D observations into a consistent 3D representation. Choose this when encoding semantic or functional information into the 3D scene is required.

### [SAID-NeRF](13619-said-nerf.md)
SAID-NeRF exploits instance masks from Visual Foundation Models to enhance surface estimation of transparent objects by decomposing appearance into diffuse/specular components and enforcing higher surface densities. Choose this for reconstructing transparent objects where RGB alone is ambiguous.

### [MINE](13661-mine.md)
MINE models the source camera's frustum using a continuous depth Multiplane Image (MPI) representation, allowing novel view synthesis via homography warping after a single encoder pass. Choose this for efficient rendering of multiple novel views from a single source image.

### [IE-NeRF](13737-ie-nerf.md)
IE-NeRF separates static scene rendering from transient occlusions in "in-the-wild" scenes using image-dependent feature encodings and a pre-trained inpainting module, avoiding the need for a 3D transient field. Choose this for uncontrolled scenes with moving objects or transient artifacts.

### [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md)
This family replaces the continuous MLP with discrete structures like voxel grids, hash tables, or triplanes, storing features for direct interpolation to enable real-time differentiable volume rendering. Choose this for significant latency reduction and real-time inference capabilities.

### [Aleth-NeRF](13764-aleth-nerf.md)
Aleth-NeRF trains on under- and over-exposed images by introducing local and global concealing fields to suppress light transport, enabling synthesis of normal-light views from low-light inputs without paired data. Choose this for low-light or high-contrast scene reconstruction.

### [Unified Volumetric Avatar (UVA)](13784-unified-volumetric-avatar-uva.md)
UVA represents dynamic human avatars by anchoring structured latent codes to a deformable mesh in canonical space, enabling local editing of geometry and texture while supporting novel view synthesis. Choose this for dynamic human avatars requiring local editing capabilities.

### [Gear-NeRF](13848-gear-nerf.md)
Gear-NeRF leverages semantic segmentation to stratify dynamic scenes into motion-based 'gears', assigning higher resolution to regions with larger motion scales for efficient 4D sampling. Choose this for dynamic scenes with varying motion complexity.

### [Transformer and Vision Model Integration](13911-transformer-and-vision-model-integration.md)
This family integrates Vision Transformers (ViT) into NeRF to leverage global semantic understanding and long-range dependencies, solving limitations of MLP-based NeRFs in single-image inputs or occlusions. Choose this for generalizable reconstruction or scenes with complex occlusions.

### [Human and Specific Subject Modeling](13997-human-and-specific-subject-modeling.md)
Methods in this family specialize NeRF architectures for human subjects, often incorporating skeletal priors or deformation fields to handle non-rigid motion and pose-dependent appearance. Choose this for high-fidelity human reconstruction and animation.

### [OPONeRF](14014-oponerf.md)
OPONeRF personalizes plenoptic mapping parameters for each sampled 3D point by dynamically conditioning network weights on the point's representation, handling test-time scene changes and perturbations. Choose this for robustness against motion, illumination changes, or contamination.

### [Mixer-NeRF](14073-mixer-nerf.md)
Mixer-NeRF addresses blurry details in standard NeRF by introducing a hybrid spatial feature learning module (MLCA) and a squeeze-and-excitation (SE) network to mix spatial and channel features before MLP inference. Choose this when high-frequency detail preservation is critical.

### [SCALAR-NeRF](14267-scalar-nerf.md)
SCALAR-NeRF is a coarse-to-fine framework for large-scale scenes that decomposes the environment into spatial blocks, using a shared global decoder and reference-image-based fusion to avoid "foggy" artifacts. Choose this for training large-scale scenes on a single GPU.

### [Sparse View and Few-Shot Optimization](14428-sparse-view-and-few-shot-optimization.md)
These techniques mitigate overfitting and geometry breakdown in NeRF trained with drastically reduced viewpoints ($|S| < 20$) through in-situ regularization or deformable sampling. Choose this when input data is extremely sparse.

### [Mixture-of-Experts and Modular Architectures](14429-mixture-of-experts-and-modular-architectures.md)
This family replaces the single continuous NeRF function with multiple specialized networks (experts) or parallel streams to improve compression, training speed, or representation capacity. Choose this for complex scenes requiring specialized handling of different regions or features.

### [Uncertainty and Reliability](14487-uncertainty-and-reliability.md)
Uncertainty methods extend NeRF to quantify prediction confidence by modeling the scene as a probabilistic entity, providing pixel-level reliability metrics for color and depth. Choose this for applications requiring robust filtering or conformal prediction.

### [Object Decomposition and Composition](14518-object-decomposition-and-composition.md)
These methods explicitly separate a scene into distinct semantic or geometric object instances, enabling instance-level editing, manipulation, and amodal segmentation. Choose this when structural decomposition for editing is required.

### [Lighting and Appearance Models](14522-lighting-and-appearance-models.md)
Lighting models decouple scene geometry from illumination variations by learning implicit appearance embeddings or replacing the view-dependent MLP with explicit lighting queries. Choose this for real-world image collections with varying lighting and shadows.

### [Optimization and Training Procedures](14565-optimization-and-training-procedures.md)
This family covers algorithmic procedures for optimizing NeRF, including structural modifications to the optimization scope such as skipping expensive evaluations for empty rays. Choose this for improving training efficiency and convergence.

### [Image Enhancement and Restoration Methods](14566-image-enhancement-and-restoration-methods.md)
These methods modify the training pipeline to reconstruct sharp details from blurry or degraded inputs by explicitly modeling the degradation process during rendering. Choose this when input images are low-resolution or contain blur.

### [Modular, Hierarchical, and Latent Architectures](14567-modular-hierarchical-and-latent-architectures.md)
This family extends NeRF to handle non-rigid deformation with topological changes (e.g., HyperNeRF) or hierarchical scene structures (e.g., Strata-NeRF) using latent codes or higher-dimensional spaces. Choose this for complex dynamic or stratified scenes.

### [NeRF-W](14630-nerf-w.md)
NeRF-W handles unconstrained "in-the-wild" photo collections by disentangling shared static geometry from image-dependent transient elements and photometric variations using learned embeddings. Choose this for reconstructing scenes with moving objects and lighting changes.

### [Generalizable Implicit Reconstruction with SRDF](14760-generalizable-implicit-reconstruction-with-srdf.md)
VolRecon uses a Signed Ray Distance Function (SRDF) and a ray transformer to aggregate multi-view features, addressing over-smoothing in generalizable implicit reconstruction. Choose this for generalizable reconstruction with fine details and low noise.

### [Neural Lumigraph Rendering](15006-neural-lumigraph-rendering.md)
Neural Lumigraph Rendering jointly optimizes an implicit SDF for shape and a radiance field for appearance, exporting a high-resolution surface mesh for real-time rendering. Choose this for real-time rendering of static scenes with view-dependent appearance.

### [MuRF (Multi-Baseline Radiance Fields)](15007-murf-multi-baseline-radiance-fields.md)
MuRF is a feed-forward method that constructs a target view frustum volume aligned with the target camera, using a 3D context-aware convolutional decoder to handle large baselines. Choose this for sparse view synthesis with large baseline variations.

### [Gaussian and Primitive-Based Representations](15011-gaussian-and-primitive-based-representations.md)
This family replaces the continuous MLP with discrete geometric primitives or explicit Gaussian distributions, improving rendering efficiency and geometric fidelity via alpha-blended primitives. Choose this for high-efficiency rendering with explicit geometry.

#### NeRF-VAE
- [S1] A generative NeRF model that generalizes to out-of-distribution scenes and removes the need to train on each scene from scratch.
- [S1] The NeRF renderer is conditioned on a latent code. This latent code is trained using Iterative Amortized Inference and a ResNet encoder.
- [S1] An attention-based scene function is introduced instead of the typical MLP.
- [S1] Outperforms baseline NeRF with a low number of scene views (5-20), but is outperformed by baseline NeRF when a large number of views are available (100+) due to lower scene expressivity.

#### PIE-NeRF
- [S1] A pipeline integrating physics-based elastodynamic simulation with a neural radiance field representation, using a meshless discretisation based on quadratic generalized moving least squares on top of the density field of a NeRF.
- [S1] Enables large deformations and nonlinear hyperelastic material simulation directly on the implicit representation and supports interactive manipulation of real-world captured scenes with complex geometries.

#### KiloNeRF-style Grid Distillation
- [S4, unofficial] Distills a large teacher NeRF into a spatially partitioned grid of tiny MLPs to enable fast, adaptive evaluation by mapping 3D positions to local student networks.
- [S4, unofficial] Initialize a dictionary mapping 3D grid cell indices (i,j,k) to TinyMLP instances.
- [S4, unofficial] For each training iteration, sample a random ray and generate num_samples stratified samples along it.
- [S4, unofficial] Compute the grid cell index for each sample by normalizing its position within the bounding box and scaling by grid resolution.
- [S4, unofficial] Accumulate L2 loss between student and teacher outputs across all samples.
- [S4, unofficial] Update all grid MLPs using the accumulated loss and the configured learning rate.
- [S4, unofficial] grid_resolution: 3D tuple defining the number of cells per axis, e.g., (16,16,16).
- [S4, unofficial] num_distill_iterations: Number of distillation optimization steps, e.g., 1000.
- [S4, unofficial] num_samples: Number of stratified samples per ray, e.g., 384.
- [S4, unofficial] learning_rate: Optimization step size for grid MLP updates, e.g., 1e-3.
- [S4, unofficial] bmin, bmax: Axis-aligned bounding box defining the scene bounds, e.g., [0,0,0] and [1,1,1].

#### NeRF-Editing
- [S6] The first mesh-based shape deformation method, leveraging explicit representations for scene geometry edits and implicit representations for realistic rendering effects.

- [S6] A method employing a point cloud-guided NeRF model for shape manipulation, leveraging K-D trees and deterministic integration strategy for accurate point cloud-based rendering, with Phong reflection modeling to enhance color fidelity and geometric detail.

#### Shared G-MLP
- [S7] A shared geometry MLP that enables the constraint of multi-view consistency to be propagated from the NeRF branch to the detection branch.
- [S7] Without the shared G-MLP, performance drops from 50.1 to 48.1 mAP@.25, as the influence of multi-view consistency is only propagated into the image backbone.

## Background
The original NeRF architecture by Mildenhall et al. [1] employed a hierarchical rendering approach with two networks (coarse and fine) to improve computational efficiency. Subsequent works have focused on accelerating training and inference, with many efforts falling into the categories of architectural modifications, optimization procedures, and representation substitutions. The standard implementation uses dense layers with ReLU activations, with default parameters including a network depth of 8 layers and 256 channels per layer [S3, unofficial].
