# Voxel and Sparse Grid Representations

Also called: Grid-based NeRF, Hash Encoding, Triplane NeRF, Sparse Voxel Octrees

## Overview
Voxel and Sparse Grid Representations replace the continuous Multi-Layer Perceptron (MLP) function of standard NeRF with discrete spatial structures (voxel grids, hash tables, or triplanes) to store volume density and appearance features [14428-sparse-view-and-few-shot-optimization.md]. This substitution enables real-time differentiable volume rendering by retrieving features via interpolation rather than heavy feed-forward computation, significantly reducing latency while maintaining memory efficiency [S1]. Unlike MLP-based approaches that require evaluating a network for every sample point, these methods map 3D coordinates directly to feature vectors, allowing for scalable training on large scenes and efficient inference on consumer hardware [S1].

## Shared principles
The family shares the mechanism of substituting the implicit coordinate-to-color/density mapping $f_{MLP}(\mathbf{x}, \mathbf{d})$ with an explicit spatial data structure $G(\mathbf{x})$.

1.  **Spatial Discretization:** The 3D scene is partitioned into a grid, hash table, or set of planes. Each element in the structure stores learnable parameters (features, density, or SH coefficients).
2.  **Feature Retrieval:** For a sample point $\mathbf{x}$ on a ray, features are retrieved by querying the structure. This typically involves:
    *   **Trilinear Interpolation:** For dense or sparse voxel grids, features are interpolated from the 8 nearest voxels [S1].
    *   **Hashing:** For sparse hash tables, coordinates are hashed to indices in a lookup table, often with multi-resolution layers [S1].
    *   **Bilinear Interpolation:** For triplane representations, 3D points are projected onto 2D planes, and features are interpolated from the 4 nearest grid points on each plane [S1].
3.  **Differentiable Rendering:** The retrieved features (density $\sigma$ and color/view-dependent parameters) are used in the standard differentiable volume rendering equation:
    $$
    \hat{C}(r) = \sum_{k=1}^{N} w_k \mathbf{c}_k, \quad w_k = T_k \alpha_k, \quad T_k = \prod_{j=1}^{k-1} (1 - \alpha_j)
    $$
    where $\alpha_k = 1 - e^{-\sigma_k \delta_k}$ [S1]. The gradients flow back through the interpolation and rendering steps to update the grid features.

## Subtopics

### [Voxel-based Radiance Fields](11470-voxel-based-radiance-fields.md)
Replaces the MLP with discrete 3D voxel grids storing density and Spherical Harmonic (SH) coefficients. It uses trilinear interpolation for real-time rendering. Choose this for standard real-time NeRF applications where memory is not the primary constraint for very large scenes.

### [Neural Multi-View Image Reconstruction with Hash Encoding](13013-neural-multi-view-image-reconstruction-with-hash-encoding.md)
Uses a multi-resolution hash table for geometry (SDF) and a separate light field network for color. It distinguishes itself by using SDF thresholding for explicit mesh extraction and sparse storage, reducing memory usage compared to dense voxels. Choose this when explicit surface reconstruction is required or when memory efficiency for high-frequency details is critical.

### [G-NeLF](13480-g-nelf.md)
A grid-based NeLF that predicts ray color directly using a hash-based multi-resolution tri-plane and an LSTM, bypassing explicit volume density modeling. It achieves comparable quality with ~1/10th the parameters of Instant-NGP. Choose this for extreme parameter efficiency and when sequential inference is acceptable.

### [SCALAR-NeRF](14267-scalar-nerf.md)
A coarse-to-fine framework for large-scale scenes that partitions the scene into blocks, trains a shared decoder from a coarse global hash model, and fuses results using the global model to avoid "foggy" artifacts. Choose this for large-scale scene reconstruction on a single GPU where Block-NeRF's foggy appearance is unacceptable.

### [TriDF](14761-tridf.md)
A hybrid explicit-implicit representation for few-shot novel view synthesis (e.g., 3 images). It decouples color (explicit triplanes) and density (implicit MLP) to reduce computational burden. Choose this for remote sensing or sparse-view scenarios where standard triplanes fail due to insufficient supervision.

### [Tile and Slide Framework](15219-tile-and-slide-framework.md)
An out-of-core method for large-scale Earth observation (10km x 10km) that partitions the scene into non-overlapping 3D tiles, each with an independent NeRF. It uses a 2x2 sliding window and segmented sampling to fit within single-GPU memory. Choose this for massive scenes that exceed the memory capacity of any single monolithic NeRF representation.

## Background
The shift from MLPs to grid-based representations was driven by the need for real-time rendering and scalability. Standard NeRF [14469-nerf.md] is slow due to MLP evaluation per sample. Early voxel-based methods [11470-voxel-based-radiance-fields.md] demonstrated that trilinear interpolation could accelerate rendering by orders of magnitude. Hash encoding [13013-neural-multi-view-image-reconstruction-with-hash-encoding.md] (e.g., Instant-NGP) further improved memory efficiency by sparsely storing features. Triplane representations [14761-tridf.md] and large-scale tiling [15219-tile-and-slide-framework.md] extended these concepts to handle few-shot and city-scale scenes, respectively.
