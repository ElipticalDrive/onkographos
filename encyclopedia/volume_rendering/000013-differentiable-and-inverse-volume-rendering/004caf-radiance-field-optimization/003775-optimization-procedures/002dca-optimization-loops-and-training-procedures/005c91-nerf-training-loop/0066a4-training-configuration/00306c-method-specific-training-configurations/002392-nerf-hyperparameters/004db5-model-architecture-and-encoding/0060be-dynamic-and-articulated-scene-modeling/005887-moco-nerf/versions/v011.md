# MoCo-NeRF

Also called: Motion-Oriented Compositional Neural Radiance Fields

## Overview
MoCo-NeRF is a framework for free-viewpoint rendering of monocular human videos that models non-rigid body motions as radiance residual fields rather than spatial offsets, using rigid skeletal transformations as a prior [S1]. It decomposes the representation into a rigid branch learning a canonical T-pose radiance field and a non-rigid branch optimizing pose-driven radiance residuals, allowing direct supervision from ground-truth pixel colors [S1]. Unlike offset-based strategies that suffer from high computational complexity and misaligned learning objectives, MoCo-NeRF reduces prediction range to the radiance space, achieving state-of-the-art performance with significantly less training time [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Monocular video frames of a dynamic human subject; camera poses; skeletal joint positions $J$ for each frame; ground-truth image patches.
*   **Outputs:** Rendered RGB images for novel viewpoints; learned radiance fields (rigid and non-rigid).

**Data Structures:**
*   **Skeletal Weights Volume Decoder:** Optimizes canonical skinning weights $w^c_k$ for $K$ joints [S1].
*   **Multi-Hash Encoding (MHE):** A multiresolution hash grid. For single-subject: one MHE $\psi_{hash}$ with 16 levels, feature dimension $H=2$ per level [S1]. For multi-subject: one global MHE $\psi^G_{hash}$ (4 levels, $H=2$) and $N_s$ local MHEs $\{\psi^i_{hash}\}$ (16 levels, $H=2$) [S1].
*   **Learnable Base Code:** $S \in \mathbb{R}^{64}$, randomly initialized [S1].
*   **Identity Codes:** $\{S_i\}_{i=1}^{N_s}$, learnable vectors for multi-subject ID [S1].
*   **MLP Decoders:**
    *   $M_{rigid}$: Predicts rigid color $c$ and density $\sigma$ [S1].
    *   $M_{nr}$: Predicts residuals $\Delta c, \Delta \sigma$ [S1].
*   **Projection Matrices:** $W_p, W_Q, W_K, W_V$ for pose-embedded feature generation [S1].

**Numbered Steps:**

1.  **Canonical Transformation:** Transform an observation point $\mathbf{x}$ to a canonical point $\mathbf{x}_c$ using inverse linear blend skinning [S1]:
    $$ \mathbf{x}_c = \sum_{k=1}^K w^o_k (R_k \mathbf{x} + \mathbf{t}_k) $$
    where $w^o_k = \frac{w^c_k(R_k \mathbf{x} + \mathbf{t}_k)}{\sum_{j=1}^K w^c_j(R_j \mathbf{x} + \mathbf{t}_j)}$, $R_k, \mathbf{t}_k$ are rotation and translation of bone $k$, and $w^c_k$ are optimized canonical skinning weights [S1].

2.  **Rigid Branch Feature Query:** Query multiresolution volumetric features $\mathbf{f}_{\mathbf{x}_c}$ from the MHE $\psi_{hash}$ [S1]:
    $$ \mathbf{f}_{\mathbf{x}_c} = \psi_{hash}(\mathbf{x}_c) $$
    For multi-subject $i$, concatenate global features, sliced local features, and subject ID code $S_i$:
    $$ \mathbf{f}_{comb} = \psi^G_{hash}(\mathbf{x}_c) \oplus (\psi^i_{hash}(\mathbf{x}_c))^{:H} \oplus S_i $$
    where $H=2$ is the feature dimension [S1].

3.  **Rigid Branch Prediction:** Slice the first half ($H$ dimensions) of the features at each resolution level to compute $\mathbf{f}^{:H}_{\mathbf{x}_c}$ [S1]. Predict rigid color $c$ and density $\sigma$ using MLP $M_{rigid}$ [S1]:
    $$ c, \sigma = M_{rigid}(\mathbf{f}^{:H}_{\mathbf{x}_c}) $$
    For multi-subject, use $\mathbf{f}_{comb}$ [S1].

4.  **Non-Rigid Branch Feature Preparation:** Use the full feature $\mathbf{f}_{\mathbf{x}_c}$ (not sliced). Freeze the first half representing canonical radiance. Denote the remaining optimized half as $\mathbf{f}^*_{\mathbf{x}_c}$ [S1].

5.  **Pose-Embedded Implicit Feature Generation:**
    a. Initialize learnable base code $S \in \mathbb{R}^{64}$ [S1].
    b. Apply sinusoidal positional encoding $\gamma$ to 23 joint positions $J=\{j_i\}_{i=1}^{23}$ with $L=10$ frequency bands [S1]:
        $$ \gamma(j_i) = [j_i, \sin(2^0 \pi j_i), \cos(2^0 \pi j_i), \dots, \sin(2^{L-1} \pi j_i), \cos(2^{L-1} \pi j_i)] $$
        Resulting in $\gamma(J) \in \mathbb{R}^{23 \times 63}$ [S1].
    c. Project encoded joints to raw pose-embedded code $\mathbf{P}_{raw}$ using projection matrix $W_p$ [S1]:
        $$ \mathbf{P}_{raw} = W_p \cdot \gamma(J) $$
    d. Generate query $\mathbf{P}_q$ from $S$, and key $\mathbf{P}_k$, value $\mathbf{P}_v$ from $\mathbf{P}_{raw}$ via linear projections [S1]:
        $$ \mathbf{P}_q = W_Q \cdot S, \quad \mathbf{P}_k = W_K \cdot \mathbf{P}_{raw}, \quad \mathbf{P}_v = W_V \cdot \mathbf{P}_{raw} $$
    e. Compute final implicit feature $\mathbf{P}_{nr}$ using cross-attention [S1]:
        $$ \mathbf{P}_{nr} = \text{softmax}(\mathbf{P}_q \cdot \mathbf{P}_k^\top) \cdot \mathbf{P}_v $$

6.  **Non-Rigid Branch Prediction:** Predict color and density residuals $\Delta c, \Delta \sigma$ using MLP $M_{nr}$ conditioned on $\mathbf{f}^*_{\mathbf{x}_c}$ and $\mathbf{P}_{nr}$ [S1]:
    $$ \Delta c, \Delta \sigma = M_{nr}(\mathbf{f}^*_{\mathbf{x}_c}; \mathbf{P}_{nr}) $$

7.  **Compositional Rendering:** For each ray $\mathbf{r}$, query $M$ samples. Compute final RGB $C_{final}$ using stratified sampling and volume rendering with compositional density $(\sigma + \Delta \sigma)$ and color $(c + \Delta c)$ [S1]:
    $$ C_{final}(\mathbf{r}) = \sum_{m=1}^M T_m (1 - \exp(-(\sigma_m + \Delta \sigma_m)\delta_m)) (c_m + \Delta c_m) $$
    where transmittance $T_m = \exp(-\sum_{n=1}^{m-1} \sigma_n \delta_n)$ and $\delta_m$ is the distance between adjacent samples [S1]. Also compute $C_{rigid}$ from $(c, \sigma)$ for loss calculation [S1].

8.  **Optimization:**
    a. Sample $N_p$ patches per iteration. Render patches from $C_{rigid}$ ($\hat{P}^r_k$) and $C_{final}$ ($\hat{P}^f_k$) [S1].
    b. Compute LPIPS loss using pre-trained VGGNet against ground truth patch $P^{GT}_k$ [S1]:
        $$ \mathcal{L}_{LPIPS} = \text{LPIPS}(VGG(\hat{P}), VGG(P^{GT})) $$
    c. Compute MSE losses $\mathcal{L}^r_{MSE}, \mathcal{L}^f_{MSE}$ for rigid and final patches [S1].
    d. Compute SSIM loss $\mathcal{L}^f_{SSIM}$ only for final patches [S1].
    e. Total loss $\mathcal{L}^o$ with hyperparameter $\lambda=0.2$ [S1]:
        $$ \mathcal{L}^o = \lambda \mathcal{L}^r + (1-\lambda) \mathcal{L}^f $$
        $$ \mathcal{L}^r = \mathcal{L}^r_{LPIPS} + \mathcal{L}^r_{MSE}, \quad \mathcal{L}^f = \mathcal{L}^f_{LPIPS} + \mathcal{L}^f_{MSE} + \mathcal{L}^f_{SSIM} $$

**Parameters:**
*   $K$: Total number of joints (typically 23) [S1].
*   $L$: Number of frequency bands in sinusoidal positional encoding (typically 10) [S1].
*   $\lambda$: Hyperparameter for balancing rigid and final loss terms (typically 0.2) [S1].
*   Optimizer: Adam with betas (0.9, 0.99) [S1].
*   Learning rate: $5 \times 10^{-5}$ for skeletal weights volume decoder, $5 \times 10^{-3}$ for all other components [S1].
*   MHE configuration: 16 levels with feature dimension $H=2$; global MHE uses 4 levels with $H=2$ [S1].
*   Sampling: 6 patches of size $32 \times 32$ per iteration, with 256 samples per ray [S1].

**Edge Cases and Pitfalls:**
*   Spatial offset strategies suffer from high computational complexity because a single spatial offset spans an unbounded range and is unique for every 3D point across all input frames and body poses [S1].
*   Spatial offset strategies suffer from misaligned learning objectives because the learning objective of spatial offsets is not directly aligned with conventional RGB-based supervision [S1].
*   MoCo-NeRF avoids these by modeling non-rigid motions as radiance residuals [S1].

## Operating characteristics
*   **Time Complexity:** Training time is significantly reduced compared to offset-based methods. Single-subject training takes 1–2 hours on an RTX 3090 GPU [S1]. Multi-subject training (6 subjects) takes ~2 hours on one RTX 3090 GPU [S1].
*   **Memory Complexity:** Uses a single MHE for single-subject, and global + local MHEs for multi-subject. Memory usage is comparable to other hash-based NeRFs but optimized for dynamic content [S1].
*   **Measured Performance:**
    *   Single-subject (ZJU-MoCap subjects 377, 386, 387, 392, 393, 394; 23 views: 1 train, 22 eval): PSNR 31.06, SSIM 0.9734, LPIPS* 28.83 [S1].
    *   Multi-subject (ZJU-MoCap subjects 377, 386, 392): PSNR 31.97, SSIM 0.9781, LPIPS* 24.54 [S1].
*   **Scaling:** Supports unified training of multiple subjects within a single framework without significant increase in training time [S1].
*   **Strengths:** Direct color supervision for non-rigid motions; high-fidelity rendering of cloth dynamics; efficient training; multi-subject support.
*   **Limitations:** Requires skeletal joint positions as input; relies on accurate inverse linear blend skinning.
*   **When to use:** Free-viewpoint rendering of dynamic humans from monocular videos where training time and non-rigid motion fidelity are critical.
*   **When not to use:** Static scenes (use standard NeRF); scenes with complex non-human non-rigid motions without skeletal priors.

## Background
MoCo-NeRF was proposed by J. Kim et al. in the paper "Motion-Oriented Compositional Neural Radiance Fields for Monocular Dynamic Human Modeling" [S1]. It addresses the limitations of spatial offset-based methods for modeling non-rigid motions in dynamic human rendering, such as high computational complexity and misaligned learning objectives [S1]. The method was evaluated on the ZJU-MoCap and MonoCap datasets [S1].
