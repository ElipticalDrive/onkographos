# DONeRF

Also called: Depth Oracle Neural Radiance Fields, DONeRF Training Configuration, DONeRF training setup, Depth Oracle Network, DoNeRF

## Overview
DONeRF is a training configuration and architectural variant of Neural Radiance Fields (NeRF) designed for real-time rendering by replacing standard dense raymarching with a two-network pipeline: a depth oracle network and a shading network [S3]. It solves the prohibitive computational cost of NeRF by using the oracle to predict sample locations, allowing the shading network to accumulate color using only a few samples per ray (typically 2–16) [S3]. It sets itself apart from standard NeRF by explicitly decoupling geometry estimation from shading, using a classification-based oracle to guide sparse sampling, and employing a non-linear space warping to handle large depth ranges [S3].

## How it works
DONeRF consists of two distinct neural networks trained sequentially. The depth oracle network predicts sample locations along a ray, and the shading network computes color and density at those locations [S1][S3].

### Inputs and Outputs
*   **Inputs:** Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$, and optionally ground truth depth maps (for training).
*   **Outputs:** Rendered RGB color $\mathbf{C}(\mathbf{r})$ and accumulated opacity.

### Data Structures
1.  **View Cell:** A bounding box with a primary orientation and maximum viewing angle, defining the region of interest for a set of cameras [S3].
2.  **Depth Oracle Network:** An 8-layer MLP with 256 hidden units per layer, ReLU activation, and no positional encoding [S1].
3.  **Shading Network:** An 8-layer MLP with 256 hidden units per layer, ReLU activation, using positional encoding [S1].

### Numbered Steps

1.  **Ray Unification:** Transform ray origins and directions into a unified space relative to the view cell to reduce input ambiguity [S3].
2.  **Depth Oracle Forward Pass:**
    *   Concatenate the unified 3D position $\mathbf{x}$ and view direction $\mathbf{d}$.
    *   Pass through the Depth Oracle MLP.
    *   The oracle outputs a classification vector representing discretized depth bins along the ray [S3].
3.  **Sample Selection:**
    *   Select $N_s$ sample indices from the oracle's classification output [S1].
    *   The number of samples $N_s$ is a hyperparameter (e.g., DONeRF-2, DONeRF-4, DONeRF-16) [S3].
4.  **Space Warping:**
    *   Transform the selected sample positions logarithmically.
    *   Warp the samples towards the view cell to better capture high-frequency details in the foreground and background [S3].
5.  **Shading Network Forward Pass:**
    *   Apply positional encoding $\gamma(\cdot)$ to the warped 3D positions $\mathbf{x}$ and directions $\mathbf{d}$ [S1].
    *   $\gamma(\mathbf{x})$ is a 63-dimensional vector; $\gamma(\mathbf{d})$ is a 27-dimensional vector [S1].
    *   Pass $\gamma(\mathbf{x})$ through the first layer of the Shading MLP.
    *   Concatenate $\gamma(\mathbf{d})$ to the feature vector before the last layer [S1].
    *   Output volume density $\sigma \in \mathbb{R}^+$ and color $\mathbf{c} \in \mathbb{R}^3$ for each sample [S1].
6.  **Volume Rendering:**
    *   Compute opacity $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ and transmittance $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_i)$ for the selected samples [Parent].
    *   Accumulate color: $\hat{C}(\mathbf{r}) = \sum_{i=1}^{N_s} T_i \alpha_i \mathbf{c}_i$ [Parent].

### Formulas
*   **Opacity Loss ($\text{loss}_O$):** Used to prevent dark pixel artifacts when rays do not accumulate to full opacity [S3].
    $$
    \text{loss}_O = \begin{cases} 
    0, & \text{if } \sum_{i=1}^{N_s} \delta_i \geq 1 \\
    \left( \left( \sum_{i=1}^{N_s} \delta_i \right) - 1 \right)^2, & \text{otherwise}
    \end{cases}
    $$
    where $\delta_i$ is the distance between samples (or distance to surface if using depth-based sampling) and $N_s$ is the number of samples per ray [S3].

*   **Total Loss:**
    $$
    \text{loss} = \alpha \cdot \text{loss}_{\text{MSE}} + \beta \cdot \text{loss}_O
    $$
    where $\text{loss}_{\text{MSE}}$ is the mean squared error between rendered and ground truth RGB colors [S3].

*   **# Run Metric:**
    $$
    \# \text{Run} = 1 + \frac{N_s}{N_p}
    $$
    where $N_s$ is the number of samples selected by the oracle and $N_p$ is the number of grouped samples (in standard DONeRF, $N_p=1$) [S1].

### Parameters
*   **Network Architecture:** Both networks have 8 hidden layers with 256 hidden units [S3].
*   **Training Schedule:**
    1.  Train Depth Oracle for 300,000 iterations [S3].
    2.  Train Shading Network for 300,000 iterations using oracle predictions [S3].
*   **Optimizer:** Adam [S3].
*   **Learning Rate:** 0.0005 [S3].
*   **Batch Size:** 4096 samples per iteration [S3].
*   **Loss Weights:** $\alpha = 1.0$ (MSE), $\beta = 10.0$ (Opacity Loss) [S3].
*   **Samples per Ray ($N_s$):** Typically 2, 4, 8, or 16 [S3].
*   **View Cell Parameters:** K-5, Z-5, I-128 (specifics of the view cell definition) [S3].

### Edge Cases and Pitfalls
*   **Dark Pixel Artifacts:** At low sample counts, rays may not accumulate to opacity 1 for opaque surfaces, causing darkening. This is remedied by the opacity loss term [S3].
*   **Cheating:** Shading networks with low sample counts may "cheat" by relying on opacity outputs to mix background color into the accumulation [S3].
*   **Reflective/Transparent Surfaces:** Low sample counts and single depth estimates are insufficient for perfect replication of view-dependent phenomena like mirrors or refractive water [S3].
*   **No Ground Truth Depth:** If ground truth depth is unavailable, a dense NeRF (12 layers, 512 hidden units, 128 samples/ray) is trained first to extract depth maps, which are then used to train the DONeRF oracle [S3]. This results in a ~1 dB PSNR drop compared to using GT depth [S3].
*   **Background Noise:** In no-GT training, NeRF may output high-frequency depth values in the background, creating zero-contribution samples [S3].

import torch
import torch.nn as nn
import torch.optim as optim

class DepthOracle(nn.Module):
    """
    Depth Oracle Network: 8 layers, 256 hidden units, ReLU, no positional encoding.
    Input: Concatenated position x (3) and direction d (3).
    Output: Classification logits for depth bins.
    """
    def __init__(self):
        super().__init__()
        layers = []
        # First layer
        layers.append(nn.Linear(6, 256)) # 3 for x, 3 for d
        layers.append(nn.ReLU())
        # Hidden layers
        for _ in range(6):
            layers.append(nn.Linear(256, 256))
            layers.append(nn.ReLU())
        # Output layer
        layers.append(nn.Linear(256, 256)) # Number of depth bins
        self.network = nn.Sequential(*layers)

    def forward(self, x, d):
        # x: [B, 3], d: [B, 3]
        input_vec = torch.cat([x, d], dim=-1)
        logits = self.network(input_vec)
        return logits

class ShadingNetwork(nn.Module):
    """
    Shading Network: 8 layers, 256 hidden units, ReLU.
    Input: Positional encoded x and d.
    Output: Density (1) and Color (3).
    """
    def __init__(self, num_freqs_x=10, num_freqs_d=4):
        super().__init__()
        # Positional encoding dimensions: 2*num_freqs + 1
        dim_x = 2 * num_freqs_x + 1
        dim_d = 2 * num_freqs_d + 1
        
        layers = []
        # First layer takes gamma(x)
        layers.append(nn.Linear(dim_x, 256))
        layers.append(nn.ReLU())
        
        # Hidden layers
        for _ in range(6):
            layers.append(nn.Linear(256, 256))
            layers.append(nn.ReLU())
            
        # Last layer takes gamma(d) concatenated
        layers.append(nn.Linear(256 + dim_d, 4)) # 1 for sigma, 3 for color
        self.network = nn.Sequential(*layers)
        self.num_freqs_x = num_freqs_x
        self.num_freqs_d = num_freqs_d

    def positional_encoding(self, x, num_freqs):
        # Standard NeRF positional encoding
        # x: [B, D], returns [B, 2*num_freqs*D + D]
        # Simplified for 3D input
        scales = torch.tensor([2**i for i in range(num_freqs)], device=x.device)
        shaped = x.reshape(-1, 1, 3) * scales.reshape(1, -1, 1)
        shaped = shaped.reshape(-1, num_freqs * 3)
        pe = torch.cat([torch.sin(shaped), torch.cos(shaped)], dim=-1)
        pe = torch.cat([x.reshape(-1, 3), pe], dim=-1)
        return pe

    def forward(self, x, d):
        # x: [B, 3], d: [B, 3]
        gamma_x = self.positional_encoding(x, self.num_freqs_x)
        gamma_d = self.positional_encoding(d, self.num_freqs_d)
        
        # First layer uses gamma(x)
        h = self.network[0](gamma_x)
        h = self.network[1](h) # ReLU
        
        # Hidden layers
        for layer in self.network[2:-1]:
            h = layer(h)
            
        # Last layer concatenates gamma(d)
        h = torch.cat([h, gamma_d], dim=-1)
        out = self.network[-1](h)
        
        sigma = torch.exp(out[:, 0:1]) # Ensure positive density
        color = torch.sigmoid(out[:, 1:4]) # RGB in [0, 1]
        return sigma, color

def opacity_loss(sigma, sample_positions, ray_origins):
    """
    Computes the opacity loss to prevent dark pixels.
    """
    # Calculate delta
    deltas = torch.norm(torch.diff(sample_positions, dim=-2, prepend=ray_origins.unsqueeze(1)), dim=-1)
    
    # Sum of deltas (approximation of accumulated depth/opacity contribution)
    # Note: The formula in [S3] uses sum of deltas directly as a proxy for opacity accumulation
    # in the context of the loss definition provided.
    sum_deltas = torch.sum(deltas, dim=-1)
    
    # Loss definition from [S3]
    # loss_O = 0 if sum(delta) >= 1 else (sum(delta) - 1)^2
    mask = (sum_deltas < 1.0).float()
    loss = mask * (sum_deltas - 1.0)**2
    return loss.mean()

## Operating characteristics
*   **Time Complexity:** Inference costs are reduced by up to 48x compared to NeRF [S3]. DONeRF requires approximately 4.35 MFLOP per pixel [S3].
*   **Memory Complexity:** Compact; requires only two MLPs (approx. 4 MB) without additional data structures or acceleration structures [S3].
*   **Measured Performance:** On an NVIDIA RTX 3090 at 800x800 resolution with 2 samples/ray, DONeRF renders in 51.3 ms (~20 fps) [S3]. Breakdown: Ray unification (0.21 ms), Oracle (12.64 ms), Warping (3.46 ms), Shading (34.9 ms), Final color (0.09 ms) [S3].
*   **Scaling:** Shading network cost scales nearly linearly with the number of samples: 34.9 ms (2 samples), 65.4 ms (4 samples), 136.4 ms (8 samples), 270.4 ms (16 samples) [S3].
*   **Strengths:** Real-time rendering capability, high quality (average PSNR 31.14 dB vs NeRF 30.52 dB), compact memory footprint [S3].
*   **Limitations:** Not end-to-end trainable; struggles without high-quality depth supervision [S2]. Reflective/transparent surfaces are difficult to render accurately [S3].

## Background
DONeRF was introduced by [S3] to bring compact neural representations closer to practical real-time rendering applications such as games and virtual reality. It addresses the prohibitive computational cost of NeRF, which requires dozens of petaFLOPS for dense raymarching. The method was developed to enable interactive rendering (20 fps) on a single GPU by using a depth oracle network to guide sparse sampling.
