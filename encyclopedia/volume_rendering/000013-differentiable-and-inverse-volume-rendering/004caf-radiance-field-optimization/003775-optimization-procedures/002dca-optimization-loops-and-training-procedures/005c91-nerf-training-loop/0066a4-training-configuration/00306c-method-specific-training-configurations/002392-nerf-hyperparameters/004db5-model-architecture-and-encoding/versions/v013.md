# Model Architecture and Encoding


## Overview
Model Architecture and Encoding defines the neural network structures, feature representations, and positional encoding schemes used to map 3D coordinates and viewing directions to radiance field properties (density, color, semantics). It solves the problem of efficiently representing complex 3D scenes with high-frequency details and view-dependent effects while maintaining computational tractability. It is distinguished from sibling methods like [NeRF Initialization Strategies](8674-nerf-initialization-strategies.md) by focusing on the structural definition of the model rather than parameter initialization, and from [Model Architecture Modifications](11313-model-architecture-modifications.md) by encompassing the foundational encoding and network topology choices that define the base representation.

## Shared principles
The core mechanism involves querying a function $f_\theta: (\mathbf{x}, \mathbf{d}) \rightarrow (\sigma, \mathbf{c})$ where $\mathbf{x} \in \mathbb{R}^3$ is the 3D position, $\mathbf{d} \in S^2$ is the viewing direction, $\sigma$ is the volume density, and $\mathbf{c} \in \mathbb{R}^3$ is the RGB color. The architecture typically consists of two Multi-Layer Perceptrons (MLPs): a density network and a color network.

1.  **Positional Encoding:** Raw coordinates $\mathbf{x}$ and directions $\mathbf{d}$ are mapped to higher-dimensional features using sinusoidal positional encoding $\gamma(\cdot)$ or hash encoding to enable the MLP to learn high-frequency functions [Parent, S1].
2.  **Feature Aggregation:** In grid-based methods, features are interpolated from multi-resolution grids (voxels, planes, or hash tables) and concatenated with positional encodings before being fed into the MLPs [S1].
3.  **Skip Connections:** Dense skip connections are often used to pass low-frequency information from the input directly to deeper layers, aiding convergence [S1].
4.  **Activation Functions:** Density is typically activated using Softplus or Exponential to ensure $\sigma > 0$, while color is activated using Sigmoid to bound values to $[0, 1]$ [S1].

## Subtopics

### [Depth-Guided NeRF Training Configuration](11916-depth-guided-nerf-training-configuration.md)
This configuration defines the hyperparameters, architectural modifications, and optimization settings for training a Neural Radiance Field (NeRF) model using depth priors to improve reconstruction quality. It builds on [Model Architecture and Encoding](13550-model-architecture-and-encoding.md) by integrating a depth supervision loss and specific regularization techniques. It is distinguished from sibling methods like [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md) by its explicit use of Earth Mover’s Distance (EMD) or standard depth losses rather than semantic or generative constraints, and from [Binary Radiance Fields](13622-binary-radiance-fields.md) by its continuous density representation.

### [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md)
CLIPNeRF training configuration defines the optimization procedure for text-guided stylization of Neural Radiance Fields (NeRFs) by minimizing the negative cosine similarity between rendered image embeddings and text prompt embeddings in the CLIP latent space. It distinguishes itself from standard NeRF reconstruction by freezing density parameters and optimizing only color/feature networks to enforce a specific stylistic trajectory, utilizing patch-based rendering to manage memory constraints.

### [Binary Radiance Fields](13622-binary-radiance-fields.md)
Binary Radiance Fields (BiRF) is a storage-efficient radiance field representation that constrains feature grid parameters to binary values (+1 or -1) to achieve compact storage without post-processing compression. Unlike methods that compress pre-trained models or use real-valued floating-point grids, BiRF performs binarization during training using a straight-through estimator, maintaining reconstruction quality via a 2D-3D hybrid multi-resolution architecture. It outperforms state-of-the-art efficient models like Instant-NGP and TensoRF in storage efficiency while maintaining comparable or better PSNR.

### [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md)
The Mip-NeRF 360 MLP architecture is a specific neural network configuration for radiance field optimization that replaces standard positional encoding with **integrated positional encoding** to handle aliasing and frequency filtering during volume rendering. It solves the problem of high-frequency detail loss and aliasing artifacts when rendering scenes with varying camera distances by analytically integrating the positional encoding function over conical frustums. It is distinguished from standard NeRF by its use of integrated encoding for density inputs and optional Integrated Directional Encoding (IDE) for view-dependent effects, along with a specific skip-connection topology and activation biasing strategy.

### SUDS
SUDS is a 4D radiance field representation designed for large-scale dynamic urban scenes that factorizes the scene into three separate multi-resolution hash table structures: static, dynamic, and far-field [S1]. It enables free-viewpoint rendering, semantic decomposition, and 3D scene flow estimation at arbitrary poses and time steps using only unlabeled inputs (RGB, sparse LiDAR, 2D descriptors, and optical flow) [S1]. Unlike sibling methods that rely on supervised 3D bounding boxes or panoptic labels, SUDS achieves scalability to hundreds of square kilometers and tens of thousands of objects by using a spatial partitioning strategy and explicit shadow modeling to disentangle static background from dynamic foreground without manual annotation [S1].

### CCNeRF
CCNeRF is a neural field representation that enables efficient compression and composition of 3D scenes without using neural networks for rendering [S1]. Unlike NeRF variants that rely on a shared MLP renderer (e.g., NSVF) or hybrid tensor-MLP approaches (e.g., TensoRF), CCNeRF models the radiance field entirely through tensor rank decomposition, allowing arbitrary composition of objects and dynamic level-of-detail (LOD) adjustment via rank truncation without retraining [S1].

### [Rip-NeRF](15532-rip-nerf.md)
Rip-NeRF is a hybrid radiance field method that renders high-fidelity, anti-aliased images by combining cone casting with anisotropic 3D Gaussian characterization. It differs from sibling methods like Zip-NeRF by using Ripmap-Encoded Platonic Solids for efficient anisotropic area-sampling, whereas Zip-NeRF relies on a multi-sampling mechanism that is effective but computationally inefficient.

### [UE4-NeRF](15539-ue4-nerf.md)
UE4-NeRF is a neural rendering system designed for the real-time interactive rendering of large-scale 3D scenes by partitioning the environment into sub-NeRFs represented as textured polygonal meshes. It solves the limitations of traditional NeRFs regarding training time and real-time performance by integrating a learned neural shader into the Unreal Engine 4 (UE4) rasterization pipeline. Unlike grid-based large-scale methods like Block-NeRF, UE4-NeRF uses regular octahedra to represent scene geometry, enabling it to handle tilted surfaces and semi-transparent objects more effectively while achieving real-time frame rates at 4K resolution.

### [Generative Occupancy Fields (GOF)](15773-generative-occupancy-fields-gof.md)
Generative Occupancy Fields (GOF) is a 3D-aware image synthesis method that combines radiance fields with occupancy representations to learn compact object surfaces without impeding training convergence. It solves the problem of diffused surfaces in standard generative radiance fields (like GRAFs) and the sparse gradient convergence issues in direct occupancy networks by transitioning from cumulative volume rendering to surface-point rendering. Unlike siblings that predict volume density $\sigma$ and rely on cumulative alpha composition, GOF predicts alpha values $\alpha$ directly, reinterpreting them as occupancy to enable root-finding for precise surface location.

### [Panoptic Radiance Field](15849-panoptic-radiance-field.md)
Panoptic Lifting learns a panoptic 3D volumetric representation from posed RGB images and machine-generated 2D panoptic segmentation masks, lifting noisy 2D labels into a consistent 3D representation of color, density, semantics, and instances. It differs from sibling methods like [Panoptic NeRF](11916-panoptic-nerf.md) and [DM-NeRF](11916-dm-nerf.md) by requiring no manual ground truth (such as coarse meshes or per-image 2D panoptic segmentations), relying instead on pre-trained 2D segmentation networks to generate supervision.

#### Triplane NeRF with Diffusion Prior
- [S1] The framework uses a triplane NeRF representation where scene codes are optimized jointly with a diffusion prior to handle sparse-view data and ensure end-to-end coherence.
- [S1] Prediction Format: v-parameterization $\hat{v}_\phi(x(t), t)$ from [43], such that $\hat{x} = \alpha(t)x(t) - \sigma(t)\hat{v}$.
- [S1] Weighting Function $w(t)$: Uses SNR-based weighting $w(t) = (\alpha(t)/\sigma(t))^2\omega$ from Eq. (5), instead of LSGM mechanisms.
- [S1] Scene code $\xi_i$: Shape $\mathbb{R}^{3 \times 6 \times 128 \times 128}$, representing a triplane NeRF representation.
- [S1] Denoising Network Input/Output: Noisy and denoised triplane features, with channels of all three planes stacked together.
- [S1] Denoising Network Architecture: U-Net with 122M parameters.

#### Explicit Mesh Reconstruction from Neural Fields
- [S4] An algorithm to extract an explicit 3D mesh representation from the implicit neural radiance field learned by CodeNeRF, allowing for 3D reconstruction from a single input image.
- [S4] Feed the center coordinates of a $256^3$ voxel grid to the CodeNeRF MLP to obtain volume density values $\sigma$.
- [S4] Apply the Marching Cubes algorithm to the volume density values $\sigma$ to find mesh vertices.
- [S4] Cast rays along the vertex normals of the generated mesh to associate colors to the vertices.

#### Efficient EndoNeRF scene representation
- [S5] A voxel-grids-based scene representation that replaces coordinate-based MLPs with explicit density and feature volume grids to accelerate optimization, combined with a canonical field and time-dependent deformation field for dynamic surgical scenes.
- [S5] The dynamic scene at time $t$ is modeled by warping a canonical radiance field (represented by $\mathbf{V}_\sigma$ and $\mathbf{V}_a$) with a time-dependent deformation field.
- [S5] The deformation field is modeled using decomposed 4D motion fields and a 3-layer MLP that maps a spatial-temporal coordinate to a deformation offset.

## Background
The foundational NeRF architecture introduced by Mildenhall et al. (2020) established the use of fully connected MLPs with positional encoding for radiance field representation [Parent]. Subsequent developments focused on efficiency (Instant-NGP, TensoRF), robustness to aliasing (Mip-NeRF), and specialized applications like dynamic scenes (SUDS) or generative modeling (EG3D, GOF). The field has evolved from pure coordinate-based MLPs to hybrid grid-MLP structures and tensor decompositions to balance quality and performance.
