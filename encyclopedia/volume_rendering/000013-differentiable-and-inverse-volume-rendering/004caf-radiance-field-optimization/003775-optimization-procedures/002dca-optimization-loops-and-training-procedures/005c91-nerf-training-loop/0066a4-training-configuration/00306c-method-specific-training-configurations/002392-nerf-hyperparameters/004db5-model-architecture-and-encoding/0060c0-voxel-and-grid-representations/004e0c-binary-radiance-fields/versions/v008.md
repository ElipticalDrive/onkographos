# Binary Radiance Fields

Also called: BRF

## Overview
Binary Radiance Fields (BiRF) is a storage-efficient radiance field representation that constrains feature grid parameters to binary values (+1 or -1) to drastically reduce memory footprint while maintaining high reconstruction quality [S1]. Unlike post-processing compression methods such as PlenOctrees or Re:NeRF, which require additional optimization steps and are bounded by pre-trained model performance, BiRF performs binarization during training without post-optimization [S1]. It achieves this through a 2D-3D hybrid multi-resolution architecture that combines a 3D voxel grid with three orthogonal 2D plane grids, mitigating hash collisions inherent in pure 3D hash encoding [S1].

## How it works
BiRF maps a 3D spatial coordinate $\mathbf{x} \in \mathbb{R}^3$ and a viewing direction $\mathbf{d} \in \mathbb{R}^3$ to volume density $\sigma \in \mathbb{R}$ and color $\mathbf{c} \in \mathbb{R}^3$ using binary feature grids and shallow MLPs [S1].

### Inputs and Outputs
*   **Inputs:** 3D coordinate $\mathbf{x}$, viewing direction $\mathbf{d}$.
*   **Outputs:** Density $\sigma$, color $\mathbf{c}$.

### Data Structures
The core data structure is a set of multi-resolution feature grids implemented using hash encoding [S1]. All grid parameters are constrained to binary values $\{-1, +1\}$ [S1].

1.  **3D Voxel Grid ($\Phi_{\theta_{xyz}}$):**
    *   Contains $L$ resolution levels.
    *   Resolutions range from 16 to 1024 [S1].
    *   Maximum number of feature vectors per level: $T_{3D}$ [S1].
2.  **2D Plane Grids ($\Phi_{\theta_{xy}}, \Phi_{\theta_{xz}}, \Phi_{\theta_{yz}}$):**
    *   Three orthogonal grids corresponding to the XY, XZ, and YZ planes [S1].
    *   Contains $M$ resolution levels.
    *   Resolutions range from 64 to 512 [S1].
    *   Maximum number of feature vectors per level: $T_{2D}$ [S1].
3.  **Feature Dimension ($F$):**
    *   The dimension of feature vectors per level [S1].
    *   Model variants scale with $F \in \{2, 4, 8\}$ [S1].

### Parameters
*   **$\lambda_{\text{sparsity}}$:** Weight for the sparsity loss. Value: $2.0 \times 10^{-5}$ [S1].
*   **$L$:** Number of levels in the 3D grid. Determined by $T_{3D}$ [S1].
*   **$M$:** Number of levels in the 2D grids. Determined by $T_{2D}$ [S1].
*   **$T_{3D}$:** Max feature vectors per 3D level.
    *   Small model (Ours-S): $\log_2(T_{3D}) = 17$ [S1].
    *   Base model (Ours-B): $\log_2(T_{3D}) = 19$ [S1].
*   **$T_{2D}$:** Max feature vectors per 2D level.
    *   Small model (Ours-S): $\log_2(T_{2D}) = 15$ [S1].
    *   Base model (Ours-B): $\log_2(T_{2D}) = 17$ [S1].
*   **MLP Architecture:**
    *   Density MLP: 1 hidden layer, 128 channels [S1].
    *   Color MLP: 2 hidden layers, 128 channels [S1].
    *   Activation: ReLU [S1].
    *   Directional Encoding: Spherical Harmonics basis functions [S1].

### Numbered Steps

1.  **Binarization:** Transform real-valued grid parameters $\theta$ to binary parameters $\theta'$ using the sign function:
    $$ \theta' = \text{sign}(\theta) = \begin{cases} +1 & \text{if } \theta \ge 0 \\ -1 & \text{otherwise} \end{cases} $$
    During training, gradients are propagated using the Straight-Through Estimator (STE). The gradient is passed if $|\theta| \le 1$, and stopped otherwise to prevent scale divergence [S1].

2.  **3D Feature Encoding:** For input coordinate $\mathbf{x}$, compute features from the 3D grid by linearly interpolating the binary parameters across $L$ resolution levels and concatenating them:
    $$ \mathbf{f}_{xyz} = \left\{ \text{interp}(\mathbf{x}, \text{sign}(\Phi^l_{\theta_{xyz}})) \right\}_{l=1}^L $$
    where $\text{interp}$ denotes tri-linear interpolation [S1].

3.  **2D Feature Encoding:** Project $\mathbf{x}=(x,y,z)$ to 2D coordinates: $\mathbf{x}_{xy}=(x,y)$, $\mathbf{x}_{xz}=(x,z)$, $\mathbf{x}_{yz}=(y,z)$. For each axis, interpolate binary parameters across $M$ resolution levels and concatenate:
    $$ \mathbf{f}_{xy} = \left\{ \text{interp}(\mathbf{x}_{xy}, \text{sign}(\Phi^m_{\theta_{xy}})) \right\}_{m=1}^M $$
    Repeat for $\mathbf{f}_{xz}$ and $\mathbf{f}_{yz}$ using bi-linear interpolation [S1].

4.  **Feature Concatenation:** Combine all encoded features:
    $$ \mathbf{f} = \{ \mathbf{f}_{xyz}, \mathbf{f}_{xy}, \mathbf{f}_{xz}, \mathbf{f}_{yz} \} $$

5.  **Positional Encoding:** Apply sinusoidal positional encoding $\gamma(\mathbf{x})$ to the input 3D coordinate [S1].

6.  **Density Prediction:** Feed positional encoded coordinates $\gamma(\mathbf{x})$ and features $\mathbf{f}$ into the density MLP to obtain density $\sigma$ and embedding features $\mathbf{e}$:
    $$ (\sigma, \mathbf{e}) = \text{MLP}_{\text{density}}(\gamma(\mathbf{x}), \mathbf{f}) $$

7.  **Color Prediction:** Feed embedding features $\mathbf{e}$ and directional information $\mathbf{d}$ (encoded via spherical harmonics) into the color MLP to acquire color $\mathbf{c}$:
    $$ \mathbf{c} = \text{MLP}_{\text{color}}(\mathbf{e}, \mathbf{d}) $$

### Edge Cases and Pitfalls
*   **Hash Collisions:** 3D grids suffer from hash collisions at higher resolutions [S1]. The 2D grids supplement the 3D grid, alleviating collision impact and reinforcing features with fewer parameters [S1].
*   **Gradient Vanishing:** The derivative of the sign function is zero almost everywhere [S1]. This is solved by the Straight-Through Estimator (STE), which passes gradients through the threshold function during training [S1].
*   **Scale Divergence:** Large values of $\theta$ can cause divergence [S1]. STE stops propagating gradients when $|\theta| > 1$, constraining the value to $\{-1, 1\}$ [S1].

## Operating characteristics
*   **Storage Efficiency:** BiRF achieves significant storage reduction. The small model (Ours-S2) requires less than 0.5 MB of storage space [S1]. This outperforms baselines like TensoRF-CP (3.7 MB) and Instant-NGP (24.5 MB) on the mic scene while maintaining comparable or better PSNR [S1].
*   **Performance:** On Synthetic-NeRF scenes, BiRF achieves a PSNR of 32.03 dB [S1]. On Synthetic-NSVF, it achieves 34.48 dB [S1]. On Tanks and Temples, it achieves 28.20 dB [S1].
*   **Training Time:** Training takes approximately 6, 9, and 14 minutes for Ours-B2 to Ours-B8 models on Synthetic-NeRF scenes, respectively, on a single NVIDIA RTX A6000 GPU [S1].
*   **Strengths:** Compact storage, no post-optimization required, superior reconstruction performance compared to prior efficient methods [S1].
*   **Limitations:** Performance is bounded by the binarization strategy; extremely high-fidelity reconstruction may require larger feature dimensions or more levels, increasing storage [S1].

## Background
Binary Radiance Fields were proposed by Seungjoo Shin and Jaesik Park from POSTECH and Seoul National University, respectively [S1]. The work was published on arXiv in June 2023 (v2 in December 2023) [S1]. The method builds on Instant-NGP [S1] and uses the occupancy grid implementation from NerfAcc [S1]. It addresses the storage bottleneck of neural radiance fields by introducing binary feature encoding [S1].
