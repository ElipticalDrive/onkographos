# Conditional NeRF Implementation Details

Also called: Conditional NeRF, Conditional NeRF Architecture, Conditional NeRF Model Specs

## Overview
Conditional NeRF is a generative model for a specific object category that maps a 5D coordinate (spatial position $\mathbf{x}$ and view direction $\mathbf{v}$) along with instance-specific latent codes to volumetric density $\sigma$ and view-dependent radiance $\mathbf{c}$ [S1]. It differs from standard per-scene NeRF by conditioning the neural field on latent vectors that dedicatedly control shape and appearance, enabling the generation of novel instances within a category [S1]. It builds on [Conditional and Latent Representations](15989-conditional-and-latent-representations.md) by providing the specific architectural and training configurations required to implement the conditional mapping and latent injection mechanisms.

## How it works
**Inputs and Outputs:**
The model $F_\theta$ takes as input:
1.  Spatial position $\mathbf{x} \in \mathbb{R}^3$.
2.  View direction $\mathbf{v} \in \mathbb{R}^3$ (normalized).
3.  Shape latent code $\mathbf{z}_s \in \mathbb{R}^{128}$.
4.  Appearance latent code $\mathbf{z}_a \in \mathbb{R}^{128}$.

The output is:
1.  Volumetric density $\sigma \in \mathbb{R}$.
2.  View-dependent radiance $\mathbf{c} \in \mathbb{R}^3$ (RGB).

**Data Structures and Layout:**
The core component is an 8-layer Multi-Layer Perceptron (MLP) [S1].
*   **Hidden Units:** 256 per layer.
*   **Activations:** ReLU for all hidden layers.
*   **Input Dimension:** 64. This dimension is composed of the concatenated positional encodings of $\mathbf{x}$, $\mathbf{v}$, $\mathbf{z}_s$, and $\mathbf{z}_a$.
*   **Output:** A single scalar for $\sigma$ and three scalars for $\mathbf{c}$.

**Positional Encoding:**
The positional encoding function $\Gamma(\mathbf{p})$ projects each coordinate $p$ of a vector $\mathbf{p}$ into a high-dimensional space using sinusoidal functions [S1]. For a frequency band parameter $m$, the encoding has $2m$ dimensions. The $k$-th dimension ($k \in \{0, \dots, 2m-1\}$) is defined as [S1]:
$$
\gamma(\mathbf{p})_k = \begin{cases} \sin(2^k \pi p), & \text{if } k \text{ is even} \\ \cos(2^k \pi p), & \text{if } k \text{ is odd} \end{cases}
$$
The input to the MLP is the concatenation: $\Gamma(\mathbf{x}) \oplus \mathbf{z}_s, \Gamma(\mathbf{v}) \oplus \mathbf{z}_a$ [S1]. Note that in the disentangled variant, $\Gamma(\mathbf{x})$ is replaced by a deformed encoding $\Gamma^*(\mathbf{x}, \mathbf{z}_s)$ (see Subtopics).

**Deformation Network (Disentangled Variant):**
To achieve disentanglement, a deformation network maps the shape code $\mathbf{z}_s$ to displacement vectors $\Delta \mathbf{x}$ [S1].
*   **Architecture:** 4-layer MLP.
*   **Hidden Units:** 256 per layer.
*   **Activations:** ReLU.
*   **Input:** $\mathbf{z}_s \in \mathbb{R}^{128}$.
*   **Output:** Displacement vectors $\Delta \mathbf{x} \in \mathbb{R}^{3 \times 2m}$ corresponding to each band of the positional encoding $\Gamma(\mathbf{x})$ [S1].
*   **Deformed Encoding:** $\Gamma^*(\mathbf{p}, \mathbf{z}_s) = \{ \gamma^*(\mathbf{p}, \Delta \mathbf{p}) \}$, where $\Delta \mathbf{p}$ are the displacements derived from $\mathbf{z}_s$ [S1].

**Rendering:**
The rendering process follows standard volume rendering [Parent](3065-nerf-hyperparameters.md). For a ray $r$, $N_c$ points $\{t_i\}$ are sampled. Density $\sigma_i$ and color $\mathbf{c}_i$ are computed using $F$. The pixel color $\hat{C}$ is computed via alpha compositing [S1]:
$$
\hat{C}(r, \mathbf{z}_s, \mathbf{z}_a) = \sum_{i=1}^{N_c} \mathbf{c}_i \alpha_i \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)
$$
where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ and $\delta_i = t_{i+1} - t_i$ [S1].

**Training Optimization:**
The network is trained using the Adam optimizer [S1].
*   **Initial Learning Rate:** $10^{-4}$.
*   **Decay:** By 0.5 every 50,000 steps [S1].
*   **Inversion Optimization:** When optimizing latent codes for a specific input image (inversion), Adam is used with an initial learning rate of $10^{-3}$, decreasing by 0.75 every 100 steps [S1].
*   **Loss Weights:** In the inversion process, regularization weights are $\lambda_r = 0.5$, $\lambda_v = 0.1$, $\lambda_s = 0.2$, and $\lambda_a = 0.2$ [S1].

## Subtopics

### [Disentangled Conditional NeRF](16793-disentangled-conditional-nerf.md)
Disentangled Conditional NeRF is a generative neural radiance field architecture that achieves independent control over object shape and appearance by isolating shape conditioning to explicit volumetric deformation of positional encodings. Unlike standard conditional NeRFs where concatenating latent codes causes mutual intervention (e.g., shape changes altering color), this method prevents such interference by deferring appearance conditioning to the radiance field while applying shape conditioning via a deformation network. It is chosen when independent manipulation of shape and appearance is required without cross-talk. See [Disentangled Conditional NeRF](16793-disentangled-conditional-nerf.md).

### CLIP-Driven Manipulation via Mappers
A feed-forward approach using shape mapper $M_s$ and appearance mapper $M_a$ to update initial shape/appearance codes ($\mathbf{z}_{s0}, \mathbf{z}_{a0}$) based on a text prompt $t$, avoiding per-sample optimization [S1]. The updated codes are calculated as $\mathbf{z}_s = M_s(\hat{E}_t(t)) + \mathbf{z}_{s0}$ and $\mathbf{z}_a = M_a(\hat{E}_t(t)) + \mathbf{z}_{a0}$, where $\hat{E}_t$ is the pre-trained CLIP text encoder [S1]. The mappers are 2-layer MLPs with ReLU activations and channel sizes 128, 256, 128 [S1]. This is chosen for text-driven manipulation where rapid inference is needed.

### Deferred Appearance Conditioning
A technique where appearance conditioning is deferred to concatenate the appearance code with the view direction as input to the radiance prediction network, allowing appearance manipulation without affecting shape/density [S1]. This ensures that changes to $\mathbf{z}_a$ do not influence $\sigma$. It is used in the disentangled variant to maintain shape integrity during appearance editing.

## Operating characteristics
**Time and Memory Complexity:**
The model uses an 8-layer MLP with 256 hidden units. The deformation network is a 4-layer MLP with 256 hidden units. The complexity is dominated by the MLP forward pass per sample point. Memory usage is proportional to the number of parameters in the MLPs and the storage of latent codes per instance.

**Measured Performance:**
The model was trained on an NVIDIA V100 GPU [S1]. It was evaluated on the Photoshapes and Carla datasets [S1]. For the Carla dataset, 10K cars were rendered at 256x256 resolution [S1]. The method requires only one view per instance for training, unlike EditNeRF which requires multiple views [S1].

**Strengths and Limitations:**
Strengths include the ability to generate novel instances from a single view and text-driven manipulation without per-sample optimization (in the CLIP variant) [S1]. Limitations include the potential for mutual intervention in the standard conditional formulation if disentanglement is not used [S1]. The inversion process (optimizing latent codes for a specific image) can be time-consuming and requires careful tuning of learning rates and regularization weights [S1].

**When to Use:**
Use when generating multiple instances of a category with controlled shape and appearance is required. Use the disentangled variant when independent editing is critical. Use the CLIP-driven variant for text-based generation.

## Background
Conditional NeRF was introduced in the paper "CLIP-NeRF: Text-and-Image Driven Manipulation of Neural Radiance Fields" by Can Wang et al., published in CVPR 2022 [S1]. It builds upon the original per-scene NeRF [24] and addresses the need for generative models of 3D objects that can be manipulated via latent codes or text prompts. The work extends previous methods like EditNeRF by allowing generation of new instances rather than just editing existing ones, and by using a single view for training [S1].
