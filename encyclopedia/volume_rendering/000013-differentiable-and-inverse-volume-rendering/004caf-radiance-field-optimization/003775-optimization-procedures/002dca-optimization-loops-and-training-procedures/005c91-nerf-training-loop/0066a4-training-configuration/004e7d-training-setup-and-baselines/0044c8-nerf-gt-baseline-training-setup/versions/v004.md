# NeRF-GT Baseline Training Setup
Also called: NeRF-GT
## Overview
NeRF-GT is a reference training configuration for Neural Radiance Fields (NeRF) that uses High Dynamic Range (HDR) rendered views as input to establish an upper-bound performance baseline for novel view synthesis [S1]. It differs from standard NeRF setups by explicitly addressing the high dynamic range of scenes, serving as a ground-truth reference against which methods trained on Low Dynamic Range (LDR) data are evaluated [S1].
## How it works
**Inputs and Outputs:**
*   **Input:** A dataset of HDR views (or consistently exposed LDR views) of a scene. The ground truth for evaluation is the tone-mapped LDR version of these HDR views [S1].
*   **Output:** A trained NeRF model capable of synthesizing novel views. The model's raw output is HDR radiance, which is tone-mapped to LDR for loss computation [S1].

**Data Structures:**
*   **NeRF Model:** Standard MLP-based radiance field representation [S1].
*   **HDR Views:** Pixel values representing radiance with high dynamic range [S1].
*   **LDR Views:** Tone-mapped pixel values used for supervision [S1].

**Steps:**
1.  **Training Input:** Train the NeRF model using HDR views as the primary input data [S1].
2.  **Prediction Tone-Mapping:** During the forward pass, the NeRF model predicts HDR pixel values for each ray. These predicted HDR values are then tone-mapped into LDR pixel values [S1].
3.  **Loss Computation:** Compute the loss by comparing the tone-mapped predicted LDR pixel values to the tone-mapped ground truth LDR views [S1].

**Pitfalls:**
*   Training directly on HDR views can fail to encode all areas of a scene well due to the high dynamic range, even when using tone-mapped colors for loss calculation [S1]. This is because the high dynamic range makes it difficult for the network to capture details across all intensity levels simultaneously [S1].

**Pseudocode:**
```python
def train_nerf_gt(nerf_model, hdr_dataset, tone_map_function, optimizer, epochs):
    """
    Trains a NeRF model using HDR views as input, with loss computed on tone-mapped LDR outputs.
    
    Args:
        nerf_model: The NeRF neural network.
        hdr_dataset: Iterable of (camera_params, hdr_image) tuples.
        tone_map_function: Function to convert HDR radiance to LDR color.
        optimizer: Optimizer for the NeRF model.
        epochs: Number of training epochs.
    """
    for epoch in range(epochs):
        for camera_params, hdr_image in hdr_dataset:
            # 1. Sample rays from the scene using camera_params
            rays = sample_rays(camera_params, hdr_image.shape)
            
            # 2. Forward pass to get predicted HDR radiance
            # predicted_hdr is the raw HDR output from the NeRF model
            predicted_hdr = nerf_model(rays)
            
            # 3. Tone-map the predicted HDR values to LDR
            predicted_ldr = tone_map_function(predicted_hdr)
            
            # 4. Tone-map the ground truth HDR image to LDR
            # Note: The ground truth LDR is derived from the input HDR image
            gt_ldr = tone_map_function(hdr_image)
            
            # 5. Compute loss between tone-mapped predictions and tone-mapped ground truth
            loss = compute_loss(predicted_ldr, gt_ldr)
            
            # 6. Backpropagate and update
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
```
## Subtopics
## Operating characteristics
*   **Performance:** Serves as an upper-bound baseline for novel HDR view synthesis [S1].
*   **Limitations:** May struggle to encode all scene areas well due to the high dynamic range, even with tone-mapped loss [S1].
*   **Use Case:** Used for evaluating the performance gap of proposed methods that train on LDR data [S1].
## Background
*   **Origin:** Introduced in "HDR-NeRF: High Dynamic Range Neural Radiance Fields" by X. Huang et al. [S1].
*   **Purpose:** To provide a reference for HDR novel view synthesis, as no existing dataset was appropriate for this task at the time of publication [S1].
*   **Dataset:** The authors collected a new dataset using Blender's Cycles path-tracer for 3D models and real-world scenes [S1].
