# Forward Warping for Novel View Synthesis

Also called: Canonical Field Forward Warping, Forward Flow

## Overview
Forward Warping for Novel View Synthesis is a method for rendering dynamic scenes by modeling a static scene at a canonical time step and forward warping the entire canonical radiance field to other time steps [S1]. It addresses the many-to-one and one-to-many mapping difficulties inherent in dynamic scene reconstruction by employing differentiable forward warping with average splatting and an inpaint network [S1]. Unlike backward flow-based methods such as NDVG, this approach achieves superior performance, particularly for canonical frames, by explicitly warping the field rather than predicting flow for backward sampling [S1].

## How it works
The method operates in two stages: coarse and fine. It utilizes a canonical representation where geometry and appearance are defined at a specific canonical time $t_{can}$, and deformation is modeled via a trajectory field.

### Inputs and Outputs
*   **Inputs:** A set of multi-view images $\{I_t\}$ at various time steps $t$. The canonical time $t_{can}$ is selected as the first frame for D-NeRF datasets and the middle frame for HyperNeRF datasets [S1].
*   **Outputs:** A rendered RGB image for any arbitrary view and time step $t$.

### Data Structures
The method maintains several voxel grids and neural networks. All grids are 3D voxel structures.

1.  **Canonical Radiance Feature Grid ($V_{Rf}$):** Stores radiance features. Feature dimension is 12 [S1].
2.  **Canonical Coordinate Grid ($V_{rCan}$):** Stores the 3D coordinate of each voxel center [S1].
3.  **Canonical Density Grid ($V_{\sigma}^{Can}$):** Stores canonical density values $\sigma$ [S1].
4.  **Canonical Color Feature Grid ($V_{cf}^{Can}$):** Stores canonical color features. Dimension is 3 in the coarse stage and 12 in the fine stage [S1].
5.  **Canonical Deformation Feature Grid ($V_{Df}^{Can}$):** Stores deformation features. Dimension is 0 for D-NeRF (no deformation features, only DCT) and 12 for HyperNeRF [S1].
6.  **Trajectory Grid ($V_{T}^{t}$):** Stores DCT parameters for each voxel's trajectory. The number of DCT bases is 15 for D-NeRF and 25 for HyperNeRF [S1].
7.  **Deformation Flow Grid ($V_{flow}$):** Stores the deformation flow vector of each voxel from the canonical position to time $t$ [S1].
8.  **Warped Radiance Field ($V_{R}^{t}$):** The radiance field at time $t$ obtained by warping $V_{Rf}$ using $V_{flow}$ [S1].
9.  **Inpainted Radiance Field ($V_{R}^{t, Inp}$):** The field $V_{R}^{t}$ after processing by the Inpaint Network [S1].
10. **Upsampled Radiance Field ($V_{R}^{t, Up}$):** The field $V_{R}^{t, Inp}$ after upsampling [S1].

### Neural Networks
1.  **Canonical Radiance Network ($F_{\theta_1}$):**
    *   **Structure:** 3-layer MLP, width 128, ReLU activation [S1].
    *   **Input:** Radiance feature sampled from $V_{Rf}$ (dim 12) and embedded position (dim 33) [S1].
    *   **Output:** Density (dim 1) and color feature (dim 3 or 12, depending on stage) [S1].
2.  **Canonical Deformation Network ($F_{\theta_2}$):**
    *   **Structure:** 4-layer MLP, width 64 [S1].
    *   **Input:** Deformation feature (dim 0 or 12) and embedded position (dim 33) [S1].
    *   **Output:** Trajectory parameters (DCT coefficients) [S1].
3.  **View Dependent Color Network ($F_{\theta_4}$):**
    *   **Structure:** 2-layer MLP, width 64 [S1].
    *   **Input:** Embedded view direction (dim 27) and color feature (dim 12) [S1].
    *   **Output:** RGB color (dim 3) [S1].
4.  **Inpaint Network ($F_{\theta_3}$):**
    *   **Structure:** UNet with 4 encode layers and 3 decode layers, plus an upsample layer [S1].
    *   **Encode Layer:** Max pooling + two convolution layers (Instance Norm + Conv + ReLU) [S1].
    *   **Decode Layer:** Up-sample interpolation + two convolution layers (Instance Norm + Conv + ReLU) [S1].
    *   **Upsample Layer:** Same structure as a decode layer [S1].

### Algorithm Steps

#### 1. Canonical Field Initialization (Coarse Stage)
The coarse stage learns a proxy geometry.
1.  Initialize voxel grids $V_{Rf}, V_{rCan}, V_{\sigma}^{Can}, V_{cf}^{Can}$ (dim 3), $V_{Df}^{Can}$ (dim 0), and $V_{T}^{t}$ [S1].
2.  Set voxel resolution to $6^3$ [S1].
3.  For each training iteration:
    a. Sample rays $\mathbf{r}$ from input images.
    b. For each ray, sample $K$ points $w_k$ along the ray.
    c. Query $V_{Rf}$ and $V_{rCan}$ at $w_k$ to get radiance feature $\mathbf{f}$ and coordinate $\mathbf{x}$ [S1].
    d. Compute embedded position $\mathbf{e}_p$ from $\mathbf{x}$ (dim 33) [S1].
    e. Pass $\mathbf{f}$ and $\mathbf{e}_p$ to $F_{\theta_1}$ to get density $\sigma$ and color feature $\mathbf{c}_{feat}$ [S1].
    f. Compute transmittance $T(w_k)$ and accumulated weight $A_{accum}(k) = T(w_k) \sigma(w_k) \delta_k$ [S1].
    g. Render color $\mathbf{C}_{gt}(\mathbf{r})$ from ground truth image [S1].
    h. Compute losses (see Losses section) [S1].
    i. Update parameters $\theta_1$ and voxel grids [S1].
4.  Do not use the Inpaint Network in the coarse stage [S1].

#### 2. Deformation and Trajectory Learning
1.  For each voxel in $V_{Df}^{Can}$, query $F_{\theta_2}$ with deformation feature and embedded position to get DCT coefficients [S1].
2.  Store coefficients in $V_{T}^{t}$ [S1].
3.  For a target time $t$, compute the deformation flow $V_{flow}$ for each voxel by evaluating the DCT trajectory at time $t$ relative to the canonical time [S1].

#### 3. Forward Warping (Fine Stage)
The fine stage refines the field and handles dynamic appearance.
1.  Set voxel resolution to $8^3$ (D-NeRF) or $7^3$ (HyperNeRF) [S1].
2.  Set Inpaint Network scale factor to 2.0 [S1].
3.  For each training iteration:
    a. Sample rays $\mathbf{r}$ from input images at time $t$.
    b. **Warping:**
        i. Sample points $w_k$ along $\mathbf{r}$ in the canonical space.
        ii. Query $V_{flow}$ at $w_k$ to get flow vector $\mathbf{v}_{flow}$ [S1].
        iii. Compute warped position $w_k' = w_k + \mathbf{v}_{flow}$ [S1].
        iv. Use **Average Splatting** to transfer features from canonical grid $V_{Rf}$ to warped grid $V_{R}^{t}$ at positions $w_k'$ [S1]. Average splatting is used instead of softmax splatting as it provides similar performance with less complexity [S1].
    c. **Inpainting:**
        i. Pass $V_{R}^{t}$ through $F_{\theta_3}$ (Inpaint Network) to get $V_{R}^{t, Inp}$ [S1].
        ii. Upsample $V_{R}^{t, Inp}$ to get $V_{R}^{t, Up}$ [S1].
    d. **Rendering:**
        i. For points $w_k$ in canonical space, query $V_{R}^{t, Inp}$ and $V_{R}^{t, Up}$ to get color features [S1].
        ii. Pass color features and embedded view direction to $F_{\theta_4}$ to get RGB color $\mathbf{c}(w_k)$ [S1].
        iii. Render final color $\mathbf{C}_{Inp}(\mathbf{r})$ and $\mathbf{C}_{Up}(\mathbf{r})$ using volume rendering [S1].
    e. **Loss Computation:** Compute total loss (see Losses section) [S1].
    f. **Progressive Training:** Start with 10 images closest to $t_{can}$. Add one image with the closest time step every 60 iterations [S1].
    g. Update parameters $\theta_1, \theta_2, \theta_3, \theta_4$ and voxel grids [S1].

### Losses
The total loss is:
$$ \mathcal{L} = \mathcal{L}_{photo} + w_1\mathcal{L}_{ptc} + w_2\mathcal{L}_{bg} + w_3\mathcal{L}_{flow} + w_4\mathcal{L}_{vdiff} + w_5\mathcal{L}_{tv}(\mathbf{V}_{\sigma}^{\text{Can}}) + w_6\mathcal{L}_{tv}(\mathbf{V}_{\text{flow}}^t) + w_7\mathcal{L}_{tv}(\mathbf{D}) $$
where $\mathcal{L}_{photo}$ is the standard pixel-wise photometric loss [S1].

1.  **Point-wise Color Loss ($\mathcal{L}_{ptc}$):** Supervises sampled points weighted by accumulation.
    $$ \mathcal{L}_{ptc} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Up}}(\mathbf{r})) $$
    $$ \mathcal{L}(\mathbf{C}(\mathbf{r})) = \frac{1}{K} \sum_{k=1}^{K} A_{\text{accum}}(k) \|\mathbf{c}(w_k) - \mathbf{C}_{\text{gt}}(\mathbf{r})\|_2^2 $$
    $$ A_{\text{accum}}(k) = T(w_k) \, \sigma(w_k) \delta_k $$
    where $\mathbf{C}_{\text{Inp}}$ and $\mathbf{C}_{\text{Up}}$ are colors from inpainted and upsampled fields [S1].

2.  **Background Entropy Loss ($\mathcal{L}_{bg}$):** Encourages densities to concentrate on foreground or background.
    $$ \mathcal{L}_{bg} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Up}}(\mathbf{r})) $$
    $$ \mathcal{L}(\mathbf{A}(\mathbf{r})) = -\frac{1}{K-1} \sum_{k=1}^{K-1} [ A_{\text{accum}}(k)\log(A_{\text{accum}}(k)) + (1-A_{\text{accum}}(k))\log(1-A_{\text{accum}}(k)) ] $$
    [S1]

3.  **Total Variation Losses ($\mathcal{L}_{tv}$):** Applied to canonical density grid, flow grid, and deformation features $\mathbf{D}$ [S1].

### Parameters
*   **Coarse Stage:**
    *   Voxel Number: $6^3$ [S1].
    *   Inpaint Scale: 1.5 (not used in coarse stage) [S1].
    *   Iterations: 20,000 [S1].
    *   Weights: $w_1=10^{-1}, w_2=10^{-2}, w_3=10^{-5}, w_4=0, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$ [S1].
*   **Fine Stage:**
    *   Voxel Number: $8^3$ (D-NeRF), $7^3$ (HyperNeRF) [S1].
    *   Inpaint Scale: 2.0 [S1].
    *   Iterations: 100,000 [S1].
    *   Weights: $w_1=10^{-2}, w_2=10^{-3}, w_3=10^{-5}, w_4=10^{-5}, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$ [S1].
*   **Optimization:**
    *   Optimizer: Adam [S1].
    *   Learning Rate: $10^{-1}$ for voxel grids, $10^{-3}$ for networks [S1].
*   **Progressive Training:** Start with 10 images closest to canonical step; add one image with closest time step every 60 iterations [S1].

### Edge Cases and Pitfalls
*   **Memory Consumption:** High, especially for real scenes [S1].
*   **Training Speed:** Slow, approximately one day per scene on a GeForce RTX 3090 [S1].
*   **Coarse Stage Necessity:** Removing the coarse stage causes significant performance drops because the voxel grid covers a larger space without proxy geometry filtering [S1].
*   **Inpaint Network Importance:** Removing the inpaint network significantly reduces performance (e.g., Hell Warrior PSNR drops from 27.71 to 27.15) [S1].
*   **Canonical Time Selection:** Setting canonical time to the middle frame improves performance for HyperNeRF as the geometry is closer to other time steps [S1].

## Operating characteristics
*   **Time Complexity:** Training takes approximately one day per scene on a GeForce RTX 3090 [S1].
*   **Memory Complexity:** High memory consumption, particularly for real-world scenes [S1].
*   **Model Size:** 260M parameters for D-NeRF, 440M for HyperNeRF [S1].
*   **Rendering Speed:** 7 seconds per image for D-NeRF, 15 seconds per image for HyperNeRF [S1].
*   **Strengths:** Achieves state-of-the-art performance on public datasets, especially for canonical frames. Forward warping design offers advantages over backward flow methods like NDVG [S1].
*   **Limitations:** Slow training speed and high memory usage [S1].

## Background
Forward Warping for Novel View Synthesis was proposed in the paper "Forward Flow for Novel View Synthesis of Dynamic Scenes" [S1]. It builds on the concept of canonical fields, similar to D-NeRF [S1], but introduces a forward warping pipeline with average splatting and an inpaint network to handle dynamic scenes. The method was evaluated on the D-NeRF and HyperNeRF datasets, as well as a newly built "Lego Complete Dataset" [S1]. It addresses limitations of backward flow methods by explicitly warping the canonical field [S1].
