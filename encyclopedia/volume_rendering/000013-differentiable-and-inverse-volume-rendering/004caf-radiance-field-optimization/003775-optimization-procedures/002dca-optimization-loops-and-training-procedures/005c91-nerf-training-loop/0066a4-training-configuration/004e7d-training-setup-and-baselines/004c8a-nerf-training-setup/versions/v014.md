# NeRF Training Setup

Also called: Control-NeRF Training Setup, Nerfstudio Training

## Overview
This method defines the training configuration for Neural Radiance Fields (NeRF) using the Nerfstudio library, specifically leveraging NerfAcc and Instant-NGP for fast convergence on static scenes [S2]. It differs from standard NeRF implementations by replacing the positionally encoded 3D position input with a pre-sampled 64-dimensional feature vector, thereby omitting positional encoding for the spatial coordinates while retaining it for the viewing direction [S1]. This setup is designed for static environments with minimal dynamic elements, such as surgical scenes [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A dataset of multi-view images (e.g., LLFF or laparoscopic video frames), estimated camera poses, and a pre-computed 3D feature volume $V_s$ [S1, S2].
*   **Outputs:** Optimized network weights for the coarse network $\hat{C}_c$ and fine network $\hat{C}_f$, producing rendered RGB images and opacity values [S1, S2].

**Data Structures:**
*   **Feature Volume ($V_s$):** A 3D grid storing 64-dimensional feature vectors.
*   **Ray Bundle:** A batch of rays defined by origin and direction, sampled from the image plane [S2].
*   **Network Input:** A tuple $(\mathbf{v}_s, \gamma(\mathbf{d}))$, where $\mathbf{v}_s$ is the sampled feature vector and $\gamma(\mathbf{d})$ is the encoded direction [S1].

**Numbered Steps:**
1.  **Ray Sampling:** For each training batch, sample 1024 rays from the input images [S1, S2]. The images are typically scaled to a resolution of $504 \times 378$ [S1].
2.  **Feature Sampling:** For each ray, sample points along its length. Retrieve the 64-dimensional feature vector $\mathbf{v}_s$ at each point $\mathbf{p}$ from the volume $V_s$ using trilinear sampling $S(V_s, \mathbf{p})$ [S1]. No positional encoding is applied to $\mathbf{v}_s$ [S1].
3.  **Direction Encoding:** Encode the ray direction $\mathbf{d} \in \mathbb{R}^3$ using positional encoding $\gamma(\mathbf{d})$ [S1].
4.  **Coarse Network Forward Pass:** Pass $(\mathbf{v}_s, \gamma(\mathbf{d}))$ to the coarse network $\hat{C}_c$ to predict density $\sigma$ and color $\mathbf{c}$ for 64 evenly spaced points along the ray [S1].
5.  **Fine Network Sampling:** Use the opacity results from the coarse network to sample 64 additional points, focusing on relevant portions of the scene volume (e.g., near surfaces) [S1].
6.  **Fine Network Forward Pass:** Pass the features and encoded directions for the fine points to the fine network $\hat{C}_f$ to predict final density and color [S1].
7.  **Volume Rendering:** Compute the rendered color $\mathbf{C}(\mathbf{r})$ and opacity using the discrete approximation of the volume rendering integral [S1]:
    $$ \mathbf{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i $$
    where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance, $\sigma_i$ is the density, $\delta_i$ is the segment length, and $\mathbf{c}_i$ is the color [S1, S2].
8.  **Loss Computation:** Calculate the photometric loss (Mean Squared Error) between the rendered image and the ground truth image [S1, S2].
9.  **Optimization:** Update network weights using stochastic gradient descent (typically Adam) [S1, S2].

**Formulas:**
*   **Directional Positional Encoding:**
    $$ \gamma(\mathbf{p}) = [\sin(2^0\pi\mathbf{p}), \cos(2^0\pi\mathbf{p}), \dots, \sin(2^{L-1}\pi\mathbf{p}), \cos(2^{L-1}\pi\mathbf{p})] $$
    where $\mathbf{p}$ is each dimension of the direction vector $\mathbf{d}$ and $L=4$ [S1].
*   **Transmittance:**
    $$ T(t) = \exp \left( -\int_{t_n}^{t} \sigma(\mathbf{v}_s) ds \right) $$
    Discretized for implementation [S1].

**Parameters:**
*   **Encoding Depth ($L$):** 4 for direction encoding [S1].
*   **Batch Size:** 1024 rays [S1].
*   **Resolution:** $504 \times 378$ (LLFF datasets) [S1].
*   **Points per Ray:** 64 for coarse, 64 for fine [S1].
*   **Hardware:** Single RTX A6000 GPU, 128 GB RAM [S2].
*   **Library:** Nerfstudio, utilizing NerfAcc and Instant-NGP [S2].

**Edge Cases and Pitfalls:**
*   **Dynamic Content:** The method assumes static scenes. Significant movement (surgical tools, organs) may introduce artifacts if not masked or handled separately [S2].
*   **Feature Volume Alignment:** The feature volume $V_s$ must be accurately aligned with the camera poses; misalignment leads to incorrect feature sampling [S1].
*   **Precision:** Trilinear sampling assumes continuous feature space; discrete grid boundaries may cause artifacts if not handled with proper interpolation [S1].

## Subtopics

### Image-Based NeRF Training
Trains a NeRF using RGB images as ground truth, optimizing both geometry (via Eikonal loss) and appearance (via color loss) [S3, unofficial]. It differs from the main setup by explicitly adding an Eikonal loss for geometry regularization, similar to SDF training, and typically runs for a fixed number of epochs (e.g., 250) on lower resolution images (e.g., 128x128) [S3, unofficial]. It uses a standard dataset loading pipeline (`get_nerf_datasets`) and ray bundle construction [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the number of rays per batch (1024) and the number of points per ray (128 total). Fast convergence is achieved using Instant-NGP and NerfAcc [S2].
*   **Memory Complexity:** Requires storing the 3D feature volume $V_s$ and network weights. The RTX A6000 GPU provides sufficient VRAM for these models [S2].
*   **Performance:** Optimized for static scenes with minimal dynamic content [S2]. Performance on LLFF datasets shows competitive PSNR and SSIM when using the feature volume approach compared to standard positional encoding [S1].
*   **Strengths:** Fast convergence, reduced input dimensionality for the network (64-dim feature vs. 60-dim encoded position + 3-dim position) [S1].
*   **Limitations:** Requires pre-computation of the feature volume, which may be challenging for highly dynamic or unstructured scenes [S1, S2].

## Background
The method originates from the Control-NeRF paper, which introduces editable feature volumes for scene rendering [S1]. It was adapted for laparoscopic surgical video rendering using the Nerfstudio library, NerfAcc, and Instant-NGP to handle static abdominal environments [S2]. The approach modifies the standard NeRF architecture by replacing the positionally encoded 3D position input with a sampled feature vector [S1].
