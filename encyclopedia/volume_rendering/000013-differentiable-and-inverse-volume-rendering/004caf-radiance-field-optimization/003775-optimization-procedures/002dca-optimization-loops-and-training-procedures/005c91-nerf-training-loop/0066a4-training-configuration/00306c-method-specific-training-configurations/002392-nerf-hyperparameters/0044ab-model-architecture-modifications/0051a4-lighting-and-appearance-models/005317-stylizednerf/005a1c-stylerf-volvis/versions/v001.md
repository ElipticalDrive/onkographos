# StyleRF-VolVis


## Overview
StyleRF-VolVis is a framework for editing the style (appearance) of a DVR scene represented by a NeRF model without losing original content (geometry) information [S1]. It supports both photorealistic (PSE) and non-photorealistic (NPSE) editing in a single pipeline by separating content and appearance, allowing explicit assignment of different styles to different DVR regions via a Palette Color Network (PCN) and an Unrestricted Color Network (UCN), while preserving view-dependent lighting [S1]. It differs from prior works by supporting both photorealistic and non-photorealistic editing in a single framework, whereas others focus on one or the other [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Multi-view images of the scene, an initial Transfer Function (TF) defining opacity ranges, and optionally reference images for style transfer.
*   **Outputs:** A stylized DVR scene represented by the optimized networks, allowing for interactive PSE and NPSE.

**Data Structures:**
1.  **Base NeRF Model:** Uses Instant-NGP architecture [S1].
    *   **Density MLP:** Takes position $x$ and hash-grid encoded features; outputs density $\sigma(x)$.
    *   **Hash-grid Encoder:** Multiresolution hash-grid encoding for efficient optimization [S1].
    *   *Note:* Parameters are frozen after Stage 1.
2.  **Palette Color Network (PCN):** Composed of two branches [S1]:
    *   **Specular Branch (Lighting MLP):**
        *   Inputs: Geometry features (from density MLP) and spherical harmonics (SH) encoded view direction $d$.
        *   Output: Grayscale specular color $c_s(x, d)$.
    *   **Diffuse Branch (Palette MLP):**
        *   Inputs: Features from palette hash-grid encoder $E_p$.
        *   Outputs: Intensity $I(x)$, weights $\omega_i(x)$ for $N_P$ palette colors, and color offsets $\delta_i(x)$.
    *   **Palette Colors:** $P = \{P_1, ..., P_{N_P}\}$, extracted and refined from input images.
3.  **Unrestricted Color Network (UCN):**
    *   Architecture: Similar to the diffuse branch but without palette constraints.
    *   Inputs: Geometry features (no view direction $d$ during optimization to ensure cross-view consistency).
    *   Output: Diffuse color $c_d(x)$.

**Numbered Steps:**

1.  **Stage 1: Base NeRF Optimization**
    *   Optimize the base NeRF model (Instant-NGP) to reconstruct scene geometry using the loss $L_{BASE}$ [S1]:
        $$ L_{BASE} = ||c(r) - \hat{c}(r)||_2^2 $$
        where $c(r)$ is ground-truth color and $\hat{c}(r)$ is predicted color [S1].
    *   Freeze all parameters of the base NeRF (density MLP and hash-grid encoder) to prevent style editing from affecting geometry [S1].

2.  **Palette Refinement**
    *   Extract initial palette colors $P_{CONVEX}$ using the RGB convex hull method from multi-view images [S1].
    *   Refine the palette by removing similar colors. Calculate the distance between colors in HSB space using only the hue component. If the distance is below a threshold, remove the color [S1].
    *   Determine the final number of palette colors $N_P$ [S1].

3.  **Stage 2: PCN Optimization (PSE)**
    *   Initialize the PCN. Initialize shallow layers of the palette MLP with hidden parameters from the base NeRF’s color function [S1].
    *   Optimize PCN parameters and palette colors $P$ using the loss $L_{PALETTE}$ [S1]:
        $$ L_{PALETTE} = ||c(r) - \hat{c}(r)||_2^2 + \lambda_\delta \sum_{i=1}^{M} \sum_{j=1}^{N_P} ||\delta_j(x_i)||_2^2 $$
        where $\lambda_\delta = 0.1$ is the regularization strength [S1].
    *   The predicted color $c(x, d)$ is computed as [S1]:
        $$ c(x, d) = c_s(x, d) + I(x) \sum_{i=1}^{N_P} \omega_i(x)(P_i + \delta_i(x)) $$
    *   Render $\hat{c}(r)$ using the standard NeRF volume rendering equation [S1]:
        $$ \hat{c}(r) = \sum_{i=1}^{M} \alpha_i (1 - \omega_i) c(x_i, d) $$
        where $\omega_i = \exp(-(t_i - t_{i-1})\sigma(x_i))$ is transmittance, $\alpha_i = \prod_{j=1}^{i-1} \omega_i$ is attenuation, and $r=(o,d)$ is the ray [S1].

4.  **Photorealistic Style Editing (PSE) Setup**
    *   For PSE, compute the difference $\Delta P$ between the original palette $P$ and target palette $P'$ in HSB space [S1].
    *   Add $\Delta P_i$ to $P_i + \delta_i(x)$ in the color equation [S1].
    *   For opacity/lighting editing, multiply $\sigma(x_{P_i})$ or $c_s(x_{P_i}, d)$ by a scalar [S1].

5.  **Stage 3: UCN Optimization (NPSE) via Knowledge Distillation (KD)**
    *   **Initialization:** Perform color transfer in the PCN (teacher) to match target style colors. This ensures the UCN (student) color representation matches selected styles before NPSE [S1].
    *   **Optimization:** Optimize the UCN using KD to transfer color knowledge from the PCN [S1].
    *   Remove view direction input in UCN optimization to ensure cross-view consistency during NPSE [S1].
    *   Optimize on a single camera view by rendering different regions independently to map a style to a region [S1].
    *   Utilize the additional lighting MLP (optimized in Stage 2) to preserve DVR lighting during NPSE, keeping view directions for lighting calculation [S1].

6.  **Inference**
    *   For partial stylization, combine color representations: regions preserving original appearance use colors from PCN; stylized regions use UCN [S1].
    *   Perform additional feedforward steps of the lighting MLP to provide lighting information [S1].

```python
def render_neRF(ray_o, ray_d, density_mlp, hash_grid, color_fn):

# Stage 1: Base NeRF
def train_base_nerf(images, tf):

    for epoch in epochs:

# Stage 2: PCN
def train_pcn(density_mlp, hash_grid, images, ref_images):
    # Extract initial palette
    P_convex = extract_convex_hull_colors(ref_images)
    # Refine palette
    P = refine_palette(P_convex, threshold=0.1) # Threshold based on hue distance
    N_P = len(P)
    
    lighting_mlp = init_lighting_mlp()
    palette_mlp = init_palette_mlp()
    # Initialize shallow layers of palette_mlp with base NeRF hidden params [S1]
    init_palette_mlp_shallow(palette_mlp, density_mlp)
    
    optimizer = Adam([lighting_mlp.parameters(), palette_mlp.parameters(), P])
    
    for epoch in epochs:
        for image in images:
            ray_o, ray_d = sample_rays(image)
            points, depths = sample_points(ray_o, ray_d, density_mlp)
            
            # Get geometry features
            geo_features = density_mlp(points, hash_grid)
            
            # Specular branch
            view_dir_sh = encode_spherical_harmonics(ray_d)
            c_s = lighting_mlp(geo_features, view_dir_sh)
            
            # Diffuse branch
            palette_features = palette_mlp(points, hash_grid) # Uses palette hash-grid encoder E_p
            I = intensity(palette_features)
            weights = softmax(palette_weights(palette_features)) # N_P weights
            delta = color_offsets(palette_features) # N_P offsets
            
            # Compute diffuse color
            c_d = I * sum(weights[i] * (P[i] + delta[i]) for i in range(N_P))
            
            # Total color
            c = c_s + c_d
            
            # Render
            sigma = density_mlp(points, hash_grid)
            c_pred = render_neRF(ray_o, ray_d, density_mlp, hash_grid, lambda x, d: c)
            c_gt = image.color
            
            # Loss
            mse_loss = mse(c_gt, c_pred)
            reg_loss = LAMBDA_DELTA * sum(norm(delta[i])**2 for i in range(N_P))
            loss = mse_loss + reg_loss
            
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
    return lighting_mlp, palette_mlp, P

# Stage 3: UCN (NPSE)
def train_ucn(pcn_lighting_mlp, pcn_palette_mlp, pcn_P, images, target_style_ref):
    # Color transfer in PCN to match target style
    pcn_P = transfer_style_colors(pcn_P, target_style_ref)
    
    ucn = init_ucn()
    # KD: UCN learns to match PCN output
    optimizer = Adam(ucn.parameters())
    
    for epoch in epochs:
        for image in images: # Optimize on single view for region mapping
            ray_o, ray_d = sample_rays(image)
            points, depths = sample_points(ray_o, ray_d, density_mlp)
            
            # PCN (Teacher)
            geo_features = density_mlp(points, hash_grid)
            c_s_teacher = pcn_lighting_mlp(geo_features, encode_spherical_harmonics(ray_d))
            # PCN diffuse
            I_t = intensity(pcn_palette_mlp(points, hash_grid))
            w_t = softmax(pcn_palette_weights(pcn_palette_mlp(points, hash_grid)))
            d_t = pcn_palette_offsets(pcn_palette_mlp(points, hash_grid))
            c_d_teacher = I_t * sum(w_t[i] * (pcn_P[i] + d_t[i]) for i in range(N_P))
            c_teacher = c_s_teacher + c_d_teacher
            
            # UCN (Student) - No view direction input
            ucn_features = ucn(points, hash_grid) # Or similar encoder
            c_d_student = ucn_output(ucn_features)
            
            # KD Loss: Match student to teacher
            kd_loss = mse(c_d_student, c_d_teacher)
            
            # Optional: Add reconstruction loss if needed, but primary is KD
            loss = kd_loss
            
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
    return ucn

# Inference
def render_stylized(ray_o, ray_d, density_mlp, hash_grid, lighting_mlp, palette_mlp, P, ucn, region_mask):
    points, depths = sample_points(ray_o, ray_d, density_mlp)
    geo_features = density_mlp(points, hash_grid)
    
    # Lighting (Preserved)
    c_s = lighting_mlp(geo_features, encode_spherical_harmonics(ray_d))
    
    # Diffuse: Mix PCN and UCN based on region mask
    # If region_mask indicates stylized, use UCN. Else use PCN.
    # Note: UCN does not take view direction
    c_d_ucn = ucn_output(ucn(points, hash_grid))
    
    # PCN Diffuse
    I_p = intensity(palette_mlp(points, hash_grid))
    w_p = softmax(palette_weights(palette_mlp(points, hash_grid)))
    d_p = palette_offsets(palette_mlp(points, hash_grid))
    c_d_pcn = I_p * sum(w_p[i] * (P[i] + d_p[i]) for i in range(N_P))
    
    # Combine
    c_d = where(region_mask, c_d_ucn, c_d_pcn)
    c = c_s + c_d
    
    sigma = density_mlp(points, hash_grid)
    return render_neRF(ray_o, ray_d, density_mlp, hash_grid, lambda x, d: c)
```

**Parameters:**
*   $\lambda_\delta = 0.1$: Regularization strength for color offsets [S1].
*   Initial Transfer Function (TF): Defines opacity ranges. Regions with opacity equal to zero in the initial TF cannot be represented by NeRF and thus cannot undergo PSE or NPSE [S1].
*   Palette Refinement Threshold: Hue distance threshold in HSB space for removing similar colors [S1].

**Edge Cases and Pitfalls:**
*   **Zero Opacity:** If the initial TF sets opacity to zero for certain regions, NeRF cannot represent these values, and PSE/NPSE cannot be applied to them [S1].
*   **Similar Colors:** If colors among different regions in the input DVR scene are similar, palette refinement may not separate them correctly. Users must manually adjust the number of palette colors and their RGB values [S1].
*   **Lighting Direction:** Lighting direction cannot be modified because no normal information is available, although lighting intensity can be adjusted [S1].
*   **NPSE Consistency:** Discarding view direction in UCN is necessary for cross-view consistency but requires careful initialization via PSE color transfer to avoid inaccurate style matching [S1].

## Operating characteristics
*   **Time Complexity:** Training is slower than ARF but faster than SNeRF [S1]. The process involves three stages: Base NeRF, PCN, and UCN (KD) [S1]. NPSE optimization on a single camera view requires rendering different regions independently, slowing the stylization process [S1].
*   **Memory Complexity:** Uses Instant-NGP hash-grid encoding, which is memory efficient compared to dense voxel grids [S1]. Additional memory for PCN and UCN parameters [S1].
*   **Measured Performance:**
    *   Inference time on combustion dataset: 564 ms [S1].
    *   Training time on combustion dataset: 1.2 h [S1].
    *   Training time on vortex dataset: 29.7 m [S1].
    *   Inference time on vortex dataset: 373 ms [S1].
    *   Cross-view consistency: Achieves best short- and long-range cross-view consistency (MSE and LPIPS) compared to AdaIN, ReReVST, ARF, and SNeRF [S1].
*   **Strengths:** Supports both PSE and NPSE in a single framework; preserves view-dependent lighting; allows explicit assignment of different styles to different regions; better cross-view consistency than image-based methods [S1].
*   **Limitations:** Slower training than ARF; interactive PSE supported but not interactive NPSE; cannot modify lighting direction; sensitive to similar colors in input [S1].
*   **When to use:** When high-quality, cross-view consistent stylization of DVR scenes is required, especially when mixing PSE and NPSE or applying different styles to different regions.
*   **When not to use:** When real-time interactive NPSE is required, or when lighting direction modification is needed.

## Background
StyleRF-VolVis is the first work in VolVis that targets style transfer in the NeRF space [S1]. It builds on NeRF representation  and Instant-NGP architecture . It adapts NeRF's palette-based recoloring strategy  and uses Knowledge Distillation (KD)  to transfer color knowledge. It differs from prior works like ARF  and SNeRF  by supporting both photorealistic and non-photorealistic editing in a single framework and preserving view-dependent lighting [S1].
