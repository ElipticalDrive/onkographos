# Mip-NeRF 360 MLP Architecture

Also called: Integrated Positional Encoding MLP, PosEnc MLP

## Overview
The Mip-NeRF 360 MLP architecture is a specific neural network configuration for radiance fields that replaces standard positional encoding with **integrated positional encoding** to handle aliasing and frequency mismatch during volume rendering [S1, unofficial]. It consists of a density network and a color network separated by a bottleneck feature vector, where the density network processes 3D coordinates with integrated encoding and the color network processes the bottleneck features combined with directional encoding [S1, unofficial]. This architecture is distinct from standard NeRF by explicitly modeling the integration of the positional encoding function over the conical frustum of a ray segment, rather than sampling at discrete points [S1, unofficial].

## How it works
The method maps a 3D spatial coordinate $\mathbf{x} \in \mathbb{R}^3$ and a viewing direction $\mathbf{d} \in \mathbb{R}^3$ to volume density $\sigma \in \mathbb{R}$ and color $\mathbf{c} \in \mathbb{R}^3$. The implementation relies on JAX and Flax conventions as found in the reference source [S1, unofficial].

### Inputs and Outputs
*   **Inputs:**
    *   `means`: Array of shape `(..., 3)` representing 3D coordinates.
    *   `covs`: Array of shape `(..., 3, 3)` representing the covariance matrices of the conical frustums at those coordinates.
    *   `viewdirs`: Array of shape `(..., 3)` representing viewing directions.
    *   `refdirs`: (Optional) Array of shape `(..., 3)` representing reflection directions.
    *   `normals`: (Optional) Array of shape `(..., 3)` representing surface normals.
*   **Outputs:**
    *   `rgb`: Array of shape `(..., 3)` representing final colors.
    *   `raw_density`: Scalar or array of raw density values.
    *   `normals`: Array of shape `(..., 3)` representing computed surface normals.

### Data Structures and Configuration
The architecture is defined by a configuration object containing the following fields [S1, unofficial]:

| Field | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `net_depth` | int | 8 | Depth of the density MLP. |
| `net_width` | int | 256 | Width of the density MLP layers. |
| `bottleneck_width` | int | 256 | Width of the bottleneck feature vector. |
| `net_depth_viewdirs` | int | 1 | Depth of the color MLP. |
| `net_width_viewdirs` | int | 128 | Width of the color MLP layers. |
| `min_deg_point` | int | 0 | Minimum degree for point positional encoding. |
| `max_deg_point` | int | 12 | Maximum degree for point positional encoding. |
| `skip_layer` | int | 4 | Frequency of skip connections in density MLP. |
| `skip_layer_dir` | int | 4 | Frequency of skip connections in color MLP. |
| `deg_view` | int | 4 | Degree of directional encoding. |
| `density_bias` | float | -1.0 | Bias added to raw density before activation. |
| `density_noise` | float | 0.0 | Standard deviation of noise added to raw density. |
| `rgb_bias` | float | 0.0 | Bias added to raw color before activation. |
| `rgb_padding` | float | 0.001 | Padding for RGB output range. |
| `use_reflections` | bool | False | Use reflection directions instead of view directions. |
| `use_directional_enc` | bool | False | Use Integrated Directional Encoding (IDE). |
| `enable_pred_normals` | bool | False | Enable explicit normal prediction. |
| `disable_density_normals` | bool | True | Disable automatic normal computation from density. |
| `basis_shape` | str | 'icosahedron' | Basis shape for integrated encoding. |
| `basis_subdivisions` | int | 2 | Tessellation count for the basis. |
| `use_diffuse_color` | bool | False | Predict diffuse/specular split. |
| `use_specular_tint` | bool | False | Predict specular tint vector. |
| `use_n_dot_v` | bool | False | Feed $\mathbf{n} \cdot \mathbf{v}$ to color network. |
| `bottleneck_noise` | float | 0.0 | Noise added to bottleneck features. |
| `density_activation` | Callable | ReLU | Activation for density. |
| `rgb_activation` | Callable | Sigmoid | Activation for RGB. |
| `net_activation` | Callable | ReLU | Activation for hidden layers. |

import jax.numpy as jnp
import jax
from jax import random

def mlp_mipnerf_360(
    means, covs, viewdirs, refdirs=None, normals=None,
    config, pos_basis_t, dir_enc_fn, key=None
):
    """
    Implements the Mip-NeRF 360 MLP architecture.
    
    Args:
        means: (..., 3) 3D coordinates.
        covs: (..., 3, 3) Covariance matrices of conical frustums.
        viewdirs: (..., 3) Viewing directions.
        refdirs: (..., 3) Optional reflection directions.
        normals: (..., 3) Optional surface normals.
        config: Configuration object with hyperparameters.
        pos_basis_t: Transpose of the basis matrix for integrated PE.
        dir_enc_fn: Function to encode directions.
        key: Random key for noise.
        
    Returns:
        rgb: (..., 3) Final colors.
        raw_density: Raw density values.
        normals_out: Computed normals.
    """
    
    # 1. Setup and Validation
    if config.use_reflections:
        if config.enable_pred_normals and config.disable_density_normals:
            raise ValueError("Reflections require normals to be computed.")
        # Flip viewdirs because they point from camera to point, 
        # but reflection functions typically assume point to camera.
        viewdirs = -viewdirs
        
    # 2. Density Network Input: Integrated Positional Encoding
    # Linearize means and covs if a warp function is provided
    if config.warp_fn is not None:
        means, covs = track_linearize(config.warp_fn, means, covs)
        
    # Lift and diagonalize to get variances for integrated PE
    lifted_means, lifted_vars = lift_and_diagonalize(
        means, covs, pos_basis_t
    )
    
    # Compute integrated positional encoding
    # This integrates the sinusoidal encoding over the Gaussian distribution
    # defined by mean and variance, providing aliasing-free features.
    x = integrated_pos_enc(
        lifted_means, lifted_vars, 
        config.min_deg_point, config.max_deg_point
    )
    
    # 3. Density Network (MLP)
    # Hidden layers with skip connections
    for i in range(config.net_depth):
        x = dense(x, config.net_width)
        x = config.net_activation(x)
        if i > 0 and i % config.skip_layer == 0:
            x = jnp.concatenate([x, x_original], axis=-1)
            
    # Output raw density
    raw_density = dense(x, 1)[..., 0]
    
    # Add noise to density if configured
    if config.density_key is not None and config.density_noise > 0:
        noise = random.normal(key, raw_density.shape)
        raw_density += config.density_noise * noise
        
    # 4. Normal Computation (if enabled)
    if not config.disable_density_normals:
        # Compute gradient of raw density w.r.t. means
        # Using value_and_grad for efficiency
        raw_density_val, raw_grad_density = jax.value_and_grad(
            lambda m: predict_density(m, covs, config, pos_basis_t, dir_enc_fn),
            has_aux=False
        )(means)
        
        # Normals are negative normalized gradient
        normals_out = l2_normalize(-raw_grad_density)
    else:
        normals_out = normals if normals is not None else None
        
    # Apply density activation and bias
    final_density = config.density_activation(raw_density + config.density_bias)
    
    # 5. Directional Encoding
    if config.use_reflections and refdirs is not None:
        dir_input = refdirs
    else:
        dir_input = viewdirs
        
    if config.use_directional_enc:
        dir_enc = dir_enc_fn(dir_input)
    else:
        # Standard positional encoding for directions
        dir_enc = pos_enc(dir_input, min_deg=0, max_deg=config.deg_view, append_identity=True)
        
    # 6. Color Network Input Preparation
    # Get bottleneck features (from previous step or density network output)
    # Note: In standard NeRF, bottleneck is output of density network hidden layer.
    # Here, we assume 'bottleneck' is passed or derived. 
    # Based on notes, bottleneck is concatenated with dir_enc.
    
    # Broadcast dir_enc to match bottleneck shape
    # Assuming bottleneck has shape (..., bottleneck_width)
    dir_enc_expanded = jnp.broadcast_to(
        dir_enc[..., None, :], 
        bottleneck.shape[:-1] + (dir_enc.shape[-1],)
    )
    
    x_color = [bottleneck, dir_enc_expanded]
    
    # Optional: Add n dot v
    if config.use_n_dot_v and normals_out is not None:
        n_dot_v = jnp.sum(normals_out * viewdirs[..., None, :], axis=-1, keepdims=True)
        x_color.append(n_dot_v)
        
    # Optional: Add GLO vectors (global illumination)
    if config.glo_vec is not None:
        glo_expanded = jnp.broadcast_to(
            config.glo_vec[..., None, :], 
            bottleneck.shape[:-1] + (config.glo_vec.shape[-1],)
        )
        x_color.append(glo_expanded)
        
    # Concatenate all inputs
    x_color = jnp.concatenate(x_color, axis=-1)
    
    # 7. Color Network (MLP)
    for i in range(config.net_depth_viewdirs):
        x_color = dense(x_color, config.net_width_viewdirs)
        x_color = config.net_activation(x_color)
        if i > 0 and i % config.skip_layer_dir == 0:
            x_color = jnp.concatenate([x_color, x_color_original], axis=-1)
            
    # 8. RGB Output
    raw_rgb = dense(x_color, config.num_rgb_channels)
    
    # Apply RGB bias and premultiplier
    rgb_premultiplied = config.rgb_premultiplier * raw_rgb + config.rgb_bias
    
    # Handle diffuse/specular split if enabled
    if config.use_diffuse_color:
        # Predict diffuse and specular separately
        raw_rgb_diffuse = raw_rgb[..., 0:3] # Assuming specific channel layout
        diffuse_linear = jnp.sigmoid(raw_rgb_diffuse - jnp.log(3.0))
        
        if config.use_specular_tint:
            specular_linear = config.tint * rgb_premultiplied
        else:
            specular_linear = 0.5 * rgb_premultiplied
            
        rgb_combined = specular_linear + diffuse_linear
        rgb = jnp.clip(linear_to_srgb(rgb_combined), 0.0, 1.0)
    else:
        rgb = config.rgb_activation(rgb_premultiplied)
        
    # Apply RGB padding
    rgb = rgb * (1 + 2 * config.rgb_padding) - config.rgb_padding
    
    return rgb, raw_density, normals_out

def integrated_pos_enc(means, variances, min_deg, max_deg):
    """
    Computes integrated positional encoding for a Gaussian distribution.
    The integral of sin(2^d * pi * (mu + sigma * z)) over z ~ N(0,1)
    results in sin(2^d * pi * mu) * exp(-0.5 * (2^d * pi * sigma)^2).
    """
    degrees = jnp.arange(min_deg, max_deg)
    scales = jnp.power(2, degrees)
    
    # Compute the variance scaling factor
    # exp(-0.5 * (scale * sigma)^2)
    var_scales = jnp.exp(-0.5 * (scales * jnp.sqrt(variances))**2)
    
    # Standard PE: sin(2^d * pi * mu) and cos(2^d * pi * mu)
    scaled_means = means[..., None, :] * scales[:, None, None] * jnp.pi
    sin_vals = jnp.sin(scaled_means)
    cos_vals = jnp.cos(scaled_means)
    
    # Apply variance scaling
    sin_vals = sin_vals * var_scales[..., None]
    cos_vals = cos_vals * var_scales[..., None]
    
    return jnp.concatenate([sin_vals, cos_vals], axis=-1)

def lift_and_diagonalize(means, covs, basis_t):
    """
    Lifts the covariance matrix into the basis space and diagonalizes it.
    Returns lifted means and variances.
    """
    # Project means into basis
    lifted_means = jnp.matmul(means, basis_t)
    
    # Project covariances and extract diagonal
    # covs_lifted = basis_t^T @ covs @ basis_t
    # variances = diag(covs_lifted)

    lifted_vars = jnp.diagonal(covs_lifted, axis1=-2, axis2=-1)
    
    return lifted_means, lifted_vars

### Parameters and Typical Values
*   **Network Depth:** The density network typically has 8 layers (`net_depth=8`), while the color network has 1 layer (`net_depth_viewdirs=1`) [S1, unofficial].
*   **Width:** Density network width is 256 (`net_width=256`), color network width is 128 (`net_width_viewdirs=128`), and bottleneck width is 256 (`bottleneck_width=256`) [S1, unofficial].
*   **Encoding Degrees:** Point encoding ranges from degree 0 to 12 (`min_deg_point=0`, `max_deg_point=12`), and view direction encoding uses degree 4 (`deg_view=4`) [S1, unofficial].
*   **Skip Connections:** Skip connections are added every 4 layers in both networks (`skip_layer=4`, `skip_layer_dir=4`) [S1, unofficial].
*   **Density Bias:** A bias of -1.0 is added to raw density before activation (`density_bias=-1.0`) to keep initial densities low [S1, unofficial].

### Edge Cases and Pitfalls
*   **Reflections and Normals:** If `use_reflections` is True, normals must be available. If `enable_pred_normals` is False and `disable_density_normals` is True, a `ValueError` is raised [S1, unofficial].
*   **View Direction Flip:** When using reflections, view directions must be flipped (`-viewdirs`) before computing the reflection vector, as standard reflection functions assume directions pointing toward the camera, while NeRF rays point from camera to point [S1, unofficial].
*   **Normal Stability:** Normals are computed from the gradient of the **raw** (pre-activation) density, not the activated density, because the activation function (e.g., ReLU) can have zero or steep gradients that destabilize normal estimation [S1, unofficial].
*   **Precision:** Evaluations and color correction should use 64-bit floating point precision to avoid artifacts in metric computation [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The integrated positional encoding adds computational overhead compared to standard positional encoding due to the calculation of variances and exponential scaling factors, but it reduces the need for high-frequency sampling, potentially allowing for coarser sampling strategies [S1, unofficial].
*   **Memory Complexity:** The architecture uses standard MLP memory footprint. The basis matrix for integrated encoding is precomputed and stored, adding negligible memory overhead [S1, unofficial].
*   **Strengths:** Significantly reduces aliasing artifacts in novel views, especially for scenes with high-frequency details or large depth variations, by integrating the encoding function over the ray segment [S1, unofficial].
*   **Limitations:** Slightly more complex implementation than standard NeRF. The integrated encoding assumes a Gaussian distribution of the ray segment, which may not perfectly model all sampling strategies [S1, unofficial].
*   **When to Use:** Recommended for "in-the-wild" scenes with large depth ranges and high-frequency textures, where standard NeRF suffers from aliasing [S1, unofficial].

## Background
The Mip-NeRF 360 MLP architecture was introduced by Google Research as part of the Mip-NeRF 360 project, which extends the original Mip-NeRF approach to unbounded, in-the-wild scenes [S1, unofficial]. It builds upon the integrated positional encoding concept to handle the frequency mismatch inherent in volume rendering. The implementation details provided are from the official `google-research/multinerf` repository [S1, unofficial].
