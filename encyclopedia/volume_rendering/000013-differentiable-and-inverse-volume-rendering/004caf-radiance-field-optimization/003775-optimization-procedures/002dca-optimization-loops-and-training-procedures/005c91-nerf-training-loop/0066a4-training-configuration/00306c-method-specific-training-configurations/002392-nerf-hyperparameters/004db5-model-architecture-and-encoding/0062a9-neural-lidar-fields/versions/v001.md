# Neural LiDAR Fields


## Overview
Neural LiDAR Fields reconstructs a 3D point cloud scene into an implicit continuous representation by redefining neural fields specifically for LiDAR sensors, modeling geometric depth, reflection intensity, and ray-drop probability [S1]. Unlike standard NeRFs that optimize for photometric RGB loss, this method adapts the radiance field formulation to LiDAR physics, enabling novel space-time view synthesis for dynamic driving scenarios [S1]. It distinguishes itself by combining coarse-resolution multi-planar features with high-resolution hash grid representations to mitigate hash collisions while maintaining efficiency [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** LiDAR point clouds (position, intensity, time), camera intrinsics/extrinsics (for ray generation), and temporal indices for dynamic scenes.
*   **Outputs:** Predicted depth $\hat{\mathcal{D}}$, intensity $\hat{\mathcal{I}}$, and ray-drop probability $\hat{\mathcal{P}}$ for synthesized rays.

**Data Structures**
The method employs a hybrid feature representation to handle large-scale dynamic scenes:
1.  **Multi-planar Features:** Coarse-resolution features stored in planar grids.
2.  **Hash Grid:** High-resolution feature grid using spatial hashing to avoid collisions.
3.  **Temporal Encoding:** Time information is aggregated into the planar and hash features to support 4D (space-time) reconstruction [S1].

**Positional Encoding**
Input coordinates undergo hierarchical positional encoding $\gamma(\cdot)$ [S1]. For a scalar input $p$, the encoding is:
$$ \gamma(p) = (\sin(2^0 \pi p), \cos(2^0 \pi p), \dots, \sin(2^{L-1} \pi p), \cos(2^{L-1} \pi p)) $$
where $L$ is the number of frequency bands . This is applied to position and direction vectors [S1].

**Ray Generation**
Lasers are transmitted at specific angular intervals within the LiDAR's Field of View (FOV), using the sensor center as origin $o$ [S1]. The direction $\mathbf{d}$ is determined by azimuth angle $\theta$ and elevation angle $\phi$ in a polar coordinate system [S1]:
$$ \mathbf{d} = (\cos \theta \cos \phi, \ \sin \theta \sin \phi, \ \cos \phi)^T $$
3D points are sampled along these rays within a defined near/far range [S1].

**Network Architecture and Prediction**
The neural field predicts density $\sigma$, intensity $i$, and ray-drop probability $p$ for each sampled point [S1].
1.  **Feature Query:** Temporal aggregated planar features $\mathbf{f}_{\text{planar}}$ and hash features $\mathbf{f}_{\text{hash}}$ are retrieved based on the 3D position [S1].
2.  **Intensity Prediction:** A dedicated MLP takes the features and position-encoded viewpoint $\gamma(\mathbf{d})$ as input [S1]:
    $$ i = \mathrm{MLP}_{\text{intensity}}(\mathbf{f}_{\text{planar}}, \mathbf{f}_{\text{hash}}, \gamma(\mathbf{d})) $$
3.  **Ray-drop Prediction:** A separate MLP predicts the ray-drop probability $\rho$ (denoted as $p_i$ in rendering equations) [S1]:
    $$ \rho = \mathrm{MLP}_{\text{raydrop}}(\mathbf{f}_{\text{planar}}, \mathbf{f}_{\text{hash}}, \gamma(\mathbf{d})) $$
4.  **Density:** Density $\sigma$ is predicted from the position features (standard NeRF branch) [S1].

**Rendering (Alpha Composition)**
The final outputs are computed by alpha-compositing along the ray $\mathbf{r}$ with $N$ samples [S1]:
*   **Opacity:** $\alpha_i = 1 - e^{-\sigma_i \delta_i}$, where $\delta_i$ is the distance between samples [S1].
*   **Transmittance:** $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ [S1].
*   **Depth:**
    $$ \hat{\mathcal{D}}(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - e^{-\sigma_i \delta_i}) z_i $$
    where $z_i$ is the depth value of the queried point [S1].
*   **Intensity:**
    $$ \hat{\mathcal{I}}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i i_i $$
*   **Ray-drop Probability:**
    $$ \hat{\mathcal{P}}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i p_i $$
    where $i_i$ and $p_i$ are the point-wise outputs [S1].

**Ray-drop Refinement**
To address noisy point-wise ray-drop predictions, a U-Net with residuals refines the global ray-drop mask using the full predicted depth, intensity, and ray-drop probability as inputs [S1]. The refinement loss is binary cross-entropy:
$$ \mathcal{L}_{\text{refine}} = \mathrm{BCELoss}(\hat{\mathcal{M}}_{\text{Pred}}, \mathcal{M}_{\text{GT}}) $$
where $\hat{\mathcal{M}}_{\text{Pred}}$ is the refined mask and $\mathcal{M}_{\text{GT}}$ is the ground truth [S1].

**Pseudocode**
```python
def neural_lidar_fields_render(ray_origin, ray_direction, time_step, planar_features, hash_grid, mlp_intensity, mlp_raydrop, mlp_density, num_samples):
    """
    Renders depth, intensity, and ray-drop probability for a single LiDAR ray.
    """
    # 1. Sample points along the ray
    # Generate N points between near and far bounds
    t_values = linspace(near, far, num_samples)
    points = ray_origin + t_values * ray_direction
    
    # 2. Query features and predict properties
    densities = []
    intensities = []
    ray_drops = []
    
    for point in points:
        # Query hybrid features (planar + hash) at point location for given time
        f_planar = query_planar_features(point, time_step, planar_features)
        f_hash = query_hash_features(point, hash_grid)
        
        # Positional encoding of direction
        d_encoded = positional_encoding(ray_direction)
        
        # Predict density
        sigma = mlp_density(f_planar, f_hash, point)
        densities.append(sigma)
        
        # Predict intensity
        i = mlp_intensity(f_planar, f_hash, d_encoded)
        intensities.append(i)
        
        # Predict ray-drop probability
        p = mlp_raydrop(f_planar, f_hash, d_encoded)
        ray_drops.append(p)
        
    # 3. Alpha composition
    densities = array(densities)
    intensities = array(intensities)
    ray_drops = array(ray_drops)
    
    # Calculate opacity and transmittance
    # delta is distance between consecutive samples
    deltas = diff(t_values, prepend=near) 
    alphas = 1.0 - exp(-densities * deltas)
    
    # Transmittance T_i = product(1 - alpha_j) for j < i
    # T_1 = 1.0
    transmittances = ones(num_samples)
    for i in range(1, num_samples):
        transmittances[i] = transmittances[i-1] * (1.0 - alphas[i-1])
        
    # Render Depth
    # D(r) = sum(T_i * alpha_i * z_i)
    # Note: z_i is the depth value (distance along ray) which is t_values[i]
    depth = sum(transmittances * alphas * t_values)
    
    # Render Intensity
    # I(r) = sum(T_i * alpha_i * i_i)
    intensity = sum(transmittances * alphas * intensities)
    
    # Render Ray-drop Probability
    # P(r) = sum(T_i * alpha_i * p_i)
    ray_drop_prob = sum(transmittances * alphas * ray_drops)
    
    return depth, intensity, ray_drop_prob

def positional_encoding(v, L=10):
    """
    Hierarchical positional encoding.
    gamma(p) = (sin(2^0 pi p), cos(2^0 pi p), ..., sin(2^{L-1} pi p), cos(2^{L-1} pi p))
    """
    encoded = []
    for l in range(L):
        freq = 2**l * pi
        encoded.append(sin(freq * v))
        encoded.append(cos(freq * v))
    return array(encoded)
```

## Operating characteristics
*   **Complexity:** The use of hash grids provides efficient memory access and storage, scaling better than dense volumetric grids for large scenes [S1]. Multi-planar features reduce the memory footprint for coarse geometry [S1].
*   **Performance:** The method is designed for large-scale dynamic driving scenarios, balancing efficiency and reconstruction quality [S1].
*   **Strengths:** Avoids adverse effects of hash collisions through hybrid representation; explicitly models LiDAR-specific physics (intensity, ray-drop) rather than just RGB [S1].
*   **Limitations:** Ray-drop prediction at the point-wise level is inherently noisy and unreliable, requiring a separate U-Net refinement step [S1].

## Background
Neural LiDAR Fields, specifically implemented as LiDAR4D, was introduced to address the limitations of standard NeRFs when applied to LiDAR data. Standard NeRFs rely on photometric loss for RGB images, which does not directly translate to LiDAR's time-of-flight and intensity measurements [S1]. The method builds on the concept of neural radiance fields but redefines the output space to include geometric depth, reflection intensity, and ray-drop probability [S1]. It was developed to enable novel space-time view synthesis for dynamic driving scenarios, incorporating temporal information encoding to handle 4D scenes [S1].
