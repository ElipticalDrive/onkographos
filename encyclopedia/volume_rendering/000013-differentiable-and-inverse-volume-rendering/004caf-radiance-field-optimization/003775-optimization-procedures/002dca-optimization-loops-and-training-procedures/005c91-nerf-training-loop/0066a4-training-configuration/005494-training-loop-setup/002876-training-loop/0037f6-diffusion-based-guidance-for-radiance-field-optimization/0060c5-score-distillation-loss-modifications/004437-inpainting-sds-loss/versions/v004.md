# Inpainting SDS Loss

Also called: Inpainting-based Score Distillation Sampling, SDS loss with scene context

## Overview
Inpainting SDS Loss (LiSDS) is a score distillation method that guides the optimization of a radiance field by conditioning a diffusion model on both a text prompt and a spatial mask representing known scene context [S1, unofficial][S2]. It solves the problem of incomplete or poorly composited object generation inherent in vanilla SDS, which often produces isolated parts (e.g., only a head) that fail to integrate with the background [S2]. By using an inpainting diffusion model, LiSDS ensures the generated object maintains complete geometry and proper pose relative to the scene [S2]. It is distinguished from [Mask+SDS with Background Prompt](14382-mask-sds-with-background-prompt.md) by its specific reliance on the inpainting variant of the diffusion model to harmonize the new object with existing scene information [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Radiance field parameters $\Theta$, text embedding $y$, binary mask $M$, and optionally a masked image $I_M$ containing the known scene context [S1, unofficial][S2].
*   **Outputs:** Gradient signal $\nabla_\Theta L$ for updating $\Theta$ [S2].

**Data Structures:**
*   **Mask $M$:** A binary mask indicating the region to be inpainted or optimized. In [S2], $M$ is derived by projecting a 3D bounding box into the camera viewpoint. In [S1, unofficial], $M$ distinguishes between in-boundary (IB) and out-of-boundary (OB) regions relative to the object prior [S1, unofficial].
*   **Noisy Image $x_t$ / $I_t$:** The rendered image $I$ perturbed by Gaussian noise $\epsilon$ at time step $t$ [S1, unofficial][S2].

**Parameters:**
*   **Time step $t$:** Randomly sampled from the diffusion process [S1, unofficial][S2].
*   **Weighting $\omega(t)$:** Derived from the variance schedule [S2].
*   **Loss weights:** $\lambda_{iSDS}$, $\delta_R(\theta, \phi)$, $\lambda_{sp}$ (for sparsity) [S1, unofficial].

**Steps:**
1.  **Render:** Render an image $I$ from the radiance field $\Theta$ at a camera viewpoint [S2].
2.  **Mask Application:** Apply the binary mask $M$ to define the inpainting region. If using the approach in [S2], construct the masked image $I_M$ by combining the rendered image with the known scene context within the mask [S2].
3.  **Noise Addition:** Transform the image into a noisy image $x_t$ (or $I_t$) at a random time step $t$:
    $$ x_t = \sqrt{\bar{\alpha}_t} I + \sqrt{1-\bar{\alpha}_t} \epsilon $$
    where $\epsilon$ is Gaussian noise [S1, unofficial][S2].
4.  **Noise Prediction:** Pass the noisy image $x_t$ (and $I_M$ if applicable), text embedding $y$, mask $M$, and time step $t$ into a fine-tuned or pre-trained inpainting diffusion model $\epsilon_\phi$ to predict the noise $\hat{\epsilon}$ [S1, unofficial][S2]:
    $$ \hat{\epsilon} = \epsilon_\phi(x_t; y, t, M) \quad \text{or} \quad \epsilon_\phi(I_t; y, I_M, M, t) $$
5.  **Loss Calculation:** Compute the Inpainting SDS Loss $L_{iSDS}$ as the squared difference between the predicted noise and the actual noise [S1, unofficial][S2]:
    $$ L_{iSDS} = \mathbb{E}_{t,\epsilon} [||\hat{\epsilon} - \epsilon||^2_2] $$
6.  **Gradient Computation:** Calculate the gradient with respect to the radiance field parameters $\Theta$:
    $$ \nabla_\Theta L_{iSDS} = \mathbb{E}_{t,\epsilon,C} [\omega(t) \cdot (\hat{\epsilon} - \epsilon) \frac{\partial x_t}{\partial \Theta}] $$
    where $C$ represents the conditioning information (text, mask, scene) [S2].

**Edge Cases and Pitfalls:**
*   **Vanilla SDS Failure:** Using vanilla SDS without inpainting context leads to incomplete objects (e.g., generating only a cat's head) that do not composite correctly [S2].
*   **Texture Continuity:** Without refinement, generated parts may lack texture continuity with the prior [S1, unofficial].
*   **Saturation:** Generated objects may exhibit over-saturation if saturation loss is not applied [S2].

**Pseudocode:**
```python
def inpainting_sds_loss(radiance_field, camera, text_embedding, mask, diffusion_model, time_step_sampler, weighting_function):
    """
    Computes the Inpainting SDS Loss gradient.
    
    Args:
        radiance_field: The NeRF or radiance field parameters theta.
        camera: Camera pose and intrinsics.
        text_embedding: Text conditioning y.
        mask: Binary mask M for the inpainting region.
        diffusion_model: Inpainting diffusion model epsilon_phi.
        time_step_sampler: Sampler for time step t.
        weighting_function: Function omega(t).
        
    Returns:
        gradient: Gradient with respect to radiance field parameters.
    """
    # 1. Render image from radiance field
    # Note: Implementation details of rendering depend on the specific radiance field type (NeRF, 3DGS)
    rendered_image = render(radiance_field, camera)
    
    # 2. Sample time step and noise
    t = time_step_sampler()
    epsilon = sample_gaussian_noise(rendered_image.shape)
    
    # 3. Create noisy image
    # alpha_bar_t is the cumulative product of alpha schedule up to t
    alpha_bar_t = get_alpha_bar(t)
    noisy_image = sqrt(alpha_bar_t) * rendered_image + sqrt(1 - alpha_bar_t) * epsilon
    
    # 4. Predict noise using inpainting model
    # The model conditions on text, mask, and potentially the masked image
    # If the model requires the masked image I_M, it must be constructed here
    # I_M = apply_mask(rendered_image, mask) # Depending on model implementation
    predicted_noise = diffusion_model(noisy_image, text_embedding, mask, t)
    
    # 5. Compute loss
    loss = mean_squared_error(predicted_noise, epsilon)
    
    # 6. Compute gradient
    # Backpropagate through the diffusion model and the rendering process
    gradient = compute_gradient(loss, radiance_field)
    
    return gradient
```

## Subtopics

### [MVIP-NeRF](11931-mvip-nerf.md)
MVIP-NeRF is a diffusion-based method for multiview-consistent inpainting of Neural Radiance Fields (NeRFs). It solves the problem of reconstructing missing geometry and texture in masked regions of a scene while maintaining consistency across multiple camera views. Unlike prior approaches that rely on independent 2D inpainting per view—often resulting in inconsistencies and poor geometry—MVIP-NeRF jointly optimizes across views. It employs Score Distillation Sampling (SDS) with a text-conditioned diffusion model to guide inpainting in masked regions, alongside RGB reconstruction in visible areas.

### RefFusion
RefFusion inpaints one reference image using an inpainting Latent Diffusion Model (LDM) on both global and locally cropped versions of the reference view [S3]. It utilizes SDS loss to distill learned priors from the adapted LDM into the scene, incorporating a discriminator loss and depth loss to improve quality [S3]. Quantitatively, RefFusion surpassed all baselines in LPIPSdir (0.4283) compared to NeRF-In (0.4884), SPIn-NeRF (SD) (0.5701), SPIn-NeRF (LaMa) (0.4654), Inpaint3D (0.5150), Reference-guided inpainting (SDV2) (0.4532), and Reference-guided inpainting (SDXL) (0.4453) [S3].

### Random Patch Refinement
Random Patch Refinement is a refinement step applied during the last 10% of training to improve texture and color continuity by masking foreground patches and optimizing them with LiSDS, excluding the Reliability-guided loss ($L_R$) [S1, unofficial]. During this final phase, if an in-boundary view is sampled, $L_R$ is excluded, and a random patch is given to the foreground to refine the corresponding part with LiSDS [S1, unofficial]. This process results in the color and texture of the generated 3D object becoming more similar to the part generated by LiSDS, while maintaining the overall shape and content of the image prior [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the number of diffusion steps and the cost of rendering the radiance field. The inpainting model inference adds significant overhead compared to vanilla SDS [S1, unofficial][S2].
*   **Memory Complexity:** Requires storing the radiance field, the diffusion model weights, and intermediate noisy images [S1, unofficial][S2].
*   **Performance:** LiSDS generates complete objects with proper poses that seamlessly integrate with the scene, outperforming vanilla SDS which often generates incomplete parts [S2]. GO-NeRF using LiSDS achieved an average CLIP score of 74.6, significantly outperforming baselines like Blended-NeRF (63.0) and Spin-NeRF (60.8) [S2].
*   **Strengths:** Ensures harmonized composition with existing scene context; generates complete geometry; maintains texture continuity with refinement [S1, unofficial][S2].
*   **Limitations:** Requires a fine-tuned or pre-trained inpainting diffusion model; may require additional losses (sparsity, saturation) for optimal results [S1, unofficial][S2].
*   **When to use:** When generating 3D objects that need to be integrated into an existing 3D scene or when inpainting missing parts of a scene [S1, unofficial][S2].
*   **When not to use:** When generating a standalone object without scene context, vanilla SDS may be sufficient and faster [S2].

## Background
Inpainting SDS Loss was introduced to address the limitations of vanilla Score Distillation Sampling (SDS) in 3D generation, specifically the issue of incomplete object generation and poor scene integration [S1, unofficial][S2]. The method leverages the capabilities of 2D inpainting diffusion models to provide generative priors conditioned on text and scene information [S2]. It builds on the principles of [Score Distillation Loss Modifications](18224-score-distillation-loss-modifications.md) and is closely related to [Mask+SDS with Background Prompt](14382-mask-sds-with-background-prompt.md) [S1, unofficial][S2].
