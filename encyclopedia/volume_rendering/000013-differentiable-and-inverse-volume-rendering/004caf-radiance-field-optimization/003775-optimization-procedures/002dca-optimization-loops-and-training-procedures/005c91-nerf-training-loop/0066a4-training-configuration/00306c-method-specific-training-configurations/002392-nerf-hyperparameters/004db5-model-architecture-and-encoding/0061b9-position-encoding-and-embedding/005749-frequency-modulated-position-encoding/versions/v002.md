# Frequency-Modulated Position Encoding

Also called: FM-NeRF Encoding, Frequency-Modulated Point Cloud Rendering with Easy Editing

## Overview
Frequency-Modulated Position Encoding is a coordinate encoding scheme used in point-based radiance field optimization to map 3D spatial coordinates and viewing directions into a high-dimensional feature space. It solves the problem of representing high-frequency geometric and appearance details in sparse point clouds by applying sine and cosine basis functions with exponentially increasing frequencies. It differs from standard NeRF positional encoding by narrowing the encoding interval and using specific frequency bands (powers of 2 and 2^0.5) to provide finer basis function support, which is critical for the stability of point-based volume rendering and subsequent editing tasks.

**Numbered Steps:**
1.  **Preprocessing (Optional but part of the method's pipeline):**
    - Perform 4-20 loops of point cloud denoising and completion.
    - For each denoising step, train for 300 epochs.
    - When training converges, remove low-opacity points.
2.  **Coordinate Encoding:**
    - For each 3D point $\mathbf{p}$, compute the spatial encoding $\gamma(\mathbf{p})$ using $L_{spatial}=10$ bands.
    - For each viewing direction $\mathbf{d}$, compute the directional encoding $\gamma(\mathbf{d})$ using $L_{dir}=2$ bands.
    - Concatenate $\gamma(\mathbf{p})$ and $\gamma(\mathbf{d})$ to form the input feature vector.
3.  **Feature Extraction (AFNet MLP):**
    - Pass the concatenated features through a 5-layer MLP.
    - Input dimension: 120 (as per source, though formula yields 72; [G] assumes other features or a different $L$ definition might account for the difference, but the formula is explicit).
    - Hidden dimensions: 256, 256, 256, 128.
    - Output dimension: 11 (3-channel raw color + 8-channel feature map).
4.  **Rasterization:**
    - Expand each point to a disk.
    - Select radius based on two rules:
        1. Cover gaps between points to prevent bleeding (seeing occluded surfaces/background).
        2. Keep radius as small as possible to avoid inaccurate depth estimation and edge expansion.
5.  **Volume Rendering:**
    - Render the image using the opacity $\alpha$ and color $\mathbf{c}$ predicted by the MLP.
    - Compute loss $\mathcal{L} = \mathcal{L}_{RGB} + \lambda_{sparse} \mathcal{L}_{sparse}$.
    - For scenes without background, add transparency loss (L2 distance of predicted vs ground truth transparency).

**Formulas:**
The frequency-modulated positional encoding for an input $\mathbf{p}$ (coordinate or direction) with $L$ bands is:

$$
\gamma (\mathbf {p}) = \left (\sin \left (2^0 \pi \mathbf {p}\right ), \cos \left (2^0 \pi \mathbf {p}\right ), \sin \left (2^{0.5} \pi \mathbf {p}\right ), \cos \left (2^{0.5} \pi \mathbf {p}\right ), \dots, \sin \left (2^{L-1} \pi \mathbf {p}\right ), \cos \left (2^{L-1} \pi \mathbf {p}\right ) \right )
$$

The training loss is:

$$
\mathcal{L} = \mathcal{L}_{\text{RGB}} + \lambda_{\text{sparse}} \mathcal{L}_{\text{sparse}}
$$

Where:
- $\mathcal{L}_{\text{RGB}} = ||\hat{C} - C_{gt}||_2^2$
- $\mathcal{L}_{\text{sparse}} = \frac{1}{N} \sum_{i=1}^N [\log(\alpha_i) + \log(1-\alpha_i)]$
- $\hat{C}$ is predicted color.
- $C_{gt}$ is ground truth color.
- $N$ is the number of points.
- $\alpha_i$ is the opacity of point $i$.
- $\lambda_{\text{sparse}} = 5 \times 10^{-4}$.

**Parameters:**
- $L_{spatial}$ (frequency bands for spatial coordinates): 10.
- $L_{dir}$ (frequency bands for view directions): 2.
- Learning rate for MLP: $5 \times 10^{-4}$.
- Learning rate for opacity parameters $\alpha$: 0.01.
- Training resolution: 800x800 (NeRF-Synthetic), 640x640 (Tanks and Temples), 800x800 (ScanNet), 720x720 (DTU).
- Test resolution: 800x800 (NeRF-Synthetic), 1920x1056 (Tanks and Temples), 1200x1600 (ScanNet), 960x1200 (DTU).
- Data Augmentation: Random scaling (factor [0.5, 1.5] of side length) and cropping.

**Pitfalls:**
- **Bleeding:** If the rasterization radius is too small, points from occluded surfaces and the background can be seen through the front surface.
- **Edge Expansion:** If the rasterization radius is too large, it leads to inaccurate depth estimation and object edges expand.
- **Precision:** The source notes that the effect of the radius is not significant in ablation studies, but heuristic selection is required.

## Subtopics

### Point Cloud Denoising and Completion
A preprocessing step involving alternating loops of denoising and completion to improve the initial point cloud quality before encoding. [S1]

### AFNet MLP
The decoder network that takes the encoded features and outputs color and feature maps. It uses gated convolution blocks in its U-Net variant for editing. [S1]

### Rasterization Radius Selection
A heuristic method for determining the disk radius for point expansion to balance bleeding and edge expansion. [S1]

## Operating characteristics
- **Time Complexity**: One epoch consumes approximately 12.8 seconds on the NeRF-Synthetic dataset. Realistic rendering is achieved in 10 minutes, but convergence takes about 10 hours. [S1]
- **Memory Complexity**: Not given in the sources.
- **Measured Performance**: Achieves higher PSNR/SSIM on NeRF-Synthetic and Tanks and Temples datasets compared to NeRF, CCNeRF, NPBG, NPBG++, and Huang et al. Comparable or better results on ScanNet and DTU. [S1]
- **Strengths**: Fast convergence for realistic rendering; effective handling of sparse point clouds via frequency modulation; supports easy editing. [S1]
- **Limitations**: Requires careful selection of rasterization radius; sensitive to point cloud quality (requires preprocessing). [S1]
- **When to use**: When working with sparse point clouds and needing high-quality novel view synthesis with editing capabilities. [S1]
- **When not to use**: When computational resources are extremely limited and fast convergence is not required, or when dense point clouds are available and simpler encoding might suffice. [G]

## Background
The method originates from the paper "Frequency-Modulated Point Cloud Rendering with Easy Editing" published in CVPR 2023. It builds on the positional encoding form of NeRF but narrows the encoding interval to provide more fine-grained basis function support. It is used in the context of point-based radiance field optimization, specifically for tasks involving point cloud rendering and editing. [S1]
