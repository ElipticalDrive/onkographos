# Conditional Radiance Field Training

Also called: Conditional NeRF, Instance-conditioned NeRF

## Overview
Conditional Radiance Field Training extends the standard NeRF architecture to model a dataset of multiple 3D instances by learning instance-specific latent codes for shape and appearance [S1]. It solves the problem of generalizing across variations in geometry and texture without requiring separate models per instance, achieving reconstruction quality comparable to independent single-instance NeRFs while sharing network weights [S1]. It differs from sibling methods by explicitly disentangling shape and appearance into separate latent vectors and optimizing them jointly with the network parameters [S1, 2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A dataset of $K$ instances. For each instance $k \in \{1, \dots, K\}$, the method uses a set of training rays $R_k$. Each ray $r$ is defined by origin $\mathbf{o}$ and direction $\mathbf{d}$.
*   **Outputs:** Rendered color $\hat{C}(r, \mathbf{z}^{(s)}, \mathbf{z}^{(c)})$ and density $\sigma$ for sampled points along the ray.

**Data Structures:**
*   **Network Weights:** Two Multi-Layer Perceptrons (MLPs), $F_{\text{coarse}}$ and $F_{\text{fine}}$, each 4 layers deep with 256 channels width and ReLU activations [S1].
*   **Latent Codes:**
    *   Shape code $\mathbf{z}^{(s)}_k \in \mathbb{R}^{32}$ for instance $k$ [S1].
    *   Color code $\mathbf{z}^{(c)}_k \in \mathbb{R}^{32}$ for instance $k$ [S1].
    *   These codes are learnable parameters optimized alongside network weights [S1].
*   **Ray Sets:** $R_k$ is the set of all training rays for instance $k$ [S1].

**Numbered Steps:**
1.  **Initialization:** Initialize $F_{\text{coarse}}$ and $F_{\text{fine}}$ with random weights. Initialize shape codes $\mathbf{z}^{(s)}_k$ and color codes $\mathbf{z}^{(c)}_k$ for all $K$ instances [S1].
2.  **Iteration Loop:** Repeat until convergence (average 1M iterations) [S1]:
    a.  **Instance Sampling:** Randomly sample an object instance index $k \in \{1, \dots, K\}$ [S1].
    b.  **Code Retrieval:** Retrieve the corresponding shape code $\mathbf{z}^{(s)}_k$ and color code $\mathbf{z}^{(c)}_k$ [S1].
    c.  **Ray Sampling:** Sample a batch of training rays from the set $R_k$ belonging to instance $k$ [S1].
    d.  **Coarse Network Forward Pass:**
        i.  For each ray $r$, sample points using stratified sampling [S1].
        ii. Inject positional and directional embeddings. Inject $\mathbf{z}^{(s)}_k$ and $\mathbf{z}^{(c)}_k$ wherever positional or directional embeddings are injected in the original NeRF model [S1].
        iii. Pass inputs through $F_{\text{coarse}}$ to estimate density $\sigma$ and color $\mathbf{c}$ [S1].
        iv. Render $\hat{C}_{\text{coarse}}(r, \mathbf{z}^{(s)}_k, \mathbf{z}^{(c)}_k)$ using alpha compositing [S1].
    e.  **Hierarchical Sampling:** Use the density outputs from the coarse network to sample a hierarchical volume (importance sampling) for the fine network [S1].
    f.  **Fine Network Forward Pass:**
        i.  Pass inputs through $F_{\text{fine}}$ to estimate density $\sigma$ and color $\mathbf{c}$ [S1].
        ii. Render $\hat{C}_{\text{fine}}(r, \mathbf{z}^{(s)}_k, \mathbf{z}^{(c)}_k)$ using alpha compositing [S1].
    g.  **Loss Calculation:** Compute the photometric loss $L_{\text{train}}$ [S1]:
        $$
        L_{\text{train}} = \sum_{k=1}^{K} \sum_{r \in R_k} \left( \| \hat{C}_{\text{coarse}}(r, \mathbf{z}^{(s)}_k, \mathbf{z}^{(c)}_k) - C(r) \|_2^2 + \| \hat{C}_{\text{fine}}(r, \mathbf{z}^{(s)}_k, \mathbf{z}^{(c)}_k) - C(r) \|_2^2 \right)
        $$
        where $C(r)$ is the ground truth color [S1].
    h.  **Optimization:** Update network weights and latent codes $\mathbf{z}^{(s)}_k, \mathbf{z}^{(c)}_k$ using the Adam optimizer [S1].

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $10^{-4}$ for training [S1].
*   **Beta1:** 0.9 [S1].
*   **Beta2:** 0.999 [S1].
*   **Epsilon:** $10^{-8}$ [S1].
*   **Training Duration:** Until convergence, average 1M iterations [S1].
*   **Code Dimension:** 32 dimensions for both shape and color codes [S1].

**Edge Cases and Pitfalls:**
*   **Density Independence:** The density output $\sigma$ is generally independent of the viewing direction $\mathbf{d}$, depending only on position and shape code [S1].
*   **Radiance Dependence:** The radiance output $\mathbf{c}$ depends on position, viewing direction, and appearance code [S1].
*   **Shared Shape Branch:** Using a shared shape branch improves performance over a single shared code for both shape and color [S1].
*   **Parameter Count:** Layer widths in ablations are increased to keep the number of parameters approximately equal across experiments [S1].

**Pseudocode:**
```python
import numpy as np

def train_conditional_nerf(instances, rays_per_instance, num_iterations=1000000):
    """
    Train a conditional radiance field on a dataset of instances.
    
    Args:
        instances: List of K instances. Each instance has a set of rays R_k.
        rays_per_instance: Number of rays to sample per instance per iteration.
        num_iterations: Number of training iterations.
        
    Returns:
        F_coarse: Coarse network weights.
        F_fine: Fine network weights.
        z_s: Shape codes for all instances.
        z_c: Color codes for all instances.
    """
    K = len(instances)
    
    # Initialize networks (4 layers, 256 channels, ReLU)
    F_coarse = initialize_mlp(4, 256)
    F_fine = initialize_mlp(4, 256)
    
    # Initialize latent codes (32-dimensional)
    z_s = np.random.randn(K, 32)
    z_c = np.random.randn(K, 32)
    
    # Optimizer state
    optimizer = Adam(F_coarse.parameters() + F_fine.parameters() + z_s + z_c, 
                     lr=1e-4, beta1=0.9, beta2=0.999, eps=1e-8)
    
    for iteration in range(num_iterations):
        # Sample instance
        k = np.random.randint(0, K)
        
        # Get codes for instance k
        z_s_k = z_s[k]
        z_c_k = z_c[k]
        
        # Get rays for instance k
        R_k = instances[k].rays
        
        # Sample batch of rays
        batch_rays = sample_batch(R_k, rays_per_instance)
        
        total_loss = 0.0
        
        for r in batch_rays:
            # Stratified sampling for coarse network
            points_coarse = stratified_sample_ray(r)
            
            # Forward pass through coarse network
            # Inject embeddings and codes z_s_k, z_c_k
            sigma_coarse, color_coarse = F_coarse(points_coarse, r.direction, z_s_k, z_c_k)
            
            # Render coarse color
            C_coarse = render_volume(points_coarse, sigma_coarse, color_coarse)
            
            # Hierarchical sampling for fine network based on coarse density
            points_fine = hierarchical_sample(points_coarse, sigma_coarse)
            
            # Forward pass through fine network
            sigma_fine, color_fine = F_fine(points_fine, r.direction, z_s_k, z_c_k)
            
            # Render fine color
            C_fine = render_volume(points_fine, sigma_fine, color_fine)
            
            # Ground truth color for ray r
            C_gt = instances[k].get_ground_truth_color(r)
            
            # Compute loss
            loss_coarse = np.sum((C_coarse - C_gt) ** 2)
            loss_fine = np.sum((C_fine - C_gt) ** 2)
            
            total_loss += loss_coarse + loss_fine
        
        # Backpropagate and update
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
        
    return F_coarse, F_fine, z_s, z_c

def render_volume(points, sigma, color):
    """
    Standard volume rendering with alpha compositing.
    """
    # Compute delta distances between points
    deltas = np.diff(points, axis=0)
    # Add epsilon to avoid division by zero
    deltas = np.maximum(deltas, 1e-10)
    
    # Compute alpha
    alpha = 1.0 - np.exp(-sigma * deltas)
    
    # Compute transmittance
    T = np.cumprod(1.0 - alpha, axis=0)
    T = np.concatenate([np.ones((1, 3)), T[:-1]], axis=0)
    
    # Composite color
    weights = alpha * T
    C = np.sum(weights * color, axis=0)
    
    return C
```

## Operating characteristics
*   **Time Complexity:** Training time is proportional to the number of iterations (average 1M) and the number of instances $K$ [S1].
*   **Memory Complexity:** Memory usage scales with the number of instances $K$ due to the storage of latent codes $\mathbf{z}^{(s)}_k$ and $\mathbf{z}^{(c)}_k$ [S1].
*   **Performance:** On the PhotoShapes dataset, the method matches the performance of training independent NeRF models for each instance [S1].
*   **Scalability:** The method scales well to more training instances. When training with all 626 instances of the PhotoShape dataset, it achieves reconstruction quality comparable to independent models [S1].
*   **Strengths:** Accurately models shape and appearance differences across instances; generalizes to unseen views; supports editing [S1].
*   **Limitations:** Requires joint optimization of codes and network weights, which can be computationally intensive [S1].

## Background
*   **Origin:** Proposed in "Editing Conditional Radiance Fields" (2021) [S1].
*   **History:** Builds on the original NeRF paper [45] and extends it to handle multiple instances by introducing latent codes [S1].
*   **Usage:** Used for editing 3D objects, generalizing across instances, and rendering multiple views of objects with varying shape and appearance [S1].
