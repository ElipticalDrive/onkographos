# Differentiable Primitive Assembly

Also called: DPA-Net Primitive Assembly, Quadric Primitive Assembly

## Overview
Differentiable Primitive Assembly (DPA) models 3D shapes as an assembly of quadric primitives using differentiable intersection and union operations, trained with image-space losses only without 3D supervision [S1]. It differs from its sibling [Viewing Direction Gaussian Splatting](14273-viewing-direction-gaussian-splatting.md) by representing geometry via implicit quadric surfaces grouped into convexes, rather than explicit anisotropic Gaussians [S1].

## How it works
**Inputs:** Fused image features $f$ (from a shared MLP/feature network), query points $\mathbf{x}_i$ sampled along camera rays.
**Outputs:** Primitive parameters, selection matrix, occupancy field, rendered color $C_b$, and mask $M_c$.

**Data Structures:**
1.  **Primitive Parameters Matrix $P$**: Shape $\mathbb{R}^{P \times 7}$. Each row contains $(a, b, c, d, e, f, g)$. The first three parameters $(a, b, c)$ are enforced to be non-negative [S1].
2.  **Selection Matrix $T$**: Shape $\mathbb{R}^{P \times C}$. Entries are floating-point in $[0, 1]$ during training, ideally binary. Each column selects primitives for one convex [S1].
3.  **Weight Vector $w$**: Shape $\mathbb{R}^C$. Learnable weights close to 1 [S1].

**Numbered Steps:**

1.  **Query Matrix Construction**: For $N$ query points, construct matrix $Q \in \mathbb{R}^{N \times 7}$ where the $i$-th row is $(x_i^2, y_i^2, z_i^2, x_i, y_i, z_i, 1)$ [S1].
2.  **Distance Estimation**: Compute $D = QP^\top \in \mathbb{R}^{N \times P}$. $D_{i,p}$ is the approximate signed distance between point $i$ and primitive $p$. $D_{i,p} < 0$ if inside, $> 0$ if outside [S1].
3.  **Convex Occupancy**: Compute $O = \text{ReLU}(D)T \in \mathbb{R}^{N \times C}$. $O_{i,c} = 0$ if point $i$ is inside convex $c$, $> 0$ if outside [S1].
4.  **Exact Occupancy**: Compute $a^*_i = \min_{1 \le c \le C} O_{i,c}$. $a^*_i = 0$ if inside, $> 0$ if outside [S1].
5.  **Soft Occupancy**: Compute $a^+_i = \mathcal{L}(\sum_{c=1}^C w_c \mathcal{L}(1 - O_{i,c}))$, where $\mathcal{L}(\cdot)$ clips input to $[0, 1]$. $a^+_i \approx 1$ if inside, $< 1$ if outside [S1].
6.  **Opacity Assignment**:
    *   Phase 1: $\alpha_i = a^+_i$ [S1].
    *   Phases 2 & 3: $\alpha_i = \exp(-10 a^*_i)$ [S1].
7.  **Differentiable Rendering**:
    *   Color: $C_b = \sum_{i=1}^R t_i \alpha_i c_{b,i}$, where $t_i = \prod_{k=1}^{i-1} (1 - \alpha_k)$ [S1].
    *   Mask: $M_c = \sum_{i \in \Omega} t_i \alpha_i$ [S1].
8.  **Loss Computation**:
    *   Photo/Mask Loss: $\mathcal{L}_{ph} = \frac{1}{B} \sum_{j=1}^B ||\hat{C}_j - C_j||_2^2 + \frac{1}{B} \sum_{j=1}^B ||\hat{M}_j - M_j||_2^2$ [S1].
    *   Selection Loss: $\mathcal{L}_T = \sum_{i,j} \max(-T_{i,j}, 0) + \max(T_{i,j} - 1, 0)$ [S1].
    *   Weight Loss: $\mathcal{L}_w = \sum_j |w_j - 1|$ [S1].
    *   Overlapping Loss: $\mathcal{L}_{over} = \sum_{i \in \Omega} \max(h_i, 1.9)$, where $h_i = \sum_{c=1}^C \exp(-10 O_{i,c})$ and $\Omega = \{i | a^*_i < 0.01\}$ [S1].
9.  **Silhouette-aware Sampling**: Sample 256 pixels randomly and 1,000 pixels around contours (obtained via morphological closing + Gaussian noise on mask) [S1].
10. **Primitive Dropout (Phase 3 only)**: Iterate rows of binary $T$. Set $p$-th row to zero, compute new occupancy $b^*$. Quantify variation $v = K \sum_{i=1}^P \mathbb{1}(\text{XOR}(b^*_i < 0.1, a^*_i < 0.1))$. If $v \approx 0$, keep zero; else restore. Apply every 400 iterations [S1].

import numpy as np

def compute_quadric_distance(query_points, primitive_params):
    """
    query_points: (N, 3)
    primitive_params: (P, 7) -> (a, b, c, d, e, f, g)
    Returns: D (N, P)
    """
    # Q: (N, 7)
    x, y, z = query_points[:, 0], query_points[:, 1], query_points[:, 2]
    Q = np.column_stack([x**2, y**2, z**2, x, y, z, np.ones(N)])
    # D = Q @ P^T
    D = Q @ primitive_params.T
    return D

def compute_convex_occupancy(D, T):
    """
    D: (N, P)
    T: (P, C)
    Returns: O (N, C)
    """
    # O = ReLU(D) @ T
    O = np.maximum(D, 0) @ T
    return O

def compute_exact_occupancy(O):
    """
    O: (N, C)
    Returns: a_star (N,)
    """
    a_star = np.min(O, axis=1)
    return a_star

def compute_soft_occupancy(O, w):
    """
    O: (N, C)
    w: (C,)
    Returns: a_plus (N,)
    """
    # L(x) = clip(x, 0, 1)
    clipped = np.clip(1 - O, 0, 1)
    # sum_c w_c * L(1 - O_ic)
    weighted_sum = clipped @ w
    a_plus = np.clip(weighted_sum, 0, 1)
    return a_plus

def render_ray(points_along_ray, opacities, colors):
    """
    points_along_ray: (R,) - sorted by depth
    opacities: (R,)
    colors: (R, 3)
    Returns: color (3,), mask (1,)
    """
    R = len(points_along_ray)
    transmittance = np.ones(R + 1)
    for i in range(R - 1, -1, -1):
        transmittance[i] = transmittance[i+1] * (1 - opacities[i])
    
    color = np.zeros(3)
    mask = 0.0
    for i in range(R):
        t_i = transmittance[i]
        alpha_i = opacities[i]
        color += t_i * alpha_i * colors[i]
        mask += t_i * alpha_i
        
    return color, mask

def compute_overlapping_loss(O, a_star):

    O: (N, C)
    a_star: (N,)
    Returns: L_over (scalar)
    """
    # Omega: points inside shape
    mask_inside = a_star < 0.01
    if not np.any(mask_inside):

    h_inside = h[mask_inside]
    L_over = np.sum(np.maximum(h_inside, 1.9))
    return L_over

**Edge Cases and Pitfalls:**
*   **Complex Topologies**: Random pixel sampling struggles with thin structures or holes; silhouette-aware sampling is required [S1].
*   **Redundant Primitives**: Primitive dropout is needed to remove redundant primitives (up to 29%) [S1].
*   **Generalization**: Pretrained models may underperform on novel shapes deviating from training data; test-time adaptation is necessary [S1].

## Subtopics

### Test-Time Adaptation
A three-phase refinement process for instance-specific shapes. Phase 1 uses soft occupancy and all losses. Phase 2 switches to exact occupancy and removes weight loss. Phase 3 binarizes $T$, freezes it, and adds overlapping loss [S1].

### Silhouette-Aware Sampling
Adaptive pixel sampling allocating more pixels to object contours to handle complex topologies [S1].

### Primitive Dropout
A regularization technique to remove redundant primitives by checking if removing a primitive significantly alters the shape [S1].

## Operating characteristics
*   **Time Complexity**: Not given in the sources.
*   **Memory Complexity**: Not given in the sources.
*   **Measured Performance**: Trained on sparse-view images. Achieves compact primitive assembly with up to 29% redundant primitives removed [S1].
*   **Strengths**: Differentiable intersection/union allows training with image-space losses only. Handles complex structures via silhouette-aware sampling and dropout [S1].
*   **Limitations**: Requires test-time adaptation for novel shapes. Struggles with random sampling on complex topologies [S1].
*   **When to Use**: When 3D supervision is unavailable and sparse-view input is provided. When compact, structured representation is desired [S1].
*   **When Not to Use**: When dense multi-view input is available and explicit geometry is preferred over implicit assembly [S1].

## Background
DPA-Net was introduced in 2024 by the authors of "DPA-Net: Structured 3D Abstraction from Sparse Views via Differentiable Primitive Assembly" [S1]. It builds on CAPRI-Net [S1] and adopts intersection/union operations from [6, 55]. It is used for 3D shape abstraction from sparse views [S1].
