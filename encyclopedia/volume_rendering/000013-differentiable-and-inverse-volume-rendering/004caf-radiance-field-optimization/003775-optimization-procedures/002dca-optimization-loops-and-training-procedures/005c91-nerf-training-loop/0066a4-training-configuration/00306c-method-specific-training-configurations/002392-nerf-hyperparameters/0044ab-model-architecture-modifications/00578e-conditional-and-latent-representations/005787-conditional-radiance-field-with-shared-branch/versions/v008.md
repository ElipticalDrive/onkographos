# Conditional Radiance Field with Shared Branch

Also called: CRF with Shared Branch, Modular Conditional Radiance Field

## Overview
The Conditional Radiance Field with Shared Branch is a neural radiance field architecture designed for shape and color disentanglement, enabling efficient instance-specific editing by allowing specific submodules to be fine-tuned independently [S1]. It maps a 3D location $\mathbf{x}$, viewing direction $\mathbf{d}$, and instance-specific latent codes to volumetric density $\sigma$ and radiance $\mathbf{c}$ [S1]. Unlike standard conditional formulations that concatenate all latent codes with positional encodings, this method separates the shape representation into a category-specific shared branch and an instance-specific branch, improving view synthesis quality and scalability to multiple instances [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D position $\mathbf{x}$, viewing direction $\mathbf{d}$, instance-specific shape code $\mathbf{z}^{(s)}$, instance-specific color code $\mathbf{z}^{(c)}$.
*   **Outputs:** Scalar density $\sigma$, radiance vector $\mathbf{c}$.

**Data Structures:**
The network consists of five Multi-Layer Perceptrons (MLPs), all configured identically unless specified:
*   **$F_{\text{share}}$**: Shared shape network.
*   **$F_{\text{inst}}$**: Instance-specific shape network.
*   **$F_{\text{fuse}}$**: Fusion shape network.
*   **$F_{\text{dens}}$**: Output density network (Linear layer).
*   **$F_{\text{rad}}$**: Output radiance network.

Each MLP ($F_{\text{share}}, F_{\text{inst}}, F_{\text{fuse}}$) has 4 hidden layers, 256 channels per layer, and ReLU activations. The output of these MLPs is a 256-dimensional feature vector [S1]. $F_{\text{dens}}$ is a linear layer mapping 256 dimensions to 1 (scalar density). $F_{\text{rad}}$ is a 2-layer MLP (implied by "two-layer MLP" in source, typically meaning 2 hidden layers or 2 linear layers; standard NeRF convention suggests 2 hidden layers for radiance, but source says "two-layer MLP... to get radiance". Latent codes $\mathbf{z}^{(s)}$ and $\mathbf{z}^{(c)}$ are 32-dimensional vectors [S1].

**Numbered Steps:**

1.  **Positional Encoding:** Compute the positional encoding $\gamma(\mathbf{x})$ for the input position $\mathbf{x}$ and $\gamma(\mathbf{d})$ for the viewing direction $\mathbf{d}$ using the standard NeRF positional encoding scheme [S1].
2.  **Shared Shape Representation:** Pass the positional encoding $\gamma(\mathbf{x})$ through the shared shape network $F_{\text{share}}$ to obtain the shared shape feature $\mathbf{f}_{\text{share}}$:
    $$ \mathbf{f}_{\text{share}} = F_{\text{share}}(\gamma(\mathbf{x})) $$
3.  **Instance-Specific Shape Representation:** Concatenate the shape code $\mathbf{z}^{(s)}$ with the positional encoding $\gamma(\mathbf{x})$. Pass the concatenated vector through the instance-specific shape network $F_{\text{inst}}$ to obtain the instance shape feature $\mathbf{f}_{\text{inst}}$:
    $$ \mathbf{f}_{\text{inst}} = F_{\text{inst}}([\mathbf{z}^{(s)}; \gamma(\mathbf{x})]) $$
4.  **Fusion:** Add the shared and instance-specific shape features, then pass the sum through the fusion shape network $F_{\text{fuse}}$ to obtain the fused shape feature $\mathbf{f}_{\text{fuse}}$:
    $$ \mathbf{f}_{\text{fuse}} = F_{\text{fuse}}(\mathbf{f}_{\text{share}} + \mathbf{f}_{\text{inst}}) $$
5.  **Density Prediction:** Pass the fused shape feature $\mathbf{f}_{\text{fuse}}$ through the linear density network $F_{\text{dens}}$ to obtain the scalar density $\sigma$:
    $$ \sigma = F_{\text{dens}}(\mathbf{f}_{\text{fuse}}) $$
6.  **Radiance Prediction:** Concatenate the fused shape feature $\mathbf{f}_{\text{fuse}}$, the color code $\mathbf{z}^{(c)}$, and the encoded viewing direction $\gamma(\mathbf{d})$. Pass this concatenated vector through the radiance network $F_{\text{rad}}$ to obtain the radiance $\mathbf{c}$:
    $$ \mathbf{c} = F_{\text{rad}}([\mathbf{f}_{\text{fuse}}; \mathbf{z}^{(c)}; \gamma(\mathbf{d})]) $$

**Rendering:**
The rendering process follows standard volume rendering [Parent](3065-nerf-hyperparameters.md). For a ray $r$, $N_c$ points $\{t_i\}$ are sampled. Density $\sigma_i$ and color $\mathbf{c}_i$ are computed using the network defined above. The pixel color $\hat{C}$ is computed via alpha compositing:
$$ \hat{C}(r, \mathbf{z}^{(s)}, \mathbf{z}^{(c)}) = \sum_{i=1}^{N_c} \mathbf{c}_i \alpha_i \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) $$
where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ and $\delta_i = t_{i+1} - t_i$ [S1].

**Parameters:**
*   Shape code dimension: 32 [S1].
*   Color code dimension: 32 [S1].
*   MLP depth for $F_{\text{share}}, F_{\text{inst}}, F_{\text{fuse}}$: 4 layers [S1].
*   MLP width: 256 channels [S1].
*   Activation: ReLU [S1].
*   Optimizer: Adam [S1].
*   Training learning rate: $10^{-4}$ [S1].
*   Edit learning rate: $10^{-2}$ [S1].

**Edge Cases and Pitfalls:**
*   **Precision:** Standard float32 precision is assumed for latent codes and network weights [S1].
*   **Boundaries:** The method assumes valid positional encodings. Degenerate inputs (e.g., identical positions for different instances) are handled by the instance-specific branch [S1].
*   **Caching:** During optimization, the set of training rays is small, allowing caching of intermediate representations to accelerate editing [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class ConditionalRadianceFieldSharedBranch(nn.Module):
    def __init__(self, pos_enc_dim, view_enc_dim, latent_dim=32, hidden_dim=256, num_hidden_layers=4):
        super().__init__()
        # F_share: 4 layers, 256 channels, ReLU
        self.f_share = nn.Sequential(
            nn.Linear(pos_enc_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim)
        )
        
        # F_inst: 4 layers, 256 channels, ReLU
        # Input: [z_s; gamma(x)]
        self.f_inst = nn.Sequential(
            nn.Linear(latent_dim + pos_enc_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim)
        )
        
        # F_fuse: 4 layers, 256 channels, ReLU
        self.f_fuse = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim)
        )
        
        # F_dens: Linear layer
        self.f_dens = nn.Linear(hidden_dim, 1)
        
        # F_rad: Two-layer MLP (2 hidden layers, 256 channels, ReLU)
        # Input: [f_fuse; z_c; gamma(d)]
        self.f_rad = nn.Sequential(
            nn.Linear(hidden_dim + latent_dim + view_enc_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 3) # RGB
        )

    def forward(self, x, d, z_s, z_c):
        # 1. Shared shape representation
        f_share = self.f_share(x)
        
        # 2. Instance-specific shape representation
        # Concatenate z_s and x
        x_inst_input = torch.cat([z_s, x], dim=-1)
        f_inst = self.f_inst(x_inst_input)
        
        # 3. Fuse representations
        f_fuse = self.f_fuse(f_share + f_inst)
        
        # 4. Predict density
        sigma = self.f_dens(f_fuse)
        
        # 5. Predict radiance
        # Concatenate f_fuse, z_c, and d
        rad_input = torch.cat([f_fuse, z_c, d], dim=-1)
        c = self.f_rad(rad_input)
        
        return sigma, c
```

## Operating characteristics
*   **Time and Memory Complexity:** The shared branch reduces the number of parameters that need to be updated during editing, accelerating color edits by 3.2× and shape edits by 1.9× compared to non-modular approaches [S1]. Caching of intermediate representations is feasible due to the small set of training rays during optimization [S1].
*   **Measured Performance:** On the PhotoShapes dataset, the model with the shared shape branch achieves a PSNR of 35.79, compared to 33.91 for a model without the shared shape branch [S1].
*   **Strengths:** Improves view synthesis quality, enables efficient editing by isolating shape and color updates, and scales better to multiple instances [S1].
*   **Limitations:** Requires careful tuning of latent codes and network architecture to maintain disentanglement [S1].
*   **When to Use:** When efficient instance-specific editing (shape or color) is required, and the dataset contains multiple instances of similar objects [S1].
*   **When Not to Use:** When editing efficiency is not a priority, or when the dataset contains highly diverse objects where a shared shape representation is not beneficial [S1].

## Background
The Conditional Radiance Field with Shared Branch was introduced in the paper "Editing Conditional Radiance Fields" (2021) [S1]. The method builds on the original NeRF architecture [45] and aims to provide modular inductive biases for better shape and color disentanglement. It was developed to address the limitations of single-instance NeRF models and to enable efficient editing of 3D objects represented as radiance fields [S1].
