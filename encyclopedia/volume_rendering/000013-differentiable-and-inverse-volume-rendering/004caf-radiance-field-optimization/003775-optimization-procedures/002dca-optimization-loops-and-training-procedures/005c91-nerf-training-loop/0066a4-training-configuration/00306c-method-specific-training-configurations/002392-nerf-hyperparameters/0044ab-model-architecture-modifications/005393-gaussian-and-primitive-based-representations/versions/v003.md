# Gaussian and Primitive-Based Representations

Also called: Gaussian Splatting, Primitive Assembly, Neural Point Clouds, Frequency-Modulated Point Clouds

## Overview
This family replaces the continuous, global Multi-Layer Perceptron (MLP) radiance field of standard NeRF with discrete, local representations: learnable geometric primitives (Gaussians, quadrics), neural point clouds, or frequency-modulated point attributes. It solves the computational bottleneck of ray marching through empty space and the spectral bias of MLPs by leveraging differentiable rasterization or local neighborhood aggregation [13657-differentiable-primitive-assembly.md][14273-viewing-direction-gaussian-splatting.md][15538-point-nerf-representation.md][15903-frequency-modulated-point-cloud-rendering.md]. Unlike the parent's continuous function approximation, these methods explicitly model scene geometry or features as a collection of discrete entities, enabling real-time rendering speeds and superior handling of high-frequency details [15903-frequency-modulated-point-cloud-rendering.md].

## Shared principles
The family shares the substitution of the global implicit function $f(\mathbf{x}, \mathbf{d})$ with a discrete set of entities $\mathcal{E} = \{e_i\}_{i=1}^N$. Rendering is performed by aggregating contributions from these entities along camera rays, rather than integrating a density field $\sigma(\mathbf{x})$ via numerical quadrature.

1.  **Discrete Representation:** The scene is defined by a finite set of parameters. For Gaussians, this is mean $\mathbf{m}$, covariance $\mathbf{\Sigma}$, color $\mathbf{c}$, and opacity $\sigma$. For points, this is position $\mathbf{p}$, feature vector $\mathbf{f}$, and confidence $\gamma$. For primitives, this is quadric coefficients $\mathbf{P}$ and selection matrices $\mathbf{T}$.
2.  **Local Aggregation/Rasterization:**
    *   **Gaussian Splatting:** Projects 3D Gaussians to 2D screen space as ellipsoids and rasterizes them using differentiable Gaussian splatting [14273-viewing-direction-gaussian-splatting.md].
    *   **Point Clouds:** Queries local neighborhoods (K-nearest neighbors within radius $R$) to aggregate features via inverse distance weighting [15538-point-nerf-representation.md] or applies local frequency modulation [15903-frequency-modulated-point-cloud-rendering.md].
    *   **Primitives:** Evaluates implicit signed distance functions (SDFs) for quadrics and combines them via soft boolean operations (min/max pooling) [13657-differentiable-primitive-assembly.md].
3.  **Differentiable Optimization:** All parameters are optimized end-to-end using image-space photometric losses ($\mathcal{L}_{ph}$). Gradients flow through the rasterization or aggregation step to update the discrete parameters [13657-differentiable-primitive-assembly.md][14273-viewing-direction-gaussian-splatting.md][15538-point-nerf-representation.md].

## Subtopics

### [Differentiable Primitive Assembly](13657-differentiable-primitive-assembly.md)
Models 3D shapes as an assembly of learnable convex quadric primitives. It differs from Gaussian Splatting by evaluating implicit signed distances in 3D space and combining them via soft boolean operations, allowing for complex topologies like holes and thin structures. It is chosen when explicit geometric abstraction from sparse views is required without 3D ground truth supervision.

### [Viewing Direction Gaussian Splatting](14273-viewing-direction-gaussian-splatting.md)
A hybrid method combining 3D Gaussian Splatting's geometric efficiency with NeRF's view-dependent appearance modeling. It uses a lightweight MLP to modulate Gaussian opacity based on viewing direction, resolving artifacts on shiny surfaces. It is chosen when view-dependent effects (reflections, transparency) are critical but global NeRF is too slow.

### [Point-NeRF Representation](15538-point-nerf-representation.md)
Represents radiance fields using a discrete neural point cloud. It differs from Gaussian Splatting by using inverse-distance weighted feature aggregation from local neighborhoods rather than 2D projection splatting. It is chosen for efficient ray marching in empty space and leveraging classical point cloud structures.

### [Frequency-Modulated Point Cloud Rendering](15903-frequency-modulated-point-cloud-rendering.md)
Also known as AFNet, this method uses an Adaptive Frequency Net to modulate implicit radiance signals with local texture frequency encoding. It addresses the spectral bias of standard MLPs by predicting local frequency and phase parameters per point. It is chosen for high-fidelity local detail reconstruction and real-time rendering of textured scenes.

### GARF
A method using Gaussian activations as an alternative to positional encoding in NeRF, combined with bundle adjustment for pose estimation from unknown camera poses. It successfully recovers scene representations from unknown camera poses in challenging scenes with low-textured regions [S1].

## Background
The shift from continuous MLPs to discrete representations emerged to address the computational cost of volume rendering and the inability of standard NeRF to render in real-time. Gaussian Splatting [14273-viewing-direction-gaussian-splatting.md] and Neural Point Clouds [15538-point-nerf-representation.md] leverage differentiable rasterization techniques adapted from computer graphics. Differentiable Primitive Assembly [13657-differentiable-primitive-assembly.md] extends this by using implicit surfaces for better topological control. Frequency-Modulated Point Clouds [15903-frequency-modulated-point-cloud-rendering.md] address the spectral bias inherent in MLP-based radiance fields. GARF [S1] explores Gaussian activations for pose estimation.
