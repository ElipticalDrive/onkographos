# Binary Radiance Fields

Also called: BRF

## Overview
Binary Radiance Fields (BiRF) is a storage-efficient radiance field representation that constrains feature grid parameters to binary values (+1 or -1) to achieve compact storage without post-processing compression [S1]. Unlike methods that compress pre-trained models, BiRF performs binarization during training using a 2D-3D hybrid multi-resolution architecture, significantly reducing storage overhead while maintaining reconstruction quality [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D coordinate $\mathbf{x} \in \mathbb{R}^3$, viewing direction $\mathbf{d} \in S^2$.
*   **Output:** Volume density $\sigma \in \mathbb{R}$, color $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures:**
The representation consists of four multi-resolution feature grids implemented using hash encoding [S1]:
1.  **3D Voxel Grid ($\Phi_{\theta_{xyz}}$):** $L$ levels with resolutions ranging from 16 to 1024. Each level stores up to $T_{3D}$ feature vectors.
2.  **2D Plane Grids ($\Phi_{\theta_{xy}}, \Phi_{\theta_{xz}}, \Phi_{\theta_{yz}}$):** $M$ levels with resolutions ranging from 64 to 512. Each level stores up to $T_{2D}$ feature vectors.
3.  **Feature Values:** Each grid parameter is constrained to $\{-1, +1\}$, stored as 1-bit values [S1].
4.  **MLPs:**
    *   Density MLP: 1 hidden layer, 128 channels, ReLU activation.
    *   Color MLP: 2 hidden layers, 128 channels, ReLU activation.
    *   Directional Encoding: Spherical Harmonics basis functions [S1].

**Parameters:**
*   $L$: Number of 3D grid levels.
*   $M$: Number of 2D grid levels.
*   $T_{3D}$: Max feature vectors per 3D level.
*   $T_{2D}$: Max feature vectors per 2D level.
*   $F$: Feature dimension per level.
*   $\lambda_{sparsity}$: Sparsity loss weight ($2.0 \times 10^{-5}$) [S1].
*   Model Variants:
    *   Small (Ours-S): $\log_2(T_{3D}) = 17, \log_2(T_{2D}) = 15$.
    *   Base (Ours-B): $\log_2(T_{3D}) = 19, \log_2(T_{2D}) = 17$.
    *   Dimensions $F \in \{2, 4, 8\}$ [S1].

**Steps:**

1.  **Binarization:**
    Real-valued grid parameters $\theta$ are transformed to binary $\theta'$ using the sign function:
    $$ \theta' = \text{sign}(\theta) = \begin{cases} +1 & \text{if } \theta \ge 0 \\ -1 & \text{otherwise} \end{cases} $$
    Gradients are propagated using the Straight-Through Estimator (STE). The gradient is passed if $|\theta| \le 1$, otherwise it is zeroed to prevent scale divergence [S1]:
    $$ \frac{\partial L}{\partial \theta} = \frac{\partial L}{\partial \theta'} \cdot \mathbb{I}(|\theta| \le 1) $$
    [G] During inference, $\theta'$ is read directly as +1 or -1.

2.  **3D Feature Encoding:**
    For input $\mathbf{x}$, compute features from the 3D grid by linearly interpolating binary parameters across $L$ levels and concatenating:
    $$ \mathbf{f}_{xyz} = \bigcup_{l=1}^{L} \text{interp}(\mathbf{x}, \text{sign}(\Phi^l_{\theta_{xyz}})) $$
    where $\text{interp}$ denotes tri-linear interpolation [S1].

3.  **2D Feature Encoding:**
    Project $\mathbf{x}=(x,y,z)$ to 2D coordinates: $\mathbf{x}_{xy}=(x,y)$, $\mathbf{x}_{xz}=(x,z)$, $\mathbf{x}_{yz}=(y,z)$. For each axis, interpolate binary parameters across $M$ levels and concatenate:
    $$ \mathbf{f}_{xy} = \bigcup_{m=1}^{M} \text{interp}(\mathbf{x}_{xy}, \text{sign}(\Phi^m_{\theta_{xy}})) $$
    Repeat for $\mathbf{f}_{xz}$ and $\mathbf{f}_{yz}$ using bi-linear interpolation [S1].

4.  **Feature Concatenation:**
    Combine all encoded features:
    $$ \mathbf{f} = [\mathbf{f}_{xyz}, \mathbf{f}_{xy}, \mathbf{f}_{xz}, \mathbf{f}_{yz}] $$
    [S1]

5.  **Positional Encoding:**
    Apply Sinusoidal Positional Encoding (SPE) to $\mathbf{x}$:
    $$ \gamma(\mathbf{x}) = (\sin(2^0 \pi \mathbf{x}), \cos(2^0 \pi \mathbf{x}), \dots, \sin(2^{L-1} \pi \mathbf{x}), \cos(2^{L-1} \pi \mathbf{x})) $$
    [S1]

6.  **Density Prediction:**
    Feed $\gamma(\mathbf{x})$ and $\mathbf{f}$ into the density MLP:
    $$ (\sigma, \mathbf{e}) = \text{MLP}_{\text{density}}(\gamma(\mathbf{x}), \mathbf{f}) $$
    where $\mathbf{e}$ is the embedded feature [S1].

7.  **Color Prediction:**
    Feed $\mathbf{e}$ and directional encoding $\mathbf{d}$ (using Spherical Harmonics) into the color MLP:
    $$ \mathbf{c} = \text{MLP}_{\text{color}}(\mathbf{e}, \mathbf{d}) $$
    [S1]

**Loss Function:**
*   **Reconstruction Loss:** $L_{\text{recon}} = \sum_{\mathbf{r} \in \mathcal{R}} ||\hat{C}(\mathbf{r}) - C(\mathbf{r})||_2^2$ [S1].
*   **Sparsity Loss:** $L_{\text{sparsity}} = \sum_{i,k} \log(1 + 2\sigma(\mathbf{r}_i(t_k))^2)$ [S1].
*   **Total Loss:** $L = L_{\text{recon}} + \lambda_{\text{sparsity}} L_{\text{sparsity}}$ [S1].

## Operating characteristics
*   **Storage:** Extremely compact. Ours-S2 requires < 0.5 MB, outperforming Instant-NGP (24.5 MB) and TensoRF-CP (3.7 MB) on the mic scene [S1]. Total storage for MLPs is 0.06–0.11 MB [S1].
*   **Performance:** PSNR of 32.03 dB on Synthetic-NeRF, 34.48 dB on Synthetic-NSVF, 28.20 dB on Tanks and Temples [S1].
*   **Training Time:** ~6–14 minutes per scene on NVIDIA RTX A6000 for 20K iterations [S1].
*   **Strengths:** No post-processing compression required; superior reconstruction quality compared to prior efficient methods with smaller storage [S1].
*   **Limitations:** Hash collisions in 3D grids at high resolutions are mitigated by 2D grids but remain a factor [S1]. Scale divergence can occur if $|\theta| > 1$ without STE constraints [S1].

## Background
Binary Radiance Fields were proposed by Seungjoo Shin and Jaesik Park in 2023 [S1]. The method builds on Instant-NGP  and NerfAcc , leveraging hash encoding and occupancy grids. It addresses the storage bottleneck of neural radiance fields by introducing binary feature encoding during training [S1].
