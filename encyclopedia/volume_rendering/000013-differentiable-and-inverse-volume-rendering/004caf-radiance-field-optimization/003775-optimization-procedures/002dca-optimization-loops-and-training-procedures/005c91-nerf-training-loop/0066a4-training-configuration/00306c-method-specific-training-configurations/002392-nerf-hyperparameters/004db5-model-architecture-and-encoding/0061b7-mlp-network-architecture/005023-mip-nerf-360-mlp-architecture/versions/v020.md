# Mip-NeRF 360 MLP Architecture

Also called: Integrated Positional Encoding MLP, PosEnc MLP

## Overview
The Mip-NeRF 360 MLP architecture is a specific neural network configuration for radiance field optimization that replaces standard positional encoding with **Integrated Positional Encoding (IPE)** to handle aliasing and frequency mismatch during volume rendering [S1, unofficial]. It structures the network into two distinct Multi-Layer Perceptrons (MLPs): a density network that processes 3D spatial coordinates and a color network that processes view-dependent features, connected by a bottleneck vector [S1, unofficial]. This architecture is designed to be compatible with the Mip-NeRF ray integration strategy, ensuring that the network's output is consistent with the integrated volume rendering equation [S1, unofficial].

## How it works
The method takes a 3D position $\mathbf{x}$ and a viewing direction $\mathbf{d}$ (or reflection direction $\mathbf{r}$) as inputs and outputs volume density $\sigma$ and color $\mathbf{c}$. The implementation relies on the `multinerf` library structure [S1, unofficial].

### Data Structures and Configuration
The architecture is defined by a configuration object containing the following parameters [S1, unofficial]:
*   **Network Dimensions:** `net_depth` (int, default 8), `net_width` (int, default 256), `bottleneck_width` (int, default 256), `net_depth_viewdirs` (int, default 1), `net_width_viewdirs` (int, default 128).
*   **Encoding Degrees:** `min_deg_point` (int, default 0), `max_deg_point` (int, default 12), `deg_view` (int, default 4).
*   **Skip Connections:** `skip_layer` (int, default 4), `skip_layer_dir` (int, default 4).
*   **Activations & Biases:** `density_bias` (float, default -1), `rgb_bias` (float, default 0), `density_noise` (float, default 0), `rgb_padding` (float, default 0.001).
*   **Flags:** `use_reflections` (bool, default False), `use_directional_enc` (bool, default False), `use_n_dot_v` (bool, default False), `use_diffuse_color` (bool, default False), `use_specular_tint` (bool, default False), `enable_pred_normals` (bool, default False), `disable_density_normals` (bool, default True).
*   **Basis:** `basis_shape` (str, default 'icosahedron'), `basis_subdivisions` (int, default 2).

### Step-by-Step Method

1.  **Initialization and Setup**
    *   If `use_reflections` is True, ensure normals are computable (either `enable_pred_normals` is True or `disable_density_normals` is False). If not, raise `ValueError` [S1, unofficial].
    *   Precompute the transpose of the basis matrix for IPE using `geopoly.generate_basis(basis_shape, basis_subdivisions)` and store as `pos_basis_t` [S1, unofficial].
    *   Initialize the directional encoding function `dir_enc_fn`:
        *   If `use_directional_enc` is True, generate an Integrated Directional Encoding (IDE) function using `ref_utils.generate_ide_fn(deg_view)` [S1, unofficial].
        *   Otherwise, use standard positional encoding `coord.pos_enc` with `min_deg=0`, `max_deg=deg_view`, and `append_identity=True` [S1, unofficial].

2.  **Density Network (Spatial Encoding)**
    *   **Input:** 3D position $\mathbf{x}$ (represented as mean $\mu$ and covariance $\Sigma$ if using integrated encoding).
    *   **Linearization (Optional):** If a warping function `warp_fn` is provided, linearize the means and covariances using `coord.track_linearize(warp_fn, means, covs)` [S1, unofficial].
    *   **Lifting and Diagonalization:** Lift the means and covariances into the basis space and diagonalize them using `coord.lift_and_diagonalize(means, covs, pos_basis_t)` to obtain `lifted_means` and `lifted_vars` [S1, unofficial].
    *   **Integrated Positional Encoding:** Compute the input feature vector $x$ using `coord.integrated_pos_enc(lifted_means, lifted_vars, min_deg_point, max_deg_point)` [S1, unofficial]. This replaces the standard $\sin(\mathbf{x})$ encoding with an integral over the Gaussian distribution defined by the mean and covariance.
    *   **MLP Forward Pass (Density):**
        *   Iterate $i$ from 0 to `net_depth` - 1.
        *   Apply a dense layer with width `net_width` and activation `net_activation` (typically ReLU) to $x$.
        *   If $i > 0$ and $i \pmod{\text{skip\_layer}} == 0$, concatenate the current $x$ with the original input to this block (skip connection) along the last axis.
    *   **Raw Density Output:** Apply a final dense layer with width 1 to $x$. Extract the scalar `raw_density` [S1, unofficial].
    *   **Density Noise (Optional):** If `density_noise` > 0, add Gaussian noise: `raw_density += density_noise * random.normal(density_key, raw_density.shape)` [S1, unofficial].
    *   **Normal Computation (Optional):** If `disable_density_normals` is False:
        *   Flatten means and covariances.
        *   Compute the gradient of `raw_density` with respect to the input coordinates using `jax.vmap(jax.value_and_grad(predict_density, has_aux=True))` [S1, unofficial].
        *   Compute normals as the negative normalized gradient: `normals = -ref_utils.l2_normalize(raw_grad_density)` [S1, unofficial].
    *   **Final Density:** Apply activation and bias: `density = density_activation(raw_density + density_bias)` [S1, unofficial].

3.  **Color Network (View-Dependent Encoding)**
    *   **Directional Encoding:** Compute `dir_enc` using `dir_enc_fn` on the view direction $\mathbf{d}$ (or reflection direction $\mathbf{r}$ if `use_reflections` is True). Note: If using reflections, flip viewdirs (`-viewdirs`) before reflection because they point from camera to point, whereas reflection functions assume they point toward the camera [S1, unofficial].
    *   **Feature Concatenation:**
        *   Broadcast `dir_enc` to match the bottleneck shape dimensions [S1, unofficial].
        *   Initialize the input list $x$ with the bottleneck vector from the density network.
        *   Append `dir_enc` to $x$.
        *   If `use_n_dot_v` is True, compute $n \cdot v = \sum \text{normals} \times \text{viewdirs}$ and append to $x$ [S1, unofficial].
        *   If `glo_vec` (global vector) is provided, broadcast it to match the bottleneck shape and append to $x$ [S1, unofficial].
        *   Concatenate all elements in $x$ along the last axis.
    *   **MLP Forward Pass (Color):**
        *   Iterate $i$ from 0 to `net_depth_viewdirs` - 1.
        *   Apply a dense layer with width `net_width_viewdirs` and activation `net_activation` to $x$.
        *   If $i > 0$ and $i \pmod{\text{skip\_layer\_dir}} == 0$, concatenate the current $x$ with the original input to this block (skip connection) along the last axis.
    *   **RGB Output:**
        *   Compute raw RGB: `raw_rgb = dense_layer(num_rgb_channels)(x)` [S1, unofficial].
        *   Apply premultiplier and bias: `rgb_premultiplied = rgb_premultiplier * raw_rgb + rgb_bias` [S1, unofficial].
        *   Apply activation: `rgb = rgb_activation(rgb_premultiplied)` [S1, unofficial].

4.  **Post-Processing (Optional)**
    *   **Specular/Diffuse Split:** If `use_diffuse_color` is True:
        *   Compute diffuse linear color: `diffuse_linear = nn.sigmoid(raw_rgb_diffuse - log(3.0))` [S1, unofficial].
        *   Compute specular linear color: If `use_specular_tint` is True, `specular_linear = tint * rgb`; else `specular_linear = 0.5 * rgb` [S1, unofficial].
        *   Combine and tone map: `rgb = clip(linear_to_srgb(specular_linear + diffuse_linear), 0.0, 1.0)` [S1, unofficial].
    *   **RGB Padding:** Apply padding to ensure output range: `rgb = rgb * (1 + 2 * rgb_padding) - rgb_padding` [S1, unofficial].

### Pseudocode

```python
import jax.numpy as jnp
from jax import random, vmap, value_and_grad

def mipnerf360_mlp_forward(
    x, # 3D position (mean)
    cov, # Covariance of 3D position (for IPE)
    viewdirs, # Viewing direction
    config, # Configuration object
    params, # Network parameters
    rng # Random key for noise
):
    """
    Forward pass for Mip-NeRF 360 MLP.
    """
    # 1. Setup
    if config.use_reflections:
        if not config.enable_pred_normals and config.disable_density_normals:
            raise ValueError("Reflections require normals to be computed.")
        
        # Flip viewdirs for reflection calculation
        refdirs = -viewdirs 
        # Compute normals if not predicted by network
        if config.disable_density_normals:
             # Placeholder for normal computation logic from density network
             normals = compute_normals_from_density(x, params['density'], config)
        else:
             normals = params['pred_normals']
             
        # Reflect viewdirs
        refdirs = reflect(refdirs, normals)
        dir_input = refdirs
    else:
        dir_input = viewdirs

    # Precompute basis transpose (done once during init)
    pos_basis_t = config.pos_basis_t

    # 2. Density Network
    # Lift and diagonalize for IPE
    lifted_means, lifted_vars = lift_and_diagonalize(x, cov, pos_basis_t)
    
    # Integrated Positional Encoding
    x_enc = integrated_pos_enc(lifted_means, lifted_vars, 
                               config.min_deg_point, config.max_deg_point)
    
    # Density MLP
    x_d = x_enc
    for i in range(config.net_depth):
        x_d = dense_layer(x_d, params['density_weights'][i], params['density_biases'][i])
        x_d = activation(x_d)
        if i > 0 and i % config.skip_layer == 0:
            x_d = jnp.concatenate([x_d, x_enc], axis=-1)
            
    raw_density = dense_layer(x_d, params['density_final_w'], params['density_final_b'])[..., 0]
    
    # Density Noise
    if config.density_noise > 0:
        raw_density += config.density_noise * random.normal(rng, raw_density.shape)
        
    # Density Activation
    density = density_activation(raw_density + config.density_bias)
    
    # Normal Computation (if needed for reflections or output)
    if not config.disable_density_normals:
        # Compute gradient of raw_density w.r.t x
        # Note: In JAX, this requires vmap over batch dimensions
        grad_fn = value_and_grad(lambda x: predict_density(x, params['density'], config))
        _, raw_grad_density = grad_fn(x)
        normals = -l2_normalize(raw_grad_density)

    # 3. Color Network
    # Directional Encoding
    if config.use_directional_enc:
        dir_enc = generate_ide_fn(config.deg_view)(dir_input)
    else:
        dir_enc = pos_enc(dir_input, min_deg=0, max_deg=config.deg_view, append_identity=True)
        
    # Bottleneck from density network (simplified: assume x_d is bottleneck or passed explicitly)
    # In standard MipNeRF360, the bottleneck is the output of the density MLP before the final layer
    # Here we assume x_d is the bottleneck feature vector
    bottleneck = x_d 
    
    # Broadcast dir_enc to match bottleneck shape
    dir_enc = jnp.broadcast_to(
        dir_enc[..., None, :], 
        bottleneck.shape[:-1] + (dir_enc.shape[-1],)
    )
    
    # Concatenate features
    x_c = [bottleneck, dir_enc]
    
    if config.use_n_dot_v:
        n_dot_v = jnp.sum(normals * viewdirs[..., None, :], axis=-1, keepdims=True)
        x_c.append(n_dot_v)
        
    if config.glo_vec is not None:
        glo_vec = jnp.broadcast_to(config.glo_vec, bottleneck.shape)
        x_c.append(glo_vec)
        
    x_c = jnp.concatenate(x_c, axis=-1)
    
    # Color MLP
    for i in range(config.net_depth_viewdirs):
        x_c = dense_layer(x_c, params['color_weights'][i], params['color_biases'][i])
        x_c = activation(x_c)
        if i > 0 and i % config.skip_layer_dir == 0:
            x_c = jnp.concatenate([x_c, x_c_original], axis=-1) # x_c_original needs tracking
            
    raw_rgb = dense_layer(x_c, params['color_final_w'], params['color_final_b'])
    
    # RGB Output
    rgb = rgb_activation(config.rgb_premultiplier * raw_rgb + config.rgb_bias)
    
    # Post-processing
    if config.use_diffuse_color:
        diffuse_linear = sigmoid(raw_rgb_diffuse - jnp.log(3.0))
        if config.use_specular_tint:
            specular_linear = config.tint * rgb
        else:
            specular_linear = 0.5 * rgb
        rgb = clip(linear_to_srgb(specular_linear + diffuse_linear), 0.0, 1.0)
        
    rgb = rgb * (1 + 2 * config.rgb_padding) - config.rgb_padding
    
    return density, rgb, normals
```

## Operating characteristics
*   **Complexity:** The computational complexity is dominated by the MLP forward passes. The IPE step adds overhead for lifting, diagonalizing, and computing the integrated encoding, which is more expensive than standard positional encoding but necessary for aliasing control [S1, unofficial].
*   **Memory:** The architecture uses a bottleneck vector of width 256 to connect the density and color networks, reducing the parameter count compared to a single monolithic MLP [S1, unofficial].
*   **Strengths:** The integrated positional encoding allows the network to represent high-frequency details without aliasing artifacts when rendering at different scales or distances, which is critical for the "360" (unbounded) scenes [S1, unofficial].
*   **Limitations:** The reliance on JAX-specific operations (e.g., `jax.vmap`, `value_and_grad`) makes direct porting to other frameworks (PyTorch, TensorFlow) require careful rewriting of the gradient and batching logic [S1, unofficial]. The default configuration assumes a specific basis shape ('icosahedron') and subdivisions (2) for the IPE basis [S1, unofficial].

## Background
The Mip-NeRF 360 MLP architecture was introduced by Google Research as part of the Mip-NeRF 360 project, which extended the original NeRF and Mip-NeRF methods to handle unbounded, 360-degree scenes [S1, unofficial]. It builds upon the Mip-NeRF concept of integrating positional encoding over conical frustums, adapting it for the MLP structure used in the `multinerf` library [S1, unofficial]. The architecture supports various extensions such as specular tinting, roughness prediction, and normal estimation, making it a versatile base for advanced radiance field optimizations [S1, unofficial].
