# Conditional Radiance Field Training

Also called: Conditional NeRF, Instance-conditioned NeRF

## Overview
Conditional Radiance Field Training is a method for modeling shape and appearance variations across multiple instances of an object category by training a single neural radiance field conditioned on instance-specific latent codes [S1]. It solves the problem of efficiently representing a dataset of objects (e.g., chairs) without training separate independent NeRF models for each instance, while maintaining rendering accuracy comparable to independent models [S1]. It differs from [Conditional Radiance Field with Shared Branch](15964-conditional-radiance-field-with-shared-branch.md) by explicitly separating shape and appearance codes and injecting them at multiple points in the network architecture, rather than relying solely on a shared branch structure [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A dataset of $K$ object instances. For each instance $k \in \{1, \dots, K\}$, a set of training rays $R_k$ with associated ground truth colors $C(r)$.
*   **Outputs:** A conditional radiance field model consisting of two networks ($F_{coarse}, F_{fine}$) and learned latent codes for each instance.

**Data Structures:**
*   **Shape Code ($\mathbf{z}^{(s)}_k$):** A 32-dimensional vector for instance $k$.
*   **Color Code ($\mathbf{z}^{(c)}_k$):** A 32-dimensional vector for instance $k$.
*   **Networks:** Two Multi-Layer Perceptrons (MLPs), $F_{coarse}$ and $F_{fine}$. Each is 4 layers deep with 256 channels wide, using ReLU activations [S1].
*   **Architecture Details:** The networks use skip connections. The shape code is embedded and injected into the network at the same locations where positional or directional embeddings are injected in the original NeRF model [S1]. Separate shape and color codes are used [S1].

**Numbered Steps:**
1.  **Initialization:** Initialize $F_{coarse}$ and $F_{fine}$ with random weights. Initialize $\mathbf{z}^{(s)}_k$ and $\mathbf{z}^{(c)}_k$ for all $k \in \{1, \dots, K\}$.
2.  **Sampling Instance:** During each training iteration, sample an object instance $k$ uniformly from $\{1, \dots, K\}$ [S1].
3.  **Retrieving Codes:** Retrieve the corresponding shape code $\mathbf{z}^{(s)}_k$ and color code $\mathbf{z}^{(c)}_k$ for instance $k$ [S1].
4.  **Sampling Rays:** Sample a batch of training rays from the set $R_k$ belonging to instance $k$ [S1].
5.  **Coarse Rendering:**
    *   For each ray $r$ in the batch, use stratified sampling to sample points along the ray.
    *   Query $F_{coarse}$ with position $\mathbf{x}$, direction $\mathbf{d}$, $\mathbf{z}^{(s)}_k$, and $\mathbf{z}^{(c)}_k$ to obtain density $\sigma$ and color $\mathbf{c}$.
    *   Compute coarse rendered color $\hat{C}_{coarse}(r, \mathbf{z}^{(s)}_k, \mathbf{z}^{(c)}_k)$ using volume rendering [S1].
6.  **Hierarchical Sampling:** Use the density outputs from $F_{coarse}$ to sample a hierarchical volume (importance sampling) for the fine network [S1].
7.  **Fine Rendering:**
    *   Query $F_{fine}$ with the new sample points, $\mathbf{x}$, $\mathbf{d}$, $\mathbf{z}^{(s)}_k$, and $\mathbf{z}^{(c)}_k$ to obtain density and color.
    *   Compute fine rendered color $\hat{C}_{fine}(r, \mathbf{z}^{(s)}_k, \mathbf{z}^{(c)}_k)$ using volume rendering [S1].
8.  **Loss Calculation:** Compute the photometric loss for the batch:
    $$
    \mathcal{L}_{train} = \sum_{k=1}^{K} \sum_{r \in R_k} \left( \|\hat{C}_{coarse}(r, \mathbf{z}^{(s)}_k, \mathbf{z}^{(c)}_k) - C(r)\|_2^2 + \|\hat{C}_{fine}(r, \mathbf{z}^{(s)}_k, \mathbf{z}^{(c)}_k) - C(r)\|_2^2 \right)
    $$
    [S1]
9.  **Optimization:** Update network weights and latent codes $\mathbf{z}^{(s)}_k, \mathbf{z}^{(c)}_k$ using the Adam optimizer [S1].

## Operating characteristics
*   **Time Complexity:** Training involves two forward passes per ray (coarse and fine) and hierarchical sampling. Training takes approximately 1M iterations [S1].
*   **Memory Complexity:** Requires storing latent codes for all $K$ instances ($2 \times 32 \times K$ floats) plus the network weights. The networks are 4 layers deep with 256 channels [S1].
*   **Performance:** On the PhotoShapes dataset, the method matches the performance of training independent NeRF models for each instance [S1]. It scales well to more training instances (e.g., 626 instances in PhotoShapes) [S1].
*   **Strengths:** Accurately models shape and appearance differences across instances. Efficiently handles multiple instances in a single model.
*   **Limitations:** Requires joint optimization of codes and network weights. Performance depends on the quality of the latent codes.

## Background
*   **Origin:** The method was introduced in "Editing Conditional Radiance Fields" [S1].
*   **History:** It builds upon the original NeRF paper [45] and extends it to handle multiple instances by conditioning on latent codes. It was evaluated on the PhotoShapes [51] and Aubry chairs [5] datasets.
*   **Usage:** Used for modeling object categories with shape and appearance variations, and for editing radiance fields [S1].
