# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the hyperparameters and architectural modifications required to train a Neural Radiance Field (NeRF) model using depth priors, specifically as detailed in the Depth-Guided NeRF method [S1]. It addresses the problem of optimizing radiance fields by incorporating depth supervision, which improves geometric accuracy and convergence stability. It differs from standard NeRF training by introducing specific dropout regularization, a depth loss term with scene-dependent weighting, and a dedicated learning rate for depth scale parameters [S1].

## How it works
The method modifies the standard NeRF training loop [Parent](13550-model-architecture-and-encoding.md) by altering the network architecture and the optimization objective.

**Inputs and Outputs**
*   **Inputs:** Camera poses, image colors, and ground truth depth maps (where available).
*   **Outputs:** Optimized NeRF parameters (density $\sigma$ and color $\mathbf{c}$) and depth predictions.

**Data Structures and Architecture**
The network architecture builds upon the original NeRF [S1]. The key modification is the addition of regularization layers:
*   **Dropout:** Dropout layers with probability $p=0.1$ are added after each of the first eight fully connected ReLU-activated layers that encode the positional encoding [S1].

**Loss Function Components**
The total loss includes the standard color loss and a depth loss term. The depth loss is weighted by $\lambda$ and potentially scaled by an uncertainty weight $\gamma$ [S1].

**Parameters**
*   **Depth loss weight ($\lambda$):** $0.007$ for all scenes, except scene 710, where it is $0.02$ [S1].
*   **Uncertainty weight ($\gamma$):** $1$ [S1].
*   **Optimizer:** Adam [S1].
*   **Initial learning rate:** $5 \times 10^{-4}$ [S1].
*   **Learning rate schedule:** The learning rate is reduced to $5 \times 10^{-5}$ after 80% of the total training steps [S1].
*   **Weight decay:** $1 \times 10^{-6}$ [S1].
*   **Total training steps:** $500,000$ [S1].
*   **Depth scale learning rate:** $1 \times 10^{-7}$ [S1].

**Depth Evaluation Metrics**
When evaluating depth accuracy, the following metrics are computed over pixels $k=1, \dots, K$ with valid ground truth depth $d_k$ and predicted depth $\hat{d}_k$ [S1]:

$$
\text{RMSE}(d, \hat{d}) = \sqrt{\frac{1}{K} \sum_{k=1}^{K} (d_k - \hat{d}_k)^2}
$$

$$
\text{RMSE}_{\log}(d, \hat{d}) = \sqrt{\frac{1}{K} \sum_{k=1}^{K} (\log d_k - \log \hat{d}_k)^2}
$$

$$
\text{AbsRel}(d, \hat{d}) = \frac{1}{K} \sum_{k=1}^{K} \frac{|d_k - \hat{d}_k|}{d_k}
$$

$$
\text{SqRel}(d, \hat{d}) = \frac{1}{K} \sum_{k=1}^{K} \frac{(d_k - \hat{d}_k)^2}{d_k}
$$

**Pseudocode**
The following pseudocode outlines the training loop configuration and loss computation.

```python
def train_depth_guided_nerf():
    # 1. Initialize Model with Dropout
    # Build standard NeRF MLP [Parent](13550-model-architecture-and-encoding.md)
    model = NeRF()
    
    # Add dropout layers with p=0.1 after the first 8 FC ReLU layers
    # Note: Implementation detail [G]
    for i, layer in enumerate(model.positional_encoding_layers[:8]):
        if isinstance(layer, nn.Linear):
            # Insert dropout after the linear layer and before activation
            # Assuming standard ReLU activation follows
            pass 

    # 2. Initialize Optimizer
    optimizer = Adam(
        params=model.parameters(),
        lr=5e-4,
        weight_decay=1e-6
    )
    
    # Separate optimizer or param group for depth scale if applicable
    # Note: The source specifies a distinct learning rate for depth scale [S1]
    # Implementation detail [G]: This usually implies a separate parameter group
    # or a specific parameter named 'depth_scale' in the model.
    depth_scale_param = model.depth_scale # [G] Assumed attribute
    optimizer.add_param_group({'params': [depth_scale_param], 'lr': 1e-7})

    total_steps = 500000
    step_threshold = int(total_steps * 0.8)

    # 3. Training Loop
    for step in range(total_steps):
        # Sample rays and query NeRF
        rays = sample_rays()
        sigma, color = model(rays)
        
        # Render predicted color and depth
        pred_color = render_color(sigma, color)
        pred_depth = render_depth(sigma, rays)
        
        # Get ground truth
        gt_color = get_gt_color(rays)
        gt_depth = get_gt_depth(rays)
        
        # Compute Color Loss (e.g., MSE)
        color_loss = mse_loss(pred_color, gt_color)
        
        # Compute Depth Loss
        # Note: The specific depth loss function (e.g., L1, L2, EMD) is not explicitly 
        # named in the text, but metrics are RMSE and AbsRel [S1]. 
        # Standard practice uses L1 or L2. We assume L1 or L2 here [G].
        depth_loss = l1_loss(pred_depth, gt_depth)
        
        # Apply scene-specific depth weight
        if scene_id == 710:
            lambda_depth = 0.02
        else:
            lambda_depth = 0.007
            
        # Apply uncertainty weight
        gamma = 1
        
        total_loss = color_loss + gamma * lambda_depth * depth_loss
        
        # Backpropagate
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
        
        # Learning Rate Schedule
        if step == step_threshold:
            for param_group in optimizer.param_groups:
                param_group['lr'] = 5e-5

    return model
```

## Subtopics

### DS-NeRF Depth Loss Integration
This variant involves integrating the depth loss implementation from the official DS-NeRF code base into the training code base [S2]. It requires re-training on LLFF train/test splits using released configuration files, as the original publication results for LLFF used a different split and DTU results could not be reproduced due to missing configuration files [S2].

## Operating characteristics
*   **Complexity:** The addition of dropout layers and depth loss computation adds negligible overhead to the standard NeRF training complexity.
*   **Performance:** The configuration is designed to improve depth estimation accuracy, as evidenced by the specific evaluation metrics (RMSE, AbsRel) [S1].
*   **Limitations:** The configuration is sensitive to the choice of depth loss weight $\lambda$, which varies by scene [S1]. The use of dropout may slightly slow down convergence compared to a non-regularized model but improves generalization [S1].

## Background
The Depth-Guided NeRF Training configuration originates from the work on "Depth-Guided NeRF Training via Earth Mover’s Distance" [S1]. It builds upon the original NeRF architecture [S1] and incorporates depth supervision to enhance geometric reconstruction. The method was evaluated on datasets such as ScanNet and LLFF [S1].
