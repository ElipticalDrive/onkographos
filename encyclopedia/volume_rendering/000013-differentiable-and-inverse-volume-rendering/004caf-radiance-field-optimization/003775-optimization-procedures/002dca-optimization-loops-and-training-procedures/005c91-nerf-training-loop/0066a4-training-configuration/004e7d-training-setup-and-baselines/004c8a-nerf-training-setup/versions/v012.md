# NeRF Training Setup

Also called: Control-NeRF Training Setup, Nerfstudio Training

## Overview
This article defines the training configuration for NeRF-based models using the Nerfstudio library, specifically leveraging NerfAcc and Instant-NGP for fast convergence on static scenes [S2]. It also details the specific architectural modifications introduced in Control-NeRF, which replaces standard positional encoding of 3D positions with sampled feature vectors [S1]. The method solves the problem of efficient radiance field optimization by combining accelerated sampling strategies with feature-volume-based inputs, distinguishing it from standard NeRF which relies on explicit positional encoding [S1].

## How it works
The training process involves optimizing a coarse network $\hat{C}_c(\mathbf{r})$ and a fine network $\hat{C}_f(\mathbf{r})$ using a two-stage sampling approach. The input to the radiance function is a sampled feature vector rather than a positionally encoded 3D coordinate.

**Inputs and Outputs:**
*   **Input:** A batch of rays sampled from multi-view images. Each ray is defined by its origin and direction.
*   **Output:** Rendered color and opacity for the rays, used to compute loss against ground truth images.

**Data Structures:**
*   **Feature Volume ($V_s$):** A 3D volume storing 64-dimensional feature vectors for scene $s$.
*   **Sampled Feature Vector ($\mathbf{v}_s$):** Obtained via trilinear sampling $S(V_s, \mathbf{p})$ at point $\mathbf{p} \in \mathbb{R}^3$. No positional encoding is applied to $\mathbf{v}_s$ [S1].
*   **Direction Encoding ($\gamma(\mathbf{d})$):** The direction vector $\mathbf{d} \in \mathbb{R}^3$ is encoded using positional encoding with depth $L=4$ [S1].

**Numbered Steps:**
1.  **Ray Sampling:** Sample 1024 rays per batch from LLFF multi-view image datasets scaled to a resolution of $504 \times 378$ [S1].
2.  **Coarse Network Optimization:** Optimize the coarse network $\hat{C}_c(\mathbf{r})$ by sampling 64 points from evenly spaced bins along the ray length [S1].
3.  **Fine Network Sampling:** Sample 64 additional points for the fine network $\hat{C}_f(\mathbf{r})$. These points are sampled based on the opacity results from the coarse network to focus on relevant portions of the scene volume [S1].
4.  **Feature Sampling:** For each sampled point $\mathbf{p}$, retrieve the 64-dimensional feature vector $\mathbf{v}_s = S(V_s, \mathbf{p})$ from the volume $V_s$ using trilinear sampling [S1].
5.  **Direction Encoding:** Apply positional encoding to the direction vector $\mathbf{d}$:
    $$ \gamma(\mathbf{p}) = [\sin(2^0\pi\mathbf{p}), \cos(2^0\pi\mathbf{p}), \dots, \sin(2^{L-1}\pi\mathbf{p}), \cos(2^{L-1}\pi\mathbf{p})] $$
    where $\mathbf{p}$ is each dimension of $\mathbf{d}$ and $L=4$ [S1].
6.  **Radiance Function Input:** Pass the concatenated input $(\mathbf{v}_s, \gamma(\mathbf{d}))$ to the radiance function $F_\Theta$ to predict color $\mathbf{c}$ and density $\sigma$ [S1].
7.  **Volume Rendering:** Compute the rendered color $\mathbf{C}(\mathbf{r})$ using the discretized approximation of the volume rendering integral:
    $$ \mathbf{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i $$
    where $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$, $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, and $\delta_i$ is the distance between samples [S1, G].
8.  **Loss Computation:** Compute the loss between the rendered color and the ground truth image color.

**Parameters:**
*   **Positional Encoding Depth ($L$):** 4 [S1].
*   **Feature Vector Dimension:** 64 [S1].
*   **Batch Size:** 1024 rays [S1].
*   **Image Resolution:** $504 \times 378$ [S1].
*   **Library:** Nerfstudio [S2].
*   **Models:** NerfAcc and Instant-NGP [S2].
*   **Scene Type:** Static scenes with minimal surgical tools, actions, and moving organs [S2].
*   **Hardware:** Single RTX A6000 GPU and 128 GB RAM [S2].

**Edge Cases and Pitfalls:**
*   **Precision:** Trilinear sampling assumes the feature volume is stored in a format supporting this interpolation (e.g., dense grid or VDB) [S1].
*   **Boundaries:** Ray sampling must handle cases where rays exit the volume bounds; standard NeRF implementations typically clamp or terminate rays [G].
*   **Degenerate Input:** The method assumes valid camera poses and synchronized image frames [S2].

    Apply positional encoding to each dimension of p.

    frequencies = torch.pow(2.0, torch.arange(L, device=p.device).float()) * torch.pi
    # p has shape (..., D). We want to apply sin/cos to each dim.
    # Reshape p to (..., D, 1) and frequencies to (1, 1, L)
    p_expanded = p.unsqueeze(-1) # (..., D, 1)

    encoded = p_expanded * freqs # (..., D, L)
    sin_vals = torch.sin(encoded)
    cos_vals = torch.cos(encoded)
    # Concatenate sin and cos for each frequency
    encoded = torch.cat([sin_vals, cos_vals], dim=-1) # (..., D, 2*L)
    return encoded.view(*p.shape[:-1], -1) # (..., D*2*L)

## Subtopics

### Image-Based NeRF Training
Training a NeRF using RGB images as ground truth, optimizing both geometry (via Eikonal loss) and appearance (via color loss) [S3, unofficial]. It involves loading datasets using `get_nerf_datasets`, sampling random pixels to construct ray bundles, and computing mean squared error between predicted and ground truth colors [S3, unofficial]. An Eikonal loss is added for geometry regularization, similar to SDF training [S3, unofficial]. The learning rate is updated using a scheduler after each epoch [S3, unofficial]. This variant typically runs for 250 epochs on 128x128 images for datasets like Lego [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** The two-stage sampling (coarse + fine) increases the number of network queries per ray compared to single-stage methods, but the use of Instant-NGP and NerfAcc accelerates convergence [S2].
*   **Memory Complexity:** Requires storing the 64-dimensional feature volume $V_s$ in memory [S1]. The hardware setup uses 128 GB RAM, which is sufficient for typical surgical scene volumes [S2].
*   **Measured Performance:** Trained on a single RTX A6000 GPU [S2]. Specific PSNR/SSIM metrics are provided for Control-NeRF on LLFF datasets (e.g., Fern PSNR 25.752, T-Rex PSNR 26.510) [S1].
*   **Strengths:** Fast convergence on static scenes; feature-volume approach allows for scene manipulation and editing [S1, S2].
*   **Limitations:** Restricted to static scenes with minimal dynamic elements (surgical tools, moving organs) [S2].
*   **When to Use:** When fast training on static scenes is required and scene manipulation is desired [S1, S2].
*   **When Not to Use:** For highly dynamic scenes or when explicit 3D position encoding is preferred for geometry [S1, S2].

## Background
The method originates from the Control-NeRF paper, which introduced editable feature volumes for scene rendering and manipulation [S1]. It was adapted for laparoscopic surgical video rendering using the Nerfstudio library, NerfAcc, and Instant-NGP to handle static abdominal environments [S2]. The approach modifies the standard NeRF architecture by replacing positional encoding of 3D positions with sampled feature vectors [S1].
