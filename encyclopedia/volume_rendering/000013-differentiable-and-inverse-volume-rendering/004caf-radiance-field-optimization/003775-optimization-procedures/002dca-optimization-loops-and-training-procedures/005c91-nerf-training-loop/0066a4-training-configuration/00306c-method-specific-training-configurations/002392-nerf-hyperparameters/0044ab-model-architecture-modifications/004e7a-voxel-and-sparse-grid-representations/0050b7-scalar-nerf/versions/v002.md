# SCALAR-NeRF

Also called: SCAlable LARge-scale Neural Radiance Fields for Scene Reconstruction

## Overview
SCALAR-NeRF is a coarse-to-fine framework for scalable large-scale neural scene reconstruction that structures the representation as an encoder-decoder architecture to avoid the 'foggy' artifacts common in block-based methods like Block-NeRF [S1, unofficial]. It enables training on a single GPU by partitioning the scene into blocks, sharing a decoder from a coarse global model, and fusing local outputs using the global model rather than simple weighting functions [S1, unofficial].

## How it works
**Inputs:** A dataset of images $\{I_i\}$ with corresponding camera poses $\{P_i\}$ covering a large-scale scene.
**Outputs:** A set of local NeRF models and a fusion strategy to render novel views.

**Data Structures:**
1.  **Multi-resolution Hash Table Encoder:** A hash table of size $2^{19}$ (or similar) storing feature vectors. It consists of $L$ levels, where each level maps spatial coordinates to a feature vector $f_l \in \mathbb{R}^F$. The total feature embedding is $F = [f_1, \dots, f_L] \in \mathbb{R}^{L \cdot F}$ [S1, unofficial].
2.  **Shared Decoder:** A shallow MLP that maps the feature embedding $F$ to volume density $\sigma$ and color $\mathbf{c}$: $\sigma, \mathbf{c} = \text{Decoder}(F)$ [S1, unofficial].
3.  **Block Partitioning:** The scene is divided into spatial blocks. Each block has an Axis-Aligned Bounding Box (AABB).

**Parameters:**
*   **Hash Table Size:** $2^{19}$ [S1, unofficial].
*   **AABB Scale Factor ($s_{\text{AABB}}$):** Controls the overlap between blocks. Optimal value found is 1.2 [S1, unofficial].
*   **Space Contraction:** For unbounded scenes, coordinates are contracted using the Mip-NeRF360 method [S1, unofficial]:
    $$
    \text{contract}(\mathbf{x}) = \begin{cases} 
    \mathbf{x}, & \|\mathbf{x}\| \le 1, \\
    \frac{\mathbf{x}}{2 - \frac{1}{\|\mathbf{x}\|}}, & \|\mathbf{x}\| > 1.
    \end{cases}
    $$

**Steps:**

1.  **Train Coarse Global Model:**
    *   Train a global NeRF model on the entire image dataset using a multi-resolution hash table encoder and a shared decoder.
    *   This model serves as a reference for fusion and provides the initial weights for the local decoders.

2.  **Partition Scene into Blocks:**
    *   Use KMeans clustering on the image centroids or camera positions to partition the training images into $K$ blocks.
    *   Define the bounding box for each block.

3.  **Expand Overlapping Regions:**
    *   Scale up the bounding box of each local block by the factor $s_{\text{AABB}}$ to create overlap regions with neighboring blocks. This ensures that points near boundaries are covered by multiple local models [S1, unofficial].

4.  **Initialize Local Models:**
    *   For each block $k$, create a local model.
    *   **Encoder:** Each local block has its own dedicated hash table encoder (or shares the global one? The text says "dedicated local model" but also "share the decoder". The architecture diagram shows separate Hash Table Encoders for each block, implying local encoders).
    *   **Decoder:** Inherit the decoder weights from the trained coarse global model. This shared decoder promotes alignment in the feature space of local encoders [S1, unofficial].

5.  **Train Local Models:**
    *   Train each local model on the images assigned to its block.
    *   **Fixing the Decoder:** To save memory and allow larger hash tables, the shared decoder can be fixed (frozen) during local training. This eliminates the need to save the computational graph for the decoder parameters [S1, unofficial].
    *   **Optional Fine-tuning:** The shared decoder can optionally be fine-tuned for better quality, but fixing it yields satisfactory results and faster training [S1, unofficial].

6.  **Fuse Local Outputs:**
    *   To render a novel view, synthesize images from each local block model.
    *   Fuse these images using the reference image rendered from the coarse global model. This leverages the global model to discard poorly rendered results from local blocks, mitigating the "foggy" appearance caused by simple blending [S1, unofficial].
    *   *Note:* The paper explicitly states that using an Inverse Distance Weighting (IDW) function for fusion performs worse than using the global model reference, especially when blocks are close [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training is faster than training a single large global model with a huge hash table because local models are smaller and can be trained in parallel. However, the initial global model training adds overhead.
*   **Memory Complexity:** Significantly reduced compared to a single global model with a large hash table. The hash table size is kept small ($2^{19}$) per block, and the shared decoder can be fixed, saving memory [S1, unofficial]. This allows fitting the model on a single non-commercial GPU [S1, unofficial].
*   **Performance:** Outperforms Block-NeRF and Instant-NGP (with larger hash tables) in PSNR, SSIM, and LPIPS on large-scale scenes like Tanks and Temples [S1, unofficial].
*   **Strengths:** Scalable to large scenes, avoids foggy artifacts, fits on single GPU.
*   **Limitations:** Requires careful tuning of the AABB scale factor. Too large a factor increases hash collisions and degrades quality [S1, unofficial]. The fusion step is critical and poorly defined in the paper (no explicit formula), relying on the global model reference.

## Background
SCALAR-NeRF was introduced by Yu Chen and Gim Hee Lee from the National University of Singapore in November 2023 [S1, unofficial]. It addresses the limitations of Block-NeRF, which suffers from foggy artifacts when block centroids are close, and the memory constraints of scaling up hash table sizes in Instant-NGP for large scenes [S1, unofficial].
