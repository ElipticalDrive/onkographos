# Mip-NeRF 360 MLP Architecture

Also called: Integrated Positional Encoding MLP, PosEnc MLP

## Overview
The Mip-NeRF 360 MLP architecture is a two-branch Multi-Layer Perceptron (MLP) designed to predict density and color for radiance fields by integrating positional encoding over conical frustums to mitigate aliasing [S1, unofficial]. It distinguishes itself from standard NeRF by using Integrated Positional Encoding (IPE) for spatial coordinates and optional Integrated Directional Encoding (IDE) for view/reflection directions, enabling the prediction of specular tinting, roughness, and GLO vectors [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D point coordinates $\mathbf{x}$, covariance matrices $\Sigma$ (representing the conical frustum cross-section), view directions $\mathbf{d}$, and optional reflection directions $\mathbf{d}_{ref}$.
*   **Outputs:** Raw density $\sigma$, RGB color $\mathbf{c}$, and optionally normals $\mathbf{n}$, roughness $\rho$, and diffuse/specular components.

**Data Structures:**
The architecture is defined by a configuration object containing the following fields [S1, unofficial]:
*   `net_depth`: int (default 8). Depth of the density MLP.
*   `net_width`: int (default 256). Width of the density MLP hidden layers.
*   `bottleneck_width`: int (default 256). Width of the feature vector connecting density and color networks.
*   `net_depth_viewdirs`: int (default 1). Depth of the color MLP.
*   `net_width_viewdirs`: int (default 128). Width of the color MLP hidden layers.
*   `min_deg_point`: int (default 0). Minimum degree for point IPE.
*   `max_deg_point`: int (default 12). Maximum degree for point IPE.
*   `skip_layer`: int (default 4). Frequency of skip connections in the density MLP.
*   `skip_layer_dir`: int (default 4). Frequency of skip connections in the color MLP.
*   `deg_view`: int (default 4). Degree for directional encoding.
*   `density_bias`: float (default -1.0). Bias added to raw density before activation.
*   `density_noise`: float (default 0.0). Standard deviation of noise added to raw density.
*   `rgb_bias`: float (default 0.0). Bias added to raw color before activation.
*   `rgb_padding`: float (default 0.001). Padding for RGB output range.
*   `use_reflections`: bool (default False). Use reflection directions instead of view directions.
*   `use_directional_enc`: bool (default False). Use IDE for directions.
*   `enable_pred_roughness`: bool (default False). Predict roughness.
*   `roughness_bias`: float (default -1.0). Bias for roughness.
*   `use_diffuse_color`: bool (default False). Separate diffuse/specular colors.
*   `use_specular_tint`: bool (default False). Predict specular tint.
*   `use_n_dot_v`: bool (default False). Include $\mathbf{n} \cdot \mathbf{v}$ in color input.
*   `bottleneck_noise`: float (default 0.0). Noise for bottleneck features.
*   `basis_shape`: str (default 'icosahedron'). Basis for IPE ('octahedron' or 'icosahedron').
*   `basis_subdivisions`: int (default 2). Tessellation count for basis.
*   `density_activation`: Callable. Activation for density (e.g., Softplus).
*   `rgb_activation`: Callable. Activation for RGB (e.g., Sigmoid).
*   `net_activation`: Callable. Activation for hidden layers (e.g., ReLU).
*   `enable_pred_normals`: bool. Enable normal prediction via network output.
*   `disable_density_normals`: bool. Disable normal prediction via gradient.

**Numbered Steps:**

1.  **Setup:**
    *   If `use_reflections` is True, ensure normals are available (either via `enable_pred_normals` or by not setting `disable_density_normals` to True). If not, raise `ValueError` [S1, unofficial].
    *   Precompute the transpose of the basis matrix for IPE using `geopoly.generate_basis(basis_shape, basis_subdivisions)` and store as `pos_basis_t` [S1, unofficial].
    *   If `use_directional_enc` is True, generate the Integrated Directional Encoding (IDE) function using `ref_utils.generate_ide_fn(deg_view)`. Otherwise, define `dir_enc_fn` using coordinate positional encoding with `min_deg=0`, `max_deg=deg_view`, and `append_identity=True` [S1, unofficial].

2.  **Density Prediction:**
    *   If a `warp_fn` is provided, linearize the means and covariances using `coord.track_linearize(warp_fn, means, covs)` [S1, unofficial].
    *   Lift and diagonalize the means and covariances using the precomputed basis transpose: `lifted_means, lifted_vars = coord.lift_and_diagonalize(means, covs, pos_basis_t)` [S1, unofficial].
    *   Compute the Integrated Positional Encoding (IPE) for the lifted coordinates: `x = coord.integrated_pos_enc(lifted_means, lifted_vars, min_deg_point, max_deg_point)` [S1, unofficial].
    *   Iterate $i$ from 0 to `net_depth` - 1:
        *   Apply a dense layer with width `net_width` and activation `net_activation` to `x`.
        *   If $i > 0$ and $i \pmod{\text{skip\_layer}} == 0$, concatenate `x` with the original input to this block along the last axis [S1, unofficial].
    *   Output raw density: `raw_density = dense_layer(1)(x)[..., 0]` [S1, unofficial].
    *   If `density_key` is not None and `density_noise` > 0, add noise: `raw_density += density_noise * random.normal(density_key, raw_density.shape)` [S1, unofficial].
    *   Compute final density: `density = density_activation(raw_density + density_bias)` [S1, unofficial].

3.  **Normal Computation (Optional):**
    *   If `disable_density_normals` is False, compute normals from the gradient of the raw density for numerical stability [S1, unofficial].
    *   Flatten `means` and `covs`. Use `jax.vmap(jax.value_and_grad(predict_density, has_aux=True))` to compute `raw_density` and `raw_grad_density` simultaneously [S1, unofficial].
    *   Compute normals: `normals = -ref_utils.l2_normalize(raw_grad_density)` [S1, unofficial].
    *   *Note:* If `use_reflections` is True, flip view directions (`-viewdirs`) before reflection because they point from camera to point, whereas reflection utilities assume they point toward the camera [S1, unofficial].

4.  **Color Network Input Preparation:**
    *   If `use_directional_enc` is True, encode directions using the IDE function. Otherwise, use `dir_enc_fn`.
    *   Broadcast `dir_enc` to match the bottleneck shape dimensions: `dir_enc = jnp.broadcast_to(dir_enc[..., None, :], bottleneck.shape[:-1] + (dir_enc.shape[-1],))` [S1, unofficial].
    *   Initialize input list `x` with the bottleneck features from the density network.
    *   Append `dir_enc` to `x`.
    *   If `use_n_dot_v` is True, compute `dotprod = jnp.sum(normals_to_use * viewdirs[..., None, :], axis=-1, keepdims=True)` and append to `x` [S1, unofficial].
    *   If `glo_vec` is not None, broadcast it to match the bottleneck shape and append to `x` [S1, unofficial].
    *   Concatenate all elements in `x` along the last axis [S1, unofficial].

5.  **Color Network:**
    *   Iterate $i$ from 0 to `net_depth_viewdirs` - 1:
        *   Apply a dense layer with width `net_width_viewdirs` and activation `net_activation` to `x`.
        *   If $i > 0$ and $i \pmod{\text{skip\_layer\_dir}} == 0$, concatenate `x` with the original input to this block along the last axis [S1, unofficial].

6.  **RGB Output and Post-Processing:**
    *   Compute raw RGB: `rgb_premultiplied = dense_layer(num_rgb_channels)(x)` [S1, unofficial].
    *   Apply specular/diffuse split if `use_diffuse_color` is True:
        *   `diffuse_linear = nn.sigmoid(raw_rgb_diffuse - jnp.log(3.0))` [S1, unofficial].
        *   If `use_specular_tint` is True, `specular_linear = tint * rgb`. Else, `specular_linear = 0.5 * rgb` [S1, unofficial].
        *   Combine and tone map: `rgb = jnp.clip(image.linear_to_srgb(specular_linear + diffuse_linear), 0.0, 1.0)` [S1, unofficial].
    *   If not using diffuse/special split, apply standard activation: `rgb = rgb_activation(rgb_premultiplier * rgb_premultiplied + rgb_bias)` [S1, unofficial].
    *   Apply RGB padding: `rgb = rgb * (1 + 2 * rgb_padding) - rgb_padding` [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The IPE computation involves matrix multiplications for lifting and encoding, which is $O(D \cdot L)$ where $D$ is the dimensionality of the lifted coordinates and $L$ is the number of encoding frequencies. The MLP forward pass is $O(N \cdot W^2)$ where $N$ is the number of layers and $W$ is the width.
*   **Memory Complexity:** The MLP weights scale with $N \cdot W^2$. The IPE basis matrix scales with the basis shape and subdivisions.
*   **Strengths:** Handles aliasing in large scenes (360-degree) better than standard NeRF due to IPE. Supports complex appearance models (specular, roughness).
*   **Limitations:** More complex to implement than standard NeRF. Requires careful handling of normals for reflections.
*   **When to use:** For 360-degree scenes or scenes with significant depth variation where aliasing is a problem. When specular highlights or view-dependent effects are important.
*   **When not to use:** For simple scenes where standard NeRF suffices. When computational resources are extremely limited and the overhead of IPE is prohibitive.

## Background
The Mip-NeRF 360 MLP architecture was introduced by Google Research in the "Mip-NeRF 360: Unbounded Anti-Aliased Neural Radiance Fields" paper [S1, unofficial]. It extends the original Mip-NeRF concept to unbounded, 360-degree scenes. The key innovation is the integration of positional encoding over the conical frustum of a ray segment, which acts as a low-pass filter to prevent aliasing. The architecture supports various extensions like specular tinting and roughness prediction, making it suitable for high-fidelity rendering of complex environments.
