# Binary Radiance Fields

Also called: BRF

## Overview
Binary Radiance Fields (BiRF) is a storage-efficient radiance field representation that constrains feature grid parameters to binary values (+1 or -1) to drastically reduce memory footprint while maintaining reconstruction quality [S1]. Unlike post-processing compression methods that require additional optimization steps and are bounded by pre-trained model performance, BiRF performs binarization during training using a 2D-3D hybrid multi-resolution architecture [S1]. It builds on [Model Architecture and Encoding](13550-model-architecture-and-encoding.md) by replacing real-valued feature lookups with binary-encoded hash grids, enabling compact storage (e.g., < 0.5 MB) without sacrificing the ability to model complex volumetric scenes [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D spatial coordinate $\mathbf{x} \in \mathbb{R}^3$, viewing direction $\mathbf{d} \in \mathbb{R}^3$.
*   **Outputs:** Volume density $\sigma \in \mathbb{R}$, color $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures:**
The core data structure is a multi-resolution 2D-3D hybrid feature grid implemented using hash encoding [S1].
1.  **3D Voxel Grid ($\Phi_{\theta_{xyz}}$):** Contains $L$ resolution levels. Resolutions range from 16 to 1024. Each level stores up to $T_{3D}$ feature vectors.
2.  **2D Plane Grids ($\Phi_{\theta_{xy}}, \Phi_{\theta_{xz}}, \Phi_{\theta_{yz}}$):** Three orthogonal planes. Each contains $M$ resolution levels. Resolutions range from 64 to 512. Each level stores up to $T_{2D}$ feature vectors.
3.  **Parameter Storage:** All grid parameters $\theta$ are constrained to binary values $\{-1, +1\}$, stored as 1-bit integers [S1].
4.  **MLPs:**
    *   Density MLP: 1 hidden layer, 128 channels, ReLU activation.
    *   Color MLP: 2 hidden layers, 128 channels, ReLU activation.
    *   Input feature dimension per level is $F \in \{2, 4, 8\}$ [S1].

**Parameters:**
*   $L$: Number of 3D grid levels.
*   $M$: Number of 2D grid levels.
*   $T_{3D}$: Max feature vectors per 3D level. Small model (Ours-S): $\log_2(T_{3D}) = 17$. Base model (Ours-B): $\log_2(T_{3D}) = 19$ [S1].
*   $T_{2D}$: Max feature vectors per 2D level. Small model (Ours-S): $\log_2(T_{2D}) = 15$. Base model (Ours-B): $\log_2(T_{2D}) = 17$ [S1].
*   $F$: Feature dimension per level.
*   $\lambda_{\text{sparsity}}$: Sparsity loss weight. Value: $2.0 \times 10^{-5}$ [S1].
*   Optimizer: Adam, initial learning rate 0.01, decayed by 0.33 at 15K and 18K iterations [S1].

**Numbered Steps:**

1.  **Binarization (Training):** Maintain real-valued parameters $\theta$ in memory. During the forward pass, apply the sign function to obtain binary parameters $\theta'$:
    $$ \theta' = \text{sign}(\theta) = \begin{cases} +1 & \text{if } \theta \ge 0 \\ -1 & \text{otherwise} \end{cases} $$
    [S1]

2.  **Gradient Propagation (STE):** To backpropagate through the non-differentiable sign function, use the Straight-Through Estimator (STE). The gradient is passed unchanged if $|\theta| \le 1$, and zero otherwise. This constrains $\theta$ to $\{-1, 1\}$ and prevents scale divergence [S1]:
    $$ \frac{\partial L}{\partial \theta} = \begin{cases} \frac{\partial L}{\partial \theta'} & \text{if } |\theta| \le 1 \\ 0 & \text{otherwise} \end{cases} $$
    [S1]

3.  **3D Feature Encoding:** For input $\mathbf{x}$, compute features from the 3D grid by tri-linearly interpolating the binary parameters $\theta'$ across $L$ levels and concatenating them:
    $$ \mathbf{f}_{xyz} = \left\{ \text{interp}(\mathbf{x}, \text{sign}(\Phi^l_{\theta_{xyz}})) \right\}_{l=1}^L $$
    where $\text{interp}$ denotes tri-linear interpolation [S1].

4.  **2D Feature Encoding:** Project $\mathbf{x}=(x,y,z)$ to 2D coordinates: $\mathbf{x}_{xy}=(x,y)$, $\mathbf{x}_{xz}=(x,z)$, $\mathbf{x}_{yz}=(y,z)$. For each axis, bi-linearly interpolate the binary parameters across $M$ levels and concatenate:
    $$ \mathbf{f}_{xy} = \left\{ \text{interp}(\mathbf{x}_{xy}, \text{sign}(\Phi^m_{\theta_{xy}})) \right\}_{m=1}^M $$
    Repeat for $\mathbf{f}_{xz}$ and $\mathbf{f}_{yz}$ [S1].

5.  **Feature Concatenation:** Combine all encoded features:
    $$ \mathbf{f} = \{ \mathbf{f}_{xyz}, \mathbf{f}_{xy}, \mathbf{f}_{xz}, \mathbf{f}_{yz} \} $$
    [S1]

6.  **Positional Encoding:** Apply sinusoidal positional encoding $\gamma(\mathbf{x})$ to the input coordinate $\mathbf{x}$ [S1].

7.  **Density Prediction:** Feed $\gamma(\mathbf{x})$ and $\mathbf{f}$ into the density MLP to obtain density $\sigma$ and embedded feature $\mathbf{e}$:
    $$ (\sigma, \mathbf{e}) = \text{MLP}_{\text{density}}(\gamma(\mathbf{x}), \mathbf{f}) $$
    [S1]

8.  **Color Prediction:** Feed $\mathbf{e}$ and directional encoding $\mathbf{d}$ (using spherical harmonics) into the color MLP to obtain color $\mathbf{c}$:
    $$ \mathbf{c} = \text{MLP}_{\text{color}}(\mathbf{e}, \mathbf{d}) $$
    [S1]

9.  **Loss Calculation:** Compute reconstruction loss $L_{\text{recon}}$ (MSE between rendered and ground truth colors) and sparsity loss $L_{\text{sparsity}}$ using Cauchy loss to encourage sparse density:
    $$ L_{\text{sparsity}} = \sum_{i,k} \log(1 + 2\sigma(\mathbf{r}_i(t_k))^2) $$
    Total loss:
    $$ L = L_{\text{recon}} + \lambda_{\text{sparsity}} L_{\text{sparsity}} $$
    [S1]

## Operating characteristics
*   **Storage:** Extremely compact. Ours-S2 requires < 0.5 MB, outperforming TensoRF-CP (3.7 MB) and Instant-NGP (24.5 MB) on the mic scene [S1].
*   **Training Time:** Approximately 6, 9, and 14 minutes for Synthetic-NeRF scenes using Ours-B2 to Ours-B8 models on a single NVIDIA RTX A6000 [S1].
*   **Performance:** PSNR of 32.03 dB on Synthetic-NeRF, 34.48 dB on Synthetic-NSVF, and 28.20 dB on Tanks and Temples [S1].
*   **Strengths:** Significant storage reduction without post-optimization; competitive reconstruction quality; efficient ray sampling via occupancy grid [S1].
*   **Limitations:** Hash collisions in 3D grids at high resolutions are mitigated by 2D grids but remain a factor; requires careful handling of gradient flow due to binarization [S1].
*   **When to use:** When storage is a critical constraint and real-time or near-real-time training is desired.
*   **When not to use:** When maximum possible reconstruction quality is required regardless of storage size, or when post-training compression is acceptable.

## Background
Binary Radiance Fields were proposed by Seungjoo Shin and Jaesik Park from POSTECH and Seoul National University, published in arXiv:2306.07581v2 on December 4, 2023 [S1]. The method addresses the storage bottleneck of neural radiance fields by introducing binary feature encoding. It builds on the Instant-NGP architecture [20] and uses the occupancy grid from NerfAcc [42] for efficient ray sampling [S1].
