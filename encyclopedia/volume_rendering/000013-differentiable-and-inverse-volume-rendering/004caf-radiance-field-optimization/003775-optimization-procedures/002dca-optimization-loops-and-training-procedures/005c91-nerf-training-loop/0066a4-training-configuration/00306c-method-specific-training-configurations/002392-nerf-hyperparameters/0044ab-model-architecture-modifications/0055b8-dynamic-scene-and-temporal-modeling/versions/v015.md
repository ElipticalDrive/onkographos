# Dynamic Scene and Temporal Modeling

Also called: Dynamic NeRF, 4D Radiance Fields, Time-conditioned NeRF

## Overview
Dynamic Scene and Temporal Modeling extends static neural radiance fields to represent scenes that change over time, enabling novel view synthesis and tracking for video sequences . Unlike static methods, these approaches introduce a temporal dimension to the input space or representation, allowing the radiance field to vary continuously or discretely across time steps . This family addresses the many-to-one and one-to-many mapping ambiguities inherent in dynamic scene reconstruction by explicitly modeling motion, deformation, or temporal features .

## Shared principles
The standard NeRF architecture [Parent](3065-nerf-hyperparameters.md) serves as the baseline for most modifications. It consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ [14428-sparse-view-and-few-shot-optimization.md].

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories [14428-sparse-view-and-few-shot-optimization.md]:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation [14428-sparse-view-and-few-shot-optimization.md].
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs).

## Subtopics

### [Gear-NeRF](13848-gear-nerf.md)
A framework for free-viewpoint rendering and tracking of dynamic scenes that leverages semantic information from image segmentation models to stratify the scene into motion-based 'gears', allowing for region-specific spatio-temporal sampling resolution. It differs from standard dynamic NeRFs by replacing the unified 4D volume with a series of 4D feature volumes, one per gear level, where higher gears correspond to regions with larger motion scales and thus receive higher-resolution sampling. This approach improves photo-realistic dynamic novel view synthesis and enables free-viewpoint object tracking as a by-product.

### [NeRF with Time Parameter](14705-nerf-with-time-parameter.md)
This method adapts the standard NeRF architecture [Parent](3065-nerf-hyperparameters.md) for dynamic scenes by introducing a temporal dimension to the input space. It solves the problem of static scene representation in video sequences by allowing the neural radiance field to vary over time. Unlike sibling methods that may use complex graph structures or explicit warping, this approach relies solely on expanding the MLP input vector. While it improves reconstruction quality over vanilla NeRF, it remains a baseline that lacks detailed dynamic reasoning and suffers from blurry predictions.

### [Forward Warping for Novel View Synthesis](15541-forward-warping-for-novel-view-synthesis.md)
Forward Warping for Novel View Synthesis is a method for rendering dynamic scenes by modeling a static "canonical" radiance field and differentially warping this field to target time steps. It addresses the many-to-one and one-to-many mapping ambiguities inherent in dynamic scene reconstruction by using average splatting for forward warping and an inpaint network to fill occluded regions. Unlike backward-flow methods such as NDVG, this approach leverages a coarse-to-fine training strategy with explicit voxel grids for canonical features, achieving state-of-the-art performance on canonical frames and generalizing well to unseen times.

### [Dynamic Appearance Particle Neural Radiance Field](15550-dynamic-appearance-particle-neural-radiance-field.md)
Dynamic Appearance Particle NeRF is a method for modeling dynamic scenes from monocular video data by combining a static grid-based radiance field with a particle-based dynamic component. It solves the problem of reconstructing time-varying scenes without requiring multi-view stereo data or prior geometric knowledge of dynamic objects. Unlike ParticleNeRF, which encodes the entire scene with particles and requires multiple views per frame, this method applies appearance particles only to dynamic elements and uses a grid-based field for efficient linear interpolation, enabling processing of single-camera video streams.

### [KFD-NeRF](15551-kfd-nerf.md)
KFD-NeRF is a dynamic neural radiance field method that models the 4D radiance field as a dynamic system with temporally varying states, estimated using a Kalman filter to combine observations from input data and predictions based on local linear motion equations. It differs from sibling methods like [Gear-NeRF](13848-gear-nerf.md) and [NeRF with Time Parameter](14705-nerf-with-time-parameter.md) by explicitly separating motion estimation into an observer branch (shallow MLP) and a predictor branch (linear motion model), weighted by a learnable Kalman gain, rather than relying solely on time-conditioned feature interpolation or rigid deformation priors. It utilizes a tri-plane spatial representation for the canonical space to enable a shallower observation network and faster convergence.
