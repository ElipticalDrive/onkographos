# Binary Radiance Fields

Also called: BRF

## Overview
Binary Radiance Fields (BiRF) is a storage-efficient radiance field representation that constrains feature grid parameters to binary values (+1 or -1) to achieve compact storage without post-processing compression [S1]. Unlike methods that compress pre-trained models or use real-valued grids, BiRF performs binarization during training using a 2D-3D hybrid multi-resolution architecture, significantly reducing storage overhead while maintaining reconstruction quality [S1].

## How it works
BiRF maps a 3D position $\mathbf{x} \in \mathbb{R}^3$ and viewing direction $\mathbf{d} \in S^2$ to density $\sigma$ and color $\mathbf{c}$ using binary feature grids and shallow MLPs, building on the shared principles of encoding and decoding [Parent].

### Inputs and Outputs
*   **Inputs:** 3D coordinate $\mathbf{x}$, viewing direction $\mathbf{d}$.
*   **Outputs:** Volume density $\sigma \in \mathbb{R}$, color $\mathbf{c} \in \mathbb{R}^3$.

### Data Structures
The model consists of a multi-resolution 2D-3D hybrid feature grid and two MLPs. All grids use hash encoding [S1].

**1. Feature Grids**
*   **3D Voxel Grid ($\Phi_{\theta xyz}$):** $L$ resolution levels. Resolutions range from 16 to 1024. Each level stores up to $T_{3D}$ feature vectors.
*   **2D Plane Grids ($\Phi_{\theta xy}, \Phi_{\theta xz}, \Phi_{\theta yz}$):** $M$ resolution levels. Resolutions range from 64 to 512. Each level stores up to $T_{2D}$ feature vectors.
*   **Parameter Storage:** Parameters are binary, stored as 1-bit values (+1 or -1) [S1].
*   **Dimensions:**
    *   Small model (Ours-S): $\log_2(T_{3D}) = 17$, $\log_2(T_{2D}) = 15$ [S1].
    *   Base model (Ours-B): $\log_2(T_{3D}) = 19$, $\log_2(T_{2D}) = 17$ [S1].
    *   Feature dimension per level $F \in \{2, 4, 8\}$ [S1].

**2. MLPs**
*   **Density MLP:** 1 hidden layer, 128 channels, ReLU activation. Inputs: positional encoded $\mathbf{x}$ and concatenated features $\mathbf{f}$. Outputs: density $\sigma$ and embedding $\mathbf{e}$ [S1].
*   **Color MLP:** 2 hidden layers, 128 channels, ReLU activation. Inputs: embedding $\mathbf{e}$ and directional encoding $\mathbf{d}$. Outputs: color $\mathbf{c}$ [S1].
*   **Directional Encoding:** Spherical harmonics basis functions [S1].

### Parameters
*   $\lambda_{\text{sparsity}}$: Sparsity loss weight. Value: $2.0 \times 10^{-5}$ [S1].
*   Optimizer: Adam, initial learning rate 0.01, decayed by factor 0.33 at iterations 15,000 and 18,000 [S1].
*   Warm-up: First 1,000 iterations [S1].
*   Training iterations: 20,000 [S1].

### Pseudocode

```python
import math

def sign(x):
    """Binarization operator: +1 if x >= 0, -1 otherwise."""
    return 1.0 if x >= 0 else -1.0

def ste_sign(x):
    """Straight-Through Estimator for sign function.
    Returns sign(x) as output.
    Gradient is 1 if |x| <= 1, else 0.
    """
    # Forward pass
    out = sign(x)
    # Backward pass logic is handled by the framework using the gradient rule:
    # dL/dx = dL/dout * (1 if |x| <= 1 else 0)
    return out

def hash_encode(x, grid, level_res, max_vectors):
    """Hash encoding for a grid at a specific resolution level.
    Maps coordinate x to a hash index, retrieves binary parameters,
    and returns the interpolated feature vector.
    Note: Implementation details of hash function and interpolation
    are assumed to be provided by the underlying hash grid library
    (e.g., Instant-NGP style).
    """
    # 1. Hash the coordinate to an index
    index = hash_function(x, level_res)
    
    # 2. Retrieve binary parameters from the grid
    # The grid stores binary values (+1/-1)
    params = grid.get_parameters(index, max_vectors)
    
    # 3. Interpolate binary parameters to get feature vector
    # For 3D: trilinear interpolation
    # For 2D: bilinear interpolation
    features = interpolate(params, x, level_res)
    
    return features

def get_3d_features(x, grids_3d, L, T_3D):
    """Compute features from the 3D voxel grid."""
    features_list = []
    for l in range(1, L + 1):
        # Resolution for level l (e.g., 16 to 1024)
        res = get_resolution(l, min_res=16, max_res=1024, num_levels=L)
        # Get binary parameters and interpolate
        f = hash_encode(x, grids_3d[l], res, T_3D)
        features_list.append(f)
    return concatenate(features_list)

def get_2d_features(x, grids_2d, M, T_2D):
    """Compute features from the three 2D plane grids."""
    features_list = []
    
    # Project x to 2D planes
    x_xy = (x[0], x[1])
    x_xz = (x[0], x[2])
    x_yz = (x[1], x[2])
    
    planes = [grids_2d['xy'], grids_2d['xz'], grids_2d['yz']]
    coords = [x_xy, x_xz, x_yz]
    
    for plane, coord in zip(planes, coords):
        for m in range(1, M + 1):
            # Resolution for level m (e.g., 64 to 512)
            res = get_resolution(m, min_res=64, max_res=512, num_levels=M)
            # Get binary parameters and interpolate (bilinear)
            f = hash_encode(coord, plane, res, T_2D)
            features_list.append(f)
    return concatenate(features_list)

def positional_encoding(x, num_frequencies=10):
    """Sinusoidal positional encoding."""
    scales = [2**i for i in range(num_frequencies)]
    encoded = []
    for scale in scales:
        encoded.append(math.sin(scale * x))
        encoded.append(math.cos(scale * x))
    return encoded

def spherical_harmonics_encoding(d, degree=4):
    """Spherical harmonics encoding for direction d."""
    # Implementation depends on specific SH library
    # Returns feature vector based on direction
    return sh_basis(d, degree)

def density_mlp(x_pos_enc, features):
    """Shallow MLP for density prediction."""
    # Input: x_pos_enc (from positional_encoding)
    # Input: features (concatenated 3D and 2D features)
    # Architecture: 1 hidden layer, 128 channels, ReLU
    h = linear(features, 128)
    h = relu(h)
    h = linear(h, 128)
    sigma, embedding = split_output(h)
    return sigma, embedding

def color_mlp(embedding, d_sh_enc):
    """Shallow MLP for color prediction."""
    # Input: embedding (from density_mlp)
    # Input: d_sh_enc (from spherical_harmonics_encoding)
    # Architecture: 2 hidden layers, 128 channels, ReLU
    h = linear(concatenate([embedding, d_sh_enc]), 128)
    h = relu(h)
    h = linear(h, 128)
    h = relu(h)
    color = linear(h, 3)
    return color

def forward(x, d, grids_3d, grids_2d, L, M, T_3D, T_2D, F):
    """Main forward pass for Binary Radiance Fields."""
    
    # 1. Binarize grid parameters (during training, gradients flow via STE)
    # This is implicit in the grid storage/lookup if implemented with STE
    # For inference, parameters are already binary
    
    # 2. Feature Encoding
    f_xyz = get_3d_features(x, grids_3d, L, T_3D)
    f_2d = get_2d_features(x, grids_2d, M, T_2D)
    
    # 3. Concatenate features
    f = concatenate([f_xyz, f_2d])
    
    # 4. Positional Encoding for x
    x_enc = positional_encoding(x)
    
    # 5. Density Prediction
    sigma, embedding = density_mlp(x_enc, f)
    
    # 6. Directional Encoding for d
    d_enc = spherical_harmonics_encoding(d)
    
    # 7. Color Prediction
    color = color_mlp(embedding, d_enc)
    
    return sigma, color

def loss_function(rendered_color, ground_truth_color, density_samples, lambda_sparsity):
    """Total loss function."""
    # Reconstruction Loss (L2)
    l_recon = sum((rendered_color - ground_truth_color)**2)
    
    # Sparsity Loss (Cauchy Loss)
    # L_sparsity = sum(log(1 + 2 * sigma^2))
    l_sparsity = sum(math.log(1 + 2 * sigma**2) for sigma in density_samples)
    
    total_loss = l_recon + lambda_sparsity * l_sparsity
    return total_loss
```

### Edge Cases and Pitfalls
*   **Hash Collisions:** 3D grids suffer from hash collisions at higher resolutions. The 2D grids supplement the 3D grid, alleviating collision impact and reinforcing features with fewer parameters [S1].
*   **Gradient Vanishing:** The derivative of the sign function is zero almost everywhere. BiRF uses the Straight-Through Estimator (STE) to pass gradients through the threshold function during training [S1].
*   **Scale Divergence:** Large values of real-valued parameters $\theta$ can cause divergence. STE stops propagating gradients when $|\theta| > 1$, constraining the value to $\{-1, 1\}$ [S1].

## Operating characteristics
*   **Storage Efficiency:** BiRF achieves significant storage reduction. The small model (Ours-S2) requires less than 0.5 MB, outperforming TensoRF-CP (3.7 MB) and Instant-NGP (24.5 MB) on the mic scene while maintaining comparable or better PSNR [S1].
*   **Training Time:** Approximately 6, 9, and 14 minutes for Synthetic-NeRF scenes for Ours-B2 to Ours-B8 models on a single NVIDIA RTX A6000 GPU [S1].
*   **Performance:** PSNR of 32.03 dB for Synthetic-NeRF, 34.48 dB for Synthetic-NSVF, and 28.20 dB for Tanks and Temples scenes [S1].
*   **Strengths:** Compact storage, no post-optimization required, superior reconstruction performance compared to prior efficient methods [S1].
*   **Limitations:** Performance is bounded by the binary representation capacity; may struggle with extremely high-frequency details compared to full-precision models [S1].

## Background
Binary Radiance Fields were proposed by Seungjoo Shin and Jaesik Park in December 2023 [S1]. The work addresses the storage bottleneck of neural radiance fields by introducing binary feature encoding and a 2D-3D hybrid multi-resolution architecture. It builds upon Instant-NGP and NerfAcc implementations [S1].
