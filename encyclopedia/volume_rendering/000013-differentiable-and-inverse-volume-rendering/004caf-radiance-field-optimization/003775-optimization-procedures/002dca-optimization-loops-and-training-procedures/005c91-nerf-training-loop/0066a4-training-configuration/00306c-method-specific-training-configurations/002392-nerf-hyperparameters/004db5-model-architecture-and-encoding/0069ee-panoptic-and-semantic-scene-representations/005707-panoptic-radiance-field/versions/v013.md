# Panoptic Radiance Field

Also called: Panoptic Lifting

## Overview
Panoptic Lifting learns a panoptic 3D volumetric representation from posed RGB images and machine-generated 2D panoptic segmentation masks, lifting noisy 2D labels into a consistent 3D representation comprising color, density, semantics, and instances [S1]. It differs from siblings like [Panoptic NeRF](11916-panoptic-nerf.md) and [DM-NeRF](11916-depth-guided-nerf-training-configuration.md) by requiring no manual ground truth (such as coarse meshes or per-image 2D panoptic segmentations), relying instead on pre-trained 2D segmentation networks [S1]. It outperforms these methods in scene-level Panoptic Quality (PQ) while maintaining comparable novel view synthesis PSNR [S1].

## How it works
**Inputs:** Posed RGB images $\{I\}$ and corresponding machine-generated 2D panoptic segmentation masks. The 2D masks provide an RGB color $\hat{c}_r \in \mathbb{R}^3$, a semantic class $\hat{k}_r \in K$, and a 2D instance ID $\hat{h}_r \in H_I$ for each ray $r$ belonging to a training image. The instance ID $\hat{h}_r$ is defined only for "thing" classes $\hat{k}_r \in K_T$ [S1].

**Outputs:** A panoptic radiance field $\Phi(\mathbf{x}, \mathbf{d})$ that, for any 3D point $\mathbf{x} \in \mathbb{R}^3$ and viewing direction $\mathbf{d} \in S^2$, outputs:
1.  Density $\sigma \in \mathbb{R}_{\ge 0}$.
2.  Semantic class distribution $\kappa$ over classes $K$.
3.  Distribution $\pi$ over surrogate identifiers $J$.
4.  RGB color $\mathbf{c} \in \mathbb{R}^3$ [S1].

**Data Structures:**
The representation leverages a TensoRF [4] architecture for color and density. Two separate small Multi-Layer Perceptrons (MLPs) are used for the semantic field and the instance field [S1].
*   **Semantic MLP:** Outputs the semantic class distribution $\kappa$.
*   **Instance MLP:** Outputs the distribution $\pi$ over a fixed number of class-agnostic, 3D-consistent surrogate identifiers $J$ [S1].
*   **Surrogate Identifiers:** The set $J$ is fixed in size. The set of all possible 3D instances is $H_{3D} := K_T \times J$ [S1].

**Preprocessing (Test-Time Augmentation):**
To handle noise in machine-generated labels, test-time augmentations (horizontal flip, scale, brightness, contrast) are applied to input images. The resulting segmentations are fused by segment clustering to obtain a semantic class distribution $\hat{\kappa}_r$ and a confidence estimate $w_r$ for each pixel (ray $r$) [S1].

**Linear Assignment:**
To resolve inconsistencies in 2D instance identifiers across views, a linear assignment problem is solved. The cost is based on the model’s current 3D predictions and the machine-generated 2D masks. This maps each 2D instance $\hat{h}_r$ to a unique 3D surrogate identifier via an injective mapping $\Pi^*_R$ [S1].

**Rendering:**
Given a ray $r$ parameterized as $r = p_0 + t\mathbf{d}_r$, the transmittance is $\alpha_t(r) := \exp \left(-\int_0^t \sigma(r_s)ds\right)$. The rendered value for any vector field $f$ is:
$$ R[f |r, \sigma] := \int_0^\infty \alpha_t (r)\sigma(r_t)f (r_t, \mathbf{d}_{r_t})dt $$
Color $\mathbf{c}_r$, semantic distribution $\kappa_r$, and instance distribution $\pi_r$ are rendered using this equation [S1].

**Novel View Panoptic Segmentation:**
For a ray $r$ from a novel view:
1.  Compute the most probable semantic class: $k^*_r := \arg \max_{k \in K} \kappa_r(k)$.
2.  If $k^*_r$ is a thing class, compute the most probable surrogate identifier: $j^*_r := \arg \max_{j \in J} \pi_r(j)$.
3.  Form the unique 3D instance identifier: $(k^*_r, j^*_r) \in H_{3D}$ [S1].

**Training Objective:**
The total loss is:
$$ L_{tot}(R) := \lambda_{ins} L_{ins}(R_I) + \lambda_{con} L_{con}(R_I) + \lambda_{RGB} L_{RGB}(R_S) + \lambda_{sem} L_{sem}(R_S) $$
where $R_S$ are rays randomly sampled across the scene and $R_I$ are rays sampled from a single image [S1].

1.  **Semantic Loss ($L_{sem}$):** Cross-entropy between the rendered distribution $\kappa_r$ and the augmented label distribution $\hat{\kappa}_r$, weighted by confidence $w_r$:
    $$ L_{sem}(R) := -\frac{1}{|R|} \sum_{r \in R} w_r \sum_{k \in K} \hat{\kappa}_r(k) \log \kappa_r(k) $$
    The semantic field outputs bounded probability distributions directly, not logits, to prevent semantic inconsistencies in low-density areas [S1].

2.  **Instance Loss ($L_{ins}$):** Log-loss of the rendered instance distribution $\pi_r$ relative to the mapped 2D instance. For a batch of rays $R$, let $R_h$ be the subset of rays belonging to 2D instance $h \in H_I$, and $H_R \subseteq H_I$ be the subset of 2D instances in the batch. Each ray $r$ is assigned the most compatible 3D surrogate identifier $\Pi^*_R(\hat{h}_r)$ [S1].

3.  **Segment Consistency Loss ($L_{con}$):** Guides semantic supervision to avoid optima that fragment objects in the presence of label inconsistencies [S1].

4.  **Photometric Loss ($L_{RGB}$):** L2 loss on the rendered color $\mathbf{c}_r$ against the ground truth $\hat{c}_r$ [S1].

import torch
import torch.nn as nn
import torch.nn.functional as F

class PanopticRadianceField:
    def __init__(self, num_surrogates, num_classes, tensorf_config):
        """
        Initialize the Panoptic Lifting model.
        
        Args:
            num_surrogates (int): Fixed number of class-agnostic surrogate identifiers (|J|).
            num_classes (int): Number of semantic classes (|K|).
            tensorf_config (dict): Configuration for the TensoRF density/color backbone.
        """
        super().__init__()
        # TensoRF backbone for density and color
        self.tensorf = TensoRFBackbone(tensorf_config)
        
        # Semantic MLP: outputs bounded probability distribution over K
        # Uses Softmax to ensure bounded probabilities [S1]
        self.semantic_mlp = nn.Sequential(
            nn.Linear(tensorf_config.feature_dim, 128),
            nn.ReLU(),
            nn.Linear(128, num_classes)
        )
        
        # Instance MLP: outputs distribution over J surrogate identifiers
        # Uses Softmax to ensure bounded probabilities [S1]
        self.instance_mlp = nn.Sequential(
            nn.Linear(tensorf_config.feature_dim, 128),
            nn.ReLU(),
            nn.Linear(128, num_surrogates)
        )
        
        # Loss weights [S1]
        self.lambda_ins = 1.0
        self.lambda_con = 1.35
        self.lambda_sem = 1.0
        self.lambda_rgb = 1.0

    def forward(self, x, d):
        """
        Query the radiance field at point x with direction d.
        
        Args:
            x (Tensor): 3D points, shape (N, 3).
            d (Tensor): Viewing directions, shape (N, 3).
            
        Returns:
            sigma (Tensor): Density, shape (N,).
            c (Tensor): RGB color, shape (N, 3).
            kappa (Tensor): Semantic class distribution, shape (N, K).
            pi (Tensor): Surrogate identifier distribution, shape (N, J).
        """
        # Encode and decode density and color using TensoRF [S1]
        sigma, c = self.tensorf(x, d)
        
        # Get features for semantic and instance heads [S1]
        # Note: TensoRF typically provides features at x; d is used for view-dependent color
        features = self.tensorf.get_features(x)
        
        # Semantic head: outputs logits, then softmax for bounded probabilities [S1]
        semantic_logits = self.semantic_mlp(features)
        kappa = F.softmax(semantic_logits, dim=-1)
        
        # Instance head: outputs logits, then softmax for bounded probabilities [S1]
        instance_logits = self.instance_mlp(features)
        pi = F.softmax(instance_logits, dim=-1)
        
        return sigma, c, kappa, pi

    def render_ray(self, ray_origins, ray_directions, sigma_fn, kappa_fn, pi_fn, c_fn, t_near, t_far, num_samples):
        """
        Render a ray using volumetric rendering.
        
        Args:
            ray_origins (Tensor): Ray origins, shape (R, 3).
            ray_directions (Tensor): Ray directions, shape (R, 3).
            sigma_fn (callable): Function returning density sigma(x, d).
            kappa_fn (callable): Function returning semantic distribution kappa(x, d).
            pi_fn (callable): Function returning instance distribution pi(x, d).
            c_fn (callable): Function returning color c(x, d).
            t_near (float): Near plane distance.
            t_far (float): Far plane distance.
            num_samples (int): Number of samples per ray.
            
        Returns:
            color (Tensor): Rendered RGB, shape (R, 3).
            kappa_r (Tensor): Rendered semantic distribution, shape (R, K).
            pi_r (Tensor): Rendered instance distribution, shape (R, J).
            depth (Tensor): Rendered depth, shape (R,).
        """
        # Sample points along the ray [S1]
        t_vals = torch.linspace(t_near, t_far, num_samples)
        dists = t_vals[1:] - t_vals[:-1]
        z_vals = t_vals + dists * torch.rand_like(t_vals)
        
        # Query fields at sampled points
        # x = ray_origins + ray_directions * z_vals[..., None]
        # This requires broadcasting x and d to match sampled points
        # For brevity, assuming a helper `sample_and_query` exists that handles this
        # and returns sigma, c, kappa, pi for all samples
        sigma, c, kappa, pi = sample_and_query(
            ray_origins, ray_directions, z_vals, 
            sigma_fn, c_fn, kappa_fn, pi_fn
        )
        
        # Compute transmittance alpha_t(r) [S1]
        # alpha_t(r) = exp(-int_0^t sigma(r_s) ds)
        # Discrete approximation:
        alpha = 1.0 - torch.exp(-sigma * dists)
        transmittance = torch.cumprod(1.0 - alpha + 1e-10, dim=-1) # Cumulative product of (1-alpha)
        # Adjust transmittance to be at the start of each segment
        transmittance = torch.cat([torch.ones_like(transmittance[:, :1]), transmittance[:, :-1]], dim=-1)
        
        # Rendered values: R[f|r, sigma] = int alpha_t * sigma * f dt [S1]
        weights = alpha * transmittance
        weights_sum = weights.sum(dim=-1, keepdim=True)
        
        color = (weights[..., None] * c).sum(dim=-2)
        kappa_r = (weights[..., None] * kappa).sum(dim=-2)
        pi_r = (weights[..., None] * pi).sum(dim=-2)
        depth = (weights * z_vals).sum(dim=-1)
        
        return color, kappa_r, pi_r, depth

    def compute_loss(self, rays, gt_color, gt_kappa_dist, gt_confidence, gt_2d_instances, mapping):
        """
        Compute the total training loss.
        
        Args:
            rays (dict): Dictionary containing ray origins, directions, and sampled points.
            gt_color (Tensor): Ground truth RGB, shape (R, 3).
            gt_kappa_dist (Tensor): Ground truth semantic distribution from TTA, shape (R, K).
            gt_confidence (Tensor): Confidence weights from TTA, shape (R,).
            gt_2d_instances (Tensor): Ground truth 2D instance IDs, shape (R,).
            mapping (dict): Mapping from 2D instance IDs to 3D surrogate IDs.
            
        Returns:
            total_loss (Tensor): Scalar loss value.
        """
        # Forward pass
        sigma, c, kappa, pi = self.forward(rays['x'], rays['d'])
        
        # Render color, semantic, and instance distributions [S1]
        c_r, kappa_r, pi_r, _ = self.render_ray(
            rays['origins'], rays['directions'],
            lambda x, d: self.forward(x, d)[0],
            lambda x, d: self.forward(x, d)[2],
            lambda x, d: self.forward(x, d)[3],
            lambda x, d: self.forward(x, d)[1],
            t_near=0.0, t_far=10.0, num_samples=128
        )
        
        # Photometric Loss (L_RGB) [S1]
        l_rgb = F.mse_loss(c_r, gt_color)
        
        # Semantic Loss (L_sem) [S1]
        # Cross-entropy weighted by confidence
        # L_sem = -1/|R| sum w_r sum_k kappa_hat_r(k) log kappa_r(k)
        l_sem = -torch.mean(gt_confidence * torch.sum(gt_kappa_dist * torch.log(kappa_r + 1e-10), dim=-1))
        
        # Instance Loss (L_ins) and Segment Consistency Loss (L_con) [S1]
        # Map 2D instances to 3D surrogates using linear assignment result 'mapping'
        # For each ray, get the target surrogate ID
        target_surrogates = torch.zeros_like(gt_2d_instances)
        for r_idx, inst_id in enumerate(gt_2d_instances):
            if inst_id in mapping:
                target_surrogates[r_idx] = mapping[inst_id]
            else:
                target_surrogates[r_idx] = -1 # Ignore if not mapped
        
        # Instance Loss: Log-loss of rendered pi_r relative to target surrogates
        # Only for thing classes (assumed handled by gt_2d_instances being valid only for things)
        valid_mask = target_surrogates >= 0
        if valid_mask.sum() > 0:
            target_one_hot = F.one_hot(target_surrogates[valid_mask].long(), num_classes=pi.shape[1])
            l_ins = -torch.mean(torch.sum(pi_r[valid_mask] * torch.log(pi_r[valid_mask] + 1e-10) * target_one_hot.float(), dim=-1))
            l_con = 0.0 # Placeholder for segment consistency loss logic [S1]
        else:
            l_ins = torch.tensor(0.0)
            l_con = torch.tensor(0.0)
            
        # Gradient Blocking: Stop gradients from semantic and instance branches to geometry [S1]
        # This is implemented by detaching sigma or the features used for sigma from the semantic/instance heads
        # In the forward pass, ensure sigma is not in the computation graph of kappa/pi
        # (Handled by architecture design: TensoRF outputs sigma separately)
        
        total_loss = (self.lambda_ins * l_ins + 
                      self.lambda_con * l_con + 
                      self.lambda_rgb * l_rgb + 
                      self.lambda_sem * l_sem)
        
        return total_loss

    def optimize(self, dataloader, optimizer, num_iterations):
        """
        Training loop.
        
        Args:
            dataloader: Iterator yielding batches of (rays, gt_color, gt_kappa_dist, gt_confidence, gt_2d_instances).
            optimizer: Adam optimizer with lr=5e-4 for MLPs, 1e-2 for TensoRF [S1].
            num_iterations: Total training iterations (450k) [S1].
        """
        for i in range(num_iterations):
            batch = next(dataloader)
            rays, gt_color, gt_kappa_dist, gt_confidence, gt_2d_instances = batch
            
            # Linear assignment step to update mapping based on current predictions [S1]
            # This is done periodically or per batch to map 2D instances to 3D surrogates
            mapping = solve_linear_assignment(self, gt_2d_instances, rays)
            
            optimizer.zero_grad()
            loss = self.compute_loss(rays, gt_color, gt_kappa_dist, gt_confidence, gt_2d_instances, mapping)
            loss.backward()
            optimizer.step()
            
            if i % 1000 == 0:
                print(f"Iteration {i}, Loss: {loss.item()}")

**Parameters:**
*   $K$: Set of semantic classes, partitioned into thing classes $K_T$ and stuff classes $K_S$ [S1].
*   $J$: Set of surrogate identifiers. Fixed number held by the instance field MLP [S1].
*   $H_{3D}$: Set of all possible 3D instances, $H_{3D} := K_T \times J$ [S1].
*   Loss weights: $\lambda_{con} = 1.35$, $\lambda_{ins} = 1$, $\lambda_{sem} = 1$, $\lambda_{RGB} = 1$ [S1].
*   Optimizer: Adam. Learning rates: $5 \times 10^{-4}$ for MLPs, $1 \times 10^{-2}$ for TensoRF lines and planes [S1].
*   Training hardware: 1 NVIDIA A6000. Duration: 450k iterations (~10 hours) [S1].
*   Pre-trained 2D panoptic segmentation model: Mask2Former with Swin-L backbone [S1].

**Edge Cases and Pitfalls:**
*   **Logits vs. Probabilities:** Rendering class logits instead of probabilities can introduce semantic inconsistencies across viewpoints because unbounded logits can generate significant signals in low-density areas, violating geometric constraints. This is resolved by rendering bounded probability distributions (using Softmax) [S1].
*   **Geometry Corruption:** Supervision from noisy 2D labels can influence geometry, causing "cloudy" geometry to satisfy conflicting labels. This is avoided by stopping gradients from the semantic and instance branches back to the density field [S1].
*   **Class Limitations:** The method is limited to classes supported by the pre-trained 2D segmentation model (e.g., COCO Panoptic classes) [S1].
*   **Offline Processing:** The method runs offline due to lengthy pre-processing for pose estimation, 2D segmentation inference, and neural field optimization [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Training requires 450k iterations (~10 hours) on a single NVIDIA A6000 [S1]. The use of TensoRF for density/color and small MLPs for semantics/instances keeps the model size manageable compared to full MLP NeRFs, but the linear assignment and TTA add preprocessing overhead.
*   **Measured Performance:** Improves scene-level PQ by 8.4% on Hypersim, 13.8% on Replica, and 10.6% on ScanNet over state-of-the-art methods [S1]. Maintains comparable PSNR for novel view synthesis [S1].
*   **Strengths:** Robust to inherent noise in machine-generated labels; enables in-the-wild scene processing without manual ground truth; supports scene editing (deletion, duplication, manipulation) [S1].
*   **Limitations:** Limited to classes in the pre-trained 2D model; offline processing; requires posed images [S1].
*   **When to use:** When 3D panoptic segmentation is needed from unstructured image collections without manual annotation, and novel view synthesis with semantic consistency is required.
*   **When not to use:** When real-time processing is required, or when classes outside the pre-trained 2D model's vocabulary are needed.

## Background
Panoptic Lifting was introduced in "Panoptic Lifting for 3D Scene Understanding with Neural Fields" (CVPR 2023) [S1]. It addresses the limitation of previous panoptic NeRF methods (Panoptic NeRF, DM-NeRF) which required manual ground truth (coarse meshes or per-image 2D panoptic segmentations) [S1]. It builds on the TensoRF architecture [4] and leverages advances in 2D panoptic segmentation (e.g., Mask2Former) [S1].
