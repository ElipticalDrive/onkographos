# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF is a text-guided stylization method that optimizes a Neural Radiance Field (NeRF) to match the semantic embedding of a target text prompt [S2]. It distinguishes itself from standard NeRF training by replacing or augmenting photometric reconstruction losses with a directional CLIP loss, which enforces the trajectory of stylization in the CLIP embedding space [S2]. This approach solves the problem of text-driven 3D scene editing without requiring 3D ground-truth annotations, relying instead on the alignment between rendered views and text embeddings [S2].

## How it works
**Inputs and Outputs**
*   **Inputs:** A pre-trained NeRF model (density and color networks), a source image $\mathbf{I}_{src}$ (optional, for relative loss), a target text prompt $\mathbf{t}_{tgt}$, and a text encoder $\mathcal{E}_t$ (CLIP ViT-B/32) [S1, S2].
*   **Outputs:** Optimized NeRF parameters that render images semantically aligned with $\mathbf{t}_{tgt}$ [S2].

**Data Structures**
*   **NeRF Model:** Follows the parent structure [Parent]. The density network $f_\sigma$ and color network $f_c$ are parameterized.
*   **CLIP Text Encoder:** $\mathcal{E}_t$ maps text $\mathbf{t}$ to a normalized embedding vector $\hat{\mathbf{e}}_t = \mathcal{E}_t(\mathbf{t}) / \|\mathcal{E}_t(\mathbf{t})\|$ [S2].
*   **CLIP Image Encoder:** $\mathcal{E}_i$ maps an image $\mathbf{I}$ to a normalized embedding vector $\hat{\mathbf{e}}_i = \mathcal{E}_i(\mathbf{I}) / \|\mathcal{E}_i(\mathbf{I})\|$ [S2].

**Parameters**
*   **Iterations:** 500 [S1].
*   **Optimizer:** Adam with learning rate $\eta = 0.0001$ [S1].
*   **Patch Size:** $128 \times 128$ pixels [S1].
*   **Ray Sampling Stride:** 5 within the patch, resulting in a receptive field of $640 \times 640$ on the original image scale [S1].
*   **Importance Sampling Points:** 16 per ray during patch rendering [S1].
*   **Fine MLP Samples:** 80 total (64 coarse + 16 fine) [S1].
*   **Network Freezing:** Sub-parameters related to density are frozen; only color network parameters are optimized [S1].

**Loss Function**
Two variants of the directional CLIP loss are used [S2]:

1.  **Absolute Directional CLIP Loss:** Measures cosine similarity between the rendered image embedding and the target text embedding.
    $$ \mathcal{L}_{dir}^{abs} = 1 - \langle \hat{\mathbf{e}}_i(\mathbf{I}_{tgt}), \hat{\mathbf{e}}_t(\mathbf{t}_{tgt}) \rangle $$
    where $\mathbf{I}_{tgt}$ is the rendered image [S2].

2.  **Relative Directional CLIP Loss:** Measures the similarity of the *direction* of change from source to target in both image and text spaces. This mitigates mode collapse [S2].
    $$ \mathcal{L}_{dir}^{rel} = 1 - \langle \hat{\mathbf{e}}_i(\mathbf{I}_{tgt}) - \hat{\mathbf{e}}_i(\mathbf{I}_{src}), \hat{\mathbf{e}}_t(\mathbf{t}_{tgt}) - \hat{\mathbf{e}}_t(\mathbf{t}_{src}) \rangle $$
    where $\mathbf{t}_{src}$ is the text prompt describing the source image [S2].

**Algorithm**
1.  Initialize NeRF parameters. Freeze density network weights [S1].
2.  For iteration $k = 1$ to 500:
    a. Sample a random pose from the training dataset [S1].
    b. Render a patch $\mathbf{I}_{patch}$ of size $128 \times 128$ using the current NeRF.
       i. Sample rays with stride 5 to cover the patch [S1].
       ii. Perform volume rendering with 16 importance sampling points per ray [S1].
    c. Resize $\mathbf{I}_{patch}$ to the input resolution required by CLIP (typically $224 \times 224$) using bilinear interpolation [S1].
    d. Compute image embedding $\hat{\mathbf{e}}_i = \mathcal{E}_i(\mathbf{I}_{patch})$ [S2].
    e. Compute text embedding $\hat{\mathbf{e}}_t = \mathcal{E}_t(\mathbf{t}_{tgt})$ [S2].
    f. Calculate loss $\mathcal{L}_{dir}$ (absolute or relative) [S2].
    g. Compute gradients of $\mathcal{L}_{dir}$ with respect to the color network parameters [S1].
    h. Update color network parameters using Adam ($\eta=0.0001$) [S1].

**Edge Cases and Pitfalls**
*   **Memory Constraints:** Naive differentiable rendering of high-resolution images is intractable due to memory limits [S1]. The patch-based approach is required [S1].
*   **Mode Collapse:** The absolute directional CLIP loss can cause mode collapse of the generator and hurt generation diversity [S2].
*   **Insufficient Magnitude:** Directional loss alone struggles to reach sufficient stylization magnitude, resulting in weak style transfer [S2]. This is because it only measures directional similarity between normalized vectors, ignoring distance [S2].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of iterations (500) and the number of rays sampled per patch. Patch rendering is significantly faster than full-image rendering [S1].
*   **Memory Complexity:** Proportional to the patch size ($128 \times 128$) and sampling depth (80 samples/ray), rather than the full image resolution [S1].
*   **Strengths:** Enables text-driven 3D editing without 3D supervision; computationally efficient via patch rendering [S1, S2].
*   **Limitations:** May produce insufficient stylization magnitude if only directional loss is used; absolute directional loss risks mode collapse [S2].
*   **When to use:** When text-guided stylization of a NeRF is required and photometric reconstruction is not the primary goal or is augmented with semantic guidance [S2].
*   **When not to use:** When high-fidelity photometric reconstruction is the sole objective, or when diversity of generation is critical and absolute directional loss is employed [S2].

## Background
CLIPNeRF was introduced by Wang et al. in 2021 [S2]. It extends the StyleCLIP framework [Patashnik et al. 2021] and StyleGAN-NADA [Gal et al. 2021] from 2D image editing to 3D NeRF stylization. The method leverages the pre-trained CLIP model to align rendered views with text prompts [S2]. The relative directional loss variant was proposed to address the mode collapse and magnitude issues observed in the absolute directional approach [S2].
