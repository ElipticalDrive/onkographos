# MoCo-NeRF

Also called: Motion-Oriented Compositional Neural Radiance Fields

## Overview
MoCo-NeRF is a framework for free-viewpoint rendering of monocular human videos that models non-rigid body motions as radiance residual fields rather than spatial offsets [S1]. It separates the rigid canonical representation from pose-dependent non-rigid residuals, allowing for direct color supervision of the dynamic components [S1]. Unlike sibling methods that rely on spatial deformation fields, MoCo-NeRF reduces learning complexity by predicting residuals in the radiance space conditioned on a rigid prior [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Monocular video frames $I_j$, camera poses, and skeletal joint positions $J$ for each frame.
*   **Outputs:** Rendered RGB images $C_{final}$ for arbitrary viewpoints and times.

**Data Structures:**
1.  **Skeletal Weights Volume Decoder:** An explicit volume decoder optimized to predict canonical skinning weights $w^c_k$ for $K$ joints [S1].
2.  **Multiresolution Hash Encoding (MHE):**
    *   **Single-Subject:** One global MHE $\psi_{hash}$ with 16 levels, feature dimension $H=2$ per level [S1].
    *   **Multi-Subject:** One global MHE $\psi_{hash}^G$ (4 levels, $H=2$) shared across subjects, and $N_s$ local MHEs $\{\psi_{hash}^i\}$ for subject-specific details [S1].
3.  **Learnable Base Code:** $S \in \mathbb{R}^{64}$, randomly initialized and optimized per subject (or per ID in multi-subject) [S1].
4.  **Identity Codes:** $\{S_i\}_{i=1}^{N_s}$, learnable codes acting as a codebook for multi-subject differentiation [S1].
5.  **MLP Decoders:**
    *   $M_{rigid}$: Predicts rigid color $c$ and density $\sigma$.
    *   $M_{nr}$: Predicts non-rigid residuals $\Delta c, \Delta \sigma$.
6.  **Projection Matrices:** $W_p, W_Q, W_K, W_V$ for pose-embedded feature generation [S1].

**Numbered Steps:**

1.  **Canonical Transformation:** Transform an observed 3D point $\mathbf{x}$ at time $t$ to its canonical counterpart $\mathbf{x}_c$ using inverse linear blend skinning [S1]:
    $$ \mathbf{x}_c = \sum_{k=1}^K w^o_k (R_k \mathbf{x} + \mathbf{t}_k) $$
    where $R_k, \mathbf{t}_k$ are the rotation and translation of bone $k$, and observation weights $w^o_k$ are computed from canonical weights $w^c_k$ [S1]:
    $$ w^o_k = \frac{w^c_k(R_k \mathbf{x} + \mathbf{t}_k)}{\sum_{j=1}^K w^c_j(R_j \mathbf{x} + \mathbf{t}_j)} $$
    The canonical weights $w^c_k$ are predicted by the skeletal weights volume decoder [S1].

2.  **Rigid Branch Feature Query:** Query multiresolution volumetric features $f_{\mathbf{x}_c}$ from the MHE $\psi_{hash}$ (or $\psi_{hash}^G$ and $\psi_{hash}^i$ in multi-subject mode) [S1]:
    $$ f_{\mathbf{x}_c} = \psi_{hash}(\mathbf{x}_c) $$

3.  **Rigid Radiance Prediction:** Slice the first half ($H$ dimensions) of $f_{\mathbf{x}_c}$ at each resolution level to compute $f^{:H}_{\mathbf{x}_c}$. Predict rigid color $c$ and density $\sigma$ using $M_{rigid}$ [S1]:
    $$ c, \sigma = M_{rigid}(f^{:H}_{\mathbf{x}_c}) $$
    *Note:* In multi-subject mode, concatenate global features, sliced local features, and subject ID code $S_i$: $c, \sigma = M_{rigid}(\psi_{hash}^G(\mathbf{x}_c) \oplus (\psi_{hash}^i(\mathbf{x}_c))^{:H} \oplus S_i)$ [S1].

4.  **Non-Rigid Feature Preparation:** Use the full feature $f_{\mathbf{x}_c}$ but freeze the first half representing canonical radiance. Denote the remaining optimized half as $f^*_{\mathbf{x}_c}$ [S1].

5.  **Pose-Embedded Implicit Feature Generation:**
    a. Initialize learnable base code $S \in \mathbb{R}^{64}$ [S1].
    b. Apply sinusoidal positional encoding $\gamma$ to 23 joint positions $J$:
       $$ \gamma(\mathbf{j}_i) = [\mathbf{j}_i, \sin(2^0 \pi \mathbf{j}_i), \cos(2^0 \pi \mathbf{j}_i), \dots, \sin(2^{L-1} \pi \mathbf{j}_i), \cos(2^{L-1} \pi \mathbf{j}_i)] $$
       where $L=10$ frequency bands [S1].
    c. Project encoded joints $\gamma(J) \in \mathbb{R}^{23 \times 63}$ to raw pose-embedded code $P_{raw}$:
       $$ P_{raw} = W_p \cdot \gamma(J) $$
    d. Generate query $P_q$ from $S$, and key $P_k$, value $P_v$ from $P_{raw}$ via linear projections:
       $$ P_q = W_Q \cdot S, \quad P_k = W_K \cdot P_{raw}, \quad P_v = W_V \cdot P_{raw} $$
    e. Compute final implicit feature $P_{nr}$ using cross-attention:
       $$ P_{nr} = \text{softmax}(P_q \cdot P_k^\top) \cdot P_v $$

6.  **Non-Rigid Residual Prediction:** Predict color and density residuals $\Delta c, \Delta \sigma$ using $M_{nr}$ conditioned on $f^*_{\mathbf{x}_c}$ and $P_{nr}$ [S1]:
    $$ \Delta c, \Delta \sigma = M_{nr}(f^*_{\mathbf{x}_c}; P_{nr}) $$

7.  **Compositional Rendering:** For each ray $\mathbf{r}$, query $M$ samples. Compute final RGB $C_{final}$ using stratified sampling and volume rendering with compositional density $(\sigma + \Delta \sigma)$ and color $(c + \Delta c)$ [S1]:
    $$ C_{final}(\mathbf{r}) = \sum_{m=1}^M T_m (1 - \exp(-(\sigma_m + \Delta \sigma_m)\delta_m)) (c_m + \Delta c_m) $$
    where transmittance $T_m = \exp(-\sum_{n=1}^{m-1} \sigma_n \delta_n)$ and $\delta_m$ is the distance between adjacent samples [S1].

8.  **Rigid Rendering (for Loss):** Compute $C_{rigid}$ from $(c, \sigma)$ using the same volume rendering equation [S1].

**Parameters:**
*   $K$: Total number of joints (23) [S1].
*   $L$: Number of frequency bands in positional encoding ($L=10$) [S1].
*   $\lambda$: Hyperparameter for balancing rigid and final loss ($\lambda=0.2$) [S1].
*   $H$: Feature dimension per MHE level ($H=2$) [S1].
*   $M$: Samples per ray ($M=256$) [S1].
*   $N_p$: Patches per iteration ($N_p=6$) [S1].
*   Patch size: $32 \times 32$ [S1].

**Edge Cases and Pitfalls:**
*   **Spatial Offset Misalignment:** Traditional spatial offset strategies suffer from high computational complexity because offsets span an unbounded range and are unique for every 3D point across all frames. MoCo-NeRF avoids this by modeling non-rigid motions as radiance residuals, which have a bounded range and are directly supervised by RGB colors [S1].
*   **Frozen Features:** The non-rigid branch relies on freezing the first half of the MHE features to ensure coherent residual learning relative to the canonical representation [S1].

        self.h_dim = h_dim

## Operating characteristics
*   **Time Complexity:** Training is significantly faster than offset-based methods. Single-subject training takes 1–2 hours on an RTX 3090, compared to 38.9 hours for HumanNeRF [S1]. Multi-subject training (6 subjects) takes ~2 hours, compared to ~123 hours for NHP [S1].
*   **Memory Complexity:** Uses a single MHE for single-subject, or global + local MHEs for multi-subject. The MHE configuration is 16 levels with $H=2$ per level [S1].
*   **Performance:** Achieves state-of-the-art PSNR/SSIM/LPIPS* on ZJU-MoCap and MonoCap datasets. Single-subject PSNR ~31.06, SSIM 0.9734 [S1]. Multi-subject PSNR 31.97, SSIM 0.9781 [S1].
*   **Strengths:** Direct color supervision for non-rigid motions; efficient training; supports multi-subject training.
*   **Limitations:** Relies on accurate skeletal joint positions; assumes a canonical T-pose representation.

## Background
MoCo-NeRF was proposed by J. Kim et al. in 2024 [S1]. It addresses the limitations of spatial offset strategies in dynamic human modeling, which suffer from high computational complexity and misaligned learning objectives [S1]. The method builds on the principles of canonical transformation and articulation priors shared by [Dynamic and Articulated Scene Modeling](18219-dynamic-and-articulated-scene-modeling.md).
