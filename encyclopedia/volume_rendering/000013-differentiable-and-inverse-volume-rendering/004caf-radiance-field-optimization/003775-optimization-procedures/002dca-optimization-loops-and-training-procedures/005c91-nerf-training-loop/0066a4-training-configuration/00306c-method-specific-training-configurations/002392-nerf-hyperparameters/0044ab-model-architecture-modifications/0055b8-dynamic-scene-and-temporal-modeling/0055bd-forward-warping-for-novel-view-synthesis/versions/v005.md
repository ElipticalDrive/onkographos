# Forward Warping for Novel View Synthesis

Also called: Canonical Field Forward Warping, Forward Flow

## Overview
Forward Warping for Novel View Synthesis is a method for rendering dynamic scenes by modeling a static scene at a canonical time step and forward warping the entire canonical field to other time steps [S1]. It addresses the many-to-one and one-to-many mapping difficulties inherent in dynamic scene reconstruction using differentiable forward warping with average splatting and an inpaint network [S1]. It sets itself apart from backward flow-based methods like NDVG by leveraging a canonical-based representation that achieves state-of-the-art performance, particularly for canonical frames [S1].

## How it works
The method operates on a canonical radiance field and warps it to target time steps $t$. It uses a coarse-to-fine training strategy.

### Inputs and Outputs
*   **Inputs:** Training images $\mathcal{I}$ with known camera poses and time steps $t$.
*   **Outputs:** Rendered images $C(\mathbf{r}, t)$ for novel views and time steps.

### Data Structures
The method maintains several voxel grids and neural networks.

**Voxel Grids:**
1.  **Canonical Radiance Feature Grid ($VR_f$):** Voxel grid containing radiance features. Feature dimension is 12.
2.  **Canonical Coordinate Grid ($VR_{Can}$):** Voxel grid containing the coordinate of each voxel.
3.  **Canonical Density Grid ($V_{\sigma}^{Can}$):** Voxel grid containing canonical density.
4.  **Canonical Color Feature Grid ($V_{cf}^{Can}$):** Voxel grid containing canonical color features. Dimension is 3 or 12 depending on the training stage.
5.  **Canonical Deformation Feature Grid ($VD_f^{Can}$):** Voxel grid containing canonical deformation features. Dimension is 0 for D-NeRF, 12 for HyperNeRF.
6.  **Trajectory Grid ($VT_t$):** Voxel grid containing DCT parameters of each voxel's trajectory.
7.  **Deformation Flow Grid ($V_{flow}$):** Voxel grid containing deformation flow of each voxel from canonical to time $t$.
8.  **Warped Radiance Field ($VR_t$):** Radiance field at time $t$ warped from $VR_{Can}$.
9.  **Inpainted Radiance Field ($VR_t^{Inp}$):** Radiance field at time $t$ after inpainting by $F_{\theta3}$.
10. **Upsampled Radiance Field ($VR_t^{Up}$):** Upsampled radiance field at time $t$.

**Neural Networks:**
1.  **Canonical Radiance Network ($F_{\theta1}$):** 3-layer MLP, width 128, ReLU activation.
2.  **Canonical Deformation Network ($F_{\theta2}$):** 4-layer MLP, width 64.
3.  **Inpaint Network ($F_{\theta3}$):** UNet structure with 4 encode layers and 3 decode layers, plus an upsample layer. Each encode layer has one max pooling layer and two convolution layers. Each decode layer has one up-sample interpolation layer and two convolution layers. Convolution layers use instance norm followed by convolution and ReLU.
4.  **View Dependent Color Network ($F_{\theta4}$):** 2-layer MLP, width 64.

### Numbered Steps

1.  **Canonical Field Initialization:**
    *   Initialize voxel grids $VR_f$, $VR_{Can}$, $V_{\sigma}^{Can}$, $V_{cf}^{Can}$, $VD_f^{Can}$, $VT_t$, and $V_{flow}$.
    *   Initialize networks $F_{\theta1}$, $F_{\theta2}$, $F_{\theta3}$, and $F_{\theta4}$.
    *   Set canonical time $t_{can}$ (first frame for D-NeRF, middle frame for HyperNeRF) [S1].

2.  **Canonical Radiance Estimation ($F_{\theta1}$):**
    *   Sample radiance feature $\mathbf{f}_{rad}$ from $VR_f$ (dim 12) and embedded position $\mathbf{p}$ (dim 33).
    *   Compute density $\sigma$ (dim 1) and color feature $\mathbf{f}_{col}$ (dim 3 or 12) using $F_{\theta1}(\mathbf{f}_{rad}, \mathbf{p})$ [S1].

3.  **Deformation Flow Estimation ($F_{\theta2}$):**
    *   Sample deformation feature $\mathbf{f}_{def}$ from $VD_f^{Can}$ (dim 0 for D-NeRF, 12 for HyperNeRF) and embedded position $\mathbf{p}$ (dim 33).
    *   Compute trajectory parameters using $F_{\theta2}(\mathbf{f}_{def}, \mathbf{p})$. For D-NeRF, use 15 DCT bases; for HyperNeRF, use 25 DCT bases [S1].
    *   Store trajectory parameters in $VT_t$ [S1].

4.  **Forward Warping (Average Splatting):**
    *   For a target time $t$, compute the deformation flow $\mathbf{v}$ for each voxel from canonical to $t$ using the trajectory parameters in $VT_t$ and store in $V_{flow}$ [S1].
    *   Warp the canonical radiance field $VR_{Can}$ to time $t$ using average splatting based on the flow in $V_{flow}$ to produce $VR_t$ [S1].
    *   *Note:* Average splatting is used instead of softmax splatting as it provides comparable performance with less complexity [S1].

5.  **Inpainting:**
    *   Pass $VR_t$ through the Inpaint Network $F_{\theta3}$ to produce the inpainted radiance field $VR_t^{Inp}$ [S1].
    *   The Inpaint Network consists of a UNet and an upsample layer. The UNet has 4 encode layers and 3 decode layers. Each encode layer has one max pooling layer and two convolution layers. Each decode layer has one up-sample interpolation layer and two convolution layers. Convolution layers use instance norm followed by convolution and ReLU. The upsample layer has the same structure as the decode layer [S1].

6.  **Upsampling:**
    *   Upsample $VR_t^{Inp}$ to produce $VR_t^{Up}$ [S1].

7.  **Rendering:**
    *   Render color $\mathbf{C}_{Inp}(\mathbf{r})$ from $VR_t^{Inp}$ and $\mathbf{C}_{Up}(\mathbf{r})$ from $VR_t^{Up}$ using volume rendering [S1].
    *   For a ray $\mathbf{r}$, sample points $w_k$.
    *   Compute accumulated transmittance $T(w_k)$ and density $\sigma(w_k)$.
    *   Compute accumulation weight $A_{accum}(k) = T(w_k) \, \sigma(w_k) \delta_k$ [S1].
    *   Compute color feature from $VR_t^{Inp}$ or $VR_t^{Up}$, then pass through View Dependent Color Network $F_{\theta4}$.
    *   $F_{\theta4}$ input: embedded view direction (dim 27) and color feature (dim 12). Output: RGB color (dim 3) [S1].

8.  **Loss Computation:**
    *   Compute Point-wise Color Loss $\mathcal{L}_{ptc}$:
        $$ \mathcal{L}_{ptc} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Up}}(\mathbf{r})) $$
        where
        $$ \mathcal{L}(\mathbf{C}(\mathbf{r})) = \frac{1}{K} \sum_{k=1}^{K} A_{\text{accum}}(k) \|\mathbf{c}(w_k) - \mathbf{C}_{\text{gt}}(\mathbf{r})\|_2^2 $$
        and $A_{\text{accum}}(k) = T(w_k) \, \sigma(w_k) \delta_k$ [S1].
    *   Compute Background Entropy Loss $\mathcal{L}_{bg}$:
        $$ \mathcal{L}_{bg} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Up}}(\mathbf{r})) $$
        where
        $$ \mathcal{L}(\mathbf{A}(\mathbf{r})) = -\frac{1}{K-1} \sum_{k=1}^{K-1} [ A_{\text{accum}}(k)\log(A_{\text{accum}}(k)) + (1-A_{\text{accum}}(k))\log(1-A_{\text{accum}}(k)) ] $$
        [S1].
    *   Compute Total Loss:
        $$ \mathcal{L} = \mathcal{L}_{photo} + w_1\mathcal{L}_{ptc} + w_2\mathcal{L}_{bg} + w_3\mathcal{L}_{flow} + w_4\mathcal{L}_{vdiff} + w_5\mathcal{L}_{tv}(\mathbf{V}_{\sigma}^{\text{Can}}) + w_6\mathcal{L}_{tv}(\mathbf{V}_{\text{flow}}^t) + w_7\mathcal{L}_{tv}(\mathbf{D}) $$
        where $w_1..w_7$ are balancing weights [S1].

9.  **Optimization:**
    *   Update voxel grids and networks using Adam optimizer.
    *   Learning rate: $1e-1$ for voxel grids, $1e-3$ for networks [S1].

### Parameters

**Coarse Stage:**
*   Voxel Number: $6^3$ [S1].
*   Inpaint Scale: 1.5 [S1].
*   Iterations: 20,000 [S1].
*   Weights: $w_1=1e-1, w_2=1e-2, w_3=1e-5, w_4=0., w_5=1e-6, w_6=1e-3, w_7=1e-1$ [S1].
*   Note: Inpaint network is not used during the coarse stage [S1].

**Fine Stage:**
*   Voxel Number: $8^3$ for D-NeRF, $7^3$ for HyperNeRF [S1].
*   Inpaint Scale: 2.0 [S1].
*   Iterations: 100,000 [S1].
*   Weights: $w_1=1e-2, w_2=1e-3, w_3=1e-5, w_4=1e-5, w_5=1e-6, w_6=1e-3, w_7=1e-1$ [S1].
*   Progressive Training: Start with 10 images closest to canonical step, add one image with closest time step every 60 iterations [S1].

### Edge Cases and Pitfalls
*   **Memory Consumption:** High memory consumption, especially for real scenes [S1].
*   **Training Speed:** Slow training speed (~1 day per scene on GeForce RTX 3090) [S1].
*   **Coarse Stage Importance:** Removing the coarse stage causes significant performance drop because the voxel grid covers bigger space without proxy geometry filtering [S1].
*   **Inpaint Network Importance:** Removing the inpaint network significantly reduces performance (e.g., Hell Warrior PSNR drops from 27.71 to 27.15) [S1].
*   **Canonical Time Selection:** Setting canonical time to the middle frame helps improve performance for HyperNeRF as the geometry is closer to other time steps [S1].

## Operating characteristics
*   **Time Complexity:** Training takes approximately 1 day per scene on a GeForce RTX 3090 GPU [S1].
*   **Memory Complexity:** High memory consumption, especially for real scenes [S1].
*   **Model Size:** 260M parameters for D-NeRF, 440M for HyperNeRF [S1].
*   **Rendering Speed:** 7s per image for D-NeRF, 15s per image for HyperNeRF [S1].
*   **Strengths:** Achieves state-of-the-art performance on public datasets, especially for canonical frames. Forward warping design provides clear advantage over backward flow-based methods like NDVG [S1].
*   **Limitations:** High memory usage and slow training speed [S1].

## Background
Forward Warping for Novel View Synthesis was proposed in the paper "Forward Flow for Novel View Synthesis of Dynamic Scenes" [S1]. It builds on the canonical-based representation approach to dynamic scene rendering. The method addresses the challenges of many-to-one and one-to-many mappings in dynamic scenes by using differentiable forward warping with average splatting and an inpaint network. It has been evaluated on the D-NeRF dataset and a newly built Lego Complete Dataset [S1].
