# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the hyperparameters, architectural modifications, and optimization settings for training a Neural Radiance Field (NeRF) model using depth priors to regularize the reconstruction [S1]. It addresses the ambiguity in volume density estimation by incorporating explicit depth supervision, which is particularly effective for scenes with limited viewpoint coverage or ambiguous geometry [S1]. It differs from standard NeRF training by introducing a specific depth loss term and architectural dropout, and from [Binary Radiance Fields](13622-binary-radiance-fields.md) by maintaining continuous density representations rather than discrete occupancy grids.

## How it works
The method modifies the standard NeRF training loop by integrating a depth loss term into the total objective function and adjusting the network architecture to improve generalization [S1].

**Inputs:**
*   Camera poses and intrinsics.
*   RGB images.
*   Ground truth depth maps (optional but required for the depth loss term).
*   Scene bounds (min/max depth).

**Outputs:**
*   Trained NeRF model parameters (MLP weights).
*   Rendered RGB images and depth maps.

**Data Structures:**
*   **NeRF Model:** Builds on the original NeRF architecture [S1]. It consists of fully connected layers with ReLU activations.
*   **Positional Encoding:** Standard positional encoding is used for input coordinates $\mathbf{x}$ and viewing directions $\mathbf{d}$ [S1].
*   **Dropout:** Dropout layers with probability $p=0.1$ are inserted after each of the first eight fully connected ReLU-activated layers that encode the positional encoding [S1].

**Loss Function:**
The total loss $L$ combines the standard photometric loss $L_{rgb}$ and a depth loss $L_{depth}$ weighted by $\lambda$ [S1]:
$$ L = L_{rgb} + \lambda L_{depth} $$
The depth loss is typically computed as an $L_1$ or $L_2$ distance between predicted and ground truth depth, potentially weighted by uncertainty [S1]. The uncertainty threshold $\tau$ for evaluating depth validity is calculated as:
$$ \tau = (\text{max\_depth} - \text{min\_depth}) \cdot 0.0001 $$
For ScanNet, $\text{max\_depth} = 10$ and $\text{min\_depth} = 0.001$ [S1].

**Optimization Steps:**
1.  **Initialize** the NeRF model parameters.
2.  **Set Hyperparameters:**
    *   Optimizer: Adam [S1].
    *   Initial Learning Rate (LR): $5 \times 10^{-4}$ [S1].
    *   Weight Decay: $1 \times 10^{-6}$ [S1].
    *   Total Training Steps: 500,000 [S1].
    *   Depth Loss Weight ($\lambda$): $0.007$ for most scenes; $0.02$ for scene 710 [S1].
    *   Uncertainty Weight ($\gamma$): $1$ [S1].
    *   Depth Scale Learning Rate: $1 \times 10^{-7}$ [S1].
3.  **Training Loop:**
    *   Sample rays from input images.
    *   Render RGB and Depth for each ray.
    *   Compute $L_{rgb}$ against ground truth RGB.
    *   Compute $L_{depth}$ against ground truth depth (if available).
    *   Compute total loss $L$.
    *   Backpropagate and update weights.
4.  **Learning Rate Schedule:** Reduce the main learning rate to $5 \times 10^{-5}$ after 80% of the total training steps [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.optim as optim

class DepthGuidedNeRF(nn.Module):
    def __init__(self, input_dim, hidden_dim, num_layers=8):
        super().__init__()
        self.layers = nn.ModuleList()
        for i in range(num_layers):
            self.layers.append(nn.Linear(input_dim if i == 0 else hidden_dim, hidden_dim))
            self.layers.append(nn.ReLU())
            # Add dropout after first 8 ReLU layers as per [S1]
            if i < 8:
                self.layers.append(nn.Dropout(p=0.1))
        self.output_layer = nn.Linear(hidden_dim, 4) # 3 for color, 1 for density

    def forward(self, x):
        for layer in self.layers:
            x = layer(x)
        return self.output_layer(x)

def train_depth_guided_nerf(model, optimizer, scheduler, dataloader, total_steps, lambda_depth=0.007, scene_id=710):
    # Adjust lambda for specific scenes [S1]
    if scene_id == 710:
        lambda_depth = 0.02
    
    model.train()
    step = 0
    while step < total_steps:
        for batch in dataloader:
            images, depths, poses = batch
            
            # Forward pass
            rgb_pred, depth_pred = model(poses) # Simplified forward logic
            
            # Compute losses [S1]
            loss_rgb = torch.mean((rgb_pred - images) ** 2)
            loss_depth = torch.mean(torch.abs(depth_pred - depths))
            
            total_loss = loss_rgb + lambda_depth * loss_depth
            
            # Backward pass
            optimizer.zero_grad()
            total_loss.backward()
            optimizer.step()
            
            # Learning rate schedule [S1]
            if step > 0.8 * total_steps:
                scheduler.step()
            
            step += 1
            if step >= total_steps:
                break

# Configuration [S1]
# Optimizer: Adam, lr=5e-4, weight_decay=1e-6
# Scheduler: ReduceLROnPlateau or manual step to 5e-5 at 80%
# Depth Scale LR: 1e-7 (applied to specific depth scale parameters if present)
```

## Subtopics

### DS-NeRF Depth Loss Integration
This variant involves integrating the depth loss implementation from the official DS-NeRF codebase into the training pipeline [S2]. Due to missing configuration files for the DTU dataset in the official release, results for DTU were taken from the publication, while LLFF results were re-trained on specific train/test splits using released configuration files [S2]. This approach relies on PDC-Net correspondences for multi-view consistency [S2].

## Operating characteristics
*   **Complexity:** The addition of dropout layers and depth loss computation adds negligible overhead to the standard NeRF training complexity, which is dominated by ray marching and MLP evaluation [S1].
*   **Performance:** The configuration is designed to improve depth accuracy and geometric consistency, particularly in scenes with sparse viewpoints [S1].
*   **Limitations:** The specific hyperparameters (e.g., $\lambda=0.007$) are tuned for specific datasets like ScanNet and may require adjustment for other domains [S1]. The reliance on ground truth depth maps limits applicability to scenes where such data is available or can be reliably estimated [S1].
*   **Hardware:** Standard GPU acceleration is sufficient, as the method does not introduce significant memory or compute bottlenecks beyond standard NeRF rendering [S1].

## Background
The Depth-Guided NeRF Training Configuration originates from the work on "Depth-Guided NeRF Training via Earth Mover’s Distance" [S1]. It builds upon the original NeRF architecture [15] and incorporates techniques from DS-NeRF [S2] to leverage depth supervision. The method was developed to address the lack of explicit geometric constraints in standard NeRF training, which can lead to ambiguous reconstructions in unbounded or sparse-view scenarios [S1].
