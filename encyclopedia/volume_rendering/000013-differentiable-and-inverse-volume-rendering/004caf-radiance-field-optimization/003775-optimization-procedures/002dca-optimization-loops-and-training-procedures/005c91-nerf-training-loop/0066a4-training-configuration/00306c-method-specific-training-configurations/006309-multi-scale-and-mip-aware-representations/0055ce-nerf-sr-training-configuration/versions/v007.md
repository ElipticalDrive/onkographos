# NeRF-SR Training Configuration

Also called: NeRF-SR, NeRF Super-Resolution

## Overview
NeRF-SR is a training configuration designed to synthesize high-resolution novel views from low-resolution input images by optimizing a neural radiance field with a supersampling strategy [S1]. It differs from standard NeRF training by explicitly targeting high-resolution output during the optimization loop, rather than rendering low-resolution views and post-processing them [S1]. It builds on [NeRF Training Loop](3065-nerf-training-loop.md) but modifies the sampling and loss computation to enforce high-frequency detail recovery [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Low-resolution (LR) images (e.g., $504 \times 378$) and their corresponding camera poses.
*   **Output:** A trained MLP representing the radiance field and high-resolution (HR) rendered images (e.g., $1008 \times 756$ for $\times 2$ scale).

**Data Structures:**
*   **Radiance Field:** An MLP mapping 3D coordinates and viewing directions to volume density $\sigma$ and color $\mathbf{c}$. The architecture follows the standard NeRF "coarse" and "fine" MLPs [S1].
*   **Ray Batch:** A set of 2048 rays sampled per batch [S1].

**Numbered Steps:**
1.  **Ray Sampling:** For each training iteration, sample 2048 rays from the training views [S1].
2.  **Hierarchical Sampling:**
    *   **Coarse Stage:** Sample $N_c = 64$ points along each ray using uniform sampling [S1].
    *   **Fine Stage:** Sample $N_f = 64$ points along each ray using importance sampling based on the coarse density estimates [S1].
3.  **Volume Rendering:** Compute the predicted color $\hat{C}(\mathbf{r})$ for each ray using the differentiable volume rendering integral [Parent]:
    $$ \hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i $$
    where $N$ is the number of samples (64 for coarse, 64 for fine), $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, and $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ [Parent].
4.  **Loss Computation:** Calculate the photometric loss between the rendered HR pixel color $\hat{C}(\mathbf{r})$ and the ground truth HR pixel color $C_{gt}$ [S1]. The ground truth HR images are generated by upsampling the LR inputs or are the target resolution if available, but the training objective minimizes the difference at the HR resolution [S1].
5.  **Optimization:** Update the MLP parameters using the Adam optimizer [S1].

**Parameters:**
*   **Optimizer:** Adam with $\beta_1 = 0.9, \beta_2 = 0.999$ [S1].
*   **Batch Size:** 2048 rays [S1].
*   **Learning Rate:** Exponentially decayed from $5 \times 10^{-4}$ to $5 \times 10^{-6}$ [S1].
*   **Samples:** 64 coarse samples, 64 fine samples [S1].
*   **Epochs:** 20 epochs for Blender dataset, 30 epochs for LLFF dataset [S1]. Each epoch consists of one iteration over the whole training set [S1].

**Pseudocode:**
```python
# NeRF-SR Training Loop
# Assumes standard NeRF MLP structure with coarse and fine networks

def train_nerf_sr(model, train_dataset, optimizer, num_epochs):
    # Hyperparameters
    batch_size = 2048
    num_coarse_samples = 64
    num_fine_samples = 64
    lr_start = 5e-4
    lr_end = 5e-6
    
    # Initialize optimizer with specified beta values
    # optimizer = Adam(model.parameters(), lr=lr_start, betas=(0.9, 0.999))
    
    for epoch in range(num_epochs):
        # Learning rate decay
        current_lr = lr_start * (lr_end / lr_start) ** (epoch / num_epochs)
        set_learning_rate(optimizer, current_lr)
        
        for batch in train_dataset:
            rays, gt_colors = batch
            
            # 1. Coarse Sampling
            # Sample points along rays
            coarse_points = sample_points(rays, num_coarse_samples)
            
            # Forward pass through coarse MLP
            coarse_sigma, coarse_color = model.forward_coarse(coarse_points)
            
            # Volume rendering for coarse color
            coarse_rendered_colors = volume_render(coarse_points, coarse_sigma, coarse_color)
            
            # 2. Fine Sampling (Importance Sampling based on coarse density)
            fine_points = importance_sample(rays, coarse_sigma, num_fine_samples)
            
            # Forward pass through fine MLP
            fine_sigma, fine_color = model.forward_fine(fine_points)
            
            # Volume rendering for fine color
            fine_rendered_colors = volume_render(fine_points, fine_sigma, fine_color)
            
            # 3. Loss Computation
            # Compare fine rendered colors with ground truth HR colors
            loss = mean_squared_error(fine_rendered_colors, gt_colors)
            
            # 4. Optimization Step
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()

def volume_render(points, sigma, color):
    # Compute opacity alpha and transmittance T
    # delta is distance between consecutive samples
    deltas = compute_deltas(points)
    alpha = 1.0 - torch.exp(-sigma * deltas)
    transmittance = torch.cumprod(torch.exp(-sigma * deltas), dim=0)
    transmittance = torch.cat([torch.ones_like(transmittance[:, :1]), transmittance[:, :-1]], dim=1)
    
    # Weighted sum of colors
    weights = alpha * transmittance
    rendered_color = torch.sum(weights * color, dim=1)
    return rendered_color
```

**Edge Cases and Pitfalls:**
*   **Arbitrary Scale Limitation:** NeRF-SR does not support arbitrary-scale super-resolution; it is trained for specific scale factors (e.g., $\times 2, \times 4$) [S1].
*   **Real-world Detail:** Supersampling alone may be insufficient for complex real-world scenes (like LLFF), requiring additional refinement [S1].

## Subtopics

### Refinement Network (Ours-Refine)
A post-processing network that boosts NeRF-SR outputs with texture details and edge sharpness, particularly for real-world LLFF dataset where supersampling alone is insufficient [S1]. It uses a fixed number of reference patches ($K=8$) with dimensions $64 \times 64$ [S1]. During inference, input images are divided into non-overlapping patches and stitched together after refinement [S1]. Reference patches are extracted by backprojecting 3D coordinates from the estimated depth and camera parameters to a reference image [S1]. For scale $\times 2$, PSNR increases slightly but LPIPS improves; for scale $\times 4$, refinement is necessary as supersampling derives fewer details [S1]. Inference time is negligible (~1.3 seconds on a single 1080Ti for a $1008 \times 756$ image) compared to rendering (~48 seconds) [S1]. LLFF $\times 2$ Refined metrics: PSNR 27.34, SSIM 0.842, LPIPS 0.103. LLFF $\times 4$ Refined metrics: PSNR 25.59, SSIM 0.759, LPIPS 0.165 [S1].

## Operating characteristics
*   **Time Complexity:** Training time scales with the number of epochs and batch size. Rendering a $1008 \times 756$ image takes ~48 seconds on a single 1080Ti [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** On LLFF dataset, NeRF-SR (Ours-Refine) achieves PSNR 27.34 (SSIM 0.842, LPIPS 0.103) for $\times 2$ scale and PSNR 25.59 (SSIM 0.759, LPIPS 0.165) for $\times 4$ scale [S1].
*   **Strengths:** Achieves photorealistic renderings without external data; exploits 3D consistency [S1].
*   **Limitations:** Does not support arbitrary-scale super-resolution; introduces extra computation efficiency compared to standard NeRF, though it consumes no more time than training a HR NeRF [S1].
*   **When to use:** When high-resolution novel view synthesis is required from low-resolution inputs and the scale factor is fixed [S1].
*   **When not to use:** When arbitrary-scale super-resolution is needed or when real-world detail is critical and refinement is not feasible [S1].

## Background
NeRF-SR was introduced in "NeRF-SR: High-Quality Neural Radiance Fields using Supersampling" [S1]. It is the first pipeline for high-resolution novel view synthesis with mostly low-resolution inputs, achieving photorealistic renderings without external data [S1]. It exploits 3D consistency through a supersampling strategy that finds corresponding points in high-resolution space [S1].
