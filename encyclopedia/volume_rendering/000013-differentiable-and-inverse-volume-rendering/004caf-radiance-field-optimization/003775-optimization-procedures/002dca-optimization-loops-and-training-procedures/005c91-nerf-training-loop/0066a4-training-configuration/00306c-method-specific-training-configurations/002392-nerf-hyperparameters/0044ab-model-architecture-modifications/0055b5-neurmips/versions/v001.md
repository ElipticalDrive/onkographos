# NeurMiPs

Also called: NeurMiPs (Neural Mixture of Planar Experts), Neural Mixture of Planar Experts, Neural Mixture of Planar Experts for View Synthesis

## Overview
NeurMiPs represents a 3D scene as a mixture of $K$ learnable rectangular planar surfaces, where each surface acts as an independent "expert" predicting view-dependent color and transparency via a local neural radiance field [S1]. It alleviates the frontal-parallel limitation of traditional Multi-Plane Imagery (MPI) while maintaining high efficiency through analytical ray-plane intersection and parallel CUDA execution, offering superior extrapolation capabilities compared to voxel-based methods like PlenOctrees and KiloNeRF [S1].

## How it works
**Inputs:** Sparse 3D point cloud $\{x_i\}$ from Structure-from-Motion (SfM) [S1]; ground-truth images and camera poses [S1].
**Outputs:** Rendered image color $c(r)$ for a ray $r$; depth map $d(r)$ [S1].

**Data Structures:**
*   **Planar Expert Geometry ($s_k$):** A tuple for each expert $k \in \{1, \dots, K\}$ containing:
    *   $p_k$: 3D center coordinate.
    *   $n_k$: Normalized 3D normal vector.
    *   $u_k$: Normalized up vector defining the local y-axis direction.
    *   $w_k, h_k$: Width and height of the rectangle [S1].
*   **Student Network ($f_k$):** A Multi-Layer Perceptron (MLP) for each expert $k$.
    *   Architecture: 3 fully-connected hidden layers with ReLU activation; final output layer with sigmoid activation [S1].
    *   Input: Local 3D coordinate $x_{p,k}$ on the plane and normalized view direction $d \in S^2$. The direction $d$ is transformed into a higher-dimensional space using high-frequency functions before input [S1].
    *   Output: Color $c_k$ and transparency $\alpha_k$ [S1].
*   **Alpha Texture ($A_k$):** A $w \times h$ texture map storing pre-rendered, view-independent alpha values for plane $k$, used for acceleration [S1].

**Numbered Steps:**

1.  **Plane Initialization:** Initialize $\{s_k\}$ using the coarse SfM point cloud $\{x_i\}$. Centers $p_k$ are selected via farthest point sampling; normals $n_k, u_k$ are estimated from local point sets [S1]. Optimize geometry parameters by minimizing the geometry loss $\mathcal{L}_g$:
    $$
    \mathcal{L}_g = \sum_i \min_k d(x_i, s_k) + \lambda \sum_k (w_k h_k)^2
    $$
    where $d(x_i, s_k)$ is the distance from point $x_i$ to the closest rectangular surface $s_k$, and $(w_k h_k)^2$ is an area regularization term to prevent arbitrarily large rectangles. $\lambda$ is a weighting factor [S1].

2.  **Teacher Model Training:** Train a large-capacity standard NeRF as a teacher model. Point sampling is conducted through NeurMiPs's ray-plane intersection. Jointly optimize planar experts' geometric parameters and the teacher's weights. The total loss is:
    $$
    \mathcal{L}_{total} = \mathcal{L}_g + \mathcal{L}_c
    $$
    where $\mathcal{L}_c$ is the photometric loss:
    $$
    \mathcal{L}_c = \sum_{r} \|c(r) - c_{\text{gt}}(r)\|_2^2
    $$
    [S1].

3.  **Distillation:** For each planar expert $k$, draw random points uniformly from its rectangle and random view directions from the half unit sphere. Update the student network $f_k$ parameters by minimizing the L2 loss between the teacher's output $(c_{teacher}, \alpha_{teacher})$ and the student's output $(c_k, \alpha_k)$ for both color and alpha [S1].

4.  **Fine-Tuning:** Fix the plane parameters $\{s_k\}$. Fine-tune the student radiance field models to improve rendering quality by minimizing the L2-photometric loss $\mathcal{L}_c$ between rendered pixel color and ground-truth color [S1].

5.  **Rendering (Ray Casting):**
    a. **Ray-Plane Intersection:** For a ray $r = \{o, d\}$ and plane $k$, compute the intersection point $x_k$:
    $$
    x_k = o + \frac{(p_k - o) \cdot n_k}{d \cdot n_k} d
    $$
    Keep only intersected rectangles [S1].
    b. **Radiance Evaluation:** For each intersecting expert, evaluate $f_k(x_{p,k}, d)$ to output $\alpha_k$ and $c_k$. If alpha baking is enabled, retrieve $\alpha_k$ via bilinear interpolation from texture $A_k$ [S1].
    c. **Alpha Composition:** Collect samples $\{x_j, c_j, \alpha_j\}$. Sort from closest to furthest to eye $o$. Compute final color:
    $$
    c(r) = \sum_j \left( \prod_i^{j-1} (1 - \alpha_i) \right) \alpha_j c_j
    $$
    [S1].
    d. **Early Ray Termination:** If transmittance $\prod (1 - \alpha_i)$ is close to zero, stop evaluating further planes. Re-normalize if the sum of alpha values is smaller than 1 [S1].
    e. **Depth Estimation:** Compute expected depth:
    $$
    d(r) = \sum_j \left( \prod_i^{j-1} (1 - \alpha_i) \right) \alpha_j t_j
    $$
    where $t_j$ is the depth of sampled point $j$ [S1].

def ray_plane_intersection(ray_o, ray_d, plane_center, plane_normal):
    """
    Computes intersection of ray r=o+td with infinite plane defined by center p and normal n.
    Returns t if intersection exists, else None.
    """
    denom = np.dot(ray_d, plane_normal)
    if abs(denom) < 1e-8:
        return None
    t = np.dot(plane_center - ray_o, plane_normal) / denom
    if t < 0:
        return None
    return t

def get_local_coords(intersection_point, plane_center, plane_normal, plane_up, plane_width, plane_height):
    """
    Converts 3D intersection point to 2D local coordinates (u, v) on the plane.
    Assumes plane_up is orthogonal to plane_normal.
    """
    # Define local basis vectors
    # v_axis is plane_up
    # u_axis is cross(normal, up)
    plane_right = np.cross(plane_normal, plane_up)
    plane_right = plane_right / np.linalg.norm(plane_right)
    
    # Vector from center to intersection
    vec = intersection_point - plane_center
    
    # Project onto local axes
    u = np.dot(vec, plane_right)
    v = np.dot(vec, plane_up)
    
    # Normalize to [-1, 1] range relative to half-width/height
    u_norm = u / (plane_width / 2.0)
    v_norm = v / (plane_height / 2.0)
    
    return u_norm, v_norm

def check_point_in_rectangle(u_norm, v_norm):
    """

    return -1.0 <= u_norm <= 1.0 and -1.0 <= v_norm <= 1.0

**Parameters:**
*   $K$: Number of planar experts. Typical values: 500 for Replica dataset, 1000 for Tanks & Temples dataset [S1].
*   Optimizer: Adam with learning rate $5 \times 10^{-4}$ [S1].
*   Training Epochs: Teacher model: 6K epochs; Distillation: 1.5K epochs; Fine-tuning: 2.5K epochs [S1].
*   $\lambda$: Weighting factor for area regularization in $\mathcal{L}_g$. Value not specified in sources [S1].

**Edge Cases and Pitfalls:**
*   **Finite Plane Size:** Planes may not cover all regions in extreme viewpoints, inducing higher depth error for background scenes. This can be resolved by adopting multiple-layer boxes [S1].
*   **SfM Dependency:** Performance degrades if sparse point clouds are noisy or unavailable [S1].
*   **Unbounded Scenes:** Currently cannot handle unbounded scenes. A possible solution is incorporating techniques from NeRF++ to model background texture with non-Euclidean coordinates [S1].
*   **Alpha Baking Artifacts:** Applying alpha baking directly during inference might bring a minor rendering performance drop or quality drop due to discretization [S1].

## Operating characteristics
*   **Time Complexity:** Rendering is accelerated by analytical ray-plane intersection and early ray termination. Custom CUDA kernels fuse network evaluation of all experts into a single kernel for parallel rendering [S1].
*   **Memory Complexity:** Lower memory footprint compared to voxel-based approaches due to compact planar parameterization and small MLPs per expert [S1]. Alpha baking increases memory usage for textures [S1].
*   **Measured Performance:**
    *   **Replica:** 19.16 FPS on a single TITAN RTX using custom CUDA kernel [S1].
    *   **Tanks & Temples (Truck scene):** 976 FPS at 1920x1080 resolution on a single RTX 3090 using texture baking [S1].
    *   **Quality (Tanks & Temples):** PSNR 28.46, SSIM 0.908, LPIPS 0.089 [S1].
    *   **Quality (Replica):** PSNR 30.80, SSIM 0.900, LPIPS 0.088 [S1].
*   **Strengths:** More efficient in memory and computation than NeRF; more sample-efficient; better extrapolation; captures detailed textures on planar surfaces with sharp boundaries; better geometry reflection than MPI; handles non-planar and thin objects well [S1].
*   **Limitations:** Cannot handle unbounded scenes natively; relies heavily on SfM; finite plane size causes depth errors in extreme viewpoints [S1].

## Background
NeurMiPs was introduced in the paper "NeurMiPs: Neural Mixture of Planar Experts for View Synthesis" [S1]. It builds upon the success of neural radiance fields [44, 73] and multi-plane imagery [73], aiming to combine the geometric flexibility of neural rendering with the efficiency of planar representations. It addresses the "stack-of-cards" effect of NeX and the blurriness of NeRF in large-scale scenes [S1].
