# StyleGAN2 Training Configuration

Also called: StyleGAN2 Training Setup

## Overview
This configuration adapts the StyleGAN2 training pipeline for 3D-aware image synthesis, specifically within the context of differentiable volume rendering frameworks like VoxGRAF [S1]. It solves the problem of stable GAN training for high-resolution 3D representations by leveraging established 2D GAN stabilization techniques. It sets itself apart from standard NeRF training setups [13271-nerf-training-setup.md] by utilizing equalized learning rates, minibatch standard deviation, and R1 regularization, while explicitly omitting path regularization and style-mixing [S1]. It differs from the NeRF-GT baseline [11349-nerf-gt-baseline-training-setup.md] by relying on the specific discriminator architecture and regularization schedules of StyleGAN2 rather than generic volumetric losses alone.

## How it works
**Inputs and Outputs:**
*   **Inputs:** Real image batches, latent vectors $z$, and optional conditional inputs.
*   **Outputs:** Updated Generator ($G$) and Discriminator ($D$) weights.

**Data Structures:**
*   **Generator ($G$):** Style-based generator with equalized learning rates.
*   **Discriminator ($D$):** StyleGAN2 discriminator with conditional input and skip connections for progressive growing.
*   **EMA State:** Exponential Moving Average of generator weights.

**Numbered Steps:**
1.  **Equalized Learning Rates:** Scale the learning rate for each trainable parameter in the generator and discriminator inversely proportional to the square root of the number of parameters in that layer [S1]. This ensures stable gradient flow across layers of varying sizes.
2.  **Minibatch Standard Deviation:** Append a minibatch standard deviation layer to the end of the discriminator [S1]. This layer computes the standard deviation of features across the minibatch dimension and concatenates it as an additional channel to the feature map, helping the discriminator detect mode collapse.
3.  **Exponential Moving Average (EMA):** Maintain an EMA of the generator weights. Update the EMA weights $\theta_{ema}$ after each generator update:
    $$ \theta_{ema} \leftarrow \alpha \theta_{ema} + (1 - \alpha) \theta_{gen} $$
    where $\alpha$ is the decay rate (typically close to 1, e.g., 0.999) [S1].
4.  **Mixed Precision:** Perform forward and backward passes for both generator and discriminator using mixed-precision arithmetic (FP16/FP32) to accelerate training and reduce memory usage [S1].
5.  **R1 Regularization:** Apply R1 regularization to the discriminator to enforce gradient penalty [S1]. Unlike standard StyleGAN2, R1 regularization is applied only once every 4 minibatches to reduce computational cost [S1].
    *   Compute the R1 penalty on real images $x$:
        $$ \mathcal{L}_{R1} = \frac{\gamma}{2} \mathbb{E}_{x \sim p_{data}} [\|\nabla_x D(x)\|_2^2] $$
    *   The regularization strength is $\gamma = 1$ [S1].
6.  **Exclusions:** Do not use path regularization or style-mixing [S1]. These features are omitted to reduce complexity and memory usage in the 3D-aware context.

**Parameters:**
*   **R1 Regularization Strength ($\gamma$):** 1 [S1].
*   **R1 Frequency:** Once every 4 minibatches [S1].
*   **Learning Rate:** Not given in the sources.
*   **EMA Decay:** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Small Datasets:** For small datasets like AFHQ, finetuning a generator pretrained on FFHQ is required [S1]. Use representation dimensions $R_I = 128$ and $R_G = 32$ before pruning [S1].
*   **Progressive Growing:** When using progressive growing, the discriminator must use a skip architecture that adds a downsampled version of the input image to the input of each layer [S1].

```python
def train_step(real_images, latent_z, discriminator, generator, ema_generator, optimizer_d, optimizer_g, global_step):
    # 1. Equalized Learning Rates are handled by the model architecture definition
    # 2. Minibatch Std Dev is handled by the discriminator architecture
    
    # 3. Discriminator Update
    # Compute D(real) and D(fake)
    d_real = discriminator(real_images)
    z_fake = latent_z
    fake_images = generator(z_fake)
    d_fake = discriminator(fake_images.detach())
    
    # Standard GAN loss
    loss_d = compute_gan_loss(d_real, d_fake)
    
    # R1 Regularization (applied every 4 minibatches)
    if global_step % 4 == 0:
        real_images.requires_grad = True
        d_real_grad = discriminator(real_images)
        r1_penalty = compute_r1_penalty(d_real_grad, real_images)
        loss_d += r1_penalty * gamma # gamma = 1
        
    optimizer_d.zero_grad()
    loss_d.backward()
    optimizer_d.step()
    
    # 4. Generator Update
    fake_images = generator(latent_z)
    d_fake = discriminator(fake_images)
    loss_g = compute_gan_loss(d_fake) # Maximize D(fake)
    
    optimizer_g.zero_grad()
    loss_g.backward()
    optimizer_g.step()
    
    # 5. EMA Update
    update_ema(ema_generator, generator, decay=0.999) # Decay not specified, typical value used
    
    return loss_d, loss_g

def compute_r1_penalty(d_output, real_images):
    # Compute gradient of D with respect to real images
    grad = torch.autograd.grad(
        outputs=d_output.sum(), 
        inputs=real_images, 
        create_graph=True, 
        retain_graph=True, 
        only_inputs=True
    )[0]
    # L2 norm squared
    penalty = (grad ** 2).sum(dim=1).mean()
    return penalty
```

## Subtopics

### Conditional Discriminator with Skip Connections for Progressive Growing
A variant of the discriminator used when training with progressive growing [S1]. It incorporates conditional input and uses a skip architecture that adds a downsampled version of the input image to the input of each layer [S1]. This allows the discriminator to handle images of increasing resolution smoothly during training [S1].

## Operating characteristics
*   **Time Complexity:** R1 regularization is applied every 4 minibatches, reducing the computational overhead compared to applying it every step [S1]. Mixed precision further accelerates training [S1].
*   **Memory Complexity:** R1 regularization frequency reduction also lowers memory usage [S1].
*   **Strengths:** Stable training for high-resolution 3D representations; leverages mature 2D GAN techniques; efficient rendering via CUDA kernels [S1].
*   **Limitations:** Requires careful handling of small datasets via finetuning [S1]; omits style-mixing and path regularization which may affect sample diversity in some contexts [S1].
*   **When to use:** When training 3D-aware GANs (like VoxGRAF) and stability is a concern; when leveraging pretrained 2D generators [S1].
*   **When not to use:** When style-mixing or path regularization is critical for the specific application [S1].

## Background
This configuration is derived from the StyleGAN2 training methodology  and adapted for 3D-aware image synthesis in frameworks like VoxGRAF [S1]. It builds on the principle of using equalized learning rates and minibatch standard deviation for stability [S1]. The specific omission of path regularization and style-mixing is a modification from the original StyleGAN2  to suit the 3D volume rendering context [S1]. The use of R1 regularization every 4 steps is a computational optimization noted in the VoxGRAF implementation [S1].
