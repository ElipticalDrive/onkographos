# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the training protocol for Neural Radiance Fields (NeRF) that incorporate depth priors to improve reconstruction quality, particularly in sparse-view or ambiguous geometry scenarios. It extends the standard NeRF optimization loop by integrating a depth loss term and specific architectural regularizations. It differs from sibling methods like [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md) by focusing on geometric consistency via depth metrics rather than semantic alignment, and from [Binary Radiance Fields](13622-binary-radiance-fields.md) by maintaining continuous density representations.

## How it works
The method modifies the standard NeRF training loop [Parent](13550-model-architecture-and-encoding.md) by adding dropout regularization to the encoding network and introducing a weighted depth loss.

**Inputs:**
- Camera poses and intrinsics.
- RGB images.
- Ground truth depth maps (optional, depending on scene).
- Scene-specific depth bounds ($min\_depth$, $max\_depth$).

**Outputs:**
- Trained NeRF model parameters (MLP weights).
- Rendered RGB images and depth maps.

**Data Structures:**
- **MLP Weights:** Standard dense layer weights for the density and color networks.
- **Dropout Mask:** Binary mask applied during training to the first 8 fully connected layers of the positional encoding network.
- **Depth Map:** 2D array of depth values $d_{gt}$ corresponding to pixel coordinates.

**Parameters:**
- Dropout probability $p = 0.1$.
- Depth loss weight $\lambda$: $0.007$ for most scenes; $0.02$ for scene 710.
- Uncertainty weight $\gamma = 1$.
- Optimizer: Adam.
- Learning rate $lr = 5 \times 10^{-4}$.
- LR schedule: Reduce to $5 \times 10^{-5}$ after 80% of total steps.
- Weight decay $wd = 1 \times 10^{-6}$.
- Total training steps $T = 500,000$.
- Depth scale learning rate $lr_{scale} = 1 \times 10^{-7}$.
- Threshold $\tau = (max\_depth - min\_depth) \times 0.0001$.

**Steps:**
1. **Initialize Model:** Construct the NeRF architecture as defined in [Parent](13550-model-architecture-and-encoding.md).
2. **Add Dropout:** Insert dropout layers with probability $p=0.1$ after each of the first eight fully connected ReLU-activated layers that encode the positional encoding [S1].
3. **Define Loss Function:** The total loss $\mathcal{L}$ is a combination of the standard RGB photometric loss $\mathcal{L}_{rgb}$ and the depth loss $\mathcal{L}_{depth}$:
   $$ \mathcal{L} = \mathcal{L}_{rgb} + \lambda \mathcal{L}_{depth} $$
   The depth loss is typically computed against ground truth depth $d$ and predicted depth $\hat{d}$ using metrics such as RMSE or AbsRel [S1].
4. **Compute Uncertainty Threshold:** For depth evaluation or filtering, compute the threshold $\tau$ using scene-specific bounds:
   $$ \tau = (max\_depth - min\_depth) \cdot 0.0001 $$
   For ScanNet, $max\_depth = 10$ and $min\_depth = 0.001$ [S1].
5. **Optimization Loop:**
   For step $t$ from 1 to $T$:
   a. Sample rays and render RGB and depth.
   b. Compute $\mathcal{L}_{rgb}$ and $\mathcal{L}_{depth}$.
   c. Compute total loss $\mathcal{L}$.
   d. Update weights using Adam optimizer with $lr$ and $wd$.
   e. Apply dropout masks during forward pass [S1].
   f. Adjust learning rate: if $t > 0.8 T$, set $lr = 5 \times 10^{-5}$ [S1].
   g. Update depth scale parameters with $lr_{scale} = 1 \times 10^{-7}$ [S1].

**Edge Cases and Pitfalls:**
- **Scene 710:** Requires a higher depth loss weight ($\lambda = 0.02$) compared to other scenes ($\lambda = 0.007$) [S1].
- **Depth Bounds:** The threshold $\tau$ depends on accurate $min\_depth$ and $max\_depth$ values, which vary by dataset (e.g., ScanNet) [S1].
- **Overfitting:** The dropout layers are critical for preventing overfitting when using depth priors, especially in sparse-view settings [S1].

## Subtopics

### DS-NeRF Depth Loss Integration
Integrates the depth loss implementation from the official DS-NeRF code base into the training pipeline. This variant requires re-training on specific train/test splits (e.g., LLFF) because original publication results used different splits or unreleased configurations. For DTU, official results are used as reproduction with released config files failed, potentially due to undocumented architectural tricks like reduced positional encoding frequency [S2].

## Operating characteristics
- **Time Complexity:** Standard NeRF training complexity, extended by depth loss computation. Total steps are fixed at 500,000 [S1].
- **Memory Complexity:** Standard NeRF memory usage, plus storage for depth maps and dropout masks.
- **Performance:** Improves geometric accuracy in scenes with ambiguous geometry by leveraging depth priors [S1].
- **Strengths:** Robustness to sparse views; better depth consistency.
- **Limitations:** Requires ground truth depth or reliable depth estimation; sensitive to depth loss weight $\lambda$ [S1].
- **When to Use:** Sparse-view reconstruction, scenes with textureless regions, or when geometric accuracy is prioritized over photometric fidelity.
- **When Not to Use:** Dense-view scenarios where standard NeRF suffices; scenes without reliable depth priors.

## Background
Originated from the integration of depth guidance into NeRF training, as detailed in "Depth-Guided NeRF Training via Earth Mover’s Distance" [S1]. The method builds on the original NeRF architecture [Parent](13550-model-architecture-and-encoding.md) and incorporates techniques from DS-NeRF for depth loss integration [S2]. It is used in applications requiring high-fidelity 3D reconstruction from limited or noisy pose data, such as in the SPARF framework [S2].
