# StylizedNeRF

Also called: StyleNeRF

## Overview
StylizedNeRF (also known as StyleNeRF) is a method for generating high-resolution, 3D-consistent stylized images by integrating a style-based generator (StyleGAN2) with a differentiable volume renderer [S2, unofficial]. It solves the problem of 3D inconsistency in neural rendering by using a mutual learning strategy to optimize both the stylized NeRF and a 2D stylization network, handling ambiguities via learnable latent codes [S1]. It differs from its siblings by explicitly decoupling content geometry (via a NeRF++ backbone) and appearance (via StyleGAN2-style synthesis), whereas Spherical Harmonics NeRF focuses on physical lighting decomposition and Neural-PIL focuses on pre-integrated lighting approximations [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A dataset of images (e.g., FFHQ), camera poses, and target style images.
*   **Outputs:** A 3D-aware generator that synthesizes stylized images from random latent codes and camera parameters.

**Data Structures:**
The model consists of two main components: a **Mapping Network** and a **Synthesis Network**.
1.  **Mapping Network:** An 8-layer fully connected network [S2, unofficial]. It maps a standard Gaussian sampled latent code $\mathbf{z}$ to a style vector $\mathbf{w}$.
2.  **Synthesis Network:** Based on NeRF++ [S2, unofficial].
    *   **Foreground Field:** An MLP with 256 hidden units [S2, unofficial].
    *   **Background Field:** An MLP with 128 hidden units [S2, unofficial].
    *   **Color Field:** A shared MLP for color prediction [S2, unofficial].
    *   **Style-Conditioned Blocks:** Consist of an affine transformation layer and a $1 \times 1$ Convolution layer [S2, unofficial].

**Numbered Steps:**
1.  **Latent Sampling:** Sample a latent code $\mathbf{z} \sim \mathcal{N}(0, I)$ [S2, unofficial].
2.  **Style Mapping:** Pass $\mathbf{z}$ through the Mapping Network to obtain style vectors $\mathbf{w}$ [S2, unofficial].
3.  **NeRF++ Rendering:**
    *   For a ray $\mathbf{r}$, sample points $\mathbf{x}_i$.
    *   Encode position $\mathbf{x}_i$ using Fourier features with dimension $L=10$:
        $$
        \gamma(\mathbf{x}) = [\mathbf{x}, \sin(2^0\pi\mathbf{x}), \cos(2^0\pi\mathbf{x}), \dots, \sin(2^{L-1}\pi\mathbf{x}), \cos(2^{L-1}\pi\mathbf{x})]
        $$
    *   Input $\gamma(\mathbf{x}_i)$ and style $\mathbf{w}$ into the Foreground/Background MLPs to predict density $\sigma_i$ [S2, unofficial].
    *   Input $\gamma(\mathbf{x}_i)$ and $\mathbf{w}$ into the shared Color MLP to predict color $\mathbf{c}_i$ [S2, unofficial].
    *   Render the image using standard volume rendering integration [S2, unofficial].
4.  **StyleGAN2 Synthesis Integration:**
    *   The style vectors $\mathbf{w}$ are broadcast to the synthesis network blocks [S2, unofficial].
    *   In each Style-Conditioned Block, the convolution weights are modulated by the affine-transformed styles and demodulated for computation [S2, unofficial].
    *   Activation uses Leaky ReLU [S2, unofficial].
5.  **Mutual Learning:**
    *   Optimize the stylized NeRF and the 2D stylization network simultaneously [S1].
    *   Use learnable latent codes to handle ambiguities of 2D stylized results, ensuring 3D geometry consistency [S1].
6.  **Loss Calculation:**
    *   Use a non-saturating GAN objective with R1 regularization [S2, unofficial].
    *   Apply a NeRF path regularization to enforce 3D consistency [S2, unofficial].

**Parameters:**
*   **Mapping Network:** 8 fully connected layers, learning rate $100\times$ lower than default [S2, unofficial].
*   **Latent/Style Dimensions:** 512 [S2, unofficial].
*   **Foreground MLP Hidden Units:** 256 [S2, unofficial].
*   **Background MLP Hidden Units:** 128 [S2, unofficial].
*   **Fourier Feature Dimension ($L$):** 10 [S2, unofficial].
*   **Input Resolution:** Fixed at $32^2$ for all experiments [S2, unofficial].
*   **Feature Sizes:** Decrease from 512 (for $32\times32$) to 32 (for $1024\times1024$) after 2D aggregation [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **GPU Memory:** Training at high resolutions requires careful batch sizing (default batch size 64) and potentially progressive growing [S2, unofficial].
*   **Dataset Size:** Small datasets (e.g., etFaces) may require fine-tuning from a pretrained model (e.g., FFHQ) to train stably [S2, unofficial].

## Subtopics

### [Physical Imaging Model with Spherical Harmonics](16376-physical-imaging-model-with-spherical-harmonics.md)
This method integrates a physically constrained imaging model into the NeRF optimization loop to decompose illumination into direct sunlight and ambient skylight, using spherical harmonics to model the latter. It differs from standard NeRF by explicitly separating albedo, surface normals, and lighting to provide auxiliary supervision, thereby reducing lighting ambiguity and improving reconstruction fidelity in shadowed or radiometrically inconsistent regions.

### [StyleRF-VolVis](16573-stylerf-volvis.md)
StyleRF-VolVis is a framework for editing the style (appearance) of a DVR scene represented by a NeRF model without losing original content (geometry) information. It supports both photorealistic (PSE) and non-photorealistic (NPSE) editing in a single pipeline by separating content and appearance, allowing explicit assignment of different styles to different DVR regions via a Palette Color Network (PCN) and an Unrestricted Color Network (UCN), while preserving view-dependent lighting. It differs from prior works by supporting both photorealistic and non-photorealistic editing in a single framework, whereas others focus on one or the other.

### [Non-Photorealistic Style Editing](16597-non-photorealistic-style-editing.md)
Non-Photorealistic Style Editing (NPSE) is a style transfer process for volume rendering that assigns specific styles to distinct regions of a scene using an unrestricted color network and Nearest Neighbor Feature Matching (NNFM) loss. Unlike StylizedNeRF which assigns one style to the whole scene, NPSE allows explicit assignment of different styles to different DVR regions. Unlike ARF and StylizedNeRF which discard view directions to ensure consistency, NPSE removes view direction input only in the Unrestricted Color Network (UCN) optimization to preserve lighting while ensuring consistency.

## Operating characteristics
*   **Time Complexity:** Training is computationally intensive, requiring approximately three days on 8 Tesla V100 GPUs for default configurations [S2, unofficial].
*   **Memory Complexity:** High memory usage due to the combination of NeRF++ and StyleGAN2 architectures; feature sizes scale with resolution [S2, unofficial].
*   **Strengths:** Achieves high-quality, 3D-consistent stylized images; handles unbounded backgrounds via NeRF++ [S2, unofficial].
*   **Limitations:** Requires large datasets for stable training; sensitive to hyperparameters like learning rate and batch size [S2, unofficial].
*   **When to use:** When high-resolution, 3D-consistent stylized image synthesis is required.
*   **When not to use:** When computational resources are limited or when view-dependent lighting preservation is critical without style transfer (consider Spherical Harmonics NeRF).

## Background
StylizedNeRF was introduced as a style-based 3D-aware generator for high-resolution image synthesis [S2, unofficial]. It builds on the NeRF++ architecture [S2, unofficial] and the StyleGAN2 framework [S2, unofficial]. The method addresses the limitations of previous neural rendering approaches that failed to learn geometry correctly or produced 3D inconsistent artifacts [S2, unofficial]. It utilizes a mutual learning strategy to optimize both the stylized NeRF and the 2D stylization network, ensuring consistency in geometry [S1].
