# Voxel-based Radiance Fields

Also called: Voxel NeRF, Voxel Radiance Fields

## Overview
Voxel-based Radiance Fields replace the multi-layer perceptron (MLP) of standard Neural Radiance Fields with discrete voxel grids to store volume density and spherical harmonic (SH) coefficients, enabling real-time differentiable volume rendering [S1]. Unlike MLP-based NeRF which requires heavy computation of fully-connected layers for every sample point, this method directly computes color from interpolated grid values, eliminating feed-forward operations [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of input images with known camera poses; 3D sample points $\mathbf{X}_k$ along rays; viewing directions $\mathbf{d}$.
*   **Outputs:** Rendered image color $\hat{C}(r)$ for each ray $r$.

**Data Structures:**
Two dense 3D voxel grids are maintained:
1.  **Density Grid ($G_\sigma$):** Maps $\mathbb{R}^3 \rightarrow \mathbb{R}$. Stores scalar volume density values.
2.  **SH Grid ($G_{sh}$):** Maps $\mathbb{R}^3 \rightarrow \mathbb{R}^{9 \times 3}$. Stores degree-2 spherical harmonic coefficients for RGB color. Each voxel contains 9 coefficients per color channel (27 values total).

**Numbered Steps:**
1.  **Grid Initialization:** Initialize $G_\sigma$ and $G_{sh}$ on a regular 3D grid covering the scene bounding box.
2.  **Ray Sampling:** For each pixel, cast a ray and sample $N$ points $\mathbf{X}_k$ along the ray segment between near and far planes.
3.  **Density Query:** For each sample point $\mathbf{X}_k$, retrieve density $\sigma_k$ by performing trilinear interpolation from the 8 nearest neighbors in $G_\sigma$ [S1].
4.  **SH Coefficient Query:** For each sample point $\mathbf{X}_k$, retrieve the vector of SH coefficients $\mathbf{v}_k$ by performing trilinear interpolation from the 8 nearest neighbors in $G_{sh}$ [S1].
5.  **Color Computation:** Compute the view-dependent color $\mathbf{c}_k$ using the SH coefficients and the viewing direction $\mathbf{d}$ [S1]:
    $$
    \mathbf{c}_k = S(\mathbf{d})^\intercal \cdot \mathbf{v}_k
    $$
    where $S(\mathbf{d}) : \mathbb{R}^3 \rightarrow \mathbb{R}^9$ is the basis function mapping the viewing direction to the SH basis vector [S1].
6.  **Volume Rendering:** Compute the final pixel color $\hat{C}(r)$ using the standard differentiable volume rendering equation [S1]:
    $$
    \hat{C}(r) = \sum_{k=1}^{N} w_k \mathbf{c}_k, \quad w_k = T_k \alpha_k, \quad T_k = \prod_{j=1}^{k-1} (1 - \alpha_j)
    $$
    where opacity $\alpha_k = 1 - e^{-\sigma_k \delta_k}$ and $\delta_k$ is the distance between sample points [S1].

**Formulas:**
*   Density: $\sigma_k = \mathcal{G}_\sigma(\mathbf{X}_k)$ [S1]
*   Color: $\mathbf{c}_k = S(\mathbf{d})^\intercal \cdot \mathcal{G}_{sh}(\mathbf{X}_k)$ [S1]
*   $\mathcal{G}_\sigma$ and $\mathcal{G}_{sh}$ denote trilinear interpolation from the nearest 8 voxels [S1].

**Parameters:**
*   **SH Degree:** Degree 2 is used, resulting in 9 coefficients per channel [S1].
*   **Grid Resolution:** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Boundary Handling:** Trilinear interpolation requires valid neighbors. Points outside the grid bounds must be handled (e.g., clamping or treating as empty) [G].
*   **Precision:** Floating-point precision in interpolation may affect gradient stability during training [G].

**Pseudocode:**
```python
def render_ray(ray_origin, ray_direction, grid_sigma, grid_sh, near, far, num_samples):
    """
    Renders a single ray using voxel-based radiance fields.
    
    Args:
        ray_origin: (3,) array, camera origin.
        ray_direction: (3,) array, normalized ray direction.
        grid_sigma: 3D array of shape (D, D, D), density grid.
        grid_sh: 3D array of shape (D, D, D, 27), SH coefficient grid.
        near: float, near plane distance.
        far: float, far plane distance.
        num_samples: int, number of sample points per ray.
        
    Returns:
        color: (3,) array, rendered RGB color.
    """
    # Sample points along the ray
    t = np.linspace(near, far, num_samples)
    points = ray_origin + ray_direction * t[:, np.newaxis]
    
    # Initialize accumulation variables
    accumulated_alpha = 0.0
    accumulated_color = np.zeros(3)
    
    # Precompute SH basis for the viewing direction
    # S(d) maps direction to R^9 vector
    sh_basis = compute_sh_basis(ray_direction) # Returns (9,) array
    
    for i in range(num_samples):
        x_k = points[i]
        
        # 1. Query density via trilinear interpolation
        sigma_k = trilinear_interpolate(grid_sigma, x_k)
        
        # 2. Query SH coefficients via trilinear interpolation
        # grid_sh stores 27 values (9 coeffs * 3 channels) per voxel
        sh_coeffs_k = trilinear_interpolate(grid_sh, x_k) # Returns (27,) array
        
        # 3. Compute color
        # Reshape sh_coeffs_k to (3, 9) to separate channels
        sh_coeffs_k = sh_coeffs_k.reshape(3, 9)
        
        # Color for each channel: dot product of SH basis and coefficients
        # c_k = S(d)^T . v_k
        color_k = np.dot(sh_basis, sh_coeffs_k.T) # Shape (3,)
        
        # 4. Compute opacity
        # Assume uniform step size delta for simplicity, or compute from t[i] - t[i-1]
        delta = (far - near) / num_samples
        alpha_k = 1.0 - np.exp(-sigma_k * delta)
        
        # 5. Accumulate
        weight = (1.0 - accumulated_alpha) * alpha_k
        accumulated_color += weight * color_k
        accumulated_alpha += weight
        
        # Early termination if fully opaque
        if accumulated_alpha > 0.99:
            break
            
    return accumulated_color

def compute_sh_basis(direction):
    """
    Computes the degree-2 spherical harmonic basis vector for a given direction.
    Returns a (9,) array.
    """
    x, y, z = direction
    # Degree 0
    c0 = 1.0 / np.sqrt(4 * np.pi)
    
    # Degree 1
    c1 = np.sqrt(3.0 / (4 * np.pi)) * y
    c2 = np.sqrt(3.0 / (4 * np.pi)) * z
    c3 = np.sqrt(3.0 / (4 * np.pi)) * x
    
    # Degree 2
    c4 = np.sqrt(15.0 / (4 * np.pi)) * y * z
    c5 = np.sqrt(15.0 / (4 * np.pi)) * z * x
    c6 = np.sqrt(15.0 / (4 * np.pi)) * (2 * z**2 - x**2 - y**2)
    c7 = np.sqrt(15.0 / (4 * np.pi)) * x * y
    c8 = np.sqrt(15.0 / (4 * np.pi)) * (x**2 - y**2)
    
    return np.array([c0, c1, c2, c3, c4, c5, c6, c7, c8])

def trilinear_interpolate(grid, point):
    """
    Performs trilinear interpolation on a 3D grid.
    Assumes grid is defined on [0, 1]^3.
    """
    # Normalize point to grid coordinates [0, D-1]
    # This assumes the grid covers the unit cube. 
    # In practice, a transformation matrix maps world coords to grid indices.
    # For this self-contained example, we assume point is already in grid indices.
    
    # Get integer coordinates
    ix, iy, iz = np.floor(point).astype(int)
    # Get fractional coordinates
    fx, fy, fz = point - np.floor(point)
    
    # Clamp indices to grid bounds
    ix = np.clip(ix, 0, grid.shape[0] - 2)
    iy = np.clip(iy, 0, grid.shape[1] - 2)
    iz = np.clip(iz, 0, grid.shape[2] - 2)
    
    # Get 8 neighbors
    v000 = grid[ix, iy, iz]
    v100 = grid[ix+1, iy, iz]
    v010 = grid[ix, iy+1, iz]
    v110 = grid[ix+1, iy+1, iz]
    v001 = grid[ix, iy, iz+1]
    v101 = grid[ix+1, iy, iz+1]
    v011 = grid[ix, iy+1, iz+1]
    v111 = grid[ix+1, iy+1, iz+1]
    
    # Interpolate x
    v00 = v000 * (1-fx) + v100 * fx
    v01 = v010 * (1-fx) + v110 * fx
    v10 = v001 * (1-fx) + v101 * fx
    v11 = v011 * (1-fx) + v111 * fx
    
    # Interpolate y
    v0 = v00 * (1-fy) + v01 * fy
    v1 = v10 * (1-fy) + v11 * fy
    
    # Interpolate z
    result = v0 * (1-fz) + v1 * fz
    
    return result
```

## Operating characteristics
*   **Time Complexity:** Rendering is faster than MLP-based NeRF because it eliminates the forward pass through fully-connected layers. Color is computed directly from interpolated grid values [S1].
*   **Memory Complexity:** Memory usage is proportional to the grid resolution cubed ($D^3$) times the feature size (27 values per voxel for SH + 1 for density). It is more memory-efficient than storing large MLP weights for high-resolution scenes but less efficient than sparse representations [S1].
*   **Measured Performance:** Enables real-time volume rendering [S1].
*   **Strengths:** Real-time rendering capability; memory-efficient framework limiting learnable parameters to grid values [S1].
*   **Limitations:** Fixed resolution limits detail; aliasing artifacts may occur if grid resolution is insufficient; memory usage grows cubically with resolution [G].
*   **When to use:** When real-time rendering is required and scene complexity allows for a fixed-resolution grid representation [S1].
*   **When not to use:** For scenes requiring infinite detail or highly dynamic geometry where fixed grids are inadequate [G].

## Background
Voxel-based Radiance Fields were introduced as a memory-efficient alternative to MLP-based NeRF, replacing the network with voxel grids for volume density and spherical harmonic coefficients [S1]. The approach leverages differentiable volume rendering while eliminating feed-forward operations to achieve real-time performance [S1]. It has been applied to optimization tasks such as blurred view reconstruction [S1].
