# Vox-Surf

Also called: Voxel-based Implicit Surface Representation

## Overview
Vox-Surf is a voxel-based neural implicit surface representation that combines explicit sparse voxel structures with neural implicit surface representations to enable efficient surface reconstruction and realistic rendering from multi-view posed images [S1]. It differs from traditional voxel-based methods by storing only trainable embeddings at voxel corners rather than explicit SDF or color values, and from dense neural implicit methods by restricting learning to occupied space via a sparse hierarchical octree, thereby reducing sampling in empty areas [S1].

## How it works
**Inputs:** A set of multi-view posed images, camera poses, and an approximate bounding volume of the scene. Optional depth sensor data may be provided.
**Outputs:** A sparse octree of voxels with trainable corner embeddings, a geometry extractor network, and an appearance extractor network. The system renders images and extracts surfaces.

**Data Structures:**
*   **Voxel Grid:** The scene is divided into a set of coarse voxels $V = \{V_1, ..., V_k\}$ forming the leaf nodes of a sparse hierarchical octree [S1].
*   **Embeddings:** Each voxel has eight corner vertices. Each vertex stores a fixed-length optimizable embedding vector $e \in \mathbb{R}^{L_e}$ containing encoded geometry and appearance information [S1]. Adjacent voxels share 4 vertices and their corresponding embeddings [S1].
*   **Geometry Extractor ($F_\sigma$):** An MLP mapping $F_\sigma: \mathbb{R}^{L_e} \rightarrow \mathbb{R}^{1+L_f}$. It takes an embedding $e$ and outputs a signed distance value $\sigma \in \mathbb{R}$ (the first element, index `[0]`) and a geometry feature vector $f \in \mathbb{R}^{L_f}$ (the remaining elements, index `[1:]`) [S1].
*   **Appearance Extractor ($F_c$):** An MLP that takes concatenated inputs to output color [S1].

**Retrieval Function:**
For any 3D point $p$ within a voxel $V_i$, its embedding $e$ is retrieved via $\Gamma: \mathbb{R}^3 \rightarrow \mathbb{R}^{L_e}$. This function performs trilinear interpolation of the embeddings from the eight voxel corners based on their coordinates [S1].

**Algorithm Steps:**

1.  **Voxel Initialization:**
    *   Divide the bounding area into uniformly spaced coarse voxels [S1].
    *   Build a sparse hierarchical octree using these voxels as leaf nodes [S1].
    *   Assign each vertex a random initial embedding $e \in \mathbb{R}^{L_e}$ [S1].

2.  **Ray Generation and Culling:**
    *   Generate rays $r=(o,d)$ from camera centers [S1].
    *   Perform an axis-aligned bounding box (AABB) intersection test between each ray and the octree [S1].
    *   Cull rays that do not intersect any voxels [S1].
    *   For remaining rays, calculate the distance $m_{V_i}$ inside each intersected voxel $V_i$ [S1].

3.  **Surface-Aware Sampling:**
    *   **Step 1 (Uniform Voxel Sampling):** Uniformly sample points $p$ on rays inside the intersected voxels [S1].
    *   **Step 2 (Cross-Surface Voxel Searching):** Compute the SDF for sampled points using $F_\sigma(\Gamma(p))$. Identify points $p_i, p_{i+1}$ where the SDF changes sign (positive to negative). Mark the voxels containing these points as "important voxels" [S1].
    *   **Step 3 (Resampling):** Increase the sampling probability in important voxels. Normalize probabilities along the ray. Resample rays with a fixed total point count. Two variants exist: 'full' (all important voxels) for unstable shapes, and 'first' (only the first important voxel) for fine details on stable shapes [S1].
    *   **Boundary Handling:** To prevent cross-voxel accumulation (where sampling spacing exceeds voxel boundaries due to interpolation independence), cut off intervals near voxel boundaries and recalculate sample points $t_i$ and $t_j$ [S1].

4.  **Geometry and Appearance Extraction:**
    *   For each sampling point $p$, retrieve embedding $e = \Gamma(p)$ [S1].
    *   Apply positional encoding to $e$ and the ray direction $d$ [S1].
    *   Compute SDF $\sigma$ and feature $f$: $[\sigma, f] = F_\sigma(e)$ [S1].
    *   Compute surface normal $n$ via automatic differentiation: $n = \frac{d F_\sigma(\Gamma(p))[0]}{dp}$ [S1].
    *   Compute color $c$: $c = F_c(\text{concat}(f, d, e))$ [S1].

5.  **Volume Rendering:**
    *   Compute the S-density function: $\phi_s(\sigma) = \frac{s e^{-s\sigma}}{(1 + e^{-s\sigma})^2}$, where $s$ is a scale parameter [S1].
    *   Compute discrete volume density weight:
        $$ \alpha(t_i) = \text{ReLU}\left( \frac{\Phi_s(F_\sigma(\Gamma(r(t_i)))[0]) - \Phi_s(F_\sigma(\Gamma(r(t_{i+1})))[0])}{\Phi_s(F_\sigma(\Gamma(r(t_i)))[0])} \right) $$
        where $\Phi_s(\sigma) = (1 + e^{-s\sigma})^{-1}$ [S1].
    *   Compute discrete accumulated transmittance:
        $$ T(t_i) = \prod_{j=1}^{i-1} (1 - \alpha(t_j)) $$
        [S1].
    *   Rendered color:
        $$ C(r) = \sum_i T(t_i) \alpha_i(t_i) c_i $$
        [S1].

6.  **Progressive Training (Pruning and Splitting):**
    *   **Voxel Pruning:** Uniformly sample $N_p$ points inside each voxel. Compute SDF values. If any point $p$ inside voxel $V_i$ has $|F_\sigma(\Gamma(p))[0]| < \tau$ (distance threshold $\tau$), keep the voxel ($K=1$); otherwise, prune it ($K=0$) [S1].
    *   **Voxel Splitting:** Periodically split existing voxels into 8 sub-voxels and insert them into the octree. Compute initial embeddings for new vertices using $\Gamma$. Optimize these embeddings independently of parent nodes [S1].

**Loss Functions:**
*   **Color Loss:** $L_{color} = \sum_r ||\hat{C}(r) - C(r)||_1$, where $\hat{C}(r)$ is the ground truth color [S1].
*   **Eikonal Loss:** $L_{eikonal} = \sum_i (||\nabla F_\sigma(\Gamma(p_i))[0]||_2 - 1)^2$, applied to sampled points $p_i$ to constrain the gradient magnitude of the SDF to 1 [S1].
*   **Depth Loss (if depth data available):**
    *   Occupancy function: $\text{occ}(t) = \text{Sigmoid}(-\text{scale} \cdot F_\sigma(\Gamma(r(t)))[0])$ [S1].
    *   $L_{outside} = \sum_{t < \hat{t} - \delta t} ||1 - \text{occ}(t)||_2^2$ [S1].
    *   $L_{near} = \sum_{\hat{t} - \delta t \le t \le \hat{t} + \delta t} ||F_\sigma(\Gamma(r(t)))[0]||_2^2$ [S1].
    *   $L_{inside} = \sum_{t > \hat{t} + \delta t} ||\text{occ}(t)||_2^2$ [S1].
    *   Total Depth Loss: $L_{depth} = L_{outside} + L_{near} + L_{inside}$ [S1].
    *   $\delta t$ is a small noise tolerance depth range depending on sensor confidence [S1].

**Parameters:**
*   $L_e$: Embedding dimension. Not given in the sources.
*   $L_f$: Feature vector dimension. Not given in the sources.
*   $s$: Scale parameter for S-density. Not given in the sources.
*   $\tau$: Distance threshold for voxel pruning. Not given in the sources.
*   $\delta t$: Noise tolerance for depth loss intervals. Depends on depth sensor confidence [S1].

**Edge Cases and Pitfalls:**
*   **Cross-voxel Accumulation:** Because voxels are independent due to the interpolation mechanism, sampling spacing cannot exceed the voxel boundary. If it does, cross-voxel accumulation occurs. This is mitigated by cutting off intervals near voxel boundaries and recalculating sample points [S1].
*   **Surface Missing:** Voxel pruning in the early stages can cause surface missing. This can be alleviated by increasing sampling density in the early stage [S1].

## Operating characteristics
*   **Memory Efficiency:** By using a sparse hierarchical octree and pruning empty voxels, Vox-Surf reduces memory consumption compared to dense neural implicit methods [S1].
*   **Rendering Speed:** The method performs well in rendering speed, approaching real-time at low resolutions, and is faster than previous methods [S1].
*   **Reconstruction Quality:** It can learn fine surface details and accurate colors [S1].
*   **Scalability:** Suitable for almost any scene, including large-scale scenes like street views, due to its sparse representation [S1].
*   **Applications:** The resulting fine voxels can be used as bounding volumes for collision detection in 3D interactions (grabbing, collision) and for scene editing [S1].

## Background
Vox-Surf was proposed as a voxel-based neural implicit surface representation and reconstruction framework [S1]. It combines voxel-based representation with image-based surface reconstruction for efficient surface reconstruction and realistic rendering [S1]. The method addresses the limitations of traditional voxel-based implicit surfaces (which store explicit SDF, weight, and color in tiny voxels) and dense neural implicit surface methods (which define the entire space in a single network) by storing only trainable embeddings in voxel vertices and dividing the scene into multiple bounded voxels [S1]. The source code is publicly available at https://github.com/zju3dv/Vox-Surf [S1].
