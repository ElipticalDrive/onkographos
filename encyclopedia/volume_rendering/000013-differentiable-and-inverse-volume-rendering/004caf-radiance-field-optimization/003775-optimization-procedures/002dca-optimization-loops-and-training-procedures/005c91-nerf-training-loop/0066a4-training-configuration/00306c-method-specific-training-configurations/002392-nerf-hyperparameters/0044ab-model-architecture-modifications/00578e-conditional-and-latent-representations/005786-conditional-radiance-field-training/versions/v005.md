# Conditional Radiance Field Training

Also called: Conditional NeRF, Instance-conditioned NeRF

## Overview
Conditional Radiance Field Training extends the standard NeRF baseline [Parent](15989-conditional-and-latent-representations.md) by learning instance-specific latent codes for shape and appearance, allowing a single network to model multiple distinct 3D objects. It solves the problem of efficiently representing a dataset of varying instances without training separate models for each, achieving reconstruction accuracy comparable to independent per-instance NeRFs while sharing a unified network architecture.

## How it works
**Inputs and Outputs:**
*   **Inputs:** A dataset of $K$ instances. For each instance $k$, a set of training rays $R_k$ with ground truth colors $C(r)$.
*   **Outputs:** A conditional radiance field model (two MLPs: coarse and fine) and learned latent codes $\mathbf{z}_k^{(s)}$ (shape) and $\mathbf{z}_k^{(c)}$ (color) for each instance $k$.

**Data Structures:**
*   **Latent Codes:** Two vectors per instance $k$: $\mathbf{z}_k^{(s)} \in \mathbb{R}^{32}$ and $\mathbf{z}_k^{(c)} \in \mathbb{R}^{32}$ [S1]. These are learnable parameters optimized alongside network weights.
*   **Network Architecture:** Two Multi-Layer Perceptrons (MLPs), $F_{coarse}$ and $F_{fine}$, each 4 layers deep with 256 channels per layer [S1]. Both use ReLU activations. Skip connections are used, embedding the shape code and input position/direction into intermediate layers [S1].
*   **Ray Sampling:** Stratified sampling is used for the coarse network. Hierarchical sampling is used for the fine network, conditioned on the density output of the coarse network [S1].

**Numbered Steps:**
1.  **Initialization:** Initialize the coarse network $F_{coarse}$, fine network $F_{fine}$, and latent codes $\mathbf{z}_k^{(s)}, \mathbf{z}_k^{(c)}$ for all $k \in \{1, \dots, K\}$.
2.  **Instance Sampling:** During each training iteration, sample an object instance $k$ uniformly from $\{1, \dots, K\}$ [S1].
3.  **Ray Sampling:** Sample a batch of training rays from the set $R_k$ belonging to instance $k$ [S1].
4.  **Coarse Rendering:** For each ray $r$, use stratified sampling to generate points. Compute density and color using $F_{coarse}(\mathbf{x}, \mathbf{d}, \mathbf{z}_k^{(s)}, \mathbf{z}_k^{(c)})$. Render color $\hat{C}_{coarse}(r, \mathbf{z}_k^{(s)}, \mathbf{z}_k^{(c)})$ using volume rendering [S1].
5.  **Fine Rendering:** Use the density output from $F_{coarse}$ to sample points hierarchically for the fine network. Compute density and color using $F_{fine}(\mathbf{x}, \mathbf{d}, \mathbf{z}_k^{(s)}, \mathbf{z}_k^{(c)})$. Render color $\hat{C}_{fine}(r, \mathbf{z}_k^{(s)}, \mathbf{z}_k^{(c)})$ [S1].
6.  **Loss Calculation:** Compute the photometric loss for the batch [S1]:
    $$
    L_{train} = \sum_{k=1}^{K} \sum_{r \in R_k} \left( \|\hat{C}_{coarse}(r, \mathbf{z}_k^{(s)}, \mathbf{z}_k^{(c)}) - C(r)\|_2^2 + \|\hat{C}_{fine}(r, \mathbf{z}_k^{(s)}, \mathbf{z}_k^{(c)}) - C(r)\|_2^2 \right)
    $$
7.  **Optimization:** Update network weights and latent codes using the Adam optimizer [S1].

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $10^{-4}$ for training [S1].
*   **Beta1:** 0.9 [S1].
*   **Beta2:** 0.999 [S1].
*   **Epsilon:** $10^{-8}$ [S1].
*   **Training Duration:** Until convergence, averaging 1 million iterations [S1].
*   **Code Dimension:** 32 dimensions for both shape and color codes [S1].

**Edge Cases and Pitfalls:**
*   **Parameter Count:** In ablation studies, layer widths were increased to keep the number of parameters approximately equal across experiments, ensuring fair comparison [S1].
*   **Editing vs. Training:** During editing (not training), the coarse network is kept fixed, and only the fine network and codes are optimized with a higher learning rate ($10^{-2}$) for 100 iterations [S1].

**Pseudocode:**

```python
import numpy as np

def train_conditional_nerf(instances, rays_per_instance, num_iterations=1000000):
    """
    Train a conditional radiance field on K instances.
    
    Args:
        instances: List of K instance objects. Each has a method get_rays(batch_size).
        rays_per_instance: Number of rays to sample per instance per iteration.
        num_iterations: Total training steps.
        
    Returns:
        F_coarse, F_fine: Trained network functions.
        z_s, z_c: Learned latent codes for shape and color.
    """
    K = len(instances)
    
    # Initialize networks (4 layers, 256 channels, ReLU, skip connections)
    # F_coarse and F_fine take (x, d, z_s, z_c) -> (sigma, c)
    F_coarse = initialize_mlp(depth=4, width=256)
    F_fine = initialize_mlp(depth=4, width=256)
    
    # Initialize latent codes: 32-dim vectors for each instance
    z_s = np.random.randn(K, 32)
    z_c = np.random.randn(K, 32)
    
    # Adam optimizer state for weights and codes
    optimizer = AdamOptimizer(lr=1e-4, beta1=0.9, beta2=0.999, eps=1e-8)
    optimizer.add_parameters(F_coarse.weights)
    optimizer.add_parameters(F_fine.weights)
    optimizer.add_parameters(z_s)
    optimizer.add_parameters(z_c)
    
    for iteration in range(num_iterations):
        # 1. Sample instance k
        k = np.random.randint(0, K)
        
        # 2. Get latent codes for instance k
        zk_s = z_s[k]
        zk_c = z_c[k]
        
        # 3. Sample batch of rays for instance k
        rays = instances[k].get_rays(rays_per_instance)
        ground_truth_colors = rays.colors # Shape: (batch_size, 3)
        
        # 4. Coarse Rendering
        # Stratified sampling for points along rays
        coarse_points = stratified_sample(rays, num_samples=64)
        coarse_sigma, coarse_color = F_coarse(coarse_points.x, coarse_points.d, zk_s, zk_c)
        coarse_rendered_color = volume_render(coarse_points, coarse_sigma, coarse_color)
        
        # 5. Fine Rendering
        # Hierarchical sampling based on coarse density
        fine_points = hierarchical_sample(rays, coarse_sigma, num_samples=48)
        fine_sigma, fine_color = F_fine(fine_points.x, fine_points.d, zk_s, zk_c)
        fine_rendered_color = volume_render(fine_points, fine_sigma, fine_color)
        
        # 6. Compute Loss
        # L_train = sum(||C_hat_coarse - C||^2 + ||C_hat_fine - C||^2)
        loss_coarse = np.mean((coarse_rendered_color - ground_truth_colors) ** 2)
        loss_fine = np.mean((fine_rendered_color - ground_truth_colors) ** 2)
        loss = loss_coarse + loss_fine
        
        # 7. Backpropagate and Update
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
    return F_coarse, F_fine, z_s, z_c

def volume_render(points, sigma, color):
    """
    Standard volume rendering with alpha compositing.
    points: (N, 3) coordinates
    sigma: (N,) density
    color: (N, 3) radiance
    """
    # Calculate distances between adjacent samples
    # Assuming points are sorted along the ray
    delta = np.diff(points, axis=0)
    delta = np.append(delta, np.zeros((1, 3)), axis=0) # Handle last point
    dists = np.linalg.norm(delta, axis=1)
    
    # Alpha compositing
    alpha = 1.0 - np.exp(-sigma * dists)
    weights = alpha * np.cumprod(np.exp(-np.concatenate(([0], sigma[:-1] * dists[:-1]))))
    # Note: The cumulative product term in the exponent is sum_{j=1}^{i-1} sigma_j * delta_j
    # Simplified implementation for vectorized rendering:
    T = np.exp(-np.cumsum(np.concatenate(([0], sigma[:-1] * dists[:-1]))))
    A = alpha * T
    rendered_color = np.sum(A[:, np.newaxis] * color, axis=0)
    
    return rendered_color
```

## Operating characteristics
*   **Time Complexity:** Training requires approximately 1 million iterations [S1]. Each iteration involves forward passes through two networks and sampling.
*   **Memory Complexity:** Memory usage scales with the number of instances $K$ due to the storage of latent codes $\mathbf{z}_k^{(s)}$ and $\mathbf{z}_k^{(c)}$ ($2 \times 32 \times K$ floats) plus the network weights.
*   **Performance:** On the PhotoShapes dataset, the method matches the performance of training independent NeRF models for each instance [S1]. It scales well to large datasets, such as the 626 instances in PhotoShapes [S1].
*   **Strengths:** Efficiently models shape and appearance differences across instances; avoids training separate models; generalizes to unseen views.
*   **Limitations:** Requires joint optimization of codes and network weights; performance depends on the quality of the latent code initialization and optimization.

## Background
The method was introduced in "Editing Conditional Radiance Fields" [S1]. It builds on the original NeRF paper [S1] and extends it by incorporating instance-specific latent codes. The method was evaluated on the PhotoShapes and Aubry chairs datasets [S1]. It is used for tasks such as 3D reconstruction, view synthesis, and editing of 3D instances [S1].
