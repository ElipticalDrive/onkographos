# Frequency-Modulated Point Cloud Rendering

Also called: AFNet, Adaptive Frequency Net, Adaptive Frequency Net (AFNet) based rendering, FreqPCR, Frequency-Modulated Radiance Mapping

## Overview
Frequency-Modulated Point Cloud Rendering (also known as AFNet) is a point cloud-based rendering pipeline that uses an Adaptive Frequency Net to modulate implicit radiance signals with local texture frequency encoding, enabling high-fidelity local detail reconstruction, real-time rendering, and user-friendly editing [S1]. It addresses the spectral bias of standard MLPs, which favor low-frequency signals, by predicting local frequency and phase parameters for each point to adaptively modulate the radiance signal, allowing the network to handle varying texture frequencies (high for textured regions, low for smooth regions) [S1]. Unlike sibling methods that rely on global frequency encoding or fixed activation functions, AFNet dynamically adjusts the frequency basis support per point, resulting in sharper textures and significantly faster rendering speeds (1700× faster than NeRF, 37× faster than CCNeRF) [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D points $\mathcal{P} = \{\mathbf{p}_i\}_{i=1}^M$ with initial attributes (position, color, opacity). Camera parameters (view and projection matrices).
*   **Output:** Rendered 2D image $C(\mathbf{p})$ for a given camera view.

**Data Structures:**
*   **Point Cloud:** Each point $i$ stores position $\mathbf{p}_i \in \mathbb{R}^3$, color $\mathbf{c}_i \in \mathbb{R}^3$, and opacity $\alpha_i \in [0, 1]$.
*   **Feature Tensor:** For the $i$-th layer of the network, input feature $\mathbf{X}^{(i)} \in \mathbb{R}^{M \times C}$, where $M$ is the number of points and $C$ is the feature dimension [S1].
*   **Frequency Parameters:** Predicted adaptive frequencies $\omega^{(i)} \in \mathbb{R}^{M \times 1}$ and phases $\phi^{(i)} \in \mathbb{R}^{M \times 1}$ for each point at each layer [S1].

**Numbered Steps:**

1.  **Point Cloud Geometry Optimization (Preprocessing):**
    *   Use volume rendering to optimize point cloud geometry.
    *   Keep multiple points in the pixel buffer per ray (instead of just the closest point) to allow for opacity learning [S1].
    *   Learn the opacity $\alpha_i$ of each point based on volume rendering. This step improves rendering PSNR by 2-4dB for poorly reconstructed scenes and avoids artifacts [S1].
    *   *Note:* This step is performed before the main radiance mapping optimization.

2.  **Radiance Mapping with AFNet:**
    *   For each point $\mathbf{p}_i$, query the AFNet to predict color and features.
    *   The AFNet consists of a hypernetwork and adaptive frequency activation layers.
    *   **Hypernetwork:** A two-layer MLP takes the spatial coordinates (or intermediate features) as input and predicts the adaptive frequency $\omega^{(i)}$ and phase $\phi^{(i)}$ for each point [S1].
    *   **Adaptive Frequency Activation Layer (AF Layer):**
        *   Compute the sinusoidal filter output: $\sin(\omega^{(i)} \circ \mathbf{X}^{(i)} + \phi^{(i)})$ [S1].
        *   Compute the Hadamard (element-wise) product between the filtered feature and the input feature $\mathbf{X}^{(i)}$ to produce the output $\mathbf{Y}^{(i)}$:
            $$
            \mathbf{Y}^{(i)} = \mathbf{X}^{(i)} \circ \sin(\omega^{(i)} \circ \mathbf{X}^{(i)} + \phi^{(i)})
            $$
            where $\circ$ denotes the Hadamard product [S1].
        *   The dimensions of $\omega^{(i)}$ and $\phi^{(i)}$ ($M \times 1$) are broadcast to $M \times C$ during computation [S1].
    *   The final RGB color is obtained after the last AF layer and a linear projection [S1].

3.  **Differentiable Rendering:**
    *   Project the optimized point cloud to 2D screen space.
    *   Sort points by depth for each pixel.
    *   Compute pixel color using alpha compositing:
        $$
        C(\mathbf{p}) = \sum_{i \in \mathcal{N}} \mathbf{c}_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j)
        $$
        where $\mathcal{N}$ is the set of primitives contributing to pixel $\mathbf{p}$ [S1].

4.  **Object Editing (Optional):**
    *   Edit the point cloud directly (e.g., move, scale, or delete points).
    *   The deformation field between the original and deformed 3D space is obtained by querying the corresponding transformations performed on the point cloud [S1].
    *   Re-render the edited point cloud.

5.  **Scene Composition (Optional):**
    *   Combine multiple scenes at the pixel level.
    *   Use a masking strategy based on the depth buffer to avoid cross-scene training and ensure correct occlusion [S1].

import torch
import torch.nn as nn
import torch.nn.functional as F

class AFNet(nn.Module):
    """
    Adaptive Frequency Net for point cloud radiance mapping.
    """
    def __init__(self, input_dim, hidden_dim, output_dim, num_layers, num_points):
        super(AFNet, self).__init__()
        self.num_layers = num_layers
        self.num_points = num_points
        
        # Hypernetwork: Two-layer MLP to predict omega and phi
        # Input: spatial coordinates or previous layer features
        # Output: omega (Mx1) and phi (Mx1)
        self.hypernet = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 2) # Outputs [omega, phi] per point
        )
        
        # Main network layers with AF activation
        self.layers = nn.ModuleList()
        for i in range(num_layers):
            in_ch = input_dim if i == 0 else hidden_dim
            out_ch = hidden_dim if i < num_layers - 1 else output_dim
            self.layers.append(nn.Linear(in_ch, out_ch))
            
    def af_layer(self, x, omega, phi):
        """
        Adaptive Frequency Activation Layer.
        Y = X * sin(omega * X + phi)
        """
        # x: (M, C)
        # omega: (M, 1) -> broadcast to (M, C)
        # phi: (M, 1) -> broadcast to (M, C)
        sin_val = torch.sin(omega * x + phi)
        y = x * sin_val
        return y

    def forward(self, x):
        """
        x: (M, input_dim)
        Returns: (M, output_dim)
        """
        M, C = x.shape
        
        for i, layer in enumerate(self.layers):
            # Predict omega and phi using hypernetwork
            # hypernet input is x (or intermediate features)
            hp = self.hypernet(x)
            omega = hp[:, 0].unsqueeze(1) # (M, 1)
            phi = hp[:, 1].unsqueeze(1)   # (M, 1)
            
            # Apply linear transformation
            x = layer(x)
            
            # Apply AF activation
            if i < self.num_layers - 1:
                x = self.af_layer(x, omega, phi)
            else:
                # Last layer: no AF activation, just linear (or ReLU if specified)
                # Based on Fig 3, last layer is Linear -> final RGB
                pass
                
        return x

        """

        Returns: screen_coords (M, 2), depths (M,), valid_mask (M,)
        """
        # Homogeneous coordinates
        points_h = torch.cat([points_3d, torch.ones_like(points_3d[:, :1])], dim=1) # (M, 4)
        
        # View transform
        points_view = torch.matmul(points_h, view_matrix.T) # (M, 4)
        
        # Project transform
        points_proj = torch.matmul(points_view, proj_matrix.T) # (M, 4)
        
        # Perspective division
        x = points_proj[:, 0] / points_proj[:, 3]
        y = points_proj[:, 1] / points_proj[:, 3]
        z = points_proj[:, 2] / points_proj[:, 3]
        
        # Normalize to [0, 1] or [-1, 1] depending on convention
        # Assuming OpenGL convention: x, y in [-1, 1], z in [0, 1]
        screen_x = (x + 1) * 0.5 * self.width
        screen_y = (1 - y) * 0.5 * self.height # Flip y for image coordinates
        
        valid_mask = (points_proj[:, 3] > 0) & (screen_x >= 0) & (screen_x < self.width) & (screen_y >= 0) & (screen_y < self.height)
        
        return torch.stack([screen_x, screen_y], dim=1), z, valid_mask

**Parameters:**
*   **Hypernetwork:** Two-layer MLP [S1].
*   **AF Layer:** Sinusoidal activation function $\sin(\omega X + \phi)$ followed by element-wise multiplication with input $X$ [S1].
*   **Rendering Speed:** 39.27 FPS on NeRF-Synthetic dataset [S1].

**Edge Cases and Pitfalls:**
*   **Spectral Bias:** Standard MLPs with ReLU have strong spectral bias towards low-frequency signals, limiting high-frequency reconstruction in point cloud rendering [S1]. AFNet mitigates this by adapting frequencies locally.
*   **Geometry Optimization:** Previous surface point-based works could not optimize point cloud geometry because they kept only the closest point as surface estimation for each ray. AFNet uses volume rendering to keep more points and learn opacity, avoiding this issue [S1].
*   **Cross-Scene Training:** When composing multiple scenes, a masking strategy based on the depth buffer is required to avoid cross-scene training artifacts [S1].

## Background
Frequency-Modulated Point Cloud Rendering (AFNet) was proposed by Zhang et al. in 2023 [S1]. It is motivated by the observation that standard MLPs suffer from spectral bias towards low-frequency signals, which limits their ability to reconstruct high-frequency textures in 3D scenes [S1]. The method introduces an Adaptive Frequency Net (AFNet) that uses a hypernetwork to predict local frequency and phase parameters for each point, allowing the network to adaptively modulate the radiance signal based on local texture complexity [S1]. The method was evaluated on NeRF-Synthetic, ScanNet, DTU, and Tanks and Temples datasets, demonstrating superior performance in terms of rendering speed and editing capabilities compared to NeRF and CCNeRF [S1].
