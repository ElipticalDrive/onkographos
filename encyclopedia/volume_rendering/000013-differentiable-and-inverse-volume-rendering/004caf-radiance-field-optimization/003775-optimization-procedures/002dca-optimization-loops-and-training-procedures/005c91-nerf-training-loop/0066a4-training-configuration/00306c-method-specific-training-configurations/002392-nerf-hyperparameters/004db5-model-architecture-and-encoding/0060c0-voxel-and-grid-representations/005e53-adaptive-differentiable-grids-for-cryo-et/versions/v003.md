# Adaptive Differentiable Grids for Cryo-ET

Also called: Adaptive density grid optimization, Adaptive density grids based on an octree structure, Adaptive differentiable grids, Coordinate-based representation with adaptive octree

## Overview
Adaptive Differentiable Grids (ADG) is a learning-based representation for cryo-electron tomography (cryo-ET) reconstruction that replaces the fully connected MLPs of traditional neural fields with an adaptive octree structure where each node stores an optimizable 3D density grid [S1]. It solves the challenge of reconstructing high-noise, low-signal-to-noise ratio (SNR) cryo-ET data by combining a differentiable image formation model with regularization terms (Total Variation, boundary consistency, and cross-nodes non-local constraints) to jointly reconstruct and denoise the volume [S1]. Unlike standard neural fields which either learn noise or oversmooth features, ADG uses trilinear interpolation for faster querying and an octree structure to prioritize regions with detailed features while denoising uniform regions [S1].

## How it works

### Inputs and Outputs
*   **Inputs:**
    *   A set of 2D projection images $b$ from a tilt series [S1].
    *   The corresponding projection operator $A$ (Radon transform) for each ray [S1].
    *   A binary mask $M$ excluding rays intersecting fiducial markers or padded gray regions [S1].
    *   A Region of Interest (ROI) defining the volume bounds [S1].
*   **Outputs:**
    *   An optimized octree structure where each enabled node contains a 3D density grid [S1].
    *   A continuous 3D density field reconstructed by querying the density grids at desired voxel positions within the ROI [S1].

### Data Structures

**Octree Node:**
Each node in the octree represents a sub-volume of the ROI.
*   **Status:** `enabled` or `disabled`. Disabled nodes (outside ROI or empty) are skipped during optimization [S1].
*   **Density Grid ($G$):** A 3D tensor of shape $\mathbb{R}^{N_x \times N_y \times N_z}$ storing the volume density values $\sigma$ [S1]. In the source, $N_x = N_y = N_z$ is a fixed hyperparameter for all nodes [S1].
*   **Geometry:** Implicitly defined by the octree hierarchy and the global ROI bounds.

**Global State:**
*   **Octree:** A hierarchical structure of nodes.
*   **Hyperparameters:**
    *   $N_x, N_y, N_z$: Grid dimensions per node.
    *   $N_{max}$: Maximum number of samples per node for ray sampling [S1].
    *   $k_{tv}, k_{cnlc}, k_{bc}$: Weighting parameters for Total Variation, Cross-Nodes Non-Local Constraint, and Boundary Consistency losses respectively [S1].
    *   $N_{nodes}^{limit}$: Fixed limit on the total number of active octree nodes [S1].

### Query Mechanism
For a query point $p \in \mathbb{R}^3$, the density $f_\phi(p)$ is retrieved as follows:
1.  Identify the leaf octree node $oc$ that contains $p$ [S1].
2.  Retrieve the density grid $G_{oc}$ associated with node $oc$ [S1].
3.  Perform trilinear interpolation on $G_{oc}$ using the local coordinates of $p$ within the node's bounding box [S1].

$$ f_\phi(p) = \text{trilinear\_interp}(p, G_{oc}) $$

This operation is differentiable, allowing gradients to flow back to the grid values [S1].

### Optimization Procedure

The optimization is performed in two phases: **Octree Structure Update** and **Density Grid Optimization** [S1].

#### Phase 1: Octree Structure Update (Coarse-to-Fine)
This phase uses down-sampled projections to determine the optimal octree topology [S1].

1.  **Initialization:** Initialize the octree from the ROI. Disable all nodes outside the ROI [S1].
2.  **Iteration:**
    a.  **Ray Sampling:** For each ray in the down-sampled projections, determine the intersection with the current octree. For each octree node $oc$ crossed by the ray, select $N_{oc}$ 3D positions using stratified random sampling [S1]:
        $$ N_{oc} = N_{max} \left\lfloor \frac{loc}{doc} \right\rfloor $$
        where $loc$ is the length of the ray segment inside node $oc$, and $doc$ is the diagonal length of node $oc$ [S1].
    b.  **Density Query:** Sample densities $f_\phi(p)$ at these positions using trilinear interpolation [S1].
    c.  **Loss Computation:** Compute the data-fidelity loss $L_{data}$ (defined below) [S1].
    d.  **Update Loss Calculation:** Uniformly sample each octant (node) and compute the standard deviation (SD) of the densities inside each enabled node [S1].
    e.  **Mixed-Integer Program:** Solve a mixed-integer program to decide the fate of each node: divide into eight child octants, merge with siblings, or keep as is. The decision is based on the SD (high SD implies detailed features, favoring division) and the constraint that the total number of nodes must remain below $N_{nodes}^{limit}$ [S1].
    f.  **Update:** Apply the structural changes to the octree [S1].

#### Phase 2: Density Grid Optimization (Fine)
This phase freezes the octree structure and optimizes the values within the density grids using the original noisy projections [S1].

1.  **Freeze Structure:** Disable further octree updates [S1].
2.  **Iteration:**
    a.  **Ray Sampling:** For each ray in the original projections, sample 3D positions using the same stratified strategy as Phase 1, based on the fixed octree structure [S1].
    b.  **Density Query:** Query densities $f_\phi(p)$ via trilinear interpolation [S1].
    c.  **Loss Computation:** Compute the total loss $L_{total}$ (defined below) [S1].
    d.  **Gradient Descent:** Update the values in all enabled density grids $G$ using gradient descent [S1].

### Loss Function

The total loss is a weighted sum of the data-fidelity term and three regularization terms [S1]:

$$ L_{total} = L_{data} + k_{tv} L_{tv} + k_{cnlc} L_{cnlc} + k_{bc} L_{bc} $$

**1. Data-Fidelity Loss ($L_{data}$):**
Based on the discretized image formation model $b_i = A_i x_i + n_i$, where $b_i$ is measured intensity, $A_i$ is the Radon transform, and $x_i$ is the sampled density vector [S1]. The loss is defined over a batch of $N$ sampling points:

$$ L_{data}(\phi) = \frac{1}{N} \sum_{i=1}^{N} \| M (A f_\phi(p_i) - b_i) \|_2^2 $$

where $M$ is a binary mask excluding rays intersecting fiducial markers or padded borders [S1].

**2. Total Variation Loss ($L_{tv}$):**
A spatial regularizer to smooth the reconstruction and reduce noise [S1]. The source notes that applying TV to neural fields is non-trivial but is included in the loss [S1]. The exact formula is not provided in the text, but it is applied to the density grid values [S1].

**3. Cross-Nodes Non-Local Constraint Loss ($L_{cnlc}$):**
Designed to capture long-range dependencies and reduce noise by enforcing consistency between different parts of the volume. To avoid computational cost on large volumes, two enabled nodes $m$ and $n$ are randomly selected at each iteration [S1]. Densities $f_\phi(p_i^m)$ and $f_\phi(p_j^n)$ are sampled from their respective grids [S1]. The loss is:

$$ L_{cnlc} = \sum \| \text{softmax}(f_\phi(p_i^m)^T f_\phi(p_j^n)) f_\phi(p_j^n) - f_\phi(p_i^m) \|_2^2 $$

This estimates similarities between density vectors in different nodes [S1].

**4. Boundary Consistency Loss ($L_{bc}$):**
Addresses discontinuity artifacts at grid edges caused by independent optimization of neighboring octree nodes. It minimizes the density difference between neighboring grids at their shared boundaries [S1]. The exact formula is not provided, but it operates on the boundary voxels of adjacent nodes [S1].

def trilinear_interp(point, grid):
    """
    Performs trilinear interpolation on a 3D grid at a given point.
    point: (x, y, z) in local coordinates [0, 1] relative to grid bounds.
    grid: 3D numpy array of shape (Nx, Ny, Nz).
    Returns: scalar density value.
    """
    # Map point to grid indices
    ix = point[0] * (grid.shape[0] - 1)
    iy = point[1] * (grid.shape[1] - 1)
    iz = point[2] * (grid.shape[2] - 1)
    
    # Get corner indices
    x0, x1 = int(np.floor(ix)), int(np.ceil(ix))
    y0, y1 = int(np.floor(iy)), int(np.ceil(iy))
    z0, z1 = int(np.floor(iz)), int(np.ceil(iz))
    
    # Clamp indices
    x0 = max(0, min(x0, grid.shape[0] - 1))
    x1 = max(0, min(x1, grid.shape[0] - 1))
    y0 = max(0, min(y0, grid.shape[1] - 1))
    y1 = max(0, min(y1, grid.shape[1] - 1))
    z0 = max(0, min(z0, grid.shape[2] - 1))
    z1 = max(0, min(z1, grid.shape[2] - 1))
    
    # Fractional distances
    dx = ix - x0
    dy = iy - y0
    dz = iz - z0
    
    # Interpolate
    c00 = grid[x0, y0, z0] * (1-dx) + grid[x1, y0, z0] * dx
    c01 = grid[x0, y1, z0] * (1-dx) + grid[x1, y1, z0] * dx
    c10 = grid[x0, y0, z1] * (1-dx) + grid[x1, y0, z1] * dx
    c11 = grid[x0, y1, z1] * (1-dx) + grid[x1, y1, z1] * dx
    
    v0 = c00 * (1-dy) + c01 * dy
    v1 = c10 * (1-dy) + c11 * dy
    
    return v0 * (1-dz) + v1 * dz

### Edge Cases and Pitfalls
*   **High Noise:** Standard neural fields fail on cryo-ET data because they learn noise or oversmooth. ADG handles this via regularization (TV, CNLC, BC) [S1].
*   **Discontinuity Artifacts:** Independent optimization of octree nodes causes discontinuities at grid edges. This is mitigated by the Boundary Consistency Loss ($L_{bc}$) [S1].
*   **Fiducial Markers and Borders:** Fiducial markers and padded gray regions interfere with reconstruction. A binary mask $M$ is applied to the data-fidelity loss to exclude these rays [S1].
*   **Noise Model:** Raw cryo-ET data follows a Poisson noise model, but after preprocessing (motion/intensity correction), it is approximated as Gaussian noise for simplicity [S1].

## Operating characteristics

*   **Time Complexity:** Faster than MLP-based neural fields because querying density uses trilinear interpolation ($O(1)$) instead of evaluating a deep network [S1]. The octree structure accelerates optimization by focusing computations on regions with features [S1].
*   **Memory Complexity:** Lower than classical tomographic reconstruction techniques because it does not store the entire 3D volume during optimization; it only stores the octree nodes and their density grids [S1]. The memory usage scales with the number of active octree nodes, which is kept below a fixed limit [S1].
*   **Measured Performance:** Evaluated on EMPIAR 10643, EMPIAR 10453, and EMPIAR 11462 datasets [S1]. Outperforms SART+TV, Kniesel et al., and NeAT in reconstruction quality and denoising [S1].
*   **Strengths:**
    *   Better detail preservation in complex regions and denoising in uniform regions due to adaptive octree [S1].
    *   Faster querying and optimization compared to MLPs [S1].
    *   Flexible regularization framework for high-noise data [S1].
*   **Limitations:**
    *   Requires careful tuning of hyperparameters ($k_{tv}, k_{cnlc}, k_{bc}, N_{max}$) [S1].
    *   The mixed-integer program for octree update adds computational overhead during the coarse phase [S1].
    *   Discontinuity artifacts can still occur if boundary consistency is not properly weighted [S1].
*   **When to Use:** Cryo-ET reconstruction and denoising where high noise and missing wedge artifacts are present [S1].
*   **When Not to Use:** Scenes with very low feature density where a uniform grid might be more efficient, or when real-time rendering is required without pre-computation (though ADG is faster than MLPs, it is still slower than direct grid lookup) [S1].
