# Activation Feature Density Approximation

Also called: Approximate density extraction, f3 density functions

## Overview
Activation Feature Density Approximation estimates volumetric density $\hat{d}$ directly from intermediate activation features $f_\ell$ of a coordinate-based MLP, replacing the expensive coarse network evaluation with a lightweight computation [S1]. It differs from sibling methods like [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md) by operating on standard density fields using statistical properties of hidden activations rather than geometric distance metrics, and from [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md) by remaining fully differentiable and implicit [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Intermediate activation features $f_\ell$ for a ray $r$, where $f_\ell \in \mathbb{R}^{N_s \times N_h}$. $N_s$ is the number of samples along the ray, and $N_h$ is the number of hidden units in layer $\ell$.
*   **Output:** Estimated density vector $\hat{d} \in \mathbb{R}^{N_s}$ and subsequent sample weights $\hat{w}$.

**Data Structures:**
*   $A^{(\ell)} \in \mathbb{R}^{N_s \times N_h}$: Raw activations after the ReLU function at layer $\ell$.
*   $f_\ell$: Mean activation feature vector per sample.

**Steps:**
1.  **Extract Activation Features:** Compute the mean activation over hidden units for each sample along the ray [S1]:
    $$ f_\ell = \frac{1}{N_h} \sum_{i=1}^{N_h} A^{(\ell)}_i $$
    where $A^{(\ell)}_i$ is the activation vector for the $i$-th hidden unit [S1]. The activations are recorded after the ReLU has been applied [S1].

2.  **Compute Statistics:** Calculate the mean $\mu(f_\ell)$ and standard deviation $\sigma(f_\ell)$ of the feature vector $f_\ell$ along the last dimension (the $N_s$ samples) [S1].

3.  **Estimate Density:** Apply one of three handcrafted functions $f_k$ ($k \in \{1, 2, 3\}$) to $f_\ell$ to produce $\hat{d}$ [S1]:
    *   **f1 (Aggressive):**
        $$ \hat{d} = \text{ReLU}\left( (\mu(f_\ell) - \sigma(f_\ell)) - f_\ell \right) $$
    *   **f2 (Conservative):**
        $$ \hat{d} = \text{ReLU}\left( (\mu(f_\ell) - \frac{\sigma(f_\ell)}{2}) - f_\ell \right) $$
    *   **f3 (Squared Conservative):**
        $$ \hat{d} = \text{ReLU}\left( (\mu(f_\ell) - \frac{\sigma(f_\ell)}{2}) - f_\ell \right)^2 $$
    These functions are designed such that activation minima correspond to significant density, transforming $f_\ell$ into a vector of mostly zeros except where density is significant [S1].

4.  **Compute Weights:** Convert $\hat{d}$ to weights $\hat{w}$ using piecewise-constant PDF normalization [S1]:
    $$ \hat{w}_i = \frac{\hat{d}_i}{\sum_{j=1}^{N_s} \hat{d}_j} $$

5.  **Sampling:** Perform inverse transform sampling on weights $\hat{w}$ to determine sample positions, as done in standard NeRF [S1].

**Parameters:**
*   **Layer $\ell$:** The method is typically applied to the first 3 layers of the MLP [S1]. Layer 2 is often optimal for Mip-NeRF [S1].
*   **Function Choice:** $f_2$ generally performs best for Mip-NeRF [S1].

**Pitfalls:**
*   **High Variance:** Equation $f_1$ is prone to failure if the distribution along a ray exhibits high standard deviation [S1].
*   **Detail Loss:** Equations $f_2$ and $f_3$ extract density more conservatively but may lead to insufficient detail as the interval between fine samples grows larger [S1].

**Pseudocode:**
```python
import numpy as np

def activation_feature_density_approximation(activations, layer_idx):
    """
    activations: numpy array of shape (N_s, N_h) representing A^(l) after ReLU.
    layer_idx: integer index of the layer (used for logging or selection logic).
    Returns: estimated_density (N_s,), weights (N_s,)
    """
    # Step 1: Extract activation features f_l
    # Mean over hidden units N_h
    f_l = np.mean(activations, axis=1) # Shape: (N_s,)

    # Step 2: Compute statistics along the sample dimension (already 1D)
    mu = np.mean(f_l)
    sigma = np.std(f_l, ddof=0) # Population std dev as implied by standard definition in context

    # Step 3: Apply density function (using f2 as default best performer)
    # f2: ReLU( (mu - sigma/2) - f_l )
    raw_density = (mu - sigma / 2.0) - f_l
    estimated_density = np.maximum(0, raw_density) # ReLU

    # Step 4: Compute weights
    density_sum = np.sum(estimated_density)
    if density_sum == 0:
        # Guard against division by zero if all densities are zero
        weights = np.zeros_like(estimated_density)
    else:
        weights = estimated_density / density_sum

    return estimated_density, weights
```

## Operating characteristics
*   **Time Complexity:** Reduces inference time by replacing the coarse MLP evaluation with a small MLP or direct computation [S1]. Speedup depends on the number of samples $N_s$ [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** On the Mip-NeRF LLFF dataset (1008x756), using layer 2 with $f_2$ achieved 25.44 PSNR, 0.75 SSIM, 0.22 LPIPS, and a 40% speedup [S1]. On the Blender dataset, layer 2 with $f_2$ achieved 29.04 PSNR, 0.93 SSIM, 0.07 LPIPS, and a 49% speedup [S1].
*   **Scaling:** Potential speedup is dependent on the number of samples $N_s$, which is large for NeRFs [S1].
*   **Strengths:** Significantly reduces inference time; leverages structural information naturally stored in early MLP layers [S1].
*   **Limitations:** $f_1$ fails with high variance; $f_2/f_3$ may lose detail with large sample intervals [S1].
*   **When to use:** When inference speed is critical and the scene allows for conservative density estimation [S1].
*   **When not to use:** When high-fidelity detail is required in regions with high activation variance [S1].

## Background
The method was proposed in "Analyzing the Internals of Neural Radiance Fields" (2024) [S1]. It is based on the observation that intermediate activations of coordinate-based MLPs exhibit notable structural information and that activation feature space minima indicate samples with significant density [S1]. The method was evaluated on NeRF and Mip-NeRF models [S1].
