# StyleGAN2 Training Configuration

Also called: StyleGAN2 Training Setup

## Overview
This configuration adapts the StyleGAN2 architecture for training 3D-aware image synthesis models (such as VoxGRAF) by integrating specific regularization and optimization techniques. It solves the problem of stable GAN convergence and high-fidelity texture synthesis in differentiable volume rendering contexts. It is distinguished from standard NeRF training setups by its reliance on GAN-specific mechanisms like equalized learning rates, minibatch standard deviation, and R1 regularization, rather than photometric MSE alone.

## How it works
**Inputs:**
- Training image batches (e.g., AFHQ, FFHQ, Carla).
- Pretrained generator weights (optional, for fine-tuning on small datasets).

**Outputs:**
- Trained generator and discriminator models.

**Data Structures:**
- **Generator:** Style-based synthesis network with skip connections for progressive growing.
- **Discriminator:** StyleGAN2 discriminator with conditional input and minibatch standard deviation layer.

**Parameters:**
- **R1 regularization strength ($\gamma$):** 1.0 [S1].
- **R1 regularization frequency:** Once every 4 minibatches [S1].
- **Learning rate scaling ($\eta_{fg}$):** 0.4 for AFHQ and FFHQ; 0.1 for Carla [S1].
- **Background learning rate ($\eta_{bg}$):** 0.1 [S1].
- **Feature consistency loss weight ($\lambda_{fcvg}$):** 0.1 [S1].
- **Background consistency loss weight ($\lambda_{bg}$):** 0.1 [S1].
- **Truncation psi ($\psi$):** 0.7 (for evaluation/sampling) [S1].
- **Fine-tuning dimensions (AFHQ):** $R_I = 128$, $R_G = 32$ (before pruning) [S1].

**Steps:**
1. **Initialize Models:** Load the StyleGAN2 discriminator and generator. If training on small datasets like AFHQ, load a generator pretrained on FFHQ and prune it to dimensions $R_I = 128$ and $R_G = 32$ [S1].
2. **Configure Learning Rates:** Apply equalized learning rates to all trainable parameters in the generator and discriminator [S1]. Set specific learning rate scalings: $\eta_{fg} = 0.4$ for AFHQ/FFHQ, $\eta_{fg} = 0.1$ for Carla; $\eta_{bg} = 0.1$ for all [S1].
3. **Setup Discriminator:** Add a minibatch standard deviation layer at the end of the discriminator [S1]. For progressive growing, implement a skip architecture that adds a downsampled version of the input image to the input of each layer [S1].
4. **Configure Regularization:** Apply R1 regularization to the discriminator [S1]. Calculate the gradient penalty term using $\gamma = 1$ [S1]. Apply this regularization once every 4 minibatches to reduce computational cost [S1].
5. **Disable Specific StyleGAN2 Features:** Do not use path regularization or style-mixing [S1].
6. **Enable Mixed Precision:** Use mixed-precision arithmetic for both generator and discriminator forward and backward passes [S1].
7. **Apply EMA:** Maintain an exponential moving average (EMA) of the generator weights during training [S1].
8. **Volume Rendering Integration:** For rendering, use equidistant sampling points in steps of 0.5 voxels. Skip voxels with opacity $\sigma_i < 10^{-10}$ and stop rendering early if transmittance $T_i < 10^{-7}$ [S1].

## Subtopics

### Conditional Discriminator with Skip Connections for Progressive Growing
A variant of the discriminator used in StyleGAN2 to facilitate progressive growing. It uses conditional input and implements a skip architecture that adds a downsampled version of the input image to the input of each layer [S1]. This allows the model to start training at low resolution and gradually add layers, improving stability and convergence [S1].

## Operating characteristics
- **Time Complexity:** Reduced by applying R1 regularization only once every 4 minibatches [S1].
- **Memory Complexity:** Reduced by using mixed-precision arithmetic and skipping low-opacity voxels during rendering ($\sigma_i < 10^{-10}$) [S1].
- **Performance:** High-fidelity texture synthesis suitable for 3D-aware image synthesis [S1].
- **Strengths:** Stable training on small datasets (via fine-tuning), efficient rendering, and high-quality outputs [S1].
- **Limitations:** Requires careful tuning of learning rate scalings for different datasets (e.g., Carla vs. AFHQ) [S1].
- **When to use:** When training 3D-aware generative models that require high-frequency texture details and stable GAN convergence [S1].
- **When not to use:** When computational resources are extremely limited and R1 regularization cannot be afforded even at reduced frequency, or when photometric reconstruction is the sole objective without adversarial training [S1].

## Background
Originated from the StyleGAN2 architecture [S1] and adapted for 3D-aware image synthesis in VoxGRAF [S1]. The configuration builds on the official PyTorch implementation of StyleGAN2 [S1]. It was developed to address the challenges of training GANs for volumetric representations, leveraging techniques like equalized learning rates and R1 regularization to ensure stability [S1].
