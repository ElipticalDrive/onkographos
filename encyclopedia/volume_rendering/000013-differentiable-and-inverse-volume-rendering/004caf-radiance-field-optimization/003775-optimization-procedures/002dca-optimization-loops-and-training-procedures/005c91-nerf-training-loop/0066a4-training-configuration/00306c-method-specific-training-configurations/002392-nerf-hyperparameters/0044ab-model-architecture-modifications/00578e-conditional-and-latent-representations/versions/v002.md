# Conditional and Latent Representations

Also called: Conditional Radiance Fields, Latent NeRFs

## Overview
Conditional and Latent Representations extend standard NeRF architectures to model entire object classes or multiple 3D instances using a single neural network, rather than training separate models for each scene [S1]. By conditioning the radiance field on per-instance latent codes, this approach enables efficient representation of varying geometry and texture, supports instance-specific editing, and maintains reconstruction accuracy comparable to independent NeRFs while sharing a common network backbone [S1]. It differs from sibling methods like [Conditional Radiance Field with Shared Branch](15964-conditional-radiance-field-with-shared-branch.md) by explicitly decoupling shape and color codes and injecting them into the embedding layers, whereas the sibling method separates the geometric representation into shared and instance-specific branches to improve editing efficiency [S1].

## Shared principles
The core mechanism involves conditioning the neural radiance field $F$ on instance-specific latent vectors $\mathbf{z}^{(s)}$ (shape) and $\mathbf{z}^{(c)}$ (appearance/color) [S1]. The network takes a 3D location $\mathbf{x}$, viewing direction $\mathbf{d}$, and these latent codes to output radiance $\mathbf{c}$ and density $\sigma$ [S1]:
$$
(\mathbf{c}, \sigma) = F(\mathbf{x}, \mathbf{d}, \mathbf{z}^{(s)}, \mathbf{z}^{(c)})
$$
The density output $\sigma$ is typically independent of the viewing direction, while the radiance $\mathbf{c}$ depends on both position and viewing direction [S1]. Rendering follows standard volume rendering principles: points $\{t_i\}$ are sampled along a ray, and colors are composited using alpha compositing [S1]:
$$
\hat{C}(r, \mathbf{z}^{(s)}, \mathbf{z}^{(c)}) = \sum_{i=1}^{N_c} c_i \alpha_i \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)
$$
where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ and $\delta_i = t_{i+1} - t_i$ [S1]. The latent codes $\mathbf{z}^{(s)}$ and $\mathbf{z}^{(c)}$ are learned parameters optimized jointly with the network weights during training [S1].

## Subtopics

### [Conditional Radiance Field Training](15963-conditional-radiance-field-training.md)
A method for modeling shape and appearance variations across multiple 3D instances by training a single neural radiance field conditioned on per-instance latent codes. It solves the problem of efficiently representing a dataset of objects with varying geometry and texture without training separate models for each instance, matching the reconstruction accuracy of independent NeRFs while sharing a common network backbone. It differs from sibling methods like [Conditional Radiance Field with Shared Branch](15964-conditional-radiance-field-with-shared-branch.md) by explicitly decoupling shape and color codes and injecting them into the embedding layers, whereas the sibling method typically shares the branch earlier in the network.

### [Conditional Radiance Field with Shared Branch](15964-conditional-radiance-field-with-shared-branch.md)
The Conditional Radiance Field with Shared Branch is a neural radiance field architecture designed for shape and color disentanglement, enabling efficient instance-specific editing by allowing specific submodules to be fine-tuned independently. It maps a 3D location $\mathbf{x}$, viewing direction $\mathbf{d}$, and instance-specific latent codes to radiance and density, distinguishing itself from sibling methods by explicitly separating the geometric representation into shared and instance-specific branches to improve view synthesis quality and editing efficiency.

### Conditional Radiance Field
#### definition
- [S1] A neural network representation that extends NeRF to model an entire object class (e.g., chairs) rather than a single scene, using latent vectors for shape and appearance to allow editing.
- [S1] The network $F$ takes a 3D location $\mathbf{x}$, viewing direction $\mathbf{d}$, and instance-specific latent vectors $\mathbf{z}^{(s)}$ and $\mathbf{z}^{(c)}$ to output radiance $\mathbf{c}$ and density $\sigma$.
- [S1] The density output $\sigma$ is independent of the viewing direction.
- [S1] The radiance output $\mathbf{c}$ depends on both position and viewing direction.
#### step
- [S1] Sample $N_c$ 3D points $\{t_i\}$ along a cast ray $r$ from pixel location, ordered near to far.
- [S1] Compute radiance $c_i$ and density $\sigma_i$ at each sampled point $t_i$ using network $F$.
#### formula
- [S1] Alpha compositing value: $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, where $\delta_i = t_{i+1} - t_i$ is the distance between adjacent samples.
#### parameter
- [S1] $\mathbf{x}$: 3D location vector $(x, y, z)$.
- [S1] $\mathbf{d}$: viewing direction vector $(\phi, \theta)$.
- [S1] $\mathbf{z}^{(c)}$: latent color (appearance) vector.
#### layout
- [S1] Network $F$ is parametrized as a multi-layer perceptron (MLP).

## Background
The concept of conditional radiance fields was introduced in "Editing Conditional Radiance Fields" (ICCV 2021) [S1]. The work builds upon the original NeRF representation [45] to enable editing over entire shape classes, such as "chairs," by learning a model that extends NeRF with latent vectors over shape and appearance [S1]. The representation is trained over a set of shapes belonging to a class, where each shape instance is represented by latent shape and appearance vectors [S1]. This disentanglement allows for the modification of certain parts of the network during editing, such as updating only the fine network and codes for color editing, or updating the network for shape editing [S1].
