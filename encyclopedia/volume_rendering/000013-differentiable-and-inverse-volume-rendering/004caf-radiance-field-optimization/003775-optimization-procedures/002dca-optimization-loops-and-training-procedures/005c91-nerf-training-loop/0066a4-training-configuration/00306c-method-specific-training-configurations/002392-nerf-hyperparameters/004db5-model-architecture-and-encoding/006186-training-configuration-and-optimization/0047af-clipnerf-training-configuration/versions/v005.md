# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF training configuration defines the optimization procedure for text-guided stylization of Neural Radiance Fields (NeRFs) by minimizing the negative cosine similarity between rendered image embeddings and text prompt embeddings in the CLIP latent space [S1, S2]. It distinguishes itself from standard NeRF reconstruction by freezing density-related parameters and optimizing only appearance features to enforce a specific stylistic trajectory without altering the underlying geometry [S1].

## How it works
**Inputs and Outputs:**
- **Input:** A NeRF model (typically InstantNGP-based [S1]), a source image $I_{src}$, a target text prompt $t_{tgt}$, and optionally a source text prompt $t_{src}$ for relative loss.
- **Output:** A stylized NeRF model where the radiance field reflects the style described by $t_{tgt}$.

**Data Structures:**
- **CLIP Encoder:** Uses CLIP ViT-B/32 [S1]. The image encoder $\mathcal{E}_i$ and text encoder $\mathcal{E}_t$ output normalized embedding vectors $\hat{\mathbf{e}}_i$ and $\hat{\mathbf{e}}_t$ [S2].
- **NeRF Parameters:** Split into density-related sub-parameters (frozen) and appearance/feature sub-parameters (optimized) [S1].

**Formulas:**
1.  **Absolute Directional CLIP Loss:** Measures cosine similarity between the rendered image $I_{tgt}$ and target text $t_{tgt}$ [S2]:
    $$ \mathcal{L}_{dir} = \sum \left( 1 - \langle \hat{\mathcal{E}}_i(I_{tgt}), \hat{\mathcal{E}}_t(t_{tgt}) \rangle \right) $$
    This guides the rendering with a global direction of the target text [S2].

2.  **Relative Directional CLIP Loss:** Transfers style from source to target using a pair of text prompts $(t_{src}, t_{tgt})$ to mitigate mode collapse [S2]:
    $$ \mathcal{L}_{dir} = \sum \left( 1 - \langle \hat{\mathcal{E}}_i(I_{tgt}) - \hat{\mathcal{E}}_i(I_{src}), \hat{\mathcal{E}}_t(t_{tgt}) - \hat{\mathcal{E}}_t(t_{src}) \rangle \right) $$
    This enforces the correct stylization trajectory while ignoring magnitude differences [S2].

**Parameters:**
- **Iterations:** 500 [S1].
- **Optimizer:** Adam with learning rate $0.0001$ [S1].
- **Patch Size:** $128 \times 128$ pixels [S1].
- **Ray Sampling Stride:** 5 within the patch, resulting in a receptive field of $640 \times 640$ on the original image [S1].
- **Importance Sampling Points:** 16 per ray during patch rendering [S1].
- **Fine MLP Samples:** 80 total (64 coarse + 16 fine) [S1].

**Steps:**
1.  Initialize the NeRF model and freeze all parameters related to volume density $\sigma$ [S1].
2.  Randomly sample a pose from the training dataset [S1].
3.  Render a $128 \times 128$ patch from the current view using importance sampling with 16 points per ray [S1].
4.  Apply bilinear interpolation to resize the rendered patch if necessary before feeding to CLIP [S1].
5.  Compute the CLIP embeddings for the rendered patch and the target text prompt using CLIP ViT-B/32 [S1].
6.  Calculate the loss ($\mathcal{L}_{dir}$) based on the chosen variant (absolute or relative) [S2].
7.  Backpropagate the loss to update only the appearance/feature parameters of the NeRF [S1].
8.  Repeat for 500 iterations [S1].

**Pitfalls:**
- **Memory Constraints:** Naive differentiable rendering of high-resolution images is intractable due to memory limits; patch-based rendering is required [S1].
- **Mode Collapse:** Absolute directional CLIP loss can cause mode collapse of the generator and hurt generation diversity [S2].
- **Insufficient Magnitude:** Directional loss alone struggles to reach sufficient stylization magnitude, resulting in weak style transfer because it ignores vector distances [S2].

## Operating characteristics
- **Time Complexity:** Limited by the 500 iterations and the cost of CLIP inference per patch [S1].
- **Memory Complexity:** Reduced by using $128 \times 128$ patches and 16 sampling points instead of full-resolution rendering [S1].
- **Strengths:** Enables text-driven stylization of 3D scenes without retraining geometry [S1].
- **Limitations:** May produce insufficient stylization magnitude or mode collapse if absolute loss is used without relative guidance [S2].

## Background
The method originates from CLIP-NeRF [Wang et al. 2021a], which extended StyleCLIP [Patashnik et al. 2021] to 3D. It was further refined in NeRF-Art [S2] to address mode collapse and magnitude issues using relative directional loss. The implementation often builds on InstantNGP [S1] for computational efficiency.
