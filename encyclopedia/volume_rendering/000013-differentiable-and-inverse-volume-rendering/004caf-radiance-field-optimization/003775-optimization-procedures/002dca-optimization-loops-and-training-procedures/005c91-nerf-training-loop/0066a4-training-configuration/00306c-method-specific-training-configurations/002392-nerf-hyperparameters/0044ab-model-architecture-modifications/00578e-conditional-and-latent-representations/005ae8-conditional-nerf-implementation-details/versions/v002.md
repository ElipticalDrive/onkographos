# Conditional NeRF Implementation Details

Also called: Conditional NeRF, Conditional NeRF Architecture, Conditional NeRF Model Specs, Implementation Details

## Overview
Conditional NeRF is a generative model for a specific object category that maps spatial position $\mathbf{x}$, viewing direction $\mathbf{v}$, and instance-specific latent codes to volumetric density $\sigma$ and radiance $\mathbf{c}$ [S1]. It differs from standard NeRF by optimizing learnable shape and appearance latent codes per instance, and from its siblings by explicitly disentangling these controls to prevent mutual interference during manipulation [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Spatial position $\mathbf{x} \in \mathbb{R}^3$, viewing direction $\mathbf{v} \in \mathbb{R}^3$, shape code $\mathbf{z}_s \in \mathbb{R}^{128}$, appearance code $\mathbf{z}_a \in \mathbb{R}^{128}$.
*   **Outputs:** Scalar density $\sigma \in \mathbb{R}$, RGB radiance $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures:**
1.  **Positional Encoding ($\Gamma$):** Sinusoidal encoding applied to coordinates. For a scalar $p$, the $k$-th dimension ($k \in \{0, \dots, 2m-1\}$) is:
    $$
    \gamma(p)_k = \begin{cases} \sin(2^k \pi p), & \text{if } k \text{ is even} \\ \cos(2^k \pi p), & \text{if } k \text{ is odd} \end{cases}
    $$
    [S1]
2.  **Deformed Positional Encoding ($\Gamma^*$):** Used in the disentangled variant. The shape code $\mathbf{z}_s$ is mapped to displacement vectors $\Delta \mathbf{x} \in \mathbb{R}^{3 \times 2m}$ corresponding to each band of $\Gamma(\mathbf{x})$. The deformed encoding is $\Gamma^*(\mathbf{x}, \mathbf{z}_s) = \{\gamma^*(\mathbf{x}, \Delta \mathbf{x})\}$ [S1].
3.  **MLP Weights:** Stored as standard tensor parameters.

**Network Architecture:**
The core function $F_\theta$ is an 8-layer Multi-Layer Perceptron (MLP) with 256 hidden units per layer and ReLU activations [S1].
*   **Input Dimension:** 64. This is derived from the concatenation of the positional encodings of $\mathbf{x}$, $\mathbf{v}$, $\mathbf{z}_s$, and $\mathbf{z}_a$.
*   **Output:** The final layer outputs $\sigma$ (scalar) and $\mathbf{c}$ (3D vector).

**Deformation Network (Disentangled Variant):**
A separate 4-layer MLP with 256 hidden units and ReLU activations [S1].
*   **Input:** Shape code $\mathbf{z}_s \in \mathbb{R}^{128}$.
*   **Output:** Displacement vectors $\Delta \mathbf{x}$ for deforming the positional encoding of $\mathbf{x}$ [S1].

**Mappers (Feed-Forward Manipulation):**
Two 2-layer MLPs with ReLU activations, channel sizes 128, 256, 128 [S1].
*   **Shape Mapper ($M_s$):** Input is CLIP text embedding $\hat{E}_t(t)$. Output updates $\mathbf{z}_s$.
*   **Appearance Mapper ($M_a$):** Input is CLIP text embedding $\hat{E}_t(t)$. Output updates $\mathbf{z}_a$.
[S1]

**Rendering:**
Standard volume rendering with alpha compositing [S1]:
$$
\hat{C}(\mathbf{r}, \mathbf{z}_s, \mathbf{z}_a) = \sum_{i=1}^{N_c} c_i \alpha_i \exp \left( -\sum_{j=1}^{i-1} \sigma_j \delta_j \right)
$$
where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ and $\delta_i = t_{i+1} - t_i$ [S1].

**Training Steps:**
1.  **Initialization:** Initialize network weights $\theta$, shape codes $\mathbf{z}_s^{(k)}$, and appearance codes $\mathbf{z}_a^{(k)}$ for each instance $k$ in the dataset [S1].
2.  **Forward Pass:**
    *   Compute $\Gamma(\mathbf{x})$ and $\Gamma(\mathbf{v})$ [S1].
    *   If using disentangled architecture, compute $\Gamma^*(\mathbf{x}, \mathbf{z}_s)$ via the Deformation Network [S1].
    *   Concatenate inputs:
        *   Standard: $[\Gamma(\mathbf{x}) \oplus \mathbf{z}_s, \Gamma(\mathbf{v}) \oplus \mathbf{z}_a]$ [S1].
        *   Disentangled: $[\Gamma^*(\mathbf{x}, \mathbf{z}_s), \Gamma(\mathbf{v}) \oplus \mathbf{z}_a]$ [S1].
    *   Pass through $F_\theta$ to get $\sigma$ and $\mathbf{c}$ [S1].
    *   Render image $\hat{C}$ using volume rendering [S1].
3.  **Loss Calculation:** Compute loss against ground truth image $I$ [S1].
4.  **Optimization:**
    *   Update network weights $\theta$ using Adam optimizer, initial learning rate $10^{-4}$, decayed by 0.5 every 50,000 steps [S1].
    *   Update latent codes $\mathbf{z}_s, \mathbf{z}_a$ using Adam optimizer, initial learning rate $10^{-3}$, decreasing by 0.75 every 100 steps [S1].
5.  **Inversion (for existing images):** Iteratively optimize $\mathbf{z}_s$ and $\mathbf{z}_a$ to project an input image onto the generation manifold [S1].

import torch
import torch.nn as nn
import torch.nn.functional as F

class SinusoidalPositionalEncoding(nn.Module):
    def __init__(self, num_bands):
        super().__init__()
        self.num_bands = num_bands

    def forward(self, x):
        # x: (..., 3)
        # Output: (..., 6 * num_bands)
        # Note: The source defines gamma(p)_k for k in 0..2m-1.
        # We assume m is the number of bands per dimension.
        # Total dimensions = 3 * 2 * m.
        # Here we implement the specific sin/cos formula.
        freq_bands = torch.exp(torch.linspace(0, 1, self.num_bands, device=x.device) * torch.log(torch.tensor(2.0)))
        # x_scaled: (..., 3, num_bands)
        x_scaled = x.unsqueeze(-1) * freq_bands.unsqueeze(0).unsqueeze(0)
        # sin and cos: (..., 3, num_bands)
        sin_vals = torch.sin(2 * torch.pi * x_scaled)
        cos_vals = torch.cos(2 * torch.pi * x_scaled)
        # Interleave sin and cos as per formula: k even -> sin, k odd -> cos
        # k=0 (even) -> sin, k=1 (odd) -> cos, etc.
        # Stack sin and cos along the last dim
        out = torch.stack([sin_vals, cos_vals], dim=-2) # (..., 3, num_bands, 2)
        out = out.reshape(*x.shape[:-1], -1) # (..., 6 * num_bands)
        return out

class ConditionalNeRF(nn.Module):

        super().__init__()
        layers = []
        for i in range(num_layers):
            layers.append(nn.Linear(input_dim if i == 0 else hidden_dim, hidden_dim))
            layers.append(nn.ReLU())
        layers.append(nn.Linear(hidden_dim, 4)) # 1 for sigma, 3 for color
        self.mlp = nn.Sequential(*layers)

    def forward(self, x_enc, v_enc, z_s, z_a, use_deformation=False, deformation_net=None):
        # x_enc: (..., 6m), v_enc: (..., 6m), z_s: (..., 128), z_a: (..., 128)

            # deformation_net outputs displacement for positional encoding bands
            # Assuming deformation_net takes z_s and outputs delta for x_enc
            x_enc = deformation_net(x_enc, z_s)
        
        # Concatenate
        # Standard: [Gamma(x) + z_s, Gamma(v) + z_a]
        # Disentangled: [Gamma*(x, z_s), Gamma(v) + z_a]

        # are not concatenated directly into the 64-dim input, or the positional

        # Given "input dimension is 64", we will concatenate and pass to MLP.

class DeformationNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        layers = []
        for i in range(4):
            layers.append(nn.Linear(128 if i == 0 else 256, 256))
            layers.append(nn.ReLU())
        self.mlp = nn.Sequential(*layers)
        # Output: displacement for positional encoding bands
        # Source says: zs to displacement vectors dx in R^{3x2m}
        # Assuming m=2 (from 64 input dim logic? 3*2*2=12? No.)
        # We output 3 * 2 * m dimensions.
        self.output_dim = 3 * 2 * 2 # Example m=2

    def forward(self, x_enc, z_s):
        # x_enc: (..., 6m), z_s: (..., 128)
        # We need to map z_s to displacement.
        # Source: "zs to displacement vectors"
        # We assume a linear projection or small MLP from z_s to displacement
        # The source says Deformation Network takes z_s.
        # It does not explicitly say it takes x_enc as input to the MLP,

        # Let's assume it outputs displacement directly from z_s.
        displacement = self.mlp(z_s)
        # Apply displacement to x_enc?
        # Source: Gamma*(x, zs) = {gamma*(x, delta_p)}
        # This implies adding displacement to the positional encoding arguments.
        # However, x_enc is already encoded.
        # Usually, deformation is applied to x before encoding.
        # But here, the input to Conditional NeRF is Gamma(x).
        # The source says: "deform the local volume field... by explicit volumetric deformation of positional encodings"
        # This suggests modifying the encoded position.
        # We will assume displacement is added to x_enc.
        # Note: x_enc and displacement must have same shape.

class Mapper(nn.Module):
    def __init__(self):
        super().__init__()
        layers = []
        for i in range(2):
            layers.append(nn.Linear(128 if i == 0 else 256, 256 if i == 1 else 128))
            layers.append(nn.ReLU())
        self.mlp = nn.Sequential(*layers)

    def forward(self, text_embedding, z_initial):
        # text_embedding: (..., 128) from CLIP
        # z_initial: (..., 128)
        delta = self.mlp(text_embedding)
        return z_initial + delta

## Subtopics

### [Disentangled Conditional NeRF](16793-disentangled-conditional-nerf.md)
Disentangled Conditional NeRF achieves independent control over shape and appearance by isolating shape conditioning to explicit volumetric deformation of positional encodings. Unlike standard conditional NeRFs where concatenating latent codes causes mutual intervention (e.g., shape changes altering color), this method prevents such interference by deferring appearance conditioning to the radiance field while applying shape conditioning via a deformation network.

### CLIP-Driven Manipulation via Mappers
A feed-forward approach using shape mapper $M_s$ and appearance mapper $M_a$ to update initial shape/appearance codes ($\mathbf{z}_{s0}, \mathbf{z}_{a0}$) based on a text prompt $t$, avoiding per-sample optimization [S1]. The updated codes are $\mathbf{z}_s = M_s(\hat{E}_t(t)) + \mathbf{z}_{s0}$ and $\mathbf{z}_a = M_a(\hat{E}_t(t)) + \mathbf{z}_{a0}$ [S1].

### Deferred Appearance Conditioning
A technique where appearance conditioning is deferred to concatenate the appearance code with the viewing direction as input to the radiance prediction network, allowing appearance manipulation without affecting shape/density [S1].

## Operating characteristics
*   **Time Complexity:** Training involves iterative optimization of latent codes and network weights. Inversion is iterative and time-consuming if done per sample, but feed-forward mappers reduce this to a single forward pass [S1].
*   **Memory Complexity:** Requires storing latent codes $\mathbf{z}_s, \mathbf{z}_a$ for each instance, plus network weights. The MLP is 8 layers, 256 hidden units [S1].
*   **Performance:** Trained on NVIDIA V100 GPU [S1].
*   **Strengths:** Enables text-driven manipulation of both shape and appearance without per-sample optimization when using mappers [S1]. Disentangles shape and appearance to prevent interference [S1].
*   **Limitations:** Requires training data from a single object category [S1]. Feed-forward mappers require training [S1].

## Background
Conditional NeRF was introduced in "CLIP-NeRF: Text-and-Image Driven Manipulation of Neural Radiance Fields" by Can Wang et al. (CVPR 2022) [S1]. It builds on the original per-scene NeRF [S1].
