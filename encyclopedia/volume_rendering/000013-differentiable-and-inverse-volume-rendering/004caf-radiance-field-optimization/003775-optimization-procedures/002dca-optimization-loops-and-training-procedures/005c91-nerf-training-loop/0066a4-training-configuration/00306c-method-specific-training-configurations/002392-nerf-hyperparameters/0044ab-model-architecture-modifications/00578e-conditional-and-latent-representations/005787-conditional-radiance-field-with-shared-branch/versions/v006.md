# Conditional Radiance Field with Shared Branch

Also called: CRF with Shared Branch, Modular Conditional Radiance Field

## Overview
The Conditional Radiance Field with Shared Branch is a neural radiance field architecture designed for shape and color disentanglement, enabling efficient editing by allowing specific submodules to be finetuned [S1]. It maps a 3D location $\mathbf{x}$, viewing direction $\mathbf{d}$, and instance-specific shape code $\mathbf{z}^{(s)}$ and color code $\mathbf{z}^{(c)}$ to radiance $\mathbf{c}$ and scalar density $\sigma$ [S1]. Unlike standard NeRF or basic conditional variants, this method introduces a shared shape network that learns a category-specific geometric representation, improving view synthesis quality and scalability to multiple instances [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D position $\mathbf{x}$, viewing direction $\mathbf{d}$, instance-specific shape latent code $\mathbf{z}^{(s)} \in \mathbb{R}^{32}$, instance-specific color latent code $\mathbf{z}^{(c)} \in \mathbb{R}^{32}$.
*   **Outputs:** Scalar density $\sigma \in \mathbb{R}$, radiance color $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures:**
The network consists of five Multi-Layer Perceptrons (MLPs), all with 4 layers, 256 hidden channels, and ReLU activations [S1]:
1.  $F_{\text{share}}$: Shared shape network.
2.  $F_{\text{inst}}$: Instance-specific shape network.
3.  $F_{\text{fuse}}$: Fusion shape network.
4.  $F_{\text{dens}}$: Output density network (linear layer).
5.  $F_{\text{rad}}$: Output radiance network (2-layer MLP).

Latent codes $\mathbf{z}^{(s)}$ and $\mathbf{z}^{(c)}$ are learnable parameters optimized alongside network weights [S1].

**Positional Encoding:**
Standard NeRF positional encoding $\gamma(\cdot)$ is applied to $\mathbf{x}$ and $\mathbf{d}$ [S1].

**Algorithm Steps:**
1.  **Compute Shared Shape Representation:** Pass the positional encoding of the position, $\gamma(\mathbf{x})$, through the shared shape network:
    $$ \mathbf{h}_{\text{share}} = F_{\text{share}}(\gamma(\mathbf{x})) $$
2.  **Compute Instance-Specific Shape Representation:** Concatenate the shape code $\mathbf{z}^{(s)}$ with $\gamma(\mathbf{x})$, then pass through the instance-specific shape network:
    $$ \mathbf{h}_{\text{inst}} = F_{\text{inst}}([\mathbf{z}^{(s)}; \gamma(\mathbf{x})]) $$
3.  **Fuse Representations:** Add the outputs of the shared and instance-specific networks, then pass through the fusion network:
    $$ \mathbf{h}_{\text{fuse}} = F_{\text{fuse}}(\mathbf{h}_{\text{share}} + \mathbf{h}_{\text{inst}}) $$
4.  **Predict Density:** Pass the fused representation through the linear density network:
    $$ \sigma = F_{\text{dens}}(\mathbf{h}_{\text{fuse}}) $$
5.  **Predict Radiance:** Concatenate the fused representation $\mathbf{h}_{\text{fuse}}$, the color code $\mathbf{z}^{(c)}$, and the encoded viewing direction $\gamma(\mathbf{d})$. Pass this concatenation through the radiance network:
    $$ \mathbf{c} = F_{\text{rad}}([\mathbf{h}_{\text{fuse}}; \mathbf{z}^{(c)}; \gamma(\mathbf{d})]) $$

**Rendering:**
Rendering follows standard volume rendering with alpha compositing [S1]:
$$ \hat{C}(r, \mathbf{z}^{(s)}, \mathbf{z}^{(c)}) = \sum_{i=1}^{N_c} c_i \alpha_i \exp \left( -\sum_{j=1}^{i-1} \sigma_j \delta_j \right) $$
where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ and $\delta_i = t_{i+1} - t_i$ [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class ConditionalRadianceFieldSharedBranch(nn.Module):
    def __init__(self, dim_z=32, hidden_dim=256, num_layers=4):
        super().__init__()
        # Fshare: 4 layers, 256 channels, ReLU
        self.Fshare = self._make_mlp(num_layers, hidden_dim, relu=True)
        # Finst: 4 layers, 256 channels, ReLU
        self.Finst = self._make_mlp(num_layers, hidden_dim, relu=True)
        # Ffuse: 4 layers, 256 channels, ReLU
        self.Ffuse = self._make_mlp(num_layers, hidden_dim, relu=True)
        # Fdens: Linear layer (1 layer implied by "linear layer")
        self.Fdens = nn.Linear(hidden_dim, 1)
        # Frad: 2-layer MLP, 256 channels, ReLU
        # Input dim: hidden_dim + dim_z + dim_gamma_d
        # Output dim: 3 (RGB)
        self.Frad = self._make_mlp(2, hidden_dim, relu=True, final_dim=3)
        
        # Latent codes are parameters
        self.z_s = nn.Parameter(torch.randn(1, dim_z))
        self.z_c = nn.Parameter(torch.randn(1, dim_z))

    def _make_mlp(self, num_layers, hidden_dim, relu=True, final_dim=None):
        layers = []
        in_dim = hidden_dim
        for i in range(num_layers):
            out_dim = final_dim if (i == num_layers - 1 and final_dim is not None) else hidden_dim
            layers.append(nn.Linear(in_dim, out_dim))
            if relu and not (final_dim is not None and i == num_layers - 1):
                layers.append(nn.ReLU())
            in_dim = out_dim
        return nn.Sequential(*layers)

    def forward(self, x, d, z_s, z_c):
        """
        x: [N, 3] positions
        d: [N, 3] directions
        z_s: [N, 32] shape codes
        z_c: [N, 32] color codes
        """
        # Positional encoding is assumed to be handled externally or as a helper
        # For implementation completeness, we assume gamma is a function that expands dims
        # Standard NeRF gamma(x) expands 3D to 6D (sin/cos)
        gamma_x = positional_encoding(x, num_frequencies=10) # [N, 60]
        gamma_d = positional_encoding(d, num_frequencies=4)  # [N, 24]
        
        # 1. Shared shape representation
        h_share = self.Fshare(gamma_x) # [N, 256]
        
        # 2. Instance-specific shape representation
        # Concatenate z_s and gamma_x
        z_s_expanded = z_s.unsqueeze(1).expand(-1, gamma_x.size(1), -1).reshape(-1, z_s.size(1)) # [N, 32]
        # Note: z_s is per-instance, but here we assume batched processing where z_s corresponds to rows
        # In practice, z_s might be [N_instances, 32]. If batched by ray, z_s must be gathered.
        # Assuming z_s and z_c are passed as [N, 32] for the current batch of rays belonging to instances.
        inst_input = torch.cat([z_s, gamma_x], dim=-1) # [N, 32+60]
        h_inst = self.Finst(inst_input) # [N, 256]
        
        # 3. Fuse representations
        h_fuse = self.Ffuse(h_share + h_inst) # [N, 256]
        
        # 4. Predict density
        sigma = self.Fdens(h_fuse).squeeze(-1) # [N]
        
        # 5. Predict radiance
        # Concatenate h_fuse, z_c, gamma_d
        rad_input = torch.cat([h_fuse, z_c, gamma_d], dim=-1) # [N, 256+32+24]
        c = self.Frad(rad_input) # [N, 3]
        
        return c, sigma

def positional_encoding(x, num_frequencies=10):
    """Standard NeRF positional encoding."""
    x = x.unsqueeze(-1) # [N, 3, 1]
    scales = torch.tensor([2**i for i in range(num_frequencies)], dtype=x.dtype, device=x.device)
    shaped = x * (2 * torch.pi * scales) # [N, 3, num_freq]
    encoded = torch.cat([torch.sin(shaped), torch.cos(shaped)], dim=-1) # [N, 3, 2*num_freq]
    return encoded.reshape(x.shape[0], -1)
```

**Parameters:**
*   Shape and color code dimension: 32 [S1].
*   MLP depth: 4 layers for $F_{\text{share}}$, $F_{\text{inst}}$, $F_{\text{fuse}}$ [S1].
*   MLP width: 256 channels [S1].
*   Feature dimension: 256-dimensional features output by $F_{\text{share}}$, $F_{\text{inst}}$, $F_{\text{fuse}}$ [S1].
*   Optimizer: Adam [S1].
*   Training learning rate: $10^{-4}$ [S1].
*   Edit learning rate: $10^{-2}$ [S1].

**Edge Cases and Pitfalls:**
*   **Caching:** Because the set of training rays is small during optimization, caching computed features is computationally feasible and recommended to accelerate edits [S1].
*   **Disentanglement:** The architecture explicitly separates shape and color paths to enable independent editing. Mixing these paths degrades editing quality [S1].

## Operating characteristics
*   **Performance:** On the PhotoShapes dataset, the shared shape branch improves PSNR from 33.91 (without shared branch) to 35.79 [S1].
*   **Efficiency:** Accelerates color edits by $3.2\times$ and shape edits by $1.9\times$ compared to non-modular approaches by allowing selective updates [S1].
*   **Scalability:** The shared branch helps the model scale to more instances by learning a category-specific geometric representation [S1].
*   **Limitations:** Requires joint optimization of latent codes and network weights, which can be sensitive to learning rate choices (e.g., $10^{-4}$ for training, $10^{-2}$ for editing) [S1].

## Background
The method was introduced in "Editing Conditional Radiance Fields" (ICCV 2021) [S1]. It builds on the inductive biases of NeRF, specifically positional encodings and stage-wise network design, to create a modular model for shape and color disentanglement [S1]. It is used for editing 3D objects by optimizing a loss over network parameters and learned codes, allowing for accurate and efficient modifications [S1].
