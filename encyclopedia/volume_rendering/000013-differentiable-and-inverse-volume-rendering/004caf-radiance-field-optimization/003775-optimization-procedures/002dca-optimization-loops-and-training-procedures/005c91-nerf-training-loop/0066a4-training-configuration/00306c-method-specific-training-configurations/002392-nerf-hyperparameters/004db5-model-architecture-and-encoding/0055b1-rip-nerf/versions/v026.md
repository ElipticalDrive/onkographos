# Rip-NeRF

Also called: Rip-NeRF25k

## Overview
Rip-NeRF is a radiance field method that renders high-fidelity anti-aliased images by combining cone casting with an anisotropic 3D Gaussian representation [S1]. It distinguishes itself from sibling methods like Zip-NeRF by using Ripmap-Encoded Platonic Solids to enable efficient anisotropic area-sampling, whereas Zip-NeRF relies on a multi-sampling mechanism that is effective but computationally inefficient [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of calibrated multi-view 2D images.
*   **Outputs:** Rendered pixel colors and densities for the scene.

**Data Structures**
1.  **Ripmap Encoding ($R$):** A hierarchical grid of learnable features.
    *   **Base Level ($R_{0,0}$):** The only learnable level. Shape: $H=512, W=512, C=16$ [S1].
    *   **Derived Levels:** Generated from the base level using averaging operations to ensure consistency and compactness [S1].
2.  **Platonic Solid:** A geometric proxy for the 3D Gaussian. Default is an icosahedron with 10 unparalleled faces $\{P_i | i = 1, \dots, n\}$ [S1].
3.  **Anisotropic 3D Gaussian:** Characterizes each conical frustum, parameterized by mean $\boldsymbol{\mu}$ and covariance $\boldsymbol{\Sigma}$ [S1].
4.  **Tiny MLP ($F_\theta$):** Estimates color $\mathbf{c}$ and density $\sigma$ from aggregated features [S1].

**Numbered Steps**
1.  **Cone Casting:** For each pixel, cast a cone into the scene and divide it into multiple conical frustums [S1].
2.  **Gaussian Characterization:** Characterize each conical frustum as an anisotropic 3D Gaussian with mean $\boldsymbol{\mu}$ and covariance $\boldsymbol{\Sigma}$ [S1].
3.  **Platonic Solid Projection:** Project the 3D Gaussian onto the faces of the Platonic solid. For each face $P_i$, compute the projected 2D Gaussian parameters $(\boldsymbol{\mu}_{proj}, \boldsymbol{\Sigma}_{proj})$ using the projection matrix $M_i \in \mathbb{R}^{3 \times 2}$:
    $$ \boldsymbol{\mu}_{proj} = M_i^T \boldsymbol{\mu} $$
    $$ \boldsymbol{\Sigma}_{proj} = M_i^T \boldsymbol{\Sigma} M_i $$
    [S1]
4.  **Ripmap Query:** For each face $P_i$, query a feature vector $\mathbf{f}_i$ from the Ripmap Encoding using tetra-linear interpolation. The interpolation position $(p_x, p_y)$ and level $(l_x, l_y)$ are determined by $\boldsymbol{\mu}_{proj}$ and $\boldsymbol{\Sigma}_{proj}$ respectively [S1].
    *   The level indices are adjusted by a hyper-parameter $w$ to cover the probability mass of the Gaussian footprint. The sources specify $w=2.0$ [S1].
    *   The derivation of lower levels from the base level $R_{0,0}$ follows:
        $$ R_{i,j} = \begin{cases} \text{Avg}_{2\times1} R_{i,j-1} & \text{if } j \neq 0 \\ \text{Avg}_{1\times2} R_{i-1,j} & \text{if } i \neq 0 \text{ \& } j = 0 \\ R_{0,0} & \text{otherwise} \end{cases} $$
        where $i$ and $j$ are indices in the $x$ and $y$ directions [S1].
5.  **Feature Aggregation:** Concatenate all feature vectors $\{\mathbf{f}_i | i = 1, \dots, n\}$ from the Platonic solid faces and the encoded view direction $\mathbf{d}$ to form the final feature vector $\mathbf{f}$ [S1].
6.  **Color and Density Estimation:** Pass $\mathbf{f}$ through the tiny MLP $F_\theta$ to estimate color $\mathbf{c}$ and density $\sigma$ [S1].
7.  **Volume Rendering:** Render the pixel color using standard volume rendering with the estimated $\mathbf{c}$ and $\sigma$ [S1].
8.  **Optimization:** Optimize the system end-to-end using a photometric loss scaled by the area of the pixel footprint on the image plane (area loss $L_{area}$) [S1].

import torch
import torch.nn as nn
import torch.nn.functional as F

class RipNeRF:
    def __init__(self, ripmap_base_shape=(512, 512, 16), num_faces=10):
        """
        Initialize Rip-NeRF.
        :param ripmap_base_shape: (H, W, C) of the base Ripmap level R_0,0
        :param num_faces: Number of faces on the Platonic solid (default 10 for icosahedron)
        """
        # Base level is learnable; derived levels are computed on the fly
        self.R_base = nn.Parameter(torch.randn(ripmap_base_shape) * 0.01)
        self.num_faces = num_faces
        self.w = 2.0  # Hyper-parameter for Gaussian footprint coverage
        self.mlp = TinyMLP() # Defined below
        self.projection_matrices = self._get_icosahedron_projections()

    def _get_icosahedron_projections(self):
        """
        Returns a list of projection matrices M_i for the 10 faces of an icosahedron.
        Each M_i is (3, 2).
        Note: Exact geometric derivation of icosahedron face normals and projection matrices
        is implementation-specific. This placeholder assumes a pre-computed list exists.
        """
        # [G] Placeholder for geometric constants. In practice, these are fixed matrices
        # mapping 3D world coordinates to the 2D plane of each icosahedron face.
        return [torch.eye(2) for _ in range(self.num_faces)] # Simplified for structure

    def _get_derived_level(self, R_base, i, j):
        """
        Computes derived Ripmap level R_{i,j} from base level using averaging.
        """
        if i == 0 and j == 0:
            return R_base
        elif j != 0:
            # Avg_{2x1}: Average along x-axis (dim 1)
            # Assuming R_base is (H, W, C)
            # To get level i,j, we conceptually downsample.
            # The source defines R_{i,j} based on R_{i,j-1} or R_{i-1,j}.
            # This recursive definition implies a hierarchical grid.
            # For simplicity in this self-contained pseudocode, we assume
            # a helper function that performs the specific averaging defined in Eq 1.
            return self._average_operation(R_base, i, j, mode='avg_2x1')
        else: # i != 0 & j == 0
            return self._average_operation(R_base, i, j, mode='avg_1x2')

    def _average_operation(self, R_base, i, j, mode):
        """
        Performs the averaging operation to derive lower levels.
        Note: The exact downsampling factor and indices depend on the specific
        implementation of the Ripmap hierarchy not fully detailed in the text.
        We assume a standard 2x2 or 2x1 average pooling to simulate the derivation.
        """
        # [G] Implementation detail: The source states only R_0,0 is learnable.
        # Derived levels are averages. We simulate this by pooling the base.
        # The indices i, j likely correspond to resolution levels.
        # If i=1, j=0, it's Avg_{1x2} of R_{0,0}.
        # If i=0, j=1, it's Avg_{2x1} of R_{0,0}.
        # This is a simplification. A full implementation would manage the grid hierarchy.
        if mode == 'avg_2x1':
            # Average along width (dim 1)
            return F.avg_pool2d(R_base.permute(2, 0, 1), kernel_size=(1, 2)).permute(1, 2, 0)
        else:
            # Average along height (dim 0)
            return F.avg_pool2d(R_base.permute(2, 0, 1), kernel_size=(2, 1)).permute(1, 2, 0)

    def query_riipmap(self, R_base, px, py, lx, ly):
        """
        Queries feature vector from Ripmap using tetra-linear interpolation.
        :param R_base: Base level tensor (H, W, C)
        :param px, py: Normalized coordinates in [0, 1]
        :param lx, ly: Level indices (integers)
        :return: Feature vector f (C,)
        """
        # Determine the level to query based on lx, ly
        # Note: The source uses Eq 2 and 3 for position/level determination.
        # We assume R_base is the source for all levels via derivation.
        # For this pseudocode, we query the base level directly for simplicity,
        # as the derivation logic is complex and context-dependent.
        # In a real implementation, one would fetch R_{lx, ly}.
        
        # Normalize coordinates to [-1, 1] for grid_sample
        x = 2.0 * px - 1.0
        y = 2.0 * py - 1.0
        
        # Grid sample requires (N, H, W, C) or (N, C, H, W)
        # R_base is (H, W, C).
        coords = torch.stack([x, y], dim=-1).unsqueeze(0).unsqueeze(0) # (1, 1, 1, 2)
        R_expanded = R_base.unsqueeze(0).unsqueeze(0) # (1, 1, H, W, C) -> needs reshaping for grid_sample
        
        # Standard grid_sample expects (N, C, H, W)
        R_grid = R_base.permute(2, 0, 1).unsqueeze(0) # (1, C, H, W)
        
        # Interpolate
        # [G] grid_sample uses bilinear by default. Tetra-linear in 3D/4D context
        # might imply interpolation across levels if R was a 4D tensor (H, W, L, C).
        # The source says "tetra-linear interpolation on the Ripmap Encoding".
        # Given R is 3D (H,W,C) and levels are derived, this likely refers to
        # interpolation in the 2D plane of the specific level.
        # We use bilinear interpolation here as a proxy for the 2D query.
        features = F.grid_sample(R_grid, coords, align_corners=True) # (1, C, 1, 1)
        return features.squeeze()

    def forward(self, gaussians, view_directions):
        """
        Forward pass for a batch of conical frustums.
        :param gaussians: List of tuples (mu, Sigma) for each frustum
        :param view_directions: Tensor of view directions d (N, 3)
        :return: Rendered colors and densities
        """
        all_features = []
        
        for mu, Sigma in gaussians:
            face_features = []
            for i in range(self.num_faces):
                M_i = self.projection_matrices[i]
                
                # Project 3D Gaussian to 2D
                mu_proj = M_i.T @ mu # (2,)
                Sigma_proj = M_i.T @ Sigma @ M_i # (2, 2)
                
                # Determine query position and level
                # [G] The source states position (px, py) and level (lx, ly) are determined
                # by mu_proj and Sigma_proj. Eq 2 and 3 define this.
                # Typically, px, py = mu_proj, and lx, ly relate to sqrt(Sigma) scaled by w.
                px, py = mu_proj[0], mu_proj[1]
                
                # Compute level indices based on covariance and w
                # [G] Specific formula for lx, ly from Sigma and w is not explicitly written
                # as a single equation in the notes, but w=2.0 adjusts probability mass coverage.
                # We assume a standard mapping where larger variance -> higher level (coarser).
                # This is a placeholder for the specific Eq 2/3 logic.
                lx = int(torch.sqrt(Sigma_proj[0,0]) * self.w)
                ly = int(torch.sqrt(Sigma_proj[1,1]) * self.w)
                
                # Query Ripmap
                f_i = self.query_riipmap(self.R_base, px, py, lx, ly)
                face_features.append(f_i)
            
            # Concatenate face features
            f_concat = torch.cat(face_features, dim=0)
            
            # Encode view direction
            # [G] View direction encoding is not detailed in the notes.
            # We assume a simple embedding or direct concatenation.
            d_encoded = view_directions # Placeholder
            
            # Aggregate
            f_final = torch.cat([f_concat, d_encoded], dim=0)
            all_features.append(f_final)
            
        all_features = torch.stack(all_features)
        
        # Estimate color and density
        colors, densities = self.mlp(all_features)
        
        return colors, densities

class TinyMLP(nn.Module):
    def __init__(self):
        super().__init__()
        # [G] Architecture of TinyMLP is not specified.
        # Assuming a small network to output color (3) and density (1).
        self.net = nn.Sequential(
            nn.Linear(100, 64), # Input size depends on num_faces * C + 3
            nn.ReLU(),
            nn.Linear(64, 32),
            nn.ReLU(),
            nn.Linear(32, 4) # 3 for color, 1 for density
        )
    
    def forward(self, x):
        out = self.net(x)
        color = out[:, :3]
        density = out[:, 3:]
        return color, density

**Parameters**
*   **Ripmap Base Shape:** $H=512, W=512, C=16$ [S1].
*   **Platonic Solid:** Icosahedron (10 faces) [S1].
*   **Hyper-parameter $w$:** 2.0 (adjusts Gaussian footprint coverage) [S1].
*   **Optimizer:** AdamW [S1].
*   **Iterations:** 120k (standard Rip-NeRF) or 25k (Rip-NeRF25k variant) [S1].
*   **Weight Decay:** $1 \times 10^{-5}$ [S1].
*   **Initial Learning Rate:** $2 \times 10^{-3}$, modulated by MultiStepLR [S1].
*   **Ripmap LR Scale:** 10.0 times the base learning rate [S1].
*   **Libraries:** `tiny-cuda-nn` for MLP, CUDA kernels for Projection/Encoding, `NerfAcc` for binary occupancy grid [S1].

**Edge Cases and Pitfalls**
*   **Empty Space:** Use a binary occupancy grid (via NerfAcc) to skip samples in empty areas [S1].
*   **Precision:** The derivation of Ripmap levels ensures consistency, but precise implementation of the tetra-linear interpolation and level indexing is critical [S1].
*   **Degenerate Input:** The method assumes calibrated multi-view images [S1].

## Subtopics

### Ripmap Encoding
A hierarchical feature grid where only the base level is learnable, and lower levels are derived via averaging to support efficient area sampling [S1].

### Platonic Solid Projection
A technique to project 3D Gaussians onto the faces of a Platonic solid (e.g., icosahedron) to facilitate anisotropic area sampling [S1].

## Operating characteristics
*   **Training Time:** 2.6 hours on NVIDIA A100-SXM4-80GB GPU for 120k iterations [S1]. Rip-NeRF25k takes 32 minutes (11.76% of Zip-NeRF's 4.5h) [S1].
*   **Model Size:** 160 MB [S1].
*   **GPU Memory:** 20 GB during training [S1].
*   **Rendering Speed:** 3 FPS [S1].
*   **Comparison:** Outperforms Zip-NeRF in training time (2.6h vs 4.5h), model size (160MB vs 592MB), and rendering speed (3 FPS vs 0.25 FPS). Zip-NeRF has slightly better SSIM [S1].
*   **Strengths:** High-fidelity anti-aliasing, efficient anisotropic area-sampling, compact representation [S1].
*   **Limitations:** Requires calibrated multi-view images [S1].

## Background
Rip-NeRF was introduced in 2024 by authors including Hu et al., presented at SIGGRAPH 2024 [S1]. It builds on previous work in anti-aliasing radiance fields such as Mip-NeRF and Tri-MipRF, aiming to improve efficiency and quality through Ripmap-Encoded Platonic Solids [S1].
