# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the training protocol for a Neural Radiance Field (NeRF) model that incorporates depth priors to improve reconstruction quality, particularly in sparse-view or ambiguous scenarios. It modifies the standard NeRF architecture by adding regularization and integrates a depth-specific loss term. It is distinguished from sibling methods like [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md) by its explicit use of geometric depth supervision rather than semantic or frequency-based constraints.

## How it works
The method extends the standard NeRF optimization loop by modifying the network architecture and the loss function.

**Inputs:**
*   Camera poses and intrinsics.
*   RGB images.
*   Ground truth depth maps (optional but required for the depth loss).
*   Scene-specific depth bounds ($min\_depth$, $max\_depth$).

**Outputs:**
*   Optimized NeRF model parameters (MLP weights, positional encoding tables).

**Data Structures:**
*   **NeRF MLP:** Builds on the original NeRF architecture [S1]. It consists of fully connected layers with ReLU activations.
*   **Dropout Layers:** Added after the first eight fully connected ReLU-activated layers that encode the positional encoding.

**Parameters:**
*   **Dropout Probability ($p$):** 0.1 [S1].
*   **Depth Loss Weight ($\lambda$):** 0.007 for most scenes; 0.02 for scene 710 [S1].
*   **Uncertainty Weight ($\gamma$):** 1 [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate ($lr$):** $5 \times 10^{-4}$ [S1].
*   **Learning Rate Schedule:** Reduced to $5 \times 10^{-5}$ after 80% of total steps [S1].
*   **Weight Decay:** $1 \times 10^{-6}$ [S1].
*   **Total Training Steps:** 500,000 [S1].
*   **Depth Scale Learning Rate:** $1 \times 10^{-7}$ [S1].
*   **Depth Threshold ($\tau$):** Used to evaluate depth map uncertainty. Calculated as $\tau = (max\_depth - min\_depth) \cdot 0.0001$ [S1]. For ScanNet, $max\_depth = 10$ and $min\_depth = 0.001$ [S1].

**Algorithm Steps:**
1.  **Initialize** the NeRF MLP with standard weights.
2.  **Modify Architecture:** Insert dropout layers with probability $p=0.1$ after each of the first eight fully connected ReLU-activated layers in the positional encoding path [S1].
3.  **Sample Rays:** For each training image, sample points along rays using the standard NeRF sampling strategy (uniform and/or importance sampling).
4.  **Forward Pass:** Compute volume density $\sigma$ and color $\mathbf{c}$ for sampled points. Render the predicted color $\hat{C}(\mathbf{r})$ using the standard volume rendering equation.
5.  **Compute RGB Loss:** Calculate the mean squared error between rendered colors $\hat{C}(\mathbf{r})$ and ground truth image colors $C(\mathbf{r})$.
6.  **Compute Depth Loss:**
    *   Predict depth values from the accumulated transmittance and sampled depths.
    *   Filter out invalid depth pixels using the threshold $\tau$ [S1].
    *   Calculate the depth loss (e.g., L1 or L2) between predicted depth $\hat{d}$ and ground truth depth $d$ for valid pixels [S1].
7.  **Compute Total Loss:** Combine losses:
    $$ L_{total} = L_{rgb} + \lambda L_{depth} $$
    where $\lambda$ is the depth loss weight [S1].
8.  **Update Weights:** Perform gradient descent using Adam optimizer with the specified learning rates and weight decay [S1].
9.  **Schedule LR:** Reduce the main learning rate to $5 \times 10^{-5}$ after 80% of the 500,000 steps [S1].

**Pseudocode:**
```python
def train_depth_guided_nerf(model, dataloader, config):
    optimizer = Adam(model.parameters(), lr=config.lr, weight_decay=config.weight_decay)
    scheduler = StepLR(optimizer, step_size=config.steps * 0.8, gamma=0.1) # Reduce to 5e-5
    
    # Architecture modification: Add dropout to first 8 FC layers
    for i, layer in enumerate(model.mlp.layers[:8]):
        if isinstance(layer, Linear) and layer.activation == ReLU:
            layer.add_dropout(p=0.1)
            
    for step in range(config.total_steps):
        for batch in dataloader:
            rays, gt_colors, gt_depths = batch
            
            # Forward pass
            predicted_colors, predicted_depths, transmittances = model(rays)
            
            # RGB Loss
            rgb_loss = mse(predicted_colors, gt_colors)
            
            # Depth Loss
            # Filter valid depth pixels based on threshold tau
            valid_mask = compute_valid_depth_mask(gt_depths, config.max_depth, config.min_depth)
            depth_loss = l1_loss(predicted_depths[valid_mask], gt_depths[valid_mask])
            
            # Total Loss
            lambda_d = config.lambda_d
            if scene_id == 710:
                lambda_d = 0.02
            else:
                lambda_d = 0.007
                
            total_loss = rgb_loss + lambda_d * depth_loss
            
            # Backward pass
            optimizer.zero_grad()
            total_loss.backward()
            optimizer.step()
            
        scheduler.step()
```

## Subtopics

### DS-NeRF Depth Loss Integration
This variant involves integrating the depth loss implementation from the official DS-NeRF codebase into the training pipeline. It requires re-training on specific datasets (LLFF, DTU) using released configuration files, as original publication results may use different splits or unreleased architectural tricks (e.g., reduced positional encoding frequency) to prevent overfitting [S2].

## Operating characteristics
*   **Time Complexity:** Standard NeRF training complexity, scaled by the number of training steps (500,000) [S1].
*   **Memory Complexity:** Standard NeRF memory usage, plus minimal overhead for storing depth maps and dropout states [S1].
*   **Performance:** Improves geometric accuracy and reduces floating artifacts in scenes with sparse views or ambiguous geometry by leveraging depth priors [S1].
*   **Strengths:** Robustness to sparse input; better depth estimation [S1].
*   **Limitations:** Requires ground truth depth maps for training; sensitive to depth scale and threshold parameters [S1].
*   **When to use:** When depth accuracy is critical or input views are sparse [S1].
*   **When not to use:** When only RGB images are available without depth supervision [S1].

## Background
This configuration was introduced in the context of Depth-Guided NeRF training via Earth Mover’s Distance [S1]. It builds upon the original NeRF architecture [S1] and incorporates techniques from DS-NeRF [S2]. The method addresses the issue of geometric ambiguity in NeRF reconstruction by explicitly supervising the depth output during training.
