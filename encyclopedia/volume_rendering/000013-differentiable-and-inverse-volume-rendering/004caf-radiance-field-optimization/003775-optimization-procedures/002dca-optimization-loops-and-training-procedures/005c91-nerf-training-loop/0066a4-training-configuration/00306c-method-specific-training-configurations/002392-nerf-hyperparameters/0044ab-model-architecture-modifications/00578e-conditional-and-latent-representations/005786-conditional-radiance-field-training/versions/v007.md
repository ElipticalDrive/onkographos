# Conditional Radiance Field Training

Also called: Conditional NeRF, Instance-conditioned NeRF

## Overview
Conditional Radiance Field Training is a method for modeling shape and appearance variations across multiple 3D instances by training a single unified radiance field conditioned on instance-specific latent codes [S1]. It solves the problem of efficiently representing a dataset of diverse objects (e.g., chairs) without training separate NeRF models for each, while maintaining rendering quality comparable to independent per-instance models [S1]. It differs from sibling methods by explicitly decoupling shape and appearance into separate learned codes and utilizing a shared shape branch to enforce geometric consistency across instances [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A dataset of $K$ object instances. For each instance $k$, a set of training rays $R_k$ with corresponding ground truth colors $C(r)$. Two latent codes per instance: a shape code $\mathbf{z}_k^{(s)}$ and a color code $\mathbf{z}_k^{(c)}$.
*   **Output:** Rendered color $\hat{C}(r)$ for any ray $r$ given instance codes, and optimized network parameters.

**Data Structures:**
*   **Shape Code $\mathbf{z}_k^{(s)}$:** A 32-dimensional learned vector for instance $k$.
*   **Color Code $\mathbf{z}_k^{(c)}$:** A 32-dimensional learned vector for instance $k$.
*   **Coarse Network $F_{coarse}$:** An MLP with skip connections, taking positional encoding $\gamma(\mathbf{x})$, view direction $\gamma(\mathbf{d})$, shape code $\mathbf{z}_k^{(s)}$, and color code $\mathbf{z}_k^{(c)}$. Outputs density $\sigma$ and color $\mathbf{c}$.
*   **Fine Network $F_{fine}$:** An MLP with skip connections, taking the same inputs as $F_{coarse}$. Outputs color $\mathbf{c}$.
*   **Shared Shape Branch:** A component within the networks that processes the shape code $\mathbf{z}_k^{(s)}$ to influence geometry (density) predictions, shared across instances [S1].

**Numbered Steps:**
1.  **Initialization:** Initialize $F_{coarse}$, $F_{fine}$, and the set of shape codes $\{\mathbf{z}_k^{(s)}\}_{k=1}^K$ and color codes $\{\mathbf{z}_k^{(c)}\}_{k=1}^K$.
2.  **Instance Sampling:** For each training iteration, sample an object instance index $k$ uniformly from $\{1, \dots, K\}$.
3.  **Code Retrieval:** Retrieve the shape code $\mathbf{z}_k^{(s)}$ and color code $\mathbf{z}_k^{(c)}$ for the sampled instance $k$.
4.  **Ray Sampling:** Sample a batch of training rays $\{r\}$ from the set $R_k$ associated with instance $k$.
5.  **Coarse Network Forward Pass:**
    *   For each ray $r$, sample points using stratified sampling.
    *   Compute positional encoding $\gamma(\mathbf{x})$ and directional encoding $\gamma(\mathbf{d})$.
    *   Concatenate $\gamma(\mathbf{x})$, $\gamma(\mathbf{d})$, $\mathbf{z}_k^{(s)}$, and $\mathbf{z}_k^{(c)}$.
    *   Pass through $F_{coarse}$ to estimate density $\sigma$ and color $\mathbf{c}$.
    *   Render coarse color $\hat{C}_{coarse}(r, \mathbf{z}_k^{(s)}, \mathbf{z}_k^{(c)})$ using volume rendering with the estimated density.
6.  **Hierarchical Sampling:** Use the density outputs from $F_{coarse}$ to sample a hierarchical volume of points for the fine network.
7.  **Fine Network Forward Pass:**
    *   For each ray $r$, pass the hierarchical samples through $F_{fine}$ using the same concatenated inputs.
    *   Render fine color $\hat{C}_{fine}(r, \mathbf{z}_k^{(s)}, \mathbf{z}_k^{(c)})$.
8.  **Loss Calculation:** Compute the photometric loss for the batch:
    $$
    L_{train} = \sum_{k=1}^{K} \sum_{r \in R_k} \left( \|\hat{C}_{coarse}(r, \mathbf{z}_k^{(s)}, \mathbf{z}_k^{(c)}) - C(r)\|_2^2 + \|\hat{C}_{fine}(r, \mathbf{z}_k^{(s)}, \mathbf{z}_k^{(c)}) - C(r)\|_2^2 \right)
    $$
9.  **Optimization:** Update network parameters and codes $\mathbf{z}_k^{(s)}, \mathbf{z}_k^{(c)}$ using the Adam optimizer.

**Formulas:**
*   **Positional Encoding:** $\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]$ [Parent].
*   **Training Loss:** $L_{train} = \sum_{k=1}^{K} \sum_{r \in R_k} (\|\hat{C}_{coarse}(r, \mathbf{z}_k^{(s)}, \mathbf{z}_k^{(c)}) - C(r)\|_2^2 + \|\hat{C}_{fine}(r, \mathbf{z}_k^{(s)}, \mathbf{z}_k^{(c)}) - C(r)\|_2^2)$ [S1].

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $10^{-4}$ for training [S1].
*   **Beta1:** 0.9 [S1].
*   **Beta2:** 0.999 [S1].
*   **Epsilon:** $10^{-8}$ [S1].
*   **Training Duration:** Until convergence, averaging 1M iterations [S1].
*   **Code Dimension:** 32 dimensions for both shape and color codes [S1].
*   **Network Width:** Layer width increased in ablations to keep parameter count approximately equal across experiments [S1].

**Edge Cases and Pitfalls:**
*   **Precision:** Standard float32 is implied by the use of standard NeRF baselines [S1].
*   **Boundaries:** The method assumes foreground/background separation is handled similarly to the baseline NeRF [S1].
*   **Degenerate Input:** If an instance has no training rays, it cannot be optimized; the method requires a valid set $R_k$ for each $k$ [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.optim as optim

class ConditionalNeRF:
    def __init__(self, K, code_dim=32, lr=1e-4):
        """
        K: Number of instances
        code_dim: Dimensionality of shape and color codes
        """
        # Initialize networks (architecture details like skip connections omitted for brevity)
        self.F_coarse = CoarseNetwork()
        self.F_fine = FineNetwork()
        
        # Learnable codes for each instance
        self.shape_codes = nn.Parameter(torch.randn(K, code_dim))
        self.color_codes = nn.Parameter(torch.randn(K, code_dim))
        
        self.optimizer = optim.Adam(
            list(self.F_coarse.parameters()) + 
            list(self.F_fine.parameters()) + 
            [self.shape_codes, self.color_codes],
            lr=lr,
            betas=(0.9, 0.999),
            eps=1e-8
        )
        
    def forward(self, rays, instance_indices):
        """
        rays: Tensor of shape (batch_size, 3) containing ray origins and directions
        instance_indices: Tensor of shape (batch_size,) containing instance IDs k
        """
        # Get codes for the batch
        shape_codes = self.shape_codes[instance_indices]
        color_codes = self.color_codes[instance_indices]
        
        # Encode positions and directions
        # Note: gamma function implementation assumed from Parent article
        pos_enc = positional_encoding(rays[:, :3])
        dir_enc = positional_encoding(rays[:, 3:])
        
        # Concatenate inputs: pos, dir, shape_code, color_code
        # The exact concatenation order and injection points are defined in [S1]
        inputs = torch.cat([pos_enc, dir_enc, shape_codes, color_codes], dim=-1)
        
        # Sample points for coarse network
        coarse_points, coarse_weights = sample_stratified(rays, self.F_coarse)
        
        # Render coarse color
        coarse_colors = render_volume(coarse_points, coarse_weights, self.F_coarse, inputs)
        
        # Sample hierarchical points using coarse density
        fine_points, fine_weights = sample_hierarchical(coarse_points, coarse_weights, self.F_fine)
        
        # Render fine color
        fine_colors = render_volume(fine_points, fine_weights, self.F_fine, inputs)
        
        return coarse_colors, fine_colors

    def train_step(self, rays, ground_truth_colors, instance_indices):
        self.optimizer.zero_grad()
        
        coarse_pred, fine_pred = self.forward(rays, instance_indices)
        
        # Photometric loss
        loss_coarse = torch.mean((coarse_pred - ground_truth_colors) ** 2)
        loss_fine = torch.mean((fine_pred - ground_truth_colors) ** 2)
        
        loss = loss_coarse + loss_fine
        loss.backward()
        self.optimizer.step()
        
        return loss.item()
```

## Operating characteristics
*   **Time Complexity:** Training time is proportional to the number of instances $K$ and the number of iterations (avg 1M) [S1]. Each iteration processes a batch of rays from one instance.
*   **Memory Complexity:** Memory usage scales with $K$ due to the storage of $2K$ latent codes (shape and color) [S1]. The network parameters are shared, so memory does not scale linearly with $K$ for the MLPs.
*   **Measured Performance:** On the PhotoShapes dataset, the method matches the performance of training independent NeRF models for each instance in terms of PSNR and LPIPS [S1].
*   **Scaling:** The method scales well to more training instances; experiments were conducted with all 626 instances of the PhotoShapes dataset [S1].
*   **Strengths:** Efficiently models shape and appearance differences across instances; avoids training separate models; generalizes to unseen views [S1].
*   **Limitations:** Requires a dataset of multiple instances; performance depends on the quality of the learned codes [S1].
*   **When to use:** When you have a dataset of multiple similar objects (e.g., chairs) and want a single model to represent them all efficiently.
*   **When not to use:** When you have only a single instance or no shared structure between instances.

## Background
The method was introduced in "Editing Conditional Radiance Fields" (2021) [S1]. It builds on the original NeRF architecture [45] and extends it to handle multiple instances by learning instance-specific codes. The method was evaluated on the PhotoShapes and Aubry chairs datasets [S1].
