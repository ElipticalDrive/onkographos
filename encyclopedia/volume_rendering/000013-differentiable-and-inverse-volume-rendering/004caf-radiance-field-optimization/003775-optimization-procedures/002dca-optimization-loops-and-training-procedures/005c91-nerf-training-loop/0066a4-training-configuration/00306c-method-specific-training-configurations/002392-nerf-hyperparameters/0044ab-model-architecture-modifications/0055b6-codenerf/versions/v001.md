# CodeNeRF

Also called: Disentangled Neural Radiance Fields for Object Categories

## Overview
CodeNeRF is an implicit 3D neural representation that learns the variation of object shapes and textures across a semantic category, enabling the synthesis of novel views of unseen objects from a single unposed input image [S1]. Unlike standard NeRF which is scene-specific, CodeNeRF disentangles shape and texture by learning separate latent embeddings, allowing for one-shot reconstruction and explicit editing of object geometry and appearance [S1]. It sets itself apart from siblings like [DoF-NeRF](9432-dof-nerf.md) or [NeRF-VPT](11770-nerf-vpt.md) by jointly optimizing camera pose, shape code, and texture code at inference time without requiring known camera parameters, whereas many alternatives assume fixed or known poses [S1].

## How it works
CodeNeRF uses an auto-decoder architecture with decoupled shape and texture embedding spaces [S1]. The model consists of two Multi-Layer Perceptrons (MLPs), $F^s_{\Theta_s}$ and $F^t_{\Theta_t}$, which share weights $\Theta$ but process different inputs to predict volume density and color [S1].

**Inputs and Outputs:**
*   **Training Inputs:** A set of $N$ images $\mathcal{V} = \{I_i, K_i, T_i\}_{i=1}^N$ depicting $M$ objects with known poses (intrinsic $K_i$ and extrinsic $T_i$) [S1].
*   **Inference Input:** A single unposed reference image $I_{test}$ of an unseen object [S1].
*   **Outputs:** Rendered pixel colors $\hat{C}(r)$, volume density $\sigma$, and RGB color $\mathbf{c}$ [S1].

**Data Structures:**
1.  **Network Weights $\Theta$:** Parameters for the MLPs $F^s_{\Theta_s}$ and $F^t_{\Theta_t}$ [S1].
2.  **Shape Embeddings $\{\mathbf{z_s}^j\}_{j=1}^M$:** A latent vector for each object in the training set, representing its shape [S1].
3.  **Texture Embeddings $\{\mathbf{z_t}^j\}_{j=1}^M$:** A latent vector for each object in the training set, representing its texture [S1].
4.  **Camera Parameters (Inference):** Azimuth $\phi$, elevation $\theta$, and distance $\rho$ [S1].

**Positional Encoding:**
The model uses positional encoding $\gamma(\cdot)$ for 3D coordinates $\mathbf{x}$ and viewing directions $\mathbf{d}$ [S1].
$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$
*   Frequencies for $\mathbf{x}$: 10 [S1].
*   Frequencies for $\mathbf{d}$: 4 [S1].

**Network Architecture:**
The shape network $F^s_{\Theta_s}$ takes the positional encoded position $\gamma(\mathbf{x})$ and the shape code $\mathbf{z_s}$ to output volume density $\sigma$ and an intermediate feature vector $\mathbf{v} \in \mathbb{R}^{256}$ [S1]:
$$
F^s_{\Theta_s}: (\gamma_{\mathbf{x}}(\mathbf{x}), \mathbf{z_s}) \xrightarrow{} (\sigma, \mathbf{v})
$$
The texture network $F^t_{\Theta_t}$ takes the feature vector $\mathbf{v}$, the positional encoded viewing direction $\gamma_{\mathbf{d}}(\mathbf{d})$, and the texture code $\mathbf{z_t}$ to output the RGB color $\mathbf{c}$ [S1]:
$$
F^t_{\Theta_t}: (\mathbf{v}, \gamma_{\mathbf{d}}(\mathbf{d}), \mathbf{z_t}) \xrightarrow{} (\mathbf{c})
$$
The full radiance field is $F_{\Theta} = F^t_{\Theta_t} \circ F^s_{\Theta_s}$ [S1].

**Volume Rendering:**
Color is aggregated using standard volumetric rendering [S1]. For a camera ray $r(t) = \mathbf{c} + t\mathbf{d}$, $N$ uniform samples are taken from near to far bounds [S1]. The estimated color $\hat{C}(r)$ is:
$$
\hat{C}(r) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i
$$
where $\delta_i = t_{i+1} - t_i$ and $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ [S1].

**Training Procedure:**
1.  For each image in the training set, sample a batch of 4094 rays using known intrinsic and extrinsic parameters [S1].
2.  Sample 64 points along each ray [S1].
3.  For each point, retrieve the object's shape code $\mathbf{z_s}$ and texture code $\mathbf{z_t}$ [S1].
4.  Compute $\sigma$ and $\mathbf{c}$ using $F_{\Theta}$ [S1].
5.  Render the image using volume rendering [S1].
6.  Compute the loss $\mathcal{L}$ and update $\Theta$, $\{\mathbf{z_s}^j\}$, and $\{\mathbf{z_t}^j\}$ using AdamW [S1].

**Inference Procedure:**
1.  Given a single unposed image $I_{test}$, initialize $\mathbf{z_s}$ and $\mathbf{z_t}$ with the mean vector of the trained embeddings [S1].
2.  Initialize camera parameters $\phi, \theta, \rho$ [S1].
3.  Optimize $\mathbf{z_s}, \mathbf{z_t}, \phi, \theta, \rho$ jointly by minimizing the photometric loss while keeping $\Theta$ fixed [S1].
4.  Run optimization for 299 iterations [S1].
5.  Use the optimized codes and pose to render novel views [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np

# Positional Encoding Function
def positional_encoding(x, num_frequencies):
    """
    Applies positional encoding to input x.
    x: tensor of shape (..., D)
    num_frequencies: int
    Returns: tensor of shape (..., D + 2*D*num_frequencies)
    """
    # x is expected to be in range [-1, 1] or similar, but standard NeRF PE
    # assumes input scaling. The formula in [S1] implies standard sine/cosine
    # scaling by powers of 2.
    scales = 2.0 ** torch.arange(num_frequencies, device=x.device)
    scaled_x = x.unsqueeze(-1) * scales.unsqueeze(0) # Shape (..., D, num_freq)
    scaled_x = scaled_x.view(*x.shape[:-1], -1)      # Shape (..., D*num_freq)
    pe = torch.cat([torch.sin(scaled_x), torch.cos(scaled_x)], dim=-1)
    return torch.cat([x, pe], dim=-1)

class CodeNeRF(nn.Module):
    def __init__(self, shape_dim=256, texture_dim=256, feature_dim=256):
        super().__init__()
        # Shape Network: Input (pos_x, z_s) -> (sigma, v)
        # pos_x dim: 3 + 2*3*10 = 63
        # z_s dim: shape_dim
        self.shape_net = nn.Sequential(
            nn.Linear(63 + shape_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 1 + feature_dim) # sigma (1) + v (feature_dim)
        )
        
        # Texture Network: Input (v, pos_d, z_t) -> (c)
        # v dim: feature_dim
        # pos_d dim: 3 + 2*3*4 = 27
        # z_t dim: texture_dim
        self.texture_net = nn.Sequential(
            nn.Linear(feature_dim + 27 + texture_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 3) # RGB color
        )

    def forward(self, x, d, z_s, z_t):
        """
        x: (N, 3) 3D points
        d: (N, 3) viewing directions
        z_s: (M, shape_dim) shape codes for M objects
        z_t: (M, texture_dim) texture codes for M objects
        object_ids: (N,) indices into z_s and z_t
        """
        # Note: In training, we pass object IDs to select the correct z_s/z_t
        # For simplicity in this pseudocode, we assume z_s and z_t are broadcasted
        # or indexed appropriately. Here we assume z_s and z_t are (N, dim)
        # corresponding to the N points.
        
        # Encode inputs
        pos_x = positional_encoding(x, 10)
        pos_d = positional_encoding(d, 4)
        
        # Shape Network
        shape_input = torch.cat([pos_x, z_s], dim=-1)
        shape_out = self.shape_net(shape_input)
        sigma = shape_out[:, 0:1]
        v = shape_out[:, 1:]
        
        # Texture Network
        texture_input = torch.cat([v, pos_d, z_t], dim=-1)
        c = self.texture_net(texture_input)
        
        return sigma, c

def render_ray(rays_o, rays_d, z_s, z_t, model, num_samples=64, near=0.0, far=1.0):
    """
    Renders a batch of rays.
    rays_o: (B, 3) origins
    rays_d: (B, 3) directions (normalized)
    z_s: (B, shape_dim)
    z_t: (B, texture_dim)
    """
    t_vals = torch.linspace(near, far, num_samples)
    # Uniform sampling as per [S1]
    z_vals = t_vals
    
    # Points along ray: o + t * d
    points = rays_o.unsqueeze(1) + z_vals.unsqueeze(1) * rays_d.unsqueeze(1) # (B, N, 3)
    
    # Get sigma and c
    sigma, c = model(points, rays_d.unsqueeze(1).expand_as(points), z_s.unsqueeze(1), z_t.unsqueeze(1))
    
    # Compute deltas
    deltas = z_vals[:, 1:] - z_vals[:, :-1]
    # Add a small epsilon to avoid division by zero or log(0) issues if needed, 
    # though here we use exp(-sigma*delta)
    
    # Transmittance
    # alpha = 1 - exp(-sigma * delta)
    # T_i = exp(-sum_{j=1}^{i-1} sigma_j * delta_j)
    
    # Accumulate opacity
    sigma_delta = sigma[:, :-1] * deltas # (B, N-1)
    # Note: sigma is (B, N). We use N-1 deltas.
    # T_i calculation:
    # T_1 = 1
    # T_2 = exp(-sigma_1 * delta_1)
    # T_i = exp(-sum_{j=1}^{i-1} sigma_j * delta_j)
    
    # Cumulative sum of sigma * delta
    # We need to handle the first sample's contribution to the last term if we want N terms,
    # but standard NeRF rendering sums N terms.
    # Let's stick to the formula: C(r) = sum_{i=1}^N T_i (1 - exp(-sigma_i delta_i)) c_i
    # where delta_i = t_{i+1} - t_i. This implies N-1 intervals for N points?
    # [S1] says "N uniform samples". Usually this means N points.
    # If N points, there are N-1 intervals between them.
    # However, NeRF often adds a "last" sample or treats the last interval as extending to infinity.
    # [S1] Eq 3: sum_{i=1}^N. delta_i = t_{i+1} - t_i. This implies t_{N+1} exists.
    # Standard implementation: sample N points, assume last point is far enough or add a dummy.
    # Let's assume standard NeRF 2-stage or simple uniform:
    # We will sample N points. We need N deltas.
    # Let's assume the last delta is large or we just use N-1 deltas and N-1 colors?
    # [S1] text: "aggregates color ... at N uniform samples".
    # Formula: sum_{i=1}^N.
    # Let's implement the standard NeRF rendering with N samples and N-1 deltas, 
    # assuming the last sample contributes with T_N and alpha_N, and T_{N+1}=0.
    
    # Re-evaluating [S1] Eq 3: delta_i = t_{i+1} - t_i.
    # If we have N samples t_1...t_N, we have N-1 deltas.
    # The sum goes to N. This is slightly ambiguous without the "last sample" convention.
    # Standard NeRF (Knapik et al / Mildenhall et al) uses N coarse samples, then N fine samples.
    # For uniform, we usually just use the N-1 intervals.
    # Let's assume the standard interpretation:
    # alpha_i = 1 - exp(-sigma_i * delta_i)
    # T_i = product_{j=1}^{i-1} (1 - alpha_j)
    # Color = sum_{i=1}^{N-1} T_i * alpha_i * c_i + T_N * c_N (assuming last sample is opaque or background)
    # Or simply: T_i = exp(-sum_{j=1}^{i-1} sigma_j delta_j).
    # C = sum_{i=1}^{N-1} T_i (1 - exp(-sigma_i delta_i)) c_i.
    # And we ignore the last sample's contribution to alpha compositing if we don't have t_{N+1}.
    # However, [S1] explicitly sums to N.
    # Let's assume t_{N+1} = far + small_epsilon or similar.
    
    # To be safe and consistent with [S1] Eq 3 which sums to N:
    # We will add a dummy sample at far + 1.0 to get N deltas.
    
    t_vals_full = torch.cat([t_vals, t_vals[:, -1:] + 1.0], dim=1) # (B, N+1)
    z_vals_full = t_vals_full
    deltas = z_vals_full[:, 1:] - z_vals_full[:, :-1] # (B, N)
    
    # sigma and c are (B, N)
    sigma_delta = sigma * deltas.unsqueeze(-1) # (B, N, 1) ? No, sigma is (B,N), deltas (B,N)
    sigma_delta = sigma * deltas # (B, N)
    
    # T_i = exp(-sum_{j=1}^{i-1} sigma_j delta_j)
    # Cumsum of sigma_delta
    cum_sigma_delta = torch.cumsum(sigma_delta, dim=1) # (B, N)
    # T_i corresponds to sum up to i-1.
    # T_1 = exp(0) = 1
    # T_2 = exp(-sigma_1 delta_1)
    # We can shift cum_sigma_delta
    T = torch.exp(torch.cat([torch.zeros_like(cum_sigma_delta[:, 0:1]), cum_sigma_delta[:, :-1]], dim=1)) # (B, N)
    
    alpha = 1.0 - torch.exp(-sigma_delta) # (B, N)
    
    weights = T * alpha # (B, N)
    color = torch.sum(weights.unsqueeze(-1) * c, dim=1) # (B, 3)
    
    return color

def train_step(model, rays_o, rays_d, gt_colors, z_s, z_t, optimizer, nu=1.0):
    optimizer.zero_grad()
    
    # Render
    pred_colors = render_ray(rays_o, rays_d, z_s, z_t, model)
    
    # Photometric Loss
    photometric_loss = torch.mean((pred_colors - gt_colors) ** 2)
    
    # Regularization Loss on latent vectors
    reg_loss = (1.0 / (nu ** 2)) * (torch.mean(z_s ** 2) + torch.mean(z_t ** 2))
    
    loss = photometric_loss + reg_loss
    loss.backward()
    optimizer.step()
    
    return loss.item()

def inference_optimize(model, image, H, W, K, T_init, num_iters=299, lr_z=1e-2, lr_cam=1e-2):
    """
    Optimizes z_s, z_t, and camera pose for a single image.
    """
    # 1. Initialize latent codes with mean of trained embeddings
    # Assuming model has access to mean_z_s and mean_z_t from training
    z_s = model.mean_z_s.clone().detach().requires_grad_(True)
    z_t = model.mean_z_t.clone().detach().requires_grad_(True)
    
    # 2. Initialize camera pose
    # T_init is the initial extrinsic matrix (4x4)
    # Parameters: azimuth, elevation, distance
    # We optimize these parameters to reconstruct T
    # Simplified: Optimize T directly or its parameters. 
    # [S1] optimizes azimuth, elevation, distance.
    # Let's assume we have a function to convert (phi, theta, rho) to T.
    # For pseudocode, we optimize T directly for simplicity, or assume parameters.
    # Let's optimize T directly as a 4x4 matrix, constrained to be a valid camera matrix?
    # [S1] says "optimize the rotation and translation".
    # We'll optimize the pose parameters.
    
    # Initialize pose parameters
    # T_init provides a starting point.
    # Let's assume we extract phi, theta, rho from T_init or initialize randomly.
    # [S1] says initializations had rotation errors > 30 deg.
    # We'll just optimize T directly for the sake of the algorithm description,
    # noting that [S1] uses spherical coordinates.
    
    # To be precise to [S1]:
    # Optimize phi, theta, rho.
    # Initial values from T_init or random.
    # Learning rates: 1e-2, 1e-1, 1e-1.
    
    # For this pseudocode, we will optimize the extrinsic matrix T directly 
    # to keep it self-contained, but note the specific LR per parameter in [S1].
    T_opt = T_init.clone().detach().requires_grad_(True)
    
    optimizer_z = optim.Adam([z_s, z_t], lr=lr_z)
    optimizer_cam = optim.Adam([T_opt], lr=1e-2) # Simplified LR
    
    for i in range(num_iters):
        # 1. Generate rays from current camera pose T_opt
        # Function to generate rays from image coordinates and camera matrix
        rays_o, rays_d = generate_rays_from_image(K, T_opt, H, W)
        
        # 2. Render
        pred_colors = render_ray(rays_o, rays_d, z_s, z_t, model)
        
        # 3. Compute Loss (Photometric only, no reg on z during inference? 
        # [S1] Eq 5 shows reg term in inference loss too: min L + 1/nu^2 (||zs||^2 + ||zt||^2))
        # So we keep regularization.
        
        # Flatten gt image to match ray order
        gt_colors_flat = image.view(-1, 3)
        
        photometric_loss = torch.mean((pred_colors - gt_colors_flat) ** 2)
        reg_loss = (1.0 / (nu ** 2)) * (torch.mean(z_s ** 2) + torch.mean(z_t ** 2))
        
        loss = photometric_loss + reg_loss
        
        optimizer_z.zero_grad()
        optimizer_cam.zero_grad()
        
        loss.backward()
        
        optimizer_z.step()
        optimizer_cam.step()
        
    return z_s, z_t, T_opt

# Helper to generate rays (Standard pinhole camera)
def generate_rays_from_image(K, T, H, W):
    """
    K: (3, 3) Intrinsic
    T: (4, 4) Extrinsic (World to Camera)
    Returns rays_o (B, 3), rays_d (B, 3)
    """
    # Pixel coordinates
    u, v = torch.meshgrid(torch.arange(W), torch.arange(H), indexing='ij')
    u = u.float().view(-1)
    v = v.float().view(-1)
    
    # Homogeneous pixel coordinates
    pixels = torch.stack([u, v, torch.ones_like(u)], dim=1) # (H*W, 3)
    
    # Intrinsic inverse
    K_inv = torch.inverse(K)
    
    # Ray directions in camera space
    dirs_cam = (K_inv @ pixels.T).T # (H*W, 3)
    dirs_cam = dirs_cam / torch.norm(dirs_cam, dim=1, keepdim=True)
    
    # Ray origins in camera space are (0,0,0)
    origins_cam = torch.zeros_like(dirs_cam)
    
    # Transform to world space
    # T is World -> Camera. We need Camera -> World.
    # T_world_cam = T
    # T_cam_world = T^{-1}
    T_cam_world = torch.inverse(T)
    
    # Rotate directions
    R = T_cam_world[:3, :3]
    t = T_cam_world[:3, 3]
    
    rays_d = (R @ dirs_cam.T).T
    rays_o = (R @ origins_cam.T).T + t
    
    return rays_o, rays_d
```

**Parameters:**
*   **Positional Encoding Frequencies:** 10 for $\mathbf{x}$, 4 for $\mathbf{d}$ [S1].
*   **Training Learning Rates:**
    *   Network weights $\Theta$: $10^{-4}$ [S1].
    *   Latent vectors $\mathbf{z_s}, \mathbf{z_t}$: $10^{-3}$ [S1].
*   **Inference Learning Rates:**
    *   Latent vectors $\mathbf{z_s}, \mathbf{z_t}$: $10^{-2}$ [S1].
    *   Camera azimuth $\phi$: $10^{-2}$ [S1].
    *   Camera elevation $\theta$: $10^{-1}$ [S1].
    *   Camera distance $\rho$: $10^{-1}$ [S1].
*   **Training Batch Size:** 4094 rays per image [S1].
*   **Samples per Ray:** 64 [S1].
*   **Inference Iterations:** 299 [S1].
*   **Regularization Weight:** $\nu$ (value not given in sources) [S1].

**Edge Cases and Pitfalls:**
*   **Camera Pose Initialization:** Initial camera pose estimates can have rotation errors above 30 degrees (average 80 degrees) [S1]. The optimization converges in 85% of cases despite this [S1].
*   **Disentanglement Failure:** If the architecture is modified to input view direction into the shape network (M1) or use a single embedding for shape and texture (M2), disentanglement fails, leading to incorrect textures or unwanted shape changes during editing [S1].

## Operating characteristics
*   **Time Complexity:** Training requires optimizing network weights and latent codes for all objects. Inference requires iterative optimization (299 iterations) per unseen object to find latent codes and camera pose [S1].
*   **Memory Complexity:** Stores latent codes for each object in the category ($M$ objects) [S1].
*   **Performance:** On the ShapeNet-SRN benchmark, CodeNeRF achieves competitive PSNR and SSIM scores for novel view synthesis and few-shot reconstruction [S1].
*   **Strengths:** Enables one-shot reconstruction from a single unposed image; allows explicit editing of shape and texture; disentangles shape and texture effectively [S1].
*   **Limitations:** Requires iterative optimization at inference time; convergence is not guaranteed (85% success rate) [S1].

## Background
CodeNeRF was introduced in 2021 by [S1]. It builds on the original NeRF [S1] and draws inspiration from SRN [S1] and DeepSDF [S1]. It addresses the limitation of NeRF being scene-specific by learning a category-level representation [S1].
