# Voxel-based Radiance Fields

Also called: Voxel NeRF, Voxel Radiance Fields

## Overview
Voxel-based Radiance Fields replace the multi-layer perceptron (MLP) coordinate mapping of standard NeRF with explicit 3D voxel grids to store volume density and spherical harmonic (SH) coefficients, enabling real-time differentiable volume rendering [S1]. Unlike MLP-based approaches that require heavy feed-forward computation for every sample point, this method computes color directly from interpolated grid values, significantly reducing latency while maintaining memory efficiency through sparse reconstruction strategies [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D sample point location $\mathbf{X}_k$ and viewing direction $\mathbf{d}$ for the $k$-th sample on a ray.
*   **Output:** Volume density $\sigma_k$ and view-dependent color $\mathbf{c}_k$.

**Data Structures:**
The representation consists of two distinct voxel grids:
1.  **Density Grid ($G_\sigma$):** A 3D grid mapping $\mathbb{R}^3 \rightarrow \mathbb{R}$. Each voxel stores a single scalar value representing volume density.
2.  **SH Coefficient Grid ($G_{sh}$):** A 3D grid mapping $\mathbb{R}^3 \rightarrow \mathbb{R}^{9 \times 3}$. Each voxel stores a tensor of degree 2 spherical harmonic coefficients for RGB color. The dimension $9$ corresponds to the number of basis functions for degree 2 SH, and $3$ corresponds to the RGB channels.

**Retrieval and Interpolation:**
For any query point $\mathbf{X}_k$, features are retrieved via trilinear interpolation from the 8 nearest neighboring voxels in both grids [S1]. This operation is denoted as $\mathcal{G}_\sigma(\mathbf{X}_k)$ for density and $\mathcal{G}_{sh}(\mathbf{X}_k)$ for SH coefficients.

**Formulas:**
The volume density is computed directly from the density grid:
$$
\sigma_k = \mathcal{G}_\sigma(\mathbf{X}_k)
$$

The color is computed by projecting the viewing direction into SH space and dotting it with the interpolated SH coefficients:
$$
\mathbf{c}_k = S(\mathbf{d})^\intercal \cdot \mathcal{G}_{sh}(\mathbf{X}_k)
$$
Where:
*   $S(\mathbf{d}): \mathbb{R}^3 \rightarrow \mathbb{R}^9$ is the spherical harmonic function mapping the viewing direction $\mathbf{d}$ to a 9-dimensional vector of SH basis values.
*   $\mathcal{G}_{sh}(\mathbf{X}_k)$ returns the $9 \times 3$ matrix of interpolated SH coefficients.
*   The result $\mathbf{c}_k$ is a 3-dimensional RGB color vector.

**Rendering:**
The retrieved $\sigma_k$ and $\mathbf{c}_k$ are used in the standard differentiable volume rendering equation (as defined in the parent article) to compute the final pixel color $\hat{C}(r)$ [S1]. Gradients flow back through the trilinear interpolation and SH projection steps to update the voxel grid parameters.

**Training and Optimization:**
The method supports coarse-to-fine sparse voxel reconstruction combined with a pruning strategy to enable memory-efficient training [S1]. This allows the representation to adaptively refine resolution in relevant areas while discarding empty or redundant voxels.

**Pseudocode:**
```python
def get_density_and_color(X_k, d, G_sigma, G_sh):
    """
    Retrieve density and color for a sample point using voxel grids.
    
    Args:
        X_k: 3D location (tensor of shape [3])
        d: Viewing direction (tensor of shape [3])
        G_sigma: Density grid (trilinear interpolator mapping R3->R)
        G_sh: SH coefficient grid (trilinear interpolator mapping R3->R^{9x3})
        
    Returns:
        sigma_k: Volume density (scalar)
        c_k: Color (tensor of shape [3])
    """
    # 1. Retrieve density via trilinear interpolation from G_sigma
    sigma_k = G_sigma.interpolate(X_k)
    
    # 2. Retrieve SH coefficients via trilinear interpolation from G_sh
    # Returns a matrix of shape [9, 3]
    sh_coeffs = G_sh.interpolate(X_k)
    
    # 3. Compute SH basis vector for direction d
    # S(d) maps R3 -> R9
    sh_basis = compute_sh_basis(d, degree=2)
    
    # 4. Compute color by dotting SH basis with coefficients
    # c_k = S(d)^T * sh_coeffs
    c_k = sh_basis @ sh_coeffs
    
    return sigma_k, c_k

def compute_sh_basis(d, degree):
    """
    Compute spherical harmonic basis vector for a given direction.
    For degree 2, this returns a 9-dimensional vector.
    Implementation details for SH basis calculation are standard mathematical
    functions of the spherical coordinates of d.
    """
    # Normalize direction
    d = d / torch.norm(d)
    
    # Convert to spherical coordinates (theta, phi)
    # theta: polar angle from z-axis, phi: azimuthal angle in xy-plane
    theta = torch.acos(d[2])
    phi = torch.atan2(d[1], d[0])
    
    # Compute degree 2 SH basis functions
    # The 9 basis functions for degree 2 are standard formulas involving
    # sin(theta), cos(theta), sin(phi), cos(phi).
    # This is a standard mathematical computation, not a learned parameter.
    basis = [
        0.282095,
        -0.488603 * d[1],
        0.488603 * d[2],
        -0.488603 * d[0],
        1.092548 * d[0] * d[1],
        -1.092548 * d[1] * d[2],
        0.315392 * (3 * d[2]**2 - 1),
        -1.092548 * d[0] * d[2],
        0.546274 * (d[0]**2 - d[1]**2)
    ]
    return torch.tensor(basis)
```

## Operating characteristics
*   **Performance:** Achieves real-time volume rendering by eliminating the heavy computation of fully-connected layers required by MLP-based NeRF [S1].
*   **Memory Efficiency:** Limits learnable parameters to the values stored in the voxel grid. Sparse voxel reconstruction and pruning strategies further reduce memory usage compared to dense grids [S1].
*   **Scalability:** Suitable for optimization tasks such as blurred view reconstruction, where memory constraints and rendering speed are critical [S1].
*   **Limitations:** Resolution is discrete and tied to the grid size. High-frequency details may require very fine grids, which can increase memory usage if sparsity is not effectively managed.

## Background
Voxel-based Radiance Fields were introduced as a memory-efficient alternative to the original NeRF [29] by replacing the implicit MLP representation with explicit voxel grids [S1]. This approach leverages the differentiable volume rendering framework of NeRF but optimizes for computational efficiency by using trilinear interpolation and spherical harmonics for view-dependent color [S1]. The method has been applied to problems such as extreme motion blur reconstruction (ExBluRF), demonstrating its utility in scenarios requiring efficient optimization and rendering [S1].
