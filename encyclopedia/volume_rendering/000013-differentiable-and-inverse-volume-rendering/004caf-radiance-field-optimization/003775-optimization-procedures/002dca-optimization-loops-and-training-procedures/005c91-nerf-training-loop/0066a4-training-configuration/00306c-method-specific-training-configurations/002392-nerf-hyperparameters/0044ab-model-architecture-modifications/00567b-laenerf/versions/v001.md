# LAENeRF
Also called: Local Appearance Editing for Neural Radiance Fields

## Overview
LAENeRF is a unified framework for the photorealistic and non-photorealistic local appearance editing of pre-trained Neural Radiance Fields (NeRFs) [S1]. It solves the problem of recoloring or stylizing arbitrary 3D regions while minimizing background artifacts and maintaining interactivity [S1]. Unlike methods that rely on semantic segmentation masks or single-target colors, LAENeRF learns a palette-based color decomposition within a user-selected region, enabling smooth transitions to the original scene content [S1]. It sets itself apart by estimating per-ray termination points to define the editable region, reducing memory requirements compared to voxel-based approaches, and introducing geometry-aware losses to preserve small structures during stylization [S1].

## How it works
LAENeRF operates on a pre-trained NeRF $\Theta_{NeRF}$ (typically Instant-NGP based [S1]). The method consists of three phases: Region Selection, LAENeRF Module Optimization, and Distillation/Transfer [S1].

### Inputs and Outputs
*   **Inputs:** Pre-trained NeRF $\Theta_{NeRF}$, training images $\mathcal{C}$, camera poses, user 2D scribble mask on a reference view, optional style image $s$ (for stylization).
*   **Outputs:** Edited NeRF parameters $\Theta'_{NeRF}$, or a trained LAENeRF module with parameters $\Theta_{LAENeRF}$ and palette $\hat{P}$ for interactive editing.

### Data Structures
1.  **Edit Grid ($E$):** A 3D voxel grid of resolution $128^3$ [S1]. It uses a bitfield where bits are set to 1 for voxels intersecting the selected region. It is a subset of the Instant-NGP occupancy grid [S1].
2.  **Growing Queue ($G$):** A queue storing direct neighbors of voxels in $E$ to facilitate smooth transitions [S1].
3.  **Growing Grid ($\mathcal{G}$):** A 3D grid constructed from $G$ used to compute transition weights [S1].
4.  **LAENeRF Module:** A lightweight neural network consisting of:
    *   **Hash Grid Encoder:** A trainable multi-resolution hash grid (from Instant-NGP [S1]) encoding input positions $\xi(x_{term})$.
    *   **Weight MLP:** Takes $\xi(x_{term})$ and outputs per-ray barycentric weights $\hat{w} \in [0, 1]^{N_{\hat{P}}}$ [S1].
    *   **Offset MLP:** Takes $\xi(x_{term})$ and spherical harmonics encoded view direction $\gamma(d)$ to output view-dependent offsets $\hat{\delta} \in [-1, 1]^3$ [S1].
5.  **Color Palette ($\hat{P}$):** A learnable matrix $\hat{P} \in \mathbb{R}^{N_{\hat{P}} \times 3}$, where $N_{\hat{P}}$ is the number of base colors [S1].

### Numbered Steps

#### 1. Region Selection
1.  User scribbles on a 2D projection of the scene.
2.  For each selected pixel, cast a ray $r$ from camera position $o$ in direction $d$.
3.  Raymarch through the original NeRF $\Theta_{NeRF}$ and the occupancy grid $O$ to compute estimated depth $\zeta$ and accumulated alpha $T_\alpha$ inside the edit grid $E$.
    *   **Estimated Depth:**
        $$ \zeta = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) t_{i+1} $$
        where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$, $\sigma_i$ is density, $\delta_i = t_{i+1} - t_i$, and $t_i$ are sample positions [S1].
    *   **Ray Termination:**
        $$ x_{term} = o + \zeta d $$
    *   **Accumulated Alpha in Edit Grid:**
        $$ T_\alpha = \sum_{i=1}^{N} \mathbbm{1}(o + t_i d \in E) T_i (1 - \exp(-\sigma_i \delta_i)) $$
        where $\mathbbm{1}(\cdot)$ is the indicator function [S1].
4.  If $T_\alpha > \tau_{edit}$ (default $\tau_{edit} = 0.5$), map $x_{term}$ to the nearest voxel in $E$ and set its bit to 1 [S1].
5.  **Region Growing:** Initialize a queue $G$ with neighbors of selected voxels. While $G$ is not empty:
    *   Pop voxel $v$ from $G$.
    *   If occupancy grid $O$ at $v$ is set ($O=1$):
        *   Add $v$ to $E$ (set bit to 1).
        *   Add neighbors of $v$ to $G$ [S1].

#### 2. LAENeRF Module Optimization
1.  **Featurization:** For each ray $r$ intersecting $E$, compute $x_{term}$ as in Step 1. Encode $x_{term}$ using the hash grid to get $\xi(x_{term})$ [S1].
2.  **Prediction:**
    *   Compute weights $\hat{w} = \text{MLP}_w(\xi(x_{term}))$.
    *   Encode view direction $d$ using spherical harmonics $\gamma(d)$ [S1].
    *   Compute offsets $\hat{\delta} = \text{MLP}_\delta(\xi(x_{term}), \gamma(d))$ [S1].
    *   Compose predicted color:
        $$ \hat{c} = \text{clamp}(\hat{w}^T \hat{P} + \hat{\delta}) $$
        where $\text{clamp}(\cdot)$ restricts values to $[0, 1]$ [S1].
3.  **Loss Calculation:** Minimize the following losses with respect to $\Theta_{LAENeRF}$ and $\hat{P}$:
    *   **Content Loss:**
        $$ L_{content} = \|\hat{c} - \mathcal{C}(r)\|_2^2 $$
        where $\mathcal{C}(r)$ is the ground truth color [S1].
    *   **Style Loss (Optional):**
        $$ L_{style} = \lambda_{style} \|G(s) - G(\hat{c})\|_2^2 $$
        where $G(\cdot)$ is the Gram matrix of features from a semantic encoder (e.g., VGG19 conv5, conv6, conv7 [S1]) and $s$ is the style image. Set $\lambda_{style}=0$ for photorealistic recoloring [S1].
    *   **Total Variation Loss (Geometry-Aware):**
        $$ L_{TV} = \lambda_{TV} \|\nabla \hat{c} \cdot (1 - \text{depth\_guide})\|_2^2 $$
        where $\nabla \hat{c}$ is the image gradient of $\hat{c}$, and $\text{depth\_guide}_{i,j} = (|\text{depth}_{i,j+1} - \text{depth}_{i,j}|, |\text{depth}_{i+1,j} - \text{depth}_{i,j}|)$ [S1].
    *   **Depth Discontinuity Loss:**
        $$ L_{depth-disc} = -\lambda_{depth-disc} \|\nabla \hat{c} \cdot \text{depth\_guide}\|_2^2 $$
        This encourages gradients at depth discontinuities [S1].
    *   **Offset Loss:**
        $$ L_{offset} = \lambda_{offset} \|\hat{\delta}\|_2^2 $$
        Prevents extreme high-frequency offset solutions [S1].
    *   **Palette Regularization:**
        $$ L_{palette} = \|\lfloor \hat{P} \rfloor \cdot \hat{P}\|_2^2 $$
        Ensures $\hat{P}_{i,j} \in [0, 1]$ [S1].
    *   **Weight Loss:**
        $$ L_{weight} = \lambda_{weight} (1 - \|\hat{w}\|_\infty) $$
        Encourages sparse per-pixel predictions [S1].
    *   **Smooth Transition Loss (Optional):**
        Compute minimum distance $d_{min}$ from $x_{term}$ to points in $\mathcal{G}$ (raymarched through $G$ and $O$).
        $$ d_{trans} = 1 - \frac{\min(d_{min}, \tau_{dist})}{\tau_{dist}} $$
        $$ L_{smooth} = \lambda_{smooth} \|(\hat{c} - c)^2 \cdot d_{trans}\|_1 $$
        where $c$ is the original NeRF color. This adds to $L_{content}$ when $d_{trans} \in (0, 1]$ to smooth boundaries [S1].
4.  **Palette Pruning:** After $1.5 \times 10^3$ iterations, remove palette entries that do not contribute significantly [S1].

#### 3. Distillation/Transfer
1.  Construct a modified training dataset. For each ray $r$:
    *   If $r$ intersects $E$, target color is $T_\alpha \hat{c} + (1 - T_\alpha) \mathcal{C}(r)$ [S1].
    *   If $r$ does not intersect $E$, target color is $\mathcal{C}(r)$ [S1].
2.  Fine-tune the original NeRF $\Theta_{NeRF}$ using this modified dataset for $7 \times 10^4$ iterations [S1].

### Parameters
*   **Edit Grid Resolution:** $128^3$ [S1].
*   **Edit Threshold ($\tau_{edit}$):** 0.5 [S1].
*   **Transition Size ($\tau_{dist}$):** $1 \times 10^{-2}$ [S1].
*   **Initial Palette Size ($N_{\hat{P}}$):** 8 [S1].
*   **Learning Rate:** $1 \times 10^{-3}$ for all components except $\hat{P}$ ($1 \times 10^{-2}$) [S1].
*   **Loss Weights (Stylization):** $\lambda_{style} = 1.3 \times 10^2$, $\lambda_{TV} = 1 \times 10^{-4}$, $\lambda_{depth-disc} = 5 \times 10^{-4}$, $\lambda_{weight} = 1 \times 10^{-7}$, $\lambda_{offset} = 5 \times 10^{-5}$, $\lambda_{smooth} = 1 \times 10^{-3}$ [S1].
*   **Loss Weights (Recoloring):** $\lambda_{style} = \lambda_{TV} = \lambda_{depth-disc} = 0$ [S1].
*   **Training Iterations:** $1 \times 10^5$ for LAENeRF, $7 \times 10^4$ for distillation [S1].

### Edge Cases and Pitfalls
*   **Occlusions:** Handled by requiring $T_\alpha > \tau_{edit}$ [S1].
*   **Small Structures:** Eliminated in naive stylization; mitigated by geometry-aware losses ($L_{TV}, L_{depth-disc}$) [S1].
*   **Sharp Discontinuities:** Occur at boundaries of $E$ if adjacent cells are occupied; mitigated by smooth transition loss $L_{smooth}$ using growing grid $\mathcal{G}$ [S1].
*   **Noise in $x_{term}$:** Caused by imperfect geometry reconstruction; mitigated by $L_{offset}$ and $L_{TV}$ [S1].
*   **Palette Pruning:** Non-contributing palette entries should be removed after $1.5 \times 10^3$ iterations [S1].

## Subtopics

### Geometry-Aware Stylization with Depth Estimation
A stylization technique that respects the learned geometry of the pre-trained NeRF by performing depth estimation to counteract the removal of small structures common in naive 2D style transfer [S1]. It uses depth-guided total variation and depth discontinuity losses to preserve geometric details [S1]. Implementation detail: Train LAENeRF without $L_{style}$, $L_{offset}$, and $L_{TV}$ for the first 1000 iterations to achieve a well-initialized palette $\hat{P}$ before applying these geometry-aware losses [S1].

## Operating characteristics
*   **Time Complexity:** The LAENeRF module is lightweight (shallow MLPs), allowing for interactive previews after ~20 seconds of training [S1]. Distillation takes no longer than 5 minutes on an NVIDIA RTX 4090 [S1].
*   **Memory Complexity:** Reduced compared to voxel-based methods because it operates on estimated ray termination points ($x_{term}$) rather than dense voxel grids for the editing module [S1].
*   **Performance:** Outperforms PaletteNeRF with semantic guidance by reducing background MSE error rates by 59% on the LLFF dataset [S1]. Introduces fewer background artifacts than Ref-NPR [S1].
*   **Strengths:** Interactive, supports both photorealistic recoloring and non-photorealistic stylization, smooth transitions, minimal background artifacts [S1].
*   **Limitations:** Requires a pre-trained NeRF. Performance depends on the quality of the initial geometry reconstruction [S1].
