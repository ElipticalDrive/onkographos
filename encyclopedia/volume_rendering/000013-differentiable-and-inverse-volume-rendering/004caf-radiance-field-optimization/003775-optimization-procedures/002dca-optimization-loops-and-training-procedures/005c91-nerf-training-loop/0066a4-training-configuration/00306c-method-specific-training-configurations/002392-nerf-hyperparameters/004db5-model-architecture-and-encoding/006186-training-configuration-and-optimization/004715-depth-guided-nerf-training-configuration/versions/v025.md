# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the hyperparameters, architectural modifications, and optimization settings for training a Neural Radiance Field (NeRF) model using depth priors to improve reconstruction quality [S1]. It distinguishes itself from standard NeRF training by explicitly integrating a depth loss term and modifying the network architecture to handle uncertainty in depth predictions [S1]. It builds on [Model Architecture and Encoding](13550-model-architecture-and-encoding.md).

## How it works
**Inputs:**
*   Training images with known camera poses.
*   Ground truth depth maps (optional but recommended for the depth loss component).
*   Scene-specific parameters: `max_depth` and `min_depth` for uncertainty thresholding [S1].

**Outputs:**
*   A trained NeRF model (MLP weights) capable of rendering color and depth.

**Data Structures:**
*   **NeRF Model:** Builds on the original NeRF architecture [S1].
    *   **Modifications:** Dropout layers with probability $p=0.1$ are added after each of the first eight fully connected ReLU-activated layers that encode the positional encoding [S1].
*   **Loss Function Components:**
    *   Color Loss: Standard pixel-wise difference between rendered and ground truth colors.
    *   Depth Loss: Weighted by $\lambda$.
    *   Uncertainty Loss: Weighted by $\gamma$.

**Parameters:**
*   **Depth Loss Weight ($\lambda$):** $0.007$ for all scenes, except scene 710 where it is $0.02$ [S1].
*   **Uncertainty Weight ($\gamma$):** $1$ [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate (Network):** $5 \times 10^{-4}$, reduced to $5 \times 10^{-5}$ after 80% of total steps [S1].
*   **Weight Decay:** $1 \times 10^{-6}$ [S1].
*   **Total Training Steps:** $500,000$ [S1].
*   **Depth Scale Learning Rate:** $1 \times 10^{-7}$ [S1].
*   **Uncertainty Threshold ($\tau$):** Calculated as $\tau = (\text{max\_depth} - \text{min\_depth}) \cdot 0.0001$ [S1].
    *   Example values for ScanNet: $\text{max\_depth} = 10$, $\text{min\_depth} = 0.001$ [S1].

**Algorithm:**
1.  **Initialize:** Load the NeRF model with positional encoding. Apply dropout layers ($p=0.1$) after the first 8 FC ReLU layers [S1].
2.  **Sample Rays:** For each training image, sample rays through pixels.
3.  **Forward Pass:**
    *   Encode 3D positions and viewing directions.
    *   Predict density $\sigma$ and color $\mathbf{c}$.
    *   Render color and depth along the ray using volume rendering equations.
4.  **Compute Loss:**
    *   Calculate color loss between rendered and ground truth colors.
    *   Calculate depth loss between rendered and ground truth depth.
    *   Calculate uncertainty loss based on the threshold $\tau$ [S1].
    *   Total Loss $L = L_{color} + \lambda L_{depth} + \gamma L_{uncertainty}$ [S1].
5.  **Update:**
    *   Compute gradients.
    *   Update network weights using Adam with LR $5 \times 10^{-4}$ and weight decay $1 \times 10^{-6}$ [S1].
    *   Update depth scale parameter with LR $1 \times 10^{-7}$ [S1].
6.  **Schedule:** Reduce network learning rate to $5 \times 10^{-5}$ after 80% of the 500,000 steps [S1].
7.  **Repeat:** Until 500,000 steps are completed [S1].

**Edge Cases and Pitfalls:**
*   **Scene 710:** Requires a higher depth loss weight ($\lambda = 0.02$) compared to other scenes ($\lambda = 0.007$) [S1].
*   **Uncertainty Threshold:** Must be computed per scene based on its specific depth range [S1].

## Subtopics

### DS-NeRF Depth Loss Integration
Integrates the depth loss implementation from the official DS-NeRF code base into the training pipeline [S2]. Due to missing configuration files for DTU in the official release and different train/test splits for LLFF in the original publication, re-training is performed on the specific train/test splits using the released configuration files [S2].

## Operating characteristics
*   **Time Complexity:** Determined by the number of training steps (500,000) and the cost of forward/backward passes through the modified MLP [S1].
*   **Memory Complexity:** Standard NeRF memory usage plus storage for depth maps and uncertainty calculations [S1].
*   **Strengths:** Improved depth accuracy and handling of uncertainty in depth predictions [S1].
*   **Limitations:** Requires ground truth depth maps for the depth loss component [S1]. Performance may vary across scenes (e.g., scene 710 requires different hyperparameters) [S1].
*   **When to use:** When depth accuracy is critical and ground truth depth data is available [S1].
*   **When not to use:** When depth data is unavailable or when computational resources are severely limited due to the additional loss computation [S1].

## Background
Originated from the work on Depth-Guided NeRF Training via Earth Mover’s Distance [S1]. The configuration is designed to enhance NeRF training by incorporating depth priors, addressing issues related to depth ambiguity in standard NeRF methods [S1]. It has been applied to datasets such as ScanNet and LLFF [S1, S2].
