# Training Setup and Baselines


## Overview
This family defines the specific hyperparameter configurations, optimization routines, and baseline protocols required to train neural radiance field representations. It addresses the problem of stabilizing convergence and maximizing reconstruction quality across diverse architectural choices, ranging from standard MLP-based NeRFs to sparse VDB structures and GAN-based generators. It differs from sibling articles by focusing on the *configuration* of the training process (learning rates, sampling strategies, regularization strengths) rather than the architectural components (encodings, samplers) or the loss functions themselves.

## Shared principles
All methods in this family share the core differentiable volume rendering loop as defined in [Training Loop Setup](1522-training-loop-setup.md). The fundamental optimization objective is typically the Mean Squared Error (MSE) between the rendered pixel color $\hat{\mathbf{C}}$ and the ground truth $\mathbf{C}_{gt}$:
$$ \mathcal{L} = \frac{1}{B} \sum_{k=1}^{B} \| \hat{\mathbf{C}}_k - \mathbf{C}_{gt, k} \|^2 $$
where $B$ is the batch size. The rendering equation for a ray $\mathbf{r}$ remains:
$$ \hat{\mathbf{C}}(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i $$
where $\sigma_i$ is volume density, $\mathbf{c}_i$ is color, $\delta_i$ is sample distance, and $T_i$ is accumulated transmittance.

## Subtopics

### [NeRF-GT Baseline Training Setup](11349-nerf-gt-baseline-training-setup.md)
A baseline protocol for training NeRFs using High Dynamic Range (HDR) input views to synthesize HDR novel views [11349-nerf-gt-baseline-training-setup.md]. It addresses the limitation of standard NeRF which uses Low Dynamic Range (LDR) inputs and cannot capture extreme lighting variations [11349-nerf-gt-baseline-training-setup.md]. Unlike standard LDR training, it explicitly models HDR radiance and applies tone-mapping during loss computation to compare against LDR ground truth [11349-nerf-gt-baseline-training-setup.md]. It is chosen when HDR scene reconstruction is required. See [NeRF-GT Baseline Training Setup](11349-nerf-gt-baseline-training-setup.md).

### [StyleGAN2 Training Configuration](12972-stylegan2-training-configuration.md)
Adapts the StyleGAN2 architecture for 3D-aware generative models (e.g., StyleNeRF, VoxGRAF) by optimizing a neural representation to minimize photometric differences [12972-stylegan2-training-configuration.md]. It distinguishes itself by incorporating StyleGAN2-specific stabilizers: equalized learning rates, minibatch standard deviation in the discriminator, exponential moving average (EMA) of generator weights, and sparse R1 regularization, while omitting path regularization and style-mixing [12972-stylegan2-training-configuration.md]. It is chosen for generative 3D synthesis. See [StyleGAN2 Training Configuration](12972-stylegan2-training-configuration.md).

### [NeRF Training Setup](13271-nerf-training-setup.md)
Describes the configuration for NeRF-based models using the Nerfstudio library, leveraging NerfAcc and Instant-NGP for fast convergence on static scenes [13271-nerf-training-setup.md]. It covers modifications such as replacing standard positional encoding with sampled feature vectors (Control-NeRF) [13271-nerf-training-setup.md]. It solves the problem of efficient optimization for static environments using two-stage sampling and specific input representations [13271-nerf-training-setup.md]. It differs from standard NeRF by using feature volumes instead of raw positional encoding for density network input [13271-nerf-training-setup.md]. It is chosen for efficient static scene reconstruction. See [NeRF Training Setup](13271-nerf-training-setup.md).

### [NLR Baseline](15254-nlr-baseline.md)
Represents a scene using a set of learned basis functions (volumetric primitives) rather than a single monolithic MLP [15254-nlr-baseline.md]. It solves the problem of efficient novel view synthesis by optimizing basis coefficients to minimize photometric error [15254-nlr-baseline.md]. It is distinguished by its use of fixed spatial basis functions combined with a lightweight network to predict coefficients, rather than querying a dense grid or deep MLP for every sample point [15254-nlr-baseline.md]. It is chosen for basis-function-based representations. See [NLR Baseline](15254-nlr-baseline.md).

#### NeuralVDB Hyperparameter Configuration
*   **Step:** Batch sampling strategy is either drawing $2^{16}$ random samples per epoch, or resampling a subset of input voxels at fixed intervals and drawing $2^{12}$ batches per epoch. The resampling subset size equals resampling intervals (100 or 500) multiplied by batch size. Resampling is used when fine details with thin structures are critical [S1, unofficial].
*   **Parameter:** Subdomain size must be a multiple of 512. Too large wastes compute on empty subdomains; too small increases dispatch overhead and causes dominant overlapping halo regions leading to redundant computation [S1, unofficial]. Network width: Level-1 networks use half the width of level-0 networks. Default starting point: level-0 width 128, depth 3. Use 4 layers for volumes requiring more detail capture [S1, unofficial]. Optimizer: Adam. Default learning rate: 0.001. Decay: 0.975 every 100 epochs (no resampling) or 0.75 every 1,000 epochs (with resampling). Max epochs: 2,500 for non-resampled; more for resampled cases [S1, unofficial].
*   **Comparison:** Dense grid training produces the highest noise. Block grid (dense leaf nodes without active masks) reduces noise but still shows visible fog artifacts. Sparse VDB with active voxel masks yields the best visual quality and low noise reconstruction [S1, unofficial].

#### Neural Codebook Training Configuration
*   **Step:** Multiply learning rate by 0.3 for every 5,000 iterations. Cast the trained Neural Codebook (NCB) to float16 after training [S2].
*   **Parameter:** Optimizer: Adam with $\beta_1 = 0.9$ and $\beta_2 = 0.999$. Weight decay: $1e-5$. Initial learning rate: $5e-3$. Total training iterations: 20,000. Batch size: 100,000 voxels [S2].

## Background
The concept of training neural radiance fields was introduced by Mildenhall et al. in 2020 [S1, unofficial]. The specific configurations for HDR training, StyleGAN2 integration, and sparse VDB optimizations have been developed subsequently to address limitations in dynamic range, generative stability, and computational efficiency, respectively [S1, unofficial][S2].
