# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF training configuration defines the optimization procedure for text-guided stylization of Neural Radiance Fields (NeRFs) by minimizing the negative cosine similarity between rendered images and text prompts in the CLIP embedding space [S1, S2]. It distinguishes itself from standard NeRF reconstruction by freezing density-related parameters and utilizing directional losses (absolute or relative) to enforce semantic style trajectories rather than photometric fidelity [S2].

## How it works
**Inputs:**
*   A pre-trained NeRF model (density and color networks) initialized from a source scene [S1].
*   A target text prompt $\mathbf{t}_{tgt}$ describing the desired style [S2].
*   (Optional) A source text prompt $\mathbf{t}_{src}$ for relative directional loss [S2].
*   Training views (cameras) from the original dataset [S1].

**Outputs:**
*   Optimized NeRF parameters (specifically the color network and bottleneck features, while density parameters remain frozen) [S1].
*   Stylized 3D scene representation [S2].

**Data Structures:**
*   **CLIP Model:** Uses the ViT-B/32 variant [S1]. The image encoder $\mathcal{E}_i$ and text encoder $\mathcal{E}_t$ map inputs to normalized embedding vectors $\hat{\mathbf{e}}$ [S2].
*   **Patch Data:** A $128 \times 128$ pixel patch is rendered per iteration [S1]. Rays are sampled with a stride of 5, covering a $640 \times 640$ receptive field in the original image resolution [S1].

**Loss Functions:**
Two variants of directional CLIP loss are employed [S2]:

1.  **Absolute Directional CLIP Loss:** Measures the cosine similarity between the rendered image $\mathbf{I}_{tgt}$ and the target text prompt $\mathbf{t}_{tgt}$ [S2].
    $$ \mathcal{L}_{dir}^{abs} = 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) \rangle $$
    This guides the NeRF rendering with a global direction of the target text [S2].

2.  **Relative Directional CLIP Loss:** Transfers style from a source domain to a target domain by measuring the directional similarity between the difference of embeddings [S2].
    $$ \mathcal{L}_{dir}^{rel} = 1 - \left\langle \frac{\hat{\mathcal{E}}_i(\mathbf{I}_{tgt}) - \hat{\mathcal{E}}_i(\mathbf{I}_{src})}{\|\hat{\mathcal{E}}_i(\mathbf{I}_{tgt}) - \hat{\mathcal{E}}_i(\mathbf{I}_{src})\|}, \frac{\hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) - \hat{\mathcal{E}}_t(\mathbf{t}_{src})}{\|\hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) - \hat{\mathcal{E}}_t(\mathbf{t}_{src})\|} \right\rangle $$
    This approach mitigates mode collapse by relying on a pair of text prompts $(\mathbf{t}_{src}, \mathbf{t}_{tgt})$ [S2].

**Parameters:**
*   **Iterations:** 500 [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $0.0001$ [S1].
*   **Text Encoder:** CLIP ViT-B/32 [S1].
*   **Patch Size:** $128 \times 128$ pixels [S1].
*   **Ray Sampling Stride:** 5 within the patch [S1].
*   **Importance Sampling Points:** 16 per ray during patch rendering [S1].
*   **Fine MLP Samples:** 80 total (64 coarse + 16 fine) [S1].

**Algorithm:**
1.  Initialize NeRF parameters. Freeze all parameters related to density $\sigma$ [S1].
2.  For iteration $k = 1$ to 500:
    a. Randomly sample a training view (camera pose) [S1].
    b. Render a $128 \times 128$ image patch $\mathbf{I}_{patch}$ using the current NeRF.
       i. Sample rays with stride 5 to cover the patch [S1].
       ii. For each ray, perform volume rendering using 16 importance samples (plus 64 coarse samples if using the two-stage sampling scheme) [S1].
    c. Resize $\mathbf{I}_{patch}$ via bilinear interpolation to match CLIP input dimensions [S1].
    d. Compute embeddings: $\hat{\mathbf{e}}_i = \hat{\mathcal{E}}_i(\mathbf{I}_{patch})$ and $\hat{\mathbf{e}}_t = \hat{\mathcal{E}}_t(\mathbf{t}_{tgt})$ [S2].
    e. Compute loss $\mathcal{L}_{dir}$ (either absolute or relative) [S2].
    f. Backpropagate $\mathcal{L}_{dir}$ to update only the non-density parameters (color network and bottleneck features) using Adam with LR $0.0001$ [S1].

**Edge Cases and Pitfalls:**
*   **Memory Constraints:** Naive differentiable rendering of high-resolution images is intractable due to memory limits [S1]. The patch-based approach with reduced sampling (16 points) is required [S1].
*   **Mode Collapse:** Absolute directional CLIP loss can cause mode collapse of the generator and hurt generation diversity [S2].
*   **Insufficient Magnitude:** Directional loss alone measures trajectory but ignores magnitude, potentially resulting in weak or insufficient style transfer [S2]. Relative loss or additional contrastive losses may be needed to enforce proper stylization magnitude [S2].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of iterations (500) and the number of rays sampled per patch. The patch-based rendering reduces memory complexity compared to full-image rendering [S1].
*   **Memory Complexity:** Significantly reduced by rendering only $128 \times 128$ patches and using 16 importance samples per ray [S1].
*   **Strengths:** Enables text-driven stylization of 3D scenes without requiring 3D annotations; efficient memory usage via patch rendering [S1, S2].
*   **Limitations:** May suffer from mode collapse (absolute loss) or insufficient stylization magnitude (directional loss only) [S2]. Quality depends heavily on the CLIP model's ability to align text and image embeddings [S2].
*   **When to use:** When text-guided artistic stylization of a NeRF is required, and photometric accuracy is secondary to semantic style transfer [S2].
*   **When not to use:** When high-fidelity photometric reconstruction is needed, or when 3D-consistent style transfer requires more than directional guidance (e.g., magnitude control) [S2].

## Background
CLIPNeRF was introduced by Wang et al. in 2021 as an extension of StyleCLIP [Patashnik et al. 2021] to 3D neural radiance fields [S2]. It utilizes the pre-trained CLIP model to guide NeRF optimization via text prompts [S1, S2]. The directional CLIP loss was originally designed for face image editing in StyleCLIP and later adapted for generative NeRF editing [S2]. The configuration described here follows the implementation details provided by Kwea123 et al. [S1].
