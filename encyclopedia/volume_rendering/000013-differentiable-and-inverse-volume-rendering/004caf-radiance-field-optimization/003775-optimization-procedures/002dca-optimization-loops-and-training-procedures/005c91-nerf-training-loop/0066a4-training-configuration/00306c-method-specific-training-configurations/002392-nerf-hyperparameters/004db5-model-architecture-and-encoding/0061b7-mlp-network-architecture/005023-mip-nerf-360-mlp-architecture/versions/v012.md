# Mip-NeRF 360 MLP Architecture

Also called: Integrated Positional Encoding MLP, PosEnc MLP

## Overview
The Mip-NeRF 360 MLP architecture is a specific neural network configuration for radiance field optimization that replaces standard positional encoding with **integrated positional encoding** to handle aliasing and frequency filtering during volume rendering [S1, unofficial]. It solves the problem of high-frequency detail loss and aliasing artifacts when rendering scenes with varying camera distances by analytically integrating the positional encoding function over conical frustums [S1, unofficial]. It is distinguished from standard NeRF by its use of integrated encoding for density inputs and optional Integrated Directional Encoding (IDE) for view-dependent effects, along with a specific skip-connection topology and activation biasing strategy [S1, unofficial].

## How it works
The method consists of two main MLPs: a density network and a color network. The density network processes 3D positions (and their associated uncertainty/covariance) to output raw density, while the color network processes bottleneck features and view directions to output RGB color.

### Inputs and Outputs
*   **Inputs**:
    *   3D position mean $\mathbf{x}$ and covariance $\Sigma$ (or lifted variance $\sigma^2$).
    *   View direction $\mathbf{d}$ (or reflection direction $\mathbf{d}_{ref}$).
    *   Optional: Normal vectors $\mathbf{n}$, GLO vectors, roughness.
*   **Outputs**:
    *   Raw density $\sigma_{raw}$.
    *   RGB color $\mathbf{c}$.
    *   Optional: Normals, roughness, diffuse/specular components.

### Data Structures
The architecture is defined by a configuration object containing the following fields [S1, unofficial]:

| Field | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `net_depth` | int | 8 | Depth of density MLP. |
| `net_width` | int | 256 | Width of density MLP layers. |
| `bottleneck_width` | int | 256 | Width of feature vector passed to color MLP. |
| `net_depth_viewdirs` | int | 1 | Depth of color MLP. |
| `net_width_viewdirs` | int | 128 | Width of color MLP layers. |
| `min_deg_point` | int | 0 | Min degree of integrated positional encoding. |
| `max_deg_point` | int | 12 | Max degree of integrated positional encoding. |
| `skip_layer` | int | 4 | Skip connection frequency for density MLP. |
| `skip_layer_dir` | int | 4 | Skip connection frequency for color MLP. |
| `deg_view` | int | 4 | Degree of directional encoding. |
| `density_bias` | float | -1.0 | Bias added to raw density before activation. |
| `density_noise` | float | 0.0 | Std dev of noise added to raw density. |
| `rgb_bias` | float | 0.0 | Bias added to raw color before activation. |
| `rgb_padding` | float | 0.001 | Padding for RGB output range. |
| `use_reflections` | bool | False | Use reflection directions instead of view directions. |
| `use_directional_enc` | bool | False | Use IDE for directions. |
| `basis_shape` | str | 'icosahedron' | Basis shape for integrated encoding. |
| `basis_subdivisions` | int | 2 | Tessellation count for basis. |
| `use_diffuse_color` | bool | False | Predict diffuse/specular separately. |
| `use_specular_tint` | bool | False | Predict specular tint vector. |
| `use_n_dot_v` | bool | False | Feed $\mathbf{n} \cdot \mathbf{d}$ to color MLP. |
| `bottleneck_noise` | float | 0.0 | Std dev of noise added to bottleneck. |
| `enable_pred_normals` | bool | False | Enable predicted normals. |
| `disable_density_normals` | bool | True | Disable density gradient normals. |
| `warp_fn` | callable | None | Function to linearize means/covs. |
| `density_activation` | callable | Softplus | Activation for density. |
| `rgb_activation` | callable | Sigmoid | Activation for RGB. |
| `net_activation` | callable | ReLU | Activation for hidden layers. |

        x_bottleneck.shape[:-1] + (dir_enc.shape[-1],)

        x_color_input.append(n_dot_v)
        
    # Add GLO vector if provided
    if config.glo_vec is not None:
        glo_vec = jnp.broadcast_to(config.glo_vec, x_bottleneck.shape)
        x_color_input.append(glo_vec)
        
    x_color_input = jnp.concatenate(x_color_input, axis=-1)
    
    # 5. Color MLP
    net_depth_viewdirs = config.net_depth_viewdirs
    net_width_viewdirs = config.net_width_viewdirs
    skip_layer_dir = config.skip_layer_dir
    net_activation = config.net_activation
    
    h = x_color_input
    for i in range(net_depth_viewdirs):
        h = jnp.dot(h, params['color_w'][i]) + params['color_b'][i]
        if i > 0 and i % skip_layer_dir == 0:
            h = jnp.concatenate([h, x_color_input], axis=-1)
        h = net_activation(h)
        
    raw_rgb = jnp.dot(h, params['color_out_w']) + params['color_out_b']
    
    # 6. RGB Output and Post-processing
    rgb = config.rgb_activation(config.rgb_premultiplier * raw_rgb + config.rgb_bias)
    
    # Specular/Diffuse Split
    if config.use_diffuse_color:
        raw_rgb_diffuse = raw_rgb[..., :3] # Assuming first 3 channels are diffuse
        diffuse_linear = jnp.sigmoid(raw_rgb_diffuse - jnp.log(3.0))
        if config.use_specular_tint:
            specular_linear = config.tint * rgb
        else:
            specular_linear = 0.5 * rgb
        rgb = jnp.clip(linear_to_srgb(specular_linear + diffuse_linear), 0.0, 1.0)
    else:
        rgb = jnp.clip(rgb, 0.0, 1.0)
        
    # RGB Padding
    rgb = rgb * (1 + 2 * config.rgb_padding) - config.rgb_padding
    
    return rgb, final_density, normals

### Parameters
*   **Network Depths**: `net_depth=8` for density, `net_depth_viewdirs=1` for color [S1, unofficial].
*   **Network Widths**: `net_width=256` for density, `net_width_viewdirs=128` for color, `bottleneck_width=256` [S1, unofficial].
*   **Encoding Degrees**: `min_deg_point=0`, `max_deg_point=12` for points; `deg_view=4` for directions [S1, unofficial].
*   **Skip Connections**: `skip_layer=4` for density, `skip_layer_dir=4` for color [S1, unofficial].
*   **Biases**: `density_bias=-1.0`, `rgb_bias=0.0` [S1, unofficial].
*   **Padding**: `rgb_padding=0.001` [S1, unofficial].
*   **Basis**: `basis_shape='icosahedron'`, `basis_subdivisions=2` [S1, unofficial].

### Edge Cases and Pitfalls
*   **Reflections Require Normals**: If `use_reflections` is True, normals must be computed (either via `enable_pred_normals` or by not disabling density normals). Otherwise, a `ValueError` is raised [S1, unofficial].
*   **Reflection Direction Flip**: When computing reflection directions, view directions are flipped (`-viewdirs`) before reflection because they typically point from camera to point, whereas reflection utilities often assume they point toward the camera [S1, unofficial].
*   **Normal Stability**: Normals are computed from the gradient of the **raw** (pre-activation) density, not the activated density, because it is numerically more stable when the activation function has steep or flat gradients [S1, unofficial].
*   **Precision**: High-precision (float64) is recommended for color correction and metric computation steps to avoid quantization errors [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: The integrated positional encoding adds computational overhead compared to standard positional encoding due to the exponential decay terms and basis transformations, but it eliminates the need for post-processing filtering. The MLP complexity is dominated by the dense layers: $O(D \cdot W^2)$ for density and $O(D_v \cdot W_v^2)$ for color, where $D, W$ are depth and width of density MLP, and $D_v, W_v$ for color MLP.
*   **Memory Complexity**: The memory footprint is determined by the MLP weights and the intermediate activations. The integrated encoding does not significantly increase memory usage compared to standard PE, as it operates on the same input dimensions.
*   **Strengths**: Reduces aliasing artifacts in rendered images, especially for scenes with high-frequency details or varying camera distances. Improves convergence and visual quality in 360-degree scenes.
*   **Limitations**: Slightly higher computational cost for encoding. Requires careful tuning of `density_bias` and `rgb_padding` to ensure proper output ranges.
*   **When to Use**: Recommended for NeRF training in 360-degree scenes or when high-frequency details are present and aliasing is observed.
*   **When Not to Use**: For simple scenes with low-frequency content, standard NeRF may be sufficient and faster.

## Background
The Mip-NeRF 360 MLP architecture was introduced by Google Research in the "Mip-NeRF 360" paper [S1, unofficial]. It builds upon the original NeRF architecture by integrating positional encoding analytically to handle the frequency filtering inherent in volume rendering. The method is part of the Mip-NeRF family, which aims to reduce aliasing by treating rays as cones rather than lines. The specific MLP configuration described here is the default implementation used in the `multinerf` repository [S1, unofficial].
