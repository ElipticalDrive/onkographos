# Generative Occupancy Fields (GOF)


## Overview
Generative Occupancy Fields (GOF) is a 3D-aware image synthesis method that combines radiance fields with occupancy representations to learn compact object surfaces without impeding training convergence [S1, unofficial]. It solves the problem of diffused surfaces in generative radiance fields (like pi-GAN) and the sparse gradient convergence issues in direct occupancy networks by transitioning from cumulative volume rendering to surface-point rendering [S1, unofficial]. Unlike its siblings, GOF predicts alpha values (interpreted as occupancy) instead of volume densities, enabling surface-aware image synthesis via root-finding [S1, unofficial].

## How it works
GOF reinterprets the alpha values in the cumulative rendering process as occupancy values to locate the learned surface via root-finding [S1, unofficial]. It employs a training-time transition where the sampling region shrinks from the entire volume to a minimal neighborhood around the surface [S1, unofficial].

### Inputs and Outputs
*   **Inputs:**
    *   Latent code $z \sim p_z$ (truncated or sampled).
    *   Camera pose $\xi \sim p_\xi$ (defined by origin $o$ and direction $d$).
    *   Near and far bounds $[t_n, t_f]$ for the viewing ray.
*   **Outputs:**
    *   Rendered image color $\tilde{C}(r, z)$ for ray $r$.
    *   Surface point $x_s$ (optional, for surface rendering mode).

### Data Structures
*   **Generator Network $G_\theta$:** A FiLMed-SIREN backbone [S1, unofficial] that takes spatial coordinate $x$, latent code $z$, and direction $d$ (for color) to predict occupancy/alpha values $\alpha_\theta(x, z)$.
*   **Discriminator Network $D_\phi$:** Standard GAN discriminator for image realism.
*   **Sampling Parameters:**
    *   $N$: Number of rendering samples (Typical: 12) [S1, unofficial].
    *   $M$: Number of root-finding bins (Typical: 12) [S1, unofficial].
    *   $m_s$: Secant iterations (Typical: 3) [S1, unofficial].
    *   $\tau$: Threshold for root-finding (Typical: 0.5) [S1, unofficial].
    *   $\Delta_{init}$: Initial shrinking interval, $(t_f - t_n)/2$ [S1, unofficial].
    *   $\Delta_{min}$: Minimal shrinking interval (pre-defined) [S1, unofficial].
    *   $\gamma$: Shrinking rate parameter [S1, unofficial].

### Formulas
1.  **Alpha Value (Occupancy):**
    $$ \alpha_\theta(x_i, z) = 1 - \exp(-\sigma_\theta(x_i, z)\delta_i) $$
    This value naturally falls in $[0, 1]$ [S1, unofficial].

2.  **Rendering (Cumulative):**
    $$ \tilde{C}(r, z) = \sum_{i=1}^{N} \alpha_\theta(x_i, z) \left( \prod_{j<i} (1 - \alpha_\theta(x_j, z)) \right) c_\theta(x_i, d, z) $$
    Where $c_\theta$ is the predicted color [S1, unofficial].

3.  **Opacity Regularization Loss:**
    $$ L_{opacity} = \frac{1}{N} \sum_{i=1}^{N} \left[ \log(\alpha_\theta(x_i, z)) + \log(1 - \alpha_\theta(x_i, z)) \right] $$
    Aims to reduce entropy of alpha values [S1, unofficial].

4.  **Normal Regularization Loss:**
    $$ L_{normal} = \sum_{x_s \in S} \| n_\theta(x_s, z) - n_\theta(x_s + \epsilon, z) \|_2^2 $$
    Encourages surface normal smoothness [S1, unofficial].

5.  **GAN Loss:**
    $$ L_{origin}(\theta_D, \theta_G) = \mathbb{E}_{z \sim p_z, \xi \sim p_\xi} f(D_{\theta_D}(G_{\theta_G}(z, \xi))) + \mathbb{E}_{I \sim p_D} f(-D_{\theta_D}(I)) + \lambda ||\nabla_{D_{\theta_D}}(I)||_2^2 $$
    Where $f(u) = -\log(1 + \exp(-u))$ [S1, unofficial].

6.  **Total Loss:**
    $$ L(\theta, \phi) = L_{origin}(\theta, \phi) + \lambda_{normal} L_{normal} + \lambda_{opacity} L_{opacity} $$

### Pseudocode

```python
def gof_render(ray_origin, ray_direction, near_bound, far_bound, latent_code, step_index, 
               N=12, M=12, ms=3, tau=0.5, delta_min=0.01, delta_init=None, gamma=0.01):
    """
    Renders an image using GOF.
    If step_index is provided, uses shrinking sampling.
    If step_index is None (inference), can use surface-only rendering.
    """
    # 1. Locate Surface via Root-Finding
    # Sample M evenly-spaced points in [near_bound, far_bound]
    t_bins = linspace(near_bound, far_bound, M + 1)
    x_bins = [ray_origin + t * ray_direction for t in t_bins]
    
    # Query alpha values (no gradients needed for root-finding)
    alpha_bins = [generator.query_alpha(x, latent_code) for x in x_bins]
    
    # Find bin k_s where alpha crosses threshold tau
    # k_s is the index such that alpha[k_s] < tau <= alpha[k_s+1]
    k_s = None
    for k in range(M):
        if alpha_bins[k] < tau <= alpha_bins[k+1]:
            k_s = k
            break
            
    if k_s is None:
        # Fallback: if surface not found, use center of volume or handle error
        # [G] Implementation detail: Return black or default color if no surface found
        return None, None

    # Secant method to refine surface point x_s
    t_left = t_bins[k_s]
    t_right = t_bins[k_s+1]
    alpha_left = alpha_bins[k_s]
    alpha_right = alpha_bins[k_s+1]
    
    for _ in range(ms):
        # Linear interpolation (secant method) to find t where alpha = tau
        # t_new = t_left + (tau - alpha_left) * (t_right - t_left) / (alpha_right - alpha_left)
        if abs(alpha_right - alpha_left) < 1e-8:
            break
        t_new = t_left + (tau - alpha_left) * (t_right - t_left) / (alpha_right - alpha_left)
        x_new = ray_origin + t_new * ray_direction
        alpha_new = generator.query_alpha(x_new, latent_code)
        
        if alpha_new < tau:
            t_left = t_new
            alpha_left = alpha_new
        else:
            t_right = t_new
            alpha_right = alpha_new
            
    t_surface = (t_left + t_right) / 2
    x_surface = ray_origin + t_surface * ray_direction
    
    # 2. Determine Sampling Region
    if step_index is not None:
        # Training: Shrinking region
        # Delta_n = max(delta_init * exp(-gamma * step_index), delta_min)
        # [G] delta_init should be passed or computed as (far_bound - near_bound) / 2
        delta_n = max(delta_init * exp(-gamma * step_index), delta_min)
        t_start = t_surface - delta_n
        t_end = t_surface + delta_n
        
        # Clamp to [near_bound, far_bound]
        t_start = max(t_start, near_bound)
        t_end = min(t_end, far_bound)
        
        # Sample N points in [t_start, t_end]
        t_samples = linspace(t_start, t_end, N + 1)[:-1] # Exclude end to get N intervals? 
        # Note: Source says ti ~ U[ts - delta + (2i-2)/N * delta, ts - delta + 2i/N * delta]
        # This implies N intervals. We sample N points.
        # Let's use uniform sampling within the interval for simplicity as per standard practice,
        # or follow the specific uniform distribution logic if strict adherence is required.
        # The source formula for ti suggests sampling points uniformly distributed in the shrinking window.
        t_samples = [t_start + i * (t_end - t_start) / N for i in range(N)]
    else:
        # Inference: Can use minimal region or single point
        # Option A: Minimal region cumulative rendering
        delta_n = delta_min
        t_start = t_surface - delta_n
        t_end = t_surface + delta_n
        t_samples = linspace(t_start, t_end, N + 1)[:-1]
        
        # Option B: Surface point only (N=1)
        # t_samples = [t_surface]
        # [G] Default to minimal region cumulative for robustness unless specified
        
    # 3. Render
    # Compute color using alpha composition
    # T_i = product(1 - alpha_j) for j < i
    # C = sum(T_i * alpha_i * c_i)
    
    transmittance = 1.0
    color = [0.0, 0.0, 0.0]
    
    for t in t_samples:
        x = ray_origin + t * ray_direction
        alpha = generator.query_alpha(x, latent_code)
        c = generator.query_color(x, ray_direction, latent_code)
        
        contribution = transmittance * alpha * c
        color += contribution
        transmittance *= (1.0 - alpha)
        
    return color, x_surface

def gof_train_step(generator, discriminator, batch_images, latent_codes, camera_poses, step_index, 
                   lambda_normal=1.0, lambda_opacity=1.0, delta_init=None, gamma=0.01):
    """
    Performs one training step for GOF.
    """
    # 1. Generate fake images
    fake_images = []
    for z, pose in zip(latent_codes, camera_poses):
        color, _ = gof_render(pose.origin, pose.direction, pose.near, pose.far, z, step_index, 
                              delta_init=delta_init, gamma=gamma)
        fake_images.append(color)
        
    # 2. Compute GAN Loss
    # L_origin = E[f(D(G(z)))] + E[f(-D(I))] + lambda * ||grad(D(I))||^2
    loss_gan = compute_gan_loss(generator, discriminator, fake_images, batch_images)
    
    # 3. Compute Regularization Losses
    # L_opacity: computed on the sampled points during rendering
    # [G] Need to access the alpha values from the rendering step to compute this
    # L_normal: computed on the surface points
    # [G] Need to access the surface points x_s from the rendering step to compute this
    
    loss_opacity = compute_opacity_loss(alpha_values_from_rendering)
    loss_normal = compute_normal_loss(surface_points_from_rendering, generator)
    
    # 4. Total Loss
    total_loss = loss_gan + lambda_normal * loss_normal + lambda_opacity * loss_opacity
    
    # 5. Backpropagate
    total_loss.backward()
    
    return total_loss
```

### Edge Cases and Pitfalls
*   **Shape-Color Ambiguity:** Direct training of generative radiance fields fails to maintain surface compactness because small perturbations on surfaces still lead to realistic RGB images, fooling the discriminator [S1, unofficial]. GOF mitigates this by shrinking the sampling region.
*   **Convergence Issues:** Directly applying occupancy representations to generative models causes severe convergence problems due to sparse gradients located only on object surfaces [S1, unofficial]. GOF starts with cumulative rendering (dense gradients) and transitions to surface rendering.
*   **Density Thresholding:** Predicted densities in generative radiance fields range from 0 to 50, making it hard to determine an effective threshold for surface location [S1, unofficial]. GOF uses alpha values (range [0,1]) and a fixed threshold $\tau=0.5$ for root-finding.
*   **Inference Speed:** Standard rendering requires $M + m_s + N$ queries. Surface-only rendering requires $M + m_s + 1$ queries [S1, unofficial].
*   **Furry Objects:** Surface rendering mode may make furry cat images over-smooth and less realistic [S1, unofficial]. GOF is more suitable for solid objects with only one surface.

## Operating characteristics
*   **Time Complexity:** Rendering requires $M + m_s + N$ queries for standard mode, or $M + m_s + 1$ for surface-only mode. Baselines (like pi-GAN) require $2N$ queries due to hierarchical sampling [S1, unofficial].
*   **Memory Complexity:** Depends on the generator network size (FiLMed-SIREN) and the number of sampled points. No large voxel grids are stored, unlike VoxelNeRF or similar sparse methods.
*   **Performance:** Outperforms baselines on MAD (Mean Angle Deviation, measuring compactness) and is comparable on SIDE (Scale-Invariant Depth Error, measuring depth accuracy) on CelebA, BFM, and Cats datasets [S1, unofficial].
*   **Strengths:** Compact and smooth surfaces; efficient rendering with surface points; stable training via transition from radiance fields.
*   **Limitations:** Less effective for non-solid or multi-surface objects (e.g., furry animals) in surface-only mode; requires careful tuning of shrinking parameters.

## Background
*   **Origin:** Proposed by Xudong Xu, Xingang Pan, Dahua Lin, and Bo Dai from CUHK-SenseTime Joint Lab, MPI for Informatics, and Nanyang Technological University [S1, unofficial].
*   **Paper:** "Generative Occupancy Fields for 3D Surface-Aware Image Synthesis" (arXiv:2111.00969, Nov 2021) [S1, unofficial].
*   **Development:** GOF builds on the concept of generative radiance fields (like pi-GAN) and occupancy networks. It addresses the trade-off between the ease of training with cumulative rendering and the compactness of occupancy representations.
*   **Usage:** Evaluated on CelebA, BFM, and Cats datasets for 3D-aware image synthesis [S1, unofficial].
