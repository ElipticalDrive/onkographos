# ActiveNeRF Model Architecture

Also called: ActiveNeRF MLP structure, Uncertainty-aware NeRF network

## Overview
ActiveNeRF extends the standard NeRF architecture by incorporating uncertainty estimation directly into the neural network's output, allowing the model to predict not only volume density and color but also the prediction variance for each sampled point [S1]. This modification enables active view selection strategies by quantifying where the model is uncertain, distinguishing it from standard NeRF which outputs only deterministic RGB and density values [S1].

## How it works
The ActiveNeRF model is a multi-layer perceptron (MLP) that processes positional-encoded 3D coordinates and viewing directions to predict volume density, color, and prediction variance [S1].

**Inputs and Outputs**
*   **Input:** 3D spatial coordinates $\mathbf{x} = (x, y, z)$ and viewing direction $\mathbf{d} = (d_x, d_y, d_z)$.
*   **Outputs:** Volume density $\sigma$, RGB color $\mathbf{c}$, and prediction variance $\alpha^2$ [S1].

**Data Structures and Layout**
The network consists of two main branches originating from the encoded 3D coordinates:
1.  **Density and Variance Branch:** An 8-layer MLP with a residual connection on the 4th layer processes the encoded coordinates. The output of this MLP is passed through two separate fully connected (FC) layers:
    *   One FC layer outputs the volume density $\sigma$.
    *   One FC layer with a softplus activation function outputs the prediction variance $\alpha^2$ [S1].
2.  **Color Branch:** The latent feature vector from the 8-layer MLP is concatenated with the encoded viewing directions. This concatenated vector is passed through a final FC layer to predict the RGB color $\mathbf{c}$ [S1].

**Positional Encoding**
Both 3D coordinates and viewing directions are encoded using a sinusoidal positional encoding function $\gamma(p)$ [S1]:

$$
\gamma(p) = (\sin(2^0\pi p), \cos(2^0\pi p), \dots, \sin(2^{L-1}\pi p), \cos(2^{L-1}\pi p))
$$

where $p$ is the input component (coordinate or direction) and $L$ is the number of frequency bands [S1].

**Parameters**
*   $L=10$: Number of frequency bands for 3D coordinates [S1].
*   $L=4$: Number of frequency bands for viewing directions [S1].

**Algorithm**
The following pseudocode describes the forward pass of the ActiveNeRF model. It assumes standard vector operations and a basic MLP block.

```python
import math
import numpy as np

def positional_encoding(p, L):
    """
    Applies sinusoidal positional encoding to input p.
    p: array-like of shape (..., D)
    L: int, number of frequency bands
    Returns: array of shape (..., D * 2 * L)
    """
    # p is expected to be a numpy array
    # Reshape to handle batch dimensions if necessary, but here we assume
    # p is (N, D) where N is number of points and D is 3 or 3.
    # We need to expand dimensions to compute frequencies.
    
    # Create frequency bands
    # freq_bands = 2^0, 2^1, ..., 2^(L-1)
    freq_bands = np.array([2**i for i in range(L)])
    
    # Expand p to (N, D, 1) and freq_bands to (1, 1, L)
    # Resulting shape for argument: (N, D, L)
    arg = np.expand_dims(p, axis=-1) * np.expand_dims(freq_bands * np.pi, axis=0)
    
    # Compute sin and cos
    # arg shape: (N, D, L)
    sin_vals = np.sin(arg)
    cos_vals = np.cos(arg)
    
    # Concatenate along the last axis
    # Output shape: (N, D, 2*L)
    encoded = np.concatenate([sin_vals, cos_vals], axis=-1)
    
    # Flatten the last two dimensions to (N, D * 2 * L)
    return encoded.reshape(p.shape[0], -1)

class ActiveNeRF:
    def __init__(self, hidden_dim=256):
        """
        Initializes the ActiveNeRF model.
        hidden_dim: int, dimension of hidden layers.
        """
        self.hidden_dim = hidden_dim
        # Note: In a real implementation, weights would be learned parameters.
        # Here we define the structure.
        
        # 8-layer MLP for 3D coordinates
        # Layer 1: Input_dim -> hidden_dim
        # Layers 2-3: hidden_dim -> hidden_dim
        # Layer 4: hidden_dim -> hidden_dim (with residual)
        # Layers 5-8: hidden_dim -> hidden_dim
        self.mlp_weights = []
        self.mlp_biases = []
        
        # Initialize weights (placeholder for actual initialization logic)
        # Layer 1
        self.mlp_weights.append(np.random.randn(24, hidden_dim)) # 24 = 3 * 2 * 10
        self.mlp_biases.append(np.zeros(hidden_dim))
        
        # Layers 2-8
        for _ in range(7):
            self.mlp_weights.append(np.random.randn(hidden_dim, hidden_dim))
            self.mlp_biases.append(np.zeros(hidden_dim))
            
        # Density head: 1 FC layer
        self.density_weight = np.random.randn(hidden_dim, 1)
        self.density_bias = np.zeros(1)
        
        # Variance head: 1 FC layer with softplus
        self.variance_weight = np.random.randn(hidden_dim, 1)
        self.variance_bias = np.zeros(1)
        
        # Color head: 1 FC layer
        # Input: hidden_dim + (3 * 2 * 4) = hidden_dim + 24
        self.color_weight = np.random.randn(hidden_dim + 24, 3)
        self.color_bias = np.zeros(3)

    def mlp_forward(self, x_encoded):
        """
        Forward pass through the 8-layer MLP with residual connection on layer 4.
        x_encoded: (N, 24)
        Returns: latent feature (N, hidden_dim)
        """
        h = x_encoded
        for i in range(8):
            # Linear transformation
            h = h @ self.mlp_weights[i] + self.mlp_biases[i]
            
            # ReLU activation (standard for NeRF MLPs, implied by "MLP" in context of NeRF)
            h = np.maximum(0, h)
            
            # Residual connection on the 4th layer (index 3)
            if i == 3:
                h = h + x_encoded # Note: x_encoded is the input to the MLP, not the previous layer's output?
                # Correction based on standard NeRF residual: usually residual is added to the output of the layer.
                # The source says "residual connection on the 4th layer".
                # In standard NeRF [20], the residual is added to the input of the 4th layer? 
                # Actually, standard NeRF adds the input of the block to the output.
                # Let's assume the residual is added to the output of the 4th layer, 
                # where the input to the 4th layer is the output of the 3rd.
                # However, the source says "residual connection on the 4th layer".
                # Usually this means: output_4 = relu(W * output_3 + b) + input_3? 
                # Or output_4 = relu(W * output_3 + b) + input_MLP?
                # The source [S1] says "MLP with 8 fully-connected layers ... with residual connection on the 4th layer".
                # Standard NeRF implementation adds the input of the layer to the output of the layer for layers 4-8?
                # No, standard NeRF adds the input of the *block* (which is the input to the first layer of the block) 
                # to the output of the last layer of the block.
                # But here it's a single 8-layer MLP.
                # Let's stick to the most common interpretation: 
                # Layer 4 output = ReLU(W4 * h3 + b4) + h3? Or + x_encoded?
                # Given the ambiguity, and that standard NeRF uses residual connections between layers 4-8 
                # where the input to layer 4 is added to the output of layer 8? No.
                # Standard NeRF: h = ReLU(W * h + b). If layer index >= 4, h = h + h_prev?
                # Let's assume the residual is added to the output of the 4th layer from the input of the 4th layer.
                # But we don't store h_prev easily in a loop without care.
                # Let's assume the residual is added to the output of the 4th layer, 
                # where the "input" for the residual is the output of the 3rd layer.
                pass 
        
        # Refined Residual Logic for 8-layer MLP:
        # The source says "residual connection on the 4th layer".
        # This likely means the standard NeRF residual structure:
        # For layers 4, 5, 6, 7, 8: output = ReLU(W * input + b) + input
        # But wait, standard NeRF has a specific structure.
        # Let's implement the standard NeRF residual:
        # h = ReLU(W * h + b)
        # if layer_index >= 4: h = h + h_prev (where h_prev is the output of layer 3 for layer 4, etc?)
        # Actually, in standard NeRF, the residual is added to the *input* of the layer.
        # h_new = ReLU(W * h_old + b) + h_old? No, that's just identity if W=0.
        # It is: h_new = ReLU(W * h_old + b) + h_prev?
        # Let's look at the standard NeRF code.
        # h = F.relu(self.fc1(x))
        # h = F.relu(self.fc2(h))
        # h = F.relu(self.fc3(h))
        # h = F.relu(self.fc4(h)) + h # Residual here?
        # No, standard NeRF adds the input of the *block* to the output of the *block*.
        # But here it is a single MLP.
        # Let's assume the residual is added to the output of the 4th layer from the input of the 4th layer.
        # This is a common "residual connection on layer 4" interpretation.
        
        # Re-implementing with explicit storage for residual
        h = x_encoded
        h_prev = None
        for i in range(8):
            h_prev = h
            h = h @ self.mlp_weights[i] + self.mlp_biases[i]
            h = np.maximum(0, h)
            if i == 3: # 4th layer (0-indexed)
                h = h + h_prev
        
        return h

    def forward(self, x, d):
        """
        Forward pass of ActiveNeRF.
        x: (N, 3) 3D coordinates
        d: (N, 3) viewing directions
        Returns: sigma (N, 1), alpha_sq (N, 1), color (N, 3)
        """
        # 1. Positional Encoding
        x_enc = positional_encoding(x, L=10) # (N, 24)
        d_enc = positional_encoding(d, L=4)  # (N, 24)
        
        # 2. Process 3D coordinates through MLP
        latent = self.mlp_forward(x_enc) # (N, hidden_dim)
        
        # 3. Predict Density
        sigma = latent @ self.density_weight + self.density_bias # (N, 1)
        
        # 4. Predict Variance
        var_out = latent @ self.variance_weight + self.variance_bias # (N, 1)
        alpha_sq = np.exp(var_out) # Softplus is approximated by exp for variance? 
        # Source says "softplus activation function to predict the corresponding variance".
        # Softplus(x) = log(1 + exp(x)).
        # Let's use softplus explicitly.
        alpha_sq = np.log(1 + np.exp(var_out))
        
        # 5. Predict Color
        # Concatenate latent feature with encoded viewing directions
        color_input = np.concatenate([latent, d_enc], axis=1) # (N, hidden_dim + 24)
        color = color_input @ self.color_weight + self.color_bias # (N, 3)
        
        return sigma, alpha_sq, color
```

**Edge Cases and Pitfalls**
*   **Variance Prediction:** The variance output uses a softplus activation, ensuring the predicted variance is always positive [S1].
*   **Residual Connection:** The residual connection is specifically applied on the 4th layer of the 8-layer MLP [S1].
*   **Encoding Bands:** The number of bands $L$ differs for coordinates (10) and directions (4), which must be handled separately during encoding [S1].

## Background
ActiveNeRF was introduced in the paper "ActiveNeRF: Learning Where to See with Uncertainty Estimation" [S1]. The model architecture is similar to the original NeRF [20], but extends it to support active view selection by predicting uncertainty [S1]. The initial training set consists of 4 images, with 4 new perceptions captured every 40,000 iterations [S1]. The model is trained using the Adam optimizer with an initial learning rate of $5 \times 10^{-4}$, decaying exponentially to $5 \times 10^{-5}$, using a batch size of 1024 rays on a single RTX 2080 Ti GPU [S1].
