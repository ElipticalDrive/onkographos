# AR-NeRF Training Configuration

Also called: AR-NeRF Implementation Details, AR-NeRF architecture and training configuration

## Overview
AR-NeRF (Aperture Rendering Neural Radiance Fields) is an unsupervised method for learning depth and defocus effects from natural images by integrating aperture rendering into the NeRF framework [S1]. It solves the problem of generating novel views with realistic depth-of-field effects without requiring explicit depth or aperture annotations [S1]. Unlike standard NeRF variants that render sharp images, AR-NeRF explicitly models the camera aperture to synthesize defocused images, distinguishing it from siblings like [NeRF Hyperparameters](3065-nerf-hyperparameters.md) which focus on general rendering quality, and [Mip-NeRF Optimization and Activation Details](3409-mip-nerf-optimization-and-activation-details.md) which address aliasing [S1]. It builds on [Method-Specific Training Configurations](6267-method-specific-training-configurations.md) by incorporating specific GAN-based regularization and network architectures derived from pi-GAN [S1].

## How it works
AR-NeRF trains a neural radiance field using a Generative Adversarial Network (GAN) framework, combining photometric consistency with adversarial and identity regularization [S1]. The method uses a mapping network to project latent codes into intermediate latent vectors, which are then fed into foreground and background synthesis networks [S1].

**Inputs and Outputs:**
*   **Input:** Unsupervised collection of natural images (e.g., flowers, birds, faces) without depth or camera pose labels.
*   **Output:** A trained radiance field capable of rendering novel views with adjustable defocus strength and focus distance.

**Data Structures and Layouts:**
1.  **Mapping Network:**
    *   Architecture: Multi-Layer Perceptron (MLP).
    *   Hidden Layers: 3 layers.
    *   Units per Layer: 256.
    *   Activation: Leaky Rectified Linear Unit (LReLU) with negative slope 0.2 [S1].
    *   Latent Code Dimension: 256 [S1].
2.  **Foreground Synthesis Network:**
    *   Architecture: MLP with FiLM (Feature-wise Linear Modulation) conditioned SIREN layers [S1].
    *   Hidden Layers: 8 layers.
    *   Units per Layer: 128 [S1].
    *   Note: Reduced from 256 (original pi-GAN) to allow more points per ray, improving performance without significant quality loss [S1].
3.  **Background Synthesis Network:**
    *   Architecture: MLP with FiLM-SIREN layers.
    *   Hidden Layers: 8 layers.
    *   Units per Layer: 64 [S1].
    *   Rationale: Fewer parameters assumed sufficient due to simpler background geometry [S1].
4.  **Discriminator:**
    *   **For FFHQ (Faces):** CoordConv layers followed by residual blocks [S1].
    *   **For Oxford Flowers / CUB-200-2011:** Same as FFHQ but **without** CoordConv layers [S1]. CoordConv was found to have negative effects on non-aligned objects like flowers and birds [S1].

**Training Steps:**
1.  **Data Preparation:** Load dataset images. For AR-NeRF-R (defocus renderer), generate 128×128 training images using AR-NeRF by increasing input point density [S1].
2.  **Network Initialization:** Initialize Mapping, Foreground Synthesis, Background Synthesis, and Discriminator networks according to the layouts above [S1].
3.  **Forward Pass (Rendering):**
    *   Sample rays from the camera.
    *   Query density $\sigma$ and color $\mathbf{c}$ from the synthesis networks conditioned on the latent code and position [S1].
    *   Compute rendered color $\hat{C}(\mathbf{r})$ using differentiable volume rendering [Parent].
    *   Apply aperture rendering to simulate defocus based on aperture size $s$ and focus distance $f$ [S1].
4.  **Loss Computation:**
    *   **Photometric Loss:** MSE or Charbonnier loss between rendered image and ground truth [Parent][S1].
    *   **R1 Regularization:** Gradient penalty on the discriminator input with weight $\lambda_{R1} = 0.2$ [S1].
    *   **Identity Regularization:** Weight $\lambda_{id} = 15$ to maintain identity consistency across viewpoints [S1].
    *   **GAN Loss:** Non-saturating GAN loss [S1].
5.  **Optimization:**
    *   Update networks using the Adam optimizer [S1].
    *   Learning Rate: $0.00006$ [S1].
    *   Iterations: 200,000 [S1].

**Pseudocode:**
```python
# AR-NeRF Training Loop
# Hyperparameters
lr = 0.00006
iterations = 200000
lambda_r1 = 0.2
lambda_id = 15
latent_dim = 256

# Initialization
mapping_net = MLP(hidden_layers=3, units=256, activation=LReLU(negative_slope=0.2))
fg_synthesis_net = MLP_FiLM_SIREN(hidden_layers=8, units=128)
bg_synthesis_net = MLP_FiLM_SIREN(hidden_layers=8, units=64)

# Discriminator selection based on dataset
if dataset == "FFHQ":
    discriminator = Discriminator_CoordConv_Residual()
else: # Oxford Flowers, CUB-200-2011
    discriminator = Discriminator_Residual_No_CoordConv()

optimizer = Adam(params=map(list, [mapping_net.parameters(), fg_synthesis_net.parameters(), 
                                   bg_synthesis_net.parameters(), discriminator.parameters()]), lr=lr)

for i in range(iterations):
    # 1. Sample batch of images
    images = load_batch(dataset)
    
    # 2. Sample latent codes
    z = sample_latent(latent_dim)
    
    # 3. Map latent code to intermediate latent
    w = mapping_net(z)
    
    # 4. Render image with aperture rendering
    # Note: Aperture parameters s and f can be varied for defocus control
    rendered_image = render_arnerf(w, fg_synthesis_net, bg_synthesis_net, s, f)
    
    # 5. Compute Discriminator predictions
    real_pred = discriminator(images)
    fake_pred = discriminator(rendered_image.detach())
    
    # 6. Compute GAN Loss (Non-saturating)
    gan_loss = -mean(fake_pred)
    
    # 7. Compute R1 Regularization
    # Gradient penalty on real images
    grad_real = compute_gradient(discriminator, images)
    r1_reg = lambda_r1 * mean(grad_real ** 2)
    
    # 8. Compute Identity Regularization
    # Render same object from different viewpoints with same latent code
    # Identity loss encourages consistent appearance
    id_loss = lambda_id * compute_identity_loss(rendered_image, images)
    
    # 9. Compute Photometric Loss (MSE/Charbonnier)
    photometric_loss = compute_mse(rendered_image, images)
    
    # 10. Total Loss
    total_loss = gan_loss + r1_reg + id_loss + photometric_loss
    
    # 11. Backpropagation and Update
    optimizer.zero_grad()
    total_loss.backward()
    optimizer.step()
```

**Edge Cases and Pitfalls:**
*   **CoordConv Misuse:** Using CoordConv layers in the discriminator for datasets with non-aligned objects (e.g., flowers, birds) degrades performance [S1].
*   **Ray Density:** Processing time and memory increase with the number of rays. Using stratified sampling is more efficient than fixed rays; approximately 10 rays are needed for performance comparable to stratified sampling with fewer rays [S1].
*   **Resolution Scaling:** For higher-resolution images, the number of points along the ray must be increased to maintain quality [S1].

## Subtopics

### AR-NeRF-R
A defocus renderer trained on AR-NeRF-generated images that allows continuous and intuitive manipulation of defocus strength and focus distance given an input image [S1]. Unlike AR-GAN-DR, where defocus parameters are uniquely determined by the input image, AR-NeRF-R allows interactive adjustment via auxiliary inputs [S1].
*   **Definition:** A conditional U-Net that takes an image and auxiliary parameters (aperture size $s$, focus distance $f$) to output a defocused image [S1].
*   **Training Steps:**
    1.  Generate 128×128 training images using AR-NeRF by increasing input point density [S1].
    2.  Train a conditional U-Net on these images [S1].
    3.  Feed aperture size $s$ and focus distance $f$ as auxiliary scalar inputs to the U-Net [S1].
    4.  Output defocused images by varying $s$ and $f$ continuously [S1].
*   **Parameters:**
    *   $s$: Auxiliary continuous control parameter for defocus strength [S1].
    *   $f$: Auxiliary continuous control parameter for focus plane depth [S1].
*   **Layout:** U-Net with two auxiliary scalar inputs concatenated or injected as conditioning signals [S1].
*   **Usage:** Trained on Oxford Flowers dataset (128×128 images generated by AR-NeRF); evaluated on iPhone2DSLR Flower dataset [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Processing time and memory usage increase linearly with the number of rays and points per ray [S1]. The reduction of synthesis network units from 256 to 128 allows for a larger number of points per ray, improving performance at the cost of slightly increased computation per point [S1].
*   **Measured Performance:** Evaluated on Oxford Flowers, CUB-200-2011, and FFHQ datasets [S1]. AR-NeRF achieves lower FID and KID scores compared to baseline GANs (AR-GAN, AR-GAN++, RGBD-GAN) [S1].
*   **Strengths:** Unsupervised learning of depth and defocus; continuous control of defocus parameters in AR-NeRF-R; effective handling of aperture rendering [S1].
*   **Limitations:** Requires careful tuning of discriminator architecture based on dataset alignment (CoordConv vs. no CoordConv) [S1]. Higher resolutions require increased point density, impacting memory [S1].
*   **When to Use:** When unsupervised learning of depth and defocus from natural images is required, and explicit annotations are unavailable [S1].
*   **When Not to Use:** When supervised depth estimation is available and defocus control is not the primary goal; when computational resources are severely limited for high-resolution rendering [S1].

## Background
AR-NeRF was introduced in the paper "AR-NeRF: Unsupervised Learning of Depth and Defocus Effects from Natural Images with Aperture Rendering Neural Radiance Fields" [S1]. It builds upon pi-GAN, a state-of-the-art generative variant of NeRF [S1]. The method was applied to three datasets: Oxford Flowers (8,189 images, 102 categories), CUB-200-2011 (11,788 images, 200 bird species), and FFHQ (70,000 face images) [S1]. The architecture was carefully tuned from pi-GAN, including reducing synthesis network units and adjusting discriminator components based on dataset characteristics [S1].
