# Object Decomposition and Composition
## Overview
Object Decomposition and Composition methods extend standard NeRF architectures to separate a scene into distinct object instances and a background, enabling individual object manipulation, editing, and amodal segmentation [14428-sparse-view-and-few-shot-optimization.md]. Unlike sibling methods that may rely on explicit point clouds or separate segmentation pipelines, these approaches integrate decomposition into the differentiable rendering pipeline, often using one-hot activation mechanisms or frequency-based partitioning to disentangle objects while maintaining global consistency [13525-dm-nerf.md][14413-unified-decompositional-and-compositional-nerf.md][15935-detail-based-segmentation.md].
## Shared principles
The standard NeRF architecture  serves as the baseline for most modifications. It consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ [14428-sparse-view-and-few-shot-optimization.md].

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories [14428-sparse-view-and-few-shot-optimization.md]:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation [14428-sparse-view-and-few-shot-optimization.md].
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
    [14428-sparse-view-and-few-shot-optimization.md].
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs) [14428-sparse-view-and-few-shot-optimization.md].
## Subtopics

### [DM-NeRF](13525-dm-nerf.md)
DM-NeRF simultaneously reconstructs continuous 3D scene geometry, decomposes all individual objects in 3D space, and supports flexible object shape manipulation (translation, rotation, size adjustment, deformation) from 2D images only [13525-dm-nerf.md]. It extends the standard NeRF architecture by introducing an **object field** that predicts a unique one-hot object code for every 3D point, enabling instance-level decomposition without 3D ground truth labels [13525-dm-nerf.md]. Unlike sibling methods that may rely on explicit point clouds or separate segmentation pipelines, DM-NeRF integrates decomposition and manipulation into a single differentiable rendering pipeline, addressing visual occlusions and collisions via a lightweight inverse query algorithm [13525-dm-nerf.md].

### [Unified Decompositional and Compositional NeRF](14413-unified-decompositional-and-compositional-nerf.md)
Unified Decompositional and Compositional NeRF (UDC-NeRF) is a two-stage framework that jointly learns object-level and scene-level implicit representations to enable both novel view synthesis and scene editing [14413-unified-decompositional-and-compositional-nerf.md]. Unlike methods that treat global scene modeling and local object decomposition as separate tasks, UDC-NeRF unites them in a single pipeline where a coarse global field guides sampling for a fine-grained stage that decomposes the scene into distinct object and background radiance fields [14413-unified-decompositional-and-compositional-nerf.md]. It distinguishes itself from siblings like [DM-NeRF](13525-dm-nerf.md) by explicitly modeling the interaction between decomposition and composition through a one-hot activation mechanism and residual composition, allowing for disentangled object manipulation while maintaining global consistency [14413-unified-decompositional-and-compositional-nerf.md].

### [Detail-based Segmentation](15935-detail-based-segmentation.md)
Detail-based Segmentation is a divide-and-conquer strategy for NeRF optimization that partitions a scene into multiple specialized networks based on the spatial frequency of detected objects [15935-detail-based-segmentation.md]. It solves the problem of single-NeRF networks struggling to learn high-frequency details by assigning high-frequency objects to dedicated NeRFs while grouping low-frequency objects into a shared NeRF [15935-detail-based-segmentation.md]. Unlike siblings that use semantic or geometric cues, this method relies on a user-adjustable frequency threshold to determine network allocation [15935-detail-based-segmentation.md].

#### Fig-NeRF
- **Definition:** Scene composition model for object interpolation and amodal segmentation using two separate NeRF models for foreground and background [S1].
- **Steps:** Use an appearance NeRF conditioned on latent codes for the background model [S1]. Use two photometric losses, one for the foreground and one for the background [S1].

## Background
Origin: Fig-NeRF (April 2021) [91] took on scene composition focusing on object interpolation and amodal segmentation, using two separate NeRF models (deformable Nerfies for foreground, appearance NeRF for background) [S1]. Yang et al. (September 2021) [92] created Object-NeRF, a composition model separating and editing objects using a hybrid voxel-based approach with two different NeRFs conditioned on interpolated voxel features [S1].
