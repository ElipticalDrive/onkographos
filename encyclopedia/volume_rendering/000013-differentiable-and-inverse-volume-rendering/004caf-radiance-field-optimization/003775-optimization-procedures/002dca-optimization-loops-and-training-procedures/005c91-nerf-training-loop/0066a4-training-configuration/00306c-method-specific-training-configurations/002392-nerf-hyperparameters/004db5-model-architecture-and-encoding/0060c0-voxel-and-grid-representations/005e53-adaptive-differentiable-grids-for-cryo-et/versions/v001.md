# Adaptive Differentiable Grids for Cryo-ET

Also called: Adaptive density grid optimization, Adaptive density grids based on an octree structure, Adaptive differentiable grids, Coordinate-based representation with adaptive octree

## Overview
Adaptive Differentiable Grids (ADG) is a coordinate-based neural representation method designed for cryo-electron tomography (cryo-ET) reconstruction and denoising. It replaces the fully connected multi-layer perceptrons (MLPs) used in traditional neural fields with an adaptive octree structure where each node stores an optimizable 3D density grid [S1]. This approach solves the problem of high noise and missing-wedge artifacts in cryo-ET by combining differentiable image formation with regularization priors, offering faster query speeds and better detail preservation than MLP-based methods [S1]. It distinguishes itself from sibling methods like [NeAT](13622-binary-radiance-fields.md) by using discretized density grids with trilinear interpolation instead of local decoders, and from [Binary Radiance Fields](13622-binary-radiance-fields.md) by maintaining continuous density values optimized via a specific tomographic loss [S1].

## How it works
**Inputs:**
*   Tilt-series projections (2D images) from a cryo-ET dataset.
*   Camera parameters (projection geometry).
*   Region of Interest (ROI) bounding box.

**Outputs:**
*   An adaptive octree structure where each enabled node contains a 3D density grid.
*   A reconstructed 3D density volume obtained by querying the octree.

**Data Structures:**
1.  **Octree Node:**
    *   `enabled`: Boolean flag indicating if the node is active.
    *   `grid`: A 3D tensor of shape $(N_x, N_y, N_z)$ storing density values. In the source, $N_x = N_y = N_z$ for all nodes [S1].
    *   `children`: List of 8 child nodes (if divided).
2.  **Density Grid:**
    *   Stores scalar density values at grid vertices.
    *   Queried via differentiable trilinear interpolation [S1].

**Algorithm Steps:**

1.  **Initialization:**
    *   Initialize the octree from the ROI.
    *   Disable all nodes outside the ROI [S1].
    *   Set initial density values in the root node's grid (implementation detail: typically zeros or initialized from a coarse reconstruction, though the source notes "optimized from captured projections" implying the optimization loop handles initialization [S1]).

2.  **Coarse Optimization (Structure Update):**
    *   Use down-sampled projections to update the octree structure.
    *   For each enabled node, uniformly sample octants and compute the standard deviation (SD) of the densities inside the node [S1].
    *   If the SD is significant, the node has a higher chance of being divided into eight child octants [S1].
    *   Solve a mixed-integer program to divide, merge, or keep octants, ensuring the total number of nodes remains below a fixed limit [S1].
    *   *Note:* This step accelerates computation by prioritizing regions with features [S1].

3.  **Fine Optimization (Grid Update):**
    *   Freeze the octree structure.
    *   Update the density grid in each enabled octree node using the original noisy projections [S1].
    *   Apply a binary mask $M$ to exclude rays intersecting fiducial markers or padded gray regions [S1].

4.  **Ray Sampling:**
    *   For each ray, determine the intersection with the current octree.
    *   For each octree node $oc$ crossed by the ray, calculate the number of samples $N_{oc}$:
        $$ N_{oc} = N_{max} \frac{loc}{doc} $$
        where $N_{max}$ is a hyperparameter (maximum samples per node), $loc$ is the length of the ray segment inside node $oc$, and $doc$ is the diagonal length of node $oc$ [S1].
    *   Select $N_{oc}$ 3D positions along the ray segment using stratified random sampling [S1].

5.  **Density Query:**
    *   For a query point $p$, identify the octree node containing $p$.
    *   Retrieve the density $f_\phi(p)$ by performing trilinear interpolation from the eight vertex densities of the density grid within that node [S1].

6.  **Loss Computation:**
    *   Compute the total loss $L_{total}$ as a weighted sum of four terms [S1]:
        $$ L_{total} = L_{data} + k_{tv} L_{tv} + k_{cnlc} L_{cnlc} + k_{bc} L_{bc} $$
    *   **Data Fidelity ($L_{data}$):**
        $$ L_{data}(\phi) = \frac{1}{N} \sum_{i=1}^{N} || M (A f_\phi(p_i) - b_i) ||_2^2 $$
        where $N$ is the batch size (number of sampling points), $A$ is the Radon transform (projection operator), $b_i$ is the measured intensity, and $M$ is the binary mask [S1].
    *   **Total Variation ($L_{tv}$):**
        Standard TV loss applied to the density grid to smooth noise [S1].
    *   **Cross-Nodes Non-Local Constraint ($L_{cnlc}$):**
        Randomly select two enabled nodes $m$ and $n$ inside the ROI. Sample densities $f_\phi(p_i^m)$ and $f_\phi(p_j^n)$ from their grids. Compute:
        $$ L_{cnlc} = \sum || \text{softmax}(f_\phi(p_i^m)^T f_\phi(p_j^n)) f_\phi(p_j^n) - f_\phi(p_i^m) ||_2^2 $$
        This term estimates similarities between density vectors in different nodes to enforce non-local consistency [S1].
    *   **Boundary Consistency ($L_{bc}$):**
        Minimizes density differences between neighboring grids at their shared boundaries to prevent discontinuity artifacts [S1].

7.  **Optimization Loop:**
    *   Backpropagate gradients through the differentiable trilinear interpolation and the projection operator $A$ to update the density grid values [S1].
    *   Repeat steps 2-6 until convergence.

**Parameters:**
*   $N_x, N_y, N_z$: Grid size for each density node. Typically $N_x = N_y = N_z$ [S1].
*   $N_{max}$: Maximum number of samples per node in ray sampling [S1].
*   $k_{tv}, k_{cnlc}, k_{bc}$: Weighting parameters for Total Variation, Cross-Nodes Non-Local Constraint, and Boundary Consistency losses [S1].

**Edge Cases and Pitfalls:**
*   **Noise:** Raw cryo-ET data follows a Poisson model, but preprocessing (motion/intensity correction) allows it to be approximated as Gaussian noise for simplicity [S1].
*   **Discontinuities:** Independent optimization of octree nodes causes artifacts at grid edges. This is mitigated by the boundary consistency loss $L_{bc}$ [S1].
*   **Fiducial Markers:** Rays intersecting fiducial markers or padded borders interfere with reconstruction. A binary mask $M$ excludes these rays from the data-fidelity loss [S1].
*   **Standard Neural Fields:** MLP-based fields are inadequate for high-noise cryo-ET as they either learn noise or oversmooth features [S1].

## Operating characteristics
*   **Time Complexity:** Faster than MLP-based neural fields because querying density involves trilinear interpolation ($O(1)$) rather than evaluating a neural network [S1].
*   **Memory Complexity:** Lower than classical tomographic reconstruction techniques as it does not store the entire 3D volume during optimization, only the active octree nodes [S1].
*   **Performance:** Demonstrated on EMPIAR 10643, EMPIAR 10453, and EMPIAR 11462 datasets [S1].
*   **Strengths:** Better detail preservation in complex regions and effective denoising in uniform regions compared to MLPs [S1].
*   **Limitations:** Requires solving a mixed-integer program for octree updates, which adds complexity to the optimization loop [S1].

## Background
The method was proposed by Wang et al. in the paper "Adaptive differentiable grids for cryo-electron tomography reconstruction and denoising" [S1]. It builds on recent advances in coordinate-based neural representations (neural fields) and octree structures (such as NeAT and ACORN) to address the specific challenges of cryo-ET, including low signal-to-noise ratio and missing-wedge artifacts [S1].
