# Model Architecture Modifications

Also called: NeRF Architecture Variants, Implicit Representation Modifications

## Overview
Model Architecture Modifications extend the standard Neural Radiance Field (NeRF) framework by altering the input conditioning, output heads, or underlying geometric representation to address specific limitations such as sparse views, dynamic scenes, or the need for semantic understanding. Unlike standard NeRF, which maps 3D coordinates and viewing directions to density and color via a static Multi-Layer Perceptron (MLP), these modifications introduce learnable parameters, auxiliary networks, or discrete data structures to encode additional scene properties [S1, S6].

## Shared principles
The standard NeRF architecture consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network [S6]. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ [S6].

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation [S6].
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
    [S6].
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs) [S6].

## Subtopics

### [DoF-NeRF](9432-dof-nerf.md)
DoF-NeRF extends the standard NeRF architecture to simulate depth-of-field effects by introducing two learnable scalar parameters per training view: the aperture parameter $K$ and the focus distance $F$. These parameters are jointly optimized with the NeRF network parameters. The method implements a "concentrate-and-scatter" process based on the Circle of Confusion (CoC) diameter $\delta(h_t) = K \times |1/F - 1/h_t|$. Choose this method when training on shallow depth-of-field inputs to recover an all-in-focus 3D representation.

### [NeRF-VPT](11770-nerf-vpt.md)
NeRF-VPT uses a cascading view prompt tuning paradigm where the RGB output of a preceding stage serves as a visual prompt for the next stage. Each stage $i$ concatenates the positional encoding, direction encoding, and the previous stage's RGB output $\mathbf{c}(r)_{i-1}$. This plug-and-play modification enhances image quality in sparse-view settings without external networks.

### [MixRT](12401-mixrt.md)
MixRT replaces the continuous NeRF MLP with a hybrid representation combining a low-quality triangle mesh, a view-dependent displacement map, and a compressed NeRF model stored in an Instant-NGP hash table. It offloads ray intersection to rasterizers and feature extraction to SIMD units, achieving real-time rendering on edge devices. Choose this for real-time applications on constrained hardware.

### [Activation Feature Density Approximation](12492-activation-feature-density-approximation.md)
This method estimates volumetric density $\hat{d}$ directly from intermediate activation features $\mathbf{f}_\ell$ of the coarse MLP, replacing expensive coarse network evaluations with lightweight statistical computations. It retains the standard density-based rendering formulation while optimizing the density prediction step.

### [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md)
SDF representations replace the standard density field $\sigma(\mathbf{x})$ with a continuous scalar field $s(\mathbf{x})$ representing the distance to the nearest surface. Geometry is defined via the zero-level set, and surface normals are derived from the SDF gradient $\mathbf{n} = \nabla s(\mathbf{x}) / \|\nabla s(\mathbf{x})\|$. Choose this for explicit, smooth surface reconstruction.

### [Volume-Augmented NeRF](12973-volume-augmented-nerf.md)
This variant binds an explicit fluid volume value $v_i$ to each sample point, allowing the network to learn density and color based on fluid flow. The Density MLP takes $\gamma(\mathbf{x}_i)$ and $v_i$ as input. Choose this for dynamic fluid scenes.

### [Neural-PIL Decomposition Architecture](12975-neural-pil-decomposition-architecture.md)
This architecture separates scene estimation into distinct networks for geometry, material properties (BRDF embedding $\mathbf{z}_b$), and illumination (embedding $\mathbf{z}_l$). It uses an expected termination point approach for rendering. Choose this for scenes with varying lighting conditions requiring explicit reflectance decomposition.

### [Feature Fields](12995-feature-fields.md)
Feature Fields generalize NeRF by predicting arbitrary per-point feature signals $\mathbf{f}$ in addition to color and density. These features are rendered using the standard volume integration equation, lifting 2D supervision into a consistent 3D representation.

### [SAID-NeRF](13619-said-nerf.md)
SAID-NeRF decomposes appearance into view-independent diffuse and view-dependent specular components and uses semantic masks from Visual Foundation Models to enforce higher surface densities for transparent objects. It builds on Instant-NGP and Semantic and Feature Branches.

### [MINE](13661-mine.md)
MINE models the frustum of the source camera using a continuous depth Multiplane Image (MPI) representation, conditioned on input images via a fully-convolutional decoder. It renders novel views via homography warping, requiring $1 + N_{\text{planes}}$ forward passes regardless of the number of target views.

### [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md)
These methods replace the continuous MLP with discrete spatial structures (dense grids, sparse voxel trees, or hash tables) to store volume density and appearance features. This enables real-time rendering by leveraging hardware-accelerated interpolation or hashing.

### [Aleth-NeRF](13764-aleth-nerf.md)
Aleth-NeRF introduces a 'Concealing Field' assumption to model illumination adaptive volume rendering, allowing synthesis of normal-light views from low-light or over-exposed LDR images. It uses local and global concealing fields to suppress light transport.

### [Unified Volumetric Avatar (UVA)](13784-unified-volumetric-avatar-uva.md)
UVA anchors structured latent codes to a deformable mesh in canonical space, enabling local and independent editing of geometry and texture for dynamic human avatars. It is end-to-end trainable and jointly optimized with a skinning field.

### [Gear-NeRF](13848-gear-nerf.md)
Gear-NeRF stratifies the scene into motion-based 'gears' using semantic information, assigning higher resolution to regions with larger motion scales. It uses a series of 4D feature volumes, one per gear level, for efficient dynamic scene rendering.

### [Transformer and Vision Model Integration](13911-transformer-and-vision-model-integration.md)
This family integrates Vision Transformers (ViT) to extract global semantic features, which are fused with local CNN features to condition the NeRF MLP. This addresses the lack of global scene modeling in standard MLP-based NeRFs.

### [OPONeRF](14014-oponerf.md)
OPONeRF dynamically conditions network weights $\Theta$ on the point's representation $\mathbf{x}$ and the overall scene representation $\mathbf{F}$, subdividing the scene to handle test-time changes and perturbations.

### [Mixer-NeRF](14073-mixer-nerf.md)
Mixer-NeRF introduces a Hybrid Spatial Feature Learning Module (MLCA) and a Squeeze-and-Excitation (SE) module to mix spatial and channel features before the main MLP inference, addressing the loss of local information in standard NeRF.

### [MuRF (Multi-Baseline Radiance Fields)](15007-murf-multi-baseline-radiance-fields.md)
MuRF constructs a target view frustum volume aligned with the target camera and uses a 3D context-aware convolutional decoder to aggregate multi-view information, solving large baseline synthesis issues.

### [Decentralized Federated NeRF](15032-decentralized-federated-nerf.md)
DecentNeRF distributes training to users, maintaining global and personal MLP weights to handle crowdsourced images with transient personal content, using Secure Multi-Party Computation for aggregation.

### [Neural Proxy](15220-neural-proxy.md)
Neural Proxy represents targets as animatable proxies by injecting an animatable mesh into the scene, combining neural volume rendering with neural texture to enable unseen animation synthesis.

### [ViSNeRF](15255-visnerf.md)
ViSNeRF factorizes the static 3D spatial volume and $K$-D parameter space into vector-matrix components and CP components, respectively, using separate small MLPs for density and color decoding to handle high-dimensional volumetric scenes.

### [EBAD-NeRF](15441-ebad-nerf.md)
EBAD-NeRF reconstructs sharp radiance fields from motion-blurred images by jointly optimizing learnable camera poses and NeRF parameters using hybrid event-RGB data, modeling complex camera motion trajectories.

#### NeRF-VAE
- **Definition:** A generative NeRF model that generalizes to out-of-distribution scenes and removes the need to train on each scene from scratch [S1].
- **Steps:** The NeRF renderer is conditioned on a latent code trained using Iterative Amortized Inference and a ResNet encoder. An attention-based scene function is introduced instead of the typical MLP [S1].
- **Comparison:** Outperforms baseline NeRF with a low number of scene views (5-20), but is outperformed by baseline NeRF when a large number of views are available (100+) due to lower scene expressivity [S1].

#### PIE-NeRF
- **Definition:** A pipeline integrating physics-based elastodynamic simulation with a neural radiance field representation, using a meshless discretisation based on quadratic generalized moving least squares on top of the density field of a NeRF [S1].
- **Steps:** Enables large deformations and nonlinear hyperelastic material simulation directly on the implicit representation and supports interactive manipulation of real-world captured scenes with complex geometries [S1].

#### DäRF Implementation Details
- **Parameters:** NeRF Backbone: K-planes [36]. MDE Model: DPT-hybrid [38]. Optimizer: Adam [21]. NeRF Learning Rate: 1e-2. MDE Learning Rate: 1e-5. LR Schedule: Cosine warmup [S2, unofficial].

#### NeRF Model Architecture
- **Definition:** The neural network architecture for NeRF, consisting of dense layers with ReLU activations, potentially using view directions as input [S3, unofficial].
- **Parameters:** `D`: The depth of the network (number of hidden layers). Default is 8. `input_ch_views`: The number of input channels for view directions. Default is 3. `output_ch`: The number of output channels. Default is 4 (RGB + density). `use_viewdirs`: Boolean flag to determine if view directions are used as input to the network [S3, unofficial].

#### S3-NeRF
- **Definition:** A method using shadow and shading cues to infer scene geometry and enable single-image NeRF training [S1].
- **Steps:** Employ a UNISURF-based occupancy field 3D representation instead of density. Use a modified physics-based rendering equation. Use occupancy-based shadow calculation [S1].

#### NeRF with Time Parameter
- **Steps:** Add a time parameter to the model inputs to adapt NeRF for dynamic scenes. Positionally encode the time parameter and concatenate it with the positional encoding of spatial coordinates $\gamma_x(\mathbf{x})$ [S4].
- **Parameters:** Train using the configuration reported for NeRF's real forward-facing experiments [S4].
- **Comparison:** Adding a time parameter improves quality over vanilla NeRF but still lacks detail, suffers from blurry predictions, and fails to reason about scene dynamics [S4].

#### NeRF-Editing
- **Definition:** The first mesh-based shape deformation method, leveraging explicit representations for scene geometry edits and implicit representations for realistic rendering effects [S5].
- **Steps:** 1. Extract explicit triangular mesh from NeRF. 2. Enable intuitive user-driven deformations through classic ARAP deformation method. 3. Generate tetrahedral mesh around triangular mesh to propagate deformations spatially. 4. Employ tetrahedral vertex interpolation to transform discrete deformations into continuous field. 5. Ensure rays passing through mesh bend according to user adjustments [S5].

#### NeuralEditor
- **Definition:** A method employing a point cloud-guided NeRF model for shape manipulation, leveraging K-D trees and deterministic integration strategy for accurate point cloud-based rendering, with Phong reflection modeling to enhance color fidelity and geometric detail [S5].
- **Steps:** 1. Employ point cloud-guided NeRF model. 2. Leverage K-D trees. 3. Use deterministic integration strategy. 4. Achieve accurate point cloud-based rendering. 5. Apply Phong reflection modeling [S5].

#### Shared G-MLP
- **Definition:** A shared geometry MLP that enables the constraint of multi-view consistency to be propagated from the NeRF branch to the detection branch [S6].
- **Number:** Without the shared G-MLP, performance drops from 50.1 to 48.1 mAP@.25, as the influence of multi-view consistency is only propagated into the image backbone [S6].

## Background
The original NeRF implementation by Mildenhall et al. employed hierarchical rendering with two networks (coarse and fine) to improve computational efficiency [S1]. Subsequent works have focused on accelerating training and inference, often by modifying the architecture to handle specific constraints like sparse views, dynamic scenes, or real-time requirements [S1]. The standard architecture uses positional encoding $\gamma(\mathbf{x}, d_1, d_2)$ to map inputs to high-dimensional vectors [S6].
