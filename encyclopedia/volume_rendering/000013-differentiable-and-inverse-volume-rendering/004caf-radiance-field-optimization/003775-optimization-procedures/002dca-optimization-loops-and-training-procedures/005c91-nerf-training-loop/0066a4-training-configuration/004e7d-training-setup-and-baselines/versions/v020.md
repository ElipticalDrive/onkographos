# Training Setup and Baselines


## Overview
This family defines the specific hyperparameter configurations, data handling strategies, and architectural constraints required to train differentiable volume rendering models, ranging from standard Neural Radiance Fields (NeRF) to generative 3D-aware models and sparse neural volumes. It solves the problem of translating theoretical radiance field formulations into stable, reproducible training pipelines by specifying exact sampling rates, loss functions, and optimization schedules. It differs from sibling articles by focusing on the *configuration* of the training process (e.g., learning rates, batch sizes, specific network inputs like feature volumes or codebooks) rather than the algorithmic loop structure itself [11349-nerf-gt-baseline-training-setup.md][12972-stylegan2-training-configuration.md][13271-nerf-training-setup.md][15254-nlr-baseline.md].

## Shared principles
All methods in this family operate within the differentiable volume rendering framework defined in [NeRF Training Loop](1522-training-loop-setup.md). The core mechanism involves:
1.  **Ray Sampling:** Generating rays from camera poses and sampling points along them.
2.  **Network Query:** Evaluating a neural network (MLP, VDB-based, or Codebook-based) at sample points to predict volume density $\sigma$ and color $\mathbf{c}$.
3.  **Volume Rendering:** Computing the final pixel color $\hat{\mathbf{C}}(\mathbf{r})$ using the discretized volume rendering equation:
    $$ \hat{\mathbf{C}}(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i $$
    where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance and $\delta_i$ is the distance between samples [11349-nerf-gt-baseline-training-setup.md][13271-nerf-training-setup.md][15254-nlr-baseline.md].
4.  **Loss Computation:** Minimizing the difference between rendered images and ground truth, typically using Mean Squared Error (MSE) or adversarial losses [11349-nerf-gt-baseline-training-setup.md][12972-stylegan2-training-configuration.md][13271-nerf-training-setup.md][15254-nlr-baseline.md].
5.  **Optimization:** Updating network parameters using gradient-based optimizers (Adam, RMSprop) [11349-nerf-gt-baseline-training-setup.md][12972-stylegan2-training-configuration.md][13271-nerf-training-setup.md][15254-nlr-baseline.md].

## Subtopics

### [NeRF-GT Baseline Training Setup](11349-nerf-gt-baseline-training-setup.md)
Establishes a reference protocol for NeRF using High Dynamic Range (HDR) inputs to serve as an upper bound for HDR synthesis methods [11349-nerf-gt-baseline-training-setup.md]. It differs from standard NeRF by explicitly handling the dynamic range mismatch between HDR scene representations and LDR ground truth observations via tone-mapping during loss computation [11349-nerf-gt-baseline-training-setup.md]. Unlike [NeRF Training Setup](13271-nerf-training-setup.md), which assumes consistent exposure, this setup addresses high dynamic range challenges that can lead to poor encoding of scene areas [11349-nerf-gt-baseline-training-setup.md]. Choose this when evaluating HDR-to-LDR synthesis methods. Key parameters include 64 coarse samples, 128 fine samples, a batch size of 2,048 rays, resolution 800×600, and 200,000 iterations [11349-nerf-gt-baseline-training-setup.md]. The loss is computed between tone-mapped predicted LDR values and tone-mapped ground truth LDR views [11349-nerf-gt-baseline-training-setup.md].

### [StyleGAN2 Training Configuration](12972-stylegan2-training-configuration.md)
Adapts the StyleGAN2 architecture for 3D-aware generative models using differentiable volume rendering [12972-stylegan2-training-configuration.md]. It solves the problem of stable GAN training for high-resolution 3D synthesis by combining adversarial losses, equalized learning rates, and specific discriminator structures (minibatch standard deviation) rather than purely photometric losses [12972-stylegan2-training-configuration.md]. It differs from NeRF-based setups by relying on adversarial dynamics and R1 regularization [12972-stylegan2-training-configuration.md]. Choose this for 3D-aware generative modeling. Key parameters include RMSprop optimizer ($\eta=0.002$, $\alpha=0.99$, $\epsilon=10^{-8}$), mapping network LR of $0.00002$, EMA decay of 0.999, batch size 32, resolution 64×64, and 500,000 iterations [12972-stylegan2-training-configuration.md]. R1 regularization strength is 1.0 or 0.01, applied every 4 or 16 iterations [12972-stylegan2-training-configuration.md]. Mixed precision (FP16) is used for the generator; sources disagree on whether it applies to the discriminator [12972-stylegan2-training-configuration.md].

### [NeRF Training Setup](13271-nerf-training-setup.md)
Describes the training configuration for NeRF-based models using Nerfstudio and NerfAcc for fast convergence on static scenes [13271-nerf-training-setup.md]. It details the setup for Control-NeRF, which replaces standard positional encoding of 3D positions with sampled feature vectors from a pre-computed volume $V_s$ [13271-nerf-training-setup.md]. It differs from standard NeRF by using feature volumes for the fine network input and from other baselines by utilizing specific libraries like Nerfstudio [13271-nerf-training-setup.md]. Choose this for efficient training of static scenes or when using pre-computed feature volumes. Key parameters include 64 coarse samples, 64 fine samples, batch size 1,024 rays, resolution 504×378 (Control-NeRF) or 128×128 (Image-Based NeRF), and 250 epochs [13271-nerf-training-setup.md]. Direction encoding uses $L=4$ bands [13271-nerf-training-setup.md].

### [NLR Baseline](15254-nlr-baseline.md)
Implements the Neural Lumigraph Representation (NLR) as a foundational reference for differentiable volume rendering [15254-nlr-baseline.md]. It solves novel view synthesis by learning a continuous radiance field parameterized by neural networks, distinct from grid-based or explicit mesh representations [15254-nlr-baseline.md]. Unlike [NeRF Training Setup](13271-nerf-training-setup.md), NLR employs a specific architecture optimized for light fields, and unlike [NeRF-GT Baseline Training Setup](11349-nerf-gt-baseline-training-setup.md), it focuses on the original NLR formulation without meta-learning enhancements [15254-nlr-baseline.md]. Choose this as a baseline for light field learning. Key parameters include 800×600 resolution, with training taking ~2.21s/iteration and rendering ~0.025s/frame [15254-nlr-baseline.md].

#### NeuralVDB Hyperparameter Configuration
Configures training for NeuralVDB, a high-resolution sparse volume representation using hierarchical neural networks [S1, unofficial].
*   **Step:** Batch sampling either draws $2^{16}$ random samples per epoch or resamples a subset of input voxels at fixed intervals (100 or 500) and draws $2^{12}$ batches per epoch. Resampling is used when fine details with thin structures are critical [S1, unofficial].
*   **Parameter:** Subdomain size must be a multiple of 512; too large wastes compute on empty subdomains, too small increases dispatch overhead and causes dominant overlapping halo regions [S1, unofficial]. Network width: Level-1 networks use half the width of level-0 networks. Default level-0 width is 128, depth 3; use 4 layers for volumes requiring more detail [S1, unofficial]. Optimizer: Adam, default LR 0.001. Decay: 0.975 every 100 epochs (no resampling) or 0.75 every 1,000 epochs (with resampling). Max epochs: 2,500 for non-resampled [S1, unofficial].
*   **Comparison:** Dense grid training produces the highest noise. Block grid (dense leaf nodes without active masks) reduces noise but shows visible fog artifacts. Sparse VDB with active voxel masks yields the best visual quality and low noise reconstruction [S1, unofficial].

#### Neural Codebook Training Configuration
Configures training for the Neural Codebook (NCB) for compact real-time radiance fields [S2].
*   **Step:** Multiply learning rate by 0.3 for every 5,000 iterations. Cast the trained NCB to float16 after training [S2].
*   **Parameter:** Optimizer: Adam with $\beta_1 = 0.9$ and $\beta_2 = 0.999$. Weight decay: $1e-5$. Initial learning rate: $5e-3$. Total training iterations: 20,000. Batch size: 100,000 voxels [S2].

## Background
The concept of training differentiable volume rendering pipelines originated with the introduction of Neural Radiance Fields (NeRF) [13271-nerf-training-setup.md]. Subsequent work adapted these pipelines for specific challenges: HDR rendering [11349-nerf-gt-baseline-training-setup.md], 3D-aware generative modeling via StyleGAN2 integration [12972-stylegan2-training-configuration.md], and sparse neural volume representations like NeuralVDB [S1, unofficial] and Neural Codebooks [S2]. The NLR baseline provides an earlier reference for neural light field parameterization [15254-nlr-baseline.md]. Modern implementations often leverage libraries like Nerfstudio and NerfAcc to streamline these configurations [13271-nerf-training-setup.md].
