# Generative Occupancy Fields (GOF)


## Overview
Generative Occupancy Fields (GOF) is a 3D-aware image synthesis method that learns compact object surfaces by transitioning from cumulative volume rendering to surface-point rendering [S1, unofficial]. It solves the problem of diffused surfaces in standard generative radiance fields (like pi-GAN) and the sparse gradient convergence issues in direct occupancy networks by reinterpreting alpha values as occupancy probabilities and using root-finding to locate the surface [S1, unofficial]. Unlike siblings that predict volume density $\sigma$ directly, GOF predicts alpha values $\alpha$ to resolve shape-color ambiguity and enable deterministic surface representation [S1, unofficial].

## How it works
GOF combines a generative radiance field with an occupancy-based surface localization mechanism. The network predicts alpha values (interpreted as occupancy) rather than volume density, allowing the use of root-finding to identify the object surface. Training involves a "shrinking" process where the sampling region contracts around the located surface, ensuring gradient density remains high near the geometry.

### Inputs and Outputs
*   **Inputs:**
    *   Latent code $z \sim p_z$ (typically truncated for inference).
    *   Camera pose $\xi \sim p_\xi$ (defined by origin $o$ and viewing direction $d$).
    *   Near and far bounds $[t_n, t_f]$ for the viewing ray.
*   **Outputs:**
    *   Rendered RGB image $I$.
    *   (Implicitly) A compact 3D surface representation defined by the zero-level set of the occupancy field.

### Data Structures
The core data structure is the neural generator network $G_\theta$.
*   **Architecture:** FiLMed-SIREN backbone [S1, unofficial].
*   **Inputs to Network:** 3D position $x \in \mathbb{R}^3$, viewing direction $d \in S^2$, and latent code $z$.
*   **Outputs from Network:**
    *   Alpha value $\alpha_\theta(x, z) \in [0, 1]$.
    *   Color $c_\theta(x, d, z) \in [0, 1]^3$.
*   **Note:** The network does not explicitly output volume density $\sigma$. Instead, $\sigma$ is implicitly defined by the relationship $\alpha_\theta(x, z) = 1 - \exp(-\sigma_\theta(x, z)\delta_i)$ [S1, unofficial].

### Parameters
*   $\tau$: Threshold for root-finding. Typical value: $0.5$ [S1, unofficial].
*   $N$: Number of points sampled for rendering. Typical value: $12$ [S1, unofficial].
*   $M$: Number of bins/points used for initial surface location via root-finding. Typical value: $12$ [S1, unofficial].
*   $m_s$: Number of secant method iterations for refining surface location. Typical value: $3$ [S1, unofficial].
*   $\Delta_{init}$: Initial sampling interval radius. Defined as $(t_f - t_n)/2$ [S1, unofficial].
*   $\Delta_{min}$: Minimal sampling interval radius (pre-defined constant) [S1, unofficial].
*   $\gamma$: Decay rate for the shrinking interval [S1, unofficial].
*   $\lambda_{normal}, \lambda_{opacity}$: Loss balancing coefficients [S1, unofficial].

### Formulas
**1. Alpha Value Definition**
The network predicts $\alpha_\theta(x, z)$ directly. This is related to the implicit volume density $\sigma_\theta$ and step size $\delta_i$ by:
$$ \alpha_\theta(x_i, z) = 1 - \exp(-\sigma_\theta(x_i, z)\delta_i) $$
This value naturally falls in the range $[0, 1]$ [S1, unofficial].

**2. Rendering (Alpha Composition)**
The integrated color $\tilde{C}(r, z)$ for a ray $r$ is estimated by summing contributions from sampled points $x_i$:
$$ \tilde{C}(r, z) = \sum_{i=1}^{N} \alpha_\theta(x_i, z) \left( \prod_{j<i} (1 - \alpha_\theta(x_j, z)) \right) c_\theta(x_i, d, z) $$
Let $T_i = \prod_{j<i} (1 - \alpha_\theta(x_j, z))$ be the transmittance. Then:
$$ \tilde{C}(r, z) = \sum_{i=1}^{N} T_i \alpha_\theta(x_i, z) c_\theta(x_i, d, z) $$
This is equivalent to the standard volume rendering equation where $\alpha$ replaces $1 - \exp(-\sigma \delta)$ [S1, unofficial].

**3. Surface Location via Root-Finding**
To locate the surface $S$, GOF samples $M$ evenly-spaced points $x_k$ partitioning the volume $[t_n, t_f]$.
1.  Query generator for alpha values $\alpha_\theta(x_k, z)$.
2.  Find the bin $k_S$ where the alpha crosses the threshold $\tau$:
    $$ k_S = \arg\min_k (\alpha_\theta(x_k, z) < \tau \le \alpha_\theta(x_{k+1}, z)) $$
3.  Apply the secant method iteratively $m_s$ times to find the precise surface point $x_s = o + t_s d$ within the bin $[x_{k_S}, x_{k_S+1}]$ [S1, unofficial].

**4. Shrinking Sampling Region**
During training step $n$, the sampling interval $\Delta_n$ shrinks exponentially:
$$ \Delta_n = \max(\Delta_{init} \exp(-\gamma n), \Delta_{min}) $$
Points are sampled uniformly in $[t_s - \Delta_n, t_s + \Delta_n]$. If the region exceeds $[t_n, t_f]$, it is shifted back [S1, unofficial].

**5. Loss Functions**
*   **GAN Loss:**
    $$ L_{origin}(\theta_D, \theta_G) = \mathbb{E}_{z \sim p_z, \xi \sim p_\xi} f(D_{\theta_D}(G_{\theta_G}(z, \xi))) + \mathbb{E}_{I \sim p_D} f(-D_{\theta_D}(I)) + \lambda ||\nabla_{D_{\theta_D}}(I)||_2^2 $$
    where $f(u) = -\log(1 + \exp(-u))$ [S1, unofficial].
*   **Opacity Regularization:** Reduces entropy of alpha values.
    $$ L_{opacity} = \frac{1}{N} \sum_{i=1}^{N} \log(\alpha_\theta(x_i, z)) + \log(1 - \alpha_\theta(x_i, z)) $$
*   **Normal Regularization:** Encourages smooth surface normals $n_\theta$ at surface points $x_s \in S$.
    $$ L_{normal} = \sum_{x_s \in S} ||n_\theta(x_s, z) - n_\theta(x_s + \epsilon, z)||_2 $$
*   **Total Loss:**
    $$ L(\theta, \phi) = L_{origin}(\theta, \phi) + \lambda_{normal} L_{normal} + \lambda_{opacity} L_{opacity} $$
    where $\theta$ are generator parameters and $\phi$ are discriminator parameters [S1, unofficial].

### Pseudocode

```python
import math
import torch

def generate_image(generator, latent_code, camera_origin, camera_direction, 
                   t_near, t_far, N_render, M_root, m_secant, tau, 
                   training_step, gamma, delta_init, delta_min):
    """
    Generates a single image for a given ray and latent code.
    During training, uses shrinking sampling. During inference, can use 
    minimal region or single surface point.
    """
    # 1. Locate Surface via Root-Finding
    # Sample M points evenly spaced in [t_near, t_far]
    t_bins = torch.linspace(t_near, t_far, M_root + 1)
    x_bins = camera_origin + t_bins.unsqueeze(1) * camera_direction.unsqueeze(0)
    
    # Query alpha values (no gradients needed for root finding)
    with torch.no_grad():
        alpha_bins, _ = generator(x_bins, camera_direction, latent_code)
        
    # Find bin where alpha crosses threshold tau
    # alpha < tau (free space) -> alpha >= tau (occupied)
    # Note: Source says alpha < tau <= alpha_next. 
    # We look for the first index k where alpha[k] < tau AND alpha[k+1] >= tau
    is_free = alpha_bins < tau
    is_occupied_next = alpha_bins[1:] >= tau
    
    # Find the transition index
    # k_S is the index in the original bins array
    transition_mask = is_free[:-1] & is_occupied_next
    k_S = torch.argmax(transition_mask.float())
    
    # Secant method refinement
    t_left = t_bins[k_S]
    t_right = t_bins[k_S + 1]
    alpha_left = alpha_bins[k_S]
    alpha_right = alpha_bins[k_S + 1]
    
    for _ in range(m_secant):
        # Linear interpolation (secant method for root finding of alpha - tau = 0)
        t_s = t_left - (alpha_left - tau) * (t_right - t_left) / (alpha_right - alpha_left)
        
        # Clamp to bin
        t_s = torch.clamp(t_s, t_left, t_right)
        
        # Evaluate alpha at new point
        x_s = camera_origin + t_s * camera_direction
        with torch.no_grad():
            alpha_s, _ = generator(x_s.unsqueeze(0), camera_direction, latent_code)
            
        # Update bounds based on alpha_s relative to tau
        if alpha_s < tau:
            t_left = t_s
            alpha_left = alpha_s
        else:
            t_right = t_s
            alpha_right = alpha_s
            
    t_surface = t_s
    x_surface = camera_origin + t_surface * camera_direction
    
    # 2. Determine Sampling Region
    if training_step is not None:
        # Training: Shrinking region
        delta_n = max(delta_init * math.exp(-gamma * training_step), delta_min)
        t_start = t_surface - delta_n
        t_end = t_surface + delta_n
        
        # Clamp to volume bounds
        t_start = max(t_start, t_near)
        t_end = min(t_end, t_far)
        
        # Sample N points uniformly in [t_start, t_end]
        t_samples = torch.linspace(t_start, t_end, N_render)
    else:
        # Inference: Option A - Minimal region cumulative rendering
        # t_samples = torch.linspace(t_surface - delta_min, t_surface + delta_min, N_render)
        
        # Inference: Option B - Single surface point rendering (Speed up)
        # This is theoretically sufficient when delta_min -> 0
        t_samples = torch.tensor([t_surface])
        N_render = 1
        
    # 3. Render
    x_samples = camera_origin + t_samples.unsqueeze(1) * camera_direction.unsqueeze(0)
    alpha_samples, color_samples = generator(x_samples, camera_direction, latent_code)
    
    # Alpha composition
    # T_i = product(1 - alpha_j) for j < i
    # Using cumulative product for efficiency
    one_minus_alpha = 1.0 - alpha_samples
    transmittance = torch.cumprod(one_minus_alpha, dim=0)
    # Shift transmittance: T_0 = 1, T_i = T_{i-1} * (1 - alpha_{i-1})
    # torch.cumprod gives [1-a0, (1-a0)(1-a1), ...]
    # We need [1, (1-a0), (1-a0)(1-a1), ...]
    transmittance = torch.cat([torch.ones_like(transmittance[0:1]), transmittance[:-1]], dim=0)
    
    contribution = transmittance * alpha_samples * color_samples
    color = torch.sum(contribution, dim=0)
    
    return color

class GenerativeOccupancyField:
    def __init__(self, generator, discriminator, lambda_normal, lambda_opacity):
        self.generator = generator
        self.discriminator = discriminator
        self.lambda_normal = lambda_normal
        self.lambda_opacity = lambda_opacity
        
    def compute_loss(self, real_images, latent_codes, camera_poses, 
                     t_near, t_far, N_render, M_root, m_secant, tau, 
                     training_step, gamma, delta_init, delta_min):
        """
        Computes the total GOF loss.
        """
        # 1. Generate fake images
        fake_images = []
        for z, pose in zip(latent_codes, camera_poses):
            # Extract origin and direction from pose
            origin = pose.origin
            direction = pose.direction
            img = generate_image(
                self.generator, z, origin, direction, 
                t_near, t_far, N_render, M_root, m_secant, tau,
                training_step, gamma, delta_init, delta_min
            )
            fake_images.append(img)
        fake_images = torch.stack(fake_images)
        
        # 2. GAN Loss
        # f(u) = -log(1 + exp(-u))
        def f(u):
            return -torch.log(1 + torch.exp(-u))
            
        gan_loss_fake = torch.mean(f(self.discriminator(fake_images)))
        gan_loss_real = torch.mean(f(-self.discriminator(real_images)))
        
        # Gradient penalty
        # lambda * ||grad_D(I)||^2
        # Note: Implementation of gradient penalty usually requires interpolation
        # Here we assume a standard GAN loss structure as per source
        gan_loss = gan_loss_fake + gan_loss_real 
        # Plus gradient penalty term as defined in source eq 7
        # L_origin = E[f(D(G(z)))] + E[f(-D(I))] + lambda ||grad D(I)||^2
        
        # 3. Opacity Regularization
        # Recompute alphas for the sampled points to compute L_opacity
        # This requires re-running the sampling logic or storing it
        # For brevity, assuming we have access to alpha_samples from generation
        # L_opacity = 1/N sum (log(alpha) + log(1-alpha))
        opacity_loss = 0.0
        # ... (compute opacity loss from alpha_samples used in rendering) ...
        
        # 4. Normal Regularization
        # Compute surface normals at x_surface
        # L_normal = sum ||n(x_s) - n(x_s + eps)||^2
        normal_loss = 0.0
        # ... (compute normal loss from surface points) ...
        
        total_loss = gan_loss + self.lambda_normal * normal_loss + self.lambda_opacity * opacity_loss
        return total_loss
```

### Edge Cases and Pitfalls
*   **Shape-Color Ambiguity:** Direct training of generative radiance fields fails to maintain surface compactness because small perturbations on surfaces still lead to realistic RGB images, fooling the discriminator [S1, unofficial]. GOF mitigates this by reinterpreting alpha as occupancy and using root-finding.
*   **Convergence Issues:** Directly applying occupancy representations to generative models causes severe convergence problems due to sparse gradients located only on object surfaces. GOF avoids this by starting with cumulative rendering (dense gradients) and gradually shrinking the sampling region [S1, unofficial].
*   **Density Thresholding:** Predicted densities in generative radiance fields can range from 0 to 50, making it hard to determine an effective threshold for surface location. GOF bypasses this by using alpha values which are bounded in $[0, 1]$ [S1, unofficial].
*   **Inference Speed:** Standard rendering requires $M + m_s + N$ queries. Single-point surface rendering requires $M + m_s + 1$ queries. Baselines typically require $2N$ queries due to hierarchical sampling [S1, unofficial].
*   **Object Type:** GOF is more suitable for solid objects with only one surface. Surface rendering mode may make furry or complex multi-layered images over-smooth and less realistic [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Rendering requires $M + m_s + N$ network queries for standard cumulative rendering, or $M + m_s + 1$ for single-point surface rendering. This is comparable to or slightly higher than baselines requiring $2N$ queries, but surface rendering can be significantly faster for offline applications [S1, unofficial].
*   **Memory Complexity:** Depends on the generator architecture (FiLMed-SIREN). No explicit voxel grid is stored, unlike grid-based methods.
*   **Performance:** Outperforms baselines on MAD (Mean Angle Deviation, measuring compactness) and is comparable on SIDE (Scale-Invariant Depth Error, measuring depth accuracy) on datasets like CelebA, BFM, and Cats [S1, unofficial].
*   **Strengths:** Learns compact and smooth surfaces; resolves shape-color ambiguity; enables efficient surface-only rendering.
*   **Limitations:** Struggles with non-solid or multi-layered objects (e.g., fur); requires careful tuning of shrinking parameters ($\gamma, \Delta_{min}$).

## Background
*   **Origin:** Proposed by Xudong Xu, Xingang Pan, Dahua Lin, and Bo Dai in 2021 [S1, unofficial].
*   **Paper:** "Generative Occupancy Fields for 3D Surface-Aware Image Synthesis" (arXiv:2111.00969) [S1, unofficial].
*   **Development:** GOF builds on the concept of Generative Radiance Fields (GRAFs) and pi-GAN, which suffer from diffused surfaces. It also draws inspiration from Occupancy Networks, which provide deterministic surfaces but suffer from sparse gradients in generative settings. GOF unifies these by transitioning from radiance field rendering to occupancy-based surface rendering during training.
*   **Usage:** Evaluated on CelebA, BFM, and Cats datasets for 3D-aware image synthesis [S1, unofficial].
