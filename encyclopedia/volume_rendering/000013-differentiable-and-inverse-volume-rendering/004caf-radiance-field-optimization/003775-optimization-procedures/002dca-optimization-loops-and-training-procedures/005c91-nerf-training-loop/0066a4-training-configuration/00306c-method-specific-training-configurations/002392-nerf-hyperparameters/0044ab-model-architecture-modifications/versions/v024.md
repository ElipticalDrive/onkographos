# Model Architecture Modifications

Also called: NeRF Architecture Variants, Neural Radiance Field Structural Changes

## Overview
Model Architecture Modifications encompass structural changes to the standard Neural Radiance Field (NeRF) pipeline, which typically consists of two Multi-Layer Perceptrons (MLPs) mapping 3D coordinates and view directions to volume density $\sigma$ and color $\mathbf{c}$ [S6]. These modifications address limitations in standard NeRF regarding geometric accuracy, rendering efficiency, handling of dynamic scenes, and robustness to sparse or adverse input conditions. Unlike standard NeRF, which treats the scene as a monolithic implicit function, these methods introduce auxiliary heads, substitute the continuous MLP with discrete structures (voxels, points, primitives), or augment the input/output domains with semantic, temporal, or physical priors.

## Shared principles
The standard NeRF architecture [S6] serves as the baseline for all modifications. It consists of a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ [14428-sparse-view-and-few-shot-optimization.md].

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories [14428-sparse-view-and-few-shot-optimization.md]:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation [14428-sparse-view-and-few-shot-optimization.md].
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color [14428-sparse-view-and-few-shot-optimization.md]:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs) [14428-sparse-view-and-few-shot-optimization.md].

## Subtopics

### [DoF-NeRF](9432-dof-nerf.md)
DoF-NeRF extends the standard NeRF architecture to simulate depth-of-field (DoF) effects by explicitly modeling the aperture and focus distance. Unlike standard NeRF which assumes all-in-focus inputs, DoF-NeRF introduces two learnable scalar parameters per training view: the aperture parameter $K$ and the focus distance $F$. These are jointly optimized with the NeRF network parameters. The method computes observed colors based on the Circle of Confusion (CoC) diameter $\delta(h_t)$ for a spatial point at object distance $h_t$. It enables the optimization of a clear, all-in-focus 3D scene representation from shallow DoF inputs. See [DoF-NeRF](9432-dof-nerf.md).

### [NeRF-VPT](11770-nerf-vpt.md)
NeRF-VPT is a cascading view prompt tuning paradigm that progressively enhances image quality by using RGB information from preceding rendering iterations as visual prompts for subsequent stages. It solves the problem of limited scene understanding in sparse-view settings by iteratively refining the network's output. Unlike methods relying on external networks, NeRF-VPT uses only the network's internal output as prior knowledge, making it a plug-and-play modification. See [NeRF-VPT](11770-nerf-vpt.md).

### [Activation Feature Density Approximation](12492-activation-feature-density-approximation.md)
This method estimates volumetric density $\hat{d}$ directly from intermediate activation features $\mathbf{f}_\ell$ of a coordinate-based MLP, replacing expensive coarse network evaluations with lightweight computation. It differs from SDF-based methods by retaining the standard density-based rendering formulation while optimizing the density prediction step itself. See [Activation Feature Density Approximation](12492-activation-feature-density-approximation.md).

### [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md)
SDF representations replace the standard NeRF density field $\sigma(\mathbf{x})$ with a continuous scalar field $s(\mathbf{x})$ representing the distance to the nearest surface, defining geometry via the zero-level set $\{\mathbf{x} \mid s(\mathbf{x}) = 0\}$. This addresses geometric inaccuracy and surface holes typical of density-based NeRFs by providing a more explicit and smooth formulation of surfaces. Unlike standard NeRFs that model soft volumetric boundaries, SDF methods leverage the gradient of the distance function for surface normals $\mathbf{n} = \frac{\nabla s(\mathbf{x})}{\|\nabla s(\mathbf{x})\|}$. See [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md).

### [Volume-Augmented NeRF](12973-volume-augmented-nerf.md)
Volume-Augmented NeRF is designed for dynamic scenes, specifically fluid dynamics, where density and color change over time due to fluid flow. Unlike static NeRF, it binds an explicit fluid volume value $v_i$ to each sample point, allowing the renderer to learn density and color based on the spatial distribution provided by a differentiable fluid simulator. It serves as the rendering component in a joint differentiable framework bridging a neural Euler simulator and the radiance field. See [Volume-Augmented NeRF](12973-volume-augmented-nerf.md).

### [Neural-PIL Decomposition Architecture](12975-neural-pil-decomposition-architecture.md)
This architecture separates the estimation of scene geometry, material properties, and illumination into distinct networks to handle varying lighting conditions. Unlike standard NeRF which predicts view-dependent color directly, it predicts density, a BRDF embedding, and an illumination embedding, using a learned pre-integrated lighting network to efficiently render shaded colors. It is chosen when input images are captured under varying illumination and explicit reflectance decomposition is required. See [Neural-PIL Decomposition Architecture](12975-neural-pil-decomposition-architecture.md).

### SAID-NeRF
SAID-NeRF exploits instance masks from Visual Foundation Models (VFMs) to enhance NeRF’s estimation of surfaces of transparent objects. It differs from standard NeRF by decomposing appearance into view-independent diffuse and view-dependent specular components and using semantic segmentation to enforce higher surface densities for transparent objects. It builds on Instant-NGP for efficient encoding and Semantic and Feature Branches for joint optimization. See [SAID-NeRF](13619-said-nerf.md).

### [MINE](13661-mine.md)
MINE models the frustum of the source camera using a continuous depth Multiplane Image (MPI) representation, conditioned on input images via a fully-convolutional decoder. Unlike pixelNeRF and GRF, which model the entire 3D space per ray, MINE reconstructs the frustum of the source camera per plane, allowing rendering of any target view via homography warping after a single encoder pass and a fixed number of decoder passes. This makes MINE significantly more efficient than ray-based methods when rendering multiple novel views. See [MINE](13661-mine.md).

### [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md)
These representations replace the continuous Multi-Layer Perceptron (MLP) function of standard NeRF with discrete, spatially structured data structures (dense voxels, sparse grids, hash tables, or triplanes) to store volume density and appearance features. This substitution enables memory-efficient training, real-time differentiable volume rendering, and scalability to large scenes by avoiding heavy feed-forward computation for every sample point. Unlike MLP-based approaches, these methods retrieve values directly via interpolation or hashing. See [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md).

### [Aleth-NeRF](13764-aleth-nerf.md)
Aleth-NeRF trains on under- and over-exposed images to render normal-light novel views by introducing a 'Concealing Field' assumption, where air particles attenuate emission rather than objects lacking emission. It differs from standard NeRF by modeling illumination adaptive volume rendering through local and global concealing fields to suppress light transport. Unlike RAW-NeRF which requires 16-bit HDR RAW images, Aleth-NeRF operates on standard 8-bit LDR images and trains end-to-end without pre-processing or post-processing enhancement networks. See [Aleth-NeRF](13764-aleth-nerf.md).

### [Transformer and Vision Model Integration](13911-transformer-and-vision-model-integration.md)
This family integrates Vision Transformers (ViT) and general Transformer architectures into Neural Radiance Fields to leverage global semantic understanding and long-range dependencies. It solves the limitations of standard MLP-based NeRFs, which lack explicit global scene modeling and struggle with single-image inputs or occlusions. Unlike sibling methods that rely on per-scene optimization or canonical coordinate systems, these models either generalize across scenes without per-scene tuning or explicitly model self-occlusion via attention mechanisms. See [Transformer and Vision Model Integration](13911-transformer-and-vision-model-integration.md).

### [Human and Specific Subject Modeling](13997-human-and-specific-subject-modeling.md)
This family adapts the standard NeRF architecture to model dynamic human subjects, enabling novel view synthesis and novel pose rendering from monocular or sparse multi-view inputs. Unlike static scene modeling, these methods handle non-rigid deformation, occlusion, and human topology by explicitly integrating parametric human priors (such as SMPL) or structured latent codes anchored to deformable meshes, rather than relying solely on implicit MLP representations. See [Human and Specific Subject Modeling](13997-human-and-specific-subject-modeling.md).

### [OPONeRF](14014-oponerf.md)
OPONeRF personalizes the parameters of the plenoptic mapping function for each sampled 3D point to handle test-time scene changes and robustness against perturbations. Unlike vanilla NeRFs where network parameters are shared and fixed, OPONeRF dynamically conditions the network weights $\Theta$ on the point's representation $\mathbf{x}$ and the overall scene representation $\mathbf{F}$. This approach subdivides the scene and discriminatively responds to local variations, providing more expressiveness than methods that model static appearance as stochastic variables. See [OPONeRF](14014-oponerf.md).

### [Mixer-NeRF](14073-mixer-nerf.md)
Mixer-NeRF addresses the loss of local information and blurry details in standard NeRFs by introducing a hybrid spatial feature learning module (MLCA) and a squeeze-and-excitation (SE) network module. It sets itself apart from standard NeRF by explicitly mixing spatial and channel features via fully connected layers before the main MLP inference, rather than relying solely on positional encoding and MLP weights to capture high-frequency details. See [Mixer-NeRF](14073-mixer-nerf.md).

### [Sparse View and Few-Shot Optimization](14428-sparse-view-and-few-shot-optimization.md)
This family addresses severe overfitting, geometry breakdown, and artifact generation (such as floaters) that occur when training NeRF with a drastically reduced number of input viewpoints ($|S| < 20$). Unlike standard NeRF methods that rely on dense sampling, these techniques mitigate ambiguity through in-situ regularization, deformable sampling strategies, or pseudo-observation densification. See [Sparse View and Few-Shot Optimization](14428-sparse-view-and-few-shot-optimization.md).

### [Mixture-of-Experts and Modular Architectures](14429-mixture-of-experts-and-modular-architectures.md)
This family replaces or augments the single continuous function of standard NeRF with multiple specialized networks (experts) or parallel processing streams(13765-mixture-of-experts-implicit-neural-representation.md). It solves the limitations of conventional Implicit Neural Representations (INRs), which struggle with complex features using a single network, and grid-based INRs, which suffer from boundary discontinuities(13765-mixture-of-experts-implicit-neural-representation.md). It sets itself apart from siblings like DoF-NeRF or Feature Fields by explicitly partitioning the input domain or ray batch among distinct neural modules(13765-mixture-of-experts-implicit-neural-representation.md). See [Mixture-of-Experts and Modular Architectures](14429-mixture-of-experts-and-modular-architectures.md).

### [Uncertainty and Reliability](14487-uncertainty-and-reliability.md)
Uncertainty and Reliability methods extend standard NeRF architectures to quantify prediction confidence, addressing artifacts, redundancy, and geometry collapse in sparse or unstructured data. Unlike deterministic NeRF variants that output fixed values, these methods model the scene as a probabilistic entity, providing pixel-level reliability metrics for color and depth to enable robust filtering and conformal prediction. See [Uncertainty and Reliability](14487-uncertainty-and-reliability.md).

### [Object Decomposition and Composition](14518-object-decomposition-and-composition.md)
These methods extend standard NeRF architectures to explicitly separate a scene into distinct semantic or geometric object instances, enabling instance-level editing, manipulation, and amodal segmentation. Unlike standard NeRF variants that treat the scene as a monolithic radiance field, these methods introduce auxiliary outputs (object codes, separate heads, or latent codes) to decompose the volume. This family is distinguished from sibling methods like Feature Fields or Lighting and Appearance Models by its primary focus on structural decomposition for editing. See [Object Decomposition and Composition](14518-object-decomposition-and-composition.md).

### [Lighting and Appearance Models](14522-lighting-and-appearance-models.md)
Lighting and Appearance Models modify the standard NeRF architecture to explicitly represent illumination and material properties, enabling relighting and handling varying lighting conditions. Unlike standard NeRF, which learns view-dependent color implicitly via an MLP, these models separate albedo from illumination. They differ from siblings like NeRF in the Wild (NeRF-W) by explicitly modeling illumination rather than relying on appearance embeddings, and from Neural Pre-Integrated Lighting (Neural-PIL) by using global bases rather than pre-integrated local lighting. See [Lighting and Appearance Models](14522-lighting-and-appearance-models.md).

### [Optimization and Training Procedures](14565-optimization-and-training-procedures.md)
This family covers the algorithmic procedures for optimizing Neural Radiance Fields (NeRF) and related representations, ranging from standard training loops to specialized acceleration and editing techniques. It addresses the problem of efficiently minimizing the photometric loss between rendered and ground-truth images while managing computational constraints. Unlike standard gradient descent on the full network, methods in this family often employ structural modifications to the optimization scope, such as skipping expensive fine-pass evaluations for empty rays or restricting updates to specific network layers to preserve pre-trained geometric features. See [Optimization and Training Procedures](14565-optimization-and-training-procedures.md).

### [Image Enhancement and Restoration Methods](14566-image-enhancement-and-restoration-methods.md)
Image Enhancement and Restoration Methods address the degradation of input imagery—such as blur, transient occlusions, or low resolution—by integrating restoration mechanisms directly into the NeRF optimization loop. Unlike standard NeRF which assumes sharp, clean inputs, these methods either model the degradation process (e.g., blur kernels) or separate static scene geometry from transient artifacts (e.g., pedestrians) to render clean novel views. They differ from sibling methods like DeblurNeRF and IE-NeRF by focusing on specific degradation types: optical blur, transient occlusions, or resolution limits, often using 2D priors (inpainting, super-resolution) to guide 3D consistency. See [Image Enhancement and Restoration Methods](14566-image-enhancement-and-restoration-methods.md).

### [Modular, Hierarchical, and Latent Architectures](14567-modular-hierarchical-and-latent-architectures.md)
This family extends standard NeRF architectures to handle non-rigid deformation with topological changes and hierarchical scene structures, respectively. HyperNeRF models non-rigidly deforming scenes by lifting the canonical 3D space into a higher-dimensional ambient space, allowing smooth topological variations without discontinuous deformation mappings. Strata-NeRF models stratified scenes (e.g., interior/exterior) by replacing continuous positional encoding inputs with discrete latent codes, preventing the "cloudy" artifacts that arise when training a single continuous field on hierarchical levels. See [Modular, Hierarchical, and Latent Architectures](14567-modular-hierarchical-and-latent-architectures.md).

### [MuRF (Multi-Baseline Radiance Fields)](15007-murf-multi-baseline-radiance-fields.md)
MuRF is a feed-forward method for sparse view synthesis that solves the problem of rendering novel views under varying camera baseline settings, including both small and large baselines. It differs from prior radiance field methods by constructing a **target view frustum volume** aligned with the target camera rather than a reference input view, and by using a **3D context-aware convolutional decoder** instead of independent ray-based rendering. This approach effectively aggregates multi-view information even when overlap between input and target views is small, a common failure mode for reference-volume methods in large baseline scenarios. See [MuRF (Multi-Baseline Radiance Fields)](15007-murf-multi-baseline-radiance-fields.md).

### [Gaussian and Primitive-Based Representations](15011-gaussian-and-primitive-based-representations.md)
This family replaces the continuous Multi-Layer Perceptron (MLP) radiance field with discrete geometric primitives or explicit Gaussian distributions to improve rendering efficiency and geometric fidelity. It differs from sibling methods like Voxel and Sparse Grid Representations by using analytic primitives (quadrics or Gaussians) rather than voxel grids, and from Signed Distance Function (SDF) Representations by relying on alpha-blended primitives rather than implicit surface marching. See [Gaussian and Primitive-Based Representations](15011-gaussian-and-primitive-based-representations.md).

### [Decentralized Federated NeRF](15032-decentralized-federated-nerf.md)
Decentralized Federated NeRF (DecentNeRF) is a framework for learning global 3D scene representations from crowd-sourced images by distributing training computation to users and aggregating only global radiance field models to minimize server compute and personal data leakage. It solves the problem of achieving photorealistic 3D reconstruction of global scene content while preventing the server from reconstructing transient personal content (e.g., users, objects) present in crowdsourced images taken at different times. Unlike centralized approaches like NeRF-W which require all personal user images to be transferred to a central server, or existing federated learning NeRF techniques which assume static scenes devoid of personal information, DecentNeRF handles personal content and uses secure aggregation. It differs from siblings like DoF-NeRF and NeRF-VPT by explicitly decomposing the scene into global and personal radiance fields per user and employing a learned weighted aggregation protocol with Secure Multi-Party Computation (SMPC). See [Decentralized Federated NeRF](15032-decentralized-federated-nerf.md).

### [Neural Proxy](15220-neural-proxy.md)
Neural Proxy is a neural rendering method that represents photo-realistic targets as animatable proxies, enabling the synthesis of unseen animations without temporal learning. It combines neural volume rendering with neural texture by injecting an animatable mesh proxy into the scene, mimicking the traditional CG pipeline of using a 3D mesh for geometry and a texture for appearance. Unlike NeRF, which ties content to continuous Cartesian coordinates making animation difficult, Neural Proxy allows particles to move with the animated proxy geometry. Unlike Neural Texture, which requires animated training samples to render unseen animations, Neural Proxy renders unseen animations by animating the proxy geometry itself. See [Neural Proxy](15220-neural-proxy.md).

### [ViSNeRF](15255-visnerf.md)
ViSNeRF is a hybrid neural radiance field method designed for the efficient synthesis of visualizations from dynamic volumetric scenes with arbitrary adjustable parameters (e.g., time, isovalue, transfer function coefficients). It solves the scalability problem of representing high-dimensional $(3+K)$-D radiance fields by combining explicit feature grids with implicit MLP decoders and applying generalized tensor factorization. Unlike standard NeRF which uses a single MLP, ViSNeRF factorizes the static 3D spatial volume into vector-matrix components and the $K$-D parameter space into CP components, reducing memory complexity from $O(N^3 M^K)$ to $O(N^2 M)$. It is distinguished from siblings like K-Planes and HexPlane by its specific use of separate small MLPs for density and color decoding and its tailored regularization strategies for explicit grid features. See [ViSNeRF](15255-visnerf.md).

### [EBAD-NeRF](15441-ebad-nerf.md)
EBAD-NeRF is a method for reconstructing sharp 3D radiance fields from motion-blurred images by jointly optimizing learnable camera poses and NeRF parameters using hybrid event-RGB data. It distinguishes itself from prior works like BAD-NeRF and E2 NeRF by modeling complex camera motion trajectories with multiple learnable poses rather than linear interpolation or fixed pre-estimated poses, and by explicitly supervising the motion blur via an intensity-change-metric event loss. See [EBAD-NeRF](15441-ebad-nerf.md).

### [Point-NeRF Representation](15538-point-nerf-representation.md)
Point-NeRF replaces the continuous Multi-Layer Perceptron (MLP) function used in standard NeRF with a discrete neural point cloud to model a continuous volumetric radiance field. This approach avoids ray sampling in empty space by leveraging classical point clouds that approximate scene geometry, allowing for faster optimization and higher-quality rendering than standard NeRF. It differs from sibling methods like Gaussian and Primitive-Based Representations by using point-based aggregation rather than volumetric primitives, and from Voxel and Sparse Grid Representations by maintaining explicit geometric anchors rather than implicit grid structures. See [Point-NeRF Representation](15538-point-nerf-representation.md).

### [NeurMiPs](15543-neurmips.md)
NeurMiPs represents a 3D scene as a mixture of $K$ learnable rectangular planar surfaces, where each surface acts as an independent "expert" predicting view-dependent color and transparency via a local neural radiance field. It alleviates the frontal-parallel limitation of traditional Multi-Plane Imagery (MPI) while maintaining high efficiency through analytical ray-plane intersection and parallel CUDA execution, offering superior extrapolation capabilities compared to voxel-based methods like PlenOctrees and KiloNeRF. See [NeurMiPs](15543-neurmips.md).

### [CodeNeRF](15544-codenerf.md)
CodeNeRF is an implicit 3D neural representation that learns the variation of object shapes and textures across a semantic category, enabling the synthesis of novel views of unseen objects from a single unposed input image. Unlike standard NeRF which is scene-specific, CodeNeRF disentangles shape and texture by learning separate latent embeddings, allowing for one-shot reconstruction and explicit editing of object geometry and appearance. It sets itself apart from siblings like DoF-NeRF or NeRF-VPT by jointly optimizing camera pose, shape code, and texture code at inference time without requiring known camera parameters, whereas many alternatives assume fixed or known poses. See [CodeNeRF](15544-codenerf.md).

### [Dynamic Scene and Temporal Modeling](15546-dynamic-scene-and-temporal-modeling.md)
Dynamic Scene and Temporal Modeling extends static Neural Radiance Fields (NeRF) to reconstruct and render scenes that change over time, solving the problem of temporal consistency and motion representation in novel view synthesis. Unlike static NeRF variants that assume a frozen geometry, these methods explicitly model the 4D space-time volume, addressing challenges such as non-rigid deformation, occlusion changes, and the many-to-one mapping ambiguities inherent in dynamic environments. See [Dynamic Scene and Temporal Modeling](15546-dynamic-scene-and-temporal-modeling.md).

### [NeRF-Casting](15547-nerf-casting.md)
NeRF-Casting is a method for synthesizing photorealistic specular appearance and reflections in real-world scenes by integrating ray tracing into the NeRF rendering pipeline. It solves the problem of view-dependent appearance modeling by casting reflection rays from points along camera rays into the NeRF geometry to render feature vectors, which are then decoded into color using a small MLP, rather than querying a large MLP for outgoing radiance. Unlike Ref-NeRF, which reparameterizes outgoing radiance as a function of reflected view direction and requires a large MLP to encode the entire environment, NeRF-Casting uses ray tracing to naturally synthesize consistent reflections of nearby and distant content without requiring the MLP to represent the full environment at every point. See [NeRF-Casting](15547-nerf-casting.md).

### [RoseNeRF](15548-rosenerf.md)
RoseNeRF is a method for high-fidelity novel view synthesis of real refractive objects that simplifies complex ray interactions inside transparent media to a single refraction event. It models refraction by predicting a single refracted ray using a 4D light field representation and a refraction network, avoiding the need for Index of Refraction (IoR) fields or detailed surface reconstructions. Unlike deformation field methods that predict position offsets for each sampling point, RoseNeRF predicts the refracted ray and uses hierarchical sampling, avoiding the need for point-by-point deformation and additional priors like IoR. See [RoseNeRF](15548-rosenerf.md).

### NeRF-Det
NeRF-Det is a method for indoor 3D object detection using posed RGB images that explicitly models scene geometry as an opacity field by jointly training a NeRF branch with a 3D detection pipeline. It improves upon the "NeRF-then-Det" paradigm (e.g., NeRF-RPN) by integrating multi-view geometry constraints from the NeRF branch into 3D detection through a shared geometry MLP, enabling end-to-end training without per-scene optimization. Unlike prior methods that struggle to model geometry or rely on external depth estimation, NeRF-Det learns a generalizable geometry-aware volumetric representation that enhances detection accuracy while maintaining low inference latency. See [NeRF-Det](15549-nerf-det.md).

### [Semantic and Feature Field Extensions](15556-semantic-and-feature-field-extensions.md)
Semantic and Feature Field Extensions generalize the standard NeRF formulation by predicting arbitrary per-point feature signals $\mathbf{f}$ in addition to color $\mathbf{c}$ and density $\sigma$. This allows the network to learn quantities such as semantic labels, physical properties, or embeddings from 2D foundation models, enabling 3D-aware semantic understanding and zero-shot query-based editing. Unlike standard NeRF which is purely photometric, these methods lift 2D supervision into a consistent 3D representation. See [Semantic and Feature Field Extensions](15556-semantic-and-feature-field-extensions.md).

### [Neural Density-Distance Fields](15665-neural-density-distance-fields.md)
Neural Density-Distance Fields (NeDDF) is a method that reciprocally constrains distance and density fields, extending the distance field formulation to adapt to any density field. It allows for boundaryless scenes and complex shapes by deriving density from depth values obtained via volume rendering. Unlike standard NeRF which predicts density directly, NeDDF predicts a distance field $D$ and computes density $\sigma$ via its gradient, enabling more stable mesh extraction and camera pose localization through reprojection error. See [Neural Density-Distance Fields](15665-neural-density-distance-fields.md).

### [LAENeRF](15738-laenerf.md)
LAENeRF is a unified framework for the photorealistic and non-photorealistic local appearance editing of pre-trained Neural Radiance Fields (NeRFs). It solves the problem of recoloring or stylizing arbitrary 3D regions while minimizing background artifacts and maintaining interactivity. Unlike methods that rely on semantic segmentation masks or single-target colors, LAENeRF learns a palette-based color decomposition within a user-selected region, enabling smooth transitions to the original scene content. It sets itself apart by estimating per-ray termination points to define the editable region, reducing memory requirements compared to voxel-based approaches, and introducing geometry-aware losses to preserve small structures during stylization. See [LAENeRF](15738-laenerf.md).

### [ExtremeNeRF](15739-extremenerf.md)
ExtremeNeRF is a few-shot view synthesis framework designed to generate novel views from sparse multi-view images captured under unconstrained, varying illumination. Unlike standard NeRF or illumination-robust methods like NeRF-W and RegNeRF that require dense input views or constrained lighting, ExtremeNeRF achieves robustness by enforcing multi-view albedo consistency through a two-stage intrinsic decomposition pipeline. It distinguishes itself by using an offline full-image network (FIDNet) to generate pseudo-albedo ground truths for input images, which then guide an online patch-wise network (PIDNet) to decompose synthesized novel view patches, ensuring that the learned geometry and appearance are illumination-invariant. See [ExtremeNeRF](15739-extremenerf.md).

### [Frequency-Modulated Point Cloud Rendering](15903-frequency-modulated-point-cloud-rendering.md)
Frequency-Modulated Point Cloud Rendering (also known as AFNet or FreqPCR) is a real-time rendering pipeline that replaces the standard continuous MLP radiance field with a point cloud representation modulated by an Adaptive Frequency Net (AFNet). It solves the problem of high-frequency detail reconstruction and slow rendering speeds inherent in standard NeRF architectures by using a hypernetwork to predict local texture frequencies and phases for each point, which are then used to modulate the radiance signal via adaptive activation layers. Unlike standard NeRF which suffers from spectral bias towards low frequencies, this method adapts its frequency basis support locally, enabling high-fidelity reconstruction of textured regions while maintaining low computational cost for smooth regions. It is distinct from sibling methods like Point-NeRF Representation by explicitly modeling frequency modulation per point rather than just using point features, and from Gaussian and Primitive-Based Representations by using a neural activation modulation strategy rather than explicit geometric primitives with fixed kernels. See [Frequency-Modulated Point Cloud Rendering](15903-frequency-modulated-point-cloud-rendering.md).

#### NeRF-VAE
NeRF-VAE is a generative NeRF model that generalizes to out-of-distribution scenes and removes the need to train on each scene from scratch [S1]. The NeRF renderer is conditioned on a latent code, which is trained using Iterative Amortized Inference and a ResNet encoder [S1]. An attention-based scene function is introduced instead of the typical MLP [S1]. It outperforms baseline NeRF with a low number of scene views (5-20), but is outperformed by baseline NeRF when a large number of views are available (100+) due to lower scene expressivity [S1].

#### PIE-NeRF
PIE-NeRF is a pipeline integrating physics-based elastodynamic simulation with a neural radiance field representation, using a meshless discretisation based on quadratic generalized moving least squares on top of the density field of a NeRF [S1]. It enables large deformations and nonlinear hyperelastic material simulation directly on the implicit representation and supports interactive manipulation of real-world captured scenes with complex geometries [S1].

#### DäRF Implementation Details
DäRF uses K-planes as the NeRF backbone and DPT-hybrid as the MDE model [S2, unofficial]. The optimizer is Adam [S2, unofficial]. The NeRF learning rate is 1e-2, and the MDE learning rate is 1e-5 [S2, unofficial]. The LR schedule is cosine warmup [S2, unofficial].

#### NeRF Model Architecture
The neural network architecture for NeRF consists of dense layers with ReLU activations, potentially using view directions as input [S3, unofficial]. The depth of the network (number of hidden layers) `D` defaults to 8 [S3, unofficial]. The number of input channels for view directions `input_ch_views` defaults to 3 [S3, unofficial]. The number of output channels `output_ch` defaults to 4 (RGB + density) [S3, unofficial]. A boolean flag `use_viewdirs` determines if view directions are used as input to the network [S3, unofficial].

#### S3-NeRF
S3-NeRF is a method using shadow and shading cues to infer scene geometry and enable single-image NeRF training [S1]. It employs a UNISURF-based occupancy field 3D representation instead of density [S1]. It uses a modified physics-based rendering equation and occupancy-based shadow calculation as key implementation differences [S1].

#### NeuralEditor
NeuralEditor employs a point cloud-guided NeRF model for shape manipulation, leveraging K-D trees and a deterministic integration strategy for accurate point cloud-based rendering [S4]. It applies Phong reflection modeling to enhance color fidelity and geometric detail [S4].

#### Network Architectures
MLPs A and F use the MLP designed in NeRF, with hidden layer sizes increased from 256 to 384 [S5]. MLPs A and F are not used during inference, allowing more time on training [S5]. Small MLP H is the same as the small MLP used in SNeRG, with two hidden layers, each consisting 16 neurons [S5].

#### NeRF-Swin
NeRF-Swin is a baseline method that performs super-resolution on an LR NeRF using released SwinIR models under the 'Real-World Image Super-Resolution' setting, trained on more than 10k LR-HR pairs [S6]. On synthetic Blender dataset, SwinIR may produce false predictions due to domain mismatch [S6]. On real-world LLFF dataset, SwinIR tends to be oversmooth and may predict false color or geometry [S6]. Performance metrics: Blender ×2 (100x100): PSNR 26.34, SSIM 0.913, LPIPS 0.075; Blender ×4 (100x100): PSNR 24.85, SSIM 0.881, LPIPS 0.108; Blender ×2 (200x200): PSNR 28.03, SSIM 0.926, LPIPS 0.058; Blender ×4 (200x200): PSNR 26.78, SSIM 0.906, LPIPS 0.086; LLFF ×2: PSNR 25.18, SSIM 0.793, LPIPS 0.147; LLFF ×4: PSNR 23.26, SSIM 0.685, LPIPS 0.247 [S6].

## Background
The standard NeRF architecture, introduced by Mildenhall et al. [S6], consists of two Multi-Layer Perceptrons (MLPs) mapping 3D coordinates and view directions to volume density and color. Subsequent works have modified this architecture to address specific limitations, such as geometric accuracy [S1], rendering efficiency [S1], handling of dynamic scenes [S1], and robustness to sparse or adverse input conditions [S1].
