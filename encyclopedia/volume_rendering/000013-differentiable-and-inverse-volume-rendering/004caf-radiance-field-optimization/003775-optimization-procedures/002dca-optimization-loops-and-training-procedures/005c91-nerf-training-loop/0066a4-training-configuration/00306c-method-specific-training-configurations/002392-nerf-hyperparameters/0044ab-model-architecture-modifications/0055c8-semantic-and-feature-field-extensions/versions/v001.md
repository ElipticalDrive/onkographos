# Semantic and Feature Field Extensions

Also called: Feature Fields, DINO-enhanced NeRF, Semantic Ray (S-Ray)

## Overview
Semantic and Feature Field Extensions generalize the standard NeRF formulation by predicting arbitrary per-point feature signals $\mathbf{f}$ in addition to color $\mathbf{c}$ and density $\sigma$ [S1, unofficial]. This allows the network to learn quantities such as semantic labels, physical properties, or embeddings from 2D foundation models, enabling 3D-aware semantic understanding and zero-shot query-based editing [S1, unofficial]. Unlike standard NeRF which is purely photometric, these methods lift 2D supervision into a consistent 3D representation [S1, unofficial].

## Shared principles
The standard NeRF architecture consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network . The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ .

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories [14428-sparse-view-and-few-shot-optimization.md]:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation [14428-sparse-view-and-few-shot-optimization.md].
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color [14428-sparse-view-and-few-shot-optimization.md]:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs) [14428-sparse-view-and-few-shot-optimization.md].

## Subtopics

### [Feature Fields](12995-feature-fields.md)
Feature fields generalize the Neural Radiance Field (NeRF) formulation by predicting arbitrary per-point feature signals $\mathbf{f}$ in addition to color $\mathbf{c}$ and density $\sigma$. This extension allows the network to learn any quantity that can be projected and supervised from 2D observations, such as semantic labels, physical properties, or embeddings from 2D foundation models. Unlike standard NeRF which is purely photometric, feature fields enable 3D-aware semantic understanding, object segmentation, and zero-shot query-based editing by lifting 2D supervision into a consistent 3D representation.

### [DINO-enhanced NeRF](15497-dino-enhanced-nerf.md)
DINO-enhanced NeRF integrates pre-trained DINO vision features into the NeRF architecture to enhance few-shot 3D reconstruction. It sets itself apart from siblings [Feature Fields](12995-feature-fields.md) and [Semantic Ray (S-Ray)](15552-semantic-ray-s-ray.md) by specifically leveraging self-supervised features from the DINO family (e.g., DINOv2) and investigating the impact of freezing, fine-tuning via LoRA, and multi-scale fusion of these features.

### [Semantic Ray (S-Ray)](15552-semantic-ray-s-ray.md)
Semantic Ray (S-Ray) is a method for learning a generalizable semantic field that infers semantic labels on novel viewpoints across unseen scenes, addressing the overfitting and lack of generalization inherent in single-scene methods like Semantic-NeRF. It distinguishes itself by decomposing dense attention into intra-view radial and cross-view sparse attentions to efficiently exploit semantic context from multiple reprojected views, enabling a unified model trained on multiple scenes to generalize to new ones.

### NeRF with Frozen DINO Features
#### definition
- [S1, unofficial] A NeRF variant that integrates pre-trained DINOv2 features by projecting them to match NeRF input dimensions and concatenating them with positional encodings before feeding into the NeRF MLP.
#### formula
- [S1, unofficial] $f'(x) = W_f \cdot f(x) + b_f$ where $f(x)$ is the aggregated feature vector from all views, and $W_f, b_f$ are learned linear transformation parameters.
- [S1, unofficial] Input to NeRF MLP: $F_\theta([\gamma(x), \gamma(d), f'(x)]) \rightarrow (c, \sigma)$ where $f'(x)$ is projected to 256 dimensions.
#### parameter
- [S1, unofficial] Feature projection dimension: 256 (matching NeRF hidden units).
- [S1, unofficial] DINO Model: DINOv2-base, pre-trained on ImageNet, frozen during training.
#### layout
- [S1, unofficial] Feature Extraction: DINOv2-base model outputs dense feature maps $F_i \in \mathbb{R}^{H \times W \times D}$ where $D=768$. Features are bilinearly sampled at projected 2D coordinates $(u_i, v_i) = \Pi(P_i, x)$ for each 3D point $x$.
