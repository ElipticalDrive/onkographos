# Conditional Radiance Field with Shared Branch

Also called: CRF with Shared Branch, Modular Conditional Radiance Field

## Overview
This method defines a modular neural radiance field architecture that disentangles shape and color representations to enable efficient instance-specific editing and multi-instance training. It improves upon standard conditional radiance fields by introducing a shared shape branch, which increases view synthesis quality (PSNR 35.79 vs 33.91 on PhotoShapes) and facilitates scaling to larger datasets [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D position $\mathbf{x}$, viewing direction $\mathbf{d}$, instance-specific shape latent code $\mathbf{z}^{(s)} \in \mathbb{R}^{32}$, instance-specific color latent code $\mathbf{z}^{(c)} \in \mathbb{R}^{32}$.
*   **Outputs:** Scalar density $\sigma \in \mathbb{R}$, radiance color $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures:**
The network consists of five Multi-Layer Perceptrons (MLPs), all with 4 hidden layers, 256 channels width, and ReLU activations, outputting 256-dimensional features [S1]:
1.  $F_{\text{share}}$: Shared shape network.
2.  $F_{\text{inst}}$: Instance-specific shape network.
3.  $F_{\text{fuse}}$: Fusion shape network.
4.  $F_{\text{dens}}$: Density output network (linear layer).
5.  $F_{\text{rad}}$: Radiance output network (2-layer MLP).

**Parameters:**
*   Latent code dimension: 32 for both $\mathbf{z}^{(s)}$ and $\mathbf{z}^{(c)}$ [S1].
*   Optimizer: Adam [S1].
*   Training learning rate: $10^{-4}$ [S1].
*   Edit learning rate: $10^{-2}$ [S1].

**Algorithm:**
The forward pass computes density and radiance as follows [S1]:

1.  **Positional Encoding:** Compute positional encodings $\gamma(\mathbf{x})$ and $\gamma(\mathbf{d})$ using the standard NeRF scheme [45].
2.  **Shared Shape Representation:** Pass $\gamma(\mathbf{x})$ through $F_{\text{share}}$ to get shared features $\mathbf{h}_{\text{share}}$.
    $$ \mathbf{h}_{\text{share}} = F_{\text{share}}(\gamma(\mathbf{x})) $$
3.  **Instance-Specific Shape Representation:** Concatenate the shape code $\mathbf{z}^{(s)}$ with $\gamma(\mathbf{x})$, then pass through $F_{\text{inst}}$ to get instance features $\mathbf{h}_{\text{inst}}$.
    $$ \mathbf{h}_{\text{inst}} = F_{\text{inst}}([\mathbf{z}^{(s)}; \gamma(\mathbf{x})]) $$
4.  **Fusion:** Add the shared and instance-specific features, then pass through $F_{\text{fuse}}$ to get fused shape features $\mathbf{h}_{\text{fuse}}$.
    $$ \mathbf{h}_{\text{fuse}} = F_{\text{fuse}}(\mathbf{h}_{\text{share}} + \mathbf{h}_{\text{inst}}) $$
5.  **Density Prediction:** Pass $\mathbf{h}_{\text{fuse}}$ through the linear density network $F_{\text{dens}}$ to obtain scalar density $\sigma$.
    $$ \sigma = F_{\text{dens}}(\mathbf{h}_{\text{fuse}}) $$
6.  **Radiance Prediction:** Concatenate $\mathbf{h}_{\text{fuse}}$, the color code $\mathbf{z}^{(c)}$, and the view direction encoding $\gamma(\mathbf{d})$. Pass this concatenation through the radiance network $F_{\text{rad}}$ to obtain radiance $\mathbf{c}$.
    $$ \mathbf{c} = F_{\text{rad}}([\mathbf{h}_{\text{fuse}}; \mathbf{z}^{(c)}; \gamma(\mathbf{d})]) $$

**Rendering:**
The final color $\hat{C}$ for a ray $r$ is computed via standard volume rendering with alpha compositing [S1]:
$$ \hat{C}(r, \mathbf{z}^{(s)}, \mathbf{z}^{(c)}) = \sum_{i=1}^{N_c} c_i \alpha_i \exp \left( -\sum_{j=1}^{i-1} \sigma_j \delta_j \right) $$
where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ and $\delta_i = t_{i+1} - t_i$ [S1].

**Training:**
The network weights and latent codes $\mathbf{z}^{(s)}_k, \mathbf{z}^{(c)}_k$ for each instance $k$ are jointly optimized using a photometric loss against ground truth colors [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SharedBranchCRF(nn.Module):
    def __init__(self, latent_dim=32, hidden_dim=256, num_layers=4):
        super().__init__()
        self.latent_dim = latent_dim
        
        # Helper to create 4-layer MLPs with ReLU
        def make_mlp(input_dim, output_dim):
            layers = []
            for _ in range(num_layers):
                layers.append(nn.Linear(input_dim, hidden_dim))
                layers.append(nn.ReLU())
                input_dim = hidden_dim
            layers.append(nn.Linear(hidden_dim, output_dim))
            return nn.Sequential(*layers)

        # F_share: takes positional encoding only
        self.F_share = make_mlp(hidden_dim, hidden_dim) # Assumes pos_enc_dim is handled externally or passed
        
        # F_inst: takes [z_s; pos_enc]
        self.F_inst = make_mlp(hidden_dim + latent_dim, hidden_dim)
        
        # F_fuse: takes [h_share + h_inst]
        self.F_fuse = make_mlp(hidden_dim, hidden_dim)
        
        # F_dens: linear layer for density
        self.F_dens = nn.Linear(hidden_dim, 1)
        
        # F_rad: 2-layer MLP for radiance
        self.F_rad = nn.Sequential(
            nn.Linear(hidden_dim + latent_dim + hidden_dim, hidden_dim), # [h_fuse; z_c; d_enc]
            nn.ReLU(),
            nn.Linear(hidden_dim, 3) # Output RGB
        )

    def forward(self, x, d, z_s, z_c, pos_enc_fn):
        """
        x: (N, 3) positions
        d: (N, 3) view directions
        z_s: (N, latent_dim) shape codes
        z_c: (N, latent_dim) color codes
        pos_enc_fn: function to compute positional encoding
        """
        # 1. Positional Encoding
        gamma_x = pos_enc_fn(x)
        gamma_d = pos_enc_fn(d)
        
        # 2. Shared Shape Representation
        h_share = self.F_share(gamma_x)
        
        # 3. Instance-Specific Shape Representation
        # Concatenate z_s and gamma_x
        z_s_expanded = z_s.unsqueeze(1).expand(-1, gamma_x.size(1), -1) if gamma_x.dim() > 1 else z_s
        # Note: Standard NeRF pos_enc is a vector. If x is (N,3), gamma_x is (N, D).
        # z_s is (N, 32). Concat along last dim.
        inst_input = torch.cat([z_s, gamma_x], dim=-1)
        h_inst = self.F_inst(inst_input)
        
        # 4. Fusion
        h_fuse = self.F_fuse(h_share + h_inst)
        
        # 5. Density
        sigma = self.F_dens(h_fuse).squeeze(-1)
        
        # 6. Radiance
        # Concatenate h_fuse, z_c, gamma_d
        rad_input = torch.cat([h_fuse, z_c, gamma_d], dim=-1)
        c = self.F_rad(rad_input)
        
        return c, sigma
```

## Operating characteristics
*   **Performance:** On the PhotoShapes dataset, the shared branch improves PSNR from 33.91 (without shared branch) to 35.79 [S1].
*   **Efficiency:** Caching training rays allows acceleration of color edits by 3.2× and shape edits by 1.9× [S1].
*   **Scalability:** The shared shape branch helps the model scale to more instances compared to models without it [S1].
*   **Complexity:** The architecture uses multiple MLPs (5 total), increasing parameter count compared to a single-branch conditional NeRF, but enables modular updates during editing [S1].

## Background
The method was introduced in "Editing Conditional Radiance Fields" (ICCV 2021) [S1]. It builds on the inductive biases of NeRF [45] and aims to provide a modular model for better shape and color disentanglement, allowing specific submodules to be fine-tuned for editing tasks [S1].
