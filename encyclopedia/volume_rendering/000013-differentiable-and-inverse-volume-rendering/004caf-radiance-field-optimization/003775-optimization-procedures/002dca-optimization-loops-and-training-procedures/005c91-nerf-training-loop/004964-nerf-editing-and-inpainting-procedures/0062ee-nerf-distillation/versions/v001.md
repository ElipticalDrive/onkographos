# NeRF Distillation

Also called: Distilling edit to NeRF, Edit consolidation, Hashgrid export

## Overview
NeRF Distillation is a post-processing optimization procedure that collapses user-defined spatial edits into the canonical representation of a neural radiance field, specifically the Instant-NGP hashgrid format [S1]. Unlike iterative editing methods that maintain a separate deformation field or cage structure, this method re-trains the scene to bake the edits directly into the base hashgrid parameters [S1]. It is distinguished from sibling methods like [Progressive Inpainting-and-Erasing](8658-progressive-inpainting-and-erasing.md) by its focus on consolidating arbitrary geometric or appearance edits into a single, static, high-performance representation without retaining the edit history [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained NeRF representation $f_\theta$ (typically Instant-NGP hashgrids), a set of user-defined edits $\{E_i\}$, each defined by a source region (cage) and a target transformation (deformation), and the original training images.
*   **Output:** A single set of optimized NeRF parameters $\theta'$ representing the edited scene in canonical space.

**Data Structures:**
*   **Hashgrid:** The standard Instant-NGP multi-resolution hash table storing feature vectors.
*   **Mapping Table:** A list of unique mappings $s \to s_{i...j}$ tracked per ray. A mapping represents a transformation of a sample $s$ from canonical space to a deformed space due to edit $i$, potentially followed by edit $j$.
*   **Ray List:** The set of rays to be traced, including original rays and copies for handling mappings.

**Algorithm:**

1.  **Mapping Identification:**
    For each sample $s$ generated along rays during the initial pass:
    *   Check if $s$ lies within the source cage of any edit $i$.
    *   If yes, compute the transformed position $s_i = T_i(s)$. This creates a mapping $s \to s_i$.
    *   Recursively check if $s_i$ lies within the source cage of another edit $j$. If so, compute $s_{ij} = T_j(s_i)$, creating mapping $s \to s_{ij}$.
    *   If $s$ is not transformed, it retains the "default mapping" (identity).
    *   Store all unique mappings for each ray.

2.  **Ray Preparation:**
    *   Identify rays with more than one unique mapping.
    *   For each such ray $r$, generate copies $r'$ corresponding to each alternative mapping.
    *   For each mapping $m \in \{s \to s_{target}\}$:
        *   If the mapping is valid (not broken), prepare to trace the ray with samples transformed according to $m$.
        *   **Broken Mapping Check:** A mapping is "broken" if the target sample $s_{target}$ lies inside the deformed cage of a *later* edit $k$ (where "later" implies a temporal or sequential dependency in the edit list, or simply that applying $k$ would overwrite $i$). If broken, skip this mapping [S1].

3.  **Rendering and Loss Computation:**
    For each ray $r$ and its associated mappings:
    *   Trace the ray. For samples $s$ along the ray:
        *   If $s$ has a mapping $s \to s_{target}$, query the NeRF at $s_{target}$ (in canonical space) to get density $\sigma$ and color $\mathbf{c}$.
        *   If $s$ has the default mapping, query the NeRF at $s$.
    *   Perform volume rendering to compute the pixel color $C$.
    *   Compute the photometric loss $L_{render}$ against the original input image.

4.  **Gradient Propagation and Update:**
    *   **Shared Samples:** If a sample location (in canonical space) is shared by multiple rays or mappings (e.g., outside any cage), it only receives gradients from the *first* ray that references it [S1]. This prevents conflicting updates from different edit paths.
    *   **Non-Copying Edits (Clearing):** If an edit $i$ is non-copying (i.e., it moves content rather than duplicating it), the source region must be cleared to prevent artifacts in the empty space left behind.
        *   Identify samples that end up in the undeformed canonical cage of edit $i$ during their mapping process.
        *   These samples are part of "clearing rays."
        *   For these samples, the integration target is empty space (zero density). The loss encourages $\sigma \to 0$ and $\mathbf{c} \to 0$ (or background) at these locations [S1].

5.  **Optimization Loop:**
    *   Minimize the total loss $L = L_{render} + L_{clear}$ using gradient descent to update $\theta$.
    *   Repeat until convergence.

**Pseudocode:**

```python
def nerf_distillation(nerf_model, edits, training_images, optimizer):
    """
    Distills edits into the NeRF hashgrid.
    :param nerf_model: Instant-NGP model with hashgrids
    :param edits: List of edit objects, each with source_cage, target_transform, and is_copying flag
    :param training_images: List of (image, camera_pose) tuples
    :param optimizer: Optimizer for nerf_model parameters
    """

            for edit in edits:

                    mapping_chain.append((edit.id, transformed_s))
                    current_s = transformed_s
                else:

                mappings.append((s, mapping_chain))
            else:
                mappings.append((s, [])) # Default mapping
        
        ray_mappings[ray_id] = mappings

                # Check for broken mappings

                    continue
                
                # Determine query point in canonical space
                query_point = s
                for edit_id, transformed_s in mapping_chain:
                    query_point = transformed_s
                
                # Query NeRF
                sigma, color = nerf_model.query(query_point)
                
                # Volume rendering step (simplified)
                # In reality, this is integrated over the ray segment
                weight = sigma * exp(-sigma * distance)
                rendered_color += weight * color
                alpha += weight
                
                # Handle non-copying edit clearing
                if not is_copying_edit(mapping_chain[-1].edit_id):
                    # If this sample is part of a clearing ray for a non-copying edit
                    # The target is empty space
                    clear_loss = sigma**2 + (color - background_color)**2
                    total_loss += clear_loss
                
                # Gradient sharing: Only process gradients for the first ray referencing this canonical point
                # This is handled by the optimizer's gradient accumulation logic
                # or by masking gradients for shared points
            
            # Photometric loss
            photometric_loss = (rendered_color - img.pixel_value)**2
            total_loss += photometric_loss
        
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
```

**Parameters:**
*   **Learning Rate:** Standard Adam optimizer settings for Instant-NGP [S1].
*   **Number of Epochs:** Sufficient for convergence of the hashgrid features [S1].
*   **Edit Order:** The order of edits matters for determining "broken" mappings [S1].

**Edge Cases and Pitfalls:**
*   **Broken Mappings:** If a sample is transformed by edit $i$ into a region that is then transformed by edit $j$, and $j$'s deformation overwrites $i$'s result, the mapping is broken. The implementation skips these mappings [S1].
*   **Non-Copying Edits:** Failure to clear the source region of a non-copying edit results in random density or color artifacts in the empty space [S1].
*   **Gradient Conflicts:** Shared sample locations outside cages must only receive gradients from one ray to prevent conflicting updates [S1].

## Operating characteristics
*   **Time Complexity:** Requires re-training the entire scene, which is comparable to initial training time but typically faster due to warm-starting from a pre-trained model [S1].
*   **Memory Complexity:** No additional memory overhead for deformation fields or cages; the final representation is a standard Instant-NGP hashgrid [S1].
*   **Strengths:** Produces a compact, high-performance representation suitable for real-time rendering; consolidates all edits into a single static model [S1].
*   **Limitations:** Cannot easily undo edits; requires re-training for any change; broken mappings may lead to loss of content in complex edit sequences [S1].
*   **When to Use:** When a final, optimized, and compact NeRF representation is needed after multiple edits [S1].
*   **When Not to Use:** When interactive editing or easy undo/redo is required [S1].

## Background
NeRF Distillation was introduced in the context of the NeRFshop pipeline, which aims to provide a comprehensive toolkit for NeRF editing and manipulation [S1]. The method builds on the foundations of converting between NeRF representations, specifically targeting the Instant-NGP hashgrid format for its efficiency [S1]. It addresses the need for a clean, consolidated representation after complex editing operations, avoiding the accumulation of deformation fields [S1].
