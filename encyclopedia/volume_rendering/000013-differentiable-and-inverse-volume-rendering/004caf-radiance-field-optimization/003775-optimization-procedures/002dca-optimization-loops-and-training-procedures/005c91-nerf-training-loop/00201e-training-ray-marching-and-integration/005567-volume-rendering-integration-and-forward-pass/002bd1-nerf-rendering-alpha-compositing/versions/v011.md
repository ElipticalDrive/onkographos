# NeRF Rendering (Alpha Compositing)

Also called: NeRF Integration, NeRF Rendering Equation, Vanilla NeRF Volume Rendering, Standard NeRF rendering, Neural Radiance Field Volume Rendering

## Overview
NeRF Rendering (Alpha Compositing) is the differentiable volume rendering technique used to synthesize novel views from a continuous 5D radiance field by integrating density and color along camera rays [S1, S11]. It solves the problem of mapping discrete 3D scene representations into 2D images by approximating the volume rendering integral via numerical quadrature [S1, S10]. Unlike deterministic ray tracing which follows fixed paths, NeRF leverages a probabilistic density function to determine the expected color contribution of each sample point, handling view-dependent effects and occlusion through alpha compositing [S11]. It sets itself apart from its siblings by serving as the foundational differentiable rendering primitive that enables gradient-based optimization of the neural network parameters [S1, S10].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A trained neural network $F_\Theta$ (typically two MLPs or one multi-output MLP) that maps a 5D coordinate $(x, d)$ to volume density $\sigma$ and color $c$ [S10, S11]. Camera parameters (origin $o$, direction $d$) for each pixel [S11]. Integration bounds $t_n$ (near) and $t_f$ (far) defining the ray segment [S1]. Number of samples $N$ [S3].
*   **Outputs:** Rendered RGB color $\hat{C}(r)$ and optionally expected depth $\hat{D}(r)$ for each pixel [S1][S6, unofficial].

**Data Structures:**
*   **Rays:** Defined by origin $o \in \mathbb{R}^3$ and direction $d \in \mathbb{R}^3$ (normalized) [S11].
*   **Samples:** A set of $N$ points along the ray, represented by distances $t_i$ from the origin, where $x_i = o + t_i d$ [S4].
*   **Predictions:** For each sample $i$, the network outputs density $\sigma_i \in \mathbb{R}$ and color $c_i \in \mathbb{R}^3$ [S10].

**Numbered Steps:**

1.  **Ray Generation:** For each pixel in the target image, generate a camera ray $r(t) = o + td$ using the camera's intrinsic and extrinsic parameters [S1, S3].
2.  **Sampling:** Divide the ray segment $[t_n, t_f]$ into $N$ equally spaced bins. Draw one sample $t_i$ uniformly at random from within each bin $i$ [S1, S10]:
    $$ t_i \sim U\left[t_n + \frac{i-1}{N}(t_f - t_n), t_n + \frac{i}{N}(t_f - t_n)\right] $$
    This is known as non-deterministic stratified sampling [S1, S11].
3.  **Network Query:** For each sample point $x_i = o + t_i d$ and viewing direction $d$, query the neural network to obtain volume density $\sigma_i$ and color $c_i$ [S1, S11].
    $$ [\sigma_i, c_i] = F_\Theta(x_i, d) $$
    Apply activation functions: typically ReLU for density ($\sigma_i \ge 0$) and Sigmoid for color ($c_i \in [0, 1]$) [S8].
4.  **Delta Calculation:** Compute the distance $\delta_i$ between adjacent samples. To handle the end of the ray, append a large value (e.g., $10^{10}$) to the deltas [S6, unofficial][S8]:
    $$ \delta_i = t_{i+1} - t_i \quad \text{for } i < N $$
    $$ \delta_N = \infty \quad (\text{or a large constant}) $$
5.  **Alpha Compositing:** Calculate the opacity $\alpha_i$ for each sample, representing the probability that the ray hits the object at sample $i$ [S1, S8]:
    $$ \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
6.  **Transmittance:** Calculate the accumulated transmittance $T_i$, the probability that the ray travels from the camera to sample $i$ without being intercepted [S1, S3]:
    $$ T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) = \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    Note: $T_1 = 1$ [S7, unofficial]. Add a small epsilon ($\epsilon = 10^{-10}$) to $(1-\alpha_j)$ before the cumulative product to prevent numerical instability [S8].
7.  **Weight Calculation:** Compute the weight $w_i$ for each sample, which is the product of transmittance and opacity [S8]:
    $$ w_i = T_i \alpha_i $$
8.  **Color Integration:** Compute the final rendered color $\hat{C}(r)$ as the weighted sum of colors [S1][S6, unofficial]:
    $$ \hat{C}(r) = \sum_{i=1}^{N} w_i c_i = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) c_i $$
9.  **Depth Integration (Optional):** Compute the expected depth $\hat{D}(r)$ as the weighted sum of sample distances [S1][S6, unofficial]:
    $$ \hat{D}(r) = \sum_{i=1}^{N} w_i t_i $$
10. **Background Handling:** If the background is assumed to be white, add the complement of the accumulated opacity to the RGB result [S6, S7, unofficial]:
    $$ \hat{C}_{final}(r) = \hat{C}(r) + (1 - \sum_{i=1}^{N} w_i) \cdot 1 $$

**Pseudocode:**

```python
import torch
import math

def nerf_render(rays_o, rays_d, t_vals, model, N_samples, white_background=False):
    """
    Render a batch of rays using NeRF alpha compositing.
    
    Args:
        rays_o: Tensor of shape (B, 3), ray origins.
        rays_d: Tensor of shape (B, 3), ray directions (normalized).
        t_vals: Tensor of shape (B, N_samples), sample distances along rays.
        model: Neural network function taking (points, directions) -> (sigma, rgb).
        N_samples: Number of samples per ray.
        white_background: Boolean, if True, composite against white background.
        
    Returns:
        rgb: Tensor of shape (B, 3), rendered colors.
        depth: Tensor of shape (B,), rendered depths.
    """
    # 1. Query Network
    # Expand rays_o and rays_d to match sample dimensions
    # points shape: (B, N_samples, 3)
    points = rays_o.unsqueeze(1) + rays_d.unsqueeze(1) * t_vals.unsqueeze(2)
    
    # directions shape: (B, 1, 3)
    directions = rays_d.unsqueeze(1)
    
    # Query model: returns sigma and rgb
    # sigma shape: (B, N_samples, 1), rgb shape: (B, N_samples, 3)
    sigma, rgb = model(points, directions)
    
    # 2. Apply Activations
    # sigma >= 0
    sigma = torch.relu(sigma)
    # rgb in [0, 1]
    rgb = torch.sigmoid(rgb)
    
    # 3. Compute Deltas
    # delta between adjacent samples
    deltas = t_vals[:, 1:] - t_vals[:, :-1]  # Shape: (B, N_samples - 1)
    
    # Append infinity for the last segment
    # delta_inf shape: (B, 1)
    delta_inf = torch.ones_like(deltas[:, :1]) * 1e10
    deltas = torch.cat([deltas, delta_inf], dim=-1)  # Shape: (B, N_samples)
    
    # 4. Compute Alpha
    # alpha = 1 - exp(-sigma * delta)
    alpha = 1.0 - torch.exp(-sigma * deltas)  # Shape: (B, N_samples)
    
    # 5. Compute Transmittance
    # T_i = product(1 - alpha_j) for j < i
    # Use exclusive cumulative product
    # (1 - alpha) + eps to avoid 0
    eps = 1e-10
    transmittance = torch.cumprod((1.0 - alpha + eps)[:, :-1], dim=-1)  # Shape: (B, N_samples - 1)
    
    # Prepend 1.0 for the first sample
    # T shape: (B, N_samples)
    T = torch.cat([torch.ones_like(transmittance[:, :1]), transmittance], dim=-1)
    
    # 6. Compute Weights
    # w_i = T_i * alpha_i
    weights = T * alpha  # Shape: (B, N_samples)
    
    # 7. Compute RGB
    # rgb_final = sum(w_i * c_i)
    rgb_final = torch.sum(weights.unsqueeze(-1) * rgb, dim=1)  # Shape: (B, 3)
    
    # 8. Compute Depth
    # depth_final = sum(w_i * t_i)
    # Use t_vals[:, 1:] for depth calculation if using deltas, 
    # but standard NeRF uses the sample positions t_vals directly for expected depth.
    # Note: t_vals passed in are the sample positions.
    depth_final = torch.sum(weights * t_vals, dim=1)  # Shape: (B,)
    
    # 9. Background Handling
    if white_background:
        # accumulated opacity
        weights_sum = torch.sum(weights, dim=1, keepdim=True)  # Shape: (B, 1)
        rgb_final = rgb_final + (1.0 - weights_sum)
        
    return rgb_final, depth_final
```

**Parameters:**
*   $N$: Number of samples per ray. Typical values are 64–256 for coarse sampling and 128–512 for fine sampling [S1, S11].
*   $t_n, t_f$: Near and far clipping planes. $t_n$ is usually the camera center or a small offset, $t_f$ is determined by the scene's bounding volume [S1].
*   $\epsilon$: Small constant for numerical stability in transmittance calculation (e.g., $10^{-10}$) [S8].

**Edge Cases and Pitfalls:**
*   **Numerical Instability:** If $\sigma_i \delta_i$ is very large, $\exp(-\sigma_i \delta_i)$ underflows to 0, causing $\alpha_i$ to be 1. If $\sigma_i \delta_i$ is very small, $\alpha_i$ underflows to 0. Using `log` space for transmittance or adding epsilon prevents `NaN` gradients [S8].
*   **Boundary Conditions:** The last sample's delta must be handled carefully. Using a large constant (infinity) ensures that any remaining density beyond the last sample contributes to the final color, preventing dark edges [S6, unofficial][S8].
*   **View-Dependent Effects:** The color $c_i$ depends on the viewing direction $d$. Failing to pass $d$ to the network results in Lambertian (view-independent) rendering, which is incorrect for non-Lambertian materials [S11].

## Subtopics

### [Depth-Guided Sampling](7490-depth-guided-sampling.md)
Focuses sampling on estimated surface regions using depth priors to improve quality and reduce redundant samples.

### [Rendered Depth-Guided Warping](8893-rendered-depth-guided-warping.md)
Uses rendered depth to warp existing image data for consistency regularization during training.

### [Depth-Prior Guided Stratified Sampling](11292-depth-prior-guided-stratified-sampling.md)
Replaces uniform sampling with depth-prior guided stratified sampling to focus on likely surfaces.

### [Neus SDF Volume Rendering](12443-neus-sdf-volume-rendering.md)
Renders SDFs by converting them to density fields using a logistic distribution derivative, concentrating weight at the zero-level set.

### [Progressive Blur Estimation](14151-progressive-blur-estimation.md)
Models blur as a distribution of rays using a two-stage implicit function module.

### [MipNerfModel](14207-mipnerfmodel.md)
Treats rays as cones/cylinders and uses integrated positional encoding to solve aliasing artifacts.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot P)$ per ray, where $N$ is the number of samples and $P$ is the cost of the neural network query [S1, S11]. Total time is proportional to the number of pixels and rays processed.
*   **Memory Complexity:** $O(N \cdot B)$, where $B$ is the batch size (number of rays processed in parallel) [S6, unofficial][S8]. High memory usage can be mitigated by chunking rays [S16, unofficial].
*   **Measured Performance:** On synthetic datasets (e.g., ShapeNet), standard NeRF rendering achieves ~4.2 fps on a single GPU, while optimized variants (e.g., Raymarcher) can reach 34.9 fps with slightly lower PSNR [S19, unofficial]. Real-time rendering (>40 fps) is possible with 2D neural rendering modules like HeadNeRF [S20].
*   **Strengths:** Differentiable, enabling end-to-end training from 2D images; handles view-dependent effects; produces high-quality, photorealistic results [S11].
*   **Limitations:** Computationally expensive due to repeated MLP queries; requires significant training time and compute power [S11]; sensitive to sampling strategies [S1].
*   **When to Use:** When high-quality novel view synthesis is required and training time is acceptable; for scenes with complex lighting and view-dependent effects [S11].
*   **When Not to Use:** When real-time performance is critical without acceleration techniques; when scene geometry is simple and explicit representations (meshes) are sufficient [S11].

## Background
NeRF (Neural Radiance Fields) was first presented by Mildenhall et al. in 2020 [S11]. It represents a scene as a continuous 5D function mapping spatial coordinates and viewing directions to density and color [S10, S11]. The method was inspired by classical volume rendering [22] and differentiable rendering techniques [S1]. It has been widely implemented in platforms like Instant NGP (Müller et al., 2022), Nerfstudio (Tancik et al., 2023), and Luma AI [S11]. Applications include cultural heritage reconstruction, particularly for challenging surfaces like metallic, translucent, or transparent objects [S11].
