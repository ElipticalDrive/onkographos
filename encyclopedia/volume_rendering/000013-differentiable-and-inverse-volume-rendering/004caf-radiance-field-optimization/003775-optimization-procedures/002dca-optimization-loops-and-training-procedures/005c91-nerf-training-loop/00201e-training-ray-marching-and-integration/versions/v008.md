# Training Ray Marching and Integration

Also called: Training Ray Marching, NeRF Forward Pass, Standard NeRF forward

## Overview
Training Ray Marching and Integration is the differentiable forward pass that synthesizes RGB images from a Neural Radiance Field (NeRF) during optimization. It solves the problem of computing gradients for network parameters by approximating the continuous volume rendering integral as a discrete weighted sum along camera rays [S3, S5, S10, unofficial]. Unlike [NeRF Evaluation and Metric Calculation](3079-nerf-evaluation-and-metric-calculation.md), which uses deterministic rendering for reproducible metrics, this method employs stochastic sampling with perturbation to facilitate optimization [S2, S6, unofficial]. It differs from [Standard Metric Computation](13741-standard-metric-computation.md) by encompassing the entire rendering pipeline, including ray generation, adaptive sampling, and neural network evaluation, rather than just post-processing statistical aggregation [S1, S2, unofficial].

## How it works
The method takes camera parameters and a scene representation as input, generates rays, samples points along them using an occupancy grid or uniform distribution, queries a neural network for density and color, and integrates these values using alpha compositing to produce an RGB image and depth map [S3, S5, S10, unofficial].

### Inputs and Outputs
*   **Inputs**:
    *   `rays_o`: Ray origins, float tensor of shape $[N, 3]$ [S2, S10, unofficial].
    *   `rays_d`: Ray directions, float tensor of shape $[N, 3]$ [S2, S10, unofficial].
    *   `nears`/`fars`: Near and far clipping distances for each ray, float tensor of shape $[N]$ [S2, S10, unofficial].
    *   `bound`: Bounding box size scalar defining the spatial extent for ray marching [S2, S10, unofficial].
    *   `density_bitfield`: Packed density bitfield, uint8 array of shape $[C \cdot H^3 / 8]$, used for acceleration [S2, S10, unofficial].
    *   `perturb`: Boolean flag to enable noise addition to sample positions [S2, S10, unofficial].
    *   `max_steps`: Maximum number of sampled points along each ray, int [S2, S10, unofficial].
    *   `dt_gamma`: Time delta gamma parameter (cone angle), float, for adaptive step sizing [S2, S10, unofficial].
    *   `mean_count`: Estimated mean steps to accelerate training, int32 [S2, S10, unofficial].
*   **Outputs**:
    *   `xyzs`: Generated point coordinates, float tensor of shape $[M, 3]$ [S2, S10, unofficial].
    *   `dirs`: View directions, float tensor of shape $[M, 3]$ [S2, S10, unofficial].
    *   `deltas`: Step sizes, float tensor of shape $[M, 2]$ (first element is delta_t, second is rays_t) [S2, S10, unofficial].
    *   `rays`: Ray metadata, int32 tensor of shape $[N, 3]$ storing (index, point_offset, point_count) for each ray [S2, S10, unofficial].
    *   `rgb_map`: Rendered RGB image, shape $[W, H, 3]$ [S5, unofficial].
    *   `depth_map`: Rendered depth image, shape $[W, H]$ [S5, unofficial].
    *   `acc_map`: Accumulated transmittance/opacity map, shape $[W, H]$ [S5, unofficial].

### Data Structures
*   **RayBundle**: Contains `rays_o`, `rays_d`, `nears`, `fars` [S3, unofficial].
*   **OccupancyGrid**: A sparse grid structure used to prune empty space during ray marching. Initialized with `roi_aabb` (scene bounding box), `resolution` (e.g., 128 or 256), and `contraction_type` (e.g., AABB or UN_BOUNDED_SPHERE) [S7, S9, unofficial].
*   **Density Bitfield**: A compact representation of the density field used for fast lookup during ray marching [S2, S10, unofficial].

### Steps
1.  **Ray Generation**: Compute ray origins (`rays_o`) and directions (`rays_d`) in world space using camera parameters and the camera-to-world transformation matrix [S9, S10, unofficial].
2.  **Ray Marching (Sampling)**:
    *   Initialize a counter array to track sample counts [S8, S10, unofficial].
    *   Call the ray marching kernel (e.g., `raymarching.march_rays_train`) with inputs `rays_o`, `rays_d`, `bound`, `density_bitfield`, `nears`, `fars`, `perturb`, `max_steps`, and `dt_gamma` [S10, unofficial].
    *   The kernel uses the occupancy grid or density bitfield to skip empty space and generates sample points `xyzs`, directions `dirs`, deltas `deltas`, and ray indices `rays` [S8, S10, unofficial].
    *   If `perturb` is true, uniform noise in $[-0.5, 0.5] \times \text{sample\_dist}$ is added to z-values, where $\text{sample\_dist} = (\text{fars} - \text{nears}) / \text{num\_steps}$ [S10, unofficial].
    *   If `mean_count` is set and greater than 0, the output is trimmed to this count; if the actual count exceeds `mean_count`, rays are randomly dropped [S2, S10, unofficial].
3.  **Neural Network Query**:
    *   Query the neural network (implicit function) at the sampled points `xyzs` and directions `dirs` to obtain volume density (`sigmas`) and color (`rgbs`) [S10, unofficial].
    *   Scale the queried densities by `density_scale` if applicable [S10, unofficial].
4.  **Integration (Alpha Compositing)**:
    *   Compute segment distances `dists` by taking the difference between consecutive depth values, appending a large constant ($10^{10}$) for the last segment to ensure full contribution if opaque [S5, S10, unofficial].
    *   Compute opacity $\alpha$ for each segment: $\alpha = 1 - \exp(-\sigma \cdot d)$ [S5, unofficial].
    *   Compute transmittance $T$: $T_i = \prod_{j=0}^{i-1} \exp(-\sigma_j \delta_j)$, implemented as cumulative product of $\exp(-\text{density} \times \text{deltas})$ with $T[0]=1$ [S3, unofficial].
    *   Compute weights $w_i$: $w_i = T_i (1 - \exp(-\sigma_i \delta_i))$ [S3, unofficial].
    *   Compute final RGB: $C = \sum w_i c_i$ [S5, unofficial].
    *   Compute final Depth: $D = \sum w_i d_i$ [S5, unofficial].
    *   Compute Accumulated Transmittance: $A = \sum w_i$ [S5, unofficial].
    *   Add background color: $C_{final} = C + (1 - A) \times \text{bg\_color}$ [S7, S10, unofficial].
5.  **Chunking**: If the number of rays exceeds `chunk_size` (default 64 * 1024), process rays in chunks and concatenate results along the batch dimension [S3, S6, unofficial].

    """
    Performs the forward pass for NeRF training.
    """
    # 1. Ray Marching (Sampling)
    # This step is typically implemented in CUDA for performance.
    # Inputs: rays_o [N, 3], rays_d [N, 3], nears [N], fars [N]
    # Outputs: xyzs [M, 3], dirs [M, 3], deltas [M, 2], rays [N, 3]
    xyzs, dirs, deltas, rays = raymarching_march_rays_train(
        rays_o=rays_o,
        rays_d=rays_d,
        bound=bound,
        density_bitfield=density_bitfield,
        nears=nears,
        fars=fars,
        perturb=perturb,
        max_steps=max_steps,
        dt_gamma=dt_gamma,
        mean_count=mean_count
    )
    
    # 2. Neural Network Query
    # Query network for sigmas and RGB at sampled points
    sigmas, rgbs = neural_network_query(xyzs, dirs)
    
    # 3. Integration (Alpha Compositing)
    # Compute weights and composite
    weights_sum, depth, image = raymarching_composite_rays_train(
        sigmas=sigmas,
        rgbs=rgbs,
        deltas=deltas,
        rays=rays,
        bound=bound
    )
    
    # Add background color
    bg_color = torch.tensor([1.0, 1.0, 1.0], device=xyzs.device) # Default white background
    image = image + (1.0 - weights_sum.unsqueeze(-1)) * bg_color
    
    # Normalize depth
    depth = torch.clamp(depth - nears[rays[:, 0]], min=0.0) / (fars[rays[:, 0]] - nears[rays[:, 0]])
    
    return image, depth, weights_sum

def raymarching_march_rays_train(rays_o, rays_d, bound, density_bitfield, nears, fars, perturb, max_steps, dt_gamma, mean_count):
    """
    Simulates the CUDA ray marching kernel.
    """
    # Initialize counter
    counter = torch.zeros(16, dtype=torch.int32, device=rays_o.device)
    local_step = 0
    
    # Generate initial uniform z-values
    num_steps = max_steps
    z_vals = torch.linspace(nears, fars, num_steps).to(rays_o.device)
    
    if perturb:
        sample_dist = (fars - nears) / num_steps
        noise = torch.rand_like(z_vals) * sample_dist * 2.0 - sample_dist
        z_vals = z_vals + noise
        
    # Compute 3D coordinates
    xyzs = rays_o.unsqueeze(1) + rays_d.unsqueeze(1) * z_vals.unsqueeze(2)
    dirs = rays_d.unsqueeze(1).expand_as(xyzs)
    
    # Compute deltas
    dists = z_vals[..., 1:] - z_vals[..., :-1]
    one_e_10 = torch.tensor([1e10], dtype=dists.dtype, device=dists.device)
    dists = torch.cat((dists, one_e_10.expand(dists[..., :1].shape)), dim=-1)
    deltas = torch.stack((dists, dists), dim=-1) # Simplified delta representation
    
    # Pruning and acceleration logic would occur here in CUDA
    # For the sake of this pseudocode, we assume xyzs, dirs, deltas are filtered
    # based on occupancy grid and mean_count
    
    # Return sampled points
    return xyzs, dirs, deltas, torch.arange(len(rays_o)).unsqueeze(1)

def raymarching_composite_rays_train(sigmas, rgbs, deltas, rays, bound):
    """
    Performs alpha compositing.
    """
    # Compute opacity
    alpha = 1.0 - torch.exp(-sigmas * deltas[..., 0])
    
    # Compute transmittance
    transmittance = torch.cat((torch.ones_like(alpha[..., :1]), 
                               torch.cumprod(torch.exp(-sigmas * deltas[..., 0]) + 1e-10, dim=-1)[:-1]), dim=-1)
    
    # Compute weights
    weights = alpha * transmittance
    
    # Composite RGB
    image = torch.sum(weights.unsqueeze(-1) * rgbs, dim=-2)
    
    # Composite Depth
    # Assuming z_vals are available or passed in; here we approximate with midpoints
    # In practice, z_vals are returned from march_rays_train
    # For this simplified version, we assume depth is integrated similarly

    # Accumulated transmittance
    weights_sum = torch.sum(weights, dim=-1)
    
    return weights_sum, image, image # Simplified return

### Parameters and Typical Values
*   `chunk_size`: 64 * 1024 [S6, unofficial].
*   `near_plane`: 0.2 for MIPNeRF360, 0.0 for NeRF Synthetic [S11, unofficial].
*   `render_step_size`: 1e-3 for MIPNeRF360, 5e-3 for NeRF Synthetic [S11, unofficial].
*   `cone_angle` (`dt_gamma`): 0.004 for MIPNeRF360, 0.0 for NeRF Synthetic [S11, unofficial].
*   `alpha_thre`: 1e-2 for MIPNeRF360, 0.0 for NeRF Synthetic [S11, unofficial].
*   `occupancy_grid_res`: 256 if learned background, 128 otherwise [S7, unofficial].
*   `density_bitfield`: uint8 array [S2, S10, unofficial].

### Edge Cases and Pitfalls
*   **Precision**: Add a small epsilon ($10^{-10}$) to $1-\alpha$ in transmittance calculation for numerical stability [S5, unofficial].
*   **Boundaries**: Use a large constant ($10^{10}$) for the last segment's delta to ensure it contributes fully if the volume is opaque [S5, S10, unofficial].
*   **Memory**: Use chunking to avoid out-of-memory errors when processing large numbers of rays [S3, S6, unofficial].
*   **Empty Space**: Use occupancy grid pruning to skip empty space, significantly improving performance [S9, S11, unofficial].

## Subtopics

### Training Ray Marching and Integration — CUDA Ray Marching (Training)
A rendering function that uses an occupancy grid estimator to skip empty space during volume rendering, optimizing performance [S11, unofficial]. It is the core CUDA implementation of the ray marching step, often referred to as `march_rays_train` or `run_cuda` [S11, unofficial].

### Progressive Strided Ray Sampling
A progressive sampling strategy to stabilize GAN training, starting with large stride ray generation and progressively reducing stride size to cover larger regions initially and focus on local regions later [S12]. It involves randomly sampling patches from reference and unseen views, obtaining geometry pseudo-labels via image warping, and decreasing stride $s$ as training proceeds [S12].

### Coarse-to-Fine Optimization Scheme
An optimization strategy where initial optimization uses multi-view stereo normal maps for supervision to rapidly converge mesh geometry, followed by remeshing (subdivision) and a shift to RGB and mask losses to restore fine-grained textures [S13, unofficial]. Remeshing operations are performed at specific iterations (e.g., 100th, 200th, 400th) to increase mesh resolution [S13, unofficial].

### Real-time Novel View Rendering during Training
A procedure to render novel views during training to enable interactive previews by querying the pre-trained NeRF [S14]. It involves querying the NeRF for ray termination and accumulated alpha, and if alpha > 0.5, using the termination point as input to a local appearance editing network [S14].

## Operating characteristics
*   **Time Complexity**: Dominated by the neural network query and ray marching. The use of occupancy grids and density bitfields reduces the number of points queried, improving performance [S9, S11, unofficial].
*   **Memory Complexity**: Scales with the number of rays and samples per ray. Chunking is used to manage memory usage [S3, S6, unofficial].
*   **Performance**: Can achieve real-time rendering on consumer hardware with optimized implementations like Instant-NGP [S2, unofficial].
*   **Strengths**: Differentiable, allowing end-to-end optimization of scene representations from 2D images [S1, S5, unofficial].
*   **Limitations**: Computationally expensive for high-resolution scenes without acceleration structures [S2, unofficial].
*   **When to Use**: During the training phase of NeRFs to compute gradients [S3, S5, unofficial].
*   **When Not to Use**: During evaluation or inference if real-time performance is critical and the model is already trained; use deterministic rendering instead [S2, S6, unofficial].

## Background
The method originates from the NeRF paper by Mildenhall et al. (2020) [S3, S5, unofficial]. It has been developed and optimized in various subsequent works, including Instant-NGP for faster training and rendering [S2, S9, unofficial], and various GAN-based NeRF training approaches [S12][S13, unofficial]. It is widely used in 3D scene reconstruction, novel view synthesis, and inverse rendering tasks [S3, S5, unofficial].
