# HybridNeRF Model Architecture

Also called: HybridNeRF

## Overview
HybridNeRF is a neural radiance field architecture that combines dense multi-resolution 3D feature grids with multi-resolution triplanes to featurize 3D sample locations [S1]. It solves the trade-off between the geometric fidelity of 3D grids and the memory efficiency of 2D representations by using a hybrid feature extraction scheme [S1]. It sets itself apart from pure grid-based methods like [NeRF Network Query with Hashed Embeddings](3107-nerf-network-query-with-hashed-embeddings.md) by incorporating triplanes, and from pure triplane methods by retaining 3D volumetric features, allowing for more robust geometry reconstruction while maintaining high rendering quality [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D point $\mathbf{x}$ and a viewing direction $\mathbf{d}$.
*   **Outputs:** Color $\mathbf{c}$ and signed distance $f$ (from which density $\sigma$ is derived).

**Data Structures:**
1.  **3D Feature Grids:** Three resolution levels with dimensions $128^3$, $256^3$, and $512^3$.
2.  **Triplanes:** Seven resolution levels with dimensions ranging from $128^2$ to $8,192^2$.
3.  **Surfaceness Field:** A $512^3$ voxel grid storing $\beta(\mathbf{x})$, queried via nearest-neighbor interpolation [S1].
4.  **MLPs:** Separate MLPs for color and signed distance prediction.

**Algorithm:**
1.  **Feature Fetching (3D):** For the input point $\mathbf{x}$, fetch $K=4$ features per level from the three 3D feature grids ($128^3, 256^3, 512^3$) using trilinear interpolation.
2.  **Feature Fetching (Triplanes):** For the input point $\mathbf{x}$, fetch $K=4$ features per level from the seven triplane levels ($128^2$ to $8,192^2$) using bilinear interpolation.
3.  **Aggregation (3D):** Sum the fetched features across all three 3D resolution levels to produce a single summed 3D feature vector.
4.  **Aggregation (Triplanes):** Sum the fetched features across all seven triplane resolution levels to produce a single summed triplane feature vector.

6.  **Direction Encoding:** Encode the viewing direction $\mathbf{d}$ using spherical harmonics up to the 4th degree.
7.  **Prediction:**
    *   Pass $\mathbf{v}$ and the encoded direction to the **Signed Distance MLP** to predict $f(\mathbf{x})$.
    *   Pass $\mathbf{v}$ and the encoded direction to the **Color MLP** to predict $\mathbf{c}$.
    *   Query the **Surfaceness Field** at $\mathbf{x}$ to get $\beta(\mathbf{x})$.
8.  **Density Calculation:** Compute density $\sigma(\mathbf{x})$ using the SDF formulation:
    $$ \sigma(\mathbf{x}) = \beta(\mathbf{x}) \Psi(f(\mathbf{x})\beta(\mathbf{x})) $$
    where $\Psi$ is the CDF of the standard Laplace distribution.

**Parameters:**
*   $K=4$: Number of features fetched per level [S1].
*   3D Grid Levels: $128^3, 256^3, 512^3$ [S1].
*   Triplane Levels: 7 levels from $128^2$ to $8,192^2$ [S1].
*   Surfaceness Grid: $512^3$ voxel grid [S1].
*   SH Degree: 4 [S1].

**Pitfalls:**
*   **Aliasing:** The multi-resolution feature grid can cause aliasing artifacts. This is handled using the method described in VR-NeRF [S1].
*   **Surfaceness Tuning:** The surfaceness parameter $\beta(\mathbf{x})$ must be carefully tuned. Too high a value degrades rendering near fine objects and transparent structures [S1]. The Eikonal loss is tracked to determine when to stop increasing surfaceness in specific regions [S1].

## Subtopics

### [Shading Replacement for Relighting](6346-shading-replacement-for-relighting.md)
Shading Replacement for Relighting is a technique for object insertion that avoids inferring scene illumination by replacing the inserted object's shading with shading from existing scene points. It solves the problem of lighting inconsistency when compositing objects into neural radiance field (NeRF) scenes, where naive composition leads to unrealistic results due to varying illumination. It sets itself apart from direct relighting methods by not requiring explicit light source estimation, instead relying on the correlation between surface normals and shading in Lambertian scenes. See [Shading Replacement for Relighting](6346-shading-replacement-for-relighting.md).

### [Hybrid Multi-Space Module](11712-hybrid-multi-space-module.md)
The Hybrid Multi-Space Module extends grid-based NeRF methods (such as iNGP and TensoRF) to handle multiple sub-spaces (e.g., reflections and refractions) by decomposing the multi-space composition information into a small MLP branch, while the main branch models multiple radiance fields using explicit grids. Unlike pure feature-field approaches, this module integrates discrete learnable grids with small MLPs to output densities and colors for each sub-space, enabling efficient rendering of complex light paths in grid-based architectures. It builds on [HybridNeRF Model Architecture](4842-hybridnerf-model-architecture.md). See [Hybrid Multi-Space Module](11712-hybrid-multi-space-module.md).

### [LidaRF Hybrid Representation](12893-lidarf-hybrid-representation.md)
LidaRF is a NeRF variant for street scenes that fuses explicit Lidar point cloud features with an implicit hash-based grid representation to improve geometry and rendering quality under sparse and collinear camera trajectories. It differs from prior Lidar-only NeRF approaches by avoiding low-resolution and incomplete rendering caused by sparse Lidar coverage and limited field of view; instead, it combines explicit Lidar geometry with a high-resolution implicit grid. See [LidaRF Hybrid Representation](12893-lidarf-hybrid-representation.md).

### [Pano-NeRF](15013-pano-nerf.md)
Pano-NeRF is a method for geometry recovery and High Dynamic Range (HDR) novel view synthesis from sparse Low Dynamic Range (LDR) panoramic images. It models the scene using irradiance fields, which treat radiance as both a signal conveying lighting information and a light source illuminating other pixels, thereby increasing observation counts for geometry and leveraging irradiance-radiance attenuation for HDR reconstruction. It differs from standard radiance field methods by integrating surface rendering principles into the volume rendering framework to explicitly model inter-reflection and lighting interactions. See [Pano-NeRF](15013-pano-nerf.md).

### [FastSR-NeRF](16574-fastsr-nerf.md)
FastSR-NeRF is a method that improves the rendering efficiency of Neural Radiance Fields (NeRF) on consumer-grade hardware by combining a lightweight NeRF model with a CNN-based super-resolution (SR) module. It solves the problem of high computational cost and long training times associated with high-resolution NeRF rendering by training the NeRF to produce low-resolution (LR) 3D-consistent features and upscaling them to high-resolution (HR) outputs. Unlike prior NeRF+SR methods that rely on complex training procedures, knowledge distillation, or high-resolution reference images, FastSR-NeRF requires no architectural changes to the NeRF backbone and uses a simple end-to-end training pipeline. See [FastSR-NeRF](16574-fastsr-nerf.md).

### [NeRFCodec](16590-nerfcodec.md)
NeRFCodec is an end-to-end compression framework for plane-based hybrid Neural Radiance Fields (NeRF) that integrates non-linear transform, quantization, and entropy coding to achieve memory-efficient scene representation. It solves the high storage requirements of hybrid representations by leveraging a pre-trained 2D neural image codec, adapted with content-specific parameters for each scene, to compress feature planes while maintaining high visual fidelity. Unlike methods that apply generic image codecs directly or use wavelet transforms, NeRFCodec modifies the encoder and decoder heads of the 2D codec to exploit inter-channel information in feature planes, achieving superior rate-distortion performance with a memory budget of approximately 0.5 MB per scene. See [NeRFCodec](16590-nerfcodec.md).

### Geometry Composition by Segmented Sampling
Geometry Composition by Segmented Sampling is a method for inserting objects into a scene by transforming sampling points from scene coordinates to object coordinates using the inserting position (translation and rotation). It composites density as a normalized sum of densities of corresponding points from scene and object, and reflectance as a weighted sum of reflectance values where weights are the densities of the voxel particles. The final image is rendered using the composited density, reflectance, and shading. See [Geometry Composition by Segmented Sampling](12345-geometry-composition-by-segmented-sampling.md) (Note: No specific article ID provided in prompt for this minor variant, so it is listed here as a subtopic entry).

### HybridNeRF SDF Density Formulation
The HybridNeRF SDF Density Formulation computes density $\sigma_{\text{SDF}}(\mathbf{x})$ as $\beta(\mathbf{x})\Psi(f(\mathbf{x})\beta(\mathbf{x}))$, where $f(\mathbf{x})$ is the signed distance field output, $\beta(\mathbf{x})$ is the surfaceness parameter, and $\Psi$ is the CDF of a standard Laplace distribution. The Laplace CDF $\Psi(s)$ is defined piecewise: $\frac{1}{2} \exp(-s)$ if $s > 0$, and $1 - \frac{1}{2} \exp(s)$ if $s \leq 0$. The surfaceness field $\beta(\mathbf{x})$ is stored in a $512^3$ voxel grid and queried via nearest-neighbor interpolation. See [HybridNeRF SDF Density Formulation](12346-hybridnerf-sdf-density-formulation.md).

### SeaThru-NeRF
SeaThru-NeRF extends NeRFs to handle underwater scattering media by treating the medium as a semi-transparent entity with separate color and density parameters from opaque objects. It replaces the traditional single opaque object density with the sum of object density and medium density, allowing for rendering in scattering media. See [SeaThru-NeRF](12347-seathru-nerf.md).

### Neural Proxy Rendering with Mixed Samplers
Neural Proxy Rendering with Mixed Samplers is a rendering pipeline that mixes a neural proxy sampler for animated objects and a neural scene sampler for static elements, using a neural texture for local surface appearance. It separates the particle set into proxy and scene sets, using triangle intersection methods to determine the convex set of rays intersecting the proxy mesh, and samples local features via Barycentric coordinates. Unlike NeRF which uses global scene information, neural proxy uses local information. See [Neural Proxy Rendering with Mixed Samplers](12348-neural-proxy-rendering.md).

### Normal Smoothness Constraint
Normal Smoothness Constraint is an adaptive constraint that ensures continuity of estimated surface normals in flat regions while preserving sharp features by weighting the normal difference based on albedo similarity. It samples a perturbed point by adding uniform noise in the normalized 3D space with magnitude 0.01, and computes an edge-aware weight mask from the albedo color difference. The loss is minimized to reduce high-frequency noise on continuous surfaces. See [Normal Smoothness Constraint](12349-normal-smoothness-constraint.md).

*   **Limitations:** Negatively impacts quality near fine objects (lamp wires) and transparent structures (glass door) if not carefully tuned [S1]. Requires careful tuning of the surfaceness parameter $\beta(\mathbf{x})$ [S1].

*   **When not:** When rendering very fine details or transparent structures, as quality may degrade [S1].

## Background
HybridNeRF was introduced in the paper "HybridNeRF: Efficient Neural Rendering via Adaptive Volumetric Surfaces" [S1]. It builds on previous work in neural radiance fields, specifically combining ideas from multi-resolution 3D feature grids and triplane-based representations [S1]. The method uses a proposal network similar to Nerfacto to improve sampling efficiency [S1].
