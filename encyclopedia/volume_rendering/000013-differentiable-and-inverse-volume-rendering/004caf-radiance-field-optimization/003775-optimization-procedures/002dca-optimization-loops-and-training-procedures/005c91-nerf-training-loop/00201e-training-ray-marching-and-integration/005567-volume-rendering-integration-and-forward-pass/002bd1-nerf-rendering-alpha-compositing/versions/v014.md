# NeRF Rendering (Alpha Compositing)

Also called: NeRF Integration, NeRF Rendering Equation, Neural Radiance Fields rendering, Alpha Compositing in NeRF, Standard NeRF

## Overview
NeRF Rendering computes the expected color $\hat{C}(r)$ for a camera ray $r$ by discretizing the ray segment $[t_n, t_f]$ into $N$ samples and approximating the volume rendering integral as a weighted sum of emitted colors [S1, S2, S3]. It differs from sibling methods like the [NeRF-style Volume Rendering Integrator](5964-nerf-style-volume-rendering-integrator.md) by explicitly defining the standard two-stage (coarse/fine) sampling and alpha-compositing pipeline that forms the baseline for most Neural Radiance Field implementations [S1, S13].

## How it works
**Inputs:**
*   Ray origin $o$ and direction $d$.
*   Near ($t_n$) and far ($t_f$) clipping distances.
*   Number of samples $N$ (typically 64 for both coarse and fine stages [S11]).
*   Neural network model $F_\Theta$ (MLP) that maps $(x, d)$ to $(\sigma, c)$ [S1, S12].

**Outputs:**
*   Rendered color $\hat{C}(r) \in \mathbb{R}^3$.
*   (Optional) Expected depth $\hat{D}(r)$.

**Data Structures:**
*   **Samples:** Array of $N$ distances $t_i$ along the ray.
*   **Predictions:** For each sample $i$, a tuple $(\sigma_i, c_i)$ where $\sigma_i \ge 0$ is volume density and $c_i \in [0,1]^3$ is color.
*   **Deltas:** Array $\delta_i = t_{i+1} - t_i$ representing interval lengths. $\delta_N$ is typically set to a large value (e.g., $10^{10}$) to ensure the ray terminates [S7, unofficial][S9].

**Steps:**

1.  **Sampling:** Divide the interval $[t_n, t_f]$ into $N$ equally spaced bins. Draw one sample $t_i$ uniformly at random from each bin $[t_n + \frac{i-1}{N}(t_f - t_n), t_n + \frac{i}{N}(t_f - t_n)]$ [S1, S12, S13]. This is known as non-deterministic stratified sampling [S2].
2.  **Query:** For each sample point $x_i = o + t_i d$, compute the positional encoding $\gamma(x_i)$ and $\gamma(d)$, then pass them through the MLP to obtain density $\sigma_i$ and color $c_i$ [S1, S12]. Apply ReLU to $\sigma_i$ and Sigmoid to $c_i$ to enforce bounds [S9].
3.  **Delta Calculation:** Compute the distance between adjacent samples: $\delta_i = t_{i+1} - t_i$ for $i=1 \dots N-1$. Append a large value (e.g., $10^{10}$) for the last segment $\delta_N$ to handle the ray end [S7, unofficial][S9]. Normalize deltas by the ray direction norm if $t_i$ are not in world units [S7, unofficial].
4.  **Alpha Conversion:** Convert density to opacity (alpha) using the Beer-Lambert law approximation:
    $$ \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
    [S1, S2, S9].
5.  **Transmittance Calculation:** Compute the accumulated transmittance $T_i$, the probability that the ray reaches sample $i$ without being absorbed:
    $$ T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) = \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    [S1, S2, S9]. To prevent numerical instability (NaNs) during gradient computation, add a small epsilon ($\epsilon = 10^{-10}$) to the term $(1-\alpha_j)$ before the cumulative product [S9]. $T_1 = 1.0$.
6.  **Weighting:** Compute the weight $w_i$ for each sample:
    $$ w_i = \alpha_i T_i $$
    [S1, S9].
7.  **Compositing:** Compute the final color as the weighted sum:
    $$ \hat{C}(r) = \sum_{i=1}^{N} w_i c_i $$
    [S1, S2, S9].
8.  **Background Handling:** If a white background is assumed, add the contribution of rays that pass through the scene without terminating:
    $$ \hat{C}_{final}(r) = \hat{C}(r) + \left(1 - \sum_{i=1}^{N} w_i\right) c_{bg} $$
    where $c_{bg} = (1, 1, 1)$ [S7, unofficial][S9].

**Pseudocode:**

```python
import torch
import math

def nerf_rendering(rays, t_vals, model, white_back=True, eps=1e-10):
    """
    rays: (B, H, W, 3) ray origins
    t_vals: (B, H, W, N) sample distances along rays
    model: callable taking (points, dirs) -> (sigma, rgb)
    Returns: rgb (B, H, W, 3), depth (B, H, W)
    """
    # 1. Query Model
    # Expand dimensions to match ray structure for broadcasting
    points = rays.unsqueeze(-2) + t_vals.unsqueeze(-1) * rays.unsqueeze(-2).norm(dim=-1, keepdim=True) # Simplified: assume unit direction or normalize
    # Note: Standard implementation uses ray direction directly. 
    # Assuming rays contains origin and direction. 
    # Let's assume rays_flat is (B*H*W*N, 3) and dirs_flat is (B*H*W*N, 3)
    
    # Reshape for model input
    B, H, W, N = t_vals.shape
    rays_flat = rays.reshape(-1, N, 3) # (B*H*W, N, 3)
    # Direction is usually constant per ray. 
    # For simplicity, assume we have ray_dirs of shape (B, H, W, 3)
    # We need to broadcast direction to samples.
    
    # Standard NeRF implementation (e.g., kwea123/nerf_pl) structure:
    # 1. Get predictions
    # 2. Slice sigma and rgb
    # 3. Compute deltas
    # 4. Compute alpha
    # 5. Compute transmittance
    # 6. Compute weights
    # 7. Composite
    
    # Placeholder for model call logic which depends on specific architecture
    # predictions shape: (B, H, W, N, 4) -> [rgb, sigma]
    predictions = model(rays_flat) # Returns (B*H*W, N, 4)
    predictions = predictions.reshape(B, H, W, N, 4)
    
    rgb = torch.sigmoid(predictions[..., :3])
    sigma = torch.relu(predictions[..., 3])
    
    # 2. Deltas
    # delta = t[i+1] - t[i]
    deltas = t_vals[..., 1:] - t_vals[..., :-1] # (B, H, W, N-1)
    
    # Append infinity for the last segment
    delta_inf = torch.ones_like(deltas[..., :1]) * 1e10
    deltas = torch.cat([deltas, delta_inf], dim=-1) # (B, H, W, N)
    
    # Normalize deltas by ray direction norm if t_vals are not in world units
    # Assuming rays include direction, we normalize here if needed. 
    # In many implementations, t_vals are already in world units or direction is normalized.
    # If not: deltas = deltas * torch.norm(ray_dirs, dim=-1, keepdim=True)
    
    # 3. Alpha
    alpha = 1.0 - torch.exp(-sigma * deltas)
    
    # 4. Transmittance
    # T[i] = product(1 - alpha[j]) for j < i
    # Use cumprod with exclusive=True
    # Add eps to prevent 0s
    transmittance = torch.cumprod((1.0 - alpha + eps)[:, :, :, :-1], dim=-1) # (B, H, W, N-1)
    # Prepend 1.0 for the first sample
    transmittance = torch.cat([torch.ones_like(transmittance[..., :1]), transmittance], dim=-1) # (B, H, W, N)
    
    # 5. Weights
    weights = alpha * transmittance
    
    # 6. Color
    rgb_final = torch.sum(weights.unsqueeze(-1) * rgb, dim=-2) # (B, H, W, 3)
    
    # 7. Background
    if white_back:
        weights_sum = torch.sum(weights, dim=-1, keepdim=True) # (B, H, W, 1)
        rgb_final = rgb_final + (1.0 - weights_sum) * torch.tensor([1.0, 1.0, 1.0])
        
    # 8. Depth (Optional)
    depth_final = torch.sum(weights * t_vals, dim=-1) # (B, H, W)
    
    return rgb_final, depth_final
```

## Subtopics

### [Depth-Guided Sampling](7490-depth-guided-sampling.md)
Focuses scene sampling on estimated surface regions using depth priors to increase sample density in relevant areas, reducing redundant sampling in free space.

### [Rendered Depth-Guided Warping](8893-rendered-depth-guided-warping.md)
Uses rendered depth to warp existing image data for consistency regularization, rather than guiding ray sampling.

### [Depth-Prior Guided Stratified Sampling](11292-depth-prior-guided-stratified-sampling.md)
Replaces uniform depth sampling by using predicted depth priors and confidence bounds to focus sampling on likely object surfaces.

### [Neus SDF Volume Rendering](12443-neus-sdf-volume-rendering.md)
Replaces standard density with an SDF-based weighting scheme, concentrating weight at the zero-level set of the SDF for precise surface extraction.

### [Progressive Blur Estimation](14151-progressive-blur-estimation.md)
Models blur as a distribution of rays using a two-stage implicit function module, predicting multiple ray origins and directions.

### [MipNerfModel](14207-mipnerfmodel.md)
Approximates integrated positional encoding by treating rays as cones/cylinders to solve aliasing artifacts, using multi-level sampling.

### [Event Simulation from NeRF](15450-event-simulation-from-nerf.md)
Simulates asynchronous event streams from a NeRF to supervise training using real event camera observations, handling motion blur.

### NeRF Rendering Pipeline
A standard inference loop that iterates over camera poses, renders RGB and depth using the volume rendering equation, and optionally computes PSNR or saves images. It often includes downsampling via a `render_factor` for speed and processes rays in chunks to manage memory [S18, unofficial].

### NeRF-XL Multi-GPU Volume Rendering
Scales NeRF rendering across multiple GPUs by partitioning the ray into segments. Each GPU computes local transmittance and color contributions, which are then globally composed using a gather operation to accumulate the final image, reducing data transfer during inference [S19].

### NeRF Volume Rendering via Numerical Quadrature
Approximates the volume rendering integral by summing contributions from sampled spheres inside the cone using numerical quadrature, often used in conjunction with Tri-Mip representations to handle anti-aliasing [S20].

### Raymarcher
An alternative to standard volume rendering that uses an RM-LSTM to predict a single intersection point and directly outputs RGB values, skipping the accumulation step. It is significantly faster (~80x) but yields slightly lower quality (PSNR 23.02 vs 23.34) compared to baseline volume rendering [S21, unofficial].

### 2D Neural Rendering Module
A module that maps low-resolution feature maps to final images using upsampling layers and 1x1 convolutions to alleviate multi-view inconsistent artifacts, enabling real-time rendering (>40 fps) [S22].

### HeadNeRF Inference
A specific application of the 2D Neural Rendering Module for parametric head models, sampling 64 points per ray and passing the resulting feature map through the upsampling module for real-time performance [S22].

### Depth Estimation from NeRF
Extracts 3D point-cloud data by analyzing the transmittance function $T(t)$ along the ray. The surface depth $t_{surface}$ is found by minimizing the first-order derivative of $T(t)$, i.e., $t_{surface} \approx \arg \min_t |\frac{dT(t)}{dt}|$ [S23].

### PixelNeRF Rendering Module
Takes input images and a target pose to produce an approximate rendering. It samples points along rays, reprojects them into input cameras to gather features, and appends positional encodings to form a tensor for diffusion conditioning [S24].

### NeRF Rendering with Stratified Sampling
Uses a two-stage sampling strategy: coarse sampling with uniform distribution to determine object positions, followed by fine sampling based on volume density weights to improve detail representation [S25].

### Motion Blur Simulation via Pose Averaging
Models motion blur by discretizing exposure time into $p$ evenly sampled poses (typically $p=5$), rendering a sharp image for each, and averaging them. Assumes uniform motion or linear interpolation for intermediate poses [S11].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot P)$ per ray, where $N$ is the number of samples and $P$ is the number of pixels (rays). Training requires many iterations over the dataset.
*   **Memory Complexity:** $O(N \cdot P)$ to store intermediate predictions and gradients. High memory usage is a primary bottleneck, often requiring chunking of rays [S18, unofficial].
*   **Performance:** The original NeRF implementation required extremely high computing power and long training times [S13]. Modern variants (e.g., Instant NGP) use multi-resolution hash encoding to significantly reduce processing time [S13].
*   **Strengths:** Handles view-dependent effects (non-Lambertian materials) better than standard photogrammetry [S13]. Capable of synthesizing novel views with fine details and smooth transitions [S13].
*   **Limitations:** Neither a point cloud nor a mesh; consists of continuous voxels, affecting 3D reconstruction interpretation [S13]. Original versions were slow [S13].
*   **Use Cases:** Cultural heritage reconstruction (metallic, translucent, transparent surfaces, fine details) [S13]. Implemented in platforms like Instant NGP, Nerfstudio, and Luma AI [S13].

## Background
NeRF (Neural Radiance Fields) was first presented by Mildenhall et al. in 2020 [S13]. It represents a static scene as a continuous 5D function mapping spatial location and viewing direction to volume density and emitted radiance [S12, S13]. The method uses an MLP to model geometry and appearance from a sparse set of images, optimizing network weights via a squared error photometric loss between rendered and ground truth colors [S1, S12]. Instant NGP by Müller et al. (2022) later introduced multi-resolution hash encoding to accelerate training [S13].
