# Masked Evaluation

Also called: Depth reprojection masking, Evaluation Visibility Mask Generation

## Overview
Masked Evaluation restricts radiance field metric computation to pixels visible in at least two training views, preventing metric degradation from evaluating regions that NeRFs cannot predict by design [S1, S2]. Unlike sibling methods like [Unified Metric Aggregation](3644-unified-metric-aggregation.md) which may aggregate errors across all pixels, or [PSNR Evaluation Pipeline](4315-psnr-evaluation-pipeline.md) which computes standard metrics on full images, this method explicitly excludes occluded or single-view-only geometry to ensure fair comparison of geometric consistency [S2]. It differs from [View-Consistency Metric (E_warp)](15720-view-consistency-metric-e-warp.md) by serving as a preprocessing step for standard metrics (like PSNR) rather than a self-supervised regularizer, using depth reprojection to define the valid evaluation domain [S1, S2].

## How it works
**Inputs and Outputs:**
- **Inputs:**
  - Set of training views $V_{train} = \{v_1, ..., v_N\}$ with associated camera poses $P_i$ and intrinsics $K_i$.
  - Predicted depth maps $D_i$ for each training view $v_i$, generated by a Dense-NeRF model [S1, S2].
  - Test view $v_{test}$ with camera pose $P_{test}$ and intrinsics $K_{test}$.
  - Predicted depth map $D_{test}$ for the test view, generated by the same Dense-NeRF model [S1, S2].
  - Threshold parameter $\tau$ [S1, S2].
- **Outputs:**
  - Binary visibility mask $M_{test}$ of the same spatial dimensions as $v_{test}$, where $M_{test}(x,y) = 1$ if the pixel is visible in at least two training views, and $0$ otherwise [S1, S2].

**Data Structures:**
- Depth maps are 2D arrays of floating-point values representing distance from the camera center [S1, S2].
- The mask is a 2D binary array (uint8 or bool) [S1, S2].

**Steps:**
1. **Initialize Visibility Counter:** Create a zero-initialized integer array $C_{test}$ with the same height and width as $D_{test}$ [S1, S2]. This array will count how many training views consider each pixel visible [S2].
2. **Iterate Training Views:** For each training view $v_i \in V_{train}$:
   a. **Reprojection:** Warp the depth map $D_i$ from the coordinate system of $v_i$ to the coordinate system of $v_{test}$ using the relative camera pose $P_i^{-1} P_{test}$ and intrinsics $K_i, K_{test}$ [S1, S2]. Let the warped depth map be $D_{i \to test}$ [S1, S2].
   b. **Depth Comparison:** For each pixel $(x,y)$ in $v_{test}$:
      i. Retrieve the predicted depth from the test view: $d_{test} = D_{test}(x,y)$ [S1, S2].
      ii. Retrieve the warped depth from the training view: $d_{warped} = D_{i \to test}(x,y)$ [S1, S2].
      iii. Compute the absolute depth difference: $\Delta d = |d_{test} - d_{warped}|$ [S1, S2].
      iv. **Thresholding:** If $\Delta d < \tau$, mark the pixel as visible in view $v_i$ by incrementing the counter: $C_{test}(x,y) \leftarrow C_{test}(x,y) + 1$ [S1, S2].
3. **Final Mask Generation:** For each pixel $(x,y)$ in $v_{test}$:
   a. If $C_{test}(x,y) \ge 2$, set $M_{test}(x,y) = 1$ [S1, S2].
   b. Otherwise, set $M_{test}(x,y) = 0$ [S1, S2].

**Parameters:**
- **Depth Difference Threshold ($\tau$):** Set to $0.05 \times \max(D_{train})$, where $\max(D_{train})$ is the maximum depth value in the training view's depth map [S1, S2].

**Pseudocode:**
```python
def generate_masked_evaluation_mask(
    train_views: List[View],
    test_view: View,
    dense_nerf: DenseNeRFModel,
    threshold_factor: float = 0.05
) -> np.ndarray:
    """
    Generates a binary visibility mask for a test view based on depth consistency
    with at least two training views.
    
    Args:
        train_views: List of training view objects containing camera pose, intrinsics,
                     and associated depth map from Dense-NeRF.
        test_view: Test view object containing camera pose, intrinsics,
                   and associated depth map from Dense-NeRF.
        dense_nerf: Model used to predict depth maps (assumed to provide depth maps
                    for all views passed).
        threshold_factor: Factor to multiply max depth by for thresholding.
    
    Returns:
        Binary mask (numpy array) where 1 indicates visibility in >= 2 training views.
    """
    # Get depth maps from Dense-NeRF
    # Note: In practice, these are pre-computed or passed as inputs.
    # Here we assume dense_nerf.predict_depth(view) returns the depth map.
    train_depths = {v.id: dense_nerf.predict_depth(v) for v in train_views}
    test_depth = dense_nerf.predict_depth(test_view)
    
    # Initialize visibility counter
    h, w = test_depth.shape
    visibility_count = np.zeros((h, w), dtype=np.int32)
    
    # Threshold calculation
    # Use max depth of the current training view being processed or a global max?
    # Sources say "maximum depth of the train view" (singular), implying per-view or global.
    # We use the max depth of the specific training view for consistency with "train view" singular in source.
    # However, standard practice often uses a global scene max. 
    # Source [S1, S2] says "0.05 times the maximum depth of the train view".
    # We will use the max depth of the specific training view i for the threshold.
    
    for train_view in train_views:
        d_train = train_depths[train_view.id]
        d_test = test_depth
        
        # Warp depth from train_view to test_view
        # This function handles the projection: 
        # 1. Unproject d_train to 3D points in train_view frame
        # 2. Transform 3D points to test_view frame using relative pose
        # 3. Project 3D points to test_view image plane to get d_warped
        d_warped = warp_depth(d_train, train_view, test_view)
        
        # Calculate max depth for threshold for this specific training view
        max_depth_train = np.max(d_train)
        threshold = threshold_factor * max_depth_train
        
        # Compute absolute difference
        # Handle invalid depths (e.g., 0 or infinity) if necessary [G]
        # Assuming valid depths are positive.
        diff = np.abs(d_test - d_warped)
        
        # Check visibility condition
        # Note: d_warped might have invalid values where warping fails (occlusion in source view).
        # We should only count if d_warped is valid.
        valid_warped = (d_warped > 0) & (np.isfinite(d_warped))
        valid_test = (d_test > 0) & (np.isfinite(d_test))
        valid = valid_warped & valid_test
        
        visible_in_train = (diff < threshold) & valid
        
        # Increment counter for visible pixels
        visibility_count += visible_warped.astype(np.int32)
        
    # Generate final mask: visible in at least 2 views
    mask = (visibility_count >= 2).astype(np.uint8)
    
    return mask

def warp_depth(depth_map: np.ndarray, src_view: View, dst_view: View) -> np.ndarray:
    """
    Warps a depth map from source view to destination view.
    
    Args:
        depth_map: 2D array of depth values in src_view.
        src_view: Source view with camera matrix K_src and pose P_src.
        dst_view: Destination view with camera matrix K_dst and pose P_dst.
        
    Returns:
        2D array of depth values in dst_view coordinate system.
    """
    # 1. Get image dimensions
    h, w = depth_map.shape
    
    # 2. Create 2D grid of pixel coordinates in source view
    y, x = np.meshgrid(np.arange(h), np.arange(w), indexing='ij')
    
    # 3. Unproject to 3D points in source camera frame
    # Inverse intrinsic matrix
    K_inv_src = np.linalg.inv(src_view.K)
    
    # Homogeneous coordinates in image plane
    # Shape: (3, H*W)
    img_coords = np.vstack([x.flatten(), y.flatten(), np.ones(h*w)])
    
    # Ray directions in camera frame (assuming normalized device coordinates or similar)
    # Actually, we need to convert pixel coords to 3D points given depth.
    # Point = K_inv * [x, y, 1] * depth
    rays = K_inv_src @ img_coords # Shape: (3, H*W)
    
    # Scale rays by depth to get 3D points in source camera frame
    # depth_map is (H, W). Flatten to (H*W,)
    depths_flat = depth_map.flatten()
    
    # 3D points in source camera frame
    points_src_cam = rays * depths_flat[np.newaxis, :] # Shape: (3, H*W)
    
    # 4. Transform 3D points to world frame
    # P_src is usually [R|t]. We assume P_src transforms world to camera? 
    # Or camera to world? Standard NeRF conventions vary.
    # Let's assume P_src is the transformation from World to Camera (view matrix).
    # So points_world = P_src^{-1} @ points_cam
    # Or if P_src is World->Camera, then points_cam = P_src @ points_world.
    # Let's assume standard: P is World->Camera.
    # We need points in World frame to transform to dst_view.
    # points_world = P_src^{-1} @ [points_cam; 1]
    
    # Construct homogeneous points in src camera frame
    points_src_cam_h = np.vstack([points_src_cam, np.ones(h*w)])
    
    # Inverse of view matrix to get World coordinates
    # Assuming src_view.P is 4x4 World->Camera matrix
    P_src_inv = np.linalg.inv(src_view.P)
    points_world_h = P_src_inv @ points_src_cam_h
    
    # Extract 3D points
    points_world = points_world_h[:3, :]
    
    # 5. Transform 3D points to destination camera frame
    # P_dst is World->Camera
    points_dst_cam_h = dst_view.P @ points_world_h
    
    # Extract 3D points in dst camera frame
    points_dst_cam = points_dst_cam_h[:3, :]
    
    # 6. Project to destination image plane
    # K_dst @ points_dst_cam
    projected_h = dst_view.K @ points_dst_cam
    
    # Normalize by z
    z = projected_h[2, :]
    x_dst = projected_h[0, :] / z
    y_dst = projected_h[1, :] / z
    
    # 7. Interpolate depth from original depth map? 
    # No, we are warping the depth map itself.
    # The depth in dst view is the z-coordinate of the point in dst camera frame.
    # But we need to map this back to the dst image grid.
    # We have x_dst, y_dst for every pixel in src.
    # We need to create a dst image where each pixel (x_dst, y_dst) gets the depth z.
    
    # Create output depth map
    dst_depth = np.zeros((h, w))
    
    # Round coordinates to nearest integer
    x_dst_int = np.round(x_dst).astype(np.int32)
    y_dst_int = np.round(y_dst).astype(np.int32)
    
    # Filter valid pixels (within dst image bounds)
    valid_mask = (x_dst_int >= 0) & (x_dst_int < w) & \
                 (y_dst_int >= 0) & (y_dst_int < h) & \
                 (z > 0) # Valid depth
                
    x_dst_valid = x_dst_int[valid_mask]
    y_dst_valid = y_dst_int[valid_mask]
    z_valid = z[valid_mask]
    
    # Assign depths
    dst_depth[y_dst_valid, x_dst_valid] = z_valid
    
    return dst_depth
```

**Edge Cases and Pitfalls:**
- **Depth Accuracy Dependency:** Mask accuracy is entirely dependent on the accuracy of the Dense-NeRF depth estimation. Incorrect Dense-NeRF depths produce incorrect masks [S1, S2].
- **Specular Surfaces:** Using depth-based reprojection is robust to specular objects, whereas color-based reprojection fails on such surfaces [S1, S2].
- **Unseen Regions:** Unmasked evaluation includes regions not visible in training views, which radiance fields memorize rather than predict, artificially inflating error metrics [S2].
- **Invalid Depths:** Warping may produce invalid depths (e.g., from occlusions in the source view). These should be handled by ignoring pixels where $d_{warped}$ is invalid or zero [G].

## Subtopics

### [Masked Evaluation (Depth-based Visibility Mask Generation)](8648-masked-evaluation-depth-based-visibility-mask-generation.md)
Generates a binary visibility mask to identify pixels in a reference view that are occluded (invisible) when observed from a new camera pose. It solves the problem of evaluating or inpainting regions that have no geometric correspondence in other views, which often leads to artifacts or incorrect depth predictions in radiance field optimization. It differs from sibling methods like [View-Consistency Metric](15720-view-consistency-metric-e-warp.md) by explicitly using depth warping errors to detect occlusion rather than relying solely on photometric color differences or optical flow consistency.

### [View-Consistency Metric (E_warp)](15720-view-consistency-metric-e-warp.md)
The View-Consistency Metric (E_warp) evaluates the geometric and photometric consistency of a radiance field by measuring the reconstruction error between a rendered view and a neighboring view warped into the target viewpoint. It serves as a self-supervised regularizer or evaluation metric that penalizes inconsistencies arising from incorrect depth or color predictions, leveraging optical flow and occlusion masks to isolate valid correspondences. It differs from standard PSNR or LPIPS by explicitly accounting for viewpoint changes and occlusions, ensuring that errors are only measured where scene content is visible in both views.

## Operating characteristics
- **Time Complexity:** $O(N \cdot H \cdot W)$, where $N$ is the number of training views, and $H, W$ are the image dimensions. Each training view requires warping and comparison for every pixel [S1, S2].
- **Memory Complexity:** $O(H \cdot W)$ for storing the visibility counter and mask, plus $O(H \cdot W)$ for intermediate warped depth maps if processed sequentially [S1, S2].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales linearly with the number of training views.
- **Strengths:** Robust to specular objects; prevents metric degradation from evaluating unseen geometry; ensures fair comparison of geometric consistency [S1, S2].
- **Limitations:** Highly dependent on the accuracy of the Dense-NeRF depth estimation; incorrect depths lead to incorrect masks [S1, S2].
- **When to Use:** When evaluating radiance fields trained on sparse input views, particularly when comparing models that may memorize unseen regions [S1, S2].
- **When Not to Use:** When depth estimation is unreliable or when evaluating full-image fidelity including unseen regions is desired [S1, S2].

## Background
Masked Evaluation was introduced in the context of regularizing sparse input Neural Radiance Fields (NeRFs) to prevent them from being evaluated on regions they cannot predict by design [S1, S2]. Radiance fields are designed to memorize a scene and are ill-equipped to predict unseen regions or the depth of objects seen in only one input view [S1, S2]. The method was proposed to address the issue that unmasked evaluation artificially inflates error metrics by including these unpredictable regions [S2]. It relies on depth-based reprojection techniques similar to those described by Cho et al. [2017] and Kanchana et al. [2022] [S1, S2]. The approach was implemented and released alongside the SimpleNeRF and Simple-RF models [S1, S2].
