# Masked Evaluation

Also called: Depth reprojection masking, Evaluation Visibility Mask Generation

## Overview
Masked Evaluation restricts NeRF metric computation to pixels visible in at least two training views, preventing evaluation on unseen regions that NeRFs cannot predict by design [S1, S2]. It differs from sibling methods like [Unified Metric Aggregation](3644-unified-metric-aggregation.md) by explicitly excluding occluded or single-view geometry from the error calculation, thereby avoiding the artificial inflation of error metrics caused by radiance fields memorizing rather than predicting unseen content [S2].

## How it works
**Inputs and Outputs**
- **Inputs**:
  - Set of training views $V_{train}$, each with a camera pose $P_i$ and a depth map $D_i$ predicted by a Dense-NeRF model.
  - Set of test views $V_{test}$, each with a camera pose $P_j$ and a depth map $D_j$ predicted by the same Dense-NeRF model.
  - Depth difference threshold parameter $\tau$.
- **Outputs**:
  - A binary visibility mask $M_j$ for each test view $j \in V_{test}$, where $M_j(u, v) = 1$ if the pixel $(u, v)$ is visible in at least two training views, and $0$ otherwise.

**Data Structures**
- Depth maps $D$: 2D arrays of shape $(H, W)$, containing float values representing depth from the camera center.
- Camera poses $P$: 4x4 transformation matrices mapping world coordinates to camera coordinates.
- Visibility mask $M$: 2D boolean array of shape $(H, W)$.

**Parameters**
- Depth difference threshold $\tau$: Set to $0.05 \times \max(D_i)$, where $\max(D_i)$ is the maximum depth value in the training view's depth map [S1, S2].

**Steps**
1. Initialize the visibility count map $C_j$ for each test view $j$ to all zeros. $C_j$ has shape $(H, W)$ and stores the number of training views that consider a pixel visible.
2. For each training view $i \in V_{train}$:
   a. Retrieve the training view's depth map $D_i$ and camera pose $P_i$.
   b. Retrieve the test view's camera pose $P_j$.
   c. For each pixel $(u, v)$ in the test view:
      i. Compute the 3D point $X$ in the test view's coordinate system using the depth $D_j(u, v)$ and the inverse camera projection of $P_j$.
      ii. Transform $X$ to the training view's coordinate system using the relative pose $P_i P_j^{-1}$.
      iii. Project $X$ into the training view's image plane to obtain coordinates $(u', v')$.
      iv. If $(u', v')$ is within the bounds of the training view's image, retrieve the depth $D_i(u', v')$ from the training view's depth map.
      v. Compute the absolute depth difference $\Delta d = |D_j(u, v) - D_i(u', v')|$.
      vi. If $\Delta d < \tau$, increment $C_j(u, v)$ by 1.
3. For each test view $j$:
   a. Generate the final mask $M_j$ such that $M_j(u, v) = 1$ if $C_j(u, v) \ge 2$, and $0$ otherwise.
4. Use $M_j$ to mask the rendered and ground-truth images before computing metrics (e.g., PSNR, SSIM).

**Edge Cases and Pitfalls**
- **Depth Accuracy Dependency**: Mask accuracy is entirely dependent on the accuracy of the Dense-NeRF depth estimation; incorrect Dense-NeRF depths produce incorrect masks [S1, S2].
- **Specular Surfaces**: Using depth-based reprojection maintains robustness to specularity, whereas color-based reprojection fails on specular surfaces [S1, S2].
- **Single-View Objects**: Radiance fields are designed to memorize scenes and are ill-equipped to predict the depth of objects seen in only one input view. Masking prevents evaluating these regions [S1, S2].

## Subtopics

### [Masked Evaluation (Depth-based Visibility Mask Generation)](8648-masked-evaluation-depth-based-visibility-mask-generation.md)
Generates a binary visibility mask to identify pixels in a reference view that are occluded (invisible) when observed from a new camera pose. It differs from siblings by explicitly using depth warping errors to detect occlusion rather than relying solely on photometric color differences.

### [View-Consistency Metric (E_warp)](15720-view-consistency-metric-e-warp.md)
Evaluates geometric and photometric consistency by measuring reconstruction error between a rendered view and a neighboring view warped into the target viewpoint. It differs from standard PSNR by explicitly accounting for viewpoint changes and occlusions.

## Operating characteristics
- **Time Complexity**: $O(N_{train} \cdot H \cdot W)$, where $N_{train}$ is the number of training views, and $H, W$ are image dimensions. For each training view, every pixel in the test view (or training view, depending on implementation direction) is processed.
- **Memory Complexity**: $O(H \cdot W)$ for storing the visibility count map and the final mask.
- **Strengths**: Robust to specular objects; prevents metric degradation from predicting unseen geometry; ensures evaluation is restricted to geometrically consistent regions [S1, S2].
- **Limitations**: Highly dependent on the accuracy of the Dense-NeRF depth estimation; if depth estimates are poor, the mask will be incorrect [S1, S2].
- **When to Use**: When evaluating NeRFs on sparse input views where unseen regions are likely to cause high error metrics due to memorization rather than prediction [S1, S2].
- **When Not to Use**: When the goal is to evaluate the model's ability to hallucinate or predict unseen content, or when depth estimation is unreliable [S1, S2].

## Background
Masked Evaluation was introduced in the context of regularizing sparse input Neural Radiance Fields (NeRFs) to prevent them from being evaluated on regions they cannot predict by design [S1, S2]. The method relies on depth-based reprojection techniques similar to those described by Cho et al. [2017] and Kanchana et al. [2022] [S1, S2]. It addresses the issue that radiance fields memorize scenes and are ill-equipped to predict the depth of objects seen in only one input view [S1, S2].
