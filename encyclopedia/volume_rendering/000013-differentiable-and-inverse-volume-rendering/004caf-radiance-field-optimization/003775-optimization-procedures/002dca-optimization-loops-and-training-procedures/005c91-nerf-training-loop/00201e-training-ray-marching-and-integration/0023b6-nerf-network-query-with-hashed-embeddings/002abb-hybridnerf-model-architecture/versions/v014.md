# HybridNeRF Model Architecture

Also called: HybridNeRF

## Overview
HybridNeRF is a neural radiance field architecture that combines 3D feature grids with 2D triplanes to efficiently represent complex scenes [S1]. It solves the trade-off between the high memory cost of pure 3D voxel representations and the limited geometric expressiveness of pure 2D plane-based methods by using a hybrid query mechanism [S1]. Unlike its siblings, it explicitly sums features across resolution levels rather than concatenating them, reducing the MLP input dimensionality while maintaining multi-scale detail [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D point coordinate $\mathbf{x} \in \mathbb{R}^3$ and a viewing direction $\mathbf{d} \in \mathbb{R}^3$.
*   **Output:** Color $\mathbf{c} \in \mathbb{R}^3$ and volume density $\sigma \in \mathbb{R}$ (or signed distance, depending on the specific variant, but standard HybridNeRF outputs radiance properties) [S1].

**Data Structures:**
1.  **3D Feature Grids:** A set of 3D voxel grids at 3 resolution levels: $128^3$, $256^3$, and $512^3$ [S1]. Each cell stores a feature vector.
2.  **Triplanes:** A set of 2D feature planes (triplanes) at 7 resolution levels, ranging from $128^2$ to $8,192^2$ [S1]. These represent the scene from three orthogonal views (XY, YZ, XZ) or similar projections, aggregated across levels [S1].
3.  **MLP:** A Multi-Layer Perceptron that takes the aggregated features and outputs color and density [S1].

**Parameters:**
*   $K=4$: The number of feature vectors fetched per level from both the 3D grids and the triplanes [S1].
*   $L_{3D}=3$: The number of resolution levels for the 3D grids [S1].
*   $L_{2D}=7$: The number of resolution levels for the triplanes [S1].
*   $D_{MLP}=16$: The dimension of the input to the color MLP ($4 \times K$) [S1].

**Algorithm:**
1.  **Query 3D Grids:** For the input point $\mathbf{x}$, fetch $K=4$ feature vectors from each of the 3 resolution levels of the 3D feature grids using trilinear interpolation. Let these features be $F_{3D}^{(l)}$ for $l \in \{1, 2, 3\}$.
2.  **Sum 3D Features:** Sum the fetched features across all 3D levels:
    $$ \mathbf{f}_{3D} = \sum_{l=1}^{3} F_{3D}^{(l)} $$
    [S1]
3.  **Query Triplanes:** For the input point $\mathbf{x}$, project it onto the three orthogonal planes defining the triplanes. Fetch $K=4$ feature vectors from each of the 7 resolution levels of the triplanes using bilinear interpolation. Let these features be $F_{2D}^{(l)}$ for $l \in \{1, \dots, 7\}$.
4.  **Sum 2D Features:** Sum the fetched features across all triplane levels:
    $$ \mathbf{f}_{2D} = \sum_{l=1}^{7} F_{2D}^{(l)} $$
    [S1]
5.  **Concatenate:** Concatenate the summed 3D features and summed 2D features to form the input vector for the MLP:
    $$ \mathbf{v} = [\mathbf{f}_{3D}; \mathbf{f}_{2D}] $$
    The resulting vector $\mathbf{v}$ has dimension $4K = 16$ [S1].
6.  **Encode Direction:** Encode the viewing direction $\mathbf{d}$ using spherical harmonics up to the 4th degree [S1].
7.  **MLP Forward Pass:** Pass $\mathbf{v}$ and the encoded direction into the MLP to predict color $\mathbf{c}$ and density $\sigma$ [S1].

**Edge Cases and Pitfalls:**
*   **Aliasing:** Due to the multi-resolution feature grid, aliasing artifacts can occur. HybridNeRF handles aliasing using the same technique as VR-NeRF [S1].
*   **Precision:** Trilinear and bilinear interpolation are used, requiring careful handling of coordinate normalization to grid boundaries [S1].

## Subtopics

### [SeaThru-NeRF](11884-seathru-nerf.md)
SeaThru-NeRF is a variant designed for visualizing scenes in dispersed scattering media like fog or subaquatic environments. It extends HybridNeRF by treating the scattering medium as a semi-transparent entity with distinct color and density parameters, separate from opaque objects. This allows the model to distinguish between directly illuminated and backscattered segments, enabling restoration of scene hue and 3D configuration in obscured areas. It builds on HybridNeRF by incorporating specific scattering physics into the volume rendering integral.

### [FastSR-NeRF](16574-fastsr-nerf.md)
FastSR-NeRF improves rendering efficiency on consumer hardware by combining a lightweight NeRF model with a CNN-based super-resolution module. It trains the NeRF to produce low-resolution 3D-consistent features and upscales them to high-resolution outputs. Unlike prior methods, it requires no architectural changes to the NeRF backbone and uses a simple end-to-end training pipeline.

### [NeRFCodec](16590-nerfcodec.md)
NeRFCodec is an end-to-end compression framework for plane-based hybrid NeRFs. It integrates non-linear transform, quantization, and entropy coding to achieve memory-efficient scene representation. It leverages a pre-trained 2D neural image codec, adapted with content-specific parameters, to compress feature planes while maintaining high visual fidelity, achieving a memory budget of approximately 0.5 MB per scene.

### [Ambiguity-Aware Depth Estimates](16981-ambiguity-aware-depth-estimates.md)
This technique learns a multimodal distribution of depth estimates conditioned on a single input image using an implicit generative model. It captures inherent ambiguities in monocular depth estimation, such as non-opaque surfaces and albedo-shading confusion. Unlike GANs, it uses conditional Implicit Maximum Likelihood Estimation (cIMLE) to prevent mode collapse.

### [Space-time Neural Irradiance Fields](17161-space-time-neural-irradiance-fields.md)
ST-NIF represents a dynamic scene as a 4D implicit function mapping spatiotemporal coordinates $(x,t)$ to color and volume density. It solves the problem of free-viewpoint video synthesis from a single moving camera by regularizing the under-constrained geometry of dynamic scenes. It introduces empty-space and static-scene losses to prevent haze-like artifacts and disocclusion errors.

### [Knowledge NeRF](17854-knowledge-nerf.md)
Knowledge NeRF is a few-shot novel view synthesis method for dynamic articulated objects. It reconstructs a current state $S_1$ using sparse inputs (typically 5 images) by leveraging a pretrained NeRF model of a previous state $S_0$ as a knowledge base. It uses a lightweight projection module to map points from the current state to the knowledge base, achieving clarity comparable to NeRF trained with abundant images.

### Geometry Composition by Segmented Sampling
This method allows for the insertion of objects into a scene represented by HybridNeRF [S2]. It transforms sampling points from scene coordinates to object coordinates using the object's inserting position (translation and rotation) [S2]. The composited density is the normalized sum of densities of corresponding points from the scene and the object at the same position [S2]. The reflectance is the weighted sum of reflectance values, where the weights are the densities of the voxel particles [S2]. The final image is rendered using the composited density, reflectance, and shading [S2]. Direct composition may lead to missing areas of the object, requiring careful handling of the object's volume [S2].

### Neural Proxy Rendering with Mixed Samplers
This variant mixes a neural proxy sampler $S_p$ for animated objects and a neural scene sampler $S_c$ for static elements, using a neural texture for local surface appearance [S3, unofficial]. The particle set $X$ is separated into proxy set $X_p$ and scene set $X_c$ [S3, unofficial]. For each ray $r$, the convex set $X_r$ bounded by the closest and farthest intersection points with the proxy mesh $M$ is found [S3, unofficial]. The triangle intersection method $f_\delta$ from [MT97] is used to get $(\hat{t}, u_\delta, v_\delta) = f_\delta(r, \delta)$, where $\hat{t}$ is distance and $u_\delta, v_\delta$ are Barycentric coordinates [S3, unofficial]. The convex set is determined by:
$$ D_\delta(r) = \{(\hat{t}, u_\delta, v_\delta) | (\hat{t}, u_\delta, v_\delta) = f_\delta(r, \delta) \land \delta \in M_\delta\} $$
$$ D = \{\hat{t} | (\hat{t}, u_\delta, v_\delta) \in D_\delta(r) \land u_\delta, v_\delta \ge 0 \land u_\delta + v_\delta \le 1\} $$
$$ \hat{t}_n = \min D, \quad \hat{t}_f = \max D $$
The sampled proxy set for a batch of rays $R$ is $X_p = \bigcup_{r \in R} X_r$ [S3, unofficial]. The sampler $S(x)$ is defined as:
$$ S(x) = \begin{cases} S_p(x) & \text{if } x \in X_p \cap X_{M_\tau} \\ S_c(x) & \text{if } x \in X_c \\ (0, 0) & \text{otherwise} \end{cases} $$
where $X_{M_\tau}$ specifies the volume within the proxy and its shell [S3, unofficial]. The model is trained with photometric loss $L = \sum_{r \in R} ||\hat{C}(r) - C(r)||_2^2$ [S3, unofficial]. Unlike NeRF, which uses global scene information, neural proxy uses local information sampled via Barycentric coordinates [S3, unofficial]. Offset parameters $\epsilon, \epsilon^-$ are used to adjust the proxy volume to contain the target [S3, unofficial].

### E2NeRF
E2NeRF learns sharp neural 3D representations from blurred images and event data by combining bio-inspired event camera and standard RGB camera inputs [S4]. It introduces blur rendering loss and event rendering loss to guide the network by modeling the actual blurring process and event generation process [S4]. It constructs an event-stream-based camera pose estimation framework to generalize the method to real-world applications [S4]. It effectively learns sharp NeRF from blurred images, especially in complex and low-light scenes [S4]. Introduced in 2023 [S4].

### LU-NeRF
LU-NeRF jointly estimates camera pose and scene representation by synchronizing locally unlocalized NeRFs [S4]. It employs a local-to-global learning framework, which first optimizes on a subset of local data (mini-scenes), then brings the poses of these mini-scenes into a global reference frame through a robust pose synchronization step, and finally performs fine-grained optimization of the global poses and scenes [S4]. It succeeds even in the absence of a priori knowledge of the pose distribution [S4].

### StructNeRF
StructNeRF is a NeRF technique for indoor settings that enhances new view creation from limited inputs using structural indicators in multi-view inputs [S4]. It integrates structural indicators into self-guided depth estimation by limiting textured area shapes via patch-based multi-view coherent photometric loss and applies planar coherence loss to untextured areas to maintain three-dimensional coherent planes [S4]. It implements progressive training to reduce noise from the limited depth point cloud in structure-from-motion (SfM) [S4].

### SHERF
SHERF is a generalizable human NeRF model for recovering animatable 3D humans from a single input image, forecasting ongoing varied depth assessments from each perspective [S4]. It uses conditional implicit maximum likelihood estimation (cIMLE) to address intrinsic uncertainty in single-eye depth estimation [S4]. It presents a spatial sculpting loss technique to merge various theoretical depth maps across perspectives and distill them into a unified geometry aligning with all views [S4]. Introduced in 2023 [S4].

### IR-NeRF
IR-NeRF is a NeRF training method without camera poses that improves the robustness of pose estimation on real images by introducing implicit pose regularization [S4]. It constructs a scene codebook that implicitly captures the scene-specific camera pose distribution as a priori [S4]. It consistently outperforms GNeRF in terms of image quality metrics (PSNR, SSIM, and LPIPS) [S4].

### SparseNeRF
SparseNeRF addresses the problem of synthesizing new views from finite perspectives by extracting depth priors from pre-trained depth models or rough depth maps captured by consumer-grade depth sensors [S4]. It introduces local depth ordering and spatial continuity constraints to extract robust depth priors from rough depth maps [S4]. A pitfall is that it relies on pre-trained depth models or depth maps captured by consumer-grade sensors, the accuracy and quality of which can be limited by real-world conditions [S4].

## Operating characteristics
*   **Time Complexity:** The query time depends on the number of resolution levels and the interpolation cost. Fetching $K$ features from $L_{3D}$ 3D grids and $L_{2D}$ triplanes involves $L_{3D} + L_{2D}$ interpolation operations per point [S1].
*   **Memory Complexity:** The memory usage is determined by the total number of cells in the 3D grids and triplanes. With 3 levels of 3D grids ($128^3, 256^3, 512^3$) and 7 levels of triplanes ($128^2$ to $8,192^2$), the memory footprint is significantly lower than a single high-resolution 3D grid but higher than a single triplane [S1].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** The method scales with the number of resolution levels and the feature dimension $K$ [S1].
*   **Strengths:** Efficient memory usage compared to pure 3D grids; better geometric expressiveness than pure 2D planes; handles aliasing effectively [S1].
*   **Limitations:** Requires careful tuning of resolution levels and feature dimensions; may suffer from aliasing if not handled properly [S1].
*   **When to use:** Suitable for scenes requiring high-quality novel view synthesis with limited memory resources [S1].
*   **When not to use:** Not suitable for scenes with extreme dynamic range or complex lighting without additional modifications [S1].

## Background
HybridNeRF was introduced in the paper "HybridNeRF: Efficient Neural Rendering via Adaptive Volumetric Surfaces" [S1]. It builds upon the concept of using hybrid representations to balance the strengths of 3D and 2D neural radiance fields. The method addresses the limitations of pure 3D voxel-based NeRFs, which are memory-intensive, and pure 2D plane-based NeRFs, which may lack geometric detail. By combining 3D feature grids with 2D triplanes and summing features across levels, HybridNeRF achieves a more efficient and expressive representation [S1].
