# FourieRF

Also called: FourieRF: Few-Shot NeRFs via Progressive Fourier Frequency Control, Fourier Parameterization for Few-Shot NeRFs

## Overview
FourieRF is a few-shot Neural Radiance Field (NeRF) estimation method that prevents high-frequency artifacts and catastrophic overfitting by parameterizing grid-based features with a Fourier Transform prior [S1]. Unlike sibling methods that rely on external data priors or complex occlusion regularization, FourieRF uses an explicit curriculum training procedure to progressively increase the maximum learnable Fourier frequency, ensuring stable convergence on sparse data [S1]. It builds on [NeRF Network Query with Hashed Embeddings](3107-nerf-network-query-with-hashed-embeddings.md) by applying frequency control to the feature grids of grid-based NeRFs (specifically TensoRF) rather than MLP positional encodings [S1].

## How it works
**Inputs:** A set of $V$ sparse input images (typically 3–9 views) with known camera poses; a grid-based NeRF representation (CP or VM decomposition) initialized with feature tensors.
**Outputs:** A trained radiance field model capable of novel view synthesis.

**Data Structures:**
The scene is represented by a 3D feature tensor $\mathbf{T} \in \mathbb{R}^{I \times J \times K}$. FourieRF operates on the factorized components of this tensor.
1.  **CP Decomposition:** $\mathbf{T}$ is decomposed into a sum of rank-1 tensors. The method applies frequency control to the 1D feature vectors $\mathbf{v} \in \mathbb{R}^d$.
2.  **VM Decomposition:** $\mathbf{T}$ is decomposed into a sum of outer products of a vector and a matrix (e.g., $\mathbf{v}_{r1} \circ \mathbf{M}_{r2,3}$). The method applies frequency control to:
    *   1D feature vectors $\mathbf{v} \in \mathbb{R}^d$.
    *   2D feature matrices $\mathbf{w} \in \mathbb{R}^{d_1 \times d_2}$ [S1].

**Parameters:**
*   $N$: Total number of training iterations (typically 10,000) [S1].
*   $f_0$: Initial clipping threshold, representing the percentage of Fourier coefficients allowed. Default: $0.01\%$ ($0.0001$) for real scenes, $0.3\%$ for synthetic scenes [S1].
*   $\Delta$: Increment per iteration, calculated as $\Delta = \frac{1 - f_0}{N}$ [S1].
*   $f_t$: Clipping threshold at iteration $t$ [S1].
*   Optimizer: AdamW with $\beta_1 = 0.9, \beta_2 = 0.98$ [S1].
*   Weight Decay: $0.2$ for synthetic scenes, $0$ for real scenes [S1].
*   $w_{TV}$: Total Variation loss weight for appearance and density features. Value: $1.0$ [S1].
*   $w_{L1}$: L1 loss weight for density features (real scenes only). Value: $10^{-4}$ [S1].

**Algorithm:**
The core mechanism is a progressive Fourier frequency control loop applied at the start of every training iteration, before gradient accumulation [S1].

1.  **Initialization:** Initialize feature vectors and matrices in the spatial domain. Set $f_0$ and calculate $\Delta$ [S1].
2.  **Threshold Update:** At the start of iteration $t$, update the clipping threshold:
    $$ f_t = f_{t-1} + \Delta $$
    This update must occur before any gradients are computed to maintain differentiability [S1].
3.  **Feature Transformation:** For each feature component in the grid decomposition, apply the Fourier clipping:
    *   **1D Features ($\mathbf{v} \in \mathbb{R}^d$):**
        Compute the mask $\alpha(f_t)$ of length $d_f$ (dimension of FFT). The mask is defined as:
        $$ \alpha_i(f_t) = \begin{cases} 1 & \text{if } i < t_\alpha(f_t) \\ t_\alpha(f_t) - \lfloor t_\alpha(f_t) \rfloor & \text{if } i = t_\alpha(f_t) \\ 0 & \text{otherwise} \end{cases} $$
        where $t_\alpha(f_t) = d_f \times f_t$.
        Transform the feature:
        $$ \hat{\mathbf{v}} = \text{IFFT}(\text{FFT}(\mathbf{v}) \odot \alpha(f_t)) $$
    *   **2D Features ($\mathbf{w} \in \mathbb{R}^{d_1 \times d_2}$):** (Used only in VM decomposition)
        Compute the circular mask $\beta(f_t)$. The mask is a circle centered at $c = (\lfloor d_1/2 \rfloor, \lfloor d_2/2 \rfloor)$ with radius $r = f_t \sqrt{\frac{\max(d_1, d_2)^2}{2}}$. Coefficients outside the circle are set to 0.
        Transform the feature:
        $$ \hat{\mathbf{w}} = \text{IFFT}(\text{FFT}(\mathbf{w}) \odot \beta(f_t)) $$
4.  **Network Forward Pass:** Use the smoothed features $\hat{\mathbf{v}}$ and $\hat{\mathbf{w}}$ to query the NeRF network for density and color.
5.  **Loss Computation:** Compute the photometric loss (L2 or L1) between rendered and input images. Add regularization losses:
    *   Total Variation loss on features with weight $w_{TV} = 1.0$ [S1].
    *   L1 loss on density features ($w_{L1} = 10^{-4}$) for real scenes [S1].
    *   Weight decay (synthetic scenes) or L1 density loss (real scenes) to remove floaters [S1].
6.  **Backward Pass:** Compute gradients and update parameters using AdamW [S1].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def fourie_rf_step(features_1d, features_2d, iteration, total_iterations, f0):
    """
    Applies Fourier frequency control to NeRF grid features.
    
    Args:
        features_1d: List of 1D feature tensors [v] in R^d.
        features_2d: List of 2D feature tensors [w] in R^(d1*d2).
        iteration: Current training iteration t.
        total_iterations: Total number of iterations N.
        f0: Initial clipping threshold percentage (e.g., 0.0001 for 0.01%).
        
    Returns:
        Smoothed features_1d, features_2d.
    """
    # 1. Update clipping threshold
    # Delta is the linear increment per iteration
    delta = (1.0 - f0) / total_iterations
    f_t = f0 + iteration * delta
    
    # 2. Process 1D Features
    smoothed_1d = []
    for v in features_1d:
        # FFT along the feature dimension (last dim)
        v_fft = torch.fft.fft(v, dim=-1)
        
        # Create 1D mask alpha(f_t)
        d_f = v_fft.shape[-1]
        t_alpha = d_f * f_t
        
        # Create indices array
        indices = torch.arange(d_f, device=v.device)
        
        # Apply mask definition: 1 if i < t_alpha, fractional if i == t_alpha, 0 otherwise
        mask = torch.zeros_like(v_fft.real)
        mask[indices < t_alpha] = 1.0
        mask[indices == t_alpha] = t_alpha - torch.floor(t_alpha)
        
        # Apply mask and IFFT
        v_smoothed_fft = v_fft * mask.unsqueeze(-1) # Ensure broadcasting works if mask is 1D
        v_smoothed = torch.fft.ifft(v_smoothed_fft, dim=-1).real
        smoothed_1d.append(v_smoothed)
        
    # 3. Process 2D Features (VM decomposition only)
    smoothed_2d = []
    for w in features_2d:
        # FFT along spatial feature dimensions (last two dims)
        w_fft = torch.fft.fft2(w)
        
        d1, d2 = w.shape[-2], w.shape[-1]
        center_c1 = torch.floor(d1 / 2).to(w.device)
        center_c2 = torch.floor(d2 / 2).to(w.device)
        
        # Create coordinate grids for the frequency domain
        y, x = torch.meshgrid(torch.arange(d1, device=w.device), 
                              torch.arange(d2, device=w.device), 
                              indexing='ij')
        
        # Calculate distance from center
        dist = torch.sqrt((x - center_c1)**2 + (y - center_c2)**2)
        
        # Radius r = f_t * sqrt(max(d1, d2)^2 / 2)
        max_dim = max(d1, d2)
        radius = f_t * torch.sqrt(torch.tensor(max_dim**2 / 2.0, device=w.device))
        
        # Create 2D mask beta(f_t): 1 inside circle, 0 outside
        mask_2d = (dist <= radius).float()
        
        # Apply mask and IFFT
        w_smoothed_fft = w_fft * mask_2d.unsqueeze(-1).unsqueeze(-1)
        w_smoothed = torch.fft.ifft2(w_smoothed_fft).real
        smoothed_2d.append(w_smoothed)
        
    return smoothed_1d, smoothed_2d

def train_fourie_rf(input_images, camera_poses, grid_features, optimizer, total_iterations=10000, f0=0.0001):
    """
    Main training loop for FourieRF.
    """
    features_1d, features_2d = grid_features # Unpack CP/VM components
    
    for t in range(total_iterations):
        # Step 1: Update features with Fourier control BEFORE gradient computation
        features_1d, features_2d = fourie_rf_step(features_1d, features_2d, t, total_iterations, f0)
        
        # Step 2: Forward pass through NeRF using smoothed features
        # (Assuming a standard NeRF query function that takes feature tensors)
        # This step depends on the specific grid-based NeRF implementation (e.g., TensoRF)
        rendered_colors, densities = query_nerf(features_1d, features_2d, camera_poses, input_images)
        
        # Step 3: Compute Loss
        # Photometric loss (e.g., L2)
        photometric_loss = F.mse_loss(rendered_colors, input_images)
        
        # Regularization
        tv_loss = compute_total_variation_loss(features_1d + features_2d)
        tv_loss = tv_loss * 1.0 # w_TV = 1.0
        
        l1_density_loss = torch.tensor(0.0)
        # Apply L1 on density for real scenes (not synthetic)
        # This check depends on dataset type, assumed handled externally or via flag
        # l1_density_loss = F.l1_loss(densities, target) * 1e-4 
        
        total_loss = photometric_loss + tv_loss + l1_density_loss
        
        # Step 4: Backward pass
        optimizer.zero_grad()
        total_loss.backward()
        
        # Step 5: Optimizer step (AdamW)
        optimizer.step()
```

**Edge Cases and Pitfalls:**
*   **Differentiability:** The threshold update $f_t$ must be applied at the start of the iteration, before any gradient is accumulated. Applying it during the backward pass or after gradient computation breaks differentiability [S1].
*   **Overfitting to Views:** In few-shot settings, models may overfit to directional information. FourieRF mitigates this by using a simplified decoder that does not use positional encodings for features or view directions [S1].
*   **Occlusion:** In real scenes, matter appearing in front of the camera can cause overfitting. FourieRF applies FreeNeRF's occlusion regularization without modification [S1].
*   **Under-constrained Scenes:** In severely under-constrained scenarios with significant view occlusion, FourieRF may still produce reconstruction errors [S1].
*   **Synthetic vs. Real Scenes:** Synthetic scenes (white background) require a higher initial $f_0$ ($0.3\%$) compared to real scenes ($0.01\%$) [S1]. Synthetic scenes use weight decay ($0.2$) for floater removal, while real scenes use L1 density loss ($10^{-4}$) [S1].

## Operating characteristics
*   **Time Complexity:** Training time is approximately 10 minutes for convergence on the Blender dataset (6 views, 10k iterations) [S1].
*   **Speed Comparison:** FourieRF achieves $0.93\times$ the training time of TensoRF, $5.181\times$ faster than ZeroRF, and $35.71\times$ faster than FreeNeRF on the Blender dataset [S1]. It is slightly faster than vanilla TensoRF because it does not predict "useless" floaters [S1].
*   **Memory Complexity:** Inherits the memory complexity of the underlying grid decomposition (CP or VM). VM decomposition reduces space complexity from $O(n^3)$ to $O(n^2)$ compared to CP [S1].
*   **Strengths:** Fast convergence, robust on both synthetic and real scenes, no computational overhead per iteration, avoids complex occlusion regularization required by FreeNeRF [S1].
*   **Limitations:** May fail in severely under-constrained scenarios with heavy occlusion [S1]. Performance depends on the choice of $\Delta$ (increment speed), though the linear schedule is generally robust [S1].
*   **When to use:** Few-shot novel view synthesis (3–9 views) where training speed is critical and external data priors (depth, diffusion) are unavailable.
*   **When not to use:** Dense-view settings where standard NeRFs perform adequately, or scenarios with severe unobserved geometry where even frequency control cannot resolve ambiguities [S1].

## Background
FourieRF was introduced by Diego Gomez, Bingchen Gong, and Maks Ovsjanikov from LIX, École Polytechnique, IP Paris, in February 2025 [S1]. The method addresses the "few-shot rendering problem," where high-frequency artifacts and catastrophic overfitting occur early in optimization due to sparse supervision [S1]. It builds upon TensoRF [S1] and compares against baselines like FreeNeRF and ZeroRF [S1]. The approach is inspired by the observation that low frequencies are easier to learn correctly and provide a robust base for subsequent higher frequencies [S1].
