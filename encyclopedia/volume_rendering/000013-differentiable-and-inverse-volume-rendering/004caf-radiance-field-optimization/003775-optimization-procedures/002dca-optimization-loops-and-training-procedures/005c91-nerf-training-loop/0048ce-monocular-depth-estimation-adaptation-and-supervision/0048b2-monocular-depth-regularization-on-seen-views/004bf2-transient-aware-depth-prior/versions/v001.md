# Transient-Aware Depth Prior

Also called: DPT depth supervision, monocular depth loss

## Overview
The Transient-Aware Depth Prior incorporates geometric constraints from a pre-trained monocular depth estimation (MDE) network into NeRF training to stabilize pose and geometry optimization for unconstrained image collections [S1, unofficial]. It differs from sibling methods like NoPe-NeRF by explicitly filtering the depth supervision signal using a transient confidence weight, ensuring that depth consistency is enforced only on static scene geometry rather than transient objects [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:**
    *   Training image $i$ with camera pose.
    *   Rendered NeRF depth $\hat{D}_i(r)$ for ray $r$.
    *   Predicted inverse depth $D^{inv}_i(r)$ from the DPT network [S1, unofficial].
    *   Candidate density $\sigma_i^{(c)}$ and shared density $\sigma$ from the NeRF network [S1, unofficial].
*   **Outputs:**
    *   Transient-aware depth loss $L_{depth}(r)$ used for backpropagation [S1, unofficial].

**Data Structures**
*   **Learnable Parameters:** Per-image scale $\eta_i$ and shift $\xi_i$ [S1, unofficial].
*   **Hyperparameters:** Depth loss weight $\lambda_d = 0.001$ [S1, unofficial].

**Steps**
1.  **Acquire Monocular Prior:** For each training image $i$, extract the dense predicted inverse depth map $D^{inv}_i(r)$ using the DPT-Large model [S1, unofficial].
2.  **Align Depth:** Compute the aligned monocular depth $D^*_i(r)$ by applying the learnable scale $\eta_i$ and shift $\xi_i$ to the inverse depth:
    $$ D^*_i(r) = \frac{1}{\eta_i D^{inv}_i(r) + \xi_i} $$
    This aligns the relative scale of the monocular prediction with the NeRF's coordinate system [S1, unofficial].
3.  **Render NeRF Depth:** Compute the expected depth $\hat{D}_i(r)$ along ray $r$ using volume rendering:
    $$ \hat{D}_i(r) = \sum_{k=1}^{K} T(t_k) \alpha(\sigma(t_k)\delta_k) t_k $$
    where $T(t_k)$ is the accumulated transmittance, $\alpha$ is the opacity, $\sigma$ is the density, and $t_k$ are sample points [S1, unofficial].
4.  **Compute Transient Confidence:** Calculate the transient confidence weight $W_{depth}(r)$ based on the ratio of candidate density to shared density. This weight indicates the likelihood that the ray passes through a transient object:
    $$ W_{depth}(r) = \sum_{k=1}^{K} T_i(t_k) \alpha(\sigma_i^{(c)}(t_k)\delta_k) $$
    Here, $T_i(t_k)$ is the transmittance computed using the candidate density $\sigma_i^{(c)}$ [S1, unofficial].
5.  **Calculate Loss:** Compute the weighted L1 loss between the aligned monocular depth and the rendered NeRF depth. The weight $(1 - W_{depth}(r))$ suppresses the loss in areas with high transient confidence:
    $$ L_{depth}(r) = (1 - W_{depth}(r)) \| D^*_i(r) - \hat{D}_i(r) \|_1 $$
    The total depth loss is scaled by $\lambda_d = 0.001$ [S1, unofficial].

**Pseudocode**
```python
def compute_transient_aware_depth_loss(
    ray_r, 
    nerf_model, 
    dpt_model, 
    image_idx,
    lambda_d=0.001
):
    # 1. Acquire monocular inverse depth
    # DPT outputs inverse depth. Shape: (H, W)
    d_inv = dpt_model(image_idx) 
    
    # 2. Get learnable scale and shift for this image
    eta = learnable_params[image_idx].eta
    xi = learnable_params[image_idx].xi
    
    # 3. Render NeRF depth and densities
    # Returns: rendered_depth, transmittance, candidate_alpha, shared_alpha
    rendered_depth, T, alpha_cand, alpha_shared = nerf_model.render(ray_r)
    
    # 4. Compute aligned monocular depth
    # D* = 1 / (eta * D_inv + xi)
    # Note: D_inv is inverse depth, so we must handle division carefully
    # If D_inv is 0, handle as infinity or small epsilon
    d_mono_aligned = 1.0 / (eta * d_inv + xi)
    
    # 5. Compute transient confidence weight
    # W_depth = sum(T_i * alpha_cand)
    # T_i is transmittance using candidate density
    # Assuming T returned is already computed with candidate density for the transient head
    w_depth = T * alpha_cand
    w_depth_sum = sum(w_depth) # Sum over samples k
    
    # 6. Compute L1 loss
    # L = (1 - W) * || D* - D_hat ||
    # Note: The source formula implies W is a scalar weight for the ray or per-sample?
    # Source Eq 14: L_depth(r) = (1 - W_depth(r)) || ... ||
    # W_depth(r) is defined as a sum over k. This suggests W is a scalar per ray.
    
    l1_loss = abs(d_mono_aligned - rendered_depth)
    loss = (1.0 - w_depth_sum) * l1_loss
    
    return lambda_d * loss
```

**Edge Cases and Pitfalls**
*   **Division by Zero:** If $\eta_i D^{inv}_i(r) + \xi_i$ is zero, the aligned depth becomes infinite. A small epsilon should be added to the denominator [G].
*   **Transient Objects:** If the transient confidence weight $W_{depth}(r)$ is close to 1, the loss is suppressed. If $W_{depth}(r)$ is close to 0, the full L1 loss is applied. This prevents transient objects from distorting the static geometry [S1, unofficial].
*   **Scale Ambiguity:** Monocular depth is scale-ambiguous. The learnable parameters $\eta_i$ and $\xi_i$ must be optimized jointly with the NeRF and poses. If not optimized, the depth prior may misalign [S1, unofficial].
*   **Hyperparameter Sensitivity:** The depth loss weight $\lambda_d$ is set to 0.001. Using a larger value may degrade rendering quality as the pseudo-labels are not ground truth [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Adds the cost of querying the DPT model and computing the depth loss per ray. The DPT inference is typically done once per image or cached, so the per-step cost is dominated by the depth loss computation [S1, unofficial].
*   **Memory Complexity:** Requires storing learnable scale and shift parameters per image [S1, unofficial].
*   **Strengths:** Provides strong geometric cues for pose estimation in unconstrained image collections where inter-frame constraints are unavailable [S1, unofficial]. Filters out transient objects to prevent geometry corruption [S1, unofficial].
*   **Limitations:** Relies on the accuracy of the monocular depth estimator. Pseudo-labels are not ground truth and can degrade quality if over-weighted [S1, unofficial].

## Background
The method is inspired by NoPe-NeRF [S2] but adapted for unconstrained images where inter-frame losses are not applicable [S1, unofficial]. It uses the DPT network [S1, unofficial] for monocular depth prediction. The transient-aware filtering mechanism is specific to the UP-NeRF framework [S1, unofficial].
