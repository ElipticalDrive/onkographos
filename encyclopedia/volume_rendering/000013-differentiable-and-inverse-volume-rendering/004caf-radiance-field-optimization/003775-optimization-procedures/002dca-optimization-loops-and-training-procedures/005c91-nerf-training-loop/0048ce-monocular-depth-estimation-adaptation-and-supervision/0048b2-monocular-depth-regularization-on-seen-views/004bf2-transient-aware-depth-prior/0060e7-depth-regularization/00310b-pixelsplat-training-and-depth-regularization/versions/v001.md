# PixelSplat Training and Depth Regularization

Also called: Depth Regularization for 3DGS, PixelSplat Training

## Overview
PixelSplat Training and Depth Regularization is a specific training protocol for the PixelSplat architecture, which reconstructs 3D scenes from image pairs using 3D Gaussian Splatting [S1]. It solves the problem of producing high-quality, dense point clouds from generalizable 3D reconstruction by combining a multi-stage visual loss with a geometric depth regularization term [S1]. It is distinguished from its siblings by its specific use of multiple Gaussians per ray to enable multi-depth estimation and its explicit fine-tuning phase for depth map consistency, whereas [DNGaussian](7399-dngaussian.md) focuses on differentiable normal rendering and [Edge-Aware Disparity Regularization](9140-edge-aware-disparity-regularization.md) focuses on disparity edge preservation [Parent].

## How it works
The method consists of two phases: a primary training phase for visual fidelity and a secondary fine-tuning phase for geometric regularization [S1].

**Inputs and Outputs**
*   **Inputs:** Pairs of reference images, camera poses, and intrinsic parameters.
*   **Outputs:** A set of 3D Gaussians (centers $\mu$, scales $s$, rotations $q$, opacities $\alpha$, colors $c$) and, optionally, rendered depth maps $D$ [S1].

**Data Structures**
*   **Gaussian Parameters:** Standard 3DGS parameters.
*   **Ray Sampling:** For each ray, 3 Gaussians are placed [S1].
*   **Alpha Normalization:** Each Gaussian's alpha is divided by 3, such that $\alpha = \phi_z / 3$, ensuring the total opacity of Gaussians along a single ray sums to approximately 1 [S1].

**Training Procedure**
The training is divided into two stages [S1]:

1.  **Primary Training (300,000 steps):**
    *   **Batch Size:** 7 scenes per batch [S1].
    *   **Views:** 4 target views are rendered per scene [S1].
    *   **Loss Schedule:**
        *   Steps 0–150,000: Mean Squared Error (MSE) loss between rendered and ground truth RGB images [S1].
        *   Steps 150,000–300,000: MSE loss supplemented with LPIPS loss with a weight of 0.05 [S1].
    *   **Camera Geometry:** The distance between reference views is linearly increased from 25 to 45 units over the first 150,000 steps [S1].
    *   **Gaussian Placement:** To allow gradients for multiple estimated depths, 3 Gaussians are placed along each ray. Their positions are determined by independently sampling from the ray's probability distribution 3 times [S1].

2.  **Depth Regularization Fine-Tuning (50,000 steps):**
    *   This phase generates high-quality point clouds by optimizing for depth consistency [S1].
    *   **Loss Function:** A depth regularization loss $\mathcal{L}_{reg\_depth}$ is applied [S1].
    *   **Depth Map Generation:** For each rendered view, a corresponding depth map $D$ is generated [S1].
    *   **Regularization Formula:** The loss is computed using horizontal and vertical second-order differences of the depth map $D$ at pixel coordinates $\mathbf{u} = (u_x, u_y)$ [S1]:
        $$ D_x^{\Delta}[\mathbf{u}] = D[u_{x-1}, u_y] - 2D[u_x, u_y] + D[u_{x+1}, u_y] $$
        $$ D_y^{\Delta}[\mathbf{u}] = D[u_x, u_{y-1}] - 2D[u_x, u_y] + D[u_x, u_{y+1}] $$
    *   The total loss for this phase is the sum of these difference terms (implementation detail: typically summed or averaged over all pixels $\mathbf{u}$) [S1].

**Pseudocode**

```python
def train_pixelSplat_depth_reg():
    # Phase 1: Primary Training
    model = PixelSplatModel()
    optimizer = Adam(model.parameters())
    
    # Schedule parameters
    total_steps_primary = 300000
    steps_mse_only = 150000
    batch_size = 7
    num_target_views = 4
    num_gaussians_per_ray = 3
    lpips_weight = 0.05
    
    for step in range(total_steps_primary):
        # 1. Prepare Batch
        batch = get_batch(batch_size) # Contains image pairs and poses
        
        # 2. Update Camera Distance Schedule (0 to 150k steps)
        if step < steps_mse_only:
            progress = step / steps_mse_only
            # Linearly increase distance from 25 to 45
            camera_distance = 25 + progress * (45 - 25)
            apply_camera_distance_schedule(batch, camera_distance)
        
        # 3. Forward Pass with Multi-Depth Gaussians
        rendered_images = []
        rendered_depths = []
        
        for scene in batch:
            # Render 4 target views
            for view_idx in range(num_target_views):
                view_data = scene.get_target_view(view_idx)
                
                # Place 3 Gaussians per ray
                # Sample positions independently from ray probability distribution
                gaussian_positions = []
                for _ in range(num_gaussians_per_ray):
                    pos = sample_from_ray_distribution(view_data.ray, view_data.pose)
                    gaussian_positions.append(pos)
                
                # Set alphas: alpha = phi_z / 3
                # (Assuming phi_z is the base opacity before division)
                gaussians = create_gaussians(
                    positions=gaussian_positions,
                    alphas=[phi_z / 3 for phi_z in base_opacities],
                    # Other params: scales, rotations, colors
                )
                
                # Render using differentiable rasterizer
                img, depth = rasterize(gaussians, view_data)
                rendered_images.append(img)
                rendered_depths.append(depth)
        
        # 4. Compute Loss
        losses = []
        for i, (rendered_img, gt_img) in enumerate(zip(rendered_images, batch.gt_images)):
            mse_loss = mse(rendered_img, gt_img)
            losses.append(mse_loss)
            
            if step >= steps_mse_only:
                lpips_loss = lpips(rendered_img, gt_img)
                losses.append(lpips_weight * lpips_loss)
        
        loss_primary = sum(losses) / len(losses)
        
        # 5. Backpropagate
        optimizer.zero_grad()
        loss_primary.backward()
        optimizer.step()

    # Phase 2: Depth Regularization Fine-Tuning
    total_steps_fine = 50000
    for step in range(total_steps_fine):
        batch = get_batch(batch_size)
        
        rendered_depths = []
        for scene in batch:
            for view_idx in range(num_target_views):
                view_data = scene.get_target_view(view_idx)
                # Re-use trained Gaussians or re-sample? 
                # Sources imply fine-tuning the model, so Gaussians are updated.
                # However, the specific "3 Gaussians per ray" placement logic 
                # is described in the context of the forward pass for gradients.
                # We assume the same placement strategy is maintained or 
                # the rasterizer handles the depth extraction from the current Gaussians.
                
                # Render to get depth map D
                _, depth_map = rasterize(model.gaussians, view_data)
                rendered_depths.append(depth_map)
        
        # Compute Depth Regularization Loss
        depth_loss = 0.0
        for depth_map in rendered_depths:
            # Compute horizontal and vertical second-order differences
            # D[u] represents depth_map[u_x, u_y]
            # Assuming boundary handling (e.g., zero-padding or ignoring edges)
            h_diff = second_order_difference(depth_map, axis='x')
            v_diff = second_order_difference(depth_map, axis='y')
            
            # Sum of differences (implementation detail: sum over all u)
            depth_loss += sum(h_diff) + sum(v_diff)
            
        loss_reg = depth_loss / len(rendered_depths)
        
        optimizer.zero_grad()
        loss_reg.backward()
        optimizer.step()

def second_order_difference(depth_map, axis):
    """
    Computes second-order difference along the specified axis.
    axis='x': D[u_{x-1}, u_y] - 2D[u_x, u_y] + D[u_{x+1}, u_y]
    axis='y': D[u_x, u_{y-1}] - 2D[u_x, u_y] + D[u_x, u_{y+1}]
    """
    if axis == 'x':
        # Shift left and right
        left = depth_map[:, :-2] # u_{x-1}
        center = depth_map[:, 1:-1] # u_x
        right = depth_map[:, 2:] # u_{x+1}
        # Note: indices depend on exact array layout, assuming standard image coords
        # D[u_{x-1}, u_y] corresponds to column x-1
        return left - 2 * center + right
    else: # axis == 'y'
        top = depth_map[:-2, :] # u_{y-1}
        center = depth_map[1:-1, :] # u_y
        bottom = depth_map[2:, :] # u_{y+1}
        return top - 2 * center + bottom
```

## Subtopics

### SparSplat Training Objective
SparSplat Training Objective is a variant that uses end-to-end training with multi-view RGB images and ground truth depth supervision, while keeping deep feature networks frozen for efficiency [S2, unofficial]. It employs a multi-stage coarse-to-fine optimization framework [S2, unofficial]. The loss function combines MSE, SSIM, perceptual, L1 depth, depth distortion, and normal consistency losses [S2, unofficial]:
$$ \mathcal{L}_k = \mathcal{L}_{mse} + \lambda_s \mathcal{L}_{ssim} + \lambda_p \mathcal{L}_{perc} + \lambda_\alpha \mathcal{L}_d + \lambda_\beta \mathcal{L}_n + \lambda_\gamma \mathcal{L}_{depth} $$
where $\mathcal{L}_d = \sum_{i,j} \omega_i \omega_j |z_i - z_j|$ (depth distortion) and $\mathcal{L}_n = \sum_i \omega_i (1 - n_i^T N)$ (normal consistency) [S2, unofficial]. The total loss is the sum of stage losses weighted by $\lambda_k$ [S2, unofficial].

## Operating characteristics
*   **Memory:** Requires approximately 80 GB of VRAM on a single GPU for the primary training phase [S1].
*   **Time:** Primary training takes 300,000 steps; fine-tuning takes 50,000 steps [S1].
*   **Scalability:** The method uses a batch size of 7, which is constrained by the high VRAM requirement [S1].
*   **Strengths:** Produces high-quality point clouds via depth regularization; generalizable from image pairs [S1].
*   **Limitations:** High VRAM consumption; requires significant training time (350,000 steps total) [S1].

## Background
PixelSplat was introduced by [S1] (CVPR 2024) as a scalable generalizable 3D reconstruction method using 3D Gaussian Splatting from image pairs. The depth regularization technique is a specific fine-tuning step proposed within this work to improve geometric accuracy for point cloud generation [S1].
