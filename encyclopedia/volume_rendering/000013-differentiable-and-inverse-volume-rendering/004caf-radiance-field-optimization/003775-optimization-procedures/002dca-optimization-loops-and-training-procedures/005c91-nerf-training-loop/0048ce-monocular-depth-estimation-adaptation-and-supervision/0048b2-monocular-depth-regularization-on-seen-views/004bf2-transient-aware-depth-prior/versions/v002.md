# Transient-Aware Depth Prior

Also called: DPT depth supervision, monocular depth loss

## Overview
The Transient-Aware Depth Prior is a regularization technique for Neural Radiance Fields (NeRF) that incorporates geometric priors from a monocular depth estimator (typically DPT) to constrain optimization and suppress artifacts like floaters or geometry collapse [S1, unofficial]. It distinguishes itself from sibling methods by explicitly aligning the scale and offset of the monocular depth map using learnable per-image parameters and filtering the loss with a transient confidence weight derived from the NeRF's own density fields, rather than relying on generalizable priors or inter-frame consistency alone [S1, unofficial]. This allows the method to apply depth supervision only to static regions, preventing the network from learning incorrect geometry for transient objects [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** Training image $i$, camera pose, ray $r$ passing through pixel, pre-trained Monocular Depth Estimation (MDE) network (DPT), current NeRF model (shared density $\sigma$ and candidate density $\sigma^{(c)}$).
- **Outputs:** Depth loss value $L_{depth}$ for the current ray.

**Data Structures:**
- **Monocular Depth Prior:** Dense inverse depth map $D^{inv}_i$ predicted by DPT for image $i$.
- **Learnable Parameters:** Per-image scale $\eta_i$ and shift $\xi_i$.
- **NeRF Densities:** Shared density $\sigma$ (static geometry) and candidate density $\sigma^{(c)}$ (transient/uncertain geometry).

**Steps:**
1. **Acquire Monocular Depth:** For each training image $i$, predict the inverse depth map $D^{inv}_i$ using the DPT network [S1, unofficial].
2. **Compute Aligned Monocular Depth:** Transform the inverse depth to align with the NeRF's coordinate system using learnable scale $\eta_i$ and shift $\xi_i$ [S1, unofficial]:
   $$ D^*_i(r) = \frac{1}{\eta_i D^{inv}_i(r) + \xi_i} $$
   where $D^*_i(r)$ is the aligned monocular depth prior for ray $r$ [S1, unofficial].
3. **Render NeRF Depth:** Compute the expected depth $\hat{D}_i(r)$ from the NeRF using volume rendering integration along the ray [S1, unofficial]:
   $$ \hat{D}_i(r) = \sum_{k=1}^{K} T(t_k) \alpha(\sigma(t_k)\delta_k) t_k $$
   where $t_k$ are sample points, $\delta_k$ is the distance between samples, $\alpha$ is the opacity, $T(t_k)$ is the transmittance, and $\sigma$ is the shared density [S1, unofficial].
4. **Calculate Transient Confidence Weight:** Determine the weight $W_{depth}(r)$ based on the ratio of candidate density to shared density. This weight indicates the likelihood that the ray passes through a transient object [S1, unofficial]:
   $$ W_{depth}(r) = \sum_{k=1}^{K} T_i(t_k) \alpha(\sigma^{(c)}(t_k)\delta_k) $$
   where $T_i(t_k)$ is the transmittance computed using the candidate density $\sigma^{(c)}$ [S1, unofficial]. Note: $W_{depth}(r) \in [0, 1]$. High values indicate transient content [S1, unofficial].
5. **Compute Depth Loss:** Calculate the L1 loss between the aligned monocular depth and the rendered NeRF depth, weighted by the transient confidence. The loss is applied only to areas with low transient confidence (high static confidence) [S1, unofficial]:
   $$ L_{depth}(r) = (1 - W_{depth}(r)) \| D^*_i(r) - \hat{D}_i(r) \|_1 $$
   [S1, unofficial].

**Parameters:**
- $\lambda_d$: Weight for the depth loss in the total loss function. Typical value: $0.001$ [S1, unofficial].
- $\eta_i, \xi_i$: Learnable scale and shift parameters for each image $i$ [S1, unofficial].

**Pseudocode:**
```python
def compute_transient_aware_depth_loss(ray, image_idx, nerf_model, dpt_model, eta, xi):
    """
    ray: Ray object with origins and directions.
    image_idx: Index of the current training image.
    nerf_model: NeRF model providing shared density sigma and candidate density sigma_c.
    dpt_model: Pre-trained DPT model for monocular depth estimation.
    eta: Learnable scale parameter for image_idx.
    xi: Learnable shift parameter for image_idx.
    """
    # 1. Acquire monocular inverse depth from DPT
    # D_inv is a dense map for the image; we sample it at the ray's pixel coordinates
    pixel_coords = ray.get_pixel_coordinates()
    d_inv = dpt_model.predict_inverse_depth(image_idx, pixel_coords)
    
    # 2. Compute aligned monocular depth D*
    # D* = 1 / (eta * D_inv + xi)
    d_mono = 1.0 / (eta * d_inv + xi)
    
    # 3. Render NeRF depth D_hat
    # Sample points along the ray
    t_samples = ray.sample_points(K=K_samples)
    sigma_shared = nerf_model.get_shared_density(t_samples)
    sigma_cand = nerf_model.get_candidate_density(t_samples)
    
    # Compute opacity alpha and transmittance T
    # alpha = 1 - exp(-sigma * delta)
    deltas = t_samples[1:] - t_samples[:-1]
    # Handle last delta or edge case if necessary [G]
    deltas = np.append(deltas, deltas[-1]) 
    
    alpha = 1.0 - np.exp(-sigma_shared * deltas)
    
    # Transmittance T(t_k) = product of (1 - alpha_j) for j < k
    T = np.cumprod(np.concatenate([[1.0], 1.0 - alpha[:-1]]))
    
    # Rendered depth D_hat = sum(T * alpha * t)
    d_hat = np.sum(T * alpha * t_samples)
    
    # 4. Calculate transient confidence weight W_depth
    # W_depth = sum(T_cand * alpha_cand)
    # Alpha_cand uses candidate density sigma_c
    alpha_cand = 1.0 - np.exp(-sigma_cand * deltas)
    T_cand = np.cumprod(np.concatenate([[1.0], 1.0 - alpha_cand[:-1]]))
    w_depth = np.sum(T_cand * alpha_cand)
    
    # 5. Compute weighted L1 loss
    # L_depth = (1 - W_depth) * |D* - D_hat|
    loss = (1.0 - w_depth) * np.abs(d_mono - d_hat)
    
    return loss
```

## Subtopics

## Operating characteristics
- **Time Complexity:** Adds the cost of a forward pass through the DPT network per image (or cached) and additional density evaluations for the candidate head to compute $W_{depth}$ [S1, unofficial].
- **Memory Complexity:** Requires storing learnable $\eta_i, \xi_i$ per image and potentially caching DPT outputs [S1, unofficial].
- **Performance:** Improves novel view synthesis metrics (PSNR, SSIM) on unconstrained datasets like PhotoTourism compared to baselines like BARF and NeRF-W [S1, unofficial].
- **Strengths:** Effectively suppresses floaters and geometry collapse in unconstrained image collections by leveraging strong geometric priors [S1, unofficial].
- **Limitations:** The depth prior is a pseudo-label and not ground truth; over-reliance can degrade rendering quality if not properly weighted [S1, unofficial]. The method relies on the accuracy of the DPT model [S1, unofficial].
- **When to use:** When training NeRF on unconstrained image sets with potential transient objects and unknown poses [S1, unofficial].
- **When not to use:** When high-quality ground truth depth is available, or when computational resources for DPT inference are prohibitive [S1, unofficial].

## Background
The method was introduced in UP-NeRF (Unconstrained Pose-Prior-Free Neural Radiance Fields) [S1, unofficial]. It is inspired by NoPe-NeRF [S2], which also uses monocular depth regularization. However, UP-NeRF adapts the approach for unconstrained images by using per-image affine alignment and transient-aware weighting, whereas NoPe-NeRF originally focused on video sequences with inter-frame losses [S1, unofficial]. The DPT (Dense Prediction Transformer) model is used as the monocular depth estimator [S1, unofficial][S2].
