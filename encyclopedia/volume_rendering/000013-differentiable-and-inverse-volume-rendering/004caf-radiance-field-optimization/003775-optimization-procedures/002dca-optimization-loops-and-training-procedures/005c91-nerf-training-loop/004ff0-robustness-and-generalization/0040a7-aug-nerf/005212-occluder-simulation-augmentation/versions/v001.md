# Occluder simulation augmentation

Also called: Transient occluder simulation

## Overview
Occluder simulation augmentation is a data augmentation technique that overlays randomly positioned and colored squares on training images to test and improve model robustness to in-the-wild transient occlusions [S1]. It sets itself apart from standard augmentation by explicitly simulating the physical presence of temporary objects that obscure underlying geometry, forcing the neural radiance field to learn to ignore or represent these artifacts as non-permanent features [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of training images $\{I_i\}$ for a static scene.
*   **Output:** An augmented dataset $\{I'_i\}$ where transient occluders are simulated.

**Data Structures:**
*   **Occluder:** A rectangular region defined by its top-left coordinate $(x, y)$, width $w$, and height $h$ in pixel space.
*   **Stripes:** The occluder is composed of 10 vertical stripes. Each stripe has a random color $C_j \in \mathbb{R}^3$ (RGB).

**Steps:**
1.  **Reference Image:** Leave the first training image $I_0$ untouched to serve as a reference for evaluation [S1].
2.  **Iteration:** For each subsequent training image $I_i$ ($i > 0$):
    a.  **Position Selection:** Randomly select a position $(x, y)$ for the occluder square within the image boundaries [S1].
    b.  **Color Generation:** Generate 10 random colors $\{C_1, ..., C_{10}\}$ for the vertical stripes [S1].
    c.  **Overlay:** Draw a square at $(x, y)$ filled with the 10 vertical stripes of the generated colors [S1].
    d.  **Result:** The resulting image $I'_i$ contains the occluder [S1].

**Parameters:**
*   **Stripes per Occluder:** 10 [S1].
*   **Occluder Shape:** Square [S1].
*   **Occluder Position:** Random [S1].
*   **Occluder Color:** Random [S1].

**Edge Cases and Pitfalls:**
*   **Consistency:** The occluders must not have a consistent 3D location across images. If they do, the model may learn them as part of the static geometry rather than transient noise [S1].
*   **Evaluation Bias:** Standard metrics like PSNR, MS-SSIM, and LPIPS are unable to ignore transient objects. Evaluating against reference images that contain occluders will yield poor scores because the NeRF model is designed to generate clean scenes without such occlusions [S1].

**Pseudocode:**
```python
import random
import numpy as np

def apply_occluder_augmentation(image: np.ndarray) -> np.ndarray:
    """
    Applies transient occluder simulation to a single training image.
    
    Args:
        image: Input training image (H, W, 3) in RGB.
        
    Returns:
        Augmented image with a random occluder.
    """
    # Create a copy to avoid modifying the original
    augmented_image = image.copy()
    h, w, _ = augmented_image.shape
    
    # 1. Randomly position the occluder square
    # The source does not specify the size of the square, only that it is a square.
    # We assume a reasonable size relative to the image, e.g., 10% of the smaller dimension.
    size = max(1, int(min(h, w) * 0.1))
    x = random.randint(0, w - size)
    y = random.randint(0, h - size)
    
    # 2. Generate 10 random vertical stripes
    # Each stripe has a random color
    num_stripes = 10
    stripe_width = max(1, size // num_stripes)
    
    for j in range(num_stripes):
        # Random color for this stripe
        color = np.random.randint(0, 256, size=3, dtype=np.uint8)
        
        # Calculate x-coordinates for this stripe
        stripe_x_start = x + j * stripe_width
        stripe_x_end = min(x + (j + 1) * stripe_width, x + size)
        
        # Ensure the last stripe covers any remaining width
        if j == num_stripes - 1:
            stripe_x_end = x + size
            
        # 3. Overlay the stripes on the image
        # Clip to image boundaries
        y_start = max(0, y)
        y_end = min(h, y + size)
        x_start = max(0, stripe_x_start)
        x_end = min(w, stripe_x_end)
        
        if x_end > x_start and y_end > y_start:
            augmented_image[y_start:y_end, x_start:x_end] = color
            
    return augmented_image

def augment_dataset(images: list) -> list:
    """
    Augments a list of training images.
    The first image is left untouched.
    """
    augmented_images = []
    for i, img in enumerate(images):
        if i == 0:
            # Leave the first training image untouched for reference
            augmented_images.append(img)
        else:
            augmented_images.append(apply_occluder_augmentation(img))
    return augmented_images
```

## Subtopics

### Differentiable Augmentation Layer
A training technique to promote robustness against image attacks by applying differentiable augmentations to the fully rendered image before passing it to a watermark decoder [S2]. Unlike occluder simulation which modifies input training data, this method modifies the output of the renderer [S2]. It selects a random pair of augmentations from a set including brightness, contrast, color jiggle, gaussian blur, gaussian noise, hue, posterize, RGB shift, saturation, median blur, box blur, motion blur, sharpness, and differentiable JPEG compression [S2]. This ensures the embedded watermark survives typical image processing attacks [S2].

## Operating characteristics
*   **Performance Impact:** On the Lego dataset, this variation reduces NeRF's PSNR by 14 dB on average [S1].
*   **Reason for Degradation:** NeRF and NeRF-A represent occluders as colored fog in 3D space, thereby causing the underlying geometry (e.g., the Lego figure) to be obscured [S1].
*   **Strengths:** Tests model robustness to in-the-wild occlusions [S1].
*   **Limitations:** Standard evaluation metrics (PSNR, MS-SSIM, LPIPS) are biased against this augmentation because they compare against clean reference images, while the model is trained to ignore the occluders [S1].

## Background
Originated in the context of "NeRF in the Wild" (NeRF-W), where unconstrained photo collections contain transient objects like people and vehicles [S1]. The technique was introduced to address the inconsistency and non-smooth geometries that arise when standard NeRF models try to fit these transient objects as part of the static scene [S1]. It is a component of the Aug-NeRF framework, which injects worst-case perturbations into the NeRF pipeline [Parent].
