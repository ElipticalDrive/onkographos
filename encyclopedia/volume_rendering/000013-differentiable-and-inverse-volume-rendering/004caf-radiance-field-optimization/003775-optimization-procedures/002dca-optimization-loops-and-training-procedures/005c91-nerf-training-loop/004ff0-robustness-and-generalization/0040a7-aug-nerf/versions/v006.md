# Aug-NeRF

Also called: Aug-NeRF Training Pipeline, Augmented NeRF, Triple-Level Physically-Grounded Augmentations

## Overview
Aug-NeRF is a training framework for Neural Radiance Fields (NeRF) that injects worst-case adversarial perturbations at three distinct levels of the rendering pipeline—input coordinates, intermediate MLP features, and pre-rendering output—to implicitly regularize the model [S1]. Unlike explicit smoothness regularizers (e.g., Laplacian or Total Variation) that aggressively constrain MLP flexibility, Aug-NeRF uses these physically-grounded perturbations to induce a data-adaptive smoothness prior, enhancing generalization to unseen views and robustness to noisy supervision [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ training images $I = \{I_i \in \mathbb{R}^{M}\}_{i=1}^N$ with corresponding camera poses $P = \{\phi_i \in \mathbb{R}^{3 \times 4}\}_{i=1}^N$.
*   **Outputs:** Optimized neural radiance field parameters $\Theta$.

**Data Structures:**
*   **Ray Representation:** $r = (o, d, \theta)$, where $o \in \mathbb{R}^3$ is the optical center, $d \in \mathbb{R}^3$ is the direction, and $\theta \in [-\pi, \pi]^2$ is the angular view direction [S1].
*   **Radiance Field:** $F_\Theta(p, \theta) = (g \circ f(p, \theta), h \circ f(p))$, mapping spatial coordinate $p \in \mathbb{R}^3$ and view direction $\theta$ to color $c \in \mathbb{R}^3$ and density $\sigma \in \mathbb{R}^+$ [S1]. The network $F_\Theta$ consists of a positional encoding $\gamma$ and an MLP, structured as $F_\Theta = \gamma \circ \text{MLP}_\Theta$ [S1].
*   **Perturbations:** $\delta = (\delta_p, \delta_f, \delta_r)$, where $\delta_p$ affects coordinates, $\delta_f$ affects features, and $\delta_r$ affects output [S1].

**Parameters:**
*   $K$: Total number of depth intervals sampled per ray (sum of coarse and fine samples).
*   $t_n, t_f$: Near and far bounds of the ray segment [S1].
*   $\lambda$: Regularization weight, set to 0.1 [S1].
*   $\epsilon$: Radius of the perturbation search space (e.g., $\epsilon_p$ for coordinates, $\epsilon_f$ for features, $\epsilon_c, \epsilon_\sigma$ for output) [S1].
*   PGD Configuration: Coordinate level uses 3 steps with step size $10^{-2}$; Feature level uses 1 step with step size $10^{-3}$; Pre-rendering level uses 1 step with step size $10^{-5}$ [S1].

**Algorithm:**
The method formulates training as a min-max game:
$$ \min _{\Theta } \mathbb{E}_{(r, \widehat{C}) \sim P(\mathcal{R})} \max _{\delta } \left \| C^\dag (r | \Theta , \delta ) - \widehat{C} \right \|_2^2 $$
where $C^\dag$ is the rendered color under perturbation $\delta$ [S1]. The full objective combines photometric loss and adversarial regularization:
$$ \mathbb{E}_{(r, \widehat{C}) \sim P(\mathcal{R})} \left \| C(r | \Theta ) - \widehat{C} \right \|_2^2 + \lambda \max _{\delta } \left \| C^\dag (r | \Theta , \delta ) - \widehat{C} \right \|_2^2 $$
[S1].

**Steps:**
1.  **Ray Casting:** For each pixel in each training image $I_i$, cast a ray $r_i = (o_i, d_i, \theta_i)$ using the inverse projection of camera pose $\phi_i$ [S1].
2.  **Perturbation Search:** For the current ray, compute worst-case perturbations $\delta_t, \delta_{xyz}, \delta_\theta, \delta_f, \delta_c, \delta_\sigma$ using Projected Gradient Descent (PGD) to maximize the loss [S1].
    *   The PGD update rule for $\ell_\infty$ norm constraint is:
        $$ \delta^{(t+1)} = \text{Proj}_{\|\delta\|_\infty \le \epsilon} \left [ \delta^{(t)} + \alpha \cdot \text{sgn}(\nabla_{\delta} \mathcal{L}(\Theta | \mathcal{R}, \delta )) \right ] $$
        where $\alpha$ is the step size and $\text{Proj}$ clamps the perturbation within the radius $\epsilon$ [S1].
3.  **Sampling:**
    *   **Coarse:** Sample $K/2$ depth intervals $t_k$ uniformly between $t_n$ and $t_f$ [S1].
    *   **Fine:** Sample $K/2$ depth intervals $t_k$ proportional to the densities from the coarse pass [S1].
4.  **Coordinate Perturbation:**
    *   Compute perturbed depth: $t^\dag_k = t_k + \delta_{t,k}$ [S1].
    *   Compute perturbed view direction: $\theta^\dag = \theta + \delta_\theta$ [S1].
    *   Compute perturbed point: $p^\dag_k = o + t^\dag_k d + \delta_{xyz}$ [S1].
    *   Constraints: $\delta_t$ is bounded by $|\alpha_t (t_{k+1} - t_k)|$; $\delta_{xyz}$ lies in a ball $B(0, \epsilon_p)$; $\delta_\theta$ is restricted to $[-\epsilon_p / 2f, \epsilon_p / 2f]^2$ [S1].
5.  **Network Query:**
    *   Query unperturbed color and density: $(c_k, \sigma_k) = g \circ f(p_k, \theta), h \circ f(p_k)$ where $p_k = o + t_k d$ [S1].
    *   Query perturbed features: $f^\dag_k = f(p^\dag_k) + \delta_f$ [S1].
    *   Compute perturbed color: $c^\dag_k = g(f^\dag_k, \theta^\dag) + \delta_c$ [S1].
    *   Compute perturbed density: $\sigma^\dag_k = h(f^\dag_k) + \delta_\sigma$ [S1].
    *   Note: $\delta_c, \delta_\sigma$ are clamped to ensure $c^\dag_k, \sigma^\dag_k$ remain in $[0, 1]$ [S1].
6.  **Volumetric Rendering:**
    *   Compute intervals: $\Delta t_k = t_k - t_{k-1}$, $\Delta t^\dag_k = t^\dag_k - t^\dag_{k-1}$ [S1].
    *   Compute transmittance: $T(k) = \exp(-\sum_{l=1}^{k-1} \sigma_l \Delta t_l)$, $T^\dag(k) = \exp(-\sum_{l=1}^{k-1} \sigma^\dag_l \Delta t^\dag_l)$ [S1].
    *   Render unperturbed color: $C_i = \sum_{k=1}^K T(k)(1 - \exp(-\sigma_k \Delta t_k))c_k$ [S1].
    *   Render perturbed color: $C^\dag_i = \sum_{k=1}^K T^\dag(k)(1 - \exp(-\sigma^\dag_k \Delta t^\dag_k))c^\dag_k$ [S1].
7.  **Loss and Update:**
    *   Compute loss: $\mathcal{L} = \|C_i - \widehat{C}_i\|_2^2 + \lambda \|C^\dag_i - \widehat{C}_i\|_2^2$ [S1].
    *   Update $\Theta$ via gradient descent on $\mathcal{L}$ [S1].

**Pseudocode:**
```python
def aug_nerf_train(images, poses, F_theta, K, lambda_reg, pgd_config):
    """
    images: List of N training images.
    poses: List of N camera poses (3x4 matrices).
    F_theta: Neural radiance field function F_theta(p, theta) -> (c, sigma).
             F_theta consists of encoder f, color branch g, density branch h.
    K: Total number of samples per ray.
    lambda_reg: Adversarial regularization weight (0.1).
    pgd_config: Dict with keys 'coord_steps', 'coord_alpha', 'feat_steps', 'feat_alpha', 
                'output_steps', 'output_alpha', and epsilon bounds.
    """
    rays = []
    for i in range(len(images)):
        for pixel in images[i].pixels:
            o, d, theta = cast_ray(pixel, poses[i])
            rays.append((o, d, theta, pixel.color))
    
    for iteration in range(500000): # 500K iterations
        ray = random_sample(rays)
        o, d, theta, C_gt = ray
        
        # 1. Generate Adversarial Perturbations via PGD
        # Initialize deltas to zero
        delta_t = 0
        delta_xyz = [0, 0, 0]
        delta_theta = [0, 0, 0]
        delta_f = [0] * D # D is hidden dimension
        delta_c = [0, 0, 0]
        delta_sigma = 0
        
        # Coordinate PGD
        for step in range(pgd_config['coord_steps']):
            # Compute loss gradient w.r.t coordinate perturbations
            grad = compute_coord_grad(o, d, theta, C_gt, F_theta, delta_t, delta_xyz, delta_theta)
            delta_t += pgd_config['coord_alpha'] * sign(grad['t'])
            delta_xyz += pgd_config['coord_alpha'] * sign(grad['xyz'])
            delta_theta += pgd_config['coord_alpha'] * sign(grad['theta'])
            # Project to constraints
            delta_t = clamp(delta_t, -epsilon_t, epsilon_t)
            delta_xyz = clamp_norm(delta_xyz, epsilon_p)
            delta_theta = clamp_range(delta_theta, -epsilon_p/2f, epsilon_p/2f)
            
        # Feature PGD
        for step in range(pgd_config['feat_steps']):
            grad = compute_feat_grad(o, d, theta, C_gt, F_theta, delta_t, delta_xyz, delta_theta, delta_f)
            delta_f += pgd_config['feat_alpha'] * sign(grad['f'])
            delta_f = clamp_range(delta_f, -epsilon_f, epsilon_f)
            
        # Output PGD
        for step in range(pgd_config['output_steps']):
            grad = compute_output_grad(o, d, theta, C_gt, F_theta, delta_t, delta_xyz, delta_theta, delta_f, delta_c, delta_sigma)
            delta_c += pgd_config['output_alpha'] * sign(grad['c'])
            delta_sigma += pgd_config['output_alpha'] * sign(grad['sigma'])
            # Clamp to valid range for color/density
            delta_c = clamp_range(delta_c, -epsilon_c, epsilon_c)
            delta_sigma = clamp_range(delta_sigma, -epsilon_sigma, epsilon_sigma)

        # 2. Sampling
        coarse_samples = uniform_sample(K/2, t_n, t_f)
        fine_samples = proportional_sample(K/2, coarse_samples, F_theta, o, d, theta)
        all_samples = sorted(coarse_samples + fine_samples)
        
        # 3. Perturbed Rendering
        C_perturbed = 0
        T_prev = 1.0
        
        for k in range(len(all_samples)):
            t_k = all_samples[k]
            t_k_pert = t_k + delta_t
            
            # Perturbed Point
            p_k_pert = o + t_k_pert * d + delta_xyz
            theta_pert = theta + delta_theta
            
            # Perturbed Features
            f_pert = F_theta.encoder(p_k_pert) + delta_f
            
            # Perturbed Density and Color
            sigma_k_pert = F_theta.density_branch(f_pert) + delta_sigma
            c_k_pert = F_theta.color_branch(f_pert, theta_pert) + delta_c
            
            # Clamp outputs
            sigma_k_pert = clamp(sigma_k_pert, 0, 1)
            c_k_pert = clamp(c_k_pert, 0, 1)
            
            # Intervals
            if k == 0:
                delta_t_k_pert = t_k_pert - t_n
            else:
                delta_t_k_pert = t_k_pert - all_samples[k-1]
                
            # Transmittance
            T_curr = T_prev * exp(-sigma_k_pert * delta_t_k_pert)
            
            # Contribution
            alpha_k = 1 - exp(-sigma_k_pert * delta_t_k_pert)
            C_perturbed += T_prev * alpha_k * c_k_pert
            
            T_prev = T_curr
            
        # 4. Loss and Update
        C_clean = render_clean(o, d, theta, F_theta, all_samples) # Standard NeRF render
        loss = norm_sq(C_clean - C_gt) + lambda_reg * norm_sq(C_perturbed - C_gt)
        update_weights(F_theta, loss)
```

## Subtopics

### Occluder simulation augmentation
A data augmentation technique that simulates transient occluders by overlaying randomly positioned and colored squares on training images to test model robustness to in-the-wild occlusions [S2]. Each square consists of ten vertical, colored stripes with colors chosen at random, and they do not have a consistent 3D location across images [S2]. On the Lego dataset, this variation reduces NeRF's PSNR by 14 dB on average, as NeRF represents occluders as colored fog in 3D space, obscuring underlying geometry [S2].

## Operating characteristics
*   **Time Complexity:** The method adds significant overhead due to the inner-loop PGD optimization for perturbation search at each training step. The number of PGD steps varies by level (3 for coordinates, 1 for features, 1 for output) [S1].
*   **Memory Complexity:** Requires storing gradients for perturbations in addition to standard NeRF parameters. The feature perturbation $\delta_f$ has dimension $D$ (hidden dimension of the MLP) [S1].
*   **Performance:** Achieves up to 1.5 dB PSNR gain over baseline NeRF [S1]. On LLFF, it reduces average error by 14.3%–26.0%; on 360° NeRF-Synthetic, by 12.5%–44.7% [S1]. Specific PSNR improvements on LLFF include fern (+1.34), orchids (+1.24), trex (+1.37) [S1].
*   **Strengths:** Implicitly regularizes the loss landscape without sacrificing representation flexibility, unlike explicit regularizers (Laplacian, TV) which can degrade performance [S1]. Robust to noisy supervision (Gaussian and Shot noise), reducing average error by 6.5%–26.9% [S1].
*   **Limitations:** Excessively strong perturbations (e.g., PGD-10) deteriorate training performance [S1]. The method assumes a batch size of 1 for simplicity in the base description [S1].
*   **Hardware:** Tested on NVIDIA RTX A6000 GPU with 48 GB memory [S1].

## Background
Aug-NeRF was proposed by Tianlong Chen, Peihao Wang, Zhiwen Fan, and Zhangyang Wang from The University of Texas at Austin [S1]. It was published in 2022 (arXiv:2207.01164v1) [S1]. The work addresses the generalization gap in NeRF where interpolated novel views yield inconsistent and non-smooth geometries [S1]. It draws inspiration from robust data augmentations in convolutional neural networks, applying worst-case perturbations to the NeRF pipeline for the first time [S1].
