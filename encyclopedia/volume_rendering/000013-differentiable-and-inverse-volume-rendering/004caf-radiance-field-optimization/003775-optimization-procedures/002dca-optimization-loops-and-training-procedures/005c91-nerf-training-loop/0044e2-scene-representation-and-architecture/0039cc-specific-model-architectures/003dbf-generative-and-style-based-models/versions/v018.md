# Generative and Style-based Models

Also called: Generative NeRF, Style-based Radiance Fields, 3D-aware GANs

## Overview
Generative and style-based models synthesize novel 3D-consistent images from latent codes or text prompts, solving the limitation of standard NeRF which only reconstructs specific input scenes. Unlike standard NeRF, which optimizes a fixed MLP for a single scene, these methods train a generator network to map a latent distribution to a radiance field, enabling the creation of new, unseen 3D objects or styles [S1, S2]. They differ from siblings like [Sparse and Efficient Representations](9326-sparse-and-efficient-representations.md) by prioritizing generative capability and high-fidelity texture synthesis over efficient reconstruction of observed data.

## Shared principles
All methods in this family share the mechanism of mapping 6D input coordinates (3D position $\mathbf{x}$ and 2D viewing direction $\mathbf{d}$) to 4D output values (density $\sigma$ and color $\mathbf{c}$) using a differentiable neural network. This allows the radiance field to be optimized through the volumetric rendering integral.

**Input Representation:**
Raw coordinates $\mathbf{x}$ and $\mathbf{d}$ are rarely used directly due to the spectral bias of MLPs, which struggle to fit high-frequency details. They are mapped to a higher-dimensional space using positional encoding $\gamma(\cdot)$ [S1][S3]. For a coordinate $\mathbf{x}$, the encoding includes the original value and sinusoidal functions at increasing frequencies:
$$
\gamma(\mathbf{x}) = (\sin(2^0 \pi \mathbf{x}), \cos(2^0 \pi \mathbf{x}), \dots, \sin(2^{L-1} \pi \mathbf{x}), \cos(2^{L-1} \pi \mathbf{x}))
$$
where $L$ is the number of frequency bands [S1][S3].

**Network Topology:**
The canonical implementation uses two coupled Multi-Layer Perceptrons (MLPs): a density network $F_\sigma$ and a color network $F_c$ [S1][S3].
1.  **Density Network:** Takes the encoded position $\gamma(\mathbf{x})$ as input. It consists of $L$ hidden layers with ReLU activations and skip connections from the input to every 4th layer to preserve low-frequency information [S1][S3]. The output is the density $\sigma$.
2.  **Color Network:** Takes the encoded position $\gamma(\mathbf{x})$, the raw viewing direction $\mathbf{d}$, and the intermediate feature vector from the density network (usually the output of the last hidden layer before the density head) as input. It predicts the color $\mathbf{c}$ using a final ReLU or sigmoid activation [S1][S3].

**Rendering Integration:**
During training, rays are sampled at points $\mathbf{x}_i$ along the ray. The MLPs predict $\sigma_i$ and $\mathbf{c}_i$. The pixel color $C(\mathbf{r})$ is computed via volumetric rendering:
$$
C(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i, \quad \text{where } \alpha_i = 1 - \exp(-\sigma_i \delta_i), \quad T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)
$$
and $\delta_i$ is the distance between samples [S1][S3].

## Subtopics

### [StyleNeRF](8659-stylenerf.md)
Conditions NeRF weights on style vectors derived from a mapping network, enabling fine-grained appearance control while maintaining 3D geometry consistency. Choose when high-resolution, style-controllable 3D generation is required.

### [HyperNeRFGAN](8765-hypernerfgan.md)
Uses a hypernetwork to generate NeRF weights from noise, enabling 3D-aware generation without view-dependent training data. Choose when training data lacks view-dependent cues or when weight-space conditioning is preferred.

### [Latent-NeRF](9110-latent-nerf.md)
Integrates a pre-trained latent diffusion model (Stable Diffusion) to guide NeRF optimization via score distillation. Choose for text-guided or shape-guided high-resolution 3D synthesis without 3D training data.

### [pi-GAN](10298-pi-gan.md)
Uses a SIREN backbone conditioned by a StyleGAN-inspired mapping network with Feature-wise Linear Modulation (FiLM). Choose for unsupervised 3D representation learning with high image quality on standard datasets.

### [GIRAFFE](11360-giraffe.md)
Represents scenes as compositions of multiple entities (objects + background), each with separate feature fields and transformations. Choose when explicit control over individual object pose, shape, and appearance is needed.

### [Generative Latent Optimization](11963-generative-latent-optimization.md)
Jointly optimizes generator parameters and latent codes to reconstruct a dataset, bypassing adversarial training. Choose when discriminator-free reconstruction of specific views or attributes is desired.

- [S1] Deforms feature maps rather than 3D points so lighting and expression changes stay consistent during motion.

### Adversarial Training (GAN)
- [S2] Training a discriminator network in parallel with the super-resolution generator to classify images as ground truth or predicted, using the discriminator's output as a loss term for the generator.
- [S2] Discriminator Loss: $L_{GAN,D} = - \log(D(x)) - \log(1 - D(G(z)))$. Generator Loss: $L_{GAN,G} = - \log(D(G(z)))$. Here, $z$ is the input over all timesteps, $G(z)$ is the generated result, $D(x)$ is the discriminator score for real data $x$, and $x$ is replaced by $G(z)$ for fake data.

- [S3] Trains a 2D PST network for more realistic scene presentation.

- [S3] Introduces a nearest neighbor feature matching loss to impart detailed style structures onto the original NeRF.

## Background
Generative NeRF models emerged as an extension of the original NeRF framework [S1]. While standard NeRF reconstructs a single static scene from images, generative variants aim to learn a distribution over 3D shapes and appearances. Early works like [GRAF](9572-generative-and-style-based-models.md) and [pi-GAN](10298-pi-gan.md) adapted GAN architectures to 3D radiance fields. Subsequent methods like [StyleNeRF](8659-stylenerf.md) and [HyperNeRFGAN](8765-hypernerfgan.md) introduced style-based and hypernetwork-based conditioning to improve resolution and controllability. More recently, methods like [Latent-NeRF](9110-latent-nerf.md) have integrated diffusion models to leverage large-scale 2D priors for 3D generation. These models are used in computer graphics for content creation, virtual reality, and 3D editing [S1, S2, S3].
