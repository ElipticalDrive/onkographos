# Progressively-connected Light Field Network (ProLiF) Architecture


## Overview
ProLiF is a neural light field representation that decouples geometry and appearance via coupled MLPs, optimized through a progressive training scheme that incrementally increases network connectivity [S1, unofficial]. It differs from sibling methods like NeLF by training with a fixed total parameter budget that is redistributed from many small subnetworks to fewer, wider networks over time, preventing overfitting in early stages while enabling high-fidelity detail reconstruction in later stages [S1, unofficial].

## How it works
ProLiF builds on [Specific Model Architectures](8585-specific-model-architectures.md) by using a set of independent subnetworks that are merged during training.

**Inputs and Outputs:**
*   **Input:** Ray parameters $(u, v, s, t)$ and depth samples. At stage $k$, the input vector $p_k$ consists of sampled $x-y$ coordinates: $p_k = [x^k_0, y^k_0, \dots, x^k_{D_k-1}, y^k_{D_k-1}]$ [S1, unofficial].
*   **Output:** Concatenated color and density values for the depth samples [S1, unofficial].

**Data Structures:**
*   **Subnetworks:** At training stage $k$, the model consists of $N_k = D \times 2^{-k}$ subnetworks $\Phi^k = \{F^k_0, F^k_1, \dots, F^k_{N_k-1}\}$ [S1, unofficial].
*   **Width:** Each subnetwork has a hidden width of $W \times 2^k$ [S1, unofficial].
*   **Total Capacity:** The sum of hidden widths for each layer remains constant throughout training [S1, unofficial].
*   **Parameters:**
    *   $D$: Preset parameter determining the initial number of subnetworks and depth samples. At stage $k=0$, $N_0 = D$ and $D_0 = D$ [S1, unofficial].
    *   $W$: Preset parameter determining the base hidden width [S1, unofficial].
    *   Final Stage: When $k = \log_2(D)$, ProLiF becomes a single fully-connected MLP with $\Phi^k = \{F^k_0\}$ [S1, unofficial].

**Numbered Steps:**

1.  **Initialization (Stage $k=0$):** Initialize $D$ subnetworks, each with hidden width $W$. The input depth samples are $D_0 = D$.
2.  **Forward Pass:** For each ray, compute sampled $x-y$ coordinates $x^k_i = u + (s-u)d^k_i$ and $y^k_i$ [S1, unofficial]. Pass the concatenated input vector $p_k$ through the active subnetworks to predict density and color.
3.  **Rendering:** Compute pixel color $C(\mathbf{r})$ using volumetric rendering with the predicted $\sigma_i$ and $\mathbf{c}_i$ [S1, unofficial].
4.  **Progressive Connection (Merging):** At the end of stage $k$, merge neighboring subnetworks to form stage $k+1$.
    *   Merge $F^k_{2i}$ and $F^k_{2i+1}$ into $F^{k+1}_i$ for $i \in \{0, \dots, D \times 2^{-(k+1)} - 1\}$ [S1, unofficial].
    *   **Weight Matrix Construction:** The new weight matrix $W^{k+1}_i$ is constructed by zero-padding and concatenating the weights of the merged subnetworks:
        $$
        W^{k+1}_i = \begin{bmatrix} W^k_{2i} & 0 \\ 0 & W^k_{2i+1} \end{bmatrix}
        $$
        This ensures the output $z^{k+1}_i = [z^k_{2i}, z^k_{2i+1}]$ remains unchanged [S1, unofficial].
    *   **Bias Vector Construction:** The new bias vector is concatenated:
        $$
        b^{k+1}_i = [b^k_{2i}, b^k_{2i+1}]
        $$
        [S1, unofficial].
5.  **Depth Subdivision:** When switching from stage $k$ to $k+1$, the number of depth samples increases from $D_k$ to $D_{k+1} = D \times 2^{k+1}$ [S1, unofficial]. The input vector changes from $p_k$ to $p_{k+1}$ [S1, unofficial].
6.  **Reparameterization for Subdivision:** To maintain output invariance despite the input dimension doubling, reparameterize the weights and biases of the first and last layers.
    *   **Input Layer Reparameterization:** Double the weights and scale by 0.5.
    *   **Output Layer Reparameterization:** Double-copy the original parameters of the last layers [S1, unofficial].

**Pseudocode:**

```python
def subdiv_input_layers(org_weight, org_bias):
    """
    Reparameterize weights and biases for depth subdivision.
    org_weight: shape [n_subnetworks, d_out, d_in]
    org_bias: shape [n_subnetworks, d_out]
    Returns: new_weight, new_bias
    """
    bias = org_bias
    # Rearrange to separate the two halves of the input dimension
    # c=2 implies splitting the last dimension into 2 parts
    weight = rearrange(org_weight, 'n o (d c) -> n o d c', c=2)
    # Concatenate the weight matrix with itself along the input channel dimension
    # and scale by 0.5 to preserve the output value
    weight = concatenate([weight, weight], dim=3) * 0.5
    # Rearrange back to original shape structure
    weight = rearrange(weight, 'n o d c -> n o (d c)')
    return weight, bias

def add_connections(org_weight, org_bias):
    """
    Merge neighboring subnetworks and reparameterize output layers.
    org_weight: shape [n_subnetworks, d_out, d_in]
    org_bias: shape [n_subnetworks, d_out]
    Returns: new_weight, new_bias
    """
    n_subnetworks, d_out, d_in = org_weight.shape
    # Number of merged subnetworks
    new_n_subnetworks = n_subnetworks // 2
    
    new_weight = []
    new_bias = []
    
    for i in range(new_n_subnetworks):
        # Get weights and biases for the two subnetworks to merge
        w1 = org_weight[2 * i]
        w2 = org_weight[2 * i + 1]
        b1 = org_bias[2 * i]
        b2 = org_bias[2 * i + 1]
        
        # Construct new weight matrix by zero-padding and concatenating
        # W^{k+1}_i = [[W^k_{2i}, 0], [0, W^k_{2i+1}]]
        # Assuming d_out is the output dimension of the previous layer
        # and d_in is the input dimension.
        # We need to pad w1 and w2 to match the new output dimension d_out * 2
        # However, the source specifies the output z^{k+1}_i = [z^k_{2i}, z^k_{2i+1}]
        # This implies the output dimension doubles.
        
        # Zero padding for w1: [d_out, d_in] -> [2*d_out, d_in]
        # Top half is w1, bottom half is zeros
        w1_padded = concatenate([w1, zeros_like(w1)], dim=0)
        
        # Zero padding for w2: [d_out, d_in] -> [2*d_out, d_in]
        # Top half is zeros, bottom half is w2
        w2_padded = concatenate([zeros_like(w2), w2], dim=0)
        
        # Concatenate vertically
        merged_w = concatenate([w1_padded, w2_padded], dim=0)
        
        # Concatenate biases vertically
        merged_b = concatenate([b1, b2], dim=0)
        
        new_weight.append(merged_w)
        new_bias.append(merged_b)
        
    return stack(new_weight), stack(new_bias)
```

**Edge Cases and Pitfalls:**
*   **Output Invariance:** During subdivision, the weight reparameterization (doubling weights and scaling by 0.5) is critical to ensure that hidden features and final outputs remain unchanged despite the input dimension doubling [S1, unofficial].
*   **Stage Transition:** The transition from stage $k$ to $k+1$ requires both merging subnetworks and subdividing depth samples. The reparameterization must be applied to both input and output layers to maintain consistency [S1, unofficial].

## Subtopics

### [Progressive Training Scheme](17248-progressive-training-scheme.md)
A training strategy that incrementally increases neuron connections across training stages to prevent overfitting and improve detail reconstruction in light field networks.

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** The total parameter count is constant throughout training, as the sum of hidden widths for each layer remains constant [S1, unofficial].
*   **Performance:** Not given in the sources.
*   **Strengths:** Prevents overfitting in early training stages by using many small subnetworks, while enabling high-fidelity detail reconstruction in later stages by merging them into a single large network [S1, unofficial].
*   **Limitations:** Requires careful reparameterization to maintain output invariance during stage transitions [S1, unofficial].

## Background
ProLiF was introduced in a 2022 preprint titled "Progressively-connected Light Field Network for Efficient View Synthesis" [S1, unofficial]. It addresses the challenge of balancing training stability and reconstruction quality in neural light field representations.
