# Volume Rendering Prior (VRPrior)

Also called: learnable differentiable renderer, neural weight function

## Overview
VRPrior replaces handcrafted, 1D ray-centric equations for mapping unsigned distance fields (UDF) to opaque density with a learned neural network $f_w$ that incorporates 3D spatial context from neighboring points [S1]. It solves the bias and sensitivity to outliers inherent in methods using only two neighbors on a ray, providing robustness to unsigned distance variations and enabling better generalization to unseen scenes [S1]. Unlike sibling methods that rely on fixed geometric loss terms or SDF truncation shells, VRPrior learns the optimal weighting function for alpha blending directly from ground truth geometry [S1].

## How it works
VRPrior operates in two distinct phases: **Prior Training** (learning the mapping function $f_w$) and **Generalization** (optimizing the scene's UDF field $f_u$ and color network $f_c$ using the fixed $f_w$) [S1].

### Inputs and Outputs
*   **Prior Training Inputs:** Ground truth meshes $\{S_h\}_{h=1}^H$, camera poses for $A$ views per shape.
*   **Prior Training Outputs:** Network parameters $\theta_w$ for $f_w$.
*   **Generalization Inputs:** Multi-view RGB images $\{I_j\}_{j=1}^J$, camera poses.
*   **Generalization Outputs:** Optimized UDF field $f_u$, color network $f_c$, and rendered RGB/Depth images.

### Data Structures and Network Layout
The core component is the volume rendering prior network $f_w$. It does not take a single query point in isolation but processes a local neighborhood [S1].

1.  **Neighbor Selection:** For a query point $q_n$ on a ray, identify $M$ nearest neighbors $\{q'_m\}_{m=1}^M$ along the ray. The sources specify grouping these neighbors into three sets based on distance to $q_n$:
    *   Group 1: $M_1 = 10$ nearest neighbors.
    *   Group 2: $M_2 = 20$ next nearest neighbors.
    *   Group 3: $M_3 = 30$ furthest neighbors.
    *   Total $M = M_1 + M_2 + M_3 = 60$ [S1].
2.  **Feature Construction:** For each neighbor $q'_m$, compute:
    *   Unsigned distance: $u'_m = f_{u_{gt}}(q'_m)$ (during prior training) or $f_u(q'_m)$ (during generalization).
    *   Sampling interval: $\delta_m$, the distance between $q'_m$ and its adjacent neighbor along the ray.
3.  **Network Architecture $f_w$:**
    *   **Feature Extraction:** Three separate Multi-Layer Perceptrons (MLPs), denoted $f_{w1}$, process the concatenated features (distances + intervals) for each of the three groups. These MLPs have **non-shared** parameters [S1].
    *   **Feature Fusion:** The output feature vectors from the three $f_{w1}$ networks are summed element-wise.
    *   **Density Prediction:** The summed features are passed to a final MLP $f_{w2}$ with skip connections to predict the opaque density $\sigma_n$ [S1].

### Numbered Steps

#### Phase 1: Prior Training
1.  **Generate Ground Truth UDFs:** For each training shape $S_h$, compute the ground truth unsigned distance field $f_{u_{gt}}$ [S1].
2.  **Render Reference Depth:** For each shape $S_h$, render $A=100$ depth images $\{D^h_a\}_{a=1}^A$ from random view angles using $f_{u_{gt}}$ and the standard volume rendering integral [S1].
3.  **Compute Opaque Density:** For each pixel in the rendered images, shoot a ray. Sample $N=128$ points hierarchically [S1]. For each query point $q_n$:
    *   Find $M$ nearest neighbors $\{q'_m\}$ along the ray.
    *   Retrieve ground truth distances $f_{u_{gt}}(q'_m)$ and intervals $\delta_m$.
    *   Compute $\sigma_n = f_w(\{\delta_m\}, \{f_{u_{gt}}(q'_m)\})$ using the current network $f_w$ [S1].
4.  **Render Predicted Depth:** Accumulate weights $w_n = \sigma_n \prod_{n'=1}^{n-1} (1 - \sigma_{n'})$ and compute predicted depth $\tilde{D}^h_a = \sum w_{n'} d_{n'}$ [S1].
5.  **Optimize $f_w$:** Minimize the L2 error between predicted and ground truth depth:
    $$ \mathcal{L}_{\theta_w} = \sum_{h=1}^H \sum_{a=1}^A \| D^h_a - \tilde{D}^h_a \|_2^2 $$
    Update parameters $\theta_w$ of $f_w$ [S1].
    *   *Note:* RGB images are **not** used in this phase to avoid reducing generalization ability [S1].

#### Phase 2: Generalization (Unseen Scene)
1.  **Freeze $f_w$:** Fix parameters $\theta_w$ obtained from Phase 1 [S1].
2.  **Initialize UDF:** Initialize a UDF field $f_u$ (e.g., spherical initialization) and a color network $f_c$ [S1].
3.  **Ray Sampling:** For each training view $I_j$, shoot rays. Sample $N=128$ points $\{q_n\}$ along each ray using hierarchical sampling [S1].
4.  **Compute Opaque Density:** For each query $q_n$:
    *   Find $M$ nearest neighbors $\{q'_m\}$ along the ray.
    *   Compute current distances $f_u(q'_m)$ and intervals $\delta_m$.
    *   Compute $\sigma_n = f_w(\{\delta_m\}, \{f_u(q'_m)\})$ using the frozen $f_w$ [S1].
5.  **Volume Rendering:**
    *   Compute weights: $w_n = \sigma_n \prod_{n'=1}^{n-1} (1 - \sigma_{n'})$ [S1].
    *   Compute rendered color: $I'_j = \sum_{n'=1}^N w_{n'} f_c(q_{n'})$ [S1].
    *   Compute rendered depth: $D'_j = \sum_{n'=1}^N w_{n'} d_{n'}$ [S1].
6.  **Optimize Scene:** Minimize the total loss:
    $$ \mathcal{L} = \mathcal{L}_{rgb} + \lambda \mathcal{L}_e $$
    Where $\mathcal{L}_{rgb} = \sum_{j=1}^J \| I_j - I'_j \|$ and $\mathcal{L}_e$ is the Eikonal loss [S1].
    *   Update $f_u$ and $f_c$.
7.  **Surface Extraction:** Extract the zero-level set of the optimized $f_u$ as the mesh surface (e.g., using Marching Cubes) [S1].

### Formulas
*   **Opaque Density:**
    $$ \sigma_n = f_w(\{\delta_m\}_{m=1}^M, \{f_u(q'_m)\}_{m=1}^M) $$
    Where $q'_m \in NN(q_n)$ are the $M$ nearest neighbors of $q_n$ along the ray, and $\delta_m$ is the sampling interval [S1].
*   **Weight Calculation:**
    $$ w_n = \sigma_n \times \prod_{n'=1}^{n-1} (1 - \sigma_{n'}) $$
    Where $\sigma_{n'}$ is the opaque density at the $n'$-th sample [S1].
*   **Rendered Color:**
    $$ I' = \sum_{n'=1}^N w_{n'} \times f_c(q_{n'}) $$
    Where $f_c(q_{n'})$ is the predicted color at sample $n'$ [S1].
*   **Rendered Depth:**
    $$ D' = \sum_{n'=1}^N w_{n'} \times d_{n'} $$
    Where $d_{n'}$ is the depth of sample $n'$ [S1].
*   **Prior Training Loss:**
    $$ \min_{\theta_w} \sum_{h=1}^H \sum_{a=1}^A \| D^h_a - \tilde{D}^h_a \|_2^2 $$
    Where $H$ is the number of training shapes, $A=100$ is views per shape, $D^h_a$ is ground truth depth, and $\tilde{D}^h_a$ is rendered depth [S1].
*   **Generalization Loss:**
    $$ \mathcal{L} = \mathcal{L}_{rgb} + \lambda \mathcal{L}_e $$
    Where $\lambda = 0.1$ [S1].

### Parameters
*   $N=128$: Number of hierarchical samples along each ray [S1].
*   $A=100$: Number of ground truth depth images rendered per shape during prior training [S1].
*   $M_1=10, M_2=20, M_3=30$: Sizes of the three neighbor groups [S1].
*   $\lambda=0.1$: Weight for the Eikonal loss [S1].

### Edge Cases and Pitfalls
*   **RGB in Prior Training:** Using RGB images during the prior training phase reduces the generalization ability of the learned prior. The prior should only be trained on depth errors to learn the UDF-to-density mapping [S1].
*   **Small Receptive Fields:** Handcrafted equations using only $M=2$ neighbors are biased at ray-surface intersections and sensitive to unsigned distance outliers because they lack 3D awareness [S1]. VRPrior mitigates this by using $M=60$ neighbors across multiple scales.
*   **Precision:** The method relies on accurate neighbor search along the ray. Hierarchical sampling is used to mitigate bias in non-intersection regions [S1].

class VRPriorNetwork(nn.Module):
    """
    The neural network f_w that maps neighbor distances and intervals to opaque density.
    """
    def __init__(self, input_dim=2, hidden_dim=64, output_dim=1):
        super(VRPriorNetwork, self).__init__()
        # Three separate MLPs for the three neighbor groups (M1=10, M2=20, M3=30)
        # Input: concatenated [distances, intervals]
        # Note: The exact hidden layers are not specified, assuming standard MLP structure
        self.fw1_group1 = self._build_mlp(input_dim, hidden_dim)
        self.fw1_group2 = self._build_mlp(input_dim, hidden_dim)
        self.fw1_group3 = self._build_mlp(input_dim, hidden_dim)
        
        # Final MLP with skip connections
        # Input: sum of features from group1, group2, group3
        self.fw2 = self._build_mlp_with_skip(hidden_dim, output_dim)

    def _build_mlp(self, input_dim, hidden_dim):
        # Simplified MLP structure
        return nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU()
        )

    def _build_mlp_with_skip(self, input_dim, output_dim):
        return nn.Sequential(
            nn.Linear(input_dim, input_dim), # Skip connection implies adding input to hidden

        """

        Actually, the input is grouped. Let's assume inputs are pre-grouped.
        distances: (B, M1), (B, M2), (B, M3)
        intervals: (B, M1), (B, M2), (B, M3)

        feat3 = self.fw1_group3(cat3)
        
        # Sum features
        summed_feats = feat1 + feat2 + feat3
        
        # Final prediction
        sigma = self.fw2(summed_feats)
        return sigma

    neighbor_udfs = udf_field(neighbor_points)

    # Split neighbors into groups

def volume_render(query_points, colors, sigma, ray_origins, ray_directions):
    """
    Standard volume rendering accumulation.
    """
    N = query_points.shape[0]
    
    # Compute weights
    # w_n = sigma_n * prod_{n'=1}^{n-1} (1 - sigma_{n'})
    # This is typically done with cumulative products for efficiency
    
    alphas = 1.0 - sigma
    # Cumulative product of (1 - sigma)
    # Note: sigma is opaque density, so (1-sigma) is transmittance
    transmittance = torch.cumprod(alphas, dim=0)
    # Shift transmittance by 1 step for w_n calculation
    # w_n = sigma_n * T_{n-1}
    # T_0 = 1.0
    T_shifted = torch.cat([torch.ones_like(transmittance[:, :1]), transmittance[:, :-1]], dim=1)
    
    weights = sigma * T_shifted
    
    # Render Color
    rendered_color = torch.sum(weights * colors, dim=0)
    
    # Render Depth
    # d_n is the depth of query point n along the ray
    depths = torch.sum(weights * query_points, dim=0) # Assuming query_points are depths
    
    return rendered_color, depths

## Operating characteristics
*   **Time Complexity:** The prior training phase requires rendering $A=100$ views for $H$ shapes, which is computationally expensive but done once. The generalization phase has similar complexity to standard NeRF but with the overhead of neighbor search ($M=60$) and the forward pass of $f_w$ for every sample.
*   **Memory Complexity:** Requires storing the UDF field, color network, and the parameters of $f_w$. The neighbor search may require efficient spatial data structures if not ray-based.
*   **Strengths:** Robust to unsigned distance outliers; 3D aware due to multi-scale neighbor aggregation; better generalization to unseen scenes compared to handcrafted functions.
*   **Limitations:** Requires ground truth meshes for prior training; sensitive to the quality of neighbor search; may be slower than handcrafted methods due to neural network inference.
*   **When to use:** When dealing with unsigned distance fields and needing robust density estimation that generalizes across different shapes and surface complexities.
*   **When not to use:** When ground truth meshes are unavailable for prior training; when computational resources are extremely limited and neural network inference is prohibitive.

## Background
VRPrior was introduced in the paper "VRP-UDF: Toward Unbiased Learning of Unsigned Distance Functions From Multi-View Images With Volume Rendering Priors" [S1]. It addresses the limitations of previous methods like NeUDF and 2S-UDF, which used handcrafted equations with small receptive fields (M=2) that were biased at ray-surface intersections and sensitive to outliers [S1]. The method builds on the idea of learnable neural rendering frameworks [S1].
