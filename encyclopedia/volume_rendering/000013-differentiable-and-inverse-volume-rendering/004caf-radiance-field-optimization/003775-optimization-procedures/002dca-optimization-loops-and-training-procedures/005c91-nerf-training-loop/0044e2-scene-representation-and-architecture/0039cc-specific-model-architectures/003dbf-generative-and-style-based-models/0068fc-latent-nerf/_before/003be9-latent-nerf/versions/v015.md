# Latent-NeRF


## Overview
Latent-NeRF is a method for optimizing Neural Radiance Fields (NeRF) by mapping scene geometry and appearance into a compact latent space, which is then refined using a pre-trained 2D latent diffusion model [S1, S2]. It solves the problem of low-frequency artifacts and lack of high-frequency detail in standard NeRF training by leveraging the generative priors of diffusion models [S1, S2]. Unlike standard NeRF, which predicts RGB colors directly, Latent-NeRF predicts pseudo-color channels corresponding to latent features, allowing the use of powerful 2D image priors for 3D consistency [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D position $\mathbf{x}$, viewing direction $\mathbf{d}$, and optional text/shape guidance conditions.
*   **Output:** Volume density $\sigma$ and a feature map $\mathbf{z}$ in a compact latent space (specifically 4 channels for the specific implementation cited) [S1, S2].

**Data Structures:**
*   **NeRF MLP:** A Multi-Layer Perceptron that takes encoded position $\gamma(\mathbf{x})$ and direction $\mathbf{d}$ as input.
*   **Latent Space:** The output of the NeRF MLP is a 4-channel feature map $\mathbf{z}$ (pseudo-colors) [S2]. This corresponds to the latent features used by the Stable Diffusion model [S1, S2].
*   **Diffusion Model:** A pre-trained Stable Diffusion model [S1] or similar latent diffusion model [S2] used for score distillation.

**Numbered Steps:**
1.  **NeRF Forward Pass:** For a given ray, sample points $\mathbf{x}_i$ and directions $\mathbf{d}_i$. The NeRF MLP predicts density $\sigma_i$ and a 4-channel latent feature vector $\mathbf{z}_i$ [S2].
2.  **Volumetric Rendering:** Render the latent feature map $\mathbf{z}$ from the viewpoint using standard volumetric rendering integration [S2]:
    $$
    \mathbf{z}(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i \mathbf{z}_i, \quad \text{where } \alpha_i = 1 - \exp(-\sigma_i \delta_i), \quad T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)
    $$
    This produces a 2D feature map $\mathbf{z}$ for the current view [S2].
3.  **Noise Addition:** Add noise to the rendered feature map $\mathbf{z}$ to generate a noisy latent image $\mathbf{z}_t$ [S2].
4.  **Diffusion Denoising:** Use the pre-trained Stable Diffusion model to denoise $\mathbf{z}_t$ back to $\mathbf{z}_0$, guided by text prompts and/or shape constraints [S1, S2].
5.  **Score Distillation Sampling (SDS):** Compute the gradient of the diffusion model's denoising prediction with respect to the noisy latent $\mathbf{z}_t$ [S2].
6.  **Backpropagation:** Backpropagate the denoising loss through the volumetric rendering equation to update the NeRF MLP weights [S2].

**Formulas:**
*   **Latent Rendering:** The rendered latent map $\mathbf{z}$ is computed as a weighted sum of per-sample latent features $\mathbf{z}_i$, where weights are determined by transmittance $T_i$ and opacity $\alpha_i$ [S2].
*   **Guidance:** The method supports text guidance and shape guidance for refinement or strict constraints [S1].

**Parameters:**
*   **Latent Channels:** 4 channels are used in the cited implementation to match the input of the diffusion model [S1, S2].
*   **Resolution:** The NeRF outputs 64x64 latent features, which are then decoded by the diffusion model to 512x512 RGB images [S1].

**Edge Cases and Pitfalls:**
*   **Resolution Mismatch:** Naive 2D super-resolution leads to inconsistent details across views; Latent-NeRF avoids this by operating in the latent space before diffusion decoding [S1].
*   **3D Consistency:** Without proper distillation, 2D diffusion priors may introduce view-inconsistent artifacts. The iterative nature of the optimization helps align 3D details [S1].

## Subtopics

### Points2NeRF
Points2NeRF generates NeRF representations directly from 3D point clouds using a hypernetwork-based auto-encoder [S1]. It solves the problem of reconstructing high-quality radiance fields from sparse 3D input by learning a mapping from point clouds to NeRF weights, rather than optimizing per-object parameters [S1]. Unlike standard NeRF, it trains a single hypernetwork to produce weights for any input point cloud, enabling generation at test time [S1].

### [NeRF as an Auto-Decoder](12795-nerf-as-an-auto-decoder.md)
NeRF as an Auto-Decoder generalizes single-scene NeRF fitting to multi-scene optimization by sharing network parameters across scenes while maintaining per-scene latent codes. It treats the plenoptic function as a decoder and scene-specific codes as latent variables with Gaussian priors, enabling joint learning of a code bank and shared weights. This allows unconditional 3D generation and single-view reconstruction, unlike standard NeRF which requires per-scene optimization.

### [DLR-NeRF Construction](18172-dlr-nerf-construction.md)
DLR-NeRF Construction is a network distillation method that transforms a low-rank NeRF (LR-NeRF) into a distilled, slimmer network (DLR-NeRF) by decomposing weight tensors into Tensor Train (TT) components. It solves the problem of preserving low-rank properties during weight quantization, which would otherwise break the rank constraint during fine-tuning. It acts as a bridge between low-rank approximation and quantization, ensuring the distilled network maintains structural benefits while enabling efficient compression.

### DiSR-NeRF
DiSR-NeRF generates high-fidelity, super-resolved NeRFs without requiring high-resolution training data [S1]. It differs from naive 2D super-resolution, which leads to inconsistent details across views [S1]. It introduces Iterative 3D Synchronization (I3DS), which alternates between 2D diffusion-based super-resolution and NeRF training to progressively align details in 3D space [S1]. It also uses Renoised Score Distillation (RSD), which refines the diffusion process by optimizing over intermediate denoised latents to produce sharper and more consistent results [S1].

### Pix2NeRF
Pix2NeRF uses a loss function that includes the $\pi$-GAN loss plus: 1) Reconstruction loss comparing predicted and sampled latent features $z$ to ensure latent space consistency, 2) Reconstruction loss ensuring image reconstruction quality between real images $I_{real}$ and reconstructed images $I_{reconstructed}$ (generated from predicted $z_{pred}, d_{pred}$), and 3) A conditional adversarial objective to prevent mode collapse towards trivial poses [S1].

### MEIL-NeRF and CLNeRF adaptation
These are adaptations of single-scene continual learning NeRF methods for multiple scenes by adding a scene-specific latent code [S3]. The scene-specific latent code dimension is 32 [S3].

## Operating characteristics
*   **Time Complexity:** Training is slower than standard NeRF due to the iterative denoising steps and backpropagation through the diffusion model [S2].
*   **Memory Complexity:** Requires storing the pre-trained diffusion model weights in addition to the NeRF parameters [S2].
*   **Performance:** Achieves high-fidelity, 512x512 RGB images from 64x64 latent features [S1]. Outperforms DS-NeRF, PixelNeRF, and DietNeRF on NeRF Synthetic, DTU, and LLFF datasets [S1].
*   **Strengths:** Enables text-guided and shape-guided 3D generation; produces high-frequency details not present in low-resolution training data [S1, S2].
*   **Limitations:** Computationally expensive due to diffusion model usage; requires careful tuning of guidance strength [S1, S2].

## Background
Latent-NeRF was introduced in November 2022 [S1]. It was inspired by advances in generative 2D computer vision, specifically the use of latent diffusion models like Stable Diffusion [S1, S2]. It is the first approach to allow coloring of a grid under the guidance of a pre-trained diffusion model, achieving impressive results in novel view synthesis [S2]. It builds upon the concept of score distillation sampling (SDS) introduced in DreamFusion [S1].
