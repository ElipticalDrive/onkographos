# NeRF-SR

Also called: NeRF-SR Refinement, NeRF-SR: High-Quality Neural Radiance Fields using Supersampling, Patch-Based Refinement

## Overview
NeRF-SR is a super-resolution method that attacks the problem by deterministic supersampling that enforces sub-pixel multi-view consistency and by a depth guided patch warp and refine network that reuses one high-resolution reference image [S1, S2]. It solves the problem of generating high-resolution novel views from mostly low-resolution inputs by exploiting the 3D consistency of NeRF, where an observed pixel absorbs information from nearby views [S2]. Unlike Super-NeRF which couples NeRF with a GAN based 2D super-resolution backbone, NeRF-SR stays closer to classical supersampling and patch based refinement [S1]. Unlike Mip-NeRF which only considers rendering with downsampled resolutions, NeRF-SR studies how to increase the resolution of NeRF [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Posed multi-view low-resolution images of the target scene; one high-resolution reference image ($I_{REF}$) [S2].
*   **Outputs:** High-resolution synthesized images ($I_n$) and depth maps for novel viewpoints [S2].

**Data Structures:**
*   **NeRF Model:** A multi-layer perceptron (MLP) predicting per-point density $\sigma(\mathbf{x})$ and color $c(\mathbf{x}, \mathbf{d}) = (r, g, b)$ given 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$ [S2].
*   **Refinement Network:** A U-Net based convolutional network [S2].
    *   **Encoder:** Consists of seven convolutional layers followed by ReLU activation [S2].
    *   **Decoder:** Takes as input the nearest-neighbor upsampled features from previous layers concatenated with both the encoded features of the input SR patch and max-pooled features of reference patches [S2]. All convolutional layers are followed by a ReLU activation [S2].

**Parameters:**
*   **Supersampling Rays:** Multiple rays are shot per pixel. The exact number is not specified in the sources [G: Typically 4-16 rays per pixel in supersampling contexts, but NeRF-SR sources do not specify].
*   **Reference Patches ($K$):** Number of reference patches sampled within a fixed window around the projected location. The exact value of $K$ is not specified in the sources [G: The text mentions "sample K reference patches", but does not give a number].
*   **Loss Weights ($\lambda_l$):** Reciprocal of the number of neurons in layer $l$ of the pretrained VGG-19 network [S2].

**Numbered Steps:**

1.  **NeRF Training with Supersampling:**
    Train the base NeRF using the low-resolution input images. During rendering for supervision, shoot multiple rays at each image pixel to enforce multi-view constraints at a sub-pixel level [S2].
    *   **Supervision:** Compare the average color of sub-pixels, referred to as 'average kernel' [S2]. Note: The sources mention that while the method assumes an "average kernel" degradation, the actual Blender dataset uses Lanczos downsampling, which is asymmetric. Using a symmetric average kernel for degradation simulation improves results (e.g., PSNR 30.94 vs 29.77 for Blender $\times 2$ at 100x100) [S2].

2.  **Depth Estimation:**
    Render the estimated depth map $d_{i,j}$ for the target view using the trained NeRF [S2].

3.  **Reference Patch Extraction (Testing/Inference):**
    For each pixel $(i,j)$ in the synthesized SR patch $P_e$:
    a. Compute its 3D world coordinate using the estimated depth $d_{i,j}$ and camera parameters [S2].
    b. Backproject this 3D coordinate to the high-resolution reference image $I_{REF}$ to find the corresponding pixel location [S2].
    c. Extract patches around this location to form a set of reference patches $\{P_{REF}^k\}_{k=1}^K$ [S2].
    d. Points falling out of $I_{REF}$ are discarded [S2].
    The transformation between camera extrinsic matrices from the target view $I_n$ to $I_{REF}$ is denoted as $T$, and $K_{REF}$ and $K_n$ refer to the camera intrinsic matrices [S2].

4.  **Patch Refinement:**
    For each SR patch $P_e$:
    a. Encode $P_e$ and each reference patch $P_{REF}^k$ respectively using the encoder (7 conv layers + ReLU) [S2].
    b. The decoder generates the refined patch $P$ from the concatenated features (nearest-neighbor upsampled features, encoded $P_e$, and max-pooled features of $\{P_{REF}^k\}$) [S2].
    c. The refinement stage is efficient and introduces negligible running time compared with NeRF rendering [S2].

**Pseudocode:**

import torch
import torch.nn as nn
import torch.nn.functional as F

class RefinementEncoder(nn.Module):
    """Encoder consisting of seven convolutional layers followed by ReLU."""
    def __init__(self):
        super().__init__()
        # Implementation detail: 7 conv layers. 
        # Exact channel dimensions are not specified in sources [G: Standard U-Net encoder structure assumed, e.g., 64, 128, 256...]
        self.conv1 = nn.Conv2d(3, 64, 3, padding=1)
        self.conv2 = nn.Conv2d(64, 64, 3, padding=1)
        self.conv3 = nn.Conv2d(64, 128, 3, padding=1)
        self.conv4 = nn.Conv2d(128, 128, 3, padding=1)
        self.conv5 = nn.Conv2d(128, 256, 3, padding=1)
        self.conv6 = nn.Conv2d(256, 256, 3, padding=1)
        self.conv7 = nn.Conv2d(256, 256, 3, padding=1)
        
    def forward(self, x):
        x = F.relu(self.conv1(x))
        x = F.relu(self.conv2(x))
        x = F.relu(self.conv3(x))
        x = F.relu(self.conv4(x))
        x = F.relu(self.conv5(x))
        x = F.relu(self.conv6(x))
        x = F.relu(self.conv7(x))
        return x

class RefinementDecoder(nn.Module):
    """Decoder that generates refined patch from concatenated features."""
    def __init__(self):
        super().__init__()
        # Implementation detail: Decoder layers not fully specified [G: Standard upsampling conv layers]
        self.conv_out = nn.Conv2d(256, 3, 3, padding=1) # Output 3 channels (RGB)
        
    def forward(self, features):
        # features: concatenated encoded features
        x = F.relu(self.conv_out(features))
        return x

class RefinementNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.encoder = RefinementEncoder()
        self.decoder = RefinementDecoder()
        
    def forward(self, P_e, P_REF_list):
        """
        P_e: SR patch tensor [B, 3, H, W]
        P_REF_list: List of reference patch tensors [B, K, 3, H, W]
        """
        # Encode SR patch
        feat_e = self.encoder(P_e)
        
        # Encode reference patches and pool
        ref_feats = []
        for P_ref in P_REF_list:
            feat_ref = self.encoder(P_ref)
            # Max pool at the same spatial resolution
            pooled_ref = F.max_pool2d(feat_ref, kernel_size=feat_ref.shape[2])
            ref_feats.append(pooled_ref)
            
        # Concatenate features
        # Note: Source says "concatenated with both the encoded features of P_e and max pooled features of P_REF"
        # Assuming concatenation along channel dimension
        combined = torch.cat([feat_e] + ref_feats, dim=1)
        
        # Decode
        refined_patch = self.decoder(combined)
        return refined_patch

    P: HR patch from I_REF at the same location
    K: Number of reference patches to sample
    window_size: Fixed window around P to sample reference patches
    """
    # Sample K reference patches within a fixed window around P
    P_REF_list = []
    for k in range(K):
        # Sample patch from I_REF within window around P
        # Implementation detail: Exact sampling logic for window not specified [G: Random crop within window]
        P_ref = sample_patch_from_reference(P, window_size)
        P_REF_list.append(P_ref)
        
    # Perform perspective transformations on P_e and P as during testing
    # (To account for different camera poses)
    P_e_transformed = perspective_transform(P_e)
    P_transformed = perspective_transform(P)
    
    # Forward pass
    P_refined = model(P_e_transformed, P_REF_list)
    
    # Loss function: L_refine = L_rec + L_per
    # L_rec = ||P_e - P||_1
    # L_per = sum_l lambda_l ||phi_l(P) - phi_l(P_refined)||_1
    # phi_l is a set of layers in a pretrained VGG-19
    # lambda_l is the reciprocal of the number of neurons in layer l
    
    loss_rec = torch.mean(torch.abs(P_refined - P_transformed))
    
    # Perceptual loss calculation
    loss_per = 0
    phi_layers = get_vgg19_layers()
    for l, phi_l in enumerate(phi_layers):
        lambda_l = 1.0 / phi_l.num_neurons # Not given in sources, assumed definition
        loss_per += lambda_l * torch.mean(torch.abs(phi_l(P_refined) - phi_l(P_transformed)))
        
    loss = loss_rec + loss_per
    return loss

    # Volume rendering to get pixel color

    # Supervision: Compare average color of sub-pixels (average kernel)
    # Implementation detail: The exact "average kernel" comparison is not defined as a standard loss [G: Likely comparing rendered sub-pixel averages to downsampled ground truth]
    return pixel_colors

def refine_patch(nerf_model, I_REF, camera_params, P_e, K):
    """
    Refine a single SR patch using the reference image.
    """
    # Get depth map from NeRF
    depth_map = nerf_model.render_depth(camera_params)
    
    # Extract reference patches
    P_REF_list = []
    for i, j in pixel_locations(P_e):
        # Compute 3D world coordinate
        x_3d = backproject(depth_map[i, j], camera_params)
        
        # Backproject to I_REF
        uv_ref = project_to_reference(x_3d, camera_params, I_REF)
        
        # Extract patch around uv_ref
        if uv_ref is within I_REF bounds:
            P_ref = extract_patch(I_REF, uv_ref)
            P_REF_list.append(P_ref)
            
    # Refine
    P_refined = RefinementNetwork(P_e, P_REF_list)
    return P_refined

**Edge Cases and Pitfalls:**
*   **Arbitrary Scale:** The method does not support arbitrary-scale super-resolution [S2].
*   **Reference Out of Bounds:** Points falling out of $I_{REF}$ during backprojection are discarded [S2].
*   **Degradation Kernel:** The method assumes an "average kernel" degradation for supervision, but real datasets (like Blender) use Lanczos. Using the correct kernel (symmetric average) improves results [S2].
*   **Training Data:** Training data for the refinement network is only available at the camera pose of $I_{REF}$, requiring perspective transformations during training to generalize to other views [S2].

## Operating characteristics
*   **Time Complexity:** The refinement stage is efficient and introduces negligible running time compared with NeRF rendering [S2].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:**
    *   **Blender $\times 2$ (100x100):** PSNR 29.77, SSIM 0.946, LPIPS 0.045 [S2].
    *   **Blender $\times 4$ (100x100):** PSNR 28.07, SSIM 0.921, LPIPS 0.071 [S2].
    *   **Blender $\times 2$ (200x200):** PSNR 31.00, SSIM 0.952, LPIPS 0.038 [S2].
    *   **Blender $\times 4$ (200x200):** PSNR 28.46, SSIM 0.921, LPIPS 0.076 [S2].
    *   **LLFF $\times 2$:** PSNR 27.31, SSIM 0.838, LPIPS 0.139 [S2].
    *   **LLFF $\times 4$:** PSNR 25.13, SSIM 0.730, LPIPS 0.244 [S2].
*   **Scaling:** Not given in the sources.
*   **Strengths:** Generates high-quality results for novel view synthesis at HR on both synthetic and real-world datasets without any external information [S2]. Outperforms baselines that require LR-HR pairs for training [S2]. Works even with only one HR reference [S2].
*   **Limitations:** Does not enjoy the nice arbitrary-scale property [S2]. Requires at least one HR reference image [S2].

## Background
*   **Origin:** NeRF-SR was presented by Wang et al. from Tsinghua University and Kuaishou Technology [S2].
*   **Paper:** "NeRF-SR: High-Quality Neural Radiance Fields using Supersampling" published in ACM Multimedia (MM '22), October 10–14, 2022, Lisboa, Portugal [S2].
*   **History:** It is the first framework that produces decent multi-view super-resolution results with mostly LR input images [S2].
*   **Usage:** Used for high-resolution novel view synthesis, particularly in VR and AR applications [S2].
