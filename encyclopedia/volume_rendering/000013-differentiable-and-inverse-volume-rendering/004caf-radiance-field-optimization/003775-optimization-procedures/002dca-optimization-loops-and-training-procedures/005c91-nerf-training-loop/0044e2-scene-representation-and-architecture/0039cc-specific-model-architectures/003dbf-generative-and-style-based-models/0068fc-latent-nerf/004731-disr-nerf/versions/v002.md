# DiSR-NeRF
## Overview
DiSR-NeRF is a method for generating high-fidelity, super-resolved Neural Radiance Fields (NeRFs) from low-resolution multi-view images without requiring high-resolution training data [S1]. It addresses the view-inconsistent details inherent in naive 2D super-resolution by alternating between diffusion-based super-resolution and NeRF training [S1].
## How it works
**Inputs:** Low-resolution multi-view images [S1].
**Outputs:** A high-resolution NeRF representation [S1].

**Data Structures:**
*   **NeRF:** Multi-layer perceptron mapping 3D coordinates and viewing directions to volume density and RGB color [G].
*   **Latent Diffusion Model:** Pre-trained autoencoder with encoder $E$, decoder $D$, and noise prediction model $\epsilon_\theta$ [G].
*   **Latents:** Compressed image representations $z = E(x)$ [G].

**Parameters:**
*   Iteration count for the alternating loop (Not given in the sources [G]).
*   Noise schedule for the diffusion process (Not given in the sources [G]).

**Steps:**
1.  **Iterative 3D Synchronization (I3DS):** The method alternates between two phases to progressively align details in 3D space [S1]:
    *   **2D Diffusion-based Super-Resolution:** Apply super-resolution to the LR images using the diffusion model to generate plausible HR textures [S1].
    *   **NeRF Training:** Train the NeRF to fit the super-resolved images [S1].
2.  **Renoised Score Distillation (RSD):** To refine the diffusion process and produce sharper, more consistent results, RSD optimizes over intermediate denoised latents [S1]. This involves:
    *   Sampling noise and adding it to the latent [G].
    *   Predicting the noise or score using the diffusion model [G].
    *   Updating the NeRF parameters based on the gradient of the distillation loss computed from these intermediate states [G].

**Formulas:**
Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Inconsistency:** Naive 2D super-resolution leads to inconsistent details across views [S1]. DiSR-NeRF mitigates this via I3DS and RSD [S1].
*   **Data Requirement:** Does not require high-resolution training data [S1].

**Pseudocode:**
```python
def DiSR_NeRF(lr_images, camera_poses, num_iterations, learning_rate):
    # Initialize NeRF MLP parameters [G]
    nerf = MLP()
    # Pre-trained diffusion model components [G]
    encoder = AutoencoderEncoder()
    decoder = AutoencoderDecoder()
    noise_model = NoisePredictor()
    
    for step in range(num_iterations):
        # I3DS Phase 1: 2D Diffusion-based Super-Resolution
        z_lr = encoder(lr_images)
        # Apply diffusion step to generate HR latents [G]
        z_hr = diffusion_step(z_lr, noise_model)
        hr_images = decoder(z_hr)
        
        # I3DS Phase 2: NeRF Training
        rendered = volume_render(nerf, camera_poses)
        loss = sum((rendered - hr_images) ** 2) / len(rendered)
        nerf.update(learning_rate * gradient(loss, nerf))
        
        # RSD Refinement: Optimize over intermediate denoised latents [S1]
        # Sample noise and add to latent [G]
        z_noisy = z_hr + random_noise()
        # Predict noise using diffusion model [G]
        noise_pred = noise_model(z_noisy, step)
        # Compute distillation loss gradient w.r.t NeRF [G]
        rsd_loss = distillation_loss(rendered, noise_pred, encoder, decoder)
        nerf.update(learning_rate * gradient(rsd_loss, nerf))
    return nerf
```
## Subtopics

### Super-NeRF
Super-NeRF is a super-resolution method that couples NeRF with a GAN-based 2D super-resolution backbone and per-view latent codes [S1]. It explicitly searches the latent space of a powerful SR prior to generate plausible yet view-consistent details [S1]. It jointly optimizes a high-resolution NeRF that is supervised only through the downsampled consistency constraint [S1]. This contrasts with DiSR-NeRF's diffusion-based approach and NeRF-SR's classical supersampling and patch-based refinement [S1].

**Measured Performance:**
DiSR-NeRF outperforms existing methods in generating high-fidelity, super-resolved NeRFs [S1].

**Strengths and Limitations:**
*   **Strengths:** Generates high-fidelity, super-resolved NeRFs without needing high-resolution training data [S1]. Produces sharper and more consistent results than naive 2D super-resolution [S1].
*   **Limitations:** Relies on a pre-trained diffusion model, which may introduce artifacts if the prior is mismatched [G].

**When to Use:**
Use when high-resolution training data is unavailable and view-consistent super-resolution is required [S1].
## Background
DiSR-NeRF was introduced in April 2024 [S1]. It addresses the challenge of generating high-resolution, view-consistent NeRFs from only low-resolution multi-view images, which is a common practice due to computational costs [S1]. It builds on the concept of using generative priors for NeRF super-resolution, differing from earlier methods like Super-NeRF (April 2023) which used GANs [S1].
