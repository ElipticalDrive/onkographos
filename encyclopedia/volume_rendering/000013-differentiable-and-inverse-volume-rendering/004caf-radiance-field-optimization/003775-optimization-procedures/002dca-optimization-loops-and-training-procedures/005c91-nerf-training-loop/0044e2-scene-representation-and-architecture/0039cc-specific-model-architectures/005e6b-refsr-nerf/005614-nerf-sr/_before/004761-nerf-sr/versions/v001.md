# NeRF-SR

Also called: NeRF-SR Refinement, Patch-Based Refinement

## Overview
NeRF-SR is a super-resolution method for Neural Radiance Fields that recovers high-frequency details by combining deterministic supersampling with a depth-guided patch-based refinement network [S1, S2]. It solves the problem of blurry NeRF outputs by reusing a single high-resolution reference image to inject observed textures into the synthesized image, rather than relying on generative priors [S1, S2]. Unlike Super-NeRF, which couples NeRF with a GAN-based backbone and latent codes, NeRF-SR stays closer to classical supersampling and explicit patch-based refinement [S1].

## How it works
**Inputs:**
- A coarse NeRF model $\mathcal{N}$ trained on low-resolution input images.
- A single high-resolution reference image $I_{REF}$ with known camera intrinsics $K_{REF}$ and extrinsics $T_{REF}$.
- A target camera pose with intrinsics $K_n$ and extrinsics $T_n$ for which a super-resolved image $I_n$ is to be synthesized.
- Estimated depth map $d$ for the target view (obtained from the coarse NeRF).

**Outputs:**
- A super-resolved image $I_n$ with high-frequency details blended from $I_{REF}$.

**Data Structures:**
- **Patch $P_e$**: A low-resolution (SR) patch extracted from the initial NeRF synthesis at the target pose.
- **Patch $P$**: A high-resolution patch extracted from $I_{REF}$.
- **Reference Patches $\{P_{REF}^k\}_{k=1}^K$**: A set of $K$ patches from $I_{REF}$ corresponding to the spatial location of $P_e$.

**Network Architecture:**
The refinement network is a U-Net based convolutional network [S2].
- **Encoder**: Consists of seven convolutional layers, each followed by a ReLU activation [S2].
- **Decoder**: Takes concatenated features as input. It combines nearest-neighbor upsampled features from previous layers with the encoded features of $P_e$ and the max-pooled features of $\{P_{REF}^k\}_{k=1}^K$ at the same spatial resolution [S2]. All convolutional layers in the decoder are followed by a ReLU activation [S2].

**Algorithm Steps:**

1.  **Coarse Synthesis**: Render the initial low-resolution image $I_{SR}$ using the coarse NeRF $\mathcal{N}$ at the target camera pose $(K_n, T_n)$. Obtain the associated depth map $d$ [S2].

2.  **Patch Extraction (Testing Phase)**:
    For each pixel $(i, j)$ in the patch $P_e$ of $I_{SR}$:
    a. Compute the 3D world coordinate $X_{i,j}$ using the estimated depth $d_{i,j}$ and camera parameters [S2]:
    $$ X_{i,j} = T_n^{-1} \cdot K_n^{-1} \cdot \begin{bmatrix} i \\ j \\ 1 \end{bmatrix} \cdot d_{i,j} $$
    *(Note: The source formula (7) in [S2] describes computing the 3D world coordinate based on $d_{i,j}$ and camera parameters, then backprojecting to $I_{REF}$ [S2]. The exact matrix multiplication order depends on coordinate system conventions, but the logical flow is: pixel $\to$ camera frame $\to$ world frame $\to$ reference camera frame $\to$ reference pixel.)*
    b. Transform $X_{i,j}$ to the reference camera frame using the transformation $T$ between $T_n$ and $T_{REF}$ [S2].
    c. Project to the reference image plane using $K_{REF}$ to find the corresponding pixel location in $I_{REF}$ [S2].
    d. Extract patches around this location to form the set $\{P_{REF}^k\}_{k=1}^K$ [S2]. Points falling outside the bounds of $I_{REF}$ are discarded [S2].

3.  **Refinement**:
    a. Encode $P_e$ and each $P_{REF}^k$ using the encoder [S2].
    b. Concatenate the encoded features of $P_e$ with the max-pooled features of $\{P_{REF}^k\}_{k=1}^K$ [S2].
    c. Pass the concatenated features through the decoder to generate the refined patch $P$ [S2].
    d. Assemble all refined patches to form the final super-resolved image $I_n$ [S2].

**Training Data Sampling:**
- Sample $P_e$ randomly from the SR image at the camera pose of $I_{REF}$ [S2].
- Sample $P$ from $I_{REF}$ at the same location [S2].
- Perform perspective transformations on $P_e$ and $P$ to simulate different camera poses, as testing inputs come from different poses [S2].
- Sample $K$ reference patches within a fixed window around $P$ to account for inaccuracies in reference patch alignment at test time [S2].

**Loss Function:**
The refinement network is trained using a combination of reconstruction loss and perceptual loss [S2]:
$$ L_{refine} = L_{rec} + L_{per} = ||P_e - P||_1 + \sum_l \lambda_l ||\phi_l(P) - \phi_l(P_e)||_1 $$
where $\phi_l$ is a set of layers in a pretrained VGG-19 network, and $\lambda_l$ is the reciprocal of the number of neurons in layer $l$ [S2].

**Parameters:**
- $K$: Number of reference patches sampled. Not given in the sources.
- Window size for sampling $K$ patches: Not given in the sources.
- Number of encoder layers: 7 [S2].

**Edge Cases and Pitfalls:**
- Points falling outside $I_{REF}$ are discarded [S2].
- Inaccuracy in depth estimation or camera pose alignment may require sampling multiple reference patches within a window [S2].

## Operating characteristics
- **Time Complexity**: Not given in the sources.
- **Memory Complexity**: Not given in the sources.
- **Strengths**: Works even with only one high-resolution reference image [S2]. Extra details come from propagating observed textures rather than learning a generative prior, which can be more stable than GAN-based approaches [S1].
- **Limitations**: Requires a high-resolution reference image $I_{REF}$ [S1, S2]. Performance depends on the accuracy of depth estimation and camera pose alignment for patch warping [S2].
- **When to use**: When a single high-resolution reference image is available and generative priors are undesirable or unstable [S1, S2].
- **When not to use**: When no reference image is available (consider ZS-SRT [S1]) or when multiple reference images are available and a generative approach is preferred (consider Super-NeRF [S1]).

## Background
NeRF-SR was introduced in December 2021 [S1]. It represents a shift in NeRF super-resolution from exploiting internal 3D consistency to leveraging external high-resolution references [S1]. It contrasts with Super-NeRF (April 2023), which uses GAN-based priors, and ZS-SRT (December 2023), which is zero-shot and uses no external references [S1].
