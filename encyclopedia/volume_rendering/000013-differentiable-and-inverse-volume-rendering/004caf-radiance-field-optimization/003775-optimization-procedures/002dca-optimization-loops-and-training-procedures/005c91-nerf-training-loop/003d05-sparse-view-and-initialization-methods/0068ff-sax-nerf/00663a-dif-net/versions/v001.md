# DIF-Net

Also called: Continuous Intensity Field Representation, Deep Intensity Field Network

## Overview
DIF-Net is a supervised deep learning method for sparse-view Cone-Beam CT (CBCT) reconstruction that formulates the CT volume as a continuous intensity field $g: \mathbb{R}^3 \rightarrow \mathbb{R}$, regressing the intensity value $v$ of an arbitrary 3D point $p$ from $K$ 2D projections $I$ [S1]. Unlike NeRF-based methods that require per-patient optimization, DIF-Net learns prior knowledge from a large dataset, enabling high-quality reconstruction from extremely sparse views ($\le 10$) without per-scan training [S1]. It differs from voxel-based methods by avoiding 3D CNNs for feature decoding, thereby reducing memory requirements and enabling scalable output resolutions without model retraining [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** $K$ 2D projection images $I = \{I_1, \dots, I_K\}$, where each $I_i \in \mathbb{R}^{H \times W}$. The projections correspond to scanning angles $\alpha_i$ and imaging parameters $\beta$ (distance, spacing).
*   **Outputs:** A 3D volume of intensity values $V$, where each voxel's intensity is the output of the network for its corresponding 3D coordinate.

**Data Structures:**
*   **Feature Maps:** $\{F_1, \dots, F_K\}$, where $F_i \in \mathbb{R}^{C \times H \times W}$. $C$ is the number of feature channels (default 128).
*   **Point Coordinates:** A set of 3D points $P = \{p_1, \dots, p_N\}$ in world coordinates, ranging from $(0,0,0)$ to $(s_h H, s_w W, s_d D)$.
*   **Intensity Values:** Scalar values $v \in \mathbb{R}$.

**Parameters:**
*   $K$: Number of sparse projection views. Typical value: $\le 10$.
*   $C$: Number of output feature channels in the U-Net encoder. Value: 128.
*   $N$: Number of points sampled per training iteration. Typical value: 10,000.
*   $s$: Scaling ratio for output resolution. Condition: $s > 1$.
*   Intensity Threshold: Value to distinguish foreground from background. Value: $10^{-5}$.
*   Optimizer: Stochastic Gradient Descent (SGD) with momentum 0.98 and initial learning rate 0.01.
*   Learning Rate Schedule: Decreased by a factor of $0.001^{1/400} \approx 0.9829$ per epoch.
*   Batch Size: 4.
*   Training Epochs: 400.

**Step-by-Step Method:**

1.  **Feature Extraction:**
    For each projection $I_i$, extract feature maps $F_i$ using a shared 2D encoder. The encoder is a U-Net [S1].
    $$ F_i = \text{Encoder}(I_i), \quad F_i \in \mathbb{R}^{C \times H \times W} $$

2.  **View-Specific Querying:**
    For a 3D point $p \in \mathbb{R}^3$ and view $i$ with angle $\alpha_i$ and parameters $\beta$:
    a. Compute 2D projection coordinates $p'_i \in \mathbb{R}^2$ using the projection function $\phi$:
    $$ p'_i = \phi(p, \alpha_i, \beta) $$
    The projection function $\phi$ transforms $p$ from the world coordinate system to the scanner coordinate system via rotation matrix $R(\alpha_i) \in \mathbb{R}^{4 \times 4}$, projects onto the 2D imaging panel via projection matrix $A(\beta) \in \mathbb{R}^{3 \times 4}$, and applies homogeneous division $H: \mathbb{R}^3 \rightarrow \mathbb{R}^2$ [S1]:
    $$ \phi(p, \alpha_i, \beta) = H \left( A(\beta) R(\alpha_i) \begin{bmatrix} p \\ 1 \end{bmatrix} \right) $$
    b. Query the view-specific feature $f_i \in \mathbb{R}^C$ from feature map $F_i$ via bilinear interpolation $\pi$:
    $$ f_i = \pi(F_i, p'_i) $$

3.  **Cross-View Fusion:**
    Aggregate the list of $K$ view-specific features $F(p) = \{f_1, \dots, f_K\}$ into a single vector $\bar{f} \in \mathbb{R}^C$ using a set function $\delta(\cdot)$.
    *   **Implementation (Uniform Angles):** If training and test angles are uniformly sampled (e.g., $0^\circ$ to $180^\circ$), $F(p)$ is treated as an ordered list. $\delta(\cdot)$ is implemented as a 2-layer MLP:
        $$ \bar{f} = \text{MLP}_{\text{fusion}}([f_1, \dots, f_K]) $$
        Architecture: $K \times C \rightarrow \lfloor K/2 \rfloor \times C \rightarrow 1 \times C$ (Note: The source describes the MLP structure as $K \rightarrow \lfloor K/2 \rfloor \rightarrow 1$, implying the reduction happens on the view dimension, resulting in a vector of size $C$) [S1].
    *   **Alternative (Non-Uniform Angles):** If view angles are inconsistent, use max pooling or average pooling [S1].

4.  **Intensity Regression:**
    Apply a 4-layer MLP to the fused feature $\bar{f}$ to regress the intensity value $v \in \mathbb{R}$:
    $$ v = \text{MLP}_{\text{reg}}(\bar{f}) $$
    Architecture: $C \rightarrow 2C \rightarrow \lfloor C/2 \rfloor \rightarrow \lfloor C/8 \rfloor \rightarrow 1$ [S1].

5.  **Training Sampling:**
    To handle class imbalance (background air ~62%, foreground bones/organs ~38%):
    a. Identify foreground and background areas using an intensity threshold of $10^{-5}$ via binary classification on ground truth [S1].
    b. Randomly sample $N$ points (default 10,000) from the world coordinate range $(0,0,0)$ to $(s_h H, s_w W, s_d D)$.
    c. Ensure balanced sampling: $N/2$ points from foreground and $N/2$ points from background [S1].

6.  **Loss Calculation:**
    Compute ground-truth intensity values $\hat{V} = \{\hat{v}_1, \dots, \hat{v}_N\}$ for the sampled points using trilinear interpolation from the ground-truth CT volume [S1].
    Calculate the Mean-Square-Error (MSE) loss:
    $$ L(V, \hat{V}) = \frac{1}{N} \sum_{i=1}^{N} (v_i - \hat{v}_i)^2 $$

7.  **Inference/Reconstruction:**
    a. Uniformly sample a dense point set covering all voxels. For a target resolution $H \times W \times D$, sample $H \times W \times D$ points from $(0,0,0)$ to $(s_h H, s_w W, s_d D)$ [S1].
    b. For scalable resolutions, sample $\lfloor H/s \rfloor \times \lfloor W/s \rfloor \times \lfloor D/s \rfloor$ points to generate a coarse image (speed) or $\lfloor sH \rfloor \times \lfloor sW \rfloor \times \lfloor sD \rfloor$ points for higher resolution, where $s > 1$ [S1].
    c. Input projections and points to DIF-Net to generate intensity values, reconstructing the CT volume [S1].

**Edge Cases and Pitfalls:**
*   **Class Imbalance:** Uniform sampling leads to imbalanced prediction because background (air) occupies more space than foreground (bones/organs). Using an intensity threshold of $10^{-5}$ to balance foreground and background sampling is critical [S1].
*   **Point Count:** Using fewer points (e.g., 5,000) may destabilize the loss and gradient during training, leading to performance degradation. 10,000 points are sufficient for best performance [S1].
*   **View Angle Consistency:** The MLP fusion assumes uniformly sampled angles. If view angles are inconsistent across training/test data, max pooling is a more general solution [S1].
*   **Encoder Choice:** Using a pre-trained ResNet18 encoder instead of U-Net does not bring improvement (PSNR/SSIM: 29.2/0.92 vs 29.3/0.92), indicating U-Net is powerful enough for feature extraction in this task [S1].

## Background
DIF-Net was introduced by Yiqun Lin, Zhongjin Luo, Wei Zhao, and Xiaomeng Li in 2023 [S1]. It is the first method to introduce a continuous intensity field for supervised CBCT reconstruction [S1]. It addresses the limitations of voxel-based methods (high memory, fixed resolution) and NeRF-based methods (per-patient optimization, slower inference) [S1]. The method is implemented using PyTorch on a single NVIDIA RTX 3090 GPU [S1].
