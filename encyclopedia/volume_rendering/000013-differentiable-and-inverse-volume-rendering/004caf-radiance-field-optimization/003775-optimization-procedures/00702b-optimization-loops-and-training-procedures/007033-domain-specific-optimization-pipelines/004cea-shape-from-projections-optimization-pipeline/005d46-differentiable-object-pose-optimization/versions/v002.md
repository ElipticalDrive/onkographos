# Differentiable Object Pose Optimization

Also called: Joint Pose Optimization for Objects, Object Pose Refinement via Differentiable Rendering, Refining Geometry

## Overview
This method refines the 6D pose and scale of segmented 3D objects by minimizing the discrepancy between rendered and observed image data [S1]. It addresses coarse pose initialization by optimizing object parameters directly in image space using differentiable rendering [S1]. It operates as a sub-component of the Shape-from-Projections Optimization Pipeline [S1].

## How it works
**Inputs:**
*   Segmented 3D objects with initial coarse poses and geometry [S1].
*   Target images containing segmentation masks ($M_{it}$) and depth maps ($D_t$) [S1].
*   Object pose parameters $\theta_{obj}$ for each object, comprising scaling, horizontal translation, and rotation around the vertical axis [S1].

**Outputs:**
*   Refined object poses $\theta_{obj}$ that minimize the loss function [S1].

**Data Structures:**
*   **Object Pose Parameters ($\theta_{obj}$):** Vector containing scale factor, 2D translation vector (horizontal plane), and 1D rotation angle (around vertical axis) [S1].
*   **Rendered Mask ($M_{ir}$):** Soft mask generated by the differentiable renderer [S1].
*   **Rendered Depth ($D_r$):** Depth map generated by the differentiable renderer, normalized to unit range [S1].
*   **Target Mask ($M_{it}$):** Estimated segmentation mask for the object [S1].
*   **Target Depth ($D_t$):** Estimated depth for the object, normalized to unit range [S1].

**Loss Function:**
The optimization minimizes a composite loss $L_{obj}$ defined as [S1]:

$$L_{obj} = \sum_i L1(M_{ir}(\theta_{obj}) * D_r(\theta_{obj}), M_{it} * D_t) + \sum_i L1(G(M_{ir}(\theta_{obj})), G(M_{it}))$$

Where:
*   $i$ iterates over the set of objects [S1].
*   $*$ denotes element-wise multiplication [S1].
*   $L1$ is the mean absolute error [S1].
*   $G$ is a 2D Gaussian convolution pyramid applied to the mask [S1].
*   $M_{ir}$ and $D_r$ are functions of the current pose parameters $\theta_{obj}$ [S1].

**Algorithm Steps:**
1.  **Initialize Poses:** Initialize object poses based on segmented point clouds or coarse geometry predictions [S1].
2.  **Define Constraints:**
    *   For objects on the floor/ceiling: Constrain optimization to scaling, horizontal translation, and vertical-axis rotation to preserve alignment with the room floor/ceiling [S1].
    *   For objects on walls: Constrain optimization to transformations and scaling along the wall plane [S1].
3.  **Render:** Use a differentiable renderer to generate the rendered mask $M_{ir}$ and rendered depth $D_r$ for the current object poses $\theta_{obj}$. The renderer must generate masks with anti-aliasing to ensure non-zero gradients for mask comparison losses [S1].
4.  **Compute Loss:** Calculate $L_{obj}$ using the formula above. The first term combines mask and depth errors (weighted by depth), and the second term compares blurred versions of the masks to capture structural similarity [S1].
5.  **Optimize:** Update $\theta_{obj}$ using gradient descent to minimize $L_{obj}$ [G].
6.  **Iterate:** Repeat steps 3–5 until convergence or a maximum number of iterations is reached [G].

**Pitfalls:**
*   **Zero Gradients:** If the differentiable renderer does not produce anti-aliased masks, the gradient of the mask loss with respect to pose parameters may be zero, preventing optimization [S1].

## Subtopics

### ShAPO
ShAPO extracts comprehensive 3D details (shape, 6D pose, scale, and appearance) of multiple objects from a single RGB-D observation [S2]. It uses an octree-based differentiable optimization and draws on pose, texture, and masks derived from an FPN backbone [S2].

## Background
This method is part of the PSDR-Room pipeline, which reconstructs rooms from single photos using differentiable rendering [S1]. It builds on the Shape-from-Projections Optimization Pipeline by adding a specific stage for refining object poses after coarse geometry prediction [S1].
