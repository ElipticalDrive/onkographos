# Activation-Informed Coarse-to-Fine Rendering

Also called: Activation-based early exit, Masked fine pass

## Overview
This method accelerates NeRF inference by skipping the expensive fine-pass MLP evaluation for rays determined to be empty or background, based on intermediate activation values from the coarse pass [S1]. It sets itself apart from standard coarse-to-fine rendering by using a data-driven mask derived from hidden layer statistics rather than a fixed geometric threshold or uniform sampling, achieving significant speedups on synthetic scenes with transparent backgrounds [S1].

## How it works
**Inputs:**
- Ray $r$ generated from pixel $(x, y)$ and camera pose.
- Positional encoding function $\gamma(\cdot)$.
- Coarse MLP $\Theta_{\text{coarse}}$ and Fine MLP $\Theta_{\text{fine}}$.
- Number of coarse samples $N_c$ and fine samples $N_f$ (total fine samples $N_c + N_f = 192$ in the source experiment) [S1].

**Outputs:**
- Final rendered color $\hat{C}$.

**Data Structures:**
- Activation tensor $A^{(\ell)} \in \mathbb{R}^{N_s \times N_h}$, where $N_s$ is the number of samples along the ray and $N_h$ is the number of hidden units in layer $\ell$ [S1].
- Scalar activation $v_\ell \in \mathbb{R}$ for the ray [S1].
- Threshold $\tau \in \mathbb{R}$ [S1].

**Steps:**
1. For each pixel $(x, y)$, generate ray $r$ and apply positional encoding $\gamma(\cdot)$ to the sample points [S1].
2. Pass the $N_s$ samples along ray $r$ through the coarse MLP $\Theta_{\text{coarse}}$ to obtain predicted densities $\sigma$ and intermediate activations $A^{(\ell)}$ at layer $\ell$ [S1].
3. Compute the scalar activation $v_\ell$ for the ray by summing all elements of the activation tensor $A^{(\ell)}$ and dividing by the number of samples $N_s$ and hidden units $N_h$:
   $$ v_\ell = \frac{1}{N_s} \sum_{i=1}^{N_s} \sum_{j=1}^{N_h} A^{(\ell)}_{i,j} $$
   [S1, Eq. 9]. Note: Activations are recorded after the ReLU function has been applied [S1].
4. Calculate the threshold $\tau$ as the mean activation $\mu(V_\ell)$ of the activation image $V_\ell$ across all rays/pixels in the current view or batch:
   $$ \tau = \mu(V_\ell) $$
   [S1].
5. Identify the set of rays $P$ where $v_\ell < \tau$. These rays are treated as having no significant scene content (e.g., transparent background) [S1].
6. For each ray $r$:
   - If $r \in P$ (i.e., $v_\ell < \tau$), evaluate the fine MLP $\Theta_{\text{fine}}$ using $N_c + N_f$ samples to compute the final radiance [S1].
   - If $r \notin P$ (i.e., $v_\ell \ge \tau$), use the coarse radiance $\hat{C}_c$ as the final output $\hat{C}$ [S1].

**Parameters:**
- $\ell$: Layer index for activation analysis. Typical values are 1, 2, or 3. Applying the method to earlier layers accelerates inference more substantially [S1].
- $\tau$: Threshold for skipping the fine pass. Value: $\mu(V_\ell)$, the mean of the activation image $V_\ell$ [S1].

**Edge Cases and Pitfalls:**
- The method relies on transparent backgrounds found in synthetic scenes (e.g., Blender dataset) [S1]. It fails on real-world scenes with detailed backgrounds, necessitating a density approximation method instead [S1].
- Using activations after ReLU causes information loss but results in more consistent histograms for feature representation $f_\ell$ [S1].

**Pseudocode:**
```python
def activation_informed_render(ray, theta_coarse, theta_fine, layer_index):
    # 1. Generate samples and apply positional encoding
    # Assume samples are already generated along ray r
    encoded_samples = positional_encoding(samples)
    
    # 2. Pass through coarse MLP to get activations
    # theta_coarse returns densities and intermediate activations
    # A[layer_index] is the activation tensor after ReLU at layer_index
    densities, activations = theta_coarse(encoded_samples)
    A = activations[layer_index] # Shape: (N_s, N_h)
    
    # 3. Compute scalar activation v_l
    N_s, N_h = A.shape
    v_l = (1.0 / (N_s * N_h)) * torch.sum(A)
    
    # 4. Determine threshold tau (computed globally or per-view)
    # tau is the mean of all v_l values in the current view/batch
    # This value is assumed to be pre-computed and passed in
    if v_l < tau:
        # 5. Ray is in set P (empty/background) -> Evaluate fine pass
        # Use N_c + N_f samples for fine pass
        fine_encoded_samples = positional_encoding(fine_samples)
        fine_densities, _ = theta_fine(fine_encoded_samples)
        final_radiance = volume_render(fine_densities, ...)
    else:
        # 6. Ray is not in set P -> Use coarse output
        final_radiance = volume_render(densities, ...)
        
    return final_radiance
```

## Subtopics

### Density Approximation using Activations
Uses activation features $f_\ell$ to estimate density $\hat{d}$ via histograms, allowing the coarse pass to be skipped entirely for background rays. This extends the method to real-world scenes with detailed backgrounds where transparent backgrounds are absent [S1].

### Application to Proposal Networks
The method is applied to proposal network samplers (e.g., in Nerfacto with Mip-NeRF 360 sampler) to accelerate initial sampling stages [S1].

## Operating characteristics
- **Time Complexity**: Reduces inference time by skipping the fine MLP evaluation for a subset of rays.
- **Measured Performance**: On the Blender 'lego' scene (800x800):
  - Layer 1: 34.69% speedup, 40% of rays processed by fine pass, PSNR 29.66, SSIM 0.93, LPIPS 0.04 [S1].
  - Layer 3: 55% speedup, 47% of rays processed by fine pass, PSNR 31.21, SSIM 0.95, LPIPS 0.02 [S1].
- **Strengths**: Significant performance improvement with negligible image quality loss on synthetic scenes [S1]. Early layers provide substantial acceleration [S1].
- **Limitations**: Fails on real-world scenes with detailed backgrounds without the density approximation extension [S1].

## Background
Originated in the paper "Analyzing the Internals of Neural Radiance Fields" [S1]. The method leverages the observation that intermediate activations in NeRF MLPs contain notable structural information and correlate with density, allowing for efficient culling of background rays [S1].
