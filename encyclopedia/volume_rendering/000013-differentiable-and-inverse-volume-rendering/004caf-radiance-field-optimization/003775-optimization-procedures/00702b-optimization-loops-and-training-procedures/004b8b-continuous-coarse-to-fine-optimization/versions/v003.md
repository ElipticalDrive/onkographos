# Continuous Coarse-To-Fine Optimization

Also called: Continuous LOD scheduling, Progressive Optimization, Texture MIP Pyramid Optimization

## Overview
Continuous Coarse-To-Fine Optimization is a progressive training strategy that mitigates shape-radiance ambiguity and convergence to low-quality local optima by restricting the Level of Detail (LOD) of the scene representation to coarse levels initially, then gradually relaxing this regularization [S1, unofficial][S2]. Unlike discrete multi-stage approaches, it operates continuously in LOD space, allowing for dynamic resolution extension without modifying previously trained parameters or decoder weights [S1, unofficial]. It sets itself apart from I-NGP-based architectures by keeping all decoder latent space dimensions supervised during LOD expansion, so adding new grid levels only adds degrees of freedom to the mapping function rather than requiring global weight refinement [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Scene observations (images and camera poses), initial scene parameters (emission, roughness, specular, albedo), and hyperparameters for the LOD scheduler ($L_0, n_{ctf}$) and optimizer (learning rates) [S1, unofficial][S2].
*   **Outputs:** Optimized scene representation (hierarchical grids and albedo texture) and material parameters [S1, unofficial][S2].

**Data Structures:**
*   **LOD Grids:** Hierarchical grid structures where each level $l$ corresponds to a specific spatial resolution. The structure supports continuous LOD sampling, where a sample's effective resolution is determined by a scheduler value based on the training epoch [S1, unofficial].
*   **Albedo Texture:** A spatially varying RGB texture map, initially at $1024 \times 1024$ resolution, refined to $4096 \times 4096$ [S2].
*   **Material Parameters:** Emission coefficients, roughness coefficients, specular coefficients, and diffuse albedo [S2].

**Numbered Steps:**

1.  **Initialization:** Initialize the scene with emission parameters. Set the initial maximal LOD $L = L_0$, where $L_0$ defines the number of grid levels used at initialization [S1, unofficial][S2].
2.  **LOD Scheduling:** For each epoch $n$, update the maximal allowed LOD $L$ using the linear scheduler:
    $$
    L = L_0 + \frac{n}{n_{ctf}}
    $$
    where $n$ is the current epoch, $n_{ctf}$ is a hyperparameter controlling the speed of the coarse-to-fine process, and $L \in \mathbb{R}^+$ [S1, unofficial]. The value $L$ is clamped to a specified maximum resolution [S1, unofficial].
3.  **Cone Casting with LOD Clamping:** During volume rendering (cone casting), clamp the samples' LOD to the current maximal LOD $L$. Grids at level $L + 1$ and above are set to zero and are not optimized [S1, unofficial].
4.  **Variable Introduction Sequence:** Gradually introduce optimization variables in the following order [S2]:
    a.  **Emission:** Optimize emission parameters first.
    b.  **Roughness & Specular:** Optimize roughness and specular coefficients next.
    c.  **Albedo:** Optimize spatially-varying albedo last.
5.  **Albedo Refinement:** Optimize albedo first as a $1024 \times 1024$ RGB texture. Then, refine it in two stages to reach the final $4096 \times 4096$ resolution [S2].
6.  **Sparsity Pruning:** After the first albedo refinement stage, identify emitters contributing a small fraction of the total scene radiance and round their values to zero [S2].
7.  **Gradient Clamping:** To handle noisy Monte Carlo estimates from path tracing, clamp gradients to $\pm 10^{-8}$ before optimizer rescaling to prevent outliers from destabilizing the optimization [S2].

**Pseudocode:**

```python
def continuous_coarse_to_fine_optimization(scene_params, observations, n_epochs, L0, n_ctf, max_L):
    # Initialize parameters
    emission = scene_params['emission']
    roughness = scene_params['roughness']
    specular = scene_params['specular']
    albedo = scene_params['albedo']  # Initial resolution 1024x1024

    # Learning rates per parameter group
    lr_emission = 1.0
    lr_roughness_specular = 0.005
    lr_albedo = 0.1

    # Optimizer state (simplified Adam-like update)
    m = {k: 0.0 for k in ['emission', 'roughness', 'specular', 'albedo']}
    v = {k: 0.0 for k in ['emission', 'roughness', 'specular', 'albedo']}
    t = 0

    for n in range(n_epochs):
        t += 1
        # 1. Update maximal LOD
        L = L0 + n / n_ctf
        if L > max_L:
            L = max_L

        # 2. Prepare scene for rendering with LOD clamping
        # Grids at level > L are zeroed out and frozen
        scene = scene_params.copy()
        for level in scene['grids']:
            if level > L:
                scene['grids'][level] = 0.0

        # 3. Render and compute loss
        total_loss = 0.0
        for obs in observations:
            # Sample rays, clamp LOD to L during sampling [Comment: Standard ray sampling]
            samples = sample_rays(obs.rays, max_lod=L)
            # Render using emission-absorption model [Comment: Standard volume rendering]
            image = render_volume(scene, samples)
            # Mean squared error
            loss = sum((image[i] - obs.images[i]) ** 2 for i in range(len(image))) / len(image)
            total_loss += loss

        # 4. Backpropagate with gradient clamping
        gradients = compute_gradients(total_loss, scene_params)
        # Clamp gradients to prevent outliers from noisy MC estimates
        for key in gradients:
            g = gradients[key]
            if g > 1e-8: g = 1e-8
            if g < -1e-8: g = -1e-8
            gradients[key] = g

        # 5. Update parameters
        for key in ['emission', 'roughness', 'specular', 'albedo']:
            m[key] = 0.9 * m[key] + 0.1 * gradients[key]
            v[key] = 0.9 * v[key] + 0.1 * (gradients[key] ** 2)
            bias_correction_m = m[key] / (1 - 0.9 ** t)
            bias_correction_v = v[key] / (1 - 0.9 ** t)
            step_size = lr_emission if key == 'emission' else (lr_roughness_specular if key in ['roughness', 'specular'] else lr_albedo)
            scene_params[key] -= step_size * bias_correction_m / (bias_correction_v ** 0.5 + 1e-8)

        # 6. Albedo refinement stages
        if n == n_refinement_stage_1:
            # Refine albedo to 4096x4096 [Comment: Standard texture upscaling]
            albedo = upscale_albedo(albedo, target_size=(4096, 4096))
            # Prune low-contributing emitters
            total_radiance = sum(scene_params['emission'])
            for i in range(len(scene_params['emission'])):
                if scene_params['emission'][i] / total_radiance < 0.01:
                    scene_params['emission'][i] = 0.0

    return scene_params
```

**Parameters:**
*   $L_0$: Initial number of used grids at initialization [S1, unofficial].
*   $n_{ctf}$: Hyperparameter describing the speed of the coarse-to-fine process [S1, unofficial].
*   Initial albedo resolution: $1024 \times 1024$ [S2].
*   Final albedo resolution: $4096 \times 4096$ [S2].
*   Gradient clamp: $\pm 10^{-8}$ [S2].
*   Adam learning rates: 1 for emission, 0.005 for roughness & specular, 0.1 for diffuse albedo [S2].

**Edge Cases and Pitfalls:**
*   **Shape-Radiance Ambiguity:** Starting with all unknowns at highest resolution leads to low-quality local optima [S2].
*   **Decoder Latent Space:** In I-NGP-based architectures, keeping grid values to zero leaves some decoder latent space dimensions unsupervised, causing global weight refinement issues when new grids are optimized [S1, unofficial]. This method avoids this by supervising all decoder latent space dimensions [S1, unofficial].
*   **Noisy Gradients:** Path-traced samples can include extremely high-valued outliers caused by improbable light paths, requiring gradient clamping [S2].

## Subtopics

### LOD Scheduling
A method for continuously varying the resolution of the scene representation during training. It sets itself apart by allowing dynamic resolution extension without modifying decoder weights [S1, unofficial]. Choose it when dealing with challenging setups or few images [S1, unofficial]. See [Continuous Coarse-To-Fine Optimization](52-continuous-coarse-to-fine-optimization.md).

### Variable Introduction
A strategy for gradually adding optimization variables (emission, roughness, specular, albedo) to avoid local optima. It sets itself apart by following a specific sequence inspired by texture MIP pyramids [S2]. Choose it for complex material and lighting reconstruction [S2]. See [Continuous Coarse-To-Fine Optimization](52-continuous-coarse-to-fine-optimization.md).

## Background
Continuous Coarse-To-Fine Optimization was introduced in the context of RING-NeRF and texture-space differentiable rendering [S1, unofficial][S2]. It builds on the idea of progressive optimization from coarse to fine levels, inspired by texture MIP pyramids [S2]. It addresses the limitations of I-NGP-based architectures in handling coarse-to-fine training [S1, unofficial].
