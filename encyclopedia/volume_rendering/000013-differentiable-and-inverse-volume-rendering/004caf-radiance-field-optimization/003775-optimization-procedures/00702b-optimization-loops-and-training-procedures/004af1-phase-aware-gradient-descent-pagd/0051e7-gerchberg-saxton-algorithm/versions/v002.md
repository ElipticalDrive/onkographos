# Gerchberg-Saxton Algorithm

Also called: Iterative Phase Optimization, iterative phase retrieval

## Overview
The Gerchberg-Saxton algorithm is an iterative phase retrieval method used to compute phase-only holograms by optimizing object point phases to produce constant amplitude across the hologram plane [S1]. It solves the problem of phase-only display constraints, where the display hardware can only modulate phase, not amplitude [S1]. Unlike direct calculation methods, it separates the optimization of interference patterns from the final amplitude constraint, leveraging the fact that the human eye does not detect image phase [S1]. It is the most common method for computing phase-only holograms for simple text and symbology [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Target image intensity distribution; hologram plane resolution; object point positions (if applicable).
*   **Output:** Phase-only hologram $H$ (phase values $\phi_h$).

**Data Structures:**
*   Complex field arrays for the object plane and hologram plane.
*   Amplitude and phase masks.

**Steps:**
1.  **Initialization:** Start with an initial guess for the complex field at the hologram plane. Typically, the amplitude is set to a constant value (e.g., uniform), and the phase is either random or derived from the target image [S1, S2].
2.  **Forward Propagation:** Propagate the complex field from the hologram plane to the object plane using a wave propagation model (e.g., Fourier transform for far-field, Fresnel transform for near-field) [S1].
3.  **Object Plane Constraint:** Replace the amplitude of the propagated field at the object plane with the target amplitude (derived from the target image intensity), while preserving the calculated phase [S1].
4.  **Backward Propagation:** Propagate the constrained field back from the object plane to the hologram plane using the inverse wave propagation model [S1].
5.  **Hologram Plane Constraint:** Replace the amplitude of the field at the hologram plane with a constant value (uniform amplitude), while preserving the calculated phase [S1].
6.  **Iteration:** Repeat steps 2-5 for a specified number of iterations [S1].
7.  **Output:** The phase of the complex field at the hologram plane after the final iteration is the hologram [S1].

**Formulas:**
Let $U_h(x,y)$ be the complex field at the hologram plane and $U_o(u,v)$ be the complex field at the object plane.
The propagation is modeled as:
$$ U_o = \mathcal{P}(U_h) $$
$$ U_h^{(k+1)} = A_h \cdot \exp(i \cdot \arg(\mathcal{P}^{-1}(A_o \cdot \exp(i \cdot \arg(U_o^{(k)}))))) $$
Where:
*   $\mathcal{P}$ is the forward propagation operator.
*   $\mathcal{P}^{-1}$ is the backward propagation operator.
*   $A_h$ is the constant target amplitude at the hologram plane.
*   $A_o$ is the target amplitude at the object plane (square root of target intensity).
*   $k$ is the iteration index.

**Parameters:**
*   **Number of iterations:** Typically 10-100 [S1].

**Edge Cases and Pitfalls:**
*   **Speckle:** Iteratively optimized holograms tend to include undesirable high-frequency noise or speckle [S1].
*   **Computational Expense:** The method is computationally expensive due to the many iterations required [S1].
*   **Local Minima:** The algorithm may converge to local minima, resulting in suboptimal holograms [G].

**Pseudocode:**
```python
def gerchberg_saxton(target_intensity, hologram_shape, num_iterations, propagation_func, inverse_propagation_func):
    """
    Gerchberg-Saxton algorithm for phase-only hologram generation.
    
    Args:
        target_intensity: 2D array, target image intensity.
        hologram_shape: tuple, (height, width) of the hologram.
        num_iterations: int, number of iterations.
        propagation_func: function, forward propagation (e.g., FFT).
        inverse_propagation_func: function, backward propagation (e.g., IFFT).
        
    Returns:
        hologram_phase: 2D array, phase-only hologram.
    """
    # Initialize complex field at hologram plane
    # Amplitude is constant, phase is random or zero
    amplitude_h = np.ones(hologram_shape)
    phase_h = np.random.uniform(0, 2 * np.pi, hologram_shape)
    field_h = amplitude_h * np.exp(1j * phase_h)
    
    # Target amplitude at object plane
    target_amplitude_o = np.sqrt(target_intensity)
    
    for k in range(num_iterations):
        # Forward propagation to object plane
        field_o = propagation_func(field_h)
        
        # Enforce object plane amplitude constraint
        phase_o = np.angle(field_o)
        field_o_constrained = target_amplitude_o * np.exp(1j * phase_o)
        
        # Backward propagation to hologram plane
        field_h = inverse_propagation_func(field_o_constrained)
        
        # Enforce hologram plane amplitude constraint (constant amplitude)
        phase_h = np.angle(field_h)
        field_h = amplitude_h * np.exp(1j * phase_h)
        
    # Return the phase of the final hologram field
    return np.angle(field_h)
```

## Subtopics

### Weighted Fourier Iterative Algorithm
An iterative algorithm to design Computer-Generated Holograms (CGHs) by finding a phase distribution on the hologram plane that approximates a target focal pattern, used to generate multiple simultaneous focal points for voxel positioning [S2]. It differs from the base Gerchberg-Saxton algorithm by introducing a weighting function $w$ to control convergence and enforce amplitude constraints more flexibly [S2]. It is chosen for its high uniformity among reconstructed focal points and simplicity of implementation based on iterative fast Fourier transform operations [S2]. To choose it, use it when generating multiple simultaneous focal points for applications like laser processing or voxel positioning [S2].

**Steps:**
1.  **Initialization:** Initialize amplitude $a_h(x,y)$ as uniform values on the hologram plane [S2]. Form initial phase $\phi_h$ by inverse Fourier transform of complex amplitude constructed with the target pattern [S2].
2.  **Forward Propagation:** Calculate the reconstructed plane amplitude $u_r(\nu_x, \nu_y)$ using the Fourier transform: $u_r(\nu_x, \nu_y) = \mathcal{F}[u_h(x,y)]$, where $u_h(x,y) = a_h(x,y)\exp(i\phi_h(x,y))$ [S2].
3.  **Constrained Amplitude Update:** In iteration step $k$, constrain the reconstructed plane amplitude to the desired distribution $a_t(\nu_x, \nu_y)$ using the weighting function $w^{(k+1)}$: $u_r^{(k+1)}(\nu_x, \nu_y) = w^{(k+1)}(\nu_x, \nu_y) a_t(\nu_x, \nu_y) \exp(i\phi_r(\nu_x, \nu_y))$, where $\phi_r = \arg(u_r^{(k)})$ [S2].
4.  **Weighting Function Update:** Update the weighting function iteratively: $w^{(k+1)}(\nu_x, \nu_y) = w^{(k)}(\nu_x, \nu_y) \{ \frac{a_t(\nu_x, \nu_y)}{|u_r^{(k)}(\nu_x, \nu_y)|} \}^\alpha$ [S2].
5.  **Backward Propagation:** Calculate the new hologram plane field $u_h$ using the inverse Fourier transform of $u_r^{(k+1)}$ [S2].
6.  **Iteration:** Repeat steps 2-5 for a specified number of iterations [S2].
7.  **Output:** Generate optimal $\phi_h$ as a CGH by calculating $\arg(u_h)$ after iterations [S2].

**Formulas:**
$$ u_r(\nu_x, \nu_y) = \mathcal{F}[u_h(x,y)] $$
$$ u_h(x,y) = a_h(x,y)\exp(i\phi_h(x,y)) $$
$$ u_r^{(k+1)}(\nu_x, \nu_y) = w^{(k+1)}(\nu_x, \nu_y) a_t(\nu_x, \nu_y) \exp(i\phi_r(\nu_x, \nu_y)) $$
$$ w^{(k+1)}(\nu_x, \nu_y) = w^{(k)}(\nu_x, \nu_y) \left\{ \frac{a_t(\nu_x, \nu_y)}{|u_r^{(k)}(\nu_x, \nu_y)|} \right\}^\alpha $$
Where:
*   $a_h, \phi_h$: amplitude and phase on SLM.
*   $\nu_x, \nu_y$: spatial frequencies.
*   $\mathcal{F}[\cdot]$: Fourier transform.
*   $a_t$: desired amplitude distribution.
*   $\alpha$: adjustable parameter controlling convergence.

**Parameters:**
*   **$\alpha$:** Adjustable parameter controlling convergence. Typical value: 0.1 [S2].

## Operating characteristics
*   **Time Complexity:** $O(N \log N)$ per iteration due to FFT operations, where $N$ is the number of pixels. Total time is proportional to the number of iterations [S1].
*   **Memory Complexity:** $O(N)$ for storing the complex fields at each plane [S1].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Performance scales linearly with the number of iterations and the size of the hologram [S1].
*   **Strengths:** Simple to implement; effective for generating phase-only holograms with constant amplitude [S1, S2].
*   **Limitations:** Computationally expensive; prone to speckle noise; may converge to local minima [S1].
*   **When to use:** When phase-only holograms are required and computational resources are available [S1].
*   **When not to use:** When real-time performance is critical and speckle is unacceptable [S1].

## Background
The Gerchberg-Saxton algorithm was introduced by Gerchberg and Saxton in 1972 [S1]. It is a well-established phase retrieval method used in various applications, including holography and optics [S2]. Modern variations add error compensation and define "do not care" regions to increase performance [S1]. It is commonly used in holographic near-eye displays for virtual and augmented reality [S1].
