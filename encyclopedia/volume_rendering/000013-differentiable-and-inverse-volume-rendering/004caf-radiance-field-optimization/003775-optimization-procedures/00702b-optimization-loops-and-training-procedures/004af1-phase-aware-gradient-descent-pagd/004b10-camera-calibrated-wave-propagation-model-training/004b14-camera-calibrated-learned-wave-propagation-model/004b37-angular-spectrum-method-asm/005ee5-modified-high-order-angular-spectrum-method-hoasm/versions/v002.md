# Modified High Order Angular Spectrum Method (HOASM)


## Overview
HOASM is a differentiable wave propagation model that separates the propagation of zero-order and first-order diffraction terms to handle them differently before feeding them into a neural network [S1]. It builds on [Angular Spectrum Method (ASM)](12941-angular-spectrum-method-asm.md) by introducing a specific preprocessing step for the first-order term involving grid patterning and sinc weighting, distinguishing it from standard ASM which propagates all orders together [S1].

## How it works
**Inputs and Outputs:** The input is a complex field $U(x,y)$ at the source plane (e.g., SLM), propagation distance $z$, wavelength $\lambda$, and SLM parameters (pixel size $p$, resolution) [S1]. The output is a single-channel intensity image $I(x,y)$ at the sensor plane [S1].

**Data Structures:** The U-Net input is a stacked tensor of the real and imaginary parts of the propagated zero-order and first-order fields [S1]. The U-Net architecture consists of 4 downsampling layers, 4 upsampling layers, channels increasing from 4 to 32 in the first downsampling layer, doubling in each of the next 3 downsampling layers to 256 channels, and a single-channel output [S1].

**Steps:**
1. Propagate the zero-order component of the complex field using the standard Angular Spectrum Method (ASM) [S1].
2. Compute the Fourier transform of the complex field and zero-pad it [S1].
3. Pattern the zero-padded Fourier transform into a $3 \times 3$ grid [S1].
4. Zero out the center Fourier transform of the grid [S1].
5. Weight the Fourier representation of the first-order term with a sinc function [S1].
6. Propagate the weighted first-order term to the sensor plane using ASM [S1].
7. Down-sample and crop the resulting first-order field [S1].
8. Split the complex fields of both the zero-order and first-order into their real and imaginary parts, and stack them [S1].
9. Feed the stacked tensor into a U-Net to produce a single-channel output representing the intensity of the propagated wavefront [S1].

    first_imag = np.imag(first_order_processed)

def asm_propagate(field, z, wavelength, pixel_size):
    # Compute spatial frequencies
    fx = np.fft.fftfreq(field.shape[1], d=pixel_size)
    fy = np.fft.fftfreq(field.shape[0], d=pixel_size)
    fx, fy = np.meshgrid(fx, fy)

    # Compute ASM transfer function H(fx, fy) = exp(i * 2 * pi * z * sqrt(1/lambda^2 - fx^2 - fy^2))
    # [G] Evanescent waves (where argument is imaginary) are typically zeroed or handled via complex sqrt.
    k = 2.0 * np.pi / wavelength
    kx, ky = 2.0 * np.pi * fx, 2.0 * np.pi * fy
    kz = np.sqrt(k**2 - kx**2 - ky**2)
    # Handle evanescent waves by setting kz to imaginary or zeroing contribution
    kz = np.where(kx**2 + ky**2 <= k**2, kz, 0.0 + 1j * np.sqrt(kx**2 + ky**2 - k**2))
    H = np.exp(1j * kz * z)

    # Propagate in frequency domain
    F = np.fft.fft2(field)
    F_prop = F * H
    propagated = np.fft.ifft2(F_prop)
    return propagated

def pattern_to_3x3_grid(fourier_field):
    # [G] Source does not specify exact grid patterning algorithm.
    # We implement a simple block-averaging to map the 2D frequency plane to a 3x3 grid.
    rows, cols = fourier_field.shape
    # Pad to divisible by 3 if necessary
    pad_r = (3 - rows % 3) % 3
    pad_c = (3 - cols % 3) % 3
    padded = np.pad(fourier_field, ((0, pad_r), (0, pad_c)), mode='constant')
    r, c = padded.shape
    grid = np.zeros((3, 3), dtype=complex)
    for i in range(3):
        for j in range(3):
            grid[i, j] = np.mean(padded[i::3, j::3])
    return grid

def downsample_and_crop(field, target_resolution):
    # [G] Exact downsampling/cropping method is not specified.
    # We resize to target resolution using bilinear interpolation.
    return np.array([np.array([np.mean(field[i::2, j::2]) for j in range(0, field.shape[1], 2)]) for i in range(0, field.shape[0], 2)]) # Simplified for pseudocode

def u_net_forward(input_tensor):
    # [G] Standard U-Net forward pass implementation details are not provided.
    # Architecture: 4 down, 4 up, channels 4->32->64->128->256->...->1.
    # We return a placeholder tensor of the correct output shape.
    return np.zeros((input_tensor.shape[0], input_tensor.shape[1], 1))

## Background
HOASM is implemented as a modified version of the High Order Angular Spectrum Method (HOASM) as described by Gopakumar et al. [2021] [S1]. It was developed for use in simultaneous color computer-generated holography, specifically within the context of the "Simultaneous Color Holography" project [S1]. The method is used to simulate wave propagation from a Spatial Light Modulator (SLM) to a sensor plane, incorporating experimental calibration for specific SLM hardware (Holoeye Pluto-2.1-Vis-016) [S1].
