# Modified High Order Angular Spectrum Method (HOASM)

## Overview
HOASM is a differentiable wave propagation model that separates the propagation of zero-order and first-order diffraction terms to handle them differently before feeding them into a neural network [S1]. It builds on [Angular Spectrum Method (ASM)](12941-angular-spectrum-method-asm.md) by introducing a specific preprocessing step for the first-order term involving grid patterning and sinc weighting, distinguishing it from standard ASM which propagates all orders together [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Complex field $U(x,y)$ at the source plane (e.g., SLM), propagation distance $z$, wavelength $\lambda$, and SLM parameters (pixel size $p$, resolution).
*   **Output:** Single-channel intensity image $I(x,y)$ at the sensor plane.

**Data Structures:**
*   **Complex Field:** 2D array of complex numbers representing the wavefront.
*   **U-Net Input:** Stacked real and imaginary parts of the propagated zero-order and first-order fields.
*   **U-Net Architecture:**
    *   Downsampling path: 4 layers.
    *   Channels: Start with 4 input channels. First layer maps to 32 channels. Each subsequent downsampling layer doubles the channel count (32 $\to$ 64 $\to$ 128 $\to$ 256).
    *   Upsampling path: 4 layers.
    *   Output: Single channel (intensity).

**Steps:**
1.  **Zero-Order Propagation:** Propagate the zero-order component of the complex field using the standard Angular Spectrum Method (ASM) [S1].
2.  **First-Order Preparation:**
    a. Compute the Fourier transform of the complex field.
    b. Zero-pad the Fourier transform.
    c. Pattern the zero-padded Fourier transform into a $3 \times 3$ grid [S1].
    d. Zero out the center Fourier transform of this grid [S1].
    e. Weight the Fourier representation of the first-order term with a sinc function [S1].
3.  **First-Order Propagation:** Propagate the weighted first-order term to the sensor plane using ASM [S1].
4.  **Post-Processing:** Down-sample and crop the resulting first-order field [S1].
5.  **Stacking:** Split the complex fields of both the zero-order and first-order into their real and imaginary parts. Stack these four components (Real$_0$, Imag$_0$, Real$_1$, Imag$_1$) to form the input tensor for the neural network [S1].
6.  **Neural Network Inference:** Feed the stacked tensor into a U-Net to produce a single-channel output representing the intensity of the propagated wavefront [S1].

    Propagates a complex field using the Modified High Order Angular Spectrum Method.

        z: Propagation distance.
        wavelength: Wavelength of light.
        pixel_size: Size of SLM pixels.

    """

    first_order_processed = downsample_and_crop(first_order_propagated)
    
    # Step 5: Split and Stack
    # Split zero-order into real and imaginary parts
    zero_real = real(zero_order_propagated)
    zero_imag = imag(zero_order_propagated)
    
    # Split first-order into real and imaginary parts
    first_real = real(first_order_processed)
    first_imag = imag(first_order_processed)
    
    # Stack: [Real_0, Imag_0, Real_1, Imag_1]
    input_tensor = stack([zero_real, zero_imag, first_real, first_imag], axis=-1)
    
    # Step 6: U-Net Inference
    intensity = u_net_forward(input_tensor)
    
    return intensity

def asm_propagate(field, z, wavelength, pixel_size):
    """
    Standard Angular Spectrum Method propagation.
    """
    # Compute spatial frequencies
    # [G] Standard ASM implementation details (frequency grid calculation) are assumed.
    fx, fy = compute_frequency_grid(field.shape, pixel_size)
    
    # Compute transfer function
    # H(fx, fy) = exp(i * 2 * pi * z * sqrt(1/lambda^2 - fx^2 - fy^2))

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** The method is designed for differentiable rendering in virtual environments, specifically for simultaneous color holography [S1].
*   **Strengths:** Allows for separate handling of diffraction orders, potentially improving accuracy or training stability in neural holography [S1].
*   **Limitations:** Requires a neural network (U-Net) for final intensity prediction, adding computational overhead compared to pure analytical ASM [S1].

## Background
HOASM is implemented as a modified version of the High Order Angular Spectrum Method (HOASM) as described by Gopakumar et al. [2021] [S1]. It was developed for use in simultaneous color computer-generated holography, specifically within the context of the "Simultaneous Color Holography" project [S1]. The method is used to simulate wave propagation from a Spatial Light Modulator (SLM) to a sensor plane, incorporating experimental calibration for specific SLM hardware (Holoeye Pluto-2.1-Vis-016) [S1].
