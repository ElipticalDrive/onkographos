# Stage-based Differentiable Volume/Radiance Field Training

Also called: Mitsuba radiance field optimization, TLIR training loop [S1, unofficial]

## Overview
A stage-based optimization loop for differentiable volume or radiance field reconstruction that alternates between image-based and ray-based sampling modes, applies stochastic preconditioning with exponential alpha decay, and optionally upsamples parameters between stages [S1, unofficial]. It distinguishes itself from sibling methods by explicitly managing memory via ray batching and using a progressive upsampling schedule to stabilize training of high-resolution radiance fields [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Inputs:** Scene geometry and radiance field parameters, reference images (with masks and optional AOVs), training configuration parameters [S1, unofficial].
- **Outputs:** Optimized radiance field parameters, loss history, test image metrics (PSNR) [S1, unofficial].

**Data Structures**
- `spn_state`: Dictionary storing stochastic preconditioning state [S1, unofficial].
  - `alpha` (float): Current preconditioning scale factor [S1, unofficial].
  - `step` (int): Iteration counter for the current decay phase [S1, unofficial].
  - `gamma` (float): Exponential decay factor [S1, unofficial].
- `losses`: List of scalar loss values recorded per iteration [S1, unofficial].

**Parameters**
- `use_ray_batching` (bool): Selects between image-based and ray-based sampling modes [S1, unofficial].
- `rays_per_batch` (int): Number of rays sampled per iteration in ray-based mode [S1, unofficial].
- `spp` (int): Samples per pixel used for test image rendering [S1, unofficial].
- `num_iterations_per_stage` (int): Number of optimization iterations per training stage [S1, unofficial].
- `num_stages` (int): Total number of training stages for progressive upsampling [S1, unofficial].
- `enable_upsampling` (bool): Whether to upsample parameters between stages [S1, unofficial].
- `learning_rate` (float): Base learning rate for the optimizer [S1, unofficial].
- `stochastic_preconditioning_starting_alpha` (float): Initial alpha value for SPN decay [S1, unofficial].
- `stochastic_preconditioning_iterations` (int): Number of iterations over which alpha decays exponentially [S1, unofficial].
- `stochastic_preconditioning_update_interval` (int): Frequency of SPN state updates [S1, unofficial].

**Algorithm Steps**
1. **Initialization:** Set integrator loss type [S1, unofficial]. Configure stochastic preconditioning (SPN) with `stochastic_preconditioning_starting_alpha` [S1, unofficial]. Initialize Random Number Generator (RNG) with seed `stage_idx * 1000` [S1, unofficial]. Initialize `spn_state` with `alpha = starting_alpha`, `step = 0` [S1, unofficial].
2. **Sampling Mode Selection:** If `use_ray_batching` is true, shuffle the pre-extracted ray batch using the RNG [S1, unofficial]. If false, select a random sensor index and sample all rays from that image using `sample_rays_from_image` [S1, unofficial].
3. **Ray Sampling:** In ray-based mode, sample `rays_per_batch` rays from the shuffled batch and convert to Mitsuba tensors [S1, unofficial]. In image-based mode, use the rays, target colors, and masks returned by `sample_rays_from_image` [S1, unofficial].
4. **Rendering and Gradient Computation:** Retrieve current `spn_alpha` from `spn_state` [S1, unofficial]. Set AOV loss masks if available [S1, unofficial]. Create an independent sampler seeded with iteration index and ray count [S1, unofficial]. Render rays with automatic gradient computation [S1, unofficial].
5. **Optimization Step:** Append the scalar loss value to the losses list [S1, unofficial]. Step the optimizer [S1, unofficial]. Perform post-step updates on the integrator [S1, unofficial]. Update `spn_state['step']` [S1, unofficial]. If `spn_state['step']` is a multiple of `stochastic_preconditioning_update_interval`, update `spn_state['alpha']` using exponential decay [S1, unofficial].
6. **Stage Evaluation:** After `num_iterations_per_stage` iterations, render `num_test_images` test images using the current scene state and compute PSNR against reference images [S1, unofficial].
7. **Upsampling:** If `enable_upsampling` is true and not the final stage, upsample integrator parameters and update the scene state before proceeding to the next stage [S1, unofficial].

**Stochastic Preconditioning (SPN) Decay**
The decay factor `gamma` is calculated as:
$$
\gamma = 10^{-4 \cdot \frac{1}{\text{stochastic\_preconditioning\_iterations}}}
$$
If `stochastic_preconditioning_iterations` is 0, `gamma` and `alpha` are explicitly set to 0.0 to prevent division by zero or invalid decay calculations [S1, unofficial].

**Pseudocode**
```python
import random
import math
import numpy as np

# Minimal standard implementations for self-containment
class IndependentSampler:
    def __init__(self, seed):
        self.rng = random.Random(seed)
    def get_next(self):
        return self.rng.random()

def pre_extract_rays(reference_data):
    # Standard operation: flatten all sensor rays into a single list
    return [ray for sensor in reference_data.sensors for ray in sensor.rays]

def sample_rays_from_batch(ray_batch, count):
    # Standard operation: slice batch and convert to tensors
    return ray_batch[:count], ray_batch[:count].colors, ray_batch[:count].masks

def sample_rays_from_image(reference_data, sensor_idx):
    # Standard operation: extract rays from a specific sensor
    sensor = reference_data.sensors[sensor_idx]
    return sensor.rays, sensor.colors, sensor.masks

def render_rays_with_gradient(rays, target_colors, sampler, scene, spp, spn_alpha):
    # Standard operation: compute emission-absorption model and MSE loss
    # Uses parent article's volume rendering equation [44-radiance-field-optimization.md]
    rendered = compute_volume_rendering(rays, scene, spp)
    loss = np.mean((rendered - target_colors) ** 2)
    return rendered, loss, {}

def render_test_images(scene, sensors, spp):
    return [compute_volume_rendering(s.rays, scene, spp) for s in sensors]

def compute_psnr(rendered, targets):
    mse = np.mean((rendered - targets) ** 2)
    return 10 * math.log10(1.0 / mse) if mse > 0 else float('inf')

def upsample_parameters(scene, integrator):
    # Standard operation: increase grid resolution or feature dimensions
    integrator.upsample_scene(scene)

def train_stage_based_radiance_field(scene, config, reference_data):
    # 1. Initialization
    spn_state = {
        'alpha': config.stochastic_preconditioning_starting_alpha,
        'step': 0,
        'gamma': 0.0
    }
    
    # Calculate gamma
    if config.stochastic_preconditioning_iterations > 0:
        spn_state['gamma'] = 1e-4 ** (1.0 / config.stochastic_preconditioning_iterations)
    else:
        spn_state['gamma'] = 0.0
        spn_state['alpha'] = 0.0

    losses = []
    rng = random.Random()
    rng.seed(config.stage_idx * 1000)
    
    # Pre-extract ray batch if using ray batching
    if config.use_ray_batching:
        ray_batch = pre_extract_rays(reference_data)
    
    for iteration in range(config.num_iterations_per_stage):
        # 2. Sampling Mode Selection
        if config.use_ray_batching:
            # Shuffle ray batch
            random.shuffle(ray_batch, lambda: rng.random())
            # 3. Ray Sampling (Ray-based mode)
            rays_mi, target_colors, masks = sample_rays_from_batch(ray_batch, config.rays_per_batch)
        else:
            # 3. Ray Sampling (Image-based mode)
            sensor_idx = rng.randint(0, len(reference_data.sensors) - 1)
            rays_mi, target_colors, masks = sample_rays_from_image(reference_data, sensor_idx)
            
        # 4. Rendering and Gradient Computation
        # Create independent sampler
        sampler = IndependentSampler(seed=iteration * config.rays_per_batch)
        
        # Render with gradient computation
        rendered_colors, loss, aovs = render_rays_with_gradient(
            rays=rays_mi,
            target_colors=target_colors,
            sampler=sampler,
            scene=scene,
            spp=config.spp,
            spn_alpha=spn_state['alpha']
        )
        
        # 5. Optimization Step
        losses.append(loss)
        optimizer.step()
        integrator.post_step_update()
        
        # Update SPN state
        spn_state['step'] += 1
        if spn_state['step'] % config.stochastic_preconditioning_update_interval == 0:
            spn_state['alpha'] *= spn_state['gamma']
            
    # 6. Stage Evaluation
    test_images = render_test_images(scene, reference_data.test_sensors, config.spp)
    psnr = compute_psnr(test_images, reference_data.test_targets)
    
    # 7. Upsampling
    if config.enable_upsampling and config.stage_idx < config.num_stages - 1:
        upsample_parameters(scene, integrator)
        
    return losses, psnr
```

## Subtopics

### Staggered Optimization Scheme
Alternates optimization of different parameter groups (e.g., geometry and appearance) in a staggered manner to reduce interference. Choose when parameters are highly coupled and joint optimization causes instability. [5832-staggered-optimization-scheme.md]

### Two-Stage Inverse Rendering Optimization
Separates the optimization into a coarse geometry stage and a fine appearance stage. Choose when initial geometry estimates are poor and need stabilization before refining appearance. [7387-two-stage-inverse-rendering-optimization.md]

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of iterations and rays per batch [S1, unofficial]. Test image rendering adds a constant overhead per stage [S1, unofficial].
- **Memory Complexity:** Ray-based mode reduces memory overhead by batching rays, enabling better data shuffling for large datasets compared to image-based mode which loads all rays from a single image [S1, unofficial].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales with `num_stages` and `enable_upsampling` [S1, unofficial]. Higher resolution requires more stages or larger batches [S1, unofficial].
- **Strengths:** Reduces memory overhead via ray batching; stabilizes training via progressive upsampling and stochastic preconditioning [S1, unofficial].
- **Limitations:** Requires pre-extraction of ray batches for ray-based mode; SPN decay parameters need tuning [S1, unofficial].
- **When to use:** Large datasets where memory is a constraint; high-resolution radiance fields requiring progressive refinement [S1, unofficial].
- **When not to use:** Small datasets where image-based sampling is sufficient; real-time applications due to iterative nature [S1, unofficial].

## Background
Originated in the TLIR (Two-Level Inverse Rendering) framework, implemented in Mitsuba [S1, unofficial]. The method addresses the challenges of training differentiable volume rendering by managing memory and stabilizing convergence through staged optimization and stochastic preconditioning [S1, unofficial].
