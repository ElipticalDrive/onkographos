# Inverse Rendering Optimization Setup

Also called: Adam optimizer for inverse rendering, L2 loss optimization

## Overview
This method configures the optimization loop for inverse rendering of implicit surfaces, using the Adam optimizer [S1] with an L2 loss function [S1]. It recovers geometry from multi-view observations by minimizing the difference between rendered and ground-truth images [S1].

## How it works
**Inputs:**
*   Implicit surface representation (grid-based SDF with tricubic interpolation) [S1].
*   $N_v = 8$ camera views [S1].
*   Ground-truth images for the camera views [S1].
*   Differentiable renderer (e.g., Mitsuba 3 with `cuda_ad_rgb` backend) [S1].

**Outputs:**
*   Optimized implicit surface parameters (SDF grid values) [S1].

**Data Structures:**
*   **SDF Grid:** Parameter array storing signed distance values and interpolation weights [S1].
*   **Optimizer State:** Adam maintains first and second moment estimates for each SDF parameter [G].

**Parameters:**
*   **Optimizer:** Adam [Kingma and Ba 2014] [S1].
*   **Loss Function:** L2 loss (Mean Squared Error) [S1].
*   **Number of Views ($N_v$):** 8 [S1].
*   **Batch Size ($B$):** 2 [S1].
*   **Epochs:** 64 to 256 [S1].

**Steps:**
1.  Initialize SDF grid parameters and Adam optimizer states (first moment $m$, second moment $v$) to zero [G].
2.  Sample a batch of $B=2$ views from the $N_v=8$ available views [S1].
3.  Render images for the batch using the current SDF representation and the differentiable renderer [S1].
4.  Compute the L2 loss between rendered and ground-truth images [S1]:
    $$ L = \frac{1}{N} \sum_{i=1}^{N} (I_{\text{rendered}}[i] - I_{\text{gt}}[i])^2 $$
    where $N$ is the total number of pixels in the batch [S1].
5.  Backpropagate gradients through the differentiable renderer to the SDF parameters using automatic differentiation [S1].
6.  Update SDF parameters using the Adam optimizer step [S1].
7.  Repeat steps 2–6 for 64 to 256 epochs [S1].

**Pseudocode:**
```python
# Initialize SDF grid parameters to zero [G]
sdf_params = [0.0] * num_params
# Initialize Adam optimizer states [G]
m = [0.0] * num_params
v = [0.0] * num_params
t = 0
lr = 0.001
beta1, beta2, eps = 0.9, 0.999, 1e-8

for epoch in range(num_epochs):
    # Sample batch of view indices [S1]
    view_indices = random.sample(range(num_views), batch_size)
    total_loss = 0.0

    for view_idx in view_indices:
        # Render image and compute L2 loss against ground truth [S1]
        rendered = render(sdf_params, view_idx)
        gt = ground_truth_images[view_idx]
        loss = sum((r - g)**2 for r, g in zip(rendered, gt)) / len(rendered)

        # Compute gradients via automatic differentiation [S1]
        grads = compute_gradients(loss, sdf_params)

        # Adam parameter update [G]
        t += 1
        for i in range(num_params):
            m[i] = beta1 * m[i] + (1 - beta1) * grads[i]
            v[i] = beta2 * v[i] + (1 - beta2) * grads[i]**2
            m_hat = m[i] / (1 - beta1**t)
            v_hat = v[i] / (1 - beta2**t)
            sdf_params[i] -= lr * m_hat / (v_hat**0.5 + eps)

        total_loss += loss

def render(params, view_idx):
    # Differentiable rendering using current SDF parameters and camera view [S1]
    return [0.0] * num_pixels

def compute_gradients(loss, params):

    return [0.0] * num_params
```

**Edge Cases:**
*   **Occlusion:** In configurations where light is blocked by geometry (e.g., ceiling with a small hole), sampling becomes difficult and gradients consist only of secondary boundary integrals, making optimization hard [S1].
*   **Precision:** Tricubic interpolation ensures continuous surface normals, which aids gradient stability during optimization [S1].

### [Emission UV Texture Map Optimization](19205-emission-uv-texture-map-optimization.md)
Recovers an emission UV texture map for a scene mesh by minimizing rendering loss between ground-truth HDR images and rendered images, using L1 regularization and adaptive clipping/boosting to encourage sparsity and accelerate convergence. It differs from differentiable rasterization inverse rendering by supporting a maximum light transport depth of 3 (2 bounces) instead of 2 (1 bounce), enabling indirect lighting optimization. Choose it when optimizing emissive materials with indirect lighting effects.

## Operating characteristics
*   **Time Complexity:** Runtime is typically 30 to 90 minutes per optimization run [S1].
*   **Hardware:** Experiments conducted on NVIDIA RTX 4090 GPU [S1].
*   **Scalability:** Uses a small batch size (2) and limited views (8), optimized for single-GPU high-fidelity reconstruction rather than distributed training [S1].
*   **Strengths:** Stable convergence via Adam and L2 loss; continuous normals from tricubic interpolation aid gradient stability [S1].
*   **Limitations:** Highly occluded scenes make light sampling difficult and gradients sparse [S1].
*   **Resolution/Scene Scaling:** Not given in the sources.

## Background
This setup is derived from the "Path-Space Differentiable Rendering of Implicit Surfaces" paper (2024) [S1]. It builds on the diffsdf approach [Vicini et al. 2022] for implicit surface representation [S1]. The method is used in inverse rendering experiments to quantitatively compare optimized shapes using Chamfer distance [S1].
