# Emission UV Texture Map Optimization

Also called: Emission Texture Optimization, Inverse Rendering Optimization

## Overview
This method recovers an emission UV texture map for a scene mesh by minimizing the rendering loss between ground-truth HDR images and rendered images, using L1 regularization and adaptive clipping/boosting to encourage sparsity and accelerate convergence [S1]. It differs from differentiable rasterization inverse rendering by supporting a maximum light transport depth of 3 (2 bounces) instead of 2 (1 bounce), enabling indirect lighting optimization [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of ground-truth 32-bit HDR images $\{I_1, \dots, I_n\}$ with dimensions $(h_{\text{im}}, w_{\text{im}}, c_{\text{im}})$ and known camera poses; a UV-unwrapped mesh with associated UV coordinates; a fixed BSDF parameter set (albedo texture map, specular transmission map at 1.0, roughness map at 0.5) [S1].
*   **Outputs:** An optimized emission UV texture map $T_{\text{emission}}$ with dimensions $(h_{\text{tx}}, w_{\text{tx}}, c_{\text{tx}})$; a pruned mesh containing only faces with emitting vertices [S1].

**Data Structures**
*   $T_{\text{emission}}$: A 3D texture map (height $h_{\text{tx}}$, width $w_{\text{tx}}$, channels $c_{\text{tx}}$) storing emission values. Initialized uniformly with near-zero values [S1].
*   Mesh: A triangular mesh where each vertex has associated UV coordinates $(u, v)$ [S1].

**Parameters**
*   $\alpha$: Tunable hyperparameter for the rendering loss weight [S1].
*   Cadence: Frequency of clipping/boosting steps. Default: every 2 epochs [S1].
*   Brightness threshold: Minimum emission value to be considered a light source. Default: 0.2 [S1].

**Steps**
1.  **Initialization:** Initialize $T_{\text{emission}}$ uniformly with near-zero values [S1]. Keep BSDF parameters fixed: albedo texture map, specular transmission map at 1.0, roughness map at 0.5 [S1].
2.  **Rendering:** For each optimization step $i \in [1, n]$ in a given epoch, render images $\tilde{I}_i$ from identical camera poses using a Path-Replay Backpropagation (PRB) integrator with maximum depth 3 (2 bounces) that directly renders emitters [S1].
3.  **Regularization:** Apply uniform L1 regularization to $T_{\text{emission}}$ to encourage sparsity, based on the inductive bias that most of the scene does not emit light [S1].
4.  **Clipping and Boosting:** Periodically (every `Cadence` epochs), perform the following on $T_{\text{emission}}$ in 32-bit linear color space:
    *   Clip values below the `Brightness threshold` to 0 [S1].
    *   Boost values above the `Brightness threshold` to accelerate convergence [S1].
    *   This step is self-correcting via the rendering loss [S1].
5.  **Convergence Check:** Repeat steps 2-4 until convergence [S1].
6.  **Post-processing:** Prune triangular faces where all vertices fall below the `Brightness threshold`. Lookup vertex brightness via UV coordinates in $T_{\text{emission}}$ [S1]. The result is a reduced mesh used as an area light for shadow passes [S1].

**Objective Function**
The objective is to minimize:
$$ \text{minimize} \frac{1}{\alpha} \| I_i - \tilde{I}_i \|_2^2 + \frac{\| T_{\text{emission}} \|_1}{h_{\text{im}} w_{\text{im}} c_{\text{im}}} (h_{\text{tx}} w_{\text{tx}} c_{\text{tx}}) $$
where $I_i$ is the ground truth image, $\tilde{I}_i$ is the rendered image, $T_{\text{emission}}$ is the emission UV texture map, $(h_{\text{im}}, w_{\text{im}}, c_{\text{im}})$ are image dimensions, $(h_{\text{tx}}, w_{\text{tx}}, c_{\text{tx}})$ are texture dimensions, and $\alpha$ is a hyperparameter [S1].

**Pseudocode**
```python
import numpy as np

def optimize_emission_texture(mesh_faces, uv_coords, gt_images, camera_poses, alpha=1.0, cadence=2, threshold=0.2):
    # 1. Initialization
    h_tx, w_tx, c_tx = 1024, 1024, 3  # [G] Standard UV texture dimensions
    T_emission = np.zeros((h_tx, w_tx, c_tx))

    # Fixed BSDF parameters
    albedo_map = np.ones((h_tx, w_tx, c_tx))  # [G] Pre-computed from MonoSDF appearance model
    specular_transmission = 1.0
    roughness = 0.5

    epoch = 0
    prev_loss = np.inf
    while True:  # [G] Standard convergence loop
        total_loss = 0.0
        for i in range(len(gt_images)):
            gt_image = gt_images[i]
            pose = camera_poses[i]

            # 2. Rendering
            # [S1] Step: Render using Path-Replay Backpropagation (PRB) integrator with max depth 3.
            # Computes radiance at camera rays and returns image + gradients w.r.t. T_emission.
            rendered_image, grads = np.zeros_like(gt_image), np.zeros_like(T_emission)  # [S1] PRB integrator step

            # 3. Regularization & Objective
            l2_loss = np.mean((gt_image - rendered_image) ** 2)
            l1_norm = np.sum(np.abs(T_emission))
            l1_reg = (l1_norm / (gt_image.shape[0] * gt_image.shape[1] * gt_image.shape[2])) * (h_tx * w_tx * c_tx)
            loss = (1.0 / alpha) * l2_loss + l1_reg
            total_loss += loss

            # Update T_emission using gradients
            T_emission -= 0.01 * grads  # [G] Standard gradient descent step

        epoch += 1

        # 4. Clipping and Boosting
        if epoch % cadence == 0:
            # Clip values below threshold to 0
            T_emission[T_emission < threshold] = 0.0
            # Boost values above threshold to accelerate convergence
            T_emission[T_emission >= threshold] *= 2.0  # [G] Standard multiplier for acceleration

        # 5. Convergence Check
        if abs(prev_loss - total_loss) < 1e-6:
            break
        prev_loss = total_loss

    # 6. Post-processing
    pruned_faces = []
    for face in mesh_faces:
        min_brightness = np.inf
        for vertex in face.vertices:
            u, v = uv_coords[vertex]
            # [G] Standard texture sampling
            h, w, c = T_emission.shape
            u_idx = int(np.clip(u * (w - 1), 0, w - 1))
            v_idx = int(np.clip(v * (h - 1), 0, h - 1))
            brightness = T_emission[v_idx, u_idx, :]
            if np.max(brightness) < min_brightness:
                min_brightness = np.max(brightness)
        if min_brightness >= threshold:
            pruned_faces.append(face)
    return T_emission, pruned_faces
```

## Operating characteristics
*   **Time Complexity:** Not given in the sources. [S1]
*   **Memory Complexity:** Not given in the sources. [S1]
*   **Measured Performance:** Not given in the sources. [S1]
*   **Scaling:** Not given in the sources. [S1]
*   **Strengths:** Supports indirect lighting optimization (maximum light transport depth of 3) unlike differentiable rasterization (maximum depth of 2) [S1]. L1 regularization encourages sparsity, which aligns with the inductive bias that most of the scene does not emit light [S1]. Periodic clipping and boosting accelerate convergence and avoid local minima from dim non-light sources [S1].
*   **Limitations:** Requires reasonably accurate geometry (e.g., from MonoSDF) to avoid biasing results to bad local minima due to noisy geometry during differentiable surface rendering [S1].
*   **When to use:** When recovering emission maps for scenes with indirect lighting and sparse light sources, given accurate geometry [S1].
*   **When not to use:** When geometry is noisy or inaccurate, or when indirect lighting is not a concern and rasterization-based methods are sufficient [S1].

## Background
This method is part of the Dynamic Mesh-Aware Radiance Fields framework [S1]. It builds on the use of MonoSDF for accurate geometry reconstruction and SDFStudio for UV unwrapping [S1]. The PRB integrator is used for differentiable surface rendering [S1]. The method is used to create area lights for shadow passes in a Hybrid Renderer [S1].
