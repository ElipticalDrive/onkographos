# Emission UV Texture Map Optimization

Also called: Emission Texture Optimization, Inverse Rendering Optimization

## Overview
This method recovers an emission UV texture map for a scene mesh by minimizing the rendering loss between ground-truth HDR images and rendered images, using L1 regularization and adaptive clipping/boosting to encourage sparsity and accelerate convergence [S1]. It differs from differentiable rasterization inverse rendering by supporting a maximum light transport depth of 3 (2 bounces) instead of 2 (1 bounce), enabling indirect lighting optimization [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of ground-truth 32-bit HDR images $\{I_1, \dots, I_n\}$ with dimensions $(h_{im}, w_{im}, c_{im})$ and known camera poses; a UV-unwrapped mesh with associated UV coordinates; a fixed BSDF parameter set (albedo texture map, specular transmission map at 1.0, roughness map at 0.5) [S1].
*   **Outputs:** An optimized emission UV texture map $T_{emission}$ with dimensions $(h_{tx}, w_{tx}, c_{tx})$; a pruned mesh containing only faces with emitting vertices [S1].

**Data Structures**
*   $T_{emission}$: A 3D texture map (height $h_{tx}$, width $w_{tx}$, channels $c_{tx}$) storing emission values. Initialized uniformly with near-zero values [S1].
*   Mesh: A triangular mesh where each vertex has associated UV coordinates $(u, v)$ [S1].

**Parameters**
*   $\alpha$: Tunable hyperparameter for the rendering loss weight [S1].
*   Cadence: Frequency of clipping/boosting steps. Default: every 2 epochs [S1].
*   Brightness threshold: Minimum emission value to be considered a light source. Default: 0.2 [S1].

**Steps**
1.  **Initialization:** Initialize $T_{emission}$ uniformly with near-zero values [S1]. Keep BSDF parameters fixed: albedo texture map, specular transmission map at 1.0, roughness map at 0.5 [S1].
2.  **Rendering:** For each optimization step $i \in [1, n]$ in a given epoch, render images $\tilde{I}_i$ from identical camera poses using a Path-Replay Backpropagation (PRB) integrator with maximum depth 3 (2 bounces) that directly renders emitters [S1].
3.  **Regularization:** Apply uniform L1 regularization to $T_{emission}$ to encourage sparsity, based on the inductive bias that most of the scene does not emit light [S1].
4.  **Clipping and Boosting:** Periodically (every `Cadence` epochs), perform the following on $T_{emission}$ in 32-bit linear color space:
    *   Clip values below the `Brightness threshold` to 0 [S1].
    *   Boost values above the `Brightness threshold` to accelerate convergence [S1].
    *   This step is self-correcting via the rendering loss [S1].
5.  **Convergence Check:** Repeat steps 2-4 until convergence [S1].
6.  **Post-processing:** Prune triangular faces where all vertices fall below the `Brightness threshold`. Lookup vertex brightness via UV coordinates in $T_{emission}$ [S1]. The result is a reduced mesh used as an area light for shadow passes [S1].

**Objective Function**
The objective is to minimize:
$$ \text{minimize} \frac{1}{\alpha} \| I_i - \tilde{I}_i \|_2^2 + \frac{\| T_{emission} \|_1}{(h_{im} * w_{im} * c_{im})} (h_{tx} * w_{tx} * c_{tx}) $$
where $I_i$ is the ground truth image, $\tilde{I}_i$ is the rendered image, $T_{emission}$ is the emission UV texture map, $(h_{im}, w_{im}, c_{im})$ are image dimensions, $(h_{tx}, w_{tx}, c_{tx})$ are texture dimensions, and $\alpha$ is a hyperparameter [S1].

**Pseudocode**
```python
def optimize_emission_texture(mesh, uv_coords, gt_images, camera_poses, alpha=1.0, cadence=2, threshold=0.2):
    """
    Optimizes the emission UV texture map for a scene mesh.
    
    Args:
        mesh: Triangular mesh with vertices and faces.
        uv_coords: UV coordinates for each vertex.
        gt_images: List of ground-truth HDR images.
        camera_poses: List of camera poses corresponding to gt_images.
        alpha: Hyperparameter for rendering loss weight.
        cadence: Frequency of clipping/boosting steps (epochs).
        threshold: Brightness threshold for clipping/boosting.
        
    Returns:
        T_emission: Optimized emission texture map.
        pruned_mesh: Mesh with non-emitting faces removed.
    """
    # Initialize emission texture with near-zero values
    h_tx, w_tx, c_tx = get_texture_dimensions(mesh)
    T_emission = np.zeros((h_tx, w_tx, c_tx))
    
    # Fixed BSDF parameters
    albedo_map = get_albedo_texture(mesh) # Pre-computed
    specular_transmission = 1.0
    roughness = 0.5
    
    # Optimization loop
    epoch = 0
    while not converged(T_emission):
        for i, (gt_image, pose) in enumerate(zip(gt_images, camera_poses)):
            # Render image using PRB integrator with max depth 3
            rendered_image = render_prb(mesh, T_emission, albedo_map, specular_transmission, roughness, pose, max_depth=3)
            
            # Compute loss
            # Note: L1 norm of T_emission is applied uniformly
            l2_loss = np.mean((gt_image - rendered_image) ** 2)
            l1_reg = np.sum(np.abs(T_emission)) / (gt_image.shape[0] * gt_image.shape[1] * gt_image.shape[2]) * (h_tx * w_tx * c_tx)
            loss = (1.0 / alpha) * l2_loss + l1_reg
            
            # Backpropagate to update T_emission
            update_texture(T_emission, loss)
        
        epoch += 1
        
        # Periodic clipping and boosting
        if epoch % cadence == 0:
            T_emission = clip_and_boost(T_emission, threshold)
            
    # Post-processing: prune non-emitting faces
    pruned_mesh = prune_mesh(mesh, uv_coords, T_emission, threshold)
    
    return T_emission, pruned_mesh

def clip_and_boost(T_emission, threshold):
    """
    Clips values below threshold to 0 and boosts values above threshold.
    """
    # Clip low values
    T_emission[T_emission < threshold] = 0.0
    
    # Boost high values
    # The exact boosting factor is not specified in the source, but it is applied to accelerate convergence.
    # A common approach is to scale up values above the threshold.
    # [G] Assuming a simple scaling factor of 2.0 for values above threshold, as the source mentions "boost" without specifying the factor.
    mask = T_emission >= threshold
    T_emission[mask] *= 2.0
    
    return T_emission

def prune_mesh(mesh, uv_coords, T_emission, threshold):
    """
    Prunes faces where all vertices have emission values below the threshold.
    """
    pruned_faces = []
    for face in mesh.faces:
        vertex_brightnesses = []
        for vertex in face.vertices:
            u, v = uv_coords[vertex]
            # Lookup brightness in T_emission
            brightness = lookup_texture(T_emission, u, v)
            vertex_brightnesses.append(brightness)
        
        # If all vertices are below threshold, prune the face
        if all(b < threshold for b in vertex_brightnesses):
            continue
        else:
            pruned_faces.append(face)
            
    return Mesh(faces=pruned_faces, vertices=mesh.vertices)
```

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Not given in the sources.
*   **Strengths:** Supports indirect lighting optimization (max depth 3) unlike differentiable rasterization (max depth 2) [S1]. L1 regularization encourages sparsity, which is appropriate for scenes where most surfaces do not emit light [S1]. Clipping and boosting accelerate convergence and avoid local minima from dim non-light sources [S1].
*   **Limitations:** Requires reasonably accurate geometry (e.g., from MonoSDF) to avoid biasing results to bad local minima due to noisy geometry during differentiable surface rendering [S1].
*   **When to use:** When recovering emission maps for scenes with indirect lighting and sparse light sources, given accurate geometry.
*   **When not to use:** When geometry is noisy or inaccurate, or when indirect lighting is not a concern and rasterization-based methods are sufficient.

## Background
This method is part of the Dynamic Mesh-Aware Radiance Fields framework [S1]. It builds on the use of MonoSDF for accurate geometry reconstruction and SDFStudio for UV unwrapping [S1]. The PRB integrator is used for differentiable surface rendering [S1]. The method is used to create area lights for shadow passes in a Hybrid Renderer [S1].
