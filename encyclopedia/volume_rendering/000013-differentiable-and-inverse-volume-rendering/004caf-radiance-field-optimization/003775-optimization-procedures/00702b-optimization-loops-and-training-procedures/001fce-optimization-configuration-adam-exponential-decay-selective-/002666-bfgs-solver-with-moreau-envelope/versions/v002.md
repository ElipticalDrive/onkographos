# BFGS Solver with Moreau Envelope

Also called: BFGS with Moreau Envelope, Huber Reconstruction

## Overview
This method solves inverse problems, specifically tomographic reconstruction, by minimizing a composite objective function consisting of a data fidelity term and a regularizer [S1, unofficial]. It sets itself apart by using the BFGS quasi-Newton algorithm to handle the non-smooth L1 regularization via its Moreau envelope, providing a differentiable approximation that allows second-order optimization steps [S1, unofficial]. This contrasts with first-order Gradient Descent solvers [3280-gradient-descent-solver.md] and avoids the explicit projection steps required by constrained material solvers [7899-euclidean-projection-for-material-constraints.md].

## How it works
The method minimizes an objective function $F(x)$ defined as the sum of a squared L2 data discrepancy and a smoothed L1 regularizer applied to the image gradient [S1, unofficial].

**Inputs:**
- Forward operator $A$ (e.g., Ray Transform) [S1, unofficial].
- Noisy measurement data $y$ [S1, unofficial].
- Image space $X$ (e.g., uniform discrete space) [S1, unofficial].
- Gradient operator $\nabla$ [S1, unofficial].
- Hyperparameters: smoothing parameter $\sigma$, regularization weight $\lambda$, maximum iterations $maxiter$, and memory size $num\_store$ [S1, unofficial].

**Outputs:**
- Reconstructed image $x$ [S1, unofficial].

**Data Structures:**
- $x$: The current estimate of the image, stored as a tensor/array in $X$ [S1, unofficial].
- $H^{-1}_0$: Initial inverse Hessian estimate, implemented as a scaling operator [S1, unofficial].
- $s, y$ vectors: Stored for Limited Memory BFGS (L-BFGS) history [S1, unofficial].

**Steps:**
1. **Initialize Operator Norm:** Compute the operator norm of $A$ using the power method to scale the initial Hessian estimate [S1, unofficial].
   $$ opnorm = \|A\| $$
2. **Initialize Inverse Hessian:** Set the initial inverse Hessian estimate $H^{-1}_0$ as a scaled identity operator [S1, unofficial]:
   $$ H^{-1}_0 = \frac{0.5}{\|A\|^2} I $$
3. **Define Data Term:** Construct the squared L2 norm of the residual [S1, unofficial]:
   $$ D(x) = \|Ax - y\|_2^2 $$
4. **Define Regularizer:**
   - Compute the gradient of the image: $g = \nabla x$ [S1, unofficial].
   - Apply the Group L1 norm to the gradient: $\|g\|_{1,2}$ [S1, unofficial].
   - Smooth this non-smooth norm using the Moreau envelope with parameter $\sigma$ [S1, unofficial]:
     $$ R(x) = \text{MoreauEnvelope}_{\sigma}(\|\nabla x\|_{1,2}) $$
5. **Define Objective:** Combine terms [S1, unofficial]:
   $$ F(x) = D(x) + \lambda R(x) $$
6. **Solve:** Run the BFGS solver (specifically L-BFGS if $num\_store$ is limited) starting from an initial guess (often the FBP pseudoinverse result) [S1, unofficial].
   - Use the precomputed $H^{-1}_0$ as the initial Hessian approximation [S1, unofficial].
   - Limit iterations to $maxiter$ [S1, unofficial].
   - Store $num\_store$ vectors for the limited memory update [S1, unofficial].

**Parameters:**
- $\sigma = 0.03$: Smoothing parameter for the Moreau envelope [S1, unofficial].
- $\lambda = 0.3$: Regularization weight [S1, unofficial].
- $maxiter = 200$: Maximum number of iterations [S1, unofficial].
- $num\_store = 10$: Number of vectors stored for L-BFGS [S1, unofficial].

**Pitfalls:**
- The initial reconstruction (pseudoinverse) must use the 'Hann' filter to match the reference implementation's assumptions [S1, unofficial].
- Precision issues may arise if the operator norm is not computed accurately, affecting the scaling of the Hessian estimate [G].

**Pseudocode:**
```python
def bfgs_moreau_envelope_solver(A, y, space, sigma=0.03, lam=0.3, maxiter=200, num_store=10):
    # 1. Compute operator norm via power iteration
    opnorm = power_method_opnorm(A)
    
    # 2. Initialize inverse Hessian estimate as a scaled identity
    hessinv_estimate = ScalingOperator(space, 0.5 / opnorm**2)
    
    # 3. Define data term: squared L2 norm of residual
    def data_discrepancy(x):
        return sum((A(x) - y)**2)
    
    # 4. Define regularizer: Moreau envelope of Group L1 norm on gradient
    gradient_op = Gradient(space)
    l1_norm = GroupL1Norm(gradient_op.range)
    smoothed_l1 = MoreauEnvelope(l1_norm, sigma=sigma)
    def regularizer(x):
        return smoothed_l1(gradient_op(x))
    
    # 5. Define objective function
    def obj_fun(x):
        return data_discrepancy(x) + lam * regularizer(x)
    
    # 6. Initial guess via FBP pseudoinverse with Hann filter
    x = fbp_pseudoinverse(A, y, filter_type='Hann')
    
    # 7. Solve using BFGS with limited memory
    s = [zeros_like(x) for _ in range(num_store)]
    y_vec = [zeros_like(x) for _ in range(num_store)]
    k = 0
    
    for i in range(maxiter):
        grad = compute_gradient(obj_fun, x)
        d = lbfgs_two_loop(grad, s, y_vec, k, hessinv_estimate)
        alpha = line_search(obj_fun, x, grad, d)
        x_new = x + alpha * d
        s[k % num_store] = x_new - x
        y_vec[k % num_store] = compute_gradient(obj_fun, x_new) - grad
        k += 1
        x = x_new
        
    return x
```

## Operating characteristics
- **Time Complexity:** Each iteration involves computing the gradient of the data term and the smoothed regularizer [S1, unofficial]. The L-BFGS update is $O(m \cdot d)$ where $m$ is $num\_store$ and $d$ is the dimension of the image [G]. The dominant cost is usually the forward and adjoint operator evaluations ($A$ and $A^*$) [G].
- **Memory Complexity:** $O(d)$ for the image and gradients, plus $O(m \cdot d)$ for the L-BFGS history vectors [G].
- **Performance:** The Moreau envelope makes the L1 norm differentiable, allowing BFGS to converge faster than first-order methods for smooth approximations, but the smoothing parameter $\sigma$ must be chosen carefully to balance accuracy and differentiability [S1, unofficial][G].
- **Strengths:** Handles non-smooth regularization (L1) effectively within a second-order framework [S1, unofficial]. The Hann filter initialization provides a stable starting point [S1, unofficial].
- **Limitations:** Requires computation of the operator norm, which can be expensive for large operators [G]. The smoothing parameter $\sigma$ is a hyperparameter that affects convergence and solution quality [S1, unofficial].
- **When to use:** Suitable for tomographic reconstruction and other inverse problems where L1 regularization on gradients is desired and second-order convergence is beneficial [S1, unofficial].
- **When not to use:** If the operator norm is too expensive to compute or if the problem size is extremely large, first-order methods might be preferred [G].

## Background
The method is based on the reference implementation from the `learned_gradient_tomography` repository [S1, unofficial]. It combines classical tomographic reconstruction techniques (FBP with Hann filter) with modern optimization methods (BFGS with Moreau envelope) to solve inverse problems [S1, unofficial]. The use of the Moreau envelope to smooth the L1 norm is a standard technique in convex optimization to enable the use of gradient-based methods [G].
