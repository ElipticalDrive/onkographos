# Optimization Configuration (Adam + Exponential Decay + Selective L2)

Also called: Optimization Procedure, Optimizer Settings, Parameter update rule, Training optimizer setup

## Overview
This configuration defines the standard training loop for neural radiance fields and implicit surface representations, combining the Adam optimizer with a staircase exponential learning rate schedule and selective L2 weight decay. It addresses the instability of training coordinate-based neural fields by providing robust convergence parameters, particularly for noisy real-world scan data or complex geometric priors [S2, unofficial]. It sets itself apart from generic optimization loops by explicitly integrating domain-specific augmentations and specific regularization techniques (like CVT for discretization stability) into the core training loop [S1][S2, unofficial].

## How it works
The method initializes a scene representation and iteratively updates parameters using a composite optimizer setup. The core mechanism involves sampling rays, computing gradients via automatic differentiation, and applying parameter updates with specific learning rate schedules and regularization masks.

### Inputs and Outputs
**Inputs:**
*   Scene representation parameters (e.g., MLP weights for density and color, appearance embeddings) [S1][S2, unofficial].
*   Camera poses and intrinsics [S1, S3].
*   Target images (color and/or depth) [S1, S3].
*   Hyperparameters: Initial learning rate ($lr$), decay rate, transition steps, and L2 regularization coefficient [S2, unofficial].

**Outputs:**
*   Optimized scene representation parameters [S1][S2, unofficial].
*   Rendered images matching the targets [S1].

### Data Structures
**Optimizer Configuration:**
*   `param_labels`: A dictionary mapping parameter names to optimizer targets.
    *   Layout: `{"nerf": "network", "bg": "network", "appearance_embeddings": "ae"}` [S2, unofficial].
*   `mask`: A boolean mask dictating where L2 decay is applied.
    *   Layout: `{"nerf": {"density_mlp": True, "rgb_mlp": True, "position_encoder": False}, "bg": True, "appearance_embeddings": False}` [S2, unofficial].
*   `optimizer_network`: Adam optimizer instance for network weights [S2, unofficial].
    *   Parameters: `learning_rate=lr_sch`, `b1=0.9`, `b2=0.99`, `eps=1e-15`, `eps_root=1e-15` [S2, unofficial].
*   `optimizer_ae`: Adam optimizer instance for appearance embeddings [S2, unofficial].
    *   Parameters: `learning_rate=1e-4`, `b1=0.9`, `b2=0.99`, `eps=1e-8`, `eps_root=0` [S2, unofficial].
*   `combined_optimizer`: Multi-transform optimizer combining the above [S2, unofficial].
    *   Mapping: `transforms={"network": optimizer_network, "ae": optimizer_ae}` [S2, unofficial].

**Training State:**
*   `lr_sch`: Learning rate schedule instance [S2, unofficial].
    *   Parameters: `init_value=lr`, `transition_steps=10_000`, `decay_rate=1/3`, `staircase=True`, `transition_begin=10_000`, `end_value=lr/100` [S2, unofficial].
*   `step`: Current optimization step counter [S2, unofficial].

### Numbered Steps
1.  **Initialization:**
    *   Translate and scale the scene to lie within a $[-1, 1]^3$ bounding cube [S1].
    *   Initialize the learning rate schedule with `staircase=True` [S2, unofficial].
    *   Initialize the combined optimizer with the specified parameters [S2, unofficial].
    *   Set the initial step counter to 0 [G].

2.  **Ray Sampling:**
    *   Randomly select $|P_b| = 1024$ rays per iteration [S1].
    *   For each ray, compute sample points:
        *   Fixed samples: $S'_f = 16$ [S1].
        *   Variable samples: $S'_c$ is chosen such that there is on average one sample for every 1.5 cm of ray length [S1].
    *   Apply positional encoding: 8 bands for point coordinates, 4 bands for view direction vector [S1].

3.  **Forward Pass:**
    *   Compute the radiance field values (density $\sigma$, color $\mathbf{c}$) for the sampled points using the current network parameters [S1].
    *   Render the image using the standard emission-absorption model (see [Parent](5622-optimization-loops-and-training-procedures.md)) [S1].
    *   If applicable, apply distortion correction using a 6-layer MLP (width 128) on 2D camera pixel space [S1].

4.  **Loss Computation:**
    *   Compute the loss between rendered and target images.
    *   Loss weights: $\lambda_1 = 0.1$, $\lambda_2 = 10$, $\lambda_3 = 6 \times 10^3$ [S1].
    *   For inverse rendering setups, use L2 loss [S3].

5.  **Gradient Computation:**
    *   Compute gradients with respect to the scene parameters using the specified loss weights and positional encodings [S1].
    *   Use reverse-mode automatic differentiation [44-radiance-field-optimization.md].

6.  **Parameter Update:**
    *   Update the learning rate based on the current step:
        *   If `staircase=True`, the learning rate is held constant for `transition_begin` steps, then decays by `decay_rate` every `transition_steps` steps [S2, unofficial].
        *   Note: `staircase=True` combined with `transition_begin=10_000` delays the first learning rate drop to step 20,000 [S2, unofficial].
    *   Apply the Adam update rule to the parameters, respecting the `mask` for L2 regularization:
        *   L2 decay coefficient: $1 \times 10^{-6}$ [S2, unofficial].
        *   L2 decay is applied to `density_mlp`, `rgb_mlp`, and `bg` parameters, but **not** to `position_encoder` or `appearance_embeddings` [S2, unofficial].
    *   Increment the step counter.

7.  **Iteration:**
    *   Repeat steps 2-6 until convergence or maximum iterations reached.

### Pseudocode
```python
import jax.numpy as jnp
from jax import grad, value_and_grad

def initialize_optimizer(lr, param_labels, mask):
    """
    Initialize the combined optimizer and learning rate schedule.
    """
    # Learning rate schedule: optax.exponential_decay
    lr_sch = {
        'init_value': lr,
        'transition_steps': 10_000,
        'decay_rate': 1/3,
        'staircase': True,
        'transition_begin': 10_000,
        'end_value': lr / 100
    }
    
    # Network optimizer: optax.adam
    optimizer_network = {
        'name': 'adam',
        'learning_rate': lr_sch,
        'b1': 0.9,
        'b2': 0.99,
        'eps': 1e-15,
        'eps_root': 1e-15
    }
    
    # Appearance embedding optimizer: optax.adam
    optimizer_ae = {
        'name': 'adam',
        'learning_rate': 1e-4,
        'b1': 0.9,
        'b2': 0.99,
        'eps': 1e-8,
        'eps_root': 0
    }
    
    # Combined optimizer: optax.multi_transform
    combined_optimizer = {
        'transforms': {
            'network': optimizer_network,
            'ae': optimizer_ae
        },
        'param_labels': param_labels
    }
    
    return lr_sch, combined_optimizer

def compute_learning_rate(step, lr_sch):
    """
    Compute the current learning rate based on the schedule.
    """
    if lr_sch['staircase']:
        # Staircase decay: hold for transition_begin, then decay every transition_steps
        if step < lr_sch['transition_begin']:
            return lr_sch['init_value']
        else:
            # Number of decay steps
            decay_steps = (step - lr_sch['transition_begin']) // lr_sch['transition_steps']
            lr = lr_sch['init_value'] * (lr_sch['decay_rate'] ** decay_steps)
            return max(lr, lr_sch['end_value'])
    else:
        # Continuous decay (not used in the specified config)
        return lr_sch['init_value'] * (lr_sch['decay_rate'] ** (step / lr_sch['transition_steps']))

def apply_l2_decay(params, mask, l2_coeff):
    """
    Apply L2 regularization to parameters based on the mask.
    """
    l2_loss = 0.0
    for key, value in params.items():
        if key in mask:
            if isinstance(mask[key], bool):
                if mask[key]:
                    l2_loss += jnp.sum(value ** 2)
            elif isinstance(mask[key], dict):
                for sub_key, sub_mask in mask[key].items():
                    if sub_mask:
                        l2_loss += jnp.sum(params[key][sub_key] ** 2)
    return l2_loss * l2_coeff

def train_step(params, images, cameras, lr_sch, combined_optimizer, mask, l2_coeff):
    """
    Perform one training step.
    """
    step = combined_optimizer['step']
    
    # 1. Ray Sampling
    rays = sample_rays(images, cameras, num_rays=1024)
    
    # 2. Forward Pass
    rendered_images = render_rays(params, rays)
    
    # 3. Loss Computation
    # Using L2 loss for inverse rendering [S3] or weighted loss [S1]
    loss = jnp.mean((rendered_images - images) ** 2)
    
    # 4. Gradient Computation
    grad_fn = value_and_grad(lambda p: loss + apply_l2_decay(p, mask, l2_coeff))
    current_loss, grads = grad_fn(params)
    
    # 5. Parameter Update
    current_lr = compute_learning_rate(step, lr_sch)
    
    # Apply Adam update (simplified representation)
    # In practice, this would use the specific Adam implementation from optax
    updated_params = adam_update(params, grads, current_lr, b1=0.9, b2=0.99, eps=1e-15)
    
    # 6. Increment Step
    combined_optimizer['step'] = step + 1
    
    return updated_params, current_loss

def sample_rays(images, cameras, num_rays):
    """
    Sample rays from the images and cameras.
    """
    # Randomly select num_rays
    indices = jnp.random.choice(images.shape[0], num_rays, replace=False)
    rays = []
    for idx in indices:
        # Generate ray from camera pose and pixel coordinates
        ray = generate_ray(cameras[idx])
        rays.append(ray)
    return jnp.stack(rays)

def render_rays(params, rays):
    """
    Render rays using the radiance field.
    """
    # Positional encoding
    points = rays['points']
    directions = rays['directions']
    encoded_points = positional_encoding(points, num_bands=8)
    encoded_directions = positional_encoding(directions, num_bands=4)
    
    # MLP forward pass
    density, color = mlp_forward(params['network'], encoded_points, encoded_directions)
    
    # Volume rendering
    rendered_colors = volume_rendering(density, color, rays['t_near'], rays['t_far'])
    return rendered_colors

def positional_encoding(x, num_bands):
    """
    Apply positional encoding.
    """
    # Sine and cosine functions
    frequencies = 2 ** jnp.arange(num_bands) * jnp.pi
    encoded = jnp.concatenate([jnp.sin(f * x) for f in frequencies], axis=-1)
    return encoded

def volume_rendering(density, color, t_near, t_far):
    """
    Standard emission-absorption volume rendering.
    """
    # Sample points along the ray
    t_vals = jnp.linspace(t_near, t_far, num_samples)
    deltas = t_vals[1:] - t_vals[:-1]
    
    # Transmittance
    alpha = 1 - jnp.exp(-density * deltas)
    T = jnp.cumprod(1 - alpha + 1e-10, axis=-1)
    
    # Color
    weights = alpha * T
    rendered_color = jnp.sum(weights * color, axis=-2)
    return rendered_color
```

### Edge Cases and Pitfalls
*   **Learning Rate Schedule Delay:** `staircase=True` combined with `transition_begin=10_000` delays the first learning rate drop to step 20,000, as the initial LR is held for the first 10k steps before the staircase division triggers [S2, unofficial].
*   **L2 Decay on Encodings:** Applying L2 decay to position encoders or appearance embeddings is explicitly disabled to prevent divergence or suboptimal convergence during long training runs [S2, unofficial].
*   **Numerical Stability:** Small epsilon values ($1 \times 10^{-15}$) are used in Adam to prevent division by zero in the adaptive learning rate calculation [S2, unofficial].

## Subtopics

### [Gradient Descent Solver](3280-gradient-descent-solver.md)
The Gradient Descent Solver is a matrix-free optimization method used to update voxel grid parameters in differentiable volume rendering, such as in DiffVox. It supports both constant update rates and the Adam optimizer, providing stable behavior for ill-conditioned systems. It distinguishes itself from second-order methods like [Newton's Method](6442-newton-s-method.md) by avoiding Hessian computation, and from direct least-squares solvers like [CGLS Solver](3285-cgls-solver-conjugate-gradient-least-squares.md) by minimizing the residual via iterative gradient steps rather than solving normal equations directly.

### [BFGS Solver with Moreau Envelope](3781-bfgs-solver-with-moreau-envelope.md)
This method solves inverse problems, specifically tomographic reconstruction, by minimizing a composite objective function consisting of a data fidelity term and a regularizer. It sets itself apart by using the BFGS quasi-Newton algorithm to handle the non-smooth L1 regularization via its Moreau envelope, providing a differentiable approximation that allows second-order optimization steps. This contrasts with first-order Gradient Descent solvers and avoids the explicit projection steps required by constrained material solvers.

### [Training Protocol](4528-training-protocol.md)
The Training Protocol defines the standard optimization procedure for neural networks in differentiable volume rendering, encompassing optimizer settings, learning rate scheduling, and data augmentation strategies. It addresses the instability of training coordinate-based neural fields by providing a robust configuration for convergence, particularly when dealing with noisy real-world scan data or complex geometric priors. It sets itself apart from generic optimization loops by explicitly integrating domain-specific augmentations (such as Gaussian noise for point clouds) and specific regularization techniques (like CVT for discretization stability) into the core training loop.

### [Euclidean Projection for Material Constraints](7899-euclidean-projection-for-material-constraints.md)
This method enforces physical validity on material parameters during differentiable rendering optimization by projecting updated values back into their feasible domain after each optimizer step. It specifically addresses the problem of unconstrained gradient updates (e.g., from Adam) driving color or BSDF parameters outside physically plausible ranges, which causes numerical instability or non-physical reflectance. It differs from its siblings by being a post-update constraint enforcement mechanism rather than a solver or training schedule; it builds on [Optimization Configuration (Adam + Exponential Decay + Selective L2)](2133-optimization-configuration-adam-exponential-decay-selective-.md) by applying a hard boundary check after the parameter update.

## Background
*   **Origin:** The Adam optimizer was introduced by Kingma and Ba in 2014 [S3]. The specific configuration of Adam with exponential decay and selective L2 regularization is used in various neural radiance field and implicit surface reconstruction methods [S1][S2, unofficial][S3].
*   **History and Development:** The method has been widely adopted in differentiable volume rendering due to its effectiveness in training large neural networks [S1][S2, unofficial].
*   **Usage:** Used in neural RGB-D surface reconstruction [S1], JAX-based neural graphics primitives [S2, unofficial], and path-space differentiable rendering of implicit surfaces [S3].
