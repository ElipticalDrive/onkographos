# L2 Update
Also called: L2-norm minimization update step, PWLS Update

## Overview
The L2 Update is a single optimization step for differentiable volume rendering that minimizes the L2-norm of the residual between projected and measured data [S1, unofficial]. It supports subset-based processing to handle large datasets and provides two update paths: a standard backprojection update and a weighted update incorporating Poisson-statistics-based scaling [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** `projections` (measured data), `volume` (current volume estimate), `geometry` (projection geometry), `settings` (configuration flags `update_residual`, `studentst`), `num_subsets` (number of subsets) [S1, unofficial].
- **Outputs:** Updated `volume`, normalized residual norm `rnorm` [S1, unofficial].

**Data Structures:**
- `projections`: Array of measured projection values [S1, unofficial].
- `volume`: 3D array of voxel values [S1, unofficial].
- `geometry`: Object defining projection parameters [S1, unofficial].
- `residual`: Temporary array matching the shape of the current subset [S1, unofficial].
- `vol_tmp`, `bwp_w`: Temporary arrays matching the shape of `volume` [S1, unofficial].
- `fwp_w`: Temporary array matching the shape of the current subset [S1, unofficial].

**Steps:**
1. Retrieve `settings.update_residual` and `settings.studentst` [S1, unofficial].
2. Determine the number of subsets [S1, unofficial].
3. Compute the backprojection weight normalization factor by calling `_bp_norm(projections, volume, geometry)` [S1, unofficial].
4. Loop over subsets generated by `_subset_generator(projections, volume, geometry, copy=True)` [S1, unofficial]:
    a. Initialize `residual` as a contiguous zero array with the same shape as the current subset [S1, unofficial].
    b. Forward project the current `volume` into `residual` [S1, unofficial].
    c. Apply filters to `residual` [S1, unofficial].
    d. If `update_residual` is true, compute the root mean square of `residual` and add it to `rnorm` [S1, unofficial].
    e. If `studentst` is true, apply Student's T norm with degree 6 to `residual` [S1, unofficial].
    f. Scale `residual` by `bp_weight * num_subsets * 2` [S1, unofficial].
    g. Backproject `residual` into `volume` (`filtered=False`) [S1, unofficial].
    h. Return `rnorm / num_subsets` [S1, unofficial].
5. Retrieve `settings.update_residual` [S1, unofficial].
6. Determine the number of subsets [S1, unofficial].
7. Compute the backprojection weight normalization factor by calling `_bp_norm(projections, volume, geometry)` [S1, unofficial].
8. Loop over subsets generated by `_subset_generator(projections, volume, geometry, copy=True)` [S1, unofficial]:
    a. Initialize `vol_tmp` and `bwp_w` as zero arrays with the same shape as `volume` [S1, unofficial].
    b. Compute weights `fwp_w` as `exp(-subset)` [S1, unofficial].
    c. Backproject `fwp_w` into `bwp_w` (`filtered=False`) [S1, unofficial].
    d. Initialize `residual` as a contiguous zero array with the same shape as the current subset [S1, unofficial].
    e. Forward project the current `volume` into `residual` [S1, unofficial].
    f. Apply filters to `residual` [S1, unofficial].
    g. If `update_residual` is true, compute the root mean square of `residual` and add it to `rnorm` [S1, unofficial].
    h. Scale `residual` by `bp_weight * num_subsets * 2 * fwp_w` [S1, unofficial].
    i. Backproject `residual` into `vol_tmp` (`filtered=False`) [S1, unofficial].
    j. Normalize `bwp_w` by dividing by its maximum value [S1, unofficial].
    k. Clamp `bwp_w` values below `1e-2` to `1e-2` [S1, unofficial].
    l. Update `volume` by adding `vol_tmp` divided by `bwp_w` [S1, unofficial].
    m. Return `rnorm / num_subsets` [S1, unofficial].

**Pseudocode:**
```python
def l2_update_standard(projections, volume, geometry, settings, num_subsets):
    """Standard L2-norm update path."""
    rnorm = 0.0
    bp_weight = _bp_norm(projections, volume, geometry)
    subsets = _subset_generator(projections, volume, geometry, copy=True)
    
    for subset in subsets:
        residual = [0.0] * len(subset)
        residual = _forward_project(volume, geometry)
        residual = _apply_filters(residual)
        
        if settings.update_residual:
            rnorm += math.sqrt(sum(r**2 for r in residual) / len(residual))
            
        if settings.studentst:
            residual = _apply_student_t_norm(residual, degree=6)
            
        residual = [r * bp_weight * num_subsets * 2 for r in residual]
        volume = _backproject(residual, geometry, filtered=False)
        
    rnorm = rnorm / num_subsets
    return rnorm

def l2_update_weighted(projections, volume, geometry, settings, num_subsets):
    """Weighted L2-norm update path with Poisson scaling."""
    rnorm = 0.0
    bp_weight = _bp_norm(projections, volume, geometry)
    subsets = _subset_generator(projections, volume, geometry, copy=True)
    
    for subset in subsets:
        vol_tmp = [0.0] * len(volume)
        bwp_w = [0.0] * len(volume)
        fwp_w = [math.exp(-s) for s in subset]
        bwp_w = _backproject(fwp_w, geometry, filtered=False)
        
        residual = [0.0] * len(subset)
        residual = _forward_project(volume, geometry)
        residual = _apply_filters(residual)
        
        if settings.update_residual:
            rnorm += math.sqrt(sum(r**2 for r in residual) / len(residual))
            
        residual = [r * bp_weight * num_subsets * 2 * f for r, f in zip(residual, fwp_w)]
        vol_tmp = _backproject(residual, geometry, filtered=False)
        
        max_bwp = max(bwp_w)
        bwp_w = [b / max_bwp for b in bwp_w]
        bwp_w = [max(b, 1e-2) for b in bwp_w]
        volume = [v + vt / bw for v, vt, bw in zip(volume, vol_tmp, bwp_w)]
        
    rnorm = rnorm / num_subsets
    return rnorm
```

**Parameters:**
- `update_residual`: Boolean flag to update the residual norm [S1, unofficial].
- `studentst`: Boolean flag to apply Student's T norm [S1, unofficial].
- `num_subsets`: Number of subsets to process [S1, unofficial].
- `degree`: Degrees of freedom for Student's T distribution (default 6) [S1, unofficial].

**Edge Cases and Pitfalls:**
- Precision issues may arise when computing `exp(-subset)` for large negative values [S1, unofficial].
- Clamping `bwp_w` to `1e-2` prevents division by zero but may introduce bias in low-weight regions [S1, unofficial].
- The method assumes that the `geometry` object provides accurate projection parameters [G].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of voxels and projections, scaled by the number of subsets [G].
- **Memory Complexity:** Linear with respect to the number of voxels and projections, due to temporary arrays [G].
- **Measured Performance:** Not given in the sources [S1, unofficial].
- **Scaling:** Scales well with the number of subsets, as each subset can be processed independently [G].
- **Strengths:** Handles large datasets efficiently through subset processing; incorporates Poisson statistics for improved accuracy [S1, unofficial].
- **Limitations:** Requires careful tuning of parameters such as `num_subsets` and `degree`; may be sensitive to noise in the projections [G].
- **When to Use:** Suitable for differentiable volume rendering tasks where Poisson statistics are relevant and large datasets need to be processed efficiently [G].
- **When Not to Use:** Not suitable for real-time applications due to the computational cost of forward and backprojection operations [G].
