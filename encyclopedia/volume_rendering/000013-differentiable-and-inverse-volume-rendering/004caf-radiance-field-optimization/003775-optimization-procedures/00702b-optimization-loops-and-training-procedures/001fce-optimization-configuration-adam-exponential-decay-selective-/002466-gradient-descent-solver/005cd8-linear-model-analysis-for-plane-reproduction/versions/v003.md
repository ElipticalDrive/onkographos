# Linear Model Analysis for Plane Reproduction
Also called: Geometric Initialization Justification, Theorem 1 Analysis

## Overview
This analysis provides a theoretical justification for the loss function's ability to converge to the signed distance function (SDF) of a plane when input data is sampled from a plane, using a linear model $f(x; w) = w^T x$ [S1, unofficial]. It differs from fixed volumetric grids (like RGVF) by being data-dependent and avoiding cubic-size memory requirements and interpolation schemes [S1, unofficial].

## How it works
**Inputs:**
- Point cloud $X = \{x_i\}_{i \in I}$ in $\mathbb{R}^d$, where $x_i = y_i + \epsilon_i$ [S1, unofficial]. $y_i$ spans a $(d-1)$-dimensional hyperplane $H$ containing the origin, and $\epsilon_i$ are small deviations with $\|\epsilon_i\| < \delta$ [S1, unofficial].
- Regularization parameter $\lambda$ [S1, unofficial].

**Outputs:**
- Weight vector $w$ (or $q$ in transformed coordinates) representing the approximate SDF normal [S1, unofficial].

**Data Structures:**
- Covariance matrix components: Eigenvalues $\lambda_j$ and eigenvectors $u_j$ from spectral decomposition [S1, unofficial].
- Transformed coordinates $q = U^T w$ [S1, unofficial].

**Steps:**
1. **Spectral Decomposition:** Compute the spectral decomposition of the covariance matrix of the point cloud:
   $$ \sum_{i \in I} x_i x_i^T = U D U^T $$
   where $U = (u_1, \dots, u_d)$ is the orthogonal matrix of eigenvectors and $D = \text{diag}(\lambda_1, \dots, \lambda_d)$ with $0 \le \lambda_1 < \lambda_2 \le \dots \le \lambda_d$ [S1, unofficial].
2. **Coordinate Transformation:** Change coordinates to $q = U^T w$ [S1, unofficial]. The loss function becomes diagonalized:
   $$ \ell(q) = q^T D q + \lambda (\|q\| - 1)^2 $$
3. **Critical Point Identification:** Find critical points by setting the gradient to zero [S1, unofficial]. For $q \neq 0$, critical points satisfy:
   $$ 2\lambda(\|q\| - 1) = -\lambda_j $$
   This yields critical points $q_j = \pm \sqrt{1 - \frac{\lambda_j}{2\lambda}} e_j$ for $j \in [d]$, and $q=0$, where $e_j$ is the $j$-th standard basis vector [S1, unofficial].
4. **Global Minima Selection:** If $\lambda > \frac{\lambda_1}{2}$, the global minima are $\pm q = \pm \sqrt{1 - \frac{\lambda_1}{2\lambda}} e_1$ [S1, unofficial]. These correspond to the approximate SDF to the plane [S1, unofficial].

**Formulas:**
- **Linear Loss:**
   $$ \ell(w) = \sum_{i \in I} (w^T x_i)^2 + \lambda (\|w\| - 1)^2 $$
   This is a simplified version of the general loss using squared error and removing normal data terms [S1, unofficial].
- **Gradient in Transformed Coordinates:**
   $$ \nabla_q \ell(q)^T = 2(D + 2\lambda(\|q\| - 1)I)q $$
- **Hessian in Transformed Coordinates:**
   $$ \nabla^2_q \ell(q) = 2D + 4\lambda(\|q\| - 1)I + 8\lambda q q^T $$

**Parameters:**
- $\lambda$: Regularization parameter. Must satisfy $\lambda > \frac{\lambda_1}{2}$ for the global minima to exist in the form of the SDF [S1, unofficial].

**Edge Cases and Pitfalls:**
- If $\lambda \le \frac{\lambda_1}{2}$, the term $1 - \frac{\lambda_1}{2\lambda}$ becomes non-positive, and the global minima corresponding to the SDF do not exist in this form [S1, unofficial].
- The parameter $\lambda$ must be chosen sufficiently large compared to the deviation from planarity $\delta$ [S1, unofficial].
- The analysis assumes the point cloud is sampled approximately from a plane [S1, unofficial]. In the general MLP case, this analysis holds locally, where the deviation from planarity is quantified by surface curvature [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def linear_model_analysis(point_cloud, lambda_reg):
    """
    Analyze linear model for plane reproduction.
    
    Args:
    point_cloud: numpy array of shape (N, d)
    lambda_reg: float, regularization parameter
    
    Returns:
    w_opt: numpy array of shape (d,), optimal weight vector
    """
    # Step 1: Spectral Decomposition
    # Compute covariance matrix: sum_{i in I} x_i x_i^T
    cov_matrix = point_cloud.T @ point_cloud
    # Eigen decomposition (eigh returns sorted eigenvalues ascending)
    eigenvalues, eigenvectors = np.linalg.eigh(cov_matrix)
    
    lambda_1 = eigenvalues[0]
    U = eigenvectors
    D = np.diag(eigenvalues)
    
    # Edge case check
    if lambda_reg <= lambda_1 / 2:
        raise ValueError("Lambda must be greater than lambda_1 / 2 for global minima to exist.")
    
    # Step 2 & 3: Identify Global Minima in Transformed Coordinates
    # The global minima in transformed coordinates are +/- q_1
    # q_1 = sqrt(1 - lambda_1 / (2 * lambda_reg)) * e_1
    factor = np.sqrt(1 - lambda_1 / (2 * lambda_reg))
    q_opt = np.zeros(point_cloud.shape[1])
    q_opt[0] = factor  # Corresponds to e_1
    
    # Step 4: Transform back to original coordinates
    # w = U q
    w_opt = U @ q_opt
    
    return w_opt
```

## Subtopics

### Liapunov Function Convergence Analysis
A theoretical proof technique using a Liapunov function to demonstrate that continuous gradient flow converges to global minima of the loss function for plane reproduction in non-noisy data [S1, unofficial]. It initializes $q_0$ randomly from a continuous probability distribution in $\mathbb{R}^d$, ensuring with probability 1 that $q_0$ is not orthogonal to $e_1$ [S1, unofficial]. It selects $v$ such that $v^T q_0 > 0$, where $v = \pm \sqrt{1 - \frac{\lambda_1}{2\lambda}} e_1$ from Theorem 1 [S1, unofficial]. It verifies Liapunov conditions on the domain $\Omega = \{q \in \mathbb{R}^d \mid e_1^T q > 0\}$: Energy ($h(v)=0$ and $h(q)>0$ for $q \in \Omega \setminus \{v\}$), Decreasing ($\nabla h(q) \cdot \frac{dq}{dt}(q) < 0$ for $q \in \Omega \setminus \{v\}$), and Bounded (level-sets $\{q \mid h(q)=c\}$ are bounded) [S1, unofficial]. The Liapunov function is $h(q) = \frac{\|q - v\|^2}{1 + \|q\|^2}$ [S1, unofficial]. The derivative proves the decreasing property: $\nabla h \cdot \frac{dq}{dt} = -\frac{8 v^T q}{(1+\|q\|^2)^2} (q^T D q + \lambda(\|q\|^2 - 1)) \le 0$, using $v^T q = q_1 > 0$ and $D$ positive semi-definite [S1, unofficial]. It concludes that $q(t) \to q^*$ as $t \to \infty$, where $q^*$ is a global minimum of the loss, and the limit model approximates the signed distance function to the hyperplane [S1, unofficial].

## Background
Originated in the paper "Implicit Geometric Regularization for Learning Shapes" [S1, unofficial]. The analysis is presented as Theorem 1 and Theorem 2, justifying the use of the Eikonal regularization term alone for implicitly regularizing the zero level set [S1, unofficial]. It contrasts with previous works that used Eikonal regularization in combination with other explicit reconstruction terms [S1, unofficial]. The analysis uses perturbation theory for eigenvalues and eigenvectors of Hermitian matrices [S1, unofficial].
