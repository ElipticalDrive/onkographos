# Gradient-based Optimization with Surrogate Function

Also called: Iterative optimization using surrogate function, NGD-based optimization

## Overview
This method estimates spatially varying extinction coefficients $\beta$ by minimizing a cost function $E(\beta)$ that fits a forward-model rendering to image measurements, using a surrogate function to avoid computing the full Jacobian per gradient step [S1, unofficial]. It sets itself apart from direct Jacobian computation by decoupling the expensive forward-model rendering (FMC) from the gradient descent updates, requiring only one FMC rendering per block of $NGD$ gradient steps rather than $N_{voxels}$ [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** Measured images $\{i_{c,\mu}^{measured}\}$ for views $c=1 \dots N_{views}$ and channels $\mu \in \{R, G, B\}$; camera parameters; physical constants ($\sigma_{\mu}^{aerosol}, \beta_{\mu}^{air}$); regularization weight $\eta$; step size $\Delta$; number of gradient steps per surrogate update $NGD$ [S1, unofficial].
- **Outputs:** Estimated aerosol extinction field $\hat{\beta}^{aerosol}$ [S1, unofficial].

**Data Structures:**
- $\beta^{(q)}$: 3D grid of aerosol extinction coefficients at iteration $q$ [S1, unofficial].
- $j_{all}^{(q)}$: Field of radiance values $\{j_{c,\mu}^{(q)}\}$ computed via Forward Monte Carlo (FMC) at iteration $q$ [S1, unofficial].
- $Q_c$: Diagonal weighting matrix for view $c$, where element $(k,k)$ is $R_{c,p}^{(q)}$, the number of rays passing through voxel $k$ in view $c$ [S1, unofficial].
- $L$: 3D Laplacian matrix [S1, unofficial].
- $W$: Diagonal altitude-dependent weight matrix [S1, unofficial].
- $M_c$: Sun-mask binary matrix for view $c$ [S1, unofficial].

**Formulas:**
1.  **Channel Extinction:**
    $$ \beta_{\mu} = \beta_{\mu}^{air} + \tilde{\sigma}_{\mu} \beta_{G}^{aerosol} $$
    where $\tilde{\sigma}_{\mu} = \sigma_{\mu}^{aerosol} / \sigma_{G}^{aerosol}$ [S1, unofficial].

2.  **Cost Function:**
    $$ E(\beta) = \sum_{c=1}^{N_{views}} \sum_{\mu=R,G,B} M_c \left[ i_{c,\mu}^{measured} - i_c(\beta_{\mu}) \right]^2 + \eta \Psi(\beta_{G}^{aerosol}) $$
    where $i_c(\beta_{\mu})$ is the modeled intensity [S1, unofficial].

3.  **Regularization Term:**
    $$ \Psi(\beta_{G}^{aerosol}) = \| W \beta_{G}^{aerosol} \|^2 $$
    Gradient: $2 L^T W^T W \beta_{G}^{aerosol}$ [S1, unofficial].

4.  **Gradient of Cost Function:**
    $$ \frac{\partial E}{\partial \beta} = 2 \sum_{c=1}^{N_{views}} \sum_{\mu=R,G,B} \tilde{\sigma}_{\mu} Q_c M_c J_c(\beta_{\mu}) M_c \left[ i_c(\beta_{\mu}) - i_{c,\mu}^{measured} \right] + \eta \frac{\partial \Psi}{\partial \beta} $$
    When $j_{all}$ is fixed, the Jacobian $J_c$ degenerates to a simple calculation based on the surrogate field [S1, unofficial].

5.  **Surrogate Update:**
    $$ \hat{\beta}^{(q+1)} = \arg \min_{\beta \in C} E(\beta | j_{all}^{(q)}) $$
    This minimization is performed using Gradient Descent steps [S1, unofficial].

6.  **Gradient Descent Step:**
    $$ \beta_{d+1} = \beta_d - \Delta \frac{\partial E(\beta | j_{all}^{(q)})}{\partial \beta} $$
    where $d$ indexes the gradient descent step within the current surrogate block [S1, unofficial].

7.  **Camera Noise Simulation (for input preparation):**
    $$ i_{c,\mu}^{measured} \leftarrow \left( i_{c,\mu}^{measured} + o_{noise} \right) \cdot \frac{2^{10}}{\max(\{M_c \cdot i_{c,\mu}^{measured}\})} $$
    Clipped to $[0, 1024]$ and rounded. $o_{noise}$ is white noise with standard deviation 0.4 [S1, unofficial].

**Parameters:**
- $\Delta$ (Step size): $10^{-3}$ [S1, unofficial].
- $NGD$ (Gradient steps per surrogate update): $5$ [S1, unofficial].
- $\eta$ (Regularization weight): Not given in the sources.

**Pseudocode:**
```python
def gradient_based_optimization_with_surrogate(measured_images, camera_params, physical_constants, 
                                               eta, delta, ngd, max_iterations):
    """
    Estimates aerosol extinction beta using surrogate function optimization.
    """
    # Precompute physical constants
    sigma_tilde = {mu: physical_constants['sigma_aerosol'][mu] / physical_constants['sigma_aerosol']['G'] 
                   for mu in ['R', 'G', 'B']}
    
    # Precompute masks and weighting matrices
    sun_masks = {c: compute_sun_masks(camera_params[c]) for c in range(len(camera_params))}
    weighting_matrices = {c: compute_weighting_matrices(camera_params[c]) for c in range(len(camera_params))}
    laplacian_matrix = compute_3d_laplacian()
    altitude_weights = compute_altitude_weights()
    
    # Initialize beta (e.g., null initialization)
    beta = zeros_like(beta_grid)
    
    q = 0
    while q < max_iterations:
        # 1. Forward Model Rendering (FMC) to compute surrogate field
        # This is not an inverse problem; complexity does not increase with N_voxels
        j_all = fmc_trace(beta, camera_params, physical_constants)
        
        # 2. Gradient Descent Block
        for d in range(ngd):
            # Compute gradient using fixed surrogate field j_all
            gradient = compute_gradient_surrogate(
                beta=beta, 
                j_all=j_all, 
                measured_images=measured_images, 
                sun_masks=sun_masks, 
                weighting_matrices=weighting_matrices, 
                sigma_tilde=sigma_tilde,
                laplacian_matrix=laplacian_matrix,
                altitude_weights=altitude_weights,
                eta=eta
            )
            
            # Update beta
            beta = beta - delta * gradient
            
        # 3. Increment iteration counter
        q += 1
        
    return beta

def compute_gradient_surrogate(beta, j_all, measured_images, sun_masks, weighting_matrices, 
                               sigma_tilde, laplacian_matrix, altitude_weights, eta):
    """
    Computes gradient of E(beta | j_all) where j_all is fixed.
    """
    gradient = zeros_like(beta)
    
    # Regularization gradient: 2 * L^T * W^T * W * beta
    reg_gradient = 2.0 * mat_vec_mul(laplacian_matrix.T, mat_vec_mul(altitude_weights.T, mat_vec_mul(altitude_weights, beta)))
    
    for c in range(len(measured_images)):
        for mu in ['R', 'G', 'B']:
            # Access surrogate field j_all[c][mu]
            j_c_mu = j_all[c][mu]
            
            # Compute modeled intensity i_c from j_all (simplified mapping)
            i_c_modeled = map_radiance_to_intensity(j_c_mu)
            
            # Residual
            residual = i_c_modeled - measured_images[c][mu]
            
            # Masking
            masked_residual = elementwise_mul(sun_masks[c], residual)
            
            # Weighting
            Q_c = weighting_matrices[c]
            
            # Jacobian term degenerates when j_all is fixed
            # J_c(beta | j_c_mu) is a simple calculation based on the fixed field
            jacobian_term = compute_degenerate_jacobian_term(beta, j_c_mu, Q_c, sun_masks[c])
            
            # Accumulate gradient
            # Term: 2 * sigma_tilde * Q_c * M_c * J_c * M_c * residual
            masked_res = elementwise_mul(sun_masks[c], residual)
            jac_res = mat_vec_mul(jacobian_term, masked_res)
            weighted_jac = elementwise_mul(Q_c, elementwise_mul(sun_masks[c], jac_res))
            
            gradient += 2.0 * sigma_tilde[mu] * weighted_jac
            
    # Add regularization gradient
    gradient += eta * reg_gradient
    
    return gradient

def fmc_trace(beta, camera_params, physical_constants):
    """
    Computes radiance field j_all using Forward Monte Carlo (FMC).
    """
    j_all = {}
    for c in range(len(camera_params)):
        j_all[c] = {}
        for mu in ['R', 'G', 'B']:
            j_all[c][mu] = trace_rays_through_medium(beta, camera_params[c], physical_constants[mu])
    return j_all

def compute_sun_masks(camera):
    """Returns binary mask M_c for pixels around the Sun."""
    return create_binary_mask(camera.sun_position, camera.lens_flare_radius)

def compute_weighting_matrices(camera):
    """Returns diagonal matrix Q_c where Q_c[k,k] = number of rays through voxel k."""
    ray_counts = count_ray_voxel_intersections(camera, beta)
    return create_diagonal_matrix(ray_counts)

def compute_3d_laplacian():
    """Returns 3D Laplacian matrix L."""
    return build_laplacian_matrix(grid_shape)

def compute_altitude_weights():
    """Returns diagonal matrix W with altitude-dependent weights."""
    altitudes = get_voxel_altitudes()
    return create_diagonal_matrix(altitude_function(altitudes))

def zeros_like(array):
    """Returns an array of zeros with the same shape as array."""
    return [0.0] * len(array)

def elementwise_mul(a, b):
    """Element-wise multiplication of two arrays."""
    return [a[i] * b[i] for i in range(len(a))]

def mat_vec_mul(matrix, vector):
    """Matrix-vector multiplication."""
    result = [0.0] * len(matrix)
    for i in range(len(matrix)):
        for j in range(len(vector)):
            result[i] += matrix[i][j] * vector[j]
    return result

def map_radiance_to_intensity(radiance_field):
    """Converts radiance field to intensity values."""
    return scale_and_clip(radiance_field, min_val=0.0, max_val=1.0)

def compute_degenerate_jacobian_term(beta, j_c_mu, Q_c, M_c):
    """
    Computes the degenerate Jacobian-vector product when j_all is fixed.
    The exact degenerate form is derived from the fixed radiance field geometry.
    """
    # Implementation detail: This typically involves ray-voxel intersection counts
    # or similar geometric factors derived from the FMC step.
    return geometric_weighting_from_radiance(j_c_mu, Q_c, M_c)

def preprocess_measurements(measured_images, sun_masks):
    """Applies camera noise simulation to input images."""
    o_noise_std = 0.4
    processed = {}
    for c in range(len(measured_images)):
        processed[c] = {}
        for mu in ['R', 'G', 'B']:
            img = measured_images[c][mu]
            masked_max = max(elementwise_mul(sun_masks[c], img))
            noise = [random.gauss(0, o_noise_std) for _ in img]
            scaled = elementwise_mul([x + y for x, y in zip(img, noise)], 1024.0 / masked_max)
            processed[c][mu] = [max(0.0, min(1024.0, round(x))) for x in scaled]
    return processed
```

**Edge Cases and Pitfalls:**
- **Sun Masking:** Pixels around the Sun are masked ($M_c$) because Monte Carlo estimates have high variance due to forward scattering phase function sampling. Additionally, physical sun occluders cause saturation [S1, unofficial].
- **Ill-conditioning:** Voxels near cameras have unstable $\beta$ estimates because they affect more pixels, leading to higher gradient magnitudes. This is solved by the diagonal weighting matrix $Q_c$, where element $(k,k)$ is the number of rays passing through voxel $k$ [S1, unofficial].
- **Convergence:** Starting from $\beta^{aerosol}=0$, satisfactory convergence occurs after several hundred iterations [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Direct Jacobian computation requires $O(N_{voxels})$ FMC renderings per iteration, which is computationally expensive. The surrogate approach requires only one FMC rendering per $NGD$ gradient descent steps, significantly reducing cost [S1, unofficial].
- **Memory Complexity:** Requires storing the radiance field $j_{all}$ and the extinction field $\beta$. The weighting matrices $Q_c$ are diagonal, requiring $O(N_{voxels})$ memory per view [S1, unofficial].
- **Performance:** On Atm1 (Haze blobs), $\delta_{mass} = 1.7\%$ (null init) vs $3.4\%$ (single scattering init). On Atm4 (Haze front), $\delta_{mass} = 14\%$ (null init) vs $4.1\%$ (single scattering init) [S1, unofficial].
- **Strengths:** Effective gradient calculation without $N_{voxels}$ rendering processes; handles ill-conditioning via weighting [S1, unofficial].
- **Limitations:** Requires careful tuning of $\Delta$ and $NGD$; sensitive to noise in forward scattering regions (mitigated by sun mask) [S1, unofficial].

## Background
This method was developed for in-situ multi-scattering tomography, specifically for recovering aerosol distributions from multi-view images [S1, unofficial]. It builds on the concept of surrogate functions to avoid the computational burden of direct Jacobian computation in heterogeneous media [S1, unofficial]. The method was compared against a baseline reconstruction using a single scattering approximation [S1, unofficial].
