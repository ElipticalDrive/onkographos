# Moment-Damped Levenberg-Marquardt Optimizer

Also called: Hybrid LM-Adam Optimizer, Moment-LM Optimizer, TurboGS Optimizer, hybrid moment-damped LM, sparse moment-damped Levenberg-Marquardt

## Overview
A hybrid optimization strategy for sparse-pixel training that partitions Gaussian parameters into geometry and base appearance blocks, solving them via small Levenberg-Marquardt (LM) systems with Adam-style moment damping, while updating Higher-order Spherical Harmonic (SH) coefficients separately with Adam [S1, unofficial]. It sets itself apart from its parent [Gradient Descent Solver](3280-gradient-descent-solver.md) by introducing Hessian-informed updates for geometry and appearance to stabilize convergence under sparse supervision [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Current Gaussian parameters $\theta$, Adam first moment $m$, Adam second moment $v$, Jacobians $J_g$ and $J_a$ for geometry and base appearance blocks, loss gradient moments $m_{SH}$ for SH coefficients [S1, unofficial].
- Output: Parameter updates $\Delta g$, $\Delta a$, and $\Delta \theta_{SH}$ [S1, unofficial].

**Data Structures:**
- Gaussian parameters $\theta$ are partitioned into:
  - Geometry block $g \in \mathbb{R}^{10}$: position (3), scale (3), rotation (4 quaternion) [S1, unofficial].
  - Base appearance block $a \in \mathbb{R}^{4}$: RGB DC coefficients (3), opacity (1) [S1, unofficial].
  - Higher-order SH coefficients: updated separately [S1, unofficial].

**Parameters:**
- $\epsilon$: Small constant for numerical stability (standard Adam value, e.g., $10^{-8}$) [G].
- $\eta$: Learning rate for Adam update of SH coefficients [G].
- $\sqrt{v}$: Element-wise square root of the second moment vector $v$, serving as an adaptive diagonal damping term [S1, unofficial].

**Steps:**
1. **Partition Parameters:** Separate $\theta$ into geometry block $g$ and base appearance block $a$ [S1, unofficial].
2. **Compute Jacobians:** Calculate $J_g$ and $J_a$ with respect to the rendered loss [S1, unofficial].
3. **Solve LM System for $g$ and $a$:** For each block $b \in \{g, a\}$, solve the linear system:
   $$ (J_b^\top J_b + \text{diag}(\sqrt{v_b} + \epsilon)) \Delta b = -m_b $$
   where $m_b$ is the Adam first moment for block $b$, and $v_b$ is the Adam second moment for block $b$ [S1, unofficial]. The term $\text{diag}(\sqrt{v_b} + \epsilon)$ acts as a moment-based diagonal damping term to stabilize sparse gradients [S1, unofficial].
4. **Solve via Cholesky:** Perform Cholesky decomposition on the matrix $(J_b^\top J_b + \text{diag}(\sqrt{v_b} + \epsilon))$ to solve for $\Delta b$ efficiently [S1, unofficial].
5. **Update SH Coefficients:** Update higher-order SH coefficients $\theta_{SH}$ using Adam-style moment damping [S1, unofficial].
6. **Apply Updates:** Apply $\Delta g$, $\Delta a$, and $\Delta \theta_{SH}$ to the respective parameters [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def moment_damped_lm_update(g, a, theta_sh, m_g, m_a, m_sh, v_g, v_a, v_sh, J_g, J_a, eta, epsilon, step_count):
    """
    Perform one step of Moment-Damped Levenberg-Marquardt optimization.
    
    Args:
        g: Geometry parameters (R^10)
        a: Base appearance parameters (R^4)
        theta_sh: Higher-order SH coefficients
        m_g, m_a, m_sh: Adam first moments for respective blocks
        v_g, v_a, v_sh: Adam second moments for respective blocks
        J_g, J_a: Jacobians of loss w.r.t g and a
        eta: Learning rate for SH update
        epsilon: Small constant for numerical stability
        step_count: Current training step for bias correction
        
    Returns:
        Updated g, a, theta_sh
    """
    # Step 1: Solve LM system for geometry block g
    H_g = J_g.T @ J_g
    damping_g = np.sqrt(v_g) + epsilon
    A_g = H_g + np.diag(damping_g)
    b_g = -m_g
    L_g = np.linalg.cholesky(A_g)
    y_g = np.linalg.solve(L_g, b_g)
    delta_g = np.linalg.solve(L_g.T, y_g)
    
    # Step 2: Solve LM system for base appearance block a
    H_a = J_a.T @ J_a
    damping_a = np.sqrt(v_a) + epsilon
    A_a = H_a + np.diag(damping_a)
    b_a = -m_a
    L_a = np.linalg.cholesky(A_a)
    y_a = np.linalg.solve(L_a, b_a)
    delta_a = np.linalg.solve(L_a.T, y_a)
    
    # Step 3: Update SH coefficients using Adam
    beta1, beta2 = 0.9, 0.999
    m_hat_sh = m_sh / (1 - beta1**step_count)
    v_hat_sh = v_sh / (1 - beta2**step_count)
    delta_sh = -eta * (m_hat_sh / (np.sqrt(v_hat_sh) + epsilon))
    
    # Step 4: Apply updates
    g_new = g + delta_g
    a_new = a + delta_a
    theta_sh_new = theta_sh + delta_sh
    
    return g_new, a_new, theta_sh_new
```

**Edge Cases and Pitfalls:**
- Ignoring SH cross-parameter correlations is a practical trade-off; joint optimization would substantially increase Jacobian size and memory overhead [S1, unofficial].
- Sparse gradients can be unstable; the moment-based damping $\sqrt{v}$ is critical for stabilization [S1, unofficial].

## Subtopics

### Hybrid Optimizer
A tailored optimizer that couples Hessian-informed updates with Adam moment damping to stabilize and improve convergence under sparse supervision [S1, unofficial]. It integrates Adam moments with Hessian-informed updates [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Solving small LM systems via Cholesky decomposition is efficient for the fixed small block sizes (10 and 4 dimensions) [S1, unofficial]. The overall complexity is dominated by Jacobian computation and Cholesky factorization, which is lightweight for these small blocks [S1, unofficial].
- **Memory Complexity:** Low memory overhead compared to full Newton methods due to block partitioning and ignoring SH correlations [S1, unofficial].
- **Measured Performance:** On Mip-NeRF 360, Moment-LM achieves 29.50dB PSNR vs 29.42dB for Sparse Adam-only, with identical training time (90s) and NGS (0.64M) [S1, unofficial].
- **Scaling:** Suitable for sparse-pixel training scenarios where full dense optimization is too costly [S1, unofficial].
- **Strengths:** Higher PSNR/SSIM, lower LPIPS, and more stable high-frequency details compared to sparse Adam-only optimization under similar training times [S1, unofficial].
- **Limitations:** Trade-off in accuracy due to ignoring SH cross-parameter correlations [S1, unofficial].

## Background
Originated in TurboGS: Accelerating 3D Gaussian Splatting via Error-Guided Sparse Pixel Sampling and Optimization [S1, unofficial]. It is used in the context of 3D Gaussian Splatting (3DGS) to accelerate training while maintaining or improving rendering quality [S1, unofficial].
