# ADMM Solver
Also called: Alternating Direction Method of Multipliers, Standard ADMM

## Overview
The ADMM Solver is a proximal algorithm used to solve separable minimization problems of the form $\min_x f(x) + g(x)$ or $\min_x f(x) + g(Dx)$, where $f(x)$ is a data fidelity term and $g(x)$ is a prior or regularization term [S1, unofficial]. It sets itself apart from its parent [Normal Equations-based Solver](5483-normal-equations-based-solver.md) by splitting composite objectives into simpler sub-problems that are solved via proximal operators or constrained minimization [S1, unofficial].

## How it works
**Inputs:**
- Objective functions $f(x)$ and $g(\cdot)$, where $f$ is typically a quadratic data term (e.g., $\|Ax - p\|_2^2$) and $g$ is a convex prior (e.g., $\ell_1$ norm or Total Variation) [S1, unofficial].
- Linear operator $D$ (identity $I$ for standard form, or a transform matrix for generalized form) [S1, unofficial].
- Penalty parameter $\rho > 0$ [S1, unofficial].
- Proximal parameter $\mu$ (required for Linearized ADMM, optional for Standard ADMM depending on implementation) [S2].
- Maximum iterations $T$ or convergence tolerance $\epsilon$ [G].

**Outputs:**
- Reconstructed volume $x$ [S1, unofficial].

**Data Structures:**
- $x \in \mathbb{R}^n$: Current primal variable (reconstruction).
- $z \in \mathbb{R}^m$: Auxiliary variable for the prior term.
- $u \in \mathbb{R}^m$: Scaled dual variable (Lagrange multiplier).
- $y \in \mathbb{R}^m$: Dual variable (used in Linearized ADMM).

**Numbered Steps (Standard ADMM for $\min_x f(x) + g(Dx)$):**
1. Initialize $x^0, z^0, u^0$.
2. For $k = 0$ to $T-1$:
   a. **x-update:** Solve $x^{k+1} = \operatorname{argmin}_x \left( f(x) + \frac{\rho}{2} \|Dx - z^k + u^k\|_2^2 \right)$ [S1, unofficial].
   b. **z-update:** Solve $z^{k+1} = \operatorname{argmin}_z \left( g(z) + \frac{\rho}{2} \|Dx^{k+1} - z + u^k\|_2^2 \right)$ [S1, unofficial].
   c. **u-update:** $u^{k+1} = u^k + Dx^{k+1} - z^{k+1}$ [S1, unofficial].
3. Return $x^T$.

**Special Case: Standard Form ($D=I$):**
When $D=I$, the updates simplify to proximal operators:
1. $x^{k+1} = \operatorname{prox}_{\rho f}(x^k - u^k)$
2. $z^{k+1} = \operatorname{prox}_{\rho g}(x^{k+1} + u^k)$
3. $u^{k+1} = u^k + x^{k+1} - z^{k+1}$ [S1, unofficial].

**Pseudocode (Standard ADMM with CG for x-update):**

```python
def admm_solver(A, p, D, prox_f, prox_g, rho, max_iter, tol):
    """
    Solves min_x f(x) + g(Dx) using Standard ADMM.
    Assumes f(x) = 0.5 * ||Ax - p||^2.
    prox_f and prox_g are functions implementing the proximal operators.
    """
    n = len(p)
    m = len(p) # Assuming D is square/compatible for simplicity
    x = [0.0] * n
    z = [0.0] * m
    u = [0.0] * m
    z_prev = [0.0] * m

    for k in range(max_iter):
        # x-update: argmin_x f(x) + (rho/2) * ||Dx - z + u||^2
        # For f(x) = 0.5 * ||Ax - p||^2, this solves (A^T A + rho D^T D) x = A^T p + rho D^T (z - u)
        # Solved via Conjugate Gradient as in RTK [S1, unofficial]
        rhs = [0.0] * n
        for i in range(n):
            rhs[i] = mat_vec_mul(A.T, p)[i] + rho * mat_vec_mul(D.T, [z[j] - u[j] for j in range(m)])[i]
        H = lambda v: mat_vec_mul(A.T, mat_vec_mul(A, v)) + rho * mat_vec_mul(D.T, mat_vec_mul(D, v))
        x = conjugate_gradient_solve(H, rhs, max_inner=100)

        # z-update: prox_{rho^{-1} g}(D x + u) [S1, unofficial]
        Dz_plus_u = mat_vec_mul(D, x)
        for i in range(m):
            Dz_plus_u[i] += u[i]
        z = prox_g(Dz_plus_u, 1.0 / rho)

        # u-update: u + Dx - z [S1, unofficial]
        Dx = mat_vec_mul(D, x)
        for i in range(m):
            u[i] = u[i] + Dx[i] - z[i]

        # Convergence check [S3]
        if k > 0:
            r_pri = norm([x[i] - z[i] for i in range(min(n, m))])
            r_dual = norm([z[i] - z_prev[i] for i in range(m)])
            if r_pri < tol and r_dual < tol:
                break
        z_prev = z.copy()
    return x

def conjugate_gradient_solve(H, b, max_inner=100):
    """Solves H x = b using Conjugate Gradient."""
    n = len(b)
    x = [0.0] * n
    r = b[:]
    p_vec = r[:]
    r_dot_r = dot(r, r)
    for _ in range(max_inner):
        Hp = H(p_vec)
        alpha = r_dot_r / dot(p_vec, Hp)
        x = [x[i] + alpha * p_vec[i] for i in range(n)]
        r = [r[i] - alpha * Hp[i] for i in range(n)]
        r_dot_r_new = dot(r, r)
        if r_dot_r_new < 1e-10:
            break
        beta = r_dot_r_new / r_dot_r
        p_vec = [r[i] + beta * p_vec[i] for i in range(n)]
        r_dot_r = r_dot_r_new
    return x

def mat_vec_mul(M, v):
    """Standard matrix-vector multiplication."""
    return [sum(M[i][j] * v[j] for j in range(len(v))) for i in range(len(M))]

def dot(v1, v2):
    """Dot product of two vectors."""
    return sum(a * b for a, b in zip(v1, v2))

def norm(v):
    """L2 norm of a vector."""
    return dot(v, v) ** 0.5
```

**Parameters:**
- $\rho$: Augmented Lagrangian penalty parameter [S1, unofficial].
- $\mu$: Proximal parameter for Linearized ADMM. Constraint: $\mu \rho \|K\|^2 \le 1$ [S2].

**Edge Cases and Pitfalls:**
- For tomography, $f(x) = \|Ax - p\|_2^2$, making the x-update a least-squares problem solved via Conjugate Gradient (CG) in implementations like RTK [S1, unofficial].
- If $A^T A + \rho I$ is ill-conditioned, CG convergence may be slow [G].
- Convergence is not guaranteed for non-convex problems [G].

## Subtopics

### [L1 Shearlet Regularized CT Reconstruction (ADMM)](10811-l1-shearlet-regularized-ct-reconstruction-admm.md)
This method solves the L1 shearlet regularized computed tomography (CT) reconstruction problem using the Alternating Direction Method of Multipliers (ADMM). It minimizes a composite objective consisting of a weighted L1 norm of shearlet coefficients and a quadratic data fidelity term, subject to non-negativity constraints on the image. It sets itself apart from standard filtered backprojection by enforcing sparsity in the shearlet domain to handle limited-angle artifacts, and from its parent [ADMM Solver](10107-admm-solver.md) by specifically structuring the proximal steps for shearlet shrinkage and non-negativity clamping.

### Linearized Alternating Direction Method of Multipliers (LADMM)
A proximal algorithm used to solve optimization problems of the form $\arg \min_v F(v) + G(Kv)$ [S2]. It modifies the standard ADMM x-update to avoid solving a linear system by linearizing the quadratic term, at the cost of introducing a proximal parameter $\mu$ [S2].
- **Initialization:** $v^{(0)} \in \mathbb{R}^N$, $z^{(0)} \in \mathbb{R}^d$, $y^{(0)} = 0_d$ [S2].
- **Iterations ($t = 1$ to $T_1$):**
  1. $v^{(t+1)} = \text{prox}_{\mu F}(v^{(t)} - \mu \rho K^T (K v^{(t)} - z^{(t)} + y^{(t)}))$ [S2].
  2. $z^{(t+1)} = \text{prox}_{\rho G}(K v^{(t+1)} + y^{(t)})$ [S2].
  3. $y^{(t+1)} = y^{(t)} + K v^{(t+1)} - z^{(t+1)}$ [S2].
- **Parameters:** $\mu$ (proximal parameter) and $\rho$ (penalty parameter) must satisfy $\mu \rho \|K\|^2 \le 1$ [S2]. $T_1$ is the number of iterations [S2]. $z$ and $y$ are additional variables of size $d$ [S2].

### ADMM Convergence Metrics
Metrics used to track the convergence of the ADMM optimization loop by measuring violations of primal and dual feasibility [S3].
- **Primal Residual:** $\text{RMSE}(A x_t, p_t)$ [S3].
- **Dual Residual:** $\text{RMSE}(A x_t, A x_{t-1})$ [S3].
- **Comparison:** Raskar codes yield slightly faster convergence (lower residuals per iteration) compared to boxcar codes [S3].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** $O(n)$ for storing $x, z, u$ (and $v, y$ for LADMM) [S1, unofficial][S2].
- **Strengths:** Handles non-smooth regularizers (like $\ell_1$) efficiently by splitting them into simple proximal steps [S1, unofficial].
- **Limitations:** Convergence can be slow for ill-conditioned problems [G]. The x-update may require an iterative solver (like CG), adding inner-loop complexity [S1, unofficial].
- **When to use:** When the objective function is separable into a data term and a prior term, and the prior term has a simple proximal operator (e.g., sparsity, total variation) [S1, unofficial].
- **When not to use:** When the problem is strictly convex and smooth, and a direct solver (like Cholesky) is feasible and faster [G].

## Background
ADMM was introduced as a technique to solve separable minimization problems [S1, unofficial]. It is implemented in the Reconstruction ToolKit (RTK) for total variation-regularized reconstruction [S1, unofficial]. Linearized ADMM (LADMM) was developed to avoid solving linear systems in the x-update, making it suitable for large-scale problems [S2]. The method has been applied in electron microscopy tilt-series reconstruction [S2] and joint temporal de-blurring and tomographic reconstruction [S3].
