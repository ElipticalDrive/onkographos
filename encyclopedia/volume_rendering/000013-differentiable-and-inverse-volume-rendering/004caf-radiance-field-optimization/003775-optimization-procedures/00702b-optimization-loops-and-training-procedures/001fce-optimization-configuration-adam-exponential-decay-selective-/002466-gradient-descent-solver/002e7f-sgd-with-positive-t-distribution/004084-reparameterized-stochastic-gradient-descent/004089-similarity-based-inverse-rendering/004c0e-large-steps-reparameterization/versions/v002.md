# Large Steps reparameterization

Also called: Nicolet et al. 2021 method, Nicolet et al. Large Steps, Shape Reconstruction with Large Steps

## Overview
Large Steps reparameterization is a gradient preconditioning technique for inverse rendering of geometry that handles sparse silhouette gradients and prevents flipped triangles [S1]. It achieves fast convergence by preconditioning the bias of gradient steps toward smooth solutions without enforcing smoothness in the final result [S2, unofficial]. It sets itself apart from standard optimizers by treating optimization as a spatiotemporal process that applies Laplacian smoothing and infinity-norm filtering [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Current vertex positions $x \in \mathbb{R}^{3N}$, Laplacian matrix $L \in \mathbb{R}^{3N \times 3N}$, hyperparameter $\lambda > 0$, and loss gradient $\nabla_x f$ [S1].
*   **Output:** Updated vertex positions $x$ [S1].

**Data Structures:**
*   **Reparameterized Variable ($u$):** $u \in \mathbb{R}^{3N}$, defined as $u = (I + \lambda L)x$ [S1].
*   **Optimizer State ($m_u, v_u$):** First and second moment estimates for $u$, initialized to zero vectors of size $3N$ [G].

**Parameters:**
*   $\lambda$: Controls the strength of regularization introduced by the Laplacian matrix [S2, unofficial].
*   $\alpha, \beta_1, \beta_2, \epsilon$: Standard Adam hyperparameters for learning rate, decay rates, and numerical stability [G].

**Steps:**
1.  **Reparameterization:** Compute the transformed variable $u$ from the current geometry $x$: $u = (I + \lambda L)x$ [S1].
2.  **Gradient Transformation:** Compute the gradient with respect to $u$ using the chain rule: $\nabla_u f = (I + \lambda L)^{-1} \nabla_x f$ [S1].
3.  **UniformAdam Update:** Perform an update on $u$ using the UniformAdam variant of Adam [S1].
4.  **Inverse Reparameterization:** Convert the updated $u$ back to the physical space $x$: $x = (I + \lambda L)^{-1} u$ [S1].

**Pseudocode:**
```python
def solve_linear_system(A, b):
    # Standard linear algebra routine to solve A * y = b

def large_steps_update(x, L, lambda_reg, grad_x, m_u, v_u, alpha, beta1, beta2, epsilon, t):
    # 1. Reparameterization: u = (I + lambda * L) * x
    I = identity_matrix(L.shape[0])
    A = I + lambda_reg * L
    u = A @ x

    # 2. Gradient transformation: grad_u = (I + lambda * L)^-1 * grad_x
    grad_u = solve_linear_system(A, grad_x)

    # 3. UniformAdam update on u
    m_u = beta1 * m_u + (1 - beta1) * grad_u
    v_u = beta2 * v_u + (1 - beta2) * (grad_u ** 2)

    bias_1 = 1 - beta1 ** t
    bias_2 = 1 - beta2 ** t
    m_hat = m_u / bias_1
    v_hat = v_u / bias_2

    # UniformAdam: replace element-wise division by v_hat with scalar infinity norm
    v_inf = max(v_hat)
    delta_u = -alpha * m_hat / ((v_inf ** 0.5) + epsilon)
    u = u + delta_u

    # 4. Inverse reparameterization: x = (I + lambda * L)^-1 * u
    x = solve_linear_system(A, u)
    return x, m_u, v_u
```

**Edge Cases and Pitfalls:**
*   Sparse silhouette gradients cause local vertex perturbations that quickly lead to flipped triangles and tangled meshes [S1].
*   The matrix $(I + \lambda L)$ requires $\lambda > 0$ and a positive semi-definite $L$ to guarantee invertibility [G].
*   Implementations must adjust $\lambda$ and the step size when switching differentiable rendering backends [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Dominated by two linear system solves per step [S1].
*   **Memory Complexity:** Linear in the number of vertices for storing $L$ and optimizer states [G].
*   **Strengths:** Prevents mesh topology errors and enables higher learning rates [S1][S2, unofficial].
*   **Limitations:** Requires Laplacian computation and careful hyperparameter tuning [S1][S2, unofficial].
*   **When to use:** Shape reconstruction in inverse rendering where mesh topology preservation is critical and gradients are sparse [S1].
*   **When not to use:** When computational resources are extremely limited and iterative linear solves are too slow [G].

## Background
The Large Steps reparameterization was introduced by Nicolet et al. in 2021 to stabilize gradient-based mesh reconstruction [S1]. Subsequent implementations adapt the method for different differentiable rendering engines, requiring hyperparameter adjustments [S2, unofficial].
