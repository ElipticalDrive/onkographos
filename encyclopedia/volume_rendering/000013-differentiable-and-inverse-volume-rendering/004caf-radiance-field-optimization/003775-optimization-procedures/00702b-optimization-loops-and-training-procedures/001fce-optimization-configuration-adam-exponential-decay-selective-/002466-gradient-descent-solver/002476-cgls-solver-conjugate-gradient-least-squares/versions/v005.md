# CGLS Solver (Conjugate Gradient Least Squares)
Also called: Sparse Linear Least Squares Solver
## Overview
The CGLS solver is a sparse linear least squares method used to solve optimization problems where the normal equations ($A^T A$) are ill-conditioned due to quadratic condition numbers [S1, unofficial]. It provides numerically stable results for large or almost rank-deficient problems, distinguishing itself from direct solvers by avoiding the explicit formation of $A^T A$ [S1, unofficial]. While generally slower than computing $A^T A$ and $A^T b$ for moderately sized problems, it is preferred when numerical stability is critical [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: Matrix $A$ (implicitly available via matrix-vector products), vector $b$.
- Output: Solution vector $x$ minimizing $\|Ax - b\|^2$.

**Data Structures:**
- Vectors $x, p, r, Ap$ of size $n$ (dimension of the solution space).
- Scalar parameters $\alpha, \beta$.

**Algorithm Steps:**
1. Initialize $x_0 = 0$.
2. Compute initial residual $r_0 = b - A x_0 = b$.
3. Set initial search direction $p_0 = r_0$.
4. For $k = 0, 1, \dots$ until convergence:
   a. Compute matrix-vector product $Ap_k = A p_k$.
   b. Compute step size $\alpha_k = \frac{r_k^T r_k}{p_k^T A p_k}$.
   c. Update solution $x_{k+1} = x_k + \alpha_k p_k$.
   d. Update residual $r_{k+1} = r_k - \alpha_k A p_k$.
   e. Check convergence: if $\|r_{k+1}\|$ is sufficiently small, stop.
   f. Apply Jacobi preconditioning [S1, unofficial]. Let $M$ be the diagonal of $A^T A$ (or an approximation thereof). The preconditioned residual $\tilde{r}$ is computed as $\tilde{r}_i = r_i / M_{ii}$.
   g. Compute $\beta_k = \frac{\tilde{r}_{k+1}^T \tilde{r}_{k+1}}{r_k^T r_k}$.
   h. Update search direction $p_{k+1} = \tilde{r}_{k+1} + \beta_k p_k$.

**Parameters:**
- Convergence tolerance: Not given in the sources.
- Preconditioner: Jacobi preconditioner [S1, unofficial].

**Edge Cases and Pitfalls:**
- Ill-conditioning: The method is specifically chosen to handle ill-conditioned systems where normal equations fail [S1, unofficial].
- Rank deficiency: Provides stable results for almost rank-deficient problems [S1, unofficial].
- Performance: Slower than normal equation approaches for moderately sized problems [S1, unofficial].

**Pseudocode:**
```python
def cgls_solve(A_matvec, b, max_iter=1000, tol=1e-6):
    """
    Solves min ||Ax - b||^2 using CGLS with Jacobi preconditioning.
    A_matvec: function that computes A * v for a vector v.
    b: target vector.
    """
    n = len(b)
    x = [0.0] * n
    r = [b[i] for i in range(n)]  # r = b - A*x, initially x=0
    p = [r[i] for i in range(n)]
    
    # Compute diagonal of A^T A for Jacobi preconditioning
    # Note: In practice, this requires computing A^T A diagonal or approximating it.
    # If A is not explicitly available, this step might be an approximation [G].
    # Here we assume we can compute the diagonal of A^T A.
    diag_AtA = [0.0] * n
    for i in range(n):
        # Compute i-th column of A, then its norm squared
        col_i = A_matvec([1.0 if j == i else 0.0 for j in range(n)])
        diag_AtA[i] = sum(col_i[j]**2 for j in range(n))
    
    # Avoid division by zero
    for i in range(n):
        if diag_AtA[i] == 0:
            diag_AtA[i] = 1.0

    r_dot_r = sum(r[i]**2 for i in range(n))
    
    for k in range(max_iter):
        Ap = A_matvec(p)
        p_Ap = sum(p[i] * Ap[i] for i in range(n))
        
        if p_Ap == 0:
            break
            
        alpha = r_dot_r / p_Ap
        
        # Update x
        for i in range(n):
            x[i] += alpha * p[i]
            
        # Update r
        r_dot_r_new = 0.0
        for i in range(n):
            r[i] -= alpha * Ap[i]
            r_dot_r_new += r[i]**2
            
        if r_dot_r_new < tol:
            break
            
        # Jacobi Preconditioning
        r_tilde = [r[i] / diag_AtA[i] for i in range(n)]
        
        r_tilde_dot_r_tilde = sum(r_tilde[i]**2 for i in range(n))
        beta = r_tilde_dot_r_tilde / r_dot_r
        
        # Update p
        for i in range(n):
            p[i] = r_tilde[i] + beta * p[i]
            
        r_dot_r = r_dot_r_new
        
    return x
```
## Subtopics

### [Conjugate Gradient Solver for Compressive Volume Rendering](4270-conjugate-gradient-solver-for-compressive-volume-rendering.md)
This method recovers missing pixels in a rendered volume image by solving a regularized least-squares optimization problem using the Conjugate Gradient algorithm. It allows reconstruction from a subset of pixels, reducing total rendering time compared to full volume rendering. It differs from its parent [CGLS Solver (Conjugate Gradient Least Squares)](3285-cgls-solver-conjugate-gradient-least-squares.md) by explicitly defining the regularization term $H$ via B-spline convolution and the sampling matrix $S$ for pixel dropping, whereas the parent focuses on the general numerical stability of the least-squares formulation.

### [Symmetric Least Squares Solver](4723-symmetric-least-squares-solver.md)
The Symmetric Least Squares Solver solves the linear system $Ax = b$ where $A$ is a symmetric matrix, typically arising from the normal equations $A^T A$ in least-squares problems. It differs from the parent [CGLS Solver](3285-cgls-solver-conjugate-gradient-least-squares.md) by explicitly computing the pseudoinverse via Singular Value Decomposition (SVD) rather than using iterative conjugate gradients. This approach provides a direct solution suitable for small, dense symmetric systems (e.g., $3 \times 3$) where numerical stability via eigenvalue thresholding is required, contrasting with the iterative nature of [Conjugate Gradient Solver for Compressive Volume Rendering](4270-conjugate-gradient-solver-for-compressive-volume-rendering.md).

### [Adaptive Grid Optical Tomography](13834-adaptive-grid-optical-tomography.md)
Adaptive Grid Optical Tomography is a volumetric reconstruction method that represents the 3D density field using an adaptive octree grid of piecewise constant basis functions, allowing for higher effective resolution and better memory efficiency than uniform grids by using fewer basis functions in uniform regions. It solves the problem of reconstructing dynamic, semi-transparent phenomena (such as smoke and flames) from multi-view video sequences by iteratively refining the grid resolution only where the reconstruction error is high, combined with a visual hull constraint to restrict the solution space. Unlike uniform grid approaches, which quickly exhaust memory limits for high-resolution multi-camera setups, this method uses 20-25% of the memory while achieving comparable accuracy.

### Cholesky Solver
Solves $Hc = \eta$ by performing Cholesky decomposition of $H$, followed by forward and backward substitution [S2]. This is used when $H$ is positive-definite and symmetric, such as the Hankel matrix of the biased moment vector [S2].

### Scalar Field Expansion Solver
Addresses problems when solving outer vertices of very sparse parent voxels that lack enough neighboring child voxels to create a linear system of equations [S3, unofficial]. It solves sparse cases using the scalar field expansion method described in Appendix B of the source [S3, unofficial]. A pitfall is that Singular Value Decomposition (SVD) often results in incorrect values for these sparse cases, with resulting values being both positive (outside bounds) and negative (inside the model) [S3, unofficial].

## Operating characteristics
- **Time Complexity:** Generally slower than computing $A^T A$ and $A^T b$ for moderately sized problems [S1, unofficial].
- **Memory Complexity:** Sparse, as it avoids forming $A^T A$ explicitly [S1, unofficial].
- **Numerical Stability:** Provides numerically more stable results for very large or almost rank-deficient problems compared to normal equations [S1, unofficial].
- **Strengths:** Handles ill-conditioned systems better than normal equations [S1, unofficial].
- **Limitations:** Slower for moderate problem sizes [S1, unofficial].
- **When to Use:** When $A^T A$ is ill-conditioned or rank-deficient [S1, unofficial].
- **When Not to Use:** For moderately sized problems where speed is prioritized over stability [S1, unofficial].
## Background
The CGLS solver is based on the work by Paige and Saunders [PS82], as cited in [S1, unofficial]. It is used in transfer function optimization for comparative volume rendering [S1, unofficial].
