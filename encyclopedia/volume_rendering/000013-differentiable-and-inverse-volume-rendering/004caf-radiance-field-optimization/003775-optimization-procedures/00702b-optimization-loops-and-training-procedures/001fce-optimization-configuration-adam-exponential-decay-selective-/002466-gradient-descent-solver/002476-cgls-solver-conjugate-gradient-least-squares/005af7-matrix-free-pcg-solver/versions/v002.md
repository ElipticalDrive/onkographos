# Matrix-Free PCG Solver
Also called: Implicit normal operator PCG, Matrix-Free PCG, Triangle-Structured Matrix-Free PCG Solver, Vertex-Block Preconditioned PCG

## Overview
The Matrix-Free PCG Solver is a method for solving the global normal system $Hx=g$ arising in closed-form radiance-field optimization [S1, unofficial]. It evaluates the matrix-vector product $Hu$ directly from rasterization records without constructing the global observation or normal matrices $H$ [S1, unofficial]. Unlike factorization-based solvers that explicitly assemble and decompose the normal matrix, this variant maintains smaller GPU memory by never materializing $A$ and $H$ [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   Set of calibrated RGB images $\{I_k\}_{k=1}^K$ [S1, unofficial].
*   Rasterization records $R$ containing, for each valid pixel $p_{k,r}$ in view $k$: triangle vertex indices $\{i_{s,k,r}\}_{s=0}^2$ [S1, unofficial], observation vectors $\{\phi_{s,k,r}\}_{s=0}^2$ (SH basis evaluations at the pixel) [S1, unofficial], and weight $w_{k,r}$ (grazing-angle down-weighting) [S1, unofficial].
*   Global SH regularizer $\Lambda$, composed of vertex blocks $\Lambda_i \in \mathbb{R}^{q \times q}$ for each vertex $i$ [S1, unofficial].
*   Tolerance $\delta$: Prescribed relative residual tolerance for PCG termination [S1, unofficial].
*   $T_{max}$: Maximum iteration count for PCG (typically 300) [S1, unofficial].

**Outputs:**
*   Estimated appearance coefficients $X^* \in \mathbb{R}^{q N_v \times 3}$, where $N_v$ is the number of vertices and $q$ is the SH dimension per channel [S1, unofficial].

### Data Structures
*   **Vertex Blocks:** The solution vector $X$ and right-hand side $G$ are partitioned by vertex. $G_i \in \mathbb{R}^{q \times 3}$ stores the accumulated RHS for vertex $i$ [S1, unofficial].
*   **Preconditioner Blocks:** $P_i \in \mathbb{R}^{q \times q}$ stores the diagonal block of the normal matrix for vertex $i$ [S1, unofficial].
*   **Cholesky Factors:** $L_i \in \mathbb{R}^{q \times q}$ such that $P_i = L_i L_i^\top$ [S1, unofficial].
*   **PCG Vectors:** $X^{(\tau)}$ (solution), $r$ (residual), $p$ (search direction), $z$ (preconditioned residual), $h$ (normal product result) [S1, unofficial].

### Steps
1.  Construct the right-hand side $G$ and the vertex-block preconditioner $P$ [S1, unofficial].
2.  Initialize $G_i = 0$ for all vertices $i=1 \dots N_v$ [S1, unofficial].
3.  Initialize $P_i = \Lambda_i$ for all vertices $i=1 \dots N_v$ [S1, unofficial].
4.  For each view $k = 1 \dots K$ and each valid pixel $p_{k,r}$:
    5.  For each vertex $s \in \{0, 1, 2\}$ of the covering triangle:
        6.  Update RHS: $G_{i_{s,k,r}} \leftarrow G_{i_{s,k,r}} + w_{k,r} \phi_{s,k,r} I_k(p_{k,r})^\top$ [S1, unofficial].
        7.  Update Preconditioner: $P_{i_{s,k,r}} \leftarrow P_{i_{s,k,r}} + w_{k,r} \phi_{s,k,r} \phi_{s,k,r}^\top$ [S1, unofficial].
8.  Compute Cholesky factor $L_i$ such that $P_i = L_i L_i^\top$ [S1, unofficial].
9.  Evaluate the matrix-vector product $h = Hu$ without forming $H$ [S1, unofficial].
10. Update: $h_{i_{s,k,r}} \leftarrow h_{i_{s,k,r}} + w_{k,r} \phi_{s,k,r} \left( \sum_{t=0}^2 \phi_{t,k,r}^\top u_{i_{t,k,r}} \right)$ [S1, unofficial].
11. Solve $H X^{(\tau)} = G^{(\tau)}$ using Preconditioned Conjugate Gradients [S1, unofficial].

### Pseudocode
```python
def TriangleSetup(R, K, Nv, q, Lambda):
    G = [zeros(q, 3) for _ in range(Nv)]
    P = [copy(Lambda[i]) for i in range(Nv)]
    for k in range(K):
        for p_kr in R[k]:
            for s in range(3):
                i = p_kr.vertex_indices[s]
                w = p_kr.weight
                phi = p_kr.observation_vectors[s]
                I_val = p_kr.image_value
                G[i] += w * phi * I_val.T
                P[i] += w * phi * phi.T
    L = []
    for i in range(Nv):
        L.append(cholesky(P[i]))
    return G, L

def TriangleNormal(u, R, K, Nv, q, Lambda):
    h = [copy(Lambda[i] @ u[i]) for i in range(Nv)]
    for k in range(K):
        for p_kr in R[k]:
            for s in range(3):
                i = p_kr.vertex_indices[s]
                w = p_kr.weight
                phi_s = p_kr.observation_vectors[s]
                inner = sum(phi_t.T @ u[p_kr.vertex_indices[t]] for t in range(3))
                h[i] += w * phi_s * inner
    return h

def PCG_Loop(G, L, R, K, Nv, q, Lambda, delta, Tmax):
    X = [zeros(q, 3) for _ in range(Nv)]
    for tau in range(3):
        g = [G[i][tau] for i in range(Nv)]
        r = copy(g)
        eta = sum(dot(v, v) for v in r)
        z = solve_preconditioner(L, r)
        p = copy(z)
        sigma = dot(r, z)
        for t in range(1, Tmax + 1):
            h = TriangleNormal(p, R, K, Nv, q, Lambda)
            alpha = sigma / dot(p, h)
            for i in range(Nv):
                X[i][tau] += alpha * p[i]
            for i in range(Nv):
                r[i] -= alpha * h[i]
            if sum(dot(v, v) for v in r) <= delta * eta:
                break
            z = solve_preconditioner(L, r)
            sigma_new = dot(r, z)
            beta = sigma_new / sigma
            for i in range(Nv):
                p[i] = z[i] + beta * p[i]
            sigma = sigma_new
    return X
```

### Formulas
*   **RHS Accumulation:** $G_{i_{s,k,r}} \leftarrow G_{i_{s,k,r}} + w_{k,r} \phi_{s,k,r} I_k(p_{k,r})^\top$ [S1, unofficial].
*   **Preconditioner Accumulation:** $P_{i_{s,k,r}} \leftarrow P_{i_{s,k,r}} + w_{k,r} \phi_{s,k,r} \phi_{s,k,r}^\top$ [S1, unofficial].
*   **Cholesky Decomposition:** $P_i = L_i L_i^\top$ [S1, unofficial].
*   **Regularization Term:** $h_i \leftarrow \Lambda_i u_i$ [S1, unofficial].
*   **Pixel Contribution to Normal Product:** $h_{i_{s,k,r}} \leftarrow h_{i_{s,k,r}} + w_{k,r} \phi_{s,k,r} \left( \sum_{t=0}^2 \phi_{t,k,r}^\top u_{i_{t,k,r}} \right)$ [S1, unofficial].
*   **Termination Condition:** $\sum_{i=1}^{N_v} \|G_i^{(\tau)} - H_i X_i^{(\tau)}\|_2^2 \le \delta \sum_{i=1}^{N_v} \|G_i^{(\tau)}\|_2^2$ [S1, unofficial].

### Parameters
*   $\delta$: Relative residual tolerance. Tighter tolerances reduce final residual error but require more iterations [S1, unofficial].
*   $T_{max}$: Maximum iterations. Set to 300 in evaluations to prevent infinite loops on ill-conditioned systems [S1, unofficial].

### Edge Cases and Pitfalls
*   **Ill-conditioning:** Without adaptive SH regularization, weakly supported SH components cause ill-conditioning, making the unregularized system difficult to solve within $T_{max}$ iterations [S1, unofficial].
*   **Memory:** The method processes views sequentially during matrix-free evaluation, so peak memory does not grow with the number of views $K$ [S1, unofficial].

## Operating characteristics
*   **Memory Complexity:** $M_{GPU} = O(N_v q + HW q)$ [S1, unofficial]. Peak memory depends on vertices and image resolution, not the number of views $K$ [S1, unofficial].
*   **Computational Complexity:**
    *   Setup: $O(KHWq^2 + N_v q^3)$ [S1, unofficial].
    *   Per Iteration: $O(KHWq + N_v q^2)$ [S1, unofficial].
    *   Total solve time grows linearly with $K$ [S1, unofficial].
*   **Strengths:** Maintains smaller GPU memory than factorization-based solvers by never materializing $A$ and $H$ [S1, unofficial]. The vertex-block preconditioner preserves coupling among all SH coefficients of the same vertex, improving numerical efficiency over scalar Jacobi preconditioners [S1, unofficial].
*   **Limitations:** Requires $T_{max}$ iterations; convergence depends on the conditioning provided by adaptive SH regularization [S1, unofficial].
*   **Accuracy:** At tight stopping tolerances, the residual MAE approaches that of the explicitly assembled factorization-based solver, confirming high numerical accuracy [S1, unofficial].

## Background
The Matrix-Free PCG Solver was introduced in CF-Splat: Closed-Form Triangle Splatting with Mesh Priors [S1, unofficial]. It addresses the computational and memory costs of explicitly constructing the global normal matrix $H$ for large-scale scenes [S1, unofficial]. The method exploits the three-vertex support of each pixel to evaluate the normal operator directly from rasterization records [S1, unofficial].
