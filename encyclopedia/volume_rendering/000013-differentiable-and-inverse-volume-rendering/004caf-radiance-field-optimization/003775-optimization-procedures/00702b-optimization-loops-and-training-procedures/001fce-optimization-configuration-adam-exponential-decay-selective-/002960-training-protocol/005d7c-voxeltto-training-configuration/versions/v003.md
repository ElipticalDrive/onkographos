# VoxelTTO Training Configuration
Also called: VoxelTTO Training Details

## Overview
VoxelTTO training configures the optimization of a voxel-aligned feed-forward 3D Gaussian Splatting (3DGS) module initialized from a frozen Visual Foundation Model (VFM) [S1, unofficial]. It solves the problem of adapting large pre-trained vision models to specific 3D reconstruction tasks via test-time optimization, keeping the VFM parameters frozen while optimizing only the lightweight 3DGS module [S1, unofficial]. It differs from standard neural field training by employing a hybrid loss combining rendered depth/RGB with VFM-predicted depth alignment [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** A sequence of 3–16 video frames resized to $224 \times 448$ pixels. Ground-truth depth maps and RGB images are required for supervision [S1, unofficial].
- **Outputs:** Optimized parameters for the voxel-aligned feed-forward 3DGS module. The VFM weights remain frozen [S1, unofficial].

**Data Structures:**
- **Architecture:** DA3-GIANT with $L=40$ alternating-attention layers [S1, unofficial].
- **Parameters:** Total model size is 1.39B parameters. Only 75.3M parameters are trainable (the 3DGS module) [S1, unofficial].
- **Initialization:** The model is initialized with pretrained VFM weights [S1, unofficial].

**Loss Function:**
The total loss $L$ is a weighted sum of depth and RGB losses [S1, unofficial]:

$$
L = L_{depth} + L_{rgb} = \lambda_{\ell^1_d} L_{\ell^1_{depth}} + \lambda_{align} L_{align_{depth}} + \lambda_{\ell^1} L_{\ell^1_{rgb}} + \lambda_{ssim} L_{ssim_{rgb}}
$$

Where:
- $L_{\ell^1_{depth}}$: $\ell^1$ loss between rendered depth and ground-truth depth.
- $L_{align_{depth}}$: Alignment loss between rendered depth and VFM-predicted depth.
- $L_{\ell^1_{rgb}}$: $\ell^1$ loss between rendered RGB and ground-truth RGB.
- $L_{ssim_{rgb}}$: SSIM loss between rendered RGB and ground-truth RGB [S1, unofficial].

**Loss Weights:**
- $\lambda_{\ell^1_d} = 0.25$
- $\lambda_{align} = 0.25$
- $\lambda_{\ell^1} = 0.9$
- $\lambda_{ssim} = 1.0$ [S1, unofficial]

**Optimization Steps:**
1. **Data Sampling:** For each dataset, define a minimum and maximum frame gap. Randomly select an interval between the first and last frame within this range. Sample 3–16 frames from this interval [S1, unofficial].
2. **Preprocessing:** Resize input frames to $224 \times 448$ [S1, unofficial].
3. **Initialization:** Load pretrained DA3-GIANT weights. Freeze all VFM parameters. Initialize the voxel-aligned feed-forward 3DGS module [S1, unofficial].
4. **Optimizer Setup:** Use Adam optimizer. Set initial learning rate to $3 \times 10^{-6}$. Set minimum learning rate to $10^{-8}$ [S1, unofficial].
5. **Scheduling:** Apply cosine annealing schedule with a 2K warm-up period [S1, unofficial].
6. **Iteration:** Perform 30K optimization iterations [S1, unofficial].
7. **Loss Computation:** At each step, render depth and RGB from the current 3DGS representation. Compute $L_{depth}$ and $L_{rgb}$ using the defined weights. Backpropagate only through the trainable 3DGS parameters [S1, unofficial].

**Pseudocode:**
```python
import math
import random

def l1_loss(a, b):
    return sum(abs(a[i] - b[i]) for i in range(len(a))) / len(a)

def alignment_loss(rendered, vfm_pred):
    return sum(abs(rendered[i] - vfm_pred[i]) for i in range(len(rendered))) / len(rendered)

def ssim_loss(rendered, gt):
    return sum((rendered[i] - gt[i])**2 for i in range(len(rendered))) / len(rendered)

class AdamOptimizer:
    def __init__(self, params, lr):
        self.params = params
        self.lr = lr
        self.m = {id(p): 0.0 for p in params}
        self.v = {id(p): 0.0 for p in params}
        self.t = 0
    def zero_grad(self):
        for p in self.params: p.grad = 0.0
    def step(self):
        self.t += 1
        for p in self.params:
            g = p.grad
            self.m[id(p)] = 0.9 * self.m[id(p)] + 0.1 * g
            self.v[id(p)] = 0.999 * self.v[id(p)] + 0.001 * g**2
            bc1 = 1.0 - 0.9**self.t
            bc2 = 1.0 - 0.999**self.t
            p -= self.lr * (self.m[id(p)] / bc1) / (math.sqrt(self.v[id(p)] / bc2) + 1e-8)

NUM_ITERATIONS = 30000
WARMUP_ITERATIONS = 2000
INITIAL_LR = 3e-6
MIN_LR = 1e-8
LAMBDA_L1_D = 0.25
LAMBDA_ALIGN = 0.25
LAMBDA_L1_RGB = 0.9
LAMBDA_SSIM = 1.0
FRAME_COUNT_MIN = 3
FRAME_COUNT_MAX = 16
RESIZE_WIDTH = 224
RESIZE_HEIGHT = 448

# Initialize DA3-GIANT architecture with L=40 alternating-attention layers [S1, unofficial]
model = initialize_DA3_GIANT(L=40)
vfm_params = model.get_frozen_params()
gs_params = model.get_trainable_params() # 75.3M trainable 3DGS module [S1, unofficial]
optimizer = AdamOptimizer(gs_params, lr=INITIAL_LR)

for iteration in range(NUM_ITERATIONS):
    # Data sampling: sources do not specify exact frame selection logic beyond gap bounds [G]
    min_gap, max_gap = 1, 10 # Placeholder bounds; actual bounds depend on dataset [G]
    gap = random.randint(min_gap, max_gap)
    frame_indices = random.sample(range(gap), k=random.randint(FRAME_COUNT_MIN, FRAME_COUNT_MAX))
    frames = [load_frame(idx) for idx in frame_indices] # Standard I/O [G]

    # Preprocessing: resize frames to 224x448 [S1, unofficial]
    frames = [resize_image(f, RESIZE_WIDTH, RESIZE_HEIGHT) for f in frames] # Standard I/O [G]
    gt_depth, gt_rgb = get_ground_truth(frames) # Standard I/O [G]

    # Forward pass: render depth/RGB and get VFM depth prediction [S1, unofficial]
    rendered_depth, rendered_rgb = model.forward(frames)
    vfm_depth = model.vfm_predict_depth(frames) # VFM frozen [S1, unofficial]

    # Loss computation
    l1_depth = l1_loss(rendered_depth, gt_depth)
    align_depth = alignment_loss(rendered_depth, vfm_depth)
    l1_rgb = l1_loss(rendered_rgb, gt_rgb)
    ssim_rgb = ssim_loss(rendered_rgb, gt_rgb)

    loss = (LAMBDA_L1_D * l1_depth +
            LAMBDA_ALIGN * align_depth +
            LAMBDA_L1_RGB * l1_rgb +
            LAMBDA_SSIM * ssim_rgb)

    # Optimization step
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    # Learning rate scheduling
    progress = iteration / NUM_ITERATIONS
    if iteration < WARMUP_ITERATIONS:
        current_lr = INITIAL_LR * (iteration / WARMUP_ITERATIONS)
    else:
        current_lr = MIN_LR + 0.5 * (INITIAL_LR - MIN_LR) * (1 + math.cos(math.pi * (progress - WARMUP_ITERATIONS/NUM_ITERATIONS) / (1 - WARMUP_ITERATIONS/NUM_ITERATIONS)))
    optimizer.lr = current_lr
```

## Subtopics

### [Test-Time Optimization](17445-test-time-optimization.md)
A technique to exploit known camera parameters while keeping the pretrained visual foundation model (VFM) parameters frozen. It adapts lightweight LoRA modules using pose supervision.

## Operating characteristics
- **Time Complexity:** Training takes approximately 40 hours [S1, unofficial].
- **Hardware:** 2 RTX PRO 6000 GPUs [S1, unofficial].
- **Memory Complexity:** Not given in the sources [S1, unofficial].
- **Strengths:** Efficient adaptation of large VFMs by freezing most parameters. Combines ground-truth supervision with VFM priors for robust depth alignment [S1, unofficial].
- **Limitations:** Limited to sequential frame inputs [S1, unofficial].

## Background
VoxelTTO was introduced in the paper "VoxelTTO: Voxel-Aligned Feed-Forward 3D Gaussian Splatting with Test-Time Optimization" by Lin et al. (2025) [S1, unofficial]. It builds on the DA3-GIANT architecture and aims to improve 3D reconstruction accuracy by leveraging test-time optimization with frozen visual foundation models [S1, unofficial].
