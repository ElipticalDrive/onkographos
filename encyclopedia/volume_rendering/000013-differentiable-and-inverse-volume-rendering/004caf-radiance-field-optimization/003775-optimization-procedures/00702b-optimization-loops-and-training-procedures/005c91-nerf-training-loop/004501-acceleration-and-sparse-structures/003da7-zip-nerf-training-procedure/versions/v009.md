# Zip-NeRF Training Procedure

Also called: Joint training for Zip-NeRF, Zip-NeRF-based radiance cache training

## Overview
The Zip-NeRF Training Procedure is a two-stage optimization method for inverse rendering that jointly trains a physically-based material model, environment map, and radiance caches (Zip-NeRF and Fast Cache) to estimate incoming radiance [S1]. It sets itself apart from standard NeRF training by using a specialized photometric loss with a gradient trick to handle the non-analytic expectation of the radiance estimator, and by employing a two-stage schedule that first stabilizes the cache before joint optimization [S1].

## How it works
The method consists of two sequential stages: Cache Training and Joint Training [S1].

### Inputs and Outputs
**Inputs:**
*   Multi-view image dataset (e.g., TensoIR-synthetic, Open Illumination) [S1].
*   Camera poses and intrinsics [S1].
*   Initial Zip-NeRF structure (sparse hash grid + MLP) and Fast Cache structure (low-res hash grid + small MLP) [S1].
*   Physically-based material model parameters $\Phi$ [S1].
*   Environment map parameters [S1].

**Outputs:**
*   Optimized Zip-NeRF radiance cache [S1].
*   Optimized Fast Cache [S1].
*   Optimized material parameters $\Phi$ [S1].
*   Optimized environment map [S1].

### Data Structures
*   **Zip-NeRF Cache:** A sparse hash grid storing features, decoded by an MLP to predict radiance [S1]. Accessed via spatial constraints defined in [Acceleration and Sparse Structures](11405-acceleration-and-sparse-structures.md) [G].
*   **Fast Cache:** A lightweight hash grid and small MLP predicting incoming radiance $L_{fast}$ [S1].
*   **Occlusion-aware Importance Sampler:** Samples directions for cache evaluation [S1].

### Numbered Steps

#### Stage 1: Cache Training
1.  **Initialize:** Set up Zip-NeRF cache parameters [S1].
2.  **Sample Rays:** Sample a batch of $N_{rays} = 16384$ primary rays from the training dataset [S1].
3.  **Evaluate Cache:** For each ray, query the Zip-NeRF cache to estimate incoming radiance $\hat{L}_{cache}$ [S1].
4.  **Compute Loss:** Calculate the Charbonnier loss between the predicted cache radiance and the ground truth incoming radiance [S1].
5.  **Update:** Optimize Zip-NeRF cache parameters using the computed loss [S1].
6.  **Schedule:** Repeat for 100,000 iterations [S1].
    *   **Learning Rate:** Warm up from 0 to 0.01 over the first 10,000 iterations [S1].
    *   **Decay:** Linearly decrease from 0.01 to 0.001 over the remaining 90,000 iterations [S1].

#### Stage 2: Joint Training
1.  **Initialize:** Load optimized Zip-NeRF cache from Stage 1 [S1]. Initialize material parameters $\Phi$, environment map, and Fast Cache [S1].
2.  **Sample Rays:** Sample a batch of $N_{rays} = 1024$ primary rays [S1].
3.  **Estimate Incoming Radiance:** For each primary ray, estimate incoming radiance $\hat{L}_i$ using a combination of caches [S1]:
    *   Use 64 secondary rays to estimate $L_{fast}$ from the Fast Cache [S1].
    *   Use 16 secondary rays to estimate $\Delta L_o$ from the NeRF-cache (Zip-NeRF) [S1].
    *   Combine these estimates to form the final radiance estimator $\hat{L}_i(\mathbf{o}, \omega_o; \Phi)$ [S1].
4.  **Compute Photometric Loss:** Calculate the loss between the ground truth image $I(\mathbf{o}, \omega_o)$ and the estimated radiance $\hat{L}_i$ [S1]. Because the expected value $\mathbb{E}[\hat{L}_i]$ lacks an analytic expression, apply the **gradient trick** [S1]:
    $$ \mathcal{L}_{\text{photometric}} = \frac{2 \left( I(\mathbf{o}, \omega_o) - \hat{L}_i(\mathbf{o}, \omega_o; \Phi) \right) \operatorname{stopgrad}\left( I(\mathbf{o}, \omega_o) - \hat{L}_i(\mathbf{o}, \omega_o; \Phi) \right)}{\operatorname{stopgrad}\left( \hat{L}_i^{\text{cache}}(\mathbf{o}, \omega_o; \Phi) \right)} $$
    where $\operatorname{stopgrad}(\cdot)$ denotes the stop-gradient operation, preventing gradients from flowing through the cache estimation during the material update [S1].
5.  **Update:** Optimize material parameters $\Phi$, environment map, Fast Cache, and Occlusion-aware Importance Sampler [S1].
    *   **Learning Rate for Fast Cache & Sampler:** $1.5625 \times 10^{-4}$ [S1].
    *   **Learning Rate for Others (Material, Env Map):** $3.125 \times 10^{-5}$ [S1].
6.  **Iterate:** Repeat for 40,000 iterations (TensoIR-synthetic) or 100,000 iterations (Open Illumination) [S1].

### Formulas
*   **Charbonnier Loss (Stage 1):** $\mathcal{L}_{\text{Charbonnier}} = \sqrt{(\hat{L}_{cache} - L_{gt})^2 + \epsilon^2}$ [S1].
*   **Photometric Loss (Stage 2):** $\mathcal{L}_{\text{photometric}} = \frac{2 \left( I(\mathbf{o}, \omega_o) - \hat{L}_i(\mathbf{o}, \omega_o; \Phi) \right) \operatorname{stopgrad}\left( I(\mathbf{o}, \omega_o) - \hat{L}_i(\mathbf{o}, \omega_o; \Phi) \right)}{\operatorname{stopgrad}\left( \hat{L}_i^{\text{cache}}(\mathbf{o}, \omega_o; \Phi) \right)}$ [S1].
*   **Learning Rate Schedule (Stage 1):** 
    $$ \text{lr}(t) = \begin{cases} 0.01 \cdot \frac{t}{10000} & t < 10000 \\ 0.01 - 0.009 \cdot \frac{t - 10000}{90000} & t \ge 10000 \end{cases} $$
    where $t$ is the iteration number [S1].

### Parameters
*   **Stage 1 Batch Size:** 16384 rays [S1].
*   **Stage 1 Iterations:** 100,000 [S1].
*   **Stage 1 Learning Rate:** Warmup 0 to 0.01 (10k iters), then linear decay to 0.001 (90k iters) [S1].
*   **Stage 2 Batch Size:** 1024 rays [S1].
*   **Stage 2 Iterations:** 40,000 (TensoIR-synthetic), 100,000 (Open Illumination) [S1].
*   **Stage 2 Learning Rate (Fast Cache & Sampler):** $1.5625 \times 10^{-4}$ [S1].
*   **Stage 2 Learning Rate (Material & Env Map):** $3.125 \times 10^{-5}$ [S1].
*   **Fast Cache Samples:** 64 secondary rays [S1].
*   **NeRF Cache Samples:** 16 secondary rays [S1].

### Edge Cases and Pitfalls
*   **Non-analytic Expectation:** The expected value of the radiance estimator $\mathbb{E}[\hat{L}_i]$ cannot be computed analytically [S1]. Direct minimization of the squared error between $I$ and $\mathbb{E}[\hat{L}_i]$ is impossible [S1]. The gradient trick must be used to obtain correct gradients in expectation [S1].
*   **Precision:** The use of `stopgrad` on the cache estimates is critical to prevent unstable gradients from the Monte Carlo sampling process from affecting the cache training during joint optimization [S1].

### Pseudocode

```python
def train_zip_nrf_stage1(dataset, zip_nrf_cache, iterations=100000, batch_size=16384):
    """Stage 1: Optimize Zip-NeRF radiance cache."""
    optimizer = Optimizer(zip_nrf_cache.parameters())
    
    for step in range(iterations):
        # Learning rate schedule
        if step < 10000:
            lr = 0.01 * (step / 10000.0)
        else:
            lr = 0.01 - (0.009 * (step - 10000) / 90000.0)
        
        optimizer.set_lr(lr)
        
        # [Comment: Sample rays from dataset]
        rays = sample_rays(dataset, batch_size)
        
        # Evaluate Zip-NeRF cache
        L_cache = zip_nrf_cache.forward(rays)
        
        # [Comment: Retrieve ground truth incoming radiance from dataset]
        L_gt = get_ground_truth_incoming_radiance(rays)
        
        # Charbonnier Loss
        loss = charbonnier_loss(L_cache, L_gt)
        
        # Backprop and update
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

def train_zip_nrf_stage2(dataset, zip_nrf_cache, fast_cache, material_model, env_map, 
                         iterations, batch_size=1024, num_fast_samples=64, num_nerf_samples=16):
    """Stage 2: Joint training of material, environment, and caches."""
    lr_fast = 1.5625e-4
    lr_other = 3.125e-5
    
    optimizer_fast = Optimizer(fast_cache.parameters() + material_model.sampler.parameters(), lr=lr_fast)
    optimizer_other = Optimizer(material_model.parameters() + env_map.parameters(), lr=lr_other)
    
    for step in range(iterations):
        # [Comment: Sample rays from dataset]
        rays = sample_rays(dataset, batch_size)
        
        # Estimate incoming radiance using caches
        # 1. Fast Cache estimation (64 samples)
        L_fast = fast_cache.estimate_incoming_radiance(rays, num_samples=num_fast_samples)
        
        # 2. Zip-NeRF Cache estimation (16 samples)
        L_nerf = zip_nrf_cache.estimate_incoming_radiance(rays, num_samples=num_nerf_samples)
        
        # Combine estimates to form final estimator L_hat_i
        L_hat_i = combine_caches(L_fast, L_nerf)
        
        # [Comment: Retrieve ground truth image color]
        I_gt = get_ground_truth_image_color(rays)
        
        # Photometric Loss with Gradient Trick
        diff = I_gt - L_hat_i
        diff_stopgrad = stopgrad(diff)
        L_cache_stopgrad = stopgrad(L_hat_i)
        
        # Loss formula
        loss = (2.0 * diff * diff_stopgrad / L_cache_stopgrad).mean()
        
        # Backprop and update
        optimizer_fast.zero_grad()
        optimizer_other.zero_grad()
        
        loss.backward()
        
        optimizer_fast.step()
        optimizer_other.step()
```

## Subtopics

### [Fast Cache (Control Variate Radiance Cache)](9552-fast-cache-control-variate-radiance-cache.md)
A computationally efficient approximation of incoming radiance using a lightweight hash grid and small MLP, serving as a control variate to correct bias in the NeRF cache.

### [NeRF-Casting Reflection Model](11495-nerf-casting-reflection-model.md)
A rendering procedure for specular reflections that casts reflected rays through a volume representation and uses a lightweight decoder, differing by explicitly approximating the reflection cone via a von Mises-Fisher distribution.

### [Conical Reflected Features](11502-conical-reflected-features.md)
Estimates expected volume-rendered features over a vMF distribution of reflected rays, avoiding Monte Carlo integration costs by modeling angular spread via conical sampling.

## Operating characteristics
*   **Time Complexity:** Stage 1 takes 5.5 hours on a single A100 for 100,000 iterations [S1]. Stage 2 takes 6.5 hours on a single A100 for 100,000 iterations [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Reduces bias in radiance caching by using a control variate (Fast Cache) [S1]. Joint training allows for consistent optimization of material and environment [S1].
*   **Limitations:** Requires significant GPU time (12+ hours total for full training) [S1]. Relies on the quality of the initial Zip-NeRF cache [S1].
*   **When to Use:** When high-fidelity inverse rendering with accurate specular reflections is required, and computational resources allow for multi-stage optimization [S1].
*   **When Not to Use:** When real-time performance is required during training, or when hardware is limited (e.g., no A100-class GPU) [S1].

## Background
The Zip-NeRF Training Procedure is described in "Flash Cache: Reducing Bias in Radiance Cache Based Inverse Rendering" [S1]. It builds upon the Zip-NeRF acceleration structure and addresses the bias issues in radiance caching for inverse rendering [S1]. The method integrates concepts from RawNeRF's loss function and gradient trick [S1].
