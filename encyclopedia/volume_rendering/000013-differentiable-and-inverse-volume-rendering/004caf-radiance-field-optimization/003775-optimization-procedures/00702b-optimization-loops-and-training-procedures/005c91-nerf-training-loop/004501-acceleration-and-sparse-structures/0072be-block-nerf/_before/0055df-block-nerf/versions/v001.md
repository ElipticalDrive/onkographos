# Block-NeRF


## Overview
Block-NeRF is a method for scalable large-scale neural view synthesis that decomposes an environment into multiple independently trained Neural Radiance Fields (Block-NeRFs), each fitting into memory [S1]. It decouples rendering time from scene size and allows per-block updates without retraining the entire environment [S1]. Unlike network ensembles that must be trained jointly, Block-NeRFs are modeled independently, allowing maximum flexibility and piecewise updates [S1].

## How it works
Block-NeRF represents large-scale environments by splitting the scene into a set of Block-NeRFs [S1]. Each Block-NeRF is trained on data within a specific radius of its origin coordinate [S1]. At inference, the system selects relevant blocks, renders them, and composites the results [S1].

### Inputs and Outputs
**Inputs:**
- A set of posed camera images with known exposure levels and appearance conditions [S1].
- Camera poses, refined via learned pose offsets [S1].
- A grid of Block-NeRF origins defining the spatial decomposition [S1].

**Outputs:**
- A rendered image for a target view, composited from active Block-NeRFs [S1].
- Trained Block-NeRF models, each containing density, color, and visibility networks [S1].

### Data Structures
Each Block-NeRF consists of three Multi-Layer Perceptrons (MLPs) [S1]:
1.  **Density Network ($f_\sigma$):** Predicts volume density $\sigma$ and a feature vector.
    -   Structure: 8 layers, width 512 (Mission Bay) or 1024 (other experiments) [S1].
2.  **Color Network ($f_c$):** Predicts color $c$ given density features, viewing direction, exposure, and appearance embedding.
    -   Structure: 3 layers, width 128 [S1].
3.  **Visibility Network ($f_v$):** Predicts visibility (approximation of transmittance $T_i$) for culling blocks.
    -   Structure: 4 layers, width 128 [S1].

**Parameters:**
-   **Appearance Embeddings:** 32-dimensional latent codes per image, optimized via Generative Latent Optimization [S1].
-   **Pose Offsets:** Per-segment translation and $3 \times 3$ residual rotation matrix, initialized to 0 [S1].
-   **Exposure Scaling Factor ($t$):** 1,000 [S1].

### Numbered Steps

#### 1. Scene Decomposition and Placement
1.  Divide the environment into a grid of Block-NeRFs to ensure full coverage [S1].
2.  Place Block-NeRF origins typically at intersections, covering the intersection and 75% of the way to the next, resulting in 50% overlap between adjacent blocks on connecting street segments [S1].
3.  Apply a geographical filter to ensure training data for each block stays exactly within its intended bounds [S1].

#### 2. Training Individual Block-NeRFs
For each Block-NeRF, optimize the networks $f_\sigma$, $f_c$, and $f_v$ jointly:

1.  **Input Processing:**
    -   For a sample point $x$ and viewing direction $d$, compute positional encoding [S1].
    -   Compute exposure input: $E = \gamma_{PE}(\text{shutter speed} \times \text{analog gain} / t)$, where $\gamma_{PE}$ is a sinusoidal positional encoding with 4 levels and $t=1000$ [S1].
    -   Retrieve the appearance embedding $a$ for the current image [S1].

2.  **Density Prediction:**
    -   Feed $x$ into $f_\sigma$ to predict density $\sigma$ and a feature vector $z$ [S1].

3.  **Color Prediction:**
    -   Concatenate $z$, $d$, $E$, and $a$ [S1].
    -   Feed the concatenated vector into $f_c$ to output color $c$ [S1].

4.  **Visibility Prediction:**
    -   Feed $x$ and $d$ into $f_v$ to predict visibility $v$ [S1].
    -   Supervise $v$ using Mean Squared Error (MSE) loss against the transmittance $T_i$ computed from $\sigma$, scaled by $10^{-6}$ [S1].
    -   $T_i = \exp(-\sum_{j<i} \Delta_j \sigma_j)$, where $\Delta_j = t_j - t_{j-1}$ [S1].

5.  **Transient Object Handling:**
    -   Use a semantic segmentation model to mask dynamic objects (cars, pedestrians) [S1].
    -   Ignore masked areas during training [S1].

6.  **Pose Refinement:**
    -   Optimize pose offsets (translation and rotation) jointly with the NeRF [S1].
    -   Regularize the element-wise L2 norm of pose offsets, scaled by $10^5$ at start, linearly decaying to $10^{-1}$ after 5000 iterations [S1].

7.  **Optimization:**
    -   Use Adam optimizer [S1].
    -   Batch size: 16,384 [S1].
    -   Iterations: 300,000 [S1].
    -   Learning rate: Annealed logarithmically from $2 \times 10^{-3}$ to $2 \times 10^{-5}$, with warm-up for first 1024 iterations [S1].
    -   Sampling: 256 samples for coarse/fine networks during training [S1].

#### 3. Appearance Alignment
1.  Start from a root Block-NeRF [S1].
2.  Optimize the appearance embeddings of neighboring Block-NeRFs to minimize L2 loss between their respective area renders and the root [S1].
3.  Propagate optimized appearance iteratively through the scene [S1].
4.  Convergence typically occurs within 100 iterations per block [S1].

#### 4. Inference and Compositing
1.  **Block Selection:**
    -   Compute visibility maps for all Block-NeRFs within a given radius of the camera [S1].
    -   Discard Block-NeRFs with low visibility [S1].
    -   Render only a subset of active blocks [S1].

2.  **Rendering:**
    -   For each active Block-NeRF, render the image using standard volume rendering integration [S1].
    -   $c_{out} = \sum_{i=1}^{N} w_i c_i$, where $w_i = T_i (1 - e^{-\Delta_i \sigma_i})$ [S1].

3.  **Compositing:**
    -   Interpolate between Block-NeRF renders using inverse distance weighting (IDW) in 2D image space [S1].
    -   Calculate weights $w_i \propto \text{distance}(c, x_i)^{-p}$, where $c$ is the camera origin, $x_i$ is the Block-NeRF center, and $p$ is the power parameter [S1].
    -   Typical $p$ values: 4 for Alamo Square, 1 for Mission Bay [S1].

### Parameters and Typical Values
-   **Network Widths:** $f_\sigma$: 512 (Mission Bay) or 1024; $f_c$: 128; $f_v$: 128 [S1].
-   **Appearance Embedding Dim:** 32 [S1].
-   **Batch Size:** 16,384 [S1].
-   **Iterations:** 300,000 [S1].
-   **Learning Rate:** $2 \times 10^{-3}$ to $2 \times 10^{-5}$ [S1].
-   **Sampling:** 256 (training), 512 (video rendering) [S1].
-   **Visibility Loss Scale:** $10^{-6}$ [S1].
-   **Pose Regularization:** $10^5$ decaying to $10^{-1}$ over 5000 iterations [S1].
-   **IDW Power ($p$):** 4 (Alamo Square), 1 (Mission Bay) [S1].

### Edge Cases and Pitfalls
-   **Transient Objects:** Dynamic objects (cars, pedestrians) violate the static scene assumption. Must be masked out using semantic segmentation during training [S1].
-   **Temporal Artifacts:** Reducing overlap improves PSNR/SSIM but increases temporal artifacts during interpolation. 50% overlap is recommended to avoid these artifacts [S1].
-   **Pose Errors:** Collected data may have pose errors. Learned pose refinement is required, but must be heavily regularized in early training to allow the network to learn rough geometry first [S1].
-   **Exposure Variance:** Varying lighting and weather conditions require appearance embeddings and exposure conditioning to prevent visual discontinuities [S1].

## Operating characteristics
-   **Time Complexity:** Rendering time is decoupled from scene size; only active blocks are rendered [S1]. Typically fewer than 3 blocks are rendered per frame [S1].
-   **Memory Complexity:** Each Block-NeRF fits into memory independently [S1].
-   **Performance:** Training takes 9–24 hours per Block-NeRF on 32 TPU v3 cores [S1]. Rendering a 1200x900px image for a single Block-NeRF takes ~5.9 seconds [S1].
-   **Scalability:** Scales to arbitrarily large environments by adding blocks [S1].
-   **Strengths:** Independent training allows piecewise updates; no need for large-scale SfM; handles environmental variations [S1].
-   **Limitations:** Requires careful placement and overlap management; appearance alignment is an iterative optimization process [S1].

## Background
Block-NeRF was introduced by Matthew Tancik, Vincent Casser, Xinchen Yan, Ben Mildenhall, Pratul P. Srinivasan, Jonathan T. Barron, Sabeek Pradhan, and Henrik Kretzschmar in arXiv:2202.05263v1 on Feb 10, 2022 [S1]. It builds on mip-NeRF and NeRF-W, extending them to handle large-scale urban scenes collected over months with varying conditions [S1]. It is used for autonomous driving simulation and aerial surveying [S1].
