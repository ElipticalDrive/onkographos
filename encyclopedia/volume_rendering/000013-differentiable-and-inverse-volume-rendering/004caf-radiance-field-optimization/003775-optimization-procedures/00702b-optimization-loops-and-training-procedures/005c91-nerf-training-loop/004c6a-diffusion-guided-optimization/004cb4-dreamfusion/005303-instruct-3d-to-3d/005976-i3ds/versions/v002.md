# I3DS
Also called: I3DS (Iterative 3D Diffusion Synthesis), Iterative 3D Diffusion Synthesis, Iterative 3D Synchronization

## Overview
I3DS is an iterative framework for super-resolving a Low-Resolution (LR) Neural Radiance Field (NeRF) into a Super-Resolution (SR) NeRF by alternating between 2D image upscaling via diffusion models and 3D NeRF synchronization to ensure view consistency [S1]. It solves the problem of generating high-fidelity, view-consistent 3D geometry and texture from LR inputs without requiring large multi-view image datasets or high-resolution reference images [S1]. Unlike [Focaldreamer](14868-focaldreamer.md), [DITTO-NeRF](17847-ditto-nerf.md), and [Text-to-Image-to-3D Reconstruction](19327-text-to-image-to-3d-reconstruction.md), I3DS segregates the process into distinct upscaling and synchronization stages rather than jointly optimizing 2D and 3D parameters in a single loop, achieving higher quality than prior-based methods while being significantly faster than diffusion-guided methods like DreamFusion [S1].

## How it works
**Inputs:**
*   $\omega_{lr}$: The initial low-resolution NeRF weights [S1].
*   $I_{lr}$: The set of low-resolution reference images [S1].
*   $P_{tr}$: The set of training camera poses [S1].
*   $y_{text}$: A fixed text prompt embedding (e.g., "subject, high resolution, 4K, photo") [S1].

**Outputs:**
*   $\omega_{sr}$: The super-resolved NeRF weights [S1].

**Data Structures:**
*   **NeRF ($\omega$):** Represents the radiance field. The implementation uses Instant-NGP as the default backbone [S1].
*   **Latent Space:** Images are encoded into latent vectors $z$ using a Variational Autoencoder (VAE) [S1].
*   **Ray Data:** Each ray is defined by origin $r_o$, direction $r_d$, and center color $ctr$ [S1].

**Parameters:**
*   $max\_stage\_iter$: Total number of I3DS cycles. Default is 4 [S1].
*   $max\_sync\_iter$: Number of synchronization steps per stage. Not given in the sources.
*   $batch\_size$: Number of patches processed during upscaling. Default is 16 [S1].
*   $\eta$: Learning rate for all learnable parameters. Default is $1e-2$ [S1].
*   $patch\_size$: Resolution of random crops in latent space. Default is $128 \times 128$ in latent space, corresponding to $512 \times 512$ image patches [S1].

**Algorithm:**
The method iterates through stages. In each stage, it first upscales the rendered images using a Refinement Step Diffusion (RSD) model, then synchronizes the NeRF to these new images [S1].

```python
def I3DS(ω_lr, I_lr, P_tr, max_stage_iter):
    ω = ω_lr
    for stage_iter in range(max_stage_iter):
        # Upscaling stage
        x0 = RENDER_IMAGE(ω, P_tr)
        x0 = INTERPOLATE_X4(x0)
        z0 = VAE_ENCODE(x0)
        z0_prime = RSD(z0, I_lr)
        x0_prime = VAE_DECODE(z0_prime)
        I_tr = x0_prime

        # Synchronization stage
        # max_sync_iter not given in sources
        for sync_iter in range(max_sync_iter):
            r_o, r_d, ctr = SAMPLE_RAYS(I_tr, P_tr)
            c_hat = RENDER_RAYS(r_o, r_d)
            # Gradient descent step on ω to minimize ||c_hat - ctr||
            ω = ω - η * ∇_ω ||c_hat - ctr||^2
            ω_old = ω
    return ω_sr = ω
```

**RSD Refinement Details:**
The RSD step refines the latent $z_0$ to be consistent with LR images $I_{lr}$ while adding high-frequency details guided by diffusion [S1]. It is related to Score Distillation Sampling (SDS) but operates on latent residuals [S1].
*   Input to RSD: Latent $z_0$, text prompt $y_{text}$, noise level $y_{noise\_level}$, min timestep $t_{min}$, max timestep $t_{max}$, LR images $I_{lr}$ [S1].
*   Output: Refined latent residuals $h_\theta$ [S1].
*   The RSD objective is derived from the difference of latent vector residuals $z_{t-1}$ and $\hat{z}_{t-1}$ (the one-step denoised estimate) [S1].
*   The loss is defined as $L_{RSD} = \|z_{t-1} - \hat{z}_{t-1}\|$ [S1].
*   $\hat{z}_{t-1}$ is obtained directly from the predicted noise $\hat{\epsilon}_\phi(z_t, y, t)$ using the DDPM denoising equation, avoiding re-noising $\hat{z}_0$ [S1].
*   In practice, RSD is applied to random crops of size $128 \times 128$ in latent space (corresponding to $512 \times 512$ image patches) with a batch size of 16 [S1].

**Edge Cases and Pitfalls:**
*   **Precision:** The method relies on the stability of the VAE encode/decode cycle and the diffusion model's denoising process [G]. Ensure that the VAE latent space normalization matches the diffusion model's expected input distribution [G].
*   **Boundaries:** The 4x interpolation step assumes the LR NeRF output is compatible with standard image interpolation [G]. If the NeRF output contains NaNs or extreme values, interpolation may fail; clamp or filter invalid pixels before encoding [G].

## Operating characteristics
*   **Time Complexity:** The optimization time is dominated by the diffusion upscaling and NeRF synchronization steps [S1].
*   **Memory Complexity:** Uses dynamic ray sampling to increase ray count when the occupancy grid is pruned, optimizing GPU memory usage [S1]. Patch-based processing ($128 \times 128$ latent crops) reduces memory footprint during upscaling [S1].
*   **Measured Performance:** On the LLFF dataset, DiSR-NeRF achieves the highest PSNR and SSIM scores among prior-based methods (DiSR-NeRF, IN2N, DreamFusion-SDS, SDx4) [S1]. NIQE scores improve with increasing I3DS cycles, indicating convergence to high-quality details [S1].
*   **Scaling:** The method scales with the number of stages (default 4) and sync iterations [G]. Increasing stages improves quality but increases time linearly [G].
*   **Strengths:** View-consistent super-resolution without high-res reference images; faster than DreamFusion due to segregated stages; high detail generation via diffusion [S1].
*   **Limitations:** Longer optimization time than NGP, SDx4, NeRF-SR, and IN2N due to RSD optimization [S1]. Relies on the quality of the LR NeRF and LR images [S1].
*   **When to use:** When super-resolving a NeRF from LR inputs without high-res references is required, and view consistency is critical [S1].
*   **When not to use:** When computational speed is the primary constraint and high resolution is not needed; use standard NeRF training or simple upsampling instead [G].

## Background
I3DS was introduced in the paper "DiSR-NeRF: Diffusion-Guided View-Consistent Super-Resolution NeRF" [S1]. It builds on the Instant-NGP backbone [S1] and utilizes Stable Diffusion for upscaling [S1]. The method was developed to address the limitations of existing NeRF super-resolution methods that either require high-resolution reference images or suffer from view inconsistency [S1]. The research was supported by the National Research Foundation, Singapore under its AI Singapore Programmes [S1].
