# InFusionSurf
## Overview
InFusionSurf is a NeRF-style RGB-D 3D surface reconstruction framework that refines depth information to enhance reconstruction quality with minimal impact on optimization time, using per-frame intrinsic refinement and TSDF Fusion prior learning [S1]. It addresses camera motion-induced blurs in depth frames by correcting the camera intrinsic matrix per frame and accelerates training by pre-training the geometric prior using classical TSDF Fusion [S1]. It builds on [Neural RGB-D Surface Reconstruction](11352-neural-rgb-d-surface-reconstruction.md) by adding specific intrinsic refinement and a two-stage initialization process [S1].
## How it works
**Inputs and Outputs:**
*   **Inputs:** A sequence of RGB-D video frames (color images $C_{u,v}^i$ and depth maps), initial camera poses $[R|t]$, and initial camera intrinsics ($f_x, f_y, c_x, c_y$) [S1].
*   **Outputs:** A trained hybrid scene representation consisting of a dense feature grid $\mathcal{V}^{(feat)}$, MLPs for color ($MLP^C$) and signed distance ($MLP^D$), per-frame latent embeddings $\xi_i$, per-frame intrinsic refinement parameters ($s^i, \tau^i$), and an image-plane deformation field (from parent method) [S1]. The final output is a renderable radiance field and a mesh extracted via Marching Cubes [S1].

**Data Structures:**
1.  **Dense Feature Grid $\mathcal{V}^{(feat)}$:**
    *   Layout: 3D array of dimensions $N_x \times N_y \times N_z$ [S1].
    *   Dimensions calculated as $N_x = \lceil L_x/g_s \rceil$, $N_y = \lceil L_y/g_s \rceil$, $N_z = \lceil L_z/g_s \rceil$, where $L_x, L_y, L_z$ are scene bounds and $g_s$ is cell size [S1].
    *   Values: Each cell stores a feature vector of length $F$ [S1].
    *   Initialization: Zeros [S1].
2.  **MLPs:**
    *   $MLP^C$: Color decoder. 2 hidden layers, 128 nodes each [S1].
    *   $MLP^D$: Signed distance decoder. 2 hidden layers, 128 nodes each [S1].
    *   Image-plane deformation MLP (from parent): 2 hidden layers, 64 nodes each [S1].
3.  **Per-Frame Parameters:**
    *   Scaling matrix $s^i \in \mathbb{R}^{3 \times 3}$ and translation vector $\tau^i \in \mathbb{R}^3$ for each frame $i$ [S1].
    *   Latent embedding $\xi_i$ for each frame $i$ [S1].

**Numbered Steps:**
1.  **Scene Bounds and Grid Setup:** Estimate scene bounds $L_x, L_y, L_z$ from depth frames and initial poses [S1]. Set cell size $g_s$ (default 0.1m) and feature length $F$ (default 12) [S1]. Compute grid dimensions $N_x, N_y, N_z$ and initialize $\mathcal{V}^{(feat)}$ with zeros [S1].
2.  **Phase 1: TSDF Fusion Prior Learning:** Set $F=1$ for this phase [S1]. Run TSDF Fusion on the input depth frames to generate a TSDF volume [S1]. Randomly sample grid cells and query their center points $p$ [S1]. Query the TSDF Fusion volume for the signed distance value $D_{TSDF}(p)$ [S1]. Compute feature vector $\phi_p$ via trilinear interpolation of the 8 nearest vertices in $\mathcal{V}^{(feat)}$ [S1]. Compute predicted signed distance $\hat{D}_p = MLP^D(\phi_p)$ [S1]. Minimize mean squared error between $\hat{D}_p$ and $D_{TSDF}(p)$ [S1]. Optimize only $\mathcal{V}^{(feat)}$ and $MLP^D$ [S1]. Run for 3,000 iterations [S1].
3.  **Phase 2: Progressive Learning (Low-Frequency):** Set $F=12$ [S1]. Randomly sample ray batches $r_b$ [S1]. For each ray, sample points $S_c$ every 0.015625m along the ray [S1]. Compute normalized image coordinates $\varrho_{u,v}$ using initial intrinsics [S1]:
    $$ \varrho_{u,v} = \begin{bmatrix} 1/f_x & 0 & -c_x/f_x \\ 0 & -1/f_y & c_y/f_y \\ 0 & 0 & -1 \end{bmatrix} \begin{bmatrix} u \\ v \\ 1 \end{bmatrix} $$
    *(Note: Source [S1] Eq. 6 contains a typo in the vector $\begin{bmatrix} v \\ u \\ 1 \end{bmatrix}$; standard pinhole projection uses $\begin{bmatrix} u \\ v \\ 1 \end{bmatrix}$ [S1].)* Apply per-frame intrinsic refinement to get refined $\hat{\varrho}_{u,v}^i$ [S1]. Compute ray direction $\hat{d}_{u,v}^i = [R|t] [\hat{\varrho}_{u,v}^i; 1]$ [S1]. Sample points $p$ along $\hat{d}_{u,v}^i$ [S1]. Compute $\phi_p$ via trilinear interpolation from $\mathcal{V}^{(feat)}$ [S1]. Compute $\hat{D}_p = MLP^D(\phi_p)$ [S1]. Compute weight $\omega_p = \sigma(\hat{D}_p/tr) \cdot \sigma(-\hat{D}_p/tr)$ [S1]. Compute color $C_{p,d}^i = MLP^C(\phi_p, \Lambda(\hat{d}_{u,v}^i), \xi_i)$ [S1]. Compute rendered color $\hat{C}_r^i = \frac{\sum \omega_p C_{p,d}^i}{\sum \omega_p}$ [S1]. Compute Loss $\mathcal{L}$ (see below) [S1]. Optimize all parameters ($\mathcal{V}^{(feat)}, MLP^C, MLP^D, \xi_i, s^i, \tau^i$, deformation field) [S1]. Run for 7,000 iterations [S1].
4.  **Phase 3: Progressive Learning (High-Frequency):** Halve the grid cell size $g_s$ (e.g., from 0.1m to 0.05m) [S1]. Re-initialize or resize $\mathcal{V}^{(feat)}$ to new dimensions $N_x, N_y, N_z$ [S1]. Sample points $S_c$ as in Phase 2 [S1]. Identify surfaces in $S_c$ and sample additional points $S_f$ around these surfaces [S1]. Use both $S_c$ and $S_f$ for loss computation [S1]. Optimize all parameters [S1]. Run for 65,000 iterations [S1].

**Per-Frame Intrinsic Refinement:**
*   For each frame $i$, optimize scaling $s^i$ and translation $\tau^i$ [S1].
*   $s^i = \text{diag}(s_x^i, s_y^i, 1)$, $\tau^i = [\tau_x^i, \tau_y^i, 0]^T$ [S1].
*   Initialize $s^i$ to identity (1,1,1) and $\tau^i$ to zero [S1].
*   Refined coordinate: $\hat{\varrho}_{u,v}^i = s^i \cdot (\varrho_{u,v} + \tau^i)$ [S1].

**Loss Function:**
$$ \mathcal{L} = \lambda_{fs} \mathcal{L}_{fs} + \lambda_{sdf} \mathcal{L}_{sdf} + \lambda_{rgb} \mathcal{L}_{rgb} + \lambda_{reg} \mathcal{L}_{reg} $$
*   $\mathcal{L}_{fs}$ (Points outside truncation $S_{fs}$): $\frac{1}{|r_b|} \sum_{r \in r_b} \frac{1}{|S_{fs}|} \sum_{\mathbf{p} \in S_{fs}} (\hat{D}_p - tr)^2$ [S1].
*   $\mathcal{L}_{sdf}$ (Points inside truncation $S_{sdf}$): $\frac{1}{|r_b|} \sum_{r \in r_b} \frac{1}{|S_{sdf}|} \sum_{\mathbf{p} \in S_{sdf}} (\hat{D}_p - D_r^i)^2$, where $D_r^i$ is the observed depth-derived signed distance [S1].
*   $\mathcal{L}_{rgb}$: $\frac{1}{|r_b|} \sum_{r \in r_b} (\hat{C}_r^i - C_{u,v}^i)^2$ [S1].
*   $\mathcal{L}_{reg}$: L2 regularization on $\xi_i$, $s^i, \tau^i$, and deformation parameters [S1]. Scaling parameters are regularized around 1 [S1].

**Parameters:**
*   $tr = 0.05$m [S1].
*   $\lambda_{fs} = 10, \lambda_{sdf} = 6 \times 10^3, \lambda_{rgb} = 0.5, \lambda_{reg} = 0.1$ [S1].
*   Optimizer: ADAM, lr=$5 \times 10^{-4}$, decays to 1/10 every 250K iterations, $\beta_1=0.9, \beta_2=0.999$ [S1].
*   Training iterations: 3K for phase 1, 7K for phase 2, 65K for phase 3 [S1].
*   Feature grid dimension $F=12$ (Phase 2/3), $F=1$ (Phase 1) [S1].
*   Cell size $g_s=0.1$m [S1].
*   Per-frame intrinsic refinement adds only four additional parameters per frame [S1].

        self.scene_bounds = scene_bounds  # Lx, Ly, Lz in meters
        self.depth_frames = depth_frames
        self.color_frames = color_frames
        self.poses = initial_poses        # [R|t]
        self.fx, self.fy, self.cx, self.cy = initial_intrinsics
        
        # Hyperparameters
        self.gs = 0.1                     # 10cm
        self.tr = 0.05                    # 5cm

        Nz = int(np.ceil(scene_bounds[2] / self.gs))
        
        # Data structures
        self.V_feat = torch.zeros(Nx, Ny, Nz, 1)  # Phase 1 uses F=1
        self.MLP_D = MLP(in_dim=1, h1=128, h2=128, out_dim=1)
        self.MLP_C = MLP(in_dim=1, h1=128, h2=128, out_dim=3)  # Input dim updated dynamically in forward
        self.deformation_MLP = MLP(in_dim=2, h1=64, h2=64, out_dim=2)  # From parent method
        
        # Per-frame parameters
        self.num_frames = len(depth_frames)
        self.scales = torch.ones(self.num_frames, 3)  # sx, sy, 1
        self.translations = torch.zeros(self.num_frames, 3)  # tx, ty, 0
        self.latents = torch.randn(self.num_frames, 16)  # Example latent dim
        
        # Optimizers
        self.opt_phase1 = torch.optim.Adam(list(self.V_feat) + list(self.MLP_D.parameters()), lr=5e-4)
        self.opt_phase2 = torch.optim.Adam(
            list(self.V_feat) + list(self.MLP_C.parameters()) + 
            list(self.MLP_D.parameters()) + list(self.deformation_MLP.parameters()) + 
            [self.scales, self.translations, self.latents], lr=5e-4
        )

    def trilinear_interp(self, V, points):
        # points: (N, 3) in grid coordinates [0, Nx-1], [0, Ny-1], [0, Nz-1]
        # Returns (N, F)
        p = points.float()
        p0 = p.floor().long()
        p1 = p0 + 1
        p0[:, 0] = torch.clamp(p0[:, 0], 0, V.shape[0]-1)
        p0[:, 1] = torch.clamp(p0[:, 1], 0, V.shape[1]-1)
        p0[:, 2] = torch.clamp(p0[:, 2], 0, V.shape[2]-1)
        p1[:, 0] = torch.clamp(p1[:, 0], 0, V.shape[0]-1)
        p1[:, 1] = torch.clamp(p1[:, 1], 0, V.shape[1]-1)
        p1[:, 2] = torch.clamp(p1[:, 2], 0, V.shape[2]-1)
        
        w000 = V[p0[:,0], p0[:,1], p0[:,2]]
        w100 = V[p1[:,0], p0[:,1], p0[:,2]]
        w010 = V[p0[:,0], p1[:,1], p0[:,2]]
        w110 = V[p1[:,0], p1[:,1], p0[:,2]]
        w001 = V[p0[:,0], p0[:,1], p1[:,2]]
        w101 = V[p1[:,0], p0[:,1], p1[:,2]]
        w011 = V[p0[:,0], p1[:,1], p1[:,2]]
        w111 = V[p1[:,0], p1[:,1], p1[:,2]]
        
        dx, dy, dz = p - p0.float()
        w00 = w000 * (1-dx) + w100 * dx
        w01 = w001 * (1-dx) + w101 * dx
        w10 = w010 * (1-dx) + w110 * dx
        w11 = w011 * (1-dx) + w111 * dx
        return w00 * (1-dy) + w10 * dy + (w01 * (1-dy) + w11 * dy) * dz

    def get_normalized_coords(self, u, v):
        # Standard inverse intrinsic matrix applied to [u, v, 1]^T [S1]
        x = (u - self.cx) / self.fx
        y = -(v - self.cy) / self.fy
        z = -torch.ones_like(u)
        return torch.stack([x, y, z], dim=-1)

    def refine_intrinsics(self, rho, frame_idx):
        s = self.scales[frame_idx]
        t = self.translations[frame_idx]
        s_mat = torch.diag(s)
        rho_refined = (s_mat @ (rho + t.unsqueeze(0)).T).T
        return rho_refined

    def compute_sdf_loss(self, points, D_obs, is_outside):
        D_pred = self.MLP_D(self.trilinear_interp(self.V_feat, points))
        target = self.tr if is_outside else D_obs
        return torch.mean((D_pred - target) ** 2)

    def render(self, ray_dirs, frame_idx):
        # Sample points along rays
        t_vals = torch.linspace(0.1, 5.0, 128)  # Example range
        points = ray_dirs.unsqueeze(1) * t_vals.unsqueeze(0) + self.poses[frame_idx][3].unsqueeze(0)

        weights = torch.sigmoid(D_pred / self.tr) * torch.sigmoid(-D_pred / self.tr)
        color_input = torch.cat([phi, self.latents[frame_idx].unsqueeze(0).expand(phi.shape[0], -1)], dim=-1)
        colors = self.MLP_C(color_input)
        weights = weights / (weights.sum(dim=0, keepdim=True) + 1e-8)
        return (weights * colors).sum(dim=0)

## Operating characteristics
*   **Time Complexity:** Training is significantly faster than Neural RGB-D [S1]. 75K iterations take ~96 minutes on average, which is 7.3 to 8.7 times faster than Neural RGB-D [S1].
*   **Memory Complexity:** Uses a dense feature grid [S1]. Memory usage scales with $N_x N_y N_z F$ [S1]. The grid size is determined by scene bounds and cell size $g_s$ [S1].
*   **Measured Performance:** On ScanNet V2 and synthetic scenes, InFusionSurf outperforms GO-Surf in C-ℓ1, IoU, and F-score with 20% less training time at 20K iterations [S1]. While InFusionSurf showed outstanding performance on the three major measures, it was less effective on normal consistency (NC), indicating relatively uneven surfaces [S1].
*   **Strengths:** Fast training, high-quality geometry reconstruction, handles motion blur in depth frames via intrinsic refinement [S1].
*   **Limitations:** Relies on simple transformation matrices for intrinsic refinement; does not handle local blurs (object motion, rolling shutter) effectively [S1]. Less effective on normal consistency [S1].
*   **When to use:** Quick reconstruction of complex geometries from RGB-D video with camera motion [S1].
*   **When not to use:** Scenes with significant local motion blur or rolling shutter effects where uniform intrinsic refinement is insufficient [S1].
