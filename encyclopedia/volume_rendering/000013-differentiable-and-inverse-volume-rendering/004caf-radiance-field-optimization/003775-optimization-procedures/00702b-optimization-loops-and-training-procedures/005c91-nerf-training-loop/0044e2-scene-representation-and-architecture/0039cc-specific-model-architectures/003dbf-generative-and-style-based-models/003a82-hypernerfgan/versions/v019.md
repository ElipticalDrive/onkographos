# HyperNeRFGAN

Also called: Hypernetwork NeRF GAN, HyperNeRF

## Overview
HyperNeRFGAN is a generative model that uses a hypernetwork to produce the weights of a simplified NeRF target network, trained using the StyleGAN2 objective to generate 3D representations from a Gaussian noise distribution [S1, unofficial]. It solves the problem of 3D-aware image generation when camera positions are unavailable or unreliable by removing viewing directions from the NeRF input and using a hypernetwork to implicitly encode 3D structure [S1, unofficial]. It sets itself apart from siblings like [GRAF](11360-giraffe.md) and [π-GAN](10298-pi-gan.md) by generating NeRF weights directly via Factorized Multiplicative Modulation (FMM) layers rather than conditioning a SIREN-based field, and from [StyleNeRF](8659-stylenerf.md) by using a single MLP for density and color without explicit view dependence [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Generator Input:** A noise vector $\mathbf{z}$ sampled from a standard Gaussian distribution $\mathcal{N}(0, I)$ [S1, unofficial].
*   **Generator Output:** The weights $\theta$ of the target NeRF model $F_\theta$ [S1, unofficial].
*   **Target NeRF Input:** 3D spatial coordinates $\mathbf{x} = (x, y, z)$ [S1, unofficial].
*   **Target NeRF Output:** Volume density $\sigma$ and color $\mathbf{c}$ [S1, unofficial].
*   **Discriminator Input:** 2D rendered images [S1, unofficial].
*   **Discriminator Output:** Real/Fake probability [S1, unofficial].

**Data Structures:**
The target NeRF $F_\theta$ is a single Multi-Layer Perceptron (MLP) [S1, unofficial].
*   **Architecture:** It consists of hidden layers using Factorized Multiplicative Modulation (FMM) layers [S1, unofficial].
*   **FMM Layer Layout:** An FMM layer transforms an input $\mathbf{x}_{in}$ to output $\mathbf{y}$ using shared weights $\mathbf{W}$ and $\mathbf{b}$, and modulation matrices $\mathbf{A}$ and $\mathbf{B}$ generated by the hypernetwork [S1, unofficial].
    *   $\mathbf{W} \in \mathbb{R}^{n_{out} \times n_{in}}$
    *   $\mathbf{b} \in \mathbb{R}^{n_{out}}$
    *   $\mathbf{A} \in \mathbb{R}^{n_{out} \times k}$
    *   $\mathbf{B} \in \mathbb{R}^{k \times n_{in}}$
    *   $k$ is the rank parameter, controlling the trade-off between expressiveness and memory [S1, unofficial].
*   **Target Network Dimensions:**
    *   Hidden layer channels: 128 (reduced from standard 256) [S1, unofficial].
    *   Hidden layers: 4 to 8 (reduced from standard 8) [S1, unofficial].
    *   Output: Concatenated $\sigma$ and $\mathbf{c}$ [S1, unofficial].

**Rendering Integration:**
The target NeRF $F_\theta$ renders 2D images from various perspectives. The rendering follows the standard volumetric rendering integral [G], but without viewing direction inputs [S1, unofficial].
$$
C(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i, \quad \text{where } \alpha_i = 1 - \exp(-\sigma_i \delta_i), \quad T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)
$$
where $\delta_i$ is the distance between samples along ray $\mathbf{r}$ [G].

**Training Procedure:**
The model is trained using a minimax game between a Generator $G$ (the hypernetwork) and a Discriminator $D$ [S1, unofficial].

1.  Sample a noise vector $\mathbf{z} \sim \mathcal{N}(0, I)$ [S1, unofficial].
2.  Pass $\mathbf{z}$ through Generator $G$ to obtain the target NeRF weights $\theta = G(\mathbf{z})$ [S1, unofficial].
3.  Instantiate the target NeRF $F_\theta$ using $\theta$ [S1, unofficial].
4.  Render 2D images from multiple camera viewpoints using $F_\theta$ [S1, unofficial].
5.  Compute the GAN loss $V(D, G)$ [S1, unofficial]:
    $$
    V(D, G) = \mathbb{E}_{\mathbf{x} \sim P_{data}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z} \sim P_{noise}}[\log(1 - D(G(\mathbf{z})))]
    $$
    where $P_{data}$ is the distribution of real 2D images and $P_{noise}$ is the Gaussian noise distribution [S1, unofficial].
6.  Update $G$ and $D$ to minimize $V(D, G)$ with respect to $G$ and maximize it with respect to $D$ [S1, unofficial].

import torch
import torch.nn as nn
import torch.nn.functional as F

class FMMLayer(nn.Module):
    """
    Factorized Multiplicative Modulation Layer.
    y = W * (A @ B) * x_in + b
    """
    def __init__(self, n_in, n_out, k):
        super().__init__()
        self.n_in = n_in
        self.n_out = n_out
        self.k = k
        # Shared weights (learned during training, not generated by G)
        # Note: In HyperNeRFGAN, W and b are shared across instances,
        # but A and B are generated by G for each instance.
        # However, the paper states W and b are shared matrices.
        # Implementation detail: W and b are parameters of the FMM layer itself,
        # while A and B are inputs to this layer from the Generator.
        self.W = nn.Parameter(torch.randn(n_out, n_in) * 0.02)
        self.b = nn.Parameter(torch.zeros(n_out))

    def forward(self, x_in, A, B):
        # A: (n_out, k), B: (k, n_in)
        modulation = A @ B
        # Element-wise multiplication of W and modulation
        # W: (n_out, n_in), modulation: (n_out, n_in)
        weighted_W = self.W * modulation
        return F.linear(x_in, weighted_W, self.b)

class TargetNeRF(nn.Module):
    """
    Simplified NeRF using FMM layers.
    Input: x (3D position)
    Output: sigma, color
    """
    def __init__(self, n_layers=4, n_channels=128, k=10):
        super().__init__()
        self.n_layers = n_layers
        self.n_channels = n_channels
        self.k = k
        
        # Input layer: 3 -> n_channels
        self.fmm_0 = FMMLayer(3, n_channels, k)
        
        # Hidden layers: n_channels -> n_channels
        self.fmm_layers = nn.ModuleList([
            FMMLayer(n_channels, n_channels, k) for _ in range(n_layers - 2)
        ])
        
        # Output layers: n_channels -> 1 (sigma), n_channels -> 3 (color)
        # These are standard linear layers or FMM layers with fixed modulation?
        # The paper says "single MLP that takes spatial location... and transforms to c and sigma".
        # It implies the final layers might also be FMM or standard.
        # Given "FMM layers" are used in the architecture, we assume all layers are FMM.
        # However, standard NeRF has separate heads.
        # Let's assume the last layer produces sigma and the one before produces features for color.
        # Or simpler: The output of the last FMM is features.
        # We need to output sigma and color.
        # Let's assume standard linear heads for simplicity if not specified, 
        # but the paper emphasizes FMM. 
        # "F_theta employs factorized multiplicative modulation (FMM) layers"
        # We will use FMM for all layers.
        
        self.fmm_sigma = FMMLayer(n_channels, 1, k)
        self.fmm_color = FMMLayer(n_channels, 3, k)

    def forward(self, x, A_list, B_list):
        """
        x: (B, 3)
        A_list: List of A matrices for each layer, shape [(n_out, k), ...]
        B_list: List of B matrices for each layer, shape [(k, n_in), ...]
        """
        h = x
        # First layer
        h = self.fmm_0(h, A_list[0], B_list[0])
        h = F.relu(h)
        
        # Hidden layers
        for i, fmm in enumerate(self.fmm_layers):
            h = fmm(h, A_list[i+1], B_list[i+1])
            h = F.relu(h)
            
        # Output heads
        sigma = self.fmm_sigma(h, A_list[-2], B_list[-2]) # Assuming last layer index
        color = self.fmm_color(h, A_list[-1], B_list[-1])
        
        return sigma.squeeze(-1), color

class Generator(nn.Module):
    """
    Hypernetwork Generator (StyleGAN2 backbone).
    Input: z (noise vector)
    Output: List of A and B matrices for TargetNeRF
    """
    def __init__(self, n_layers=4, n_channels=128, k=10, z_dim=512):
        super().__init__()
        self.n_layers = n_layers
        self.n_channels = n_channels
        self.k = k
        self.z_dim = z_dim
        
        # StyleGAN2-like mapping network
        self.mapping = nn.Sequential(
            nn.Linear(z_dim, 512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, 512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, 512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, 512),
            nn.LeakyReLU(0.2),
        )
        
        # Synthesis network to generate modulation parameters
        # We need to generate A and B for each layer.
        # Total layers in TargetNeRF: 1 (input) + (n_layers-2) (hidden) + 2 (heads) = n_layers + 1
        # Actually, let's assume n_layers refers to hidden layers in TargetNeRF.
        # Total FMM layers = 1 (input) + n_layers (hidden) + 2 (heads) = n_layers + 3
        # But the paper says "decrease number of layers from 8 to 4".
        # Let's assume n_layers is the total number of FMM layers in TargetNeRF.
        
        self.num_fmm_layers = n_layers + 1 # Input + Hidden + Output heads? 
        # Let's stick to the paper's "4 layers" example.
        # If n_layers=4, we have 4 FMM layers? Or 4 hidden?
        # "decrease the number of layers from 8 to 4" usually refers to hidden layers.
        # Let's assume n_layers is the number of hidden layers.
        # Total FMM layers = 1 (input) + n_layers (hidden) + 2 (heads) = n_layers + 3
        
        self.synthesis = nn.Sequential(
            nn.Linear(512, 512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, 512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, 512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, 512),
            nn.LeakyReLU(0.2),
        )
        
        # Output layer to generate A and B for all FMM layers
        # Each FMM layer needs A (n_out, k) and B (k, n_in)
        # Layer 0: 3 -> n_channels. A: (n_channels, k), B: (k, 3)
        # Layer i: n_channels -> n_channels. A: (n_channels, k), B: (k, n_channels)
        # Layer last-1: n_channels -> 1. A: (1, k), B: (k, n_channels)
        # Layer last: n_channels -> 3. A: (3, k), B: (k, n_channels)
        
        # Simplified: Generate a large vector and reshape
        # Total params = sum(n_out * k + k * n_in) for all layers
        # Let's assume a simpler approach: Generate A and B for each layer sequentially
        
        self.num_fmm = n_layers + 3 # Input + Hidden + 2 Heads
        
        # Calculate total output size
        total_params = 0
        # Input layer
        total_params += n_channels * k + k * 3
        # Hidden layers
        for _ in range(n_layers):
            total_params += n_channels * k + k * n_channels
        # Output layers
        total_params += 1 * k + k * n_channels # Sigma
        total_params += 3 * k + k * n_channels # Color
        
        self.output_layer = nn.Linear(512, total_params)

    def forward(self, z):
        style = self.mapping(z)
        style = self.synthesis(style)
        params = self.output_layer(style)
        
        # Reshape params into A and B matrices for each layer
        A_list = []
        B_list = []
        
        idx = 0
        
        # Input layer: 3 -> n_channels
        n_out = self.n_channels
        n_in = 3
        A = params[:, idx:idx + n_out * self.k].view(-1, n_out, self.k)
        B = params[:, idx + n_out * self.k:idx + n_out * self.k + self.k * n_in].view(-1, self.k, n_in)
        A_list.append(A)
        B_list.append(B)
        idx += n_out * self.k + self.k * n_in
        
        # Hidden layers
        for _ in range(self.n_layers):
            n_out = self.n_channels
            n_in = self.n_channels
            A = params[:, idx:idx + n_out * self.k].view(-1, n_out, self.k)
            B = params[:, idx + n_out * self.k:idx + n_out * self.k + self.k * n_in].view(-1, self.k, n_in)
            A_list.append(A)
            B_list.append(B)
            idx += n_out * self.k + self.k * n_in
            
        # Sigma head: n_channels -> 1
        n_out = 1
        n_in = self.n_channels
        A = params[:, idx:idx + n_out * self.k].view(-1, n_out, self.k)
        B = params[:, idx + n_out * self.k:idx + n_out * self.k + self.k * n_in].view(-1, self.k, n_in)
        A_list.append(A)
        B_list.append(B)
        idx += n_out * self.k + self.k * n_in
        
        # Color head: n_channels -> 3
        n_out = 3
        n_in = self.n_channels
        A = params[:, idx:idx + n_out * self.k].view(-1, n_out, self.k)
        B = params[:, idx + n_out * self.k:idx + n_out * self.k + self.k * n_in].view(-1, self.k, n_in)
        A_list.append(A)
        B_list.append(B)
        
        return A_list, B_list

**Parameters:**
*   $k$ (rank of modulation matrices): 10 [S1, unofficial].
*   Hidden layer channels: 128 [S1, unofficial].
*   Network depth: 4 to 8 layers [S1, unofficial].
*   Input noise vector: Gaussian distribution [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Viewing Directions:** Standard NeRF requires viewing directions. HyperNeRFGAN omits them, which is suitable for datasets lacking view-dependent characteristics (e.g., reflections) [S1, unofficial].
*   **Fine Network:** HyperNeRFGAN rejects the "fine" network used in standard NeRF for multi-scale rendering, using only the "coarse" network to reduce training cost [S1, unofficial].
*   **Computational Expense:** Reducing channels from 256 to 128 and layers from 8 to 4 reduces computational expense [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time is reduced compared to standard NeRF due to the omission of the fine network and reduced network size (128 channels, 4-8 layers) [S1, unofficial].
*   **Memory Complexity:** Controlled by the rank $k$ of the modulation matrices. Higher $k$ increases expressiveness but also memory usage [S1, unofficial].
*   **Measured Performance:**
    *   **ShapeNet Car:** FID 29.6 (vs. Point2NeRF 82.1) [S1, unofficial].
    *   **CARLA:** FID 20.5, KID 0.78, IS 4.20 (outperforming HoloGAN, GRAF, π-GAN) [S1, unofficial].
    *   **CelebA:** FID 15.04, KID 0.66, IS 2.63 (comparable to π-GAN) [S1, unofficial].
*   **Strengths:** Does not require camera position information; suitable for medical data and datasets with few views; superior performance on datasets where camera estimation is challenging [S1, unofficial].
*   **Limitations:** Cannot model view-dependent effects (e.g., reflections) as viewing directions are omitted [S1, unofficial].
*   **When to Use:** When camera poses are unknown/unreliable, or for medical imaging (DRR) [S1, unofficial].
*   **When Not to Use:** When view-dependent effects are critical [S1, unofficial].

## Background
HyperNeRFGAN was introduced in 2023 by authors who proposed using a hypernetwork to generate NeRF weights, trained with a StyleGAN2 objective [S1, unofficial]. It addresses the limitation of NeRF training requiring camera positions, which is often unavailable in medical data or datasets with few views [S1, unofficial]. It builds on the hypernetwork paradigm [Ha et al., 2016] and INR-GAN [S1, unofficial].
