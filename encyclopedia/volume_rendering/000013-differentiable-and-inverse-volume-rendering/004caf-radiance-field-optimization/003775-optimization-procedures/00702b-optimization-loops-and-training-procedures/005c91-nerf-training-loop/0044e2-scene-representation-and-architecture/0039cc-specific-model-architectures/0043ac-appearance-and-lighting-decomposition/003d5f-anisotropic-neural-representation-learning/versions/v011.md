# Anisotropic Neural Representation Learning

Also called: Anisotropic NeRF, SH-guided anisotropic features

## Overview
Anisotropic Neural Representation Learning (ANRL) is a method for neural volume rendering that models volumetric density and latent features as view-dependent functions using spherical harmonics (SH) to eliminate directional ambiguity [S1]. Unlike standard NeRF which assumes isotropic point-sampled features, ANRL replaces the initial MLP output with SH coefficients, allowing the representation to capture anisotropy directly without shape-based sampling parameterization [S1]. This approach improves reconstruction quality in scenes with complex lighting or reflective surfaces while maintaining rendering efficiency [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Ray origin $\mathbf{o}$, direction $\mathbf{d}$, near/far bounds $t_n, t_f$ [S1].
*   **Output:** Pixel color $C(\mathbf{r})$ [S1].

**Data Structures:**
The method modifies the first Multi-Layer Perceptron (MLP) of the standard NeRF architecture [S1].
1.  **Positional Encoding:** Input coordinates $\mathbf{x}$ and directions $\mathbf{d}$ are mapped to a higher-dimensional space using positional encoding $\gamma(\cdot)$ to mitigate spectral bias [S1].
    $$
    \gamma(\mathbf{x}) = (\sin(2^0 \pi \mathbf{x}), \cos(2^0 \pi \mathbf{x}), \dots, \sin(2^{L-1} \pi \mathbf{x}), \cos(2^{L-1} \pi \mathbf{x}))
    $$
    where $L$ is the number of frequency bands [G].
2.  **SH-MLP ($F_{SH}$):** Takes $\gamma(\mathbf{x})$ as input [S1]. It consists of $L$ hidden layers with ReLU activations and skip connections from the input to every 4th layer [S1]. Instead of outputting raw density $\sigma$ and latent features, it outputs coefficients for spherical harmonic basis functions [S1].
3.  **Appearance MLP ($F_c$):** Takes the evaluated view-dependent features, $\gamma(\mathbf{x})$, and $\mathbf{d}$ as input to compute final color $\mathbf{c}$ [S1].

**Numbered Steps:**
1.  **Ray Sampling:** Sample $N$ points $t_i$ along the ray within bounds $[t_n, t_f]$ in near-to-far order [S1]. Define intervals $I_i = [t_i, t_{i+1}]$ [S1].
2.  **SH Coefficient Prediction:** For each sample point $\mathbf{x}_i$, pass $\gamma(\mathbf{x}_i)$ through $F_{SH}$ to obtain SH coefficients $\mathbf{w}_i$ [S1].
3.  **Anisotropic Feature Evaluation:** Evaluate the SH basis functions at the query viewing direction $\mathbf{d}$ using coefficients $\mathbf{w}_i$ to produce view-dependent density $\sigma_i$ and latent features $\mathbf{f}_i$ [S1]. This step captures anisotropy explicitly [S1].
4.  **Regularization (Training Only):** Decompose anisotropic elements from the predicted density and latent features [S1]. Apply a point-wise operation to penalize the energy of anisotropy in the geometry representation to prevent over-fitting and shape-radiance ambiguity [S1].
5.  **Color Computation:** Pass $\mathbf{f}_i$, $\gamma(\mathbf{x}_i)$, and $\mathbf{d}$ through $F_c$ to obtain color $\mathbf{c}_i$ [S1].
6.  **Volume Rendering:** Compute pixel color using the discrete Riemann sum approximation [S1]:
    $$
    \hat{C}(\mathbf{r}) = \sum_{i=0}^{N} \mathbf{c}_i T_i (1 - \exp(-\sigma_i (t_{i+1} - t_i)))
    $$
    where $T_i = \exp\left(-\sum_{j=0}^{i-1} \sigma_j (t_{j+1} - t_j)\right)$ represents occlusion [S1].

**Pseudocode:**
```python
import numpy as np

def positional_encoding(x, L):
    """Standard positional encoding for mitigating spectral bias [G]."""
    freq_bands = 2.0 ** np.arange(L) * np.pi
    return np.concatenate([np.sin(x * freq_bands), np.cos(x * freq_bands)], axis=-1)

def sh_basis(direction, degree):
    """Computes SH basis functions for a given direction [G]."""
    d = direction / np.linalg.norm(direction)
    x, y, z = d
    basis = []
    # Degree 0
    basis.append(1.0 / np.sqrt(4 * np.pi))
    # Degree 1
    if degree >= 1:
        inv_sqrt = 1.0 / np.sqrt(3 * np.pi)
        basis.append(z * inv_sqrt)
        basis.append(x * inv_sqrt)
        basis.append(y * inv_sqrt)
    # Degree 2 (standard compact form)
    if degree >= 2:
        inv_sqrt2 = 1.0 / np.sqrt(5 * np.pi)
        basis.append((3 * z**2 - 1) * inv_sqrt2)
        basis.append(x * z * inv_sqrt2)
        basis.append(y * z * inv_sqrt2)
        basis.append((x**2 - y**2) * inv_sqrt2)
        basis.append(x * y * inv_sqrt2)
    return np.array(basis)

def anisotropic_nerf_forward(x_samples, d, sh_mlp, color_mlp, degree, t_bounds):
    """Forward pass for Anisotropic Neural Representation Learning."""
    N = x_samples.shape[0]
    L = 10  # Typical number of frequency bands [G]
    
    # 1. Positional Encoding
    gamma_x = positional_encoding(x_samples, L)
    
    # 2. Predict SH Coefficients
    # sh_mlp outputs coefficients for density and latent features
    sh_coeffs = sh_mlp(gamma_x)  # Shape: (N, K)
    
    # 3. Evaluate Anisotropic Features
    sh_basis_vec = sh_basis(d, degree)  # Shape: (K,)
    # Project coefficients onto direction to get view-dependent values
    # Assuming first half of coefficients are for density, second for features
    K = sh_coeffs.shape[1]
    mid = K // 2
    sigma = np.dot(sh_coeffs[:, :mid], sh_basis_vec)  # Shape: (N,)
    features = np.dot(sh_coeffs[:, mid:], sh_basis_vec)  # Shape: (N, F)
    
    # 4. Regularization (Training Only)
    # [G] Specific regularization formula not provided in sources.
    # loss_aniso = compute_anisotropy_penalty(sigma, features)
    
    # 5. Color Computation
    colors = color_mlp(features, gamma_x, d)  # Shape: (N, 3)
    
    # 6. Volume Rendering
    t_n, t_f = t_bounds
    t = np.linspace(t_n, t_f, N + 1)
    deltas = t[1:] - t[:-1]
    
    # Transmittance and alpha
    sigma_delta = sigma * deltas
    alpha = 1.0 - np.exp(-sigma_delta)
    
    # Cumulative transmittance T_i
    transmittance = np.ones(N + 1)
    for i in range(1, N + 1):
        transmittance[i] = transmittance[i-1] * (1.0 - alpha[i-1])
            
    # Weighted sum: C(r) = sum c_i * T_i * (1 - exp(-sigma_i * delta_i))
    weights = transmittance[:-1] * alpha
    color = np.sum(weights[:, np.newaxis] * colors, axis=0)
    
    return color
```

**Parameters:**
*   $N$: Number of samples on the ray within near and far bounds ($t_n$ and $t_f$) [S1].
*   $L$: Number of frequency bands for positional encoding [G].
*   SH Degree: Determines the number of coefficients $K = (degree + 1)^2$ [G].

**Edge Cases and Pitfalls:**
*   **Shape-Radiance Ambiguity:** Training with only color reconstruction loss causes strong anisotropy and ambiguity [S1]. This is mitigated by the point-wise regularization of anisotropy energy [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Eliminates directional ambiguity; improves reconstruction quality for anisotropic materials; plug-and-play with various NeRF frameworks [S1].
*   **Limitations:** Requires regularization to prevent over-fitting of anisotropy; computational cost of SH evaluation [S1].
*   **When to Use:** Scenes with complex lighting, reflections, or anisotropic materials where standard isotropic NeRF fails [S1].
*   **When Not to Use:** Simple scenes with diffuse materials where isotropic representation is sufficient [S1].

## Background
Anisotropic Neural Representation Learning was proposed to address the limitations of standard NeRF in handling directional ambiguity [S1]. It builds on the principle of decoupling view-independent geometry from view-dependent lighting [Parent]. The method was introduced in "Improving Neural Volume Rendering via Learning View-Dependent Integral Approximation" [S1].
