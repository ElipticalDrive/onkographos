# Instruct-NeRF2NeRF

Also called: Instruct-NeRF2NeRF Baseline

## Overview
Instruct-NeRF2NeRF (IN2N) is a diffusion-based method for editing a Neural Radiance Field (NeRF) scene guided by text instructions, utilizing InstructPix2Pix [S1, S3]. It solves the problem of 3D scene modification by iteratively updating the training dataset with edited images and retraining the NeRF [S2, S3]. It differs from its sibling [Edit-NeRF](9388-edit-nerf.md) by bypassing explicit 3D deformation fields or conditional radiance field architectures, instead relying on 2D image-level diffusion editing to drive 3D consistency [S1, S2].

## How it works
**Inputs and Outputs:**
- Input: A pre-trained NeRF model representing the original scene, a set of original training images $\{I_i\}$, and a text instruction $T$ [S1, S3].
- Output: An edited NeRF model that renders scenes consistent with instruction $T$ [S3].

**Data Structures:**
- The method operates on the existing NeRF representation and the 2D image dataset [S2, S3].

**Algorithm:**
1. **Initialization:** Load the original NeRF model and the original training image dataset [S2].
2. **Iterative Editing Loop:**
   a. For each image $I_i$ in the training dataset:
      i. Pass $I_i$ and the text instruction $T$ to the InstructPix2Pix (IP2P) model [S2, S3].
      ii. Generate the edited image $I'_i = \text{IP2P}(I_i, T)$ [S2, S3].
   b. Replace the original dataset $\{I_i\}$ with the edited dataset $\{I'_i\}$ [S2].
   c. Re-train the NeRF model using the edited dataset $\{I'_i\}$ [S2, S3].
3. **Convergence:** Repeat steps 2a-2c until the edited NeRF converges or a fixed number of iterations is reached [S3].

**Parameters:**
- Text Instruction $T$: A natural language string describing the desired edit. Example: "Make it look like it was taken at night." [S3].
- InstructPix2Pix Model: A fine-tuned Stable Diffusion model capable of following text instructions to edit images [S3].

**Edge Cases and Pitfalls:**
- **Lack of Localization:** The method applies edits to entire 2D images, lacking the ability to perform precise, localized modifications [S2].
- **Scene Preservation:** It sometimes fails to preserve the rest of the scene, resulting in a blurrier scene compared to the original [S1].
- **Global Changes:** It may introduce unintended texture and color changes to the entire scene rather than just the target object [S1].

## Subtopics

## Operating characteristics
- **Time Complexity:** High. Requires iterative retraining of the NeRF after each round of 2D image editing [S2, S3].
- **Memory Complexity:** Not given in the sources.
- **Performance:** Demonstrates high-quality local edit results on real scenes [S1]. Slower than methods like [Depth-Guided Sequential Editing](13713-depth-guided-sequential-editing.md) which avoid integrating a diffusion model into the training loop [S1].
- **Scaling:** Not given in the sources.
- **Strengths:** Simple implementation leveraging existing 2D editing models; intuitive text-based control [S2, S3].
- **Limitations:** Applies edits to entire 2D images, lacking precise localization [S2]. Sometimes fails to preserve the rest of the scene, resulting in a blurrier output and unintended texture/color changes across the entire scene [S1].
- **When to use:** When intuitive text-based editing is prioritized over strict multi-view consistency or speed [S1, S2].
- **When not to use:** When precise, localized modifications or strict multi-view consistency are required [S1, S2].

## Background
Instruct-NeRF2NeRF was presented at ICCV 2023 [S1, S2]. It is the first work to edit a NeRF by iteratively updating the training dataset with edited images generated by a text-based image editing model, specifically InstructPix2Pix [S2]. It builds on the capability of generative models to edit 2D images according to text instructions [S3].
