# GAN Inversion Encoder and Optimization
Also called: GSN Inversion Encoder and Optimization
## Overview
This method enables view synthesis and scene editing by inverting a trained Generative Scene Network (GSN) or locally conditioned radiance field. It employs a learned encoder to map input views to an initial latent code grid, which is then refined via optimization to reconstruct the scene. It differs from standard GAN inversion by operating on a structured latent grid conditioned on camera poses rather than a single global latent vector, allowing for spatially varying scene representations [S1].
## How it works
**Inputs and Outputs:**
- **Inputs:** A set of posed source views $S = \{(X, T)_i\}_{i=t-5}^t$, where $X$ is the image and $T$ is the camera pose.
- **Outputs:** An optimized latent code grid $\hat{W}$.

**Data Structures:**
- **Encoder $E_{\theta_E}$:** A neural network mapping views and poses to latent codes.
- **Feature Volume $V$:** A 3D tensor $V \in \mathbb{R}^{c \times s \times s \times s}$ storing back-projected features.
- **Latent Grid $W_0$:** A 2D tensor $W_0 \in \mathbb{R}^{c \times s \times s}$ representing the initial latent codes.
- **Optimized Grid $\hat{W}$:** The result of optimizing $W_0$.

**Steps:**
1. **Encoder Forward Pass:** Process source views $X$ through a backbone network (UNet with ResNet-50 encoder) to extract feature maps.
2. **Back-Projection:** Use camera poses $T$ to back-project the feature maps into the shared feature volume $V \in \mathbb{R}^{c \times s \times s \times s}$ [S1].
3. **Pooling:** Perform average pooling over the height dimension of $V$ to obtain the initial latent code grid $W_0 \in \mathbb{R}^{c \times s \times s}$ [S1].
4. **Orientation Selection:** Predict $W_0$ at multiple rotation angles about the y-axis for the input views. Select the orientation that minimizes the auto-encoding LPIPS loss [60] to find the generator's preferred orientation. Use this orientation for subsequent optimization [S1].
5. **Optimization:** Optimize $W_0$ via Stochastic Gradient Descent (SGD) for 1000 iterations to produce $\hat{W}$ [S1]. The radiance field $f$ parameters are frozen during this step [S1].

**Formula:**
The encoder is trained using a reconstruction loss:
$$
L(\hat{X}, T, W; \theta_E) = \|W - E_{\theta_E}(\hat{X}, T)\|_2^2 + \|\hat{X} - f(E_{\theta_E}(\hat{X}, T), T)\|_2^2
$$
where the first term encourages reconstruction of the local latent grid and the second term encourages samples from the locally conditioned radiance field $f$ to match the original input views [S1].

**Pseudocode:**
```python
def gan_inversion_encoder_optimization(source_views, camera_poses, encoder, radiance_field, num_iterations=1000):
    """
    Inverts a GSN using an encoder and optimization.
    
    Args:
        source_views: List of images X.
        camera_poses: List of camera poses T.
        encoder: Trained encoder E_theta_E.
        radiance_field: Trained locally conditioned radiance field f.
        num_iterations: Number of SGD steps.
        
    Returns:
        optimized_W: The optimized latent code grid.
    """
    # Step 1-3: Encode views to initial latent grid
    # Backbone processes views to feature maps
    feature_maps = encoder.backbone(source_views)
    
    # Back-project features to volume V using poses
    V = back_project_features(feature_maps, camera_poses, volume_size=(s, s, s))
    
    # Average pool over height dimension to get W0
    W0 = average_pool_height(V)
    
    # Step 4: Find preferred orientation
    best_orientation = None
    min_lpips_loss = infinity
    
    # Try multiple rotation angles about y-axis
    for angle in rotation_angles:
        rotated_poses = rotate_poses(camera_poses, angle, axis='y')
        # Predict W0 with rotated poses
        W0_rotated = encoder(source_views, rotated_poses)
        # Calculate LPIPS loss between original views and reconstruction
        # Note: Reconstruction requires passing W0_rotated through radiance field
        reconstructed_views = radiance_field.render(W0_rotated, rotated_poses)
        lpips_loss = compute_lpips_loss(source_views, reconstructed_views)
        
        if lpips_loss < min_lpips_loss:
            min_lpips_loss = lpips_loss
            best_orientation = angle
            W0 = W0_rotated
            
    # Apply best orientation to poses for optimization
    final_poses = rotate_poses(camera_poses, best_orientation, axis='y')
    
    # Step 5: Optimize W0
    W_opt = W0.clone().requires_grad_(True)
    optimizer = SGD([W_opt], lr=learning_rate)
    
    for i in range(num_iterations):
        optimizer.zero_grad()
        # Render current latent grid
        rendered_views = radiance_field.render(W_opt, final_poses)
        # Compute reconstruction loss
        loss = compute_reconstruction_loss(source_views, rendered_views)
        loss.backward()
        optimizer.step()
        
    return W_opt
```

**Edge Cases and Pitfalls:**
- **Orientation Ambiguity:** Scenes may not share a canonical orientation. Failure to select the preferred orientation can lead to poor reconstruction [S1].
- **Training Stability:** Mixed precision training should not be applied to the discriminator if present, as it decreases stability [S1].
- **Memory Cost:** Training the generator incurs memory costs; optimization is performed with frozen generator parameters to reduce this [S1].

## Subtopics

### [GSN Inversion](16716-gsn-inversion.md)
The process of finding a latent code grid $\hat{W}$ that, when passed through a trained locally conditioned radiance field $f$, reconstructs input source views $S$ and predicts target views $T$. It solves the problem of generating unseen parts of a scene or editing scenes by optimizing latent codes rather than sampling from the prior.

## Operating characteristics
- **Time Complexity:** Optimization requires 1000 SGD iterations per scene [S1].
- **Memory Complexity:** Depends on the size of the feature volume $V \in \mathbb{R}^{c \times s \times s \times s}$ and the latent grid [S1].
- **Strengths:** Allows for view synthesis and scene editing by optimizing latent codes. Handles multiple views and camera poses [S1].
- **Limitations:** Requires a pre-trained encoder and radiance field. Optimization can be computationally expensive [S1].
- **When to Use:** When view synthesis or editing of scenes represented by a GSN is required [S1].
- **When Not to Use:** When real-time inference is critical, as optimization adds latency [S1].

## Background
The method is based on GAN inversion techniques applied to Generative Scene Networks (GSN) [S1]. It was introduced in "Unconstrained Scene Generation with Locally Conditioned Radiance Fields" [S1]. The approach builds on common practices for GAN inversion [57] and uses a hybrid inversion approach [S1].
