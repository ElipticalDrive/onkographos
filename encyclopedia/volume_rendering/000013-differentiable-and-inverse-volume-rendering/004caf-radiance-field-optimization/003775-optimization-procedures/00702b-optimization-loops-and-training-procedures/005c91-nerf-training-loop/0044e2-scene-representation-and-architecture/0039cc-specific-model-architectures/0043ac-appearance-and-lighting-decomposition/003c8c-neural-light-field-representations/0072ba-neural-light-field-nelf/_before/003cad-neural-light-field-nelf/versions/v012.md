# Neural Light Field (NeLF)

Also called: Implicit Neural Light Field, LFN, Light Field Network with Local Ray Conditioning, Light Field Networks

## Overview
Neural Light Field (NeLF) is a scene representation method that maps camera rays directly to RGB color values, bypassing the volumetric ray-marching and alpha-composition steps required by Neural Radiance Fields (NeRF) [S3, unofficial][S4]. Unlike NeRF, which requires multiple forward passes per ray to aggregate radiance, NeLF achieves novel view synthesis with a single forward pass per ray, enabling rendering speeds that are orders of magnitude faster [S3, unofficial][S4]. While standard NeLF implementations often use shallow networks, efficient variants like R2L employ deep residual MLPs trained via knowledge distillation from a pre-trained NeRF teacher to maintain high visual fidelity [S3, unofficial][S4]. The method builds on [Specific Model Architectures](8585-specific-model-architectures.md) by decoupling view-independent geometric features from view-dependent lighting effects.

## How it works
**Inputs and Outputs:**
The method takes a camera ray, represented as a concatenation of the spatial coordinates of $K$ sampled points along the ray, forming a $3K$-dimensional input vector [S4]. In the R2L implementation, $K=16$ [S4]. It outputs a 3D RGB color vector $\mathbf{c} = (r, g, b)$ [S4].

**Data Structures and Layout:**
1.  **Ray Representation:** The ray is encoded as a concatenation of spatial coordinates of $K$ sampled points along the ray, forming a $3K$-dimensional input vector [S4]. In the R2L implementation, $K=16$ [S4].
2.  **Network Architecture:** A deep residual Multi-Layer Perceptron (MLP) $G_\phi$ maps the input ray to RGB [S4]. Common configurations include width $W=256$ and depth $D=88$ (W256D88, ~12M FLOPs) or $W=181, D=88$ (W181D88, ~6M FLOPs) [S4]. The network uses extensive residual blocks [S4].
3.  **Positional Encoding:** Inputs are enriched using positional encoding $\gamma(\cdot)$ to mitigate spectral bias [S1, S4].
    $$
    \gamma(\mathbf{x}) = (\sin(2^0 \pi \mathbf{x}), \cos(2^0 \pi \mathbf{x}), \dots, \sin(2^{L-1} \pi \mathbf{x}), \cos(2^{L-1} \pi \mathbf{x}))
    $$
    where $L$ is the number of frequency bands [S1, S4].

**Training Procedure (Distillation):**
NeLF is typically trained by distilling knowledge from a pre-trained NeRF teacher model $F_{\Theta^*}$ [S4].
1.  **Pseudo Data Generation:** Rays are sampled from a uniform distribution $U$ within a viewing bounding box inferred from training camera poses [S4].
    $$
    \begin{aligned}
    x_o &\sim U(x_{o,\min}, x_{o,\max}), & y_o &\sim U(y_{o,\min}, y_{o,\max}), & z_o &\sim U(z_{o,\min}, z_{o,\max}) \\
    x_d &\sim U(x_{d,\min}, x_{d,\max}), & y_d &\sim U(y_{d,\min}, y_{d,\max}), & z_d &\sim U(z_{d,\min}, z_{d,\max})
    \end{aligned}
    $$
    The teacher model queries these rays to obtain target RGB values $(\hat{r}, \hat{g}, \hat{b})$ [S4].
2.  **Loss Function:** The NeLF student network $G_\phi$ is trained using Mean Squared Error (MSE) loss between its output and the teacher's output [S4].
    $$
    L = \text{MSE}(G_\phi(\mathbf{p}_1, \dots, \mathbf{p}_K), (\hat{r}, \hat{g}, \hat{b}))
    $$
    where $\mathbf{p}_i$ are the $K$ sampled points along the ray [S4].
3.  **Hard Example Mining:** To focus on high-frequency details, a pool of hard examples (rays with larger loss) is maintained [S4]. In each iteration, the top $r$ fraction of batch losses is added to the pool, and $r$ examples are randomly picked from the pool to augment the training batch [S4]. Default $r=0.2$ [S4].

**Rendering:**
During inference, for each pixel, a ray is defined [S4]. $K$ points are evenly spaced along the ray [S4]. The concatenated coordinates are fed into $G_\phi$ to directly predict the pixel color [S4].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class PositionalEncoding(nn.Module):
    def __init__(self, num_bands):
        super().__init__()
        self.num_bands = num_bands

    def forward(self, x):
        # x shape: (batch_size, K, 3)
        scales = torch.tensor([2**i * math.pi for i in range(self.num_bands)], dtype=x.dtype, device=x.device)
        x = x.unsqueeze(-1) * scales.view(1, 1, 1, -1)
        x = torch.cat([torch.sin(x), torch.cos(x)], dim=-1)
        return x.view(x.shape[0], -1)

class ResidualBlock(nn.Module):
    def __init__(self, width):
        super().__init__()
        self.fc1 = nn.Linear(width, width)
        self.fc2 = nn.Linear(width, width)
        self.relu = nn.ReLU()

    def forward(self, x):
        out = self.fc1(x)
        out = self.relu(out)
        out = self.fc2(out)
        return x + out

class NeLF(nn.Module):
    def __init__(self, width=256, depth=88, num_pe_bands=10, K=16):
        super().__init__()
        self.K = K
        self.pe = PositionalEncoding(num_pe_bands)
        input_dim = K * 3 * (2 * num_pe_bands)
        self.input_layer = nn.Linear(input_dim, width)
        
        layers = []
        for _ in range(depth):
            layers.append(ResidualBlock(width))
        self.residual_layers = nn.ModuleList(layers)
        
        self.output_layer = nn.Linear(width, 3)

    def forward(self, ray_coords):
        """
        ray_coords: (batch_size, 3*K) where K=16
        """
        b_size = ray_coords.shape[0]
        coords_3d = ray_coords.view(b_size, self.K, 3)
        pe_coords = self.pe(coords_3d)
        pe_flat = pe_coords.view(b_size, -1)
        
        x = self.input_layer(pe_flat)
        for layer in self.residual_layers:
            x = layer(x)
        rgb = self.output_layer(x)
        return rgb

def train_step(student_model, teacher_model, batch_coords, optimizer, hard_pool, r=0.2):
    """
    batch_coords: (batch_size, 48) # 16 points * 3 coords
    hard_pool: list of (coords, target) tuples
    """
    optimizer.zero_grad()
    
    # 1. Student forward pass
    student_output = student_model(batch_coords) # (B, 3)
    
    # 2. Compute loss against teacher targets
    # Teacher is queried with ray parameters to get targets (S4)
    # For self-contained code, we assume teacher_targets are provided or derived.
    # Here we simulate teacher query with origin/direction extracted from first/last points.
    origins = batch_coords[:, :3]
    last_points = batch_coords[:, -3:]
    directions = last_points - origins
    directions = directions / (torch.norm(directions, dim=1, keepdim=True) + 1e-8)
    teacher_input = torch.cat([origins, directions], dim=1)
    teacher_targets = teacher_model(teacher_input) # (B, 3)
    
    loss = F.mse_loss(student_output, teacher_targets)
    
    # 3. Hard Example Mining (S4)
    # Sort losses ascending, add top r% to pool, sample r% from pool to augment batch
    batch_losses = torch.abs(student_output - teacher_targets).mean(dim=1)
    _, indices = torch.sort(batch_losses)
    top_k = max(1, int(r * len(indices)))
    hard_indices = indices[-top_k:]
    
    for idx in hard_indices:
        hard_pool.append((batch_coords[idx], teacher_targets[idx]))
    
    if len(hard_pool) > 0:
        pool_size = max(1, int(r * len(batch_coords)))
        pool_indices = torch.randint(0, len(hard_pool), (pool_size,))
        pool_coords = torch.stack([hard_pool[i][0] for i in pool_indices])
        pool_targets = torch.stack([hard_pool[i][1] for i in pool_indices])
        
        # Augment batch with hard examples
        augmented_coords = torch.cat([batch_coords, pool_coords], dim=0)
        augmented_targets = torch.cat([teacher_targets, pool_targets], dim=0)
        
        aug_student_output = student_model(augmented_coords)
        aug_loss = F.mse_loss(aug_student_output, augmented_targets)
        loss = loss + aug_loss
        
    loss.backward()
    optimizer.step()
    
    return loss.item()
```

## Subtopics

### [Point-based Neural Light Field](17252-point-based-neural-light-field.md)
A variant that samples points along the ray and predicts density/color for each point, accumulating them via volume rendering. It differs from direct ray-to-color mapping by avoiding the 3D geometry-agnostic nature of direct mapping, though it introduces entanglement between point coordinates. Choose this variant when multi-view consistency is critical and batch rendering efficiency outweighs the computational cost of per-point density prediction.

## Operating characteristics
- **Time Complexity:** Rendering requires a single forward pass per ray, resulting in $O(1)$ queries per pixel compared to $O(N)$ for NeRF ray marching [S3, unofficial].
- **Memory Complexity:** The model size is determined by the MLP parameters (e.g., 12M FLOPs for W256D88) [S4]. No voxel grids or large feature volumes are stored [S4].
- **Performance:** On synthetic scenes, R2L achieves a 26–35× FLOPs reduction and 28–31× wall-time speedup compared to NeRF [S4]. On the DTU dataset with 3 input views, rendering time is 0.25 seconds compared to 27.01 seconds for PixelNeRF [S1].
- **Quality:** On synthetic scenes, R2L achieves a 1.4–2.8 dB average PSNR improvement over NeRF [S4]. On DTU with 3 views, PSNR is 19.86 and SSIM is 0.657 [S1].
- **Limitations:** May lack high-frequency details compared to NeRF-based counterparts [S1]. Deep networks require residual connections to be trainable [S4].
- **When to use:** Use when real-time novel view synthesis is required and a pre-trained NeRF teacher is available for distillation [S4]. Avoid when strict multi-view geometric consistency is mandatory without additional supervision [S3, unofficial].

## Background
Neural Light Fields map camera rays directly to radiance in 4D light space, enabling real-time rendering with significantly reduced memory usage [S2]. The R2L method, a prominent implementation, was proposed by Wang et al. to distill NeRF knowledge into a deep residual NeLF network, achieving significant speedups without customized parallelism [S4]. The approach addresses the lack of inherent multi-view consistency by enforcing it through distillation supervision and meta-learning frameworks [S2]. It is primarily used for efficient novel view synthesis in computer graphics and vision pipelines [S3, unofficial][S4].
