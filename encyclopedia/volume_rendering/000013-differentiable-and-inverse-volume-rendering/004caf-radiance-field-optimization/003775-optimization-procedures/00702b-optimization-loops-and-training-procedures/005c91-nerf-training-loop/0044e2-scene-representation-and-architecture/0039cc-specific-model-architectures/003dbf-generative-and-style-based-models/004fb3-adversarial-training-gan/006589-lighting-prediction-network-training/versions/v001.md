# Lighting Prediction Network Training

Also called: Hybrid Loss Training for Lighting Prediction

## Overview
A training strategy for predicting lighting conditions in street scenes that addresses depth rendering ambiguity and encourages photorealism through adversarial supervision [S1]. It distinguishes itself from standard differentiable rendering pipelines by combining a multi-term hybrid loss (including sky regression, reconstruction, and regularization) with a PatchGAN discriminator, trained in a two-stage process (pre-training followed by joint adversarial training) to stabilize convergence [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ground truth lighting parameters (direction $f_{dir}$, intensity $f_{intensity}$), real-world images $\{I_{real}\}$ from nuScenes [2] and HoliCity [22] street views, and HDR panoramas.
*   **Outputs:** Predicted lighting parameters and rendered images $\hat{I}_{edit}$.

**Data Structures:**
*   **Discriminator ($D$):** A 5-layer PatchGAN network with spectral norm [S1].
*   **Generator:** The lighting prediction network (architecture details not specified in sources, but implied to output latent codes and radiance/depth) [S1].
*   **Loss Weights:** $\lambda_{sky}=1, \lambda_{recon}=1, \lambda_{transmit}=1, \lambda_{reg}=10^{-4}, \lambda_{adv}=3 \times 10^{-3}$ [S1].

**Numbered Steps:**
1.  **Pre-training:** Train the model without the adversarial loss term $L_{adv}$ for 50 epochs [S1].
2.  **Joint Training:** Train the model with all loss terms for an additional 50 epochs [S1].
3.  **Sky Regression Loss ($L_{sky}$):** Compute the L1 loss for the latent code. Linearly fade out this specific loss component during the first 50 epochs of the joint training phase [S1].
4.  **Adversarial Training:**
    *   Sample real images $I_{real}$ and generated images $\hat{I}_{edit}$ [S1].
    *   Compute discriminator loss $L_D$ using hinge loss [S1].
    *   Update discriminator $D$ [S1].
    *   Compute generator adversarial loss $L_{adv}$ based on $D(\hat{I}_{edit})$ [S1].
5.  **Optimization:** Update the generator parameters using the total hybrid loss $L_{hybrid}$ [S1].

**Formulas:**
The final hybrid loss is defined as [S1]:
$$
L_{hybrid} = \lambda_{sky} L_{sky} + \lambda_{recon} L_{recon} + \lambda_{reg} L_{reg} + \lambda_{transmit} L_{transmit} + \lambda_{adv} L_{adv}
$$
where:
*   $L_{sky}$: Sky regression loss (L1 loss on latent code, faded in first 50 epochs).
*   $L_{recon}$: Radiance and depth reconstruction loss.
*   $L_{reg}$: Regularization loss encouraging the alpha channel of the volume to be binary (0 or 1) to address depth rendering ambiguity [S1].
*   $L_{transmit}$: Sky separation loss.
*   $L_{adv}$: Adversarial supervision loss.

The discriminator uses hinge loss [S1]:
$$
L_D = \max(0, 1 - D(I_{real})) + \max(0, 1 + D(\hat{I}_{edit}))
$$

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $3 \times 10^{-4}$, decaying by a factor of 0.3 every 30 epochs [S1].
*   **Discriminator Batch Size:** 1 [S1].
*   **Total GPU Memory:** 20G (8G for network inference, 12G for rendering) [S1].

**Pseudocode:**
```python
# Initialization
optimizer = Adam(params=model.parameters(), lr=3e-4)
discriminator = PatchGAN_5Layer_SpectralNorm()
disc_optimizer = Adam(params=discriminator.parameters(), lr=3e-4) # Assumed same LR schedule

# Hyperparameters
epochs_pretrain = 50
epochs_joint = 50
total_epochs = epochs_pretrain + epochs_joint
decay_factor = 0.3
decay_step = 30

# Loss weights
lambda_sky = 1.0
lambda_recon = 1.0
lambda_reg = 1e-4
lambda_transmit = 1.0
lambda_adv = 3e-3

# Training Loop
for epoch in range(1, total_epochs + 1):
    # Learning rate decay
    current_lr = 3e-4 * (decay_factor ** (epoch // decay_step))
    set_learning_rate(optimizer, current_lr)
    set_learning_rate(disc_optimizer, current_lr)

    for batch in dataloader:
        # Forward pass
        predicted_lighting, rendered_image = model(batch.input)
        
        # Compute losses
        # L_sky: Sky regression loss (L1 on latent code)
        # Note: Fade out logic applied here if epoch <= 50 (relative to joint phase start)
        # Assuming 'epoch' here is global, so joint phase starts at epoch 51
        if epoch <= epochs_pretrain:
            # Pre-training phase: no adversarial loss
            l_sky = compute_l1_loss_latent(predicted_lighting, batch.target_lighting)
            l_recon = compute_reconstruction_loss(rendered_image, batch.target_image)
            l_reg = compute_alpha_regularization(rendered_image.alpha)
            l_transmit = compute_sky_separation(rendered_image, batch.target_image)
            l_adv = 0.0
        else:
            # Joint training phase
            # Linearly fade out L1 loss for latent code in the first 50 epochs of joint training
            # epoch 51 -> factor 1.0, epoch 100 -> factor 0.0
            fade_factor = max(0.0, 1.0 - (epoch - epochs_pretrain) / epochs_joint)
            l_sky = compute_l1_loss_latent(predicted_lighting, batch.target_lighting) * fade_factor
            l_recon = compute_reconstruction_loss(rendered_image, batch.target_image)
            l_reg = compute_alpha_regularization(rendered_image.alpha)
            l_transmit = compute_sky_separation(rendered_image, batch.target_image)
            
            # Adversarial Loss
            # D is discriminator
            d_real = discriminator(batch.target_image)
            d_fake = discriminator(rendered_image.detach())
            
            # Hinge loss for discriminator
            l_d_real = max(0, 1 - d_real)
            l_d_fake = max(0, 1 + d_fake)
            l_d = l_d_real + l_d_fake
            
            # Update Discriminator
            disc_optimizer.zero_grad()
            l_d.backward()
            disc_optimizer.step()
            
            # Generator adversarial loss (using fake images)
            d_fake_gen = discriminator(rendered_image)
            l_adv = max(0, 1 - d_fake_gen) # Standard GAN generator loss for hinge
            
        # Total Hybrid Loss
        l_hybrid = (lambda_sky * l_sky + 
                    lambda_recon * l_recon + 
                    lambda_reg * l_reg + 
                    lambda_transmit * l_transmit + 
                    lambda_adv * l_adv)
        
        # Update Generator
        optimizer.zero_grad()
        l_hybrid.backward()
        optimizer.step()
```

**Edge Cases and Pitfalls:**
*   **Depth Ambiguity:** The regularization loss $L_{reg}$ is critical to prevent the volume alpha channel from converging to intermediate values, which causes depth rendering ambiguity [S1].
*   **Training Stability:** The two-stage training (pre-training then joint) is necessary to stabilize the adversarial training [S1].
*   **Memory Constraints:** The method requires significant GPU memory (20G total), with rendering consuming the majority (12G) [S1].

## Operating characteristics
*   **Time Complexity:** Not explicitly given, but training involves 4000 epochs in the main paper context [S1] (though the specific lighting prediction section details 100 epochs of the specific hybrid loss strategy, the main paper mentions 4000 epochs for the full model including other components). The provided notes specify 50 pre-training + 50 joint epochs for the hybrid loss component [S1].
*   **Memory Complexity:** 20G GPU memory usage (8G for network inference, 12G for rendering) [S1].
*   **Strengths:** Addresses depth rendering ambiguity via regularization; encourages photorealism via adversarial supervision; handles sky regression ambiguity via fading loss [S1].
*   **Limitations:** High GPU memory requirement; requires careful tuning of loss weights and learning rate decay [S1].
*   **When to use:** When generating photorealistic street scene lighting with differentiable rendering and depth ambiguity is a concern [S1].
*   **When not to use:** When GPU memory is limited (<20G) or when adversarial training instability is unacceptable without careful tuning [S1].

## Background
Originated in the context of "Neural Light Field Estimation for Street Scenes with Differentiable Virtual Object Insertion" [S1]. The method combines techniques from differentiable rendering (sky regression, depth reconstruction) with GAN-based adversarial training (PatchGAN discriminator) to improve the realism of predicted lighting in street scenes [S1]. It builds on prior work addressing depth rendering ambiguity [S1].
