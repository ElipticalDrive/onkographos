# CLIP-NeRF

## Overview
CLIP-NeRF is a neural radiance field method that enables text- or image-guided editing of 3D scenes by extracting latent space displacements from user input via the CLIP model [S1, S2]. It differs from prior editing methods like Edit-NeRF by bypassing per-edit latent code optimization, achieving significant speedups (8–60x) through a disentangled conditional architecture that maps semantic input directly to shape and appearance modifications [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A pre-trained NeRF representation (initial weights and base latent codes), a user-provided text prompt or reference image, and camera parameters for the target view [S1].
*   **Outputs:** A modified radiance field capable of rendering the scene according to the semantic guidance, and the rendered image [S1].

**Data Structures:**
The method relies on a disentangled conditional NeRF architecture [S2]. Key components include:
1.  **Base NeRF:** Standard MLPs for density $\sigma$ and color $\mathbf{c}$, conditioned on latent codes [S1].
2.  **Shape Latent Code ($z_s$):** A vector controlling geometric deformation [S2].
3.  **Appearance Latent Code ($z_a$ or $z_c$):** A vector controlling texture and color [S1, S2].
4.  **Shape Mapper Network:** A neural network that takes the CLIP embedding of the input text/image and outputs the displacement for $z_s$ [S1].
5.  **Appearance Mapper Network:** A neural network that takes the CLIP embedding and outputs the displacement for $z_a$ [S1].
6.  **Deformation Network (Instance-Specific Network):** An MLP that takes the encoded position and the shape latent code to produce a deformation vector, modifying the input position before it enters the density network [S1, S2].

**Steps:**
1.  **CLIP Embedding:** Encode the user input (text or image) into a latent vector using the pre-trained CLIP model [S1, S2].
2.  **Latent Displacement Extraction:** Pass the CLIP embedding through the Shape Mapper and Appearance Mapper networks to compute displacements $\Delta z_s$ and $\Delta z_a$ [S1].
3.  **Latent Code Update:** Add the computed displacements to the base latent codes to form the updated scene representation: $z_s^{\text{new}} = z_s^{\text{base}} + \Delta z_s$ and $z_a^{\text{new}} = z_a^{\text{base}} + \Delta z_a$ [S1, S2].
4.  **Deformation:** For a ray point $\mathbf{x}$, encode it with positional encoding $\gamma(\mathbf{x})$ [S1]. Pass $\gamma(\mathbf{x})$ and $z_s^{\text{new}}$ through the Deformation Network to get a deformation vector $\mathbf{d}_{\text{def}}$ [S1, S2]. Compute the deformed position $\mathbf{x}' = \mathbf{x} + \mathbf{d}_{\text{def}}$ [S1].
5.  **Radiance Field Query:**
    *   Query the Density Network with $\gamma(\mathbf{x}')$ and $z_s^{\text{new}}$ to get density $\sigma$ [S1, S2].
    *   Query the Color Network with $\gamma(\mathbf{x}')$, viewing direction $\mathbf{d}$, and $z_a^{\text{new}}$ to get color $\mathbf{c}$ [S1, S2].
6.  **Volume Rendering:** Render the pixel color $C(\mathbf{r})$ using the standard volumetric rendering integral [S2]:
    $$
    C(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i, \quad \text{where } \alpha_i = 1 - \exp(-\sigma_i \delta_i), \quad T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)
    $$
    where $\delta_i$ is the distance between samples [S2].

**Pseudocode:**
```python
def positional_encoding(x, L):
    # x: (N, 3), returns (N, 2*L*3)
    encoded = []
    for i in range(L):
        freq = 2.0 ** i * 3.141592653589793
        encoded.append(x * freq)
    sin_vals = [v.sin() for v in encoded]
    cos_vals = [v.cos() for v in encoded]
    return torch.cat(sin_vals + cos_vals, dim=-1)

def clip_nerf_render(ray_origin, ray_direction, clip_input, base_zs, base_za,
                     shape_mapper, appearance_mapper, deformation_net,
                     density_net, color_net, L=10, num_samples=128,
                     near=0.0, far=1.0):
    # 1. CLIP embedding (assumed pre-computed or passed as tensor)
    clip_emb = clip_input

    # 2. Latent displacements
    delta_zs = shape_mapper(clip_emb)
    delta_za = appearance_mapper(clip_emb)

    # 3. Update latent codes
    zs = base_zs + delta_zs
    za = base_za + delta_za

    # 4. Sample points along ray
    t_vals = torch.linspace(near, far, num_samples)
    t_diffs = t_vals[1:] - t_vals[:-1]
    t_diffs = torch.cat([t_diffs, torch.tensor([1e10], device=t_vals.device)])
    points = ray_origin.unsqueeze(0) + ray_direction.unsqueeze(0) * t_vals.unsqueeze(1)

    # 5. Encode & Deform
    x_enc = positional_encoding(points, L)
    def_vec = deformation_net(x_enc, zs)
    deformed_points = points + def_vec
    deformed_enc = positional_encoding(deformed_points, L)

    # 6. Query networks
    densities = density_net(deformed_enc, zs).squeeze(-1) # (N,)
    colors = color_net(deformed_enc, ray_direction, za)   # (N, 3)

    # 7. Volume rendering
    alphas = 1.0 - torch.exp(-densities * t_diffs)
    transmittances = torch.cumprod(torch.exp(-alphas[:-1]), dim=0)
    transmittances = torch.cat([torch.ones_like(transmittances[:1]), transmittances])
    weights = alphas * transmittances
    rendered_color = torch.sum(weights.unsqueeze(-1) * colors, dim=0)
    return rendered_color
```

**Edge Cases and Pitfalls:**
*   **Precision and Boundaries:** The deformation network modifies spatial coordinates before density evaluation, requiring careful handling of out-of-bounds or degenerate deformations to prevent NaN values in the exponential term [G].
*   **Semantic Alignment:** The quality of the edit depends on how well the CLIP embedding aligns with the underlying 3D geometry, which may require careful prompt engineering or reference image selection [S2].

## Operating characteristics
*   **Time Complexity:** Significantly faster than Edit-NeRF during the editing phase because it avoids iterative optimization of latent codes for each edit [S1]. The speedup is reported as a factor of ~8–60 depending on the task [S1].
*   **Memory Complexity:** Requires storing the base NeRF weights, the mapper networks, and the deformation network [S1, S2].
*   **Strengths:** Enables global deformation and shape operations with high freedom; fast editing without per-edit optimization [S2].
*   **Limitations:** Not given in the sources.

## Background
CLIP-NeRF was proposed by Wang et al. in 2022 [S2]. It builds upon the latent-conditioned NeRF framework and Edit-NeRF, aiming to overcome the slow editing speed of iterative latent optimization by leveraging the pre-trained multimodal capabilities of CLIP [S1, S2]. It is used for text- or image-guided 3D scene editing and generation [S1, S2].
