# Lighting Prediction Network Training

Also called: Hybrid Loss Training for Lighting Prediction

## Overview
A training strategy for predicting lighting conditions in street scenes that addresses depth rendering ambiguity and encourages photorealism through adversarial supervision [S1]. It distinguishes itself from standard differentiable rendering pipelines by combining a multi-term hybrid loss (including sky regression, reconstruction, and regularization) with a PatchGAN discriminator, trained in a two-stage process (pre-training followed by joint adversarial training) to stabilize convergence [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ground truth lighting parameters (direction $f_{dir}$, intensity $f_{intensity}$), real-world images $\{I_{real}\}$ from nuScenes and HoliCity street views, and HDR panoramas [S1].
*   **Outputs:** Predicted lighting parameters and rendered images $\hat{I}_{edit}$ [S1].

**Data Structures:**
*   **Discriminator ($D$):** A 5-layer PatchGAN network with spectral normalization applied to each weight matrix [S1].
*   **Generator:** The lighting prediction network that outputs latent codes and radiance/depth volumes [S1].
*   **Loss Weights:** $\lambda_{sky}=1$, $\lambda_{recon}=1$, $\lambda_{transmit}=1$, $\lambda_{reg}=10^{-4}$, $\lambda_{adv}=3 \times 10^{-3}$ [S1].

**Numbered Steps:**
1.  **Pre-training:** Train the generator without the adversarial loss term $L_{adv}$ for 50 epochs [S1].
2.  **Joint Training:** Train the generator with all loss terms for an additional 50 epochs [S1].
3.  **Sky Regression Loss ($L_{sky}$):** Compute the L1 loss for the latent code and linearly fade it out during the first 50 epochs of training [S1].
4.  **Adversarial Training:** Sample real images $I_{real}$ and generated images $\hat{I}_{edit}$ [S1]. Compute the discriminator loss $L_D$ using hinge loss [S1]. Update the discriminator $D$ [S1]. Compute the generator adversarial loss $L_{adv}$ based on $D(\hat{I}_{edit})$ [S1].
5.  **Optimization:** Update the generator parameters using the total hybrid loss $L_{hybrid}$ [S1].

**Formulas:**
The final hybrid loss is defined as [S1]:
$$
L_{hybrid} = \lambda_{sky} L_{sky} + \lambda_{recon} L_{recon} + \lambda_{reg} L_{reg} + \lambda_{transmit} L_{transmit} + \lambda_{adv} L_{adv}
$$
where:
*   $L_{sky}$: Sky regression loss (L1 loss on latent code, faded in the first 50 epochs).
*   $L_{recon}$: Radiance and depth reconstruction loss.
*   $L_{reg}$: Regularization loss encouraging the alpha channel of the volume to be binary (0 or 1) to address depth rendering ambiguity [S1].
*   $L_{transmit}$: Sky separation loss.
*   $L_{adv}$: Adversarial supervision loss.

The discriminator uses hinge loss [S1]:
$$
L_D = \max(0, 1 - D(I_{real})) + \max(0, 1 + D(\hat{I}_{edit}))
$$

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $3 \times 10^{-4}$, decaying by a factor of 0.3 every 30 epochs [S1].
*   **Discriminator Batch Size:** 1 [S1].
*   **Total GPU Memory:** 20G (8G for network inference, 12G for rendering) [S1].

**Edge Cases and Pitfalls:**
*   **Depth Ambiguity:** The regularization loss $L_{reg}$ is critical to prevent the volume alpha channel from converging to intermediate values, which causes depth rendering ambiguity [S1].
*   **Training Stability:** The two-stage training (pre-training then joint) is necessary to stabilize the adversarial training [S1].
*   **Memory Constraints:** The method requires significant GPU memory (20G total), with rendering consuming the majority (12G) [S1].

**Pseudocode:**
```python
import math

# Standard operations
def mean_abs_error(pred, target):
    return sum(abs(p - t) for p, t in zip(pred, target)) / len(pred)

def alpha_regularization(alpha):
    # Encourages alpha to be 0 or 1 [G]
    return sum(a * (1 - a) for a in alpha) / len(alpha)

class AdamOptimizer:
    def __init__(self, params, lr, beta1=0.9, beta2=0.999, eps=1e-8):
        self.params = params
        self.lr = lr
        self.m = {id(p): 0.0 for p in params}
        self.v = {id(p): 0.0 for p in params}
        self.t = 0
    def zero_grad(self):
        for p in self.params: p.grad = 0.0
    def step(self):
        self.t += 1
        for p in self.params:
            g = p.grad
            self.m[id(p)] = 0.9 * self.m[id(p)] + 0.1 * g
            self.v[id(p)] = 0.999 * self.v[id(p)] + 0.001 * (g ** 2)
            m_hat = self.m[id(p)] / (1 - 0.9 ** self.t)
            v_hat = self.v[id(p)] / (1 - 0.999 ** self.t)
            p -= self.lr * m_hat / (math.sqrt(v_hat) + 1e-8)

class PatchGAN5LayerSpectralNorm:
    # 5-layer convolutional network with spectral normalization on each weight matrix [G]
    def __init__(self): pass
    def forward(self, x): pass

# Setup
model = LightingPredictionNetwork()
discriminator = PatchGAN5LayerSpectralNorm()
optimizer = AdamOptimizer(model.parameters(), lr=3e-4)
disc_optimizer = AdamOptimizer(discriminator.parameters(), lr=3e-4)

epochs_pretrain = 50
epochs_joint = 50
total_epochs = epochs_pretrain + epochs_joint
decay_factor = 0.3
decay_step = 30

lambda_sky = 1.0
lambda_recon = 1.0
lambda_reg = 1e-4
lambda_transmit = 1.0
lambda_adv = 3e-3

for epoch in range(1, total_epochs + 1):
    # Learning rate decay: 3e-4, decaying by 0.3 every 30 epochs [S1]
    current_lr = 3e-4 * (decay_factor ** ((epoch - 1) // decay_step))
    optimizer.lr = current_lr
    disc_optimizer.lr = current_lr

    for batch in training_data:
        # Forward pass
        latent_pred, rendered_image = model(batch.input)
        target_lighting = batch.target_lighting
        target_image = batch.target_image

        # Loss computation
        l_recon = mean_abs_error(rendered_image, target_image)
        l_reg = alpha_regularization(rendered_image.alpha)
        l_transmit = 0.0  # Sky separation loss: Not defined in the sources. [G]

        if epoch <= epochs_pretrain:
            # Pre-training phase: no adversarial loss [S1]
            l_sky = mean_abs_error(latent_pred, target_lighting)
            l_adv = 0.0
        else:
            # Joint training phase
            # Linearly fade out L1 loss for latent code in the first 50 epochs [S1]
            fade_factor = max(0.0, 1.0 - (epoch - 1) / 50.0)
            l_sky = mean_abs_error(latent_pred, target_lighting) * fade_factor

            # Adversarial training
            d_real = discriminator(target_image)
            d_fake = discriminator(rendered_image.detach())

            # Discriminator hinge loss [S1]
            l_d = max(0, 1 - d_real) + max(0, 1 + d_fake)

            # Update Discriminator (batch size 1) [S1]
            disc_optimizer.zero_grad()
            l_d.backward()
            disc_optimizer.step()

            # Generator adversarial loss (hinge GAN standard) [G]
            d_fake_gen = discriminator(rendered_image)
            l_adv = max(0, 1 - d_fake_gen)

        # Total hybrid loss [S1]
        l_hybrid = (lambda_sky * l_sky +
                    lambda_recon * l_recon +
                    lambda_reg * l_reg +
                    lambda_transmit * l_transmit +
                    lambda_adv * l_adv)

        # Update Generator
        optimizer.zero_grad()
        l_hybrid.backward()
        optimizer.step()
```

## Operating characteristics
*   **Time Complexity:** Not explicitly given, but training involves 4000 epochs in the main paper context [S1]. The specific hybrid loss strategy details 100 epochs (50 pre-training + 50 joint) [S1].
*   **Memory Complexity:** 20G GPU memory usage (8G for network inference, 12G for rendering) [S1].
*   **Strengths:** Addresses depth rendering ambiguity via regularization; encourages photorealism via adversarial supervision; handles sky regression ambiguity via fading loss [S1].
*   **Limitations:** High GPU memory requirement; requires careful tuning of loss weights and learning rate decay [S1].
*   **When to use:** When generating photorealistic street scene lighting with differentiable rendering and depth ambiguity is a concern [S1].
*   **When not to use:** When GPU memory is limited (<20G) or when adversarial training instability is unacceptable without careful tuning [S1].

## Background
Originated in the context of "Neural Light Field Estimation for Street Scenes with Differentiable Virtual Object Insertion" [S1]. The method combines techniques from differentiable rendering (sky regression, depth reconstruction) with GAN-based adversarial training (PatchGAN discriminator) to improve the realism of predicted lighting in street scenes [S1]. It builds on prior work addressing depth rendering ambiguity [S1].
