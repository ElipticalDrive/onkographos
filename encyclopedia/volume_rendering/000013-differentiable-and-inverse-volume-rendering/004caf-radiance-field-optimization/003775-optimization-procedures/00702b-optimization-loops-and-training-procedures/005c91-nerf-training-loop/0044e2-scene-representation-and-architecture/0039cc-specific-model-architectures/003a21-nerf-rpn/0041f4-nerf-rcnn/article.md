# NeRF-RCNN

Also called: Instance-NeRF RCNN stage

## Overview
NeRF-RCNN is a proposal-based 3D instance segmentation model that takes a pre-trained NeRF as input and outputs 3D Axis-Aligned Bounding Boxes (AABB), class labels, and discrete 3D masks of detected objects [S1]. It extends NeRF-RPN by appending a box prediction head (MLP) and a mask prediction head (3D CNN) to refine coarse proposals into precise instance-level geometry [S1]. Unlike Semantic-NeRF, which produces only semantic labels, NeRF-RCNN generates discrete instance masks and bounding boxes [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained Instance-NeRF model (providing radiance and density fields), and Region of Interest (RoI) proposals generated by NeRF-RPN [S1].
*   **Output:** For each proposal, class logits, AABB regression offsets, and discrete 3D masks [S1].

**Data Structures:**
*   **Sampled Grid:** A 3D grid covering the full traceable volume of the Instance-NeRF, uniformly sampled for appearance and density [S1].
*   **RoI Features:** Extracted via 3D RoIAlign, ensuring consistent feature dimensions across proposals [S1].
*   **Box Offsets ($t_{i,k}$):** A 6-dimensional vector per class $k$ for each RoI $i$: $(tx_{i,k}, ty_{i,k}, tz_{i,k}, tw_{i,k}, tl_{i,k}, th_{i,k})$ [S1].
*   **Masks ($m_{i,k}$):** A 3D binary mask of size $m \times m \times m$ for each class $k$ [S1].

**Parameters:**
*   $m=5$ for the box head resolution [S1].
*   $m=10$ for the mask head resolution [S1].
*   $\lambda_1, \lambda_2$: Hyper-parameters weighting regression and mask losses [S1].
*   NMS threshold for NeRF-RCNN: 0.15 [S1].
*   Score threshold for detection: 0.5 [S1].

**Numbered Steps:**
1.  **Sampling:** Uniformly sample appearance and density on a grid covering the full traceable volume of the pre-trained Instance-NeRF model [S1].
2.  **Proposal Generation:** Pass the sampled grid to NeRF-RPN to output proposals and a feature pyramid [S1].
3.  **Feature Extraction:** Extract features using a backbone identical to NeRF-RPN [S1].
4.  **RoI Alignment:** Use 3D RoIAlign to obtain features within the RoI of each output proposal. This extends standard RoIAlign with an additional dimension to ensure consistent feature extraction for each RoI on the feature map [S1].
5.  **Ground Truth Assignment:** For each RoI, set the ground truth box with the largest Intersection over Union (IoU) as its regression target [S1].
6.  **Box Head Processing:**
    *   Flatten the aligned RoI features.
    *   Pass through a fully connected layer for encoding.
    *   Split into a box branch and a classification branch [S1].
    *   The box branch regresses the RoI to a more accurate bounding box per class.
    *   The classification branch predicts classification scores [S1].
7.  **Mask Head Processing:**
    *   Feed aligned features into a 3D CNN (Mask Head).
    *   Output $L$ binary masks of size $m \times m \times m$ for each RoI, where $L$ is the number of classes including background [S1].
    *   Apply sigmoid activation [S1].
8.  **2D Mask Refinement (Post-Processing/Refinement Stage):**
    *   Apply 2D mask refinement using CascadePSP on the Instance-NeRF results to improve segmentation quality on object boundaries [S1].
    *   Compose the refined masks into a single segmentation map to further optimize the instance field [S1].

**Formulas:**
*   **Box Offsets:** The output $t_{i,k}$ relates to bounding box parameters as follows [S1]:
    $$
    \begin{aligned}
    tx_{i,k} &= (x_k - x_a)/w_a \\
    ty_{i,k} &= (y_k - y_a)/l_a \\
    tz_{i,k} &= (z_k - z_a)/h_a \\
    tw_{i,k} &= \log(w_k/w_a) \\
    tl_{i,k} &= \log(l_k/l_a) \\
    th_{i,k} &= \log(h_k/h_a)
    \end{aligned}
    $$
    Where $x_k, y_k, z_k$ are center coordinates, $w_k, l_k, h_k$ are side lengths, and $x_a, y_a, z_a, w_a, l_a, h_a$ are the corresponding RoI parameters [S1].

*   **Box Regression Loss ($L_{reg}$):**
    $$
    L_{reg} = \frac{1}{|N_p|} \sum_{i \in N_p} \sum_{k=1}^L p_{i,k} L_{smooth}(t_{i,k}, t^*_i)
    $$
    Where $N_p$ is the set of positive samples, $L$ is the number of classes including background, $p_{i,k}$ is the $k$-th dimension of the predicted score vector $p_i$, $t_{i,k}$ is the box offset of class $k$, and $t^*_i$ is the ground-truth target. $L_{smooth}$ is the smooth L1 loss [S1]. Note: For an RoI associated with ground truth class $c$, only the $c$-th box regression loss contributes [S1].

*   **Mask Loss ($L_{mask}$):**
    $$
    L_{mask} = \frac{\lambda_2}{|N_p|} \sum_{i \in N_p} \sum_{k=1}^L p_{i,k} L_p(m_{i,k}, m^*_i)
    $$
    Where $m_{i,k}$ is the predicted mask of class $k$, $m^*_i$ is the ground truth mask, and $L_p$ is the binary cross-entropy (BCE) loss. Only the mask BCE loss corresponding to the ground truth label contributes [S1].

*   **Classification Loss ($L_{cls}$):**
    $$
    L_{cls} = \frac{1}{|N|} \sum_{i \in N} L_{BCE}(p_i, p^*_i)
    $$
    Where $N$ is the set of sampled RoIs, $p_i$ is the predicted classification score vector after sigmoid, and $p^*_i$ is the ground truth target [S1].

*   **Total Loss:**
    $$
    L = L_{cls} + \lambda_1 L_{reg} + \lambda_2 L_{mask}
    $$
    Where $\lambda_1, \lambda_2$ are hyper-parameters [S1].

def nerf_rcnn_forward(pretrained_nerf, rpn_proposals):
    """
    Forward pass for NeRF-RCNN.
    Args:
        pretrained_nerf: Pre-trained Instance-NeRF model.
        rpn_proposals: List of RoI proposals from NeRF-RPN.
    Returns:
        boxes: Refined 3D bounding boxes.
        scores: Classification scores.
        masks: Discrete 3D masks.
    """
    # 1. Sample grid from NeRF
    grid = sample_appearance_and_density(pretrained_nerf)
    
    # 2. Extract features using backbone (same as NeRF-RPN)
    feature_pyramid = extract_features(grid)
    
    # 3. RoI Align
    roi_features = []
    for proposal in rpn_proposals:
        # Extend RoIAlign with 3rd dimension
        feat = roi_align_3d(feature_pyramid, proposal.roi_box)
        roi_features.append(feat)
    
    roi_features = stack(roi_features)
    
    # 4. Box Head (MLP)
    # Flatten and encode
    encoded = flatten(roi_features)
    encoded = fully_connected(encoded, hidden_dim)
    
    # Split into branches
    box_branch_output = fully_connected(encoded, box_branch_dim)
    cls_branch_output = fully_connected(encoded, cls_branch_dim)
    
    # Regress boxes
    # Output is 6 values per class: tx, ty, tz, tw, tl, th
    raw_offsets = box_branch_output
    boxes = decode_boxes(raw_offsets, rpn_proposals.roi_boxes)
    
    # Classify
    scores = sigmoid(cls_branch_output)
    
    # 5. Mask Head (3D CNN)
    # Input: roi_features
    masks = mask_head_3d_cnn(roi_features)
    # Output: L binary masks of size m x m x m
    masks = sigmoid(masks)
    
    return boxes, scores, masks

    """

    gt_boxes, gt_labels, gt_masks = ground_truth
    
    # Identify positive samples (RoIs with largest IoU with GT)
    positive_indices = assign_gt_boxes(boxes, gt_boxes)
    
    # Classification Loss (BCE)
    # Apply to all RoIs or just positive? Source says N is set of sampled RoIs.
    # Standard RCNN applies cls loss to all, but reg/mask only to positive.
    # Source Eq 13 sums over N (all RoIs).
    l_cls = mean(binary_cross_entropy(scores, gt_labels))
    
    # Box Regression Loss (Smooth L1)
    # Only for positive samples
    l_reg = 0
    if len(positive_indices) > 0:
        pos_boxes = boxes[positive_indices]
        pos_gt_boxes = gt_boxes[positive_indices]
        pos_scores = scores[positive_indices]
        # Smooth L1 loss
        l_reg = smooth_l1_loss(pos_boxes, pos_gt_boxes)
        # Weight by score? Source formula includes p_i,k. 
        # Assuming p_i,k is the score for the specific class k.

        l_reg = weighted_smooth_l1(pos_scores, pos_boxes, pos_gt_boxes)

    # Mask Loss (BCE)
    # Only for positive samples
    l_mask = 0
    if len(positive_indices) > 0:
        pos_masks = masks[positive_indices]
        pos_gt_masks = gt_masks[positive_indices]
        pos_scores = scores[positive_indices]
        # BCE loss
        l_mask = binary_cross_entropy(pos_masks, pos_gt_masks)

## Subtopics

### [Panoptic NeRF](11957-panoptic-nerf.md)
Panoptic NeRF is a method for 3D-to-2D label propagation in urban environments, designed to extend autonomous driving datasets with semantic annotations. It distinguishes itself by using a dual semantic field architecture: one field is rigidly defined by 3D bounding boxes to enforce geometric correctness, while the other is learned to capture semantic distribution. This approach outperforms non-deep learning methods and prior semantic label transfer techniques on the KITTI-360 dataset.

## Operating characteristics
*   **Complexity:** The method relies on a pre-trained NeRF and a proposal network (NeRF-RPN). The RCNN stage adds a 3D CNN mask head and an MLP box head. The complexity is dominated by the 3D feature extraction and the 3D RoIAlign operation on the sampled grid [S1].
*   **Performance:** Benchmarked on the NeRF-RPN dataset (1015 scenes from 3D-FRONT) with multi-view images, camera poses, 3D bounding boxes, and 2D/3D ground truth instance segmentation [S1].
*   **Strengths:** It is one of the first methods to propose 3D instance segmentation for NeRF without utilizing ground-truth information at test time, generalizing to different kinds of scenes requiring only a pre-trained NeRF during inference [S1]. It produces discrete instance masks and bounding boxes, unlike Semantic-NeRF [S1].
*   **Limitations:** Instance label regularization can smooth out detailed structures like thin chair legs or lamp stands, degrading segmentation quality on object silhouettes [S1]. The method requires a large NeRF segmentation dataset (e.g., 3D-FRONT) for training [S1].
*   **When to use:** When 3D instance segmentation is required for a pre-trained NeRF scene, particularly in indoor environments like those in the 3D-FRONT dataset [S1].
*   **When not to use:** When instance-level information is not needed (use Semantic-NeRF instead) or when computational resources for 3D CNNs and 3D RoIAlign are insufficient [S1].

## Background
NeRF-RCNN was introduced in the paper "Instance Neural Radiance Field" [S1]. It builds on NeRF-RPN [23] and imitates the architecture of Mask R-CNN [19]. The method was trained on a large NeRF segmentation dataset built on 3D-FRONT, a large-scale synthetic indoor scene dataset [S1]. The authors note that they are among the first to propose 3D instance segmentation for NeRF without utilizing ground-truth information at test time [S1].
