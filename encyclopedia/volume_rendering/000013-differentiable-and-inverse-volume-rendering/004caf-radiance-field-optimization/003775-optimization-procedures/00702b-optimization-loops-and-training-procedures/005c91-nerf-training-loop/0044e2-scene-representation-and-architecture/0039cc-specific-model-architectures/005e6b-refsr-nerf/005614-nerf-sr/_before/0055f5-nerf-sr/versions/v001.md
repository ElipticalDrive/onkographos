# NeRF-SR

Also called: NeRF-SR: High-Quality Neural Radiance Fields using Supersampling

## Overview
NeRF-SR is a method for high-resolution novel view synthesis that operates on mostly low-resolution inputs by exploiting the 3D consistency inherent in Neural Radiance Fields [S1]. It distinguishes itself from 2D super-resolution methods and other NeRF variants like Mip-NeRF by enforcing multi-view constraints at a sub-pixel level through supersampling and propagating details from a single high-resolution reference image via a depth-guided refinement network [S1].

## How it works
**Inputs:**
*   Posed multi-view low-resolution images of the target scene.
*   (Optional) One high-resolution reference image of the scene.

**Outputs:**
*   High-resolution color images for novel viewpoints.
*   High-resolution depth maps.

**Data Structures:**
The method builds upon the standard NeRF architecture [S1].
*   **NeRF Model:** A multi-layer perceptron (MLP) that takes a 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$ as input and outputs volume density $\sigma$ and color $\mathbf{c}$ [S1].
*   **Refinement Network:** A network that takes estimated depth and image patches as input to hallucinate details [S1].

**Steps:**

1.  **Supersampling Strategy:**
    To exploit 3D consistency, the method shoots multiple rays at each image pixel rather than a single ray [S1]. This enforces multi-view constraints at a sub-pixel level [S1].
    *   For a target pixel, multiple rays are generated within the pixel's footprint.
    *   The NeRF model is queried along these rays to obtain density and color samples.
    *   The final pixel color is computed by volume rendering these samples [S1].
    *   **Supervision:** During training, the rendered average color of the sub-pixels is compared against the ground truth. This is referred to as the "average kernel" supervision [S1]. Note that in practice, if the input images were downsampled using Lanczos interpolation, the degradation is asymmetric, but the method assumes an average kernel for supervision [S1].

2.  **Patch-wise Warp-and-Refine (Optional, when HR reference is available):**
    If a single high-resolution reference image is provided, a refinement network is used to propagate its details to the entire scene [S1].
    *   **Depth Estimation:** The NeRF model provides estimated depth for the scene [S1].
    *   **Warping:** Details from the HR reference image are warped to the target view using the estimated 3D geometry (depth) [S1].
    *   **Refinement:** A refinement network blends the warped details with the NeRF rendering [S1]. This stage is efficient and introduces negligible running time compared to standard NeRF rendering [S1].

**Formulas:**
The volume rendering equation used for supersampling is standard:
$$
\hat{C}(r) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i
$$
where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance, $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ is the opacity, $\sigma_i$ is the density, $\mathbf{c}_i$ is the color, and $\delta_i$ is the distance between samples [S1].

**Parameters:**
*   **Scale Factors:** The method supports specific integer scale factors (e.g., $\times 2, \times 4$). It does not support arbitrary-scale super-resolution [S1].
*   **Input Resolution:** Tested on $100 \times 100$ and $200 \times 200$ for Blender dataset, and $504 \times 378$ for LLFF dataset [S1].

**Edge Cases and Pitfalls:**
*   **Arbitrary Scale:** The method does not support arbitrary-scale super-resolution [S1].
*   **Degradation Kernel:** The method assumes an "average kernel" for supervision. If the actual degradation is asymmetric (e.g., Lanczos), performance may be suboptimal, though symmetric downscale/upscale operations yield better results [S1].
*   **HR Reference Dependency:** The refinement stage requires at least one HR reference image. Without it, the method relies solely on supersampling [S1].

## Operating characteristics
*   **Time Complexity:** The refinement stage introduces negligible running time compared to standard NeRF rendering [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:**
    *   **Blender $\times 2$ (100x100):** PSNR 29.77, SSIM 0.946, LPIPS 0.045 [S1].
    *   **Blender $\times 4$ (100x100):** PSNR 28.07, SSIM 0.921, LPIPS 0.071 [S1].
    *   **Blender $\times 2$ (200x200):** PSNR 31.00, SSIM 0.952, LPIPS 0.038 [S1].
    *   **Blender $\times 4$ (200x200):** PSNR 28.46, SSIM 0.921, LPIPS 0.076 [S1].
    *   **LLFF $\times 2$:** PSNR 27.31, SSIM 0.838, LPIPS 0.139 [S1].
    *   **LLFF $\times 4$:** PSNR 25.13, SSIM 0.730, LPIPS 0.244 [S1].
*   **Strengths:** Generates high-quality results for novel view synthesis at high resolution on both synthetic and real-world datasets without external priors [S1]. Outperforms baselines that require LR-HR pairs for training [S1].
*   **Limitations:** Does not support arbitrary-scale super-resolution [S1].

## Background
NeRF-SR was presented by researchers from Tsinghua University and Kuaishou Technology in 2022 [S1]. It is the first framework to produce decent multi-view super-resolution results with mostly low-resolution input images [S1]. The method addresses the limitation of standard NeRF, which struggles with resolutions beyond observed images, and Mip-NeRF, which only considers rendering with downsampled resolutions [S1].
