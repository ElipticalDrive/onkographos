# ViP-NeRF

Also called: Visibility Prior NeRF

## Overview
ViP-NeRF is a training procedure for Neural Radiance Fields (NeRF) that introduces visibility priors to supervise density estimation, specifically designed to improve rendering quality under sparse input view conditions (fewer than 50–100 views) [S1]. It prevents artifacts caused by insufficient training data by estimating whether pixels in a main view are visible in secondary views and using this information to regularize the NeRF density field [S1]. Unlike methods that rely on pre-trained geometric priors or diffusion models, ViP-NeRF computes these priors directly from input images using planar scanned volumes without requiring any pre-training [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ input images (where $N < 50$), their corresponding camera poses, and intrinsic parameters.
*   **Outputs:** A trained NeRF model (implicit function mapping 3D coordinates and viewing directions to density $\sigma$ and color $\mathbf{c}$) and a visibility prior map for each main view.

**Data Structures:**
*   **NeRF Model:** Standard MLP mapping $(\mathbf{x}, \mathbf{d}) \to (\sigma, \mathbf{c})$.
*   **Visibility Prior Map:** A 2D tensor of the same resolution as the main view image, containing values indicating the likelihood of visibility (derived from error thresholds).
*   **Plane Scan Volume:** A 3D volume or list of warped images representing different depth planes of a secondary view projected onto the main view's coordinate system.

**Algorithm Steps:**

1.  **Visibility Regularization Setup:** For each training iteration, select a "main view" $I_m$ and a "secondary view" $I_s$ from the input set. The goal is to estimate the visibility of pixels in $I_m$ using $I_s$.

2.  **Plane Scan Volume Creation:**
    *   Define a set of depth planes $D = \{d_1, d_2, ..., d_k\}$ spanning the scene's depth range.
    *   For each depth $d_i \in D$, warp the image $I_s$ to the coordinate system of $I_m$ using the known camera poses and the depth $d_i$. Let $W(I_s, d_i)$ be the warped image.
    *   This creates a stack of warped images, forming the plane scan volume.

3.  **Error Map Computation:**
    *   Compare each warped image $W(I_s, d_i)$ with the main view image $I_m$.
    *   Compute an error map $E_i$ for each depth plane. The error metric is typically the photometric difference (e.g., Mean Squared Error or L1 loss) between corresponding pixels.
    *   $$ E_i(\mathbf{u}) = \| I_m(\mathbf{u}) - W(I_s, d_i)(\mathbf{u}) \|^2 $$
    *   where $\mathbf{u}$ is the pixel coordinate in the main view.

4.  **Minimum Error Aggregation:**
    *   For each pixel $\mathbf{u}$, find the minimum error across all depth planes:
    *   $$ E_{min}(\mathbf{u}) = \min_{i} E_i(\mathbf{u}) $$
    *   A low $E_{min}(\mathbf{u})$ indicates that the pixel in the main view is likely visible in the secondary view at the corresponding depth.

5.  **Visibility Prior Map Generation:**
    *   Threshold the minimum error map $E_{min}$ to generate the binary or soft visibility prior map $V_m$:
    *   $$ V_m(\mathbf{u}) = \begin{cases} 1 & \text{if } E_{min}(\mathbf{u}) < \tau \\ 0 & \text{otherwise} \end{cases} $$
    *   where $\tau$ is a predefined threshold. $V_m(\mathbf{u}) = 1$ implies the pixel is visible; $0$ implies occlusion or invalid depth.

6.  **Density Supervision:**
    *   During NeRF training, use the visibility prior map $V_m$ to supervise the density $\sigma$ along the rays cast from the main view.
    *   If $V_m(\mathbf{u}) = 1$, enforce that the accumulated density along the ray corresponds to a visible surface (e.g., by penalizing density in free space or encouraging density at the expected depth).
    *   If $V_m(\mathbf{u}) = 0$, relax the density constraints or penalize density in regions that should be occluded.
    *   This regularization is applied in addition to the standard photometric loss between rendered and input images.

**Parameters:**
*   **Number of Depth Planes ($k$):** Not given in the sources.
*   **Threshold ($\tau$):** Not given in the sources.
*   **Input View Count:** Fewer than 50–100 views [S1].

**Edge Cases and Pitfalls:**
*   **Depth Ambiguity:** If the scene has large unobserved regions, the plane scan volume may not cover all relevant depths, leading to incorrect visibility estimates [S1].
*   **Textureless Regions:** Photometric error may be low in textureless areas even if the depth is incorrect, leading to false visibility priors [S1].
*   **Occlusion Handling:** The method assumes that if a pixel is not visible in a secondary view, it is occluded. This may fail in cases of transparent objects or complex lighting [S1].

## Subtopics

### Visibility-Based Interpolation
Interpolation methods that weigh Block-NeRFs based on per-pixel or per-image predicted visibility to improve sharpness of distant areas [S2]. On the Mission Bay dataset, Pixelwise Visibility achieved a PSNR of 27.39 and Imagewise Visibility achieved a PSNR of 27.41 [S2]. These methods produce sharper reconstructions of far-away areas but are prone to temporal inconsistency, making them suitable only for still images [S2].

## Operating characteristics
**Time and Memory Complexity:**
*   **Time:** The visibility prior computation requires warping images for multiple depth planes, which adds computational overhead per training iteration. The complexity depends on the number of depth planes $k$ and the image resolution.
*   **Memory:** Requires storing the plane scan volume, which scales with the number of depth planes and image resolution.

**Measured Performance:**
*   On the RealEstate-10K dataset, ViP-NeRF achieves a PSNR index 3–4 points higher than the latest paper in 2, 3, and 4 input views [S1].

**Strengths and Limitations:**
*   **Strengths:** Effective in sparse view scenarios; does not require pre-training; improves density estimation reliability [S1].
*   **Limitations:** Sensitive to the choice of threshold $\tau$ and number of depth planes; may struggle with textureless or transparent regions [S1].

**When to Use:**
*   Use when training data is sparse (fewer than 50 views) and pre-trained geometric priors are unavailable [S1].

**When Not to Use:**
*   Avoid when temporal consistency is required (e.g., video synthesis) due to potential artifacts from visibility estimation errors [S2].

## Background
ViP-NeRF was introduced to address the challenge of novel view synthesis with sparse input views [S1]. It builds on the idea that visibility information between views can provide a reliable estimate to supervise the density field [S1]. The method was cited in a 2024 survey on methods and strategies for improving NeRF quality [S1].
