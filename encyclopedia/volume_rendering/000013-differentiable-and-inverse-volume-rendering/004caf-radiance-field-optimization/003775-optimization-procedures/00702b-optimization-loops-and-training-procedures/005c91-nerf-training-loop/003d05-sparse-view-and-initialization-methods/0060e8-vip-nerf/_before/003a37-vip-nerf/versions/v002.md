# ViP-NeRF

Also called: Visibility Prior NeRF

## Overview
ViP-NeRF is a training procedure for Neural Radiance Fields (NeRF) that introduces visibility priors to supervise density estimation, specifically designed to improve rendering quality under sparse input view conditions (fewer than 50–100 views) [S1]. It prevents artifacts caused by insufficient training data by estimating whether pixels in a main view are visible in secondary views, using this information to regularize the NeRF density field [S1]. Unlike methods that rely on pre-trained geometric priors or diffusion models, ViP-NeRF computes these visibility priors using planar scanned volumes without requiring any pre-training [S1].

## How it works
**Inputs:**
*   A set of input images with known camera poses.
*   For each "main view" image, a set of "secondary view" images.
*   A NeRF model parameterized by $\theta$, mapping 3D coordinates $\mathbf{x}$ and viewing directions $\mathbf{d}$ to density $\sigma$ and color $\mathbf{c}$.

**Outputs:**
*   A trained NeRF model.
*   A visibility prior map for the main view.

**Data Structures:**
*   **Plane Scan Volume:** A 3D tensor or list of 2D error maps. For a given main view and secondary view pair, this volume contains error maps corresponding to different depth planes.
*   **Visibility Prior Map:** A 2D map of the same resolution as the main view image, where each pixel value indicates the likelihood of visibility (derived from thresholded minimum error).

**Algorithm:**

1.  **Visibility Regularization Setup:** The method integrates a visibility regularization term into the NeRF training loss. This term uses the visibility prior map to supervise the density $\sigma$ of the NeRF [S1].

2.  **Visibility Prior Estimation:** For a specific main view $I_{main}$ and a secondary view $I_{sec}$, estimate the visibility of each pixel in $I_{main}$ by checking if it is visible in $I_{sec}$ [S1].

3.  **Effective Prediction of Visibility (Planar Scan):**
    a.  Define a set of depth planes $D = \{d_1, d_2, ..., d_k\}$ relative to the camera frame of the secondary view.
    b.  For each depth plane $d_i \in D$:
        i.  Warp the image $I_{sec}$ to the coordinate system of the main view using the known camera poses and the depth $d_i$. Let the warped image be $I_{warped}^{(i)}$.
        ii. Compute an error map $E^{(i)}$ between the main view $I_{main}$ and the warped image $I_{warped}^{(i)}$. The error can be measured using pixel-wise differences (e.g., L1 or L2 norm) or structural similarity.
    c.  Find the minimum error for each pixel across all depth planes:
        $$ E_{min}(u, v) = \min_{i} E^{(i)}(u, v) $$
        where $(u, v)$ are pixel coordinates in the main view.
    d.  Threshold the minimum error map $E_{min}$ to obtain the visibility prior map $V_{map}$:
        $$ V_{map}(u, v) = \begin{cases} 1 & \text{if } E_{min}(u, v) < \tau \\ 0 & \text{otherwise} \end{cases} $$
        where $\tau$ is a predefined threshold. A value of 1 indicates the pixel is likely visible in the secondary view, and 0 indicates it is likely occluded or not visible [S1].

4.  **NeRF Training with Visibility Prior:**
    a.  Render the main view using the current NeRF model.
    b.  Compute the standard photometric loss between the rendered image and $I_{main}$.
    c.  Compute the visibility regularization loss. For pixels where $V_{map}(u, v) = 1$, enforce that the accumulated density along the ray should correspond to a visible surface (e.g., by penalizing high density in empty space or ensuring density peaks align with the visible geometry). For pixels where $V_{map}(u, v) = 0$, the density can be suppressed if the geometry is not consistent with the secondary view's occlusion [S1].
    d.  Update NeRF parameters $\theta$ using gradient descent.

**Parameters:**
*   $\tau$: Threshold for visibility prior map. Value not given in the sources.
*   $D$: Set of depth planes. The number of planes and their range are not given in the sources.

**Edge Cases and Pitfalls:**
*   **Precision:** The accuracy of the visibility prior depends on the precision of the camera poses and the warping process. Incorrect poses can lead to erroneous visibility maps.
*   **Boundaries:** The method assumes that the secondary view provides reliable visibility information. If the secondary view is too far or has significant occlusion differences, the visibility prior may be noisy.
*   **Degenerate Input:** If the main view and secondary view are identical or nearly identical, the visibility prior may be trivial. The method is designed for distinct views.

## Subtopics

### Visibility-Based Interpolation
Interpolation methods that weigh Block-NeRFs based on per-pixel or per-image predicted visibility to improve sharpness of distant areas [S2]. On the Mission Bay dataset, Pixelwise Visibility achieved a PSNR of 27.39 and Imagewise Visibility achieved a PSNR of 27.41 [S2]. These methods produce sharper reconstructions of far-away areas but are prone to temporal inconsistency, making them suitable only for still images [S2].

## Operating characteristics
*   **Time and Memory Complexity:** The method requires computing planar scanned volumes for each main-secondary view pair during training, which adds computational overhead. The complexity depends on the number of depth planes and the resolution of the images.
*   **Measured Performance:** On the RealEstate-10K dataset, ViP-NeRF achieves a PSNR index 3-4 points higher than the latest paper in 2, 3, and 4 input views [S1].
*   **Strengths:** Improves rendering quality under sparse view conditions without pre-training.
*   **Limitations:** Requires careful tuning of the threshold $\tau$ and the set of depth planes. Performance may degrade if camera poses are inaccurate.
*   **When to use:** When training NeRFs with very few input views (e.g., 2-4 views) and no external geometric priors are available.
*   **When not to use:** When temporal consistency is required for video rendering, as related visibility-based interpolation methods are prone to temporal inconsistency [S2].

## Background
ViP-NeRF was introduced to address the challenge of novel view synthesis with sparse input views. It builds on the idea that visibility information from multiple views can provide a reliable estimate to supervise the density of the NeRF [S1]. The method was proposed in the context of improving the rendering quality of synthesized images from new viewpoints under sparse input view conditions [S1].
