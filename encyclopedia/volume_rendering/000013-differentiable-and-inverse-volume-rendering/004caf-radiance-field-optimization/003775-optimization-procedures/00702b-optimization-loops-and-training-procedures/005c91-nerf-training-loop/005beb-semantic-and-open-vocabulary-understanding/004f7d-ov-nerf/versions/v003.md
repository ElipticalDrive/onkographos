# OV-NeRF

Also called: Open-Vocabulary Neural Radiance Fields With Vision and Language Foundation Models for 3D Semantic Understanding

## Overview
OV-NeRF is a method for accurate NeRF-based open-vocabulary 3D semantic understanding that leverages pre-trained vision and language foundation models (CLIP and SAM) to enhance semantic field learning through single-view and cross-view strategies [S1]. It addresses the limitations of prior methods (e.g., LERF, 3DOVS) that directly use noisy and view-inconsistent 2D CLIP relevancy maps for training [S1]. OV-NeRF introduces Region Semantic Ranking (RSR) regularization to rectify coarse boundaries using SAM mask proposals and Cross-view Self-enhancement (CSE) to enforce consistency using the model's own refined 3D predictions [S1]. Builds on [Semantic and Open-Vocabulary Understanding](17023-semantic-and-open-vocabulary-understanding.md).

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ posed training images $I = \{I_i \in \mathbb{R}^{H \times W \times 3} \mid i \in \{1, \dots, N\}\}$ and a set of text descriptions for $M$ classes [S1].
*   **Outputs:** A trained semantic field $\Gamma_\theta$ capable of rendering RGB color, volume density, and semantic features for any ray, along with segmentation logits for open-vocabulary queries [S1].

**Data Structures:**
The core representation is an implicit neural volumetric representation defined by an MLP $\Gamma_\theta$ [S1].
*   **Geometry/Color Branch:** $\Gamma_\theta: (x, d) \to (c, \sigma)$
    *   $x \in \mathbb{R}^3$: 3D position.
    *   $d \in \mathbb{R}^3$: View direction.
    *   $c \in \mathbb{R}^3$: RGB color.
    *   $\sigma \in \mathbb{R}$: Volume density [S1].
*   **Semantic Branch:** An additional MLP branch outputs a semantic vector $f_k$.
    *   $f_k \in \mathbb{R}^D$: Semantic feature vector for the $k$-th sampled point.
    *   $D = 512$: Feature dimension [S1].
*   **Text Embeddings:** $t_c \in \mathbb{R}^{M \times D}$: Textual features for $M$ classes generated by the CLIP text encoder [S1].
*   **Pre-computed Features (Offline):**
    *   $F(r)$: Multi-scale CLIP relevancy feature for ray $r$ [S1].
    *   $S(r)$: Selection vector for suitable scale selection [S1].
    *   $D(r)$: Pre-computed DINO feature for ray $r$ [S1].
    *   $\tilde{S}(r)$: RSR-regularized relevancy map for ray $r$ [S1].

**Numbered Steps:**

1.  **Ray Sampling:** Randomly sample rays from all training images in batches [S1]. For a ray $r$ emitted from camera center $o$ with direction $d$, parameterize points as $r(t) = o + td$ [S1]. Sample $K$ points along the ray with depths $t_1, \dots, t_K$ [S1]. Let $\delta_k = t_{k+1} - t_k$ be the distance between neighboring points [S1].
2.  **NeRF Forward Pass:** For each sampled point $k$ along ray $r$: Query the geometry/color branch: $(c_k, \sigma_k) = \Gamma_\theta(x_k, d)$ [S1]. Query the semantic branch: $f_k = \text{SemanticMLP}(x_k, d)$ [S1]. Compute opacity: $\alpha_k = 1 - \exp(-\delta_k \sigma_k)$ [S1]. Compute transmittance: $T_k = \prod_{j=0}^{k-1} (1 - \alpha_j)$, with $T_0 = 1$ [S1].
3.  **Volume Rendering:** Render RGB color: $\hat{C}(r) = \sum_{k=1}^K T_k \alpha_k c_k$ [S1]. Render semantic feature: $\hat{F}(r) = \sum_{k=1}^K T_k \alpha_k f_k$ [S1]. Compute segmentation logits for text query $t_c$: $\hat{S}(r) = \cos\langle t_c, \hat{F}(r)\rangle$ [S1]. Render DINO feature $\hat{D}(r)$ similarly using a DINO feature branch [S1].
4.  **Region Semantic Ranking (RSR) Regularization (Offline Pre-processing):** For each training image $I_i$: Compute CLIP image feature: $F_i = E_i(I_i)$ [S1]. Compute initial noisy relevancy map: $S_i = \text{argmax}(\cos\langle t_c, F_i \rangle)$ [S1]. Generate region mask proposals using SAM: $R_i = E_{\text{sam}}(I_i) = \{R^1_i, \dots, R^n_i\}$ [S1]. For each region $R^k_i$: Extract pixels from $S_i$ within the mask: $S^k_i = R^k_i * S_i$ [S1]. Rank classes in $S^k_i$ by pixel count in descending order [S1]. Select the top class $S^{k_l}_{i_l}$ [S1]. Update the regularized map $\tilde{S}_i$ by setting pixels in $R^k_i$ to $S^{k_l}_{i_l}$ [S1]. The process is defined as $\tilde{S}_i = \Psi(S_i)$ [S1].
5.  **Cross-view Self-enhancement (CSE) (Post-training):** After training OV-NeRF for several epochs, render pseudo outputs (semantic features and logits) from the trained field for both training views and unseen novel views [S1]. Use these 3D-consistent rendered semantics as supervision targets to further refine the semantic field, replacing inconsistent 2D CLIP semantics [S1].
6.  **Loss Computation and Optimization:** Compute the following losses for each ray $r$ in the batch: Photometric RGB loss: $L_{\text{color}} = \|\hat{C}(r) - C(r)\|_2^2$ [S1]. Relevancy feature loss: $L_{\text{feat}} = -\cos\langle \hat{F}(r), S(r)F(r) \rangle$ [S1]. RSR Loss (replacing standard map loss): $L_{\text{RSR}} = L_{ce}(\hat{S}(r), \tilde{S}(r))$ [S1]. DINO feature loss: $L_{\text{dino}}$ computed as in [29], [30] [S1]. Total Loss: $L = L_{\text{color}} + L_{\text{feat}} + L_{\text{RSR}} + L_{\text{dino}}$ [S1]. Optimize parameters $\theta$ using gradient descent [S1].

**Pseudocode:**

```python
def ov_nerf_training_loop(training_images, text_embeddings, num_epochs):
    """
    Main training loop for OV-NeRF.
    """
    # Helper definitions (standard math/array operations)
    def cosine_similarity(a, b): return (a * b).sum() / (a.norm() * b.norm())
    def argmax(x, axis): return x.argmax(axis=axis)
    def cumprod(x, axis): return torch.cumprod(x, dim=axis)
    def clip_image_encoder(img): return img  # Pre-computed CLIP image feature
    def sam_model(img): return img           # Pre-computed SAM mask proposals
    def get_ray_batches(images): return []   # Yields batches of rays
    def sample_points_along_rays(rays): return rays.points, rays.directions
    def l2_loss(pred, target): return (pred - target).pow(2).sum()
    def cross_entropy_loss(logits, target): return torch.nn.functional.cross_entropy(logits, target)
    def fda_loss(pred, target): return torch.nn.functional.mse_loss(pred, target)  # FDA loss per [29,30]
    def render_pseudo_outputs(model, views): return model.render_all(views)
    def cse_refinement(model, labels): return model  # CSE loss formulation not detailed in sources [S1]

    # 1. Offline RSR Pre-processing
    rsr_maps = {}
    for i, img in enumerate(training_images):
        clip_feat = clip_image_encoder(img)
        noisy_map = argmax(cosine_similarity(text_embeddings, clip_feat), axis=0)
        masks = sam_model(img)
        refined = torch.zeros_like(noisy_map)
        for mask in masks:
            region_scores = mask * noisy_map
            dominant = argmax(region_scores.sum(axis=(1, 2)), axis=0)
            refined[mask > 0] = dominant
        rsr_maps[i] = refined

    # 2. Initialize OV-NeRF Model
    model = OVNeRFModel()
    optimizer = Adam(model.parameters())

    # 3. Training Loop
    for epoch in range(num_epochs):
        for batch in get_ray_batches(training_images):
            points, dirs = sample_points_along_rays(batch.rays)
            colors, densities = model.geometry_branch(points, dirs)
            sem_feats = model.semantic_branch(points, dirs)
            dino_feats = model.dino_branch(points, dirs)

            alphas = 1.0 - torch.exp(-batch.distances * densities)
            transmittances = cumprod(1.0 - alphas, axis=0)
            transmittances = torch.cat([torch.ones_like(transmittances[0:1]), transmittances[:-1]], axis=0)

            rend_colors = (transmittances * alphas * colors).sum(axis=0)
            rend_sem = (transmittances * alphas * sem_feats).sum(axis=0)
            rend_dino = (transmittances * alphas * dino_feats).sum(axis=0)

            logits = cosine_similarity(text_embeddings, rend_sem)
            loss_color = l2_loss(rend_colors, batch.gt_colors)
            target_feat = batch.clip_feat * batch.selection_vec
            loss_feat = -cosine_similarity(rend_sem, target_feat)
            rsr_map = get_rsr_map(batch.ray_indices, rsr_maps)
            loss_rsr = cross_entropy_loss(logits, rsr_map)
            loss_dino = fda_loss(rend_dino, batch.dino_feat)

            total_loss = loss_color + loss_feat + loss_rsr + loss_dino
            optimizer.zero_grad()
            total_loss.backward()
            optimizer.step()

    # 4. Cross-view Self-enhancement (CSE)
    # Render pseudo-labels from trained model for training and novel views
    pseudo_labels = render_pseudo_outputs(model, training_images + novel_views)
    # CSE loss formulation not detailed in sources [S1]
    model = cse_refinement(model, pseudo_labels)
    return model
```

**Parameters:**
*   $D = 512$: Semantic feature dimension [S1].
*   $M$: Number of text classes (varies by query) [S1].
*   RSR process $\Psi$ is performed offline and does not add to training time [S1].

**Edge Cases and Pitfalls:**
*   **Noisy CLIP Maps:** Direct use of 2D CLIP relevancy maps leads to coarse boundaries and view inconsistency [S1].
*   **View Inconsistency:** 2D semantics from CLIP are view-inconsistent [S1].
*   **SAM Proposals:** SAM generates region proposals via uniform sampling of query points and non-maximal suppression, filtering low confidence masks [S1].

## Operating characteristics
*   **Performance:** OV-NeRF achieves a 20.31% improvement in mIoU on the Replica dataset and an 18.42% improvement on the ScanNet dataset compared to state-of-the-art methods [S1].
*   **Complexity:** The RSR process is performed offline, so it does not increase training time [S1]. The core training complexity is similar to standard NeRF optimization but includes additional forward passes for CLIP and DINO features and the RSR loss computation [S1].
*   **Strengths:** Superior segmentation results due to precise boundary rectification (RSR) and cross-view consistency (CSE) [S1]. Robust across various CLIP configurations [S1].
*   **Limitations:** Relies on pre-trained foundation models (CLIP, SAM, DINO) which may have inherent biases or limitations in zero-shot generalization [S1]. The CSE strategy requires an initial training phase before self-enhancement can begin [S1].

## Background
OV-NeRF was proposed to address the limitations of methods like LERF [29] and 3DOVS [30], which straightforwardly utilize coarse and noisy CLIP relevancy maps for training [S1]. It builds on the principles of differentiable volume rendering and open-vocabulary segmentation using vision-language models [S1].
