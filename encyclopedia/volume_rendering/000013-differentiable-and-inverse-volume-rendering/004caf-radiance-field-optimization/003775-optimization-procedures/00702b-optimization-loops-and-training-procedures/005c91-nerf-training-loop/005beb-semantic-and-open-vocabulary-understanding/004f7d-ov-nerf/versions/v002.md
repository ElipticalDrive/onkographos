# OV-NeRF

Also called: Open-Vocabulary Neural Radiance Fields With Vision and Language Foundation Models for 3D Semantic Understanding

## Overview
OV-NeRF is a method for accurate NeRF-based open-vocabulary 3D semantic understanding that leverages pre-trained vision and language foundation models (CLIP and SAM) to enhance semantic field learning through single-view and cross-view strategies [S1]. It addresses the limitations of prior methods (e.g., LERF, 3DOVS) that directly use noisy and view-inconsistent 2D CLIP relevancy maps for training [S1]. OV-NeRF introduces Region Semantic Ranking (RSR) regularization to rectify coarse boundaries using SAM mask proposals and Cross-view Self-enhancement (CSE) to enforce consistency using the model's own refined 3D predictions [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ posed training images $I = \{I_i \in \mathbb{R}^{H \times W \times 3} \mid i \in \{1, \dots, N\}\}$ and a set of text descriptions for $M$ classes.
*   **Outputs:** A trained semantic field $\Gamma_\theta$ capable of rendering RGB color, volume density, and semantic features for any ray, along with segmentation logits for open-vocabulary queries.

**Data Structures:**
The core representation is an implicit neural volumetric representation defined by an MLP $\Gamma_\theta$.
*   **Geometry/Color Branch:** $\Gamma_\theta: (x, d) \to (c, \sigma)$
    *   $x \in \mathbb{R}^3$: 3D position.
    *   $d \in \mathbb{R}^3$: View direction.
    *   $c \in \mathbb{R}^3$: RGB color.
    *   $\sigma \in \mathbb{R}$: Volume density.
*   **Semantic Branch:** An additional MLP branch outputs a semantic vector $f_k$.
    *   $f_k \in \mathbb{R}^D$: Semantic feature vector for the $k$-th sampled point.
    *   $D = 512$: Feature dimension [S1].
*   **Text Embeddings:** $t_c \in \mathbb{R}^{M \times D}$: Textual features for $M$ classes generated by the CLIP text encoder [S1].
*   **Pre-computed Features (Offline):**
    *   $F(r)$: Multi-scale CLIP relevancy feature for ray $r$ [S1].
    *   $S(r)$: Selection vector for suitable scale selection [S1].
    *   $D(r)$: Pre-computed DINO feature for ray $r$ [S1].
    *   $\tilde{S}(r)$: RSR-regularized relevancy map for ray $r$ [S1].

**Numbered Steps:**

1.  **Ray Sampling:** Randomly sample rays from all training images in batches. For a ray $r$ emitted from camera center $o$ with direction $d$, parameterize points as $r(t) = o + td$. Sample $K$ points along the ray with depths $t_1, \dots, t_K$. Let $\delta_k = t_{k+1} - t_k$ be the distance between neighboring points [S1].

2.  **NeRF Forward Pass:** For each sampled point $k$ along ray $r$:
    *   Query the geometry/color branch: $(c_k, \sigma_k) = \Gamma_\theta(x_k, d)$.
    *   Query the semantic branch: $f_k = \text{SemanticMLP}(x_k, d)$.
    *   Compute opacity: $\alpha_k = 1 - \exp(-\delta_k \sigma_k)$.
    *   Compute transmittance: $T_k = \prod_{j=0}^{k-1} (1 - \alpha_j)$, with $T_0 = 1$ [S1].

3.  **Volume Rendering:**
    *   Render RGB color: $\hat{C}(r) = \sum_{k=1}^K T_k \alpha_k c_k$.
    *   Render semantic feature: $\hat{F}(r) = \sum_{k=1}^K T_k \alpha_k f_k$.
    *   Compute segmentation logits for text query $t_c$: $\hat{S}(r) = \cos\langle t_c, \hat{F}(r)\rangle$.
    *   Render DINO feature $\hat{D}(r)$ similarly using a DINO feature branch [S1].

4.  **Region Semantic Ranking (RSR) Regularization (Offline Pre-processing):**
    *   For each training image $I_i$:
        *   Compute CLIP image feature: $F_i = E_i(I_i)$.
        *   Compute initial noisy relevancy map: $S_i = \text{argmax}(\cos\langle t_c, F_i \rangle)$.
        *   Generate region mask proposals using SAM: $R_i = E_{\text{sam}}(I_i) = \{R^1_i, \dots, R^n_i\}$.
        *   For each region $R^k_i$:
            *   Extract pixels from $S_i$ within the mask: $S^k_i = R^k_i * S_i$.
            *   Rank classes in $S^k_i$ by pixel count in descending order.
            *   Select the top class $S^{k_{l}}_{i_l}$.
            *   Update the regularized map $\tilde{S}_i$ by setting pixels in $R^k_i$ to $S^{k_{l}}_{i_l}$.
    *   The process is defined as $\tilde{S}_i = \Psi(S_i)$ [S1].

5.  **Cross-view Self-enhancement (CSE) (Post-training):**
    *   After training OV-NeRF for several epochs, render pseudo outputs (semantic features and logits) from the trained field for both training views and unseen novel views [S1].
    *   Use these 3D-consistent rendered semantics as supervision targets to further refine the semantic field, replacing inconsistent 2D CLIP semantics [S1].

6.  **Loss Computation and Optimization:**
    *   Compute the following losses for each ray $r$ in the batch:
        *   Photometric RGB loss: $L_{\text{color}} = \|\hat{C}(r) - C(r)\|_2^2$.
        *   Relevancy feature loss: $L_{\text{feat}} = -\cos\langle \hat{F}(r), S(r)F(r) \rangle$.
        *   RSR Loss (replacing standard map loss): $L_{\text{RSR}} = L_{ce}(\hat{S}(r), \tilde{S}(r))$.
        *   DINO feature loss: $L_{\text{dino}} = L_{fda}(\hat{D}(r), D(r))$ (FDA loss as defined in [30]) [S1].
    *   Total Loss: $L = L_{\text{color}} + L_{\text{feat}} + L_{\text{RSR}} + L_{\text{dino}}$.
    *   Optimize parameters $\theta$ (and semantic branch parameters) using gradient descent [S1].

**Pseudocode:**

```python
def ov_nerf_training_loop(training_images, text_descriptions, num_epochs):
    """
    Main training loop for OV-NeRF.
    """
    # 1. Offline RSR Pre-processing
    # This is performed once before training to generate precise supervision maps.
    rsr_supervision_maps = {}
    for i, image in enumerate(training_images):
        # Get CLIP image features
        clip_img_feat = clip_image_encoder(image)
        # Get initial noisy relevancy map
        initial_map = argmax(cosine_similarity(text_embeddings, clip_img_feat))
        # Get SAM region proposals
        sam_masks = sam_model(image)
        
        # Apply Region Semantic Ranking
        refined_map = zeros_like(initial_map)
        for mask in sam_masks:
            # Extract class scores within the mask region
            region_scores = mask * initial_map
            # Find the dominant class in this region
            dominant_class = argmax(sum(region_scores, axis=(1, 2))) # Assuming spatial aggregation
            # Assign dominant class to the mask region
            refined_map[mask] = dominant_class
        
        rsr_supervision_maps[i] = refined_map

    # 2. Initialize OV-NeRF Model
    model = OVNeRFModel()
    optimizer = Adam(model.parameters())

    # 3. Training Loop
    for epoch in range(num_epochs):
        for batch in get_ray_batches(training_images):
            rays = batch.rays
            gt_colors = batch.gt_colors
            
            # Forward pass
            # Sample points along rays
            points, directions = sample_points_along_rays(rays)
            
            # Query NeRF branches
            colors, densities = model.geometry_branch(points, directions)
            semantic_feats = model.semantic_branch(points, directions)
            dino_feats = model.dino_branch(points, directions)
            
            # Volume rendering
            alphas = 1 - exp(-distances * densities)
            transmittances = cumprod(1 - alphas)
            
            rendered_colors = sum(transmittances * alphas * colors)
            rendered_semantics = sum(transmittances * alphas * semantic_feats)
            rendered_dinos = sum(transmittances * alphas * dino_feats)
            
            # Compute logits
            logits = cosine_similarity(text_embeddings, rendered_semantics)
            
            # Compute Losses
            # L_color
            loss_color = l2_loss(rendered_colors, gt_colors)
            
            # L_feat (using pre-computed F(r) and S(r) from CLIP)
            # Note: S(r)F(r) implies scaling the CLIP feature by the selection vector
            target_feat = batch.precomputed_clip_feat * batch.precomputed_selection_vec
            loss_feat = -cosine_similarity(rendered_semantics, target_feat)
            
            # L_RSR (using RSR-regularized maps)
            # Map ray to image index to retrieve pre-computed RSR map
            rsr_map = get_rsr_map_for_ray(batch.ray_indices)
            loss_rsr = cross_entropy_loss(logits, rsr_map)
            
            # L_dino (using pre-computed DINO features)
            loss_dino = fda_loss(rendered_dinos, batch.precomputed_dino_feat)
            
            total_loss = loss_color + loss_feat + loss_rsr + loss_dino
            
            # Backpropagate
            optimizer.zero_grad()
            total_loss.backward()
            optimizer.step()

    # 4. Cross-view Self-enhancement (CSE)
    # After initial training, render pseudo-labels from the trained model
    # and use them to further refine the model for consistency.
    # This step leverages 3D consistent semantics from the well-trained field.
    pseudo_labels = render_pseudo_outputs(model, training_images + novel_views)
    # Re-train or fine-tune using these pseudo-labels as supervision
    # (Implementation details for CSE specific loss formulation are not explicitly 
    # detailed in the provided text beyond "leveraging refined 3D consistent semantics")
    model = cse_refinement(model, pseudo_labels)
    
    return model
```

**Parameters:**
*   $D = 512$: Semantic feature dimension [S1].
*   $M$: Number of text classes (varies by query) [S1].
*   RSR process $\Psi$ is performed offline and does not add to training time [S1].

**Edge Cases and Pitfalls:**
*   **Noisy CLIP Maps:** Direct use of 2D CLIP relevancy maps leads to coarse boundaries and view inconsistency. RSR is required to rectify this [S1].
*   **View Inconsistency:** 2D semantics from CLIP are view-inconsistent. CSE is necessary to enforce 3D consistency [S1].
*   **SAM Proposals:** SAM generates region proposals via uniform sampling of query points and non-maximal suppression. Low confidence masks are filtered [S1].

## Operating characteristics
*   **Performance:** OV-NeRF achieves a 20.31% improvement in mIoU on the Replica dataset and an 18.42% improvement on the ScanNet dataset compared to state-of-the-art methods [S1].
*   **Complexity:** The RSR process is performed offline, so it does not increase training time. The core training complexity is similar to standard NeRF optimization but includes additional forward passes for CLIP and DINO features and the RSR loss computation [S1].
*   **Strengths:** Superior segmentation results due to precise boundary rectification (RSR) and cross-view consistency (CSE). Robust across various CLIP configurations [S1].
*   **Limitations:** Relies on pre-trained foundation models (CLIP, SAM, DINO) which may have inherent biases or limitations in zero-shot generalization. The CSE strategy requires an initial training phase before self-enhancement can begin [S1].

## Background
OV-NeRF was proposed to address the limitations of methods like LERF [29] and 3DOVS [30], which straightforwardly utilize coarse and noisy CLIP relevancy maps for training [S1]. It builds on the principles of differentiable volume rendering and open-vocabulary segmentation using vision-language models [S1]. The method was published in IEEE Transactions on Circuits and Systems for Video Technology in 2024 [S1].
