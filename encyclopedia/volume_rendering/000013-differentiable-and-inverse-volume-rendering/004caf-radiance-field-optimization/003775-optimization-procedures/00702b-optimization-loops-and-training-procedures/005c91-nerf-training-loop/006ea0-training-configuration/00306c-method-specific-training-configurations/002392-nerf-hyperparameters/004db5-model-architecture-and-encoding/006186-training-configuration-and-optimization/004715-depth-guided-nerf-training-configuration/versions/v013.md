# Depth-Guided NeRF Training Configuration
Also called: Depth-Guided NeRF Training
## Overview
This configuration defines the training protocol for Neural Radiance Fields (NeRF) that incorporate depth priors to improve reconstruction quality, particularly in sparse-view or noisy-pose scenarios. It modifies the standard NeRF architecture with specific regularization and integrates a depth-aware loss function. It is distinguished from sibling methods by its specific hyperparameter tuning for depth scale learning and its reliance on the Earth Mover’s Distance (EMD) formulation for depth supervision, as opposed to CLIP-based semantic guidance [12073-clipnerf-training-configuration.md] or binary occupancy representations [13622-binary-radiance-fields.md].
## How it works
**Inputs and Outputs:**
*   **Inputs:** Multi-view RGB images, camera poses, and optionally ground-truth depth maps (or depth estimates from a separate module).
*   **Outputs:** A trained NeRF model capable of rendering RGB images and depth maps.

**Data Structures and Architecture Modifications:**
The network architecture builds on the original NeRF [Parent]. The primary modification is the addition of regularization layers:
*   **Dropout:** Dropout layers with probability $p=0.1$ are added after each of the first eight fully connected ReLU-activated layers that encode the positional encoding.

**Loss Function:**
The total loss combines the standard photometric loss with a depth loss. The depth loss is weighted by $\lambda$. An uncertainty term is also included, weighted by $\gamma$.
$$ \mathcal{L}_{total} = \mathcal{L}_{rgb} + \lambda \mathcal{L}_{depth} + \gamma \mathcal{L}_{uncertainty} $$
The depth evaluation metrics used to assess performance (and implicitly guide the loss behavior in related implementations) include Root Mean Square Error (RMSE), Log-RMSE, Absolute Relative Error (AbsRel), and Squared Relative Error (SqRel) [S1]:
$$ \text{RMSE}(d, \hat{d}) = \sqrt{\frac{1}{K} \sum_{k=1}^{K} (d_k - \hat{d}_k)^2} $$
$$ \text{RMSE}_{\log}(d, \hat{d}) = \sqrt{\frac{1}{K} \sum_{k=1}^{K} (\log d_k - \log \hat{d}_k)^2} $$
$$ \text{AbsRel}(d, \hat{d}) = \frac{1}{K} \sum_{k=1}^{K} \frac{|d_k - \hat{d}_k|}{d_k} $$
$$ \text{SqRel}(d, \hat{d}) = \frac{1}{K} \sum_{k=1}^{K} \frac{(d_k - \hat{d}_k)^2}{d_k} $$
where $K$ is the number of pixels with valid ground truth depth.

**Training Steps:**
1.  **Initialization:** Initialize the NeRF MLPs.
2.  **Sampling:** Sample rays through the scene.
3.  **Rendering:** Compute volume rendering for RGB and depth.
4.  **Depth Uncertainty Thresholding:** Calculate a threshold $\tau$ to evaluate depth map uncertainty. For ScanNet, this is defined as:
    $$ \tau = (\text{max\_depth} - \text{min\_depth}) \cdot 0.0001 $$
    where $\text{max\_depth} = 10$ and $\text{min\_depth} = 0.001$ [S1].
5.  **Loss Calculation:** Compute photometric loss and depth loss using the weighted parameters.
6.  **Optimization:** Update weights using the Adam optimizer.

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Initial Learning Rate:** $5 \times 10^{-4}$ [S1].
*   **Learning Rate Schedule:** Reduce to $5 \times 10^{-5}$ after 80% of total steps [S1].
*   **Weight Decay:** $1 \times 10^{-6}$ [S1].
*   **Depth Loss Weight ($\lambda$):** $0.007$ for all scenes, except scene 710 where it is $0.02$ [S1].
*   **Uncertainty Weight ($\gamma$):** $1$ [S1].
*   **Depth Scale Learning Rate:** $1 \times 10^{-7}$ [S1].
*   **Total Training Steps:** $500,000$ [S1].

**Pseudocode:**
```python
def train_depth_guided_nerf(images, poses, gt_depths, num_steps=500000):
    # Initialize NeRF model with dropout layers
    model = NeRFModel()
    for i in range(8):
        model.add_dropout(layer_index=i, p=0.1)
        
    optimizer = Adam(model.parameters(), lr=5e-4, weight_decay=1e-6)
    
    # Depth scale specific learning rate
    depth_scale_param = get_depth_scale_parameter(model)
    optimizer.add_param_group({'params': [depth_scale_param], 'lr': 1e-7})
    
    for step in range(num_steps):
        # Learning rate schedule: reduce to 5e-5 after 80% of steps
        if step > 0.8 * num_steps:
            set_learning_rate(optimizer, 5e-5)
            
        # Sample rays and render
        rays = sample_rays(images, poses)
        rgb_pred, depth_pred = model.render(rays)
        
        # Compute photometric loss
        loss_rgb = compute_mse_loss(rgb_pred, rays.rgb_gt)
        
        # Compute depth loss
        # Note: Specific EMD formulation details are in the source paper,
        # but the integration uses the official DS-NeRF depth loss implementation [S2]
        loss_depth = compute_depth_loss(depth_pred, rays.depth_gt)
        
        # Compute uncertainty loss (weight gamma = 1)
        loss_uncertainty = compute_uncertainty_loss(depth_pred, rays.depth_gt)
        
        # Scene-specific depth loss weight
        if scene_id == 710:
            lambda_depth = 0.02
        else:
            lambda_depth = 0.007
            
        total_loss = loss_rgb + lambda_depth * loss_depth + 1.0 * loss_uncertainty
        
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
```

## Subtopics

### DS-NeRF Depth Loss Integration
This variant refers to the specific integration of the depth loss function from the DS-NeRF official code base into the training pipeline. It is chosen when leveraging established depth-consistency losses from DS-NeRF. Implementation requires re-training on LLFF train/test splits using released configuration files, as original publication results for LLFF used a different split and DTU results could not be reproduced due to missing config files [S2].

## Operating characteristics
**Time and Memory Complexity:**
Not given in the sources. The training duration is fixed at 500,000 steps [S1].

**Measured Performance:**
Not given in the sources. The configuration is designed to improve depth accuracy and overall reconstruction quality in depth-guided settings [S1].

**Strengths and Limitations:**
*   **Strengths:** The specific dropout regularization prevents overfitting in the early layers. The small depth scale learning rate ($1e-7$) allows for fine-tuning of depth scaling parameters without destabilizing the main network weights [S1].
*   **Limitations:** The configuration is specific to the ScanNet and LLFF datasets (as per the source details). Reproducing results for other datasets like DTU may require additional architectural tricks not covered in the standard configuration [S2].

**When to use it:**
Use this configuration when training a NeRF model that requires explicit depth supervision, particularly for indoor scenes (ScanNet) or outdoor scenes (LLFF) where depth priors are available or can be estimated.

## Background
This configuration originates from the work on "Depth-Guided NeRF Training via Earth Mover’s Distance" [S1]. It builds upon the original NeRF architecture [Parent] and incorporates techniques from DS-NeRF [S2] for depth loss integration. The method addresses the challenge of rendering high-quality depth maps alongside RGB images by explicitly optimizing for depth consistency using EMD and specific hyperparameter tuning.
