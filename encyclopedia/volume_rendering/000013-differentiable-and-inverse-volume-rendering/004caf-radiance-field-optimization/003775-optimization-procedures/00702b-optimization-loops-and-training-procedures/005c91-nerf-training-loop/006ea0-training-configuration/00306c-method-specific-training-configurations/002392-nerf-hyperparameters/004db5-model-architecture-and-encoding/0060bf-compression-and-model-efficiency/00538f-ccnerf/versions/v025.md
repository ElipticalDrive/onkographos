# CCNeRF

Also called: Compressible-Composable NeRF, Rank-residual Decomposition NeRF

## Overview
CCNeRF is a neural field representation that enables efficient compression and composition of 3D scenes by learning a hybrid tensor rank decomposition of the scene without using neural networks for rendering [S1]. Unlike NeRF variants that rely on a shared MLP renderer (e.g., NSVF) or hybrid tensor-MLP approaches (e.g., TensoRF), CCNeRF models the radiance field *only* with tensor rank decomposition, preserving low-rank approximation properties to allow dynamic model size adjustment via rank truncation and arbitrary composition via rank concatenation [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 2D images with known camera poses $(o, d)$ and a target rank configuration (ratio of vector- to matrix-based components).
*   **Output:** A compressed radiance field representation consisting of decomposed rank components (vectors or matrices) and a weight matrix, enabling volume rendering of new views.

**Data Structures:**
The model structure consists of two main parts [S1]:
1.  **Rank Components:** A set of decomposed components representing the scene. These are either:
    *   **Vector-based (CP):** Corresponding to CANDECOMP/PARAFAC decomposition.
    *   **Matrix-based (Triple Plane):** A less compact variant using factor matrices.
    *   The ratio of vector- to matrix-based components is controllable to trade off between model size and performance.
2.  **Weight Matrix:** A matrix storing rank weights for different feature channels.

**Querying a 3D Coordinate:**
To query a 3D coordinate $\mathbf{x}$ for density $\sigma$ and color $\mathbf{c}$:
1.  Project the coordinate $\mathbf{x}$ to the decomposed vectors or matrices [S1].
2.  Perform weighted interpolation using the stored rank weights [S1].

**Volume Rendering:**
The final pixel color $\hat{C}(r)$ for a ray $r$ is computed using the standard volume rendering equation [S1]:
$$
\hat{C}(r) = \sum_i T_i \alpha_i c_i
$$
where:
*   $T_i = \prod_{j<i} (1 - \alpha_i)$ is the accumulated transmittance.
*   $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ is the opacity at sample $i$.
*   $\delta_i = t_{i+1} - t_i$ is the distance between samples.
*   $\sigma_i$ is the density and $c_i$ is the color at sample position $t_i$ along ray $r$ from origin $o$ with direction $d$.

**Composition:**
Different models are composed by concatenating their rank components along the rank dimension [S1]. A transformation matrix is recorded for each object to control its position and orientation in the composed scene [S1].

**Compression (Rank Truncation):**
Model size is dynamically adjusted by rank truncation. An empirical sort-and-truncate strategy is used to achieve near-optimal low-rank approximation at any targeted rank, allowing trade-off between model size and rendering quality without retraining [S1]. The number of components kept in the decomposition determines the model size and detail level; lower ranks preserve primary information due to rank-residual learning [S1].

**Tucker Decomposition Context:**
The method is motivated by tensor decomposition. For a 3D tensor $T \in \mathbb{R}^{H \times W \times D}$, the Tucker decomposition is defined as [S1]:
$$
T_{i,j,k} = \sum_{p=1}^P \sum_{q=1}^Q \sum_{r=1}^R S_{p,q,r} U^x_{i,p} U^y_{j,q} U^z_{k,r}
$$
where $S$ is the core tensor and $U^x, U^y, U^z$ are factor matrices. CCNeRF uses a hybrid of CP and Tucker-like structures.

**Pitfalls and Edge Cases:**
*   **Truncation Optimality:** Standard truncated Higher-Order SVD (HOSVD) does not hold the optimal property of truncated SVD, but yields a quasi-optimal solution sufficient for practical use [S1].
*   **MLP Dependency:** Unlike TensoRF, CCNeRF avoids MLPs in the rendering path to preserve low-rank properties; introducing MLPs would prevent compression or composition [S1].

## Operating characteristics
*   **Compression:** Achieves near-optimal low-rank approximation at any targeted rank without extra optimization [S1].
*   **Composition:** Supports arbitrary transformation and composition of different models without retraining or compatibility constraints [S1].
*   **Storage:** Storage cost growth in composed scenes can be mitigated by compressing unimportant objects [S1].
*   **Quality:** Achieves comparable rendering quality to state-of-the-art methods [S1].

## Background
CCNeRF was introduced by Jiaxiang Tang, Xiaokang Chen, Jingbo Wang, and Gang Zeng from Peking University and Chinese University of Hong Kong [S1]. It addresses the difficulty of manipulating implicit NeRF representations, which are often restricted by shared renderer networks or suffer from large model sizes [S1]. The method builds on the low-rank approximation property of SVD and applies it to neural radiance fields via rank-residual learning [S1].
