# Spatially Encoded Radiance Fields

Also called: Sparse Radiance Fields, Voxel-based NeRF

## Overview
Spatially Encoded Radiance Fields (SERF) simplify the implicit radiance function by spatially decomposing it into smaller, local functions to reduce the computational complexity and inference latency of the Multi-Layer Perceptron (MLP) [S1]. Unlike standard NeRF which relies on a dense global MLP for all queries, SERF methods store feature vectors in a voxel grid (often sparse or multi-resolution), allowing the MLP to operate on localized features, thereby achieving equal or higher rendering quality with a smaller network [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Camera ray parameters (origin $o$, direction $d$), voxel grid data structures, and MLP weights.
*   **Output:** Volume density $\sigma$ and view-dependent color $\mathbf{c}$ for the ray.

**Data Structures:**
*   **Voxel Grid:** A 3D grid storing feature vectors. The grid can be dense, sparse, or multi-resolution (e.g., Instant-NeRF) [S1].
    *   *Layout:* Each voxel contains a feature vector $\mathbf{f}$. The size and resolution are hyperparameters.
    *   *Sparse Implementation:* Uses a hash map or linked list to store only occupied voxels, reducing memory usage [S1].
*   **MLP:** A smaller network than standard NeRF, taking encoded features as input [S1].

**Numbered Steps:**
1.  **Ray Sampling:** Generate sample points along the camera ray $r(\lambda) = o + \lambda d$ within the near/far range [S1].
2.  **Feature Lookup:** For each sample point, determine its position in the voxel grid.
    *   If the grid is dense, interpolate features from surrounding voxels.
    *   If the grid is sparse, retrieve the feature vector if the voxel is occupied, or use a default/zero feature if empty [S1].
3.  **Feature Encoding:** The retrieved feature vector $\mathbf{f}$ is processed. In some implementations, the spatial position may be encoded or combined with the feature vector [S1].
4.  **MLP Inference:** The feature vector (and potentially encoded position/direction) is passed to the MLP.
    *   The MLP predicts the volume density $\sigma$ and the color $\mathbf{c}$ [S1].
5.  **Rendering:** Use the predicted $\sigma$ and $\mathbf{c}$ in the volume rendering integral to compute the final pixel color [S1].

**Formulas:**
*   Ray parameterization: $r(\lambda) = o + \lambda d$ [S1].
*   Volume Rendering Integral: $C(r) = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i$, where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ and $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ [S1].

**Parameters:**
*   Voxel grid resolution: Not given in the sources.
*   MLP size: Smaller than standard NeRF, but exact dimensions not specified [S1].
*   Sparsity threshold: Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Empty Voxels:** In sparse grids, handling empty voxels requires a default feature value or fallback mechanism [S1].
*   **Interpolation Artifacts:** In dense grids, trilinear interpolation between voxels can introduce blurring or artifacts if the resolution is too low [S1].
*   **Precision:** Floating-point precision issues may arise when mapping continuous ray samples to discrete voxel indices [G].

**Pseudocode:**
```python
def render_ray(ray_origin, ray_direction, voxel_grid, mlp, near, far, num_samples):
    # Generate sample points along the ray
    lambdas = np.linspace(near, far, num_samples)
    points = ray_origin + lambdas[:, None] * ray_direction
    
    # Initialize output arrays
    densities = np.zeros(num_samples)
    colors = np.zeros((num_samples, 3))
    
    for i, point in enumerate(points):
        # 1. Feature Lookup
        # Determine voxel coordinates for the point
        voxel_coords = point_to_voxel_coords(point, voxel_grid.resolution, voxel_grid.origin)
        
        # Retrieve feature vector from the voxel grid
        # For sparse grids, check if voxel is occupied
        if voxel_grid.is_occupied(voxel_coords):
            feature_vector = voxel_grid.get_feature(voxel_coords)
        else:
            # Default feature for empty voxels (e.g., zeros)
            feature_vector = np.zeros(voxel_grid.feature_dim)
            
        # 2. MLP Inference
        # Pass feature vector to MLP to get density and color
        # Note: Some implementations may also encode position/direction here
        sigma, color = mlp.forward(feature_vector)
        
        densities[i] = sigma
        colors[i] = color
        
    # 3. Volume Rendering
    # Compute transmittance and alpha
    deltas = np.diff(np.concatenate(([near], lambdas)))
    alphas = 1 - np.exp(-densities * deltas)
    transmittance = np.exp(-np.cumsum(densities * deltas))
    transmittance = np.concatenate(([1.0], transmittance[:-1]))
    
    # Composite color
    final_color = np.sum(transmittance[:, None] * alphas[:, None] * colors, axis=0)
    
    return final_color
```

## Subtopics

### Sparse Radiance Fields
Uses sparse voxel grids to store features, reducing memory usage and computation for empty space [S1].

### Instant-NeRF
Uses a multi-resolution feature voxel grid to accelerate training and rendering [S1].

### Plenoxels
Represents the radiance field using a voxel grid without an MLP, encoding density and color directly [S1].

## Operating characteristics
*   **Time Complexity:** Faster inference than standard NeRF due to the smaller MLP and localized feature lookups [S1].
*   **Memory Complexity:** Depends on the voxel grid resolution and sparsity. Sparse grids reduce memory usage significantly [S1].
*   **Strengths:** Reduced computational load, faster rendering, ability to use smaller MLPs [S1].
*   **Limitations:** Potential artifacts from interpolation or empty voxel handling [S1].
*   **When to Use:** When inference speed is critical and memory is constrained [S1].

## Background
*   **Origin:** The concept of spatially decomposing the radiance function was demonstrated by Yu et al. [S1].
*   **Development:** Müller et al. developed Instant-NeRF, a multi-resolution feature voxel grid approach [S1].
*   **Usage:** Used in various radiance field techniques to improve efficiency [S1].
