# NRFF

Also called: Neural Radiance Feature Field

## Overview
NRFF encodes view-dependent effects in radiance fields by replacing Ref-NeRF's positional encoding and roughness/IDE inputs with a structured latent representation of specular reflections [S1]. It differs from its siblings like [Multi-Space Neural Radiance Field (MS-NeRF)](11707-multi-space-neural-radiance-field-ms-nerf.md) and [Semantic-NeRF](14889-semantic-nerf.md) by explicitly modeling anisotropic reflections using Anisotropic Spherical Gaussians (ASG) and a custom Rendering Equation Encoding (REE) in the latent space, rather than relying on isotropic roughness or precomputed environment maps [S1]. It builds on [Feature Fields](12995-feature-fields.md).

## How it works
**Inputs:** Camera rays defined by origin $\mathbf{o}$ and direction $\mathbf{d}$; ground-truth color images; optional ground-truth feature maps or teacher network outputs for supervision [S1, 12995-feature-fields.md].
**Outputs:** Rendered color images $\hat{\mathbf{C}}$ and rendered feature maps $\hat{\mathbf{F}}$ [12995-feature-fields.md].

**Data Structures:**
1.  **Spatial MLP:** Takes 3D position $\mathbf{x}$ [S1]. Uses Multiscale Tensor Decomposition (MTD) for input representation [S1]. Outputs a vector of 128 values representing $N=8 \times 16$ ASG lobes [S1].
2.  **ASG MLP:** Takes the 128 ASG feature vector [S1]. Outputs bottleneck coefficients $\mathbf{a}$, and scalar bandwidth coefficients $\boldsymbol{\lambda}, \boldsymbol{\mu}$ (all of length $N$), where $\lambda_i, \mu_i > 0$ model the ASG shape in orthogonal directions [S1].
3.  **Directional MLP:** Takes the REE vector (size $8 \times 16 \times 2$) and view direction $\mathbf{d}$ [S1]. Outputs color $\mathbf{c}$ and density $\sigma$ [S1].

**Rendering Equation Encoding (REE):**
The REE integrates specular contributions in the latent space [S1]. For a reflection direction $\hat{\omega}_r$, the encoding is computed as [S1]:

$$
\text{REE}(\hat{\omega}_r, \mathbf{a}, \boldsymbol{\lambda}, \boldsymbol{\mu}) = \sum_{i=0}^{N-1} a_i S(\hat{\omega}_r; \omega_i) \exp\left(-\lambda_i (\hat{\omega}_r \cdot \omega_{\lambda_i})^2 - \mu_i (\hat{\omega}_r \cdot \omega_{\mu_i})^2\right)
$$

Where:
*   $N = 128$ is the number of ASG lobes [S1].
*   $a_i$ is the bottleneck coefficient of the $i$-th ASG [S1].
*   $S(\hat{\omega}_r; \omega_i) = \max(\hat{\omega}_r \cdot \omega_i, 0)$ is a smooth term [S1].
*   $\lambda_i, \mu_i > 0$ are bandwidth coefficients related to orthogonal axes $\omega_{\lambda_i}, \omega_{\mu_i}$ [S1].
*   The set of directions $\omega_i$ covers the unit sphere (360 degrees) [S1].

**Algorithm Steps:**
1.  Sample points $\mathbf{x}_i$ along the ray [G].
2.  Pass $\mathbf{x}_i$ through the Spatial MLP (using MTD) to get ASG features [S1].
3.  Pass ASG features through the ASG MLP to obtain coefficients $\mathbf{a}, \boldsymbol{\lambda}, \boldsymbol{\mu}$ [S1].
4.  Compute the REE vector for the view direction $\mathbf{d}$ using the formula above [S1].
5.  Pass the REE vector and $\mathbf{d}$ through the Directional MLP to get $\mathbf{c}_i, \sigma_i$ [S1].
6.  Render color and features using standard volume integration [12995-feature-fields.md].
7.  Compute loss:
    *   Color loss (standard MSE/SSIM) [S1].
    *   Feature loss (if available) [S1, 12995-feature-fields.md].
    *   Regularization loss $L_f$ to enforce sparsity:
        $$
        L_f = \frac{\beta}{M} \sum_{i=0}^{M-1} \frac{|\mathbf{F}_\tau^i|}{\tau}
        $$
        Where $M$ is the number of features in the density field representation, $\mathbf{F}_\tau$ is the density field feature map, $\tau$ is a threshold, and $\beta$ is a coefficient [S1].

**Pseudocode:**

```python
import math

def sample_points(ray_origin, ray_direction, num_samples, t_near=0.0, t_far=1.0):
    """Uniformly samples points along a ray segment."""
    t_vals = [t_near + i * (t_far - t_near) / (num_samples - 1) for i in range(num_samples)]
    return [ray_origin + ray_direction * t for t in t_vals]

def volume_render(colors, densities, deltas):
    """Standard alpha compositing for volume rendering."""
    alpha = [1.0 - math.exp(-d * dt) for d, dt in zip(densities, deltas)]
    transmittance = 1.0
    rendered = [0.0, 0.0, 0.0]
    for c, a in zip(colors, alpha):
        rendered = [rendered[j] + transmittance * a * c[j] for j in range(3)]
        transmittance *= (1.0 - a)
    return rendered

def compute_ree(view_direction, a, lambda_coeffs, mu_coeffs, lobe_directions, lobe_lambda_axes, lobe_mu_axes):
    """Computes the Rendering Equation Encoding vector per lobe."""
    ree_values = []
    for i in range(len(a)):
        omega_i = lobe_directions[i]
        omega_lambda_i = lobe_lambda_axes[i]
        omega_mu_i = lobe_mu_axes[i]
        dot_ri = sum(v * d for v, d in zip(view_direction, omega_i))
        dot_rl = sum(v * d for v, d in zip(view_direction, omega_lambda_i))
        dot_rm = sum(v * d for v, d in zip(view_direction, omega_mu_i))
        term = a[i] * max(dot_ri, 0.0)
        term *= math.exp(-lambda_coeffs[i] * dot_rl ** 2)
        term *= math.exp(-mu_coeffs[i] * dot_rm ** 2)
        ree_values.append(term)
    return ree_values

def nrff_forward(ray_origin, ray_direction, spatial_mlp, asg_mlp, directional_mlp, num_samples, t_near, t_far, lobe_directions, lobe_lambda_axes, lobe_mu_axes):
    """Renders a single ray using the NRFF architecture."""
    points = sample_points(ray_origin, ray_direction, num_samples, t_near, t_far)
    deltas = [math.dist(points[i], points[i-1]) if i > 0 else 0.0 for i in range(len(points))]
    
    colors = []
    densities = []
    
    for x in points:
        asg_features = spatial_mlp(x)
        a, lambda_coeffs, mu_coeffs = asg_mlp(asg_features)
        
        ree_values = compute_ree(ray_direction, a, lambda_coeffs, mu_coeffs, lobe_directions, lobe_lambda_axes, lobe_mu_axes)
        # Reshape flat 128 values to 8x16x2 as required by the directional MLP
        ree_vector = [ree_values[i*2:(i+1)*2] for i in range(0, len(ree_values), 2)]
        
        c, sigma = directional_mlp(ree_vector, ray_direction)
        colors.append(c)
        densities.append(sigma)
        
    return volume_render(colors, densities, deltas)
```

**Parameters:**
*   $N$: Number of ASG lobes, set to $8 \times 16 = 128$ [S1].
*   $\mathbf{a}$: Bottleneck coefficients vector, length $N$ [S1].
*   $\lambda, \mu$: Scalar coefficients modeling ASG shape, must be $> 0$ [S1].
*   $\beta$: Coefficient for regularization term $L_f$ [S1].
*   $\tau$: Threshold in regularization term [S1].

**Edge Cases:**
*   $\lambda_i, \mu_i$ must be strictly positive to ensure valid Gaussian shapes [S1].
*   Not given in the sources.

## Operating characteristics
*   **Complexity:** Uses Multiscale Tensor Decomposition (MTD) for efficiency in reconstructing scene geometry and appearance compared to standard Positional Encoding [S1].
*   **Performance:** Shows proficiency in encoding view-dependent effects and superior rendering quality on diverse datasets compared to Ref-NeRF [S1].
*   **Strengths:** Explicit modeling of anisotropic reflections; sparse feature representation enhances interpretability and mitigates overfitting [S1].
*   **Limitations:** Requires auxiliary ASG MLP and REE computation, increasing architectural complexity over standard NeRF [S1].

## Background
NRFF was proposed by Albert Barreiro, Roger Marı́, Rafael Redondo, Gloria Haro, Carles Bosch, and David Berga from Eurecat and Universitat Pompeu Fabra [S1]. It was submitted on 2024-07-09, accepted on 2025-01-17, and published in *Image Processing On Line* on 2025-03-12 [S1]. It builds on the Ref-NeRF formulation [S1].
