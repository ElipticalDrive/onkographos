# CCNeRF

Also called: Compressible-Composable NeRF, Rank-residual Decomposition NeRF

## Overview
CCNeRF is a neural field representation that enables efficient compression and composition of 3D scenes by learning a hybrid tensor rank decomposition of the scene without using neural networks for rendering [S1]. Unlike NeRF variants that rely on a shared MLP renderer (e.g., NSVF) or hybrid tensor-MLP approaches (e.g., TensoRF), CCNeRF models the radiance field *only* with tensor rank decomposition, preserving the low-rank approximation properties required for dynamic size adjustment and arbitrary composition [S1].

## How it works
CCNeRF represents a 3D scene as a 4D feature volume described by rank components and a weight matrix. The method allows for dynamic model size adjustment via rank truncation and composition via rank concatenation [S1].

### Inputs and Outputs
*   **Input:** A set of 2D images with known camera poses $(o, d)$ and a target rank configuration (or compression ratio).
*   **Output:** A set of decomposed rank components (vectors or matrices) and a rank weight matrix, which together define the radiance field function $f(\mathbf{x}, \mathbf{d})$.

### Data Structures
The model structure consists of two main parts [S1]:
1.  **Rank Weight Matrix ($W$):** A matrix storing weights for different feature channels. If there are $C$ feature channels and $R$ total ranks, $W \in \mathbb{R}^{C \times R}$.
2.  **Rank Components:** A set of decomposed components. Each component is either:
    *   **Vector-based (CP):** Corresponding to CANDECOMP/PARAFAC decomposition. For a 3D spatial grid, this involves factor matrices $U^x, U^y, U^z$.
    *   **Matrix-based (Triple Plane):** A less compact variant using plane factors.
    The ratio of vector- to matrix-based components is controllable.

### Formulas
The volume rendering equation remains standard [S1]:
$$ \hat{C}(r) = \sum_i T_i \alpha_i c_i $$
where $T_i = \prod_{j<i} (1 - \alpha_i)$, $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, and $\delta_i = t_{i+1} - t_i$. Here $\sigma_i$ is density, $c_i$ is color, and $t_i$ is the sample position along ray $r$ from origin $o$ with direction $d$.

The core representation uses a hybrid tensor rank decomposition. For a 3D tensor $T \in \mathbb{R}^{H \times W \times D}$, the Tucker decomposition is defined as [S1]:
$$ T_{i,j,k} = \sum_{p=1}^P \sum_{q=1}^Q \sum_{r=1}^R S_{p,q,r} U^x_{i,p} U^y_{j,q} U^z_{k,r} $$
where $S$ is the core tensor and $U^x, U^y, U^z$ are factor matrices. CCNeRF extends this to a 4D feature volume (3D space + 1D view direction or feature channel) using a hybrid of CP and Tucker-like structures.

### Parameters
*   **Rank ($R$):** The number of components kept in the decomposition. This determines the model size and detail level. Lower ranks preserve primary information due to rank-residual learning [S1].
*   **Component Type Ratio:** The proportion of vector-based (CP) vs. matrix-based (Triple Plane) components [S1].

### Steps
1.  **Initialization:** Initialize the rank components and weight matrix. The method employs a **rank-residual learning strategy** to encourage lower ranks to preserve more important information of the whole scene [S1].
2.  **Training:** Optimize the rank components and weights to minimize the photometric loss between rendered images and ground truth images. The optimization does not involve an MLP renderer; the field is defined purely by the tensor decomposition [S1].
3.  **Querying a 3D Coordinate:** To evaluate the field at a specific 3D coordinate $\mathbf{x}$:
    1.  Project the coordinate to the decomposed vectors or matrices.
    2.  Perform weighted interpolation using the stored rank weights $W$ [S1].
4.  **Compression (Rank Truncation):** To compress the model:
    1.  Compute the importance of each rank component.
    2.  Use an empirical **sort-and-truncate strategy** to remove the least important ranks. This achieves near-optimal low-rank approximation at any targeted rank without retraining [S1].
5.  **Composition:** To compose different models:
    1.  Concatenate the rank components of different objects along the rank dimension.
    2.  Record a transformation matrix for each object to control its position and orientation in the scene.
    3.  The combined model can be further compressed by compressing less important objects [S1].

### Edge Cases and Pitfalls
*   **Truncation Optimality:** Standard truncated Higher-Order SVD (HOSVD) does not hold the optimal property of truncated SVD, but yields a quasi-optimal solution sufficient for practical use [S1].
*   **MLP Dependency:** Unlike TensoRF, which uses MLPs that prevent compression/composition, CCNeRF must avoid MLPs in the rendering path to preserve low-rank approximation properties [S1].

## Operating characteristics
*   **Compression:** Achieves near-optimal low-rank approximation at any targeted rank without retraining, allowing dynamic trade-off between model size and rendering quality [S1].
*   **Composition:** Supports arbitrary transformation and composition of different models by concatenating rank components. Storage cost growth is mitigated by compressing unimportant objects in the composed scene [S1].
*   **Rendering Speed:** Since it uses no neural networks for rendering, query speed depends on the tensor decomposition evaluation, which is generally faster than MLP-based decoders [S1].
*   **Quality:** Comparable rendering quality to state-of-the-art methods [S1].

## Background
CCNeRF was introduced by Jiaxiang Tang, Xiaokang Chen, Jingbo Wang, and Gang Zeng from Peking University and Chinese University of Hong Kong in 2022 [S1]. It addresses the difficulty of manipulating implicit NeRF representations, such as compression and composition, which are typically restricted by shared renderer networks or suffer from large model sizes [S1]. The method is motivated by the low-rank approximation property of the SVD algorithm [S1].
