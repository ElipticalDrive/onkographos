# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the hyperparameters, architecture modifications, and optimization settings for training a Neural Radiance Field (NeRF) model using depth priors to improve geometry reconstruction [S1]. It builds on [Model Architecture and Encoding](13550-model-architecture-and-encoding.md) by integrating a depth loss term and specific regularization techniques. It is distinguished from sibling methods like [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md) by its explicit focus on geometric consistency via depth supervision rather than semantic or frequency-based constraints.

## How it works
**Inputs:**
*   Training images with corresponding camera poses.
*   Ground truth depth maps (optional but recommended for the depth loss component).
*   Scene-specific parameters: `max_depth` and `min_depth` for uncertainty thresholding [S1].

**Outputs:**
*   Trained NeRF model parameters $\theta$.
*   Rendered images and depth maps.

**Data Structures:**
*   **NeRF Model:** Follows the standard MLP structure from [Model Architecture and Encoding](13550-model-architecture-and-encoding.md).
    *   **Modification:** Dropout layers with probability $p=0.1$ are added after each of the first eight fully connected ReLU-activated layers that encode the positional encoding [S1].
*   **Optimizer State:** Adam optimizer state variables (first and second moment estimates) for all parameters [S1].

**Parameters:**
*   Depth loss weight ($\lambda$): $0.007$ for most scenes; $0.02$ for scene 710 [S1].
*   Uncertainty weight ($\gamma$): $1$ [S1].
*   Initial learning rate ($\eta_0$): $5 \times 10^{-4}$ [S1].
*   Depth scale learning rate ($\eta_{scale}$): $1 \times 10^{-7}$ [S1].
*   Weight decay ($\omega$): $1 \times 10^{-6}$ [S1].
*   Total training steps ($T$): $500,000$ [S1].
*   Learning rate schedule: Reduce to $5 \times 10^{-5}$ after $80\%$ of total steps [S1].
*   Uncertainty threshold ($\tau$): Calculated as $\tau = (\text{max\_depth} - \text{min\_depth}) \cdot 0.0001$ [S1].
    *   Typical values for ScanNet: $\text{max\_depth} = 10$, $\text{min\_depth} = 0.001$ [S1].

**Numbered Steps:**

1.  **Initialization:** Initialize the NeRF model parameters $\theta$ and Adam optimizer state. Set the learning rate to $\eta_0 = 5 \times 10^{-4}$ for general parameters and $\eta_{scale} = 1 \times 10^{-7}$ for the depth scale parameter [S1].
2.  **Sampling:** For each training step, sample a batch of rays. For each ray, sample points $\mathbf{x}_i$ along the ray segment.
3.  **Forward Pass:** Query the NeRF model $F_\theta(\mathbf{x}_i, \mathbf{d})$ to obtain volume density $\sigma_i$ and color $\mathbf{c}_i$ for each sample point [S1].
4.  **Rendering:** Compute the rendered color $\hat{C}(r)$ and depth $\hat{D}(r)$ for each ray using standard volume rendering equations [S1]:
    $$ \hat{C}(r) = \sum_i T_i \alpha_i c_i, \quad T_i = \prod_{j<i} (1 - \alpha_i), \quad \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
    where $\delta_i$ is the distance between samples [S1].
    *Note: The specific formula for depth rendering is not explicitly detailed in the sources, but typically involves weighting samples by $\alpha_i$ and their depth $z_i$.*
5.  **Loss Computation:**
    *   Compute the photometric loss (e.g., MSE) between rendered color $\hat{C}(r)$ and ground truth color $C(r)$ [S1].
    *   Compute the depth loss between rendered depth $\hat{D}(r)$ and ground truth depth $D(r)$ [S1].
    *   Compute the uncertainty-weighted depth loss. The uncertainty threshold $\tau$ is used to evaluate the validity of depth predictions [S1].
    *   Total Loss:
        $$ \mathcal{L} = \mathcal{L}_{color} + \lambda \mathcal{L}_{depth} + \gamma \mathcal{L}_{uncertainty} $$
        where $\lambda$ is the depth loss weight and $\gamma$ is the uncertainty weight [S1].
6.  **Optimization:**
    *   Compute gradients of $\mathcal{L}$ with respect to $\theta$.
    *   Apply Adam optimizer update with weight decay $\omega = 1 \times 10^{-6}$ [S1].
    *   Update learning rate: If current step $t > 0.8 \times T$, set learning rate to $5 \times 10^{-5}$ [S1].
7.  **Iteration:** Repeat steps 2-6 for $T = 500,000$ steps [S1].

## Subtopics

### DS-NeRF Depth Loss Integration
Integrates the depth loss implementation from the official DS-NeRF code base into the training pipeline [S2]. This variant is used when re-training on LLFF train/test splits using released configuration files, as original publication results for LLFF used a different split and DTU results could not be reproduced due to missing config files [S2].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of training steps ($500,000$) and the number of samples per ray [S1].
*   **Memory Complexity:** Proportional to the number of parameters in the NeRF model and the batch size [S1].
*   **Performance:** The configuration is designed to improve geometric accuracy through depth supervision [S1].
*   **Strengths:** Explicit depth guidance improves reconstruction quality, especially in textureless regions [S1].
*   **Limitations:** Requires ground truth depth maps for the depth loss component [S1]. Performance may vary across scenes (e.g., scene 710 requires a different depth loss weight) [S1].
*   **When to use:** When high-quality geometry is required and ground truth depth is available [S1].
*   **When not to use:** When depth information is unavailable or unreliable [S1].

## Background
The Depth-Guided NeRF Training Configuration was introduced in the paper "Depth-Guided NeRF Training via Earth Mover’s Distance" [S1]. It builds upon the original NeRF architecture [S1]. The method was evaluated on datasets such as ScanNet and LLFF [S1, S2].
