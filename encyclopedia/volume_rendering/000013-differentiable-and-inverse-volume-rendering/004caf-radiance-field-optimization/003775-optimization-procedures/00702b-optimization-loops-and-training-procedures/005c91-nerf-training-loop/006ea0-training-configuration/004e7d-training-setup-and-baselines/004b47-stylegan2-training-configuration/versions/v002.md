# StyleGAN2 Training Configuration

Also called: StyleGAN2 Training Setup

## Overview
This configuration adapts the StyleGAN2 architecture for training 3D-aware image synthesis models, specifically leveraging sparse voxel grids for efficient volume rendering [S1]. It differs from standard StyleGAN2 by disabling path regularization and style-mixing, and by applying R1 regularization sparsely to reduce computational cost [S1]. It builds on [Training Setup and Baselines](13740-training-setup-and-baselines.md) by utilizing mixed-precision and equalized learning rates [S1].

## How it works
**Inputs:**
*   Generator network parameters.
*   Discriminator network parameters.
*   Minibatch of latent vectors $z$ and corresponding ground-truth images $I_{gt}$.
*   Pretrained generator weights (optional, for fine-tuning on small datasets) [S1].

**Outputs:**
*   Updated generator and discriminator weights.
*   Exponential Moving Average (EMA) of generator weights [S1].

**Data Structures:**
*   **Generator:** Standard StyleGAN2 generator structure with equalized learning rates [S1].
*   **Discriminator:** Standard StyleGAN2 discriminator structure with a minibatch standard deviation layer appended at the end [S1].

**Steps:**
1.  **Equalized Learning Rates:** Apply equalized learning rates to all trainable parameters in the generator and discriminator [S1]. This ensures stable training dynamics across layers with different scales.
2.  **Minibatch Standard Deviation:** Append a minibatch standard deviation layer to the discriminator. This layer computes the standard deviation of features across the batch dimension and concatenates it as an additional channel, helping the discriminator detect mode collapse [S1].
3.  **Exponential Moving Average (EMA):** Maintain an EMA of the generator weights. Update the EMA weights after each optimizer step using a decay factor (typically close to 1, e.g., 0.9999, though exact value not specified in sources) [S1].
4.  **Mixed Precision:** Perform forward and backward passes for both generator and discriminator using mixed-precision (FP16/FP32) arithmetic to accelerate training and reduce memory usage [S1].
5.  **Disable Path Regularization and Style-Mixing:** Unlike standard StyleGAN2, do not apply path length regularization or style-mixing during training [S1].
6.  **R1 Regularization:** Apply R1 gradient penalty to the discriminator. To reduce computational cost, compute the R1 penalty only once every 4 minibatches [S1].
    *   **R1 Strength:** $\gamma = 1$ for all datasets [S1].
    *   **Frequency:** Every 4 minibatches [S1].
7.  **Fine-tuning (Small Datasets):** For small datasets like AFHQ, initialize the generator by fine-tuning a generator pretrained on FFHQ. Use specific resolution parameters: $R_I = 128$ and $R_G = 32$ before pruning the representation [S1].

**Pitfalls:**
*   **Small Datasets:** Training from scratch on small datasets (e.g., AFHQ) may fail. Use the specified fine-tuning strategy with pretrained FFHQ weights [S1].
*   **Computational Cost:** Applying R1 regularization every minibatch is computationally expensive. The sparse application (every 4 minibatches) is a critical optimization for memory and speed [S1].

## Subtopics

### Conditional Discriminator with Skip Connections for Progressive Growing
A variant of the discriminator used to facilitate progressive growing in StyleGAN2-based models [S1]. It uses conditional input and implements a skip architecture that adds a downsampled version of the input image to the input of each layer, as introduced in StyleGAN2 [S1]. This allows the model to start training at low resolution and gradually increase it [S1].

## Operating characteristics
*   **Time Complexity:** Reduced compared to standard StyleGAN2 due to the absence of path regularization and style-mixing, and the sparse application of R1 regularization (every 4 minibatches) [S1].
*   **Memory Footprint:** Reduced due to mixed-precision training and sparse R1 regularization [S1].
*   **Strengths:** Efficient training for 3D-aware synthesis; stable convergence via equalized learning rates and EMA; effective handling of small datasets via fine-tuning [S1].
*   **Limitations:** Requires careful initialization for small datasets; relies on custom CUDA kernels for efficient volume rendering integration (not part of the core training config but necessary for the full pipeline) [S1].
*   **When to Use:** When training 3D-aware generative models using sparse voxel grids and needing efficient training with GAN stability techniques [S1].
*   **When Not to Use:** When standard 2D image synthesis benefits from path regularization or style-mixing are required [S1].

## Background
This configuration is derived from the official PyTorch implementation of StyleGAN2 [S1]. It was adapted for use in VoxGRAF, a method for fast 3D-aware image synthesis with sparse voxel grids [S1]. The approach builds on the stability techniques of StyleGAN2 (equalized learning rates, minibatch std dev, EMA) while optimizing for the specific computational demands of 3D volume rendering [S1].
