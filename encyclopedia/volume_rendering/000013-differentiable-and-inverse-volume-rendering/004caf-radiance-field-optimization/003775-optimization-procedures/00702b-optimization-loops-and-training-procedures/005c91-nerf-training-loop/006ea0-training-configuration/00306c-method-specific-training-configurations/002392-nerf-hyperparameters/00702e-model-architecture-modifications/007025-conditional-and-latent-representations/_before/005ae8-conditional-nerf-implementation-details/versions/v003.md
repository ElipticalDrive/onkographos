# Conditional NeRF Implementation Details

Also called: Conditional NeRF, Conditional NeRF Architecture, Conditional NeRF Model Specs, Implementation Details

## Overview
Conditional NeRF is a generative model for a specific object category that maps 5D coordinates (spatial position $\mathbf{x}$ and view direction $\mathbf{v}$) along with dedicated latent vectors for shape ($\mathbf{z}_s$) and appearance ($\mathbf{z}_a$) to volumetric density $\sigma$ and view-dependent radiance $\mathbf{c}$ [S1]. It differs from standard NeRF by replacing the single-scene optimization with a category-level generative process controlled by explicit latent codes, and it distinguishes itself from sibling methods like [Conditional Radiance Field Training](15963-conditional-radiance-field-training.md) by enforcing disentanglement: shape conditioning is applied via volumetric deformation of positional encodings, while appearance conditioning is deferred to the radiance prediction network to prevent mutual interference between shape and color [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Spatial position $\mathbf{x} \in \mathbb{R}^3$, view direction $\mathbf{v} \in \mathbb{R}^3$, shape code $\mathbf{z}_s \in \mathbb{R}^{128}$, appearance code $\mathbf{z}_a \in \mathbb{R}^{128}$.
*   **Outputs:** Scalar density $\sigma \in \mathbb{R}$, RGB radiance $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures and Layout:**
The model consists of three main components: the Conditional NeRF MLP, the Deformation Network, and (optionally) Mappers for text-driven manipulation.

1.  **Conditional NeRF MLP:**
    *   **Architecture:** 8-layer Multi-Layer Perceptron (MLP).
    *   **Hidden Units:** 256 per layer.
    *   **Activation:** ReLU for all hidden layers.
    *   **Input Dimension:** 64. This input is formed by concatenating the deformed positional encoding of position and the concatenated view direction with the appearance code.
    *   **Output:** A single scalar for density $\sigma$ and a 3D vector for color $\mathbf{c}$.

2.  **Deformation Network:**
    *   **Purpose:** Maps the shape code $\mathbf{z}_s$ to displacement vectors to deform the positional encoding of $\mathbf{x}$, thereby controlling shape without affecting appearance [S1].
    *   **Architecture:** 4-layer MLP.
    *   **Hidden Units:** 256 per layer.
    *   **Activation:** ReLU.
    *   **Input:** Shape code $\mathbf{z}_s \in \mathbb{R}^{128}$.
    *   **Output:** Displacement vectors $\Delta \mathbf{x} \in \mathbb{R}^{3 \times 2m}$, where $2m$ is the number of frequency bands in the positional encoding.

3.  **Mappers (Optional, for CLIP-NeRF):**
    *   **Purpose:** Feed-forward networks to update initial codes $\mathbf{z}_{s0}, \mathbf{z}_{a0}$ based on a text prompt [S1].
    *   **Architecture:** 2-layer MLPs.
    *   **Channel Sizes:** 128, 256, 128.
    *   **Activation:** ReLU.

**Positional Encoding:**
The sinusoidal positional encoding $\Gamma(\mathbf{p})$ projects each coordinate $p$ of vector $\mathbf{p}$ to a high-dimensional space using frequency bands $k \in \{0, \dots, 2m-1\}$ [S1]:

$$
\gamma(\mathbf{p})_k = \begin{cases} \sin(2^k \pi p), & \text{if } k \text{ is even} \\ \cos(2^k \pi p), & \text{if } k \text{ is odd} \end{cases}
$$

**Algorithm Steps:**

1.  **Encode Position:** Compute the standard positional encoding $\Gamma(\mathbf{x})$ for the spatial position.
2.  **Deform Position (Shape Control):**
    *   Pass the shape code $\mathbf{z}_s$ through the Deformation Network to obtain displacement vectors $\Delta \mathbf{x}$.
    *   Apply these displacements to the frequency bands of $\Gamma(\mathbf{x})$ to produce the deformed positional encoding $\Gamma^*(\mathbf{x}, \mathbf{z}_s)$ [S1].
    *   *Note:* In the standard conditional formulation (Eq. 1 in [S1]), $\Gamma(\mathbf{x})$ and $\mathbf{z}_s$ are concatenated directly. However, the disentangled variant (Eq. 4 in [S1]) uses deformation. The implementation details section specifies the deformation network architecture, implying the disentangled variant is the primary implementation described for shape control.
3.  **Encode View Direction:** Compute $\Gamma(\mathbf{v})$ for the view direction.
4.  **Prepare Radiance Input:** Concatenate $\Gamma(\mathbf{v})$ with the appearance code $\mathbf{z}_a$ [S1]. This is the "Deferred Appearance Conditioning" technique, ensuring appearance manipulation does not affect density/shape [S1].
5.  **Construct MLP Input:** Concatenate the deformed positional encoding $\Gamma^*(\mathbf{x}, \mathbf{z}_s)$ with the view-appearance vector $\Gamma(\mathbf{v}) \oplus \mathbf{z}_a$. The total input dimension is 64.
6.  **Predict Density and Color:** Pass the concatenated vector through the 8-layer Conditional NeRF MLP.
    *   The first output neuron is $\sigma$.
    *   The next three output neurons are $\mathbf{c}$.

**Parameters:**
*   **Optimizer:** Adam.
*   **Training Learning Rate:** $10^{-4}$, decayed by 0.5 every 50,000 steps [S1].
*   **Inversion Learning Rate:** $10^{-3}$, decreasing by 0.75 every 100 steps [S1].
*   **Loss Weights:** $\lambda_r = 0.5$, $\lambda_v = 0.1$, $\lambda_s = \lambda_a = 0.2$ [S1].
*   **Hardware:** NVIDIA V100 GPU [S1].

**Edge Cases and Pitfalls:**
*   **Precision:** The exponential growth in positional encoding frequencies ($2^k$) can lead to numerical instability for large $k$. The paper uses a specific parity-based sin/cos assignment which may require careful handling of floating-point precision [S1].
*   **Disentanglement:** If the deformation network is not properly trained, shape changes may inadvertently affect appearance, violating the disentanglement principle [S1].
*   **Inversion:** Optimizing codes for inversion requires careful learning rate scheduling to avoid divergence [S1].

## Subtopics

### [Disentangled Conditional NeRF](16793-disentangled-conditional-nerf.md)
Disentangled Conditional NeRF is a generative neural radiance field architecture that achieves independent control over object shape and appearance by isolating shape conditioning to explicit volumetric deformation of positional encodings. Unlike standard conditional NeRFs where concatenating latent codes causes mutual intervention (e.g., shape changes altering color), this method prevents such interference by deferring appearance conditioning to the radiance field while applying shape conditioning via a deformation network. It is chosen when independent manipulation of shape and appearance is required without cross-talk. See [Disentangled Conditional NeRF](16793-disentangled-conditional-nerf.md).

### CLIP-Driven Manipulation via Mappers
A feed-forward approach using shape mapper $M_s$ and appearance mapper $M_a$ to update initial shape/appearance codes ($\mathbf{z}_{s0}, \mathbf{z}_{a0}$) based on a text prompt $t$, avoiding per-sample optimization [S1]. The updated codes are calculated as $\mathbf{z}_s = M_s(\hat{E}_t(t)) + \mathbf{z}_{s0}$ and $\mathbf{z}_a = M_a(\hat{E}_t(t)) + \mathbf{z}_{a0}$, where $\hat{E}_t$ is the pre-trained CLIP text encoder [S1]. This allows text-driven manipulation without iterative optimization.

### Deferred Appearance Conditioning
A technique where appearance conditioning is deferred to concatenate the appearance code with the view direction as input to the radiance prediction network, allowing appearance manipulation without affecting shape/density [S1]. This ensures that the density $\sigma$ is predicted solely from the deformed position, while color $\mathbf{c}$ depends on the view and appearance [S1].

## Operating characteristics
*   **Time Complexity:** Training time is comparable to standard NeRF but requires optimization of latent codes for inversion, which can be time-consuming if done per-sample. The feed-forward mapper approach reduces inference time for manipulation [S1].
*   **Memory Complexity:** The model stores the MLP weights and the latent codes. The deformation network adds minimal overhead. The 128-dimensional codes are small compared to the scene representation [S1].
*   **Performance:** Evaluated on the Photoshapes and Carla datasets. The method achieves text-driven manipulation of shape and appearance [S1].
*   **Strengths:** Disentanglement of shape and appearance; text-driven manipulation via CLIP; category-level generation.
*   **Limitations:** Requires a category-level dataset; inversion optimization can be unstable; disentanglement relies on the deformation network's accuracy [S1].
*   **When to use:** When independent control of shape and appearance is needed for a specific object category.
*   **When not to use:** For single-scene reconstruction or when category-level data is unavailable.

## Background
Conditional NeRF was introduced in the paper "CLIP-NeRF: Text-and-Image Driven Manipulation of Neural Radiance Fields" by Can Wang et al., published in CVPR 2022 [S1]. It builds on the original NeRF architecture [24] and extends it to a generative model for object categories. The work addresses the limitations of per-scene optimization and single-scene manipulation by introducing latent codes for shape and appearance, and leveraging CLIP for text-driven control [S1].
