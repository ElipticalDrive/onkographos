# SCARF

Also called: SCARF, Scalable Continel Learning Framework

## Overview
SCARF is a memory-efficient continual learning framework for multiple 3D scenes that factorizes NeRF MLP weights into scene-specific and cross-scene shared components, generating parameters via a hypernetwork [S1]. It solves the problem of catastrophic forgetting and linear parameter growth when training NeRFs on sequential scenes, allowing the model to learn new scenes without retraining the entire network from scratch [S1]. Unlike vanilla NeRF, where parameters grow linearly with the number of scenes $N$, SCARF’s parameter count depends primarily on the number of layers $L$, achieving significant compression rates (e.g., 0.03% for 50 scenes) [S1]. It is orthogonal to single-scene NeRF extensions and can be combined with them [S1].

## How it works
**Inputs and Outputs:**
- **Inputs:** A sequence of 3D scenes $\{S_1, S_2, \dots, S_N\}$. For each scene $S_i$, training data consists of pixel rays and random sampled points.
- **Outputs:** A unified NeRF model capable of rendering any of the $N$ scenes. The model outputs RGB radiance and volume density $\sigma$ for a given 3D position $\mathbf{x}$ and view direction $\mathbf{d}$, conditioned on a scene identifier.

**Data Structures:**
The model consists of an Encoder, a Decoder, and a Parameter Generator.

1.  **Encoder:**
    -   **Input:** 10-degree positional encoding of position $\mathbf{x}$, denoted $\gamma(\mathbf{x})$.
    -   **Layers:** 8 fully-connected (FC) layers, each with 256 channels.
    -   **Activation:** ReLU.
    -   **Skip Connection:** Input $\gamma(\mathbf{x})$ is concatenated with the output of the 5th layer.
    -   **Output:** Volume density $\sigma$ and a 256-dimensional feature vector $\mathbf{h}$.
    -   **Parameters:** Scene-specific. Generated by the Parameter Generator.

2.  **Decoder:**
    -   **Input:** Concatenation of feature vector $\mathbf{h}$ and 4-degree positional encoding of viewing direction $\gamma(\mathbf{d})$.
    -   **Layers:** 2 FC layers. First layer has 128 channels, second has 3 channels (RGB).
    -   **Activation:** ReLU (for the 128-channel layer).
    -   **Output:** RGB radiance $\mathbf{c}$.
    -   **Parameters:** Cross-scene shared.

3.  **Parameter Generator (Hypernetwork):**
    -   **Input:** Scene-specific random noise vector $\mathbf{z}$ (dimension 256) or learnable matrices.
    -   **Process:**
        1.  Pass $\mathbf{z}$ through a generator network $G(\cdot)$ to output a latent feature.
        2.  Resize the latent feature to shape $(256, 21)$.
        3.  Multiply by a learnable coefficient matrix $W_c$.
        4.  Multiply by the cross-scene shared weight matrix $W_{CS}$ (shape $21 \times 256$).
    -   **Output:** Parameters for the Encoder's FC layers.
    -   **Parameters:** The generator network weights are shared. The coefficient matrix $W_c$ and $W_{CS}$ are learnable.

**Numbered Steps:**

1.  **Initialization:** Initialize the cross-scene shared weight matrix $W_{CS}$, the coefficient matrix $W_c$, and the Parameter Generator $G$. Initialize the Decoder parameters.
2.  **Scene-Specific Parameter Generation:** For a new scene $S_i$:
    a. Sample a random noise vector $\mathbf{z}_i$ of dimension 256.
    b. Compute latent feature $\mathbf{f} = G(\mathbf{z}_i)$.
    c. Reshape $\mathbf{f}$ to $(256, 21)$.
    d. Compute intermediate matrix $M = \mathbf{f} \times W_c$.
    e. Compute Encoder layer weights $W_{enc} = M \times W_{CS}$.
    f. Construct the Encoder MLP using $W_{enc}$ and the fixed skip connection logic.
3.  **Training New Scene ($S_i$):**
    a. **Warm-up:** Train the new scene's Encoder parameters for 2000 steps using only the photometric loss $L_C(r)$ for the new scene [S1].
    b. **Joint Training:** Optimize the full model (Encoder parameters for $S_i$, shared Decoder, shared Generator components) using the Adam optimizer.
    c. **Loss Function:** Combine photometric loss for the new scene with Uncertain Surface Distillation (USD) loss for previously learned scenes [S1].
    d. **Batching:** Use a batch size of 4096 pixel rays for the new scene and 1024 pixel rays plus 8192 random sampled points for distillation [S1].
4.  **Rendering:**
    a. For a query $(\mathbf{x}, \mathbf{d})$ for scene $S_i$:
    b. Generate Encoder weights using $\mathbf{z}_i$ as in Step 2.
    c. Forward pass through Encoder to get $\sigma$ and $\mathbf{h}$.
    d. Forward pass through Decoder to get $\mathbf{c}$.
    e. Volume rendering to produce final image.

**Formulas:**

Vanilla NeRF parameter count for $N$ scenes [S1]:
$$
P_{vanilla} = (c_{in} \times (c_{out} + 1) \times L) \times N + P_d \times N
$$
where $c_{in}$ and $c_{out}$ are input/output dimensions per encoder layer, $L$ is encoder layers, $P_d$ is decoder parameters.

SCARF parameter count [S1]:
$$
P_{SCARF} \approx N \times (Z + K \times K) + L \times (Z \times K \times c_{in} + K \times c_{out}) + P_d
$$
where $Z$ is the number of parameters in the random noise vector, $K$ is the latent dimension (21 in implementation), $P_c$ is coefficient matrix parameters (included in $K \times K$), $P_G$ is generator parameters (included in $Z \times K \times c_{in}$), $P_{CSWM}$ is cross-scene shared weight matrix parameters (included in $K \times c_{out}$).

**Parameters with Typical Values:**
-   Positional encoding degree for position: 10 [S1].
-   Positional encoding degree for viewing direction: 4 [S1].
-   Encoder layer dimension: 256 [S1].
-   Decoder layer dimensions: 128, 3 [S1].
-   Parameter generator learning rate: Initial $1 \times 10^{-4}$, decays exponentially to $5 \times 10^{-5}$ [S1].
-   Learnable matrices ($W_c, W_{CS}$) learning rate: Initial $5 \times 10^{-4}$, decays exponentially to $5 \times 10^{-5}$ [S1].
-   Batch size for new scene training: 4096 pixel rays [S1].
-   Batch size for distillation: 1024 pixel rays and 8192 random sampled points [S1].
-   Warm-up steps for new scenes: 2000 steps [S1].
-   USD occupancy grid resolution: $50 \times 50 \times 50$ [S1].
-   Surface distillation threshold $\tau$: 3 [S1].

**Edge Cases and Pitfalls:**
-   **Unbounded Background:** For datasets like TanksAndTemples with unbounded backgrounds, foreground masking is required for ground truth RGB images, following NSVF [S1].
-   **Regularization Weight:** If using EWC-style regularization, the loss weight should be multiplied by a large factor (e.g., 108) to make the regularization loss approximately 10% of the photometric loss [S1].
-   **Precision:** The parameter generation involves matrix multiplications and resizing; ensure numerical stability in the hypernetwork output.

**Pseudocode:**

import torch
import torch.nn as nn
import torch.nn.functional as F

class SCARF:
    def __init__(self, latent_dim=21, noise_dim=256, encoder_dim=256, decoder_dims=[128, 3]):
        """
        Initialize SCARF model components.
        """
        # Cross-scene shared weight matrix (21 x 256)
        self.W_cs = nn.Parameter(torch.randn(latent_dim, encoder_dim))
        
        # Learnable coefficient matrix (latent_dim x latent_dim)
        self.W_coeff = nn.Parameter(torch.eye(latent_dim))
        
        # Parameter Generator (Hypernetwork)
        # Input: noise_dim, Output: latent_dim * latent_dim (to reshape to latent_dim x latent_dim)
        self.generator = nn.Sequential(
            nn.Linear(noise_dim, 512),
            nn.ReLU(),
            nn.Linear(512, latent_dim * latent_dim)
        )
        
        # Decoder (Shared across scenes)
        self.decoder = nn.Sequential(
            nn.Linear(encoder_dim + 10, decoder_dims[0]), # 10 for view dir pos enc
            nn.ReLU(),
            nn.Linear(decoder_dims[0], decoder_dims[1])
        )
        
        # Scene-specific noise vectors (stored per scene)
        self.scene_noises = {}

    def generate_encoder_weights(self, scene_id):
        """
        Generate encoder weights for a specific scene using its noise vector.
        """
        if scene_id not in self.scene_noises:
            # Initialize new scene noise
            self.scene_noises[scene_id] = torch.randn(1, 256)
        
        noise = self.scene_noises[scene_id]
        
        # Generate latent feature
        latent_feature = self.generator(noise) # Shape: (1, latent_dim * latent_dim)
        latent_feature = latent_feature.view(1, 256, 21) # Resize to (1, 256, 21)
        
        # Multiply by coefficient matrix
        # latent_feature: (1, 256, 21), W_coeff: (21, 21)
        # Result: (1, 256, 21)
        coeff_out = torch.bmm(latent_feature, self.W_coeff.unsqueeze(0))
        
        # Multiply by cross-scene shared weight matrix
        # coeff_out: (1, 256, 21), W_cs: (21, 256)
        # Result: (1, 256, 256) -> This represents the weight matrix for one FC layer
        # Note: The paper describes generating parameters for 8 layers. 
        # This simplified generation assumes one weight matrix per layer or a shared structure.
        # For 8 layers, we would typically generate 8 such matrices or use a more complex generator.
        # Based on [S1], the output is a fully-connected layer parameter. 
        # We assume the generator outputs weights for all 8 layers or a single layer structure is replicated.
        # Here we generate one layer's weights as an example.
        layer_weights = torch.bmm(coeff_out, self.W_cs.unsqueeze(0)) # (1, 256, 256)
        
        return layer_weights.squeeze(0) # (256, 256)

    def forward_encoder(self, x_pos, scene_id):
        """
        Forward pass through the generated encoder.
        x_pos: (N, 3) positions
        """
        # Positional encoding (10 degree)
        # Assuming a standard positional encoding function is available
        x_pe = positional_encoding(x_pos, degree=10) # (N, 21)
        
        # Generate weights for the encoder layers
        # In practice, we need weights for 8 layers. 
        # The pseudocode simplifies this to one layer generation for clarity.
        # A full implementation would loop 8 times or generate all at once.
        
        # Layer 1-4
        h = x_pe
        for i in range(4):
            w = self.generate_encoder_weights(scene_id) # Simplified: same weights for demo
            h = F.relu(torch.mm(h, w))
            
        # Layer 5 (Skip connection)
        w = self.generate_encoder_weights(scene_id)
        h = F.relu(torch.mm(h, w))
        h = torch.cat([h, x_pe], dim=-1) # Skip connection
        
        # Layer 6-8
        for i in range(3):
            w = self.generate_encoder_weights(scene_id)
            h = F.relu(torch.mm(h, w))
            
        # Output layer (Density and Feature)
        w = self.generate_encoder_weights(scene_id)
        # Assuming output dim is 257 (256 feature + 1 density)
        # This requires a specific weight matrix shape. 
        # Simplified: return h as feature and a separate density head
        sigma = torch.sigmoid(torch.sum(h, dim=-1, keepdim=True)) # Simplified density
        feature = h
        
        return sigma, feature

    def forward_decoder(self, feature, x_view):
        """
        Forward pass through the shared decoder.
        feature: (N, 256)
        x_view: (N, 3) view directions
        """
        # View direction positional encoding (4 degree)
        d_pe = positional_encoding(x_view, degree=4) # (N, 10)
        
        # Concatenate feature and view direction encoding
        input_dec = torch.cat([feature, d_pe], dim=-1) # (N, 266)
        
        # Decoder forward
        out = self.decoder(input_dec)
        return out

    def render(self, x_pos, x_view, scene_id):
        """
        Render a pixel for a given scene.
        """
        sigma, feature = self.forward_encoder(x_pos, scene_id)
        rgb = self.forward_decoder(feature, x_view)
        return rgb, sigma

## Operating characteristics
-   **Time Complexity:** Training is approximately 1.2x slower than vanilla NeRF due to the Uncertain Surface Distillation (USD) strategy and hypernetwork weight generation [S1]. Rendering speed is equivalent to vanilla NeRF as weights are pre-generated [S1].
-   **Memory Complexity:** Parameter count grows linearly with the number of scenes $N$ in vanilla NeRF, but depends primarily on the number of layers $L$ in SCARF [S1].
-   **Performance:** Achieves 16.4% compression rate for 8 scenes and 0.03% compression rate for 50 scenes compared to vanilla NeRF [S1].
-   **Strengths:** Memory-efficient continual learning, low parameter growth with scene count, orthogonal to other NeRF extensions [S1].
-   **Limitations:** Slower training time, requires careful tuning of distillation and regularization weights [S1].
-   **When to use:** When training NeRFs on a sequence of diverse 3D scenes with limited memory resources.
-   **When not to use:** When real-time training speed is critical or when only a single scene is being modeled.

## Background
SCARF was introduced in the paper "SCARF: Scalable Continual Learning Framework for Memory-efficient Multiple Neural Radiance Fields" [S1]. It addresses the limitations of vanilla NeRF in continual learning scenarios, where parameters grow linearly with the number of scenes, leading to high memory consumption and catastrophic forgetting. SCARF uses a hypernetwork to generate scene-specific weights, allowing for efficient sharing of cross-scene features. It is distinct from other hypernetwork-based NeRF methods like HyP-NeRF, HyperNeRFGAN, and MLP-Maps, which focus on category-level or generative modeling, whereas SCARF focuses on continual learning across different scenes [S1]. It is also distinct from BungeeNeRF, which focuses on multi-scale representation within a single scene [S1].
