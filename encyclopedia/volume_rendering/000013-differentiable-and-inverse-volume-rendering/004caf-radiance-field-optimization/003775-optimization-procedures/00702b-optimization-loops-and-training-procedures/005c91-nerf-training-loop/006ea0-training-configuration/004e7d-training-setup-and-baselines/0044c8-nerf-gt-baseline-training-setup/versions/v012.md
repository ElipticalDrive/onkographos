# NeRF-GT Baseline Training Setup

Also called: NeRF-GT

## Overview
The NeRF-GT baseline establishes a standard training configuration for the original Neural Radiance Fields (NeRF) model, serving as a reference point for comparing novel radiance field optimization methods. It defines specific hyperparameters for sampling, batching, and iteration counts to ensure reproducible convergence on standard test scenes. Unlike variants that optimize for speed or generalization, this setup prioritizes high-fidelity scene fitting using a fixed coarse-to-fine sampling strategy.

## How it works
The method implements the standard NeRF training loop with specific hyperparameter constraints derived from the original implementation's recommended configuration.

**Inputs and Outputs**
- **Input:** A set of calibrated training images with known camera poses and intrinsics.
- **Output:** A trained MLP representing the volumetric scene (density $\sigma$ and view-dependent color $\mathbf{c}$).

**Data Structures**
The implementation uses a coarse-to-fine sampling strategy.
- **Coarse Phase:** 64 samples are drawn along each ray.
- **Fine Phase:** 128 samples are drawn along each ray.
- **Batching:** 2,048 rays are processed per batch.
- **Resolution:** Training is conducted at 800 × 600 pixels.

**Numbered Steps**
1. Initialize the neural network parameters for the NeRF model.
2. For each training iteration:
   a. Randomly select 2,048 rays from the training views.
   b. For each ray, sample 64 points along the segment between the near and far clipping planes (coarse phase).
   c. Render the coarse color and depth by volume rendering the sampled points.
   d. For each ray, sample 128 points, typically stratified around the peaks of the coarse density distribution (fine phase).
   e. Render the fine color and depth.
   f. Compute the loss between the rendered fine color and the ground truth pixel color.
   g. Update the network parameters using gradient descent.
3. Repeat until 200,000 solver steps are completed.

**Parameters**
- **Coarse samples:** 64 [S2, unofficial].
- **Fine samples:** 128 [S2, unofficial].
- **Batch size (rays):** 2,048 [S2, unofficial].
- **Resolution:** 800 × 600 pixels [S2, unofficial].
- **Total iterations:** 200,000 solver steps [S2, unofficial].

**Edge Cases and Pitfalls**
- **Convergence:** The training must run for the full 200,000 steps to converge, as recommended by the original authors [S2, unofficial].
- **Hardware Scaling:** Timing results are extrapolated from averaged measurements of 100 iterations [S2, unofficial].

**Pseudocode**
```python
def train_nerf_gt_baseline(training_images, camera_poses, num_steps=200000):
    # Initialize NeRF MLP
    nerf = initialize_nerf_mlp()
    
    # Hyperparameters from baseline configuration
    coarse_samples = 64
    fine_samples = 128
    batch_size = 2048
    resolution = (800, 600)
    
    optimizer = Adam(nerf.parameters())
    
    for step in range(num_steps):
        # Sample batch of rays
        rays = sample_rays(training_images, camera_poses, batch_size)
        
        # Coarse phase
        z_coarse = stratified_sample(rays, coarse_samples)
        rgb_coarse, depth_coarse, weights_coarse = volume_render(nerf, rays, z_coarse)
        
        # Fine phase
        # Samples are typically drawn from the distribution defined by weights_coarse
        z_fine = stratified_sample_around_peaks(rays, weights_coarse, fine_samples)
        rgb_fine, depth_fine, weights_fine = volume_render(nerf, rays, z_fine)
        
        # Loss computation
        gt_colors = get_ground_truth_colors(rays)
        loss = mse_loss(rgb_fine, gt_colors)
        
        # Optimization step
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
    return nerf
```

## Subtopics

### NeRF Baseline
The NeRF Baseline refers to the standard configuration described above, which serves as the primary reference for evaluating new methods in terms of training time and rendering quality. It is characterized by the specific use of 64 coarse and 128 fine samples, a batch size of 2,048 rays, and a fixed training duration of 200,000 steps at 800×600 resolution [S2, unofficial].

## Operating characteristics
- **Time Complexity:** The training time is approximately 0.40 seconds per iteration [S2, unofficial].
- **Memory Complexity:** Not given in the sources.
- **Measured Performance:** On the tested hardware, the training time is 0.40 sec/iteration, and the rendering time is 32 seconds per frame [S2, unofficial].
- **Scaling:** The timing results were derived by averaging 100 iteration times and extrapolating [S2, unofficial].
- **Strengths:** Provides a consistent, high-fidelity baseline for comparison across different radiance field methods.
- **Limitations:** The fixed iteration count and sampling strategy may not be optimal for all scene types or hardware configurations.

## Background
The NeRF-GT baseline is based on the original Neural Radiance Fields method [S2, unofficial]. The specific hyperparameters (64 coarse samples, 128 fine samples, 2,048 batch size, 200,000 steps) are taken from the configuration recommended by the original authors for scene fitting tasks [S2, unofficial]. The baseline is used to evaluate the performance of newer methods like IBRNet, NLR, and others in terms of training speed and rendering quality [S2, unofficial].
