# Model Architecture and Encoding

Also called: NeRF MLP, Radiance Field Network, Positional Encoding, Triplane Representation, Hybrid Implicit Surface

## Overview
Model Architecture and Encoding defines the neural network structure and input embedding strategies used to map 3D spatial coordinates and viewing directions to volume density and color in Neural Radiance Fields (NeRF). It solves the problem of representing complex, high-frequency 3D scenes with continuous functions that are differentiable for gradient-based optimization. It distinguishes itself from sibling methods like [NeRF Initialization Strategies](8674-nerf-initialization-strategies.md) by focusing on the functional form of the representation (MLP depth, branching, encoding basis) rather than the initialization of weights or poses. Key variants include standard hash-encoded MLPs, triplane-based representations, and hybrid surface/volume architectures.

## How it works

### Inputs and Outputs
*   **Inputs:** 3D spatial coordinates $\mathbf{x} \in \mathbb{R}^3$ and viewing direction $\mathbf{d} \in \mathbb{R}^3$ (normalized). Some variants also accept time $t$, pose parameters, or latent codes.
*   **Outputs:** Volume density $\sigma \in \mathbb{R}$ (or SDF value $s$), and RGB color $\mathbf{c} \in \mathbb{R}^3$. Some architectures output additional fields such as normals, occupancy, or material properties.

### Data Structures and Layouts

#### 1. Standard MLP Architecture (Vanilla NeRF)
*   **Structure:** A single Multi-Layer Perceptron (MLP) with $L$ hidden layers.
*   **Layout:**
    *   Input dimension: $2L_{pos} + 2L_{dir} + 3$ (where $L_{pos}$ and $L_{dir}$ are the number of frequency bands for position and direction encoding).
    *   Hidden layers: $L$ layers of size $H$ (typically 256 or 512) with ReLU activation.
    *   Branching: A skip connection from the input to the $H/2$-th layer. The output of the $H/2$-th layer is concatenated with the viewing direction encoding to predict color.
    *   Density Output: The output of the final layer predicts $\sigma$.
    *   Color Output: A separate branch (or the final layers) predicts $\mathbf{c}$.

#### 2. Hash Encoding (InstantNGP)
*   **Structure:** A multi-resolution hash grid replaces positional encoding.
*   **Layout:**
    *   Grids: $L$ resolutions, from $2^8$ to $2^{19}$ (or similar).
    *   Voxel Size: $2^8$ to $2^{19}$ per axis.
    *   Embedding Dimension: $d$ (typically 2 or 4) per resolution level.
    *   Hash Table: Maps 3D coordinates to indices in a flat array of learnable vectors.
    *   Interpolation: Trilinear interpolation of the 8 corner vectors of the voxel containing the query point.

#### 3. Triplane Representation (EG3D, StyleNeRF)
*   **Structure:** Three 2D feature planes ($T_{xy}, T_{xz}, T_{yz}$) representing the scene.
*   **Layout:**
    *   Tensor Shape: $\mathbb{R}^{3 \times C \times R \times R}$ (e.g., $3 \times 32 \times 256 \times 256$).
    *   Query: Project 3D point $\mathbf{x}$ onto each plane to get 2D coordinates.
    *   Aggregation: Average or sum the features from the three planes.
    *   Decoder: An MLP takes the aggregated feature and viewing direction to predict $\sigma$ and $\mathbf{c}$.

#### 4. Hybrid Implicit Surface (ViiNeuS)
*   **Structure:** Two separate MLPs: $F_\Theta^h$ (Hybrid) and $F_\Theta^c$ (Color).
*   **Layout:**
    *   $F_\Theta^h$: Input $\mathbf{x}$. Outputs density $\sigma$, Signed Distance Function (SDF) value $f(\mathbf{x})$, and a latent vector $\mathbf{h}$.
    *   $F_\Theta^c$: Input $\mathbf{h}$, viewing direction $\mathbf{d}$, and normal $\mathbf{n}$ (gradient of SDF). Outputs color $\mathbf{c}$.

### Numbered Steps

1.  **Coordinate Embedding:**
    *   **Positional Encoding (PE):** Map $\mathbf{x}$ and $\mathbf{d}$ to higher dimensions using sine/cosine functions [S15].
        $$ \gamma(\mathbf{p}) = (\sin(2^0 \pi \mathbf{p}), \cos(2^0 \pi \mathbf{p}), \dots, \sin(2^{L-1} \pi \mathbf{p}), \cos(2^{L-1} \pi \mathbf{p})) $$
    *   **Hash Encoding:** Query multi-resolution grids and interpolate [S1].
    *   **Triplane Projection:** Project $\mathbf{x}$ to 2D coordinates on $xy, xz, yz$ planes and interpolate features [S42, unofficial].

2.  **Feature Aggregation (if applicable):**
    *   For Triplanes, average the features from the three planes.
    *   For Hybrid models, pass $\mathbf{x}$ through $F_\Theta^h$ to get $\mathbf{h}, \sigma, f(\mathbf{x})$.

3.  **MLP Forward Pass:**
    *   Concatenate embedded position and direction (and $\mathbf{h}$ if hybrid).
    *   Pass through hidden layers with skip connections.
    *   Output $\sigma$ and $\mathbf{c}$.

4.  **SDF to Density Conversion (if Hybrid):**
    *   Convert SDF $s$ to opacity $\sigma$ using a Laplacian CDF [S22]:
        $$ \sigma = \begin{cases} \frac{1}{2} \exp(s/\beta) & \text{if } s \le 0 \\ 1 - \frac{1}{2} \exp(-s/\beta) & \text{if } s > 0 \end{cases} $$
    *   Or use a learnable $\beta$ [S35]:
        $$ \sigma(\mathbf{x}) = \begin{cases} \frac{1}{\beta}(1 - \exp(s/\beta)) & \text{if } s < 0 \\ \frac{1}{2\beta}\exp(-s/2\beta) & \text{if } s \ge 0 \end{cases} $$

5.  **Volume Rendering:**
    *   Sample points along ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$.
    *   Compute transmittance $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$.
    *   Render color: $\hat{C}(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i$ [S1].

### Formulas

*   **Standard NeRF Mapping:**
    $$ F_\Theta: (\mathbf{x}, \mathbf{d}) \rightarrow (\sigma, \mathbf{c}) $$
    $$ \sigma = D_\theta(\gamma_{L_1}(\mathbf{x})), \quad \mathbf{c} = C_\theta(\gamma_{L_2}(\mathbf{x}), \gamma_{L_3}(\mathbf{d})) $$
    Where $L_3 \le L_1 \le L_2$ control frequency separation [S23].

*   **Triplane Feature Fusion:**
    $$ \mathbf{f}(\mathbf{x}) = \frac{1}{3} \sum_{k \in \{xy, xz, yz\}} \text{Interpolate}(T_k, \text{Project}(\mathbf{x}, k)) $$

*   **Hybrid Density (ViiNeuS):**
    $$ (\sigma, f(\mathbf{x}), \mathbf{h}) = F_\Theta^h(\text{emb}_x(\mathbf{x})) $$
    $$ \mathbf{c} = F_\Theta^c(\text{emb}_d(\mathbf{d}), \mathbf{h}, -\nabla f(\mathbf{x})) $$

*   **Residual NeRF Mixing:**
    $$ \hat{C}(\mathbf{r}) = \sum_{i=1}^N T_i (1 - \exp(-((1-\beta)\sigma_{bg} + \beta\sigma_{res})_i \delta_i)) (c_{bg} + c_{res})_i $$
    Where $\beta$ is predicted by a Mixnet [S3].

### Parameters with Typical Values

*   **MLP Depth:** 8 layers (Vanilla NeRF), 2-4 layers (InstantNGP/Hash), 9 encoder + 2 decoder (SCARF) [S18].
*   **Hidden Dimension:** 256, 512 (Vanilla), 64 (ViiNeuS) [S1].
*   **Positional Encoding Bands ($L$):** 10 (Vanilla), 15 for position, 4 for direction (NeRF-W) [S45].
*   **Hash Grid Resolutions:** $2^8$ to $2^{19}$ [S1].
*   **Triplane Resolution:** $256 \times 256$ [S44].
*   **Triplane Channels:** 32 [S44].

### Edge Cases and Pitfalls

*   **High-Frequency Loss:** Standard PE may fail to capture high-frequency details if $L$ is too small. Hash encoding mitigates this via multi-resolution [S1].
*   **Mirror Symmetry:** Unposed NeRFs suffer from mirror symmetry ambiguities. Mini-scene partitioning helps resolve this [S2].
*   **Transparent Objects:** Standard NeRF struggles with transparency. Residual NeRF separates background and object density [S3].
*   **SDF Initialization:** SDF-based methods require careful initialization to avoid local minima. Hybrid volumetric-to-surface transition helps [S1].
*   **Domain Mismatch:** LIIF-based super-resolution may produce false predictions on synthetic data due to domain mismatch [S48].

### Pseudocode

```python
def positional_encoding(x, num_bands):
    """
    Standard positional encoding for NeRF.
    x: tensor of shape (..., 3)
    num_bands: int L
    """
    freq_bands = 2.0 ** torch.arange(num_bands, dtype=x.dtype, device=x.device) * math.pi
    # Expand dims to broadcast
    freq_bands = freq_bands.view(1, 1, -1)
    x_expanded = x.unsqueeze(-1) * freq_bands
    pe = torch.cat([torch.sin(x_expanded), torch.cos(x_expanded)], dim=-1)
    return pe.view(x.shape[0], -1)

def hash_encoding(x, hash_table, num_resolutions, embedding_dim):
    """
    Hash encoding for InstantNGP.
    x: tensor of shape (..., 3)
    hash_table: list of tensors, one per resolution
    num_resolutions: int
    embedding_dim: int
    """
    total_embed = torch.zeros(x.shape[0], embedding_dim * num_resolutions, device=x.device)
    for i in range(num_resolutions):
        resolution = 2 ** (8 + i)
        # Normalize x to [0, resolution)
        x_scaled = x * resolution
        # Get voxel indices
        voxel_indices = torch.floor(x_scaled).long() % resolution
        # Get corner indices (8 corners)
        corners = get_corner_indices(voxel_indices)
        # Interpolate features from hash_table[i]
        features = trilinear_interpolate(hash_table[i], corners, x_scaled)
        total_embed[:, i*embedding_dim:(i+1)*embedding_dim] = features
    return total_embed

def triplane_query(triplanes, x):
    """
    Query triplane representation.
    triplanes: tensor of shape (3, C, R, R)
    x: tensor of shape (..., 3)
    """
    # Project to xy, xz, yz
    xy_coords = x[..., [0, 1]] # (..., 2)
    xz_coords = x[..., [0, 2]]
    yz_coords = x[..., [1, 2]]
    
    # Normalize to [-1, 1] if needed, then to [0, R-1]
    # Assuming triplanes are in [-1, 1] space
    xy_coords = (xy_coords + 1) / 2 * (R - 1)
    xz_coords = (xz_coords + 1) / 2 * (R - 1)
    yz_coords = (yz_coords + 1) / 2 * (R - 1)
    
    f_xy = interpolate_2d(triplanes[0], xy_coords)
    f_xz = interpolate_2d(triplanes[1], xz_coords)
    f_yz = interpolate_2d(triplanes[2], yz_coords)
    
    return (f_xy + f_xz + f_yz) / 3.0

def nerf_forward(x, d, model_type='standard'):
    """
    Forward pass for different NeRF architectures.
    """
    if model_type == 'standard':
        pe_x = positional_encoding(x, 10)
        pe_d = positional_encoding(d, 4)
        # Concatenate and pass through MLP
        input_feat = torch.cat([pe_x, pe_d], dim=-1)
        # ... MLP layers ...
        sigma, color = mlp(input_feat)
        return sigma, color
    
    elif model_type == 'hybrid':
        # ViiNeuS style
        emb_x = hash_encoding(x, hash_table, 16, 2) # Example
        sigma, sdf, h = mlp_hybrid(emb_x)
        # Compute normal from sdf
        normal = compute_gradient(sdf, x)
        emb_d = positional_encoding(d, 4)
        color = mlp_color(torch.cat([emb_d, h, normal], dim=-1))
        return sigma, color, sdf
    
    elif model_type == 'triplane':
        tri_feat = triplane_query(triplanes, x)
        pe_d = positional_encoding(d, 4)
        input_feat = torch.cat([tri_feat, pe_d], dim=-1)
        sigma, color = mlp_decoder(input_feat)
        return sigma, color
```

## Subtopics

### [Depth-Guided NeRF Training Configuration](11916-depth-guided-nerf-training-configuration.md)
A training configuration for Neural Radiance Fields (NeRF) that incorporates depth priors to regularize the optimization process, addressing the ambiguity of scale and geometry in sparse-view or uncalibrated settings. It distinguishes itself from standard NeRF training by explicitly integrating a depth loss term and modifying the MLP architecture with dropout to prevent overfitting to noisy depth estimates.

### [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md)
CLIPNeRF training configuration refers to the specific optimization procedures and hyperparameters used to edit or stylize Neural Radiance Fields (NeRFs) using text prompts via the CLIP vision-language model. It solves the problem of applying high-level semantic guidance to 3D scene representations without retraining the entire radiance field from scratch. It differs from standard NeRF training by freezing the underlying density and color fields and optimizing only specific manipulation parameters (such as shape or appearance mappers) or latent codes to minimize a CLIP-based distance metric.

### [Binary Radiance Fields](13622-binary-radiance-fields.md)
Binary Radiance Fields (BiRF) is a storage-efficient radiance field representation that reduces model size by binarizing feature embedding parameters to $\{-1, +1\}$ using a sign function and backpropagating through a straight-through estimator. Unlike post-processing compression methods such as PlenOctrees or Re:NeRF, which require additional optimization steps and are bounded by pre-trained model performance, BiRF performs binarization during training without post-optimization. It employs a 2D-3D hybrid multi-resolution architecture to maintain reconstruction quality while achieving significantly lower storage overhead compared to real-valued floating-point grids.

### [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md)
The Mip-NeRF 360 MLP architecture is a two-branch Multi-Layer Perceptron (MLP) that predicts volume density and view-dependent radiance for differentiable volume rendering. It distinguishes itself from standard NeRF by using **integrated positional encoding** to analytically integrate the positional encoding function over Gaussian intervals, thereby reducing aliasing artifacts from high-frequency scene details. The architecture supports optional extensions for specular shading, roughness prediction, and normal estimation.

### SUDS
SUDS is a 4D radiance field representation designed for large-scale dynamic urban scenes that factorizes the scene into three separate hash table data structures to efficiently encode static, dynamic, and far-field radiance fields [S1]. It distinguishes itself from sibling methods like [Neural Scene Graphs](17706-neural-scene-graphs.md) and [UrbanIR](16200-urbanir.md) by eliminating the need for supervised 3D bounding boxes or panoptic labels, instead relying on unlabeled RGB, sparse LiDAR, and optical flow to learn scene flow and semantic decomposition [S1]. Unlike [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md) which focuses on static environments, SUDS explicitly models temporal dynamics and ego-motion across multiple video inputs [S1].

### CCNeRF
CCNeRF is a neural field representation that enables efficient compression and composition of 3D scenes by learning a hybrid tensor rank decomposition of the scene without using neural networks for rendering [S1]. Unlike NeRF variants that rely on a shared MLP renderer (e.g., NSVF) or hybrid tensor-MLP approaches (e.g., TensoRF), CCNeRF models the radiance field *only* with tensor rank decomposition, preserving low-rank approximation properties to allow dynamic model size adjustment via rank truncation and arbitrary composition via rank concatenation [S1].

### [Rip-NeRF](15532-rip-nerf.md)
Rip-NeRF is a radiance field method that renders high-fidelity anti-aliased images by combining cone casting with an anisotropic 3D Gaussian representation. It distinguishes itself from sibling methods like Zip-NeRF by using Ripmap-Encoded Platonic Solids to enable efficient anisotropic area-sampling, whereas Zip-NeRF relies on a multi-sampling mechanism that is effective but computationally inefficient.

### [UE4-NeRF](15539-ue4-nerf.md)
UE4-NeRF is a neural rendering system designed for the real-time interactive rendering of large-scale 3D scenes, such as industrial parks and farmlands, by integrating Neural Radiance Fields (NeRF) with the Unreal Engine 4 (UE4) rasterization pipeline. Unlike traditional NeRF methods that rely on volumetric ray-marching or grid-based lookups, UE4-NeRF partitions the scene into sub-regions (blocks), represents each block using textured polygonal meshes initialized from regular octahedra, and computes colors via a neural shader within the engine. It sets itself apart from its siblings by enabling real-time frame rates at high resolutions (up to 4K) and supporting scene editing with traditional 3D models, addressing the slow convergence and opacity binarization limitations of Mobile-NeRF and the grid-structure constraints of Block-NeRF.

### [Generative Occupancy Fields (GOF)](15773-generative-occupancy-fields-gof.md)
Generative Occupancy Fields (GOF) is a 3D-aware image synthesis method that combines radiance fields with occupancy representations to learn compact object surfaces without impeding training convergence. It solves the problem of diffused surfaces in prior generative radiance fields (like pi-GAN) and the sparse gradient convergence issues in direct occupancy networks by transitioning from cumulative volume rendering to surface-point rendering. Unlike its siblings that predict volume densities, GOF predicts alpha values interpreted as occupancy, enabling surface-aware synthesis via root-finding.

### [Panoptic Radiance Field](15849-panoptic-radiance-field.md)
Panoptic Lifting learns a panoptic 3D volumetric representation from posed RGB images and machine-generated 2D panoptic segmentation masks, lifting noisy 2D labels into a consistent 3D representation. It differs from siblings like [Panoptic NeRF](13622-panoptic-nerf.md) and [DM-NeRF](13622-dm-nerf.md) by requiring only machine-generated 2D labels rather than manual ground truth or coarse meshes, and it explicitly handles instance consistency via linear assignment and surrogate identifiers.

### [Frequency-Modulated Position Encoding](15897-frequency-modulated-position-encoding.md)
Frequency-Modulated Position Encoding is a positional encoding scheme used in point-based radiance field optimization methods, specifically designed to provide fine-grained basis function support for frequency modulation of spatial coordinates and view directions. It solves the problem of representing high-frequency geometric details in sparse point clouds by narrowing the encoding interval compared to standard NeRF embeddings. It sets itself apart from standard NeRF encoding by using a specific power-of-2 exponent progression ($2^0, 2^{0.5}, \dots, 2^{L-1}$) rather than integer powers, and is distinct from sibling methods like [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md) which uses integrated positional encoding for anti-aliasing, or [CCNeRF](15008-ccnerf.md) which relies on different architectural priors.

### [MoCo-NeRF](16197-moco-nerf.md)
MoCo-NeRF is a framework for free-viewpoint rendering of monocular human videos that models non-rigid body motions as radiance residual fields rather than spatial offsets, using rigid skeletal transformations as a prior. It decomposes the representation into a rigid branch learning a canonical T-pose radiance field and a non-rigid branch optimizing pose-driven radiance residuals, allowing direct supervision from ground-truth pixel colors. Unlike offset-based strategies that suffer from high computational complexity and misaligned learning objectives, MoCo-NeRF reduces prediction range to the radiance space, achieving state-of-the-art performance with significantly less training time.

### UrbanIR
UrbanIR is a method for inverse rendering of large-scale urban scenes from a single monocular video under single illumination, inferring shape, albedo, visibility, and sun/sky illumination to enable relighting and night simulation [S1]. It differs from standard NeRFs by learning intrinsic attributes (albedo, normal) independent of lighting, and from other relightable methods like NeRF-OSR or FEGR by requiring only single-illumination RGB video without LiDAR or multiple cameras [S1].

### [Multi-view Aggregation with Skeletal Features](16433-multi-view-aggregation-with-skeletal-features.md)
This method improves pose refinement and feature representation in articulated neural radiance fields by incorporating multi-view constraints when motion is captured from multiple cameras. It differs from single-view approaches by averaging joint rotation estimates across views without requiring camera calibration, and combines time-augmented skeletal features with pixel-aligned image features via a cross-attention mechanism to produce robust density and color predictions.

### [Adaptive Differentiable Grids for Cryo-ET](17614-adaptive-differentiable-grids-for-cryo-et.md)
Adaptive Differentiable Grids (ADG) is a learning-based representation for cryo-electron tomography (cryo-ET) that reconstructs 3D density fields using an adaptive octree structure where each node stores an optimizable 3D density grid. It solves the challenge of reconstructing high-noise, low-signal-to-noise ratio (SNR) cryo-ET data by combining differentiable image formation with regularization, replacing the fully connected MLPs of traditional neural fields to improve speed and detail preservation. Unlike standard neural fields that either learn noise or oversmooth features, ADG uses trilinear interpolation for faster querying and allows explicit regularization (TV, boundary consistency, non-local constraints) to separate signal from noise.

### [Neural Light Fields with Ray-Space Embedding](17616-neural-light-fields-with-ray-space-embedding.md)
Neural Light Fields with Ray-Space Embedding is a view synthesis method that maps 4D ray parameters directly to integrated radiance, enabling rendering with a single network evaluation per pixel for small-baseline scenes. It distinguishes itself from NeRF by avoiding hundreds of volume rendering evaluations per ray, instead using a ray-space embedding network to re-map input rays into an interpolable latent space, which facilitates the registration of rays observing the same 3D points and the interpolation of unobserved rays.

### [Neural Scene Graphs](17706-neural-scene-graphs.md)
Neural Scene Graphs (NSG) is a method for decomposing dynamic, multi-object scenes into a learned hierarchical scene graph with decoupled object transformations and scene representations, enabling novel view synthesis and rendering of unseen object arrangements. Unlike existing neural rendering methods that encode the entire scene into a single, static network, NSG uses a hierarchical scene-graph model with object-level implicit representations, allowing for the modeling of dynamic scenes with varying object poses and compositions.

### Triplane NeRF with Diffusion Prior
The framework uses a triplane NeRF representation where scene codes are optimized jointly with a diffusion prior to handle sparse-view data and ensure end-to-end coherence [S43]. It uses a v-parameterization from diffusion models and SNR-based weighting for training. The scene code is a tensor of shape $\mathbb{R}^{3 \times 6 \times 128 \times 128}$, and the denoising network is a U-Net with 122M parameters [S43].

### EG3D Triplane Representation
EG3D uses a triplane representation $T \in \mathbb{R}^{256 \times 256 \times 96}$ (3 planes of $32 \times 256 \times 256$) to render feature and RGB images at $128 \times 128$ resolution, which are then super-resolved to $512 \times 512$ using a 2D network [S44]. It achieves 42 fps on an RTX 3090 [S44].

### NeRF-W Hyperparameter Configuration
NeRF-W uses a base MLP of 8 layers with 512 hidden units, and static/transient MLPs of 4 layers with 128 units. It uses 15 positional encoding bands for position and 4 for direction. It samples 512 points per ray per model (1024 total) during training and 2048 during evaluation. Appearance embedding dimension is 48, transient is 16. It uses Adam with batch size 2048, initial LR 0.001, decaying ten-fold every 150,000 iterations for 300,000 iterations [S45].

### Explicit Mesh Reconstruction from Neural Fields
An algorithm to extract an explicit 3D mesh from CodeNeRF. It feeds a $256^3$ voxel grid center coordinates to the CodeNeRF MLP to get density $\sigma$, applies Marching Cubes to find vertices, and casts rays along vertex normals to associate colors [S46].

### Efficient EndoNeRF scene representation
A voxel-grids-based representation that replaces MLPs with explicit density and feature volume grids. It models dynamic scenes by warping a canonical radiance field with a time-dependent deformation field modeled by a 3-layer MLP [S47].

### NeRF-Liif
A baseline method that super-resolves LR images using a pretrained LIIF model. It requires LR-HR pairs for training. On synthetic Blender data, it may produce false predictions due to domain mismatch. On real-world LLFF data, it tends to be oversmooth [S48].

### UniSurf
A method unifying volume rendering and surface rendering. It uses an occupancy field and volume rendering in early stages for optimization without mask supervision, then surface rendering in later stages to extract level-set surfaces, achieving sharp textures without mask supervision [S49, unofficial].

### SGC Optimization Framework
Uses a loss function $L = L_{rgb1} + \gamma_{sh} L_{rgb2} + \gamma_{sm} L_{normalSM} + \gamma_{bi} L_{bilateral}$. It uses Adam optimizer with initial LR $5 \times 10^{-4}$, batch size 1024, and 128 samples per ray. It addresses blurring in standard NeRF by ensuring smoothness in flat areas and sharpness at edges [S50].

### Neural Human Performer
A feed-forward method for synthesizing novel-view videos of humans from sparse multi-view inputs. It uses a parametric 3D body model (SMPL) and transformer-based aggregation of spatio-temporal features. It samples memory frames and constructs time-augmented skeletal features [S51, unofficial].

## Operating characteristics

*   **Time Complexity:** Depends on MLP depth and encoding. Standard NeRF is $O(L \cdot H)$ per sample. Hash encoding is $O(1)$ lookup but requires interpolation. Triplane is $O(1)$ projection and interpolation.
*   **Memory Complexity:** Standard NeRF is $O(L \cdot H^2)$. Hash encoding is $O(\sum 2^{3 \cdot res} \cdot d)$. Triplane is $O(3 \cdot C \cdot R^2)$.
*   **Performance:** InstantNGP (Hash) is significantly faster than vanilla NeRF due to efficient encoding and smaller MLP [S1]. EG3D Triplane achieves real-time rates (42 fps) [S44].
*   **Strengths:** Triplanes and Hash encodings enable high-resolution rendering and real-time performance. Hybrid models (ViiNeuS) provide better surface quality.
*   **Limitations:** Standard NeRF is slow and memory-intensive. Triplanes may struggle with unbounded scenes. Hash encoding requires careful tuning of resolutions.

## Background

*   **Origin:** The original NeRF paper (Mildenhall et al., 2020) introduced the MLP architecture with positional encoding [S15].
*   **Development:** Subsequent works introduced hash encoding (Müller et al., 2022) [S1], triplane representations (Karras et al., 2022) [S44], and hybrid surface/volume methods (Liu et al., 2020, ViiNeuS 2025) [S1, S22].
*   **Usage:** Used in novel view synthesis, 3D reconstruction, and AR/VR applications.
