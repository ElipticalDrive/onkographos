# Forward Warping for Novel View Synthesis

Also called: Canonical Field Forward Warping, Forward Flow

## Overview
Forward Warping for Novel View Synthesis is a method for rendering dynamic scenes by modeling a static "canonical" radiance field and forward-warping this field to target time steps using a learned deformation flow [S1]. It addresses the many-to-one and one-to-many mapping ambiguities inherent in dynamic scenes by employing differentiable forward warping with average splatting and a subsequent inpainting network to fill occluded regions [S1]. Unlike direct time-conditioning methods that map $(\mathbf{x}, \mathbf{d}, t)$ directly, or backward-flow methods that warp from target to canonical space, this approach explicitly constructs the target view by displacing canonical voxels, which provides a clear advantage in handling complex dynamic topologies [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A set of multi-view images $\{I_i\}$ captured at various time steps $t_i$.
*   Camera poses and intrinsics for each input image.
*   A canonical time $t_{can}$ (first frame for D-NeRF, middle frame for HyperNeRF) [S1].

**Outputs:**
*   A rendered RGB image for any arbitrary spatial position $(x, y)$ and time $t$.
*   Learned parameters for the canonical radiance field, deformation flow, and inpainting network.

### Data Structures
The method relies on several voxel grids and neural networks. All voxel grids are 3D structures indexed by spatial coordinates.

1.  **Canonical Radiance Feature Grid ($V_{Rf}$):** Stores radiance features for each voxel. Feature dimension is 12 [S1].
2.  **Canonical Coordinate Grid ($V_{rCan}$):** Stores the 3D spatial coordinates of each voxel center [S1].
3.  **Canonical Density Grid ($V_{\sigma}^{Can}$):** Stores the density $\sigma$ for each voxel in the canonical space [S1].
4.  **Canonical Color Feature Grid ($V_{cf}^{Can}$):** Stores color features. Dimension is 3 or 12 depending on the training stage [S1].
5.  **Canonical Deformation Feature Grid ($V_{Df}^{Can}$):** Stores deformation features. Dimension is 0 for D-NeRF (no extra features) and 12 for HyperNeRF [S1].
6.  **Trajectory Grid ($V_{Tt}$):** Stores Discrete Cosine Transform (DCT) parameters for the trajectory of each voxel. The number of DCT bases is 15 for D-NeRF and 25 for HyperNeRF [S1].
7.  **Deformation Flow Grid ($V_{flow}$):** Stores the deformation flow vector $\mathbf{d}(\mathbf{x}, t)$ mapping a canonical point to its position at time $t$ [S1].
8.  **Warped Radiance Field ($V_{Rt}$):** The radiance field at time $t$ after forward warping from the canonical field [S1].
9.  **Inpainted Radiance Field ($V_{Rt}^{Inp}$):** The radiance field after the inpainting network refines $V_{Rt}$ [S1].
10. **Upsampled Radiance Field ($V_{Rt}^{Up}$):** The final radiance field after upsampling $V_{Rt}^{Inp}$ [S1].

### Neural Networks
Four networks are used:

1.  **Canonical Radiance Network ($F_{\theta_1}$):**
    *   **Input:** Radiance feature from $V_{Rf}$ (dim 12) concatenated with embedded position (dim 33).
    *   **Output:** Density (dim 1) and color feature (dim 3 or 12) [S1].
    *   **Structure:** 3-layer MLP, width 128, ReLU activation [S1].

2.  **Canonical Deformation Network ($F_{\theta_2}$):**
    *   **Input:** Deformation feature from $V_{Df}^{Can}$ (dim 0 or 12) concatenated with embedded position (dim 33).
    *   **Output:** DCT coefficients for trajectory prediction [S1].
    *   **Structure:** 4-layer MLP, width 64 [S1].

3.  **View Dependent Color Network ($F_{\theta_4}$):**
    *   **Input:** Embedded view direction (dim 27) concatenated with color feature (dim 12).
    *   **Output:** RGB color (dim 3) [S1].
    *   **Structure:** 2-layer MLP, width 64 [S1].

4.  **Inpaint Network ($F_{\theta_3}$):**
    *   **Input:** Warped radiance field features.
    *   **Output:** Refined radiance field features.
    *   **Structure:** UNet with 4 encode layers and 3 decode layers, plus an upsample layer. Each encode layer has one max pooling layer and two convolution layers (Instance Norm + Conv + ReLU). Each decode layer has one up-sample interpolation layer and two convolution layers (Instance Norm + Conv + ReLU) [S1].

### Algorithm Steps

#### 1. Canonical Field Initialization
Initialize voxel grids $V_{Rf}, V_{rCan}, V_{\sigma}^{Can}, V_{cf}^{Can}, V_{Df}^{Can}$ within a bounding box. Initialize $V_{Tt}$ with DCT parameters. Initialize networks $F_{\theta_1}, F_{\theta_2}, F_{\theta_4}, F_{\theta_3}$ with random weights [S1].

#### 2. Deformation Flow Prediction
For a target time $t$ and a voxel at canonical position $\mathbf{x}_{can}$:
1.  Query $V_{Df}^{Can}$ at $\mathbf{x}_{can}$ to get deformation feature $\mathbf{f}_{def}$ [S1].
2.  Query $V_{rCan}$ at $\mathbf{x}_{can}$ to get coordinate $\mathbf{x}_{coord}$ [S1].
3.  Compute embedded position $\gamma(\mathbf{x}_{coord})$ (dim 33) [S1].
4.  Pass $\mathbf{f}_{def}$ and $\gamma(\mathbf{x}_{coord})$ through $F_{\theta_2}$ to get DCT coefficients [S1].
5.  Evaluate the trajectory using DCT bases to predict the displacement $\Delta \mathbf{x}$ [S1].
6.  Compute the deformation flow $\mathbf{d}(\mathbf{x}_{can}, t) = \mathbf{x}_{can} + \Delta \mathbf{x}$ [S1].
7.  Store $\mathbf{d}(\mathbf{x}_{can}, t)$ in $V_{flow}$ at $\mathbf{x}_{can}$ [S1].

#### 3. Forward Warping (Average Splatting)
To construct the radiance field at time $t$ ($V_{Rt}$):
1.  Iterate over all voxels in the canonical grid.
2.  For each voxel at $\mathbf{x}_{can}$, retrieve its radiance feature $\mathbf{f}_{rad}$ from $V_{Rf}$ and its predicted position $\mathbf{x}_{new} = \mathbf{d}(\mathbf{x}_{can}, t)$ from $V_{flow}$ [S1].
3.  Splat $\mathbf{f}_{rad}$ to $\mathbf{x}_{new}$ in the target grid $V_{Rt}$ using **average splatting**.
    *   *Note:* Softmax splatting was tested but rejected due to complexity and lack of improvement [S1].
    *   Average splatting accumulates features by summing and dividing by the count of voxels splatting to the same target location [S1].
4.  The result is the warped radiance field $V_{Rt}$ [S1].

#### 4. Inpainting
1.  Pass $V_{Rt}$ through the Inpaint Network $F_{\theta_3}$ to produce $V_{Rt}^{Inp}$ [S1].
2.  Upsample $V_{Rt}^{Inp}$ to produce the final radiance field $V_{Rt}^{Up}$ [S1].

#### 5. Rendering
For a ray $r$ at time $t$:
1.  Sample points $w_k$ along the ray.
2.  Query $V_{Rt}^{Up}$ at $w_k$ to get density $\sigma(w_k)$ and color feature $\mathbf{c}_{feat}(w_k)$ [S1].
3.  Compute color $\mathbf{c}(w_k)$ using $F_{\theta_4}$ with $\mathbf{c}_{feat}(w_k)$ and embedded view direction [S1].
4.  Compute accumulated transmittance $T(w_k)$ and accumulation weight $A_{accum}(k) = T(w_k) \sigma(w_k) \delta_k$ [S1].
5.  Render color $\mathbf{C}(r)$ via volume rendering integral [S1].

### Loss Functions

**Point-wise Color Loss ($\mathcal{L}_{ptc}$):**
Supervises the color of sampled points weighted by their accumulation.
$$
\mathcal{L}_{ptc} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Inp}}(r)) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Up}}(r))
$$
where
$$
\mathcal{L}(\mathbf{C}(r)) = \frac{1}{K} \sum_{k=1}^{K} A_{\text{accum}}(k) \|\mathbf{c}(w_k) - \mathbf{C}_{\text{gt}}(r)\|_2^2
$$
and $A_{\text{accum}}(k) = T(w_k) \sigma(w_k) \delta_k$ [S1].

**Background Entropy Loss ($\mathcal{L}_{bg}$):**
Encourages densities to concentrate on foreground or background.
$$
\mathcal{L}_{bg} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Inp}}(r)) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Up}}(r))
$$
where
$$
\mathcal{L}(\mathbf{A}(r)) = -\frac{1}{K-1} \sum_{k=1}^{K-1} \left[ A_{\text{accum}}(k)\log(A_{\text{accum}}(k)) + (1-A_{\text{accum}}(k))\log(1-A_{\text{accum}}(k)) \right]
$$
[S1].

**Total Loss:**
$$
\mathcal{L} = \mathcal{L}_{photo} + w_1\mathcal{L}_{ptc} + w_2\mathcal{L}_{bg} + w_3\mathcal{L}_{flow} + w_4\mathcal{L}_{vdiff} + w_5\mathcal{L}_{tv}(V_{\sigma}^{Can}) + w_6\mathcal{L}_{tv}(V_{flow}^t) + w_7\mathcal{L}_{tv}(\mathbf{D})
$$
where $\mathcal{L}_{tv}$ denotes Total Variation loss, and $\mathbf{D}$ represents other regularization terms [S1].

### Parameters and Training Strategy

**Coarse Stage:**
*   **Voxel Number:** $6^3$ [S1].
*   **Inpaint Scale:** 1.5 [S1].
*   **Iterations:** 20,000 [S1].
*   **Weights:** $w_1=10^{-1}, w_2=10^{-2}, w_3=10^{-5}, w_4=0, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$ [S1].
*   **Note:** Inpaint network is **not** used in the coarse stage. The purpose is to learn proxy geometry [S1].

**Fine Stage:**
*   **Voxel Number:** $8^3$ for D-NeRF, $7^3$ for HyperNeRF [S1].
*   **Inpaint Scale:** 2.0 [S1].
*   **Iterations:** 100,000 [S1].
*   **Weights:** $w_1=10^{-2}, w_2=10^{-3}, w_3=10^{-5}, w_4=10^{-5}, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$ [S1].
*   **Progressive Training:** Start with 10 images closest to the canonical time step. Add one image with the closest time step every 60 iterations [S1].

**General Settings:**
*   **Learning Rate:** $10^{-1}$ for voxel grids, $10^{-3}$ for networks [S1].
*   **Canonical Time:** First frame for D-NeRF, middle frame for HyperNeRF [S1].
*   **Optimizer:** Adam [S1].

### Edge Cases and Pitfalls
*   **Memory Consumption:** High, especially for real scenes [S1].
*   **Training Speed:** Slow, approximately one day per scene on a GeForce RTX 3090 [S1].
*   **Coarse Stage Necessity:** Removing the coarse stage causes significant performance drops because the voxel grid covers a larger space without proxy geometry filtering [S1].
*   **Inpainting Importance:** Removing the inpaint network significantly reduces performance (e.g., Hell Warrior PSNR drops from 27.71 to 27.15) [S1].
*   **Splatting Choice:** Softmax splatting was found to introduce unnecessary complexity without improving results compared to average splatting [S1].

## Operating characteristics

**Time and Memory Complexity:**
*   **Training Time:** ~1 day per scene on GeForce RTX 3090 [S1].
*   **Model Size:** 260M parameters for D-NeRF, 440M for HyperNeRF [S1].
*   **Rendering Speed:** 7s per image for D-NeRF, 15s per image for HyperNeRF [S1].
*   **Memory:** High memory consumption, particularly for real-world scenes [S1].

**Strengths and Limitations:**
*   **Strengths:** Achieves state-of-the-art performance on public datasets (D-NeRF, HyperNeRF) and new datasets (Lego Complete), especially for canonical frames [S1]. The forward warping design offers a clear advantage over backward flow methods like NDVG [S1].
*   **Limitations:** Slow training speed and high memory usage [S1].

**When to Use:**
*   When high-quality novel view synthesis for dynamic scenes is required, and computational resources (time/GPU memory) are available.
*   When canonical frame accuracy is critical.

**When Not to Use:**
*   When real-time training or low-memory constraints are present.
*   When fast inference is required (rendering is slow compared to static NeRFs).

## Background

**Origin:**
The method was proposed in the paper "Forward Flow for Novel View Synthesis of Dynamic Scenes" [S1]. It builds on the concept of canonical space representations but introduces a forward warping pipeline with average splatting and an inpainting network to handle dynamic topology changes.

**History and Development:**
The method addresses limitations in existing dynamic NeRF approaches, such as D-NeRF and HyperNeRF, which rely on deformation fields but may struggle with occlusions and many-to-one mappings. By forward-warping the canonical field, the method explicitly models the movement of geometry. It was evaluated on D-NeRF, HyperNeRF, and a newly built Lego Complete Dataset [S1].

**Usage:**
Used for novel view synthesis of dynamic scenes, including sports, animals, and articulated objects. It is particularly effective for scenes with significant non-rigid deformation [S1].
