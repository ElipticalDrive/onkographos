# Unified Volumetric Avatar (UVA)

## Overview
Unified Volumetric Avatar (UVA) is a neural representation for dynamic human avatars that enables local and independent editing of both geometry and texture while supporting novel view synthesis and novel pose rendering [S1, unofficial]. It distinguishes itself from UV-mapping-based methods by anchoring structured latent codes to a deformable mesh in canonical space, allowing direct 3D-to-3D manipulation, and from two-stage distillation methods by being end-to-end trainable from scratch [S1, unofficial].

## How it works
**Inputs:**
- Target observation points $x_t$ sampled from camera rays in a specific pose.
- A deformable canonical mesh $M$ with anchor nodes.
- Skeleton pose parameters $\theta_t$ for the target frame.
- Top-K parameter for nearest-neighbor interpolation.

**Outputs:**
- Final color $c(r)$ for each ray $r$.
- Volume density $\sigma$ for volume rendering.

**Data Structures:**
1.  **Deformable Canonical Mesh $M$**: A mesh in canonical space with $N$ anchor nodes. Each node $i$ stores:
    -   Position $p_i$ in canonical space.
    -   Geometry latent code $l_{geo}^i \in \mathbb{R}^{d_{geo}}$.
    -   Appearance latent code $l_{rgb}^i \in \mathbb{R}^{d_{rgb}}$.
    -   UV coordinates $(u_i, v_i)$ associated with the node's position on the mesh surface.
2.  **Neural Deformation Field**: An MLP $\phi_{def}$ that predicts a non-rigid displacement $\Delta$ given a canonical point and pose.
3.  **Geometry/Texture MLPs**: Two separate MLPs, $\phi_{geo}$ and $\phi_{rgb}$ (or a joint MLP as depicted in Figure 2 of [S1, unofficial]), that predict density $\sigma$ and base color $c_0$ given latent codes and a signed height indicator.
4.  **Shading Factor Predictor**: An MLP $\phi_{shade}$ that predicts a pose-dependent shading factor $s$ given pose parameters.

**Numbered Steps:**

1.  **LBS Weight Calculation**: Given a sampled point $x_t$ in the target (observation) space, find its Top-K nearest neighbors on the current posed mesh. Interpolate the Linear Blending Skinning (LBS) weights $w_b$ of these neighbors to determine the skinning weights for $x_t$ [S1, unofficial].
    $$ w_b = \text{InterpolateLBS}(x_t, \text{Top-K Neighbors}) $$

2.  **Canonical Space Transformation**: Transform the target point $x_t$ to the canonical space $x_c$. This is achieved by inverting the LBS transformation using the computed weights $w_b$ and applying a neural deformation field to account for non-rigid motion [S1, unofficial].
    $$ x_c = \text{LBS}^{-1}(x_t, w_b) + \phi_{def}(x_c, \theta_t) $$
    *Note: The exact inversion formula involves solving for the canonical position that maps to $x_t$ under the skinning field. The source indicates a combination of NN motion field inversion and a neural deformation field $\Delta$ [S1, unofficial].*

3.  **Latent Code Interpolation**: For the canonical point $x_c$, find its Top-K nearest neighbors on the canonical mesh $M$. Interpolate the geometry latent codes $l_{geo}$ and appearance latent codes $l_{rgb}$ from these anchor nodes [S1, unofficial].
    $$ l_{geo} = \text{NNInterpolate}(x_c, \{l_{geo}^i\}, K) $$
    $$ l_{rgb} = \text{NNInterpolate}(x_c, \{l_{rgb}^i\}, K) $$

4.  **Signed Height Indicator Calculation**: Compute the local signed height indicator $\tilde{h}$ for $x_c$. This consists of the UV coordinates $(u, v)$ of the nearest mesh node and the point-to-surface distance $\bar{d}$ relative to the anchored mesh [S1, unofficial].
    $$ \tilde{h} = [u, v, \bar{d}] $$
    This indicator resolves spatial ambiguity caused by discrete latent codes [S1, unofficial].

5.  **Density and Base Color Prediction**: Pass the interpolated latent codes and the signed height indicator through an MLP to predict volume density $\sigma$ and base color $c_0$ [S1, unofficial].
    $$ \sigma, c_0 = \text{MLP}([l_{geo}, l_{rgb}, \tilde{h}]) $$

6.  **Shading Modulation**: Predict a pose-dependent shading factor $s$ using the current pose parameters $\theta_t$. Modulate the base color $c_0$ with $s$ to represent surface illumination changes across poses [S1, unofficial].
    $$ s = \phi_{shade}(\theta_t) $$
    $$ c_{modulated} = c_0 \otimes s $$

7.  **Volume Rendering**: Integrate the modulated colors and densities along the target ray $r$ using standard volume rendering integration to produce the final color $c(r)$ [S1, unofficial].
    $$ c(r) = \int_{t_n}^{t_f} T(t) \sigma(t) c_{modulated}(t) dt $$
    where $T(t) = \exp(-\int_{t_n}^t \sigma(s) ds)$.

**Parameters:**
-   **Top-K**: The number of nearest neighbors used for interpolating LBS weights and latent codes. Typical values are not explicitly stated in the notes, but Table 1 in [S1, unofficial] lists configurations for "Local Tex." and "Local Geo." with values like 4, 8, suggesting K is a hyperparameter tuned per component.

**Edge Cases and Pitfalls:**
-   **Spatial Ambiguity**: Using discrete latent codes defined on mesh nodes diffused via nearest-neighbor interpolation leads to spatial query indistinguishability [S1, unofficial]. This is mitigated by the signed height indicator $\tilde{h}$, which provides continuous local context [S1, unofficial].
-   **Boundary Conditions**: The LBS weight interpolation assumes the point $x_t$ is within the influence of the mesh vertices. Points far from the mesh may have undefined weights.

## Operating characteristics
-   **Time Complexity**: Depends on the cost of finding Top-K nearest neighbors (typically $O(N \log N)$ or $O(N)$ with spatial hashing) and the MLP evaluations. Rendering requires ray marching, adding a factor proportional to the number of samples per ray.
-   **Memory Complexity**: Proportional to the number of mesh nodes $N$ times the dimensionality of latent codes ($d_{geo} + d_{rgb}$).
-   **Strengths**: Enables local and independent editing of geometry and texture [S1, unofficial]. End-to-end trainable without manual parameter tuning [S1, unofficial]. Supports novel view and pose synthesis [S1, unofficial].
-   **Limitations**: Performance depends on the quality of the canonical mesh and LBS weights. Spatial ambiguity requires careful handling via the signed height indicator [S1, unofficial].
-   **When to use**: When local editing of dynamic human avatars is required alongside high-quality rendering.
-   **When not to use**: For static objects where simpler methods suffice, or if real-time performance is critical and the overhead of neural deformation and latent interpolation is too high.

## Background
UVA was proposed in the paper "UVA: Towards Unified Volumetric Avatar for View Synthesis, Pose rendering, Geometry and Texture Editing" [S1, unofficial]. It addresses the limitations of previous methods that either relied on pre-defined UV mapping (making local texture editing difficult) or used two-stage distilling methods (requiring manual tuning and suitable only for static objects) [S1, unofficial]. The method builds on the concept of neural radiance fields (NeRF) [26] and dynamic neural fields [33, 27, 28], adapting them for human avatars with explicit mesh-based editing capabilities [S1, unofficial].
