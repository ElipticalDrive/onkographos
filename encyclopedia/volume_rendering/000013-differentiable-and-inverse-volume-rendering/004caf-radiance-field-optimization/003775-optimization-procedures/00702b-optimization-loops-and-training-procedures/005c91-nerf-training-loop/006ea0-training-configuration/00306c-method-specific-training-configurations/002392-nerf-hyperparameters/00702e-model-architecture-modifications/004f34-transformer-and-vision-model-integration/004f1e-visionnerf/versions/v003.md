# VisionNeRF

Also called: Vision Transformer for NeRF

## Overview
VisionNeRF is a novel view synthesis method that infers a 3D representation from a single unposed input image by combining global features learned from a Vision Transformer (ViT) and local appearance features extracted from a 2D CNN, rendered via a NeRF-based MLP [S1]. Unlike sibling methods such as [ViT-NeRF](13878-vit-nerf.md) or [TransNeRF](13907-transnerf.md) which may rely on posed inputs or different architectural priors, VisionNeRF specifically addresses the challenge of self-occlusion in single-image scenarios by using self-attention to retrieve relevant features from distant parts of the source view for occluded regions, rather than querying features along the ray corresponding to the visible surface [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A single unposed image $I_s$ at camera $s$. No camera pose information is required [S1].
*   **Output:** A rendered novel view image for a target camera pose (which must be provided during inference, though not during training) [S1].

**Data Structures:**
1.  **Feature Tokens:** A sequence of vectors derived from the input image, representing global semantic information.
2.  **Multi-level Feature Maps:** A set of 2D feature maps at different resolutions (coarse-to-fine) derived from the unflattened and resampled tokens.
3.  **Local Feature Maps:** 2D feature maps extracted directly from the input image using a CNN, capturing high-frequency details and local appearance.
4.  **NeRF MLP:** A multi-layer perceptron that takes 3D coordinates and concatenated features as input and outputs volume density and color [S1].

**Numbered Steps:**

1.  **Global Feature Extraction:** Lift the input 2D image $I_s$ into feature tokens. Apply a Vision Transformer (ViT) to these tokens to learn global information and long-range dependencies [S1].
2.  **Feature Resampling:** Unflatten the ViT feature tokens and resample them into multi-level feature maps. This process captures global information in a coarse-to-fine manner, allowing the network to access global context at different spatial resolutions [S1].
3.  **Local Feature Extraction:** Extract local features from the input image $I_s$ using a 2D convolutional neural network (CNN). These features capture fine-grained details and local appearance information [S1].
4.  **NeRF Conditioning and Rendering:** For a target viewpoint, sample points along rays. For each 3D point query, aggregate the global features (from the multi-level maps) and local features (from the CNN maps) conditioned on the 3D location. Train a multi-layer perceptron (MLP) network conditioned on this learned 3D representation (global ViT features + local CNN features) to predict volume density and color, performing volume rendering to synthesize the novel view [S1].

**Coordinate System:**
The method operates in a viewer-centered coordinate system. It does not enforce constraints like symmetry or canonical coordinate systems, relying instead on the learned 3D representation to handle geometry [S1].

**Pitfalls and Edge Cases:**
*   **Self-occlusion:** In standard image-conditioned models (e.g., PixelNeRF), when a target view pixel is invisible from the input view, the model incorrectly uses features from other visible surfaces (e.g., using window features to render a wheel) [S1]. VisionNeRF mitigates this by using self-attention to find long-range dependencies, allowing it to retrieve relevant features from distant parts of the source view for occluded regions [S1].
*   **Unposed Input:** The method requires no camera pose information for the input image, which simplifies data collection but requires the model to implicitly learn the 3D structure from a single view [S1].

**Pseudocode:**

```python
def vision_nerf_render(input_image, target_cameras, vit_model, cnn_model, nerf_mlp):
    """
    Renders novel views from a single unposed image using VisionNeRF.
    
    Args:
        input_image: Tensor of shape (H, W, 3), the single input image.
        target_cameras: List of camera poses (extrinsics and intrinsics) for the target views.
        vit_model: Pre-trained Vision Transformer model.
        cnn_model: Pre-trained 2D CNN model for local features.
        nerf_mlp: Trained MLP for volume rendering.
        
    Returns:
        List of rendered images for each target camera.
    """
    # Step 1: Global Feature Extraction
    # Lift image to tokens and apply ViT
    # Note: Exact tokenization (patch size, embedding dim) depends on ViT implementation
    tokens = vit_model.encode(input_image)
    
    # Step 2: Feature Resampling
    # Unflatten tokens and resample into multi-level feature maps
    # This creates a hierarchy of global features (e.g., levels 1, 2, 3)
    global_feature_maps = vit_model.resample_tokens_to_maps(tokens)
    
    # Step 3: Local Feature Extraction
    # Extract local features using CNN
    local_feature_maps = cnn_model.extract_features(input_image)
    
    rendered_images = []
    
    for camera in target_cameras:
        # Step 4: NeRF Conditioning and Rendering
        # Sample points along rays for the target camera
        points_3d, ray_directions = sample_rays(camera)
        
        # For each point, query features from global and local maps
        # This involves projecting 3D points to 2D feature map coordinates
        # and interpolating features at those coordinates
        
        global_features = query_feature_maps(points_3d, global_feature_maps)
        local_features = query_feature_maps(points_3d, local_feature_maps)
        
        # Concatenate features and 3D coordinates
        # The exact concatenation strategy (e.g., concatenating along channel dim)
        # is defined by the MLP input layer
        combined_input = concatenate(global_features, local_features, points_3d)
        
        # Pass through MLP to get density and color
        density, color = nerf_mlp(combined_input)
        
        # Perform volume rendering
        # Standard NeRF volume rendering formula
        image = volume_render(density, color, ray_directions)
        
        rendered_images.append(image)
        
    return rendered_images
```

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** On the ShapeNet dataset, VisionNeRF achieves LPIPS: 0.09 and PSNR: 21.03 for novel views [S1]. This compares to PixelNeRF's LPIPS: 0.20 and PSNR: 21.85 [S1].
*   **Strengths:**
    *   Handles self-occlusion better than standard image-conditioned models by using self-attention to retrieve relevant features from distant parts of the source view [S1].
    *   Renders richer details and more accurate structure in unseen regions without enforcing symmetry or canonical coordinate systems [S1].
    *   Generalizes across multiple object categories using a single model [S1].
*   **Limitations:**
    *   Performance in PSNR is slightly lower than PixelNeRF (21.03 vs 21.85), though perceptual quality (LPIPS) is significantly better (0.09 vs 0.20) [S1].
    *   Relies on a single unposed image, which may limit the amount of 3D information available compared to multi-view methods.
*   **When to use:** When only a single unposed image is available and high perceptual quality in occluded regions is required.
*   **When not to use:** When camera poses are known and multi-view inputs are available, as other methods may leverage this additional information for higher accuracy.

## Background
VisionNeRF was proposed by Wei-Sheng Lai, Ravi Ramamoorthi, and Tsung-Yi Lin, with work done while interning at Google and at Google respectively [S1]. The method was presented at the IEEE Winter Conference on Applications of Computer Vision (WACV) in 2023 [S1]. It addresses the problem of novel view synthesis from a single unposed image, building on the Neural Radiance Fields (NeRF) framework [S1]. The authors hypothesize that self-occlusion causes incorrectly conditioned features in existing image-conditioned models and propose using ViT and CNN to form a more expressive 3D representation [S1]. The method was trained and evaluated on the ShapeNet dataset, including 13 object categories, as well as real-world images [S1].
