# Gaussian and Primitive-Based Representations

Also called: Differentiable Primitive Assembly, Viewing Direction Gaussian Splatting, Point-NeRF, Frequency-Modulated Point Cloud Rendering, AFNet, GARF

## Overview
Gaussian and Primitive-Based Representations replace the global implicit neural field of standard NeRF with explicit geometric primitives (Gaussians, quadrics, or points) to improve rendering efficiency and geometric fidelity. This family solves the limitations of MLP-based density estimation, such as spectral bias and slow convergence, by leveraging differentiable rasterization or local feature aggregation. Unlike standard NeRF, which queries a continuous function for every sample point, these methods project or aggregate discrete 3D elements, allowing for real-time rendering speeds and explicit scene editing capabilities.

## Shared principles
All methods in this family represent the scene using a discrete set of 3D elements $\mathcal{E} = \{e_i\}_{i=1}^N$ rather than a single global neural network mapping coordinates to density/color.

1.  **Explicit Representation:** The scene geometry and appearance are encoded in learnable parameters of the primitives (e.g., position, covariance, color, opacity, or local feature vectors).
2.  **Differentiable Rendering:** Rendering is performed via differentiable rasterization (for Gaussians/Points) or differentiable volume integration (for Primitives), allowing gradients to flow from the image space loss back to the primitive parameters.
3.  **Local vs. Global:** Unlike global implicit fields, these methods often rely on local queries (neighborhoods for points) or spatial sorting (depth sorting for Gaussians) to compute pixel contributions.

## Subtopics

### [Differentiable Primitive Assembly](13657-differentiable-primitive-assembly.md)
Differentiable Primitive Assembly (DPA) models 3D shapes as an assembly of convex quadric primitives, combining them via differentiable soft boolean operations to produce an occupancy field. It solves the problem of 3D shape abstraction from sparse or single views by optimizing primitive parameters and selection matrices end-to-end using only image-space photometric and mask losses, without requiring 3D ground truth supervision. Unlike Gaussian Splatting which rasterizes explicit ellipsoids, DPA evaluates implicit signed distance functions (SDFs) for quadrics and aggregates them via min/max pooling logic, allowing for the representation of complex topologies including holes and thin structures.

### [Viewing Direction Gaussian Splatting](14273-viewing-direction-gaussian-splatting.md)
Viewing Direction Gaussian Splatting (VDGS) is a hybrid neural rendering method that combines the geometric efficiency of 3D Gaussian Splatting with the view-dependent appearance modeling of Neural Radiance Fields (NeRF). While standard Gaussian Splatting uses static per-Gaussian color and opacity, VDGS employs a neural network to modulate opacity (and optionally color) based on the viewing direction, enabling accurate rendering of specular reflections, transparency, and glass without the computational overhead of full NeRF integration. It solves the limitation of classical Gaussians in handling view-dependent artifacts by conditioning the radiance field on the camera position relative to the Gaussian center.

### [Point-NeRF Representation](15538-point-nerf-representation.md)
Point-NeRF replaces the global implicit function of NeRF with a discrete neural point cloud to model a continuous volumetric radiance field, avoiding ray sampling in empty space by leveraging classical point clouds that approximate scene geometry. It differs from Gaussian Splatting by using inverse-distance weighted aggregation of local feature vectors rather than projecting 2D Gaussians, and from Differentiable Primitive Assembly by regressing radiance from point neighborhoods rather than evaluating implicit signed distance functions.

### [Frequency-Modulated Point Cloud Rendering](15903-frequency-modulated-point-cloud-rendering.md)
Frequency-Modulated Point Cloud Rendering (also known as AFNet) is a real-time rendering pipeline that represents a scene as a discrete point cloud and reconstructs high-fidelity radiance fields using an Adaptive Frequency Net (AFNet). It solves the problem of spectral bias in standard implicit neural representations, where Multi-Layer Perceptrons (MLPs) with ReLU activations fail to reconstruct high-frequency textures, by injecting locally predicted frequency and phase parameters into the activation layers. Unlike its siblings, it achieves real-time performance (39.27 FPS on NeRF-Synthetic) and supports direct object-level editing and scene composition by operating on explicit point geometry rather than a global implicit field.

#### GARF
GARF uses Gaussian activations as an alternative to positional encoding in NeRF, combined with bundle adjustment for pose estimation from unknown camera poses [S1]. It uses Gaussian activations as an effective alternative to positional encoding and performs bundle adjustment for pose estimation [S1]. GARF successfully recovers scene representations from unknown camera poses in challenging scenes with low-textured regions [S1].

## Background
The shift from implicit neural fields to explicit primitives began with the need for real-time rendering and better geometric control. Gaussian Splatting introduced differentiable rasterization of 3D Gaussians for fast rendering [S1]. Subsequent works like VDGS and Point-NeRF hybridized these explicit representations with neural networks to handle view-dependency and local features. DPA extended primitive-based modeling to convex quadrics for shape abstraction [S1]. AFNet addressed the spectral bias of MLPs in point-based rendering [S1]. GARF explored Gaussian activations for pose estimation [S1].
