# NeRF Analogies

Also called: Example-Based Visual Attribute Transfer, NeRF Analogies: Example-Based Visual Attribute Transfer

## Overview
NeRF Analogies is a method for transferring visual attributes (appearance) from a source NeRF to a target NeRF by establishing dense semantic correspondences using Vision Transformer (ViT) features [S1]. It solves the problem of appearance editing in 3D by creating a "NeRF analogy" where the target object adopts the texture and material properties of the source object based on semantic similarity rather than geometric proximity [S1]. It is distinguished from sibling methods like [ViT-NeRF](13878-vit-nerf.md) and [VisionNeRF](13885-visionnerf.md) by its explicit use of cross-scene semantic matching to drive a differentiable loss function, rather than using vision features solely for conditioning a single-scene reconstruction [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A source NeRF (representing the appearance to transfer) and a target NeRF (representing the geometry to retain). Both are typically initialized from sparse or single-view inputs.
*   **Outputs:** A target NeRF with the appearance of the source NeRF applied to its geometry.

**Data Structures:**
*   **Source NeRF:** Standard MLP-based radiance field.
*   **Target NeRF:** Standard MLP-based radiance field.
*   **Feature Maps:** Dense semantic feature maps extracted from the source image using a ViT backbone. For 400p images, these have a resolution of $392 \times 392$ with 384 features per pixel [S1].

**Method Steps:**

1.  **Feature Extraction:**
    *   Extract features from the source image using DiNO-ViT with a ViT-8B backbone [S1].
    *   Use a patch size of 8 and a stride of 4 pixels to create overlapping patches [S1].
    *   Increase spatial resolution by querying the ViT on four subsequent translations of the image (one pixel in $-x$ and $-y$ directions) [S1].
    *   Use the output of the deepest (11th) attention layer, specifically the **key-component** of the attention maps, as the semantic feature vector $\mathbf{f}$ [S1].

2.  **Radiance Field Prediction:**
    *   For a 3D point $\mathbf{x}$ sampled along a ray in the target scene, compute the corresponding 2D location $\pi(\mathbf{x})$ on the source image plane [G].
    *   Interpolate the feature vector $\mathbf{f}$ from the source feature maps at $\pi(\mathbf{x})$ [G].
    *   Predict density $\sigma$ and color $\mathbf{c}$ using the target NeRF MLP:
        $$ (\sigma, \mathbf{c}) = \text{MLP}(\gamma(\mathbf{x}), \mathbf{d}, \mathbf{f}) $$
        where $\gamma(\mathbf{x})$ is the positional encoding of $\mathbf{x}$ and $\mathbf{d}$ is the viewing direction [G]. The MLP architecture consists of 8 layers of 256 neurons, followed by a single layer of 128 neurons, and an output layer activated by a Sigmoid function [S1].

3.  **Loss Computation:**
    *   Compute the color loss $\mathcal{L}_c$ between the rendered color and the ground truth (or source appearance) [S1].
    *   Compute the Difference-of-Gaussians (DoG) loss $\mathcal{L}_G$ to enforce edge consistency and reduce noisy correspondences [S1].
    *   Total loss:
        $$ \mathcal{L} = \mathcal{L}_c + \lambda \, \mathcal{L}_G $$
        where $\lambda$ is a weighting factor [S1].

4.  **Optimization:**
    *   Optimize the target NeRF parameters using the Adam optimizer [S1].
    *   Set $\lambda = 0$ for the first 20,000 iterations [S1].
    *   Gradually increase $\lambda$ up to 50 over the remaining iterations [S1].
    *   Train for a total of 60,000 iterations [S1].

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $1 \times 10^{-4}$ [S1].
*   **Batch Size:** 512 [S1].
*   **DoG Weight ($\lambda$):** Starts at 0, fades in to 50 [S1].
*   **Training Iterations:** 60,000 [S1].

**Edge Cases and Pitfalls:**
*   **Noisy Correspondences:** DiNO features may produce noisy correspondences where points on the target mesh map to different points in the source NeRF. This is mitigated by using L1 loss for sparsity and the DoG loss [S1].
*   **Feature Granularity:** Using coarser features (e.g., DiNO-v2) reduces correspondence quality [S1].
*   **Semantic vs. Geometric:** The method relies on semantic similarity, not geometric similarity. Transferring appearance to semantically unrelated but similarly shaped objects (e.g., avocado to armchair) yields plausible but imperfect results [S1].

## Operating characteristics
*   **Time Complexity:** Training takes less than two hours on a single GPU, including feature extraction [S1].
*   **Memory Complexity:** High-resolution feature maps (e.g., $392 \times 392 \times 384$ for 400p images) require significant memory for storage and interpolation [S1].
*   **Performance:** Evaluated on real-world scenes using NeRFStudio Instant-NGP and synthetic object pairs [S1].
*   **Strengths:** Enables appearance transfer between different objects/scenes; leverages semantic priors for robust correspondence [S1].
*   **Limitations:** Computationally expensive feature extraction compared to lightweight descriptors (though less so than diffusion features); performance degrades if semantic correspondence is weak [S1].
*   **When to use:** When the goal is to transfer appearance/texture from one object to another based on semantic similarity.
*   **When not to use:** When real-time inference is required (feature extraction is slow) or when geometric correspondence is more important than semantic appearance.

## Background
*   **Origin:** Proposed by Michael Fischer, Zhengqin Li, Thu Nguyen-Phuoc, Aljaž Božič, Zhao Dong, Carl Marshall, and Tobias Ritschel from University College London and Meta Reality Labs [S1].
*   **History:** Published in CVPR 2024 [S1]. The method builds on the use of Vision Transformers (ViT) for dense feature extraction and differentiable rendering [S1].
*   **Usage:** Evaluated using NeRFStudio Instant-NGP for real-world scenes and 2D methods lifted to 3D [S1].
