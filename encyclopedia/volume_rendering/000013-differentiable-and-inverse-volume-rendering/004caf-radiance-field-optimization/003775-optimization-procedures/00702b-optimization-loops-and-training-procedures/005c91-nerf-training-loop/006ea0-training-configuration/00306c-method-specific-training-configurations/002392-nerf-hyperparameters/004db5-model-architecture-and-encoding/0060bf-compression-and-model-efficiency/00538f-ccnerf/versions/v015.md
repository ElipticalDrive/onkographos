# CCNeRF
Also called: Rank-residual Decomposition NeRF

## Overview
CCNeRF is a neural field representation that enables efficient compression and composition of 3D scenes by learning a hybrid tensor rank decomposition of the scene without using neural networks for rendering [S1]. Unlike NeRF variants that rely on a shared MLP renderer (e.g., NSVF) or hybrid tensor-MLP approaches (e.g., TensoRF), CCNeRF models the radiance field *only* with tensor rank decomposition, preserving low-rank approximation properties to allow dynamic model size adjustment via rank truncation and arbitrary composition via rank concatenation [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D coordinates $\mathbf{x} = (x, y, z)$ and viewing direction $\mathbf{d} = (\theta, \phi)$.
*   **Output:** Volume density $\sigma \in \mathbb{R}_{\ge 0}$ and RGB color $\mathbf{c} \in [0, 1]^3$.

**Data Structures:**
The model consists of two main components [S1]:
1.  **Rank Weights Matrix ($W$):** A matrix storing weights for different feature channels. It maps the aggregated rank components to the final output dimensions (density and color).
2.  **Rank Components:** A set of decomposed vectors or matrices representing the scene. These are either:
    *   **Vector-based (CP):** Corresponding to CANDECOMP/PARAFAC decomposition.
    *   **Matrix-based (Triple Plane):** Corresponding to a less compact triple plane variant.
    The ratio of vector- to matrix-based components is controllable.

**Formulas:**
The volume rendering equation follows the standard differentiable volume rendering formulation [S1]:
$$ \hat{C}(r) = \sum_i T_i \alpha_i c_i $$
where $T_i = \prod_{j<i} (1 - \alpha_i)$, $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, and $\delta_i = t_{i+1} - t_i$. Here $\sigma_i$ is density, $c_i$ is color, and $t_i$ is the sample position along ray $r$ from origin $o$ with direction $d$.

The underlying tensor decomposition is based on Tucker decomposition. For a 3D tensor $T \in \mathbb{R}^{H \times W \times D}$, the decomposition is defined as [S1]:
$$ T_{i,j,k} = \sum_{p=1}^P \sum_{q=1}^Q \sum_{r=1}^R S_{p,q,r} U^x_{i,p} U^y_{j,q} U^z_{k,r} $$
where $S$ is the core tensor and $U^x, U^y, U^z$ are factor matrices. CCNeRF uses a hybrid approach combining CP and Tucker-like structures.

**Parameters:**
*   **Rank ($R$):** The number of components kept in the decomposition. This determines the model size and detail level. Lower ranks preserve primary information due to rank-residual learning [S1].
*   **Component Type Ratio:** The proportion of vector-based (CP) vs. matrix-based (Triple Plane) components.

**Steps:**
1.  **Querying a 3D Coordinate:**
    a. Project the 3D coordinate $\mathbf{x}$ to the decomposed vectors or matrices [S1].
    b. Perform weighted interpolation using the stored rank weights $W$ and the projected components to compute the aggregated feature representation [S1].
    c. Map the aggregated features to $\sigma$ and $\mathbf{c}$ using the rank weights matrix $W$ [S1].
2.  **Composition:**
    a. To compose different models, concatenate their rank components along the rank dimension [S1].
    b. Record a transformation matrix for each object to control its position and orientation in the scene [S1].
3.  **Compression (Rank Truncation):**
    a. Use an empirical sort-and-truncate strategy to achieve near-optimal low-rank approximation at any targeted rank [S1].
    b. This allows dynamic trade-off between model size and rendering quality without retraining [S1].

**Pitfalls:**
*   Standard truncated Higher-Order SVD (HOSVD) does not hold the optimal property of truncated SVD, but yields a quasi-optimal solution sufficient for practical use [S1].
*   Using MLPs in the decomposition (as in TensoRF) disturbs the property of tensor rank decomposition and prevents achieving compression or composition [S1].

## Operating characteristics
*   **Compression:** Achieves near-optimal compression without extra optimization by leveraging rank-residual learning [S1].
*   **Composition:** Supports arbitrary transformation and composition of different models without retraining or compatibility constraints [S1].
*   **Storage:** Model size is dynamically adjustable via rank truncation [S1].
*   **Rendering:** Does not use neural networks for rendering, which reduces computational overhead during inference compared to MLP-based decoders [S1].

## Background
CCNeRF was introduced by Jiaxiang Tang, Xiaokang Chen, Jingbo Wang, and Gang Zeng from Peking University and Chinese University of Hong Kong [S1]. It addresses the difficulty of manipulating implicit NeRF representations, such as compression and composition, which are typically restricted by shared renderer networks or suffer from large model sizes [S1]. The method builds on the low-rank approximation property of the SVD algorithm and introduces a rank-residual learning strategy to encourage the preservation of primary information in lower ranks [S1].
