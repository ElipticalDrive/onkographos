# Neural Deformable Anchor (NeuDA)


## Overview
NeuDA is a neural implicit representation for high-fidelity surface reconstruction that replaces learnable feature vectors at voxel vertices with optimized 3D positions (anchors) to adaptively encode local geometry [S1]. It solves the limitation of standard voxel grids, where uniformly distributed features fail to capture small structures with complicated topologies, by allowing anchors to move from grid corners to the vicinity of abrupt geometry-changing areas [S1]. Unlike Instant-NGP, which uses multi-resolution hash encoding and may suffer from hash collisions, NeuDA uses hierarchical voxel grids with deformable anchors to better exploit spatial context [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of multi-view images with known camera poses; a hierarchical voxel grid structure $G$.
*   **Output:** A rendered color image $\hat{C}$ for a given view, and an implicit surface defined by the zero-level set of the SDF.

**Data Structures:**
*   **Hierarchical Anchor Grid ($G$):** A set of levels. At each level $l$, the grid consists of vertices. Each vertex $v$ stores a deformable anchor defined by a base position $p_v$ and an offset $\Delta p_v$. The initial state is uniform distribution at voxel vertices.
*   **SDF Network ($F$):** A 4-layer Multi-Layer Perceptron (MLP) that takes the encoded feature as input and outputs the signed distance value $f(x)$ and a geometric feature vector $z(x)$ [S1].
*   **Color Network ($M$):** A 4-layer MLP that takes view direction $d$, surface normal $n$, and geometric feature $\hat{z}$ to output color $c$ [S1].

**Numbered Steps:**

1.  **Coordinate Normalization:** For a sample point $p$ along a ray, normalize its coordinate to the grid's scale, denoted as $x$ [S1].
2.  **Voxel Mapping:** Map the normalized coordinate $x$ to a specific voxel $V$ using the formula:
    $$ V = \{v \mid \lfloor x \cdot N \rfloor \le v < \lceil x \cdot N \rceil \} $$
    where $N$ is the grid size. The anchors are stored at the eight vertices of this voxel [S1].
3.  **Feature Interpolation (Deformable Anchors):** Compute the input feature $\phi(p, \psi(G))$ by interpolating the frequency encoding of the eight adjacent anchors. The set of deformable anchors is $\psi(G) = \{p_v, \Delta p_v \mid v \in G\}$ [S1]. The formula is:
    $$ \phi(p, \psi(G)) = \sum_{v \in V} w(p_v) \cdot \gamma(p_v + \Delta p_v) $$
    where $\gamma$ is the frequency encoding function [S1].
4.  **Weight Calculation:** The weight $w(p_n)$ for each anchor $n$ is calculated using cosine similarity to measure the contribution of different anchors:
    $$ w(p_n) = \frac{\hat{w}(p_n)}{\sum_n \hat{w}(p_n)}, \quad \hat{w}(p_n) = \frac{p \cdot p_n}{\|p\| \|p_n\|} $$
    [S1].
5.  **Frequency Encoding:** The frequency encoding function $\gamma$ is applied to the three coordinate values in the anchor position individually. For a level $l$, the encoding is:
    $$ \gamma(p_l) = (\sin(2^l \pi p_l), \cos(2^l \pi p_l)) $$
    This returns a small 6-dimensional embedding $\phi(\hat{p}_l)$ for each anchor grid level. Multi-level embeddings are concatenated [S1].
6.  **SDF and Geometry Prediction:** Feed the concatenated feature into the SDF network $F$ to obtain the signed distance $f(p)$ and geometric feature $\hat{z}$ [S1].
7.  **Opacity Calculation:** Calculate discrete opacity $\alpha_i$ for sample point $i$ based on the SDF values at consecutive points $t_i$ and $t_{i+1}$ along the ray, using a trainable parameter $s$:
    $$ \alpha_i = \max\left( \frac{\Phi_s(f(p(t_i))) - \Phi_s(f(p(t_{i+1})))}{\Phi_s(f(p(t_i)))}, 0 \right) $$
    where $\Phi_s(x) = (1 + e^{-sx})^{-1}$ [S1].
8.  **Rendering:** Accumulate the rendered color $\hat{C}$ along the ray with $N$ discrete sampled points:
    $$ \hat{C} = \sum_{i=1}^{N} T_i \alpha_i c_i $$
    where $T_i = \prod_{j=1}^{i-1}(1-\alpha_j)$ is the accumulated transmittance, and $c_i$ is the color output by the color network $M$ using $d$, $n$, and $\hat{z}$ [S1].

**Parameters:**
*   **$s$:** A trainable parameter in the opacity calculation. As optimization converges, $1/s$ approaches zero [S1].
*   **Network Depth:** The SDF network $F$ and Color network $M$ are both 4-layer MLPs. This is shallower than the 8-layer MLP used in NeuS [S1].

**Pitfalls:**
*   **Standard Voxel Limitations:** Standard voxel grids store uniformly distributed features which may fail to capture small structures with complicated topologies. NeuDA mitigates this by optimizing anchor positions, but requires careful initialization and optimization of the anchor offsets $\Delta p_v$ [S1].
*   **Hash Collision Avoidance:** Unlike hash-based methods (e.g., Instant-NGP), NeuDA avoids hash collisions by using hierarchical voxel grids, but this may incur higher memory overhead for large grids [S1].

## Operating characteristics
*   **Complexity:** Time and memory complexity depend on the hierarchical grid resolution and the number of sampled points per ray. The use of hierarchical grids allows for efficient multi-scale representation.
*   **Performance:** Experiments on DTU and BlendedMVS datasets show NeuDA is superior in recovering high-quality geometry with fine-grained details compared to baselines and SOTA methods [S1].
*   **Strengths:** Improves flexibility of voxel grid representation; better exploits spatial context; adapts to abrupt geometry changes; uses shallower networks (4-layer vs 8-layer) due to promising scene representation capability of the deformable anchor structure [S1].
*   **Limitations:** Requires optimization of anchor positions in addition to network weights; hierarchical grid management adds implementation complexity compared to single-level grids [S1].
*   **When to use:** High-fidelity surface reconstruction where capturing small structures and sharp local topologies is critical.
*   **When not to use:** When computational resources are extremely limited and the scene geometry is simple; when hash-based methods are preferred for their speed and collision resistance is not a concern [S1].

## Background
NeuDA was introduced by Bowen Cai, Jinchi Huang, Rongfei Jia, Chengfei Lv, and Huan Fu from Alibaba Group. It was published on arXiv on March 26, 2023 (arXiv:2303.02375v2) [S1]. The method addresses limitations in previous works like IDR and NeuS, which overlook spatial context in 3D space when predicting and rendering surfaces, potentially failing to capture sharp local topologies such as small holes and structures [S1]. It builds on the differentiable ray casting framework established by NeuS [S1].
