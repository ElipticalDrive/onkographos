# Two-Plane Diffusion Model (TPDM)

Also called: TDPM

## Overview
Two-Plane Diffusion Model (TPDM) is a method for solving 3D inverse problems and generating 3D voxel volumes by training two separate 2D diffusion models on perpendicular planes and alternating their usage during the denoising process to maintain 3D consistency [S1]. It avoids the curse of dimensionality by assuming a 3D distribution is the product of 2D distributions, allowing it to handle 3D volumes without using a 3D diffusion model [S1]. Unlike [Diffusion-Based Guidance for Radiance Field Optimization](8117-diffusion-based-guidance-for-radiance-field-optimization.md) which guides optimization via gradients, TPDM performs conditional sampling directly on the volume using a primary model for measurement consistency and an auxiliary model for cross-plane consistency [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Observed 3D measurement data $Y \in \mathbb{R}^{d_1 \times d_2 \times d_3}$, forward operator $A(\cdot): \mathbb{R}^{d_1 \times d_2} \to \mathbb{R}^{d_1 \times d_2}$, pre-trained primary score model $s_{\theta^*}$, pre-trained auxiliary score model $s_{\phi^*}$, noise schedule $\{\sigma_i\}_{i=0}^{10}$, number of denoising steps $N$, integer hyperparameter $K$, and measurement consistency strength $\lambda$ [S1].
*   **Output:** Reconstructed 3D volume $X_0 \in \mathbb{R}^{d_1 \times d_2 \times d_3}$ [S1].

**Data Structures:**
*   $X_i$: Tensor of shape $d_1 \times d_2 \times d_3$ representing the volume at denoising step $i$.
*   $Y$: Tensor of shape $d_1 \times d_2 \times d_3$ representing the measurement data.
*   $s_{\theta^*}$: Primary 2D diffusion model (score function).
*   $s_{\phi^*}$: Auxiliary 2D diffusion model (score function).

**Parameters:**
*   $K$: Integer controlling the ratio of primary to auxiliary model usage. If $K=4$, the primary model is used 3 times and the auxiliary 1 time (ratio 3:1) [S1].
*   $\lambda$: Hyperparameter controlling the strength of measurement consistency in the Data Consistency (DPS) step [S1].
*   $N$: Number of denoising steps. Typical value: 2000 [S1].
*   $\sigma_t$: Noise schedule parameter. Scheduled by a geometric sequence from $\sigma_0 = 0.01$ to $\sigma_1 = 378$ [S1].

**Algorithm Steps:**
1.  Initialize the noisy volume $X_N$ by sampling from a Gaussian distribution $\mathcal{N}(0, \sigma_1^2 I)$ with shape $d_1 \times d_2 \times d_3$ [S1].
2.  Iterate backwards from $i = N-1$ down to $0$:
    a.  Set time step $t = i/N$ [S1].
    b.  Initialize an empty tensor $X_i$ with the same shape as $X_N$ [S1].
    c.  Determine if the primary model is used. If $K$ is an integer, use the condition `mod(i, K) != 0`. If true, use the primary model $s_{\theta^*}$; otherwise, use the auxiliary model $s_{\phi^*}$ [S1]. (For non-integer $K$, sample from a Bernoulli distribution with probability $p = 1 - 1/K$) [S1].
    d.  **If using the primary model:**
        i.  Loop $j$ from $1$ to $d_3$ (slicing along the $Z$-axis, or the axis perpendicular to the primary plane):
            1.  Extract current slice $x = X_{i+1}[:, :, j]$ and corresponding measurement slice $y = Y[:, :, j]$ [S1].
            2.  Compute the predicted clean sample $\hat{x}_0 = x + \sigma_t^2 \cdot s_{\theta^*}(x, t)$ [S1].
            3.  Perform one step of the 2D Diffusion Probabilistic Model (DPM) using $x$, $s_{\theta^*}$, $\sigma_t$, and $t$ to get $x'$ [S1].
            4.  Apply data consistency correction: $x'' = x' - \lambda \nabla_x \|A(\hat{x}_0) - y\|_2^2$ [S1].
            5.  Assign the corrected slice to $X_i[:, :, j] = x''$ [S1].
    e.  **If using the auxiliary model:**
        i.  Loop $j$ from $1$ to $d_1$ (slicing along the $X$-axis, or the axis perpendicular to the auxiliary plane):
            1.  Extract current slice $x = X_{i+1}[j, :, :]$ [S1].
            2.  Perform one step of the 2D DPM using $x$, $s_{\phi^*}$, $\sigma_t$, and $t$ to get $x'$ [S1].
            3.  Assign the denoised slice to $X_i[j, :, :] = x'$ [S1].
3.  Return $X_0$ [S1].

**Pseudocode:**
```python
import math
import random

def tpdm_sample(Y, A, s_theta_star, s_phi_star, sigma_schedule, N, K, lambda_val):
    """
    Solves 3D inverse problem using Two-Plane Diffusion Model.
    
    Args:
        Y: Observed 3D measurement data, shape (d1, d2, d3).
        A: Forward operator function. Takes a 2D slice and returns measurement.
        s_theta_star: Primary 2D score model function.
        s_phi_star: Auxiliary 2D score model function.
        sigma_schedule: List of noise levels sigma_t, descending from sigma_1 to sigma_0.
        N: Number of denoising steps.
        K: Integer controlling primary/auxiliary ratio.
        lambda_val: Strength of measurement consistency.
        
    Returns:
        X0: Reconstructed 3D volume.
    """
    d1, d2, d3 = Y.shape
    sigma_1 = sigma_schedule[0]
    # Initialize X_N ~ N(0, sigma_1^2 I)
    X_next = [[[random.gauss(0, sigma_1) for _ in range(d2)] for _ in range(d1)] for _ in range(d3)]

    for i in range(N - 1, -1, -1):
        t = i / N
        sigma_t = sigma_schedule[i]
        sigma_next = sigma_schedule[i + 1] if i + 1 < len(sigma_schedule) else 0.0
        X_curr = [[[0.0 for _ in range(d2)] for _ in range(d1)] for _ in range(d3)]

        # Determine model usage: mod(i, K) != 0 for integer K [S1]
        use_primary = (i % K) != 0

        if use_primary:
            for j in range(d3):
                x = X_next[:, :, j]
                y = Y[:, :, j]
                score = s_theta_star(x, t)
                x0_hat = x + (sigma_t ** 2) * score
                x_prime = step_2d_dpm(x, s_theta_star, sigma_t, sigma_next, t)
                grad_x = compute_data_consistency_gradient(x, x0_hat, y, A)
                x_double_prime = x_prime - lambda_val * grad_x
                X_curr[:, :, j] = x_double_prime
        else:
            for j in range(d1):
                x = X_next[j, :, :]
                x_prime = step_2d_dpm(x, s_phi_star, sigma_t, sigma_next, t)
                X_curr[j, :, :] = x_prime

        X_next = X_curr
    return X_next

def step_2d_dpm(x, score_model, sigma_t, sigma_next, t):
    # Euler-Maruyama step for VE-SDE [G]
    noise = random.normal(size=x.shape)
    return x + (sigma_next ** 2 - sigma_t ** 2) * score_model(x, t) + math.sqrt(max(0, sigma_next ** 2 - sigma_t ** 2)) * noise

def compute_data_consistency_gradient(x, x0_hat, y, A):
    # Computes gradient of ||A(x0_hat) - y||^2 w.r.t x [G]
    residual = A(x0_hat) - y
    return 2.0 * residual  # Simplified; general case uses adjoint of A
```

**Edge Cases and Pitfalls:**
*   **Boundaries:** The slicing loops assume the volume dimensions $d_1, d_2, d_3$ are accessible. If the volume is not cubic, the slicing logic must adapt to the chosen primary/auxiliary planes [S1].
*   **Degenerate Input:** The method assumes the forward operator $A$ is differentiable to compute the gradient $\nabla_x \|A(\hat{x}_0) - y\|_2^2$ [S1].

## Operating characteristics
*   **Time Complexity:** The method iterates $N$ times (typically 2000) [S1]. In each step, it processes all slices of the volume [S1]. For the primary model, it processes $d_3$ slices; for the auxiliary, $d_1$ slices [S1]. The complexity is $O(N \cdot (d_1 + d_3))$ 2D DPM steps per volume [S1].
*   **Memory Complexity:** Requires storing the 3D volume $X$ and the measurement $Y$ [S1]. The 2D models are loaded once. Memory is $O(d_1 \cdot d_2 \cdot d_3)$ [S1].
*   **Measured Performance:**
    *   **SV-CT (36-view):** TPDM achieved PSNR 38.25 and SSIM (Axial) 0.947, outperforming DPS (38.20, 0.942) and score-CT (37.56, 0.951) [S1].
    *   **CS-MRI (×48 acceleration):** TPDM achieved PSNR 37.17 and SSIM (Axial) 0.966, outperforming DiffusionMBIR (34.83, 0.950) and DPS (35.30, 0.951) [S1].
*   **Strengths:** Avoids artifacts in the batch direction that plague 2D solvers like DPS when applied to 3D [S1]. Works in an unsupervised manner without fine-tuning for individual inverse problems [S1].
*   **Limitations:** Performance on non-primary planes (e.g., Coronal/Sagittal in SV-CT) can be lower than the primary plane, though still competitive [S1]. Requires pre-training of two 2D models [S1].

## Background
TPDM was introduced in the paper "Improving 3D Imaging with Pre-Trained Perpendicular 2D Diffusion Models" (ICCV 2023) [S1]. It addresses the limitations of 2D diffusion models (like DPS) when applied to 3D inverse problems, which suffer from artifacts in the batch direction [S1]. The method leverages the assumption that a 3D distribution can be approximated by the product of 2D distributions on perpendicular planes, allowing it to solve general 3D inverse problems (such as CS-MRI, SV-CT, and MRI ZSR) and generate 3D volumes without a 3D diffusion model [S1].
