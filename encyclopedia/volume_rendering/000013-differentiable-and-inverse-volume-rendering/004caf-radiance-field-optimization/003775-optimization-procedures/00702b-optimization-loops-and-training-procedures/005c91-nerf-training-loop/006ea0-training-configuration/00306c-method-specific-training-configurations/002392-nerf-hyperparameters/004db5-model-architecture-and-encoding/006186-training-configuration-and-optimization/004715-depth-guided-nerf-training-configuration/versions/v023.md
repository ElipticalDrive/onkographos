# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the training protocol for Neural Radiance Fields (NeRF) that incorporate depth supervision to improve geometry reconstruction and training stability. It addresses the ambiguity of volume density in standard NeRF by integrating ground-truth depth priors into the loss function. It differs from sibling methods like [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md) (which uses semantic constraints) and [Binary Radiance Fields](13622-binary-radiance-fields.md) (which discretizes space) by maintaining continuous volumetric representation while explicitly penalizing depth prediction errors.

## How it works
The method extends the standard NeRF optimization loop by adding a depth loss term and specific architectural regularizations.

**Inputs:**
*   Camera poses and intrinsics.
*   RGB images.
*   Ground-truth depth maps (sparse or dense).
*   Scene-specific depth bounds ($min\_depth$, $max\_depth$).

**Outputs:**
*   Optimized NeRF weights $\theta$.
*   Rendered RGB images and depth maps.

**Data Structures:**
*   **NeRF Model:** Builds on the standard MLP architecture [Parent](13550-model-architecture-and-encoding.md).
*   **Dropout Mask:** Applied to the first 8 fully connected layers of the positional encoding network.

**Parameters:**
*   Depth loss weight $\lambda$: $0.007$ for most scenes; $0.02$ for scene 710 [S1].
*   Uncertainty weight $\gamma$: $1$ [S1].
*   Optimizer: Adam.
*   Learning rate (LR): $5 \times 10^{-4}$, reduced to $5 \times 10^{-5}$ after 80% of total steps [S1].
*   Weight decay: $1 \times 10^{-6}$ [S1].
*   Depth scale LR: $1 \times 10^{-7}$ [S1].
*   Total steps: $500,000$ [S1].
*   Uncertainty threshold $\tau$: Calculated as $\tau = (max\_depth - min\_depth) \cdot 0.0001$ [S1].

**Algorithm:**

1.  **Initialize** NeRF parameters $\theta$ and depth scale parameter.
2.  **Sample** rays and query the network $F_\theta$ to obtain volume density $\sigma$ and color $\mathbf{c}$ [Parent].
3.  **Compute** the standard volumetric rendering loss (e.g., MSE between rendered and ground-truth RGB).
4.  **Compute** the predicted depth $\hat{d}$ from the sampled points and weights.
5.  **Evaluate Uncertainty:** For each pixel, determine if the depth is valid using the threshold $\tau$. If the predicted depth uncertainty exceeds $\tau$, the depth loss contribution for that pixel may be modulated by $\gamma$ [S1].
6.  **Compute Depth Loss:** Calculate the error between predicted depth $\hat{d}$ and ground-truth depth $d$. The specific metric (e.g., RMSE, AbsRel) is applied only to pixels with valid ground-truth depth indices $k \in \{1, \dots, K\}$ [S1].
7.  **Aggregate Loss:** Combine the RGB loss and the depth loss weighted by $\lambda$:
    $$ L_{total} = L_{rgb} + \lambda L_{depth} $$
    *(Note: The exact formulation of $L_{depth}$ involving $\gamma$ and $\tau$ is implementation-specific, but $\gamma=1$ implies standard weighting in the cited experiments [S1]).*
8.  **Update:** Perform gradient descent using Adam with the specified LR schedule and weight decay [S1].
9.  **Repeat** for 500,000 steps [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.optim as optim

def compute_depth_loss(predicted_depth, gt_depth, valid_mask, lambda_depth):
    """
    Computes the depth loss for valid pixels.
    """
    # Filter valid pixels
    pred_valid = predicted_depth[valid_mask]
    gt_valid = gt_depth[valid_mask]
    
    # Example: Mean Absolute Relative Error (AbsRel) as per [S1] Eq 4
    # Note: [S1] reports multiple metrics; the loss function itself is typically L1 or L2 on depth.
    # We assume a standard L1 or L2 loss scaled by lambda.
    # The source [S1] defines evaluation metrics, not the exact training loss formula,
    # but implies depth supervision is added. We use a generic L1 depth loss here.
    loss = torch.mean(torch.abs(pred_valid - gt_valid))
    return lambda_depth * loss

def train_depth_guided_nerf(model, optimizer, data_loader, total_steps, lambda_depth, lr_schedule):
    """
    Training loop for Depth-Guided NeRF.
    """
    model.train()
    
    for step in range(total_steps):
        # 1. Get batch: rays, gt_rgb, gt_depth, valid_mask
        rays, gt_rgb, gt_depth, valid_mask = next(data_loader)
        
        # 2. Forward pass
        # model returns color and depth (and optionally uncertainty)
        # Note: Depth is derived from the same samples used for color rendering
        rendered_rgb, rendered_depth = model(rays)
        
        # 3. Compute RGB Loss
        rgb_loss = nn.functional.mse_loss(rendered_rgb, gt_rgb)
        
        # 4. Compute Depth Loss
        # Apply lambda_depth (0.007 or 0.02 depending on scene)
        depth_loss = compute_depth_loss(rendered_depth, gt_depth, valid_mask, lambda_depth)
        
        # 5. Total Loss
        # Uncertainty weight gamma is 1, so it acts as a direct multiplier if included in depth_loss calc
        total_loss = rgb_loss + depth_loss
        
        # 6. Backward pass
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
        
        # 7. LR Schedule
        # Reduce LR to 5e-5 after 80% of steps
        if step == int(total_steps * 0.8):
            for param_group in optimizer.param_groups:
                param_group['lr'] = 5e-5

    return model
```

**Edge Cases and Pitfalls:**
*   **Scene 710:** Requires a higher depth loss weight ($\lambda = 0.02$) compared to other scenes ($\lambda = 0.007$) [S1].
*   **Depth Scale:** The depth scale parameter requires a significantly lower learning rate ($1 \times 10^{-7}$) than the main network weights ($5 \times 10^{-4}$) to ensure stable convergence [S1].
*   **Uncertainty Threshold:** The threshold $\tau$ is scene-dependent, calculated from the min/max depth bounds of the specific dataset (e.g., ScanNet) [S1].

## Subtopics

### DS-NeRF Depth Loss Integration
Integrates the depth loss implementation from the official DS-NeRF codebase into the training pipeline. This variant is chosen when leveraging established depth loss formulations from DS-NeRF. It requires re-training on specific train/test splits (e.g., LLFF) because original publication results used different splits or unreleased configurations [S2].

## Operating characteristics
*   **Time Complexity:** Dominated by the standard NeRF ray marching and MLP evaluation, plus the additional forward pass or derivation for depth. Total steps are fixed at 500,000 [S1].
*   **Memory Complexity:** Standard NeRF memory usage plus storage for depth maps and uncertainty masks [S1].
*   **Strengths:** Improves geometric accuracy and reduces floating surface artifacts by constraining the volume density along the ray [S1].
*   **Limitations:** Requires ground-truth depth data (or reliable depth estimation) [S1]. Performance is sensitive to the depth loss weight $\lambda$ and the uncertainty threshold $\tau$ [S1].
*   **When to use:** When high-fidelity geometry is required and depth priors are available.
*   **When not to use:** When depth data is unavailable or unreliable, or when computational budget is extremely limited (due to additional loss computation).

## Background
This configuration originates from the work on Depth-Guided NeRF Training via Earth Mover’s Distance [S1]. It builds upon the original NeRF architecture [Parent] and incorporates techniques from DS-NeRF [S2]. The method was developed to address the lack of geometric constraints in standard NeRF training, particularly for indoor scenes like ScanNet [S1].
