# Position Encoding

Also called: Frequency Position Encoding, Sine/Cosine Encoding

## Overview
Position Encoding (PE) is a feature mapping technique that transforms low-frequency coordinate representations into high-frequency information using sine and cosine functions, thereby increasing dimensionality to help deep networks approximate high-frequency functions and prevent the loss of high-frequency spatial information [S2]. It sets itself apart from its siblings by serving as the foundational explicit encoding scheme for NeRF, whereas alternatives like Frequency-Modulated Position Encoding or Random Offset Annealed Fourier Encoding introduce stochasticity, modulation, or local affine transformations to address specific limitations such as spectral bias or domain shift [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A query point coordinate vector $x \in \mathbb{R}^3$ and a camera viewing direction vector $d \in \mathbb{R}^3$.
*   **Output:** A high-dimensional encoded vector resulting from the application of the encoding function $\gamma(\cdot)$ to $x$ and $d$, which is then concatenated and passed to the MLP.

**Data Structures:**
The encoding relies on a frequency matrix $F$ and an encoding level parameter $L$.
*   **Frequency Matrix ($F$):** In hardware implementations (e.g., ICARUS), $F$ is stored in local memory. For $R=3$ (3-dimensional data), one memory block of size $3 \times 128$ stores the matrix [S1]. For $R=6$ (6-dimensional data, combining $x$ and $d$), two separate $3 \times 128$ memory blocks are used: the first stores the first half of the matrix, and the second stores the second half [S1].
*   **Encoding Levels ($L$):** The number of frequency bands. In the standard NeRF configuration, $L=10$ for position $x$ and $L=4$ for direction $d$ [S2].

**Formulas:**
The encoding function $\gamma: \mathbb{R} \to \mathbb{R}^{2L}$ is defined as [S2]:
$$
\gamma(p) = (\sin(2^0\pi p), \cos(2^0\pi p), \dots, \sin(2^{L-1}\pi p), \cos(2^{L-1}\pi p))
$$
The final encoded feature vector is computed by applying $\gamma$ separately to each component of $x$ and $d$, and then feeding the result into a regular MLP $F_{\Theta'}$ [S2]:
$$
F_\Theta = F_{\Theta'} \circ \gamma
$$
where $\circ$ denotes the composition of the mapping $\gamma$ with the MLP $F_{\Theta'}$ [S2].

**Parameters:**
*   $L_x = 10$: Encoding levels for position [S2].
*   $L_d = 4$: Encoding levels for direction [S2].
*   $R$: Dimensionality of the input data. Supports $R=3$ (position only) and $R=6$ (position + direction) [S1].

**Numbered Steps:**
1.  **Initialize Frequency Matrix:** Store the frequency matrix $F$ in local memory. The matrix is constant for all sample points in a particular rendering task [S1].
2.  **Stream Inputs:** Stream the position $x$ and direction $d$ into the matrix multiplication unit [S1].
3.  **Matrix Multiplication:** Multiply the streamed positions/directions with the frequency matrix $F$ in a pipelined manner to generate an intermediate vector $z$ [S1].
    *   For $R=3$: Access one memory block. Process through the first 3 stages of the cascaded MAC unit (3 multiplications and 2 additions in serial) [S1].
    *   For $R=6$: Access two memory blocks simultaneously. Process through all 6 stages of the cascaded MAC unit [S1].
4.  **Trigonometric Transformation:** Feed the intermediate vector $z$ to a Coordinate Rotation Digital Computer (CORDIC) array to generate the final transformed features $\sin(z)$ and $\cos(z)$ [S1].
5.  **MLP Forward Pass:** Pass the concatenated sine and cosine features into the neural network $F_{\Theta'}$ to predict density and color [S2].

**Pseudocode:**
```python
import math

def position_encoding(p, L):
    """
    Applies the standard NeRF position encoding to a scalar or vector p.
    
    Args:
        p (float or list of floats): Input coordinate(s).
        L (int): Number of frequency bands.
        
    Returns:
        list: Encoded vector of size 2 * L * len(p).
    """
    encoded = []
    # Handle both scalar and vector inputs
    if isinstance(p, (int, float)):
        p = [p]
    
    for coord in p:
        for l in range(L):
            freq = (2 ** l) * math.pi
            encoded.append(math.sin(freq * coord))
            encoded.append(math.cos(freq * coord))
    return encoded

def nerf_encode(x, d, L_x=10, L_d=4):
    """
    Encodes position x and direction d for NeRF.
    
    Args:
        x (list of 3 floats): 3D position coordinates.
        d (list of 3 floats): 3D viewing direction vector.
        L_x (int): Encoding levels for position.
        L_d (int): Encoding levels for direction.
        
    Returns:
        list: Concatenated encoded vector for x and d.
    """
    enc_x = position_encoding(x, L_x)
    enc_d = position_encoding(d, L_d)
    return enc_x + enc_d
```

**Edge Cases and Pitfalls:**
*   **Precision:** The use of high-frequency sine/cosine functions can lead to numerical instability if the input coordinates are not normalized or if the frequency bands $2^l$ become excessively large, potentially causing overflow or loss of precision in floating-point representations [S2].
*   **Boundary Conditions:** The encoding is periodic. If the scene coordinates are not bounded or normalized to a specific range (e.g., $[-1, 1]$ or $[0, 1]$), the high-frequency components may alias or fail to represent the spatial structure correctly [S2].
*   **Spectral Bias:** While PE addresses spectral bias by introducing high frequencies, the MLP still tends to learn low-frequency functions first. The choice of $L$ must balance the ability to represent high-frequency details against the network's capacity to learn them [S2].

## Subtopics

### Frequency-Modulated Position Encoding
Modulates the frequency of the encoding based on the input position, allowing for adaptive frequency resolution. Choose when the scene has varying levels of detail across different regions. [Frequency-Modulated Position Encoding](15897-frequency-modulated-position-encoding.md)

### Neural Light Fields with Ray-Space Embedding
Embeds ray-space coordinates directly, often used for light field rendering. Choose when dealing with light field data structures rather than volumetric radiance fields. [Neural Light Fields with Ray-Space Embedding](17616-neural-light-fields-with-ray-space-embedding.md)

### Ray-Space Embedding Network with Local Affine Transformation
Uses local affine transformations to adapt the encoding to local geometric structures. Choose when global periodic encodings fail to capture local geometric variations. [Ray-Space Embedding Network with Local Affine Transformation](18128-ray-space-embedding-network-with-local-affine-transformation.md)

### Skeleton-Relative Encoding
Encodes positions relative to a skeleton structure, useful for articulated objects. Choose when rendering characters or articulated models. [Skeleton-Relative Encoding](18148-skeleton-relative-encoding.md)

### Random Offset Annealed Fourier Encoding
Uses random Fourier features with annealing to improve optimization dynamics. Choose when standard sine/cosine encoding leads to optimization difficulties or local minima. [Random Offset Annealed Fourier Encoding](18686-random-offset-annealed-fourier-encoding.md)

## Operating characteristics
*   **Time Complexity:** The encoding step is $O(L \cdot D)$, where $L$ is the number of frequency bands and $D$ is the dimensionality of the input (3 for position, 3 for direction). This is negligible compared to the MLP evaluation, which is typically $O(N_{layers} \cdot W^2)$ where $W$ is the hidden width [S2].
*   **Memory Complexity:** The memory footprint for the encoding parameters is minimal, as the frequencies are fixed constants. However, the intermediate vector size is $2 \cdot L \cdot D$, which for standard NeRF ($L_x=10, L_d=4, D=3$) results in a vector of size $72$ [S2].
*   **Measured Performance:** In standard NeRF, this encoding allows the network to approximate high-frequency functions effectively, leading to high-quality renderings of complex scenes [S2]. Hardware implementations like ICARUS show that using a cascaded MAC unit and CORDIC array can efficiently compute these operations, with $R=6$ mode utilizing two memory blocks and 6 MAC stages [S1].
*   **Strengths:** Simple to implement, differentiable, and effective at mitigating spectral bias in MLPs [S2].
*   **Limitations:** Fixed frequency bands may not be optimal for all scenes; high frequencies can be difficult to learn without careful initialization or optimization strategies [S2].
*   **When to Use:** Standard NeRF training and rendering where high-frequency details are present and the scene is bounded [S2].
*   **When Not to Use:** Scenes with unbounded coordinates or where adaptive frequency resolution is required (consider Frequency-Modulated Position Encoding) [S1, S2].

## Background
Position Encoding was introduced in the seminal NeRF paper by Mildenhall et al. (2020) to address the spectral bias of MLPs, which tend to learn low-frequency functions and lose high-frequency spatial information [S2]. The technique maps low-frequency coordinates to a higher-dimensional space using sine and cosine functions with exponentially increasing frequencies [S2]. It has since become a standard component in many neural radiance field architectures, with various extensions proposed to improve performance and efficiency [S1, S2].
