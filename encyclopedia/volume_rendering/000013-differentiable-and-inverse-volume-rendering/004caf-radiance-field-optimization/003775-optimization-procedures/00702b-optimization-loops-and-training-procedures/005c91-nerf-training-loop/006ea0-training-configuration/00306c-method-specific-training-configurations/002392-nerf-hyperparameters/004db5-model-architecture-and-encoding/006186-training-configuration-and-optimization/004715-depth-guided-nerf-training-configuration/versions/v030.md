# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the training protocol for a Neural Radiance Field (NeRF) model that incorporates depth priors to improve reconstruction quality, specifically building on the standard NeRF architecture [S1]. It distinguishes itself from sibling methods by explicitly integrating a depth loss term weighted by $\lambda$ and an uncertainty weight $\gamma$ into the optimization loop, alongside specific architectural modifications such as dropout layers to prevent overfitting [S1]. Unlike methods that rely solely on photometric loss, this approach leverages geometric constraints from depth maps, making it suitable for scenes where depth supervision is available or can be estimated [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** Camera poses, intrinsics, images, and corresponding ground-truth depth maps (or estimated depth maps with uncertainty).
*   **Outputs:** Trained NeRF MLP weights, including density $\sigma$ and color $\mathbf{c}$ predictions, optimized via the combined photometric and depth losses.

**Data Structures**
The network architecture builds upon the original NeRF [15] (see [Model Architecture and Encoding](13550-model-architecture-and-encoding.md)). Key modifications include:
1.  **Dropout:** Dropout layers with probability $p=0.1$ are added after each of the first eight fully connected ReLU-activated layers that encode the positional encoding [S1].
2.  **Depth Scale:** A specific learning rate is assigned to the depth scale parameter [S1].

**Numbered Steps**
1.  **Initialize:** Initialize the NeRF MLP weights. Set Adam optimizer parameters: initial learning rate $\eta = 5 \times 10^{-4}$, weight decay $\omega = 10^{-6}$ [S1].
2.  **Depth Threshold:** Calculate the uncertainty threshold $\tau$ for evaluating depth map validity:
    $$ \tau = (\text{max\_depth} - \text{min\_depth}) \cdot 0.0001 $$
    For ScanNet, $\text{max\_depth} = 10$ and $\text{min\_depth} = 0.001$ [S1].
3.  **Sampling:** Sample points along camera rays using the standard NeRF ray sampling procedure (see [Model Architecture and Encoding](13550-model-architecture-and-encoding.md)) [S1].
4.  **Forward Pass:** Compute predicted color $\hat{\mathbf{c}}$ and volume density $\hat{\sigma}$ for sampled points. Render the image and predict depth $\hat{d}$ [S1].
5.  **Loss Calculation:** Compute the total loss $\mathcal{L}$:
    $$ \mathcal{L} = \mathcal{L}_{rgb} + \lambda \mathcal{L}_{depth} + \gamma \mathcal{L}_{uncertainty} $$
    Where:
    *   $\mathcal{L}_{rgb}$ is the standard photometric loss (e.g., MSE between rendered and ground-truth colors) [S1].
    *   $\mathcal{L}_{depth}$ is the depth loss. The evaluation metrics provided (RMSE, AbsRel, SqRel) are for reporting, but the training loss typically involves an $L_1$ or $L_2$ difference between predicted and ground-truth depth [S1].
    *   $\lambda$ is the depth loss weight: $\lambda = 0.007$ for most scenes, and $\lambda = 0.02$ for scene 710 [S1].
    *   $\gamma$ is the uncertainty weight: $\gamma = 1$ [S1].
6.  **Optimization:** Update weights using Adam optimizer. Reduce learning rate to $5 \times 10^{-5}$ after 80% of total steps [S1].
7.  **Depth Scale Update:** Update the depth scale parameter with a dedicated learning rate of $10^{-7}$ [S1].
8.  **Repeat:** Continue for 500,000 total training steps [S1].

**Pseudocode**
```python
# Configuration constants
LR_INITIAL = 5e-4
LR_FINAL = 5e-5
LR_DEPTH_SCALE = 1e-7
WEIGHT_DECAY = 1e-6
DROPOUT_PROB = 0.1
TOTAL_STEPS = 500000
LAMBDA_DEPTH = 0.007  # Use 0.02 for scene 710
GAMMA_UNCERTAINTY = 1.0
MAX_DEPTH = 10.0
MIN_DEPTH = 0.001
THRESHOLD_FACTOR = 0.0001

# Initialize NeRF model with dropout after first 8 FC layers
model = NeRFModel(dropout_prob=DROPOUT_PROB)

# Initialize optimizer
optimizer = Adam(model.parameters(), lr=LR_INITIAL, weight_decay=WEIGHT_DECAY)

# Separate parameter group for depth scale if applicable
# Note: Specific implementation of depth scale parameter depends on model definition
depth_scale_param = model.get_depth_scale_parameter()
optimizer.add_param_group({'params': [depth_scale_param], 'lr': LR_DEPTH_SCALE})

# Training loop
for step in range(TOTAL_STEPS):
    # Learning rate schedule: reduce to LR_FINAL after 80% of steps
    if step > 0.8 * TOTAL_STEPS:
        set_lr(optimizer, LR_FINAL)
    
    # Get batch: images, poses, depth maps
    images, poses, depth_maps = get_batch()
    
    # Render NeRF
    rendered_colors, rendered_depths, uncertainties = render_neRF(model, poses)
    
    # Calculate depth threshold for uncertainty evaluation
    tau = (MAX_DEPTH - MIN_DEPTH) * THRESHOLD_FACTOR
    
    # Compute losses
    loss_rgb = compute_mse_loss(rendered_colors, images)
    loss_depth = compute_depth_loss(rendered_depths, depth_maps, tau)
    loss_uncertainty = compute_uncertainty_loss(uncertainties)
    
    # Combined loss
    loss = loss_rgb + LAMBDA_DEPTH * loss_depth + GAMMA_UNCERTAINTY * loss_uncertainty
    
    # Backpropagate and optimize
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

**Parameters**
*   **Depth loss weight ($\lambda$):** 0.007 (default), 0.02 (scene 710) [S1].
*   **Uncertainty weight ($\gamma$):** 1 [S1].
*   **Optimizer:** Adam [S1].
*   **Initial learning rate:** $5 \times 10^{-4}$ [S1].
*   **Learning rate schedule:** Reduce to $5 \times 10^{-5}$ after 80% of steps [S1].
*   **Weight decay:** $10^{-6}$ [S1].
*   **Total training steps:** 500,000 [S1].
*   **Depth scale learning rate:** $10^{-7}$ [S1].

**Edge Cases and Pitfalls**
*   **Scene 710:** Requires a higher depth loss weight ($\lambda = 0.02$) compared to other scenes [S1].
*   **Depth Threshold:** The threshold $\tau$ for evaluating depth uncertainty is scene-dependent (based on max/min depth) [S1].
*   **Overfitting:** The use of dropout is critical to prevent overfitting, especially when depth loss is introduced [S1].

## Subtopics

### DS-NeRF Depth Loss Integration
Integrates the depth loss implementation from the official DS-NeRF code base into the training pipeline [S2]. This variant requires re-training on LLFF train/test splits using released configuration files, as the original publication results for LLFF used a different split and DTU results could not be reproduced due to missing config files [S2].

## Operating characteristics
*   **Time Complexity:** Training requires 500,000 steps, which is comparable to standard NeRF training times [S1].
*   **Memory Complexity:** The addition of dropout layers and depth loss computation adds minimal memory overhead [S1].
*   **Strengths:** Improves geometric accuracy by leveraging depth priors [S1].
*   **Limitations:** Requires depth maps (ground truth or estimated) [S1]. Performance may vary across scenes (e.g., scene 710 requires different hyperparameters) [S1].
*   **When to use:** When depth supervision is available and geometric accuracy is prioritized over pure photometric fidelity [S1].

## Background
This configuration originates from the work on Depth-Guided NeRF Training via Earth Mover’s Distance [S1]. It builds upon the original NeRF architecture [15] and incorporates techniques from DS-NeRF [S2] for depth loss integration. The method was developed to address the lack of geometric constraints in standard NeRF training, particularly in sparse-view scenarios [S1, S2].
