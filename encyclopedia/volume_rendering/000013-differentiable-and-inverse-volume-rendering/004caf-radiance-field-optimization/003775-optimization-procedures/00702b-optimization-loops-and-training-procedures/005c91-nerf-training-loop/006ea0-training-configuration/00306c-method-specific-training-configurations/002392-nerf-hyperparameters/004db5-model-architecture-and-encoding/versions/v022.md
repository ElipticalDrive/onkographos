# Model Architecture and Encoding

Also called: NeRF Architecture, Coordinate-based Radiance Fields, Feature Grids, Positional Encoding

## Overview
Model Architecture and Encoding defines the neural network structure and input transformation functions used to map 3D spatial coordinates and viewing directions to volume density and color. It solves the problem of representing continuous 3D radiance fields in a differentiable manner suitable for gradient-based optimization. It differs from sibling methods by focusing on the internal representation of the scene (e.g., MLP depth, hash grid resolution, encoding basis functions) rather than the training loop dynamics or loss functions.

## Shared principles
The core mechanism involves a coordinate-based neural network that accepts a 3D position $\mathbf{x} \in \mathbb{R}^3$ and a viewing direction $\mathbf{d} \in S^2$ as inputs. These raw coordinates are typically transformed into a higher-dimensional feature space using an encoding function $\gamma(\cdot)$ before being processed by Multi-Layer Perceptrons (MLPs) or feature grids. The network outputs volume density $\sigma \in \mathbb{R}$ and color $\mathbf{c} \in \mathbb{R}^3$. The density is used for alpha composition during volume rendering, while the color is view-dependent.

## Subtopics

### [Depth-Guided NeRF Training Configuration](11916-depth-guided-nerf-training-configuration.md)
This configuration modifies the standard NeRF architecture by adding dropout regularization to the positional encoding layers to improve geometric accuracy when using depth priors [11916-depth-guided-nerf-training-configuration.md]. It uses a standard NeRF MLP with dropout probability $p=0.1$ after the first eight fully connected ReLU layers [11916-depth-guided-nerf-training-configuration.md].

### [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md)
CLIPNeRF training freezes the density-related parameters of the standard NeRF MLP and optimizes only the color/view-dependent parameters to achieve text-guided stylization [12073-clipnerf-training-configuration.md]. It uses a standard MLP architecture but splits parameters into density and color sub-parameters, freezing the former [12073-clipnerf-training-configuration.md].

### [Binary Radiance Fields](13622-binary-radiance-fields.md)
Binary Radiance Fields (BiRF) replaces real-valued feature grids with binary values (+1 or -1) stored in a multi-resolution 2D-3D hybrid hash encoding architecture [13622-binary-radiance-fields.md]. It uses a 3D voxel grid and 2D plane grids with binary feature vectors, processed by small MLPs (1 hidden layer for density, 2 for color) [13622-binary-radiance-fields.md].

### [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md)
The Mip-NeRF 360 MLP architecture uses Integrated Positional Encoding (IPE) and Integrated Directional Encoding (IDE) to handle anti-aliasing by accounting for the spatial extent (covariance) of query points [14098-mip-nerf-360-mlp-architecture.md]. It builds on the standard NeRF MLP structure but replaces sinusoidal encoding with basis-function-based integrated encoding [14098-mip-nerf-360-mlp-architecture.md].

### SUDS
SUDS uses a multi-resolution hash encoding with spatial partitioning into three separate hash tables (static, dynamic, far-field) to encode large-scale dynamic scenes [14964-suds.md]. It maps 3D/4D coordinates to features via hash indexing and linear/quadlinear interpolation, processed by MLPs for density, color, and flow [14964-suds.md].

### CCNeRF
CCNeRF models the radiance field *only* with tensor rank decomposition (hybrid CP and triple plane variant) without using MLPs for rendering [15008-ccnerf.md]. It uses a rank weights matrix and decomposed rank components, allowing dynamic compression via rank truncation and composition via rank concatenation [15008-ccnerf.md].

### [Rip-NeRF](15532-rip-nerf.md)
Rip-NeRF uses Ripmap-Encoded Platonic Solids to enable efficient anisotropic area-sampling for cone casting [15532-rip-nerf.md]. It characterizes conical frustums with 3D Gaussians, projects them onto Platonic solid faces, and queries a hierarchical feature grid (Ripmap) using tetra-linear interpolation, processed by a tiny MLP [15532-rip-nerf.md].

### [UE4-NeRF](15539-ue4-nerf.md)
UE4-NeRF partitions the scene into sub-NeRFs represented as textured polygonal meshes (regular octahedra) with multi-resolution hash encoding [15539-ue4-nerf.md]. It uses an Encoder MLP (4 layers) to predict opacity/features from hash-encoded positions and a Decoder MLP (3 layers) to predict color from features and spherical harmonics view directions [15539-ue4-nerf.md].

### [Generative Occupancy Fields (GOF)](15773-generative-occupancy-fields-gof.md)
GOF predicts alpha values $\alpha$ directly (interpreted as occupancy) rather than density, using a FiLMed-SIREN generator network [15773-generative-occupancy-fields-gof.md]. It uses root-finding to locate surfaces and shrinks the sampling region around the surface during training [15773-generative-occupancy-fields-gof.md].

### [Panoptic Radiance Field](15849-panoptic-radiance-field.md)
Panoptic Radiance Field uses TensoRF for color and density, and two small MLPs for semantic and instance distributions [15849-panoptic-radiance-field.md]. It outputs density, semantic distribution, instance distribution, and color for any 3D point and viewing direction [15849-panoptic-radiance-field.md].

### [Frequency-Modulated Position Encoding](15897-frequency-modulated-position-encoding.md)
FMPE uses fractional exponents (powers of $2^{0.5}$) instead of integer powers of 2 for sinusoidal positional encoding to provide finer-grained frequency support [15897-frequency-modulated-position-encoding.md]. It maps inputs to a high-dimensional feature space using $\sin(2^k \pi \mathbf{p})$ and $\cos(2^k \pi \mathbf{p})$ where $k \in \{0, 0.5, \dots, L-1\}$ [15897-frequency-modulated-position-encoding.md].

### [MoCo-NeRF](16197-moco-nerf.md)
MoCo-NeRF decomposes the representation into a rigid branch (canonical radiance field) and a non-rigid branch (radiance residuals) [16197-moco-nerf.md]. It uses Multi-Hash Encoding (MHE) for feature query and pose-embedded implicit features generated via cross-attention for non-rigid prediction [16197-moco-nerf.md].

### UrbanIR
UrbanIR uses Instant-NGP spatial hash-based voxel representation with individual MLP headers for intrinsic attributes (albedo, normal, semantics, density) [16200-urbanir.md]. It decodes these intrinsics independently of lighting, enabling relighting via a separate lighting model [16200-urbanir.md].

### Triplane NeRF with Diffusion Prior
Uses a triplane NeRF representation ($\mathbb{R}^{3 \times 6 \times 128 \times 128}$) optimized jointly with a diffusion prior (U-Net with 122M parameters) using v-parameterization and SNR-based weighting [S1].

### EG3D Triplane Representation
Uses a triplane representation $T \in \mathbb{R}^{256 \times 256 \times 96}$ (3 planes, 32 channels each) decoded by a lightweight MLP for features, color, and density [S2]. Renders feature and RGB images at 128x128, then upscales to 512x512 via a 2D super-resolution network [S2].

### NeRF-W Hyperparameter Configuration
Uses an 8-layer 512-unit Base MLP and 4-layer 128-unit Static/Transient MLPs with 15 position frequencies and 4 view direction frequencies [S3].

### Explicit Mesh Reconstruction from Neural Fields
Extracts meshes from CodeNeRF by querying density on a $256^3$ voxel grid and applying Marching Cubes, then casting rays for vertex colors [S4].

### Efficient EndoNeRF scene representation
Replaces coordinate-based MLPs with explicit density and feature volume grids ($\mathbf{V}_\sigma, \mathbf{V}_a$) and models dynamics with a 3-layer MLP deformation field [S5].

### NeRF-Liif
Super-resolves LR images using a pretrained LIIF model, requiring LR-HR pairs and introducing external data priors [S6].

### UniSurf
Unifies volume and surface rendering by using an occupancy field, volume rendering in early stages, and surface rendering in later stages [S7, unofficial].

## Background
The foundational NeRF architecture [Mildenhall et al. 2020] introduced the use of coordinate-based MLPs with sinusoidal positional encoding to represent continuous 3D scenes [S7, unofficial]. Subsequent works have modified this architecture to improve efficiency (Instant-NGP, SUDS), accuracy (Mip-NeRF 360), storage (BiRF, CCNeRF), or capabilities (relighting, dynamic scenes) [S1, S2, S3, S4, S5, S6][S7, unofficial].
