# Panoptic Radiance Field

Also called: Panoptic Lifting

## Overview
Panoptic Lifting learns a panoptic 3D volumetric representation from posed RGB images and machine-generated 2D panoptic segmentation masks, lifting noisy 2D labels into a consistent 3D representation of color, density, semantics, and instances [S1]. It differs from siblings like [Panoptic NeRF](11916-panoptic-nerf.md) and [DM-NeRF](11916-panoptic-nerf.md) by requiring no manual ground truth or coarse meshes, relying solely on pre-trained 2D segmentation inference, and employs specific robustness mechanisms (bounded fields, gradient blocking) to handle label noise [S1].

## How it works
**Inputs:** Posed RGB images $\{I\}$ and corresponding machine-generated 2D panoptic segmentation masks.
**Outputs:** A panoptic radiance field $\Phi(\mathbf{x}, \mathbf{d})$ capable of rendering novel view RGB images, depth, semantic class distributions, and 3D-consistent instance identifiers.

**Data Structures:**
The scene is represented by a function $\Phi: \mathbb{R}^3 \times S^2 \to \mathbb{R} \times \mathcal{K} \times \mathcal{J} \times \mathbb{R}^3$.
1.  **Geometry and Color:** Uses a TensoRF [4] representation. This consists of shared 3D grid features and view-dependent coefficients (lines and planes) to predict density $\sigma \in \mathbb{R}_{\ge 0}$ and color $\mathbf{c} \in \mathbb{R}^3$.
2.  **Semantic Field:** A small Multi-Layer Perceptron (MLP) that takes the encoded 3D position and outputs a semantic class distribution $\boldsymbol{\kappa}$ over the set of classes $\mathcal{K}$.
3.  **Instance Field:** A separate small MLP that takes the encoded 3D position and outputs a distribution $\boldsymbol{\pi}$ over a fixed set of surrogate identifiers $\mathcal{J}$.

**Definitions:**
*   $\mathcal{K}$: Set of semantic classes, partitioned into thing classes $\mathcal{K}_T$ and stuff classes $\mathcal{K}_S$.
*   $\mathcal{J}$: Set of surrogate identifiers. The size $|\mathcal{J}|$ is a fixed hyperparameter.
*   $\mathcal{H}^{3D}$: Set of all possible 3D instances, defined as $\mathcal{H}^{3D} := \mathcal{K}_T \times \mathcal{J}$.
*   Ray $\mathbf{r}$: Parameterized as $\mathbf{r}(t) = \mathbf{p}_0 + t\mathbf{d}_r$, where $\mathbf{p}_0$ is the origin, $\mathbf{d}_r$ is the unit direction, and $t$ is the scalar distance.
*   $\hat{\mathbf{c}}_\mathbf{r}$: Ground truth RGB color for ray $\mathbf{r}$.
*   $\hat{k}_\mathbf{r}$: Semantic class label for ray $\mathbf{r}$.
*   $\hat{h}_\mathbf{r}$: 2D instance ID for ray $\mathbf{r}$ (defined only if $\hat{k}_\mathbf{r} \in \mathcal{K}_T$).

**Preprocessing (Test-Time Augmentation):**
To estimate confidence and robustify labels, test-time augmentations (horizontal flip, scale, brightness, contrast) are applied to input images. The resulting segmentations are fused via segment clustering to produce for each ray $\mathbf{r}$:
1.  A semantic class distribution $\hat{\boldsymbol{\kappa}}_\mathbf{r}$ over $\mathcal{K}$.
2.  A confidence estimate $w_\mathbf{r} \in [0, 1]$.

**Rendering Equation:**
For any vector field $\mathbf{f}$ along ray $\mathbf{r}$ given density $\sigma$:
$$ R[\mathbf{f} | \mathbf{r}, \sigma] := \int_0^\infty \alpha_t(\mathbf{r}) \sigma(\mathbf{r}_t) \mathbf{f}(\mathbf{r}_t, \mathbf{d}_{\mathbf{r}_t}) dt $$
where $\alpha_t(\mathbf{r}) := \exp \left(-\int_0^t \sigma(\mathbf{r}_s) ds \right)$ is the transmittance probability at $t$.
In discrete form (standard volume rendering):
$$ \hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i, \quad T_i = \prod_{j=1}^{i-1} (1 - \alpha_j), \quad \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
The rendered semantic distribution $\boldsymbol{\kappa}_\mathbf{r}$ and instance distribution $\boldsymbol{\pi}_\mathbf{r}$ are computed similarly using the rendering equation on the outputs of the semantic and instance MLPs.

**Training Procedure:**
The total loss is a weighted sum of instance, consistency, RGB, and semantic losses:
$$ L_{tot}(\mathbf{R}) := \lambda_{ins} L_{ins}(\mathbf{R}_I) + \lambda_{con} L_{con}(\mathbf{R}_I) + \lambda_{RGB} L_{RGB}(\mathbf{R}_S) + \lambda_{sem} L_{sem}(\mathbf{R}_S) $$
where $\mathbf{R}_S$ are rays randomly sampled across the scene and $\mathbf{R}_I$ are rays sampled from a single image.

1.  **RGB Loss ($L_{RGB}$):** Standard L2 photometric loss between rendered color $\mathbf{c}_\mathbf{r}$ and ground truth $\hat{\mathbf{c}}_\mathbf{r}$.
2.  **Semantic Loss ($L_{sem}$):** Cross-entropy between rendered distribution $\boldsymbol{\kappa}_\mathbf{r}$ and augmented label distribution $\hat{\boldsymbol{\kappa}}_\mathbf{r}$, weighted by confidence $w_\mathbf{r}$:
    $$ L_{sem}(\mathbf{R}) := -\frac{1}{|\mathbf{R}|} \sum_{\mathbf{r} \in \mathbf{R}} w_\mathbf{r} \sum_{k \in \mathcal{K}} \hat{\boldsymbol{\kappa}}_\mathbf{r}(k) \log \boldsymbol{\kappa}_\mathbf{r}(k) $$
3.  **Instance Loss ($L_{ins}$):**
    *   For each 2D instance $h \in \mathcal{H}_I$ present in the batch, solve a linear assignment problem to map the noisy 2D instance ID $\hat{h}_\mathbf{r}$ to a 3D surrogate identifier $j \in \mathcal{J}$. The cost is based on the model's current predictions and the 2D masks.
    *   Let $\Pi^*_\mathbf{R}$ be the injective mapping from 2D instances to 3D surrogate IDs.
    *   The loss minimizes the log-loss of the rendered instance distribution $\boldsymbol{\pi}_\mathbf{r}$ against the mapped surrogate ID.
4.  **Segment Consistency Loss ($L_{con}$):** An additional loss term to guide semantic supervision, avoiding optima that fragment objects due to label inconsistencies. [G] Typically implemented as a regularization term encouraging spatial smoothness or consistency of semantic predictions among nearby samples along the same ray.
5.  **Gradient Blocking:** Gradients from the semantic and instance branches are stopped from back-propagating to the density $\sigma$ (geometry) parameters. This prevents noisy labels from corrupting the geometry ("cloudy geometry").
6.  **Bounded Segmentation Fields:** The semantic and instance MLPs are constrained to output bounded probability distributions directly, rather than unbounded logits followed by softmax. This prevents significant semantic signals in low-density areas.

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class PanopticRadianceField:
    def __init__(self, num_surrogates, num_classes, tensorf_config):
        # Geometry and Color: TensoRF representation
        self.geometry_color = TensoRF(tensorf_config)
        
        # Semantic Field: Small MLP
        self.semantic_mlp = nn.Sequential(
            nn.Linear(geometry_color.feature_dim, 128),
            nn.ReLU(),
            nn.Linear(128, num_classes)
        )
        
        # Instance Field: Small MLP
        self.instance_mlp = nn.Sequential(
            nn.Linear(geometry_color.feature_dim, 128),
            nn.ReLU(),
            nn.Linear(128, num_surrogates)
        )
        
        # Hyperparameters
        self.lambda_ins = 1.0
        self.lambda_con = 1.35
        self.lambda_rgb = 1.0
        self.lambda_sem = 1.0
        self.num_classes = num_classes
        self.num_surrogates = num_surrogates

    def forward(self, rays_o, rays_d, t_near, t_far, num_samples):
        """
        Renders a single ray.
        Returns: color, density, semantic_dist, instance_dist
        """
        # Sample points along ray
        t_vals = torch.linspace(t_near, t_far, num_samples)
        xyz = rays_o.unsqueeze(1) + rays_d.unsqueeze(1) * t_vals.unsqueeze(0)
        
        # Encode positions using TensoRF
        # Note: TensoRF encoding is complex; simplified here as a feature extraction
        features = self.geometry_color.encode(xyz)
        
        # Predict density
        sigma = self.geometry_color.predict_density(features)
        sigma = torch.clamp(sigma, min=1e-4) # [G] Prevent division by zero
        
        # Predict semantic logits (bounded via sigmoid/softmax later)
        sem_logits = self.semantic_mlp(features)
        # Bounded probability distribution: use Softmax to ensure sum=1 and values in [0,1]
        sem_dist = F.softmax(sem_logits, dim=-1)
        
        # Predict instance logits
        inst_logits = self.instance_mlp(features)
        inst_dist = F.softmax(inst_logits, dim=-1)
        
        # Predict color
        color = self.geometry_color.predict_color(features, rays_d)
        
        # Volume Rendering
        # Compute alphas
        deltas = t_vals[1:] - t_vals[:-1]
        deltas = torch.cat([deltas, torch.tensor([1e10]).to(deltas.device)])
        alpha = 1.0 - torch.exp(-sigma * deltas)
        
        # Transmittance
        transmittance = torch.cumprod(torch.exp(-sigma * deltas), dim=0)
        transmittance = torch.cat([torch.ones_like(transmittance[:, :1]), transmittance], dim=-1)
        
        # Render Color
        weights = alpha * transmittance
        rendered_color = torch.sum(weights.unsqueeze(-1) * color, dim=0)
        
        # Render Semantic Distribution
        rendered_sem_dist = torch.sum(weights.unsqueeze(-1) * sem_dist, dim=0)
        
        # Render Instance Distribution
        rendered_inst_dist = torch.sum(weights.unsqueeze(-1) * inst_dist, dim=0)
        
        return rendered_color, sigma, rendered_sem_dist, rendered_inst_dist

    def compute_loss(self, rays_o, rays_d, t_near, t_far, gt_color, gt_sem_dist, gt_conf, 
                     gt_2d_instances, instance_mapping_cost_fn):
        """
        Computes the total training loss.
        """
        # Forward pass
        pred_color, sigma, pred_sem_dist, pred_inst_dist = self.forward(rays_o, rays_d, t_near, t_far)
        
        # 1. RGB Loss
        loss_rgb = F.mse_loss(pred_color, gt_color)
        
        # 2. Semantic Loss (Cross Entropy weighted by confidence)
        # gt_sem_dist is the distribution from TTA
        # pred_sem_dist is the rendered distribution
        # Stop gradients from semantic branch to geometry is handled by detaching sigma or using detach() on semantic inputs if necessary.
        # Here, we assume the MLPs are separate heads. To stop gradients to geometry, we detach the features used by semantic/instance MLPs 
        # or simply ensure the optimizer doesn't update geometry weights via these heads.
        # In practice, this is done by splitting the optimizer or using .detach().
        loss_sem = -torch.mean(gt_conf * torch.sum(gt_sem_dist * torch.log(pred_sem_dist + 1e-8), dim=-1))
        
        # 3. Instance Loss
        # Map 2D instances to 3D surrogates using linear assignment
        # instance_mapping_cost_fn computes cost matrix between 2D instances and 3D surrogates based on current predictions
        # This step is typically done per batch or globally. Simplified here:
        # Assume we have a mapping function that returns the best surrogate ID for each 2D instance
        mapped_surrogates = instance_mapping_cost_fn(gt_2d_instances, pred_inst_dist)
        
        # Create one-hot targets for mapped surrogates
        inst_targets = F.one_hot(mapped_surrogates, num_classes=self.num_surrogates).float()
        
        # NCE or Cross Entropy loss for instances
        # The source mentions NCE loss for instances. Standard Cross Entropy is a proxy if NCE details are supplementary.
        # We use Cross Entropy here as a standard implementation of supervised classification loss.
        loss_inst = F.cross_entropy(pred_inst_dist, mapped_surrogates)
        
        # 4. Consistency Loss
        # [G] Placeholder for segment consistency loss. Typically encourages smoothness.
        loss_con = 0.0 # Placeholder
        
        # Total Loss
        total_loss = (self.lambda_ins * loss_inst + 
                      self.lambda_con * loss_con + 
                      self.lambda_rgb * loss_rgb + 
                      self.lambda_sem * loss_sem)
        
        return total_loss, loss_rgb, loss_sem, loss_inst

    def render_panoptic(self, rays_o, rays_d, t_near, t_far):
        """
        Renders novel view panoptic segmentation.
        """
        pred_color, sigma, pred_sem_dist, pred_inst_dist = self.forward(rays_o, rays_d, t_near, t_far)
        
        # Get most probable semantic class
        pred_sem_class = torch.argmax(pred_sem_dist, dim=-1)
        
        # Get most probable surrogate ID if class is a 'thing' class
        # Assuming thing classes are known indices
        thing_classes = [...] # Defined by dataset
        pred_inst_id = torch.full_like(pred_sem_class, -1)
        
        is_thing = torch.isin(pred_sem_class, thing_classes)
        if torch.any(is_thing):
            pred_surrogate = torch.argmax(pred_inst_dist[is_thing], dim=-1)
            pred_inst_id[is_thing] = pred_surrogate
            
        # 3D Instance ID is pair (sem_class, surrogate)
        return pred_color, pred_sem_class, pred_inst_id
```

**Edge Cases and Pitfalls:**
*   **Unbounded Logits:** Rendering class logits instead of probabilities allows the model to generate significant semantic signals in low-density areas, violating geometric constraints. This is resolved by rendering bounded probability distributions (softmax) [S1].
*   **Geometry Corruption:** Supervision from noisy 2D labels can influence geometry, causing "cloudy" geometry to satisfy conflicting labels. This is avoided by stopping gradients from segmentation branches back to densities [S1].
*   **Label Noise:** Machine-generated labels are noisy and inconsistent across views. Test-time augmentations and confidence weighting are required to mitigate this [S1].
*   **Instance Inconsistency:** 2D instance IDs are not preserved across views. Linear assignment is used to map 2D instances to 3D surrogate IDs consistently [S1].

## Operating characteristics
*   **Time Complexity:** Training is iterative and requires 450k iterations (~10 hours on 1 NVIDIA A6000) [S1]. Rendering is comparable to standard NeRF but includes additional MLP evaluations for semantics and instances.
*   **Memory Complexity:** Depends on the TensoRF grid size and the number of surrogate identifiers. The instance field holds a fixed number of surrogates [S1].
*   **Performance:** Improves scene-level Panoptic Quality (PQ) by 8.4% on Hypersim, 13.8% on Replica, and 10.6% on ScanNet over state-of-the-art methods [S1]. Maintains comparable PSNR for novel view synthesis [S1].
*   **Strengths:** Robust to noise in machine-generated labels; requires no manual 3D ground truth; enables scene editing (deletion, duplication, manipulation) [S1].
*   **Limitations:** Offline process due to pose estimation and segmentation inference; limited to classes supported by the pre-trained 2D segmenter (e.g., Mask2Former) [S1].

## Background
Panoptic Lifting was introduced in "Panoptic Lifting for 3D Scene Understanding with Neural Fields" (CVPR 2023) [S1]. It addresses the limitations of prior panoptic NeRF methods (Panoptic NeRF, DM-NeRF) which required manual ground truth or coarse meshes. It builds on [TensoRF](13550-model-architecture-and-encoding.md) for efficient geometry and color representation.
