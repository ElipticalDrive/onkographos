# Forward Warping for Novel View Synthesis

Also called: Canonical Field Forward Warping, Forward Flow

## Overview
Forward Warping for Novel View Synthesis is a method for rendering dynamic scenes by modeling a static scene at a canonical time step and forward warping the entire canonical radiance field to other time steps [S1]. It addresses the many-to-one and one-to-many mapping difficulties inherent in dynamic scene reconstruction by using differentiable forward warping with average splatting and an inpaint network [S1]. Unlike backward flow methods such as NDVG, this approach achieves superior performance, particularly for canonical frames, by explicitly warping the field rather than estimating flow for each ray [S1].

## How it works
The method operates in two stages: a coarse stage to learn proxy geometry and a fine stage for high-fidelity rendering. It relies on a canonical space where the scene is static, and deformation fields map canonical coordinates to time $t$.

### Inputs and Outputs
*   **Inputs:** A set of images $\{I_i\}$ with known camera poses and timestamps $\{t_i\}$. The canonical time $t_{can}$ is selected (first frame for D-NeRF, middle frame for HyperNeRF) [S1].
*   **Outputs:** A rendered image $C(\mathbf{r})$ for a query ray $\mathbf{r}$ at time $t$.

### Data Structures
The method maintains several voxel grids and neural networks. All grids are 3D voxel structures.

**Voxel Grids:**
1.  **Canonical Radiance Feature Grid ($V_{Rf}$):** Stores radiance features. Dimension: 12 [S1].
2.  **Canonical Coordinate Grid ($V_{rCan}$):** Stores the 3D coordinate of each voxel center [S1].
3.  **Canonical Density Grid ($V_{\sigma}^{Can}$):** Stores canonical density values $\sigma$ [S1].
4.  **Canonical Color Feature Grid ($V_{cf}^{Can}$):** Stores color features. Dimension: 3 (coarse) or 12 (fine) [S1].
5.  **Canonical Deformation Feature Grid ($V_{Df}^{Can}$):** Stores deformation features. Dimension: 0 for D-NeRF, 12 for HyperNeRF [S1].
6.  **Trajectory Grid ($V_{Tt}$):** Stores Discrete Cosine Transform (DCT) parameters for each voxel's trajectory [S1].
7.  **Deformation Flow Grid ($V_{flow}$):** Stores the deformation flow vector from canonical space to time $t$ for each voxel [S1].
8.  **Warped Radiance Field ($V_{Rt}$):** The radiance field at time $t$ after warping from $V_{Rf}$ [S1].
9.  **Inpainted Radiance Field ($V_{Rt}^{Inp}$):** The warped field after processing by the inpaint network [S1].
10. **Upsampled Radiance Field ($V_{Rt}^{Up}$):** The field after upsampling [S1].

**Neural Networks:**
1.  **Canonical Radiance Network ($F_{\theta_1}$):** 3-layer MLP, width 128, ReLU activation. Input: radiance feature from $V_{Rf}$ (dim 12) + embedded position (dim 33). Output: density (dim 1) + color feature (dim 3 or 12) [S1].
2.  **Canonical Deformation Network ($F_{\theta_2}$):** 4-layer MLP, width 64. Input: deformation feature from $V_{Df}^{Can}$ (dim 0 or 12) + embedded position (dim 33). Output: deformation parameters [S1].
3.  **View Dependent Color Network ($F_{\theta_4}$):** 2-layer MLP, width 64. Input: embedded view direction (dim 27) + color feature (dim 12). Output: RGB color (dim 3) [S1].
4.  **Inpaint Network ($F_{\theta_3}$):** UNet structure with 4 encode layers and 3 decode layers, plus an upsample layer. Encode layers: max pooling + 2 convolutions. Decode layers: up-sample interpolation + 2 convolutions. Convolutions use instance norm followed by convolution and ReLU [S1].

### Numbered Steps

**1. Initialization**
Initialize voxel grids $V_{Rf}, V_{rCan}, V_{\sigma}^{Can}, V_{cf}^{Can}, V_{Df}^{Can}, V_{Tt}$ with zeros or small random values. Initialize networks $F_{\theta_1}, F_{\theta_2}, F_{\theta_4}, F_{\theta_3}$ [S1].

**2. Coarse Stage Training**
*   **Voxel Resolution:** $6^3$ [S1].
*   **Inpaint Scale:** 1.5 [S1].
*   **Iterations:** 20,000 [S1].
*   **Process:**
    1.  Sample rays.
    2.  Query $F_{\theta_1}$ for density and color features using canonical coordinates.
    3.  Compute deformation flow $V_{flow}$ using $F_{\theta_2}$ and DCT parameters from $V_{Tt}$ [S1].
    4.  **Forward Warping:** Use average splatting to warp $V_{Rf}$ to time $t$ to create $V_{Rt}$ [S1]. Average splatting is used instead of softmax splatting to reduce complexity, as softmax showed no obvious improvement [S1].
    5.  Render from $V_{Rt}$ to compute loss.
    6.  **Note:** The inpaint network $F_{\theta_3}$ is **not** used in the coarse stage [S1].
*   **Loss Weights (Coarse):** $w_1=10^{-1}, w_2=10^{-2}, w_3=10^{-5}, w_4=0, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$ [S1].

**3. Fine Stage Training**
*   **Voxel Resolution:** $8^3$ for D-NeRF, $7^3$ for HyperNeRF [S1].
*   **Inpaint Scale:** 2.0 [S1].
*   **Iterations:** 100,000 [S1].
*   **Progressive Training:** Start with 10 images closest to $t_{can}$. Add one image with the closest time step every 60 iterations [S1].
*   **Process:**
    1.  Sample rays.
    2.  Query $F_{\theta_1}$ for density and color features.
    3.  Compute deformation flow $V_{flow}$ [S1].
    4.  **Forward Warping:** Warp $V_{Rf}$ to $V_{Rt}$ using average splatting [S1].
    5.  **Inpainting:** Pass $V_{Rt}$ through $F_{\theta_3}$ to get $V_{Rt}^{Inp}$ [S1].
    6.  **Upsampling:** Upsample $V_{Rt}^{Inp}$ to get $V_{Rt}^{Up}$ [S1].
    7.  Render from both $V_{Rt}^{Inp}$ and $V_{Rt}^{Up}$ to compute losses [S1].
*   **Loss Weights (Fine):** $w_1=10^{-2}, w_2=10^{-3}, w_3=10^{-5}, w_4=10^{-5}, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$ [S1].

**4. Rendering**
For a query ray $\mathbf{r}$ at time $t$:
1.  Sample points $w_k$ along $\mathbf{r}$.
2.  Get deformation flow $V_{flow}$ at $w_k$ to warp canonical coordinates to time $t$.
3.  Query $F_{\theta_1}$ for $\sigma$ and color features at warped coordinates.
4.  Query $F_{\theta_4}$ for RGB color using color features and embedded view direction [S1].
5.  Compute accumulated color $C(\mathbf{r})$ using standard volume rendering [S1].

### Formulas

**Point-wise Color Loss ($\mathcal{L}_{ptc}$):**
Supervises the color of sampled points weighted by their accumulation.
$$ \mathcal{L}_{ptc} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Up}}(\mathbf{r})) $$
where
$$ \mathcal{L}(\mathbf{C}(\mathbf{r})) = \frac{1}{K} \sum_{k=1}^{K} A_{\text{accum}}(k) \|\mathbf{c}(w_k) - \mathbf{C}_{\text{gt}}(\mathbf{r})\|_2^2 $$
and
$$ A_{\text{accum}}(k) = T(w_k) \, \sigma(w_k) \delta_k $$
$\mathbf{C}_{\text{Inp}}$ and $\mathbf{C}_{\text{Up}}$ are colors rendered from the inpainted and upsampled fields respectively. $T(w_k)$ is the transmittance, $\sigma(w_k)$ is density, and $\delta_k$ is the segment length [S1].

**Background Entropy Loss ($\mathcal{L}_{bg}$):**
Encourages densities to concentrate on foreground or background.
$$ \mathcal{L}_{bg} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Up}}(\mathbf{r})) $$
where
$$ \mathcal{L}(\mathbf{A}(\mathbf{r})) = -\frac{1}{K-1} \sum_{k=1}^{K-1} \left[ A_{\text{accum}}(k)\log(A_{\text{accum}}(k)) + (1-A_{\text{accum}}(k))\log(1-A_{\text{accum}}(k)) \right] $$
[ S1]

**Total Loss:**
$$ \mathcal{L} = \mathcal{L}_{photo} + w_1\mathcal{L}_{ptc} + w_2\mathcal{L}_{bg} + w_3\mathcal{L}_{flow} + w_4\mathcal{L}_{vdiff} + w_5\mathcal{L}_{tv}(\mathbf{V}_{\sigma}^{\text{Can}}) + w_6\mathcal{L}_{tv}(\mathbf{V}_{\text{flow}}^t) + w_7\mathcal{L}_{tv}(\mathbf{D}) $$
$\mathcal{L}_{photo}$ is the standard photometric loss. $\mathcal{L}_{flow}$ and $\mathcal{L}_{vdiff}$ are flow and video difference losses (weights $w_3, w_4$). $\mathcal{L}_{tv}$ is total variation loss. $\mathbf{D}$ likely refers to deformation parameters or similar regularized field [S1].

### Parameters
*   **Learning Rate:** $10^{-1}$ for voxel grids, $10^{-3}$ for networks [S1].
*   **Optimizer:** Adam [S1].
*   **DCT Bases:** 15 for D-NeRF, 25 for HyperNeRF [S1].
*   **Embedding Dimensions:** Position 33, View Direction 27 [S1].

### Edge Cases and Pitfalls
*   **Memory Consumption:** High, especially for real scenes [S1].
*   **Training Speed:** Slow, approximately one day per scene on GeForce RTX 3090 [S1].
*   **Coarse Stage Importance:** Removing the coarse stage causes significant performance drops because the voxel grid covers a larger space without proxy geometry filtering [S1].
*   **Inpaint Network:** Removing the inpaint network significantly reduces performance (e.g., Hell Warrior PSNR drops from 27.71 to 27.15) [S1].
*   **Canonical Time Selection:** Setting canonical time to the middle frame improves performance for HyperNeRF as the geometry is closer to other time steps [S1].

## Operating characteristics
*   **Time Complexity:** Training is slow, taking ~1 day per scene [S1]. Rendering is slow, 7s per image for D-NeRF, 15s per image for HyperNeRF [S1].
*   **Memory Complexity:** High memory consumption due to multiple voxel grids and large model size (260M parameters for D-NeRF, 440M for HyperNeRF) [S1].
*   **Strengths:** SOTA performance on public datasets, especially for canonical frames. Clear advantage over backward flow methods like NDVG [S1].
*   **Limitations:** High memory usage, slow training and rendering speeds [S1].

## Background
The method was proposed in "Forward Flow for Novel View Synthesis of Dynamic Scenes" [S1]. It builds on the principle of canonical space representation shared by methods like KFD-NeRF [15551-kfd-nerf.md] but distinguishes itself by using forward warping of the entire field rather than backward flow estimation. It addresses limitations of previous dynamic NeRF methods by explicitly handling the many-to-one and one-to-many mapping issues through differentiable forward warping and inpainting.
