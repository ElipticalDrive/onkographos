# Part-Wise NARF (NARFP)

## Overview
Part-Wise NARF (NARFP) is a neural articulated radiance field method that models an articulated object by training a separate Ray-Traced NeRF (RT-NeRF) for each rigid part, combining their outputs to estimate global density and color [S1]. It differs from holistic approaches by explicitly computing rigid transformations via forward kinematics, thereby avoiding implicit transformation issues and part dependency problems inherent in other methods [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A kinematic 3D pose configuration of an articulated object $\{T_0, \boldsymbol{\zeta}, \boldsymbol{\theta}\}$, where $T_0$ is the root transformation, $\boldsymbol{\zeta}$ represents global parameters, and $\boldsymbol{\theta}$ represents joint angles [S1]. A global 3D location $\mathbf{x}$ and a 2D viewing direction $\mathbf{d}$ [S1].
*   **Outputs:** Rendered color $C(\mathbf{r})$ and optionally a foreground mask $M(\mathbf{r})$ or segmentation mask $S_i(\mathbf{r})$ [S1].

**Data Structures:**
*   **Parts:** The object is decomposed into $P$ rigid parts.
*   **RT-NeRFs:** A set of $P$ separate RT-NeRF models, denoted as $F_{\Theta^i}^{l^i, \boldsymbol{\zeta}}$ for part $i$, where $i \in \{1, \dots, P\}$ [S1]. Each model has its own weights $\Theta^i$ and local coordinate frame $l^i$ [S1].
*   **Transformations:** Global rigid transformations $\{l_i \mid i = 1, \dots, P\}$ computed via forward kinematics [S1].

**Numbered Steps:**
1.  **Compute Global Transformations:** Given the kinematic pose $\{T_0, \boldsymbol{\zeta}, \boldsymbol{\theta}\}$, compute the global rigid transformation $l_i$ for each rigid part $i$ using forward kinematics [S1].
2.  **Transform Coordinates:** For a global 3D location $\mathbf{x}$ and viewing direction $\mathbf{d}$, transform the coordinates for each part $i$ into the local coordinate frame of that part:
    $$ \mathbf{x}^i = R^{i-1}(\mathbf{x} - \mathbf{t}^i) $$
    $$ \mathbf{d}^i = R^{i-1}\mathbf{d} $$
    where $R^{i-1}$ and $\mathbf{t}^i$ are the rotation and translation components of the transformation from the parent frame to part $i$ [S1].
3.  **Estimate Part Properties:** Estimate the density $\sigma^i$ and color $c^i$ for each part $i$ using its specific RT-NeRF $F_{\Theta^i}^{l^i, \boldsymbol{\zeta}}$. The input to the network includes positional encoding $\gamma(\mathbf{x}^i)$, directional encoding $\gamma(\mathbf{d}^i)$, and potentially other embeddings $\gamma(\boldsymbol{\xi}^i)$ and global parameters $\gamma(\boldsymbol{\zeta})$ [S1]:
    $$ (\sigma^i, c^i) = F_{\Theta^i}^{l^i, \boldsymbol{\zeta}}(\gamma(\mathbf{x}^i), \gamma(\mathbf{d}^i), \gamma(\boldsymbol{\xi}^i), \gamma(\boldsymbol{\zeta})) $$
4.  **Combine Densities and Colors:** Combine the density and color estimates $\{\sigma^i, c^i \mid i = 1, \dots, P\}$ from all parts using a soft-max weighted sum to determine the global density $\sigma$ and color $c$. This avoids the non-differentiable max operation [S1]:
    $$ \sigma = \frac{\sum_{i=1}^P \exp(\sigma^i/\tau) \sigma^i}{\sum_{i=1}^P \exp(\sigma^i/\tau)} $$
    $$ c = \frac{\sum_{i=1}^P \exp(\sigma^i/\tau) c^i}{\sum_{i=1}^P \exp(\sigma^i/\tau)} $$
    where $\tau$ is the temperature parameter of the soft-max function [S1].
5.  **Volume Rendering:** Apply volume rendering using the combined density $\sigma$ and color $c$ to generate the rendered color $C(\mathbf{r})$ along a camera ray $\mathbf{r}$ [S1].
6.  **Estimate Masks (Optional):** Estimate the foreground mask $M(\mathbf{r})$ as the integral of opacity along the camera ray, weighted by the index of the part with the highest density. Specifically, let $s_j(\mathbf{r})$ be the index of the part with the greatest density at sample $j$. The segmentation mask $S_i(\mathbf{r})$ for part $i$ is:
    $$ S_i(\mathbf{r}) = \sum_{j=1}^N T_j (1 - \exp(-\sigma_j \delta_j)) (s_j(\mathbf{r}) == i) $$
    where $T_j$ is the transmittance, $\sigma_j$ is the density, and $\delta_j$ is the distance between samples [S1].

**Parameters:**
*   $\tau$: Temperature parameter of the soft-max function, used to control the sharpness of the weighting between parts [S1]. Typical values are not specified in the sources.

**Pitfalls and Edge Cases:**
*   **Non-differentiability:** The max operation for selecting the highest density part is not differentiable, so a soft-max function is used instead to allow gradient propagation for training [S1].
*   **Zero-Density Samples:** Training is dominated by zero-density point samples because a surface point belongs to only one part, resulting in zero density for all other parts. This makes the computation inefficient as parts with small densities do not significantly affect the final value but still require evaluation [S1].

## Operating characteristics
*   **Complexity:** Computational cost is proportional to the number of object parts $P$, limiting representation capacity for complex articulated objects [S1].
*   **Training Efficiency:** Training is dominated by zero-density point samples because a surface point belongs to only one part, resulting in zero density for all other parts. This makes the computation inefficient [S1].
*   **Strengths:** Explicitly computes rigid transformations via forward kinematics, avoiding implicit transformation issues and part dependency problems inherent in other methods [S1].
*   **Limitations:** Computationally expensive due to the linear scaling with the number of parts and the inefficiency of evaluating zero-density parts [S1].

## Background
Part-Wise NARF (NARFP) was introduced in the paper "Neural Articulated Radiance Field" [S1]. It is one of three types of neural articulated radiance fields proposed, alongside Holistic NARF (NARFH) and Disentangled NARF [S1].
