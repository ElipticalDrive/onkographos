# StyleRF-VolVis
## Overview
StyleRF-VolVis is a framework for editing the style (appearance) of a DVR scene represented by a NeRF model without losing original content (geometry) information [S1]. It supports both photorealistic (PSE) and non-photorealistic (NPSE) editing in a single pipeline by separating content and appearance, allowing explicit assignment of different styles to different DVR regions via a Palette Color Network (PCN) and an Unrestricted Color Network (UCN), while preserving view-dependent lighting [S1]. It differs from prior works by supporting both photorealistic and non-photorealistic editing in a single framework, whereas others focus on one or the other [S1].
## How it works
**Inputs and Outputs:**
*   **Inputs:** Multi-view images of the scene, an initial Transfer Function (TF) defining opacity ranges, and optionally reference images for style transfer [S1].
*   **Outputs:** A stylized DVR scene represented by the optimized networks, allowing for interactive PSE and NPSE [S1].

**Data Structures:**
1.  **Base NeRF Model:** Uses Instant-NGP architecture [S1].
    *   **Density MLP:** Takes position $x$ and hash-grid encoded features; outputs density $\sigma(x)$ [S1].
    *   **Hash-grid Encoder:** Multiresolution hash-grid encoding for efficient optimization [S1].
    *   *Note:* Parameters are frozen after Stage 1 [S1].
2.  **Palette Color Network (PCN):** Composed of two branches [S1].
    *   **Specular Branch (Lighting MLP):**
        *   Inputs: Geometry features (from density MLP) and spherical harmonics (SH) encoded view direction $d$ [S1].
        *   Output: Grayscale specular color $c_s(x, d)$ [S1].
    *   **Diffuse Branch (Palette MLP):**
        *   Inputs: Features from palette hash-grid encoder $E_p$ [S1].
        *   Outputs: Intensity $I(x)$, weights $\omega_i(x)$ for $N_P$ palette colors, and color offsets $\delta_i(x)$ [S1].
    *   **Palette Colors:** $P = \{P_1, ..., P_{N_P}\}$, extracted and refined from input images [S1].
3.  **Unrestricted Color Network (UCN):**
    *   Architecture: Similar to the diffuse branch but without palette constraints [S1].
    *   Inputs: Geometry features (no view direction $d$ during optimization to ensure cross-view consistency) [S1].
    *   Output: Diffuse color $c_d(x)$ [S1].

**Numbered Steps:**

1.  **Stage 1: Base NeRF Optimization**
    *   Optimize the base NeRF model (Instant-NGP) to reconstruct scene geometry using the loss $L_{BASE}$ [S1]:
        $$ L_{BASE} = ||c(r) - \hat{c}(r)||_2^2 $$
        where $c(r)$ is ground-truth color and $\hat{c}(r)$ is predicted color [S1].
    *   Freeze all parameters of the base NeRF (density MLP and hash-grid encoder) to prevent style editing from affecting geometry [S1].

2.  **Palette Refinement**
    *   Extract initial palette colors $P_{CONVEX}$ using the RGB convex hull method from multi-view images [S1].
    *   Refine the palette by removing similar colors [S1]. Calculate the distance between colors in HSB space using only the hue component [S1]. If the distance is below a threshold, remove the color [S1].
    *   Determine the final number of palette colors $N_P$ [S1].

3.  **Stage 2: PCN Optimization (PSE)**
    *   Initialize the PCN [S1]. Initialize shallow layers of the palette MLP with hidden parameters from the base NeRF’s color function [S1].
    *   Optimize PCN parameters and palette colors $P$ using the loss $L_{PALETTE}$ [S1]:
        $$ L_{PALETTE} = ||c(r) - \hat{c}(r)||_2^2 + \lambda_\delta \sum_{i=1}^{M} \sum_{j=1}^{N_P} ||\delta_j(x_i)||_2^2 $$
        where $\lambda_\delta = 0.1$ is the regularization strength [S1].
    *   The predicted color $c(x, d)$ is computed as [S1]:
        $$ c(x, d) = c_s(x, d) + I(x) \sum_{i=1}^{N_P} \omega_i(x)(P_i + \delta_i(x)) $$
    *   Render $\hat{c}(r)$ using the standard NeRF volume rendering equation [S1]:
        $$ \hat{c}(r) = \sum_{i=1}^{M} \alpha_i (1 - \omega_i) c(x_i, d) $$
        where $\omega_i = \exp(-(t_i - t_{i-1})\sigma(x_i))$ is transmittance, $\alpha_i = \prod_{j=1}^{i-1} \omega_j$ is attenuation, and $r=(o,d)$ is the ray [S1].

4.  **Photorealistic Style Editing (PSE) Setup**
    *   For PSE, compute the difference $\Delta P$ between the original palette $P$ and target palette $P'$ in HSB space [S1].
    *   Add $\Delta P_i$ to $P_i + \delta_i(x)$ in the color equation [S1].
    *   For opacity/lighting editing, multiply $\sigma(x_{P_i})$ or $c_s(x_{P_i}, d)$ by a scalar [S1].

5.  **Stage 3: UCN Optimization (NPSE) via Knowledge Distillation (KD)**
    *   **Initialization:** Perform color transfer in the PCN (teacher) to match target style colors [S1]. This ensures the UCN (student) color representation matches selected styles before NPSE [S1].
    *   **Optimization:** Optimize the UCN using KD to transfer color knowledge from the PCN [S1].
    *   Remove view direction input in UCN optimization to ensure cross-view consistency during NPSE [S1].
    *   Optimize on a single camera view by rendering different regions independently to map a style to a region [S1].
    *   Utilize the additional lighting MLP (optimized in Stage 2) to preserve DVR lighting during NPSE, keeping view directions for lighting calculation [S1].

6.  **Inference**
    *   For partial stylization, combine color representations: regions preserving original appearance use colors from PCN; stylized regions use UCN [S1].
    *   Perform additional feedforward steps of the lighting MLP to provide lighting information [S1].

**Pseudocode:**

```python
import math

def optimize_params(params, loss_fn, lr, steps):
    """Standard parameter update loop."""
    for _ in range(steps):
        loss = loss_fn()
        loss.backward()
        for p in params:
            if p.grad is not None:
                p -= lr * p.grad
                p.grad.zero_()

def extract_convex_hull_colors(images):
    """Extract initial palette using RGB convex hull method."""
    # Flatten all pixel RGB values from multi-view images
    all_colors = [pixel.rgb for img in images for pixel in img.pixels]
    # Compute convex hull vertices in RGB space
    return convex_hull_vertices(all_colors)

def refine_palette(P, hue_threshold):
    """Remove similar colors based on hue distance in HSB space."""
    refined = []
    for color in P:
        h, s, b = rgb_to_hsb(color)
        is_similar = False
        for existing in refined:
            h_ex, _, _ = rgb_to_hsb(existing)
            if abs(h - h_ex) < hue_threshold:
                is_similar = True
                break
        if not is_similar:
            refined.append(color)
    return refined

def transfer_style_colors(P, target_palette):
    """Compute delta P in HSB space and add to original palette."""
    new_P = []
    for i, (p_orig, p_target) in enumerate(zip(P, target_palette)):
        h_o, s_o, b_o = rgb_to_hsb(p_orig)
        h_t, s_t, b_t = rgb_to_hsb(p_target)
        delta_h = h_t - h_o
        delta_s = s_t - s_o
        delta_b = b_t - b_o
        new_color = hsb_to_rgb(h_o + delta_h, s_o + delta_s, b_o + delta_b)
        new_P.append(new_color)
    return new_P

def render_volume(ray_o, ray_d, density_fn, color_fn, M=128):
    """Standard volume rendering with M samples."""
    t_start, t_end = 0.0, 1.0
    dt = (t_end - t_start) / M
    transmittance = 1.0
    accumulated_color = [0.0, 0.0, 0.0]
    for i in range(M):
        t = t_start + i * dt
        x = ray_o + t * ray_d
        sigma = density_fn(x)
        alpha = 1.0 - math.exp(-sigma * dt)
        c = color_fn(x, ray_d)
        accumulated_color += alpha * transmittance * c
        transmittance *= (1.0 - alpha)
    return accumulated_color

def train_base_nerf(images, tf, lr=0.01, steps=10000):
    density_mlp, hash_grid = init_instant_ngp()
    def loss_fn():
        ray_o, ray_d = sample_rays_from_image(images[0])
        points, depths = sample_points_along_ray(ray_o, ray_d, density_mlp, M=128)
        sigma = density_mlp(points, hash_grid)
        c_pred = render_volume(ray_o, ray_d, lambda x: density_mlp(x, hash_grid), lambda x, d: base_color_fn(x, d, hash_grid))
        c_gt = images[0].color
        return mse(c_gt, c_pred)
    optimize_params([density_mlp.parameters(), hash_grid.parameters()], loss_fn, lr, steps)
    return density_mlp, hash_grid

def train_pcn(density_mlp, hash_grid, images, ref_images, lr=0.001, steps=5000):
    P_convex = extract_convex_hull_colors(ref_images)
    P = refine_palette(P_convex, hue_threshold=0.15)
    N_P = len(P)
    lighting_mlp = init_lighting_mlp()
    palette_mlp = init_palette_mlp()
    init_palette_mlp_shallow(palette_mlp, density_mlp)
    
    def loss_fn():
        ray_o, ray_d = sample_rays_from_image(images[0])
        points, depths = sample_points_along_ray(ray_o, ray_d, density_mlp, M=128)
        geo_features = density_mlp(points, hash_grid)
        view_dir_sh = encode_spherical_harmonics(ray_d, degree=3)
        c_s = lighting_mlp(geo_features, view_dir_sh)
        palette_features = palette_mlp(points, hash_grid)
        I = intensity(palette_features)
        weights = softmax(palette_weights(palette_features), dim=-1)
        delta = color_offsets(palette_features)
        c_d = I * sum(weights[i] * (P[i] + delta[i]) for i in range(N_P))
        c = c_s + c_d
        c_pred = render_volume(ray_o, ray_d, lambda x: density_mlp(x, hash_grid), lambda x, d: c)
        c_gt = images[0].color
        mse_loss = mse(c_gt, c_pred)
        reg_loss = 0.1 * sum(norm(delta[i])**2 for i in range(N_P))
        return mse_loss + reg_loss
    optimize_params([lighting_mlp.parameters(), palette_mlp.parameters(), P], loss_fn, lr, steps)
    return lighting_mlp, palette_mlp, P

def train_ucn(lighting_mlp, palette_mlp, P, images, target_style_ref, lr=0.001, steps=3000):
    P = transfer_style_colors(P, target_style_ref)
    N_P = len(P)
    ucn = init_ucn()
    
    def loss_fn():
        ray_o, ray_d = sample_rays_from_image(images[0])
        points, depths = sample_points_along_ray(ray_o, ray_d, density_mlp, M=128)
        geo_features = density_mlp(points, hash_grid)
        view_dir_sh = encode_spherical_harmonics(ray_d, degree=3)
        c_s_teacher = lighting_mlp(geo_features, view_dir_sh)
        palette_features = palette_mlp(points, hash_grid)
        I_t = intensity(palette_features)
        w_t = softmax(palette_weights(palette_features), dim=-1)
        d_t = color_offsets(palette_features)
        c_d_teacher = I_t * sum(w_t[i] * (P[i] + d_t[i]) for i in range(N_P))
        c_teacher = c_s_teacher + c_d_teacher
        ucn_features = ucn(points, hash_grid)
        c_d_student = ucn_output(ucn_features)
        return mse(c_d_student, c_d_teacher)
    optimize_params(ucn.parameters(), loss_fn, lr, steps)
    return ucn

def render_stylized(ray_o, ray_d, density_mlp, hash_grid, lighting_mlp, palette_mlp, P, ucn, region_mask, M=128):
    points, depths = sample_points_along_ray(ray_o, ray_d, density_mlp, M=M)
    geo_features = density_mlp(points, hash_grid)
    view_dir_sh = encode_spherical_harmonics(ray_d, degree=3)
    c_s = lighting_mlp(geo_features, view_dir_sh)
    palette_features = palette_mlp(points, hash_grid)
    I_p = intensity(palette_features)
    w_p = softmax(palette_weights(palette_features), dim=-1)
    d_p = color_offsets(palette_features)
    c_d_pcn = I_p * sum(w_p[i] * (P[i] + d_p[i]) for i in range(len(P)))
    ucn_features = ucn(points, hash_grid)
    c_d_ucn = ucn_output(ucn_features)
    c_d = where(region_mask, c_d_ucn, c_d_pcn)
    c = c_s + c_d
    return render_volume(ray_o, ray_d, lambda x: density_mlp(x, hash_grid), lambda x, d: c)
```

**Parameters:**
*   $\lambda_\delta = 0.1$: Regularization strength for color offsets [S1].
*   Initial Transfer Function (TF): Defines opacity ranges [S1]. Regions with opacity equal to zero in the initial TF cannot be represented by NeRF and thus cannot undergo PSE or NPSE [S1].
*   Palette Refinement Threshold: Hue distance threshold in HSB space for removing similar colors [S1].

**Edge Cases and Pitfalls:**
*   **Zero Opacity:** If the initial TF sets opacity to zero for certain regions, NeRF cannot represent these values, and PSE/NPSE cannot be applied to them [S1].
*   **Similar Colors:** If colors among different regions in the input DVR scene are similar, palette refinement may not separate them correctly [S1]. Users must manually adjust the number of palette colors and their RGB values [S1].
*   **Lighting Direction:** Lighting direction cannot be modified because no normal information is available, although lighting intensity can be adjusted [S1].
*   **NPSE Consistency:** Discarding view direction in UCN is necessary for cross-view consistency but requires careful initialization via PSE color transfer to avoid inaccurate style matching [S1].

## Operating characteristics
*   **Time Complexity:** Training is slower than ARF but faster than SNeRF [S1]. The process involves three stages: Base NeRF, PCN, and UCN (KD) [S1]. NPSE optimization on a single camera view requires rendering different regions independently, slowing the stylization process [S1].
*   **Memory Complexity:** Uses Instant-NGP hash-grid encoding, which is memory efficient compared to dense voxel grids [S1]. Additional memory is required for PCN and UCN parameters [S1].
*   **Measured Performance:** Inference time on combustion dataset is 564 ms [S1]. Training time on combustion dataset is 1.2 h [S1]. Training time on vortex dataset is 29.7 m [S1]. Inference time on vortex dataset is 373 ms [S1]. StyleRF-VolVis achieves the best short- and long-range cross-view consistency (MSE and LPIPS) compared to AdaIN, ReReVST, ARF, and SNeRF [S1].
*   **Strengths:** Supports both PSE and NPSE in a single framework [S1]. Preserves view-dependent lighting [S1]. Allows explicit assignment of different styles to different regions [S1]. Achieves better cross-view consistency than image-based methods [S1].
*   **Limitations:** Slower training than ARF [S1]. Interactive PSE is supported but interactive NPSE is not [S1]. Cannot modify lighting direction [S1]. Sensitive to similar colors in input [S1].
*   **When to use:** When high-quality, cross-view consistent stylization of DVR scenes is required, especially when mixing PSE and NPSE or applying different styles to different regions [S1].
*   **When not to use:** When real-time interactive NPSE is required, or when lighting direction modification is needed [S1].

## Background
StyleRF-VolVis is the first work in VolVis that targets style transfer in the NeRF space [S1]. It builds on NeRF representation and Instant-NGP architecture [S1]. It adapts NeRF's palette-based recoloring strategy and uses Knowledge Distillation (KD) to transfer color knowledge [S1]. It differs from prior works like ARF and SNeRF by supporting both photorealistic and non-photorealistic editing in a single framework and preserving view-dependent lighting [S1].
