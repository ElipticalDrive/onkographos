# Vox-Surf

Also called: Voxel-based Implicit Surface Representation

## Overview
Vox-Surf is a voxel-based neural implicit surface representation that combines explicit sparse voxel structures with neural implicit surface representations to enable efficient surface reconstruction and realistic rendering from multi-view posed images [S1]. It differs from traditional voxel-based methods by storing only trainable embeddings at voxel corners rather than explicit SDF or color values, and from dense neural implicit methods by restricting learning to occupied space via a sparse hierarchical octree [S1]. This approach reduces sampling in empty areas, allowing for finer surface details with larger voxels and a lightweight network [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of multi-view posed images (and optionally depth sensors), camera poses, and an approximate bounding box of the scene [S1].
*   **Outputs:** A sparse octree of voxels with optimized vertex embeddings, from which a surface mesh can be extracted (zero-level set) and images can be rendered [S1].

**Data Structures:**
*   **Voxel Structure:** The scene is divided into a set of coarse voxels $V = \{V_1, ..., V_k\}$ forming the leaf nodes of a sparse hierarchical octree [S1].
*   **Vertex Embeddings:** Each voxel has eight corner vertices. Each vertex stores a fixed-length trainable embedding vector $e \in \mathbb{R}^{L_e}$ containing encoded geometry and appearance information [S1]. Adjacent voxels share 4 vertices and their corresponding embeddings [S1].
*   **Geometry Extractor ($F_\sigma$):** An MLP mapping $F_\sigma: \mathbb{R}^{L_e} \rightarrow \mathbb{R}^{1+L_f}$. It takes an embedding $e$ and outputs a signed distance value $\sigma \in \mathbb{R}$ (the first element, index [0]) and a geometry feature vector $f \in \mathbb{R}^{L_f}$ (the remaining elements, index [1:]) [S1].
*   **Appearance Extractor ($F_c$):** An MLP mapping color based on concatenated inputs [S1].

**Query Mechanism:**
For any 3D point $p$ within a voxel $V_i$, its embedding $e$ is retrieved via the retrieval function $\Gamma: \mathbb{R}^3 \rightarrow \mathbb{R}^{L_e}$ [S1]. This function performs trilinear interpolation of the embeddings from the eight voxel corners based on their coordinates [S1].

**Numbered Steps:**

1.  **Voxel Initialization:**
    *   Divide the bounding area into uniformly spaced coarse voxels [S1].
    *   Build a sparse hierarchical octree with these voxels as leaf nodes [S1].
    *   Assign each vertex a random initial embedding $e \in \mathbb{R}^{L_e}$ [S1].

2.  **Ray Generation & AABB Culling:**
    *   Generate rays $r=(o,d)$ for each image pixel [S1].
    *   Perform axis-aligned bounding box (AABB) intersection tests between rays and the octree [S1].
    *   Cull rays that do not intersect any voxels [S1].
    *   For remaining rays, calculate the distance $m_{V_i}$ inside each intersected voxel $V_i$ [S1].

3.  **Surface-Aware Sampling:**
    *   **Step 1 (Uniform Voxel Sampling):** Uniformly sample points $p$ on rays inside the intersected voxels [S1].
    *   **Step 2 (Cross-Surface Voxel Searching):** Compute SDF values using $F_\sigma(\Gamma(p))$. Identify points $p_i, p_{i+1}$ where the SDF changes sign (positive to negative), indicating a surface intersection. Mark the voxels containing these points as "important voxels" [S1].
    *   **Step 3 (Resampling):** Increase sampling probability in important voxels. Normalize probabilities along the ray. Resample rays with a fixed total point count. Two variants exist: 'full' (all important voxels) for unstable shapes, and 'first' (only the first important voxel) for fine details on stable shapes [S1].
    *   **Boundary Handling:** To prevent cross-voxel accumulation (where sampling spacing exceeds voxel boundaries due to interpolation independence), cut off intervals near voxel boundaries and recalculate sample points $t_i$ and $t_j$ [S1].

4.  **Geometry Extraction:**
    *   For each sampled point $p$, retrieve embedding $e = \Gamma(p)$ [S1].
    *   Apply positional encoding to $e$ and the ray direction $d$ [S1].
    *   Feed $e$ into $F_\sigma$ to get signed distance $\sigma = F_\sigma(e)[0]$ and geometry feature $f = F_\sigma(e)[1:]$ [S1].
    *   Compute surface normal $n$ via double backpropagation (automatic differentiation) on the SDF output: $n = \frac{d F_\sigma(\Gamma(p))[0]}{dp}$ [S1].

5.  **Appearance Extraction:**
    *   Concatenate the geometry feature $f$, ray direction $d$, and point embedding $e$ [S1].
    *   Feed the concatenation into the appearance extractor $F_c$ to obtain color $c$ [S1].

6.  **Volume Rendering:**
    *   Convert SDF $\sigma$ to density using the S-density function $\phi_s(\sigma)$ [S1]:
        $$ \phi_s(\sigma) = \frac{s e^{-s\sigma}}{(1 + e^{-s\sigma})^2} $$
        where $s$ is a scale parameter [S1].
    *   Calculate discrete volume density weight $\alpha(t_i)$ for sample point $t_i$:
        $$ \alpha(t_i) = \text{ReLU}\left( \frac{\Phi_s(F_\sigma(\Gamma(r(t_i)))[0]) - \Phi_s(F_\sigma(\Gamma(r(t_{i+1})))[0])}{\Phi_s(F_\sigma(\Gamma(r(t_i)))[0])} \right) $$
        where $\Phi_s(\sigma) = (1 + e^{-s\sigma})^{-1}$ is the Sigmoid function [S1].
    *   Calculate discrete accumulated transmittance $T(t_i)$:
        $$ T(t_i) = \prod_{j=1}^{i-1} (1 - \alpha(t_j)) $$
        [S1].
    *   Compute rendered color $C(r)$:
        $$ C(r) = \sum_i T(t_i) \alpha_i(t_i) c_i $$
        [S1].

7.  **Progressive Training (Pruning and Splitting):**
    *   **Voxel Pruning:** Uniformly sample $N_p$ points inside each voxel. Compute SDF values. If any point $p$ inside voxel $V_i$ has $|F_\sigma(\Gamma(p))[0]| < \tau$ (distance threshold $\tau$), keep the voxel ($K=1$); otherwise, prune it ($K=0$) [S1].
    *   **Voxel Splitting:** Periodically split existing voxels into 8 sub-voxels and insert them into the octree. Compute initial embeddings for new vertices using $\Gamma$. Optimize these embeddings independently of parent nodes [S1].

**Formulas:**
*   **Surface Extraction:** $S = \{ p \in \mathbb{R}^3 \mid F_\sigma(\Gamma(p))[0] = 0 \}$ [S1].
*   **Occupancy Function:** $occ(t) = \text{Sigmoid}(-\text{scale} \cdot F_\sigma(\Gamma(r(t)))[0])$ [S1].
*   **Color Loss:** $L_{\text{color}} = \sum_r \|\hat{C}(r) - C(r)\|_1$ [S1].
*   **Eikonal Loss:** $L_{\text{eikonal}} = \sum_i (\|\nabla F_\sigma(\Gamma(p_i))[0]\|_2 - 1)^2$ [S1].
*   **Depth Loss:**
    *   $L_{\text{outside}} = \sum_t \|1 - occ(t)\|_2^2$ for $t < \hat{t} - \delta_t$ [S1].
    *   $L_{\text{near}} = \sum_t \|F_\sigma(\Gamma(r(t)))[0]\|_2^2$ for $\hat{t} - \delta_t \le t \le \hat{t} + \delta_t$ [S1].
    *   $L_{\text{inside}} = \sum_t \|occ(t)\|_2^2$ for $t > \hat{t} + \delta_t$ [S1].
    *   $L_{\text{depth}} = L_{\text{outside}} + L_{\text{near}} + L_{\text{inside}}$ [S1].

**Parameters:**
*   **$L_e$:** Length of the vertex embedding vector. Not given in the sources.
*   **$L_f$:** Length of the geometry feature vector. Not given in the sources.
*   **$\tau$:** Distance threshold for voxel pruning. Not given in the sources.
*   **$s$:** Scale parameter for the S-density function. Not given in the sources.
*   **$\delta_t$:** Small noise tolerance depth range for depth loss intervals. Depends on the confidence of the given depth sensor data. Not given in the sources.
*   **Positional Encoding:** Applied to both embedding vector $e$ and view direction $d$ before feeding into the network, as proposed in NeRF [S1].

**Pitfalls:**
*   **Cross-voxel accumulation:** Because voxels are independent due to the interpolation mechanism, sampling spacing cannot exceed the voxel boundary. If it does, cross-voxel accumulation occurs. To prevent this, intervals near voxel boundaries must be cut off and sample points recalculated [S1].
*   **Surface Missing:** Voxel pruning in the early stages can cause surface missing. This can be alleviated by increasing the sampling density in the early stage [S1].

## Subtopics

### Binary Radiance Fields
Uses binary occupancy grids instead of continuous embeddings or densities. Chosen when memory is extremely constrained and fine detail is less critical. [Link](13622-binary-radiance-fields.md)

### Adaptive Differentiable Grids for Cryo-ET
Adapts grid resolution specifically for cryo-electron tomography data. Chosen for scientific imaging of biological structures. [Link](17614-adaptive-differentiable-grids-for-cryo-et.md)

### Depth-Guided Robust and Fast Point Cloud Fusion NeRF
Integrates point cloud fusion with NeRF training. Chosen when robust point cloud data is available to guide initialization. [Link](18135-depth-guided-robust-and-fast-point-cloud-fusion-nerf.md)

### Sparse Feature Volume
Uses sparse feature volumes for efficient representation. Chosen for large-scale scenes where dense grids are prohibitive. [Link](18180-sparse-feature-volume.md)

### PAC-NeRF
Uses probabilistic attention for compact NeRF representation. Chosen for high-quality rendering with reduced memory. [Link](18672-pac-nerf.md)

### Spatially Encoded Radiance Fields
Encodes spatial information directly into the radiance field. Chosen for specific encoding efficiency gains. [Link](21788-spatially-encoded-radiance-fields.md)

## Operating characteristics
*   **Time and Memory Complexity:** Memory usage is reduced compared to dense neural implicit methods because it only reconstructs occupied space via a sparse hierarchical octree [S1]. Inference speed is improved due to the reduction in sample points through voxel pruning [S1].
*   **Measured Performance:** Experiments on DTU, ScanNet, and KITTI-360 datasets show that Vox-Surf learns fine surface details and accurate colors with less memory and faster rendering than previous methods [S1]. It can approach real-time at low resolution [S1].
*   **Scaling:** The method is suitable for almost any scene due to its sparsity [S1]. It scales well with scene size by pruning empty voxels and splitting only where necessary [S1].
*   **Strengths:** Efficient surface reconstruction, realistic rendering, memory efficiency, fast inference, and suitability for 3D interactions (collision detection, scene editing) due to explicit voxel representation [S1].
*   **Limitations:** Requires multi-view posed images and an approximate bounding box [S1]. Performance depends on the confidence of depth sensor data if used [S1]. Early-stage surface missing can occur if sampling density is not increased [S1].
*   **When to use:** When efficient surface reconstruction and rendering from multi-view images are needed, especially for 3D interactive applications like AR/VR or collision detection [S1].
*   **When not to use:** When dense, continuous volume rendering of transparent scenes is required without explicit surface extraction, or when posed multi-view images are not available [S1].

## Background
Vox-Surf was proposed in the paper "Vox-Surf: Voxel-Based Implicit Surface Representation" published in IEEE Transactions on Visualization and Computer Graphics in 2022 [S1]. It builds on previous voxel-based implicit surface methods and neural implicit methods like NeRF [S1]. The method addresses the limitations of traditional voxel-based methods (storing explicit SDF/color) and dense neural implicit methods (learning in empty areas) by using trainable embeddings at voxel corners [S1]. The source code is publicly available at https://github.com/zju3dv/Vox-Surf [S1].
