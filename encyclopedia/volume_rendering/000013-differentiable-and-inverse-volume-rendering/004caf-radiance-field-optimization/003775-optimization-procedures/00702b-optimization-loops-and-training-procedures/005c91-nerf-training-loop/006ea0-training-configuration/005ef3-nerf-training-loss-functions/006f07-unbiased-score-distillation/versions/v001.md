# Unbiased Score Distillation

Also called: USD

## Overview
Unbiased Score Distillation (USD) is a training loss function for radiance fields that rectifies critical bias in traditional Score Distillation Sampling (SDS) by substituting the biased unconditional noise predictions of multi-view diffusion models (e.g., Zero-1-to-3) with the true unconditional noise from a pre-trained 2D diffusion model (e.g., Stable Diffusion) [S1]. Unlike prior methods that enforce multi-view consistency via restrictive volume or ray aggregation, USD uses the optimized radiance field itself as a consistency prior, allowing full freedom in camera pose selection during optimization [S1].

## How it works
**Inputs and Outputs:**
- **Inputs:**
  - $\theta$: Parameters of the radiance field (e.g., NeRF).
  - $\phi$: Parameters of the multi-view diffusion model (e.g., Zero-1-to-3), denoted as $\epsilon_\phi$.
  - $\psi$: Parameters of the base 2D diffusion model (e.g., Stable Diffusion), denoted as $\epsilon_\psi$.
  - $c_I$: Input image condition (the source image for 3D generation).
  - $c_P$: Camera pose condition for the view to be synthesized.
  - $t$: Diffusion timestep.
  - $\epsilon$: Standard Gaussian noise.
  - $\omega$: Guidance scale.
- **Outputs:**
  - Gradient $\nabla_{\theta} \mathcal{L}_{\text{USD}}$ to update radiance field parameters $\theta$.

**Data Structures:**
- **Latent $\mathbf{z}_t$**: The noisy latent variable at timestep $t$, computed as $\mathbf{z}_t = \sqrt{\alpha_t}\mathbf{z} + \sqrt{1-\alpha_t}\epsilon$, where $\mathbf{z}$ is the clean latent and $\alpha_t$ is from the noise scheduler [S1].
- **Conditions**:
  - $c_I$: Image embedding (e.g., CLIP text/image features).
  - $c_P$: Camera pose embedding.
  - $\emptyset$: Dropped condition (represented as a zero tensor or null pointer depending on implementation, but semantically "no condition") [S1].

**Step-by-Step Method:**

1.  **Identify Bias in Multi-View Diffuser:**
    Standard multi-view diffusers like Zero-1-to-3 are trained to predict noise $\epsilon_\phi(\mathbf{z}_t, c_I, c_P)$. To enable Classifier-Free Guidance (CFG), they must predict unconditional noise. However, Zero-1-to-3 only drops $c_I$ during training, keeping $c_P$. During inference, it replaces the tensor after the fully connected layer $f(\cdot)$ with zeros. Since $f(0) \neq 0$, this does not equate to setting $c_P = \emptyset$, resulting in biased unconditional noise predictions $\epsilon_\phi(\mathbf{z}_t, c_P, \emptyset)$ and $\epsilon_\phi(\mathbf{z}_t, \emptyset, \emptyset)$ [S1].

2.  **Rectify Bias via Stable Diffusion Unconditional Noise:**
    The bias is rectified by replacing the multi-view model's unconditional noise with the true unconditional noise from a pre-trained 2D diffusion model $\epsilon_\psi(\mathbf{z}_t, \emptyset)$. This is valid because Zero-1-to-3 and Stable Diffusion share the same Variational Autoencoder (VAE) architecture, making their latent spaces compatible [S1].

3.  **Simplify Guidance Formula:**
    The standard CFG formula for a model with two conditions ($c_I, c_P$) is:
    $$
    \epsilon_\phi^{\text{CFG}}(\mathbf{z}_t, c_I, c_P) = \alpha_1[\epsilon_\phi(\mathbf{z}_t, c_I, c_P) - \epsilon_\phi(\mathbf{z}_t, c_P, \emptyset)] + \alpha_2[\epsilon_\phi(\mathbf{z}_t, c_P, \emptyset) - \epsilon_\phi(\mathbf{z}_t, \emptyset, \emptyset)] + \epsilon_\phi(\mathbf{z}_t, \emptyset, \emptyset)
    $$
    [S1].
    To eliminate the biased intermediate term $\epsilon_\phi(\mathbf{z}_t, c_P, \emptyset)$, set guidance scales $\alpha_1 = \alpha_2 = \omega$. This yields Conditional Residual Guidance (CRG):
    $$
    \epsilon_\phi^{\text{CRG}}(\mathbf{z}_t, c_I, c_P) = \omega[\epsilon_\phi(\mathbf{z}_t, c_I, c_P) - \epsilon_\phi(\mathbf{z}_t, \emptyset, \emptyset)] + \epsilon_\phi(\mathbf{z}_t, \emptyset, \emptyset)
    $$
    [S1].

4.  **Substitute Unconditional Noise:**
    Substitute $\epsilon_\phi(\mathbf{z}_t, \emptyset, \emptyset)$ with $\epsilon_\psi(\mathbf{z}_t, \emptyset)$ from Stable Diffusion. The noise difference term for the loss becomes:
    $$
    \epsilon_\phi^{\text{FG}}(\mathbf{z}_t, c_I, c_P) - \epsilon = \omega [\epsilon_\phi(\mathbf{z}_t, c_I, c_P) - \epsilon_\psi(\mathbf{z}_t, \emptyset)] + \lambda [\epsilon_\psi(\mathbf{z}_t, \emptyset) - \epsilon]
    $$
    [S1].

5.  **Remove Regularization Term ($\lambda = 0$):**
    Standard SDS corresponds to $\lambda = 1$. However, setting $\lambda = 0$ removes the regularization term $[\epsilon_\psi(\mathbf{z}_t, \emptyset) - \epsilon]$, which significantly improves the details of the generated 3D content [S1]. This aligns with findings from Direct Distillation of Scores (DDS) and Consistency Score Distillation (CSD) [S1].

6.  **Compute USD Gradient:**
    The final Unbiased Score Distillation loss gradient is:
    $$
    \nabla_{\theta} \mathcal{L}_{\text{USD}} = \mathbb{E}_{t, c_P, \epsilon} \left[ w(t) \left[ \omega (\epsilon_{\phi}(\mathbf{z}_t, c_I, c_P) - \epsilon_{\psi}(\mathbf{z}_t, \emptyset)) \right] \frac{\partial \mathbf{z}_t}{\partial \theta} \right]
    $$
    [S1].
    Here, $w(t)$ is the standard SDS weighting function (e.g., $\frac{\partial \mathbf{z}_t}{\partial \epsilon}$ or similar scheduler-dependent weight).

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def compute_usd_gradient(
    nerf_params, 
    camera_pose, 
    input_image_condition, 
    diffusion_model_phi, # Multi-view diffuser (e.g., Zero-1-to-3)
    diffusion_model_psi, # Base 2D diffuser (e.g., Stable Diffusion)
    vae,                 # Shared VAE for encoding/decoding
    t,                   # Diffusion timestep
    omega,               # Guidance scale
    w_t                  # Weighting function w(t)
):
    """
    Computes the Unbiased Score Distillation (USD) gradient for NeRF optimization.
    
    Args:
        nerf_params: Parameters of the radiance field (NeRF).
        camera_pose: Camera pose condition c_P.
        input_image_condition: Input image condition c_I (e.g., CLIP embedding).
        diffusion_model_phi: Multi-view diffusion model epsilon_phi.
        diffusion_model_psi: Base 2D diffusion model epsilon_psi.
        vae: Variational Autoencoder for latent space conversion.
        t: Current diffusion timestep.
        omega: Guidance scale (alpha_1 = alpha_2 = omega).
        w_t: Weighting factor w(t) for the current timestep.
        
    Returns:
        gradient: Gradient of the USD loss w.r.t nerf_params.
    """
    
    # 1. Render a view from the current NeRF
    # Render RGB image at the given camera pose
    rendered_rgb = render_ne_view(nerf_params, camera_pose)
    
    # 2. Encode rendered image to latent space
    # Use the shared VAE to encode the rendered image
    z_0 = vae.encode(rendered_rgb)
    
    # 3. Add noise to latent
    # Sample standard Gaussian noise epsilon
    epsilon = torch.randn_like(z_0)
    # Compute noisy latent z_t using the noise scheduler alpha_t
    # Note: alpha_t is typically pre-computed or available from the scheduler
    alpha_t = get_alpha(t) 
    sqrt_alpha_t = torch.sqrt(alpha_t)
    sqrt_one_minus_alpha_t = torch.sqrt(1 - alpha_t)
    z_t = sqrt_alpha_t * z_0 + sqrt_one_minus_alpha_t * epsilon
    
    # 4. Predict noise from Multi-View Diffuser (phi) with conditions
    # Condition: Image (c_I) and Camera Pose (c_P)
    epsilon_phi_cond = diffusion_model_phi(z_t, c_I=input_image_condition, c_P=camera_pose)
    
    # 5. Predict unconditional noise from Base 2D Diffuser (psi)
    # Condition: None (empty)
    # This rectifies the bias in phi's unconditional prediction
    epsilon_psi_uncond = diffusion_model_psi(z_t, c_I=None, c_P=None)
    
    # 6. Compute the USD noise difference
    # Formula: omega * (epsilon_phi(c_I, c_P) - epsilon_psi(empty))
    # Lambda is set to 0, so the regularization term [epsilon_psi - epsilon] is omitted
    usd_noise_diff = omega * (epsilon_phi_cond - epsilon_psi_uncond)
    
    # 7. Compute the gradient
    # Gradient of z_t w.r.t NeRF parameters
    # z_t depends on rendered_rgb, which depends on nerf_params
    # We need d(z_t)/d(nerf_params)
    # Since z_t = sqrt_alpha_t * z_0 + sqrt_one_minus_alpha_t * epsilon,
    # and epsilon is constant w.r.t nerf_params:
    # d(z_t)/d(nerf_params) = sqrt_alpha_t * d(z_0)/d(nerf_params)
    
    # Compute gradient of the noise difference w.r.t z_t (standard SDS step)
    # In practice, this is often done via automatic differentiation through the diffusion model
    # However, the standard SDS formulation uses:
    # grad = E[ w(t) * (epsilon_pred - epsilon) * d(z_t)/d(theta) ]
    # Here, our "epsilon_pred" equivalent in the gradient flow is the term inside the expectation
    # that gets multiplied by d(z_t)/d(theta).
    
    # The term (usd_noise_diff - epsilon) is NOT correct here because we replaced the baseline.
    # The USD gradient is derived directly from the modified noise difference.
    # According to Eq 7: grad = E[ w(t) * [omega(...)] * d(z_t)/d(theta) ]
    
    # Calculate d(z_t)/d(nerf_params)
    # We need to backpropagate through the VAE decode -> Render -> NeRF
    # But wait, z_t is in latent space. The diffusion model takes z_t.
    # The gradient flows from the diffusion model loss back to z_t, then to z_0, then to rendered_rgb, then to nerf_params.
    
    # Let's compute the gradient of the USD loss w.r.t z_t first?
    # No, the standard implementation computes the gradient w.r.t the image/latent directly.
    # The term (epsilon_pred - epsilon) in standard SDS is replaced by the USD noise difference.
    # However, note that the USD formula Eq 7 does NOT subtract epsilon from the noise difference.
    # It uses [omega(...) ] directly.
    
    # Let's verify the gradient direction.
    # Standard SDS: L = E[ w(t) * || epsilon_pred - epsilon ||^2 ]
    # grad_theta = E[ w(t) * (epsilon_pred - epsilon) * d(z_t)/d(theta) ]
    # USD modifies the "epsilon_pred" part.
    # The USD loss is effectively minimizing the distance between the multi-view model's conditional prediction
    # and the base model's unconditional prediction, scaled by omega.
    # The gradient is:
    
    # We need the gradient of the noise difference w.r.t z_t to propagate back to z_0?
    # Actually, in PyTorch, we can just compute the loss and backprop.
    # But for explicit formula:
    
    # The term multiplying d(z_t)/d(theta) is:
    # w(t) * omega * (epsilon_phi_cond - epsilon_psi_uncond)
    
    # Wait, does it subtract epsilon?
    # Eq 7: w(t) [ omega(...) ] d(z_t)/d(theta)
    # It does NOT subtract epsilon.
    
    # So, we compute the gradient of the "USD noise difference" w.r.t z_t?
    # No, the gradient is with respect to theta.
    # chain rule: d(L)/d(theta) = d(L)/d(z_t) * d(z_t)/d(theta)
    # d(L)/d(z_t) is not directly computed. Instead, we use the fact that:
    # In SDS, the gradient is approximated by:
    # grad = w(t) * (epsilon_pred - epsilon) * d(z_t)/d(theta)
    # Here, epsilon_pred is replaced by the USD formulation.
    
    # Let's implement the gradient computation using autograd for clarity and correctness.
    
    # Create a tensor that requires grad
    z_t.requires_grad_(True)
    
    # Predict noises
    eps_phi = diffusion_model_phi(z_t, c_I=input_image_condition, c_P=camera_pose)
    eps_psi = diffusion_model_psi(z_t, c_I=None, c_P=None)
    
    # USD noise difference
    usd_diff = omega * (eps_phi - eps_psi)
    
    # The "loss" component that drives the gradient
    # In standard SDS, we minimize || eps_pred - epsilon ||^2
    # The gradient of 0.5 * ||x||^2 w.r.t x is x.
    # So the gradient term is (eps_pred - epsilon).
    # In USD, the term is just usd_diff?
    # Let's look at Eq 7 again.
    # grad = E[ w(t) * [omega(...)] * d(z_t)/d(theta) ]
    # This implies the "residual" is just the USD noise difference.
    
    # However, usually score distillation minimizes the distance to the score.
    # The score is -epsilon / sqrt(1-alpha).
    # The gradient direction is determined by the difference between the predicted score and the true score (epsilon).
    # In USD, we are distilling from the multi-view model.
    # The multi-view model's "score" is represented by eps_phi.
    # But we correct it with eps_psi.
    
    # Let's stick to the formula in Eq 7 strictly.
    # The term multiplying d(z_t)/d(theta) is w(t) * omega * (eps_phi - eps_psi).
    
    # To get d(z_t)/d(theta), we need to backpropagate from z_t to theta.
    # But z_t is derived from z_0, which is derived from rendered_rgb, which is derived from theta.
    
    # We can compute the gradient of the USD difference w.r.t z_t?
    # No, we don't need d(usd_diff)/d(z_t). We need d(z_t)/d(theta).
    # And we multiply them.
    
    # In practice, we compute:
    # loss = 0.5 * (usd_diff - 0)^2 ? No.
    # The gradient is simply the vector field defined by the equation.
    
    # Let's compute the gradient of the "USD residual" w.r.t z_t?
    # Actually, the standard way to implement SDS is:
    # 1. Get epsilon_pred.
    # 2. Compute grad_z = w(t) * (epsilon_pred - epsilon).
    # 3. Backprop grad_z through the VAE decode and Renderer to theta.
    
    # For USD, the "epsilon_pred" equivalent in the gradient vector is:
    # epsilon_usd = omega * (eps_phi - eps_psi) + epsilon? 
    # No, Eq 7 says the term is just omega(...) without subtracting epsilon.
    
    # Let's re-read Eq 6 and 7.
    # Eq 6: epsilon_phi^FG - epsilon = omega(...) + lambda(...)
    # Eq 7: grad = E[ w(t) * [omega(...)] * d(z_t)/d(theta) ]
    # This implies that the "error" term being minimized is effectively just the USD difference.
    # This is distinct from standard SDS where we minimize distance to epsilon.
    
    # So, the gradient vector in latent space is:
    grad_z_t = w_t * usd_diff
    
    # Now, we need to backpropagate this gradient from z_t to nerf_params.
    # Path: z_t -> z_0 -> rendered_rgb -> nerf_params
    # z_t = sqrt_alpha_t * z_0 + sqrt_one_minus_alpha_t * epsilon
    # d(z_t)/d(z_0) = sqrt_alpha_t
    # So, grad_z_0 = grad_z_t * sqrt_alpha_t
    
    grad_z_0 = grad_z_t * sqrt_alpha_t
    
    # Decode z_0 to image space
    # rendered_rgb = vae.decode(z_0)
    # We need grad_rendered_rgb = grad_z_0 * d(z_0)/d(rendered_rgb)
    # d(z_0)/d(rendered_rgb) is the gradient of the VAE encode function.
    # But we have grad_z_0. We can backprop through the VAE decode?
    # No, we have the gradient w.r.t z_0. We need to pass it to the renderer.
    # The renderer outputs rendered_rgb.
    # We need to backprop from z_0 to rendered_rgb.
    # z_0 = vae.encode(rendered_rgb)
    # So we need grad_rendered_rgb = grad_z_0 * d(z_0)/d(rendered_rgb)
    
    # In PyTorch, we can just create a computational graph.
    # But we already have z_t.
    # Let's reconstruct the graph for backprop.
    
    # Re-encode to ensure graph is connected?
    # No, we can just use the gradient we computed.
    # But we need to backprop through the VAE encode.
    
    # Let's do it explicitly:
    # 1. Render image from NeRF
    # 2. Encode to z_0
    # 3. Add noise to get z_t
    # 4. Compute USD diff
    # 5. Backprop USD diff w.r.t z_t
    # 6. Backprop w.r.t z_0
    # 7. Backprop w.r.t rendered_rgb
    # 8. Backprop w.r.t nerf_params
    
    # Step 1-3 are forward pass.
    # Step 4 computes the value.
    # Step 5-8 are backward pass.
    
    # Compute gradient w.r.t z_t
    # usd_diff is a tensor.
    # We want d(L)/d(z_t) = w_t * usd_diff
    # But wait, is L = 0.5 * ||usd_diff||^2?
    # If L = 0.5 * ||usd_diff||^2, then dL/d(usd_diff) = usd_diff.
    # And d(usd_diff)/d(z_t) is the Jacobian of the diffusion models.
    # But Eq 7 suggests we use usd_diff directly as the gradient vector.
    # This implies the loss is not explicitly defined as a squared error, but the gradient is defined directly.
    # This is common in score distillation: the gradient is the score difference.
    
    # So, we treat `usd_diff` as the gradient in latent space.
    
    # Backpropagate through VAE encode
    # z_0 = vae.encode(rendered_rgb)
    # grad_rendered_rgb = grad_z_0 * d(z_0)/d(rendered_rgb)
    
    # We can compute this by:
    # grad_z_0.retain_grad() # Not needed if we backprop manually
    # But we need to connect z_0 to rendered_rgb.
    
    # Let's assume we have the rendered_rgb tensor from step 1.
    # We need to backprop from z_0 to rendered_rgb.
    
    # grad_z_0 is the gradient w.r.t z_0.
    # We can use torch.autograd.grad to get grad_rendered_rgb.
    
    grad_rendered_rgb = torch.autograd.grad(
        outputs=z_0, 
        inputs=rendered_rgb, 
        grad_outputs=grad_z_0, 
        retain_graph=True, 
        create_graph=False
    )[0]
    
    # Now backprop from rendered_rgb to nerf_params
    gradient = torch.autograd.grad(
        outputs=rendered_rgb, 
        inputs=nerf_params, 
        grad_outputs=grad_rendered_rgb, 
        retain_graph=False, 
        create_graph=False
    )[0]
    
    return gradient
```

**Parameters:**
- $\omega$ (Guidance Scale): Typically $>1$. Controls the strength of the difference between conditional and unconditional noise. [S1].
- $\lambda$ (Regularization Weight): Set to $0$. Setting $\lambda=1$ reverts to standard SDS, which produces less detailed 3D content. [S1].
- $\alpha_1, \alpha_2$: Set to $\omega$ to simplify the CFG formula. [S1].

**Edge Cases and Pitfalls:**
- **Bias in Zero-1-to-3:** Zero-1-to-3 does not truly train unconditional noise by dropping both conditions. It only drops $c_I$ and keeps $c_P$. During inference, it replaces the tensor after the fully connected layer $f(\cdot)$ with zeros. Since $f(0) \neq 0$, this is not equivalent to setting $c_P=\emptyset$, leading to biased unconditional noise predictions. USD avoids this by using Stable Diffusion's unconditional noise. [S1].
- **Domain Bias:** The dataset used for fine-tuning multi-view diffusers is often object-centric, which may introduce additional domain bias. USD mitigates this by using the general-purpose Stable Diffusion unconditional noise. [S1].
- **Precision:** The method relies on the compatibility of the VAE latent spaces between the multi-view diffuser and the base 2D diffuser. [S1].

## Operating characteristics
- **Time Complexity:** Depends on the number of diffusion steps and the cost of rendering from the NeRF. Each optimization step requires one forward pass through the NeRF, one encoding through the VAE, and two forward passes through diffusion models (phi and psi).
- **Memory Complexity:** Requires memory for the NeRF parameters, the diffusion models, and the VAE. The latent space size is smaller than image space, reducing memory compared to pixel-space distillation.
- **Measured Performance:** On GSO, RTMV, and Objaverse datasets (1,000 random images), SD unconditional noise $\epsilon_\psi(\mathbf{z}_t, \emptyset)$ yields superior denoising results compared to Zero-1-to-3 noise. At T=50 noise steps: PSNR 40.26, SSIM 0.992, LPIPS 0.008. Zero-1-to-3 noise with inference setup $\epsilon_\phi(\mathbf{z}_t, 0)$ yields PSNR 36.13, SSIM 0.979, LPIPS 0.015. [S1].
- **Strengths:** Generates high-quality, detailed 3D content with better geometry fidelity than standard SDS. Maintains full freedom in camera pose selection, unlike methods using volume or ray aggregation. [S1].
- **Limitations:** Requires access to both a multi-view diffuser and a base 2D diffusion model. Computationally more expensive than single-model distillation due to the two diffusion model forward passes. [S1].
- **When to Use:** When high-fidelity geometry and texture are required, and camera pose flexibility is important. [S1].
- **When Not to Use:** When computational resources are limited, or when a single diffusion model is available. [S1].

## Background
Unbiased Score Distillation (USD) was introduced in the paper "Optimized View and Geometry Distillation from Multi-view Diffuser" [S1]. The work addresses the limitations of existing methods that use multi-view diffusion models (like Zero-1-to-3) for 3D generation. It identifies a critical bias in the unconditional noise predictions of these models and proposes a rectification strategy using the unconditional noise from a pre-trained 2D diffusion model (Stable Diffusion). The method also leverages the radiance field as a consistency prior to ensure multi-view consistency without restricting camera poses. [S1].
