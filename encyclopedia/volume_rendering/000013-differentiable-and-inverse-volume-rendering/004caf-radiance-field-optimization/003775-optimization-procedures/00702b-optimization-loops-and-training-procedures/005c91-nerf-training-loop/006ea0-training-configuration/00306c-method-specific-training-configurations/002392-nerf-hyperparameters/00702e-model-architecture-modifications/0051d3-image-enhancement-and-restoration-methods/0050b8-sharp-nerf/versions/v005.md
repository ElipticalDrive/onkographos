# Sharp-NeRF

Also called: Grid-based Fast Deblurring Neural Radiance Fields using Sharpness Prior

## Overview
Sharp-NeRF is a grid-based NeRF framework that renders clean, sharp images from input blurry images by modeling spatially varying blur using discrete learnable kernels and a sharpness prior [S1]. It distinguishes itself from sibling methods like DeblurNeRF and DP-NeRF by replacing neural network-based kernel generators with a fixed set of discrete kernels indexed by a precomputed sharpness map, significantly reducing training time to approximately half an hour while maintaining high-quality deblurring [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of blurry training images (views) and their corresponding camera poses [S1].
*   **Outputs:** A grid-based neural field representation of the scene and a set of discrete blur kernels [S1]. At inference, the system outputs sharp novel views [S1].

**Data Structures:**
1.  **Grid-based Neural Field:** A decomposed-grid representation (e.g., Tri-Plane or Hash Grid) storing density and color information, replacing the standard MLP [S1].
2.  **Sharpness Level Map ($L$):** A 2D map per view where each pixel value is an integer index $k \in \{0, \dots, N_k-1\}$ representing the quantized sharpness level of that pixel [S1].
3.  **Discrete Blur Kernels ($B$):** A set of $N_k$ learnable 2D convolution kernels [S1].
4.  **Ray Patch:** A $K \times K$ grid of rays sampled from the camera frustum, corresponding to a $K \times K$ pixel patch in the image plane [S1].

**Preprocessing (Offline):**
1.  For each training view, compute a defocus map (sharpness measure) for every pixel using a sharpness measure operator [S1].
2.  Quantize the continuous sharpness values into $N_k$ discrete levels to create the sharpness level map $L$ [S1]. This step is performed once before training and is not part of the differentiable graph [S1].

**Training Steps:**
1.  **Ray Patch Sampling:** Sample a $K \times K$ patch of rays from the training view [S1].
2.  **Sharp Rendering:** Query the grid-based neural field with the ray patch inputs to render a sharp image patch $I_c'$ [S1].
3.  **Kernel Indexing:** Retrieve the sharpness level map $L$ corresponding to the current view [S1]. For each pixel $(u,v)$ in the patch, obtain its sharpness index $k = L(u,v)$ [S1].
4.  **Kernel Selection:** Select the discrete blur kernel $B_k$ from the set $B$ based on index $k$ [S1].
5.  **Blurring Synthesis:** Compute the blurred patch $I_b$ as a weighted sum of the per-pixel weights $w_x$ and the rendered sharp image patch $I_c'$ [S1]. The operation is defined as $I_b(u,v) = \sum_{k=0}^{N_k-1} w_x^{(k)}(u,v) \cdot (B_k * I_c')(u,v)$, where $*$ denotes 2D convolution, $\cdot$ is element-wise multiplication, and $w_x^{(k)}$ is the indicator weight for sharpness level $k$ at pixel $(u,v)$ [S1].
6.  **Loss Computation:** Compare the synthesized blurred patch $I_b$ with the input blurry training image patch $I_{blur}$ using a reconstruction loss (e.g., L1) [S1].
7.  **Optimization:** Backpropagate through the blurring operation to update the grid parameters and the discrete kernels $B$ [S1].

**Inference:**
1.  Sample rays for the target novel view [S1].
2.  Query the grid-based neural field to render the sharp image $I_c$ directly [S1].
3.  The blur kernel module is bypassed; the output is the sharp image $I_c$ [S1].

**Pseudocode:**
```python
import numpy as np

def quantize(values, num_levels):
    """Quantize continuous values into discrete indices [0, num_levels-1]."""
    min_v, max_v = values.min(), values.max()
    if max_v == min_v:
        return np.zeros_like(values, dtype=int)
    return np.clip(((values - min_v) / (max_v - min_v) * (num_levels - 1)).astype(int), 0, num_levels - 1)

def apply_convolution(image, kernel):
    """Apply 2D convolution with zero-padding."""
    kh, kw = kernel.shape
    pad_h, pad_w = kh // 2, kw // 2
    padded = np.pad(image, ((pad_h, pad_h), (pad_w, pad_w), (0, 0)), mode='constant')
    out = np.zeros_like(image)
    for y in range(image.shape[0]):
        for x in range(image.shape[1]):
            out[y, x] = np.sum(padded[y:y+kh, x:x+kw, :] * kernel, axis=(0, 1))
    return out

def train_sharp_nerf(sharpness_maps, blurry_images, grid, kernels, patch_size, epochs, learning_rate):
    # sharpness_maps: list of 2D arrays (H, W) with integer indices
    # blurry_images: list of 3D arrays (H, W, 3)
    # grid: object with .query(rays) method returning (K, K, 3)
    # kernels: list of 2D arrays (kh, kw, 3)
    for epoch in range(epochs):
        for s_map, blurry_img in zip(sharpness_maps, blurry_images):
            h, w = blurry_img.shape[:2]
            y0, x0 = np.random.randint(0, h - patch_size + 1), np.random.randint(0, w - patch_size + 1)
            patch_slice = slice(y0, y0 + patch_size), slice(x0, x0 + patch_size)

            # 1. Sample ray patch and 2. Render sharp patch
            rays = generate_rays_from_coords(patch_slice) # [G] Standard frustum sampling
            sharp_patch = grid.query(rays)

            # 3. Kernel Indexing: get sharpness indices for the patch
            indices = s_map[patch_slice]

            # 4 & 5. Blurring Synthesis: weighted sum of convolved sharp patches
            blurred_patch = np.zeros_like(sharp_patch)
            for k in range(len(kernels)):
                conv_patch = apply_convolution(sharp_patch, kernels[k])
                mask = (indices == k)
                blurred_patch[mask] += conv_patch[mask]

            # 6. Loss Computation
            target_patch = blurry_img[patch_slice]
            loss = np.mean(np.abs(blurred_patch - target_patch))

            # 7. Optimization
            grid.update(loss)
            kernels.update(loss)
```

**Parameters:**
*   $N_k$: The number of discrete blur kernels. The sources do not specify the exact value used in experiments, only that it is a "few" to handle spatially varying blur [S1].
*   $K$: The size of the ray patch. The sources mention rendering 5 or 6 neighboring pixels, implying a patch size likely around $5\times5$ or $6\times6$ [S1].

**Edge Cases and Pitfalls:**
*   **Memory:** Storing a unique blur kernel for every pixel is impractical for high-resolution, multi-view images [S1]. Sharp-NeRF avoids this by quantizing sharpness levels into $N_k$ discrete kernels [S1].
*   **Training Time:** Rendering multiple neighboring pixels for a single pixel increases training time proportionally [S1]. Sharp-NeRF mitigates this by rendering a patch and applying convolution, which is more efficient than per-pixel ray batching [S1].
*   **Preprocessing Dependency:** The sharpness level map $L$ is computed offline [S1]. If the input images have varying blur characteristics not captured by the initial quantization, the discrete kernels may not fully represent the blur [S1].

## Operating characteristics
*   **Time Complexity:** Training time is significantly reduced compared to MLP-based methods, taking approximately half an hour [S1]. This is achieved by using a grid-based representation and discrete kernels instead of MLPs for kernel generation [S1].
*   **Memory Complexity:** Lower than MLP-based NeRFs due to the grid representation [S1].
*   **Strengths:** Fast training time; handles spatially varying blur effectively using discrete kernels; high-quality sharp novel view synthesis [S1].
*   **Limitations:** Relies on accurate precomputed sharpness maps; discrete kernels may not capture complex, continuous blur variations as well as learned continuous kernels [S1].
*   **When to use:** When training time is a constraint and the blur is primarily defocus-based [S1].

## Background
Sharp-NeRF was proposed to address the high computational cost of MLP-based NeRF deblurring methods like Deblur-NeRF and DP-NeRF [S1]. It builds on the idea of using grid-based representations for speed [S1]. The method was introduced in the paper "Sharp-NeRF: Grid-based Fast Deblurring Neural Radiance Fields using Sharpness Prior" [S1].
