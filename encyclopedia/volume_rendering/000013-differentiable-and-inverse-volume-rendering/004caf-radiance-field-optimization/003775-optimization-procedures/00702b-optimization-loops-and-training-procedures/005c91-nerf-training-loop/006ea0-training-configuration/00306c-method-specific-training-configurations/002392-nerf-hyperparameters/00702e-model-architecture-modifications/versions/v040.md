# Model Architecture Modifications

Also called: NeRF Architecture Variants, Radiance Field Network Topologies

## Overview
Model Architecture Modifications alter the topology, input/output dimensions, or internal connectivity of the neural radiance field to address specific challenges such as dynamic scenes, transparency, mobile efficiency, or semantic consistency [S1]. These modifications set themselves apart from the baseline NeRF by introducing specialized components like blend weight fields, residual networks, or multi-input multi-output (MIMO) structures, optimizing for trade-offs between training speed, inference latency, and reconstruction fidelity [S1].

## Shared principles
The baseline NeRF architecture [Parent](3065-nerf-hyperparameters.md) defines a continuous volumetric scene representation $F_\Theta: (\mathbf{x}, \mathbf{d}) \rightarrow (\sigma, \mathbf{c})$, where $\mathbf{x} \in \mathbb{R}^3$ is the spatial position, $\mathbf{d} \in \mathbb{R}^3$ is the viewing direction, $\sigma$ is the volume density, and $\mathbf{c} \in \mathbb{R}^3$ is the view-dependent color [G]. The rendering process integrates these outputs along rays using standard volume rendering equations [G].

Most modifications in this family retain the core volume rendering equation but alter one or more of the following components:
1.  **Input Space:** Augmenting $\mathbf{x}$ and $\mathbf{d}$ with additional signals such as latent codes $\mathbf{z}$, time $t$, illumination embeddings $\mathbf{z}_l$, or external feature vectors $\mathbf{f}$ from vision models [S1][S2, unofficial][S3, unofficial].
2.  **Network Topology:** Replacing the monolithic MLP with specialized branches (e.g., separate density and color networks), modular experts, or hybrid structures combining MLPs with convolutional or transformer backbones [S1][S2, unofficial].
3.  **Output Space:** Extending the output tuple $(\sigma, \mathbf{c})$ to include additional fields such as uncertainty, semantic logits, or physical properties like albedo and normals [S1].

## Subtopics

### [DoF-NeRF](9432-dof-nerf.md)
DoF-NeRF extends the standard NeRF to simulate depth-of-field effects by introducing learnable aperture and focus parameters per view, enabling the synthesis of clear, all-in-focus novel views from defocused inputs. Choose this method when handling scenes with shallow depth-of-field or when explicit control over optical blur is required.

### [NeRF-VPT](11770-nerf-vpt.md)
NeRF-VPT is a cascading view prompt tuning paradigm that iteratively incorporates rendered images from preceding stages as visual prompts to enhance image quality in subsequent iterations. Choose this method for progressive refinement of sparse-view or standard NeRF settings without requiring external priors.

### [NeRF-VAE](11991-nerf-vae.md)
NeRF-VAE is a generative model that learns a distribution over 3D scenes via a latent code, enabling zero-shot novel view synthesis for out-of-distribution scenes without per-scene optimization. Choose this method when generalizing across a category of objects rather than reconstructing a single specific scene.

### [Activation Feature Density Approximation](12492-activation-feature-density-approximation.md)
This method estimates volumetric density directly from intermediate MLP activation features, replacing the coarse density network evaluation to speed up inference. Choose this method when real-time performance is critical and the scene structure can be inferred from hidden activations.

### [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md)
SDF Representations replace the implicit density field with a continuous scalar field representing the distance to the nearest surface, providing geometrically accurate surface extraction. Choose this method when precise mesh extraction and surface reconstruction are prioritized over volumetric opacity modeling.

### [Volume-Augmented NeRF](12973-volume-augmented-nerf.md)
Volume-Augmented NeRF binds explicit fluid volume values to the NeRF input, allowing the network to learn density and color variations driven by fluid flow in dynamic scenes. Choose this method for inverse rendering of dynamic fluid scenes where a differentiable simulator is available.

### [Neural-PIL Decomposition Architecture](12975-neural-pil-decomposition-architecture.md)
This architecture separates the scene representation into a view-dependent appearance model and a physically-based material model, enabling realistic relighting and material editing. Choose this method when disentangling illumination, geometry, and material properties is required for editing tasks.

### [Feature Fields](12995-feature-fields.md)
Feature Fields generalize NeRF to predict arbitrary per-point feature signals (e.g., semantic labels, geometric properties) in addition to color and density. Choose this method for tasks like zero-shot segmentation, object manipulation, or 3D detection that require high-dimensional 3D representations.

### [SAID-NeRF](13619-said-nerf.md)
SAID-NeRF exploits instance masks from Visual Foundation Models to enhance surface estimation for transparent objects by jointly optimizing a semantic field. Choose this method for reconstructing transparent objects where RGB data alone is ambiguous.

### [MINE](13661-mine.md)
MINE combines Multi-Plane Images (MPI) with NeRF to reconstruct dense 3D representations from single images, with complexity independent of the number of target views. Choose this method for efficient single-image novel view synthesis where scaling to many target views is a concern.

### [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md)
This family replaces the continuous MLP with explicit spatial data structures (voxels, octrees, hash tables) to eliminate heavy feed-forward computations, enabling real-time rendering. Choose this method for large-scale scenes or real-time applications where memory and speed are constrained.

### [Aleth-NeRF](13764-aleth-nerf.md)
Aleth-NeRF synthesizes normal-light views from under- or over-exposed inputs by modeling illumination adaptive volume rendering through local and global concealing fields. Choose this method for low-light or high-dynamic-range scene reconstruction from standard 8-bit LDR images.

### [Transformer and Vision Model Integration](13911-transformer-and-vision-model-integration.md)
This family integrates Vision Transformers (ViT) into NeRF architectures to replace or augment the MLP, enabling generalizable novel view synthesis from few images. Choose this method when leveraging global semantic features for few-shot or single-image reconstruction is beneficial.

### [Human and Specific Subject Modeling](13997-human-and-specific-subject-modeling.md)
This family modifies NeRF to represent dynamic, articulated human subjects using parametric body priors (e.g., SMPL) to disentangle motion from appearance. Choose this method for novel view synthesis of humans under unseen poses or for generalizing across subjects.

### [OPONeRF](14014-oponerf.md)
OPONeRF personalizes plenoptic mapping parameters for each sampled 3D point to handle test-time scene changes and robustness. Choose this method when dealing with dynamic scenes or contamination where local variations need to be discriminated from a frozen training timeframe.

### [Mixer-NeRF](14073-mixer-nerf.md)
Mixer-NeRF introduces a hybrid spatial feature learning module (MLCA) and Squeeze-and-Excitation (SE) module to mix spatial and channel features, addressing the loss of local detail in standard NeRFs. Choose this method for high-texture or complex lighting scenarios where local correlations are important.

### [Sparse View and Few-Shot Optimization](14428-sparse-view-and-few-shot-optimization.md)
This family addresses overfitting and artifact generation in NeRFs trained with drastically reduced viewpoints by introducing in-situ depth priors or pseudo-observations. Choose this method when training data is limited to fewer than 20 views.

### [Mixture-of-Experts and Modular Architectures](14429-mixture-of-experts-and-modular-architectures.md)
MoE architectures decompose the scene representation into specialized sub-networks dynamically activated based on input characteristics, reducing per-ray computation. Choose this method for handling irregular data distributions or boundary continuity issues in large scenes.

### [Uncertainty and Reliability](14487-uncertainty-and-reliability.md)
These methods extend NeRF architectures to quantify aleatoric and epistemic uncertainty, enabling filtering of poorly rendered views and reliable geometry assessment. Choose this method for active view selection or when confidence intervals are required for downstream applications.

### [Object Decomposition and Composition](14518-object-decomposition-and-composition.md)
This family decomposes the scene representation into distinct components (foreground/background, instances) for instance-level editing and segmentation. Choose this method when structural separation of scene entities is needed for manipulation or analysis.

### [Lighting and Appearance Models](14522-lighting-and-appearance-models.md)
These models decouple intrinsic scene properties (geometry, albedo) from extrinsic appearance factors (illumination, style) to enable explicit lighting control. Choose this method for relighting, style transfer, or intrinsic decomposition tasks.

### [Image Enhancement and Restoration Methods](14566-image-enhancement-and-restoration-methods.md)
These methods modify the pipeline to handle input defects like motion blur or transient occlusions, separating static scene geometry from artifacts. Choose this method for reconstructing sharp scenes from uncontrolled "in-the-wild" data.

### [Modular, Hierarchical, and Latent Architectures](14567-modular-hierarchical-and-latent-architectures.md)
This family introduces modularity and hierarchical structures to handle complex properties like non-rigid deformation or topological changes. Choose this method for dynamic, stratified, or semantically rich environments.

### [NeuralEditor](14895-neuraleditor.md)
NeuralEditor exploits an explicit point cloud representation as the structural basis for the implicit field, allowing direct geometry editing by moving points. Choose this method for interactive scene editing where explicit shape manipulation is required.

### [MuRF (Multi-Baseline Radiance Fields)](15007-murf-multi-baseline-radiance-fields.md)
MuRF is a feed-forward method for sparse view synthesis that constructs a target view frustum volume aligned with the novel view, addressing large camera baselines. Choose this method for sparse view synthesis with large baseline differences between input and target views.

### [Gaussian and Primitive-Based Representations](15011-gaussian-and-primitive-based-representations.md)
This family replaces the implicit function with explicit geometric structures (Gaussians, points, primitives) to improve rendering speed and editability. Choose this method for real-time rendering, high-frequency detail reconstruction, or explicit scene editing.

### [Decentralized Federated NeRF](15032-decentralized-federated-nerf.md)
DecentNeRF is a decentralized framework for learning global 3D scene representations from crowd-sourced images while preserving privacy. Choose this method for large-scale scene reconstruction where data privacy and server compute minimization are critical.

### [Neural Proxy](15220-neural-proxy.md)
Neural Proxy represents targets as animatable proxies (meshes with neural textures) to enable rendering of unseen animations without temporal learning. Choose this method for animating photo-realistic targets in a CG-like pipeline.

### [ViSNeRF](15255-visnerf.md)
ViSNeRF combines explicit spatial feature grids with implicit MLP decoders and tensor decomposition for efficient synthesis of visualizations from dynamic volumetric scenes. Choose this method for high-dimensional radiance fields with adjustable parameters like time or isovalue.

### [EBAD-NeRF](15441-ebad-nerf.md)
EBAD-NeRF reconstructs sharp 3D radiance fields from motion-blurred images and hybrid event-RGB data by modeling complex camera motion blur. Choose this method when input images are significantly blurred due to camera motion.

### [DINO-enhanced NeRF](15497-dino-enhanced-nerf.md)
This family integrates pre-trained DINO vision features into NeRF to enhance 3D reconstruction, particularly in few-shot scenarios. Choose this method when leveraging self-supervised semantic priors is beneficial, though note potential performance degradation in extreme few-shot settings.

### [NeurMiPs](15543-neurmips.md)
NeurMiPs represents a scene as a mixture of learnable planar surfaces, each acting as an expert predicting view-dependent color and transparency. Choose this method for superior extrapolation capabilities and real-time rendering speeds compared to voxel-based methods.

### [CodeNeRF](15544-codenerf.md)
CodeNeRF learns variation of object shapes and textures across a semantic category using disentangled latent embeddings, enabling synthesis from a single unposed image. Choose this method for generative modeling of object categories with explicit editing capabilities.

### [Dynamic Scene and Temporal Modeling](15546-dynamic-scene-and-temporal-modeling.md)
This family extends NeRF to represent time-varying scenes by augmenting the input space with time or modeling the scene as a dynamic system. Choose this method for novel view synthesis of video data or dynamic environments.

### [NeRF-Casting](15547-nerf-casting.md)
NeRF-Casting synthesizes specular reflections by casting reflection rays into the NeRF geometry and decoding features with a small MLP. Choose this method for photorealistic specular reflections with low computational overhead compared to Monte Carlo methods.

### [RoseNeRF](15548-rosenerf.md)
RoseNeRF simplifies complex ray interactions in transparent media to a single refraction event using a 4D light field representation. Choose this method for high-fidelity synthesis of real refractive objects without detailed surface reconstructions.

### [NeRF-Det](15549-nerf-det.md)
NeRF-Det explicitly models scene geometry as an opacity field and jointly trains a NeRF branch with a 3D detection pipeline. Choose this method for indoor 3D object detection where multi-view consistency constraints are needed for the detector.

### [Semantic Ray (S-Ray)](15552-semantic-ray-s-ray.md)
S-Ray learns a generalizable semantic field using Cross-Reprojection Attention to infer semantic labels across unseen scenes. Choose this method for generalizable semantic segmentation in novel viewpoints.

### [Neural Density-Distance Fields](15665-neural-density-distance-fields.md)
NeDDF reciprocally constrains distance and density fields, deriving density from the derivative of a distance field to handle boundaryless scenes. Choose this method for more stable meshes and better handling of transparency and thin surfaces.

### [LAENeRF](15738-laenerf.md)
LAENeRF is a unified framework for local appearance editing using a 3D edit grid and palette-based neural module. Choose this method for interactive recoloring or stylization of arbitrary 3D regions with smooth transitions.

### [ExtremeNeRF](15739-extremenerf.md)
ExtremeNeRF is a few-shot view synthesis framework that enforces multi-view albedo consistency to solve illumination-induced geometry distortion. Choose this method for sparse multi-view images under unconstrained, varying illumination.

### [Conditional and Latent Representations](15989-conditional-and-latent-representations.md)
This family introduces low-dimensional latent codes to condition the radiance field, enabling generative modeling and disentangled control of shape and appearance. Choose this method for generative control via learned latent distributions.

### [ActiveNeRF Model Architecture](16203-activenerf-model-architecture.md)
ActiveNeRF predicts prediction variance (uncertainty) for each sampled point, allowing the rendering pipeline to weigh contributions based on confidence. Choose this method for active view selection strategies.

### [SCARF](16591-scarf.md)
SCARF enables memory-efficient continual learning of multiple scenes using a single network by factorizing MLP weights into shared and scene-specific components. Choose this method for continual learning of scene sequences with catastrophic forgetting prevention.

### [PL-NeRF](18117-pl-nerf.md)
PL-NeRF is specialized for power transmission lines, using $L_\infty$ norm spatial compression and Integrated Positional Encoding to reduce aliasing. Choose this method for reconstructing long, narrow, low-texture structures.

### [Separate Modeling of Colors and Volume Density](18161-separate-modeling-of-colors-and-volume-density.md)
This method decouples density and color prediction into two distinct networks with different positional encoding frequencies to address overfitting in few-shot synthesis. Choose this method when geometry and appearance require different frequency representations.

### [Network Structure Modifications](20497-network-structure-modifications.md)
This broad category alters topology, input/output dimensions, or connectivity to address challenges like dynamic scenes or transparency. Choose this method when specific architectural changes like residual networks or MIMO structures are needed.

### [Neural blend weight field network](21760-neural-blend-weight-field-network.md)
This network predicts residual blend weights for skeletal animation by combining spatial encoding with per-frame latent codes. Choose this method for animating static canonical radiance fields into novel human poses.

### PIE-NeRF
PIE-NeRF integrates physics-based elastodynamic simulation with a neural radiance field representation using a meshless discretisation based on quadratic generalized moving least squares on top of the density field [S1]. This enables large deformations and nonlinear hyperelastic material simulation directly on the implicit representation and supports interactive manipulation of real-world captured scenes with complex geometries [S1].

### DäRF Implementation Details
DäRF uses K-planes as the NeRF backbone and DPT-hybrid as the Monocular Depth Estimation (MDE) model [S2, unofficial]. The optimizer is Adam with a learning rate of $1 \cdot 10^{-2}$ for NeRF and $1 \cdot 10^{-5}$ for MDE, using a cosine warmup learning rate schedule [S2, unofficial].

### S3-NeRF
S3-NeRF uses shadow and shading cues to infer scene geometry and enable single-image NeRF training [S1]. Key implementation differences include employing a UNISURF-based occupancy field 3D representation instead of density, using a modified physics-based rendering equation, and using occupancy-based shadow calculation [S1].

### NeRF with Frozen DINO Features
This variant integrates pre-trained DINOv2 features by projecting them to match NeRF input dimensions and concatenating them with positional encodings before feeding into the NeRF MLP [S3, unofficial]. The feature projection is defined as $f'(x) = W_f \cdot f(x) + b_f$ where $f(x)$ is the aggregated feature vector from all views, and $W_f, b_f$ are learned linear transformation parameters [S3, unofficial]. The input to the NeRF MLP is $F_\theta([\gamma(x), \gamma(d), f'(x)]) \rightarrow (c, \sigma)$ where $f'(x)$ is projected to 256 dimensions [S3, unofficial]. The DINO model is DINOv2-base, pre-trained on ImageNet, and frozen during training [S3, unofficial]. Features are bilinearly sampled at projected 2D coordinates $(u_i, v_i) = \Pi(P_i, x)$ for each 3D point $x$ [S3, unofficial].

### NeRF-Swin
NeRF-Swin performs super-resolution on an LR NeRF using released SwinIR models under the 'Real-World Image Super-Resolution' setting, trained on more than 10k LR-HR pairs [S4]. On the synthetic Blender dataset, SwinIR may produce false predictions due to domain mismatch [S4]. On the real-world LLFF dataset, SwinIR tends to be oversmooth and may predict false color or geometry [S4]. Performance metrics include: Blender ×2 (100x100): PSNR 26.34, SSIM 0.913, LPIPS 0.075; Blender ×4 (100x100): PSNR 24.85, SSIM 0.881, LPIPS 0.108; Blender ×2 (200x200): PSNR 28.03, SSIM 0.926, LPIPS 0.058; Blender ×4 (200x200): PSNR 26.78, SSIM 0.906, LPIPS 0.086; LLFF ×2: PSNR 25.18, SSIM 0.793, LPIPS 0.147; LLFF ×4: PSNR 23.26, SSIM 0.685, LPIPS 0.247 [S4].

### Neural Architecture Search for NeRF
This approach trains NeRFs with different combinations of network depth and width on a volumetric video frame and measures the quality of images rendered using PSNR [S5]. Network Depth ($d$) search space is {1, 2, 4, 6, 8} initially, narrowed to {2, 4}; Network Width ($w$) search space is {64, 128, 256} initially, narrowed to {128, 256} [S5]. Network depth provides the ability to learn hierarchical representations, while network width provides the capacity to 'memorize' the training data [S5]. Reducing width monotonically decreases quality, while reducing depth first improves then drops quality if smaller than 2 [S5].

### Multi-Identity NeRF
MI-NeRF is a neural rendering method that learns a single network to represent multiple identities by modeling multiplicative interactions between facial expressions and identity codes, enabling expression transfer and lip-syncing across unseen identities [S6, unofficial]. It learns a multiplicative module $M(E_i, i)$ that conditions the network, where $E_i$ is the expression code for image $i$ and $i$ is the learnable identity code [S6, unofficial]. The identity code dimension $d$ is set to 16 [S6, unofficial]. Unlike single-identity methods (AD-NeRF, LipNeRF) that learn audio-lip representations from only 3 or 20 seconds, MI-NeRF leverages information from multiple identities for more accurate lip synchronization [S6, unofficial]. It is used for facial expression transfer and lip-synced video synthesis [S6, unofficial].

### IntrinsicNeRF Model Architecture
IntrinsicNeRF is a model that outputs reflectance, shading, and residual terms for real-time augmented applications [S7]. It is trained using unsupervised prior and reflectance clustering as constraints in the loss function [S7].

### Piecewise Linear NeRF
PL-NeRF is a NeRF variant that uses a piecewise linear opacity formulation for volume rendering, replacing the standard piecewise constant opacity assumption [S8]. It optimizes separate networks for coarse and fine models, jointly trained with MSE loss on ground truth images [S8]. Hyperparameters include: Batch size: 1024 rays; Learning rate: $5 \times 10^{-4}$, decaying exponentially to $5 \times 10^{-5}$; Training iterations: 500k per scene; Coarse samples: 128; Fine samples: 64; Hardware: Single Nvidia V100 GPU [S8]. It outperforms vanilla NeRF (constant opacity) in all metrics (PSNR, SSIM, LPIPS) on Blender and LLFF datasets [S8]. It is implemented on top of NeRF-Pytorch by changing volume rendering to piecewise linear opacity formulation and utilizing exact importance sampling [S8].
