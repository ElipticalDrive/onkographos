# NLR Baseline

Also called: Neural Lumigraph Representation

## Overview
The NLR Baseline is a neural radiance field method that represents a scene using a set of learned basis functions (volumetric primitives) rather than a single monolithic MLP [S1, unofficial]. It solves the problem of efficient novel view synthesis by optimizing these basis coefficients to minimize photometric error, offering a distinct architectural alternative to standard MLP-based NeRF implementations [S1, unofficial]. It is distinguished from its siblings by its use of a fixed set of spatial basis functions combined with a lightweight network to predict coefficients, rather than querying a dense grid or a deep MLP for every sample point [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of calibrated camera poses and corresponding RGB images.
*   **Output:** A set of basis function coefficients and network weights that allow rendering of novel views.

**Data Structures:**
The specific layout of the basis functions and the internal network weights is not explicitly detailed in the provided sources [S1, unofficial]. The method relies on an implementation provided by the original authors [S1, unofficial].

**Steps:**
1.  **Ray Sampling:** Generate rays from the camera poses and sample points along them, similar to the shared principles of the parent family [S1, unofficial].
2.  **Basis Evaluation:** Evaluate the pre-defined volumetric basis functions at the sample points [S1, unofficial].
3.  **Coefficient Prediction:** Use a lightweight network to predict the coefficients for the basis functions based on the sample point coordinates and view direction [S1, unofficial].
4.  **Rendering:** Compute the color and density by combining the basis function values with the predicted coefficients, following the discretized volume rendering integral defined in the parent article [S1, unofficial].
5.  **Loss Computation:** Calculate the Mean Squared Error (MSE) between the rendered image and the ground truth training view [S1, unofficial].
6.  **Optimization:** Update the network weights and basis coefficients using gradient descent [S1, unofficial].

**Parameters:**
*   **Resolution:** Training and testing views are processed at 800x600 resolution [S1, unofficial].
*   **Iterations:** The number of iterations required for convergence is not explicitly stated, but it is noted that NLR requires more iterations per second than some competitors due to its architecture [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Implementation Dependency:** The method's performance and exact behavior depend heavily on the specific implementation provided by the authors, which may not be fully open-source or standardized [S1, unofficial].
*   **Convergence Speed:** While individual iterations may be slower than some methods, the total training time may be competitive due to fewer required iterations for convergence in some variants [S1, unofficial].

```python
def nlr_baseline_step(camera_pose, ground_truth_image, basis_functions, network_weights):
    # 1. Ray Sampling
    rays = generate_rays(camera_pose)
    sample_points = sample_along_rays(rays)
    
    # 2. Basis Evaluation
    # Evaluate basis functions at sample points
    basis_values = evaluate_basis_functions(sample_points, basis_functions)
    
    # 3. Coefficient Prediction
    # Predict coefficients using the lightweight network
    # View direction and position are typically concatenated
    coefficients = predict_coefficients(sample_points, camera_pose.direction, network_weights)
    
    # 4. Rendering
    # Combine basis values and coefficients to get density and color
    # This step follows the standard volume rendering equation from the parent article
    density, color = compute_density_and_color(basis_values, coefficients)
    rendered_image = volume_render(rays, density, color)
    
    # 5. Loss Computation
    loss = mean_squared_error(rendered_image, ground_truth_image)
    
    # 6. Optimization
    gradients = compute_gradients(loss, network_weights)
    update_weights(network_weights, gradients)
    
    return loss
```

## Subtopics

### MetaNLR Baseline
MetaNLR is a variant of NLR that wraps the NLR implementation with an outer meta-learning loop using the Reptile algorithm [S1, unofficial]. It learns the initialization of the shape and color networks to enable rapid specialization to new test scenes using only a few inner-loop steps [S1, unofficial]. It is chosen when few-shot novel view synthesis is required [S1, unofficial]. The meta-learning rate is set to $5 \times 10^{-2}$ [S1, unofficial]. It uses the same training and testing views at 800x600 resolution as the baseline NLR [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time is approximately 2.21 seconds per iteration [S1, unofficial]. Rendering time is approximately 0.025 seconds per frame [S1, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** On the DTU dataset, NLR takes 2.21 sec/iteration, which is slower than NeRF (0.40 sec/iteration) and IDR (0.2 sec/iteration) but faster than SVS* (1.38 sec/iteration after mesh computation) [S1, unofficial].
*   **Scaling:** Not given in the sources.
*   **Strengths:** Fast rendering time (0.025 sec/frame) [S1, unofficial].
*   **Limitations:** Slower training iteration time compared to some other methods [S1, unofficial].
*   **When to use:** When fast rendering is prioritized over training speed, or when using the MetaNLR variant for few-shot learning.
*   **When not:** When training speed is the primary constraint and fewer iterations are not guaranteed to offset the per-iteration cost.

## Background
NLR (Neural Lumigraph Representation) was introduced in the paper "Neural Lumigraph Representation" [S1, unofficial]. The baseline implementation was provided by the original authors for comparison in the study "Fast Training of Neural Lumigraph Representations using Meta Learning" [S1, unofficial]. It is used as a baseline for novel view synthesis tasks, particularly in comparison to meta-learning approaches like MetaNLR.
