# DDPM Denoise Function Network

Also called: 3D Convolutional Denoiser, DDPM Denoiser

## Overview
The DDPM Denoise Function Network is a 3D convolutional neural network used as the core denoiser in diffusion-based radiance field optimization. It predicts the noise component $\epsilon_\theta$ for a noisy 3D latent field, enabling the reverse diffusion process to iteratively refine the radiance field representation. It differs from sibling methods like [DDIM Sampling with Classifier-Free Guidance](8118-ddim-sampling-with-classifier-free-guidance.md) by its specific architectural choice of an 8-layer 3D U-Net-like structure designed for voxel grid inputs, rather than relying on 2D image latents or transformer-based attention mechanisms.

## How it works
**Inputs and Outputs:**
- Input: Noisy 3D latent field $x_t$ at timestep $t$, typically represented as a voxel grid.
- Output: Predicted noise $\epsilon_\theta(x_t, t)$ or the denoised field estimate $\tilde{f}_0^t$.

**Data Structures:**
The network processes 3D voxel grids. The input resolution is $32 \times 32 \times 32$. The latent representation is a tensor of shape $(N, C, D, H, W)$ where $N$ is batch size, $C$ is channels, and $D, H, W$ are spatial dimensions.

**Network Architecture:**
The network consists of 8 layers of 3D convolutions [S1, unofficial].
- **Encoder (Layers 1-4):** Four 3D convolutional layers with stride 2.
  - Layer widths (channels): 32, 64, 128, 256.
  - Resolution mapping: $32 \to 16 \to 8 \to 4$.
- **Decoder (Layers 5-8):** Four 3D transposed convolutional layers with stride 2.
  - Layer widths (channels): 256, 128, 64, 32.
  - Resolution mapping: $4 \to 8 \to 16 \to 32$.

**Algorithm Steps:**
1. **Forward Pass:** Pass the noisy latent $x_t$ through the 8-layer 3D convolution network to predict the noise $\epsilon_\theta(x_t, t)$ [S1, unofficial].
2. **Denoising Estimate:** Compute the estimated clean field $\tilde{f}_0^t$ using the standard DDPM reverse step formula, combining the prediction with the diffusion schedule parameters $\alpha_t, \bar{\alpha}_t$ [S1, unofficial][S2].
3. **Rendering:** Perform volumetric rendering on the current denoised estimate $\tilde{f}_0^t$ from a specific camera pose to generate a synthetic image $\tilde{I}_t$ [S2].
4. **Gradient Computation:** Compute the photometric error between the rendered image $\tilde{I}_t$ and the target foreground-masked image $I$. Calculate the gradient of this error with respect to the denoised field estimate: $\nabla_{\tilde{f}_t} (\tilde{I}_t, I)$ [S2].
5. **Guidance Update:** Update the denoised field estimate by steering it towards the target image using a guidance weight $\lambda$:
   $$ \tilde{f}_0^t \leftarrow \tilde{f}_0^t - \lambda \nabla_{\tilde{f}_t} (\tilde{I}_t, I) $$
   This step integrates the diffusion prior with the photometric consistency constraint [S2].

**Parameters:**
- Guidance weight $\lambda$: Small scalar value (exact value not specified in sources, described as "small") [S2].
- Optimizer: Adam optimizer with learning rate $10^{-2}$ [S2].
- L2 Regularization: Weighted with $5 \times 10^{-2}$ on the latent code [S2].

**Edge Cases and Pitfalls:**
- The method assumes the input latent is a 3D voxel grid. If the input is not aligned with the $32^3$ resolution, interpolation or padding is required [G].
- The gradient computation via volumetric rendering must be differentiable to allow backpropagation through the rendering process [S2].

## Subtopics

### Classifier Guidance for Image-to-Volume Synthesis
This variant conditions the diffusion model using a classifier guidance approach for image-to-volume synthesis. It steers the sampling process by computing gradients from the photometric error between the rendered view and the target image, similar to the main method but explicitly framed as classifier guidance for synthesizing 3D volumes from 2D images [S2].

## Operating characteristics
- **Time Complexity:** Depends on the number of diffusion steps and the cost of volumetric rendering per step. The 3D convolution network is relatively lightweight compared to 2D image models due to the small voxel resolution ($32^3$) [S1, unofficial].
- **Memory Complexity:** Requires storing the 3D voxel grid and intermediate feature maps. The peak memory usage is determined by the largest feature map ($256$ channels at $4 \times 4 \times 4$ resolution) [S1, unofficial].
- **Strengths:** Directly operates in 3D space, ensuring geometric consistency. Integrates photometric guidance for high-fidelity image-to-volume synthesis [S2].
- **Limitations:** Limited to low-resolution voxel grids ($32^3$) due to computational constraints of 3D convolutions. Not suitable for high-resolution detailed geometry without multi-resolution approaches [S1, unofficial].

## Background
The DDPM Denoise Function Network was introduced in the context of 3D radiance field diffusion models, specifically for tasks like image-to-volume synthesis and text-to-3D generation. It builds upon the Denoising Diffusion Probabilistic Models (DDPM) framework, adapting it to 3D voxel representations. The architecture was designed to efficiently encode and decode 3D spatial information using 3D convolutions [S1, unofficial][S2].
