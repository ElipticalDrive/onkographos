# NeRF Optimization via SDS
## Overview
NeRF Optimization via SDS optimizes a Neural Radiance Field (NeRF) to match a text prompt using Score Distillation Sampling (SDS) gradients [S1, unofficial]. It distinguishes itself from sibling methods like SUDS or Rip-NeRF by explicitly incorporating view-dependent text conditioning based on camera azimuth angles and specific regularization terms for entropy and orientation [S1, unofficial].

## How it works
The method optimizes NeRF parameters by rendering images, encoding them into a latent space, and computing SDS loss [S1, unofficial].

### Inputs and Outputs
*   **Inputs:** Text prompt, optional negative prompt, camera poses/intrinsics, and hyperparameters (`lr`, `lambda_entropy`, `lambda_orient`, `latent_iter_ratio`, etc.) [S1, unofficial].
*   **Outputs:** Optimized NeRF model parameters and rendered images [S1, unofficial].

### Data Structures
*   **NeRF Model (`NeRFNetwork`):** A Multi-Layer Perceptron (MLP) representing the radiance field [S1, unofficial]. It takes encoded 3D position and view direction as input and outputs volume density ($\sigma$) and RGB color ($\mathbf{c}$) [S1, unofficial]. The architecture follows the standard NeRF MLP structure with sinusoidal positional encoding (see [Model Architecture and Encoding](13550-model-architecture-and-encoding.md)) [S1, unofficial].
*   **Text Embeddings:** A dictionary mapping text conditions (e.g., "front", "side", "back", "default") to latent text embeddings [S1, unofficial].
*   **Dataset (`NeRFDataset`):** Stores images, camera parameters (rotation $R$, translation $T$, focal length $F$, principal point $C$), and optional masks [S1, unofficial].

### Numbered Steps
1.  **Initialize Text Embeddings:** Prepare text embeddings using `prepare_embeddings(sds, prompt, neg_prompt, view_dependent=True)` [S1, unofficial].
2.  **Initialize NeRF Model:** Instantiate `NeRFNetwork` and move it to the target device [S1, unofficial].
3.  **Configure Optimizer:** Create an Adan optimizer with learning rate $5 \times \text{lr}$ (where $\text{lr} = 10^{-3}$), eps $10^{-8}$, weight decay $2 \times 10^{-5}$, max grad norm $5.0$, and a constant LambdaLR scheduler [S1, unofficial].
4.  **Load Data:** Load training and test datasets (`NeRFDataset`) with specified height, width, and batch sizes [S1, unofficial].
5.  **Optimization Loop:** Iterate through epochs and training batches [S1, unofficial]. For each step:
    a.  **Calculate Iteration Ratio:** $\text{exp\_iter\_ratio} = (\text{global\_step} - \text{args.exp\_start\_iter}) / (\text{args.exp\_end\_iter} - \text{args.exp\_start\_iter})$ [S1, unofficial].
    b.  **Set Shading and Background Parameters:** If $\text{exp\_iter\_ratio} \le \text{args.latent\_iter\_ratio}$, set `ambient_ratio` = $1.0$, `shading` = "normal", `bg_color` = `None` [S1, unofficial]. Otherwise, sample `ambient_ratio` uniformly between $\text{args.min\_ambient\_ratio}$ and $1.0$, and choose `shading` as "textureless" (probability $\text{args.textureless\_ratio}$) or "lambertian" [S1, unofficial].
    c.  **Set Background Color:** If $\text{args.bg\_radius} > 0$ and a random number $> 0.5$, use `bg_net` (`bg_color=None`); else use a random single-color background $\mathbf{c}_{bg} \sim \text{Uniform}(0, 1)^3$ [S1, unofficial].
    d.  **Render:** Perform a forward pass through the NeRF model with rays, MVP matrix, $H$, $W$, and shading/background parameters. Reshape output to $[B, 3, H, W]$ [S1, unofficial].
    e.  **Select Text Conditioning:** If `args.view_dep_text` is true, calculate azimuth angle $\phi$ of the camera [S1, unofficial]. If $|\phi| \le 45^\circ$, use `embeddings["front"]` [S1, unofficial]. If $45^\circ < |\phi| \le 135^\circ$, use `embeddings["side"]` [S1, unofficial]. Else, use `embeddings["back"]` [S1, unofficial]. Otherwise, use `embeddings["default"]` [S1, unofficial].
    f.  **Encode to Latent Space:** Interpolate `pred_rgb` to $512 \times 512$ using bilinear interpolation, then encode: $\text{latents} = \text{sds.encode\_imgs}(\text{interpolate}(\text{pred\_rgb}, \text{size}=(512, 512)))$ [S1, unofficial].
    g.  **Compute SDS Loss:** Calculate $\mathcal{L}_{SDS} = \text{sds.sds\_loss}(\text{latents}, \text{text\_cond}, \text{text\_uncond})$, where `text_cond` is the selected text embedding and `text_uncond` is the unconditional embedding [S1, unofficial].
    h.  **Entropy Regularization:** If $\text{args.lambda\_entropy} > 0$, compute entropy loss on alpha values ($\alpha$) from rendering. Clamp $\alpha$ to $[10^{-5}, 1 - 10^{-5}]$ [S1, unofficial]. $\mathcal{L}_{entropy} = -\mathbb{E}[\alpha \log_2 \alpha + (1 - \alpha) \log_2 (1 - \alpha)]$. Scale by $\text{args.lambda\_entropy} \times \min(1, 2 \times \text{global\_step} / \text{args.iters})$ [S1, unofficial].
    i.  **Orientation Regularization:** If $\text{args.lambda\_orient} > 0$ and `loss_orient` exists in outputs, add $\text{args.lambda\_orient} \times \text{loss\_orient}$ to loss [S1, unofficial].
    j.  **Backward Pass:** Sum all loss components. Perform backward pass. If `args.loss_scaling` is true, use `GradScaler` for mixed precision; otherwise, use standard backward [S1, unofficial].

### Pseudocode
```python
import torch
import torch.nn.functional as F

def compute_azimuth(cameras):
    """Compute azimuth angle in degrees from camera rotation matrices."""
    if isinstance(cameras, torch.Tensor):
        forward = -cameras[:, :, 2]
        return torch.atan2(forward[:, 1], forward[:, 0]) * 180.0 / torch.pi
    else:
        Rs = torch.stack([c.R for c in cameras])
        forward = -Rs[:, :, 2]
        return torch.atan2(forward[:, 1], forward[:, 0]) * 180.0 / torch.pi

def optimize_nerf_sds(sds_model, nerf_model, dataset, prompt, neg_prompt, args, device):
    embeddings = sds_model.prepare_embeddings(prompt=prompt, neg_prompt=neg_prompt, view_dependent=True)
    optimizer = torch.optim.Adan(nerf_model.parameters(), lr=5e-3, eps=1e-8, weight_decay=2e-5, max_grad_norm=5.0)
    scheduler = torch.optim.lr_scheduler.LambdaLR(optimizer, lr_lambda=lambda epoch: 1.0)
    global_step = 0
    total_iters = args.iters

    for epoch in range(args.epochs):
        for batch in dataset:
            images, cameras, masks = batch
            exp_iter_ratio = (global_step - args.exp_start_iter) / (args.exp_end_iter - args.exp_start_iter)

            if exp_iter_ratio <= args.latent_iter_ratio:
                ambient_ratio = 1.0
                shading = "normal"
                bg_color = None
            else:
                ambient_ratio = torch.rand(1).item() * (1.0 - args.min_ambient_ratio) + args.min_ambient_ratio
                shading = "textureless" if torch.rand(1).item() < args.textureless_ratio else "lambertian"
                bg_color = None

            if args.bg_radius > 0 and torch.rand(1).item() > 0.5:
                bg_color = None
            else:
                bg_color = torch.rand(3, device=device)

            pred_rgb, alphas, outputs = nerf_model.render(cameras=cameras, img_size=(args.height, args.width), ambient_ratio=ambient_ratio, shading=shading, bg_color=bg_color)

            if args.view_dep_text:
                azimuth = compute_azimuth(cameras)
                if torch.abs(azimuth) <= 45:
                    text_cond = embeddings["front"]
                elif torch.abs(azimuth) <= 135:
                    text_cond = embeddings["side"]
                else:
                    text_cond = embeddings["back"]
            else:
                text_cond = embeddings["default"]

            text_uncond = embeddings.get("uncond", embeddings["default"])
            pred_rgb_resized = F.interpolate(pred_rgb, size=(512, 512), mode="bilinear", align_corners=False)
            latents = sds_model.encode_imgs(pred_rgb_resized)
            loss = sds_model.sds_loss(latents, text_cond, text_uncond)

            if args.lambda_entropy > 0:
                alphas_clamped = torch.clamp(alphas, min=1e-5, max=1-1e-5)
                loss_entropy = (-(alphas_clamped * torch.log2(alphas_clamped) + (1 - alphas_clamped) * torch.log2(1 - alphas_clamped))).mean()
                loss += args.lambda_entropy * min(1.0, 2 * global_step / total_iters) * loss_entropy

            if args.lambda_orient > 0 and "loss_orient" in outputs:
                loss += args.lambda_orient * outputs["loss_orient"]

            if args.loss_scaling:
                scaler = torch.cuda.amp.GradScaler()
                with torch.cuda.amp.autocast():
                    scaler.scale(loss).backward()
                scaler.step(optimizer)
                scaler.update()
            else:
                loss.backward()

            optimizer.step()
            optimizer.zero_grad()
            scheduler.step()
            global_step += 1
```

### Parameters
*   `lr`: Base learning rate, typically $10^{-3}$ [S1, unofficial].
*   `args.exp_start_iter`, `args.exp_end_iter`: Iteration range for exponential scheduling [S1, unofficial].
*   `args.latent_iter_ratio`: Threshold for switching shading/background strategies [S1, unofficial].
*   `args.min_ambient_ratio`: Minimum ambient ratio for later training stages [S1, unofficial].
*   `args.textureless_ratio`: Probability of using "textureless" shading [S1, unofficial].
*   `args.bg_radius`: Radius for background network usage [S1, unofficial].
*   `args.view_dep_text`: Boolean flag for view-dependent text conditioning [S1, unofficial].
*   `args.lambda_entropy`: Weight for entropy regularization [S1, unofficial].
*   `args.lambda_orient`: Weight for orientation regularization [S1, unofficial].

### Edge Cases and Pitfalls
*   **Precision:** Mixed precision training (`GradScaler`) is recommended to handle potential numerical instability in SDS gradients [S1, unofficial].
*   **Boundaries:** Alpha values must be clamped to $[10^{-5}, 1-10^{-5}]$ before computing entropy to avoid $\log(0)$ [S1, unofficial].

## Operating characteristics
*   **Measured Performance:** On the "Truck" dataset, the method achieved a Mean PSNR of 27.717 and Mean SSIM of 0.926 [S1, unofficial].
*   **When to Use:** When generating 3D scenes from text prompts is required [S1, unofficial].
*   **When Not to Use:** Not given in the sources.

## Background
The method is implemented in the repository "Diffusion-guided-3D-Representations" [S1, unofficial]. It builds upon the concept of Score Distillation Sampling (SDS), adapting it for NeRF optimization. The approach incorporates view-dependent text conditioning and specific regularization techniques to improve the quality of the generated 3D models [S1, unofficial].
