# REF2-NeRF
Also called: Reflection and Refraction aware Neural Radiance Field

## Overview
REF2-NeRF is a NeRF-based modeling method designed for scenes containing transparent objects, specifically glass cases, where multiple reflection and refraction effects occur [S1]. It solves the challenge of accurately modeling such scenes by estimating refraction surfaces and separating direct (view-independent) and reflected (view-dependent) light components using two independent MLPs: a glass network for refraction offsets and a decomposition NeRF for rendering [S1]. Unlike methods that assume straight light rays or only handle reflections, REF2-NeRF handles both refraction and reflection in scenes with multiple transparent objects by introducing a view-independent density field and a view-dependent offset field [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A set of $n$ images $\{I_k\}$ taken from different viewpoints, with predetermined camera poses [S1].
*   **Output:** A rendered image $C(\mathbf{r})$ for a given ray $\mathbf{r}$, along with separated view-independent and view-dependent components [S1].

**Data Structures and Network Layout**
The method uses four main neural network components:
1.  **Glass Network ($\Theta_{gl}$):** An MLP that takes positional encoding of position $\Gamma(\mathbf{x})$ and view direction $\Gamma(\mathbf{d})$ as input. It outputs glass density $\sigma_{gl} \in \mathbb{R}$ and an offset vector $\Delta \mathbf{x} \in \mathbb{R}^3$ [S1].
2.  **Decomposition NeRF ($\Theta_{nf}$):** An MLP that takes positional encoding of the adjusted position $\Gamma(\mathbf{x}')$ and view direction $\Gamma(\mathbf{d})$ as input. It outputs view-independent density $\sigma_{vi} \in \mathbb{R}$, view-independent color $\mathbf{c}_{vi} \in \mathbb{R}^3$, view-dependent density $\sigma_{vd} \in \mathbb{R}$, and a view-dependent feature vector $\mathbf{f}_{vd} \in \mathbb{R}^\theta$ [S1].
3.  **Decoder MLP ($\Theta_{dc}$):** Takes the rendered view-dependent feature vector $\mathbf{F}_{vd}$ as input and outputs the reflection color $\mathbf{C}_{vd}$ [S1].
4.  **Gate MLP ($\Theta_{gt}$):** Takes the rendered view-dependent feature vector $\mathbf{F}_{vd}$ as input and outputs a blending parameter $\alpha \in [0, 1]$ [S1].

**Parameters**
*   Feature vector dimension $\theta$: 64 [S1].
*   Regularization weight $\epsilon$: $10^{-5}$ [S1].
*   Coarse sampling points: 128 [S1].
*   Hierarchical fine sampling points: 64 [S1].
*   Additional glass density sampling points: 32 [S1].
*   Additional view-independent density sampling points: 32 [S1].
*   Total fine model sampling points: 192 [S1].

**Algorithm Steps**

1.  **Ray Sampling:** For a ray $\mathbf{r}$, sample $N$ points $\mathbf{x}_i$ at uniform intervals (coarse stage, $N=128$) [S1].
2.  **Glass Network Forward Pass:** For each sampled point $\mathbf{x}_i$ and view direction $\mathbf{d}_i$, compute glass density $\sigma_{gl,i}$ and offset $\Delta \mathbf{x}_i$ using $\Theta_{gl}$:
    $$ \sigma_{gl,i}, \Delta \mathbf{x}_i = \Theta_{gl}(\Gamma(\mathbf{x}_i), \Gamma(\mathbf{d}_i)) $$
    [S1]
3.  **Refraction Weight Calculation:** Calculate the weight $w_i$ for each sampling point $i$ using glass density $\sigma_{gl,i}$ and the distance $\delta_{gl,i}$ between adjacent points. Compute transmittance $T_i$:
    $$ w_i = T_i (1 - \exp(-\sigma_{gl,i} \delta_{gl,i})) $$
    $$ T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_{gl,j} \delta_{gl,j}\right) $$
    [S1]
4.  **Position Adjustment:** Adjust the position of each sample point to account for refraction. The adjusted position $\mathbf{x}'_i$ is calculated by cumulatively adding the weighted offsets:
    $$ \mathbf{x}'_i = \mathbf{x}_i + \sum_{j=1}^{i} w_j \Delta \mathbf{x}_j $$
    [S1]
5.  **View-Independent Rendering:** Perform volume rendering on the adjusted positions $\mathbf{x}'_i$ using view-independent density $\sigma_{vi,i}$ and color $\mathbf{c}_{vi,i}$ from $\Theta_{nf}$. Note that $\Theta_{nf}$ for this component does not use view direction $\mathbf{d}$ [S1].
    $$ \mathbf{C}_{vi}(\mathbf{r}) = \sum_{i=1}^{N} T_{vi,i} (1 - \exp(-\sigma_{vi,i} \delta_{vi,i})) \mathbf{c}_{vi,i} $$
    where $T_{vi,i}$ is calculated similarly to Eq. 4 using $\sigma_{vi}$ [S1].
6.  **View-Dependent Feature Rendering:** Perform volume rendering on adjusted positions $\mathbf{x}'_i$ and view directions $\mathbf{d}_i$ using view-dependent density $\sigma_{vd,i}$ and feature vector $\mathbf{f}_{vd,i}$ from $\Theta_{nf}$:
    $$ \mathbf{F}_{vd}(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_{vd,i} \delta_{vd,i})) \mathbf{f}_{vd,i} $$
    [S1]
7.  **View-Dependent Color and Blending:** Decode the rendered feature vector $\mathbf{F}_{vd}$ into reflection color $\mathbf{C}_{vd}$ using $\Theta_{dc}$ and determine blending parameter $\alpha$ using $\Theta_{gt}$:
    $$ \mathbf{C}_{vd}(\mathbf{r}) = \Theta_{dc}(\mathbf{F}_{vd}(\mathbf{r})) $$
    $$ \alpha(\mathbf{r}) = \Theta_{gt}(\mathbf{F}_{vd}(\mathbf{r})) $$
    [S1]
8.  **Final Image Composition:** Combine the view-independent and view-dependent components:
    $$ \mathbf{C}(\mathbf{r}) = \mathbf{C}_{vi}(\mathbf{r}) + \alpha(\mathbf{r}) \mathbf{C}_{vd}(\mathbf{r}) $$
    [S1]
9.  **Training:** Optimize parameters $\{\Theta_{gl}, \Theta_{nf}, \Theta_{dc}, \Theta_{gt}\}$ by minimizing the total loss $L$:
    $$ L = L_{render} + \epsilon L_{offset} $$
    where $L_{render} = \sum_{\mathbf{r} \in R} \|\bar{\mathbf{C}}(\mathbf{r}) - \mathbf{C}(\mathbf{r})\|^2$ and $L_{offset} = \sum_{\mathbf{x}, \mathbf{d}} \|\Delta \mathbf{x}\|^2$ [S1].

**Pseudocode**

```python
import torch
import torch.nn as nn
import math

class REF2NeRF:
    def __init__(self, theta_dim=64, epsilon=1e-5):
        """
        Initialize the REF2-NeRF model components.
        :param theta_dim: Dimension of the view-dependent feature vector.
        :param epsilon: Regularization weight for offset loss.
        """
        # Glass Network: Input [Gamma(x), Gamma(d)] -> [sigma_gl, delta_x]
        self.gl_network = nn.Sequential(
            nn.Linear(2 * 256, 256), # Assuming 256 dim for positional encoding of x and d
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 4) # 1 for sigma_gl, 3 for delta_x
        )
        
        # Decomposition NeRF: Input [Gamma(x'), Gamma(d)] -> [sigma_vi, c_vi, sigma_vd, f_vd]
        # Note: sigma_vi and c_vi do not depend on d in the forward pass logic described,
        # but the network architecture takes both. We split outputs.
        self.decomp_nerf = nn.Sequential(
            nn.Linear(2 * 256, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 1 + 3 + 1 + theta_dim) # sigma_vi(1), c_vi(3), sigma_vd(1), f_vd(theta_dim)
        )
        
        # Decoder MLP: Input F_vd -> C_vd
        self.decoder = nn.Sequential(
            nn.Linear(theta_dim, 24),
            nn.ReLU(),
            nn.Linear(24, 24),
            nn.ReLU(),
            nn.Linear(24, 3) # RGB color
        )
        
        # Gate MLP: Input F_vd -> alpha
        self.gate = nn.Sequential(
            nn.Linear(theta_dim, 24),
            nn.ReLU(),
            nn.Linear(24, 24),
            nn.ReLU(),
            nn.Linear(24, 1) # Scalar alpha
        )
        
        self.epsilon = epsilon
        self.theta_dim = theta_dim

    def positional_encoding(self, x, num_freq_bands=10):
        """Standard positional encoding for NeRF."""
        # Placeholder for standard NeRF positional encoding function
        # Returns concatenated sin/cos of scaled frequencies
        pass

    def forward(self, rays_o, rays_d, num_coarse=128, num_fine=192):
        """
        Render a batch of rays.
        :param rays_o: Origin of rays [B, 3]
        :param rays_d: Direction of rays [B, 3]
        :param num_coarse: Number of coarse samples
        :param num_fine: Number of fine samples (192 in REF2-NeRF)
        :return: Rendered colors [B, 3]
        """
        # 1. Coarse Sampling
        t_coarse = torch.linspace(0, 1, num_coarse).to(rays_o.device)
        x_coarse = rays_o.unsqueeze(1) + rays_d.unsqueeze(1) * t_coarse.unsqueeze(0) # [B, N_coarse, 3]
        
        # 2. Glass Network Forward Pass (Coarse)
        # Compute positional encodings
        # Note: In practice, positional encoding is applied to x and d
        # For simplicity, assuming a helper function or inline expansion
        # Here we assume x_coarse and rays_d are encoded.
        # Let's assume we have a function get_pe(x) that returns [B, 256]
        # and get_pe_d(d) that returns [B, 256]
        
        # To make this self-contained, we'll define a simple PE for demonstration
        # In real implementation, this would be the standard NeRF PE
        def simple_pe(x, num_freq=10):
            # x: [B, 3] or [B, N, 3]
            x = x.view(-1, 3)
            freq_bands = 2.0 ** torch.linspace(0, num_freq-1, num_freq).to(x.device)
            x = x.unsqueeze(-1) * freq_bands.unsqueeze(0) # [B*N, 3, num_freq]
            x = torch.cat([torch.sin(x), torch.cos(x)], dim=-1) # [B*N, 6*num_freq]
            return x.view(x_coarse.shape[0], x_coarse.shape[1], -1)

        pe_x_coarse = simple_pe(x_coarse)
        pe_d_coarse = simple_pe(rays_d.unsqueeze(1).expand(-1, num_coarse, -1))
        
        gl_input = torch.cat([pe_x_coarse, pe_d_coarse], dim=-1)
        gl_output = self.gl_network(gl_input) # [B, N_coarse, 4]
        sigma_gl = gl_output[..., 0] # [B, N_coarse]
        delta_x = gl_output[..., 1:] # [B, N_coarse, 3]
        
        # 3. Refraction Weight Calculation (Coarse)
        # Calculate distances between adjacent points
        # delta_t = t[i] - t[i-1]
        # delta_x_dist = delta_t * ||d|| (assuming d is normalized)
        # For simplicity, assume rays_d are normalized and delta_t is uniform
        delta_t = t_coarse[1] - t_coarse[0]
        delta_dist = delta_t * torch.ones_like(sigma_gl) # [B, N_coarse]
        
        # Transmittance T_i = exp(-sum_{j=1}^{i-1} sigma_gl_j * delta_dist_j)
        # We need to compute this cumulatively
        alpha_gl = 1 - torch.exp(-sigma_gl * delta_dist) # [B, N_coarse]
        T_gl = torch.cumprod(1 - alpha_gl, dim=1) # [B, N_coarse]
        T_gl = torch.cat([torch.ones_like(T_gl[:, :1]), T_gl[:, :-1]], dim=1) # Shift right, fill first with 1
        
        # Weights w_i = T_i * (1 - exp(-sigma_gl_i * delta_dist_i))
        w = T_gl * alpha_gl # [B, N_coarse]
        
        # 4. Position Adjustment (Coarse)
        # x'_i = x_i + sum_{j=1}^{i} w_j * delta_x_j
        # Cumulative sum of weighted offsets
        weighted_offsets = w.unsqueeze(-1) * delta_x # [B, N_coarse, 3]
        cumulative_offsets = torch.cumsum(weighted_offsets, dim=1) # [B, N_coarse, 3]
        x_prime_coarse = x_coarse + cumulative_offsets # [B, N_coarse, 3]
        
        # 5. Fine Sampling
        # Hierarchical sampling based on coarse density
        # In REF2-NeRF, additional points are sampled using glass density and view-independent density
        # Total fine points = 192 (128 coarse + 64 hierarchical + 32 glass + 32 view-indep)
        # The description says "Total points for fine model: 192".
        # This implies the fine model processes 192 points.
        # We need to generate 192 points.
        # Let's assume we sample 192 points uniformly for simplicity in this pseudocode,
        # as the exact hierarchical sampling logic for the 3 additional sets is not fully detailed
        # beyond "sampled using glass density" and "sampled using view-independent density".
        # However, the standard NeRF coarse-to-fine is used for the 64 points.
        # The 32+32 points are "additional".
        # For the purpose of this implementation, we will assume the fine model receives
        # a set of 192 points, which are adjusted positions.
        
        t_fine = torch.linspace(0, 1, num_fine).to(rays_o.device)
        x_fine = rays_o.unsqueeze(1) + rays_d.unsqueeze(1) * t_fine.unsqueeze(0) # [B, N_fine, 3]
        
        # Apply refraction adjustment to fine points
        # We need to interpolate the offset field to the fine points
        # This is complex. A simpler approach is to assume the fine points are also adjusted
        # by the glass network.
        # Let's re-run the glass network for fine points
        pe_x_fine = simple_pe(x_fine)
        pe_d_fine = simple_pe(rays_d.unsqueeze(1).expand(-1, num_fine, -1))
        gl_input_fine = torch.cat([pe_x_fine, pe_d_fine], dim=-1)
        gl_output_fine = self.gl_network(gl_input_fine)
        sigma_gl_fine = gl_output_fine[..., 0]
        delta_x_fine = gl_output_fine[..., 1:]
        
        # Recalculate weights and offsets for fine points
        delta_dist_fine = delta_t * torch.ones_like(sigma_gl_fine)
        alpha_gl_fine = 1 - torch.exp(-sigma_gl_fine * delta_dist_fine)
        T_gl_fine = torch.cumprod(1 - alpha_gl_fine, dim=1)
        T_gl_fine = torch.cat([torch.ones_like(T_gl_fine[:, :1]), T_gl_fine[:, :-1]], dim=1)
        w_fine = T_gl_fine * alpha_gl_fine
        weighted_offsets_fine = w_fine.unsqueeze(-1) * delta_x_fine
        cumulative_offsets_fine = torch.cumsum(weighted_offsets_fine, dim=1)
        x_prime_fine = x_fine + cumulative_offsets_fine # [B, N_fine, 3]
        
        # 6. Decomposition NeRF Forward Pass
        pe_x_prime_fine = simple_pe(x_prime_fine)
        pe_d_fine = simple_pe(rays_d.unsqueeze(1).expand(-1, num_fine, -1))
        decomp_input = torch.cat([pe_x_prime_fine, pe_d_fine], dim=-1)
        decomp_output = self.decomp_nerf(decomp_input) # [B, N_fine, 1+3+1+theta_dim]
        
        sigma_vi = decomp_output[..., 0]
        c_vi = decomp_output[..., 1:4]
        sigma_vd = decomp_output[..., 4]
        f_vd = decomp_output[..., 5:]
        
        # 7. View-Independent Rendering
        # T_vi_i calculation is same as Eq 4 using sigma_vi
        alpha_vi = 1 - torch.exp(-sigma_vi * delta_dist_fine)
        T_vi = torch.cumprod(1 - alpha_vi, dim=1)
        T_vi = torch.cat([torch.ones_like(T_vi[:, :1]), T_vi[:, :-1]], dim=1)
        
        C_vi = torch.sum(T_vi.unsqueeze(-1) * alpha_vi.unsqueeze(-1) * c_vi, dim=1) # [B, 3]
        
        # 8. View-Dependent Feature Rendering
        # Use T_i from glass density? The formula says "Ti" which is the same as Eq 4.
        # Eq 4 uses sigma_gl. So we use T_gl_fine.
        F_vd = torch.sum(T_gl_fine.unsqueeze(-1) * alpha_gl_fine.unsqueeze(-1) * f_vd, dim=1) # [B, theta_dim]
        
        # 9. View-Dependent Color and Blending
        C_vd = self.decoder(F_vd) # [B, 3]
        alpha = torch.sigmoid(self.gate(F_vd)) # [B, 1]
        
        # 10. Final Image Composition
        C = C_vi + alpha * C_vd # [B, 3]
        
        return C

    def compute_loss(self, rendered_color, target_color):
        """
        Compute the total loss.
        :param rendered_color: [B, 3]
        :param target_color: [B, 3]
        :return: Total loss scalar
        """
        L_render = torch.mean((rendered_color - target_color) ** 2)
        
        # L_offset requires access to delta_x from the glass network
        # This is a simplified placeholder. In practice, you need to store delta_x
        # from the forward pass.
        # For this pseudocode, we assume we have access to delta_x from the last forward pass
        # or we recompute it.
        # Let's assume we have a method to get the last delta_x
        # delta_x = self.last_delta_x # [B, N, 3]
        # L_offset = torch.mean(delta_x ** 2)
        
        # Since we can't easily store state in this simple class, we'll skip the exact L_offset calculation
        # in the loss function and assume it's handled by the training loop.
        # L_offset = torch.mean(self.last_delta_x ** 2)
        
        # L = L_render + epsilon * L_offset
        # return L_render + self.epsilon * L_offset
        return L_render
```

**Edge Cases and Pitfalls**
*   **Precision:** The cumulative sum of weighted offsets can lead to precision issues if the number of samples is large or the offsets are significant.
*   **Boundaries:** The method assumes known camera poses, which can be difficult to acquire in scenes with glass objects. A robotic arm is recommended [S1].
*   **Degenerate Input:** If the glass density is zero everywhere, the method degenerates to a standard NeRF with view-dependent features.

## Operating characteristics
*   **Time Complexity:** Training takes approximately 10 hours per scene on an Nvidia RTX 4080 GPU for 200,000 iterations [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Scaling:** The method uses a coarse-to-fine sampling strategy with 192 points for the fine model [S1].
*   **Strengths:** Handles both refraction and reflection in scenes with multiple transparent objects. Separates direct and reflected light components [S1].
*   **Limitations:** Requires predetermined camera poses, which are difficult to acquire in glass scenes [S1].
*   **When to use:** Scenes with glass cases or multiple transparent objects where both refraction and reflection are present [S1].
*   **When not to use:** Scenes without transparent objects or where only reflection or only refraction is present, as other methods may be simpler or more efficient [S1].

## Background
REF2-NeRF was proposed in 2024 by authors who addressed the challenges of modeling scenes with multiple glass objects, such as objects in a glass showcase [S1]. It builds on the LB-NeRF method, which simplifies refraction as an offset from a straight light ray, by introducing a view-independent density field and a view-dependent offset field [S1]. It also differs from MS-NeRF, which uses multiple explicit spaces for mirrors, by using a single view-dependent feature field to handle reciprocal reflections from multiple glass plates [S1].
