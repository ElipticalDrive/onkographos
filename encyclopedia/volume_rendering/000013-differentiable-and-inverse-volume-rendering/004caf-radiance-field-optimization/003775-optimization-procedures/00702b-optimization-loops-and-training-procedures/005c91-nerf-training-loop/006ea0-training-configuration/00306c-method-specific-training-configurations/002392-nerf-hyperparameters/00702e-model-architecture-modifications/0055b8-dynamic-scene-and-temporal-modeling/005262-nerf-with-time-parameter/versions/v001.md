# NeRF with Time Parameter

Also called: NeRF + time, NeRF with Time Parameter Baseline, Time-NeRF

## Overview
This method adapts the static Neural Radiance Field (NeRF) architecture to handle dynamic scenes by introducing a temporal coordinate $t$ as an additional input to the implicit function [S1]. It solves the problem of representing time-varying geometry and appearance, which standard NeRF cannot capture due to its static assumption [S1]. Unlike sibling methods that may use explicit motion fields or particle systems, this approach directly extends the input domain of the MLP, serving as a baseline for time-aware rendering [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Spatial coordinates $\mathbf{x} \in \mathbb{R}^3$, view direction $\mathbf{d} \in \mathbb{R}^3$, and time parameter $t \in \mathbb{R}$.
*   **Outputs:** Volume density $\sigma \in \mathbb{R}$ and emitted color $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures:**
The model is a Multi-Layer Perceptron (MLP) $F_\Theta$. The input vector is constructed by concatenating positional encodings.
*   Spatial encoding: $\gamma(\mathbf{x})$
*   Direction encoding: $\gamma(\mathbf{d})$
*   Time encoding: $\gamma(t)$

**Positional Encoding:**
The time parameter $t$ is encoded using the same scheme as spatial coordinates [S1]:
$$
\gamma(t) = [\sin(2^0\pi t), \cos(2^0\pi t), \dots, \sin(2^{d_t-1}\pi t), \cos(2^{d_t-1}\pi t)]
$$
where $d_t$ is the number of frequency bands for time [S1]. This encoding is concatenated with $\gamma(\mathbf{x})$ and $\gamma(\mathbf{d})$ before being fed into the MLP [S1].

**Rendering Equation:**
Rendering follows standard volume integration, but density and color are sampled at the specific time $t$ of the target view [S1]:
$$
C(\mathbf{r}, t) = \int_{s_n}^{s_f} T(s, t) \sigma(\mathbf{r}(s), t) c(\mathbf{r}(s), \mathbf{d}, t) ds
$$
where the transmittance $T(s, t)$ is defined as:
$$
T(s, t) = \exp\left(-\int_{s_n}^{s} \sigma(\mathbf{r}(s'), t) ds'\right)
$$
Here, $\mathbf{r}(s) = \mathbf{o} + s\mathbf{d}$ is the ray equation, $\mathbf{o}$ is the camera origin, and $s_n, s_f$ are near and far clipping planes [S1].

**Training:**
The model is trained by minimizing the photometric loss between rendered images and ground truth frames at corresponding timestamps [S1]. The configuration reported for NeRF's real forward-facing experiments is used [S1].

def positional_encode_time(t, num_freq_bands):
    """
    Encodes time parameter t using sinusoidal positional encoding.
    """
    frequencies = [2**i * math.pi for i in range(num_freq_bands)]
    encoded = []
    for freq in frequencies:
        encoded.append(math.sin(freq * t))
        encoded.append(math.cos(freq * t))
    return encoded

def nerf_with_time_forward(x, d, t, model, num_freq_bands_x, num_freq_bands_d, num_freq_bands_t):
    """
    Forward pass for NeRF with time parameter.
    """
    # Encode inputs
    x_enc = positional_encode(x, num_freq_bands_x)
    d_enc = positional_encode(d, num_freq_bands_d)
    t_enc = positional_encode_time(t, num_freq_bands_t)
    
    # Concatenate encodings
    input_vector = x_enc + d_enc + t_enc
    
    # Pass through MLP
    sigma, color = model(input_vector)
    
    return sigma, color

## Subtopics

### Temporal Compression of NeRF Models
A compression strategy for sequences of NeRF models that exploits temporal redundancy by treating the first model as a key-frame and compressing only the deltas between successive models [S2]. To implement this:
1.  Initialize the NeRF for the first frame from scratch (trained from the beginning) [S2].
2.  For subsequent frames, initialize the new NeRF based on the previous frame's trained NeRF to encourage temporal redundancy and save training time [S2].
3.  Calculate the delta between the current frame's NeRF weights and the previous frame's NeRF weights [S2].
4.  Apply exponent-based quantization and Huffman coding to the deltas [S2].
5.  To restore a model, accumulate the decoded deltas to the reference model (the previous frame's model) [S2].

## Operating characteristics
**Strengths and Limitations:**
Adding a time parameter improves quality over vanilla NeRF for dynamic scenes [S1]. However, it still lacks detail, suffers from blurry predictions, and fails to reason about scene dynamics [S1]. It is not suitable for complex dynamic scenes where significant structural changes occur [S1].

**Performance:**
On KITTI dataset scenes, NeRF + time achieves a PSNR of 24.18, SSIM of 0.677, and LPIPS of 0.425, which is better than vanilla NeRF (PSNR 23.34, SSIM 0.662, LPIPS 0.415) but worse than the proposed Neural Scene Graphs method (PSNR 26.66, SSIM 0.806, LPIPS 0.186) [S1].

## Background
This method was introduced as a baseline modification to NeRF to handle dynamic scenes by simply adding a time input [S1]. It was evaluated on the KITTI dataset to assess the limitations of simple time-parameterization compared to more advanced methods like Neural Scene Graphs [S1].
