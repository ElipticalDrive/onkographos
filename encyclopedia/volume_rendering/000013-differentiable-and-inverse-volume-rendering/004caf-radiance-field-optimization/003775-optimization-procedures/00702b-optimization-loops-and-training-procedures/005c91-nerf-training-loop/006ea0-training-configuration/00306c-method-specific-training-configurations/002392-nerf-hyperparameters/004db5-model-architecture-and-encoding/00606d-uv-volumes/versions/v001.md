# UV Volumes

Also called: UV Volume Representation

## Overview
UV Volumes is a method for real-time, editable free-view rendering of human performers that decouples smooth volumetric geometry from high-frequency appearance [S1]. It encodes density and UV coordinates in a 3D feature volume while storing detailed appearance in a 2D Neural Texture Stack (NTS), distinguishing itself from standard NeRFs by enabling real-time performance (30 FPS) and retexturing via pose-dependent texture generation [S1].

## How it works
**Inputs:** Multi-view video frames, a posed SMPL model parameterized by pose $\theta$, and latent codes $\mathbf{z}$ anchored to the SMPL vertices [S1].
**Outputs:** A rendered color image for a given camera ray $\mathbf{r}$ [S1].

**Data Structures:**
1.  **UV Volumes:** A 3D feature volume generated by a 3D sparse CNN. It stores the feature vector $f(\mathbf{x}, \mathbf{z}, \theta)$ at 3D points $\mathbf{x}$ [S1].
2.  **Neural Texture Stack (NTS):** A set of 2D texture maps $\mathcal{E}_k$, one for each body part $k$, generated by a CNN texture generator $G$ [S1].
3.  **SMPL Model:** Provides the 3D mesh geometry and pose $\theta$ [S1].

**Steps:**
1.  **Generate UV Volumes:** Voxelize the latent codes $\mathbf{z}$ anchored on the SMPL vertices. Input these voxels into a 3D sparse CNN to produce the 3D feature volume (UV Volumes) [S1].
2.  **Ray Sampling:** For a camera ray $\mathbf{r}$, sample $N$ points $\{\mathbf{x}_i\}_{i=1}^N$ between near and far bounds. The sampling positions are determined by the posed SMPL model geometry [S1].
3.  **Feature Query:** Query the feature vector $f(\mathbf{x}_i, \mathbf{z}, \theta)$ from the UV Volumes at each sampled point $\mathbf{x}_i$ [S1].
4.  **Density Prediction:** Predict the volume density $\sigma(\mathbf{x}_i)$ using a shallow MLP $M_\sigma$:
    $$ \sigma(\mathbf{x}_i) = M_\sigma(f(\mathbf{x}_i, \mathbf{z}, \theta)) $$
    where $M_\sigma$ is a shallow MLP, $f$ is the feature vector, $\mathbf{x}_i$ is the 3D point, $\mathbf{z}$ are latent codes, and $\theta$ is the pose [S1].
5.  **Volume Rendering of Features:** Render the feature volume into a 2D feature map $\mathcal{F}(\mathbf{r})$ using standard volume rendering:
    $$ \mathcal{F}(\mathbf{r}) = \sum_{i=1}^N T_i (1 - \exp(-\sigma(\mathbf{x}_i) \delta_i)) f(\mathbf{x}_i, \mathbf{z}, \theta) $$
    where $T_i = \exp \left( - \sum_{j=1}^{i-1} \sigma(\mathbf{x}_j) \delta_j \right)$ is the accumulated transmittance, and $\delta_i = \|\mathbf{x}_{i+1} - \mathbf{x}_i\|_2$ is the distance between adjacent sampled points [S1].
6.  **UV Coordinate Prediction:** Decode the feature map $\mathcal{F}(\mathbf{r})$ pixel-by-pixel using an MLP $M_{uv}$ to predict part assignments $\hat{\mathcal{P}}$ and UV coordinates $\hat{\mathcal{U}}, \hat{\mathcal{V}}$:
    $$ \left(\hat{\mathcal{P}}(\mathbf{r}), \hat{\mathcal{U}}(\mathbf{r}), \hat{\mathcal{V}}(\mathbf{r})\right) = M_{uv}(\mathcal{F}(\mathbf{r})) $$
    where $\hat{\mathcal{P}}$ represents the probability of the pixel belonging to a specific body part, and $\sum_{k=1}^{N_k} \hat{\mathcal{P}}_k(\mathbf{r}) = 1$ [S1].
7.  **Generate Neural Texture Stack:** For each body part $k \in \{1, \dots, N_k\}$, generate the texture stack $\mathcal{E}_k$ using a CNN texture generator $G$ conditioned on pose $\theta$ and a one-hot label vector $\mathbf{k}$:
    $$ \mathcal{E}_k = G(\theta, \mathbf{k}) $$
    The number of body parts is $N_k = 24$ [S1].
8.  **Color Reconstruction:** Interpolate texture embeddings from the NTS using the predicted UV coordinates and part assignments. The final color is recovered by querying the NTS with the UV coordinates $\hat{\mathcal{U}}, \hat{\mathcal{V}}$ weighted by the part assignments $\hat{\mathcal{P}}$ [S1].

**Parameters:**
*   $N_k = 24$: Number of body parts used to subdivide the body surface for the NTS [S1].
*   $N$: Number of samples along the ray [S1].

**Edge Cases and Pitfalls:**
*   The method relies on the accuracy of the posed SMPL model for ray sampling and geometry [S1].
*   The UV coordinates must be consistent with the Densepose UV unwrap used to query the NTS [S1].

## Operating characteristics
*   **Performance:** Renders 960 × 540 resolution images at an average of 30 FPS on CMU Panoptic, ZJU Mocap, and H36M datasets [S1].
*   **Strengths:** Real-time rendering speed; editability (retexturing); better generalization on novel poses and shapes due to the mapping between the parameterized human model and smooth texture coordinates [S1].
*   **Limitations:** Requires a posed SMPL model and multi-view video input for training; limited to human performance rendering [S1].

## Background
UV Volumes was proposed to address the high computational costs of real-time free-view human rendering in VR/AR applications [S1]. It separates high-frequency appearance from the 3D volume, encoding smooth densities and UV coordinates in a 3D volume and detailed appearance in a 2D Neural Texture Stack (NTS) [S1]. The method was published in CVPR 2023 [S1].
