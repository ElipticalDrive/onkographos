# Lifting 2D GAN to 3D Radiance Field

Also called: GAN-to-NeRF Lifting, Lift3D

## Overview
This method distills 3D structural knowledge from a pretrained 2D Generative Adversarial Network (StyleGAN2) into a shared conditional Neural Radiance Field (NeRF) to generate novel 3D objects with arbitrary poses for data augmentation [S1]. It differs from naive isolated NeRF reconstruction by jointly optimizing a shared NeRF and latent codes for all objects simultaneously (Generative Latent Optimization), thereby learning shared category priors and mitigating noise from imperfect GAN interpretation [S1].

## How it works
**Inputs:**
*   Pretrained StyleGAN2 model (trained on LSUN Car dataset) [S1].
*   A set of 3D object templates (e.g., ShapeNet cars) [S1].
*   Ground truth masks for real data (optional, for IoU loss) [S1].

**Outputs:**
*   A shared conditional NeRF $\Phi_\theta$ parameterized by $\theta$ [S1].
*   Optimized latent codes $\hat{Z}$ for each generated object [S1].

**Data Structures:**
1.  **StyleGAN2 Latent Space ($w^*$):** The latent code $z$ is mapped to $w^* = (w_1^*, \dots, w_{16}^*)$ via 16 affine transformations [S1].
    *   $w_p$: First 8 layers, designated as "pose latents" [S1].
    *   $w_{sa}$: Remaining 8 layers, designated as "shape/appearance latents" [S1].
2.  **NeRF Representation (Tri-plane):**
    *   Three axis-aligned orthogonal feature planes (XY, YZ, XZ) [S1].
    *   Each plane is a 2D tensor of features [S1].
    *   A single-layer SIREN-based MLP outputs density $\sigma$ and RGB color $c$ [S1].
3.  **Pose Label ($P$):** Defined by azimuth ($0^\circ-360^\circ$) and elevation ($0^\circ-20^\circ$) on a unit sphere looking at the origin [S1].

**Numbered Steps:**

1.  **Disentangle StyleGAN2:**
    *   Use optimization-based GAN inversion [43] on a 3D template model (e.g., ShapeNet car) to find template latents [S1].
    *   Associate the first 8 layers of these template latents with specific pose labels $P$ obtained by rendering the template under 200 different viewpoints [S1].

2.  **Generate 2D Training Data:**
    *   Sample pose latents $w_p$ from the disentangled pose latent space [S1].
    *   Sample shape/appearance latents $w_{sa}$ randomly from a Gaussian distribution $\mathcal{Z}$ [S1].
    *   Combine to form full latent $w^*$ and generate 2D images $I$ using StyleGAN2 [S1].
    *   Filter out generated images with confidence lower than 0.5 (regarded as noisy) [S1].
    *   Filter out objects outside drivable areas by using a pretrained HRNet [37] to extract drivable areas in 2D, converting to Bird's-Eye-View (BEV) via Inverse Perspective Mapping (IPM), and removing objects outside this region [S1].

3.  **Joint Optimization (GLO):**
    *   Optimize the shared NeRF parameters $\theta$ and latent codes $z$ for all objects simultaneously [S1].
    *   Minimize the total loss $\mathcal{L}$ defined below [S1].

4.  **Volumetric Rendering:**
    *   For a camera ray $r(t) = o + td$ with bounds $t_n$ and $t_f$, compute transmittance $T(t)$ and expected color $C(r)$ [S1]:
        $$ T(t) = \exp\left(-\int_{t_n}^{t} \sigma(r(s)) ds\right) $$
        $$ C(r) = \int_{t_n}^{t_f} T(t) \sigma(r(t)) c(r(t), d) dt $$
    *   The NeRF $\Phi_\theta(z, P)$ takes latent $z$ and pose $P$ as conditions [S1].
    *   To query the tri-plane representation for a point $x$:
        1.  Project $x$ onto the three orthogonal planes [S1].
        2.  Retrieve feature vectors via bilinear interpolation [S1].
        3.  Sum the three feature vectors [S1].
        4.  Feed the sum to the SIREN-based MLP conditioned on $z$ to output $\sigma$ and $c$ [S1].

5.  **Shadow Generation:**
    *   Cast a pre-computed shadow map at the bottom of each object to improve visual quality [S1].

6.  **Composition:**
    *   Predict binary mask $\hat{M}$ based on accumulated transmittance at the furthest bound $t_f$ [S1]:
        $$ \hat{M} = \begin{cases} 1 & \text{if } T(t_f) \geq 0.5 \\ 0 & \text{if } T(t_f) < 0.5 \end{cases} $$
    *   Alpha blend foreground image $I_2$ and background image $I_1$ using mask $M$ (smoothed with a Gaussian filter) [S1]:
        $$ I_{out} = I_1 \times M + I_2 \times (1 - M) $$

**Formulas:**

*   **Optimization Objective:**
    $$ \hat{Z}, \hat{\theta} = \arg \min_{z, \theta} \mathcal{L}(I, \Phi_{\theta}(z, P)) $$
    Where $\hat{Z}$ is the concatenation of all latent codes, $P$ is the pose label, and $\mathcal{L}$ is the loss function [S1].

*   **Total Loss:**
    $$ \mathcal{L} = \sum_{i=1}^{N} (\mathcal{L}_{RGB} + \lambda_{IoU}\mathcal{L}_{IoU} + \lambda_{perc}\mathcal{L}_{perc}) $$
    Where $N$ is the number of image pairs, and $\lambda_{IoU}, \lambda_{perc}$ are loss weights [S1].

*   **Photometric Loss (L1):**
    $$ \mathcal{L}_{RGB} = \frac{1}{CHW} |I_i - \Phi_{\theta}(z_i, P_i)| $$
    Where $C, H, W$ are channel, height, and width dimensions [S1].

*   **Perceptual Loss:**
    $$ \mathcal{L}_{perc} = \frac{1}{CHW} |VGG(I_i) - VGG(\hat{I}_i)| $$
    Where VGG is the 16-layer VGG network pretrained on ImageNet [S1].

*   **IoU Loss:**
    $$ \mathcal{L}_{IoU} = 1 - \frac{\hat{M} \cap M^*}{\hat{M} \cup M^*} $$
    Where $\hat{M}$ is the predicted mask and $M^*$ is the ground truth mask (extracted via PointRend) [S1].

**Parameters:**
*   **Pose Sampling Range:** Azimuth $0^\circ-360^\circ$, Elevation $0^\circ-20^\circ$ [S1].
*   **Mask Threshold:** $T(t_f) \geq 0.5$ for foreground [S1].
*   **Confidence Filter:** Filter images with confidence $< 0.5$ [S1].
*   **Loss Weights:** $\lambda_{IoU}, \lambda_{perc}$ (values not given in the sources) [S1].

**Edge Cases and Pitfalls:**
*   **Noisy GAN Sampling:** Generated images may be corrupted or have incorrect pose labels. Mitigated by filtering images with confidence $< 0.5$ and using drivable area constraints [S1].
*   **Inductive Bias Neglect:** Naive isolated reconstruction fails to learn shared priors. Addressed by joint optimization (GLO) [S1].
*   **Precision:** L1 loss is used for photometric error, which is robust to outliers compared to L2 [S1].
*   **Boundaries:** Shadow maps are pre-computed and cast at the bottom of objects to handle lighting interactions [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Evaluated on KITTI and nuScenes datasets for 3D object detection tasks using AP and mAP metrics [S1].
*   **Scaling:** The method can generate a large object bank (e.g., 1000 vehicles, each with 200 multi-view images) [S1].
*   **Strengths:** Enables generation of novel 3D objects with arbitrary poses; leverages high-quality 2D GAN priors; efficient 3D representation via tri-plane [S1].
*   **Limitations:** Relies on the quality of the pretrained 2D GAN; requires GAN inversion for template latents; noisy GAN sampling can hinder reconstruction if not filtered [S1].
*   **When to Use:** When data augmentation for 3D object detection is needed, and a high-quality 2D GAN for the target category is available [S1].
*   **When Not to Use:** When the target category lacks a suitable pretrained 2D GAN or when precise geometric accuracy without generative priors is required [S1].
