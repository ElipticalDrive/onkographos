# Interval Score Matching

Also called: LucidDreamer (ISM)

## Overview
Interval Score Matching (ISM) modifies Score Distillation Sampling (SDS) by replacing the standard DDPM forward noising process with DDIM inversion and introducing supervision from multiple interval diffusion steps [S1][S2, unofficial]. This avoids the high reconstruction error associated with single-step updates in standard SDS [S1][S2, unofficial].

## How it works
Inputs: A frozen diffusion model $\epsilon_\theta$, a radiance field $\Theta$, a prompt, and a diffusion schedule [G].
Outputs: Gradients $\nabla_\Theta L$ for updating $\Theta$ [G].

Data Structures:
- $x_0$: The rendered image (or latent) from $\Theta$ [G].
- $x_t$: The noisy sample at timestep $t$ [G].
- $\hat{\epsilon}$: The noise prediction from the frozen model [G].

Steps:
1. Render an image $x_0$ from the current radiance field parameters $\Theta$ [G].
2. Apply DDIM inversion to generate noisy samples $x_t$ from $x_0$, replacing the standard DDPM forward noising process [S1][S2, unofficial].
3. Select a set of interval timesteps $t$ across the diffusion process rather than a single timestep [G].
4. For each interval step $t$, query the frozen diffusion model $\epsilon_\theta$ to predict the noise $\hat{\epsilon}_\theta(x_t, \cdot)$ [G].
5. Compute the gradient signal using the residual $\hat{\epsilon}_\theta - \epsilon$ weighted by a schedule function $\omega(t)$, and backpropagate through the differentiable renderer to update $\Theta$ [G].

Pseudocode:
```python
def interval_score_matching(render_fn, diffusion_model, prompt, theta, timesteps, weights):
    x0 = render_fn(theta)
    # Standard DDIM inversion algorithm [G]
    def ddim_invert(x_t, t, eps_pred):
        alpha_t, alpha_prev = diffusion_model.alphas[t], diffusion_model.alphas[t-1]
        return (torch.sqrt(alpha_prev) / torch.sqrt(alpha_t)) * (x_t - torch.sqrt(1 - alpha_t) * eps_pred) + \
               torch.sqrt(1 - alpha_prev) * eps_pred
    noisy_samples = [x0]
    for t in reversed(timesteps):
        eps_pred = diffusion_model.predict_noise(noisy_samples[-1], t, prompt)
        noisy_samples.append(ddim_invert(noisy_samples[-1], t, eps_pred))
    noisy_samples.reverse()
    gradients = 0.0
    for t, weight in zip(timesteps, weights):
        xt = noisy_samples[t]
        epsilon_pred = diffusion_model.predict_noise(xt, t, prompt)
        epsilon_actual = diffusion_model.noise_schedule.sample_noise(xt.shape)
        residual = epsilon_pred - epsilon_actual
        grad = torch.autograd.grad(xt, theta, grad_outputs=weight * residual, retain_graph=True)[0]
        gradients += grad
    return gradients
```

## Background
Origin: Interval Score Matching was proposed by the authors of LucidDreamer [S1][S2, unofficial].
History: It was introduced as an improvement to SDS loss to enhance the quality of 3D asset generation from text prompts [S1][S2, unofficial].
Usage: It is used in differentiable rendering pipelines to optimize NeRF, 3D Gaussian Splatting (3DGS), and DMTet representations [S1][S2, unofficial].
