# Deceptive-NeRF/3DGS

Also called: Deceptive-3DGS, Deceptive-NeRF, DeceptiveX

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that densifies input observations by generating photorealistic pseudo-observations via a diffusion model, treating them as real training views to overcome overfitting and artifacts in few-view settings [S1]. Unlike diffusion-based regularizers (e.g., SDS) that infer a large diffusion model at every optimization step to score rendered images, this method infers the diffusion model only during the pseudo-observation generation phase, drastically reducing computational cost while improving reconstruction quality [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $W$ sparse input images $I = \{I_1, I_2, \dots, I_W\}$ with known calibrated camera poses.
*   **Outputs:** A trained NeRF or 3D Gaussian Splatting (3DGS) representation capable of rendering novel views.

**Data Structures:**
*   **NeRF Representation:** Parameterized by $\theta$. For MLP-based NeRFs, it maps $(\mathbf{x}, \mathbf{d}) \mapsto (\sigma, \mathbf{c})$ [S1]. For voxel-grid variants, it uses explicit voxel grids [S1].
*   **3DGS Representation:** Composed of Gaussians. Each Gaussian $i$ is defined by position, covariance (or scale/orientation), opacity logit $o_i$, and spherical harmonic (SH) coefficients $\mathbf{c}_i$ [S1].
*   **Bounding Box:** Defined by the outermost input cameras [S1].
*   **Pseudo-Observations:** RGB-D images generated by the diffusion model.

**Algorithm Steps:**

1.  **Initialization:**
    *   For Deceptive-NeRF: Initialize the NeRF backbone (e.g., Nerfacto) [S1].
    *   For Deceptive-3DGS: Randomly initialize Gaussians without utilizing Colmap point clouds [S1]. Define the bounding box using the outermost input cameras [S1].

2.  **Coarse Rendering:**
    *   Train the current NeRF/3DGS representation on the current set of real and pseudo-observations.
    *   Render coarse novel view images and depth maps from viewpoints within the bounding box.
    *   For NeRF, the predicted color for a pixel is computed via volume rendering [S1]:
        $$ \hat{\mathbf{C}} = \sum_{k=1}^K \hat{T}(t_k)\alpha(\sigma(t_k)\delta_k)\mathbf{c}(t_k) $$
        where $\hat{T}(t_k) = \exp\left(-\sum_{k'=1}^{k-1} \sigma(t_k)\delta(t_k)\right)$, $\alpha(x) = 1 - \exp(-x)$, and $\delta_k = t_{k+1} - t_k$ [S1].
    *   For 3DGS, the color is computed as [S1]:
        $$ \hat{\mathbf{C}} = \sum_{i=1}^n \mathbf{c}_i \alpha_i \prod_{j=1}^{i-1}(1-\alpha_j) $$
        where $\alpha_i$ is given by evaluating a 2D Gaussian multiplied by the opacity logit $o$ [S1].

3.  **Uncertainty Estimation:**
    *   Compute a reconstruction uncertainty measure from the coarse renderings. High uncertainty corresponds to areas with artifacts or inconsistencies [S1]. This uncertainty map guides the diffusion model [S1].

4.  **Pseudo-Observation Generation (Deceptive Diffusion):**
    *   Feed the coarse rendered images into a deceptive diffusion model.
    *   The diffusion model is guided by the uncertainty measure to generate high-quality pseudo-observations (RGB-D images) from the corresponding viewpoints [S1].
    *   The diffusion model enhances the RGB-D images, removing artifacts present in the coarse renderings [S1].

5.  **Optimization:**
    *   Optimize the NeRF/3DGS representation by minimizing the photometric loss (mean squared error) on both the real input images and the newly generated pseudo-observations [S1].
    *   The loss function is defined as [S1]:
        $$ \mathcal{L} = \sum_{i=1}^n \|\mathbf{C}_i - \hat{\mathbf{C}}_i\|^2 $$
        where $\mathbf{C}_i$ are the target colors (real or pseudo) and $\hat{\mathbf{C}}_i$ are the rendered colors [S1].

6.  **Iteration:**
    *   Randomly sample novel views $\{\phi_{pseudo}\}$ within the bounding box defined by the outermost input cameras [S1].
    *   Alternate between generating pseudo-observations and training scene representations.
    *   Repeat the process for a fixed number of iterations (typically 5) [S1].
    *   This process densifies the input observations by 5 to 10 times [S1].

**Parameters:**
*   **Densification Factor:** 5 to 10 times the original amount of observations [S1].
*   **Number of Alternation Iterations:** 5 [S1].
*   **Backbone:** Nerfacto for Deceptive-NeRF; Splatfacto for Deceptive-3DGS [S1].
*   **Backbone Settings:** Default proposal sampling, scene contraction, and appearance embeddings [S1].

**Edge Cases and Pitfalls:**
*   **Sparse Inputs:** Standard NeRF/3DGS pipelines suffer from severe artifacts and overfitting with sparse inputs [S1].
*   **Uncertainty Guidance:** Without uncertainty guidance, the diffusion model cannot effectively remove artifacts in coarse renderings, leading to inconsistencies between pseudo-observations and input images [S1]. Ablation shows PSNR drops from 20.44 to 18.61 without uncertainty guidance [S1].
*   **Initialization:** For 3DGS, random initialization is used instead of Colmap point clouds [S1].

## Operating characteristics
*   **Time Complexity:** Nearly tenfold faster than methods using diffusion models as per-step regularizers/scorers [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:**
    *   On Hypersim dataset with 10 input views:
        *   Deceptive-NeRF ("View Densifier"): PSNR 20.44, SSIM 0.748, LPIPS 0.173, Training Time 17min, Rendering FPS 5.3 [S1].
        *   Regularizer variant: PSNR 19.31, SSIM 0.710, LPIPS 0.253, Training Time 2h40min, Rendering FPS 1.1 [S1].
    *   On DTU dataset scan 65 with 9 input views: Chamfer Distance 1.86 (vs NeRF 3.75, FreeNeRF 3.63, DiffusioNeRF 1.93) [S1].
*   **Scaling:** Works effectively with as few as 3 input images [S1].
*   **Strengths:** High-quality sparse-view reconstruction; significantly faster training and rendering compared to regularizer-based diffusion methods; effective at removing artifacts in coarse renderings.
*   **Limitations:** Requires a pre-trained 2D diffusion model; performance depends on the quality of the coarse initial reconstruction.
*   **When to use:** Sparse-view reconstruction scenarios where standard NeRF/3DGS fail due to overfitting or artifacts.
*   **When not to use:** When computational resources for diffusion model inference are extremely limited (though less than regularizer methods, it still requires inference); when dense input views are available (standard methods may suffice).

## Background
*   **Origin:** Proposed by X. Liu et al. in "Deceptive-NeRF/3DGS: Diffusion-Generated Pseudo-Observations for High-Quality Sparse-View Reconstruction" [S1].
*   **History:** The method addresses the limitation of NeRF and 3DGS requiring large numbers of training views [S1]. It builds on the idea of using diffusion priors for 3D reconstruction but shifts from regularization to view densification [S1].
*   **Usage:** Used on Hypersim dataset [47], mip-NeRF 360 dataset [4], and DTU dataset [S1].
