# Mip-NeRF Optimization and Activation Details

Also called: JaxNeRF Training Procedure, Mip-NeRF Misc. Changes

## Overview
This article details the specific implementation choices for training Mip-NeRF and JaxNeRF that improve optimization stability and robustness without significantly altering accuracy or speed [S1]. These "miscellaneous" changes address common failure modes in neural radiance field training, such as catastrophic gradient vanishing and saturation issues, by modifying activation functions, input encoding strategies, and learning rate schedules [S1]. Unlike standard NeRF implementations, Mip-NeRF removes the identity concatenation from the MLP input and employs shifted softplus and widened sigmoid activations to ensure smoother optimization landscapes [S1].

## How it works
The training process minimizes the photometric difference between rendered pixel colors and ground truth images using the Adam optimizer [S1]. The method modifies the standard NeRF training loop in three key areas: input encoding, activation functions, and learning rate scheduling [S1].

### Inputs and Outputs
*   **Inputs:** Training images, camera intrinsics, camera extrinsics, and dataset metadata (near/far clipping planes) [S1].
*   **Outputs:** Optimized MLP weights for density $\tau$ and color $\mathbf{c}$ [S1].

### Data Structures
*   **Integrated Positional Encoding (IPE):** The input to the MLP is the IPE only. The original NeRF practice of concatenating the positional encoding with the original position and view direction (identity encoding) is removed [S1].
*   **View Direction Encoding:** The ray direction $\mathbf{d}$ is normalized, positionally encoded with $L=4$ frequencies, and injected into the last layer of the MLP after $\tau$ is predicted but before $\mathbf{c}$ is predicted [S1].

### Activation Functions
Standard ReLU and sigmoid activations are replaced to prevent optimization failure modes [S1].

1.  **Density Activation:** The density $\tau$ is produced using a shifted softplus function:
    $$ \tau = \log(1 + \exp(x - 1)) $$
    This is equivalent to initializing the biases for $\tau$ to $-1$, resulting in small initial density values. This prevents the MLP from emitting negative values everywhere, which would cause zero gradients and catastrophic failure [S1].

2.  **Color Activation:** The color $\mathbf{c}$ is produced using a "widened" sigmoid:
    $$ \mathbf{c} = \frac{1 + 2\epsilon}{1 + \exp(-x)} - \epsilon $$
    where $\epsilon = 0.001$. This function saturates slightly outside the $[0, 1]$ range, avoiding failure modes where the network attempts to explain black or white pixels by saturating activations [S1].

### Learning Rate Schedule
The learning rate $\eta_i$ at iteration $i$ combines a warmup phase and a logarithmic annealing phase [S1].

1.  **Warmup:** For the first $n_w = 2500$ iterations, a scale factor is annealed from $\lambda_w = 0.01$ to $1$.
2.  **Annealing:** The base learning rate is annealed logarithmically from $\eta_0 = 5 \cdot 10^{-4}$ to $\eta_n = 5 \cdot 10^{-6}$ over $n$ total iterations.

The combined formula is:
$$ \eta_i = \left( \lambda_w + (1 - \lambda_w) \sin\left(\frac{\pi}{2} \operatorname{clip}\left(\frac{i}{n_w}, 0, 1\right)\right) \right) \times \exp\left( \left(1 - \frac{i}{n}\right) \log(\eta_0) + \frac{i}{n} \log(\eta_n) \right) $$

### Pseudocode

```python
import math

def density_activation(x):
    """
    Shifted softplus activation for density.
    Equivalent to initializing bias to -1.
    """
    return math.log(1 + math.exp(x - 1))

def color_activation(x):
    """
    Widened sigmoid activation for color.
    Saturates slightly outside [0, 1] to handle black/white pixels.
    """
    epsilon = 0.001
    return (1 + 2 * epsilon) / (1 + math.exp(-x)) - epsilon

def learning_rate_schedule(i, n, n_w, eta_0, eta_n):
    """
    Compute learning rate at iteration i.
    
    Args:
        i: Current iteration index.
        n: Total number of iterations.
        n_w: Number of warmup iterations.
        eta_0: Initial learning rate (5e-4).
        eta_n: Final learning rate (5e-6).
        
    Returns:
        Learning rate at iteration i.
    """
    # Warmup factor: anneals from 0.01 to 1
    # clip(i/n_w, 0, 1) ensures the factor is 0.01 for i < 0 (not possible) 
    # and 1 for i >= n_w.
    clip_val = min(max(i / n_w, 0.0), 1.0)
    warmup_factor = 0.01 + (1 - 0.01) * math.sin((math.pi / 2) * clip_val)
    
    # Logarithmic annealing factor
    anneal_factor = math.exp((1 - i / n) * math.log(eta_0) + (i / n) * math.log(eta_n))
    
    return warmup_factor * anneal_factor

def forward_pass(position, view_direction, mlp_weights):
    """
    Simplified forward pass incorporating Mip-NeRF specific details.
    
    Args:
        position: 3D coordinate.
        view_direction: Ray direction vector.
        mlp_weights: Weights and biases of the MLP.
        
    Returns:
        density: Scalar density value.
        color: RGB color vector.
    """
    # 1. Input Encoding: Use IPE only, no identity concatenation
    # Note: IPE computation depends on the specific Gaussian parameters 
    # of the conical frustum, which are handled in the sampling step.
    # Here we assume 'encoded_pos' is the result of IPE.
    encoded_pos = compute_ipe(position) 
    
    # 2. MLP Forward Pass for Density
    # The MLP takes encoded_pos as input.
    # The last layer produces a raw value for density.
    raw_density = mlp_forward(encoded_pos, mlp_weights['density_layers'])
    
    # Apply shifted softplus activation
    density = density_activation(raw_density)
    
    # 3. View Direction Handling
    # Normalize direction
    normalized_dir = normalize(view_direction)
    # Positional encoding with L=4
    encoded_dir = positional_encoding(normalized_dir, L=4)
    
    # 4. MLP Forward Pass for Color
    # Concatenate density features (or intermediate features) with encoded_dir
    # Inject encoded_dir into the last layer before color prediction
    raw_color = mlp_forward_with_view_dependency(
        encoded_pos, 
        encoded_dir, 
        mlp_weights['color_layers']
    )
    
    # Apply widened sigmoid activation
    color = color_activation(raw_color)
    
    return density, color
```

### Edge Cases and Pitfalls
*   **Negative Density:** Using standard ReLU for density can lead to the MLP emitting negative values everywhere, causing zero gradients and optimization failure. The shifted softplus prevents this [S1].
*   **Saturation on Black/White Pixels:** Standard sigmoid saturation can cause optimization failure when explaining extreme pixel values. The widened sigmoid mitigates this [S1].
*   **Identity Concatenation:** Including the original position and view direction in the MLP input (identity encoding) does not meaningfully improve performance or speed and complicates the formalization of IPE features. It is removed in Mip-NeRF [S1].

## Subtopics

### [Mip-NeRF 360 Optimization Setup](3426-mip-nerf-360-optimization-setup.md)
Mip-NeRF 360 Optimization Setup defines the training configuration for unbounded neural radiance fields, specifically addressing the challenge of rendering large-scale, "in-the-wild" scenes with limited video memory. It combines a scene contraction function to warp unbounded space into a finite sphere with a multi-stage proposal sampling strategy and a specific loss formulation to ensure training stability and anti-aliasing. It sets itself apart from standard NeRF implementations by explicitly handling unbounded domains through coordinate warping and using a stop-gradient mechanism to decouple proposal network optimization from the final NeRF network.

### [Scale-Dependent Downweighting for Grid Interpolation](8571-scale-dependent-downweighting-for-grid-interpolation.md)
Scale-Dependent Downweighting is a technique to anti-alias trilinear interpolation in neural radiance fields by downweighting features interpolated from grid cells that are small relative to the sampling Gaussian's spread, preventing aliasing artifacts from high-frequency content. Unlike naive trilinear interpolation which causes aliasing at high frequencies, this method uses the Gaussian CDF to weight samples, similar to Mip-NeRF's IPE features but applied to grid-based representations.

### [S-NeRF Training Configuration](15165-s-nerf-training-configuration.md)
S-NeRF training configuration defines the specific hyperparameters, network architectures, and confidence-based loss weighting used to optimize Neural Radiance Fields for dynamic street scenes using LiDAR and RGB data. It distinguishes itself from standard NeRF variants by employing a dual-phase training loop (foreground vehicles vs. background street views) and integrating geometry/projection confidence maps to mitigate depth outliers from moving objects. This configuration builds on [Mip-NeRF Optimization and Activation Details](3409-mip-nerf-optimization-and-activation-details.md) but adds specific LiDAR-guided confidence mechanisms and distinct MLP topologies for foreground/background separation.

### Alternative Gaussian Positional Encoding
An alternative to Integrated Positional Encoding (IPE) involves concatenating the positional encodings of the mean and the (signed) square root of the elements of the covariance matrix [S1]. Specifically, positional encoding with $L=12$ is applied to the mean $\mu$, and positional encoding with $L=2$ is applied to $\text{vec}(\text{triu}(\text{sign}(\Sigma) \circ \sqrt{|\Sigma|}))$ [S1]. This approach performs comparably to IPE but is sensitive to hyperparameters $L$ and covariance parameterization, whereas IPE is hyperparameter-free and compact [S1]. IPE features are insensitive to off-diagonal elements of $\Sigma$ (correlation), but experiments show that modeling this correlation does not improve accuracy [S1].

### Reflected Cone Derivation
A geometric derivation to shift the origin of a reflected ray so that its cone radius matches the incident ray's cone radius at the intersection point, ensuring consistent view-dependent appearance for reflections [S2]. The condition for equating radii is $\dot{r}\|\bar{\mathbf{x}} - \mathbf{o}\| = \dot{r}'\|\bar{\mathbf{x}} - \mathbf{o}'\|$, where $\dot{r}$ is the incident ray radius parameter, $\bar{\mathbf{x}}$ is the intersection point, $\mathbf{o}$ is the incident ray origin, $\dot{r}'$ is the reflected ray radius parameter, and $\mathbf{o}'$ is the reflected ray origin [S2]. This is solved along with the constraint that $\mathbf{o}'$ lies on the reflected ray [S2].

### RawNeRF
A method for High Dynamic Range (HDR) image view synthesis and denoising that adapts Mip-NeRF to use raw linear images as training data, allowing post-processing after rendering [S3]. It renders in a linear color space and supervises with variable exposure images, scaling the NeRF models’ “exposure” by the training image’s shutter speed, as well as a per-channel learned scaling factor [S3]. Unlike HDR-NeRF which uses LDR images, RawNeRF uses raw linear images, allowing varying exposure and tone-mapping curves to be applied after NeRF rendering [S3].

## Operating characteristics
*   **Training Time:** Mip-NeRF is 13x faster to train than a brute-force supersampling baseline (16 rays/pixel) [S1].
*   **Evaluation Speed:** Mip-NeRF is 16x faster to evaluate than the supersampling baseline [S1].
*   **Quality:** Mip-NeRF outperforms brute-force supersampling in quality metrics (PSNR, SSIM, LPIPS) [S1].
*   **Stability:** The modified activation functions and learning rate schedule improve training stability, particularly with large learning rates, though the core accuracy remains similar to the original NeRF setup [S1].
*   **Memory:** The use of a single unified multiscale model (as opposed to separate per-scale models) reduces memory overhead compared to some multi-scale variants [S1].

## Background
Mip-NeRF was introduced by Barron et al. in 2021 [S1]. The optimization details described here are part of the JaxNeRF codebase implementation, which was used for all experiments in the Mip-NeRF paper [S1]. The "miscellaneous" changes were identified through ablation studies to improve robustness without affecting the core accuracy or speed of the method [S1]. RawNeRF, an adaptation of Mip-NeRF for HDR, was created by Mildenhall et al. in November 2021 [S3].
