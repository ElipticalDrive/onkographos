# Conditional NeRF Implementation Details

Also called: Conditional NeRF, Conditional NeRF Architecture, Conditional NeRF Model Specs, Implementation Details

## Overview
Conditional NeRF is a generative model for a specific object category that maps a 5D coordinate (spatial position $\mathbf{x}$ and view direction $\mathbf{v}$) along with instance-specific latent vectors to volumetric density $\sigma$ and view-dependent radiance $\mathbf{c}$ [S1]. It differs from standard NeRF by introducing dedicated latent codes for shape ($\mathbf{z}_s$) and appearance ($\mathbf{z}_a$), allowing the network to generate diverse instances within a category rather than reconstructing a single static scene [S1]. This approach enables text- and image-driven manipulation of 3D structures without per-sample optimization during inference, provided mappers are trained [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Spatial position $\mathbf{x} \in \mathbb{R}^3$, view direction $\mathbf{v} \in \mathbb{R}^3$, shape latent code $\mathbf{z}_s \in \mathbb{R}^{128}$, appearance latent code $\mathbf{z}_a \in \mathbb{R}^{128}$.
*   **Outputs:** Scalar density $\sigma \in \mathbb{R}$, RGB radiance $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures and Layout:**
The core network is an 8-layer Multi-Layer Perceptron (MLP) with ReLU activations [S1].
*   **Hidden Units:** 256 per layer.
*   **Input Dimension:** 64. This dimension is derived from the concatenation of positional encodings and latent codes.
*   **Output:** The final layer outputs $\sigma$ (scalar) and $\mathbf{c}$ (3-vector).

**Positional Encoding:**
The input coordinates are projected into a high-dimensional space using sinusoidal positional encoding $\Gamma(\mathbf{p})$ [S1]. For a coordinate $p$, the $k$-th dimension of the encoding $\gamma(p)_k$ (where $k \in \{0, \dots, 2m-1\}$) is defined as:
$$
\gamma(p)_k = \begin{cases} \sin(2^k \pi p), & \text{if } k \text{ is even} \\ \cos(2^k \pi p), & \text{if } k \text{ is odd} \end{cases}
$$
The parameter $m$ controls the number of frequency bands [S1].

**Network Formulation:**
The conditional NeRF function $F_{\theta'}$ maps the encoded inputs to density and radiance [S1]:
$$
F_{\theta'}(\mathbf{x}, \mathbf{v}, \mathbf{z}_s, \mathbf{z}_a) : \Gamma(\mathbf{x}) \oplus \mathbf{z}_s, \Gamma(\mathbf{v}) \oplus \mathbf{z}_a \rightarrow (\mathbf{c}, \sigma)
$$
where $\oplus$ denotes concatenation [S1].

**Deformation Network (Shape Conditioning):**
To disentangle shape from appearance, the shape code $\mathbf{z}_s$ is used to deform the positional encoding of the position $\mathbf{x}$ [S1].
*   **Architecture:** 4-layer MLP, 256 hidden units per layer, ReLU activations [S1].
*   **Input:** $\mathbf{z}_s \in \mathbb{R}^{128}$.
*   **Output:** Displacement vectors $\Delta \mathbf{x} \in \mathbb{R}^{3 \times 2m}$ corresponding to each band of the positional encoding $\Gamma(\mathbf{x})$ [S1].
*   **Deformed Encoding:** The deformed positional encoding is denoted as $\Gamma^*(\mathbf{x}, \mathbf{z}_s)$ [S1].

**Mappers (Feed-Forward Manipulation):**
To avoid optimizing latent codes for each sample, feed-forward mappers update initial codes $\mathbf{z}_{s0}, \mathbf{z}_{a0}$ based on a text prompt $\mathbf{t}$ [S1].
*   **Architecture:** 2-layer MLPs with ReLU activations [S1].
*   **Channel Sizes:** 128, 256, 128 [S1].
*   **Shape Mapper ($M_s$):** Takes CLIP text features $\hat{E}_t(\mathbf{t})$ as input.
*   **Appearance Mapper ($M_a$):** Takes CLIP text features $\hat{E}_t(\mathbf{t})$ as input.
*   **Update Rules:**
    $$
    \mathbf{z}_s = M_s(\hat{E}_t(\mathbf{t})) + \mathbf{z}_{s0}
    $$
    $$
    \mathbf{z}_a = M_a(\hat{E}_t(\mathbf{t})) + \mathbf{z}_{a0}
    $$
    where $\hat{E}_t$ is the pre-trained CLIP text encoder [S1].

**Deferred Appearance Conditioning:**
To prevent appearance manipulation from affecting shape/density, the appearance code $\mathbf{z}_a$ is concatenated with the view direction $\mathbf{v}$ (and its encoding) before entering the radiance prediction network, while density is predicted independently of $\mathbf{z}_a$ [S1]. The final disentangled formulation is:
$$
F_{\theta}(\mathbf{x}, \mathbf{v}, \mathbf{z}_s, \mathbf{z}_a) : \Gamma^*(\mathbf{x}, \mathbf{z}_s), \Gamma(\mathbf{v}) \oplus \mathbf{z}_a \rightarrow (\mathbf{c}, \sigma)
$$
[ S1 ]

**Rendering:**
Rendering follows the standard volume rendering equation using alpha compositing [S1]. For a ray $r$ with $N_c$ sampled points $\{t_i\}$, the color $\hat{C}$ is:
$$
\hat{C}(r, \mathbf{z}_s, \mathbf{z}_a) = \sum_{i=1}^{N_c} c_i \alpha_i \exp \left( -\sum_{j=1}^{i-1} \sigma_j \delta_j \right)
$$
where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ and $\delta_i = t_{i+1} - t_i$ [S1].

**Training and Optimization:**
*   **Network Training:** Optimized using Adam. Initial learning rate $10^{-4}$, decayed by 0.5 every 50,000 steps [S1].
*   **Inversion (Inverse Manipulation):** To project an input image to the generation manifold, shape and appearance codes are optimized iteratively (EM algorithm) [S1]. Optimizer: Adam. Initial learning rate $10^{-3}$, decreasing by 0.75 every 100 steps [S1].
*   **Loss Weights:** $\lambda_r = 0.5$, $\lambda_v = 0.1$, $\lambda_s = \lambda_a = 0.2$ [S1].

## Subtopics

### [Disentangled Conditional NeRF](16793-disentangled-conditional-nerf.md)
An architecture that achieves individual control over shape and appearance by isolating shape conditioning to explicit volumetric deformation of the positional encoding, preventing mutual intervention where shape changes affect color. It uses a deformation network to map $\mathbf{z}_s$ to displacement vectors for the positional encoding, while deferring appearance conditioning to the radiance network. Choose this when independent editing of geometry and texture is required. Link: [Disentangled Conditional NeRF](16793-disentangled-conditional-nerf.md).

### CLIP-Driven Manipulation via Mappers
A feed-forward approach using shape mapper $M_s$ and appearance mapper $M_a$ to update initial shape/appearance codes ($\mathbf{z}_{s0}, \mathbf{z}_{a0}$) based on a text prompt $\mathbf{t}$, avoiding per-sample optimization [S1]. It uses the CLIP text encoder $\hat{E}_t$ to generate features that are added to the initial codes [S1]. Choose this for text-driven 3D editing without iterative inversion [S1].

### Deferred Appearance Conditioning
A technique where appearance conditioning is deferred to concatenate the appearance code with the view direction as input to the radiance prediction network, allowing appearance manipulation without affecting shape/density [S1]. This ensures that changes in $\mathbf{z}_a$ do not influence the density output $\sigma$ [S1].

## Operating characteristics
*   **Time Complexity:** Training involves optimizing network weights and latent codes. Inversion (inverse manipulation) is iterative and time-consuming if done per sample, but the feed-forward mapper approach avoids this [S1].
*   **Memory Complexity:** The model stores the 8-layer MLP (8 * 256 hidden units) and the deformation network (4-layer MLP). Latent codes are stored per instance [S1].
*   **Performance:** Trained on NVIDIA V100 GPU [S1]. The method allows generation from a single view per instance, unlike EditNeRF which requires multiple views [S1].
*   **Strengths:** Enables text- and image-driven manipulation; disentangles shape and appearance; works with single-view inputs [S1].
*   **Limitations:** Requires training mappers for text-driven manipulation; inversion can be slow if not using mappers [S1].

## Background
Conditional NeRF was introduced in the paper "CLIP-NeRF: Text-and-Image Driven Manipulation of Neural Radiance Fields" by Can Wang et al. (2022) [S1]. It builds upon the original NeRF [S1] and extends it to a generative model for object categories. The work addresses the limitations of per-scene NeRF by introducing latent codes for shape and appearance, and further introduces disentangled conditioning and feed-forward mappers for manipulation [S1].
