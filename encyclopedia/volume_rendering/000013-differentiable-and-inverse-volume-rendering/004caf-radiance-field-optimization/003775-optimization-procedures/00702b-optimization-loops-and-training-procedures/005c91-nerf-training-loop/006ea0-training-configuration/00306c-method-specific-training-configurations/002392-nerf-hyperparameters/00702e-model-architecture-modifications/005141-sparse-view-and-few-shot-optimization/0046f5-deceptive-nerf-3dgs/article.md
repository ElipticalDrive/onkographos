# Deceptive-NeRF/3DGS

Also called: Deceptive-3DGS, Deceptive-NeRF, DeceptiveX

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that mitigates overfitting and artifacts by densifying input observations with photorealistic pseudo-observations generated via a 2D diffusion model [S1]. Unlike methods that use diffusion models as per-step regularizers (e.g., SDS), this approach treats generated pseudo-observations as real training data, alternating between generation and optimization to progressively enrich the training set [S1]. It is applicable to both MLP-based NeRFs and 3D Gaussian Splatting (3DGS) [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A sparse set of $W$ input images $I = \{I_1, I_2, \dots, I_W\}$ with known camera poses.
*   **Output:** A trained scene representation (NeRF or 3DGS) capable of rendering high-quality novel views.

**Data Structures:**
*   **Scene Representation:**
    *   **NeRF:** A neural radiance field $f_\Theta: (\mathbf{x}, \mathbf{d}) \rightarrow (\sigma, \mathbf{c})$, where $\mathbf{x} \in \mathbb{R}^3$ is spatial position, $\mathbf{d} \in \mathbb{R}^3$ is viewing direction, $\sigma$ is volume density, and $\mathbf{c} \in \mathbb{R}^3$ is view-dependent color [S1]. The implementation uses Nerfacto from NerfStudio [S1].
    *   **3DGS:** A set of 3D Gaussians. For Deceptive-3DGS, Gaussians are randomly initialized without using Colmap point clouds [S1]. The implementation uses Splatfacto from NerfStudio [S1].
*   **Bounding Box:** Defined by the outermost input cameras [S1].
*   **Pseudo-Observations:** RGB-D images generated by the diffusion model [S1].

**Parameters:**
*   **Densification Factor:** The method increases the number of training views by 5 to 10 times [S1].
*   **Alternation Iterations:** The process of generating pseudo-observations and training is repeated 5 times [S1].
*   **Backbone Settings:** Default proposal sampling, scene contraction, and appearance embeddings are used for both Nerfacto and Splatfacto [S1].

**Algorithm Steps:**

1.  **Initialization:**
    *   Define the bounding box using the outermost input cameras [S1].
    *   Initialize the scene representation:
        *   For NeRF: Initialize Nerfacto parameters [S1].
        *   For 3DGS: Randomly initialize Gaussians [S1].

2.  **Iterative Loop (Repeat $K=5$ times):**
    *   **Step 1: Coarse Rendering.**
        *   Render coarse novel view images and depth maps from the current scene representation at randomly sampled viewpoints $\{\phi_{pseudo}\}$ within the bounding box [S1].
        *   For NeRF, the rendered color $\hat{\mathbf{C}}$ for a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ is computed via volume rendering [S1]:
            $$ \hat{\mathbf{C}} = \sum_{k=1}^K \hat{T}(t_k) \alpha(\sigma(t_k)\delta_k) \mathbf{c}(t_k) $$
            where $\hat{T}(t_k) = \exp\left(-\sum_{k'=1}^{k-1} \sigma(t_{k'})\delta_{k'}\right)$, $\alpha(x) = 1 - \exp(-x)$, and $\delta_k = t_{k+1} - t_k$ [S1].
        *   For 3DGS, the color $\mathbf{C}$ is computed as [S1]:
            $$ \mathbf{C} = \sum_{i=1}^n \mathbf{c}_i \alpha_i \prod_{j=1}^{i-1}(1-\alpha_j) $$
            where $\mathbf{c}_i$ is the color from SH coefficients, and $\alpha_i$ is the opacity derived from a 2D Gaussian multiplied by an opacity logit $o$ [S1].

    *   **Step 2: Uncertainty Estimation.**
        *   Compute an uncertainty measure from the coarse renderings. High uncertainty corresponds to areas with artifacts or inconsistencies [S1]. This uncertainty map guides the diffusion model [S1].

    *   **Step 3: Pseudo-Observation Generation.**
        *   Feed the coarse rendered images and the uncertainty map into a "deceptive diffusion model" [S1].
        *   The diffusion model generates high-quality pseudo-observations (RGB-D images) from the corresponding viewpoints, conditioned on the uncertainty to ensure consistency with real inputs and remove artifacts [S1].

    *   **Step 4: Optimization.**
        *   Optimize the scene representation by minimizing the photometric loss (Mean Squared Error) on both the real input images $I$ and the newly generated pseudo-observations [S1].
        *   For NeRF, the loss is [S1]:
            $$ \mathcal{L} = \sum_{i=1}^n \|\mathbf{C}_i - \hat{\mathbf{C}}_i\|^2 $$
            where $\mathbf{C}_i$ is the ground truth or pseudo-observation color and $\hat{\mathbf{C}}_i$ is the rendered color [S1].
        *   For 3DGS, a similar photometric loss is applied [S1].

3.  **Final Output:**
    *   After 5 iterations, the final scene representation is used for rendering [S1].

**Edge Cases and Pitfalls:**
*   **Sparse Inputs:** Standard NeRF/3DGS pipelines suffer from severe artifacts and overfitting with sparse inputs [S1]. This method mitigates this by densifying observations [S1].
*   **Uncertainty Guidance:** Without uncertainty guidance, reconstruction quality drops significantly (PSNR 18.61 vs 20.44 on Hypersim) [S1]. The uncertainty measure is critical for ensuring 3D consistency and removing artifacts [S1].
*   **Initialization:** For 3DGS, random initialization is used instead of Colmap point clouds, which is a specific pitfall/choice for this method [S1].

## Operating characteristics
*   **Time Complexity:** Nearly tenfold faster than methods using diffusion models as per-step regularizers (e.g., SDS) [S1]. This is because the diffusion model is only inferred during the pseudo-observation generation phase, not at every training step [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:**
    *   **Hypersim (10 views):** Deceptive-NeRF achieved PSNR 20.44, SSIM 0.748, LPIPS 0.173, Training Time 17min, Rendering FPS 5.3 [S1].
    *   **Comparison:** The "Regularizer" approach achieved PSNR 19.31, SSIM 0.710, LPIPS 0.253, Training Time 2h40min, Rendering FPS 1.1 [S1].
    *   **DTU (Scan 65, 9 views):** Deceptive-NeRF achieved Chamfer Distance 1.86, compared to NeRF 3.75, FreeNeRF 3.63, and DiffusioNeRF 1.93 [S1].
*   **Scaling:** The method works effectively with as few as 3 input images [S1].
*   **Strengths:** High-quality sparse-view reconstruction, fast training speed, super-resolution capabilities [S1].
*   **Limitations:** Requires a pre-trained 2D diffusion model [S1].

## Background
*   **Origin:** Proposed by X. Liu et al. in "Deceptive-NeRF/3DGS: Diffusion-Generated Pseudo-Observations for High-Quality Sparse-View Reconstruction" [S1].
*   **History:** The method addresses the limitation of NeRF and 3DGS requiring large numbers of training views, which hampers consumer-level usage where sparse captures are common [S1]. It builds on the idea of using diffusion priors but shifts from regularization to view densification [S1].
*   **Usage:** Used on Hypersim, mip-NeRF 360, and DTU datasets [S1].
