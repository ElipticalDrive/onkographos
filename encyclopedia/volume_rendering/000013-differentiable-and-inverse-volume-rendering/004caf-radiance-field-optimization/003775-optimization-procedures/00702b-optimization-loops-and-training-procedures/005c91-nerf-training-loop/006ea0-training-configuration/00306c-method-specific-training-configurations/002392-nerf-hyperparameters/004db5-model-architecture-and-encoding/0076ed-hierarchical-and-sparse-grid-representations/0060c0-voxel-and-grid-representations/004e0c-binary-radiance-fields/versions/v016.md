# Binary Radiance Fields

Also called: BRF

## Overview
Binary Radiance Fields (BiRF) is a storage-efficient radiance field representation that constrains feature grid parameters to binary values (+1 or -1) to achieve compact storage without post-processing compression [S1]. Unlike methods that compress pre-trained models, BiRF performs binarization during training, allowing it to outperform state-of-the-art efficient radiance field models in reconstruction quality while using significantly less memory (e.g., < 0.5 MB for Synthetic-NeRF scenes) [S1]. It builds on [Model Architecture and Encoding](13550-model-architecture-and-encoding.md) by replacing real-valued hash grid features with binary ones and employing a 2D-3D hybrid grid structure to mitigate hash collisions inherent in high-resolution 3D grids [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D coordinate $\mathbf{x} \in \mathbb{R}^3$ and a viewing direction $\mathbf{d} \in S^2$.
*   **Output:** Volume density $\sigma \in \mathbb{R}_{\ge 0}$ and RGB color $\mathbf{c} \in [0, 1]^3$.

**Data Structures:**
The model uses a multi-resolution 2D-3D hybrid feature grid implemented via hash encoding [S1].
1.  **3D Voxel Grid ($\Phi_{\theta_{xyz}}$):** Contains $L$ levels with resolutions ranging from 16 to 1024. Each level stores up to $T_{3D}$ feature vectors.
2.  **2D Plane Grids ($\Phi_{\theta_{xy}}, \Phi_{\theta_{xz}}, \Phi_{\theta_{yz}}$):** Three orthogonal planes. Each contains $M$ levels with resolutions ranging from 64 to 512. Each level stores up to $T_{2D}$ feature vectors.
3.  **Feature Values:** All grid parameters are binary, constrained to $\{-1, +1\}$. Each feature vector has dimension $F \in \{2, 4, 8\}$ [S1].
4.  **MLPs:**
    *   **Density MLP:** 1 hidden layer, 128 channels, ReLU activation. Inputs: positional encoding $\gamma(\mathbf{x})$ and concatenated features $\mathbf{f}$. Outputs: density $\sigma$ and embedding $\mathbf{e}$.
    *   **Color MLP:** 2 hidden layers, 128 channels, ReLU activation. Inputs: embedding $\mathbf{e}$ and directional encoding $\mathbf{d}$. Outputs: color $\mathbf{c}$.
    *   **Directional Encoding:** Spherical harmonics basis functions [S1].

**Parameters:**
*   $L$: Number of 3D grid levels.
*   $M$: Number of 2D grid levels.
*   $T_{3D}$: Max feature vectors per 3D level. Small model (Ours-S): $\log_2(T_{3D}) = 17$. Base model (Ours-B): $\log_2(T_{3D}) = 19$.
*   $T_{2D}$: Max feature vectors per 2D level. Small model (Ours-S): $\log_2(T_{2D}) = 15$. Base model (Ours-B): $\log_2(T_{2D}) = 17$.
*   $F$: Feature dimension per level.
*   $\lambda_{\text{sparsity}}$: Sparsity loss weight. Value: $2.0 \times 10^{-5}$ [S1].

**Steps:**

1.  **Binarization:** During training, real-valued grid parameters $\theta$ are binarized to $\theta'$ using the sign function:
    $$ \theta' = \text{sign}(\theta) = \begin{cases} +1 & \text{if } \theta \ge 0 \\ -1 & \text{otherwise} \end{cases} $$
    Gradients are propagated using the Straight-Through Estimator (STE). The gradient is passed if $|\theta| \le 1$, otherwise it is zeroed to prevent scale divergence [S1].

2.  **Feature Encoding (3D):** For input $\mathbf{x}$, compute features from the 3D grid by tri-linearly interpolating the binary parameters across $L$ levels and concatenating them:
    $$ \mathbf{f}_{xyz} = \left\{ \text{interp}(\mathbf{x}, \text{sign}(\Phi^l_{\theta_{xyz}})) \right\}_{l=1}^L $$
    where $\text{interp}$ denotes tri-linear interpolation [S1].

3.  **Feature Encoding (2D):** Project $\mathbf{x}=(x,y,z)$ to 2D coordinates: $\mathbf{x}_{xy}=(x,y)$, $\mathbf{x}_{xz}=(x,z)$, $\mathbf{x}_{yz}=(y,z)$. For each axis, bi-linearly interpolate binary parameters across $M$ levels and concatenate:
    $$ \mathbf{f}_{xy} = \left\{ \text{interp}(\mathbf{x}_{xy}, \text{sign}(\Phi^m_{\theta_{xy}})) \right\}_{m=1}^M $$
    Repeat for $\mathbf{f}_{xz}$ and $\mathbf{f}_{yz}$ [S1].

4.  **Feature Concatenation:** Combine all encoded features:
    $$ \mathbf{f} = \{ \mathbf{f}_{xyz}, \mathbf{f}_{xy}, \mathbf{f}_{xz}, \mathbf{f}_{yz} \} $$

5.  **Positional Encoding:** Apply sinusoidal positional encoding $\gamma(\mathbf{x})$ to the input 3D coordinate [S1].

6.  **Density Prediction:** Feed $\gamma(\mathbf{x})$ and $\mathbf{f}$ into the density MLP:
    $$ (\sigma, \mathbf{e}) = \text{MLP}_{\text{density}}(\gamma(\mathbf{x}), \mathbf{f}) $$

7.  **Color Prediction:** Feed $\mathbf{e}$ and directional encoding $\mathbf{d}$ into the color MLP:
    $$ \mathbf{c} = \text{MLP}_{\text{color}}(\mathbf{e}, \mathbf{d}) $$

**Pseudocode:**

```python
import numpy as np

def sign_ste(theta):
    """
    Binarization with Straight-Through Estimator.
    Returns +1 if theta >= 0, else -1.
    Gradient is 1 if |theta| <= 1, else 0.
    """
    binary = np.where(theta >= 0, 1.0, -1.0)
    # Gradient mask for backpropagation [G: Standard STE implementation]
    grad_mask = np.where(np.abs(theta) <= 1.0, 1.0, 0.0)
    return binary, grad_mask

def interpolate_3d(grid_hash, x, levels, max_features):
    """
    Tri-linear interpolation of binary 3D grid features.
    grid_hash: Hash table mapping hash indices to binary feature vectors.
    x: 3D coordinate.
    levels: List of grid resolutions.
    max_features: Max features per level.
    """
    features = []
    for l, res in enumerate(levels):
        # Get binary parameters for this level
        # Note: In practice, hash lookup returns the binary vector directly
        # if the grid is stored as bits. Here we assume access to sign(Phi).
        # interp performs tri-linear interpolation of the binary values.
        feat = tri_linear_interpolate(grid_hash[l], x, res)
        features.append(feat)
    return np.concatenate(features)

def interpolate_2d(grid_hash, x_proj, levels, max_features):
    """
    Bi-linear interpolation of binary 2D grid features.
    """
    features = []
    for l, res in enumerate(levels):
        feat = bi_linear_interpolate(grid_hash[l], x_proj, res)
        features.append(feat)
    return np.concatenate(features)

def get_features(x, grids_3d, grids_2d, levels_3d, levels_2d, max_f_3d, max_f_2d):
    """
    Compute binary features from 2D-3D hybrid grid.
    """
    # 3D Grid
    f_xyz = interpolate_3d(grids_3d, x, levels_3d, max_f_3d)
    
    # 2D Grids
    x_xy = x[:2]
    x_xz = np.array([x[0], x[2]])
    x_yz = x[1:]
    
    f_xy = interpolate_2d(grids_2d['xy'], x_xy, levels_2d, max_f_2d)
    f_xz = interpolate_2d(grids_2d['xz'], x_xz, levels_2d, max_f_2d)
    f_yz = interpolate_2d(grids_2d['yz'], x_yz, levels_2d, max_f_2d)
    
    # Concatenate
    f = np.concatenate([f_xyz, f_xy, f_xz, f_yz])
    return f

def predict_radiance(x, d, grids_3d, grids_2d, levels_3d, levels_2d, 
                     max_f_3d, max_f_2d, density_mlp, color_mlp, 
                     pos_encoder, dir_encoder):
    """
    Forward pass for Binary Radiance Fields.
    """
    # 1. Feature Encoding
    f = get_features(x, grids_3d, grids_2d, levels_3d, levels_2d, max_f_3d, max_f_2d)
    
    # 2. Positional Encoding
    x_enc = pos_encoder(x)
    
    # 3. Density Prediction
    # MLP_Density takes [x_enc, f]
    density_input = np.concatenate([x_enc, f])
    sigma, e = density_mlp(density_input)
    
    # 4. Color Prediction
    # MLP_Color takes [e, d_enc]
    d_enc = dir_encoder(d)
    c = color_mlp(np.concatenate([e, d_enc]))
    
    return sigma, c

def compute_loss(renders, ground_truth, sigmas, lambda_sparsity):
    """
    Compute total loss including reconstruction and sparsity.
    """
    # Reconstruction Loss (L2)
    l_recon = np.mean((renders - ground_truth) ** 2)
    
    # Sparsity Loss (Cauchy)
    # L_sparsity = sum(log(1 + 2 * sigma^2))
    l_sparsity = np.sum(np.log(1 + 2 * sigmas ** 2))
    
    total_loss = l_recon + lambda_sparsity * l_sparsity
    return total_loss
```

**Edge Cases and Pitfalls:**
*   **Hash Collisions:** 3D grids suffer from hash collisions at higher resolutions. The 2D grid supplementation alleviates this impact and reinforces features with fewer parameters [S1].
*   **Gradient Vanishing:** The derivative of the sign function is zero almost everywhere. The STE solves this by passing gradients through the threshold function during training [S1].
*   **Scale Divergence:** Large values of $\theta$ can cause divergence. STE stops propagating gradients when $|\theta| > 1$, constraining the value to $\{-1, 1\}$ [S1].

## Operating characteristics
*   **Storage:** Extremely compact. The Ours-S2 variant requires < 0.5 MB, outperforming TensoRF-CP (3.7 MB) and Instant-NGP (24.5 MB) on the mic scene [S1]. Total storage capacity of MLPs varies from 0.06 to 0.11 MB depending on feature dimension $F$ [S1].
*   **Performance:** Achieves PSNR of 32.03 dB on Synthetic-NeRF, 34.48 dB on Synthetic-NSVF, and 28.20 dB on Tanks and Temples with 0.5 MB storage [S1].
*   **Training Time:** Approximately 6, 9, and 14 minutes for Synthetic-NeRF scenes for Ours-B2 to Ours-B8 models on a single NVIDIA RTX A6000 GPU [S1].
*   **Strengths:** Storage efficiency without post-optimization; superior reconstruction quality compared to prior efficient methods with comparable training time [S1].
*   **Limitations:** Performance is bounded by the binary representation capacity; may struggle with extremely high-frequency details compared to full-precision models if grid resolution is limited [S1].
*   **When to use:** When storage is a critical bottleneck and high-fidelity reconstruction is still required, particularly for static scenes [S1].

## Background
Binary Radiance Fields were proposed by Seungjoo Shin and Jaesik Park from POSTECH and Seoul National University, published in arXiv:2306.07581v2 on December 4, 2023 [S1]. The method addresses the storage bottleneck of neural radiance fields by introducing binary feature encoding. It extends the modern multi-resolution hash encoding architecture (Instant-NGP) to a 2D-3D hybrid grid. The implementation is based on Instant-NGP using the occupancy grid from NerfAcc [S1].
