# SCADE

Also called: Space Carving with Ambiguity-Aware Depth Estimates

## Overview
SCADE is a NeRF training method that regularizes optimization using a multimodal depth prior to resolve ambiguities in scenes with non-opaque surfaces (e.g., glass) [S1]. It differs from unimodal prior methods like DDP by modeling multiple possible depth hypotheses per pixel and supervising the full ray termination distribution via a space carving loss, enabling 3D regularization rather than 2D moment matching [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of $N$ images with known camera poses (obtained via SfM [S1]), and a pretrained ambiguity-aware depth estimation prior [S1].
*   **Outputs:** A radiance field MLP (as defined in [Model Architecture and Encoding](13550-model-architecture-and-encoding.md)) optimized to render novel views with reduced "dust" and improved geometry consistency [S1].

**Data Structures**
*   **Ambiguity-Aware Prior:** A neural network initialized with weights from the pretrained LeReS model [S1]. It takes an image patch as input and outputs a distribution of depth estimates [S1]. The implementation uses $M=20$ depth estimates per pixel to sample from this multimodal distribution [S1].
*   **Ray Termination Distribution:** For a given ray, the NeRF predicts a volume density $\sigma$ and color $\mathbf{c}$ at sampled points [G]. The probability density function (PDF) of the ray termination distance $d$ is computed as $p(d) = T(d)\sigma(d)\Delta d$, where $T(d)$ is the accumulated transmittance [G].

**Numbered Steps**
1.  **Prior Estimation:** For each training image, pass the image through the ambiguity-aware prior to obtain $M$ depth estimates $\{d_1, \dots, d_M\}$ for each pixel [S1].
2.  **Ray Sampling:** For each pixel, generate a camera ray $r(\lambda) = o + \lambda d$ [S1]. Sample $N=128$ stratified points along the ray within the near/far range [G].
3.  **NeRF Forward Pass:** Query the NeRF MLP at each sample point to obtain $\sigma$ and $\mathbf{c}$ [S1]. Compute the rendered color $C_r$ and the ray termination PDF $p(d)$ [G].
4.  **Space Carving Loss Calculation:**
    *   For each of the $M$ prior depth estimates $d_m$, identify the corresponding sample point $x_m$ along the ray [S1].
    *   Compute the loss such that it encourages the probability density of points *in front of* $x_m$ to decrease, effectively pushing the mass of the distribution to $x_m$ or beyond [S1].
    *   The loss supervises the full distribution rather than just the expected value (moment) [S1].
5.  **Optimization:** Minimize the total loss, which includes the space carving loss and standard photometric reconstruction loss, using gradient descent [S1].

**Formulas**
*   **Ray Termination PDF:**
    $$ p(d) = T(d)\sigma(d)\Delta d $$
    where $T(d) = \exp\left(-\sum_{k=1}^{d-1} \sigma_k \Delta_k\right)$ is the transmittance, $\sigma$ is volume density, and $\Delta$ is the distance between samples [G].
*   **Space Carving Loss:** The loss function operates on the PDF $p(d)$ [S1]. To move a sample from the ray termination distance distribution farther in depth, the loss requires decreasing the probability density of all points in front of it [S1]. This provides 3D supervision, unlike 2D supervision which operates on moments (integrals along the ray) [S1].

**Parameters**
*   $M$: Number of depth estimates used from the prior. Set to 20 in experiments [S1].
*   Initialization: Weights initialized with the pretrained LeReS model [S1].

**Edge Cases and Pitfalls**
*   **Non-opaque Surfaces:** Standard depth priors fail on glass/mirrors because they assume a single depth mode [S1]. SCADE handles this by modeling multimodal distributions (e.g., depth through glass, on glass, or mixture) [S1].
*   **Inconsistent Labels:** The prior is trained on Taskonomy data where labels for non-opaque surfaces are inconsistent (shooting through, on surface, or mixture), allowing the model to learn ambiguity via cIMLE [S1].

**Pseudocode**
```python
def space_carving_loss(p_pdf, prior_depths, ray_sample_depths):
    """
    Computes the space carving loss for a single ray.
    
    Args:
        p_pdf: Array of shape (K,) representing the probability density 
               of ray termination at each of K sample points along the ray.
        prior_depths: Array of shape (M,) containing M depth estimates 
                      from the ambiguity-aware prior for the corresponding pixel.
        ray_sample_depths: Array of shape (K,) containing the depth values 
                           of the K sample points along the ray.
                           
    Returns:
        loss: Scalar loss value.
    """
    loss = 0.0
    for d_prior in prior_depths:
        # Find the index of the sample point closest to the prior depth estimate
        idx = min(range(len(ray_sample_depths)), key=lambda i: abs(ray_sample_depths[i] - d_prior))
        # The loss encourages decreasing probability density of all points 
        # in front of the sample corresponding to the prior depth.
        # Points in front of the target sample
        front_mask = [ray_sample_depths[i] < ray_sample_depths[idx] for i in range(len(ray_sample_depths))]
        # Accumulate probability mass in front
        mass_in_front = sum(p_pdf[i] for i in range(len(p_pdf)) if front_mask[i])
        # The loss increases if there is significant mass in front of the 
        # expected depth, pushing the network to reduce density there.
        loss += mass_in_front
    return loss / len(prior_depths)
```

## Subtopics

### Ambiguity-Aware Prior
A depth estimation model that captures multimodal distributions using cIMLE on inconsistently labeled data (Taskonomy) [S1].

### Space Carving Loss
A loss function that supervises the full distribution of ray termination distances, enabling 3D supervision and clearing "dust" [S1].

## Operating characteristics
*   **Performance:** On ScanNet, SCADE achieves PSNR 21.54, SSIM 0.732, LPIPS 0.292, outperforming Vanilla NeRF (19.03, 0.670, 0.398) and DDP (19.29, 0.695, 0.368) [S1]. On in-the-wild iPhoneX data, it achieves PSNR 22.82, SSIM 0.743, LPIPS 0.347, outperforming Vanilla NeRF (20.46, 0.713, 0.398) and DDP (21.28, 0.727, 0.366) [S1].
*   **Sparsity:** In sparse view settings (18 views, 1.87 avg visible), SCADE achieves PSNR 21.66 vs DDP's 19.35. In denser settings (24 views, 2.2 avg visible), SCADE achieves 24.84 vs DDP's 23.56 [S1].
*   **Strengths:** Robust to non-opaque surfaces (glass, mirrors) and sparse views. Provides 3D supervision which clears artifacts ("dust") better than 2D moment-based supervision [S1].
*   **Limitations:** Requires a pretrained depth prior (LeReS) and SfM for camera poses [S1].

## Background
SCADE was introduced in the paper "SCADE: NeRFs from Space Carving with Ambiguity-Aware Depth Estimates" [S1]. It addresses the underconstrained nature of NeRF reconstruction with modest numbers of in-the-wild views by regularizing optimization with multimodal depth estimates [S1]. The method builds on the concept of depth priors in NeRFs but extends them to handle ambiguity via space carving [S1].
