# Switch-NeRF

Also called: HMoHE, Heterogeneous Mixture of Hash Experts

## Overview
Switch-NeRF++ is a large-scale Neural Radiance Field method that uses a trainable decomposition and heterogeneous representation to scale NeRF to large scenes, extending Switch-NeRF with hash-based networks and heterogeneous experts [S1]. It employs a Heterogeneous Mixture of Hash Experts (HMoHE) framework where a hash-based gating network dynamically routes 3D points to specialized hash experts with varying resolution ranges, allowing the network to select a suitable resolution range for each scene part [S1]. Unlike Switch-NeRF which uses homogeneous experts and an MLP-based gating network, Switch-NeRF++ uses heterogeneous hash experts and a hash-based gating network to learn heterogeneous decomposition and representation efficiently [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D point coordinates $\mathbf{x} \in \mathbb{R}^3$, view direction $\mathbf{d} \in \mathbb{R}^3$, and an appearance embedding $\mathbf{a}$ [S1].
*   **Outputs:** Volume density $\sigma$ and RGB color $\mathbf{c}$ for the point $\mathbf{x}$ [S1].

**Data Structures:**
*   **Hash Experts:** There are $N$ hash experts [S1]. Each expert $i$ consists of a multi-resolution hash encoding grid with a distinct resolution range [S1].
*   **Gating Network:** A hash-based gating network $G$ that maps point features into gate values $G(\mathbf{x})$ [S1].
*   **Prediction Heads:** Small MLPs for density and color prediction [S1].

**Numbered Steps:**
1.  **Gating Network Evaluation:** For a 3D point $\mathbf{x}$, the hash-based gating network computes gate values. This involves looking up feature encoding $\mathbf{f}_g$ in the hash encoding by computing a hash value of $\mathbf{x}$, and using a small MLP to predict gating values [S1].
2.  **Gate Normalization:** Compute gate values $G = \text{Softmax}(\mathbf{f}_g)$ [S1].
3.  **Expert Selection:** Select the top-1 hash expert $i$ using $i = \arg \max(G)$ [S1].
4.  **Expert Feature Encoding:** Compute the feature encoding $\mathbf{E}_i(\mathbf{x})$ using the selected hash expert $i$ [S1].
5.  **Gate Application:** Multiply the gate value by the expert output to ensure differentiability: $\hat{\mathbf{E}}_i(\mathbf{x}) = G_i \cdot \mathbf{E}_i(\mathbf{x})$ [S1].
6.  **Direction Encoding:** Compute spherical harmonics of direction $\mathbf{d}$: $\text{SH}_d = \text{SphericalHarmonics}(\mathbf{d})$ [S1].
7.  **Feature Concatenation:** Concatenate features: $\mathbf{f}_{\text{final}} = [\hat{\mathbf{E}}_i(\mathbf{x}), \text{SH}_d, \mathbf{a}]$, where $\mathbf{a}$ is the appearance embedding [S1].
8.  **Density Prediction:** Predict density $\sigma = \text{MLP}_{\text{density}}(\hat{\mathbf{E}}_i(\mathbf{x}))$ [S1].
9.  **Color Prediction:** Predict color $\mathbf{c} = \text{MLP}_{\text{color}}(\hat{\mathbf{E}}_i(\mathbf{x}))$ [S1].
10. **Rendering:** Render the pixel color using volume rendering along the ray [S1].
11. **Loss Calculation:** Compute the rendering loss and the gate balance loss [S1].

**Formulas:**
*   **Transmittance:** $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ [S1].
*   **Rendered Color:** $\hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i$ [S1].
*   **Rendering Loss:** $L_r = \sum_{\mathbf{r} \in \mathcal{R}} ||\hat{C}(\mathbf{r}) - C(\mathbf{r})||^2$ [S1].
*   **Gate Balance Loss:** $L_b = \sum_n f_i g_i$ [S1].
*   **Overall Loss:** $L_o = L_r + \lambda L_b$ [S1].

**Parameters:**
*   Number of hash experts $N = 8$ [S1].
*   Learning rate: $5 \times 10^{-4}$, exponentially decreasing [S1].
*   Balance loss weight $\lambda$: $5 \times 10^{-4}$ [S1].

**Pitfalls:**
*   The discrete selection operation of experts is not differentiable, and gradients cannot be back-propagated through it into the gating network [S1]. This is addressed by multiplying gate values to the expert outputs [S1].
*   A single gating network is used to avoid large increases in memory and computation cost [S1].

**Pseudocode:**
```python
import math

def softmax(x):
    max_x = max(x)
    exp_x = [math.exp(xi - max_x) for xi in x]
    sum_exp = sum(exp_x)
    return [e / sum_exp for e in exp_x]

def spherical_harmonics(d, degree=4):
    # Standard spherical harmonics encoding for direction d [G]
    sh = []
    dx, dy, dz = d
    for l in range(degree + 1):
        for m in range(-l, l + 1):
            sh.append(math.sin(l * math.atan2(math.sqrt(dx**2 + dy**2), dz)) * math.cos(m * math.atan2(dy, dx)))
    return sh

def concatenate(lists):
    return [item for sublist in lists for item in sublist]

def diff(t, prepend=None):
    if prepend is not None:
        t = [prepend] + t
    return [t[i] - t[i-1] for i in range(1, len(t))]

def cumsum(x):
    res = []
    s = 0.0
    for xi in x:
        s += xi
        res.append(s)
    return res

def linspace(start, stop, num):
    if num == 1: return [start]
    step = (stop - start) / (num - 1)
    return [start + i * step for i in range(num)]

def ones_like(x):
    return [1.0] * len(x)

def switch_nerf_forward(x, d, a, gating_hash, experts, density_head, color_head):
    # 1. Gating Network Evaluation
    fg = lookup_hash(gating_hash, x)  # Hash lookup operation [S1]
    gate_values = small_mlp(fg)       # Small MLP prediction [S1]
    
    # 2. Gate Normalization
    G = softmax(gate_values)
    
    # 3. Expert Selection (Top-1)
    i = G.index(max(G))
    
    # 4. Expert Feature Encoding
    Ei_x = lookup_hash(experts[i], x)  # Hash lookup operation [S1]
    
    # 5. Gate Application
    Gi = G[i]
    E_hat_i_x = [Gi * val for val in Ei_x]
    
    # 6. Direction Encoding
    SH_d = spherical_harmonics(d)
    
    # 7. Feature Concatenation
    f_final = concatenate([E_hat_i_x, SH_d, a])
    
    # 8. Density Prediction
    sigma = density_head(E_hat_i_x)  # Returns scalar [S1]
    
    # 9. Color Prediction
    c = color_head(E_hat_i_x)        # Returns list of 3 [S1]
    
    return sigma, c

def render_ray(ray_origin, ray_direction, near, far, num_samples, gating_hash, experts, density_head, color_head, appearance_embedding):
    t = linspace(near, far, num_samples)
    points = [[ray_origin[j] + t[k] * ray_direction[j] for j in range(3)] for k in range(num_samples)]
    
    sigma_list = []
    c_list = []
    for point in points:
        sigma, c = switch_nerf_forward(point, ray_direction, appearance_embedding, gating_hash, experts, density_head, color_head)
        sigma_list.append(sigma)
        c_list.append(c)
    
    # Volume Rendering
    delta = diff(t, prepend=near)
    if len(delta) < len(sigma_list):
        delta.append(delta[-1])
        
    alpha = [1.0 - math.exp(-sigma_list[k] * delta[k]) for k in range(len(sigma_list))]
    transmittance_exponents = cumsum([sigma_list[k] * delta[k] for k in range(len(sigma_list))])
    T = [math.exp(-exponent) for exponent in transmittance_exponents]
    # Shift T right to get transmittance BEFORE each sample: T_i = exp(-sum_{j=1}^{i-1} sigma_j delta_j)
    T = [1.0] + T[:-1]
    
    rendered_color = [sum(T[k] * alpha[k] * c_list[k][j] for k in range(len(sigma_list))) for j in range(3)]
    return rendered_color
```

## Operating characteristics
*   **Time Complexity:** Switch-NeRF++ achieves an 8x acceleration in training and a 16x acceleration in rendering compared to Switch-NeRF [S1]. It achieves state-of-the-art results with 5.5h training (50k steps), which is 8x faster than Switch-NeRF (44h) and 5x faster than Mega-NeRF (30h) [S1].
*   **Memory Complexity:** Hash dispatching uses less GPU memory in training compared to MoE dispatching [S1].
*   **Measured Performance:** On the UrbanBIS scene (6.5km², 13k images), Switch-NeRF++ achieved a PSNR of 20.76, compared to 19.58 for INGP [S1].
*   **Strengths:** Highly scalable to large-scale scenes, end-to-end trainable, efficient hash-based gating and dispatching, heterogeneous representation for diverse scene parts [S1].
*   **When to use:** Large-scale scene modeling where scalability and efficiency are critical [S1].
*   **When not to use:** Small-scale scenes where simpler methods like Instant-NGP might be sufficient [S1].

## Background
Switch-NeRF++ was introduced in [S1]. It extends the previous Switch-NeRF method [S1]. The method is evaluated on Mega-NeRF, UrbanBIS, Block-NeRF, and MatrixCity datasets [S1].
