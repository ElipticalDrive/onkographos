# NeRF Training Setup

Also called: Control-NeRF Training Setup, Nerfstudio Training

## Overview
This article describes the training configuration for NeRF-based models using the Nerfstudio library, specifically leveraging NerfAcc and Instant-NGP for fast convergence on static scenes [S2]. It also details the specific architectural modifications introduced in Control-NeRF, which replaces standard positional encoding of 3D positions with sampled feature vectors [S1]. The method solves the problem of efficiently optimizing radiance fields for static environments, such as laparoscopic surgical videos, by utilizing hierarchical sampling and specific input representations [S2]. It differs from standard NeRF implementations by substituting the 60-parameter positionally encoded input with a 64-dimensional feature vector and omitting positional encoding on that vector [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Multi-view images (e.g., LLFF datasets or laparoscopic video frames), camera poses, and a pre-computed volume $V_s$ containing sampled features.
*   **Outputs:** Optimized network parameters for coarse ($\hat{C}_c$) and fine ($\hat{C}_f$) networks, producing rendered images with color $\mathbf{c}$ and opacity $\sigma$.

**Data Structures:**
*   **Volume $V_s$:** A 3D volume storing 64-dimensional feature vectors.
*   **Feature Vector $\mathbf{v}_s$:** A 64-dimensional vector obtained via trilinear sampling $S(V_s, \mathbf{p})$ at point $\mathbf{p} \in \mathbb{R}^3$. No positional encoding is applied to $\mathbf{v}_s$ [S1].
*   **Direction Vector $\mathbf{d}$:** A 3D vector representing ray direction.
*   **Encoded Direction $\gamma(\mathbf{d})$:** A higher-dimensional vector derived from $\mathbf{d}$ using positional encoding [S1].

**Numbered Steps:**
1.  **Ray Sampling:** Sample 1024 rays per batch from the input images [S1]. For laparoscopic applications, rays are sampled from input images and corresponding camera poses, excluding specific regions (e.g., red lines in visualization) to prevent artifacts at intersections [S2].
2.  **Coarse Network Optimization:** Optimize a coarse network $\hat{C}_c(\mathbf{r})$ that samples 64 points from evenly spaced bins along the ray length [S1].
3.  **Fine Network Sampling:** Sample 64 additional points for a fine network $\hat{C}_f(\mathbf{r})$. These points are sampled based on the coarse network's opacity results to focus on relevant portions of the scene volume [S1].
4.  **Feature Sampling:** For each sample point $\mathbf{p}$, obtain the feature vector $\mathbf{v}_s = S(V_s, \mathbf{p})$ using trilinear sampling [S1].
5.  **Direction Encoding:** Apply positional encoding to the direction vector $\mathbf{d} \in \mathbb{R}^3$. The encoding function is defined as:
    $$ \gamma(\mathbf{p}) = [\sin(2^0\pi\mathbf{p}), \cos(2^0\pi\mathbf{p}), \dots, \sin(2^{L-1}\pi\mathbf{p}), \cos(2^{L-1}\pi\mathbf{p})] $$
    where $\mathbf{p}$ is each dimension of $\mathbf{d}$ and $L=4$ [S1].
6.  **Network Forward Pass:** Pass the feature vector $\mathbf{v}_s$ and the encoded direction $\gamma(\mathbf{d})$ to the radiance function $F_\Theta$:
    $$ F_\Theta: (\mathbf{v}_s, \gamma(\mathbf{d})) \rightarrow (\mathbf{c}, \sigma) $$
    Note: Unlike standard NeRF, the 3D position is not passed to the network, and no positional encoding is applied to $\mathbf{v}_s$ [S1].
7.  **Volume Rendering:** Compute the rendered color $\mathbf{C}(\mathbf{r})$ for a ray $\mathbf{r}$ using the discretized approximation of the integral:
    $$ \mathbf{C}(\mathbf{r}) = \sum_{i=1}^N T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i $$
    where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance, $\sigma_i$ is the density, $\delta_i$ is the segment length, and $\mathbf{c}_i$ is the color [S1][S3, unofficial].
8.  **Loss Computation:** Compute the photometric loss (mean squared error between predicted and ground truth colors) and, if applicable, an Eikonal loss for geometry regularization [S3, unofficial].
9.  **Optimization:** Update network parameters using gradient-based optimization (e.g., Adam) [S2][S3, unofficial].

**Parameters:**
*   **Positional Encoding Depth ($L$):** 4 for direction encoding [S1].
*   **Batch Size:** 1024 rays [S1].
*   **Image Resolution:** 504 × 378 for LLFF datasets [S1]; 128 × 128 for lego dataset in Image-Based NeRF [S3, unofficial].
*   **Epochs:** 250 for Image-Based NeRF [S3, unofficial].
*   **Hardware:** Single RTX A6000 GPU and 128 GB RAM [S2].

**Edge Cases and Pitfalls:**
*   **Precision:** Ensure that the trilinear sampling operation $S(V_s, \mathbf{p})$ handles boundary conditions correctly to avoid artifacts [S1].
*   **Artifacts:** In laparoscopic applications, exclude rays intersecting specific regions (e.g., surgical tools or image borders) to prevent artifacts [S2].
*   **Input Mismatch:** Do not apply positional encoding to the feature vector $\mathbf{v}_s$, as this is a key deviation from standard NeRF [S1].

## Subtopics

### Image-Based NeRF Training
Training a NeRF using RGB images as ground truth, optimizing both geometry (via Eikonal loss) and appearance (via color loss) [S3, unofficial]. It differs from the Control-NeRF setup by explicitly including an Eikonal loss for geometry regularization and using a standard dataset loading pipeline (`get_nerf_datasets`) [S3, unofficial]. Choose this variant when geometry regularization is critical for the scene structure [S3, unofficial]. It typically runs for 250 epochs on 128x128 images [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** Not explicitly given, but Instant-NGP and NerfAcc are designed for fast convergence [S2].
*   **Memory Complexity:** Not explicitly given, but depends on the volume size and network parameters [S1, S2].
*   **Measured Performance:** Trained on a single RTX A6000 GPU with 128 GB RAM [S2].
*   **Strengths:** Fast convergence on static scenes; efficient ray sampling using NerfAcc and Instant-NGP [S2].
*   **Limitations:** Limited to static scenes with minimal moving objects (e.g., surgical tools) [S2].
*   **When to Use:** For static scene rendering, particularly in medical imaging (laparoscopic videos) [S2].
*   **When Not to Use:** For dynamic scenes with significant motion [S2].

## Background
The NeRF Training Setup described here originates from the Control-NeRF paper, which introduced editable feature volumes for scene rendering and manipulation [S1]. It was adapted for laparoscopic surgical video rendering using the Nerfstudio library, NerfAcc, and Instant-NGP to handle static abdominal environments [S2]. The method builds on the standard NeRF architecture but modifies the input representation to use sampled feature vectors instead of positionally encoded 3D coordinates [S1].
