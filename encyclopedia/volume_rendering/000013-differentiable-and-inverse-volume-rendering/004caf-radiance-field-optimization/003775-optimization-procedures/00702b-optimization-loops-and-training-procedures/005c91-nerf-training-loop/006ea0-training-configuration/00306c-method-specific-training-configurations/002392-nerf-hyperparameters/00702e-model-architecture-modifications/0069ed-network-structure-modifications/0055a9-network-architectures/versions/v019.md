# Network Architectures
Also called: NeRF Network Architectures

## Overview
Network architectures in NeRF define the function $F_\Theta: (\mathbf{x}, \mathbf{d}) \rightarrow (\sigma, \mathbf{c})$ that maps 3D spatial positions $\mathbf{x}$ and viewing directions $\mathbf{d}$ to volume density $\sigma$ and view-dependent color $\mathbf{c}$ [G]. While the standard NeRF architecture uses two MLPs, variants modify this structure to handle dynamic scenes, noise, specific object manipulations, or efficiency constraints [S1, S3, S5, S6].

## How it works
The core task is to learn a continuous volumetric scene representation [G]. The rendering process integrates these outputs along rays using standard volume rendering equations [G].

### Standard NeRF Architecture
The baseline architecture [S1] employs two Multi-Layer Perceptrons (MLPs):
1.  **Position MLP ($\Phi_{pos}$)**: Takes the spatial position $\mathbf{x}$ and its positional encoding $\gamma(\mathbf{x})$ to produce a feature vector $\mathbf{h}$ [G].
2.  **Shading MLP ($\Phi_{shade}$)**: Takes the feature vector $\mathbf{h}$ and the viewing direction $\mathbf{d}$ (encoded as $\gamma(\mathbf{d})$) to predict the volume density $\sigma$ and the RGB color $\mathbf{c}$ [G].

### MobileNeRF Architectures (A, F, H)
*   **MLPs A and F**: Use the MLP designed in NeRF, with hidden layer sizes increased from 256 to 384 [S1]. They are not used during inference, allowing more time on training [S1].
*   **MLP H**: Same as the small MLP used in SNeRG, with two hidden layers, each consisting 16 neurons [S1].

## Subtopics

### [MIMO-DONeRF](16217-mimo-donerf.md)
MIMO-DONeRF is a method that applies the Multi-Input Multi-Output (MIMO) neural rendering concept to the DONeRF architecture. It modifies the shading network to accept multiple spatial inputs and view directions simultaneously, producing multiple color and density outputs per forward pass. This approach improves inference speed compared to increasing the number of samples in standard DONeRF, while maintaining or improving image quality by allowing the network to accumulate neighbor information through grouped samples. It differs from standard DONeRF by processing $N_p$ samples in parallel rather than sequentially, and from MIMO-NeRF by being specifically adapted to the two-network structure (depth oracle and shading) of DONeRF.

### [Point-NeRF Adaptation for Object Manipulation](16395-point-nerf-adaptation-for-object-manipulation.md)
This method adapts the Point-NeRF architecture to enable 3D scene geometry decomposition and manipulation from 2D images. It solves the problem of editing specific objects within a complex scene by replacing the standard Multi-View Stereo (MVS) point cloud generation with ground-truth dense data during training and using a diffusion model to infer object codes for manipulation. It differs from standard Point-NeRF by integrating a DM-NeRF module to map spatial locations to object codes and modifying the rendering pipeline to support point transformation.

### [Sparse Latent Space for 4D Novel View Synthesis (SLS4D)](18112-sparse-latent-space-for-4d-novel-view-synthesis-sls4d.md)
SLS4D is a method for 4D novel-view synthesis that represents dynamic radiance fields using a learnable sparse latent space, reducing network parameters compared to dense grid discretizations while maintaining high-frequency detail via attention-based interpolation. It differs from dense grid methods (like TiNeuVox) by avoiding the $O(N^3TF)$ space complexity of 4D grids, and from per-image latent code methods by offering better generalization across time through continuous temporal interpolation.

### [Neural Feature Fusion Fields (N3F)](18114-neural-feature-fusion-fields-n3f.md)
Neural Feature Fusion Fields (N3F) is a method that distills dense 2D image features from a pre-trained teacher network into a 3D neural field (student) via differentiable volumetric rendering, enabling 3D-aware feature representation. Unlike Semantic NeRF or Panoptic NeRF which fuse discrete semantic labels, N3F fuses continuous dense feature vectors, allowing for open-world applications without manual labels. It differs from standard feature distillation because the student operates in 3D world space (ensuring spatial consistency) while the teacher operates in 2D image space.

### [CLNeRF Architecture with Embeddings](18159-clnerf-architecture-with-embeddings.md)
CLNeRF is a model architecture modification for NeRF that enables continual learning by incorporating scene changes (appearance and geometry) over time within a single model, preventing model size growth as new scans are added. It sets itself apart from sibling methods like MIMO-DONeRF and SLS4D by using explicit, trainable per-scan embedding vectors rather than latent space compression or multi-instance networks, allowing for efficient updates and low overhead for generative replay.

### [Mutual Information Gradient Shaping](18669-mutual-information-gradient-shaping.md)
Mutual Information Gradient Shaping (MIGS), implemented as JacobiNeRF, is a training regularization technique that shapes the tangent space of a Neural Radiance Field (NeRF) to encode semantic correlations between scene entities. Unlike first-order approaches that distill 2D features into 3D radiance channels or treat labels as separate output channels, MIGS aligns the Jacobians of correlated entities to maximize their mutual information under random weight perturbations, enabling efficient sparse label propagation and semantic consensus.

### [Multi-Level Neural Scene Graph](19889-multi-level-neural-scene-graph.md)
Multi-Level Neural Scene Graph (NSG) is a scene representation that decomposes an environment into a graph of static, dynamic, and temporal nodes to model urban environments with moving objects and appearance variations. It distinguishes itself from sibling architectures by explicitly separating the radiance field into a static component $\phi$ and a dynamic component $\psi$, conditioned on sequence-level and object-level latent vectors respectively, enabling the disentanglement of scene-dependent appearance from object texture.

### [NAN (Noise-Aware NeRFs)](20279-nan-noise-aware-nerfs.md)
NAN is a burst-denoising method that extends the IBRNet architecture to handle degraded noisy images, such as those captured in low-light conditions, by modifying feature extraction, aggregation, and color blending to be noise-aware. Unlike standard NeRFs that synthesize novel views, NAN fixes an existing view image by leveraging multiple noisy inputs of the same scene. It distinguishes itself from its sibling [MIMO-DONeRF](16217-mimo-donerf.md) and [Point-NeRF Adaptation for Object Manipulation](16395-point-nerf-adaptation-for-object-manipulation.md) by explicitly modeling spatial noise statistics through 3D blending kernels and cross-view variance features, rather than relying solely on single-pixel cross-view consistency.

### [Multiplicative Interaction Module](21736-multiplicative-interaction-module.md)
The Multiplicative Interaction Module (MIM) is a neural component that generates conditional inputs for a NeRF by computing multiplicative interactions between expression, identity, and optional latent codes to improve facial disentanglement and rendering quality. It sets itself apart from sibling methods like [MIMO-DONeRF](16217-mimo-donerf.md) or [Point-NeRF Adaptation for Object Manipulation](16395-point-nerf-adaptation-for-object-manipulation.md) by explicitly modeling higher-order (second and third) multiplicative dependencies between semantic codes rather than relying on linear concatenation or simple additive fusion.

### [Part-Wise NARF (NARFP)](23078-part-wise-narf-narfp.md)
Part-Wise NARF (NARFP) is a neural articulated radiance field method that models an articulated object by training a separate Ray-Traced NeRF (RT-NeRF) for each rigid part, combining their outputs to estimate global density and color. It differs from holistic approaches by explicitly computing rigid transformations via forward kinematics, thereby avoiding implicit transformation issues and part dependency problems inherent in other methods.

### Pyramid NeRF
Pyramid NeRF accomplishes rapid NeRF training and inference through the application of an image pyramid and a strategy based on frequency optimization [S2]. It utilizes a 'low-frequency-first, high-frequency-second' approach, substituting large MLPs with thousands of smaller ones via progressive segmentation [S2]. It introduces a sampling approach that is aware of depth to enhance rendering quality and hasten training convergence [S2]. It enhances training speed by 15x and inference speed by 805x relative to the original NeRF [S2].

### Residual-NeRF-S
Residual-NeRF-S is an ablation variant of Residual-NeRF where background and residual NeRFs are merged by simply adding their outputs before activation, instead of using a Mixnet [S3]. Residual-NeRF-S produces worse depth and view reconstruction compared to Residual-NeRF with Mixnet, especially for partially opaque objects [S3].

### OccNet
OccNet (Occupancy Networks) is a single-level version of NeRF that does not leverage positional encodings [S4, unofficial]. Performance on 2D Images: 13.90 PSNR / 0.437 SSIM [S4, unofficial]. Performance on Radiance Field: 20.60 PSNR / 0.849 SSIM [S4, unofficial]. Training Time: 02:17 / 100:23 [S4, unofficial]. Model Size: 0.38 / 0.43 [S4, unofficial].

### Dynamic Scene Network Architecture
The Dynamic Scene Network Architecture divides dynamic scenes into static and dynamic parts modeled by two separate MLPs [S5]. It uses equidistant sampling to obtain spatial points along rays, instead of hierarchical sampling [S5]. It uses predicted scene flow to establish inter-frame relationship for time consistency [S5]. The Dynamic Network $F_{\Theta}^{dy}$ inputs positional encoding of position $\gamma(\mathbf{x})$, direction $\gamma(\mathbf{d})$, and time $\gamma(t)$, outputting color $\mathbf{c}_t$, density $\sigma_t$, scene flow $\mathcal{F}_t$, and disocclusion weights $\mathcal{W}_t$ [S5]. The Static Network $F_{\Theta}^{st}$ inputs positional encoding of position $\gamma(\mathbf{x})$ and direction $\gamma(\mathbf{d})$, outputting color $\mathbf{c}$, density $\sigma$, and blending weight $v$ [S5].

### NeRF Network Architecture with Blend Weight Field
The NeRF Network Architecture with Blend Weight Field defines the radiance field ($F_\sigma$, $F_c$) and blend weight field ($F_{\Delta w}$), following the original NeRF but with specific modifications for blend weights [S6]. It uses single-level NeRF, sampling 64 points along each camera ray [S6]. The network $F_{\Delta w}$ is almost same as $F_\sigma$, except the final output layer has 24 channels and applies exp(·) to the output [S6]. The appearance code $\mathbf{l}_i$ dimension is 128 [S6].

## Operating characteristics
The standard NeRF architecture is computationally intensive due to the evaluation of two MLPs per sample point along each ray [G]. Variants like Pyramid NeRF offer significant speedups, enhancing training speed by 15x and inference speed by 805x relative to the original NeRF [S2]. Dynamic architectures like the Dynamic Scene Network require additional outputs (scene flow, disocclusion weights) and time inputs, increasing model complexity but enabling temporal consistency [S5]. MobileNeRF variants (A, F, H) optimize for mobile inference by reducing network size or leveraging rasterization pipelines, with MLPs A and F being unused during inference to save time [S1]. OccNet, lacking positional encodings, suffers from significantly lower performance (13.90 PSNR on 2D images) compared to multi-level NeRF [S4, unofficial]. Residual-NeRF-S simplifies the merging process but degrades depth and view reconstruction quality for opaque objects [S3].

## Background
The standard NeRF architecture was introduced by Mildenhall et al. in 2020 [G]. Subsequent modifications have addressed specific challenges such as dynamic scenes [S5], noise [S1], mobile deployment [S1], and object manipulation [S3, S1]. The concept of using separate MLPs for position and shading has been adapted in various ways, including multi-input multi-output structures [S1], residual networks [S3], and blend weight fields [S6].
