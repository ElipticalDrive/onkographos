# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF training configuration defines the optimization procedure for text-guided stylization of Neural Radiance Fields (NeRFs) by minimizing the negative cosine similarity between rendered images and text prompts in the CLIP embedding space [S1]. It distinguishes itself from standard NeRF reconstruction by freezing density-related parameters and utilizing directional losses to enforce stylistic trajectories, addressing the trade-off between stylization magnitude and diversity [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A pre-trained NeRF model $F_\theta$, a source image $\mathbf{I}_{src}$ (optional, for relative loss), a target text prompt $\mathbf{t}_{tgt}$, and a source text prompt $\mathbf{t}_{src}$ (optional).
*   **Outputs:** Updated NeRF parameters $\theta$ that produce stylized renderings.

**Data Structures:**
*   **NeRF Model:** Standard MLP architecture. Parameters are split into density-related sub-parameters and color/view-dependent sub-parameters [S1].
*   **CLIP Encoder:** ViT-B/32 architecture, used to embed images and text into a shared latent space [S1].

**Numbered Steps:**
1.  **Initialization:** Load the pre-trained NeRF model. Freeze all sub-parameters related to volume density $\sigma$ [S1].
2.  **Patch Sampling:** To manage memory constraints inherent in differentiable rendering of high-resolution images [S1], select a random training pose. Sample rays for a $128 \times 128$ pixel patch with a stride interval of 5. This results in a receptive field of $640 \times 640$ on the original image resolution [S1].
3.  **Efficient Rendering:** Render the patch using importance sampling. Reduce the number of importance sampling points to 16 per ray to ensure memory efficiency [S1]. The fine MLP uses a total of 80 samples (64 coarse + 16 fine) [S1].
4.  **Interpolation:** Apply bilinear interpolation to resize the rendered patch if necessary before feeding it to the CLIP encoder [S1].
5.  **Embedding:** Encode the rendered image $\mathbf{I}_{tgt}$ and the target text prompt $\mathbf{t}_{tgt}$ using the CLIP ViT-B/32 encoder to obtain normalized vectors $\hat{\mathcal{E}}_i(\mathbf{I}_{tgt})$ and $\hat{\mathcal{E}}_t(\mathbf{t}_{tgt})$ [S2].
6.  **Loss Calculation:** Compute the directional CLIP loss. Two variants exist:
    *   **Absolute Directional CLIP Loss:** Measures cosine similarity between the rendered image and the target text [S2].
        $$ \mathcal{L}_{dir} = 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) \rangle $$
    *   **Relative Directional CLIP Loss:** Transfers style from source to target using a pair of text prompts $(\mathbf{t}_{src}, \mathbf{t}_{tgt})$ and the source image $\mathbf{I}_{src}$ [S2].
        $$ \mathcal{L}_{dir} = 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}) - \hat{\mathcal{E}}_i(\mathbf{I}_{src}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) - \hat{\mathcal{E}}_t(\mathbf{t}_{src}) \rangle $$
7.  **Optimization:** Update the unfrozen NeRF parameters using the Adam optimizer with a learning rate of $0.0001$ [S1].
8.  **Iteration:** Repeat steps 2–7 for 500 iterations [S1].

**Pseudocode:**
```python
def train_clipnerf(nerf_model, text_prompt, source_image=None, source_text=None, iterations=500):
    # 1. Freeze density parameters
    for param in nerf_model.density_parameters:
        param.requires_grad = False
    
    optimizer = Adam(nerf_model.color_parameters, lr=0.0001)
    clip_encoder = get_clip_vit_b_32()
    
    for i in range(iterations):
        # 2. Sample random pose and patch
        pose = sample_random_pose()
        # Stride 5 for 128x128 patch -> 640x640 receptive field
        rays = sample_rays(pose, patch_size=128, stride=5)
        
        # 3. Render patch with reduced samples for memory efficiency
        # 64 coarse + 16 fine = 80 total samples
        rendered_patch = render_nerf_patch(nerf_model, rays, num_samples=16)
        
        # 4. Resize/Interpolate
        rendered_patch = bilinear_resize(rendered_patch, target_size=224) # CLIP input size
        
        # 5. Encode
        img_emb = clip_encoder.encode_image(rendered_patch)
        text_emb = clip_encoder.encode_text(text_prompt)
        
        # 6. Compute Loss
        if source_image is not None and source_text is not None:
            # Relative Directional CLIP Loss
            src_img_emb = clip_encoder.encode_image(source_image)
            src_text_emb = clip_encoder.encode_text(source_text)
            
            diff_img_emb = normalize(img_emb - src_img_emb)
            diff_text_emb = normalize(text_emb - src_text_emb)
            
            loss = 1.0 - cosine_similarity(diff_img_emb, diff_text_emb)
        else:
            # Absolute Directional CLIP Loss
            loss = 1.0 - cosine_similarity(normalize(img_emb), normalize(text_emb))
            
        # 7. Optimize
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
    return nerf_model
```

**Parameters:**
*   **Iterations:** 500 [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** 0.0001 [S1].
*   **Text Encoder:** CLIP ViT-B/32 [S1].
*   **Patch Size:** $128 \times 128$ [S1].
*   **Ray Sampling Stride:** 5 (within the patch) [S1].
*   **Importance Sampling Points:** 16 per ray during patch rendering [S1].
*   **Fine MLP Samples:** 80 total (64 coarse + 16 fine) [S1].

**Edge Cases and Pitfalls:**
*   **Memory Constraints:** Naive differentiable rendering of high-resolution images is intractable due to memory limits [S1]. The patch-based approach with stride sampling is required [S1].
*   **Mode Collapse:** The absolute directional CLIP loss can cause mode collapse of the generator and hurt generation diversity [S2].
*   **Insufficient Magnitude:** Directional losses alone may struggle to reach sufficient stylization magnitude, resulting in weak style transfer [S2].

## Operating characteristics
*   **Time Complexity:** Proportional to the number of iterations (500) and the cost of rendering patches with reduced sampling (16 points) [S1].
*   **Memory Complexity:** Significantly reduced compared to full-image rendering by using $128 \times 128$ patches and fewer sampling points [S1].
*   **Strengths:** Enables text-guided stylization of NeRFs without requiring 3D ground truth [S2]. Efficient rendering allows optimization on standard hardware [S1].
*   **Limitations:** Absolute loss may reduce diversity [S2]. Directional loss may lack sufficient magnitude for strong stylization [S2].
*   **When to use:** When text-guided stylization of a pre-existing NeRF is required [S1].
*   **When not to use:** When high diversity is critical and absolute loss is used [S2]. When strong magnitude is required without additional contrastive mechanisms [S2].

## Background
CLIPNeRF was introduced by Wang et al. in 2021, extending the StyleCLIP method [Patashnik et al. 2021] to 3D scene representation [S2]. The directional CLIP loss was first designed for face image editing in StyleCLIP and later extended to generative NeRF editing in CLIP-NeRF [S2]. The relative directional loss variant was proposed in StyleGAN-NADA [Gal et al. 2021] to mitigate mode collapse [S2]. The specific training configuration detailed here (freezing density, patch-based rendering) is described in the context of decomposing NeRF for editing via feature field distillation [S1].
