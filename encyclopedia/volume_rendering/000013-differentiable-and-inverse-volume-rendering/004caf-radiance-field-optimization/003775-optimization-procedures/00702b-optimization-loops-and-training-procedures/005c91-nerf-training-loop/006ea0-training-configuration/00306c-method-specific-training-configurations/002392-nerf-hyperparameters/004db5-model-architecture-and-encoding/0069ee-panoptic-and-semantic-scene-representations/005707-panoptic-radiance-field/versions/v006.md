# Panoptic Radiance Field

Also called: Panoptic Lifting

## Overview
Panoptic Lifting learns a panoptic 3D volumetric representation from posed RGB images and machine-generated 2D panoptic segmentation masks, lifting noisy 2D labels into a consistent 3D representation comprising color, density, semantics, and instances [S1]. It differs from siblings like [Panoptic NeRF](11916-panoptic-nerf.md) and [DM-NeRF](11916-panoptic-nerf.md) by requiring only machine-generated 2D labels rather than manual ground truth or coarse meshes, and from [SemanticNeRF](11916-panoptic-nerf.md) by explicitly modeling 3D-consistent instance identifiers via surrogate IDs [S1].

## How it works
**Inputs:** Posed RGB images $\{I\}$ and corresponding machine-generated 2D panoptic segmentation masks. Each training ray $r$ has an associated RGB color $\hat{\mathbf{c}}_r \in \mathbb{R}^3$, semantic class $\hat{k}_r \in \mathcal{K}$, and 2D instance ID $\hat{h}_r \in \mathcal{H}_I$ (defined only for thing classes $\hat{k}_r \in \mathcal{K}_T$) [S1].

**Outputs:** A panoptic radiance field $\Phi(\mathbf{x}, \mathbf{d})$ that assigns to each 3D point $\mathbf{x} \in \mathbb{R}^3$ and viewing direction $\mathbf{d} \in S^2$:
1.  Density $\sigma \in \mathbb{R}_{\ge 0}$.
2.  Semantic class distribution $\kappa$ over classes $\mathcal{K}$.
3.  Distribution $\pi$ over surrogate identifiers $\mathcal{J}$.
4.  RGB color $\mathbf{c} \in \mathbb{R}^3$ [S1].

**Data Structures:**
*   **TensoRF Representation:** Used for density $\sigma$ and color $\mathbf{c}$ [S1].
*   **Semantic MLP:** A small MLP taking $\mathbf{x}$ as input, outputting $\kappa$ [S1].
*   **Instance MLP:** A small MLP taking $\mathbf{x}$ as input, outputting $\pi$ over a fixed set of surrogate identifiers $\mathcal{J}$ [S1].
*   **Surrogate Identifiers:** A fixed number of class-agnostic 3D-consistent IDs held by the instance field [S1].
*   **3D Instance Set:** $\mathcal{H}_{3D} := \mathcal{K}_T \times \mathcal{J}$ [S1].

**Preprocessing (Test-Time Augmentation):**
To handle noisy 2D labels, test-time augmentations (horizontal flip, scale, brightness, contrast) are applied to input images. Resulting segmentations are fused by segment clustering to obtain a semantic class distribution $\hat{\kappa}_r$ and a confidence estimate $w_r$ for each pixel/ray $r$ [S1].

**Linear Assignment:**
To resolve inconsistent 2D instance IDs across views, a linear assignment is solved. The cost is based on the model's current 3D instance predictions and the machine-generated 2D masks. This maps each 2D instance $\hat{h}_r$ to a unique 3D surrogate identifier via an injective mapping $\Pi^*_R$ [S1].

**Rendering:**
For a ray $r$, the rendered value of any vector field $f$ is:
$$ R[f | r, \sigma] := \int_0^\infty \alpha_t(r) \sigma(r_t) f(r_t, \mathbf{d}_r) dt $$
where $\alpha_t(r) := \exp \left(-\int_0^t \sigma(r_s) ds\right)$ is the transmittance [S1].
*   **Semantic Rendering:** The rendered semantic distribution $\kappa_r$ is computed directly (bounded probabilities, not logits) [S1].
*   **Instance Rendering:** The rendered surrogate ID distribution $\pi_r$ is computed [S1].
*   **Panoptic Prediction:** For a novel view ray $r$, the semantic class is $k^*_r := \arg \max_{k \in \mathcal{K}} \kappa_r(k)$. If $k^*_r \in \mathcal{K}_T$, the surrogate ID is $j^*_r := \arg \max_{j \in \mathcal{J}} \pi_r(j)$. The 3D instance ID is $(k^*_r, j^*_r)$ [S1].

**Loss Functions:**
The total loss is:
$$ L_{tot}(R) := \lambda_{ins} L_{ins}(R_I) + \lambda_{con} L_{con}(R_I) + \lambda_{RGB} L_{RGB}(R_S) + \lambda_{sem} L_{sem}(R_S) $$
where $R_S$ are rays randomly sampled across the scene and $R_I$ are rays sampled from a single image [S1].

1.  **Photometric Loss ($L_{RGB}$):** L2 loss between rendered color $R[\mathbf{c}|r, \sigma]$ and ground truth $\hat{\mathbf{c}}_r$ [S1].
2.  **Semantic Loss ($L_{sem}$):** Cross-entropy between rendered distribution $\kappa_r$ and augmented label distribution $\hat{\kappa}_r$, weighted by confidence $w_r$:
    $$ L_{sem}(R) := -\frac{1}{|R|} \sum_{r \in R} w_r \sum_{k \in \mathcal{K}} \hat{\kappa}_r(k) \log \kappa_r(k) $$
    [S1].
3.  **Instance Loss ($L_{ins}$):** Log-loss (NCE) between rendered surrogate ID distribution $\pi_r$ and the mapped 2D instance target $\Pi^*_R(\hat{h}_r)$ for rays belonging to instance $h$ [S1].
4.  **Segment Consistency Loss ($L_{con}$):** Guides semantic supervision to avoid fragmenting objects due to label inconsistencies [S1].

**Gradient Blocking:**
Gradients from semantic and instance branches are stopped from flowing back to the density network to prevent noisy labels from corrupting geometry [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class PanopticRadianceField:
    def __init__(self, num_surrogates, num_classes, tensorf_config):
        # TensoRF for density and color
        self.tensorf = TensoRF(tensorf_config)
        
        # Small MLP for semantic distribution
        self.semantic_mlp = nn.Sequential(
            nn.Linear(3, 64),
            nn.ReLU(),
            nn.Linear(64, num_classes)
        )
        
        # Small MLP for surrogate ID distribution
        self.instance_mlp = nn.Sequential(
            nn.Linear(3, 64),
            nn.ReLU(),
            nn.Linear(64, num_surrogates)
        )
        
        # Loss weights
        self.lambda_ins = 1.0
        self.lambda_con = 1.35
        self.lambda_rgb = 1.0
        self.lambda_sem = 1.0

    def forward(self, x, d):
        """
        x: [N, 3] 3D points
        d: [N, 3] viewing directions
        Returns: sigma, c, kappa, pi
        """
        # TensoRF outputs density and color
        sigma, c = self.tensorf(x, d)
        
        # Semantic distribution (bounded probabilities)
        # Note: Source specifies rendering bounded probabilities, not logits.
        # We apply Softmax to ensure valid distribution.
        semantic_logits = self.semantic_mlp(x)
        kappa = F.softmax(semantic_logits, dim=-1)
        
        # Instance distribution (bounded probabilities)
        instance_logits = self.instance_mlp(x)
        pi = F.softmax(instance_logits, dim=-1)
        
        return sigma, c, kappa, pi

    def render(self, rays, sigma, kappa, pi):
        """
        rays: [N, 4] (origin, direction)
        sigma: [N] density along ray
        kappa: [N, K] semantic distribution
        pi: [N, J] surrogate ID distribution
        Returns: rendered_color, rendered_kappa, rendered_pi
        """
        # Standard volume rendering equation
        # alpha_t(r) = exp(-int_0^t sigma(r_s) ds)
        # R[f] = int alpha_t * sigma * f dt
        
        # Discretized rendering
        # Assuming rays are sampled at points t_i
        # alpha_i = exp(-sum_{j<i} sigma_j * delta_j)
        # weight_i = alpha_i * (1 - exp(-sigma_i * delta_i))
        
        # Placeholder for actual volume rendering implementation
        # which computes transmittance and accumulated weights
        weights = compute_transmittance_weights(sigma)
        
        rendered_color = torch.sum(weights.unsqueeze(-1) * c, dim=-2)
        rendered_kappa = torch.sum(weights.unsqueeze(-1) * kappa, dim=-2)
        rendered_pi = torch.sum(weights.unsqueeze(-1) * pi, dim=-2)
        
        return rendered_color, rendered_kappa, rendered_pi

    def compute_loss(self, rays, gt_color, gt_sem_dist, gt_conf, gt_2d_instances, 
                     mapped_3d_instances, is_single_image_batch):
        """
        gt_color: [N, 3]
        gt_sem_dist: [N, K]
        gt_conf: [N]
        gt_2d_instances: [N]
        mapped_3d_instances: [N] (surrogate IDs)
        """
        sigma, c, kappa, pi = self.forward(rays.x, rays.d)
        
        rendered_color, rendered_kappa, rendered_pi = self.render(rays, sigma, kappa, pi)
        
        # RGB Loss
        l_rgb = F.mse_loss(rendered_color, gt_color)
        
        # Semantic Loss (Cross-Entropy weighted by confidence)
        # L_sem = - sum(w_r * sum_k(hat_kappa_r(k) * log(kappa_r(k))))
        l_sem = 0
        for r in range(len(rays)):
            # Ensure numerical stability
            log_kappa = torch.log(kappa[r] + 1e-8)
            l_sem += -gt_conf[r] * torch.sum(gt_sem_dist[r] * log_kappa)
        l_sem = l_sem / len(rays)
        
        # Instance Loss (NCE/Log-loss)
        # Minimizes log-loss of rendered distribution vs mapped target
        l_ins = 0
        for r in range(len(rays)):
            target_id = mapped_3d_instances[r]
            # One-hot target
            target = torch.zeros_like(pi[r])
            target[target_id] = 1.0
            # Cross entropy
            log_pi = torch.log(pi[r] + 1e-8)
            l_ins += -torch.sum(target * log_pi)
        l_ins = l_ins / len(rays)
        
        # Segment Consistency Loss (Placeholder for specific formulation)
        # Source mentions it guides semantic supervision to avoid fragmentation
        l_con = compute_segment_consistency_loss(kappa, gt_sem_dist) 
        
        # Total Loss
        # Gradients from semantic and instance branches are blocked from geometry
        # This is implemented by detaching sigma from the computation graph
        # or using stop_gradient on the semantic/instance branches before they affect sigma.
        # Here we assume the forward pass already handles this via architecture or autograd hooks.
        
        total_loss = (self.lambda_ins * l_ins + 
                      self.lambda_con * l_con + 
                      self.lambda_rgb * l_rgb + 
                      self.lambda_sem * l_sem)
        
        return total_loss, l_rgb, l_sem, l_ins, l_con

    def edit_scene(self, rays, instance_to_delete, new_position, new_rotation):
        """
        Scene editing operations.
        """
        # Get current predictions
        sigma, c, kappa, pi = self.forward(rays.x, rays.d)
        
        # Determine 3D instance ID for each ray
        k_star = torch.argmax(kappa, dim=-1)
        j_star = torch.argmax(pi, dim=-1)
        instance_ids = torch.stack([k_star, j_star], dim=-1)
        
        # Deletion: Set density to 0 for points matching instance_to_delete
        mask_delete = torch.all(instance_ids == instance_to_delete, dim=-1)
        sigma = torch.where(mask_delete, torch.zeros_like(sigma), sigma)

        # This requires ray manipulation logic not fully detailed in source
        # Placeholder:
        # if ray passes through new_position/rotation:
        #    query sigma, c, etc. from original instance region
        
        return sigma, c, kappa, pi
```

**Parameters:**
*   $\mathcal{K}$: Set of semantic classes, partitioned into thing classes $\mathcal{K}_T$ and stuff classes $\mathcal{K}_S$ [S1].
*   $\mathcal{J}$: Set of surrogate identifiers. Fixed number held by the instance field MLP [S1].
*   $\lambda_{con} = 1.35, \lambda_{ins} = 1, \lambda_{sem} = 1, \lambda_{RGB} = 1$ [S1].
*   Optimizer: Adam. Learning rates: $5 \times 10^{-4}$ for MLPs, $1 \times 10^{-2}$ for TensoRF lines and planes [S1].
*   Training hardware: 1 NVIDIA A6000. Duration: 450k iterations (~10 hours) [S1].
*   Pre-trained 2D panoptic segmentation model (e.g., Mask2Former with Swin-L backbone) [S1].

**Edge Cases and Pitfalls:**
*   **Logits vs. Probabilities:** Rendering class logits instead of probabilities can introduce semantic inconsistencies because unbounded logits can generate significant signals in low-density areas, violating geometric constraints. The method renders bounded probability distributions [S1].
*   **Geometry Corruption:** Supervision from noisy 2D labels can influence geometry, causing "cloudy" geometry to satisfy conflicting labels. This is avoided by stopping gradients from segmentation branches back to densities [S1].
*   **Class Limitation:** The method is limited to classes supported by the pre-trained 2D segmentation model [S1].
*   **Offline Nature:** The method runs offline due to lengthy pre-processing for pose estimation, 2D segmentation inference, and neural field optimization [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Improves scene-level Panoptic Quality (PQ) by 8.4% on Hypersim, 13.8% on Replica, and 10.6% on ScanNet over state of the art [S1]. Maintains comparable PSNR for novel view synthesis [S1]. Outperforms Mask2Former, SemanticNeRF, DM-NeRF, and PNF on mIoU and PQ_scene [S1].
*   **Scaling:** Not given in the sources.
*   **Strengths:** Robust to inherent noise in machine-generated labels; enables in-the-wild scene processing; supports scene editing (deletion, duplication, manipulation) [S1].
*   **Limitations:** Offline processing; limited to classes in the pre-trained 2D model; requires posed images [S1].
*   **When to use:** When only machine-generated 2D panoptic masks are available and 3D-consistent panoptic segmentation is required.
*   **When not to use:** When real-time performance is required or when classes outside the pre-trained 2D model's scope are needed [S1].

## Background
Panoptic Lifting was introduced in "Panoptic Lifting for 3D Scene Understanding with Neural Fields" (CVPR 2023) [S1]. It addresses the limitation of previous methods like Panoptic NeRF and DM-NeRF, which required manual ground truth (coarse meshes or per-image 2D panoptic segmentations) [S1]. It builds on [Model Architecture and Encoding](13550-model-architecture-and-encoding.md) by using TensoRF for density/color and adding semantic/instance MLP heads.
