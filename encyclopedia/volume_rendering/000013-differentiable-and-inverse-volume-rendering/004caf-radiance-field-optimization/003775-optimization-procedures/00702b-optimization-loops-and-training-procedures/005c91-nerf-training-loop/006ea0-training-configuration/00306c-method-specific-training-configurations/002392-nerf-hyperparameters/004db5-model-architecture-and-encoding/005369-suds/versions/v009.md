# SUDS
Also called: Scalable Urban Dynamic Scenes

## Overview
SUDS is a 4D radiance field representation designed for large-scale dynamic urban scenes that factorizes the scene into three separate multi-resolution hash table structures: static, dynamic, and far-field [S1]. It solves the problem of scaling neural reconstruction to city-level footprints with thousands of dynamic objects by using unlabeled target signals (RGB, sparse LiDAR, 2D descriptors, and 2D optical flow) for supervision, avoiding the need for expensive 3D bounding box or panoptic labels [S1]. Unlike sibling methods that rely on per-object NeRFs or supervised segmentation, SUDS handles ego-motion and multi-video inputs by indexing separate interpolating functions per video without linear memory growth, enabling free-viewpoint rendering and 3D scene flow estimation at arbitrary poses and time steps [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ordered RGB images from $N$ videos taken at different days with diverse weather/lighting, associated camera poses, aligned sparse LiDAR depth, 2D self-supervised DINO descriptors, and 2D optical flow predictions [S1].
*   **Outputs:** Rendered RGB color $\hat{C}(\mathbf{r})$, semantic features $\hat{F}(\mathbf{r})$, 3D scene flow vectors, and shadow ratios for any ray $\mathbf{r}$ at any time $t$ and video $vid$ [S1].

**Data Structures:**
The scene is decomposed into $K$ spatial cells with centroids $\mathbf{k} \in \mathbb{R}^3$. Each cell contains three multi-resolution hash table branches:
1.  **Static Branch:** Stores 3D spatial voxels $\mathbf{v}_{l,s}$ at $L$ resolution levels.
2.  **Dynamic Branch:** Stores 4D spacetime voxels $\mathbf{v}_{l,d}$ at $L$ resolution levels.
3.  **Far-field Branch:** Stores 3D voxels $\mathbf{v}_{l,e}$ (indexed by normalized direction) for the environment map [S1].

Each hash table stores $F$-dimensional feature vectors. Hash indices are computed using specific hash functions that include a video ID ($vid$) to index separate interpolating functions for each video [S1].

**Numbered Steps:**

1.  **Spatial Partitioning:** Split the scene into $K$ spatial cells. Generate training datasets for each cell by including only datapoints whose camera rays intersect the cell. Prune irrelevant rays using LiDAR depth measurements to ensure visibility [S1].
2.  **Voxel Lookup:** For an input coordinate $(\mathbf{x}, \mathbf{d}, t, vid)$, find surrounding voxels at $L$ resolution levels for the static ($\mathbf{v}_{l,s}$), dynamic ($\mathbf{v}_{l,d}$), and far-field ($\mathbf{v}_{l,e}$) branches. Resolution doubles between levels [S1].
3.  **Hash Indexing:** Compute hash indices for voxel corners:
    $$ i_{l,s} = \text{static hash}(\text{space}(\mathbf{v}_{l,s})) $$
    $$ i_{l,d} = \text{dynamic hash}(\text{space}(\mathbf{v}_{l,d}), \text{time}(\mathbf{v}_{l,d}), vid) $$
    $$ i_{l,e} = \text{env hash}(\text{dir}(\mathbf{v}_{l,e}), vid) $$
    [S1]
4.  **Feature Interpolation:** Look up feature vectors corresponding to the corners. Linearly interpolate features for the static branch. Use quadlinear interpolation for the dynamic 4D branch. Handle hash collisions via gradient averaging. Concatenate results from all $L$ levels into a feature vector $\mathbf{f} \in \mathbb{R}^{LF}$ along with auxiliary inputs (viewing direction $\mathbf{d}$) [S1].
5.  **MLP Evaluation:** Pass the concatenated feature vector into an MLP to obtain per-branch outputs:
    *   **Static:** View-dependent color $\mathbf{c}_s(\mathbf{x}, \mathbf{d}, \mathbf{A}_{vid}\mathbf{F}(t)) \in \mathbb{R}^3$ and view-independent density $\sigma_s(\mathbf{x}) \in \mathbb{R}$. Lighting is conditioned via a video-specific matrix $\mathbf{A}_{vid}$ and Fourier-encoded time index $\mathbf{F}(t)$ [S1].
    *   **Dynamic:** Time/video-dependent density $\sigma_d(\mathbf{x}, t, vid) \in \mathbb{R}$, color $\mathbf{c}_d(\mathbf{x}, t, vid, \mathbf{d}) \in \mathbb{R}^3$, and scalar shadow ratio $\rho_d(\mathbf{x}, t, vid) \in [0, 1]$. Also predict forward/backward 3D scene flow $\mathbf{s}_{t0}(\mathbf{x}, t, vid) \in \mathbb{R}^3$ with values in $[-1, 1]$ [S1].
    *   **Far-field:** Environment map color $\mathbf{c}_e(\mathbf{d}, vid) \in \mathbb{R}^3$ [S1].
    *   **Semantic:** Add $C$-dimensional output heads to each branch to distill DINO features: $\Phi_s(\mathbf{x}) \in \mathbb{R}^C$, $\Phi_d(\mathbf{x}, t, vid) \in \mathbb{R}^C$, $\Phi_e(\mathbf{d}, vid) \in \mathbb{R}^C$ [S1].
6.  **Density Combination:** Compute total density as the sum of static and dynamic densities:
    $$ \sigma(\mathbf{x}, t, vid) = \sigma_s(\mathbf{x}) + \sigma_d(\mathbf{x}, t, vid) $$
    [S1]
7.  **Radiance Combination:** Compute total radiance by combining static and dynamic components, scaled by the shadow ratio:
    $$ \mathbf{c}(\mathbf{x}, t, vid, \mathbf{d}) = \frac{(1 - \rho_d)\sigma_s \mathbf{c}_s + \sigma_d \mathbf{c}_d}{\sigma} $$
    [S1]
8.  **Rendering:** Integrate along ray $\mathbf{r}$ to compute color $\hat{C}(\mathbf{r}, t, vid)$:
    $$ \hat{C}(\mathbf{r}, t, vid) = \int_0^{+\infty} T(t)\sigma(\mathbf{r}(t), t, vid)\mathbf{c}(\mathbf{r}(t), t, vid, \mathbf{d}) dt + T(+\infty)\mathbf{c}_e(\mathbf{d}, vid) $$
    where $T(t) = \exp\left(-\int_0^t \sigma(\mathbf{r}(s), t, vid) ds\right)$ [S1].
9.  **Loss Calculation:** Minimize the total loss $\mathcal{L}$:
    $$ \mathcal{L} = \mathcal{L}_c + \lambda_f \mathcal{L}_f + \lambda_d \mathcal{L}_d + \lambda_o \mathcal{L}_o + \mathcal{L}_c^w + \lambda_f \mathcal{L}_f^w + \lambda_{cyc} \mathcal{L}_{cyc} + \mathcal{L}_{sm} + \mathcal{L}_{slo} + \lambda_e \mathcal{L}_e + \lambda_d \mathcal{L}_d + \lambda_\rho \mathcal{L}_\rho $$
    [S1]
    *   **Reconstruction:** L2 photometric loss $\mathcal{L}_c(\mathbf{r}) = ||\hat{C}(\mathbf{r}) - \mathbf{C}(\mathbf{r})||^2$ and L1 feature loss $\mathcal{L}_f(\mathbf{r}) = ||\hat{F}(\mathbf{r}) - \mathbf{F}(\mathbf{r})||_1$ [S1].
    *   **Depth:** L2 depth loss $\mathcal{L}_d(\mathbf{r}) = ||\hat{D}(\mathbf{r}) - D(\mathbf{r})||^2$ where $\hat{D}(\mathbf{r}) = \int_0^{+\infty} T(s)\sigma(\mathbf{r}(s)) ds$ [S1].
    *   **Flow:** Minimize distance from observed optical flow $\mathbf{O}$ via $\mathcal{L}_o(\mathbf{r}) = \sum_{t0} ||\mathbf{X}(\mathbf{o}) - \hat{\mathbf{X}}_{t0}(\mathbf{r})||_1$, where $\hat{\mathbf{X}}_{t0}(\mathbf{r}) = \int_0^{+\infty} T(t)\sigma(\mathbf{r}(t))(\mathbf{r}(t) + \mathbf{s}_{t0}(\mathbf{r}(t))) dt$ [S1].
    *   **Warping:** Advect samples using predicted flow to get warped density $\sigma^w$, color $\mathbf{c}^w$, features $\Phi^w$. Render warped color $\hat{C}^w$ and feature $\hat{F}^w$. Downweight loss in ambiguous regions using weight $W_{t0}(\mathbf{r})$ derived from dynamic geometry difference. Minimize $\mathcal{L}_c^w$ and $\mathcal{L}_f^w$ [S1].
    *   **Flow Regularization:** Cycle consistency $\mathcal{L}_{cyc}(\mathbf{r}) = \sum_{t0} \sum_{\mathbf{x}} w_{t0}(\mathbf{x}, t) ||\mathbf{s}_{t0}(\mathbf{x}, t) + \mathbf{s}_t(\mathbf{x}+\mathbf{s}_{t0}, t-t0)||_1$. Spatial/temporal smoothness $\mathcal{L}_{sm}$ and static scene prior $\mathcal{L}_{slo} = \sum_{t0} \sum_{\mathbf{x}} ||\mathbf{s}_{t0}(\mathbf{x}, t)||_1$ [S1].
    *   **Static-Dynamic Factorization:** Skewed binary entropy loss $\mathcal{L}_e(\mathbf{r}) = \int_0^{+\infty} H\left(\frac{\sigma_d(\mathbf{r}(t))}{\sigma_s(\mathbf{r}(t)) + \sigma_d(\mathbf{r}(t))}\right) dt$ with $k=1.75$, where $H(x) = -(x \log x + (1-x) \log (1-x))$. Penalize max dynamic ratio $\mathcal{L}_d(\mathbf{r}) = \max\left(\frac{\sigma_d}{\sigma_s + \sigma_d}\right)$ along each ray [S1].
    *   **Shadow:** Penalize squared magnitude of shadow ratio $\mathcal{L}_\rho(\mathbf{r}) = \int_0^{+\infty} \rho_d(\mathbf{r}(t))^2 dt$ [S1].

**Parameters:**
*   $F$: Dimensionality of feature vectors in hash tables [S1].
*   $L$: Number of resolution levels (resolution doubles between levels) [S1].
*   $N$: Number of input videos [S1].
*   $vid$: Video ID identifier [S1].
*   $\mathbf{A}_{vid}$: Video-specific matrix for lighting conditioning [S1].
*   $\mathbf{F}(t)$: Fourier-encoded time index [S1].
*   $k$: Constant set to 1.75 in skewed binary entropy loss [S1].
*   $C$: Dimensionality of DINO feature grid [S1].
*   Training: 250,000 iterations, 4098 rays per batch, Adam optimizer, initial LR $5 \times 10^{-3}$, final LR $5 \times 10^{-4}$ [S1].

**Edge Cases and Pitfalls:**
*   Hash collisions are handled via gradient averaging [S1].
*   Ambiguous regions in warping loss are downweighted using weights derived from dynamic geometry difference [S1].
*   The shadow ratio loss prevents over-explaining dark regions [S1].

## Operating characteristics
*   **Time and Memory Complexity:** SUDS scales to tens of thousands of objects across 1.2 million frames from 1700 videos spanning hundreds of kilometers [S1]. It is 10x quicker to train than state-of-the-art methods relying on ground truth 3D bounding box annotations [S1]. Memory usage is controlled by multi-resolution hash tables and spatial partitioning, avoiding the linear memory growth of per-object NeRFs (e.g., NSG requires >1TB for 30s video) [S1].
*   **Strengths:** Handles ego-motion and multi-video representations; uses unlabeled inputs (RGB, LiDAR, flow) for supervision; enables unsupervised 3D instance segmentation and cuboid detection; models shadows explicitly [S1].
*   **Limitations:** Requires aligned sparse LiDAR and optical flow predictions (though these are "free" supervision sources); relies on self-supervised DINO descriptors which may be sparse [S1].
*   **When to use:** Large-scale dynamic urban scene reconstruction with multiple video inputs and diverse lighting conditions.
*   **When not to use:** Small-scale static scenes or scenes where labeled 3D bounding boxes are available and sufficient (simpler methods may be faster to implement).

## Background
SUDS was introduced in 2023 by [S1]. It builds on Instant-NGP's multi-resolution hash tables and extends them to support 4D dynamic scenes and multi-video indexing. It addresses limitations of prior dynamic scene representations that required supervised inputs like panoptic segmentation labels or bounding boxes, which are difficult to acquire for in-the-wild captures. SUDS is used for free-viewpoint synthesis of dynamic urban scenes, unsupervised 3D instance segmentation, and unsupervised 3D cuboid detection. It has been evaluated on KITTI and Virtual KITTI 2 datasets [S1].
