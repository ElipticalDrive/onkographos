# Disentangled Conditional NeRF

Also called: Disentangled Conditional NeRF Training

## Overview
Disentangled Conditional NeRF is a generative radiance field architecture that achieves individual control over the shape and appearance of 3D objects by isolating their conditioning mechanisms [S1]. Unlike standard conditional NeRFs where concatenating latent codes to position features causes mutual intervention (e.g., shape changes altering color), this method uses explicit volumetric deformation for shape conditioning and direct latent injection for appearance, preventing cross-talk between the two attributes [S1]. It is typically trained in two stages: first, a GAN-based training of the generator and deformation network, and second, the training of CLIP-driven mappers for text-based manipulation [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Spatial position $\mathbf{x} \in \mathbb{R}^3$, view direction $\mathbf{v}$, shape code $\mathbf{z}_s$, appearance code $\mathbf{z}_a$, and optionally a text prompt $\mathbf{t}$.
*   **Outputs:** Density $\sigma$ and color $\mathbf{c}$ for volume rendering.

**Data Structures:**
1.  **Deformation Network $T$:** An MLP mapping $(\mathbf{x}, \mathbf{z}_s) \rightarrow \Delta \mathbf{x}$.
    *   $\Delta \mathbf{x} \in \mathbb{R}^{3 \times 2m}$: Displacement vectors corresponding to each band of the positional encoding $\Gamma(\mathbf{x})$, where $m$ is the number of frequency bands.
2.  **Generator $F_\Theta$:** The main NeRF MLP mapping $(\mathbf{x}^*, \mathbf{v}, \mathbf{z}_a) \rightarrow (\sigma, \mathbf{c})$.
    *   $\mathbf{x}^*$: Deformed positional encoding.
3.  **Discriminator $D$:** A standard GAN discriminator evaluating image realism.
4.  **CLIP Encoders $\hat{E}_t, \hat{E}_i$:** Pre-trained text and image encoders (frozen during Stage 2).
5.  **Mappers $M_s, M_a$:** MLPs mapping CLIP text embeddings to shape and appearance code adjustments.

**Numbered Steps:**

1.  **Conditional Shape Deformation:**
    *   Input spatial position $\mathbf{x}$ and shape code $\mathbf{z}_s$ to the deformation network $T$.
    *   Network outputs displacement vectors $\Delta \mathbf{x} \in \mathbb{R}^{3 \times 2m}$.
    *   Compute the deformed positional encoding $\Gamma^*(\mathbf{x}, \mathbf{z}_s)$. The displacement is applied to the position before positional encoding or directly to the encoded features. The source defines $\Gamma^*(\mathbf{p}, \Delta \mathbf{p})$ as the result of applying displacement $\Delta \mathbf{p}$ to position $\mathbf{p}$ [S1]. Specifically, $\Delta \mathbf{x}$ corresponds to each band of $\Gamma(\mathbf{x})$.
    *   Formula: $T: (\mathbf{x}, \mathbf{z}_s) \rightarrow \Delta \mathbf{x}$ [S1].

2.  **Radiance Field Evaluation:**
    *   Feed the deformed encoding $\Gamma^*(\mathbf{x}, \mathbf{z}_s)$, view direction $\mathbf{v}$, and appearance code $\mathbf{z}_a$ into the main NeRF MLP $F_\Theta$.
    *   Output density $\sigma$ and color $\mathbf{c}$.
    *   Render the image $I_{gen} = F_\Theta(\mathbf{v}, \mathbf{z}_s, \mathbf{z}_a)$ using standard volume rendering [S1].

3.  **Stage 1: GAN Training of Generator and Deformation Network:**
    *   Randomly sample $\mathbf{z}_s \sim \mathcal{Z}_s$ (normal distribution), $\mathbf{z}_a \sim \mathcal{Z}_a$ (normal distribution), and camera pose $\mathbf{v} \sim \mathcal{Z}_v$ (upper hemisphere) [S1].
    *   Sample real images $\mathbf{I}$ from the training data distribution $\mathcal{D}$.
    *   Minimize the GAN loss $L_{GAN}$ with respect to $F_\Theta$ and $T$:
        $$ L_{GAN} = \mathbb{E}_{\mathbf{z}_s, \mathbf{z}_a, \mathbf{v}} [f(D(F_\Theta(\mathbf{v}, \mathbf{z}_s, \mathbf{z}_a)))] + \mathbb{E}_{\mathbf{I} \sim \mathcal{D}} [f(-D(\mathbf{I}))] + \lambda_r \|\nabla D(\mathbf{I})\|^2 $$
        where $f(x) = -\log(1 + \exp(-x))$ and $\lambda_r$ is the gradient penalty regularization weight [S1].

4.  **Stage 2: CLIP-Driven Manipulation (Mapper Training):**
    *   Fix weights of $F_\Theta$, $T$, and $D$ (denoted $\hat{F}_\Theta, \hat{T}, \hat{D}$).
    *   Train shape mapper $M_s$ and appearance mapper $M_a$.
    *   Sample $\mathbf{z}_s, \mathbf{z}_a, \mathbf{v}$ as in Stage 1, and text prompt $\mathbf{t}$ from a pre-defined library $\mathcal{T}$ [S1].
    *   Compute CLIP text embedding $\mathbf{e}_t = \hat{E}_t(\mathbf{t})$.
    *   **Shape Mapper Loss:**
        $$ L_{shape} = f(\hat{D}(\hat{F}_\Theta(\mathbf{v}, M_s(\mathbf{e}_t) + \mathbf{z}_s, \mathbf{z}_a))) + \lambda_c D_{CLIP}(\hat{F}_\Theta(\mathbf{v}, M_s(\mathbf{e}_t) + \mathbf{z}_s, \mathbf{z}_a), \mathbf{t}) $$
    *   **Appearance Mapper Loss:**
        $$ L_{appear} = f(\hat{D}(\hat{F}_\Theta(\mathbf{v}, \mathbf{z}_s, M_a(\mathbf{e}_t) + \mathbf{z}_a))) + \lambda_c D_{CLIP}(\hat{F}_\Theta(\mathbf{v}, \mathbf{z}_s, M_a(\mathbf{e}_t) + \mathbf{z}_a), \mathbf{t}) $$
        where $\lambda_c$ is the weight for the CLIP distance term [S1].

**Parameters:**
*   $\lambda_r$: Regularization weight for the gradient penalty in $L_{GAN}$. Value not given in the sources.
*   $\lambda_c$: Weight for the CLIP distance term in mapper losses. Value not given in the sources.
*   $m$: Number of frequency bands in positional encoding. Value not given in the sources.

**Pitfalls:**
*   **Mutual Intervention:** Trivially concatenating the shape code $\mathbf{z}_s$ to the position features causes shape changes to affect color. This is solved by deferring color conditioning to the main MLP and applying shape conditioning via explicit deformation [S1].
*   **Precision:** The displacement $\Delta \mathbf{x}$ is applied per band of the positional encoding. Implementation must ensure the dimensionality of $\Delta \mathbf{x}$ matches the output dimension of $\Gamma(\mathbf{x})$ [S1].

## Subtopics

### CLIP Manipulator Training
A two-stage training procedure where the generator is fixed, and CLIP-driven mappers ($M_s, M_a$) are trained to map text embeddings to latent code adjustments [S1]. It allows text-based editing of shape and appearance independently. The shape mapper modifies the shape code $\mathbf{z}_s$ via $M_s(\hat{E}_t(\mathbf{t}))$, while the appearance mapper modifies $\mathbf{z}_a$ via $M_a(\hat{E}_t(\mathbf{t}))$. It uses a GAN loss on the discriminator and a CLIP distance loss to align the generated image with the text prompt [S1].

## Operating characteristics
*   **Time Complexity:** Training involves two stages. Stage 1 requires GAN training of the generator and deformation network. Stage 2 requires training two smaller mapper networks. No specific time metrics are given in the sources.
*   **Memory Complexity:** Requires storing the generator, deformation network, discriminator, and CLIP encoders. No specific memory metrics are given in the sources.
*   **Strengths:** Provides individual control over shape and appearance, preventing mutual intervention. Enables text-driven manipulation via CLIP mappers. Produces more natural color editing results compared to methods like EditNeRF [S1].
*   **Limitations:** Requires a GAN framework, which can be unstable to train. Relies on pre-trained CLIP models. The deformation network adds complexity to the pipeline.
*   **When to use:** When individual control over shape and appearance is required, and text-driven manipulation is desired.
*   **When not to use:** When computational resources for GAN training are limited, or when simple per-scene optimization is sufficient.

## Background
Disentangled Conditional NeRF was introduced in the paper "CLIP-NeRF: Text-and-Image Driven Manipulation of Neural Radiance Fields" [S1]. It addresses the limitation of standard conditional NeRFs where latent codes for shape and appearance are entangled, leading to unwanted side effects during manipulation [S1]. The method builds on the conditional NeRF framework [S1] and integrates GAN training and CLIP-driven manipulation to achieve robust and disentangled 3D editing.
