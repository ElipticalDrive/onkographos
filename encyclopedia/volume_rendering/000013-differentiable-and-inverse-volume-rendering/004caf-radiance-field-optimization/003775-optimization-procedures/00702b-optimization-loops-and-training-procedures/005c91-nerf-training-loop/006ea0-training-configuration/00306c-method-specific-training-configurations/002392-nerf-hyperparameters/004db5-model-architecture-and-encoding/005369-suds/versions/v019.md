# SUDS

Also called: Scalable Urban Dynamic Scenes

## Overview
SUDS is a 4D neural radiance field representation designed for large-scale dynamic urban scenes, enabling free-viewpoint rendering, semantic decomposition, and 3D scene flow estimation at arbitrary poses and time steps [S1]. It distinguishes itself from sibling methods by factorizing the scene into three separate multi-resolution hash table branches (static, dynamic, and far-field) and utilizing unlabeled target signals (RGB, sparse LiDAR, 2D descriptors, and optical flow) for supervision, thereby avoiding the need for ground-truth 3D bounding boxes or panoptic segmentation labels [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** Ordered RGB images from $N$ videos taken at different days (diverse weather/lighting), associated camera poses, aligned sparse LiDAR depth measurements, 2D self-supervised DINO descriptors, and 2D optical flow predictions [S1].
*   **Outputs:** For a query $(\mathbf{x}, \mathbf{d}, t, \text{vid})$, the method outputs total volume density $\sigma$, color $\mathbf{c}$, semantic features $\Phi$, and scene flow vectors $\mathbf{s}$ [S1].

**Data Structures**
The scene is decomposed into $K$ spatial cells, each trained independently [S1]. Within each cell, the representation consists of three multi-resolution hash table branches:
1.  **Static Branch:** Stores 3D spatial voxels $v_{l,s}$ [S1].
2.  **Dynamic Branch:** Stores 4D spacetime voxels $v_{l,d}$ [S1].
3.  **Far-field Branch:** Stores 3D voxels $v_{l,e}$ indexed by normalized direction vectors, representing an environment map [S1].

Each branch uses $L$ resolution levels, where resolution doubles between levels [S1]. Features are stored as $F$-dimensional vectors in hash tables [S1].

**Hash Indexing**
Instead of storing features at voxel corners directly, SUDS computes hash indices for each corner using specific hash functions [S1]:
$$ i_{l,s} = \text{static hash}(\text{space}(v_{l,s})) $$
$$ i_{l,d} = \text{dynamic hash}(\text{space}(v_{l,d}), \text{time}(v_{l,d}), \text{vid}) $$
$$ i_{l,e} = \text{env hash}(\text{dir}(v_{l,e}), \text{vid}) $$
The video ID ($\text{vid}$) is included in the dynamic and far-field hash functions to index separate interpolating functions for each video without linear memory growth [S1]. Hash collisions are handled via gradient averaging [S1].

**Feature Interpolation**
For a given input coordinate $(\mathbf{x}, \mathbf{d}, t, \text{vid})$, the method finds surrounding voxels at all $L$ levels for the static and dynamic branches [S1].
*   **Static:** Linear interpolation of features to the nearest voxel vertices [S1].
*   **Dynamic:** Quadlinear interpolation of features in the 4D spacetime voxel [S1].
*   **Far-field:** Interpolation based on direction [S1].

The interpolated features from all $L$ levels are concatenated into a feature vector $\mathbf{f} \in \mathbb{R}^{LF}$ [S1].

**MLP Evaluation**
The feature vector $\mathbf{f}$ is concatenated with auxiliary inputs (viewing direction $\mathbf{d}$, and for the static branch, a lighting embedding) and passed into a Multi-Layer Perceptron (MLP) [S1].

*   **Static Branch Output:**
    *   View-independent density: $\sigma_s(\mathbf{x}) \in \mathbb{R}$ [S1].
    *   View-dependent color: $\mathbf{c}_s(\mathbf{x}, \mathbf{d}, \mathbf{A}_{\text{vid}} \mathbf{F}(t)) \in \mathbb{R}^3$ [S1].
    *   Semantic features: $\Phi_s(\mathbf{x}) \in \mathbb{R}^C$ [S1].
    *   *Lighting Conditioning:* The static branch conditions on a latent embedding computed as $\mathbf{A}_{\text{vid}} \mathbf{F}(t)$, where $\mathbf{A}_{\text{vid}}$ is a video-specific matrix and $\mathbf{F}(t)$ is a Fourier-encoded time index [S1].

*   **Dynamic Branch Output:**
    *   Time/video-dependent density: $\sigma_d(\mathbf{x}, t, \text{vid}) \in \mathbb{R}$ [S1].
    *   Time/video-dependent color: $\mathbf{c}_d(\mathbf{x}, t, \text{vid}, \mathbf{d}) \in \mathbb{R}^3$ [S1].
    *   Shadow ratio: $\rho_d(\mathbf{x}, t, \text{vid}) \in [0, 1]$ [S1].
    *   Semantic features: $\Phi_d(\mathbf{x}, t, \text{vid}) \in \mathbb{R}^C$ [S1].
    *   Scene flow: Forward and backward 3D scene flow vectors $\mathbf{s}_{t_0}(\mathbf{x}, t, \text{vid}) \in \mathbb{R}^3$ with values in $[-1, 1]$ [S1].

*   **Far-field Branch Output:**
    *   Environment map color: $\mathbf{c}_e(\mathbf{d}, \text{vid}) \in \mathbb{R}^3$ [S1].
    *   Semantic features: $\Phi_e(\mathbf{d}, \text{vid}) \in \mathbb{R}^C$ [S1].

**Density and Radiance Combination**
Total density is the sum of static and dynamic densities:
$$ \sigma(\mathbf{x}, t, \text{vid}) = \sigma_s(\mathbf{x}) + \sigma_d(\mathbf{x}, t, \text{vid}) $$
Total radiance combines static and dynamic components, scaled by the shadow ratio $\rho_d$:
$$ \mathbf{c}(\mathbf{x}, t, \text{vid}, \mathbf{d}) = \frac{(1 - \rho_d)\sigma_s \mathbf{c}_s + \sigma_d \mathbf{c}_d}{\sigma} $$
Semantic features are combined similarly as a weighted sum [S1].

**Rendering**
For a camera ray $\mathbf{r}$ with direction $\mathbf{d}$ at frame $t$ and video $\text{vid}$, the color $\hat{C}$ is accumulated along sampled points $\mathbf{r}(t)$:
$$ \hat{C}(\mathbf{r}, t, \text{vid}) = \int_0^{+\infty} T(t) \sigma(\mathbf{r}(t), t, \text{vid}) \mathbf{c}(\mathbf{r}(t), t, \text{vid}, \mathbf{d}) dt + T(+\infty) \mathbf{c}_e(\mathbf{d}, \text{vid}) $$
where $T(t) = \exp\left(-\int_0^t \sigma(\mathbf{r}(s), t, \text{vid}) ds\right)$ [S1].

**Training Configuration**
*   **Iterations:** 250,000 [S1].
*   **Batch Size:** 4098 rays per batch [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** Initial $5 \times 10^{-3}$, decaying to $5 \times 10^{-4}$ [S1].
*   **Sampling:** Proposal sampling strategy similar to Mip-NeRF 360 [S1].

**Loss Functions**
The total loss is a weighted sum of reconstruction, warping, flow, and factorization losses [S1]:
$$ \mathcal{L} = \mathcal{L}_c + \mathcal{L}_f + \lambda_d \mathcal{L}_d + \mathcal{L}_c^w + \lambda_f \mathcal{L}_f^w + \lambda_{lo} \mathcal{L}_{cyc} + \mathcal{L}_{sm} + \mathcal{L}_{slo} + \lambda_e \mathcal{L}_e + \lambda_d \mathcal{L}_d + \lambda_\rho \mathcal{L}_\rho $$

1.  **Reconstruction Losses:**
    *   Photometric: $\mathcal{L}_c(\mathbf{r}) = \|\mathbf{C}(\mathbf{r}) - \hat{\mathbf{C}}(\mathbf{r})\|^2$ [S1].
    *   Feature: $\mathcal{L}_f(\mathbf{r}) = \|\mathbf{F}(\mathbf{r}) - \hat{\mathbf{F}}(\mathbf{r})\|_1$ [S1].
    *   Depth: $\mathcal{L}_d(\mathbf{r}) = \|D(\mathbf{r}) - \hat{D}(\mathbf{r})\|^2$, where $\hat{D}(\mathbf{r}) = \int_0^{+\infty} T(s)\sigma(\mathbf{r}(s)) ds$ [S1].

2.  **Warping Losses:**
    Samples are advected using predicted flow $\mathbf{s}_{t_0}$ to get warped density $\sigma^w$, color $\mathbf{c}^w$, and features $\Phi^w$. These are rendered to $\hat{\mathbf{C}}^w$ and $\hat{\mathbf{F}}^w$. The loss is downweighted in ambiguous regions using weight $W_{t_0}(\mathbf{r})$ [S1]:
    $$ \mathcal{L}_c^w(\mathbf{r}) = \sum_{t_0 \in [-1,1]} (1 - W_{t_0}(\mathbf{r})) \|\mathbf{C}(\mathbf{r}) - \hat{\mathbf{C}}_{t_0}^w(\mathbf{r})\|^2 $$
    $$ \mathcal{L}_f^w(\mathbf{r}) = \sum_{t_0 \in [-1,1]} (1 - W_{t_0}(\mathbf{r})) \|\mathbf{F}(\mathbf{r}) - \hat{\mathbf{F}}_{t_0}^w(\mathbf{r})\|_1 $$
    [S1].

3.  **Flow Losses:**
    *   Optical Flow: Predict 3D position $\hat{X}_{t_0}(\mathbf{r}) = \int_0^{+\infty} T(t)\sigma(\mathbf{r}(t))(\mathbf{r}(t) + \mathbf{s}_{t_0}(\mathbf{r}(t))) dt$. Render to 2D and minimize distance from observed optical flow $\mathbf{O}$: $\mathcal{L}_o(\mathbf{r}) = \sum_{t_0} \|\mathbf{X}(\mathbf{o}) - \hat{X}_{t_0}(\mathbf{r})\|_1$ [S1].
    *   Cycle Consistency: $\mathcal{L}_{cyc}(\mathbf{r}) = \sum_{t_0 \in [-1,1]} \sum_{\mathbf{x}} w_{t_0}(\mathbf{x}, t) \|\mathbf{s}_{t_0}(\mathbf{x}, t) + \mathbf{s}_t(\mathbf{x} + \mathbf{s}_{t_0}, t - t_0)\|_1$ [S1].
    *   Smoothness: $\mathcal{L}_{sm}$ encourages spatial/temporal smoothness [S1].
    *   Static Prior: $\mathcal{L}_{slo} = \sum_{t_0} \sum_{\mathbf{x}} \|\mathbf{s}_{t_0}(\mathbf{x}, t)\|_1$ [S1].

4.  **Static-Dynamic Factorization Losses:**
    *   Skewed Binary Entropy: $\mathcal{L}_e(\mathbf{r}) = \int_0^{+\infty} H\left(\frac{\sigma_d(\mathbf{r}(t))}{\sigma_s(\mathbf{r}(t)) + \sigma_d(\mathbf{r}(t))}\right) dt$, where $H(x) = -(x \log x + (1-x) \log (1-x))$ and $k=1.75$ [S1].
    *   Max Dynamic Ratio: $\mathcal{L}_d(\mathbf{r}) = \max\left(\frac{\sigma_d}{\sigma_s + \sigma_d}\right)$ along each ray [S1].
    *   Shadow Loss: $\mathcal{L}_\rho(\mathbf{r}) = \int_0^{+\infty} \rho_d(\mathbf{r}(t))^2 dt$ [S1].

## Operating characteristics
*   **Scalability:** SUDS scales to tens of thousands of objects across 1.2 million frames from 1700 videos spanning hundreds of kilometers [S1].
*   **Training Speed:** SUDS is 10x quicker to train than state-of-the-art methods that rely on ground truth 3D bounding box annotations [S1].
*   **Memory:** Unlike object-centric methods like NSG which require over 1TB of memory for a 30-second video, SUDS uses multi-resolution hash tables to manage memory efficiently [S1].
*   **Strengths:** Handles ego-motion and multi-video representations; disentangles dynamic objects from static background; models shadow effects; uses unlabeled inputs for supervision [S1].
*   **Limitations:** Requires sparse LiDAR and optical flow for optimal performance (though these are "free" supervision sources); relies on self-supervised DINO descriptors which may be sparse [S1].

## Background
SUDS (Scalable Urban Dynamic Scenes) was introduced in 2023 as a method for learning a global representation of urban scenes [S1]. It builds on the multi-resolution hash table approach of Instant-NGP [S1] and addresses the limitations of prior dynamic scene representations that required supervised inputs like panoptic segmentation labels or bounding boxes [S1]. It is designed to facilitate free-viewpoint rendering, semantic decomposition, and 3D scene flow at arbitrary poses and time steps using multiple video inputs [S1].
