# MLP Network Architecture


## Overview
This family defines the Multi-Layer Perceptron (MLP) architectures used to map encoded spatial coordinates and viewing directions to volume density and RGB color in differentiable volume rendering [G]. It solves the problem of representing continuous radiance fields as differentiable functions, distinguishing itself from sibling methods like [Voxel and Grid Representations](18218-voxel-and-grid-representations.md) or [Triplane and Planar Representations](18410-triplane-and-planar-representations.md) by relying exclusively on fully-connected layers to process high-dimensional positional encodings rather than convolutional or sparse grid structures [G].

## Shared principles
The core mechanism involves transforming low-dimensional input coordinates into a high-dimensional feature space using specific positional or eigenfunction encodings, which are then processed by a fully-connected MLP to predict radiance field properties [S1, S3, S4]. The architecture typically consists of two branches: a density branch that processes encoded position features to predict volume density $\sigma$, and a color branch that processes encoded direction features concatenated with intermediate features from the density branch to predict RGB color $\mathbf{c}$ [S1, S4]. Input coordinates $\mathbf{x}$ (position) and $\mathbf{d}$ (view direction) are mapped to higher dimensions using hierarchical sinusoidal positional encoding $\gamma(\cdot)$ or eigenfunction embeddings $\gamma_{Intr}(\cdot)$ [S1, S4].

## Subtopics

### [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md)
Uses Integrated Positional Encoding (IPE) to handle aliasing by lifting mean and covariance of Gaussian query distributions through a basis transformation before encoding. Supports advanced appearance modeling (specular tinting, roughness) while maintaining the two-branch structure. Choose when anti-aliasing and complex material properties are required.

### [Mip-NeRF Network Architecture](18138-mip-nerf-network-architecture.md)
A smaller, more efficient network structure compared to the original NeRF baseline, optimized for integration with depth-assisted training. It uses reduced hidden layer dimensions and specific output layer configurations. Choose when computational efficiency and noisy depth measurements are priorities.

### Intrinsic Neural Fields Network Architecture
A neural network architecture for learning functions on a 2-manifold, using an eigenfunction embedding for intrinsic coordinates and sine/cosine positional encoding for view directions [S1]. It concatenates the eigenfunction embedding $\gamma_{Intr}(p)$ and the positional encoding $\gamma_{FF}(d)$ [S1]. Used in all experiments except those in Section 5.4 [S1].

### Nerflets Model Architecture
Coarse-to-fine sampling is performed as in NeRF, but both coarse and fine samples are drawn from a single MLP rather than two distinct networks [S2]. Each nerflet uses an MLP with 4 hidden layers and 32 hidden dimensions per layer, with the shortcut connection from the original NeRF architecture removed [S2]. The background neural field uses NeRF++ style encoding, with an MLP having 6 hidden layers and 128 hidden dimensions [S2].

### NeRF Network Architecture
A fully-connected ResNet architecture used to predict volume density and color from spatial coordinates and encoded features [S3]. It aggregates features across source views after block 3 using an average-pooling operation to enable an arbitrary number of views as input [S3]. The architecture consists of 5 ResNet blocks with width 512, where each linear layer is followed by a ReLU activation [S3].

### HelixSurf Network Architecture
HelixSurf uses two MLPs to encode the implicit signed distance field (SDF-MLP) and implicit radiance field (RF-MLP), respectively [S4]. The SDF-MLP uses Softplus activation defined as $\text{Softplus}(x) = \beta_1 \times \log(1 + \exp(\beta \times x))$, where $\beta = 100$ [S4]. Positional encoding $\gamma(x)$ is applied to input spatial position $x$ with frequencies $L=6$, and spherical encoding $Sh(\cdot)$ is applied to input view direction $v$ with degrees set to 4 [S4]. The network takes position $x$ and view direction $v$ as inputs, outputs SDF and color $c$, and computes surface normal $n = \nabla f(x)$ [S4].

### MLP Architecture for Context & Quantization
Neural network architecture for quantization and context modeling in HAC++, combining specific MLPs and varying input channels [S5]. MLPq and MLPc are combined into a single 3-layer MLP with ReLU activation [S5]. MLPa consists of multiple MLPs with varying input channels to accommodate different numbers of input chunks across different intra steps, with a lightweight version employed for Synthetic-NeRF [S5].

## Background
The standard MLP architecture for radiance fields was introduced in the original NeRF paper (Mildenhall et al., 2020), establishing the two-branch density/color structure with sinusoidal positional encoding [G]. The Mip-NeRF architecture (Barron et al., 2021/2022) extended this by introducing Integrated Positional Encoding to address frequency limitations [G]. The Intrinsic Neural Fields architecture (Koestler et al., 2022) adapted the MLP for 2-manifolds using eigenfunction embeddings [S1]. The pixelNeRF architecture (Liu et al., 2021) modified the MLP into a ResNet to handle multi-view inputs [S3]. HelixSurf (2023) applies dual MLPs with Softplus activations for robust indoor scene learning [S4]. HAC++ (2025) utilizes combined 3-layer MLPs for efficient 3D Gaussian Splatting compression [S5].
