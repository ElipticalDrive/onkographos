# Model Architecture Modifications

Also called: NeRF Architecture Variants, Radiance Field Network Modifications

## Overview
Model Architecture Modifications extend the standard Neural Radiance Field (NeRF) framework by altering the input conditioning, output heads, or underlying implicit representation to address specific limitations such as dynamic scenes, sparse inputs, or the need for semantic understanding. Unlike standard NeRF, which maps 3D coordinates and viewing directions to density and color via a static Multi-Layer Perceptron (MLP), these methods introduce learnable parameters, auxiliary networks, or discrete structures to encode additional information. They set themselves apart from optimization-only modifications (like [Regularization Techniques](11314-regularization-techniques.md)) by changing the network's topology or data flow, enabling capabilities such as depth-of-field simulation, real-time rendering, or physics-based deformation.

## Shared principles
The standard NeRF architecture [S6] consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$.

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation.
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs).

## Subtopics

### [DoF-NeRF](9432-dof-nerf.md)
DoF-NeRF extends the standard NeRF to simulate depth-of-field effects by introducing learnable aperture $K$ and focus distance $F$ parameters per view. It differs from siblings like [NeRF-VPT](11770-nerf-vpt.md) by explicitly modeling optical blur via the Circle of Confusion (CoC) diameter $\delta(h_t) = K \times |1/F - 1/h_t|$ rather than refining image quality through iterative prompts. Choose it when synthesizing all-in-focus views from shallow DoF inputs.

### [NeRF-VPT](11770-nerf-vpt.md)
NeRF-VPT uses a cascading view prompt tuning paradigm where RGB images from previous rendering stages serve as visual prompts for subsequent networks. It differs from [MixRT](12401-mixrt.md) by relying on internal network outputs rather than hardware-accelerated rasterization, making it a plug-and-play refinement method for sparse-view settings.

### [MixRT](12401-mixrt.md)
MixRT is a hybrid representation combining a low-quality triangle mesh, a view-dependent displacement map, and a compressed NeRF (Instant-NGP format) to enable real-time rendering on edge devices. It differs from [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md) by offloading ray intersection to rasterizers and surface refinement to texture mapping units, achieving >30 FPS at 720p.

### [Activation Feature Density Approximation](12492-activation-feature-density-approximation.md)
This method estimates volumetric density $\hat{d}$ directly from intermediate activation features $\mathbf{f}_\ell$ of the coarse MLP, replacing expensive coarse network evaluations. It differs from [SDF-based Neural Fields](12947-sdf-based-neural-fields.md) by retaining the standard density-based rendering formulation while optimizing the density prediction step itself.

### [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md)
SDF Representations replace volumetric density with a continuous scalar field $s(\mathbf{x})$ representing distance to the nearest surface, defining geometry via a zero-level set. This approach addresses geometric inaccuracy and surface holes typical of density-based NeRFs by enabling sharper surface reconstruction.

### [Volume-Augmented NeRF](12973-volume-augmented-nerf.md)
Volume-Augmented NeRF binds an explicit fluid volume value $v_i$ to each sample point, allowing density and color to be learned based on spatial distribution from a differentiable fluid simulator. It serves as the rendering component in a joint differentiable framework for dynamic fluid scenes.

### [Neural-PIL Decomposition Architecture](12975-neural-pil-decomposition-architecture.md)
This architecture separates scene geometry, material properties, and illumination into distinct networks, predicting density, a BRDF embedding, and an illumination embedding. It is chosen when input images are captured under varying illumination and explicit reflectance decomposition is required.

### [Feature Fields](12995-feature-fields.md)
Feature Fields generalize NeRF by predicting arbitrary per-point feature signals $\mathbf{f}$ in addition to color and density, enabling 3D-aware semantic understanding. Unlike siblings that modify input space or use separate networks, this family integrates signals directly into the volume rendering pipeline.

### [SAID-NeRF](13619-said-nerf.md)
SAID-NeRF exploits instance masks from Visual Foundation Models to enhance surface estimation of transparent objects by decomposing appearance into diffuse and specular components. It builds on [Instant-NGP](13738-voxel-and-sparse-grid-representations.md) and [Semantic and Feature Branches](12095-semantic-and-feature-branches.md) for joint geometry and semantic optimization.

### [MINE](13661-mine.md)
MINE models the frustum of the source camera using a continuous depth Multiplane Image (MPI) representation, conditioned on input images via a fully-convolutional decoder. It differs from pixelNeRF and GRF by reconstructing the frustum per plane, allowing rendering of any target view via homography warping after a single encoder pass.

### [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md)
These representations replace the continuous MLP with discrete structures (voxel grids, hash tables, or triplanes) to store volume density and appearance features. This substitution enables real-time differentiable volume rendering by computing color and density directly via interpolation, significantly reducing latency.

### [Aleth-NeRF](13764-aleth-nerf.md)
Aleth-NeRF trains on under- and over-exposed images to render normal-light novel views by introducing 'Concealing Field' assumptions where air particles attenuate emission. It differs from RAW-NeRF by operating on standard 8-bit LDR images without pre-processing or post-processing enhancement networks.

### [Unified Volumetric Avatar (UVA)](13784-unified-volumetric-avatar-uva.md)
UVA represents dynamic human avatars by anchoring structured latent codes to a deformable mesh in canonical space, enabling local and independent editing of geometry and texture. Unlike two-stage distilling methods, UVA is end-to-end trainable and jointly optimized with the skinning field.

### [Gear-NeRF](13848-gear-nerf.md)
Gear-NeRF leverages semantic information to stratify dynamic scenes into motion-based 'gears', allowing region-specific spatio-temporal sampling resolution. It solves the inefficiency of uniform 4D sampling by assigning higher resolution to regions with larger motion scales.

### [Transformer and Vision Model Integration](13911-transformer-and-vision-model-integration.md)
This family integrates Vision Transformers (ViT) into NeRFs to leverage global semantic understanding and long-range dependencies. It solves the limitations of standard MLP-based NeRFs, which lack explicit global scene modeling and struggle with single-image inputs or occlusions.

### [Human and Specific Subject Modeling](13997-human-and-specific-subject-modeling.md)
Not given in the sources.

### [OPONeRF](14014-oponerf.md)
OPONeRF personalizes the parameters of the plenoptic mapping function for each sampled 3D point by dynamically conditioning network weights $\Theta$ on the point's representation $\mathbf{x}$ and the overall scene representation $\mathbf{F}$. This provides more expressiveness and flexibility than methods that model static appearance as stochastic variables.

### [Mixer-NeRF](14073-mixer-nerf.md)
Mixer-NeRF addresses the loss of local information in standard NeRFs by introducing a hybrid spatial feature learning module (MLCA) and a squeeze-and-excitation (SE) network module. It sets itself apart by explicitly mixing spatial and channel features via fully connected layers before the main MLP inference.

### [SCALAR-NeRF](14267-scalar-nerf.md)
SCALAR-NeRF is a coarse-to-fine framework for scalable large-scale neural scene reconstruction that decomposes expansive scenes into manageable spatial blocks. It fuses local outputs using a reference image rendered from the coarse global model, effectively discarding poorly rendered results compared to Block-NeRF's IDW blending.

### [Sparse View and Few-Shot Optimization](14428-sparse-view-and-few-shot-optimization.md)
This family addresses severe overfitting and artifact generation when training NeRF with drastically reduced input viewpoints ($|S| < 20$). Unlike standard NeRF methods, these techniques mitigate ambiguity through in-situ regularization, deformable sampling strategies, or pseudo-observation densification.

### [Mixture-of-Experts and Modular Architectures](14429-mixture-of-experts-and-modular-architectures.md)
This family replaces or augments the single continuous function of standard NeRF with multiple specialized networks (experts) or parallel processing streams. It solves the limitations of conventional Implicit Neural Representations (INRs) by explicitly partitioning the input domain or ray batch among distinct neural modules.

### [Uncertainty and Reliability](14487-uncertainty-and-reliability.md)
Uncertainty and Reliability methods extend standard NeRF architectures to quantify prediction confidence, addressing artifacts and geometry collapse in sparse data. Unlike deterministic NeRF variants, these methods model the scene as a probabilistic entity, providing pixel-level reliability metrics.

### [Object Decomposition and Composition](14518-object-decomposition-and-composition.md)
Object Decomposition and Composition methods explicitly separate a scene into distinct semantic or geometric object instances, enabling instance-level editing. This family is distinguished from siblings like [Feature Fields](12995-feature-fields.md) by its primary focus on structural decomposition for editing rather than just appearance or semantic labeling.

### [Lighting and Appearance Models](14522-lighting-and-appearance-models.md)
Lighting and Appearance Models modify the standard NeRF color prediction head to decouple scene geometry from illumination variations. They solve the problem of rendering failure in real-world image collections where lighting changes cause significant per-image appearance differences.

### [Optimization and Training Procedures](14565-optimization-and-training-procedures.md)
This family covers algorithmic procedures for optimizing NeRFs, ranging from standard training loops to specialized acceleration techniques. Unlike standard gradient descent, methods in this family often employ structural modifications to the optimization scope, such as skipping expensive fine-pass evaluations for empty rays.

### [Image Enhancement and Restoration Methods](14566-image-enhancement-and-restoration-methods.md)
Image Enhancement and Restoration Methods address input imagery degradation (blur, transient occlusions, low resolution) by integrating restoration mechanisms directly into the NeRF optimization loop. They differ from sibling methods by focusing on specific degradation types, often using 2D priors to guide 3D consistency.

### [Modular, Hierarchical, and Latent Architectures](14567-modular-hierarchical-and-latent-architectures.md)
This family extends standard NeRF architectures to handle non-rigid deformation with topological changes and hierarchical scene structures. [HyperNeRF](13906-hypernerf.md) models non-rigidly deforming scenes by lifting canonical space into a higher-dimensional ambient space, while [Strata-NeRF](14015-strata-nerf.md) models stratified scenes using discrete latent codes.

### [Generalizable Implicit Reconstruction with SRDF](14760-generalizable-implicit-reconstruction-with-srdf.md)
VolRecon is a generalizable implicit reconstruction method that combines local projection features with global shape priors from a coarse feature volume. It differs from siblings by utilizing a Signed Ray Distance Function (SRDF) and a ray transformer to aggregate features along the viewing ray, addressing over-smoothing issues.

### [MuRF (Multi-Baseline Radiance Fields)](15007-murf-multi-baseline-radiance-fields.md)
MuRF is a feed-forward method for sparse view synthesis that constructs a **target view frustum volume** aligned with the target camera rather than a reference input view. It uses a **3D context-aware convolutional decoder** to aggregate multi-view information even when overlap between input and target views is small.

### [Gaussian and Primitive-Based Representations](15011-gaussian-and-primitive-based-representations.md)
This family replaces the continuous MLP radiance field with discrete geometric primitives or explicit Gaussian distributions. It differs from [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md) by using analytic primitives rather than voxel grids, and from [SDF Representations](12495-signed-distance-function-sdf-representations.md) by relying on alpha-blended primitives.

### [Decentralized Federated NeRF](15032-decentralized-federated-nerf.md)
DecentNeRF learns global 3D scene representations from crowd-sourced images by distributing training computation to users and aggregating only global radiance field models. It solves the problem of achieving photorealistic 3D reconstruction while preventing server reconstruction of transient personal content, using Secure Multi-Party Computation (SMPC).

### [Tile and Slide Framework](15219-tile-and-slide-framework.md)
The Tile and Slide Framework (Snake-NeRF) scales NeRFs to large-scale Earth observation scenes by dividing the region into non-overlapping 3D tiles, each trained with its own NeRF. It enforces a strict single-device memory budget through a 2x2 sliding window progression, ensuring linear time complexity.

### [Neural Proxy](15220-neural-proxy.md)
Neural Proxy represents photo-realistic targets as animatable proxies by injecting an animatable mesh proxy into the scene. Unlike NeRF, which ties content to continuous Cartesian coordinates, Neural Proxy allows particles to move with the animated proxy geometry, enabling unseen animation synthesis.

### [ViSNeRF](15255-visnerf.md)
ViSNeRF is a hybrid neural radiance field method for efficient synthesis of visualizations from dynamic volumetric scenes with arbitrary adjustable parameters. It solves scalability by combining explicit feature grids with implicit MLP decoders and applying generalized tensor factorization, reducing memory complexity from $O(N^3 M^K)$ to $O(N^2 M)$.

#### NeRF-VAE
- **Definition:** A generative NeRF model that generalizes to out-of-distribution scenes and removes the need to train on each scene from scratch [S1].
- **Step:** The NeRF renderer is conditioned on a latent code trained using Iterative Amortized Inference and a ResNet encoder. An attention-based scene function is introduced instead of the typical MLP [S1].
- **Comparison:** Outperforms baseline NeRF with a low number of scene views (5-20), but is outperformed by baseline NeRF when a large number of views are available (100+) due to lower scene expressivity [S1].

#### PIE-NeRF
- **Definition:** A pipeline integrating physics-based elastodynamic simulation with a neural radiance field representation, using a meshless discretisation based on quadratic generalized moving least squares on top of the density field of a NeRF [S1].
- **Step:** Enables large deformations and nonlinear hyperelastic material simulation directly on the implicit representation and supports interactive manipulation of real-world captured scenes with complex geometries [S1].

#### DäRF Implementation Details
- **Parameter:** NeRF Backbone: K-planes [36]. MDE Model: DPT-hybrid [38]. Optimizer: Adam [21]. NeRF Learning Rate: 1e-2. MDE Learning Rate: 1e-5. LR Schedule: Cosine warmup [S2, unofficial].

#### NeRF Model Architecture
- **Definition:** The neural network architecture for NeRF, consisting of dense layers with ReLU activations, potentially using view directions as input [S3, unofficial].
- **Parameter:** `D`: The depth of the network (number of hidden layers). Default is 8. `input_ch_views`: The number of input channels for view directions. Default is 3. `output_ch`: The number of output channels. Default is 4 (RGB + density). `use_viewdirs`: Boolean flag to determine if view directions are used as input to the network [S3, unofficial].

#### S3-NeRF
- **Definition:** A method using shadow and shading cues to infer scene geometry and enable single-image NeRF training [S1].
- **Step:** Employ a UNISURF-based occupancy field 3D representation instead of density. Use a modified physics-based rendering equation. Use occupancy-based shadow calculation [S1].

#### KiloNeRF-style Grid Distillation
- **Definition:** Distills a large teacher NeRF into a spatially partitioned grid of tiny MLPs to enable fast, adaptive evaluation by mapping 3D positions to local student networks [S4, unofficial].
- **Step:** Initialize a dictionary mapping 3D grid cell indices (i,j,k) to TinyMLP instances. For each training iteration, sample a random ray and generate num_samples stratified samples along it. Compute the grid cell index for each sample by normalizing its position within the bounding box and scaling by grid resolution. Accumulate L2 loss between student and teacher outputs across all samples. Update all grid MLPs using the accumulated loss and the configured learning rate [S4, unofficial].
- **Parameter:** grid_resolution: 3D tuple defining the number of cells per axis, e.g., (16,16,16). num_distill_iterations: Number of distillation optimization steps, e.g., 1000. num_samples: Number of stratified samples per ray, e.g., 384. learning_rate: Optimization step size for grid MLP updates, e.g., 1e-3. bmin, bmax: Axis-aligned bounding box defining the scene bounds, e.g., [0,0,0] and [1,1,1] [S4, unofficial].

#### NeRF with Time Parameter
- **Step:** Add a time parameter to the model inputs to adapt NeRF for dynamic scenes. Positionally encode the time parameter and concatenate it with the positional encoding of spatial coordinates $\gamma_x(\mathbf{x})$ [S5].
- **Parameter:** Train using the configuration reported for NeRF's real forward-facing experiments [S5].
- **Comparison:** Adding a time parameter improves quality over vanilla NeRF but still lacks detail, suffers from blurry predictions, and fails to reason about scene dynamics [S5].

#### NeRF-Editing
- **Definition:** The first mesh-based shape deformation method, leveraging explicit representations for scene geometry edits and implicit representations for realistic rendering effects [S6].
- **Step:** 1. Extract explicit triangular mesh from NeRF. 2. Enable intuitive user-driven deformations through classic ARAP deformation method. 3. Generate tetrahedral mesh around triangular mesh to propagate deformations spatially. 4. Employ tetrahedral vertex interpolation to transform discrete deformations into continuous field. 5. Ensure rays passing through mesh bend according to user adjustments [S6].

#### NeuralEditor
- **Definition:** A method employing a point cloud-guided NeRF model for shape manipulation, leveraging K-D trees and deterministic integration strategy for accurate point cloud-based rendering, with Phong reflection modeling to enhance color fidelity and geometric detail [S6].
- **Step:** 1. Employ point cloud-guided NeRF model. 2. Leverage K-D trees. 3. Use deterministic integration strategy. 4. Achieve accurate point cloud-based rendering. 5. Apply Phong reflection modeling [S6].

#### Shared G-MLP
- **Definition:** A shared geometry MLP that enables the constraint of multi-view consistency to be propagated from the NeRF branch to the detection branch [S7].
- **Number:** Without the shared G-MLP, performance drops from 50.1 to 48.1 mAP@.25, as the influence of multi-view consistency is only propagated into the image backbone [S7].

## Background
The standard NeRF architecture was introduced by Mildenhall et al. [1] in 2020, utilizing hierarchical rendering with coarse and fine networks to improve computational efficiency. Subsequent works have focused on accelerating training and inference, with most efforts falling into architectural modifications such as input expansion, output expansion, or representation substitution. The original implementation used dense layers with ReLU activations, with default parameters including a network depth of 8 layers and 256 channels per layer [S3, unofficial].
