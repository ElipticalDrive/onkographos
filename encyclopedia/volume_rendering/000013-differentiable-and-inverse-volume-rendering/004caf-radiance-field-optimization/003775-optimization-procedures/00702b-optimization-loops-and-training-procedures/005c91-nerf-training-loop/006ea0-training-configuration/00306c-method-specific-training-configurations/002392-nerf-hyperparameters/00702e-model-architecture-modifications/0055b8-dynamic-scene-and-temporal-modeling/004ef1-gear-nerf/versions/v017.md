# Gear-NeRF

Also called: Gear-NeRF: Free-Viewpoint Rendering and Tracking with Motion-aware Spatio-Temporal Sampling

## Overview
Gear-NeRF is a dynamic scene representation method that stratifies a 4D volumetric scene into multiple "gear" levels based on semantic motion scales, allowing for region-specific spatio-temporal sampling resolution [S1]. Unlike unified 4D representations, it uses a series of 4D feature volumes where higher-motion regions are assigned higher gear levels and sampled more densely, improving dynamic novel view synthesis while enabling free-viewpoint object tracking [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $W$ input videos $\mathcal{V} = \{V_1, V_2, \dots, V_W\}$ of a dynamic scene with calibrated camera poses [S1].
*   **Output:** A radiance field representation capable of rendering novel views at arbitrary times $t$ and tracking objects via semantic prompts [S1].

**Data Structures:**
The representation consists of a series of 4D feature volumes, one for each gear level $G \in \{1, \dots, N_{\text{gear}}\}$ [S1].
*   **Shared Spatial Features:** Functions $h_j(\cdot, \cdot)$ for $j \in \{1, 2, 3\}$ are shared across all gears. These map 2D coordinate tuples to features using bilinear interpolation on regularly spaced 2D feature grids [S1].
*   **Gear-Specific Temporal Features:** Each gear $G$ has its own set of spatio-temporal embedding functions $k^G_j(\cdot, \cdot)$ for $j \in \{1, 2, 3\}$. These map 2D coordinate tuples to features of dimension $M$ using bilinear interpolation on regularly spaced 2D feature grids [S1].
*   **Linear Transforms:** Shared linear transforms $B_j(\cdot)$ map the element-wise products to feature vectors [S1].
*   **Semantic Embedding:** A separate planar-factorized 4D feature volume computes the gear level assignment $g(\mathbf{x}, t)$ for any coordinate [S1]. The source provides the start of this formula: $g(\mathbf{x}, t) = \mathbf{1}^\top (h'_1(x, y) \odot k'_1(z, t) + \dots)$ but does not provide the complete closed-form expression or the specific dimensions of $h'$ and $k'$ [S1].

**Parameters:**
*   $N_{\text{gear}}$: The total number of gear levels used to stratify the scene representation [S1].
*   $M$: The dimensionality of the feature vectors produced by the embedding functions [S1].
*   Typical values: Not given in the sources.

**Algorithm Steps:**
1.  **Semantic Embedding Optimization:** Optimize a 4D semantic embedding based on powerful image segmentation models (specifically SAM) to profile the scene into semantic regions [S1]. This embedding is used to determine motion scales.
2.  **Gear Assignment:** For any space-time coordinate $(\mathbf{x}, t)$, compute the gear level $G$ using the semantic embedding. Regions with larger motion scales are assigned higher gear levels through a gear determination scheme [S1].
3.  **Feature Vector Computation:** For a specific gear level $G$ and coordinate $(\mathbf{x}, t)$, compute the feature vector $\mathbf{f}^G(\mathbf{x}, t)$ using the following formula:
    $$
    \mathbf{f}^G(\mathbf{x}, t) = B_1 (h_1(x, y) \bowtie k^G_1(z, t)) + B_2 (h_2(x, z) \bowtie k^G_2(y, t)) + B_3 (h_3(y, z) \bowtie k^G_3(x, t))
    $$
    where:
    *   $\mathbf{x} = (x, y, z)$ is the spatial position.
    *   $t$ is the time parameter.
    *   $h_j(\cdot, \cdot)$ are functions evaluated by bilinear interpolation on regularly spaced 2D feature grids embedding coordinate tuples to features.
    *   $k^G_j(\cdot, \cdot)$ are functions evaluated by bilinear interpolation on regularly spaced 2D feature grids embedding coordinate tuples to features of dimension $M$.
    *   $\bowtie$ denotes element-wise product.
    *   $B_j$ denotes a linear transform mapping products to feature vectors [S1].
4.  **Radiance Field Output:** Pass the feature vector $\mathbf{f}^G(\mathbf{x}, t)$ through a tiny MLP to map it to volume density $\sigma$ and view-dependent emitted color $\mathbf{c}$, given the viewing direction $\mathbf{d}$ [S1].
5.  **Spatio-Temporal Sampling:** Perform spatio-temporal sampling along rays. Regions assigned to higher gear levels (larger motion scales) are sampled at higher resolution [S1].

**Pseudocode:**
```python
def compute_feature_vector(x, y, z, t, gear_level, shared_h, shared_B, gear_k, M):
    """
    Computes the feature vector f^G(x, t) for a specific gear G.
    
    Args:
        x, y, z: Spatial coordinates (floats)
        t: Time coordinate (float)
        gear_level: Integer gear level G
        shared_h: Dictionary of shared spatial feature grids h1, h2, h3
        shared_B: List of linear transforms B1, B2, B3
        gear_k: Dictionary of gear-specific temporal feature grids k^G_1, k^G_2, k^G_3
        M: Dimension of feature vectors
        
    Returns:
        Feature vector f^G(x, t) of dimension M
    """
    # Extract shared spatial features via bilinear interpolation
    # h1(x, y) -> feature vector
    h1_xy = bilinear_interpolate(shared_h['h1'], x, y)
    # h2(x, z) -> feature vector
    h2_xz = bilinear_interpolate(shared_h['h2'], x, z)
    # h3(y, z) -> feature vector
    h3_yz = bilinear_interpolate(shared_h['h3'], y, z)
    
    # Extract gear-specific spatio-temporal features via bilinear interpolation
    # k^G_1(z, t) -> feature vector of dimension M
    k1_zt = bilinear_interpolate(gear_k['k1'][gear_level], z, t)
    # k^G_2(y, t) -> feature vector of dimension M
    k2_yt = bilinear_interpolate(gear_k['k2'][gear_level], y, t)
    # k^G_3(x, t) -> feature vector of dimension M
    k3_xt = bilinear_interpolate(gear_k['k3'][gear_level], x, t)
    
    # Element-wise products
    prod1 = h1_xy * k1_zt
    prod2 = h2_xz * k2_yt
    prod3 = h3_yz * k3_xt
    
    # Linear transforms and summation
    f = shared_B[0](prod1) + shared_B[1](prod2) + shared_B[2](prod3)
    
    return f

def get_gear_level(x, t, semantic_embedding):
    """
    Determines the gear level for a space-time coordinate.
    Note: The exact formula for g(x,t) is incomplete in sources.
    This function represents the gear determination scheme based on motion scales.
    """
    # Compute semantic embedding-based metric for motion scale
    # g(x, t) = 1^T (h'_1(x, y) o k'_1(z, t) + ...) [S1]
    # Assign higher gear level to larger motion scales
    motion_scale = compute_motion_scale_from_semantic_embedding(x, t, semantic_embedding)
    gear_level = map_motion_scale_to_gear(motion_scale, N_gear)
    return gear_level

def render_ray(ray_origin, ray_direction, t, scene_params):
    """
    Renders a single pixel for a given ray and time.
    """
    # Sample points along the ray
    points = sample_points_along_ray(ray_origin, ray_direction)
    
    densities = []
    colors = []
    
    for point in points:
        x, y, z = point
        # Determine gear level for this point
        gear_level = get_gear_level(x, t, scene_params['semantic_embedding'])
        
        # Compute feature vector for the specific gear
        f = compute_feature_vector(x, y, z, t, gear_level, 
                                   scene_params['shared_h'], 
                                   scene_params['shared_B'], 
                                   scene_params['gear_k'], 
                                   scene_params['M'])
        
        # Map feature vector to density and color via tiny MLP
        sigma, color = scene_params['mlp'](f, ray_direction)
        
        densities.append(sigma)
        colors.append(color)
        
    # Standard volume rendering integration
    alpha = 1 - exp(-densities * delta_t)
    weights = alpha * cumprod(1 - alpha[:-1])
    final_color = sum(weights * colors)
    
    return final_color
```

**Edge Cases and Pitfalls:**
*   **Precision:** Bilinear interpolation on 2D grids requires careful handling of coordinate normalization to grid boundaries [S1].
*   **Degenerate Input:** The method relies on calibrated camera poses; uncalibrated inputs are not supported [S1].
*   **Semantic Embedding:** The quality of gear assignment depends on the underlying segmentation model (SAM); errors in segmentation may lead to incorrect motion scale estimation [S1].

## Subtopics

### NeRF with Time Parameter
Adds a time parameter to the standard NeRF architecture. Gear-NeRF extends this by stratifying the representation based on motion scales rather than using a single unified time-aware volume [S1, 14705-nerf-with-time-parameter.md].

### Forward Warping for Novel View Synthesis
Uses forward warping to handle dynamic scenes. Gear-NeRF uses spatio-temporal sampling stratification instead [S1, 15541-forward-warping-for-novel-view-synthesis.md].

### Dynamic Appearance Particle Neural Radiance Field
Represents dynamic scenes using particles. Gear-NeRF uses 4D feature volumes stratified by gears [S1, 15550-dynamic-appearance-particle-neural-radiance-field.md].

### KFD-NeRF
Uses keyframe-based deformation fields. Gear-NeRF uses semantic embedding for motion-aware sampling [S1, 15551-kfd-nerf.md].

### SLS4D
Uses sparse latent space for 4D scenes. Gear-NeRF uses dense 4D feature volumes stratified by gears [S1, 16576-sls4d.md].

### ST-NeRF
Uses spatial-temporal encoding. Gear-NeRF adds the gear stratification mechanism on top of spatio-temporal encoding [S1, 18515-st-nerf.md].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Achieves state-of-the-art rendering and tracking performance on multiple challenging datasets [S1].
*   **Scaling:** Higher gear levels allow for higher-resolution sampling in dynamic regions, potentially increasing computational cost in those areas but reducing it in static regions compared to uniform high-resolution sampling [S1].
*   **Strengths:** Enhanced dynamic novel view synthesis via smarter spatio-temporal sampling; enables free-viewpoint tracking of objects of interest almost for free [S1].
*   **Limitations:** Relies on powerful image segmentation models (SAM) for semantic embedding; requires calibrated camera poses [S1].
*   **When to use:** When rendering dynamic scenes with varying motion scales and when free-viewpoint tracking is desired [S1].
*   **When not to use:** When computational resources are extremely limited and uniform resolution is acceptable; when camera poses are not calibrated [S1].

## Background
Gear-NeRF was introduced in 2024 by the authors of "Gear-NeRF: Free-Viewpoint Rendering and Tracking with Motion-aware Spatio-Temporal Sampling" [S1]. It addresses the issue that dynamic regions require more resources per unit volume than static regions due to their time-evolving nature [S1]. The method leverages semantic information from image segmentation models to stratify the scene into motion-based 'gears', allowing for region-specific spatio-temporal sampling resolution [S1].
