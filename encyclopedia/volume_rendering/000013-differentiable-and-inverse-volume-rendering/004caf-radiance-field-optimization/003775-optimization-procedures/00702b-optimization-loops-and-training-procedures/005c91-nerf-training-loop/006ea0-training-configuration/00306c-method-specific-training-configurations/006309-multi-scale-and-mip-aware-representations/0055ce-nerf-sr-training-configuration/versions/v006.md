# NeRF-SR Training Configuration

Also called: NeRF-SR, NeRF Super-Resolution

## Overview
NeRF-SR is a training configuration designed to synthesize high-resolution (HR) novel views from low-resolution (LR) input images by optimizing a neural radiance field with a supersampling strategy [S1]. It differs from standard NeRF training by explicitly leveraging 3D consistency during the rendering process to recover high-frequency details that are lost in LR inputs, rather than relying on post-hoc 2D upsampling [S1]. It builds on [Method-Specific Training Configurations](6267-method-specific-training-configurations.md) by modifying the sampling and optimization loop to support arbitrary resolution rendering while maintaining photometric accuracy against ground truth [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ LR images with known camera poses and intrinsics. The method is resolution-agnostic during training but targets specific HR output resolutions during inference.
*   **Outputs:** A trained MLP representing the radiance field $(\sigma, \mathbf{c})$ and, optionally, a refined HR image via a post-processing refinement network.

**Data Structures:**
*   **Radiance Field MLP:** Standard NeRF MLP structure mapping 3D coordinates and viewing directions to density $\sigma$ and color $\mathbf{c}$.
*   **Ray Batch:** A batch of $B$ rays sampled from the training views.
*   **Sample Points:** For each ray, $N_c$ coarse samples and $N_f$ fine samples are generated.

**Parameters:**
*   **Optimizer:** Adam with $\beta_1 = 0.9, \beta_2 = 0.999$ [S1].
*   **Batch Size:** $B = 2048$ rays per batch [S1].
*   **Learning Rate:** Exponential decay from $5 \times 10^{-4}$ to $5 \times 10^{-6}$ [S1].
*   **Sampling:** Hierarchical sampling with $N_c = 64$ coarse samples and $N_f = 64$ fine samples [S1].
*   **Epochs:** 20 epochs for Blender dataset; 30 epochs for LLFF dataset [S1].

**Algorithm Steps:**
1.  **Ray Sampling:** For each training image, sample rays through each pixel.
2.  **Hierarchical Sampling:**
    *   Sample $N_c$ points along each ray using a uniform or learned distribution.
    *   Compute coarse density $\sigma_c$ and transmittance $T$.
    *   Use $T$ to weight a histogram for resampling $N_f$ points in regions of high density (fine sampling) [S1].
3.  **Network Forward Pass:**
    *   Query the MLP for density $\sigma_i$ and color $\mathbf{c}_i$ at each sample point $i$.
4.  **Volume Rendering:**
    *   Compute opacity $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ and transmittance $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ [Parent].
    *   Render color $\hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i$ [Parent].
    *   *Note:* In NeRF-SR, the "supersampling" aspect implies that the training targets are LR images, but the ray marching and MLP queries effectively resolve the scene at a higher granularity, allowing the model to learn HR details implicitly [S1].
5.  **Loss Computation:**
    *   Compute photometric loss between rendered color $\hat{C}(\mathbf{r})$ and ground truth LR image color $C_{gt}$.
    *   Metrics used for evaluation: PSNR, SSIM, and LPIPS [S1].
6.  **Optimization:**
    *   Update MLP parameters using Adam optimizer.
    *   Decay learning rate exponentially [S1].

**Pseudocode:**
```python
def train_nerf_sr(model, lr_scheduler, optimizer, train_loader, epochs):
    # Hyperparameters from [S1]
    batch_size = 2048
    num_coarse_samples = 64
    num_fine_samples = 64
    
    for epoch in range(epochs):
        for batch in train_loader:
            rays_o, rays_d, gt_colors = batch
            
            # 1. Hierarchical Sampling
            # Sample coarse points
            t_vals_coarse = sample_t_vals(num_coarse_samples)
            z_vals_coarse = rays_o + t_vals_coarse * rays_d
            
            # Query coarse MLP
            sigma_coarse, rgb_coarse = model.forward(rays_o, rays_d, z_vals_coarse)
            
            # Compute transmittance for fine sampling
            deltas = z_vals_coarse[1:] - z_vals_coarse[:-1]
            alpha_coarse = 1.0 - torch.exp(-sigma_coarse * deltas)
            transmittance = torch.cumprod(1.0 - alpha_coarse + 1e-10, dim=-1)
            
            # Resample for fine points based on transmittance
            z_vals_fine = resample(z_vals_coarse, transmittance, num_fine_samples)
            
            # 2. Fine Pass
            sigma_fine, rgb_fine = model.forward(rays_o, rays_d, z_vals_fine)
            
            # 3. Volume Rendering
            deltas_fine = z_vals_fine[1:] - z_vals_fine[:-1]
            alpha_fine = 1.0 - torch.exp(-sigma_fine * deltas_fine)
            transmittance_fine = torch.cumprod(1.0 - alpha_fine + 1e-10, dim=-1)
            
            weights = alpha_fine * transmittance_fine
            rgb_rendered = torch.sum(weights.unsqueeze(-1) * rgb_fine, dim=-2)
            
            # 4. Loss and Optimization
            loss = mse_loss(rgb_rendered, gt_colors)
            loss.backward()
            optimizer.step()
            optimizer.zero_grad()
            
        lr_scheduler.step()
```

**Edge Cases and Pitfalls:**
*   **Arbitrary Scale Limitation:** NeRF-SR does not support arbitrary-scale super-resolution natively; it is trained for specific scale factors (e.g., $\times 2, \times 4$) [S1].
*   **Real-World Detail Loss:** Supersampling alone may be insufficient for complex real-world scenes (e.g., LLFF dataset) where high-frequency textures are lost, necessitating a refinement network [S1].

## Subtopics

### Refinement Network (Ours-Refine)
A post-processing module that boosts NeRF-SR outputs with texture details and edge sharpness, specifically for real-world datasets like LLFF where supersampling alone yields insufficient photorealism [S1]. It operates during inference by dividing input images into non-overlapping patches, refining them using reference patches, and stitching them back together [S1]. It uses a fixed number of reference patches $K=8$ with dimensions $64 \times 64$ [S1]. The refinement is necessary for larger magnifications (e.g., $\times 4$) where supersampling derives fewer details, though it provides subtle LPIPS improvements even at $\times 2$ [S1].

## Operating characteristics
*   **Time Complexity:** The training time is comparable to training a standard HR NeRF, as it consumes no more time than training a HR NeRF directly [S1]. Inference time for the base NeRF-SR is dominated by the MLP rendering (e.g., ~48 seconds for a $1008 \times 756$ image on a single 1080Ti) [S1].
*   **Memory Complexity:** Standard NeRF memory footprint for MLP weights and ray batches.
*   **Performance:** On the LLFF dataset, NeRF-SR with refinement (Ours-Refine) achieves PSNR 27.34, SSIM 0.842, and LPIPS 0.103 at $\times 2$ scale, and PSNR 25.59, SSIM 0.759, and LPIPS 0.165 at $\times 4$ scale [S1].
*   **Strengths:** Achieves photorealistic HR novel view synthesis from LR inputs without external data, leveraging 3D consistency [S1].
*   **Limitations:** Lacks arbitrary-scale support; introduces extra computation during the refinement stage (e.g., +1.3 seconds for refinement on a $1008 \times 756$ image) [S1].

## Background
NeRF-SR was introduced to address the limitation of standard NeRF in generating high-resolution details from low-resolution training data. It is the first pipeline to achieve HR novel view synthesis with mostly LR inputs without external data [S1]. The method exploits 3D consistency through a supersampling strategy [S1].
