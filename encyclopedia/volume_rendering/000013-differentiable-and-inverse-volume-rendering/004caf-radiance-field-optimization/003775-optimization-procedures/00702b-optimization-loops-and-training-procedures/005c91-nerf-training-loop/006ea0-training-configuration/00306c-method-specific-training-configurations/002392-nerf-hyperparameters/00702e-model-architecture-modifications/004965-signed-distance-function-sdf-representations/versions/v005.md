# Signed Distance Function (SDF) Representations


## Overview
Signed Distance Function (SDF) representations replace the implicit volume density field of standard NeRFs with a continuous scalar field representing the distance to the nearest surface, defining geometry via the zero-level set rather than soft volumetric boundaries [S1]. This approach addresses the geometric inaccuracy and surface holes typical of density-based NeRFs by providing a more explicit and smooth formulation of surfaces, enabling sharper reconstructions and direct mesh extraction [S1]. It sets itself apart from density-based alternatives like [SDF-based Neural Fields](12947-sdf-based-neural-fields.md) and [RS-Recon](15321-rs-recon.md) by explicitly modeling surface boundaries rather than volumetric occupancy.

## Shared principles
The core mechanism involves predicting a continuous scalar field $s: \mathbb{R}^3 \rightarrow \mathbb{R}$ where $s(\mathbf{x})$ represents the signed distance from point $\mathbf{x}$ to the closest surface, with the sign conventionally negative inside the object and positive outside [S1]. The surface geometry is defined as the zero-level set $\{\mathbf{x} \mid s(\mathbf{x}) = 0\}$ [S1].

To enable volumetric rendering, the predicted SDF value $s(\mathbf{x})$ must be converted into a volume density $\sigma(\mathbf{x})$ suitable for integration along rays [S1]. While the specific conversion function varies by implementation, it generally involves a differentiable mapping that concentrates density near the zero-level set [G]. The surface normal $\mathbf{n}$ is derived from the gradient of the SDF:
$$ \mathbf{n} = \frac{\nabla s(\mathbf{x})}{\|\nabla s(\mathbf{x})\|} $$
This normal is computed via finite differences or analytical gradients and used for surface reconstruction and rendering [G].

## Subtopics

### [ProbeSDF](11363-probesdf.md)
ProbeSDF is a neural surface reconstruction method that decouples spatial and angular light field components using two volumetric grids of different resolutions to achieve real-time rendering and accelerated training. It addresses the computational bottleneck of standard SDF-based neural fields by replacing the core appearance MLP with a lightweight model that uses spherical harmonic light field probes for angular variation and planar factorized features for spatial texture. Unlike Plenoxels or 3D Gaussian Splatting which require significantly more parameters per voxel (27 and 48 respectively), ProbeSDF uses as few as four parameters per voxel while maintaining high expressiveness.

### [SDF-based Neural Fields](12947-sdf-based-neural-fields.md)
SDF-based Neural Fields replace the implicit density field of standard NeRFs with a Signed Distance Function (SDF) to provide a more explicit and smooth formulation of surfaces. This approach addresses the geometric inaccuracy and surface holes typical of density-based NeRFs by leveraging the zero-level set of the SDF to define geometry.

### [Generalizable Implicit Reconstruction with SRDF](14760-generalizable-implicit-reconstruction-with-srdf.md)
VolRecon is a generalizable implicit reconstruction method that predicts a Signed Ray Distance Function (SRDF) to reconstruct scenes with fine details and minimal noise from multi-view images. It distinguishes itself from sibling methods like [SDF-based Neural Fields](12947-sdf-based-neural-fields.md) by combining local projection features aggregated via a view transformer with global shape priors from a coarse feature volume, processed by a ray transformer to resolve surface ambiguity. Unlike standard SDF approaches that define distance in any direction, SRDF constrains the distance measurement to the specific ray direction, enabling more robust surface localization along the viewing ray.

### [SDF-based Neural Volume Rendering with PBR](15009-sdf-based-neural-volume-rendering-with-pbr.md)
This method integrates Signed Distance Function (SDF) representations for geometry with Physically Based Rendering (PBR) material models to achieve smoother geometric structures and accurate specular reflections, overcoming the coarse detail and foggy artifacts typical of standard NeRF. Unlike sibling methods such as [ProbeSDF](11363-probesdf.md) or [SDF-based Neural Fields](12947-sdf-based-neural-fields.md) which may focus primarily on geometry or general neural fields, this approach specifically decouples geometry (via SDF) from material appearance (via PBR), providing interpretable parameters for reflection and diffuse components. It builds on [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md) by converting the SDF into a density field for volumetric integration while using the SDF gradient for surface normals required by the PBR model.

### [RS-Recon](15321-rs-recon.md)
RS-Recon is a neural scene reconstruction method that replaces the standard Signed Distance Function (SDF) with a Signed Ray Distance Function (SRDF) to model volume density, specifically addressing noise and inaccuracies in multi-object indoor scenes. Unlike SDF-based methods which consider surface points across the entire scene and may exhibit fluctuations leading to local minimum values, SRDF measures the shortest distance to the surface along a specific camera ray, eliminating the influence of surrounding surfaces not located on that ray.

#### Truncated SDF NeRF
**Definition:** A method that replaces the density MLP with a truncated SDF MLP and computes pixel color as a weighted sum of sampled colors [S1].
**Steps:** Reconstruct the triangular mesh of the scene by using Marching Cubes on the truncated SDF MLP [S1].
**Formulas:** The pixel color is computed as:
$$ C(r) = \frac{\sum_{i=1}^{N} w_i c_i}{\sum_{i=1}^{N} w_i} $$
where $c_i$ is the sampled color and $w_i$ is the weight [S1]. The weight is given by:
$$ w_i = \Phi\left(\frac{D_i}{t_r}\right) \cdot \Phi\left(-\frac{D_i}{t_r}\right) $$
where $D_i$ is the SDF value, $t_r$ is the truncation distance, and $\Phi$ is the sigmoid function [S1]. The truncation distance cuts off any SDF value too far from individual surfaces [S1].
**Parameters:** Per-frame appearance latent code from NeRF-W is used to account for white-balance and exposure changes [S1].
**Pitfalls:** Multiple ray-surface intersections are handled by assigning a weight of zero to subsequent truncation regions so they do not contribute to the pixel color [S1].

## Background
The concept of using SDFs for neural rendering emerged as a solution to the "foggy" and geometrically ambiguous outputs of standard density-based NeRFs [S1]. Azinovic et al. introduced the truncated SDF approach in April 2021, replacing the density MLP with a truncated SDF MLP to enable clean mesh reconstruction via Marching Cubes [S1]. Concurrently, Park et al. introduced Nerfies in November 2020, which used deformation fields for dynamic scenes, laying groundwork for non-rigid SDF applications [S1]. In June 2022, SparseNeuS improved upon NeuS by focusing on sparse-view SDF reconstruction using a hybrid representation of geometry encoding volumes and learnable image features [S1]. These developments shifted the focus from implicit volume density to explicit surface boundaries, allowing for better geometric fidelity and clean reconstruction results via Marching Cubes [S1].
