# EBAD-NeRF

Also called: Event-driven Bundle Adjustment for Deblurring Neural Radiance Fields

## Overview
EBAD-NeRF is a framework that jointly optimizes learnable camera poses during exposure time and NeRF parameters to reconstruct sharp 3D representations from blurry images and event data [S1]. It explicitly models motion blur via an intensity-change-metric event loss and a photo-metric blur loss [S1]. Unlike BAD-NeRF, which uses linear interpolation of start and end poses, EBAD-NeRF uses multiple learnable poses to model complex motion trajectories [S1]. Unlike E2 NeRF, which uses pre-deblurred images and COLMAP for fixed poses, EBAD-NeRF jointly optimizes poses and NeRF parameters [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Blurry RGB images $B$, corresponding event data (intensity changes), and approximate initial camera poses.
*   **Outputs:** Optimized NeRF network parameters $\theta$, optimized camera poses $\{P_i\}$ for each view during exposure, and a sharp 3D radiance field representation.

**Data Structures:**
*   **NeRF MLP ($F_\theta$):** A multi-layer perceptron taking encoded 3D coordinates and view directions, outputting color $c$ and density $\sigma$ [S1].
*   **Learnable Poses:** For each view, a set of $p$ learnable poses $\{P_i\}_{i=1}^p$ representing the camera trajectory during the exposure time $[t_{start}, t_{end}]$ [S1]. These are transferred into SE(3) space [S1].
*   **Ray Sampling:** For each pixel, a ray $r$ is defined by the camera pose and pixel coordinate $x$ [S1]. The ray segment from $l_{near}$ to $l_{far}$ is divided into $N$ equal parts [S1].

**Numbered Steps:**

1.  **Trajectory Modeling:** For each view, model the camera motion trajectory using $p$ learnable camera poses $\{P_i\}_{i=1}^p$ sampled evenly over the exposure time $[t_{start}, t_{end}]$ [S1]. Transfer these poses into SE(3) space [S1].
2.  **Positional Encoding:** For a 3D coordinate $o$ and view direction $d$, apply positional encoding $\gamma_K$ to map inputs to $K+1$ dimensions [S1]:
    $$ \gamma_K(x) = \{\sin(2^k \pi x), \cos(2^k \pi x)\}_{k=0}^K $$
3.  **NeRF Query:** Input the encoded coordinates and directions into the NeRF MLP $F_\theta$ to obtain color $c$ and density $\sigma$ [S1]:
    $$ (c, \sigma) = F_\theta(\gamma_o(o), \gamma_d(d)) $$
4.  **Volume Rendering (Sharp Image):** For each of the $p$ poses, render a sharp virtual image color $C(P(t_i), x)$ using volume rendering [S1]:
    $$ C(r, x) = \sum_{i=1}^N T_i (1 - \exp(-\sigma_i \delta_i)) c_i $$
    where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$, $\delta_i = l_{i+1} - l_i$ is the distance between adjacent sampled points, and $T_i$ is the transparency between $l_{near}$ and the $i$-th sampled point [S1].
5.  **Blur Simulation:** Discretize the image formation integral by averaging the sharp rendered colors from the $p$ poses to simulate the blurry image $\hat{B}(x)$ [S1]:
    $$ \hat{B}(x) = \frac{1}{p} \sum_{i=1}^p C(P(t_i), x) $$
6.  **Loss Computation:**
    *   **Photo-metric Blur Loss:** Compute the difference between the simulated blurry image $\hat{B}$ and the actual blurry input image $B$ [S1].
    *   **Intensity-Change-Metric Event Loss:** Supervise the pose changes during exposure using event data to explicitly connect the camera motion trajectory to the target sharp NeRF [S1].
7.  **Joint Optimization:** Update both the NeRF network parameters $\theta$ and the learnable camera poses $\{P_i\}$ using the combined losses [S1].

**Parameters:**
*   $N$: Number of equal parts the ray segment is divided into for stratified sampling [S1].
*   $p$: Number of learnable poses used to model the motion trajectory during exposure [S1].
*   $K$: Degree of positional encoding [S1].
*   $l_{near}, l_{far}$: Near and far clipping planes of the ray segment [S1].

**Edge Cases and Pitfalls:**
*   **Complex Motion:** Linear interpolation (as in BAD-NeRF) fails to model complex motion blur; EBAD-NeRF addresses this by using multiple learnable poses [S1].
*   **Pose Initialization:** Unlike E2 NeRF, which relies on fixed poses from COLMAP, EBAD-NeRF optimizes poses, requiring careful initialization or robust optimization to avoid local minima [S1].

## Operating characteristics
*   **Time Complexity:** Training time increases due to the joint optimization of NeRF parameters and multiple learnable poses per view, as well as the computation of event loss [S1].
*   **Memory Complexity:** Requires storing $p$ poses per view in addition to standard NeRF parameters [S1].
*   **Strengths:** Can recover accurate camera trajectories and learn sharper 3D representations compared to prior works, especially in low-light or high-speed moving camera scenarios [S1].
*   **Limitations:** Relies on the availability of hybrid event-RGB data [S1].
*   **When to use:** When reconstructing sharp NeRF from blurry images captured with a moving camera, especially when event data is available [S1].
*   **When not to use:** When only static, sharp images are available, or when event data is not accessible [S1].

## Background
EBAD-NeRF was proposed to address the limitations of previous deblurring NeRF methods like Deblur-NeRF, BAD-NeRF, and E2 NeRF [S1]. Deblur-NeRF uses a deformable sparse kernel, BAD-NeRF linearly interpolates poses, and E2 NeRF uses pre-deblurred images and fixed COLMAP poses [S1]. EBAD-NeRF introduces event cameras to measure intensity changes with high temporal resolution, making up for the information deficiency in blurry images [S1]. It was evaluated on synthetic scenes extended with event data and real-captured Event-RGB (ERGB) data using a DAVIS-346 event camera [S1].
