# IE-NeRF

Also called: IE-NeRF Pipeline, Image-dependent NeRF with transient mask inpainting, Inpainting Enhanced NeRF

## Overview
IE-NeRF is a Neural Radiance Field (NeRF) variant designed for novel view synthesis in uncontrolled, "in-the-wild" environments containing transient occlusions (e.g., pedestrians, vehicles) [S1]. It solves the problem of static scene reconstruction in the presence of dynamic elements by separating static scene properties from transient occlusions using a learned 2D transient mask and a pre-trained image inpainting module [S1]. Unlike sibling methods such as [DeblurNeRF](11964-deblurnerf.md) or [Sharp-NeRF](14270-sharp-nerf.md) which focus on blur or sharpness, IE-NeRF specifically addresses transient occlusions. It differs from [NeRF-W](11964-deblurnerf.md) by using a single MLP to predict both static radiance and a 2D transient mask (rather than a 3D transient field) and from [SF-NeRF](11964-deblurnerf.md) by learning the mask end-to-end rather than relying on pre-trained semantic segmentation priors [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of unposed or posed images $\{I_i\}$ with associated camera poses. Each image $I_i$ is downsampled by a factor of 2 [S1].
*   **Outputs:** A continuous volumetric representation of the static scene, parameterized by density $\sigma$ and image-dependent color $\mathbf{c}$, enabling the rendering of novel views free of transient occlusions [S1].

**Data Structures and Layout:**
1.  **CNN Encoder ($E_E$):** Encodes input image $I_i$ into a feature latent vector $\ell_i \in \mathbb{R}^d$ [S1].
2.  **NeRF MLPs:**
    *   **MLP$_{\theta_1}$:** Takes positional encoding $\gamma_x(\mathbf{r}(t))$ of the ray point $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$. Outputs static density $\sigma(t)$ and intermediate feature $z_i(t)$ [S1].
    *   **MLP$_{\theta_2}$:** Takes directional encoding $\gamma_d(\mathbf{d})$, intermediate feature $z_i(t)$, and image latent $\ell_i$. Outputs image-dependent static color $\mathbf{c}_i(t)$ and transient mask embedding $\ell_t$ [S1].
    *   **Architecture:** 8 fully connected layers with 256 hidden units. $\sigma$ is output via ReLU. $\mathbf{c}$ and $\ell_t$ pass through an additional 128-unit layer with Sigmoid activation [S1].
3.  **Transient Mask Generator ($E_\phi$):** Linear layers mapping 2D pixel location $\mathbf{l}_{ij}$ and embedding $\ell_t$ to a 2D pixel-wise transient mask probability $M_{ij}$ [S1].
4.  **Inpainting Module ($G_\Delta$):** Pre-trained LaMa network. Input is a 4-channel tensor $\mathbf{x}' = \text{stack}(\mathbf{x} \odot \mathbf{m}, \mathbf{m})$, where $\mathbf{x}$ is the masked image and $\mathbf{m}$ is the binary thresholded mask. Output is the restored static image $\hat{I}_i^r$ and depth $\hat{D}_i^r$ [S1].
    *   **LaMa Architecture:** ResNet-like with 3 downsampling blocks, 12 residual blocks using Fast Fourier Convolution (FFC), and 3 upsampling blocks [S1].

**Numbered Steps:**
1.  **Image Encoding:** Encode each input image $I_i$ into a latent vector $\ell_i$ using CNN encoder $E_E$ [S1].
2.  **Ray Sampling:** Sample points along camera rays $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ using mip-NeRF cone casting with Integrated Positional Encoding (IPE) [S1].
3.  **Static Feature Prediction:** Compute $[\sigma(t), z_i(t)] = \text{MLP}_{\theta_1}[\gamma_x(\mathbf{r}(t))]$ [S1].
4.  **Radiance and Mask Embedding:** Compute $[\mathbf{c}_i(t), \ell_t] = \text{MLP}_{\theta_2}[\gamma_d(\mathbf{d}), z_i(t), \ell_i]$ [S1].
5.  **Transient Mask Generation:** For each pixel $(u,v)$ with location $\mathbf{l}_{ij}$, compute transient mask probability $M_{ij} = E_\phi(\mathbf{l}_{ij}, \ell_t)$ [S1]. Threshold $M_{ij}$ to create binary mask $\mathbf{m}_{ij}$ [S1].
6.  **Static Rendering:** Render static color $\hat{C}_i(\mathbf{r})$ and depth $\hat{D}_i(\mathbf{r})$ using volume rendering integration over static density $\sigma(t)$ and color $\mathbf{c}_i(t)$ [S1].
7.  **Inpainting:** Feed original image $I_i$ and mask $\mathbf{m}_{ij}$ into LaMa to generate restored static image $\hat{I}_i^r$ and depth $\hat{D}_i^r$ [S1].
8.  **Optimization:** Minimize total loss $L$ combining static photometric loss, transient loss, LPIPS loss, and depth loss [S1].

**Formulas:**
*   **Volume Rendering:**
    $$ \hat{C}_i(\mathbf{r}) = \sum_{k=1}^{K} T(t_k) \alpha(\sigma(t_k)\delta_k) \mathbf{c}_i(t_k) $$
    where $T(t_k) = \exp\left(-\sum_{k'=1}^{k-1} \sigma(t_{k'})\delta_{k'}\right)$ and $\alpha(\sigma\delta) = 1 - \exp(-\sigma\delta)$ [S1].
*   **Transient Loss ($L_t$):**
    $$ L_t = \sum_{ij} (1 - M_{ij}) \|\mathbf{C}(\mathbf{r}_{ij}) - \hat{\mathbf{C}}_s(\mathbf{r}_{ij})\|^2 + \lambda M_{ij} \|\mathbf{C}_s(\mathbf{r}_{ij}) - \hat{\mathbf{C}}_s(\mathbf{r}_{ij})\|^2 $$
    where $\mathbf{C}$ is observed color, $\hat{\mathbf{C}}_s$ is rendered static color, and $\lambda$ balances static/transient components [S1].
*   **Depth Loss ($L_{depth}$):**
    $$ L_{depth} = \frac{1}{|\mathcal{R}|} \sum_{\mathbf{r} \in \mathcal{R}} \|\hat{D}_s(\mathbf{r}) - \hat{D}_r(\mathbf{r})\|^2 $$
    where $\hat{D}_s$ is rendered static depth and $\hat{D}_r$ is inpainted depth [S1].
*   **Total Loss:**
    $$ L = \alpha \sum_{ij} L_s + \beta \sum_{ij} L_t + \gamma \sum_i L_{LPIPS} + \rho \sum_i L_{depth} $$
    where $L_s$ is static photometric loss (MSE on non-transient pixels), $L_{LPIPS}$ is perceptual loss inside the mask [S1].
*   **Frequency Regularization (RegFre-IPE):**
    $$ \gamma'_L(t, T; \mathbf{x}) = \gamma_L(\mathbf{x}) \odot \omega(t, T, L) $$
    where $\omega_i(t, T, L)$ is a linearly increasing frequency mask bit based on iteration $t$, max iteration $T$, max frequency $L$, and transient mask factor $r$ (ratio of transient pixels) [S1]:
    $$ \omega_i(t, T, L) = \begin{cases} 1 & \text{if } i \le \lfloor \frac{t \cdot L}{T} \rfloor + 3 \\ 0 & \text{if } i > \lfloor \frac{t \cdot L}{T} \rfloor + 6 \end{cases} $$
    (Note: Source [S1] Eq 17 defines $\omega$ with a transition zone between $+3$ and $+6$ relative to the threshold, effectively ramping up frequencies as training progresses) [S1].

**Parameters:**
*   $\lambda$: Balance weight for transient loss [S1].
*   $\alpha, \beta, \gamma, \rho$: Weights for static, transient, LPIPS, and depth losses respectively [S1].
*   $L$: Maximum encoded frequency in positional encoding [S1].
*   $r$: Transient mask factor (ratio of transient pixels to total image area) [S1].
*   Typical Values: Not given in the sources.

**Pseudocode:**
```python
def ie_nerf_forward(image, camera_pose, ray_samples):
    """
    Forward pass for a single image and its rays.
    image: Input image I_i
    camera_pose: Camera origin o and direction d for rays
    ray_samples: Sampled points t_k along rays
    """
    # 1. Encode Image
    # E_E is a CNN encoder
    latent_i = E_E(image)
    
    # 2. Positional Encoding (IPE with Frequency Regularization)
    # gamma_L is the base positional encoding function
    # t is current iteration, T is max iteration, L is max frequency
    # r is the transient mask factor from previous iteration or estimate
    pos_enc = IntegratedPositionalEncoding(ray_samples, L=L, t=t, T=T, r=r)
    
    # 3. MLP Theta 1: Density and Intermediate Feature
    # MLP_theta1 takes pos_enc
    sigma, z_i = MLP_theta1(pos_enc)
    
    # 4. MLP Theta 2: Color and Transient Embedding
    # gamma_d is directional encoding
    # latent_i is image latent
    color_c, transient_emb = MLP_theta2(gamma_d(camera_pose.d), z_i, latent_i)
    
    # 5. Transient Mask Generation
    # For each pixel location l_ij
    transient_mask_prob = E_phi(transient_emb, pixel_locations)
    
    # Threshold to get binary mask m_ij
    # Threshold value not specified in sources [G: Use 0.5 as standard default]
    binary_mask = (transient_mask_prob > 0.5).float()
    
    # 6. Volume Rendering (Static)
    # T(t_k) = exp(-sum_{k'<k} sigma(t_k') * delta_k')
    # alpha = 1 - exp(-sigma * delta)
    # C_i(r) = sum T(t_k) * alpha(t_k) * color_c(t_k)
    rendered_color = VolumeRender(sigma, color_c, ray_samples)
    rendered_depth = RenderDepth(sigma, ray_samples)
    
    # 7. Inpainting
    # Mask the original image
    masked_image = image * (1 - binary_mask)
    # LaMa input: stack(masked_image, binary_mask) -> 4 channels
    la_ma_input = stack([masked_image, binary_mask], dim=-1)
    
    # G_delta is LaMa network
    restored_image, restored_depth = G_delta(la_ma_input)
    
    return rendered_color, rendered_depth, binary_mask, restored_image, restored_depth

def compute_loss(rendered_color, rendered_depth, binary_mask, 
                 restored_image, restored_depth, ground_truth_image, 
                 ground_truth_depth, lambda_param, alpha, beta, gamma, rho):
    """
    Compute total loss.
    """
    # Static Photometric Loss (L_s)
    # MSE on pixels outside the transient mask
    static_mask = 1 - binary_mask
    L_s = MeanSquaredError(rendered_color * static_mask, 
                           ground_truth_image * static_mask)
    
    # Transient Loss (L_t)
    # Term 1: Occlusion error (outside mask)
    term1 = MeanSquaredError(rendered_color, ground_truth_image) * (1 - binary_mask)
    # Term 2: Reconstruction error (inside mask)
    # Uses restored image as proxy for ground truth static color
    term2 = MeanSquaredError(rendered_color, restored_image) * binary_mask
    L_t = Sum(term1 + lambda_param * term2)
    
    # LPIPS Loss (L_LPIPS)
    # Perceptual loss inside the mask
    L_LPIPS = LPIPS(rendered_color * binary_mask, 
                    restored_image * binary_mask)
    
    # Depth Loss (L_depth)
    L_depth = MeanSquaredError(rendered_depth, restored_depth)
    
    # Total Loss
    L = alpha * L_s + beta * L_t + gamma * L_LPIPS + rho * L_depth
    
    return L
```

**Edge Cases and Pitfalls:**
*   **Sparse Inputs:** The method struggles with small datasets or sparse inputs because the transient mask lacks sufficient information to guide the inpainting process reliably [S1].
*   **High-Frequency Instability:** High-frequency signals cause instability in transient separation. Mitigated by starting training without positional encoding and incrementally boosting frequency via RegFre-IPE [S1].
*   **Inpainting Blurriness:** Inpainting modules may produce blurry results and view inconsistencies. Mitigated by using LPIPS loss inside the mask and depth supervision [S1].
*   **Semantic Limitations:** If using semantic masks (IE-NeRF-SM), it may overlook shadows or images on walls and struggle with small occluders not in predefined classes [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Evaluated on Phototourism dataset (Brandenburg Gate, Sacre Coeur, Trevi Fountain, Taj Mahal) using 2x downsampled images [S1].
    *   **Brandenburg Gate:** PSNR 25.33, SSIM 0.898, LPIPS 0.158 [S1].
    *   **Comparison:** Outperforms NeRF (18.90/0.816/0.232), NeRF-W (24.17/0.891/0.167), and Ha-NeRF (24.04/0.877/0.139) [S1].
*   **Scaling:** Not given in the sources.
*   **Strengths:** Effectively separates static and transient components in uncontrolled environments without requiring 3D transient fields or external semantic priors [S1]. RegFre-IPE training strategy improves early convergence and final quality [S1].
*   **Limitations:** Performance degrades with sparse inputs; inpainting artifacts may persist if the transient mask is inaccurate; requires pre-filtering of low-quality images (NIMA < 3) and images with >80% transient coverage [S1].
*   **When to use:** Novel view synthesis in "in-the-wild" scenes with significant transient occlusions (people, cars) where static scene reconstruction is desired.
*   **When not to use:** Scenes with very sparse input views or when high-fidelity reconstruction of transient objects is required (as they are removed).

## Background
*   **Origin:** Proposed by Wang et al. from Sun Yat-sen University and Pengcheng Laboratory [S1].
*   **Paper:** "IE-NeRF: Exploring transient mask inpainting to enhance neural radiance fields in the wild" [S1].
*   **History:** Builds on NeRF [S1], NeRF-W [S1], and HA-NeRF [S1]. It addresses limitations of NeRF-W (3D transient field) and SF-NeRF (semantic priors) by introducing a 2D transient mask guided inpainting approach [S1].
*   **Usage:** Evaluated on cultural landmark scenes from the Phototourism dataset [S1].
