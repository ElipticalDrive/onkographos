# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
A training configuration for Neural Radiance Fields (NeRF) that incorporates depth priors to regularize the optimization process, addressing the ambiguity of monocular depth estimation in inverse volume rendering. It distinguishes itself from standard NeRF training by modifying the network architecture with specific dropout layers and introducing a weighted depth loss term, setting it apart from sibling methods like [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md) which rely on semantic constraints rather than geometric depth priors.

## How it works
**Inputs:**
- Camera poses and intrinsics.
- Input images.
- Ground truth depth maps (optional, for loss computation).
- Scene-specific depth bounds ($min\_depth$, $max\_depth$).

**Outputs:**
- Trained NeRF model parameters (MLP weights, embedding tables).

**Data Structures:**
- **NeRF MLP:** Standard NeRF architecture [S1].
  - Input: Positional encoding of $(x, y, z, \theta, \phi)$.
  - Layers: Fully connected ReLU-activated layers.
  - Modification: Dropout layers with probability $p=0.1$ are inserted after each of the first eight fully connected layers [S1].
- **Optimizer State:** Adam optimizer state variables (first and second moments) [S1].

**Parameters:**
- Depth loss weight ($\lambda$): $0.007$ for most scenes; $0.02$ for scene 710 [S1].
- Uncertainty weight ($\gamma$): $1$ [S1].
- Optimizer: Adam [S1].
- Initial learning rate ($\eta$): $5 \times 10^{-4}$ [S1].
- Learning rate schedule: Reduce to $5 \times 10^{-5}$ after 80% of total steps [S1].
- Weight decay: $1 \times 10^{-6}$ [S1].
- Total training steps: $500,000$ [S1].
- Depth scale learning rate: $1 \times 10^{-7}$ [S1].
- Threshold ($\tau$): Used to evaluate depth map uncertainty. Calculated as $\tau = (max\_depth - min\_depth) \cdot 0.0001$ [S1].
  - Example values for ScanNet: $max\_depth = 10$, $min\_depth = 0.001$ [S1].

**Steps:**
1. **Initialize** the NeRF model with positional encoding. Insert dropout layers ($p=0.1$) after the first eight fully connected ReLU layers [S1].
2. **Initialize** the Adam optimizer with learning rate $\eta = 5 \times 10^{-4}$ and weight decay $1 \times 10^{-6}$ [S1].
3. **Initialize** the depth scale parameter with learning rate $1 \times 10^{-7}$ [S1].
4. **For** each training step $t$ from $1$ to $500,000$:
   a. **Sample** rays from input images.
   b. **Render** color and depth values using the current NeRF model [S1].
   c. **Compute** the depth uncertainty threshold $\tau = (max\_depth - min\_depth) \cdot 0.0001$ [S1].
   d. **Compute** the depth loss $L_{depth}$ between predicted depth $\hat{d}$ and ground truth depth $d$ [S1].
   e. **Compute** the total loss $L = L_{color} + \lambda L_{depth} + \gamma L_{uncertainty}$ [S1].
      - Note: The specific formulation of $L_{uncertainty}$ is not detailed in the provided notes, but $\gamma=1$ is specified [S1].
   f. **Update** model parameters using Adam optimizer [S1].
   g. **Update** depth scale parameter using its specific learning rate [S1].
   h. **Adjust** learning rate: If $t > 0.8 \times 500,000$, set $\eta = 5 \times 10^{-5}$ [S1].

**Pseudocode:**
```python
# Initialization
model = NeRF()
# Add dropout layers after first 8 FC layers
for i, layer in enumerate(model.first_eight_fc_layers):
    layer.add_dropout(p=0.1)

optimizer = Adam(model.parameters(), lr=5e-4, weight_decay=1e-6)
depth_scale_optimizer = Adam([model.depth_scale], lr=1e-7)

# Training loop
total_steps = 500000
for step in range(1, total_steps + 1):
    # 1. Forward pass
    rays = sample_rays(images, poses)
    color, depth, uncertainty = model(rays)
    
    # 2. Compute losses
    # Ground truth depth d and predicted depth d_hat are available
    # Depth loss L_depth is computed based on ground truth and prediction
    # Specific formula for L_depth is not provided in notes, but L_color is standard
    L_color = compute_color_loss(color, gt_color)
    L_depth = compute_depth_loss(depth, gt_depth) # Implementation detail not specified
    
    # Uncertainty loss component
    # Threshold tau is used to evaluate uncertainty
    max_depth = 10.0 # Example for ScanNet
    min_depth = 0.001 # Example for ScanNet
    tau = (max_depth - min_depth) * 0.0001
    
    # Gamma is 1
    gamma = 1.0
    # L_uncertainty computation detail not specified in notes [G: Placeholder for uncertainty loss term]
    L_uncertainty = compute_uncertainty_loss(uncertainty, tau) 
    
    # Lambda depends on scene
    if scene_id == 710:
        lambda_depth = 0.02
    else:
        lambda_depth = 0.007
        
    L = L_color + lambda_depth * L_depth + gamma * L_uncertainty
    
    # 3. Backward pass and update
    optimizer.zero_grad()
    depth_scale_optimizer.zero_grad()
    L.backward()
    optimizer.step()

            param_group['lr'] = 5e-5
```

**Edge Cases and Pitfalls:**
- **Scene 710:** Requires a different depth loss weight ($\lambda=0.02$) compared to other scenes ($\lambda=0.007$) [S1].
- **Depth Bounds:** The threshold $\tau$ depends on scene-specific $min\_depth$ and $max\_depth$ values [S1].
- **Uncertainty Evaluation:** A very small threshold $\tau$ is used to evaluate depth map uncertainty [S1].

## Subtopics

### DS-NeRF Depth Loss Integration
Integrates the depth loss from the DS-NeRF official code base into the training pipeline. Due to missing configuration files for DTU results in the official code base and a different train/test split for LLFF results in the original publication, re-training is performed on the specific train/test splits using the released configuration files [S2].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Measured Performance:** Not given in the sources.
- **Strengths:** Incorporates geometric depth priors to regularize training, potentially improving depth accuracy and convergence [S1].
- **Limitations:** Requires ground truth depth maps for the depth loss term [S1]. Performance may vary across scenes (e.g., scene 710 requires different hyperparameters) [S1].
- **When to use:** When depth accuracy is critical and ground truth depth data is available [S1].
- **When not to use:** When ground truth depth is unavailable or when computational resources are limited for the additional loss computation [G].

## Background
Originated from the Depth-Guided NeRF method, which uses Earth Mover’s Distance for depth guidance [S1]. The configuration details are derived from the implementation described in the associated paper [S1].
