# Dynamic Scene and Temporal Modeling

Also called: SLS4D, Sparse Latent Space for 4D Novel View Synthesis

## Overview
Dynamic Scene and Temporal Modeling addresses the challenge of representing and rendering 4D scenes (3D space + time) from monocular or multi-view video sequences, where the scene geometry and appearance change over time. Unlike static NeRF methods [Parent](3065-nerf-hyperparameters.md) that assume a fixed radiance field, this method decouples spatial and temporal dynamics to handle motion efficiently. It sets itself apart from sibling methods like [NeRF with Time Parameter](14705-nerf-with-time-parameter.md) by abandoning direct coordinate-based interpolation in favor of a sparse, learnable latent space representation, and from [Gear-NeRF](13848-gear-nerf.md) by using a unified latent feature space rather than semantic stratification. The core innovation is the use of dense learnable time slots and a sparse set of global latent codes, reducing parameters to approximately 6% of previous state-of-the-art methods like V4D while maintaining high rendering quality [S1].

## How it works
The method, specifically instantiated as SLS4D [S1], represents the 4D radiance field using a sparse latent space. It separates the scene into a temporal component (time slots) and a spatial component (latent codes), connected by a deformation field and an attention-based interpolator.

### Inputs and Outputs
*   **Inputs:**
    *   4D coordinate $\mathbf{q} = (x, y, z, t)$, where $(x,y,z)$ is the 3D position and $t$ is the normalized time.
    *   View direction $\mathbf{d}$.
    *   A set of learnable time slot features $\mathbf{T} \in \mathbb{R}^{T \times D_t}$.
    *   A set of learnable spatial latent codes $\mathbf{L} \in \mathbb{R}^{B \times D_l}$.
*   **Outputs:**
    *   Volume density $\sigma$.
    *   Color $\mathbf{c}$.

### Data Structures
1.  **Time Slots ($\mathbf{T}$):** A dense matrix of size $T \times D_t$. Each row represents a temporal basis function. $T$ is the number of time slots.
2.  **Latent Codes ($\mathbf{L}$):** A sparse matrix of size $B \times D_l$. These are global learnable vectors that implicitly encode spatial positions. $B$ is the number of latent codes.
3.  **Deformation Field ($\mathcal{M}_{def}$):** A 7-layer Multi-Layer Perceptron (MLP).
    *   Input: 4D coordinate $\mathbf{q} = (x, y, z, t)$.
    *   Output: 3D displacement vector $\Delta \mathbf{p} = (\Delta x, \Delta y, \Delta z)$.
4.  **Interpolator Decoder ($\mathcal{M}_{interp}$):** A network using GeGLU (Gated Linear Unit with bilinear gating) activation. It takes the query feature (derived from the deformed position) and key features (latent codes) to produce the final feature vector.

### Parameters
*   $B = 512$: Number of latent features (codes).
*   $T = 512$: Number of time slots.
*   $D_t, D_l$: Dimensionality of time slot and latent code vectors (Not given in the sources, but implied by matrix dimensions).
*   Learning Rate Decay: Cosine * Exponential decay function. Cosine decay alone is unstable; exponential decay alone may get stuck in local optima [S1].

### Steps
1.  **Temporal Encoding:**
    The input time $t$ is used to select or interpolate from the dense time slot features $\mathbf{T}$. This creates a temporal context vector $\mathbf{v}_t$ that captures the global state of the scene at time $t$. The time slots ensure smooth transitions between timestamps [S1].

2.  **Deformation Field Prediction:**
    The 4D coordinate $\mathbf{q} = (x, y, z, t)$ is passed through the deformation MLP $\mathcal{M}_{def}$.
    $$
    \Delta \mathbf{p} = \mathcal{M}_{def}(x, y, z, t)
    $$
    The deformed position $\mathbf{p}'$ is calculated as:
    $$
    \mathbf{p}' = (x, y, z) + \Delta \mathbf{p}
    $$
    This step decouples time and space, mapping the dynamic position to a canonical static space [S1].

3.  **Spatial Feature Interpolation (Attention Mechanism):**
    The deformed position $\mathbf{p}'$ serves as a query. The spatial latent codes $\mathbf{L}$ serve as keys and values. The attention weights $\mathbf{w}$ for each latent code are computed using the inner product of the query feature of $\mathbf{p}'$ and the key value of the latent codes.
    $$
    \mathbf{w}_i = \text{softmax}\left( \frac{\mathbf{q}_{feat}(\mathbf{p}') \cdot \mathbf{k}_i}{\sqrt{d}} \right)
    $$
    where $\mathbf{q}_{feat}$ is a feature representation of the deformed position, $\mathbf{k}_i$ is the key vector for the $i$-th latent code, and $d$ is the dimensionality.
    The aggregated spatial feature $\mathbf{f}_{spatial}$ is:
    $$
    \mathbf{f}_{spatial} = \sum_{i=1}^{B} \mathbf{w}_i \mathbf{v}_i
    $$
    where $\mathbf{v}_i$ is the value vector (latent code) for the $i$-th code. This mechanism allows the model to adaptively weight latent codes based on the 3D position, abandoning direct coordinate relationships in favor of relative relationships in the latent space [S1].

4.  **Radiance Field Prediction:**
    The aggregated spatial feature $\mathbf{f}_{spatial}$ and the temporal context $\mathbf{v}_t$ are concatenated and passed through the Interpolator Decoder $\mathcal{M}_{interp}$.
    $$
    \mathbf{f}_{final} = \mathcal{M}_{interp}(\mathbf{f}_{spatial}, \mathbf{v}_t)
    $$
    The decoder outputs the density $\sigma$ and color $\mathbf{c}$ (and potentially other auxiliary outputs if extended). The use of GeGLU in the decoder provides higher fitting capacity for complex nonlinear relationships compared to standard GeLU or MLP [S1].

5.  **Rendering:**
    Standard volume rendering is performed along rays using the predicted $\sigma$ and $\mathbf{c}$:
    $$
    \hat{C}(r) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i
    $$
    where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ and $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$.

### Pseudocode

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SLS4D:
    def __init__(self, B=512, T=512, D_t=256, D_l=256, D_feat=256):
        """
        Initialize the SLS4D model.
        
        Args:
            B: Number of spatial latent codes.
            T: Number of time slots.
            D_t: Dimension of time slot features.
            D_l: Dimension of latent codes.
            D_feat: Dimension of intermediate features.
        """
        super().__init__()
        # Dense learnable time slot features
        self.time_slots = nn.Parameter(torch.randn(T, D_t))
        
        # Sparse learnable spatial latent codes
        self.latent_codes = nn.Parameter(torch.randn(B, D_l))
        
        # Deformation Field: 7-layer MLP
        # Input: 4D coord (x,y,z,t), Output: 3D displacement (dx,dy,dz)
        self.deformation_mlp = nn.Sequential(
            nn.Linear(4, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 3) # Output displacement
        )
        
        # Interpolator Decoder with GeGLU
        # Input: concatenated spatial feature and time context
        self.interpolator = nn.Sequential(
            nn.Linear(D_l + D_t, D_feat),
            nn.GELU(), # Note: Source specifies GeGLU, simplified here as standard GLU or GELU for structure
            # Actual GeGLU implementation:
            # nn.Linear(D_l + D_t, D_feat * 2),
            # lambda x: F.gelu(x[:, :D_feat]) * x[:, D_feat:]
            nn.Linear(D_feat, D_feat),
            nn.ReLU(),
            nn.Linear(D_feat, 4) # Output: sigma (1) + color (3)
        )

    def get_time_context(self, t):
        """
        Get temporal context from time slots.
        t: normalized time in [0, 1]
        """
        # Map t to index in time slots
        # Assuming linear interpolation between slots
        idx = t * (len(self.time_slots) - 1)
        idx_low = int(idx)
        idx_high = min(idx_low + 1, len(self.time_slots) - 1)
        weight = idx - idx_low
        
        t_low = self.time_slots[idx_low]
        t_high = self.time_slots[idx_high]
        
        return t_low * (1 - weight) + t_high * weight

    def deform(self, x, y, z, t):
        """
        Predict displacement using deformation field.
        """
        coord = torch.stack([x, y, z, t], dim=-1)
        displacement = self.deformation_mlp(coord)
        return displacement

    def interpolate_spatial(self, deformed_pos):
        """
        Interpolate spatial features using attention mechanism.
        deformed_pos: (..., 3) tensor of deformed 3D coordinates.
        """
        # Project deformed position to query feature space
        # Source says "query feature of the 3D position"
        # We assume a simple projection or use the position itself as query
        query = deformed_pos # Or a linear layer: self.query_proj(deformed_pos)
        
        # Keys and Values are the latent codes
        keys = self.latent_codes # (B, D_l)
        values = self.latent_codes # (B, D_l)
        
        # Compute attention weights
        # Inner product of query and key
        # query: (..., 3) or (..., D_q) -> need to match dimensions
        # Assuming query is projected to D_l for compatibility
        # [G] Implementation detail: Source mentions inner product of query feature and key value.
        # We assume a linear projection for query to match latent dimension D_l.
        query_proj = torch.matmul(query, self.query_proj_weight) if hasattr(self, 'query_proj_weight') else query
        
        # Attention scores
        scores = torch.matmul(query_proj, keys.T) # (..., B)
        weights = F.softmax(scores, dim=-1)
        
        # Weighted sum of values
        spatial_feature = torch.matmul(weights, values) # (..., D_l)
        return spatial_feature

    def forward(self, x, y, z, t, view_dir=None):
        """
        Forward pass for a single point.
        """
        # 1. Temporal Context
        t_ctx = self.get_time_context(t)
        
        # 2. Deformation
        disp = self.deform(x, y, z, t)
        x_d, y_d, z_d = x + disp[..., 0], y + disp[..., 1], z + disp[..., 2]
        
        # 3. Spatial Interpolation
        deformed_pos = torch.stack([x_d, y_d, z_d], dim=-1)
        spatial_feat = self.interpolate_spatial(deformed_pos)
        
        # 4. Radiance Field Prediction
        input_feat = torch.cat([spatial_feat, t_ctx], dim=-1)
        output = self.interpolator(input_feat)
        
        sigma = output[..., 0:1]
        color = output[..., 1:4]
        
        return sigma, color

    def compute_loss(self, pred_color, gt_color, deformation_field_output):
        """
        Compute loss including Total Variance (TV) loss for temporal smoothness.
        """
        # Color loss (e.g., L1 or L2)
        color_loss = F.mse_loss(pred_color, gt_color)
        
        # TV Loss for deformation field temporal smoothness
        # [G] Source mentions TV loss for supervision of temporal smoothness in deformation fields.
        # We approximate TV loss on the displacement predictions across time.
        # This requires access to multiple time steps or a specific formulation.
        # Assuming deformation_field_output contains displacements for a batch of times.
        tv_loss = 0.0
        if deformation_field_output is not None:
            # Simple TV loss on the displacement values
            tv_loss = torch.mean(torch.abs(deformation_field_output[..., :-1] - deformation_field_output[..., 1:]))
            
        return color_loss + tv_loss
```

### Edge Cases and Pitfalls
*   **Long-Duration Inputs:** Excessively long-duration inputs may struggle to fit data adequately with a small number of parameters ($B=512, T=512$). A growing NeRF strategy may be required for such cases [S1].
*   **Absence of Deformation Fields:** Without the deformation field (SLS4Dnd), the decoupling between time and space is lost, posing challenges in extracting information for reconstruction and degrading quality [S1].
*   **Removing Time Slots:** Removing time slots (SLS4Dnf) results in degradation of rendering quality because smooth transitions between timestamps are not ensured [S1].
*   **Decoder Choice:** Using only GeLU (SLS4Dge) or a standard MLP (SLS4Dml) as the interpolator decoder results in inferior performance compared to GeGLU, which offers higher fitting capacity for complex nonlinear relationships [S1].
*   **Learning Rate Stability:** Using only cosine decay (SLS4Dco) leads to instability and susceptibility to sub-optimal outcomes. Using only exponential decay (SLS4Deo) may get stuck in local optima. The combined cosine*exp decay is necessary [S1].

## Subtopics

### [Gear-NeRF](13848-gear-nerf.md)
Uses semantic segmentation to stratify the scene into motion-based 'gears' with region-specific sampling resolution. Choose when semantic labels are available and motion varies significantly across regions.

### [NeRF with Time Parameter](14705-nerf-with-time-parameter.md)
Expands the MLP input with a time dimension. Choose as a baseline for simple dynamic scenes; lacks detailed dynamic reasoning and can be blurry.

### [Forward Warping for Novel View Synthesis](15541-forward-warping-for-novel-view-synthesis.md)
Models a static canonical field and warps it to target times. Choose when dealing with many-to-one/one-to-many mapping ambiguities and explicit voxel grids are feasible.

### [Dynamic Appearance Particle Neural Radiance Field](15550-dynamic-appearance-particle-neural-radiance-field.md)
Combines a static grid with particle-based dynamic components. Choose for monocular video where only specific elements are dynamic, avoiding multi-view requirements.

### [KFD-NeRF](15551-kfd-nerf.md)
Uses a Kalman filter to estimate temporally varying states. Choose when explicit motion estimation (observer/predictor branches) is preferred over implicit latent interpolation.

## Operating characteristics
*   **Time Complexity:** Training time is significantly reduced compared to dense voxel-based methods. On an Nvidia 4090, SLS4D takes approximately 3 hours to achieve results similar to V4D (7 hours), and 6 hours total for final results [S1].
*   **Memory Complexity:** The method uses a sparse latent space, reducing the number of network parameters to approximately 6% of previous SOTA work V4D (~0.25M parameters vs ~0.1M-37M for others) [S1]. The feature vector space (FS) is also small.
*   **Performance:** Achieves state-of-the-art results on the D-NeRF dataset: PSNR 34.84, SSIM 0.981, LPIPS 0.025 [S1].
*   **Strengths:** High parameter efficiency, good handling of global dynamics, smooth temporal transitions via time slots.
*   **Limitations:** Struggles with excessively long-duration scenes due to fixed latent space size. Relies on the assumption that spatial features can be captured by a finite set of global codes.

## Background
The method, SLS4D, was introduced to address the limitations of dense voxel grids and direct coordinate-based interpolation in dynamic NeRFs. It builds on the D-NeRF [27] paradigm of using deformation fields but replaces the dense feature space with a sparse latent space. The work was published in IEEE Transactions on Visualization and Computer Graphics in 2024 [S1]. It compares favorably to methods like T-NeRF, D-NeRF, TiNeuVox, K-Plane, HexPlane, and V4D [S1].
