# Transformer and Vision Model Integration

Also called: Vision Transformer NeRF, TransNeRF, NeRF Analogies

## Overview
This family integrates Vision Transformers (ViTs) into Neural Radiance Fields to leverage global semantic context, long-range dependencies, and cross-scene transfer capabilities that standard CNN-based encoders lack. It solves the limitations of local feature aggregation by enabling models to reason about occluded regions via self-attention [13878-vit-nerf.md], generalize across scenes without per-scene optimization [13907-transnerf.md], or transfer appearance attributes via semantic correspondence [18133-nerf-analogies.md]. Unlike sibling methods that rely on canonical coordinates or posed multi-view inputs, these approaches utilize transformer attention mechanisms to condition volume rendering on hybrid global-local features or latent scene representations.

## Shared principles
All methods in this family replace or augment the standard CNN-based image encoder of NeRF with a Vision Transformer backbone to extract high-level semantic features.

1.  **Tokenization and Attention:** Input images are split into patches or tokens. A Transformer Encoder processes these tokens using multi-head self-attention to capture global relationships between distant parts of the scene, which is critical for handling self-occlusion and generalization [13878-vit-nerf.md], [13885-visionnerf.md].
2.  **Feature Resampling:** Global latent features from the ViT are unflattened and resampled into multi-level 2D feature maps (coarse-to-fine) to align with spatial coordinates for volume rendering [13878-vit-nerf.md], [13885-visionnerf.md].
3.  **Hybrid Conditioning:** Rendering is conditioned on a combination of these global transformer features and local appearance features (often from a CNN) to balance semantic consistency with high-frequency detail [13878-vit-nerf.md], [13885-visionnerf.md].
4.  **Semantic Correspondence:** In cross-scene applications, dense semantic correspondences are established between source and target scenes using ViT key-component features, enabling appearance transfer without geometric alignment [18133-nerf-analogies.md].

## Subtopics

### [ViT-NeRF](13878-vit-nerf.md)
A view synthesis method that combines a ViT for global shape information and a 2D CNN for local appearance, conditioning rendering on hybrid per-pixel features. It produces sharper edges than SRN and PixelNeRF and avoids blurriness on invisible parts by not requiring a canonical coordinate system [13878-vit-nerf.md].

### [VisionNeRF](13885-visionnerf.md)
Infers a 3D representation from a single unposed input image. It addresses self-occlusion by using self-attention to retrieve relevant features from distant parts of the source view for occluded regions, rather than querying features along the ray corresponding to the visible surface [13885-visionnerf.md].

### [TransNeRF](13907-transnerf.md)
A generalizable method that learns a generic radiance field for novel scenes using an encoder-decoder Transformer framework, avoiding per-scene optimization. It aggregates multi-view information into a coordinate-based representation via attention, exploring deep relationships amongst multiple views [13907-transnerf.md].

### [NeRF Analogies](18133-nerf-analogies.md)
Transfers visual appearance attributes from a source NeRF to a target NeRF by establishing dense semantic correspondences using ViT features. It solves style/texture transfer by creating a "NeRF analogy" where the target adopts source visual characteristics while maintaining its own geometry [18133-nerf-analogies.md].

## Background
The integration of Transformers into NeRF stems from the need to overcome the limited receptive field of CNNs. Standard NeRFs [15530-network-architectures.md] and early image-conditioned variants like PixelNeRF [15530-network-architectures.md] rely on local pooling or CNN features, which struggle with global consistency and occlusion. ViT-NeRF [13878-vit-nerf.md] and VisionNeRF [13885-visionnerf.md] introduced ViTs to capture long-range dependencies. TransNeRF [13907-transnerf.md] extended this to generalizable learning across scenes. NeRF Analogies [18133-nerf-analogies.md] later utilized the semantic power of ViTs (specifically DiNO) for cross-scene attribute transfer.
