# Low Rank NeRF Approximation with ADMM

Also called: TT Decompression via ADMM, Tensor Train NeRF Compression

## Overview
This method reduces the model size of a trained Neural Radiance Field (NeRF) by decomposing its fully connected layer weights into a Tensor Train (TT) format [S1, unofficial]. It solves the resulting rank-constrained optimization problem using the Alternating Direction Method of Multipliers (ADMM) to minimize reconstruction error while enforcing low-rank structure [S1, unofficial]. It is distinguished from sibling methods like [CCNeRF](15008-ccnerf.md) by its specific use of ADMM for rank-constrained weight decomposition rather than other compression or clustering techniques.

## How it works
**Inputs and Outputs**
- **Input:** A trained NeRF model with fully connected layer weight matrices $\mathbf{W}_i \in \mathbb{R}^{n_1 \times n_2}$ and bias vectors $\mathbf{b}_i$.
- **Output:** Low-rank Tensor Train cores $\mathbf{Q}_{1i} \in \mathbb{R}^{n_1 \times r}$ and $\mathbf{Q}_{2i} \in \mathbb{R}^{r \times n_2}$, and the original bias vectors $\mathbf{b}_i$.

**Data Structures**
- $\mathbf{W}_i$: Original weight matrix for layer $i$.
- $\mathbf{Z}_i$: Auxiliary variable for layer $i$, same shape as $\mathbf{W}_i$.
- $\mathbf{U}_i$: Dual multiplier variable for layer $i$, same shape as $\mathbf{W}_i$.
- $\mathbf{Q}_{1i}$: First TT core, size $n_1 \times r$.
- $\mathbf{Q}_{2i}$: Second TT core, size $r \times n_2$.
- $r$: Target rank (integer).
- $\rho$: Penalty parameter (scalar, positive).

**Formulas**
The TT decomposition approximates the weight matrix as:
$$ \mathbf{W}_i \approx \mathbf{Q}_{1i} \mathbf{Q}_{2i} $$
where $\mathbf{Q}_{1i} \in \mathbb{R}^{1 \times n_1 \times r}$ and $\mathbf{Q}_{2i} \in \mathbb{R}^{r \times n_2 \times 1}$ are the full tensor cores, but the first dimension of $\mathbf{Q}_{1i}$ and last dimension of $\mathbf{Q}_{2i}$ are squeezed for storage, resulting in sizes $n_1 \times r$ and $r \times n_2$ respectively [S1, unofficial].

The optimization minimizes the Augmented Lagrangian (scaled dual form):
$$ \mathcal{L}(\mathbf{W}_i, \mathbf{Z}_i, \mathbf{U}_i) = l(\mathbf{W}_i) + g(\mathbf{Z}_i) + \frac{\rho}{2}||\mathbf{W}_i - \mathbf{Z}_i + \mathbf{U}_i||_F^2 + \frac{\rho}{2}||\mathbf{U}_i||_F^2 $$
where $l(\mathbf{W}_i) = ||\mathbf{c}' - \mathbf{c}_{gt}||_2^2$ is the rendering reconstruction error (rendered pixel value vs ground truth), $g(\mathbf{Z}_i)$ enforces the rank constraint, $\rho$ is the penalty parameter, and $\mathbf{U}_i$ is the dual multiplier [S1, unofficial].

**Parameters**
- **Rank $r$:** Controls compression ratio. Typical experimental values: 40, 50, 70, 90 [S1, unofficial].
- **Penalty $\rho$:** Positive scalar. Value not given in the sources.

**Algorithm Steps**
For each fully connected layer $i$ with weights $\mathbf{W}_i$:

1. **Initialize:** Set $\mathbf{Z}_i^0 = \mathbf{W}_i^0$, $\mathbf{U}_i^0 = \mathbf{0}$. Set iteration counter $t=0$.
2. **Iterate until convergence:**
   a. **W-update:** Update $\mathbf{W}_i$ by minimizing the Lagrangian with respect to $\mathbf{W}_i$ using gradient descent:
      $$ \mathbf{W}_i^{t+1} = \arg\min_{\mathbf{W}_i} \mathcal{L}(\mathbf{W}_i^t, \mathbf{Z}_i^t, \mathbf{U}_i^t) $$
      [S1, unofficial]
   b. **Z-update:** Update $\mathbf{Z}_i$ by projecting $\mathbf{W}_i^{t+1} + \mathbf{U}_i^t$ onto the low-rank TT format with rank $r$:
      $$ \mathbf{Z}_i^{t+1} = \Pi_r(\mathbf{W}_i^{t+1} + \mathbf{U}_i^t) $$
      where $\Pi_r$ is the operation that decomposes the matrix into the TT format truncated to rank $r$. [S1, unofficial]
   c. **U-update:** Update the dual multiplier:
      $$ \mathbf{U}_i^{t+1} = \mathbf{U}_i^t + \mathbf{W}_i^{t+1} - \mathbf{Z}_i^{t+1} $$
      [S1, unofficial]
3. **Final Decomposition:** After convergence, the low-rank weights $\mathbf{W}_i^*$ are decomposed into $\mathbf{Q}_{1i}$ and $\mathbf{Q}_{2i}$ such that $\mathbf{W}_i^* \approx \mathbf{Q}_{1i} \mathbf{Q}_{2i}$. The bias vectors $\mathbf{b}_i$ remain unchanged as they are rank 1 [S1, unofficial].

**Pseudocode**
```python
def low_rank_nerf_admm(W_init, rank_r, rho, max_iters, lr_w):
    """
    Performs ADMM-based low-rank approximation for a single layer's weights.
    
    Args:
        W_init: Initial weight matrix of shape (n1, n2).
        rank_r: Target rank r.
        rho: Penalty parameter.
        max_iters: Maximum number of ADMM iterations.
        lr_w: Learning rate for W-update gradient descent.
        
    Returns:
        Q1: First TT core of shape (n1, r).
        Q2: Second TT core of shape (r, n2).
    """
    n1, n2 = W_init.shape
    W = W_init.copy()
    Z = W_init.copy()
    U = np.zeros_like(W)
    
    for t in range(max_iters):
        # Step 1: W-update
        # Minimize L(W, Z, U) w.r.t W using gradient descent.
        # L = l(W) + rho/2 * ||W - Z + U||_F^2 + const
        # grad_L_w = grad_l(W) + rho * (W - Z + U)
        # Note: grad_l(W) requires backpropagation through the NeRF rendering loss.
        # This step assumes access to the gradient of the rendering loss w.r.t W.
        grad_l = compute_rendering_gradient(W) # [G] Placeholder for specific loss gradient computation
        grad_L = grad_l + rho * (W - Z + U)
        W = W - lr_w * grad_L
        
        # Step 2: Z-update
        # Project (W + U) onto low-rank TT format with rank r.
        # This involves computing the TT decomposition and truncating to rank r.
        Z = project_to_tt_rank(W + U, rank_r) # [G] Placeholder for TT decomposition/truncation logic
        
        # Step 3: U-update
        U = U + W - Z
        
    # Final decomposition
    # Decompose the final W into Q1 and Q2
    Q1, Q2 = decompose_tt(W, rank_r)
    
    return Q1, Q2

def project_to_tt_rank(M, r):
    """
    Computes the Tensor Train decomposition of M and truncates to rank r.
    Returns the matrix representation of the truncated TT cores.
    """
    # [G] Implementation detail: This typically involves SVD-based TT decomposition.
    # For a matrix, TT cores Q1 (n1 x r) and Q2 (r x n2) are obtained.
    # The product Q1 @ Q2 approximates M.
    # Here we return the product of the truncated cores to serve as Z.
    Q1, Q2 = compute_tt_cores(M, r)
    return Q1 @ Q2

def compute_tt_cores(M, r):
    """
    Computes the first and second TT cores of matrix M with target rank r.
    Returns Q1 of shape (n1, r) and Q2 of shape (r, n2).
    """
    # [G] Implementation detail: This is the core TT decomposition step.
    # For a matrix, this is equivalent to a truncated SVD if r < min(n1, n2).
    # U, S, Vt = np.linalg.svd(M, full_matrices=False)
    # Q1 = U[:, :r] * np.sqrt(S[:r])
    # Q2 = np.sqrt(S[:r]) * Vt[:r, :]
    # However, for higher-order tensors or specific TT formats, more complex algorithms are used.
    # Given the source describes matrix weights, truncated SVD is a valid interpretation.
    U, S, Vt = np.linalg.svd(M, full_matrices=False)
    Q1 = U[:, :r] * np.sqrt(S[:r])
    Q2 = np.sqrt(S[:r]) * Vt[:r, :]
    return Q1, Q2
```

**Edge Cases and Pitfalls**
- **Bias Parameters:** Bias vectors $\mathbf{b}_i$ are rank 1 and are not optimized via ADMM; they remain unchanged [S1, unofficial].
- **Approximation Error:** Straightforward decomposition causes large approximation error; ADMM is required to guarantee low-rank property without significant performance degradation [S1, unofficial].
- **Camera Pose:** The method assumes camera pose parameters (focal length $f$, parallax offset $\Delta$) are either known or treated as trainable variables alongside weights [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Depends on the number of ADMM iterations and the cost of gradient descent for the rendering loss. The projection step $\Pi_r$ involves TT decomposition, which is generally efficient for low ranks.
- **Memory Complexity:** Reduces storage from $O(n_1 n_2)$ to $O(r(n_1 + n_2))$ per layer.
- **Measured Performance:** Experiments used target ranks $r \in \{40, 50, 70, 90\}$ [S1, unofficial].
- **Strengths:** Effective reduction of NeRF model size for light field compression while maintaining reconstruction quality.
- **Limitations:** Requires iterative optimization (ADMM) after initial training. Approximation error must be managed.
- **When to use:** When transmitting or storing NeRF models is a bottleneck, particularly for structured light fields.
- **When not to use:** When real-time training updates are required without post-processing, or when memory is not the primary constraint.

## Background
The method was proposed in the context of light field compression, where the large size of NeRF models makes them less efficient to transmit than compressed light field views [S1, unofficial]. It builds on the idea of treating camera pose parameters as trainable variables [S1, unofficial]. The use of ADMM for tensor rank optimization is based on prior work [36] (not provided in sources), and the TT decomposition is based on [35] (not provided in sources). The specific application to NeRF for light fields is detailed in [S1, unofficial].
