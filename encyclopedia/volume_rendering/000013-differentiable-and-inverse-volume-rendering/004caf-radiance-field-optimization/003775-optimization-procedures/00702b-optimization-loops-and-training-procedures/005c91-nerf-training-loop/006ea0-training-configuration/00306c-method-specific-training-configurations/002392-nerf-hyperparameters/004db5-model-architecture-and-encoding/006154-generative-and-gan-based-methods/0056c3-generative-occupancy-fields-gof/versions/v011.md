# Generative Occupancy Fields (GOF)


## Overview
Generative Occupancy Fields (GOF) is a 3D-aware image synthesis method that combines radiance fields with occupancy representations to learn compact object surfaces without impeding training convergence [S1, unofficial]. It solves the problem of diffused surfaces in standard generative radiance fields (like pi-GAN) and the sparse gradient convergence issues in direct occupancy networks by transitioning from cumulative volume rendering to surface-point rendering [S1, unofficial]. Unlike siblings that predict volume density $\sigma$ and rely on cumulative alpha composition, GOF predicts alpha values $\alpha$ directly, reinterpreting them as occupancy to locate surfaces via root-finding [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A latent code $z \sim p_z$ (typically truncated for inference) and a camera pose $\xi \sim p_\xi$ (origin $o$ and direction $d$).
*   **Output:** A synthesized 2D image $I$ and, implicitly, a compact 3D surface representation.

**Data Structures:**
*   **Generator $G_\theta$:** A neural network (specifically a FiLMed-SIREN backbone) that takes encoded coordinates and latent code $z$, outputting alpha values $\alpha_\theta(x, z) \in [0, 1]$ and color $\mathbf{c}_\theta(x, d, z) \in \mathbb{R}^3$ [S1, unofficial].
*   **Discriminator $D_\phi$:** A standard GAN discriminator evaluating real vs. generated images [S1, unofficial].

**Parameters:**
*   $N$: Number of rendering samples per ray. Typical value: 12 [S1, unofficial].
*   $M$: Number of bins for root-finding. Typical value: 12 [S1, unofficial].
*   $m_s$: Number of secant iterations for surface refinement. Typical value: 3 [S1, unofficial].
*   $\tau$: Threshold for root-finding. Typical value: 0.5 [S1, unofficial].
*   $\Delta_{init}$: Initial sampling interval half-width. Set to $(t_f - t_n)/2$ [S1, unofficial].
*   $\Delta_{min}$: Minimal sampling interval half-width. Not given in the sources.
*   $\gamma$: Decay rate for shrinking interval. Not given in the sources.
*   $\lambda_{normal}, \lambda_{opacity}$: Loss balancing coefficients. Not given in the sources.

**Algorithm Steps:**

1.  **Surface Location via Root-Finding:**
    To locate the surface $S$ along a ray $r(t) = o + td$ bounded by $[t_n, t_f]$:
    1.  Sample $M$ evenly-spaced points $x_k$ partitioning the volume $[t_n, t_f]$. These points do not require gradient computation [S1, unofficial].
    2.  Query the generator for alpha values $\alpha_\theta(x_k, z)$.
    3.  Find the bin $k_S$ where the alpha crosses the threshold $\tau$:
        $$ k_S = \arg\min_k (\alpha_\theta(x_k, z) < \tau \le \alpha_\theta(x_{k+1}, z)) $$
    4.  Apply the secant method iteratively $m_s$ times within the bin $[x_{k_S}, x_{k_S+1}]$ to find the precise surface point $x_s$ and its depth $t_s$ [S1, unofficial].

2.  **Shrinking Sampling Region (Training Only):**
    To transition from radiance fields to occupancy representations, the sampling region shrinks during training:
    1.  Initialize $\Delta_{init} = (t_f - t_n)/2$.
    2.  At training step $n$, compute the current interval half-width:
        $$ \Delta_n = \max(\Delta_{init} \exp(-\gamma n), \Delta_{min}) $$
    3.  Sample $N$ points uniformly in the interval $[t_s - \Delta_n, t_s + \Delta_n]$. The points $t_i$ are sampled as:
        $$ t_i \sim U\left[t_s - \Delta_n + \frac{2i-2}{N}\Delta_n, t_s - \Delta_n + \frac{2i}{N}\Delta_n\right] $$
    4.  If the region $[t_s - \Delta_n, t_s + \Delta_n]$ exceeds the global bounds $[t_n, t_f]$, shift it back to fit within $[t_n, t_f]$ [S1, unofficial].

3.  **Rendering:**
    Render the image using alpha composition. Since GOF predicts $\alpha$ directly, the color $\tilde{C}(r, z)$ is:
    $$ \tilde{C}(r, z) = \sum_{i=1}^{N} \alpha_\theta(x_i, z) \left( \prod_{j<i} (1 - \alpha_\theta(x_j, z)) \right) \mathbf{c}_\theta(x_i, d, z) $$
    *   **Training:** Use the shrinking region $[t_s - \Delta_n, t_s + \Delta_n]$ with $N$ points [S1, unofficial].
    *   **Inference:** Use the minimal region $[t_s - \Delta_{min}, t_s + \Delta_{min}]$ with $N$ points, or render using only the single surface point $x_s$ (i.e., $N=1$) for speed [S1, unofficial].

**Loss Functions:**
The total loss is a combination of GAN loss, normal regularization, and opacity regularization:
$$ L(\theta, \phi) = L_{origin}(\theta, \phi) + \lambda_{normal} L_{normal} + \lambda_{opacity} L_{opacity} $$

1.  **GAN Loss ($L_{origin}$):**
    $$ L_{origin}(\theta_D, \theta_G) = \mathbb{E}_{z \sim p_z, \xi \sim p_\xi} f(D_{\theta_D}(G_{\theta_G}(z, \xi))) + \mathbb{E}_{I \sim p_D} f(-D_{\theta_D}(I)) + \lambda ||\nabla_{D_{\theta_D}}(I)||_2^2 $$
    where $f(u) = -\log(1 + \exp(-u))$ [S1, unofficial].

2.  **Normal Regularization ($L_{normal}$):**
    Encourages surface normal smoothness at the located surface points $x_s \in S$:
    $$ L_{normal} = \sum_{x_s \in S} ||\mathbf{n}_\theta(x_s, z) - \mathbf{n}_\theta(x_s + \epsilon, z)||_2^2 $$
    where $\mathbf{n}_\theta$ is the estimated surface normal [S1, unofficial].

3.  **Opacity Regularization ($L_{opacity}$):**
    Reduces the entropy of predicted alpha values, pushing them towards 0 or 1:
    $$ L_{opacity} = \frac{1}{N} \sum_{i=1}^{N} \log(\alpha_\theta(x_i, z)) + \log(1 - \alpha_\theta(x_i, z)) $$
    [S1, unofficial].

import numpy as np

def generate_image(generator, discriminator, latent_code, camera_pose, 
                   t_n, t_f, N_render, M_bins, m_secant, tau, 
                   training_step, gamma, delta_min, lambda_normal, lambda_opacity):
    """
    Synthesize an image using Generative Occupancy Fields.
    
    Args:
        generator: Function G_theta(x, z) -> (alpha, color)
        discriminator: Function D_phi(image)
        latent_code: z
        camera_pose: (origin_o, direction_d)
        t_n, t_f: Near and far clipping planes
        N_render: Number of points for rendering
        M_bins: Number of bins for root finding
        m_secant: Number of secant iterations
        tau: Threshold for surface detection
        training_step: Current training step n
        gamma: Decay rate for shrinking
        delta_min: Minimal sampling interval half-width
        lambda_normal: Weight for normal regularization
        lambda_opacity: Weight for opacity regularization
        
    Returns:
        rendered_image, loss, gradients
    """
    origin, direction = camera_pose
    
    # 1. Surface Location via Root-Finding
    # Sample M evenly spaced points in [t_n, t_f]
    t_bins = np.linspace(t_n, t_f, M_bins + 1)
    x_bins = origin + t_bins[:, np.newaxis] * direction[np.newaxis, :]
    
    # Query alpha values (no gradients needed for root finding)
    with torch.no_grad():
        alpha_bins, _ = generator(x_bins, latent_code)
        
    # Find bin where alpha crosses tau
    # alpha < tau (free) to alpha >= tau (occupied)
    # Note: Source uses strict inequality < tau <= alpha for next point
    crossing_indices = np.where((alpha_bins[:-1] < tau) & (alpha_bins[1:] >= tau))[0]
    
    if len(crossing_indices) == 0:
        # Fallback if no crossing found, use midpoint or handle error
        t_s = (t_n + t_f) / 2
    else:
        k_s = crossing_indices[0]
        t_start = t_bins[k_s]
        t_end = t_bins[k_s + 1]
        
        # Secant method refinement
        t_curr = t_start
        t_prev = t_end # Initialize with other end of bin
        for _ in range(m_secant):
            alpha_curr, _ = generator(origin + t_curr * direction, latent_code)
            alpha_prev, _ = generator(origin + t_prev * direction, latent_code)
            
            # Secant update: t_new = t_curr - alpha_curr * (t_prev - t_curr) / (alpha_prev - alpha_curr)
            # We want alpha(t) = tau. 
            # Linear interpolation: alpha(t) ≈ alpha_curr + (alpha_prev - alpha_curr) * (t - t_curr) / (t_prev - t_curr)
            # Set alpha(t) = tau => tau = alpha_curr + slope * (t - t_curr)
            # t = t_curr + (tau - alpha_curr) / slope
            if abs(alpha_prev - alpha_curr) < 1e-8:
                break
            slope = (alpha_prev - alpha_curr) / (t_prev - t_curr)
            t_new = t_curr + (tau - alpha_curr) / slope
            t_prev = t_curr
            t_curr = t_new
            
        t_s = t_curr

    # 2. Determine Sampling Interval
    if training_step > 0:
        delta_init = (t_f - t_n) / 2
        delta = max(delta_init * np.exp(-gamma * training_step), delta_min)
    else:
        delta = delta_init # Or initial large value
        
    # Clamp to bounds
    t_min_sample = max(t_n, t_s - delta)
    t_max_sample = min(t_f, t_s + delta)
    
    # 3. Render
    # Sample N points in [t_min_sample, t_max_sample]
    t_render = np.linspace(t_min_sample, t_max_sample, N_render + 1)[:-1] # Uniform sampling logic from source
    # Source formula: t_i ~ U[t_s - delta + (2i-2)/N * delta, t_s - delta + 2i/N * delta]
    # This implies uniform distribution over the interval [t_s - delta, t_s + delta]
    # Let's use standard uniform sampling within the clamped interval for implementation simplicity
    # if exact source formula is too rigid for general bounds.
    # However, source says: "sample N points uniformly in [t_s - delta, t_s + delta]"
    # and gives the CDF inversion.
    
    # Re-implementing source sampling exactly:
    # Interval I = [t_s - delta, t_s + delta]
    # Clamped Interval I_clamped = [max(t_n, t_s - delta), min(t_f, t_s + delta)]
    # If I_clamped is invalid, shift back.
    
    # For simplicity in pseudocode, assuming valid clamping:
    t_samples = np.linspace(t_min_sample, t_max_sample, N_render)
    x_samples = origin + t_samples[:, np.newaxis] * direction[np.newaxis, :]
    
    # Query generator for alpha and color
    alpha_samples, color_samples = generator(x_samples, latent_code)
    
    # Alpha Composition
    # C = sum( alpha_i * (prod_{j<i} (1 - alpha_j)) * c_i )
    # T_i = prod_{j<i} (1 - alpha_j)
    
    # Compute transmittance
    one_minus_alpha = 1.0 - alpha_samples
    transmittance = np.ones(N_render)
    for i in range(1, N_render):
        transmittance[i] = transmittance[i-1] * one_minus_alpha[i-1]
        
    # Weighted sum
    weights = transmittance * alpha_samples
    rendered_color = np.sum(weights[:, np.newaxis] * color_samples, axis=0)
    
    # 4. Loss Calculation (Training Only)
    if training_step is not None:
        # Opacity Loss
        opacity_loss = np.mean(np.log(alpha_samples) + np.log(1 - alpha_samples))
        
        # Normal Loss (requires gradient through surface point)
        # Compute normal at surface point x_s

        # Source uses ||n(x_s) - n(x_s + eps)||
        # This requires differentiable normal estimation.

## Subtopics

### GRAFs (Generative Radiance Fields)
The parent class of methods that combine GANs with NeRF-like rendering. GOF differs by predicting alpha/occupancy instead of density [S1, unofficial]. [GRAFs](52-grafs.md)

### Occupancy Networks
Methods that predict binary occupancy for surface reconstruction. GOF borrows the root-finding surface location technique from these networks. [Occupancy Networks](52-occupancy-networks.md)

## Operating characteristics
*   **Time Complexity:** GOF requires $M + m_s + N$ queries for standard rendering, or $M + m_s + 1$ for single-point surface rendering. Baselines (like pi-GAN) require $2N$ queries due to hierarchical sampling [S1, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** GOF significantly outperforms baselines on the Mean Angle Deviation (MAD) metric, indicating more compact surfaces, and is comparable on Scale-Invariant Depth Error (SIDE) [S1, unofficial].
*   **Strengths:** Combines the training stability of radiance fields (dense gradients) with the surface compactness of occupancy networks. Efficient inference possible with single-point rendering.
*   **Limitations:** Single-point rendering can make furry or complex textures over-smooth and less realistic. Best suited for solid objects with a single surface [S1, unofficial].
*   **When to use:** 3D-aware image synthesis where compact, smooth surfaces are desired (e.g., faces, solid objects).
*   **When not to use:** Scenes with complex, multi-layered, or translucent structures where single-surface assumption fails.

## Background
GOF was proposed by Xudong Xu, Xingang Pan, Dahua Lin, and Bo Dai from CUHK-SenseTime Joint Lab, MPI for Informatics, and Nanyang Technological University [S1, unofficial]. It was published on arXiv in November 2021 [S1, unofficial]. The method addresses the "shape-color ambiguity" in generative radiance fields, where discriminators are fooled by small surface perturbations that still produce realistic images, leading to diffused surfaces [S1, unofficial]. It builds on the observation that alpha values in cumulative rendering resemble occupancy values, allowing a transition from volume rendering to surface rendering [S1, unofficial].
