# Gear-NeRF

Also called: Gear-NeRF: Free-Viewpoint Rendering and Tracking with Motion-aware Spatio-Temporal Sampling

## Overview
Gear-NeRF is a dynamic scene representation method that stratifies a 4D scene into multiple "gears" based on semantic motion scales, allowing for region-specific spatio-temporal sampling resolution [S1]. It solves the inefficiency of uniform sampling in dynamic NeRFs by assigning higher-resolution feature volumes to regions with larger motion, thereby improving photo-realistic novel view synthesis and enabling free-viewpoint object tracking [S1]. Unlike standard dynamic NeRFs that use a single unified 4D volume, Gear-NeRF uses a series of parallel 4D feature volumes, one for each gear level [S1].

## How it works
**Inputs:** A set of $W$ input videos $V = \{V_1, V_2, \dots, V_W\}$ of a dynamic scene with calibrated camera poses [S1].
**Outputs:** Rendered images for novel views and time steps; tracking masks for user-selected objects [S1].

**Data Structures:**
1.  **Gear Levels:** The scene is stratified into $N_{gear}$ levels (gears), indexed by $G \in \{1, \dots, N_{gear}\}$ [S1].
2.  **4D Feature Volumes:** For each gear $G$, there is a dedicated 4D feature volume. The feature vector $f^G(\mathbf{x}, t)$ at spatial coordinate $\mathbf{x}=(x,y,z)$ and time $t$ is computed using planar factorization [S1].
3.  **Semantic Embedding:** A 4D semantic embedding is optimized to profile the scene into semantic regions, derived from powerful image segmentation models (e.g., SAM) [S1].
4.  **Gear Assignment Volume:** A separate planar-factorized 4D feature volume determines the gear level $g(\mathbf{x}, t)$ for any coordinate [S1].

**Formulas:**
The feature vector for gear $G$ at coordinate $(\mathbf{x}, t)$ is calculated as [S1]:
$$
f^G(\mathbf{x}, t) = B_1 (h_1(x, y) \bowtie k^G_1(z, t)) + B_2 (h_2(x, z) \bowtie k^G_2(y, t)) + B_3 (h_3(y, z) \bowtie k^G_3(x, t))
$$
Where:
*   $h_i(\cdot, \cdot)$ are vector-valued functions evaluated by bilinear interpolation on regularly spaced 2D feature grids embedding coordinate tuples to features of dimension $M$ [S1].
*   $k^G_i(\cdot, \cdot)$ are the spatio-temporal embeddings specific to gear $G$, also evaluated by bilinear interpolation on 2D grids [S1].
*   $\bowtie$ denotes element-wise product [S1].
*   $B_i$ denotes a linear transform mapping the products to feature vectors [S1].
*   The functions $h_j(\cdot, \cdot)$ and transforms $B_j(\cdot)$ are shared by all gears, while $k^G_j(\cdot, \cdot)$ are unique to each gear [S1].

The gear level $g(\mathbf{x}, t)$ at any spatio-temporal coordinate is computed from a planar-factorized 4D feature volume [S1]:
$$
g(\mathbf{x}, t) = \mathbf{1}^\top (h'_1(x, y) \bowtie k'_1(z, t) + \dots)
$$
(Note: The source text cuts off the full expansion of the gear assignment formula, but indicates it uses similar planar factorization with shared spatial terms $h'$ and gear-specific temporal/spatial terms $k'$ [S1]).

**Parameters:**
*   $N_{gear}$: The total number of gear levels used to stratify the scene representation based on motion scales [S1].
*   $M$: The dimension of the feature space for the embeddings [S1].

**Algorithm Steps:**
1.  **Semantic Profiling:** Optimize a 4D semantic embedding based on powerful image segmentation models (e.g., SAM) to profile the scene into semantic regions [S1].
2.  **Gear Determination:** Use the gear determination scheme (based on the semantic embedding and motion analysis) to assign each spatio-temporal coordinate $(\mathbf{x}, t)$ to a gear level $G$ [S1]. Regions with larger motion scales are assigned higher gear levels [S1].
3.  **Feature Volume Optimization:** For each gear $G$, optimize the specific spatio-temporal embeddings $k^G_i(z, t)$ and $k'_i(z, t)$ while keeping the shared spatial embeddings $h_i$ and $h'_i$ constant across gears [S1].
4.  **Spatio-Temporal Sampling:** During rendering, sample points along rays. For a point $(\mathbf{x}, t)$, determine its gear $G$ via the gear assignment volume. Retrieve the feature vector $f^G(\mathbf{x}, t)$ using the formula above [S1].
5.  **NeRF Output:** Pass the feature vector $f^G(\mathbf{x}, t)$ through a tiny MLP to predict volume density $\sigma$ and view-dependent color $\mathbf{c}$ given viewing direction $\mathbf{d}$ [S1].
6.  **Rendering:** Perform standard volume rendering integration using the sampled $\sigma$ and $\mathbf{c}$ values [S1].
7.  **Tracking (Optional):** Use the optimized 4D semantic embedding to enable free-viewpoint tracking of target objects given user prompts (e.g., clicks) [S1].

**Edge Cases and Pitfalls:**
*   **Precision:** Bilinear interpolation on 2D grids requires careful handling of coordinate normalization to $[0, 1]$ or $[-1, 1]$ ranges depending on the implementation of the grid lookup [G].
*   **Boundary Conditions:** The gear assignment volume must handle coordinates outside the scene bounding box gracefully, typically by clamping or assigning a default gear (e.g., static/background) [G].
*   **Degenerate Input:** If a region has zero motion, it should be assigned to the lowest gear level to save computational resources [S1].

## Operating characteristics
*   **Time Complexity:** Rendering time depends on the number of gears and the sampling resolution per gear. Higher gears require denser sampling, increasing cost for dynamic regions [S1].
*   **Memory Complexity:** Memory usage scales with $N_{gear} \times \text{GridSize} \times M$. Since spatial features are shared, memory is saved compared to independent 4D volumes per region, but it is higher than a single unified volume [S1].
*   **Strengths:** Improves photo-realistic dynamic novel view synthesis by allocating resources to dynamic regions; enables free-viewpoint object tracking almost for free [S1].
*   **Limitations:** Requires calibrated camera poses and input videos; relies on external segmentation models for semantic profiling [S1].
*   **When to use:** When rendering dynamic scenes with varying motion scales where uniform sampling is inefficient or insufficient for high-quality dynamic regions [S1].
*   **When not to use:** For static scenes or scenes with uniform motion where the overhead of gear stratification is not justified [S1].

## Background
Gear-NeRF was introduced in 2024 by the authors of "Gear-NeRF: Free-Viewpoint Rendering and Tracking with Motion-aware Spatio-Temporal Sampling" [S1]. It addresses the limitations of existing NeRF-based methods in handling dynamic scenes with varying motion scales and provides free-viewpoint tracking capabilities [S1]. The method builds on the principles of dynamic scene and temporal modeling [Parent](15546-dynamic-scene-and-temporal-modeling.md) by introducing a stratified representation based on motion-aware spatio-temporal sampling.
