# Coarse-Fine Dynamic Radiance Field

Also called: Compositional Radiance Field with Coarse Voxel and Fine MLP, Hybrid Encoder-Decoder Radiance Field

## Overview
The Coarse-Fine Dynamic Radiance Field is a method for novel view synthesis of dynamic scenes, specifically designed to capture high-frequency details in dynamic human heads by combining a discrete voxel grid for geometry estimation with a continuous MLP for fine-level radiance [S1]. It differs from standard NeRF by conditioning the continuous scene function on spatially-varying local animation codes retrieved from the coarse grid, and from Neural Volumes by using a hybrid representation that avoids the cubic memory complexity of high-resolution voxel grids while providing a reliable geometric prior for efficient sampling [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A sparse set of input views (typically 3 concatenated camera views) representing the current frame, camera intrinsics/extrinsics, and a global animation code $z$ derived from the encoder.
*   **Outputs:** Rendered RGB images $I_r$ and accumulated opacity $A_r$ for novel viewpoints.

**Data Structures:**
1.  **Global Animation Code ($z$):** A latent vector $z \in \mathbb{R}^{256}$ sampled from a Gaussian distribution.
2.  **Coarse Voxel Grid ($G$):** A 3D grid of dimensions $D \times D \times D \times F$, where $D=64$ and $F=68$. Each voxel at position $p$ stores:
    *   Coarse color $ec_p \in \mathbb{R}^3$
    *   Differential opacity $\sigma_{ep} \in \mathbb{R}$
    *   View-independent local animation code $f_p \in \mathbb{R}^{32}$
    *   View-dependent local animation code $f_{vp} \in \mathbb{R}^{32}$
3.  **Continuous Scene Function ($f$):** An MLP that takes positional encoded coordinates, view direction, and local animation codes to output fine color $c_p \in \mathbb{R}^3$ and differential opacity $\sigma_p \in \mathbb{R}$.

**Numbered Steps:**

1.  **Encoder (Global Code Generation):**
    *   Concatenate $N_{views}$ input views (e.g., 3) along the channel axis.
    *   Pass through a 2D convolutional network to predict parameters $\mu, \sigma \in \mathbb{R}^{256}$ of a diagonal Gaussian distribution.
    *   Sample the global animation code $z \in \mathbb{R}^{256}$ using the reparameterization trick: $z = \mu + \epsilon \odot \sigma$, where $\epsilon \sim \mathcal{N}(0, I)$ [S1].

2.  **Decoder (Coarse Grid Generation):**
    *   Initialize two 3D convolutional branches conditioned on $z$.
    *   **Branch 1 (View-Independent):** Predicts $\sigma_{ep}$ and $f_p$. Conditioned only on $z$.
    *   **Branch 2 (View-Dependent):** Predicts $ec_p$ and $f_{vp}$. Conditioned on $z$ and viewpoint $v$.
    *   Viewpoint $v$ is computed as the normalized difference between the camera location and the center of the scene [S1].
    *   Combine outputs into the voxel grid $G \in \mathbb{R}^{64 \times 64 \times 64 \times 68}$ [S1].

3.  **Coarse Volumetric Rendering:**
    *   For a ray $r$ originating at camera center $o$ with direction $d$, sample $N$ points $p_i = o + d_i \cdot r$, where $d_i$ are uniformly sampled between near plane $d_{min}$ and far plane $d_{max}$ [S1].
    *   Retrieve voxel values ($ec_{p_i}, \sigma_{ep_i}, f_{p_i}, f_{vp_i}$) via trilinear interpolation from $G$ [S1].
    *   Compute accumulated opacity $A_{er}$ and color $I_{e0_r}$:
        $$ A_{er} = \sum_{i=1}^{N} T_i \alpha_i $$
        $$ I_{e0_r} = \sum_{i=1}^{N} T_i \alpha_i ec_{p_i} $$
        where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_{ep_j} \delta_j)$, $\alpha_i = 1 - \exp(-\sigma_{ep_i} \delta_i)$, and $\delta_i = |d_{i+1} - d_i|$ [S1].
    *   Compute final coarse rendering:
        $$ I_{er} = I_{e0_r} + (1 - A_{er}) I_{bg_r} $$
        where $I_{bg_r}$ is the background color [S1].

4.  **Efficient Sampling (Fine Depth Estimation):**
    *   Compute coarse depth estimate $d_{er}$:
        $$ d_{er} = \frac{1}{A_{er}} \sum_{i=1}^{N} T_i \alpha_i d_i $$
    *   Define sampling range $\Delta d = \frac{d_{max} - d_{min}}{k}$, where $k=10$ [S1].
    *   Sample fine depths $d$ from uniform distribution $U[d_{er} - \Delta d, d_{er} + \Delta d]$ [S1].

5.  **Fine Volumetric Rendering:**
    *   For each fine sample point $p$, retrieve local animation codes $f_p, f_{vp}$ from $G$ via trilinear interpolation [S1].
    *   Apply positional encoding $\phi(\cdot)$ to position $p$ and view direction $v$ [S1].
    *   Evaluate continuous scene function $f$:
        $$ c_p, \sigma_p = f(\phi(p), \phi(v), f_p, f_{vp}) $$
    *   Compute fine accumulated opacity $A_r$ and color $I_{r}$ using the same compositing equations as coarse rendering (Eq. 2-3 in source) [S1].

**Formulas:**
*   **Positional Encoding:** $\gamma(p) = (\sin(2^0 \pi p), \cos(2^0 \pi p), \dots, \sin(2^{L-1} \pi p), \cos(2^{L-1} \pi p))$ applied to each component of $p$ and $v$ [S1].
*   **Opacity Prior Loss:** $L_\beta = \sum_{r \in R} (\log A_r + \log(1 - A_r))$ [S1].
*   **Total Loss:** $L = L_r + L_{er} + \lambda_f L_\beta + \lambda_c L_{e\beta} + \lambda_{KL} L_{KL}$ [S1].
    *   $L_r = \sum_{r \in R} ||I_r - I_{gt_r}||^2_2$
    *   $L_{KL}$ encourages smoothness in the global latent space [S1].

**Parameters:**
*   Grid Dimension $D=68$ (Note: Source says $D=64$ spatial, $F=68$ feature) [S1].
*   Latent Dimension $256$ [S1].
*   Local Animation Code Dimension $32$ per type ($f_p, f_{vp}$) [S1].
*   Sampling multiplier $k=10$ [S1].
*   Input Views: 3 concatenated views [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class CoarseFineDynamicRadianceField:
    def __init__(self, D=64, F=68, latent_dim=256, num_views=3, k=10):
        self.D = D
        self.F = F
        self.latent_dim = latent_dim
        self.num_views = num_views
        self.k = k
        
        # Encoder: 2D ConvNet -> mu, sigma
        self.encoder = Encoder2D(latent_dim=latent_dim)
        
        # Decoder: Two 3D Conv branches
        # Branch 1: View-independent (sigma_ep, f_p)
        self.decoder_branch1 = Decoder3DViewIndep(latent_dim=latent_dim, out_channels=33) # 1 for sigma, 32 for f_p
        # Branch 2: View-dependent (ec_p, f_vp)
        self.decoder_branch2 = Decoder3DViewDep(latent_dim=latent_dim, out_channels=35) # 3 for ec, 32 for f_vp
        
        # Continuous Scene Function: MLP
        self.scene_mlp = MLPSceneFunction()
        
        # Positional Encoding function (standard NeRF PE)
        self.pos_enc = PositionalEncoding()

    def encode(self, views):
        """
        views: Tensor of shape (B, num_views, C, H, W)
        Returns: z (B, latent_dim)
        """
        # Concatenate views along channel axis
        x = torch.cat([views[:, i] for i in range(self.num_views)], dim=1)
        mu, sigma = self.encoder(x)
        # Reparameterization trick
        eps = torch.randn_like(sigma)
        z = mu + eps * sigma
        return z

    def decode(self, z, viewpoint_v):
        """
        z: Tensor (B, latent_dim)
        viewpoint_v: Tensor (B, 3) normalized camera direction
        Returns: Voxel Grid G (B, D, D, D, F)
        """
        # Branch 1: View-independent
        # Output: sigma_ep (B, D, D, D, 1) and f_p (B, D, D, D, 32)
        out1 = self.decoder_branch1(z)
        sigma_ep = out1[:, :, :, :, :1]
        f_p = out1[:, :, :, :, 1:33]
        
        # Branch 2: View-dependent
        # Output: ec_p (B, D, D, D, 3) and f_vp (B, D, D, D, 32)
        out2 = self.decoder_branch2(z, viewpoint_v)
        ec_p = out2[:, :, :, :, :3]
        f_vp = out2[:, :, :, :, 3:35]
        
        # Concatenate features
        # G shape: (B, D, D, D, 1 + 32 + 3 + 32) = (B, D, D, D, 68)
        G = torch.cat([sigma_ep, f_p, ec_p, f_vp], dim=-1)
        return G

    def trilinear_interpolate(self, G, points):
        """
        G: (B, D, D, D, F)
        points: (N, 3) normalized coordinates in [-1, 1] or [0, 1] depending on implementation
        Returns: values (N, F)
        """
        # Normalize points to [-1, 1] if necessary
        # Use grid_sample or manual interpolation
        # Assuming points are normalized to [-1, 1]
        points_norm = points * 2 - 1
        points_norm = points_norm.unsqueeze(0).unsqueeze(0).unsqueeze(0) # (1, 1, 1, 1, 3)
        
        # G needs to be (B, F, D, D, D) for grid_sample
        G_perm = G.permute(0, 4, 1, 2, 3)
        
        # grid_sample expects input (N, C, D, H, W) for 3D
        # We need to sample multiple points. 
        # Simplified: assume batch size 1 for this snippet, or loop
        # Using torch.nn.functional.grid_sample
        values = F.grid_sample(G_perm, points_norm, mode='bilinear', padding_mode='zeros', align_corners=True)
        # values shape: (B, F, 1, 1, 1) -> squeeze
        return values.squeeze(-1).squeeze(-1).squeeze(-1)

    def render_coarse(self, G, rays_o, rays_d, d_min, d_max, N_samples):
        """
        rays_o: (B, 3)
        rays_d: (B, 3)
        Returns: I_er, A_er, d_er, sampled_points, sampled_codes
        """
        # Sample depths uniformly
        depths = torch.linspace(d_min, d_max, N_samples).unsqueeze(0).unsqueeze(0) # (1, 1, N)
        # Expand to batch and ray count if necessary. Assuming single ray per batch for simplicity or vectorized
        # Let's assume rays_o, rays_d are (B, 3) and we process one ray at a time or vectorized
        # For vectorized: rays_o (B, 3), rays_d (B, 3)
        # depths (B, N)
        depths = depths.expand(rays_o.shape[0], -1)
        
        # Points: p = o + d * t
        # rays_o: (B, 1, 3), rays_d: (B, 1, 3), depths: (B, N, 1)
        points = rays_o.unsqueeze(1) + rays_d.unsqueeze(1) * depths.unsqueeze(2) # (B, N, 3)
        
        # Interpolate voxel values
        # G: (B, D, D, D, F)
        # points: (B, N, 3)
        # Need to interpolate for each point
        # Flatten points for interpolation
        B, N, _ = points.shape
        points_flat = points.view(-1, 3)
        
        # Interpolate
        # Note: grid_sample requires normalized coordinates. Assuming points are in [-1, 1]
        # If points are in world space, they must be normalized relative to grid bounds
        points_norm = points_flat * 2 - 1 # Assuming grid is [-1, 1]
        points_norm = points_norm.unsqueeze(0).unsqueeze(0).unsqueeze(0) # (1, 1, 1, 1, 3)
        G_perm = G.permute(0, 4, 1, 2, 3) # (B, F, D, D, D)
        
        # grid_sample
        vals = F.grid_sample(G_perm, points_norm, mode='bilinear', padding_mode='zeros', align_corners=True)
        vals = vals.squeeze(-1).squeeze(-1).squeeze(-1) # (B, F, N) -> (B, N, F)
        vals = vals.permute(0, 2, 1)
        
        # Extract components
        # sigma_ep: index 0
        # f_p: indices 1:33
        # ec_p: indices 33:36
        # f_vp: indices 36:68
        sigma_ep = vals[:, :, 0] # (B, N)
        f_p = vals[:, :, 1:33] # (B, N, 32)
        ec_p = vals[:, :, 33:36] # (B, N, 3)
        f_vp = vals[:, :, 36:68] # (B, N, 32)
        
        # Compute alphas and Ts
        # delta_t = d_{i+1} - d_i
        deltas = torch.diff(depths, dim=1, prepend=torch.zeros(B, 1)) # (B, N)
        # alpha = 1 - exp(-sigma * delta)
        alpha = 1.0 - torch.exp(-sigma_ep * deltas)
        # T = exp(-sum_{j<i} sigma_j * delta_j)
        # Cumulative sum of sigma * delta
        sigma_delta = sigma_ep * deltas
        cum_sigma_delta = torch.cumsum(sigma_delta, dim=1)
        T = torch.exp(-torch.cat([torch.zeros(B, 1), cum_sigma_delta[:, :-1]], dim=1))
        
        # Accumulate
        A_er = torch.sum(T * alpha, dim=1) # (B,)
        I_e0 = torch.sum(T.unsqueeze(2) * alpha.unsqueeze(2) * ec_p, dim=1) # (B, 3)
        
        # Background color (assume 0 or black)
        I_bg = torch.zeros_like(I_e0)
        I_er = I_e0 + (1.0 - A_er.unsqueeze(1)) * I_bg
        
        # Coarse depth estimate
        # d_er = (1/A_er) * sum(T * alpha * d)
        weighted_depth = T * alpha * depths
        d_er = torch.sum(weighted_depth, dim=1) / (A_er + 1e-8)
        
        return I_er, A_er, d_er, points, f_p, f_vp, ec_p, sigma_ep

    def render_fine(self, rays_o, rays_d, d_min, d_max, coarse_d_er, coarse_A_er, coarse_f_p, coarse_f_vp, viewpoint_v):
        """
        Returns: I_r, A_r
        """
        # Compute delta_d
        delta_d = (d_max - d_min) / self.k
        
        # Sample fine depths
        # Uniform in [d_er - delta_d, d_er + delta_d]
        # Number of fine samples? Not specified, assume M samples
        M = 32 # Example value
        fine_depths = torch.rand(rays_o.shape[0], M) * 2 * delta_d + (coarse_d_er.unsqueeze(1) - delta_d)
        
        # Points
        points = rays_o.unsqueeze(1) + rays_d.unsqueeze(1) * fine_depths.unsqueeze(2)
        
        # Interpolate local codes from coarse grid at fine points
        # Note: In the paper, local codes are retrieved from the coarse grid at the query point p
        # We need to interpolate f_p and f_vp at the fine points
        # Re-use interpolation logic from coarse render but for fine points
        # coarse_f_p, coarse_f_vp were retrieved at coarse points. 
        # We need to retrieve them at fine points.
        # Let's assume we have a function to get codes at any point
        fine_f_p, fine_f_vp = self.get_local_codes_at_points(coarse_f_p, coarse_f_vp, points, rays_o, rays_d, d_min, d_max) 
        # Note: The source says "Feature vectors fp, fvp are obtained from the coarse voxel grid via trilinear interpolation"
        # So we must interpolate from G at the fine points.
        # Since we don't have G here, we assume we pass G or re-interpolate.
        # For this pseudocode, we assume we have access to G or the interpolation result.
        # Let's assume we re-interpolate from G.
        
        # For simplicity, let's assume we pass G to this function or re-calculate
        # In practice, you would call trilinear_interpolate(G, fine_points)
        
        # Apply Positional Encoding
        phi_p = self.pos_enc(points) # (B, M, D_pe)
        phi_v = self.pos_enc(viewpoint_v.unsqueeze(1).expand(-1, M, -1)) # (B, M, D_pe)
        
        # Concatenate local codes
        # f_p: (B, M, 32), f_vp: (B, M, 32)
        local_codes = torch.cat([fine_f_p, fine_f_vp], dim=2) # (B, M, 64)
        
        # Input to MLP: phi_p, phi_v, local_codes
        # MLP input dimension: D_pe * 2 + 64
        mlp_input = torch.cat([phi_p, phi_v, local_codes], dim=2)
        
        # Predict sigma and color
        out = self.scene_mlp(mlp_input) # (B, M, 4) -> sigma, c_r, c_g, c_b
        sigma_p = out[:, :, 0]
        c_p = out[:, :, 1:]
        
        # Compute alphas and Ts for fine rendering
        # Need deltas for fine samples
        fine_deltas = torch.diff(fine_depths, dim=1, prepend=torch.zeros(B, 1))
        alpha_fine = 1.0 - torch.exp(-sigma_p * fine_deltas)
        cum_sigma_delta_fine = torch.cumsum(sigma_p * fine_deltas, dim=1)
        T_fine = torch.exp(-torch.cat([torch.zeros(B, 1), cum_sigma_delta_fine[:, :-1]], dim=1))
        
        A_r = torch.sum(T_fine * alpha_fine, dim=1)
        I_r = torch.sum(T_fine.unsqueeze(2) * alpha_fine.unsqueeze(2) * c_p, dim=1)
        
        return I_r, A_r

    def get_local_codes_at_points(self, G, points):
        # Helper to interpolate local codes from G at arbitrary points
        # points: (B, N, 3)
        # G: (B, D, D, D, 68)
        # Returns: f_p (B, N, 32), f_vp (B, N, 32)
        B, N, _ = points.shape
        points_flat = points.view(-1, 3)
        points_norm = points_flat * 2 - 1
        points_norm = points_norm.unsqueeze(0).unsqueeze(0).unsqueeze(0)
        G_perm = G.permute(0, 4, 1, 2, 3)
        vals = F.grid_sample(G_perm, points_norm, mode='bilinear', padding_mode='zeros', align_corners=True)
        vals = vals.squeeze(-1).squeeze(-1).squeeze(-1).permute(0, 2, 1)
        f_p = vals[:, :, 1:33]
        f_vp = vals[:, :, 36:68]
        return f_p, f_vp

    def forward(self, views, rays_o, rays_d, viewpoint_v, d_min, d_max):
        z = self.encode(views)
        G = self.decode(z, viewpoint_v)
        
        # Coarse Render
        I_er, A_er, d_er, coarse_points, coarse_f_p, coarse_f_vp, _, _ = self.render_coarse(G, rays_o, rays_d, d_min, d_max, N_samples=64)
        
        # Fine Render
        # Need to interpolate local codes at fine points
        # Re-interpolate from G at fine points
        # First, get fine points
        delta_d = (d_max - d_min) / self.k
        fine_depths = torch.rand(rays_o.shape[0], 32) * 2 * delta_d + (d_er.unsqueeze(1) - delta_d)
        fine_points = rays_o.unsqueeze(1) + rays_d.unsqueeze(1) * fine_depths.unsqueeze(2)
        
        fine_f_p, fine_f_vp = self.get_local_codes_at_points(G, fine_points)
        
        I_r, A_r = self.render_fine(rays_o, rays_d, d_min, d_max, d_er, A_er, coarse_f_p, coarse_f_vp, viewpoint_v)
        # Note: render_fine above assumes local codes are passed or retrieved. 
        # Adjusted logic: pass fine_f_p, fine_f_vp to render_fine or retrieve inside.
        # For clarity, let's assume render_fine takes G and points.
        
        return I_r, I_er, A_r, A_er, z
```

## Operating characteristics
*   **Time Complexity:** Rendering involves two passes: coarse ray marching on a $64^3$ grid and fine ray marching on a smaller depth range. The coarse pass is $O(N_{coarse})$ and the fine pass is $O(N_{fine})$. The use of coarse depth to limit the fine sampling range reduces the number of MLP evaluations significantly compared to uniform sampling over the entire volume [S1].
*   **Memory Complexity:** The coarse voxel grid requires $O(D^3 \cdot F)$ memory, where $D=64$ and $F=68$. This is significantly less than a high-resolution uniform grid needed for similar detail, avoiding the cubic complexity of high-res voxels [S1]. The MLP memory is constant and small [S1].
*   **Strengths:** Captures fine details in dynamic scenes (e.g., facial expressions) better than pure MLP methods (NeRF) by using local animation codes. More memory efficient than high-res voxel methods (Neural Volumes) by using a hybrid approach [S1].
*   **Limitations:** Requires a multi-camera setup for training (e.g., 100 cameras) to generate the global animation code [S1]. The method is specific to dynamic human heads and may not generalize to other dynamic scenes without modification [S1].
*   **When to use:** When rendering dynamic human heads with high-frequency details (expressions, talking) from a multi-camera setup.
*   **When not to use:** For static scenes, single-view reconstruction, or scenes without significant dynamic local variations that can be captured by local animation codes.

## Background
The method was introduced in "Learning Compositional Radiance Fields of Dynamic Human Heads" by Gkioxari et al. (2020) [S1]. It builds upon NeRF  and Neural Volumes  (referenced as [23] and [17] in the source). The paper addresses the limitations of static Octree representations and pure MLP approaches in capturing dynamic human appearance [S1].
