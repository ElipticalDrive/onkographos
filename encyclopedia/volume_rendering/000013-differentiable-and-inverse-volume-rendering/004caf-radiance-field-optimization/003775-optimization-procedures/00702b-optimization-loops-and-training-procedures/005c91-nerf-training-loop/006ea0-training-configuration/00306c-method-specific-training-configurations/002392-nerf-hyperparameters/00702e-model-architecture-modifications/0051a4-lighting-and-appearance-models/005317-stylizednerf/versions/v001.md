# StylizedNeRF

Also called: Stylized Neural Radiance Fields

## Overview
StylizedNeRF is a method for 3D scene stylization that generates view-consistent stylized renderings from multi-view images. It solves the problem of transferring 2D artistic styles to 3D radiance fields while maintaining geometric consistency. It sets itself apart from sibling methods like [Spherical Harmonics NeRF](14480-spherical-harmonics-nerf.md) by explicitly decoupling style transfer from geometry optimization through a mutual learning strategy with a 2D stylization network, rather than modifying the radiance field's spectral representation or lighting model directly.

## How it works
**Inputs and Outputs:**
- **Inputs:** A set of $N$ input images $\{I_i\}$ with corresponding camera poses. A target style image $I_{style}$.
- **Outputs:** A stylized NeRF model capable of rendering stylized views of the scene.

**Data Structures:**
The method utilizes two primary components:
1.  **Stylized NeRF:** A standard NeRF architecture (coarse and fine MLPs) representing the scene's geometry and base appearance.
2.  **2D Stylization Network:** A pre-trained or learnable 2D image-to-image translation network (e.g., based on WCT or AdaIN) that maps content features to style features.
3.  **Learnable Latent Codes:** A set of latent vectors $\mathbf{z}$ used to resolve ambiguities in the 2D stylization process, ensuring view consistency.

**Method Steps:**
1.  **Initialization:** Initialize the Stylized NeRF parameters $\theta_{NeRF}$ and the 2D Stylization Network parameters $\theta_{2D}$. Initialize learnable latent codes $\mathbf{z}$.
2.  **Forward Pass (NeRF):** For a given ray $r$, sample points $\mathbf{x}_i$ along the ray. Query the Stylized NeRF to obtain volume density $\sigma_i$ and base color $\mathbf{c}_i$. Compute transmittance $T_i$ and opacity $\alpha_i$. Render the base color $\hat{\mathbf{c}}_{base}(r)$ using standard volume rendering:
    $$
    \hat{\mathbf{c}}_{base}(r) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i
    $$
3.  **2D Stylization:** Pass the rendered base image (or patches thereof) through the 2D Stylization Network. The network uses the learnable latent codes $\mathbf{z}$ to guide the style transfer, producing a stylized image $\hat{I}_{stylized}$.
4.  **Loss Computation:**
    -   **Content Loss:** Measures the difference between the stylized output and the original content structure.
    -   **Style Loss:** Measures the statistical similarity (e.g., Gram matrix) between the stylized output and the target style image.
    -   **Geometry Consistency Loss:** Ensures that the stylized renderings maintain the same geometric structure as the input views, often by comparing depth maps or using a self-distillation loss.
5.  **Mutual Learning Optimization:** Update both $\theta_{NeRF}$ and $\theta_{2D}$ simultaneously. The NeRF is optimized to provide a consistent geometric base for the 2D network, while the 2D network is optimized to apply the style while respecting the latent codes that enforce consistency.
6.  **Iteration:** Repeat steps 2-5 for all rays/views until convergence.

**Parameters:**
-   Learning rates for NeRF and 2D network: Not given in the sources.
-   Number of samples per ray: Not given in the sources.
-   Latent code dimension: Not given in the sources.

**Edge Cases and Pitfalls:**
-   **Ambiguity in 2D Stylization:** Without latent codes, 2D stylization may produce inconsistent styles across different views of the same 3D point. The learnable latent codes mitigate this [S1].
-   **Geometric Drift:** Aggressive style transfer may distort geometry. The geometry consistency loss prevents this [S1].

## Subtopics

### LAENeRF
LAENeRF is a variant for local stylization. It uses a 3D grid for content selection and region growing for smooth transitions between regions. It introduces a NeRF-like module for palette-based color decomposition within selected regions and incorporates style loss to maintain low processing time [S1].

## Operating characteristics
-   **Time Complexity:** Not given in the sources.
-   **Memory Complexity:** Not given in the sources.
-   **Strengths:** Ensures view-consistent stylization by handling 2D ambiguities via latent codes. Mutual learning allows joint optimization of geometry and style.
-   **Limitations:** Requires careful balancing of style and geometry losses. Performance depends on the quality of the underlying 2D stylization network.
-   **When to use:** When view-consistent stylization of a 3D scene is required, and the style can be approximated by a 2D network.
-   **When not to use:** When local or partial stylization is needed (use LAENeRF instead) or when arbitrary style transfer with a single model is required (use PNeSM).

## Background
StylizedNeRF was introduced in [102] (cited in [S1]). It builds on the standard NeRF framework and integrates techniques from 2D image stylization. It addresses the limitations of previous methods that either failed to maintain geometric consistency or required separate models for different styles.
