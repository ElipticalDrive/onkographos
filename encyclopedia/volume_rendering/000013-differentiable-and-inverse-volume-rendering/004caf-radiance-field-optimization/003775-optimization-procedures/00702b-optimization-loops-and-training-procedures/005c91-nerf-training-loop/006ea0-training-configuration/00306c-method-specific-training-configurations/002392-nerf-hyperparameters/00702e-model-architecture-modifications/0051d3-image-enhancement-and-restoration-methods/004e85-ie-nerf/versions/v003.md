# IE-NeRF

Also called: IE-NeRF Pipeline, Image-dependent NeRF with transient mask inpainting, Inpainting Enhanced NeRF

## Overview
IE-NeRF is a neural radiance field method that enhances novel view synthesis in uncontrolled "in-the-wild" environments by separating static scene rendering from transient occlusions (e.g., pedestrians, vehicles) using an image-dependent feature encoding and a pre-trained inpainting module, rather than learning a 3D transient field [S1]. Unlike siblings such as [DeblurNeRF](11964-deblurnerf.md) or [Sharp-NeRF](14270-sharp-nerf.md) which address blur or sharpness, IE-NeRF specifically targets transient artifacts. It differs from [NeRF-W](11964-deblurnerf.md) by using a single MLP to predict both static properties and a 2D transient mask, which guides an external inpainting network to generate supervision signals, avoiding the complexity of dual NeRF pipelines or prior-assisted semantic segmentation [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of uncontrolled images $\{I_i\}$ with corresponding camera poses (origin $o$ and direction $d$).
*   **Outputs:** A static radiance field capable of rendering novel views of the static scene, free from transient occlusions.

**Data Structures and Layout:**
The model consists of three main modules [S1]:
1.  **CNN Encoder ($E_E$):** Encodes input image $I_i$ into a feature latent vector $\ell_i \in \mathbb{R}^k$.
2.  **NeRF MLPs:**
    *   **MLP$_{\theta_1}$:** 8 fully connected layers, 256 hidden units. Input: Positional encoded position $\gamma_x(r(t))$. Output: Static density $\sigma(t)$ and intermediate feature $z_i(t)$.
    *   **MLP$_{\theta_2}$:** 8 fully connected layers, 256 hidden units. Input: Concatenation of $\ell_i$, $\gamma_d(d)$, $z_i(t)$, and original position $(x,y,z)$. Output: Image-dependent radiance $c_i(t)$ and transient mask embedding $\ell_t$.
    *   **Transient Mask Head:** A fully connected layer with 128 channels and Sigmoid activation. Input: $\ell_t$ and 2D pixel location $l_{ij}=(u,v)$. Output: Transient mask probability $M_{ij}$.
    *   **Static Color Head:** A fully connected layer with 128 channels and Sigmoid activation. Input: Output of MLP$_{\theta_2}$. Output: Static RGB color $c$.
3.  **Inpainting Module ($G_\Delta$):** Pre-trained LaMa model. Input: Four-channel tensor $x' = \text{stack}(x \odot m, m)$, where $x$ is the masked image and $m$ is the binary mask. Output: Restored static image $\hat{I}_r$ and repaired depth map $\hat{D}_r$.

**Numbered Steps:**

1.  **Image Encoding:** Encode each input image $I_i$ into a feature latent vector $\ell_i$ using the CNN encoder $E_E$ [S1].
2.  **Ray Sampling:** For a camera ray $r(t) = o + td$, sample $K$ points $t_k$ along the ray.
3.  **Static Feature Prediction:** Process the pose position $r(t)$ through MLP$_{\theta_1}$ with integrated positional encoding $\gamma_x$ to output density $\sigma(t)$ and intermediate feature $z_i(t)$ [S1]:
    $$ [\sigma(t), z_i(t)] = \text{MLP}_{\theta_1}[\gamma_x(r(t))] $$
4.  **Radiance and Mask Embedding:** Feed the directional vector $d$ (with encoding $\gamma_d$), the intermediate feature $z_i(t)$, the original position $(x,y,z)$, and the image embedding $\ell_i$ into MLP$_{\theta_2}$ to predict image-dependent radiance $c_i(t)$ and transient mask embedding $\ell_t$ [S1]:
    $$ c_i(t) = \text{MLP}_{\theta_2}[\gamma_d(d), z_i(t)] $$
5.  **Transient Mask Generation:** Generate a 2D pixel-wise transient mask probability $M_{ij}$ by mapping the 2D pixel location $l_{ij}$ and transient embedding $\ell_t$ through linear layers $E_\phi$ [S1]:
    $$ M_{ij} = E_\phi(l_{ij}, \ell_t) $$
    The mask is thresholded to create a binary mask $m_{ij}$ for the inpainting module [S1].
6.  **Volumetric Rendering:** Compute the approximated pixel color $\hat{C}_i(r)$ using the static density $\sigma(t)$ and image-dependent radiance $c_i(t)$ [S1]:
    $$ \hat{C}_i(r) = \sum_{k=1}^{K} T(t_k) \cdot \alpha(\sigma(t_k)\delta_k) \cdot c_i(t_k) $$
    where $T(t_k) = \exp\left(-\sum_{k'=1}^{k-1} \sigma(t_{k'}) \cdot \delta_{k'}\right)$ is the transmittance.
7.  **Inpainting Supervision Generation:**
    *   Apply the thresholded transient mask $m_{ij}$ to the original image $I_i$ to create a masked image.
    *   Feed the masked image and mask into the pre-trained LaMa inpainting network $G_\Delta$ to produce the restored static image $\hat{I}_r$ [S1].
    *   Render depth maps $\hat{D}_s$ from the static NeRF and inpaint them using LaMa guided by the transient mask to produce restored depth maps $\hat{D}_r$ for geometry supervision [S1].
8.  **Optimization:** Optimize the model by minimizing the total loss function $L$ [S1]:
    $$ L = \alpha \sum_{ij} L_s + \beta \sum_{ij} L_t + \gamma \sum_i L_{\text{LPIPS}} + \rho \sum_i L_{\text{depth}} $$
    *   **Static Loss ($L_s$):** Mean squared error between rendered static color $\hat{C}_s$ and ground truth $C$ outside the transient mask, plus LPIPS loss inside the mask [S1].
    *   **Transient Loss ($L_t$):** Balances occlusion and reconstruction errors [S1]:
        $$ L_t = \sum_{ij} (1 - M_{ij}) \| C(r_{ij}) - \hat{C}_s(r_{ij}) \|^2 + \lambda M_{ij} \| C_s(r_{ij}) - \hat{C}_s(r_{ij}) \|^2 $$
        where $\lambda$ balances static/transient components. The first term handles occlusion error (comparing rendered static to original image outside mask), and the second term handles reconstruction error (comparing rendered static to repaired ground truth inside mask) [S1].
    *   **Depth Loss ($L_{\text{depth}}$):** $\ell_2$ distance between rendered static depth $\hat{D}_s$ and inpainted depth $\hat{D}_r$ [S1].

**Parameters:**
*   $\lambda$: Parameter adjusting the balance between transient and static components in $L_t$ [S1].
*   $\alpha, \beta, \gamma, \rho$: Weights for static loss, transient loss, perceptual loss, and depth loss respectively [S1].
*   $L$: Hyperparameter determining the maximum encoded frequency in the positional encoding [S1].
*   $r$: Transient mask factor, defined as the ratio of transient pixels to the total image area [S1].

**Subtopics:**
*   **IE-NeRF(IM):** Uses an independent network without spatial constraints to generate the transient mask, lacking prior supervision and leading to artifacts [S1].
*   **IE-NeRF(SM):** Leverages a pre-trained semantic model (MaskDINO) to generate the transient mask, predefining transient objects (people, cars, etc.). It struggles with smaller occluders and shadows [S1].

## Operating characteristics
*   **Time and Memory Complexity:** The method uses a single NeRF pipeline (8 layers, 256 units) plus a CNN encoder and a LaMa inpainting module. LaMa is a ResNet-like architecture with 3 downsampling, 12 FFC residual, and 3 upsampling blocks. This adds significant inference time for the inpainting step during training supervision generation, but the NeRF itself is standard size.
*   **Measured Performance:** On the Phototourism dataset (Brandenburg Gate), IE-NeRF achieved PSNR 25.33, SSIM 0.898, and LPIPS 0.158, outperforming NeRF (18.90/0.816/0.232), NeRF-W (24.17/0.891/0.167), and Ha-NeRF (24.04/0.877/0.139) [S1].
*   **Scaling:** The method is evaluated on 2x downsampled images. It struggles with small datasets and sparse inputs because the transient mask lacks sufficient information to infer and guarantee the inpainting process [S1].
*   **Strengths:** Effectively separates transient components in uncontrolled environments without needing 3D transient fields or semantic priors. Uses frequency regularization (RegFre-IPE) to stabilize training [S1].
*   **Limitations:** Inpainting modules may produce blurry results and inconsistencies across views. High-frequency signals cause instability in transient separation. Requires pre-filtering of low-quality images (NIMA < 3) and images with >80% transient occupancy [S1].

## Background
IE-NeRF was proposed by Wang et al. from Sun Yat-sen University and Pengcheng Laboratory, published in *Neurocomputing* in 2024 (arXiv:2407.10695) [S1]. It addresses the limitations of standard NeRF and NeRF-W in "in-the-wild" scenarios where transient objects (pedestrians, vehicles) and varying illumination degrade novel view synthesis. Unlike NeRF-W which uses a 3D transient field, IE-NeRF introduces an image-dependent 2D mask map and an inpainting module to restore the static scene [S1].
