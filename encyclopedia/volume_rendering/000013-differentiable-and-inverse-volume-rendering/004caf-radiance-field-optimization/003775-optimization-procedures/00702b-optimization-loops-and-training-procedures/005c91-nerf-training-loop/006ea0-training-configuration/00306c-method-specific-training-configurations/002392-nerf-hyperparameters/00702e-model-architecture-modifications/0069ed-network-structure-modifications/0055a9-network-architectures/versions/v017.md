# Network Architectures
Also called: NeRF Network Architectures

## Overview
NeRF network architectures define the specific neural network structures used to map spatial coordinates and view directions to volume density and color [S1, S3, S5, S6]. While the standard NeRF uses a single multi-layer perceptron (MLP) for both density and color, various modifications introduce multi-network setups, residual connections, dynamic/static splits, or specific output fields to address challenges such as transparency [S3], dynamic scenes [S5], and mobile deployment [S1]. These architectures set themselves apart from the baseline by altering the input conditioning (e.g., time, appearance codes), the internal connectivity (e.g., mixnets, multiplicative interactions), or the output structure (e.g., blend weights, scene flow) to enable specific rendering capabilities [S1, S3, S5, S6].

## How it works
The core mechanism involves defining one or more MLPs that take geometric and view-dependent inputs, often processed through positional encoding, to produce radiance field parameters [S1, S5, S6]. The specific architecture depends on the target application (e.g., static, dynamic, transparent, or mobile) [S1, S3, S5, S6].

### Standard NeRF Baseline
The baseline architecture consists of two MLPs [S6]:
1. **Density Network ($F_\sigma$):** Maps 3D position $\mathbf{x}$ to volume density $\sigma$ [S6].
2. **Color Network ($F_c$):** Maps 3D position $\mathbf{x}$, view direction $\mathbf{d}$, and optionally an appearance code $\mathbf{c}_{app}$ to view-dependent color $\mathbf{c}$ [S6].
Both networks typically use ReLU activations and a final linear layer [G]. The density output is often passed through a softplus or exp function to ensure positivity [S6].

### Multi-Input MLP (mi-MLP)
As described in the sibling article, this architecture processes multiple samples or inputs simultaneously to improve efficiency or context awareness [16599-multi-input-mlp-mi-mlp.md] [G].

### Specific Architectural Variants

#### 1. MobileNeRF Architecture (A, F, H)
This architecture separates the network into components used during training and inference [S1].
* **Networks A and F:** These are MLPs used during training but not inference [S1]. They utilize the standard NeRF MLP design but with increased hidden layer sizes [S1].
    * **Hidden Layer Size:** 384 neurons (increased from the standard 256) to allow more computational budget during training [S1].
* **Network H:** A small MLP used for inference [S1].
    * **Structure:** Two hidden layers, each with 16 neurons [S1].
* **Texture Storage:** Features are stored in 8-dimensional vectors, packed into two 4-channel PNG images [S1]. The alpha channel is squeezed into the first feature channel (alpha is 1 if the first feature is non-zero) [S1].

#### 2. Dynamic Scene Network Architecture
Divides the scene into static and dynamic components modeled by two separate MLPs [S5].
* **Dynamic Network ($F_{\Theta}^{dy}$):**
    * **Inputs:** Positional encoding of position $\gamma(\mathbf{x})$, direction $\gamma(\mathbf{d})$, and time $\gamma(t)$ [S5].
    * **Outputs:** Color $\mathbf{c}_t$, density $\sigma_t$, scene flow $\mathcal{F}_t$, and disocclusion weights $\mathcal{W}_t$ [S5].
    * **Formula:**
        $$ (\mathbf{c}_t, \sigma_t, \mathcal{F}_t, \mathcal{W}_t) = F_{\Theta}^{dy}(\gamma(\mathbf{x}), \gamma(\mathbf{d}), \gamma(t)) $$
* **Static Network ($F_{\Theta}^{st}$):**
    * **Inputs:** Positional encoding of position $\gamma(\mathbf{x})$ and direction $\gamma(\mathbf{d})$ [S5].
    * **Outputs:** Color $\mathbf{c}$, density $\sigma$, and blending weight $v$ [S5].
    * **Formula:**
        $$ (\mathbf{c}, \sigma, v) = F_{\Theta}^{st}(\gamma(\mathbf{x}), \gamma(\mathbf{d})) $$
* **Sampling:** Uses equidistant sampling along rays instead of hierarchical sampling [S5].

#### 3. NeRF with Blend Weight Field
Modifies the standard radiance field architecture to handle dynamic human bodies by introducing a blend weight field [S6].
* **Radiance Field Networks ($F_\sigma, F_c$):** Follow the original NeRF architecture [S6].
    * **Sampling:** Single-level NeRF, sampling 64 points along each camera ray [S6].
* **Blend Weight Field Network ($F_{\Delta w}$):**
    * **Structure:** Almost identical to $F_\sigma$ [S6].
    * **Output Layer:** Has 24 channels [S6].
    * **Activation:** Applies $\exp(\cdot)$ to the output [S6].
* **Codes:** Appearance code $\mathbf{l}_i$ and blend weight field code $\boldsymbol{\psi}_i$ both have dimensions of 128 [S6].

#### 4. Residual-NeRF-S (Ablation Variant)
An ablation of Residual-NeRF that merges background and residual NeRFs by simply adding their outputs before activation, rather than using a Mixnet [S3].
* **Background Network ($\Phi_{bg}$):**
    * **Inputs:** $h(x, y, z, \theta, \phi)$ (position and view angles).
    * **Outputs:** $(c'_{bg}, \sigma_{bg})$.
* **Residual Network ($\Phi_{res}$):**
    * **Inputs:** $h(x, y, z, \theta, \phi)$.
    * **Outputs:** $(c'_{res}, \sigma_{res})$.
* **Merging:**
    * **Color:** $c_{bg+res} = S(c'_{bg} + c'_{res})$, where $S(x) = \frac{1}{1 + e^{-x}}$ (Sigmoid).
    * **Rendering Equation:**
        $$ \hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - \exp(-(\sigma_{bg} + \sigma_{res})_i \delta_i)) (c_{bg+res})_i $$
    * **Transmittance:** $T_i = \exp(-\sum_{j=1}^{i-1} (\sigma_{bg} + \sigma_{res})_j \delta_j)$ [S3].

#### 5. OccNet (Single-Level NeRF)
A single-level version of NeRF that does not leverage positional encodings [S4, unofficial].
* **Structure:** Single transformation level [S4, unofficial].
* **Performance:**
    * 2D Images: 13.90 PSNR / 0.437 SSIM [S4, unofficial].
    * Radiance Field: 20.60 PSNR / 0.849 SSIM [S4, unofficial].
    * Training Time: 02:17 / 100:23 [S4, unofficial].
    * Model Size: 0.38 / 0.43 [S4, unofficial].

### Pseudocode: Dynamic Scene Network Forward Pass
```python
def concatenate(*tensors):
    """Concatenates 1D lists/tensors along the last dimension."""
    result = []
    for t in tensors:
        result.extend(t)
    return result

def dynamic_scene_forward(x, d, t, pos_enc, static_net, dynamic_net):
    """
    Forward pass for the Dynamic Scene Network Architecture.
    
    Args:
        x: 3D position vector (list of 3 floats)
        d: View direction vector (list of 3 floats)
        t: Time scalar (float)
        pos_enc: Function to apply positional encoding gamma()
        static_net: MLP for static component
        dynamic_net: MLP for dynamic component
        
    Returns:
        final_color: Rendered color (list of 3 floats)
        final_sigma: Volume density (float)
    """
    # 1. Encode inputs
    x_enc = pos_enc(x)
    d_enc = pos_enc(d)
    t_enc = pos_enc(t)
    
    # 2. Static Network Forward
    # Inputs: x_enc, d_enc
    static_in = concatenate(x_enc, d_enc)
    static_out = static_net(static_in)
    c_st = static_out[:3]      # Color
    sigma_st = static_out[3]   # Density
    v = static_out[4]          # Blending weight
    
    # 3. Dynamic Network Forward
    # Inputs: x_enc, d_enc, t_enc
    dynamic_in = concatenate(x_enc, d_enc, t_enc)
    dynamic_out = dynamic_net(dynamic_in)
    c_dy = dynamic_out[:3]     # Color
    sigma_dy = dynamic_out[3]  # Density
    # Scene flow and disocclusion weights are also output but not used in basic color rendering
    # F_t = dynamic_out[4:7]
    # W_t = dynamic_out[7:10]
    
    # 4. Blend Static and Dynamic
    # Linear blend for sigma and color using weight v (exact blending function not specified in source) [G]
    sigma_final = sigma_st * (1 - v) + sigma_dy * v
    c_final = [c_st[i] * (1 - v) + c_dy[i] * v for i in range(3)]
    
    return c_final, sigma_final
```

## Subtopics

### [MIMO-DONeRF](16217-mimo-donerf.md)
MIMO-DONeRF is a method that applies the Multi-Input Multi-Output (MIMO) neural rendering concept to the DONeRF architecture. It modifies the shading network to accept multiple spatial inputs and view directions simultaneously, producing multiple color and density outputs per forward pass. This approach improves inference speed compared to increasing the number of samples in standard DONeRF, while maintaining or improving image quality by allowing the network to accumulate neighbor information through grouped samples. It differs from standard DONeRF by processing $N_p$ samples in parallel rather than sequentially, and from MIMO-NeRF by being specifically adapted to the two-network structure (depth oracle and shading) of DONeRF.

### [Point-NeRF Adaptation for Object Manipulation](16395-point-nerf-adaptation-for-object-manipulation.md)
This method adapts the Point-NeRF architecture to enable 3D scene geometry decomposition and manipulation from 2D images. It solves the problem of editing specific objects within a complex scene by replacing the standard Multi-View Stereo (MVS) point cloud generation with ground-truth dense data during training and using a diffusion model to infer object codes for manipulation. It differs from standard Point-NeRF by integrating a DM-NeRF module to map spatial locations to object codes and modifying the rendering pipeline to support point transformation.

### [Sparse Latent Space for 4D Novel View Synthesis (SLS4D)](18112-sparse-latent-space-for-4d-novel-view-synthesis-sls4d.md)
SLS4D is a method for 4D novel-view synthesis that represents dynamic radiance fields using a learnable sparse latent space, reducing network parameters compared to dense grid discretizations while maintaining high-frequency detail via attention-based interpolation. It differs from dense grid methods (like TiNeuVox) by avoiding the $O(N^3TF)$ space complexity of 4D grids, and from per-image latent code methods by offering better generalization across time through continuous temporal interpolation.

### [Neural Feature Fusion Fields (N3F)](18114-neural-feature-fusion-fields-n3f.md)
Neural Feature Fusion Fields (N3F) is a method that distills dense 2D image features from a pre-trained teacher network into a 3D neural field (student) via differentiable volumetric rendering, enabling 3D-aware feature representation. Unlike Semantic NeRF or Panoptic NeRF which fuse discrete semantic labels, N3F fuses continuous dense feature vectors, allowing for open-world applications without manual labels. It differs from standard feature distillation because the student operates in 3D world space (ensuring spatial consistency) while the teacher operates in 2D image space.

### [CLNeRF Architecture with Embeddings](18159-clnerf-architecture-with-embeddings.md)
CLNeRF is a model architecture modification for NeRF that enables continual learning by incorporating scene changes (appearance and geometry) over time within a single model, preventing model size growth as new scans are added. It sets itself apart from sibling methods like MIMO-DONeRF and SLS4D by using explicit, trainable per-scan embedding vectors rather than latent space compression or multi-instance networks, allowing for efficient updates and low overhead for generative replay.

### [Mutual Information Gradient Shaping](18669-mutual-information-gradient-shaping.md)
Mutual Information Gradient Shaping (MIGS), implemented as JacobiNeRF, is a training regularization technique that shapes the tangent space of a Neural Radiance Field (NeRF) to encode semantic correlations between scene entities [G]. Unlike first-order approaches that distill 2D features into 3D radiance channels or treat labels as separate output channels, MIGS aligns the Jacobians of correlated entities to maximize their mutual information under random weight perturbations, enabling efficient sparse label propagation and semantic consensus [G].

### [Multi-Level Neural Scene Graph](19889-multi-level-neural-scene-graph.md)
Multi-Level Neural Scene Graph (NSG) is a scene representation that decomposes an environment into a graph of static, dynamic, and temporal nodes to model urban environments with moving objects and appearance variations. It distinguishes itself from sibling architectures by explicitly separating the radiance field into a static component $\phi$ and a dynamic component $\psi$, conditioned on sequence-level and object-level latent vectors respectively, enabling the disentanglement of scene-dependent appearance from object texture.

### [NAN (Noise-Aware NeRFs)](20279-nan-noise-aware-nerfs.md)
NAN is a burst-denoising method that extends the IBRNet architecture to handle degraded noisy images, such as those captured in low-light conditions, by modifying feature extraction, aggregation, and color blending to be noise-aware. Unlike standard NeRFs that synthesize novel views, NAN fixes an existing view image by leveraging multiple noisy inputs of the same scene. It distinguishes itself from its sibling [MIMO-DONeRF](16217-mimo-donerf.md) and [Point-NeRF Adaptation for Object Manipulation](16395-point-nerf-adaptation-for-object-manipulation.md) by explicitly modeling spatial noise statistics through 3D blending kernels and cross-view variance features, rather than relying solely on single-pixel cross-view consistency.

### [Multiplicative Interaction Module](21736-multiplicative-interaction-module.md)
The Multiplicative Interaction Module (MIM) is a neural component that generates conditional inputs for a NeRF by computing multiplicative interactions between expression, identity, and optional latent codes to improve facial disentanglement and rendering quality. It sets itself apart from sibling methods like [MIMO-DONeRF](16217-mimo-donerf.md) or [Point-NeRF Adaptation for Object Manipulation](16395-point-nerf-adaptation-for-object-manipulation.md) by explicitly modeling higher-order (second and third) multiplicative dependencies between semantic codes rather than relying on linear concatenation or simple additive fusion.

### [Part-Wise NARF (NARFP)](23078-part-wise-narf-narfp.md)
Part-Wise NARF (NARFP) is a neural articulated radiance field method that models an articulated object by training a separate Ray-Traced NeRF (RT-NeRF) for each rigid part, combining their outputs to estimate global density and color. It differs from holistic approaches by explicitly computing rigid transformations via forward kinematics, thereby avoiding implicit transformation issues and part dependency problems inherent in other methods.

### Pyramid NeRF
Pyramid NeRF accomplishes rapid NeRF training and inference through the application of an image pyramid and a strategy based on frequency optimization [S2]. It utilizes a "low-frequency-first, high-frequency-second" approach, substituting large MLPs with thousands of smaller ones via progressive segmentation, markedly enhancing both training and inference efficiency [S2]. Furthermore, the introduction of a sampling approach that is aware of depth aims to enhance the quality of rendering and hasten the convergence of training [S2]. The experimental findings reveal that Pyramid NeRF enhances training and inference speeds by 15x and 805x, respectively, and notably betters structural and perceptual resemblance relative to the original NeRF [S2].

### Residual-NeRF-S
Residual-NeRF-S is an ablation variant of Residual-NeRF where background and residual NeRFs are merged by simply adding their outputs before activation, instead of using a Mixnet [S3]. Residual-NeRF-S produces worse depth and view reconstruction compared to Residual-NeRF with Mixnet, especially for partially opaque objects [S3].

### OccNet
OccNet (Occupancy Networks) is a single-level version of NeRF that does not leverage positional encodings [S4, unofficial]. Performance on 2D Images: 13.90 PSNR / 0.437 SSIM [S4, unofficial]. Performance on Radiance Field: 20.60 PSNR / 0.849 SSIM [S4, unofficial]. Training Time: 02:17 / 100:23 [S4, unofficial]. Model Size: 0.38 / 0.43 [S4, unofficial].

## Operating characteristics
* **Standard NeRF:** High memory usage due to large MLPs and extensive sampling. Slow training and inference times [G].
* **MobileNeRF:** Optimized for mobile devices. Networks A and F are training-only, allowing larger hidden layers (384) without inference overhead. Network H is small (16 neurons/layer) for fast inference. Texture storage is optimized for hardware constraints (power of 2, max 4096x4096) [S1].
* **Dynamic Scene Network:** Requires equidistant sampling, which may be less efficient than hierarchical sampling but simplifies the architecture for dynamic scenes. Outputs additional fields (scene flow, disocclusion) increasing output dimensionality [S5].
* **Blend Weight Field:** Adds complexity with an additional network $F_{\Delta w}$ with 24 output channels and exp activation. Appearance codes are 128-dimensional [S6].
* **Residual-NeRF-S:** Simpler merging strategy (addition + sigmoid) compared to Mixnet, but results in lower quality for transparent objects [S3].
* **OccNet:** Significantly lower performance (10dB PSNR drop) compared to multi-level NeRF with positional encodings, highlighting the importance of frequency optimization [S4, unofficial].
* **Pyramid NeRF:** Offers massive speedups (15x training, 805x inference) but relies on progressive segmentation and depth-aware sampling [S2].

## Background
NeRF architectures have evolved from the original single-MLP design [S6] to address specific limitations such as dynamic scenes [S5] and transparency [S3]. The introduction of positional encodings was a critical step, as single-level models without them (OccNet) showed significantly reduced performance [S4, unofficial]. Subsequent works have explored multi-network structures, residual learning, and specialized output fields to handle complex scene properties [S1, S3, S5, S6].
