# GALA3D

Also called: GALA3D
## Overview
GALA3D is a two-stage method for 3D scene generation that leverages both object-level and scene-level models to achieve realistic composition [S1]. It addresses the challenge of generating coherent 3D scenes by first synthesizing individual objects and then composing them into a global environment [S1]. Unlike single-stage text-to-3D methods, GALA3D separates the generation of local geometry (objects) from global layout (scenes), using MVDream for object synthesis and a scene-level diffusion model for composition [S1].

## How it works
**Inputs and Outputs:**
- Input: Text prompt describing the desired scene.
- Output: A composed 3D scene representation (e.g., point cloud or Gaussian splats) containing multiple objects arranged in a scene.

**Data Structures:**
- Object-level representation: Generated by MVDream, typically a point cloud or 3D Gaussian Splatting (3DGS) representation [S1].
- Scene-level representation: A collection of object-level representations arranged in a spatial layout [S1].

**Steps:**
1. **Object Generation:** Use the object-level text-to-3D model MVDream [246] to generate realistic 3D objects from the text prompt [S1]. MVDream provides multi-view diffusion guidance to ensure geometric consistency [S1].
2. **Scene Composition:** Use a scene-level diffusion model to compose the generated objects into a coherent 3D scene [S1]. This stage handles the spatial arrangement and interaction between objects [S1].
3. **Refinement (Optional):** Some implementations may include a stage to remove outliers in the point cloud and refine the 3DGS representation through two-stage optimization (coarse training followed by refinement) [S1].

**Parameters:**
- Text prompt: Defines the semantic content of the scene.
- MVDream model: Pre-trained text-to-3D model [S1].
- Scene-level diffusion model: Pre-trained model for scene composition [S1].

**Edge Cases and Pitfalls:**
- Outliers in the generated point cloud may need removal to ensure clean geometry [S1].
- The quality of the final scene depends heavily on the accuracy of the object-level generation and the effectiveness of the scene-level composition [S1].

## Subtopics

### Lightplane-augmented Viewset Diffusion
This process simultaneously generates multiple views of the object as well as its 3D model [S2]. During inference, the viewset is initialized with Gaussian noise [S2]. The model iteratively denoises the viewset by applying a reconstruction model [S2]. Each image $I_i$ in the viewset is replaced with $I_i^t = \alpha_t I_i + \sigma_t \epsilon_i$ where $t$ is the noising schedule, $\alpha_t$ and $\sigma_t = \sqrt{1 - \alpha_t^2}$ are the noise level, and $\epsilon_i$ is a random Normal noise vector [S2]. This approach boosts scalability by increasing the amount of 2D information lifted to 3D and allows for larger model and batch sizes during training due to memory savings [S2].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** The Lightplane-augmented variant significantly reduces memory usage, allowing for increased model and batch sizes during training [S2].
- **Performance:** Benchmarks show improvements in scalability and speed for 3D tasks [S2].
- **Strengths:** Enables generation of complex scenes with multiple objects; scalable to large-scale 3D models [S1, S2].
- **Limitations:** Requires two separate models (object-level and scene-level); quality depends on the pre-trained models [S1].

## Background
GALA3D was introduced to explore 3D scene generation by combining object-level and scene-level generation processes [S1]. It builds on the idea of using text-to-3D models like MVDream for object synthesis and extends it to scene-level composition [S1]. The method is part of the broader effort to improve the realism and coherence of generated 3D scenes [S1].
