# Feature Fields

Also called: Generalized NeRF, Semantic Fields

## Overview
Feature Fields generalize the Neural Radiance Field (NeRF) formulation to predict arbitrary per-point feature signals $\mathbf{f}$ in addition to color $\mathbf{c}$ and density $\sigma$ [S1, Parent, unofficial]. This allows the radiance field to encode semantic labels, geometric properties, or high-dimensional embeddings, enabling tasks such as zero-shot segmentation, object manipulation, and 3D detection [S1, unofficial][S3, S4]. Unlike sibling methods that may focus on specific downstream applications like pose estimation [PI-NeRF](12124-pi-nerf.md) or gaze redirection [GazeNeRF](12127-gazenerf.md), this family provides the general mechanism for lifting 2D feature observations into a consistent 3D representation [Parent].

## Shared principles
The baseline NeRF architecture [Parent](3065-nerf-hyperparameters.md) defines a continuous volumetric scene representation $F_\Theta: (\mathbf{x}, \mathbf{d}) \rightarrow (\sigma, \mathbf{c})$, where $\mathbf{x} \in \mathbb{R}^3$ is the spatial position, $\mathbf{d} \in \mathbb{R}^3$ is the viewing direction, $\sigma$ is the volume density, and $\mathbf{c} \in \mathbb{R}^3$ is the view-dependent color [G]. The rendering process integrates these outputs along rays using standard volume rendering equations [G].

Most modifications in this family retain the core volume rendering equation but alter one or more of the following components:
1.  **Input Space:** Augmenting $\mathbf{x}$ and $\mathbf{d}$ with additional signals such as latent codes $\mathbf{z}$, time $t$, illumination embeddings $\mathbf{z}_l$, or external feature vectors $\mathbf{f}$ from vision models [S1, unofficial][S2, unofficial][S3].
2.  **Network Topology:** Replacing the monolithic MLP with specialized branches (e.g., separate density and color networks), modular experts, or hybrid structures combining MLPs with convolutional or transformer backbones [S1, unofficial][S2, unofficial].
3.  **Output Space:** Extending the output tuple $(\sigma, \mathbf{c})$ to include additional fields such as surface normals $\mathbf{n}$, semantic logits $\mathbf{s}$, uncertainty variance $\nu$, or blend weights $\Delta w$ [S1, unofficial][S2, unofficial].
4.  **Representation Basis:** Substituting the coordinate-based implicit function with explicit structures like voxel grids, hash tables, Gaussian primitives, or planar surfaces, which change how features are stored and interpolated [S1, unofficial][S2, unofficial].

## Subtopics

### [Multi-Space Neural Radiance Field (MS-NeRF)](11707-multi-space-neural-radiance-field-ms-nerf.md)
MS-NeRF addresses the failure of standard single-space Neural Radiance Fields (NeRF) to render reflective and refractive objects, which often results in blurry or distorted images due to violated multi-view consistency. It represents the scene using a group of feature fields in parallel sub-spaces instead of a single radiance field in Euclidean space, allowing virtual images to be placed in sub-spaces visible only from certain views. Unlike single-space NeRF, which often requires manual labeling of reflective surfaces to avoid sub-optimal convergence, MS-NeRF automatically handles mirror-like objects without such labeling.

### [NRFF](12072-nrff.md)
NRFF is a method for encoding view-dependent effects, specifically specularities, in neural radiance fields by replacing the standard positional encoding and roughness/IDE inputs of Ref-NeRF with a multiscale tensor decomposition and Anisotropic Spherical Gaussians (ASG). It differs from its siblings by explicitly modeling reflection geometry in a latent space via a Rendering Equation Encoding (REE) before passing data to the directional MLP, rather than relying on explicit roughness maps or pre-computed environment maps.

### [Semantic and Feature Branches](12095-semantic-and-feature-branches.md)
Semantic and Feature Branches extend the standard NeRF formulation by predicting arbitrary per-point feature signals $\mathbf{f}$ in addition to color $\mathbf{c}$ and density $\sigma$ [Parent]. This allows the radiance field to encode semantic labels, geometric properties, or high-dimensional embeddings, enabling tasks such as zero-shot segmentation, object manipulation, and 3D detection. Unlike sibling methods that may focus on specific downstream applications like pose estimation [PI-NeRF](12124-pi-nerf.md) or gaze redirection [GazeNeRF](12127-gazenerf.md), this family provides the general mechanism for lifting 2D feature observations into a consistent 3D representation [Parent].

### [NeRF for Object Segmentation](12404-nerf-for-object-segmentation.md)
This method extends the standard NeRF formulation to perform object segmentation by simultaneously estimating scene geometry and predicting semantic occlusion masks. It introduces "area encoding" to represent the probability that a sampling point belongs to an occluded area, leveraging the strong correlation between geometry estimation and semantic label prediction. Unlike sibling methods that predict arbitrary feature vectors [Parent], this approach specifically targets binary or probabilistic occlusion masks to enable 3D de-occlusion and inpainting.

### [Semantic-NeRF](14889-semantic-nerf.md)
Semantic-NeRF is a method that extends the Neural Radiance Field (NeRF) formulation to synthesize semantic labels for novel views by predicting a semantic feature vector in addition to color and density. It solves the problem of integrating 2D semantic supervision into a 3D implicit representation, enabling multi-view consistent semantic understanding and label propagation from sparse or noisy annotations. It sets itself apart from sibling methods like [Multi-Space Neural Radiance Field (MS-NeRF)](11707-multi-space-neural-radiance-field-ms-nerf.md) and [NRFF](12072-nrff.md) by specifically focusing on the direct integration of categorical semantic labels via a dedicated output branch, rather than general feature fields or instance-specific segmentation.

### [Augmented Features (Avg, Var, Color)](15000-augmented-features-avg-var-color.md)
Augmented Features (Avg, Var, Color) is a method for enhancing volumetric scene representation in multi-view 3D object detection by enriching the feature space with statistical moments and low-level appearance cues. It solves the problem of insufficient geometric priors in standard neural radiance fields by explicitly modeling the variance of the cost volume and incorporating color information alongside the mean. It sets itself apart from sibling methods like [Semantic-NeRF](14889-semantic-nerf.md) by focusing on statistical geometry priors (variance) rather than semantic labels, and from [Feature Fields](12995-feature-fields.md) by specifically targeting the cost volume augmentation for detection tasks rather than general feature synthesis.

### Object Field Representation
A function $f(\mathbf{p})$ that maps a 3D point $\mathbf{p}$ to an object code vector $\mathbf{o}$, representing object ownership independent of viewing angles [S2, unofficial]. The object field is defined as $\mathbf{o} = f(\mathbf{p})$, where $\mathbf{o} \in \mathbb{R}^{H+1}$ and $H$ is a predefined maximum number of solid objects the network predicts [S2, unofficial]. The last dimension is reserved for empty space to handle occlusion and collision [S2, unofficial]. The function $f$ is parameterized by a series of MLPs [S2, unofficial].

### N3F
A method that learns additional feature fields to realize self-supervised 3D segmentation [S3].

### NeRF Branch Feature Sampling and Augmentation
Variance of color features describes occupancy: low variance implies occupied 3D location (Lambertian assumption), high variance implies free space (different appearances from different views) [S4]. Sample points along the ray originated from the camera: $r(t) = \mathbf{o} + t \times \mathbf{d}$, where $\mathbf{o}$ is the ray origin and $\mathbf{d}$ is the view direction [S4]. Augment sampled features with variance from multiple views to describe occupancy. Compute variance: $V_{var}(\mathbf{p}) = \sum_{i=1}^{M_p} (V_i(\mathbf{p}) - V_{avg}(\mathbf{p}))^2 / M_p$ [S4]. Compute mean and variance for pixel RGB values in the same way as for deep features [S4]. Pass sampled augmented features into NeRF MLPs to generate density and color [S4]. Density and latent features are computed as: $\sigma(\mathbf{p}), \hat{\mathbf{h}}(\mathbf{p}) = \text{G-MLP}(\bar{V}(\mathbf{p}), \gamma(\mathbf{p}))$, where $\bar{V}(\mathbf{p})$ is ray features aggregated and augmented from multi-view features, and $\gamma(\mathbf{p})$ is position encoding [S4]. Color is computed as: $\mathbf{c}(\mathbf{p}, \mathbf{d}) = \text{C-MLP}(\hat{\mathbf{h}}(\mathbf{p}), \mathbf{d})$ [S4]. Augmented feature $\bar{V}$ is a concatenation of $\{V_{avg}, V_{var}, \text{RGB}_{avg}, \text{RGB}_{var}\}$ [S4]. Grid resolution for 3D detection: $40 \times 40 \times 16$ [S4]. Source image feature map resolution: typically $160 \times 120$ [S4].

### Feature Sampling from Multi-View 2D Features
Sampling point features along the ray from multi-view image features instead of low-resolution volume features to address the need for high-resolution images in NeRF [S4]. Sampling from image features achieves 20.51 PSNR for novel-view synthesis compared to 18.93 with volume sampling [S4].

## Background
The concept of feature fields originated as a generalization of the NeRF formulation, where the network predicts arbitrary per-point feature signals $\mathbf{f}$ in addition to color $\mathbf{c}$ and density $\sigma$, rather than only color [S1, unofficial]. Supervision is achieved by reprojecting the predicted 3D features onto the 2D image plane and comparing them to corresponding 2D feature maps, mirroring the color reconstruction process [S1, unofficial]. This approach allows the encoding of semantic labels, physical properties, or latent descriptors from foundation models [S1, unofficial].

The field has evolved to include specific applications such as semantic segmentation (e.g., Semantic-NeRF) [S1, unofficial], object manipulation (e.g., DM-NeRF) [S2, unofficial], and self-supervised segmentation (e.g., N3F) [S3]. It is also used in multi-view 3D object detection to enhance geometric priors through variance and color augmentation [S4].

Training and exploiting feature fields introduces notable challenges. The high dimensionality of feature embeddings substantially increases memory usage and computational cost [S1, unofficial]. Moreover, the process of lifting 2D features into 3D remains fundamentally 2D-driven and lacks the intrinsic geometric reasoning that explicit 3D encoders could provide [S1, unofficial]. Finally, unlike direct NeRF interpretation methods that infer semantics in a single forward pass, feature fields require per-scene optimization before their semantics can be exploited, limiting scalability for large datasets or real-time use [S1, unofficial].
