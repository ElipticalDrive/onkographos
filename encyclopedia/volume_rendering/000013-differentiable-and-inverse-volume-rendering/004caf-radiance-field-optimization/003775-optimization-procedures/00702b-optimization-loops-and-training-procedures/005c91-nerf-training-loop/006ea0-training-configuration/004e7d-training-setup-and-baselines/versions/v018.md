# Training Setup and Baselines


## Overview
This family defines the specific hyperparameter configurations, data handling strategies, and architectural constraints required to train differentiable volume rendering models, ranging from standard NeRF baselines to GAN-based 3D generators and sparse neural volumes. It differs from the general [Training Loop](1522-training-loop-setup.md) by fixing the static configuration parameters (such as batch sizes, learning rates, and sampling densities) that govern the optimization dynamics, rather than the dynamic iteration logic.

## Shared principles
All methods in this family share the core differentiable volume rendering pipeline defined in [NeRF Training Loop](1522-training-loop-setup.md), where pixel colors are computed via ray marching and backpropagated through the neural network. Common principles include:
1.  **Ray Sampling:** Generating rays from camera poses and sampling points along them to query the radiance field.
2.  **Network Query:** Evaluating a neural network (MLP or hierarchical structure) at sample points to obtain volume density $\sigma$ and color $\mathbf{c}$.
3.  **Volume Rendering:** Computing the final pixel color $\hat{\mathbf{C}}(\mathbf{r})$ using the discretized integral:
    $$ \hat{\mathbf{C}}(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i $$
    where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance and $\delta_i$ is the distance between samples [S1, unofficial][S2].
4.  **Loss Computation:** Minimizing the difference between rendered images and ground truth, typically using Mean Squared Error (MSE) [S1, unofficial][S2].
5.  **Optimization:** Updating network parameters using gradient-based optimizers, typically Adam [S1, unofficial][S2].

## Subtopics

### [NeRF-GT Baseline Training Setup](11349-nerf-gt-baseline-training-setup.md)
Establishes a reference protocol for NeRF using HDR inputs, serving as an upper-bound for HDR synthesis methods. It differs from standard NeRF by explicitly handling the dynamic range mismatch between HDR scene representations and LDR ground truth via tone-mapping during loss computation. It is chosen when evaluating HDR-to-LDR synthesis performance.

### [StyleGAN2 Training Configuration](12972-stylegan2-training-configuration.md)
Adapts StyleGAN2 for 3D-aware image synthesis (e.g., StyleNeRF). It differs from standard NeRF by employing equalized learning rates, minibatch standard deviation in the discriminator, and sparse R1 regularization to stabilize GAN training. It excludes path regularization and style-mixing to reduce computational cost. It is chosen for GAN-based 3D generation.

### [NeRF Training Setup](13271-nerf-training-setup.md)
Describes training for NeRF-based models using Nerfstudio/Instant-NGP, specifically Control-NeRF. It differs from standard NeRF by using feature volumes instead of raw coordinates for the fine network input. It is chosen for efficient training of static scenes with control features.

### [NLR Baseline](15254-nlr-baseline.md)
Implements the Neural Lumigraph Representation (NLR) as a foundational reference for differentiable volume rendering. It differs from NeRF by using a specific architecture optimized for light fields rather than a static MLP. It is chosen for baseline comparisons in meta-learning novel view synthesis.

### NeuralVDB Hyperparameter Configuration
Configures the training of sparse neural volumes using VDB structures.
*   **Step:** Use batch sampling strategy: either draw $2^{16}$ random samples per epoch, or resample a subset of input voxels at fixed intervals (100 or 500) and draw $2^{12}$ batches per epoch. Resampling subset size = resampling intervals $\times$ batch size. Use resampling when fine details with thin structures are critical [S1, unofficial].
*   **Parameter:** Subdomain size must be a multiple of 512. Too large wastes compute on empty subdomains; too small increases dispatch overhead and causes dominant overlapping halo regions leading to redundant computation [S1, unofficial]. Network width: Level-1 networks use half the width of level-0 networks. Default starting point: level-0 width 128, depth 3. Use 4 layers for volumes requiring more detail capture [S1, unofficial]. Optimizer: Adam. Default learning rate: 0.001. Decay: 0.975 every 100 epochs (no resampling) or 0.75 every 1,000 epochs (with resampling). Max epochs: 2,500 for non-resampled; more for resampled cases [S1, unofficial].
*   **Comparison:** Dense grid training produces the highest noise. Block grid (dense leaf nodes without active masks) reduces noise but still shows visible fog artifacts. Sparse VDB with active voxel masks yields the best visual quality and low noise reconstruction [S1, unofficial].

### Neural Codebook Training Configuration
Configures the training of Neural Codebooks (NCB) for compact radiance fields.
*   **Step:** Multiply learning rate by 0.3 for every 5,000 iterations. Cast the trained NCB to float16 after training [S2].
*   **Parameter:** Optimizer: Adam with $\beta_1 = 0.9$ and $\beta_2 = 0.999$. Weight decay: $1e-5$. Initial learning rate: $5e-3$. Total training iterations: 20,000. Batch size: 100,000 voxels [S2].

## Background
The concept of training differentiable volume rendering was introduced by Mildenhall et al. in 2020 with NeRF [S2]. Subsequent works adapted these training setups for specific architectures, such as NLR [S1, unofficial], StyleGAN2-based 3D generators [S1, unofficial], and sparse neural volumes like NeuralVDB [S1, unofficial] and Neural Codebooks [S2].
