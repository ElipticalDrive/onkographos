# Hierarchical and Sparse Grid Representations


## Overview
Hierarchical and Sparse Grid Representations replace the coordinate-based MLP bottleneck of standard NeRFs with explicit, discrete data structures (voxels, grids, or octrees) to accelerate training and inference [S1]. Unlike sibling [Triplane and Planar Representations](18410-triplane-and-planar-representations.md) which use 2D projections, these methods store features in 3D volumetric structures, enabling aggressive empty space skipping and caching .

## Shared principles
The family shares a mechanism of discretizing 3D space into learnable structures and querying them via differentiable interpolation.

**Discretization**
The 3D scene space is divided into voxels organized in a hierarchy (e.g., coarse-to-fine levels, octrees) or a regular tensor $\mathbb{R}^{H \times W \times D}$ [S1].

**Feature Storage**
Each voxel (or octree node) stores learnable parameters, which may include:
*   Volume density $\sigma$ [S1].
*   Latent feature vectors $f$ or $e$ used to decode color or SDF [S1].
*   Binary values $\{-1, +1\}$ for compressed storage .

**Differentiable Query**
For a query point $\mathbf{x}$, values are retrieved via interpolation. Standard trilinear interpolation is used for 3D grids:
$$ f(\mathbf{x}) = \text{interp}(\mathbf{x}, \mathbf{V}) $$
where $\mathbf{V}$ is the feature grid [S1]. This operation is differentiable, allowing gradients to flow back to the grid values during optimization [S1].

**Decoding**
Interpolated features are passed to a small decoder network (typically an MLP) $S_\Theta$ to predict final outputs like color $\mathbf{c}$ or SDF $s$:
$$ \mathbf{c}(\mathbf{x}) = S_\Theta(\text{interp}(\mathbf{x}, \mathbf{V}_a)) $$
[S1].

## Subtopics

### [Voxel and Grid Representations](18218-voxel-and-grid-representations.md)
Stores scene information in explicit 3D structures (regular grids, octrees) rather than solely relying on MLPs. Solves the computational bottleneck of evaluating large MLPs for every ray sample by replacing them with fast, differentiable interpolation. Allows aggressive empty space skipping and early ray termination.

### [Triplane and Planar Representations](18410-triplane-and-planar-representations.md)
Encodes 3D scenes using three orthogonal 2D feature grids ($xy, xz, yz$). Reduces memory footprint through 2D convolutions compared to 3D voxel grids, though it introduces an axis-aligned bias.

### MERF (Memory-Efficient Radiance Field)
**Definition**
A representation introduced by Reiser et al. that allows for fast rendering of large-scale scenes [S1].

**Layout**
Utilizes a sparse feature grid and high-resolution 2D feature planes [S1].

## Background
The concept of using explicit grids for neural rendering emerged as a solution to the high computational cost of coordinate-based MLPs. Reiser et al. introduced the Memory-Efficient Radiance Field (MERF) to address the limitations of traditional methods by enabling fast rendering of large-scale scenes [S1]. This approach paved the way for subsequent methods like Neuralangelo, which utilized multi-resolution 3D hash grids for dense surface reconstruction [S1].
