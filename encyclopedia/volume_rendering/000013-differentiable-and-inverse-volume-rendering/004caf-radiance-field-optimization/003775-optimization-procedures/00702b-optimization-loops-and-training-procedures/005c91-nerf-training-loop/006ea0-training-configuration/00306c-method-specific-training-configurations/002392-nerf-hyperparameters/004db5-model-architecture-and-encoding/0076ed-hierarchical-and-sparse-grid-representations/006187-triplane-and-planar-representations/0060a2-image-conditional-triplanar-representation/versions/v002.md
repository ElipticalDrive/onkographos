# Image-Conditional Triplanar Representation
Also called: Tri-plane Features

## Overview
Image-Conditional Triplanar Representation is a 3D scene representation that constructs a fixed set of three axis-aligned 2D feature grids from input images, enabling efficient neural rendering without the cubic complexity of voxel-based methods [S1]. It differs from standard triplane approaches by explicitly conditioning the feature grid construction on camera poses and intrinsic parameters via a back-projected 3D feature volume, allowing the representation to capture appearance details directly from the input view rather than relying solely on a generic latent code [S1].

## How it works
**Inputs and Outputs**
*   **Input:** An input image $I \in \mathbb{R}^{H_i \times W_i \times 3}$, camera pose $\gamma_i$, and camera intrinsic matrix $K_i$.
*   **Output:** A triplanar feature tensor $S \in \mathbb{R}^{3 \times C \times D \times D}$, where the three planes correspond to the $xy$, $xz$, and $yz$ canonical planes [S1].

**Data Structures**
The core data structure is the triplane tensor $S$.
*   **Shape:** $\mathbb{R}^{3 \times C \times D \times D}$.
*   **Dimensions:**
    *   First dimension (size 3): Indexes the three orthogonal planes ($xy, xz, yz$).
    *   Second dimension (size $C$): Feature dimension per grid cell.
    *   Last two dimensions (size $D \times D$): Spatial resolution of each 2D plane [S1].

**Algorithm Steps**
1.  **Image Feature Extraction:** Extract low-resolution spatial features from the input image $I$ using an ImageNet pre-trained ConvNet backbone $E$. This transforms the input image into a 2D feature map $F_I \in \mathbb{R}^{H_i/2 \times W_i/2 \times C}$ [S1].
2.  **Back-Projection to 3D Volume:** Project the local features from $F_I$ backwards along every ray into a 3D feature volume $V_F$. This projection uses the camera pose $\gamma_i$ and intrinsic matrix $K_i$ to map 2D feature locations to 3D space [S1].
3.  **Depth Encoding:** Since features along a single camera ray are identical in the raw grid, encode the depth of individual features using an MLP $Z$. The MLP $V_Z = Z(V_F, x_c, d)$ takes as input:
    *   Concatenated features in the grid ($V_F$).
    *   Positions of the grid in the camera frame ($x_c$).
    *   Directions from the world frame positions ($x_w$) to the camera frame [S1].
    *   The output is the depth-encoded feature volume $V_Z$ [S1].
4.  **Triplane Construction (Feature Aggregation):** Construct the triplane features $S_{xy}, S_{xz}, S_{yz}$ by summing weighted depth-encoded features from $V_Z$. The weights are softmax scores obtained from dedicated aggregation MLPs ($A_{xy}, A_{xz}, A_{yz}$) conditioned on the encoded features and world coordinates [S1]. The formulas are:
    $$
    \mathbf{S}_{xy} = \sum_i w_{xy_i} \mathbf{V}_{Z_i}, \quad w_{xy} = A_{xy}(V_{Z_i}, x_{w_z})
    $$
    $$
    \mathbf{S}_{xz} = \sum_i w_{xz_i} \mathbf{V}_{Z_i}, \quad w_{xz} = A_{xz}(V_{Z_j}, x_{w_y})
    $$
    $$
    \mathbf{S}_{yz} = \sum_i w_{yz_i} \mathbf{V}_{Z_i}, \quad w_{yz} = A_{yz}(V_{Z_j}, x_{w_x})
    $$
    Here, $w_{xy}, w_{xz}, w_{yz}$ are softmax scores obtained after summing over the $z, y,$ and $x$ dimensions respectively [S1].
5.  **Upsampling and Refinement:** Transform the built image-conditional triplanes into a new $G$-channel output using learned 2D convolutions. The channel dimension is reduced such that $G = C/4$, while the spatial dimension of the planes is upsampled from $D \times D$ to the image feature space resolution ($H/2 \times W/2$). These convolutions act as inpainting networks to fill in missing features [S1].
6.  **Rendering:** The resulting triplane features condition the neural volumetric rendering process. Points are sampled along rays, features are gathered by projecting points onto the canonical planes and bilinearly interpolating, and a lightweight MLP (NeRF decoder) predicts density and color [S1].

**Edge Cases and Pitfalls**
*   **Missing Features:** The method relies on 2D convolutions to act as inpainting networks to fill in missing features in the triplanes, suggesting that sparse input views may result in incomplete initial projections [S1].
*   **Depth Ambiguity:** The explicit depth encoding MLP $Z$ is required because features along a ray are identical in the raw back-projected volume; without this, the triplane representation would lose depth information [S1].

## Operating characteristics
*   **Complexity:** Avoids the cubic complexity of voxel-based representations ($O(D^3)$) by using a fixed number of 2D planes ($O(D^2)$ per plane, total $O(D^2)$) [S1].
*   **Expressiveness:** More expressive than BEV or 2D feature representations because it retains all three dimensions (unlike BEV which omits the z-axis) [S1].
*   **Performance:** Enables accurate neural rendering and full expressivity at scale [S1].
*   **Strengths:** Computationally efficient compared to 3D CNNs or voxels; leverages pre-trained 2D CNNs for feature extraction [S1].
*   **Limitations:** Relies on the quality of the input image features and camera poses; performance may degrade with very sparse views if the inpainting mechanism is insufficient [S1].

## Background
The Image-Conditional Triplanar Representation was introduced in the paper "NeO 360: Neural Fields for Sparse View Synthesis of Outdoor Scenes" [S1]. It builds upon prior works involving volumetric reconstruction [55, 39, 25] and aims to address the limitations of cubic complexity in voxels and the lack of expressiveness in 2D/BEV representations [S1].
