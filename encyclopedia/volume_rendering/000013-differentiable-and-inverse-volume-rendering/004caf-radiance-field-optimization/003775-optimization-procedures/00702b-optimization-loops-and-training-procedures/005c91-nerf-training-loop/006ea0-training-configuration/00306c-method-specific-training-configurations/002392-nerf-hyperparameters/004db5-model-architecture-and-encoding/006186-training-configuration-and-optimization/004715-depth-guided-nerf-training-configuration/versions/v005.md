# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the hyperparameters, architecture modifications, and optimization settings for training a Neural Radiance Field (NeRF) model using depth priors to improve reconstruction quality [S1]. It builds on [Model Architecture and Encoding](13550-model-architecture-and-encoding.md) by integrating depth supervision into the loss function and adjusting the network's regularization and learning rate schedules to handle depth-specific features [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D positions $\mathbf{x} \in \mathbb{R}^3$, viewing directions $\mathbf{d} \in \mathbb{R}^3$, and ground truth depth maps $D_{gt}$ for the input views [S1].
*   **Outputs:** Volume density $\sigma$, color $\mathbf{c}$, and predicted depth $\hat{d}$ [S1].

**Data Structures:**
The network architecture follows the standard NeRF MLP structure but includes specific modifications:
*   **Dropout:** Dropout layers with probability $p=0.1$ are added after each of the first eight fully connected ReLU-activated layers that encode the positional encoding [S1].
*   **Depth Scale:** A specific learnable parameter for depth scaling is maintained with its own optimizer state [S1].

**Optimization Steps:**
1.  **Sampling:** Sample rays through the scene and compute volume rendering for color and density as per the standard NeRF formulation [S1].
2.  **Depth Prediction:** Compute the expected depth $\hat{d}$ from the volume rendering weights and depths along the ray [S1].
3.  **Loss Calculation:** Compute the total loss $\mathcal{L}$:
    $$ \mathcal{L} = \mathcal{L}_{color} + \lambda \mathcal{L}_{depth} + \gamma \mathcal{L}_{uncertainty} $$
    Where:
    *   $\mathcal{L}_{color}$ is the standard photometric loss [S1].
    *   $\mathcal{L}_{depth}$ is the depth loss (e.g., L1 or L2 between $\hat{d}$ and $D_{gt}$) [S1].
    *   $\mathcal{L}_{uncertainty}$ is an uncertainty regularization term [S1].
    *   $\lambda$ is the depth loss weight.
    *   $\gamma$ is the uncertainty weight.
4.  **Thresholding for Uncertainty:** Evaluate the uncertainty of the depth map using a threshold $\tau$:
    $$ \tau = (\text{max\_depth} - \text{min\_depth}) \cdot 0.0001 $$
    For ScanNet, $\text{max\_depth} = 10$ and $\text{min\_depth} = 0.001$ [S1].
5.  **Optimization:** Update network weights using the Adam optimizer [S1].

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Initial Learning Rate:** $5 \times 10^{-4}$ [S1].
*   **Learning Rate Schedule:** Reduce learning rate to $5 \times 10^{-5}$ after 80% of total steps [S1].
*   **Weight Decay:** $1 \times 10^{-6}$ [S1].
*   **Total Training Steps:** 500,000 [S1].
*   **Depth Loss Weight ($\lambda$):** $0.007$ for all scenes except scene 710, where it is $0.02$ [S1].
*   **Uncertainty Weight ($\gamma$):** $1$ [S1].
*   **Depth Scale Learning Rate:** $1 \times 10^{-7}$ [S1].

**Pseudocode:**
```python
def train_depth_guided_nerf(model, optimizer, data_loader, config):
    # Initialize optimizer with specific learning rates
    # Standard weights use config.lr (5e-4)
    # Depth scale uses config.depth_scale_lr (1e-7)
    
    total_steps = config.total_steps  # 500,000
    lr_decay_step = int(total_steps * 0.8)
    
    for step, batch in enumerate(data_loader):
        x, d, gt_depth = batch
        
        # Forward pass
        sigma, color, pred_depth = model(x, d)
        
        # Compute color loss (standard NeRF)
        loss_color = compute_color_loss(color, batch.gt_color)
        
        # Compute depth loss
        # Note: Specific depth loss formula (e.g., L1, L2) depends on implementation
        # but is weighted by lambda
        loss_depth = compute_depth_loss(pred_depth, gt_depth)
        
        # Compute uncertainty loss (if applicable)
        # Threshold tau is computed per scene based on min/max depth
        max_depth = 10.0  # Example for ScanNet
        min_depth = 0.001 # Example for ScanNet
        tau = (max_depth - min_depth) * 0.0001
        loss_uncertainty = compute_uncertainty_loss(pred_depth, tau)
        
        # Combine losses
        lambda_depth = config.lambda_depth  # 0.007 or 0.02 for scene 710
        gamma_uncertainty = config.gamma_uncertainty  # 1
        
        total_loss = loss_color + lambda_depth * loss_depth + gamma_uncertainty * loss_uncertainty
        
        # Backward pass and update
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
        
        # Learning rate schedule
        if step == lr_decay_step:
            adjust_learning_rate(optimizer, new_lr=5e-5)
            
        if step >= total_steps:
            break
```

## Subtopics

### DS-NeRF Depth Loss Integration
Integrates the depth loss implementation from the official DS-NeRF code base into the training pipeline [S2]. Due to missing configuration files for DTU in the official release and different train/test splits for LLFF in the original publication, this variant involves re-training on specific splits using released configuration files to ensure reproducibility [S2].

## Operating characteristics
*   **Time Complexity:** Training requires 500,000 steps [S1]. The addition of depth loss computation adds minimal overhead compared to color loss [S1].
*   **Memory Complexity:** Standard NeRF memory usage plus storage for depth maps and uncertainty metrics [S1].
*   **Strengths:** Improves geometric accuracy by leveraging depth priors [S1].
*   **Limitations:** Requires ground truth depth maps for training [S1]. Performance may vary across scenes (e.g., scene 710 requires different hyperparameters) [S1].
*   **When to use:** When depth supervision is available and geometric accuracy is prioritized over pure photometric fidelity [S1].

## Background
This configuration originates from the work on Depth-Guided NeRF Training via Earth Mover’s Distance [S1]. It adapts the original NeRF architecture [15] by adding dropout for regularization and integrating depth-specific loss terms and learning rates [S1]. The approach is part of the broader effort to improve NeRF reconstruction quality using auxiliary geometric cues [S1].
