# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF is a text-guided stylization method for Neural Radiance Fields (NeRF) that enforces the trajectory of stylization in the CLIP embedding space by measuring cosine similarity between rendered images and text prompts [S2]. It distinguishes itself from standard NeRF optimization by freezing density-related parameters and optimizing only the color/feature fields to minimize the negative cosine similarity between a target text prompt and the rendered view [S1].

## How it works
**Inputs:**
*   A pre-trained NeRF model (density and color networks).
*   A source image $\mathbf{I}_{src}$ (optional, for relative loss).
*   A target text prompt $\mathbf{t}_{tgt}$ and optionally a source text prompt $\mathbf{t}_{src}$.
*   A camera pose sampled from the training dataset.

**Outputs:**
*   A stylized rendered image patch $\mathbf{I}_{tgt}$.
*   Updated color/feature network parameters.

**Data Structures:**
*   **CLIP Encoder:** Uses CLIP ViT-B/32 [S1]. The image encoder $\mathcal{E}_i$ and text encoder $\mathcal{E}_t$ produce normalized embedding vectors $\hat{\mathbf{e}}_i$ and $\hat{\mathbf{e}}_t$.
*   **NeRF Model:** Two MLPs (density and color) connected by a bottleneck feature vector $\mathbf{e}$ [Parent]. The density network parameters are frozen during this specific optimization loop [S1].
*   **Rendering Patch:** A $128 \times 128$ pixel patch is rendered. Rays are sampled with a stride of 5, covering a $640 \times 640$ receptive field of the original image [S1].

**Parameters:**
*   **Iterations:** 500 [S1].
*   **Optimizer:** Adam with learning rate $0.0001$ [S1].
*   **Sampling:** Importance sampling points during patch rendering are reduced to 16 for memory efficiency [S1]. The fine MLP uses 64 coarse + 16 fine samples, totaling 80 samples per ray [S1].
*   **Text Encoder:** CLIP ViT-B/32 [S1].

**Loss Functions:**
Two variants of the directional CLIP loss are used. Let $\langle \cdot, \cdot \rangle$ denote the dot product.

1.  **Absolute Directional CLIP Loss:** Measures cosine similarity between the rendered stylized image $\mathbf{I}_{tgt}$ and the target text prompt $\mathbf{t}_{tgt}$ [S2].
    $$ \mathcal{L}_{dir} = 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) \rangle $$
    This guides the NeRF rendering with a global direction of the target text, independent of a reference starting point [S2].

2.  **Relative Directional CLIP Loss:** Transfers the source image $\mathbf{I}_{src}$ to the target domain guided by the CLIP-space trajectory embedded by a pair of text prompts $(\mathbf{t}_{src}, \mathbf{t}_{tgt})$ [S2].
    $$ \mathcal{L}_{dir} = 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}) - \hat{\mathcal{E}}_i(\mathbf{I}_{src}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) - \hat{\mathcal{E}}_t(\mathbf{t}_{src}) \rangle $$
    This ensures the stylization trajectory is relative to the source rather than absolute [S2].

**Algorithm:**
1.  Initialize NeRF model with pre-trained density and color networks.
2.  Freeze all parameters related to the density network [S1].
3.  For iteration $k = 1$ to $500$:
    a. Sample a random camera pose from the training dataset [S1].
    b. Render a $128 \times 128$ patch $\mathbf{I}_{tgt}$ using the current color network, sampling rays with stride 5 and 16 importance samples per ray [S1].
    c. Encode $\mathbf{I}_{tgt}$ using $\mathcal{E}_i$ to get $\hat{\mathcal{E}}_i(\mathbf{I}_{tgt})$ [S2].
    d. Encode text prompt(s) using $\mathcal{E}_t$ to get $\hat{\mathcal{E}}_t(\mathbf{t}_{tgt})$ and optionally $\hat{\mathcal{E}}_t(\mathbf{t}_{src})$ [S2].
    e. Compute $\mathcal{L}_{dir}$ using either the absolute or relative formula [S2].
    f. Compute gradient of $\mathcal{L}_{dir}$ with respect to the color network parameters.
    g. Update color network parameters using Adam optimizer with learning rate $0.0001$ [S1].
4.  Return the updated NeRF model.

**Edge Cases and Pitfalls:**
*   **Memory Constraints:** Naive differentiable rendering of high-resolution images is intractable due to memory constraints [S1]. The patch-based rendering with stride 5 is required [S1].
*   **Mode Collapse:** The absolute directional CLIP loss can cause mode-collapse of the generator and hurt generation diversity [S2].
*   **Insufficient Magnitude:** The directional CLIP loss measures directional similarity between normalized embedded vectors but ignores their actual distances, struggling to reach sufficient stylization magnitude [S2]. This results in weak or insufficient style transfer [S2].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Reduced by using $128 \times 128$ patches and 16 importance samples per ray instead of full-resolution rendering [S1].
*   **Strengths:** Enables text-driven stylization of NeRFs [S2].
*   **Limitations:** Absolute loss causes mode collapse; directional loss lacks magnitude control [S2].
*   **When to use:** When text-guided stylization of a NeRF is required and computational resources are limited [S1].
*   **When not to use:** When high diversity or strong magnitude of stylization is critical, as absolute loss reduces diversity and directional loss lacks magnitude [S2].

## Background
CLIPNeRF was introduced by Wang et al. in 2021 [S2]. It extends the absolute directional CLIP loss first designed in StyleCLIP [Patashnik et al. 2021] for face image editing to generative NeRF editing [S2]. The relative directional loss variant was further explored in StyleGAN-NADA [Gal et al. 2021] and applied to NeRF-Art [S2].
