# Point-NeRF Representation

Also called: Neural point cloud, Point-based radiance field

## Overview
Point-NeRF is a point-based radiance field representation that models a continuous volumetric radiance field using a discrete neural point cloud [S1]. It solves the problem of inefficient ray sampling in empty space inherent to grid-based methods like NeRF by leveraging classical point clouds that approximate scene geometry [S1]. Unlike its siblings, it regresses density and radiance from local neighborhood features rather than using global coordinate encoding or Gaussian splatting [S1].

## How it works
**Inputs:** A set of $N$ neural points $\mathcal{P}$, a 3D shading location $\mathbf{x}$, a viewing direction $\mathbf{d}$, and hyperparameters $K$ (number of neighbors) and $R$ (query radius).
**Outputs:** Volume density $\sigma$ and view-dependent radiance $\mathbf{r}$ at $\mathbf{x}$.

**Data Structures:**
The scene is represented by a neural point cloud $\mathcal{P} = \{(\mathbf{p}_i, \mathbf{f}_i, \gamma_i) \mid i = 1, \dots, N\}$ [S1]:
*   $\mathbf{p}_i \in \mathbb{R}^3$: 3D location of point $i$.
*   $\mathbf{f}_i \in \mathbb{R}^D$: Neural feature vector encoding local scene content.
*   $\gamma_i \in [0, 1]$: Scale confidence value representing the likelihood of the point being near an actual scene surface [S1].

**Algorithm:**
1.  **Neighborhood Query:** For a query location $\mathbf{x}$, identify the set of $K$ neighboring points $\{\mathbf{p}_i\}_{i=1}^K$ within radius $R$ [S1].
2.  **Per-Point Processing:** For each neighbor $i$, compute the relative position $\Delta \mathbf{p}_i = \mathbf{x} - \mathbf{p}_i$. Process the point using an MLP $\mathcal{F}$ to predict a local feature vector $\mathbf{f}_{i,x}$ at $\mathbf{x}$ [S1]:
    $$ \mathbf{f}_{i,x} = \mathcal{F}(\mathbf{f}_i, \mathbf{x} - \mathbf{p}_i) $$
    The use of relative position $\mathbf{x} - \mathbf{p}_i$ ensures translation invariance [S1].
3.  **Feature Aggregation:** Aggregate the processed features $\mathbf{f}_{i,x}$ using inverse distance weighting to obtain a single feature $\mathbf{f}_x$ describing appearance at $\mathbf{x}$ [S1]:
    $$ \mathbf{f}_x = \sum_{i=1}^K \gamma_i \frac{w_i}{\sum_{j=1}^K w_j} \mathbf{f}_{j,x}, \quad \text{where } w_i = \frac{1}{\|\mathbf{p}_i - \mathbf{x}\|} $$
    Here, $\gamma_i$ acts as a confidence weight, and $w_i$ is the inverse distance weight [S1].
4.  **Radiance Regression:** Regress view-dependent radiance $\mathbf{r}$ from the aggregated feature $\mathbf{f}_x$ and viewing direction $\mathbf{d}$ using an MLP $\mathcal{R}$ [S1]:
    $$ \mathbf{r} = \mathcal{R}(\mathbf{f}_x, \mathbf{d}) $$
5.  **Density Regression:** Regress volume density $\sigma$ from $\mathbf{f}_x$ (and potentially $\mathbf{d}$, though the source specifies $\mathbf{r}$ depends on $\mathbf{d}$, $\sigma$ is typically derived from the same local context) [S1]. The source defines the joint regression as $(\sigma, \mathbf{r}) = \text{Point-NeRF}(\mathbf{x}, \mathbf{d}, \mathbf{p}_1, \mathbf{f}_1, \gamma_1, \dots, \mathbf{p}_K, \mathbf{f}_K, \gamma_K)$ [S1].

**Rendering:**
The final pixel color $\mathbf{c}$ is computed via volume rendering equation [S1]:
$$ \mathbf{c} = \sum_{j=1}^M \tau_j (1 - \exp(-\sigma_j \Delta_j)) \mathbf{r}_j $$
$$ \tau_j = \exp\left(-\sum_{t=1}^{j-1} \sigma_t \Delta_t\right) $$
where $\sigma_j, \mathbf{r}_j$ are density and radiance at shading sample $j$, $\Delta_t$ is the distance between adjacent samples, and $\tau_j$ is transmittance [S1].

**Pseudocode:**
```python
def point_nerf_query(x, d, points, k_neighbors, radius):
    """
    x: query 3D location [3]
    d: viewing direction [3]
    points: list of tuples (p, f, gamma)
    k_neighbors: int K
    radius: float R
    Returns: sigma (scalar), r (vector)
    """
    # 1. Query K neighbors within radius R
    neighbors = []
    for p, f, gamma in points:
        dist = norm(p - x)
        if dist < radius:
            neighbors.append((p, f, gamma, dist))
    
    # Sort by distance and take top K
    neighbors.sort(key=lambda item: item[3])
    neighbors = neighbors[:k_neighbors]
    
    if not neighbors:
        return 0.0, [0.0, 0.0, 0.0] # Default empty space

    # 2. Per-point processing
    processed_features = []
    for p, f, gamma, dist in neighbors:
        relative_pos = x - p
        # MLP F processes feature and relative position
        f_ix = mlp_F(f, relative_pos)
        processed_features.append((f_ix, gamma, dist))

    # 3. Aggregation
    total_weight = 0.0
    aggregated_f = [0.0] * len(processed_features[0][0]) # Assuming fixed dim
    
    for f_ix, gamma, dist in processed_features:
        w = 1.0 / dist
        total_weight += w
        
    for f_ix, gamma, dist in processed_features:
        w = 1.0 / dist
        weight_factor = gamma * (w / total_weight)
        for k in range(len(aggregated_f)):
            aggregated_f[k] += weight_factor * f_ix[k]
            
    # 4. Radiance and Density Regression
    # MLP R takes aggregated feature and direction
    r = mlp_R(aggregated_f, d)
    
    # Density is typically predicted from the same context
    # Source implies joint regression, but specific MLP for sigma not detailed separately
    # Assuming a separate MLP or shared head for sigma
    sigma = mlp_Sigma(aggregated_f) 
    
    return sigma, r
```

## Operating characteristics
*   **Time Complexity:** Rendering requires querying neighbors for each shading sample. Complexity is $O(M \cdot K \cdot \log N)$ or $O(M \cdot K)$ with spatial indexing, where $M$ is samples per ray. Training is faster than NeRF as it avoids empty space sampling [S1].
*   **Memory Complexity:** $O(N \cdot D)$, where $N$ is the number of points and $D$ is feature dimension [S1].
*   **Strengths:** Faster optimization than NeRF (tens of minutes vs hours/days); leverages off-the-shelf reconstruction (e.g., COLMAP); automatic hole fixing via pruning/growing [S1].
*   **Limitations:** Quality depends on point cloud initialization; performance degrades in regions with sparse points [S1].

## Background
Point-NeRF was introduced by Qiangeng Xu et al. in 2022 [S1]. It builds on the idea of neural point clouds [S1].
