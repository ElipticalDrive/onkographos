# Training Setup and Baselines


## Overview
This family defines the hyperparameter configurations, optimization loops, and baseline protocols used to train neural radiance field representations. It establishes the standard reference for photometric convergence (NeRF-GT), adapts adversarial dynamics for high-fidelity synthesis (StyleGAN2), and introduces efficient feature-volume or basis-function representations to reduce memory and compute costs (NeRF with Feature Volumes, NLR). It differs from generic training articles by specifying the exact architectural inputs (e.g., feature volumes vs. raw coordinates) and loss formulations required for these specific representation types.

## Shared principles
All methods in this family optimize a neural representation to minimize the photometric difference between rendered images and ground truth training views, typically using the Mean Squared Error (MSE) loss. The core rendering equation used for computing the predicted pixel color $\hat{\mathbf{C}}(\mathbf{r})$ along a ray $\mathbf{r}$ is the discretized volume rendering integral:

$$ \hat{\mathbf{C}}(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i $$

where:
- $N$ is the number of sample points along the ray.
- $\sigma_i$ is the volume density at sample point $i$.
- $\mathbf{c}_i$ is the view-dependent color at sample point $i$.
- $\delta_i$ is the distance between adjacent samples.
- $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance up to sample $i$.

Training typically involves:
1.  **Ray Sampling:** Generating rays from camera poses and sampling points along them.
2.  **Network Query:** Evaluating the neural network to obtain $\sigma_i$ and $\mathbf{c}_i$.
3.  **Loss Computation:** Calculating $\mathcal{L} = \frac{1}{B} \sum_{k=1}^{B} \| \hat{\mathbf{C}}_k - \mathbf{C}_{gt, k} \|^2$ for a batch of $B$ rays.
4.  **Optimization:** Updating weights using gradient descent (typically Adam).

## Subtopics

### [NeRF-GT Baseline Training Setup](11349-nerf-gt-baseline-training-setup.md)
The standard NeRF training pipeline. It serves as the foundational reference for comparing advanced methods by strictly adhering to the original NeRF protocol: uniform ray sampling, multi-resolution hierarchical sampling (coarse then fine), and standard MSE loss. It differs from HDR-specific variants by not explicitly modeling high dynamic range exposure fusion, treating input as standard low dynamic range imagery. Choose this for establishing a baseline performance metric.

### [StyleGAN2 Training Configuration](12972-stylegan2-training-configuration.md)
Adapts StyleGAN2 dynamics for 3D-aware image synthesis (e.g., StyleNeRF, VoxGRAF). It solves stable adversarial training for high-resolution neural radiance fields using equalized learning rates, minibatch standard deviation, and mixed precision. It is distinguished from standard NeRF baselines by relying on GAN-specific regularization (R1) and weight averaging (EMA) rather than purely photometric supervision. Choose this when high-fidelity texture synthesis is required over geometric accuracy.

### [NeRF Training Setup](13271-nerf-training-setup.md)
Defines training for NeRFs using feature volumes instead of raw 3D coordinates, implemented via Nerfstudio with NerfAcc and Instant-NGP backends. It solves efficient scene representation by replacing positional encoding of 3D positions with sampled feature vectors from a pre-computed volume. Unlike standard NeRF baselines that encode position $\mathbf{p}$ directly, this setup uses a 64-dimensional feature vector $\mathbf{v}_s$ as the primary spatial input, enabling editable feature volumes while maintaining fast convergence on static scenes. Choose this for static scenes requiring efficient, editable representations.

### [NLR Baseline](15254-nlr-baseline.md)
Represents a scene using learned basis vectors and a neural network mapping spatial coordinates to coefficients for these bases. It solves efficient novel view synthesis by avoiding large voxel grids or dense point clouds, relying on a compact parametric representation. It differs from standard NeRF by using a linear combination of pre-learned basis vectors weighted by a neural network, rather than directly predicting density and color from coordinates. Choose this for memory-constrained environments or when a compact parametric form is preferred.

### NeuralVDB Hyperparameter Configuration
#### step
- [S1, unofficial] Batch sampling strategy: Either draw $2^{16}$ random samples per epoch, or resample a subset of input voxels at fixed intervals and draw $2^{12}$ batches per epoch. Resampling subset size = resampling intervals (100 or 500) $\times$ batch size. Use resampling when fine details with thin structures are critical.
#### parameter
- [S1, unofficial] Subdomain size: Must be a multiple of 512. Too large wastes compute on empty subdomains; too small increases dispatch overhead and causes dominant overlapping halo regions leading to redundant computation.
- [S1, unofficial] Network width: Level-1 networks use half the width of level-0 networks. Default starting point: level-0 width 128, depth 3. Use 4 layers for volumes requiring more detail capture.
- [S1, unofficial] Optimizer: Adam optimizer. Default learning rate: 0.001. Decay: 0.975 every 100 epochs (no resampling) or 0.75 every 1,000 epochs (with resampling). Max epochs: 2,500 for non-resampled; more for resampled cases.
#### comparison
- [S1, unofficial] Dense grid training produces the highest noise. Block grid (dense leaf nodes without active masks) reduces noise but still shows visible fog artifacts. Sparse VDB with active voxel masks yields the best visual quality and low noise reconstruction.

## Background
The NeRF-GT baseline originates from the original NeRF paper [S2], establishing the standard for differentiable volume rendering optimization. The StyleGAN2 configuration adapts the StyleGAN2 architecture [S1, unofficial] for 3D-aware synthesis, addressing stability issues in adversarial training for radiance fields. The feature-volume approach leverages hierarchical neural networks and sparse VDB structures, as detailed in NeuralVDB [S1, unofficial], to improve training efficiency and reconstruction quality for high-resolution volumes. The Neural Codebook method [S2] introduces a compact representation trained with specific learning rate schedules to achieve real-time radiance fields.
