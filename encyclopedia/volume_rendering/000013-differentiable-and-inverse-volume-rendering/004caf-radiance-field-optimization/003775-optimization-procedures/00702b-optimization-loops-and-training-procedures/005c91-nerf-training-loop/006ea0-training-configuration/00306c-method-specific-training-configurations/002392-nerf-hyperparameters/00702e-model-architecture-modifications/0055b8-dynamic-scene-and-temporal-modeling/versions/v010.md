# Dynamic Scene and Temporal Modeling

Also called: Dynamic NeRF, 4D Radiance Fields, Time-Conditioned NeRF

## Overview
Dynamic Scene and Temporal Modeling extends static neural radiance fields to represent and render scenes that change over time, solving the limitation of static representations for video sequences or moving objects [14705-nerf-with-time-parameter.md]. It differs from static methods by introducing temporal dependencies into the scene representation, either through direct time conditioning, explicit deformation fields, or hybrid static-dynamic structures [14705-nerf-with-time-parameter.md][15541-forward-warping-for-novel-view-synthesis.md][15550-dynamic-appearance-particle-neural-radiance-field.md].

## Shared principles
The standard NeRF architecture [Parent](3065-nerf-hyperparameters.md) serves as the baseline for most modifications. It consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ [14428-sparse-view-and-few-shot-optimization.md].

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories [14428-sparse-view-and-few-shot-optimization.md]:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation [14428-sparse-view-and-few-shot-optimization.md].
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs).

## Subtopics

### [Gear-NeRF](13848-gear-nerf.md)
Stratifies a 4D scene into discrete "gear" levels based on semantic motion scales, assigning higher-resolution feature volumes to regions with larger motion. Choose this when region-specific spatio-temporal sampling resolution is needed for efficient dynamic novel view synthesis and object tracking.

### [NeRF with Time Parameter](14705-nerf-with-time-parameter.md)
Adapts the standard NeRF architecture by concatenating a positional-encoded time parameter to the spatial coordinates. Choose this for a simple baseline dynamic representation that relies solely on input expansion without complex warping or graph structures.

### [Forward Warping for Novel View Synthesis](15541-forward-warping-for-novel-view-synthesis.md)
Models a static "canonical" radiance field and differentially warps it to target time steps using average splatting and an inpaint network. Choose this to handle many-to-one and one-to-many mapping ambiguities in dynamic scenes, achieving state-of-the-art performance on canonical frames.

### [Dynamic Appearance Particle Neural Radiance Field](15550-dynamic-appearance-particle-neural-radiance-field.md)
Superimposes a static grid-based radiance field with a particle-based dynamic field. Choose this for reconstructing time-varying scenes from monocular video without requiring multi-view stereo data or prior geometric knowledge of dynamic objects.

### [KFD-NeRF](15551-kfd-nerf.md)
Models the 4D radiance field as a dynamic system with temporally varying states, estimated using a Kalman filter to combine observations and predictions based on local linear motion. Choose this when explicit separation of motion estimation into observation and prediction branches is required, rather than direct time conditioning.

## Background
The concept of representing dynamic scenes with neural radiance fields originated with the introduction of time as a continuous input to the NeRF architecture [14705-nerf-with-time-parameter.md]. Early approaches treated time as a simple additional dimension, which improved upon vanilla NeRF but suffered from blurriness and ghosting artifacts due to a lack of explicit dynamic reasoning [14705-nerf-with-time-parameter.md]. Subsequent developments introduced more sophisticated mechanisms, such as canonical space warping [15541-forward-warping-for-novel-view-synthesis.md], semantic stratification [13848-gear-nerf.md], and hybrid particle-grid representations [15550-dynamic-appearance-particle-neural-radiance-field.md], to address the complexities of motion, occlusion, and computational efficiency in 4D scene reconstruction.
