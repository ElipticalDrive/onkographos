# Frequency-Modulated Point Cloud Rendering

Also called: AFNet, Adaptive Frequency Net, Adaptive Frequency Net (AFNet) based rendering, FreqPCR, Frequency-Modulated Radiance Mapping

## Overview
Frequency-Modulated Point Cloud Rendering is a real-time rendering pipeline that represents scenes as explicit point clouds and uses an Adaptive Frequency Net (AFNet) to modulate implicit radiance signals with local texture frequency encoding [S1]. It solves the problem of high-frequency detail reconstruction in point-based rendering, where standard MLPs suffer from spectral bias towards low-frequency signals [S1]. Unlike its siblings, it decouples frequency adaptation from the global network by using a hypernetwork to predict per-point frequency and phase parameters, enabling sharper textures and interactive editing without the computational overhead of global implicit fields [S1].

## How it works
The method consists of three main components: point cloud geometry optimization, the AFNet radiance mapping module, and a rendering pipeline that supports editing and composition.

### Inputs and Outputs
*   **Input:** A set of 3D points $\mathcal{P} = \{p_i\}_{i=1}^N$, where each point $p_i$ has a 3D position $\mathbf{x}_i \in \mathbb{R}^3$.
*   **Output:** A rendered RGB image for a given camera view.

### Data Structures
1.  **Point Cloud:** A list of $N$ points. Each point stores:
    *   Position: $\mathbf{x}_i \in \mathbb{R}^3$.
    *   Opacity: $\alpha_i \in [0, 1]$, learned during geometry optimization.
    *   Feature Vector: $\mathbf{f}_i \in \mathbb{R}^C$, the output of the AFNet radiance mapping.
2.  **AFNet Parameters:**
    *   Hypernetwork: A two-layer MLP.
    *   Adaptive Frequencies: $\boldsymbol{\omega} \in \mathbb{R}^{N \times 1}$.
    *   Adaptive Phases: $\boldsymbol{\phi} \in \mathbb{R}^{N \times 1}$.

### Steps

#### 1. Point Cloud Geometry Optimization (Preprocessing)
Standard surface point-based works often fail to optimize geometry because they keep only the closest point per ray [S1]. To address this, volume rendering is used as a preprocessing module to optimize the point cloud geometry [S1].
1.  For each pixel, cast a ray and sample multiple points from the initial point cloud along the ray.
2.  Keep more points in the pixel buffer than just the closest one [S1].
3.  Learn the opacity $\alpha_i$ of each point using volume rendering integration. This step improves rendering PSNR by 2-4dB for poorly reconstructed scenes and avoids artifacts [S1].

#### 2. AFNet Radiance Mapping
The core of the method is the Adaptive Frequency Net (AFNet), which modulates the radiance signal using local frequency encoding [S1].

**Hypernetwork for Frequency Estimation:**
A two-layer MLP hypernetwork takes the 3D position $\mathbf{x}_i$ of each point as input and predicts the adaptive frequency $\omega_i$ and phase $\phi_i$ [S1].
*   Input: $\mathbf{x}_i \in \mathbb{R}^3$.
*   Output: $\omega_i \in \mathbb{R}$, $\phi_i \in \mathbb{R}$.
*   The hypernetwork learns these parameters without explicit frequency supervision [S1].

**Adaptive Frequency Activation Layer:**
For each point $i$, the input feature $\mathbf{X}^{(i)}$ is modulated by the predicted $\omega_i$ and $\phi_i$ [S1].
*   Let $\mathbf{X}^{(i)} \in \mathbb{R}^{M \times C}$ be the input feature matrix for a batch of $M$ points, where $C$ is the feature dimension [S1].
*   Let $\boldsymbol{\omega}^{(i)} \in \mathbb{R}^{M \times 1}$ and $\boldsymbol{\phi}^{(i)} \in \mathbb{R}^{M \times 1}$ be the predicted frequencies and phases [S1].
*   The dimensions of $\boldsymbol{\omega}^{(i)}$ and $\boldsymbol{\phi}^{(i)}$ are broadcast to $M \times C$ during computation [S1].
*   The output $\mathbf{Y}^{(i)}$ is computed as:
    $$ \mathbf{Y}^{(i)} = \mathbf{X}^{(i)} \circ \sin(\boldsymbol{\omega}^{(i)} \circ \mathbf{X}^{(i)} + \boldsymbol{\phi}^{(i)}) $$
    where $\circ$ denotes the Hadamard (element-wise) product [S1].
*   This operation acts as a nonlinear filter (sinusoidal filter) parameterized by $\omega$ and $\phi$ [S1].
*   The design is theoretically justified by measuring local frequency via the derivative of color with respect to spatial coordinates and adapting the derivative by multiplying the feature by $\omega$ [S1].

**Network Architecture:**
The AFNet consists of multiple layers. Each layer typically includes:
1.  A linear transformation.
2.  An Adaptive Frequency (AF) Layer as defined above.
3.  (Optional) ReLU activation in intermediate layers, with the final layer outputting raw RGB [S1].
The final output is the RGB color for each point.

#### 3. Rendering
1.  **Depth Sorting:** Sort points along the viewing ray by depth.
2.  **Volume Integration:** Compute the final color $C$ for each pixel using alpha compositing:
    $$ C = \sum_{i \in \text{points}} c_i \alpha_i \prod_{j < i} (1 - \alpha_j) $$
    where $c_i$ is the RGB color from AFNet, and $\alpha_i$ is the opacity from geometry optimization [S1].

### Pseudocode

```python
import numpy as np

def hypernetwork_forward(positions, hypernet_weights):
    """
    Predicts frequency and phase for each point using a 2-layer MLP.
    positions: (N, 3) array of 3D coordinates.
    hypernet_weights: List of weight matrices for the 2-layer MLP.
    Returns:
        omega: (N, 1) adaptive frequencies
        phi: (N, 1) adaptive phases
    """
    # Layer 1
    h = np.dot(positions, hypernet_weights[0])
    h = np.maximum(h, 0) # ReLU
    # Layer 2
    out = np.dot(h, hypernet_weights[1])
    # Split output into omega and phi
    omega = out[:, :1]
    phi = out[:, 1:]
    return omega, phi

def adaptive_frequency_activation(X, omega, phi):
    """
    Applies the AFNet modulation to input features.
    X: (M, C) input feature matrix
    omega: (M, 1) adaptive frequencies
    phi: (M, 1) adaptive phases
    Returns:
        Y: (M, C) output feature matrix
    """
    # Broadcast omega and phi to (M, C)
    omega_broadcast = np.broadcast_to(omega, (X.shape[0], X.shape[1]))
    phi_broadcast = np.broadcast_to(phi, (X.shape[0], X.shape[1]))
    
    # Compute sin(omega * X + phi)
    sin_term = np.sin(omega_broadcast * X + phi_broadcast)
    
    # Hadamard product
    Y = X * sin_term
    return Y

def render_point_cloud(points, camera_params):
    """
    Renders the point cloud to an image.
    points: List of objects with pos, alpha, color
    camera_params: Camera intrinsics and extrinsics
    Returns:
        image: Rendered RGB image
    """
    # 1. Project points to screen space
    # 2. Sort points by depth for each pixel
    # 3. Alpha composite
    image = np.zeros((height, width, 3))
    for y in range(height):
        for x in range(width):
            ray = get_ray(camera_params, x, y)
            # Get points along ray, sorted by depth
            sorted_points = get_points_along_ray(points, ray)
            
            accumulated_alpha = 0.0
            color = np.zeros(3)
            
            for p in sorted_points:
                # p.color is from AFNet, p.alpha is from geometry optimization
                weight = p.alpha * (1 - accumulated_alpha)
                color += weight * p.color
                accumulated_alpha += weight
                if accumulated_alpha > 0.99:
                    break
            
            image[y, x] = color
    return image

def train_afnet(points, gt_images, optimizer):

            # 2. AFNet Radiance Mapping

            # Compute features through AFNet layers

            for layer in afnet_layers:
                features = layer.linear(features)
```

### Parameters
*   **Hypernetwork:** Two-layer MLP [S1].
*   **AF Layer:** Sinusoidal activation $\sin(\omega X + \phi)$ followed by element-wise multiplication with input $X$ [S1].
*   **Rendering Speed:** 39.27 FPS on NeRF-Synthetic dataset [S1].

### Edge Cases and Pitfalls
*   **Spectral Bias:** Standard MLPs with ReLU have strong spectral bias towards low-frequency signals, limiting high-frequency reconstruction [S1]. AFNet mitigates this by adaptively increasing frequency for textured regions [S1].
*   **Geometry Optimization:** Previous surface point-based works could not optimize point cloud geometry because they kept only the closest point as surface estimation for each ray [S1]. Using volume rendering with multiple points per ray avoids this [S1].
*   **Cross-Scene Training:** In multi-scene composition, a masking strategy based on the depth buffer is required to avoid cross-scene training [S1].

## Subtopics

### Differentiable Primitive Assembly
Uses differentiable rasterization of primitives (e.g., Gaussians) to render scenes. It differs from AFNet by relying on explicit primitive shapes rather than implicit radiance mapping with frequency modulation. Choose when explicit geometric control is needed. [Differentiable Primitive Assembly](13657-differentiable-primitive-assembly.md)

### Viewing Direction Gaussian Splatting
Extends Gaussian Splatting by incorporating viewing direction into the color prediction. It differs from AFNet by using spherical harmonics or MLPs for view-dependent color rather than frequency modulation of point features. Choose for view-dependent effects with Gaussian primitives. [Viewing Direction Gaussian Splatting](14273-viewing-direction-gaussian-splatting.md)

### Point-NeRF Representation
Represents the scene as a point cloud with an MLP mapping points to radiance. It differs from AFNet by using a standard MLP without adaptive frequency modulation, potentially suffering from spectral bias in textured regions. Choose for simpler implementations without frequency adaptation. [Point-NeRF Representation](15538-point-nerf-representation.md)

## Operating characteristics
*   **Time Complexity:** Real-time rendering speed of 39.27 FPS on NeRF-Synthetic dataset [S1].
*   **Speed Comparison:** 1700x faster than NeRF and 37x faster than CCNeRF [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** High-fidelity local detail reconstruction, real-time rendering, user-friendly editing (object-level editing via point cloud manipulation), and scene composition [S1].
*   **Limitations:** Requires preprocessing for geometry optimization; performance depends on the quality of the initial point cloud [S1].
*   **When to use:** When real-time rendering and high-frequency detail reconstruction are required, and interactive editing is desired [S1].
*   **When not to use:** When global implicit representation is preferred, or when editing capabilities are not needed [S1].

## Background
Frequency-Modulated Point Cloud Rendering was proposed by Zhang et al. in 2023 [S1]. It addresses the limitations of NeRF-based editing, which often requires pre-trained segmentation models for object-level editing [S1]. The method builds on the idea of Implicit Neural Representations (INRs) and HyperNetworks [S1]. It was evaluated on NeRF-Synthetic, ScanNet, DTU, and Tanks and Temples datasets [S1].
