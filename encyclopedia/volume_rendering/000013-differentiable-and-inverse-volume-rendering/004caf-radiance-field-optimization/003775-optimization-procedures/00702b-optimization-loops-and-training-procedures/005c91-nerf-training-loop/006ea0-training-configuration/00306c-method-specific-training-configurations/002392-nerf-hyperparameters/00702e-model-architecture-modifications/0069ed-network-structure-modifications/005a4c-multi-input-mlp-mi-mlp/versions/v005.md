# Multi-input MLP (mi-MLP)
Also called: mi-MLP, per-layer inputs incorporation

## Overview
The multi-input MLP (mi-MLP) is a network structure modification for Neural Radiance Fields that incorporates 3D location and 2D viewing direction inputs into every layer of the MLP to prevent overfitting in few-shot view synthesis without reducing model capacity [S1]. Unlike vanilla NeRF, which relies on deep implicit mappings from inputs to outputs, mi-MLP ensures each layer is explicitly aware of input embeddings, allowing shorter paths between inputs and outputs and enabling synthesis with fewer parameters while preserving the ability to synthesize high-frequency details [S1].

## How it works
**Inputs and Outputs:**
- **Input:** A 5D coordinate vector $\mathbf{x}$, composed of a 3D spatial location and a 2D viewing direction.
- **Output:** Volume density $\sigma$ and view-dependent color $\mathbf{c}$ for the given ray point.

**Data Structures:**
- **Positional Encoding:** The input $\mathbf{x}$ is transformed into an embedding $\gamma_L(\mathbf{x})$ using a fixed positional encoding scheme.
- **Layer Weights:** For layer $i$, weights are split into $\mathbf{w}_i^{j0}$ (connecting input embeddings) and $\mathbf{w}_i^{j1}$ (connecting previous layer features).

**Positional Encoding:**
The input $\mathbf{x}$ is encoded using $\gamma_L(\mathbf{x})$, defined as [S1]:
$$
\gamma_L(\mathbf{x}) = (\sin(2^0 \mathbf{x}), \cos(2^0 \mathbf{x}), \dots, \sin(2^{L-1} \mathbf{x}), \cos(2^{L-1} \mathbf{x}))
$$
where $L$ is a hyperparameter controlling the number of frequency bands. The dimension of $\gamma_L(\mathbf{x})$ is $2 \cdot D \cdot L$, where $D$ is the dimension of $\mathbf{x}$ (typically $D=5$ for NeRF).

**Layer Computation:**
Let $f_i$ be the output feature vector of layer $i$. The computation for layer $i$ (where $i > 1$) is [S1]:
$$
f_i = \phi_i(f_{i-1}, \gamma_L(\mathbf{x}))
$$
with the first layer defined as:
$$
f_1 = \phi_1(\gamma_L(\mathbf{x}))
$$
Here, $\phi_i$ represents the transformation of the $i$-th layer. The $j$-th element of the output feature vector $f_i$, denoted $\phi_i^j$, is computed as [S1]:
$$
\phi_i^j(\gamma_L(\mathbf{x})) = \epsilon\left( \mathbf{w}_i^{j0}[\gamma_L(\mathbf{x})] + \mathbf{w}_i^{j1}[f_{i-1}] + b_i \right)
$$
where:
- $\epsilon$ is the activation function (default ReLU) [S1].
- $b_i \in \mathbb{R}^{d_2 \times 1}$ is the bias vector for layer $i$ [S1].
- $\mathbf{w}_i^{j0} \in \mathbb{R}^{1 \times d_1}$ are the weights connecting the input embedding to the $j$-th neuron, where $d_1$ is the dimension of $\gamma_L(\mathbf{x})$ [S1].
- $\mathbf{w}_i^{j1} \in \mathbb{R}^{1 \times d_2}$ are the weights connecting the previous layer's output to the $j$-th neuron, where $d_2$ is the hidden dimension of the MLP [S1].
- $f_{i-1}$ is the output of the previous layer, $f_{i-1} = \phi_{i-1}(\gamma_L(\mathbf{x}))$ [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import math

class PositionalEncoding(nn.Module):
    def __init__(self, num_frequencies):
        super().__init__()
        self.num_frequencies = num_frequencies

    def forward(self, x):
        # x shape: (..., 5) for (x, y, z, theta, phi)
        # Output shape: (..., 2 * 5 * num_frequencies)
        device = x.device
        # Create frequency bands
        bands = torch.pow(2.0, torch.arange(self.num_frequencies, device=device).float())
        # Expand bands to match input dimensions
        bands = bands.view(1, 1, -1) # (1, 1, L)
        # Scale input
        scaled_x = x.unsqueeze(-1) * bands # (..., 5, L)
        # Apply sin and cos
        encoded = torch.cat([torch.sin(scaled_x), torch.cos(scaled_x)], dim=-1) # (..., 5, 2*L)
        return encoded.view(*x.shape[:-1], -1) # (..., 10*L)

class MiMLPLayer(nn.Module):
    def __init__(self, input_dim, hidden_dim):
        super().__init__()
        self.input_dim = input_dim
        self.hidden_dim = hidden_dim
        # w0 connects positional encoding (input_dim) to hidden_dim
        self.w0 = nn.Linear(input_dim, hidden_dim, bias=False)
        # w1 connects previous hidden state (hidden_dim) to hidden_dim
        self.w1 = nn.Linear(hidden_dim, hidden_dim, bias=False)
        self.b = nn.Parameter(torch.zeros(hidden_dim))
        self.activation = nn.ReLU()

    def forward(self, prev_hidden, pos_encoding):
        # pos_encoding shape: (..., input_dim)
        # prev_hidden shape: (..., hidden_dim) or None for first layer
        term_input = self.w0(pos_encoding)
        if prev_hidden is not None:
            term_prev = self.w1(prev_hidden)
            out = self.activation(term_input + term_prev + self.b)
        else:
            out = self.activation(term_input + self.b)
        return out

class MiMLP(nn.Module):
    def __init__(self, num_layers, hidden_dim, num_frequencies):
        super().__init__()
        self.num_layers = num_layers
        self.hidden_dim = hidden_dim
        # Input dimension for positional encoding: 5 coords * 2 * L
        self.input_dim = 5 * 2 * num_frequencies
        
        self.pos_encoder = PositionalEncoding(num_frequencies)
        
        # Layers 1 to num_layers
        # Layer 1 takes only pos_encoding
        self.layers = nn.ModuleList()
        for i in range(num_layers):
            self.layers.append(MiMLPLayer(self.input_dim, self.hidden_dim))
            
        # Final output layer (standard linear layer)
        self.final_layer = nn.Linear(hidden_dim, 4) # 3 for color, 1 for density

    def forward(self, x):
        # x shape: (..., 5)
        pos_encoding = self.pos_encoder(x)
        
        hidden = None
        for i, layer in enumerate(self.layers):
            if i == 0:
                # First layer: no previous hidden state
                hidden = layer(None, pos_encoding)
            else:
                # Subsequent layers: concatenate previous hidden state
                hidden = layer(hidden, pos_encoding)
                
        output = self.final_layer(hidden)
        return output
```

**Parameters:**
- **$L$ (Number of frequencies):** Controls the resolution of the positional encoding. Not given in the sources.
- **Weight Initialization:** Default PyTorch initialization is used. This satisfies the condition $\|\mathbf{w}_i^{j1}\|_1 \in (0, 1]$ [S1].
- **Activation Function:** ReLU is the default [S1].

**Edge Cases and Pitfalls:**
- **Gradient Amplitude Imbalance:** During early training, vanilla MLPs exhibit similar gradient amplitudes across all layers. In contrast, mi-MLP ensures that deeper layers (closer to the output) receive large gradients while shallower layers receive extremely small ones [S1]. This behavior is theoretically supported by the ratio of gradient amplitudes between adjacent layers [S1]:
  $$
  \| \frac{\partial \mathcal{L}}{\partial \mathbf{w}_i} \|_1 / \| \frac{\partial \mathcal{L}}{\partial \mathbf{w}_{i-1}} \|_1 = \frac{1}{d_2} \sum_{j=1}^{d_2} \frac{\|\gamma_L(\mathbf{x})\|_1 + \|f_{i-1}\|_1}{\|\sum \mathbf{w}_i^{j1}\|_1 \cdot \{\|\gamma_L(\mathbf{x})\|_1 + \|f_{i-2}\|_1\}}
  $$
  where $\mathcal{L}$ is the loss function and $d_2$ is the output dimension of the layer [S1].
- **Overfitting:** The primary motivation for mi-MLP is to alleviate overfitting in few-shot view synthesis by providing explicit input connections at every layer, which allows for flexible connections between inputs and outputs [S1].

- **Strengths:** Prevents overfitting in few-shot scenarios without reducing model capacity; allows shorter paths between inputs and outputs; acts as a plug-and-play solution for existing NeRF pipelines [S1].

- **When to use:** When performing few-shot view synthesis where standard NeRF overfits, but maintaining high-frequency detail synthesis capability is required [S1].

## Background
The multi-input MLP (mi-MLP) was proposed in 2024 by the authors of "Is Vanilla MLP in Neural Radiance Field Enough for Few-Shot View Synthesis?" [S1]. It addresses the observation that trivially reducing model parameters alleviates overfitting but harms detail synthesis. The method provides an orthogonal approach by modifying the network structure to incorporate inputs into each layer, revealing that explicit awareness of input embeddings at every layer alleviates overfitting while preserving capacity [S1].
