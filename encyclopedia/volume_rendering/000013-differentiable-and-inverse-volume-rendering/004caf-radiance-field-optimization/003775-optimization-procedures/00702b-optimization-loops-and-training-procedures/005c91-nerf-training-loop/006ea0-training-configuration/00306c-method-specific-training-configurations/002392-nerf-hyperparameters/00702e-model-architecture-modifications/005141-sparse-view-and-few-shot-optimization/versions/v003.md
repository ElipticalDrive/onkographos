# Sparse View and Few-Shot Optimization

Also called: Sparse-View NeRF, Few-Shot NeRF

## Overview
Sparse View and Few-Shot Optimization addresses the degradation of Neural Radiance Field (NeRF) quality when the number of input training viewpoints $|S|$ is drastically reduced (typically $|S| < 20$) compared to the standard setting of over 100 images [12317-few-shot-nerf.md]. In this regime, standard NeRF architectures suffer from high divergent behaviors, including geometry breakdown, overfitting to input viewpoints, and the generation of artifacts in empty space [12317-few-shot-nerf.md]. This family sets itself apart by focusing on stabilizing optimization under severe data scarcity through specific architectural constraints, regularization, or data densification, rather than relying on large-scale pre-training or external depth priors alone.

## Shared principles
The standard NeRF architecture [Parent](3065-nerf-hyperparameters.md) serves as the baseline for most modifications. It consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ [14428-sparse-view-and-few-shot-optimization.md].

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories [14428-sparse-view-and-few-shot-optimization.md]:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation [14428-sparse-view-and-few-shot-optimization.md].
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs).

## Subtopics

### [Simple-NeRF](7371-simple-nerf.md)
A regularization method that trains two simpler "augmented" NeRF models (Smoothing and Lambertian) in tandem with a main NeRF. It mitigates overfitting and floaters by learning in-situ depth supervision, using a reliability mask to select only trustworthy depth estimates from the augmented models. Choose this when you need to mitigate shape-radiance ambiguity without external depth priors.

### [WaH-NeRF](11548-wah-nerf.md)
A framework that addresses sample-position confusion ('WHERE to Sample?') and prediction confusion ('HOW to Predict?') using deformable sampling and semi-supervised learning. It differs from Simple-NeRF by analyzing the sample-render process and mitigating confusion before volume rendering. Choose this when sample-position confusion is the primary issue due to sparse inputs.

### [Deceptive-NeRF/3DGS](11859-deceptive-nerf-3dgs.md)
A method that mitigates overfitting by densifying input observations with photorealistic pseudo-observations generated via a 2D diffusion model. Unlike methods using diffusion as per-step regularizers (e.g., SDS), it treats generated pseudo-observations as real training views. Choose this when computational cost of per-step diffusion is prohibitive but view densification is desired.

### [Few-shot NeRF](12317-few-shot-nerf.md)
Addresses the general degradation of NeRF quality with $|S| < 20$ by operating on the same continuous function representation but requiring specific architectural or regularization modifications. Choose this as a baseline understanding of the few-shot regime's challenges (geometry breakdown, overfitting).

### [FlipNeRF](12967-flipnerf.md)
A regularization method that generates auxiliary 'flipped reflection rays' from original input rays and estimated surface normals. It sets itself apart by deriving additional training rays directly from geometric estimates rather than using heuristic unseen-viewpoint sampling. Choose this when surface normal accuracy and reflection consistency are critical.

## Background
The problem of sparse-view reconstruction in NeRFs was identified as a significant limitation of the original NeRF architecture, which requires dense input views to avoid overfitting and artifacts [12317-few-shot-nerf.md]. Various approaches have been developed to address this, including regularization via auxiliary models [7371-simple-nerf.md], adaptive sampling [11548-wah-nerf.md], diffusion-based data augmentation [11859-deceptive-nerf-3dgs.md], and geometric consistency constraints [12967-flipnerf.md]. These methods aim to stabilize the optimization landscape and improve generalization when data is scarce.
