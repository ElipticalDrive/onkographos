# NLR Baseline

Also called: Neural Lumigraph Representation Baseline, NLR

## Overview
The NLR Baseline serves as a foundational reference for differentiable volume rendering by implementing the Neural Lumigraph Representation [3]. It solves the problem of novel view synthesis by learning a continuous radiance field parameterized by neural networks, optimized via stochastic gradient descent to minimize photometric error between rendered and ground-truth images. It is distinguished from its siblings by its specific architectural choice of decoupled shape and color networks trained via standard backpropagation, providing a performance benchmark against meta-learning approaches like MetaNLR.

## How it works
The method operates within the standard differentiable volume rendering pipeline. It learns a 3D scene representation by optimizing neural network weights to predict density and color for points sampled along rays.

**Inputs and Outputs:**
*   **Inputs:** A set of calibrated training images with known camera poses.
*   **Outputs:** A trained neural network model capable of rendering novel views of the scene.

**Data Structures:**
The implementation utilizes two primary neural networks:
1.  **Shape Network:** Predicts volume density ($\sigma$) and positional encoding features.
2.  **Color Network:** Predicts view-dependent color ($c$) using the features from the shape network and the viewing direction.
*Note: Specific network architectures (layer counts, hidden sizes, activation functions) are not detailed in the provided sources [S1, unofficial].*

**Algorithm Steps:**
1.  **Initialization:** Initialize the weights for the shape and color networks.
2.  **Ray Sampling:** For each training image, generate rays from camera centers through pixel centers. Sample points along these rays.
3.  **Network Query:** For each sampled point, query the shape network to obtain density and features. Query the color network to obtain color.
4.  **Volume Rendering:** Compute the pixel color using the differentiable volume rendering integral, combining density and color along the ray.
5.  **Loss Computation:** Calculate the Mean Squared Error (MSE) between the rendered pixel colors and the ground truth training images.
6.  **Optimization:** Update network weights using stochastic gradient descent to minimize the loss.
7.  **Iteration:** Repeat steps 2-6 for a fixed number of iterations or until convergence.

**Parameters:**
*   **Resolution:** Training and testing views are processed at 800 × 600 resolution [S1, unofficial].
*   **Learning Rate:** Not explicitly specified for the standard NLR baseline in the sources; however, the MetaNLR variant uses a meta-learning rate of $5 \times 10^{-2}$ [S1, unofficial].
*   **Iterations:** The number of iterations is not specified, but timing is extrapolated from per-iteration costs [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** Standard floating-point precision is assumed for the rendering integral.
*   **Boundaries:** Ray sampling must be bounded within the scene extent to avoid undefined network queries.
*   **Degenerate Input:** Requires accurate camera poses; inaccurate poses (as noted in comparisons with SVS*) can degrade performance [S1, unofficial].

## Subtopics

### MetaNLR Baseline
MetaNLR is a variant of NLR that wraps the standard NLR implementation with an outer meta-learning loop using the Reptile algorithm [10]. It learns the initialization of the shape and color networks to enable rapid specialization to new scenes. It is chosen when few-shot adaptation to new scenes is required. It uses the same architecture as NLR++ but performs no shape optimization during the inner loop, optimizing only the feature processing networks. The meta-learning rate is set to $5 \times 10^{-2}$ [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The training time is 2.21 seconds per iteration [S1, unofficial]. This is significantly slower than NeRF (0.40 sec/iteration) and IDR (0.2 sec/iteration) but comparable to NLR++ (2.19 sec/iteration without shape optimization) [S1, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Rendering Time:** Rendering time is 0.025 seconds per frame [S1, unofficial].
*   **Scaling:** MetaNLR/NLR++ iterations take longer because they optimize the representation for multiple entire images rather than randomly selected rays, resulting in larger ray-batch sizes [S1, unofficial]. However, they require significantly fewer iterations to converge [S1, unofficial].
*   **Strengths:** Provides a stable baseline for neural radiance fields; MetaNLR variant enables fast adaptation to new scenes.
*   **Limitations:** High per-iteration training time compared to some alternatives; requires careful tuning of meta-learning hyperparameters for the MetaNLR variant.
*   **When to use:** Use as a baseline for comparing novel view synthesis methods; use MetaNLR when few-shot learning capabilities are needed.

## Background
The NLR Baseline is based on the Neural Lumigraph Representation [3]. The specific implementation and timing results cited here are from the paper "Fast Training of Neural Lumigraph Representations using Meta Learning" [S1, unofficial]. The work builds upon the original NLR method, extending it with meta-learning techniques (MetaNLR) to accelerate adaptation to new scenes.
