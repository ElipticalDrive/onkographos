# Interval Score Matching
Also called: LucidDreamer (ISM)

## Overview
Interval Score Matching (ISM) is a modification to Score Distillation Sampling (SDS) that replaces the standard Denoising Diffusion Probabilistic Model (DDPM) forward process with Denoising Diffusion Implicit Model (DDIM) inversion [S1][S2, unofficial]. It introduces supervision from multiple interval steps of the diffusion process to mitigate the high error associated with one-step reconstruction [S1][S2, unofficial]. It is distinguished from siblings like Renoised Score Distillation (RSD) by its specific use of DDIM inversion to define the noise perturbation target rather than re-noising or standard DDPM sampling [S1][S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A radiance field $\Theta$ (e.g., NeRF, 3DGS), a frozen diffusion model $\epsilon_\theta$, a text prompt, and a set of interval steps $\mathcal{T} = \{t_1, t_2, \dots, t_k\}$ within the diffusion timeline.
- Output: Gradient $\nabla_\Theta L_{ISM}$ for updating $\Theta$.

**Data Structures:**
- $\mathcal{T}$: A list of integer timesteps $t \in [1, T]$ where $T$ is the total number of diffusion steps. The specific values of $\mathcal{T}$ are not given in the sources [S1][S2, unofficial].

**Method Steps:**
1. **Render:** Render an image $I$ from the radiance field $\Theta$ using a camera pose.
2. **Encode:** Encode $I$ into a latent space $z_0$ if using a latent diffusion model, or use $I$ directly if pixel-space.
3. **DDIM Inversion:** Instead of adding noise via the DDPM forward process, apply DDIM inversion to $z_0$ to obtain a noisy latent $z_t$ at a specific timestep $t$. This step is crucial for defining the target noise [S1][S2, unofficial].
4. **Noise Prediction:** For each interval step $t_i \in \mathcal{T}$, pass $z_{t_i}$, $t_i$, and the text prompt into the frozen diffusion model $\epsilon_\theta$ to predict the noise $\hat{\epsilon}_{t_i}$ [S1][S2, unofficial].
5. **Loss Computation:** Compute the loss by comparing the predicted noise $\hat{\epsilon}_{t_i}$ with the actual noise added during the DDIM inversion process. The sources state that supervision is introduced from these interval steps to avoid large error in one-step reconstruction [S1][S2, unofficial]. The exact mathematical formulation of the loss function combining these interval steps is not given in the sources [S1][S2, unofficial].
6. **Backpropagation:** Backpropagate the loss through the diffusion model and the differentiable renderer to compute $\nabla_\Theta L_{ISM}$ [S1][S2, unofficial].
7. **Update:** Update $\Theta$ using the computed gradient [S1][S2, unofficial].

**Edge Cases and Pitfalls:**
- The choice of interval steps $\mathcal{T}$ is critical but not specified in the sources [S1][S2, unofficial].
- DDIM inversion requires the diffusion model to be consistent with the inversion algorithm [S1][S2, unofficial].

## Subtopics

### LucidDreamer
The primary method that introduced ISM. It uses ISM to replace DDPM in SDS with DDIM inversion to improve 3D asset generation quality [S1][S2, unofficial]. See [LucidDreamer](link).

### DDIM Inversion
The mathematical process used to invert the diffusion forward process, allowing for deterministic sampling from noise to data. See [DDIM Inversion](link).

## Operating characteristics
- **Time Complexity:** Depends on the number of interval steps $|\mathcal{T}|$ and the cost of DDIM inversion. Each interval step requires a forward pass through the diffusion model.
- **Memory Complexity:** Similar to standard SDS, but may require storing intermediate latents for inversion.
- **Strengths:** Avoids high error in one-step reconstruction by leveraging multiple interval steps [S1][S2, unofficial].
- **Limitations:** Requires implementing DDIM inversion, which is more complex than standard DDPM noise addition [S1][S2, unofficial].
- **When to use:** When standard SDS suffers from reconstruction errors or when higher fidelity is needed from the diffusion prior [S1][S2, unofficial].

## Background
Interval Score Matching was proposed by LucidDreamer [S1][S2, unofficial]. It addresses the limitations of standard SDS which relies on DDPM forward process, aiming to reduce reconstruction errors by using DDIM inversion and interval supervision [S1][S2, unofficial]. It is used in 3D generation pipelines involving NeRF, 3DGS, and DMTet [S1][S2, unofficial].
