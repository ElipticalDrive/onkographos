# KFD-NeRF

Also called: Kalman Filter Guided Deformation Field NeRF, Kalman Filter Guided Dynamic NeRF

## Overview
KFD-NeRF is a dynamic neural radiance field method that models the 4D radiance field as a dynamic system with temporally varying states, estimated using a Kalman filter to combine observations from input data and predictions based on local linear motion equations [S1]. It differs from sibling methods like [Gear-NeRF](13848-gear-nerf.md) and [NeRF with Time Parameter](14705-nerf-with-time-parameter.md) by explicitly treating deformation estimation as a state estimation problem, using a Kalman gain to weight a shallow MLP-based observer against a physics-based predictor, rather than relying solely on direct time-conditioned feature interpolation or static canonical warping [S1].

## How it works
KFD-NeRF builds on [Dynamic Scene and Temporal Modeling](15546-dynamic-scene-and-temporal-modeling.md) by employing a **Canonical Space Warping** strategy where a deformation field maps dynamic points to a time-independent canonical space [S1]. It uses a **Tri-plane** spatial representation for the canonical space, which allows for a shallower observation network compared to MLP-only backbones [S1].

### Inputs and Outputs
*   **Inputs:** 3D point coordinates $\mathbf{x} \in \mathbb{R}^3$, viewing direction $\mathbf{d} \in \mathbb{R}^3$, and timestamp $t_i \in \mathbb{R}$.
*   **Outputs:** Deformation $\Delta \mathbf{x}$ (state $d\mathbf{x}_{t_i}$), density $\sigma$, and color $c$ in the canonical space.

### Data Structures
1.  **Tri-plane Representation:** Three mutually orthogonal 2D planes encoding the canonical space [S1]. Features are concatenated with raw coordinate inputs to handle coordinate shift errors [S1].
2.  **Observer MLP:** A two-layer shallow MLP that takes $\mathbf{x}$ and $t_i$ as input [S1].
    *   **Output:** Mean observation $y_{t_i}$ and noise-related terms $\varepsilon_{t_i}$ [S1].
3.  **Kalman Gain Network:** A linear layer $f$ that takes $\varepsilon_{t_i}, \varepsilon_{t_{i-1}}$ and $t_i, t_{i-1}$ as input [S1].
    *   **Output:** Kalman gain $K_{t_i}$ [S1].

### Algorithm Steps
The deformation estimation for a point $\mathbf{x}$ at time $t_i$ follows these steps:

1.  **Observer Query (Current Frame):**
    Query the observer MLP with $\mathbf{x}$ and $t_i$ to obtain the mean observation $y_{t_i}$ and noise terms $\varepsilon_{t_i}$ [S1].
    $$ y_{t_i}, \varepsilon_{t_i} = \text{Observer}(\mathbf{x}, t_i) $$

2.  **Prediction (History-Based):**
    Calculate the velocity $v_{t_i}$ using deformations from the previous two frames $t_{i-1}$ and $t_{i-2}$ [S1]:
    $$ v_{t_i} = \frac{d\mathbf{x}_{t_{i-1}} - d\mathbf{x}_{t_{i-2}}}{\Delta t_i} $$
    Compute the predicted deformation $\hat{d\mathbf{x}}_{t_i}^{-}$ using local linear motion:
    $$ \hat{d\mathbf{x}}_{t_i}^{-} = d\mathbf{x}_{t_{i-1}} + \Delta t_i \cdot v_{t_i} = 2d\mathbf{x}_{t_{i-1}} - d\mathbf{x}_{t_{i-2}} $$
    *(Note: The source provides the simplified form $2d\mathbf{x}_{t_{i-1}} - d\mathbf{x}_{t_{i-2}}$ in Algorithm 1 [S1])*

3.  **Kalman Gain Calculation:**
    Compute the Kalman gain $K_{t_i}$ using the linear layer $f$ and noise terms from current and previous frames [S1]:
    $$ K_{t_i} = f(\varepsilon_{t_i}, \varepsilon_{t_{i-1}}, t_i, t_{i-1}) $$

4.  **State Update (Deformation Estimation):**
    Combine the observation $y_{t_i}$ and prediction $\hat{d\mathbf{x}}_{t_i}^{-}$ using the Kalman gain [S1]:
    $$ \hat{d\mathbf{x}}_{t_i} = \hat{d\mathbf{x}}_{t_i}^{-} + K_{t_i} (y_{t_i} - \hat{d\mathbf{x}}_{t_i}^{-}) $$

5.  **Warping and Rendering:**
    Warp the point $\mathbf{x}$ to the canonical space using $\hat{d\mathbf{x}}_{t_i}$, then query the tri-plane representation for density and color [S1].

### Loss Functions
The total loss $\mathcal{L}$ is a weighted sum of five components [S1]:

$$ \mathcal{L} = \mathcal{L}_{image} + \mathcal{L}_{kf} + \mathcal{L}_{co} + \mathcal{L}_{prop} + \lambda_{tv} \mathcal{L}_{tv} $$

1.  **Image Loss ($\mathcal{L}_{image}$):** Standard photometric reconstruction loss [S1].
2.  **Kalman Loss ($\mathcal{L}_{kf}$):** Minimizes the error between the observation and the final estimated deformation [S1]:
    $$ \mathcal{L}_{kf} = \frac{1}{\mathcal{N}} \sum_{\mathbf{x} \in \mathcal{N}} \| y_{t_i} - \hat{d\mathbf{x}}_{t_i} \|_2^2 $$
3.  **Canonical Observation Loss ($\mathcal{L}_{co}$):** Soft regularization for the initial frame $t_0$ to normalize the canonical space [S1]:
    $$ \mathcal{L}_{co} = \frac{1}{\mathcal{N}} \sum_{\mathbf{x} \in \mathcal{N}} \mathbb{1}(t) d\mathbf{x} $$
    where $\mathbb{1}(t) = 1$ if $t=0$ and $0$ otherwise.
4.  **Proposal Loss ($\mathcal{L}_{prop}$):** Ensures consistency between the proposal network (for occupancy estimation) and the learned model [S1].
5.  **Total Variation Loss ($\mathcal{L}_{tv}$):** Encourages sparse edges in the tri-plane representation [S1]:
    $$ \mathcal{L}_{tv}(\mathbf{x}) = \frac{1}{|C|} \sum_{c, i, j} (\| \mathbf{x}_c^{i,j} - \mathbf{x}_c^{i-1,j} \|_2^2 + \| \mathbf{x}_c^{i,j} - \mathbf{x}_c^{i,j-1} \|_2^2) $$
    where $c$ is a plane from the tri-plane collection $C$, and $i, j$ are spatial indices [S1].

### Parameters
*   **Total Variation Weight ($\lambda_{tv}$):** $1 \times 10^{-4}$ [S1].
*   **Observer MLP Depth:** 2 layers [S1].

### Pseudocode
```python
def kfd_nerf_deformation(x, t_i, t_prev_1, t_prev_2, observer_mlp, kalman_gain_net):
    """
    Computes the deformation for point x at time t_i using Kalman Filter guidance.
    
    Args:
        x: 3D point coordinates (tensor)
        t_i: Current timestamp (float)
        t_prev_1: Previous timestamp (float)
        t_prev_2: Timestamp before previous (float)
        observer_mlp: Two-layer MLP returning (observation, noise_terms)
        kalman_gain_net: Linear layer returning Kalman gain
        
    Returns:
        estimated_deformation: Deformation vector for x at t_i
    """
    # 1. Observer Step for Current Frame
    y_t, eps_t = observer_mlp(x, t_i)
    
    # 2. Observer Step for Previous Frames (needed for prediction)
    # Note: In training, these are retrieved from the previous iteration's state
    d_x_prev_1, eps_prev_1 = observer_mlp(x, t_prev_1)
    d_x_prev_2, eps_prev_2 = observer_mlp(x, t_prev_2)
    
    # 3. Prediction Step
    # Calculate velocity based on local linear motion
    delta_t = t_i - t_prev_1
    velocity = (d_x_prev_1 - d_x_prev_2) / delta_t
    
    # Predicted deformation: d_x_prev_1 + delta_t * velocity
    # Simplified: 2 * d_x_prev_1 - d_x_prev_2
    d_x_pred = 2 * d_x_prev_1 - d_x_prev_2
    
    # 4. Kalman Gain Calculation
    # Input: noise terms from current and previous frame, and timestamps
    K_t = kalman_gain_net(eps_t, eps_prev_1, t_i, t_prev_1)
    
    # 5. Update Step
    # Weighted combination of prediction and observation
    estimated_deformation = d_x_pred + K_t * (y_t - d_x_pred)
    
    return estimated_deformation
```

### Edge Cases and Pitfalls
*   **Initial Training Stages:** Predictions primarily influence the process to facilitate convergence for frames with substantial motion, as observations may lack confidence [S1].
*   **Later Training Stages:** Observations take precedence to recover precise and fine-grained motion details as the observer MLP learns [S1].
*   **Coordinate Shift Errors:** Finite resolution tri-planes introduce coordinate shift errors; concatenating raw coordinates with encoded features mitigates this [S1].
*   **Canonical Space Complexity:** Hard masking (setting deformation to 0 at $t_0$) can make the canonical space too complex for warping; KFD-NeRF uses a soft regularization term instead [S1].

## Operating characteristics
*   **Performance (Synthetic Data):** PSNR 35.73 dB, SSIM 0.984, LPIPS 0.045, Average 0.0131 [S1].
*   **Performance (Real Data):** PSNR 28.75 dB, SSIM 0.891, LPIPS 0.115, Average 0.0389 [S1].
*   **Training Time:** 30 minutes for KFD-NeRF-S, 3 hours for KFD-NeRF-L (on Nvidia Real Dynamic Scenes Dataset) [S1].
*   **Parameter Size:** 175 MB for both KFD-NeRF-S and KFD-NeRF-L [S1].
*   **Strengths:** Faster convergence and lower memory footprint than MLP-based backbones (e.g., D-NeRF) due to tri-plane representation; superior view synthesis performance compared to baselines like D-NeRF, TiNeuVox-B, and KPlanes [S1].
*   **Limitations:** Relies on the assumption of locally linear motion, which may struggle with highly non-linear or abrupt motions not captured by the two-frame history [S1].

## Background
KFD-NeRF was introduced by Y. Zhan, Z. Li, et al. in 2024, drawing inspiration from control theory to model 4D radiance fields as dynamic systems [S1]. It addresses the limitations of previous dynamic NeRF methods that either disregard motion priors or rely on deep MLPs that suffer from slow convergence and high memory usage [S1]. The method integrates a Kalman filter module to optimize state estimations, combining direct observations with predictions based on motion equations [S1].
