# VisionNeRF

Also called: Vision Transformer for NeRF

## Overview
VisionNeRF is a novel view synthesis method that infers a 3D representation from a single unposed input image by combining global features learned from a Vision Transformer (ViT) and local appearance features extracted from a 2D CNN, rendered via a NeRF-based MLP [S1]. It addresses the degradation of rendering quality in occluded regions caused by self-occlusion in standard image-conditioned models, which incorrectly query features from visible surfaces when the target view pixel is invisible from the input view [S1]. Unlike [ViT-NeRF](13878-vit-nerf.md) which focuses on multi-view consistency or [TransNeRF](13907-transnerf.md) which may use different transformer architectures for scene encoding, VisionNeRF explicitly constructs a hybrid 3D representation using global ViT tokens and local CNN features to enable long-range dependency modeling for unseen regions without requiring camera pose information [S1].

## How it works
**Inputs and Outputs:**
*   Input: A single unposed image $I_s$ at camera $s$. No camera pose information is required [S1].
*   Output: A rendered novel view image for a target camera position and orientation [S1].

**Data Structures:**
1.  **Feature Tokens:** A sequence of vectors produced by the ViT encoder. If the input image is $H \times W$ and the ViT uses patches of size $P \times P$, the number of tokens is $N = (H/P) \times (W/P)$. Each token is a vector of dimension $D_{vit}$ [S1].
2.  **Multi-level Feature Maps:** A set of 2D feature maps at different resolutions, derived from unflattening and resampling the ViT tokens [S1].
3.  **Local Feature Maps:** 2D feature maps extracted by the CNN backbone, capturing local details [S1].
4.  **Radiance Field MLP:** A multi-layer perceptron that takes 3D coordinates, viewing directions, and fused features as input to predict density $\sigma$ and color $\mathbf{c}$ [S1].

**Steps:**
1.  **Global Feature Extraction:** Lift the input 2D image $I_s$ into feature tokens and apply a Vision Transformer (ViT) to learn global information [S1].
2.  **Global Feature Resampling:** Unflatten the feature tokens and resample them into multi-level feature maps to capture global information in a coarse-to-fine manner [S1].
3.  **Local Feature Extraction:** Extract local features from the input image using a 2D convolutional neural network (CNN) to capture details and appearance [S1].
4.  **Feature Fusion and Conditioning:** For a 3D point $\mathbf{x}$ sampled along a ray, project it to the input image plane to get $\pi(\mathbf{x})$. Query the global multi-level feature maps and local CNN feature maps at $\pi(\mathbf{x})$. Fuse these features.
5.  **Volume Rendering:** Pass the 3D point $\mathbf{x}$, viewing direction $\mathbf{d}$, and the fused features into the Radiance Field MLP to predict density $\sigma$ and color $\mathbf{c}$. Perform standard volumetric rendering to produce the final pixel color [S1].

**Pseudocode:**
```python
def vision_nerf_render(ray_origins, ray_directions, input_image):
    # Step 1: Global Feature Extraction
    # Lift image to tokens and apply ViT
    # Assume ViT processes patches of size P x P
    H, W, C = input_image.shape
    P = 16  # Example patch size
    num_patches_h = H // P
    num_patches_w = W // P
    
    # Extract patches and linear projection to get tokens
    patches = extract_patches(input_image, patch_size=P) # Shape: (N, P*P*C)
    tokens = linear_projection(patches) # Shape: (N, D_vit)
    
    # Apply Vision Transformer encoder layers (Self-Attention + MLP)
    global_tokens = vit_encoder(tokens) # Shape: (N, D_vit)
    
    # Step 2: Global Feature Resampling
    # Reshape tokens back to spatial grid
    global_grid = reshape_tokens_to_grid(global_tokens, num_patches_h, num_patches_w, D_vit)
    
    # Resample to multiple levels (coarse-to-fine)
    # This creates a pyramid of feature maps
    global_features_pyramid = resample_to_levels(global_grid, levels=[1, 2, 4]) 
    # Each level is a feature map of shape (H_i, W_i, D_vit)
    
    # Step 3: Local Feature Extraction
    # Extract local features using a CNN backbone
    local_features = cnn_backbone(input_image) # Shape: (H, W, D_cnn)
    
    # Step 4: Feature Fusion and Conditioning
    # For each ray, sample points and query features
    num_samples = 128
    z_vals = sample_z_vals(ray_origins, ray_directions, num_samples)
    points_3d = ray_origins + ray_directions * z_vals[:, None] # Shape: (Batch, N_samples, 3)
    
    # Project 3D points to 2D image plane to get 2D coordinates
    # This requires the intrinsic matrix K of the input camera
    # Since input is unposed, we assume the input image corresponds to a known 
    # canonical view or the projection is done relative to the input view's 
    # coordinate system. The method assumes an explicit mapping between 
    # input image pixels and 3D points.
    uv_coords = project_to_2d(points_3d, K) # Shape: (Batch, N_samples, 2)
    
    # Query global features from pyramid
    # Interpolate from the appropriate level based on depth or fixed strategy
    global_feat = interpolate_features(uv_coords, global_features_pyramid)
    
    # Query local features
    local_feat = interpolate_features(uv_coords, local_features)
    
    # Fuse features (e.g., concatenation or addition)
    fused_feat = concatenate(global_feat, local_feat)
    
    # Step 5: Volume Rendering
    # Pass points, directions, and fused features to MLP
    # Directions are normalized ray directions
    density_and_color = radiance_field_mlp(points_3d, ray_directions, fused_feat)
    
    sigma = density_and_color[..., 0] # Density
    color = density_and_color[..., 1:] # Color
    
    # Standard volumetric rendering
    weights = compute_weights(sigma, z_vals)
    rendered_color = sum(weights * color)
    
    return rendered_color
```

**Parameters:**
*   Input: A single unposed image $I_s$ [S1].
*   Coordinate System: Viewer-centered coordinate system. The method does not enforce constraints like symmetry or canonical coordinate systems [S1].
*   Dataset: ShapeNet dataset including 13 object categories, as well as real-world images [S1].

**Edge Cases and Pitfalls:**
*   **Self-occlusion:** When a target view pixel is invisible from the input view, standard image-conditioned models incorrectly use features from other visible surfaces (e.g., using window features to render a wheel). VisionNeRF mitigates this by using self-attention to find long-range dependencies, allowing it to retrieve relevant features from distant parts of the source view for occluded regions [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:** On the ShapeNet dataset, the method achieves LPIPS: 0.09 and PSNR: 21.03 for novel views, compared to PixelNeRF's LPIPS: 0.20 and PSNR: 21.85 [S1].
*   **Scaling:** Not given in the sources.
*   **Strengths:** Renders richer details in occluded regions compared to existing approaches like PixelNeRF [S1]. Generalizes across multiple object categories using a single model [S1]. Works well on real-world images [S1].
*   **Limitations:** Not given in the sources.
*   **When to use it:** When novel view synthesis from a single unposed image is required, especially for scenes with significant self-occlusion where local features alone are insufficient [S1].
*   **When not:** When camera pose information is available and multi-view consistency is already well-handled by other methods, or when computational resources are extremely limited and the overhead of ViT is prohibitive (though specific metrics are not provided).

## Background
VisionNeRF was proposed by Wei-Sheng Lai, Ravi Ramamoorthi, and Tsung-Yi Lin, with work done while interning at Google and at Google respectively [S1]. It was published in 2023 [S1]. The method addresses the problem of novel view synthesis from a single unposed image, building on the limitations of existing approaches that use local image features to reconstruct 3D objects, which often render blurry predictions at viewpoints distant from the source view [S1]. It combines advances in Vision Transformers (ViT) and Neural Radiance Fields (NeRF) [S1].
