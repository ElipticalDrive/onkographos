# Dynamic Appearance Particle Neural Radiance Field

Also called: Dynamic Appearance Particle NeRF, Lagrangian dynamic model in NeRF

## Overview
Dynamic Appearance Particle Neural Radiance Field is a method for novel view synthesis from monocular video that models scene dynamics using a particle-based representation [S1]. It solves the problem of reconstructing dynamic scenes without requiring multi-view data or prior geometric knowledge of moving objects [S1]. It differs from ParticleNeRF by applying appearance particles only to dynamic elements rather than the entire scene, and by using a grid-based field with linear interpolation for efficient querying instead of radius nearest neighbor searching [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Monocular video data (one camera view per time frame) [S1].
*   **Outputs:** Rendered pixel color $C(\mathbf{r}, t)$ for a ray $\mathbf{r}$ at time $t$ [S1].

**Data Structures:**
The method uses a hybrid representation consisting of:
1.  **Static Field ($V_s$):** A time-independent grid-based model (canonical feature field) [S1].
2.  **Dynamic Field ($V_{td}$):** A particle-based representation where dynamics are encoded in individual particle models [S1].
3.  **Weight ($w_t(x)$):** A binary indicator determining the effectiveness of the dynamic field at location $x$ and time $t$ [S1].

**Notation:**
*   $t$: Time, denoted in subscripts on the right-hand side of the superposition equation (e.g., $V_{td}$) to clarify that the dynamic component consists of an ensemble of particles [S1].
*   $\mathbf{r}(s) = \mathbf{o} + s\mathbf{d}$: Ray parameterization, where $\mathbf{o}$ is the camera center, $\mathbf{d}$ is the direction, and $s$ is the distance [S1].
*   $s_n, s_f$: Near and far bounds of the ray [S1].
*   $\sigma(\cdot)$: Volume density [S1].
*   $c(\cdot)$: Emitted radiance [S1].
*   $T(s)$: Accumulated transmittance [S1].

**Formulas:**
The rendered pixel color is computed via the standard volume rendering integral [S1]:
$$
C(\mathbf{r}, t) = \int_{s_n}^{s_f} T(s) \sigma(\mathbf{r}(s), t) c(\mathbf{r}(s), \mathbf{d}, t) ds
$$
where
$$
T(s) = \exp \left( - \int_{s_n}^{s} \sigma(\mathbf{r}(s'), t) ds' \right)
$$

The feature field $V$ is modeled by the superposition of static and dynamic components [S1]:
$$
V(x, t) = (1 - w_t(x))V_s(x) + w_t(x)V_{td}(x)
$$
where $V_s(x)$ is the static field, $V_{td}(x)$ is the dynamic field, and $w_t(x)$ is a weight taking value 1 if the dynamic field is effective at $(x,t)$ and 0 otherwise [S1]. The support of the dynamic field is implied by the particle representation [S1].

The dynamic field $V_{td}$ is formulated as a convolution with a Dirac function to integrate over finite volumes [S1]:
$$
V_{td}(x) = (V_{td} * \delta)(x) = \int V_{td}(x') \delta(x - x') d\nu(x')
$$
where $\delta(\cdot)$ is the Dirac function ($\delta(r) = 0$ for $r \neq 0$ and $\int \delta(r)d\nu = 1$) and $\nu(\cdot)$ is the volume integration variable [S1].

To quantize the field, the Dirac function $\delta$ is replaced with a kernel $W$ with finite support [S1]:
$$
W(x) = 0 \text{ when } \|x\| \text{ exceeds a small radius, and } \int W(x)d\nu(x) = 1
$$

**Steps:**
1.  Cast a ray $\mathbf{r}(s) = \mathbf{o} + s\mathbf{d}$ from the camera center $\mathbf{o}$ to the pixel on the image plane [S1].
2.  Evaluate the volume density $\sigma(\mathbf{r}(s), t)$ and emitted radiance $c(\mathbf{r}(s), \mathbf{d}, t)$ at points along the ray from near bound $s_n$ to far bound $s_f$ [S1].
3.  Compute the accumulated transmittance $T(s)$ along the ray [S1].
4.  Integrate the product of transmittance, density, and radiance to obtain the pixel color $C(\mathbf{r}, t)$ [S1].
5.  For the dynamic field component $V_{td}$, use the particle motion network to model scene dynamics across all time frames [S1].
6.  Replace the Dirac function $\delta$ with the finite-support kernel $W$ to quantize the field [S1].

**Pseudocode:**
```python
def render_dynamic_apperance_particle_nerf(ray_o, ray_d, time_t, static_grid, dynamic_particles, weight_map):
    """
    Renders a pixel color for a dynamic scene using the Dynamic Appearance Particle NeRF method.
    
    Args:
        ray_o: Origin of the ray (3D vector).
        ray_d: Direction of the ray (3D vector).
        time_t: Current time step.
        static_grid: Grid-based static field model V_s.
        dynamic_particles: List of particles representing the dynamic field V_td.
        weight_map: Function or grid providing w_t(x) values.
        
    Returns:
        Color C(r, t) for the ray.
    """
    # Sample points along the ray
    samples = sample_ray(ray_o, ray_d, near_bound=s_n, far_bound=s_f, num_samples=N)
    
    accumulated_transmittance = 1.0
    accumulated_color = [0.0, 0.0, 0.0]
    
    for s in samples:
        x = ray_o + s * ray_d
        
        # Query static field
        sigma_s, c_s = query_static_field(static_grid, x)
        
        # Query dynamic field using particle representation
        # Note: The specific particle querying mechanism (e.g., kernel convolution) 
        # is implied by the replacement of Dirac delta with kernel W [S1].
        sigma_d, c_d = query_dynamic_field(dynamic_particles, x, time_t, kernel=W)
        
        # Combine fields using superposition
        w = weight_map(x, time_t) # w_t(x) is 1 if dynamic field is effective, 0 otherwise [S1]
        
        sigma = (1 - w) * sigma_s + w * sigma_d
        c = (1 - w) * c_s + w * c_d
        
        # Volume rendering accumulation
        alpha = 1.0 - exp(-sigma * delta_s) # delta_s is the distance between samples
        weight = accumulated_transmittance * alpha
        accumulated_color += weight * c
        accumulated_transmittance *= (1.0 - alpha)
        
    return accumulated_color

def query_dynamic_field(particles, x, t, kernel):
    """
    Queries the dynamic field V_td at location x and time t.
    Implements the convolution with a finite-support kernel W [S1].
    """
    value = 0.0
    for particle in particles:
        # Calculate distance from particle to query point
        dist = norm(particle.position - x)
        
        # Apply kernel W (finite support, integral = 1) [S1]
        # If dist exceeds small radius, W is 0
        weight = kernel(dist)
        
        # Accumulate contribution from particle
        # The particle motion network encodes dynamics in individual particle models [S1]
        value += weight * particle.feature
        
    return value
```

**Parameters:**
*   **Kernel $W$:** A locally supported kernel close to 0, where $W(x) = 0$ when $\|x\|$ exceeds a small radius, and $\int W(x)d\nu(x) = 1$ [S1]. The exact radius is not specified in the sources [S1].
*   **Weight $w_t(x)$:** Takes value 1 if the dynamic field is effective at location $x$ and time $t$, and 0 otherwise [S1]. The support of the dynamic field is implied by the particle representation [S1].

**Edge Cases and Pitfalls:**
*   **Monocular Data:** The method is designed to handle monocular video data with just one camera view at each time frame, unlike ParticleNeRF which requires 20 camera views per time frame [S1].
*   **Dynamic Support:** The effectiveness of the dynamic field is determined by $w_t(x)$. If $w_t(x)$ is incorrectly set, the superposition may fail to capture dynamic elements or introduce artifacts in static regions [S1].
*   **Kernel Approximation:** Replacing the Dirac function with a finite-support kernel $W$ leads to quantization. The choice of kernel radius affects the smoothness and accuracy of the dynamic field representation [S1].

*   **Strengths:**

## Background
*   **Origin:** The method was proposed in "Dynamic Appearance Particle Neural Radiance Field" [S1].
*   **History and Development:** The method builds upon the concept of particle-based representations in NeRF, such as ParticleNeRF [S1]. It differs from ParticleNeRF by applying appearance particles only to dynamic elements and using a grid-based field for efficient querying [S1]. It also differs from ParticleNeRF by handling monocular video data instead of requiring multiple camera views [S1].
*   **Usage:** The method is designed for novel view synthesis from monocular video [S1]. It can be integrated into alternative frameworks such as InstantNGP [S1].
