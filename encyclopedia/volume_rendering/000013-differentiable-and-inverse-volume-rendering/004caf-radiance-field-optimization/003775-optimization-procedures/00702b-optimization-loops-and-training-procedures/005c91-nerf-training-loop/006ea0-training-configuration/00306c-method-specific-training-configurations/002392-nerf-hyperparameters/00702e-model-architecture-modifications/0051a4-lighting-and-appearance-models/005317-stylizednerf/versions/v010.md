# StylizedNeRF
## Overview
StylizedNeRF is a method for 3D-aware image synthesis that integrates a 2D stylization network into a NeRF optimization loop [S1]. It solves the problem of generating view-consistent stylized 3D scenes by handling the ambiguities of 2D stylization results through learnable latent codes [S1]. It sets itself apart from siblings like [Neural Pre-Integrated Lighting](13783-neural-pre-integrated-lighting-neural-pil.md) and [Spherical Harmonics NeRF](14480-spherical-harmonics-nerf.md) by using a mutual learning strategy with a 2D stylization network rather than explicit physical lighting decomposition [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Not given in the sources [S1].
*   **Outputs:** A stylized 3D radiance field capable of rendering novel views [S1].

**Data Structures:**
1.  **Stylized NeRF:** A continuous volumetric scene representation optimized during training [S1].
2.  **2D Stylization Network:** A network that processes 2D images to generate stylized features [S1].
3.  **Learnable Latent Codes:** Vectors used to modulate the stylization process and resolve 2D ambiguities [S1].

**Algorithm Steps:**
1.  Initialize the stylized NeRF and the 2D stylization network [S1].
2.  Optimize both networks simultaneously using a mutual learning strategy [S1].
3.  Inject learnable latent codes into the optimization to handle ambiguities in the 2D stylized results [S1].
4.  Enforce 3D geometry consistency during training [S1].

**Parameters:** Not given in the sources [S1].

**Edge Cases and Pitfalls:** Ambiguities in 2D stylization can lead to 3D inconsistencies; these are resolved by the learnable latent codes [S1].

## Subtopics

### [Physical Imaging Model with Spherical Harmonics](16376-physical-imaging-model-with-spherical-harmonics.md)
This method integrates a physically constrained imaging model into the NeRF optimization loop to decompose illumination into direct sunlight and ambient skylight, using spherical harmonics to model the latter. It differs from standard NeRF by explicitly separating albedo, surface normals, and lighting to provide auxiliary supervision, thereby reducing lighting ambiguity and improving reconstruction fidelity in shadowed or radiometrically inconsistent regions. Choose it when explicit lighting decomposition and shadow fidelity are required.

### [StyleRF-VolVis](16573-stylerf-volvis.md)
StyleRF-VolVis is a framework for editing the style (appearance) of a DVR scene represented by a NeRF model without losing original content (geometry) information. It supports both photorealistic (PSE) and non-photorealistic (NPSE) editing in a single pipeline by separating content and appearance, allowing explicit assignment of different styles to different DVR regions via a Palette Color Network (PCN) and an Unrestricted Color Network (UCN), while preserving view-dependent lighting. It differs from prior works by supporting both photorealistic and non-photorealistic editing in a single framework, whereas others focus on one or the other. Choose it when region-specific style assignment and view-dependent lighting preservation are needed.

### [Non-Photorealistic Style Editing](16597-non-photorealistic-style-editing.md)
Non-Photorealistic Style Editing (NPSE) is a style transfer process for volume rendering that assigns specific styles to distinct regions of a scene using an unrestricted color network and Nearest Neighbor Feature Matching (NNFM) loss. Unlike StylizedNeRF which assigns one style to the whole scene, NPSE allows explicit assignment of different styles to different DVR regions. Unlike ARF and StylizedNeRF which discard view directions to ensure consistency, NPSE removes view direction input only in the Unrestricted Color Network (UCN) optimization to preserve lighting while ensuring consistency. Choose it when region-specific non-photorealistic stylization with preserved lighting is required.

### [StyleNeRF Architecture Configuration](16789-stylenerf-architecture-configuration.md)
StyleNeRF extends the original Neural Radiance Field (NeRF) architecture by integrating a style-based generator to handle illumination changes and synthesize high-resolution images. It differs from standard NeRF by introducing a low-dimensional appearance code and style-based MLPs, setting it apart from siblings like StylizedNeRF which may use different stylization mechanisms [14882-stylizednerf.md]. Choose it when high-resolution synthesis with explicit style codes is the primary goal.

### Phong Reflection Color Modeling
Color modeling uses MLPs that take integrated average features as input to predict tint, roughness, modeled normal vector, and diffuse/specular colors [S2]. Modeled normal vectors are trained with and controlled by regularization losses from RefNeRF, and optimized towards estimated normal vectors via an additional regularization loss weighted by point confidence [S2]. This redundant normal modeling drives confidence of outlier points with abnormal normals to zero, while estimated normal vectors supervise and provide extra shape information for point features through the normal modeling MLP [S2].
