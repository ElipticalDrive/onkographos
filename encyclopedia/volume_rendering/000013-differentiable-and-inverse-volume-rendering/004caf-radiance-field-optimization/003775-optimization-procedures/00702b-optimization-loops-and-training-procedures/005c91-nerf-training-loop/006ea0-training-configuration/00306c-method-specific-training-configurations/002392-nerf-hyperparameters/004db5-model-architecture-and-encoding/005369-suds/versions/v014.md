# SUDS
Also called: Scalable Urban Dynamic Scenes

## Overview
SUDS is a 4D radiance field representation designed for large-scale dynamic urban scenes that factorizes the scene into three separate multi-resolution hash table structures: static, dynamic, and far-field [S1]. It enables free-viewpoint rendering, semantic decomposition, and 3D scene flow estimation at arbitrary poses and time steps using only unlabeled inputs (RGB, sparse LiDAR, 2D descriptors, and optical flow) [S1]. Unlike sibling methods that rely on supervised 3D bounding boxes or panoptic labels, SUDS achieves scalability to hundreds of square kilometers by combining spatial partitioning with video-specific hash indexing, allowing it to handle ego-motion and multi-video captures without linear memory growth [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** $N$ ordered RGB videos with diverse lighting/weather, associated camera poses, aligned sparse LiDAR depth, 2D self-supervised DINO descriptors, and 2D optical flow predictions [S1].
*   **Outputs:** For a query $(\mathbf{x}, \mathbf{d}, t, \text{vid})$, the method outputs view-dependent color $\mathbf{c} \in [0,1]^3$, volume density $\sigma \in \mathbb{R}_{\ge 0}$, semantic features $\boldsymbol{\Phi} \in \mathbb{R}^C$, and 3D scene flow vectors $\mathbf{s} \in [-1,1]^3$ [S1].

**Data Structures**
The scene is decomposed into $K$ spatial cells, each trained independently [S1]. Within each cell, three hash table branches are maintained:
1.  **Static Branch:** Stores 3D spatial voxels $\mathbf{v}_{l,s}$ [S1].
2.  **Dynamic Branch:** Stores 4D spacetime voxels $\mathbf{v}_{l,d}$ [S1].
3.  **Far-field Branch:** Stores 3D direction voxels $\mathbf{v}_{l,e}$ (normalized direction vectors) [S1].

Each branch uses a multi-resolution hash table hierarchy with $L$ levels, where resolution doubles between levels [S1]. Features are stored as vectors of dimension $F$ [S1]. Hash collisions are handled via gradient averaging [S1].

**Hash Indexing**
Indices for voxel corners are computed using specific hash functions that incorporate video ID ($\text{vid}$) to index separate interpolating functions per video without linear memory growth [S1]:
$$ i_{l,s} = \text{static hash}(\text{space}(\mathbf{v}_{l,s})) \quad (1) $$
$$ i_{l,d} = \text{dynamic hash}(\text{space}(\mathbf{v}_{l,d}), \text{time}(\mathbf{v}_{l,d}), \text{vid}) \quad (2) $$
$$ i_{l,e} = \text{env hash}(\text{dir}(\mathbf{v}_{l,e}), \text{vid}) \quad (3) $$
where $\text{space}(\cdot)$ extracts spatial coordinates, $\text{time}(\cdot)$ extracts the time index, and $\text{dir}(\cdot)$ extracts the viewing direction [S1].

**Feature Interpolation**
For a query $(\mathbf{x}, \mathbf{d}, t, \text{vid})$, surrounding voxels are found at all $L$ levels [S1]. Features are linearly interpolated to the nearest voxel vertices; quadlinear interpolation is used for the dynamic 4D branch [S1]. The results from all $L$ levels are concatenated into a feature vector $\mathbf{f} \in \mathbb{R}^{LF}$ [S1].

**Network Outputs**
The feature vector $\mathbf{f}$ and auxiliary inputs are passed to branch-specific MLPs:
*   **Static Branch:** Outputs view-independent density $\sigma_s(\mathbf{x}) \in \mathbb{R}$ and view-dependent color $\mathbf{c}_s(\mathbf{x}, \mathbf{d}, \mathbf{A}_{\text{vid}} \mathbf{F}(t)) \in \mathbb{R}^3$ [S1]. Lighting variations are modeled via a latent embedding $\mathbf{A}_{\text{vid}} \mathbf{F}(t)$, where $\mathbf{A}_{\text{vid}}$ is a video-specific matrix and $\mathbf{F}(t)$ is a Fourier-encoded time index [S1].
*   **Dynamic Branch:** Outputs time/video-dependent density $\sigma_d(\mathbf{x}, t, \text{vid}) \in \mathbb{R}$, color $\mathbf{c}_d(\mathbf{x}, t, \text{vid}, \mathbf{d}) \in \mathbb{R}^3$, shadow ratio $\rho_d(\mathbf{x}, t, \text{vid}) \in [0,1]$, and forward/backward scene flow $\mathbf{s}_{t0}(\mathbf{x}, t, \text{vid}) \in [-1,1]^3$ [S1].
*   **Far-field Branch:** Outputs environment map color $\mathbf{c}_e(\mathbf{d}, \text{vid}) \in \mathbb{R}^3$ [S1].
*   **Semantic Heads:** Each branch outputs $C$-dimensional semantic features $\boldsymbol{\Phi}_s, \boldsymbol{\Phi}_d, \boldsymbol{\Phi}_e$ to distill DINO teacher features [S1].

**Blending and Rendering**
Total density is the sum of static and dynamic components:
$$ \sigma(\mathbf{x}, t, \text{vid}) = \sigma_s(\mathbf{x}) + \sigma_d(\mathbf{x}, t, \text{vid}) \quad (9) $$
Total radiance combines static and dynamic colors, scaled by the shadow ratio $\rho_d$:
$$ \mathbf{c}(\mathbf{x}, t, \text{vid}, \mathbf{d}) = \frac{(1 - \rho_d)\sigma_s \mathbf{c}_s + \sigma_d \mathbf{c}_d}{\sigma} \quad (10) $$
Color $\hat{\mathbf{C}}$ for a ray $\mathbf{r}$ is accumulated via standard volume rendering, forcing intersection with the far-field environment map if no foreground geometry is hit:
$$ \hat{\mathbf{C}}(\mathbf{r}, t, \text{vid}) = \int_0^{+\infty} T(t) \sigma(\mathbf{r}(t), t, \text{vid}) \mathbf{c}(\mathbf{r}(t), t, \text{vid}, \mathbf{d}) dt + T(+\infty)\mathbf{c}_e(\mathbf{d}, \text{vid}) \quad (11) $$
where $T(t) = \exp\left(-\int_0^t \sigma(\mathbf{r}(s), t, \text{vid}) ds\right)$ [S1].

**Training Configuration**
*   **Spatial Partitioning:** The scene is split into $K$ cells. Training datasets are generated per cell by including only rays intersecting the cell and pruning rays not terminating within the cell using LiDAR depth [S1].
*   **Optimization:** Adam optimizer with learning rate decaying from $5 \times 10^{-3}$ to $5 \times 10^{-4}$ [S1].
*   **Batching:** 4098 rays per batch [S1].
*   **Iterations:** 250,000 iterations [S1].

**Loss Functions**
The total loss is a weighted sum of reconstruction, warping, flow, and factorization terms [S1]:
1.  **Reconstruction:** L2 photometric loss $\mathcal{L}_c(\mathbf{r}) = \|\mathbf{C}(\mathbf{r}) - \hat{\mathbf{C}}(\mathbf{r})\|^2$ and L1 feature loss $\mathcal{L}_f(\mathbf{r}) = \|\mathbf{F}(\mathbf{r}) - \hat{\mathbf{F}}(\mathbf{r})\|_1$ [S1]. Depth loss $\mathcal{L}_d(\mathbf{r}) = \|D(\mathbf{r}) - \hat{D}(\mathbf{r})\|^2$ using LiDAR [S1].
2.  **Warping:** Samples are advected using predicted flow $\mathbf{s}_{t0}$ to get warped density $\sigma^w$, color $\mathbf{c}^w$, and features $\boldsymbol{\Phi}^w$. Warped color $\hat{\mathbf{C}}^w$ and feature $\hat{\mathbf{F}}^w$ are rendered. Losses $\mathcal{L}_c^w$ and $\mathcal{L}_f^w$ are minimized, downweighted by $W_{t0}(\mathbf{r})$ in ambiguous regions [S1].
3.  **Flow:** 3D position $\hat{X}_{t0}(\mathbf{r})$ is predicted via scene flow integration. Loss $\mathcal{L}_o(\mathbf{r}) = \sum_{t0} \|X(\mathbf{o}) - \hat{X}_{t0}(\mathbf{r})\|_1$ minimizes distance to observed optical flow $\mathbf{O}$ [S1].
4.  **Flow Regularization:** Cycle consistency $\mathcal{L}_{cyc}(\mathbf{r}) = \sum_{t0} \sum_{\mathbf{x}} w_{t0}(\mathbf{x},t) \|\mathbf{s}_{t0}(\mathbf{x},t) + \mathbf{s}_t(\mathbf{x}+\mathbf{s}_{t0}, t-t0)\|_1$, spatial/temporal smoothness $\mathcal{L}_{sm}$, and static scene prior $\mathcal{L}_{slo} = \sum_{t0} \sum_{\mathbf{x}} \|\mathbf{s}_{t0}(\mathbf{x},t)\|_1$ [S1].
5.  **Static-Dynamic Factorization:** Skewed binary entropy loss $\mathcal{L}_e(\mathbf{r}) = \int_0^{+\infty} H\left(\frac{\sigma_d(\mathbf{r}(t))}{\sigma_s(\mathbf{r}(t)) + \sigma_d(\mathbf{r}(t))}\right) dt$ with $k=1.75$ (where $H(x) = -(x \log x + (1-x) \log (1-x))$) and max dynamic ratio penalty $\mathcal{L}_d(\mathbf{r}) = \max\left(\frac{\sigma_d}{\sigma_s + \sigma_d}\right)$ [S1].
6.  **Shadow Loss:** $\mathcal{L}_\rho(\mathbf{r}) = \int_0^{+\infty} \rho_d(\mathbf{r}(t))^2 dt$ to prevent over-explaining dark regions [S1].

```python
# Pseudocode for SUDS Query and Training Step
# Assumes global variables: hash_tables_s, hash_tables_d, hash_tables_e, 
# mlp_s, mlp_d, mlp_e, params (F, L, C, k, etc.)

def get_hash_index(branch_type, voxel_coords, time_idx, vid):
    """
    Computes hash index for a voxel corner.
    branch_type: 'static', 'dynamic', or 'env'
    voxel_coords: spatial coordinates (x,y,z) or direction (d_x, d_y, d_z)
    time_idx: frame index (for dynamic)
    vid: video ID
    """
    if branch_type == 'static':
        return static_hash(voxel_coords)
    elif branch_type == 'dynamic':
        return dynamic_hash(voxel_coords, time_idx, vid)
    elif branch_type == 'env':
        return env_hash(voxel_coords, vid)
    else:
        raise ValueError("Unknown branch type")

def interpolate_features(branch_type, query_pos, query_time, query_vid, levels):
    """
    Interpolates features from multi-resolution hash tables.
    Returns concatenated feature vector f.
    """
    features = []
    for l in levels:
        # Find surrounding voxels at level l
        voxels = find_surrounding_voxels(branch_type, query_pos, query_time, l)
        
        # Get hash indices for corners
        indices = []
        for v in voxels:
            if branch_type == 'static':
                idx = get_hash_index('static', v.space, None, None)
            elif branch_type == 'dynamic':
                idx = get_hash_index('dynamic', v.space, query_time, query_vid)
            elif branch_type == 'env':
                idx = get_hash_index('env', v.dir, None, query_vid)
            indices.append(idx)
        
        # Look up features and interpolate
        # Linear interpolation for static/env, Quadlinear for dynamic
        if branch_type == 'dynamic':
            feat = quadlinear_interpolate(indices, query_pos, query_time)
        else:
            feat = linear_interpolate(indices, query_pos)
        
        features.append(feat)
    
    # Concatenate all levels
    f = concatenate(features)
    return f

def query_sud(query_pos, query_dir, query_time, query_vid):
    """
    Main query function for SUDS.
    Returns color, density, semantic features, and scene flow.
    """
    # 1. Get features from each branch
    f_s = interpolate_features('static', query_pos, query_time, query_vid, levels)
    f_d = interpolate_features('dynamic', query_pos, query_time, query_vid, levels)
    f_e = interpolate_features('env', query_dir, query_time, query_vid, levels)
    
    # 2. Evaluate MLPs
    # Static: density, color (conditioned on lighting)
    lighting_cond = matmul(A[query_vid], fourier_encode(query_time))
    sigma_s, c_s, phi_s = mlp_s(f_s, query_dir, lighting_cond)
    
    # Dynamic: density, color, shadow ratio, flow, semantics
    sigma_d, c_d, rho_d, s_flow, phi_d = mlp_d(f_d, query_dir, query_time, query_vid)
    
    # Far-field: color, semantics
    c_e, phi_e = mlp_e(f_e, query_dir, query_vid)
    
    # 3. Combine densities
    sigma = sigma_s + sigma_d
    
    # 4. Combine colors (with shadow)
    if sigma > 0:
        c = ((1 - rho_d) * sigma_s * c_s + sigma_d * c_d) / sigma
    else:
        c = c_e # Fallback to environment if no geometry
        
    # 5. Combine semantics
    # Weighted sum similar to color, or simple concatenation depending on task
    # Assuming weighted sum for rendering consistency
    if sigma > 0:
        phi = ((1 - rho_d) * sigma_s * phi_s + sigma_d * phi_d) / sigma
    else:
        phi = phi_e
        
    return c, sigma, phi, s_flow

def compute_loss(ray, gt_color, gt_depth, gt_flow, gt_features):
    """
    Computes total loss for a batch of rays.
    """
    # Forward pass
    c, sigma, phi, s_flow = query_sud(ray.pos, ray.dir, ray.time, ray.vid)
    
    # Volume rendering for color and features
    # (Standard NeRF accumulation along ray)
    C_hat, F_hat, T = volume_render(ray, sigma, c, phi)
    
    # Reconstruction Losses
    L_c = L2(gt_color, C_hat)
    L_f = L1(gt_features, F_hat)
    L_d = L2(gt_depth, render_depth(ray, sigma))
    
    # Warping Losses
    # Advect samples using s_flow
    sigma_w, c_w, phi_w = advect_samples(ray, sigma, c, phi, s_flow)
    C_hat_w, F_hat_w = volume_render(ray, sigma_w, c_w, phi_w)
    
    # Downweight in ambiguous regions
    W = compute_ambiguity_weight(ray, sigma, s_flow)
    L_c_w = sum(W * L2(gt_color, C_hat_w))
    L_f_w = sum(W * L1(gt_features, F_hat_w))
    
    # Flow Losses
    # Predict 3D position from flow
    X_hat = integrate_flow(ray, s_flow)
    L_o = L1(gt_flow, project_to_2d(X_hat))
    
    # Flow Regularization
    L_cyc = cycle_consistency_loss(s_flow)
    L_sm = smoothness_loss(s_flow)
    L_slo = l1_norm(s_flow) # Static prior
    
    # Factorization Losses
    # Skewed binary entropy
    ratio = sigma_d / (sigma_s + sigma_d)
    H = - (ratio * log(ratio) + (1-ratio) * log(1-ratio))
    L_e = integrate(H, ray) * k # k=1.75
    
    # Max dynamic ratio
    L_d_max = max(ratio, ray)
    
    # Shadow Loss
    L_rho = integrate(rho_d**2, ray)
    
    # Total Loss
    total_loss = (L_c + L_f + L_d + 
                  L_c_w + L_f_w + 
                  L_o + L_cyc + L_sm + L_slo + 
                  L_e + L_d_max + L_rho)
    
    return total_loss
```

## Operating characteristics
*   **Time Complexity:** Training is 10x quicker than state-of-the-art methods relying on ground truth 3D bounding box annotations [S1].
*   **Memory Complexity:** Scales to tens of thousands of objects across 1.2 million frames from 1700 videos spanning hundreds of kilometers [S1]. Unlike object-centric methods like NSG which require over 1TB for a 30-second video, SUDS uses hash tables to manage memory efficiently [S1].
*   **Strengths:** Handles ego-motion and multi-video representations; uses unlabeled inputs (RGB, LiDAR, flow) for supervision; enables unsupervised 3D instance segmentation and cuboid detection [S1].
*   **Limitations:** Requires aligned sparse LiDAR and optical flow predictions (though these are "free" supervision sources, they are not raw RGB alone); relies on spatial partitioning which may introduce boundary artifacts if not handled carefully [S1].
*   **When to use:** Large-scale dynamic urban scene reconstruction where labeled 3D data is unavailable or too expensive to acquire [S1].

## Background
SUDS (Scalable Urban Dynamic Scenes) was introduced in 2023 [S1]. It builds on Instant-NGP's multi-resolution hash tables and addresses the limitations of prior dynamic NeRF methods that required supervised inputs like panoptic segmentation labels or bounding boxes [S1]. It is designed for automotive and urban data, handling ego-motion and multi-video captures, which previous methods like NSG could not do efficiently [S1].
