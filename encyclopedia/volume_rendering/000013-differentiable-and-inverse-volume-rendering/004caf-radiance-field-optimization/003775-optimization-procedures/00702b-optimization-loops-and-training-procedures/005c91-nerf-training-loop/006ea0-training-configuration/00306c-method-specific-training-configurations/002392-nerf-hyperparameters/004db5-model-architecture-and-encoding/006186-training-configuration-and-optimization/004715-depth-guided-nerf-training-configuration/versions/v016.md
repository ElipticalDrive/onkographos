# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the hyperparameters, architectural modifications, and optimization settings for training a Neural Radiance Field (NeRF) model that incorporates depth priors to improve geometry reconstruction [S1]. It addresses the problem of ambiguous depth estimation in standard NeRF training by integrating explicit depth supervision [S1]. It is distinguished from sibling methods by its specific use of Earth Mover’s Distance (EMD) for depth alignment and a fixed dropout regularization scheme on the positional encoding layers, rather than relying on semantic guidance (as in [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md)) or binary occupancy representations (as in [Binary Radiance Fields](13622-binary-radiance-fields.md)) [S1].

## How it works
The method modifies the standard NeRF training loop by adding regularization to the encoder and integrating a depth loss term into the total objective function.

**Inputs and Outputs:**
*   **Inputs:** Multi-view RGB images, camera poses, and ground-truth depth maps (or depth estimates derived from stereo/matching) [S1].
*   **Outputs:** A trained NeRF model (density and color networks) and rendered RGB images with improved geometric consistency [S1].

**Data Structures:**
The architecture builds upon the original NeRF [15] as cited in [S1].
*   **Positional Encoding Layers:** The first eight fully connected (FC) ReLU-activated layers that encode the positional encoding are modified.
*   **Dropout:** A dropout layer with probability $p=0.1$ is inserted after each of these first eight FC layers [S1].
*   **Depth Scale:** A specific parameter for depth scale is maintained with its own learning rate [S1].

**Parameters:**
*   **Depth Loss Weight ($\lambda$):** $0.007$ for all scenes, except scene 710, where it is $0.02$ [S1].
*   **Uncertainty Weight ($\gamma$):** $1$ [S1].
*   **Optimizer:** Adam [S1].
*   **Initial Learning Rate:** $5 \times 10^{-4}$ [S1].
*   **Learning Rate Schedule:** Reduced to $5 \times 10^{-5}$ after 80% of the total training steps [S1].
*   **Weight Decay:** $1 \times 10^{-6}$ [S1].
*   **Total Training Steps:** $500,000$ [S1].
*   **Depth Scale Learning Rate:** $1 \times 10^{-7}$ [S1].
*   **Uncertainty Threshold ($\tau$):** Used to evaluate depth map uncertainty, calculated as:
    $$ \tau = (\text{max\_depth} - \text{min\_depth}) \cdot 0.0001 $$
    For ScanNet, $\text{max\_depth} = 10$ and $\text{min\_depth} = 0.001$ [S1].

**Numbered Steps:**
1.  **Initialize Model:** Load the base NeRF architecture [S1].
2.  **Apply Dropout:** Insert dropout layers with $p=0.1$ after each of the first eight fully connected ReLU-activated layers that encode the positional encoding [S1].
3.  **Configure Optimizer:** Initialize Adam optimizer with learning rate $5 \times 10^{-4}$ and weight decay $1 \times 10^{-6}$ [S1].
4.  **Set Depth Scale LR:** Assign a learning rate of $1 \times 10^{-7}$ specifically to the depth scale parameter [S1].
5.  **Compute Loss:** Calculate the total loss, combining the standard NeRF rendering loss with the depth loss weighted by $\lambda$ and uncertainty weighted by $\gamma$ [S1].
6.  **Update:** Perform gradient descent.
7.  **Schedule:** After 80% of the 500,000 steps, reduce the main learning rate to $5 \times 10^{-5}$ [S1].
8.  **Evaluate:** Compute depth metrics (RMSE, RMSE log, AbsRel, SqRel) on valid pixels where ground truth depth exists [S1].

**Edge Cases and Pitfalls:**
*   **Scene 710:** Requires a higher depth loss weight ($\lambda = 0.02$) compared to other scenes ($\lambda = 0.007$) [S1].
*   **Uncertainty Threshold:** The threshold $\tau$ is scene-dependent (based on max/min depth) and must be calculated per dataset statistics (e.g., ScanNet) [S1].
*   **Reproducibility:** The original publication results for LLFF used a different train/test split, and DTU results could not be reproduced with released config files, suggesting potential undocumented architectural tricks (e.g., reduced positional encoding frequency) in the original work [S2].

## Subtopics

### DS-NeRF Depth Loss Integration
This variant involves integrating the depth loss implementation from the official DS-NeRF code base into the training code base [S2]. It requires re-training on LLFF train/test splits using released configuration files, as the original LLFF results used a different split and DTU results could not be reproduced due to missing configuration files in the official repository [S2].

## Operating characteristics
*   **Time Complexity:** Training runs for 500,000 steps [S1]. The specific time per step is not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** The configuration is designed to improve depth estimation accuracy, evaluated using RMSE, RMSE log, AbsRel, and SqRel metrics [S1].
*   **Strengths:** Explicit depth supervision via EMD and regularization via dropout on encoding layers helps prevent overfitting and improves geometric consistency [S1].
*   **Limitations:** Reproducibility issues exist for some datasets (DTU) due to missing configuration files or undocumented architectural changes in the original source [S2].
*   **When to use:** When depth priors are available and the goal is to improve the geometric fidelity of the NeRF reconstruction, particularly for indoor scenes like ScanNet [S1].

## Background
The method originates from the paper "Depth-Guided NeRF Training via Earth Mover’s Distance" [S1]. It builds on the original NeRF architecture [15] and incorporates techniques from DS-NeRF for depth loss integration [S2]. The approach is used in contexts where accurate depth estimation is critical, such as in indoor scene reconstruction (e.g., ScanNet) [S1].
