# Rendering and Diffusion Prior Pipeline

Also called: LSDS Pipeline, Latent Space Diffusion Sampling

## Overview
The Rendering and Diffusion Prior Pipeline optimizes a neural radiance field from a single input image by simultaneously minimizing a reconstruction loss for the input view and a diffusion-based prior loss for randomly sampled novel viewpoints [S1]. It distinguishes itself from sibling methods by operating directly in the latent space of a pre-trained Stable Diffusion model, using classifier-free guidance to enforce photorealistic texture and geometry consistency across unobserved angles without requiring multi-view inputs [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A single RGB image of the target object, a text prompt containing a custom token `<e>` (generated via single-image textual inversion [S1]), and a frozen Stable Diffusion model (VAE encoder/decoder and UNet).
*   **Output:** An optimized neural radiance field (NeRF) representing the 3D object.

**Data Structures:**
*   **NeRF:** Composed of feature grids and a 3-layer MLP with 64 hidden units. Feature grids have dimensionality 2. The background is modeled by a weak two-layer MLP taking viewing direction as input [S1].
*   **Latent Space:** The 512x512 rendered image is encoded into a latent representation by the Stable Diffusion VAE encoder.

**Steps:**
1.  **Textual Inversion (Pre-processing):** Generate a custom embedding token `<e>` that represents the input image in the text encoder's latent space [S1].
2.  **Rendering:** Render an image from the current NeRF state at resolution 96px [S1].
3.  **Upsampling:** Upsample the 96px render to 512px to match the Stable Diffusion input resolution [S1].
4.  **Latent Encoding:** Pass the 512px image through the Stable Diffusion VAE encoder to obtain the latent representation $z$ [S1].
5.  **Noise Addition:** Sample a timestep $t \sim U(0.02, 0.98)$ and add Gaussian noise to the latent $z$ [S1].
6.  **Diffusion Prediction:** Pass the noisy latent and the text prompt (containing `<e>`) into the frozen Stable Diffusion UNet to predict the noise $\epsilon_\theta$ [S1].
7.  **Classifier-Free Guidance:** Compute the guidance signal using a classifier-free guidance strength of 100 [S1].
8.  **Backpropagation:** Compute the loss based on the difference between predicted and actual noise. Backpropagate the gradient through the VAE encoder and the NeRF parameters. Do **not** backpropagate through the UNet [S1].
9.  **Optimization:** Update NeRF parameters using the Adam optimizer with learning rate $1e-3$ for 5000 iterations [S1].

```python
        pred_noise = pred_noise_uncond + guidance_strength * (pred_noise_cond - pred_noise_uncond)
        
        # 6. Compute Loss (Difference between actual noise and predicted noise)
        # In the latent space, the "actual" noise is the added noise scaled by the schedule
        # For implementation, we minimize the MSE between predicted noise and the added noise
        loss = F.mse_loss(pred_noise, noise)
        
        # 7. Backpropagate through VAE encoder and NeRF (NOT UNet)
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()
```

**Parameters:**
*   **Render Resolution:** 96px [S1].
*   **Upsampled Resolution:** 512px [S1].
*   **Classifier-Free Guidance Strength:** 100 [S1].
*   **Timestep Sampling:** Uniform distribution $U(0.02, 0.98)$ [S1].
*   **Optimizer:** Adam, learning rate $1e-3$ [S1].
*   **Iterations:** 5000 [S1].

**Edge Cases and Pitfalls:**
*   **Guidance Strength:** Strengths below 30 lead to geometric deformities; strengths above 30 produce good results [S1].
*   **Backpropagation Path:** Backpropagating through the UNet is incorrect for this method; gradients must flow through the VAE encoder and NeRF [S1].

## Subtopics

### Diffusion Prior Objective
An objective that uses a large pre-trained diffusion model to ensure the radiance field looks like the given object from randomly sampled novel viewpoints [S1]. It works by rendering novel views from the radiance field, passing them through the diffusion model to compute the prior objective, and optimizing the radiance field to minimize both the reconstruction objective (for the input view) and the prior objective (for novel views) simultaneously [S1].

## Operating characteristics
*   **Time Complexity:** Approximately 45 minutes on a single NVIDIA V100 GPU for 5000 iterations [S1].
*   **Memory Complexity:** Requires memory for the NeRF feature grids, the VAE encoder/decoder, and the UNet, plus intermediate latent tensors.
*   **Strengths:** Enables high-quality single-image 3D reconstruction by "dreaming up" missing views using a powerful 2D prior [S1].
*   **Limitations:** Computationally expensive due to the need to render, encode, and pass through a large diffusion model at each iteration. Sensitive to classifier-free guidance strength [S1].
*   **When to use:** Single-image 3D reconstruction where multi-view data is unavailable.
*   **When not to use:** Multi-view reconstruction tasks where direct photometric loss is sufficient and more accurate.

## Background
The method was introduced in "RealFusion 360° Reconstruction of Any Object from a Single Image" by Greif et al. (CVPR 2023) [S1]. It builds upon the concept of using diffusion models as priors for 3D generation, specifically adapting the Latent Space Diffusion Sampling (LSDS) technique to optimize NeRFs from a single image. It relies on single-image textual inversion to condition the diffusion model on the input image [S1].
