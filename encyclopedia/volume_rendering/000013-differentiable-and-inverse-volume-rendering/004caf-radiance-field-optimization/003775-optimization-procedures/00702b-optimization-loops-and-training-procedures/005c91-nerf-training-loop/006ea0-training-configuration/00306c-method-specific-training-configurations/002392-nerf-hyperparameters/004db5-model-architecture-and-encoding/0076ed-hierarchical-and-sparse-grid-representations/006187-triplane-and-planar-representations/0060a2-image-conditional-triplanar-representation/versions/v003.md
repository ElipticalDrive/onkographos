# Image-Conditional Triplanar Representation

Also called: Tri-plane Features

## Overview
Image-Conditional Triplanar Representation is a 3D scene representation that constructs axis-aligned orthogonal feature planes from input images, enabling efficient neural rendering of outdoor scenes without the cubic complexity of voxel-based methods [S1]. It differs from standard static triplane representations (e.g., EG3D) by explicitly conditioning the feature grid on camera poses and depth, allowing the planes to encode appearance information derived from multiple viewpoints rather than representing a fixed canonical volume [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** Input images $I \in \mathbb{R}^{H_i \times W_i \times 3}$, camera poses $\gamma_i$, and intrinsic matrices $K_i$.
*   **Outputs:** A triplanar feature tensor $\mathbf{S} \in \mathbb{R}^{3 \times G \times D \times D}$, where $G = C/4$ is the output channel dimension and $D \times D$ is the spatial resolution (upsampled to match the image feature space $H/2 \times W/2$) [S1].

**Data Structures**
The core data structure is the triplane tensor $\mathbf{S}$, composed of three 2D planes $\mathbf{S}_{xy}, \mathbf{S}_{xz}, \mathbf{S}_{yz}$ [S1].
*   **Shape:** $\mathbb{R}^{3 \times C \times D \times D}$ initially, transformed to $\mathbb{R}^{3 \times G \times D \times D}$ via 2D convolutions [S1].
*   **Dimensions:** The first dimension indexes the orthogonal planes ($xy, xz, yz$) [S1].
*   **Channels:** $C$ is the intermediate feature dimension; $G = C/4$ is the final channel count [S1].
*   **Resolution:** $D \times D$ corresponds to the spatial resolution of the image feature map ($H/2 \times W/2$) [S1].

**Steps**
1.  **Feature Extraction:** Extract low-resolution spatial features from input image $I$ using an ImageNet pre-trained ConvNet backbone $E$. This transforms $I$ into a 2D feature map $\mathbf{F}_I \in \mathbb{R}^{H_i/2 \times W_i/2 \times C}$ [S1].
2.  **Back-Projection:** Project local features from $\mathbf{F}_I$ backwards along every ray into a 3D feature volume $\mathbf{V}_F$ using the camera pose $\gamma_i$ and intrinsic matrix $K_i$ [S1].
3.  **Depth Encoding:** Encode the depth of individual features in the grid using an MLP $Z$. The MLP takes concatenated features from the grid, the position of the grid in the camera frame ($\mathbf{x}_c$), and the direction from the world frame position ($\mathbf{x}_w$) to the camera frame. It outputs depth-encoded features $\mathbf{V}_Z$ [S1].
    $$ \mathbf{V}_Z = Z(\mathbf{V}_F, \mathbf{x}_c, \mathbf{d}) $$
4.  **Triplane Construction:** Obtain triplane features by summing weighted depth-encoded features. The weights are softmax scores from aggregation MLPs ($A_{xy}, A_{xz}, A_{yz}$) conditioned on $\mathbf{V}_Z$ and world coordinates [S1].
    $$ \mathbf{S}_{xy} = \sum_i w_{xy_i} \mathbf{V}_{Z_i}, \quad w_{xy} = A_{xy}(\mathbf{V}_{Z_i}, \mathbf{x}_{w_z}) $$
    $$ \mathbf{S}_{xz} = \sum_i w_{xz_i} \mathbf{V}_{Z_i}, \quad w_{xz} = A_{xz}(\mathbf{V}_{Z_j}, \mathbf{x}_{w_y}) $$
    $$ \mathbf{S}_{yz} = \sum_i w_{yz_i} \mathbf{V}_{Z_i}, \quad w_{yz} = A_{yz}(\mathbf{V}_{Z_j}, \mathbf{x}_{w_x}) $$
    Where $w_{xy}, w_{xz}, w_{yz}$ are softmax scores obtained after summing over the $z, y, x$ dimensions respectively [S1].
5.  **Transformation:** Transform the built image-conditional triplanes into a new $G$-channel output using learned 2D convolutions, where $G = C/4$. This step upsamples the spatial dimension of the planes from $D \times D$ to the image feature space ($H/2 \times W/2$) [S1].
6.  **Rendering:** Use the resulting triplanes as a global feature representation. Dedicated NeRF decoder MLPs regress density and color for foreground and background based on queries into these planes [S1].

**Pseudocode**
```python
def image_conditional_triplane_representation(images, poses, intrinsics):
    """
    Construct image-conditional triplanes from input views.
    
    Args:
        images: List of input images I (H_i, W_i, 3)
        poses: List of camera poses gamma_i
        intrinsics: List of intrinsic matrices K_i
        
    Returns:
        S: Triplane tensor (3, G, D, D)
    """
    # Step 1: Feature Extraction
    # E is ImageNet pre-trained ConvNet backbone
    F_I = []
    for I in images:
        # Transform I to 2D feature map
        f = E(I) 
        F_I.append(f) # Shape: (H_i/2, W_i/2, C)
        
    # Step 2: Back-Projection to 3D Feature Volume
    # V_F is the 3D feature volume
    V_F = back_project_features(F_I, poses, intrinsics)
    
    # Step 3: Depth Encoding
    # Z is an MLP
    # x_c: position of grid in camera frame
    # x_w: position of grid in world frame
    # d: direction from x_w to camera frame
    V_Z = depth_encode(V_F, x_c, x_w)
    
    # Step 4: Triplane Construction
    # A_xy, A_xz, A_yz are feature aggregation MLPs
    # x_w_z, x_w_y, x_w_x are world coordinates projected to respective planes
    
    # For xy plane
    w_xy = softmax(A_xy(V_Z, x_w_z))
    S_xy = sum(w_xy * V_Z, dim=channel_dim)
    
    # For xz plane
    w_xz = softmax(A_xz(V_Z, x_w_y))
    S_xz = sum(w_xz * V_Z, dim=channel_dim)
    
    # For yz plane
    w_yz = softmax(A_yz(V_Z, x_w_x))
    S_yz = sum(w_yz * V_Z, dim=channel_dim)
    
    S = [S_xy, S_xz, S_yz]
    
    # Step 5: Transformation
    # G = C / 4
    # 2D convolutions upsample spatial dimension to H/2 x W/2
    S_final = []
    for plane in S:
        # Conv2D with upsampling
        plane_out = Conv2D_Upsample(plane, G)
        S_final.append(plane_out)
        
    return S_final
```

**Parameters**
*   $C$: Feature dimension per grid cell.
*   $G = C/4$: Output channel dimension after 2D convolutions [S1].
*   $D \times D$: Spatial resolution, upsampled to image feature space ($H/2 \times W/2$) [S1].

**Edge Cases and Pitfalls**
*   **Missing Features:** The 2D convolutions act as inpainting networks to fill in missing features in the triplanes, which is crucial for sparse view synthesis [S1].
*   **Coordinate Systems:** Care must be taken to correctly map world coordinates ($\mathbf{x}_w$) to camera frame positions ($\mathbf{x}_c$) and directions for the depth encoding MLP [S1].

## Operating characteristics
*   **Complexity:** Avoids the cubic complexity of 3D CNNs/voxels by using 2D planes [S1].
*   **Expressivity:** More expressive than BEV or 2D representations as it retains all three dimensions, avoiding the omission of the z-axis [S1].
*   **Performance:** Enables computationally efficient estimation of the entire scene's appearance and accurate neural rendering [S1].
*   **Use Case:** Suitable for sparse view synthesis of outdoor scenes where full 3D expressivity is needed but cubic complexity is prohibitive [S1].

## Background
*   **Origin:** Introduced in "NeO 360: Neural Fields for Sparse View Synthesis of Outdoor Scenes" [S1].
*   **Motivation:** To model 3D scenes with full expressivity at scale without omitting dimensions (as in 2D/BEV) and avoiding cubic complexity (as in voxels) [S1].
*   **Development:** Builds on prior volumetric reconstruction methods but extends them to estimate appearance and enable neural rendering, using depth-encoded features and image-conditioned aggregation [S1].
