# Differentiable Primitive Assembly

Also called: DPA-Net Primitive Assembly, Quadric Primitive Assembly

## Overview
Differentiable Primitive Assembly (DPA) models 3D shapes as an assembly of convex quadric primitives, combining them via differentiable soft boolean operations to produce an occupancy field [S1]. It solves the problem of 3D shape abstraction from sparse or single views by optimizing primitive parameters and selection matrices end-to-end using only image-space photometric and mask losses, without requiring 3D ground truth supervision [S1]. Unlike Gaussian Splatting which rasterizes explicit ellipsoids, DPA evaluates implicit signed distance functions (SDFs) for quadrics and aggregates them via min/max pooling logic, allowing for the representation of complex topologies including holes and thin structures [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Fused image features $f$ (derived from input views), query points $\mathbf{x}_i = (x_i, y_i, z_i)$ sampled along camera rays.
*   **Outputs:** Primitive parameters matrix $\mathbf{P}$, selection matrix $\mathbf{T}$, weight vector $\mathbf{w}$, rendered color $C_b$, and rendered mask $M_c$.

**Data Structures:**
1.  **Primitive Parameters Matrix $\mathbf{P}$:** Shape $\mathbb{R}^{P \times 7}$. Each row $p$ contains coefficients $(a_p, b_p, c_p, d_p, e_p, f_p, g_p)$. The first three parameters $(a_p, b_p, c_p)$ are constrained to be non-negative to ensure convexity [S1].
2.  **Selection Matrix $\mathbf{T}$:** Shape $\mathbb{R}^{P \times C}$. Entries $T_{p,c} \in [0, 1]$ indicate the inclusion of primitive $p$ in convex $c$. Ideally binary, but relaxed during training [S1].
3.  **Weight Vector $\mathbf{w}$:** Shape $\mathbb{R}^C$. Learnable weights for soft union approximation, with elements close to 1 [S1].

**Numbered Steps:**

1.  **Query Matrix Construction:** For $N$ query points, construct matrix $\mathbf{Q} \in \mathbb{R}^{N \times 7}$ where the $i$-th row is $(x_i^2, y_i^2, z_i^2, x_i, y_i, z_i, 1)$ [S1].
2.  **Primitive Parameter Prediction:** Pass fused image features $f$ through a 2-layer MLP to predict $\mathbf{P}$. Enforce $a_p, b_p, c_p \ge 0$ via activation or projection [S1].
3.  **Distance Calculation:** Compute the approximate signed distance matrix $\mathbf{D} \in \mathbb{R}^{N \times P}$:
    $$ \mathbf{D} = \mathbf{Q}\mathbf{P}^\top $$
    $D_{i,p} < 0$ if point $i$ is inside primitive $p$, and $D_{i,p} > 0$ if outside [S1].
4.  **Convex Occupancy:** Compute convex occupancy matrix $\mathbf{O} \in \mathbb{R}^{N \times C}$ using the selection matrix $\mathbf{T}$ and ReLU:
    $$ \mathbf{O} = \text{ReLU}(\mathbf{D})\mathbf{T} $$
    $O_{i,c} = 0$ if point $i$ is inside convex $c$ (intersection of selected primitives), and $O_{i,c} > 0$ if outside [S1].
5.  **Exact Occupancy:** Compute exact occupancy field $\mathbf{a}^* \in \mathbb{R}^N$ via min-pooling (union of convexes):
    $$ a^*_i = \min_{1 \le c \le C} O_{i,c} $$
    $a^*_i = 0$ if inside the shape, $> 0$ if outside [S1].
6.  **Soft Occupancy (Approximation):** Compute soft occupancy $\mathbf{a}^+ \in \mathbb{R}^N$ for gradient flow during pretraining:
    $$ a^+_i = \mathcal{L}\left( \sum_{c=1}^C w_c \mathcal{L}(1 - O_{i,c}) \right) $$
    where $\mathcal{L}(x) = \max(0, \min(1, x))$ clips input to $[0, 1]$. $a^+_i \approx 1$ if inside, $< 1$ if outside [S1].
7.  **Opacity Assignment:**
    *   Phase 1: $\alpha_i = a^+_i$ [S1].
    *   Phase 2 & 3: $\alpha_i = \exp(-10 a^*_i)$ [S1].
8.  **Differentiable Rendering:** For a ray with $R$ sampled points, compute transmittance $t_i = \prod_{k=1}^{i-1} (1 - \alpha_k)$. Render color $C_b$ and mask $M_c$:
    $$ C_b = \sum_{i=1}^R t_i \alpha_i c_{b,i} $$
    $$ M_c = \sum_{i \in \Omega} t_i \alpha_i $$
    where $c_{b,i}$ is the color predicted by the network for point $i$, and $\Omega$ is the set of points along the ray [S1].

**Pseudocode:**

```python
import numpy as np

def compute_signed_distance(query_points, primitive_params):
    """
    query_points: (N, 3) array of (x, y, z)
    primitive_params: (P, 7) array of (a, b, c, d, e, f, g)
    Returns: (N, P) distance matrix D
    """
    # Construct Q: (N, 7)
    x, y, z = query_points[:, 0], query_points[:, 1], query_points[:, 2]
    Q = np.column_stack([x**2, y**2, z**2, x, y, z, np.ones(len(query_points))])
    
    # D = Q @ P^T
    D = Q @ primitive_params.T
    return D

def compute_convex_occupancy(D, T):
    """
    D: (N, P) distance matrix
    T: (P, C) selection matrix
    Returns: (N, C) convex occupancy O
    """
    # O = ReLU(D) @ T
    D_relu = np.maximum(D, 0)
    O = D_relu @ T
    return O

def compute_exact_occupancy(O):
    """
    O: (N, C) convex occupancy
    Returns: (N,) exact occupancy a_star
    """
    # a_star = min_c O[:, c]
    a_star = np.min(O, axis=1)
    return a_star

def compute_soft_occupancy(O, w):
    """
    O: (N, C) convex occupancy
    w: (C,) weight vector
    Returns: (N,) soft occupancy a_plus
    """
    # clip(1 - O, 0, 1)
    clipped = np.clip(1 - O, 0, 1)
    # sum_c w_c * clipped[:, c]
    weighted_sum = clipped @ w
    # clip result to [0, 1]
    a_plus = np.clip(weighted_sum, 0, 1)
    return a_plus

def render_ray(opacities, colors, transmittance_prev=None):
    """
    opacities: (R,) alpha values
    colors: (R, 3) color values
    transmittance_prev: (R,) t values (accumulated from previous points)
    Returns: (3,) final color, (1,) final mask
    """
    if transmittance_prev is None:
        # Calculate transmittance t_i = product_{k=1}^{i-1} (1 - alpha_k)
        # t_1 = 1, t_2 = 1 - alpha_1, etc.
        one_minus_alpha = 1 - opacities
        # Cumulative product from right to left for t_i? 
        # Standard volume rendering: t_i = prod_{k=1}^{i-1} (1 - alpha_k)
        # Let's compute cumulative product of (1-alpha)
        cum_prod = np.cumprod(np.concatenate([[1.0], one_minus_alpha[:-1]]))
        transmittance_prev = cum_prod
        
    # Contribution: t_i * alpha_i * color_i
    contributions = transmittance_prev * opacities[:, np.newaxis] * colors
    # Final color
    final_color = np.sum(contributions, axis=0)
    # Final mask (sum of t_i * alpha_i)
    final_mask = np.sum(transmittance_prev * opacities)
    return final_color, final_mask

def loss_ph(C_hat, C_gt, M_hat, M_gt):
    """
    L_ph = L2 color + L2 mask
    """
    color_loss = np.mean((C_hat - C_gt)**2)
    mask_loss = np.mean((M_hat - M_gt)**2)
    return color_loss + mask_loss

def loss_T(T):
    """
    L_T = sum(max(-T, 0) + max(T - 1, 0))
    Keeps T in [0, 1]
    """
    penalty_neg = np.maximum(-T, 0)
    penalty_pos = np.maximum(T - 1, 0)
    return np.sum(penalty_neg) + np.sum(penalty_pos)

def loss_overlapping(O, a_star):
    """
    L_over = sum_{i in Omega} max(h_i, 1.9)
    Omega = {i | a_star_i < 0.01}
    h_i = sum_c exp(-10 * O_{i,c})
    """
    # Identify points inside shape
    inside_mask = a_star < 0.01
    if not np.any(inside_mask):
        return 0.0
    
    # Calculate h for all points
    h = np.sum(np.exp(-10 * O), axis=1)
    
    # Select h for inside points
    h_inside = h[inside_mask]
    
    # Max with 1.9
    penalty = np.maximum(h_inside, 1.9)
    
    return np.sum(penalty)

def primitive_dropout(T, a_star, K=40960):
    """
    Check if removing a primitive changes occupancy significantly.
    T: (P, C) binary selection matrix
    a_star: (N,) exact occupancy of current shape
    Returns: (P,) boolean mask of kept primitives
    """
    # Sample K points around shape (assumed pre-sampled as query_points)
    # For this function, we assume we have a way to recompute a_star for a modified T
    # In practice, this iterates over rows of T
    
    kept_primitives = np.ones(T.shape[0], dtype=bool)
    
    # Note: Recomputing a_star for every row removal is expensive.
    # The source describes iterating through each row.
    
    for p in range(T.shape[0]):
        # Create modified T with p-th row zeroed
        T_mod = T.copy()
        T_mod[p, :] = 0
        
        # Recompute D, O, a_star for T_mod
        # (Assuming query_points and primitive_params are available in scope)
        D_mod = compute_signed_distance(query_points, primitive_params)
        O_mod = compute_convex_occupancy(D_mod, T_mod)
        a_star_mod = compute_exact_occupancy(O_mod)
        
        # Quantify variation v
        # XOR(a_star_mod < 0.1, a_star < 0.1)
        cond_old = a_star < 0.1
        cond_new = a_star_mod < 0.1
        xor_diff = np.logical_xor(cond_old, cond_new)
        v = np.sum(xor_diff)
        
        # If v is close to zero, keep row zero (primitive removed)
        # Else restore
        if v > 0: # Threshold not explicitly given as "close to zero" value, assume >0 means change
            kept_primitives[p] = False
        else:
            kept_primitives[p] = True # Restore
            
    return kept_primitives
```

**Parameters:**
*   $P = 4,096$: Number of primitives [S1].
*   $C = 256$: Number of convexes [S1].
*   Learning Rate: $0.0001$ (Adam optimizer) [S1].
*   Batch Size: 4 object instances [S1].
*   Point Sampling for $L_{over}$: 40,960 points surrounding the shape [S1].
*   Silhouette Sampling: 256 random pixels + 1,000 contour pixels (obtained via morphological closing + Gaussian noise) [S1].
*   Primitive Dropout Frequency: Every 400 iterations in Phase 3 [S1].

**Edge Cases and Pitfalls:**
*   **Complex Topologies:** Random pixel sampling struggles with thin structures or holes; silhouette-aware sampling is required [S1].
*   **Redundant Primitives:** Without dropout, the assembly may contain redundant primitives; dropout removes up to 29% of primitives [S1].
*   **Overlap:** Excessive overlap between convexes degrades abstraction; $L_{over}$ penalizes points inside multiple convexes [S1].
*   **Binary Constraint:** $T$ is relaxed to $[0,1]$ during training but binarized (threshold 0.01) in Phase 3 [S1].

## Operating characteristics
*   **Time Complexity:** Rendering is $O(R)$ per ray where $R$ is sampled points. Occupancy computation is $O(N \cdot P)$ for distance and $O(N \cdot P \cdot C)$ for convex aggregation, though matrix multiplication optimizes this.
*   **Memory Complexity:** Stores $\mathbf{P}$ ($P \times 7$), $\mathbf{T}$ ($P \times C$), and $\mathbf{w}$ ($C$). For $P=4096, C=256$, $\mathbf{T}$ is $\approx 4$ million floats.
*   **Performance:** Trained on 4 NVIDIA Tesla V100 GPUs [S1].
*   **Strengths:** Handles complex topologies (holes, thin structures) better than standard NeRF; compact representation via primitive dropout; differentiable end-to-end training [S1].
*   **Limitations:** Requires test-time adaptation for novel shapes deviating from training data; sensitive to primitive count and selection matrix initialization [S1].
*   **When to Use:** Sparse-view 3D reconstruction where explicit geometry is desired; scenes with complex topology.
*   **When Not to Use:** Dense-view photorealistic rendering where Gaussian Splatting may be faster; scenes with no holes or simple convex shapes where simpler primitives suffice.

## Background
Differentiable Primitive Assembly was introduced in DPA-Net [S1]. It builds on CAPRI-Net [S1] and adopts intersection/union operations from [6, 55] (cited in S1). It addresses the limitations of NeRF in abstracting complex 3D structures by using quadric primitives and differentiable boolean operations.
