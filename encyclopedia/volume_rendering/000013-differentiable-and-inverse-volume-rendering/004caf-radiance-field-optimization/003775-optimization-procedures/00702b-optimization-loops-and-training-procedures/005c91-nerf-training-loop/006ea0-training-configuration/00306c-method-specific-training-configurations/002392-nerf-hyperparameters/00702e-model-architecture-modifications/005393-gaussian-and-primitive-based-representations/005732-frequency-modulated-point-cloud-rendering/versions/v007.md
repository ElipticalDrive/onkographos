# Frequency-Modulated Point Cloud Rendering

Also called: AFNet, Adaptive Frequency Net, Adaptive Frequency Net (AFNet) based rendering, FreqPCR, Frequency-Modulated Radiance Mapping

## Overview
Frequency-Modulated Point Cloud Rendering is a real-time rendering pipeline that represents scenes as explicit point clouds and uses an Adaptive Frequency Net (AFNet) to modulate implicit radiance signals with local texture frequency encoding [S1]. It solves the problem of high-frequency detail reconstruction in point-based rendering, where standard MLPs suffer from spectral bias towards low-frequency signals [S1]. Unlike sibling methods that use fixed activation functions or global frequency encoding, AFNet predicts local frequency and phase parameters for each point via a hypernetwork, allowing the network to adaptively handle varying texture complexities (high frequency for textured regions, low for smooth regions) [S1]. This approach enables high-fidelity local detail reconstruction, real-time rendering speeds, and user-friendly object-level editing [S1].

## How it works
The method consists of three main components: point cloud geometry optimization, the AFNet radiance mapping module, and a rendering pipeline that supports editing and composition [S1].

### Inputs and Outputs
*   **Input:** A set of $N$ 3D points $\mathcal{P} = \{\mathbf{p}_i\}_{i=1}^N$, where each point $\mathbf{p}_i$ has a position $\mathbf{x}_i \in \mathbb{R}^3$ and an initial feature vector [S1].
*   **Output:** A rendered image $C \in \mathbb{R}^{H \times W \times 3}$ for a given camera pose [S1].

### Data Structures
1.  **Point Cloud:** A list of $N$ points. Each point stores position $\mathbf{x}_i \in \mathbb{R}^3$, opacity $\alpha_i \in [0, 1]$ learned during geometry optimization, and input feature $\mathbf{X}^{(i)} \in \mathbb{R}^{M \times C}$ where $M$ is the point count and $C$ is the feature dimension [S1].
2.  **AFNet Model:** The hypernetwork is a two-layer Multi-Layer Perceptron (MLP) that takes point position $\mathbf{x}_i$ as input and outputs adaptive frequency $\omega^{(i)} \in \mathbb{R}^{M \times 1}$ and phase $\phi^{(i)} \in \mathbb{R}^{M \times 1}$ [S1]. AF Layers are a sequence of layers within the radiance mapping network, each containing a linear transformation followed by an Adaptive Frequency (AF) activation layer [S1]. A final linear layer maps the output feature to RGB color [S1].

### Step-by-Step Procedure

#### 1. Point Cloud Geometry Optimization (Preprocessing)
To address the limitation where previous surface point-based works kept only the closest point per ray (preventing geometry optimization), this method uses volume rendering as a preprocessing module [S1].
1.  Initialize a dense point cloud.
2.  During training, keep multiple points in the pixel buffer for each ray.
3.  Learn the opacity $\alpha_i$ of each point based on volume rendering.
4.  This step improves rendering PSNR by 2-4dB for poorly reconstructed scenes and avoids artifacts [S1].

#### 2. AFNet Radiance Mapping
For each point $i$ with position $\mathbf{x}_i$ and input feature $\mathbf{X}^{(i)} \in \mathbb{R}^{M \times C}$:
1.  **Frequency Estimation:** Pass $\mathbf{x}_i$ through the two-layer MLP hypernetwork to predict scalar frequency $\omega^{(i)}$ and phase $\phi^{(i)}$ [S1].
2.  **Feature Propagation:** The radiance mapping network processes features through $L$ layers. Let $\mathbf{X}^{(l)}$ be the input feature to layer $l$.
3.  **Adaptive Frequency Activation:** For each layer $l$, compute the output $\mathbf{Y}^{(l)}$ using the adaptive frequency activation layer [S1]:
    $$ \mathbf{Y}^{(l)} = \mathbf{X}^{(l)} \circ \sin(\omega^{(l)} \circ \mathbf{X}^{(l)} + \phi^{(l)}) $$
    where $\circ$ denotes the Hadamard (element-wise) product [S1]. The scalars $\omega^{(l)}$ and $\phi^{(l)}$ are broadcast to dimension $C$ during computation [S1].
4.  **Linear Transformation:** Apply a linear layer to $\mathbf{Y}^{(l)}$ to produce the input for the next layer $\mathbf{X}^{(l+1)}$ [S1].
5.  **Final Output:** After the last AF layer, apply a final linear layer to map the feature to RGB color $\mathbf{c}_i$ [S1].

#### 3. Rendering
1.  For each pixel, cast a ray and find the set of points $\mathcal{N}$ intersecting the ray or projected to the pixel [S1].
2.  Sort points by depth [S1].
3.  Compute pixel color using alpha compositing:
    $$ C = \sum_{i \in \mathcal{N}} \mathbf{c}_i \alpha_i \prod_{j < i} (1 - \alpha_j) $$
    where $\mathbf{c}_i$ is the color predicted by AFNet for point $i$, and $\alpha_i$ is its learned opacity [S1].

#### 4. Object Editing and Scene Composition
*   **Editing:** For rigid object editing, users edit the point cloud directly, and the deformation field between the original and deformed 3D space is obtained by querying the corresponding transformations performed on the point cloud [S1].
*   **Composition:** To combine multiple scenes, a masking strategy based on the depth buffer is used at the pixel level to avoid cross-scene training [S1].

### Pseudocode

```python
import torch
import torch.nn as nn

class AdaptiveFrequencyNet(nn.Module):
    """
    AFNet module for frequency-modulated point cloud rendering.
    """
    def __init__(self, feature_dim, hidden_dim, num_layers):
        super().__init__()
        self.num_layers = num_layers
        # Hypernetwork: 2-layer MLP predicting omega and phi from position
        self.hypernet = nn.Sequential(
            nn.Linear(3, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 2)
        )
        # Radiance mapping layers: Linear -> AF -> Linear -> AF ...
        self.layers = nn.ModuleList()
        for i in range(num_layers):
            in_dim = feature_dim if i == 0 else hidden_dim
            self.layers.append(nn.Linear(in_dim, hidden_dim))
        self.output_layer = nn.Linear(hidden_dim, 3)

    def forward(self, points, features):
        """
        Args:
            points: Tensor of shape (N, 3), 3D coordinates of points
            features: Tensor of shape (N, feature_dim), input features for each point
        Returns:
            colors: Tensor of shape (N, 3), predicted RGB colors
        """
        # Predict omega and phi using hypernetwork
        hyper_out = self.hypernet(points)  # (N, 2)
        omega = hyper_out[:, 0:1]          # (N, 1)
        phi = hyper_out[:, 1:2]            # (N, 1)

        current = features
        for i in range(self.num_layers):
            current = self.layers[i](current)
            # AF Layer: Y = X * sin(omega * X + phi)
            current = current * torch.sin(omega * current + phi)
        return self.output_layer(current)

def render_point_cloud(points, opacities, colors, cam_pos, cam_forward, cam_right, cam_up, img_w, img_h, focal_len):
    """
    Rasterization-based rendering for point clouds with alpha compositing.
    """
    # Project 3D points to 2D image coordinates
    rel = points - cam_pos  # (N, 3)
    depth = torch.sum(rel * cam_forward, dim=1)  # (N,)
    u = torch.sum(rel * cam_right, dim=1) / depth * focal_len + img_w / 2
    v = torch.sum(rel * cam_up, dim=1) / depth * focal_len + img_h / 2

    # Filter valid points within image bounds and in front of camera
    valid = (depth > 0) & (u >= 0) & (u < img_w) & (v >= 0) & (v < img_h)
    u, v, depth, opacities, colors = u[valid], v[valid], depth[valid], opacities[valid], colors[valid]

    # Sort points by depth (front to back)
    sort_idx = torch.argsort(depth)
    u, v, depth, opacities, colors = u[sort_idx], v[sort_idx], depth[sort_idx], opacities[sort_idx], colors[sort_idx]

    # Rasterize with alpha compositing
    image = torch.zeros((img_h, img_w, 3), device=points.device)
    alpha_buf = torch.zeros((img_h, img_w), device=points.device)

    for i in range(len(u)):
        px, py = int(u[i].item()), int(v[i].item())
        if 0 <= px < img_w and 0 <= py < img_h:
            alpha = opacities[i].item()
            color = colors[i]
            # Alpha compositing: C_new = C_old * (1 - alpha) + color * alpha
            image[py, px] = image[py, px] * (1 - alpha) + color * alpha
            alpha_buf[py, px] = alpha_buf[py, px] + alpha * (1 - alpha_buf[py, px])
    return image
```

### Parameters and Typical Values
*   **Hypernetwork:** Two-layer MLP [S1].
*   **Rendering Speed:** 39.27 FPS on NeRF-Synthetic dataset [S1].
*   **Performance:** 1700x faster than NeRF and 37x faster than CCNeRF [S1].
*   **Geometry Optimization:** Improves PSNR by 2-4dB for poorly reconstructed scenes [S1].

### Edge Cases and Pitfalls
*   **Spectral Bias:** Standard MLPs with ReLU have strong spectral bias towards low-frequency signals, limiting high-frequency reconstruction [S1].
*   **Geometry Optimization:** Previous surface point-based works could not optimize point cloud geometry because they kept only the closest point as surface estimation for each ray [S1].
*   **Cross-Scene Training:** Failure to use a depth-based masking strategy during scene composition leads to cross-scene training artifacts [S1].

## Background
Frequency-Modulated Point Cloud Rendering was proposed by Zhang et al. in 2023 [S1]. It addresses the limitations of Implicit Neural Representations (INRs) and standard MLPs in point cloud rendering, specifically the spectral bias towards low-frequency signals [S1]. The method builds on the concept of HyperNetworks [11] and Frequency Modulation Networks (MFN) [7] to create an adaptive frequency modulation mechanism [S1]. It is part of the broader effort to make neural rendering editable and real-time, competing with methods like CCNeRF and Object-NeRF [S1].
