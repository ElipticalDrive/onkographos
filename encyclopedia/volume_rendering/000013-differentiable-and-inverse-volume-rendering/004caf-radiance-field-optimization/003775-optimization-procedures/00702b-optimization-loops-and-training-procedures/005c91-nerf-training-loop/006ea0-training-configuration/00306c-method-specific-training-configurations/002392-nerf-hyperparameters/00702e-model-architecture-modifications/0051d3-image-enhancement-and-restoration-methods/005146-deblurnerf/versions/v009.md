# DeblurNeRF

Also called: Deblur-NeRF, Deblur-NeRF: Neural Radiance Fields from Blurry Images

## Overview
DeblurNeRF is a method that reconstructs a sharp Neural Radiance Field (NeRF) from blurry input images by explicitly modeling the blurring process via an analysis-by-synthesis approach [S1, S3]. It differs from its siblings [IE-NeRF](13737-ie-nerf.md) and [Sharp-NeRF](14270-sharp-nerf.md) by using a Deformable Sparse Kernel (DSK) to approximate spatially varying blur as a weighted sum of deformed rays, rather than relying on global rigid transformations or implicit restoration priors [S3]. The method jointly optimizes the NeRF and the blur kernel parameters, allowing inference to produce sharp novel views by simply rendering the NeRF without the blur simulation module [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of blurry multi-view images $B$. Camera poses and intrinsics are assumed known or estimated (e.g., via COLMAP) [S1].
*   **Outputs:** A sharp NeRF representation $F_\Theta$ and, during training, the parameters of the Deformable Sparse Kernel (DSK) module $G_\Phi$. At inference, only $F_\Theta$ is used to render sharp images [S1].

**Data Structures:**
1.  **NeRF ($F_\Theta$):** An MLP mapping 3D position $x$ and view direction $d$ to color $c$ and density $\sigma$.
    *   Input: Positional encoding $\gamma_L(x)$ and $\gamma_L(d)$.
    *   $\gamma_L(v) = [\sin(\pi v), \cos(\pi v), \dots, \sin(2^{L-1}\pi v), \cos(2^{L-1}\pi v)]^T$ [S1].
    *   $L$ is the highest frequency used [S1].
2.  **DSK Module ($G_\Phi$):** An MLP parameterizing the blur kernel.
    *   Structure: 4 fully-connected hidden layers, 64 channels each, ReLU activations. Includes a shortcut connection from the first layer to the last layer [S1].
    *   Inputs: Pixel coordinate $p$, canonical kernel location $q^0$, and a learned view embedding $l$ (length 32) [S1].
    *   Outputs: For each of $N$ kernel points, a tuple $(\Delta o_q, \Delta q, w_q)$.
        *   $\Delta o_q \in \mathbb{R}^3$: Ray origin translation [S1].
        *   $\Delta q \in \mathbb{R}^2$: Kernel location deformation (2D image plane offset) [S1].
        *   $w_q \in \mathbb{R}$: Composition weight [S1].
3.  **Canonical Kernel:** A set of $N$ fixed 2D locations $N^0(p) = \{q^0_i\}_{i=0}^{N-1}$ distributed around pixel $p$ [S1].

**Numbered Steps:**

1.  **Ray Generation (Standard NeRF):** For a pixel $p$, generate a primary ray $r_p(t) = o + t d_p$ from camera center $o$ along direction $d_p$ [S1].
2.  **Coarse Sampling:** Divide the near-to-far bounds $[t_n, t_f]$ into $N_{coarse}$ intervals using stratified sampling to generate coarse samples $r_i = o + t_i d_p$ [S3].
3.  **Coarse Rendering:** Evaluate $F_\Theta$ at samples to get $(c_i, \sigma_i)$. Compute coarse color $\hat{C}_c$ using volume rendering:
    $$ \hat{C}_c(r) = \sum_{i=1}^{N_{coarse}} T_i (1 - \exp(-\sigma_i \delta_i)) c_i $$
    where $\delta_i = t_{i+1} - t_i$ and $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ [S3].
4.  **Hierarchical Sampling:** Compute normalized weights $\hat{w}_i = w_i / \sum_j w_j$ as a PDF. Use $\hat{w}_i$ to sample $N_{fine}$ additional points for fine rendering [S3].
5.  **Fine Rendering:** Render fine color $\hat{C}_f$ using the same volume rendering formula with fine samples [S3].
6.  **DSK Prediction:** For each pixel $p$ in the batch, predict blur parameters for $N$ kernel points using $G_\Phi$:
    $$ (\Delta o_q, \Delta q, w_q) = G_\Phi(p, q^0, l), \quad q^0 \in N^0(p) $$
    [S1]. Note: Positional encoding on input $p$ is not used [S1].
7.  **Ray Deformation:** Generate $N$ optimized rays $r_q$ for the blur simulation:
    $$ r_q(t) = (o + \Delta o_q) + t d_q $$
    where $d_q$ is derived from the deformed location $q = q^0 + \Delta q$ [S1].
8.  **Blur Simulation Rendering:** Render each deformed ray $r_q$ using $F_\Theta$ to obtain colors $c^0_q$ [S1].
9.  **Blending:** Compute the predicted blurry pixel color $\hat{b}_p$ by blending the rendered colors with weights $w_q$, applying gamma correction to handle non-linear Camera Response Function (CRF):
    $$ \hat{b}_p = g\left(\sum_{q \in N(p)} w_q c^0_q\right) $$
    where $g(c^0) = (c^0)^{1/2.2}$ [S1].
10. **Loss Computation:** Compute the reconstruction loss against the ground truth blurry image $b^{gt}$:
    $$ L_{reconstruct} = \sum_{p \in R} \|\hat{b}_p - b^{gt}_p\|_2^2 $$
    where $R$ is the set of rays in the batch [S1].
11. **Alignment Loss:** Compute alignment loss to prevent non-rigid NeRF distortion and anchor the kernel:
    $$ L_{align} = \|q^0 - p\|_2^2 + \lambda_o \|\Delta o_{q^0}\|_2^2 $$
    where $q^0$ is a fixed element in $N(p)$ (typically the center) and $\lambda_o = 10$ [S1].
12. **Total Loss:**
    $$ L = L_{reconstruct} + \lambda_a L_{align} $$
    where $\lambda_a = 0.1$ [S1].
13. **Optimization:** Jointly update $F_\Theta$ and $G_\Phi$ using Adam optimizer [S1].
14. **Inference:** Render the NeRF directly using standard rays $r_p$ without the DSK module to produce sharp images [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class DeblurNeRF:
    def __init__(self, nerf_model, dsk_model, num_kernel_points=5, view_embedding_dim=32):
        self.nerf = nerf_model
        self.dsk = dsk_model
        self.N = num_kernel_points
        self.view_embedding_dim = view_embedding_dim
        self.lambda_align = 0.1
        self.lambda_o = 10
        self.epsilon = 0.1  # Initialization gain
        
        # Initialize DSK outputs to be small to start close to canonical kernel
        # This is a [G] implementation detail for stable training initialization
        with torch.no_grad():
            for param in self.dsk.parameters():
                param.mul_(0.01)

    def positional_encoding(self, x, L=10):
        """Standard NeRF positional encoding."""
        # x shape: (..., 3) or (..., 2)
        scales = torch.tensor([2**i for i in range(L)], dtype=x.dtype, device=x.device)
        xb = torch.reshape((x * scales).unsqueeze(-1), (*x.shape[:-1], L * x.shape[-1]))
        freq_bands = torch.cat([torch.sin(xb), torch.cos(xb)], dim=-1)
        return freq_bands

    def volume_render(self, ray_o, ray_d, z_vals, nerf_model):
        """Render color and density along a ray."""
        pts = ray_o.unsqueeze(1) + ray_d.unsqueeze(1) * z_vals.unsqueeze(2)
        pts_flat = pts.reshape(-1, 3)
        
        # Get positional encodings
        pts_enc = self.positional_encoding(pts_flat)
        ray_d_enc = self.positional_encoding(ray_d)
        
        # Forward NeRF
        # nerf_model expects concatenated encodings
        inputs = torch.cat([pts_enc, ray_d_enc.repeat_interleave(pts_enc.shape[0] // ray_d_enc.shape[0], dim=0)], dim=-1)
        
        # Assuming nerf_model returns (sigma, color)
        # Note: Standard NeRF MLPs often split color/density. 
        # Here we assume a simplified interface returning sigma and color directly.
        sigma, color = nerf_model(inputs)
        
        sigma = sigma.reshape(*z_vals.shape[:-1])
        color = color.reshape(*z_vals.shape[:-1], 3)
        
        # Volume rendering
        # delta_z = z_vals[:, 1:] - z_vals[:, :-1]
        # alpha = 1 - torch.exp(-sigma * delta_z)
        # T = torch.cumprod(torch.cat([torch.ones_like(alpha[..., :1]), 1 - alpha + 1e-10], dim=-1), dim=-1)[..., :-1]
        # weight = T * alpha
        # color_out = torch.sum(weight.unsqueeze(-1) * color, dim=-2)
        
        # Simplified standard volume rendering formula from notes:
        # C(r) = sum T_i (1 - exp(-sigma_i delta_i)) c_i
        delta = z_vals[:, 1:] - z_vals[:, :-1]
        transmittance = torch.exp(-torch.cumsum(sigma * delta, dim=-2))
        weights = transmittance * (1.0 - torch.exp(-sigma * delta))
        # Add last sample contribution (approx)
        # weights = torch.cat([weights, torch.zeros_like(weights[..., :1])], dim=-2)
        
        color_out = torch.sum(weights.unsqueeze(-1) * color, dim=-2)
        return color_out, sigma

    def forward(self, ray_o, ray_d, pixel_coords, view_id, gt_image):
        """
        ray_o: (B, 3)
        ray_d: (B, 3)
        pixel_coords: (B, 2)
        view_id: (B,)
        gt_image: (B, 3)
        """
        B = ray_o.shape[0]
        
        # 1. Generate canonical kernel locations N^0(p)
        # For simplicity, assume N^0 is a fixed offset grid around p
        # In practice, this might be precomputed or generated per pixel
        # Let's assume we have N canonical offsets relative to p
        # q^0 = p + offset_i
        # Note: The paper says q^0 are assigned per view. 
        # We generate N points around p.
        # [G] Implementation: Create a grid of N points centered at p
        # Assuming N=5, we might use center + 4 neighbors or a cross pattern.
        # The paper defines N^0(p) = {q^0_i}.
        
        # Generate canonical locations q^0 (B, N, 2)
        # Using a simple cross pattern for N=5: center, up, down, left, right
        offsets = torch.tensor([[0,0], [0,1], [0,-1], [1,0], [-1,0]], dtype=ray_o.dtype, device=ray_o.device)
        # Expand to batch
        # q^0 shape: (B, N, 2)
        q0 = pixel_coords.unsqueeze(1) + offsets.unsqueeze(0)
        
        # 2. Get view embeddings
        # [G] Assuming a lookup table for view embeddings
        view_embs = self.get_view_embedding(view_id) # (B, view_embedding_dim)
        
        # 3. Predict DSK parameters
        # Input to G_phi: p, q^0, l
        # Reshape for MLP: (B*N, 2 + 2 + view_dim)
        p_expanded = pixel_coords.unsqueeze(1).repeat(1, self.N, 1).reshape(-1, 2)
        q0_flat = q0.reshape(-1, 2)
        l_expanded = view_embs.unsqueeze(1).repeat(1, self.N, 1).reshape(-1, self.view_embedding_dim)
        
        dsk_input = torch.cat([p_expanded, q0_flat, l_expanded], dim=-1)
        
        # Forward DSK MLP
        # dsk_output shape: (B*N, 3 + 2 + 1) = (B*N, 6)
        # Order: delta_o (3), delta_q (2), w (1)
        dsk_output = self.dsk(dsk_input)
        
        delta_o = dsk_output[:, :3]
        delta_q = dsk_output[:, 3:5]
        w = dsk_output[:, 5:6]
        
        # Reshape back to (B, N, ...)
        delta_o = delta_o.reshape(B, self.N, 3)
        delta_q = delta_q.reshape(B, self.N, 2)
        w = w.reshape(B, self.N, 1)
        
        # 4. Compute deformed kernel locations q
        q = q0 + delta_q # (B, N, 2)
        
        # 5. Compute deformed ray directions d_q
        # d_q is derived from q. 
        # The paper says: "dq is transformed ray direction by applying delta_vT to pixel coordinates"
        # Usually, direction is computed as (q - camera_center) normalized.
        # However, the paper defines rq = (o + delta_o) + t * dq.
        # And dq comes from the deformed location.
        # [G] Standard ray direction from pixel: d = normalize(pixel - center).
        # Here, we treat q as a "virtual pixel" on the image plane.
        # We need camera intrinsics to convert q to direction.
        # Assuming we have intrinsics or can compute direction from q relative to principal point.
        # For this pseudocode, we assume a helper `pixel_to_direction` exists.
        # d_q = pixel_to_direction(q, intrinsics)
        # Since intrinsics are not passed, we assume d_q is computed from q.
        # Let's assume a simplified linear mapping for direction derivation from 2D coord
        # [G] This is a gap. In NeRF, d is view direction. 
        # If q is a 2D pixel coord, d_q = normalize(R @ (K^{-1} @ [q, 1])).
        # We will assume `compute_directions` is available.
        d_q = compute_directions(q, ray_o) # (B, N, 3)
        
        # 6. Generate deformed rays
        # rq = (o + delta_o) + t * dq
        ray_o_deformed = ray_o.unsqueeze(1) + delta_o # (B, N, 3)
        
        # 7. Sample along deformed rays
        # Use same z_vals as original ray for consistency
        # [G] Assume z_vals is generated from ray_o, ray_d bounds
        # z_vals shape: (B, N_samples)
        # We need to broadcast to (B, N, N_samples)
        z_vals = generate_z_vals(ray_o, ray_d) # (B, N_samples)
        z_vals_expanded = z_vals.unsqueeze(1).repeat(1, self.N, 1) # (B, N, N_samples)
        
        # 8. Render deformed rays
        # Colors c^0_q shape: (B, N, 3)
        c_deformed, _ = self.volume_render(ray_o_deformed, d_q, z_vals_expanded, self.nerf)
        
        # 9. Blend
        # b_hat = gamma( sum(w * c) )
        # w shape: (B, N, 1)
        blended = torch.sum(w * c_deformed, dim=1) # (B, 3)
        b_hat = torch.pow(blended, 1/2.2)
        
        # 10. Losses
        # Reconstruction Loss
        L_recon = torch.mean((b_hat - gt_image)**2)
        
        # Alignment Loss
        # q^0 is the canonical location. 
        # L_align = ||q^0 - p||^2 + lambda_o * ||delta_o_{q^0}||^2
        # Note: The paper says "q^0 is a fixed element in N(q)". 
        # Usually the center element (index 0 if center is first).
        # Let's assume index 0 is the center.
        q0_center = q0[:, 0, :] # (B, 2)
        p_center = pixel_coords # (B, 2)
        delta_o_center = delta_o[:, 0, :] # (B, 3)
        
        L_align_pos = torch.mean((q0_center - p_center)**2)
        L_align_orig = torch.mean((delta_o_center)**2)
        L_align = L_align_pos + self.lambda_o * L_align_orig
        
        L_total = L_recon + self.lambda_align * L_align
        
        return b_hat, L_total, L_recon, L_align

    def get_view_embedding(self, view_id):
        # [G] Placeholder for view embedding lookup
        return torch.zeros(view_id.shape[0], self.view_embedding_dim, device=view_id.device)

    def render_sharp(self, ray_o, ray_d):
        """Inference: Render sharp image without DSK."""
        z_vals = generate_z_vals(ray_o, ray_d)
        color, _ = self.volume_render(ray_o, ray_d, z_vals, self.nerf)
        # Apply gamma correction for display if needed, though NeRF output is usually linear
        # The paper mentions gamma correction for the blurry synthesis. 
        # For sharp inference, standard NeRF rendering is used.
        return color
```

**Parameters:**
*   $N$: Number of sparse kernel points. Default: 5 [S1].
*   $L$: Highest frequency in positional encoding. Controls smoothness [S1].
*   View embedding length: 32 [S1].
*   Batch size: 1024 rays [S1].
*   Sampling: 64 coarse samples, 64 fine samples [S1].
*   Learning rate: Starts at $5 \times 10^{-4}$, decays exponentially to $8 \times 10^{-5}$ [S1].
*   Optimizer: Adam (default parameters) [S1].
*   $\lambda_a$ (Alignment loss weight): 0.1 [S1].
*   $\lambda_o$ (Origin alignment weight): 10 [S1].
*   Initialization gain $\epsilon$: 0.1 applied to DSK outputs to keep rays close to input ray initially [S1].

**Edge Cases and Pitfalls:**
*   **Non-rigid Distortion:** If all components (NeRF and DSK) are freely optimized, the NeRF may undergo non-rigid distortion to compensate for blur errors. This is mitigated by the alignment loss $L_{align}$ [S1].
*   **3D Inconsistency:** Pixel-wise independent optimization of the blur kernel (as in DeblurNeRF) can incur inconsistency in 3D geometry and appearance compared to scene-wise shared transformations (like DP-NeRF) [S3].
*   **Positional Encoding:** Using positional encoding on the input pixel coordinate $p$ of the DSK MLP $G_\Phi$ was tested but found not to help, likely because the spatially-varying kernel changes gradually without high-frequency variation [S1].
*   **Gamma Correction:** Simple gamma correction ($1/2.2$) is used to handle non-linear CRF. More complex CRFs could be used but were found unnecessary for the tested scenes [S1].

## Operating characteristics
*   **Time Complexity:** Training requires rendering $N$ rays per pixel instead of 1. With $N=5$, the rendering cost per pixel is approximately 5x higher than standard NeRF, plus the cost of the DSK MLP forward pass. Hierarchical sampling doubles the sampling steps.
*   **Memory Complexity:** Requires storing parameters for the NeRF and the DSK MLP. The DSK MLP is small (4 layers, 64 channels). View embeddings require $32 \times V$ memory for $V$ views.
*   **Measured Performance:** Tested on synthetic scenes (Blender) and 20 real-world scenes (Canon EOS RP). Achieves higher PSNR/SSIM and lower LPIPS compared to ablations (w/o gamma, w/o align, w/o origin opt) and other methods [S1].
*   **Scaling:** Quality improves as $N$ increases, but improvement is less substantial beyond $N=5$ [S1].
*   **Strengths:** Handles both camera motion blur and defocus blur. Recovers sharp NeRF from blurry inputs. Efficient approximation for moderate blur [S2].
*   **Limitations:** Pixel-wise independent blur modeling may lead to 3D inconsistency. Less effective for severe motion blur compared to physically grounded methods like BAD-NeRF [S2].
*   **When to use:** When input images are blurry (motion or defocus) and sharp novel views are desired. Suitable for moderate blur.
*   **When not to use:** For severe motion blur where physical trajectory modeling is needed (use BAD-NeRF) or when 3D consistency across views is critical and pixel-wise blur independence causes artifacts (use DP-NeRF) [S3].

## Background
DeblurNeRF was proposed by Xiaoyu Li, Jing Liao, Qi Zhang, Jue Wang, Pedro V. Sander, and Li Ma from The Hong Kong University of Science and Technology, Tencent AI Lab, and City University of Hong Kong [S1]. It was published in CVPR 2022 (arXiv:2111.14292) [S1]. It is the first method to recover a sharp NeRF from blurry inputs by explicitly modeling the blurring process. It builds on the analysis-by-synthesis approach and the NeRF representation [S1]. It differs from DP-NeRF by using pixel-wise independent transformations (DSK) instead of scene-wise shared rigid transformations (RBK) [S3]. It is implemented on a PyTorch re-implementation of NeRF and tested on synthetic and real-world data [S1].
