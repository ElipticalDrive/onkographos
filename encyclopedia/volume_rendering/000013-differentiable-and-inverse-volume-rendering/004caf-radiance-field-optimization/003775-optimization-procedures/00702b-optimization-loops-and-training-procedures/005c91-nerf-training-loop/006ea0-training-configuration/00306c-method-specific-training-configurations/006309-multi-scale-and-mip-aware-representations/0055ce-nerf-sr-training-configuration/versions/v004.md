# NeRF-SR Training Configuration

Also called: NeRF-SR, NeRF Super-Resolution

## Overview
NeRF-SR is a method for training high-quality neural radiance fields from low-resolution input images by exploiting 3D consistency through a supersampling strategy [S1]. It differs from standard NeRF training by rendering at multiple scales during optimization to enforce detail consistency, and optionally applies a post-training refinement network to restore high-frequency textures [S1]. Unlike methods that rely on external data or pre-trained models, NeRF-SR achieves super-resolution without auxiliary inputs [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of low-resolution (LR) images with known camera poses.
*   **Output:** A trained NeRF model capable of rendering high-resolution (HR) novel views, optionally refined with texture details.

**Data Structures:**
*   **Ray Bundle:** Standard ray bundle $[B, 3]$ origins and $[B, 3]$ directions [S1].
*   **Training Set:** 100 views for training, 200 held out for testing (Blender dataset) [S1]. For LLFF, all images are used for training and averaged metrics are reported [S1].

**Numbered Steps:**

1.  **Initialization:**
    *   Initialize the Adam optimizer with $\beta_1=0.9$, $\beta_2=0.999$ [S1].
    *   Initialize the NeRF MLPs (coarse and fine) following standard NeRF architecture [S1].

2.  **Supersampling Training Loop:**
    *   For each training iteration, render the scene at multiple resolution scales simultaneously [S1].
    *   Compute the loss between the rendered images at each scale and the corresponding downsampled ground truth images [S1].
    *   The supersampling strategy ensures that the high-frequency details learned by the network are consistent with the low-resolution inputs [S1].

3.  **Optimization Parameters:**
    *   **Batch Size:** 2048 rays per batch [S1].
    *   **Learning Rate:** Exponentially decayed from $5 \times 10^{-4}$ to $5 \times 10^{-6}$ [S1].
    *   **Sampling:** Hierarchical sampling with 64 coarse samples and 64 fine samples [S1].
    *   **Epochs:**
        *   Blender dataset: 20 epochs [S1].
        *   LLFF dataset: 30 epochs [S1].
        *   Note: One epoch contains one iteration of the whole training set [S1].

4.  **Refinement (Optional):**
    *   If using the refinement network (Ours-Refine), apply it after the supersampling training to boost texture details and edge sharpness, particularly for real-world scenes like LLFF where supersampling alone is insufficient [S1].
    *   **Reference Patches:** Use $K=8$ reference patches of dimension $64 \times 64$ [S1].
    *   **Inference:** Divide input images into non-overlapping patches, refine them using the reference patches, and stitch them together [S1].
    *   **Reference Image:** The first image in the dataset is used as the reference (omitted from metric calculation) [S1].

**Pseudocode:**

```python
def train_nerf_sr(dataset, num_epochs, batch_size=2048):
    # Initialize NeRF model (coarse and fine MLPs)
    model = NeRFModel()
    
    # Initialize Adam optimizer
    optimizer = Adam(model.parameters(), lr=5e-4, betas=(0.9, 0.999))
    
    # Learning rate decay schedule
    lr_scheduler = ExponentialDecayLR(start_lr=5e-4, end_lr=5e-6)
    
    for epoch in range(num_epochs):
        for batch in dataset:
            # Get rays and ground truth images
            rays, gt_images = batch
            
            # Render at multiple scales (supersampling)
            # This step enforces 3D consistency across resolutions
            rendered_images = render_at_multiple_scales(model, rays)
            
            # Compute loss against downsampled ground truth
            loss = compute_loss(rendered_images, gt_images)
            
            # Backpropagate and update
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            # Update learning rate
            lr_scheduler.step()
            
    return model

def refine_nerf_output(model, input_image, reference_patches, patch_size=64, k=8):
    """
    Refine NeRF output using reference patches.
    """
    # Divide input image into non-overlapping patches
    patches = split_into_patches(input_image, patch_size)
    
    refined_patches = []
    for patch in patches:
        # Extract corresponding reference patches from K reference images
        ref_patches = extract_reference_patches(patch, reference_patches, k)
        
        # Apply refinement network to enhance texture and edges
        refined_patch = apply_refinement_network(patch, ref_patches)
        refined_patches.append(refined_patch)
        
    # Stitch patches back together
    refined_image = stitch_patches(refined_patches, patch_size)
    return refined_image
```

**Edge Cases and Pitfalls:**
*   NeRF-SR does not support arbitrary-scale super-resolution; it is trained for specific scale factors (e.g., $\times 2$, $\times 4$) [S1].
*   For scale factor 2, PSNR increases only slightly after refinement because supersampling already learns decent high-resolution fields, but LPIPS improves [S1].
*   For scale factor 4, refinement is necessary as supersampling derives fewer details from low-resolution inputs [S1].

## Subtopics

### Refinement Network (Ours-Refine)
A post-processing network that boosts NeRF-SR outputs with texture details and edge sharpness, particularly for real-world LLFF dataset where supersampling alone is insufficient [S1]. It uses $K=8$ reference patches of size $64 \times 64$ [S1]. During inference, input images are divided into non-overlapping patches and stitched together after refinement [S1]. It adds negligible time (~1.3 seconds on a 1080Ti for a 1008x756 image) compared to the main rendering (~48 seconds) [S1]. For LLFF $\times 2$, it yields PSNR 27.34, SSIM 0.842, LPIPS 0.103; for $\times 4$, it yields PSNR 25.59, SSIM 0.759, LPIPS 0.165 [S1].

## Operating characteristics
*   **Time Complexity:** The refinement stage adds negligible time compared to volumetric rendering (e.g., 1.3s vs 48s for a 1008x756 image on a 1080Ti) [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:**
    *   **Blender Dataset:** Trained for 20 epochs [S1].
    *   **LLFF Dataset:** Trained for 30 epochs [S1].
    *   **Metrics:** Evaluated using PSNR, SSIM, and LPIPS [S1].
*   **Strengths:** Achieves photorealistic renderings without external data by exploiting 3D consistency [S1].
*   **Limitations:** Does not support arbitrary-scale super-resolution; introduces extra computational cost compared to vanilla NeRF, though less than training a full HR NeRF [S1].

## Background
NeRF-SR was introduced as the first pipeline for high-resolution novel view synthesis using mostly low-resolution inputs without external data [S1]. It exploits 3D consistency from two perspectives: a supersampling strategy and a refinement network [S1]. The method was developed to address the limitations of vanilla NeRF and other super-resolution methods that rely on bicubic upsampling or external data [S1].
