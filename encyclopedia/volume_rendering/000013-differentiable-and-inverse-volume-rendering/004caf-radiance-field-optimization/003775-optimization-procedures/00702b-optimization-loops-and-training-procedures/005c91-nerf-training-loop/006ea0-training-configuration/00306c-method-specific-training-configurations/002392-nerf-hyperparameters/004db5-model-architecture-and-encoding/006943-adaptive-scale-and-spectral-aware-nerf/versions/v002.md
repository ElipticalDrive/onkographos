# Adaptive-Scale and Spectral-Aware NeRF

Also called: NeRF combining adaptive scaling with spectral perception

## Overview
Adaptive-Scale and Spectral-Aware NeRF is a neural radiance field variant that integrates an adaptive scale function to modulate sample point contributions and a spectral decoder to handle multispectral information, including infrared and ultraviolet wavelengths, for improved color fidelity [S1]. It builds on [Model Architecture and Encoding](13550-model-architecture-and-encoding.md) by replacing the standard color prediction with a wavelength-aware mechanism and adjusting density integration weights via local feature analysis [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** 2D toy image $I$, camera parameters $P$, global features $G$ extracted from $I$ using MTL-FeatureNet, and spectral components $\varepsilon$ [S1].
*   **Outputs:** Rendered 3D image $C(r)$ [S1].

**Data Structures**
*   **Global Features ($G$):** Extracted from input image $I$ using MTL-FeatureNet [S1].
*   **Local Features ($Q$):** Derived from 3D position $x(t)$ and global features $G$ via function $FA$ [S1].
*   **Adaptive Scale ($S$):** A scalar value computed from local features and global features [S1].
*   **Spectral Components ($\varepsilon$):** Wavelength values for which color is estimated [S1].

**Method Steps**

1.  **Initialize Model:** Load MTL-FeatureNet to extract global features $G$ from input image $I$ [S1]. Define the volume density network $\sigma(x)$ and the color network $c(x, \varepsilon, S)$ [S1].
2.  **Compute Adaptive Scale:** Extract local features $Q$ from 3D position $x(t)$ using $FA(G, x(t))$ [S1]. Compute the adaptive scale $S$ using the formula:
    $$ S(FA(G, x(t)), G) = \sigma(\beta \cdot D_{complex}(CT(FA(G, x(t)), G))) $$
    Where $D_{complex}$ is a depth network, $CT$ is a feature combination function, and $\beta$ is a parameter [S1].
3.  **Spectral-Aware Color Estimation:** Estimate color $c(x, \varepsilon)$ at position $x$ and wavelength $\varepsilon$ using the spectral decoder:
    $$ c(x, \varepsilon) = \text{softmax}\left(\sum_{n=1}^N G_n \cdot e^{-\frac{(\varepsilon - \mu_n)^2}{2\delta_n^2}}\right) \cdot MLP_{color}(F(x, \varepsilon)) $$
    Where $N$ is the number of spectral components, $G_n$ is the weight of the $n$-th component, $\mu_n$ is the center wavelength, $\delta_n^2$ is the variance, $MLP_{color}$ is a multilayer perceptron, and $F(x, \varepsilon)$ are spectral features [S1].
4.  **Rendering Integration:** Render the image $C(r)$ by integrating along the ray $r$:
    $$ C(r) = \int_{t_n}^{t_f} T(t) \cdot \sigma(p(x(t))) \cdot c(x(t), S(FA(G, x(t)), G)) \, dt $$
    Where $T(t)$ is the accumulated transmittance, $\sigma(p(x(t)))$ is the spectral-aware volume density, and $c$ is the color modulated by the adaptive scale $S$ [S1].
5.  **Output:** Return the final rendered image $C(r)$ [S1].

**Pseudocode**

```python
import math

def adaptive_scale_spectral_nerf(I, P, G, epsilon):
    """
    Render an image using Adaptive-Scale and Spectral-Aware NeRF.
    
    Args:
        I: Input 2D toy image.
        P: Camera parameters containing rays. Each ray has origin, direction, near, far, num_samples.
        G: Global features from MTL-FeatureNet.
        epsilon: Spectral components (wavelengths).
        
    Returns:
        C: Rendered 3D image.
    """
    # Precompute spectral weights for all rays
    spectral_sum = 0.0
    for n in range(N):
        spectral_sum += G_n[n] * math.exp(-((epsilon - mu_n[n])**2) / (2 * delta_n[n]**2))
    softmax_weight = 1.0  # softmax of a scalar sum evaluates to 1.0 per source formula
    
    rendered_image = []
    
    for ray in P.rays:
        accumulated_transmittance = 1.0
        ray_color = [0.0, 0.0, 0.0]
        prev_t = ray.near
        
        for t in [ray.near + (ray.far - ray.near) * (k + 0.5) / ray.num_samples for k in range(ray.num_samples)]:
            # 3D position x(t)
            x_t = [ray.origin[i] + t * ray.direction[i] for i in range(3)]
            
            # Step 2: Adaptive-Scale Function
            # Extract local features Q from 3D position x(t) using FA(G, x(t))
            Q = fa_func(G, x_t)
            
            # Compute adaptive scale S
            combined_features = ct_func(Q, G)
            depth_output = depth_net(combined_features)
            S = activation_fn(beta * depth_output)
            
            # Step 3: Spectral-Aware Color Estimation
            # Get spectral features F(x, epsilon)
            F = spectral_features_net(x_t, epsilon)
            
            # Apply MLP for color (S is passed as per step 1 definition c(x, epsilon, S))
            color = softmax_weight * mlp_color(F, S)
            
            # Step 4: Rendering Integration
            # sigma(p(x(t))) is the spectral-aware volume density
            density = density_net(x_t)
            
            # Distance between samples
            delta = t - prev_t
            
            # Opacity and transmittance update
            alpha = 1.0 - math.exp(-density * delta)
            accumulated_transmittance *= (1.0 - alpha)
            
            # Accumulate color
            for c in range(3):
                ray_color[c] += accumulated_transmittance * alpha * color[c]
            
            prev_t = t
            
        rendered_image.append(ray_color)
        
    return rendered_image
```

**Edge Cases and Pitfalls**
*   **Spectral Range:** The method supports infrared and ultraviolet information, requiring appropriate handling of $\varepsilon$ outside the visible spectrum [S1].
*   **Feature Extraction:** The quality of $G$ depends on MTL-FeatureNet; poor extraction may degrade adaptive scaling [S1].
*   **Depth Network:** $D_{complex}$ requires accurate depth estimation; errors here affect the adaptive scale $S$ [S1].
*   **Variable Naming:** The source uses $\sigma$ for both the volume density network and the activation function in the adaptive scale computation; implementations must distinguish them to avoid mathematical conflicts [S1].
