# LoRA Fine-Tuning of DINO

Also called: LoRA-NeRF, NeRF with LoRA-fine-tuned DINO features

## Overview
LoRA Fine-Tuning of DINO adapts frozen DINOv2 vision features to the geometric objectives of NeRF by applying Low-Rank Adaptation (LoRA) to the attention layers of the Vision Transformer (ViT) backbone [S1, unofficial]. It addresses the misalignment between semantic-rich frozen features and the geometric requirements of few-shot 3D reconstruction [S1, unofficial]. Unlike frozen feature baselines, this method makes only low-rank matrices trainable, allowing the model to adapt DINO features to specific reconstruction tasks while preserving prior knowledge [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Pre-trained DINOv2-base model weights ($W_0$), input images, and camera poses.
*   **Output:** Adapted DINO features ($f'$) projected to 256 dimensions, fused with positional encodings, and processed by the NeRF MLP to output RGB color ($c$) and volume density ($\sigma$) [S1, unofficial].

**Data Structures and Layout:**
1.  **DINOv2 Backbone:** The DINOv2-base model outputs 768-dimensional features [S1, unofficial].
2.  **LoRA Matrices:** For each targeted attention layer, two trainable matrices are defined:
    *   $A \in \mathbb{R}^{r \times d}$
    *   $B \in \mathbb{R}^{d \times r}$
    *   Where $d$ is the dimension of the attention layer weights and $r$ is the LoRA rank [S1, unofficial].
3.  **Feature Projection:** A linear layer projects the 768-dimensional DINO features to 256 dimensions to match the NeRF MLP input size [S1, unofficial].
4.  **NeRF MLP:** An 8-layer MLP with 256 hidden units, ReLU activations, and a skip connection at the 4th layer [S1, unofficial].

**Parameters:**
*   **LoRA Rank ($r$):** 16 [S1, unofficial].
*   **Targeted Layers:** Attention layers of the ViT [S1, unofficial].
*   **Pre-trained Weights ($W_0$):** Frozen [S1, unofficial].

**Algorithm:**
The method modifies the weight update in the attention layers of the DINO ViT. Instead of updating the full weight matrix $W$, the update is decomposed into a low-rank approximation added to the frozen weights.

1.  **Initialize:** Load pre-trained DINOv2-base weights $W_0$. Freeze $W_0$. Initialize trainable matrices $A$ and $B$ for each targeted attention layer.
2.  **Forward Pass (Feature Extraction):**
    For each input image:
    a. Pass the image through the DINOv2 backbone.
    b. For each targeted attention layer with weight $W$, compute the effective weight:
       $$W_{eff} = W_0 + BA$$
    c. Compute the attention output using $W_{eff}$.
    d. Extract the final feature vector $f_{raw} \in \mathbb{R}^{768}$.
3.  **Feature Projection:**
    Project $f_{raw}$ to $f' \in \mathbb{R}^{256}$ using a learned linear projection layer.
4.  **NeRF Rendering:**
    For each ray:
    a. Sample points along the ray.
    b. Encode position $x$ and direction $d$ using positional encoding (10 bands for position, 4 for direction) [S1, unofficial].
    c. Concatenate $[\gamma(x), \gamma(d), f'(x)]$.
    d. Pass through the NeRF MLP to predict $(c, \sigma)$.
    e. Render the image using volume rendering (32 stratified samples per ray) [S1, unofficial].
5.  **Optimization:**
    Minimize the reconstruction loss using the Adam optimizer with learning rate $2 \times 10^{-4}$ [S1, unofficial]. Only $A$, $B$, and the projection layer weights are updated; $W_0$ remains constant [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** Mixed-precision training is used to accelerate experiments [S1, unofficial].
*   **Overfitting:** Dropout rate of 0.1 is applied in the NeRF MLP [S1, unofficial].
*   **Gradient Clipping:** Max norm 1.0 is applied to prevent gradient explosion [S1, unofficial].
*   **Early Stopping:** Training stops based on validation PSNR with a patience of 20 epochs [S1, unofficial].

## Subtopics

### LoRA Fine-Tuning
A technique that fine-tunes the diffusion model with minimal computational overhead, making it adaptable to new tasks by modifying a few parameters within the model [S2].

## Operating characteristics
*   **Time Complexity:** Training typically takes 2-4 hours per experiment, depending on model complexity [S1, unofficial].
*   **Memory Complexity:** DINO features are computed once and cached for efficiency, reducing repeated forward passes through the vision backbone [S1, unofficial].
*   **Performance:** On the Lego dataset with 5 training views, LoRA-NeRF achieves a PSNR of 12.97, SSIM of 0.45, and LPIPS of 0.54 [S1, unofficial]. This is comparable to the frozen DINO-NeRF baseline (PSNR 12.99, SSIM 0.46, LPIPS 0.54) but slightly worse than the baseline NeRF (PSNR 14.71, SSIM 0.46, LPIPS 0.53) [S1, unofficial].
*   **Strengths:** Parameter-efficient adaptation of pre-trained vision features; preserves prior knowledge from ImageNet pre-training [S1, unofficial].
*   **Limitations:** In the reported experiments, LoRA-NeRF did not outperform the frozen DINO baseline or the baseline NeRF on the Lego dataset, suggesting that geometric alignment via LoRA alone may not be sufficient for few-shot reconstruction in all cases [S1, unofficial].

## Background
The method was introduced in "Limitations of NERF with pre-trained Vision Features for Few-Shot 3D Reconstruction" [S1, unofficial]. It builds on the observation that while frozen DINO features offer semantic richness, they may not align well with NeRF’s geometric objectives [S1, unofficial]. LoRA [10] is used as the adaptation mechanism. The implementation is based on PyTorch and uses the DINOv2-base model [S1, unofficial].
