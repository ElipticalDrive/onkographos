# Transformer and Vision Model Integration

Also called: NeRF Analogies, Visual Attribute Transfer via ViT

## Overview
This method transfers visual attributes (appearance) from a source NeRF to a target NeRF using dense semantic correspondences derived from Vision Transformer (ViT) features, creating a 'NeRF analogy' [S1]. It solves the problem of rigid appearance transfer by leveraging semantic similarity rather than geometric proximity, allowing for the transfer of textures and materials between objects with different geometries [S1]. Unlike sibling methods that focus on view synthesis or scene reconstruction, this approach operates as a post-processing or editing step that modifies the radiance field's appearance based on external visual cues [S1].

## How it works
The method integrates a pre-trained Vision Transformer to extract dense semantic features from source images, which are then used to guide the optimization of a target NeRF.

**Inputs and Outputs:**
*   **Input:** Source NeRF (or source images), Target NeRF (initialized or partially trained), and the target scene geometry/viewpoints.
*   **Output:** A modified target NeRF with transferred appearance attributes.

**Data Structures:**
*   **Feature Maps:** Dense 2D feature maps extracted from source images. For 400p images, these have a resolution of $392 \times 392$ with 384 features per pixel [S1].
*   **NeRF MLP:** A standard fully-connected MLP architecture [S1].
    *   Layers: 8 layers of 256 neurons, followed by 1 layer of 128 neurons.
    *   Output Layer: Activated by a Sigmoid function [S1].

**Steps:**
1.  **Feature Extraction:** Extract features from the source image using DiNO-ViT with a ViT-8B backbone [S1].
    *   Patch size: 8.
    *   Stride: 4 pixels.
    *   Resolution: Increased resolution is used to create overlapping patches for smoother feature maps [S1].
    *   Depth: The output of the deepest (11th) attention layer is used, specifically the key-component of the attention maps, as it correlates well with semantic similarity [S1].
2.  **Resolution Enhancement:** To achieve pixel-granularity dense correspondences, query the DiNO model on vertically and horizontally translated versions of the image (four subsequent translations by one pixel in -x and -y directions) [S1].
3.  **Correspondence Mapping:** Compute semantic similarity between points in the target scene and the source image features. The method assumes that semantically related regions should share appearance attributes, regardless of their geometric position [S1].
4.  **Optimization:** Train the target NeRF using a combined loss function that includes a standard color loss and a Difference-of-Gaussians (DoG) loss to enforce edge consistency [S1].

**Formulas:**
The total loss $\mathcal{L}$ is defined as:
$$
\mathcal{L} = \mathcal{L}_c + \lambda \, \mathcal{L}_G
$$
Where:
*   $\mathcal{L}_c$ is the color loss [S1].
*   $\mathcal{L}_G$ is the DoG loss [S1].
*   $\lambda$ is the weight for the DoG loss [S1].

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $1 \times 10^{-4}$ [S1].
*   **Batch Size:** 512 [S1].
*   **$\lambda$ Schedule:** $\lambda = 0$ for the first 20,000 iterations, then gradually faded in up to 50 [S1].
*   **Total Iterations:** 60,000 [S1].

**Edge Cases and Pitfalls:**
*   **Noisy Correspondences:** DiNO features may produce noisy correspondences where two points on the target mesh map to different points in the source NeRF. The use of L1 loss helps alleviate this by encouraging sparsity [S1].
*   **Feature Granularity:** Using coarser feature granularities (e.g., DiNO-v2) reduces the quality of dense correspondences [S1].
*   **Semantic vs. Geometric:** The method relies on semantic similarity, so it may fail if the source and target objects are semantically unrelated, although it can still produce plausible outcomes for similarly shaped but unrelated objects (e.g., avocado to armchair) [S1].

**Pseudocode:**
```python
def train_nerf_analogy(source_image, target_viewpoints, target_geometry):
    # 1. Feature Extraction
    # Use DiNO-ViT with ViT-8B backbone
    # Patch size: 8, Stride: 4
    # Use 11th attention layer, key-component
    base_features = extract_dino_features(source_image, patch_size=8, stride=4, layer=11)
    
    # 2. Resolution Enhancement
    # Query DiNO on translated versions of the image
    # 4 translations: -1, 0, +1 in x and y
    enhanced_features = []
    for dx in [-1, 0, 1]:
        for dy in [-1, 0, 1]:
            translated_img = translate_image(source_image, dx, dy)
            feats = extract_dino_features(translated_img, patch_size=8, stride=4, layer=11)
            enhanced_features.append(feats)
    
    # Interpolate/merge to get high-res feature map
    # Result: 392x392 resolution, 384 features per pixel for 400p input
    high_res_features = merge_features(enhanced_features)
    
    # 3. Initialize Target NeRF
    # MLP: 8x256, 1x128, Sigmoid output
    nerf = initialize_mlp(8, 256, 1, 128, activation='sigmoid')
    
    # 4. Optimization Loop
    optimizer = Adam(nerf.parameters(), lr=1e-4, batch_size=512)
    lambda_g = 0
    
    for iteration in range(60000):
        # Sample rays from target_viewpoints
        rays = sample_rays(target_viewpoints)
        
        # Render color from NeRF
        rendered_color = render_nerf(nerf, rays)
        
        # Compute Color Loss
        loss_c = compute_color_loss(rendered_color, target_gt)
        
        # Compute DoG Loss based on semantic correspondences
        # Map target points to source features using semantic similarity
        semantic_map = compute_semantic_correspondence(target_geometry, high_res_features)
        loss_g = compute_dog_loss(rendered_color, semantic_map)
        
        # Update lambda schedule
        if iteration > 20000:
            lambda_g = min(50, lambda_g + schedule_factor)
        
        # Total Loss
        loss = loss_c + lambda_g * loss_g
        
        # Backpropagate
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
    return nerf
```

## Subtopics

### [ViT-NeRF](13878-vit-nerf.md)
ViT-NeRF is a view synthesis method that conditions volume rendering on hybrid per-pixel features extracted from a single input image. It combines a Vision Transformer (ViT) to encode global shape information with a 2D CNN to extract local appearance details, addressing the blurriness and color inconsistency that occur when using only global features near the input view. Unlike methods requiring a canonical coordinate system, ViT-NeRF operates directly on image-based features, producing sharper edges and clearer structures in unseen regions compared to siblings like PixelNeRF.

### [VisionNeRF](13885-visionnerf.md)
VisionNeRF is a novel view synthesis method that infers a 3D radiance field from a single unposed input image by combining global features learned from a Vision Transformer (ViT) and local appearance features extracted from a 2D CNN. It solves the problem of self-occlusion in image-conditioned models, where standard approaches query features along the ray corresponding to the visible surface in the input view, leading to incorrect conditioning for occluded regions (e.g., using window features to render a wheel). Unlike siblings such as [ViT-NeRF](13878-vit-nerf.md) which focuses on multi-view consistency, or [TransNeRF](13907-transnerf.md) which uses transformers for ray sampling, VisionNeRF explicitly replaces the local feature projection paradigm with a hybrid global-local representation to retrieve relevant features from distant parts of the source view for occluded regions.

### [TransNeRF](13907-transnerf.md)
TransNeRF is a generalizable neural radiance field method that learns a generic 3D scene representation from multiple source views without requiring per-scene optimization. It replaces the pooling-based multi-view aggregation of prior methods with an encoder-decoder Transformer framework that explores deep relationships among views and enforces local 5D radiance field consistency via attention mechanisms.

## Operating characteristics
*   **Time Complexity:** Training time is less than two hours on a single GPU, including feature extraction [S1].
*   **Memory Complexity:** Feature maps for 400p images have a resolution of 392 with 384 features per pixel [S1].
*   **Performance:** Evaluated on real-world scenes using NeRFStudio Instant-NGP and 2D methods lifted to 3D [S1].
*   **Strengths:** Fast training, effective semantic transfer, robust to geometric differences between source and target.
*   **Limitations:** Relies on the quality of ViT features; may produce noisy correspondences; performance degrades if source and target are semantically unrelated.
*   **When to Use:** When transferring appearance between objects with similar semantics but different geometries.
*   **When Not to Use:** When precise geometric alignment is required or when source and target objects have no semantic relationship.

## Background
The method was introduced in "NeRF Analogies: Example-Based Visual Attribute Transfer for NeRFs" by Michael Fischer et al. [S1]. It builds on the standard NeRF architecture and leverages advances in Vision Transformers (ViT) for dense semantic correspondence. The use of DiNO-ViT features was chosen over diffusion features and SIFT due to their balance of semantic richness and computational efficiency [S1].
