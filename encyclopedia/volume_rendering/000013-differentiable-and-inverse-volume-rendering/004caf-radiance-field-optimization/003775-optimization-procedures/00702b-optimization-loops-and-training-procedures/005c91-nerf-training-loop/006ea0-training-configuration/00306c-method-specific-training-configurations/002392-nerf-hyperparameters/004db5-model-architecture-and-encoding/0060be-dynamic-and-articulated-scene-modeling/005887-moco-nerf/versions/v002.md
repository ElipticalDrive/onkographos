# MoCo-NeRF

Also called: Motion-Oriented Compositional Neural Radiance Fields

## Overview
MoCo-NeRF is a framework for free-viewpoint rendering of monocular human videos that models non-rigid body motions as radiance residual fields rather than spatial offsets [S1]. It decomposes the representation into a rigid branch learning a canonical T-pose radiance field via rigid skeletal transformations and a non-rigid branch optimizing pose-driven radiance residuals [S1]. Unlike offset-based strategies that suffer from high computational complexity and misaligned learning objectives, MoCo-NeRF reduces prediction range to the radiance space and establishes direct supervision from ground-truth pixel colors [S1].

## How it works
**Inputs:**
*   Monocular video frames of a human subject (or multiple subjects).
*   Skeletal pose data for each frame, consisting of $K$ joint rotations $R_k$ and translations $t_k$, and canonical skinning weights $w^c_k$ [S1].
*   Camera parameters for each frame [S1].

**Outputs:**
*   Rendered RGB images for arbitrary viewpoints and poses [S1].

**Data Structures:**
*   **Multiresolution Hash Encoding (MHE):** $\psi_{hash}$ maps 3D coordinates to feature vectors. For multi-subject, a global MHE $\psi_{hash}^G$ and $N_s$ local MHEs $\{\psi_{hash}^i\}$ are used [S1].
*   **MLP Decoders:**
    *   $\mathbf{M}_{rigid}$: Predicts rigid color $\mathbf{c}$ and density $\sigma$.
    *   $\mathbf{M}_{nr}$: Predicts non-rigid residuals $\Delta \mathbf{c}$ and $\Delta \sigma$.
*   **Learnable Base Code:** $\mathbf{S} \in \mathbb{R}^{64}$, randomly initialized [S1].
*   **Projection Matrices:** $\mathbf{W}_p, \mathbf{W}_Q, \mathbf{W}_K, \mathbf{W}_V$ for pose-embedded feature generation [S1].

**Numbered Steps:**

1.  **Canonical Transformation:** Transform an observation point $\mathbf{x}$ to a canonical point $\mathbf{x}_c$ using inverse linear blend skinning [S1]:
    $$ \mathbf{x}_c = \sum_{k=1}^K w^o_k (R_k \mathbf{x} + \mathbf{t}_k) $$
    where the observation skinning weights $w^o_k$ are computed as:
    $$ w^o_k = \frac{w^c_k(R_k \mathbf{x} + \mathbf{t}_k)}{\sum_{j=1}^K w^c_j(R_j \mathbf{x} + \mathbf{t}_j)} $$
    Here, $K$ is the total number of joints, and $w^c_k$ are the canonical skinning weights optimized explicitly [S1].

2.  **Rigid Branch Feature Query:** Query multiresolution volumetric features $\mathbf{f}_{\mathbf{x}_c}$ from the MHE $\psi_{hash}$ (or $\psi_{hash}^G$ and $\psi_{hash}^i$ in multi-subject mode) [S1]:
    $$ \mathbf{f}_{\mathbf{x}_c} = \psi_{hash}(\mathbf{x}_c) $$

3.  **Rigid Branch Prediction:** Slice the first half ($H$ dimensions) of $\mathbf{f}_{\mathbf{x}_c}$ at each resolution level to compute $\mathbf{f}^{:H}_{\mathbf{x}_c}$. Predict rigid color $\mathbf{c}$ and density $\sigma$ using $\mathbf{M}_{rigid}$ [S1]:
    $$ \mathbf{c}, \sigma = \mathbf{M}_{rigid}(\mathbf{f}^{:H}_{\mathbf{x}_c}) $$
    In multi-subject mode, concatenate global features, sliced local features, and subject ID code $\mathbf{S}_i$:
    $$ \mathbf{c}, \sigma = \mathbf{M}_{rigid}(\psi_{hash}^G(\mathbf{x}_c) \oplus (\psi_{hash}^i(\mathbf{x}_c))^{:H} \oplus \mathbf{S}_i) $$

4.  **Non-Rigid Branch Feature Preparation:** Use the full feature $\mathbf{f}_{\mathbf{x}_c}$. Freeze the first half representing canonical radiance. Denote the remaining optimized half as $\mathbf{f}^*_{\mathbf{x}_c}$ [S1].

5.  **Pose-Embedded Implicit Feature Generation:**
    a. Initialize learnable base code $\mathbf{S} \in \mathbb{R}^{64}$ [S1].
    b. Apply sinusoidal positional encoding $\gamma$ to 23 joint positions $\mathbf{J} = \{j_i\}_{i=1}^{23}$:
        $$ \gamma(j_i) = [j_i, \sin(2^0 \pi j_i), \cos(2^0 \pi j_i), \dots, \sin(2^{L-1} \pi j_i), \cos(2^{L-1} \pi j_i)] $$
        where $L=10$ frequency bands [S1].
    c. Project encoded joints $\gamma(\mathbf{J}) \in \mathbb{R}^{23 \times 63}$ to raw pose-embedded code $\mathbf{P}_{raw}$ using projection matrix $\mathbf{W}_p$:
        $$ \mathbf{P}_{raw} = \mathbf{W}_p \cdot \gamma(\mathbf{J}) $$
    d. Generate query $\mathbf{P}_q$ from $\mathbf{S}$, and key $\mathbf{P}_k$, value $\mathbf{P}_v$ from $\mathbf{P}_{raw}$ via linear projections:
        $$ \mathbf{P}_q = \mathbf{W}_Q \cdot \mathbf{S}, \quad \mathbf{P}_k = \mathbf{W}_K \cdot \mathbf{P}_{raw}, \quad \mathbf{P}_v = \mathbf{W}_V \cdot \mathbf{P}_{raw} $$
    e. Compute final implicit feature $\mathbf{P}_{nr}$ using cross-attention:
        $$ \mathbf{P}_{nr} = \text{softmax}(\mathbf{P}_q \cdot \mathbf{P}_k^\top) \cdot \mathbf{P}_v $$

6.  **Non-Rigid Branch Prediction:** Predict color and density residuals $\Delta \mathbf{c}, \Delta \sigma$ using MLP decoder $\mathbf{M}_{nr}$ conditioned on $\mathbf{f}^*_{\mathbf{x}_c}$ and $\mathbf{P}_{nr}$:
    $$ \Delta \mathbf{c}, \Delta \sigma = \mathbf{M}_{nr}(\mathbf{f}^*_{\mathbf{x}_c}; \mathbf{P}_{nr}) $$

7.  **Compositional Rendering:** For each ray $\mathbf{r}$, query $M$ samples. Compute final RGB $\mathbf{C}_{final}$ using stratified sampling and volume rendering with compositional density $(\sigma + \Delta \sigma)$ and color $(\mathbf{c} + \Delta \mathbf{c})$ [S1]:
    $$ \mathbf{C}_{final}(\mathbf{r}) = \sum_{m=1}^M T_m (1 - \exp(-(\sigma_m + \Delta \sigma_m)\delta_m)) (\mathbf{c}_m + \Delta \mathbf{c}_m) $$
    where transmittance $T_m = \exp(-\sum_{n=1}^{m-1} \sigma_n \delta_n)$ and $\delta_m$ is the adjacent distance from the $m$-th to the $m+1$-th sample [S1].

8.  **Optimization:**
    a. Sample $N_p$ patches per iteration. Render patches from $\mathbf{C}_{rigid}$ (using only rigid branch outputs) and $\mathbf{C}_{final}$ [S1].
    b. Compute LPIPS loss using pre-trained VGGNet against ground truth patch $\mathbf{P}_{GT}$:
        $$ \mathcal{L}_{\text{LPIPS}} = \text{LPIPS}(\text{VGG}(\hat{\mathbf{P}}), \text{VGG}(\mathbf{P}_{GT})) $$
    c. Compute MSE loss terms $\mathcal{L}^r_{\text{MSE}}$ and $\mathcal{L}^f_{\text{MSE}}$ for rigid and final rendered patches respectively [S1].
    d. Compute SSIM loss $\mathcal{L}^f_{\text{SSIM}}$ only for final RGB patches [S1].
    e. Compute total loss $\mathcal{L}^o$ with hyperparameter $\lambda = 0.2$:
        $$ \mathcal{L}^o = \lambda \mathcal{L}^r + (1-\lambda) \mathcal{L}^f $$
        where $\mathcal{L}^r = \mathcal{L}^r_{\text{LPIPS}} + \mathcal{L}^r_{\text{MSE}}$ and $\mathcal{L}^f = \mathcal{L}^f_{\text{LPIPS}} + \mathcal{L}^f_{\text{MSE}} + \mathcal{L}^f_{\text{SSIM}}$ [S1].

**Parameters:**
*   $L=10$: Number of frequency bands in sinusoidal positional encoding [S1].
*   $\lambda=0.2$: Hyperparameter for balancing rigid and final loss terms [S1].
*   $K$: Total number of joints in the skeletal model [S1].
*   $N_s$: Number of subjects in multi-subject training [S1].

**Edge Cases and Pitfalls:**
*   Spatial offset strategies suffer from high computational complexity because a single spatial offset spans an unbounded range and is unique for every 3D point across all input frames and body poses [S1].
*   Spatial offset strategies suffer from misaligned learning objectives because the learning objective of spatial offsets is not directly aligned with conventional RGB-based supervision [S1].
*   MoCo-NeRF avoids these by modeling non-rigid motions as radiance residuals, reducing the prediction range to the radiance space with the rigid radiance field as a prior [S1].

## Operating characteristics
*   **Time Complexity:** Training time for 6 subjects on the ZJU-MoCap dataset is 2 hours on one RTX 3090 GPU [S1].
*   **Memory Complexity:** Uses a single multiresolution hash encoding (MHE) to concurrently learn the canonical T-pose representation and the radiance residual field [S1].
*   **Strengths:** Circumvents complexities associated with learning unbounded spatial offsets; establishes more direct supervision from ground-truth pixel colors; enhances learning efficiency; supports unified training across multiple subjects without significant increase in training time [S1].
*   **Limitations:** Requires skeletal pose data for inverse linear blend skinning [S1].
*   **When to use:** Free-viewpoint rendering of dynamic human subjects in monocular videos, particularly when non-rigid motions (e.g., cloth dynamics) are significant [S1].
*   **When not to use:** Static scenes or scenes where non-rigid motion is negligible and simpler static NeRF variants suffice.

## Background
MoCo-NeRF was proposed by J. Kim et al. in 2024 [S1]. It addresses the challenges of novel view synthesis of monocular human video, which involves complex articulated body motions and non-skeletal non-rigid motions (e.g., wrinkles) [S1]. The method builds on the concept of Neural Radiance Fields (NeRF) [42] and linear blend skinning [32], extending them to model non-rigid motions as radiance residual fields rather than spatial offsets [S1]. It is evaluated on the ZJU-MoCap and MonoCap datasets [S1].
