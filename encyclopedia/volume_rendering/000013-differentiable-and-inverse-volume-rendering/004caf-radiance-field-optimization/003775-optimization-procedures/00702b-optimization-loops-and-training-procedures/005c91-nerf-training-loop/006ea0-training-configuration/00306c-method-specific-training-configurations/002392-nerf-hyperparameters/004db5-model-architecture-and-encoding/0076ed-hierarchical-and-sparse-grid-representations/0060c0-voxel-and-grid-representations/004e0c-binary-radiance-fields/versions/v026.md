# Binary Radiance Fields

Also called: BRF

## Overview
Binary Radiance Fields (BiRF) is a storage-efficient radiance field representation that reduces model size by binarizing feature embedding parameters to $\{-1, +1\}$ using a sign function and backpropagating through a straight-through estimator [S1, S2]. Unlike post-processing compression methods such as PlenOctrees or Re:NeRF, which require additional optimization steps and are bounded by pre-trained model performance, BiRF performs binarization during training without post-optimization [S2]. It employs a 2D-3D hybrid multi-resolution architecture to maintain reconstruction quality while achieving significantly lower storage overhead compared to real-valued floating-point grids [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of calibrated images with known camera poses; a 3D coordinate $\mathbf{x} = (x, y, z)$ and viewing direction $\mathbf{d} = (\theta, \phi)$ for ray sampling.
*   **Outputs:** Volume density $\sigma$ and color $\mathbf{c} = (r, g, b)$ for volumetric rendering.

**Data Structures:**
The radiance field consists of a multi-resolution 2D-3D hybrid feature grid implemented using hash encoding [S2]. All grid parameters are constrained to binary values $\{-1, +1\]$.
1.  **3D Voxel Grid ($\Phi_{\theta_{xyz}}$):** Contains $L$ resolution levels. Resolutions range from 16 to 1024. Each level contains up to $T_{3D}$ feature vectors.
2.  **2D Plane Grids ($\Phi_{\theta_{xy}}, \Phi_{\theta_{xz}}, \Phi_{\theta_{yz}}$):** Three orthogonal planes. Each contains $M$ resolution levels. Resolutions range from 64 to 512. Each level contains up to $T_{2D}$ feature vectors.
3.  **MLPs:**
    *   **Density MLP:** Shallow network with one hidden layer (128 channels, ReLU).
    *   **Color MLP:** Shallow network with two hidden layers (128 channels, ReLU).
    *   **Directional Encoding:** Spherical harmonics basis functions are used to encode $\mathbf{d}$ [S2].

**Parameters:**
*   $L$: Number of 3D grid levels.
*   $M$: Number of 2D grid levels.
*   $T_{3D}$: Max feature vectors per 3D level.
*   $T_{2D}$: Max feature vectors per 2D level.
*   $F$: Feature dimension per level. Variants use $F \in \{2, 4, 8\}$ [S2].
*   $\lambda_{\text{sparsity}}$: Sparsity loss weight. Value: $2.0 \times 10^{-5}$ [S2].
*   Model Variants:
    *   **Ours-S (Small):** $\log_2(T_{3D}) = 17$, $\log_2(T_{2D}) = 15$ [S2].
    *   **Ours-B (Base):** $\log_2(T_{3D}) = 19$, $\log_2(T_{2D}) = 17$ [S2].
*   Storage: Ours-S2 requires $< 0.5$ MB for Synthetic-NeRF scenes [S2].

**Numbered Steps:**

1.  **Binarization of Grid Parameters:**
    During training, real-valued grid parameters $\theta$ are maintained. To obtain binary parameters $\theta'$, apply the sign function:
    $$
    \theta' = \text{sign}(\theta) = \begin{cases} +1 & \text{if } \theta \ge 0 \\ -1 & \text{otherwise} \end{cases}
    $$
    Gradients are backpropagated using the Straight-Through Estimator (STE). The gradient flow is defined as:
    $$
    \frac{\partial L}{\partial \theta} = \frac{\partial L}{\partial \theta'} \cdot \mathbb{I}(|\theta| \le 1)
    $$
    where $\mathbb{I}$ is the indicator function. This stops gradient propagation when $|\theta| > 1$, constraining values to $\{-1, 1\}$ and preventing scale divergence [S2].

2.  **Binary Feature Encoding (3D):**
    For an input 3D coordinate $\mathbf{x}$, compute features from the 3D grid by linearly interpolating the binary parameters across $L$ resolution levels and concatenating them:
    $$
    \mathbf{f}_{xyz} = \left\{ \text{interp}(\mathbf{x}, \text{sign}(\Phi^l_{\theta_{xyz}})) \right\}_{l=1}^L
    $$
    where $\text{interp}$ denotes tri-linear interpolation [S2].

3.  **Binary Feature Encoding (2D):**
    Project $\mathbf{x}$ onto the three orthogonal planes: $\mathbf{x}_{xy} = (x, y)$, $\mathbf{x}_{xz} = (x, z)$, $\mathbf{x}_{yz} = (y, z)$. For each plane, interpolate binary parameters across $M$ resolution levels and concatenate:
    $$
    \mathbf{f}_{xy} = \left\{ \text{interp}(\mathbf{x}_{xy}, \text{sign}(\Phi^m_{\theta_{xy}})) \right\}_{m=1}^M
    $$
    Repeat for $\mathbf{f}_{xz}$ and $\mathbf{f}_{yz}$ using bi-linear interpolation [S2].

4.  **Feature Concatenation:**
    Combine all encoded features:
    $$
    \mathbf{f} = \{ \mathbf{f}_{xyz}, \mathbf{f}_{xy}, \mathbf{f}_{xz}, \mathbf{f}_{yz} \}
    $$

5.  **Positional Encoding:**
    Apply sinusoidal positional encoding $\gamma(\mathbf{x})$ to the input coordinate $\mathbf{x}$ [S2].

6.  **Density Prediction:**
    Feed $\gamma(\mathbf{x})$ and $\mathbf{f}$ into the density MLP:
    $$
    (\sigma, \mathbf{e}) = \text{MLP}_{\text{density}}(\gamma(\mathbf{x}), \mathbf{f})
    $$
    where $\sigma$ is volume density and $\mathbf{e}$ is the embedded feature vector [S2].

7.  **Color Prediction:**
    Feed $\mathbf{e}$ and directional encoding $\mathbf{d}$ into the color MLP:
    $$
    \mathbf{c} = \text{MLP}_{\text{color}}(\mathbf{e}, \mathbf{d})
    $$

8.  **Volumetric Rendering:**
    Render the pixel color $\hat{C}(\mathbf{r})$ along ray $\mathbf{r}$ using standard differentiable volume rendering with density $\sigma$ and color $\mathbf{c}$ [S2].

9.  **Loss Computation:**
    Compute reconstruction loss $L_{\text{recon}}$ and sparsity loss $L_{\text{sparsity}}$:
    $$
    L_{\text{recon}} = \sum_{\mathbf{r} \in \mathcal{R}} \| \hat{C}(\mathbf{r}) - C(\mathbf{r}) \|_2^2
    $$
    $$
    L_{\text{sparsity}} = \sum_{i,k} \log(1 + 2\sigma(\mathbf{r}_i(t_k))^2)
    $$
    where $\mathbf{r}_i(t_k)$ is the $k$-th sample point on ray $i$. The total loss is:
    $$
    L = L_{\text{recon}} + \lambda_{\text{sparsity}} L_{\text{sparsity}}
    $$
    [S2].

            nn.Linear(128, 128),

        f_xy = self.get_binary_features_2d(x, [g[0] for g in self.grid_2d])

        # Standard NeRF positional encoding
        gamma_x = positional_encoding(x, num_levels=10)

        density_out = self.mlp_density(density_input)
        sigma = density_out[:, 0:1]

        # 6. Color Prediction
        # Spherical Harmonics encoding for direction
        d_sh = spherical_harmonics_encoding(d, degree=3)
        color_input = torch.cat([e, d_sh], dim=-1)
        c = self.mlp_color(color_input)

    def compute_loss(self, sigma_samples, gt_color, rendered_color):
        """
        Compute total loss.
        sigma_samples: (N, 1) density values at sample points.
        gt_color: (N, 3) ground truth colors.
        rendered_color: (N, 3) rendered colors.
        """
        L_recon = F.mse_loss(rendered_color, gt_color)
        
        # Sparsity Loss: Cauchy loss
        # L_sparsity = sum(log(1 + 2 * sigma^2))
        L_sparsity = torch.sum(torch.log(1 + 2 * sigma_samples**2))
        
        L_total = L_recon + self.lambda_sparsity * L_sparsity
        return L_total

def positional_encoding(x, num_levels=10):
    """Standard NeRF positional encoding."""
    scales = 2.0 ** torch.arange(num_levels, device=x.device)
    scaled_x = x.unsqueeze(-1) * scales
    x_enc = torch.cat([torch.sin(scaled_x), torch.cos(scaled_x)], dim=-1)
    return x_enc.view(x.shape[0], -1)

def spherical_harmonics_encoding(d, degree=3):
    """Simplified SH encoding for degree 3."""
    # d is (N, 2) -> (theta, phi)
    # Convert to Cartesian for SH basis
    x = torch.sin(d[:, 1]) * torch.cos(d[:, 0])
    y = torch.sin(d[:, 1]) * torch.sin(d[:, 0])
    z = torch.cos(d[:, 1])
    
    # Degree 0
    c0 = 0.282095
    # Degree 1
    c1 = 0.488603
    c2 = 1.092548
    c3 = 0.315392
    c4 = 0.546274
    
    sh = torch.zeros(d.shape[0], 9, device=d.device)
    sh[:, 0] = c0
    sh[:, 1] = c1 * y
    sh[:, 2] = c1 * z
    sh[:, 3] = c1 * x
    sh[:, 4] = c2 * x * y
    sh[:, 5] = c2 * y * z
    sh[:, 6] = c3 * (3 * z**2 - 1)
    sh[:, 7] = c2 * x * z
    sh[:, 8] = c4 * (x**2 - y**2)
    return sh

## Operating characteristics
*   **Time Complexity:** Training time is comparable to Instant-NGP. For Synthetic-NeRF scenes, training takes approximately 6, 9, and 14 minutes for Ours-B2, Ours-B4, and Ours-B8 models respectively, on a single NVIDIA RTX A6000 [S2].
*   **Memory Complexity:** Storage size is drastically reduced. Ours-S2 requires $< 0.5$ MB, compared to 3.7 MB for TensoRF-CP and 24.5 MB for Instant-NGP on the mic scene [S2].
*   **Performance:** Achieves PSNR of 32.03 dB on Synthetic-NeRF, 34.48 dB on Synthetic-NSVF, and 28.20 dB on Tanks and Temples with 0.5 MB storage [S2].
*   **Strengths:** Storage efficiency; no post-optimization required; competitive reconstruction quality.
*   **Limitations:** Hash collisions in 3D grids at high resolutions; potential gradient vanishing due to sign function (mitigated by STE); scale divergence if gradients are not constrained (mitigated by STE threshold) [S2].
*   **When to use:** When storage size is a critical constraint and real-time or efficient training is desired.
*   **When not to use:** When maximum possible reconstruction quality is required regardless of storage size, or when post-processing compression is acceptable.

## Background
Binary Radiance Fields (BiRF) was proposed by Seungjoo Shin and Jaesik Park in 2023 [S2]. The method builds on the multi-resolution hash encoding architecture of Instant-NGP [20] and uses the occupancy grid from NerfAcc [42] for efficient ray sampling [S2]. It addresses the storage burden of implicit feature embeddings by introducing binarization during training [S1].
