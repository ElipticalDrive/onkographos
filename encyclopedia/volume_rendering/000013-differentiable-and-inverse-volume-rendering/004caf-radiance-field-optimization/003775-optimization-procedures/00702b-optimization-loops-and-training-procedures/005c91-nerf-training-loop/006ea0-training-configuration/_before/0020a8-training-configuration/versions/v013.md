# Training Configuration

Also called: ECNR Training Configuration, ExBluRF Training Configuration, Hyperparameter Configuration, Optimization Configuration, Optimizer Settings, Training Details, Training Hyperparameters

## Overview
Training Configuration defines the hyperparameters, optimization schedules, and architectural constraints required to stabilize convergence and maximize reconstruction quality in neural radiance field (NeRF) optimization. It solves the problem of disparate convergence speeds among geometric, appearance, and latent parameters by specifying learning rates, batch sizes, sampling strategies, and regularization strengths. Unlike [Scene Representation and Architecture](11368-scene-representation-and-architecture.md), which defines the model structure, or [Regularization and Loss Functions](8586-regularization-and-loss-functions.md), which defines the objective, Training Configuration controls the *process* of optimization, including learning rate scheduling, mixed precision, and view sampling strategies.

## How it works
The training configuration orchestrates the optimization loop by defining the optimizer state, data sampling parameters, and iterative updates. It typically involves initializing an optimizer (e.g., Adam) with specific hyperparameters, setting up a learning rate scheduler, and configuring the batch composition (e.g., rays per iteration).

### Inputs and Outputs
*   **Inputs:** Model parameters (weights, grids, latent codes), training images, camera poses, and configuration hyperparameters (learning rates, batch sizes, iteration counts).
*   **Outputs:** Updated model parameters, training metrics (loss, PSNR), and optionally checkpoints.

### Data Structures
*   **Optimizer State:** Maintains per-parameter moment estimates (mean $m$, variance $v$) for Adam.
*   **Scheduler State:** Tracks current iteration $t$ and total iterations $T$ for dynamic adjustments.
*   **Batch:** A collection of rays or pixels sampled from training images.

### Numbered Steps
1.  **Initialization:** Initialize model parameters. Initialize optimizer with base learning rates (e.g., $lr_0$ for embeddings, $lr_1$ for networks) and betas (e.g., $\beta_1=0.9, \beta_2=0.99$) [S6][S14, unofficial]. Initialize learning rate scheduler (e.g., LambdaLR) [S14, unofficial].
2.  **Sampling:** Sample a batch of rays or pixels. Common strategies include:
    *   Random pixel sampling from all training images [S6].
    *   Hierarchical sampling with coarse and fine stages [S2].
    *   Point distribution split (e.g., 2:2:1 surface, near, uniform) [S1].
3.  **Forward Pass:** Render the batch using the current model state. This may involve ray marching [2199-training-ray-marching-and-integration.md] and feature extraction [11368-scene-representation-and-architecture.md].
4.  **Loss Computation:** Calculate the loss function (e.g., L2, SSIM, perceptual) [S5]. Apply regularization terms if configured [8586-regularization-and-loss-functions.md].
5.  **Backward Pass:** Compute gradients. If using mixed precision [2766-mixed-precision-training.md], scale gradients to prevent underflow.
6.  **Update:** Update model parameters using the optimizer. Apply learning rate decay based on the scheduler [S14, unofficial].
7.  **Iteration:** Repeat until convergence or max iterations reached. Apply periodic actions like densification/pruning [S5], upsampling [S13], or pruning [S12].

### Formulas
*   **Adam Update:**
    $$ \theta_{t+1} = \theta_t - \frac{\eta \cdot \hat{m}_t}{\sqrt{\hat{v}_t} + \epsilon} $$
    where $\eta$ is the learning rate, $\hat{m}_t$ and $\hat{v}_t$ are bias-corrected moment estimates [S6].
*   **Dynamic Frequency Masking (FreeNeRF):**
    $$ \alpha_i(t, T, L) = \begin{cases} 1 & \text{if } i \le \lfloor \frac{t \cdot L}{T} \rfloor \\ \frac{t \cdot L}{T} - \lfloor \frac{t \cdot L}{T} \rfloor & \text{if } \lfloor \frac{t \cdot L}{T} \rfloor < i \le \lfloor \frac{t \cdot L}{T} \rfloor + 3 \\ 0 & \text{otherwise} \end{cases} $$
    for $t < T$; returns 1 if $t \ge T$ [S15, unofficial].
*   **Learning Rate Decay (LambdaLR):**
    $$ \eta_t = \eta_0 \cdot 0.1^{\min(t/T, 1)} $$
    [S14, unofficial].

### Parameters and Typical Values
*   **Optimizer:** Adam [S1, S6][S14, unofficial].
    *   $\beta_1 = 0.9, \beta_2 = 0.99, \epsilon = 10^{-15}$ [S6][S14, unofficial].
    *   Learning Rate: $10^{-3}$ to $10^{-2}$ for grids/MLPs [S2, S6][S14, unofficial].
    *   Weight Decay: $0.1$ for hash grids [S6], $2 \times 10^{-5}$ for MLPs [S12].
*   **Batch Size:**
    *   Rays: 8,192 [S2, S11], 4,096 [S10][S14, unofficial], 25,000 [S13].
    *   Pixels: $2^{16}$ [S6].
*   **Iterations:**
    *   Standard: 20,000–30,000 [S3, S5, S9][S14, unofficial].
    *   High-res/Complex: 200,000 [S8, S13].
    *   Progressive: Coarse 10k, Fine 20k [S2].
*   **Learning Rate Scheduling:**
    *   Warm-up: First 100 iterations, $10^{-4}$ to $10^{-2}$ [S6].
    *   Decay: Exponential [S2, S6], LambdaLR [S14, unofficial], Logarithmic [S3].
*   **Sampling:**
    *   Step size: Half voxel size $\delta = 0.5s$ [S2].
    *   Shift: Random shift $p \cdot \delta \cdot d/\|d\|_2$ with $p \sim U[0,1]$ [S2].

### Edge Cases and Pitfalls
*   **Gradient Underflow:** In mixed precision, use dynamic loss scaling [2766-mixed-precision-training.md].
*   **Overfitting:** Use regularization (weight decay, dropout) and early stopping [S6, S12].
*   **Disparate Convergence:** Use different learning rates for different parameter types (e.g., geometry vs. color) [S8, S3093-adam-optimisation-with-adaptive-scaling.md].
*   **Boundary Artifacts:** Apply boundary mitigation CNNs or specific pruning thresholds [S12].

### Pseudocode
```python
# Initialization
optimizer = Adam(model.parameters(), lr=lr0, betas=(0.9, 0.99), eps=1e-15)
scheduler = LambdaLR(optimizer, lambda iter: 0.1 ** min(iter / max_iters, 1))
# Optional: Warmup scheduler for first 100 iters

for iteration in range(max_iters):
    # 1. Sampling
    rays = sample_rays(batch_size, training_images, camera_poses)
    
    # 2. Forward Pass
    rendered_colors, alphas = render(rays, model)
    gt_colors = get_gt_pixels(rays, training_images)
    
    # 3. Loss Computation
    loss = L2_loss(rendered_colors, gt_colors)
    loss += 0.2 * SSIM_loss(rendered_colors, gt_colors) # Example weights [S5]
    loss += weight_decay * hash_grid_values # Example regularization [S6]
    
    # 4. Backward Pass
    optimizer.zero_grad()
    loss.backward()
    
    # 5. Update
    optimizer.step()
    scheduler.step()
    
    # 6. Periodic Actions
    if iteration % 300 == 0:
        densify_and_prune(model, rays) # Example [S5]
    if iteration in upsample_steps:
        upsample_voxel_grids(model) # Example [S13]
```

## Subtopics

### [Training Loop Setup](1522-training-loop-setup.md)
Defines the execution of a single optimization iteration, including data loading, forward rendering, loss computation, and parameter updates. It also covers initialization of the training environment (random seed, log directory, checkpoint reloading).

### [Learning Rate Scheduling](2701-learning-rate-scheduling.md)
Adjusts the optimizer's step size during training to balance convergence speed and stability. It prevents overshooting and manages the trade-off between rapid geometric alignment and precise detail refinement. It specifically controls the magnitude of parameter updates, unlike [Training Schedule](3154-training-schedule.md) which modifies loss sets [G].

### [Randomized Background Colors](2736-randomized-background-colors.md)
Replaces the fixed background color with a random sample from a uniform distribution during compositing. This solves semi-transparent background artifacts and "stuck" primitives by forcing the model to explicitly model background geometry rather than relying on a known constant.

### [Mixed Precision Training](2766-mixed-precision-training.md)
Accelerates optimization on CUDA hardware by using FP16 for forward/backward passes and FP32 for weight updates. It reduces memory bandwidth and increases throughput on Tensor Cores. It uses dynamic loss scaling to prevent gradient underflow.

### [Adam Optimisation with Adaptive Scaling](3093-adam-optimisation-with-adaptive-scaling.md)
Applies component-specific learning rate multipliers to the Adam optimizer to address disparate convergence speeds of geometric, shape, and amplitude parameters. It scales base learning rates based on dimensionality and applies fixed multipliers to positions and amplitudes.

### [Checkpoint Loading and Resume Training](3118-checkpoint-loading-and-resume-training.md)
Enables restoration of the optimization state from disk to continue training or evaluate without restarting. It handles state persistence and recovery, distinct from initial setup.

### [View Sampler](3864-view-sampler.md)
Abstract base class for selecting context and target camera views during training/inference. It manages the spatial and temporal selection of input geometry (cameras) for gradient computation.

### [Training Objective for Fine Representation](4686-training-objective-for-fine-representation.md)
Defines the loss function for optimizing the high-resolution radiance field after the coarse stage. It reduces regularization weights to prevent blurring of fine structures.

### [Method-Specific Training Configurations](6267-method-specific-training-configurations.md)
Defines hyperparameters for specific NeRF variants (e.g., Mip-NeRF’s IPE, DONeRF’s dual-network) to address challenges like anti-aliasing or efficiency.

### [Regularization and Priors](6281-regularization-and-priors.md)
Applies constraints to enforce physical plausibility and stability. It modifies the loss landscape via penalty terms, distinct from optimizer state adjustments.

### [PixelNeRF](7471-pixelnerf.md)
Conditions a NeRF renderer on image features extracted via a pretrained CNN for sparse-view synthesis. It differs from vanilla NeRF by operating in view-space with direct ray-to-pixel feature extraction.

### [Warm-start Encoding](8751-warm-start-encoding.md)
Initializes network weights for each frame with converged weights from the previous frame to reduce flickering and encoding time in animated sparse volumes.

### [Attenuation Field](9639-attenuation-field.md)
Maps 3D coordinates to attenuation coefficients $\mu$ modeling X-ray beam decay, adhering to the Beer–Lambert Law, differing from natural-image NeRFs.

### [Surface Smoothness Regularization](12970-surface-smoothness-regularization.md)
Imposes geometric constraints on rendered depth from unobserved rays to stabilize joint optimization of blur kernels and radiance fields in sparse-view DeRF.

### [Training Setup and Baselines](13740-training-setup-and-baselines.md)
Defines hyperparameter configurations and baseline protocols to stabilize convergence across diverse architectures, focusing on configuration rather than architecture or loss functions.

### [Perceptual Distillation Module](13792-perceptual-distillation-module.md)
Uses pre-deblurred images as a perceptual prior to transfer texture information to implicit clean radiance fields, enforcing feature-level consistency.

### [Anchor-Based RPN Configuration](13809-anchor-based-rpn-configuration.md)
Configures the Region Proposal Network (RPN) for object detection in NeRFs by defining 3D bounding box anchors and sampling strategies.

#### Dynamic Frequency Masking
A technique to mask tensor components (density or appearance feature) based on training iteration to enhance high-frequency details in later stages and mitigate overfitting. It calculates mask values using integer and fractional parts for smooth transition during training ($t < T$) and returns ones after training ($t \ge T$) [S15, unofficial].

#### NeRF-RPN Training Augmentation and Optimization
Applies random flips (x, y axes, prob 0.5), random z-axis rotations ($\pi/2$, prob 0.5), and slight z-axis rotations ($\alpha \in [-\pi/18, \pi/18]$, prob 0.5). Uses AdamW with lr=0.0003, weight decay=0.001, and loss weights $\lambda=5.0$ and $\lambda=1.0$ [S16].

#### Batch Size Configuration for Past Rays
Evaluates performance across ratios of $m_p$ (past task rays) to $m_c$ (current task rays). $m_p = m_c/2$ is chosen as the optimal trade-off between performance and efficiency, yielding PSNR 22.14 / MS-SSIM 0.836 on Tanks and Temples/Barn with $m_c=4096$ [S17].

#### Particle Removal and Re-sampling
Alternately removes and re-samples particles to manage count and convergence. The count of re-sampled particles gradually decreases to zero as the model converges (e.g., after 10K steps on D-NeRF) [S18].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of training iterations and batch size. Convergence speed varies by method (e.g., 15 minutes for Direct Voxel Grid [S2] vs. hours for complex dynamic scenes [S12]).
*   **Memory Complexity:** Proportional to the number of model parameters and batch size. Mixed precision [2766-mixed-precision-training.md] reduces memory bandwidth requirements.
*   **Performance:** Measured in PSNR, SSIM, and LPIPS. High-resolution training (e.g., 200k iterations) yields higher quality but requires more time [S8, S13].
*   **Strengths:** Flexible configuration allows tuning for specific datasets (static, dynamic, sparse-view).
*   **Limitations:** Hyperparameter sensitivity; poor configuration can lead to divergence or overfitting.
*   **When to Use:** Standard for all NeRF training. Specific configurations (e.g., Dynamic Frequency Masking) for few-shot or high-frequency detail enhancement [S15, unofficial].

## Background
Training configuration has evolved from the original NeRF paper [37] which used a simple Adam optimizer with a fixed learning rate. Subsequent works introduced adaptive learning rates [S2], mixed precision [S1], and method-specific configurations for dynamic scenes [S12], sparse views [S15, unofficial], and object detection [S16]. The field has moved towards more sophisticated scheduling and regularization to handle complex scenes and limited data.
