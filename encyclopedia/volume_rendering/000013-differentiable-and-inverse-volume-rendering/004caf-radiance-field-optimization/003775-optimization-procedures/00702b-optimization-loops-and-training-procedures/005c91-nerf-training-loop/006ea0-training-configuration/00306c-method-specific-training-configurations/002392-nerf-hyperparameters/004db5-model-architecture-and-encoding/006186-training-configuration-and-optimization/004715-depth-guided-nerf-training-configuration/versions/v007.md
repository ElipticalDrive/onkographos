# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the training protocol for Neural Radiance Fields (NeRF) that incorporate depth supervision to improve geometry reconstruction. It addresses the ambiguity in density estimation by integrating ground-truth depth priors into the optimization loop. It differs from standard NeRF training by introducing specific architectural regularization (dropout) and a weighted depth loss term, distinguishing it from sibling methods like [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md) which use semantic constraints, or [Binary Radiance Fields](13622-binary-radiance-fields.md) which constrain parameters to binary values.

## How it works
The method modifies the standard NeRF optimization loop by adding dropout regularization to the feature encoding network and a weighted depth consistency loss.

**Inputs:**
*   Camera poses and intrinsics.
*   RGB images.
*   Ground-truth depth maps (optional, per scene).
*   Scene-specific depth scale parameters.

**Outputs:**
*   Optimized NeRF model parameters (MLP weights, hash grid/tensor parameters).
*   Rendered RGB images and depth maps.

**Data Structures:**
*   **NeRF Model:** Follows the architecture defined in [Model Architecture and Encoding](13550-model-architecture-and-encoding.md).
*   **Depth Scale:** A learnable scalar parameter per scene, initialized to 1.0, used to align predicted depth with ground-trunit depth units.

**Parameters:**
*   **Depth Loss Weight ($\lambda$):** 0.007 for most scenes; 0.02 for scene 710 [S1].
*   **Uncertainty Weight ($\gamma$):** 1.0 [S1].
*   **Dropout Probability:** 0.1 [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate (Base):** $5 \times 10^{-4}$ [S1].
*   **Learning Rate (Depth Scale):** $1 \times 10^{-7}$ [S1].
*   **Weight Decay:** $1 \times 10^{-6}$ [S1].
*   **Total Steps:** 500,000 [S1].
*   **LR Schedule:** Reduce base learning rate to $5 \times 10^{-5}$ after 80% of total steps [S1].
*   **Depth Threshold ($\tau$):** Used to evaluate depth uncertainty. Calculated as $\tau = (\text{max\_depth} - \text{min\_depth}) \cdot 0.0001$ [S1]. For ScanNet, $\text{max\_depth}=10$ and $\text{min\_depth}=0.001$ [S1].

**Algorithm:**

1.  **Initialize** the NeRF model parameters $\theta$ and the depth scale parameter $s$ for the current scene.
2.  **For** each training step $t$ from 1 to 500,000:
    a. **Sample Rays:** Randomly sample rays from the training images.
    b. **Forward Pass:**
        i. Encode spatial coordinates $\mathbf{x}$ using positional encoding.
        ii. Pass encoded features through the first eight fully connected ReLU layers of the density network.
        iii. **Apply Dropout:** Apply dropout with probability $p=0.1$ after each of these eight layers [S1].
        iv. Continue through the remaining layers to predict volume density $\sigma$ and color $\mathbf{c}$.
        v. Perform volume rendering to obtain predicted color $\hat{C}$ and predicted depth $\hat{D}$.
    c. **Compute Losses:**
        i. **RGB Loss:** Compute the difference between rendered color $\hat{C}$ and ground-truth color $C_{gt}$ (e.g., MSE).
        ii. **Depth Loss:** Compute the difference between rendered depth $\hat{D}$ and ground-truth depth $D_{gt}$. The depth scale $s$ is applied to align units. The loss weight is $\lambda$ [S1].
        iii. **Total Loss:** $L = L_{rgb} + \lambda L_{depth}$. (Note: Uncertainty weighting $\gamma$ is set to 1, implying standard weighting unless specific uncertainty maps are used as described in the source context [S1]).
    d. **Backward Pass:**
        i. Compute gradients $\nabla_\theta L$ and $\nabla_s L$.
        ii. Update $\theta$ using Adam with learning rate $lr_\theta = 5 \times 10^{-4}$ (or $5 \times 10^{-5}$ if $t > 0.8 \times 500,000$) and weight decay $1 \times 10^{-6}$ [S1].
        iii. Update $s$ using Adam with learning rate $lr_s = 1 \times 10^{-7}$ [S1].
3.  **Return** the trained model parameters $\theta$ and depth scale $s$.

**Edge Cases and Pitfalls:**
*   **Scene 710:** Requires a higher depth loss weight ($\lambda=0.02$) compared to other scenes ($\lambda=0.007$) [S1].
*   **Depth Scale:** The depth scale is a learnable parameter with a very small learning rate ($10^{-7}$) to prevent instability while allowing unit alignment [S1].
*   **Thresholding:** The threshold $\tau$ is used for evaluating depth uncertainty, not necessarily for the loss calculation itself, but defines the validity range for metrics [S1].

## Subtopics

### DS-NeRF Depth Loss Integration
This variant involves integrating the depth loss implementation from the official DS-NeRF codebase into the training pipeline. It requires re-training on specific datasets (LLFF, DTU) using released configuration files, as original publication results for LLFF used different train/test splits and DTU results could not be reproduced due to missing configuration files [S2].

## Operating characteristics
*   **Time Complexity:** Determined by the 500,000 training steps and the cost of ray marching and MLP inference per step [S1].
*   **Memory Complexity:** Standard NeRF memory footprint plus storage for depth maps and the depth scale parameter [S1].
*   **Strengths:** Improves geometric accuracy by leveraging depth priors; dropout prevents overfitting in the density network [S1].
*   **Limitations:** Requires ground-truth depth maps; sensitive to the choice of $\lambda$ and depth scale learning rate [S1].
*   **When to Use:** When high-fidelity geometry is required and depth data is available.
*   **When Not to Use:** When depth data is unavailable or when computational resources are limited for the extended training duration [S1].

## Background
This configuration was introduced in the context of Depth-Guided NeRF training via Earth Mover’s Distance [S1]. It builds upon the original NeRF architecture [S1] and incorporates techniques from DS-NeRF for depth loss integration [S2]. The method was evaluated on datasets such as ScanNet and LLFF [S1, S2].
