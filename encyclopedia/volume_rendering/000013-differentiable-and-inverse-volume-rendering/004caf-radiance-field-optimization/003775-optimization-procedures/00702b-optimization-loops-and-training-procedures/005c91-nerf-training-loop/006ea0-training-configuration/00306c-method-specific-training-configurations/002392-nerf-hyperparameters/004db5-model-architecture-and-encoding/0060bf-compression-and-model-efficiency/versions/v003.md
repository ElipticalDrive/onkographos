# Compression and Model Efficiency
## Overview
This family covers methods that reduce the memory footprint and computational cost of NeRF representations through low-rank tensor approximations, weight decomposition, and pruning [CCNeRF](15008-ccnerf.md), [Low Rank NeRF Approximation with ADMM](18163-low-rank-nerf-approximation-with-admm.md), [S1]. It differs from sibling methods that modify architecture for specific tasks by focusing strictly on compressing the existing radiance field parameters or optimizing them under rank constraints [G].
## Shared principles
Methods in this family reduce model size by approximating dense parameters with low-rank structures or pruning weights [G]. The rendering equation remains standard volume rendering, but the radiance field query is computed via decomposed components or optimized under rank constraints [CCNeRF](15008-ccnerf.md), [Low Rank NeRF Approximation with ADMM](18163-low-rank-nerf-approximation-with-admm.md). [G] This reduces the number of trainable parameters from $O(N^2)$ or $O(N^3)$ to $O(N \cdot r)$ or $O(N \cdot r^2)$, where $r$ is the target rank.
## Subtopics

### [CCNeRF](15008-ccnerf.md)
A hybrid tensor rank decomposition method that models the radiance field only with tensor components, avoiding MLPs in the rendering path to preserve low-rank properties [CCNeRF](15008-ccnerf.md). It supports dynamic model size adjustment via rank truncation and arbitrary composition via rank concatenation [CCNeRF](15008-ccnerf.md). Choose this when you need a purely tensor-based representation that allows for scene composition and dynamic compression without retraining [CCNeRF](15008-ccnerf.md).

### [Low Rank NeRF Approximation with ADMM](18163-low-rank-nerf-approximation-with-admm.md)
This method reduces the model size of a trained NeRF by decomposing fully connected layer weights into a Tensor Train (TT) format [Low Rank NeRF Approximation with ADMM](18163-low-rank-nerf-approximation-with-admm.md). It solves the resulting rank-constrained optimization problem using the Alternating Direction Method of Multipliers (ADMM) to minimize reconstruction error while enforcing low-rank structure [Low Rank NeRF Approximation with ADMM](18163-low-rank-nerf-approximation-with-admm.md). It is distinguished from sibling methods like [CCNeRF](15008-ccnerf.md) by its specific use of ADMM for rank-constrained weight decomposition rather than other compression techniques [Low Rank NeRF Approximation with ADMM](18163-low-rank-nerf-approximation-with-admm.md).

### PackNet with NeRF
A pruning-based continual learning approach applied to NeRF for multiple scenes [S1]. Uses a pruning rate of 0.5 [S1]. Choose this when continual learning across multiple scenes is required with a fixed pruning budget [S1].

## Background
PackNet was adapted to NeRF for continual learning scenarios, demonstrating that pruning can maintain performance across multiple scenes [S1]. The SCARF framework compares this with MEIL-NeRF and CLNeRF, which handle single-scene continual learning [S1].
