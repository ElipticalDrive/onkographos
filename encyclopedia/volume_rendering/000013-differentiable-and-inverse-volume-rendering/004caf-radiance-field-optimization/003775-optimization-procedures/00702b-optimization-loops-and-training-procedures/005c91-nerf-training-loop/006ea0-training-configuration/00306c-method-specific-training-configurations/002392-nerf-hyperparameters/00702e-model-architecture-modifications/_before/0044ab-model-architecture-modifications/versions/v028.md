# Model Architecture Modifications

Also called: NeRF Architecture Variants, Implicit Representation Modifications

## Overview
Model Architecture Modifications extend the standard Neural Radiance Field (NeRF) baseline [Parent](3065-nerf-hyperparameters.md) to address specific constraints such as inference speed, memory footprint, dynamic scene representation, semantic manipulation, or input data limitations. While the standard architecture uses two Multi-Layer Perceptrons (MLPs) for density and color, these modifications generally fall into input expansion, output expansion, or representation substitution [14428-sparse-view-and-few-shot-optimization.md]. They set themselves apart by integrating auxiliary conditioning, replacing continuous MLPs with discrete structures, or adapting the network topology for parallel processing and dynamic features.

## Shared principles
The standard NeRF architecture [Parent](3065-nerf-hyperparameters.md) serves as the baseline for most modifications. It consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ [14428-sparse-view-and-few-shot-optimization.md].

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories [14428-sparse-view-and-few-shot-optimization.md]:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation [14428-sparse-view-and-few-shot-optimization.md].
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs).

## Subtopics

### [DoF-NeRF](9432-dof-nerf.md)
DoF-NeRF is a neural rendering framework that extends the standard Neural Radiance Field (NeRF) architecture to simulate the depth-of-field (DoF) effects of a physical lens, allowing it to operate on and synthesize views with arbitrary focus configurations [9432-dof-nerf.md]. Unlike standard NeRF or methods like RawNeRF and NeRFocus which assume all-in-focus inputs, DoF-NeRF explicitly models the aperture and focus distance, enabling the optimization of a clear, all-in-focus 3D scene representation from shallow DoF inputs [9432-dof-nerf.md]. It achieves this by combining optical models with volume rendering to compute observed colors based on the Circle of Confusion (CoC) diameter [9432-dof-nerf.md]. Choose this method when training on images with shallow depth-of-field and the goal is to recover a sharp, all-in-focus 3D representation.

### [NeRF-VPT](11770-nerf-vpt.md)
NeRF-VPT is a cascading view prompt tuning paradigm for novel view synthesis that progressively enhances image quality by using RGB information from preceding rendering iterations as visual prompts for subsequent stages [11770-nerf-vpt.md]. It solves the problem of limited scene understanding in sparse-view or standard NeRF settings by iteratively refining the network's output, leveraging prior knowledge sampled from the RGB space to guide optimization [11770-nerf-vpt.md]. Unlike methods that rely on external networks or specific data preprocessing, NeRF-VPT uses only the network's internal output as prior knowledge, making it a plug-and-play modification that can be integrated into variants like Mip-NeRF and TensoRF [11770-nerf-vpt.md]. Choose this method when iterative refinement of image quality is required without external priors.

### [Activation Feature Density Approximation](12492-activation-feature-density-approximation.md)
Activation Feature Density Approximation estimates volumetric density $\hat{d}$ directly from intermediate activation features $\mathbf{f}_\ell$ of a coordinate-based MLP, allowing the replacement of expensive coarse network evaluations with a lightweight computation [12492-activation-feature-density-approximation.md]. It differs from sibling methods like [SDF-based Neural Fields](12947-sdf-based-neural-fields.md) by retaining the standard density-based rendering formulation while optimizing the density prediction step itself, rather than changing the underlying geometric representation. Choose this method when inference speed is critical and the coarse network evaluation is a bottleneck.

### [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md)
Signed Distance Function (SDF) representations replace the standard NeRF density field $\sigma(\mathbf{x})$ with a continuous scalar field $s(\mathbf{x})$ representing the distance to the nearest surface, defining geometry via the zero-level set $\{\mathbf{x} \mid s(\mathbf{x}) = 0\}$ [12495-signed-distance-function-sdf-representations.md]. This substitution addresses the geometric inaccuracy and surface holes typical of density-based NeRFs by providing a more explicit and smooth formulation of surfaces [12495-signed-distance-function-sdf-representations.md]. Unlike standard NeRFs that model soft volumetric boundaries, SDF methods leverage the gradient of the distance function for surface normals and often employ truncation or ray-specific constraints to handle multi-object ambiguities [12495-signed-distance-function-sdf-representations.md]. Choose this method when explicit, watertight mesh extraction or accurate surface normals are required.

### [Volume-Augmented NeRF](12973-volume-augmented-nerf.md)
Volume-Augmented NeRF is a neural radiance field variant designed for dynamic scenes, specifically fluid dynamics, where the density and color of sample points change over time due to fluid flow [12973-volume-augmented-nerf.md]. Unlike the standard static NeRF architecture, this method binds an explicit fluid volume value $v_i$ to each sample point, allowing the renderer to learn density and color based on the spatial distribution provided by a differentiable fluid simulator [12973-volume-augmented-nerf.md]. It serves as the rendering component in a joint differentiable framework that bridges a neural Euler simulator and the radiance field [12973-volume-augmented-nerf.md]. Choose this method for simulating and rendering dynamic fluid scenes.

### [Neural-PIL Decomposition Architecture](12975-neural-pil-decomposition-architecture.md)
The Neural-PIL Decomposition Architecture separates the estimation of scene geometry, material properties, and illumination into distinct networks to handle scenes with varying lighting conditions. Unlike standard NeRF which predicts view-dependent color directly, this method predicts density, a BRDF embedding, and an illumination embedding, using a learned pre-integrated lighting network to efficiently render shaded colors [12975-neural-pil-decomposition-architecture.md]. It is chosen when the input images are captured under varying illumination and explicit reflectance decomposition is required.

### [MINE](13661-mine.md)
MINE is a novel view synthesis method that models the frustum of the source camera using a continuous depth Multiplane Image (MPI) representation, conditioned on input images via a fully-convolutional decoder [13661-mine.md]. Unlike pixelNeRF and GRF, which model the entire 3D space per ray, MINE reconstructs the frustum of the source camera per plane, allowing rendering of any target view via homography warping after a single encoder pass and a fixed number of decoder passes, independent of the number of target views [13661-mine.md]. This architectural choice makes MINE significantly more efficient than ray-based methods when rendering multiple novel views [13661-mine.md]. Choose this method for efficient multi-view synthesis from a single or few source views.

### [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md)
Voxel and Sparse Grid Representations replace the continuous Multi-Layer Perceptron (MLP) function of standard NeRF with discrete, spatially structured data structures (dense voxels, sparse grids, hash tables, or triplanes) to store volume density and appearance features [13738-voxel-and-sparse-grid-representations.md]. This substitution enables memory-efficient training, real-time differentiable volume rendering, and scalability to large scenes by avoiding the heavy feed-forward computation required for every sample point [13738-voxel-and-sparse-grid-representations.md]. Unlike MLP-based approaches that compute color and density via neural inference, these methods retrieve values directly via interpolation or hashing [13738-voxel-and-sparse-grid-representations.md]. Choose this method for real-time rendering or large-scale scene reconstruction.

### [Aleth-NeRF](13764-aleth-nerf.md)
Aleth-NeRF is a NeRF variant that trains on under- and over-exposed images to render normal-light novel views by introducing a 'Concealing Field' assumption, where air particles attenuate emission rather than objects lacking emission [13764-aleth-nerf.md]. It differs from standard NeRF by modeling illumination adaptive volume rendering through local and global concealing fields to suppress light transport, enabling synthesis of normal-light views from low-light or over-exposed inputs without paired training data [13764-aleth-nerf.md]. Unlike RAW-NeRF which requires 16-bit HDR RAW images, Aleth-NeRF operates on standard 8-bit LDR images and trains end-to-end without pre-processing or post-processing enhancement networks [13764-aleth-nerf.md]. Choose this method for novel view synthesis from low-light or over-exposed LDR images.

### [Transformer and Vision Model Integration](13911-transformer-and-vision-model-integration.md)
This family integrates Vision Transformers (ViT) and general Transformer architectures into Neural Radiance Fields to leverage global semantic understanding and long-range dependencies for novel view synthesis. It solves the limitations of standard MLP-based NeRFs, which lack explicit global scene modeling and struggle with single-image inputs or occlusions [13911-transformer-and-vision-model-integration.md]. Unlike sibling methods that rely on per-scene optimization or canonical coordinate systems, these models either generalize across scenes without per-scene tuning or explicitly model self-occlusion via attention mechanisms to retrieve features from distant parts of the source view [13911-transformer-and-vision-model-integration.md, unofficial]. Choose this method for generalizable NeRF or single-image reconstruction.

### [Human and Specific Subject Modeling](13997-human-and-specific-subject-modeling.md)
This family of methods adapts the standard NeRF architecture [Parent](11313-model-architecture-modifications.md) to model dynamic human subjects, enabling novel view synthesis and novel pose rendering from monocular or sparse multi-view inputs. Unlike static scene modeling, these methods must handle non-rigid deformation, occlusion, and the specific topology of the human body. They distinguish themselves from siblings by explicitly integrating parametric human priors (such as SMPL) or structured latent codes anchored to deformable meshes, rather than relying solely on implicit MLP representations or UV-mapping [13997-human-and-specific-subject-modeling.md]. Choose this method for animatable human avatars.

### [OPONeRF](14014-oponerf.md)
OPONeRF is a neural rendering method that personalizes the parameters of the plenoptic mapping function for each sampled 3D point to handle test-time scene changes and robustness against perturbations such as motion, illumination changes, or contamination [14014-oponerf.md, unofficial]. Unlike vanilla NeRFs where network parameters are shared and fixed, or generalizable NeRFs that condition fixed parameters on a latent code, OPONeRF dynamically conditions the network weights $\Theta$ on the point's representation $\mathbf{x}$ and the overall scene representation $\mathbf{F}$ [14014-oponerf.md, unofficial]. This approach subdivides the scene and discriminatively responds to local variations, providing more expressiveness and flexibility than methods that model static appearance as stochastic variables [14014-oponerf.md, unofficial]. Choose this method for robust rendering under test-time perturbations.

### [Mixer-NeRF](14073-mixer-nerf.md)
Mixer-NeRF is a 3D reconstruction method that addresses the loss of local information and blurry details in standard Neural Radiance Fields (NeRF) by introducing a hybrid spatial feature learning module (MLCA) and a squeeze-and-excitation (SE) network module [14073-mixer-nerf.md]. It sets itself apart from standard NeRF by explicitly mixing spatial and channel features via fully connected layers before the main MLP inference, rather than relying solely on positional encoding and MLP weights to capture high-frequency details [14073-mixer-nerf.md]. Choose this method when high-frequency detail reconstruction is critical.

### [Sparse View and Few-Shot Optimization](14428-sparse-view-and-few-shot-optimization.md)
Sparse View and Few-Shot Optimization addresses the severe overfitting, geometry breakdown, and artifact generation (such as floaters) that occur when training Neural Radiance Fields (NeRF) with a drastically reduced number of input viewpoints, typically $|S| < 20$ [14428-sparse-view-and-few-shot-optimization.md, unofficial]. Unlike standard NeRF methods that rely on dense sampling, these techniques mitigate ambiguity through in-situ regularization, deformable sampling strategies, or pseudo-observation densification, setting them apart from generalized sparse NeRFs that require large-scale pre-training or external depth priors [14428-sparse-view-and-few-shot-optimization.md, unofficial]. Choose this method when training data is extremely limited.

### [Mixture-of-Experts and Modular Architectures](14429-mixture-of-experts-and-modular-architectures.md)
This family encompasses architectures that replace or augment the single continuous function of standard NeRF with multiple specialized networks (experts) or parallel processing streams. It solves the limitations of conventional Implicit Neural Representations (INRs), which struggle with complex features using a single network, and grid-based INRs, which suffer from boundary discontinuities [14429-mixture-of-experts-and-modular-architectures.md, MIMO-NeRF](13765-mixture-of-experts-implicit-neural-representation.md). It sets itself apart from siblings like [DoF-NeRF](9432-dof-nerf.md) (which handles depth-of-field) or [Feature Fields](12995-feature-fields.md) (which add semantic channels) by explicitly partitioning the input domain or ray batch among distinct neural modules to improve compression, training speed, or representation capacity. Choose this method for complex scenes requiring specialized local representations.

### [Uncertainty and Reliability](14487-uncertainty-and-reliability.md)
Uncertainty and Reliability methods extend standard NeRF architectures to quantify prediction confidence, addressing artifacts, redundancy, and geometry collapse in sparse or unstructured data. Unlike deterministic NeRF variants that output fixed values, these methods model the scene as a probabilistic entity, providing pixel-level reliability metrics for color and depth to enable robust filtering and conformal prediction. Choose this method when robustness to outliers or confidence estimation is required.

### [Object Decomposition and Composition](14518-object-decomposition-and-composition.md)
Object Decomposition and Composition methods extend standard NeRF architectures to separate a scene into distinct object instances and a background, enabling individual object manipulation, editing, and amodal segmentation [14518-object-decomposition-and-composition.md]. Unlike sibling methods that may rely on explicit point clouds or separate segmentation pipelines, these approaches integrate decomposition into the differentiable rendering pipeline, often using one-hot activation mechanisms or frequency-based partitioning to disentangle objects while maintaining global consistency [14518-object-decomposition-and-composition.md][13525-dm-nerf.md][14413-unified-decompositional-and-compositional-nerf.md][15935-detail-based-segmentation.md]. Choose this method for scene editing and object-level manipulation.

### [Lighting and Appearance Models](14522-lighting-and-appearance-models.md)
Lighting and Appearance Models modify the standard NeRF architecture to explicitly represent, decompose, or stylize illumination and material properties, addressing the standard formulation's lack of semantic lighting control and its inability to handle varying lighting conditions or artistic styles [14522-lighting-and-appearance-models.md]. This family distinguishes itself by replacing or augmenting the view-dependent color MLP with explicit lighting bases, pre-integrated neural queries, or decoupled stylization networks, rather than relying solely on appearance embeddings [14522-lighting-and-appearance-models.md]. Choose this method for relighting, stylization, or material decomposition.

### [Optimization and Training Procedures](14565-optimization-and-training-procedures.md)
This family covers the algorithmic procedures for optimizing Neural Radiance Fields (NeRF) and related representations, ranging from standard training loops to specialized acceleration and editing techniques. It addresses the problem of efficiently minimizing the photometric loss between rendered and ground-truth images while managing computational constraints. Unlike standard gradient descent on the full network, methods in this family often employ structural modifications to the optimization scope, such as skipping expensive fine-pass evaluations for empty rays or restricting updates to specific network layers to preserve pre-trained geometric features. Choose this method for efficient training or editing.

### [Image Enhancement and Restoration Methods](14566-image-enhancement-and-restoration-methods.md)
Image Enhancement and Restoration Methods address the degradation of input imagery—such as blur, transient occlusions, or low resolution—by integrating restoration mechanisms directly into the NeRF optimization loop. Unlike standard NeRF which assumes sharp, clean inputs, these methods either model the degradation process (e.g., blur kernels) or separate static scene geometry from transient artifacts (e.g., pedestrians) to render clean novel views. They differ from sibling methods like [DeblurNeRF](11964-deblurnerf.md) and [IE-NeRF](13737-ie-nerf.md) by focusing on specific degradation types: optical blur, transient occlusions, or resolution limits, often using 2D priors (inpainting, super-resolution) to guide 3D consistency. Choose this method for handling degraded input data.

### [Modular, Hierarchical, and Latent Architectures](14567-modular-hierarchical-and-latent-architectures.md)
This family extends standard NeRF architectures to handle non-rigid deformation with topological changes and hierarchical scene structures, respectively. [HyperNeRF](13906-hypernerf.md) models non-rigidly deforming scenes by lifting the canonical 3D space into a higher-dimensional ambient space, allowing smooth topological variations without discontinuous deformation mappings. [Strata-NeRF](14015-strata-nerf.md) models stratified scenes (e.g., interior/exterior) by replacing continuous positional encoding inputs with discrete latent codes, preventing the "cloudy" artifacts that arise when training a single continuous field on hierarchical levels. Choose this method for dynamic or hierarchical scenes.

### [MuRF (Multi-Baseline Radiance Fields)](15007-murf-multi-baseline-radiance-fields.md)
MuRF is a feed-forward method for sparse view synthesis that solves the problem of rendering novel views under varying camera baseline settings, including both small and large baselines [15007-murf-multi-baseline-radiance-fields.md]. It differs from prior radiance field methods by constructing a **target view frustum volume** aligned with the target camera rather than a reference input view, and by using a **3D context-aware convolutional decoder** instead of independent ray-based rendering [15007-murf-multi-baseline-radiance-fields.md]. This approach effectively aggregates multi-view information even when overlap between input and target views is small, a common failure mode for reference-volume methods in large baseline scenarios [15007-murf-multi-baseline-radiance-fields.md]. Choose this method for large-baseline novel view synthesis.

### [Gaussian and Primitive-Based Representations](15011-gaussian-and-primitive-based-representations.md)
This family replaces the continuous Multi-Layer Perceptron (MLP) radiance field with discrete geometric primitives or explicit Gaussian distributions to improve rendering efficiency and geometric fidelity. It differs from sibling methods like [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md) by using analytic primitives (quadrics or Gaussians) rather than voxel grids, and from [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md) by relying on alpha-blended primitives rather than implicit surface marching. Choose this method for real-time rendering with explicit geometry.

### [Decentralized Federated NeRF](15032-decentralized-federated-nerf.md)
Decentralized Federated NeRF (DecentNeRF) is a framework for learning global 3D scene representations from crowd-sourced images by distributing training computation to users and aggregating only global radiance field models to minimize server compute and personal data leakage [15032-decentralized-federated-nerf.md]. It solves the problem of achieving photorealistic 3D reconstruction of global scene content while preventing the server from reconstructing transient personal content (e.g., users, objects) present in crowdsourced images taken at different times [15032-decentralized-federated-nerf.md]. Unlike centralized approaches like NeRF-W which require all personal user images to be transferred to a central server, or existing federated learning NeRF techniques which assume static scenes devoid of personal information, DecentNeRF handles personal content and uses secure aggregation [15032-decentralized-federated-nerf.md]. It differs from siblings like [DoF-NeRF](9432-dof-nerf.md) and [NeRF-VPT](11770-nerf-vpt.md) by explicitly decomposing the scene into global and personal radiance fields per user and employing a learned weighted aggregation protocol with Secure Multi-Party Computation (SMPC) [15032-decentralized-federated-nerf.md]. Choose this method for privacy-preserving crowd-sourced reconstruction.

### [Neural Proxy](15220-neural-proxy.md)
Neural Proxy is a neural rendering method that represents photo-realistic targets as animatable proxies, enabling the synthesis of unseen animations without temporal learning [15220-neural-proxy.md, unofficial]. It combines neural volume rendering with neural texture by injecting an animatable mesh proxy into the scene, mimicking the traditional CG pipeline of using a 3D mesh for geometry and a texture for appearance [15220-neural-proxy.md, unofficial]. Unlike NeRF, which ties content to continuous Cartesian coordinates making animation difficult, Neural Proxy allows particles to move with the animated proxy geometry [15220-neural-proxy.md, unofficial]. Unlike Neural Texture, which requires animated training samples to render unseen animations, Neural Proxy renders unseen animations by animating the proxy geometry itself [15220-neural-proxy.md, unofficial]. Choose this method for animatable character rendering.

### [ViSNeRF](15255-visnerf.md)
ViSNeRF is a hybrid neural radiance field method designed for the efficient synthesis of visualizations from dynamic volumetric scenes with arbitrary adjustable parameters (e.g., time, isovalue, transfer function coefficients) [15255-visnerf.md]. It solves the scalability problem of representing high-dimensional $(3+K)$-D radiance fields by combining explicit feature grids with implicit MLP decoders and applying generalized tensor factorization [15255-visnerf.md]. Unlike standard NeRF which uses a single MLP, ViSNeRF factorizes the static 3D spatial volume into vector-matrix components and the $K$-D parameter space into CP components, reducing memory complexity from $O(N^3 M^K)$ to $O(N^2 M)$ [15255-visnerf.md]. It is distinguished from siblings like [K-Planes](11770-nerf-vpt.md) and [HexPlane](11770-nerf-vpt.md) by its specific use of separate small MLPs for density and color decoding and its tailored regularization strategies for explicit grid features [15255-visnerf.md]. Choose this method for scientific visualization of multi-parameter volumetric data.

### [EBAD-NeRF](15441-ebad-nerf.md)
EBAD-NeRF is a method for reconstructing sharp 3D radiance fields from motion-blurred images by jointly optimizing learnable camera poses and NeRF parameters using hybrid event-RGB data [15441-ebad-nerf.md]. It distinguishes itself from prior works like BAD-NeRF and E2 NeRF by modeling complex camera motion trajectories with multiple learnable poses rather than linear interpolation or fixed pre-estimated poses, and by explicitly supervising the motion blur via an intensity-change-metric event loss [15441-ebad-nerf.md]. Choose this method for reconstructing scenes from motion-blurred inputs using event cameras.

### [Network Architectures](15530-network-architectures.md)
Network architectures in radiance field optimization modify the standard NeRF baseline to address specific constraints such as inference speed, memory footprint, dynamic scene representation, or semantic manipulation. While the standard architecture [Parent](3065-nerf-hyperparameters.md) uses two MLPs for density and color, these modifications generally fall into input expansion, output expansion, or representation substitution [14428-sparse-view-and-few-shot-optimization.md]. They set themselves apart by integrating auxiliary conditioning, replacing continuous MLPs with discrete structures, or adapting the network topology for parallel processing and dynamic features. Choose this method for general architectural improvements.

### [Point-NeRF Representation](15538-point-nerf-representation.md)
Point-NeRF replaces the continuous Multi-Layer Perceptron (MLP) function used in standard NeRF with a discrete neural point cloud to model a continuous volumetric radiance field [15538-point-nerf-representation.md]. This approach avoids ray sampling in empty space by leveraging classical point clouds that approximate scene geometry, allowing for faster optimization and higher-quality rendering than standard NeRF [15538-point-nerf-representation.md]. It differs from sibling methods like [Gaussian and Primitive-Based Representations](15011-gaussian-and-primitive-based-representations.md) by using point-based aggregation rather than volumetric primitives, and from [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md) by maintaining explicit geometric anchors rather than implicit grid structures. Choose this method for efficient point-based rendering.

### [NeurMiPs](15543-neurmips.md)
NeurMiPs represents a 3D scene as a mixture of $K$ learnable rectangular planar surfaces, where each surface acts as an independent "expert" predicting view-dependent color and transparency via a local neural radiance field [15543-neurmips.md]. It alleviates the frontal-parallel limitation of traditional Multi-Plane Imagery (MPI) while maintaining high efficiency through analytical ray-plane intersection and parallel CUDA execution, offering superior extrapolation capabilities compared to voxel-based methods like PlenOctrees and KiloNeRF [15543-neurmips.md]. Choose this method for efficient MPI-based rendering with local experts.

### [CodeNeRF](15544-codenerf.md)
CodeNeRF is an implicit 3D neural representation that learns the variation of object shapes and textures across a semantic category, enabling the synthesis of novel views of unseen objects from a single unposed input image [15544-codenerf.md]. Unlike standard NeRF which is scene-specific, CodeNeRF disentangles shape and texture by learning separate latent embeddings, allowing for one-shot reconstruction and explicit editing of object geometry and appearance [15544-codenerf.md]. It sets itself apart from siblings like [DoF-NeRF](9432-dof-nerf.md) or [NeRF-VPT](11770-nerf-vpt.md) by jointly optimizing camera pose, shape code, and texture code at inference time without requiring known camera parameters, whereas many alternatives assume fixed or known poses [15544-codenerf.md]. Choose this method for single-image 3D reconstruction of unseen objects.

### [Dynamic Scene and Temporal Modeling](15546-dynamic-scene-and-temporal-modeling.md)
Dynamic Scene and Temporal Modeling extends static Neural Radiance Fields (NeRF) to handle video sequences and time-varying scenes by introducing a temporal dimension $t$ into the radiance field representation [14705-nerf-with-time-parameter.md]. It solves the problem of reconstructing dynamic content, which standard NeRF cannot represent, by allowing density and color to vary over time [14705-nerf-with-time-parameter.md]. Unlike static methods, it explicitly models scene dynamics, either through direct time conditioning, deformation fields, or particle systems [13848-gear-nerf.md][15541-forward-warping-for-novel-view-synthesis.md][15550-dynamic-appearance-particle-neural-radiance-field.md][15551-kfd-nerf.md]. Choose this method for dynamic scene reconstruction.

### [NeRF-Casting](15547-nerf-casting.md)
NeRF-Casting is a method for synthesizing photorealistic specular appearance and reflections in real-world scenes by integrating ray tracing into the NeRF rendering pipeline [15547-nerf-casting.md]. It solves the problem of view-dependent appearance modeling by casting reflection rays from points along camera rays into the NeRF geometry to render feature vectors, which are then decoded into color using a small MLP, rather than querying a large MLP for outgoing radiance [15547-nerf-casting.md]. Unlike Ref-NeRF, which reparameterizes outgoing radiance as a function of reflected view direction and requires a large MLP to encode the entire environment, NeRF-Casting uses ray tracing to naturally synthesize consistent reflections of nearby and distant content without requiring the MLP to represent the full environment at every point [15547-nerf-casting.md]. Choose this method for realistic reflections without large environment maps.

### [RoseNeRF](15548-rosenerf.md)
RoseNeRF is a method for high-fidelity novel view synthesis of real refractive objects that simplifies complex ray interactions inside transparent media to a single refraction event [15548-rosenerf.md]. It models refraction by predicting a single refracted ray using a 4D light field representation and a refraction network, avoiding the need for Index of Refraction (IoR) fields or detailed surface reconstructions [15548-rosenerf.md]. Unlike deformation field methods that predict position offsets for each sampling point, RoseNeRF predicts the refracted ray and uses hierarchical sampling, avoiding the need for point-by-point deformation and additional priors like IoR [15548-rosenerf.md]. Choose this method for rendering transparent/refractive objects.

### [Semantic and Feature Field Extensions](15556-semantic-and-feature-field-extensions.md)
Semantic and Feature Field Extensions generalize the Neural Radiance Field (NeRF) formulation to predict arbitrary per-point feature signals $\mathbf{f}$ in addition to color $\mathbf{c}$ and density $\sigma$ [15556-semantic-and-feature-field-extensions.md, unofficial]. This extension enables the lifting of 2D observations—such as semantic labels, object codes, or foundation model embeddings—into a consistent 3D representation, solving the limitation of NeRF as a purely photometric model [15556-semantic-and-feature-field-extensions.md, unofficial]. Unlike sibling methods that modify the input space (e.g., [MS-NeRF](11707-multi-space-neural-radiance-field-ms-nerf.md)) or use separate networks for specific tasks (e.g., [NRFF](12072-nrff.md)), this family integrates these signals directly into the volume rendering pipeline, allowing 2D supervision to lift into a consistent 3D representation [15556-semantic-and-feature-field-extensions.md, unofficial]. Choose this method for semantic 3D understanding.

### [Neural Density-Distance Fields](15665-neural-density-distance-fields.md)
Neural Density-Distance Fields (NeDDF) is a method that reciprocally constrains distance and density fields, extending the distance field formulation to adapt to any density field [15665-neural-density-distance-fields.md, unofficial]. It allows for boundaryless scenes and complex shapes by deriving density from depth values obtained via volume rendering [15665-neural-density-distance-fields.md, unofficial]. Unlike standard NeRF which predicts density directly, NeDDF predicts a distance field $D$ and computes density $\sigma$ via its gradient, enabling more stable mesh extraction and camera pose localization through reprojection error [15665-neural-density-distance-fields.md, unofficial]. Choose this method for stable mesh extraction and boundaryless scenes.

### [LAENeRF](15738-laenerf.md)
LAENeRF is a unified framework for the photorealistic and non-photorealistic local appearance editing of pre-trained Neural Radiance Fields (NeRFs) [15738-laenerf.md]. It solves the problem of recoloring or stylizing arbitrary 3D regions while minimizing background artifacts and maintaining interactivity [15738-laenerf.md]. Unlike methods that rely on semantic segmentation masks or single-target colors, LAENeRF learns a palette-based color decomposition within a user-selected region, enabling smooth transitions to the original scene content [15738-laenerf.md]. It sets itself apart by estimating per-ray termination points to define the editable region, reducing memory requirements compared to voxel-based approaches, and introducing geometry-aware losses to preserve small structures during stylization [15738-laenerf.md]. Choose this method for interactive local editing.

### [ExtremeNeRF](15739-extremenerf.md)
ExtremeNeRF is a few-shot view synthesis framework designed to generate novel views from sparse multi-view images captured under unconstrained, varying illumination [15739-extremenerf.md]. Unlike standard NeRF or illumination-robust methods like NeRF-W and RegNeRF that require dense input views or constrained lighting, ExtremeNeRF achieves robustness by enforcing multi-view albedo consistency through a two-stage intrinsic decomposition pipeline [15739-extremenerf.md]. It distinguishes itself by using an offline full-image network (FIDNet) to generate pseudo-albedo ground truths for input images, which then guide an online patch-wise network (PIDNet) to decompose synthesized novel view patches, ensuring that the learned geometry and appearance are illumination-invariant [15739-extremenerf.md]. Choose this method for novel view synthesis under varying illumination.

### [Frequency-Modulated Point Cloud Rendering](15903-frequency-modulated-point-cloud-rendering.md)
Frequency-Modulated Point Cloud Rendering (also known as AFNet or FreqPCR) is a real-time rendering pipeline that replaces the standard continuous MLP radiance field with a point cloud representation modulated by an Adaptive Frequency Net (AFNet) [15903-frequency-modulated-point-cloud-rendering.md]. It solves the problem of high-frequency detail reconstruction and slow rendering speeds inherent in standard NeRF architectures by using a hypernetwork to predict local texture frequencies and phases for each point, which are then used to modulate the radiance signal via adaptive activation layers [15903-frequency-modulated-point-cloud-rendering.md]. Unlike standard NeRF which suffers from spectral bias towards low frequencies, this method adapts its frequency basis support locally, enabling high-fidelity reconstruction of textured regions while maintaining low computational cost for smooth regions [15903-frequency-modulated-point-cloud-rendering.md]. It is distinct from sibling methods like [Point-NeRF Representation](15538-point-nerf-representation.md) by explicitly modeling frequency modulation per point rather than just using point features, and from [Gaussian and Primitive-Based Representations](15011-gaussian-and-primitive-based-representations.md) by using a neural activation modulation strategy rather than explicit geometric primitives with fixed kernels. Choose this method for real-time high-frequency detail rendering.

### [Conditional and Latent Representations](15989-conditional-and-latent-representations.md)
Conditional and Latent Representations extend standard NeRF architectures to model entire object classes or multiple 3D instances using a single neural network, rather than training separate models for each scene [15989-conditional-and-latent-representations.md]. By conditioning the radiance field on per-instance latent codes, this approach enables efficient representation of varying geometry and texture, supports instance-specific editing, and maintains reconstruction accuracy comparable to independent NeRFs while sharing a common network backbone [15989-conditional-and-latent-representations.md]. It differs from sibling methods like [Conditional Radiance Field with Shared Branch](15964-conditional-radiance-field-with-shared-branch.md) by explicitly decoupling shape and color codes and injecting them into the embedding layers, whereas the sibling method separates the geometric representation into shared and instance-specific branches to improve editing efficiency [15989-conditional-and-latent-representations.md]. Choose this method for multi-instance or class-level generalization.

### [ActiveNeRF Model Architecture](16203-activenerf-model-architecture.md)
ActiveNeRF modifies the standard NeRF architecture [14428-sparse-view-and-few-shot-optimization.md] to output prediction variance alongside density and color, enabling uncertainty-aware view synthesis [16203-activenerf-model-architecture.md]. Unlike sibling architectures that primarily focus on input expansion or representation substitution, ActiveNeRF introduces an auxiliary output head for variance estimation to guide active sampling strategies [16203-activenerf-model-architecture.md]. #### NeuralEditor
- **Definition:** A method employing a point cloud-guided NeRF model for shape manipulation, leveraging K-D trees and deterministic integration strategy for accurate point cloud-based rendering, with Phong reflection modeling to enhance color fidelity and geometric detail [S4].
- **Steps:** 1. Employ point cloud-guided NeRF model. 2. Leverage K-D trees. 3. Use deterministic integration strategy. 4. Achieve accurate point cloud-based rendering. 5. Apply Phong reflection modeling [S4].

#### Neural Architecture Search for NeRF
- **Steps:** Train NeRFs with different combinations of network depth and width on a volumetric video frame. Measure the quality of images rendered from the trained NeRFs using Peak Signal-to-Noise Ratio (PSNR) [S6].
- **Parameters:** Network Depth ($d$): Number of layers. Initial search space: {1, 2, 4, 6, 8}. Final selected space: {2, 4}. Network Width ($w$): Number of neurons in each layer. Initial search space: {64, 128, 256}. Final selected space: {128, 256} [S6].
- **Numbers:** On RedAndBlack Frame #1450, PSNR was measured for various architectures to determine the optimal search space [S6].
- **Comparison:** Network depth provides the ability to learn hierarchical representations, while network width provides the capacity to 'memorize' the training data. Reducing width monotonically decreases quality, while reducing depth first improves then drops quality if smaller than 2 [S6].

## Background
The standard NeRF architecture [Parent](3065-nerf-hyperparameters.md) was introduced by Mildenhall et al. [S1, S6]. The original implementation employed hierarchical rendering with two networks (coarse and fine) to improve computational efficiency [S1]. Subsequent works have extensively modified this architecture to address limitations in speed, generalization, dynamic scenes, and input data quality [S1].
