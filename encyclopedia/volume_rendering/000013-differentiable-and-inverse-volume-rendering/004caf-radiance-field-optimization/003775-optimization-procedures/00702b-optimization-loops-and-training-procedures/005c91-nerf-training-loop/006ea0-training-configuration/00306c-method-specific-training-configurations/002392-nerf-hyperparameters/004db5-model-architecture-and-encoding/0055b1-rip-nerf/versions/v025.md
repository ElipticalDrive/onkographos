# Rip-NeRF

Also called: Rip-NeRF25k

## Overview
Rip-NeRF is a hybrid radiance field method that renders high-fidelity, anti-aliased images by combining cone casting with anisotropic 3D Gaussian characterization [S1]. It distinguishes itself from sibling methods like Zip-NeRF by using Ripmap-Encoded Platonic Solids to enable efficient anisotropic area-sampling, whereas Zip-NeRF relies on a multi-sampling mechanism that is less efficient [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of calibrated multi-view 2D images.
*   **Outputs:** Rendered pixel colors $\hat{C}(\mathbf{r})$ for rays $\mathbf{r}$.

**Data Structures:**
1.  **Ripmap Encoding:** A hierarchical feature grid.
    *   **Base Level ($R_{0,0}$):** Learnable tensor with shape $H \times W \times C$. Default dimensions: $H=512, W=512, C=16$ [S1].
    *   **Derived Levels:** Generated from the base level using average pooling to ensure consistency and compactness [S1].
2.  **Platonic Solid:** A geometric proxy for area sampling.
    *   **Default:** Icosahedron with 10 unparalleled faces [S1].
    *   **Faces:** Denoted as $\{P_i \mid i = 1, \dots, n\}$, where $n$ is the number of faces [S1].
3.  **3D Gaussian:** Characterizes a conical frustum.
    *   **Parameters:** Mean $\boldsymbol{\mu} \in \mathbb{R}^3$ and Covariance $\boldsymbol{\Sigma} \in \mathbb{R}^{3 \times 3}$ [S1].
4.  **Occupancy Grid:** Binary grid (from NerfAcc) to skip empty space samples [S1].

**Numbered Steps:**

1.  **Cone Casting and Frustum Division:**
    For each pixel, cast a cone and divide it into multiple conical frustums [S1]. This avoids discrete point-based sampling of continuous signals [S1].

2.  **Gaussian Characterization:**
    Characterize each conical frustum using an anisotropic 3D Gaussian parameterized by mean $\boldsymbol{\mu}$ and covariance $\boldsymbol{\Sigma}$ [S1].

3.  **Platonic Solid Projection:**
    Project the 3D Gaussian onto the faces of the Platonic solid to form 2D Gaussians [S1].
    *   For each face $P_i$, compute the projection matrix $M_i \in \mathbb{R}^{3 \times 2}$ mapping the 3D world coordinate system to the 2D coordinate system of plane $P_i$ [S1].
    *   Compute the projected mean $\boldsymbol{\mu}^{proj}_i$ and covariance $\boldsymbol{\Sigma}^{proj}_i$ of the 2D Gaussian on plane $P_i$ [S1].

4.  **Ripmap Encoding Query:**
    Query a feature vector $\mathbf{f}_i$ from the Ripmap Encoding of each plane $P_i$ using tetra-linear interpolation [S1].
    *   The position $(p_x, p_y)$ used in interpolation is determined by the mean $\boldsymbol{\mu}^{proj}_i$ [S1].
    *   The level $(l_x, l_y)$ used in interpolation is determined by the covariance $\boldsymbol{\Sigma}^{proj}_i$ [S1].
    *   The derived levels $R_{i,j}$ are computed from the base level $R_{0,0}$ as follows [S1]:
        $$
        R_{i,j} = \begin{cases} 
        \text{Avg}_{2\times 1}(R_{i, j-1}) & \text{if } j \neq 0 \\
        \text{Avg}_{1\times 2}(R_{i-1, j}) & \text{if } i \neq 0 \text{ \& } j = 0 \\
        R_{0,0} & \text{otherwise}
        \end{cases}
        $$
        where $i$ and $j$ are indices of levels in the $x$ and $y$ directions, respectively [S1].

5.  **Feature Aggregation:**
    Concatenate all feature vectors $\{\mathbf{f}_i \mid i = 1, \dots, n\}$ from the corresponding planes $\{P_i \mid i = 1, \dots, n\}$ to form the final feature vector $\mathbf{f}$ of the 3D Gaussian [S1].

6.  **Density and Color Estimation:**
    Aggregate the final feature vector $\mathbf{f}$ with the encoded view direction $\mathbf{d}$ [S1]. Pass the combined features through a tiny MLP $F_\theta$ to estimate color $\mathbf{c}$ and density $\sigma$ [S1].

7.  **Volume Rendering:**
    Render the pixel color using the estimated color $\mathbf{c}$ and density $\sigma$ via standard volume rendering [S1].

8.  **Optimization:**
    Optimize the system end-to-end using a photometric loss between rendered and observed images [S1].
    *   **Area Loss:** Scale the photometric loss for each pixel by incorporating the area of its footprint on the image plane, denoted as $L_{area}$ [S1]. This follows the approach in [Barron et al. 2021; Hu et al. 2023] [S1].

**Parameters:**
*   **Base Ripmap Encoding ($R_{0,0}$):** Shape $H=512, W=512, C=16$ [S1].
*   **Platonic Solid:** Default is icosahedron (10 faces) [S1].
*   **Hyper-parameter $w$:** Set to 2.0 to adjust how much probability mass of the Gaussian footprint is covered [S1].
*   **Optimizer:** AdamW [S1].
*   **Iterations:** 120k for Rip-NeRF; 25k for Rip-NeRF25k [S1].
*   **Weight Decay:** $1 \times 10^{-5}$ [S1].
*   **Initial Learning Rate:** $2 \times 10^{-3}$, modulated by MultiStepLR [S1].
*   **Ripmap Learning Rate:** Scaled up by 10.0 times relative to the base learning rate [S1].

**Edge Cases and Pitfalls:**
*   **Empty Space:** Use a binary occupancy grid (from NerfAcc) to skip samples in empty areas, improving efficiency [S1].
*   **Anisotropy:** The method specifically addresses anisotropic Gaussians; using isotropic sampling (like standard Tri-MipRF) results in square sampling areas that cannot precisely characterize the projected anisotropic 2D Gaussian [S1].

## Operating characteristics
*   **Training Time:** 2.6 hours on NVIDIA A100-SXM4-80GB GPU for Rip-NeRF [S1]. Rip-NeRF25k trains in 32 minutes (11.76% of Zip-NeRF's 4.5 hours) [S1].
*   **Model Size:** 160 MB [S1].
*   **GPU Memory:** 20 GB during training [S1]. (Zip-NeRF requires ~80 GB, which is unfeasible for consumer GPUs like RTX 4090) [S1].
*   **Rendering Speed:** 3 FPS [S1]. (Zip-NeRF renders at 0.25 FPS) [S1].
*   **Performance:** Outperforms Zip-NeRF in PSNR and LPIPS on the multi-scale Blender dataset [S1]. Zip-NeRF has slightly better SSIM [S1].
*   **Strengths:** High-fidelity anti-aliasing, efficient anisotropic area-sampling, compact model size, low memory footprint [S1].
*   **Limitations:** Designed for bounded objects; Zip-NeRF is designed for unbounded scenes [S1].

## Background
*   **Origin:** Rip-NeRF was introduced in the paper "Rip-NeRF: Anti-aliasing Radiance Fields with Ripmap-Encoded Platonic Solids" [S1].
*   **Development:** It builds upon hybrid representations combining explicit and implicit features, leveraging cone casting from Mip-NeRF [Barron et al. 2021] and area-sampling from Tri-MipRF [Hu et al. 2023] [S1].
*   **Usage:** Evaluated on the multi-scale Blender dataset to benchmark anti-aliasing and fine detail rendering [S1].
