# RealFusion

Also called: RealFusion optimization, RealFusion training procedure, single-image 3D reconstruction via diffusion prior

## Overview
RealFusion is a method for reconstructing a full 360° photographic 3D model of an arbitrary object from a single input image, without requiring 3D supervision or object category assumptions [S2]. It solves the ill-posed nature of single-view reconstruction by combining a NeRF photometric reconstruction loss with a Score Distillation Sampling (SDS) prior derived from a pre-trained 2D diffusion model [S2]. Unlike DreamFusion, which relies on generic text prompts and suffers from mode collapse when high guidance is applied, RealFusion uses single-image textual inversion to generate a specific prompt embedding that conditions the diffusion model to "dream up" plausible novel views of the specific input object [S2]. It builds on [Single-Image Textual Inversion](19221-single-image-textual-inversion.md) to substitute for missing multi-view data [S1].

## How it works
### Inputs and Outputs
**Inputs:**
*   A single input image $I_0$ of an object [S2].
*   An off-the-shelf image matting model to produce an object mask $M$ for $I_0$ [S2].
*   A pre-trained 2D diffusion model $\Phi$ (specifically Stable Diffusion) [S2].
*   A base radiance field architecture (InstantNGP) [S2].

**Outputs:**
*   A trained neural radiance field (NeRF) representing the 3D geometry and appearance of the object [S2].

### Data Structures
The radiance field is implemented using InstantNGP [S2].
*   **Feature Grids:** A set of feature grids $\{G_i\}_{i=1}^L$ at multiple resolutions [S2].
*   **Resolution:** Resolutions are chosen as a geometric progression between the coarsest and finest levels [S2].
*   **Configuration:** The implementation uses $L=16$ resolution levels, a feature dimension of 2, and a maximum resolution of 2048 [S2].
*   **Training State:** Feature grids are trained simultaneously, but optimization is restricted to lower-resolution grids during the first half of training (coarse-to-fine) [S2].

### Steps

#### 1. Single-Image Textual Inversion (Prompt Engineering)
Before 3D optimization, a specific text prompt is engineered to condition the diffusion model [S2].
1.  Generate random augmentations $g(I_0)$ of the input image $I_0$, where $g \in \mathcal{G}$ [S2].
2.  Treat these augmentations as a mini-dataset $\mathcal{D}_0 = \{g(I_0)\}$ [S2].
3.  Introduce a new token `hei` into the vocabulary of the diffusion model's text encoder [S2].
4.  Define the prompt template as "An image of a hei" [S2].
5.  Optimize the embedding $e(I_0)$ corresponding to `hei` by minimizing the diffusion loss $L_{diff}(\Phi(\cdot; e(I_0)))$ with respect to $e(I_0)$, while freezing all other text embeddings and model parameters [S2].
    *   *Note:* This step substitutes for alternative views by capturing object-specific details in the embedding [S1].

#### 2. Radiance Field Optimization
The radiance field parameters $\sigma$ (density) and $c$ (color) are optimized using a combined loss function [S2]. The training proceeds in a coarse-to-fine manner [S2].

**Camera Setup:**
*   **Reconstruction Camera:** Fixed at a position looking at the origin on a sphere of radius 1.8, at an angle of 15° above the plane [S2].
*   **Novel View Camera:** Randomly sampled at each optimization step [S2].

**Loss Components:**
1.  **Reconstruction Loss ($L_{rec}$):** Minimizes L2 error between the input image and the rendered image from the fixed reconstruction camera [S2].
2.  **Mask Loss ($L_{rec,mask}$):** Constrains rendered opacities $O$ at the fixed viewpoint to match the object mask $M$ [S2].
    $$ L_{rec,mask} = ||O - M||^2 $$
    where $O = R(\cdot; \sigma, c, \pi_0) \in \mathbb{R}^{H \times W}$ is the rendered opacity from the fixed reference viewpoint $\pi_0$ [S2].
3.  **SDS Prior Loss ($L_{SDS}$):** Applied to the randomly sampled novel view to enforce 3D consistency using the diffusion prior [S2].
    $$ L_{SDS}(\sigma, c; \pi, e, t) = \mathbb{E}_{t,\epsilon} \left[ w(t) (\Phi(\alpha_t I + \sigma_t \epsilon; t, e) - \epsilon) \cdot \nabla_{(\sigma,c)} I \right] $$
    where $I = R(\cdot; \sigma, c, \pi)$ is the image rendered from the novel viewpoint $\pi$, $e$ is the optimized prompt embedding, $t$ is the noise level, $\epsilon$ is the predicted noise, and $w(t)$ is a weighting function [S2].
4.  **Normal Regularization ($L_{normals}$):** Encourages smooth surface normals by comparing rendered normals to a blurred version of themselves [S2].
    $$ L_{normals} = ||N - \text{stopgrad}(\text{blur}(N, k))||^2 $$
    where $N \in \mathbb{R}^{H \times W \times 3}$ are the aggregated normals along the ray, $\text{blur}(\cdot, k)$ is a Gaussian blur with kernel size $k$, and $\text{stopgrad}$ stops gradient flow through the blur operation [S2].

**Total Loss:**
$$ \nabla_{\sigma,c} L = \nabla L_{SDS} + \lambda_{normals} \cdot \nabla L_{normals} + \lambda_{image} \cdot \nabla L_{image} + \lambda_{mask} \cdot \nabla L_{mask} $$
where $L_{image}$ corresponds to $L_{rec}$ [S2].

**Coarse-to-Fine Schedule:**
*   **First Half:** Optimize only lower-resolution feature grids $\{G_i\}_{i=1}^{L/2}$ [S2].
*   **Second Half:** Optimize all feature grids $\{G_i\}_{i=1}^L$ [S2].

**Shading Strategy:**
*   **Warmup:** Initial period uses albedo-only shading [S2].
*   **Main Training:** Stochastically applies diffuse and textureless shading throughout optimization [S2].

### Pseudocode

```python
def realfusion_train(I0, mask_model, diffusion_model, instantngp_model):
    # 1. Single-Image Textual Inversion
    # Generate augmentations of the input image
    augmentations = [augment(I0) for augment in random_augmentations]
    mini_dataset = augmentations
    
    # Initialize new token embedding 'hei'
    hei_embedding = initialize_embedding()
    
    # Optimize embedding to match input image via diffusion loss
    # Freeze diffusion model parameters and other text embeddings
    for step in range(textual_inversion_steps):
        loss_diff = compute_diffusion_loss(diffusion_model, mini_dataset, hei_embedding)
        hei_embedding -= learning_rate * gradient(loss_diff, hei_embedding)
        
    # Construct prompt
    prompt = "An image of a " + hei_embedding
    
    # 2. Radiance Field Optimization
    # Setup cameras
    reconstruction_camera = Camera(position=(0, 0, 1.8), angle=15_degrees)
    novel_view_camera = RandomCamera()
    
    # Hyperparameters
    lambda_normals = 0.5
    lambda_image = 5.0
    lambda_mask = 0.5
    k = 9  # Gaussian blur kernel size
    
    total_steps = 10000  # Example total steps
    half_steps = total_steps // 2
    
    for step in range(total_steps):
        # Coarse-to-fine grid selection
        if step < half_steps:
            active_grids = instantngp_model.grids[:len(instantngp_model.grids)//2]
        else:
            active_grids = instantngp_model.grids
            
        # Render from fixed reconstruction camera
        render_rec = instantngp_model.render(reconstruction_camera, active_grids)
        rendered_image_rec = render_rec.image
        rendered_opacity_rec = render_rec.opacity
        
        # Compute Reconstruction Losses
        # L_rec: L2 error between input image and rendered image
        loss_image = l2_loss(rendered_image_rec, I0)
        
        # L_rec,mask: L2 error between rendered opacity and object mask
        mask = mask_model(I0)
        loss_mask = l2_loss(rendered_opacity_rec, mask)
        
        # Render from random novel view camera
        render_novel = instantngp_model.render(novel_view_camera, active_grids)
        rendered_image_novel = render_novel.image
        rendered_normals_novel = render_novel.normals
        
        # Compute SDS Loss on novel view
        # Sample noise level t and noise epsilon
        t = sample_noise_level()
        epsilon = sample_noise()
        
        # Add noise to rendered novel view
        noisy_image = alpha_t * rendered_image_novel + sigma_t * epsilon
        
        # Get predicted noise from diffusion model
        predicted_noise = diffusion_model(noisy_image, t, prompt)
        
        # Compute SDS gradient
        # w(t) is a weighting function, typically dependent on t
        w_t = weighting_function(t)
        grad_sds = w_t * (predicted_noise - epsilon) * gradient(rendered_image_novel, instantngp_model.params)
        loss_sds = dot_product(grad_sds, grad_sds) # Simplified for loss value, gradient is used directly in update
        
        # Compute Normal Regularization Loss
        # Blur normals and stop gradient
        blurred_normals = gaussian_blur(rendered_normals_novel, k)
        stopped_blurred_normals = stop_gradient(blurred_normals)
        loss_normals = l2_loss(rendered_normals_novel, stopped_blurred_normals)
        
        # Total Loss
        total_loss = loss_sds + lambda_normals * loss_normals + lambda_image * loss_image + lambda_mask * loss_mask
        
        # Update Radiance Field Parameters
        instantngp_model.update(total_loss)
        
        # Stochastic Shading
        if step > warmup_steps:
            apply_stochastic_shading(instantngp_model)
```

### Parameters
*   **$\lambda_{image}$:** 5.0 [S2].
*   **$\lambda_{mask}$:** 0.5 [S2].
*   **$\lambda_{normals}$:** 0.5 [S2].
*   **$k$ (blur kernel):** 9 [S2].
*   **Diffusion Model:** Stable Diffusion trained on LAION [S2].
*   **InstantNGP Config:** 16 resolution levels, feature dimension 2, max resolution 2048 [S2].
*   **Camera Radius:** 1.8 [S2].
*   **Camera Angle:** 15° above the plane [S2].

### Edge Cases and Pitfalls
*   **Over-fitting:** Optimizing only with the reconstruction loss on a single image leads to zero loss but no sensible 3D model [S2]. Solved by the SDS prior [S2].
*   **Limited Diversity (Mode Collapse):** High classifier-free guidance weights (e.g., 100) in DreamFusion produce only generic objects. RealFusion solves this by using the specific `hei` embedding from textual inversion, allowing reconstruction of any specific object [S2].
*   **Surface Irregularities:** InstantNGP optimization can produce small surface irregularities. Solved by coarse-to-fine training [S2].
*   **Noisy Surfaces:** Low-level artifacts can appear. Solved by 2D normal vector regularization [S2].
*   **Janus Problem:** The model may copy the front view to the back of the object. This is a known failure mode [S2].
*   **Convergence Failure:** The model may produce a semi-transparent scene lacking well-defined geometry. This is a known failure mode [S2].

## Operating characteristics
*   **Time Complexity:** Training takes hours rather than days, due to the use of InstantNGP [S2].
*   **Memory Complexity:** Depends on the InstantNGP grid configuration (16 levels, dim 2, max res 2048) [S2].
*   **Strengths:**
    *   Reconstructs arbitrary objects from a single image without category assumptions [S2].
    *   Produces full 360° photographic models [S2].
    *   Significantly higher quality than CLIP priors [S2].
    *   2D normal regularization reduces variance and yields superior results compared to 3D regularization [S2].
*   **Limitations:**
    *   Susceptible to the Janus problem (front-back texture copying) [S2].
    *   Can fail to converge, resulting in semi-transparent scenes [S2].
    *   Requires an off-the-shelf matting model for the mask [S2].
*   **When to use:** Single-image 3D reconstruction of arbitrary objects in the wild or on benchmark datasets [S2].
*   **When not to use:** When multi-view images are available (other methods may be more robust) or when strict geometric accuracy without texture artifacts is required (due to Janus/convergence risks) [S2].

## Background
RealFusion was introduced in February 2023 [S1]. It builds upon the DreamFusion method [S2], which generates 3D models from text descriptions. RealFusion adapts this by conditioning on a single image using textual inversion [S1]. It uses Stable Diffusion as the prior and InstantNGP as the radiance field backbone [S1]. The method was evaluated on the CO3D dataset against Shelf-Supervised Mesh Prediction [S2].
