# Mip-NeRF Optimization and Activation Details

Also called: JaxNeRF Training Procedure, Mip-NeRF Misc. Changes

## Overview
This article defines the specific implementation details for training Mip-NeRF and JaxNeRF, focusing on activation functions, input encoding strategies, and learning rate scheduling. These modifications are designed to improve training stability and robustness without significantly altering the method's accuracy or speed [S1]. Unlike standard NeRF implementations that concatenate identity inputs, Mip-NeRF relies solely on Integrated Positional Encoding (IPE) and employs shifted/widened activations to prevent optimization failure modes such as zero gradients or saturation issues [S1].

## How it works

### Inputs and Outputs
*   **Inputs:** Integrated Positional Encoding (IPE) features derived from the mean and covariance of the conical frustum; normalized ray direction $\mathbf{d}$.
*   **Outputs:** Density $\tau$ and color $\mathbf{c}$.

### Data Structures
The neural network is a Multi-Layer Perceptron (MLP).
*   **Input Layer:** Receives only the IPE features. The concatenation of the original position and view direction (identity encoding) is removed [S1].
*   **View Direction Injection:** The view direction $\mathbf{d}$ is processed separately and injected into the last layer of the MLP after density $\tau$ is predicted but before color $\mathbf{c}$ is predicted [S1].

### Numbered Steps

1.  **Input Preprocessing:**
    *   Compute the Integrated Positional Encoding (IPE) for the spatial position and covariance.
    *   Normalize the ray direction: $\mathbf{d}_{norm} = \mathbf{d} / \|\mathbf{d}\|$.
    *   Apply positional encoding to $\mathbf{d}_{norm}$ with $L=4$ frequencies [S1].

2.  **Density Prediction:**
    *   Pass the IPE features through the MLP layers.
    *   Apply the **Density Activation** function to the final linear output $x_\tau$ to produce $\tau$.

3.  **View Direction Injection:**
    *   Concatenate the view direction encoding to the features at the final layer (or inject via bias/weight adjustment as per standard NeRF practice, specifically after $\tau$ is computed) [S1].

4.  **Color Prediction:**
    *   Apply the **Color Activation** function to the final linear output $x_c$ to produce $\mathbf{c}$ [S1].

5.  **Optimization Loop:**
    *   Use the Adam optimizer.
    *   Apply the specific learning rate schedule defined below.

### Formulas

**Density Activation:**
A shifted softplus function is used instead of ReLU to prevent catastrophic failure where the MLP emits negative values everywhere (which would result in zero gradients for $\tau$) [S1].
$$ \tau = \log(1 + \exp(x_\tau - 1)) $$
The shift by $-1$ is equivalent to initializing the biases producing $\tau$ to $-1$, resulting in small initial density values [S1].

**Color Activation:**
A "widened" sigmoid is used instead of the standard sigmoid to avoid optimization failure when explaining black or white pixels, which might otherwise cause the network to saturate [S1].
$$ \mathbf{c} = \frac{1 + 2\epsilon}{1 + \exp(-x_c)} - \epsilon $$
where $\epsilon = 0.001$. This function saturates slightly outside the $[0, 1]$ range [S1].

**Learning Rate Schedule:**
The learning rate $\eta_i$ at iteration $i$ combines a warmup phase and a logarithmic annealing phase [S1]:
$$ \eta_i = \left( \lambda_w + (1 - \lambda_w) \sin\left(\frac{\pi}{2} \operatorname{clip}\left(\frac{i}{n_w}, 0, 1\right)\right) \right) \times \left( \exp\left( \left(1 - \frac{i}{n}\right) \log(\eta_0) + \frac{i}{n} \log(\eta_n) \right) \right) $$
where:
*   $n_w = 2500$ is the number of warmup iterations.
*   $n$ is the total number of iterations.
*   $\lambda_w$ is annealed from $0.01$ to $1$ during the warmup period.
*   $\eta_0 = 5 \cdot 10^{-4}$ is the initial learning rate.
*   $\eta_n = 5 \cdot 10^{-6}$ is the final learning rate [S1].

### Parameters
*   **Optimizer:** Adam [S1].
*   **Batch Size:** 4096 [S1].
*   **Total Iterations:** 1,000,000 [S1].
*   **Warmup Iterations ($n_w$):** 2500 [S1].
*   **Initial Learning Rate ($\eta_0$):** $5 \cdot 10^{-4}$ [S1].
*   **Final Learning Rate ($\eta_n$):** $5 \cdot 10^{-6}$ [S1].
*   **Warmup Start Factor ($\lambda_w$ start):** 0.01 [S1].
*   **Warmup End Factor ($\lambda_w$ end):** 1 [S1].
*   **View Direction PE Levels ($L$):** 4 [S1].

### Edge Cases and Pitfalls
*   **Negative Density:** Using standard ReLU for density can lead to catastrophic failure if the MLP outputs negative values everywhere, causing zero gradients. The shifted softplus prevents this [S1].
*   **Saturation on Extremes:** Standard sigmoid saturation can cause optimization failure when trying to explain pure black or white pixels. The widened sigmoid mitigates this [S1].
*   **Correlation Insensitivity:** IPE features are insensitive to off-diagonal elements of the covariance matrix $\Sigma$ (correlation). Experiments indicate that modeling this correlation does not improve accuracy, so it is omitted [S1].

### Pseudocode

```python
import math

def density_activation(x):
    """
    Shifted softplus activation for density.
    Prevents negative density values which cause zero gradients.
    """
    return math.log(1 + math.exp(x - 1))

def color_activation(x, epsilon=0.001):
    """
    Widened sigmoid activation for color.
    Saturates slightly outside [0, 1] to handle black/white pixels.
    """
    return (1 + 2 * epsilon) / (1 + math.exp(-x)) - epsilon

def learning_rate_schedule(i, n, n_w, eta_0, eta_n):
    """
    Calculates the learning rate at iteration i.
    Combines linear warmup of a scale factor with logarithmic annealing.
    """
    # Calculate lambda_w annealing factor
    # lambda_w goes from 0.01 to 1 during warmup
    clip_val = min(max(i / n_w, 0), 1)
    lambda_w = 0.01 + (1 - 0.01) * math.sin((math.pi / 2) * clip_val)
    
    # Calculate logarithmic annealing factor
    # eta goes from eta_0 to eta_n
    log_eta = (1 - i / n) * math.log(eta_0) + (i / n) * math.log(eta_n)
    annealing_factor = math.exp(log_eta)
    
    return lambda_w * annealing_factor

def forward_pass(ipe_features, ray_direction):
    """
    Simulates the Mip-NeRF MLP forward pass with specific activation details.
    """
    # 1. Density Prediction
    # Assume mlp_density is the linear transformation for density
    x_tau = mlp_density(ipe_features)
    tau = density_activation(x_tau)
    
    # 2. View Direction Handling
    # Normalize direction
    d_norm = ray_direction / norm(ray_direction)
    # Apply positional encoding with L=4
    d_pe = positional_encoding(d_norm, levels=4)
    
    # 3. Color Prediction
    # Inject view direction into the last layer (conceptually)
    # Assume mlp_color takes IPE + view direction info
    x_c = mlp_color(ipe_features, d_pe)
    c = color_activation(x_c)
    
    return tau, c
```

## Subtopics

### [Mip-NeRF 360 Optimization Setup](3426-mip-nerf-360-optimization-setup.md)
Mip-NeRF 360 Optimization Setup defines the training configuration for unbounded neural radiance fields, specifically addressing the challenge of rendering large-scale, "in-the-wild" scenes with limited video memory. It combines a scene contraction function to warp unbounded space into a finite sphere with a multi-stage proposal sampling strategy and a specific loss formulation to ensure training stability and anti-aliasing. It sets itself apart from standard NeRF implementations by explicitly handling unbounded domains through coordinate warping and using a stop-gradient mechanism to decouple proposal network optimization from the final NeRF network.

### [Scale-Dependent Downweighting for Grid Interpolation](8571-scale-dependent-downweighting-for-grid-interpolation.md)
Scale-Dependent Downweighting is a technique to anti-alias trilinear interpolation in neural radiance fields by downweighting features interpolated from grid cells that are small relative to the sampling Gaussian's spread, preventing aliasing artifacts from high-frequency content. Unlike naive trilinear interpolation which causes aliasing at high frequencies, this method uses the Gaussian CDF to weight samples, similar to Mip-NeRF's IPE features but applied to grid-based representations.

### [S-NeRF Training Configuration](15165-s-nerf-training-configuration.md)
S-NeRF training configuration defines the specific hyperparameters, network architectures, and confidence-based loss weighting used to optimize Neural Radiance Fields for dynamic street scenes using LiDAR and RGB data. It distinguishes itself from standard NeRF variants by employing a dual-phase training loop (foreground vehicles vs. background street views) and integrating geometry/projection confidence maps to mitigate depth outliers from moving objects. This configuration builds on [Mip-NeRF Optimization and Activation Details](3409-mip-nerf-optimization-and-activation-details.md) but adds specific LiDAR-guided confidence mechanisms and distinct MLP topologies for foreground/background separation.

### Alternative Gaussian Positional Encoding
An alternative approach explored during Mip-NeRF development involves concatenating the positional encodings of the mean and the (signed) square root of the covariance matrix elements as input to the MLP [S1]. Specifically, positional encoding with $L=12$ is applied to the mean $\mu$, and positional encoding with $L=2$ is applied to $\text{vec}(\text{triu}(\text{sign}(\Sigma) \circ \rho |\Sigma|))$ [S1]. This alternative performs comparably to IPE features but is sensitive to hyperparameters $L$ and covariance parameterization, whereas IPE is hyperparameter-free and compact [S1].

### Reflected Cone Derivation
A geometric derivation used in Mip-NeRF to shift the origin of a reflected ray so that its cone radius matches the incident ray's cone radius at the intersection point, ensuring consistent view-dependent appearance for reflections [S2]. The condition for equating radii is $\dot{r}\|\bar{\mathbf{x}} - \mathbf{o}\| = \dot{r}'\|\bar{\mathbf{x}} - \mathbf{o}'\|$, where $\dot{r}$ is the incident ray radius parameter, $\bar{\mathbf{x}}$ is the intersection point, $\mathbf{o}$ is the incident ray origin, $\dot{r}'$ is the reflected ray radius parameter, and $\mathbf{o}'$ is the reflected ray origin [S2].

### RawNeRF
RawNeRF adapts Mip-NeRF for High Dynamic Range (HDR) image view synthesis and denoising by using raw linear images as training data, allowing post-processing after rendering [S3]. It renders in a linear color space and is supervised with variable exposure images, scaling the NeRF models’ “exposure” by the training image’s shutter speed, as well as a per-channel learned scaling factor [S3]. Unlike HDR-NeRF which uses LDR images, RawNeRF allows varying exposure and tone-mapping curves to be applied after NeRF rendering [S3].

## Operating characteristics

**Time and Memory Complexity:**
Mip-NeRF is 13x faster to train and 16x faster to evaluate than a brute-force supersampling baseline (16 rays/pixel) [S1]. The use of a single unified multiscale model (as opposed to separate per-scale models) contributes to this efficiency [S1].

**Measured Performance:**
On the multiscale Blender dataset, Mip-NeRF outperforms the 16x supersampling baseline in quality (PSNR, SSIM, LPIPS) while being significantly faster [S1].
*   **Training Time:** 2.79 hours (vs 37.18 hours for 16x SS) [S1].
*   **Test Time:** 2.48 sec/MP (vs 41.76 sec/MP for 16x SS) [S1].
*   **Params:** 612K (vs 1,191K for 16x SS) [S1].

**Strengths and Limitations:**
*   **Strengths:** Improved training stability due to shifted/widened activations; robustness to large learning rates during warmup; efficient multiscale handling without explicit supersampling [S1].
*   **Limitations:** The specific activation functions and learning rate schedule are empirical choices for stability; the method assumes the validity of the integrated positional encoding approximation [S1].

**When to Use:**
Use this configuration when training Mip-NeRF or JaxNeRF to ensure stable convergence and reproducibility with the original authors' results [S1].

## Background

**Origin:**
These details were introduced in the paper "Mip-NeRF: A Multiscale Representation for Anti-Aliasing Neural Radiance Fields" by Barron et al. (2021) [S1]. The specific activation functions and learning rate schedule are described in the supplementary material (Appendix E) of the paper, often referred to as "Miscellaneous Changes" [S1].

**History and Development:**
The JaxNeRF codebase provided the initial implementation framework. The authors noted that while these changes did not significantly change accuracy or speed, they simplified the method and increased robustness during optimization [S1]. The learning rate warmup strategy was adopted from JaxNeRF to ensure fair comparison across ablations [S1].

**Usage:**
This configuration is the standard for training Mip-NeRF and serves as a baseline for subsequent variants like RawNeRF [S3] and Mip-NeRF 360 [S2].
