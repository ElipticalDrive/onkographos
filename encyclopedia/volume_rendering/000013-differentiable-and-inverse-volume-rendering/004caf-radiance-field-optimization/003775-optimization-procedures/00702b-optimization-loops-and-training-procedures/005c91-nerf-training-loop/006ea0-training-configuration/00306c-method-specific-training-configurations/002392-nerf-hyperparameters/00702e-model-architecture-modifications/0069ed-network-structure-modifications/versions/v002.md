# Network Structure Modifications


## Overview
This family encompasses modifications to the Multi-Layer Perceptron (MLP) structures used to learn continuous volumetric scene representations $F_\Theta: (\mathbf{x}, \mathbf{d}) \rightarrow (\sigma, \mathbf{c})$ [G]. While the standard NeRF architecture [S1, unofficial] employs two MLPs—a Position MLP ($\Phi_{pos}$) and a Shading MLP ($\Phi_{shade}$)—these variants alter layer depths, input dimensions, activation functions, and output channels to address specific challenges such as dynamic scenes, transparency, mobile efficiency, and semantic consistency [S1, unofficial].

### [Multi-input MLP (mi-MLP)](16599-multi-input-mlp-mi-mlp.md)
The multi-input MLP (mi-MLP) is a network architecture modification for Neural Radiance Fields that incorporates the input embeddings (3D location and viewing direction) into every layer of the MLP to alleviate overfitting in few-shot view synthesis. Unlike the standard NeRF architecture [20497-network-structure-modifications.md] which passes features through a chain of layers where only the final layer explicitly consumes the directional encoding, mi-MLP ensures each layer is explicitly aware of the input embeddings, creating shorter paths between inputs and outputs. This allows the model to synthesize high-frequency details with fewer parameters while maintaining model capacity.

### Dynamic Scene Network Architecture
This architecture  divides dynamic scenes into static and dynamic components, modeled by two separate MLPs to handle time-variant scenes and motion.
**Inputs and Outputs:**
* **Dynamic Network ($F_{\Theta}^{dy}$)**:
  * Inputs: Positional encoding of position $\gamma(\mathbf{x})$, direction $\gamma(\mathbf{d})$, and time $\gamma(t)$ .
  * Outputs: Color $\mathbf{c}_t$, density $\sigma_t$, scene flow $\mathcal{F}_t$, and disocclusion weights $\mathcal{W}_t$ .
* **Static Network ($F_{\Theta}^{st}$)**:
  * Inputs: Positional encoding of position $\gamma(\mathbf{x})$ and direction $\gamma(\mathbf{d})$ .
  * Outputs: Color $\mathbf{c}$, density $\sigma$, and blending weight $v$ .
**Formulas:**
The networks are defined as :
$$
(\mathbf{c}_t, \sigma_t, \mathcal{F}_t, \mathcal{W}_t) = F_{\Theta}^{dy}(\gamma(\mathbf{x}), \gamma(\mathbf{d}), \gamma(t)) \quad (22)
$$
$$
(\mathbf{c}, \sigma, v) = F_{\Theta}^{st}(\gamma(\mathbf{x}), \gamma(\mathbf{d})) \quad (23)
$$
**Steps:**
1. Perform equidistant sampling to obtain spatial points along rays, rather than hierarchical sampling .
2. Use the predicted scene flow $\mathcal{F}_t$ to establish inter-frame relationships for time consistency .
3. Jointly optimize camera parameters ($\Delta f, \Delta P$) along with the MLPs $F_{\Theta}^{dy}$ and $F_{\Theta}^{st}$ .

### NeRF Network Architecture with Blend Weight Field
This architecture  extends the standard NeRF to model dynamic human bodies by introducing a blend weight field.
**Data Structures and Parameters:**
* **Radiance Field Networks ($F_\sigma, F_c$)**: Follow the original NeRF architecture .
* **Sampling**: Single-level NeRF, sampling 64 points along each camera ray .
* **Blend Weight Field Network ($F_{\Delta w}$)**:
  * Structure: Almost identical to $F_\sigma$ .
  * Output Layer: Has 24 channels .
  * Activation: Applies $\exp(\cdot)$ to the output .
* **Embeddings**: Appearance code $\mathbf{l}_i$ and blend weight field code $\boldsymbol{\psi}_i$ both have dimensions of 128 .
**Steps:**
1. Train parameters of $F_\sigma, F_c, F_{\Delta w}, \{\mathbf{l}_i\}$, and $\{\boldsymbol{\psi}_i\}$ jointly over the input video .
2. Learn neural blend weight fields under novel human poses using the transformed mesh vertices .

### MobileNeRF Architectures (A, F, H)
MobileNeRF [S1, unofficial] modifies the standard architecture to exploit the polygon rasterization pipeline for mobile efficiency.
**Parameters:**
* **MLPs A and F**: Use the MLP design from NeRF, but hidden layer sizes are increased from 256 to 384 [S1, unofficial].
* **MLP H**: Uses the small MLP from SNeRG, consisting of two hidden layers, each with 16 neurons [S1, unofficial].
* **Inference Constraint**: MLPs A and F are not used during inference, allowing for larger training-time computation [S1, unofficial].

### OccNet (Single-Level NeRF)
OccNet  represents a single-level version of NeRF that does not leverage positional encodings.
**Performance Metrics:**
* **2D Images**: 13.90 PSNR / 0.437 SSIM .
* **Radiance Field**: 20.60 PSNR / 0.849 SSIM .
* **Training Time**: 02:17 (2D) / 100:23 (Radiance Field) .
* **Model Size**: 0.38 (2D) / 0.43 (Radiance Field) .

### Residual-NeRF-S
Residual-NeRF-S  is an ablation variant of Residual-NeRF where background and residual NeRFs are merged by simply adding their outputs before activation, instead of using a Mixnet.
**Formulas:**
The rendering equation for Residual-NeRF-S is :
$$
\hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - \exp(-(\sigma_{bg} + \sigma_{res})_i \delta_i)) (c_{bg+res})_i
$$
where:
$$
c_{bg+res} = S(c'_{bg} + c'_{res})
$$
$$
(c'_{bg}, \sigma_{bg}) = \Phi_{bg}(h(\mathbf{x}, y, z, \theta, \phi))
$$
$$
(c'_{res}, \sigma_{res}) = \Phi_{res}(h(\mathbf{x}, y, z, \theta, \phi))
$$
$$
S(\mathbf{x}) = \frac{1}{1 + e^{-\mathbf{x}}}
$$
Here, $S(\cdot)$ is the sigmoid activation function applied element-wise to the sum of the background and residual color predictions before the final volume rendering integration .

### NeRF Model Architecture
#### definition
- [S1, unofficial] The neural network architecture for NeRF, consisting of dense layers with ReLU activations, potentially using view directions as input.
#### parameter
- [S1, unofficial] `D`: The depth of the network (number of hidden layers). Default is 8.
- [S1, unofficial] `input_ch_views`: The number of input channels for view directions. Default is 3.
- [S1, unofficial] `output_ch`: The number of output channels. Default is 4 (RGB + density).
- [S1, unofficial] `use_viewdirs`: Boolean flag to determine if view directions are used as input to the network.

## Background
The standard NeRF architecture [S1, unofficial] serves as the reference point for most modifications. It employs two MLPs:
1. **Position MLP ($\Phi_{pos}$)**: Takes spatial position $\mathbf{x}$ and its positional encoding $\gamma(\mathbf{x})$ to produce a feature vector $\mathbf{h}$ [G].
2. **Shading MLP ($\Phi_{shade}$)**: Takes $\mathbf{h}$ and viewing direction $\mathbf{d}$ with its encoding $\gamma(\mathbf{d})$ to predict volume density $\sigma$ and view-dependent color $\mathbf{c}$ [G].
