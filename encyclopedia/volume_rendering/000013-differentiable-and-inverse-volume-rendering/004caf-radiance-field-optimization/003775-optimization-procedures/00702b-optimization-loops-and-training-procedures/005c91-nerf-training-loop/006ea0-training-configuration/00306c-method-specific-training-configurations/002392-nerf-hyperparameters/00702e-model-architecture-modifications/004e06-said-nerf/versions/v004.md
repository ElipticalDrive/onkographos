# SAID-NeRF

Also called: Segmentation-AIDed NeRF

## Overview
SAID-NeRF is a semantic radiance field method that exploits instance masks generated by Visual Foundation Models (VFMs) to enhance NeRF’s estimation of surfaces for transparent objects, which are otherwise ambiguous when relying purely on RGB data [S1]. It differs from standard NeRF and its siblings by jointly optimizing a semantic field to enforce view-independent surface densities, thereby producing sharper depth estimates and diffuse colors suitable for robotic grasping, rather than merely capturing view-dependent specular appearance [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** $N$ RGB-D images $\{I_k, D_k\}$ with known camera poses, and a target number of semantic classes $C$ (typically $\le 3$) [S1].
*   **Outputs:** A trained implicit function $F_\Theta$ mapping 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$ to density $\sigma$, diffuse color $\mathbf{c}_d$, specular color $\mathbf{c}_s$, and semantic logits $\mathbf{s}$; rendered RGB images, depth maps, and semantic masks [S1].

**Data Structures:**
The model uses a Multiresolution Hash Encoding (MHE) for position $\mathbf{x}$ [S1].
*   **Position Encoding:** The raw coordinates $\mathbf{x}$ are processed by a frequency embedding (concatenated with MHE features) and passed through a position encoding MLP (1 layer, width 16) [S1].
*   **Direction Encoding:** The viewing direction $\mathbf{d} = (\theta, \phi)$ is projected using Spherical Harmonics (SH) basis functions [S1].
*   **MLP Heads:**
    *   **Density Head:** Takes encoded position features to output volume density $\sigma$ [S1].
    *   **Diffuse Color MLP:** Takes encoded position features to output view-independent diffuse color $\mathbf{c}_d$ [S1].
    *   **Specular Color MLP:** Takes encoded position features and SH-encoded direction $\mathbf{d}$ to output view-dependent specular color $\mathbf{c}_s$ [S1].
    *   **Semantic Head:** Takes encoded position features to output a vector of length $C$ representing semantic logits $\mathbf{s}$ [S1].

**Numbered Steps:**

1.  **Mask Generation:** Use a Visual Foundation Model (e.g., SAM) to generate instance masks for the scene [S1]. If objects are overlapping or cluttered, apply a hierarchical grouping heuristic (Algorithm 1) to create a small set of non-overlapping semantic masks consistent across views [S1].
2.  **Ray Sampling:** For each pixel, generate a ray $r$ from the camera center [S1]. Sample $N$ points $x_i$ along the ray between near $t_{near}$ and far $t_{far}$ planes [S1].
3.  **Feature Query:** For each sample point $x_i$:
    *   Query the MHE and position encoding MLP to get position features [S1].
    *   Query the density head to get $\sigma_i$ [S1].
    *   Query the diffuse color MLP to get $\mathbf{c}_{d,i}$ [S1].
    *   Query the specular color MLP with $\mathbf{d}$ to get $\mathbf{c}_{s,i}$ [S1].
    *   Query the semantic head to get logits $\mathbf{s}_i$ [S1].
4.  **Color Decomposition:** Compute the total color $c_i$ for each sample:
    $$ c_i = \mathbf{c}_{d,i} + \mathbf{c}_{s,i} $$
    A small L2 penalty is applied to $\mathbf{c}_{s,i}$ during training to encourage diffuse components [S1].
5.  **Volume Rendering (Color):** Compute the expected color $\hat{C}(r)$ using standard volume rendering integration:
    $$ \hat{C}(r) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) c_i $$
    where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance, $\delta_i = t_{i+1} - t_i$ is the distance between samples, and $c_i$ is the color at sample $i$ [S1].
6.  **Volume Rendering (Depth):** Compute the expected depth $\hat{D}(r)$:
    $$ \hat{D}(r) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) t_i $$
    where $t_i$ is the position along the ray [S1].
7.  **Volume Rendering (Semantic):** Compute the expected semantic probability $\hat{S}_k(r)$ for class $k$:
    $$ \hat{S}_k(r) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) \text{softmax}(\mathbf{s}_i)_k $$
    The semantic head leverages density assignments to enforce higher surface densities for transparent objects, correcting the ambiguity where transparent surfaces contribute little to RGB color but should have high density for depth accuracy [S1].
8.  **Loss Computation:**
    *   **RGB Loss:** L1 loss between $\hat{C}(r)$ and ground-truth RGB $C_{gt}$ [S1].
    *   **Semantic Loss:** Binary cross-entropy loss between $\hat{S}(r)$ and the generated semantic masks $S_{gt}$ [S1].
    *   **Depth Loss:** L2 loss between $\hat{D}(r)$ and ground-truth depth $D_{gt}$ from the RGB-D camera [S1].
    *   **Specular Penalty:** L2 penalty on $\mathbf{c}_s$ [S1].
9.  **Optimization:** Update parameters $\Theta$ to minimize the total loss [S1]. Training is capped at a time limit $T$ (e.g., 20 seconds for robotic tasks, 60 seconds for datasets) rather than a fixed step count [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def mhe_encode(x, mhe_dim=256):
    # Multiresolution Hash Encoding: maps 3D coords to mhe_dim features
    # Standard implementation uses hash tables and trilinear interpolation
    return torch.randn_like(x)[:, :mhe_dim]

def sh_encode(d, degree=4):
    # Spherical Harmonics encoding of direction d
    # Projects d onto SH basis functions
    return torch.randn(d.shape[0], (degree + 1) ** 2)

def freq_embed(x, num_freqs=10):
    # Frequency embedding: concatenates sin/cos of scaled coordinates
    scales = 2.0 ** torch.arange(num_freqs, device=x.device).float()
    x = x.unsqueeze(-1) * scales.unsqueeze(0)
    return torch.cat([torch.sin(x), torch.cos(x)], dim=-1)

class SAIDNeRF(nn.Module):
    def __init__(self, num_semantic_classes=3, mhe_dim=256):
        super().__init__()
        self.mhe_dim = mhe_dim
        self.pos_mlp = nn.Linear(mhe_dim + 2 * 10, 16) # +20 for freq_embed
        self.sh_degree = 4
        self.dir_dim = (self.sh_degree + 1) ** 2
        self.density_head = nn.Linear(16, 1)
        self.diffuse_head = nn.Linear(16, 3)
        self.specular_head = nn.Sequential(
            nn.Linear(16 + self.dir_dim, 16),
            nn.ReLU(),
            nn.Linear(16, 3)
        )
        self.semantic_head = nn.Sequential(
            nn.Linear(16, 32),
            nn.ReLU(),
            nn.Linear(32, num_semantic_classes)
        )

    def forward(self, x, d):
        # x: (..., 3), d: (..., 3)
        mhe_feat = mhe_encode(x, self.mhe_dim)
        freq_feat = freq_embed(x, num_freqs=10)
        pos_input = torch.cat([mhe_feat, freq_feat], dim=-1)
        pos_encoded = self.pos_mlp(pos_input)

        dir_encoded = sh_encode(d, self.sh_degree)

        sigma = self.density_head(pos_encoded).squeeze(-1)
        c_diffuse = self.diffuse_head(pos_encoded)
        c_specular = self.specular_head(torch.cat([pos_encoded, dir_encoded], dim=-1))
        semantic_logits = self.semantic_head(pos_encoded)

        return sigma, c_diffuse, c_specular, semantic_logits

def render_ray(ray_origin, ray_direction, near, far, num_samples, nerf_model):
    t_vals = torch.linspace(near, far, num_samples)
    points = ray_origin.unsqueeze(1) + t_vals.unsqueeze(0) * ray_direction.unsqueeze(1)

    sigma, c_diffuse, c_specular, semantic_logits = nerf_model(points, ray_direction)

    deltas = t_vals[1:] - t_vals[:-1]
    delta_inf = torch.tensor(1e10)
    deltas = torch.cat([deltas, delta_inf])

    alpha = 1.0 - torch.exp(-sigma * deltas)
    # T_i = exp(-sum_{j=1}^{i-1} sigma_j * delta_j)
    transmittance = torch.cumprod(torch.exp(-sigma * deltas), dim=0)
    T = torch.cat([torch.ones_like(transmittance[:1]), transmittance[:-1]])

    c_total = c_diffuse + c_specular
    weights = T * alpha
    rendered_color = torch.sum(weights.unsqueeze(-1) * c_total, dim=0)
    rendered_depth = torch.sum(weights * t_vals, dim=0)

    semantic_probs = torch.softmax(semantic_logits, dim=-1)
    rendered_semantic = torch.sum(weights.unsqueeze(-1) * semantic_probs, dim=0)

    return rendered_color, rendered_depth, rendered_semantic
```

**Parameters:**
*   **Semantic Classes ($C$):** Number of semantic labels. Empirically kept low ($\le 3$) [S1].
*   **Training Time Limit ($T$):** 20 seconds for robotic experiments, 60 seconds for ClearPose dataset [S1].
*   **MLP Widths:** Position encoding MLP width 16; Segmentation MLP widths 32 (2 layers) [S1].
*   **Loss Weights:** L1 for RGB, Binary Cross-Entropy for Semantic, L2 for Depth, small L2 penalty on specular term [S1].

**Edge Cases and Pitfalls:**
*   **Transparent Objects:** Standard NeRF fails to recover geometry for transparent objects because they contribute little to RGB color, leading to diffuse densities and incorrect depth [S1]. SAID-NeRF mitigates this by using semantic masks to enforce high density at the object surface [S1].
*   **Floaters:** Patternless or single-colored backgrounds can cause "floaters" (spurious geometry) [S1]. Adding frequency embedding to the MHE helps avoid this by providing an inductive bias towards preferring plane-like surface reconstructions due to positional encoding embedding regions with element-wise coordinates [S1].
*   **Mask Consistency:** The hierarchical mask generation heuristic (Algorithm 1) is imprecise but robust enough if $C$ is small and faulty assignments are compensated by other views [S1].
*   **RGB-D Limitations:** Depth supervision uses L2 loss on RGB-D camera data, which may be noisy or missing for transparent objects, but is still vital for scenes without significant background patterns [S1].

## Subtopics

### Hierarchical Mask Generation
A heuristic to group SAM-generated instance masks into a consistent set of non-overlapping semantic classes across views, enabling label-free training [S1].

### Semantic Radiance Field
The joint optimization of semantic and radiance fields, where semantic supervision guides density estimation to improve depth accuracy for transparent surfaces [S1].

## Operating characteristics
*   **Time Complexity:** Training is extremely fast, capped at seconds (20-60s) rather than minutes or hours, enabled by Multiresolution Hash Encoding (Instant-NGP base) and limited training duration [S1].
*   **Memory Complexity:** Uses Multiresolution Hash Encoding, which is memory-efficient compared to dense voxel grids or large MLPs [S1].
*   **Performance:** Outperforms vanilla Instant-NGP with as few as 4 images or <10 seconds of training [S1]. Effective for depth completion of transparent objects and robotic grasping [S1].
*   **Strengths:** Robust to view-dependent specular effects; works with few views; fast training suitable for real-time robotic applications; leverages zero-shot VFMs (SAM) for supervision [S1].
*   **Limitations:** Relies on the quality of SAM masks; hierarchical grouping is imprecise; depth supervision relies on RGB-D cameras which may fail on transparent objects (though the method still benefits from the signal) [S1].
*   **When to Use:** Robotic grasping of transparent objects; depth completion where RGB-only NeRF fails due to transparency; scenarios requiring fast reconstruction from few views [S1].
*   **When Not to Use:** When the primary goal is high-fidelity visual synthesis of specular effects rather than geometric depth estimation for robotic tasks [S1].

## Background
SAID-NeRF was proposed to address the challenge of acquiring accurate 3D information of transparent objects for robotics, where standard NeRFs fail to recover true shape due to specular effects and transparency [S1]. It builds on Instant-NGP [8] and leverages Visual Foundation Models (VFMs) like SAM [S1]. The method aims to overcome the long training times of previous methods like Dex-NeRF [10] and the geometric inaccuracies of standard NeRFs [S1].
