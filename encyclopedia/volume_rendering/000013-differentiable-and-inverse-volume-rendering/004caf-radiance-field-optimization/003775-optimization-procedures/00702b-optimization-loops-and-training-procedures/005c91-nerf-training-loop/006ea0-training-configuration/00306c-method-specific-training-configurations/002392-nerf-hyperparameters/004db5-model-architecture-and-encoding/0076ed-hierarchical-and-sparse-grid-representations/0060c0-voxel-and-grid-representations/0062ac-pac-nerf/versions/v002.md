# PAC-NeRF

Also called: Physics Augmented Continuum Neural Radiance Fields

## Overview
PAC-NeRF is a method for geometry-agnostic system identification that estimates both the unknown 3D geometry and physical parameters (e.g., Young’s modulus, viscosity) of highly dynamic objects from multi-view videos [S1, unofficial]. It differs from standard dynamic NeRFs by enforcing continuum mechanics conservation laws via a hybrid Eulerian-Lagrangian representation, using the Material Point Method (MPM) as a prescriptive, differentiable physics simulator rather than learning dynamics from scratch [S1, unofficial]. This approach enables robust handling of topology changes and frictional contacts while accelerating rendering through voxel discretization [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of posed multi-view video frames $\{\hat{C}(r, t_i)\}$ of a dynamic scene, where $r$ is a ray and $t_i$ is time.
*   **Output:** An explicit geometric representation (voxel grid) and physical parameters (e.g., material constants) that minimize the difference between rendered and observed images.

**Data Structures:**
The method uses a hybrid Eulerian-Lagrangian representation [S1, unofficial]:
1.  **Eulerian Grid:** Stores the NeRF fields. Based on the parent [Voxel and Grid Representations](18218-voxel-and-grid-representations.md), this consists of:
    *   **Density Grid ($\mathbf{V}_\sigma$):** Tensor of shape $\mathbb{R}^{H \times W \times D}$ storing volume density $\sigma(x, t)$.
    *   **Feature Grid ($\mathbf{V}_a$):** Tensor storing latent appearance features per voxel, used to predict color $c(x, \omega, t)$.
2.  **Lagrangian Particles:** A set of particles that advect the fields. Each particle carries state information (position, velocity) and is associated with grid values via interpolation weights.

**Query Mechanism:**
For a query point $\mathbf{x}$ in world space, grid values are retrieved via trilinear interpolation [S1, unofficial]:
$$ f(\mathbf{x}) = \text{interp}(\mathbf{x}, \mathbf{V}_a) $$
This operation is differentiable, allowing gradients to flow back to the grid values during optimization [S1, unofficial]. The color is decoded as:
$$ \mathbf{c}(\mathbf{x}) = S_\Theta(\text{interp}(\mathbf{x}, \mathbf{V}_a)) $$
where $S_\Theta$ is a decoding function (typically an MLP) [S1, unofficial].

**Numbered Steps:**
1.  **Initialization:** Initialize the Eulerian voxel NeRF for density $\sigma$ and color $c$ fields on a fixed grid [S1, unofficial]. Initialize physical parameters (e.g., Young’s modulus) and particle positions.
2.  **Particle Binding:** Bind renderable quantities (density, color) to Lagrangian particles via a sampling scheme. This involves transferring grid values to particles using Particle-to-Grid (P2G) interpolation [S1, unofficial].
3.  **Physics Simulation:** Simulate particle dynamics using a differentiable Material Point Method (MPM) [S1, unofficial]. The velocity field $\mathbf{v}$ evolves according to momentum conservation:
    $$ \frac{D\mathbf{v}}{Dt} = \frac{1}{\rho}\nabla \cdot \mathbf{T} + \mathbf{g} $$
    where $\rho$ is physical density, $\mathbf{T}$ is the internal Cauchy stress tensor, and $\mathbf{g}$ is gravity [S1, unofficial].
4.  **Grid Update (G2P):** Convert particle states back to the Eulerian grid via Grid-to-Particle (G2P) transforms. This advects the density and color fields according to the material derivative conservation law:
    $$ \frac{D\phi}{Dt} = \frac{\partial \phi}{\partial t} + \mathbf{v} \cdot \nabla \phi = 0 $$
    for fields $\phi \in \{\sigma, c\}$ [S1, unofficial].
5.  **Rendering:** Render images from the updated Eulerian voxel NeRF using the volume rendering integral [S1, unofficial]:
    $$ C(r, t) = \int_{s_n}^{s_f} T(s, t) \sigma(r(s), t) c(r(s), \omega, t) ds + c_{bg} T(s_f, t) $$
    where $T(s, t) = \exp\left(-\int_{s_n}^{s} \sigma(r(\bar{s}), t) d\bar{s}\right)$ [S1, unofficial].
6.  **Loss Computation:** Compute the rendering loss against ground truth video frames [S1, unofficial]:
    $$ \mathcal{L}_{render} = \frac{1}{N} \sum_{i=0}^{N-1} \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \| C(r, t_i) - \hat{C}(r, t_i) \|^2 $$
    where $N$ is the number of frames and $\mathcal{R}$ is the set of rays [S1, unofficial].
7.  **Optimization:** Optimize geometry (grid values) and physical parameters via gradient-based optimization (e.g., Adam) [S1, unofficial].

        self.V_sigma = nn.Parameter(torch.randn(grid_size))

**Parameters:**
*   **Physical Parameters:** Young’s modulus, fluid viscosity, friction angles, etc. [S1, unofficial].
*   **Grid Resolution:** $H \times W \times D$ [S1, unofficial].
*   **Number of Particles:** Determined by the sampling scheme [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Topology Changes:** Standard mesh-based methods fail here; PAC-NeRF uses MPM to naturally handle topology changes and frictional contacts [S1, unofficial].
*   **Unknown Geometry:** The method does not require watertight mesh representations or known object geometries [S1, unofficial].
*   **Precision:** The differentiable MPM implementation must ensure stable gradients for the stress tensor $\mathbf{T}$ and material derivative calculations [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Accelerates NeRF rendering by two orders of magnitude compared to standard dynamic NeRFs due to the Eulerian voxel representation [S1, unofficial].
*   **Memory Complexity:** Depends on the voxel grid size ($H \times W \times D$) and the number of particles. The hybrid representation requires storing both grid fields and particle states.
*   **Strengths:** Data-efficient, interpretable dynamics, handles a vast range of materials (elastic bodies, plasticine, sand, Newtonian/non-Newtonian fluids), and does not assume object geometry or topology [S1, unofficial].
*   **Limitations:** Requires a differentiable physics simulator (MPM) implementation. Performance may degrade if the MPM approximation is poor for specific material behaviors not covered by the chosen constitutive model.
*   **When to Use:** When estimating physical properties and geometry from multi-view videos of deformable objects where traditional NeRFs fail to capture physical plausibility or require excessive data.
*   **When Not to Use:** For static scenes or scenes where dynamics are not governed by continuum mechanics (e.g., rigid body collisions without deformation).

## Background
PAC-NeRF was introduced in 2023 by researchers aiming to solve the long-standing challenge of inferring geometric and physical properties from visual observations without assuming object geometry [S1, unofficial]. It builds on the concept of Neural Radiance Fields (NeRF) [Mildenhall et al., 2020] and dynamic NeRF variants (e.g., D-NeRF) [Pumarola et al., 2021; Tretschk et al., 2021; Park et al., 2021], but differs by employing a differentiable physics simulator (MPM) [Jiang et al., 2015; Hu et al., 2020] as a prescriptive dynamics model. This approach addresses the data inefficiency and lack of interpretability in learning dynamics from scratch [S1, unofficial]. It is validated on elastic bodies, plasticine, sand, and fluids [S1, unofficial].
