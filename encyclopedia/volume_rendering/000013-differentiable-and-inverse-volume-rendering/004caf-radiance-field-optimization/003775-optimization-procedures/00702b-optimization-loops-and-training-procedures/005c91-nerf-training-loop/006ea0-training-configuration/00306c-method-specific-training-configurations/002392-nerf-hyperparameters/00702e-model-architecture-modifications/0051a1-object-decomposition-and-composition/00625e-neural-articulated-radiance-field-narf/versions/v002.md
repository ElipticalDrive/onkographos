# Neural Articulated Radiance Field (NARF)
Also called: NARFP, Part-Wise NARF

## Overview
Neural Articulated Radiance Field (NARF) is a method for modeling articulated objects by decomposing them into rigid parts, each represented by a separate Rigidly Transformed Neural Radiance Field (RT-NeRF) [S1]. It solves the problem of part dependency and implicit transformation learning found in earlier unified NeRF approaches by explicitly estimating rigid transformations via forward kinematics [S1]. Unlike siblings such as [Fig-NeRF](12006-fig-nerf.md) which may use implicit pose encoding, NARF ensures each part maintains a consistent radiance field under different 3D pose configurations by combining part-wise estimates using a differentiable softmax weighting scheme [S1].

## How it works
**Inputs:**
- Pose-annotated images of an articulated object.
- A kinematic model defining the object's structure, including the number of rigid parts $P$, the kinematic tree, and the initial pose parameters (root transform $T_0$, joint angles $\zeta$, and other pose variables $\theta$) [S1].

**Outputs:**
- Rendered color images $C(\mathbf{r})$ for novel views and poses.
- Optional foreground mask $M(\mathbf{r})$ and part segmentation masks $\mathbf{S}^i(\mathbf{r})$ [S1].

**Data Structures:**
- **RT-NeRF Models:** For each part $i \in \{1, \dots, P\}$, a separate neural network $F_{\Theta^i}^{l^i, \boldsymbol{\zeta}}$ is trained. The network takes encoded local position $\gamma(\mathbf{x}^{l^i})$, encoded local viewing direction $\gamma(\mathbf{d}^{l^i})$, encoded shape variation $\gamma(\boldsymbol{\xi}^i)$, and encoded global pose $\gamma(\boldsymbol{\zeta})$ as inputs [S1].
- **Global Density and Color:** Combined values $\sigma$ and $c$ derived from the $P$ part estimates [S1].

**Steps:**

1.  **Compute Global Rigid Transformations:**
    For each rigid part $i$, compute the global rigid transformation $l_i = \{R^i, \mathbf{t}^i\}$ using forward kinematics based on the current pose configuration $\{T_0, \zeta, \theta\}$ [S1].

2.  **Transform Coordinates:**
    For a global 3D location $\mathbf{x}$ and viewing direction $\mathbf{d}$, compute the local coordinates for each part $i$:
    $$ \mathbf{x}^i = (R^i)^{-1}(\mathbf{x} - \mathbf{t}^i) $$
    $$ \mathbf{d}^i = (R^i)^{-1}\mathbf{d} $$
    [S1]

3.  **Query Part-Wise RT-NeRFs:**
    For each part $i$, query the corresponding RT-NeRF to obtain density $\sigma^i$ and color $c^i$:
    $$ (\sigma^i, \mathbf{h}^i) = F_{\Theta^i}^{l^i, \boldsymbol{\zeta}}(\gamma(\mathbf{x}^{l^i}), \gamma(\mathbf{d}^{l^i}), \gamma(\boldsymbol{\xi}^i), \gamma(\boldsymbol{\zeta})) $$
    $$ c^i = \text{ColorNetwork}(\mathbf{h}^i) $$
    [S1] (Note: The source defines the joint output as $(c^i, \sigma^i)$ in Eq. 14, implying color is derived from the intermediate feature $\mathbf{h}$ or the network outputs both).

4.  **Combine Densities and Colors:**
    Combine the estimates from all $P$ parts into a single global density $\sigma$ and color $c$ using a differentiable weighted sum via softmax over the densities, controlled by temperature parameter $\tau$:
    $$ \sigma = \frac{\sum_{i=1}^P \exp(\sigma^i/\tau)\sigma^i}{\sum_{i=1}^P \exp(\sigma^i/\tau)} $$
    $$ c = \frac{\sum_{i=1}^P \exp(\sigma^i/\tau)c^i}{\sum_{i=1}^P \exp(\sigma^i/\tau)} $$
    [S1]

5.  **Volume Rendering:**
    Perform standard volume rendering using the combined density $\sigma$ and color $c$ to generate the rendered color $C(\mathbf{r})$ for a camera ray $\mathbf{r}$:
    $$ C(\mathbf{r}) = \sum_{j=1}^N T_j c_j (1 - \exp(-\sigma_j \delta_j)) $$
    where $T_j = \exp(-\sum_{k=1}^{j-1} \sigma_k \delta_k)$ is the accumulated transmittance, $\delta_j$ is the distance between samples, and $N$ is the number of samples along the ray [S1].

6.  **Optional Mask Estimation:**
    Estimate the foreground mask $M(\mathbf{r})$ as the integral of opacity along the ray:
    $$ M(\mathbf{r}) = \sum_{j=1}^N T_j (1 - \exp(-\sigma_j \delta_j)) $$
    [S1]

**Parameters:**
- $\tau$: Temperature parameter for the softmax function. Typical values are not specified in the sources. [S1]

**Edge Cases and Pitfalls:**
- **Non-differentiable Max:** Using a max operation to select the highest density part is not differentiable, preventing gradient flow to all RT-NeRF models during training. The softmax approximation is used to resolve this [S1].
- **Zero Density Dominance:** Training is dominated by zero-density point samples because a surface point belongs to only one part, resulting in zero density for all other parts. This can lead to inefficient training as parts with small densities do not significantly affect the final value but still require computation [S1].
- **Computational Cost:** The computational cost is proportional to the number of object parts $P$, which limits the representation capacity for complex articulated objects with many parts [S1].

## Subtopics

### Holistic NARF
Holistic NARF (NARFH) combines the inputs of the RT-NeRF models from Part-Wise NARF and feeds them as a whole into a single NeRF model for direct regression of final density and color [S1]. Unlike Part-Wise NARF, NARFH does not satisfy Part Dependency because all parameters are considered for each 3D location, and object part segmentation masks cannot be generated using the part-wise selection equation [S1]. However, NARFH has computational cost almost constant to the number of object parts and naturally avoids the zero density problem [S1].

## Operating characteristics
- **Time Complexity:** Proportional to the number of object parts $P$ for Part-Wise NARF, as each part's RT-NeRF must be queried for every sample point [S1]. Holistic NARF has computational cost almost constant to the number of object parts [S1].
- **Memory Complexity:** Requires storing $P$ separate RT-NeRF models for Part-Wise NARF. Holistic NARF stores a single unified model [S1].
- **Strengths:** Avoids part dependency and implicit transformation issues by using explicit forward kinematics. Enables novel view synthesis, depth estimation, and body part segmentation [S1].
- **Limitations:** High computational cost for Part-Wise NARF with many parts. Training inefficiency due to zero-density samples [S1]. Holistic NARF loses part segmentation capability [S1].
- **When to use:** When explicit control over articulated parts is required and the number of parts is small enough to manage computational cost. When part segmentation is needed, Part-Wise NARF is preferred; for efficiency with many parts, Holistic NARF is better.

## Background
NARF was introduced in the paper "Neural Articulated Radiance Field" [S1]. It builds on the concept of RT-NeRF and addresses limitations in previous methods like P-NeRF which suffered from part dependency issues [S1]. The method is trained via pose-annotated images, decomposing articulated objects into rigid parts with local coordinate systems and global shape variations [S2, unofficial]. It is used for rendering novel views by manipulating poses, estimating depth maps, and performing body parts segmentation [S2, unofficial].
