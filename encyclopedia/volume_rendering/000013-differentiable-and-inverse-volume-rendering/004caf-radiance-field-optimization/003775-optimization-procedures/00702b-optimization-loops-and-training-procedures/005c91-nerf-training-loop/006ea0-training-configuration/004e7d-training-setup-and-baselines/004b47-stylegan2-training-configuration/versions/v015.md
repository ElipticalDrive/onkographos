# StyleGAN2 Training Configuration

Also called: StyleGAN2 Training Setup

## Overview
This configuration adapts the StyleGAN2 architecture for training 3D-aware image synthesis models (such as StyleNeRF) by integrating specific discriminator and regularization techniques. It differs from standard NeRF training setups by employing equalized learning rates, minibatch standard deviation in the discriminator, and sparse R1 regularization to stabilize GAN training while reducing memory overhead. It explicitly excludes path regularization and style-mixing, which are common in standard StyleGAN2 but omitted here to reduce computational cost.

## How it works
The method defines the training loop parameters, regularization strategies, and architectural modifications for the discriminator and generator.

**Inputs:**
- Generator weights (initially random or pretrained).
- Discriminator weights.
- Minibatch of images.
- Hyperparameters: $\gamma$ (R1 strength), $\eta_{fg}$ (foreground learning rate ratio), $\eta_{bg}$ (background learning rate ratio).

**Outputs:**
- Updated generator and discriminator weights.
- Trained 3D-aware representation.

**Data Structures:**
- **Generator:** Standard StyleGAN2 generator structure with equalized learning rates applied to trainable parameters.
- **Discriminator:** StyleGAN2 discriminator with conditional input and skip connections for progressive growing. Includes a minibatch standard deviation layer at the output.

**Steps:**
1. **Learning Rate Scaling:** Apply equalized learning rates to all trainable parameters in the generator and discriminator. This scales the learning rate by the inverse square root of the number of weights in the layer [S1].
2. **Discriminator Architecture:**
   - Use a conditional discriminator where the input includes class labels or other conditioning information [S1].
   - Implement skip connections for progressive growing: add a downsampled version of the input image to the input of each layer [S1].
   - Append a minibatch standard deviation layer at the end of the discriminator to compute the standard deviation across the batch dimension and concatenate it as a channel [S1].
3. **Regularization:**
   - Apply R1 regularization to the discriminator. The regularization term is defined as $\gamma \|\nabla_{\mathbf{x}} D(\mathbf{x})\|^2$, where $D$ is the discriminator output and $\mathbf{x}$ is the input image [S1].
   - Compute R1 regularization once every 4 minibatches to reduce computational cost [S1].
   - Do not apply path regularization or style-mixing [S1].
4. **Weight Averaging:** Apply exponential moving average (EMA) to the generator weights during training to stabilize the output [S1].
5. **Mixed Precision:** Use mixed-precision training (FP16/FP32) for both generator and discriminator to accelerate training and reduce memory usage [S1].
6. **Foreground/Background Learning Rate Adjustment:** Adjust the learning rate for foreground and background components based on dataset characteristics. Set $\eta_{fg} = 0.4$ for AFHQ and FFHQ, and $\eta_{fg} = 0.1$ for Carla. Set $\eta_{bg} = 0.1$ for all datasets [S1].

**Parameters:**
- R1 regularization strength ($\gamma$): 1 [S1].
- R1 regularization frequency: Every 4 minibatches [S1].
- Foreground learning rate ratio ($\eta_{fg}$): 0.4 (AFHQ, FFHQ), 0.1 (Carla) [S1].
- Background learning rate ratio ($\eta_{bg}$): 0.1 [S1].

**Edge Cases and Pitfalls:**
- **Small Datasets:** For small datasets like AFHQ, finetune a generator pretrained on FFHQ. Use initial resolution $R_I = 128$ and generator resolution $R_G = 32$ before pruning the representation [S1].
- **Precision:** Ensure that the skip connections in the discriminator are properly downsampled to match the feature map dimensions at each layer [S1].

## Subtopics

### Conditional Discriminator with Skip Connections for Progressive Growing
A variant of the discriminator architecture used in this configuration. It uses conditional input and implements skip connections that add a downsampled version of the input image to the input of each layer. This facilitates progressive growing, allowing the model to start training at low resolution and gradually increase it. This setup is chosen when using progressive growing strategies to stabilize training and improve image quality [S1].

## Operating characteristics
- **Time Complexity:** R1 regularization is applied every 4 minibatches, reducing the computational overhead compared to applying it every step. Mixed precision training further accelerates convergence.
- **Memory Complexity:** R1 regularization is memory-intensive; applying it every 4 minibatches reduces peak memory usage. Mixed precision also reduces memory footprint.
- **Strengths:** Stabilizes GAN training through equalized learning rates and minibatch standard deviation. Reduces computational cost via sparse R1 regularization and mixed precision.
- **Limitations:** Requires careful tuning of learning rate ratios for foreground and background components. Small datasets require pretrained initialization.
- **When to Use:** Suitable for training 3D-aware generative models where stability and memory efficiency are critical.
- **When Not to Use:** Not suitable if path regularization or style-mixing is required for specific artistic effects.

## Background
This configuration is based on the StyleGAN2 architecture [S1]. It was adapted for 3D-aware image synthesis in works such as StyleNeRF and VoxGRAF. The use of equalized learning rates and minibatch standard deviation is derived from the original StyleGAN2 paper [S1]. The omission of path regularization and style-mixing is a modification to reduce computational cost [S1]. The R1 regularization strategy is adapted from previous GAN training practices [S1].
