# VisionNeRF

Also called: Vision Transformer for NeRF

## Overview
VisionNeRF is a novel view synthesis method that infers a 3D radiance field from a single unposed input image by combining global features learned from a Vision Transformer (ViT) and local appearance features extracted from a 2D CNN [S1]. It solves the problem of rendering quality degradation in occluded regions, where standard image-conditioned models (like PixelNeRF) incorrectly query features from visible surfaces that do not correspond to the target view's geometry [S1]. Unlike sibling methods that rely on per-scene optimization or latent codes, VisionNeRF uses an explicit mapping between input image pixels and 3D point queries, enabling generalization across object categories without requiring camera pose information [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A single unposed RGB image $I_s$ at camera $s$. No camera pose information is required [S1].
*   **Output:** A rendered RGB image for a target viewpoint defined by a ray origin $\mathbf{o}$ and direction $\mathbf{d}$ [S1].

**Data Structures:**
1.  **Global Feature Maps:** Multi-level feature maps $\mathbf{F}_{global}$ generated by unflattening and resampling ViT tokens. These capture global context in a coarse-to-fine manner [S1].
2.  **Local Feature Maps:** Feature maps $\mathbf{F}_{local}$ extracted by a 2D CNN, capturing local details and appearance [S1].
3.  **NeRF MLP:** A multi-layer perceptron that predicts density $\sigma$ and color $\mathbf{c}$ conditioned on positional encodings, viewing direction, and the fused vision features [S1].

**Steps:**

1.  **Global Feature Extraction:**
    The input image $I_s$ is processed by a Vision Transformer (ViT) [S1]. The image is split into patches, linearly projected, and processed through self-attention layers to produce feature tokens [S1, Parent]. These tokens are unflattened and resampled into multi-level feature maps $\mathbf{F}_{global}$ to capture global information [S1].

2.  **Local Feature Extraction:**
    A 2D Convolutional Neural Network (CNN) processes the input image $I_s$ to extract local feature maps $\mathbf{F}_{local}$ [S1].

3.  **Feature Conditioning for 3D Points:**
    For a 3D point $\mathbf{x}$ sampled along a ray, the corresponding 2D location $\pi(\mathbf{x})$ on the input image plane is computed [Parent].
    *   The global feature vector $\mathbf{f}_{global}$ is interpolated from $\mathbf{F}_{global}$ at $\pi(\mathbf{x})$ [S1, Parent].
    *   The local feature vector $\mathbf{f}_{local}$ is interpolated from $\mathbf{F}_{local}$ at $\pi(\mathbf{x})$ [S1, Parent].
    *   The features are combined (typically concatenated or fused) to form the vision feature $\mathbf{f}$ [S1].

4.  **Radiance Field Prediction:**
    The NeRF MLP takes the positional encoding of the 3D point $\gamma(\mathbf{x})$, the viewing direction $\mathbf{d}$, and the vision feature $\mathbf{f}$ as input [Parent]:
    $$ (\sigma, \mathbf{c}) = \text{MLP}(\gamma(\mathbf{x}), \mathbf{d}, \mathbf{f}) $$
    This predicts the volume density $\sigma$ and view-dependent color $\mathbf{c}$ [S1, Parent].

5.  **Volume Rendering:**
    Standard differentiable volume rendering is performed along the ray using the predicted $\sigma$ and $\mathbf{c}$ to compute the final pixel color [S1].

        return global_maps

        """

        Returns local feature maps.
        """
        local_maps = self.cnn(image)

def volume_rendering(sigma, color, z_vals, rays_d):
    """
    Standard differentiable volume rendering.
    """
    # Compute distances between samples
    dists = z_vals[:, :, 1:] - z_vals[:, :, :-1]
    dists = torch.cat([dists, torch.tensor([1e10]).expand(dists[..., :1].shape)], dim=-1)
    
    # Compute alpha
    alpha = 1.0 - torch.exp(-sigma * dists)
    
    # Compute transmittance
    T = torch.cumprod(1.0 - alpha + 1e-10, dim=1)
    T = torch.cat([torch.ones_like(T[:, :, :1]), T[:, :, :-1]], dim=-1)
    
    # Compute weights
    weights = alpha * T

    color_rendered = torch.sum(weights[:, :, :, None] * color, dim=1)
    return color_rendered

**Parameters:**
*   **Dataset:** ShapeNet (13 object categories) and real-world images [S1].
*   **Coordinate System:** Viewer-centered coordinate system. No symmetry or canonical coordinate systems are enforced [S1].

**Edge Cases and Pitfalls:**
*   **Self-occlusion:** Standard image-conditioned models fail when a target view pixel is invisible from the input view, incorrectly using features from visible surfaces (e.g., using window features to render a wheel) [S1]. VisionNeRF mitigates this by using self-attention to find long-range dependencies, retrieving relevant features from distant parts of the source view for occluded regions [S1].
*   **Unposed Input:** The method does not require camera pose information for the input image, which simplifies the pipeline but requires the model to generalize the mapping between 2D features and 3D geometry without explicit pose constraints [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** On the ShapeNet dataset, VisionNeRF achieves LPIPS: 0.09 and PSNR: 21.03 for novel views [S1]. This compares favorably to PixelNeRF (LPIPS: 0.20, PSNR: 21.85) in terms of perceptual similarity (LPIPS), though with slightly lower PSNR [S1].
*   **Strengths:**
    *   Handles self-occlusion better than local feature-based models (e.g., PixelNeRF) by leveraging global context [S1].
    *   Generalizes across multiple object categories using a single model [S1].
    *   Renders richer details in occluded regions [S1].
    *   Does not require camera pose information [S1].
*   **Limitations:**
    *   Performance on PSNR is slightly lower than PixelNeRF on ShapeNet [S1].
    *   Relies on the quality of the pre-trained ViT and CNN backbones.
*   **When to use:** When novel view synthesis is required from a single unposed image, especially in scenarios with significant self-occlusion, and when generalization across object categories is desired [S1].
*   **When not to use:** When per-scene optimization is acceptable and higher PSNR is prioritized over perceptual quality in occluded regions, or when camera pose information is available and can be leveraged for more precise geometric alignment.

## Background
VisionNeRF was proposed by Wei-Sheng Lai, Ravi Ramamoorthi, and Tsung-Yi Lin, with work done while interning at Google and at Google respectively [S1]. The method was published in 2023 [S1]. It addresses the limitations of existing image-conditioned models that degrade significantly when target views move further from the input view due to self-occlusion [S1]. The method builds on the principles of differentiable volume rendering [S1] and integrates advances in Vision Transformers [S1]. It is trained and evaluated on the ShapeNet dataset [S1].
