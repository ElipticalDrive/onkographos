# Model Architecture and Encoding


## Overview
This article defines the structural components of Neural Radiance Field (NeRF) models, specifically the neural networks (MLPs) and data structures (grids, tensors, meshes) used to encode scene geometry and appearance, as well as the positional encoding schemes applied to input coordinates. It solves the problem of how to represent a continuous 3D radiance field in a differentiable manner suitable for gradient-based optimization. What sets this family apart from sibling articles like [NeRF Initialization Strategies](8674-nerf-initialization-strategies.md) or [Regularization Techniques](11314-regularization-techniques.md) is its focus on the *capacity* and *representation* of the model itself, rather than the optimization dynamics or loss functions. It builds on [NeRF Hyperparameters](3065-nerf-hyperparameters.md) by detailing the specific architectural choices that those hyperparameters control.

## Shared principles
All methods in this family map a 3D spatial coordinate $\mathbf{x} \in \mathbb{R}^3$ and a viewing direction $\mathbf{d} \in \mathbb{R}^3$ to volume density $\sigma \in \mathbb{R}$ and color $\mathbf{c} \in \mathbb{R}^3$. The core mechanism involves:
1.  **Encoding:** Transforming raw coordinates into a higher-dimensional feature space using positional encoding (PE) or hash/grid lookups.
2.  **Feature Aggregation:** Combining spatial features, often via concatenation or tensor decomposition.
3.  **Decoding:** Passing aggregated features through a Multi-Layer Perceptron (MLP) or linear layers to predict $\sigma$ and $\mathbf{c}$.

The standard NeRF architecture [G] uses two separate MLPs: a density network (taking encoded $\mathbf{x}$) and a color network (taking encoded $\mathbf{x}$ and $\mathbf{d}$), separated by a bottleneck feature vector. Variations modify this by using shared weights, different activation functions, or replacing the MLP with explicit geometric primitives.

## Subtopics

### [Depth-Guided NeRF Training Configuration](11916-depth-guided-nerf-training-configuration.md)
*   **What it is:** A configuration that integrates depth supervision into the NeRF architecture and training loop.
*   **Distinction:** Unlike standard NeRF, it modifies the loss function to include depth and uncertainty terms and adds dropout layers to the encoding MLP.
*   **When to choose:** When ground-truth depth maps are available and improved geometric reconstruction is required.
*   **Link:** [Depth-Guided NeRF Training Configuration](11916-depth-guided-nerf-training-configuration.md)

### [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md)
*   **What it is:** A configuration for text-guided stylization of NeRFs using CLIP embeddings.
*   **Distinction:** It freezes density-related parameters and optimizes only appearance/feature parameters to enforce stylistic trajectories without altering geometry.
*   **When to choose:** For artistic stylization or style transfer where geometry must remain consistent with the source.
*   **Link:** [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md)

### [Binary Radiance Fields](13622-binary-radiance-fields.md)
*   **What it is:** A storage-efficient representation using binary feature grids (+1/-1) with a 2D-3D hybrid multi-resolution architecture.
*   **Distinction:** Replaces real-valued grids with binary ones and uses a straight-through estimator for binarization during training, mitigating hash collisions via 2D planes.
*   **When to choose:** When memory footprint is critical and post-processing compression is undesirable.
*   **Link:** [Binary Radiance Fields](13622-binary-radiance-fields.md)

### [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md)
*   **What it is:** An MLP architecture using integrated positional encoding to handle aliasing and frequency-aware rendering.
*   **Distinction:** Analytically integrates PE over Gaussian distributions (defined by mean/covariance) and supports Integrated Directional Encoding (IDE) for advanced shading.
*   **When to choose:** For anti-aliased rendering of scenes with varying frequencies and complex lighting.
*   **Link:** [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md)

### [SUDS](14964-suds.md)
*   **What it is:** A 4D radiance field for large-scale dynamic urban scenes, factorizing the scene into static, dynamic, and far-field hash tables.
*   **Distinction:** Scales to tens of thousands of objects using self-supervised training with RGB, LiDAR, and optical flow, without supervised 3D annotations.
*   **When to choose:** For large-scale, dynamic urban scene reconstruction from multi-video inputs.
*   **Link:** [SUDS](14964-suds.md)

### [CCNeRF](15008-ccnerf.md)
*   **What it is:** A neural field representation using tensor rank decomposition for efficient compression and composition.
*   **Distinction:** Models the radiance field entirely through tensor rank decomposition (CP/Tucker), allowing arbitrary composition via rank concatenation and dynamic compression via rank truncation, avoiding MLPs for rendering.
*   **When to choose:** When scene composition, dynamic compression, or low-rank approximation is required.
*   **Link:** [CCNeRF](15008-ccnerf.md)

### [Rip-NeRF](15532-rip-nerf.md)
*   **What it is:** A hybrid method combining cone casting, 3D Gaussians, and Ripmap Encoding.
*   **Distinction:** Projects 3D Gaussians onto Platonic solid faces and queries features via tetra-linear interpolation, solving aliasing artifacts more efficiently than multi-sampling methods like Zip-NeRF.
*   **When to choose:** For high-fidelity, anti-aliased rendering with faster training and smaller model size than multi-sampling approaches.
*   **Link:** [Rip-NeRF](15532-rip-nerf.md)

### [UE4-NeRF](15539-ue4-nerf.md)
*   **What it is:** A system for real-time interactive rendering of large-scale scenes using textured polygonal meshes in Unreal Engine 4.
*   **Distinction:** Extracts explicit geometric meshes optimized via neural networks (Encoder/Decoder MLPs) and uses regular octahedra for initialization, enabling rasterization-based rendering instead of ray marching.
*   **When to choose:** For real-time interactive applications requiring scene editing and high frame rates at large scales.
*   **Link:** [UE4-NeRF](15539-ue4-nerf.md)

### [Generative Occupancy Fields (GOF)](15773-generative-occupancy-fields-gof.md)
*   **What it is:** A 3D-aware image synthesis method transitioning from volume rendering to surface-point rendering.
*   **Distinction:** Reinterprets alpha values as occupancy probabilities and uses root-finding to locate surfaces, shrinking the sampling region during training to concentrate gradients on the surface.
*   **When to choose:** For high-fidelity generative synthesis requiring precise geometric compactness and sharp surfaces.
*   **Link:** [Generative Occupancy Fields (GOF)](15773-generative-occupancy-fields-gof.md)

### Triplane NeRF with Diffusion Prior
*   **Definition:** A framework using a triplane NeRF representation optimized jointly with a diffusion prior for sparse-view reconstruction [S1].
*   **Parameters:** Uses v-parameterization $\hat{x} = \alpha(t)x(t) - \sigma(t)\hat{v}$ and SNR-based weighting $w(t) = (\alpha(t)/\sigma(t))^2\omega$ [S1].
*   **Layout:** Scene code $\xi \in \mathbb{R}^{3 \times 6 \times 128 \times 128}$; Denoising network is a 122M parameter U-Net [S1].
*   **Source:** [S1]

### EG3D Triplane Representation
*   **Step:** Renders feature image $I_f \in \mathbb{R}^{32 \times 128 \times 128}$ and raw RGB $I_{128} \in \mathbb{R}^{3 \times 128 \times 128}$, extracts depth $I_D$, and feeds them to a 2D super-resolution network [S2].
*   **Formula:** $\text{SuperRes}(I_f, I_{128}) = I_{512}$ [S2].
*   **Parameter:** Input/output resolution 512x512 [S2].
*   **Layout:** Triplane $T \in \mathbb{R}^{256 \times 256 \times 96}$ (3 planes, 32 channels each) [S2].
*   **Number:** Rendering speed 42 fps on RTX 3090 [S2].
*   **Source:** [S2]

### NeRF-W Hyperparameter Configuration
*   **Parameter:** Base MLP: 8 layers of 512 units; Static/Transient MLPs: 4 layers of 128 units. PE: 15 freq for pos, 4 for view. Sampling: 512 points/ray/model (1024 total) during training, 2048 during eval. Appearance embedding $n(a)=48$, Transient embedding $n(\tau)=16$. L1 regularizer $\lambda_u=0.01$, min importance $\beta_{min}=0.03$. Optimizer: Adam, batch 2048, lr 0.001, decaying 10x every 150k steps, 300k total iterations [S3].
*   **Number:** Hyperparameters optimized for Brandenburg Gate scene and reused [S3].
*   **Source:** [S3]

### Explicit Mesh Reconstruction from Neural Fields
*   **Definition:** Algorithm to extract explicit 3D mesh from CodeNeRF for single-image reconstruction [S4].
*   **Step:** Feed $256^3$ voxel grid centers to CodeNeRF MLP for density $\sigma$, apply Marching Cubes for vertices, cast rays along normals for colors [S4].
*   **Source:** [S4]

### Efficient EndoNeRF scene representation
*   **Definition:** Voxel-grids-based representation replacing MLPs with explicit density/feature volumes, combined with canonical field and time-dependent deformation field for dynamic surgical scenes [S5].
*   **Step:** Dynamic scene at time $t$ modeled by warping canonical field ($\mathbf{V}_\sigma, \mathbf{V}_a$) with deformation field. Deformation field uses decomposed 4D motion fields and 3-layer MLP mapping $(\mathbf{x}, t)$ to displacement $\Delta \mathbf{x}$ [S5].
*   **Source:** [S5]

### NeRF-Liif
*   **Definition:** Baseline super-resolving LR images using pretrained LIIF model, requiring LR-HR pairs [S6].
*   **Parameter:** Requires LR-HR pairs for training [S6].
*   **Pitfall:** On synthetic Blender, may produce false predictions due to domain mismatch. On real-world LLFF, tends to be oversmooth or predict false color/geometry [S6].
*   **Number:** Blender ×2 (100x100): PSNR 27.07, SSIM 0.919, LPIPS 0.067. Blender ×4 (100x100): PSNR 25.36, SSIM 0.885, LPIPS 0.125. Blender ×2 (200x200): PSNR 28.81, SSIM 0.934, LPIPS 0.058. Blender ×4 (200x200): PSNR 27.34, SSIM 0.912, LPIPS 0.096. LLFF ×2: PSNR 26.81, SSIM 0.823, LPIPS 0.145. LLFF ×4: PSNR 24.76, SSIM 0.723, LPIPS 0.292 [S6].
*   **Source:** [S6]

### UniSurf
*   **Definition:** Method unifying volume rendering and surface rendering for high-quality geometry and sharp textures without mask supervision [S7, unofficial].
*   **Step:** Uses occupancy field where occupancy at $i^{th}$ sample indicates surface presence. Uses volume rendering in early stage for optimization without mask supervision. Uses surface rendering in later stage to extract level-set surfaces [S7, unofficial].
*   **Comparison:** Unlike pure surface rendering requiring mask supervision and yielding blurry textures, this method provides high-quality novel views and sharp textures/colors without mask supervision [S7, unofficial].
*   **Source:** [S7, unofficial]

## Background
The foundational NeRF architecture [G] introduced the use of coordinate-based MLPs to encode radiance fields, mapping 5D coordinates (3D position + 2D viewing direction) to density and color. Subsequent works have diversified the architecture to address limitations in memory, rendering speed, dynamic scenes, and generative capabilities. Hash encoding (Instant-NGP) [G] introduced multi-resolution feature grids for faster training. Triplane representations [S2] reduced memory by using 2D planes. Binary quantization [S1] and tensor decompositions [S1] addressed storage efficiency. Explicit mesh extraction [S4, S1] and hybrid methods [S1] bridged the gap between implicit fields and explicit geometry. Diffusion priors [S1] and occupancy fields [S7, unofficial] extended NeRFs into generative modeling.
