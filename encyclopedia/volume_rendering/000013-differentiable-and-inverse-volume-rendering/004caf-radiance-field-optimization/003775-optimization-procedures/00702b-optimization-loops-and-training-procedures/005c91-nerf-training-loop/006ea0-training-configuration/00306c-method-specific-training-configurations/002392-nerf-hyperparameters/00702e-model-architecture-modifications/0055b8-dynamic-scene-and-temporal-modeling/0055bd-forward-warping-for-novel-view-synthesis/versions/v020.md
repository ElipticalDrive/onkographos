# Forward Warping for Novel View Synthesis

Also called: Canonical Field Forward Warping, Forward Flow

## Overview
Forward Warping for Novel View Synthesis is a method for rendering dynamic scenes by modeling a static radiance field at a canonical time step and forward-warping this entire field to other time steps [S1]. It addresses the many-to-one and one-to-many mapping difficulties inherent in dynamic scene reconstruction by employing differentiable forward warping with average splatting and an inpaint network [S1]. Unlike backward-flow methods such as NDVG, this approach achieves superior performance, particularly for canonical frames, by explicitly warping the canonical representation forward in time [S1].

## How it works
The method employs a coarse-to-fine training strategy. The coarse stage learns a proxy geometry to define a bounding box for the fine stage, while the fine stage refines the radiance field and deformation flow [S1].

### Inputs and Outputs
*   **Inputs:** A set of multi-view images $\{I_t\}$ at various time steps $t$. The canonical time $t_{can}$ is selected as the first frame for D-NeRF datasets or the middle frame for HyperNeRF datasets [S1].
*   **Outputs:** A rendered RGB image for any arbitrary view $(\mathbf{x}, \mathbf{d})$ and time $t$ [S1].

### Data Structures
The method maintains several voxel grids and neural networks. All grids are 3D voxel structures.

1.  **Canonical Radiance Feature Grid ($V_{Rf}$):** Stores radiance features. Dimension: 12 [S1].
2.  **Canonical Coordinate Grid ($V_{rCan}$):** Stores the 3D coordinate of each voxel center [S1].
3.  **Canonical Density Grid ($V_{\sigma}^{Can}$):** Stores the volume density $\sigma$ at each voxel [S1].
4.  **Canonical Color Feature Grid ($V_{cf}^{Can}$):** Stores color features. Dimension: 3 or 12, depending on the training stage [S1].
5.  **Canonical Deformation Feature Grid ($V_{Df}^{Can}$):** Stores deformation features. Dimension: 0 for D-NeRF, 12 for HyperNeRF [S1].
6.  **Trajectory Grid ($V_{Tt}$):** Stores Discrete Cosine Transform (DCT) parameters for the trajectory of each voxel [S1].
7.  **Deformation Flow Grid ($V_{flow}$):** Stores the deformation flow vector $\Delta \mathbf{x}$ for each voxel, representing the displacement from the canonical position to time $t$ [S1].
8.  **Warped Radiance Field ($V_{Rt}$):** The radiance field at time $t$, obtained by warping $V_{Rf}$ using the deformation flow [S1].
9.  **Inpainted Radiance Field ($V_{Rt}^{Inp}$):** The radiance field after processing by the Inpaint Network [S1].
10. **Upsampled Radiance Field ($V_{Rt}^{Up}$):** The radiance field after upsampling [S1].

### Neural Networks
Four networks are used:

1.  **Canonical Radiance Network ($F_{\theta_1}$):**
    *   **Structure:** 3-layer MLP, width 128, ReLU activation [S1].
    *   **Input:** Concatenation of radiance feature sampled from $V_{Rf}$ (dim 12) and embedded position (dim 33) [S1].
    *   **Output:** Density (dim 1) and color feature (dim 3 or 12) [S1].

2.  **Canonical Deformation Network ($F_{\theta_2}$):**
    *   **Structure:** 4-layer MLP, width 64 [S1].
    *   **Input:** Concatenation of deformation feature (dim 0 for D-NeRF, 12 for HyperNeRF) and embedded position (dim 33) [S1].
    *   **Output:** DCT parameters for trajectory [S1].
    *   **Note:** The number of DCT bases is 15 for D-NeRF and 25 for HyperNeRF [S1].

3.  **View Dependent Color Network ($F_{\theta_4}$):**
    *   **Structure:** 2-layer MLP, width 64 [S1].
    *   **Input:** Concatenation of embedded view direction (dim 27) and color feature (dim 12) [S1].
    *   **Output:** RGB color (dim 3) [S1].

4.  **Inpaint Network ($F_{\theta_3}$):**
    *   **Structure:** UNet with 4 encode layers and 3 decode layers, followed by an upsample layer [S1].
    *   **Encode Layer:** Max pooling layer followed by two convolution layers.
    *   **Decode Layer:** Up-sample interpolation layer followed by two convolution layers.
    *   **Convolution Layer:** Instance norm, followed by convolution and ReLU [S1].
    *   **Upsample Layer:** Same structure as the decode layer [S1].

### Training Stages and Parameters

**Coarse Stage:**
*   **Voxel Number:** $6^3$ [S1].
*   **Inpaint Scale:** 1.5 [S1].
*   **Iterations:** 20,000 [S1].
*   **Note:** The inpaint network is **not** used during the coarse stage. The purpose is to learn proxy geometry to calculate the bounding box for the fine stage [S1].

**Fine Stage:**
*   **Voxel Number:** $8^3$ for D-NeRF, $7^3$ for HyperNeRF [S1].
*   **Inpaint Scale:** 2.0 [S1].
*   **Iterations:** 100,000 [S1].
*   **Progressive Training:** Start with 10 images closest to the canonical step. Add one image with the closest time step every 60 iterations [S1].

**Optimization:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $10^{-1}$ for voxel grids, $10^{-3}$ for networks [S1].

### Forward Warping Process
The core mechanism is differentiable forward warping using average splatting [S1].

1.  **Deformation Prediction:** For a target time $t$, the deformation network $F_{\theta_2}$ predicts DCT parameters for each voxel in $V_{Df}^{Can}$. These parameters define a smooth trajectory field $V_{Tt}$ [S1].
2.  **Flow Calculation:** The trajectory field is used to compute the deformation flow $V_{flow}$, which maps each canonical voxel position $\mathbf{x}_{can}$ to its position $\mathbf{x}_t$ at time $t$ [S1].
3.  **Average Splatting:** The canonical radiance features from $V_{Rf}$ are splatted into the target space using the flow $V_{flow}$. Average splatting is used instead of softmax splatting, as softmax splatting with predicted weights showed no obvious improvement and introduced unnecessary complexity [S1]. This produces the Warped Radiance Field $V_{Rt}$ [S1].
4.  **Inpainting:** The Warped Radiance Field $V_{Rt}$ contains holes due to occlusions and many-to-one/one-to-many mappings. The Inpaint Network $F_{\theta_3}$ processes $V_{Rt}$ to produce the Inpainted Radiance Field $V_{Rt}^{Inp}$ [S1].
5.  **Upsampling:** An upsample layer refines $V_{Rt}^{Inp}$ to produce the final Upsampled Radiance Field $V_{Rt}^{Up}$ [S1].

### Rendering
To render a ray $\mathbf{r}$ at time $t$:
1.  Sample points along the ray in the canonical space.
2.  Use $F_{\theta_1}$ to get density and color features from the canonical grids.
3.  Warp the points to time $t$ using the flow $V_{flow}$.
4.  Render using standard volume rendering equations from either $V_{Rt}^{Inp}$ or $V_{Rt}^{Up}$ [S1].

### Loss Functions
The total loss is a weighted sum of several components [S1]:

$$ \mathcal{L} = \mathcal{L}_{photo} + w_1\mathcal{L}_{ptc} + w_2\mathcal{L}_{bg} + w_3\mathcal{L}_{flow} + w_4\mathcal{L}_{vdiff} + w_5\mathcal{L}_{tv}(\mathbf{V}_{\sigma}^{\text{Can}}) + w_6\mathcal{L}_{tv}(\mathbf{V}_{\text{flow}}^t) + w_7\mathcal{L}_{tv}(\mathbf{D}) $$

**Point-wise Color Loss ($\mathcal{L}_{ptc}$):**
Supervises the color of sampled points weighted by their accumulation [S1].

$$ \mathcal{L}_{ptc} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Up}}(\mathbf{r})) $$

Where:
$$ \mathcal{L}(\mathbf{C}(\mathbf{r})) = \frac{1}{K} \sum_{k=1}^{K} A_{\text{accum}}(k) \|\mathbf{c}(w_k) - \mathbf{C}_{\text{gt}}(\mathbf{r})\|_2^2 $$
$$ A_{\text{accum}}(k) = T(w_k) \, \sigma(w_k) \delta_k $$

$\mathbf{C}_{\text{Inp}}$ and $\mathbf{C}_{\text{Up}}$ are colors rendered from the inpainted and upsampled fields, respectively. $T(w_k)$ is the transmittance, $\sigma(w_k)$ is the density, and $\delta_k$ is the distance between samples [S1].

**Background Entropy Loss ($\mathcal{L}_{bg}$):**
Encourages densities to concentrate on foreground or background [S1].

$$ \mathcal{L}_{bg} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Up}}(\mathbf{r})) $$

Where:
$$ \mathcal{L}(\mathbf{A}(\mathbf{r})) = -\frac{1}{K-1} \sum_{k=1}^{K-1} [ A_{\text{accum}}(k)\log(A_{\text{accum}}(k)) + (1-A_{\text{accum}}(k))\log(1-A_{\text{accum}}(k)) ] $$

**Total Variation Losses ($\mathcal{L}_{tv}$):**
Applied to the canonical density grid, the deformation flow grid, and the deformation feature grid $\mathbf{D}$ to improve visual quality [S1].

**Loss Weights:**

| Weight | Coarse Stage | Fine Stage |
| :--- | :--- | :--- |
| $w_1$ ($\mathcal{L}_{ptc}$) | $10^{-1}$ | $10^{-2}$ |
| $w_2$ ($\mathcal{L}_{bg}$) | $10^{-2}$ | $10^{-3}$ |
| $w_3$ ($\mathcal{L}_{flow}$) | $10^{-5}$ | $10^{-5}$ |
| $w_4$ ($\mathcal{L}_{vdiff}$) | $0$ | $10^{-5}$ |
| $w_5$ ($\mathcal{L}_{tv}(\mathbf{V}_{\sigma}^{\text{Can}})$) | $10^{-6}$ | $10^{-6}$ |
| $w_6$ ($\mathcal{L}_{tv}(\mathbf{V}_{\text{flow}}^t)$) | $10^{-3}$ | $10^{-3}$ |
| $w_7$ ($\mathcal{L}_{tv}(\mathbf{D})$) | $10^{-1}$ | $10^{-1}$ |

        self.optimizer.step()

class CanonicalRadianceNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(12 + 33, 128),
            nn.ReLU(),
            nn.Linear(128, 128),
            nn.ReLU(),
            nn.Linear(128, 1 + 12) # Density + Color Feature
        )
        
    def forward(self, radiance_feat, pos_embed):
        x = torch.cat([radiance_feat, pos_embed], dim=-1)
        out = self.net(x)
        density = out[:, :1]
        color_feat = out[:, 1:]
        return density, color_feat

class CanonicalDeformationNetwork(nn.Module):
    def __init__(self, deform_feat_dim, dct_bases):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(deform_feat_dim + 33, 64),
            nn.ReLU(),
            nn.Linear(64, 64),
            nn.ReLU(),
            nn.Linear(64, 64),
            nn.ReLU(),
            nn.Linear(64, dct_bases)
        )
        
    def forward(self, deform_feat, pos_embed):
        x = torch.cat([deform_feat, pos_embed], dim=-1)
        out = self.net(x)
        return out

class ViewDependentColorNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(27 + 12, 64),
            nn.ReLU(),
            nn.Linear(64, 64),
            nn.ReLU(),
            nn.Linear(64, 3)
        )
        
    def forward(self, view_dir_embed, color_feat):
        x = torch.cat([view_dir_embed, color_feat], dim=-1)
        out = self.net(x)
        return out

class InpaintNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        # Simplified UNet structure
        self.encoder1 = nn.Sequential(nn.MaxPool2d(2), nn.Conv2d(12, 64, 3), nn.InstanceNorm2d(64), nn.ReLU(), nn.Conv2d(64, 64, 3), nn.InstanceNorm2d(64), nn.ReLU())
        self.encoder2 = nn.Sequential(nn.MaxPool2d(2), nn.Conv2d(64, 128, 3), nn.InstanceNorm2d(128), nn.ReLU(), nn.Conv2d(128, 128, 3), nn.InstanceNorm2d(128), nn.ReLU())
        self.decoder1 = nn.Sequential(nn.Upsample(scale_factor=2), nn.Conv2d(128, 64, 3), nn.InstanceNorm2d(64), nn.ReLU(), nn.Conv2d(64, 64, 3), nn.InstanceNorm2d(64), nn.ReLU())
        self.decoder2 = nn.Sequential(nn.Upsample(scale_factor=2), nn.Conv2d(64, 12, 3), nn.InstanceNorm2d(12), nn.ReLU(), nn.Conv2d(12, 12, 3), nn.InstanceNorm2d(12), nn.ReLU())
        self.upsample_layer = nn.Sequential(nn.Upsample(scale_factor=2), nn.Conv2d(12, 12, 3), nn.InstanceNorm2d(12), nn.ReLU(), nn.Conv2d(12, 12, 3), nn.InstanceNorm2d(12), nn.ReLU())
        
    def forward(self, x):
        # x is the warped radiance field
        # Apply UNet
        e1 = self.encoder1(x)
        e2 = self.encoder2(e1)
        d1 = self.decoder1(e2)
        d2 = self.decoder2(d1)
        # Apply upsample layer
        out = self.upsample_layer(d2)
        return out

## Operating characteristics
*   **Time Complexity:** Training is slow, taking approximately one day per scene on a GeForce RTX 3090 GPU [S1].
*   **Memory Complexity:** Memory consumption is high, especially for real scenes [S1].
*   **Model Size:** 260M parameters for D-NeRF, 440M for HyperNeRF [S1].
*   **Rendering Speed:** 7 seconds per image for D-NeRF, 15 seconds per image for HyperNeRF [S1].
*   **Strengths:** Achieves SOTA performance on public datasets, especially for canonical frames. The forward warping design provides a clear advantage over backward flow methods like NDVG [S1].
*   **Limitations:** High memory usage and slow training speed. The coarse stage is critical; removing it causes significant performance drops because the voxel grid covers a larger space without proxy geometry filtering [S1]. The inpaint network is also critical; removing it significantly reduces performance (e.g., Hell Warrior PSNR drops from 27.71 to 27.15) [S1].

## Background
The method was proposed in the paper "Forward Flow for Novel View Synthesis of Dynamic Scenes" [S1]. It builds on the concept of canonical fields, where a static representation is learned and then warped to dynamic time steps. The method addresses the limitations of previous dynamic NeRF approaches by explicitly modeling the forward warping process with average splatting and an inpaint network to handle occlusions and mapping ambiguities [S1].
