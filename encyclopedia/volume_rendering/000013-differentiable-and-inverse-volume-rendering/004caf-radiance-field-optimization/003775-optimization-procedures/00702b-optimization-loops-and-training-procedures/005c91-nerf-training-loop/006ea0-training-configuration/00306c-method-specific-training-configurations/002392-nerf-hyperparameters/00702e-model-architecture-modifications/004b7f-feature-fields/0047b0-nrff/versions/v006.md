# NRFF

Also called: Neural Radiance Feature Field
## Overview
NRFF is a method for encoding view-dependent effects, specifically specularities, in neural radiance fields by replacing the standard positional encoding and roughness/IDE inputs of Ref-NeRF with a multiscale tensor decomposition and Anisotropic Spherical Gaussians (ASG) [S1]. It differs from its siblings by explicitly modeling reflection geometry in a latent space via a Rendering Equation Encoding (REE) before passing data to the directional MLP, rather than relying on explicit roughness maps or pre-computed environment maps [S1].
## How it works
**Inputs and Outputs:**
*   **Input:** 3D spatial coordinate $\mathbf{x}$, viewing direction $\mathbf{d}$, and a set of $M$ ground-truth feature maps $\mathbf{F}_\tau^i$ (if supervision is available).
*   **Output:** Color $\mathbf{c}$, density $\sigma$, and rendered feature $\hat{\mathbf{F}}$.

**Data Structures:**
*   **ASG Features:** A vector of 128 values representing $N = 8 \times 16$ lobes of ASGs on a unit sphere [S1].
*   **REE Vector:** An $8 \times 16 \times 2$ vector resulting from the Rendering Equation Encoding [S1].
*   **Bottleneck:** A vector $\mathbf{a}$ of length 2 [S1].

**Steps:**
1.  **Spatial Encoding:** The spatial MLP processes $\mathbf{x}$ using Multiscale Tensor Decomposition (MTD) instead of Positional Encoding (PE) to represent the scene in a coarse-to-fine scheme [S1].
2.  **ASG Feature Prediction:** The spatial MLP predicts ASG features for each point. This involves predicting $N = 8 \times 16$ lobes, resulting in a 128-dimensional vector [S1].
3.  **ASG Bottleneck Conversion:** An auxiliary ASG MLP converts the 128 ASG features into:
    *   An anisotropic reflections bottleneck vector $\mathbf{a}$ of length 2.
    *   Two scalar coefficients $\lambda$ and $\mu$ (where $\lambda_i, \mu_i > 0$) modeling the shape of the ASG in orthogonal directions $\omega_{\lambda_i}, \omega_{\mu_i}$ [S1].
4.  **Rendering Equation Encoding (REE):** Compute the REE vector for the viewing direction $\omega_r$ using the ASG parameters:
    $$
    \text{REE}(\omega_r, \mathbf{a}, \lambda, \mu) = \sum_{i=0}^{N-1} a_i S(\omega_r; \omega_i) \exp\left(-\lambda_i (\omega_r \cdot \omega_{\lambda_i})^2 - \mu_i (\omega_r \cdot \omega_{\mu_i})^2\right)
    $$
    where $S(\omega_r; \omega_i) = \max(\omega_r \cdot \omega_i, 0)$ is a smooth term, and $\omega_i$ covers the unit sphere [S1].
5.  **Directional Processing:** The directional MLP ingests the $8 \times 16 \times 2$ REE vector (replacing the roughness and IDE inputs used in Ref-NeRF) to predict color and density [S1].
6.  **Rendering:** Render color and features using standard volume rendering integration [S1, Parent].
7.  **Loss Calculation:** Compute the loss including the auxiliary term $L_o$ from Ref-NeRF and the new regularization term $L_f$:
    $$
    L_f = \frac{\beta}{M} \sum_{i=0}^{M-1} \frac{|\mathbf{F}_\tau^i|}{\tau}
    $$
    where $M$ is the number of features, $\mathbf{F}_\tau$ is the density field feature map, and $\beta$ is a coefficient [S1].

**Pseudocode:**
```python
def nrff_forward(x, d, asg_mlp, directional_mlp, n_lobes=8*16):
    # Step 1 & 2: Spatial MLP with MTD predicts ASG features
    # MTD is a decomposition scheme; details of the tensor decomposition itself
    # are not provided in the source, but it replaces PE [S1].
    asg_features = spatial_mlp_with_mtd(x) # Returns 128-dim vector
    
    # Step 3: Auxiliary ASG MLP converts features to bottleneck and coefficients
    a, lambda_coeffs, mu_coeffs = asg_mlp(asg_features)
    # a is length 2, lambda/mu are arrays of size N
    
    # Step 4: Compute REE vector
    ree_vector = []
    for i in range(n_lobes):
        # omega_i is the direction of the i-th ASG lobe
        # S is the smooth term max(dot, 0)
        s_term = max(dot(d, omega_i), 0)
        exp_term = exp(-lambda_coeffs[i] * dot(d, omega_lambda_i)**2 
                       - mu_coeffs[i] * dot(d, omega_mu_i)**2)
        ree_component = a[i] * s_term * exp_term
        ree_vector.append(ree_component)
    
    # Reshape to 8x16x2 as per source [S1]
    ree_vector = reshape(ree_vector, (8, 16, 2))
    
    # Step 5: Directional MLP ingests REE vector
    c, sigma = directional_mlp(ree_vector)
    
    return c, sigma

def compute_loss(rendered_features, gt_features, beta, tau, M):
    # Lf regularization term [S1]
    Lf = (beta / M) * sum(abs(F_tau_i) / tau for F_tau_i in gt_features)
    # L_o from Ref-NeRF is also included [S1]
    return Lf + L_o
```

**Parameters:**
*   $N$: Number of ASG lobes, set to $8 \times 16$ [S1].
*   $\mathbf{a}$: Anisotropic reflections bottleneck vector, length 2 [S1].
*   $\lambda, \mu$: Scalar coefficients modeling ASG shape, must be $> 0$ [S1].
*   $\beta$: Coefficient for the regularization term $L_f$ [S1].

**Edge Cases:**
*   $\lambda_i, \mu_i$ must be strictly positive to ensure valid Gaussian bandwidths [S1].
*   The REE integration assumes $\omega_i$ covers the full unit sphere (360 degrees) [S1].

## Operating characteristics
*   **Complexity:** Uses Multiscale Tensor Decomposition (MTD) for efficiency in reconstructing scene geometry and appearance compared to standard PE [S1].
*   **Strengths:** Superior rendering quality on diverse datasets, particularly for specularities; sparse feature representation enhances interpretability and mitigates overfitting [S1].
*   **Limitations:** Requires auxiliary ASG MLP and REE computation; replaces standard roughness/IDE inputs which may complicate integration with existing NeRF pipelines [S1].
*   **When to use:** When modeling view-dependent specular effects is critical and standard NeRF/Ref-NeRF roughness models are insufficient [S1].

## Background
NRFF was proposed by Albert Barreiro, Roger Marı́, Rafael Redondo, Gloria Haro, Carles Bosch, and David Berga from Eurecat and Universitat Pompeu Fabra [S1]. It was submitted on 2024–07–09, accepted on 2025–01–17, and published in *Image Processing On Line* on 2025–03–12 [S1]. The method builds on the Ref-NeRF formulation but introduces architectural improvements to better encode view-dependent effects [S1].
