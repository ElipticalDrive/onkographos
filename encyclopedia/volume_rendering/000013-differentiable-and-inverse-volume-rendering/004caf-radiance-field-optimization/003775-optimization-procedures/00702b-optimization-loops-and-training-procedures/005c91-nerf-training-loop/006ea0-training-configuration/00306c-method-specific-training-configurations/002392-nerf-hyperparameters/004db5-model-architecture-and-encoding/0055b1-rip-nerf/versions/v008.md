# Rip-NeRF

Also called: Rip-NeRF25k

## Overview
Rip-NeRF is a radiance field method that renders high-fidelity, anti-aliased images by combining cone casting with an anisotropic 3D Gaussian characterization [S1]. It differs from sibling methods like Zip-NeRF by using Ripmap-Encoded Platonic Solids to enable efficient anisotropic area-sampling, whereas Zip-NeRF relies on a multi-sampling mechanism that is less efficient [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of calibrated multi-view 2D images.
*   **Outputs:** Rendered pixel colors $\mathbf{c}_{pixel}$ and optimized scene parameters (Ripmap features, Gaussian parameters).

**Data Structures:**
1.  **Ripmap Encoding ($\mathcal{R}$):** A hierarchical feature grid.
    *   **Base Level ($\mathcal{R}_{0,0}$):** Learnable tensor of shape $H \times W \times C$. Default: $512 \times 512 \times 16$ [S1].
    *   **Derived Levels:** Generated from $\mathcal{R}_{0,0}$ using averaging operations to ensure consistency and compactness [S1].
2.  **Platonic Solid:** A geometric proxy for the conical frustum. Default: Icosahedron with 10 unparalleled faces $\{P_i \mid i = 1, \dots, n\}$ [S1].
3.  **Anisotropic 3D Gaussian:** Characterizes each conical frustum, defined by mean $\boldsymbol{\mu}$ and covariance $\boldsymbol{\Sigma}$ [S1].
4.  **Tiny MLP ($F_\theta$):** A small neural network that takes aggregated features and outputs density $\sigma$ and color $\mathbf{c}$ [S1].

**Numbered Steps:**

1.  **Cone Casting and Frustum Division:**
    For each pixel, cast a cone into the scene. Divide the cone into multiple conical frustums along the ray [S1].

2.  **Gaussian Characterization:**
    Characterize each conical frustum as an anisotropic 3D Gaussian with mean $\boldsymbol{\mu}$ and covariance $\boldsymbol{\Sigma}$ [S1].

3.  **Platonic Solid Projection:**
    Project the 3D Gaussian onto the faces of the Platonic solid to form 2D Gaussians. For each face $P_i$:
    *   Compute the projection matrix $M_i \in \mathbb{R}^{3 \times 2}$ mapping the 3D world coordinate system to the 2D coordinate system of plane $P_i$ [S1].
    *   Calculate the projected mean $\boldsymbol{\mu}^{proj}_i$ and covariance $\boldsymbol{\Sigma}^{proj}_i$ of the 2D Gaussian on plane $P_i$ [S1].

4.  **Ripmap Encoding Query:**
    Query a feature vector $\mathbf{f}_i$ from the Ripmap Encoding of plane $P_i$ using tetra-linear interpolation [S1].
    *   The interpolation position $(p_x, p_y)$ is determined by $\boldsymbol{\mu}^{proj}_i$ [S1].
    *   The interpolation level $(l_x, l_y)$ is determined by $\boldsymbol{\Sigma}^{proj}_i$ [S1].
    *   The hyper-parameter $w$ in the level calculation is set to 2.0 to adjust the probability mass coverage of the Gaussian footprint [S1].
    *   *Note on Ripmap Derivation:* Derived levels $\mathcal{R}_{i,j}$ are computed from the base level $\mathcal{R}_{0,0}$ as follows [S1]:
        $$
        \mathcal{R}_{i,j} =
        \begin{cases}
        \text{Avg}_{2\times1}(\mathcal{R}_{i, j-1}) & \text{if } j \neq 0 \\
        \text{Avg}_{1\times2}(\mathcal{R}_{i-1, j}) & \text{if } i \neq 0 \text{ and } j = 0 \\
        \mathcal{R}_{0,0} & \text{otherwise}
        \end{cases}
        $$
        where $i$ and $j$ are indices of levels in the $x$ and $y$ directions, respectively. Only $\mathcal{R}_{0,0}$ is learnable [S1].

5.  **Feature Aggregation:**
    Concatenate all feature vectors $\{\mathbf{f}_i \mid i = 1, \dots, n\}$ from the Platonic solid faces and the encoded view direction $\mathbf{d}$ to form the final feature vector $\mathbf{f}$ [S1].

6.  **Density and Color Estimation:**
    Pass the aggregated feature vector $\mathbf{f}$ through the tiny MLP $F_\theta$ to estimate the density $\sigma$ and color $\mathbf{c}$ for the conical frustum [S1].

7.  **Volume Rendering:**
    Render the pixel color by performing volume rendering using the estimated $\sigma$ and $\mathbf{c}$ values across the frustums [S1].

8.  **Optimization:**
    Optimize the system end-to-end using a photometric loss between rendered and observed images. The loss is scaled by the area of the pixel footprint on the image plane (area loss $L_{area}$) [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class RipNeRF:
    def __init__(self, h=512, w=512, c=16, num_faces=10):
        """
        Initialize Rip-NeRF.
        :param h: Height of base Ripmap level
        :param w: Width of base Ripmap level
        :param c: Channels of base Ripmap level
        :param num_faces: Number of faces in the Platonic solid (default 10 for Icosahedron)
        """
        # Base level is learnable; derived levels are computed on the fly or cached
        self.base_ripmap = nn.Parameter(torch.randn(h, w, c))
        self.num_faces = num_faces
        # Tiny MLP for sigma and color
        self.mlp = nn.Sequential(
            nn.Linear(c * num_faces + 3, 64), # Assuming view dir is 3D
            nn.ReLU(),
            nn.Linear(64, 64),
            nn.ReLU(),
            nn.Linear(64, 4) # sigma (1) + color (3)
        )
        # Precompute projection matrices for the Platonic solid faces
        self.projection_matrices = self._get_icosahedron_projections()

    def _get_icosahedron_projections(self):
        """
        Returns a list of projection matrices M_i for the 10 faces of an icosahedron.
        Each M_i maps 3D world coordinates to the 2D plane of face i.
        Note: Exact geometric derivation of M_i depends on the specific icosahedron orientation.
        This is a placeholder for the actual geometric computation.
        """
        # Placeholder: In implementation, this would return a tensor of shape (10, 3, 2)
        return torch.zeros(self.num_faces, 3, 2)

    def _get_derived_ripmap(self, level_x, level_y):
        """
        Computes the feature grid at level (level_x, level_y) from the base level.
        Uses averaging operations as defined in Eq. 1.
        """
        # If base level, return it
        if level_x == 0 and level_y == 0:
            return self.base_ripmap
        
        # Determine parent level based on Eq. 1
        if level_y != 0:
            parent = self._get_derived_ripmap(level_x, level_y - 1)
            # Avg2x1: Average along y-axis (dim 1)
            # To get 2x1 average, we might need to pad or handle boundaries.
            # Simplified: Average over the last dimension if size allows, 
            # but strictly it averages 2x1 blocks.
            # For implementation, we assume standard pooling or manual averaging.
            # Here we simulate the logic:
            if parent.shape[1] >= 2:
                return F.avg_pool2d(parent.permute(2, 0, 1).unsqueeze(0), kernel_size=(1, 2), stride=1).squeeze(0).permute(1, 2, 0)
            else:
                return parent # Fallback
        else: # level_y == 0 and level_x != 0
            parent = self._get_derived_ripmap(level_x - 1, 0)
            # Avg1x2: Average along x-axis (dim 0)
            if parent.shape[0] >= 2:
                return F.avg_pool2d(parent.permute(2, 0, 1).unsqueeze(0), kernel_size=(2, 1), stride=1).squeeze(0).permute(1, 2, 0)
            else:
                return parent # Fallback

    def query_ripmap(self, pos_x, pos_y, level_x, level_y):
        """
        Queries the Ripmap at a specific position and level using tetra-linear interpolation.
        :param pos_x: Normalized x coordinate [0, 1]
        :param pos_y: Normalized y coordinate [0, 1]
        :param level_x: Level index x
        :param level_y: Level index y
        :return: Feature vector f_i
        """
        grid = self._get_derived_ripmap(level_x, level_y)
        # Normalize coordinates to [-1, 1] for grid_sample
        # Assuming grid is (H, W, C)
        h, w, c = grid.shape
        x_norm = 2.0 * pos_x * w - 1.0
        y_norm = 2.0 * pos_y * h - 1.0
        
        # grid_sample expects (N, H, W, C) or (N, C, H, W) depending on format
        # PyTorch grid_sample expects input (N, C, H, W) and grid (N, H_out, W_out, 2)
        # Here we query a single point, so we treat it as a batch of 1
        grid_4d = grid.permute(2, 0, 1).unsqueeze(0) # (1, C, H, W)
        grid_points = torch.stack([x_norm, y_norm], dim=-1).unsqueeze(0).unsqueeze(0) # (1, 1, 1, 2)
        
        # Use bilinear interpolation (tetra-linear in 2D space with levels implies bilinear in spatial)
        # Note: The paper says "tetra-linear", which usually refers to 3D trilinear + 1D level.
        # However, the Ripmap structure is 2D spatial with hierarchical levels.
        # The interpolation in spatial domain is bilinear. The level selection is discrete/interpolated.
        # Eq 3 likely defines how (lx, ly) are derived from covariance.
        # We assume bilinear interpolation on the spatial grid at the derived level.
        features = F.grid_sample(grid_4d, grid_points, mode='bilinear', padding_mode='zeros')
        return features.squeeze() # (C,)

    def forward(self, rays, gaussians):
        """
        Forward pass for a batch of rays.
        :param rays: Ray origins and directions
        :param gaussians: List of 3D Gaussians for each frustum along the ray
        :return: Rendered color and density
        """
        rendered_colors = []
        densities = []
        
        for ray_idx, (ray_origin, ray_dir) in enumerate(zip(rays['origin'], rays['direction'])):
            # 1. Cast cone and divide into frustums
            # 2. Characterize frustum as 3D Gaussian (mu, Sigma)
            # This part is handled by the input 'gaussians' structure
            frustum_gaussians = gaussians[ray_idx]
            
            frustum_colors = []
            frustum_densities = []
            
            for gaussian in frustum_gaussians:
                mu_3d, Sigma_3d = gaussian['mu'], gaussian['sigma']
                
                # 3. Project to Platonic Solid faces
                face_features = []
                for i in range(self.num_faces):
                    M_i = self.projection_matrices[i] # (3, 2)
                    
                    # Project mean and covariance
                    # mu_proj = M_i^T * mu_3d ? Or M_i * mu_3d?
                    # M_i maps 3D to 2D. So mu_proj = M_i @ mu_3d
                    mu_proj = M_i @ mu_3d # (2,)
                    
                    # Sigma_proj = M_i^T @ Sigma_3d @ M_i
                    Sigma_proj = M_i.T @ Sigma_3d @ M_i # (2, 2)
                    
                    # 4. Query Ripmap
                    # Determine position (px, py) from mu_proj
                    # Determine level (lx, ly) from Sigma_proj using w=2.0
                    # This requires specific formulas for lx, ly from Sigma.
                    # Assuming lx, ly are derived from the eigenvalues or trace of Sigma_proj
                    # Eq 3 is not fully explicit in the text provided, but w=2.0 adjusts mass coverage.
                    # We assume a function get_level_from_covariance exists.
                    lx, ly = self._get_level_from_covariance(Sigma_proj, w=2.0)
                    
                    # Normalize mu_proj to [0, 1] for grid sampling
                    # Assuming the plane coordinates are normalized or need mapping
                    px, py = self._normalize_projection(mu_proj)
                    
                    f_i = self.query_ripmap(px, py, lx, ly)
                    face_features.append(f_i)
                
                # 5. Aggregate features
                # Concatenate face features and view direction
                # View direction d needs to be encoded (e.g., positional encoding)
                d_encoded = self._encode_direction(ray_dir)
                aggregated_feature = torch.cat(face_features + [d_encoded])
                
                # 6. Estimate sigma and c
                out = self.mlp(aggregated_feature)
                sigma = torch.sigmoid(out[0]) # Ensure positive density
                color = torch.sigmoid(out[1:]) # Ensure color in [0, 1]
                
                frustum_colors.append(color)
                frustum_densities.append(sigma)
            
            # 7. Volume Rendering
            # Standard volume rendering equation
            # C = sum(T_i * c_i * (1 - exp(-sigma_i * delta_i)))
            # T_i = exp(-sum(sigma_j * delta_j))
            # This step depends on the specific volume rendering implementation (e.g., NerfAcc)
            # We assume a helper function for this
            color, density = self._volume_render(frustum_colors, frustum_densities, rays['depths'][ray_idx])
            rendered_colors.append(color)
            densities.append(density)
            
        return torch.stack(rendered_colors), torch.stack(densities)

    def _get_level_from_covariance(self, Sigma, w=2.0):
        """
        Determines the Ripmap level (lx, ly) from the 2D covariance matrix.
        The exact formula is not provided in the text, but w=2.0 is used.
        [G] Typically, levels are derived from the standard deviation (sqrt of eigenvalues).
        """
        # Placeholder implementation
        # Assuming Sigma is 2x2
        eigenvalues = torch.linalg.eigvals(Sigma).real
        std_devs = torch.sqrt(eigenvalues)
        # Map std_devs to levels. w=2.0 might mean covering 2 standard deviations.
        # Level = log2(std_dev * w) ?
        lx = int(torch.log2(std_devs[0] * w).clamp(min=0))
        ly = int(torch.log2(std_devs[1] * w).clamp(min=0))
        return lx, ly

    def _normalize_projection(self, mu_proj):
        """
        Normalizes projected mean to [0, 1] for grid sampling.
        [G] Depends on the coordinate system of the Platonic solid faces.
        """
        # Placeholder
        return mu_proj

    def _encode_direction(self, direction):
        """
        Encodes the viewing direction.
        [G] Standard positional encoding or simple concatenation.
        """
        return direction

    def _volume_render(self, colors, densities, depths):
        """
        Performs volume rendering.
        [G] Standard NeRF volume rendering.
        """
        # Placeholder
        return colors[0], densities[0]
```

**Parameters:**
*   **Ripmap Base Shape:** $H=512, W=512, C=16$ [S1].
*   **Platonic Solid:** Icosahedron (10 faces) [S1].
*   **Hyper-parameter $w$:** 2.0 (adjusts probability mass coverage) [S1].
*   **Optimizer:** AdamW [S1].
*   **Iterations:** 120k (standard), 25k (Rip-NeRF25k variant) [S1].
*   **Weight Decay:** $1 \times 10^{-5}$ [S1].
*   **Initial Learning Rate:** $2 \times 10^{-3}$, modulated by MultiStepLR [S1].
*   **Ripmap Learning Rate:** Scaled up by 10.0 times [S1].
*   **Libraries:** `tiny-cuda-nn` for MLP, CUDA kernels for Projection/Encoding, `NerfAcc` for occupancy grid [S1].

**Edge Cases and Pitfalls:**
*   **Empty Space:** Use a binary occupancy grid (via NerfAcc) to skip samples in empty areas [S1].
*   **Precision:** The Ripmap levels are derived from the base level to ensure consistency; using learnable levels for all scales would increase memory and reduce consistency [S1].
*   **Boundary Conditions:** The averaging operations for derived Ripmap levels handle boundaries by falling back to the parent level if dimensions are insufficient [S1].

## Operating characteristics
*   **Training Time:** 2.6 hours on NVIDIA A100-SXM4-80GB GPU for the standard model; 32 minutes for the Rip-NeRF25k variant [S1].
*   **Model Size:** 160 MB [S1].
*   **GPU Memory:** 20 GB during training [S1].
*   **Rendering Speed:** 3 FPS [S1].
*   **Scaling:** The Rip-NeRF25k variant achieves comparable results to Zip-NeRF with only 11.76% of the training time (32 min vs 4.5h) [S1].
*   **Strengths:** High-fidelity anti-aliasing, efficient anisotropic area-sampling, compact model size, fast training and rendering compared to Zip-NeRF [S1].
*   **Limitations:** Zip-NeRF has slightly better SSIM, though Rip-NeRF outperforms it in PSNR and LPIPS [S1]. Zip-NeRF is designed for unbounded scenes, while Rip-NeRF is benchmarked on bounded objects (Blender dataset) [S1].
*   **When to Use:** When high-fidelity anti-aliased rendering is required with limited training time and memory, especially for bounded scenes.
*   **When Not to Use:** If maximum SSIM is the primary metric and training time/memory are not constraints, Zip-NeRF might be preferred. For unbounded scenes, Zip-NeRF is more suitable [S1].

## Background
Rip-NeRF was introduced in 2024 by the authors of the paper "Rip-NeRF: Anti-aliasing Radiance Fields with Ripmap-Encoded Platonic Solids" [S1]. It builds on previous work in hybrid representations, such as Mip-NeRF [Barron et al. 2021], Tri-MipRF [Hu et al. 2023], and Zip-NeRF [Barron et al. 2023], aiming to improve the efficiency of area-sampling for anti-aliasing [S1].
