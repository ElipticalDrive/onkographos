# SUDS

Also called: Scalable Urban Dynamic Scenes

## Overview
SUDS is a 4D radiance field representation designed for large-scale dynamic urban scenes that factorizes the scene into three separate multi-resolution hash table data structures to efficiently encode static, dynamic, and far-field radiance fields [S1]. It solves the problem of scaling neural reconstruction to city-level environments with significant temporal dynamics and ego-motion by using unlabeled target signals (RGB, sparse LiDAR, 2D descriptors, 2D optical flow) for supervision, avoiding the need for expensive 3D bounding box or panoptic segmentation annotations [S1]. Unlike sibling methods that rely on per-object NeRFs or supervised labels, SUDS handles multi-video representations and ego-motion while maintaining memory efficiency through spatial partitioning and hash-based feature storage [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   $N$ ordered RGB images from different videos (varying days, weather, lighting) with associated camera poses [S1].
*   Aligned sparse LiDAR depth measurements [S1].
*   2D self-supervised DINO descriptors (teacher features) [S1].
*   2D optical flow predictions [S1].
*   Query tuple: $(\mathbf{x}, \mathbf{d}, t, \text{vid})$, where $\mathbf{x} \in \mathbb{R}^3$ is position, $\mathbf{d} \in \mathbb{R}^3$ is viewing direction, $t$ is frame index, and $\text{vid} \in \{1, \dots, N\}$ is video ID [S1].

**Outputs:**
*   Volume density $\sigma(\mathbf{x}, t, \text{vid}) \in \mathbb{R}$ [S1].
*   Color $\mathbf{c}(\mathbf{x}, t, \text{vid}, \mathbf{d}) \in \mathbb{R}^3$ [S1].
*   Semantic features $\boldsymbol{\Phi}(\mathbf{x}, t, \text{vid}) \in \mathbb{R}^C$ [S1].
*   3D scene flow vectors $\mathbf{s}_{t_0}(\mathbf{x}, t, \text{vid}) \in \mathbb{R}^3$ with values in $[-1, 1]$ [S1].
*   Shadow ratio $\rho_d(\mathbf{x}, t, \text{vid}) \in [0, 1]$ [S1].

### Data Structures
The scene is decomposed into $K$ spatial cells with centroids $\mathbf{k} \in \mathbb{R}^3$. Each cell contains three independent multi-resolution hash table branches: Static, Dynamic, and Far-field [S1].

1.  **Multi-Resolution Hash Tables:**
    *   Consist of $L$ resolution levels, where resolution doubles between levels [S1].
    *   Each level stores $F$-dimensional feature vectors [S1].
    *   Features are stored at voxel corners, indexed via hash functions rather than direct grid lookup [S1].
    *   Hash collisions are handled via gradient averaging [S1].

2.  **Hash Indexing:**
    *   **Static Branch:** Uses 3D spatial voxels $\mathbf{v}_{l,s}$. Index: $i_{l,s} = \text{static hash}(\text{space}(\mathbf{v}_{l,s}))$ [S1].
    *   **Dynamic Branch:** Uses 4D spacetime voxels $\mathbf{v}_{l,d}$. Index: $i_{l,d} = \text{dynamic hash}(\text{space}(\mathbf{v}_{l,d}), \text{time}(\mathbf{v}_{l,d}), \text{vid})$ [S1].
    *   **Far-field Branch:** Uses 3D voxels $\mathbf{v}_{l,e}$ based on normalized direction vectors. Index: $i_{l,e} = \text{env hash}(\text{dir}(\mathbf{v}_{l,e}), \text{vid})$ [S1].
    *   The $\text{vid}$ is included in the hash function to index separate interpolating functions per video without linear memory growth, but is not used for interpolation [S1].

3.  **MLP Heads:**
    *   Small Multi-Layer Perceptrons (MLPs) take concatenated features from all $L$ levels (vector $\mathbf{f} \in \mathbb{R}^{LF}$) and auxiliary inputs to predict outputs [S1].

### Numbered Steps

1.  **Spatial Partitioning:** Split the global scene into $K$ spatial cells. For each cell, generate a training dataset including only data points whose camera rays intersect the cell. Prune irrelevant rays using LiDAR depth measurements to ensure visibility [S1].

2.  **Voxel Lookup:** For a query $(\mathbf{x}, \mathbf{d}, t, \text{vid})$, find surrounding voxels at $L$ resolution levels for the static branch ($\mathbf{v}_{l,s}$), dynamic branch ($\mathbf{v}_{l,d}$), and far-field branch ($\mathbf{v}_{l,e}$) [S1].

3.  **Hash Indexing:** Compute hash indices for the corners of the surrounding voxels using the specific hash functions defined above [S1].

4.  **Feature Interpolation:**
    *   Look up feature vectors corresponding to the hashed corners [S1].
    *   Perform linear interpolation for the static branch [S1].
    *   Perform quadlinear interpolation for the dynamic 4D branch [S1].
    *   Concatenate interpolated features from all $L$ levels into a feature vector $\mathbf{f} \in \mathbb{R}^{LF}$ [S1].

5.  **Branch-Specific MLP Evaluation:**
    *   **Static Branch:** Input $\mathbf{f}$ and lighting conditioning $\mathbf{A}_{\text{vid}} \mathbf{F}(t)$ into MLP. Output view-dependent color $\mathbf{c}_s(\mathbf{x}, \mathbf{d}, \mathbf{A}_{\text{vid}} \mathbf{F}(t)) \in \mathbb{R}^3$ and view-independent density $\sigma_s(\mathbf{x}) \in \mathbb{R}$ [S1]. $\mathbf{F}(t)$ is a Fourier-encoded time index [S1]. $\mathbf{A}_{\text{vid}}$ is a video-specific matrix [S1].
    *   **Dynamic Branch:** Input $\mathbf{f}$ into MLP. Output time/video-dependent density $\sigma_d(\mathbf{x}, t, \text{vid}) \in \mathbb{R}$, color $\mathbf{c}_d(\mathbf{x}, t, \text{vid}, \mathbf{d}) \in \mathbb{R}^3$, shadow ratio $\rho_d(\mathbf{x}, t, \text{vid}) \in [0, 1]$, semantic features $\boldsymbol{\Phi}_d(\mathbf{x}, t, \text{vid}) \in \mathbb{R}^C$, and scene flow $\mathbf{s}_{t_0}(\mathbf{x}, t, \text{vid}) \in \mathbb{R}^3$ [S1].
    *   **Far-field Branch:** Output environment map color $\mathbf{c}_e(\mathbf{d}, \text{vid}) \in \mathbb{R}^3$ and semantic features $\boldsymbol{\Phi}_e(\mathbf{d}, \text{vid}) \in \mathbb{R}^C$ [S1].
    *   **Static Semantic Features:** Output $\boldsymbol{\Phi}_s(\mathbf{x}) \in \mathbb{R}^C$ [S1].

6.  **Density and Radiance Combination:**
    *   Compute total density: $\sigma(\mathbf{x}, t, \text{vid}) = \sigma_s(\mathbf{x}) + \sigma_d(\mathbf{x}, t, \text{vid})$ [S1].
    *   Compute total radiance:
        $$ \mathbf{c}(\mathbf{x}, t, \text{vid}, \mathbf{d}) = \frac{(1 - \rho_d)\sigma_s \mathbf{c}_s + \sigma_d \mathbf{c}_d}{\sigma} $$
        [S1]
    *   Compute total semantic features by blending $\boldsymbol{\Phi}_s, \boldsymbol{\Phi}_d, \boldsymbol{\Phi}_e$ using the same weights as radiance [S1].

7.  **Rendering:**
    *   Sample points $\mathbf{r}(t)$ along a camera ray $\mathbf{r}$ with direction $\mathbf{d}$ at frame $t$ and video $\text{vid}$ [S1].
    *   Compute transmittance $T(t) = \exp\left(-\int_0^t \sigma(\mathbf{r}(s), t, \text{vid}) ds\right)$ [S1].
    *   Render color:
        $$ \hat{\mathbf{C}}(\mathbf{r}, t, \text{vid}) = \int_0^{+\infty} T(t)\sigma(\mathbf{r}(t), t, \text{vid})\mathbf{c}(\mathbf{r}(t), t, \text{vid}, \mathbf{d}) dt + T(+\infty)\mathbf{c}_e(\mathbf{d}, \text{vid}) $$
        [S1]
    *   Render features $\hat{\mathbf{F}}(\mathbf{r})$ similarly [S1].
    *   Render expected depth $\hat{D}(\mathbf{r}) = \int_0^{+\infty} T(s)\sigma(\mathbf{r}(s)) ds$ [S1].

8.  **Loss Calculation:**
    *   **Reconstruction:** Minimize L2 photometric loss $\mathcal{L}_c(\mathbf{r}) = \|\mathbf{C}(\mathbf{r}) - \hat{\mathbf{C}}(\mathbf{r})\|^2$ and L1 feature loss $\mathcal{L}_f(\mathbf{r}) = \|\mathbf{F}(\mathbf{r}) - \hat{\mathbf{F}}(\mathbf{r})\|_1$ [S1].
    *   **Depth:** Minimize $\mathcal{L}_d(\mathbf{r}) = \|D(\mathbf{r}) - \hat{D}(\mathbf{r})\|^2$ [S1].
    *   **Flow:** Predict 3D position $\hat{\mathbf{X}}_{t_0}(\mathbf{r}) = \int_0^{+\infty} T(t)\sigma(\mathbf{r}(t))(\mathbf{r}(t) + \mathbf{s}_{t_0}(\mathbf{r}(t))) dt$. Render to 2D using neighboring camera matrix. Minimize $\mathcal{L}_o(\mathbf{r}) = \sum_{t_0} \|\mathbf{X}(\mathbf{o}) - \hat{\mathbf{X}}_{t_0}(\mathbf{r})\|_1$ against observed optical flow $\mathbf{O}$ [S1].
    *   **3D Warping:** Advect samples using $\mathbf{s}_{t_0}$ to get warped density $\sigma^w$, color $\mathbf{c}^w$, features $\boldsymbol{\Phi}^w$. Render warped color $\hat{\mathbf{C}}^w$ and feature $\hat{\mathbf{F}}^w$. Downweight loss in ambiguous regions using weight $W_{t_0}(\mathbf{r})$ derived from dynamic geometry difference. Minimize $\mathcal{L}_c^w$ and $\mathcal{L}_f^w$ [S1].
    *   **Flow Regularization:** Enforce cycle consistency $\mathcal{L}_{cyc}(\mathbf{r}) = \sum_{t_0} \sum_{\mathbf{x}} w_{t_0}(\mathbf{x}, t) \|\mathbf{s}_{t_0}(\mathbf{x}, t) + \mathbf{s}_t(\mathbf{x} + \mathbf{s}_{t_0}, t - t_0)\|_1$. Encourage spatial/temporal smoothness $\mathcal{L}_{sm}$ and static scene prior $\mathcal{L}_{slo} = \sum_{t_0} \sum_{\mathbf{x}} \|\mathbf{s}_{t_0}(\mathbf{x}, t)\|_1$ [S1].
    *   **Static-Dynamic Factorization:** Apply skewed binary entropy loss $\mathcal{L}_e(\mathbf{r}) = \int_0^{+\infty} H\left(\frac{\sigma_d(\mathbf{r}(t))}{\sigma_s(\mathbf{r}(t)) + \sigma_d(\mathbf{r}(t))}\right) dt$ with $k=1.75$, where $H(x) = -(x \log x + (1-x) \log (1-x))$. Penalize max dynamic ratio $\mathcal{L}_d(\mathbf{r}) = \max\left(\frac{\sigma_d}{\sigma_s + \sigma_d}\right)$ along each ray [S1].
    *   **Shadow Loss:** Penalize squared magnitude of shadow ratio $\mathcal{L}_\rho(\mathbf{r}) = \int_0^{+\infty} \rho_d(\mathbf{r}(t))^2 dt$ [S1].
    *   Total Loss: $\mathcal{L} = \mathcal{L}_c + \lambda_f \mathcal{L}_f + \lambda_d \mathcal{L}_d + \lambda_o \mathcal{L}_o + \mathcal{L}_c^w + \lambda_f \mathcal{L}_f^w + \lambda_f \mathcal{L}_{cyc} + \mathcal{L}_{sm} + \mathcal{L}_{slo} + \lambda_e \mathcal{L}_e + \lambda_d \mathcal{L}_d + \lambda_\rho \mathcal{L}_\rho$ [S1].

### Parameters
*   $F$: Dimensionality of feature vectors in hash tables [S1].
*   $L$: Number of resolution levels in hash table hierarchy (resolution doubles between levels) [S1].
*   $N$: Number of input videos [S1].
*   $\text{vid}$: Video ID identifier [S1].
*   $\mathbf{A}_{\text{vid}}$: Video-specific matrix for lighting conditioning [S1].
*   $\mathbf{F}(t)$: Fourier-encoded time index [S1].
*   $k$: Constant set to 1.75 in skewed binary entropy loss [S1].
*   $C$: Dimensionality of DINO feature grid output ($\mathbb{R}^{H \times W \times C}$) [S1].
*   Training iterations: 250,000 [S1].
*   Rays per batch: 4,098 [S1].
*   Initial learning rate: $5 \times 10^{-3}$ [S1].
*   Final learning rate: $5 \times 10^{-4}$ (decayed from initial) [S1].
*   Optimizer: Adam [S1].

### Edge Cases and Pitfalls
*   **Hash Collisions:** Handled via gradient averaging [S1].
*   **Ambiguous Regions:** Warping losses are downweighted in regions with ambiguous dynamic geometry [S1].
*   **Lighting Variations:** Modeled via video-specific matrix $\mathbf{A}_{\text{vid}}$ and Fourier-encoded time $\mathbf{F}(t)$ to handle dramatic changes across videos while maintaining smoothness within a video [S1].
*   **Memory Growth:** Using $\text{vid}$ in the hash function avoids linear memory growth with the number of videos [S1].
*   **Visibility:** LiDAR depth is used to prune rays that do not terminate within the spatial cell of interest, preventing occlusion artifacts [S1].

## Operating characteristics

*   **Time Complexity:** Training takes 250,000 iterations. SUDS is 10x quicker to train than state-of-the-art methods relying on ground truth 3D bounding box annotations [S1].
*   **Memory Complexity:** Scales to tens of thousands of objects across 1.2 million frames from 1700 videos spanning hundreds of kilometers [S1]. Uses multi-resolution hash tables to manage memory efficiently compared to per-object NeRFs (e.g., NSG requires >1TB for 30s video) [S1].
*   **Performance:** Surpasses state-of-the-art methods on KITTI and Virtual KITTI 2 datasets [S1].
*   **Strengths:** Handles ego-motion, multi-video representations, large-scale urban scenes, and dynamic objects without supervised 3D labels [S1].
*   **Limitations:** Relies on self-supervised 2D descriptors and optical flow, which may be less accurate than ground truth labels in challenging conditions [S1].

## Background

*   **Origin:** SUDS was introduced in the paper "SUDS: Scalable Urban Dynamic Scenes" [S1].
*   **History:** It addresses the limitations of prior dynamic scene representations that required supervised inputs like panoptic segmentation labels or bounding boxes, which are difficult to acquire for in-the-wild captures [S1]. It builds on ideas from Instant-NGP for hash tables and MegaNeRF for spatial partitioning [S1].
*   **Usage:** Used for free-viewpoint rendering of dynamic urban scenes, unsupervised 3D instance segmentation, and unsupervised 3D cuboid detection [S1].
