# NeRF-GT Baseline Training Setup
Also called: NeRF-GT
## Overview
The NeRF-GT baseline establishes a reference upper bound for novel view synthesis by training a standard Neural Radiance Field (NeRF) on high-dynamic-range (HDR) ground truth data [S1]. It differs from standard NeRF implementations by utilizing HDR inputs to mitigate the information loss inherent in low-dynamic-range (LDR) captures, serving as a performance ceiling for methods that must recover HDR information from LDR inputs [S1].
## How it works
**Inputs and Outputs:**
*   **Input:** A set of HDR views (or consistently exposed LDR views) representing the scene, along with corresponding camera poses.
*   **Output:** A trained NeRF model capable of rendering HDR views.

**Data Structures:**
*   **NeRF Model:** Standard MLP-based radiance field representation (position and viewing direction encoded via positional encoding).
*   **Ray Sampling:** Uniform sampling along rays for coarse and fine phases.

**Steps:**
1.  **Training:** Train the NeRF model using the HDR views as input targets [S1].
2.  **Prediction:** For each ray, query the NeRF to predict the HDR color value.
3.  **Tone Mapping:** Apply a tone-mapping operator to the predicted HDR pixel values to convert them into LDR pixel values [S1].
4.  **Loss Computation:** Compute the loss by comparing the tone-mapped predicted LDR values to the tone-mapped ground truth LDR views [S1].

**Parameters:**
*   **Coarse Samples:** 64 samples per ray [S2, unofficial].
*   **Fine Samples:** 128 samples per ray [S2, unofficial].
*   **Batch Size:** 2,048 rays per batch [S2, unofficial].
*   **Resolution:** 800 × 600 pixels [S2, unofficial].
*   **Iterations:** 200,000 solver steps [S2, unofficial].

**Pitfalls:**
*   Training directly on HDR views can fail to encode all areas of a scene well due to the high dynamic range, even when using tone-mapped colors for loss calculation [S1].

## Subtopics

### NeRF Baseline
The standard NeRF baseline trained on LDR data without HDR ground truth, serving as a lower bound compared to the NeRF-GT HDR baseline [S1].

## Operating characteristics
*   **Time Complexity:** 0.40 seconds per iteration [S2, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** Rendering time is approximately 32 seconds per frame [S2, unofficial].
*   **Strengths:** Provides an upper bound on performance by utilizing full HDR information [S1].
*   **Limitations:** High dynamic range can lead to poor encoding of scene areas if not handled carefully [S1].

## Background
The NeRF-GT baseline originates from the HDR-NeRF paper, which introduced the concept of training NeRF on HDR data to evaluate the limits of novel view synthesis [S1]. It is used as a reference point in comparative studies to assess the effectiveness of methods that synthesize HDR views from LDR inputs [S1].
