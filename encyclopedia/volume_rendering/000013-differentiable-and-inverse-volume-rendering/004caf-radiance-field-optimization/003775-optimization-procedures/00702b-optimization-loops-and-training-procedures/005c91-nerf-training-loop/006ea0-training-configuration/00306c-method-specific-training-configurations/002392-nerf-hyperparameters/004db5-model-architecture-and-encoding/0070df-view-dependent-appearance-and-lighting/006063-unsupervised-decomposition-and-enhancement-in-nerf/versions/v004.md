# Unsupervised Decomposition and Enhancement in NeRF

Also called: LLNeRF, Lighting up NeRF

## Overview
This method decomposes the view-dependent color output of a NeRF into a view-dependent lighting component $v$ and a view-independent reciprocal color basis $r$, then enhances $v$ using a neural network to produce an enhanced image $I_e$ without ground truth supervision [S1]. It differs from 2D Retinex methods by leveraging 3D geometry and multi-view consistency to constrain decomposition, avoiding the need for paired low-light/high-light training data [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Low-light training images (RAW or processed), camera poses, and intrinsics.
*   **Output:** Enhanced novel view images $I_e$ and the decomposed radiance field parameters.

**Data Structures:**
The model consists of three main neural networks:
1.  **Radiance Field ($F$):**
    *   $F_1(\tau, \mathbf{d}; \Theta_{F1})$: MLP predicting the lighting component $v$. Input: spatial coordinate $\tau$ and view direction $\mathbf{d}$. Output: scalar $v$.
    *   $F_2(\tau; \Theta_{F2})$: MLP predicting the reciprocal component $r$. Input: spatial coordinate $\tau$. Output: 3-channel vector $r$.
    *   *Note:* The standard NeRF density prediction is also present but not explicitly detailed in the decomposition formulas [S1].
2.  **Enhancement Model ($\phi$):**
    *   **Feature MLP 1:** 8 hidden layers, 256 channels each. Input: $v$.
    *   **Feature MLP 2:** 1 hidden layer, 256 channels. Input: output of Feature MLP 1.
    *   **Coeff MLP:** 1 hidden layer, 128 channels. Input: output of Feature MLP 2. Output: coefficients $\alpha$ (scalar) and $\gamma$ (3D vector).
    *   **Color MLP:** 1 hidden layer, 128 channels. Input: output of Feature MLP 2. Output: 3-channel correction (used in some variants, but the primary enhancement uses $\alpha, \gamma$) [S1].

**Numbered Steps:**
1.  **Ray Casting:** For each pixel, cast a ray through the scene. Sample $N$ points $\tau_i$ along the ray.
2.  **Decomposition:** For each sample $i$, compute the lighting component $v_i = F_1(\tau_i, \mathbf{d}; \Theta_{F1})$ and the reciprocal component $r_i = F_2(\tau_i; \Theta_{F2})$ [S1].

4.  **Rendering:** Compute the enhanced color $\hat{c}_r$ for the pixel by accumulating samples:
    $$ \hat{c}_r = \sum_i w_i \hat{v}_i \circ r_i $$
    The enhanced image is $I_e = \{ \hat{c}_r \}$ [S1].

**Formulas:**
*   **Decomposition:**
    $$ v = F_1(\tau, \mathbf{d}; \Theta_{F1}) $$
    $$ r = F_2(\tau; \Theta_{F2}) $$
    $$ c = v \circ r $$
    $$ \hat{c} = \phi(v) \circ r $$
    [S1]

*   **Enhancement Function:**
    $$ \hat{v} = \phi(v) = \left( \frac{v}{\gamma_0} \right)^{\alpha} \cdot \gamma $$
    Where $\alpha$ is a scalar, $\gamma$ is a 3D vector, and $\gamma_0$ is a fixed initialization constant [S1].

*   **Loss Functions:**
    1.  **Gray-world Prior-based Colorimetric Supervision ($L_c$):**
        $$ L_c = \mathbb{E}[(\hat{c}_r - e)^2] + \lambda_1 \mathbb{E}\left[ \frac{\text{var}_c(\hat{c}_r)}{\beta_1 + \text{var}_c(r_r)} \right] + \lambda_2 \|\gamma\|^2 $$
        Where $e=0.55$ is the target brightness, $\text{var}_c$ is channel-wise variance, and $\lambda_1, \lambda_2, \beta_1$ are hyper-parameters [S1].
    2.  **Smoothness Prior-based Supervision ($L_s$):**
        $$ L_s = L_{s\alpha} + L_{s\gamma} $$
        $$ L_{s\alpha} = \frac{1}{2} \left[ \frac{(\alpha_r - \alpha_{rh})^2}{(v_r - v_{rh})^2 + \epsilon_1} + \frac{(\alpha_r - \alpha_{rv})^2}{(v_r - v_{rv})^2 + \epsilon_1} \right] $$
        $$ L_{s\gamma} = \frac{1}{2} \left[ \frac{(\gamma_r - \gamma_{rh})^2}{(v_r - v_{rh})^2 + \epsilon_1} + \frac{(\gamma_r - \gamma_{rv})^2}{(v_r - v_{rv})^2 + \epsilon_1} \right] $$
        Where $\alpha_r, \gamma_r, v_r$ are the integrated coefficients and lighting component for a ray, and subscripts $h, v$ denote horizontal and vertical neighbors in image space. $\epsilon_1$ is a small constant [S1].
    3.  **Data Loss:**
        $$ L_{data} = \mathbb{E}[\eta(\tilde{c}_r) - \eta(c_r)] $$
        Where $\eta(y) = \log(y + \epsilon_2)$, $\tilde{c}_r$ is the observed RAW pixel, and $c_r$ is the predicted color. $\epsilon_2$ is a small constant [S1].

**Parameters:**
*   $\alpha$: Scalar output by $\phi$, adjusts lighting gain globally [S1].
*   $\gamma$: 3D vector output by $\phi$, corrects color distortion [S1].
*   $\gamma_0$: Fixed value to initialize the non-linear transform [S1].
*   $e$: Hyper-parameter for gray-world prior, set to 0.55 [S1].
*   $\lambda_1, \lambda_2, \beta_1$: Hyper-parameters for $L_c$ [S1].
*   $\epsilon_1$: Small constant in $L_s$ denominator [S1].
*   $\epsilon_2$: Small constant in tone mapping $\eta$ [S1].

**Pitfalls:**
*   In RAW images, non-linear ISP processes change noise distribution. Without correction, predicted color $c_r$ converges to a biased value $\bar{c} + b$ instead of true color $\bar{c}$, leading to color distortions [S1]. The method addresses this via $L_c$ and $L_s$.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class EnhancementModel(nn.Module):
    def __init__(self):
        super().__init__()
        # Feature MLP 1: 8x256
        self.feat1 = nn.Sequential(
            nn.Linear(1, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU()
        )
        # Feature MLP 2: 1x256
        self.feat2 = nn.Sequential(
            nn.Linear(256, 256), nn.ReLU()
        )
        # Coeff MLP: 1x128 -> 4 (alpha + gamma)
        self.coeff_mlp = nn.Sequential(
            nn.Linear(256, 128), nn.ReLU(),
            nn.Linear(128, 4) # [alpha, gamma_r, gamma_g, gamma_b]
        )
        self.gamma_0 = 1.0 # Fixed value

    def forward(self, v):
        # v is scalar (N,)
        x = self.feat1(v)
        x = self.feat2(x)
        coeffs = self.coeff_mlp(x)
        alpha = coeffs[:, 0] # (N,)
        gamma = coeffs[:, 1:] # (N, 3)
        
        # Enhancement: v_hat = (v / gamma_0)^alpha * gamma
        # v is scalar, gamma is 3D. Result is (N, 3)
        # Note: v must be broadcasted to (N, 1) for multiplication with gamma (N, 3)
        v_expanded = v.unsqueeze(1) # (N, 1)
        v_hat = (v_expanded / self.gamma_0) ** alpha.unsqueeze(1) * gamma
        return v_hat, alpha, gamma

class NeRFDecomposition(nn.Module):
    def __init__(self):
        super().__init__()
        # F1: v = F1(tau, d) -> scalar
        self.F1 = nn.Sequential(
            nn.Linear(6, 256), nn.ReLU(), # tau(3) + d(3)
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 1)
        )
        # F2: r = F2(tau) -> 3D
        self.F2 = nn.Sequential(
            nn.Linear(3, 256), nn.ReLU(), # tau(3)
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 3)
        )
        self.enhancer = EnhancementModel()

    def forward(self, tau, d):
        v = self.F1(torch.cat([tau, d], dim=-1)).squeeze(-1) # (N,)
        r = self.F2(tau) # (N, 3)
        
        v_hat, alpha, gamma = self.enhancer(v)
        
        # Enhanced color: c_hat = v_hat * r
        # v_hat is (N, 3), r is (N, 3)
        c_hat = v_hat * r
        
        return c_hat, v, r, alpha, gamma

def render_ray(tau_samples, d, nerf_model, weights):
    """
    tau_samples: (N, 3)
    d: (3,)
    weights: (N,)
    """
    c_hat, v, r, alpha, gamma = nerf_model(tau_samples, d)
    
    # Accumulate enhanced color
    c_r = torch.sum(c_hat * weights.unsqueeze(1), dim=0) # (3,)
    
    # Accumulate integrated coefficients for smoothness loss
    alpha_r = torch.sum(alpha * weights, dim=0) # Scalar
    gamma_r = torch.sum(gamma * weights, dim=0) # (3,)
    v_r = torch.sum(v * weights, dim=0) # Scalar
    
    return c_r, alpha_r, gamma_r, v_r

def compute_smoothness_loss(alpha_r, gamma_r, v_r, neighbors):
    """
    neighbors: dict with 'h' and 'v' keys, each containing alpha, gamma, v for horizontal/vertical neighbors
    """
    eps1 = 1e-6
    
    # L_sa
    alpha_h = neighbors['h']['alpha']
    alpha_v = neighbors['v']['alpha']
    v_h = neighbors['h']['v']
    v_v = neighbors['v']['v']
    
    l_sa_h = (alpha_r - alpha_h)**2 / ((v_r - v_h)**2 + eps1)
    l_sa_v = (alpha_r - alpha_v)**2 / ((v_r - v_v)**2 + eps1)
    l_sa = 0.5 * (l_sa_h + l_sa_v)
    
    # L_sg
    gamma_h = neighbors['h']['gamma']
    gamma_v = neighbors['v']['gamma']
    
    l_sg_h = torch.sum((gamma_r - gamma_h)**2) / ((v_r - v_h)**2 + eps1)
    l_sg_v = torch.sum((gamma_r - gamma_v)**2) / ((v_r - v_v)**2 + eps1)
    l_sg = 0.5 * (l_sg_h + l_sg_v)
    
    return l_sa + l_sg

    # L_c = E[(c_hat_r - e)^2] + lambda1 * E[var_c(c_hat_r) / (beta1 + var_c(r_r))] + lambda2 * ||gamma||^2
    # Note: c_hat_r and r_r are per-pixel.
    
    term1 = (c_hat_r - e)**2
    
    var_c_c_hat = torch.var(c_hat_r, dim=1, unbiased=False) # Channel-wise variance
    var_c_r = torch.var(r_r, dim=1, unbiased=False)
    
    term2 = var_c_c_hat / (beta1 + var_c_r)
    
    term3 = torch.sum(alpha**2) # ||gamma||^2? Source says ||gamma||^2. 
    # Wait, source says lambda2 ||gamma||^2. 
    # In the loss formula, it is ||gamma||^2. 
    # But gamma is the output of the network. 
    # Is it the integrated gamma or the per-sample gamma?
    # Source: "Lc = ... + lambda2 ||gamma||^2". 
    # Usually regularization is on the parameters or the output.
    # Given "prevent overfitting", it's likely on the output gamma.
    # But which gamma? The per-ray integrated gamma? Or per-sample?
    # The smoothness loss uses integrated alpha/gamma.
    # The color loss uses c_hat_r (integrated).
    # It is consistent to use integrated gamma for L_c as well.
    # However, the source doesn't explicitly say "integrated gamma".
    # Let's assume it's the integrated gamma for consistency with c_hat_r.
    
    # Re-reading: "Lc = E[(c̃r − e)^2] + ...". 
    # The expectation is over pixels.
    # So we need integrated gamma.
    
    return term1 + lambda1 * term2 + lambda2 * (gamma_r**2).sum() # ||gamma_r||^2

def compute_data_loss(c_r, c_tilde_r, eps2=1e-6):
    # L_data = E[eta(c_tilde_r) - eta(c_r)]
    # eta(y) = log(y + eps2)
    # Note: Source says E[eta(c_tilde_r) - eta(c_r)]. 
    # This is a difference, not squared error.
    # But usually it's MSE. 
    # Source: "E[η(c̃r) − η(cr)]". 
    # This looks like a regression loss without square? 
    # Or is it MSE of the log values?
    # "data loss in [21], which is the linearization of E[η(c̃r) − η(cr)]"
    # RawNeRF [21] uses MSE on the log domain.
    # So L_data = MSE(eta(c_tilde_r), eta(c_r)).
    
    eta_tilde = torch.log(c_tilde_r + eps2)
    eta_pred = torch.log(c_r + eps2)
    
    return torch.mean((eta_tilde - eta_pred)**2)
```

## Operating characteristics
*   **Time Complexity:** Depends on the number of samples per ray and the depth of the MLPs. The enhancement network adds a small overhead per sample.
*   **Memory Complexity:** Requires storing parameters for $F_1$, $F_2$, and $\phi$. The enhancement network is relatively small (8x256 + 1x256 + 1x128 layers).
*   **Strengths:** Unsupervised; does not require paired low-light/high-light data. Leverages 3D geometry for consistent decomposition. Handles color distortion caused by ISP noise bias.
*   **Limitations:** Relies on the assumption that noise in RAW images is zero-mean. Performance depends on the quality of the smoothness prior and gray-world assumption.
*   **When to use:** Low-light novel view synthesis where ground truth high-light images are unavailable.
*   **When not to use:** When paired data is available (supervised methods may be more effective).

## Background
Originated in the paper "Lighting up NeRF via Unsupervised Decomposition and Enhancement" [S1]. It addresses the issue of color distortion and low brightness in NeRFs trained on low-light images. Unlike 2D Retinex methods that require ground truth, this method uses 3D geometry and multi-view consistency to constrain the decomposition [S1].
