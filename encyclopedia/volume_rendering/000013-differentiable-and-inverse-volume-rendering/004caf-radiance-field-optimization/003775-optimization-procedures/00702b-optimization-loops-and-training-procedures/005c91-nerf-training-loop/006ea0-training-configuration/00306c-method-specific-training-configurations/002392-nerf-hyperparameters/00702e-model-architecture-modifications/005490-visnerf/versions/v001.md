# ViSNeRF

Also called: ViSNeRF (ViSualization Synthesis NeRF)

## Overview
ViSNeRF is a hybrid neural radiance field method designed for the efficient synthesis of visualizations from dynamic volumetric scenes with arbitrary adjustable parameters (e.g., time, isovalue, transfer function coefficients) [S1]. It solves the scalability problem of representing high-dimensional $(3+K)$-D radiance fields by combining explicit feature grids with implicit MLP decoders and applying generalized tensor factorization [S1]. Unlike standard NeRF which uses a single MLP, ViSNeRF factorizes the static 3D spatial volume into vector-matrix components and the $K$-D parameter space into CP components, reducing memory complexity from $O(N^3 M^K)$ to $O(N^2 M)$ [S1]. It is distinguished from siblings like [K-Planes](11770-nerf-vpt.md) and [HexPlane](11770-nerf-vpt.md) by its specific use of separate small MLPs for density and color decoding and its tailored regularization strategies for explicit grid features [S1].

## How it works
**Inputs:**
*   Training dataset: A set of 2D images (DVR or IR) of volumetric scenes, each associated with a camera pose (origin, direction) and scene parameters $\mathbf{p} = (p_0, p_1, \dots, p_{K-1})$ [S1].
*   Scene bounding box: Defines the spatial extent of the volume [S1].

**Outputs:**
*   Rendered image $\hat{C}(r)$ for a given ray $r$ and scene parameters [S1].
*   Optimized model parameters (feature grids and MLP weights) [S1].

**Data Structures:**
1.  **Spatial Feature Grid ($T^3$):** A 3D tensor of size $N \times N \times N$ (initially $128^3$, up to $300^3$) [S1]. It is not stored as a dense tensor but factorized into:
    *   Three spatial matrices: $M^X_{XY}, M^Y_{XZ}, M^Z_{YZ}$ representing XY, XZ, and YZ planes [S1].
    *   Three spatial vectors: $v^X, v^Y, v^Z$ representing axes X, Y, Z [S1].
    *   The feature depth for density is $R_\sigma=16$ and for color is $R_c=48$, totaling $R_s=64$ low-rank components [S1].
2.  **Parameter Feature Grid ($T^K$):** A $K$-D tensor where dimensions correspond to the number of distinct values for each parameter in the training set (e.g., $M^1=11$ for 11 timesteps) [S1]. Factorized into $R_p=4$ one-rank components, each being the outer product of $K$ vectors $v^1_r \circ v^2_r \circ \dots \circ v^K_r$ [S1].
3.  **MLP Decoders:** Two small Multi-Layer Perceptrons, $g_\sigma$ (density) and $g_c$ (color), each with one hidden layer of 128 channels [S1].

**Numbered Steps:**

1.  **Ray Casting and Sampling:**
    Cast rays from screen pixels toward the scene from camera locations. For each ray, estimate the integral using stratified sampling with $n$ samples along the ray segment $[t_n, t_f]$ [S1]. The step size is $\delta_i = t_{i+1} - t_i$ [S1].

2.  **Feature Retrieval:**
    For each sample point $x$ at location $(x,y,z)$ and scene parameters $\mathbf{p}$:
    *   Retrieve features from the spatial factorization. The spatial feature $f(x)$ is computed by combining the vector-matrix pairs via element-wise multiplication:
        $$ f(x) = \sum_{r=1}^{R_s} \left( (M^X_{XY,r} \circ v^Z_r) + (M^Y_{XZ,r} \circ v^Y_r) + (M^Z_{YZ,r} \circ v^X_r) \right) $$
        *Note: The source describes combining features from spatial matrices and vectors through element-wise multiplications between each vector-matrix pair, then concatenating outcomes [S1]. The formula in Eq. 4 shows the sum of outer products. The implementation note clarifies element-wise multiplication is used to combine the sampled vector and matrix values for a specific coordinate [S1].*
    *   Retrieve features from the parameter factorization. The parameter feature $f_p(\mathbf{p})$ is computed by combining parameter vectors via element-wise multiplication:
        $$ f_p(\mathbf{p}) = \sum_{r=1}^{R_p} (v^1_r \circ v^2_r \circ \dots \circ v^K_r) $$
    *   Concatenate the spatial and parameter features to construct the final feature vector $f(x, \mathbf{p})$ [S1].

3.  **Decoding:**
    *   Encode the view direction $d$ using Spherical Harmonics (SH) encoding $E_{SH}(d)$ [S1].
    *   Encode the position $x$ using Positional Encoding (PE) $E_P(x)$ [S1].
    *   Compute density $\sigma(x)$ using the density MLP:
        $$ \sigma(x) = g_\sigma(f_\sigma(x), E_P(x)) $$
        where $f_\sigma$ is the density component of the concatenated feature [S1].
    *   Compute color $c(x)$ using the color MLP:
        $$ c(x) = g_c(f_c(x), E_{SH}(d)) $$
        where $f_c$ is the color component of the concatenated feature [S1].

4.  **Volume Rendering:**
    Compose the visualization by collecting sampled points. The estimated color $\hat{C}(r)$ is:
    $$ \hat{C}(r) = \sum_{i=1}^{n} T_i (1 - \exp(-\sigma_i \delta_i)) c_i $$
    where transmittance $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$ [S1].

5.  **Loss Computation and Optimization:**
    Compute the total loss $L$:
    $$ L = L_{REC} + \lambda_1 L_{L1} + \lambda_2 L_{TV} $$
    *   $L_{REC}$: Mean Squared Error (MSE) between predicted color $\hat{C}(r)$ and ground truth [S1].
    *   $L_{L1}$: L1 norm regularization on grid weights. For parameter vectors $v_p$, weights are regularized to 1: $L_{L1} = \sum_{W \in v_p} ||1 - w||$. For other vectors/matrices $W$: $L_{L1} = \sum_{w \in W} ||w||_1 / |W|$ [S1].
    *   $L_{TV}$: Total Variation loss on density and appearance features.
        $$ L_{TV} = L_{TV1} + L_{TV2} $$
        $$ L_{TV1} = \frac{1}{|V||Q|l} \sum_{v,q,i} ||v_{i,q} - v_{i-1,q}||_2 $$
        $$ L_{TV2} = \frac{1}{|M||Q|hw} \sum_{M,q,i,j} (||M_{q,i,j} - M_{q,i-1,j}||_2^2 + ||M_{q,i,j} - M_{q,i,j-1}||_2^2) $$
        where $v$ are vectors, $M$ are matrices, $Q$ is channels, $l$ is vector length, $h,w$ are matrix dimensions [S1].

6.  **Training Schedule:**
    *   Initialize spatial grid $N=128$. For complex scenes, increase resolution at iterations 2,000, 4,000, 6,000, 8,000 to final $300^3$ [S1].
    *   At iteration 2,000, create a mask volume for empty voxels and shrink the bounding box [S1].
    *   At iteration 4,000, update mask and enable voxel skipping [S1].
    *   Train for 30,000 iterations for static scenes; 90,000 for dynamic scenes [S1].

## Operating characteristics
*   **Time Complexity:** Training is faster than baselines like InSituNet and CoordNet. For the five jets dataset, training time is 1.43 hours vs 39.22 hours for InSituNet [S1]. Inference time is slower than GAN-based methods (InSituNet, StyleGAN2) but acceptable (1.86 FPS for 256x256) [S1].
*   **Memory Complexity:** Reduces spatial memory from $O(N^3)$ to $O(N^2)$ and parameter space from $O(M^K)$ to $O(M)$ [S1]. Model size is small: 15.43 MB for five jets, 69.91 MB for Tangaroa [S1].
*   **Hardware Requirements:** Minimum 32 GB RAM and 10 GB VRAM; 64 GB RAM and 16 GB VRAM recommended for high-resolution datasets [S1].
*   **Strengths:** Handles arbitrary number of parameters; super-resolution synthesis (256x256 to 1024x1024); robust with sparse training data (95% less data than InSituNet) [S1].
*   **Limitations:** Inference is slower than traditional DVR/IR and GANs; high initial memory usage for loading high-res datasets (e.g., 29 GB for Tangaroa rays) before filtering [S1].

## Background
ViSNeRF was introduced in 2025 by researchers investigating efficient multidimensional neural radiance field representations for visualization synthesis of dynamic volumetric scenes [S1]. It builds on the NeRF architecture  and TensoRF [S1], adapting tensor factorization techniques (Block-Term and CP) to handle dynamic scenes with multiple control parameters (time, isovalue, transfer functions) [S1]. It is used in scientific visualization for super-resolution synthesis and parameter-space exploration of simulation data (e.g., Nyx, Tangaroa, five jets) [S1].
