# Training Setup and Baselines

## Overview
This family defines the hyperparameter configurations, optimization loops, and baseline protocols required to train radiance field models. It establishes the standard for reproducible convergence on static scenes, serving as a reference point for comparing novel optimization methods [11349-nerf-gt-baseline-training-setup]. It differs from standard NeRF baselines by incorporating specific architectural adaptations, such as replacing positional encoding with pre-sampled feature vectors [13271-nerf-training-setup], or adapting 2D GAN stabilization techniques for 3D-aware synthesis [12972-stylegan2-training-configuration].
## Shared principles
The training process generally involves:
1.  **Data Input:** Calibrated training images with known camera poses and intrinsics.
2.  **Ray Sampling:** Randomly selecting rays from training views to sample points along the viewing frustum.
3.  **Network Query:** Evaluating neural networks (MLPs or grids) at sampled points to predict density ($\sigma$) and color ($\mathbf{c}$).
4.  **Volume Rendering:** Computing the final pixel color via the discretized volume rendering integral:
    $$ C(\mathbf{r}) = \int_{t_n}^{t_f} T(t)\sigma(\mathbf{p})c(\mathbf{p}, \mathbf{d})dt $$
    where $T(t) = \exp\left(-\int_{t_n}^{t} \sigma(\mathbf{p})ds\right)$ [13271-nerf-training-setup].
5.  **Loss Computation:** Minimizing the difference between rendered colors and ground truth pixel colors, typically using Mean Squared Error (MSE).
6.  **Optimization:** Updating network parameters using gradient descent (e.g., Adam optimizer).

## Subtopics

### [NeRF-GT Baseline Training Setup](11349-nerf-gt-baseline-training-setup.md)
Establishes a standard training configuration for the original Neural Radiance Fields (NeRF) model. It prioritizes high-fidelity scene fitting using a fixed coarse-to-fine sampling strategy (64 coarse, 128 fine samples) and a batch size of 2,048 rays at 800×600 resolution. It serves as a reference point for comparing novel radiance field optimization methods, requiring 200,000 solver steps for convergence.

### [StyleGAN2 Training Configuration](12972-stylegan2-training-configuration.md)
Adapts the StyleGAN2 training protocol for 3D-aware image synthesis (e.g., VoxGRAF). It solves the problem of stable GAN convergence by leveraging 2D GAN stabilization techniques: equalized learning rates, minibatch standard deviation in the discriminator, and R1 regularization ($\gamma=1$ every 4 minibatches). It explicitly excludes path regularization and style-mixing for efficiency and compatibility with 3D generation pipelines.

### [NeRF Training Setup](13271-nerf-training-setup.md)
Establishes a reproducible training pipeline using Nerfstudio, NerfAcc, and Instant-NGP. It distinguishes itself by replacing the positionally encoded 3D position input with a pre-sampled 64-dimensional feature vector from a volume, omitting positional encoding for spatial coordinates while retaining it for viewing directions. It is designed for static environments (e.g., surgical scenes) at 504×378 resolution, using 1024 rays per batch.

### [NLR Baseline](15254-nlr-baseline.md)
Represents a scene as a set of neural networks mapping 3D positions to color and density, optimized via ray marching. It serves as a foundational baseline for differentiable volume rendering, distinguishing itself from NeRF by using a specific architecture for shape and color networks. It is later adapted for meta-learning in variants like MetaNLR.

### NeuralVDB Hyperparameter Configuration
*   **Step:** Either draw $2^{16}$ random samples per epoch, or resample a subset of input voxels at fixed intervals (100 or 500) and draw $2^{12}$ batches per epoch. Resampling is used when fine details with thin structures are critical [S1, unofficial].
*   **Parameter:** Subdomain size must be a multiple of 512 to balance empty space waste and dispatch overhead [S1, unofficial]. Level-1 networks use half the width of level-0 networks (default width 128, depth 3; use 4 layers for more detail) [S1, unofficial]. Optimizer is Adam with LR 0.001, decaying by 0.975 every 100 epochs (no resampling) or 0.75 every 1,000 epochs (with resampling) [S1, unofficial]. Max epochs: 2,500 for non-resampled [S1, unofficial].
*   **Comparison:** Sparse VDB with active voxel masks yields the best visual quality and low noise, whereas dense grid training produces the highest noise and block grid shows visible fog artifacts [S1, unofficial].

### Neural Codebook Training Configuration
*   **Step:** Multiply learning rate by 0.3 for every 5,000 iterations. Cast the trained Neural Codebook (NCB) to float16 after training [S2].
*   **Parameter:** Optimizer is Adam with $\beta_1 = 0.9$ and $\beta_2 = 0.999$. Weight decay is $1e-5$. Initial learning rate is $5e-3$. Total training iterations: 20,000. Batch size: 100,000 voxels [S2].

## Background
The NeRF-GT baseline originates from the original Neural Radiance Fields paper, establishing the standard for high-fidelity volume rendering optimization [11349-nerf-gt-baseline-training-setup]. The StyleGAN2 configuration adapts techniques from Karras et al. for 3D-aware generative models [12972-stylegan2-training-configuration]. The Nerfstudio-based setup leverages modern libraries like NerfAcc and Instant-NGP for fast convergence on static scenes [13271-nerf-training-setup]. The NLR baseline provides a foundational architecture for neural radiance fields [15254-nlr-baseline]. NeuralVDB and Neural Codebook configurations address specific efficiency and compression challenges in sparse volume representations [S1, unofficial][S2].
