# Model Architecture and Encoding

Also called: NeRF Architecture, Radiance Field MLPs, Feature Grids

## Overview
Model Architecture and Encoding defines the neural network structures and input representations used to map 3D spatial coordinates and viewing directions to volume density and color. It solves the problem of how to represent a continuous radiance field efficiently and differentiably for volume rendering. It is distinguished from sibling methods by its focus on the internal connectivity of the density and color networks (e.g., skip connections, bottleneck features) and the mathematical encoding of input coordinates (e.g., positional encoding, hash grids, tensor decomposition), whereas siblings like [NeRF Initialization Strategies](8674-nerf-initialization-strategies.md) focus on parameter starting values and [Regularization Techniques](11314-regularization-techniques.md) focus on loss constraints.

## Shared principles
The standard NeRF architecture [Parent](13550-model-architecture-and-encoding.md) consists of two Multi-Layer Perceptrons (MLPs): a density network and a color network. Both networks take encoded 3D spatial coordinates $\mathbf{x}$ as input. The color network additionally takes encoded viewing directions $\mathbf{d}$.

The density network outputs a volume density $\sigma \in \mathbb{R}$ and a bottleneck feature vector $\mathbf{e} \in \mathbb{R}^D$. The color network takes $\mathbf{e}$ and the encoded viewing direction $\mathbf{d}$ to output the color $\mathbf{c} \in \mathbb{R}^3$.

Input encoding is typically performed using sinusoidal positional encoding $\gamma(\cdot)$, defined as:
$$
\gamma(p) = \left[ \sin(2^0 \pi p), \cos(2^0 \pi p), \dots, \sin(2^{L-1} \pi p), \cos(2^{L-1} \pi p) \right]
$$
where $L$ is the number of frequency bands.

## Subtopics

### [Depth-Guided NeRF Training Configuration](11916-depth-guided-nerf-training-configuration.md)
[Depth-Guided NeRF Training Configuration](11916-depth-guided-nerf-training-configuration.md) modifies the standard NeRF architecture by inserting dropout layers with probability $p=0.1$ after each of the first eight fully connected ReLU-activated layers in the positional encoding network. It is chosen when depth supervision is required to improve geometry reconstruction and training stability, distinguishing itself by using fixed dropout regularization rather than architectural changes to the density/color networks themselves.

### [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md)
[CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md) freezes the density network parameters and optimizes only the color/feature fields. It is chosen for text-guided stylization, distinguishing itself by measuring cosine similarity in CLIP embedding space between rendered images and text prompts, rather than optimizing for photometric reconstruction.

### [Binary Radiance Fields](13622-binary-radiance-fields.md)
[Binary Radiance Fields](13622-binary-radiance-fields.md) replaces real-valued feature grids with binary parameters constrained to $\{+1, -1\}$ using a Straight-Through Estimator (STE) for gradient propagation. It employs a 2D-3D hybrid multi-resolution architecture with 3D voxel grids and 2D plane grids. It is chosen for storage efficiency, distinguishing itself by performing binarization during training without additional optimization steps, unlike post-processing compression methods.

### [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md)
[Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md) integrates positional encoding with the uncertainty (covariance) of input points to account for aliasing effects. It uses a configuration with specific depths and widths for density and color MLPs, including skip connections and integrated positional encoding. It is chosen for anti-aliased rendering of unbounded scenes, distinguishing itself by mapping Gaussian distributions rather than points.

### [SUDS](14964-suds.md)
[SUDS](14964-suds.md) factorizes the scene into three separate multi-resolution hash table branches: Static, Dynamic, and Far-field. It is chosen for large-scale dynamic urban scenes, distinguishing itself by handling ego-motion and temporal dynamics through spatial partitioning and hash-based feature storage, avoiding expensive 3D annotations.

### [CCNeRF](15008-ccnerf.md)
[CCNeRF](15008-ccnerf.md) replaces the implicit MLP-based query with an explicit tensor rank decomposition (hybrid CP and Tucker). It is chosen for efficient compression and composition of 3D scenes, distinguishing itself by modeling the radiance field *only* with tensor rank decomposition, allowing dynamic model size adjustment via rank truncation.

### [Rip-NeRF](15532-rip-nerf.md)
[Rip-NeRF](15532-rip-nerf.md) uses Ripmap-Encoded Platonic Solids to enable efficient anisotropic area-sampling. It is chosen for high-fidelity, anti-aliased rendering, distinguishing itself by using an anisotropic 3D Gaussian characterization of conical frustums projected onto Platonic solid faces, whereas Zip-NeRF relies on a less efficient multi-sampling mechanism.

### [UE4-NeRF](15539-ue4-nerf.md)
[UE4-NeRF](15539-ue4-nerf.md) partitions the environment into sub-NeRFs represented as textured polygonal meshes (regular octahedra) integrated into the Unreal Engine 4 rasterization pipeline. It is chosen for real-time interactive rendering of large-scale scenes, distinguishing itself by using a mesh-based representation with a neural shader, enabling real-time frame rates and scene editing.

### [Generative Occupancy Fields (GOF)](15773-generative-occupancy-fields-gof.md)
[Generative Occupancy Fields (GOF)](15773-generative-occupancy-fields-gof.md) reinterprets alpha values from volume rendering as occupancy probabilities. It is chosen for 3D-aware image synthesis, distinguishing itself by resolving shape-color ambiguity and diffused surface artifacts inherent in standard cumulative rendering, maintaining differentiable continuous representations while ensuring compact surfaces.

### [Panoptic Radiance Field](15849-panoptic-radiance-field.md)
[Panoptic Radiance Field](15849-panoptic-radiance-field.md) extends the radiance field representation to include semantic class distributions and instance identifiers. It is chosen for panoptic lifting from 2D masks, distinguishing itself by requiring only machine-generated 2D labels and employing robustness mechanisms like bounded fields and gradient blocking to handle label noise.

### Triplane NeRF with Diffusion Prior
The framework uses a triplane NeRF representation where scene codes are optimized jointly with a diffusion prior to handle sparse-view data and ensure end-to-end coherence [S1]. The denoising model is a U-Net with 122M parameters, taking noisy and denoised triplane features as input and output [S1]. The prediction format uses v-parameterization $\hat{x} = \alpha(t)x(t) - \sigma(t)\hat{v}$ [S1]. The weighting function uses SNR-based weighting $w(t) = (\alpha(t)/\sigma(t))^2\omega$ [S1]. The scene code $x_i$ has shape $\mathbb{R}^{3 \times 6 \times 128 \times 128}$ [S1].

### EG3D Triplane Representation
EG3D uses a hybrid triplane representation $T \in \mathbb{R}^{256 \times 256 \times 96}$, corresponding to 3 axis-aligned planes (xy, xz, yz), each with 32 channels and resolution $256 \times 256$ [S2]. It renders a feature image $I_f \in \mathbb{R}^{32 \times 128 \times 128}$ and raw RGB image $I_{128} \in \mathbb{R}^{3 \times 128 \times 128}$ by accumulating points along rays and performing volume rendering [S2]. A dense depth map $I_D \in \mathbb{R}^{128 \times 128}$ is also extracted [S2]. These are fed into a 2D super-resolution network to yield $I_{512} \in \mathbb{R}^{3 \times 512 \times 512}$ via $SuperRes(I_f, I_{128}) = I_{512}$ [S2]. Rendering speed is 42 fps on RTX 3090 [S2].

### NeRF-W Hyperparameter Configuration
NeRF-W uses a Base MLP with 8 layers of 512 hidden units, and Static/Transient MLPs with 4 layers of 128 hidden units each [S3]. Positional encoding frequencies are 15 for position and 4 for viewing direction [S3]. Sampling uses 512 points per ray per model (1024 total) during training, doubled to 2048 during evaluation [S3]. Appearance embedding dimension is $n(a)=48$, transient object embedding is $n(\tau)=16$ [S3]. L1 regularizer multiplier is $\lambda_u=0.01$, minimum importance threshold is $\beta_{min}=0.03$ [S3]. Optimizer is Adam, batch size 2048, initial learning rate 0.001, decaying ten-fold every 150,000 iterations, over 300,000 iterations total [S3]. These hyperparameters were optimized for the Brandenburg Gate scene and reused for remaining scenes [S3].

### Explicit Mesh Reconstruction from Neural Fields
An algorithm extracts an explicit 3D mesh from the implicit neural radiance field learned by CodeNeRF, allowing for 3D reconstruction from a single input image [S4]. The center coordinates of a $256^3$ voxel grid are fed to the CodeNeRF MLP to obtain volume density values $\sigma$ [S4]. The Marching Cubes algorithm is applied to $\sigma$ to find mesh vertices [S4]. Rays are cast along the vertex normals to associate colors to the vertices [S4].

### Efficient EndoNeRF scene representation
Efficient EndoNeRF is a voxel-grids-based scene representation that replaces coordinate-based MLPs with explicit density and feature volume grids to accelerate optimization, combined with a canonical field and time-dependent deformation field for dynamic surgical scenes [S5]. The dynamic scene at time $t$ is modeled by warping a canonical radiance field (represented by $\mathbf{V}_\sigma$ and $\mathbf{V}_a$) with a time-dependent deformation field [S5]. The deformation field is modeled using decomposed 4D motion fields and a 3-layer MLP that maps a spatial-temporal coordinate $(\mathbf{x}, t)$ to a deformation offset $\Delta \mathbf{x}$ [S5].

### NeRF-Liif
NeRF-Liif is a baseline method that super-resolves LR images using a pretrained LIIF (Local Implicit Image Function) model, which requires LR-HR pairs for training and introduces external data priors [S6]. On the synthetic Blender dataset, LIIF may produce false predictions due to domain mismatch with its external training set [S6]. On the real-world LLFF dataset, LIIF tends to be oversmooth and may predict false color or geometry [S6]. Performance metrics: Blender ×2 (100x100): PSNR 27.07, SSIM 0.919, LPIPS 0.067; Blender ×4 (100x100): PSNR 25.36, SSIM 0.885, LPIPS 0.125; Blender ×2 (200x200): PSNR 28.81, SSIM 0.934, LPIPS 0.058; Blender ×4 (200x200): PSNR 27.34, SSIM 0.912, LPIPS 0.096; LLFF ×2: PSNR 26.81, SSIM 0.823, LPIPS 0.145; LLFF ×4: PSNR 24.76, SSIM 0.723, LPIPS 0.292 [S6].

### UniSurf
UniSurf is a method unifying volume rendering (radiance fields) and surface rendering (implicit surfaces) to achieve high-quality geometry and sharp textures without mask supervision [S7, unofficial]. It uses an occupancy field where the occupancy at the $i^{th}$ sample corresponds to an indicator of surface presence [S7, unofficial]. It uses volume rendering in the early stage for optimization without mask supervision, and surface rendering in the later stage to extract level-set surfaces [S7, unofficial]. Unlike pure surface rendering which requires mask supervision and has blurry texture mapping, this method provides high-quality novel views and sharp textures/colors without mask supervision [S7, unofficial].

## Background
The standard NeRF architecture was introduced by Mildenhall et al. in 2020 [S7, unofficial]. Subsequent works have modified this architecture to address specific challenges such as aliasing (Mip-NeRF), storage efficiency (Binary Radiance Fields, CCNeRF), dynamic scenes (SUDS), real-time rendering (UE4-NeRF), and generative modeling (GOF, Triplane NeRF with Diffusion Prior).
