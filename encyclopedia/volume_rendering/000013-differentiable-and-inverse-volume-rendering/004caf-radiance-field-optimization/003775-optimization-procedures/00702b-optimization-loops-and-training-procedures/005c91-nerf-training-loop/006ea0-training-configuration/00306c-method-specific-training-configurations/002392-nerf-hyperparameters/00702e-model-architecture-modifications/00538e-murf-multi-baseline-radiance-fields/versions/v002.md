# MuRF (Multi-Baseline Radiance Fields)

Also called: Multi-Baseline Radiance Fields

## Overview
MuRF is a feed-forward method for sparse view synthesis that constructs a 3D volume aligned with the **target** novel view’s frustum, rather than a reference input view [S1]. This alignment allows effective aggregation of multi-view information for both small and large baseline settings, where reference-based volumes fail due to insufficient overlap [S1]. It differs from ray-based methods (e.g., [IBRNet](13661-mine.md), [MatchNeRF](13661-mine.md)) by using a 3D context-aware CNN decoder to model scene structure explicitly [S1].

## How it works
**Inputs:** $K$ input images $\{I_k\}_{k=1}^K$ with known camera poses; target camera pose for the novel view.
**Outputs:** Rendered target image of resolution $H \times W$.

**Data Structures:**
*   **Feature Maps $\{F_k\}$:** Extracted from input images. Multi-scale features at $1/2, 1/4, 1/8$ original resolution.
*   **Target View Frustum Volume $z$:** A 4D tensor with shape $8 \times 8 \times D \times C$.
    *   $8 \times 8$: Spatial dimensions, representing the target image resolution $H \times W$ subsampled by 8.
    *   $D$: Number of equidistant depth samples along each ray.
    *   $C$: Channel dimension containing concatenated sampled colors, features, and cosine similarities.
*   **Radiance Field:** A 4D tensor of shape $H \times W \times D \times 4$ (Color + Density) after upsampling.

**Steps:**

1.  **Multi-View Feature Extraction:**
    For each input image $I_k$:
    *   Pass $I_k$ through a weight-sharing 2D CNN encoder consisting of 6 residual blocks [S1].
    *   Insert a stride-2 convolutional layer after every 2 residual blocks to downsample by 2x.
    *   This produces feature maps at resolutions $1/2, 1/4,$ and $1/8$ of the input image [S1].
    *   Feed the $1/8$ resolution features from all $K$ views into a joint multi-view Transformer. The Transformer extends 2-view cross-attention to $K$ views, processing them simultaneously to produce final multi-view features $F_k$ at $1/8$ resolution [S1].

2.  **Target View Frustum Volume Construction:**
    *   Define the target view frustum based on the target camera pose and image resolution $H \times W$ [S1].
    *   Perform 8x spatial subsampling. Cast rays for a grid of size $(H/8) \times (W/8)$ [S1].
    *   For each ray, uniformly sample $D$ equidistant 3D points within the frustum [S1].
    *   For each sampled 3D point $p$:
        *   Project $p$ into each input view $k$ to obtain 2D coordinates.
        *   Sample color $c_k$ and feature vector $f_k$ from the corresponding input image $I_k$ and feature map $F_k$ at those coordinates [S1].
        *   Compute the cosine similarity between features from different views to provide multi-view consistency cues. Specifically, compute similarities between sampled features to aid density prediction [S1].
        *   Concatenate the sampled colors, features, and computed cosine similarities to form the volume element $z$ at that location [S1].
    *   Assemble all elements into the volume tensor $z \in \mathbb{R}^{8 \times 8 \times D \times C}$ [S1].

3.  **Radiance Field Regression:**
    *   Input the low-resolution volume $z$ into a context-aware decoder [S1].
    *   The decoder uses a (2+1)D CNN to factorize 3D convolutions for efficiency:
        *   Apply a 2D $3 \times 3 \times 1$ convolution on the spatial dimensions (height, width) [S1].
        *   Apply a 1D $1 \times 1 \times 3$ convolution on the depth dimension [S1].
    *   This process regresses the radiance field properties (color and density) for the subsampled volume [S1].

4.  **Upsampling:**
    *   Pass the output of the (2+1)D CNN through a lightweight 8x upsampler to reconstruct the full-resolution radiance field of shape $H \times W \times D \times 4$ [S1].

5.  **Volumetric Rendering:**
    *   Render the target image using standard volumetric rendering [18] on the full-resolution radiance field [S1].

**Parameters:**
*   **Spatial Subsampling Factor:** 8x. Applied to the spatial dimensions of the target image when constructing the volume [S1].
*   **D:** Number of equidistant points sampled on each ray. Not given in the sources.
*   **H x W:** Resolution of the target image [S1].

**Edge Cases and Pitfalls:**
*   **Large Baselines:** Using a reference view volume (aligned with an input view) for large baselines causes failure because the overlap between the reference and target view is small, leading to missing information outside the epipolar lines of the reference view [S1]. MuRF avoids this by aligning the volume with the target view [S1].
*   **Information Loss:** The 8x subsampling risks losing information if only a single point is sampled per pixel. The method addresses this by sampling features and colors within a window or using the multi-view consistency cues [S1].

## Background
MuRF was introduced by Haofei Xu et al. in 2024 [S1]. It addresses the limitation of previous methods that constructed volumes aligned with reference input views, which failed for large baselines due to small overlap [S1]. The method builds on [Volumetric Rendering](18-volumetric-rendering.md) and uses a [Multi-View Transformer](13661-mine.md) inspired by GMFlow [S1].
