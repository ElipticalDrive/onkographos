# StylizedNeRF

Also called: Stylized NeRF

## Overview
StylizedNeRF is a method for applying artistic styles to 3D scenes represented by Neural Radiance Fields (NeRF) while maintaining geometric consistency across viewpoints [S1]. It solves the problem of view-inconsistent stylization, where standard 2D style transfer applied per-view results in flickering or geometrically incoherent 3D structures [S1]. It differs from its siblings by employing a mutual learning strategy that jointly optimizes the 3D radiance field and a 2D stylization network, using learnable latent codes to resolve ambiguities inherent in 2D stylization [S1]. Unlike [Spherical Harmonics NeRF](14480-spherical-harmonics-nerf.md) which focuses on lighting decomposition, or [Non-Photorealistic Style Editing](16597-non-photorealistic-style-editing.md) which allows region-specific styles, StylizedNeRF applies a global style to the entire scene [S1].

## How it works
**Inputs:**
*   A pre-trained NeRF model representing the original scene geometry and appearance [S1].
*   A target style image [S1].

**Outputs:**
*   A stylized NeRF model capable of rendering novel views with the target artistic style [S1].

**Data Structures:**
*   **Stylized NeRF:** The standard NeRF representation, consisting of MLPs for density ($\sigma$) and color ($\mathbf{c}$), modified to accept style information [S1].
*   **2D Stylization Network:** A 2D neural network responsible for transforming the rendered image into the target style [S1].
*   **Learnable Latent Codes:** A set of latent vectors used to inject style information into the NeRF, resolving 2D stylization ambiguities [S1].

**Method:**
The method relies on a mutual learning framework where the 3D NeRF and the 2D stylization network are optimized simultaneously [S1].

1.  **Initialization:** Initialize the original NeRF and the 2D stylization network [S1].
2.  **Ray Sampling:** For each camera pose, sample points along rays through the scene using the NeRF [S1].
3.  **Volume Rendering:** Render the original appearance of the scene from the current NeRF parameters [S1].
4.  **2D Stylization:** Pass the rendered image through the 2D stylization network to produce a stylized image [S1].
5.  **Latent Code Injection:** Use learnable latent codes to guide the stylization process, ensuring that the 3D geometry remains consistent despite the 2D style transfer [S1].
6.  **Loss Computation:** Compute losses based on the difference between the stylized output and the target style, as well as consistency losses to enforce 3D coherence [S1].
7.  **Joint Optimization:** Update both the NeRF parameters and the 2D stylization network weights using the computed losses [S1].

**Parameters:**
*   Not given in the sources.

**Edge Cases and Pitfalls:**
*   **2D Ambiguities:** 2D style transfer can introduce artifacts that are inconsistent across views. The method addresses this via learnable latent codes [S1].
*   **Geometric Consistency:** Without proper regularization, stylization may distort the underlying geometry. The mutual learning strategy helps preserve geometry [S1].

## Subtopics

### Phong Reflection Color Modeling
A variant that integrates a Phong reflection model into the NeRF optimization [S2]. It uses MLPs to predict tint, roughness, modeled normal vectors, and diffuse/specular colors from integrated average features [S2]. Modeled normals are trained with regularization losses from RefNeRF and optimized towards estimated normals via a confidence-weighted loss, which drives outlier points with abnormal normals to zero confidence [S2].

## Background
StylizedNeRF was introduced as part of the broader effort to extend NeRF capabilities to artistic applications [S1]. It addresses the limitations of previous methods that either discarded view directions (leading to loss of lighting detail) or failed to maintain 3D consistency [S1]. The method builds on the principles of differentiable volume rendering and style transfer [S1].
