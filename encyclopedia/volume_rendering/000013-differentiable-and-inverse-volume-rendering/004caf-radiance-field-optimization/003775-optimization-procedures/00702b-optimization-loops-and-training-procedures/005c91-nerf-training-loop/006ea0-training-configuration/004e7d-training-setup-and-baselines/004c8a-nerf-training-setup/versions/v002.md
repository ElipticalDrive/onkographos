# NeRF Training Setup

Also called: Control-NeRF Training Setup

## Overview
This training setup defines the configuration for optimizing radiance fields using editable feature volumes, specifically as implemented in Control-NeRF. It addresses the problem of rendering scenes from multi-view images by replacing the standard positional encoding of 3D coordinates with pre-computed feature vectors sampled from a volume. It differs from the standard NeRF baseline [11349-nerf-gt-baseline-training-setup.md] by omitting positional encoding for spatial positions and instead utilizing a 64-dimensional feature vector as the primary spatial input, while retaining positional encoding for view directions.

## How it works
**Inputs and Outputs**
*   **Inputs:** Multi-view images (e.g., LLFF dataset) scaled to $504 \times 378$ resolution; camera poses; a pre-computed volume $V_s$ containing 64-dimensional feature vectors.
*   **Outputs:** Rendered images; optimized network parameters for coarse and fine radiance functions.

**Data Structures**
*   **Volume $V_s$:** A 3D volume where each point $\mathbf{p} \in \mathbb{R}^3$ stores a 64-dimensional feature vector $\mathbf{v}_s$.
*   **Feature Vector $\mathbf{v}_s$:** Obtained via trilinear sampling $S(V_s, \mathbf{p})$. No positional encoding is applied to $\mathbf{v}_s$ [S1].
*   **Direction Vector $\mathbf{d}$:** A 3D vector representing the ray direction.

**Positional Encoding**
Positional encoding is applied only to the direction vector $\mathbf{d}$. For each dimension $p$ of $\mathbf{d}$, the encoding $\gamma(p)$ is defined as [S1]:
$$
\gamma(p) = [\sin(2^0\pi p), \cos(2^0\pi p), \dots, \sin(2^{L-1}\pi p), \cos(2^{L-1}\pi p)]
$$
where $L=4$ is the encoding depth [S1]. The encoded direction $\gamma(\mathbf{d})$ is concatenated with $\mathbf{v}_s$ to form the input to the radiance function $F_\Theta$.

**Rendering Formula**
The color $C(\mathbf{r})$ for a ray $\mathbf{r}$ is computed using the discretized volume rendering integral [S1]:
$$
C(\mathbf{r}) = \sum_{i=1}^{N} T_i \sigma_i c_i
$$
where:
*   $N$ is the number of samples per ray.
*   $\sigma_i$ is the density predicted by the network at sample $i$.
*   $c_i$ is the color predicted by the network at sample $i$.
*   $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$ is the accumulated transmittance, with $\delta_j$ being the distance between samples $j$ and $j+1$.

**Training Procedure**
The training uses a two-stage coarse-to-fine sampling strategy [S1]:
1.  **Coarse Network ($\hat{C}_c$):** Samples $N_c = 64$ points from evenly spaced bins along the ray length.
2.  **Fine Network ($\hat{C}_f$):** Uses the opacity results from the coarse network to sample $N_f = 64$ additional points, focusing on relevant portions of the scene volume (importance sampling) [S1].
3.  **Optimization:** The networks are optimized using gradient descent. The batch size is 1024 rays [S1].

**Pseudocode**
```python
def compute_direction_encoding(d, L=4):
    """
    Computes positional encoding for direction vector d.
    d: numpy array of shape (3,)
    Returns: numpy array of shape (2 * L * 3,)
    """
    encodings = []
    for dim in d:
        for l in range(L):
            freq = 2**l * np.pi
            encodings.append(np.sin(freq * dim))
            encodings.append(np.cos(freq * dim))
    return np.array(encodings)

def render_ray(ray_origin, ray_direction, volume, coarse_net, fine_net, num_coarse=64, num_fine=64):
    """
    Renders a single ray using coarse-to-fine sampling.
    """
    # 1. Coarse Sampling
    t_coarse = np.linspace(ray_origin.t_near, ray_origin.t_far, num_coarse)
    points_coarse = ray_origin + ray_direction * t_coarse
    
    # Sample features from volume
    features_coarse = trilinear_sample(volume, points_coarse) # Shape: (num_coarse, 64)
    
    # Encode direction
    d_enc = compute_direction_encoding(ray_direction)
    
    # Predict density and color for coarse network
    # Input to net: [features_coarse[i], d_enc]
    sigma_coarse, color_coarse = coarse_net.predict(features_coarse, d_enc)
    
    # 2. Fine Sampling (Importance Sampling based on coarse opacity)
    # Note: Specific importance sampling algorithm details are referenced from [23]
    # Here we assume a placeholder for the sampling logic derived from coarse sigma
    t_fine = importance_sample(t_coarse, sigma_coarse, num_fine)
    points_fine = ray_origin + ray_direction * t_fine
    
    features_fine = trilinear_sample(volume, points_fine)
    sigma_fine, color_fine = fine_net.predict(features_fine, d_enc)
    
    # 3. Volume Rendering
    # Combine coarse and fine samples
    t_all = np.concatenate([t_coarse, t_fine])
    sigma_all = np.concatenate([sigma_coarse, sigma_fine])
    color_all = np.concatenate([color_coarse, color_fine])
    
    # Sort by depth
    sort_idx = np.argsort(t_all)
    t_all = t_all[sort_idx]
    sigma_all = sigma_all[sort_idx]
    color_all = color_all[sort_idx]
    
    # Compute transmittance and final color
    deltas = np.diff(t_all, prepend=ray_origin.t_near)
    alpha = 1.0 - np.exp(-sigma_all * deltas)
    transmittance = np.cumprod(np.exp(-sigma_all * deltas), axis=0)
    transmittance = np.concatenate([[1.0], transmittance[:-1]])
    
    contribution = alpha * transmittance * color_all
    final_color = np.sum(contribution, axis=0)
    
    return final_color

def train_step(batch_rays, volume, coarse_net, fine_net, optimizer):
    """
    Performs one training step.
    """
    optimizer.zero_grad()
    
    rendered_colors = []
    for ray in batch_rays:
        color = render_ray(ray, volume, coarse_net, fine_net)
        rendered_colors.append(color)
    
    rendered_colors = np.stack(rendered_colors)
    
    # Compute photometric loss against ground truth images
    loss = mse_loss(rendered_colors, batch_rays.gt_colors)
    
    loss.backward()
    optimizer.step()
    
    return loss.item()
```

**Parameters**
*   **Encoding Depth ($L$):** 4 [S1].
*   **Feature Vector Dimension:** 64 [S1].
*   **Coarse Samples:** 64 [S1].
*   **Fine Samples:** 64 [S1].
*   **Batch Size:** 1024 rays [S1].
*   **Image Resolution:** $504 \times 378$ [S1].

**Edge Cases and Pitfalls**
*   **Volume Sampling:** Trilinear sampling requires the volume to be defined on a grid. Degenerate cases where points fall outside the volume bounds must be handled (e.g., by clamping or returning zero density) [G].
*   **Precision:** Mixed-precision training is not explicitly detailed in the source for this specific setup, but is a common practice in similar radiance field optimizations [12972-stylegan2-training-configuration.md].

## Operating characteristics
*   **Time Complexity:** Determined by the number of samples per ray ($N_c + N_f = 128$) and the batch size (1024). The directional encoding adds a constant overhead per ray.
*   **Memory Complexity:** Depends on the size of the feature volume $V_s$ and the network parameters. The feature volume is pre-computed, reducing the need to predict spatial features from coordinates.
*   **Strengths:** Replaces high-dimensional positional encoding of 3D positions (60 parameters for $L=10$ in standard NeRF) with a fixed 64-dimensional feature vector, potentially simplifying the network's spatial learning task [S1].
*   **Limitations:** Requires a pre-computed feature volume, which adds a preprocessing step. The source does not provide specific scaling metrics or hardware benchmarks for this setup.

## Background
This setup is derived from Control-NeRF, which introduces editable feature volumes for scene rendering and manipulation. It modifies the standard NeRF architecture by substituting the positionally encoded 3D position input with a sampled feature vector from a volume, while maintaining positional encoding for view directions [S1]. The training follows the coarse-to-fine sampling strategy popularized by NeRF [23].
