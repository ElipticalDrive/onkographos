# NeRF with Time Parameter

Also called: NeRF + time, NeRF with Time Parameter Baseline, Time-NeRF

## Overview
This method adapts the static Neural Radiance Field (NeRF) architecture to handle dynamic scenes by explicitly incorporating time as an input dimension [S1]. It solves the problem of rendering temporal variations in geometry and appearance that vanilla NeRF cannot represent, which typically results in ghosting or blurring when applied to moving subjects [S1]. It differs from sibling methods like [Gear-NeRF](13848-gear-nerf.md) or [Forward Warping for Novel View Synthesis](15541-forward-warping-for-novel-view-synthesis.md) by using a direct 6D conditioning approach rather than learning deformation fields or canonical space mappings [15546-dynamic-scene-and-temporal-modeling.md].

## How it works
The method extends the standard 5D NeRF input domain $(\mathbf{x}, \mathbf{d})$ to 6D $(\mathbf{x}, \mathbf{d}, t)$, where $\mathbf{x} \in \mathbb{R}^3$ is spatial position, $\mathbf{d} \in \mathbb{R}^3$ is viewing direction, and $t \in \mathbb{R}$ is time [14705-nerf-with-time-parameter.md]. The rendered color $C(r, t)$ for a ray $r$ at time $t$ is computed via the volume rendering integral:

$$
C(r, t) = \int_{s_n}^{s_f} T(s, t)\sigma(\mathbf{r}(s), t)c(\mathbf{r}(s), \mathbf{d}, t)ds
$$

where the accumulated transmittance $T(s, t)$ is:

$$
T(s, t) = \exp\left(-\int_{s_n}^{s} \sigma(\mathbf{r}(s'), t)ds'\right)
$$

[15550-dynamic-appearance-particle-neural-radiance-field.md].

**Inputs and Outputs:**
*   **Input:** A dataset of images with known camera poses and timestamps $t$.
*   **Output:** A neural network that maps $(\mathbf{x}, \mathbf{d}, t)$ to density $\sigma$ and color $c$.

**Data Structures:**
The network architecture follows the standard NeRF MLP structure but with an expanded input layer.
*   **Positional Encoding:** The time parameter $t$ is positionally encoded using the same function $\gamma$ as spatial coordinates.
*   **Concatenation:** The encoded time vector $\gamma_t(t)$ is concatenated with the encoded spatial coordinates $\gamma_x(\mathbf{x})$ before entering the density branch of the network. The viewing direction $\mathbf{d}$ is encoded separately and concatenated later in the color branch.

**Steps:**
1.  **Encode Time:** Apply positional encoding to the scalar time value $t$ to produce $\gamma_t(t)$.
2.  **Encode Space:** Apply positional encoding to the 3D spatial coordinate $\mathbf{x}$ to produce $\gamma_x(\mathbf{x})$.
3.  **Concatenate:** Concatenate $\gamma_t(t)$ and $\gamma_x(\mathbf{x})$ to form the combined input vector for the density network.
4.  **Compute Density:** Pass the concatenated vector through the density MLP to output $\sigma(\mathbf{x}, t)$.
5.  **Compute Color:** Pass $\mathbf{x}$ and $\mathbf{d}$ through the color MLP (potentially conditioned on intermediate features) to output $c(\mathbf{x}, \mathbf{d}, t)$.
6.  **Render:** Sample points along rays and accumulate color and transmittance using the volume rendering integral defined above.

**Parameters:**
*   **Training Configuration:** The method is trained using the configuration reported for NeRF's real forward-facing experiments [S1]. Specific hyperparameters (learning rate, number of layers, etc.) are not detailed in the sources beyond this reference.

**Edge Cases and Pitfalls:**
*   **Blurriness:** The method suffers from blurry predictions and lacks detail compared to more advanced dynamic methods [S1].
*   **Lack of Dynamics Reasoning:** It fails to explicitly reason about scene dynamics, relying solely on the implicit capacity of the network to map time to appearance changes [S1].
*   **Ghosting:** While improved over vanilla NeRF, it may still exhibit artifacts if the temporal sampling is insufficient or if the network capacity is too low to capture rapid changes.

## Subtopics

### Temporal Compression of NeRF Models
A compression strategy for sequences of NeRF models that exploits temporal redundancy by treating the first model as a key-frame and compressing only the deltas between successive models [S2].
*   **Definition:** Exploits the similarity between neighboring NeRF models in a sequence [S2].
*   **Steps:**
    1.  Initialize the NeRF for the first frame from scratch (trained from the beginning) [S2].
    2.  For subsequent frames, initialize the new NeRF based on the previous frame's trained NeRF to encourage temporal redundancy and save training time [S2].
    3.  Calculate the delta between the current frame's NeRF weights and the previous frame's NeRF weights [S2].
    4.  Apply exponent-based quantization and Huffman coding to the deltas [S2].
    5.  To restore a model, accumulate the decoded deltas to the reference model (the previous frame's model) [S2].
*   **When to choose:** When storage or transmission bandwidth is limited and the scene changes gradually over time [S2].

## Operating characteristics
*   **Time Complexity:** Training time is comparable to standard NeRF but may be slightly higher due to the additional input dimension and the need to capture temporal variations. The compression variant significantly reduces training time for subsequent frames by leveraging previous weights [S2].
*   **Memory Complexity:** The model size is slightly larger than static NeRF due to the time input. The compression variant reduces storage requirements by storing only deltas [S2].
*   **Performance:** Improves quality over vanilla NeRF on dynamic scenes but still lacks detail and suffers from blurry predictions [S1]. It fails to reason about scene dynamics effectively [S1].
*   **Strengths:** Simple to implement; builds directly on existing NeRF codebases; effective for slowly changing scenes [S1, S2].
*   **Limitations:** Blurry results; poor handling of complex dynamics; no explicit motion modeling [S1].
*   **When to use:** Baseline for dynamic scene reconstruction; scenarios with limited computational resources for training complex deformation fields [S1].
*   **When not:** When high-fidelity detail is required; when scenes have complex, non-rigid motion [S1].

## Background
The method was introduced as a baseline for adapting NeRF to dynamic scenes by adding a time parameter to the model inputs [S1]. It was evaluated on the KITTI dataset to assess its ability to reconstruct seen frames and novel scene compositions [S1]. The approach highlights the limitations of simple time conditioning, motivating more advanced methods like Neural Scene Graphs [S1]. The temporal compression variant was proposed to address the storage overhead of training multiple NeRF models for video sequences [S2].
