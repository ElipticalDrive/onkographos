# NeuRay

Also called: Neural Rays

## Overview
NeuRay is an occlusion-aware image-based rendering method that represents a scene by estimating occlusion probabilities (hitting probabilities) from input views to arbitrary 3D points, enabling efficient novel view synthesis [S1]. Unlike standard radiance field methods that treat volume density as a continuous scalar, NeuRay explicitly models visibility to handle feature inconsistency caused by occlusions, particularly in sparse or 360-degree captures [S1]. It differs from sibling methods like IBRNet by integrating a visibility encoder and using spherical harmonics to fit anisotropic colors, allowing it to outperform baselines in generalization and fine-tuning settings where occlusions are prevalent [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of $N$ input images with known camera poses (intrinsics and extrinsics) [S1]. For rendering a test view, a subset of $N_w$ neighboring input images (working views) is selected [S1].
*   **Outputs:** A synthesized RGB image for the test view, and optionally depth maps [S1].

**Data Structures**
1.  **Cost Volume:** Constructed using $N_s=3$ neighboring source views [S1]. Dimensions are $H/4 \times W/4 \times D$, where $D=64$ is the number of disparity planes [S1].
2.  **Visibility Feature:** A feature map of size $H/4 \times W/4 \times 32$ generated by the Initialization Network and refined by the Visibility Encoder [S1].
3.  **Spherical Harmonics Coefficients:** For each sample point, a vector $\boldsymbol{\theta}_i \in \mathbb{R}^{16}$ representing SH coefficients up to degree 3 [S1].
4.  **Hitting Probability:** A scalar $\hat{h}_i$ representing the probability that a point $p_i$ is visible from the test view, derived from a mixture of logistics distributions [S1].

**Network Architecture**
The model consists of shared encoders and task-specific decoders for coarse and fine stages [S1].
1.  **Image Encoder:** A ResNet with 13 residual blocks, outputting a feature map with 32 channels [S1]. Convolution layers use ReLU; batch normalization is replaced by instance normalization [S1].
2.  **Initialization Network:**
    *   Inputs: Image feature ($H/4 \times W/4 \times 64$), Depth regression ($H/4 \times W/4 \times 32$), Cost Volume ($H/4 \times W/4 \times 1$) [S1].
    *   Structure: Conv3x3(32) $\rightarrow$ ResBlock(32) $\rightarrow$ Conv1x1(32) [S1].
    *   Output: Visibility Feature ($H/4 \times W/4 \times 32$) [S1].
3.  **Visibility Encoder:**
    *   Inputs: Visibility Feature ($H/4 \times W/4 \times 32$), Image feature ($H/4 \times W/4 \times 96$) [S1].
    *   Structure: Conv3x3(32) $\rightarrow$ ResBlock(32) $\rightarrow$ Conv1x1(32) [S1].
    *   Output: Refined Visibility Feature ($H/4 \times W/4 \times 32$) [S1].
4.  **Decoder F (Distribution):** Contains 5 sub-networks, each with 3 fully-connected layers [S1]. Predicts $\mu_1, \mu_2, \sigma_1, \sigma_2$ and mixing weight $w_0$ (where $w_1 = 1 - w_0$) [S1]. Uses ReLU for hidden layers, SoftPlus/Sigmoid for output [S1].
5.  **Aggregation Networks (Coarse/Fine):**
    *   **Network $\mathcal{M}$ (Feature Aggregation):** Inputs are Visibility features ($N \times K \times 32$), View directions ($N \times K \times 3$), Image features ($N \times K \times 3$) [S1].
        *   Process: MLP(1,32,32) on visibility, MLP(3,32,32) on directions, MLP(32,32,1) on image features [S1]. Element-wise product [S1]. MLP(32,32,32) [S1]. Element-wise plus [S1]. MLP(192,64,32) [S1]. Transformer [S1]. MLP(16,1) [S1]. Output: Aggregated feature [S1].
    *   **Network $\mathcal{A}$ (Alpha):** Inputs are Mean ($N \times 1 \times 32$) and Var ($N \times 1 \times 32$) [S1]. MLP(35,16,8,1) followed by Softmax [S1]. Output: Alpha value $\alpha_i \in [0,1]$ [S1].
    *   **Network $\mathcal{B}$ (Blending):** Inputs are Mean ($N \times 1 \times 32$) and Var ($N \times 1 \times 32$) [S1]. MLP(64,32,16) followed by sigmoid [S1]. Output: Blending weights ($N \times K \times 1$) [S1].

**Numbered Steps**
1.  **Initialization:** Construct a cost volume using COLMAP patch-match stereo and $N_s=3$ source views [S1]. Pass image features through the Image Encoder, Initialization Network, and Visibility Encoder to obtain the Refined Visibility Feature [S1].
2.  **Ray Sampling:** For a test ray $r(\lambda) = o + \lambda d$, sample $K_{t,1}$ points for the coarse stage and $K_{t,2}$ points for the fine stage [S1]. Default values are $K_{t,1}=64, K_{t,2}=64$ [S1]. Use the coarse model to estimate hitting probabilities $\hat{h}_i$ for all coarse points [S1]. Perform coarse-to-fine sampling: select fine points based on the distribution defined by the coarse hitting probabilities [S1].
3.  **Visibility and Alpha Computation:** For each sample point $p_i$, compute the hitting probability $\hat{h}_i$ using the mixture of $N_l=2$ logistics distributions parameterized by the Decoder F [S1]. Compute the alpha value $\alpha_i = \mathcal{A}(\mathbf{f}_i)$, where $\mathbf{f}_i$ is the aggregated feature [S1]. The network $\mathcal{A}$ assigns large $\alpha_i$ when features from visible input views are consistent [S1].
4.  **Color Computation (Radiance Field Rendering):** Compute the color $\mathbf{c}_i$ for point $p_i$ using the color blending network $\mathcal{B}$:
    $$ \mathbf{c}_i = \mathcal{B}(\mathbf{f}_i, \{\mathbf{f}_{i,j}; \mathbf{r}_{i,j} - \mathbf{r}; \mathbf{c}_{i,j}; v_{i,j}\}) $$
    where $\mathbf{r}_{i,j}$ is the view direction from the $j$-th input view to $p_i$, $\mathbf{c}_{i,j}$ is the projected color, and $v_{i,j}$ is the visibility [S1]. Render the final pixel color $\hat{c}$ using alpha compositing weighted by hitting probabilities:
    $$ \hat{c} = \sum_i \mathbf{c}_i \hat{h}_i $$
    [S1].
5.  **Spherical Harmonics Fitting (Direct Rendering / Anisotropic Color):** To represent anisotropic colors, fit a function $R(\mathbf{r}; \boldsymbol{\theta}_i)$ on the sphere for each point $p_i$ using spherical harmonics [S1]. Solve the linear least squares problem for coefficients $\boldsymbol{\theta}_i$:
    $$ \min_{\boldsymbol{\theta}_i} \sum_j \tilde{h}_{i,j}(z_{i,j}, z_{i,j}+l_i) \|R(\mathbf{r}_{i,j}; \boldsymbol{\theta}_i) - \mathbf{c}_{i,j}\|^2 + \boldsymbol{\theta}_i^\intercal \boldsymbol{\Lambda} \boldsymbol{\theta}_i $$
    where $\tilde{h}_{i,j}$ is the hitting probability, $\boldsymbol{\Lambda}$ is a diagonal regularization matrix with elements $(0, 0.001, 0.005, 0.01)$ for degrees 0 to 3, and $R$ is the SH basis function [S1]. The color is then computed as $\mathbf{c}_i = R(\mathbf{r}; \boldsymbol{\theta}_i)$ [S1].
6.  **Training and Loss:** Depth loss is $\ell_{depth} = \sum \|\mu_1 - z_{in}\|^2$, where $\mu_1$ is the mean of the first logistics distribution and $z_{in}$ is input depth from the cost volume [S1]. The color difference is weighted by hitting probabilities in the loss function to ensure occluded input rays do not interfere with output colors [S1]. During training, predicted hitting probabilities $h_i$ are memorized [S1]. If a point is invisible to view A, this is used to refine visibility predictions for other views (e.g., view D) in subsequent steps [S1].

```python
import numpy as np

def neu_ray_render(input_images, camera_poses, test_view_pose, num_working_views=8):
    """Renders a test view using NeuRay."""
    # 1. Select Working Views
    working_views = select_nearest_views(test_view_pose, camera_poses, num_working_views)
    
    # 2. Construct Cost Volume
    cost_volume = construct_cost_volume(working_views, depth_planes=64)
    
    # 3. Encode Features
    image_features = image_encoder(working_views)
    depth_regression = get_depth_from_cost_volume(cost_volume)
    visibility_feature = initialization_network(image_features, depth_regression, cost_volume)
    refined_visibility = visibility_encoder(visibility_feature, image_features)
    
    # 4. Sample Points along Test Ray
    coarse_points = sample_ray(test_view_pose, num_samples=64)
    coarse_params = distribution_decoder(refined_visibility, coarse_points)
    coarse_hitting_probs = compute_logistics_mixture(coarse_params)
    fine_points = sample_fine(coarse_points, coarse_hitting_probs, num_samples=64)
    
    # 5. Compute Alpha and Color for Fine Points
    aggregated_features = feature_aggregation_network(refined_visibility, fine_points, working_views)
    alpha_values = alpha_network(aggregated_features)
    colors = color_blending_network(aggregated_features, working_views, fine_points)
    
    # 6. Render
    final_color = np.zeros(3)
    for i, point in enumerate(fine_points):
        h_i = coarse_hitting_probs[i]
        c_i = colors[i]
        final_color += c_i * h_i
    return final_color

def select_nearest_views(test_pose, all_poses, k):
    """Selects k nearest camera poses based on translation distance."""
    distances = np.linalg.norm(all_poses[:, :3, 3] - test_pose[:3, 3], axis=1)
    return np.argsort(distances)[:k]

def construct_cost_volume(views, depth_planes):
    """Constructs a cost volume using correlation over depth planes."""
    # Standard MVS cost volume construction
    return np.zeros((views[0].height//4, views[0].width//4, depth_planes))

def image_encoder(views):
    """ResNet-13 with instance normalization, outputs 32 channels."""
    # Standard ResNet-13 forward pass
    return np.zeros((views[0].height//4, views[0].width//4, 32))

def get_depth_from_cost_volume(cost_volume):
    """Extracts depth map via argmax over cost volume depth dimension."""
    return np.argmax(cost_volume, axis=2)

def initialization_network(image_feat, depth_reg, cost_vol):
    """Conv3x3(32) -> ResBlock(32) -> Conv1x1(32)."""
    x = conv3x3(image_feat, 32)
    x = res_block(x, 32)
    return conv1x1(x, 32)

def visibility_encoder(vis_feat, image_feat):
    """Conv3x3(32) -> ResBlock(32) -> Conv1x1(32)."""
    x = conv3x3(vis_feat, 32)
    x = res_block(x, 32)
    return conv1x1(x, 32)

def sample_ray(view_pose, num_samples):
    """Samples points linearly along the camera ray."""
    origins = view_pose[:3, 3]
    directions = view_pose[:3, 3] # Simplified for ray direction
    t = np.linspace(0.1, 10.0, num_samples)
    return origins + t[:, None] * directions

def distribution_decoder(refined_vis, points):
    """Predicts 5 parameters: mu1, mu2, sigma1, sigma2, w0."""
    # MLP predicting 5 values per point
    return np.random.randn(len(points), 5)

def compute_logistics_mixture(params):
    """Computes CDF of mixture of 2 logistics distributions."""
    mu1, mu2, s1, s2, w0 = np.split(params, 5, axis=1)
    s1, s2 = np.maximum(s1, 1e-6), np.maximum(s2, 1e-6)
    cdf1 = 1.0 / (1.0 + np.exp(-(params[:, 0] - mu1) / s1))
    cdf2 = 1.0 / (1.0 + np.exp(-(params[:, 1] - mu2) / s2))
    return w0 * cdf1 + (1 - w0) * cdf2

def sample_fine(coarse_points, coarse_probs, num_samples):
    """Stratified sampling based on coarse hitting probabilities."""
    # Simple uniform resampling for demonstration
    return coarse_points[:num_samples]

def feature_aggregation_network(vis_feat, points, views):
    """MLP(1,32,32) -> MLP(3,32,32) -> MLP(32,32,1) -> prod -> MLP(32,32,32) -> + -> MLP(192,64,32) -> Transformer -> MLP(16,1)."""
    # Standard aggregation pipeline
    return np.random.randn(len(points), 32)

def alpha_network(aggregated_feat):
    """MLP(35,16,8,1) + Softmax."""
    return np.ones(len(aggregated_feat)) / len(aggregated_feat)

def color_blending_network(aggregated_feat, views, points):
    """MLP(64,32,16) + sigmoid."""
    return np.random.rand(len(points), 3)

def spherical_harmonics_fit(point, working_views, hitting_probs):
    """Fits spherical harmonics to anisotropic color at a point."""
    lambda_diag = np.array([0, 0.001, 0.005, 0.01])
    A_matrix = []
    b_vector = []
    for j, view in enumerate(working_views):
        h_ij = hitting_probs[j]
        r_ij = view_direction(view, point)
        c_ij = project_color(view, point)
        basis = evaluate_sh_basis(r_ij, degree=3)
        A_matrix.append(h_ij * basis)
        b_vector.append(h_ij * c_ij)
    A_mat = np.array(A_matrix)
    b_vec = np.array(b_vector)
    Lambda = np.diag(lambda_diag)
    ATA = A_mat.T @ A_mat
    ATb = A_mat.T @ b_vec
    theta = np.linalg.solve(ATA + Lambda, ATb)
    return theta

def evaluate_sh_basis(direction, degree):
    """Evaluates spherical harmonics basis functions up to given degree."""
    # Standard SH basis evaluation [G]
    x, y, z = direction
    if degree == 0: return np.array([1.0])
    if degree == 1: return np.array([y, z, x])
    if degree == 2: return np.array([x*y, y*z, 2*z**2 - x**2 - y**2, x*z, x**2 - y**2])
    # Degree 3 omitted for brevity, follows standard spherical harmonic definitions [G]
    return np.zeros(16)

def view_direction(view, point):
    return point - view[:3, 3]

def project_color(view, point):
    return np.random.rand(3)
```

**Parameters**
*   $D=64$: Number of planes in cost volume [S1].
*   $N_l=2$: Number of logistics distributions [S1].
*   $K_{t,1}=64, K_{t,2}=64$: Sample points in coarse/fine stages [S1].
*   $N_s=3$: Neighboring source views for cost volume [S1].
*   SH Degree: 3, resulting in $\boldsymbol{\theta} \in \mathbb{R}^{16}$ [S1].
*   Regularization $\boldsymbol{\Lambda}$: Diagonal elements $(0, 0.001, 0.005, 0.01)$ [S1].
*   Optimizer: Adam ($\beta_1=0.999, \beta_2=0.9$) [S1].
*   Batch Size: 512 rays per step [S1].
*   Learning Rate: Generalization $2 \times 10^{-4}$ (decay half every 100k steps); Finetuning $1 \times 10^{-4}$ (decay half every 100k steps) [S1].

**Edge Cases and Pitfalls**
*   **Invisible Regions:** NeuRay cannot render regions invisible to all working views, even if visible in other input views, because it is image-based [S1].
*   **Textureless/Cluttered Regions:** Feature matching struggles in textureless or cluttered complex regions (e.g., Ficus), leading to view inconsistency and artifacts [S1].
*   **Generalization Speed:** In generalization settings, predicted visibility is often inaccurate, preventing high-quality rendering with very few sample points [S1]. Speeding up rendering requires accurate surface location estimation, which is only reliable in finetuned models [S1].
*   **Direct Rendering Artifacts:** Direct rendering produces meaningful results but artifacts occur on edges [S1].

## Operating characteristics
*   **Time Complexity:** Rendering time is significantly reduced compared to NeRF [S1]. On the DTU 'birds' dataset, using 4-8 fine sample points speeds up rendering from 30s to ~3s (10x speedup) [S1].
*   **Memory Complexity:** Uses a cost volume of size $H/4 \times W/4 \times 64$ and feature maps of size $H/4 \times W/4 \times 32$ [S1]. The image encoder is lighter than IBRNet [S1].
*   **Performance:**
    *   **NeRF Synthetic (Lego):** NeuRay-Ft achieves 30.63 PSNR in ~32 minutes, comparable to NeRF's 30.27 PSNR in ~9.5 hours [S1].
    *   **LLFF (Nw=8):** NeuRay 27.06 PSNR vs IBRNet 26.87 PSNR [S1].
    *   **LLFF (Nw=2):** NeuRay 24.86 PSNR vs IBRNet 21.72 PSNR [S1].
    *   **Generalization (Lego, N=100):** NeuRay 28.41 PSNR vs IBRNet 25.64 PSNR [S1].
*   **Strengths:** Occlusion-aware, handles sparse 360-degree captures better than IBRNet, recovers details more clearly than NeRF with fewer training steps, fast finetuning [S1].
*   **Limitations:** Fails on regions invisible to all working views, struggles with textureless regions, generalization mode requires more samples for high quality [S1].
*   **When to Use:** Novel view synthesis with sparse or 360-degree input views, especially where occlusions are present [S1]. Suitable for scenarios requiring fast finetuning [S1].
*   **When Not to Use:** Scenes with large invisible regions relative to working views, or highly textureless environments [S1].

## Background
NeuRay was introduced in the paper "Neural Rays for Occlusion-aware Image-based Rendering" [S1]. It addresses the limitations of existing image-based rendering methods like IBRNet, which suffer from feature inconsistency due to occlusions in sparse captures [S1]. By explicitly modeling occlusion probabilities, NeuRay refines scene representation and provides better occlusion inference during finetuning [S1]. It is used on datasets such as LLFF, NeRF synthetic (Lego), and DTU [S1].
