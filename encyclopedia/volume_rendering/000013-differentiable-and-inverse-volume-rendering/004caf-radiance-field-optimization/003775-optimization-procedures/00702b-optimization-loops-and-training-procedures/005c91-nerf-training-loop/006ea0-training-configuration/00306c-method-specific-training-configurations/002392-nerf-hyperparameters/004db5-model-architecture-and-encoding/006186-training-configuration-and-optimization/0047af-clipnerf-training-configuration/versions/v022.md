# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF training configuration defines the optimization procedure for text-guided stylization of Neural Radiance Fields (NeRFs) by minimizing the negative cosine similarity between rendered image embeddings and text prompt embeddings in the CLIP latent space [S1, S2]. It distinguishes itself from standard NeRF training by freezing density-related parameters and utilizing patch-based rendering to manage memory constraints while applying directional losses to enforce stylistic trajectories [S1, S2].

## How it works
**Inputs and Outputs**
*   **Inputs:** A pre-trained NeRF model (encoding function $F_\theta$), a source image $I_{src}$ (optional, for relative loss), a target text prompt $t_{tgt}$, and a source text prompt $t_{src}$ (optional, for relative loss).
*   **Outputs:** A stylized NeRF model with updated color/feature parameters.

**Data Structures**
*   **NeRF Parameters:** Split into density-related parameters $\theta_\sigma$ and color/feature parameters $\theta_c$.
*   **CLIP Encoder:** ViT-B/32 architecture [S1].
*   **Patch:** A $128 \times 128$ pixel region of the rendered view.

**Numbered Steps**
1.  **Initialization:** Load the pre-trained NeRF. Freeze all parameters related to volume density $\sigma$ (sub-parameters $\theta_\sigma$) [S1].
2.  **Ray Sampling:** For a randomly sampled training view, sample rays. To cover a wide receptive field, sample rays within a $128 \times 128$ patch with a stride interval of 5 [S1]. This results in a receptive field of $640 \times 640$ in the original image resolution [S1].
3.  **Volume Rendering (Patch):** Render the patch using importance sampling. Reduce the number of importance sampling points to 16 per ray for memory efficiency [S1]. The fine MLP uses a total of 80 samples (64 coarse + 16 fine) [S1].
4.  **Embedding Extraction:** Pass the rendered patch $I_{tgt}$ through the CLIP image encoder $\mathcal{E}_i$ to obtain the normalized embedding $\hat{\mathcal{E}}_i(I_{tgt})$ [S2]. Pass the target text prompt $t_{tgt}$ through the CLIP text encoder $\mathcal{E}_t$ to obtain $\hat{\mathcal{E}}_t(t_{tgt})$ [S2].
5.  **Loss Calculation:** Compute the directional CLIP loss. Two variants exist:
    *   **Absolute Directional CLIP Loss:** Measures cosine similarity between the rendered image and the target text [S2].
        $$ \mathcal{L}_{dir} = 1 - \langle \hat{\mathcal{E}}_i(I_{tgt}), \hat{\mathcal{E}}_t(t_{tgt}) \rangle $$
    *   **Relative Directional CLIP Loss:** Measures the trajectory from source to target in CLIP space, using a source image $I_{src}$ and source text $t_{src}$ [S2].
        $$ \mathcal{L}_{dir} = 1 - \langle \hat{\mathcal{E}}_i(I_{tgt}) - \hat{\mathcal{E}}_i(I_{src}), \hat{\mathcal{E}}_t(t_{tgt}) - \hat{\mathcal{E}}_t(t_{src}) \rangle $$
6.  **Optimization:** Update only the color/feature parameters $\theta_c$ using the Adam optimizer [S1].
7.  **Iteration:** Repeat for 500 iterations [S1].

**Parameters**
*   **Iterations:** 500 [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** 0.0001 [S1].
*   **CLIP Model:** ViT-B/32 [S1].
*   **Patch Size:** $128 \times 128$ [S1].
*   **Ray Stride:** 5 (within the patch) [S1].
*   **Importance Sampling Points:** 16 [S1].
*   **Fine MLP Samples:** 80 total (64 coarse + 16 fine) [S1].

**Pitfalls**
*   **Memory Constraints:** Naive differentiable rendering of high-resolution images is intractable due to memory limits [S1]. The patch-based approach with reduced sampling is required [S1].
*   **Mode Collapse:** The absolute directional CLIP loss can cause mode collapse of the generator and hurt generation diversity [S2].
*   **Insufficient Magnitude:** Directional losses alone may struggle to reach sufficient stylization magnitude, resulting in weak style transfer [S2].

## Operating characteristics
*   **Time Complexity:** Proportional to the number of iterations (500) and the cost of rendering patches with 16 samples per ray [S1].
*   **Memory Complexity:** Significantly reduced compared to full-image rendering by using $128 \times 128$ patches and fewer sampling points [S1].
*   **Strengths:** Enables text-guided stylization of NeRFs; memory-efficient via patch rendering [S1, S2].
*   **Limitations:** Absolute loss risks mode collapse; directional loss may lack sufficient magnitude for strong stylization [S2].

## Background
The CLIPNeRF training configuration originates from the work on text-driven NeRF stylization, extending concepts from StyleCLIP and StyleGAN-NADA to 3D scene representations [S2]. It was introduced to address the challenge of editing NeRFs using natural language prompts while maintaining 3D consistency [S1, S2]. The method was further refined in NeRF-Art to address issues with magnitude and diversity in stylization [S2].
