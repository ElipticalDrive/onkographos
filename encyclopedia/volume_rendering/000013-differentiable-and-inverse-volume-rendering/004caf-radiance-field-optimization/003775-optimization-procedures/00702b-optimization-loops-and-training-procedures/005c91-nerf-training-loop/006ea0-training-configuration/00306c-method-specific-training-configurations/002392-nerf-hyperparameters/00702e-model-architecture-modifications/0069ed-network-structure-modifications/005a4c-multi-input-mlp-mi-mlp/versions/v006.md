# Multi-input MLP (mi-MLP)
Also called: mi-MLP, per-layer inputs incorporation

## Overview
The multi-input MLP (mi-MLP) is a network structure modification for Neural Radiance Fields that incorporates the raw input embeddings (3D location and viewing direction) into every layer of the MLP to prevent overfitting in few-shot view synthesis without reducing model capacity [S1]. Unlike the standard NeRF architecture which relies on a single deep path from inputs to outputs, mi-MLP creates shorter, explicit connections between the inputs and each hidden layer, allowing the model to synthesize high-frequency details with fewer effective parameters while maintaining the original network size [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 5D coordinate vector $\mathbf{x} \in \mathbb{R}^5$, composed of the 3D spatial position $\mathbf{p} \in \mathbb{R}^3$ and the 2D viewing direction $\mathbf{d} \in \mathbb{R}^2$ (normalized).
*   **Output:** Volume density $\sigma \in \mathbb{R}$ and view-dependent color $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures:**
The network consists of $L_{layers}$ linear layers followed by activation functions. Each layer $i$ (where $i=1, \dots, L_{layers}$) has:
*   Weight matrix $\mathbf{W}_i \in \mathbb{R}^{d_{out} \times (d_{in} + d_{enc})}$, where $d_{in}$ is the hidden dimension of the previous layer (or input dimension for $i=1$) and $d_{enc}$ is the dimension of the positional encoding.
*   Bias vector $\mathbf{b}_i \in \mathbb{R}^{d_{out}}$.
*   Activation function $\epsilon(\cdot)$, typically ReLU.

**Positional Encoding:**
The input $\mathbf{x}$ is transformed into an encoded embedding $\gamma_L(\mathbf{x})$ using a sinusoidal positional encoding with $L$ frequency bands [S1]:
$$
\gamma_L(\mathbf{x}) = (\sin(2^0 \mathbf{x}), \cos(2^0 \mathbf{x}), \dots, \sin(2^{L-1} \mathbf{x}), \cos(2^{L-1} \mathbf{x}))
$$
where $L$ is a hyperparameter controlling the frequencies [S1]. The dimension of $\gamma_L(\mathbf{x})$ is $2 \cdot L \cdot \dim(\mathbf{x})$.

**Algorithm:**
The mi-MLP computes the output of each layer $i$ by concatenating the positional encoding $\gamma_L(\mathbf{x})$ with the output of the previous layer $\mathbf{f}_{i-1}$ and passing it through the layer's linear transformation and activation [S1].

1.  Compute the positional encoding $\gamma_L(\mathbf{x})$ for the input $\mathbf{x}$.
2.  Initialize the input feature $\mathbf{f}_0 = \gamma_L(\mathbf{x})$.
3.  For each layer $i$ from 1 to $L_{layers}$:
    a. Concatenate the positional encoding with the previous layer's output: $\mathbf{z}_i = [\gamma_L(\mathbf{x}); \mathbf{f}_{i-1}]$.
    b. Compute the linear transformation: $\mathbf{a}_i = \mathbf{W}_i \mathbf{z}_i + \mathbf{b}_i$.
    c. Apply the activation function: $\mathbf{f}_i = \epsilon(\mathbf{a}_i)$.
4.  The final output features $\mathbf{f}_{L_{layers}}$ are passed to separate head networks (or linear layers) to predict $\sigma$ and $\mathbf{c}$.

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class PositionalEncoding(nn.Module):
    def __init__(self, num_frequencies: int):
        super().__init__()
        self.num_frequencies = num_frequencies

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        Computes the positional encoding gamma_L(x).
        x: Tensor of shape (..., D) where D is the input dimension (5 for NeRF).
        Returns: Tensor of shape (..., 2 * num_frequencies * D).
        """
        # x shape: (..., D)
        # freq_bands shape: (num_frequencies,)
        freq_bands = 2.0 ** torch.arange(self.num_frequencies, device=x.device, dtype=x.dtype)
        # Expand x to (..., D, num_frequencies)
        x_expanded = x.unsqueeze(-1) * freq_bands.unsqueeze(0).unsqueeze(0)
        # Compute sin and cos
        sin_vals = torch.sin(x_expanded)
        cos_vals = torch.cos(x_expanded)
        # Concatenate along the last dimension
        # Result shape: (..., D * num_frequencies * 2)
        return torch.cat([sin_vals, cos_vals], dim=-1)

class MiMLP(nn.Module):
    def __init__(self, 
                 input_dim: int = 5, 
                 hidden_dim: int = 256, 
                 num_layers: int = 8, 
                 num_frequencies: int = 10):
        super().__init__()
        self.input_dim = input_dim
        self.hidden_dim = hidden_dim
        self.num_layers = num_layers
        self.pos_encoding = PositionalEncoding(num_frequencies)
        
        # Calculate the dimension of the positional encoding
        # gamma_L(x) has size 2 * num_frequencies * input_dim
        self.enc_dim = 2 * num_frequencies * input_dim
        
        # Define layers
        # Layer 1 takes only the positional encoding
        self.layers = nn.ModuleList()
        
        # First layer: input is gamma_L(x)
        self.layers.append(nn.Linear(self.enc_dim, hidden_dim))
        
        # Subsequent layers: input is [gamma_L(x), f_{i-1}]
        for _ in range(num_layers - 1):
            # Input dimension is enc_dim + hidden_dim
            self.layers.append(nn.Linear(self.enc_dim + hidden_dim, hidden_dim))
            
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        Forward pass of the mi-MLP.
        x: Tensor of shape (..., 5) representing (x, y, z, theta, phi) or similar.
        Returns: Tensor of shape (..., hidden_dim) containing the final feature vector.
        """
        # Compute positional encoding
        # gamma_L(x) shape: (..., enc_dim)
        gamma_x = self.pos_encoding(x)
        
        # Initialize previous feature
        # f_0 is not explicitly used as a variable, but the first layer takes gamma_x
        f_prev = gamma_x
        
        for i, layer in enumerate(self.layers):
            if i == 0:
                # First layer input is just the positional encoding
                z = f_prev
            else:
                # Subsequent layers concatenate gamma_x with previous output
                # f_prev shape: (..., hidden_dim)
                # gamma_x shape: (..., enc_dim)
                z = torch.cat([gamma_x, f_prev], dim=-1)
            
            # Linear transformation
            a = layer(z)
            # Activation (ReLU)
            f_curr = F.relu(a)
            
            # Update previous feature
            f_prev = f_curr
            
        return f_prev
```

**Parameters:**
*   $L$ (number of frequency bands in positional encoding): Hyperparameter. Default values are not explicitly stated in the source, but standard NeRF uses 10 [S1, G].
*   Weight Initialization: Default PyTorch initialization is used. The source notes that this initialization satisfies the condition $\|\mathbf{w}_i^{j1}\|_1 \in (0, 1]$, which is critical for the gradient amplitude properties described below [S1].

**Edge Cases and Pitfalls:**
*   **Gradient Amplitude:** During early training, vanilla MLPs result in similar gradient amplitudes for all layers. In contrast, mi-MLP ensures that deeper layers (closer to the output) are updated with large gradients while shallower layers receive extremely small gradients [S1]. This behavior is derived from the ratio of gradient amplitudes between adjacent layers:
    $$
    \| \frac{\partial \mathcal{L}}{\partial \mathbf{w}_i} \|_1 / \| \frac{\partial \mathcal{L}}{\partial \mathbf{w}_{i-1}} \|_1 = \frac{1}{d_2} \sum_{j=1}^{d_2} \frac{\|\gamma_L(\mathbf{x})\|_1 + \|\phi_{i-1}(\gamma_L(\mathbf{x}))\|_1}{\|\sum \mathbf{w}_i^{j1}\|_1 \cdot \{\|\gamma_L(\mathbf{x})\|_1 + \|\phi_{i-2}(\gamma_L(\mathbf{x}))\|_1\}}
    $$
    where $d_2$ is the output dimension of the layer, $\mathbf{w}_i^{j1}$ are the weight components connecting the previous layer's output, and $\phi$ represents the layer output [S1].
*   **Overfitting:** The primary motivation for mi-MLP is to alleviate overfitting in few-shot view synthesis. By incorporating inputs into each layer, the model avoids the need to learn the input mapping implicitly through many layers, which can lead to overfitting when data is scarce [S1].

## Operating characteristics
*   **Time Complexity:** The forward pass complexity is similar to a standard MLP of the same depth, but with increased input dimensionality for each layer due to the concatenation of $\gamma_L(\mathbf{x})$. Specifically, for layer $i > 1$, the input dimension is $d_{enc} + d_{hidden}$, whereas a standard MLP has input dimension $d_{hidden}$. This increases the number of parameters and FLOPs per layer.
*   **Memory Complexity:** The number of parameters increases compared to a standard MLP of the same depth because each layer (except the first) has weights connecting to both the previous hidden state and the positional encoding.
*   **Performance:** The method boosts PSNR from 14.73 to 24.23 on few-shot view synthesis benchmarks compared to the baseline [S1]. It achieves state-of-the-art results on a wide range of benchmarks [S1].
*   **Strengths:** Prevents overfitting in few-shot settings; maintains model capacity for high-frequency details; plug-and-play solution; enables shorter paths between inputs and outputs.
*   **Limitations:** Increased parameter count per layer; requires careful initialization to maintain desired gradient properties.

## Background
The mi-MLP was proposed in the paper "Is Vanilla MLP in Neural Radiance Field Enough for Few-Shot View Synthesis?" [S1]. The authors observed that trivially reducing the number of model parameters alleviates overfitting but harms detailed synthesis. They introduced mi-MLP as an orthogonal method from the perspective of network structure, incorporating inputs into each layer to prevent overfitting without harming detailed synthesis. The method was shown to be effective in boosting performance on few-shot view synthesis tasks.
