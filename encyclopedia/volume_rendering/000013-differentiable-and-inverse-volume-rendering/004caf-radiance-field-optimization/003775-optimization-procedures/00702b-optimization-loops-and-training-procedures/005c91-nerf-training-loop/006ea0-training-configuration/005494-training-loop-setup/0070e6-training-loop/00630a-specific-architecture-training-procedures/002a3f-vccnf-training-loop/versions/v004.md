# VCCNF Training Loop

Also called: VCCNF Training

## Overview
The VCCNF (Voxelized Continuous Coordinate Normalizing Flow) training loop optimizes a conditional normalizing flow model to map Gaussian noise samples to shape latent codes, conditioned on input voxel grid data [S1, S2, unofficial]. It solves the problem of learning a structured latent space representation for 3D shapes by minimizing the mean squared error (MSE) between the flow's output and pre-computed target embeddings [S1, S2, unofficial]. Unlike sibling methods that may train implicit fields directly, this procedure specifically trains the conditional density estimator (the flow) to invert the noise-to-latent mapping, relying on external pre-computed embeddings [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** A dataset of voxel grids (shape $[N, 32, 32, 32]$ or similar, depending on `voxel_grid_size`) and corresponding model indices [S1, S2, unofficial]. Pre-computed target latent embeddings are loaded from disk [S2, unofficial].
- **Outputs:** Trained VCCNF model parameters saved as `.param` files, and a history of training losses saved as `.npy` arrays [S2, unofficial].

**Data Structures:**
- **Voxel Data:** A tensor of shape `(batch_size, voxel_grid_size, voxel_grid_size, voxel_grid_size)` containing the spatial representation of the shape [S1, S2, unofficial].
- **Indices:** A tensor of shape `(batch_size,)` containing integer indices into the embedding table [S2, unofficial].
- **Target Latents:** A tensor of shape `(batch_size, latent_dim)` retrieved from the pre-computed embeddings using the indices [S2, unofficial].
- **Gaussian Latents:** A tensor of shape `(batch_size, latent_dim)` sampled from a standard normal distribution $\mathcal{N}(0, I)$ [S2, unofficial].

**Parameters:**
- `latent_dim`: Dimensionality of the latent space. Value: 512 [S1, unofficial].
- `voxel_grid_size`: Spatial resolution of the input voxel grid. Value: 32 [S1, unofficial].
- `batch_size`: Number of samples per iteration. Value: 24 [S1, unofficial].
- `epochs`: Total number of training epochs. Value: 2000 [S1, unofficial].
- `loss_function`: Mean Squared Error (`nn.MSELoss`) [S2, unofficial].
- `scheduler`: `StepLR` with `step_size=100` and `gamma=0.5` [S2, unofficial]. Note: Source [S1, unofficial] lists `scheduler_step_size=500` and `scheduler_gamma=0.5`, creating a discrepancy in the step interval [S1, S2, unofficial]. The implementation below follows the more frequent update schedule described in [S2, unofficial] which aligns with the checkpointing frequency.

**Steps:**
1. **Initialization:** Set random seeds (42) for reproducibility [S2, unofficial]. Split the dataset into 80% training and 20% validation using `manual_seed(42)` [S2, unofficial]. Initialize the VCCNF model, optimizer (typically Adam), and loss function [S2, unofficial].
2. **Embedding Loading:** Load pre-trained shape embeddings from `embedding_dir/embeddings_epoch_{embedding_epoch}.param` [S2, unofficial].
3. **Epoch Loop:** For each epoch $e$ from `start_epoch` to `epochs`:
    a. Set model to training mode (`model.train()`) [S2, unofficial].
    b. Iterate through batches of `(voxel_data, indices)` from the training loader [S2, unofficial].
    c. Move `indices` to the target device (GPU) [S2, unofficial].
    d. Retrieve `latent_codes = embeddings(indices)` [S2, unofficial].
    e. Generate `gaussian_latents = torch.randn_like(latent_codes)` [S2, unofficial].
    f. Compute `latent_pred = model(voxel_data, gaussian_latents)` [S2, unofficial].
    g. Compute `loss = loss_fn(latent_pred, latent_codes)` [S2, unofficial].
    h. Zero gradients, perform backward pass, and step the optimizer [S2, unofficial].
    i. Accumulate loss for the epoch [S2, unofficial].
    j. Step the learning rate scheduler [S2, unofficial].
    k. Append epoch loss to the `losses` list [S2, unofficial].
4. **Checkpointing:** If `(e + 1) % 100 == 0`, print progress, save `losses_vccnf.npy`, and save `vccnf_epoch_{e+1}.param` [S2, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader, random_split
import numpy as np
import os
import random

def train_vccnf(model, train_dataset, val_dataset, embedding_dir, embedding_epoch, 
                epochs=2000, batch_size=24, latent_dim=512, voxel_grid_size=32,
                result_dir="./results", start_epoch=0):
    """
    Trains the VCCNF model to map voxel data and Gaussian latents to target latent codes.
    """
    # 1. Initialization and Reproducibility
    seed = 42
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    
    # Split dataset (Note: random_split requires a generator or fixed seed handling)
    train_size = int(0.8 * len(train_dataset))
    val_size = len(train_dataset) - train_size
    # In practice, one would use a generator with seed 42 for deterministic splitting
    train_loader = DataLoader(train_dataset, batch_size=batch_size, shuffle=True)
    val_loader = DataLoader(val_dataset, batch_size=batch_size, shuffle=False)
    
    # 2. Load Pre-computed Embeddings
    # Embeddings are assumed to be stored in a format accessible by index
    # The source specifies loading from a .param file
    embedding_path = os.path.join(embedding_dir, f"embeddings_epoch_{embedding_epoch}.param")
    # Implementation detail: Load embeddings into a tensor or Parameter buffer
    # Assuming embeddings are indexed by model index
    embeddings = load_embeddings(embedding_path) 
    
    # 3. Setup Loss and Optimizer
    loss_fn = nn.MSELoss()
    optimizer = optim.Adam(model.parameters(), lr=1e-4) # LR not specified in notes, standard default [G]
    scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=100, gamma=0.5) # Following [S2, unofficial] schedule
    
    losses = []
    
    # 4. Epoch Loop
    for e in range(start_epoch, epochs):
        model.train()
        epoch_loss = 0.0
        
        for voxel_data, indices in train_loader:
            # Move indices to device
            indices = indices.to(device) # device assumed to be set externally [G]
            
            # Retrieve target latent codes
            # embeddings is a tensor of shape (N_models, latent_dim)
            latent_codes = embeddings[indices]
            
            # Generate Gaussian latents
            gaussian_latents = torch.randn_like(latent_codes)
            
            # Forward pass
            # model takes voxel_data and gaussian_latents
            latent_pred = model(voxel_data, gaussian_latents)
            
            # Compute loss
            loss = loss_fn(latent_pred, latent_codes)
            
            # Backward pass
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            epoch_loss += loss.item()
        
        # Step scheduler
        scheduler.step()
        
        # Accumulate average loss
        avg_loss = epoch_loss / len(train_loader)
        losses.append(avg_loss)
        
        # Checkpointing every 100 epochs
        if (e + 1) % 100 == 0:
            print(f"Epoch {e+1}, Loss: {avg_loss}")
            
            # Save losses
            np.save(os.path.join(result_dir, "losses_vccnf.npy"), np.array(losses))
            
            # Save model weights
            torch.save(model.state_dict(), os.path.join(result_dir, f"vccnf_epoch_{e+1}.param"))
            
    return losses

def load_embeddings(path):
    """
    Helper to load embeddings. Source [S2, unofficial] implies a .param file.
    Implementation depends on how embeddings were saved (e.g., torch.save).
    """
    # Assuming torch.save was used for embeddings
    return torch.load(path, weights_only=True)
```

**Edge Cases and Pitfalls:**
- **Resuming Training:** The `latest_epoch()` function computes the current epoch as `len(losses) // 100 * 100` [S2, unofficial]. Unlike DeepSDFTraining, there is no existence check for the weight file before loading, which may cause crashes if the checkpoint file is missing [S2, unofficial].
- **Precision:** The use of `float` tensors for voxel data and embeddings is standard, but ensure consistent precision across the embedding loader and model [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of epochs and batch size. Each epoch involves a forward pass through the VCCNF model and a backward pass. The complexity is $O(E \cdot B \cdot (N_{flow} + N_{embed}))$, where $E$ is epochs, $B$ is batch size, $N_{flow}$ is the cost of the flow layers, and $N_{embed}$ is the cost of embedding lookup [S1, S2, unofficial].
- **Memory Complexity:** Dominated by the storage of the embedding table ($N_{models} \times latent\_dim$) and the voxel grids ($B \times voxel\_grid\_size^3$) [S1, S2, unofficial].
- **Performance:** Trained for 2000 epochs with a batch size of 24 [S1, unofficial]. The use of `StepLR` with a decay of 0.5 every 100 epochs helps stabilize convergence [S2, unofficial].
- **Strengths:** Leverages pre-computed embeddings for stable latent space targets [S1, S2, unofficial]. Simple MSE loss provides direct optimization signal [S2, unofficial].
- **Limitations:** Relies on the quality of pre-computed embeddings [S1, unofficial]. No explicit regularization terms are mentioned in the loss function, relying solely on MSE [S2, unofficial].

## Background
The VCCNF training procedure is part of the VC-SDFGen framework, which combines voxelized representations with continuous coordinate normalizing flows for 3D shape generation [S1, S2, unofficial]. It was developed by TurtleJayWang [S1, S2, unofficial]. The method builds on the principles of differentiable volume rendering and implicit neural representations, specifically adapting the training loop to handle conditional normalizing flows [S1, S2, unofficial].
