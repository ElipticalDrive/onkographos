# LLFF Dataset Loading

Also called: LLFF Data Loading, Local Light Field Fusion Dataset Loading

## Overview
LLFF Dataset Loading prepares forward-facing scenes from the Local Light Field Fusion (LLFF) dataset for differentiable volume rendering by parsing COLMAP-derived camera poses, correcting axis conventions, rescaling the scene geometry, and generating rays in Normalized Device Coordinates (NDC) [S1, unofficial][S2, unofficial][S3, unofficial]. It differs from generic NeRF dataset loaders by enforcing specific coordinate system corrections (COLMAP's 'down-right-back' to 'right-up-back'), bounding-box-based scene rescaling to normalize depth, and the generation of a parametric spiral trajectory for novel view synthesis, which are required due to the LLFF dataset's unique metadata structure and forward-facing constraints [S1, unofficial][S2, unofficial].

## How it works
**Inputs:**
- `poses_bounds.npy`: NumPy array of shape $(N, 17)$, where $N$ is the number of images. The first 15 columns contain the flattened $3 \times 5$ pose matrix (rotation and translation), and the last 2 columns contain the near and far depth bounds for the scene [S1, unofficial][S2, unofficial][S3, unofficial].
- Image directory: Typically `images/`, optionally with a downsampling suffix (e.g., `images/8` for 8x downsample) [S4, unofficial].
- Configuration parameters: `factor` (downscale factor), `holdout` (validation split interval), `white_bkgd` (background compositing flag, always `False` for LLFF) [S2, unofficial][S4, unofficial].

**Outputs:**
- `c2ws`: Camera-to-world transformation matrices of shape $(N, 4, 4)$ [S2, unofficial].
- `images`: Loaded and potentially downsampled images of shape $(N, H', W', 3)$ [S4, unofficial].
- `focal`: Rescaled focal length in pixels [S1, unofficial].
- `near`, `far`: Depth bounds for ray sampling [S2, unofficial].
- `ray_o`, `ray_d`: Ray origins and directions, optionally in NDC space [S2, unofficial].

**Data Structures:**
- `poses_bounds`: Array of shape $(N, 17)$ [S3, unofficial].
- `poses`: Reshaped to $(N, 3, 5)$, representing rotation (3x3) and translation (3x1) with an extra column for projection matrix details (often unused or zeroed in standard NeRF pipelines) [S1, unofficial][S3, unofficial].
- `bounds`: Array of shape $(N, 2)$, storing near and far depths per image [S1, unofficial].

**Steps:**
1. **Load Poses and Bounds:** Load `poses_bounds.npy` of shape $(N, 17)$ [S3, unofficial]. Reshape the pose portion to $(N, 3, 5)$ and extract the last two columns as `bounds` of shape $(N, 2)$ [S1, unofficial][S2, unofficial][S3, unofficial].
2. **Extract Intrinsics:** Extract height $H$, width $W$, and focal length $f$ from the first pose's metadata, typically from `poses[0, :, 4]` [S2, unofficial].
3. **Downscale Images:** Determine the image directory suffix based on the `factor` parameter [S4, unofficial]. If `factor > 0`, the suffix is `_{factor}`; otherwise, it is empty [S4, unofficial]. Load images from this directory, sorted by filename [S3, unofficial]. Downscale images if `downscale > 1` and pre-downscaled directory does not exist [S3, unofficial].
4. **Rescale Focal Length:** Adjust the focal length to match the training resolution [S1, unofficial]. If the original image width is $W_{orig}$ and the training width is $W_{train}$, update $f \leftarrow f \times \frac{W_{train}}{W_{orig}}$ [S1, unofficial].
5. **Correct Pose Axes:** COLMAP uses a 'down-right-back' coordinate system [S1, unofficial]. Convert to 'right-up-back' by concatenating columns: `poses = np.concatenate([poses[..., 1:2], -poses[..., :1], poses[..., 2:4]], axis=-1)` [S1, unofficial][S2, unofficial].
6. **Append Homogeneous Row:** Append a row `[0, 0, 0, 1]` to each $3 \times 4$ pose matrix to create full $4 \times 4$ camera-to-world (`c2w`) matrices [S2, unofficial].
7. **Compute Scale Factor:** Calculate the minimum near bound across all images: $d_{min} = \min(\text{bounds}[:, 0])$ [S1, unofficial]. Compute the scale factor: $s = d_{min} \times 0.75$ [S1, unofficial].
8. **Rescale Scene:** Divide all pose translations and depth bounds by $s$ [S1, unofficial]. This normalizes the scene so that the nearest depth is approximately $1/0.75 \approx 1.33$ in normalized space [S1, unofficial].
9. **Set Depth Bounds:** Set the global near and far bounds for ray sampling: $near = \min(\text{bounds}) \times 0.9$ and $far = \max(\text{bounds}) \times 1.0$ [S2, unofficial].
10. **Split Data:** Split images and poses into training and validation sets using a holdout interval [S2, unofficial]. For example, `val_ids = list(range(0, len(c2ws), holdout))` [S2, unofficial].
11. **Generate Rays:** For each pixel $(i, j)$ in each image, compute the ray direction in camera space:
    $$
    \text{dirs} = \left[ \frac{i - c_x}{f}, -\frac{j - c_y}{f}, -1 \right]
    $$
    where $c_x = W/2$ and $c_y = H/2$ [S2, unofficial]. Transform directions to world space: $\mathbf{d}_{world} = \mathbf{R} \cdot \mathbf{dirs}$, and origins: $\mathbf{o}_{world} = \mathbf{t}$ [S2, unofficial].
12. **NDC Normalization:** Convert rays to Normalized Device Coordinates (NDC) to handle forward-facing scenes uniformly [S2, unofficial]. This involves shifting ray origins to the near plane and projecting to NDC space [S2, unofficial].

**NDC Ray Conversion Formula:**
Given ray origin $\mathbf{o}$ and direction $\mathbf{d}$ in world space, and near plane $near$:
1. Compute intersection with near plane:
   $$
   t = -\frac{near + o_z}{d_z}
   $$
2. Shift origin to near plane:
   $$
   \mathbf{o}_0 = \mathbf{o} + t \mathbf{d}
   $$
3. Project to NDC:
   $$
   o_{0x}^{\text{ndc}} = -\frac{2f}{W} \frac{o_{0x}}{o_{0z}}, \quad o_{0y}^{\text{ndc}} = -\frac{2f}{H} \frac{o_{0y}}{o_{0z}}, \quad o_{0z}^{\text{ndc}} = 1 + \frac{2 \cdot near}{o_{0z}}
   $$
   $$
   d_x^{\text{ndc}} = -\frac{2f}{W} \left( \frac{d_x}{d_z} - \frac{o_{0x}}{o_{0z}} \right), \quad d_y^{\text{ndc}} = -\frac{2f}{H} \left( \frac{d_y}{d_z} - \frac{o_{0y}}{o_{0z}} \right), \quad d_z^{\text{ndc}} = -\frac{2 \cdot near}{o_{0z}}
   $$
   The resulting NDC rays are $(\mathbf{o}_{ndc}, \mathbf{d}_{ndc})$ [S2, unofficial].

**Pseudocode:**
```python
import numpy as np
import os
import imageio

def load_llff_data(
    poses_bounds_path: str,
    images_path: str,
    factor: int = 8,
    holdout: int = 8,
) -> dict:
    """
    Load and preprocess LLFF dataset.
    
    Args:
        poses_bounds_path: Path to poses_bounds.npy (N, 17).
        images_path: Path to images directory.
        factor: Downscale factor.
        holdout: Interval for validation split.
        
    Returns:
        Dictionary containing c2ws, images, focal, near, far, ray_o, ray_d.
    """
    # 1. Load poses and bounds
    poses_bounds = np.load(poses_bounds_path)
    poses_arr = poses_bounds[:, :-2].reshape(-1, 3, 5)
    bounds = poses_bounds[:, -2:]
    
    # 2. Extract intrinsics from first pose
    H, W, focal = poses_arr[0, :, 4]
    
    # 3. Determine image directory suffix
    suffix = f"_{factor}" if factor > 0 else ""
    img_dir = os.path.join(images_path, f"images{suffix}")
    
    # 4. Load images
    img_files = sorted([f for f in os.listdir(img_dir) if f.endswith(('.jpg', '.png'))])
    N = len(img_files)
    images = np.stack([imageio.imread(os.path.join(img_dir, f)) for f in img_files], axis=0)
    
    # 5. Correct pose axes (COLMAP down-right-back to right-up-back)
    poses = np.concatenate([
        poses_arr[..., 1:2], 
        -poses_arr[..., :1], 
        poses_arr[..., 2:4]
    ], axis=-1)
    
    # 6. Append homogeneous row to create c2w matrices
    c2ws = np.zeros((N, 4, 4))
    c2ws[:, :3, :4] = poses[:, :, :4]
    c2ws[:, 3, 3] = 1.0
    
    # 7. Compute scale factor and rescale scene
    near_original = np.min(bounds[:, 0])
    scale_factor = near_original * 0.75
    c2ws[:, :3, 3] /= scale_factor
    bounds /= scale_factor
    
    # 8. Set near/far bounds
    near = np.min(bounds) * 0.9
    far = np.max(bounds) * 1.0
    
    # 9. Split data
    val_ids = list(range(0, N, holdout))
    train_ids = [i for i in range(N) if i not in val_ids]
    
    # 10. Generate rays and convert to NDC
    i, j = np.meshgrid(np.arange(W, dtype=np.float32), np.arange(H, dtype=np.float32), indexing="xy")
    cx, cy = W / 2.0, H / 2.0
    dirs = np.stack([(i - cx) / focal, -(j - cy) / focal, -np.ones_like(i)], -1)
    
    ray_o_list = []
    ray_d_list = []
    
    for idx in train_ids:
        c2w = c2ws[idx]
        ray_d = np.einsum("hwc,kc->hwk", dirs, c2w[:3, :3])
        ray_o = np.broadcast_to(c2w[:3, 3], ray_d.shape)
        
        ray_o_ndc, ray_d_ndc = ndc_rays(H, W, focal, near, ray_o, ray_d)
        
        ray_o_list.append(ray_o_ndc.reshape(-1, 3))
        ray_d_list.append(ray_d_ndc.reshape(-1, 3))
        
    ray_o = np.concatenate(ray_o_list, axis=0)
    ray_d = np.concatenate(ray_d_list, axis=0)
    
    return {
        "c2ws": c2ws,
        "images": images,
        "focal": focal,
        "near": near,
        "far": far,
        "ray_o": ray_o,
        "ray_d": ray_d,
        "train_ids": train_ids,
        "val_ids": val_ids
    }

def ndc_rays(H, W, focal, near, ray_o, ray_d):
    """
    Convert rays to NDC space.
    """
    # Shift to near plane
    t = -(near + ray_o[..., 2]) / (ray_d[..., 2] + 1e-8)
    o0 = ray_o + t[..., None] * ray_d
    
    # NDC projection
    o0x = -(2 * focal / W) * o0[..., 0] / (o0[..., 2] + 1e-8)
    o0y = -(2 * focal / H) * o0[..., 1] / (o0[..., 2] + 1e-8)
    o0z = 1.0 + 2.0 * near / (o0[..., 2] + 1e-8)
    
    dx = -(2 * focal / W) * (ray_d[..., 0] / (ray_d[..., 2] + 1e-8) - o0[..., 0] / (o0[..., 2] + 1e-8))
    dy = -(2 * focal / H) * (ray_d[..., 1] / (ray_d[..., 2] + 1e-8) - o0[..., 1] / (o0[..., 2] + 1e-8))
    dz = -2.0 * near / (o0[..., 2] + 1e-8)
    
    ray_o_ndc = np.stack([o0x, o0y, o0z], axis=-1)
    ray_d_ndc = np.stack([dx, dy, dz], axis=-1)
    
    return ray_o_ndc, ray_d_ndc
```

**Parameters:**
- `factor`: Downscale factor for images. Default is often 8 [S4, unofficial].
- `holdout`: Interval for validation split. Default is often 8 [S2, unofficial].
- `white_bkgd`: Always `False` for LLFF dataset [S2, unofficial].
- `scale_factor`: Default multiplier is 0.75, ensuring nearest depth maps to ~1.33 [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** NDC conversion involves division by $d_z$. If $d_z$ is close to zero (ray parallel to image plane), this can cause numerical instability. Ensure rays are not perfectly parallel or add a small epsilon [G].
- **Boundaries:** The near and far bounds are set based on the minimum and maximum depths in the scene. If the scene has outliers, this can lead to poor sampling. Clamping or robust statistics may be needed [G].
- **Degenerate Input:** If `poses_bounds.npy` is missing or malformed, the loader will fail. Ensure the file exists and has the correct shape [G].

## Background
The LLFF (Local Light Field Fusion) dataset consists of forward-facing scenes [S3, unofficial]. It is used to prepare data for training neural radiance fields on forward-facing scenes, enabling novel view synthesis and 3D reconstruction [S1, unofficial][S2, unofficial].
