# Rendering and Diffusion Prior Pipeline

Also called: LSDS Pipeline, Latent Space Diffusion Sampling

## Overview
The Rendering and Diffusion Prior Pipeline (LSDS) enables single-image 3D reconstruction by optimizing a neural radiance field (NeRF) using a pre-trained diffusion model as a geometric and photorealistic prior [S1]. Unlike the sibling [3D-aware Autoencoder](21334-3d-aware-autoencoder.md), which enforces consistency between encoded input images and rendered latents to preserve geometry, LSDS computes the loss on the noise prediction error in the latent space using classifier-free guidance to "dream up" missing novel views [S1]. It solves the problem of reconstructing 3D geometry from a single 2D image by simultaneously minimizing a reconstruction loss on the input view and a diffusion prior loss on randomly sampled novel viewpoints [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A single input image, a text prompt, and an optimized textual embedding token $\langle e \rangle$ generated via single-image textual inversion [S1].
*   **Output:** A trained neural radiance field (NeRF) representing the 3D object.

**Data Structures:**
*   **NeRF:** Composed of feature grids and a 3-layer MLP with 64 hidden units. Each feature grid has dimensionality 2. The features are stacked and fed to the MLP [S1].
*   **Background Model:** A two-layer MLP taking viewing direction as input, purposefully weak to prevent trivial optimization [S1].
*   **VAE Encoder:** Maps images to latent space.
*   **Diffusion Model (UNet):** Pre-trained Stable Diffusion model, kept frozen [S1].

**Steps:**
1.  **Textual Inversion:** Generate a custom token embedding $\langle e \rangle$ conditioned on the input image [S1].
2.  **Rendering:** Render an image from the current NeRF state at resolution $96 \times 96$ pixels [S1].
3.  **Upsampling:** Upsample the rendered image to $512 \times 512$ pixels to match the Stable Diffusion VAE input resolution [S1].
4.  **Latent Encoding:** Pass the upsampled image through the VAE encoder to obtain the latent representation $z$ [S1].
5.  **Noise Addition:** Sample a timestep $t \sim U(0.02, 0.98)$ and add noise to the latent $z$ [S1].
6.  **Diffusion Loss:** Compute the noise prediction error using the frozen UNet, conditioned on the prompt with the optimized token $\langle e \rangle$ and using classifier-free guidance with strength $\gamma = 100$ [S1].
7.  **Gradient Flow:** Backpropagate the diffusion loss through the VAE encoder and the NeRF parameters. Do **not** backpropagate through the UNet [S1].
8.  **Reconstruction Loss:** Simultaneously compute a reconstruction loss between the rendered image and the input image [S1].
9.  **Optimization:** Update NeRF parameters using the Adam optimizer [S1].

**Pseudocode:**
```python
def train_lsd_pipeline(nerf, input_image, prompt, embedding_token, vae_encoder, unet, num_iterations=5000):
    optimizer = Adam(nerf.parameters(), lr=1e-3)
    
    for step in range(num_iterations):
        # 1. Render current NeRF state
        # Resolution is 96px as per source [S1]
        rendered_img = nerf.render_viewpoint() 
        
        # 2. Upsample to 512px for VAE compatibility [S1]
        upsampled_img = upscale(rendered_img, target_size=512)
        
        # 3. Encode to latent space [S1]
        z = vae_encoder.encode(upsampled_img)
        
        # 4. Add noise in latent space [S1]
        t = uniform_sample(low=0.02, high=0.98)
        z_noisy = add_noise(z, t)
        
        # 5. Compute diffusion prior loss using classifier-free guidance [S1]
        # Guidance strength is 100 [S1]
        noise_pred = unet.predict_noise(z_noisy, t, prompt_with_token=embedding_token, guidance_scale=100)
        diffusion_loss = compute_noise_prediction_error(z, noise_pred, t)
        
        # 6. Compute reconstruction loss [S1]
        reconstruction_loss = mse_loss(rendered_img, input_image)
        
        # 7. Total loss [S1]
        total_loss = reconstruction_loss + diffusion_loss
        
        # 8. Backpropagate through VAE encoder and NeRF, NOT UNet [S1]
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
```

**Parameters:**
*   **Render Resolution:** $96 \times 96$ pixels [S1].
*   **VAE Input Resolution:** $512 \times 512$ pixels [S1].
*   **Classifier-Free Guidance Strength:** 100 [S1].
*   **Noise Timestep Range:** $t \sim U(0.02, 0.98)$ [S1].
*   **Optimizer:** Adam, learning rate $1 \times 10^{-3}$ [S1].
*   **Iterations:** 5000 [S1].

**Edge Cases and Pitfalls:**
*   **Guidance Strength Sensitivity:** Classifier-free guidance strength below 30 leads to geometric deformities; strengths above 30 produce good results [S1].
*   **Background Model:** The background model must be weak (two-layer MLP) to prevent the NeRF from optimizing trivially by manipulating background pixels [S1].

## Subtopics

### Diffusion Prior Objective
An objective that uses a large pre-trained diffusion model to ensure the radiance field looks like the given object from randomly sampled novel viewpoints [S1]. It involves rendering novel views from the radiance field, passing them through the diffusion model to compute the prior objective, and optimizing the radiance field to minimize both the reconstruction objective (for the input view) and the prior objective (for novel views) simultaneously [S1].

## Operating characteristics
*   **Time Complexity:** The optimization process takes approximately 45 minutes on a single NVIDIA V100 GPU for 5000 iterations [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Enables high-quality single-image 3D reconstruction by leveraging powerful 2D diffusion priors [S1].
*   **Limitations:** Requires careful tuning of classifier-free guidance strength; low values cause geometric artifacts [S1]. Relies on the quality of the textual inversion embedding [S1].
*   **When to use:** When reconstructing 3D geometry from a single 2D image is required, and a pre-trained diffusion model is available [S1].
*   **When not to use:** When multiple views are available (other methods may be more efficient) or when strict geometric consistency without "dreaming" is required [S1].

## Background
The method was introduced in "RealFusion 360° Reconstruction of Any Object from a Single Image" by Greif et al. (CVPR 2023) [S1]. It addresses the limitation of NeRF-like models that typically require dozens or hundreds of views, extending them to single-image reconstruction by using a diffusion model to "dream up" missing views [S1]. The approach builds on single-image textual inversion to condition the diffusion model on the specific object [S1].
