# Spherical Harmonics NeRF

Also called: NeRF with Spherical Harmonics, SH-NeRF

## Overview
Spherical Harmonics NeRF replaces the view-dependent color prediction of the standard NeRF architecture with an explicit 2nd-order Spherical Harmonics (SH) illumination model, enabling explicit relighting by varying learnable SH coefficients [S1]. It differs from standard NeRF by decoupling surface appearance (albedo) from lighting (SH coefficients), and from siblings like Neural-PIL by using fixed SH basis functions rather than learned neural approximations for the lighting environment [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** Ray samples $\{\mathbf{x}_i\}_{i=1}^{N_{\text{depth}}}$, density values $\sigma(\mathbf{x}_i)$, transmittance $T(t_i)$, opacity $\alpha(\sigma(\mathbf{x}_i)\delta_i)$, and per-image learnable SH coefficients $\mathbf{L}$.
*   **Outputs:** Rendered color $\mathbf{C}$.

**Data Structures**
*   $\mathbf{L} \in \mathbb{R}^{9 \times 3}$: Per-image learnable SH coefficients for illumination. The first dimension (9) corresponds to the 2nd-order SH basis (3 bands: 1 + 3 + 5 = 9 coefficients), and the second dimension (3) corresponds to RGB channels.
*   $\mathbf{A} \in \mathbb{R}^3$: Accumulated screen-space albedo.
*   $\mathbf{N} \in \mathbb{R}^3$: Accumulated screen-space surface normal.
*   $\mathbf{b}(\mathbf{n}) \in \mathbb{R}^9$: SH basis vector evaluated at normal $\mathbf{n}$.

**Steps**
1.  **Compute Unnormalized Normal:** Calculate the unnormalized normal vector $\mathbf{\hat{N}}$ by summing the gradient of the density with respect to the spatial coordinates, weighted by the volume rendering weights (transmittance and opacity) over all depth samples [S1]:
    $$
    \mathbf{\hat{N}}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\text{depth}}}\right) = \sum_{i=1}^{N_{\text{depth}}} \left( \frac{\partial}{\partial \mathbf{x}_i} \sigma(\mathbf{x}_i) \right) \odot T(t_i) \alpha(\sigma(\mathbf{x}_i)\delta_i)
    $$
    where $\frac{\partial}{\partial \mathbf{x}_i} \sigma(\mathbf{x}_i)$ is the gradient of density with respect to the $x, y, z$ components of the ray sample $\mathbf{x}_i$, $T(t_i)$ is the transmittance, $\alpha$ is the opacity, and $\delta_i$ is the distance between samples [S1].

2.  **Normalize Normal:** Normalize the resulting vector $\mathbf{\hat{N}}$ to obtain the unit surface normal $\mathbf{N}$ [S1]:
    $$
    \mathbf{N}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\text{depth}}}\right) = \frac{\mathbf{\hat{N}}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\text{depth}}}\right)}{\left\| \mathbf{\hat{N}}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\text{depth}}}\right) \right\|^2}
    $$
    Note: The source formula uses the squared norm in the denominator, which is a specific implementation detail for normalization in this context [S1].

3.  **Accumulate Albedo:** Compute the accumulated albedo $\mathbf{A}$ in a manner similar to standard NeRF color accumulation, but integrating the output of an albedo MLP instead of the full color MLP [S1].

4.  **Evaluate SH Basis:** Evaluate the 2nd-order Spherical Harmonics basis functions $\mathbf{b}(\mathbf{n})$ at the computed normal $\mathbf{N}$ [S1].

5.  **Render Color:** Compute the final color $\mathbf{C}$ by multiplying the accumulated albedo $\mathbf{A}$ with the product of the SH coefficients $\mathbf{L}$ and the SH basis $\mathbf{b}(\mathbf{N})$ [S1]:
    $$
    \mathbf{C}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\text{depth}}}, \mathbf{L}\right) = \mathbf{A}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\text{depth}}}\right) \odot \mathbf{L} \mathbf{b}\left(\mathbf{N}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\text{depth}}}\right)\right)
    $$
    where $\odot$ denotes elementwise multiplication [S1].

**Pseudocode**
```python
def spherical_harmonics_nerf_render(rays, density_mlp, albedo_mlp, L, num_samples):
    """
    Renders a ray using Spherical Harmonics NeRF.
    
    Args:
        rays: List of ray samples x_i and their positions.
        density_mlp: MLP returning density sigma(x).
        albedo_mlp: MLP returning albedo A(x).
        L: Learnable SH coefficients, shape (9, 3).
        num_samples: Number of samples along the ray.
        
    Returns:
        C: Rendered color, shape (3,).
    """
    N_depth = num_samples
    hat_N = np.zeros(3)
    A = np.zeros(3)
    
    # Precompute transmittance and weights
    T_prev = 1.0
    sigma_vals = []
    x_vals = []
    
    for i in range(N_depth):
        x_i = rays[i]
        sigma = density_mlp(x_i)
        alpha = 1.0 - np.exp(-sigma * rays.delta[i]) # delta_i is distance between samples
        weight = T_prev * alpha
        
        # Accumulate Albedo
        a_i = albedo_mlp(x_i)
        A += weight * a_i
        
        # Update Transmittance
        T_prev *= (1.0 - alpha)
        
        sigma_vals.append(sigma)
        x_vals.append(x_i)
        
    # Compute Unnormalized Normal
    # Gradient of density w.r.t spatial coordinates
    for i in range(N_depth):
        x_i = x_vals[i]
        sigma = sigma_vals[i]
        # Compute gradient of sigma w.r.t x, y, z
        grad_sigma = compute_gradient_sigma(x_i, density_mlp)
        
        # Weight by transmittance and opacity
        # Note: T(t_i) and alpha(sigma(x_i)*delta_i) are used as weights
        # T(t_i) is the transmittance *before* the current sample
        # alpha is the opacity of the current sample
        weight = T_prev_at_i * (1.0 - np.exp(-sigma * rays.delta[i]))
        
        hat_N += grad_sigma * weight
        
    # Normalize Normal
    # Source formula uses squared norm in denominator
    norm_sq = np.dot(hat_N, hat_N)
    if norm_sq == 0:
        N = np.array([0.0, 0.0, 1.0]) # Default normal if undefined
    else:
        N = hat_N / norm_sq
        
    # Evaluate SH Basis
    b_N = evaluate_sh_basis_2nd_order(N) # Returns vector of size 9
    
    # Compute Lighting
    # L is (9, 3), b_N is (9,)
    # Result is (3,)
    lighting = np.dot(L.T, b_N)
    
    # Render Color
    C = A * lighting
    
    return C

def compute_gradient_sigma(x, density_mlp):
    """
    Computes the gradient of density w.r.t x, y, z.
    [G] Standard numerical or analytical gradient computation.
    """
    eps = 1e-5
    grad = np.zeros(3)
    for j in range(3):
        x_plus = x.copy()
        x_plus[j] += eps
        x_minus = x.copy()
        x_minus[j] -= eps
        grad[j] = (density_mlp(x_plus) - density_mlp(x_minus)) / (2 * eps)
    return grad

def evaluate_sh_basis_2nd_order(n):
    """
    Evaluates 2nd-order Spherical Harmonics basis functions at normal n.
    [G] Standard SH basis evaluation.
    """
    x, y, z = n
    # 2nd order SH basis (9 coefficients)
    # Y0, Y1, Y2, Y3, Y4, Y5, Y6, Y7, Y8
    # Normalized for unit sphere
    b = np.zeros(9)
    b[0] = 0.282095
    b[1] = 0.488603 * y
    b[2] = 0.488603 * z
    b[3] = 0.488603 * x
    b[4] = 1.092548 * x * y
    b[5] = 1.092548 * y * z
    b[6] = 0.315392 * (3 * z**2 - 1)
    b[7] = 1.092548 * x * z
    b[8] = 0.546274 * (x**2 - y**2)
    return b
```

**Parameters**
*   $\mathbf{L} \in \mathbb{R}^{9 \times 3}$: Per-image learnable SH coefficients for illumination [S1].
*   Order of SH: 2nd-order, resulting in 9 basis functions [S1].

**Edge Cases and Pitfalls**
*   **Shadow Generation:** The model lacks direct shadow generation, which is crucial for modeling and subsequent relighting of outdoor scenes [S1]. A dedicated shadow control network $S$ can be introduced to extend the rendering equation, but the base SH-NeRF method does not include it [S1].
*   **Normal Normalization:** The normalization step uses the squared norm in the denominator, which is a specific implementation detail that may differ from standard unit vector normalization [S1].

## Operating characteristics
*   **Time Complexity:** Rendering requires computing gradients of density, accumulating albedo and normals, and evaluating SH basis functions. The SH evaluation is constant time ($O(1)$) relative to scene complexity, but depends on the number of samples $N_{\text{depth}}$.
*   **Memory Complexity:** Requires storing per-image SH coefficients $\mathbf{L}$ ($9 \times 3$ floats per image) and the neural networks for density and albedo.
*   **Strengths:** Allows explicit relighting by varying $\mathbf{L}$; accounts for Lambertian effects; accumulation of albedo and normals reduces noise and aids convergence [S1].
*   **Limitations:** Lacks direct shadow generation; limited to Lambertian shading (no specular highlights unless extended) [S1].
*   **When to use:** When explicit relighting of outdoor or indoor scenes is required, and Lambertian approximation is sufficient.
*   **When not to use:** When accurate shadows or specular reflections are critical.

## Background
Spherical Harmonics NeRF was introduced by V. Rudnev et al. in "NeRF for Outdoor Scene Relighting" (2022) [S1]. It extends the standard NeRF framework by incorporating an explicit 2nd-order Spherical Harmonics illumination model to enable relighting capabilities, addressing the lack of semantic meaning and direct lighting control in the original NeRF representation [S1].
