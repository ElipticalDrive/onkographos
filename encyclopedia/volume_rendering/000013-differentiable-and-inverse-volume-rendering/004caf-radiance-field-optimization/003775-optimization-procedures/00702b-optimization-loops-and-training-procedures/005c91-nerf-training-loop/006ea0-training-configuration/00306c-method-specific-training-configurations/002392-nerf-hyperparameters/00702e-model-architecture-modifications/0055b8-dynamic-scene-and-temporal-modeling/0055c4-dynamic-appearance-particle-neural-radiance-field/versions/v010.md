# Dynamic Appearance Particle Neural Radiance Field

Also called: Dynamic Appearance Particle NeRF, Lagrangian dynamic model in NeRF

## Overview
Dynamic Appearance Particle NeRF is a method for modeling dynamic scenes from monocular video data by decomposing the radiance field into static and dynamic components [S1]. It differs from sibling methods like ParticleNeRF, which encode the entire scene with particles and require multi-view data, by applying appearance particles only to dynamic elements and using a grid-based field for efficient querying [S1]. This allows the method to handle monocular video with a single camera view per time frame, whereas ParticleNeRF requires approximately 20 views [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Monocular video data (sequence of images with known camera poses and timestamps $t$).
*   **Output:** A dynamic radiance field model capable of rendering novel views at arbitrary times $t$.

**Data Structures:**
1.  **Static Field ($V_s$):** A time-independent grid-based model (e.g., hash grid or dense voxel grid) storing features for static scene elements [S1].
2.  **Dynamic Field ($V_{td}$):** A particle-based representation where each particle carries appearance features and motion parameters [S1].
3.  **Weight Map ($w_t$):** A binary or soft mask indicating the spatial support of the dynamic field at time $t$ [S1].

**Notation:**
*   $V(x, t)$: Total feature field at position $x$ and time $t$.
*   $V_s(x)$: Static component of the field.
*   $V_{td}(x)$: Dynamic component of the field.
*   $w_t(x)$: Weight function, equal to 1 if the dynamic field is effective at $(x, t)$, and 0 otherwise [S1].
*   $r(s) = o + sd$: Ray equation, where $o$ is the camera center, $d$ is the direction, and $s$ is the distance along the ray [S1].
*   $\sigma(\cdot)$: Volume density.
*   $c(\cdot)$: Emitted radiance (color).
*   $T(s)$: Accumulated transmittance.

**Formulas:**
The total field is a superposition of static and dynamic components [S1]:
$$
V(x, t) = (1 - w_t(x))V_s(x) + w_t(x)V_{td}(x)
$$
The dynamic field $V_{td}$ is formulated as a convolution with a Dirac delta function to integrate over finite volumes [S1]:
$$
V_{td}(x) = (V_{td} * \delta)(x) = \int V_{td}(x')\delta(x - x')d\nu(x')
$$
where $\delta(\cdot)$ is the Dirac function ($\delta(r) = 0$ for $r \neq 0$, $\int \delta(r)d\nu = 1$) and $\nu(\cdot)$ is the volume integration variable [S1].

For rendering, the pixel color $C(r, t)$ is computed via the standard volume rendering integral [S1]:
$$
C(r, t) = \int_{s_n}^{s_f} T(s, t)\sigma(\mathbf{r}(s), t)c(\mathbf{r}(s), \mathbf{d}, t)ds
$$
where the accumulated transmittance is:
$$
T(s, t) = \exp\left(-\int_{s_n}^{s} \sigma(\mathbf{r}(s'), t)ds'\right)
$$

**Parameters:**
*   $w_t(x)$: Takes value 1 if the dynamic field is effective at location $x$ and time $t$, and 0 otherwise. The support of the dynamic field is implied by the particle representation [S1].
*   Kernel $W$: Replaces the Dirac function $\delta$ with a kernel with finite support for quantization. $W(x) = 0$ when $\|x\|$ exceeds a small radius, and $\int W(x)d\nu(x) = 1$ [S1].

**Steps:**
1.  **Initialize Fields:** Construct a static grid-based field $V_s(x)$ for static scene parts. Initialize a set of particles for the dynamic field $V_{td}(x)$ [S1].
2.  **Particle Motion:** Use a particle motion network to predict the positions and features of particles at time $t$ based on their state at previous times or a canonical frame [S1].
3.  **Field Superposition:** For a query point $x$ at time $t$, determine the weight $w_t(x)$. If the point is within the support of a dynamic particle, $w_t(x)=1$; otherwise, $w_t(x)=0$ [S1]. Compute the total field $V(x, t)$ using the superposition formula [S1].
4.  **Density and Color Prediction:** Use the total field $V(x, t)$ to predict volume density $\sigma(\mathbf{r}(s), t)$ and color $c(\mathbf{r}(s), \mathbf{d}, t)$ for points along the ray [S1].
5.  **Rendering:** Cast rays from the camera center $o$ through each pixel. Integrate the density and color along the ray from near bound $s_n$ to far bound $s_f$ to compute the pixel color $C(r, t)$ [S1].
6.  **Optimization:** Minimize the difference between rendered images and ground truth images across all time frames using gradient descent [S1].

**Pseudocode:**
```python
def render_ray(ray_origin, ray_direction, time_t, static_grid, particles, weight_map):
    """
    Renders a single pixel for a given ray and time.
    """
    # Sample points along the ray
    samples = sample_points_along_ray(ray_origin, ray_direction, num_samples=128)
    
    densities = []
    colors = []
    
    for point in samples:
        # Get static field value
        static_val = static_grid.query(point)
        
        # Get dynamic field value
        # Find nearest particle or use kernel density estimation
        dynamic_val = dynamic_field_query(point, particles, time_t)
        
        # Get weight for this point at this time
        # In practice, this might be derived from particle proximity or a learned mask
        weight = weight_map.query(point, time_t)
        
        # Superposition
        total_val = (1 - weight) * static_val + weight * dynamic_val
        
        # Predict density and color from total_val
        # This depends on the specific MLP architecture used to decode the field
        sigma, color = decode_field(total_val)
        
        densities.append(sigma)
        colors.append(color)
        
    # Volume rendering integral
    # T(s) = exp(-sum(sigma * delta_s))
    # C = sum(T(s) * sigma * color * delta_s)
    transmittance = 1.0
    color_accum = [0.0, 0.0, 0.0]
    
    for i, (sigma, color) in enumerate(zip(densities, colors)):
        alpha = 1.0 - exp(-sigma * ray_step_size)
        weight_render = transmittance * alpha
        color_accum += weight_render * color
        transmittance *= (1.0 - alpha)
        
    return color_accum

def dynamic_field_query(point, particles, time_t):
    """
    Queries the dynamic field at a point using particle representation.
    Replaces Dirac delta with a finite support kernel W.
    """
    value = [0.0, 0.0, 0.0]
    total_weight = 0.0
    
    for particle in particles:
        # Get particle position at time_t
        p_pos = particle.get_position(time_t)
        
        # Compute distance
        dist = norm(point - p_pos)
        
        # Apply kernel W (e.g., Gaussian or uniform within radius)
        # W(x) = 0 if ||x|| > radius
        kernel_val = kernel_function(dist)
        
        if kernel_val > 0:
            value += kernel_val * particle.get_features()
            total_weight += kernel_val
            
    if total_weight > 0:
        return value / total_weight
    else:
        return [0.0, 0.0, 0.0] # Or zero vector
```

**Edge Cases and Pitfalls:**
*   **Precision:** The replacement of the Dirac delta with a finite support kernel $W$ requires careful choice of radius to balance smoothness and detail [S1].
*   **Boundaries:** The weight map $w_t(x)$ must correctly handle transitions between static and dynamic regions to avoid artifacts [S1].
*   **Monocular Ambiguity:** Since the method uses monocular data, the particle motion network must be robust to depth ambiguity [S1].

## Operating characteristics
*   **Time Complexity:** Rendering time depends on the number of samples per ray and the cost of querying the static grid and dynamic particles. Grid queries are typically $O(1)$ or $O(\log N)$, while particle queries depend on the number of particles and the search strategy (e.g., nearest neighbor) [S1].
*   **Memory Complexity:** Memory usage is dominated by the static grid and the number of particles. The particle representation is generally more memory-efficient than dense voxel grids for dynamic scenes [S1].
*   **Performance:** The method is designed for efficiency, using linear interpolation for grid-based querying and particle-based querying for dynamic elements [S1].
*   **Strengths:** Handles monocular video data; separates static and dynamic components for efficient modeling; not tightly coupled to a specific architecture (can be integrated with InstantNGP) [S1].
*   **Limitations:** Requires a particle motion network to model dynamics; performance depends on the accuracy of the motion prediction [S1].

## Background
The method was proposed in "Dynamic Appearance Particle Neural Radiance Field" [S1]. It builds on the concept of Lagrangian dynamic models in NeRF [S1]. It addresses the limitations of ParticleNeRF, which requires multi-view data and encodes the entire scene with particles [S1].
