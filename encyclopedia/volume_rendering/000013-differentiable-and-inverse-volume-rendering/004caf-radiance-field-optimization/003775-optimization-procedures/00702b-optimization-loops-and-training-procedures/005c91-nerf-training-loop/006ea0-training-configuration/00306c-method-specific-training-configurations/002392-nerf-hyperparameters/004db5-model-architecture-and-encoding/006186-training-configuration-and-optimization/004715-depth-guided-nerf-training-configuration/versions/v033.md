# Depth-Guided NeRF Training Configuration

## Overview
This configuration defines the training protocol for a NeRF model using depth priors, including architecture modifications, loss weights, and optimizer settings [S1].
## How it works
**Inputs:** Ground-truth RGB images, ground-truth depth maps, camera poses, and intrinsics [G].
**Outputs:** Optimized NeRF model parameters (MLP weights, positional encoding frequencies) and rendered RGB images and depth maps [G].
**Data Structures:**
*   **NeRF Model:** A multi-layer perceptron (MLP) taking 5D input (3D position + 2D viewing direction) [G]. The architecture builds upon the original NeRF [S1].
*   **Depth Scale:** A learnable scalar parameter used to align predicted depth with ground-truth depth scale [S1].
**Numbered Steps:**
1.  **Initialization:** Initialize the NeRF MLP and the depth scale parameter [G].
2.  **Sampling:** Sample points along rays using uniform or importance sampling [G].
3.  **Forward Pass:** Encode positions and viewing directions using positional encoding. Pass through the MLP. Apply dropout with probability $p=0.1$ after each of the first eight fully connected ReLU-activated layers that encode the positional encoding [S1]. Output volume density $\sigma$ and color $\mathbf{c}$ [G]. Compute depth from the volume density and transmittance [G].
4.  **Loss Computation:** Compute photometric loss between rendered color and ground-truth color [G]. Compute depth loss between predicted depth $\hat{d}$ and ground-truth depth $d$. Compute uncertainty loss [S1]. Total loss: $\mathcal{L} = \mathcal{L}_{color} + \lambda \mathcal{L}_{depth} + \gamma \mathcal{L}_{uncertainty}$ [S1].
5.  **Optimization:** Update NeRF parameters and depth scale using the Adam optimizer [S1].
6.  **Learning Rate Schedule:** Reduce the main learning rate to $5 \times 10^{-5}$ after 80% of the total training steps [S1].
**Formulas:**
*   **Depth Evaluation Metrics (for validation, not necessarily loss):**
    $$RMSE(d, \hat{d}) = \sqrt{\frac{1}{K} \sum_{k=1}^{K} (d_k - \hat{d}_k)^2}$$
    $$RMSE_{log}(d, \hat{d}) = \sqrt{\frac{1}{K} \sum_{k=1}^{K} (\log d_k - \log \hat{d}_k)^2}$$
    $$AbsRel(d, \hat{d}) = \frac{1}{K} \sum_{k=1}^{K} \frac{|d_k - \hat{d}_k|}{d_k}$$
    $$SqRel(d, \hat{d}) = \frac{1}{K} \sum_{k=1}^{K} \frac{(d_k - \hat{d}_k)^2}{d_k}$$
    Where $K$ is the number of pixels with valid ground-truth depth [S1].
*   **Uncertainty Threshold:**
    $$\tau = (\text{max\_depth} - \text{min\_depth}) \cdot 0.0001$$
    For ScanNet, $\text{max\_depth} = 10$ and $\text{min\_depth} = 0.001$ [S1].
**Parameters:**
*   **Depth Loss Weight ($\lambda$):** $0.007$ for most scenes; $0.02$ for scene 710 [S1].
*   **Uncertainty Weight ($\gamma$):** $1$ [S1].
*   **Optimizer:** Adam [S1].
*   **Initial Learning Rate:** $5 \times 10^{-4}$ [S1].
*   **Learning Rate Schedule:** Reduce to $5 \times 10^{-5}$ after 80% of steps [S1].
*   **Weight Decay:** $1 \times 10^{-6}$ [S1].
*   **Total Training Steps:** $500,000$ [S1].
*   **Depth Scale Learning Rate:** $1 \times 10^{-7}$ [S1].
*   **Dropout Probability:** $0.1$ applied after each of the first eight fully connected ReLU-activated layers that encode the positional encoding [S1].
**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.optim as optim

class DepthGuidedNeRF(nn.Module):
    def __init__(self, input_dim=3, hidden_dim=256, num_layers=8):
        super().__init__()
        self.layers = nn.ModuleList()
        for i in range(num_layers):
            layer = nn.Linear(input_dim if i == 0 else hidden_dim, hidden_dim)
            self.layers.append(layer)
            # Dropout applied only to the first 8 layers encoding positional encoding
            if i < 8:
                self.layers.append(nn.Dropout(p=0.1))
            self.layers.append(nn.ReLU())
        self.color_layer = nn.Linear(hidden_dim, 3)
        self.sigma_layer = nn.Linear(hidden_dim, 1)

    def forward(self, x):
        for layer in self.layers:
            x = layer(x)
        sigma = self.sigma_layer(x)
        color = self.color_layer(x)
        return sigma, color

def volume_render(model, rays, depth_scale, num_samples=128):
    # Standard volume rendering integration [G]
    # rays: (N, 5) [x, y, z, dx, dy, dz]
    # Returns predicted colors (N, 3) and depths (N,)
    t_vals = torch.linspace(0.0, 1.0, num_samples, device=rays.device)
    z_vals = 0.0 + (1.0 - 0.0) * t_vals  # Simplified near/far bounds [G]
    pts = rays[:, :3].unsqueeze(1) + rays[:, 3:].unsqueeze(1) * z_vals.unsqueeze(2)
    dirs = rays[:, 3:]
    dirs = dirs / (dirs.norm(dim=1, keepdim=True) + 1e-8)
    pts_flat = pts.reshape(-1, 3)
    dirs_flat = dirs.unsqueeze(1).expand(-1, num_samples, -1).reshape(-1, 2) # Simplified direction handling [G]
    # Forward pass through MLP
    sigma_raw, color_raw = model(torch.cat([pts_flat, dirs_flat], dim=1))
    sigma = sigma_raw.reshape(-1, num_samples)
    color = color_raw.reshape(-1, num_samples, 3)
    # Alpha compositing
    deltas = z_vals[:, 1:] - z_vals[:, :-1]
    alpha = 1.0 - torch.exp(-torch.relu(sigma) * deltas)
    transmittance = torch.cumprod(1.0 - alpha + 1e-10, dim=1)
    weights = alpha * transmittance
    colors = torch.sum(weights.unsqueeze(2) * color, dim=1)
    depths = torch.sum(weights * z_vals, dim=1)
    return colors, depths

def train_depth_guided_nerf(model, optimizer, depth_scale_optimizer, dataloader, num_steps=500000):
    model.train()
    depth_scale = nn.Parameter(torch.tensor(1.0))

    # Hyperparameters
    lambda_depth = 0.007
    gamma_uncertainty = 1.0
    lr_main = 5e-4
    lr_depth_scale = 1e-7
    weight_decay = 1e-6

    for step in range(num_steps):
        # Learning rate schedule
        if step > 0.8 * num_steps:
            for param_group in optimizer.param_groups:
                param_group['lr'] = 5e-5

        rays, gt_colors, gt_depths = next(dataloader)

        # Forward pass
        predicted_colors, predicted_depths = volume_render(model, rays, depth_scale)
        predicted_depths = predicted_depths * depth_scale

        # Compute losses
        loss_color = torch.mean(torch.abs(predicted_colors - gt_colors))
        loss_depth = torch.mean(torch.abs(predicted_depths - gt_depths))
        # Uncertainty loss formulation not specified in sources [S1]
        loss_uncertainty = torch.tensor(0.0, device=rays.device)

        total_loss = loss_color + lambda_depth * loss_depth + gamma_uncertainty * loss_uncertainty

        # Backward pass
        optimizer.zero_grad()
        depth_scale_optimizer.zero_grad()
        total_loss.backward()

        optimizer.step()
        depth_scale_optimizer.step()
```
**Edge Cases and Pitfalls:**
*   **Scene 710:** Requires a higher depth loss weight ($\lambda = 0.02$) compared to other scenes ($\lambda = 0.007$) [S1].
*   **Depth Scale:** The depth scale is a learnable parameter with a very small learning rate ($1 \times 10^{-7}$) [S1].
*   **Uncertainty Threshold:** The threshold $\tau$ for evaluating depth uncertainty is scene-dependent, calculated as $(\text{max\_depth} - \text{min\_depth}) \cdot 0.0001$ [S1].
## Subtopics

### DS-NeRF Depth Loss Integration
Integrates the depth loss from the DS-NeRF official code base into the training pipeline [S2]. Due to missing configuration files for DTU in the official release, results for DTU are taken from the publication, while LLFF results are re-trained on specific train/test splits using released configuration files, as the original publication used a different split [S2].

## Operating characteristics
*   **Time Complexity:** Training requires 500,000 steps [S1]. Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Improves geometric accuracy and scale consistency by leveraging depth priors [G].
*   **Limitations:** Requires ground-truth depth maps or reliable depth estimates [G].
*   **When to use:** When monocular NeRF reconstruction suffers from scale ambiguity or poor geometry [G].
*   **When not to use:** When depth information is unavailable or unreliable [G].
## Background
This configuration originates from the work on Depth-Guided NeRF Training via Earth Mover’s Distance [S1]. It incorporates techniques from DS-NeRF [S2] for depth loss integration.
