# Category-Specific Learned Initialization

Also called: Category-specific prior initialization, Federated averaging initialization, Learned Initialization, Meta-learned Initialization

## Overview
Category-Specific Learned Initialization uses meta-learning to capture category-specific shape and appearance priors from a large shape collection (e.g., ShapeNet) to initialize instance-specific "thing" MLPs [S1]. It solves the problem of poor reconstruction quality and slow convergence when training on novel scenes with sparse input views, where standard initialization fails to complete partial views [S1]. It sets itself apart from standard initialization by distilling category-level knowledge into the starting weights, allowing the model to generalize better and converge faster, particularly in data-sparse regimes [S1]. It builds on [Meta-learning for Fast NeRF Reconstruction](18591-meta-learning-for-fast-nerf-reconstruction.md) and differs from [Per-scene fine-tuning of MVSNeRF](18907-per-scene-fine-tuning-of-mvsnerf.md) by learning priors across a category rather than adapting per-scene weights.

## How it works
**Inputs and Outputs:**
- **Input:** 2D rendered images of 3D models from a large shape collection for a specific category (e.g., ShapeNet cars) [S1].
- **Output:** A set of optimized MLP weights $\theta_{final}$ that serve as the initialization for instance-specific "thing" MLPs during novel scene reconstruction [S1].

**Data Structures:**
- $\theta$: The weights of the MLP (typically a "thing" MLP with 4 hidden layers and width 128, using positional encoding with $L=6$ frequencies for object coordinates) [S1].
- $D_k$: The dataset for client $k$, defined as a bundle of rays corresponding to every observed pixel of object instance $k$ [S1].
- $\mathcal{B}$: A set of local minibatches, where each batch contains $B$ rays [S1].

**Algorithm (Federated Averaging for Meta-Learning):**
The method employs Federated Averaging (FedAvg) to meta-learn the initialization [S1]. This process is equivalent to REPTILE meta-learning [S1].

1. **Server Initialization:** Initialize global weights $\theta_0$ [S1].
2. **Outer Loop (Meta-Training):** For each outer epoch $t = 1, 2, \dots$:
   a. **Client Updates (Parallel):** For each client $k \in \{1, \dots, K\}$ (where $K$ is the number of unique object instances):
      i. Receive current weights $\theta_t$ from the server [S1].
      ii. Split $D_k$ into batches of ray bundles of size $B$ [S1].
      iii. Perform local optimization for $E$ inner epochs:
          For each inner epoch $i = 1, \dots, E$:
          For each batch $b \in \mathcal{B}$:
          $$ \theta \leftarrow \theta - \eta \nabla_\theta \ell(\theta; b) $$
          *(Note: $\eta$ is the learning rate, $\ell$ is the loss function, typically reconstruction loss. The algorithm description assumes simple SGD but can be easily adapted for other optimizers [S1].)*
      iv. Return the updated local weights $\theta_{t+1}^k$ to the server [S1].
   b. **Server Aggregation:** Average the weights from all clients:
      $$ \theta_{t+1} = \frac{1}{K} \sum_{k=1}^{K} \theta_{t+1}^k $$
3. **Final Initialization:** The resulting $\theta_{final}$ is used as the initialization for the thing MLPs when training on a novel scene [S1].

**Usage in Novel Scene Reconstruction:**
When reconstructing a novel scene containing instances of the trained category:
1. Initialize the MLP for each object instance track $T$ with the meta-learned weights $\theta_{final}$ [S1].
2. Train the inference-time scene representation network on the novel scene data, focusing only on the individual set of object instances present [S1].

**Pseudocode:**
```python
def server_update(K, D, B, E, eta):
    theta = initialize_weights()  # [S1]
    for t in range(1, T + 1):     # [S1]
        theta_k_list = []
        for k in range(1, K + 1): # [S1]
            theta_k = client_update(k, theta, D[k], B, E, eta)
            theta_k_list.append(theta_k)
        theta = sum(theta_k_list) / K  # [S1]
    return theta

def client_update(k, theta, D_k, B, E, eta):
    batches = split_into_batches(D_k, B)  # [S1]
    for i in range(1, E + 1):             # [S1]
        for b in batches:
            theta = theta - eta * gradient_loss(theta, b)  # [S1]
    return theta
```

**Parameters:**
- $K$: Number of clients (unique object instances in the meta-training set) [S1].
- $B$: Local minibatch size (number of rays per batch) [S1].
- $E$: Number of inner (local) epochs per client [S1].
- $\eta$: Learning rate [S1].
- $\theta_t$: Network parameters after $t$ outer epochs [S1].

**Edge Cases and Pitfalls:**
- The algorithm description assumes simple SGD; adaptation for other optimizers requires modifying the `CLIENT_UPDATE` step [S1].
- Standard Xavier (Glorot) initialization fails to complete partial views with sparse inputs, whereas this method succeeds [S1].

## Subtopics

### Federated Averaging for Category-Specific Initialization
A decentralized federated training algorithm used to realize category-specific learned initialization for thing MLPs by meta-learning from 2D rendered images of 3D models from ShapeNet [S1]. It allows for parallel processing of unique object instances [S1]. It is chosen when a large shape collection is available for a specific category (e.g., cars and vans) to distill priors into initialization weights [S1]. It is equivalent to REPTILE meta-learning [S1].

## Operating characteristics
- **Time Complexity:** The meta-training phase requires $T$ outer epochs, each involving $K$ parallel client updates of $E$ inner epochs [S1]. The total computational cost is proportional to $T \times K \times E$ [G].
- **Memory Complexity:** Requires storing the MLP weights $\theta$ and the datasets $D_k$ for each client [G].
- **Performance:** On ShapeNet cars, the model reconstructs novel object instances well even with just a single image input, outperforming standard initialization which fails to complete partial views [S1]. With dense input views (at least 50 views over two full epochs), it provides faster convergence compared to standard Xavier initialization [S1].
- **Strengths:** Improves generalization and convergence; enables complete reconstruction from sparse views (1 or 3 images); efficient inference-time training as the network focuses only on present instances [S1].
- **Limitations:** Requires a large shape collection for the specific category; other object categories not covered by the meta-learned prior use biased initialization [S1].
- **When to use:** When reconstructing scenes with sparse input views for categories with available prior data (e.g., cars, vans) [S1].
- **When not to use:** For categories without a large shape collection or when dense views are available and standard initialization converges sufficiently (though learned initialization still offers faster convergence [S1]).

## Background
Originated in the Panoptic Neural Fields paper (2022) [S1]. The method leverages meta-learning [11] to capture category-specific shape and appearance priors [S1]. It uses the FedAvg algorithm [36], which is known to be equivalent to REPTILE [42] meta-learning [25] [S1]. The approach was evaluated on ShapeNet [5] cars (provided by [56]) and applied to cars and vans in dynamic KITTI scenes [S1]. It addresses the issue where dense content in "stuff" can suppress gradients from distant objects, making prior knowledge via initialization robust [S1].
