# SUDS

Also called: Scalable Urban Dynamic Scenes

## Overview
SUDS is a 4D radiance field representation designed for large-scale dynamic urban scenes that factorizes the scene into three separate hash table data structures to efficiently encode static, dynamic, and far-field radiance fields [S1]. It solves the problem of scaling neural reconstruction to city-level dimensions (hundreds of kilometers) and handling temporal dynamics without requiring supervised 3D annotations like bounding boxes or panoptic labels [S1]. Unlike sibling methods that rely on per-object NeRFs or global MLPs, SUDS uses a multi-resolution hash encoding with spatial partitioning and explicit shadow modeling, enabling unsupervised learning of scene flow and semantic features from unlabeled RGB, LiDAR, and optical flow inputs [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ordered RGB images from $N$ videos, associated camera poses, aligned sparse LiDAR depth measurements, 2D self-supervised DINO descriptors, and 2D optical flow predictions [S1].
*   **Outputs:** Volume density $\sigma$, view-dependent color $\mathbf{c}$, semantic features $\mathbf{\Phi}$, and 3D scene flow vectors $\mathbf{s}$ for any position $\mathbf{x}$, viewing direction $\mathbf{d}$, time $t$, and video ID $vid$ [S1].

**Data Structures:**
The scene is decomposed into $K$ spatial cells, each trained independently [S1]. Within each cell, three branches are modeled using multi-resolution hash tables [S1]:
1.  **Static Branch:** 3D spatial voxels $v_{l,s}$ indexed by position [S1].
2.  **Dynamic Branch:** 4D spacetime voxels $v_{l,d}$ indexed by position, time, and video ID [S1].
3.  **Far-field Branch:** 3D direction voxels $v_{l,e}$ indexed by viewing direction and video ID [S1].

Each hash table stores $F$-dimensional feature vectors at voxel corners [S1]. The hash tables have $L$ resolution levels, where resolution doubles between levels [S1].

**Hash Indexing:**
Indices for voxel corners are computed using specific hash functions [S1]:
$$ i_{l,s} = \text{static hash}(\text{space}(v_{l,s})) $$
$$ i_{l,d} = \text{dynamic hash}(\text{space}(v_{l,d}), \text{time}(v_{l,d}), vid) $$
$$ i_{l,e} = \text{env hash}(\text{dir}(v_{l,e}), vid) $$
The video ID $vid$ is included in the dynamic and far-field hashes to index separate interpolating functions for each video without linear memory growth [S1]. Hash collisions are handled via gradient averaging [S1].

**Feature Interpolation:**
For a query $(\mathbf{x}, \mathbf{d}, t, vid)$, features are retrieved from the $L$ levels of the static and dynamic branches [S1]. Features are linearly interpolated to the nearest voxel vertices; quadlinear interpolation is used for the 4D dynamic branch [S1]. Results from all $L$ levels are concatenated into a feature vector $\mathbf{f} \in \mathbb{R}^{LF}$ [S1].

**Network Outputs:**
The feature vector $\mathbf{f}$ and auxiliary inputs are passed to an MLP to produce branch-specific outputs [S1]:
*   **Static Branch:** View-independent density $\sigma_s(\mathbf{x}) \in \mathbb{R}$ and view-dependent color $\mathbf{c}_s(\mathbf{x}, \mathbf{d}, \mathbf{A}_{vid}\mathbf{F}(t)) \in \mathbb{R}^3$ [S1]. Lighting variations are modeled via a video-specific matrix $\mathbf{A}_{vid}$ multiplied by a Fourier-encoded time index $\mathbf{F}(t)$ [S1].
*   **Dynamic Branch:** Time/video-dependent density $\sigma_d(\mathbf{x}, t, vid) \in \mathbb{R}$, color $\mathbf{c}_d(\mathbf{x}, t, vid, \mathbf{d}) \in \mathbb{R}^3$, and a scalar shadow ratio $\rho_d(\mathbf{x}, t, vid) \in [0, 1]$ [S1]. It also predicts forward and backward 3D scene flow vectors $\mathbf{s}_{t0}(\mathbf{x}, t, vid) \in \mathbb{R}^3$ with values in $[-1, 1]$ [S1].
*   **Far-field Branch:** Environment map color $\mathbf{c}_e(\mathbf{d}, vid) \in \mathbb{R}^3$ [S1].
*   **Semantic Features:** Each branch outputs $C$-dimensional feature logits $\mathbf{\Phi}_s, \mathbf{\Phi}_d, \mathbf{\Phi}_e$ to distill DINO features [S1].

**Blending and Rendering:**
Total density is the sum of static and dynamic densities:
$$ \sigma(\mathbf{x}, t, vid) = \sigma_s(\mathbf{x}) + \sigma_d(\mathbf{x}, t, vid) $$
Total radiance combines static and dynamic components, scaled by the shadow ratio:
$$ \mathbf{c}(\mathbf{x}, t, vid, \mathbf{d}) = \frac{(1 - \rho_d)\sigma_s \mathbf{c}_s + \sigma_d \mathbf{c}_d}{\sigma} $$
Color $\hat{\mathbf{C}}$ for a ray $\mathbf{r}$ is accumulated via standard volume rendering:
$$ \hat{\mathbf{C}}(\mathbf{r}, t, vid) = \int_0^{+\infty} T(t)\sigma(\mathbf{r}(t), t, vid)\mathbf{c}(\mathbf{r}(t), t, vid, \mathbf{d}) dt + T(+\infty)\mathbf{c}_e(\mathbf{d}, vid) $$
where $T(t) = \exp\left(-\int_0^t \sigma(\mathbf{r}(s), t, vid) ds\right)$ [S1].

**Training Configuration:**
*   **Iterations:** 250,000 [S1].
*   **Batch Size:** 4098 rays per batch [S1].
*   **Optimizer:** Adam with learning rate decaying from $5 \times 10^{-3}$ to $5 \times 10^{-4}$ [S1].
*   **Sampling:** Proposal sampling strategy similar to Mip-NeRF 360 [S1].

**Loss Functions:**
The total loss is a weighted sum of reconstruction, warping, flow, and regularization terms [S1]:
1.  **Reconstruction:** L2 photometric loss $\mathcal{L}_c(\mathbf{r}) = \|\mathbf{C}(\mathbf{r}) - \hat{\mathbf{C}}(\mathbf{r})\|^2$ and L1 feature loss $\mathcal{L}_f(\mathbf{r}) = \|\mathbf{F}(\mathbf{r}) - \hat{\mathbf{F}}(\mathbf{r})\|_1$ [S1]. Depth loss $\mathcal{L}_d(\mathbf{r}) = \|D(\mathbf{r}) - \hat{D}(\mathbf{r})\|^2$ using LiDAR [S1].
2.  **Flow:** 3D position $\hat{\mathbf{X}}_{t0}(\mathbf{r})$ is rendered using scene flow and compared to observed optical flow $\mathbf{O}$ via $\mathcal{L}_o(\mathbf{r}) = \sum_{t0} \|\mathbf{X}(\mathbf{o}) - \hat{\mathbf{X}}_{t0}(\mathbf{r})\|_1$ [S1].
3.  **Warping:** Samples are advected using predicted flow to warp density, color, and features. Warped values are rendered and compared to ground truth, downweighted by ambiguity weight $W_{t0}$ [S1]. Losses $\mathcal{L}^w_c$ and $\mathcal{L}^w_f$ are minimized [S1].
4.  **Flow Regularization:** Cycle consistency $\mathcal{L}_{cyc}$, spatial/temporal smoothness $\mathcal{L}_{sm}$, and static scene prior $\mathcal{L}_{slo}$ (penalizing flow in static regions) [S1].
5.  **Static-Dynamic Factorization:** Skewed binary entropy loss $\mathcal{L}_e(\mathbf{r}) = \int_0^{+\infty} H\left(\frac{\sigma_d}{\sigma_s + \sigma_d}\right) dt$ with $k=1.75$, and max dynamic ratio penalty $\mathcal{L}_d(\mathbf{r}) = \max\left(\frac{\sigma_d}{\sigma_s + \sigma_d}\right)$ [S1].
6.  **Shadow Loss:** Squared magnitude of shadow ratio $\mathcal{L}_\rho(\mathbf{r}) = \int_0^{+\infty} \rho_d(\mathbf{r}(t))^2 dt$ [S1].

## Operating characteristics
SUDS scales to tens of thousands of objects across 1.2 million frames from 1700 videos spanning hundreds of kilometers [S1]. It is 10x quicker to train than state-of-the-art methods relying on ground truth 3D bounding box annotations [S1]. The multi-resolution hash table structure allows real-time training and rendering capabilities inherited from Instant-NGP [S1]. The method handles ego-motion and multi-video representations, overcoming the memory constraints of per-object NeRFs (e.g., NSG requires >1TB for 30 seconds of video) [S1].

## Background
SUDS was introduced in 2023 as a solution for large-scale dynamic urban scene reconstruction [S1]. It builds on Instant-NGP's multi-resolution hash encoding and MegaNeRF's spatial partitioning [S1]. Unlike prior dynamic scene representations that require supervised inputs like panoptic segmentation labels or bounding boxes, SUDS uses unlabeled inputs (RGB, LiDAR, optical flow) to learn scene flow and semantic predictions [S1]. It enables downstream tasks such as free-viewpoint synthesis, unsupervised 3D instance segmentation, and 3D cuboid detection [S1].
