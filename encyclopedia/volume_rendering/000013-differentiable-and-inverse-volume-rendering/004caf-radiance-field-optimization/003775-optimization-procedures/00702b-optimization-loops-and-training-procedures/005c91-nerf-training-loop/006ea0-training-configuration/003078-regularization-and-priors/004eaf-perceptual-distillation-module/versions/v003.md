# Perceptual Distillation Module

Also called: Perceptual Loss for Deblurred Radiance Fields

## Overview
The Perceptual Distillation Module (PDM) is a regularization technique for deblurring Neural Radiance Fields (NeRFs) trained on sparse views [S1]. It addresses the 3D geometric inconsistency inherent in independently deblurred multi-view images by using pre-deblurred images as a perceptual prior [S1]. The module transfers texture information from 2D deblurred priors to the implicit 3D radiance field via feature-space matching [S1].

## How it works
The module augments the training loss by comparing features extracted from rendered patches against features extracted from pre-deblurred versions of the input blurry images [S1].

**Inputs and Outputs**
*   **Inputs:** Blurry training images $I$, camera poses, the current NeRF model (MLPs for color and density), a pre-trained image deblurring network $\Theta_D$, and a pre-trained feature extractor $E$ [S1].
*   **Outputs:** A scalar perceptual loss value $\mathcal{L}_{pd}$ used for backpropagation [S1].

**Data Structures**
*   **Patch Rays ($r_{pd}^{ptc}$):** A set of rays sampled from the training view frustum corresponding to a specific image patch [S1].
*   **Deblurred Image Patch ($\bar{C}_{ptc}$):** A 2D image patch of size $S_{ptc}^{pd} \times S_{ptc}$ extracted from the pre-deblurred image $\bar{I}$ [S1].
*   **Rendered Color Patch ($\hat{C}_{ptc}$):** A 2D image patch rendered from the NeRF using rays $r_{pd}^{ptc}$ [S1]. This rendering is performed without the blur kernel to produce "clean" radiance [S1].
*   **Feature Maps ($\hat{\phi}_{ptc}, \bar{\phi}_{ptc}$):** Multi-channel feature tensors extracted from $\hat{C}_{ptc}$ and $\bar{C}_{ptc}$ respectively [S1].

**Numbered Steps**
1.  **Generate Pre-deblurred Images:** For each blurry training image $I$, compute the deblurred image $\bar{I}$ using the pre-trained deblurring network $\Theta_D$:
    $$ \bar{I} = \Theta_D(I) \quad [S1] $$
2.  **Sample Patch Rays:** On the training views, sample a set of rays $r_{pd}^{ptc}$ that correspond to a patch of size $S_{ptc}^{pd} \times S_{ptc}$ in the image plane [S1].
3.  **Render Clean Patch:** Render the color patch $\hat{C}_{ptc}$ from the sampled rays $r_{pd}^{ptc}$ using the NeRF MLPs [S1]. Crucially, this rendering does not apply the blur kernel, producing a "patch radiance" [S1].
4.  **Extract Features:** Pass both the rendered patch $\hat{C}_{ptc}$ and the corresponding deblurred image patch $\bar{C}_{ptc}$ (extracted from $\bar{I}$) through the shared pre-trained feature extractor $E$:
    $$ \hat{\phi}_{ptc} = E(\hat{C}_{ptc}) \quad [S1] $$
    $$ \bar{\phi}_{ptc} = E(\bar{C}_{ptc}) \quad [S1] $$
    Here, $E$ denotes the deterministic feature extractor network, not a statistical expectation operator [G].
5.  **Compute Perceptual Loss:** Calculate the L2 norm between the extracted feature maps:
    $$ \mathcal{L}_{pd} = ||\hat{\phi}_{ptc} - \bar{\phi}_{ptc}||_2^2 \quad [S1] $$

**Parameters**
*   **Patch Dimensions:** The source specifies $S_{ptc}^{pd} = 8$ and $S_{ptc} = 64$, yielding $8 \times 64$ patches [S1].
*   **Perceptual Loss Weight ($\lambda_{pd}$):** The weight applied to $\mathcal{L}_{pd}$ in the total loss function [S1]. Set to $0.01$ [S1].
*   **Deblurring Network ($\Theta_D$):** MPRNet [S1].
*   **Feature Extractor ($E$):** VGG19 [S1].

**Pseudocode**
```python
def perceptual_distillation_loss(
    blurry_image: Tensor,
    rays: List[Ray],
    nerf_model: NeRFModel,
    deblurring_net: Module,
    feature_extractor: Module,
    patch_dims: tuple = (8, 64),
    lambda_pd: float = 0.01
) -> Tensor:
    # Step 1: Generate deblurred image I_bar = Theta_D(I)
    deblurred_image = deblurring_net(blurry_image)

    # Step 2 & 3: Render clean patch C_hat_ptc from rays using NeRF MLPs without blur kernel
    rendered_patch = nerf_model.render(rays) # Returns tensor of shape (patch_height, patch_width, 3)

    # Step 2 (continued): Extract corresponding deblurred image patch C_bar_ptc from I_bar
    # Ray origins map to pixel coordinates; we slice the deblurred image accordingly
    h, w = patch_dims
    origin = rays[0].origin
    x, y = int(origin.x), int(origin.y)
    deblurred_patch = deblurred_image[y:y+h, x:x+w, :]

    # Step 4: Extract features phi_hat_ptc = E(C_hat_ptc) and phi_bar_ptc = E(C_bar_ptc)
    # VGG19 requires input normalization (mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]) [G]
    rendered_features = feature_extractor(rendered_patch)
    deblurred_features = feature_extractor(deblurred_patch)

    # Step 5: Compute perceptual loss L_pd = ||phi_hat_ptc - phi_bar_ptc||_2^2
    perceptual_loss = sum((rendered_features - deblurred_features) ** 2)

    # Return weighted loss
    return lambda_pd * perceptual_loss
```

**Edge Cases and Pitfalls**
*   **Geometric Inconsistency:** The method relies on the assumption that the 2D deblurred image $\bar{I}$ contains valid texture information consistent with the 3D scene [S1].
*   **Patch Alignment:** The rays $r_{pd}^{ptc}$ must precisely correspond to the spatial location of $\bar{C}_{ptc}$ in $\bar{I}$ [S1].
*   **Feature Normalization:** VGG19 requires specific input normalization (mean/std) [G]. Failure to normalize $\hat{C}_{ptc}$ and $\bar{C}_{ptc}$ identically will result in meaningless feature differences [G].

## Operating characteristics
*   **Time Complexity:** Adds overhead proportional to the number of patch rays sampled per iteration [S1]. Requires forward passes through $\Theta_D$ and $E$ per patch [S1].
*   **Memory Complexity:** Requires storing the pre-deblurred images $\bar{I}$ or computing them on the fly [S1]. The feature extractor $E$ (VGG19) is large, but only features for small patches are computed [S1].
*   **Strengths:** Effectively transfers high-frequency texture details from 2D priors to 3D fields, mitigating the blurriness and artifacts common in sparse-view deblurring [S1].
*   **Limitations:** Depends heavily on the quality of the pre-trained deblurring network $\Theta_D$ and the feature extractor $E$ [S1].
*   **When to use:** Sparse-view deblurring scenarios where geometric consistency is compromised by independent 2D deblurring [S1].
*   **When not to use:** Not given in the sources.

## Background
The Perceptual Distillation Module was introduced in the context of **Sparse-DeRF** (Deblurred Neural Radiance Fields From Sparse View) [S1]. It addresses the problem of camera motion blur in sparse view settings, where traditional NeRF optimization fails to recover sharp details due to insufficient angular coverage and blur [S1]. The method is described as a "first attempt" at utilizing pre-deblurred images as an additional prior in deblurring radiance fields [S1]. It builds upon the observation that independently deblurred multi-view images suffer from 3D geometric inconsistency, which can be alleviated by distilling texture information from these 2D priors into the 3D field [S1]. The implementation uses MPRNet for deblurring and VGG19 for feature extraction, standard choices in perceptual loss literature [S1].
