# MuRF (Multi-Baseline Radiance Fields)
Also called: Multi-Baseline Radiance Fields

## Overview
MuRF is a feed-forward neural network method for sparse view synthesis that addresses the failure of prior methods on large baseline settings by constructing a target view frustum volume aligned with the novel view, rather than a reference input view [S1]. Unlike ray-based rendering methods that process rays independently (e.g., [IBRNet](13661-mine.md), [MatchNeRF](13661-mine.md)), MuRF uses a 3D context-aware convolutional decoder to regress a radiance field from this volume, enabling effective information aggregation even when overlap between input and target views is small [S1].

## How it works
MuRF is an encoder-decoder architecture. The encoder extracts multi-view features from input images. The decoder constructs a volume aligned with the target camera frustum, samples features and colors into this volume, and uses a (2+1)D CNN to regress density and color, which are then rendered via standard volume rendering [S1].

### Inputs and Outputs
*   **Inputs**: A set of $K$ input images $\{I_k\}_{k=1}^K$ with known camera poses, and a target camera pose (view direction and position) for which a novel view is to be synthesized [S1].
*   **Outputs**: A synthesized RGB image of resolution $H \times W$ [S1].

### Data Structures
1.  **Multi-scale Features**: Extracted by the CNN encoder at resolutions $1/2, 1/4, 1/8$ of the input image dimensions [S1].
2.  **Target View Frustum Volume ($z$)**: A 4D tensor representing the discretized 3D space aligned with the target view [S1].
    *   **Layout**: $z \in \mathbb{R}^{H/8 \times W/8 \times D \times C}$ [S1].
    *   **Dimensions**:
        *   Spatial: $H/8 \times W/8$ (subsampled from $H \times W$) [S1].
        *   Depth: $D$ (number of equidistant samples per ray) [S1].
        *   Channel: $C$ (concatenated sampled features, colors, and cosine similarities) [S1].
3.  **Radiance Field**: Predicted density $\sigma$ and color $\mathbf{c}$ for each voxel in the upsampled volume [G].

### Parameters
*   $K$: Number of input views ($K \ge 2$) [S1].
*   $H, W$: Resolution of the target image [S1].
*   $D$: Number of equidistant points sampled on each ray within the target view frustum volume [S1].
*   Spatial Subsampling Factor: $8\times$, applied in the spatial dimension when constructing the target volume to efficiently handle high-resolution images [S1].
*   CNN Encoder Depth: 6 residual blocks [S1].
*   Downsampling Stride: Stride-2 convolution applied every 2 residual blocks [S1].

### Steps

1.  **Multi-View Feature Extraction**:
    For each input image $I_k$:
    *   Pass $I_k$ through a weight-sharing 2D CNN encoder consisting of 6 residual blocks [S1].
    *   Apply stride-2 convolutions after every 2 residual blocks to downsample features [S1].
    *   Obtain feature maps at $1/2, 1/4,$ and $1/8$ resolutions [S1].
    *   Feed the $1/8$ resolution features from all $K$ views into a joint multi-view Transformer to perform cross-attention across all views simultaneously [S1].
    *   Output: Multi-scale feature maps $\{F_k^{(1/2)}, F_k^{(1/4)}, F_k^{(1/8)}\}_{k=1}^K$ [S1].

2.  **Target View Frustum Volume Construction**:
    *   Define the target view frustum based on the target camera pose [S1].
    *   Cast rays from the target camera center through the target image grid [S1].
    *   Perform $8\times$ subsampling in the spatial dimension. This means rays are cast only through a grid of size $(H/8) \times (W/8)$ [S1].
    *   For each ray, uniformly sample $D$ equidistant points along the ray within the frustum [S1].
    *   Let $\mathbf{x}_i$ be the 3D coordinates of the $i$-th sample point.

3.  **Volume Element Sampling**:
    For each sample point $\mathbf{x}_i$ at spatial index $(u, v)$ in the subsampled grid:
    *   **Color Sampling**: Sample the RGB color from each input image $I_k$ at the projected 2D coordinates of $\mathbf{x}_i$ [S1].
    *   **Feature Sampling**: Sample the multi-scale features $\{F_k^{(1/2)}, F_k^{(1/4)}, F_k^{(1/8)}\}$ from each input view at the projected 2D coordinates [S1].
    *   **Cosine Similarity Calculation**: Compute the cosine similarity between the sampled feature vectors from different input views. Specifically, for a point $\mathbf{x}_i$, compute the cosine similarity between features sampled from view $j$ and view $k$. This provides multi-view consistency cues for density prediction [S1].
    *   **Concatenation**: Concatenate the sampled colors, sampled features (from all scales and views), and computed cosine similarities to form the channel vector $z_i$ [S1].
    *   The resulting volume $z$ has shape $8 \times 8 \times D \times C$ [S1].

4.  **Radiance Field Regression**:
    *   Input the volume $z$ into a (2+1)D CNN decoder [S1].
    *   The (2+1)D CNN factorizes the 3D convolution:
        *   A 2D $3 \times 3 \times 1$ convolution operates on the spatial dimensions ($8 \times 8$) [S1].
        *   A 1D $1 \times 1 \times 3$ convolution operates on the depth dimension ($D$) [S1].
    *   This factorization reduces computational cost while modeling 3D context [S1].
    *   Output: A low-resolution radiance field tensor of shape $8 \times 8 \times D \times 4$ (density $\sigma$ and RGB color $\mathbf{c}$) [S1].

5.  **Upsampling**:
    *   Apply a lightweight $8\times$ upsampler to the low-resolution radiance field [S1].
    *   Output: Full-resolution radiance field tensor of shape $H \times W \times D \times 4$ [S1].

6.  **Volume Rendering**:
    *   Render the target image using standard volumetric rendering on the full-resolution radiance field [S1].
    *   For each pixel $(u, v)$, integrate the density $\sigma$ and color $\mathbf{c}$ along the ray [G]:
        $$ C(u, v) = \sum_{i=1}^D T_i (1 - e^{-\sigma_i \delta_i}) \mathbf{c}_i $$
        where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance, and $\delta_i$ is the distance between sample points [G].

### Pseudocode

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class Shared2DCNN(nn.Module):
    def __init__(self, in_ch, out_ch):
        super().__init__()
        self.blocks = nn.ModuleList()
        for i in range(6):
            self.blocks.append(nn.Conv2d(out_ch if i > 0 else in_ch, out_ch, 3, padding=1))
            if (i + 1) % 2 == 0:
                self.blocks.append(nn.Conv2d(out_ch, out_ch, 3, stride=2, padding=1))

    def forward(self, x):
        for layer in self.blocks:
            x = F.relu(layer(x))
        return x

class MultiViewTransformer(nn.Module):
    def __init__(self, K, channels):
        super().__init__()
        self.K = K
        self.attn = nn.MultiheadAttention(channels, num_heads=4, batch_first=True)

    def forward(self, features):
        B, C, H, W = features.shape
        x = features.view(B, C, -1).permute(0, 2, 1)
        attn_out, _ = self.attn(x, x, x)
        return attn_out.permute(0, 2, 1).view(B, C, H, W)

class LightweightUpsampler(nn.Module):
    def __init__(self, scale=8):
        super().__init__()
        self.upsample = nn.Upsample(scale_factor=scale, mode='bilinear', align_corners=False)

    def forward(self, x):
        return self.upsample(x)

class MuRF:
    def __init__(self, K, D, H, W, C):
        self.K = K
        self.D = D
        self.H = H
        self.W = W
        self.C = C
        self.cnn = Shared2DCNN(3, C)
        self.transformer = MultiViewTransformer(K, C)
        self.decoder_2d = nn.Conv3d(C, C, kernel_size=(3, 3, 1), padding=(1, 1, 0))
        self.decoder_1d = nn.Conv3d(C, 4, kernel_size=(1, 1, 3), padding=(0, 0, 1))
        self.upsampler = LightweightUpsampler(scale=8)

    def extract_features(self, images):
        feats = [self.cnn(images[k]) for k in range(self.K)]
        stacked = torch.stack(feats, dim=0)
        return self.transformer(stacked)

    def cast_rays(self, cam_K, cam_R, cam_T, h_sub, w_sub, near, far):
        y, x = torch.meshgrid(torch.arange(h_sub), torch.arange(w_sub), indexing='ij')
        pts_2d = torch.stack([x.float(), y.float(), torch.ones_like(x)], dim=-1)
        pts_3d = torch.linalg.inv(cam_K) @ pts_2d.view(3, -1).T
        dirs = pts_3d / torch.norm(pts_3d, dim=-1, keepdim=True)
        origin = -cam_R.T @ cam_T
        origins = origin.unsqueeze(0).expand(h_sub * w_sub, -1)
        t = torch.linspace(near, far, self.D)
        rays_o = origins.unsqueeze(1) + dirs.unsqueeze(1) * t.unsqueeze(0).unsqueeze(-1)
        return rays_o, dirs

    def project_to_image(self, rays_o, rays_d, cam_K, cam_R, cam_T):
        pts_cam = (cam_R @ (rays_o - cam_T).T).T
        pts_proj = (cam_K @ pts_cam.T).T
        u = pts_proj[:, 0] / pts_proj[:, 2]
        v = pts_proj[:, 1] / pts_proj[:, 2]
        return torch.stack([u, v], dim=-1)

    def sample_image(self, img, coords_2d):
        h, w = img.shape[-2], img.shape[-1]
        norm_u = 2 * coords_2d[:, 0] / w - 1
        norm_v = 2 * coords_2d[:, 1] / h - 1
        grid = torch.stack([norm_u, norm_v], dim=-1).unsqueeze(0).unsqueeze(0)
        return F.grid_sample(img.unsqueeze(0), grid, align_corners=False).squeeze()

    def cosine_similarity(self, a, b):
        return F.cosine_similarity(a, b, dim=-1, eps=1e-8)

    def forward(self, images, target_cam_K, target_cam_R, target_cam_T, input_cameras, input_images, near, far):
        features = self.extract_features(images)
        h_sub, w_sub = self.H // 8, self.W // 8
        rays_o, rays_d = self.cast_rays(target_cam_K, target_cam_R, target_cam_T, h_sub, w_sub, near, far)
        
        sampled_colors = []
        sampled_feats = []
        cos_sims = []

        for k in range(self.K):
            coords = self.project_to_image(rays_o, rays_d, input_cameras[k]['K'], input_cameras[k]['R'], input_cameras[k]['T'])
            color = self.sample_image(input_images[k], coords)
            sampled_colors.append(color)
            feat = self.sample_image(features[k], coords)
            sampled_feats.append(feat)
            if k > 0:
                sim = self.cosine_similarity(feat, sampled_feats[0])
                cos_sims.append(sim)

        N = h_sub * w_sub
        vol_channels = [torch.cat(sampled_colors, dim=-1)]
        vol_channels.append(torch.cat(sampled_feats, dim=-1))
        if cos_sims:
            vol_channels.append(torch.stack(cos_sims, dim=-1))
        volume_flat = torch.cat(vol_channels, dim=-1)
        volume = volume_flat.view(h_sub, w_sub, self.D, -1).permute(0, 1, 2, 3)

        vol_conv = volume.permute(0, 3, 1, 2).unsqueeze(0)
        x = self.decoder_2d(vol_conv)
        x = self.decoder_1d(x)
        radiance_low = x.squeeze(0).permute(0, 2, 3, 1)
        radiance_full = self.upsampler(radiance_low.permute(3, 0, 1, 2)).permute(1, 2, 3, 0)

        sigma = radiance_full[..., 0]
        color = radiance_full[..., 1:4]
        delta = (far - near) / self.D
        alpha = 1.0 - torch.exp(-sigma * delta)
        T = torch.cumprod(torch.exp(-sigma * delta), dim=-2)
        T = torch.cat([torch.ones_like(T[..., 0:1, :]), T[..., :-1, :]], dim=-2)
        weights = alpha * T
        image = torch.sum(weights * color, dim=-2)
        return image
```

### Edge Cases and Pitfalls
*   **Large Baselines**: Using a reference view volume (aligned with an input view) for large baselines causes failure because the overlap between the reference and target view is small, leading to missing information outside the epipolar lines of the reference view [S1]. MuRF avoids this by aligning the volume with the target view [S1].
*   **Information Loss**: The $8\times$ spatial subsampling risks losing information if only a single sample is taken per pixel [S1]. The method compensates by sampling features and colors from multiple views and computing cosine similarities [S1].
*   **Precision**: The cosine similarity computation requires normalized feature vectors to be meaningful [G].

## Operating characteristics
*   **Time Complexity**: The method is feed-forward, so inference time is constant for a given input size [S1]. The (2+1)D CNN is more computationally efficient than full 3D convolutions [S1]. The $8\times$ subsampling reduces the number of rays processed by $64\times$ compared to full resolution, significantly speeding up feature sampling and volume construction [S1].
*   **Memory Complexity**: Memory usage is dominated by the volume $z$ and the intermediate feature maps [S1]. The subsampling reduces memory requirements for the volume [S1]. The multi-view Transformer scales with $K^2$ for cross-attention, but the method uses a joint multi-view architecture to mitigate this [S1].
*   **Performance**: MuRF achieves state-of-the-art performance on small baseline datasets (DTU, LLFF) and large baseline datasets (RealEstate10K) [S1]. It also shows promising zero-shot generalization on Mip-NeRF 360 [S1].
*   **Strengths**: General applicability to multiple baseline settings; effective 3D context modeling via CNN; efficient handling of high-resolution images via subsampling [S1].
*   **Limitations**: Requires known camera poses for input and target views [S1]. Performance may degrade if the scene bounds are poorly estimated [G].

## Background
MuRF was introduced by Haofei Xu et al. in 2024 [S1]. It addresses the limitations of previous sparse view synthesis methods that were specialized for either small or large baselines [S1]. By constructing a target view frustum volume and using a 3D context-aware CNN, MuRF provides a general solution for sparse view synthesis across different baseline settings [S1].
