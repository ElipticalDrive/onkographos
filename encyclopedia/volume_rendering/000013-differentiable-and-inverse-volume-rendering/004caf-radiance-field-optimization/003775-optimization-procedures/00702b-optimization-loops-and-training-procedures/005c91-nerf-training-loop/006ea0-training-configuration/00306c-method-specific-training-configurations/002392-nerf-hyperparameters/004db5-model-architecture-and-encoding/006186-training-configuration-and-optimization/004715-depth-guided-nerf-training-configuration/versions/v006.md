# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the hyperparameters, architectural modifications, and optimization settings required to train a Neural Radiance Field (NeRF) model using depth priors to improve geometric accuracy [S1]. It addresses the problem of NeRFs producing blurry or geometrically inconsistent reconstructions by integrating explicit depth supervision into the training loop. It differs from standard NeRF training by adding specific dropout regularization to the encoding layers and a weighted depth loss term, and differs from sibling methods like [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md) by focusing on geometric consistency via depth metrics rather than semantic consistency via vision-language models.

## How it works
**Inputs:**
*   Raw NeRF model parameters (weights for the MLPs).
*   Training images and their corresponding camera poses.
*   Ground truth depth maps for the training views.
*   Scene-specific depth bounds ($min\_depth$, $max\_depth$).

**Outputs:**
*   Trained NeRF model parameters.
*   Rendered images and depth maps.

**Data Structures:**
The model architecture builds on the standard NeRF [G] but modifies the encoding path:
*   **Positional Encoding:** Standard PE applied to 3D coordinates $\mathbf{x}$ and viewing direction $\mathbf{d}$.
*   **MLP Layers:** The first eight fully connected ReLU-activated layers that process the positional encoding features are followed by Dropout layers.
*   **Dropout:** Probability $p=0.1$ applied after each of the first eight FC layers.

**Parameters:**
*   Depth loss weight ($\lambda$): $0.007$ for most scenes; $0.02$ for scene 710 [S1].
*   Uncertainty weight ($\gamma$): $1$ [S1].
*   Optimizer: Adam [S1].
*   Initial learning rate ($\eta$): $5 \times 10^{-4}$ [S1].
*   Learning rate schedule: Reduce to $5 \times 10^{-5}$ after 80% of total steps [S1].
*   Weight decay ($\omega$): $1 \times 10^{-6}$ [S1].
*   Total training steps: $500,000$ [S1].
*   Depth scale learning rate: $1 \times 10^{-7}$ [S1].
*   Depth threshold ($\tau$): Calculated as $\tau = (max\_depth - min\_depth) \cdot 0.0001$ [S1]. For ScanNet, $max\_depth = 10$ and $min\_depth = 0.001$ [S1].

**Steps:**
1.  **Initialize** the NeRF model with standard weights.
2.  **Modify Architecture:** Insert a Dropout layer with $p=0.1$ after each of the first eight fully connected ReLU layers in the positional encoding path [S1].
3.  **Configure Optimizer:** Set Adam optimizer with $\eta = 5 \times 10^{-4}$, weight decay $\omega = 1 \times 10^{-6}$ [S1].
4.  **Set Depth Scale LR:** Assign a specific learning rate of $1 \times 10^{-7}$ to the depth scale parameter [S1].
5.  **Compute Loss:**
    *   Render color and depth from the NeRF.
    *   Compute photometric loss (standard NeRF).
    *   Compute depth loss using the configured $\lambda$. The depth evaluation metrics used for assessment are RMSE, Log-RMSE, AbsRel, and SqRel [S1]:
        $$ RMSE(\mathbf{d}, \hat{\mathbf{d}}) = \sqrt{\frac{1}{K} \sum_{k=1}^{K} (d_k - \hat{d}_k)^2} $$
        $$ RMSE_{\log}(\mathbf{d}, \hat{\mathbf{d}}) = \sqrt{\frac{1}{K} \sum_{k=1}^{K} (\log d_k - \log \hat{d}_k)^2} $$
        $$ AbsRel(\mathbf{d}, \hat{\mathbf{d}}) = \frac{1}{K} \sum_{k=1}^{K} \frac{|d_k - \hat{d}_k|}{d_k} $$
        $$ SqRel(\mathbf{d}, \hat{\mathbf{d}}) = \frac{1}{K} \sum_{k=1}^{K} \frac{(d_k - \hat{d}_k)^2}{d_k} $$
        where $K$ is the number of pixels with valid ground truth depth [S1].
    *   Combine losses with weights $\lambda$ and $\gamma$ [S1].
6.  **Update:** Perform gradient descent step.
7.  **Schedule:** After 80% of the 500,000 steps, reduce the main learning rate to $5 \times 10^{-5}$ [S1].
8.  **Repeat** until 500,000 steps are completed [S1].

**Edge Cases and Pitfalls:**
*   **Scene 710:** Requires a higher depth loss weight ($\lambda = 0.02$) compared to other scenes ($\lambda = 0.007$) [S1].
*   **Depth Threshold:** The threshold $\tau$ for evaluating depth uncertainty must be computed per scene based on its depth range [S1].
*   **Overfitting:** The dropout layers are specifically added to prevent overfitting during depth-guided training [S1].

## Subtopics

### DS-NeRF Depth Loss Integration
Integrates the depth loss implementation from the official DS-NeRF code base into the training pipeline [S2]. This variant requires re-training on LLFF train/test splits using released configuration files, as the original publication results for LLFF used a different split and DTU results could not be reproduced due to missing configuration files in the official code base [S2].

## Operating characteristics
*   **Time Complexity:** Training requires 500,000 steps [S1]. The addition of dropout and depth loss computation adds minimal overhead compared to standard NeRF.
*   **Memory Complexity:** Standard NeRF memory usage plus storage for ground truth depth maps [S1].
*   **Strengths:** Improves geometric accuracy and reduces blur by leveraging explicit depth supervision [S1].
*   **Limitations:** Requires ground truth depth maps for training [S1]. Performance is sensitive to the choice of $\lambda$ and scene-specific depth bounds [S1].
*   **When to use:** When geometric consistency is prioritized over texture fidelity and ground truth depth is available.
*   **When not to use:** When depth priors are unavailable or noisy, or when computational resources are extremely limited.

## Background
This configuration originates from the work on Depth-Guided NeRF Training via Earth Mover’s Distance [S1]. It builds upon the original NeRF architecture [G] and incorporates techniques from DS-NeRF [S2] for depth loss integration. The method was developed to address the lack of geometric precision in standard NeRFs by introducing explicit depth supervision.
