# NeRF Optimization via SDS


## Overview
NeRF Optimization via SDS (Score Distillation Sampling) optimizes the parameters of a Neural Radiance Field (NeRF) to match a user-provided text prompt by leveraging gradients from a pretrained 2D text-to-image diffusion model [S1, unofficial]. Unlike standard NeRF training which minimizes pixel-wise reconstruction error against ground-truth images, this method treats the NeRF as a differentiable renderer within an optimization loop, using the diffusion model as a perceptual prior to guide the generation of novel 3D geometry and appearance [S1, unofficial]. It distinguishes itself from sibling methods like SUDS or Rip-NeRF by explicitly incorporating view-dependent text conditioning based on camera azimuth angles and specific regularization terms for entropy and orientation [S1, unofficial].

## How it works
The method optimizes a NeRF network using SDS gradients derived from a latent diffusion model [S1, unofficial]. The process involves initializing a NeRF, preparing text embeddings, and iteratively updating the NeRF weights by rendering images, encoding them into latent space, and computing the SDS loss [S1, unofficial].

### Inputs and Outputs
*   **Inputs:**
    *   Text prompt string.
    *   Optional negative prompt string.
    *   Camera poses and intrinsics (from `NeRFDataset`) [S1, unofficial].
    *   Hyperparameters: learning rate (`lr`), optimizer settings, regularization weights (`lambda_entropy`, `lambda_orient`), iteration ratios (`latent_iter_ratio`), and shading parameters [S1, unofficial].
*   **Outputs:**
    *   Optimized NeRF model parameters (MLP weights) [S1, unofficial].
    *   Rendered images matching the text prompt [S1, unofficial].

### Data Structures
*   **NeRF Model (`NeRFNetwork`):** A Multi-Layer Perceptron (MLP) representing the radiance field [S1, unofficial]. It takes encoded 3D position and view direction as input and outputs volume density ($\sigma$) and RGB color ($\mathbf{c}$) [S1, unofficial]. The architecture follows the standard NeRF MLP structure with sinusoidal positional encoding (see [Model Architecture and Encoding](13550-model-architecture-and-encoding.md)).
*   **Text Embeddings:** A dictionary mapping text conditions (e.g., "front", "side", "back", "default") to latent text embeddings generated by the diffusion model's text encoder [S1, unofficial].
*   **Dataset (`NeRFDataset`):** Stores images, camera parameters (rotation $R$, translation $T$, focal length $F$, principal point $C$), and optional masks [S1, unofficial].

### Numbered Steps

1.  **Initialize Text Embeddings:** Prepare text embeddings using the diffusion model's encoder [S1, unofficial]. If `view_dependent` is enabled, generate embeddings for different viewpoints (e.g., front, side, back) based on azimuth angles [S1, unofficial].
    $$ \text{embeddings} = \text{prepare\_embeddings}(\text{sds}, \text{prompt}, \text{neg\_prompt}, \text{view\_dependent}=\text{True}) $$

2.  **Initialize NeRF Model:** Instantiate the `NeRFNetwork` and move it to the target device (e.g., GPU) [S1, unofficial].

3.  **Configure Optimizer:** Create an Adan optimizer with the following specific parameters [S1, unofficial]:
    *   Learning rate: $5 \times \text{lr}$, where $\text{lr} = 10^{-3}$.
    *   Epsilon: $10^{-8}$.
    *   Weight decay: $2 \times 10^{-5}$.
    *   Max gradient norm: $5.0$.
    *   Scheduler: Constant LambdaLR.

4.  **Load Data:** Load training and test datasets (`NeRFDataset`) specifying image height, width, and batch sizes [S1, unofficial].

5.  **Optimization Loop:** Iterate through epochs and training batches [S1, unofficial]. For each step:
    
    a.  **Calculate Iteration Ratio:**
        $$ \text{exp\_iter\_ratio} = \frac{\text{global\_step} - \text{args.exp\_start\_iter}}{\text{args.exp\_end\_iter} - \text{args.exp\_start\_iter}} $$
        
    b.  **Set Shading and Background Parameters:**
        *   If $\text{exp\_iter\_ratio} \le \text{args.latent\_iter\_ratio}$:
            *   Set `ambient_ratio` = $1.0$.
            *   Set `shading` = "normal".
            *   Set `bg_color` = `None`.
        *   Otherwise:
            *   Sample `ambient_ratio` uniformly between $\text{args.min\_ambient\_ratio}$ and $1.0$ [S1, unofficial].
            *   Select `shading`: "textureless" with probability $\text{args.textureless\_ratio}$, otherwise "lambertian" [S1, unofficial].
            
    c.  **Set Background Color:**
        *   If $\text{args.bg\_radius} > 0$ and a random number $> 0.5$: Use a background network `bg_net` (returning `None` for color, implying alpha blending or specific background handling) [S1, unofficial].
        *   Else: Use a random single-color background sampled from a uniform distribution: $\mathbf{c}_{bg} \sim \text{Uniform}(0, 1)^3$ [S1, unofficial].

    d.  **Render:** Perform a forward pass through the NeRF model using the current ray parameters, MVP matrix, image dimensions ($H, W$), and shading/background settings. Reshape output to $[B, 3, H, W]$ [S1, unofficial].
        $$ \text{pred\_rgb} = \text{NeRF}(rays, \dots) $$

    e.  **Select Text Conditioning:**
        *   If `args.view_dep_text` is true:
            *   Calculate azimuth angle $\phi$ of the camera.
            *   If $|\phi| \le 45^\circ$: Use `embeddings["front"]`.
            *   If $45^\circ < |\phi| \le 135^\circ$: Use `embeddings["side"]`.
            *   Else: Use `embeddings["back"]` [S1, unofficial].
        *   Else: Use `embeddings["default"]` [S1, unofficial].

    f.  **Encode to Latent Space:** Interpolate `pred_rgb` to $512 \times 512$ using bilinear interpolation. Encode the image using the diffusion model's VAE encoder [S1, unofficial]:
        $$ \text{latents} = \text{sds.encode\_imgs}(\text{interpolate}(\text{pred\_rgb}, \text{size}=(512, 512))) $$

    g.  **Compute SDS Loss:** Calculate the Score Distillation Sampling loss [S1, unofficial]:
        $$ \mathcal{L}_{SDS} = \text{sds.sds\_loss}(\text{latents}, \text{text\_cond}, \text{text\_uncond}) $$
        Where `text_cond` is the selected text embedding and `text_uncond` is the unconditional embedding (or negative prompt embedding).

    h.  **Entropy Regularization:** If $\text{args.lambda\_entropy} > 0$: Compute entropy loss on the alpha values ($\alpha$) from the rendering. Clamp $\alpha$ to $[10^{-5}, 1 - 10^{-5}]$ [S1, unofficial]:
        $$ \mathcal{L}_{entropy} = -\mathbb{E}[\alpha \log_2 \alpha + (1 - \alpha) \log_2 (1 - \alpha)] $$
        Scale the loss:
        $$ \mathcal{L}_{entropy\_scaled} = \mathcal{L}_{entropy} \times \text{args.lambda\_entropy} \times \min\left(1, \frac{2 \times \text{global\_step}}{\text{args.iters}}\right) $$
        Add to total loss.

    i.  **Orientation Regularization:** If $\text{args.lambda\_orient} > 0$ and the NeRF output contains `loss_orient`:
        $$ \mathcal{L}_{orient\_scaled} = \text{args.lambda\_orient} \times \text{loss\_orient} $$
        Add to total loss.

    j.  **Backward Pass:** Sum all loss components. Perform backward pass. If `args.loss_scaling` is true, use `GradScaler` for mixed precision training; otherwise, use standard backward [S1, unofficial].

```python
import torch
import torch.nn.functional as F

def compute_azimuth(cameras):
    """Compute azimuth angle in degrees from camera rotation matrices or poses."""
    # Extract forward vector from camera rotation (assumes standard right-handed convention)
    # Forward is typically the negative Z-axis of the camera frame.
    if isinstance(cameras, torch.Tensor):
        # cameras shape: [B, 3, 3] rotation matrices
        forward = -cameras[:, :, 2] 
        azimuth = torch.atan2(forward[:, 1], forward[:, 0]) * 180.0 / torch.pi
        return azimuth
    else:
        # Fallback for list of objects with .R attribute
        Rs = torch.stack([c.R for c in cameras])
        forward = -Rs[:, :, 2]
        return torch.atan2(forward[:, 1], forward[:, 0]) * 180.0 / torch.pi

def optimize_nerf_sds(
    sds_model, 
    nerf_model, 
    dataset, 
    prompt, 
    neg_prompt, 
    args, 
    device
):
    """
    Optimizes a NeRF model using SDS gradients.
    
    Args:
        sds_model: Pretrained diffusion model wrapper (provides encode_imgs, sds_loss, prepare_embeddings).
        nerf_model: NeRFNetwork instance.
        dataset: NeRFDataset instance yielding (images, cameras, masks) batches.
        prompt: Text prompt string.
        neg_prompt: Negative prompt string.
        args: Configuration object containing hyperparameters.
        device: Torch device.
    """
    # Step 1: Initialize Text Embeddings
    embeddings = sds_model.prepare_embeddings(
        prompt=prompt, 
        neg_prompt=neg_prompt, 
        view_dependent=True
    )
    
    # Step 2: Initialize NeRF Model (Assumed already initialized and moved to device)
    # nerf_model = NeRFNetwork().to(device)
    
    # Step 3: Configure Optimizer
    optimizer = torch.optim.Adan(
        nerf_model.parameters(),
        lr=5e-3,  # 5 * lr where lr=1e-3
        eps=1e-8,
        weight_decay=2e-5,
        max_grad_norm=5.0
    )
    scheduler = torch.optim.lr_scheduler.LambdaLR(optimizer, lr_lambda=lambda epoch: 1.0)
    
    global_step = 0
    total_iters = args.iters
    
    # Step 4: Load Data (Iteration over dataset handles batching)
    for epoch in range(args.epochs):
        for batch in dataset:
            images, cameras, masks = batch
            
            # Step 5a: Calculate Iteration Ratio
            exp_iter_ratio = (global_step - args.exp_start_iter) / (args.exp_end_iter - args.exp_start_iter)
            
            # Step 5b: Set Shading and Background Parameters
            if exp_iter_ratio <= args.latent_iter_ratio:
                ambient_ratio = 1.0
                shading = "normal"
                bg_color = None
            else:
                ambient_ratio = torch.rand(1).item() * (1.0 - args.min_ambient_ratio) + args.min_ambient_ratio
                if torch.rand(1).item() < args.textureless_ratio:
                    shading = "textureless"
                else:
                    shading = "lambertian"
                bg_color = None 
            
            # Step 5c: Set Background Color
            if args.bg_radius > 0 and torch.rand(1).item() > 0.5:
                bg_color = None # Use bg_net
            else:
                bg_color = torch.rand(3, device=device)
            
            # Step 5d: Render
            pred_rgb, alphas, outputs = nerf_model.render(
                cameras=cameras,
                img_size=(args.height, args.width),
                ambient_ratio=ambient_ratio,
                shading=shading,
                bg_color=bg_color
            )
            # pred_rgb shape: [B, 3, H, W]
            
            # Step 5e: Select Text Conditioning
            if args.view_dep_text:
                azimuth = compute_azimuth(cameras)
                if torch.abs(azimuth) <= 45:
                    text_cond = embeddings["front"]
                elif torch.abs(azimuth) <= 135:
                    text_cond = embeddings["side"]
                else:
                    text_cond = embeddings["back"]
            else:
                text_cond = embeddings["default"]
            
            text_uncond = embeddings.get("uncond", embeddings["default"])
            
            # Step 5f: Encode to Latent Space
            pred_rgb_resized = F.interpolate(pred_rgb, size=(512, 512), mode="bilinear", align_corners=False)
            latents = sds_model.encode_imgs(pred_rgb_resized)
            
            # Step 5g: Compute SDS Loss
            loss = sds_model.sds_loss(latents, text_cond, text_uncond)
            
            # Step 5h: Entropy Regularization
            if args.lambda_entropy > 0:
                alphas_clamped = torch.clamp(alphas, min=1e-5, max=1-1e-5)
                entropy = -(alphas_clamped * torch.log2(alphas_clamped) + (1 - alphas_clamped) * torch.log2(1 - alphas_clamped))
                loss_entropy = entropy.mean()
                scale_factor = min(1.0, 2 * global_step / total_iters)
                loss += args.lambda_entropy * scale_factor * loss_entropy
            
            # Step 5i: Orientation Regularization
            if args.lambda_orient > 0 and "loss_orient" in outputs:
                loss += args.lambda_orient * outputs["loss_orient"]
            
            # Step 5j: Backward Pass
            if args.loss_scaling:
                scaler = torch.cuda.amp.GradScaler()
                with torch.cuda.amp.autocast():
                    scaler.scale(loss).backward()
                scaler.step(optimizer)
                scaler.update()
            else:
                loss.backward()
            
            optimizer.step()
            optimizer.zero_grad()
            scheduler.step()
            
            global_step += 1
```

### Parameters
*   `lr`: Base learning rate, typically $10^{-3}$ [S1, unofficial].
*   `args.exp_start_iter`, `args.exp_end_iter`: Iteration range for exponential scheduling [S1, unofficial].
*   `args.latent_iter_ratio`: Threshold for switching shading/background strategies [S1, unofficial].
*   `args.min_ambient_ratio`: Minimum ambient ratio for later training stages [S1, unofficial].
*   `args.textureless_ratio`: Probability of using "textureless" shading [S1, unofficial].
*   `args.bg_radius`: Radius for background network usage [S1, unofficial].
*   `args.view_dep_text`: Boolean flag for view-dependent text conditioning [S1, unofficial].
*   `args.lambda_entropy`: Weight for entropy regularization [S1, unofficial].
*   `args.lambda_orient`: Weight for orientation regularization [S1, unofficial].

### Edge Cases and Pitfalls
*   **Precision:** Mixed precision training (`GradScaler`) is recommended to handle potential numerical instability in SDS gradients [S1, unofficial].
*   **Boundaries:** Alpha values must be clamped to $[10^{-5}, 1-10^{-5}]$ before computing entropy to avoid $\log(0)$ [S1, unofficial].
*   **Degenerate Input:** If the text prompt is empty or invalid, the embedding preparation step may fail. Ensure `neg_prompt` is handled correctly to avoid unconditional bias if not intended.
*   **View-Dependent Conditioning:** Incorrect calculation of azimuth angles can lead to mismatched text conditioning. Ensure camera coordinate systems are consistent.

## Operating characteristics
*   **Time Complexity:** Each iteration involves a forward pass through the NeRF, a forward pass through the diffusion encoder, and a backward pass through the SDS loss. The complexity is dominated by the diffusion model inference, which is significantly more expensive than standard NeRF rendering.
*   **Memory Complexity:** Requires storing the NeRF model, the diffusion model (encoder and UNet), and intermediate activations for backpropagation. Memory usage is high due to the large size of the diffusion model.
*   **Measured Performance:** On the "Truck" dataset, the method achieved a Mean PSNR of 27.717 and Mean SSIM of 0.926 [S1, unofficial].
*   **Strengths:** Enables text-driven 3D generation without requiring 3D ground-truth data. Can produce high-quality, semantically consistent 3D assets.
*   **Limitations:** Computationally expensive due to diffusion model usage. May suffer from "over-saturation" artifacts common in SDS optimization. Requires careful tuning of regularization parameters.
*   **When to Use:** When generating 3D scenes from text prompts is required, and computational resources are sufficient for diffusion-based optimization.
*   **When Not to Use:** When fast training is required, or when ground-truth images are available (standard NeRF training is more efficient and stable).
