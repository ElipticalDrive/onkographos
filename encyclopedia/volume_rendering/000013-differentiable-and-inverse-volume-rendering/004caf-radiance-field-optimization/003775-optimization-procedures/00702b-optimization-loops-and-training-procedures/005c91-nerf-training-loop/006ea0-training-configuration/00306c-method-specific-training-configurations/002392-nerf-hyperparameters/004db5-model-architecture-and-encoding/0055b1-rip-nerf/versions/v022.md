# Rip-NeRF

Also called: Rip-NeRF25k

## Overview
Rip-NeRF is a radiance field method that renders high-fidelity, anti-aliased images by combining cone casting with an anisotropic 3D Gaussian characterization [S1]. It distinguishes itself from siblings like Zip-NeRF by using Ripmap-Encoded Platonic Solids to enable efficient anisotropic area-sampling, whereas Zip-NeRF relies on a multi-sampling mechanism that is less efficient [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of calibrated multi-view 2D images.
*   **Outputs:** Rendered pixel colors and densities for volume rendering.

**Data Structures:**
1.  **Ripmap Encoding:** A hierarchical feature grid.
    *   **Base Level ($R_{0,0}$):** Learnable tensor with shape $H \times W \times C$. Default: $512 \times 512 \times 16$ [S1].
    *   **Derived Levels:** Generated from the base level using average pooling, not learnable [S1].
2.  **Platonic Solid:** A geometric proxy for area sampling.
    *   **Default:** Icosahedron with 10 unparalleled faces [S1].
    *   **Faces:** Denoted as $\{P_i \mid i = 1, \dots, n\}$, where $n=10$ for an icosahedron [S1].
3.  **3D Gaussian:** Characterizes a conical frustum.
    *   **Parameters:** Mean $\boldsymbol{\mu} \in \mathbb{R}^3$ and Covariance $\boldsymbol{\Sigma} \in \mathbb{R}^{3 \times 3}$ [S1].
4.  **Tiny MLP ($F_\theta$):** Maps aggregated features to output attributes [S1].

**Numbered Steps:**

1.  **Cone Casting and Frustum Division:**
    For each pixel, cast a cone into the scene and divide it into multiple conical frustums [S1].

2.  **3D Gaussian Characterization:**
    Characterize each conical frustum using an anisotropic 3D Gaussian parameterized by mean $\boldsymbol{\mu}$ and covariance $\boldsymbol{\Sigma}$ [S1].

3.  **Platonic Solid Projection:**
    Project the 3D Gaussian onto the faces of the Platonic solid to form 2D Gaussians [S1].
    *   For each face $P_i$, compute the projection matrix $M_i \in \mathbb{R}^{3 \times 2}$ mapping the 3D world coordinate system to the 2D coordinate system of plane $P_i$ [S1].
    *   Compute the projected mean $\boldsymbol{\mu}^{proj}_i$ and covariance $\boldsymbol{\Sigma}^{proj}_i$ of the 2D Gaussian on plane $P_i$ [S1].

4.  **Ripmap Encoding Query:**
    Query feature vectors $f_i$ from the Ripmap Encoding of each plane $P_i$ using tetra-linear interpolation [S1].
    *   The position $(p_x, p_y)$ and level $(l_x, l_y)$ used in the interpolation are determined by $\boldsymbol{\mu}^{proj}_i$ and $\boldsymbol{\Sigma}^{proj}_i$ respectively [S1].
    *   The interpolation covers the probability mass of the Gaussian footprint, adjusted by hyper-parameter $w=2.0$ [S1].
    *   *Note: The specific interpolation formula (Eq. 2 and Eq. 3 in source) is not fully detailed in the provided text, but the inputs are the projected Gaussian parameters and the Ripmap grid [S1].*

5.  **Feature Aggregation:**
    Concatenate all feature vectors $\{f_i \mid i = 1, \dots, n\}$ from the corresponding planes $\{P_i \mid i = 1, \dots, n\}$ to form the final feature vector $f$ of the 3D Gaussian [S1].

6.  **Color and Density Estimation:**
    Aggregate the final feature vector $f$ with the encoded view direction $d$. Pass this combined input through the tiny MLP $F_\theta$ to estimate color $c \in \mathbb{R}^3$ and density $\sigma \in \mathbb{R}$ [S1].

7.  **Volume Rendering:**
    Render the pixel color using the estimated color and density via standard volume rendering [S1].

8.  **Optimization:**
    Optimize the system end-to-end using a photometric loss between rendered and observed images [S1].
    *   **Area Loss:** Scale the photometric loss for each pixel by incorporating the area of its footprint on the image plane, denoted as $L_{area}$ [S1].

        """
        Initialize Rip-NeRF.

            nn.Linear(num_faces * ripmap_c + 3, 64),

            nn.Linear(64, 4)

        # Hyper-parameter for Gaussian footprint coverage
        self.w = 2.0

        """

        R_{i,j} is derived from R_{i-1,j} or R_{i,j-1} based on indices.
        """
        levels = { (0,0): base_level }

        # Determine levels based on covariance spread and hyper-parameter w
        # [G] Approximation: Higher covariance leads to lower resolution (higher level index)
        # Level indices are integers.

        Forward pass for Rip-NeRF.

**Parameters:**
*   **Base Level Ripmap Encoding ($R_{0,0}$):** Shape $H=512, W=512, C=16$ [S1].
*   **Platonic Solid:** Default is icosahedron (10 faces) [S1].
*   **Hyper-parameter $w$:** Set to 2.0 to adjust the probability mass coverage of the Gaussian footprint [S1].
*   **Optimizer:** AdamW [S1].
*   **Iterations:** 120k for Rip-NeRF; 25k for Rip-NeRF25k [S1].
*   **Weight Decay:** $1 \times 10^{-5}$ [S1].
*   **Initial Learning Rate:** $2 \times 10^{-3}$, modulated by MultiStepLR [S1].
*   **Ripmap Learning Rate:** Scaled up by 10.0 times [S1].

**Edge Cases and Pitfalls:**
*   **Empty Space:** Use a binary occupancy grid (e.g., from NerfAcc) to skip samples in empty areas [S1].
*   **Precision:** The Ripmap Encoding uses average pooling to derive levels, ensuring consistency and compactness [S1].
*   **Hardware:** Implemented using `tiny-cuda-nn` for MLP and CUDA kernels for Platonic Solid Projection and Ripmap Encoding [S1].

## Operating characteristics
*   **Training Time:** 2.6 hours on NVIDIA A100-SXM4-80GB GPU for Rip-NeRF; 32 minutes for Rip-NeRF25k [S1].
*   **Model Size:** 160 MB [S1].
*   **GPU Memory:** 20 GB during training [S1].
*   **Rendering Speed:** 3 FPS [S1].
*   **Comparison:** Outperforms Zip-NeRF in training time (2.6h vs 4.5h), model size (160MB vs 592MB), and rendering speed (3 FPS vs 0.25 FPS) [S1]. Zip-NeRF has slightly better SSIM [S1].
*   **Strengths:** Efficient anisotropic area-sampling, high-fidelity anti-aliasing, compact representation [S1].
*   **Limitations:** Requires calibrated multi-view images [S1].

## Background
*   **Origin:** Rip-NeRF was introduced in the paper "Rip-NeRF: Anti-aliasing Radiance Fields with Ripmap-Encoded Platonic Solids" [S1].
*   **History:** It builds on previous work in hybrid representations, cone casting, and area-sampling, such as Mip-NeRF, Tri-MipRF, and Zip-NeRF [S1].
*   **Usage:** Used for high-fidelity anti-aliased rendering from calibrated multi-view images [S1].
