# Multi-Space Neural Radiance Field (MS-NeRF)

Also called: MS-Mip-NeRF 360, MS-NeRFB, Multi-space NeRF

## Overview
MS-NeRF addresses the failure of standard single-space Neural Radiance Fields (NeRF) to render reflective and refractive objects, which violate multi-view consistency in Euclidean space and result in blurry or distorted images [S1, S2]. It differs from its siblings by representing the scene as a group of parallel feature fields (sub-spaces) rather than a single radiance field, allowing virtual images to be placed in sub-spaces visible only from specific viewpoints [S1]. This approach serves as a general enhancement module for existing NeRF backbones (MLP-based or grid-based) with minimal computational overhead [S1].

## How it works
MS-NeRF extends the Feature Fields parent method [Parent](12995-feature-fields.md) by replacing the single output layer with a multi-head module that predicts $K$ distinct feature sets per ray sample [S1].

**Inputs and Outputs:**
*   **Input:** Ray $r$, backbone features (position $\mathbf{x}$, direction $\mathbf{d}$).
*   **Output:** Final color $\hat{\mathbf{C}}(r)$.

**Data Structures:**
*   $K$: Hyperparameter for the total number of sub-spaces.
*   $d$: Hyperparameter for the feature dimension of the neural feature field.
*   $\sigma_{ik}$: Density at sample $i$ in sub-space $k$.
*   $\mathbf{f}_{ik}$: Feature vector (dimension $d$) at sample $i$ in sub-space $k$.
*   $\mathbf{F}^k$: Accumulated feature map for sub-space $k$ along the ray.
*   $\mathbf{C}^k$: Decoded color for sub-space $k$.
*   $w_k$: Visibility weight for sub-space $k$.

**Numbered Steps:**

1.  **Multi-Head Sampling:** For each sample point $i$ along the ray, the backbone network outputs $K$ pairs of density and feature vectors: $\{\sigma_{ik}, \mathbf{f}_{ik}\}_{k=1}^K$ [S1].
2.  **Ray Integration per Sub-space:** Integrate features along the ray for each sub-space $k$ independently to compute the accumulated feature map $\hat{\mathbf{F}}^k(r)$ [S1]:
    $$ \hat{\mathbf{F}}^k(r) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_{ik} \delta_i)) \mathbf{f}_{ik} $$
    where $N$ is the number of samples, $\delta_i$ is the distance between samples, and $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_{jk} \delta_j)$ is the accumulated transmittance for sub-space $k$ [S1].
3.  **Decoding and Gating:** Pass the accumulated features $\{\hat{\mathbf{F}}^k\}_{k=1}^K$ through two separate Multi-Layer Perceptrons (MLPs) [S1]:
    *   **Decoder MLP ($\Theta_D$):** Takes $\hat{\mathbf{F}}^k$ as input and outputs RGB color vectors $\mathbf{C}^k$ [S1].
    *   **Gate MLP ($\Theta_G$):** Takes $\hat{\mathbf{F}}^k$ as input and outputs scalar visibility weights $w_k$ [S1].
    $$ \Theta_D\{\hat{\mathbf{F}}^k\} \rightarrow \{\mathbf{C}^k\} $$
    $$ \Theta_G\{\hat{\mathbf{F}}^k\} \rightarrow \{w_k\} $$
4.  **Softmax Weighting:** Apply the softmax function to the weights $\{w_k\}$ to determine the contribution of each sub-space to the final color [S1]:
    $$ \hat{\mathbf{C}}(r) = \sum_{k=1}^{K} \left( \frac{\exp(w_k)}{\sum_{i=1}^{K} \exp(w_i)} \right) \mathbf{C}^k $$
5.  **Rendering:** The resulting $\hat{\mathbf{C}}(r)$ is the final pixel color. No additional loss terms are required compared to vanilla NeRF [S1].

```python
def ms_nerf_render(ray, backbone, decoder_mlp, gate_mlp, K, d):
    """
    Renders a single ray using the MS-NeRF multi-space module.
    
    Args:
        ray: Ray origin and direction.
        backbone: The pre-trained NeRF backbone network (MLP or Grid).
        decoder_mlp: MLP Theta_D mapping features to RGB.
        gate_mlp: MLP Theta_G mapping features to visibility weights.
        K: Number of sub-spaces.
        d: Feature dimension.
        
    Returns:
        final_color: RGB color vector.
    """
    # 1. Sample points along the ray (standard NeRF sampling)
    # Assume samples are pre-computed or generated by the backbone's sampler
    # positions: (N, 3), directions: (N, 3)
    positions, directions = sample_ray(ray)
    
    # 2. Backbone forward pass to get K densities and features
    # backbone returns K sets of (sigma, feature_vector)
    # sigma_k: (K, N)
    # features_k: (K, N, d)
    sigma_k, features_k = backbone(positions, directions)
    
    # 3. Integrate features for each sub-space k
    accumulated_features = []
    for k in range(K):
        sigma = sigma_k[k]  # (N,)
        features = features_k[k]  # (N, d)
        
        # Calculate transmittance T_i for sub-space k
        # T_i = exp(-sum_{j=1}^{i-1} sigma_j * delta_j)
        # delta is distance between samples. Assuming uniform or pre-calculated deltas.
        deltas = compute_deltas(positions) # (N,)
        
        # Accumulated transmittance
        # T[0] = 1.0
        # T[i] = T[i-1] * exp(-sigma[i-1] * deltas[i-1])
        transmittance = compute_transmittance(sigma, deltas) # (N,)
        
        # Weighted feature contribution
        # weight_i = T_i * (1 - exp(-sigma_i * delta_i))
        weights = transmittance * (1.0 - torch.exp(-sigma * deltas)) # (N,)
        
        # Sum over samples
        # F_k = sum_i (weights_i * features_i)
        F_k = torch.sum(weights.unsqueeze(1) * features, dim=0) # (d,)
        accumulated_features.append(F_k)
        
    accumulated_features = torch.stack(accumulated_features) # (K, d)
    
    # 4. Decode colors and gate weights
    # Decoder MLP: F_k -> C_k
    # Gate MLP: F_k -> w_k
    # Note: In practice, these might be batched or called iteratively.
    # Assuming decoder_mlp and gate_mlp accept a (d,) tensor and return (3,) and (1,) respectively.
    
    colors = []
    weights = []
    for k in range(K):
        F_k = accumulated_features[k]
        C_k = decoder_mlp(F_k) # (3,)
        w_k = gate_mlp(F_k)    # (1,)
        colors.append(C_k)
        weights.append(w_k)
        
    colors = torch.stack(colors) # (K, 3)
    weights = torch.stack(weights) # (K, 1)
    
    # 5. Softmax weighting
    # softmax weights over K
    softmax_weights = torch.softmax(weights.squeeze(1), dim=0) # (K,)
    
    # Final color
    final_color = torch.sum(softmax_weights.unsqueeze(1) * colors, dim=0) # (3,)
    
    return final_color
```

**Parameters:**
*   $K$: Total sub-space number. Typical values depend on scene complexity; more complex reflections/refractions may require more sub-spaces [S1, S2].
*   $d$: Feature dimension of the neural feature field [S1].

**Edge Cases and Pitfalls:**
*   **Complex Scenes:** Highly complex reflective and refractive scenes may require a larger $K$ to model accurately [S2].
*   **Multi-view Consistency:** The method specifically addresses violations of multi-view consistency caused by mirrors; standard NeRF fails here by treating virtual images as textures [S1].

## Operating characteristics
*   **Time and Memory Complexity:** The method introduces small computational overheads for training and inference compared to single-space NeRF methods [S1, S2]. The overhead comes from the additional MLPs (Decoder and Gate) and the integration over $K$ sub-spaces.
*   **Measured Performance:**
    *   On Mip-NeRF 360: Improves PSNR by 4.15 dB on reflective regions with 0.5% extra parameters [S1].
    *   On TensoRF: Improves PSNR by 2.71 dB on reflective regions with 0.046% extra parameters [S1].
    *   Does not degrade rendering quality on non-reflective regions [S1].
*   **Strengths:** Automatically handles mirror-like objects in 360-degree rendering without manual labeling of reflective surfaces [S1]. Significantly outperforms existing single-space NeRF methods in scenes with complex light paths through mirror-like objects [S1].
*   **Limitations:** May require more sub-spaces for very complex scenes [S2].
*   **When to Use:** When rendering scenes with reflective or refractive objects (e.g., mirrors, glass) where multi-view consistency is violated.
*   **When Not to Use:** For simple scenes without significant reflections/refractions, the overhead may be unnecessary as standard NeRF performs well.

## Background
MS-NeRF was proposed by Z.X. Yin et al. and published in IEEE Transactions on Pattern Analysis and Machine Intelligence (TPAMI) in 2025 (preliminary version at CVPR) [S1]. It addresses the limitation of existing NeRF methods that suffer from blurry or distorted rendering when reflective objects are present [S1]. The authors constructed a novel dataset with 33 synthetic and 7 real captured scenes with complex reflection and refraction to benchmark robustness [S1]. The method is designed as an enhancement module for both MLP-based (NeRF, Mip-NeRF, Mip-NeRF 360) and grid-based (TensoRF, iNGP) NeRF methods, and has been integrated with reconstruction methods like NeuS [S1].
