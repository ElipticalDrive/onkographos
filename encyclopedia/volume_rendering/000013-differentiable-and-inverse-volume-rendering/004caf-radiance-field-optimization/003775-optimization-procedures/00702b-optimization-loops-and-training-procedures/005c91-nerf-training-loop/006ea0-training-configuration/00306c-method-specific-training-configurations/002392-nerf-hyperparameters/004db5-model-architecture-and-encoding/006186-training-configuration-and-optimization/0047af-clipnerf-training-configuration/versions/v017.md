# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF is a text-driven stylization method that optimizes a Neural Radiance Field (NeRF) to match a target text prompt by enforcing directional similarity in the CLIP embedding space [S2]. It distinguishes itself from standard NeRF training by freezing density-related parameters and minimizing the negative cosine similarity between rendered image patches and text embeddings, thereby guiding the color and style of the radiance field without altering its geometric structure [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained NeRF model (encoding $\mathbf{x}$ and direction $\mathbf{d}$ to density $\sigma$ and color $\mathbf{c}$), a source image $\mathbf{I}_{src}$ (optional, for relative loss), a target text prompt $\mathbf{t}_{tgt}$, and a source text prompt $\mathbf{t}_{src}$ (optional).
*   **Output:** A stylized NeRF model where the rendered colors align with the semantic style of $\mathbf{t}_{tgt}$.

**Data Structures:**
*   **NeRF Model:** Standard MLP architecture mapping $(\mathbf{x}, \mathbf{d}) \to (\sigma, \mathbf{c})$. Parameters are split into density-related and color-related sub-parameters.
*   **CLIP Encoder:** ViT-B/32 variant, denoted $\mathcal{E}_t$ for text and $\mathcal{E}_i$ for images. Outputs normalized embedding vectors $\hat{\mathbf{e}}$.
*   **Training Patch:** A $128 \times 128$ pixel region sampled from the rendered view.

**Numbered Steps:**
1.  **Initialization:** Load a pre-trained NeRF. Freeze all sub-parameters related to volume density $\sigma$. Keep color $\mathbf{c}$ parameters trainable [S1].
2.  **Text Encoding:** Encode the target text prompt $\mathbf{t}_{tgt}$ (and source prompt $\mathbf{t}_{src}$ if using relative loss) using $\mathcal{E}_t$ to obtain normalized vectors $\hat{\mathcal{E}}_t(\mathbf{t}_{tgt})$ [S2].
3.  **View Sampling:** Randomly sample a camera pose from the training dataset [S1].
4.  **Patch Rendering:**
    *   Define a $128 \times 128$ patch in the image plane.
    *   To cover a wider receptive field, sample rays for this patch with a stride interval of 5. This results in a $640 \times 640$ effective receptive field on the original image resolution [S1].
    *   Render the patch using volume rendering. Reduce memory usage by limiting importance sampling points to 16 per ray. The fine MLP uses a total of 80 samples (64 coarse + 16 fine) [S1].
    *   Let the rendered patch be $\mathbf{I}_{tgt}$ [S2].
5.  **Image Encoding:** Encode the rendered patch $\mathbf{I}_{tgt}$ using $\mathcal{E}_i$ to obtain $\hat{\mathcal{E}}_i(\mathbf{I}_{tgt})$ [S2].
6.  **Loss Calculation:** Compute the directional CLIP loss. Two variants exist:
    *   **Absolute Directional Loss:** Measures cosine similarity between the rendered image and the target text [S2]:
        $$ \mathcal{L}_{dir} = 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) \rangle $$
    *   **Relative Directional Loss:** Measures the similarity of the *direction* from source to target in both image and text spaces, mitigating mode collapse [S2]:
        $$ \mathcal{L}_{dir} = 1 - \left\langle \frac{\hat{\mathcal{E}}_i(\mathbf{I}_{tgt}) - \hat{\mathcal{E}}_i(\mathbf{I}_{src})}{\|\hat{\mathcal{E}}_i(\mathbf{I}_{tgt}) - \hat{\mathcal{E}}_i(\mathbf{I}_{src})\|}, \frac{\hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) - \hat{\mathcal{E}}_t(\mathbf{t}_{src})}{\|\hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) - \hat{\mathcal{E}}_t(\mathbf{t}_{src})\|} \right\rangle $$
        *(Note: The source formula [S2] Eq. 4 omits explicit normalization in the denominator but implies normalized vectors $\hat{\cdot}$. Standard cosine similarity assumes normalized inputs.)*
7.  **Optimization:** Update the trainable color parameters using the Adam optimizer with a learning rate of $0.0001$ [S1].
8.  **Iteration:** Repeat steps 3–7 for 500 iterations [S1].

**Pseudocode:**
```python
def clipnerf_train(nerf_model, text_prompt, source_image=None, source_text=None, iterations=500):
    # 1. Initialize
    optimizer = Adam(nerf_model.color_params, lr=0.0001)
    clip_encoder = CLIP_ViT_B32()
    
    # Freeze density parameters
    nerf_model.freeze_density()
    
    # 2. Encode Text
    target_text_emb = clip_encoder.encode_text(text_prompt)
    target_text_emb = normalize(target_text_emb)
    
    source_text_emb = None
    if source_text is not None:
        source_text_emb = clip_encoder.encode_text(source_text)
        source_text_emb = normalize(source_text_emb)
        
    source_image_emb = None
    if source_image is not None:
        source_image_emb = clip_encoder.encode_image(source_image)
        source_image_emb = normalize(source_image_emb)

    for i in range(iterations):
        # 3. Sample View
        camera_pose = random_sample_training_view()
        
        # 4. Render Patch
        # Patch size 128x128, stride 5 implies sampling rays for a 640x640 area
        # but only rendering 128x128 pixels? 
        # Source says: "render a patch of 128x128 size... rays in 128x128 patch 
        # are sampled with stride interval 5... CLIP's receptive field is 640x640"
        # This implies the patch is rendered at low resolution or subsampled,
        # but the ray sampling covers a larger area.
        rendered_patch = render_patch(nerf_model, camera_pose, patch_size=128, stride=5, samples_per_ray=16)
        
        # 5. Encode Image
        rendered_patch_emb = clip_encoder.encode_image(rendered_patch)
        rendered_patch_emb = normalize(rendered_patch_emb)
        
        # 6. Compute Loss
        if source_text_emb is not None and source_image_emb is not None:
            # Relative Directional Loss
            img_diff = normalize(rendered_patch_emb - source_image_emb)
            txt_diff = normalize(target_text_emb - source_text_emb)
            loss = 1.0 - cosine_similarity(img_diff, txt_diff)
        else:
            # Absolute Directional Loss
            loss = 1.0 - cosine_similarity(rendered_patch_emb, target_text_emb)
            
        # 7. Optimize
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
    return nerf_model
```

**Parameters:**
*   **Iterations:** 500 [S1].
*   **Optimizer:** Adam, learning rate $0.0001$ [S1].
*   **Patch Size:** $128 \times 128$ pixels [S1].
*   **Ray Sampling Stride:** 5 (within the patch) [S1].
*   **Importance Sampling Points:** 16 per ray [S1].
*   **Fine MLP Samples:** 80 total (64 coarse + 16 fine) [S1].
*   **Text Encoder:** CLIP ViT-B/32 [S1].

**Edge Cases and Pitfalls:**
*   **Memory Constraints:** Naive differentiable rendering of high-resolution images is intractable due to memory limits [S1]. The patch-based approach with stride sampling is required [S1].
*   **Mode Collapse:** The absolute directional CLIP loss can cause mode collapse of the generator and hurt generation diversity [S2].
*   **Insufficient Magnitude:** Directional loss alone struggles to reach sufficient stylization magnitude, resulting in weak style transfer [S2]. This is because it measures directional similarity but ignores actual distances in embedding space [S2].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of iterations (500) and the number of rays sampled per patch. The patch-based rendering reduces memory complexity compared to full-image rendering.
*   **Memory Complexity:** Reduced by rendering small patches ($128 \times 128$) and limiting importance sampling points (16) [S1].
*   **Strengths:** Enables text-driven stylization of 3D scenes without retraining geometry; efficient memory usage via patch rendering [S1].
*   **Limitations:** Absolute loss causes mode collapse; directional loss may lack stylization magnitude [S2].
*   **When to use:** When text-guided style transfer is required for a pre-existing NeRF [S2].
*   **When not to use:** When high-fidelity geometric changes are needed (density is frozen) [S1].

## Background
CLIPNeRF was introduced by Wang et al. in 2021, extending the StyleCLIP and StyleGAN-NADA approaches to 3D radiance fields [S2]. It was designed to address the lack of significant descriptions for reproducing NeRF editing results, providing a method to distill feature fields for editing [S1]. The method builds on the observation that CLIP embeddings can guide the trajectory of stylization in the embedding space [S2].
