# MTL-FeatureNet

Also called: Multi-Task Learning Feature Network

## Overview
MTL-FeatureNet is a feature extraction network for multi-task learning that handles demands of multiple tasks by improving the accuracy and relevance of features extracted from a single 2D toy view [S1]. It addresses the challenge of adapting a unified feature representation to diverse task requirements by integrating task dynamic attention modulation and a dynamic adapter layer [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A 2D image $I$ and a set of tasks $\{T_1, T_2, \ldots, T_n\}$ [S1].
*   **Output:** A set of task-specific features $\{F_{task1}, F_{task2}, \ldots, F_{taskn}\}$ [S1].

**Data Structures**
*   **Initial Features ($C_i$):** Extracted from image $I$ for each task $T_i$ [S1].
*   **Task Relevance ($TR_i$):** A scalar score computed for each task [S1].
*   **Global Features ($F_{global}$):** The aggregated feature representation after attention modulation [S1].
*   **Task-Specific Features ($F_{taski}$):** The final output features for task $i$ [S1].

**Parameters**
*   $\gamma_{task}$: A learnable scaling factor customized for each task, adjusted during learning to optimize transformation efficiency [S1].
*   $W_{task}$: A task-specific weight matrix [S1].
*   $b_{task}$: A task-specific bias term [S1].
*   $\sigma$: An activation function [S1].
*   $\lambda_k$: Weight for the loss of task $k$ [S1].
*   $\mu$: Weight for the cross-task consistency loss [S1].
*   $v_{ij}$: A dynamically adjusted weight based on the correlation between tasks $i$ and $j$ [S1].
*   $d_k$: The dimension of the key vectors in the attention mechanism [S1].

**Formulas**
1.  **Position Encoding with Task Relevance:**
    The conventional position encoding is modulated by the task relevance score $TR$:
    $$ PE(pos, 2i) = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right) \cdot TR $$
    $$ PE(pos, 2i + 1) = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right) \cdot TR $$
    where $pos$ is position, $i$ is index, $d_{model}$ is model dimension, and $TR$ is the task relevance score [S1].

2.  **Task Dynamic Attention Modulation:**
    The attention mechanism is modulated by the task relevance score $TR_i$:
    $$ A_{t_i}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}} \cdot \exp(TR_i)\right) \cdot V $$
    where $Q, K, V$ are the query, key, and value matrices [S1].

3.  **Task-Specific Feature Transformation:**
    Task-specific features are derived from global features using a dynamic adapter layer:
    $$ F_{task} = \sigma(\gamma_{task} \cdot W_{task} \cdot F_{global} + b_{task}) $$
    where $\gamma_{task}$ scales the transformation [S1].

4.  **Composite Loss Function:**
    The total loss combines individual task losses and a cross-task consistency term:
    $$ L = \sum_k \lambda_k \cdot L_k + \mu \cdot L_{cross}(F_{task1}, F_{task2}, \ldots) $$
    where $L_k$ is the loss for task $k$ [S1].

5.  **Cross-Task Consistency Loss:**
    This loss facilitates knowledge sharing by comparing feature representations:
    $$ L_{cross}(F_{task1}, F_{task2}, \ldots) = \sum_{i \ne j} v_{ij} \cdot \|F_{taski} - F_{taskj}\|^2 $$
    where $v_{ij}$ is the dynamically adjusted weight [S1].

**Numbered Steps**
1.  **Feature Extraction and Task Relevance:** For each task $T_i$, extract initial features $C_i$ from the input image $I$. Compute the task relevance score $TR_i$ using a task-specific MLP: $TR_i = \text{MLP}_{task}(C_i)$ [S1].
2.  **Task Dynamic Attention Modulation:** For each task $T_i$, adjust the attention weights using the computed relevance score $TR_i$ via the formula $A_{t_i}(Q, K, V) = \text{softmax}((QK^T/\sqrt{d_k}) \cdot \exp(TR_i)) \cdot V$ [S1].
3.  **Dynamic Adapter Layer (DAL):** Process the modulated features through the DAL to compute task-specific features $F_{taski}$ using the transformation $F_{task} = \sigma(\gamma_{task} \cdot W_{task} \cdot F_{global} + b_{task})$ [S1].
4.  **Loss Computation:** Compute the composite loss $L$ using the individual task losses $L_k$ and the cross-task consistency loss $L_{cross}$ [S1].
5.  **Output Features:** Return the set of task-specific features $\{F_{task1}, F_{task2}, \ldots, F_{taskn}\}$ [S1].

**Pseudocode**
```python
def mtl_feature_net(image_I, tasks):
    """
    MTL-FeatureNet for multi-task feature extraction.
    
    Args:
        image_I: Input 2D image.
        tasks: List of task identifiers {T1, T2, ..., Tn}.
        
    Returns:
        List of task-specific features {F_task1, F_task2, ..., F_taskn}.
    """
    n = len(tasks)
    initial_features = []
    task_relevance_scores = []
    
    # Step 1: Feature Extraction and Task Relevance
    for i, task in enumerate(tasks):
        # Extract initial features Ci from image I [G]
        Ci = extract_features(image_I, task)
        initial_features.append(Ci)
        # Compute task relevance TRi using a task-specific MLP [G]
        TRi = mlp_task(Ci)
        task_relevance_scores.append(TRi)
        
    # Step 2: Task Dynamic Attention Modulation
    modulated_features = []
    for i, task in enumerate(tasks):
        Ci = initial_features[i]
        TRi = task_relevance_scores[i]
        
        # Project to Q, K, V [G]
        Q = project_query(Ci)
        K = project_key(Ci)
        V = project_value(Ci)
        
        # Adjust attention using TRi
        dk = Q.shape[-1]
        attention_weights = softmax((Q @ K.T) / sqrt(dk) * exp(TRi))
        Ati = attention_weights @ V
        modulated_features.append(Ati)
        
    # Step 3: Dynamic Adapter Layer (DAL)
    # Aggregate modulated features into F_global [G]
    F_global = aggregate_features(modulated_features)
    
    task_specific_features = []
    for i, task in enumerate(tasks):
        # Retrieve learnable parameters for the task [G]
        gamma_task = get_scaling_factor(task)
        W_task = get_weight_matrix(task)
        b_task = get_bias(task)
        
        # Linear transformation with scaling
        transformed = gamma_task * (W_task @ F_global) + b_task
        # Apply activation function [G]
        F_taski = activation(transformed)
        task_specific_features.append(F_taski)
        
    # Step 4: Loss Computation (training loop only)
    # L = sum(lambda_k * Lk) + mu * L_cross
    # L_cross = sum(v_ij * ||F_taski - F_taskj||^2)
    
    # Step 5: Output Features
    return task_specific_features
```

**Edge Cases and Pitfalls**
*   **Task Correlation:** The weight $v_{ij}$ in the cross-task loss depends on the correlation between tasks [S1]. The method for dynamically adjusting $v_{ij}$ is not specified in the sources [G].
*   **Attention Modulation:** The term $\exp(TR_i)$ scales the attention logits [S1]. If $TR_i$ is large, this can lead to numerical instability or overly sharp attention distributions [G].
*   **Global Feature Aggregation:** The source mentions $F_{global}$ but does not specify how it is constructed from the modulated features $A_{t_i}$ (e.g., concatenation, averaging, or attention pooling) [G].

## Operating characteristics
*   **Time Complexity:** Not given in the sources [G].
*   **Memory Complexity:** Not given in the sources [G].
*   **Measured Performance:** The method is reported to improve rendering accuracy and color reproduction fidelity for toy 3D models compared to standard NeRF approaches [S1].
*   **Strengths:** Handles multiple tasks efficiently by dynamically modulating attention and adapting features via the DAL [S1].
*   **Limitations:** Designed for 2D toy views, which may limit its applicability to complex 3D scenes without modification [S1].
*   **When to use:** When a single 2D view needs to support multiple downstream tasks with shared but distinct feature requirements [G].
*   **When not to use:** For standard single-task volume rendering where direct coordinate-to-radiance mapping is sufficient [G].

## Background
MTL-FeatureNet was introduced for multi-task learning in 3D toy reconstruction using adaptive scaled neural radiation fields [S1]. It was proposed to address the challenges of high complexity scenes and complex lighting conditions by combining adaptive scale adjustment with spectral perception [S1]. The method is part of an improved NeRF model that enhances detail-rich 3D visual content generation [S1].
