# KFD-NeRF

Also called: Kalman Filter Guided Deformation Field NeRF, Kalman Filter Guided Dynamic NeRF

## Overview
KFD-NeRF is a dynamic neural radiance field method that models the 4D radiance field as a dynamic system with temporally varying states, estimated using a Kalman filter to combine observations from input data and predictions based on local linear motion equations [S1]. It differs from sibling methods like [Gear-NeRF](13848-gear-nerf.md) and [NeRF with Time Parameter](14705-nerf-with-time-parameter.md) by explicitly separating motion estimation into an observer branch (shallow MLP) and a predictor branch (linear motion model), fusing them via a learnable Kalman gain [S1]. Unlike [Forward Warping for Novel View Synthesis](15541-forward-warping-for-novel-view-synthesis.md) which relies on explicit depth and warping, KFD-NeRF uses a deformation field to warp points to a canonical space, and unlike [Dynamic Appearance Particle Neural Radiance Field](15550-dynamic-appearance-particle-neural-radiance-field.md) which uses particles, it uses a tri-plane spatial representation for efficiency [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D point coordinates $\mathbf{x}$, timestamp $t_i$, and camera parameters. Training data consists of multi-view images released in chronological order.
*   **Outputs:** Deformation field $\hat{d\mathbf{x}}_{t_i}$ for each point, which warps $\mathbf{x}$ to a canonical space. The canonical space is encoded using a tri-plane representation. The final radiance field outputs color $\mathbf{c}$ and density $\sigma$ from the canonical coordinates.

**Data Structures:**
1.  **Tri-Plane Representation:** Three mutually orthogonal 2D planes (collection $C$) encoding the canonical space. Features from these planes are concatenated with raw coordinate inputs to handle coordinate shift errors [S1].
2.  **Observer MLP:** A two-layer shallow MLP that takes $\mathbf{x}$ and $t_i$ as input. It outputs the mean observation $y_{t_i}$ and noise-related terms $\varepsilon_{t_i}$ [S1].
3.  **Kalman Gain Network:** A linear layer $f$ that takes $\varepsilon_{t_i}, \varepsilon_{t_{i-1}}$ and timestamps $t_i, t_{i-1}$ as input to compute the Kalman gain $K_{t_i}$ [S1].

**Algorithm:**
The method models the deformation of each 3D point as a single-state dynamic system. The state $d\mathbf{x}_{t_i}$ represents the deformation for frame $t_i$. The estimation proceeds in two branches:

1.  **Prediction Branch:**
    *   Approximate velocity $v_{t_i}$ using deformations from the previous two frames:
        $$
        v_{t_i} = (d\mathbf{x}_{t_{i-1}} - d\mathbf{x}_{t_{i-2}}) / \Delta t_i
        $$
    *   Calculate the predicted deformation $\hat{d\mathbf{x}}_{t_i}^{-}$ using local linear motion:
        $$
        \hat{d\mathbf{x}}_{t_i}^{-} = 2d\mathbf{x}_{t_{i-1}} - d\mathbf{x}_{t_{i-2}}
        $$
        *(Note: The source formula in [S1] Eq. 12 and Algorithm 1 implies $\hat{d\mathbf{x}}_{t_i}^{-} = d\mathbf{x}_{t_{i-1}} + \Delta t_i \cdot v_{t_i}$, which simplifies to $2d\mathbf{x}_{t_{i-1}} - d\mathbf{x}_{t_{i-2}}$ if $\Delta t_i = 1$ or is normalized. Algorithm 1 explicitly writes $\hat{d\mathbf{x}}_{t_i}^{-} = 2d\mathbf{x}_{t_{i-1}} - d\mathbf{x}_{t_{i-2}}$.)*

2.  **Observation Branch:**
    *   Query the observer MLP with $\mathbf{x}$ and $t_i$ to get observation $y_{t_i}$ and noise terms $\varepsilon_{t_i}$ [S1].

3.  **Kalman Update:**
    *   Compute Kalman gain $K_{t_i}$:
        $$
        K_{t_i} = f(\varepsilon_{t_i}, \varepsilon_{t_{i-1}}, t_i, t_{i-1})
        $$
    *   Combine prediction and observation:
        $$
        \hat{d\mathbf{x}}_{t_i} = \hat{d\mathbf{x}}_{t_i}^{-} + K_{t_i} (y_{t_i} - \hat{d\mathbf{x}}_{t_i}^{-})
        $$

4.  **Warping and Rendering:**
    *   Warp all points in real space to the time-independent canonical space using $\hat{d\mathbf{x}}_{t_i}$.
    *   Render the radiance field from the canonical space.

**Pseudocode:**
```python
def kfd_nerf_deformation(x, t_i, t_prev, t_prev_prev, observer_mlp, kalman_gain_net):
    """
    Computes the deformation for point x at time t_i using Kalman filtering.
    
    Args:
        x: 3D point coordinates (vector)
        t_i: Current timestamp (float)
        t_prev: Previous timestamp (float)
        t_prev_prev: Timestamp before previous (float)
        observer_mlp: Two-layer MLP returning (observation, noise_terms)
        kalman_gain_net: Linear layer returning Kalman gain
        
    Returns:
        estimated_deformation: Warped displacement vector
    """
    # 1. Get previous deformations and noise terms
    # Note: In training, these are outputs from previous forward passes
    # For inference or step-by-step, these must be stored or retrieved
    d_x_prev, eps_prev = observer_mlp(x, t_prev)
    d_x_prev_prev, eps_prev_prev = observer_mlp(x, t_prev_prev)
    
    # 2. Prediction Branch
    # Calculate velocity based on local linear motion
    # Delta t is assumed to be normalized or 1 in the simplified formula
    # v_ti = (d_x_prev - d_x_prev_prev) / delta_t
    # predicted_deformation = d_x_prev + v_ti * delta_t
    # Simplified from source Algorithm 1:
    predicted_deformation = 2 * d_x_prev - d_x_prev_prev
    
    # 3. Observation Branch
    observation, eps_current = observer_mlp(x, t_i)
    
    # 4. Kalman Gain Calculation
    # Input: noise terms from current and previous step, and timestamps
    kalman_gain = kalman_gain_net(eps_current, eps_prev, t_i, t_prev)
    
    # 5. Update Step
    # estimated_deformation = predicted + gain * (observation - predicted)
    estimated_deformation = predicted_deformation + kalman_gain * (observation - predicted_deformation)
    
    return estimated_deformation
```

**Loss Functions:**
The total loss is a weighted sum of five components [S1]:
$$
\mathcal{L} = \mathcal{L}_{image} + \mathcal{L}_{kf} + \mathcal{L}_{co} + \mathcal{L}_{prop} + \lambda_{tv} \mathcal{L}_{tv}
$$

1.  **Image Loss ($\mathcal{L}_{image}$):** Standard photometric loss between rendered and ground truth images.
2.  **Kalman Loss ($\mathcal{L}_{kf}$):** Minimizes error between observation and estimated deformation:
    $$
    \mathcal{L}_{kf} = \frac{1}{\mathcal{N}} \sum_{\mathbf{x} \in \mathcal{N}} \| y_{t_i} - \hat{d\mathbf{x}}_{t_i} \|_2^2
    $$
3.  **Canonical Observation Loss ($\mathcal{L}_{co}$):** Soft regularization for frame $t_0$ to normalize the difference between canonical space and real world:
    $$
    \mathcal{L}_{co} = \frac{1}{\mathcal{N}} \sum_{\mathbf{x} \in \mathcal{N}} \mathbb{1}(t) d\mathbf{x}
    $$
    where $\mathbb{1}(t) = 1$ if $t=0$ and $0$ otherwise.
4.  **Proposal Loss ($\mathcal{L}_{prop}$):** Consistency loss between proposal network density and learned model (from Mip-NeRF 360 [2]).
5.  **Total Variation Loss ($\mathcal{L}_{tv}$):** Encourages sparse edges in the tri-plane representation:
    $$
    \mathcal{L}_{tv}(\mathbf{x}) = \frac{1}{|C|} \sum_{c, i, j} (\| \mathbf{x}_c^{i,j} - \mathbf{x}_c^{i-1,j} \|_2^2 + \| \mathbf{x}_c^{i,j} - \mathbf{x}_c^{i,j-1} \|_2^2)
    $$
    where $c$ is a plane from collection $C$, and $i, j$ are indices on the plane's resolution.

**Parameters:**
*   **Total Variation Weight ($\lambda_{tv}$):** $1 \times 10^{-4}$ [S1].
*   **Observer MLP Depth:** 2 layers [S1].
*   **Spatial Representation:** Tri-plane [S1].

**Edge Cases and Pitfalls:**
*   **Initial Training:** Predictions primarily influence the process to facilitate convergence for frames with substantial motion. Observations take precedence in later stages to recover fine-grained details [S1].
*   **Coordinate Shift:** Tri-plane encoding introduces coordinate shift errors. Mitigated by concatenating encoded tri-plane features with raw coordinate inputs [S1].
*   **Temporal Order:** Training images are released in chronological order to ensure previous frames offer ample priors for current frame learning [S1].

## Operating characteristics
*   **Time Complexity:** Training time is comparable to other dynamic NeRF methods. On synthetic data, KFD-NeRF-S takes 30 mins and KFD-NeRF-L takes 3 hours, compared to D-NeRF's 48 hours [S1].
*   **Memory Complexity:** Uses tri-plane representation which significantly reduces memory footprint compared to MLP-based spatial representations (e.g., D-NeRF uses 16 MB params, KFD-NeRF uses 175 MB for L version) [S1].
*   **Performance (Synthetic):** PSNR 35.73 dB, SSIM 0.984, LPIPS 0.045, Average 0.0131 [S1].
*   **Performance (Real):** PSNR 28.75 dB, SSIM 0.891, LPIPS 0.115, Average 0.0389 [S1].
*   **Strengths:** Accurate deformation estimation from scene observations and predictions; efficient tri-plane representation allows rapid convergence; Kalman filter balances early convergence (via prediction) and fine detail recovery (via observation) [S1].
*   **Limitations:** Relies on local linear motion assumption, which may not capture complex non-linear motions perfectly; requires chronological training order [S1].

## Background
KFD-NeRF was introduced by Li, Niu, Zhong, Nobuhara, Nishino, and Zheng from The University of Tokyo, Kyoto University, and Shanghai Artificial Intelligence Laboratory in 2024 [S1]. It is based on the paper "KFD-NeRF: Rethinking Dynamic NeRF with Kalman Filter" published in ECCV 2024 [S1]. The method draws inspiration from control theory, modeling the 4D radiance field as a dynamic system. It improves upon previous dynamic NeRF methods like D-NeRF [36] by replacing the deep MLP deformation field with a Kalman filter-guided approach and using a tri-plane spatial representation instead of an MLP-based backbone [S1].
