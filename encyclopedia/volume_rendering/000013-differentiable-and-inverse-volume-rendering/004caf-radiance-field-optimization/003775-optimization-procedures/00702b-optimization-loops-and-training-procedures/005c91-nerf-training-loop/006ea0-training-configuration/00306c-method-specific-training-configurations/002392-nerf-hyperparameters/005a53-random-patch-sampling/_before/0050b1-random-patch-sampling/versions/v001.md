# Random Patch Sampling


## Overview
Random Patch Sampling is a ray sampling strategy that selects groups of rays within a close spatial location (a patch) to model the interference of neighboring pixels caused by defocus blur, replacing conventional random ray sampling [S1]. It sets itself apart from its sibling [Patch-based Ray Sampling](11953-patch-based-ray-sampling.md) by using random selection of patches rather than grid-based selection, and from [Loss-based Adaptive Sampling](11954-loss-based-adaptive-sampling.md) by focusing on spatial locality for blur convolution rather than error metrics. It solves the problem of high training time in deblurring neural fields by reducing the number of required neighboring rays through sharing within patches [S1].

## How it works
**Inputs and Outputs:**
*   Input: A target number of interesting pixels $N$ (or region size $P'$), a blur kernel size $K \times K$, and a scene representation (e.g., TensoRF) [S1].
*   Output: A set of rendered pixels forming patches, which are used to compute blurred intensity values and train the sharpness prior [S1].

**Data Structures:**
*   **Patch:** A square region of pixels of size $P' \times P'$ [S1].
*   **Blur Kernel:** A learnable $K \times K$ kernel, initialized with a 2D Gaussian distribution [S1].

**Steps:**
1.  **Define Region:** Determine the width and height $P'$ of the region to compute intensity for the interesting pixels [S1].
2.  **Sample Patches:** Randomly select patches of size $P' \times P'$ from the image domain [S1].
3.  **Render Neighbors:** For each selected patch, render all pixels in the region $(P' + K + 1) \times (P' + K + 1)$ to account for the blur kernel's receptive field and boundary effects [S1].
    *   *Note:* The total number of rendered pixels per patch is $(P' + K + 1)^2$ [S1].
4.  **Compute Blurred Intensity:** Apply the blur kernel convolution to the rendered pixels to obtain the blurred intensity values for the central $P' \times P'$ region [S1].
5.  **Update Sharpness Prior:** Use the blurred intensity values to enforce the sharpness prior, determining the sharpness level of image pixels [S1].
6.  **Iterate:** Repeat steps 2-5 for the desired number of iterations or epochs [S1].

**Formulas:**
*   Total rendered pixels per patch:
    $$ N_{rendered} = (P' + K + 1)^2 $$
    where $P'$ is the width/height of the interesting region and $K$ is the blur kernel size [S1].
*   Reduction factor for neighboring rays per ray:
    $$ \text{Reduction} = \frac{K^2}{\frac{(P' + K + 1)^2}{P'^2}} $$
    This represents the reduction in the number of required neighboring rays per ray compared to naive rendering [S1].

**Parameters:**
*   $P'$: Width and height of the region to compute intensity. In experiments, the number of interesting pixels $P'^2$ is 122, implying $P' \approx 11$ (since $11^2=121$, likely rounded or approximate) [S1].
*   $K$: Size of the blur kernel. In experiments, $K=11$ [S1].
*   $P$: Patch size used in experiments is 22 [S1]. Note: The text distinguishes between $P'$ (region for intensity) and $P$ (patch size). It states "sample 28 patches with the patch size P = 22" and "interesting pixels $P'^2$ is 122". This implies $P' \approx 11$ and $P=22$. The formula uses $P'$.
*   Learning rate for kernel: 0.05 [S1].
*   Number of groups to skip convolution: 100 groups of each view with high sharpness value [S1].

**Edge Cases and Pitfalls:**
*   **Boundary Effects:** The rendering region $(P' + K + 1)^2$ includes neighboring pixels to handle the blur kernel's extent. Failure to render these neighbors leads to incorrect blur convolution at patch boundaries [S1].
*   **Training Time:** Rendering neighboring pixels increases training time, which is inevitable in deblurring neural fields. Naively reducing rays degrades quality [S1].
*   **Precision:** The method relies on accurate blur kernel learning. Initialization with a 2D Gaussian is critical [S1].

## Subtopics

### Finetuning Pretrained SR Model with Random Patch Sampling
A training strategy where a pretrained Super-Resolution model (EDSR) is finetuned on the NeRF dataset using random patch sampling, offering the best trade-off between training time and PSNR [S2]. It involves downloading the pretrained EDSR model from HuggingFace and finetuning it on the NeRF dataset for 150 epochs [S2]. On NeRF-Synthetic, FT-RandPatch achieves 31.64 PSNR (2×) and 32.53 PSNR (4×) with training times of 51 minutes (2×) and 19 minutes (4×) [S2]. It provides better PSNR than bilinear interpolation (29.77/26.67) and pretrained EDSR without finetuning (30.40/27.62), while being faster than distillation methods [S2].

## Operating characteristics
*   **Time Complexity:** Reduces the number of required neighboring rays per ray from $K^2$ to $\frac{K^2}{(P' + K + 1)^2 / P'^2}$ [S1]. This saves significant time compared to NeRF which fetches thousands of rays per training iteration where $N >> P'^2$ [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** On a single NVIDIA A100 GPU, with grid resolution reduced from $640^3$ to $480^3$ and grid components raised from 96 to 132 [S1].
*   **Strengths:** Effective in reducing training time while maintaining reconstruction quality for deblurring neural fields by learning affinity among neighboring pixels [S1].
*   **Limitations:** Rendering neighboring pixels increases training time compared to random ray sampling without patches, though less than naive full rendering [S1].
*   **When to Use:** When deblurring neural fields and needing to model defocus blur efficiently.
*   **When Not to Use:** When sharpness is not a concern or when computational resources are extremely limited and blur modeling is not required.

## Background
Originated in "Sharp-NeRF: Grid-based Fast Deblurring Neural Radiance Fields using Sharpness Prior" [S1]. It addresses the intermingling of neighboring pixels due to shallow depth of field in camera acquisition [S1]. The method leverages the effectiveness of sharpness measures and learning-based sharpness priors to deblur NeRF [S1].
