# Voxel and Grid Representations


## Overview
Voxel and Grid Representations replace coordinate-based Multi-Layer Perceptrons (MLPs) with explicit, differentiable 3D grids to store density and appearance features, enabling significantly faster optimization than pure MLP approaches [S1].

## Shared principles
The core mechanism discretizes the 3D scene space into a grid structure where each voxel stores learnable parameters.

**Data Structures:**
*   **Density Grid ($\mathbf{V}_\sigma$):** A tensor storing volume density $\sigma$. The evidence specifies dimensions $\mathbb{R}^{H \times W \times D}$ [S1].
*   **Feature Grid ($\mathbf{V}_a$):** A tensor storing latent appearance features per voxel [S1].

**Query Mechanism:**
For a query point $\mathbf{x}$ in world space, grid values are retrieved via interpolation:
$$ f(\mathbf{x}) = \text{interp}(\mathbf{x}, \mathbf{V}_a) $$
This operation is differentiable, allowing gradients to flow back to the grid values during optimization [S1].

**Decoding:**
The interpolated feature vector is passed to a decoding function $S_\Theta$ to predict color:
$$ \mathbf{c}(\mathbf{x}) = S_\Theta(\text{interp}(\mathbf{x}, \mathbf{V}_a)) $$
[ S1 ]

**Optimization:**
Grid parameters are updated via gradient descent to minimize the difference between rendered images and ground truth observations [S1].

```python
import torch
import torch.nn as nn

class VoxelGridQuery:
    def __init__(self, V_sigma, V_a, decoder_S):
        """
        Initialize voxel grid query mechanism.
        :param V_sigma: Density grid tensor (H, W, D)
        :param V_a: Feature grid tensor (H, W, D, P)
        :param decoder_S: Decoding function/MLP mapping features to color
        """
        self.V_sigma = V_sigma
        self.V_a = V_a
        self.decoder_S = decoder_S

    def query(self, points):
        """
        Query density and features at given 3D points.
        :param points: Tensor of shape (N, 3)
        :return: density (N,), features (N, P)
        """
        # Standard trilinear interpolation for dense grids
        # Points should be normalized to [0, 1] or grid coordinates
        density = torch.nn.functional.grid_sample(
            self.V_sigma.unsqueeze(0).unsqueeze(0), 
            points.unsqueeze(0).unsqueeze(0), 
            mode='trilinear', padding_mode='zeros'
        ).squeeze()
        
        features = torch.nn.functional.grid_sample(
            self.V_a.permute(0, 3, 1, 2).unsqueeze(0), 
            points.unsqueeze(0).unsqueeze(0), 
            mode='trilinear', padding_mode='zeros'
        ).squeeze().permute(0, 2, 1)
        
        return density, features

    def forward(self, points, directions=None):
        """
        Forward pass: query grid and decode color.
        :param points: Query points (N, 3)
        :param directions: Viewing directions (N, 3), optional
        :return: color (N, 3)
        """
        _, features = self.query(points)
        # Decoder combines features (and optionally directions) to predict color
        color = self.decoder_S(features, directions)
        return color
```

## Subtopics

### [Binary Radiance Fields](13622-binary-radiance-fields.md)
Binary Radiance Fields constrain feature grid parameters to binary values $\{-1, +1\}$ using a straight-through estimator, enabling end-to-end binarization without post-processing [13622-binary-radiance-fields.md]. It distinguishes itself by combining binary feature encoding with a 2D-3D hybrid multi-resolution architecture to mitigate hash collisions [13622-binary-radiance-fields.md]. Chosen for storage-efficient reconstruction where memory footprint must be drastically reduced while maintaining quality [13622-binary-radiance-fields.md].

### [Adaptive Differentiable Grids for Cryo-ET](17614-adaptive-differentiable-grids-for-cryo-et.md)
Adaptive Differentiable Grids replace fully connected MLPs with an adaptive octree structure where each enabled node stores a learnable 3D density grid [17614-adaptive-differentiable-grids-for-cryo-et.md]. It jointly optimizes grid structure and values using differentiable trilinear interpolation and explicit regularization (TV, boundary consistency, non-local constraints) to separate noise from signal in low-SNR data [17614-adaptive-differentiable-grids-for-cryo-et.md]. Chosen for cryo-electron tomography reconstruction where preserving fine details in complex regions while handling missing wedges and fiducial markers is critical [17614-adaptive-differentiable-grids-for-cryo-et.md].

### [Vox-Surf](18110-vox-surf.md)
Vox-Surf combines explicit sparse voxel structures with neural implicit surface representations, storing only trainable embeddings at voxel vertices rather than explicit SDF values [18110-vox-surf.md]. It uses surface-aware sampling and progressive pruning/splitting to reduce empty-space learning [18110-vox-surf.md]. Chosen for efficient surface reconstruction and realistic rendering from multi-view posed images, offering finer surface representation with larger voxels and lightweight networks compared to dense implicit methods [18110-vox-surf.md].

### [Depth-Guided Robust and Fast Point Cloud Fusion NeRF](18135-depth-guided-robust-and-fast-point-cloud-fusion-nerf.md)
This method treats the radiance field as an explicit voxel grid of features initialized and refined via multi-view point cloud fusion [18135-depth-guided-robust-and-fast-point-cloud-fusion-nerf.md]. It constructs a fused point cloud from all input views to refine inaccurate depth values, avoiding error-prone depth completion networks [18135-depth-guided-robust-and-fast-point-cloud-fusion-nerf.md]. Chosen for novel-view synthesis from sparse RGB-D inputs where robust geometry estimation, smaller model size, and faster training are prioritized [18135-depth-guided-robust-and-fast-point-cloud-fusion-nerf.md].

### [Sparse Feature Volume](18180-sparse-feature-volume.md)
The Sparse Feature Volume encodes geometry and appearance into a sparse grid of learnable latent vectors organized in a coarse-to-fine hierarchy, allocating memory only to occupied regions [18180-sparse-feature-volume.md]. It uses Transformer-based spatial fusion and GRU temporal integration to build expressive latent vectors [18180-sparse-feature-volume.md]. Chosen for high-resolution surface reconstruction and online reconstruction, offering better detail expression than continuous occupancy fields while maintaining memory efficiency [18180-sparse-feature-volume.md].

### [PAC-NeRF](18672-pac-nerf.md)
PAC-NeRF uses a hybrid Eulerian-Lagrangian representation with a differentiable Material Point Method (MPM) simulator to enforce continuum mechanics conservation laws [18672-pac-nerf.md]. It estimates physical parameters (e.g., Young’s modulus, viscosity) without assuming prior object geometry or topology [18672-pac-nerf.md]. Chosen for geometry-agnostic system identification of highly dynamic objects from multi-view videos, naturally handling topology changes and frictional contacts [18672-pac-nerf.md].

### Efficient EndoNeRF scene representation
A voxel-grids-based representation that replaces coordinate-based MLPs with explicit density ($\mathbf{V}_\sigma$) and feature volume grids ($\mathbf{V}_a$) to accelerate optimization for dynamic surgical scenes [S1]. It models dynamic scenes by warping a canonical radiance field with a time-dependent deformation field, using decomposed 4D motion fields and a 3-layer MLP to map spatial-temporal coordinates $(\mathbf{x}, t)$ to displacement $\Delta \mathbf{x}$ [S1].

### Uncertain Surface Distillation
A strategy to distill knowledge of previously learned 3D scenes by querying density on a subdivided occupancy grid [S2]. It divides each occupancy grid cell into a 5x5x5 subgrid, queries the density of each subgrid point, and considers a volume cell as a surface for distillation if any subgrid point has density above threshold $\tau$ [S2]. Uses a USD occupancy grid resolution of 50x50x50 and $\tau = 3$ [S2].

### Occupancy-Aware NeRF
A NeRF variant that jointly learns volumetric density ($\sigma$), RGB color ($\mathbf{c}$), and a binary occupancy value ($o$) for a 3D point $\mathbf{x}$ and viewing direction $\mathbf{d}$, enabling O(1) collision queries via a cached 3D array [S3, unofficial]. At inference, the occupancy grid is cached as a regular 3D array at resolution $\Delta$ [S3, unofficial]. The network uses a shared hash-grid backbone feeding a separate two-layer MLP head with sigmoid activation for the occupancy branch [S3, unofficial]. It optimizes rendering and occupancy with $L = L_{\text{rgb}} + \lambda_d L_{\text{depth}} + \lambda_o \text{BCE}(\hat{o}, o^*)$, where $o^*$ is derived from depth observations via volumetric carving [S3, unofficial].

### Neural Sparse Voxel Fields
A method that builds and dynamically updates an octree structure while the MLP is optimized, allowing for aggressive empty space skipping and early ray termination when the transmittance along the ray approaches zero [S4, unofficial].

### PlenOctrees
A method that queries the MLP to produce a sparse voxel octree of volume density and spherical harmonic coefficients, then finetunes this octree representation using a rendering loss to improve output image quality [S4, unofficial].

## Background
The shift from coordinate-based MLPs to voxel grids was driven by the need for faster optimization in neural radiance fields [S1]. Early works demonstrated that implicit-explicit voxel grid representations achieve much faster optimization than pure MLP approaches [S1]. This family of methods is applied in domains requiring rapid training or real-time rendering, such as surgical simulation [S1] and cryo-electron tomography [17614-adaptive-differentiable-grids-for-cryo-et.md].
