# Low-Light NeRF (LLNeRF)
## Overview
Low-Light NeRF (LLNeRF) is an unsupervised method that synthesizes normal-light novel views directly from low-dynamic-range (LDR) sRGB images captured in low-light conditions [S1]. It solves the problem of NeRF's inability to handle the non-linearity, low signal-to-noise ratio, and color distortion introduced by camera ISP processing in sRGB data [S1]. Unlike HDR-NeRF which requires RAW data with exposure metadata, LLNeRF decomposes radiance field learning into view-dependent and view-independent components to jointly enhance illumination and correct colors without ground truth supervision [S1].
## How it works
**Inputs and Outputs:**
- **Inputs:** A set of camera-finished, 8-bit/channel sRGB images from a low-light scene. No exposure metadata or RAW data is required [S1].
- **Outputs:** A radiance field model capable of rendering novel views with enhanced lighting, reduced noise, and corrected colors [S1].

**Data Structures:**
The model architecture extends the standard NeRF MLP structure [S1].
- **Density MLP ($F_{density}$):** Takes positional encoding $\tau$ and outputs density $\sigma$ [S1].
- **Feature MLP 1 ($F_1$):** Takes $\tau$ and view direction $d$; outputs a single-channel view-dependent component $v$ representing lighting intensity [S1].
- **Feature MLP 2 ($F_2$):** Takes $\tau$; outputs a 3-channel view-independent component $r$ representing the intrinsic color basis [S1].
- **Enhancement Model ($\phi$):** A function applied to $v$ to enhance lighting [S1].

**Numbered Steps:**
1. **Sampling:** For a camera ray $r$, sample $N$ points along the ray. Compute positional encodings $\tau_i$ for each point and view directions $d_i$ [S1].
2. **Decomposition:** For each sampled point $i$, compute the view-dependent component $v_i$ and view-independent component $r_i$ using the respective MLPs:
   $$ v_i = F_1(\tau_i, d_i; \Theta_{F1}) $$
   $$ r_i = F_2(\tau_i; \Theta_{F2}) $$
   Here, $v_i$ is a scalar (single-channel) and $r_i$ is a 3-channel vector [S1].
3. **Enhancement:** Apply the enhancement function $\phi$ to the view-dependent component $v_i$ to obtain the enhanced lighting component $\hat{v}_i = \phi(v_i)$ [S1]. The function $\phi$ is designed to increase brightness and reduce noise in the lighting component [S1].
4. **Color Reconstruction:** Compute the enhanced color $\hat{c}_i$ by element-wise multiplication (Hadamard product) of the enhanced view-dependent component and the view-independent component:
   $$ \hat{c}_i = \hat{v}_i \bullet r_i $$
   where $\bullet$ denotes element-wise multiplication [S1].
5. **Volume Rendering:** Render the final pixel color $\hat{c}_r$ using the standard volume rendering integral with the enhanced colors $\hat{c}_i$ and the original densities $\sigma_i$:
   $$ \hat{c}_r = \sum_{i=1}^{N} w_i \hat{c}_i = \sum_{i=1}^{N} \left( P_i \prod_{j=1}^{i-1} (1 - P_j) \right) \hat{c}_i $$
   where $P_i = 1 - e^{-\sigma_i \delta_i}$ is the transmittance weight, $\delta_i = t_{i+1} - t_i$ is the distance between samples, and the product term represents the accumulated transmittance [S1].
6. **Optimization:** Optimize the network parameters $\Theta_{F1}, \Theta_{F2}$ and the enhancement function $\phi$ by minimizing the photometric error between the rendered enhanced images and the input low-light images, or by using an unsupervised loss that encourages consistency and enhancement properties [S1]. *Note: The specific loss function formulation is not detailed in the provided sources, but the optimization is unsupervised [S1].*

**Formulas:**
- Decomposition: $v = F_1(\tau, d; \Theta_{F1})$, $r = F_2(\tau; \Theta_{F2})$ [S1].
- Color: $c = v \bullet r$, $\hat{c} = \phi(v) \bullet r$ [S1].
- Rendering: $\hat{c}_r = \sum_{i} w_i \hat{c}_i$ with $w_i = P_i \prod_{j<i} (1 - P_j)$ [S1].

**Parameters:**
- Input images are 8-bit/channel LDR sRGB [S1].
- Positional encoding $\psi(\cdot)$ follows the Mip-NeRF implementation (interval splitting and integrated positional encoding) [S1].

**Edge Cases and Pitfalls:**
- Standard NeRF fails on low-light sRGB images because the camera ISP process changes linearity and blends scene radiance with noise, resulting in low signal-to-noise ratio and color distortion [S1].
- Combining existing 2D low-light enhancement methods with NeRF causes view inconsistency because 2D methods do not maintain multi-view consistency and may not generalize to in-the-wild scenes [S1].
- LLNeRF avoids these pitfalls by decomposing the radiance field and learning enhancement jointly with the NeRF optimization [S1].

**Strengths and Limitations:**
- **Strengths:** Works directly on camera-finished sRGB images without requiring RAW data or exposure metadata; unsupervised; produces normal-light novel views with proper lighting, vivid colors, and details; outperforms existing low-light enhancement methods and NeRF methods [S1].
- **Limitations:** Relies on the assumption that lighting is the dominant factor varying across views; the enhancement function $\phi$ must be carefully designed to avoid over-enhancement or artifacts [S1].

**When to Use:**
Use LLNeRF when you have a collection of low-light sRGB images and want to synthesize normal-light novel views without access to RAW data or ground truth normal-light images [S1].

**When Not to Use:**
Do not use if you have RAW data with exposure metadata, in which case HDR-NeRF might be more appropriate [S1]. Do not use if you require supervised training with ground truth normal-light images [S1].

## Background
LLNeRF was proposed in the paper "Lighting up NeRF via Unsupervised Decomposition and Enhancement" [S1]. It addresses the limitations of NeRF when applied to low-light sRGB images, which suffer from non-linearity and noise due to ISP processing [S1]. Previous methods like HDR-NeRF required RAW data, and combining 2D enhancement with NeRF led to view inconsistency [S1]. LLNeRF introduces a decomposition of radiance field learning into view-dependent and view-independent components to enable unsupervised enhancement [S1].
