# SCARF
Also called: Scalable Continual Learning Framework, Scalable Continual Learning Framework for Memory-efficient Multiple Neural Radiance Fields

## Overview
SCARF is a memory-efficient continual learning framework that represents multiple 3D scenes within a single neural network [S1]. It solves the catastrophic forgetting problem that occurs when training a NeRF on a sequence of scenes with access to only one scene at a time and single-pass data [S1]. It sets itself apart from siblings like [DoF-NeRF](9432-dof-nerf.md) or [NeRF-VPT](11770-nerf-vpt.md) by factorizing the NeRF MLP weights into scene-specific and cross-scene shared components generated by a hypernetwork, rather than modifying input encodings or using prompt-based tuning [S1]. Unlike [Uncertainty and Reliability](14487-uncertainty-and-reliability.md) which focuses on confidence estimation, SCARF focuses on parameter efficiency and knowledge retention across distinct domains [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A sequence of scenes $\{S_i\}_{i=1}^N$ [S1]. For the $t$-th scene $S_t$, the input is training data (images/rays) for $S_t$ and a pre-extracted explicit density occupancy grid for all previously learned scenes $\{S_i\}_{i=1}^{t-1}$ [S1].
*   **Output:** A single unified NeRF model $M_t$ capable of rendering all scenes $\{S_i\}_{i=1}^t$ with minimal degradation on previous scenes [S1].

**Data Structures and Layout:**
The NeRF network $F_\Theta$ consists of an encoder $\{E_l\}_{l=1}^9$ and a decoder $D$ [S1].
1.  **Encoder:** 8 fully-connected layers with 256 channels, followed by an additional layer that outputs density $\sigma$ and a 256-dimensional feature vector $\mathbf{h}$ [S1]. Input is the 10-degree positional encoding of position $\mathbf{x}$ [S1]. A skip connection is added at the 5th layer [S1].
2.  **Decoder:** 2 fully-connected layers with 128 and 3 channels [S1]. Input is the feature vector $\mathbf{h}$ concatenated with the 4-degree positional encoding of viewing direction $\mathbf{d}$ [S1]. Output is RGB radiance $\mathbf{c}$ [S1].
3.  **Factorized Weights:** Each encoder layer weight matrix $E_l \in \mathbb{R}^{c_{in} \times c_{out}}$ is factorized into:
    *   **Scene-Specific Weight Matrix (SSWM):** $SM_l^i \in \mathbb{R}^{c_{in} \times K}$ [S1].
    *   **Cross-Scene Weight Matrix (CSWM):** $CM_l \in \mathbb{R}^{K \times c_{out}}$ [S1].
    *   **Coefficient Matrix:** $C_l^i \in \mathbb{R}^{K \times K}$ [S1].
    *   Relationship: $E_l^i = SM_l^i \cdot C_l^i \cdot CM_l$ [S1].
4.  **Hypernetwork:** A generator $G_l$ takes random noise $z_l^i \sim \mathcal{N}(0, 1)$ and outputs the SSWM: $SM_l^i = G_l(z_l^i)$ [S1].
5.  **Occupancy Grid:** A $50 \times 50 \times 50$ grid is pre-extracted for each scene [S1]. Each cell is subdivided into a $5 \times 5 \times 5$ subgrid [S1]. A cell is marked as "surface" if any subgrid point has density $\sigma > \tau$ [S1].

**Numbered Steps:**
1.  **Initialization (Scene 1):** Initialize the global CSWM $\{CM_l\}_{l=1}^L$ and global hypernetworks $\{G_l\}_{l=1}^L$ [S1]. For scene 1, sample random noise $z_l^1$ and initialize coefficient matrices $C_l^1$ [S1]. Train $M_1$ on scene $S_1$ using standard NeRF loss [S1]. Extract the explicit density occupancy grid for $S_1$ [S1].
2.  **Continual Learning (Scene $t > 1$):** Initialize new parameters for scene $t$: random noises $\{z_l^t\}_{l=1}^L$ and coefficient matrices $\{C_l^t\}_{l=1}^L$ [S1]. The CSWM $\{CM_l\}$ and hypernetworks $\{G_l\}$ are shared and not re-initialized [S1].
3.  **Distillation Data Preparation:** For each previous scene $i \in \{1, \dots, t-1\}$, use its pre-extracted occupancy grid to sample points where $\sigma > \tau$ [S1]. Sample rays for rendering [S1].
4.  **Forward Pass (Distillation):** For previous scenes $i$, compute radiance $\mathbf{c}_{M_t}^i$, density $\sigma_{M_t}^i$, and rendered color $C(r)_{M_t}^i$ using model $M_t$ [S1]. Compute the same metrics for the previous model $M_{t-1}$ ($\mathbf{c}_{M_{t-1}}^i, \sigma_{M_{t-1}}^i, C(r)_{M_{t-1}}^i$) [S1].
5.  **Forward Pass (New Scene):** For new scene $t$, compute rendered color $C(r)_{M_t}^t$ and ground truth $C(r)_t$ [S1].
6.  **Loss Computation:**
    *   Compute Uncertain Surface Distillation Loss $L_{dis}^i$ for each previous scene $i$:
        $$ L_{c\sigma}^i = \|\mathbf{c}_{M_t}^i - \mathbf{c}_{M_{t-1}}^i\|^2 + \alpha \|\sigma_{M_t}^i - \sigma_{M_{t-1}}^i\|^2 $$
        $$ L_{C(r)}^i = \|C(r)_{M_t}^i - C(r)_{M_{t-1}}^i\|^2 $$
        $$ L_{dis}^i = \beta_1 \mathbb{I}(\sigma_i > \tau) L_{c\sigma}^i + \beta_2 L_{C(r)}^i + \log \beta_1 + \log \beta_2 $$
        where $\mathbb{I}$ is the indicator function, $\alpha$ balances density/radiance terms, and $\beta_1, \beta_2$ are learnable self-balancing parameters [S1].
    *   Compute New Scene Loss:
        $$ L_{C(r)}^t = \|C(r)_{M_t}^t - C(r)_t\|^2 $$
    *   Total Loss:
        $$ L = \sum_{i=1}^{t-1} L_{dis}^i + \gamma L_{C(r)}^t $$
        where $\gamma$ balances the distillation loss for previous scenes and the learning loss for the new scene [S1].
7.  **Optimization:** For the first 2000 steps, optimize only $L_{C(r)}^t$ (new scene learning) to prevent immediate forgetting [S1]. For subsequent steps, optimize the total loss $L$ [S1]. Use the Adam optimizer [S1].

**Parameters and Typical Values:**
*   $K$: Latent dimension for factorized matrices [S1]. Smaller $K$ reduces parameters but requires constraints to prevent overfitting [S1].
*   $\alpha$: Balances radiance and density regularization in $L_{c\sigma}$ [S1].
*   $\beta_1, \beta_2$: Learnable self-balancing parameters for uncertainty [S1].
*   $\tau$: Density threshold for surface sampling (default 3) [S1].
*   $\gamma$: Balances distillation loss (previous scenes) and new scene learning loss [S1].
*   Positional Encoding: Degree 10 for position, Degree 4 for direction [S1].
*   Encoder Dimension: 256 [S1].
*   Decoder Dimensions: 128, 3 [S1].
*   Learning Rates: Parameter Generator ($G_l$) initial $1 \times 10^{-4}$, decays exponentially to $5 \times 10^{-5}$ [S1]. Learnable Matrices ($C_l^i, CM_l$) initial $5 \times 10^{-4}$, decays exponentially to $5 \times 10^{-5}$ [S1].
*   Batch Sizes: New Scene Training 4096 pixel rays [S1]. Distillation 1024 pixel rays and 8192 random sampled points per previous scene [S1].
*   Warm-up Steps: 2000 [S1].
*   Parameter Count: Vanilla NeRF uses $(c_{in} \times (c_{out} + 1) \times L) \times N + P_d \times N$ [S1]. SCARF uses $N \times (Z + K \times K) + L \times (Z \times K \times c_{in} + K \times c_{out}) + P_d$ [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def positional_encoding(x, degree):
    freq_bands = 2.0 ** torch.arange(degree, device=x.device).float()
    x_expanded = x.unsqueeze(-1) * freq_bands.unsqueeze(0)
    return torch.cat([torch.sin(x_expanded), torch.cos(x_expanded)], dim=-1)

def sample_surface_points(grid_density, threshold, num_samples):
    points = []
    while len(points) < num_samples:
        gx, gy, gz = torch.randint(0, 50, (3,))
        for dx in range(5):
            for dy in range(5):
                for dz in range(5):
                    if len(points) >= num_samples: break
                    density = grid_density[gx + dx/5, gy + dy/5, gz + dz/5]
                    if density > threshold:
                        points.append(torch.tensor([gx + dx/5, gy + dy/5, gz + dz/5]))
    return torch.stack(points)

class SCARF:
    def __init__(self, c_in, c_out, L, K, Z_dim):
        self.L = L
        self.K = K
        self.c_in = c_in
        self.c_out = c_out
        self.CM = nn.ParameterList([nn.Parameter(torch.randn(K, c_out)) for _ in range(L)])
        self.G = nn.ModuleList([
            nn.Sequential(nn.Linear(Z_dim, 256), nn.ReLU(), nn.Linear(256, c_in * K))
            for _ in range(L)
        ])
        self.decoder = nn.Sequential(nn.Linear(256 + 12, 128), nn.ReLU(), nn.Linear(128, 3))
        self.scene_params = {}
        self.beta1 = nn.Parameter(torch.tensor(1.0))
        self.beta2 = nn.Parameter(torch.tensor(1.0))

    def get_encoder_weights(self, scene_id, layer_idx):
        if scene_id not in self.scene_params:
            raise ValueError(f"Scene {scene_id} not initialized")
        z_l = self.scene_params[scene_id]['z'][layer_idx]
        C_l = self.scene_params[scene_id]['C'][layer_idx]
        SM_l = self.G[layer_idx](z_l).view(self.c_in, self.K)
        return torch.matmul(torch.matmul(SM_l, C_l), self.CM[layer_idx])

    def forward_encoder(self, x_pos, scene_id):
        x_pe = positional_encoding(x_pos, degree=10)
        h = x_pe
        for l in range(9):
            E_l = self.get_encoder_weights(scene_id, l)
            h = torch.matmul(h, E_l)
            if l == 4:
                h = torch.cat([h, x_pe], dim=-1)
            if l < 8:
                h = F.relu(h)
            else:
                sigma = h[:, :1]
                h = h[:, 1:]
        return sigma, h

    def forward_decoder(self, h, d_view):
        d_pe = positional_encoding(d_view, degree=4)
        return self.decoder(torch.cat([h, d_pe], dim=-1))

    def compute_distillation_loss(self, batch, scene_id, prev_model):
        c_curr, sigma_curr = self.forward_encoder(batch, scene_id)
        c_prev, sigma_prev = prev_model.forward_encoder(batch, scene_id)
        rgb_curr = self.forward_decoder(c_curr, batch)
        rgb_prev = prev_model.forward_decoder(c_prev, batch)
        l_c_sigma = torch.mean((c_curr - c_prev)**2) + 0.1 * torch.mean((sigma_curr - sigma_prev)**2)
        l_cr = torch.mean((rgb_curr - rgb_prev)**2)
        return self.beta1 * l_c_sigma + self.beta2 * l_cr + torch.log(self.beta1) + torch.log(self.beta2)

    def train_step(self, new_batch, new_scene_id, t, prev_models, occupancy_grids):
        loss_new = torch.mean((self.forward_decoder(self.forward_encoder(new_batch, new_scene_id)[1], new_batch) - new_batch)**2)
        loss_distill = 0
        for i in range(t):
            grid = occupancy_grids[i]
            distill_batch = sample_surface_points(grid, threshold=3.0, num_samples=8192)
            loss_distill += self.compute_distillation_loss(distill_batch, i, prev_models[i])
        total_loss = loss_distill + 1.0 * loss_new
        total_loss.backward()
```

**Subtopics:**
*   **Uncertain Surface Radiance field Distillation (USD):** A single-stage distillation method that uses an explicit density occupancy grid to sample points on the surface (density > threshold) for previous scenes, avoiding blank regions [S1]. It balances density/radiance field distillation and RGB pixel distillation using learnable parameters [S1].
*   **Weight Factorization:** The core mechanism of splitting NeRF weights into SSWMs (generated by hypernetwork from noise) and CSWMs (shared) [S1]. This allows adding new scenes by only adding noise and coefficient matrices [S1].

## Operating characteristics
*   **Time Complexity:** Training is approximately 1.2x slower than vanilla NeRF due to the USD strategy requiring forward passes through previous models and occupancy grid sampling [S1]. Rendering speed is equivalent to vanilla NeRF because weights are pre-generated at the start of rendering [S1].
*   **Memory Complexity:** Parameters depend primarily on the number of layers $L$ rather than the number of scenes $N$ [S1]. The compression rate is 16.4% for 8 scenes and 0.03% for 50 scenes compared to vanilla NeRF [S1].
*   **Strengths:** Memory-efficient continual learning across multiple 3D scenes with vast domain gaps; no catastrophic forgetting; orthogonal to other NeRF extensions [S1].
*   **Limitations:** Requires pre-extraction of occupancy grids for previous scenes; hyperparameter tuning for $\alpha, \beta_1, \beta_2, \gamma$ is necessary; slower training than vanilla NeRF [S1].
*   **When to use:** When learning a sequence of distinct 3D scenes with limited memory and single-pass data access [S1].
*   **When not to use:** When only a single scene is needed, or when real-time training speed is critical and memory is not a constraint [S1].

## Background
SCARF was introduced by Y. Wang et al. in a preprint submitted in 2024 [S1]. It addresses the limitation of previous continual learning works (like MEIL-NeRF, CLNeRF) which focused on single scenes with multiple sequences, by focusing on different 3D scenes with vast domain gaps [S1]. It draws inspiration from HyperNetworks for parameter generation and Progressive Volume Distillation for distillation, but improves upon Progressive Volume Distillation by being single-stage and using occupancy grids to avoid blank regions [S1].
