# Dynamic Semantic Human NeRF

Also called: H-NeRF (dynamic)

## Overview
Dynamic Semantic Human NeRF (H-NeRF) models dynamic human motion and appearance in a scene by learning a continuous function that maps spatial positions to canonical geometric and appearance descriptors, conditioned on semantic latent codes [S1, unofficial]. It solves the problem of rendering humans in arbitrary poses and shapes from sparse or dynamic video inputs by warping observations into a canonical reference frame using a pre-trained human model, allowing a single NeRF to represent the human across time [S1, unofficial]. It differs from static NeRFs by incorporating semantic latent codes for shape and pose, and from other dynamic human NeRFs by using imGHUM to provide explicit spatial-temporal correspondences and residual Signed Distance Fields (SDFs) for fine-grained deformation [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D spatial point $\mathbf{x}$, viewing direction $\mathbf{v}$, shape latent code $\beta$, pose latent code $\theta$, root transformation $T$.
*   **Outputs:** Volume density $\sigma$, view-dependent color $\mathbf{c}$, residual SDF $\Delta d$.

**Data Structures:**
*   **imGHUM:** A pre-trained implicit human model that takes $(\beta, \theta, T)$ and outputs a 4D point descriptor $(s, d)$, where $s$ is semantic information and $d$ is signed distance [S1, unofficial].
*   **NeRF Function $F_\omega$:** An MLP conditioned on $(s, d, \theta, T)$ outputting $(\sigma, \mathbf{c})$ [S1, unofficial].
*   **Residual SDF Function $\Delta H_\omega$:** An MLP conditioned on $(s, d, \theta)$ outputting $\Delta d$ [S1, unofficial].
*   **Bounding Box $\mathcal{B}$:** Defines the region where human motion warping is applied; background is assumed invariant [S1, unofficial].

**Steps:**
1.  **Canonical Warping:** For a spatial point $\mathbf{x}$ inside bounding box $\mathcal{B}$, compute the canonical descriptor $(s, d)$ using the fixed imGHUM model conditioned on $(\beta, \theta, T)$:
    $$ (s, d) = H_\omega(T^{-1}\mathbf{x}, \beta, \theta) $$
    Points outside $\mathcal{B}$ are treated as static background and do not undergo warping [S1, unofficial].
2.  **NeRF Conditioning:** Input the canonical descriptor $(s, d)$, pose code $\theta$, and root transformation $T$ into the NeRF function $F_\omega$ to predict density $\sigma$ and color $\mathbf{c}$:
    $$ (\sigma, \mathbf{c}) = F_\omega(s, d, \theta, T) $$
    Note that $\mathbf{c}$ is conditioned on $T$ to account for illumination changes due to relative position/rotation, while $\sigma$ is primarily conditioned on $\theta$ for geometric deformation [S1, unofficial].
3.  **Residual SDF Prediction:** Input $(s, d, \theta)$ into the residual SDF function $\Delta H_\omega$ to predict the residual distance $\Delta d$:
    $$ \Delta d = \Delta H_\omega(s, d, \theta) $$
    This residual models personalized geometric details on top of the imGHUM skin surface [S1, unofficial].
4.  **Regularization:** Apply a regularization term $L_{reg}$ to constrain $\Delta d$ to be non-positive, ensuring imGHUM remains within the predicted geometry:
    $$ L_{reg} = \max(0, \Delta d) $$
    [S1, unofficial].
5.  **Inference with Novel Poses/Shapes:** To render a novel pose or shape, assign new $(\beta, \theta)$ values. Add Gaussian noise to the input codes $(\theta, T)$ to prevent overfitting to training-specific deformations and appearance effects [S1, unofficial]. If views are sparse, add noise to the viewing direction $\mathbf{v}$ as well [S1, unofficial].

**Pseudocode:**
```python
def dynamic_semantic_human_nerf(x, v, beta, theta, T, bounding_box):
    """
    x: 3D spatial point
    v: viewing direction
    beta: shape latent code
    theta: pose latent code
    T: root transformation
    bounding_box: region where warping is applied
    """
    # Step 1: Canonical Warping
    if is_inside_bounding_box(x, bounding_box):
        # Apply inverse root transformation
        x_canonical = transform_inverse(T, x)
        # Get canonical descriptor from fixed imGHUM
        s, d = imghum_forward(x_canonical, beta, theta)
    else:
        # Background: no warping, assume static
        # Placeholder for background handling logic
        s, d = get_background_descriptor(x)

    # Step 2: NeRF Conditioning
    # Condition density on pose, color on pose and root transformation
    sigma, color = nerf_forward(s, d, theta, T)

    # Step 3: Residual SDF Prediction
    delta_d = residual_sdf_forward(s, d, theta)

    # Step 4: Regularization (applied during training)
    # L_reg = max(0, delta_d)

    return sigma, color, delta_d

def inference_with_noise(x, v, beta, theta, T, noise_std=0.01):
    """
    Add Gaussian noise to latent codes for generalization
    """
    theta_noisy = theta + GaussianNoise(noise_std)
    T_noisy = T + GaussianNoise(noise_std)
    v_noisy = v + GaussianNoise(noise_std) # For sparse views
    return dynamic_semantic_human_nerf(x, v_noisy, beta, theta_noisy, T_noisy)
```

**Parameters:**
*   **Noise Standard Deviation:** Not given in the sources. [G] Typical values for Gaussian noise in latent spaces range from 0.01 to 0.1.
*   **Bounding Box $\mathcal{B}$:** Not given in the sources. [G] Should tightly enclose the human subject.

**Edge Cases and Pitfalls:**
*   **imGHUM Fitting Errors:** imGHUM fitting can introduce errors in dynamic sequences. Fine-tuning imGHUM pose and shape parameters is suggested but not detailed in the core method [S1, unofficial].
*   **Background Handling:** Background is assumed invariant. If the background moves, the method fails as warping is only applied inside $\mathcal{B}$ [S1, unofficial].
*   **Overfitting:** Without noise, the network may overfit to specific pose-dependent deformations and appearance effects [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources. [G] Depends on the depth of the MLPs and the cost of imGHUM evaluation.
*   **Memory Complexity:** Not given in the sources. [G] Depends on the size of the MLPs and the number of parameters in imGHUM.
*   **Strengths:** Generalizes to novel poses and shapes; leverages semantic latent codes for interpolation; reduces computation by warping only the human region [S1, unofficial].
*   **Limitations:** Relies on the accuracy of imGHUM; background must be static; requires pre-trained imGHUM [S1, unofficial].
*   **When to Use:** Dynamic human rendering with sparse views or novel poses/shapes [S1, unofficial].
*   **When Not to Use:** Scenes with significant background motion or non-human subjects [S1, unofficial].

## Background
Dynamic Semantic Human NeRF (H-NeRF) was introduced in "H-NeRF: Neural Radiance Fields for Rendering and Temporal Reconstruction of Humans in Motion" [S1, unofficial]. It builds on prior work in dynamic NeRFs [36, 38] and integrates the imGHUM model for semantic human representation [S1, unofficial].
