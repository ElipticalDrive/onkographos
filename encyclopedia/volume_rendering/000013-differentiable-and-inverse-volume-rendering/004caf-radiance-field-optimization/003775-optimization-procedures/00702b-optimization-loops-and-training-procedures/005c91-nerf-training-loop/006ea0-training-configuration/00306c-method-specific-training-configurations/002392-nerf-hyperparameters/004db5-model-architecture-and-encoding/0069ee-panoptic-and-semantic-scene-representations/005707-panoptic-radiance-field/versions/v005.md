# Panoptic Radiance Field

Also called: Panoptic Lifting

## Overview
Panoptic Lifting learns a panoptic 3D volumetric representation from posed RGB images and machine-generated 2D panoptic segmentation masks, lifting noisy 2D labels into a consistent 3D representation comprising color, density, semantics, and instances [S1]. It differs from siblings like [Panoptic NeRF](11916-panoptic-nerf.md) and [DM-NeRF](11916-dm-nerf.md) by requiring only machine-generated 2D masks rather than manual ground truth or coarse meshes, and by explicitly solving a linear assignment problem to map inconsistent 2D instance IDs to 3D surrogate identifiers [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** Posed RGB images $\{I\}$ and corresponding machine-generated 2D panoptic segmentation masks. Each training ray $r$ has an associated RGB color $\hat{c}_r \in \mathbb{R}^3$, semantic class $\hat{k}_r \in K$, and 2D instance ID $\hat{h}_r \in H_I$ (defined only for thing classes $\hat{k}_r \in K_T$) [S1].
*   **Outputs:** A panoptic radiance field $\Phi(\mathbf{x}, \mathbf{d})$ that renders RGB color $c$, density $\sigma$, semantic class distribution $\kappa$, and instance distribution $\pi$ along any ray [S1].

**Data Structures**
The field $\Phi(\mathbf{x}, \mathbf{x})$ assigns to each 3D point $\mathbf{x} \in \mathbb{R}^3$ and viewing direction $\mathbf{d} \in S^2$:
1.  **Density:** $\sigma \in \mathbb{R}_{\ge 0}$ and **Color:** $c \in \mathbb{R}^3$, modeled using a TensoRF representation [S1].
2.  **Semantic Field:** A small MLP outputting a distribution $\kappa$ over $K$ semantic classes [S1].
3.  **Instance Field:** A separate small MLP outputting a distribution $\pi$ over $J$ fixed, class-agnostic, 3D-consistent surrogate identifiers [S1].

The set of all possible 3D instances is $H_{3D} := K_T \times J$ [S1].

**Rendering Equation**
For a vector field $f$ along ray $r$ with density $\sigma$:
$$ R[f |r, \sigma] := \int_0^\infty \alpha_t (r)\sigma(r_t)f (r_t, d_{r_t})dt $$
where $\alpha_t (r) := \exp \left(-\int_0^t \sigma(r_s)ds\right)$ is the transmittance [S1].

**Training Procedure**
1.  **Test-Time Augmentation (TTA):** Apply augmentations (horizontal flip, scale, brightness, contrast) to input images, fuse resulting segmentations via segment clustering, and compute a semantic class distribution $\hat{\kappa}_r$ and confidence $w_r$ for each pixel [S1].
2.  **Linear Assignment:** Solve a linear assignment problem to map noisy 2D instance IDs $\hat{h}_r$ to 3D surrogate identifiers $j \in J$. The cost is based on the model’s current predictions and the 2D masks, ensuring consistent lifting of 2D instances to 3D [S1].
3.  **Loss Computation:** Compute the total loss $L_{tot}$ for a batch of rays $R = R_S \cup R_I$ (where $R_S$ are rays sampled across the scene and $R_I$ are rays from a single image):
    $$ L_{tot}(R) := \lambda_{ins} L_{ins}(R_I) + \lambda_{con} L_{con}(R_I) + \lambda_{RGB} L_{RGB}(R_S) + \lambda_{sem} L_{sem}(R_S) $$
    *   **Semantic Loss ($L_{sem}$):** Cross-entropy between rendered distribution $\kappa_r$ and 2D label distribution $\hat{\kappa}_r$, weighted by confidence $w_r$:
        $$ L_{sem}(R) := -\frac{1}{|R|} \sum_{r \in R} w_r \sum_{k \in K} \hat{\kappa}_r (k) \log \kappa_r (k) $$
        The semantic field outputs bounded probability distributions directly, not logits, to prevent semantic inconsistencies in low-density areas [S1].
    *   **Instance Loss ($L_{ins}$):** Log-loss of the rendered instance distribution $\pi_r$ relative to the mapped 2D instance assignments [S1].
    *   **Segment Consistency Loss ($L_{con}$):** Guides supervision to avoid optima that fragment objects in the presence of label inconsistencies [S1].
    *   **Photometric Loss ($L_{RGB}$):** L2 loss on rendered color [S1].
4.  **Gradient Blocking:** Stop gradients from the semantic and instance branches back to the density network to prevent noisy labels from corrupting geometry [S1].
5.  **Optimization:** Update parameters using Adam [S1].

    # Transmittance

**Parameters**
*   $K$: Set of semantic classes (e.g., 80 for COCO). Partitioned into thing classes $K_T$ and stuff classes $K_S$ [S1].
*   $J$: Fixed number of surrogate identifiers held by the instance field MLP [S1].
*   $\lambda_{con} = 1.35, \lambda_{ins} = 1, \lambda_{sem} = 1, \lambda_{RGB} = 1$ [S1].
*   Optimizer: Adam. Learning rates: $5 \times 10^{-4}$ for MLPs, $1 \times 10^{-2}$ for TensoRF lines and planes [S1].
*   Training: 450k iterations (~10 hours) on 1 NVIDIA A6000 [S1].

**Edge Cases and Pitfalls**
*   **Logits vs. Probabilities:** Rendering class logits instead of probabilities can introduce semantic inconsistencies across viewpoints because unbounded logits can generate significant signals in low-density areas, violating geometric constraints. The method resolves this by rendering bounded probability distributions [S1].
*   **Geometry Corruption:** Supervision from noisy 2D labels can influence geometry, causing "cloudy" geometry to satisfy conflicting labels. This is avoided by stopping gradients from segmentation branches back to densities [S1].
*   **Class Limitations:** The method is limited to classes supported by the pre-trained 2D panoptic segmentation model (e.g., Mask2Former) [S1].

## Operating characteristics
*   **Time and Memory:** Training takes ~10 hours on a single NVIDIA A6000 for 450k iterations [S1]. Memory usage is dominated by the TensoRF representation and the two MLPs.
*   **Performance:** Improves scene-level Panoptic Quality (PQ) by 8.4% on Hypersim, 13.8% on Replica, and 10.6% on ScanNet over state-of-the-art methods [S1]. Maintains comparable PSNR for novel view synthesis [S1].
*   **Strengths:** Robust to inherent noise in machine-generated labels; enables in-the-wild scene processing without manual ground truth; supports scene editing (deletion, duplication, manipulation) [S1].
*   **Limitations:** Offline process due to lengthy pre-processing (pose estimation, 2D segmentation, optimization); limited to classes in the pre-trained 2D model [S1].

## Background
Panoptic Lifting was introduced in "Panoptic Lifting for 3D Scene Understanding with Neural Fields" (CVPR 2023) [S1]. It addresses the limitation of previous panoptic NeRF methods (like Panoptic NeRF and DM-NeRF) which required manual ground truth or coarse meshes, by lifting machine-generated 2D panoptic segmentation masks into a 3D neural field [S1].
