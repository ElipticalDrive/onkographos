# NeRF with Time Parameter

Also called: NeRF + time, NeRF with Time Parameter Baseline, Time-NeRF

## Overview
This method adapts the static Neural Radiance Field (NeRF) architecture for dynamic scenes by introducing a temporal dimension to the input space [S1]. It solves the problem of "ghosting" and blurry predictions that occur when a static implicit representation attempts to model multi-frame video data [S1]. Unlike sibling methods that explicitly model geometry or motion fields, this approach treats time as an additional coordinate, allowing the network to learn scene appearance variations directly through the radiance field [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A 3D spatial coordinate $\mathbf{x} \in \mathbb{R}^3$, a viewing direction $\mathbf{d} \in \mathbb{R}^3$, and a scalar time parameter $t \in \mathbb{R}$ [S1].
*   **Outputs:** Volume density $\sigma$ and view-dependent color $\mathbf{c}$ [S1].

**Data Structures:**
The model uses the standard Multi-Layer Perceptron (MLP) structure defined in the parent article [Parent](15546-dynamic-scene-and-temporal-modeling.md). The key modification is in the input encoding layer.

**Steps:**
1.  **Positional Encoding of Time:** Apply the same positional encoding function $\gamma_t$ used for spatial coordinates to the time parameter $t$.
    $$ \gamma_t(t) = [\sin(2^0 \pi t), \cos(2^0 \pi t), \dots, \sin(2^{L-1} \pi t), \cos(2^{L-1} \pi t)] $$
    where $L$ is the number of frequency bands [S1].
2.  **Concatenation:** Concatenate the encoded time vector $\gamma_t(t)$ with the encoded spatial position $\gamma_x(\mathbf{x})$.
    $$ \mathbf{z}_{input} = [\gamma_x(\mathbf{x}), \gamma_t(t)] $$
3.  **Network Forward Pass:** Feed $\mathbf{z}_{input}$ and the encoded viewing direction $\gamma_d(\mathbf{d})$ into the NeRF MLPs to predict density and color [S1].
4.  **Training:** Optimize the network weights using the standard NeRF loss function (MSE between rendered and ground truth pixel colors) on the dynamic scene dataset [S1].

**Parameters:**
*   **Training Configuration:** The method uses the same hyperparameters and training configuration reported for NeRF's real forward-facing experiments [S1]. Specific values (learning rate, number of samples, network depth/width) are not detailed in the source text beyond referencing the standard NeRF setup [S1].

**Edge Cases and Pitfalls:**
*   **Lack of Detail:** The method suffers from blurry predictions and lacks fine detail compared to more complex dynamic scene representations [S1].
*   **No Dynamics Reasoning:** The model fails to explicitly reason about scene dynamics (e.g., object motion trajectories), relying solely on appearance interpolation [S1].
*   **Ghosting:** While improved over vanilla NeRF, it may still exhibit artifacts if the temporal sampling is insufficient or if the scene changes are too rapid for the network's capacity [S1].

## Subtopics

### Temporal Compression of NeRF Models
A compression strategy for sequences of NeRF models that exploits temporal redundancy by treating the first model as a key-frame and compressing only the deltas between successive models [S2].

*   **Definition:** The system design stems from the insight that neighboring NeRF models share considerable similarities [S2].
*   **Steps:**
    1.  Initialize the NeRF for the first frame from scratch (trained from the beginning) [S2].
    2.  For subsequent frames, initialize the new NeRF based on the previous frame's trained NeRF to encourage temporal redundancy and save training time [S2].
    3.  Calculate the delta between the current frame's NeRF weights and the previous frame's NeRF weights [S2].
    4.  Apply exponent-based quantization and Huffman coding to the deltas [S2].
    5.  To restore a model, accumulate the decoded deltas to the reference model (the previous frame's model) [S2].
*   **When to choose:** Use this variant when storage or transmission bandwidth is constrained, and the scene exhibits high temporal coherence [S2].

## Operating characteristics
*   **Time Complexity:** Training time is comparable to standard NeRF, though slightly higher due to the increased input dimensionality [S1]. The compression variant reduces training time for subsequent frames by leveraging previous weights [S2].
*   **Memory Complexity:** Memory usage is similar to standard NeRF for a single time step. The compression variant significantly reduces storage requirements for sequences by storing only deltas [S2].
*   **Performance:** On KITTI dynamic scenes, "NeRF + time" achieves a PSNR of 24.18, SSIM of 0.677, and LPIPS of 0.425, outperforming vanilla NeRF (PSNR 23.34, SSIM 0.662, LPIPS 0.415) but underperforming more advanced methods like Neural Scene Graphs (PSNR 26.66, SSIM 0.806, LPIPS 0.186) [S1].
*   **Strengths:** Simple to implement; requires no changes to the core NeRF architecture other than input encoding [S1].
*   **Limitations:** Produces blurry results; cannot model complex dynamics or occlusions effectively; suffers from ghosting artifacts [S1].
*   **When to use:** As a baseline for dynamic scene reconstruction; when computational resources are limited and high fidelity is not required [S1].
*   **When not:** When fine detail, sharp occlusions, or explicit motion modeling is required [S1].

## Background
The method was introduced in the paper "Neural Scene Graphs for Dynamic Scenes" by Wang et al. (CVPR 2021) [S1]. It was proposed as a simple modification to the state-of-the-art static NeRF method to handle dynamic scenes, serving as a baseline to demonstrate the limitations of implicit representations without explicit dynamic modeling [S1]. The temporal compression variant was later described in "Volumetric Video Compression Through Neural-based Representation" (2024) [S2].
