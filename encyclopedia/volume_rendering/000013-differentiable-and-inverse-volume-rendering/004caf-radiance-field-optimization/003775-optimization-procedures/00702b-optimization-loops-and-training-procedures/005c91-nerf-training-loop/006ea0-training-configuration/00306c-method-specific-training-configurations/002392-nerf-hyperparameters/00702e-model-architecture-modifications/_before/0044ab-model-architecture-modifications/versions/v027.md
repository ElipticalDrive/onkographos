# Model Architecture Modifications

Also called: NeRF Architecture Variants, Neural Radiance Field Modifications

## Overview
Model Architecture Modifications extend the standard Neural Radiance Field (NeRF) framework by altering the input domain, output heads, or internal representation structures to address specific limitations such as sparse views, dynamic scenes, lighting variations, or computational efficiency. Unlike standard NeRF, which maps 3D coordinates and view directions to density and color via a static MLP, these modifications introduce conditional inputs (e.g., latent codes, time, fluid volume), substitute the implicit function with discrete structures (voxels, points, SDFs), or add auxiliary outputs (uncertainty, semantic labels) to enable specialized rendering tasks [S1, 14428-sparse-view-and-few-shot-optimization.md].

## Shared principles
The standard NeRF architecture [Parent](3065-nerf-hyperparameters.md) serves as the baseline for most modifications. It consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ [14428-sparse-view-and-few-shot-optimization.md].

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories [14428-sparse-view-and-few-shot-optimization.md]:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation [14428-sparse-view-and-few-shot-optimization.md].
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
    [14428-sparse-view-and-few-shot-optimization.md].
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs) [14428-sparse-view-and-few-shot-optimization.md].

## Subtopics

### [DoF-NeRF](9432-dof-nerf.md)
DoF-NeRF extends the standard NeRF architecture to simulate depth-of-field effects by explicitly modeling the aperture and focus distance [9432-dof-nerf.md]. It introduces two learnable scalar parameters per training view: the aperture parameter $K$ and the focus distance $F$, which are jointly optimized with the NeRF network parameters [9432-dof-nerf.md]. The method computes observed colors based on the Circle of Confusion (CoC) diameter, allowing the synthesis of all-in-focus views from shallow DoF inputs [9432-dof-nerf.md].

### [NeRF-VPT](11770-nerf-vpt.md)
NeRF-VPT is a cascading view prompt tuning paradigm that progressively enhances image quality by using RGB information from preceding rendering iterations as visual prompts for subsequent stages [11770-nerf-vpt.md]. It integrates the RGB prompt $\mathbf{c}(r)_{i-1}$ from the previous stage by concatenating it after the direction encoding, leveraging prior knowledge sampled from the RGB space to guide optimization without external networks [11770-nerf-vpt.md].

### [Activation Feature Density Approximation](12492-activation-feature-density-approximation.md)
This method estimates volumetric density $\hat{d}$ directly from intermediate activation features $\mathbf{f}_\ell$ of a coordinate-based MLP, replacing expensive coarse network evaluations with lightweight computation [12492-activation-feature-density-approximation.md]. It computes the mean activation feature vector $\mathbf{f}_\ell$ by averaging over hidden units, then applies handcrafted statistical functions to estimate density, retaining the standard density-based rendering formulation [12492-activation-feature-density-approximation.md].

### [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md)
SDF representations replace the standard NeRF density field $\sigma(\mathbf{x})$ with a continuous scalar field $s(\mathbf{x})$ representing the distance to the nearest surface, defining geometry via the zero-level set $\{\mathbf{x} \mid s(\mathbf{x}) = 0\}$ [12495-signed-distance-function-sdf-representations.md]. The surface normal $\mathbf{n}$ is derived from the SDF gradient $\mathbf{n} = \frac{\nabla s(\mathbf{x})}{\|\nabla s(\mathbf{x})\|}$, enabling more explicit and smooth surface formulations compared to soft volumetric boundaries [12495-signed-distance-function-sdf-representations.md].

### [Volume-Augmented NeRF](12973-volume-augmented-nerf.md)
Volume-Augmented NeRF is designed for dynamic fluid scenes by binding an explicit fluid volume value $v_i$ to each sample point [12973-volume-augmented-nerf.md]. The density MLP takes the positional encoding $\gamma(\mathbf{x}_i)$ and the interpolated fluid volume $v_i$ as input, allowing the renderer to learn density and color based on the spatial distribution provided by a differentiable fluid simulator [12973-volume-augmented-nerf.md].

### [Neural-PIL Decomposition Architecture](12975-neural-pil-decomposition-architecture.md)
This architecture separates scene geometry, material properties, and illumination into distinct networks to handle varying lighting conditions [12975-neural-pil-decomposition-architecture.md]. It predicts density, a BRDF embedding, and an illumination embedding, using a learned pre-integrated lighting network to efficiently render shaded colors, differing from standard NeRF which predicts view-dependent color directly [12975-neural-pil-decomposition-architecture.md].

### MINE
MINE models the frustum of the source camera using a continuous depth Multiplane Image (MPI) representation, conditioned on input images via a fully-convolutional decoder [13661-mine.md]. Unlike pixelNeRF and GRF, MINE reconstructs the frustum per plane, allowing rendering of any target view via homography warping after a single encoder pass and a fixed number of decoder passes, independent of the number of target views [13661-mine.md].

### [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md)
This family replaces the continuous MLP function with discrete, spatially structured data structures (dense voxels, sparse grids, hash tables, or triplanes) to store volume density and appearance features [13738-voxel-and-sparse-grid-representations.md]. Values are retrieved via trilinear interpolation, hashing, or bilinear interpolation from projected planes, enabling memory-efficient training and real-time differentiable volume rendering [13738-voxel-and-sparse-grid-representations.md].

### [Aleth-NeRF](13764-aleth-nerf.md)
Aleth-NeRF trains on under- and over-exposed images to render normal-light novel views by introducing a 'Concealing Field' assumption [13764-aleth-nerf.md]. It models illumination adaptive volume rendering through local and global concealing fields to suppress light transport, operating on standard 8-bit LDR images without paired training data or pre-processing enhancement networks [13764-aleth-nerf.md].

### [Transformer and Vision Model Integration](13911-transformer-and-vision-model-integration.md)
This family integrates Vision Transformers (ViT) and general Transformer architectures into NeRFs to leverage global semantic understanding and long-range dependencies [13911-transformer-and-vision-model-integration.md]. Input images are processed by a ViT encoder to extract global features, which are fused with local CNN features and conditioned into the NeRF MLP to predict density and color, solving limitations of standard MLPs in single-image inputs or occlusions [13911-transformer-and-vision-model-integration.md].

### [Human and Specific Subject Modeling](13997-human-and-specific-subject-modeling.md)
These methods adapt the standard NeRF architecture to model dynamic human subjects by integrating parametric human priors (such as SMPL) or structured latent codes anchored to deformable meshes [13997-human-and-specific-subject-modeling.md]. They handle non-rigid deformation by transforming query points from the target space to a canonical space using inverse deformation fields, decoupling geometry from pose [13997-human-and-specific-subject-modeling.md].

### OPONeRF
OPONeRF personalizes the parameters of the plenoptic mapping function for each sampled 3D point to handle test-time scene changes [14014-oponerf.md]. It dynamically conditions the network weights $\Theta$ on the point's representation $\mathbf{x}$ and the overall scene representation $\mathbf{F}$, subdividing the scene to discriminatively respond to local variations, providing more expressiveness than methods with fixed parameters [14014-oponerf.md].

### [Mixer-NeRF](14073-mixer-nerf.md)
Mixer-NeRF addresses the loss of local information in standard NeRFs by introducing a hybrid spatial feature learning module (MLCA) and a squeeze-and-excitation (SE) network module [14073-mixer-nerf.md]. It explicitly mixes spatial and channel features via fully connected layers before the main MLP inference, rather than relying solely on positional encoding and MLP weights to capture high-frequency details [14073-mixer-nerf.md].

### [Sparse View and Few-Shot Optimization](14428-sparse-view-and-few-shot-optimization.md)
This family addresses severe overfitting and artifact generation when training NeRF with drastically reduced input viewpoints ($|S| < 20$) [14428-sparse-view-and-few-shot-optimization.md]. Techniques mitigate ambiguity through in-situ regularization, deformable sampling strategies, or pseudo-observation densification, setting them apart from generalized sparse NeRFs that require large-scale pre-training [14428-sparse-view-and-few-shot-optimization.md].

### [Mixture-of-Experts and Modular Architectures](14429-mixture-of-experts-and-modular-architectures.md)
This family replaces or augments the single continuous function of standard NeRF with multiple specialized networks (experts) or parallel processing streams [14429-mixture-of-experts-and-modular-architectures.md]. It explicitly partitions the input domain or ray batch among distinct neural modules to improve compression, training speed, or representation capacity, solving limitations of conventional Implicit Neural Representations (INRs) [14429-mixture-of-experts-and-modular-architectures.md].

### [Uncertainty and Reliability](14487-uncertainty-and-reliability.md)
Uncertainty and Reliability methods extend standard NeRF architectures to quantify prediction confidence by outputting auxiliary uncertainty metrics alongside density and color [14487-uncertainty-and-reliability.md]. These metrics are typically rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color, allowing uncertainty to be propagated through the volume rendering integral to guide optimization or post-processing [14487-uncertainty-and-reliability.md].

### [Object Decomposition and Composition](14518-object-decomposition-and-composition.md)
These methods extend standard NeRF architectures to separate a scene into distinct object instances and a background, enabling individual object manipulation and amodal segmentation [14518-object-decomposition-and-composition.md]. They integrate decomposition into the differentiable rendering pipeline, often using one-hot activation mechanisms or frequency-based partitioning to disentangle objects while maintaining global consistency [14518-object-decomposition-and-composition.md].

### [Lighting and Appearance Models](14522-lighting-and-appearance-models.md)
Lighting and Appearance Models modify the standard NeRF architecture to explicitly represent illumination and material properties, enabling relighting [14522-lighting-and-appearance-models.md]. Unlike standard NeRF, which learns view-dependent color implicitly, these models separate albedo from illumination, differing from siblings like NeRF-W by explicitly modeling illumination rather than relying on appearance embeddings [14522-lighting-and-appearance-models.md].

### [Optimization and Training Procedures](14565-optimization-and-training-procedures.md)
This family covers algorithmic procedures for optimizing NeRFs, ranging from standard training loops to specialized acceleration and editing techniques [14565-optimization-and-training-procedures.md]. Methods often employ structural modifications to the optimization scope, such as skipping expensive fine-pass evaluations for empty rays or restricting updates to specific network layers to preserve pre-trained geometric features [14565-optimization-and-training-procedures.md].

### [Image Enhancement and Restoration Methods](14566-image-enhancement-and-restoration-methods.md)
These methods address input imagery degradation (blur, occlusions, low resolution) by integrating restoration mechanisms directly into the NeRF optimization loop [14566-image-enhancement-and-restoration-methods.md]. They either model the degradation process (e.g., blur kernels) or separate static scene geometry from transient artifacts, using 2D priors (inpainting, super-resolution) to guide 3D consistency [14566-image-enhancement-and-restoration-methods.md].

### [Modular, Hierarchical, and Latent Architectures](14567-modular-hierarchical-and-latent-architectures.md)
This family extends standard NeRF architectures to handle non-rigid deformation with topological changes and hierarchical scene structures [14567-modular-hierarchical-and-latent-architectures.md]. HyperNeRF models non-rigidly deforming scenes by lifting the canonical 3D space into a higher-dimensional ambient space, while Strata-NeRF models stratified scenes by replacing continuous positional encoding inputs with discrete latent codes [14567-modular-hierarchical-and-latent-architectures.md].

### [MuRF (Multi-Baseline Radiance Fields)](15007-murf-multi-baseline-radiance-fields.md)
MuRF is a feed-forward method for sparse view synthesis that constructs a **target view frustum volume** aligned with the target camera rather than a reference input view [15007-murf-multi-baseline-radiance-fields.md]. It uses a **3D context-aware convolutional decoder** to aggregate multi-view information, effectively handling small overlap between input and target views common in large baseline scenarios [15007-murf-multi-baseline-radiance-fields.md].

### [Gaussian and Primitive-Based Representations](15011-gaussian-and-primitive-based-representations.md)
This family replaces the continuous MLP radiance field with discrete geometric primitives or explicit Gaussian distributions to improve rendering efficiency and geometric fidelity [15011-gaussian-and-primitive-based-representations.md]. It uses analytic primitives (quadrics or Gaussians) rather than voxel grids, and relies on alpha-blended primitives rather than implicit surface marching [15011-gaussian-and-primitive-based-representations.md].

### [Decentralized Federated NeRF](15032-decentralized-federated-nerf.md)
Decentralized Federated NeRF (DecentNeRF) learns global 3D scene representations from crowd-sourced images by distributing training computation to users and aggregating only global radiance field models [15032-decentralized-federated-nerf.md]. It explicitly decomposes the scene into global and personal radiance fields per user and employs a learned weighted aggregation protocol with Secure Multi-Party Computation (SMPC) to prevent personal data leakage [15032-decentralized-federated-nerf.md].

### [Neural Proxy](15220-neural-proxy.md)
Neural Proxy represents photo-realistic targets as animatable proxies, combining neural volume rendering with neural texture by injecting an animatable mesh proxy into the scene [15220-neural-proxy.md]. It allows particles to move with the animated proxy geometry, enabling the synthesis of unseen animations without temporal learning, unlike NeRF which ties content to continuous Cartesian coordinates [15220-neural-proxy.md].

### ViSNeRF
ViSNeRF is a hybrid neural radiance field method for dynamic volumetric scenes with arbitrary adjustable parameters [15255-visnerf.md]. It factorizes the static 3D spatial volume into vector-matrix components and the $K$-D parameter space into CP components, reducing memory complexity from $O(N^3 M^K)$ to $O(N^2 M)$, and uses separate small MLPs for density and color decoding [15255-visnerf.md].

### [EBAD-NeRF](15441-ebad-nerf.md)
EBAD-NeRF reconstructs sharp 3D radiance fields from motion-blurred images by jointly optimizing learnable camera poses and NeRF parameters using hybrid event-RGB data [15441-ebad-nerf.md]. It models complex camera motion trajectories with multiple learnable poses rather than linear interpolation, and explicitly supervises motion blur via an intensity-change-metric event loss [15441-ebad-nerf.md].

### [Point-NeRF Representation](15538-point-nerf-representation.md)
Point-NeRF replaces the continuous MLP function with a discrete neural point cloud to model a continuous volumetric radiance field [15538-point-nerf-representation.md]. It avoids ray sampling in empty space by leveraging classical point clouds that approximate scene geometry, using neighborhood queries and feature aggregation to predict density and radiance [15538-point-nerf-representation.md].

### NeurMiPs
NeurMiPs represents a 3D scene as a mixture of $K$ learnable rectangular planar surfaces, where each surface acts as an independent "expert" predicting view-dependent color and transparency [15543-neurmips.md]. It alleviates the frontal-parallel limitation of traditional MPI while maintaining high efficiency through analytical ray-plane intersection and parallel CUDA execution [15543-neurmips.md].

### CodeNeRF
CodeNeRF is an implicit 3D neural representation that learns the variation of object shapes and textures across a semantic category, enabling synthesis of novel views of unseen objects from a single unposed input image [15544-codenerf.md]. It disentangles shape and texture by learning separate latent embeddings, allowing for one-shot reconstruction and explicit editing of object geometry and appearance [15544-codenerf.md].

### [Dynamic Scene and Temporal Modeling](15546-dynamic-scene-and-temporal-modeling.md)
These methods extend static NeRFs to reconstruct and render scenes that change over time by explicitly modeling the 4D space-time volume [15546-dynamic-scene-and-temporal-modeling.md]. The time parameter $t$ is positional encoded and concatenated with spatial encoding before being fed into the MLP, addressing challenges such as non-rigid deformation and occlusion changes [15546-dynamic-scene-and-temporal-modeling.md].

### [NeRF-Casting](15547-nerf-casting.md)
NeRF-Casting synthesizes photorealistic specular appearance and reflections by integrating ray tracing into the NeRF rendering pipeline [15547-nerf-casting.md]. It casts reflection rays from points along camera rays into the NeRF geometry to render feature vectors, which are then decoded into color using a small MLP, rather than querying a large MLP for outgoing radiance [15547-nerf-casting.md].

### RoseNeRF
RoseNeRF synthesizes high-fidelity novel views of real refractive objects by simplifying complex ray interactions to a single refraction event [15548-rosenerf.md]. It models refraction by predicting a single refracted ray using a 4D light field representation and a refraction network, avoiding the need for Index of Refraction (IoR) fields or detailed surface reconstructions [15548-rosenerf.md].

### [Semantic and Feature Field Extensions](15556-semantic-and-feature-field-extensions.md)
This family generalizes NeRF to predict arbitrary per-point feature signals $\mathbf{f}$ in addition to color $\mathbf{c}$ and density $\sigma$ [15556-semantic-and-feature-field-extensions.md]. It enables the lifting of 2D observations (semantic labels, object codes, foundation model embeddings) into a consistent 3D representation, integrating these signals directly into the volume rendering pipeline [15556-semantic-and-feature-field-extensions.md].

### [Neural Density-Distance Fields](15665-neural-density-distance-fields.md)
Neural Density-Distance Fields (NeDDF) reciprocally constrains distance and density fields, extending the distance field formulation to adapt to any density field [15665-neural-density-distance-fields.md]. It predicts a distance field $D$ and computes density $\sigma$ via its gradient, enabling more stable mesh extraction and camera pose localization through reprojection error [15665-neural-density-distance-fields.md].

### LAENeRF
LAENeRF is a unified framework for photorealistic and non-photorealistic local appearance editing of pre-trained NeRFs [15738-laenerf.md]. It learns a palette-based color decomposition within a user-selected region, estimating per-ray termination points to define the editable region and introducing geometry-aware losses to preserve small structures during stylization [15738-laenerf.md].

### ExtremeNeRF
ExtremeNeRF is a few-shot view synthesis framework designed to generate novel views from sparse multi-view images captured under unconstrained, varying illumination [15739-extremenerf.md]. It enforces multi-view albedo consistency through a two-stage intrinsic decomposition pipeline using an offline full-image network (FIDNet) and an online patch-wise network (PIDNet) [15739-extremenerf.md].

### [Frequency-Modulated Point Cloud Rendering](15903-frequency-modulated-point-cloud-rendering.md)
Frequency-Modulated Point Cloud Rendering (AFNet/FreqPCR) replaces the standard continuous MLP radiance field with a point cloud representation modulated by an Adaptive Frequency Net (AFNet) [15903-frequency-modulated-point-cloud-rendering.md]. It uses a hypernetwork to predict local texture frequencies and phases for each point, which are then used to modulate the radiance signal via adaptive activation layers, solving spectral bias towards low frequencies [15903-frequency-modulated-point-cloud-rendering.md].

### [Conditional and Latent Representations](15989-conditional-and-latent-representations.md)
This family extends standard NeRF architectures to model entire object classes or multiple 3D instances using a single neural network by conditioning the radiance field on per-instance latent codes $\mathbf{z}^{(s)}$ (shape) and $\mathbf{z}^{(c)}$ (appearance) [15989-conditional-and-latent-representations.md]. It enables efficient representation of varying geometry and texture, supporting instance-specific editing while sharing a common network backbone [15989-conditional-and-latent-representations.md].

### [ActiveNeRF Model Architecture](16203-activenerf-model-architecture.md)
ActiveNeRF modifies the standard NeRF architecture to output prediction variance alongside density and color, enabling uncertainty-aware view synthesis [16203-activenerf-model-architecture.md]. It introduces an auxiliary output head for variance estimation using a softplus activation function to guide active sampling strategies [16203-activenerf-model-architecture.md].

#### NeRF-VAE
NeRF-VAE is a generative NeRF model that generalizes to out-of-distribution scenes and removes the need to train on each scene from scratch [S1]. The NeRF renderer is conditioned on a latent code trained using Iterative Amortized Inference and a ResNet encoder, and an attention-based scene function is introduced instead of the typical MLP [S1]. It outperforms baseline NeRF with a low number of scene views (5-20) but is outperformed by baseline NeRF when a large number of views are available (100+) due to lower scene expressivity [S1].

#### PIE-NeRF
PIE-NeRF is a pipeline integrating physics-based elastodynamic simulation with a neural radiance field representation, using a meshless discretisation based on quadratic generalized moving least squares on top of the density field of a NeRF [S1]. It enables large deformations and nonlinear hyperelastic material simulation directly on the implicit representation and supports interactive manipulation of real-world captured scenes with complex geometries [S1].

#### DäRF Implementation Details
DäRF uses K-planes [36] as the NeRF Backbone and DPT-hybrid [38] as the MDE Model [S2, unofficial]. The Optimizer is Adam [21] [S2, unofficial]. The NeRF Learning Rate is 1e-2 and the MDE Learning Rate is 1e-5 [S2, unofficial]. The LR Schedule is Cosine warmup [S2, unofficial].

#### NeRF Model Architecture
The neural network architecture for NeRF consists of dense layers with ReLU activations, potentially using view directions as input [S3, unofficial]. The depth of the network (number of hidden layers) `D` defaults to 8 [S3, unofficial]. The number of input channels for view directions `input_ch_views` defaults to 3 [S3, unofficial]. The number of output channels `output_ch` defaults to 4 (RGB + density) [S3, unofficial]. The boolean flag `use_viewdirs` determines if view directions are used as input to the network [S3, unofficial].

#### S3-NeRF
S3-NeRF is a method using shadow and shading cues to infer scene geometry and enable single-image NeRF training [S1]. It employs a UNISURF-based occupancy field 3D representation instead of density, a modified physics-based rendering equation, and occupancy-based shadow calculation as key implementation differences [S1].

#### NeuralEditor
NeuralEditor employs a point cloud-guided NeRF model for shape manipulation, leveraging K-D trees and deterministic integration strategy for accurate point cloud-based rendering, with Phong reflection modeling to enhance color fidelity and geometric detail [S4]. It achieves accurate point cloud-based rendering and excels in both shape deformation and scene morphing tasks [S4].

#### Network Architectures
MLPs A and F use the MLP designed in NeRF, with hidden layer sizes increased from 256 to 384 [S5]. MLPs A and F are not used during inference, allowing more time on training [S5]. Small MLP H is the same as the small MLP used in SNeRG, with two hidden layers, each consisting 16 neurons [S5].

#### NeRF-Swin
NeRF-Swin is a baseline method that performs super-resolution on an LR NeRF using released SwinIR models under the 'Real-World Image Super-Resolution' setting, trained on more than 10k LR-HR pairs [S6]. On synthetic Blender dataset, SwinIR may produce false predictions due to domain mismatch [S6]. On real-world LLFF dataset, SwinIR tends to be oversmooth and may predict false color or geometry [S6]. Performance metrics: Blender ×2 (100x100): PSNR 26.34, SSIM 0.913, LPIPS 0.075; Blender ×4 (100x100): PSNR 24.85, SSIM 0.881, LPIPS 0.108; Blender ×2 (200x200): PSNR 28.03, SSIM 0.926, LPIPS 0.058; Blender ×4 (200x200): PSNR 26.78, SSIM 0.906, LPIPS 0.086; LLFF ×2: PSNR 25.18, SSIM 0.793, LPIPS 0.147; LLFF ×4: PSNR 23.26, SSIM 0.685, LPIPS 0.247 [S6].

## Background
The standard NeRF architecture was introduced by Mildenhall et al. [1], employing hierarchical rendering with coarse and fine networks to improve computational efficiency [S1]. Subsequent works have focused on accelerating training and inference, with efforts broadly falling into improvements of training and inference speed [S1]. The original implementation used two networks: a coarse network and a fine network, where the coarse network’s output guided sampling point selection for the fine network [S1].
