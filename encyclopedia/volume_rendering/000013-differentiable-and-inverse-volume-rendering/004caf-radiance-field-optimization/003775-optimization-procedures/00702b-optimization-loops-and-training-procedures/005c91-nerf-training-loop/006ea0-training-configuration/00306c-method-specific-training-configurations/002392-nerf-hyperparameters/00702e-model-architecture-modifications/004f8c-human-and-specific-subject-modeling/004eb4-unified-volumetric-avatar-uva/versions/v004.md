# Unified Volumetric Avatar (UVA)

## Overview
Unified Volumetric Avatar (UVA) is a neural representation that enables local and independent editing of both geometry and texture while retaining the ability to render novel views and poses [S1, unofficial]. It sets itself apart from methods using pre-defined UV mapping by anchoring structured latent codes to a deformable mesh in canonical space, allowing direct 3D-to-3D manipulation without the ambiguity of 3D-to-2D projection [S1, unofficial]. Unlike two-stage distilling methods that require manual tuning and are limited to static objects, UVA is end-to-end trainable and jointly optimized with the skinning field from scratch [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A target pose $\theta_t$, a camera ray $r$, and a deformable canonical mesh $M$ (initialized from a template, e.g., SMPL).
*   **Outputs:** The final pixel color $C(r)$ for the ray.

**Data Structures:**
1.  **Deformable Canonical Mesh $M$:** A mesh with $N$ nodes. Each node $i$ has a position $\mathbf{v}_i$ in canonical space and stores two latent codes:
    *   $\mathbf{l}_{geo}^i \in \mathbb{R}^{d_{geo}}$: Geometry latent code.
    *   $\mathbf{l}_{rgb}^i \in \mathbb{R}^{d_{rgb}}$: Appearance (texture) latent code.
2.  **MLPs:**
    *   $\phi_{def}$: Neural deformation field.
    *   $\phi_{geo}$: MLP predicting volume density $\sigma$.
    *   $\phi_{rgb}$: MLP predicting base color $\mathbf{c}_0$.
    *   $\phi_{shade}$: MLP predicting pose-dependent shading factor $s$.

**Numbered Steps:**

1.  **Compute LBS Weights ($\mathbf{w}_b$):**
    For a sampled point $\mathbf{x}_t$ in the target observation space, find its Top-$K$ nearest neighbors on the target mesh. Interpolate the Linear Blending Skinning (LBS) weights $\mathbf{w}_b$ from the weights of these neighbors [S1, unofficial].

2.  **Transform to Canonical Space ($\mathbf{x}_c$):**
    Invert the LBS transformation to estimate the canonical coordinate. This involves combining the LBS weights $\mathbf{w}_b$ with a neural non-rigid deformation field $\Delta \phi$ [S1, unofficial]. The transformation is defined as:
    $$ \mathbf{x}_c = \text{LBS}^{-1}(\mathbf{x}_t, \mathbf{w}_b) + \Delta \phi(\mathbf{x}_t, \theta_t) $$
    *Note: The exact inversion formula for LBS is not provided in the sources; it is assumed to be the standard inverse of the forward skinning operation [G].*

3.  **Interpolate Latent Codes:**
    For the canonical point $\mathbf{x}_c$, find its Top-$K$ nearest neighbors on the canonical mesh $M$. Interpolate the geometry and appearance latent codes $\mathbf{l}_{geo}$ and $\mathbf{l}_{rgb}$ from the anchored codes $\mathbf{l}_{geo}^i$ and $\mathbf{l}_{rgb}^i$ of these neighbors using nearest-neighbor interpolation [S1, unofficial].

4.  **Compute Signed Height Indicator ($\tilde{h}$):**
    Calculate a local signed height indicator $\tilde{h}$ to resolve spatial ambiguity in code interpolation. This indicator comprises:
    *   $(u, v)$: UV coordinates of the point on the canonical mesh.
    *   $\bar{d}$: Point-to-surface distance relative to the anchored mesh [S1, unofficial].
    $$ \tilde{h} = [u, v, \bar{d}] $$

5.  **Predict Density and Base Color:**
    Use the interpolated latent codes and the signed height indicator to predict volume density $\sigma$ and base color $\mathbf{c}_0$:
    $$ \sigma = \phi_{geo}(\mathbf{l}_{geo}, \tilde{h}) $$
    $$ \mathbf{c}_0 = \phi_{rgb}(\mathbf{l}_{rgb}, \tilde{h}) $$

6.  **Modulate with Shading Factor:**
    Compute a pose-dependent shading factor $s$ conditioned on the target pose $\theta_t$:
    $$ s = \phi_{shade}(\theta_t) $$
    Modulate the base color to represent surface illumination in different poses:
    $$ \mathbf{c}_{mod} = \mathbf{c}_0 \otimes s $$
    where $\otimes$ denotes element-wise multiplication or appropriate modulation [S1, unofficial].

7.  **Volume Rendering:**
    Integrate the modulated colors along the target ray $r$ using standard differentiable volume rendering [S1, unofficial]:
    $$ C(r) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_{mod, i} $$
    where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ and $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ [S1, unofficial].

**Parameters:**
*   **Top-K:** The number of nearest neighbors used for interpolating LBS weights and latent codes. Typical values are not explicitly stated in the notes, but Table 1 in [S1, unofficial] suggests comparisons with $K=4, 8$ in related contexts. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Spatial Ambiguity:** Using discrete latent codes defined on mesh nodes diffused via nearest-neighbor interpolation leads to spatial query indistinguishability. This is addressed by the signed height indicator $\tilde{h}$ [S1, unofficial].
*   **Boundary Conditions:** The method relies on the mesh topology. Points far from the mesh may have ambiguous nearest neighbors or UV coordinates. Not given in the sources.

**Pseudocode:**

```python
import numpy as np

def uva_render(ray, target_pose, canonical_mesh, l_geo_nodes, l_rgb_nodes, 
               k_nn=4, mlp_geo, mlp_rgb, mlp_shade, mlp_def):
    """
    Renders a single ray using the UVA method.
    
    Args:
        ray: Ray origin and direction.
        target_pose: Pose parameters theta_t.
        canonical_mesh: Mesh object with nodes, faces, and UV map.
        l_geo_nodes: Array of geometry latent codes for mesh nodes.
        l_rgb_nodes: Array of appearance latent codes for mesh nodes.
        k_nn: Number of nearest neighbors.
        mlp_geo, mlp_rgb, mlp_shade, mlp_def: Neural network models.
        
    Returns:
        color: Final rendered color.
    """
    # 1. Sample points along the ray in target space
    # Assuming a standard volume rendering sampler
    points_t = sample_points_along_ray(ray)
    
    colors = []
    sigmas = []
    
    for x_t in points_t:
        # 2. Compute LBS weights in target space
        # Find K nearest neighbors on the target mesh (deformed by target_pose)
        target_mesh = deform_mesh(canonical_mesh, target_pose)
        nn_indices_t = find_k_nearest_neighbors(x_t, target_mesh.vertices, k_nn)
        w_b = interpolate_lbs_weights(nn_indices_t, target_mesh.lbs_weights)
        
        # 3. Transform to canonical space
        # Invert LBS to get approximate canonical position, then add neural deformation
        x_c_approx = invert_lbs(x_t, w_b, target_pose) # [G] Placeholder for LBS inversion
        delta_phi = mlp_def(x_t, target_pose)
        x_c = x_c_approx + delta_phi
        
        # 4. Interpolate latent codes in canonical space
        nn_indices_c = find_k_nearest_neighbors(x_c, canonical_mesh.vertices, k_nn)
        l_geo = interpolate_latent_codes(nn_indices_c, l_geo_nodes)
        l_rgb = interpolate_latent_codes(nn_indices_c, l_rgb_nodes)
        
        # 5. Compute signed height indicator
        # Project x_c to canonical mesh to get UV and distance
        uv, d_bar = project_to_mesh(x_c, canonical_mesh)
        h_tilde = np.concatenate([uv, [d_bar]])
        
        # 6. Predict density and base color
        sigma = mlp_geo(l_geo, h_tilde)
        c_0 = mlp_rgb(l_rgb, h_tilde)
        
        # 7. Modulate with shading factor
        s = mlp_shade(target_pose)
        c_mod = c_0 * s # Element-wise multiplication
        
        colors.append(c_mod)
        sigmas.append(sigma)
        
    # 8. Volume Rendering
    # Standard alpha compositing
    alpha = 1.0 - np.exp(-np.array(sigmas))
    T = np.cumprod(np.concatenate([[1.0], 1.0 - alpha[:-1]]))
    color = np.sum(T * alpha * np.array(colors), axis=0)
    
    return color
```

## Operating characteristics
*   **Time Complexity:** Depends on the number of samples per ray and the cost of nearest-neighbor searches. The use of Top-K interpolation adds overhead compared to dense grid lookups but allows for sparse representation. Not given in the sources.
*   **Memory Complexity:** Proportional to the number of mesh nodes $N$ times the latent dimension ($d_{geo} + d_{rgb}$). This is generally more memory-efficient than dense voxel grids for high-resolution details but requires storing the mesh structure. Not given in the sources.
*   **Strengths:** Enables local and independent editing of geometry and texture. End-to-end trainable. Handles dynamic avatars.
*   **Limitations:** Relies on the quality of the initial mesh and LBS weights. Spatial ambiguity in interpolation requires careful handling with the signed height indicator.
*   **When to use:** When local editing of human avatars is required alongside novel view/pose synthesis.
*   **When not to use:** For static objects where simpler methods suffice, or when high-frequency texture details are better captured by UV maps without deformation.

## Background
Unified Volumetric Avatar (UVA) was proposed in the paper "UVA: Towards Unified Volumetric Avatar for View Synthesis, Pose rendering, Geometry and Texture Editing" [S1, unofficial]. It addresses the limitations of previous neural field methods that either lacked editing capabilities or relied on two-stage distillation processes. The method builds on the principles of canonical space mapping and pose conditioning shared with siblings like HumanNeRF [13842-humannerf.md] and HumanNeRF-SE [15640-humannerf-se.md], but introduces structured latent codes anchored to a mesh to facilitate editing.
