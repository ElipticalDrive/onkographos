# Voxel-based Radiance Fields

Also called: Voxel NeRF, Voxel Radiance Fields

## Overview
Voxel-based Radiance Fields replace the multi-layer perceptron (MLP) of standard NeRF with explicit voxel grids to store volume density and spherical harmonic (SH) coefficients, enabling real-time volume rendering by eliminating heavy feed-forward neural computations [S1]. This method limits learnable parameters strictly to grid values, allowing for memory-efficient training via coarse-to-fine sparse voxel reconstruction and pruning [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D spatial position $\mathbf{X}_k$ and viewing direction $\mathbf{d}$ for a sample point $k$ on a ray [S1].
*   **Output:** Volume density $\sigma_k$ and view-dependent color $\mathbf{c}_k$ [S1].

**Data Structures:**
Two separate voxel grids are maintained [S1]:
1.  **Density Grid ($G_\sigma$):** Maps $\mathbb{R}^3 \rightarrow \mathbb{R}$ [S1]. Stores scalar volume density values [S1].
2.  **SH Coefficient Grid ($G_{sh}$):** Maps $\mathbb{R}^3 \rightarrow \mathbb{R}^{9 \times 3}$ [S1]. Stores degree-2 spherical harmonic coefficients for RGB color [S1]. Each spatial location stores a vector of 9 coefficients per color channel (total 27 values per voxel) [S1].

**Interpolation:**
For any query point $\mathbf{X}_k$, features are retrieved via trilinear interpolation from the nearest 8 neighboring voxels in both $G_\sigma$ and $G_{sh}$ [S1].

**Formulas:**
The volume density is computed as:
$$ \sigma_k = \mathcal{G}_\sigma(\mathbf{X}_k) $$
where $\mathcal{G}_\sigma$ denotes trilinear interpolation from $G_\sigma$ [S1].

The color is computed as:
$$ \mathbf{c}_k = S(\mathbf{d})^\intercal \cdot \mathcal{G}_{sh}(\mathbf{X}_k) $$
where:
*   $S(\mathbf{d}): \mathbb{R}^3 \rightarrow \mathbb{R}^9$ is the spherical harmonic function mapping the viewing direction $\mathbf{d}$ to a 9-dimensional basis vector [S1].
*   $\mathcal{G}_{sh}(\mathbf{X}_k)$ is the trilinearly interpolated vector of SH coefficients from $G_{sh}$ at $\mathbf{X}_k$ [S1].
*   The dot product combines the direction basis with the spatial features to produce the RGB color vector $\mathbf{c}_k$ [S1].

**Pseudocode:**
```python
def compute_voxel_radiance_field(X_k, d, G_sigma, G_sh, H, W, D):
    """
    Compute density and color for a sample point using voxel grids.
    
    Args:
        X_k: 3D spatial position (float[3])
        d: Viewing direction (float[3])
        G_sigma: Density grid (list of lists of lists, shape HxWxD)
        G_sh: SH coefficient grid (list of lists of lists, shape HxWxDx9x3)
        H, W, D: Grid dimensions along x, y, z axes
        
    Returns:
        sigma_k: Volume density (float)
        c_k: Color RGB (float[3])
    """
    # 1. Trilinear interpolation for density
    sigma_k = trilinear_interpolate(G_sigma, X_k, H, W, D)
    
    # 2. Trilinear interpolation for SH coefficients
    # Returns shape (9, 3)
    sh_coeffs = trilinear_interpolate(G_sh, X_k, H, W, D)
    
    # 3. Compute SH basis vector for direction d
    sh_basis = compute_sh_basis(d)  # Returns shape (9,)
    
    # 4. Compute color: c_k = S(d)^T . G_sh(X_k)
    # sh_basis is (9,), sh_coeffs is (9, 3)
    # Result is (3,)
    c_k = [sum(sh_basis[i] * sh_coeffs[i][j] for i in range(9)) for j in range(3)]
    
    return sigma_k, c_k

def trilinear_interpolate(grid, point, H, W, D):
    """
    Perform trilinear interpolation from a 3D grid at a continuous point.
    Handles multi-channel data by applying interpolation element-wise.
    """
    x, y, z = point
    ix, iy, iz = int(x), int(y), int(z)
    fx, fy, fz = x - ix, y - iy, z - iz
    
    # Clamp coordinates to grid bounds [0, N-1]
    ix = max(0, min(H - 1, ix))
    iy = max(0, min(W - 1, iy))
    iz = max(0, min(D - 1, iz))
    
    # Retrieve 8 corner values
    v000 = grid[ix, iy, iz]
    v100 = grid[min(ix + 1, H - 1), iy, iz]
    v010 = grid[ix, min(iy + 1, W - 1), iz]
    v110 = grid[min(ix + 1, H - 1), min(iy + 1, W - 1), iz]
    v001 = grid[ix, iy, min(iz + 1, D - 1)]
    v101 = grid[min(ix + 1, H - 1), iy, min(iz + 1, D - 1)]
    v011 = grid[ix, min(iy + 1, W - 1), min(iz + 1, D - 1)]
    v111 = grid[min(ix + 1, H - 1), min(iy + 1, W - 1), min(iz + 1, D - 1)]
    
    # Interpolate along x
    v00 = lerp(v000, v100, fx)
    v01 = lerp(v010, v110, fx)
    v10 = lerp(v001, v101, fx)
    v11 = lerp(v011, v111, fx)
    
    # Interpolate along y
    v0 = lerp(v00, v01, fy)
    v1 = lerp(v10, v11, fy)
    
    # Interpolate along z
    return lerp(v0, v1, fz)

def lerp(a, b, t):
    """Linear interpolation between scalars or sequences."""
    if isinstance(a, (list, tuple)):
        return [a[i] + t * (b[i] - a[i]) for i in range(len(a))]
    return a + t * (b - a)

def compute_sh_basis(d):
    """
    Compute degree 2 spherical harmonic basis vector for direction d.
    Returns float[9]. Ordering matches standard implementation used in training [G].
    """
    x, y, z = d
    return [1.0, x, y, z, x * x, x * y, x * z, y * y, y * z]
```

**Edge Cases and Pitfalls:**
*   **Boundary Handling:** Trilinear interpolation requires handling coordinates outside the grid bounds by clamping to the nearest valid voxel index [G].
*   **SH Basis Ordering:** The ordering of the 9 SH coefficients in $G_{sh}$ must match the implementation of the SH basis evaluation function exactly [G].
*   **Scalability:** Dense grids consume significant memory; coarse-to-fine sparse voxel reconstruction combined with a pruning strategy is required for large scenes [S1].

## Operating characteristics
*   **Time Complexity:** Rendering is significantly faster than MLP-based NeRF because it replaces expensive fully-connected layer computations with simple memory lookups and trilinear interpolation [S1]. This architectural change enables real-time volume rendering [S1].
*   **Memory Complexity:** Memory usage scales with the number of voxels, but the framework limits learnable parameters strictly to grid values [S1]. Coarse-to-fine sparse reconstruction and pruning strategies mitigate memory consumption for large scenes [S1].
*   **Strengths:** Real-time rendering capability; memory-efficient parameterization; fully compatible with differentiable volume rendering [S1].
*   **Limitations:** Spatial resolution is strictly limited by the voxel grid dimensions; insufficient grid resolution causes aliasing artifacts at high spatial frequencies [G].
*   **When to Use:** Applications requiring real-time rendering and moderate resolution, such as blurred view reconstruction or interactive applications [S1].

## Background
Voxel-based Radiance Fields were introduced as a memory-efficient alternative to MLP-based NeRF, replacing the neural network with voxel grids for density and spherical harmonic coefficients [S1]. This approach was notably applied in ExBluRF for efficient radiance field optimization in the presence of extreme motion blur [S1]. The method leverages differentiable volume rendering while eliminating feed-forward operations to achieve real-time performance [S1].
