# Generative Occupancy Fields (GOF)

## Overview
Generative Occupancy Fields (GOF) is a generative model for 3D-aware image synthesis that combines radiance fields and occupancy representations to learn compact object surfaces without impeding training convergence [S1, unofficial]. It solves the problem of diffused surfaces in standard generative radiance fields (like pi-GAN) and the sparse gradient convergence issues in direct occupancy networks by transitioning from cumulative volume rendering to surface-point rendering [S1, unofficial]. Unlike its siblings, GOF predicts alpha values (interpreted as occupancy) instead of volume densities, enabling surface-aware image synthesis via root-finding [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A latent code $z \sim p_z$ (typically truncated for inference), a camera pose $\xi \sim p_\xi$ (defining ray origin $\mathbf{o}$ and direction $\mathbf{d}$), and training hyperparameters.
*   **Outputs:** A synthesized RGB image $I$. During training, gradients are computed against the ground truth image.

**Data Structures:**
*   **Generator $g_\theta$:** A neural network (typically a FiLMed-SIREN backbone) that takes position $\mathbf{x}$, latent code $z$, and direction $\mathbf{d}$ as input. It outputs a scalar alpha value $\alpha_\theta(\mathbf{x}, z) \in [0, 1]$ and a color vector $\mathbf{c}_\theta(\mathbf{x}, \mathbf{d}, z) \in \mathbb{R}^3$.
*   **Discriminator $D_{\theta_D}$:** A standard GAN discriminator evaluating real vs. generated images.
*   **Sampling Parameters:**
    *   $N$: Number of rendering samples per ray. Typical value: 12 [S1, unofficial].
    *   $M$: Number of bins for root-finding. Typical value: 12 [S1, unofficial].
    *   $m_s$: Number of secant iterations for surface refinement. Typical value: 3 [S1, unofficial].
    *   $\tau$: Threshold for root-finding. Typical value: 0.5 [S1, unofficial].
    *   $\Delta_{init}$: Initial sampling interval radius. Defined as $(t_f - t_n)/2$, where $[t_n, t_f]$ is the near/far bound of the volume [S1, unofficial].
    *   $\Delta_{min}$: Minimal sampling interval radius (pre-defined constant) [S1, unofficial].
    *   $\gamma$: Decay rate for the shrinking interval [S1, unofficial].

**Method Steps:**

1.  **Surface Location via Root-Finding:**
    To locate the object surface along a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$, GOF samples $M$ evenly-spaced points $x_k$ partitioning the volume interval $[t_n, t_f]$. It queries the generator for alpha values $\alpha_\theta(x_k, z)$. The surface bin $k_S$ is identified where the alpha value crosses the threshold $\tau$:
    $$ k_S = \arg\min_k (\alpha_\theta(x_k, z) < \tau \le \alpha_\theta(x_{k+1}, z)) $$
    The precise surface point $x_s$ is found by applying the secant method iteratively $m_s$ times within the bin $[x_{k_S}, x_{k_S+1}]$ [S1, unofficial]. Note: These $M$ points do not require gradient computation in implementation [S1, unofficial].

2.  **Shrinking Sampling Region (Training Only):**
    During training, the sampling region shrinks to encourage surface compactness.
    *   Initialize $\Delta = \Delta_{init}$.
    *   At training step $n$, compute the current interval radius:
        $$ \Delta_n = \max(\Delta_{init} \exp(-\gamma n), \Delta_{min}) $$
    *   Sample $N$ points uniformly in the interval $[t_s - \Delta_n, t_s + \Delta_n]$, where $t_s$ is the depth of the located surface point $x_s$. The $i$-th point $t_i$ is sampled from:
        $$ t_i \sim U\left[t_s - \Delta_n + \frac{2i-2}{N}\Delta_n, t_s - \Delta_n + \frac{2i}{N}\Delta_n\right] $$
    *   If the region $[t_s - \Delta_n, t_s + \Delta_n]$ exceeds the global bounds $[t_n, t_f]$, shift it back to fit within bounds [S1, unofficial].

3.  **Rendering:**
    Render the image using alpha composition. Let $\alpha_i = \alpha_\theta(x_i, z)$ and $\mathbf{c}_i = \mathbf{c}_\theta(x_i, \mathbf{d}, z)$. The transmittance $T_i$ and color $\tilde{C}(\mathbf{r})$ are:
    $$ T_i = \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    $$ \tilde{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i $$
    This is equivalent to the standard volume rendering formula but using predicted alphas directly [S1, unofficial].

4.  **Inference Rendering:**
    Fetch a truncated latent code $\hat{z}$. Locate the surface $x_s$ using steps 1-2 (with $\Delta_{min}$).
    *   **Standard Mode:** Sample $N$ points in $[t_s - \Delta_{min}, t_s + \Delta_{min}]$ and render using the formula above.
    *   **Surface-Only Mode:** Sample only the single surface point $x_s$ (i.e., $N=1$) and render. This is theoretically guaranteed to be indistinguishable from multi-point rendering as $\Delta_{min} \to 0$ and significantly speeds up off-line applications [S1, unofficial].

def locate_surface(ray_origin, ray_direction, t_near, t_far, generator, z, M=12, tau=0.5, ms=3):
    """
    Locates the surface along a ray using root-finding on alpha values.
    """
    # 1. Sample M evenly-spaced points
    t_bins = torch.linspace(t_near, t_far, M + 1)
    x_bins = ray_origin.unsqueeze(0) + t_bins.unsqueeze(1) * ray_direction.unsqueeze(0)
    
    # 2. Query alpha values (no gradients needed for root-finding)
    with torch.no_grad():
        alphas, _ = generator(x_bins, z, ray_direction) # Shape: (M+1, 1)
    
    # 3. Find bin where alpha crosses tau
    # alpha < tau (free space) to alpha >= tau (occupied)
    # Note: Source uses strict inequality < tau <= next. 
    # We look for the first index k where alpha[k] < tau and alpha[k+1] >= tau.
    free_mask = alphas.flatten() < tau
    occupied_mask = alphas.flatten() >= tau
    
    # Find transition
    # If no transition found, return midpoint or handle edge case
    if not torch.any(free_mask & occupied_mask.roll(1)):
        # Fallback: return midpoint if surface not found
        return (t_near + t_far) / 2.0

    # Find the index k where the transition occurs
    # We want k such that alpha[k] < tau and alpha[k+1] >= tau
    # This corresponds to free_mask[k] is True and occupied_mask[k+1] is True
    # Or simply: free_mask[k] and not free_mask[k+1]
    transition_indices = torch.where(free_mask[:-1] & ~free_mask[1:])[0]
    
    if len(transition_indices) == 0:
        return (t_near + t_far) / 2.0
        
    k_s = transition_indices[0].item()
    
    # 4. Secant method refinement
    t_left = t_bins[k_s].item()
    t_right = t_bins[k_s + 1].item()
    
    # Re-query alphas for secant method (gradients still not needed for location)
    with torch.no_grad():
        x_left = ray_origin + t_left * ray_direction
        x_right = ray_origin + t_right * ray_direction
        alpha_left, _ = generator(x_left.unsqueeze(0), z, ray_direction)
        alpha_right, _ = generator(x_right.unsqueeze(0), z, ray_direction)
        alpha_left = alpha_left.item()
        alpha_right = alpha_right.item()
        
    for _ in range(ms):
        # Secant method: t_new = t_right - alpha_right * (t_right - t_left) / (alpha_right - alpha_left)
        if abs(alpha_right - alpha_left) < 1e-8:
            break
        t_new = t_right - alpha_right * (t_right - t_left) / (alpha_right - alpha_left)
        
        # Clamp to bin
        t_new = max(t_left, min(t_right, t_new))
        
        x_new = ray_origin + t_new * ray_direction
        alpha_new, _ = generator(x_new.unsqueeze(0), z, ray_direction)
        alpha_new = alpha_new.item()
        
        if alpha_new < tau:
            t_left = t_new
            alpha_left = alpha_new
        else:
            t_right = t_new
            alpha_right = alpha_new
            
    return t_new

def render_gof(ray_origin, ray_direction, t_near, t_far, generator, z, n_step,

    """

    # Alpha composition
    # T_i = product(1 - alpha_j) for j < i

    # Compute transmittance

    # Cumulative product

**Edge Cases and Pitfalls:**
*   **Convergence:** Directly applying occupancy representations causes severe convergence problems due to sparse gradients on surfaces [S1, unofficial]. GOF mitigates this by starting with cumulative rendering (radiance field) and gradually shrinking the sampling region [S1, unofficial].
*   **Shape-Color Ambiguity:** Small perturbations on surfaces can still produce realistic RGB images, fooling the discriminator. GOF addresses this by encouraging surface compactness via the shrinking process and opacity regularization [S1, unofficial].
*   **Density Thresholding:** Predicted densities in generative radiance fields can range from 0 to 50, making thresholding difficult. GOF predicts alpha values directly, which are bounded in $[0, 1]$, allowing a fixed threshold $\tau=0.5$ [S1, unofficial].
*   **Surface Rendering Artifacts:** Rendering with only surface points may make furry or translucent objects over-smooth and less realistic. GOF is best suited for solid objects with a single clear surface [S1, unofficial].

## Operating characteristics
*   **Query Count:** GOF requires $M + m_s + N$ queries for standard rendering, or $M + m_s + 1$ for single-point surface rendering. Baselines (like pi-GAN) typically require $2N$ queries due to hierarchical sampling [S1, unofficial].
*   **Performance:** GOF achieves state-of-the-art performance on 3D-aware image synthesis metrics. It significantly outperforms baselines on MAD (Mean Angle Deviation, measuring compactness) and is comparable on SIDE (Scale-Invariant Depth Error, measuring depth accuracy) [S1, unofficial].
*   **Strengths:** Compact and smooth surfaces; efficient inference with surface-only rendering; stable training convergence compared to direct occupancy networks.
*   **Limitations:** Less suitable for translucent or furry objects; requires careful tuning of shrinking parameters ($\gamma, \Delta_{min}$); root-finding adds computational overhead per ray during training [S1, unofficial].
*   **Scaling:** The method scales with the number of rays and samples. The root-finding step adds a constant overhead ($M + m_s$) per ray.

## Background
Generative Occupancy Fields (GOF) was proposed by Xudong Xu, Xingang Pan, Dahua Lin, and Bo Dai from CUHK-SenseTime Joint Lab, MPI Informatics, and Nanyang Technological University [S1, unofficial]. It was published on arXiv in November 2021 [S1, unofficial]. The method builds on the concept of Generative Radiance Fields (GRAFs) and Occupancy Networks, aiming to combine the training stability of radiance fields with the surface compactness of occupancy networks [S1, unofficial]. It is used for 3D-aware image synthesis on datasets like CelebA, BFM, and Cats [S1, unofficial].
