# Binary Radiance Fields

Also called: BRF

## Overview
Binary Radiance Fields (BiRF) is a storage-efficient radiance field representation that constrains feature encoding parameters in multi-resolution grids to binary values (+1 or -1), reducing storage overhead to approximately 0.5 MB for standard scenes [S1]. Unlike post-processing compression methods such as PlenOctrees or Re:NeRF, which require additional optimization steps and are bounded by pre-trained model performance, BiRF performs binarization during training using a straight-through estimator, allowing for end-to-end optimization without post-optimization [S1]. It employs a 2D-3D hybrid multi-resolution architecture to mitigate hash collisions inherent in 3D grids while maintaining high reconstruction quality [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D spatial coordinate $\mathbf{x} \in \mathbb{R}^3$, viewing direction $\mathbf{d} \in S^2$.
*   **Output:** Volume density $\sigma \in \mathbb{R}_{\ge 0}$, RGB color vector $\mathbf{c} \in [0, 1]^3$.

**Data Structures:**
The representation consists of four multi-resolution feature grids implemented using hash encoding [S1]:
1.  One 3D voxel grid $\Phi_{\theta_{xyz}}$.
2.  Three 2D plane grids: $\Phi_{\theta_{xy}}$, $\Phi_{\theta_{xz}}$, $\Phi_{\theta_{yz}}$.

All grid parameters are constrained to binary values $\{-1, +1\}$ [S1]. The grids are organized into levels of increasing resolution:
*   **3D Grid:** $L$ levels with resolutions ranging from 16 to 1024. Each level stores up to $T_{3D}$ feature vectors [S1].
*   **2D Grids:** $M$ levels with resolutions ranging from 64 to 512. Each level stores up to $T_{2D}$ feature vectors [S1].
*   **Feature Dimension:** Each feature vector has dimension $F \in \{2, 4, 8\}$ [S1].

**Parameters:**
*   $L$: Number of 3D grid levels.
*   $M$: Number of 2D grid levels.
*   $T_{3D}$: Max feature vectors per 3D level.
*   $T_{2D}$: Max feature vectors per 2D level.
*   $F$: Feature dimension per level.
*   $\lambda_{\text{sparsity}}$: Sparsity loss weight. Default: $2.0 \times 10^{-5}$ [S1].

**Algorithm Steps:**

1.  **Binarization:** During training, real-valued grid parameters $\theta$ are transformed to binary parameters $\theta'$ using the sign function:
    $$ \theta' = \text{sign}(\theta) = \begin{cases} +1 & \text{if } \theta \ge 0 \\ -1 & \text{otherwise} \end{cases} $$
    Gradients are propagated using the Straight-Through Estimator (STE). The gradient is passed if $|\theta| \le 1$, otherwise it is zeroed to prevent scale divergence [S1].

2.  **3D Feature Encoding:** For input coordinate $\mathbf{x}$, compute features from the 3D grid by tri-linearly interpolating the binary parameters across $L$ resolution levels and concatenating them:
    $$ \mathbf{f}_{xyz} = \left\{ \text{interp}(\mathbf{x}, \text{sign}(\Phi^l_{\theta_{xyz}})) \right\}_{l=1}^L $$
    where $\text{interp}$ denotes tri-linear interpolation [S1].

3.  **2D Feature Encoding:** Project $\mathbf{x}=(x,y,z)$ to 2D coordinates: $\mathbf{x}_{xy}=(x,y)$, $\mathbf{x}_{xz}=(x,z)$, $\mathbf{x}_{yz}=(y,z)$. For each axis, bi-linearly interpolate binary parameters across $M$ resolution levels and concatenate:
    $$ \mathbf{f}_{xy} = \left\{ \text{interp}(\mathbf{x}_{xy}, \text{sign}(\Phi^m_{\theta_{xy}})) \right\}_{m=1}^M $$
    Repeat for $\mathbf{f}_{xz}$ and $\mathbf{f}_{yz}$ [S1].

4.  **Feature Concatenation:** Combine all encoded features:
    $$ \mathbf{f} = \{ \mathbf{f}_{xyz}, \mathbf{f}_{xy}, \mathbf{f}_{xz}, \mathbf{f}_{yz} \} $$

5.  **Positional Encoding:** Apply sinusoidal positional encoding $\gamma(\mathbf{x})$ to the input 3D coordinate [S1].

6.  **Density Prediction:** Feed $\gamma(\mathbf{x})$ and $\mathbf{f}$ into a shallow density MLP (1 hidden layer, 128 channels, ReLU) to obtain density $\sigma$ and embedded feature $\mathbf{e}$:
    $$ (\sigma, \mathbf{e}) = \text{MLP}_{\text{density}}(\gamma(\mathbf{x}), \mathbf{f}) $$

7.  **Color Prediction:** Feed $\mathbf{e}$ and directional encoding $\mathbf{d}$ (using spherical harmonics) into a shallow color MLP (2 hidden layers, 128 channels, ReLU) to obtain color $\mathbf{c}$:
    $$ \mathbf{c} = \text{MLP}_{\text{color}}(\mathbf{e}, \mathbf{d}) $$

**Loss Function:**
The total loss combines reconstruction loss and sparsity loss:
$$ \mathcal{L} = \mathcal{L}_{\text{recon}} + \lambda_{\text{sparsity}} \mathcal{L}_{\text{sparsity}} $$
where $\mathcal{L}_{\text{recon}}$ is the mean squared error between rendered and ground truth colors, and $\mathcal{L}_{\text{sparsity}}$ uses Cauchy loss to encourage sparse density:
$$ \mathcal{L}_{\text{sparsity}} = \sum_{i,k} \log(1 + 2\sigma(\mathbf{r}_i(t_k))^2) $$
where $\mathbf{r}_i$ are sampled rays and $t_k$ are sample points along them [S1].

## Operating characteristics
*   **Storage:** Extremely compact. The base model (Ours-B2) requires approximately 0.5 MB for Synthetic-NeRF scenes [S1]. This is significantly smaller than Instant-NGP (24.5 MB) and TensoRF-CP (3.7 MB) on the same scenes [S1].
*   **Performance:** Achieves PSNR of 32.03 dB on Synthetic-NeRF, 34.48 dB on Synthetic-NSVF, and 28.20 dB on Tanks and Temples [S1].
*   **Training Time:** Approximately 6-14 minutes per scene on an NVIDIA RTX A6000 for 20K iterations, depending on model size (Ours-B2 to Ours-B8) [S1].
*   **Strengths:** Minimal storage footprint; no post-optimization required; competitive reconstruction quality compared to larger models.
*   **Limitations:** Binary constraints may limit representational capacity compared to full-precision models; hash collisions in 3D grids are mitigated but not eliminated by the 2D supplement [S1].
*   **When to use:** When storage is a critical constraint and high-fidelity reconstruction is still required without the overhead of large models or post-processing compression.
*   **When not to use:** When maximum possible reconstruction quality is required regardless of storage, or when dynamic scenes requiring frequent updates are the primary focus (though not explicitly stated as a limitation, the static scene focus is implied) [S1].

## Background
Binary Radiance Fields were proposed by Seungjoo Shin and Jaesik Park from POSTECH and Seoul National University, published in December 2023 [S1]. The work addresses the storage bottleneck of neural radiance fields by introducing binary feature encoding. It builds on the multi-resolution hash encoding architecture of Instant-NGP [S1] and utilizes occupancy grids from NerfAcc [S1]. The method was implemented and evaluated on the Synthetic-NeRF, Synthetic-NSVF, and Tanks and Temples datasets [S1].
