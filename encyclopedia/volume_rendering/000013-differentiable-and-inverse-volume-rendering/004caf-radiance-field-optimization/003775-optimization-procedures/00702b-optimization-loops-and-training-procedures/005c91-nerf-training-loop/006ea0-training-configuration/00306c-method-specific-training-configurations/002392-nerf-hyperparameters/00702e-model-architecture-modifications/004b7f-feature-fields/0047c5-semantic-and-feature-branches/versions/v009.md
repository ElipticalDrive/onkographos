# Semantic and Feature Branches

Also called: Feature Fields, Distilled Feature Fields, Semantic NeRF branches, Opacity Fields for Detection

## Overview
Semantic and Feature Branches extend the standard NeRF formulation by predicting arbitrary per-point feature signals $\mathbf{f}$ in addition to color $\mathbf{c}$ and density $\sigma$ [Parent]. This allows the radiance field to encode semantic labels, geometric properties, or high-dimensional embeddings, enabling tasks such as zero-shot segmentation, object manipulation, and 3D detection [S1, S3, S4]. Unlike sibling methods that may focus on specific downstream applications like pose estimation [PI-NeRF](12124-pi-nerf.md) or gaze redirection [GazeNeRF](12127-gazenerf.md), this family provides the general mechanism for lifting 2D feature observations into a consistent 3D representation [Parent].

## Shared principles
The core mechanism modifies the radiance field function $F_\Theta$ to map input coordinates $(\mathbf{x}, \mathbf{d})$ to a tuple $(\mathbf{f}, \mathbf{c}, \sigma)$, where $\mathbf{f} \in \mathbb{R}^d$ is a feature vector [S1, Parent]. The rendering of these features follows the same volume integration principle as color [G]. For a ray $r$, the rendered feature $\hat{\mathbf{F}}(r)$ is computed as:

$$
\hat{\mathbf{F}}(r) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{f}(x_i)
$$

where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance and $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ is the opacity weight [S1, Parent]. Supervision is performed by comparing the rendered feature $\hat{\mathbf{F}}(r)$ against ground-truth 2D feature maps or teacher network outputs projected onto the image plane [S1, Parent]. This process lifts 2D observations into a consistent 3D representation [S1, Parent].

## Subtopics

### [PI-NeRF](12124-pi-nerf.md)
PI-NeRF is a framework that integrates NeRF with Invertible Neural Networks (INN) to directly output the 6-DoF camera pose from a single image without pose initialization or iterative optimization. It solves the inverse problem of view synthesis by modifying the radiance field to output high-dimensional features, which are then inverted to recover ray representations. Unlike sibling methods such as [NeRF2Points](12125-nerf2points.md) and [GazeNeRF](12127-gazenerf.md) which often rely on iterative optimization or specific geometric constraints, PI-NeRF achieves direct pose estimation by inverting the rendering process.

### [NeRF2Points](12125-nerf2points.md)
NeRF2Points is a method for generating large-scale, geometrically consistent RGBD point clouds from street-view radiance fields. It solves the problem of "pavement collapse" and floating artifacts in point clouds generated by standard NeRF variants when applied to sparse, large-scale street-view data with weak textures (e.g., road surfaces). It sets itself apart by separating the scene into road and street components via a ray gate, modeling them with separate radiance fields, and merging them using rigid transformation derived from shared rays.

### GazeNeRF
GazeNeRF is a 3D-aware method for gaze redirection that reformulates the task as a neural volume rendering problem [S1]. It solves the limitation of existing 2D methods by explicitly modeling the rigid 3D rotation of eyeballs and the non-rigid deformation of the face separately [S1]. Unlike sibling methods that mix facial features or lack 3D consistency, GazeNeRF uses a two-stream MLP architecture to predict volumetric features for the face (excluding eyes) and eyes independently, applying a rigid 3D rotation matrix to the eye features before compositing [S1].

### Distilled Feature Field (DFF)
**Definition:** A method that extends NeRF by adding a feature branch outputting a 3D feature vector $\mathbf{f}(\mathbf{x})$ to describe semantics, supervised by distilling a 2D teacher network (e.g., LSeg, DINO) via volume rendering [S1].
**Steps:** For a 3D coordinate $\mathbf{x}$, the network outputs density $\sigma(\mathbf{x})$, color $\mathbf{c}(\mathbf{x}, \mathbf{d})$, and feature vector $\mathbf{f}(\mathbf{x})$ [S1]. Apply stop-gradient to density $\sigma$ in the rendering of features $\hat{\mathbf{F}}(r)$ to prevent inconsistent supervision from harming geometry reconstruction [S1].
**Parameters:** Teacher network: Pretrained pixel-level image encoder, specifically clip-ViT-B-32-multilingual-v1 from Hugging Face [S1]. $\lambda$: Weight of the feature loss $L_f$ in the total loss function. Typical value: 0.04 [S1].
**Layout:** The model uses two networks for volume rendering with coarse-and-fine hierarchical sampling [S1].
**Comparison:** Unlike SemanticNeRF which outputs closed-set label probabilities, DFF outputs a continuous feature vector $\mathbf{f}(\mathbf{x})$ to enable zero-shot segmentation with open-set text labels [S1].

### Neural Perceptual Fields (NePeRF)
**Parameters:** $\lambda_f$: weight for the feature loss term, balancing it against the color loss. Typical value: 0.04 [S1].

### Object Segmentation Component
**Definition:** A component that generates view-consistent object masks for all views from a single user-annotated mask, using depth information and a region encoding concept [S2]. The network introduces 'area encoding' for each sampling point in the NeRF model, representing the probability that the sampling point belongs to the occluded area [S2].
**Steps:** Constrain the generation of correct area encoding by correctly modeling the geometry of the scene using the depth prior from the NeRF component [S2]. Obtain semantic information of whether sampling points belong to occluded areas under the guidance of the given mask [S2]. Generate view-consistent segmentation results (masks $M$) for all views [S2].

### Feature Volume Fusion
**Definition:** A technique to combine feature volumes from different scenes or objects into a single composition without artifacts [S3].
**Steps:** For each voxel coordinate shared across original scenes, select the feature vector with the maximum L2 norm [S3]. Use the selected feature vector to render the fused scene, achieving tight contact between objects from different scenes [S3].
**Parameters:** The L2 norm of the feature vector correlates with the color and density information carried by each voxel [S3].
**Usage:** Used to fuse feature volumes for objects from different datasets, such as combining LLFF vase/stand volumes with AXYZ human subject volumes [S3].

### Opacity Field Estimation for Detection
**Definition:** Opacity field models scene geometry as probability of object presence (1.0 if opaque) [S4].
**Steps:** Share the G-MLP learned in the NeRF branch with the detection branch. Input augmented volume features of 3D detection into the shared G-MLP [S4]. Transform density to opacity. Since ray direction and point distance are undefined in the undirected volume, exploit uniform voxel distribution to cancel constant $\delta_t$. Compute opacity: $\alpha(\mathbf{p}) = 1 - \exp(-\sigma(\mathbf{p}))$ [S4]. Multiply opacity field with feature grid for 3D detection: $\alpha(\mathbf{p}) \times V_{avg}(\mathbf{p})$ [S4].
**Formula:** Density output from G-MLP: $\sigma(\mathbf{p}) = \text{G-MLP}(\bar{V}(\mathbf{p}), \gamma(\mathbf{p}))$, where $\mathbf{p}$ is the center position of each voxel in the detection volume, $\sigma(\mathbf{p}) \in [0, \infty]$ [S4].

### DAP-NeRF
**Steps:** Particle removal and resampling are performed every 2,000 training steps [S5].
**Parameters:** Static feature grid $G_S$ and dynamic feature grid $G_D$ resolution: $160^3$ [S5]. Number of particles: 200,000 for synthetic datasets, 500,000 for real-scene datasets [S5]. Feature dimension $C$ for both particle and voxel features: 12 [S5]. Network width: 256 [S5]. Positional encoding frequency $\nu$: 10 for $(x, y, z)$, 4 for view direction $\mathbf{d}$, 8 for time $t$ [S5]. Particle removal thresholds: alpha value $\epsilon_\alpha = 0.0001$, trajectory length $\epsilon_{traj} = 0.1$ [S5]. Random resampling radius: 0.1 times the voxel length of the feature grids [S5]. Optimizer: Adam with $\beta = (0.9, 0.99)$ [S5]. Minibatch size: 4,096 rays [S5]. Learning rate for particle features: 0.005 [S5]. Learning rate for motion predictor network $\phi_m$: 0.001 [S5]. Total training iterations: 60,000 [S5]. Learning rate decay: exponential schedule, final decay factor 0.1 [S5]. Loss weights from equation (15): $w_1 = 0.01$, $w_2 = 0.001$, $w_3 = 0.01$, $w_4 = 0.01$ [S5].

### Self-Conditioned NeRF (SCNeRF)
**Definition:** A method leveraging features from a pretrained VGG network to guide radiance field training in sparse-view settings, using two modifications: local feature descriptor constraints and explicit feature-conditioned color prediction [S6].
**Steps:** Modification 1: Extract feature maps $F_{gt}$ from sparse input images using a pretrained VGG model (trained on ImageNet) [S6]. For a 3D point $p_i = (x, y, z)$, predict a bottleneck feature $b_i$ using network $M_b$: $b_i = M_b(p_i)$ [S6]. Predict a prior feature $f_i$ for the 3D point based on the shared bottleneck feature using network $M_f$: $f_i = M_f(b_i)$ [S6]. Obtain rendered feature $F(r)$ by volume rendering and minimize L2 loss between rendered features and extracted features $F_{gt}(r)$: $L_f = || F(r) - F_{gt}(r) ||_2$ [S6]. Modification 2: Explicitly constrain the relation between feature descriptors and color predictions by conditioning the color prediction network on the learned prior feature $f_i$ [S6].
**Parameters:** Pretrained network: VGG trained on ImageNet [S6].
**Comparison:** Unlike DietNerf which constrains learning in unobserved views with image-level loss, this method supervises the learning process in training views with pixel-level loss [S6].

### Invertible Neural Module (INM)
**Definition:** A bidirectional converter between ray features/representations and pixel features, consisting of two INNs (INN1 and INN2) [S7].
**Steps:** Ray Representation Construction: Convert ray $\mathbf{r}_u$ to Plücker coordinates $\mathbf{r}_{plu} = [\mathbf{d}_u, \mathbf{m}_u] \in \mathbb{R}^6$ where $\mathbf{m}_u = \mathbf{o}_u \times \mathbf{d}_u$ [S7]. Calculate endpoint $\mathbf{e}_u = \mathbf{r}_u(\sigma_r)$ [S7]. Define representation $\mathbf{r}_u = [\mathbf{r}_{plu}, \mathbf{e}_u, \mathbf{e}_u]$ [S7]. Forward Path: Input ray feature $\mathbf{f}_{r_u}$ and ray representation $\mathbf{r}_u$ [S7]. Encode ray via INN1: $\mathbf{r} = \text{INN1}(\mathbf{r}_u)$ [S7]. Output pixel feature $\mathbf{f}_u$ (implied mapping from $\mathbf{f}_{r_u}$ and $\mathbf{r}$) [S7]. Reverse Path: Input pixel feature $\mathbf{f}_u$ [S7]. Decode via INN2 inverse: $[\mathbf{r}', \mathbf{f}_{r'}] = \text{INN2}^{-1}(\mathbf{f}_u)$ [S7]. Decode ray via INN1 inverse: $\mathbf{r}' = \text{INN1}^{-1}(\mathbf{r}')$ [S7]. Output ray representation $\mathbf{r}'_u$ and ray feature $\mathbf{f}_{r'_u}$ [S7].
**Parameters:** INN1: Used to encode the ray. Sub-networks are MLPs [S7]. INN2: Consists of 3 invertible blocks, each sub-network is an MLP [S7].

### NeRF-SOS
**Steps:** Generate feature tensors from color patches rendered by the model using a self-supervised pretrained framework [S8]. Use the generated features to create volumes for appearance-segmentation [S8]. Apply contrastive losses to correlate appearance-segmentation and geometry-segmentation [S8].

### Feature-Realistic Fusion
**Steps:** Fuse general features learned from EfficientNet into the NeRF representation [S8]. Operate incrementally in real-time using a SLAM backend to manage exploration of new, unobserved scene regions [S8].

## Background
The concept of feature fields in NeRF originated from the need to go beyond color rendering for tasks like segmentation and editing. Distilled Feature Fields (DFF) introduced the idea of distilling 2D teacher network features (like CLIP or DINO) into a 3D feature field via volume rendering, enabling zero-shot segmentation [S1]. Subsequent works expanded this to include semantic labels [S1], object segmentation via area encoding [S2], and feature volume fusion for scene manipulation [S3]. The application of feature branches also extended to 3D detection, where opacity fields derived from feature branches aid in geometry-aware detection [S4], and dynamic scene modeling with particle-based feature grids [S5]. In sparse-view settings, self-conditioned NeRF used VGG features to guide training [S6], while PI-NeRF utilized invertible neural modules to map between ray and pixel features for pose estimation [S7]. Recent surveys highlight these diverse applications, including language-guided editing and intrinsic NeRF decomposition [S8].
