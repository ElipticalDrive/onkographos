# GALA3D
## Overview
GALA3D is a method for 3D scene generation that leverages both object-level and scene-level models to achieve realistic composition [S1]. It addresses the challenge of generating coherent 3D scenes by first synthesizing individual objects and then composing them into a global environment [S1]. Unlike single-stage text-to-3D methods, GALA3D separates the generation of local geometry (objects) from global layout (scenes), using MVDream for object synthesis and a scene-level diffusion model for composition [S1].

## How it works
**Inputs and Outputs:**
- Input: A text prompt describing the desired scene [S1].
- Output: A composed 3D scene representation [S1].

**Data Structures:**
- Object-level representation: Generated by MVDream, typically a point cloud or 3D Gaussian Splatting (3DGS) representation [S1].
- Scene-level composition: A diffusion model that arranges and composes the generated objects into a coherent scene [S1].

**Steps:**
1. Object Generation: Use the object-level text-to-3D model MVDream to generate realistic 3D objects from the text prompt [S1].
2. Scene Composition: Use a scene-level diffusion model to compose the generated objects into a coherent 3D scene [S1].

**Parameters:**
- Text prompt: Defines the semantic content of the scene [S1].
- MVDream model: Pre-trained text-to-3D model [S1].
- Scene-level diffusion model: Pre-trained model for scene composition [S1].

## Subtopics

### Lightplane-augmented Viewset Diffusion
This process simultaneously generates multiple views of the object as well as its 3D model [S3]. During inference, the viewset is initialized with Gaussian noise [S3]. The model iteratively denoises the viewset by applying a reconstruction model [S3]. Each image $I_i$ in the viewset is replaced with $I_i^t = \alpha_t I_i + \sigma_t \epsilon_i$ where $t$ is the noising schedule, $\alpha_t$ and $\sigma_t = \sqrt{1 - \alpha_t^2}$ are the noise level, and $\epsilon_i$ is a random Normal noise vector [S3]. This approach boosts scalability by increasing the amount of 2D information lifted to 3D and allows for larger model and batch sizes during training due to memory savings [S3]. Inference time for Lightplane is under 2 minutes, compared to 30 minutes for HoloFusion [S3]. It significantly outperforms HoloDiffusion and Viewset Diffusion on CO3Dv2, and beats HoloFusion in speed [S3].

## Operating characteristics
- Time complexity is not given in the sources [S1].
- Memory complexity is reduced in the Lightplane-augmented variant, allowing for increased model and batch sizes during training [S3].
- Performance benchmarks show improvements in scalability and speed for 3D tasks [S3].
- Strengths include enabling the generation of complex scenes with multiple objects and scalability to large-scale 3D models [S1, S3].
- Limitations include the requirement for two separate models (object-level and scene-level) and dependency on pre-trained model quality [S1].

## Background
GALA3D was introduced to explore 3D scene generation by combining object-level and scene-level generation processes [S1]. It builds on the idea of using text-to-3D models like MVDream for object synthesis and extends it to scene-level composition [S1]. The method is part of the broader effort to improve the realism and coherence of generated 3D scenes [S1].
