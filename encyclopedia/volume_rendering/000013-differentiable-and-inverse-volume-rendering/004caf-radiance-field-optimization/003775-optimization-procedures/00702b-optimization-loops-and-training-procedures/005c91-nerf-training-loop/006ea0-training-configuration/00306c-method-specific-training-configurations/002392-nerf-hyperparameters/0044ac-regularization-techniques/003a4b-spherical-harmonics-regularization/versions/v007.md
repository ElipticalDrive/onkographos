# Spherical Harmonics Regularization

Also called: SH coefficient masking, SH curriculum training, SH degree regularization

## Overview
Spherical Harmonics (SH) Regularization is a training strategy that restricts the maximum degree of Spherical Harmonics during the early stages of optimization to prevent high-frequency overfitting and stabilize geometry reconstruction [S1, S2]. It addresses the problem where high-frequency SH coefficients cause inaccurate geometry and artifacts when the model attempts to learn view-dependent effects before the coarse geometry is established [S2]. It sets itself apart from general density constraints by specifically targeting the frequency content of the radiance representation, acting as a curriculum learning mechanism for view-dependent appearance [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A voxel grid representation of the scene where each voxel stores opacity and Spherical Harmonics coefficients for color/radiance [S1, S2].
*   **Output:** A trained radiance field with stabilized geometry and reduced high-frequency artifacts, achieved by gradually unlocking high-frequency SH coefficients during training [S1, S2].

**Data Structures:**
The radiance field uses a voxel grid. Each voxel $v$ contains:
*   Opacity $\alpha_v$ (scalar) [S1, S2].
*   SH Coefficients $c_{l,m}$ for color channels [S1, S2]. For a maximum degree $L$, there are $(L+1)^2$ coefficients per color channel [G]. The coefficients are indexed by degree $l \in \{0, \dots, L\}$ and order $m \in \{-l, \dots, l\}$ [G].

**Parameters:**
*   $L_{max}$: The maximum SH degree supported by the representation (e.g., $L_{max}=3$ or $4$) [S1, S2].
*   $E_{curriculum}$: The number of epochs for the curriculum schedule. Sources specify $E_{curriculum}=5$ [S1].
*   $L_{start}$: The initial maximum SH degree allowed. Sources indicate starting with low degrees to capture diffuse reflectance [S1].
*   Masking Rate Decay: The rate at which the masking constraint is relaxed. Sources specify a decay of $1/5$ per epoch for the first 5 epochs [S1].

**Steps:**
1.  **Initialization:** Initialize the voxel grid with SH coefficients [S1, S2].
2.  **Masking Definition:** Define a binary mask $M_{l,m}$ for each SH coefficient. Coefficients for degrees $l \ge 2$ are initially fully masked ($M_{l,m}=0$), while degrees $l < 2$ are updated normally ($M_{l,m}=1$) [S1].
3.  **Gradient Application:** During backpropagation, compute gradients $\nabla c_{l,m}$ for all coefficients. Apply the mask to the gradients or the coefficients themselves:
    $$ c_{l,m}^{new} = c_{l,m}^{old} + \eta \cdot M_{l,m} \cdot \nabla c_{l,m} $$
    where $\eta$ is the learning rate. This ensures that coefficients with $l \ge 2$ do not update initially [S1].
4.  **Curriculum Schedule:** For each epoch $e$:
    *   If $e < E_{curriculum}$: Gradually relax the masking constraint. Sources describe decreasing the "rate of SH masking" by $1/5$ per epoch [S1]. This implies a linear relaxation of the constraint [G]. Specifically, the mask multiplier for degrees $l \ge 2$ increases by $0.2$ each epoch until it reaches $1.0$ at epoch $5$ [S1].
    *   If $e \ge E_{curriculum}$: Set $M_{l,m} = 1$ for all $l$. All SH coefficients are updated with full rate [S1].
5.  **Optimization:** Continue optimizing opacity, SH coefficients, and other parameters (e.g., white balance) using the standard reconstruction loss [S1].

**Pseudocode:**
```python
def update_sh_coefficients(voxel_grid, gradients, learning_rate, current_epoch):
    # Masking rate decreases by 1/5 per epoch for the first 5 epochs [S1]
    if current_epoch < 5:
        masking_rate = 1.0 - (current_epoch / 5.0)
    else:
        masking_rate = 0.0

    for voxel in voxel_grid:
        for l in range(len(voxel.c)):
            for m in range(-l, l + 1):
                grad = gradients[voxel.id][l][m]
                # Apply SH masking to coefficients of degrees 2 and 3 [S1]
                if l >= 2:
                    # Update with relaxed masking factor
                    voxel.c[l][m] += learning_rate * (1.0 - masking_rate) * grad
                else:
                    # Degrees 0 and 1 are updated with full rate
                    voxel.c[l][m] += learning_rate * grad
    return voxel_grid
```

**Edge Cases and Pitfalls:**
*   **Precision:** SH coefficients can vary in magnitude. Masking high-frequency terms prevents them from dominating the loss gradient early on, which can cause instability if not masked [S1].
*   **Boundary Conditions:** The transition from masked to unmasked coefficients must be smooth to avoid sudden changes in radiance representation [G].
*   **Degenerate Input:** In scenes with very high-frequency view-dependent effects (glossy materials), early masking might slow down convergence for those specific materials, but it stabilizes the overall geometry [S1].

## Operating characteristics
*   **Time Complexity:** Adds negligible computational overhead, as the curriculum strategy improves training efficiency without introducing extra computational cost [S2].
*   **Memory Complexity:** No additional memory overhead beyond the standard voxel grid and SH coefficient storage [S2].
*   **Performance:** Improves geometry accuracy and reduces floaters, especially in few-shot or harsh input conditions [S1, S2]. It stabilizes optimization by decoupling geometry learning (low frequency) from appearance learning (high frequency) [S1].
*   **Strengths:** Simple to implement, no extra hyperparameters beyond the curriculum length, effective at preventing high-frequency overfitting [S1, S2].
*   **Limitations:** Not given in the sources.

## Background
Spherical Harmonics Regularization was introduced in the context of Plenoxels and related voxel-based radiance field methods [S1, S2]. It was inspired by frequency regularization techniques used in FreeNeRF (positional encoding) and FourieRF (Fourier coefficients) [S2]. The specific application to SH coefficients was detailed in HDR-Plenoxels [S1] and F2Plenoxels [S2]. It is used in few-shot view synthesis and high-dynamic-range radiance field reconstruction [S1, S2].
