# StyleGAN2 Training Configuration

Also called: 2D Noise Removal, GAN Training Configuration, GSN Training Configuration, Generative Network Training Setup, StyleGAN2 Training Setup

## Overview
This configuration adapts the StyleGAN2 training protocol to 3D-aware radiance field models, explicitly removing per-pixel 2D noise injection to preserve 3D consistency across camera viewpoints [S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ground truth images $\mathbf{I}_{gt}$, camera poses $\mathbf{T}$, and latent codes $\mathbf{z} \sim \mathcal{N}(0, I)$ [S2].
*   **Outputs:** Rendered images $\hat{\mathbf{I}}$, discriminator scores $D(\mathbf{I})$, and updated network weights [S2].

**Data Structures:**
*   **Generator ($G$):** A neural network mapping latent codes to radiance fields or voxel grids, updated via RMSprop [S2].
*   **Discriminator ($D$):** A neural network evaluating image realism, which includes a minibatch standard deviation layer [S1].
*   **Exponential Moving Average (EMA):** A shadow copy of generator weights $\theta_{EMA}$ maintained separately from training weights $\theta$ [S2].

**Numbered Steps:**
1.  **Optimizer Setup:** Initialize RMSprop for $G$ and $D$ with learning rate $\eta = 0.002$, momentum $\alpha = 0.99$, and epsilon $\epsilon = 10^{-8}$ [S2].
2.  **Learning Rate Scaling:** Apply equalized learning rates to all trainable parameters in the synthesis network [S1][S2]. Set the mapping network learning rate to $100\times$ less than the synthesis network ($\eta_{map} = 0.00002$) [S2].
3.  **Data Augmentation:** Apply differentiable augmentations (random translation, color jitter, Cutout) to all discriminator inputs to combat overfitting [S2].
4.  **Noise Injection Handling:** Remove per-pixel 2D noise injection from the generator. Standard StyleGAN2 injects noise to model stochastic variations (e.g., hair), but this noise is 2D-only and breaks 3D consistency when the camera moves [S3, unofficial]. [G] If 3D-consistent noise is required, use geometry-aware noise based on estimated surface depth instead.
5.  **Regularization Strategy (R1):** Apply R1 gradient penalty to the discriminator. To reduce computational cost, use lazy regularization: compute the gradient penalty once every $k$ minibatches. For StyleNeRF: $k=4$, strength $\gamma = 1$ [S1]. For GSN: $k=16$, strength $\lambda_{R1} = 0.01$ [S2]. The R1 penalty formula is $\mathcal{L}_{R1} = \frac{\gamma}{2} \mathbb{E}_{\mathbf{x} \sim p_{data}} [||\nabla_{\mathbf{x}} D(\mathbf{x})||_2^2]$, where $\mathbf{x}$ is the discriminator input [G].
6.  **Loss Computation:** Compute adversarial loss for $G$ and $D$. If using a reconstruction-based variant (e.g., GSN), add reconstruction loss: $\mathcal{L}_{Recon} = \lambda_{Recon} ||\mathbf{I}_{gt} - \hat{\mathbf{I}}||_2^2$ with $\lambda_{Recon} = 1000$ [S2].
7.  **Backpropagation:** Update weights using the optimizer. Do not use path regularization or style-mixing [S1].
8.  **EMA Update:** Update the generator's EMA weights after each step: $\theta_{EMA} \leftarrow \alpha_{EMA} \theta_{EMA} + (1 - \alpha_{EMA}) \theta$ with decay $\alpha_{EMA} = 0.999$ [S2].
9.  **Mixed Precision:** Use mixed-precision training (FP16) for the generator [S1][S2]. For the discriminator, mixed precision may be disabled if training stability decreases (as observed in GSN) [S2].

**Pseudocode:**
```python
# Helper definitions
def RMSprop_update(params, exp_avg, lr, alpha, eps):
    for p in params:
        if p.grad is None: continue
        if p not in exp_avg: exp_avg[p] = zeros_like(p)
        exp_avg[p].mul_(alpha).add_(p.grad, alpha=1.0 - alpha)
        p.add_(exp_avg[p].sqrt().add_(eps).reciprocal(), alpha=-lr)

def deep_copy(model):
    return ModelCopy(model.state_dict())

def compute_gradients(output, input_tensor):
    return gradient(output.sum(), input_tensor, create_graph=True)

# Initialization
exp_avg_G = {}
exp_avg_D = {}
ema_decay = 0.999
ema_G = deep_copy(G)
r1_reg_every = 4
r1_gamma = 1.0

def train_step(real_images, camera_poses, latent_codes, global_step):
    # 1. Data Augmentation
    real_images_aug = augment(real_images, ops=["random_translation", "color_jitter", "cutout"])

    # 2. Generator Forward Pass (2D noise injection is removed)
    fake_images = G(latent_codes, camera_poses)

    # 3. Discriminator Forward Pass (includes minibatch standard deviation layer)
    D_real = D(real_images_aug)
    D_fake = D(fake_images.detach())

    # 4. Adversarial Loss
    loss_D = -mean(D_real) + mean(D_fake)
    loss_G = -mean(D_fake)

    # 5. R1 Regularization (Lazy)
    if global_step % r1_reg_every == 0:
        real_images_aug.requires_grad = True
        D_real_val = D(real_images_aug)
        gradients = compute_gradients(D_real_val, real_images_aug)
        r1_penalty = (r1_gamma / 2) * mean(sum(gradients**2, dim=(1, 2, 3)))
        loss_D += r1_penalty

    # 6. Backpropagation
    loss_D.backward()
    RMSprop_update(D.parameters(), exp_avg_D, lr=0.002, alpha=0.99, eps=1e-8)

    loss_G.backward()
    RMSprop_update(G.parameters(), exp_avg_G, lr=0.002, alpha=0.99, eps=1e-8)

    # 7. EMA Update
    with no_grad():
        for param_q, param_k in zip(ema_G.parameters(), G.parameters()):
            param_q.data = ema_decay * param_q.data + (1.0 - ema_decay) * param_k.data
```

**Parameters:**
*   **Learning Rate:** 0.002 for synthesis, 0.00002 for mapping [S2].
*   **R1 Strength:** $\gamma=1$ (StyleNeRF) or $\lambda_{R1}=0.01$ (GSN) [S1][S2].
*   **R1 Frequency:** Every 4 minibatches (StyleNeRF) or every 16 iterations (GSN) [S1][S2].
*   **EMA Decay:** 0.999 [S2].
*   **Batch Size:** 32 [S2].
*   **Iterations:** 500,000 for 64x64 models [S2].

**Edge Cases and Pitfalls:**
*   **Small Datasets:** For small datasets like AFHQ, finetune a generator pretrained on FFHQ with $R_I=128$ and $R_G=32$ (before pruning) [S1].
*   **3D Consistency:** Injecting per-pixel noise increases modeling capability for stochastic variation but causes inconsistency when the camera moves [S3, unofficial].
*   **Mixed Precision Stability:** Applying mixed precision to the discriminator may decrease training stability; monitor loss divergence [S2].

## Subtopics

### [Conditional Discriminator with Skip Connections for Progressive Growing](12991-conditional-discriminator-with-skip-connections-for-progress.md)
A conditional discriminator architecture designed for progressive growing in StyleGAN2-based training pipelines. It solves the stability issues associated with training high-resolution generative models by integrating conditional inputs and skip connections that inject downsampled input images into every layer. It differs from standard StyleGAN2 discriminators by explicitly supporting the progressive growing mechanism via these skip connections, and from alternative progressive methods like Progressive Up-sampling by requiring linear fading of new layers rather than inserting upsample operations.

## Operating characteristics
*   **Time Complexity:** Training is computationally intensive. 64x64 models trained for 500k iterations take approximately 4 days on two NVIDIA A100 GPUs (40GB each) [S2].
*   **Memory Complexity:** Mixed precision reduces memory cost for the generator. The discriminator may require higher precision (FP32) to maintain stability, increasing its memory footprint [S2].
*   **Strengths:** High-quality 3D-aware synthesis; stable training via R1 regularization and EMA; effective handling of small datasets via transfer learning [S1][S2][S3, unofficial].
*   **Limitations:** Removal of 2D noise reduces ability to model fine stochastic details (e.g., hair strands) unless geometry-aware noise is implemented [S3, unofficial].
*   **When to Use:** When generating high-resolution, 3D-consistent images from a generative prior (StyleGAN2) rather than optimizing a single NeRF for a specific scene [S3, unofficial].
*   **When Not to Use:** When 3D consistency is not required, or when computational resources are insufficient for GAN training (vs. supervised NeRF) [S3, unofficial].

## Background
Originating from the adaptation of StyleGAN2 [22] to 3D radiance fields, this configuration was introduced in works such as StyleNeRF [S3, unofficial] and VoxGRAF [S1]. Key developments include the removal of 2D noise for consistency [S3, unofficial] and the use of lazy R1 regularization for efficiency [S1][S2]. It is used in state-of-the-art 3D-aware image synthesis and view synthesis tasks [S3, unofficial].
