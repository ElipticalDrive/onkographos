# Model Architecture Modifications

Also called: NeRF Architecture Variants, Radiance Field Network Structures

## Overview
Model Architecture Modifications encompasses the structural changes to the neural networks that define Neural Radiance Fields (NeRFs), moving beyond the baseline two-MLP formulation to address specific limitations in geometry, appearance, efficiency, and generalization. While the standard NeRF [Parent](3065-nerf-hyperparameters.md) uses a single Multi-Layer Perceptron (MLP) to map spatial coordinates and viewing directions to volume density and color, this family includes methods that decouple these predictions, integrate external priors (such as vision transformers or depth sensors), replace implicit representations with explicit primitives, or condition the network on latent codes for generative tasks. These modifications are distinct from training hyperparameter adjustments (e.g., learning rate schedules) or sampling strategies, focusing instead on the internal topology, input/output dimensions, and feature processing pipelines of the radiance field function.

## Shared principles
The baseline NeRF architecture [Parent](3065-nerf-hyperparameters.md) defines a continuous volumetric scene representation $F_\Theta: (\mathbf{x}, \mathbf{d}) \rightarrow (\sigma, \mathbf{c})$, where $\mathbf{x} \in \mathbb{R}^3$ is the spatial position, $\mathbf{d} \in \mathbb{R}^3$ is the viewing direction, $\sigma$ is the volume density, and $\mathbf{c} \in \mathbb{R}^3$ is the view-dependent color [G]. The rendering process integrates these outputs along rays using standard volume rendering equations [G].

Most modifications in this family retain the core volume rendering equation but alter one or more of the following components:
1.  **Input Space:** Augmenting $\mathbf{x}$ and $\mathbf{d}$ with additional signals such as latent codes $\mathbf{z}$, time $t$, illumination embeddings $\mathbf{z}_l$, or external feature vectors $\mathbf{f}$ from vision models [S1][S2, S3, unofficial].
2.  **Network Topology:** Replacing the monolithic MLP with specialized branches (e.g., separate density and color networks), modular experts, or hybrid structures combining MLPs with convolutional or transformer backbones [S1][S2, unofficial].
3.  **Output Space:** Extending the output tuple $(\sigma, \mathbf{c})$ to include additional fields such as surface normals $\mathbf{n}$, semantic logits $\mathbf{s}$, uncertainty variance $\nu$, or blend weights $\Delta w$ [S1][S2, unofficial].
4.  **Representation Basis:** Substituting the coordinate-based implicit function with explicit structures like voxel grids, hash tables, Gaussian primitives, or planar surfaces, which change how features are stored and interpolated [S1][S2, unofficial].

## Subtopics

### [DoF-NeRF](9432-dof-nerf.md)
DoF-NeRF extends the NeRF architecture to simulate depth-of-field effects by incorporating optical models of geometric optics. It distinguishes itself by jointly optimizing aperture diameters and focus distances during training, allowing it to render clear novel views from shallow DoF inputs, unlike methods that assume all-in-focus inputs.

### [NeRF-VPT](11770-nerf-vpt.md)
NeRF-VPT is a cascading view prompt tuning paradigm that uses RGB information from preceding rendering iterations as visual prompts for subsequent stages. It sets itself apart by using only the network's internal output as prior knowledge, making it a plug-and-play module for existing NeRF variants without external networks.

### [NeRF-VAE](11991-nerf-vae.md)
NeRF-VAE embeds a NeRF within a Variational Autoencoder (VAE) framework to learn a distribution over 3D scenes. It differs from standard NeRF by replacing per-scene optimization with an amortized inference process using a latent code, enabling generalization to out-of-distribution scenes.

### [Activation Feature Density Approximation](12492-activation-feature-density-approximation.md)
This method estimates volumetric density directly from intermediate activation features of a coordinate-based MLP, replacing the expensive evaluation of a coarse network with a lightweight computation. It sets itself apart by leveraging internal network states rather than additional network passes.

### [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md)
SDF representations replace the implicit volume density field with a continuous scalar field representing the distance to the nearest surface. This approach addresses geometric inaccuracy and surface holes typical of density-based NeRFs by providing a more explicit formulation of surfaces.

### [Volume-Augmented NeRF](12973-volume-augmented-nerf.md)
Volume-Augmented NeRF binds explicit fluid volume values to sample points, allowing the renderer to learn density and color based on an explicit fluid distribution. Unlike standard NeRF, it augments the input with a fluid volume field $V$ to handle temporal changes in dynamic fluid scenes.

### [Neural-PIL Decomposition Architecture](12975-neural-pil-decomposition-architecture.md)
This architecture addresses reflectance decomposition by explicitly modeling the rendering pipeline as a two-stage process: a coarse network predicting view- and illumination-conditioned colors, and a decomposition network estimating density, BRDF parameters, and surface normals. It sets itself apart by computing an expected ray termination point and rendering only at that location.

### [Feature Fields](12995-feature-fields.md)
Feature Fields generalize NeRF by predicting arbitrary per-point feature signals $\mathbf{f}$ in addition to density and color. This extension allows the 3D representation to encode semantic labels or physical properties, enabling tasks like zero-shot segmentation.

### [SAID-NeRF](13619-said-nerf.md)
SAID-NeRF exploits instance masks from Visual Foundation Models to enhance surface estimation for transparent objects. It differs from standard NeRF by jointly optimizing a semantic field to enforce view-independent surface densities, producing sharper depth estimates.

### [MINE](13661-mine.md)
MINE models the frustum of the source camera using continuous depth Multiplane Images (MPI), conditioned on input images via a fully-convolutional decoder. It differs from pixelNeRF and GRF by reconstructing the source camera's frustum per plane, allowing rendering of any target view via homography warping.

### [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md)
These representations replace the continuous MLP with structured spatial data structures (voxel grids, hash tables) to store scene features. Unlike hash-based or dense MLP approaches, this method limits learnable parameters strictly to grid values, offering a memory-efficient framework.

### [Aleth-NeRF](13764-aleth-nerf.md)
Aleth-NeRF trains on under- and over-exposed images to render normal-light novel views by introducing a 'Concealing Field' assumption. It differs from RAW-NeRF by taking 8-bit LDR images as inputs and trains end-to-end without pre-processing.

### [Transformer and Vision Model Integration](13911-transformer-and-vision-model-integration.md)
This family integrates Vision Transformers (ViT) and other vision backbones into NeRF to replace or augment standard positional encoding. It solves the limitation of local MLPs by leveraging the global receptive field and semantic understanding of pre-trained vision models.

### [Human and Specific Subject Modeling](13997-human-and-specific-subject-modeling.md)
This family modifies the standard NeRF architecture to explicitly model human subjects, integrating parametric human priors (such as SMPL) or part-based decompositions to constrain the learning space for dynamic geometry and non-rigid deformation.

### [OPONeRF](14014-oponerf.md)
OPONeRF personalizes the parameters of the plenoptic mapping function for each sampled 3D point. It solves the problem of handling test-time scene changes by conditioning the renderer's weights on a global scene representation and a local point feature.

### [Mixer-NeRF](14073-mixer-nerf.md)
Mixer-NeRF addresses the loss of local information in standard NeRF by integrating a hybrid spatial feature learning module (MLCA) and a squeeze-and-excitation (SE) network module. It differs from the baseline by explicitly mixing spatial and channel features via fully connected layers.

### [Sparse View and Few-Shot Optimization](14428-sparse-view-and-few-shot-optimization.md)
This family addresses artifacts and overfitting when training NeRF with a drastically reduced number of input viewpoints. It sets itself apart by introducing specialized regularization, data densification, or geometric constraints rather than relying on large-scale pre-training.

### [Mixture-of-Experts and Modular Architectures](14429-mixture-of-experts-and-modular-architectures.md)
MoE and Modular Architectures decompose the single monolithic neural network into multiple specialized sub-networks (experts) with a gating mechanism. They set themselves apart from sibling methods like Voxel representations by maintaining continuous implicit representations without explicit grid discretization.

### [Uncertainty and Reliability](14487-uncertainty-and-reliability.md)
This family extends NeRF architectures to quantify prediction confidence by modeling outputs as distributions (Gaussian) rather than deterministic points. It differs from standard NeRF by explicitly modeling predictive variance alongside density and color.

### [Object Decomposition and Composition](14518-object-decomposition-and-composition.md)
This family explicitly separates a scene into distinct semantic or geometric entities to enable instance-level editing. It is distinguished from siblings like SDF representations by its focus on semantic/instance separation rather than just boundary representation.

### [Lighting and Appearance Models](14522-lighting-and-appearance-models.md)
These models extend the standard NeRF representation by decoupling material properties from illumination or enforcing 3D consistency in non-photorealistic rendering. They solve the problem of fixed illumination in standard radiance fields.

### [Image Enhancement and Restoration Methods](14566-image-enhancement-and-restoration-methods.md)
These methods address input data degradation in NeRF training by modeling blur, transient occlusions, or missing geometry. Unlike sibling methods that modify internal neural field capacity, these approaches explicitly model the imaging process.

### [Modular, Hierarchical, and Latent Architectures](14567-modular-hierarchical-and-latent-architectures.md)
This family extends the standard NeRF architecture by introducing modularity, hierarchical structures, or latent variable conditioning to handle complex scene properties such as non-rigid deformation and topological changes.

### [NeuralEditor](14895-neuraleditor.md)
NeuralEditor edits neural radiance fields by exploiting an explicit point cloud representation as the underlying structural backbone. Unlike traditional NeRFs, it intrinsically integrates point clouds with the implicit neural representation, enabling general shape deformation.

### [MuRF (Multi-Baseline Radiance Fields)](15007-murf-multi-baseline-radiance-fields.md)
MuRF is a feed-forward neural network method for sparse view synthesis that constructs a target view frustum volume aligned with the novel view. Unlike ray-based rendering methods, MuRF uses a 3D context-aware convolutional decoder to regress a radiance field from this volume.

### [Gaussian and Primitive-Based Representations](15011-gaussian-and-primitive-based-representations.md)
This family replaces the global implicit coordinate-to-radiance mapping with explicit, learnable 3D primitives (Gaussians, quadrics). Unlike grid-based or pure MLP approaches, these methods represent the scene as a discrete set of elements, enabling differentiable rasterization.

### [Decentralized Federated NeRF](15032-decentralized-federated-nerf.md)
DecentNeRF is a decentralized framework for learning global 3D scene representations from crowd-sourced images. It sets itself apart from centralized approaches by distributing training to users and employing a personal/global MLP decomposition to protect privacy.

### [Neural Proxy](15220-neural-proxy.md)
Neural Proxy represents photo-realistic targets as animatable proxies to enable the rendering of unseen animations. It solves the limitation of standard NeRF by combining neural volume rendering with neural texture, mimicking the typical CG pipeline.

### [ViSNeRF](15255-visnerf.md)
ViSNeRF is a hybrid neural radiance field method for dynamic volumetric scenes that combines explicit feature grids with implicit feature decoders. It distinguishes itself from fully explicit and fully implicit methods by using vector-matrix decomposition for spatial features.

### [EBAD-NeRF](15441-ebad-nerf.md)
EBAD-NeRF reconstructs sharp 3D radiance fields from motion-blurred images by jointly optimizing learnable camera poses and NeRF parameters using hybrid event-RGB data. It distinguishes itself by modeling complex camera motion trajectories with multiple learnable poses.

### [DINO-enhanced NeRF](15497-dino-enhanced-nerf.md)
This family integrates pre-trained DINO vision features into the NeRF radiance field for few-shot 3D reconstruction. It sets itself apart from sibling methods like Feature Fields by specifically leveraging self-supervised transformer features.

### [NeurMiPs](15543-neurmips.md)
NeurMiPs represents a 3D scene as a mixture of $K$ learnable rectangular planar surfaces, where each surface acts as an independent "expert". It solves the frontal-parallel limitation of traditional MPI and the high memory costs of dense volume rendering.

### [CodeNeRF](15544-codenerf.md)
CodeNeRF is an implicit 3D neural representation that learns the variation of object shapes and textures across a semantic category. It differs from sibling methods by explicitly decoupling shape and texture into independent embedding spaces.

### [Dynamic Scene and Temporal Modeling](15546-dynamic-scene-and-temporal-modeling.md)
This family extends the static NeRF representation to handle time-varying geometry and appearance. Unlike sibling methods that employ complex warping fields, this family encompasses a broad range of approaches including direct time conditioning and canonical space deformation.

### [NeRF-Casting](15547-nerf-casting.md)
NeRF-Casting synthesizes photorealistic specular appearance by integrating ray tracing into the NeRF rendering pipeline. It solves the problem of view-dependent appearance modeling by replacing expensive neural network queries for outgoing radiance with reflection rays.

### [RoseNeRF](15548-rosenerf.md)
RoseNeRF is a method for high-fidelity novel view synthesis of real refractive objects that simplifies complex ray interactions to a single refraction event. It predicts the refracted ray using a 4D light field representation, avoiding the need for Index of Refraction fields.

### [NeRF-Det](15549-nerf-det.md)
NeRF-Det is a method for indoor 3D object detection that explicitly models scene geometry as an opacity field by jointly training a NeRF branch with a 3D detection pipeline. It is a joint "NeRF-and-Det" paradigm that integrates multi-view geometry constraints.

### [Semantic Ray (S-Ray)](15552-semantic-ray-s-ray.md)
Semantic Ray (S-Ray) is a method for learning a generalizable semantic field that infers semantic labels on novel viewpoints across unseen scenes. It distinguishes itself by using a Cross-Reprojection Attention module to exploit semantic context from multiple source views.

### [Neural Density-Distance Fields](15665-neural-density-distance-fields.md)
Neural Density-Distance Fields (NeDDF) represents a scene using a reciprocally constrained distance and density field. Unlike standard NeRF, NeDDF predicts a distance field $D$ and derives density $\sigma$ from its first spatial derivative, allowing for boundaryless scenes.

### [LAENeRF](15738-laenerf.md)
LAENeRF is a unified framework for the photorealistic and non-photorealistic local appearance editing of pre-trained NeRFs. It uses a 3D edit grid for spatial selection and learns a palette-based color decomposition mapped from estimated ray terminations.

### [ExtremeNeRF](15739-extremenerf.md)
ExtremeNeRF is a few-shot view synthesis framework designed to generate novel views from sparse multi-view images captured under unconstrained, varying illumination. It achieves illumination robustness by enforcing multi-view albedo consistency.

### [Conditional and Latent Representations](15989-conditional-and-latent-representations.md)
This family extends standard NeRF architectures by conditioning the volumetric function on external latent codes or explicit deformations. It solves the problem of static scene representation by enabling the synthesis of novel instances from a learned category distribution.

### [ActiveNeRF Model Architecture](16203-activenerf-model-architecture.md)
ActiveNeRF extends the standard NeRF architecture by incorporating uncertainty estimation into the radiance field representation. It differs from siblings by explicitly modeling the predictive variance of the MLP outputs as a distinct scalar field alongside density and color.

### [SCARF](16591-scarf.md)
SCARF is a memory-efficient continual learning framework that represents multiple 3D scenes within a single neural network. It sets itself apart by factorizing the NeRF MLP weights into scene-specific and cross-scene shared components generated by a hypernetwork.

### [PL-NeRF](18117-pl-nerf.md)
PL-NeRF is a specialized NeRF architecture for the 3D reconstruction of thin, low-texture structures. It addresses discontinuity and jagged edges by combining spatial compression via the $L_\infty$ norm, Hash Encoding (HE) for positions, and Integrated Positional Encoding (IPE) for directions.

### [Separate Modeling of Colors and Volume Density](18161-separate-modeling-of-colors-and-volume-density.md)
This method addresses overfitting and artifacts by decoupling the prediction of volume density and color into two distinct neural network branches. It employs separate MLPs with different positional encoding frequencies, prioritizing low-frequency information for geometry.

### [Network Structure Modifications](20497-network-structure-modifications.md)
This family encompasses modifications to the neural network architectures used in NeRFs to map spatial coordinates and viewing directions to radiance field properties. They set themselves apart from the baseline by introducing specialized components like blend weight fields, residual networks, or multi-input multi-output structures.

### [Neural blend weight field network](21760-neural-blend-weight-field-network.md)
The neural blend weight field network predicts residual skeletal blend weights for dynamic human body animation. It enables the deformation of a canonical radiance field into novel poses by providing the weights necessary to linearly blend skeletal transformations.

### PIE-NeRF
PIE-NeRF is a pipeline integrating physics-based elastodynamic simulation with a neural radiance field representation, using a meshless discretisation based on quadratic generalized moving least squares on top of the density field of a NeRF [S1]. It enables large deformations and nonlinear hyperelastic material simulation directly on the implicit representation and supports interactive manipulation of real-world captured scenes with complex geometries [S1].

### DäRF Implementation Details
DäRF is implemented based on K-planes [36] as NeRF [S2, unofficial]. It uses DPThybrid [38] as the MDE model and Adam [21] as an optimizer, with a learning rate of $1 \cdot 10^{-2}$ for NeRF and $1 \cdot 10^{-5}$ for the MDE, along with a cosine warmup learning rate scheduling [S2, unofficial].

### S3-NeRF
S3-NeRF is a method using shadow and shading cues to infer scene geometry and enable single-image NeRF training [S1]. It employs a UNISURF-based occupancy field 3D representation instead of density, a modified physics-based rendering equation, and occupancy-based shadow calculation as key implementation differences [S1].

### NeRF with Frozen DINO Features
NeRF with Frozen DINO Features integrates pre-trained DINOv2 features by projecting them to match NeRF input dimensions and concatenating them with positional encodings before feeding into the NeRF MLP [S3, unofficial]. The DINO model is pre-trained on ImageNet and frozen during training [S3, unofficial]. Features are projected to 256 dimensions using $f'(x) = W_f \cdot f(x) + b_f$ [S3, unofficial].

### NeRF-Swin
NeRF-Swin is a baseline method that performs super-resolution on an LR NeRF using released SwinIR models under the 'Real-World Image Super-Resolution' setting, trained on more than 10k LR-HR pairs [S4]. On synthetic Blender dataset, SwinIR may produce false predictions due to domain mismatch [S4]. On real-world LLFF dataset, SwinIR tends to be oversmooth and may predict false color or geometry [S4]. Metrics: Blender ×2 (100x100): PSNR 26.34, SSIM 0.913, LPIPS 0.075; Blender ×4 (100x100): PSNR 24.85, SSIM 0.881, LPIPS 0.108; Blender ×2 (200x200): PSNR 28.03, SSIM 0.926, LPIPS 0.058; Blender ×4 (200x200): PSNR 26.78, SSIM 0.906, LPIPS 0.086; LLFF ×2: PSNR 25.18, SSIM 0.793, LPIPS 0.147; LLFF ×4: PSNR 23.26, SSIM 0.685, LPIPS 0.247 [S4].

### Neural Architecture Search for NeRF
Neural Architecture Search for NeRF trains NeRFs with different combinations of network depth and width on a volumetric video frame and measures the quality of images rendered using Peak Signal-to-Noise Ratio (PSNR) [S5]. Network depth provides the ability to learn hierarchical representations, while network width provides the capacity to 'memorize' the training data [S5]. Reducing width monotonically decreases quality, while reducing depth first improves then drops quality if smaller than 2 [S5].

### Deformable NeRF
Not given in the sources.

### Multi-Identity NeRF
Multi-Identity NeRF is a neural rendering method that learns a single network to represent multiple identities by modeling multiplicative interactions between facial expressions and identity codes, enabling expression transfer and lip-syncing across unseen identities [S6, unofficial]. It leverages information from multiple identities for more accurate lip synchronization compared to single-identity methods [S6, unofficial]. The identity code dimension $d$ is set to 16 [S6, unofficial].

### IntrinsicNeRF Model Architecture
IntrinsicNeRF is a model that outputs reflectance, shading, and residual terms for real-time augmented applications [S7]. It is trained using unsupervised prior and reflectance clustering as constraints in the loss function [S7].

### Piecewise Linear NeRF
Piecewise Linear NeRF is a NeRF variant that uses a piecewise linear opacity formulation for volume rendering, replacing the standard piecewise constant opacity assumption [S8]. It optimizes separate networks for coarse and fine models, jointly trained with MSE loss on ground truth images [S8]. Batch size: 1024 rays; Learning rate: $5 \times 10^{-4}$, decaying exponentially to $5 \times 10^{-5}$; Training iterations: 500k per scene; Coarse samples: 128; Fine samples: 64; Hardware: Single Nvidia V100 GPU [S8]. It outperforms vanilla NeRF in all metrics (PSNR, SSIM, LPIPS) on Blender and LLFF datasets [S8].

## Background
The standard NeRF architecture, introduced by Mildenhall et al. [1], established the paradigm of representing scenes as continuous volumetric functions using two MLPs. Subsequent research has focused on modifying this architecture to address issues such as slow training, limited generalization, inability to handle dynamic scenes, and lack of semantic understanding. The family of Model Architecture Modifications has grown to include methods that integrate external priors, decouple geometry and appearance, and replace implicit representations with explicit structures.
