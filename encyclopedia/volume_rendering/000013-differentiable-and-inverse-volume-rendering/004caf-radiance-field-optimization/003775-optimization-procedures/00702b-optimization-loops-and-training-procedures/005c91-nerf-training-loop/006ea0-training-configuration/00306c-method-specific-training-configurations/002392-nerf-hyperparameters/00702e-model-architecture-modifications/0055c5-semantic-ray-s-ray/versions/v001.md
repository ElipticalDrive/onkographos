# Semantic Ray (S-Ray)

Also called: S-Ray, Semantic Ray with Cross-Reprojection Attention

## Overview
Semantic Ray (S-Ray) is a method for learning a generalizable semantic field that infers semantic labels on novel viewpoints across unseen scenes, addressing the overfitting and lack of generalization inherent in single-scene methods like Semantic-NeRF [S1]. It distinguishes itself by decomposing dense attention into intra-view radial and cross-view sparse attentions to efficiently exploit semantic context from multiple reprojected views, enabling a unified model trained on multiple scenes to generalize to new ones [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ input views with known camera poses (source views) and a query ray $\mathbf{r}$ from a novel viewpoint.
*   **Outputs:** A rendered semantic label $\hat{S}(\mathbf{r})$ and density $\sigma$ for the query ray.

**Data Structures:**
*   **Contextual Space $M$:** A matrix of shape $m \times N \times C$, where $m$ is the number of source views, $N$ is the number of sampled quadrature points along the ray, and $C$ is the channel dimension. It is structured as $M = [F_1, F_2, \dots, F_m]^T$, where each $F_i \in \mathbb{R}^{N \times C}$ represents the radial feature in the $i$-th view.
*   **Radial Feature $F_i$:** A matrix where the $k$-th row corresponds to the feature at the $k$-th sampled point along the reprojected ray in view $i$, denoted as $F_i(r^*(z_k))$.

**Parameters:**
*   $N$: Number of random quadrature points between near plane $t_n$ and far plane $t_f$ used to approximate continuous integration.
*   $H$: Number of heads in the intra-view radial attention module.
*   $t_n, t_f$: Near and far clipping planes for ray sampling.
*   $\delta_k = t_{k+1} - t_k$: Interval between sampled points.

**Algorithm Steps:**

1.  **Build Initial 3D Contextual Space:**
    For the query ray $\mathbf{r}$, reproject the ray to each of the $m$ source views. Since the emitted ray is virtual, it does not map to a single exact point but defines a reprojected ray in each view, modeling reprojection uncertainty. Apply a CNN-based module to extract contextual features for the sampled points along these reprojected rays, constructing the initial contextual space $M$.

2.  **Refine Contextual Space via Cross-Reprojection Attention:**
    Decompose the dense attention over $M$ into two lightweight modules to reduce computational cost:
    *   **Intra-view Radial Attention:** For each view $i$, compute attention among the $N$ sampled points within $F_i$. This learns relations among points along the ray direction in a single view.
    *   **Cross-view Sparse Attention:** Distinguish the same physical point across different viewpoints and score the semantic contribution of each view. This aggregates information from all $m$ views.
    The output is a refined contextual space.

3.  **Semantic Ray Construction:**
    Adopt a **Semantic-Aware Weight Net** to learn the significance (weight) of each view's contribution to the semantic ray. This net processes the refined contextual space to produce view-specific weights, constructing the final semantic ray representation.

4.  **Semantic Ray Rendering:**
    Leverage a **Geometry-Aware Net** to predict the density $\sigma$ and the semantic color $c$ (or label feature) for each sample point along the query ray. Render the final semantic label using volume rendering integration.

**Formulas:**

The continuous integration for rendering is approximated by a summation of discrete samples [S1]:

$$
\hat{C}(\mathbf{r}; \theta) = \sum_{k=1}^{N} T(t_k) \alpha(\sigma(t_k) \delta_k) c(t_k)
$$

where:
*   $T(t_k) = \exp \left( - \sum_{k'=1}^{k-1} \sigma(t_{k'}) \delta_{k'} \right)$ is the accumulated transmittance.
*   $\alpha(x) = 1 - \exp(-x)$ is the opacity function.
*   $\delta_k = t_{k+1} - t_k$ is the distance between adjacent samples.

The **Intra-view Radial Attention** with $H$ heads is formulated as standard scaled dot-product attention [S1]:

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

where $Q, K, V$ are derived from the radial feature matrix $F_i \in \mathbb{R}^{N \times C}$.

**Pseudocode:**

```python
def semantic_ray_rendering(input_views, query_ray, camera_poses, model):
    """
    Renders semantic labels for a query ray using the S-Ray method.
    
    Args:
        input_views: List of m input images (source views).
        query_ray: Ray origin o and direction d for the novel view.
        camera_poses: Poses of the m input views.
        model: Contains CNN feature extractor, Cross-Reprojection Attention, 
               Semantic-Aware Weight Net, and Geometry-Aware Net.
               
    Returns:
        semantic_label: Rendered semantic label for the ray.
        density: Rendered density for the ray.
    """
    m = len(input_views)
    N = model.num_samples  # N quadrature points
    
    # 1. Build Initial 3D Contextual Space
    # Reproject query ray to each source view and extract features
    # M shape: (m, N, C)
    M = build_initial_contextual_space(input_views, query_ray, camera_poses, model.cnn_extractor)
    
    # 2. Refine Contextual Space via Cross-Reprojection Attention
    # Decompose M into intra-view and cross-view attention
    M_refined = cross_reprojection_attention(M, model.cross_reproj_attn)
    
    # 3. Semantic Ray Construction
    # Learn view significance weights
    # weights shape: (m, 1) or (m,) depending on implementation
    view_weights = semantic_aware_weight_net(M_refined, model.semantic_weight_net)
    
    # 4. Semantic Ray Rendering
    # Sample points along the query ray
    t_vals = sample_quadrature_points(query_ray.origin, query_ray.direction, N)
    
    densities = []
    semantic_features = []
    
    for t in t_vals:
        # Query geometry-aware net for density and semantic feature at point t
        # The net takes the refined contextual context and the 3D position t
        sigma, c = geometry_aware_net(t, M_refined, view_weights, model.geometry_net)
        densities.append(sigma)
        semantic_features.append(c)
        
    # Volume Rendering Integration
    # Compute transmittance T(t_k)
    transmittance = compute_transmittance(densities)
    
    # Compute opacity alpha
    alphas = [1 - exp(-sigma * delta) for sigma, delta in zip(densities, get_intervals(t_vals))]
    
    # Weighted sum for semantic label
    # Note: c(t_k) is the semantic feature/color at sample k
    semantic_label = sum(transmittance[k] * alphas[k] * semantic_features[k] for k in range(N))
    
    density_rendered = sum(transmittance[k] * alphas[k] for k in range(N))
    
    return semantic_label, density_rendered

def build_initial_contextual_space(input_views, query_ray, camera_poses, cnn_extractor):
    """
    Reprojects the query ray to source views and extracts features.
    Returns M of shape (m, N, C).
    """
    m = len(input_views)
    N = cnn_extractor.num_samples
    M = zeros((m, N, cnn_extractor.channel_dim))
    
    for i in range(m):
        # Reproject ray to view i
        # This yields a ray in view i's coordinate system, not a single point
        reprojected_ray = reproject_ray(query_ray, camera_poses[i])
        
        # Sample points along the reprojected ray
        # Extract features using CNN-based module
        # The CNN processes the view image and the ray's projection to get contextual features
        features = cnn_extractor.extract_features(input_views[i], reprojected_ray)
        M[i] = features  # Shape (N, C)
        
    return M

def cross_reprojection_attention(M, attn_module):
    """
    Applies intra-view radial and cross-view sparse attention.
    """
    # Intra-view radial attention: process each view's features independently
    # M_intra shape: (m, N, C)
    M_intra = attn_module.intra_view_attention(M)
    
    # Cross-view sparse attention: aggregate across views
    # M_refined shape: (m, N, C)
    M_refined = attn_module.cross_view_attention(M_intra)
    
    return M_refined

def compute_transmittance(densities):
    """
    Computes accumulated transmittance T(t_k).
    T(t_k) = exp(-sum_{j=0}^{k-1} sigma_j * delta_j)
    """
    N = len(densities)
    T = zeros(N)
    T[0] = 1.0
    current_exp = 0.0
    for k in range(1, N):
        # delta_k is assumed to be available or computed from t_vals
        delta = get_interval(k) 
        current_exp += densities[k-1] * delta
        T[k] = exp(-current_exp)
    return T
```

## Operating characteristics
*   **Time Complexity:** The decomposition of dense attention into intra-view radial and cross-view sparse attention reduces computational cost compared to performing dense attention over all $m \times N$ points [S1].
*   **Memory Complexity:** Lower than dense attention methods due to the sparse nature of the cross-view module and radial decomposition [S1].
*   **Performance:** S-Ray achieves comparable quality to Semantic-NeRF's result for 100k iterations per-scene optimization by fine-tuning on more images for only 10 minutes (2k iterations) [S1].
*   **Strengths:** Generalizes to unseen scenes; exploits rich semantic context from multiple views; efficient computation via attention decomposition.
*   **Limitations:** Relies on accurate reprojection; performance may degrade if reprojection uncertainty is not modeled well; requires multiple input views.
*   **When to use:** When generalizing semantic segmentation to novel scenes from multiple input views is required.
*   **When not to use:** For single-scene optimization where per-scene tuning is acceptable and generalization is not needed (Semantic-NeRF might be simpler).

## Background
*   **Origin:** Introduced by Fangfu Liu, Chubin Zhang, Yu Zheng, and Yueqi Duan from Tsinghua University in March 2023 [S1].
*   **History:** Proposed to address the limitations of Semantic-NeRF, which relies on positional encoding and trains one model per scene, leading to overfitting and poor generalization [S1]. S-Ray builds on generalizable NeRF architectures like MVSNeRF and NeuRay [S1].
*   **Usage:** Evaluated on synthetic scenes from the Replica dataset and real-world scenes from the ScanNet dataset [S1].
