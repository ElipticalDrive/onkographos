# StyleNeRF Architecture Configuration

Also called: StyleNeRF hyperparameters

## Overview
StyleNeRF extends the original Neural Radiance Field (NeRF) architecture by integrating a style-based generator to handle illumination changes and synthesize high-resolution images [S1, unofficial]. It reuses the architecture and default parameters of StyleGAN2 for its mapping network and discriminator [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** Camera parameters, 3D coordinates, and a latent style vector.
- **Outputs:** Volume density ($\sigma$) and view-dependent color ($c$).

**Data Structures and Parameters:**
- **Mapping network:** 8 fully connected layers [S1, unofficial].
- **Latent and style dimensions:** 512 [S1, unofficial].
- **Foreground field MLP hidden units:** 256 [S1, unofficial].
- **Background field MLP hidden units:** 128 [S1, unofficial].
- **Fourier feature dimension:** $L=10$ [S1, unofficial].
- **Feature sizes after 2D aggregation:** Decrease from 512 (for 32×32) to 32 (for 1024×1024) [S1, unofficial].
- **Learning rate:** The mapping network uses a learning rate $100\times$ lower than the default [S1, unofficial].
- **Batch size:** 64 [S1, unofficial].
- **Training iterations:** 25,000 images [S1, unofficial].

**Pseudocode:**
```python
def configure_stylenrf():
    """
    Returns the architecture configuration for StyleNeRF based on StyleGAN2 defaults.
    """
    config = {
        "mapping_network_layers": 8,
        "latent_dim": 512,
        "style_dim": 512,
        "foreground_mlp_hidden_units": 256,
        "background_mlp_hidden_units": 128,
        "fourier_feature_dim": 10,
        "feature_sizes_after_2d_aggregation": {
            32: 512,
            64: 256,
            128: 128,
            256: 64,
            512: 32,
            1024: 32
        },
        "mapping_network_lr_multiplier": 0.01,
        "batch_size": 64,
        "total_training_images": 25000
    }
    return config
```

## Subtopics

### NeRF Network Architecture with Appearance Code
An extension of the original NeRF network architecture that adds a low-dimensional appearance code to handle illumination changes [S2, unofficial]. The appearance code is 16-dimensional, added to the second last layer of the NeRF network $F_\phi$, and is individually stored and optimized for every frame [S2, unofficial]. NeuralBody baselines use 128-dimensional codes, whereas A-NeRF uses 16-dimensional codes to help learning global effects without deteriorating the benefits of relative encoding [S2, unofficial].

## Operating characteristics
- **Time complexity:** Training takes approximately three days on 8 Tesla V100 GPUs for 25,000 images with a batch size of 64 [S1, unofficial].
- **Memory complexity:** Not given in the sources.
- **Strengths:** Handles illumination changes effectively and generates high-resolution images up to 1024×1024 [S1, unofficial].

## Background
StyleNeRF was proposed in "StyleNeRF: A Style-based 3D-Aware Generator for High-resolution Image Synthesis" [S1, unofficial]. It builds on the original NeRF architecture and concurrent works on handling illumination changes [S2, unofficial]. The architecture reuses parameters from StyleGAN2 [S1, unofficial].
