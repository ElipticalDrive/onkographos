# Anchor-Based RPN Configuration

Also called: Anchor Sampling Configuration, RPN Anchor Setup

## Overview
This method configures the Region Proposal Network (RPN) for object detection within NeRFs by defining a structured set of 3D bounding box anchors and a sampling strategy for loss computation [S1]. It differs from anchor-free variants by explicitly generating proposals from a predefined grid of aspect ratios and scales, requiring a positive/negative sampling ratio to balance the optimization signal [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Scene feature pyramid levels, anchor hyperparameters (aspect ratios, scales), and ground truth bounding boxes [S1].
*   **Output:** A set of 256 sampled anchors with binary labels (positive/negative) used to compute the RPN loss [S1].

**Data Structures:**
1.  **Feature Pyramid Network (FPN):** Consists of 4 levels [S1].
2.  **Anchor Set:** Defined per FPN level.
    *   **Aspect Ratios:** 13 distinct 3D aspect ratios: $1:1:1$, $1:1:2$, $1:1:3$, $2:2:1$, $3:3:1$, and all permutations thereof [S1].
    *   **Scale:** Anchors on the same FPN level share the same shortest side length $s \in \{8, 16, 32, 64\}$, assigned from fine to coarse scales respectively [S1].

**Algorithm Steps:**
1.  **Generate Anchors:** For each of the 4 FPN levels, generate a grid of 3D bounding boxes using the scale $s$ for that level and one of the 13 aspect ratios [S1].
2.  **Sample Anchors:** Randomly select 256 anchors from the total set of generated anchors for the current scene in each training iteration [S1].
3.  **Label Anchors:** Assign binary labels to the sampled anchors, maintaining a 1:1 ratio of positive to negative anchors [S1].
4.  **Compute Loss:** Calculate the RPN loss using the labeled anchors, optimized with AdamW (initial learning rate 0.0003, weight decay 0.001) [S1].

**Parameters:**
*   **FPN Levels:** 4 [S1].
*   **Anchor Count per Iteration:** 256 [S1].
*   **Positive/Negative Ratio:** 1:1 [S1].
*   **Shortest Side Lengths:** $\{8, 16, 32, 64\}$ [S1].
*   **Optimizer:** AdamW [S1].
*   **Learning Rate:** 0.0003 [S1].
*   **Weight Decay:** 0.001 [S1].

**Pseudocode:**
```python
import random

def configure_anchor_rpn(fpn_levels=4, anchor_scales=[8, 16, 32, 64], aspect_ratios=[
    (1,1,1), (1,1,2), (1,1,3), (2,2,1), (3,3,1)
]):
    """
    Generates and samples anchors for RPN training.
    """
    # 1. Generate all possible anchors across FPN levels
    all_anchors = []
    for level_idx, scale in enumerate(anchor_scales):
        for ar in aspect_ratios:
            # Create anchor with shortest side 'scale' and aspect ratio 'ar'
            # Note: The 13 ratios include all permutations of the base set [S1]
            anchor = {"level": level_idx, "scale": scale, "aspect_ratio": ar}
            all_anchors.append(anchor)

    # 2. Sample 256 anchors randomly for the current iteration
    sampled_anchors = random.sample(all_anchors, k=256)

    # 3. Label anchors (1:1 positive/negative ratio)
    # [G] Ground truth boxes and IoU calculation are required but not detailed in [S1].
    labeled_anchors = []
    pos_target = 128
    neg_target = 128
    pos_count = 0
    neg_count = 0
    for anchor in sampled_anchors:
        if pos_count < pos_target:
            label = 1  # Positive
            pos_count += 1
        elif neg_count < neg_target:
            label = 0  # Negative
            neg_count += 1
        else:
            label = 0  # Fallback
        labeled_anchors.append({"anchor": anchor, "label": label})

    return labeled_anchors
```

## Subtopics

### Anchor-Free RPN Loss Computation
Instead of sampling a fixed number of anchors, this variant uses all output proposals from the network to compute the loss [S1].

## Operating characteristics
*   **Complexity:** Fixed sampling cost of 256 anchors per iteration [S1].
*   **Performance:** Optimizes RPN outputs for object detection in NeRFs [S1].
*   **Limitations:** Not given in the sources.
*   **Hardware/Resolution:** Not given in the sources.

## Background
The method is described in the NeRF-RPN framework for object detection in NeRFs [S1]. It adapts standard RPN training strategies to 3D volumetric data [S1].
