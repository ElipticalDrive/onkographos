# Dynamic Appearance Particle Neural Radiance Field

Also called: Dynamic Appearance Particle NeRF, Lagrangian dynamic model in NeRF

## Overview
Dynamic Appearance Particle Neural Radiance Field is a method for modeling dynamic scenes from monocular video data by separating the scene into static and dynamic components [S1]. It solves the problem of reconstructing time-varying geometry and appearance without requiring multi-view stereo data at each time step, which is a constraint of sibling methods like ParticleNeRF [S1]. Unlike ParticleNeRF, which encodes the entire scene with particles and uses radius nearest neighbor searching, this method applies appearance particles only to dynamic elements and integrates them with a static grid-based field, enabling efficient querying through linear interpolation [S1].

## How it works
The method models the dynamic radiance field $V(x, t)$ as a superposition of a static component $V_s(x)$ and a dynamic component $V_{td}(x)$ [S1]. The rendering process follows the standard volume rendering integral, but the field values are determined by the particle-based dynamic model [S1].

### Inputs and Outputs
- **Inputs**: Monocular video data (a sequence of images from a single camera at different times $t$). Camera poses and intrinsics are assumed known or estimated.
- **Outputs**: A dynamic radiance field model capable of rendering novel views at arbitrary times $t$.

### Data Structures
1.  **Static Field $V_s(x)$**: A time-independent grid-based model (e.g., a canonical feature field) [S1]. The specific grid resolution and interpolation method are not detailed in the sources, but it aligns with standard grid-based NeRF representations [S1].
2.  **Dynamic Field $V_{td}(x)$**: A particle-based representation [S1].
    -   **Particles**: An ensemble of particles representing dynamic elements. Each particle has a position, velocity (for motion), and appearance features.
    -   **Kernel $W$**: A finite-support kernel used to quantize the field. $W(x) = 0$ when $\|x\|$ exceeds a small radius, and $\int W(x)d\nu(x) = 1$ [S1].

### Notation
-   $x$: 3D spatial location.
-   $t$: Time, denoted in subscripts on the right-hand side of the superposition equation (e.g., $V_{td}$) to clarify that the dynamic component consists of an ensemble of particles [S1].
-   $d$: View direction.
-   $r(s) = o + sd$: Ray equation, where $o$ is the camera center and $s$ is the distance along the ray [S1].
-   $s_n, s_f$: Near and far bounds of the ray [S1].
-   $w_t(x)$: Weight function taking value 1 if the dynamic field is effective at $(x, t)$ and 0 otherwise [S1].

### Formulas
The rendered pixel color $C(r, t)$ at time $t$ is computed by integrating along the ray [S1]:

$$
C(r, t) = \int_{s_n}^{s_f} T(s) \sigma(r(s), t) c(r(s), d, t) ds
$$

where $T(s) = \exp \left( -\int_{s_n}^{s} \sigma(r(s'), t) ds' \right)$ is the accumulated transmittance [S1].

The dynamic radiance field $V(x, t)$ is defined as the superposition [S1]:

$$
V(x, t) = (1 - w_t(x))V_s(x) + w_t(x)V_{td}(x)
$$

where $V_s(x)$ is the static field and $V_{td}(x)$ is the dynamic field [S1].

The dynamic field $V_{td}$ is formulated as a convolution with a Dirac function to integrate over finite volumes [S1]:

$$
V_{td}(x) = (V_{td} * \delta)(x) = \int V_{td}(x')\delta(x - x')d\nu(x')
$$

where $\delta(\cdot)$ is the Dirac function [S1]. For implementation, the Dirac function $\delta$ is replaced with a kernel $W$ with finite support [S1]:

$$
V_{td}(x) \approx \int V_{td}(x')W(x - x')d\nu(x')
$$

where $W(x) = 0$ when $\|x\|$ exceeds a small radius, and $\int W(x)d\nu(x) = 1$ [S1].

### Steps
1.  **Initialize Static Field**: Train a static NeRF model $V_s(x)$ on the video data, treating the scene as static or using a canonical space representation [S1].
2.  **Initialize Dynamic Particles**: Initialize particles representing dynamic elements. Each particle has position, velocity, and appearance features [S1].
3.  **Define Kernel**: Define the finite-support kernel $W$ with a small radius [S1].
4.  **Define Weight Function**: Define $w_t(x)$ to indicate the effectiveness of the dynamic field at $(x, t)$. The support of the dynamic field is implied by the particle representation [S1].
5.  **Render**: For each ray $r$ and time $t$:
    a. Sample points $r(s)$ along the ray.
    b. Query the static field $V_s(r(s))$.
    c. Query the dynamic field $V_{td}(r(s))$ using the kernel $W$ and particle features.
    d. Compute the combined field $V(r(s), t)$ using the superposition formula.
    e. Compute density $\sigma$ and color $c$ from $V(r(s), t)$.
    f. Integrate to compute $C(r, t)$.
6.  **Optimize**: Minimize the difference between rendered images and ground truth images using gradient descent. The particle motion network continuously models scene dynamics across all time frames [S1].

### Pseudocode
```python
def render_ray(ray_o, ray_d, time_t, static_field, particles, kernel_W, weight_func_wt):
    """
    Render a single ray at a specific time.
    
    Args:
        ray_o: Camera origin (3D vector).
        ray_d: Ray direction (3D vector).
        time_t: Time index.
        static_field: Function to query static field V_s(x).
        particles: List of particles, each with position, velocity, and features.
        kernel_W: Kernel function W(x) with finite support.
        weight_func_wt: Function to compute w_t(x).
        
    Returns:
        color: Rendered color for the ray.
    """
    # Sample points along the ray
    s_samples = sample_points_along_ray(ray_o, ray_d, near_bound=s_n, far_bound=s_f, num_samples=N)
    
    accumulated_transmittance = 1.0
    accumulated_color = [0.0, 0.0, 0.0]
    
    for s in s_samples:
        x = ray_o + s * ray_d
        
        # Query static field
        V_s = static_field.query(x)
        
        # Query dynamic field
        # V_td is computed by convolving particle features with kernel W
        V_td = 0.0
        for particle in particles:
            # Compute distance from particle to point x
            dist = norm(particle.position - x)
            # Compute kernel weight
            w = kernel_W(dist)
            # Accumulate particle contribution
            V_td += w * particle.features
            
        # Compute weight
        w_t = weight_func_wt(x, time_t)
        
        # Superposition
        V = (1 - w_t) * V_s + w_t * V_td
        
        # Extract density and color from V
        # Note: The exact mapping from V to sigma and c is not specified in the sources.
        # This is a placeholder for the MLP that maps V to sigma and c.
        sigma, color = field_to_sigma_color(V)
        
        # Volume rendering step
        alpha = 1.0 - exp(-sigma * delta_s) # delta_s is the distance between samples
        transmittance = accumulated_transmittance
        accumulated_color += transmittance * alpha * color
        accumulated_transmittance *= (1.0 - alpha)
        
    return accumulated_color
```

### Edge Cases and Pitfalls
-   **Precision**: The kernel $W$ has a small radius. Points far from any particle will have $V_{td} \approx 0$. The weight function $w_t(x)$ must correctly handle boundaries where the dynamic field is not effective.
-   **Degenerate Input**: The method is designed for monocular video. If multi-view data is available, the method can still be used, but it may not leverage the additional information optimally compared to multi-view methods [S1].
-   **Particle Initialization**: The initialization of particles and their motion is critical. The sources do not specify the initialization strategy, but the particle motion network is trained to model dynamics [S1].

## Background
The method was proposed in the paper "Dynamic Appearance Particle Neural Radiance Field" [S1]. It builds on the Lagrangian dynamic model and particle-based representations. It differs from ParticleNeRF, which encodes the entire scene with particles and uses radius nearest neighbor searching, and requires 20 camera views per time frame [S1]. The proposed technique is not tightly coupled to a specific architecture and can be integrated into alternative frameworks such as InstantNGP [S1].
