# LLFF Data Loading and Spiral Path Generation

Also called: Real Scene NeRF Dataset Loading

## Overview
This method loads LLFF-style datasets, corrects coordinate system conventions, rescales the scene, and generates a spiral render path for novel view synthesis [S1, unofficial]. It sets itself apart from generic loaders by enforcing specific axis corrections, bounding-box-based rescaling, and parametric spiral trajectory generation [S1, unofficial].

## How it works
**Inputs:**
- Raw poses, bounds (`bds`), and images [S1, unofficial].
- Parameters: `recenter` (bool), `bd_factor` (float, default 0.75), `spherify` (bool), `N_views` (int), `path_zflat` (bool), `zdelta` (float), `zrate` (float, default 0.5) [S1, unofficial].
- File paths for `train.txt` and `test.txt` to split data [S1, unofficial].

**Outputs:**
- Rescaled poses [S1, unofficial].
- Rescaled bounds (`bds`) [S1, unofficial].
- Spiral render poses (`render_poses`) [S1, unofficial].
- Split images and masks for training and testing [S1, unofficial].

**Data Structures:**
- Poses: $N \times 4 \times 4$ homogeneous transformation matrices [S1, unofficial].
- Bounds: $N \times 2$ array where each row is $[min\_depth, max\_depth]$ [S1, unofficial].
- Images: Tensor of shape $(N, H, W, 3)$ [S1, unofficial].

**Steps:**

1. **Load and Downsample:** Load raw poses, bounds, and images, and downsample images by a factor [S1, unofficial].
2. **Correct Rotation Ordering:** Concatenate columns $poses[:, 1:2, :]$, $-poses[:, 0:1, :]$, and $poses[:, 2:, :]$, then move axis -1 to 0 [S1, unofficial].
3. **Rescale Scene:** Compute scale factor $sc = 1 / (\min(bds) \times bd\_factor)$ if $bd\_factor$ is not None, and rescale all poses and bounds by $sc$ [S1, unofficial].
4. **Recenter (Optional):** If `recenter` is True, center the poses around the origin [S1, unofficial].
5. **Spherify (Optional):** If `spherify` is True, adjust poses to lie on a sphere and update $sc$ [S1, unofficial].
6. **Compute Average Pose and Up Vector:** If not spherify, compute the average pose $c2w = \text{poses\_avg}(poses)$ and the up vector $up = \text{normalize}(\sum poses[:, :3, 1])$ [S1, unofficial].
7. **Determine Focus Depth:** Calculate $close\_depth = \min(bds) \times 0.9$, $inf\_depth = \max(bds) \times 5.0$, $mean\_dz = 1 / ((1-0.75)/close\_depth + 0.75/inf\_depth)$, and set $focal = mean\_dz$ [S1, unofficial].
8. **Adjust Path Parameters:** If `path_zflat` is True, set $zloc = -close\_depth \times 0.1$, adjust $c2w\_path[:3, 3] += zloc \times c2w\_path[:3, 2]$, set $rads[2] = 0$, $N\_rots = 1$, and $N\_views = N\_views / 2$; else set $N\_rots = 2$ [S1, unofficial].
9. **Generate Spiral Path:** Generate render poses using $\text{render\_path\_spiral}(c2w\_path, up, rads, focal, zdelta, zrate=0.5, rots=N\_rots, N=N\_views)$ [S1, unofficial].
10. **Split Data:** Split images into training and test sets based on indices listed in `train.txt` and `test.txt` [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def load_llff_data(basedir, factor=8, recenter=True, bd_factor=0.75, spherify=False, path_zflat=True, N_views=120, zdelta=0.0, zrate=0.5):
    # 1. Load raw data
    poses, bds, imgs = load_raw_llff_data(basedir, factor)
    
    # 2. Correct rotation matrix ordering
    poses = np.concatenate([poses[:, 1:2, :], -poses[:, 0:1, :], poses[:, 2:, :]], axis=1)
    poses = np.moveaxis(poses, -1, 0)
    
    # 3. Rescale
    sc = 1.0 / (np.min(bds) * bd_factor) if bd_factor is not None else 1.0
    poses *= sc
    bds *= sc
    
    # 4. Recenter
    if recenter:
        poses = recenter_poses(poses)
        
    # 5. Spherify
    if spherify:
        poses, sc = spherify_poses(poses, bds, N_views)
        
    # 6. Average pose and up vector
    c2w = poses_avg(poses)
    up = normalize(np.sum(poses[:, :3, 1], axis=0))
    
    # 7. Focus depth
    close_depth = np.min(bds) * 0.9
    inf_depth = np.max(bds) * 5.0
    mean_dz = 1.0 / (((1 - 0.75) / close_depth) + (0.75 / inf_depth))
    focal = mean_dz
    
    # 8. Path parameters
    if path_zflat:
        zloc = -close_depth * 0.1
        c2w_path = c2w.copy()
        c2w_path[:3, 3] += zloc * c2w_path[:3, 2]
        rads = np.array([1.0, 1.0, 1.0])
        rads[2] = 0.0
        N_rots = 1
        N_views_final = N_views / 2
    else:
        c2w_path = c2w
        rads = np.array([1.0, 1.0, 1.0])
        N_rots = 2
        N_views_final = N_views
        
    # 9. Generate spiral
    render_poses = render_path_spiral(c2w_path, up, rads, focal, zdelta, zrate, N_rots, N_views_final)
    
    # 10. Split data
    i_train, i_test = load_split_indices(basedir)
    
    return poses, bds, imgs, render_poses, i_train, i_test

def recenter_poses(poses):

def spherify_poses(poses, bds, N_views):
    # Adjusts poses to lie on a sphere [G]

def poses_avg(poses):
    # Computes average pose [G]
    center = np.mean(poses[:, :3, 3], axis=0)
    rot = poses[:, :3, :3]
    avg_rot = np.mean(rot, axis=0)
    # Re-orthogonalize rotation matrix [G]
    U, S, Vt = np.linalg.svd(avg_rot)
    avg_rot = U @ Vt
    pose_avg = np.eye(4)
    pose_avg[:3, :3] = avg_rot
    pose_avg[:3, 3] = center
    return pose_avg

def normalize(v):
    return v / np.linalg.norm(v)

def render_path_spiral(c2w_path, up, rads, focal, zdelta, zrate, rots, N):
    # Generates poses along a spiral trajectory [G]
    poses = []
    for i in range(int(N)):
        t = i / N
        theta = 2 * np.pi * rots * t
        phi = np.pi / 2 + (np.pi / 2) * np.sin(theta)
        x = rads[0] * np.cos(theta) * np.cos(phi)
        y = rads[1] * np.sin(theta) * np.cos(phi)
        z = rads[2] * np.sin(phi) + zdelta * t
        pos = c2w_path[:3, 3] + x * c2w_path[:3, 0] + y * c2w_path[:3, 1] + z * c2w_path[:3, 2]
        pose = np.eye(4)
        pose[:3, 3] = pos
        poses.append(pose)
    return np.array(poses)
```

**Edge Cases and Pitfalls:**
- **Precision:** Rescaling by `bd_factor` can lead to numerical instability if `bds.min()` is very small [G]. Ensure `bd_factor` is not zero.
- **Boundaries:** If `bds` contains zeros or negative values, `close_depth` calculation may fail [G]. Clamp `bds` to positive values before processing.
- **Degenerate Input:** If `N_views` is odd and `path_zflat` is True, integer division `N_views / 2` may lose a view [G]. Handle odd `N_views` explicitly if needed.
