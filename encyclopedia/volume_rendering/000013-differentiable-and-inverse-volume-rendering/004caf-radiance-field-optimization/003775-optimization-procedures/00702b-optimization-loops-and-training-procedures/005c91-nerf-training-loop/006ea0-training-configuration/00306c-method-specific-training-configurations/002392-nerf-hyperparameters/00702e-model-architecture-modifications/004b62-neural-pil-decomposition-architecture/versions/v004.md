# Neural-PIL Decomposition Architecture

Also called: Coarse and Decomposition Networks, Neural-PIL Decomposition

## Overview
The Neural-PIL Decomposition Architecture addresses the problem of reflectance decomposition in novel view synthesis under varying illumination, where standard NeRF models fail to disentangle geometry, material, and lighting [S1, unofficial]. It sets itself apart from sibling methods by explicitly modeling the rendering pipeline as a two-stage process: a **coarse network** that predicts view- and illumination-conditioned colors, and a **decomposition network** that estimates density, BRDF parameters, and surface normals, utilizing a learned **Neural Pre-Integrated Lighting (Neural-PIL)** module to efficiently compute shading [S1, unofficial]. Unlike standard volume rendering that integrates color samples along a ray, this method computes an expected ray termination point and renders only at that specific location, leveraging explicit BRDF and normal estimates [S1, unofficial].

## How it works

### Inputs and Outputs
*   **Inputs:** 3D spatial position $\mathbf{x} \in \mathbb{R}^3$, viewing direction $\boldsymbol{\omega}_o \in \mathbb{R}^3$, and an illumination embedding $\mathbf{z}_l$.
*   **Outputs:** Volume density $\sigma$, view-dependent color $\mathbf{c}$, BRDF embedding $\mathbf{z}_b \in \mathbb{R}^4$, and surface normal $\mathbf{n}$.

### Data Structures
The architecture consists of two primary neural networks and two frozen auto-encoder modules:
1.  **Coarse Network ($\Phi_{coarse}$):** An MLP taking $(\mathbf{x}, \boldsymbol{\omega}_o, \mathbf{z}_l)$ and outputting $(\sigma, \mathbf{c})$. It predicts illumination-conditioned colors.
2.  **Decomposition Network ($\Phi_{decomp}$):** An MLP taking $\mathbf{x}$ and outputting density $\sigma$ and BRDF embedding $\mathbf{z}_b \in \mathbb{R}^4$.
3.  **Light-SMAE:** A frozen auto-encoder that maps environment maps to a latent manifold.
4.  **BRDF-SMAE:** A frozen auto-encoder that maps BRDF parameters to a latent manifold $\mathbf{z}_b$.
5.  **Neural-PIL:** A network trained to approximate pre-integrated lighting $\tilde{L}_i(\boldsymbol{\omega}_r, \mathbf{b})$, conditioned on roughness and viewing geometry.

### Rendering Process
The rendering process differs from standard volumetric integration by decoupling geometry estimation from shading calculation [S1, unofficial].

1.  **Ray Termination Estimation:**
    Compute the expected termination distance $t^*$ along a camera ray by integrating sample densities $\sigma(t)$ along the ray, similar to computing a depth map [S1, unofficial].
    $$ t^* = \frac{\sum_i t_i \sigma_i \Delta t_i}{\sum_i \sigma_i \Delta t_i} $$
    *(Note: The exact weighting formula is not specified in the source text beyond "similar to depth map", but standard expected distance is implied.)*

2.  **Normal Estimation:**
    At the termination position $\mathbf{x}^*$, estimate the surface normal $\mathbf{n}$ by computing the gradient of the density output by the decomposition network with respect to the input position [S1, unofficial]:
    $$ \mathbf{n} = \frac{\nabla_{\mathbf{x}} \sigma(\mathbf{x})}{\|\nabla_{\mathbf{x}} \sigma(\mathbf{x})\|} $$
    Gradients are computed by passing backpropagation through $\Phi_{decomp}$.

3.  **BRDF Parameter Extraction:**
    Convert the BRDF embedding $\mathbf{z}_b$ predicted by $\Phi_{decomp}$ into explicit BRDF parameters $\mathbf{b}$ using the decoder of the frozen BRDF-SMAE [S1, unofficial].

4.  **Illumination Computation (Neural-PIL):**
    Compute the pre-integrated illumination $\tilde{L}_i(\boldsymbol{\omega}_r, \mathbf{b})$ using the Neural-PIL network. This network approximates the costly numerical integration of incoming light over the hemisphere, conditioned on the BRDF parameters $\mathbf{b}$ and the reflection direction $\boldsymbol{\omega}_r$ [S1, unofficial].

5.  **Shading:**
    Render the final color $\mathbf{c}$ using the estimated BRDF $\mathbf{b}$, normal $\mathbf{n}$, and pre-integrated illumination $\tilde{L}_i$. The source references "Equation 2" for this step, which typically corresponds to a standard rendering equation form:
    $$ \mathbf{c} = f_r(\boldsymbol{\omega}_o, \boldsymbol{\omega}_r, \mathbf{b}) \cdot \tilde{L}_i(\boldsymbol{\omega}_r, \mathbf{b}) $$
    where $f_r$ is the BRDF defined by parameters $\mathbf{b}$ [S1, unofficial].

### Training Protocol
The training occurs in distinct phases to manage memory and stability [S1, unofficial]:

1.  **Pre-training Manifolds:**
    Train Light-SMAE and BRDF-SMAE independently using datasets of environment maps and BRDFs, respectively. Freeze these networks after training.

2.  **Neural-PIL Training:**
    Train the Neural-PIL network using the latent manifold created by the frozen Light-SMAE encoder. This separates the lighting approximation learning from the scene-specific optimization [S1, unofficial].

3.  **Joint Scene Optimization:**
    Jointly optimize the Coarse Network and Decomposition Network on scene images.
    *   **Optimization Variables:** The illumination embedding $\mathbf{z}_l$ is optimized via the decomposition network.
    *   **Constraint:** The loss signal is **not** backpropagated to the illumination inputs in the coarse network. Only $\mathbf{z}_l$ is updated [S1, unofficial].

### Pseudocode

```python
def render_ray_coarse(ray_origin, ray_direction, coarse_net, z_l):
    """
    Standard coarse network evaluation for initial color/density prediction.
    Note: This network does not receive gradient updates for z_l during joint optimization.
    """
    # Sample points along the ray
    points = sample_points_along_ray(ray_origin, ray_direction)
    # Flatten for MLP input
    points_flat = points.reshape(-1, 3)
    directions_flat = np.tile(ray_direction, (len(points), 1))
    
    # Forward pass through Coarse Network
    # Input: x, omega_o, z_l
    sigma, c = coarse_net(points_flat, directions_flat, z_l)
    return sigma, c

def render_ray_decomposition(ray_origin, ray_direction, decomp_net, 
                             brdf_smae_decoder, neural_pil_net, z_l):
    """
    Decomposition-based rendering with Neural-PIL.
    """
    # 1. Estimate density along ray to find termination
    points = sample_points_along_ray(ray_origin, ray_direction)
    points_flat = points.reshape(-1, 3)
    
    # Forward pass through Decomposition Network
    # Input: x
    sigma, z_b = decomp_net(points_flat)
    
    # 2. Compute expected termination distance (depth-like)
    # Assuming uniform step size dt
    dt = points[1] - points[0] # Approximate step size
    weights = sigma * dt
    t_star = np.sum(points * weights) / np.sum(weights)
    
    # 3. Get position at termination
    x_star = ray_origin + t_star * ray_direction
    
    # 4. Estimate Normal via gradient of density w.r.t x
    # Compute gradient numerically or via autograd
    sigma_x_star, _ = decomp_net(x_star.reshape(1, -1))
    # Gradient of sigma w.r.t x
    grad_sigma = compute_gradient(decomp_net, x_star, output_index=0)
    n = grad_sigma / np.linalg.norm(grad_sigma)
    
    # 5. Convert BRDF embedding to parameters
    b = brdf_smae_decoder(z_b)
    
    # 6. Compute Pre-Integrated Illumination
    # Neural-PIL takes roughness (from b) and reflection direction
    # omega_r is the reflection of view direction about normal
    omega_r = reflect(ray_direction, n)
    L_tilde = neural_pil_net(omega_r, b)
    
    # 7. Render Color using BRDF and Illumination
    # Equation 2: c = f_r(omega_o, omega_r, b) * L_tilde
    # f_r is the BRDF function defined by parameters b
    c = brdf_eval(b, ray_direction, omega_r) * L_tilde
    
    return c, sigma, n

def train_jointly(scene_images, coarse_net, decomp_net, 
                  brdf_smae_decoder, neural_pil_net, light_smae_encoder):
    """
    Joint optimization step.
    """
    for image in scene_images:
        # Forward pass through decomposition network to get z_l update
        # Note: z_l is treated as a learnable parameter per scene or per ray group
        # The source specifies optimizing z_l via decomposition network
        
        # Render using decomposition method
        c_pred, sigma, n = render_ray_decomposition(...)

        loss = compute_loss(c_pred, image)
        
        # Backpropagate loss
        # CRITICAL: Do NOT backpropagate to illumination in coarse network
```

### Parameters and Edge Cases
*   **BRDF Embedding Size:** $\mathbf{z}_b \in \mathbb{R}^4$ [S1, unofficial].
*   **Illumination Embedding:** $\mathbf{z}_l$ is optimized per scene or per ray group, not backpropagated to the coarse network's input layer [S1, unofficial].
*   **Normal Estimation:** Relies on the density gradient from the decomposition network. Degenerate cases where $\nabla \sigma \approx 0$ will result in undefined normals; a small epsilon guard is required [G].
*   **Ray Termination:** The method assumes a dominant surface or thin geometry where a single termination point is sufficient. Thick volumes or participating media are not explicitly handled by the single-point termination strategy [S1, unofficial].

## Operating characteristics

*   **Time Complexity:** Rendering is faster than Monte Carlo integration because it avoids sampling the light hemisphere. However, it requires two network forward passes (coarse for initial estimate, decomposition for shading) and gradient computation for normals.
*   **Memory Complexity:** Higher than standard NeRF due to the additional decomposition network, Neural-PIL network, and the storage of BRDF embeddings $\mathbf{z}_b$ and illumination embeddings $\mathbf{z}_l$ [S1, unofficial].
*   **Strengths:** Explicitly handles varying illumination by decoupling lighting from geometry and material. The Neural-PIL module provides a differentiable, efficient approximation of pre-integrated lighting [S1, unofficial].
*   **Limitations:** The single-point termination strategy may fail for complex volumetric scenes or thick objects. The reliance on frozen SMAE manifolds limits the range of representable BRDFs and lighting conditions to those seen in the pre-training datasets [S1, unofficial].

## Background

The Neural-PIL Decomposition Architecture was introduced in the paper "Neural-PIL: Neural Pre-Integrated Lighting for Reflectance Decomposition" [S1, unofficial]. It extends the standard NeRF framework [S1, unofficial] by incorporating reflectance decomposition techniques. The method builds on the concept of separating illumination, geometry, and material properties, which is challenging in standard NeRF where these are entangled in the color output. The use of Smooth Manifold Auto-Encoders (SMAE) for BRDF and lighting representation is a key innovation from this work [S1, unofficial].
