# Model Architecture Modifications

Also called: NeRF Architecture Variants, Implicit Representation Modifications

## Overview
Model Architecture Modifications extend the standard Neural Radiance Field (NeRF) framework by altering the underlying neural network structure, input conditioning, or geometric representation to address specific limitations such as dynamic scenes, sparse views, transparency, or computational efficiency. Unlike standard NeRF, which uses a static Multi-Layer Perceptron (MLP) to map 3D coordinates and view directions to density and color, these methods introduce auxiliary heads, discrete representations, temporal dependencies, or external priors. They set themselves apart from sibling methods like [NeRF Initialization Strategies](8674-nerf-initialization-strategies.md) (which focus on weight initialization) or [Regularization Techniques](11314-regularization-techniques.md) (which focus on loss functions) by fundamentally changing the model's capacity to represent scene attributes.

## Shared principles
The standard NeRF architecture [S6] consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$.

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation.
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs).

## Subtopics

### [DoF-NeRF](9432-dof-nerf.md)
DoF-NeRF extends the standard NeRF architecture to simulate depth-of-field effects by explicitly modeling the aperture and focus distance. It differs from standard NeRF by introducing two learnable scalar parameters per training view: the aperture parameter $K$ and the focus distance $F$. These are jointly optimized with the NeRF network parameters. The method computes observed colors based on the Circle of Confusion (CoC) diameter $\delta(h_t) = K \times |1/F - 1/h_t|$, where $h_t$ is the object distance. It is chosen when the input images are captured with shallow depth-of-field and the goal is to recover an all-in-focus 3D representation.

### [NeRF-VPT](11770-nerf-vpt.md)
NeRF-VPT is a cascading view prompt tuning paradigm that enhances image quality by using RGB information from preceding rendering iterations as visual prompts. It differs from standard NeRF by iteratively refining the network's output, where each stage $i$ concatenates the positional encoding, direction encoding, and the RGB prompt $\mathbf{c}(r)_{i-1}$ from the previous stage. This placement is chosen because color is high-frequency data and direction information induces diverse color variations. It is chosen when scene understanding is limited in sparse-view settings and a plug-and-play refinement is required.

### [Activation Feature Density Approximation](12492-activation-feature-density-approximation.md)
This method estimates volumetric density $\hat{d}$ directly from intermediate activation features $\mathbf{f}_\ell$ of a coordinate-based MLP, replacing expensive coarse network evaluations. It differs from SDF-based methods by retaining the standard density-based rendering formulation. The density is estimated by computing the mean activation feature vector $\mathbf{f}_\ell$ across hidden units and applying handcrafted statistical functions (e.g., $f_1, f_2, f_3$) to $\mathbf{f}_\ell$. It is chosen when computational efficiency is critical and the coarse network is a bottleneck.

### [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md)
SDF representations replace the standard NeRF density field $\sigma(\mathbf{x})$ with a continuous scalar field $s(\mathbf{x})$ representing the distance to the nearest surface. This substitution addresses geometric inaccuracy and surface holes typical of density-based NeRFs. The surface normal $\mathbf{n}$ is derived from the SDF gradient: $\mathbf{n} = \nabla s(\mathbf{x}) / \|\nabla s(\mathbf{x})\|$. It is chosen when explicit, smooth surface reconstruction is required over soft volumetric boundaries.

### [Volume-Augmented NeRF](12973-volume-augmented-nerf.md)
Volume-Augmented NeRF is designed for dynamic fluid scenes by binding an explicit fluid volume value $v_i$ to each sample point. Unlike static NeRF, the density MLP takes $\gamma(\mathbf{x}_i)$ and $v_i$ as input, allowing the renderer to learn density based on the spatial distribution from a differentiable fluid simulator. It is chosen for rendering dynamic fluid dynamics where density changes over time due to flow.

### [Neural-PIL Decomposition Architecture](12975-neural-pil-decomposition-architecture.md)
This architecture separates scene geometry, material properties, and illumination into distinct networks. Unlike standard NeRF, it predicts density, a BRDF embedding $\mathbf{z}_b$, and an illumination embedding $\mathbf{z}_l$. It uses a learned pre-integrated lighting network to render shaded colors. It is chosen when input images are captured under varying illumination and explicit reflectance decomposition is required.

### [SAID-NeRF](13619-said-nerf.md)
SAID-NeRF exploits instance masks from Visual Foundation Models (VFMs) to enhance surface estimation for transparent objects. It decomposes appearance into view-independent diffuse and view-dependent specular components and uses semantic segmentation to enforce higher surface densities. It builds on [Instant-NGP](13738-voxel-and-sparse-grid-representations.md) for encoding and [Semantic and Feature Branches](12095-semantic-and-feature-branches.md) for joint optimization. It is chosen for robotic grasping tasks requiring sharp depth estimates of transparent objects.

### [MINE](13661-mine.md)
MINE models the frustum of the source camera using a continuous depth Multiplane Image (MPI) representation, conditioned on input images via a fully-convolutional decoder. Unlike pixelNeRF, which models the entire 3D space per ray, MINE reconstructs the frustum per plane, allowing rendering of any target view via homography warping after a single encoder pass. It is chosen for efficient multi-view synthesis where the number of target views is large.

### [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md)
This family replaces the continuous MLP with discrete, spatially structured data structures (dense voxels, sparse grids, hash tables, or triplanes). This substitution enables memory-efficient training and real-time rendering by retrieving values via interpolation or hashing rather than neural inference. It is chosen for scalability to large scenes and real-time applications.

### [Aleth-NeRF](13764-aleth-nerf.md)
Aleth-NeRF trains on under- and over-exposed images to render normal-light novel views by introducing 'Concealing Field' assumptions. It models illumination adaptive volume rendering through local and global concealing fields to suppress light transport. Unlike RAW-NeRF, it operates on standard 8-bit LDR images without pre-processing. It is chosen for low-light or over-exposed input conditions.

### [Unified Volumetric Avatar (UVA)](13784-unified-volumetric-avatar-uva.md)
UVA represents dynamic human avatars by anchoring structured latent codes to a deformable mesh in canonical space. It distinguishes itself from pre-defined UV mapping methods by enabling local and independent editing of geometry and texture. It is end-to-end trainable and jointly optimized with the skinning field. It is chosen for dynamic human avatar synthesis with local editing capabilities.

### [Transformer and Vision Model Integration](13911-transformer-and-vision-model-integration.md)
This family integrates Vision Transformers (ViT) and general Transformer architectures into NeRFs to leverage global semantic understanding. It solves the limitations of standard MLP-based NeRFs by either generalizing across scenes without per-scene tuning or explicitly modeling self-occlusion via attention mechanisms. It is chosen for single-image inputs or scenes with complex occlusions.

### [Human and Specific Subject Modeling](13997-human-and-specific-subject-modeling.md)
This family focuses on representing humans and specific subjects using specialized architectures. It often combines explicit shape priors (like SMPL) with implicit NeRF representations to avoid overfitting and reduce computational complexity. It is chosen for novel pose synthesis of humans from monocular video.

### [OPONeRF](14014-oponerf.md)
OPONeRF personalizes the parameters of the plenoptic mapping function for each sampled 3D point. Unlike vanilla NeRFs, it dynamically conditions network weights $\Theta$ on the point's representation $\mathbf{x}$ and the overall scene representation $\mathbf{F}$. This approach subdivides the scene and discriminatively responds to local variations. It is chosen for handling test-time scene changes and robustness against perturbations.

### [Mixer-NeRF](14073-mixer-nerf.md)
Mixer-NeRF addresses the loss of local information in standard NeRFs by introducing a hybrid spatial feature learning module (MLCA) and a squeeze-and-excitation (SE) network module. It explicitly mixes spatial and channel features via fully connected layers before the main MLP inference. It is chosen when high-frequency detail preservation is critical.

### [Sparse View and Few-Shot Optimization](14428-sparse-view-and-few-shot-optimization.md)
This family addresses overfitting and geometry breakdown when training with drastically reduced viewpoints ($|S| < 20$). It mitigates ambiguity through in-situ regularization, deformable sampling strategies, or pseudo-observation densification. It is chosen when input data is sparse.

### [Mixture-of-Experts and Modular Architectures](14429-mixture-of-experts-and-modular-architectures.md)
This family replaces the single continuous function of standard NeRF with multiple specialized networks (experts) or parallel processing streams. It solves the limitations of conventional Implicit Neural Representations (INRs) by explicitly partitioning the input domain or ray batch among distinct neural modules. It is chosen for improving compression, training speed, or representation capacity.

### [Uncertainty and Reliability](14487-uncertainty-and-reliability.md)
These methods extend standard NeRF architectures to quantify prediction confidence, addressing artifacts and geometry collapse in sparse data. Unlike deterministic NeRF variants, they model the scene as a probabilistic entity, providing pixel-level reliability metrics for color and depth. It is chosen for robust filtering and conformal prediction.

### [Object Decomposition and Composition](14518-object-decomposition-and-composition.md)
These methods extend standard NeRF architectures to explicitly separate a scene into distinct semantic or geometric object instances. They introduce auxiliary outputs (object codes, separate heads, or latent codes) to decompose the volume. It is chosen for instance-level editing, manipulation, and amodal segmentation.

### [Lighting and Appearance Models](14522-lighting-and-appearance-models.md)
These models modify the standard NeRF architecture to explicitly represent or control illumination and material properties. They solve the problem of semantic lighting control, relighting, and stylization by decoupling geometry, albedo, and illumination. It is chosen for physical lighting representation and stylization.

### [Optimization and Training Procedures](14565-optimization-and-training-procedures.md)
This family covers algorithmic procedures for optimizing NeRFs, ranging from standard training loops to specialized acceleration and editing techniques. It addresses efficiently minimizing photometric loss while managing computational constraints. It is chosen for improving training efficiency and convergence.

### [Image Enhancement and Restoration Methods](14566-image-enhancement-and-restoration-methods.md)
These methods address degradation of input imagery (blur, transient occlusions, low resolution) by integrating restoration mechanisms into the NeRF optimization loop. They differ from sibling methods by focusing on specific degradation types, often using 2D priors to guide 3D consistency. It is chosen for handling noisy or degraded input data.

### [Modular, Hierarchical, and Latent Architectures](14567-modular-hierarchical-and-latent-architectures.md)
This family extends standard NeRF architectures to handle non-rigid deformation with topological changes and hierarchical scene structures. [HyperNeRF](13906-hypernerf.md) models non-rigidly deforming scenes by lifting the canonical 3D space into a higher-dimensional ambient space. [Strata-NeRF](14015-strata-nerf.md) models stratified scenes by replacing continuous positional encoding inputs with discrete latent codes. It is chosen for complex dynamic or hierarchical scenes.

### [MuRF (Multi-Baseline Radiance Fields)](15007-murf-multi-baseline-radiance-fields.md)
MuRF is a feed-forward method for sparse view synthesis that constructs a **target view frustum volume** aligned with the target camera rather than a reference input view. It uses a **3D context-aware convolutional decoder** instead of independent ray-based rendering. It is chosen for rendering novel views under varying camera baseline settings, including large baselines.

### [Gaussian and Primitive-Based Representations](15011-gaussian-and-primitive-based-representations.md)
This family replaces the continuous MLP radiance field with discrete geometric primitives or explicit Gaussian distributions. It differs from voxel-based methods by using analytic primitives (quadrics or Gaussians) rather than voxel grids, and from SDF methods by relying on alpha-blended primitives. It is chosen for improved rendering efficiency and geometric fidelity.

### [Decentralized Federated NeRF](15032-decentralized-federated-nerf.md)
DecentNeRF is a framework for learning global 3D scene representations from crowd-sourced images by distributing training computation to users. It explicitly decomposes the scene into global and personal radiance fields per user and employs secure aggregation. It is chosen for privacy-preserving 3D reconstruction from crowdsourced data.

### [Neural Proxy](15220-neural-proxy.md)
Neural Proxy represents photo-realistic targets as animatable proxies, combining neural volume rendering with neural texture. It injects an animatable mesh proxy into the scene, allowing particles to move with the animated proxy geometry. It is chosen for synthesizing unseen animations without temporal learning.

### [ViSNeRF](15255-visnerf.md)
ViSNeRF is a hybrid neural radiance field method for efficient synthesis of visualizations from dynamic volumetric scenes. It combines explicit feature grids with implicit MLP decoders and applies generalized tensor factorization. It is distinguished by its specific use of separate small MLPs for density and color decoding. It is chosen for high-dimensional $(3+K)$-D radiance fields.

### [EBAD-NeRF](15441-ebad-nerf.md)
EBAD-NeRF reconstructs sharp 3D radiance fields from motion-blurred images by jointly optimizing learnable camera poses and NeRF parameters using hybrid event-RGB data. It models complex camera motion trajectories with multiple learnable poses. It is chosen for reconstructing scenes from motion-blurred inputs.

### [Point-NeRF Representation](15538-point-nerf-representation.md)
Point-NeRF replaces the continuous MLP function with a discrete neural point cloud to model a continuous volumetric radiance field. It avoids ray sampling in empty space by leveraging classical point clouds. It is chosen for faster optimization and higher-quality rendering than standard NeRF.

### [NeurMiPs](15543-neurmips.md)
NeurMiPs represents a 3D scene as a mixture of $K$ learnable rectangular planar surfaces, where each surface acts as an independent "expert". It alleviates the frontal-parallel limitation of traditional MPI while maintaining high efficiency. It is chosen for superior extrapolation capabilities compared to voxel-based methods.

### [CodeNeRF](15544-codenerf.md)
CodeNeRF is an implicit 3D neural representation that learns the variation of object shapes and textures across a semantic category. It disentangles shape and texture by learning separate latent embeddings, allowing for one-shot reconstruction. It is chosen for synthesizing novel views of unseen objects from a single unposed input image.

### [Dynamic Scene and Temporal Modeling](15546-dynamic-scene-and-temporal-modeling.md)
This family extends static NeRFs to reconstruct and render scenes that change over time by explicitly modeling the 4D space-time volume. It addresses challenges such as non-rigid deformation and occlusion changes. It is chosen for temporal consistency and motion representation in novel view synthesis.

### [NeRF-Casting](15547-nerf-casting.md)
NeRF-Casting synthesizes photorealistic specular appearance and reflections by integrating ray tracing into the NeRF rendering pipeline. It casts reflection rays from points along camera rays into the NeRF geometry to render feature vectors. It is chosen for modeling view-dependent appearance and reflections without requiring a large MLP to encode the entire environment.

### [RoseNeRF](15548-rosenerf.md)
RoseNeRF synthesizes high-fidelity novel views of real refractive objects by simplifying complex ray interactions to a single refraction event. It predicts a single refracted ray using a 4D light field representation. It is chosen for rendering transparent objects without needing Index of Refraction (IoR) fields.

### [NeRF-Det](15549-nerf-det.md)
NeRF-Det is a method for indoor 3D object detection that explicitly models scene geometry as an opacity field. It integrates multi-view geometry constraints from the NeRF branch into 3D detection through a shared geometry MLP. It is chosen for end-to-end 3D object detection with low inference latency.

### [Semantic and Feature Field Extensions](15556-semantic-and-feature-field-extensions.md)
These extensions generalize the standard NeRF formulation by predicting arbitrary per-point feature signals $\mathbf{f}$ in addition to color $\mathbf{c}$ and density $\sigma$. This allows the network to learn quantities such as semantic labels or physical properties. It is chosen for 3D-aware semantic understanding and zero-shot query-based editing.

### [HumanNeRF-SE](15640-humannerf-se.md)
A method for synthesizing novel pose images of humans from monocular video inputs by combining explicit SMPL shape priors with implicit NeRF representation. It avoids overfitting and reduces computational complexity. It is chosen for human novel pose synthesis.

### Minor Variants
#### NeRF-VAE
- [S1] A generative NeRF model that generalizes to out-of-distribution scenes and removes the need to train on each scene from scratch.
- [S1] The NeRF renderer is conditioned on a latent code. This latent code is trained using Iterative Amortized Inference and a ResNet encoder.
- [S1] An attention-based scene function is introduced instead of the typical MLP.
- [S1] Outperforms baseline NeRF with a low number of scene views (5-20), but is outperformed by baseline NeRF when a large number of views are available (100+) due to lower scene expressivity.

#### PIE-NeRF
- [S1] A pipeline integrating physics-based elastodynamic simulation with a neural radiance field representation, using a meshless discretisation based on quadratic generalized moving least squares on top of the density field of a NeRF.
- [S1] Enables large deformations and nonlinear hyperelastic material simulation directly on the implicit representation and supports interactive manipulation of real-world captured scenes with complex geometries.

#### NeuralEditor
- [S4] A method employing a point cloud-guided NeRF model for shape manipulation, leveraging K-D trees and deterministic integration strategy for accurate point cloud-based rendering, with Phong reflection modeling to enhance color fidelity and geometric detail.

#### NeRF-W
- [S7, unofficial] A variant of NeRF that models temporal modifications (variable illuminations and dynamic objects) using learned latent spaces for appearance and transient content, allowing rendering of static and dynamic parts of the scene.

## Background
The standard NeRF architecture, introduced by Mildenhall et al. [S1], uses two feed-forward neural networks: MLP_θ1 connects a 3D position to a density value σ and MLP_θ2 predicts a RGB color from a viewing direction d and a latent vector MLP_θ1 (x, y, z). The final RGB value of a pixel is computed by approximating the volume rendering integral using N_c coarse samples and N_f fine samples along a light ray with predicted colors (c_i)_n and densities (σ_i)_n [S7, unofficial]. With this formulation, NeRF models are able to render a static scene captured under controlled settings but fail in real world dynamic scenes with variable illuminations and dynamic objects [S7, unofficial]. Subsequent works have modified the architecture to address these limitations, including the introduction of generative models like NeRF-VAE [S1], dynamic modeling like NeRF-W [S7, unofficial], and efficiency improvements like NeRF-Swin [S6].
