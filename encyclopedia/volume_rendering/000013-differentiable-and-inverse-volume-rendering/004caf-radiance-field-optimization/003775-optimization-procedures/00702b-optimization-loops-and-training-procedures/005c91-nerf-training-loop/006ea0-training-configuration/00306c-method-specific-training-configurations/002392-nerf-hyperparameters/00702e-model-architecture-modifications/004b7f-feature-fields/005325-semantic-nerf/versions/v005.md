# Semantic-NeRF


## Overview
Semantic-NeRF is a method that extends the Neural Radiance Field (NeRF) formulation to synthesize semantic labels for novel views by predicting a semantic feature vector in addition to color and density [S1, S3]. It solves the problem of integrating 2D semantic supervision into a 3D implicit representation, enabling multi-view consistent semantic understanding and label propagation from sparse or noisy annotations [S1, S2]. It sets itself apart from sibling methods like [Multi-Space Neural Radiance Field (MS-NeRF)](11707-multi-space-neural-radiance-field-ms-nerf.md) and [NRFF](12072-nrff.md) by specifically focusing on the direct integration of categorical semantic labels via a dedicated output branch, rather than general feature fields or instance-specific segmentation [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** RGB images $I$, corresponding camera poses, and semantic labels $S$ (which may be sparse, noisy, or derived from a pre-trained segmentation model) [S1, S2, S3].
*   **Outputs:** Rendered RGB images and rendered semantic label maps for novel viewpoints [S1, S3].

**Data Structures:**
The method modifies the standard NeRF network $F_\Theta$ to output a tuple $(\mathbf{c}, \sigma, \mathbf{s})$ [S1, S2, S3]:
*   $\mathbf{c} \in \mathbb{R}^3$: View-dependent color.
*   $\sigma \in \mathbb{R}$: Volume density.
*   $\mathbf{s} \in \mathbb{R}^{K}$: Semantic feature vector, where $K$ is the number of semantic classes [S1]. The semantic output is direction-independent [S1].

**Network Architecture:**
The network typically consists of a shared feature encoding path and separate branches for color and semantics [S1, S2].
1.  Position $\mathbf{x}$ and viewing direction $\mathbf{d}$ are encoded.
2.  A shared MLP processes positional information to produce intermediate features [S1].
3.  One branch (often direction-independent) takes these features to predict density $\sigma$ and the semantic vector $\mathbf{s}$ [S1].
4.  Another branch takes the features and direction $\mathbf{d}$ to predict color $\mathbf{c}$ [S1].

**Rendering:**
Semantic labels are rendered using the same volume integration principle as color [S1, Parent]. For a ray $r$, the rendered semantic label distribution $\hat{\mathbf{S}}(r)$ is computed as:

$$
\hat{\mathbf{S}}(r) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{s}(x_i)
$$

where:
*   $N$ is the number of samples along the ray.
*   $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance.
*   $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ is the opacity weight.
*   $\mathbf{s}(x_i)$ is the semantic feature vector predicted at sample point $x_i$ [S1].

**Training Procedure:**
1.  **Loss Function:** The semantic labels are supervised using categorical cross-entropy loss [S1]. The total loss combines the RGB reconstruction loss and the semantic loss [S1, S3].
2.  **Optimization:** The network parameters are optimized to minimize the combined loss, ensuring that the rendered semantic labels match the ground-truth labels projected onto the image plane [S1, S2].
3.  **Pseudo-labeling (Variant):** In scenarios with limited ground-truth labels, the method can be adapted to use predictions from a pre-trained segmentation model as pseudo-labels [S2]. The rendered semantic labels from the NeRF are used to adapt the frame-level semantic network, and vice versa, ensuring alignment between semantic forecasts and NeRF renderings [S2].

**Pseudocode:**

```python
def semantic_nerf_forward(positions, directions, network):
    """
    Forward pass of Semantic-NeRF.
    positions: (N, 3) sampled points along rays
    directions: (N, 3) viewing directions
    network: The Semantic-NeRF model
    Returns: color (N, 3), density (N, 1), semantic_features (N, K)
    """
    # Shared encoding
    features = network.shared_encoder(positions)
    
    # Density and Semantic prediction (direction-independent)
    density, semantic_features = network.semantic_branch(features)
    
    # Color prediction (direction-dependent)
    color = network.color_branch(features, directions)
    
    return color, density, semantic_features

def render_semantic(rays, network, num_samples):
    """
    Renders semantic labels for a batch of rays.
    rays: (B, 3, 2) origin and direction for each ray
    network: The Semantic-NeRF model
    num_samples: Number of samples per ray
    Returns: rendered_color (B, H, W, 3), rendered_semantics (B, H, W, K)
    """
    # Sample points along rays
    t_vals = linspace(0, 1, num_samples)
    z_vals = near + t_vals * (far - near)
    points = rays[:, 0:1, :] + rays[:, 1:2, :] * z_vals.unsqueeze(2)
    
    # Get network outputs
    colors, densities, semantic_features = semantic_nerf_forward(points, rays[:, 1:2, :], network)
    
    # Compute weights
    deltas = z_vals[:, 1:] - z_vals[:, :-1]
    delta_inf = 1e10 * torch.ones_like(deltas[:, :1])
    deltas = torch.cat([deltas, delta_inf], -1)
    
    alpha = 1 - torch.exp(-densities * deltas)
    transmittance = torch.cumprod(torch.cat([torch.ones_like(alpha[:, :1]), 1 - alpha + 1e-10], -1), -1)[:, :-1]
    weights = alpha * transmittance
    
    # Render color
    rendered_color = torch.sum(weights.unsqueeze(-1) * colors, dim=1)
    
    # Render semantic labels
    rendered_semantics = torch.sum(weights.unsqueeze(-1) * semantic_features, dim=1)
    
    return rendered_color, rendered_semantics

def train_step(batch, network, optimizer, num_classes):
    """
    Single training step.
    batch: Dictionary with 'rgb', 'poses', 'semantic_labels'
    network: The Semantic-NeRF model
    optimizer: Optimizer
    num_classes: Number of semantic classes K
    """
    optimizer.zero_grad()
    
    # Render RGB and Semantics
    rendered_rgb, rendered_semantics = render_semantic(batch['poses'], network, num_samples=64)
    
    # Compute RGB Loss (e.g., MSE)
    rgb_loss = F.mse_loss(rendered_rgb, batch['rgb'])
    
    # Compute Semantic Loss (Categorical Cross-Entropy)
    # rendered_semantics is (B, H, W, K)
    # batch['semantic_labels'] is (B, H, W) containing class indices
    semantic_loss = F.cross_entropy(
        rendered_semantics.permute(0, 3, 1, 2), # (B, K, H, W)
        batch['semantic_labels']
    )
    
    # Total Loss
    loss = rgb_loss + semantic_loss
    loss.backward()
    optimizer.step()
    
    return loss.item()
```

## Subtopics

### Semantic-NeRF Training
A training variant where the NeRF is trained for each scene by fusing predictions from a pre-trained segmentation model [S2]. It uses view-consistent rendered semantic labels as pseudo-labels for model adaptation [S2]. This approach simultaneously trains a frame-level semantic network and a scene-level NeRF to ensure that semantic forecasts and NeRF renderings remain aligned [S2]. It is chosen when ground-truth semantic labels are unavailable or sparse, leveraging the NeRF's multi-view consistency to refine segmentation predictions [S2].

## Operating characteristics
*   **Time Complexity:** Training time is comparable to standard NeRF, with additional overhead for the semantic branch and loss computation [S1]. Rendering time is also similar, as the semantic branch is lightweight [S1].
*   **Memory Complexity:** Slightly higher than standard NeRF due to the storage of semantic features $\mathbf{s}$ at each sample point [S1].
*   **Performance:** Capable of training with sparse semantic label data (e.g., 10% labeled) and recovering semantic labels from pixel-wise and region-wise noise [S1]. It achieves good label super-resolution and label propagation from sparse point-wise annotations [S1].
*   **Strengths:** Enables multi-view semantic fusion, outperforming non-deep learning methods [S1]. It ensures multi-view consistency between semantic labels [S2].
*   **Limitations:** Performance depends on the quality of the initial semantic labels or segmentation model if pseudo-labeling is used [S2].
*   **When to use:** When semantic understanding of a scene is required alongside photorealistic rendering, especially with sparse or noisy annotations [S1, S2].
*   **When not to use:** When only color and geometry are needed, or when real-time inference is critical and the additional semantic branch overhead is prohibitive [S1].

## Background
Semantic-NeRF was introduced in March 2021 as the first work to integrate semantic information into NeRF [S3]. It utilized RGB images alongside corresponding semantic labels to train the NeRF network, incorporating an additional semantic output to enhance semantic understanding of scenes [S3]. The method was capable of synthesizing semantic labels for novel views using an additional direction-independent MLP branch [S1]. It built upon previous work like Fig-NeRF, which employed a similar approach [S1]. The method has been influential in subsequent research, including Panoptic NeRF and various Gaussian-Splatting-based semantic view synthesis models [S1].
