# NeRF-SR Training Configuration

Also called: NeRF-SR, NeRF Super-Resolution

## Overview
NeRF-SR is a training configuration designed to synthesize high-resolution novel views from low-resolution input images by exploiting the 3D consistency of the neural radiance field [S1]. It differs from standard NeRF training by supersampling the input resolution during training and optionally applying a post-refinement network to restore high-frequency details [S1]. It addresses the limitation that standard NeRF trained on low-resolution inputs produces blurry high-resolution renderings [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Low-resolution training images (e.g., 504×378) and their camera poses [S1].
*   **Output:** A trained NeRF model capable of rendering high-resolution images (e.g., 1008×756 for ×2 scale) [S1].

**Data Structures:**
*   **Reference Patches:** A set of $K$ patches extracted from reference images for the refinement stage.
*   **Training Batch:** A bundle of 2048 rays [S1].

**Numbered Steps:**

1.  **Dataset Splitting:**
    *   Reserve 200 images for testing and use the remaining 100 views for training [S1].
    *   For the LLFF dataset, all images are used for training, and metrics are averaged over the whole set [S1].

2.  **Initialization:**
    *   Initialize the Adam optimizer with $\beta_1 = 0.9$, $\beta_2 = 0.999$ [S1].
    *   Initialize the NeRF MLPs (coarse and fine) following the standard NeRF architecture [S1].

3.  **Training Loop:**
    *   **Sampling:** Use hierarchical sampling with 64 coarse samples and 64 fine samples per ray [S1].
    *   **Forward Pass:** Render rays using the coarse and fine MLPs [S1].
    *   **Loss:** Compute photometric loss (MSE) between rendered and ground truth colors [S1].
    *   **Optimization:** Update parameters using Adam [S1].

4.  **Refinement (Optional):**
    *   During inference, divide the rendered image into non-overlapping patches [S1].
    *   For each patch, extract $K$ reference patches from reference images using estimated depth and camera intrinsics [S1].
    *   Input the target patch and reference patches into a refinement network to boost texture details [S1].
    *   Stitch the refined patches together [S1].

**Parameters:**
*   **Batch Size:** 2048 rays [S1].
*   **Learning Rate:** Exponential decay from $5 \times 10^{-4}$ to $5 \times 10^{-6}$ [S1].
*   **Epochs:** 20 epochs for Blender dataset, 30 epochs for LLFF dataset [S1].
*   **Refinement Patches ($K$):** 8 [S1].
*   **Patch Dimensions:** 64×64 [S1].

**Pseudocode:**

```python
def train_nerf_sr(dataset, config):
    # 1. Initialization
    model = NeRFMLP()
    optimizer = Adam(model.parameters(), lr=5e-4, beta1=0.9, beta2=0.999)
    
    # 2. Data Loading
    # Split: 100 train, 200 test (for Blender)
    train_images = dataset.images[:100]
    
    # 3. Training Loop
    # 20 epochs for Blender, 30 for LLFF
    for epoch in range(config.epochs):
        for batch_idx in range(len(train_images)):
            # Ray Sampling
            ray_origins, ray_directions = get_ray_bundle(
                image=train_images[batch_idx],
                pose=dataset.poses[batch_idx]
            )
            
            # Hierarchical Sampling: 64 coarse, 64 fine
            query_points_coarse, depth_coarse = sample_rays(
                ray_origins, ray_directions, 
                n_samples=64, 
                near=dataset.near, 
                far=dataset.far
            )
            
            # Coarse Forward Pass
            rgb_coarse, sigma_coarse = model.forward(
                query_points_coarse, ray_directions
            )
            
            # Fine Sampling (Importance Sampling based on sigma_coarse)
            query_points_fine, depth_fine = importance_sample(
                sigma_coarse, depth_coarse, n_samples=64
            )
            
            # Fine Forward Pass
            rgb_fine, sigma_fine = model.forward(
                query_points_fine, ray_directions
            )
            
            # Loss Computation
            gt_rgb = train_images[batch_idx].rgb
            loss = mse_loss(rgb_fine, gt_rgb)
            
            # Optimization
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            # Learning Rate Decay
            current_lr = 5e-4 * (5e-6 / 5e-4) ** (epoch / config.epochs)
            for param_group in optimizer.param_groups:
                param_group['lr'] = current_lr

def refine_nerf_sr(rendered_image, dataset, config):
    # 1. Patch Division
    patches = divide_into_patches(rendered_image, size=64)
    refined_patches = []
    
    # 2. Reference Patch Extraction
    # K=8 reference patches
    ref_patches = extract_reference_patches(
        dataset.reference_images, 
        patches, 
        K=8
    )
    
    # 3. Refinement Network
    for patch, ref in zip(patches, ref_patches):
        refined_patch = refinement_network(patch, ref)
        refined_patches.append(refined_patch)
        
    # 4. Stitching
    final_image = stitch_patches(refined_patches)
    return final_image
```

**Edge Cases and Pitfalls:**
*   **Scale Dependency:** NeRF-SR does not support arbitrary-scale super-resolution; it is trained for specific scale factors (e.g., ×2, ×4) [S1].
*   **Refinement Necessity:** For ×2 scale, supersampling alone yields decent results, and refinement provides only minor PSNR gains, though LPIPS improves [S1]. For ×4 scale, refinement is necessary as supersampling derives fewer details [S1].
*   **Inference Time:** Refinement adds negligible time (~1.3s on 1080Ti for 1008×756) compared to volumetric rendering (~48s) [S1].

## Subtopics

### Refinement Network (Ours-Refine)
A post-processing network that boosts NeRF-SR outputs with texture details and edge sharpness, particularly for real-world LLFF datasets where supersampling alone is insufficient [S1]. It uses $K=8$ reference patches of size 64×64 [S1]. For ×2 scale, it improves LPIPS but has minimal PSNR gain; for ×4 scale, it is necessary for quality [S1]. Inference time is ~1.3 seconds on a single 1080Ti for a 1008×756 image [S1].

## Operating characteristics
*   **Time Complexity:** Training time is comparable to training a high-resolution NeRF [S1]. Inference time for a 1008×756 image is ~48 seconds for rendering plus ~1.3 seconds for refinement on a single 1080Ti [S1].
*   **Memory Complexity:** Uses 2048 rays per batch [S1].
*   **Performance:** On LLFF dataset at ×4 scale, Ours-Refine achieves PSNR 25.59, SSIM 0.759, LPIPS 0.165 [S1].
*   **Strengths:** Achieves photorealistic renderings without external data by exploiting 3D consistency [S1].
*   **Limitations:** Does not support arbitrary-scale super-resolution [S1].

## Background
NeRF-SR was introduced as the first pipeline for high-resolution novel view synthesis from mostly low-resolution inputs [S1]. It was developed to address the blurriness of standard NeRF renderings when upscaled [S1].
