# Inpainting SDS Loss

Also called: LiSDS, Inpainting-based Score Distillation Sampling, SDS loss with scene context

## Overview
Inpainting SDS Loss (LiSDS) is a score distillation method that uses a diffusion inpainting model to generate 3D content conditioned on both a text prompt and existing scene geometry [S1, unofficial][S2]. It solves the problem of incomplete object generation and poor compositional harmony found in vanilla SDS, which often produces isolated parts (e.g., only a head) that fail to integrate with the background [S2]. By conditioning the noise prediction on a binary mask $M$ and the masked rendered image $I_M$, LiSDS ensures the generated object maintains complete geometry and proper pose relative to the scene context [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** Radiance field parameters $\Theta$, camera pose, text prompt $y$, binary mask $M$ (defining the region to inpaint/generate), and the current rendered image $I$ (or latent representation).
*   **Output:** Gradient $\nabla_\Theta L$ for updating the radiance field.

**Data Structures:**
*   **Mask $M$:** A binary image of the same resolution as the rendered image, where 1 indicates the region to be inpainted/generated and 0 indicates the background/visible region. In [S2], $M$ is derived by projecting a 3D bounding box into the camera viewpoint. In [S1, unofficial], $M$ defines the "in-boundary" (IB) and "out-of-boundary" (OB) regions.
*   **Masked Image $I_M$:** The rendered image where pixels outside the mask $M$ are preserved, and pixels inside $M$ are either zeroed, blurred, or left as the current NeRF prediction depending on the specific implementation variant.

**Numbered Steps:**
1.  **Rendering:** Render an image $I$ from the current radiance field $\Theta$ using the current camera pose.
2.  **Masking:** Apply the binary mask $M$ to $I$ to create the masked image $I_M$.
3.  **Noise Addition:** Sample a timestep $t$ and Gaussian noise $\epsilon$. Add noise to $I_M$ to obtain the noisy image $x_t$.
4.  **Noise Prediction:** Pass $x_t$, timestep $t$, text embedding $y$, and mask $M$ into a frozen inpainting diffusion model $\epsilon_\phi$. The model predicts the noise $\hat{\epsilon} = \epsilon_\phi(x_t; y, t, M)$.
5.  **Gradient Computation:** Compute the gradient of the loss with respect to $\Theta$ by backpropagating through the diffusion model's noise prediction error and the differentiable renderer.

**Formulas:**
The core LiSDS loss is defined as [S1, unofficial]:
$$ L_{iSDS}(\phi, g(\theta)) = \mathbb{E}_{t,\epsilon} \left[ \| \epsilon_\phi(x_t; y, t, M) - \epsilon_t \|_2^2 \right] $$
where:
*   $y$ is the text embedding.
*   $M$ is the binary mask.
*   $\epsilon_t$ is the actual noise added at timestep $t$.
*   $x_t$ is the noisy image at timestep $t$.
*   $\epsilon_\phi$ is the inpainting diffusion model.

The gradient computation for optimization is [S2]:
$$ \nabla_\Theta L_{SDS} = \mathbb{E}_{t,\epsilon,C} \left[ \omega(t) \cdot \left( \epsilon_\phi(I_t; y, I_M, M, t) - \epsilon \right) \frac{\partial I_t}{\partial \Theta} \right] $$
where:
*   $\omega(t)$ is the weighting function (typically dependent on timestep $t$).
*   $I_t$ is the noisy image at timestep $t$.
*   $C$ represents the conditioning context (text, mask, masked image).

**Parameters:**
*   **Mask $M$:** Derived from projecting a 3D bounding box into the camera view [S2] or defined by IB/OB regions [S1, unofficial].
*   **Loss Weights:** In [S1, unofficial], the total loss includes a reliability-guided loss $L_R$ and sparsity loss $L_{sp}$: $L_{total} = \lambda_{iSDS} L_{iSDS} + \delta_R(\theta, \phi) L_R + \lambda_{sp} L_{sp}$. The weight $\delta_R$ is 1 within the IB area and 0 otherwise [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Incomplete Generation:** Vanilla SDS may generate only parts of an object (e.g., a cat's head) if not conditioned on scene context [S2]. LiSDS mitigates this by using the mask to guide the completion of the object [S2].
*   **Texture Continuity:** Standard LiSDS may result in discontinuities between the generated part and the existing image prior. A refinement step is used to address this [S1, unofficial].
*   **Saturation:** Generated objects may exhibit over-saturation. Saturation loss is sometimes applied to regulate color values [S2].

**Pseudocode:**
```python
def inpainting_sds_loss_step(radiance_field, camera_pose, text_prompt, mask, diffusion_model, timestep_sampler, noise_sampler):
    """
    Computes the gradient for Inpainting SDS Loss.
    
    Args:
        radiance_field: The NeRF or radiance field parameters theta.
        camera_pose: Current camera extrinsics and intrinsics.
        text_prompt: String text prompt for the diffusion model.
        mask: Binary mask M defining the inpainting region.
        diffusion_model: Frozen inpainting diffusion model epsilon_phi.
        timestep_sampler: Sampler for timestep t.
        noise_sampler: Sampler for Gaussian noise epsilon.
        
    Returns:
        gradient: Gradient of the loss with respect to radiance_field parameters.
    """
    # 1. Render the current image from the radiance field
    # I is the rendered image, shape (H, W, 3)
    I = differentiable_render(radiance_field, camera_pose)
    
    # 2. Create masked image I_M
    # Pixels outside the mask are preserved, inside are masked (e.g., zeroed or blurred)
    # Implementation detail: The exact masking strategy (zeroing vs keeping NeRF prediction)
    # depends on the specific diffusion model implementation.
    I_M = apply_mask(I, mask)
    
    # 3. Sample timestep and noise
    t = timestep_sampler.sample()
    epsilon = noise_sampler.sample(shape=I_M.shape)
    
    # 4. Add noise to the masked image to get x_t
    # alpha_t and sigma_t are coefficients from the diffusion model's noise schedule
    alpha_t, sigma_t = get_diffusion_coefficients(t)
    x_t = alpha_t * I_M + sigma_t * epsilon
    
    # 5. Predict noise using the inpainting diffusion model
    # The model is conditioned on text y, timestep t, and mask M
    # Note: Some implementations may also pass I_M or a version of it with masked regions
    # as context. Here we follow the formula from [S1, unofficial] and [S2].
    text_embedding = encode_text(text_prompt)
    predicted_noise = diffusion_model.predict_noise(x_t, t, text_embedding, mask)
    
    # 6. Compute the loss (Mean Squared Error between predicted and actual noise)
    loss = mean_squared_error(predicted_noise, epsilon)
    
    # 7. Compute gradient with respect to radiance field parameters
    # This requires backpropagation through the differentiable renderer and the diffusion model
    gradient = compute_gradient(loss, radiance_field)
    
    return gradient
```

## Subtopics

### [MVIP-NeRF](11931-mvip-nerf.md)
MVIP-NeRF is a diffusion-based method for multiview-consistent inpainting of Neural Radiance Fields (NeRFs). It solves the problem of reconstructing missing geometry and texture in masked regions of a scene while maintaining consistency across multiple camera views. Unlike prior approaches that rely on independent 2D inpainting per view—often resulting in inconsistencies and poor geometry—MVIP-NeRF jointly optimizes across views. It employs Score Distillation Sampling (SDS) with a text-conditioned diffusion model to guide inpainting in masked regions, alongside RGB reconstruction in visible areas.

### RefFusion
RefFusion inpaints one reference image using an inpainting Latent Diffusion Model (LDM) on both global and locally cropped versions of the reference view [S3]. It utilizes SDS loss to distill learned priors from the adapted LDM into the scene, incorporating a discriminator loss and depth loss to improve the quality of inpainting results [S3]. Quantitative results show RefFusion surpassed all baselines in LPIPSdir (0.4283) compared to NeRF-In (0.4884), SPIn-NeRF (SD) (0.5701), SPIn-NeRF (LaMa) (0.4654), Inpaint3D (0.5150), Reference-guided inpainting (SDV2) (0.4532), and Reference-guided inpainting (SDXL) (0.4453) [S3].

### Random Patch Refinement
A refinement step applied during the last 10% of training to improve texture and color continuity by masking foreground patches and optimizing them with LiSDS, excluding the Reliability-guided loss ($L_R$) [S1, unofficial]. During the final 10% of training, if an in-boundary view is sampled, the Reliability-guided loss ($L_R$) is excluded, and a random patch is given to the foreground to refine the corresponding part with the Inpainting SDS Loss ($L_{iSDS}$) [S1, unofficial]. This process results in the color and texture of the generated 3D object becoming more similar to the part generated by the LiSDS, while maintaining the overall shape and content of the image prior [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Similar to vanilla SDS, as it involves one forward pass through the diffusion model per optimization step. However, the use of inpainting models may require additional conditioning steps.
*   **Memory Complexity:** Requires storing the mask $M$ and potentially the masked image $I_M$. The diffusion model is frozen and loaded once.
*   **Performance:** LiSDS generates complete objects with proper poses that seamlessly integrate with the scene, outperforming vanilla SDS which often generates incomplete parts [S2]. GO-NeRF using LiSDS achieved an average CLIP score of 74.6, significantly outperforming baselines like Blended-NeRF (63.0) and Spin-NeRF (60.8) [S2].
*   **Strengths:** Ensures harmonized composition with existing scene context; generates complete objects; maintains texture continuity with refinement steps.
*   **Limitations:** Requires a high-quality inpainting diffusion model; may require additional losses (sparsity, saturation) for optimal results; refinement step adds complexity to the training loop.
*   **When to use:** When generating 3D objects that need to be composited into an existing scene or when inpainting missing regions in a NeRF.
*   **When not to use:** When generating a standalone object without scene context (vanilla SDS may suffice); when computational resources are extremely limited (additional losses and refinement steps increase complexity).

## Background
Inpainting SDS Loss was introduced to address the limitations of vanilla SDS in generating 3D objects that harmonize with existing scenes. Vanilla SDS often produces incomplete objects (e.g., only a cat's head) that fail to composite properly [S2]. LiSDS leverages the power of 2D inpainting diffusion models to guide 3D generation [S1, unofficial][S2]. The method was proposed in DITTO-NeRF [S1, unofficial] and GO-NeRF [S2]. DITTO-NeRF introduced LiSDS with a refinement step for texture continuity [S1, unofficial]. GO-NeRF applied LiSDS for generating objects in VR content creation, emphasizing scene context and geometry [S2]. RefFusion [S3] further adapted inpainting LDMs for 3D scene editing.
