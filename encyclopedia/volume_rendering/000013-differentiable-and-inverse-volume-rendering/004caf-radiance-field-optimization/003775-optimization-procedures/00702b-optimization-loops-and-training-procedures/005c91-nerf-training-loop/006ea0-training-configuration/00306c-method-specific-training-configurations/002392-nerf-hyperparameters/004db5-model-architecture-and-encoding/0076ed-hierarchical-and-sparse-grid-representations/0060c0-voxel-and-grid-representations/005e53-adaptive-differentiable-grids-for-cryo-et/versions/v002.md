# Adaptive Differentiable Grids for Cryo-ET

Also called: Adaptive density grid optimization, Adaptive density grids based on an octree structure, Adaptive differentiable grids, Coordinate-based representation with adaptive octree

## Overview
Adaptive Differentiable Grids (ADG) is a learning-based representation for cryo-electron tomography (cryo-ET) that reconstructs 3D density fields using an adaptive octree structure where each node stores an optimizable 3D density grid [S1]. It solves the challenge of reconstructing high-noise, low-signal-to-noise ratio (SNR) cryo-ET data by combining differentiable image formation with regularization, replacing the fully connected MLPs of traditional neural fields to improve speed and detail preservation [S1]. Unlike standard neural fields that either learn noise or oversmooth features, ADG uses trilinear interpolation for faster querying and allows explicit regularization (TV, boundary consistency, non-local constraints) to separate signal from noise [S1].

## How it works

### Inputs and Outputs
*   **Inputs:**
    *   Tilt-series projections (2D images) from cryo-ET acquisition.
    *   Camera parameters (ray origins and directions) for each projection.
    *   Region of Interest (ROI) bounding box.
    *   Binary mask $M$ excluding rays intersecting fiducial markers or padded border regions [S1].
*   **Outputs:**
    *   An adaptive octree structure with optimized 3D density grids at each enabled node.
    *   A continuous 3D density field reconstructed by querying the octree.

### Data Structures

**Octree Node**
Each node in the octree represents a sub-volume of the ROI.
*   `enabled`: Boolean flag indicating if the node is active. Disabled nodes are merged or removed.
*   `grid`: A 3D tensor of shape $(N_x, N_y, N_z)$ storing the optimizable density values.
    *   $N_x = N_y = N_z$ (uniform grid dimensions per node) [S1].
    *   Values are real numbers representing local density.
*   `parent`: Reference to the parent node (for merging logic).
*   `children`: List of 8 child nodes (for splitting logic).

**Ray Sample**
*   `point`: 3D coordinate $(x, y, z)$ in world space.
*   `node_id`: Identifier of the octree node containing the point.

### Parameters
*   $N_x, N_y, N_z$: Grid resolution per octree node. Typically $N_x = N_y = N_z$ [S1].
*   $N_{max}$: Hyperparameter for maximum number of samples per node during ray sampling [S1].
*   $k_{tv}, k_{cnlc}, k_{bc}$: Weighting parameters for Total Variation, Cross-Nodes Non-Local Constraint, and Boundary Consistency losses respectively [S1].
*   Node limit: Maximum total number of octree nodes allowed [S1].

### Algorithm Steps

1.  **Initialization:**
    *   Initialize the octree from the ROI.
    *   Disable all nodes outside the ROI [S1].
    *   Initialize density grids in enabled nodes (e.g., zeros or small random values) [G].

2.  **Coarse-to-Fine Optimization (Two-Stage Training):**
    *   **Stage 1: Octree Structure Update.**
        *   Use down-sampled projections to update the octree topology.
        *   For each iteration:
            *   Uniformly sample points inside each enabled node.
            *   Compute the standard deviation (SD) of densities within each node.
            *   If SD is significant, the node has a higher chance of being divided.
            *   Solve a mixed-integer program to divide, merge, or keep octants, ensuring the total number of nodes remains below the fixed limit [S1].
    *   **Stage 2: Density Grid Optimization.**
        *   Freeze the octree structure.
        *   Use original noisy projections to update the density grids in each enabled node [S1].

3.  **Ray Sampling:**
    *   For each ray in the current batch:
        *   Identify all octree nodes crossed by the ray.
        *   For each node $oc$, calculate the number of samples $N_{oc}$:
            $$ N_{oc} = N_{max} \frac{loc}{doc} $$
            where $loc$ is the length of the ray segment inside node $oc$, and $doc$ is the diagonal length of node $oc$ [S1].
        *   Perform stratified random sampling to select $N_{oc}$ 3D positions along the ray segment within node $oc$ [S1].

4.  **Density Query:**
    *   For a 3D point $p$ located within an octree node:
        *   Identify the 8 vertices of the density grid cell containing $p$.
        *   Compute density $f_\phi(p)$ using trilinear interpolation of the stored densities at these vertices [S1].

5.  **Loss Computation:**
    *   **Data Fidelity Loss ($L_{data}$):**
        $$ L_{data}(\phi) = \frac{1}{N} \sum_{i=1}^{N} || M (A f_\phi(p_i) - b_i) ||_2^2 $$
        where $N$ is the batch size (number of sampling points), $A$ is the Radon transform (projection operator), $b_i$ is the measured intensity, and $M$ is the binary mask excluding fiducial markers and borders [S1].
    *   **Cross-Nodes Non-Local Constraint Loss ($L_{cnlc}$):**
        *   Randomly select two enabled nodes $m$ and $n$ inside the ROI.
        *   Sample densities $f_\phi(p_i^m)$ from node $m$ and $f_\phi(p_j^n)$ from node $n$.
        $$ L_{cnlc} = \sum || \text{softmax}(f_\phi(p_i^m)^T f_\phi(p_j^n)) f_\phi(p_j^n) - f_\phi(p_i^m) ||_2^2 $$
        This term estimates similarities between density vectors in different nodes to enforce non-local consistency [S1].
    *   **Total Variation Loss ($L_{tv}$):**
        *   Standard TV regularization on the density grids to smooth noise [S1].
    *   **Boundary Consistency Loss ($L_{bc}$):**
        *   Minimizes density differences between neighboring grids at their shared boundaries to prevent discontinuity artifacts caused by independent node optimization [S1].
    *   **Total Loss:**
        $$ L_{total} = L_{data} + k_{tv} L_{tv} + k_{cnlc} L_{cnlc} + k_{bc} L_{bc} $$
        [S1]

6.  **Reconstruction:**
    *   Uniformly sample the volume in the ROI.
    *   Query density at each sample position using the learned density grids and trilinear interpolation [S1].

### Edge Cases and Pitfalls
*   **Noise Model:** Raw cryo-ET data follows a Poisson noise model, but preprocessing (motion/intensity correction) makes it approximately Gaussian, which is assumed for the loss function [S1].
*   **Discontinuities:** Independent optimization of octree nodes causes discontinuity artifacts at grid edges. This is mitigated by the boundary consistency loss $L_{bc}$ [S1].
*   **Fiducial Markers:** Rays intersecting fiducial markers or padded gray regions interfere with reconstruction. A binary mask $M$ excludes these rays from the data-fidelity loss [S1].
*   **Standard Neural Fields:** MLP-based neural fields are inadequate for high-noise cryo-ET as they either learn noise or oversmooth features. ADG addresses this via explicit regularization and adaptive grids [S1].

## Operating characteristics

*   **Time Complexity:** Faster than MLP-based neural fields because density query uses trilinear interpolation ($O(1)$) instead of network evaluation ($O(D)$ where $D$ is network depth/width) [S1]. However, octree updates involve solving a mixed-integer program, which adds overhead [S1].
*   **Memory Complexity:** Lower than classical tomographic reconstruction techniques as it does not store the entire 3D volume during optimization, only the octree nodes and their grids [S1]. Memory usage scales with the number of enabled nodes and grid resolution $N_x \times N_y \times N_z$ [S1].
*   **Performance:** Demonstrated on EMPIAR 10643, EMPIAR 10453, and EMPIAR 11462 datasets [S1]. Outperforms SART+TV, Kniesel et al., and NeAT in handling high noise and preserving details [S1].
*   **Strengths:** Fast querying, better detail preservation in complex regions, effective denoising of uniform regions, explicit regularization capabilities [S1].
*   **Limitations:** Requires careful tuning of regularization weights ($k_{tv}, k_{cnlc}, k_{bc}$) and octree update parameters. Mixed-integer programming for node updates can be computationally expensive [S1].

## Background

*   **Origin:** Proposed by Wang et al. in "Adaptive differentiable grids for cryo-electron tomography reconstruction and denoising" (2023) [S1].
*   **History:** Builds on recent advances in neural representations (NeRF) and octree-based structures (ACORN, NeAT) to address the specific challenges of cryo-ET, such as low SNR and missing wedge artifacts [S1].
*   **Usage:** Applied to cryo-electron tomography reconstruction and denoising for biological samples like viruses and cells [S1].
