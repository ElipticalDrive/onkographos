# SparseConvNet-based Skeletal Feature Sampling

Also called: 3D sparse convolution feature diffusion, SparseConvNet sampling

## Overview
This method samples time-augmented skeletal features at arbitrary 3D query points by diffusing discrete skeletal features into a continuous 3D volume using sparse convolutions, enabling spatially aware feature retrieval for NeRF input [S1, unofficial]. It differs from dense voxelization by using sparse convolutions to process only occupied voxels, improving efficiency for large 3D spaces [S1, unofficial].

## How it works
**Inputs:**
* SMPL parameters defining the human body pose and shape [S1, unofficial].
* Discrete skeletal features initialized on a voxel grid [S1, unofficial].
* A 3D query point $x$ in world coordinates [S1, unofficial].

**Outputs:**
* A sampled skeletal feature vector $s^x \in \mathbb{R}^{C \times 128}$ [S1, unofficial].

**Data Structures:**
* **Input Volume:** A 3D grid of dimensions $D_0 \times H_0 \times W_0$ representing the 3D bounding box of the human body [S1, unofficial].
* **SparseConvNet Architecture:** A sequence of sparse convolutional layers with batch normalization and ReLU activation [S1, unofficial]. The architecture is defined as follows [S1, unofficial]:
    * Layer 1: $(3 \times 3 \times 3 \text{ conv}, 64 \text{ features}, \text{stride } 1) \times 2$ [S1, unofficial]
    * Layer 2: $(3 \times 3 \times 3 \text{ conv}, 64 \text{ features}, \text{stride } 2)$ [S1, unofficial]
    * Layer 3: $(3 \times 3 \times 3 \text{ conv}, 64 \text{ features}, \text{stride } 1) \times 2$ [S1, unofficial]
    * Layer 4: $(3 \times 3 \times 3 \text{ conv}, 64 \text{ features}, \text{stride } 2)$ [S1, unofficial]
    * Layer 5: $(3 \times 3 \times 3 \text{ conv}, 64 \text{ features}, \text{stride } 1) \times 3$ [S1, unofficial]
    * Layer 6: $(3 \times 3 \times 3 \text{ conv}, 64 \text{ features}, \text{stride } 2)$ [S1, unofficial]
    * Layer 7: $(3 \times 3 \times 3 \text{ conv}, 128 \text{ features}, \text{stride } 1) \times 3$ [S1, unofficial]
    * Layer 8: $(3 \times 3 \times 3 \text{ conv}, 128 \text{ features}, \text{stride } 2)$ [S1, unofficial]
    * Layer 9: $(3 \times 3 \times 3 \text{ conv}, 128 \text{ features}, \text{stride } 1) \times 3$ [S1, unofficial]
    * Layer 10: $(3 \times 3 \times 3 \text{ conv}, 128 \text{ features}, \text{stride } 2)$ [S1, unofficial]
    * Layer 11: $(3 \times 3 \times 3 \text{ conv}, 128 \text{ features}, \text{stride } 1) \times 3$ [S1, unofficial]
    * Layer 12: $(3 \times 3 \times 3 \text{ conv}, 128 \text{ features}, \text{stride } 2)$ [S1, unofficial]
    * Layer 13: $(3 \times 3 \times 3 \text{ conv}, 128 \text{ features}, \text{stride } 1) \times 3$ [S1, unofficial]
    * Layers 14-17: Resize and concatenate outputs of layers 5, 9, 13, and 17 [S1, unofficial].

**Steps:**
1. Compute the 3D bounding box of the human body based on the SMPL parameters [S1, unofficial].
2. Divide the 3D bounding box into voxels of size $5\text{mm} \times 5\text{mm} \times 5\text{mm}$, resulting in a volume of dimensions $D_0 \times H_0 \times W_0$ [S1, unofficial].
3. Transform skeletal feature locations and the query location $x$ to the SMPL coordinate system to ensure invariance to world position and orientation [S1, unofficial].
4. Pass the input volume through the SparseConvNet architecture, which consists of 3D sparse convolutions that diffuse the skeletal features into the nearby 3D space [S1, unofficial].
5. Resize and concatenate the multi-scale outputs from layers 5, 9, 13, and 17 to form the output feature [S1, unofficial].
6. Sample the corresponding skeletal feature at query location $x$ via trilinear interpolation from the concatenated output volume [S1, unofficial].
7. Pass the sampled feature through a fully-connected layer to reduce the channel size to 128 [S1, unofficial].

**Formulas:**
* Input volume dimensions: $D_0 \times H_0 \times W_0$ [S1, unofficial].
* Output feature dimensions before reduction: $D'/16 \times H'/16 \times W'/16 \times 384$, where $D', H', W'$ correspond to the spatial dimensions after the respective strided convolutions [S1, unofficial].

**Parameters:**
* Voxel size: $5\text{mm} \times 5\text{mm} \times 5\text{mm}$ [S1, unofficial].
* Output channel size after reduction: 128 [S1, unofficial].

**Edge Cases and Pitfalls:**
* The method relies on the accuracy of the SMPL parameters to define the bounding box and coordinate transformation [S1, unofficial].
* Sparse convolutions require efficient data structures to handle sparsity [G].
