# Frequency-Modulated Position Encoding

Also called: FM-NeRF Encoding, Frequency-Modulated Point Cloud Rendering with Easy Editing

## Overview
Frequency-Modulated Position Encoding (FMPE) is a coordinate encoding scheme used in point-based radiance field optimization to map 3D spatial coordinates and viewing directions into a high-dimensional feature space. It solves the problem of representing high-frequency details in sparse point clouds by applying frequency modulation via sine and cosine functions with exponentially spaced frequencies. Unlike standard NeRF positional encoding which uses integer powers of 2, FMPE uses fractional powers (specifically $2^{k/2}$), providing finer-grained basis function support for frequency modulation [S1]. It is distinct from hash-based or grid-based encodings by relying on explicit sinusoidal transformations of raw coordinates, and from other NeRF configurations by its specific application to point cloud rasterization and iterative denoising/completion pipelines [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D position vector $\mathbf{p} \in \mathbb{R}^3$ (for spatial coordinates) or a viewing direction vector $\mathbf{d} \in S^2$ (for view directions).
*   **Output:** An encoded feature vector $\gamma(\mathbf{p})$ or $\gamma(\mathbf{d})$ of dimension $2 \times L \times D$, where $L$ is the number of frequency bands and $D$ is the dimensionality of the input (3 for position, 3 for direction).

**Data Structures:**
The encoding is a static transformation applied to input vectors. No persistent data structure is required beyond the input vector and the scalar parameter $L$. The output is a concatenated tuple of sine and cosine values.

**Parameters:**
*   $L$: Number of frequency bands.
    *   For spatial coordinates: $L = 10$ [S1].
    *   For view directions: $L = 2$ [S1].
*   $\lambda_{sparse}$: Weight for sparse regularization loss. Default value: $5 \times 10^{-4}$ [S1].

**Formulas:**
The frequency-modulated positional encoding $\gamma(\mathbf{p})$ is defined as [S1]:

$$
\gamma (\mathbf {p}) = \left (\sin \left (2^0 \pi \mathbf {p}\right ), \cos \left (2^0 \pi \mathbf {p}\right ), \sin \left (2^{0.5} \pi \mathbf {p}\right ), \cos \left (2^{0.5} \pi \mathbf {p}\right ), \dots, \sin \left (2^{L-1} \pi \mathbf {p}\right ), \cos \left (2^{L-1} \pi \mathbf {p}\right ) \right )
$$

Where:
*   $\mathbf{p}$ is the input coordinate or direction vector.
*   The exponent for the $k$-th band (0-indexed) is $k/2$.
*   The output vector has length $2 \times L \times \text{dim}(\mathbf{p})$.

**Numbered Steps:**
1.  **Preprocessing:** Perform 4-20 loops of point cloud denoising and completion. For every denoising step, train for 300 epochs. When training converges, remove low-opacity points [S1].
2.  **Encoding:** For each point in the cloud, compute the frequency-modulated encoding for its spatial position $\mathbf{p}$ using $L=10$ bands. Compute the encoding for the viewing direction $\mathbf{d}$ using $L=2$ bands [S1].
3.  **Concatenation:** Concatenate the spatial encoding and view direction encoding to form the input feature vector for the neural network [S1].
4.  **Decoding:** Pass the concatenated features through the AFNet MLP (5 layers, input dim 120, hidden dims 256, 256, 256, 128, output dim 11) to predict raw color and features [S1].
5.  **Rasterization:** Expand each point to a disk. Select the radius based on two rules: (1) cover gaps between points to prevent bleeding (seeing occluded surfaces/background), and (2) keep radius as small as possible to avoid inaccurate depth estimation and edge expansion [S1].
6.  **Loss Calculation:** Minimize the total loss $\mathcal{L} = \mathcal{L}_{RGB} + \lambda_{sparse} \mathcal{L}_{sparse}$. For scenes without background, add transparency loss (L2 distance of predicted vs ground truth transparency) [S1].
    *   $\mathcal{L}_{RGB} = ||\hat{C} - C_{gt}||_2^2$
    *   $\mathcal{L}_{sparse} = \frac{1}{N} \sum_{i=1}^N [\log(\alpha_i) + \log(1-\alpha_i)]$
    *   Where $\hat{C}$ is predicted color, $C_{gt}$ is ground truth color, $N$ is number of points, and $\alpha_i$ is opacity of point $i$ [S1].
7.  **Optimization:** Update MLP weights with learning rate $5 \times 10^{-4}$ and opacity parameters $\alpha$ with learning rate $0.01$ [S1].

**Pseudocode:**

```python
import math
import numpy as np

def frequency_modulated_encoding(p, L):
    """
    Computes the frequency-modulated positional encoding for input p.
    
    Args:
        p (np.ndarray): Input vector of shape (D,) where D is 3.
        L (int): Number of frequency bands.
        
    Returns:
        np.ndarray: Encoded vector of shape (2 * L * D,).
    """
    encoded_parts = []
    for k in range(L):
        # Exponent is k / 2.0
        exponent = k / 2.0
        freq = 2.0 ** exponent * math.pi
        
        # Apply to each dimension of p
        sin_vals = np.sin(freq * p)
        cos_vals = np.cos(freq * p)
        
        encoded_parts.append(sin_vals)
        encoded_parts.append(cos_vals)
        
    return np.concatenate(encoded_parts)

def compute_loss(predicted_color, gt_color, opacities, lambda_sparse):
    """
    Computes the total loss for FMPE training.
    
    Args:
        predicted_color (np.ndarray): Predicted color vector.
        gt_color (np.ndarray): Ground truth color vector.
        opacities (np.ndarray): Array of opacity values alpha_i.
        lambda_sparse (float): Weight for sparse loss.
        
    Returns:
        float: Total loss value.
    """
    # L2 loss for RGB
    l_rgb = np.sum((predicted_color - gt_color) ** 2)
    
    # Sparse loss
    # log(alpha_i) + log(1 - alpha_i)
    # Note: In practice, clamp opacities to avoid log(0)
    safe_opacities = np.clip(opacities, 1e-7, 1 - 1e-7)
    sparse_term = np.mean(np.log(safe_opacities) + np.log(1 - safe_opacities))
    l_sparse = sparse_term
    
    total_loss = l_rgb + lambda_sparse * l_sparse
    return total_loss
```

**Edge Cases and Pitfalls:**
*   **Bleeding Problem:** If the rasterization radius is too small, points from occluded surfaces and the background can be seen through the front surface [S1].
*   **Edge Expansion:** If the rasterization radius is too large, it leads to inaccurate depth estimation and object edges expand [S1].
*   **Low Opacity Points:** Low-opacity points should be removed when training converges to clean up the point cloud [S1].
*   **Completion Noise:** The completion step in preprocessing introduces additional noise, but this is removed in the denoising stage of the next iteration [S1].

## Subtopics

### AFNet MLP
A 5-layer MLP used for decoding the encoded features. Input feature dimension is 120, hidden dimensions are 256, 256, 256, 128, and output dimension is 11 (3-channel raw image + 8-channel feature map) [S1].

### Point Cloud Denoising and Completion
A preprocessing loop (4-20 loops) alternating between denoising and completion, with 300 epochs of training per denoising step [S1].

### Rasterization Radius Selection
A heuristic method for selecting the disk radius for point expansion to balance bleeding and edge expansion [S1].

## Operating characteristics
*   **Time Complexity:** One epoch consumes approximately 12.8 seconds on the NeRF-Synthetic dataset [S1]. Realistic rendering is achieved in 10 minutes, but almost convergence takes about 10 hours [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Achieves higher PSNR/SSIM on NeRF-Synthetic and Tanks and Temples datasets compared to NeRF, CCNeRF, NPBG, NPBG++, and Huang et al. Comparable or better results on ScanNet and DTU datasets [S1].
*   **Scaling:** Training size is typically 800x800 with random scaling augmentation [0.5, 1.5] of side length. Test resolution is 800x800 for NeRF-Synthetic, 1920x1056 for Tanks and Temples, 1200x1600 for ScanNet, and 960x1200 for DTU [S1].
*   **Strengths:** Fast convergence to realistic rendering (10 minutes), high quality on synthetic and real-world datasets, easy editing capabilities [S1].
*   **Limitations:** Requires iterative preprocessing (denoising/completion), sensitive to rasterization radius selection (though ablation shows it is not significant), relies on initial point clouds from MVSNet or depth maps [S1].
*   **When to Use:** Suitable for point-based radiance field optimization where high-frequency details are needed and initial point clouds are available. Particularly effective for scenes with sparse point clouds where frequency modulation helps capture fine details.
*   **When Not to Use:** Not suitable for scenes without initial point clouds or depth maps. May not be optimal for real-time applications requiring sub-second training times beyond the initial 10 minutes.

## Background
Frequency-Modulated Position Encoding was introduced in the paper "Frequency-Modulated Point Cloud Rendering with Easy Editing" [S1]. It builds on the positional encoding form of NeRF [21] but narrows the encoding interval to provide more fine-grained basis function support for frequency modulation. The method is part of a pipeline that includes point cloud denoising, completion, and rasterization, aiming to improve rendering quality and editing capabilities for point-based radiance fields. It has been evaluated on datasets such as NeRF-Synthetic, Tanks and Temples, ScanNet, and DTU [S1].
