# Rip-NeRF

Also called: Rip-NeRF25k

## Overview
Rip-NeRF is a radiance field method that uses Ripmap-Encoded Platonic Solids to enable efficient anisotropic area-sampling of 3D space for high-fidelity anti-aliased rendering [S1]. It differs from sibling methods like Zip-NeRF by replacing multi-sampling mechanisms with a hybrid representation that projects anisotropic 3D Gaussians onto the faces of a Platonic solid, querying features via tetra-linear interpolation on a Ripmap [S1]. This approach achieves faster training, smaller model size, and higher rendering speeds compared to Zip-NeRF, while maintaining competitive image quality [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of calibrated multi-view 2D images.
*   **Outputs:** Rendered high-fidelity anti-aliased images.

**Data Structures:**
1.  **Ripmap Encoding ($R$):** A hierarchical feature grid.
    *   **Base Level ($R_{0,0}$):** Learnable tensor with shape $H \times W \times C$. Default dimensions: $H=512, W=512, C=16$ [S1].
    *   **Derived Levels:** Generated from $R_{0,0}$ using average pooling to ensure consistency and compactness [S1].
2.  **Platonic Solid:** A geometric primitive used for projection. Default is an icosahedron with 10 unparalleled faces [S1].
3.  **Anisotropic 3D Gaussian:** Characterizes each conical frustum, parameterized by mean $\boldsymbol{\mu}$ and covariance $\boldsymbol{\Sigma}$ [S1].
4.  **Tiny MLP ($F_\theta$):** A small neural network to estimate color $\mathbf{c}$ and density $\sigma$ [S1].

**Numbered Steps:**

1.  **Cone Casting and Frustum Division:**
    For each pixel, cast a cone into the scene and divide it into multiple conical frustums [S1]. This avoids discrete point-based sampling of continuous signals [S1].

2.  **Gaussian Characterization:**
    Characterize each conical frustum as an anisotropic 3D Gaussian with mean $\boldsymbol{\mu}$ and covariance $\boldsymbol{\Sigma}$ [S1].

3.  **Platonic Solid Projection:**
    Project the 3D Gaussian onto the $n$ unparalleled faces $\{P_i | i = 1, \dots, n\}$ of the Platonic solid to form 2D Gaussians [S1].
    For each face $P_i$, compute the projected mean $\boldsymbol{\mu}^{proj}_i$ and covariance $\boldsymbol{\Sigma}^{proj}_i$ using the projection matrix $M_i \in \mathbb{R}^{3 \times 2}$ that maps the 3D world coordinate system to the 2D coordinate system of plane $P_i$ [S1]:
    $$ \boldsymbol{\mu}^{proj}_i = M_i^T \boldsymbol{\mu} $$
    $$ \boldsymbol{\Sigma}^{proj}_i = M_i^T \boldsymbol{\Sigma} M_i $$
    [S1]

4.  **Ripmap Querying:**
    For each projected 2D Gaussian on face $P_i$, query a feature vector $\mathbf{f}_i$ from the Ripmap Encoding using tetra-linear interpolation [S1].
    The interpolation position $(p_x, p_y)$ is determined by the mean $\boldsymbol{\mu}^{proj}_i$ [S1].
    The interpolation levels $(l_x, l_y)$ are determined by the covariance $\boldsymbol{\Sigma}^{proj}_i$ [S1].
    The level indices are calculated to cover the probability mass of the Gaussian footprint, adjusted by hyper-parameter $w=2.0$ [S1].
    The Ripmap levels are derived from the base level $R_{0,0}$ using average pooling [S1]:
    $$ R_{i,j} = \begin{cases} \text{Avg}_{2\times1} R_{i, j-1} & \text{if } j \neq 0 \\ \text{Avg}_{1\times2} R_{i-1, j} & \text{if } i \neq 0 \text{ \& } j = 0 \\ R_{0,0} & \text{otherwise} \end{cases} $$
    [S1]

5.  **Feature Aggregation:**
    Concatenate all feature vectors $\{\mathbf{f}_i | i = 1, \dots, n\}$ from the Platonic solid faces and the encoded view direction $\mathbf{d}$ to form the final feature vector $\mathbf{f}$ [S1].

6.  **Density and Color Estimation:**
    Pass the aggregated feature vector $\mathbf{f}$ through the tiny MLP $F_\theta$ to estimate the density $\sigma$ and color $\mathbf{c}$ of the conical frustum [S1].

7.  **Volume Rendering:**
    Render the pixel color using standard volume rendering with the estimated $\sigma$ and $\mathbf{c}$ [S1].

8.  **Optimization:**
    Optimize the system end-to-end using a photometric loss between rendered and observed images [S1].
    The loss is scaled by the area of the pixel footprint on the image plane (area loss $L_{area}$) [S1].

**Parameters:**
*   **Ripmap Base Level ($R_{0,0}$):** Shape $H=512, W=512, C=16$ [S1].
*   **Platonic Solid:** Default is icosahedron (10 faces) [S1].
*   **Hyper-parameter $w$:** Set to 2.0 to adjust Gaussian footprint coverage [S1].
*   **Optimizer:** AdamW [S1].
*   **Iterations:** 120k for Rip-NeRF; 25k for Rip-NeRF25k [S1].
*   **Weight Decay:** $1 \times 10^{-5}$ [S1].
*   **Initial Learning Rate:** $2 \times 10^{-3}$, modulated by MultiStepLR [S1].
*   **Ripmap Learning Rate:** Scaled up by 10.0 times [S1].

**Edge Cases and Pitfalls:**
*   **Empty Space:** Use a binary occupancy grid (e.g., from NerfAcc) to skip samples in empty areas [S1].
*   **Precision:** The Ripmap levels are derived from the base level to ensure consistency, which may limit flexibility compared to fully independent grids [S1].
*   **Hardware:** Requires CUDA kernels for efficient Platonic Solid Projection and Ripmap Encoding [S1].

## Operating characteristics
*   **Training Time:** 2.6 hours on NVIDIA A100-SXM4-80GB GPU for Rip-NeRF; 32 minutes for Rip-NeRF25k [S1].
*   **Model Size:** 160 MB [S1].
*   **GPU Memory:** 20 GB during training [S1].
*   **Rendering Speed:** 3 FPS [S1].
*   **Comparison:** Outperforms Zip-NeRF in training time (2.6h vs 4.5h), model size (160MB vs 592MB), and rendering speed (3 FPS vs 0.25 FPS) [S1]. Zip-NeRF has slightly better SSIM [S1].
*   **Strengths:** High-fidelity anti-aliasing, efficient anisotropic area-sampling, compact representation [S1].
*   **Limitations:** Requires calibrated multi-view images; performance on unbounded scenes may be inferior to methods like Zip-NeRF designed for such scenes [S1].

## Background
Rip-NeRF was introduced in 2024 by authors including SRN, as cited in the SIGGRAPH Conference Papers [S1]. It builds on the hybrid representation approach, combining explicit (Gaussians) and implicit (Ripmap) features, inspired by methods like Mip-NeRF, Tri-MipRF, and Zip-NeRF [S1]. The method addresses the inefficiency of multi-sampling mechanisms in previous area-sampling methods by introducing Ripmap-Encoded Platonic Solids [S1].
