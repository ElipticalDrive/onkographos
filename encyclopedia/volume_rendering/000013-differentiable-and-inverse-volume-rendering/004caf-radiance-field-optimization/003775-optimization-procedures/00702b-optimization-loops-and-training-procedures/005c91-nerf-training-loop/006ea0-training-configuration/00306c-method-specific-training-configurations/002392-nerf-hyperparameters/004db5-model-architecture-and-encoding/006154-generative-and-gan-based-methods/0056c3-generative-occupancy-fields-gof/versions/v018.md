# Generative Occupancy Fields (GOF)

## Overview
Generative Occupancy Fields (GOF) is a 3D-aware image synthesis method that combines radiance fields with occupancy representations to learn compact object surfaces without impeding training convergence [S1, unofficial]. It solves the problem of diffused surfaces in prior generative radiance fields (like pi-GAN) and the sparse gradient convergence issues in direct occupancy networks by transitioning from cumulative volume rendering to surface-point rendering [S1, unofficial]. Unlike its siblings that predict volume densities, GOF predicts alpha values interpreted as occupancy, enabling surface-aware synthesis via root-finding [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A latent code $z \sim p_z$ (typically truncated for inference) and a camera pose $\xi \sim p_\xi$.
*   **Output:** A synthesized 2D image $I$.
*   **Model:** A generator network $g_\theta$ (FiLMed-SIREN backbone) that predicts alpha values $\alpha_\theta(x, z)$ and color $c_\theta(x, d, z)$ at 3D points $x$ and directions $d$.

**Data Structures:**
*   **Ray:** Defined by origin $o$ and direction $d$, parameterized as $r(t) = o + td$.
*   **Sampling Interval:** $\Delta$, which shrinks during training.
*   **Bounds:** Near bound $t_n$ and far bound $t_f$.

**Numbered Steps:**

1.  **Surface Location via Root-Finding:**
    To locate the surface $S$ along a ray, GOF samples $M$ evenly-spaced points $x_k$ partitioning the volume $[t_n, t_f]$. It queries the generator for alpha values $\alpha_\theta(x_k, z)$. The bin $k_S$ where the alpha crosses the threshold $\tau$ is found:
    $$ k_S = \arg\min_k (\alpha_\theta(x_k, z) < \tau \le \alpha_\theta(x_{k+1}, z)) $$
    where $\tau$ is a pre-defined threshold (typically 0.5) [S1, unofficial]. The secant method is applied iteratively $m_s$ times (typically 3) to find the precise surface point $x_s = o + t_s d$ within the bin $[x_{k_S}, x_{k_S+1}]$ [S1, unofficial]. Note: These $M$ points do not require gradient computation in implementation [S1, unofficial].

2.  **Shrinking Sampling Region:**
    During training, the sampling region is gradually shrunk to focus on the surface.
    *   Initialize sampling interval $\Delta_{init} = (t_f - t_n)/2$.
    *   At training step $n$, compute the current interval:
        $$ \Delta_n = \max(\Delta_{init} \exp(-\gamma n), \Delta_{min}) $$
        where $\Delta_{min}$ is a pre-defined minimum value [S1, unofficial].
    *   Sample $N$ points uniformly in the interval $[t_s - \Delta_n, t_s + \Delta_n]$. The $i$-th point's depth $t_i$ is sampled from:
        $$ t_i \sim U\left[t_s - \Delta_n + \frac{2i-2}{N}\Delta_n, t_s - \Delta_n + \frac{2i}{N}\Delta_n\right] $$
    *   If the region $[t_s - \Delta_n, t_s + \Delta_n]$ exceeds the global bounds $[t_n, t_f]$, shift it back to fit within $[t_n, t_f]$ [S1, unofficial].

3.  **Rendering:**
    Render the image using alpha composition. The integrated color $\tilde{C}(r)$ for a ray $r$ is:
    $$ \tilde{C}(r, z) = \sum_{i=1}^{N} \alpha_\theta(x_i, z) \left( \prod_{j<i} (1 - \alpha_\theta(x_j, z)) \right) c_\theta(x_i, d, z) $$
    where $\alpha_\theta(x_i, z)$ is the predicted alpha (occupancy) and $c_\theta(x_i, d, z)$ is the emitted color [S1, unofficial].
    *   **Inference Option:** For speed, GOF can render using only the single surface point $x_s$ (i.e., $N=1$) [S1, unofficial].

**Pseudocode:**

```python
def gof_render(ray_origin, ray_direction, generator, latent_code, 
               t_n, t_f, N_render, M_bins, m_s, tau, gamma, n_step, delta_min):
    """
    Renders a single ray using Generative Occupancy Fields.
    
    Args:
        ray_origin: (3,) array, camera origin o.
        ray_direction: (3,) array, camera direction d.
        generator: Function g_theta(x, z) -> (alpha, color).
        latent_code: (Z,) array, truncated latent code z.
        t_n: float, near bound.
        t_f: float, far bound.
        N_render: int, number of points for rendering (default 12).
        M_bins: int, number of bins for root-finding (default 12).
        m_s: int, number of secant iterations (default 3).
        tau: float, threshold for surface detection (default 0.5).
        gamma: float, decay rate for shrinking interval.
        n_step: int, current training step.
        delta_min: float, minimum sampling interval.
        
    Returns:
        color: (3,) array, rendered pixel color.
    """
    # Step 1: Locate Surface via Root-Finding
    # Sample M evenly-spaced points in [t_n, t_f]
    t_bins = linspace(t_n, t_f, M_bins + 1)
    x_bins = ray_origin + t_bins[:, None] * ray_direction[None, :]
    
    # Query alpha values (no gradients needed for root-finding)
    alphas = []
    for x in x_bins:
        alpha, _ = generator(x, latent_code)
        alphas.append(alpha)
    alphas = array(alphas)
    
    # Find bin where alpha crosses tau
    # k_S is the index such that alpha[k_S] < tau <= alpha[k_S+1]
    # Handle edge cases: if all < tau, surface is beyond t_f; if all >= tau, before t_n
    # Assuming valid surface exists within bounds for standard operation
    crossing_indices = where((alphas[:-1] < tau) & (alphas[1:] >= tau))[0]
    if len(crossing_indices) == 0:
        # Fallback or error handling: use midpoint or nearest
        k_S = M_bins // 2 
    else:
        k_S = crossing_indices[0]
        
    x_start = x_bins[k_S]
    x_end = x_bins[k_S + 1]
    t_start = t_bins[k_S]
    t_end = t_bins[k_S + 1]
    
    # Secant method to refine surface point t_s
    t_curr = t_start
    t_prev = t_end # Initialize with other end of bin
    for _ in range(m_s):
        alpha_curr, _ = generator(x_start + (t_curr - t_start) * ray_direction, latent_code)
        alpha_prev, _ = generator(x_start + (t_prev - t_start) * ray_direction, latent_code)
        
        # Secant update: t_new = t_curr - alpha_curr * (t_prev - t_curr) / (alpha_prev - alpha_curr)
        # Note: The paper describes applying secant method to find the root of alpha - tau = 0
        # Let f(t) = alpha(t) - tau
        f_curr = alpha_curr - tau
        f_prev = alpha_prev - tau
        
        if abs(f_prev - f_curr) < 1e-8:
            break
            
        t_next = t_curr - f_curr * (t_prev - t_curr) / (f_prev - f_curr)
        
        # Clamp to bin
        t_next = max(t_start, min(t_end, t_next))
        
        t_prev = t_curr
        t_curr = t_next
        
    t_s = t_curr
    x_s = ray_origin + t_s * ray_direction
    
    # Step 2: Determine Sampling Interval
    delta_init = (t_f - t_n) / 2.0
    delta = max(delta_init * exp(-gamma * n_step), delta_min)
    
    # Define sampling range [t_s - delta, t_s + delta]
    t_min_sample = t_s - delta
    t_max_sample = t_s + delta
    
    # Clamp to global bounds [t_n, t_f]
    t_min_sample = max(t_min_sample, t_n)
    t_max_sample = min(t_max_sample, t_f)
    
    # Step 3: Render
    # Sample N points in [t_min_sample, t_max_sample]
    t_samples = linspace(t_min_sample, t_max_sample, N_render + 1)
    # Uniform sampling within the interval segments
    # The paper specifies: t_i ~ U[t_s - delta + (2i-2)/N * delta, t_s - delta + 2i/N * delta]
    # This is equivalent to uniform sampling in [t_s - delta, t_s + delta]
    # We use the endpoints calculated above for clamping
    t_points = linspace(t_min_sample, t_max_sample, N_render)
    x_points = ray_origin + t_points[:, None] * ray_direction[None, :]
    
    # Query alpha and color
    alphas_render = []
    colors_render = []
    for x in x_points:
        alpha, color = generator(x, latent_code)
        alphas_render.append(alpha)
        colors_render.append(color)
    alphas_render = array(alphas_render)
    colors_render = array(colors_render)
    
    # Alpha Composition
    # T_i = product_{j<i} (1 - alpha_j)
    # C = sum_{i=1}^N T_i * alpha_i * c_i
    # Note: The paper formula (4) uses alpha_i directly as the weight contribution term 
    # multiplied by the transmittance from previous points.
    # Standard volume rendering: C = sum T_i * (1 - exp(-sigma * delta)) * c
    # GOF reformulates: alpha = 1 - exp(-sigma * delta).
    # So C = sum T_i * alpha_i * c_i, where T_i = product_{j<i} (1 - alpha_j)
    
    transmittance = 1.0
    color = zeros(3)
    for i in range(N_render):
        alpha_i = alphas_render[i]
        c_i = colors_render[i]
        color += transmittance * alpha_i * c_i
        transmittance *= (1.0 - alpha_i)
        
    return color
```

**Parameters:**
*   $\tau$ (Threshold): Pre-defined threshold for root-finding. Typical value: 0.5 [S1, unofficial].
*   $N$ (Rendering Samples): Points sampled for rendering. Typical value: 12 [S1, unofficial].
*   $M$ (Root-finding Bins): Points used for surface location. Typical value: 12 [S1, unofficial].
*   $m_s$ (Secant Iterations): Number of iterative refinements. Typical value: 3 [S1, unofficial].
*   $\Delta_{min}$: Minimum sampling interval. Value not given in the sources.

**Edge Cases and Pitfalls:**
*   **Shape-Color Ambiguity:** Direct training of generative radiance fields fails to maintain surface compactness because small perturbations on surfaces still lead to realistic RGB images, fooling the discriminator [S1, unofficial]. GOF mitigates this by focusing weights on the surface via shrinking.
*   **Density Thresholding:** Predicted densities in generative radiance fields range from 0 to 50, making it hard to determine an effective threshold for surface location. GOF avoids this by predicting alpha values in $[0, 1]$ [S1, unofficial].
*   **Convergence:** Directly applying occupancy representations causes severe convergence problems due to sparse gradients. GOF solves this by starting with cumulative rendering (radiance field) and transitioning to surface rendering [S1, unofficial].
*   **Boundary Clamping:** If the shrinking sampling region exceeds $[t_n, t_f]$, it must be shifted back to fit within bounds [S1, unofficial].

## Operating characteristics
*   **Query Count:** GOF requires $M + m_s + N$ queries for standard rendering, or $M + m_s + 1$ for single-point surface rendering. Baselines (like pi-GAN) require $2N$ queries due to hierarchical sampling [S1, unofficial].
*   **Performance:** GOF outperforms baselines on MAD (Mean Angle Deviation, measuring compactness) and is comparable on SIDE (Scale-Invariant Depth Error, measuring depth accuracy) [S1, unofficial].
*   **Strengths:** Produces compact and smooth surfaces; alleviates the burden of sampling many points during inference; combines merits of radiance fields (easy training) and occupancy networks (compact surfaces) [S1, unofficial].
*   **Limitations:** Surface rendering mode may make furry cat images over-smooth and less realistic; more suitable for solid objects with only one surface [S1, unofficial].
*   **Scaling:** Not given in the sources.

## Background
*   **Origin:** Proposed by Xudong Xu, Xingang Pan, Dahua Lin, and Bo Dai from CUHK-SenseTime Joint Lab, Max Planck Institute for Informatics, and Nanyang Technological University [S1, unofficial].
*   **Paper:** "Generative Occupancy Fields for 3D Surface-Aware Image Synthesis" (arXiv:2111.00969v1, Nov 1, 2021) [S1, unofficial].
*   **History:** GOF addresses limitations in prior generative radiance fields like pi-GAN, which suffer from diffused surfaces, and occupancy networks, which suffer from convergence issues in generative settings. It builds on the observation that alpha values in cumulative rendering resemble occupancy values [S1, unofficial].
*   **Usage:** Evaluated on CelebA, BFM, and Cats datasets for 3D-aware image synthesis [S1, unofficial].
