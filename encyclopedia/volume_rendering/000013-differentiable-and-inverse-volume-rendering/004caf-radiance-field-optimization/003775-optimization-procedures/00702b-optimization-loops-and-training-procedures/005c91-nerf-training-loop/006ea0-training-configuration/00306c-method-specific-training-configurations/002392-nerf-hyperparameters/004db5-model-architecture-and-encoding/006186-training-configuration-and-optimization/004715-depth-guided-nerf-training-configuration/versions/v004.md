# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the hyperparameters, architecture modifications, and optimization settings for training a Neural Radiance Field (NeRF) model that incorporates depth priors to improve reconstruction quality, particularly in sparse-view or noisy-pose scenarios. It builds on [Model Architecture and Encoding](13550-model-architecture-and-encoding.md) by adding specific regularization and loss terms. It is distinguished from sibling methods like [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md) by its explicit integration of depth supervision via Earth Mover’s Distance (EMD) and uncertainty weighting, rather than semantic or geometric consistency losses alone.

## How it works
**Inputs:**
- Training images and corresponding camera poses.
- Ground truth depth maps (optional, used for loss calculation).
- Scene bounding box (normalized to $[0, 1]^3$).

**Outputs:**
- Trained NeRF model parameters (hash grid embeddings, MLP weights).
- Rendered images and depth maps.

**Data Structures:**
- **Hash Grids:** As defined in [Model Architecture and Encoding](13550-model-architecture-and-encoding.md).
- **MLP:** A multi-layer perceptron with ReLU activations. The first eight fully connected layers are followed by dropout layers.
- **Optimizer State:** Adam optimizer state for model parameters and a separate learning rate for the depth scale parameter.

**Parameters:**
- **Dropout Probability ($p$):** 0.1 [S1].
- **Depth Loss Weight ($\lambda$):** 0.007 for most scenes; 0.02 for scene 710 [S1].
- **Uncertainty Weight ($\gamma$):** 1 [S1].
- **Optimizer:** Adam [S1].
- **Learning Rate ($\eta$):** $5 \times 10^{-4}$ for model parameters [S1].
- **Learning Rate Schedule:** Reduce to $5 \times 10^{-5}$ after 80% of total steps [S1].
- **Weight Decay ($\omega$):** $1 \times 10^{-6}$ [S1].
- **Total Training Steps ($N$):** 500,000 [S1].
- **Depth Scale Learning Rate ($\eta_{scale}$):** $1 \times 10^{-7}$ [S1].
- **Depth Threshold ($\tau$):** $\tau = (\text{max\_depth} - \text{min\_depth}) \cdot 0.0001$ [S1]. For ScanNet, $\text{max\_depth} = 10$ and $\text{min\_depth} = 0.001$ [S1].

**Steps:**
1. **Initialize Model:** Initialize hash grids and MLP weights. Initialize Adam optimizer with $\eta = 5 \times 10^{-4}$ and weight decay $\omega = 1 \times 10^{-6}$ [S1].
2. **Add Dropout:** Insert dropout layers with probability $p=0.1$ after each of the first eight fully connected ReLU-activated layers in the MLP that encodes the positional encoding [S1].
3. **Sample Rays:** For each training step, sample rays through the scene. For each ray, sample points along the ray within the bounding box.
4. **Encode Points:** For each sampled point $\mathbf{x}$, compute the feature vector $\mathbf{f}$ using the hash grid encoding hierarchy defined in [Model Architecture and Encoding](13550-model-architecture-and-encoding.md) [S1].
5. **Predict Radiance and Depth:** Pass $\mathbf{f}$ through the MLP to predict volume density $\sigma$ and color $\mathbf{c}$. Predict depth $\hat{d}$ from the sampled points and weights [S1].
6. **Compute Color Loss:** Compute the photometric loss between rendered color $\hat{\mathbf{c}}$ and ground truth color $\mathbf{c}_{gt}$ (e.g., MSE) [S1].
7. **Compute Depth Loss:** If ground truth depth is available, compute the depth loss. The threshold $\tau$ is used to evaluate the uncertainty of the depth map [S1]. The depth loss is weighted by $\lambda$ [S1].
8. **Compute Uncertainty Loss:** Incorporate uncertainty weighting with weight $\gamma = 1$ [S1].
9. **Update Parameters:** Compute the total loss: $\mathcal{L} = \mathcal{L}_{color} + \lambda \mathcal{L}_{depth} + \gamma \mathcal{L}_{uncertainty}$ [S1]. Update model parameters using Adam [S1].
10. **Update Depth Scale:** Update the depth scale parameter using a separate learning rate $\eta_{scale} = 1 \times 10^{-7}$ [S1].
11. **Schedule Learning Rate:** After 80% of the total steps (400,000 steps), reduce the learning rate for model parameters to $5 \times 10^{-5}$ [S1].
12. **Repeat:** Repeat steps 3-11 for $N = 500,000$ steps [S1].

**Edge Cases and Pitfalls:**
- **Scene 710:** Requires a higher depth loss weight ($\lambda = 0.02$) compared to other scenes ($\lambda = 0.007$) [S1].
- **Depth Threshold:** The threshold $\tau$ must be computed per scene based on its specific depth range [S1].
- **Overfitting:** The dropout layers are critical for preventing overfitting, especially in sparse-view scenarios [S1].

## Subtopics

### DS-NeRF Depth Loss Integration
Integrates the depth loss implementation from the official DS-NeRF code base into the training pipeline. This variant requires re-training on LLFF train/test splits using released configuration files, as the original publication results for LLFF used a different split and DTU results could not be reproduced due to missing config files [S2].

## Operating characteristics
- **Time Complexity:** Dominated by the forward pass of the hash grid encoding and MLP for each sampled point. The total training time is proportional to the number of training steps (500,000) and the number of rays sampled per step [S1].
- **Memory Complexity:** Proportional to the size of the hash tables and the MLP weights. The hash table size is typically $2^{19}$ [S1].
- **Performance:** Improves reconstruction quality in sparse-view and noisy-pose scenarios by leveraging depth priors [S1].
- **Strengths:** Explicit depth supervision helps resolve ambiguities in geometry. Dropout prevents overfitting [S1].
- **Limitations:** Requires ground truth depth maps for the depth loss term. Performance may vary across different scenes (e.g., scene 710 requires different hyperparameters) [S1].
- **When to Use:** When depth information is available and can improve reconstruction quality, especially in challenging scenarios with sparse views or noisy poses [S1].
- **When Not to Use:** When depth information is not available or unreliable [S1].

## Background
This configuration was introduced in the paper "Depth-Guided NeRF Training via Earth Mover’s Distance" [S1]. It builds upon the original NeRF architecture [15] and incorporates depth supervision to improve 3D reconstruction. The method has been used in various applications, including indoor scene reconstruction (ScanNet) and outdoor scene reconstruction (LLFF) [S1, S2].
