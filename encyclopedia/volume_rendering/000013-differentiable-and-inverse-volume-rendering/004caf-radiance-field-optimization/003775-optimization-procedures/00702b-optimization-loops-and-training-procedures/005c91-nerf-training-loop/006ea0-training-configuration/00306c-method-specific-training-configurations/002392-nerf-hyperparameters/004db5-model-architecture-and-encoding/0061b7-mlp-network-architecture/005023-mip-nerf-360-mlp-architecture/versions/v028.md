# Mip-NeRF 360 MLP Architecture

Also called: Integrated Positional Encoding MLP, PosEnc MLP

## Overview
The Mip-NeRF 360 MLP architecture is a specific neural network configuration for differentiable volume rendering that integrates positional encoding directly into the network's forward pass to handle anti-aliasing via integrated positional encoding [S1, unofficial]. It differs from the standard Mip-NeRF architecture by supporting a broader set of features including specular tinting, roughness prediction, and GLO vectors, while maintaining the core density and color branch separation [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:**
    *   `means`: 3D position coordinates $\mathbf{x} \in \mathbb{R}^3$ (batched).
    *   `covs`: Covariance matrices representing the cone of integration (batched).
    *   `viewdirs`: View direction vectors $\mathbf{d} \in \mathbb{R}^3$ (batched).
    *   `normals`: Surface normals $\mathbf{n} \in \mathbb{R}^3$ (optional, batched).
    *   `glo_vec`: Global vector (optional, batched).
*   **Outputs:**
    *   `rgb`: Predicted RGB color values $\mathbf{c} \in [0, 1]^3$.
    *   `density`: Predicted volume density $\sigma$.
    *   `normals`: Predicted surface normals (optional).

**Data Structures**
The architecture is defined by a configuration object containing the following fields:
*   `net_depth`: int, depth of density MLP (default 8).
*   `net_width`: int, width of density MLP (default 256).
*   `bottleneck_width`: int, width of bottleneck vector (default 256).
*   `net_depth_viewdirs`: int, depth of color MLP (default 1).
*   `net_width_viewdirs`: int, width of color MLP (default 128).
*   `min_deg_point`: int, min degree of positional encoding for points (default 0).
*   `max_deg_point`: int, max degree of positional encoding for points (default 12).
*   `skip_layer`: int, skip connection frequency for density MLP (default 4).
*   `skip_layer_dir`: int, skip connection frequency for color MLP (default 4).
*   `deg_view`: int, degree of encoding for view directions (default 4).
*   `density_bias`: float, bias added to raw density (default -1).
*   `density_noise`: float, std dev of noise added to raw density (default 0).
*   `rgb_bias`: float, bias added to raw color (default 0).
*   `rgb_padding`: float, padding for RGB output range (default 0.001).
*   `use_reflections`: bool, use reflection directions (default False).
*   `use_directional_enc`: bool, use Integrated Directional Encoding (IDE) (default False).
*   `enable_pred_roughness`: bool, predict roughness (default False).
*   `roughness_bias`: float, bias for roughness (default -1).
*   `use_diffuse_color`: bool, separate diffuse/specular (default False).
*   `use_specular_tint`: bool, predict specular tint (default False).
*   `use_n_dot_v`: bool, feed $n \cdot v$ to color MLP (default False).
*   `bottleneck_noise`: float, std dev of noise for bottleneck (default 0.0).
*   `basis_shape`: str, basis shape for IPE ('icosahedron' or 'octahedron', default 'icosahedron').
*   `basis_subdivisions`: int, tessellation count for basis (default 2).
*   `weight_init`: str, weight initialization method.
*   `num_rgb_channels`: int, number of RGB channels (default 3).
*   `rgb_premultiplier`: float, multiplier for RGB output.
*   `density_activation`: Callable, activation for density.
*   `rgb_activation`: Callable, activation for RGB.
*   `roughness_activation`: Callable, activation for roughness.
*   `enable_pred_normals`: bool, enable normal prediction.
*   `disable_density_normals`: bool, disable density gradient normals.
*   `disable_rgb`: bool, disable RGB output.
*   `warp_fn`: Callable, warping function for linearization.

**Pseudocode**

```python
import jax.numpy as jnp
import jax
from jax import random

def mipnerf360_mlp_forward(
    means, 
    covs, 
    viewdirs, 
    config, 
    params, 
    rng=None
):
    """
    Forward pass for Mip-NeRF 360 MLP.
    
    Args:
        means: (..., 3) 3D positions.
        covs: (..., 3, 3) Covariance matrices.
        viewdirs: (..., 3) View directions.
        config: Configuration object with hyperparameters.
        params: Dictionary of network weights.
        rng: JAX PRNGKey for noise.
        
    Returns:
        rgb: (..., 3) RGB colors.
        density: (...) Volume density.
        normals: (..., 3) Surface normals (if enabled).
    """
    
    # 1. Setup and Basis Precomputation
    # In a real implementation, pos_basis_t is precomputed during initialization.
    # Here we assume it is available or computed once.
    pos_basis_t = generate_basis_transpose(config.basis_shape, config.basis_subdivisions)
    
    # 2. Directional Encoding Setup
    if config.use_directional_enc:
        dir_enc_fn = generate_ide_fn(config.deg_view)
    else:
        def dir_enc_fn(v):
            # Standard positional encoding for directions
            return coord_pos_enc(v, min_deg=0, max_deg=config.deg_view, append_identity=True)
    
    # 3. Density Prediction
    # Linearize means and covs if warping is used
    if config.warp_fn is not None:
        means, covs = coord_track_linearize(config.warp_fn, means, covs)
        
    # Lift and diagonalize to get integrated positional encoding inputs
    lifted_means, lifted_vars = coord_lift_and_diagonalize(means, covs, pos_basis_t)
    
    # Compute integrated positional encoding
    x = coord_integrated_pos_enc(lifted_means, lifted_vars, 
                                 config.min_deg_point, config.max_deg_point)
    
    # Density MLP (First Branch)
    # x shape: (..., net_width)
    for i in range(config.net_depth):
        x = dense_layer(x, params[f'density_dense_{i}'], config.net_width)
        x = config.net_activation(x)
        
        # Skip connections
        if i > 0 and i % config.skip_layer == 0:
            x = jnp.concatenate([x, x_original], axis=-1)
            # Note: x_original must be saved at start of loop or handled via residual logic
            # Simplified: In standard NeRF, skip connects to the initial input of the block.
            # Here we assume x is updated and original is tracked.
            
    # Output raw density
    raw_density = dense_layer(x, params['density_output'], 1)[..., 0]
    
    # Add density noise
    if config.density_noise > 0 and rng is not None:
        noise = random.normal(rng, raw_density.shape)
        raw_density += config.density_noise * noise
        
    # Compute normals from raw density gradient (numerically stable)
    normals = None
    if not config.disable_density_normals:
        # Flatten for vmap
        flat_means = means.reshape(-1, 3)
        flat_covs = covs.reshape(-1, 3, 3)
        
        # Compute gradient of raw_density w.r.t means
        # Using JAX vmap and value_and_grad
        def predict_density_single(m, c):
            # Re-run IPE and density MLP for single point to get gradient
            # This is computationally expensive; usually optimized in practice
            l_m, l_v = coord_lift_and_diagonalize(m[None], c[None], pos_basis_t)
            inp = coord_integrated_pos_enc(l_m, l_v, config.min_deg_point, config.max_deg_point)
            # ... run density MLP ...
            return raw_density_single
            
        # Simplified gradient computation concept
        raw_grad_density = jax.vmap(jax.value_and_grad(predict_density_single, has_aux=True))(flat_means, flat_covs)[1]
        raw_grad_density = raw_grad_density.reshape(means.shape)
        
        # Normalize normals
        normals = -ref_utils_l2_normalize(raw_grad_density)
        
    # Density Activation
    density = config.density_activation(raw_density + config.density_bias)
    
    # 4. Color Prediction (Second Branch)
    # Prepare directional encoding
    dir_enc = dir_enc_fn(viewdirs)
    
    # Broadcast dir_enc to match bottleneck shape
    # bottleneck shape is (..., bottleneck_width)
    dir_enc = jnp.broadcast_to(
        dir_enc[..., None, :], 
        x.shape[:-1] + (dir_enc.shape[-1],)
    )
    
    # Concatenate inputs for color MLP
    color_inputs = [x, dir_enc]
    
    # Add n dot v if enabled
    if config.use_n_dot_v and normals is not None:
        # normals_to_use might be predicted normals or geometry normals
        normals_to_use = normals
        dotprod = jnp.sum(normals_to_use * viewdirs[..., None, :], axis=-1, keepdims=True)
        color_inputs.append(dotprod)
        
    # Add GLO vector if enabled
    if config.glo_vec is not None:
        glo_vec = jnp.broadcast_to(config.glo_vec, x.shape[:-1] + (config.glo_vec.shape[-1],))
        color_inputs.append(glo_vec)
        
    # Concatenate all inputs
    x_color = jnp.concatenate(color_inputs, axis=-1)
    
    # Color MLP
    for i in range(config.net_depth_viewdirs):
        x_color = dense_layer(x_color, params[f'color_dense_{i}'], config.net_width_viewdirs)
        x_color = config.net_activation(x_color)
        
        if i > 0 and i % config.skip_layer_dir == 0:
            x_color = jnp.concatenate([x_color, x_color_original], axis=-1)
            
    # RGB Output
    raw_rgb = dense_layer(x_color, params['color_output'], config.num_rgb_channels)
    rgb = config.rgb_activation(config.rgb_premultiplier * raw_rgb + config.rgb_bias)
    
    # Specular/Diffuse Split (if enabled)
    if config.use_diffuse_color:
        raw_rgb_diffuse = raw_rgb[..., :3] # Assuming first 3 channels are diffuse
        diffuse_linear = jnp.sigmoid(raw_rgb_diffuse - jnp.log(3.0))
        
        if config.use_specular_tint:
            tint = params.get('specular_tint', jnp.ones_like(rgb))
            specular_linear = tint * rgb
        else:
            specular_linear = 0.5 * rgb
            
        rgb = jnp.clip(linear_to_srgb(specular_linear + diffuse_linear), 0.0, 1.0)
    else:
        # Standard RGB padding
        rgb = rgb * (1 + 2 * config.rgb_padding) - config.rgb_padding
        rgb = jnp.clip(rgb, 0.0, 1.0)
        
    return rgb, density, normals
```

**Edge Cases and Pitfalls**
*   **Reflections Require Normals:** If `use_reflections` is True, normals must be computed (via `enable_pred_normals` or by not disabling density normals). Otherwise, a `ValueError` is raised [S1, unofficial].
*   **Reflection Direction Flip:** When computing reflection directions, view directions are flipped (`-viewdirs`) before reflection because they point from camera to point, whereas `ref_utils.reflect` assumes they point toward the camera [S1, unofficial].
*   **Normal Stability:** Normals are computed from the gradient of raw (pre-activation) density because it is numerically more stable than post-activation density when the activation function has a steep or flat gradient [S1, unofficial].
*   **Bottleneck Noise:** If `bottleneck_noise` > 0, noise is added to the bottleneck vector connecting the density and color networks [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The forward pass is dominated by the MLP computations. The density branch has $O(\text{net\_depth} \times \text{net\_width}^2)$ complexity per sample. The color branch has $O(\text{net\_depth\_viewdirs} \times \text{net\_width\_viewdirs}^2)$ complexity. The integrated positional encoding adds overhead proportional to the number of frequency bands ($\text{max\_deg\_point} \times 2$).
*   **Memory Complexity:** The model stores weights for the density and color MLPs. The size is proportional to $\text{net\_depth} \times \text{net\_width}^2 + \text{net\_depth\_viewdirs} \times \text{net\_width\_viewdirs}^2$.
*   **Strengths:** Integrated positional encoding provides anti-aliasing, allowing the network to handle varying levels of detail without explicit mipmaps. The modular design supports various extensions like specular tinting and roughness prediction.
*   **Limitations:** The use of integrated positional encoding increases the dimensionality of the input to the MLP, potentially requiring more parameters to achieve the same accuracy as standard positional encoding. The computation of normals via gradient of raw density can be expensive if not optimized.
*   **When to Use:** Suitable for high-quality novel view synthesis where anti-aliasing is critical, especially in scenes with high-frequency details.
*   **When Not to Use:** If computational resources are extremely limited and anti-aliasing is not a priority, standard NeRF or Mip-NeRF might be more efficient.

## Background
The Mip-NeRF 360 MLP architecture is part of the Mip-NeRF 360 project by Google Research, which extends the original NeRF and Mip-NeRF methods to handle unbounded scenes and provide anti-aliased rendering [S1, unofficial]. It builds upon the Mip-NeRF Network Architecture by incorporating integrated positional encoding and additional features for material representation.
