# I2-SDF

Also called: Intrinsic Indoor Scene Reconstruction and Editing via Raytracing in Neural SDFs

## Overview
I2-SDF is a neural implicit framework that jointly reconstructs the geometry, material, and incident radiance of complex indoor scenes from multi-view images [S2]. It distinguishes itself from standard NeRF approaches by modeling geometry as a Signed Distance Field (SDF) and decomposing the radiance field into spatially-varying material and emission components via surface-based, differentiable Monte Carlo raytracing [S2]. This decomposition enables physically based scene relighting and editing, which standard volume rendering cannot achieve directly [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Multi-view images of an indoor scene, optionally with geometry priors such as depth maps and surface normals [S2].
*   **Outputs:** Neural fields for geometry ($F_d$), radiance ($F_c$), material ($F_a, F_\rho$), and emission ($F_e, L[\cdot]$); rendered novel views; and decomposed intrinsic maps [S2].

**Data Structures:**
The method uses four Multi-Layer Perceptrons (MLPs) to represent implicit fields [S2]:
1.  $F_d$: Maps 3D position $\mathbf{x}$ to SDF value $d(\mathbf{x})$ and its gradient (normal).
2.  $F_c$: Maps 3D position $\mathbf{x}$ and view direction $\mathbf{v}$ to radiance $\hat{c}$.
3.  $F_a, F_\rho$: Map $\mathbf{x}$ to material parameters (e.g., albedo, roughness).
4.  $F_e$: Maps $\mathbf{x}$ to emitter semantic probability (identifying light sources) [S2].

**SDF to Density Transformation:**
The SDF value $d(\mathbf{x})$ is converted to volume density $\sigma(\mathbf{x})$ using a learnable sparsity parameter $\beta$ [S2]:
$$
\sigma(\mathbf{x}) = 
\begin{cases} 
\frac{1}{\beta}(1 - \exp(d(\mathbf{x})/\beta)) & \text{if } d(\mathbf{x}) < 0 \\
\frac{1}{2\beta}\exp(-d(\mathbf{x})/2\beta) & \text{if } d(\mathbf{x}) \ge 0 
\end{cases}
$$

**Rendering:**
To render a pixel, a ray $\mathbf{r}$ is cast from camera origin $\mathbf{o}$ along direction $\mathbf{v}$ [S2]. $M$ points $\mathbf{x}_{ir} = \mathbf{o} + t_i \mathbf{v}$ are sampled along the ray and fed into $F_d$ and $F_c$ to predict SDF values and radiance [S2]. The pixel color $\hat{C}(\mathbf{r})$ is computed via numerical integration [S2]:
$$
\hat{C}(\mathbf{r}) = \sum_{i=1}^{M} T_{ri} \alpha_{ri} \hat{c}_{ir}
$$
where:
*   $\hat{c}_{ir} = F_c(\mathbf{x}_{ir}, \mathbf{v})$ is the predicted radiance [S2].
*   $\alpha_{ri} = 1 - \exp(-\sigma_{ri} \delta_{ri})$ is the opacity, with $\sigma_{ri} = \sigma(\mathbf{x}_{ir})$ and $\delta_{ri}$ the distance to the next sample [S2].
*   $T_{ri} = \prod_{j=1}^{i-1} (1 - \alpha_{rj})$ is the accumulated transmittance [S2].

**Training Strategy:**
I2-SDF employs a two-stage training scheme to resolve ambiguities between geometry, material, and lighting [S2]:
1.  **Stage 1 (Geometry & Radiance):** Train $F_d$, $F_c$, and the emitter semantic field $F_e$ [S2]. The network learns the SDF and the total incident radiance (lighting + material) [S2].
2.  **Stage 2 (Material & Emission):** Train the material fields ($F_a, F_\rho$) and the emission field $L[\cdot]$ [S2]. During this stage, $F_d$, $F_c$, and $F_e$ are fixed and detached from gradient descent [S2]. The radiance field is decomposed using surface-based, differentiable Monte Carlo raytracing [S2].

**Adaptive Sampling and Loss:**
To handle fine-grained small objects, I2-SDF introduces an error-guided adaptive sampling scheme and a "bubble loss" [S2]. Standard uniform sampling often fails to capture high-frequency details of small objects because low-frequency large objects converge faster [S2]. The adaptive scheme concentrates samples where rendering error is high, and the bubble loss penalizes deviations from the expected SDF structure near small surfaces [S2].

**Pseudocode:**
```python
import math

def compute_density(sdf_values, beta):
    """Converts SDF values to volume density using the piecewise exponential function."""
    density = []
    for d in sdf_values:
        if d < 0:
            density.append((1.0 / beta) * (1.0 - math.exp(d / beta)))
        else:
            density.append((1.0 / (2.0 * beta)) * math.exp(-d / (2.0 * beta)))
    return density

def volume_render(ray_origin, ray_direction, t_values, Fd, Fc, beta):
    """Renders a single ray using volume rendering integration."""
    points = [ray_origin + t * ray_direction for t in t_values]
    sdf_values = Fd(points)
    density = compute_density(sdf_values, beta)
    radiance = [Fc(p, ray_direction) for p in points]
    
    deltas = [t_values[i] - t_values[i-1] if i > 0 else 0.0 for i in range(len(t_values))]
    opacity = [1.0 - math.exp(-density[i] * deltas[i]) for i in range(len(t_values))]
    
    transmittance = [1.0]
    for i in range(1, len(opacity)):
        transmittance.append(transmittance[-1] * (1.0 - opacity[i-1]))
        
    color = sum(transmittance[i] * opacity[i] * radiance[i] for i in range(len(t_values)))
    return color, density, opacity

def train_stage_1(model, images, depths, normals):
    """Stage 1: Train Geometry (Fd), Radiance (Fc), and Emitter Semantic (Fe)."""
    for image, depth, normal in zip(images, depths, normals):
        rendered_image = []
        for ray in image.rays:
            # Error-guided adaptive sampling concentrates points near high-error regions [S2]
            t_vals = [ray.origin + t * ray.direction for t in [0.1, 0.3, 0.5, 0.7, 0.9]]
            color, _, _ = volume_render(ray.origin, ray.direction, t_vals, model.Fd, model.Fc, model.beta)
            rendered_image.append(color)
        loss_rgb = sum((r - g)**2 for r, g in zip(rendered_image, image.rgb)) / len(rendered_image)
        loss_sdf = sum((model.Fd(p) - d)**2 for p, d in zip(depth.points, depth.values))
        loss_emitter = sum((model.Fe(p) - e)**2 for p, e in zip(image.emitter_points, image.emitter_targets))
        total_loss = loss_rgb + loss_sdf + loss_emitter
        model.update_gradients(total_loss)

def train_stage_2(model, images):
    """Stage 2: Train Material (Fa, F_rho) and Emission (L). Fd, Fc, Fe are frozen."""
    for image in images:
        # Decompose radiance using surface-based Monte Carlo raytracing on fixed fields [S2]
        material_map = [model.Fa(p) for p in image.surface_points]
        emission_map = [model.L(p) for p in image.surface_points]
        loss_material = sum((m - target)**2 for m, target in zip(material_map, image.material_targets))
        loss_emission = sum((e - target)**2 for e, target in zip(emission_map, image.emission_targets))
        total_loss = loss_material + loss_emission
        model.update_gradients(total_loss)
```

## Operating characteristics
*   **Complexity:** Training is iterative and requires multiple passes over the dataset [S2]. Stage 1 follows standard differentiable volume rendering, while Stage 2 incorporates surface-based Monte Carlo raytracing for intrinsic decomposition [S2].
*   **Strengths:** Superior reconstruction quality for complex indoor scenes with fine-grained small objects due to adaptive sampling and bubble loss [S2]. Enables intrinsic decomposition (relighting, editing) which standard NeRF lacks [S2].
*   **Limitations:** Requires a two-stage training process, increasing implementation complexity [S2]. The second stage depends entirely on the accuracy of the fixed geometry and emitter semantic fields from the first stage [S2].
*   **When to use:** When the goal is not just novel view synthesis but also scene editing, relighting, or when the scene contains many small, high-frequency details that standard NeRF struggles to reconstruct [S2].

## Background
I2-SDF is a neural implicit framework developed by Zhu et al. [S2]. It builds upon differentiable volume rendering and neural SDF representations to address limitations in handling complex indoor scenes and intrinsic decomposition [S2]. The method was developed to enable physically based scene editing and relighting, which are difficult with standard volume rendering approaches [S2].
