# Bilateral Edge-Aware Constraint

Also called: Lbilateral

## Overview
The Bilateral Edge-Aware Constraint is a geometric regularization technique for NeRF that uses photometric differences between neighboring rays to dynamically weight geometric smoothness, preserving discontinuities at roofs, walls, and shadow transitions while suppressing local noise [S1]. It differs from standard smoothness constraints by employing adaptive bilateral weights based on both spatial proximity and albedo similarity, which is critical for implicit NeRF representations that lack fixed surface connectivity [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** For each primary ray $i$, the method requires the rendered 3D position $P_i$, the predicted surface normal $n_i$, and the albedo feature $c_i$. It also samples $K$ neighboring rays.
*   **Outputs:** A scalar loss value $L_{bilateral}$ that penalizes deviations from local planarity, weighted by bilateral consistency.

**Data Structures**
*   **Neighbor Set $N_i$:** A set of $K$ indices corresponding to neighboring rays.
*   **Geometric Data:** For each ray $k \in N_i \cup \{i\}$, the 3D position $P_k \in \mathbb{R}^3$, normal $n_k \in \mathbb{R}^3$, and albedo $c_k \in \mathbb{R}^d$ (where $d$ is the feature dimension).

**Parameters**
*   $K$: Number of neighbors sampled per ray. Value: 4 [S1].
*   $\sigma_d$: Adaptive spatial scale. Computed dynamically per ray [S1].
*   $\sigma_w$: Adaptive photometric scale. Computed dynamically per ray [S1].
*   $\gamma_{bi}$: Weight for the bilateral edge-aware term. Selected from $\{0.1, 0.01, 0.001\}$ [S1].

**Steps**
1.  **Neighbor Sampling:** For each ray $i$, sample $K=4$ neighbors by drawing integer image-plane offsets uniformly from $[-2, 2] \times [-2, 2]$, excluding the zero offset $(0,0)$ [S1].
2.  **Neighbor Rendering:** Render the corresponding neighbor rays to recover their 3D positions $P_j$, normals $n_j$, and albedo features $c_j$ for all $j \in N_i$ [S1].
3.  **Compute Adaptive Scales:**
    *   Compute the spatial scale $\sigma_d$ as the root-mean-square of the Euclidean distances between the central point $P_i$ and its neighbors $P_j$:
        $$ \sigma_d = \sqrt{\frac{1}{K} \sum_{j \in N_i} \| P_i - P_j \|^2} $$
    *   Compute the photometric scale $\sigma_w$ as the root-mean-square of the Euclidean distances between the central albedo $c_i$ and its neighbors $c_j$:
        $$ \sigma_w = \sqrt{\frac{1}{K} \sum_{j \in N_i} \| c_i - c_j \|^2} $$
    [S1]
4.  **Calculate Bilateral Weights:** For each neighbor $j \in N_i$, compute the weight $w_{i,j}$ using the exponential terms for spatial and photometric distances:
    $$ w_{i,j} = \exp\left(-\frac{\| P_i - P_j \|^2}{2\sigma_d^2}\right) \cdot \exp\left(-\frac{\| c_i - c_j \|^2}{2\sigma_w^2}\right) $$
    [S1]
5.  **Compute Normalization Factor:** Calculate $l_i$, the average edge length for normalization, defined as the mean distance to neighbors:
    $$ l_i = \frac{1}{K} \sum_{j \in N_i} \| P_i - P_j \| $$
    [S1]
6.  **Compute Local Loss:** Minimize the projected distance of neighboring points onto the tangent plane of the central point. The loss for ray $i$ is the sum of squared distances of neighbors projected onto the normal $n_i$, weighted by $w_{i,j}$ and normalized by $l_i$:
    $$ L_{bilateral}^{(i)} = \frac{1}{l_i} \sum_{j \in N_i, j \neq i} w_{i,j} \left( (P_i - P_j) \cdot n_i \right)^2 $$
    [S1]
7.  **Aggregate Loss:** Average the loss over all $N$ rays:
    $$ L_{bilateral} = \frac{1}{N} \sum_{i=1}^{N} L_{bilateral}^{(i)} $$
    [S1]

**Pseudocode**
```python
def bilateral_edge_aware_loss(central_ray, neighbor_rays, K=4):
    """
    Computes the Bilateral Edge-Aware Constraint loss for a single central ray.
    
    Args:
        central_ray: Object containing P (3D pos), n (normal), c (albedo feature).
        neighbor_rays: List of K ray objects, each containing P, n, c.
        
    Returns:
        Scalar loss value.
    """
    P_i = central_ray.P
    n_i = central_ray.n
    c_i = central_ray.c
    
    # Step 3: Compute adaptive scales
    # Spatial scale sigma_d
    spatial_diffs_sq = [np.sum((P_i - ray.P)**2) for ray in neighbor_rays]
    sigma_d = np.sqrt(np.mean(spatial_diffs_sq))
    
    # Photometric scale sigma_w
    photometric_diffs_sq = [np.sum((c_i - ray.c)**2) for ray in neighbor_rays]
    sigma_w = np.sqrt(np.mean(photometric_diffs_sq))
    
    # Step 5: Compute normalization factor l_i
    l_i = np.mean([np.sqrt(diff) for diff in spatial_diffs_sq])
    
    # Avoid division by zero if all neighbors are identical
    if l_i == 0:
        return 0.0
        
    # Step 4 & 6: Compute weights and local loss
    local_loss = 0.0
    for ray in neighbor_rays:
        P_j = ray.P
        c_j = ray.c
        
        # Spatial distance squared
        dist_sq_spatial = np.sum((P_i - P_j)**2)
        
        # Photometric distance squared
        dist_sq_photometric = np.sum((c_i - c_j)**2)
        
        # Step 4: Bilateral weight
        # Handle potential division by zero in sigma if all neighbors are identical
        w_spatial = np.exp(-dist_sq_spatial / (2 * sigma_d**2 + 1e-8))
        w_photometric = np.exp(-dist_sq_photometric / (2 * sigma_w**2 + 1e-8))
        w_ij = w_spatial * w_photometric
        
        # Projected distance onto tangent plane (normal)
        # (P_i - P_j) dot n_i
        projected_dist = np.dot(P_i - P_j, n_i)
        
        local_loss += w_ij * (projected_dist**2)
        
    # Normalize by l_i
    loss_i = local_loss / l_i
    
    return loss_i
```

## Operating characteristics
*   **Complexity:** The method adds $O(K)$ rendering calls and geometric computations per ray, where $K=4$. This increases the per-step computational cost compared to unregularized training but remains constant relative to scene size.
*   **Strengths:** It effectively preserves sharp geometric boundaries (roofs, walls) that are often blurred by standard L2 smoothness constraints [S1]. It is specifically designed to handle the lack of fixed connectivity in implicit NeRF representations [S1].
*   **Limitations:** Performance depends on the selection of $\gamma_{bi}$, which must be tuned per scene from $\{0.1, 0.01, 0.001\}$ [S1]. If $\sigma_d$ or $\sigma_w$ become very small (e.g., in flat regions with identical neighbors), numerical stability requires care (handled in pseudocode via epsilon) [S1].
*   **When to use:** Use when reconstructing scenes with distinct geometric discontinuities (urban environments, terrain with buildings) from sparse multi-view inputs [S1].

## Background
The Bilateral Edge-Aware Constraint was proposed in the context of DSM (Digital Surface Model) reconstruction from multi-view satellite images using NeRF [S1]. It was introduced to address the limitation of standard smoothness constraints that over-smooth distinct boundaries [S1]. The method is part of a broader geometric structure constraint framework that also includes a Normal Smoothness Constraint [S1].
