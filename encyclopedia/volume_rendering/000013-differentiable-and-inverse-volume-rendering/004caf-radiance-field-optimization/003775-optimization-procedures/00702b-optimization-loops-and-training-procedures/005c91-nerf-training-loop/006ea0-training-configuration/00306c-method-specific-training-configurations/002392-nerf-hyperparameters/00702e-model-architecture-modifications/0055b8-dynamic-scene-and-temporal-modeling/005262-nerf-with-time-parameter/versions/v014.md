# NeRF with Time Parameter

Also called: NeRF + time, NeRF with Time Parameter Baseline, Time-NeRF

## Overview
This method adapts the static Neural Radiance Field (NeRF) architecture to handle dynamic scenes by explicitly conditioning the network on a temporal coordinate $t$ [S1]. It solves the problem of reconstructing 4D radiance fields $R(\mathbf{x}, \mathbf{d}, t)$ from multi-view video sequences where the scene geometry and appearance change over time [S1]. Unlike sibling methods that employ complex deformation fields or canonical space warping to resolve camera-object motion ambiguity, this approach treats time as a direct input feature, allowing the MLP to learn temporal variations directly [S1]. While it improves reconstruction quality over vanilla NeRF on dynamic data, it is considered a baseline that lacks detailed dynamic reasoning and suffers from blurriness [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D spatial coordinate $\mathbf{x} \in \mathbb{R}^3$, viewing direction $\mathbf{d} \in \mathbb{R}^3$, and time parameter $t \in \mathbb{R}$.
*   **Outputs:** Volume density $\sigma \in \mathbb{R}$ and color $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures:**
The model is a Multi-Layer Perceptron (MLP). The input layer receives the concatenated positional encodings of spatial coordinates and time.
*   Positional Encoding $\gamma(\cdot)$: Standard positional encoding function applied to $\mathbf{x}$ and $t$.
*   Input Vector: $[\gamma(\mathbf{x}), \gamma(t)]$.

**Steps:**
1.  **Positional Encoding:** Compute the positional encoding for the spatial coordinates $\gamma_{\mathbf{x}}(\mathbf{x})$ and the time parameter $\gamma_t(t)$ [S1].
2.  **Concatenation:** Concatenate the encoded spatial and temporal features to form the input vector $\mathbf{v} = [\gamma_{\mathbf{x}}(\mathbf{x}), \gamma_t(t)]$ [S1].
3.  **Network Forward Pass:** Pass $\mathbf{v}$ through the MLP to predict density $\sigma$ and color $\mathbf{c}$ [S1].
4.  **Rendering:** Use the standard volume rendering integral, where density and color are functions of time $t$:
    $$ C(\mathbf{r}, t) = \int_{s_n}^{s_f} T(s, t) \sigma(\mathbf{r}(s), t) c(\mathbf{r}(s), \mathbf{d}, t) ds $$
    where $T(s, t) = \exp \left( -\int_{s_n}^{s} \sigma(\mathbf{r}(s'), t) ds' \right)$ [S1].

**Parameters:**
*   Training configuration: Uses the same hyperparameters reported for NeRF's real forward-facing experiments [S1]. Specific values (learning rate, layers, width) are not given in the sources [S1].

**Edge Cases and Pitfalls:**
*   **Blurriness:** The method suffers from blurry predictions and lacks fine detail compared to methods using deformation fields [S1].
*   **Dynamic Reasoning:** It fails to explicitly reason about scene dynamics, leading to artifacts when camera pose changes significantly relative to object motion [S1].
*   **Ghosting:** Vanilla NeRF suffers from severe ghosting on dynamic scenes; while adding time reduces this, it does not eliminate it entirely [S1].

## Subtopics

### Temporal Compression of NeRF Models
A compression strategy for sequences of NeRF models that exploits temporal redundancy by treating the first model as a key-frame and compressing only the deltas between successive models [S2]. It is chosen when storage or transmission bandwidth for a sequence of NeRFs is constrained [S2].
*   **Definition:** Exploits the similarity between neighboring NeRF models by storing only weight differences (deltas) relative to a reference model [S2].
*   **Steps:**
    1.  Initialize the NeRF for the first frame from scratch [S2].
    2.  For subsequent frames, initialize the new NeRF based on the previous frame's trained NeRF weights to encourage temporal redundancy and save training time [S2].
    3.  Calculate the delta between the current frame's NeRF weights and the previous frame's NeRF weights [S2].
    4.  Apply exponent-based quantization and Huffman coding to the deltas [S2].
    5.  To restore a model, accumulate the decoded deltas to the reference model (the previous frame's model) [S2].

## Operating characteristics
*   **Time Complexity:** Training time is reduced for subsequent frames in a sequence if the temporal compression initialization strategy is used, as the network starts from a previous solution [S2]. However, the baseline "NeRF + time" training complexity is comparable to standard NeRF, scaled by the number of frames [S1].
*   **Memory Complexity:** Standard NeRF memory usage. The temporal compression variant significantly reduces storage requirements by storing only deltas and a single reference model [S2].
*   **Performance:** On KITTI dynamic scenes, "NeRF + time" achieves a PSNR of 24.18, SSIM of 0.677, and LPIPS of 0.425, outperforming vanilla NeRF (PSNR 23.34, SSIM 0.662, LPIPS 0.415) but underperforming the proposed Neural Scene Graph method (PSNR 26.66, SSIM 0.806, LPIPS 0.186) [S1].
*   **Strengths:** Simple to implement; requires no modification to the core NeRF architecture other than input concatenation [S1].
*   **Limitations:** Produces blurry results; cannot effectively handle complex dynamics or novel scene compositions where the camera moves independently of the scene changes [S1].
*   **When to use:** As a baseline for dynamic scene reconstruction; when computational resources for complex deformation fields are unavailable [S1].
*   **When not to use:** When high-fidelity detail or accurate temporal consistency is required [S1].

## Background
The method was introduced in "Neural Scene Graphs for Dynamic Scenes" (CVPR 2021) as a baseline comparison to demonstrate the limitations of simple time-conditioning in implicit representations [S1]. It builds on the original NeRF paper [S1]. The temporal compression variant was described in "Volumetric Video Compression Through Neural-based Representation" (2024) [S2].
