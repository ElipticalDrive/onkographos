# Dynamic Appearance Particle Neural Radiance Field

Also called: Dynamic Appearance Particle NeRF, Lagrangian dynamic model in NeRF

## Overview
Dynamic Appearance Particle Neural Radiance Field is a method for modeling dynamic scenes from monocular video data by combining a static grid-based radiance field with a particle-based dynamic component [S1]. It solves the problem of reconstructing time-varying scenes without requiring multi-view stereo data or prior geometric knowledge of moving objects [S1]. Unlike ParticleNeRF, which encodes the entire scene with particles and requires multiple camera views per frame, this method applies appearance particles only to dynamic elements and uses a grid-based field for efficient querying via linear interpolation [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Monocular video data (a sequence of images at different timestamps $t$), camera poses for each frame.
*   **Outputs:** A dynamic radiance field function $V(\mathbf{x}, t)$ that outputs volume density $\sigma$ and color $\mathbf{c}$ for any 3D position $\mathbf{x}$, view direction $\mathbf{d}$, and time $t$.

**Data Structures:**
1.  **Static Field ($V_s$):** A time-independent grid-based model (e.g., hash grid or dense voxel grid) storing features for static scene elements [S1].
2.  **Dynamic Field ($V_{td}$):** A particle-based representation where each particle carries appearance features and position [S1].
3.  **Particle Motion Network:** A neural network that predicts the motion/velocity of particles over time [S1].

**Superposition Formula:**
The total feature field $V(\mathbf{x}, t)$ is computed as a weighted superposition of the static and dynamic components [S1]:
$$
V(\mathbf{x}, t) = (1 - w_t(\mathbf{x}))V_s(\mathbf{x}) + w_t(\mathbf{x})V_{td}(\mathbf{x})
$$
where:
*   $V_s(\mathbf{x})$ is the static field value at $\mathbf{x}$.
*   $V_{td}(\mathbf{x})$ is the dynamic field value at $\mathbf{x}$.
*   $w_t(\mathbf{x})$ is a binary weight: $1$ if the dynamic field is effective at $(\mathbf{x}, t)$, and $0$ otherwise [S1]. The support of the dynamic field is implied by the particle representation [S1].

**Particle-Based Dynamic Model Formulation:**
The dynamic field $V_{td}$ is formulated as a convolution with a Dirac delta function to integrate over finite volumes [S1]:
$$
V_{td}(\mathbf{x}) = (V_{td} * \delta)(\mathbf{x}) = \int V_{td}(\mathbf{x}')\delta(\mathbf{x} - \mathbf{x}')d\nu(\mathbf{x}')
$$
where $\delta(\cdot)$ is the Dirac function ($\delta(\mathbf{r}) = 0$ for $\mathbf{r} \neq 0$, $\int \delta(\mathbf{r})d\nu = 1$) and $\nu(\cdot)$ is the volume integration variable [S1].

**Quantization via Kernel Approximation:**
To enable efficient computation, the Dirac function $\delta$ is replaced with a kernel $W$ with finite support [S1]:
$$
W(\mathbf{x}) = 0 \quad \text{when } \|\mathbf{x}\| \text{ exceeds a small radius}
$$
$$
\int W(\mathbf{x})d\nu(\mathbf{x}) = 1
$$
This leads to a quantized field representation where particles contribute to grid cells within their kernel support radius [S1].

**Rendering Equation:**
Pixel color $C(\mathbf{r}, t)$ at time $t$ is computed by casting a ray $\mathbf{r}(s) = \mathbf{o} + s\mathbf{d}$ from camera center $\mathbf{o}$ [S1]:
$$
C(\mathbf{r}, t) = \int_{s_n}^{s_f} T(s, t) \sigma(\mathbf{r}(s), t) c(\mathbf{r}(s), \mathbf{d}, t) ds
$$
where:
*   $s_n, s_f$ are near and far bounds [S1].
*   $T(s, t) = \exp\left(-\int_{s_n}^{s} \sigma(\mathbf{r}(s'), t) ds'\right)$ is the accumulated transmittance [S1].
*   $\sigma(\cdot)$ is volume density and $c(\cdot)$ is emitted radiance, derived from $V(\mathbf{x}, t)$ [S1].

**Notation Convention:**
Time $t$ is denoted in subscripts on the right-hand side of the superposition equation (e.g., $V_{td}$) to clarify that the dynamic component consists of an ensemble of particles, where the time argument is fixed for the instantaneous status construction [S1].

**Training Steps:**
1.  Initialize static grid $V_s$ and dynamic particles with initial positions and features [S1].
2.  For each training step:
    a. Sample rays from input images at time $t$ [S1].
    b. Compute particle positions at time $t$ using the Particle Motion Network [S1].
    c. Evaluate $V_{td}(\mathbf{x})$ by aggregating particle features using the kernel $W$ [S1].
    d. Compute $V(\mathbf{x}, t)$ using the superposition formula [S1].
    e. Render image using volume rendering equation [S1].
    f. Compute photometric loss against ground truth [S1].
    g. Backpropagate to update static grid, particle features, and motion network parameters [S1].

**Parameters:**
*   Kernel support radius for $W$: Small radius such that $W(\mathbf{x}) = 0$ when $\|\mathbf{x}\|$ exceeds it [S1].
*   Weight $w_t(\mathbf{x})$: Binary indicator of dynamic field effectiveness [S1].

**Edge Cases and Pitfalls:**
*   **Static vs. Dynamic Boundary:** The binary weight $w_t(\mathbf{x})$ creates a hard boundary between static and dynamic regions. If a particle moves into a region previously considered static, the transition may be abrupt unless $w_t$ is smoothed (not specified in sources) [S1].
*   **Particle Density:** The accuracy of $V_{td}$ depends on particle density. Sparse particles may lead to holes in the dynamic field [S1].
*   **Monocular Ambiguity:** Without multi-view constraints, disambiguating static background from dynamic foreground may be challenging [S1].

## Operating characteristics
*   **Data Requirements:** Monocular video data (one camera view per time frame) [S1].
*   **Comparison to ParticleNeRF:** ParticleNeRF requires 20 camera views per time frame and encodes the entire scene with particles using radius nearest neighbor searching [S1]. This method uses one view and grid-based linear interpolation for dynamic elements only [S1].
*   **Architecture Flexibility:** Not tightly coupled to a specific architecture; can be integrated into frameworks like InstantNGP [S1].
*   **Performance:** Efficient querying via linear interpolation compared to nearest neighbor search in ParticleNeRF [S1].
*   **Limitations:** Relies on particle motion network for temporal consistency; may struggle with complex, non-Lagrangian dynamics [S1].

## Background
The method was proposed in "Dynamic Appearance Particle Neural Radiance Field" [S1]. It addresses limitations of ParticleNeRF, which captures only single momentary states and requires multi-view data [S1]. The approach embeds a Lagrangian dynamic model into the radiance field, using particles to model scene dynamics without prior geometric knowledge [S1].
