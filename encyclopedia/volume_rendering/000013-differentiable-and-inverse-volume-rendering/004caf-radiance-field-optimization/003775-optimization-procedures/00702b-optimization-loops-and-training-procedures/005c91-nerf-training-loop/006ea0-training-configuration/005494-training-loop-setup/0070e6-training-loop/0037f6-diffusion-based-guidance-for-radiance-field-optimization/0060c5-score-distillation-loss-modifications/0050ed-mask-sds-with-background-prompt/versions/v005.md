# Mask+SDS with Background Prompt

Also called: Mask+SDS+BGT

## Overview
Mask+SDS with Background Prompt is a differentiable rendering optimization method that addresses the "black hole" artifact in masked NeRF editing, where occluded regions lack supervision and collapse to empty space [S1]. It distinguishes itself from standard Masked SDS by explicitly appending a background description to the diffusion model's text prompt, guiding the generation of surrounding content while the mask restricts changes to the target object [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Radiance field parameters $\Theta$, a semantic mask $M$ defining the editable region, an object text prompt $P_{\text{obj}}$, and a background text prompt $P_{\text{bg}}$ [S1].
*   **Output:** Optimized radiance field $\Theta'$ [S1].

**Data Structures:**
*   **Mask $M$:** A binary tensor matching the rendered image resolution, where $M_{ij}=1$ indicates the editable region and $0$ indicates the background [G].

**Steps:**
1.  **Prompt Construction:** Concatenate the object and background prompts to form the full prompt $P_{\text{full}}$ (e.g., "a lego man head" + "leaves" $\rightarrow$ "a lego man head in leaves") [S1].
2.  **Standard SDS Loop:** Follow the shared principles of the parent method: render an image, add noise, query the frozen diffusion model, and compute the gradient signal [Parent](18224-score-distillation-loss-modifications.md).
3.  **Unmasked Constraint:** Apply a strong weighting to the unmasked region pixels in the loss calculation to prevent unwanted content generation in areas outside the mask [S1].
4.  **Optimization:** Backpropagate the gradient through the differentiable renderer to update $\Theta$ [Parent](18224-score-distillation-loss-modifications.md).

**Formulas:**
The optimization follows the standard Score Distillation Sampling (SDS) gradient [Parent]:
$$ \nabla_\Theta L = \mathbb{E}_{t,\epsilon} \left[ \omega(t) \cdot (\hat{\epsilon}_\theta(x_t, P_{\text{full}}) - \epsilon) \frac{\partial x_t}{\partial \Theta} \right] $$
where $\nabla_\Theta L$ is the gradient with respect to the radiance field parameters, $t$ is the diffusion timestep, $\epsilon$ is the added noise, $\omega(t)$ is the timestep weighting function, $\hat{\epsilon}_\theta$ is the noise prediction from the frozen diffusion model conditioned on the noisy sample $x_t$ and the full prompt $P_{\text{full}}$, and $\frac{\partial x_t}{\partial \Theta}$ is the gradient of the noisy rendered image with respect to the radiance field [Parent]. The method modifies this by applying a strong weighting to the unmasked region pixels in the loss calculation to prevent unwanted content generation [S1].

**Parameters:**
*   **Mask Weight ($\lambda_{\text{unmask}}$):** A hyperparameter controlling the constraint strength on the unmasked region, compared across different values in the source [S1].
*   **Prompts:** $P_{\text{obj}}$ and $P_{\text{bg}}$ are user-defined strings [S1].

**Edge Cases and Pitfalls:**
*   **Black Holes:** Previously occluded or covered regions may collapse into empty space ("black holes") due to a lack of explicit supervision for those areas when the background prompt is not sufficiently integrated or when using only the object prompt [S1].

## Subtopics

### Mask+SDS+CLIP
A variant that removes the background prompt from the diffusion model's text prompt and instead uses CLIP with a background prompt to fill occluded regions [S1]. It provides a view of the unmasked region to CLIP along with a background prompt to supervise and fill the black hole [S1]. While CLIP fills the black hole with reasonable texture, the generated shapes retain artifacts from the original occluded geometry (e.g., petal shapes) [S1].

### Mask+SDS+BGT+CLIP
The final combined editing configuration that uses SDS with a full prompt (object + background) and CLIP with a background prompt on unmasked views [S1]. It sets the diffusion model text prompt to include both object and background (e.g., "object in background") and simultaneously feeds unmasked views to CLIP with the background prompt to supervise the surroundings [S1]. This produces normal shapes and fills black holes with appropriate background material (e.g., green leaves around a blue rose) [S1].

## Operating characteristics
*   **Strengths:** Explicitly guides the generation of surrounding content, resulting in more reasonable shapes for the edited object compared to using only an object prompt [S1].
*   **Limitations:** Without additional mechanisms (like CLIP), the previously covered parts of the object can become "black holes" [S1].
*   **Performance:** Not given in the sources.

## Background
Originated in the paper "RePaint-NeRF: NeRF Editing via Semantic Masks and Diffusion Models" [S1]. The method was developed to improve NeRF editing by leveraging semantic masks and diffusion models, specifically addressing the issue of generating coherent backgrounds and avoiding artifacts in masked regions [S1].
