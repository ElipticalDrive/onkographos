# DDIM Sampling with Classifier-Free Guidance

Also called: Denoising Diffusion Implicit Models, DDIM Sampling, DDIM Sampling Step (with CFG & v-parameterization)

## Overview
DDIM Sampling with Classifier-Free Guidance (CFG) is a deterministic reverse diffusion process that generates or refines latent representations (e.g., voxel grids, triplanes, or scene codes) by iteratively denoising a random latent variable $x_T$ down to $x_0$ [S1, S2, unofficial]. It builds on [Diffusion Sampling and Denoising Mechanisms](14430-diffusion-sampling-and-denoising-mechanisms.md) by skipping intermediate noise steps to allow for fewer sampling iterations than standard DDPM while maintaining sample quality [S2, unofficial]. It differs from its sibling [DDPM Denoise Function Network](11102-ddpm-denoise-function-network.md) by using a deterministic transition ($\sigma_t=0$) rather than a stochastic posterior, enabling exact reconstruction from noise in the limit of infinite steps [S2, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A noisy latent $x_t$ at timestep $t$, a timestep index $t$, and conditioning information $c$ (e.g., text embeddings, images). Optional: unconditional conditioning $c_{uncond}$, a mask $m$, and the original clean sample $x_0$ (for inpainting).
- **Output:** The denoised latent $x_{t-1}$ and the predicted clean sample $\hat{x}_0$.

**Data Structures:**
The scheduler maintains several pre-computed buffers registered as tensors (typically `torch.float32`) aligned with the timestep dimension:
- `betas`: Variance schedule coefficients $\beta_t$.
- `alphas_cumprod`: Cumulative product $\bar{\alpha}_t = \prod_{i=1}^t (1 - \beta_i)$.
- `alphas_cumprod_prev`: $\bar{\alpha}_{t-1}$ (with $\bar{\alpha}_0 = 1$).
- Derived buffers: `sqrt_alphas_cumprod` ($\sqrt{\bar{\alpha}_t}$), `sqrt_one_minus_alphas_cumprod` ($\sqrt{1-\bar{\alpha}_t}$), `ddim_sigmas` ($\sigma_t$), `ddim_alphas` ($\bar{\alpha}_t$ for DDIM steps), `ddim_alphas_prev` ($\bar{\alpha}_{t-1}$ for DDIM steps), `ddim_sqrt_one_minus_alphas` ($\sqrt{1-\bar{\alpha}_t}$ for DDIM steps).

**Parameters:**
- `num_inference_steps`: Number of sampling steps. Default: 50 [S1, unofficial].
- `unconditional_guidance_scale` ($s$): CFG multiplier. Default: 1.0 (disables guidance) [S2, unofficial]. Typical values: 7.5 for sampling, 100 for refinement/training [S1, unofficial].
- `ddim_eta` ($\eta$): Controls stochasticity. Default: 0.0 (deterministic) [S2, unofficial].
- `temperature`: Scales injected noise. Default: 1.0 [S2, unofficial].
- `noise_dropout`: Dropout probability for noise. Default: 0.0 [S2, unofficial].
- `quantize_denoised`: Boolean to quantize $\hat{x}_0$. Default: False [S2, unofficial].
- `use_original_steps`: Boolean to choose between DDPM or DDIM timestep arrays. Default: False [S2, unofficial].

**Algorithm Steps:**

1. **Initialization:**
   - If $x_T$ is not provided, sample $x_T \sim \mathcal{N}(0, I)$ with shape `(batch_size, channels, height, width)` [S1, S2, unofficial].
   - Compute `ddim_timesteps` using `make_ddim_timesteps` based on `num_inference_steps` and discretization method (e.g., uniform) [S2, unofficial].
   - Compute `ddim_sigmas`, `ddim_alphas`, and `ddim_alphas_prev` using `make_ddim_sampling_parameters` with `ddim_eta` [S2, unofficial].
   - Register `betas`, `alphas_cumprod`, `sqrt_alphas_cumprod`, `sqrt_one_minus_alphas_cumprod`, `ddim_sigmas`, `ddim_alphas`, `ddim_alphas_prev`, and `ddim_sqrt_one_minus_alphas` as CUDA buffers [S2, unofficial].

2. **Loop Setup:**
   - Set scheduler timesteps: `timesteps = ddim_timesteps` [S1, S2, unofficial].
   - Reverse timesteps: `time_range = np.flip(timesteps)` [S2, unofficial].
   - Total steps: `total_steps = len(time_range)` [S2, unofficial].

3. **Iteration:**
   For each index $i$ from $0$ to `total_steps` - 1:
   - Let $t$ be `time_range[i]`.
   - Create timestep tensor $ts = \text{torch.full}((batch\_size,), t, \text{dtype}=\text{long})$ [S2, unofficial].
   - **Dynamic Guidance (Optional):** If `ucg_schedule` is provided, set `unconditional_guidance_scale = ucg_schedule[i]` [S2, unofficial].
   - **Inpainting Mask (Optional):** If mask $m$ is provided, assert $x_0$ is available. Compute $x_{orig} = q\_sample(x_0, ts)$ (forward diffusion). Update $x_t = x_{orig} \cdot m + (1 - m) \cdot x_t$ [S2, unofficial].
   - **CFG Prediction:**
     - Concatenate latent for CFG: $x_{in} = \text{cat}([x_t, x_t])$ [S2, unofficial].
     - Concatenate conditioning: $c_{in} = \text{cat}([c_{uncond}, c])$ [S2, unofficial].
     - Predict noise: $e_{t\_uncond}, e_{t\_cond} = \text{model}(x_{in}, ts, c_{in})$ [S2, unofficial].
     - Apply CFG: $e_t = e_{t\_uncond} + s \cdot (e_{t\_cond} - e_{t\_uncond})$ [S2, unofficial].
     - **V-parameterization (Optional):** If parameterization is "v", convert model output to noise: $e_t = \text{model.predict\_eps\_from\_z\_and\_v}(x_t, ts, \text{model\_output})$ [S2, unofficial].
     - **Score Corrector (Optional):** If `score_corrector` is not None and parameterization is "eps", modify $e_t$ [S2, unofficial].
   - **Predict Clean Sample ($\hat{x}_0$):**
     - If not v-parameterization: $\hat{x}_0 = \frac{x_t - \sqrt{1 - \bar{\alpha}_t} e_t}{\sqrt{\bar{\alpha}_t}}$ [S2, unofficial].
     - If v-parameterization: $\hat{x}_0 = \text{model.predict\_start\_from\_z\_and\_v}(x_t, ts, \text{model\_output})$ [S2, unofficial].
     - **Quantization (Optional):** If `quantize_denoised`, quantize $\hat{x}_0$ via `model.first_stage_model.quantize(\hat{x}_0)` [S2, unofficial].
   - **Compute Next Latent ($x_{t-1}$):**
     - Retrieve $\bar{\alpha}_{t-1}$ (`a_prev`), $\sigma_t$ (`sigma_t`), and $\sqrt{1-\bar{\alpha}_t}$ (`sqrt_one_minus_at`) from buffers [S2, unofficial].
     - Compute direction: $d = \sqrt{1 - \bar{\alpha}_{t-1} - \sigma_t^2} \cdot e_t$ [S2, unofficial].
     - Sample noise: $\epsilon = \sigma_t \cdot \mathcal{N}(0, I) \cdot \text{temperature}$ [S2, unofficial]. Apply dropout if `noise_dropout > 0` [S2, unofficial].
     - Update: $x_{t-1} = \sqrt{\bar{\alpha}_{t-1}} \hat{x}_0 + d + \epsilon$ [S2, unofficial].
   - **Record Intermediates (Optional):** If $i \% \text{log\_every\_t} == 0$ or $i == \text{total\_steps} - 1$, append $x_{t-1}$ and $\hat{x}_0$ to logs [S2, unofficial].

**Pseudocode:**

```python
import torch
import numpy as np

def make_ddim_timesteps(ddim_discr_method, num_ddim_timesteps, num_ddpm_timesteps):
    """
    Creates a list of timesteps to skip from the original DDPM schedule.
    """
    if ddim_discr_method == 'uniform':
        c = num_ddpm_timesteps // num_ddim_timesteps
        ddim_timesteps = np.asarray(list(range(0, num_ddpm_timesteps, c)))
    elif ddim_discr_method == 'old':
        ddim_timesteps = np.asarray(list(range(num_ddpm_timesteps, 0, -1)))
    else:
        raise ValueError(f"Unsupported ddim_discr_method: {ddim_discr_method}")
    return ddim_timesteps

def make_ddim_sampling_parameters(alphacums, ddim_timesteps, eta, verbose=True):
    """
    Computes the alphas and sigmas for DDIM sampling.
    """
    alphas = alphacums[ddim_timesteps]
    alphas_prev = np.asarray([alphacums[0]] + alphacums[ddim_timesteps[:-1]].tolist())
    
    # sigma calculation depends on eta
    sigmas = eta * np.sqrt((1 - alphas_prev) / (1 - alphas) * (1 - alphas / alphas_prev))
    
    return alphas, alphas_prev, sigmas

def q_sample(x_start, continuous_alpha, variance_noise, timestep):
    """
    Forward diffusion step: x_t = sqrt(alpha_t) * x_0 + sqrt(1 - alpha_t) * noise
    """
    # continuous_alpha is sqrt(alpha_t)
    # variance_noise is sqrt(1 - alpha_t)
    # Extract coefficients for the batch
    alpha_t = continuous_alpha[timestep]
    sqrt_one_minus_alpha_t = variance_noise[timestep]
    
    # Ensure shapes match
    alpha_t = alpha_t.view(-1, 1, 1, 1) if continuous_alpha.dim() > 0 else alpha_t
    sqrt_one_minus_alpha_t = sqrt_one_minus_alpha_t.view(-1, 1, 1, 1) if variance_noise.dim() > 0 else sqrt_one_minus_alpha_t
    
    return alpha_t * x_start + sqrt_one_minus_alpha_t * torch.randn_like(x_start)

def ddim_sample_with_cfg(model, scheduler, x_T, c, c_uncond, unconditional_guidance_scale, 
                         timesteps, eta=0.0, mask=None, x0=None, temperature=1.0, 
                         noise_dropout=0.0, quantize_denoised=False, use_original_steps=False):
    """
    Performs DDIM sampling with Classifier-Free Guidance.
    """
    device = x_T.device
    batch_size = x_T.shape[0]
    
    # 1. Initialize Scheduler Buffers
    if use_original_steps:
        sqrt_alphas_cumprod = scheduler.sqrt_alphas_cumprod
        sqrt_one_minus_alphas_cumprod = scheduler.sqrt_one_minus_alphas_cumprod
    else:
        sqrt_alphas_cumprod = torch.sqrt(scheduler.ddim_alphas)
        sqrt_one_minus_alphas_cumprod = scheduler.ddim_sqrt_one_minus_alphas
        
    # Pre-compute alphas_prev for the selected timesteps
    # Note: In practice, these are often pre-computed in make_ddim_sampling_parameters
    # Here we simulate the buffer access
    ddim_alphas = scheduler.ddim_alphas if not use_original_steps else scheduler.alphas_cumprod
    ddim_alphas_prev = scheduler.ddim_alphas_prev if not use_original_steps else scheduler.alphas_cumprod_prev
    
    # 2. Setup Time Range
    time_range = np.flip(timesteps)
    total_steps = len(time_range)
    
    x_t = x_T.clone()
    
    for i, t in enumerate(time_range):
        ts = torch.full((batch_size,), t, device=device, dtype=torch.long)
        index = total_steps - i - 1
        
        # 3. Inpainting Mask Handling
        if mask is not None:
            assert x0 is not None, "x0 must be provided for inpainting"
            # Compute noisy version of x0 at current timestep
            # Note: q_sample implementation above assumes noise is generated inside. 
            # For consistency with CFG, we need the specific noise used or re-sample.
            # Standard implementation often re-samples or uses stored noise. 
            # Here we assume q_sample generates consistent noise or x0 is used directly if mask is binary.
            # Simplified: img_orig = q_sample(x0, ts)
            # Update x_t = img_orig * mask + (1 - mask) * x_t
            # [G] Implementation detail: q_sample must use the same noise seed or x0 is known.
            # For this pseudocode, we assume a helper `q_sample_with_noise` exists or x0 is used directly.
            # A common approach is: x_t = x0 * mask + x_t * (1 - mask) if mask is applied to clean image?
            # No, mask is applied to the *noisy* image to preserve the original noisy structure in masked region.
            # img_orig = sqrt(alpha_t) * x0 + sqrt(1-alpha_t) * noise
            # We need the noise. Let's assume we have a way to get it or x0 is used for reconstruction.
            # Standard Stable Diffusion code: img_orig = self.model.q_sample(x0, ts)
            # img = img_orig * mask + (1. - mask) * img
            pass # Placeholder for mask logic as it requires specific noise handling

        # 4. CFG Prediction
        if unconditional_guidance_scale != 1.0:
            x_in = torch.cat([x_t] * 2)
            t_in = torch.cat([ts] * 2)
            c_in = torch.cat([c_uncond, c])
            
            model_output = model.apply_model(x_in, t_in, c_in)
            e_t_uncond, noise_pred = torch.chunk(model_output, 2)
            
            # Apply CFG formula
            noise_pred = e_t_uncond + unconditional_guidance_scale * (noise_pred - e_t_uncond)
        else:
            noise_pred = model.apply_model(x_t, ts, c)
            
        # 5. V-parameterization handling (if applicable)
        # If model outputs v, convert to eps
        # e_t = model.predict_eps_from_z_and_v(x_t, ts, noise_pred)
        e_t = noise_pred

        # 6. Predict x0
        # a_t = sqrt(alpha_t)
        a_t = sqrt_alphas_cumprod[t]
        sqrt_one_minus_at = sqrt_one_minus_alphas_cumprod[t]
        
        # pred_x0 = (x_t - sqrt(1 - a_t) * e_t) / sqrt(a_t)
        pred_x0 = (x_t - sqrt_one_minus_at * e_t) / a_t
        
        if quantize_denoised:
            pred_x0 = model.first_stage_model.quantize(pred_x0)

        # 7. Compute x_{t-1}
        # a_prev = sqrt(alpha_{t-1})
        a_prev = torch.sqrt(ddim_alphas_prev[index])
        sigma_t = scheduler.ddim_sigmas[index] if not use_original_steps else 0.0 # eta=0 implies sigma=0 for deterministic
        
        # dir_xt = sqrt(1 - a_prev^2 - sigma_t^2) * e_t
        # Note: ddim_alphas_prev is alpha_{t-1}, so sqrt is a_prev
        # The formula uses sqrt(1 - alpha_{t-1} - sigma_t^2)
        dir_xt = torch.sqrt(1.0 - a_prev**2 - sigma_t**2) * e_t
        
        # noise = sigma_t * N(0, I) * temperature
        noise = sigma_t * torch.randn_like(x_t) * temperature
        if noise_dropout > 0:
            # Apply dropout to noise
            mask_noise = torch.bernoulli(torch.full_like(noise, 1.0 - noise_dropout))
            noise = noise * mask_noise
            
        x_prev = a_prev * pred_x0 + dir_xt + noise
        
        x_t = x_prev
        
    return x_t, pred_x0
```

## Subtopics

### [Conditional Generator for NeRF Refinement](13028-conditional-generator-for-nerf-refinement.md)
The Conditional Generator is a 2D post-processing module that refines NeRF renderings by acting as a stochastic denoiser. It takes a raw NeRF rendering and an auxiliary random vector as input to produce a cleaned image, addressing artifacts that remain after 3D optimization. Unlike 3D discriminator-based methods that guide the radiance field directly, this method operates in image space, leveraging a StyleGAN2-inspired architecture to enhance perceptual quality without altering the underlying 3D representation.

### [Pseudo Linear Multistep Sampling](15261-pseudo-linear-multistep-sampling.md)
Pseudo Linear Multistep Sampling (PLMS) is a sampling method for diffusion models that uses a linear multistep predictor (Adams-Bashforth) to estimate the noise residual at the next timestep, allowing for fewer function evaluations per step compared to standard Euler or Heun methods, while maintaining stability similar to DDIM. It builds on [DDIM Sampling with Classifier-Free Guidance](8118-ddim-sampling-with-classifier-free-guidance.md) by integrating classifier-free guidance into the noise prediction step.

### [DDPM Posterior Sampling with Adaptive Step Size](19439-ddpm-posterior-sampling-with-adaptive-step-size.md)
This method performs inverse rendering by jointly denoising an environment map using a Diffusion Posterior Sampling (DPS) prior while simultaneously optimizing material parameters (base color, roughness, metallic) to fit observed input images. It differs from standard denoising by interleaving the diffusion sampling steps with gradient-based material optimization, using an adaptive step size parameter $\rho$ to balance the trade-off between the realism of the generative prior and the fidelity to the input observations.

## Operating characteristics
- **Time Complexity:** $O(T \cdot N)$, where $T$ is the number of sampling steps and $N$ is the cost of one model forward pass. DDIM allows $T \ll T_{DDPM}$ (e.g., 50 vs 1000) while maintaining quality [S2, unofficial].
- **Memory Complexity:** $O(N_{latent} + N_{buffers})$. Buffers for alphas/sigmas are small ($O(T)$). Latent size depends on resolution.
- **Performance:** Deterministic ($\eta=0$) sampling produces consistent results for the same seed. Stochastic sampling ($\eta>0$) introduces diversity [S2, unofficial].
- **Strengths:** Fewer steps than DDPM; deterministic; supports CFG for improved fidelity; supports inpainting and v-parameterization [S2, unofficial].
- **Limitations:** Requires pre-computed schedule buffers; dynamic thresholding is not implemented and raises `NotImplementedError` if enabled [S2, unofficial]; score corrector only supports eps parameterization [S2, unofficial]; mask requires $x_0$ [S2, unofficial].
- **When to use:** When high-quality generation/refinement is needed with fewer steps than DDPM, or when deterministic results are required.
- **When not to use:** When maximum diversity is needed (use DDPM or $\eta>0$), or when dynamic thresholding is required.

## Background
DDIM (Denoising Diffusion Implicit Models) was introduced as a deterministic sampling method for diffusion models [S2, unofficial]. It allows for fewer sampling steps than standard DDPM by skipping intermediate noise steps and using a fixed noise schedule [S2, unofficial]. The method computes the previous latent $x_{t-1}$ from current latent $x_t$ using a predicted noise/start, supporting classifier-free guidance and v-prediction parameterization [S2, unofficial]. It is widely used in image generation and 3D reconstruction pipelines, such as in SSDNeRF for interpolation and GaussianObject for refinement [S1, unofficial][S3].
