# Non-Photorealistic Style Editing


## Overview
Non-Photorealistic Style Editing (NPSE) is a style transfer process for volume rendering that assigns specific styles to distinct regions of a scene using an unrestricted color network and Nearest Neighbor Feature Matching (NNFM) loss [S1]. Unlike [SNeRF](16796-stylenerf-architecture.md) which assigns one style to the whole scene, NPSE allows explicit assignment of different styles to different DVR regions [S1]. Unlike [ARF](14882-stylizednerf.md) and [SNeRF](16796-stylenerf-architecture.md) which discard view directions to ensure consistency, NPSE removes view direction input only in the Unrestricted Color Network (UCN) optimization to preserve lighting while ensuring consistency [S1].

## How it works
**Inputs:** A base NeRF model (with frozen density $\sigma(\mathbf{x})$ and pre-trained color network), one or multiple reference images $S = \{S_1, S_2, \dots, S_{NP}\}$ representing desired styles for $NP$ regions, and camera views [S1].
**Outputs:** A stylized volume representation defined by the optimized Unrestricted Color Network $c_u(\mathbf{x})$ [S1].

**Data Structures:**
*   **Base NeRF:** Frozen density field $\sigma(\mathbf{x})$ [S1].
*   **Unrestricted Color Network (UCN):** Optimizable color network $c_u(\mathbf{x})$ that outputs diffuse colors [S1].
*   **Palette Weights:** $\omega_i(\mathbf{x})$ for each style region $i \in \{1, \dots, NP\}$ [S1].
*   **Feature Extractor:** Pre-trained VGG-16 model $\phi$, specifically using the `conv3` block [S1].

**Steps:**
1.  **Region Segmentation:** If the number of reference images is less than $NP$ or for local patterns, segment reference images into localized style regions using the Segment Anything Model (SAM) with optional point prompts [S1].
2.  **Network Construction:** Construct a new Radiance Field (RF) using the optimizable unrestricted color $c_u(\mathbf{x})$ and the frozen density $\sigma(\mathbf{x})$ from the base NeRF [S1].
3.  **Rendering:** Compute $NP$ rendering images $R = \{R_1, R_2, \dots, R_{NP}\}$ for each camera view. For a sample point $\mathbf{x}$, it contributes to rendering $R_i$ only if its palette weight $\omega_i(\mathbf{x})$ is greater than other palette weights [S1].
4.  **Background Handling:** Extract the luminance value from each style $S_i$ to use as the background color for the corresponding rendering $R_i$ to handle transparency artifacts [S1].
5.  **Loss Computation:** Compute the stylization loss using NNFM loss between renderings $R$ and styles $S$ via VGG-16 features [S1]. Omit content loss between original and stylized images due to suboptimal outcomes [S1].
6.  **Optimization:** Update $c_u(\mathbf{x})$ parameters using the computed loss [S1].

**Formulas:**
The NNFM loss is formulated as [S1]:
$$
L_{NNFM}(R, S) = \frac{1}{N_F N_P} \sum_{i=1}^{N_P} \sum_{f_j \in \phi(R_i)} \min_{f_k \in \phi(S_i)} d(f_j, f_k)
$$
where:
*   $\phi(R_i)$ and $\phi(S_i)$ are the feature vectors extracted from the VGG-16 model $\phi$ for rendering $R_i$ and style $S_i$ respectively [S1].
*   $N_F$ is the number of feature vectors for $\phi(R_i)$ [S1].
*   $N_P$ is the number of style regions [S1].
*   $d$ is the cosine distance between feature vectors $f_j$ and $f_k$ [S1].

**Parameters:**
*   **VGG-16 Block:** `conv3` [S1].
*   **Iterations:** 210 [S1].
*   **Views per Iteration:** One of 42 uniformly sampled camera views [S1].
*   **Learning Rate:** Fixed at 0.01, following the [ARF](14882-stylizednerf.md) setting (Adam optimizer with $\beta_1=0.9, \beta_2=0.999$, but learning rate does not decay during NPSE) [S1].
*   **Batch Size:** 4,096 rays [S1].

    optimizer = optim.Adam([ucn], lr=0.01, betas=(0.9, 0.999))

    # 5. Sample camera views uniformly
    camera_views = sample_uniform_views(num_views)

    for iteration in range(iterations):
        optimizer.zero_grad()

        # Select one view for this iteration
        view_idx = np.random.randint(0, len(camera_views))
        camera = camera_views[view_idx]

            # Apply palette weight logic: only contribute if omega_i(x) > others
            rendering_i = render_volume(base_nerf.sigma, ucn, camera, i)
            renderings.append(rendering_i)

        for i in range(num_styles):
            bg_color = extract_luminance(reference_images[i])
            renderings[i] = set_background(renderings[i], bg_color)

        # 8. Compute NNFM Loss
        loss = 0.0
        nf = 0
        for i in range(num_styles):
            feat_r = vgg_conv3(renderings[i])
            feat_s = vgg_conv3(reference_images[i])

            nf = feat_r.shape[0]
            for j in range(nf):
                min_dist = float('inf')
                for k in range(feat_s.shape[0]):
                    dist = cosine_distance(feat_r[j], feat_s[k])
                    if dist < min_dist:
                        min_dist = dist
                loss += min_dist

        loss = loss / (num_styles * nf)

        # 9. Backpropagate
        loss.backward()
        optimizer.step()

    return ucn

**Edge Cases and Pitfalls:**
*   **Transparency Artifacts:** Using incorrect background colors (e.g., black or white) leads to unsatisfactory stylization. Extracting luminance from the style image is required [S1].
*   **Content Loss:** Including content loss between original and stylized images yields suboptimal outcomes and should be omitted [S1].
*   **Memory:** Deferred backpropagation is employed to update UCN parameters for the entire image under limited GPU memory [S1].

## Subtopics

### Iterative Style Refinement for NPSE
A workflow to indirectly control NPSE stylization by iteratively refining reference image selections using negative point prompts and UCN retraining [S1]. If the initial style selection includes undesired styles, apply negative point prompts for SAM to the reference image to exclude them, then retrain the UCN to achieve the desired stylization [S1]. This is necessary because NPSE does not support direct control over the stylization process once initiated [S1].

## Operating characteristics
**Time and Memory Complexity:**
*   **Training Time:** For the "vortex" dataset, NPSE takes 29.7 minutes [S1]. For the "combustion" dataset, it takes 1.2 hours [S1]. This is faster than SNeRF (3.6 h and 3.8 h respectively) but slower than ARF (14.6 m and 20.1 m respectively) [S1].
*   **Inference Time:** For the "vortex" dataset, NPSE takes 373 ms [S1]. For the "combustion" dataset, it takes 564 ms [S1]. This is slower than ARF (204 ms and 210 ms) and SNeRF (173 ms and 195 ms) [S1].
*   **Memory:** Uses deferred backpropagation to handle limited GPU memory [S1].

**Strengths and Limitations:**
*   **Strengths:** Allows explicit assignment of different styles to different DVR regions [S1]. Preserves view-dependent lighting by removing view direction input only in UCN optimization, unlike ARF and SNeRF which discard view directions entirely [S1]. Offers higher flexibility and robustness compared to conventional NPR methods by transferring arbitrary styles within a unified framework [S1].
*   **Limitations:** Does not support direct control over the stylization process; requires iterative refinement via SAM prompts [S1]. Relies on NNFM loss which focuses on negligible local style, mitigated by color transfer to align region color with overall style color [S1].

**When to Use:**
Use when distinct styles are needed for different regions of a volume scene and view-dependent lighting preservation is important [S1].
