# Sharp-NeRF

Also called: Grid-based Fast Deblurring Neural Radiance Fields using Sharpness Prior

## Overview
Sharp-NeRF is a grid-based NeRF framework designed to render clean, sharp images from input blurry images by modeling spatially varying blur using discrete learnable kernels and a sharpness prior [S1]. Unlike sibling methods such as DeblurNeRF and IE-NeRF which rely on MLPs to generate blur kernels or require extensive training times, Sharp-NeRF achieves training times of approximately half an hour by using a decomposed-grid representation and quantized sharpness levels [S1]. It solves the problem of blind deblurring in neural radiance fields where the point spread function (PSF) varies spatially across the scene due to defocus, camera shake, or motion [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of blurry training images (and their corresponding camera poses).
*   **Outputs:** A trained grid-based neural field representation and a set of discrete blur kernels, capable of rendering sharp novel views at inference time.

**Data Structures:**
1.  **Grid-based Neural Field:** A decomposed-grid representation (e.g., TensorFacts or similar grid-based neural field architecture) storing density and color information [S1]. The specific grid dimensions and channel sizes are not given in the sources [S1].
2.  **Discrete Blur Kernels ($B$):** A set of $N_k$ learnable 2D convolution kernels. The size of each kernel is not specified, but they are applied as convolutions [S1].
3.  **Sharpness Level Map ($L$):** A per-pixel map where each pixel value is an integer index in $[0, N_k-1]$, indicating which discrete kernel from $B$ applies to that pixel [S1].

**Preprocessing:**
1.  Compute a defocus map (sharpness measure) for each training view using a sharpness measure operator [S1].
2.  Quantize the defocus map into $N_k$ discrete values to create the sharpness level map $L$ [S1]. This step is performed once before training and is not part of the forward pass during training or inference [S1].

**Training Procedure:**
The training loop optimizes the grid-based neural field and the discrete blur kernels $B$ using the following steps for each batch:

1.  **Ray Patch Sampling:** Sample ray patches with stride 1. Each patch has a spatial size of $K \times K$ pixels [S1].
2.  **Sharp Rendering:** Pass the ray patch inputs through the backbone grid-based neural fields to render a sharp image patch $I_c'$ [S1].
3.  **Kernel Indexing:** For each pixel in the patch, use the preprocessed sharpness level map $L$ to index into the set of learned discrete blur kernels $B$. This yields a per-pixel weight $w_x$ corresponding to the selected kernel [S1].
4.  **Blurring Synthesis:** Perform a weighted sum of the per-pixel weights $w_x$ and the rendered sharp image patch $I_c'$ to produce the final blurred image patch $I_b$. Specifically, the sharp patch $I_c'$ is convolved with the selected discrete kernel for each pixel location, and the results are aggregated [S1].
5.  **Loss Calculation:** Compare the synthesized blurred patch $I_b$ with the ground-truth blurry input patch. The specific loss function is not detailed in the sources, but standard image reconstruction losses (e.g., L1, L2, or perceptual losses) are implied by the context of "full-reference and non-reference metrics" evaluation [S1].

**Inference:**
At inference time, the blur kernel module is bypassed. The grid-based neural field renders the sharp image $I_c$ directly, which is used as the final output [S1].

**Pseudocode:**

```python
# Preprocessing (done once)
def preprocess_sharpness_level_map(blurry_images):
    # Compute defocus map for each view using a sharpness measure operator
    defocus_maps = [compute_sharpness_measure(img) for img in blurry_images]
    # Quantize defocus maps into Nk discrete values
    # L is a map of indices [0, Nk-1]
    L = [quantize(defocus_map, Nk) for defocus_map in defocus_maps]
    return L

# Training Step
def train_step(grid_model, blur_kernels_B, L_map, blurry_patch_gt, K, Nk):
    # 1. Sample ray patches with stride 1, size K x K
    # ray_patches is a batch of ray sets corresponding to K x K pixels
    ray_patches = sample_ray_patches(stride=1, patch_size=K)
    
    # 2. Render sharp image patch I_c' from ray patches
    # grid_model returns color/density, volume rendering produces I_c'
    I_c_prime = grid_model.render(ray_patches)
    
    # 3. Get sharpness indices for the patch from L_map
    # L_patch is a K x K tensor of indices into B
    L_patch = get_patch_from_map(L_map, ray_patches)
    
    # 4. Index blur kernels
    # Select kernels based on L_patch
    # B is a tensor of shape (Nk, kernel_height, kernel_width)
    selected_kernels = B[L_patch] 
    
    # 5. Blurring Synthesis
    # Apply selected kernel to each pixel in I_c'
    # This is effectively a spatially varying convolution
    I_b = spatially_varying_convolution(I_c_prime, selected_kernels)
    
    # 6. Compute Loss
    loss = compute_loss(I_b, blurry_patch_gt)
    
    # 7. Update parameters
    update(grid_model, blur_kernels_B, loss)
    
    return loss

# Inference
def infer(grid_model, ray_set):
    # Render sharp image directly
    I_c = grid_model.render(ray_set)
    return I_c
```

**Parameters:**
*   $N_k$: The number of discrete blur kernels used to quantize the sharpness levels. The exact value is not given in the sources [S1].
*   $K$: The spatial size ($K \times K$) of the ray patches rendered during training. The exact value is not given in the sources [S1].

**Edge Cases and Pitfalls:**
*   **High Resolution/Multi-View:** Retaining blur kernels for every individual pixel is impractical due to high-resolution and multi-view images. This is handled by quantizing sharpness levels into a few discrete kernels ($N_k$) [S1].
*   **Training Time:** Rendering multiple neighboring pixels (5 or 6) to render one pixel increases training time proportionally. This is handled by rendering a patch and applying convolution over the patch, which significantly reduces training time while maintaining quality [S1].

## Operating characteristics
*   **Time Complexity:** Training time is approximately half an hour, which is significantly faster than MLP-based methods like Deblur-NeRF and DP-NeRF [S1].
*   **Memory Complexity:** Uses a decomposed-grid representation, which is more memory-efficient than large MLPs for kernel generation [S1].
*   **Strengths:** Fast training time; handles spatially varying blur (defocus) effectively; does not require all-in-focus images for training (unlike DoF-NeRF) [S1].
*   **Limitations:** Relies on the accuracy of the sharpness measure operator for preprocessing; performance depends on the choice of $N_k$ and $K$ [S1].
*   **When to use:** When training time is a constraint and the blur is primarily defocus-based, and when high-quality sharp novel views are needed from blurry inputs [S1].
*   **When not to use:** When the blur is motion blur with a fixed kernel (Hybrid Neural Rendering Model is noted for this, but Sharp-NeRF is general) or when all-in-focus training data is available and DoF-NeRF is preferred [S1].

## Background
Sharp-NeRF was proposed to overcome the shortcomings of MLP-based NeRF methods which require tremendous computational time for deblurring [S1]. It builds on grid-based neural field architectures (such as decomposed-grid representations) to accelerate training [S1]. The method addresses the challenge of spatially varying point spread functions (PSF) in defocus-blurred scenes, which cannot be handled by fixed kernels [S1]. It was evaluated on challenging real-world datasets consisting of blurry images, showing improvements in training speed and performance comparable to or better than previous works [S1].
