# Perceptual Distillation Module

Also called: Perceptual Loss for Deblurred Radiance Fields

## Overview
The Perceptual Distillation Module addresses the 3D geometric inconsistency inherent in independently deblurred multi-view images by using pre-deblurred images as a perceptual prior to transfer texture information to the implicit clean radiance fields [S1]. It sets itself apart from standard reconstruction losses by enforcing feature-level consistency between rendered patches and pre-deblurred patches, rather than pixel-level consistency, thereby overcoming the artifacts caused by applying 2D deblurring independently to each view [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** Blurry training images $I$, camera poses, and a pre-trained image deblurring network $\Theta_D$ (MPRNet) [S1].
*   **Outputs:** Perceptual loss value $L_{pd}$ used in the total training loss [S1].

**Data Structures**
*   **Patch Rays ($r_{pd}^{ptc}$):** A set of rays sampled from the training view corresponding to a specific image patch [S1].
*   **Deblurred Image Patch ($\bar{C}_{ptc}$):** An $S_{ptc} \times S_{ptc}$ region extracted from the deblurred image $\bar{I}$ [S1].
*   **Rendered Color Patch ($\hat{C}_{ptc}$):** The color values rendered from the NeRF MLPs (without blur kernel) for the sampled patch rays [S1].
*   **Feature Maps ($\hat{\phi}_{ptc}, \bar{\phi}_{ptc}$):** Feature vectors extracted from $\hat{C}_{ptc}$ and $\bar{C}_{ptc}$ respectively using the feature extractor $E$ (VGG19) [S1].

**Parameters**
*   **Patch Size ($S_{ptc}$):** The dimension of the square patch. The sources specify $S_{ptc}=8$ for one dimension and $S_{ptc}=64$ for the other, implying a patch area or aspect ratio configuration where the total sampled area corresponds to these dimensions [S1].
*   **Perceptual Loss Weight ($\lambda_{pd}$):** 0.01 [S1].
*   **Deblurring Network ($\Theta_D$):** MPRNet [S1].
*   **Feature Extractor ($E$):** VGG19 [S1].

**Steps**
1.  **Generate Deblurred Images:** For each blurry training image $I$, generate the corresponding deblurred image $\bar{I}$ using the pre-trained deblurring network $\Theta_D$:
    $$ \bar{I} = \Theta_D(I) \quad [S1] $$
2.  **Sample Patch Rays and Patches:** On the training views, sample a set of patch rays $r_{pd}^{ptc}$ and extract the corresponding deblurred image patch $\bar{C}_{ptc}$ from $\bar{I}$. The patch size is defined as $S_{ptc} \times S_{ptc}$ [S1].
3.  **Render Patch Radiance:** Render the color patch $\hat{C}_{ptc}$ from the sampled rays $r_{pd}^{ptc}$ using the NeRF MLPs. Crucially, this rendering is performed *without* the blur kernel to produce "patch radiance" representing the clean scene [S1].
4.  **Extract Features:** Pass both the rendered color patch $\hat{C}_{ptc}$ and the deblurred image patch $\bar{C}_{ptc}$ through the shared pre-trained feature extractor $E$ to obtain feature representations:
    $$ \hat{\phi}_{ptc} = E(\hat{C}_{ptc}) \quad [S1] $$
    $$ \bar{\phi}_{ptc} = E(\bar{C}_{ptc}) \quad [S1] $$
5.  **Compute Perceptual Loss:** Calculate the $L_2$ norm squared between the extracted features:
    $$ L_{pd} = ||\hat{\phi}_{ptc} - \bar{\phi}_{ptc}||_2^2 \quad [S1] $$

**Pseudocode**
```python
def perceptual_distillation_loss(
    blurry_image: Tensor,
    patch_rays: List[Ray],
    nerf_model: NeRF,
    deblurring_net: Module,
    feature_extractor: Module
) -> Tensor:
    """
    Computes the Perceptual Distillation Loss.
    
    Args:
        blurry_image: Input blurry image I.
        patch_rays: Sampled rays r_pd_ptc for the patch.
        nerf_model: The NeRF MLPs.
        deblurring_net: Pre-trained MPRNet Theta_D.
        feature_extractor: Pre-trained VGG19 E.
        
    Returns:
        L_pd: Perceptual loss scalar.
    """
    # Step 1: Generate deblurred image
    # I_bar = Theta_D(I)
    deblurred_image = deblurring_net(blurry_image)
    
    # Step 2: Extract deblurred patch C_bar_ptc
    # Assuming patch_rays define a bounding box or region in the image plane
    # corresponding to S_ptc x S_ptc.
    # In practice, this involves mapping ray origins/intersections to pixel coordinates
    # and cropping the deblurred image.
    deblurred_patch = extract_patch_from_image(deblurred_image, patch_rays)
    
    # Step 3: Render clean patch radiance C_hat_ptc
    # Render using NeRF MLPs WITHOUT blur kernel
    rendered_patch = render_patch(nerf_model, patch_rays)
    
    # Step 4: Extract features phi_hat_ptc and phi_bar_ptc
    # phi_hat_ptc = E(C_hat_ptc)
    # phi_bar_ptc = E(C_bar_ptc)
    features_rendered = feature_extractor(rendered_patch)
    features_deblurred = feature_extractor(deblurred_patch)
    
    # Step 5: Compute L2 norm squared
    # L_pd = ||phi_hat_ptc - phi_bar_ptc||_2^2
    loss = torch.sum(torch.square(features_rendered - features_deblurred))
    
    return loss
```

**Edge Cases and Pitfalls**
*   **Geometric Inconsistency:** The module specifically targets the issue where independently deblurred images have inconsistent geometry across views. Using them as pixel-level targets would propagate these errors. The perceptual loss mitigates this by focusing on texture/feature transfer rather than exact pixel matching [S1].
*   **Blur Kernel Exclusion:** The rendered patch $\hat{C}_{ptc}$ must be generated without the blur kernel. Including the blur kernel would defeat the purpose of transferring "clean" texture information from the deblurred prior [S1].
*   **Patch Sampling:** The method relies on patch-wise sampling. The specific dimensions $S_{ptc}=8$ and $S_{ptc}=64$ are noted; implementers should ensure the patch extraction logic aligns with these specified dimensions [S1].

## Operating characteristics
*   **Time Complexity:** Adds overhead for the deblurring network inference (MPRNet) and the feature extraction (VGG19) per patch. The rendering step remains standard NeRF volume rendering.
*   **Memory Complexity:** Requires storing the deblurred images $\bar{I}$ and intermediate feature maps for the patches.
*   **Strengths:** Effectively transfers high-frequency texture details from 2D deblurring priors to the 3D radiance field, improving visual quality in sparse-view deblurring scenarios [S1].
*   **Limitations:** Relies on the quality of the pre-trained deblurring network (MPRNet) and the feature extractor (VGG19). If the deblurring network fails on a specific input, the perceptual prior may introduce incorrect textures [S1].
*   **When to use:** Sparse-view deblurring of radiance fields where geometric inconsistency from independent 2D deblurring is a significant issue [S1].

## Background
The Perceptual Distillation Module was introduced in "Sparse-DeRF: Deblurred Neural Radiance Fields From Sparse View" [S1]. It is described as a first attempt to utilize pre-deblurred images as an additional prior in deblurring radiance fields [S1]. The method builds upon the observation that independently deblurred multi-view images suffer from 3D geometric inconsistency, which can be addressed by using the deblurred images as a perceptual prior rather than direct targets [S1]. The implementation uses MPRNet for deblurring and VGG19 for feature extraction, consistent with common practices in image-based computer vision [S1].
