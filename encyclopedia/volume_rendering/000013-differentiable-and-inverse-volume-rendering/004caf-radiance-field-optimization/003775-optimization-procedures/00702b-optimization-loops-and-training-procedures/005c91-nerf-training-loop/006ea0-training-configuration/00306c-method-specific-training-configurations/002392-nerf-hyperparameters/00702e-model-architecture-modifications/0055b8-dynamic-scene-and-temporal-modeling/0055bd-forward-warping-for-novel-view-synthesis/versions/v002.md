# Forward Warping for Novel View Synthesis

Also called: Canonical Field Forward Warping, Forward Flow

## Overview
Forward Warping is a method for novel view synthesis of dynamic scenes that models a static scene at a canonical time step and forward warps the entire canonical field to other time steps [S1]. It addresses the many-to-one and one-to-many mapping difficulties inherent in dynamic scene reconstruction by using differentiable forward warping with average splatting and an inpaint network [S1]. Unlike backward flow-based methods such as NDVG, this approach leverages a canonical representation to simplify the modeling of temporal dynamics, achieving state-of-the-art performance, particularly for canonical frames [S1].

## How it works
The method employs a coarse-to-fine training strategy. It represents the scene using voxel grids for radiance features, deformation features, and density, along with several neural networks. The core pipeline involves estimating a canonical radiance field, predicting deformation flows to warp this field to target time steps, and refining the warped field using an inpaint network.

### Inputs and Outputs
*   **Inputs:** A set of multi-view images $\{I_t\}$ at various time steps $t$, camera poses, and intrinsic parameters.
*   **Outputs:** Rendered RGB images for novel views at arbitrary time steps.

### Data Structures and Layouts
The method utilizes several voxel grids and neural networks. All voxel grids are 3D structures.

**Voxel Grids:**
1.  **Canonical Radiance Feature Grid ($VR_f$):** Stores radiance features. Feature dimension is 12 [S1].
2.  **Canonical Coordinate Grid ($V_{pCan}$):** Stores the 3D coordinates of each voxel center [S1].
3.  **Canonical Density Grid ($V_{\sigma}^{Can}$):** Stores canonical density values [S1].
4.  **Canonical Color Feature Grid ($V_{cf}^{Can}$):** Stores canonical color features. Dimension is 3 in the coarse stage and 12 in the fine stage [S1].
5.  **Canonical Deformation Feature Grid ($VD_f^{Can}$):** Stores canonical deformation features. Dimension is 0 for D-NeRF dataset and 12 for HyperNeRF dataset [S1].
6.  **Trajectory Grid ($VT_t$):** Stores DCT (Discrete Cosine Transform) parameters for each voxel's trajectory [S1].
7.  **Deformation Flow Grid ($V_{flow}$):** Stores the deformation flow of each voxel from the canonical time to time $t$ [S1].
8.  **Warped Radiance Field ($VR_t$):** The radiance field at time $t$ warped from the canonical field [S1].
9.  **Inpainted Radiance Field ($VR_t^{Inp}$):** The radiance field at time $t$ after processing by the inpaint network [S1].
10. **Upsampled Radiance Field ($VR_t^{Up}$):** The upsampled radiance field at time $t$ [S1].

**Neural Networks:**
1.  **Canonical Radiance Network ($F_{\theta_1}$):**
    *   Structure: 3-layer MLP, width 128, ReLU activation [S1].
    *   Input: Concatenation of radiance feature sampled from $VR_f$ (dim 12) and embedded position $\gamma(\mathbf{x})$ (dim 33) [S1].
    *   Output: Density (dim 1) and color feature (dim 3 or 12, depending on stage) [S1].
2.  **Canonical Deformation Network ($F_{\theta_2}$):**
    *   Structure: 4-layer MLP, width 64 [S1].
    *   Input: Concatenation of deformation feature (dim 0 or 12) and embedded position $\gamma(\mathbf{x})$ (dim 33) [S1].
    *   Output: Trajectory parameters (DCT coefficients) [S1].
3.  **View Dependent Color Network ($F_{\theta_4}$):**
    *   Structure: 2-layer MLP, width 64 [S1].
    *   Input: Concatenation of embedded view direction $\gamma(\mathbf{d})$ (dim 27) and color feature (dim 12) [S1].
    *   Output: RGB color (dim 3) [S1].
4.  **Inpaint Network ($F_{\theta_3}$):**
    *   Structure: UNet with 4 encode layers and 3 decode layers, followed by an upsample layer [S1].
    *   Encode layer: Max pooling + two convolution layers (Instance Norm + Conv + ReLU) [S1].
    *   Decode layer: Up-sample interpolation + two convolution layers (Instance Norm + Conv + ReLU) [S1].
    *   Upsample layer: Same structure as decode layer [S1].

### Numbered Steps

**1. Canonical Field Estimation (Coarse Stage)**
The goal is to learn a proxy geometry.
1.  Initialize voxel grids $VR_f$, $V_{pCan}$, $V_{\sigma}^{Can}$, $V_{cf}^{Can}$ (dim 3), $VD_f^{Can}$ (dim 0), and $VT_t$.
2.  For each ray $r$ and sampled point $w_k$:
    *   Query $VR_f$ and $V_{pCan}$ to get radiance feature $\mathbf{f}$ and position $\mathbf{x}$.
    *   Compute embedded position $\gamma(\mathbf{x})$ [S1].
    *   Pass $\mathbf{f}$ and $\gamma(\mathbf{x})$ to $F_{\theta_1}$ to get density $\sigma$ and color feature $\mathbf{c}_{feat}$ [S1].
    *   Store $\sigma$ in $V_{\sigma}^{Can}$ and $\mathbf{c}_{feat}$ in $V_{cf}^{Can}$ [S1].
3.  Render image using standard volume rendering with $\sigma$ and $\mathbf{c}_{feat}$ (passed through $F_{\theta_4}$ if view-dependent color is needed, though coarse stage often uses simpler color prediction or skips view dependence for speed, the source specifies $F_{\theta_4}$ takes color feature dim 12, implying it's used in fine stage; coarse stage color feature is dim 3, so $F_{\theta_4}$ might not be used or is simplified. The source says $F_{\theta_4}$ input color feature is 12. Coarse stage $V_{cf}^{Can}$ dim is 3. Thus $F_{\theta_4}$ is likely not used in coarse stage or uses a different head. The source states "output contains density... and color feature... depending the training stage". It does not explicitly say $F_{\theta_4}$ is skipped, but the dimension mismatch suggests it. We assume standard rendering for coarse stage using the output of $F_{\theta_1}$ directly or a simple linear projection for color if view dependence is ignored, but the source lists $F_{\theta_4}$ as part of the network. Given the dimension constraint, $F_{\theta_4}$ is likely used only in the fine stage where $V_{cf}^{Can}$ has dim 12 [S1].)
4.  Optimize voxel grids and $F_{\theta_1}$ using the coarse stage loss (see Losses) for 20,000 iterations [S1].
5.  Do not use the inpaint network in the coarse stage [S1].

**2. Canonical Field Estimation (Fine Stage)**
1.  Initialize voxel grids with higher resolution. $V_{cf}^{Can}$ dimension is set to 12 [S1].
2.  Progressive Training: Start with 10 images closest to the canonical time step. Add one image with the closest time step every 60 iterations [S1].
3.  For each ray $r$ and sampled point $w_k$:
    *   Query $VR_f$ and $V_{pCan}$ to get $\mathbf{f}$ and $\mathbf{x}$ [S1].
    *   Compute $\gamma(\mathbf{x})$ [S1].
    *   Pass $\mathbf{f}$ and $\gamma(\mathbf{x})$ to $F_{\theta_1}$ to get $\sigma$ and $\mathbf{c}_{feat}$ (dim 12) [S1].
    *   Store $\sigma$ in $V_{\sigma}^{Can}$ and $\mathbf{c}_{feat}$ in $V_{cf}^{Can}$ [S1].
4.  Optimize voxel grids and $F_{\theta_1}$ using the fine stage loss for 100,000 iterations [S1].

**3. Deformation and Warping**
For a target time step $t$:
1.  For each voxel in $VD_f^{Can}$:
    *   Query $VD_f^{Can}$ to get deformation feature $\mathbf{d}_{feat}$ (dim 0 or 12) [S1].
    *   Query $V_{pCan}$ to get position $\mathbf{x}$ [S1].
    *   Compute $\gamma(\mathbf{x})$ [S1].
    *   Pass $\mathbf{d}_{feat}$ and $\gamma(\mathbf{x})$ to $F_{\theta_2}$ to get trajectory DCT parameters [S1].
2.  Compute the deformation flow $\mathbf{V}_{flow}$ from canonical position $\mathbf{x}$ to time $t$ position $\mathbf{x}_t$ using the DCT parameters and the time $t$ [S1].
3.  **Forward Warping (Average Splatting):**
    *   Warp the canonical radiance field ($VR_f$, $V_{cf}^{Can}$, $V_{\sigma}^{Can}$) to time $t$ to create $VR_t$.
    *   Use average splatting to handle many-to-one and one-to-many mappings [S1].
    *   For each voxel in the target grid at time $t$, accumulate features from canonical voxels that warp to this location, averaging them [S1].
    *   Store the result in $VR_t$ [S1].

**4. Inpainting and Rendering**
1.  Pass the warped radiance field $VR_t$ through the Inpaint Network $F_{\theta_3}$ to get $VR_t^{Inp}$ [S1].
2.  Upsample $VR_t^{Inp}$ to get $VR_t^{Up}$ [S1].
3.  **Rendering from $VR_t^{Inp}$:**
    *   For each ray $r$, sample points $w_k$.
    *   Query $VR_t^{Inp}$ to get density $\sigma$ and color feature $\mathbf{c}_{feat}$ (dim 12) [S1].
    *   Compute embedded view direction $\gamma(\mathbf{d})$ (dim 27) [S1].
    *   Pass $\mathbf{c}_{feat}$ and $\gamma(\mathbf{d})$ to $F_{\theta_4}$ to get RGB color $\mathbf{c}$ [S1].
    *   Render color $\mathbf{C}_{Inp}(r)$ using standard volume rendering [S1].
4.  **Rendering from $VR_t^{Up}$:**
    *   Similarly, render color $\mathbf{C}_{Up}(r)$ from the upsampled field [S1].

### Formulas

**Positional Encoding:**
$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$
Where $\mathbf{x}$ is position and $\mathbf{d}$ is view direction [S1].

**Point-wise Color Loss ($\mathcal{L}_{ptc}$):**
Supervises the color of sampled points weighted by their accumulation [S1].
$$
\mathcal{L}_{ptc} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Up}}(\mathbf{r}))
$$
Where:
$$
\mathcal{L}(\mathbf{C}(\mathbf{r})) = \frac{1}{K} \sum_{k=1}^{K} A_{\text{accum}}(k) \|\mathbf{c}(w_k) - \mathbf{C}_{\text{gt}}(\mathbf{r})\|_2^2
$$
$$
A_{\text{accum}}(k) = T(w_k) \, \sigma(w_k) \delta_k
$$
Here, $T(w_k)$ is the transmittance, $\sigma(w_k)$ is the density, and $\delta_k$ is the distance between samples [S1].

**Background Entropy Loss ($\mathcal{L}_{bg}$):**
Encourages densities to concentrate on foreground or background [S1].
$$
\mathcal{L}_{bg} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Up}}(\mathbf{r}))
$$
Where:
$$
\mathcal{L}(\mathbf{A}(\mathbf{r})) = -\frac{1}{K-1} \sum_{k=1}^{K-1} [ A_{\text{accum}}(k)\log(A_{\text{accum}}(k)) + (1-A_{\text{accum}}(k))\log(1-A_{\text{accum}}(k)) ]
$$
Note: The source formula for $\mathcal{L}(\mathbf{A}(\mathbf{r}))$ sums from $k=1$ to $K-1$ [S1].

**Total Loss:**
$$
\mathcal{L} = \mathcal{L}_{photo} + w_1\mathcal{L}_{ptc} + w_2\mathcal{L}_{bg} + w_3\mathcal{L}_{flow} + w_4\mathcal{L}_{vdiff} + w_5\mathcal{L}_{tv}(\mathbf{V}_{\sigma}^{\text{Can}}) + w_6\mathcal{L}_{tv}(\mathbf{V}_{\text{flow}}^t) + w_7\mathcal{L}_{tv}(\mathbf{D})
$$
Where $\mathcal{L}_{tv}$ is the total variation loss, $\mathbf{D}$ is likely the deformation feature grid or similar, and $w_i$ are balancing weights [S1].

### Parameters and Typical Values

**Coarse Stage:**
*   Voxel Number: $6^3$ [S1].
*   Inpaint Scale: 1.5 [S1].
*   Iterations: 20,000 [S1].
*   Weights: $w_1=10^{-1}, w_2=10^{-2}, w_3=10^{-5}, w_4=0, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$ [S1].

**Fine Stage:**
*   Voxel Number: $8^3$ for D-NeRF, $7^3$ for HyperNeRF [S1].
*   Inpaint Scale: 2.0 [S1].
*   Iterations: 100,000 [S1].
*   Weights: $w_1=10^{-2}, w_2=10^{-3}, w_3=10^{-5}, w_4=10^{-5}, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$ [S1].

**General:**
*   Learning Rate: $10^{-1}$ for voxel grids, $10^{-3}$ for networks [S1].
*   Canonical Time: First frame for D-NeRF, middle frame for HyperNeRF [S1].
*   Optimizer: Adam [S1].

### Edge Cases and Pitfalls
*   **Memory Consumption:** The method is memory-intensive, especially for real scenes [S1].
*   **Training Speed:** Training is slow, taking approximately one day per scene on a GeForce RTX 3090 [S1].
*   **Coarse Stage Importance:** Removing the coarse stage causes significant performance drops because the voxel grid covers a larger space without proxy geometry filtering [S1].
*   **Inpaint Network Importance:** Removing the inpaint network significantly reduces performance (e.g., Hell Warrior PSNR drops from 27.71 to 27.15) [S1].
*   **Splatting Method:** Average splatting is used instead of softmax splatting. Softmax splatting with predicted weights showed no obvious improvement and introduced too much complexity [S1].

## Operating characteristics
*   **Time Complexity:** Training is slow, taking approximately one day per scene on a GeForce RTX 3090 [S1].
*   **Memory Complexity:** Memory consumption is high, especially for real scenes [S1].
*   **Model Size:** 260M parameters for D-NeRF, 440M for HyperNeRF [S1].
*   **Rendering Speed:** 7s per image for D-NeRF, 15s per image for HyperNeRF [S1].
*   **Strengths:** Achieves state-of-the-art performance on public datasets, especially for canonical frames. The forward warping design provides a clear advantage over backward flow-based methods like NDVG [S1].
*   **Limitations:** High memory usage and slow training speed [S1].

## Background
Forward Warping was proposed in the paper "Forward Flow for Novel View Synthesis of Dynamic Scenes" [S1]. It addresses the challenges of novel view synthesis for dynamic scenes by modeling a static scene at a canonical time step and forward warping the entire canonical field to other time steps. The method was developed to handle many-to-one and one-to-many mapping difficulties using differentiable forward warping with average splatting and an inpaint network. It builds on the principles of dynamic scene and temporal modeling in NeRFs [S1].
