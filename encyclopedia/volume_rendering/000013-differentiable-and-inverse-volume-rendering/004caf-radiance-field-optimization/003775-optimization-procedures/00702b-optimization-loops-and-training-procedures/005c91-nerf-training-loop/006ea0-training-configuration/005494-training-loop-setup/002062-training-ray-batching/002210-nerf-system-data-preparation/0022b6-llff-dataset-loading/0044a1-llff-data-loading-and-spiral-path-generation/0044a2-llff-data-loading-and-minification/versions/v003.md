# LLFF Data Loading and Minification

Also called: LLFF Data Loading, LLFF Data Loading with ImageMagick Minification, LLFF Dataset Loading and Minification, LLFF Dataset Preparation, Tanks and Temples Data Loading

## Overview
This method prepares LLFF-style datasets for volume rendering by loading poses and images, downsampling them to a standard resolution, and splitting them into training and test sets [S3, unofficial]. It sets apart from generic loaders by enforcing the specific 1/8th resolution reduction and the "every 8th image" test split convention established in the original LLFF paper [S2]. It builds on [LLFF Data Loading and Spiral Path Generation](11275-llff-data-loading-and-spiral-path-generation.md) by providing the raw data tensors required for the optimization loop [G].

## How it works
**Inputs:**
- `basedir`: Path to the dataset root containing `pose/` (`.txt` files) and `rgb/` (`.jpg` files) subdirectories [S1, unofficial].
- `factor`: Integer downscale factor for images. Default is 8 [S3, unofficial].
- `llffhold`: Integer for test split interval. Default is 8 [S2].
- `movie_render_kwargs`: Dictionary for spiral path generation parameters (used in parent context, but relevant for coordinate scaling) [S1, unofficial].
- `args`: Optional arguments object, checked for `distill_active` [S1, unofficial].

**Outputs:**
- `images`: Numpy array of shape `[N, H', W', 3]` with values in `[0, 1]` [S3, unofficial].
- `poses`: Numpy array of camera extrinsics.
- `i_train`: List of indices for training images.
- `i_test`: List of indices for test images.
- `focal`: Scalar focal length derived from intrinsics.

**Data Structures:**
- Poses are stored as float32 numpy arrays [S1, unofficial].
- Images are stored as float32 numpy arrays normalized to `[0, 1]` [S3, unofficial].
- Intrinsics are loaded from `basedir/intrinsics.txt` [S1, unofficial].

**Steps:**
1. **Load File Lists:**
   - Retrieve paths for poses from `basedir/pose/*.txt` and images from `basedir/rgb/*.jpg`, sorted [S1, unofficial].
   - If `train.txt` and `test.txt` exist in `basedir`, use them to filter the image list, adjusting extensions to `.png` if necessary [S3, unofficial].
2. **Determine Dimensions and Minification:**
   - Determine image dimensions and scaling factor based on input arguments or original image size [S2].
   - Calculate target height $H'$ and width $W'$ based on `factor` [S3, unofficial].
   - If minification is required (i.e., `factor > 1`):
     - Create a new directory and resize images using ImageMagick `mogrify` command [S3, unofficial].
3. **Load Poses and Intrinsics:**
   - Load `poses_bounds.npy` if available. Reshape to extract poses as `[3, 5, N]` and bounds as `[2, N]` [S3, unofficial].
   - If `poses_bounds.npy` is not used, load individual pose files [S3, unofficial].
   - Load intrinsics from `basedir/intrinsics.txt` [S1, unofficial]. Extract focal length $f$ from $K_{0,0}$ [S1, unofficial].
4. **Load and Normalize Images:**
   - Iterate through the sorted image paths [S1, unofficial].
   - Load each RGB image.
   - Divide pixel values by 255.0 to normalize to `[0, 1]` [S1, unofficial].
   - Convert to float32 [S1, unofficial].
   - Stack images into a numpy array `images` of shape `[N, H', W', 3]` [S3, unofficial].
5. **Split Data:**
   - Determine the set index `i_set` from the first character of the RGB filename if multiple scenes are present [S1, unofficial].
   - Select test indices: Every `llffhold`-th image (e.g., indices `llffhold-1, 2*llffhold-1, ...`) [S2].
   - Select training indices: All remaining images, sampled evenly if subsampling is needed [S2].
   - Append the last split index list to `i_split` [S1, unofficial].
6. **Process Poses:**
   - Load poses as float32 arrays [S1, unofficial].
   - Calculate the centroid of camera positions [S1, unofficial].
   - Adjust pose camera centers by dividing by the scaling factor [S3, unofficial].
   - Adjust centroid based on `shift_x`, `shift_y`, `shift_z` from `movie_render_kwargs` [S1, unofficial].
   - Stack all images and poses into numpy arrays [S1, unofficial].
7. **Handle Features (Optional):**
   - If `args.distill_active` is true, load features from `basedir/features.pt` and reshape them [S1, unofficial].
   - Otherwise, create a zero tensor for features [S1, unofficial].

**Pseudocode:**

```python
import os
import numpy as np
import imageio

def load_llff_data(basedir, factor=8, llffhold=8, movie_render_kwargs=None, args=None):
    if movie_render_kwargs is None:
        movie_render_kwargs = {}
    if args is None:
        args = type('Args', (), {'distill_active': False})()
        
    # 1. Load file lists
    pose_dir = os.path.join(basedir, 'pose')
    rgb_dir = os.path.join(basedir, 'rgb')
    pose_files = sorted([os.path.join(pose_dir, f) for f in os.listdir(pose_dir) if f.endswith('.txt')])
    rgb_files = sorted([os.path.join(rgb_dir, f) for f in os.listdir(rgb_dir) if f.endswith('.jpg')])
    
    # Check for explicit splits
    train_path = os.path.join(basedir, 'train.txt')
    test_path = os.path.join(basedir, 'test.txt')
    if os.path.exists(train_path) and os.path.exists(test_path):
        with open(train_path) as f:
            train_names = [line.strip() + '.png' if not line.strip().endswith('.png') else line.strip() for line in f]
        with open(test_path) as f:
            test_names = [line.strip() + '.png' if not line.strip().endswith('.png') else line.strip() for line in f]
        # Filter rgb_files based on names (implementation detail omitted for brevity, assume alignment)
        pass

    # 2. Determine dimensions and minification
    H_orig, W_orig = 1008, 1344 # Typical LLFF size, adjust if known
    H_new = int(H_orig / factor)
    W_new = int(W_orig / factor)
    
    # 3. Minification
    resized_rgb_files = []
    if factor > 1:
        resize_dir = os.path.join(basedir, 'rgb_resized')
        os.makedirs(resize_dir, exist_ok=True)
        for f in rgb_files:
            basename = os.path.basename(f)
            out_path = os.path.join(resize_dir, basename)
            # Use ImageMagick mogrify
            import subprocess
            subprocess.run(['convert', f, '-resize', f'{W_new}x{H_new}!', out_path])
            resized_rgb_files.append(out_path)
    else:
        resized_rgb_files = rgb_files

    # 4. Load Images
    images = []
    for path in resized_rgb_files:
        img = imageio.imread(path)
        img = img.astype(np.float32) / 255.0
        images.append(img)
    images = np.stack(images, axis=0)

    # 5. Load Poses
    poses = []
    for path in pose_files:
        # Load 3x4 matrix
        pose = np.loadtxt(path, delimiter=' ').astype(np.float32)
        poses.append(pose)
    poses = np.stack(poses, axis=0)

    # 6. Load Intrinsics
    K = np.loadtxt(os.path.join(basedir, 'intrinsics.txt'), delimiter=' ').astype(np.float32)
    focal = K[0, 0]

    # 7. Split Data
    i_test = list(range(llffhold - 1, len(images), llffhold))
    i_train = [i for i in range(len(images)) if i not in i_test]

    # 8. Centering and Scaling (Simplified)
    # Calculate centroid of camera centers (poses[:, :3, 3])
    centers = poses[:, :3, 3]
    centroid = np.mean(centers, axis=0)
    poses[:, :3, 3] -= centroid
    
    # Apply shifts from movie_render_kwargs if present
    shift_x = movie_render_kwargs.get('shift_x', 0)
    shift_y = movie_render_kwargs.get('shift_y', 0)
    shift_z = movie_render_kwargs.get('shift_z', 0)
    poses[:, 0, 3] += shift_x
    poses[:, 1, 3] += shift_y
    poses[:, 2, 3] += shift_z

    return images, poses, i_train, i_test, focal
```

**Edge Cases and Pitfalls:**
- **Boundaries:** The "every 8th image" split assumes the dataset has at least 8 images [S2].
- **Alignment:** Pose files and RGB files must be strictly sorted and aligned. Mismatched indices lead to incorrect camera poses [S1, unofficial].

## Background
The specific data loading protocol, including the 1/8th resolution resize and the 1/8th image test split, became a community standard for evaluating NeRF and related methods on this dataset [S2]. The method described here implements this standard preprocessing step.
