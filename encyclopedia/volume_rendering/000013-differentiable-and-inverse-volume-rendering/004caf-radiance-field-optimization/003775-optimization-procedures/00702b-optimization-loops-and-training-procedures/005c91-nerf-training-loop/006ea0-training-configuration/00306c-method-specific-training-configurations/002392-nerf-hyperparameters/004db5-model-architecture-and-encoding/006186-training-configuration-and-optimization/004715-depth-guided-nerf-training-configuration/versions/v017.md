# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the hyperparameters, architectural modifications, and optimization settings required to train a Neural Radiance Field (NeRF) model using depth priors. It addresses the problem of geometric instability and texture-less region artifacts in standard NeRF training by integrating depth supervision. It differs from sibling methods like [CLIPNeRF](12073-clipnerf-training-configuration.md) by focusing on geometric consistency via depth metrics rather than semantic alignment, and from [Binary Radiance Fields](13622-binary-radiance-fields.md) by maintaining continuous density representations.

## How it works
**Inputs:**
*   Camera poses and intrinsics.
*   RGB images.
*   Ground truth depth maps (optional, used for loss calculation).
*   Scene-specific depth bounds ($min\_depth$, $max\_depth$).

**Outputs:**
*   Trained NeRF model parameters (MLP weights, encoding tables).
*   Rendered RGB images and depth maps.

**Data Structures:**
*   **NeRF Model:** Builds on the original NeRF architecture [S1].
    *   **Encoding:** Positional encoding of 3D coordinates $\mathbf{x}$ and viewing direction $\mathbf{d}$.
    *   **MLP:** Fully connected layers with ReLU activations.
    *   **Modification:** Dropout layers with probability $p=0.1$ are inserted after each of the first eight fully connected layers [S1].
*   **Optimizer State:** Adam optimizer state variables (first and second moment estimates).

**Parameters:**
*   **Depth Loss Weight ($\lambda$):** $0.007$ for most scenes; $0.02$ for scene 710 [S1].
*   **Uncertainty Weight ($\gamma$):** $1$ [S1].
*   **Adam Learning Rate:** $5 \times 10^{-4}$ [S1].
*   **Depth Scale Learning Rate:** $1 \times 10^{-7}$ [S1].
*   **Weight Decay:** $1 \times 10^{-6}$ [S1].
*   **Total Training Steps:** $500,000$ [S1].
*   **Learning Rate Schedule:** Reduce learning rate to $5 \times 10^{-5}$ after $80\%$ of total steps [S1].
*   **Depth Threshold ($\tau$):** Used to evaluate depth uncertainty. Calculated as:
    $$ \tau = (max\_depth - min\_depth) \cdot 0.0001 $$
    Typical values for ScanNet: $min\_depth = 0.001$, $max\_depth = 10$ [S1].

**Algorithm Steps:**
1.  **Initialize** the NeRF model with positional encoding and the modified MLP architecture (dropout after first 8 FC layers) [S1].
2.  **Initialize** Adam optimizer with learning rate $5 \times 10^{-4}$ and weight decay $1 \times 10^{-6}$ [S1].
3.  **For** each training step $t$ from $1$ to $500,000$:
    a. Sample a batch of rays from the training images.
    b. Render RGB colors and depth values for the sampled rays using the current NeRF model.
    c. Compute the photometric loss (e.g., MSE) between rendered RGB and ground truth RGB.
    d. Compute the depth loss using the rendered depth and ground truth depth. The specific depth metrics include RMSE, Log-RMSE, AbsRel, and SqRel [S1].
    e. Compute the total loss:
       $$ L_{total} = L_{rgb} + \lambda L_{depth} + \gamma L_{uncertainty} $$
       (Note: The exact formulation of $L_{uncertainty}$ is not detailed in the provided text, but $\gamma=1$ is specified [S1]).
    f. Update model parameters using Adam optimizer.
    g. If $t > 0.8 \times 500,000$, update the learning rate to $5 \times 10^{-5}$ [S1].
4.  **Return** the trained model.

**Edge Cases and Pitfalls:**
*   **Scene 710:** Requires a higher depth loss weight ($\lambda = 0.02$) compared to other scenes ($\lambda = 0.007$) [S1].
*   **Depth Scale:** Requires a separate, much smaller learning rate ($1 \times 10^{-7}$) for the depth scale parameter [S1].
*   **Threshold Calculation:** The threshold $\tau$ for depth uncertainty evaluation is scene-dependent and must be calculated based on the specific $min\_depth$ and $max\_depth$ of the dataset [S1].

## Subtopics

### DS-NeRF Depth Loss Integration
Integrates the depth loss implementation from the official DS-NeRF codebase into the training pipeline. This variant is used when re-training on specific splits (e.g., LLFF train/test splits) because original publication results for LLFF used different splits, and DTU results could not be reproduced due to missing configuration files in the official repository [S2]. It assumes the use of PDC-Net correspondences for multi-view correspondence loss [S2].

## Operating characteristics
*   **Time Complexity:** Determined by the number of training steps (500,000) and the cost of rendering rays through the MLP with dropout [S1].
*   **Memory Complexity:** Standard NeRF memory usage plus storage for dropout states and optimizer states [S1].
*   **Strengths:** Improves geometric accuracy by leveraging depth priors; dropout prevents overfitting in texture-less regions [S1].
*   **Limitations:** Requires ground truth depth maps for supervision; sensitive to the choice of $\lambda$ and $\tau$ [S1].
*   **When to Use:** When geometric consistency is critical and ground truth depth is available.
*   **When Not to Use:** When depth data is unavailable or when semantic consistency is the primary goal (use [CLIPNeRF](12073-clipnerf-training-configuration.md) instead).

## Background
This configuration originates from the work on Depth-Guided NeRF Training via Earth Mover’s Distance [S1]. It builds upon the original NeRF architecture [15] and incorporates techniques from DS-NeRF [S2] for depth loss integration. The method was developed to address the lack of geometric constraints in standard NeRF training, particularly in scenes with large texture-less areas.
