# Conditional and Latent Representations

Also called: Disentangled Conditional NeRF, HeadNeRF, CLIP-NeRF

## Overview
Conditional and Latent Representations extend standard NeRF architectures by conditioning the volumetric function $F_\Theta$ on external latent codes or explicit deformations, enabling generative modeling and semantic manipulation of 3D scenes [S1]. Unlike standard NeRF, which learns a single static scene per optimization run, this family maps spatial positions and view directions to density and color using additional inputs such as shape codes, appearance codes, or identity/expression parameters, allowing for independent control over geometry and appearance [S1]. This approach solves the problem of static scene representation by enabling the synthesis of novel instances from a learned category distribution or the real-time rendering of parametric subjects (e.g., human heads) with direct attribute control [S1].

## Shared principles
The core mechanism involves modifying the input domain of the radiance field MLP to include latent vectors $\mathbf{z}$ or deformation parameters, rather than relying solely on positional encoding $\Gamma(\mathbf{x})$ and view direction $\mathbf{d}$ [S1]. The general mapping is defined as:
$$ F_\Theta: (\mathbf{x}, \mathbf{d}, \mathbf{z}) \rightarrow (\sigma, \mathbf{c}) $$
where $\mathbf{z}$ represents the conditioning information [S1].

Key shared characteristics include:
1.  **Disentanglement**: To prevent mutual intervention (e.g., shape changes altering color), shape and appearance conditioning are often separated. Shape conditioning typically affects the spatial position $\mathbf{x}$ (via deformation) or the density prediction $\sigma$, while appearance conditioning affects the color prediction $\mathbf{c}$ [S1].
2.  **Latent Space Sampling**: Codes are sampled from learned distributions (e.g., normal distributions) or inferred from input data (e.g., via CLIP encoders) [S1].
3.  **Generative Framework**: Many implementations integrate a GAN framework, using a discriminator to ensure photorealism and consistency of the generated views [S1][S2, unofficial].

## Subtopics

### [Disentangled Conditional NeRF](16793-disentangled-conditional-nerf.md)
A generative architecture that achieves independent control over object shape and appearance by isolating shape conditioning to explicit volumetric deformation of positional encodings. Unlike standard conditional NeRFs where concatenating latent codes causes mutual intervention, this method prevents interference by deferring appearance conditioning to the radiance field while applying shape conditioning via a deformation network. It uses a GAN framework with a PatchGAN discriminator to train the generator and deformation network jointly.

### [HeadNerf](18595-headnerf.md)
A NeRF-based parametric head model that integrates neural radiance fields into a parametric representation of the human head to render high-fidelity images in real-time. It supports direct control over rendering pose and semantic attributes: identity, expression, albedo, and illumination. Unlike standard NeRF, which treats geometry and appearance as monolithic implicit functions, HeadNeRF disentangles these factors by conditioning the density prediction on shape codes (identity, expression) and the feature prediction on appearance codes (albedo, illumination), while removing viewing direction dependence to mitigate dataset bias. It accelerates rendering from seconds to milliseconds by combining volumetric rendering with a 2D neural refinement network.

### CLIP-Driven Manipulation via Mappers
A feed-forward approach using shape mapper $M_s$ and appearance mapper $M_a$ to update initial shape/appearance codes ($z_{s0}, z_{a0}$) based on a text prompt $t$, avoiding per-sample optimization [S1]. The updated shape code $z_s$ is calculated as $z_s = M_s(\hat{E}_t(t)) + z_{s0}$, and the appearance code $z_a$ as $z_a = M_a(\hat{E}_t(t)) + z_{a0}$, where $\hat{E}_t$ is the pre-trained CLIP text encoder [S1]. This differs from optimization-based editing (e.g., EditNeRF) by using learned feed-forward networks mapping user edits to latent codes, enabling fast inference for interactive editing instead of slow iterative optimization per sample [S1].

### Continuous Manipulation via Latent Space Scaling
A technique to achieve gradual editing of shape and appearance by scaling the editing direction vectors in the latent space using a scalar factor $s$ [S1]. The codes are updated as $z_s = s \times \Delta z_s + z_{s0}$ and $z_a = s \times \Delta z_a + z_{a0}$, where $\Delta z_s$ and $\Delta z_a$ are the manipulation directions provided by the code mappers [S1]. The scalar $s$ controls the intensity of the edit, with a typical range of 0 to 1.6 with step 0.2 [S1]. This allows users to adjust the degree of change given a single text prompt or exemplar [S1].

### CLIP-Driven Manipulation
A method that extracts CLIP feature embeddings from input text prompts or exemplar images and feeds them into separate feed-forward code mappers (shape and appearance) to output local displacements in the latent space [S1]. These displacements update $z_s$ and $z_a$, which are then used to render the image [S1]. The mappers are trained using a CLIP-based matching loss $D_{CLIP}(I, t) = 1 - \langle \hat{E}_i(I), \hat{E}_t(t) \rangle$ to enforce CLIP space consistency between the input constraint and output renderings [S1].

### Deferred Appearance Conditioning
A technique where appearance conditioning is deferred to concatenate the appearance code with the view direction as input to the radiance prediction network, allowing appearance manipulation without affecting shape/density [S1]. This prevents the "mutual intervention" problem where shape changes inadvertently alter color, a common issue in trivial concatenation approaches [S1].

### Conditional NeRF in GAN Framework
The integration of conditional NeRFs into a Generative Adversarial Network (GAN) framework [S2, unofficial]. This approach leverages adversarial losses to learn a 3D generative model of shape and appearance from 2D images, achieving significant improvements in photorealism compared to non-adversarial methods [S2, unofficial]. It was first proposed with voxel-grid representations and later applied to NeRFs by GRAF [S2, unofficial].

## Background
The concept of conditional NeRFs originated from the need to generalize neural radiance fields from single-scene representations to category-level generative models. The foundational work on disentangled conditional NeRFs, specifically **CLIP-NeRF**, was introduced by Wang et al. in 2022 [S1]. This paper presented the first text-and-image driven manipulation method for NeRF, using a disentangled architecture with a deformation network for shape and deferred conditioning for appearance [S1]. The integration of NeRFs into GAN frameworks was pioneered by **GRAF** (Generative Radiance Fields), which demonstrated that adversarial training significantly improves the photorealism of conditional NeRFs [S2, unofficial]. **HeadNeRF** later adapted these principles for parametric human head modeling, introducing real-time rendering capabilities through 2D refinement and explicit disentanglement of identity, expression, albedo, and illumination [S1].
