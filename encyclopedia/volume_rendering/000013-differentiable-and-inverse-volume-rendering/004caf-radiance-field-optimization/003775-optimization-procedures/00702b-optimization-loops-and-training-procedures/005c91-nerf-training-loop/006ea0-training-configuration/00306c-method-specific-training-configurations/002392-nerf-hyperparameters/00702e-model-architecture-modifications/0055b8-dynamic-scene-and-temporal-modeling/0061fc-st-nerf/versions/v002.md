# ST-NeRF
Also called: Spatially and temporally consistent NeRF

## Overview
ST-NeRF is a layered neural radiance field representation designed for editable free-viewpoint videos of dynamic scenes [S1, unofficial][S2]. It solves the problem of disentangling spatial and temporal variations in moving objects by assigning each independently moving or articulated entity to a separate layer [S1, unofficial]. Unlike monolithic dynamic NeRFs, ST-NeRF explicitly models space-time coherence through a deformation module and a canonical space radiance module, enabling direct spatial and temporal editing of individual entities [S1, unofficial][S2].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of synchronized multi-view videos (typically 16 cameras arranged in a half-circle) and human-background segmentation masks [S1, unofficial]. The model also accepts timestamps (or frame numbers) to account for temporal evolution [S1, unofficial][S2].
*   **Outputs:** Accumulated density $\sigma$ and view-dependent color $\mathbf{c}$ for rays cast through the scene layers [S1, unofficial].

**Data Structures**
The scene is represented as a collection of layers, where each layer corresponds to a distinct dynamic entity (e.g., a performer) [S1, unofficial][S2]. Each layer contains:
1.  A **Space-Time Deformation Module**: A neural network that maps 3D spatial coordinates $\mathbf{x}$ and time $t$ to a canonical space [S1, unofficial][S2].
2.  A **Neural Radiance Module**: A standard NeRF MLP that maps canonical coordinates and viewing direction $\mathbf{d}$ to density $\sigma$ and color $\mathbf{c}$ [S1, unofficial][S2].

**Algorithm**
1.  **Layer Initialization:** For each dynamic entity in the scene, initialize a separate layer with its own deformation and radiance networks [S1, unofficial][S2].
2.  **Time Encoding:** Encode the input timestamp $t$ (or frame number) directly into the model parameters or as an input feature to facilitate the disentanglement of space and time [S2].
3.  **Deformation:** For a query point $\mathbf{x}$ at time $t$, pass $(\mathbf{x}, t)$ through the Space-Time Deformation Module of the relevant layer to obtain the canonical coordinate $\mathbf{x}'$ [S1, unofficial][S2].
    $$ \mathbf{x}' = \mathcal{D}_i(\mathbf{x}, t) $$
    where $\mathcal{D}_i$ is the deformation network for layer $i$ [S1, unofficial].
4.  **Radiance Query:** Pass the canonical coordinate $\mathbf{x}'$, viewing direction $\mathbf{d}$, and potentially the timestamp $t$ into the Neural Radiance Module of layer $i$ to obtain density $\sigma_i$ and color $\mathbf{c}_i$ [S1, unofficial][S2].
    $$ \sigma_i, \mathbf{c}_i = \mathcal{R}_i(\mathbf{x}', \mathbf{d}, t) $$
    where $\mathcal{R}_i$ is the radiance network for layer $i$ [S1, unofficial].
5.  **Rendering:** Cast rays through the scene. For each ray, determine intersections with the bounding boxes of the layers [S1, unofficial][S2]. Sample points along the ray within each intersected layer. Accumulate density and color using the standard volume rendering integral, summing contributions from all layers [S1, unofficial].
    $$ \mathbf{C}(\mathbf{r}) = \sum_{i} \sum_{k} T_{i,k} (1 - \exp(-\sigma_{i,k} \delta_k)) \mathbf{c}_{i,k} $$
    where $T_{i,k}$ is the accumulated transmittance up to sample $k$ in layer $i$, and $\delta_k$ is the distance between samples [S1, unofficial][S2].

**Parameters**
*   **Number of Layers:** Equal to the number of independently moving entities [S1, unofficial].
*   **Camera Setup:** 16 synchronized cameras in a half-circle arrangement [S1, unofficial].
*   **Segmentation:** Human-background masks are required as input [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Occlusion:** The layered representation assumes entities can be disentangled. Heavy occlusion between layers may complicate the assignment of rays to specific layers [S1, unofficial].
*   **Non-Rigid Editing:** The current implementation focuses on rigid transformations (rescaling, shifting) and temporal rearrangements. Non-rigid scene editing is noted as a future direction, implying current limitations in handling complex deformations beyond the learned space-time deformation [S1, unofficial].

## Subtopics

### Neural Scene Graph (NSG)
A related layered representation that uses bounding boxes for objects and disentangles positions, deformations, and appearance. It supports background-foreground decomposition and scene editing [S1, unofficial].

### AutoRF
Builds a full 3D radiance field for each object within a bounding box, allowing efficient rendering by focusing on ray-box intersections [S2].

### PNF (Parametric Neural Fields)
Represents dynamic scenes using parametric fields for individual objects, enabling independent manipulation [S2].

### Dis-CoScene
Disentangles scene components into separate radiance fields for efficient editing and rendering [S2].

## Operating characteristics
*   **Complexity:** Rendering complexity scales with the number of layers and the number of samples per layer. Ray-box intersection tests are required to determine which layers to sample [S2].
*   **Strengths:** Enables direct spatial editing (affine transformation, insertion, removal) and temporal editing (re-timing) of individual entities [S2]. Provides spatial and temporal consistency through explicit deformation modeling [S1, unofficial].
*   **Limitations:** Requires segmented input data (human-background masks) and multiple synchronized views [S1, unofficial]. Reducing the number of input views is an open challenge [S1, unofficial]. Non-rigid editing is not fully supported in the current formulation [S1, unofficial].
*   **When to use:** When editing specific dynamic entities in a scene (e.g., rescaling, removing, or re-timing a performer) is required, and multi-view segmented data is available [S1, unofficial][S2].
*   **When not to use:** For scenes with unsegmented, densely interacting dynamic objects where layer separation is ambiguous, or when only monocular input is available [S1, unofficial].

## Background
ST-NeRF was introduced by Zhang et al. [JXX∗ 21] as a layered representation for editable free-viewpoint videos [S1, unofficial]. It builds on the principles of neural radiance fields and extends them to dynamic scenes by explicitly modeling space-time coherence [S1, unofficial]. The method is part of a broader family of neural scene graph and layered representation approaches that aim to disentangle scene components for editing and understanding [S1, unofficial][S2]. Applications include background-foreground decomposition, enriching training datasets for automotive perception, and improved object detection and scene understanding [S1, unofficial].
