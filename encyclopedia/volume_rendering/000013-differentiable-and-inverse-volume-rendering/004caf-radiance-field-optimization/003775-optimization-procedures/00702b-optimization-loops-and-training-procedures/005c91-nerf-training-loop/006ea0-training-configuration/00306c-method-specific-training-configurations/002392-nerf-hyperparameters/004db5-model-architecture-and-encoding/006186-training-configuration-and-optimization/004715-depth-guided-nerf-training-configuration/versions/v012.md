# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the training protocol for a Neural Radiance Field (NeRF) model that incorporates depth priors to improve reconstruction quality, specifically addressing the ambiguity of scale and structure in sparse-view or noisy-pose scenarios. It builds on the standard NeRF architecture [Parent](13550-model-architecture-and-encoding.md) by modifying the optimization loop to include a depth consistency loss. What sets this apart from standard NeRF training is the explicit weighting of depth supervision and the specific regularization (dropout) applied to the positional encoding layers to prevent overfitting when depth constraints are active.

## How it works
**Inputs:**
*   Ray parameters: Origin $\mathbf{o}$ and direction $\mathbf{d}$.
*   Ground truth depth maps $D_{gt}$ corresponding to the camera poses used for ray sampling.
*   Scene-specific depth bounds: $min\_depth$ and $max\_depth$.

**Outputs:**
*   Rendered RGB image $C(\mathbf{r})$.
*   Predicted depth map $\hat{D}$.
*   Uncertainty map $\sigma_{depth}$ (used for adaptive weighting).

**Data Structures:**
*   **NeRF Model:** Two MLPs (density and color) as defined in [Parent](13550-model-architecture-and-encoding.md).
*   **Dropout Mask:** Binary mask applied to the first 8 fully connected layers of the positional encoding network.
*   **Optimizer State:** Adam optimizer state for model parameters and a separate state for the depth scale parameter.

**Parameters:**
*   Dropout probability $p_{drop} = 0.1$.
*   Depth loss weight $\lambda$: $0.007$ for most scenes; $0.02$ for scene 710.
*   Uncertainty weight $\gamma = 1$.
*   Adam learning rate $lr = 5 \times 10^{-4}$.
*   Depth scale learning rate $lr_{scale} = 1 \times 10^{-7}$.
*   Weight decay $wd = 1 \times 10^{-6}$.
*   Total training steps $T_{total} = 500,000$.
*   Schedule step: $0.8 \times T_{total}$.

**Formulas:**
1.  **Uncertainty Threshold:**
    $$ \tau = (max\_depth - min\_depth) \cdot 0.0001 $$
    Where $max\_depth = 10$ and $min\_depth = 0.001$ for ScanNet scenes [S1].

2.  **Depth Loss:**
    The depth loss is computed only on pixels $k$ where the ground truth depth $d_k$ is valid and the predicted uncertainty is below $\tau$. The specific loss function is not explicitly defined in the source text, but standard implementations typically use an L1 or L2 loss on the predicted depth $\hat{d}_k$ and ground truth $d_k$. The source cites the integration of the DS-NeRF depth loss [S2].

3.  **Total Loss:**
    $$ L_{total} = L_{rgb} + \lambda \cdot L_{depth} + \gamma \cdot L_{uncertainty} $$
    (Note: The exact form of $L_{uncertainty}$ is not detailed in the provided notes, but $\gamma$ scales its contribution [S1]).

**Steps:**
1.  **Initialize Model:** Load the standard NeRF architecture [Parent](13550-model-architecture-and-encoding.md).
2.  **Add Regularization:** Insert dropout layers with probability $p_{drop}=0.1$ after each of the first eight fully connected ReLU-activated layers that encode the positional encoding [S1].
3.  **Initialize Optimizer:**
    *   Create Adam optimizer for NeRF parameters with $lr=5 \times 10^{-4}$ and $wd=1 \times 10^{-6}$.
    *   Create separate Adam optimizer (or parameter group) for the depth scale parameter with $lr=1 \times 10^{-7}$ [S1].
4.  **Training Loop:** For step $t$ from 1 to $T_{total}$:
    a. Sample rays from training images.
    b. Render RGB and Depth using the NeRF model.
    c. Compute $L_{rgb}$ against ground truth RGB.
    d. Compute $L_{depth}$ against ground truth depth $D_{gt}$, masking out invalid pixels and those with uncertainty $>\tau$ [S1].
    e. Compute total loss $L_{total}$ using weights $\lambda$ and $\gamma$ [S1].
    f. Backpropagate and update parameters.
    g. **Learning Rate Schedule:** If $t > 0.8 \times T_{total}$, reduce the main learning rate to $5 \times 10^{-5}$ [S1].
5.  **Evaluation:** Compute metrics (RMSE, AbsRel, etc.) on the test set using valid pixels [S1].

## Subtopics

### DS-NeRF Depth Loss Integration
This variant involves integrating the specific depth loss implementation from the DS-NeRF official code base into the training loop. It requires re-training on LLFF train/test splits using released configuration files, as the original publication results for LLFF used a different split and DTU results could not be reproduced due to missing config files [S2].

## Operating characteristics
*   **Time Complexity:** Standard NeRF volume rendering complexity $O(N \cdot R)$, where $N$ is samples per ray and $R$ is number of rays. The depth loss computation adds $O(P)$ where $P$ is the number of pixels, but is negligible compared to rendering.
*   **Memory Complexity:** Standard NeRF memory usage. Dropout adds negligible overhead.
*   **Performance:** The configuration is designed for scenes like ScanNet and LLFF. The specific depth loss weight $\lambda$ is tuned per scene (0.007 or 0.02) to balance RGB and depth fidelity [S1].
*   **Strengths:** Improves geometric accuracy and scale consistency by leveraging depth priors. Dropout prevents overfitting to noisy depth or RGB data.
*   **Limitations:** Requires ground truth depth maps. Performance may degrade if depth maps are inaccurate or if the uncertainty threshold $\tau$ is not well-calibrated. Reproducing DTU results is difficult due to missing configuration files in the official DS-NeRF code [S2].

## Background
This configuration originates from the work on "Depth-Guided NeRF Training via Earth Mover’s Distance" [S1]. It builds upon the original NeRF architecture [Parent](13550-model-architecture-and-encoding.md) and incorporates techniques from DS-NeRF [S2] to handle depth supervision. The specific hyperparameters (dropout, learning rate schedule, loss weights) were empirically determined for datasets like ScanNet and LLFF.
