# CCNeRF
Also called: Compressible-Composable NeRF, Rank-residual Decomposition NeRF

## Overview
CCNeRF is a neural field representation that models 3D scenes using hybrid tensor rank decomposition (CP and triple-plane variants) without neural networks for rendering, enabling dynamic compression via rank truncation and arbitrary composition via rank concatenation [S1]. Unlike NeRF variants that rely on shared MLP renderers (e.g., NSVF) or hybrid tensor-MLP approaches (e.g., TensoRF), CCNeRF preserves the low-rank approximation property of the radiance field, allowing model size and detail levels to be adjusted post-training without retraining [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 2D images with known camera poses $(o, d)$ for a 3D scene [S1].
*   **Output:** A compressed radiance field representation consisting of rank components (vectors or matrices) and a weight matrix, capable of rendering colors $\hat{C}(r)$ for any ray $r$ [S1].

**Data Structures:**
The model structure consists of two main parts [S1]:
1.  **Rank Components:** A set of decomposed components representing the scene [S1].
2.  **Weight Matrix:** A matrix storing rank weights for different feature channels, mapping the decomposed components to the final output (density and color) [S1].
The rank components are either vector-based (CP) with factor matrices $U^x, U^y, U^z$ for spatial dimensions, or matrix-based (Triple Plane) with factor matrices for 2D planes (e.g., $U^{xy}, U^{yz}, U^{xz}$) [S1]. The ratio of vector- to matrix-based components is controllable [S1].

**Formulas:**
The volume rendering equation computes the pixel color $\hat{C}(r)$ for a ray $r$ [S1]:
$$ \hat{C}(r) = \sum_i T_i \alpha_i c_i $$
where $T_i = \prod_{j<i} (1 - \alpha_j)$ is the transmittance, $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ is the opacity, $\delta_i = t_{i+1} - t_i$ is the distance between sample points, $\sigma_i$ is the density, $c_i$ is the color, and $t_i$ is the sample position along ray $r$ from origin $o$ with direction $d$ [S1].
The underlying tensor decomposition follows the Tucker form for a 3D tensor $T \in \mathbb{R}^{H \times W \times D}$ [S1]:
$$ T_{i,j,k} = \sum_{p=1}^P \sum_{q=1}^Q \sum_{r=1}^R S_{p,q,r} U^x_{i,p} U^y_{j,q} U^z_{k,r} $$
where $S$ is the core tensor and $U^x, U^y, U^z$ are factor matrices [S1].

**Querying a 3D Coordinate:**
To query a 3D coordinate $\mathbf{x}$, the coordinate is first projected to the decomposed vectors or matrices [S1]. Then, weighted interpolation is performed using the stored rank weights [S1].

**Training and Rank-Residual Learning:**
The model is trained to learn a hybrid tensor rank decomposition [S1]. A rank-residual learning strategy is employed to encourage lower ranks to preserve more important information of the whole scene [S1].

**Compression (Rank Truncation):**
Model size is dynamically adjusted by rank truncation [S1]. An empirical sort-and-truncate strategy is used to achieve near-optimal low-rank approximation at any targeted rank [S1]. Components are sorted based on their importance, and the least important components are removed to achieve a targeted rank $r$ [S1]. This allows a trade-off between model size and rendering quality without retraining [S1]. Standard truncated Higher-Order SVD (HOSVD) does not hold the optimal property of truncated SVD but yields a quasi-optimal solution sufficient for practical use [S1].

**Composition (Rank Concatenation):**
Different models (objects) are composed into a single scene by concatenating their rank components along the rank dimension [S1]. A transformation matrix is recorded for each object to control its position and orientation in the composed scene [S1]. The growth of storage cost can be mitigated by compressing (truncating) less important objects in the composed scene [S1].

**Pseudocode:**
```python
import math

def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def bilinear_interpolate(grid, x, y):
    """Standard bilinear interpolation on a 2D grid [G]."""
    x0, y0 = int(math.floor(x)), int(math.floor(y))
    x1, y1 = x0 + 1, y0 + 1
    dx, dy = x - x0, y - y0
    top = grid[y0][x0] * (1 - dx) + grid[y0][x1] * dx
    bottom = grid[y1][x0] * (1 - dx) + grid[y1][x1] * dx
    return top * (1 - dy) + bottom * dy

def query_ccnerf(x, y, z, rank_components, weight_matrix):
    """Query the radiance field at coordinate (x, y, z)."""
    projected_values = []
    for comp in rank_components:
        if comp['type'] == 'CP':
            val = 1.0
            for U in comp['vectors']:
                val *= dot([x, y, z], U)
            projected_values.append(val)
        elif comp['type'] == 'TRIPLE_PLANE':
            val = 1.0
            for plane in comp['planes']:
                if plane['axis'] == 'xy':
                    val *= bilinear_interpolate(plane['grid'], x, y)
                elif plane['axis'] == 'yz':
                    val *= bilinear_interpolate(plane['grid'], y, z)
                elif plane['axis'] == 'xz':
                    val *= bilinear_interpolate(plane['grid'], x, z)
            projected_values.append(val)
    features = [sum(p * w for p, w in zip(projected_values, w_row)) for w_row in weight_matrix]
    return features[0], features[1:]

def sort_by_importance(rank_components, weight_matrix):
    """Sort components by importance derived from weight matrix norms."""
    importances = []
    for i, _ in enumerate(rank_components):
        norm = math.sqrt(sum(w**2 for w in weight_matrix[i]))
        importances.append((norm, i))
    importances.sort(key=lambda x: x[0], reverse=True)
    return [idx for _, idx in importances]

def compress_ccnerf(rank_components, weight_matrix, target_rank):
    """Compress the model by truncating rank components."""
    sorted_indices = sort_by_importance(rank_components, weight_matrix)
    selected = sorted_indices[:target_rank]
    return [rank_components[i] for i in selected], [weight_matrix[i] for i in selected]

def compose_ccnerf(models, transformations):
    """Compose multiple CCNeRF models into a single scene."""
    all_components = []
    all_weights = []
    for m in models:
        all_components.extend(m['rank_components'])
        all_weights.extend(m['weight_matrix'])
    return {
        'rank_components': all_components,
        'weight_matrix': all_weights,
        'transformations': transformations
    }
```

## Operating characteristics
*   **Compression:** Achieves near-optimal low-rank approximation at any targeted rank without retraining [S1].
*   **Composition:** Supports arbitrary composition of different models without retraining or compatibility constraints, as there are no MLP renderers [S1].
*   **Storage:** Model size is dynamically adjustable [S1]. Storage cost growth in composed scenes can be mitigated by compressing unimportant objects [S1].
*   **Limitations:** Standard truncated HOSVD is quasi-optimal, not strictly optimal [S1].

## Background
CCNeRF was introduced by Jiaxiang Tang, Xiaokang Chen, Jingbo Wang, and Gang Zeng in 2022 [S1]. It addresses the difficulty of manipulating NeRF models (like compression and composition) caused by their implicit representation and shared MLP renderer [S1]. The method is motivated by the low-rank approximation property of the SVD algorithm and the use of tensor decomposition in vision tasks [S1]. It builds on the idea that neural radiance fields can be modeled using tensor rank decomposition, similar to image compression [S1].
