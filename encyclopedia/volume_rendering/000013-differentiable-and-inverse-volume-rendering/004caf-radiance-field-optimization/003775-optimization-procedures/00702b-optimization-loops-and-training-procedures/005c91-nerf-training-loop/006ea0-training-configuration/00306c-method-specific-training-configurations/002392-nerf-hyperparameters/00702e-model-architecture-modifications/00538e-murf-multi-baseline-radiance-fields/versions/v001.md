# MuRF (Multi-Baseline Radiance Fields)
Also called: Multi-Baseline Radiance Fields

## Overview
MuRF is a feed-forward method for sparse view synthesis that solves the problem of rendering novel views under varying camera baseline settings, including both small and large baselines [S1]. It differs from prior radiance field methods by constructing a **target view frustum volume** aligned with the target camera rather than a reference input view, and by using a **3D context-aware convolutional decoder** instead of independent ray-based rendering [S1]. This approach effectively aggregates multi-view information even when overlap between input and target views is small, a common failure mode for reference-volume methods in large baseline scenarios [S1].

## How it works
MuRF is an encoder-decoder architecture. The encoder extracts multi-view features from input images. The decoder constructs a volume aligned with the target view's frustum, samples features and colors into this volume, and regresses a radiance field using a convolutional network. The final image is rendered via volumetric rendering [S1].

### Inputs and Outputs
*   **Inputs:** A set of $K$ input images $\{I_k\}_{k=1}^K$ with known camera poses. A target camera pose for the novel view.
*   **Outputs:** A rendered target image of resolution $H \times W$ and color $\mathbf{c} \in \mathbb{R}^3$ [S1].

### Data Structures and Layouts
1.  **Multi-scale Features $\{F_k\}$:** Extracted from each input image $I_k$. The 2D CNN produces features at resolutions $1/2$, $1/4$, and $1/8$ of the original image size [S1].
2.  **Target View Frustum Volume $z$:** A 4D tensor representing the discretized 3D space aligned with the target view.
    *   **Dimensions:** $8 \times 8 \times D \times C$ [S1].
    *   **Spatial Dimensions:** $8 \times 8$ represents the spatially subsampled resolution of the target image (original $H \times W$ divided by 8) [S1].
    *   **Depth Dimension:** $D$ is the number of equidistant points sampled on each ray within the frustum [S1].
    *   **Channel Dimension:** $C$ is the aggregated channel dimension containing concatenated sampled features, colors, and cosine similarities [S1].

### Steps

1.  **Multi-View Feature Extraction:**
    For each input image $I_k$, extract features using a weight-sharing 2D CNN followed by a joint multi-view Transformer [S1].
    *   The CNN consists of 6 residual blocks [12]. A stride-2 convolutional layer is applied every 2 residual blocks, yielding features at $1/2$, $1/4$, and $1/8$ resolutions [S1].
    *   The $1/8$ resolution features from all $K$ views are fed into a joint multi-view Transformer. This Transformer extends 2-view cross-attention to $K$ views, allowing efficient processing of multiple input views [S1].
    *   Let $F_k^{(1/8)}$ denote the final multi-view features for image $k$ at $1/8$ resolution [S1].

2.  **Target View Frustum Volume Construction:**
    To render a target image of resolution $H \times W$:
    *   Cast rays from the target camera through the scene.
    *   Perform $8\times$ subsampling in the spatial dimension. This results in an $8 \times 8$ grid of rays [S1].
    *   On each ray, uniformly sample $D$ equidistant points within the target view frustum volume [S1].
    *   For each sampled 3D point, sample feature and color information from the input images $\{I_k\}$ and the extracted feature maps $\{F_k^{(1/8)}\}$ [S1].
    *   Compute the cosine similarity between the sampled features from different input views to provide multi-view consistency cues [S1].
    *   Concatenate the sampled colors, sampled features, and computed cosine similarities to form the volume elements $z$ [S1]. The resulting volume has dimensions $8 \times 8 \times D \times C$ [S1].

3.  **Radiance Field Regression:**
    Reconstruct the radiance field (density $\sigma$ and color $\mathbf{c}$) from the low-resolution volume $z$ using a $(2+1)$D CNN decoder [S1].
    *   The $(2+1)$D CNN factorizes the 3D $3\times3\times3$ convolution into:
        *   A 2D $3\times3\times1$ convolution on the spatial dimensions.
        *   A 1D $1\times1\times3$ convolution on the depth dimension [S1].
    *   This produces a low-resolution radiance field [S1].

4.  **Upsampling:**
    Obtain the full-resolution radiance field by applying a lightweight $8\times$ upsampler to the output of the $(2+1)$D CNN [S1]. The upsampler operates on the low-resolution output to restore the $H \times W$ spatial resolution [S1].

5.  **Volumetric Rendering:**
    Render the target image using standard volumetric rendering [18] on the full-resolution radiance field. The color $\hat{\mathbf{c}}(r)$ for a ray $r$ is computed as:
    $$
    \hat{\mathbf{c}}(r) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i
    $$
    where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance, $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ is the opacity, $\sigma_i$ is the volume density, $\mathbf{c}_i$ is the color, and $\delta_i$ is the distance between samples [S1, S6].

### Parameters
*   **Spatial Subsampling Factor:** $8\times$. Applied in the spatial dimension during volume construction to handle high-resolution images efficiently [S1].
*   **$D$:** Number of equidistant points sampled on each ray. (Not given in the sources.)
*   **$H \times W$:** Resolution of the target image [S1].
*   **$K$:** Number of input views ($K \ge 2$) [S1].

### Edge Cases and Pitfalls
*   **Large Baselines with Reference Volumes:** Using a reference view volume for large baselines causes failure because the overlap between the reference and target view is small, leading to missing information outside the epipolar lines of the reference view [S1]. MuRF avoids this by aligning the volume with the target view [S1].
*   **Spatial Subsampling:** The $8\times$ spatial subsampling is critical for handling high-resolution images efficiently. Without it, the memory footprint would be prohibitive [S1].
*   **Ray Independence:** Unlike ray-based methods (e.g., SRF, IBRNet, GPNR, GNT, MatchNeRF) that render each ray independently, MuRF's volume representation allows for 3D context modeling, which yields better scene structures [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources. However, the $8\times$ spatial subsampling reduces the volume size significantly compared to full-resolution sampling [S1].
*   **Measured Performance:** MuRF achieves state-of-the-art performance across multiple baseline settings on DTU, LLFF, RealEstate10K, and Mip-NeRF 360 datasets [S1]. It outperforms specialized small baseline methods (e.g., ENeRF) and large baseline methods (e.g., AttnRend) [S1].
*   **Scaling:** The method supports different numbers of input views ($K \ge 2$) and generalizes to zero-shot scenarios on Mip-NeRF 360 [S1].
*   **Strengths:** Effective for both small and large baselines; leverages 3D context for better scene structure; efficient handling of high-resolution images via subsampling [S1].
*   **Limitations:** Requires known camera poses for input and target views [S1]. The method is feed-forward, so it does not optimize for a specific scene but rather learns a generalizable representation [S1].

## Background
MuRF (Multi-Baseline Radiance Fields) was proposed by Haofei Xu et al. from ETH Zurich, University of Tübingen, Monash University, Shanghai Jiao Tong University, and Microsoft [S1]. The paper was presented at CVPR 2024 [S1]. It addresses the limitations of previous radiance field methods that were specialized for small baselines or relied on reference view volumes, which fail in large baseline scenarios [S1]. The method builds on the principles of differentiable volume rendering and multi-view feature aggregation [S1].
