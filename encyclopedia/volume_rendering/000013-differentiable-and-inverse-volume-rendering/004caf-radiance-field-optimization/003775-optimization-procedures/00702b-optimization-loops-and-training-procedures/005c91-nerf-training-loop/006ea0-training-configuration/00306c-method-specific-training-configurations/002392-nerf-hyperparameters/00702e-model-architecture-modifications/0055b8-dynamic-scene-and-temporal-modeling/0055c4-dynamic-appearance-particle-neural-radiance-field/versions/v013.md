# Dynamic Appearance Particle Neural Radiance Field

Also called: Dynamic Appearance Particle NeRF, Lagrangian dynamic model in NeRF

## Overview
Dynamic Appearance Particle Neural Radiance Field is a method for novel view synthesis in dynamic scenes using monocular video input [S1]. It solves the problem of modeling temporal dynamics without requiring multi-view data or prior geometric knowledge of moving objects [S1]. It differs from ParticleNeRF by applying particle-based representation only to dynamic elements while keeping a static grid for the background, and by supporting single-camera input rather than requiring multiple views per time frame [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Monocular video data (one camera view at each time frame $t$).
*   **Output:** Rendered pixel color $C(\mathbf{r}, t)$ for any ray $\mathbf{r}$ and time $t$.

**Data Structures:**
The method uses a hybrid representation defined by the superposition equation (Eq. 3 in [S1]):
$$V(\mathbf{x}, t) := (1 - w_t(\mathbf{x}))V_s(\mathbf{x}) + w_t(\mathbf{x})V_{td}(\mathbf{x})$$
*   $V_s(\mathbf{x})$: Static field component. Uses a time-independent grid-based model (canonical feature field) [S1].
*   $V_{td}(\mathbf{x})$: Dynamic field component. Represented as an ensemble of particles [S1].
*   $w_t(\mathbf{x})$: Weight function. Takes value 1 if the dynamic field is effective at $(\mathbf{x}, t)$ and 0 otherwise [S1]. The support of the dynamic field is implied by the particle representation [S1].

**Notation Convention:**
Time $t$ is denoted in subscripts on the right-hand side (e.g., $V_{td}$) to clarify that the dynamic component consists of an ensemble of particles, where the time argument is fixed for the instantaneous status construction [S1].

**Rendering Formula:**
The pixel color $C(\mathbf{r}, t)$ at time $t$ is computed by casting a ray $\mathbf{r}(s) = \mathbf{o} + s\mathbf{d}$ from camera center $\mathbf{o}$ to the pixel, integrating along the ray from near bound $s_n$ to far bound $s_f$ [S1]:
$$C(\mathbf{r}, t) = \int_{s_n}^{s_f} T(s)\sigma(\mathbf{r}(s), t)c(\mathbf{r}(s), \mathbf{d}, t)ds$$
where $T(s) = \exp\left(-\int_{s_n}^{s} \sigma(\mathbf{r}(s'), t)ds'\right)$ is the accumulated transmittance, $\sigma(\cdot)$ is volume density, and $c(\cdot)$ is emitted radiance [S1].

**Particle-Based Dynamic Model Formulation:**
The dynamic field $V_{td}$ is formulated as a convolution with a Dirac function to integrate over finite volumes [S1]:
$$V_{td}(\mathbf{x}) = (V_{td} * \delta)(\mathbf{x}) = \int V_{td}(\mathbf{x}')\delta(\mathbf{x} - \mathbf{x}')d\nu(\mathbf{x}')$$
where $\delta(\cdot)$ is the Dirac function ($\delta(\mathbf{r}) = 0$ for $\mathbf{r} \neq 0$ and $\int \delta(\mathbf{r})d\nu = 1$) and $\nu(\cdot)$ is the volume integration variable [S1].

**Quantization:**
To implement the model, the Dirac function $\delta$ is replaced with a kernel $W$ with finite support [S1]:
*   $W(\mathbf{x}) = 0$ when $\|\mathbf{x}\|$ exceeds a small radius.
*   $\int W(\mathbf{x})d\nu(\mathbf{x}) = 1$ [S1].
This finite-width kernel approximation leads to a quantization of the field [S1].

**Implementation Steps:**
1.  Initialize a static grid-based field $V_s(\mathbf{x})$ for the background [S1].
2.  Initialize a set of particles representing the dynamic elements $V_{td}$ [S1].
3.  For each time frame $t$:
    a. Update particle positions/attributes using a particle motion network (details of the network architecture are not specified in the provided notes, but the method employs it to continuously model dynamics) [S1].
    b. For each ray $\mathbf{r}$ and sample point $\mathbf{x}$ along the ray:
        i. Determine $w_t(\mathbf{x})$ based on whether $\mathbf{x}$ falls within the support of the dynamic particles [S1].
        ii. Query $V_s(\mathbf{x})$ using linear interpolation on the grid [S1].
        iii. Query $V_{td}(\mathbf{x})$ by convolving the particle features with the kernel $W$ (replacing $\delta$) [S1].
        iv. Compute $V(\mathbf{x}, t)$ using the superposition formula [S1].
        v. Extract density $\sigma$ and radiance $c$ from $V(\mathbf{x}, t)$ [S1].
    c. Render $C(\mathbf{r}, t)$ using volume rendering integration [S1].
4.  Optimize parameters (static grid, particle motion network, particle attributes) using monocular video data [S1].

**Parameters:**
*   Kernel support radius: "small radius" [S1].
*   $w_t(\mathbf{x})$: Binary weight (0 or 1) [S1].

**Edge Cases and Pitfalls:**
*   The method assumes the dynamic elements can be effectively separated from the static background via the weight $w_t(\mathbf{x})$ [S1].
*   Precision issues may arise if the kernel support radius is not chosen appropriately relative to particle density [S1].

## Subtopics

### ParticleNeRF
Encodes the entire scene with particles and uses radius nearest neighbor searching; requires 20 camera views per time frame [S1].

### InstantNGP
An alternative framework into which the Lagrangian representation can be integrated [S1].

## Operating characteristics
*   **Data Requirements:** Monocular video data (one camera view at each time frame) [S1].
*   **Comparison to ParticleNeRF:** Does not require multi-view data (20 views) [S1]. Uses grid-based field with linear interpolation for efficient querying instead of radius nearest neighbor searching [S1].
*   **Architecture:** Not tightly coupled to a specific architecture; can be integrated into frameworks like InstantNGP [S1].
*   **Performance:** Not given in the sources.
*   **Complexity:** Not given in the sources.

## Background
The method was proposed in "Dynamic Appearance Particle Neural Radiance Field" [S1]. It addresses limitations of concurrent works that rely on specific physical models or pre-extracted initial shapes [S1]. It builds on the canonical feature field framework [S1].
