# Training Setup and Baselines


## Overview
This family defines the specific hyperparameter configurations, data handling strategies, and baseline architectures used to train neural radiance fields and related implicit representations. It addresses the problem of stabilizing optimization, managing memory constraints, and establishing performance benchmarks for novel view synthesis. It differs from sibling articles like [Learning Rate Scheduling](2701-learning-rate-scheduling.md) or [Mixed Precision Training](2766-mixed-precision-training.md) by focusing on the structural setup of the training pipeline (e.g., input representations, GAN-specific stabilizers, or baseline network architectures) rather than just the optimization dynamics or precision formats.

## Shared principles
The articles in this family share the goal of defining a reproducible "recipe" for training a specific neural rendering method. They typically specify:
1.  **Input Representation:** How 3D positions, directions, or features are encoded (e.g., positional encoding depth, feature vector dimensions, or pre-computed volumes).
2.  **Sampling Strategy:** The number of rays per batch, samples per ray, and whether hierarchical or stratified sampling is used.
3.  **Loss Functions:** The primary photometric loss (e.g., MSE) and any specific regularization terms (e.g., R1, Eikonal, or tone-mapping adjustments).
4.  **Optimizer Settings:** Base learning rates, decay schedules, and specific optimizer variants (e.g., Adam parameters).
5.  **Baseline Comparisons:** Establishing upper-bound or reference models (like NeRF-GT or NLR) to evaluate the proposed method's efficiency or quality.

## Subtopics

### [NeRF-GT Baseline Training Setup](11349-nerf-gt-baseline-training-setup.md)
Establishes a reference configuration for standard NeRF using ground-truth (GT) data, typically HDR renders or consistently exposed LDR views. It serves as an upper-bound reference for HDR synthesis methods, training directly on HDR inputs rather than recovering HDR from multiple LDR exposures. Unlike generic NeRF setups, it employs tone-mapping for loss computation to handle high dynamic range. Key parameters include a batch size of 2,048 rays, 64 coarse samples, and 128 fine samples per ray, trained for 200,000 iterations at 800×600 resolution. A key pitfall is that training directly on HDR views can fail to encode all scene areas well due to the vast intensity range, even with tone-mapped losses.

### [StyleGAN2 Training Configuration](12972-stylegan2-training-configuration.md)
Adapts the StyleGAN2 pipeline for 3D-aware image synthesis (e.g., in VoxGRAF). It solves stability issues in GAN training for high-resolution 3D representations by leveraging 2D GAN stabilization techniques. It differs from standard NeRF setups by using equalized learning rates, minibatch standard deviation, and R1 regularization, while omitting path regularization and style-mixing. Key parameters include an R1 regularization strength ($\gamma$) of 1 applied every 4 minibatches. For small datasets, fine-tuning a generator pretrained on FFHQ is required using specific representation dimensions ($R_I=128, R_G=32$).

### [NeRF Training Setup](13271-nerf-training-setup.md)
Describes the configuration for NeRF-based models using Nerfstudio, NerfAcc, and Instant-NGP for static scenes. It details architectural modifications such as replacing standard positional encoding of 3D positions with sampled feature vectors from a pre-computed volume $V_s$. The method uses a 64-dimensional feature vector $\mathbf{v}_s$ obtained via trilinear sampling, with no positional encoding applied to $\mathbf{v}_s$. Direction vectors $\mathbf{d}$ are encoded using positional encoding with depth $L=4$. The setup uses a batch size of 1,024 rays, 64 coarse samples, and 64 fine samples. It is optimized for static environments like laparoscopic videos, excluding specific regions (e.g., surgical tools) to prevent artifacts.

### [NLR Baseline](15254-nlr-baseline.md)
NLR is a neural implicit representation method for novel view synthesis that models the light field using an MLP to predict density and color. It serves as a baseline for comparing training efficiency and rendering speed against NeRF and IDR. Unlike explicit geometry methods, NLR learns a continuous volumetric representation directly from images. It requires more iterations to converge, leading to longer total training times, but offers reasonable per-iteration costs (2.21 seconds/iteration) and fast rendering (0.025 seconds/frame) at 800×600 resolution.

### NeuralVDB Hyperparameter Configuration
A minor variant focusing on sparse volume representation using hierarchical neural networks.
*   **Step:** Uses either $2^{16}$ random samples per epoch or resamples a subset of input voxels at fixed intervals (100 or 500) and draws $2^{12}$ batches per epoch. Resampling is used when fine details with thin structures are critical [S1, unofficial].
*   **Parameter:** Subdomain size must be a multiple of 512; too large wastes compute on empty subdomains, while too small increases dispatch overhead and causes dominant overlapping halo regions [S1, unofficial]. Level-1 networks use half the width of level-0 networks (default width 128, depth 3; use 4 layers for more detail). Optimizer is Adam with LR 0.001, decaying by 0.975 every 100 epochs (no resampling) or 0.75 every 1,000 epochs (with resampling). Max epochs: 2,500 for non-resampled [S1, unofficial].
*   **Comparison:** Dense grid training produces the highest noise. Block grid (dense leaf nodes without active masks) reduces noise but shows fog artifacts. Sparse VDB with active voxel masks yields the best visual quality and low noise [S1, unofficial].

### Neural Codebook Training Configuration
A minor variant for compact real-time radiance fields.
*   **Step:** Multiplies learning rate by 0.3 for every 5,000 iterations. Casts the trained Neural Codebook (NCB) to float16 after training [S2].
*   **Parameter:** Optimizer is Adam with $\beta_1 = 0.9$ and $\beta_2 = 0.999$. Weight decay is $1e-5$. Initial learning rate is $5e-3$. Total training iterations: 20,000. Batch size: 100,000 voxels [S2].

## Background
The concept of training baselines for neural rendering emerged with the original NeRF paper [S1, unofficial], which established standard hyperparameters (e.g., 64/128 samples, Adam optimizer) as a reference point. Subsequent works like NeuralVDB [S1, unofficial] and Neural Codebook [S2] introduced specific optimizations for sparse volumes and compact representations, requiring tailored training setups to handle memory and sparsity. StyleGAN2 adaptations [S1, unofficial] brought GAN-specific stabilization techniques to 3D-aware synthesis. The NLR method [S1, unofficial] provides a comparative baseline for neural light field representations. These configurations are critical for reproducible research in differentiable volume rendering.
