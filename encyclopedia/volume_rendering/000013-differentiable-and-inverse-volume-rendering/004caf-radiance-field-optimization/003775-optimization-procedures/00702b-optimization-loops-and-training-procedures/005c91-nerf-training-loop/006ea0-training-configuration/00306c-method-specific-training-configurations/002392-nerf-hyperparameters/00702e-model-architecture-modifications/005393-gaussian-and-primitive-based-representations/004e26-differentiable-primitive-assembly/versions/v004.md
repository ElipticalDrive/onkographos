# Differentiable Primitive Assembly

Also called: DPA-Net Primitive Assembly, Quadric Primitive Assembly

## Overview
Differentiable Primitive Assembly (DPA) models 3D shapes as an assembly of learnable quadric primitives, utilizing differentiable intersection and union operations to construct the final geometry [S1]. It solves the problem of 3D shape abstraction from sparse views by replacing global continuous functions with a discrete set of primitives, trained exclusively with image-space losses without requiring 3D ground truth supervision [S1]. Unlike Gaussian Splatting which projects 2D ellipsoids, DPA evaluates implicit signed distances in 3D space and combines them via soft boolean operations, allowing for complex topologies like holes and thin structures [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Fused image features $f$ (from multiple views), query points $\mathbf{x}_i$ sampled along camera rays.
*   **Outputs:** Primitive parameters, selection matrix, occupancy field, and rendered pixel colors $C_b$ and masks $M_c$.

**Data Structures:**
1.  **Primitive Parameters Matrix $\mathbf{P}$:** Shape $\mathbb{R}^{P \times 7}$. Each row $p$ contains $(a, b, c, d, e, f, g)$. The first three parameters $(a, b, c)$ are constrained to be non-negative to ensure convexity [S1].
2.  **Selection Matrix $\mathbf{T}$:** Shape $\mathbb{R}^{P \times C}$. Ideally binary, but takes floating-point values in $[0, 1]$ during training. Each column $c$ selects a subset of primitives to form one convex shape [S1].
3.  **Weight Vector $\mathbf{w}$:** Shape $\mathbb{R}^{C}$. Learnable weights for the soft union operation, initialized close to 1 [S1].

**Parameters:**
*   $P = 4,096$: Number of primitives [S1].
*   $C = 256$: Number of convexes [S1].
*   Optimizer: Adam, learning rate $0.0001$ [S1].
*   Batch size: 4 object instances [S1].

**Steps:**

1.  **Primitive Parameterization:**
    Define a quadric primitive equation for a query point $(x, y, z)$:
    $$ |a|x^2 + |b|y^2 + |c|z^2 + dx + ey + fz + g = 0 $$
    where $(a, b, c, d, e, f, g)$ are the parameters from matrix $\mathbf{P}$ [S1].

2.  **Distance Estimation:**
    Construct a query matrix $\mathbf{Q}$ where the $i$-th row is $(x_i^2, y_i^2, z_i^2, x_i, y_i, z_i, 1)$ for $N$ query points [S1].
    Compute the distance matrix $\mathbf{D} = \mathbf{Q}\mathbf{P}^\top$. The entry $D_{i,p}$ is the approximate signed distance between point $i$ and primitive $p$. $D_{i,p} < 0$ indicates the point is inside the primitive [S1].

3.  **Primitive Intersection (Convex Construction):**
    Compute the convex occupancy matrix $\mathbf{O} = \text{ReLU}(\mathbf{D})\mathbf{T}$.
    $$ O_{i,c} = \sum_{p=1}^P \text{ReLU}(D_{i,p}) T_{p,c} $$
    $O_{i,c} = 0$ if point $i$ is inside convex $c$, and $O_{i,c} > 0$ if outside [S1].

4.  **Union of Convexes (Occupancy):**
    Compute the exact occupancy $\mathbf{a}^*$ using min-pooling (union):
    $$ a^*_i = \min_{1 \leq c \leq C} O_{i,c} $$
    $$ a^*_i = \begin{cases} 0 & \text{inside} \\ > 0 & \text{outside} \end{cases} $$
    For gradient flow during training, use the soft approximation $\mathbf{a}^+$:
    $$ a^+_i = \mathcal{L} \left( \sum_{c=1}^C w_c \mathcal{L} (1 - O_{i,c}) \right) $$
    where $\mathcal{L}(\cdot)$ clips input to $[0, 1]$. $a^+_i \approx 1$ if inside, $< 1$ if outside [S1].

5.  **Differentiable Rendering:**
    For each pixel, accumulate color and mask along the ray with $R$ sampled points:
    $$ C_b = \sum_{i=1}^R t_i \alpha_i c_{b,i} $$
    $$ M_c = \sum_{i \in \Omega} t_i \alpha_i $$
    where $t_i = \prod_{k=1}^{i-1} (1 - \alpha_k)$ is the transmittance, $\alpha_i$ is the opacity (derived from occupancy), and $c_{b,i}$ is the color predicted by an MLP [S1].

6.  **Loss Computation:**
    *   **Photo/Mask Loss ($\mathcal{L}_{ph}$):**
        $$ \mathcal{L}_{ph} = \frac{1}{B} \sum_{j=1}^B ||\hat{C}_j - C_j||_2^2 + \frac{1}{B} \sum_{j=1}^B ||\hat{M}_j - M_j||_2^2 $$
        where $B$ is the number of pixels in the batch [S1].
    *   **Selection Matrix Loss ($\mathcal{L}_T$):**
        $$ \mathcal{L}_T = \sum_{i,j} \max(-T_{i,j}, 0) + \max(T_{i,j} - 1, 0) $$
        Constrains $\mathbf{T}$ entries to $[0, 1]$ [S1].
    *   **Weight Loss ($\mathcal{L}_w$):**
        $$ \mathcal{L}_w = \sum_j |w_j - 1| $$
        Keeps weights close to 1 [S1].
    *   **Overlapping Loss ($\mathcal{L}_{over}$):**
        $$ h_i = \sum_{c=1}^C \exp(-10 O_{i,c}) $$
        $$ \mathcal{L}_{over} = \sum_{i \in \Omega} \max(h_i, 1.9) $$
        where $\Omega$ is the set of points inside the shape ($a^*_i < 0.01$). Penalizes excessive overlap between convexes [S1].

7.  **Training Phases:**
    *   **Pretraining:** Minimize $\mathcal{L} = \mathcal{L}_{ph} + \mathcal{L}_T + \mathcal{L}_w$. Opacity $\alpha = a^+$. Optimize network, $\mathbf{T}$, and $\mathbf{w}$ [S1].
    *   **Test-Time Adaptation (TTA) Phase 1:** Use test images as GT. Loss $\mathcal{L}_{ph} + \mathcal{L}_T + \mathcal{L}_w$. Opacity $\alpha = a^+$. Optimize network, $\mathbf{T}$, $\mathbf{w}$ [S1].
    *   **TTA Phase 2:** Use exact occupancy $a^*$. Loss $\mathcal{L}_{ph} + \mathcal{L}_T$. Opacity $\alpha = \exp(-10a^*)$. Optimize network, $\mathbf{T}$ [S1].
    *   **TTA Phase 3:** Binarize $\mathbf{T}$ with threshold 0.01 and freeze it. Loss $\mathcal{L}_{ph} + \mathcal{L}_{over}$. Opacity $\alpha = \exp(-10a^*)$. Optimize network only [S1].

8.  **Silhouette-Aware Sampling:**
    Sample 256 pixels randomly across raster space and 1,000 pixels around object contours. Contours are obtained by morphological closing on the mask image plus Gaussian noise [S1].

9.  **Primitive Dropout (Phase 3):**
    Iterate through each row $p$ of binary $\mathbf{T}$. Set row $p$ to zero, compute new occupancy $b^*$, and quantify variation:
    $$ v = K \sum_{i=1}^P \mathbb{1}(\text{XOR}(b^*_i < 0.1, a^*_i < 0.1)) $$
    where $K = 40,960$ is the number of sampled points. If $v \approx 0$, keep row zero; else restore. Apply every 400 iterations [S1].

```python
import torch
import torch.nn.functional as F

def compute_quadric_distance(query_points, primitive_params):
    """
    query_points: (N, 3) tensor of (x, y, z)
    primitive_params: (P, 7) tensor of (a, b, c, d, e, f, g)
    Returns: (N, P) distance matrix D
    """
    # Q: (N, 7)
    x, y, z = query_points[:, 0], query_points[:, 1], query_points[:, 2]
    Q = torch.stack([x**2, y**2, z**2, x, y, z, torch.ones_like(x)], dim=1)
    
    # P: (P, 7)
    # D = Q @ P.T -> (N, P)
    D = torch.matmul(Q, primitive_params.T)
    return D

def compute_convex_occupancy(D, T):
    """
    D: (N, P) distance matrix
    T: (P, C) selection matrix
    Returns: (N, C) convex occupancy O
    """
    # ReLU(D) -> (N, P)
    relu_D = F.relu(D)
    # O = ReLU(D) @ T -> (N, C)
    O = torch.matmul(relu_D, T)
    return O

def compute_exact_occupancy(O):
    """
    O: (N, C) convex occupancy
    Returns: (N,) exact occupancy a_star
    """
    # a_star = min(O) over C
    a_star = torch.min(O, dim=1)[0]
    return a_star

def compute_soft_occupancy(O, w):
    """
    O: (N, C) convex occupancy
    w: (C,) weight vector
    Returns: (N,) soft occupancy a_plus
    """
    # L(1 - O) clips to [0, 1]
    clipped = torch.clamp(1 - O, 0, 1)
    # weighted sum
    weighted_sum = torch.sum(w * clipped, dim=1)
    # final clip
    a_plus = torch.clamp(weighted_sum, 0, 1)
    return a_plus

def render_ray(points_along_ray, colors_along_ray, occupancy_values, opacity_func):
    """
    points_along_ray: (R,) indices or not needed if sorted by depth
    colors_along_ray: (R, 3)
    occupancy_values: (R,) alpha input
    opacity_func: function to convert occupancy to alpha
    Returns: color, mask, transmittance history
    """
    alpha = opacity_func(occupancy_values)
    # Clamp alpha to avoid NaN gradients
    alpha = torch.clamp(alpha, 0, 0.999)
    
    transmittance = torch.ones_like(alpha)
    for i in range(1, len(alpha)):
        transmittance[i] = transmittance[i-1] * (1 - alpha[i-1])
        
    # Color accumulation
    # C = sum(t_i * alpha_i * c_i)
    # Note: t_i in formula is product of (1-alpha) for k < i
    # In loop above, transmittance[i] is t_i
    weights = transmittance * alpha
    color = torch.sum(weights.unsqueeze(1) * colors_along_ray, dim=0)
    
    # Mask accumulation
    mask = torch.sum(weights)
    
    return color, mask

def loss_ph(pred_color, gt_color, pred_mask, gt_mask):
    return F.mse_loss(pred_color, gt_color) + F.mse_loss(pred_mask, gt_mask)

def loss_T(T):
    # max(-T, 0) + max(T-1, 0)
    return torch.sum(torch.clamp(-T, min=0)) + torch.sum(torch.clamp(T - 1, min=0))

def loss_overlapping(O, a_star):
    # Omega: points inside shape (a_star < 0.01)
    inside_mask = a_star < 0.01
    if not torch.any(inside_mask):
        return torch.tensor(0.0)
    
    # h_i = sum(exp(-10 * O_i,c))
    h = torch.sum(torch.exp(-10 * O), dim=1)
    
    # Only penalize points inside shape
    h_inside = h[inside_mask]
    
    # max(h_i, 1.9)
    penalty = torch.clamp(h_inside - 1.9, min=0)
    return torch.sum(penalty)
```

## Operating characteristics
*   **Time Complexity:** Dominated by the matrix multiplications $\mathbf{Q}\mathbf{P}^\top$ ($O(N \cdot P)$) and $\text{ReLU}(\mathbf{D})\mathbf{T}$ ($O(N \cdot P \cdot C)$). With $N$ query points, $P=4096$, and $C=256$, this is computationally heavier than simple Gaussian splatting per point but allows for complex CSG-like structures.
*   **Memory Complexity:** Requires storing $\mathbf{P}$ ($P \times 7$), $\mathbf{T}$ ($P \times C$), and intermediate matrices $\mathbf{D}$ ($N \times P$) and $\mathbf{O}$ ($N \times C$) during forward pass.
*   **Strengths:** Capable of representing complex topologies (holes, thin structures) better than simple point clouds or Gaussians. Differentiable CSG operations allow for end-to-end training from images only.
*   **Limitations:** Requires careful tuning of the multi-phase test-time adaptation. The soft approximation of occupancy can lead to "blobby" artifacts if not regularized. Redundant primitives may persist without dropout.
*   **When to use:** When sparse-view 3D reconstruction requires explicit geometric abstraction with complex topology, and 3D ground truth is unavailable.
*   **When not to use:** For real-time rendering of simple scenes where Gaussian Splatting is sufficient, or when dense multi-view input is available and neural radiance fields are preferred.

## Background
DPA was introduced in the DPA-Net paper, inspired by CAPRI-Net and other works on differentiable CSG [S1]. It addresses the limitations of NeRF variants in abstracting complex 3D structures by explicitly modeling primitives. The method was developed to improve generalization to novel shapes via test-time adaptation [S1].
