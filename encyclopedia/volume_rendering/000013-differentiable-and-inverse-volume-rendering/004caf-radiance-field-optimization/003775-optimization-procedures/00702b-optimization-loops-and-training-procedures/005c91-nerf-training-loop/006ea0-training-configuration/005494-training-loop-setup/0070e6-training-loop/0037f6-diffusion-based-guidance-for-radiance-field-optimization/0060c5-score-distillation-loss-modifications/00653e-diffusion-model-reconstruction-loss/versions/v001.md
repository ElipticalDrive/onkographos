# Diffusion Model Reconstruction Loss

Also called: Modified LSDS with DM noise comparison, Unsuccessful Experiment: Diffusion Model Reconstruction Loss

## Overview
This method attempts to enforce fidelity to a specific input image during radiance field optimization by comparing the noise predictions of a frozen diffusion model for a noisy rendered image against the noise predictions for a noisy version of the input image itself. It serves as a perceptual reconstruction constraint, aiming to align the generated content with the input's structure and style, distinct from standard pixel-level reconstruction losses. It is distinguished from sibling methods like [Interval Score Matching](8995-interval-score-matching.md) and [Renoised Score Distillation (RSD)](16424-renoised-score-distillation-rsd.md) by its direct comparison of two noise estimates (rendered vs. input) rather than comparing a noise estimate to the added noise or using re-noising schedules.

## How it works
The method operates within the differentiable rendering loop described in [Score Distillation Loss Modifications](18224-score-distillation-loss-modifications.md). It modifies the gradient signal by introducing a second branch for the input image.

**Inputs and Outputs:**
*   **Input:** Current radiance field parameters $\Theta$, camera pose $p^*$ corresponding to the input image viewpoint, the input image $I_{in}$, and a frozen diffusion model $\epsilon_\theta$.
*   **Output:** Gradient signal $\nabla_\Theta L$ used to update $\Theta$.

**Data Structures:**
*   **Rendered Image $I_{render}$:** Output of the differentiable renderer $R(\Theta, p^*)$.
*   **Input Image $I_{in}$:** The reference image to match.
*   **Noisy Latents:** $z_t^{render}$ and $z_t^{in}$, obtained by adding noise to $I_{render}$ and $I_{in}$ respectively at timestep $t$.

**Steps:**
1.  Render an image $I_{render}$ from the current radiance field $\Theta$ at the target camera pose $p^*$.
2.  Sample a timestep $t$ from the diffusion schedule.
3.  Sample Gaussian noise $\epsilon_{render} \sim \mathcal{N}(0, I)$.
4.  Compute the noisy rendered latent: $z_t^{render} = \bar{\alpha}_t I_{render} + \sqrt{1-\bar{\alpha}_t} \epsilon_{render}$.
5.  Sample the *same* noise realization $\epsilon_{render}$ (or an independent one, depending on implementation, but typically independent for the input branch to maintain stochasticity) $\epsilon_{in} \sim \mathcal{N}(0, I)$.
6.  Compute the noisy input latent: $z_t^{in} = \bar{\alpha}_t I_{in} + \sqrt{1-\bar{\alpha}_t} \epsilon_{in}$.
7.  Query the frozen diffusion model $\epsilon_\theta$ to predict the noise for the rendered branch: $\hat{\epsilon}_{render} = \epsilon_\theta(z_t^{render}, t, \text{prompt})$.
8.  Query the frozen diffusion model $\epsilon_\theta$ to predict the noise for the input branch: $\hat{\epsilon}_{in} = \epsilon_\theta(z_t^{in}, t, \text{prompt})$.
9.  Compute the loss as the squared difference between the two predicted noise vectors.
10. Backpropagate the gradient through the diffusion model's noise prediction for the rendered branch to update $\Theta$.

**Formula:**
The loss function is defined as:
$$ L = \mathbb{E}_{t, \epsilon_{render}, \epsilon_{in}} \left[ w(t) \| \epsilon_\theta(z_t^{render}, t) - \epsilon_\theta(z_t^{in}, t) \|_2^2 \right] $$
where:
*   $z_t^{render}$ is the noisy latent of the rendered image.
*   $z_t^{in}$ is the noisy latent of the input image.
*   $\epsilon_\theta(\cdot, t)$ is the noise predictor of the frozen diffusion model at timestep $t$.
*   $w(t)$ is the weighting function (typically derived from the diffusion schedule, e.g., $1/\sigma_t^2$).

**Parameters:**
*   **Diffusion Model $\epsilon_\theta$:** A pre-trained text-to-image diffusion model (e.g., Stable Diffusion).
*   **Prompt:** The text prompt used to condition the diffusion model.
*   **Timestep $t$:** Sampled from the diffusion schedule.

**Pitfalls:**
*   **Color/Texture Mismatch:** The method may reconstruct the input image to a certain degree but fail to match exact input image colors or textures [S1].
*   **Gradient Conflict:** Comparing two noisy predictions may introduce conflicting gradients if the diffusion model's prior does not align well with the specific input instance.

**Pseudocode:**
```python
def diffusion_model_reconstruction_loss(
    radiance_field: RadianceField,
    input_image: Tensor,
    camera_pose: CameraPose,
    diffusion_model: DiffusionModel,
    prompt: str,
    timestep: int,
    weighting_fn: Callable[[int], float]
) -> Tensor:
    """
    Computes the Diffusion Model Reconstruction Loss.
    
    Args:
        radiance_field: The radiance field parameters Theta.
        input_image: The reference input image I_in.
        camera_pose: The camera pose p* for rendering.
        diffusion_model: The frozen diffusion model epsilon_theta.
        prompt: The conditioning text prompt.
        timestep: The diffusion timestep t.
        weighting_fn: Function w(t) returning the weight for timestep t.
        
    Returns:
        The scalar loss value L.
    """
    # Step 1: Render the image from the current radiance field
    rendered_image = radiance_field.render(camera_pose)
    
    # Step 2: Sample noise for the rendered image
    epsilon_render = torch.randn_like(rendered_image)
    
    # Step 3: Compute noisy latent for rendered image
    # Assuming alpha_bar and sigma are precomputed for timestep t
    z_t_render = alpha_bar[t] * rendered_image + sqrt(1 - alpha_bar[t]) * epsilon_render
    
    # Step 4: Sample noise for the input image
    epsilon_in = torch.randn_like(input_image)
    
    # Step 5: Compute noisy latent for input image
    z_t_in = alpha_bar[t] * input_image + sqrt(1 - alpha_bar[t]) * epsilon_in
    
    # Step 6: Predict noise for rendered branch
    epsilon_pred_render = diffusion_model.predict_noise(z_t_render, timestep, prompt)
    
    # Step 7: Predict noise for input branch
    epsilon_pred_in = diffusion_model.predict_noise(z_t_in, timestep, prompt)
    
    # Step 8: Compute loss
    loss = weighting_fn(timestep) * torch.mean((epsilon_pred_render - epsilon_pred_in) ** 2)
    
    return loss
```

## Subtopics

### Reference View Score Distillation
A loss function applied during NeuS mesh reconstruction to ensure consistency between the reconstructed geometry's rendering at the input viewpoint and the original input image, using score distillation instead of pixel-level MSE [S2]. It adds small noise (Stable Diffusion scheduler $t=200$) to NeRF render images and conducts denoising, then optimizes NeuS parameters $\Theta$ by adding $\mathcal{L}_{RV}$ to the original photometric loss [S2]. The formula is:
$$ \mathcal{L}_{RV} = \mathbb{E}_{\mathbf{t}, \epsilon} \left[ w(\mathbf{t}) \| \epsilon_{\psi}(\mathbf{z}_{\mathbf{t}}^*, \emptyset) - \epsilon_{\psi}(\mathbf{y}_{\mathbf{t}}, \emptyset) \|_2^2 \right] $$
where $\mathbf{z}_t^* = R(\Theta, p^*)$ is the noisy latent of the NeuS rendering at input camera pose $p^*$, $\mathbf{y}_t$ is the noisy latent of the input view image, $\epsilon_\psi$ is the Stable Diffusion noise predictor, and $w(t)$ is the weighting function [S2]. RV uses a patch-aware noise/latent-level approach emphasizing perceptual quality, whereas MSE loss operates directly at the pixel-level [S2].

## Operating characteristics
*   **Time Complexity:** Requires two forward passes through the diffusion model per timestep (one for the rendered image, one for the input image), doubling the diffusion model inference cost compared to standard SDS.
*   **Memory Complexity:** Requires storing the noisy latents for both the rendered and input images.
*   **Performance:** The method was found to be unsuccessful in matching exact input image colors or textures, leading to its classification as an unsuccessful experiment in the context of RealFusion [S1].
*   **Strengths:** Provides a perceptual constraint that may help with structural consistency.
*   **Limitations:** Fails to capture fine-grained color and texture details accurately [S1].
*   **When to use:** Potentially useful when structural alignment is more important than photometric fidelity, though standard SDS or pixel-level losses may be more reliable.
*   **When not to use:** When exact color/texture reproduction is required.

## Background
The method was explored as part of the RealFusion project, which focuses on 360° reconstruction of any object from a single image [S1]. It was investigated as a modification of LSDS (Latent Score Distillation) to incorporate input image information directly into the diffusion prior [S1]. The authors found that while it allowed for some reconstruction of the input image, it did not match exact colors or textures, leading to its categorization as a failure case [S1]. A related variant, Reference View Score Distillation, was proposed in the context of NeuS mesh reconstruction to leverage input view information for geometry and texture distillation [S2].
