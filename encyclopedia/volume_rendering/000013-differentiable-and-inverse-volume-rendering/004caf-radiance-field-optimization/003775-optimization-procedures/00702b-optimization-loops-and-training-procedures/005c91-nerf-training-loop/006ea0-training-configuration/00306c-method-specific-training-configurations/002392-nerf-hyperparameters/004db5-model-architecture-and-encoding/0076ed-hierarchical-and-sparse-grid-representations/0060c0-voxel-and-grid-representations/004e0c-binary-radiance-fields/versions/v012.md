# Binary Radiance Fields

Also called: BRF

## Overview
Binary Radiance Fields (BiRF) is a storage-efficient radiance field representation that constrains feature grid parameters to binary values (+1 or -1) to achieve compact storage without post-processing compression [S1]. Unlike methods that compress pre-trained models, BiRF performs binarization during training, utilizing a 2D-3D hybrid multi-resolution architecture to maintain reconstruction quality while reducing storage overhead to less than 0.5 MB for standard scenes [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D coordinate $\mathbf{x} = (x, y, z)$ and viewing direction $\mathbf{d} = (\theta, \phi)$.
*   **Output:** Volume density $\sigma$ and RGB color $\mathbf{c}$.

**Data Structures:**
The feature representation consists of a multi-resolution 2D-3D hybrid grid implemented using hash encoding [S1].
1.  **3D Voxel Grid ($\Phi_{\theta_{xyz}}$):** Contains $L$ resolution levels. Resolutions range from 16 to 1024. Each level stores up to $T_{3D}$ feature vectors.
2.  **2D Plane Grids ($\Phi_{\theta_{xy}}, \Phi_{\theta_{xz}}, \Phi_{\theta_{yz}}$):** Three orthogonal planes. Each contains $M$ resolution levels. Resolutions range from 64 to 512. Each level stores up to $T_{2D}$ feature vectors.
3.  **Feature Values:** All grid parameters are binary, constrained to $\{-1, +1\}$. Each feature vector has dimension $F$.
4.  **MLPs:**
    *   Density MLP: 1 hidden layer, 128 channels, ReLU activation.
    *   Color MLP: 2 hidden layers, 128 channels, ReLU activation.
    *   Directional Encoding: Spherical Harmonics basis functions [S1].

**Parameters:**
*   $L$: Number of 3D grid levels.
*   $M$: Number of 2D grid levels.
*   $T_{3D}$: Max feature vectors per 3D level.
*   $T_{2D}$: Max feature vectors per 2D level.
*   $F$: Feature dimension per level.
*   $\lambda_{\text{sparsity}}$: Sparsity loss weight. Default: $2.0 \times 10^{-5}$ [S1].

**Algorithm Steps:**

1.  **Binarization:**
    Real-valued grid parameters $\theta$ are binarized to $\theta'$ using the sign function:
    $$ \theta' = \text{sign}(\theta) = \begin{cases} +1 & \text{if } \theta \ge 0 \\ -1 & \text{otherwise} \end{cases} $$
    Gradients are propagated using the Straight-Through Estimator (STE). The gradient is passed if $|\theta| \le 1$, otherwise it is zeroed to prevent scale divergence [S1]:
    $$ \frac{\partial L}{\partial \theta} = \frac{\partial L}{\partial \theta'} \cdot \mathbb{I}(|\theta| \le 1) $$

2.  **Feature Encoding:**
    For a query coordinate $\mathbf{x}$:
    *   **3D Features ($f_{xyz}$):** Tri-linearly interpolate binary parameters from the 3D grid across $L$ levels and concatenate:
        $$ f_{xyz} = \bigoplus_{l=1}^{L} \text{interp}(\mathbf{x}, \text{sign}(\Phi^l_{\theta_{xyz}})) $$
    *   **2D Features ($f_{xy}, f_{xz}, f_{yz}$):** Project $\mathbf{x}$ to 2D coordinates ($\mathbf{x}_{xy}=(x,y)$, etc.). Bi-linearly interpolate binary parameters from each 2D grid across $M$ levels and concatenate:
        $$ f_{xy} = \bigoplus_{m=1}^{M} \text{interp}(\mathbf{x}_{xy}, \text{sign}(\Phi^m_{\theta_{xy}})) $$
        Repeat for $f_{xz}$ and $f_{yz}$.
    *   **Concatenation:** Combine all features:
        $$ f = [f_{xyz}, f_{xy}, f_{xz}, f_{yz}] $$

3.  **Density Prediction:**
    Apply sinusoidal positional encoding $\gamma(\mathbf{x})$ to the input coordinate. Feed $\gamma(\mathbf{x})$ and $f$ into the density MLP:
    $$ (\sigma, \mathbf{e}) = \text{MLP}_{\text{density}}(\gamma(\mathbf{x}), f) $$
    where $\mathbf{e}$ is the embedded feature vector.

4.  **Color Prediction:**
    Encode direction $\mathbf{d}$ using spherical harmonics. Feed $\mathbf{e}$ and encoded $\mathbf{d}$ into the color MLP:
    $$ \mathbf{c} = \text{MLP}_{\text{color}}(\mathbf{e}, \mathbf{d}) $$

5.  **Loss Calculation:**
    *   **Reconstruction Loss ($L_{\text{recon}}$):** Mean Squared Error between rendered color $\hat{C}(\mathbf{r})$ and ground truth $C(\mathbf{r})$ over sampled rays $\mathcal{R}$:
        $$ L_{\text{recon}} = \sum_{\mathbf{r} \in \mathcal{R}} ||\hat{C}(\mathbf{r}) - C(\mathbf{r})||_2^2 $$
    *   **Sparsity Loss ($L_{\text{sparsity}}$):** Cauchy loss to encourage sparse density, accelerating rendering by allowing empty space skipping via occupancy grids:
        $$ L_{\text{sparsity}} = \sum_{i,k} \log(1 + 2\sigma(\mathbf{r}_i(t_k))^2) $$
    *   **Total Loss:**
        $$ L = L_{\text{recon}} + \lambda_{\text{sparsity}} L_{\text{sparsity}} $$

## Operating characteristics
*   **Storage:** Extremely compact. The base model (Ours-B2) uses approximately 0.5 MB, significantly less than Instant-NGP (24.5 MB) and TensoRF-CP (3.7 MB) on the mic scene [S1].
*   **Training Time:** Approximately 6–14 minutes per scene on an NVIDIA RTX A6000 for Synthetic-NeRF scenes, depending on model size (Ours-B2 to Ours-B8) [S1].
*   **Performance:** Achieves PSNR of 32.03 dB on Synthetic-NeRF, 34.48 dB on Synthetic-NSVF, and 28.20 dB on Tanks and Temples [S1].
*   **Strengths:** Minimal storage footprint; no post-processing compression required; faster rendering due to sparsity regularization [S1].
*   **Limitations:** Hash collisions in 3D grids at high resolutions are mitigated by 2D grids but remain a factor; requires careful tuning of $\lambda_{\text{sparsity}}$ [S1].
*   **Hardware:** Implemented on NVIDIA RTX A6000 [S1].

## Background
Binary Radiance Fields were proposed by Seungjoo Shin and Jaesik Park from POSTECH and Seoul National University, published in December 2023 (arXiv:2306.07581v2) [S1]. The method builds on Instant-NGP's multi-resolution hash encoding  and NerfAcc's occupancy grid , aiming to solve the storage bottleneck of neural radiance fields by replacing real-valued features with binary ones during training.
