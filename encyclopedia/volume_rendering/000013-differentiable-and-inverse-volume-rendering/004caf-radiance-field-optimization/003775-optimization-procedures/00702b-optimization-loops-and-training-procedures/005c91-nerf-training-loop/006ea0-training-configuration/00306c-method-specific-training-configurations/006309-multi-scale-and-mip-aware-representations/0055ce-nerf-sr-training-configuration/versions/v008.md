# NeRF-SR Training Configuration

Also called: NeRF-SR, NeRF Super-Resolution

## Overview
NeRF-SR is a training configuration designed to synthesize high-resolution novel views from low-resolution input images by optimizing a neural radiance field with a supersampling strategy [S1]. It differs from standard NeRF training by explicitly leveraging 3D consistency to recover high-frequency details that are lost during low-resolution rendering, addressing the limitation that standard NeRF cannot effectively super-resolve from LR inputs without retraining on HR data [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Low-resolution (LR) training images (e.g., 504×378), camera poses, and intrinsic parameters.
*   **Outputs:** A trained neural radiance field capable of rendering high-resolution (HR) images (e.g., 1008×756 or higher).

**Data Structures:**
*   **Neural Network:** Two Multi-Layer Perceptrons (MLPs) for coarse and fine passes, identical in architecture to the baseline NeRF [S1].
*   **Training Data:** A set of $N$ views. For the Blender dataset, 100 views are used for training and 200 are held out for testing [S1]. For the LLFF dataset, all images are used for training [S1].

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** Exponentially decayed from $5 \cdot 10^{-4}$ to $5 \cdot 10^{-6}$ [S1].
*   **Batch Size:** 2048 rays per batch [S1].
*   **Sampling:** Hierarchical sampling with 64 coarse samples and 64 fine samples [S1].
*   **Epochs:** 20 epochs for the Blender dataset; 30 epochs for the LLFF dataset [S1].
*   **Reference Patches (Refinement):** $K=8$ reference patches, each $64 \times 64$ pixels [S1].

**Algorithm Steps:**
1.  **Initialization:** Initialize the coarse and fine MLPs. Set the learning rate to $5 \cdot 10^{-4}$ [S1].
2.  **Ray Sampling:** For each batch, sample 2048 rays from the training images [S1].
3.  **Hierarchical Sampling:**
    *   **Coarse Pass:** Sample 64 points along each ray. Compute density $\sigma$ and color $\mathbf{c}$ using the coarse MLP. Compute opacity $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ and transmittance $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ [Parent].
    *   **Fine Pass:** Use the coarse density distribution to guide importance sampling for 64 fine points. Compute $\sigma$ and $\mathbf{c}$ using the fine MLP [S1].
4.  **Volume Rendering:** Compute the final pixel color $\hat{C}(\mathbf{r})$ using the fine samples:
    $$ \hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i $$
    where $N=64$ [Parent].
5.  **Loss Computation:** Compare the rendered HR pixel colors against the ground truth HR images (upsampled from LR inputs or rendered at HR resolution) using photometric loss [S1].
6.  **Optimization:** Update network parameters using the Adam optimizer with the exponentially decaying learning rate [S1].
7.  **Iteration:** Repeat steps 2–6 for the specified number of epochs (20 for Blender, 30 for LLFF) [S1].

**Refinement Network (Optional Post-Processing):**
For real-world datasets like LLFF, a refinement network can be applied to boost texture details and edge sharpness [S1].
1.  **Patch Extraction:** Divide the input image into non-overlapping patches [S1].
2.  **Reference Selection:** Select $K=8$ reference patches from a reference image (typically the first image in the dataset) [S1].
3.  **Backprojection:** For each pixel in a target patch, compute the 3D world coordinate using estimated depth and camera parameters, then backproject to the reference image to extract corresponding reference patches [S1].
4.  **Refinement:** Input the target patch and reference patches into the refinement network to produce the refined patch [S1].
5.  **Stitching:** Stitch the refined patches together to form the final high-resolution image [S1].

**Edge Cases and Pitfalls:**
*   **Scale Factor:** The method does not support arbitrary-scale super-resolution; it is trained for specific scale factors (e.g., $\times 2, \times 4$) [S1].
*   **Real-world Data:** Supersampling alone is insufficient for complex real-world scenes (LLFF); the refinement network is necessary for scale factors $\ge 4$ [S1].
*   **Metrics:** Evaluation uses PSNR, SSIM, and LPIPS [S1].

## Subtopics

### Refinement Network (Ours-Refine)
A post-processing module that boosts NeRF-SR outputs with texture details and edge sharpness, particularly for real-world LLFF datasets where supersampling alone is insufficient [S1]. It uses a fixed number of $K=8$ reference patches of size $64 \times 64$ [S1]. During inference, input images are divided into non-overlapping patches, refined using reference patches, and stitched together [S1]. It is necessary for scale factor 4, where supersampling derives fewer details, but provides only marginal PSNR improvement for scale factor 2, though LPIPS improves [S1].

## Operating characteristics
**Time and Memory Complexity:**
*   **Training Time:** Comparable to training a standard HR NeRF, as it consumes no more time than training a HR NeRF directly [S1].
*   **Inference Time:** For a $1008 \times 756$ image on a single 1080Ti, NeRF’s MLP rendering takes ~48 seconds, and the refinement stage adds 1.3 seconds [S1].

**Measured Performance:**
*   **LLFF Dataset (Scale $\times 2$):** PSNR 27.34, SSIM 0.842, LPIPS 0.103 (with refinement) [S1].
*   **LLFF Dataset (Scale $\times 4$):** PSNR 25.59, SSIM 0.759, LPIPS 0.165 (with refinement) [S1].
*   **Comparison:** Outperforms NeRF, NeRF-Bi (bicubic upsampling), NeRF-Liif, and NeRF-Swin on the LLFF dataset [S1].

**Strengths and Limitations:**
*   **Strengths:** Achieves photorealistic renderings from mostly low-resolution inputs without external data by exploiting 3D consistency [S1].
*   **Limitations:** Does not support arbitrary-scale super-resolution; introduces extra computational overhead compared to standard NeRF, though less than training a full HR NeRF [S1].

## Background
NeRF-SR was introduced to address the inability of standard NeRF to super-resolve from low-resolution inputs. It was presented by Wang et al. in the paper "NeRF-SR: High-Quality Neural Radiance Fields using Supersampling" [S1]. The method builds on the original NeRF framework [32] and utilizes hierarchical sampling and supersampling strategies to recover high-frequency details [S1].
