# KFD-NeRF

Also called: Kalman Filter Guided Deformation Field NeRF, Kalman Filter Guided Dynamic NeRF

## Overview
KFD-NeRF is a dynamic neural radiance field method that models the 4D radiance field as a dynamic system with temporally varying states, estimated using a Kalman filter to combine observations from input data and predictions based on local linear motion equations [S1]. It differs from sibling methods like [Gear-NeRF](13848-gear-nerf.md) and [NeRF with Time Parameter](14705-nerf-with-time-parameter.md) by explicitly separating motion estimation into an observation branch (shallow MLP) and a prediction branch (linear motion model), weighted by a learnable Kalman gain, rather than directly conditioning a single network on time or using rigid/semi-rigid deformation priors [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D point coordinates $\mathbf{x}$, timestamp $t_i$, and previous frame deformation states $d\mathbf{x}_{t_{i-1}}, d\mathbf{x}_{t_{i-2}}$ and noise terms $\varepsilon_{t_{i-1}}, \varepsilon_{t_{i-2}}$.
*   **Outputs:** Estimated deformation $\hat{d\mathbf{x}}_{t_i}$ for the current frame, which warps $\mathbf{x}$ to the canonical space. The canonical space features are then queried to render color and density.

**Data Structures:**
1.  **Tri-Plane Representation:** Three mutually orthogonal 2D planes encode the canonical space. Features are concatenated with raw coordinate inputs to handle coordinate shift errors [S1].
2.  **Observer MLP:** A two-layer shallow MLP takes $(\mathbf{x}, t_i)$ and outputs mean observation $y_{t_i}$ and noise-related terms $\varepsilon_{t_i}$ [S1].
3.  **Kalman Gain Network:** A linear layer $f$ takes $(\varepsilon_{t_i}, \varepsilon_{t_{i-1}}, t_i, t_{i-1})$ and outputs the Kalman gain $K_{t_i}$ [S1].

**Numbered Steps:**
1.  **Observer Query:** For the current frame $t_i$, query the observer MLP with $\mathbf{x}$ and $t_i$ to obtain observation $y_{t_i}$ and noise term $\varepsilon_{t_i}$ [S1].
2.  **Velocity Calculation:** Approximate velocity $v_{t_i}$ using deformations from the previous two frames:
    $$
    v_{t_i} = (d\mathbf{x}_{t_{i-1}} - d\mathbf{x}_{t_{i-2}}) / \Delta t_i
    $$
    where $\Delta t_i$ is the time interval [S1].
3.  **Prediction:** Calculate the predicted deformation state $\hat{d\mathbf{x}}_{t_i}^{-}$ using local linear motion:
    $$
    \hat{d\mathbf{x}}_{t_i}^{-} = d\mathbf{x}_{t_{i-1}} + \Delta t_i \cdot v_{t_i} = 2d\mathbf{x}_{t_{i-1}} - d\mathbf{x}_{t_{i-2}}
    $$
    [S1].
4.  **Kalman Gain Calculation:** Compute $K_{t_i}$ using the linear layer $f$:
    $$
    K_{t_i} = f(\varepsilon_{t_i}, \varepsilon_{t_{i-1}}, t_i, t_{i-1})
    $$
    [S1].
5.  **Deformation Estimation:** Combine observation and prediction:
    $$
    \hat{d\mathbf{x}}_{t_i} = \hat{d\mathbf{x}}_{t_i}^{-} + K_{t_i} (y_{t_i} - \hat{d\mathbf{x}}_{t_i}^{-})
    $$
    [S1].
6.  **Warping:** Warp all points $\mathbf{x}$ to the canonical space using $\hat{d\mathbf{x}}_{t_i}$.
7.  **Rendering:** Query the tri-plane representation in the canonical space to render color and density [S1].

**Formulas:**
*   **Kalman Loss:** Minimizes error between observation and estimated deformation:
    $$
    \mathcal{L}_{kf} = \frac{1}{\mathcal{N}} \sum_{\mathbf{x} \in \mathcal{N}} \| y_{t_i} - \hat{d\mathbf{x}}_{t_i} \|_2^2
    $$
    [S1].
*   **Canonical Observation Loss:** Soft regularization for frame $t_0$:
    $$
    \mathcal{L}_{co} = \frac{1}{\mathcal{N}} \sum_{\mathbf{x} \in \mathcal{N}} \mathbb{1}(t) d\mathbf{x}
    $$
    where $\mathbb{1}(t) = 1$ if $t=0$ and $0$ otherwise [S1].
*   **Total Variation Loss:** Encourages sparse edges in the tri-plane:
    $$
    \mathcal{L}_{tv}(\mathbf{x}) = \frac{1}{|C|} \sum_{c, i, j} (\| \mathbf{x}_c^{i,j} - \mathbf{x}_c^{i-1,j} \|_2^2 + \| \mathbf{x}_c^{i,j} - \mathbf{x}_c^{i,j-1} \|_2^2)
    $$
    where $c$ is a plane from collection $C$ [S1].
*   **Total Loss:**
    $$
    \mathcal{L} = \mathcal{L}_{image} + \mathcal{L}_{kf} + \mathcal{L}_{co} + \mathcal{L}_{prop} + \lambda_{tv} \mathcal{L}_{tv}
    $$
    [S1].

**Parameters:**
*   $\lambda_{tv}$: Total variation weight, experimentally chosen as $1 \times 10^{-4}$ [S1].
*   Observer MLP depth: 2 layers [S1].

**Pseudocode:**
```python
def kfd_nerf_deformation_step(x, t_i, t_prev, d_x_prev, d_x_prev_prev, 
                              epsilon_prev, observer_mlp, kalman_gain_net):
    """
    Computes the deformation for point x at time t_i using Kalman filtering.
    
    Args:
        x: 3D point coordinates.
        t_i: Current timestamp.
        t_prev: Previous timestamp.
        d_x_prev: Deformation at t_prev.
        d_x_prev_prev: Deformation at t_prev_prev.
        epsilon_prev: Noise term at t_prev.
        observer_mlp: Two-layer MLP for observations.
        kalman_gain_net: Linear layer for Kalman gain.
        
    Returns:
        Estimated deformation d_x_hat.
    """
    # Step 1: Observer Query for current frame
    y_t_i, epsilon_t_i = observer_mlp(x, t_i)
    
    # Step 2: Velocity Calculation
    # Approximate velocity using previous two frames' deformations
    delta_t = t_i - t_prev
    v_t_i = (d_x_prev - d_x_prev_prev) / delta_t
    
    # Step 3: Prediction
    # Local linear motion prediction
    d_x_pred = d_x_prev + delta_t * v_t_i
    
    # Step 4: Kalman Gain Calculation
    # Learnable gain based on noise terms and timestamps
    K_t_i = kalman_gain_net(epsilon_t_i, epsilon_prev, t_i, t_prev)
    
    # Step 5: Update
    # Combine prediction and observation
    d_x_hat = d_x_pred + K_t_i * (y_t_i - d_x_pred)
    
    return d_x_hat, y_t_i, epsilon_t_i
```

**Edge Cases and Pitfalls:**
*   **Initial Training:** Predictions primarily influence the process to facilitate convergence for frames with substantial motion [S1].
*   **Late Training:** Observations take precedence to recover precise and fine-grained motion details [S1].
*   **Coordinate Shift:** Tri-plane encoding introduces coordinate shift errors; concatenating raw coordinates mitigates this [S1].

## Subtopics

### Tri-Plane Representation
A spatial encoding using three orthogonal 2D planes, allowing for faster convergence and lower memory usage compared to MLP-based backbones, enabling a shallower observer MLP [S1].

### Deformation Field vs. Feature Interpolation
KFD-NeRF uses deformation fields $D(\mathbf{x}, t) \rightarrow \Delta \mathbf{x}$ instead of time-conditioned feature interpolation $F(\mathbf{x}, t) \rightarrow \mathbf{f}$. Deformation fields are smoother and easier to fit with MLPs due to inductive smoothness bias, whereas feature interpolation exhibits high-frequency signals during abrupt radiance changes [S1].

## Operating characteristics
*   **Performance (Synthetic):** PSNR 35.73 dB, SSIM 0.984, LPIPS 0.045, Average 0.0131 [S1].
*   **Performance (Real):** PSNR 28.75 dB, SSIM 0.891, LPIPS 0.115, Average 0.0389 [S1].
*   **Training Time:** 30 minutes (small model) to 3 hours (large model) on real data, comparable to or faster than baselines like D-NeRF (48 hrs) and TiNeuVox-B (40 mins) [S1].
*   **Memory:** Parameter size ranges from 175 MB to 175 MB for KFD-NeRF variants, competitive with voxel-based methods [S1].
*   **Strengths:** Accurate deformation estimation from scene observations and predictions; efficient tri-plane representation; robust handling of dynamic scenes via Kalman filtering [S1].
*   **Limitations:** Relies on local linear motion assumption, which may not capture complex non-linear motions perfectly [S1].

## Background
KFD-NeRF was introduced by Li et al. in 2024, drawing inspiration from control theory to model 4D radiance fields as dynamic systems [S1]. It addresses the limitations of previous dynamic NeRF methods that either disregard motion priors or use rigid/semi-rigid assumptions, by integrating a Kalman filter to optimize state estimations from both observations and predictions [S1].
