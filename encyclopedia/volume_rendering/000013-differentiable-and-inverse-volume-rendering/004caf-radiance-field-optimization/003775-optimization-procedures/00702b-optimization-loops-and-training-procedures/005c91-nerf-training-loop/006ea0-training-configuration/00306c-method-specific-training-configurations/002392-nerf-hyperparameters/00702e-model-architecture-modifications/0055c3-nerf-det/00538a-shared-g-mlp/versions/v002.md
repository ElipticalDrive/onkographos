# Shared G-MLP

Also called: NeRF-Det

## Overview
The Shared G-MLP is a component of the NeRF-Det architecture that links the Neural Radiance Field (NeRF) branch with the 3D object detection branch using a shared geometry-based Multi-Layer Perceptron [S1]. It enables gradient flow from the NeRF branch to the detection branch, propagating multi-view consistency constraints to the detector [S2]. This joint training setup improves upon NeRF-to-Det approaches by directly integrating the branches [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D spatial coordinates $(x, y, z)$ sampled along rays or within the voxel grid [S1, S2].
*   **Output:** A geometry-aware feature representation used by both the volume rendering loss and the detection head [S1, S2].

**Data Structures:**
*   **Shared G-MLP:** A standard Multi-Layer Perceptron [G]. The specific layer dimensions, activation functions, and weight initialization are not given in the sources [G].

**Steps:**
1.  **Coordinate Sampling:** Sample 3D points along rays or within the 3D volume feature grid [S1, S2].
2.  **Geometry Encoding:** Pass the 3D coordinates through the Shared G-MLP to obtain a geometry-aware feature or density value [S1, S2].
3.  **Joint Optimization:** The geometry output is used by the NeRF branch to compute volume rendering losses [S1]. The same output is used by the detection branch to estimate opacity fields for 3D bounding box regression [S1]. Gradients from both losses flow back through the Shared G-MLP weights [S2].
4.  **Free Space Masking:** The shared geometry signal effectively masks out free space in the feature volume, reducing ambiguity for the detection head [S1].

**Formulas:**
Not given in the sources [G].

**Parameters:**
*   **MLP Depth/Width:** Not given in the sources [G].
*   **Activation Function:** Not given in the sources [G].

**Edge Cases and Pitfalls:**
*   **Performance Degradation:** Removing the shared G-MLP causes a drastic performance drop in 3D object detection [S2]. Specifically, mAP@.25 decreases from 50.1 to 48.1 [S2]. This occurs because the influence of multi-view consistency is restricted to the image backbone rather than the volumetric representation [S2].

## Subtopics

### NeRF-Det
The parent method that utilizes the Shared G-MLP for joint NeRF and detection training [S1]. It explicitly models scene geometry as an opacity field to improve indoor 3D object detection from posed RGB images [S1, S2]. [Link](15549-nerf-det.md)

## Operating characteristics
**Time and Memory Complexity:**
Not given in the sources [G].

**Measured Performance:**
*   In the ablation study, the method achieves an mAP@.25 of 50.1 and mAP@.50 of 24.4 when using the Shared G-MLP with multi-view 2D feature sampling [S2].
*   Without the Shared G-MLP, performance drops to 48.1 mAP@.25 and 23.8 mAP@.50 [S2].

**Strengths and Limitations:**
*   **Strengths:** Enables direct gradient flow from NeRF to the detection branch, effectively masking free space and reducing feature volume ambiguity [S1]. Propagates multi-view consistency constraints to the detection module [S2].
*   **Limitations:** Requires joint training of NeRF and detection branches [S1].

**When to Use:**
Use when performing joint NeRF-and-detection tasks where multi-view consistency is critical for accurate 3D bounding box regression and free-space suppression [S1, S2].

## Background
The Shared G-MLP was introduced in the NeRF-Det paper [S2]. It addresses limitations in previous NeRF-to-Det approaches by ensuring the NeRF branch sufficiently influences the detection branch [S1]. The method builds on the concept of using neural volumetric features for direct 3D bounding box regression [S1].
