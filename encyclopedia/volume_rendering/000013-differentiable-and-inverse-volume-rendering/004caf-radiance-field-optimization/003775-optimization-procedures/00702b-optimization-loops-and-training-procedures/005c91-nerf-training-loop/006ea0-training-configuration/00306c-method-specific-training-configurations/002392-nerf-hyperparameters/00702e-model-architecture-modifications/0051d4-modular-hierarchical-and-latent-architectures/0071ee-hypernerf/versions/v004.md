# HyperNeRF

Also called: Hyper-Space Template, Hyper-space Neural Radiance Fields, HyperNeRF (2021), HyperNeRF Template

## Overview
HyperNeRF is a method for modeling non-rigidly deforming scenes with topological variations (e.g., openings, closings, or peeling) by extending the canonical space of a Neural Radiance Field into a higher-dimensional ambient space [S3][S4, unofficial]. It addresses the limitation of continuous deformation fields, which cannot model discontinuities required for topological changes, by treating each observation frame as a non-planar slice through a hyperdimensional "template" NeRF [S3][S5, unofficial]. Unlike strictly deformation-based approaches like Nerfies, HyperNeRF combines deformation with latent conditioning in higher dimensions, allowing it to capture topology changes by sacrificing hard spatial correspondences [S2, S4, unofficial].

## How it works
HyperNeRF builds on [Deformable NeRF (Nerfies)](14015-strata-nerf.md) by embedding the scene representation in a higher-dimensional space. The core idea is that a 3D scene undergoing topological change can be represented as a static object in a higher-dimensional ambient space, where the observed 3D scene is a "slice" through this hyper-space [S3].

### Inputs and Outputs
*   **Inputs:** A set of $N$ images $\{I_i\}_{i=1}^N$ with known camera poses, viewing directions $\mathbf{d}$, and spatial coordinates $\mathbf{x}$.
*   **Outputs:** A rendered color $\mathbf{c}$ and volume density $\sigma$ for any ray $(\mathbf{x}, \mathbf{d})$ at a specific "moment" or observation index $i$.

### Data Structures and Networks
The method consists of three primary neural networks (MLPs):

1.  **Deformation Field ($W$):** Maps observation-space coordinates to canonical hyper-space coordinates.
    *   Input: Spatial position $\mathbf{x} \in \mathbb{R}^3$, latent deformation code $\boldsymbol{\omega}_i \in \mathbb{R}^{D_\omega}$.
    *   Output: A vector in $\mathfrak{se}(3)$ encoding rotation $\mathbf{r}$ and translation $\mathbf{v}$ [S3].
    *   Note: This is identical to the deformation field in Nerfies [S3].

2.  **Ambient Slicing Surface ($H$):** Defines the non-planar surface that slices the hyper-space to yield the 3D scene for observation $i$.
    *   Input: Spatial position $\mathbf{x} \in \mathbb{R}^3$, latent deformation code $\boldsymbol{\omega}_i$.
    *   Output: Ambient coordinates $\mathbf{w} \in \mathbb{R}^W$.
    *   The slicing surface is defined as $\mathbf{w} = H(\mathbf{x}, \boldsymbol{\omega}_i)$ [S3].

3.  **Template NeRF ($F$):** The radiance field defined in the canonical hyper-space.
    *   Input: Canonical spatial position $\mathbf{x}' \in \mathbb{R}^3$, ambient coordinates $\mathbf{w} \in \mathbb{R}^W$, viewing direction $\mathbf{d} \in \mathbb{R}^3$, latent appearance code $\boldsymbol{\psi}_i \in \mathbb{R}^{D_\psi}$.
    *   Output: Color $\mathbf{c} \in \mathbb{R}^3$ and density $\sigma \in \mathbb{R}$ [S3].
    *   Formula: $F: (\mathbf{x}', \mathbf{w}, \mathbf{d}, \boldsymbol{\psi}_i) \rightarrow (\mathbf{c}, \sigma)$ [S3].

### Parameters
*   $W$: Number of ambient dimensions. Typical value: 2 [S3].
*   $m$: Number of sinusoids in positional encoding. $m=6$ for spatial input $\mathbf{x}$ to $H$; $m=1$ for ambient input $\mathbf{w}$ to $F$ [S3].
*   $\alpha$: Bandwidth control parameter for coarse-to-fine optimization [S3].

### Numbered Steps

1.  **Positional Encoding:**
    Apply sinusoidal positional encoding $\gamma(\cdot)$ to inputs. For a coordinate $\mathbf{u}$ and bandwidth parameter $m$:
    $$ \gamma(\mathbf{u}) = [\sin(\mathbf{u}), \cos(\mathbf{u}), \dots, \sin(2^{m-1}\mathbf{u}), \cos(2^{m-1}\mathbf{u})]^T $$
    For optimization, use windowed positional encoding $\gamma_\alpha(\mathbf{u})$ to control the Neural Tangent Kernel (NTK) bandwidth [S3]:
    $$ \gamma_\alpha(\mathbf{u}) = [w_0(\alpha)\sin(\mathbf{u}), \dots, w_{m-1}(\alpha)\cos(2^{m-1}\mathbf{u})]^T $$
    where $w_j(\alpha) = \frac{1 - \cos(\pi \text{clamp}(\alpha - j, 0, 1))}{2}$ and $\alpha$ increases linearly from 0 to $m$ [S3].

2.  **Deformation (Observation to Canonical Space):**
    For a pixel at observation $i$ with spatial coordinate $\mathbf{x}$ and latent code $\boldsymbol{\omega}_i$:
    *   Compute deformation parameters $(\mathbf{r}, \mathbf{v}) = W(\gamma(\mathbf{x}), \boldsymbol{\omega}_i)$.
    *   Apply the rigid transformation defined by $(\mathbf{r}, \mathbf{v})$ to $\mathbf{x}$ to get the canonical spatial coordinate $\mathbf{x}'$.
    *   Note: The deformation field $W$ is shared across all observations but conditioned on $\boldsymbol{\omega}_i$ [S3].

3.  **Slicing Surface Evaluation:**
    *   Compute the ambient coordinates $\mathbf{w}$ for the current spatial position $\mathbf{x}$ and observation $i$:
        $$ \mathbf{w} = H(\gamma(\mathbf{x}), \boldsymbol{\omega}_i) $$
    *   This $\mathbf{w}$ represents the "height" or position along the ambient axes for the slice at $\mathbf{x}$ [S3].

4.  **Template NeRF Query:**
    *   Construct the full input to the template NeRF $F$:
        *   Spatial: $\mathbf{x}'$ (from Step 2).
        *   Ambient: $\mathbf{w}$ (from Step 3).
        *   Direction: $\mathbf{d}$ (ray direction).
        *   Appearance: $\boldsymbol{\psi}_i$ (latent appearance code for frame $i$) [S3].
    *   Query the network:
        $$ (\mathbf{c}, \sigma) = F(\gamma(\mathbf{x}'), \gamma(\mathbf{w}), \gamma(\mathbf{d}), \boldsymbol{\psi}_i) $$
    *   Note: The input $\mathbf{w}$ to $F$ is typically encoded with $m=1$ [S3].

5.  **Volume Rendering:**
    *   Integrate $(\mathbf{c}, \sigma)$ along the ray using standard volume rendering equations to produce the final pixel color [G].

### Pseudocode

```python
import jax.numpy as jnp
from jax import grad, jit

def positional_encoding(x, m):
    """
    Standard sinusoidal positional encoding.
    x: (..., D)
    m: int, number of frequency bands
    Returns: (..., D * 2 * m)
    """
    freq_bands = 2.0 ** jnp.arange(m)
    scaled_x = x[..., None, :] * freq_bands[None, None, :]
    encoded = jnp.concatenate([jnp.sin(scaled_x), jnp.cos(scaled_x)], axis=-1)
    return encoded

def windowed_positional_encoding(x, m, alpha):
    """
    Windowed positional encoding for coarse-to-fine optimization.
    x: (..., D)
    m: int
    alpha: float, bandwidth control parameter [0, m]
    Returns: (..., D * 2 * m)
    """
    freq_bands = 2.0 ** jnp.arange(m)
    scaled_x = x[..., None, :] * freq_bands[None, None, :]
    
    # Window function w_j(alpha)
    j_indices = jnp.arange(m)
    # clamp(alpha - j, 0, 1)
    clamped = jnp.clip(alpha - j_indices, 0.0, 1.0)
    # (1 - cos(pi * clamped)) / 2
    weights = (1.0 - jnp.cos(jnp.pi * clamped)) / 2.0
    
    # Apply weights to sin and cos components
    sin_part = jnp.sin(scaled_x) * weights[None, None, :]
    cos_part = jnp.cos(scaled_x) * weights[None, None, :]
    
    return jnp.concatenate([sin_part, cos_part], axis=-1)

def hypernerf_forward(x_obs, d, omega_i, psi_i, params, m_spatial=6, m_ambient=1):
    """
    Forward pass for HyperNeRF.
    
    Args:
        x_obs: (..., 3) Observation space spatial coordinates.
        d: (..., 3) Viewing directions.
        omega_i: (..., D_omega) Latent deformation code for frame i.
        psi_i: (..., D_psi) Latent appearance code for frame i.
        params: Dictionary containing weights for W, H, F.
        m_spatial: int, positional encoding bands for spatial input.
        m_ambient: int, positional encoding bands for ambient input.
        
    Returns:
        color: (..., 3) Rendered color.
        density: (..., 1) Volume density.
    """
    
    # 1. Deformation Field W: x_obs, omega_i -> se(3)
    # W takes encoded spatial pos and latent code
    x_obs_enc = windowed_positional_encoding(x_obs, m_spatial, alpha=1.0) # Alpha handled in training loop
    w_input = jnp.concatenate([x_obs_enc, omega_i], axis=-1)
    se3_params = MLP_W(w_input, params['W']) # Returns (..., 6)
    r, v = jnp.split(se3_params, 2, axis=-1)
    
    # Apply rigid transformation to x_obs to get x_canonical
    # Note: Simplified rigid transform application. 
    # In practice, r and v are used to construct a 4x4 matrix or applied via rotation/translation.
    x_canonical = apply_se3_transform(x_obs, r, v) 
    
    # 2. Slicing Surface H: x_obs, omega_i -> w (ambient coords)
    # H takes encoded spatial pos and latent code
    h_input = jnp.concatenate([x_obs_enc, omega_i], axis=-1)
    w_ambient = MLP_H(h_input, params['H']) # Returns (..., W)
    
    # 3. Template NeRF F: x_canonical, w_ambient, d, psi_i -> c, sigma
    # Encode all inputs
    x_can_enc = windowed_positional_encoding(x_canonical, m_spatial, alpha=1.0)
    w_enc = windowed_positional_encoding(w_ambient, m_ambient, alpha=1.0)
    d_enc = windowed_positional_encoding(d, m_spatial, alpha=1.0)
    
    f_input = jnp.concatenate([x_can_enc, w_enc, d_enc, psi_i], axis=-1)
    output = MLP_F(f_input, params['F']) # Returns (..., 4) -> [c_r, c_g, c_b, sigma]
    
    color = output[..., :3]
    density = output[..., 3:]
    
    return color, density

def apply_se3_transform(x, r, v):
    """
    Applies a rigid transformation defined by rotation r and translation v to x.
    r: (..., 3) rotation vector (axis-angle or similar)
    v: (..., 3) translation vector
    Returns: (..., 3) transformed coordinates.
    """
    # Convert rotation vector to rotation matrix R
    R = rotation_vector_to_matrix(r)
    # x' = R @ x + v
    # Broadcasting: R is (..., 3, 3), x is (..., 3)
    rotated_x = jnp.einsum('...ij,...j->...i', R, x)
    return rotated_x + v

def rotation_vector_to_matrix(r):
    """
    Converts a rotation vector (axis-angle) to a rotation matrix.
    r: (..., 3)
    Returns: (..., 3, 3)
    """
    # Implementation of Rodrigues' rotation formula
    # This is a standard math operation, assumed available or implemented
    theta = jnp.linalg.norm(r, axis=-1, keepdims=True)
    axis = r / (theta + 1e-8)
    sin_theta = jnp.sin(theta)
    cos_theta = jnp.cos(theta)
    I = jnp.eye(3)
    K = jnp.array([[[0, -axis[..., 2], axis[..., 1]],
                    [axis[..., 2], 0, -axis[..., 0]],
                    [-axis[..., 1], axis[..., 0], 0]]])
    # R = I + sin(theta)*K + (1-cos(theta))*K^2
    # Note: Broadcasting K needs to match batch dims
    # Simplified for pseudocode clarity
    K_skew = jnp.zeros_like(r)[..., None, :] # Placeholder for skew-symmetric matrix construction
    # Actual implementation requires careful broadcasting
    return I + sin_theta * K_skew + (1 - cos_theta) * jnp.matmul(K_skew, K_skew)
```

### Edge Cases and Pitfalls
*   **Topological Discontinuities:** Continuous deformation fields (like Nerfies) fail on topological changes because MLPs with positional encoding perform band-limited interpolation, making it difficult to model the discontinuities required for openings/closings [S3]. HyperNeRF solves this by using higher dimensions.
*   **Elastic Regularization:** The elastic regularization loss from Nerfies (penalizing non-unit singular values of the deformation Jacobian) is ill-suited for HyperNeRF because topological variations violate the as-rigid-as-possible assumption [S3].
*   **Camera Registration:** HyperNeRF is dependent on accurate camera registration. Poor registration leads to artifacts or degraded performance [S4, unofficial].
*   **Occlusions and Rapid Motion:** The method is limited to observed data and cannot faithfully reconstruct rapid motion or occluded regions [S4, unofficial].
*   **Illumination and Transients:** HyperNeRF fails on real-world photos with varying illumination and transient occluders (e.g., people walking through the scene) [S4, unofficial].
*   **Ambient Dimension Choice:** Increasing the number of ambient dimensions $W$ beyond 2 did not improve performance in the original experiments, suggesting $W=2$ is sufficient for the tested sequences [S3].

## Operating characteristics
*   **Time Complexity:** Training is computationally intensive. The original implementation trained at half 1080p resolution (960x540) for 250k iterations, taking roughly 8 hours on 4 TPU v4s. Full-HD training took roughly 64 hours [S3].
*   **Memory Complexity:** Depends on the size of the MLPs ($W, H, F$) and the batch size. The method uses 128 samples per ray during training [S3].
*   **Performance:** HyperNeRF outperforms Nerfies, reducing average error rates by 4.1% for interpolation and 8.6% for novel-view synthesis, as measured by LPIPS [S3].
*   **Strengths:** Capable of modeling topological changes (e.g., mouth opening, banana peeling) which are impossible for standard deformation-based NeRFs [S1, S3].
*   **Limitations:** Requires precise camera poses; struggles with unobserved regions, rapid motion, and transient occlusions; sensitive to illumination changes [S4, unofficial].

## Background
HyperNeRF was introduced by Keunhong Park et al. in June 2021 [S1, S3]. It is an extension of Deformable NeRF (Nerfies) [S2, unofficial]. The method is inspired by level set methods pioneered in the late 1980s by Osher and Sethian, which model moving scenes as static objects in a higher-dimensional ambient space [S3]. HyperNeRF adapts this framework to neural radiance fields, using MLPs to represent general, curved slicing manifolds rather than restricting them to hyperplanes [S3]. It was designed to address the limitations of continuous deformation fields in modeling topological variations in dynamic scenes [S3].
