# Spherical Harmonics Regularization

Also called: SH coefficient masking, SH curriculum training, SH degree regularization

## Overview
Spherical Harmonics Regularization is a training strategy that restricts the maximum degree of Spherical Harmonics (SH) during the early stages of radiance field optimization to prevent high-frequency overfitting and stabilize geometry reconstruction [S1, S2]. It differs from sibling methods by applying this frequency constraint directly to the SH coefficients within a voxel grid representation, rather than to positional encodings or Fourier features [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** Radiance field parameters including voxel opacity, SH coefficients (for degrees 0–3), and potentially white balance/CRF parameters; multi-view LDR images.
*   **Output:** Updated SH coefficients and other radiance field parameters optimized under the regularization constraint.

**Data Structures:**
*   **SH Coefficients:** Stored per voxel. For degree $L$, there are $(L+1)^2$ coefficients. Degrees 0–3 are typically used, totaling $1+4+9+16=30$ coefficients per voxel [S1].
*   **Mask/State:** A boolean or integer state tracking the maximum allowable SH degree for the current training epoch.

**Steps:**
1.  **Initialization:** Initialize SH coefficients for all degrees (0–3) [S1].
2.  **Early Stage Constraint (Epochs 0–4):**
    *   Restrict the maximum SH degree used for color/feature representation to a low value (e.g., degree 0 or 1, representing diffuse reflectance) [S1, S2].
    *   Apply "SH masking" to coefficients of higher degrees (specifically degrees 2 and 3) [S1]. This prevents gradients from updating high-frequency components that can cause instability [S1].
    *   The masking rate decreases by $1/5$ per epoch during these first five epochs [S1]. This implies a gradual release of constraints:
        *   Epoch 0: Mask all high-frequency (Degree $\ge 2$) coefficients completely.
        *   Epoch 1: Allow $1/5$ of the high-frequency coefficients to update (or reduce mask strength by 20%).
        *   Epoch 2: Allow $2/5$ update.
        *   Epoch 3: Allow $3/5$ update.
        *   Epoch 4: Allow $4/5$ update.
    *   *Note:* The exact implementation of "decreasing rate by 1/5" is interpreted as a linear schedule of mask relaxation over the first 5 epochs [S1].
3.  **Full Optimization (Epoch $\ge 5$):**
    *   After the early five epochs, update SH coefficients of all degrees with full rate (no masking) [S1].
4.  **Loss Calculation:**
    *   Compute the total loss $\mathcal{L} = \mathcal{L}_{recon} + \lambda_{reg} \mathcal{L}_{reg}$, where $\mathcal{L}_{reg}$ incorporates the effect of the masking (effectively zeroing gradients for masked coefficients) [S1].

**Pseudocode:**
```python
def spherical_harmonics_regularization_step(epoch, max_epochs_early=5, degrees_to_mask=[2, 3]):
    """
    Determines the update mask for SH coefficients based on the current epoch.
    Implements the curriculum schedule from HDR-Plenoxels [S1].
    """
    # Initialize mask for all coefficients to 1.0 (fully active)
    sh_mask = 1.0
    
    if epoch < max_epochs_early:
        # Calculate relaxation rate: 1/5 per epoch
        # Epoch 0: 0/5 relaxed (fully masked)
        # Epoch 1: 1/5 relaxed
        # ...
        # Epoch 4: 4/5 relaxed
        relaxation_rate = epoch / max_epochs_early
        
        # Apply mask to specific high degrees
        # Note: The source specifies masking degrees 2 and 3 [S1]
        # We assume a binary mask or a scaling factor. 
        # "Decrease the rate of SH masking by 1/5" implies the mask strength 
        # (which prevents update) decreases.
        
        # If mask=1 means "blocked", then:
        # Epoch 0: mask=1 (blocked)
        # Epoch 1: mask=0.8 (20% allowed)
        # ...
        # Epoch 4: mask=0.2 (80% allowed)
        
        mask_strength = 1.0 - relaxation_rate
        
        # Apply to degrees 2 and 3
        # In a flattened array or structured tensor, this targets indices 
        # corresponding to l=2 and l=3
        sh_mask[degrees_to_mask] = mask_strength
        
    else:
        # After early epochs, no masking
        sh_mask = 1.0
        
    return sh_mask

def update_sh_coefficients(sh_coeffs, gradients, sh_mask):
    """
    Applies the mask to gradients before updating SH coefficients.
    """
    # Zero out gradients for masked coefficients
    masked_gradients = gradients * sh_mask
    # Standard gradient descent update
    sh_coeffs = sh_coeffs - learning_rate * masked_gradients
    return sh_coeffs
```

**Parameters:**
*   `max_epochs_early`: 5 [S1].
*   `degrees_to_mask`: [2, 3] [S1].
*   `relaxation_step`: 1/5 per epoch [S1].

**Edge Cases:**
*   **Harsh Input Conditions:** The method is specifically designed to stabilize optimization when input data is sparse or noisy ("harsh condition input case") [S1].
*   **White Balance Mismatch:** Without this regularization, if the optimization speed of white balance does not match SH coefficients, ambiguity may arise in later steps [S1].

## Operating characteristics
*   **Time Complexity:** Negligible additional computational cost during training, as masking is a simple multiplication or zeroing operation [S2].
*   **Memory Complexity:** No additional memory overhead; uses existing SH coefficient storage [S2].
*   **Strengths:** Stabilizes early optimization; prevents high-frequency overfitting; improves coarse geometry reconstruction; reduces floaters near cameras when combined with other techniques [S1, S2].
*   **Limitations:** Requires careful tuning of the early epoch schedule; may slow down convergence if the relaxation is too slow [S1].
*   **When to Use:** Few-shot view synthesis, sparse input scenarios, or when training voxel-based radiance fields (like Plenoxels) [S1, S2].
*   **When Not to Use:** Dense input scenarios with abundant views may not require this stabilization [S1].

## Background
*   **Origin:** Introduced in HDR-Plenoxels (2022) as "SH coefficient masking" to stabilize optimization for high dynamic range radiance fields [S1].
*   **Development:** Later adopted and adapted in F2Plenoxels (2026) as a "curriculum training strategy" to mitigate high-frequency overfitting in few-shot view synthesis [S2].
*   **Inspiration:** Inspired by frequency regularization techniques in FreeNeRF (positional encoding) and FourieRF (Fourier coefficients), but applied to SH coefficients in voxel grids [S2].
*   **Usage:** Used in voxel-based radiance field methods like Plenoxels and its variants [S1, S2].
